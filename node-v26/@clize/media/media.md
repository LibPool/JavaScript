# @clize/media

> 标签: agent, agents, ai, ai-agents, claude-code, clize, codex, gpt-image, image-generation, media-generation, music-generation, text-to-image, text-to-video, veo, video-generation

## 简介

Agent Media — a studio your AI agent operates: images (gpt-image, nano-banana, up to 16 reference images), video (veo) and music, generated from a chat and saved as real files. Every job priced first; a budget you set gates the spend. Installs the Clize C
