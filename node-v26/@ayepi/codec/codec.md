# @ayepi/codec

> 标签: ayepi, bigint, codec, date, json, map, serialization, set

## 简介

Rich JSON codec — tagged, reversible serialization of Date, BigInt, Map, Set, undefined, Error, and custom types through JSON.stringify/parse
