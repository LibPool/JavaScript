# @hookraft/useengagement

> 标签: active-time, analytics, clicks, engagement, hooks, offline, react, scroll, tracking, typescript

## 简介

Silently track user engagement — clicks, scroll depth, active time, idle time. Syncs to your backend on exit with offline queue support.
