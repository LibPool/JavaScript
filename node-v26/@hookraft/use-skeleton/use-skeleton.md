# @hookraft/use-skeleton

> 标签: auto-skeleton, dom-scanning, hooks, loading, nextjs, page-skeleton, react, shimmer, skeleton, typescript

## 简介

Zero-config automatic skeleton loading for React. DOM-scanning engine that generates shimmer overlays for entire pages — no per-component setup needed.
