# @csbc-dev/s3-uploader

> 标签: aws, blob, custom-elements, declarative, presigned-url, s3, upload, wc-bindable, web-components

## 简介

Declarative S3 (and S3-compatible) blob store component for Web Components. Server-side signing, browser-direct upload, no AWS SDK, via wc-bindable-protocol.
