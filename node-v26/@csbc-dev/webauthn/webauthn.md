# @csbc-dev/webauthn

> 标签: custom-elements, declarative, fido2, framework-agnostic, passkey, passwordless, wc-bindable, web-components, webauthn

## 简介

Declarative WebAuthn / Passkeys component for Web Components. Server-side challenge + verification, browser-native credentials.create()/.get(), via wc-bindable-protocol.
