# kid-git

> 标签: explain-code, git-like, grade-3, history, javascript, learn-to-code, python, tsx, typescript, variable-tracer

## 简介

A tiny git-like helper that explains code in grade-3 English, traces variables, and saves history. Supports Python, JavaScript, TypeScript, TSX.
