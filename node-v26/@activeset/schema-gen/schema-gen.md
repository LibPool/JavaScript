# @activeset/schema-gen

> 标签: gemma, json-ld, ollama, schema-org, seo, structured-data, webflow

## 简介

Generate Schema.org JSON-LD recommendations for Webflow static pages using a local Ollama model (Gemma by default). Output is a portable JSON file you can import into the ActiveSet dashboard.
