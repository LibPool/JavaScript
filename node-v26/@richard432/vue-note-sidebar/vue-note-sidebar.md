# @richard432/vue-note-sidebar

> 标签: component, notes, pouchdb, sidebar, tree, vue, vue3

## 简介

A reusable Vue 3 sidebar component for browsing PouchDB-backed notes, with folder tree, tag filtering, per-note tagging, search highlighting and a responsive mobile drawer.
