# @react-haptic/react

> 标签: feedback, haptic, haptics, micro-interactions, mobile, mui, navigator.vibrate, react, shadcn, tailwind, tailwindcss, ux, vibration

## 简介

Bring native iOS/Android-style haptic feedback to the web, declaratively. Zero dependencies. Works with shadcn/ui, MUI, and plain HTML.
