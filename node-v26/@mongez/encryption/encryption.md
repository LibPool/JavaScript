# @mongez/encryption

> 标签: aead, aes, aes-gcm, crypto, crypto-js, decrypt, decryption, encrypt, encryption, hash, md5, mongez, pbkdf2, sha1, sha256, sha512, webcrypto

## 简介

Authenticated encryption for JSON-encodable values using WebCrypto AES-256-GCM with PBKDF2 key derivation, plus the common hash functions (md5, sha1, sha256, sha512) and a legacy crypto-js decrypt path.
