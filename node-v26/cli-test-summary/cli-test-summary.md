# cli-test-summary

> 标签: agents, claude-code, cli, codex, flaky, jest, mcp, mcp-server, pytest, summary, test, test-runner, testing, vitest

## 简介

Run a project's tests and get one JSON answer: pass/fail counts and every failure with file, line and message, for node:test, vitest, jest, pytest, go, cargo and dotnet. Re-runs failures alone to tell real from flaky. CLI, MCP server, Claude Code and Code
