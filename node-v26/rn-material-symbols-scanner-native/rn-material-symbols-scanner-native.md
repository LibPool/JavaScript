# rn-material-symbols-scanner-native

> 标签: material-symbols, metro, napi-rs, oxc, react-native, rn-material-symbols, scanner

## 简介

Optional native (Rust) source scanner for rn-material-symbols: finds the Material Symbols names used in React Native source. Installed automatically as an optional dependency; not meant to be used directly.
