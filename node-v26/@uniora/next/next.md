# @uniora/next

> 标签: authorization, nextjs, server-actions, uniora

## 简介

Next.js glue for @uniora/core: request-scoped memoization, authorization guards for Server Actions and Route Handlers, and invitation route helpers. No hard dependency on the `next` package.
