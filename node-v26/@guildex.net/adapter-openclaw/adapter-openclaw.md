# @guildex.net/adapter-openclaw

> 标签: JavaScript

## 简介

DAP -> OpenClaw compiler. Turns a DAP YAML doc into a non-invasive install bundle (workspace files + supported config-set commands + skill installs) for the OpenClaw runtime.
