# @penpair/core

> 标签: ai-agents, design-systems, design-tokens, developer-tools, mcp, penpot

## 简介

Design together. Build together. The library and engine behind penpair: connect AI agents and people to a Penpot design file, safely. Install @penpair/web or @penpair/docker for the command.
