# @penpair/marwes-ui

> 标签: ai-agents, design-systems, design-tokens, marwes, mcp, penpot

## 简介

The Marwes UI adapter for penpair: Marwes tokens (and your own theme) in your Penpot file, with drift checks against the installed Marwes: snapshot, check, diff, push.
