# @aocommons/paperclip-registry

> 标签: agents, ao-commons, autonomous-organization, paperclip, registry

## 简介

Runs inside a Paperclip operator's environment. Reads their company from the Paperclip API, keeps only allowlisted fields, and writes the sanitized snapshot the AO Commons registry accepts. The Paperclip token never leaves the operator's machine.
