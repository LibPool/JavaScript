# @clickhouse/rowbinary

> 标签: clickhouse, decoder, encoder, parser, rowbinary, skill, streaming, writer

## 简介

RowBinary building blocks for Node.js — read and write (decode/encode) ClickHouse RowBinary / RowBinaryWithNames(AndTypes) streams. Ships with the clickhouse-js-node-rowbinary agent skill.
