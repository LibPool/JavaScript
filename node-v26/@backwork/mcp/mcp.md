# @backwork/mcp

> 标签: backwork, coverage, healthcare, mcp, mcp-server, medical-codes, medical-policy, medicare, model-context-protocol, payer, prior-authorization

## 简介

MCP server for Backwork: Medicare and payer medical policy, prior authorization, claim risk, and medical codes. Hosted OAuth remote or local stdio.
