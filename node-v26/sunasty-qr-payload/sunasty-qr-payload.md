# sunasty-qr-payload

> 标签: matmsg, otpauth, parser, qr, qrcode, rfc6238, totp, vcard, webcrypto, wifi

## 简介

Zero-dependency structured QR payload parser (Wi-Fi, 2FA TOTP otpauth://, vCard, mailto, MATMSG, SMS, tel, URL security analyzer) and RFC 6238 TOTP generator via Web Crypto SubtleCrypto.
