# @kit-dev/react-jql-builder

> 标签: filter-builder, jira, jql, query-builder, react, search, typescript

## 简介

A seamless, schema-driven query builder for React + TypeScript, inspired by Jira's JQL. Visual and free-text modes, live completeness validation, typed schema config.
