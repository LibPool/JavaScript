# @reliantlabs/forge-web-runtime

> 标签: JavaScript

## 简介

The forge frontend runtime: Connect interceptor stack, session, error boundary, toast queue, <Resource> container, W3C trace propagation and client RUM. The web twin of forge/pkg.
