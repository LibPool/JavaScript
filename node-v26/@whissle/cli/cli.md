# @whissle/cli

> 标签: agents, ai, cli, conversational-ai, stt, tts, voice, voice-agents, whissle

## 简介

Command-line interface for the Whissle Voice Agents platform — configure agents, run them, and pull your calls, transcripts and usage for your own evaluation.
