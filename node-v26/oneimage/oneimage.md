# oneimage

> 标签: agent-skill, claude, claude-code, claude-desktop, design, image, playwright, poster, skill, thumbnail

## 简介

Agent skill that turns a prompt into a finished image or image set, rendered locally with free tools. One command installs it for Claude Code and Claude Desktop.
