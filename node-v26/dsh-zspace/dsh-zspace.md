# dsh-zspace

> 标签: deepseek-harness, dsh, dsh-plugin, nas, webdav-alternative, zspace, 极空间

## 简介

极空间（ZSpace）NAS plugin for DeepSeek Harness: cross-network agent tools for browsing, searching, reading, uploading and organizing NAS files through the desktop client's relay — no LAN, no WebDAV, no SSH, no Python.
