# @bricklab/core

> 标签: browser, bun, bwc, nextjs, nodejs, python, runtime, sandbox, wasm, webassembly, webcontainer

## 简介

Run Node, Bun and Python projects fully client-side in the browser: Node's real lib/, the real npm/yarn/pnpm, and real CPython. The framework-agnostic BWC WebContainer SDK.
