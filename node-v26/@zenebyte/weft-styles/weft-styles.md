# @zenebyte/weft-styles

> 标签: JavaScript

## 简介

Weft design system styles — DTCG tokens (Foundations/) compiled to CSS custom properties, JS/TS constants, and flat JSON per theme, plus component skins (Components/) over lumis, compiled to CSS.
