# @bsday.js/dataset

> 标签: astronomical-dataset, bikram-sambat, bsday, bsdayjs, dashain, devanagari, hamro-patro, javascript, karana, nakshatra, nepal, nepali-calendar-dataset, nepali-date, nepali-festivals, nepali-holidays, nepali-patro, panchang, panchangam, tihar, tithi, typescript, vedic-astrology, yoga

## 简介

111-year astronomical Vedic Panchang (Tithi, Nakshatra, Yoga, Karana), Nepali festivals, and government public holidays dataset (1990–2100 BS / 40,543 days) for bsday.js.
