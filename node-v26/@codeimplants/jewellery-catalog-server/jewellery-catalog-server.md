# @codeimplants/jewellery-catalog-server

> 标签: catalog, express, jewellery, mongoose, nodejs, zod

## 简介

Server half of the shared jewellery catalogue: Mongoose schema factories, strict Zod request validation and update helpers for the catalogue and per-shop taxonomy
