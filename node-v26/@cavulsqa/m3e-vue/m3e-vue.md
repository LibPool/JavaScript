# @cavulsqa/m3e-vue

> 标签: capacitor, components, material-3, material-expressive, vue, vue3

## 简介

Material 3 Expressive components for Vue 3: wavy progress, the shape-morphing loading indicator, spring-driven sheets, button groups, flexible navigation, expressive lists and menus, built on @cavulsqa/m3e.
