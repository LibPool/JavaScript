# @verisaegis/verifier

> 标签: aegis, ai-agents, identity, passport, sdk, trust

## 简介

Veris Protocol reference verifier — a local, in-memory implementation of the protocol for self-hosting, testing, and understanding how verification works. Does not call the hosted API.
