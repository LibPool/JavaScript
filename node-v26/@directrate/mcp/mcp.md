# @directrate/mcp

> 标签: award, claude, cursor, directrate, hotel, mcp, model-context-protocol, points, rates

## 简介

directrate hotel rates, member rates, award points, OTA parity, calendars and comp sets as MCP tools — a stdio bridge to https://api.directrate.dev/mcp for clients that only run local servers.
