# @dhlx/red-black-tree

> 标签: JavaScript

## 简介

这是一个用 TypeScript 实现的红黑树 (RBTree) 和基于红黑树的树映射 (TreeMap) 的 npm 包。该实现提供了高效的插入、删除、搜索操作，并支持键值对存储。
