# @aermes/expo-continued-task

> 标签: BGContinuedProcessingTask, BackgroundTasks, background, expo, ios, react-native

## 简介

iOS 26 BGContinuedProcessingTask for Expo apps: long user-started work that keeps running after the user leaves, with the system progress banner — tap-only start, an honest bar, never "Failed", and a grace-grant fallback.
