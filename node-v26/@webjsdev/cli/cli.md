# @webjsdev/cli

> 标签: cli, dev, scaffold, webjs

## 简介

The CLI for WebJs, a full-stack JavaScript framework built on web components with server-side rendering and no build step. Runs the dev and production servers, scaffolds apps, validates conventions, and drives the database. Node 24+ or Bun.
