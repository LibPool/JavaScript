# @chessviewer-org/chess-viewer

> 标签: board, board-themes, chess, chess-board, chess-diagram, chess-position, chess-svg, chess-utils, chessboard, chessboard-image, chessviewer, diagram, dpi, fen, fen-parser, fen-to-svg, latex, lichess, skak, svg, typescript

## 简介

Chess diagram toolkit — parse & edit FEN positions, manipulate boards, render SVG diagrams, export LaTeX, board themes, color, image & DPI utilities. Works in Node.js and browsers.
