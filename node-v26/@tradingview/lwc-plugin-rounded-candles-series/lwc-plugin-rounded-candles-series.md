# @tradingview/lwc-plugin-rounded-candles-series

> 标签: lightweight-charts, lightweight-charts-plugin, lwc-plugin

## 简介

Candlestick series with rounded corners for a softer visual style. A drop-in replacement for the built-in candlestick series.
