# @yatmo/elements

> 标签: custom-elements, isochrone, listing, map, neighbourhood, no-framework, poi, points-of-interest, property, proptech, real-estate, web-components, yatmo

## 简介

Real estate maps, points of interest and neighbourhood text as HTML elements: <yatmo-map>, <yatmo-pois> and <yatmo-text> web components for property pages, with no framework and no build step. Powered by Yatmo.
