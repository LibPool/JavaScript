# @yatmo/mcp

> 标签: ai, claude, location, mcp, mcp-server, model-context-protocol, neighbourhood, points-of-interest, real-estate, travel-time, yatmo

## 简介

Yatmo MCP server (local stdio edition): neighbourhood data for AI assistants and agents. Nearest school, nursery, supermarket, public transport, train station and motorway with travel times around any property, in 25 countries.
