# @yatmo/maps

> 标签: iframe, isochrone, listing-search, map, neighbourhood, poi, points-of-interest, proptech, real-estate, travel-time, yatmo

## 简介

The Yatmo browser plugins for real estate websites from npm: typed iframe URL builder, and loaders for the JavaScript map, summary table and neighbourhood text plugins.
