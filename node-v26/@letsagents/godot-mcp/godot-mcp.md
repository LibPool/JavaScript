# @letsagents/godot-mcp

> 标签: ai, claude, debugging, game-development, godot, mcp, model-context-protocol

## 简介

MCP server that gives AI clients runtime feedback from Godot (errors / scene tree / node props / screenshot) for an AI self-correction loop.
