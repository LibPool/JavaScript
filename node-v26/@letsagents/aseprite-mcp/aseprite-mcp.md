# @letsagents/aseprite-mcp

> 标签: ai, animation, aseprite, claude, lua, mcp, model-context-protocol, pixel-art, spritesheet

## 简介

MCP server that exposes Aseprite to LLM clients (76 tools — drawing, layers, frames/cels, tilemaps, palettes, animation tweens, transforms, spritesheet export) by generating Lua scripts and driving Aseprite headlessly.
