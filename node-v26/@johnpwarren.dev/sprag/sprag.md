# @johnpwarren.dev/sprag

> 标签: ai-codegen, architecture, ast-grep, code-quality, god-object, lint, pre-commit, technical-debt

## 简介

Enforce human-authored architectural invariants as a ratcheted gate on every change — so AI-built codebases don't silently rot (the k10s failure mode). Real-AST (ast-grep) for Go/TS/JS/Python + a heuristic fallback; pre-commit + AI-loop + debt-trend.
