# terminal-legibility

> 标签: accessibility, agent-skill, agentskills, aider, bat, catppuccin, charm, claude-code, cli, codex, delta, difftastic, git-diff, glow, gruvbox, gum, legibility, readability, terminal, tui

## 简介

Agent Skill that makes terminal/TUI coding-agent sessions scannable. Audits and sets up a legible theme + font, readable git diffs (delta/difftastic/bat), glamorous markdown rendering (glow/gum), and agent verbosity — then applies a self-formatting output
