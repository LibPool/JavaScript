> 标签: angular, angular-library, blob, browser, browser-api, data-url, logging, navigation, resource-url, router, scalable, signals, standalone, state-management, tab-management, testable, typescript, utility

## 简介

Angular 20+ navigation, tab management, and browser utilities for scalable web apps. Includes safe resource handling, data URL/Blob utilities, and testable browser API injection. Designed for standalone Angular apps, signals, and robust state management.
