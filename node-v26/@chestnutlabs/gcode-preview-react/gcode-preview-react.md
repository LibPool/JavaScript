# @chestnutlabs/gcode-preview-react

> 标签: 3d-printing, chestnutlabs, cnc, component, gcode, hooks, preview, react, toolpath, viewer

## 简介

Thin React integration for the Chestnut Labs G-code viewer (DD-007 D1 amendment): useGcodePreview hook + GcodePreview component as a reactivity bridge over @chestnutlabs/gcode-preview-core.
