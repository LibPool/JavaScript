# @chestnutlabs/gcode-preview-vue

> 标签: JavaScript

## 简介

Thin Vue 3 integration for the Chestnut Labs G-code viewer (DD-007): useGcodePreview composable + GcodePreview component over the framework-neutral parser/renderer/progress packages.
