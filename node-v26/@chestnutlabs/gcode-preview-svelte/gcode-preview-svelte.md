# @chestnutlabs/gcode-preview-svelte

> 标签: 3d-printing, chestnutlabs, cnc, component, gcode, preview, store, svelte, toolpath, viewer

## 简介

Thin Svelte integration for the Chestnut Labs G-code viewer (DD-007 D1 amendment): createGcodePreview store/action API + GcodePreview component as a reactivity bridge over @chestnutlabs/gcode-preview-core.
