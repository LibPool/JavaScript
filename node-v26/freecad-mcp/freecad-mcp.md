# freecad-mcp

> 标签: 3d, cad, freecad, mcp, model-context-protocol, parametric, step, stl

## 简介

Drive a local FreeCAD installation from any MCP client: parametric part modelling, measurement, screenshots and CAD export. Zero runtime dependencies.
