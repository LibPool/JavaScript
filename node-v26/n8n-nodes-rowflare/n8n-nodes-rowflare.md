# n8n-nodes-rowflare

> 标签: airtable-alternative, database, n8n, n8n-community-node-package, no-code, rowflare, spreadsheet

## 简介

n8n nodes for Rowflare, the open-source Airtable alternative: read and write records, list bases and tables, and trigger on new records.
