# @pcd/semaphore-group-pcd

> 标签: JavaScript

## 简介

A wrapper of the [Semaphore](https://semaphore.appliedzkp.org/) protocol, which enables PCD SDK-conforming applications to request, prove, and verify semaphore group membership proofs.
