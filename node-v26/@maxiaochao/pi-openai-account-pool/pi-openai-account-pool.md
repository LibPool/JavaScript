# @maxiaochao/pi-openai-account-pool

> 标签: oauth, openai-codex, pi-extension, pi-package

## 简介

Pool several ChatGPT Plus/Pro logins behind pi's openai-codex provider and switch accounts automatically when one runs out of quota.
