# @streetjs/notion

> 标签: connector, database, esm, integration, notion, street-framework, streetjs, typescript, webhook

## 简介

StreetJS Notion connector: a typed Notion API client (pages, databases, blocks, search) built on @streetjs/integrations, with a required Notion-Version header and X-Notion-Signature HMAC webhook verification.
