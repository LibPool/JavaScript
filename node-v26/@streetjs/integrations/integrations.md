> 标签: connector, esm, http, integrations, oauth, street-framework, streetjs, typescript, webhook-verification

## 简介

StreetJS integration foundation: a base HTTP connector (injectable fetch, token auth, typed requests, normalized errors, retry) and inbound-webhook signature verification primitives that vendor connectors (Slack, GitHub, …) build on. Zero runtime dependen
