# @streetjs/database

> 标签: connection-pool, database, esm, meta-package, migrations, postgresql, repository, schema, street-framework, streetjs, typescript

## 简介

StreetJS database meta-package: a single import that re-exports the PostgreSQL wire driver (@streetjs/postgres), connection pool (@streetjs/pool), schema inspector, migration runner, and generic repository. No logic of its own.
