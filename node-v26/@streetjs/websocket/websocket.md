# @streetjs/websocket

> 标签: channels, esm, presence, realtime, server-sent-events, sse, street-framework, streetjs, typescript, websocket, ws

## 简介

StreetJS realtime foundation: a hardened WebSocket server (origin + auth gating, heartbeat, capacity limits), an event-framed socket, an SSE connection, and a transport-agnostic channel hub with presence and typing. Built on ws.
