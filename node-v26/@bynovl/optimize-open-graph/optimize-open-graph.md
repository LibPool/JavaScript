# @bynovl/optimize-open-graph

> 标签: novl, og-tags, open-graph, opengraph, optimize, seo, social-sharing, static-site, twitter-cards, validation

## 简介

Open Graph validation submodule for the NOVL Optimize project. Checks HTML for Open Graph meta tags, content completeness, and best practices for social sharing in static sites.
