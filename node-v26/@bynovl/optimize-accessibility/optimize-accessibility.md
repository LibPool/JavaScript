# @bynovl/optimize-accessibility

> 标签: a11y, accessibility, alt-text, aria, best-practices, contrast, novl, optimize, semantic-html, static-site, validation

## 简介

Accessibility validation submodule for the NOVL Optimize. Checks HTML for accessibility best practices, ARIA usage, contrast, alt text, and semantic structure in static sites.
