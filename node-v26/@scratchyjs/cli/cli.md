# @scratchyjs/cli

> 标签: JavaScript

## 简介

Code-generation CLI for the Scratchy framework. Scaffold Drizzle models, tRPC routers, Fastify routes, Qwik pages and components, plugins, migrations, seeds, and tests — all from the command line.
