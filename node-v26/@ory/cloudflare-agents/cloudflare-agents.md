# @ory/cloudflare-agents

> 标签: agent, agents, ai, authorization, cloudflare, ory, workers

## 简介

Ory Agent Security for the Cloudflare Agents SDK — per-tool authorization, activity auditing, and identity propagation by wrapping the AI SDK tools passed to streamText. Built on @ory/argus.
