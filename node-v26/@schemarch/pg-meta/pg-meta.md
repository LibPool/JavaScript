# @schemarch/pg-meta

> 标签: JavaScript

## 简介

SQL builders for Postgres catalog introspection, shared by Schemarch Studio and [`postgres-meta`](https://github.com/schemarch/postgres-meta). Each builder in `src/sql/` returns a safe, parameterized SQL fragment (`SafeSqlFragment`) that a caller executes
