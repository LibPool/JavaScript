# daily-kural-js

> 标签: daily-quote, kural, tamil, thirukkural, thirukural, tirukkural, web-component, திருக்குறள்

## 简介

Zero-dependency Thirukkural (திருக்குறள்) for the browser and Node: kural of the day, filters, search, a <daily-kural> element, and a CLI.
