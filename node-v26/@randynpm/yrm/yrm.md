# @randynpm/yrm

> 标签: NPM, registry

## 简介

NPM registry manager can help you easy and fast switch between different npm registries, now include: cnpm, taobao, nj(nodejitsu), rednpm, edunpm

## 官网

- 官网：https://github.com/i5ting/yrm
- 源码仓库：git://github.com/i5ting/yrm.git
- npm 页面：https://www.npmjs.com/package/@randynpm/yrm

## 历史版本号

- 当前版本：1.0.5

- 1.0.5

## 获取地址

- npm 安装：`npm install @randynpm/yrm`
- npm registry：https://registry.npmjs.org/@randynpm/yrm
