# @keywaytech/pi-provider-manager

> 标签: extension, llm, llm-provider, model-config, openai-compatible, pi, pi-coding-agent, pi-package, react, typescript, vite

## 简介

A pi-coding-agent extension that provides a local web UI to manage custom LLM API providers & models. Edit models.json + default provider/model/thinking-level, auto-backup, localhost-only.
