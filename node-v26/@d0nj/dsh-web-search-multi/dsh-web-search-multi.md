# @d0nj/dsh-web-search-multi

> 标签: deepseek-harness, dsh, exa, firecrawl, parallel, tavily, web-search

## 简介

Multi-backend web search provider for DeepSeek Harness: configure Exa, Tavily, Parallel and Firecrawl at once and route between them explicitly or by strategy (fixed, round-robin, random, failover, merge).
