# @samwen/lambda-helper

> 标签: AWS, AWS Lambda function errors, EMFILE, Failed to refresh slots cache, MongoServerSelectionError, Timeout, api gateway, api invoke, console test, file descriptor, getaddrinfo EMFILE, ioredis, lambda, leak, limit, mongodb, node, sns, sqs

## 简介

An effort to enable single lambda handles functionally the same requests from different sources: console test, sns, sqs, api gateway and api invoke. It also addresses AWS lambda EMFILE issue.
