# @conduitvc/airbnb-base

> 标签: JavaScript

## 简介

> Neutrino preset that supports linting Node.js projects with Airbnb's ESLint config, following the [Airbnb styleguide](https://github.com/airbnb/javascript), with Conduit's stylistic preferences.
