# @simplesmoothsafe/pptb-offboarding-wizard

> 标签: dataverse, offboarding, ownership, powerplatform, pptb, reassign, security-roles, toolbox, users

## 简介

A user is leaving: inventory everything they hold — records per table, flows, personal views and charts, queues, teams, roles, connection references, direct reports — pick a successor, preview the reassignment and apply it in one audited run.
