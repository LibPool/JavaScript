# ew-iframe-editor

> 标签: adapter, code-editor, embed, ew-code-editor, iframe, jdoodle, onecompiler, playground, postmessage

## 简介

Embed online code editors into any web page via iframe with initial code loading. Built-in ew-code-editor support, with adapter pattern for custom editor integration.
