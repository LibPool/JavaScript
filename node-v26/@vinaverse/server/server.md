# @vinaverse/server

> 标签: aws-lambda, express, fastify, hono, sdk, vinaverse, webhooks

## 简介

Vinaverse for Node backends: verify webhooks into typed contract events, with adapters for AWS Lambda, Express, Fastify and Hono, serve tools, and call the Vinaverse API typed.
