# mm_validate

> 标签: commonjs, json schema, mm_common, mm_infra, mm_mod, nodejs, schema, validate, validator, 参数验证, 数据校验, 超级美眉

## 简介

这是一个通用的 Node.js 参数验证模块，按 JSON Schema 常用子集校验参数，返回首个错误信息。
