# @nasdigitaluk/withnate-tool-core

> 标签: browser, client-side, dpi, exif, image, print, withnate

## 简介

Shared spine for the withnate.co.uk browser tools. Header-only image measurement, Exif reading, unit arithmetic, file intake and mounting. No network, no storage.
