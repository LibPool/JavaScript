# @border-shape/core

> 标签: border-shape, clip-path, css, path, shape, svg

## 简介

Framework-agnostic SVG `path()` builder for `clip-path` and the upcoming CSS [`border-shape`](https://www.w3.org/TR/css-borders-4/#border-shape-func) property.
