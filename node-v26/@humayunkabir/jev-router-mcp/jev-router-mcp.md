# @humayunkabir/jev-router-mcp

> 标签: decision, jev, laya, mcp, model-context-protocol, opencode, router, system1

## 简介

MCP server that routes a question to the best tool using a Jev decision engine (/v1/systemone). Works with any Jev-compatible server — Laya is one.
