> 标签: claude-code, mcp, pi-extension, pi-package, pi-processes, syntax-highlighting, tool-calls, tool-folding, tool-rendering, transcript

## 简介

Tool folding for the pi agent — a reply's tool calls collapse to one clickable line; failures, edit diffs and running jobs stay visible
