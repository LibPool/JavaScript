# @uiplaybox/client

> 标签: JavaScript

## 简介

1) Загружаем Preview 2) Загржуается FrameManager 3) Загружается indexJson и получается структура тестов 4) Добавляется текущий фрейм по uuid и key кейса. (учитывается что загружен ли indexJson)    1) Грузятся все процессоры uuid    2) Инициализируюет
