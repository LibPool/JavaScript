# @merktop/mcp

> 标签: JavaScript

## 简介

MCP server + CLI for Merktop's x402 facilitator — let your agent (or you) pay x402 APIs with spend caps, and check seller usage/billing.

## 官网

- 官网：https://facilitator.merktop.com
- npm 页面：https://www.npmjs.com/package/@merktop/mcp
