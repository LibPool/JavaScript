# @klixsoft/react-native-fonepay

> 标签: deeplink, fonepay, intent, nepal, payment, payment-gateway, qr, react-native

## 简介

Fonepay Intent (bank-app deep link) payments for React Native: bank deep links, live payment watching and a React hook. No WebView, no native code.
