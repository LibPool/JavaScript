# @flowlinejs/nodes-builtin

> 标签: automation, workflow, workflow-builder, workflow-nodes

## 简介

Built-in Flowline nodes: conditionals, switch, forEach, stop, delay, waitForCallback, httpRequest, transform, callSubflow and triggers.
