# @chainlesschain/core-settlement

> 标签: JavaScript

## 简介

P1 settlement core — append-only signed transfer-log ledger (federation node hosts, cannot forge/mint) + custodian-driven escrow gated by M-of-N multisig. See docs/design 去中心化交易_知识资产加密交付与AI撮合_v1 §8.2/§6.
