# @b-333/tokens

> 标签: JavaScript

## 简介

Cross-platform design tokens for web + React Native. One W3C DTCG source → CSS variables, a Tailwind preset, and a typed native theme. Coral accent, Fraunces + Inter, warm paper surfaces.
