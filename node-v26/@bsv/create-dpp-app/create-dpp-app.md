# @bsv/create-dpp-app

> 标签: bsv, create, digital-product-passport, dpp, scaffold

## 简介

Scaffold a Digital Product Passport application on BSV: a web app, an API that writes and reads passports with the @bsv/dpp packages, and an offline dry run as its first test
