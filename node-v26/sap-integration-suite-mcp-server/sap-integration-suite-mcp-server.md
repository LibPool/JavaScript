# sap-integration-suite-mcp-server

> 标签: JavaScript

## 简介

A production-ready Model Context Protocol (MCP) server for the SAP Integration Suite, providing unified access to Cloud Integration, API Management, Event Mesh, Integration Assessment, Open Connectors, and Edge Integration Cell.
