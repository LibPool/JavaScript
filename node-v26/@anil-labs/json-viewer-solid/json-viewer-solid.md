# @anil-labs/json-viewer-solid

> 标签: json-tree, json-viewer, solid, solidjs, tree-view

## 简介

SolidJS bindings for @anil-labs/json-viewer-core — a framework-agnostic JSON tree viewer with expand/collapse, syntax highlighting, dark/light themes and copy-to-clipboard.
