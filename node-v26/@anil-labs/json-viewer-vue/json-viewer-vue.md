# @anil-labs/json-viewer-vue

> 标签: json-tree, json-viewer, tree-view, vue, vue3

## 简介

Vue 3 bindings for @anil-labs/json-viewer-core — a collapsible JSON tree viewer with syntax highlighting, type badges, dark/light themes and copy-to-clipboard.
