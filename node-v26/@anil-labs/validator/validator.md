# @anil-labs/validator

> 标签: form, framework-agnostic, laravel, quasar, rules, schema, typescript, validation, validator, vue

## 简介

An expressive, strictly-typed, framework-agnostic validation library for TypeScript — a Laravel-style dataset validator plus a chainable single-field rule builder.
