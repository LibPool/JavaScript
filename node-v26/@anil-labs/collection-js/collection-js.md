# @anil-labs/collection-js

> 标签: array, async, chainable, collection, collection-js, data-structure, fluent, functional, javascript, laravel, laravel-collections, lazy, library, typescript

## 简介

A fluent, Laravel-inspired Collection library for JavaScript and TypeScript. Provides 120+ chainable methods for elegant array manipulation. Framework-independent — works in Node, any JS framework, or straight off a CDN.
