# @agentegrity/claude-sdk

> 标签: agent, agentegrity, anthropic, claude, observability, security

## 简介

Zero-config agentegrity adapter for the Claude Agent SDK (@anthropic-ai/claude-agent-sdk). Mirrors the Python agentegrity.claude module.
