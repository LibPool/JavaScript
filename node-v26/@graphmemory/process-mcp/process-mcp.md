# @graphmemory/process-mcp

> 标签: ai, claude, dev, mcp, model-context-protocol, process, supervisor

## 简介

MCP server that supervises long-running dev processes — start, stop, restart, list, tail logs (JSON-aware), wait for readiness, run one-shot commands. HTTP transport, lives in its own process so state survives Claude Code restarts.
