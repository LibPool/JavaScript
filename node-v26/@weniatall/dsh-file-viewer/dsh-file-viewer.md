# @weniatall/dsh-file-viewer

> 标签: deepseek-harness, dsh, explorer, file-viewer, preview

## 简介

Workspace file viewer and Git panel for DeepSeek Harness: file tree, syntax-highlighted code, images, PDF, Excel and Word, plus local/remote branches, paged commit history, commit diffs, working-tree changes and changed-file navigation
