# @apatureai/sigil

> 标签: calibration, conformal-prediction, e-process, eval, llm-as-judge, model-risk

## 简介

Error bars for LLM-as-judge evals: calibration (ECE/Brier/reliability), finite-sample risk certificates (Clopper-Pearson, Learn-Then-Test), Pass^k reliability, anytime-valid drift monitoring, and a cost-at-equal-quality frontier gated by an exact McNemar
