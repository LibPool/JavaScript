# @mingchain/ming-seal

> 标签: JavaScript

## 简介

铭印（MingSeal）是专为OpenClaw龙虾设计的BSV区块链司法存证插件，将AI Agent的对话、决策、动作哈希锚定到BSV链上，生成可司法验证的存证证书。
