# @transtyle/exporter-mui

> 标签: createtheme, css-variables, design-system, design-tokens, dtcg, material-ui, mui, react, theming

## 简介

Transtyle exporter for Material UI v9: a createTheme options object in CSS-variables mode, every role a palette key per colour scheme.
