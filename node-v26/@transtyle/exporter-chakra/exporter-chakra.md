# @transtyle/exporter-chakra

> 标签: chakra-theme, chakra-ui, design-system, design-tokens, dtcg, react, semantic-tokens, theming

## 简介

Transtyle exporter for Chakra UI v3: a defineConfig object whose semantic tokens give every role Chakra's eight colour-palette keys, per colour scheme.
