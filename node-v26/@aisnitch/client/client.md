# @aisnitch/client

> 标签: agent, ai, aisnitch, claude-code, client, monitoring, opencode, sdk, websocket

## 简介

Lightweight TypeScript SDK to consume the AISnitch WebSocket event stream — auto-reconnect, Zod parsing, session tracking, filters, and human-readable helpers.
