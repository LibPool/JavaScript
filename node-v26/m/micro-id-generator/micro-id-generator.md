# micro-id-generator

> 标签: base62, epoch-id, id-generator, micro-id, nanoid, short-id, smart-id, timestamp-id, tiny-id, unique-id

## 简介

A compact, fast, timestamp-based unique ID generator using custom epoch and Base62 encoding.
