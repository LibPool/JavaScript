# mobkit

> 标签: apicloud, avm, cli, mobile, mobkit, sdk, vite, wifi, yonyou

## 简介

MobKit —— APICloud / AVM 移动工程的 WiFi 真机同步、用友云工作台集成与 CLI。命令行（mobkit / mk）与程序化库（import { wifiSync } from 'mobkit'）同包。
