# mediaforge

> 标签: audio, ffmpeg, ffprobe, fluent, hls, mediaforge, streaming, typescript, video, waveform

## 简介

Fully typed TypeScript wrapper for FFmpeg — fluent API, v6/v7/v8 compatible, zero native bindings
