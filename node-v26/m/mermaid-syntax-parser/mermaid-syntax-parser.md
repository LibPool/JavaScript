# mermaid-syntax-parser

> 标签: JavaScript

## 简介

This project parses Mermaid text and validate it without the need for Puppeter or any browser. The project is based on [mermaid-js/mermaid](https://github.com/mermaid-js/mermaid/tree/60db05b75cef303b8056173901f8e11ddb5f70f8) (Feb 2025).
