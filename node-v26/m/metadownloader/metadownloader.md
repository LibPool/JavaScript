# metadownloader

> 标签: download, facebook downloader, instadl, instagram, instagram downloader, metadownloader

## 简介

metadownloader is a JavaScript package created to simplify the process of downloading videos from Instagram and Facebook. With a focus on simplicity and efficiency, this tool allows you to integrate video downloading capabilities seamlessly into your web
