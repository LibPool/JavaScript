# monad-mcp

> 标签: ai-agents, blockchain, claude, defi, evm, mcp, model-context-protocol, monad, privy, viem, wallet, web3

## 简介

MCP server for the Monad blockchain — balances, transfers, swaps, lending, staking, bridging & x402 payments for AI agents, with Privy-backed signing and session keys.
