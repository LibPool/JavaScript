# mk-toast

> 标签: UI, alarm, alert, ecosystem:Vue.js, flash message, floating message, informer, message, message balloon, notification, notifier, notify, toast, toastr

## 简介

Flash messages (notifications/toast). Library agnostic with VUE.js connector. Smooth CSS animation with no twitching.
