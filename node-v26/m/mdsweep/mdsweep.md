# mdsweep

> 标签: agents, claude-code, cleanup, cli, markdown, repo-hygiene

## 简介

Find, grade, and safely quarantine the markdown artifacts coding agents leave behind (SUMMARY.md, PLAN.md, scratch notes...). Read-only by default, never deletes, one-command undo.
