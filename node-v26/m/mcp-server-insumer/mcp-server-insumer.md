> 标签: acp, agent-trust, agentic-commerce, ai-agents, attestation, blockchain, compliance, condition-based-access, eas-attestation, ecdsa, insumer, kyc, mcp, mcp-server, merkle-proof, nft-verification, on-chain-verification, token-gating, ucp, web3

## 简介

MCP server for InsumerAPI: condition-based access infrastructure. Send a wallet and conditions, get a signed boolean across 37 chains. 27 tools: attestation, wallet trust profiles (50 checks across 28 chains incl. Solana, XRPL, Bitcoin, Tron, Stellar, Sui
