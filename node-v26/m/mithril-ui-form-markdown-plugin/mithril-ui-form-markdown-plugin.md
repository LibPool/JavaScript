# mithril-ui-form-markdown-plugin

> 标签: form, markdown, mithril, plugin, ui, wysiwyg

## 简介

Plugin to add a WYSIWYG markdown editor (mithril-markdown-wysiwyg) to Mithril-UI-Form, with a sanitized readonly display.
