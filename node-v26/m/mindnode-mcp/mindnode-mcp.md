# mindnode-mcp

> 标签: ai-agent, automation, claude, macos, mcp, mcp-server, mind-map, mindmap, mindnode, modelcontextprotocol, reverse-engineering

## 简介

MCP server for MindNode (macOS): connect Claude and AI agents to the mind-mapping app with no API — read mind maps as Markdown, create maps from outlines
