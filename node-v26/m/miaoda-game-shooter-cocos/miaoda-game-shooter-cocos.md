# miaoda-game-shooter-cocos

> 标签: bullet, bullet-hell, cocos, cocos-creator, component, danmaku, shmup

## 简介

Cocos Creator skin for miaoda-game-shooter-core: a pooled bullet renderer that drives Node positions/rotation from the pure-TS bullet simulation, plus an Emitter component. The reusable rendering layer for any shoot-'em-up / bullet-hell game.
