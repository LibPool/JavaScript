# multi-ai-sdk

> 标签: ai-assistant, ai-client, ai-sdk, anthropic, chat-widget, claude, cohere, deepseek, gemini, grok, groq, llm, mistral, nvidia-nim, ollama, openai, perplexity, qwen, streaming-llm, together-ai, token-budget, typescript, zero-dependency

## 简介

Universal multi-provider AI SDK. Single lightweight API for 18 providers (Groq, OpenAI, Gemini, Claude, Mistral, DeepSeek, etc). Features: auto-fallback, JSON repair, context window guards, and embeddable chat widget.
