# mcp-orchestrate

> 标签: ai-agent, claude-code, codex, delegation, fallback, grok, mcp, model-context-protocol, opencode, pi-coding-agent, router

## 简介

MCP server that routes a coding task to a user-configured model tier (light/standard/heavy) with capability filtering and provably-safe cross-backend fallback. Backend-agnostic; you configure every model.
