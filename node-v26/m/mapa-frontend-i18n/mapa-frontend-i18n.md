# mapa-frontend-i18n

> 标签: JavaScript

## 简介

Biblioteca Angular de internacionalização (i18n) construída sobre [`@angular/localize`](https://angular.dev/guide/i18n). Fornece os catálogos de tradução do produto MAPA (pt-BR, en, es) e funções para inicializar o idioma da aplicação.
