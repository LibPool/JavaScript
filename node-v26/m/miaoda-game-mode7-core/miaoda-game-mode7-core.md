# miaoda-game-mode7-core

> 标签: affine, cocos, flight, mode7, phaser, pseudo-3d, racing, retro, scanline

## 简介

Engine-agnostic Mode 7 math with SNES-style affine screen-to-map transforms and perspective ground scanlines for retro racing, flight and world maps. No rendering dependency.
