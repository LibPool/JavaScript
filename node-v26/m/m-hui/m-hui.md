# m-hui

> 标签: hui, react-component

## 简介

基于 React 开发的移动端轻量 UI 库. 结合 HTML5, CSS3, ES6, React15 的优势, 吸收 [react-weui](https://github.com/weui/react-weui),  [amazeui-react](https://github.com/amazeui/amazeui-react) 的 UI 控件.
