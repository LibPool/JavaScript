# mapcheckr-cli

> 标签: cli, geoguessr, google-maps, mapcheckr, street-view, streetview

## 简介

Fast Geoguessr map checker — same defaults as mapcheckr.vercel.app, runs against the reverse-engineered Google Street View metadata endpoints. No headless browser, no API key.
