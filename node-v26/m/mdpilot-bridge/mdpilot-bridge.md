# mdpilot-bridge

> 标签: agent, bridge, claude, claude-code, cli, mdpilot, websocket

## 简介

Local companion that lets MDPilot's Pilot tab command a live Claude Code agent. Token-paired WebSocket on 127.0.0.1; mutating tools wait for approval in the browser via a PreToolUse hook.
