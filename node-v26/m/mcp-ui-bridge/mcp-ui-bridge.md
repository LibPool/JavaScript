# mcp-ui-bridge

> 标签: accessibility, ai, automation, browser automation, enterprise, llm, mcp, mcp-ui-bridge, pagination, playwright, production-ready, semantic html, ui bridge, viewport filtering

## 简介

Production-ready library for LLM-web interaction via Model Context Protocol (MCP) with bulletproof pagination, robust element detection, viewport-optimized parsing and enterprise-grade stability using Playwright automation.
