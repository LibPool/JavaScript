# mcp-spy

> 标签: ai, claude, debugging, llm, mcp, model-context-protocol, observability, proxy, tui

## 简介

Free & open-source observability proxy for the Model Context Protocol (MCP). Intercept, inspect and replay MCP traffic in real time — right in your terminal.
