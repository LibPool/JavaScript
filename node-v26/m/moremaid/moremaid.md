# moremaid

> 标签: archive, auto-cleanup, cli, code-highlighting, converter, documentation, encryption, full-text-search, html, markdown, markdown-browser, markdown-server, markdown-viewer, marked, mermaid, mermaid-diagrams, moremaid, pack, prism, search, syntax-highlighting, themes, viewer

## 简介

Powerful Markdown viewer with Mermaid diagrams, archive support, and 10+ themes. Pack and share markdown projects as .moremaid files with encryption. Features full-text search, syntax highlighting, and auto-cleanup.
