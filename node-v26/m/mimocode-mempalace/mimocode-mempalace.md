# mimocode-mempalace

> 标签: ai-memory, bun, knowledge-graph, llm, long-term-memory, memory, mempalace, mimocode, opencode, plugin, semantic-search, typescript

## 简介

MemPalace long-term memory for MiMoCode: captures every completed turn into a semantic memory palace and injects relevant memories back into the system prompt
