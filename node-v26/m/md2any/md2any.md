# md2any

> 标签: agent, cli, llm, markdown, playwright, publish, skill, twitter, wechat, x, xiaohongshu, zhihu, 小红书, 微信公众号, 知乎

## 简介

一篇 Markdown，发到微信公众号 / 知乎 / 小红书 / Twitter(X)。自动截长图、AI 生成平台文案与串推、真实浏览器自动填内容传图。可作为 Agent Skill 使用。
