# mcp-google-multi

> 标签: claude, claude-code, gmail, google, google-calendar, google-contacts, google-docs, google-drive, google-meet, google-sheets, google-tasks, google-workspace, mcp, mcp-server, model-context-protocol, oauth, search-console

## 简介

Local MCP server for Google Workspace (Gmail, Drive, Calendar, Sheets, Docs, Contacts, Tasks, Meet, Search Console, +Forms/Chat/Admin) across multiple accounts — OAuth-only, encrypted token storage, deny-by-default writes.
