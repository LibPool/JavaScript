# mcp-animenewsnetwork

> 标签: ai, anime, anime-news-network, animenewsnetwork, claude, cursor, encyclopedia, llm, manga, mcp, mcp-server, model-context-protocol, modelcontextprotocol, news, no-api-key

## 简介

MCP server for Anime News Network. Search the anime and manga encyclopedia, read cast, staff and episodes, and follow the news wire. No API key required.
