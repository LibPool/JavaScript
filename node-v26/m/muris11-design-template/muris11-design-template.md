# muris11-design-template

> 标签: agent-skills, design-system, design-template, monochrome, ui

## 简介

Design Template — 30 curated design systems as agent skills (monochrome, bauhaus, cyberpunk, claymorphism, etc.). Each skill = <role> + <design-system> + checklist.
