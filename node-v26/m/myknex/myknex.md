# myknex

> 标签: bookshelf, knex, objection, orm, sequelize, typeorm, waterline

## 简介

一个简洁的 knex 封装   + 充分暴露 knex 的特性 + 提供简洁的 orm 接口 + 提供简洁的连接查询接口
