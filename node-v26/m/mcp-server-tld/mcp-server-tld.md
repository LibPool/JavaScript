# mcp-server-tld

> 标签: agent, ai, borrowing, defi, jtoken, justlend, lending, mcp, model-context-protocol, tron

## 简介

MCP server for JustLend V1 DAO on TRON blockchain. Supports supply, borrow, repay, withdraw, market data, mining rewards (USDD/WBTC), API integration, general TRON chain utilities, and AI-guided DeFi prompts.
