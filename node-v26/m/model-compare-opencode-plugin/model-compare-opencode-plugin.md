# model-compare-opencode-plugin

> 标签: llm, model-compare, opencode, openrouter, plugin

## 简介

OpenCode plugin that switches OpenRouter model aliases to the best value-for-money pick from canonical/model-compare's ranking (balanced, price, quality).
