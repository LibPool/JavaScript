# mcpscope

> 标签: agent, ai-agents, benchmark, cli, evaluation, llm, llm-eval, llm-evaluation, lm-studio, local-first, local-llm, mcp, mcp-client, mcp-server, model-context-protocol, observability, ollama, openrouter, tool-calling, tool-use, typescript

## 简介

A local-first workbench for developing, inspecting, and benchmarking MCP servers against local (LM Studio, Ollama) or remote (OpenRouter) models — Web UI, CLI, and MCP interface over one shared store.
