# mcp-pacemaker

> 标签: bridge, claude-desktop, cursor, keep-alive, mcp, model-context-protocol, proxy, sse, supervisor, vscode

## 简介

Keeps your MCP servers alive across editor restarts, reboots, and token expiry — pluggable auth, cross-platform auto-start, one-command setup. Zero-dependency bridge; a small CLI for setup.
