# mcp-google-ads

> 标签: ad-management, automation, claude, google-ads, marketing, mcc, mcp, model-context-protocol, ppc, sem

## 简介

MCP server for Google Ads API with MCC support, 44 tools for campaign management, reporting, and optimization. Read-only by default -- mutating tools require GOOGLE_ADS_MCP_WRITE=true. All creates/updates land PAUSED.
