# mandate-mcp

> 标签: agent-payments, budget, claude, guardrails, keeperhub, mcp, model-context-protocol, spending-policy, x402

## 简介

MCP server for a spending authority an agent cannot argue with: preflight a payment against a policy anchored on chain, read any agent's budget and the reason behind every refusal, and spend only when the fifteen rules allow it.
