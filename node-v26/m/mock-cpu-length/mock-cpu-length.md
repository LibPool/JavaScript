# mock-cpu-length

> 标签: JavaScript

## 简介

Mock os.cpus().length in CI env(`!!process.env.CI === true`). It often gets wrong CPU core length when using `os.cpus().length` in some CI environments due to containerized technology such as [CPU share](https://docs.docker.com/config/containers/resource_
