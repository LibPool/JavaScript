# mascotlab-mcp

> 标签: claude-code, cursor, image-generation, mascot, mcp, model-context-protocol

## 简介

Generate your app's mascot, then props, poses and animations that stay on-model. Runs the hosted MascotLab MCP server over stdio for clients without remote support.
