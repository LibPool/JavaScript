# miox

> 标签: JavaScript

## 简介

miox 是一个单页应用的管理框架。在传统web开发中，浏览器会帮助开发者管理会话历史以及页面的创建、销毁、切入切出等生命行为，在SPA开发中，这些工作需要由SPA的管理框架来实现，miox 就是做了这样的工作。
