# mini-lodash-utils

> 标签: lodash, rollup, toolkit, typescript, utils

## 简介

一个基于 Rollup 构建的轻量级 JS 工具函数库，类似 lodash，支持 ESM/CJS，适合直接发布到 npm。

## 官网

- npm 页面：https://www.npmjs.com/package/mini-lodash-utils

- npm registry：https://registry.npmjs.org/mini-lodash-utils
