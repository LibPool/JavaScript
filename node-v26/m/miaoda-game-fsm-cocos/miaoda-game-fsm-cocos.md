# miaoda-game-fsm-cocos

> 标签: ai, cocos, cocos-creator, component, finite-state-machine, fsm, game-ai

## 简介

Cocos Creator skin for miaoda-game-fsm-core: a thin @ccclass Component that runs a gameplay finite state machine against a context and drives it from the node's update(dt). For enemy AI, character states and game flow.
