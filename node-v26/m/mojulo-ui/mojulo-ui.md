# mojulo-ui

> 标签: dashboard, mcp, mojulo

## 简介

The mojulo dashboard: the prebuilt local web UI over the same ~/.mojulo state the mojulo MCP server drives. It runs on the exact mojulo version it was published with and binds to 127.0.0.1.
