# mnemonic-converter

> 标签: JavaScript

## 简介

This is stripped down version of Coinomis Mnemonic Code Converter: <https://coinomi.github.io/tools/bip39/> for Monero and Haven. It is slightly adjusted to integrate it easier into other projects
