# mmt-testlight

> 标签: api-testing, ci, cli, mcp, multimeter, postman-alternative, rest-client, testlight, yaml

## 简介

AI-powered REST Client and Git-native API testing CLI for YAML .mmt files. Same tests in VS Code and CI. Alternative to Postman.
