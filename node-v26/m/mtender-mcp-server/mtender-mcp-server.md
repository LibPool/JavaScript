# mtender-mcp-server

> 标签: ai-agents, anthropic, claude, govtech, llm-tools, mcp, model-context-protocol, modelcontextprotocol, moldova, mtender, ocds, open-contracting, procurement, transparency, typescript

## 简介

Modern MCP server for Moldova's MTender public procurement data (OCDS 1.1.5). Protocol revision 2025-11-25. Tools, resources, prompts, vision-OCR for scanned PDFs, SSRF-hardened.
