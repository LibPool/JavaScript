# metakocka-mcp

> 标签: ai, claude, erp, mcp, metakocka, model-context-protocol

## 简介

Model Context Protocol (MCP) server for the Metakocka ERP — let Claude and other AI assistants read your documents, invoices, products, stock and partners.
