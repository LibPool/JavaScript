# mup-mcp-server

> 标签: claude, interactive, llm, mcp, mcp-server, model-context-protocol, mup, tools, ui

## 简介

MCP server that turns HTML MUP panels into interactive tools for LLMs — render UI, call functions, and pipe data between panels
