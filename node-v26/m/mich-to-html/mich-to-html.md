# mich-to-html

> 标签: dom, hast, html, hyperscript, mich, render, render-to-string, rendering, server, server-side-rendering, side, ssr, str, string, to, to-html, to-string, virtual, virtual-dom

## 简介

Tiny and naive implementation of rendering HAST-compliant virtual dom trees to HTML string, just in ~420 bytes.
