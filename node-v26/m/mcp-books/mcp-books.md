# mcp-books

> 标签: archives, bnf, books, data-bnf, full-text-search, internet-archive, library-of-congress, mcp, mcp-server, model-context-protocol, newspapers, ocr

## 简介

MCP server that searches the Internet Archive, the Library of Congress and data.bnf.fr at once, inside scanned text and across catalogues. No API key required.
