# mcp-marketcal

> 标签: ai-agents, finance, market-holidays, mcp, model-context-protocol, settlement-date, trading-calendar

## 简介

MCP server for correct trading-day and settlement-date math — is_trading_day, next/previous trading day, market holidays, and T+N settlement for NYSE, NASDAQ, LSE, and XETRA.
