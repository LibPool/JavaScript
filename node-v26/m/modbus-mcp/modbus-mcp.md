# modbus-mcp

> 标签: industrial, iot, mcp, modbus, modbus-rtu, modbus-tcp

## 简介

NPX-based MCP server for Modbus (TCP/UDP/Serial) — tools for reading/writing coils and registers, typed decoding, tag maps, and health
