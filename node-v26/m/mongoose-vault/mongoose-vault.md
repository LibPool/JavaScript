# mongoose-vault

> 标签: encrypt, encryption, encryptions-as-a-service, hashicorp, mongo, mongodb, mongoose, vault

## 简介

Simple encryption plugin for Mongoose, using the transit backend from Hasicorp's Vault (Encryption as a Service).
