> 标签: database, db-tools, metrics, mongo, mongodb, monitoring, observability, performance, performance-monitoring, profiling, query-analysis, query-optimization, query-profiler, slow-query

## 简介

A command-line utility for MongoDB that activates the database profiler, generates interactive html report to let you identify performance bottlenecks
