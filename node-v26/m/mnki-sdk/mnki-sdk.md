# mnki-sdk

> 标签: a2a, agent-security, ai-agents, authorization, authzen, delegation, dpop, jws, mcp, mnki, spiffe, wimse

## 简介

mnki — the Agent Trust SDK for TypeScript: give an agent an identity (keys + signed requests), guard() any tool call (local or hosted, observe → enforce), verify, delegate, attest, explain decisions, offline verification. Framework adapters as subpaths: m
