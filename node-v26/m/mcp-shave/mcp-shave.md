# mcp-shave

> 标签: claude-code, codex, context-pruning, cursor, json-rpc, llm, mcp, model-context-protocol, proxy, token-optimization, token-saver, windsurf

## 简介

Zero-dependency stdio JSON-RPC proxy for MCP servers that prunes noisy payloads and saves 50-92% of LLM context tokens
