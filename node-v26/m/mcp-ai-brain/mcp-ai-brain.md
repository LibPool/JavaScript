# mcp-ai-brain

> 标签: agent, ai, claude, cursor, embeddings, local-embeddings, local-first, mcp, memory, persistent-memory, semantic-search, sqlite, token-savings, transformers, vector-search, windsurf

## 简介

Local-first persistent memory for AI agents. SQLite + hybrid search (keyword + local vector embeddings). Zero API costs. Works with Claude, Cursor, Windsurf, and any MCP-compatible agent.
