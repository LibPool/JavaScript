# mountebank-studio

> 标签: api-mocking, imposter, mbtest, mock, mock-server, mountebank, service-virtualization, stub, test-doubles

## 简介

A visual console for Mountebank: imposters, stubs, responses and captured traffic, without hand-writing JSON. Unofficial — not affiliated with the mountebank project.
