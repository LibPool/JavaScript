# merpeeps-mermaid-layout

> 标签: diagram, flowchart, frontmatter, graph, layout, mermaid, mermaid-diagram, mermaid-layout, mermaid-plugin, merpeeps, positions, visual-editor

## 简介

Save node positions and styling for Mermaid diagrams inside the diagram file itself, and render them. A mermaid layout plugin plus the metadata format behind it.
