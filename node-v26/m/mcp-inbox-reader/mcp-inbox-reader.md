# mcp-inbox-reader

> 标签: ai, claude, inbox, local-first, mcp, mcp-server, model-context-protocol, notes, s3, webdav

## 简介

MCP Server that lets AI agents read your inBox notes from your own S3/WebDAV cloud storage. Local-first, zero server.
