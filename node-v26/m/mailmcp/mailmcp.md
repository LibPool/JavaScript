# mailmcp

> 标签: email-mcp-client, email-mcp-server, email-mcp-tools, email-mcp-utils, gmail-mcp, mailmcp, qq-email-mcp

## 简介

An email MCP service that supports querying and sending messages via QQ, Gmail, and other providers, extracting only the text content—ideal for summarization.
