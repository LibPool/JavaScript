# mcp-handshake

> 标签: claude-code, cli, debugging, developer-tools, diagnostics, mcp, model-context-protocol

## 简介

Diagnoses MCP server connection failures by actually performing the initialize handshake and classifying the result — instead of treating any stderr output as a connection failure, which is a confirmed false-alarm pattern across multiple MCP host clients.
