# mcp-tenant-context

> 标签: async-hooks, async-local-storage, context-propagation, mcp, model-context-protocol, multi-tenant, request-context, tenant, tenant-context, typescript

## 简介

AsyncLocalStorage-backed tenant + actor context propagation for MCP servers and request-scoped Node services. Keep tenantSlug and the request actor out of every handler signature. Zero runtime dependencies.
