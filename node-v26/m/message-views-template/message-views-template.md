# message-views-template

> 标签: vue, vue-cli3, vuecli3, vuejs

## 简介

+ 一个会话视图、朋友圈、微信收藏的 视图模板，只需要 写好自己数据结构的适配层，然后以props传入 即可。 + 项目刚开始开发，很多事件和需求并不完善； + 项目主要于公司业务，用于展示市面上大多数社交app的会话视图和朋友圈，的通用展示解决方案；
