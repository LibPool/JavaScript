# maru-mcp

> 标签: agent, claude, email, gmail, mcp, model-context-protocol

## 简介

The MCP stdio shim for Maru — the open-source agent gateway to your own email. Connects Claude Code, Claude Desktop, or any MCP client to a running Maru app over a local socket.
