# mysql-readonly-mcp-server

> 标签: ai-agent, database, mcp, mcp-server, model-context-protocol, mysql, query, read-only, readonly, sql

## 简介

只读 MySQL MCP Server：让 Agent 安全地执行 SELECT/SHOW 查询，查看数据库、表清单与表结构，支持多库连接与 SQL 只读校验
