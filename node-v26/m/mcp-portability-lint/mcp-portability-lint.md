# mcp-portability-lint

> 标签: claude, compatibility, gemini, json-schema, lint, mcp, model-context-protocol

## 简介

Lint MCP tool schemas against per-client compatibility rules — catch 'this tool silently fails on Gemini/Claude clients' before shipping. Every rule cites the upstream issue and the exact error string.
