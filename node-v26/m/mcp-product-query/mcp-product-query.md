> 标签: ai-tools, badminton-rackets, enum-constraints, mcp, model-context-protocol, parameter-validation, product-search, running-shoes, tool-calling-test

## 简介

An MCP stdio server that provides product search tools for running shoes and badminton rackets with strict enum parameter validation for testing AI tool calling capabilities.
