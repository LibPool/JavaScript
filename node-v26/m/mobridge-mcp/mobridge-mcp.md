# mobridge-mcp

> 标签: accessibility, android, claude, cursor, ios, mcp, mobridge, model-context-protocol, ui-automation

## 简介

MoBridge MCP — a stdio MCP server exposing on-device Android/iOS UIs as fast semantic read / observe / find / act / verify tools plus screenshots. Ships an installer that wires it into Claude Code, Claude Desktop, Cursor and Codex.
