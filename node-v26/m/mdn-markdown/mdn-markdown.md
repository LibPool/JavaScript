# mdn-markdown

> 标签: JavaScript

## 简介

This is a standalone copy of the code in https://github.com/mdn/yari/ that converts from MDN's Markdown into HTML. That in turn uses mostly packages from [unified](https://unifiedjs.com/) to convert GFM, with some custom extensions, as documented in https
