# mcp-google-ads-doctor

> 标签: claude-desktop, diagnostic, doctor, google-ads, mcp

## 简介

Diagnose a broken Claude Desktop + mcp-google-ads setup in one command. Prints a checklist with pass/fail/warn and actionable next steps. Thin delegating wrapper.
