# md-links-jammie

> 标签: CLI, command-line interface, links, markdown, md-links, path

## 简介

Interfaz de línea de comando (CLI) que permite validar las URLs en los archivos markdown, recibe una ruta como argumento, analiza el archivo e imprime las URLs que encuentre.
