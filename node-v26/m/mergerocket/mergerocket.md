# mergerocket

> 标签: cli, concatenate, directory, gitignore, llm, llm-context, merge, recursive, text-files

## 简介

A CLI tool that recursively merges the text files in a directory into one output file, wrapping each file in configurable markers so a whole tree fits in a single LLM prompt.
