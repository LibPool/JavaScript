# mstodo-bridge

> 标签: claude, mcp, mcp-server, microsoft-todo, model-context-protocol, outlook, tasks, todo

## 简介

Local MCP server for Microsoft To Do. Chat-native login (click a link, paste the callback), built-in OAuth client, auto token refresh, Windows-friendly.
