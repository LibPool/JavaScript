# mcp-ts-template

> 标签: agent, ai, ai-agent, authentication, cloudflare-workers, declarative-tools, dependency-injection, elicitation, error-handling, hono, llm-integration, mcp, mcp-server, model-context-protocol, observability, opentelemetry, otel, server-template, template, typescript, zod

## 简介

TypeScript template for MCP servers with declarative tools/resources, pluggable auth, multi-backend storage, OpenTelemetry observability, and Cloudflare Workers support.
