# my-mern-frontend

> 标签: JavaScript

## 简介

একটা ready React + Tailwind + Router + Query setup যেটা তুমি `npx` দিয়ে নতুন প্রোজেক্ট তৈরি করতে ব্যবহার করতে পারবে।   Basic configuration গুলো আগে থেকেই সেট করে রাখা আছে, তাই নতুন project শুরু করা অনেক দ্রুত হয়।
