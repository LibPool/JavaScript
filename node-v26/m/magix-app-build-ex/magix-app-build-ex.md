# magix-app-build-ex

> 标签: JavaScript

## 简介

This is the tools used for the release of Magix Application 修正版，支持生成非-min.js的压缩文件，兼容requirejs [ by chonzhi ]

- 源码仓库：git://github.com/thx/magix-app-build-ex.git
- npm 页面：https://www.npmjs.com/package/magix-app-build-ex
