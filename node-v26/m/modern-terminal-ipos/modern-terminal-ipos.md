# modern-terminal-ipos

> 标签: JavaScript

## 简介

Aplikasi add-ons untuk pengguna iPos 5 untuk bisa menampilkan harga ke customer jika ingin mengecek harga secara mandiri tanpa harus mengunjungi petugas kasir
