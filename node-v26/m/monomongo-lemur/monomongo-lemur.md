# monomongo-lemur

> 标签: lemur, mongodb, mongoose, monomongo-lemur

## 简介

MonoMongo es una biblioteca para gestionar conexiones con bases de datos MongoDB utilizando Mongoose, facilitando el manejo de entornos locales y de producción.
