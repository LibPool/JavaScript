# mcp-llm-studio

> 标签: ai, claude, claude-code, llm, lm-studio, local-llm, mcp, model-context-protocol

## 简介

MCP server bridging Claude Code (and other MCP clients) to a local LM Studio instance. Exposes model lifecycle (list/load/unload/download), single-turn inference with reasoning and stats, multi-turn chat with SQLite-persisted history, and embeddings.
