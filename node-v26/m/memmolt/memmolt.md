# memmolt

> 标签: agent-memory, claude-code, fts5, mcp, memory, model-context-protocol, rag, sqlite, vector-search

## 简介

Structured, searchable, long-term memory for AI agents. Hybrid FTS5 + vector search over a local SQLite store, exposed via MCP.
