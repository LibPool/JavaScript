# mtnjs-ws

> 标签: JavaScript

## 简介

Pure JavaScript mtnjs websocket library for node.js and browsers. Can be used to easily connect to and obtain data from the mtnjs blockchain via public apis or local nodes.

## 官网

- npm 页面：https://www.npmjs.com/package/mtnjs-ws

## 获取地址

- npm registry：https://registry.npmjs.org/mtnjs-ws
- Node 要求：>= 6.0.0
