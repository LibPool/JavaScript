# muche-dsh-plugin

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, muche

## 简介

连接小沐（MuChe 数字生命）的 dsh 插件：可以和有持续状态的小沐聊天，小沐可调用本机 dsh 执行任务
