# mcp-server-graylog

> 标签: debugging, distributed-tracing, elasticsearch, error-tracking, graylog, log-search, logging, mcp, microservices, model-context-protocol, observability, production-debugging, trace-id

## 简介

Model Context Protocol (MCP) server for Graylog log searching with distributed tracing. Search logs, trace requests across services, get surrounding context, and debug production issues.
