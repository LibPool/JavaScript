# mcp-auth-gateway

> 标签: ai, authentication, claude, cursor, gateway, internal-tools, jwt, mcp, model-context-protocol, oauth2, sso

## 简介

MCP Gateway - 统一认证网关，让 AI 快速接入企业内部系统。支持 SSO(OAuth2+PKCE)、JWT(自动刷新)、用户名密码认证，配置驱动自动注册 MCP Tools。
