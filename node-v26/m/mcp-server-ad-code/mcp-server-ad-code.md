# mcp-server-ad-code

> 标签: JavaScript

## 简介

只要你提供一个香港中原外网的房源编号(房源编号可以在这里查找：[https://hk.centanet.com](https://hk.centanet.com)  )  ，就可以得到盤源和所屬屋苑的盤源基本信息。
