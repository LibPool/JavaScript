# material-react-table-pragmatic

> 标签: data table, material-table, material-ui, react-table, tanstack table

## 简介

A fully featured Material UI V6 implementation of TanStack React Table V8, written from the ground up in TypeScript. Forked to add drag and drop functionality from atlassians pragmatic drag and drop library.
