# mammalia

> 标签: JavaScript

## 简介

Pick a pseudo-random mammal name from a list of all known mammals. To be specific, that is all members of the taxonomic class Mammalia. The data is sourced from [Mammal Species of the World][msw] (Wilson & Reeder, 2005).
