# momentum-search

> 标签: adaptive, algorithm, auto-tune, browser, evolution, gradient, isomorphic, loss-function, machine-learning, momentum, nodejs, optimization, parameter-search, tuning

## 简介

A TypeScript library to iteratively tune parameters using adaptive momentum-based optimization to minimize a given loss function.
