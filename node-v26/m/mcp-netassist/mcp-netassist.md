# mcp-netassist

> 标签: china-network, diagnostics, github, mcp, mcp-server, model-context-protocol, network, proxy, troubleshooting, windows

## 简介

Network & proxy diagnostics as an MCP server: GitHub reachability, system proxy status, proxy port probing, DNS/TCP/HTTP diagnosis, hosts conflict scan and a doctor that suggests what to change. Works with any MCP client.
