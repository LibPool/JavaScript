# mcp-delphi-codecoverage

> 标签: claude, claude-code, code-coverage, delphi, delphicodecoverage, documentation, dunitx, mcp, model-context-protocol

## 简介

MCP server that helps generate Delphi Units, Forms and DUnitX tests already in the shape the DelphiCodeCoverage tool expects (Map file settings, console test runner, CLI usage, CI script) - built for use with Claude Code and other MCP clients
