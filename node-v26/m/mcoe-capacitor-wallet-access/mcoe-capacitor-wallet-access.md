# mcoe-capacitor-wallet-access

> 标签: capacitor, native, plugin

## 简介

Designed to allow Front End Developers access to the contents of a user's Wallet. This means that the plugin will ultimately allow for the retrieval, alteration, or deletion of PKPasses from a user's wallet. Currently only functional in capacitor v3.9.0 a
