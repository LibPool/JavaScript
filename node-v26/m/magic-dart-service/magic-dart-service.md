# magic-dart-service

> 标签: dart, disclosure, k-ifrs, korea, mcp, model-context-protocol, opendart, self-hosted, sveltekit, 전자공시

## 简介

Self-hosted web app and MCP server over a local cache of OpenDART (Korean electronic disclosure) data, with accounts, passkeys and an English UI.
