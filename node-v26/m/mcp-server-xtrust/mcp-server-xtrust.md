# mcp-server-xtrust

> 标签: business-directory, company-lookup, edr, mcp, model-context-protocol, ukraine, xtrust

## 简介

MCP server for xtrust.info — Ukrainian business directory: company contacts, ratings, phone and website reputation, and official ЄДР (state registry) legal-entity data.
