# miio-controller

> 标签: controll, mi, miio, protocol, xiaomi

## 简介

This is plugin developed by based on plugin [miIO Device Library](https://www.npmjs.com/package/miio) It's plugin provides simple work above protocol miIO, is provided simple API for send and recieve commands different device's. Have support async method
