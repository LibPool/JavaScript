# mp4cat

> 标签: aac, browser, concat, concatenate, h264, lossless, mp4, mux, nanoodle, no-deps, remux, video, zero-dependencies

## 简介

Zero-dependency lossless mp4 concatenation for Node and the browser — copy compressed samples onto one timeline, no ffmpeg, no re-encode
