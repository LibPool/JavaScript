# matrix-db-client

> 标签: cloudflare, crud, d1, database, mongodb, mysql, nuxt, postgresql, schema, sqlite, typescript

## 简介

模块化异步数据库 CRUD 客户端, 自动适配 SQLite/MySQL/D1/MongoDB/PostgreSQL, 支持表/字段 Schema 导入导出, 兼容 Nuxt4 (Node.js & Cloudflare Pages)
