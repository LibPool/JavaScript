# mouse-keepalive

> 标签: automation, cli, cross-platform, idle, keep-alive, linux, macos, mouse, prevent-sleep, tool, windows

## 简介

A cross-platform tool to automatically move the mouse at specified intervals to prevent system sleep or lock
