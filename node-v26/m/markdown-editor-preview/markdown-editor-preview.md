# markdown-editor-preview

> 标签: editor, markdown, markdown-preview, vue

## 简介

基于Vue3和TypeScript的Markdown预览编辑器，支持双向滚动同步、代码高亮和自定义渲染器，提供流畅的编辑和预览体验
