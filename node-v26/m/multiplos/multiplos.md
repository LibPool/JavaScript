# multiplos

> 标签: común, mcm, multiplos, mínimo

## 简介

Este paquete es para la exploración de múltiplos de números naturales, puedes utilizar la mcm([n,...]) para poder encontrar el mínimo común múltiplo de 1 o mas números naturales.
