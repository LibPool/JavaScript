# markdown-it-attrs

> 标签: attributes, classes, commonmark, curly brackets, header_attributes, identifiers, ids, markdown, markdown-it, markdown-it-plugin, pandoc

## 简介

Add classes, identifiers and attributes to your markdown with {} curly brackets, similar to pandoc's header attributes
