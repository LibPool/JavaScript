# mcp-testlib

> 标签: assert, jest, matchers, mcp, mcp-server, model-context-protocol, test, testing, vitest

## 简介

Testing library for MCP servers — in-memory test client, Vitest/Jest matchers, and test doubles for sampling and elicitation.
