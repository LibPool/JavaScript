# maxpat-probe

> 标签: ableton, amxd, cli, jitter, max, max-for-live, maxmsp, maxpat

## 简介

Read Max/MSP patchers and Max for Live devices from the command line — inspect, search, extract and diff .maxpat and .amxd files without opening Max.
