# m2m-uiux-vue

> 标签: JavaScript

## 简介

Vue 3 컴포넌트 라이브러리. 컴포넌트마다 **서브패스로 개별 import** 하고, 스타일은 Tailwind 없이 SCSS 모듈 + `--m2m-*` CSS 변수로 구성됩니다. `--m2m-font-size` 하나로 UI 전체가 비례 스케일됩니다. 동일 API 의 React 판(`m2m-uiux-react`)이 함께 배포되며 props · 상수명 · 디자인 토큰이 100% 동일합니다.
