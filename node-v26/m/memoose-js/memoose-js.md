# memoose-js

> 标签: async-cache, batch-cache, cache, function-cache, in-memory-cache, memoization, memoize, nextjs, redis, ttl, typescript

## 简介

Memoization with swappable cache providers — same code in dev (memory), test (disabled), and prod (Redis). Just swap the provider.
