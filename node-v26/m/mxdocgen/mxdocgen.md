# mxdocgen

> 标签: Mendix, documentation, mpk

## 简介

A small tool that mimics the documentation generation capabilities offered in Mendix Studio Pro, but with greater flexibility.

It uses the Mendix Model SDK to extract information from a Mendix model, which is then fed into a set of templates to generate
