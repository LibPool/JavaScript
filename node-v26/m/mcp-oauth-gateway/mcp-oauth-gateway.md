# mcp-oauth-gateway

> 标签: dsh, gateway, mcp, model-context-protocol, oauth, oauth2, oauth21, pkce, proxy, rfc8414, rfc8707, rfc9728

## 简介

OAuth 2.1 for MCP clients that only know how to send a static Authorization header: a loopback gateway that does RFC 9728 discovery, PKCE and silent refresh on their behalf.
