# masterlink-backend-sdk

> 标签: backend, market-data, masterlink, sdk, stock, taiwan, trading

## 简介

Masterlink SDK 封裝，專為後端應用程式設計，提供簡潔易用的 API 來存取台灣證券市場的交易和行情資料
