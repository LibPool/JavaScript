# ml-time-graph

> 标签: annotations, chart, dataviz, incident-analysis, logs, metrics, mkt, monitoring, observability, renderer, sensor, ssr, svg, telemetry, time-series, typescript, visualization

## 简介

TypeScript library for time-series charts with rich contextual annotation — telemetry, sensors, metrics, logs, finance. DOM-free SVG output, identical in the browser and on the server.
