# markdown-it-obsidian-imgsize

> 标签: image, image size, img, imgsize, markdown, markdown-it, markdown-it-plugin, obsidian

## 简介

A markdown-it plugin, adding width (and height) attributes to image elements, according to the syntax of external images in Obsidian.
