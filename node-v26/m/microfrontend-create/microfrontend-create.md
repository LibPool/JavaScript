# microfrontend-create

> 标签: angular, builder, generator, js, lit, microfrontend, modulefederationplugin, react, svelte, vanillajs, vue, webcomponents, webpack

## 简介

This is a microfrontend project builder through webpack v5 (ModuleFederationPlugin). You can create a 'container' or 'child' microfrontend. You will also be able to decide under which development environment to work, be it 'React', 'Vue', 'Angular', 'Svel
