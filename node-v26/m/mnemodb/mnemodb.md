# mnemodb

> 标签: agent, agent-memory, ai, claude, llm, markdown, mcp, memory, memory-format

## 简介

MnemoDB — the agent memory format. A database whose files you can read: human-readable .mem.md memory for AI agents. Umbrella package re-exporting @mnemodb/core.
