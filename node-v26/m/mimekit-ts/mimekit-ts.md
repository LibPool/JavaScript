# mimekit-ts

> 标签: email, mbox, mime, mimekit-ts, parser, rfc2045, rfc2047, rfc2822, tnef

## 简介

TypeScript port of MimeKit (Lite scope): non-throwing Result-based MIME parsing/creation, byte-parity verified against the C# implementation
