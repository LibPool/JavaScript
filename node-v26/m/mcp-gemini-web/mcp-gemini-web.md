# mcp-gemini-web

> 标签: ai, gemini, grounding, mcp, model-context-protocol, research, search, web-search

## 简介

MCP server exposing a grounded web search tool powered by Gemini 3 + Google Search grounding, with configurable verbosity, optional sources, and research mode.
