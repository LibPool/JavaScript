# mcp-zebrunner

> 标签: dashboards, mcp, model-context-protocol, qa, reporting, tcm, testing, zebrunner

## 简介

Advanced Zebrunner MCP Server — analytics, reporting, and safe mutations for Zebrunner. Complements the official Zebrunner MCP (beta). Tools registered as adv_<name> with legacy aliases kept for backward compatibility.
