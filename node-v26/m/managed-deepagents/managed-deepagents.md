# managed-deepagents

> 标签: agents, cli, deepagents, langchain, langgraph

## 简介

Managed Deep Agents — the `defineDeepAgent` authoring interface plus the CLI that compiles and deploys a code-first Deep Agent repository to a managed LangGraph runtime.
