# mdefender-pro

> 标签: csrf, express, firewall, middleware, nodejs, owasp, protection, security, sqli, waf, web-application-firewall, xss

## 简介

MDefender Pro - Web Application Firewall middleware for Node.js/Express. Protects against XSS, SQLi, CSRF, and other OWASP Top 10 attacks.
