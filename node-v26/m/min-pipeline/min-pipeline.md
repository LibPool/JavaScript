# min-pipeline

> 标签: automation, ci-cd, min-pipeline, webhook

## 简介

A lightweight CI/CD system inspired by Jenkins, designed for simplicity and full control. It allows you to define, run, and monitor build pipelines with real-time logs, minimal overhead, and easy self-hosting.
