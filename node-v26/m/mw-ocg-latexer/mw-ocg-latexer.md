# mw-ocg-latexer

> 标签: latex, pdf, wikitext

## 简介

Converts mediawiki collection bundles (as generated by mw-ocg-bundler) to beautiful PDFs (via XeLaTeX)

## 官网

- 源码仓库：git://github.com/wikimedia/mediawiki-extensions-Collection-OfflineContentGenerator-latex_renderer
- npm 页面：https://www.npmjs.com/package/mw-ocg-latexer
