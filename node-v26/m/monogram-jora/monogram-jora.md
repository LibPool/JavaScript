# monogram-jora

> 标签: grammar, jora, monaco, monarch, monogram, syntax-highlighting, textmate, tmlanguage, tree-sitter, vscode

## 简介

TextMate grammar, VS Code language configuration, Monaco Monarch tokenizer, and tree-sitter grammar for the Jora query language, derived from a single grammar definition with Monogram.
