# medusa-plugin-smtp-senpai

> 标签: email, mailsenpai, medusa, medusa-notification, medusa-plugin, medusa-plugin-integration, medusa-plugin-notification, medusa-provider, medusa-v2, notification, smtp-senpai

## 简介

Medusa v2 notification module provider for SMTP Senpai by MailSenpai: send order and customer emails on the email channel through the EU SMTP relay API.
