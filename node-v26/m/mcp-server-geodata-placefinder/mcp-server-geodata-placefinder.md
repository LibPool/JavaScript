# mcp-server-geodata-placefinder

> 标签: duckdb, geocoding, geolocation, mcp, model-context-protocol, overture-maps, places

## 简介

MCP server for the GeoData Placefinder geocoding API — search places, reverse geocode, find nearest places, and look up full place details powered by Overture Maps.
