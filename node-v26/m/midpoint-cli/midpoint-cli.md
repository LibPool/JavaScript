# midpoint-cli

> 标签: blockchain, databridge, developer, midpoint, oracle, pricefeed

## 简介

Use the midpoint CLI to set up midpoints - specifying a set of off-chain actions to be triggered from on-chain events. Midpoints can be oracles that query APIs based on requests from chain, data bridges to pass arbitrary messages between chains, data feed
