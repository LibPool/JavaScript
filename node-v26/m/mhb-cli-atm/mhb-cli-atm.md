# mhb-cli-atm

> 标签: JavaScript

## 简介

This is a Cli-ATM project <br> It have multifucntions like fast cash, Cash withdraw and balance check. <br> The Pin code of this ATM is 8877.<br> If you Enter wrong pin 3 times it show the message <b><i> Your Account is Locked </b> </i>
