# mcp-secure

> 标签: agent-identity, agent-security, agentsign, ecdsa, gguf, hardware-security-module, hsm, kms, mcp, mcp-secure, mcps, message-signing, model-context-protocol, model-integrity, model-signing, owasp, passport, pkcs11, revocation, safetensors, secure-mcp, supply-chain, trust

## 简介

MCPS -- MCP Secure. Drop-in secure replacement for the MCP SDK. ECDSA message signing, body integrity, replay protection, tool integrity, and audit trail.
