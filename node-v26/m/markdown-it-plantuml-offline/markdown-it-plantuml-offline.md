# markdown-it-plantuml-offline

> 标签: markdown, markdown-it, markdown-it-plugin, plantuml, uml

## 简介

Plugin to create block-level uml diagrams for markdown-it markdown parser by using the local Java-based PlantUML CLI (no remote server posts)
