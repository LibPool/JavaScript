# mcp-wacta

> 标签: claude, codex, cta, cursor, mcp, model-context-protocol, wacta, whatsapp, wordpress

## 简介

Servidor MCP (Model Context Protocol) para operar la suite WaCta de WordPress: configuración, Registro Único de CTAs y analítica de WhatsApp, con Application Passwords. Cero dependencias.
