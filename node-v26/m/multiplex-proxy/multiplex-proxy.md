# multiplex-proxy

> 标签: http-proxy, proxy, proxy-server, socks-proxy, socks5, socks5-server

## 简介

A Commercial-Grade, High-Performance Node.js proxy solution that multiplexes HTTP and SOCKS5 protocols onto a single TCP port.
