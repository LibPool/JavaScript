# mcp-ashby

> 标签: ashby, ats, careers, compensation, hiring, job-board, job-search, jobs, mcp, mcp-server, model-context-protocol, no-api-key

## 简介

MCP server for public Ashby job boards. Resolve a company to its board, search its openings, read one posting and its pay. No API key required.
