# musically

> 标签: angular, chord-chart, chordpro, chords, guitar, lit, music, music-theory, piano, react, sheet-music, transpose, ukulele, web-components

## 简介

Framework-agnostic UI toolkit for creating, editing, and displaying chord-over-lyric song sheets, with switchable chord diagrams for piano, guitar, and ukulele.
