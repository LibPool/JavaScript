# mmt-mcp

> 标签: api-testing, cursor, mcp, multimeter, testlight, yaml

## 简介

Multimeter MCP server for Cursor, Copilot, and Claude. Scaffold, validate, format, and run YAML .mmt API tests. Do not invent .mmt syntax.
