# mcp-toolmetry

> 标签: agents, evals, llm, mcp, model-context-protocol, tool-descriptions, tool-use

## 简介

Measure how well AI agents actually use your MCP server's tools — then rewrite the tool descriptions and prove the improvement with before/after data.
