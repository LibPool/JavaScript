# mk-json-2-csv

> 标签: converter, csv, csv-2-json, csv2json, csv2json-converter, json, json-2-csv, json2csv, json2csv-converter

## 简介

A JSON to CSV and CSV to JSON converter that natively supports sub-documents and auto-generates the CSV heading.

- 源码仓库：http://github.com/mrodrig/json-2-csv.git
