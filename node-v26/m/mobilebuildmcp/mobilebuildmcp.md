# mobilebuildmcp

> 标签: ios, macos, mcp, modelcontextprotocol, simulator, xcode, xcodebuild

## 简介

MobileBuildMCP is a Model Context Protocol server that provides tools for Xcode project management, simulator management, and app utilities.
