# muslim.js

> 标签: API, Aladhan, AladhanAPI, Allah, Calendar, DZAN, Hijri, Muslim, Prayer, Quran, dzan, muslim.js, muslimjs, quran

## 简介

Node.js package help you with Aladhan APIv1, A comprehensive wrapper for Aladhan API v1, providing easy access to prayer times, Hijri calendars, and Islamic data for Node.js applications.
