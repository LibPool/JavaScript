# mostcracked

> 标签: claude-code, cli, codex, cursor, leaderboard, omp, statusline

## 简介

The global leaderboard for people who code with Claude Code, Codex, omp and Cursor. Every prompt and every file edit is a point, live at mostcracked.com.
