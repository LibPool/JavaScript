# masked-input-x

> 标签: input, mask, react, typescript

## 简介

🧩 Маска ввода для React на TypeScript — лёгкая альтернатива `react-input-mask`.   Поддерживает маску по шаблону, вставку, удаление, управление курсором и `beforeMaskedStateChange`.
