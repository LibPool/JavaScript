# metrics2xlsx

> 标签: JavaScript

## 简介

metrics2xlsx is a tool that allows you to convert system metrics files uploded on S3 and formatted by [system-metrics-formatter](https://www.npmjs.com/package/system-metrics-formatter) into a .xlsx file.To collect those data we recommend using the npm mod
