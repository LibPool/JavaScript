# midday.ahk

> 标签: 12h, 24h, ahk, am-time, ampm, ante-meridiem, meridiem, meridiem-time, midday, midday-time, military-time, pm-time, post-meridiem, time

## 简介

Converts 24-hour (military) time string to 12-hour (meridiem) time string and vice versa.
