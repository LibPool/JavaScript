# my-workbench

> 标签: agents, claude, claude-code, oh-my-opencode, openbitfun, opencode, scaffold

## 简介

Portable OpenCode + Claude Code agent setup: copies the .opencode/ and .claude/ agent configuration into your project (or user level with --user).
