# mcp-yandex-metrica

> 标签: analytics, mcp, model-context-protocol, web-analytics, yandex, yandex-metrica, yandex-metrika

## 简介

MCP server for the Yandex Metrica API — list counters and goals, pull web-analytics statistics (visits, users, bounce rate, conversions) from AI agents.
