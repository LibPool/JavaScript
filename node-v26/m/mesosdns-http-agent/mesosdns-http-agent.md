# mesosdns-http-agent

> 标签: DNS, Mesos DNS, Mesosphere, Service Discovery, agent, http, request, resolve, transparent

## 简介

A http.Agent which makes it possible to consume Mesos service resources by simply using the Mesos DNS service names
