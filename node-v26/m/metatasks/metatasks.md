# metatasks

> 标签: ES2015, ES7, classes, concurrency-limited, concurrent, decorators, fault-tolerant, fifo, harmony, metadata, observable, persistable, persistent, promises, proxy, queue, reliable, state-tracking, syntactic sugar, task, tasks

## 简介

FIFO queue for Promise-based tasks. Optionally persistent to ensure tasks survive reboots. Supports concurrency-limiting, metadata and state-tracking for statistics.
