## 简介

Reputation oracle for onchain AI agents on Base. Vet any wallet or ERC-20 token before payments, swaps, escrow releases via mainstreet_preflight → BLOCK/CAUTION/PROCEED in <100ms with EIP-712 signatures. Covers Virtuals agents, Clanker tokens, DEX launche
