# multiversx-sc-mcp

> 标签: ai, blockchain, claude, defi, elrond, esdt, mcp, model-context-protocol, multiversx, smart-contract, web3

## 简介

MCP server for MultiversX blockchain and smart contract interaction — 41 tools for querying, deploying, verifying contracts, managing wallets, issuing tokens, batch transfers, and more. ABI-aware with auto-discovery.
