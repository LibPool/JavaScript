> 标签: ci, cypress, disposable-email, e2e, e2e-testing, email, email-api, email-testing, email-verification, inbox, integration-testing, jest, mail-testing, mailfornet, otp, playwright, puppeteer, qa, temporary-email, test-email, testing, throwaway-email, verification-code, vitest, webhooks

## 简介

Disposable email inboxes for automated tests. Create an inbox, sign up with it, and read the verification code back out — from your test code. Zero dependencies, TypeScript types included.
