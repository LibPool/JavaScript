# miaoda-game-lighting-core

> 标签: cocos, grid, light, lighting, phaser, radiosity, roguelike, rot-js, torch

## 简介

Engine-agnostic tile-level gameplay lighting on a grid — multi-source light with color mixing and an optional radiosity-style bounce pass. Built on rot-js's Lighting + FOV. Feed it walls + light sources, read back a lit color per tile; pairs with miaoda-g
