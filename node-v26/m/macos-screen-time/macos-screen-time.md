# macos-screen-time

> 标签: analytics, bun, knowledgec, macos, screen-time, screentime, sqlite, tracking, usage

## 简介

Access macOS Screen Time data with zero external dependencies. Uses Bun's built-in SQLite to read the knowledgeC.db database.
