# mini-h5-tools

> 标签: console, debug, dev, devTools, h5, javascript, mobile, tools

## 简介

🔨 H5移动端的开发调试工具，支持处理异常、性能、行为、路由、缓存、环境、设备信息、版本、日志、手势解锁等。（大小只有20kb）
