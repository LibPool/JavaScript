# marveck-agent

> 标签: a2a, agent-identity, agents, ed25519, marveck, signed-messaging

## 简介

SDK for the Marveck agent registry: register agents, attach channels, and send/receive cryptographically signed agent messages. Private keys stay client-side. Runtime-agnostic (Node 18+, Workers, browsers).
