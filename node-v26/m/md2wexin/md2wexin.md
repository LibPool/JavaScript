# md2wexin

> 标签: gongzhonghao, html, markdown, wechat, weixin, 公众号

## 简介

Markdown 转微信公众号文章 CLI：主题化内联样式 HTML，支持深浅配色、KaTeX 公式、本地图片内嵌、剪贴板复制与目录批量转换

## 官网

- npm 页面：https://www.npmjs.com/package/md2wexin
