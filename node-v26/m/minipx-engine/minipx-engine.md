> 标签: avif, cli, compress, compression, image, image-optimization, jpeg, jsquash, minipx, mozjpeg, optimize, oxipng, png, squoosh, target-size, wasm, webp

## 简介

MiniPx's local image compression engine as a library + CLI. mozjpeg, oxipng, WebP and AVIF via WASM — the API you don't pay per call for.
