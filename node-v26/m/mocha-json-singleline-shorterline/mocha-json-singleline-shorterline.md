# mocha-json-singleline-shorterline

> 标签: JSON, ci, fluentd, mocha, reporter, spec

## 简介

A mocha reporter that outputs single-line JSON, allows fluentd parsing. It also only includes stats and information about failures, so that the line is shorter.
