# mv3-wait-for-element

> 标签: browser-extension, chrome-extension, content-script, dom, dom-ready, edge-extension, firefox-extension, manifest-v3, mutation-observer, mv3, spa, typescript, wait-for-element, web-extension, webextension

## 简介

Wait for a DOM element to appear or disappear — tiny MutationObserver-backed helper for Chrome extension content scripts on Manifest V3 (MV3). Zero dependencies, fully typed.
