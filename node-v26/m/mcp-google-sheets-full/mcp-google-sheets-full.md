## 简介

The Google Sheets MCP server that can do anything the Sheets API can — 26 tools including read/write, structural batchUpdate, Drive search, and `run_sheets_script` to execute arbitrary Node code with pre-authenticated `sheets`/`drive`/`auth`/`spreadsheetI
