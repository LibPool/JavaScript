# msh-zip

> 标签: binary, bitdict, chunk, compression, coorddict, dedup, deduplication, ecc, error-correction, gzip, hamming, msh, sha256, streaming

## 简介

Fixed-chunk dedup + entropy compression with ECC protection and C native acceleration (MSH1 format)
