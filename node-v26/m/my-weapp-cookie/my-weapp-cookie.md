# my-weapp-cookie

> 标签: cookie, wxapp

## 简介

一行代码让微信小程序支持 cookie，以保证基于 cookie 的服务器会话机制不会失效，与 web 端共用会话机制

- 源码仓库：git+https://github.com/charleslo1/weapp-cookie.git
- npm 页面：https://www.npmjs.com/package/my-weapp-cookie
