# magic-oxlint-plugin

> 标签: eslint-plugin, lint, oxc, oxlint, plugin

## 简介

oxlint JS-plugin rules. Opt-in under `magic/*`: prefer-early-return, no-ancestor-directory-import, no-barrel-file, no-manual-classname, no-module-mocks, prefer-suspense-query, react-hooks-strict-return, react-require-autocomplete. Plus `react-native/*` —
