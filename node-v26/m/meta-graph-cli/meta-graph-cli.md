# meta-graph-cli

> 标签: business-manager, cli, facebook, graph-api, instagram, marketing-api, meta

## 简介

One passthrough CLI (fbg) for the Meta Graph API: Business Manager, system users, asset assignment, ad accounts, custom audiences, webhooks, Pages/IG. One token, every endpoint, read+write.
