# metamuse-mcp

> 标签: mcp, metamuse, muse, rh777, robinhood-chain, usdg, wallet

## 简介

MCP server for MetaMuse: a muse's own wallet on Robinhood Chain. Buy stock tokens, pay in USDG through rh777, run a vault, inside the ceiling its human set on chain. The key never leaves this machine.
