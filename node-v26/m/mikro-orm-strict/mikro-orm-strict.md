# mikro-orm-strict

> 标签: entity-manager, mikro-orm, mikroorm, orm, strict, type-safe, typescript, unflushed

## 简介

Type-safe extensions for MikroORM: createStrict, assignStrict, getStrictReference, Unflushed<T>, and flush guards
