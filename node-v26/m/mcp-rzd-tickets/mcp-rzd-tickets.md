# mcp-rzd-tickets

> 标签: agent-tools, mcp, model-context-protocol, railway, rzd, tickets

## 简介

Read-only MCP server that gives AI agents live visibility into RZD train tickets, cars, lower/upper seats and adjacent pairs.
