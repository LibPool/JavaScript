# mcp-supermercados-cl

> 标签: chile, claude, jumbo, lider, mcp, model-context-protocol, precios, santa-isabel, shopping-list, supermercado, tottus, unimarc

## 简介

Servidor MCP para buscar productos, comparar precios y armar la mejor lista de compra en supermercados chilenos (Jumbo, Santa Isabel, Unimarc, Tottus, Lider) desde Claude o ChatGPT.
