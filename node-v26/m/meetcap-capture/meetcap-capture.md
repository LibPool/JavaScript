# meetcap-capture

> 标签: audio, capture, mediarecorder, meetcap, recorder

## 简介

Shared recording engine for meetcap — the backend-agnostic capture state machine (events, pause accounting, crash-safe chunk ordering) that meetcap-renderer (Electron) and meetcap-web (browser) plug their capture/persistence/permission backends into.
