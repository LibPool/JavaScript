# mycastle

> 标签: archery, cli, devkit, kibana, mysql, workspace, xxl-job, yunxiao

## 简介

Personal workspace toolkit: scaffold a work hub and run cross-platform read-only CLIs (Kibana / XXL-Job / Archery / MySQL / repo-changes). Skills are managed by the `skills` CLI.
