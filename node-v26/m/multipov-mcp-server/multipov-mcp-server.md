# multipov-mcp-server

> 标签: ai-review, capital-thought, claude, code-review, mcp, model-context-protocol, multipov, personas, review

## 简介

MCP server for multipov.ai — stdio-to-HTTP proxy that forwards tool calls to the hosted multipov.ai MCP endpoint. Exposes 14 tools for multi-perspective AI reviews, persona browsing, and voice rewrites from MCP-aware clients like Claude Code, Claude Deskt
