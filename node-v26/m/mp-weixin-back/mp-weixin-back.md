# mp-weixin-back

> 标签: back-navigation, gesture-back, miniprogram, mp-weixin, navigate-back, navigation-intercept, page-back, uni-app, uniapp, vite-plugin, vue3, wechat, 微信小程序, 手势返回, 页面返回拦截

## 简介

Vite plugin to intercept back navigation (gesture back & navbar back) in WeChat miniprogram (mp-weixin) built with uni-app + Vue 3. 监听微信小程序的手势返回和页面默认导航栏的返回
