# mcp-widget-studio

> 标签: devtools, mcp, mcp-client, mcp-inspector, mcp-ui, model-context-protocol, openai-apps-sdk

## 简介

Web-based MCP client with a widget renderer — inspect servers, call tools, and render their UIs the way ChatGPT renders apps. Supports OpenAI Apps SDK & MCP-UI.
