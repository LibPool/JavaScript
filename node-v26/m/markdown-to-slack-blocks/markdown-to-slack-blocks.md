# markdown-to-slack-blocks

> 标签: block-kit, blockkit, chatops, converter, data-table, data_table, gfm, llm, markdown, markdown-parser, markdown-to-slack, mrkdwn, parser, rich-text, rich-text-block, slack, slack-api, slack-block-kit, slack-blocks, slack-bot, slack-message, table, typescript

## 简介

A powerful, type-safe library to convert Markdown (incl. GFM tables, code, mentions, and LLM output) into Slack Block Kit JSON — and back. Supports Slack's native data_table block with dynamic cell typing.
