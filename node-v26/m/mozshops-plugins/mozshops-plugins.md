# mozshops-plugins

> 标签: JavaScript

## 简介

## Overview Mozshops-Plugins is a framework designed to facilitate the creation of custom plugins and themes for [Mozshops.store](https://mozshops.store). It provides a streamlined way to design and deploy plugins with customized functionality and themes
