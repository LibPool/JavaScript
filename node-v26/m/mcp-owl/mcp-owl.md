# mcp-owl

> 标签: ai-assistant, ai-tools, ast-parser, claude, code-analysis, code-understanding, codebase-navigation, cursor, kiro, laravel, llm, mcp, mcp-server, model-context-protocol, nestjs, nextjs, php, semantic-code-analysis, symbol-resolver, typescript

## 简介

MCP server for codebase navigation — explains symbols, traces execution flows, and searches references via AST parsing and LLM. Supports PHP and TypeScript projects.
