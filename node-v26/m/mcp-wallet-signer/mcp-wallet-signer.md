# mcp-wallet-signer

> 标签: ai-agent, blockchain, browser-wallet, claude, ethereum, evm, mcp, metamask, model-context-protocol, non-custodial, signing, transaction-signing, wallet, web3

## 简介

MCP server that routes EVM transactions and messages to your own browser wallet for signing — a thin shim over browser-web3-signer
