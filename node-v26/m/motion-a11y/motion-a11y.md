# motion-a11y

> 标签: a11y, accessibility, animation, ci, framer-motion, gsap, linter, lottie, motion, prefers-reduced-motion, seizure, static-analysis, vestibular, wcag

## 简介

Accessibility linter for animation code. Finds motion that can trigger vestibular disorders and seizures in Framer Motion, Motion, GSAP, Lottie and the Web Animations API.
