# mailchimp-reports

> 标签: JavaScript

## 简介

1. Clone the repo  2. run `npm install` to install dependencies 3. Add your MailChimp API Key to edit `app.js` 4. Run via `node app` or `supervisor app` 5. Navigate to http://127.0.0.1:3002
