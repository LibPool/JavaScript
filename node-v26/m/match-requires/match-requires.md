# match-requires

> 标签: analyze, ast, code, exec, exports, expression, expressions, find, local, match, matcher, matches, matching, module, modules, path, paths, re, regex, regexp, regular, require, requires, source, statement, test

## 简介

Match require statements in a string. Returns an array of matching require statements. Each match is an object with line number, variable name, and module name. Statements in code comments are ignored.
