# marco-runtime

> 标签: agent, agent-runtime, ai, anthropic, claude, deepseek, marco, sandbox, tools

## 简介

An opinionated agent runtime built on marco-agent. Sandboxed code execution, workspace context, skills system, conversation persistence, and a streaming HTTP handler — pluggable, product-agnostic. The third layer of the marco family: harness → agent → run
