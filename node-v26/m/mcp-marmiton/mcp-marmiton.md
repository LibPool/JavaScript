# mcp-marmiton

> 标签: ai, claude, cooking, cursor, food, french, llm, marmiton, mcp, mcp-server, model-context-protocol, modelcontextprotocol, no-api-key, recipe, recipes, scaling, servings

## 简介

MCP server for Marmiton. Search recipes, read ingredients and steps, and scale quantities to any number of servings. No API key required.
