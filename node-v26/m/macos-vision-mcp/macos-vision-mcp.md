# macos-vision-mcp

> 标签: accessibility, ai-agent, apple-vision, barcode, claude, claude-desktop, computer-use, cursor, desktop-automation, document-detection, face-detection, image-classification, image-to-text, macos, mcp, mcp-server, model-context-protocol, ocr, offline, on-device, pdf, pdf-ocr, privacy, qr-code, screen-capture, screenshot, text-extraction, ui-automation, ui-testing, vision-framework

## 简介

Local OCR and on-device screen reading for MCP clients (Claude, Cursor): read any window, locate elements to click, assert what's on screen. Apple Vision, no API keys, nothing uploaded.
