# many-ai-cli

> 标签: ai, approvals, claude-code, cli, codex, dashboard, terminal

## 简介

Web dashboard to manage approvals and progress across multiple AI coding CLIs (Claude Code / Codex / Copilot / Cursor / OpenCode / Grok). Bundles a native Go binary per platform — no standalone exe download, no Mark-of-the-Web SmartScreen prompt.
