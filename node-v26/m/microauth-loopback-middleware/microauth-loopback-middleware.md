# microauth-loopback-middleware

> 标签: JavaScript

## 简介

This middleware provide a easy way to authenticate request with the [auth-service](https://github.com/zekylaf/auth-service) tokens. As its name implies, is designed for the loopback framework and relays on the user and acess-token built in models.
