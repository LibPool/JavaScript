# mcp-increazy

> 标签: ai-tools, anthropic, claude, ecommerce, headless, increazy, mcp, model-context-protocol, pwa

## 简介

MCP server for Increazy headless PWA e-commerce platform — manage codes, CMS, SEO, backups and publishing from any MCP-compatible client (Claude Desktop, Claude Code, Cursor).
