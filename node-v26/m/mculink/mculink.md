# mculink

> 标签: arm, cortex-m, debugging, embedded, ffi, foreign-function-interface, jlink, mcu, microcontroller, segger

## 简介

Type-safe FFI compatible with ARMv6-M that allows MCU interoperation with computers via J-Link
