# minivec

> 标签: ann, browser, embeddings, hnsw, in-memory, nearest-neighbor, rag, semantic-search, similarity-search, vector-database, vector-store

## 简介

Tiny embedded vector store - HNSW approximate search from scratch, exact search, metadata filters, JSON persistence. Zero dependencies; Node, browser, edge.
