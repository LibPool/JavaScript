# mcp-skills-server

> 标签: agent-skills, enterprise, mcp, model-context-protocol, sep-2640, skills, typescript

## 简介

Enterprise-grade TypeScript MCP server that progressively serves Agent Skills over MCP, implementing SEP-2640 and bundling the upstream addyosmani/agent-skills catalog.
