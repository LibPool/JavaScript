# mongoose-populate-virtuals

> 标签: aggregation, join, mongoose, mongoose-deep-populate, mongoose-power-populate, mongoose-reverse-populate, populate, population

## 简介

Extend Mongoose 4+ population with virtual attributes that can be populated in either direction.
