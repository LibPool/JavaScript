# mvc-integrator

> 标签: DB2, Dialects, ERD, ERD Editor, MVC, Model, Visual Studio Code

## 简介

The MVC-Integrator is to help developers to build consistency systems. The tool will generate classes releted to an ERD Model created on ERD Editor. Also, it is going to work directly with some database dialects. The development and test are using Visual
