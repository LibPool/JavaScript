# mcmodsdevbridge

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, end-to-end, fabric, forge, minecraft, mod-development, neoforge, powershell, probe, windows

## 简介

Minecraft 26.3 mod development bridge for DeepSeek Harness: starts a real dedicated server and a real client, connects and ops, runs a scenario JSON of probe HTTP calls, collects evidence and tears everything down, on Fabric / Forge / NeoForge. Ships 11 s
