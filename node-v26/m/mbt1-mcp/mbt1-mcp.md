# mbt1-mcp

> 标签: JavaScript

## 简介

MBT1 心理測驗網（mbt1.org）的 MCP server — 讓 AI 助理讀取 MBTI、星座、九型、DISC、愛情與趣味心理測驗，以及人格／自我成長文章。原創繁體中文台灣在地內容。
