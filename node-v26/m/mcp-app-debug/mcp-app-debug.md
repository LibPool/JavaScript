# mcp-app-debug

> 标签: aggregator, app-bridge, conformance, csp, debug, diagnostics, gateway, host-conformance, iframe, mcp, mcp-apps, model-context-protocol, playwright, stdio, tool-namespacing, ui

## 简介

Debug both ends of MCP Apps — render your server's app in a Playwright browser with 7 automated diagnostics, 12 under --profile (npx mcp-app-debug <server-url>), or grade a HOST's MCP Apps conformance with a probe fixture server (npx mcp-app-debug host).
