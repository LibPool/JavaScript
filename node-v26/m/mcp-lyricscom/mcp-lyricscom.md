# mcp-lyricscom

> 标签: ai, claude, cursor, llm, lyrics, lyrics.com, mcp, mcp-server, model-context-protocol, modelcontextprotocol, music, no-api-key, search, song, song-lyrics

## 简介

MCP server for lyrics.com. Search song lyrics by word or by title, and fetch full lyrics. No API key required.
