# markdown-it-glossary

> 标签: abbreviation, docs, documentation, glossary, markdown-it, markdown-it-plugin, tooltip, vitepress, vitepress-plugin

## 简介

Define a glossary once in a plain Markdown file and get it back as site-wide hover tooltips (<abbr title="...">) wherever those terms appear — with a Markdown-frontmatter opt-out per page. Built for VitePress, works with any markdown-it consumer.
