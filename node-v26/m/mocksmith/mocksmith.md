# mocksmith

> 标签: api-mocking, e2e, mock, mock-server, playwright, sse, testing, vite, websocket

## 简介

A session-aware mock server for HTTP, WebSocket, raw TCP/TLS and SSE, with declarative scenarios, a runtime control API, a Playwright fixture and Vite integration.
