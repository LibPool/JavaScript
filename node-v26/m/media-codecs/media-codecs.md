# media-codecs

> 标签: avc, codecs, mp4, vp, webcodecs, webm

## 简介

Get a codec parameter string (like 'avc1.4d002a') from human readable options (like { name: 'Main', level: '4.2' }) and back to a descriptive name ('AVC Main Profile Level 4.2').
