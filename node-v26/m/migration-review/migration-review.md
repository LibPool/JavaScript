# migration-review

> 标签: ci, cli, database, devtools, migration, postgres, postgresql, safety, schema, sql

## 简介

PostgreSQL migration safety review CLI and library. Detect destructive changes, locking hazards, transaction incompatibilities, and risky data operations before production.
