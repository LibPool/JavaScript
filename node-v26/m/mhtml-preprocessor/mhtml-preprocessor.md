# mhtml-preprocessor

> 标签: html, html preprocessor

## 简介

The HTML preprocessor, which looks and feels like HTML, yet empowers it with a modern, intuitive syntax. Not for "MIME encapsulation of aggregate HTML documents" (.mhtml) files.
