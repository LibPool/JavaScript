# modern-js-plugin-module-transform-paths

> 标签: JavaScript

## 简介

modernjs 在别名转换的时候暂时无法处理类似 `Promise<import('@common/utils')>` 这样形式的代码，因此产生了本插件，使用 `typescript-transform-paths` 来处理别名
