# millionaire-node

> 标签: JavaScript

## 简介

Bu, Node.js ile oluşturulmuş bir CLI uygulamasıdır. Kullanıcıların farklı node kurulumlarını ve yapılandırmalarını listeleyip, istedikleri node'leri kurmalarına olanak tanır.
