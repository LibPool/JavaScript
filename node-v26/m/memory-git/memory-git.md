# memory-git

> 标签: agent, ai-agents, claude, efs, exec, flush, git, git-cli, git-in-memory, gitignore, in-memory, isomorphic-git, llm, memfs, memory, nfs, non-blocking, typescript, vfs, virtual-filesystem

## 简介

In-memory Git for AI agents, slow filesystems (EFS/NFS), and test harnesses. Bash-like exec() dispatcher, no subprocess, isolated per-instance volumes, .gitignore-aware loading, explicit flush.
