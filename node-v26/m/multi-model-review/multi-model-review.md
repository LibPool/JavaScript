# multi-model-review

> 标签: agent, code-review, multi-model, pi, pi-coding-agent, pi-extension, pi-package

## 简介

A faithful port of oh-my-pi's /review command onto pi — verbatim upstream prompts, diff logic and heuristics — extended so every shard of the diff is reviewed by several different model families, which then cross-check each other.
