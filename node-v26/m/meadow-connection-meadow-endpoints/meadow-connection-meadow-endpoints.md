# meadow-connection-meadow-endpoints

> 标签: connection, meadow, meadow-endpoints, rest

## 简介

Meadow connection that fronts a remote meadow-endpoints REST API as a meadow data source. Pairs with the in-meadow Meadow-Provider-MeadowEndpoints provider — this module supplies the connection-manager wrapper, form schema, and shared cookie/header state
