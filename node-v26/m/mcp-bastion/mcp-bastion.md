# mcp-bastion

> 标签: agent, agentic, ai, ai-security, audit, audit-log, compliance, gateway, guardrails, llm, llm-security, mcp, mcp-gateway, mcp-proxy, mcp-security, mcp-server, model-context-protocol, nist-ai-rmf, observability, owasp, proxy, reconnect, reliability, security, tool-poisoning

## 简介

Reliability + security proxy for the Model Context Protocol (MCP): self-healing connections, runtime tool-security (rug-pull/poisoning detection), and a compliance-mapped audit trail.
