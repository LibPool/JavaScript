# ms-route

> 标签: JavaScript

## 简介

1. Use EsoRouter.RegisterInstance to instance Web server. E.g EsoRouter.RegisterInstance(fastify) or EsoRouter.RegisterInstance(express) 2. Create route description with valid schema EsoRouter.RegisterPostRouteDescription 3. You are able to use web serv
