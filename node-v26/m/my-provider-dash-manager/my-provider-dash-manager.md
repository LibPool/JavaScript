# my-provider-dash-manager

> 标签: account-manager, cloudflare, dashboard, electron, github, multi-account, netlify, railway, render, sessions, supabase, vercel, windows

## 简介

Manage many accounts per cloud service (Vercel, Netlify, Supabase, Cloudflare, Railway, Render, GitHub) in one desktop app — isolated persistent sessions, one tab per account.
