# mqtt-bridge-doorbird

> 标签: JavaScript

## 简介

This is an MQTT Bridge that integrates with [Doorbird][doorbird] "smart" doorbells. These doorbells offer a live camera feed, motion sensor, relays and of course a doorbell button.
