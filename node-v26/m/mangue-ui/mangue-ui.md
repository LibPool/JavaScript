# mangue-ui

> 标签: component-library, design-system, nextjs, radix, react, shadcn, tailwindcss

## 简介

Design system and component library: radix-nova shadcn primitives, a decoupled app shell (sidebar / header / command menu), an AI chat panel, and OKLch design tokens.
