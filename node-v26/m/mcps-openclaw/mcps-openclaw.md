# mcps-openclaw

> 标签: agent, ecdsa, mcp, mcp-secure, mcps, openclaw, security, signing, trust

## 简介

MCPS cryptographic signing integration for OpenClaw MCP transport. ECDSA P-256 message signing, replay protection, tool integrity for OpenClaw agents.
