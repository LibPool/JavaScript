# @couchbase/couchbase-linux-arm64-openssl3

> 标签: JavaScript

## 简介

Couchbase Node.js SDK platform specific binary for napi runtime on linux OS with arm64 architecture and OpenSSL 3.x.

## 官网

- 官网：http://www.couchbase.com/communities/nodejs
- 源码仓库：git+ssh://git@github.com/couchbase/couchnode.git
