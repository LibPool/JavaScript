# @dynamicagents/plugins

> 标签: agents-sdk, ai-agents, browser-rendering, cloudflare-workers, containers, durable-objects, git, plugins

## 简介

Optional, composable capabilities for a Dynamic Agent: browser rendering, a Linux container, git and pull requests on GitHub, a scratchpad, and Claude Code sessions. One subpath per plugin, so a bundle grows only with what it imports.
