# @dvai-bridge/ios-litertlm-core

> 标签: JavaScript

## 简介

DVAI-Bridge iOS LiteRT-LM core — Swift wrapper around Google's LiteRT-LM runtime for LLM inference on iOS/macOS. Metal GPU acceleration on Apple Silicon; iOS 16+/macOS 13+ link-time minimum. SPM-only (no CocoaPods upstream).
