# angular-popout-window

> 标签: JavaScript

## 简介

Angular library to popout part of your application to a new un-docked browser child window.

- 官网：https://github.com/Shemesh/angular-popout-window
- 源码仓库：git+https://github.com/Shemesh/angular-popout-window.git
