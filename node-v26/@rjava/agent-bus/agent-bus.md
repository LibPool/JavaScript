# @rjava/agent-bus

> 标签: agents, claude-code, codex, cursor, interop, mcp, model-context-protocol, session-handoff

## 简介

A local communication bus for the coding agents on your machine — Claude Code, Codex, and Cursor discover each other's sessions, ask each other questions, and hand work across vendor lines. One MCP server, zero daemons.
