# @bpromote/dsl-admin

> 标签: JavaScript

## 简介

`@bpromote/dsl-admin` 是一个全栈实现的企业级应用框架，通过结合 JSON - Schema 提供了强大的 DSL（领域特定语言）配置能力，能够帮助开发者快速搭建和定制企业级应用。通过灵活的配置和扩展机制，开发者可以根据不同的业务需求轻松定制页面、菜单、数据结构等。
