# @eventferry/mssql-cdc-relay

> 标签: cdc, change-data-capture, event-driven, event-publishing, low-latency, microservices, mssql, nodejs, outbox, outbox-pattern, sql-server, sqlserver, transactional-outbox, typescript, waker

## 简介

SQL Server CDC-driven Waker for @eventferry/mssql (sub-second latency via Change Data Capture; requires SQL Server Agent — not available on Azure SQL Database)
