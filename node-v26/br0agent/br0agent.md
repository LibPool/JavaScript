# br0agent

> 标签: agent, ai, browser-ui, cli, coding-agent, deepseek, glm, llm, local, openai-compatible, zero-dependency

## 简介

Local coding agent with a browser UI: zero-dependency Node.js server, OpenAI-compatible backends, built-in file/shell tools, per-turn snapshots and rollback
