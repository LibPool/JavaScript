# @plurnk/plurnk-execs-common

> 标签: exec, executor, node, plurnk, python3, repl, runtime, shell, subprocess

## 简介

Universal subprocess executor for plurnk-service's exec scheme — one package exposing the shell, Node.js, Python 3, and supported host interpreters.
