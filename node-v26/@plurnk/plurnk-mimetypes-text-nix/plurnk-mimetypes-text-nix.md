# @plurnk/plurnk-mimetypes-text-nix

> 标签: JavaScript

## 简介

text/x-nix mimetype handler for plurnk-service. Tier 2: tree-sitter-nix grammar built to WASM and shipped pre-built. Covers flakes, derivations, attrsets, let-expressions, and lambdas.
