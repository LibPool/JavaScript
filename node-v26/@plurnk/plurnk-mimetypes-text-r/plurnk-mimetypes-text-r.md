# @plurnk/plurnk-mimetypes-text-r

> 标签: JavaScript

## 简介

text/x-r mimetype handler for plurnk-service. Tier 2: tree-sitter-r grammar built to WASM and shipped pre-built. Covers R 4.1+ including native pipes, lambdas, S3/S4 object systems, and tidyverse-style code.
