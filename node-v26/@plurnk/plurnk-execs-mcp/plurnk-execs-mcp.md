# @plurnk/plurnk-execs-mcp

> 标签: exec, executor, mcp, model-context-protocol, plurnk, runtime

## 简介

MCP executor bridge for plurnk-service — each configured server is an EXEC tag whose live catalog exposes its tools and input schemas.
