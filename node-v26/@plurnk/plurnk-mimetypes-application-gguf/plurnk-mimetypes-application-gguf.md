# @plurnk/plurnk-mimetypes-application-gguf

> 标签: JavaScript

## 简介

application/x-gguf (GGUF local-LLM model) mimetype handler for plurnk-service. Parses the metadata header (arch/quant/context/tokenizer) without loading weights. Hand-rolled, no parser dependency.
