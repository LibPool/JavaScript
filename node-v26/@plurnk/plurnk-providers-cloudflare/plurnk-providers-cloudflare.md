# @plurnk/plurnk-providers-cloudflare

> 标签: JavaScript

## 简介

Cloudflare Workers AI provider for plurnk-service. Routes @cf/{...} aliases through Workers AI's OpenAI-compatible relay; resolves real per-token pricing and context_window from /ai/models/search at fromEnv time.
