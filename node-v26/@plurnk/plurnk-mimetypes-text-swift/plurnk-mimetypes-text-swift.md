# @plurnk/plurnk-mimetypes-text-swift

> 标签: JavaScript

## 简介

text/x-swift mimetype handler for plurnk-service. Tier 2: tree-sitter-swift grammar built to WASM and shipped pre-built in this package. Covers Swift 6 features (macros, parameter packs, typed throws, noncopyable types, ownership modifiers).
