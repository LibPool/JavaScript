# @plurnk/plurnk-mimetypes-embeddings

> 标签: JavaScript

## 简介

Portable local/hosted embedder for @plurnk/plurnk-mimetypes' explicitly requested embedding seam. The bundled local MiniLM path uses vendored WASM with no native addon, runtime network, or transitive install scripts.
