# @plurnk/plurnk-providers-google

> 标签: JavaScript

## 简介

Google Gemini provider for plurnk-service. Routes google/{model} aliases through Gemini's OpenAI-compatible chat-completions endpoint; resolves context window from /v1beta/models at fromEnv time.
