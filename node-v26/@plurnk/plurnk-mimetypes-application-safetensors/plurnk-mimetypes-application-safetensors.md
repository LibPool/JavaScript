# @plurnk/plurnk-mimetypes-application-safetensors

> 标签: JavaScript

## 简介

application/x-safetensors (safetensors model weights) mimetype handler for plurnk-service. Reads the JSON header into a tensor inventory without loading weights. Hand-rolled, no parser dependency.
