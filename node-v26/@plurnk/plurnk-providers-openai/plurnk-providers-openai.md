# @plurnk/plurnk-providers-openai

> 标签: JavaScript

## 简介

OpenAI-compatible provider for plurnk-service. Talks to OpenAI, llama-server, Ollama (OpenAI-compat), or any other endpoint speaking the chat-completions API.
