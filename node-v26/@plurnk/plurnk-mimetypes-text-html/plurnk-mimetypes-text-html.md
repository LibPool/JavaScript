# @plurnk/plurnk-mimetypes-text-html

> 标签: JavaScript

## 简介

text/html and application/xhtml+xml mimetype handler for plurnk-service. Structural extraction via parse5; readable markdown (content channel) via Readability + an owned serializer over linkedom.
