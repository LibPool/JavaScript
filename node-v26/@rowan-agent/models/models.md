# @rowan-agent/models

> 标签: JavaScript

## 简介

Model descriptors, protocol Provider dispatch, SSE streaming, and cost calculation. The Agent Runtime uses this package through `ModelConfig` or `ModelRef + StreamFn`; it does not depend on Agent lifecycle state.
