# @anywalletkit/seed-vault

> 标签: anywalletkit, argon2id, backup, passkey, prf, seed, xchacha20-poly1305

## 简介

Encrypted backups of wallet secrets for Any Wallet Kit: a versioned, self-describing envelope (XChaCha20-Poly1305 under a random data key) that one or more protectors unlock — a password through Argon2id, or a 32-byte key from a passkey PRF, an iCloud Key
