# @dcs.labs/mcp-rseries-shim

> 标签: audit, ed25519, mcp, ml-dsa, model-context-protocol, receipts, rseries

## 简介

Auto-emit R2 v1.1 hybrid receipts (Ed25519 + ML-DSA-65) for any MCP tool call. Wrap your client, get a verifiable receipt per call.
