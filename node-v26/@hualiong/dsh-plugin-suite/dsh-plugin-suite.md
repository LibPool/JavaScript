# @hualiong/dsh-plugin-suite

> 标签: cost-lite, deepseek-harness, dsh-bundle, dsh-plugin, mcp, mcp-manager, oauth, qq-bot, qqbot, session-delete

## 简介

One installable DSH bundle with four independent plugins: the MCP Manager panel (which also drives the OAuth-enabled Streamable HTTP MCP client bridge), the Session Delete UI, the QQ bot bridge, and the per-model session cost meter.
