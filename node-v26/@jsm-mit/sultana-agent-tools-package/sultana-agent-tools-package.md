# @jsm-mit/sultana-agent-tools-package

> 标签: JavaScript

## 简介

Agent tool layer for Sultana: framework-agnostic tools over the Sultana core canister wrapper — a salon owner's set (services, promos, schedule) and a customer's set (search, free times, booking), each with a read-only set that needs no identity.
