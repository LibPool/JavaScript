# @nuasite/cms-mdx-editor

> 标签: cms, editor, mdx, milkdown, nuasite, react

## 简介

React MDX body editor (Milkdown) for Nua CMS collection entries — round-trips component blocks, props, children and imports. Consumed by collections-admin and the webmaster collections tab.
