# @qualflare/cypress

> 标签: cypress, cypress-reporter, e2e, flaky-tests, qualflare, test-reporter, test-reporting, test-results

## 简介

Native Cypress reporter for Qualflare — captures status, per-attempt retry history, screenshots, command traces and metadata.
