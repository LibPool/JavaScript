# @aviato-media/pilot-client-react

> 标签: JavaScript

## 简介

React bindings for @aviato-media/pilot-client-sdk. Provider + hooks (useAviatoPilotClient, usePilotConnection, usePilotConnections, usePairing, usePilotIdentity) backed by useSyncExternalStore over the SDK's subscribe surface.
