# @wecdev/webpack-system-operations

> 标签: attach, hook, run process, sleep, wait, wait until, webpack

## 简介

System operation collection for webpack build. You can attach any of these operations (run process, sleep, wait until) to any webpack hook with webpack-hook-attacher
