# @clipy/sdk

> 标签: ai-agent, clipy, screen-recording, sdk, transcript, webhooks

## 简介

Official TypeScript SDK for the Clipy REST API and webhooks: read recordings, transcripts, summaries and key moments, and verify webhook deliveries.
