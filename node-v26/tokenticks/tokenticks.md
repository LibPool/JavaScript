# tokenticks

> 标签: ci, cost, finops, llm, mcp, prompt, tokenizer, tokens

## 简介

Token counts and LLM cost checks for prompts in your repo: a CI linter, pull-request cost diffs, and an MCP server. Runs locally; prompts are never uploaded.
