# @equationalapplications/prisma-outbox

> 标签: at-least-once, event-sync, outbox-pattern, prisma, sqlite-sync, transactional-outbox

## 简介

Sync core-llm-wiki SQLite outbox events to your Prisma-backed database using the transactional outbox pattern — at-least-once delivery with ordering guarantees.
