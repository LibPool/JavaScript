# @razorwind/design-md

> 标签: design-md, design-tokens, dtcg, razorwind, storm-software

## 简介

Razorwind DESIGN.md plugin that can create a DESIGN.md design-system specification file from design tokens or read a DESIGN.md file and return the design-system specification.
