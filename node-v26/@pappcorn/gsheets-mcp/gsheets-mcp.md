# @pappcorn/gsheets-mcp

> 标签: claude, google-sheets, mcp, model-context-protocol, spreadsheet

## 简介

MCP server for Google Sheets — inspect, search and EDIT spreadsheets shared with you, in place, without loading them into the context. Uses your own Google OAuth app.
