# @enfexia/carbone

> 标签: document, docx, json, ods, odt, pdf, report, xslx

## 简介

Fast, Simple and Powerful report generator. Injects JSON and produces PDF, DOCX, XLSX, ODT, PPTX, ODS, ...!
