# @pieverseio/merchant-sdk

> 标签: 402, a2a, agent, hono, payments, pieverse

## 简介

Merchant-side SDK for the Pieverse A2A Commerce Protocol — accept 402-gated agent payments, create challenges, and subscribe to a durable event feed.
