# @siteonce/midnight

> 标签: clip-path, fixed-header, header, midnight.js, navigation, no-dependencies, react, scroll, solid, svelte, vanilla-js, vue

## 简介

A modern vanilla JS plugin for fixed headers that change style as you scroll through sections. Zero dependencies. Inspired by Aerolab's midnight.js.
