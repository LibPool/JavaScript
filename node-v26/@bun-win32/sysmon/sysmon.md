# @bun-win32/sysmon

> 标签: bun, cpu, etw, eventlog, ffi, memory, metrics, monitoring, pdh, process, sysmon, systeminformation, windows, wmic

## 简介

Native-speed Windows system metrics, PDH counters, Event Log tail, and a decoded real-time ETW firehose for Bun — CPU/memory/disk/process/socket data via direct FFI, no PowerShell, no wmic, no node-gyp.
