# @sfdt/plugin

> 标签: devops, oclif-plugin, salesforce, sf-plugin, sfdt

## 简介

Salesforce CLI (sf) plugin for SFDT — exposes the @sfdt/cli commands as `sf sfdt <command>`. Thin wrapper; reimplements no logic.
