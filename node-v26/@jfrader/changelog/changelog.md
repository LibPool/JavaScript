# @jfrader/changelog

> 标签: changelog, cli, frontmatter, markdown, release, release-notes, whats-new

## 简介

Zero-dependency changelog system: markdown entries, an agent-facing MD workflow, a build that emits CHANGELOG.md + JSON, and a self-contained end-user page served by a tiny backend.
