# @specwright/plugin

> 标签: ai, automation, bdd, claude, e2e, playwright, specwright, testing

## 简介

Generate, run, and auto-heal Playwright BDD tests using AI agents — drop-in plugin that explores your app, writes Gherkin feature files, and fixes failures automatically
