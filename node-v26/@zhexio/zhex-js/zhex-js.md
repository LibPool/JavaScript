# @zhexio/zhex-js

> 标签: cards, checkout, payments, pci, tokenization, zhex

## 简介

Zhex Elements — hosted card fields for PCI-safe tokenization. Mounts an iframe served by js.zhex.io and exchanges a Zhex token your server can charge.
