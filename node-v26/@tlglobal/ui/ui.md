# @tlglobal/ui

> 标签: JavaScript

## 简介

66 React components for TuringLab products — built on Radix primitives, styled with Tailwind v4, themeable via [`@tlglobal/tokens`](https://www.npmjs.com/package/@tlglobal/tokens). Ships pre-compiled JS (ESM + CJS) and hand-authored `.d.ts` types.
