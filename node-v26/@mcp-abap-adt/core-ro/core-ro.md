# @mcp-abap-adt/core-ro

> 标签: abap, adt, mcp, mcp-server, read-only, sap

## 简介

The read-only MCP server for SAP ABAP ADT over stdio: the readonly tools (with system and search) and the leftover-session list and logoff, no high, debugger, background-run or resume tool. One destination through the auth broker, as @mcp-abap-adt/core; c
