# @mcp-abap-adt/compact-sse-ro

> 标签: abap, adt, compact, mcp, mcp-server, read-only, sap, sse

## 简介

The read-only compact MCP server for SAP ABAP ADT over HTTP+SSE: the 17 compact tools that change nothing, with credentials only from the x-sap-* headers of the request that opens each SSE connection. No auth broker, no stores.
