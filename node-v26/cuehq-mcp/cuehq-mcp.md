# cuehq-mcp

> 标签: cuehq, mcp, model-context-protocol

## 简介

run the cuehq mcp server as a local command: a stdio bridge to https://www.cuehq.social/mcp for agents that start mcp servers themselves.

## 官网

- 官网：https://www.cuehq.social/agents
- npm 页面：https://www.npmjs.com/package/cuehq-mcp

- 0.0.0-stage
- 0.1.0

- npm registry：https://registry.npmjs.org/cuehq-mcp
