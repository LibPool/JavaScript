# @wanshi-kg/wanshi

> 标签: cli, entity-extraction, knowledge-graph, knowledge-graph-extraction, llm, mcp, ner, ollama, openai, provenance, rag, relation-extraction, temporal-knowledge-graph, typescript

## 简介

Local-first CLI that turns files, code, PDFs, audio and transcripts into a provenance-tracked knowledge graph — via local Ollama or any OpenAI-compatible LLM.
