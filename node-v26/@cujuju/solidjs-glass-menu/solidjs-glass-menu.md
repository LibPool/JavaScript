# @cujuju/solidjs-glass-menu

> 标签: flyout, glass, glassmorphism, menu, popover, solidjs

## 简介

Glass-surfaced menu shell for SolidJS — a header (title + action slot + close button) over a scrollable body, styled with the .glass-menu surface.
