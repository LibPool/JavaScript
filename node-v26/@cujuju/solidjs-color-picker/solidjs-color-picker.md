# @cujuju/solidjs-color-picker

> 标签: canvas, color-picker, hsv, palette, solid, solidjs, tradingview

## 简介

TradingView-style color picker for SolidJS — canvas-based HSV controls, palette grid, alpha support, EyeDropper API, zero dependencies.
