# @cujuju/solidjs-context-menu

> 标签: context-menu, flyout, glassmorphism, menu, popover, solidjs, submenu

## 简介

Cursor-positioned context menu for SolidJS — nested submenus, slider / button-row / checkbox entries, viewport clamping, top-layer popover, styled with the .glass-menu surface.
