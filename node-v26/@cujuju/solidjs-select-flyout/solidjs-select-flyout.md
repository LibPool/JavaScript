# @cujuju/solidjs-select-flyout

> 标签: accessible, combobox, dropdown, flyout, glassmorphism, listbox, select, solidjs

## 简介

Keyboard-accessible <select> replacement for SolidJS — roving focus, type-ahead, ARIA combobox/listbox, rendered through an anchored glass-menu panel so backdrop-filter actually applies.
