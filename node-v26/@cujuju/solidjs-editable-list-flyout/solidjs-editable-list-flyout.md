# @cujuju/solidjs-editable-list-flyout

> 标签: editable-list, flyout, inline-add, popover, select, solidjs

## 简介

Composed flyout primitive for SolidJS — anchored popover wrapping editable rows with built-in inline add affordance. Drop-in flyout-select with create/rename/delete.
