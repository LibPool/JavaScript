# @stigmer/embed

> 标签: ai-agents, chat-widget, embed, iframe, stigmer, web-component

## 简介

One-line script embed for shared Stigmer agents — a framework-free <stigmer-agent> web component that bootstraps the hosted chat page in an iframe
