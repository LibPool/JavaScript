# @leaperone/remote-au

> 标签: audio, audiorelay, cli, lan, loopback, miniaudio, mixer, udp

## 简介

N→1 LAN audio aggregation CLI — multiple senders capture audio, one receiver mixes and plays it back. Go + miniaudio, UDP (default) / TCP, auto-discovery.
