# @fullview/react-native-fullview-sdk

> 标签: android, cobrowsing, fullview, ios, react-native, screen-sharing, session-replay, support

## 简介

Fullview SDK for React Native: live support meetings with screen sharing and data redaction, with the native iOS and Android libraries bundled.
