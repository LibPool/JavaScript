# @leiash/cli

> 标签: cli, leia.sh, leiash

## 简介

The Leia CLI tool can be used to create custom modules for your Leia.sh cloud hosted applications but also to create a custom tailored backend for self hosting the Leia Framework. View the documentation for more information https://docs.leia.sh/cli
