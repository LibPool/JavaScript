# @mlx-bun/module-models

> 标签: JavaScript

## 简介

Model management module for mlx-bun applications: the hub and library routes, model switching, downloads and cache cleanup, adapter mounting, merge and export, the ls, get, scan, fit, gc and upload verbs, and the Models panel
