# @fabplane/cli

> 标签: bom, cli, fabplane, inventory, kicad, mcp, pcb

## 简介

Typed API client, CLI (`fabplane`) and stdio MCP server for fabplane.com, plus a client for the local fabdesk desktop daemon.

- 源码仓库：git+https://github.com/fabPlane/fabplane-cli.git
