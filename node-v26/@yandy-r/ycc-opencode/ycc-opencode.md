# @yandy-r/ycc-opencode

> 标签: experimental, opencode, opencode-plugin, ycc

## 简介

Experimental opt-in OpenCode V2 plugin registering the ycc bundle (skills, agents, commands, MCP servers, and session instructions) through its setup hook. The file-copy install remains the primary path.
