# @axorum/sandbox

> 标签: agent, axorum, ledger, policy, sandbox, testing, webassembly

## 简介

The Axorum sandbox in WebAssembly: a world's agent plane behind a fetch, a clock you move, and the reads to assert on, in Node and the browser.
