# dsh-macos-notifications

> 标签: deepseek, deepseek-harness, desktop, dsh, dsh-plugin, macos, notifications

## 简介

Six native macOS notification switches for DeepSeek Harness Desktop: approvals, questions, task completion, subtasks, errors, and turn end.
