# @orvacon/cryptokit

> 标签: iyzico, orvacon, payment-orchestration, payments, typescript

## 简介

Zero-dependency cryptographic primitives for orvacon: Ed25519 signing, HMAC-SHA256, SHA-256, HKDF, timing-safe comparison, and the signed-webhook envelope. Web Crypto only.
