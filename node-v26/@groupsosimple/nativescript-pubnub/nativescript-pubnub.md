# @groupsosimple/nativescript-pubnub

> 标签: Android, JavaScript, NativeScript, PubNub, TypeScript, iOS

## 简介

This is a Nativescript plugin wraper for the PubNub SDK. It has implementations for both Android and iOS SDKs.
