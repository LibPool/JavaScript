# @idevgames/motion-js

> 标签: ambient-motion, animation, continuous-animation, css, css-animations, css-variables, data-attribute-html, design, frontend, html, js, loading-animations, motion, performance, raf, requestAnimationFrame, simple, time-animations, time-based

## 简介

Motion.js is a global time engine for CSS-native animation. It updates time-reactive CSS variables once per second while CSS handles smooth 60fps interpolation. Outputs --motion-time, --motion-progress, --motion-loop, --motion-bounce, and --motion-noise.
