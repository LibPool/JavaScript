# @flowslens/runtime

> 标签: click-tracking, developer-tools, devtools, distributed-tracing, express, express-middleware, fastify, flowlens, flowslens, instrumentation, javascript, middleware, mongodb, mongodb-driver, mongoose, mongoose-plugin, nestjs, nextjs, nextjs-instrumentation, nodejs, nuxt, observability, performance, prisma, profiling, query-timing, react, request-tracing, spans, tracer, tracing, typescript, zero-dependency

## 简介

Zero-dependency, development-only request tracer for Node.js, Next.js, Express, NestJS, Mongoose and the MongoDB driver: links a browser click to the API calls and database queries it caused, with per-step timings.
