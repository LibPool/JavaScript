# @jadedm/nestjs-verify-redis

> 标签: ioredis, nestjs, otp, rate-limit, redis, verify

## 简介

Redis store adapter for @jadedm/nestjs-verify. Atomic rate limit, cooldown, phone-index via Lua and native TTL primitives.
