# @best-i18n/next-unprefixed-locale

> 标签: app-router, codegen, default-locale, i18n, locale, next, nextjs, static-export

## 简介

Serve the default locale unprefixed in a Next.js static export: mirrors app/[locale] into a route group that pins the locale
