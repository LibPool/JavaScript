# @gfed-medusa/sf-lib-account

> 标签: JavaScript

## 简介

This package contains all account related components, types, and other resources shared across the GFED Medusa Storefront ecosystem. It is primarily consumed by the `mf-account`, but can also be used by other frontend MFEs.
