# @deploybaseline/shopify

> 标签: JavaScript

## 简介

Shopify emulator for local development and tests: the GraphQL Admin API (2026-10) with products, inventory, customers, orders, and fulfillment, app installation over OAuth, and HMAC-signed webhooks.
