# @deploybaseline/servicenow

> 标签: JavaScript

## 简介

ServiceNow emulator for Baseline: the Table API with encoded queries, dot-walked fields, display values, and paging headers; incident, change request, and problem state rules; users, groups, and roles with ACL checks; custom `u_` tables from seed config;
