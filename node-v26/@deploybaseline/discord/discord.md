# @deploybaseline/discord

> 标签: JavaScript

## 简介

Discord emulator for local development and tests: the Bot REST API v10, the Gateway over WebSocket with intents, RESUME, and sharding, interactions with callbacks, followups, and Ed25519 signed HTTP delivery, OAuth2 with bot installs, per-route rate limit
