# @deploybaseline/jira

> 标签: JavaScript

## 简介

Jira Cloud REST API emulator: REST v3 and v2, issues, transitions, comments, watchers, changelog, JQL search, saved filters, Agile boards, sprints, backlog, rank, epics, projects, users, metadata, admin webhooks, OAuth 2.0 (3LO), app webhooks, and an insp
