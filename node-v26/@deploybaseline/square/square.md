# @deploybaseline/square

> 标签: JavaScript

## 简介

Square emulator for local development and tests: the Square API 2026-09-16 with payments (sandbox test nonces, delayed capture), refunds, orders with server-computed totals, customers, the catalog, locations, and merchants, idempotency keys, OAuth with sc
