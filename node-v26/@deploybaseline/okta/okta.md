# @deploybaseline/okta

> 标签: JavaScript

## 简介

Okta OAuth 2.0 / OpenID Connect and management API emulator for local development and tests: OIDC discovery, JWKS, OAuth authorize/token/userinfo/introspect/revoke/logout, client registration, users, groups, apps, and authorization servers.
