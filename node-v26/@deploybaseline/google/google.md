# @deploybaseline/google

> 标签: JavaScript

## 简介

Google OAuth 2.0 / OpenID Connect + Gmail, Calendar, Drive, Sheets, and Docs emulator: OAuth authorize, token exchange, userinfo, RS256 OIDC discovery and JWKS, token revocation, Gmail messages, drafts, threads, labels, history, and settings, Calendar eve
