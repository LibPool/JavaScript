# @deploybaseline/zendesk

> 标签: JavaScript

## 简介

Zendesk emulator for Baseline: the Support API v2 with tickets that follow the real status lifecycle, comments and internal notes, audits, bulk jobs, users and identities, organizations, groups, search with the Zendesk query syntax, views, triggers, signe
