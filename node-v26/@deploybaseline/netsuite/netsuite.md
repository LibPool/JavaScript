# @deploybaseline/netsuite

> 标签: JavaScript

## 简介

NetSuite emulator for SuiteTalk REST web services: the record service for customers, contacts, vendors, employees, items, transactions, and lists (with sublists, subrecords, upsert by external ID, `q` filtering, and paging), transforms and record actions,
