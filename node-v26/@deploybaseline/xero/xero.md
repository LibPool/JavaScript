# @deploybaseline/xero

> 标签: JavaScript

## 简介

Xero emulator for Baseline: the Accounting API at `/api.xro/2.0` (organisation, accounts, tax rates, contacts, items with tracked inventory, invoices, credit notes, payments, bank transactions, attachments) with Dynamic LINQ `where` filters, tenants and c
