# @boole/truncate-tokens

> 标签: anthropic, claude, gpt, llm, openai, tiktoken, tokenizer, tokens, truncate

## 简介

Truncate strings to a token budget without cutting mid-token or mid-character. Provider-agnostic with adapter support.
