# @zapier/discord-connector

> 标签: agent, ai, automation, connector, discord, mcp, skills, tools, zapier

## 简介

Agent-callable Discord tools — send and manage messages, start threads and forum posts, manage channels, members, and roles, and post via webhooks. Use when the user mentions Discord or wants to post, read, or manage Discord servers, channels, or members,
