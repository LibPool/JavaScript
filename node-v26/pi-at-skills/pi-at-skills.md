# pi-at-skills

> 标签: autocomplete, completion, mention, opencode, pi, pi-extension, pi-package, skill, skills

## 简介

opencode 风格 · 用 @ 在输入框任意位置调用 pi skill，同时保留 @ 的文件附件能力。Invoke pi skills with @ anywhere in the prompt, sharing one @ menu with file attachments.
