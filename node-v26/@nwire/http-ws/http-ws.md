# @nwire/http-ws

> 标签: nwire, transport, websocket, wire, ws

## 简介

Nwire — native WebSocket transport. wsInterface() mounts a ws.Server as a NwireServable; .on()/.broadcast()/.subscribe(action) bind JSON {type, payload} envelopes; opt-in telemetry stream for Studio Live.
