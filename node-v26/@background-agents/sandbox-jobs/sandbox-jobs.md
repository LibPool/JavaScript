# @background-agents/sandbox-jobs

> 标签: background, daytona, long-running, process, sandbox

## 简介

Run, observe, and reconnect to long-running shell processes in a Daytona sandbox via the filesystem. Byte-offset incremental reads, real exit codes, and cold-reconnect-by-id.
