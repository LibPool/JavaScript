# @otwa/mcp-server

> 标签: ai, claude, cloud, cursor, mcp, model-context-protocol, otwa, otwa.cloud, vps

## 简介

Official Model Context Protocol server for otwa.cloud — provision and manage servers from Claude Code, Claude Desktop, Cursor, Windsurf, VS Code, Zed, Continue, OpenCode and other MCP-capable AI tools.
