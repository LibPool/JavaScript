# @grip-labs/payclaw-openclaw

> 标签: agent-payments, base, openclaw, openclaw-plugin, payclaw, usdc

## 简介

PayClaw as a native OpenClaw plugin. Registers payclaw_pay / payclaw_balance / payclaw_history as OpenClaw tools, wrapping the @grip-labs/payclaw SDK so any OpenClaw agent can move USDC on Base mainnet. v0.2: true gasless via Circle Paymaster + Kernel sma
