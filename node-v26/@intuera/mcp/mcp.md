> 标签: ai-agent, claude, cro, ecommerce, intuera, mcp, model-context-protocol, shopify, woocommerce

## 简介

Intuera MCP server — gives AI coding agents role-gated, evidence-backed e-commerce recommendations from the Intuera platform, and (with consent) feeds anonymized results back for research.
