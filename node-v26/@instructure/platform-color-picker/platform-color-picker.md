# @instructure/platform-color-picker

> 标签: JavaScript

## 简介

Host-agnostic course color picker for the Canvas widget dashboard. Lets a user choose a predefined or custom hex color (and optionally edit a course nickname) and persists it to Canvas via `@instructure/platform-canvas-fetch`.
