# @mounaji_npm/logger

> 标签: logging, logscope, mounaji, observability, shipper, structured-logs

## 简介

Structured app logger with a fail-open HTTP batch shipper (LogScope ingest), opt-in console patching, secret redaction and request context via AsyncLocalStorage. Node-only, zero UI.
