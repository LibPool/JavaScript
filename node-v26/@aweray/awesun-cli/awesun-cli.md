# @aweray/awesun-cli

> 标签: JavaScript

## 简介

AweSun (向日葵) 远程控制命令行工具，支持设备管理、远程桌面控制、文件传输、端口转发、SSH 等功能的跨平台 CLI，支持Windows/macOS/Linux多平台
