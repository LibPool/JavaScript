# @hyper.authio/mcp

> 标签: authio, mcp, model-context-protocol, oauth, oidc, resource-server, rfc8693, rfc9470, rfc9728

## 简介

Protect an MCP server with Authio, on top of @hyper.authio/server: token validation, protected resource metadata (RFC 9728), WWW-Authenticate challenges with step-up, per-tool authorization and connected-account token exchange.
