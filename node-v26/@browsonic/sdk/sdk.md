# @browsonic/sdk

> 标签: apache-2, browser, browser-error-tracking, client-side-error-tracking, crash-reporting, error-tracking, exception-tracking, frontend, javascript-error-monitoring, logging, monitoring, observability, privacy-first, real-user-monitoring, rum, sdk, telemetry

## 简介

Privacy-first browser RUM and error tracking SDK. Lightweight (~33 KB core / ~54 KB full, gzipped), framework-agnostic, no PII by default.
