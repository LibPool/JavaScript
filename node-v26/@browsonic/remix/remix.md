# @browsonic/remix

> 标签: browser-error-tracking, browsonic, browsonic-remix, exception-tracking, javascript-error-monitoring, remix, remix-adapter, remix-run, rum, telemetry

## 简介

Remix adapter for @browsonic/sdk — route ErrorBoundary, action wrapper, client-entry capture. Re-exports @browsonic/react. Apache-2.0.
