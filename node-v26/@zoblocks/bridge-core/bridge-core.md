# @zoblocks/bridge-core

> 标签: ant-design, css-variables, design-tokens, healthcare, material-ui, theming

## 简介

The theme-bridge contract: how a UI framework's resolved theme becomes ZoBlocks's component token surface. No framework, no React, no DOM.
