# @zoblocks/identity-core

> 标签: accessibility, avatar, fhir, healthcare, initials, patient, patient-identification, wcag

## 简介

The identity engine behind ZoBlocks's patient avatar, chip and banner. Name resolution, deterministic swatches, script-aware initials, and the disambiguation pass that keeps two patients with one name apart — no React, no DOM.
