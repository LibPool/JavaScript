# @zoblocks/tabs-testing

> 标签: accessibility, aria, playwright, tabs, testing, testing-library, wcag

## 简介

Assertions that read the accessibility tree of a tab strip. Catches the defects a snapshot test passes: a tablist of links, a strip with no tab stop, a dangling aria-controls.
