# @wigtoken-temp/wigtoken

> 标签: anthropic, claude, claude-code, observability, prometheus, self-hosted, telemetry, token-usage

## 简介

Self-host aggregator for Claude Code token usage. Watches transcripts and exposes a real-time SSE counter, a Prometheus /metrics endpoint, and an authenticated ingestion API for distributed agents.
