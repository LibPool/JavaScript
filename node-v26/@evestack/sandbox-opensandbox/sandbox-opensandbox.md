# @evestack/sandbox-opensandbox

> 标签: agent, eve, gvisor, isolation, opensandbox, sandbox

## 简介

Run an eve agent's sandbox on a self-hosted Alibaba OpenSandbox server. Apache-2.0, reattaches across restarts.
