# @evestack/mcp

> 标签: agent, control-plane, eve, evestack, mcp, model-context-protocol, observability

## 简介

evestack's control plane as an MCP server. Ask Claude Code why last night's agent run got denied, what it cost, and turn it into a regression test — over stdio, read-only by default.
