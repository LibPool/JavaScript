# @tanstack/ai-sandbox-local-process

> 标签: agent, ai, harness, local, sandbox, tanstack

## 简介

Local-process sandbox provider for TanStack AI — runs the agent directly on the host through the uniform SandboxHandle (no isolation; trusted/dev use).
