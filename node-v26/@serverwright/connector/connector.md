# @serverwright/connector

> 标签: JavaScript

## 简介

Serverwright private connector: a small service a workspace runs on a network that can already reach its own hosts, so Serverwright can operate them without exposing them to the public internet.

## 官网

- 官网：https://serverwright.io
- npm 页面：https://www.npmjs.com/package/@serverwright/connector
