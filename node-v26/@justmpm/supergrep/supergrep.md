# @justmpm/supergrep

> 标签: ai, ast, ast-grep, claude, code-analysis, code-search, mcp, opencode, structural-search, tree-sitter

## 简介

Busca estrutural de código com AST Grep + MCP server. Encontra padrões com precisão sintática, ignorando formatação e comentários. Suporta TypeScript, JavaScript, TSX, CSS e HTML. Usável como biblioteca (executeFind/getTree) ou via MCP/CLI.
