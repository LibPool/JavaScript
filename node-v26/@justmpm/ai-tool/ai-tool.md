# @justmpm/ai-tool

> 标签: ai, claude, code-analysis, dependency-analysis, impact-analysis, javascript, opencode, skott, symbol-search, typescript

## 简介

Ferramenta de análise de código para projetos TypeScript/JavaScript. Mapa do projeto, impacto de mudanças, Cloud Functions, busca de símbolos e áreas funcionais. Usa Skott + ts-morph internamente.
