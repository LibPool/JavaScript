# @cronwatch/mcp

> 标签: agents, claude, cron, mcp, model context protocol, monitoring

## 简介

MCP server for CronWatch. Lets Claude Code, Cursor, and other agents list jobs, read failures, run a check, and silence alerts in an app that uses @cronwatch/sdk.
