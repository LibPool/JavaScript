# @cronwatch/sdk

> 标签: agents, cloudflare, cron, d1, email, heartbeat, mcp, monitoring, nextjs, pg_cron, scheduled jobs, sentry, supabase, vercel cron, workers

## 简介

Cron and scheduled-job monitoring that lives inside your app. Wrap a job, mount a route, get told when it is missed, failed, slow, or over budget. No server to run.
