# @xemahq/redis-namespace-nest

> 标签: JavaScript

## 简介

Consumer seam for redis-pool-api: resolves a service's per-(biome, org) Redis namespace, mints a short-lived ACL credential for it, and owns key construction so the enforced prefix cannot be forgotten.
