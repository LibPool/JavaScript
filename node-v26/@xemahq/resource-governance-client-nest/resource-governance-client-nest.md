# @xemahq/resource-governance-client-nest

> 标签: nestjs, outbox, resource-accounting, resource-governance, service-registry, xema

## 简介

Registry-native NestJS client for publishing resource inventory, usage, provider-cost, admission, and reconciliation records to a compatible resource-governance service.
