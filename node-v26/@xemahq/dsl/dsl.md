# @xemahq/dsl

> 标签: JavaScript

## 简介

Consolidated Xema OS DSL bundle — pure compilers/codecs for the workflow DSL, workspace-manifest DSL, deliverable-spec DSL, and the workflow payload codec. One package, per-surface subpath exports. No framework/runtime deps.
