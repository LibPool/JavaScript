# @appcat/web-sdk

> 标签: analytics, apple-search-ads, attribution, capi, conversion-tracking, conversions-api, deferred-deep-links, facebook, google-ads, meta, roas, server-side-tracking, tiktok, web-sdk

## 简介

Server-side attribution SDK for web apps. Track conversions via Meta CAPI, TikTok Events API, Google Ads, and Apple Search Ads. Works in browser and Node.js.
