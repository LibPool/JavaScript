# @zx06/tavily

> 标签: dsh, dsh-plugin, search, tavily, web-search

## 简介

Tavily web search for DeepSeek Harness: a ctx.web search provider plus tavily_search/extract/crawl/map/research tools, with a settings page for the API key, quota, and audit log
