# @nodegx/canvas-look

> 标签: JavaScript

## 简介

The NodeGX canvas look as data — category colour schemes, wire colours, card metrics, the structure lane, fonts — for a home-made editor that wants to look like NodeGX. GENERATED from the editor's CanvasTheme and token CSS (scripts/canvas-look/generate.js
