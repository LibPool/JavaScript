# @debuffjp/tenten

> 标签: aseprite, debuff, gamedev, mcp, pixel-art, sprites

## 简介

tenten: a headless, scriptable pixel-art and animation tool. Indexed sprites, frames, tags and slices drawn as text grids and ops over an MCP server, a CLI and a TypeScript API, with a text render in every result. Imports and exports .aseprite.
