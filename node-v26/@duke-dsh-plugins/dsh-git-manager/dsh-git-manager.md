# @duke-dsh-plugins/dsh-git-manager

> 标签: deepseek-harness, dsh, git, plugin, worktree

## 简介

DSH 正式 bundle 插件：在 DSH Web UI 里管理 Git 工作区——入口在输入框「模式」选择器旁（仅 git 仓库显示），进入与设置同规格的居中面板：变更暂存（hunk 级/行级/stash）、分支与 tag、交互式 rebase、提交历史（分支线图形/过滤/范围对比/revert/reset/fixup/undo）、合并冲突解决、blame/reflog、worktree 管理（行内脏状态、作用域切进 review 改动、自动注册为 DSH 工作区）、remote/config 设置，
