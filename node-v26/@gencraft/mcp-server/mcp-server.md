# @gencraft/mcp-server

> 标签: agent, ai, claude, gencraft, image-generation, mcp, model-context-protocol

## 简介

MCP server for GenCraft AI image generation. Exposes generate_image / get_task / batch_get_tasks tools to any MCP-compatible LLM agent (Claude Desktop, Cursor, Cline, …).
