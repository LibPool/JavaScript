# @allchemylabs/aether-wcag-scanner

> 标签: a11y, accessibility, axe-core, claude-code, claude-plugin, mcp, mcp-server, playwright, wcag

## 简介

WCAG 2.1 AA accessibility scanner (Playwright + axe-core) with grounded, browser-verified fixes. MCP server for Claude Code and any MCP client; also a Claude Code plugin.
