# @fietiger/joplin-mcp

> 标签: JavaScript

## 简介

这是一个基于 [Model Context Protocol (MCP)](https://modelcontextprotocol.io/) 的服务器，允许 AI 模型（如 Claude）通过 Joplin 的 Web Clipper 服务与您的 [Joplin](https://joplinapp.org/) 笔记库进行交互。
