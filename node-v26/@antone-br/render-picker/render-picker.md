# @antone-br/render-picker

> 标签: ai-coding-agent, claude-code, click-to-source, css-selector, devtools, inspector, nextjs, picker, react, react-19, sourcemap, vscode, xpath

## 简介

Dev-only Next.js toolkit: pick any element to copy its route, XPath, CSS selector, React component and source file:line (React 19 compatible, sourcemap-resolved), plus Ctrl+click to open the source in VS Code.
