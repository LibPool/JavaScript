# @skaterqiang/protege-js

> 标签: bfo, description-logic, functional-syntax, knowledge-graph, manchester-syntax, ontology, owl, owl2, owl2-rl, parser, protege, rdf, rdfs, rdfxml, reasoner, reasoning, semantic-web, serializer, swrl, turtle

## 简介

Zero-dependency OWL 2 / RDF / SWRL library for Node.js: 6 parsers, 3 serializers, and a forward-chaining reasoner covering all 78 W3C OWL 2 RL rules plus QL/EL profiles. A Node.js port of Protégé's non-UI core.
