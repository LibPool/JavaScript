# @oberhahn/sdk

> 标签: anthropic, bedrock, gemini, llm, oberhahn, observability, openai, token-usage

## 简介

Thin server-side SDK that wraps native provider SDKs, extracts token usage + attribution, and posts canonical events to OBERHAHN.
