# @uwmd/verify

> 标签: commercial-real-estate, markdown, underwriting, uwmd, verification

## 简介

The reference implementation of the UW Markdown standard — read and verify .uw.md underwriting documents: reader, validation, calc evaluator, metric dictionary, receipts, integrity, modules and the verification profiles.
