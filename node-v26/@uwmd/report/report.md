# @uwmd/report

> 标签: commercial-real-estate, credit-memo, lender-package, pdf, underwriting, uwmd

## 简介

PDF report pipeline for UW Markdown — render the lender package / credit memo HTML from @uwmd/core to PDF via headless Chromium (system Chrome/Edge through playwright-core).
