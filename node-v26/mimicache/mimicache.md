# mimicache

> 标签: as400, cache, ibm-i, ibmi, in-memory, key-value, pase, redis-compatible, resp, ttl

## 简介

MIMIC Is Merely an In-memory Cache: a small, zero-dependency, Redis-compatible in-memory cache server in pure Node.js. Built for IBM i (PASE) and anywhere else Redis can't be installed.
