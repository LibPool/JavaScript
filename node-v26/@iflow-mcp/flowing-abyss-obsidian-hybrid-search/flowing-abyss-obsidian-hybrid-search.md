# @iflow-mcp/flowing-abyss-obsidian-hybrid-search

> 标签: JavaScript

## 简介

An [MCP server](https://modelcontextprotocol.io) and CLI tool that makes your Obsidian vault queryable by AI assistants. Indexes notes into SQLite with FTS5 full-text search, trigram fuzzy matching, and `sqlite-vec` vector similarity — results are merged
