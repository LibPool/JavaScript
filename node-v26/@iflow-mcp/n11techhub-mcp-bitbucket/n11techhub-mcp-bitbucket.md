# @iflow-mcp/n11techhub-mcp-bitbucket

> 标签: ai, atlassian, bitbucket, llm, mcp, model-context-protocol, nodejs, typescript

## 简介

A Node.js/TypeScript Model Context Protocol (MCP) server for Atlassian Bitbucket Server/Data Center that enables AI systems to securely interact with Bitbucket repositories, pull requests, and code.
