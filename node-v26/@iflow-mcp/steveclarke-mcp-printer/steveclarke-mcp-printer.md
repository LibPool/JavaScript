# @iflow-mcp/steveclarke-mcp-printer

> 标签: automation, cli, cups, document, linux, llm, macos, mcp, mcp-server, model-context-protocol, pdf, printer, printing, queue

## 简介

MCP server for printing documents on macOS/Linux via CUPS. Gives AI assistants the ability to print files, manage print queues, and control printers.
