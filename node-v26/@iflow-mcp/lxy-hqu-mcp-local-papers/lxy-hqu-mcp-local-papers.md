# @iflow-mcp/lxy-hqu-mcp-local-papers

> 标签: JavaScript

## 简介

本系统基于 MCP (Model Context Protocol) 构建，提供本地 PDF 解析、结构化提取、数学公式深度解析、代码生成与可视化功能。 所有计算均在本地运行，支持通过 Trae 内置大模型或本地 LLM 进行增强。
