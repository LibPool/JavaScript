# pi-bg-shell

> 标签: background, bash, pi, pi-coding-agent, pi-extension, pi-package, shell

## 简介

Background shell tasks for the Pi coding agent: start non-blocking commands with bash_bg and get woken with the output when they exit, Claude Code style.
