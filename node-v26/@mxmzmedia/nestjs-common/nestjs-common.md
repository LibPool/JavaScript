# @mxmzmedia/nestjs-common

> 标签: JavaScript

## 简介

Example shared NestJS building blocks: health endpoints, request logging, config validation, a cloud client with a local fallback, an app bootstrap helper, and a migration runner. Built with tsc (decorator metadata).
