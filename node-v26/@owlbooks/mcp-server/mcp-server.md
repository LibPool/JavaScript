# @owlbooks/mcp-server

> 标签: accounting, ai, claude, mcp, model-context-protocol, owlbooks

## 简介

OwlBooks MCP server — exposes the v1 REST API as MCP tools (auto-generated from the OpenAPI spec). Configure in Claude Code, Claude Desktop, Cursor, Codex, or any MCP-aware client.
