# eslint-plugin-boolean-trap

> 标签: boolean, boolean-trap, code-quality, eslint, eslint-plugin, eslintplugin, readability, typescript

## 简介

ESLint rules that catch the boolean trap: positional true/false arguments and boolean parameters that make call sites unreadable.
