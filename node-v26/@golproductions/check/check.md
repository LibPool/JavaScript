# @golproductions/check

> 标签: ai-agents, ai-coding-agent, ai-hallucination, ai-safety, anti-hallucination, claude-code, developer-tools

## 简介

Anti-hallucination layer for Claude Code: before a command or file write runs, your own machine checks it, and what it proves missing is blocked.
