# @seam-media/cli

> 标签: ffmpeg-free, render, seam, video, video-editor, webgpu

## 简介

Seam Video — a flowing video editor where edits are defined as JSON (.seam files). CLI for rendering .seam files to mp4 and resolving timelines.
