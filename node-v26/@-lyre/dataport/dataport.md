# @~lyre/dataport

> 标签: csv, data, etl, export, import, lyre, streaming

## 简介

Framework-agnostic streaming import/export engine for Node. Owns data-flow (parse → map → validate → batch → sink; source → format → stream); the host owns persistence via thin Sink/Source adapters. CSV in/out, per-row error reporting, bounded batching. A
