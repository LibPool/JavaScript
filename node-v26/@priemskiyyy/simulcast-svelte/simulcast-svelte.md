# @priemskiyyy/simulcast-svelte

> 标签: pubsub, real-time, realtime, runes, simulcast, ssr, subscriptions, svelte, svelte5, typed-events, typescript, websocket

## 简介

Svelte bindings for simulcast: a provider component that owns the realtime session and rune-based utilities for shared channel subscriptions, typed events, channel status, and connection state.
