# @priemskiyyy/flare-posthog

> 标签: adapter, error-reporting, error-tracking, flare, posthog, typescript

## 简介

PostHog error tracking destination for flare in the browser: each report is one $exception event with its own properties and exception steps, sent only while PostHog identifies the report's user, over the posthog-js instance you inject.
