# @priemskiyyy/flare-datadog

> 标签: adapter, datadog, error-reporting, error-tracking, flare, rum, typescript

## 简介

Datadog RUM destination for flare in the browser: each exception is one RUM error carrying the report's own attributes under context.flare, sent only while RUM attaches the report's user, over the datadogRum you inject.
