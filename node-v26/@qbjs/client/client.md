# @qbjs/client

> 标签: api, drizzle, drizzle-orm, filter, hono, mysql, orm, pagination, postgresql, query-builder, query-string, query-utility, rest-api, sort, sqlite, typescript

## 简介

A lightweight utility, zero-dependency client-side query builder for @qbjs/core. Build clean, type-safe filters, pagination, sorting, and search queries without boilerplate.
