# @packet-net/ax25

> 标签: amateur-radio, ax25, ham-radio, kiss, packet-radio, tnc, web-serial

## 简介

Browser-targeted TypeScript library for AX.25 v2.2 connected-mode sessions over Web Serial KISS modems.
