# @xpufx/paseo-x-comms

> 标签: agent, cross-daemon, daemon, e2ee, mcp, paseo, plugin, relay

## 简介

Cross-daemon agent conversation over Paseo Relay: a Paseo plugin that bundles the MCP server so agents on one daemon can talk to agents on another (relay offer or direct host).
