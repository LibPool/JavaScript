# react-native-better-pdf

> 标签: expo, nitro, pdf, pdf-viewer, pdfkit, pdfrenderer, react-native

## 简介

A native, virtualized PDF viewer for React Native built on Nitro Views. PDFKit on iOS, PdfRenderer on Android, zero JS in the scroll/zoom/render path.
