# dsh-image-lite

> 标签: cordis, deepseek, deepseek-harness, dsh, dsh-plugin, image-generation, plugin

## 简介

DSH 生图插件支持双模式生图：直接对话大模型，通过 image_generate_lite 工具生图；或在侧边栏「生图工作台」处理生图任务。
