# @vfvrpq/photo-route-map

> 标签: exif, gps, html-generator, map, maplibre, photo, route, tianditu, timeline

## 简介

Turn a directory of GPS-tagged JPEG photos into an openable light-theme route-map web page (timeline, popups, AOI overlay). Zero runtime dependencies, plain Node >= 18.
