# @vefimov/pdf-anchor

> 标签: citations, highlight, pdf, pdf-viewer, react, react-pdf, text-matching

## 简介

Highlight citations inside a PDF and jump between them. React viewer built on react-pdf, plus a framework-agnostic core.
