# @tlawat/mushaf-fonts-qpc-v4-tajweed

> 标签: fonts, kfgqpc, mushaf, qul, quran, remotion

## 简介

QUL's KFGQPC V4 colour (COLR/CPAL tajweed) page fonts, used by every theme except 'plain', unmodified. The fallback (or offline) font source of @tlawat/remotion-mushaf-line; bundled as assets when imported.
