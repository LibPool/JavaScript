# @tlawat/mushaf-fonts-qpc-v4

> 标签: fonts, kfgqpc, mushaf, qul, quran, remotion

## 简介

QUL's KFGQPC V4 monochrome (plain) page fonts: glyph outlines that follow CSS color, used by the 'plain' theme, unmodified. The fallback (or offline) font source of @tlawat/remotion-mushaf-line; bundled as assets when imported.
