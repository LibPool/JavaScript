# magnetkit

> 标签: android, gesture, magnet, magnetic ui, magnetometer, physics, react

## 简介

Magnetic UI for React on the web: a real magnet near an Android phone pulls your interface, through the Magnet Bridge app that runs the magnet model on the phone.
