# flare-forge-cli

> 标签: agents, artifacts, ci, claude-code, cloudflare, codex, cursor, forge, git, mcp

## 简介

CLI for Flare Forge (intent-native git for many agents on one repo) and Flare Actions (its CI engine): declare intents, connect agents over MCP, verify runs, read digests.
