# @adea-ai/catalog-schema

> 标签: agents, catalog, marketplace, mcp, plugins, schema, skills, zod

## 简介

Deterministic catalog schema for AI agent plugin marketplaces: plugins, capabilities, releases, provenance, licensing, security classification, and per-harness compatibility.
