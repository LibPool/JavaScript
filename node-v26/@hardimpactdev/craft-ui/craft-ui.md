# @hardimpactdev/craft-ui

> 标签: charts, components, inertia, kanban, laravel, reka-ui, shadcn-vue, tailwindcss, typescript, ui, vue, vue3

## 简介

A Vue 3 component library for building clean, calm user interfaces. Built on Reka UI and shadcn-vue with layout, navigation, kanban, and chart components.
