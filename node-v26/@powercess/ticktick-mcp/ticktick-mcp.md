# @powercess/ticktick-mcp

> 标签: dida365, mcp, model-context-protocol, reverse-engineering, task-management, ticktick, todo

## 简介

MCP server for TickTick (ticktick.com / dida365.com) built on the private web API — the same endpoints the web app calls, with cookie auth and full read/write task, project, tag, habit and calendar coverage.
