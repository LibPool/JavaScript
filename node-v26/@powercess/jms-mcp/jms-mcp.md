# @powercess/jms-mcp

> 标签: JavaScript

## 简介

JumpServer MCP server - query and operate JumpServer-managed assets via MCP (stdio). 924 tools auto-generated from the JumpServer API. Supports Access Key (HTTP Signature) and Bearer auth.
