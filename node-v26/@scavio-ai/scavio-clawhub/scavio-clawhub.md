# @scavio-ai/scavio-clawhub

> 标签: clawhub, mcp, openclaw, structured-data, web-scraping, web-search

## 简介

Structured web data for OpenClaw agents across 31 platforms with one API key - search, extraction, commerce, social, travel, jobs, real-estate, app stores, software reviews, ad libraries and company filings.
