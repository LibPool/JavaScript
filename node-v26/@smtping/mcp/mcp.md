# @smtping/mcp

> 标签: claude, cursor, email validation, email verification, mcp, mcp server, model context protocol, smtping

## 简介

Official SMTPing MCP server: let Claude, Cursor, VS Code and other AI assistants verify email addresses, clean lists and check spamtrap, disposable, spambot and complainer lists.
