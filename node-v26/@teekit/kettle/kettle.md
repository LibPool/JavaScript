# @teekit/kettle

> 标签: JavaScript

## 简介

@teekit/kettle is a simple workerd-based JS runtime for confidential workers. It provides to JS dependencies required for @teekit/tunnel, quote generation, and sqlite (via libsql/sqld, optionally encrypted).
