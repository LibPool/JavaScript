# bootstrap-css-only

> 标签: JavaScript

## 简介

[Bootstrap](http://getbootstrap.com/) CSS and font libraries only. No javascript, and more importantly NO depenedency on jQuery.

## 官网

- 官网：http://getbootstrap.com
- 源码仓库：git+https://github.com/fyockm/bootstrap-css-only.git
- npm 页面：https://www.npmjs.com/package/bootstrap-css-only
