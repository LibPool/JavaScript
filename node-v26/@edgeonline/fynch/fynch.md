# @edgeonline/fynch

> 标签: analytics, conversion-tracking, datalayer, event-tracking, google-tag-manager, gtm

## 简介

Client-side event tracking library for GTM integrators — listens for form, click, scroll, booking, and chat interactions and pushes them to the dataLayer.
