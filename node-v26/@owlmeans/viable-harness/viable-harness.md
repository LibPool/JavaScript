# @owlmeans/viable-harness

> 标签: JavaScript

## 简介

Set a coding agent (Claude Code, Codex, Copilot, OpenCode) up to work with the OwlMeans Viable platform: its instruction section, its worker subagent, its MCP entry — and the describe_harness / install_harness connector tools.
