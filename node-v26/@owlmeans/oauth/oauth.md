# @owlmeans/oauth

> 标签: JavaScript

## 简介

Shared OAuth 2.1 contracts for OwlMeans authorization servers and clients — device authorization, authorization code + PKCE, protected-resource and authorization-server metadata, Client ID Metadata Documents, the shared consent flow, and runtime-agnostic
