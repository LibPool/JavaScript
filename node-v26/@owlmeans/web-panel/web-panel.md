# @owlmeans/web-panel

> 标签: JavaScript

## 简介

shadcn UI + Tailwind v4 implementation of the OwlMeans web panel layer. Wraps the headless `@owlmeans/client-panel` logic with shadcn primitives instead of Material UI.
