# mot3r

> 标签: agents, claude-code, claude-desktop, cursor, mcp, model-context-protocol, mot, vscode

## 简介

Installer and stdio bridge for the mot gateway. Wires the mot MCP endpoint into Claude Code, Claude Desktop, Cursor and VS Code. No dependencies.
