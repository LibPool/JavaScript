# @bkm016/calcite

> 标签: agent, client, headless, headlessmc, mcp, minecraft, testing

## 简介

Drive a real Minecraft Java client from code or AI agents: launch, join servers, read client-side entities, chat, run commands and take screenshots. Ships a CLI and an MCP server.
