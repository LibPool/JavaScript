# @vohlsyr/plugin-trading-strategy-data

> 标签: backtest, crypto, elizaos, elizaos-plugins, trading, x402

## 简介

ElizaOS plugin for Trading Strategy Data: backtestable crypto trend signals and on-demand backtesting for BTC/ETH/SOL/XRP/ADA, paid per call via x402 (USDC on Base).
