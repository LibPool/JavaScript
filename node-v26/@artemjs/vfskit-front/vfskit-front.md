# @artemjs/vfskit-front

> 标签: abstraction, browser, encryption, filesystem, fs, jsdelivr, remote, storage, vfs, virtual-file-system

## 简介

Universal VFS abstraction for the browser - in-memory + encryption + a remote client that drives any vfskit backend. Frontend kit, served via jsDelivr.
