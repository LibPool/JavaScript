# @openuidev/angular-lang

> 标签: ai, angular, components, generative-ui, llm, model-driven-ui, openui, openui-lang, parser, prompt-generation, renderer, streaming, ui-generation, zod

## 简介

Angular bindings for OpenUI Lang. Define model-renderable Angular components, generate prompts from those definitions, and render OpenUI Lang in Angular applications.
