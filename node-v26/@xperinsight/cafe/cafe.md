# @xperinsight/cafe

> 标签: JavaScript

## 简介

`cafe` 是一个 macOS 防休眠 CLI。它基于系统自带的 `caffeinate`，可选通过 `pmset` 支持合盖也不休眠，并在电量低于阈值时自动停止防休眠、恢复系统设置。在经过验证的 Apple Silicon 机型上，运行界面还会显示芯片温度和风扇转速，并允许临时启用温控散热。
