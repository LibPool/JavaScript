# @t-2/accessibility

> 标签: a11y, accessibility, contrast, dyslexia, grayscale, inclusive, reduce-motion, wcag, widget

## 简介

Framework-agnostic accessibility widget: black & white, reduce motion, readable typography, reading aids, presets, persistence and i18n. Zero runtime dependencies.
