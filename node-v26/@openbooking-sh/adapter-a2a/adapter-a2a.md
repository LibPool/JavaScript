# @openbooking-sh/adapter-a2a

> 标签: a2a, agent2agent, ai-agents, appointments, booking, mcp, model-context-protocol, openbooking, scheduling

## 简介

A2A (Agent2Agent) Agent Card generation for OpenBooking. SendMessage endpoint routing to the same booking engine as MCP and UCP.
