# @varman96/paper

> 标签: ai-coding, claude-code, cli, codex, coding-agents, cursor, debugging, developer-tools, error-logs, incident-report, terminal

## 简介

Paper captures command failures locally in a structured Incident Report for coding-agent investigation. Local-first. No telemetry.
