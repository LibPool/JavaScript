# @plantgeekz_com/botanical-name

> 标签: botanical, botany, cultivar, gardening, icn, icncp, nomenclature, parser, plant, plants, scientific-name, taxonomy

## 简介

Parse, normalize and format botanical plant names (ICN + ICNCP): hybrids, infraspecific ranks, authors, cultivars, groups and correct italics. Zero dependencies, runs in Node and the browser.
