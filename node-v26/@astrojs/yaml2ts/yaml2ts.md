# @astrojs/yaml2ts

> 标签: JavaScript

## 简介

Package to convert a YAML string to a Volar VirtualCode, to be used by the Astro language server to provide intellisense

## 官网

- 源码仓库：git+https://github.com/withastro/astro.git
