# @aprovan/sandbox-host

> 标签: aprovan, executor, sandbox, utdk

## 简介

Run Aprovan sandboxes on a machine you own: the @utdk/sandbox driver for registered machines, plus the executor and agent that serve them

## 官网

- npm 页面：https://www.npmjs.com/package/@aprovan/sandbox-host

- Node 要求：>=20.0.0
