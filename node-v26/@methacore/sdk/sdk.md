# @methacore/sdk

> 标签: artim, methacore, oauth, pkce, sdk

## 简介

SDK für externe Methacore-Apps (eigene Domain, eigenes Hosting): OAuth (PKCE), Host-Bridge, API-Client, App-Speicher und Exporte.
