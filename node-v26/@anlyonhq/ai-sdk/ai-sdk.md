# @anlyonhq/ai-sdk

> 标签: agent-actions, agent-tools, ai, ai-sdk, anlyon, approvals, human-in-the-loop, llm, vercel-ai-sdk

## 简介

Vercel AI SDK integration for Anlyon: expose hosted actions as tools the model can call without holding a credential, and wait for human approval inside the turn.
