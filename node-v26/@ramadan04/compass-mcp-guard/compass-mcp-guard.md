# @ramadan04/compass-mcp-guard

> 标签: ai-agent, crypto, execution-firewall, guardrail, mcp, policy-engine, security, solana, wallet

## 简介

Execution firewall for AI agents on Solana. MCP proxy that validates, simulates, approves and audits every sensitive on-chain action before an AI agent can execute it.
