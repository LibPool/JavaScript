# @ever-works/everworks-playbooks-plugin

> 标签: JavaScript

## 简介

Ever Works Playbooks — first-party playbook-provider plugin supplying the built-in Playbook catalogue: packaged outcomes with their trigger, steps, required capabilities, artefacts and escalation points.
