# @kongyo2/kongyoroid

> 标签: agent, cli, formant, japanese, jpreprocess, kongyo2, llm, mml, singing, singing-synthesis, speech, streaming, text-to-speech, tts, voicevox

## 简介

Japanese speech and singing synthesis for LLM agents: a JSON-first CLI and typed library with a built-in deterministic formant engine, a dictionary-backed Japanese text frontend (jpreprocess), streaming output, and an optional VOICEVOX ENGINE adapter.
