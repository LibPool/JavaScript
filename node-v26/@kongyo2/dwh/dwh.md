# @kongyo2/dwh

> 标签: agent, ai, artifacts, claude-code, cli, coding-agents, discord, file-transfer, webhook

## 简介

Deliver files from a coding agent to a human over a Discord webhook. Files only — no messages, and rate limits are waited out, never surfaced.
