# @greymoth/jp-readiness-mcp

> 标签: ai-agent, compliance, i18n, invoice, japan, japan-readiness, mcp, model-context-protocol, tokushoho

## 简介

MCP server that lets an AI coding agent check a site or text for Japan-readiness: 特商法 disclosure, インボイス T-number, CJK typesetting, JP payments, hreflang, IME. Deterministic, no model calls.
