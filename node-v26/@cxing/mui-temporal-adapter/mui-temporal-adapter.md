# @cxing/mui-temporal-adapter

> 标签: date-adapter, date-picker, material-ui, mui, temporal, x-date-pickers

## 简介

A Temporal-API-backed dateAdapter for @mui/x-date-pickers, with on-demand polyfill fallbacks for browsers lacking native Temporal or locale week-info support.
