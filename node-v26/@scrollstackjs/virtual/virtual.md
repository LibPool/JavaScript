# @scrollstackjs/virtual

> 标签: dynamic-height, framework-agnostic, headless, infinite-scroll, list-virtualization, resize-observer, scrollstack, ssr, typescript, virtual-list, virtual-scroll, virtualization, virtualized-list, windowing

## 简介

Headless list virtualization for ScrollStack — render 50 rows out of 50,000, with dynamic measurement, window scrolling and an infinite-scroll bridge. Framework-agnostic.
