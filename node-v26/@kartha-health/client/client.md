# @kartha-health/client

> 标签: JavaScript

## 简介

Safe clinical-access layer for Kartha Health: cloud-agnostic MCP-JWT signing, Streamable-HTTP MCP client, guardrail executor, observation digest, deterministic temporal windowing.
