# @pwguler/pi-pengepul-provider

> 标签: pengepul, pi, pi-extension, pi-package, pi-pengepul-provider, provider

## 简介

pi custom provider for pengepul, a relay that pools your Claude/Codex subscriptions. Key and relay base live in auth.json; both native wires (Anthropic Messages, OpenAI Chat Completions) come from one catalog.
