# perigee-mcp

> 标签: astronomy, education, mcp, model-context-protocol, satellites, space

## 简介

MCP server for Perigee: positions, distances, mission facts and embeddable 3D views of the objects orbiting the Earth, the Moon, Mars and the Sun, with provenance and accuracy, for AI teaching assistants.
