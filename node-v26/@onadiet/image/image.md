# @onadiet/image

> 标签: avif, compress-image, image-compression, jpeg, local, no-upload, onadiet, optimize-image, png, sharp, shrink-image, webp

## 简介

onadiet image adapter: detect · weigh · slim standalone images (JPEG/PNG/WebP/AVIF) by re-encoding, downscaling, and optional format-switch (sharp/libvips). Permissive-only.
