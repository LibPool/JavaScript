# @aotter/mantle-auth

> 标签: JavaScript

## 简介

Optional Better Auth identity for Mantle: staff roles, email OTP, social sign-in, and the OAuth 2.1 / MCP authorization surface, over a SQLite-shaped DatabaseDriver wrapping the same store Better Auth uses.
