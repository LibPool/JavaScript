# safe-to-json

> 标签: browser, circular, circular-reference, cloudflare-workers, edge, error-cause, error-reporting, error-serializer, error-to-json, esm, json, json-stringify-safe, logging, max-depth, node, observability, safe-stringify, safe-to-json, serialize, serialize-error, serializer, stringify, structured-logging, telemetry, truncate, typescript, workerd, zero-dependency

## 简介

Safely serialize any value to plain JSON: handles circular references, serializes Error (name, message, stack, cause), truncates long strings and large arrays. Zero dependencies, works in Cloudflare Workers, browsers and Node.
