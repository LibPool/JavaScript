# @open-music-sdk/developer-token

> 标签: apple-music, apple-music-api, developer-token, es256, jose, jwt, musickit, sdk, typescript

## 简介

Developer tokens for the Apple Music API: sign one with jose, or get a provider that mints or fetches them and keeps them fresh.
