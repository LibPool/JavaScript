# @open-music-sdk/browser

> 标签: apple-music, apple-music-api, browser, musickit, player, preview, sdk, sign-in, typescript

## 简介

The Apple Music API for a page: a client that fetches its developer token from your server, with the catalog, the library and the playlist verbs on it, Apple's sign-in run for you, the preview player, and the rest of the family from one import. No signing
