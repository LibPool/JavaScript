# @wdk-starter/wdk-protocol-eip3009

> 标签: bare, eip-3009, eip3009, ethereum, evm, gasless, meta-transaction, protocol, receiveWithAuthorization, stablecoin, transferWithAuthorization, usdc, usdt, wdk

## 简介

A WDK protocol module that lets @tetherto/wdk-wallet-evm accounts create and submit EIP-3009 (transferWithAuthorization) gasless, signature-based stablecoin transfers — for USDt, USDC and any EIP-3009 token.
