# @syntaxsmith/rosetta

> 标签: automation, cdp, chatgpt, chatgpt-pro, claude-code, codex, mcp, model-context-protocol, openai, puppeteer, sse, websocket

## 简介

Programmatic access to ChatGPT Pro by translating between the auth-holder Chrome page and a Node API. Hijacks /backend-api/f/conversation via CDP Fetch.requestPaused, follows the WS second leg for Pro CoT, returns aggregated text + supports multi-turn / r
