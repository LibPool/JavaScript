# @antv/context

> 标签: antv, context, embedding, huggingface, semantic-search, transformers, vector, zvec

## 简介

A local context retrieval library that enables semantic search over your documentation. It loads documents (Markdown, JSON, Text), vectorizes them using [Transformers.js](https://huggingface.co/transformers.js), and stores vectors locally in `.zvec` files
