# dsh-model-doctor

> 标签: balance, connectivity, deepseek, deepseek-harness, dsh, dsh-plugin, model-selector, ui

## 简介

模型医生：在对话输入区的模型选择菜单里，为每个模型选项追加「连通检测」与「删除」按钮——直接适配 DSH 官方模型菜单（按官方 DOM 契约精确定位，不依赖任何菜单渲染插件），检测直连各网关探测连通性/欠费/额度，删除直接从 llm-pi-ai 配置移除模型（自动备份配置文档）。
