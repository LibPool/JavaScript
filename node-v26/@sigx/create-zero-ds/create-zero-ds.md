# @sigx/create-zero-ds

> 标签: SignalX, create, design-system, scaffold, sigx

## 简介

Scaffold a SignalX Zero design system from a style brief — `pnpm create @sigx/zero-ds <name> --brief <id>` lays down the package with @sigx/zero-basic's recipes as the baseline, fitted to the brief's vocabulary.
