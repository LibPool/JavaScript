# @sigx/richtext-markdown

> 标签: commonmark, editor, gfm, markdown, mdast, richtext, signalx, sigx, streaming

## 简介

Markdown for @sigx/richtext — a CommonMark + GFM parser that keeps finalized blocks stable while text streams in, a serializer, the markdown DocumentFormat and the editor preset
