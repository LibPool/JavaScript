# @sigx/markdown

> 标签: commonmark, editor, gfm, markdown, mdast, signalx, sigx, streaming

## 简介

Markdown for SignalX — an mdast-compatible incremental parser that keeps finalized blocks stable while text streams in, a serializer, a renderer-neutral engine with a DOM view, and a block-tree editor
