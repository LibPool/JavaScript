# @sigx/zero-daisyui

> 标签: JavaScript

## 简介

DaisyUI-flavored design system for SignalX Zero — daisy's token values and component look as a pure tokens+recipes skin over @sigx/zero primitives. No Tailwind, no daisyUI plugin required.
