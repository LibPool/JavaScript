# @pashoo2/crypto-utilities

> 标签: crypto key, crypto key export, crypto key import, crypto key parsing, crypto key serialization, crypto utilities, data decryption, data encryption, data signing, data verification, decryption, encryption, nodejs crypto, password, password encryption, password with salt, sign, typescript, typescript crypto, verify, web crypto

## 简介

Utilities for a data signing and verification, encryption and decryption, a password generation with a salt, crypto keys generation, serialization, parsing of them. Written in Typescript both for a browser and NodeJS.
