# @dreyv/x402-client

> 标签: agentic-payments, agents, ai-agents, cloudflare, dreyv, http-402, payments, solana, stablecoin, usdc, x402

## 简介

Drop-in buyer SDK for x402 (HTTP 402 Payment Required). Give any agent a wallet, a budget, and an audit trail — pay any x402-protected URL on the open web via a Dreyv prepaid balance or custodial Solana wallet.
