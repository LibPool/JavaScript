# @alistigo/artifact-list

> 标签: alistigo, claude, embed, list, react, umd, widget

## 简介

Self-contained UMD bundle of the Alistigo list widget — for Claude HTML artifacts and standalone pages. Includes React, Lingui, and all Alistigo packages; no external dependencies required.
