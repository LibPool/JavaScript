# dsh-dotclaude

> 标签: claude, claude-code, cordis, deepseek-harness, dotclaude, dsh, dsh-plugin, permissions, slash-commands

## 简介

Run a Claude Code project's .claude/ assets inside DeepSeek Harness: project slash commands with argument expansion, and permissions.deny enforcement. No host patches, silent when absent.
