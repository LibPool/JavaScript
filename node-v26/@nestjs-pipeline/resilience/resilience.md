# @nestjs-pipeline/resilience

> 标签: bulkhead, circuit-breaker, cockatiel, cqrs, fallback, fault-tolerance, nestjs, pipeline, resilience, retry, timeout

## 简介

Resilience for @nestjs-pipeline/core, powered by cockatiel — named policies shared by outbound adapters (retry, circuit breaker, timeout, bulkhead, fallback) and a behavior for handler-level retry, timeout and bulkhead.
