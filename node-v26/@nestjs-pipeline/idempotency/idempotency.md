# @nestjs-pipeline/idempotency

> 标签: behavior, cqrs, deduplication, idempotency, idempotent, nestjs, pipeline, retry-safe

## 简介

Idempotency behavior for the NestJS pipeline — atomically excludes concurrent duplicates and replays stored successful responses per idempotency key, via a pluggable store (in-memory default, Redis/Postgres drop-in).
