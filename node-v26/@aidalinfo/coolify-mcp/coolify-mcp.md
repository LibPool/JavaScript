# @aidalinfo/coolify-mcp

> 标签: coolify, deployment, infrastructure, mcp, model-context-protocol

## 简介

MCP server for Coolify (fork of @masonator/coolify-mcp) — adds docker_compose_location updates, pre/post deployment commands, and server SSH key retrieval
