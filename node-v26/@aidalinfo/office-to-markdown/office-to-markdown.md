> 标签: bun, document-conversion, document-processing, docx, docx-to-markdown, latex, mammoth, markdown, math-equations, office, office-to-markdown, omml, table-conversion, turndown, typescript

## 简介

Modern TypeScript library for converting Office documents (DOCX) to Markdown format, optimized for Bun runtime with enhanced table support and math equation conversion.
