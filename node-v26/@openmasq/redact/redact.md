# @openmasq/redact

> 标签: anonymization, anthropic, data-masking, dlp, gdpr, llm, llm-security, ner, openai, pii, pii-detection, pii-redaction, presidio, presidio-alternative, privacy, prompt, pseudonymization, redaction

## 简介

Reversible PII redaction for LLM prompts: detect sensitive data, replace it with realistic fakes, restore the reply from a vault. Offline, TypeScript.
