# @aeunius/peru-rules

> 标签: cci, dni, peru, ruc, sunat, validacion, validation, vue

## 简介

Validación de documentos y datos peruanos en JavaScript: RUC, DNI, carné de extranjería, pasaporte, celular, placa vehicular y CCI, con reglas para formularios de Vue.
