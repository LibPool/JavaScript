# @kabeep/node-steam-library

> 标签: library, nodejs, registry, steam, typescript, valve, vdf, windows

## 简介

Obtain the installation directory and application list of Steam through the Windows registry.

## 获取地址

- npm 安装：`npm install @kabeep/node-steam-library`
- npm registry：https://registry.npmjs.org/@kabeep/node-steam-library
- Node 要求：>=18
