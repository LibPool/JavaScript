# @swiftimg/cli

> 标签: cdn, cli, cloudflare, gif, image-cdn, image-hosting, screenshot, sharex, swiftimg, upload, webp

## 简介

CLI and zero-dependency client for swiftimg — fast image & GIF hosting and an image CDN/API on Cloudflare.
