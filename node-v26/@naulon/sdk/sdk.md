# @naulon/sdk

> 标签: ai-crawler, citation, content-licensing, micropayments, naulon, paywall, rsl, stablecoin, usdc, x402

## 简介

The naulon publisher contract: credits + settlement wire types, validators, HMAC sign/verify, and credits resolvers. One source of truth for the money-routing trust boundary.
