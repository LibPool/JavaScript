# @guveno/cli

> 标签: bitcoin, cli, crypto, custody, ethereum, guveno, hd-wallet, wallet

## 简介

Command-line tool for managing Guveno custody wallets and server resources — create wallets, sign withdrawals, and drive the Guveno API from your terminal.
