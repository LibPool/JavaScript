# dsh-ui-picker

> 标签: ai, code-agent, css-selector, deepseek, deepseek-harness, devtools, dom-inspector, dsh, dsh-plugin, element-inspector, element-picker, frontend, llm, react, ui-inspector, ui-picker, vue, web-development, xpath

## 简介

点选前端页面上的任意 UI 控件，自动把控件详情（标签/CSS 选择器/XPath/组件名/样式）写入 DeepSeek Harness 输入框，让 AI 精准定位要改的界面元素。
