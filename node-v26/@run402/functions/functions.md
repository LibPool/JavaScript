# @run402/functions

> 标签: ai-agent, in-function-helpers, lambda, run402, serverless

## 简介

In-function helper library for Run402 serverless functions - db, adminDb, auth, email, ai, assets, verifyWebhook. Auto-bundled into deployed functions; also installable for local TypeScript autocomplete.
