# @zhiji-labs/vite-plugin-sourcemaps

> 标签: error-monitoring, observability, sourcemap, vite

## 简介

Vite build plugin for uploading private Source Maps to Zhiji. It removes `sourcesContent`, uploads maps with a dedicated `sourcemap_upload` key, and removes every `.map` file from the public output bundle after successful upload.
