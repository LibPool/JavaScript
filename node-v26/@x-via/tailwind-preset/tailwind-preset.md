# @x-via/tailwind-preset

> 标签: JavaScript

## 简介

Preset Tailwind + theme.css com a identidade X-VIA (escalas azul/verde/amarelo/vermelho/neutro, tokens shadcn, radius/tipografia). Sequestra as variáveis do shadcn.
