# @cra-agent/ledger

> 标签: agent-payments, ai-agents, arc, audit-log, circle, ledger, micropayments, postgres, receipts, usdc, x402

## 简介

Append-only payment ledger for agent payments: every quote, rejection, signature, settlement and failure. In-memory or Postgres.
