# @richkitjs/core

> 标签: block-editor, contenteditable, document-editor, editor, extensible, framework-agnostic, headless, headless-editor, html, json, notion-like, prosemirror, rich-text, rich-text-editor, richkit, text-editor, typescript, wysiwyg

## 简介

Headless, framework-agnostic rich text editor built on ProseMirror. Extension API, schema builder, chainable commands, HTML/JSON I/O and autosave. 64 KB gzipped.
