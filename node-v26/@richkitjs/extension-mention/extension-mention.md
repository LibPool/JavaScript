# @richkitjs/extension-mention

> 标签: at-mention, autocomplete, editor, mention, mentions, prosemirror, rich-text, rich-text-editor, richkit, richkit-extension, text-editor, wysiwyg

## 简介

@mentions for RichKit: an inline mention node for users or pages, fed by your own list. No directory or network calls built in.
