# @scriptonita/chess-football-ui

> 标签: JavaScript

## 简介

Shared, framework-agnostic React UI for Chess.Football: board, pieces, scoreboard, controls and the game store. Consumed by the Next.js app and the CrazyGames Vite SPA.
