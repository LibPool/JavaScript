# @dev-dga/tokens

> 标签: colors, css-variables, design-system, design-tokens, dga, gov, government, ksa, platforms-code, saudi, saudi-arabia, saudi-design-system, sdga, sdga-platforms-code, spacing, tailwind, tailwind-preset, tokens, typography, ui-library

## 简介

Design tokens for Saudi Arabia's DGA (Digital Government Authority) Platforms Code design system, an independent implementation. Colors, typography, spacing, radius, and shadows as typed TypeScript objects. Not affiliated with the DGA.
