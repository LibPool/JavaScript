# @zerowidth/shims-sdk

> 标签: browser, calibration, classifier, embeddings, few-shot, intent, local-first, on-device, routing, shim, shims, text-classification, transformers.js, zerowidth

## 简介

Shims: tiny decision models that run in the client — one shared encoder, a few KB per decision, a gate that knows when not to answer. Runtime, compiler and CLI.
