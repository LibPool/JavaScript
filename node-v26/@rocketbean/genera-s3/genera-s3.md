# @rocketbean/genera-s3

> 标签: aws, backblaze, driver, genera, minio, r2, s3, spaces, storage, wasabi

## 简介

S3-compatible storage driver for Genera — one driver for AWS S3, Cloudflare R2, DigitalOcean Spaces, Backblaze B2, Wasabi, MinIO, and IDrive e2.
