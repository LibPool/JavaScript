# @redrossa/pi-model-router

> 标签: ai, jev, llm, model-router, pi, pi-extension, pi-package, typesafe

## 简介

Pi extension that classifies each prompt with TypeSafe's Jev and routes it to the model you're logged into that best fits the task.
