# @vdnp/image-turbo

> 标签: canvas, compression, dropzone, headless, image, nextjs, presigned-url, r2, react, s3, upload, webp

## 简介

Blazing-fast client-side image compression (Canvas/WebP) with a headless React hook and a minimalist dropzone. Direct-to-cloud upload ready.
