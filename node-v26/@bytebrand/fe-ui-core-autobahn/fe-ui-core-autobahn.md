# @bytebrand/fe-ui-core-autobahn

> 标签: JavaScript

## 简介

auto.de md3 (Autobahn) design system — UI primitives, cards, chrome, VDP modules, theme CSS and locales. Ships raw TypeScript source (like fe-ui-core before it); each consumer's bundler compiles it.
