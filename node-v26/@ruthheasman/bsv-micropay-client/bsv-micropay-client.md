# @ruthheasman/bsv-micropay-client

> 标签: 402, ai-agent, bitcoin-sv, bsv, client, fetch, micropayments, pay-per-use, sdk

## 简介

Client SDK for BSV micropayments. Wraps fetch with automatic 402 payment handling. Works with @bsv/sdk for autonomous AI agents.
