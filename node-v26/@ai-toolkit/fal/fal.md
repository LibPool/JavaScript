# @ai-toolkit/fal

> 标签: ai-toolkit

## 简介

The **[fal provider](https://sdk.khulnasoft.com/providers/ai-toolkit-providers/fal)** for the [AI TOOLKIT](https://sdk.khulnasoft.com/docs) contains image model support for the [fal.ai API](https://fal.ai/).
