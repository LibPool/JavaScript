# emdash-plugin-sheet-table

> 标签: astro, cms, csv, data-table, datatable, emdash, emdash-cms, emdash-plugin, excel-export, google-sheet, google-sheets, google-sheets-to-table, pdf-export, responsive-table, searchable-table, sheets, sortable-table, spreadsheet, spreadsheet-to-table, table, tabs

## 简介

Google Sheets to table plugin for EmDash CMS. Show a live, searchable, sortable Google Sheet on your Astro site, with 9 themes, CSV/Excel/PDF export, frozen columns, tab groups, private sheets and auto-sync.
