# @scrolled/nav-graph

> 标签: bfs, directed-graph, graph, navigation, navigator, pathfinding, scrolled

## 简介

Framework-agnostic graph core: IR types + Zod schema, an authoring DSL, a compiler (IR → runtime adjacency), and pathfinding (BFS + eligibility). The engine behind Scrolled Navigator; usable standalone in Node and the browser.
