# @gloomhaven-enhanced/datahaven

> 标签: JavaScript

## 简介

This repo is meant as a data source for information about Gloomhaven content. For now this is pretty much just a raw dump of the data from the TTS mod of Gloomhaven with lots of information that is only needed for TTS itself.
