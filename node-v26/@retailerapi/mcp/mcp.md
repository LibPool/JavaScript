# @retailerapi/mcp

> 标签: amazon, anthropic, barcode-lookup, bestbuy, claude, cross-retailer, ean-lookup, ebay, homedepot, lowes, mcp, model-context-protocol, price-history, product-api, product-data, retailerapi, target, upc-lookup, walmart

## 简介

Model Context Protocol server for retailerapi.com — unified product data across major US retailers (Walmart, Amazon, eBay, Target, Best Buy, Lowe's, Home Depot) plus universal URL passthrough for every Shopify store and any retailer that ships Product JSO
