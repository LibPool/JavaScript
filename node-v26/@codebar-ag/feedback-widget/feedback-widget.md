# @codebar-ag/feedback-widget

> 标签: annotation, bug-report, feedback, feedback-widget, laravel, screenshot, shadow-dom, typescript, user-feedback

## 简介

Self-hosted feedback widget: full-page screenshots with annotations, diagnostics and drafts. Vanilla TypeScript, Shadow DOM, no runtime dependencies in the core.
