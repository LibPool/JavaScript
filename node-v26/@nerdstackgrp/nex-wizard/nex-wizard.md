# @nerdstackgrp/nex-wizard

> 标签: angular, astro, cli, expo, flutter, mobile, monitoring, nex, nextjs, observability, python, react, react-native, svelte, vue, wizard

## 简介

Connect an application (web, server, React Native, Expo or Flutter) to Nex with one command: detects the framework, signs you in, picks the project, installs and configures the right Nex SDK, and sends a test event.
