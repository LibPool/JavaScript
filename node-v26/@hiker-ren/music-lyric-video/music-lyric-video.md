# @hiker-ren/music-lyric-video

> 标签: audio-reactive, claude-code, hyperframes, karaoke, lyric-video, music-visualization, skill, whisper

## 简介

Claude Code skill — 从音乐/音频文件生成 HyperFrames 歌词视频（卡拉OK风格）。完整管线：音频 → 频段提取 → Whisper 转录 → 歌词行分组 → HyperFrames 合成 → MP4 渲染。
