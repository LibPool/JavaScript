# @openapis-online/proxy

> 标签: ANTHROPIC_BASE_URL, anthropic, claude-code, cli, openapis, proxy, setup

## 简介

One-command setup to point Claude Code at the free OpenAPIs proxy. Auto-detects shell, edits your rc file idempotently, rolls back cleanly.
