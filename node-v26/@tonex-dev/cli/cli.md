# @tonex-dev/cli

> 标签: accessibility, cli, color, contrast, design-system, design-tokens, material-design, mcu, oklch, shadcn, tailwind, theme, wcag

## 简介

Turn a brand seed color into a complete light+dark theme with guaranteed WCAG contrast — shadcn, design.md, Material, or JSON — via Google's Material Color Utilities. Stop hand-picking hex.
