# @sqlml/cli

> 标签: code-generation, database, dbml, entity-generation, migrations, mysql, orm, postgres, prisma, schema, sql, sqlite, sqlml, typeorm

## 简介

DBML-first database toolkit — generate TypeORM/Prisma models, manage migrations, version schemas, and browse data via Web UI.
