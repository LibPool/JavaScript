# @adep/cf-compat

> 标签: JavaScript

## 简介

Cloudflare Workers 兼容层（ADR-0024 / CF-010）：Workers 模块格式适配（createAdepFunction）+ cfEnv 绑定组装 + D1/KV/R2 shim，供 Cloudflare 应用迁移到 adep 平台。零平台重栈依赖。
