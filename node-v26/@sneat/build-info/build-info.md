# @sneat/build-info

> 标签: JavaScript

## 简介

sneat-stamp-build-info: stamps an app's own version/git-hash/build-timestamp into build-info.ts + build-info.json, for use with @sneat/core-public's provideBuildInfo() and @sneat/components' AppVersionComponent.
