# @sneat/astro

> 标签: JavaScript

## 简介

Shared Astro building blocks for Sneat marketing landings — i18n toolkit, build/deploy scripts, and themeable chrome (BaseLayout, Header, Footer, LangSwitcher …) driven by the fleet --color-* token contract.
