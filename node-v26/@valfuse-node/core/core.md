# @valfuse-node/core

> 标签: form, i18n, localization, react, schema, typescript, valfuse, validation, vue

## 简介

Umbrella entry point for valfuse-node — re-exports form domain, localization runtime, and React/Vue adapters so a single install gives you the full library.
