# @ozymandros/electron-message-bridge-adapter-grpc

> 标签: @ozymandros/electron-message-bridge, electron, grpc, ipc, transport, typescript

## 简介

gRPC transport adapter for @ozymandros/electron-message-bridge. Exposes typed IPC handlers over a gRPC channel for language-agnostic client access.
