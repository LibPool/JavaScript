# @encoradb/core

> 标签: aes-gcm, database, encryption, field-level-encryption, kms, nodejs, orm, privacy, security, typescript

## 简介

The core encryption engine for **EncoraDB**. This package handles AES-256-GCM field encryption, HKDF key derivation, HMAC blind indexing for searchable queries, and SOC2 audit logging.
