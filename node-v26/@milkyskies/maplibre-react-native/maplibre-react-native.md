# @milkyskies/maplibre-react-native

> 标签: android, ios, mapbox, maplibre, maps, react-native

## 简介

Fork of @maplibre/maplibre-react-native with Android fixes: marker pan-lag (Choreographer-driven positioning), overlap-touch hit-test (rank by anchor screen-Y), and post-destroy lifecycle safety (markerViewManager cleanup + project/unproject null-checks).
