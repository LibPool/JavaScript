# @ruby-mcp/gems-mcp

> 标签: gems, mcp, model-context-protocol, package-manager, rails, ruby, rubygems

## 简介

MCP server for interacting with RubyGems.org API, Gemfiles, and gemspecs - search gems, get versions, and manage dependencies
