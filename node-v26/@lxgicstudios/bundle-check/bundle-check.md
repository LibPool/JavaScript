# @lxgicstudios/bundle-check

> 标签: alternatives, audit, bundle, check, ci, cli, dependencies, gzip, lightweight, minified, npm, package, size

## 简介

Check npm package bundle sizes before installing. Shows minified + gzipped size, dependency count, and suggests lighter alternatives. Perfect for CI pipelines.
