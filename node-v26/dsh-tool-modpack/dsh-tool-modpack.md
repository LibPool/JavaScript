# dsh-tool-modpack

> 标签: ai-image, cordis, deepseek-harness, dsh, ftb-quests, minecraft, modpack, modrinth, plugin, resourcepack, tool

## 简介

DeepSeek Harness 整合包制作工具集：22 个 modpack_* 工具，覆盖 Minecraft 整合包从规划、环境搭建、模组管理、配置定制、任务书生成、界面设计（含 AI 生图）、本地化、测试验证到多平台发布的完整生命周期。零外部 MCP 服务依赖。
