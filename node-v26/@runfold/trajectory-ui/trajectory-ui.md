# @runfold/trajectory-ui

> 标签: agent, react, trajectory, trajectory-ui

## 简介

A standalone host for the unchanged DeepSeek Harness Trajectory implementation. This is a browser-only React library; its public API is the `EventTrajectory` component and its props. Projection runtime details remain internal.
