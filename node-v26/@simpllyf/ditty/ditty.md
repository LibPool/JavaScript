# @simpllyf/ditty

> 标签: background-music, game-audio, generative-music, music, procedural, raga, synthesizer, web-audio, zero-dependency

## 简介

Zero-dependency, harmony-led generative music engine for the browser — endless, seamlessly-looping multi-instrument background music, synthesized via the Web Audio API.
