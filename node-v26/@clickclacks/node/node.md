# @clickclacks/node

> 标签: analytics, clickclacks, cloudflare-workers, events, product-analytics, server

## 简介

Server-side SDK for ClickClacks product analytics. Batches, gzips and retries events safely on Node 18+ and Cloudflare Workers.
