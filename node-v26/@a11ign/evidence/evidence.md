# @a11ign/evidence

> 标签: a11y, accessibility, nvda, screen-reader, wcag

## 简介

The shared evidence contract for screen-reader accessibility captures: wire types, pure verification predicates, and the WCAG 2.2 AA criteria list. Zero dependencies, no I/O.
