# @nilskluewer/pi-subagent

> 标签: agent, permission-gate, pi, pi-coding-agent, pi-extension, pi-package, subagent, tool

## 简介

Subagent tool for Pi: one task per call, inline or named agent personas, resumable sessions, background runs with subagent_wait, a live subagent panel, and a parent-side approval coordinator for the permission gate extension.
