# @memef1f1y/dsh-plugin-proxy

> 标签: deepseek-harness, dsh, dsh-plugin, proxy, socks5, undici

## 简介

Runtime-switchable outbound proxy for the DeepSeek Harness: hot-reload HTTP(S)/SOCKS5 routing for every global-fetch request via a settings section (+ web settings card).
