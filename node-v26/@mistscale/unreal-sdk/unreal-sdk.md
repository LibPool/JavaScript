# @mistscale/unreal-sdk

> 标签: ai, game-sdk, mistscale, npc, unreal, unreal-engine, websocket

## 简介

MistScale Unreal SDK — a UE5 plugin for NPC chat, voice, and spatial context over the MistScale REST and WebSocket APIs. Published on npm for versioned/CDN distribution; Unreal itself installs this by copying MistscaleSDK/ into a project's Plugins/ folder
