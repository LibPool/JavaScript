# @nudata/nu-duck

> 标签: JavaScript

## 简介

A browser script that loads DuckDB-WASM and exposes a ready-to-use connection as `window.nu_duck`. Load it from a CDN and run SQL queries in the browser without bundling DuckDB into your own app.
