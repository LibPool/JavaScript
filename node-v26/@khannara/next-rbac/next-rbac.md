# @khannara/next-rbac

> 标签: access-control, app-router, authorization, hierarchical-roles, middleware, mongodb, mysql, next13, next14, next15, nextjs, permission-gate, permissions, postgresql, prisma, rbac, react, role-based, server-actions, server-components, sqlite, typescript

## 简介

Enterprise-ready Role-Based Access Control (RBAC) for Next.js 13+ App Router with TypeScript support. Supports MongoDB, Prisma (PostgreSQL, MySQL, SQLite, etc.), hierarchical roles, and middleware protection.
