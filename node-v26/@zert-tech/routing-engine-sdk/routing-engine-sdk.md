# @zert-tech/routing-engine-sdk

> 标签: cross-chain, dex, multi-chain, routing-engine-sdk, sdk, swap, zert, zert-tech

## 简介

<a href="https://docs.zert.com/routing-engine-sdk/sdk-overview">Routing Engine SDK</a> is a TypeScript/JavaScript client for **Zert's routing API**. Use it in front-end or back-end apps to discover chains/tokens/pairs, request quotes, run the swap signing
