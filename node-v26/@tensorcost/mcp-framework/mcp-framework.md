# @tensorcost/mcp-framework

> 标签: json-rpc, mcp, model-context-protocol, nestjs, tensorcost, tools

## 简介

Product-agnostic NestJS module for hosting an MCP (Model Context Protocol) JSON-RPC server with pluggable key verification, scopes, rate limiting, and internal-auth forwarding.
