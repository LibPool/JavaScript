# @chart-on/indicators

> 标签: JavaScript

## 简介

Built-in chart indicators (SMA, EMA, Bollinger Bands, VWAP, RSI, MACD, volume MA, cumulative volume, Keltner, Donchian, Supertrend, Ichimoku, ATR, Stochastic, Stoch RSI, DMI/ADX, OBV, moon phases) for @chart-on/core.
