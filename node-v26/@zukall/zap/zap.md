# @zukall/zap

> 标签: address, address builder, address creator, address maker, builder address, builders address, building address, coordinate address, coordinates, geolocation, gps address, grid, location address, physical address, physical address creator, physical address maker, typescript, zap, zukall, zukall-addressing-protocol

## 简介

ZAP (Zukall Addressing Protocol): a physical address maker that turns GPS coordinates into consistent location addresses, with reverse lookup, distance, and route planning.
