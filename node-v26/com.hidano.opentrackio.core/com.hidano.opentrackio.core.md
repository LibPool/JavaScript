# com.hidano.opentrackio.core

> 标签: camera-tracking, opentrackio, smpte, virtual-production

## 简介

Protocol layer for SMPTE RIS-OSVP OpenTrackIO in Unity: sample model, packet parsing, CBOR/JSON decoding, and coordinate conversion. Has no dependency on URP or UnityEditor.
