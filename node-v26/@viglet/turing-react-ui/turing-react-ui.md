# @viglet/turing-react-ui

> 标签: chat, headless, react, turing, ui, viglet

## 简介

Headless React UI primitives for Viglet Turing ES — design-agnostic chat / rich-content components (e.g. TuringHtmlSandbox) shared across the admin console and viglet.com. No API or axios dependency; skin via classNames / labels / icons.
