# @viglet/turing-flow-dsl

> 标签: chat-flow, dsl, turing, type-safe, typescript

## 简介

TypeScript DSL for Viglet Turing ES chat flows — author flows as typed source, transpile to the editor's JSON wire format. Catches enum typos (tone, guardrail, trigger) at compile time.
