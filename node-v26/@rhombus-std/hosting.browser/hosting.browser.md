# @rhombus-std/hosting.browser

> 标签: bfcache, browser, generic-host, hosting, ioc, lifetime, page-lifecycle, typescript

## 简介

Browser hosting for the Generic Host: BrowserLifetime (page-lifecycle-driven shutdown, bfcache-safe), the PageLifecycleEvents bridge for hosted services, a browser IHostEnvironment factory, and the BrowserHost.createApplicationBuilder facade wiring in-mem
