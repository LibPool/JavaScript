# @rhombus-std/primitives

> 标签: change-token, primitives, typescript

## 简介

Change-token primitives (IChangeToken, ChangeToken.onChange, CancellationChangeToken, CompositeChangeToken), the augmentation registry, and the Type system every other family builds on. A leaf package -- zero dependencies.
