# @rhombus-std/fileproviders.composite

> 标签: composite, fileproviders, filesystem, typescript

## 简介

Composite file provider: CompositeFileProvider/CompositeDirectoryContents fold multiple IFileProvider instances into one, trying each in registration order. Depends on @rhombus-std/fileproviders.core and @rhombus-std/primitives.
