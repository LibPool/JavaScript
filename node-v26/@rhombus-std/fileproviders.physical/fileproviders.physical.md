# @rhombus-std/fileproviders.physical

> 标签: fileproviders, filesystem, physical, typescript

## 简介

Disk-backed file provider: PhysicalFileProvider serves IFileInfo/IDirectoryContents off the on-disk file system and watches exact files and directory prefixes for changes. Depends on @rhombus-std/fileproviders.core and @rhombus-std/primitives.
