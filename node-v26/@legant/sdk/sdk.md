# @legant/sdk

> 标签: ai-agents, authorization, delegation, legant, mcp, oauth2, rfc8693

## 简介

Offline verifier + authorizer for Legant delegation tokens (RFC 8693 sub/act), with Tier-B revocation-feed support. Zero runtime dependencies.
