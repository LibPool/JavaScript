# @shapething/textstore

> 标签: JavaScript

## 简介

A thin wrapper around [N3 Store](https://github.com/rdfjs/N3.js) and [Flexsearch](https://github.com/nextapps-de/flexsearch) enabling in-memory fuzzy text search.
