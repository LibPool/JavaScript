# @renxqoo/rxopen-cli

> 标签: agent, agentdatacli, cli, daily-news, hot-search, news, open-data, rxcli, translate, weather

## 简介

rxopen — an open-data CLI built on @renxqoo/agent-data-cli, wrapping all public APIs of the vikiboss/60s open-source project (news, trending, weather, fuel prices, lunar calendar, translate, QR code, 60+ endpoints)
