# pi-commandcode-bridge

> 标签: cmd, command-code, commandcode, pi-extension, pi-package, pi-provider

## 简介

Pi provider that runs Command Code models through the cmd CLI (works without API access), with the model list and reasoning efforts discovered from cmd.
