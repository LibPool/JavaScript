# @deepintshield/ai-security

> 标签: ai, anthropic, deepintshield, gateway, guardrails, llm, observability, openai, proxy

## 简介

DeepintShield - the open-source, OpenAI-compatible AI gateway. Route, secure, cache, and observe LLM traffic. This package downloads the prebuilt gateway binary for your platform and runs it.
