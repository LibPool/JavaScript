# @uipath/ui-widgets-pdf-viewer

> 标签: data-fabric, pdf, pdf-viewer, react, react-pdf, storage-bucket, ui, uipath

## 简介

A React PDF viewer widget for UiPath coded apps — renders PDFs from Orchestrator Storage Buckets, Data Fabric entity attachments, or plain URLs/Blobs
