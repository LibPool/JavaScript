# @uipath/delegate-stdio

> 标签: JavaScript

## 简介

Run a UiPath Delegate agent as a subprocess speaking JSON-Lines over stdio. Self-contained: installing this package pulls in @uipath/delegate-sdk — no separate SDK install.
