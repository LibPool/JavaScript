# @adhd/apigen-base-errors

> 标签: JavaScript

## 简介

Canonical error model for apigen — one set of error codes mapped to each transport's status convention (HTTP, gRPC, CLI exit, MCP), plus streaming-error phase helpers. Pure TypeScript (**platform: shared**).
