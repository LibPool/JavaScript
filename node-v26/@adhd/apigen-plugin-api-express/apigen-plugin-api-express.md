# @adhd/apigen-plugin-api-express

> 标签: JavaScript

## 简介

apigen target plugin (`--type api-express`) — exposes a source file's exports as an **Express HTTP API**. One `POST /<namespace>/<fn>` route per export (handlers call `res.json(result)`). Generates `routes.ts` to disk _and_ runs a live server.
