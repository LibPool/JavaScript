# @adhd/sox-ingest

> 标签: data, ingest, summary, tags, transform, typescript

## 简介

Write-path single-item transforms for the memory domain — content-hash (SHA-256), extractive summary (lead-N sentences, zero LLM), deterministic tag extraction, and chunking/normalization. Pure stateless functions; no storage deps.
