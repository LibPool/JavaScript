# @fddarcbase/client

> 标签: JavaScript

## 简介

单组织 Go 基础版的独立 TypeScript API 客户端。运行时只依赖 `@fddarcbase/shared`，不依赖 React、Semi UI、TanStack Query、Web 源码或浏览器存储。支持 workspace 开发和根目录 `pack:packages` 的编译后 tarball 交付，可在仓库外安装，并由普通 Node 直接导入 ESM。
