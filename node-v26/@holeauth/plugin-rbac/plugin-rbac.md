# @holeauth/plugin-rbac

> 标签: authorization, holeauth, holeauth-plugin, permissions, rbac

## 简介

holeauth plugin: headless role/group/permission system with Minecraft-style wildcards and negations. Use @holeauth/rbac-yaml for YAML config, @holeauth/rbac-drizzle for DB storage.
