# @vivliostyle/remark-footnote-pandoc

> 标签: JavaScript

## 简介

Pandoc-style endnote rewriter used by VFM. Converts mdast-util-to-hast's default endnote markup into a `<section role="doc-endnotes">` block with renumbering and duplicate-call backlinks.
