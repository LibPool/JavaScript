> 标签: agent, ainative, claude, cursor, growth, linkedin, mcp, model-context-protocol, post-scheduling, reddit, scheduling, slack, social-media, social-media-mcp, youtube

## 简介

AINative Social Growth MCP — post and schedule across LinkedIn, Slack, Reddit, YouTube and more from one MCP, via the AINative backend (official platform APIs). This npm package is a thin launcher for the Python `ainative-social-mcp` server.
