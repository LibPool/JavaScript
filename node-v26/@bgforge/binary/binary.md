# @bgforge/binary

> 标签: binary, fallout, map, modding, parser, pro

## 简介

Library and CLI for parsing and serialising Fallout (PRO, MAP) and Infinity Engine (ITM, SPL, EFF, CRE, DLG) binary files (round-trip to canonical JSON snapshots), and reading installed IE games (KEY, BIF, TLK, IDS, 2DA).
