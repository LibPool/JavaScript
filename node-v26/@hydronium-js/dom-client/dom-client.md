# @hydronium-js/dom-client

> 标签: JavaScript

## 简介

Hydronium's browser client runtime: Bridge API 2 Lua 5.4.9 WASM engine, DOM bridge, mount/hydrate, dev HMR client, JS-island bootstrap, and the dev error overlay. Canonical source for what used to be hand-maintained under dom/src/hydronium_dom/client/ --
