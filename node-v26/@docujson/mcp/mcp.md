# @docujson/mcp

> 标签: ai, anthropic, claude, cursor, docujson, document-generation, mcp, model-context-protocol, openai, pdf, template

## 简介

Model Context Protocol server for DocuJSON. Connect Claude Desktop, Cursor, and other AI assistants to DocuJSON's PDF generation and template builder.
