# @8kugames/dsh-zed-acp

> 标签: acp, agent-client-protocol, coding-agent, deepseek-harness, dsh, zed

## 简介

Zed-oriented Agent Client Protocol server for DeepSeek Harness: installable dsh plugin (`dsh plugin --profile zed add @8kugames/dsh-zed-acp`) exposing persistent sessions, inclusive session/fork, turn steering, plan mode, agent presets, permission presets
