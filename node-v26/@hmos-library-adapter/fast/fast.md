# @hmos-library-adapter/fast

> 标签: agent, android, arkts, flutter, harmonyos, hub, ohos, opencode, openharmony, react-native, sdk

## 简介

鸿蒙三方库适配/升级/修复统一调度入口 — 自动识别适配、升级或修复意图，分发到对应子包完成鸿蒙适配、升级或问题修复。安装到 OpenCode 宿主。
