# @stylexswc/rs-compiler

> 标签: JavaScript

## 简介

High-performance Rust/NAPI-RS/SWC compiler for StyleX CSS-in-JS with compile-time atomic CSS extraction, metadata, source maps, and Babel-plugin replacement APIs for Node.js.
