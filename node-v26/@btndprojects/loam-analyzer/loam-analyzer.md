# @btndprojects/loam-analyzer

> 标签: JavaScript

## 简介

Loam analyzer — the headless, platform-agnostic camera core (capture profiles, the quality gate, the analysis pipeline, permission states and the failure taxonomy) shared by @btndprojects/loam-ui-web and @btndprojects/loam-ui-native. It owns no device API
