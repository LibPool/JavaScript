# @hyuga/redline

> 标签: agent, ai, claude-code, coding-agent, developer-tools, guardrails, hooks

## 简介

A limiter that counts the whole session instead of asking about one call: writes to production, irreversible commands and outward sends add up, the number never goes down, and past the edge it stops only when nobody is in the seat.
