# @clickterm/widget

> 标签: agreement, browser, clickterm, clickwrap, consent, sdk, terms, tos, typescript, widget

## 简介

Browser SDK (TypeScript) that embeds Clickterm clickwrap agreements into host pages as a modal dialog or inline checkbox.

- 官网：https://clickterm.com
- 源码仓库：git+https://github.com/TelQ/ct-widget.git
