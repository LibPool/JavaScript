# quickinfo

> 标签: api, astro, astro-integration, code, documentation, docusaurus, docusaurus-plugin, hover, mkdocs, quickinfo, sphinx, tooltip

## 简介

Editor-style API hover tooltips for docs: signatures and docstrings on every API symbol in code blocks and prose. Docusaurus, Astro, Sphinx, MkDocs, or any other static site generator.
