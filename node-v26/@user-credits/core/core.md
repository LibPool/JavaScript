# @user-credits/core

> 标签: credit-flow, credits-balance, payment-screens, user-credits

## 简介

An open-source frontend and backend library designed to implement pay-as-you-go features in your web or mobile applications. Credit flow is managed locally instead of being sent back and forth to payment platforms as Stripe, in addition, you own your data
