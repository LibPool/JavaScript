# @resoul/wireauth

> 标签: aes-gcm, crypto, ecdh, handshake, secure-channel, websocket

## 简介

Transport-agnostic client-side RSA+ECDH handshake and AES-256-GCM secure channel (browser Web Crypto API). Companion to the Go wireauth server package.
