# @kalandramo/desktop-kit

> 标签: app-registry, capability-gating, desktop, desktop-shell, react, tailwindcss, ui-components, window-manager, wm

## 简介

React desktop kit: Tailwind v4 UI primitives, the app registry, and the desktop shell (windows, snapping, persistence, iframe handshake).
