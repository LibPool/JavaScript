# @absolutejs/audit

> 标签: absolutejs, audit, audit-log, compliance, hash-chain, siem, soc2, tamper-evident

## 简介

Cross-surface audit-event substrate for the AbsoluteJS ecosystem — append-only event log with pluggable sinks, optional hash-chain tamper-evidence, and live-wire helpers that thread sync mutations, queue jobs, runtime exits, and secret rotations into one
