# @absolutejs/errors

> 标签: absolutejs, audit, effect, effect-ts, errors, exceptions, issues, observability, sentry, telemetry, tracking

## 简介

Effect-native, Sentry-equivalent exception capture for the AbsoluteJS substrate. createErrorTracker decorates @absolutejs/audit + @absolutejs/telemetry + a durable issue store; capture() returns a CaptureOutcome with per-sink delivery state + typed (Data.
