# @absolutejs/deploy

> 标签: absolutejs, bun, deploy, droplet, release, rsync, ssh, vps

## 简介

Generic Bun-project deploy pipeline. A Target (localTarget / sshTarget) is anywhere you can exec + upload — DigitalOcean droplets, Linode, Hetzner, Vultr, your own boxes. Bundled pipeline: prepare → upload → install → build → link → restart → verify. Atom
