# dsh-wechat-notice

> 标签: dsh, dsh-plugin, notification, notify, wechat, wecom, weixin, 企业微信, 微信, 通知

## 简介

微信通知合一插件：企业微信群机器人 + 个人微信直连（weixin-agent-sdk）双通道，回合结束 / 审批请求 / Agent 出错时按自定义模板推送，设置页 Tab 切换双通道配置。WeCom group robot + personal WeChat direct notifier for DeepSeek Harness.
