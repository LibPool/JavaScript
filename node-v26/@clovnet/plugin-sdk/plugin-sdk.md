# @clovnet/plugin-sdk

> 标签: casinowebengine, cwe, igaming, plugin, sdk

## 简介

Clovnet plugin SDK — the complete, contract-only surface for building Clovnet plugins (manifest, PluginContext, routes, datasets, jobs, migrations) plus an in-memory test harness under ./testing.
