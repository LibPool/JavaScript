# @gpits/fontsource-variable-discover

> 标签: auto discovery, fonts, fontsource, fontsource-variable

## 简介

A typescript module (and cli command) that discovers fontsource-variable fonts from package.json and can export them to 1) a css file containing import statements, and 2) a json file containing their main metadata
