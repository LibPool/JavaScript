# @whatbroke/whatbroke

> 标签: bug, cli, crash, debugging, git, mcp, repro, stack-trace

## 简介

Terminal-side capture layer for local Node crashes: packages the error, the diff since it last worked, and a ranked guess at the responsible file — secrets scrubbed — and hands it to your coding agent over MCP.
