# @meui-creative/send

> 标签: email, email-adapter, meui, payload, payloadcms, resend, transactional, webhooks

## 简介

Official client for meuiSend (Meui transactional email platform): typed API client, Payload CMS email adapter and Standard Webhooks verification. Zero runtime dependencies.
