# react-faq-accordion

> 标签: accessibility, accordion, details, faq, faqpage, prerender, react, schema.org, seo, ssr, summary

## 简介

Animated React FAQ accordion built on <details> — the answer text stays in the server-rendered HTML, so search engines and AI crawlers can read it without running JavaScript.
