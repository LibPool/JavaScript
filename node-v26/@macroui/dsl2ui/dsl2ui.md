# @macroui/dsl2ui

> 标签: ai, component, dsl, dsl2ui, framework-agnostic, react, render, server-sent-events, sse, streaming-ui, svelte, ui-framework, vue, web-components

## 简介

Dsl2UI — Zero-dependency streaming UI description & rendering framework for AI chat. Describe UI with a tiny DSL, stream over SSE, render to real DOM incrementally.
