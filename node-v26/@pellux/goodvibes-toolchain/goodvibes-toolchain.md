# @pellux/goodvibes-toolchain

> 标签: ci, goodvibes, publish, release, toolchain

## 简介

Shared GoodVibes CI/CD toolchain: parameterized release, publish, and verification tools (sdk-pin gate, build-binaries, release-cut, coverage-gate, per-job-green, and more) consumed by every GoodVibes repo.
