# @nefevcore/abap-adt-protocol

> 标签: abap, abap-adt, abap-development-tools, abap-unit, adt, atc, rest, sap, sap-abap, transport

## 简介

Pure-TypeScript client for the SAP ABAP Development Tools (ADT) REST protocol: authentication, session, CSRF, object CRUD, activation, search, ABAP Unit, ATC and transport management.
