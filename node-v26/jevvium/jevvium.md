# jevvium

> 标签: acceptance-criteria, appium, decision-model, jev, mobile-testing, test-automation, test-plan, webdriverio

## 简介

Turn test plans written in plain words into Appium tests. A decision model follows the plan through the app, tapping, typing and scrolling, then jevvium writes a plain, deterministic test from the path it found.
