# @coless/wikiit

> 标签: Coless, wikiit

## 简介

`wikiit` 是面向 Agent 和开发者的知识库命令行工具，提供连接配置、认证、知识库与知识资源管理、内容检索及 FAQ 操作，并支持 JSON、文本和 NDJSON 输出。
