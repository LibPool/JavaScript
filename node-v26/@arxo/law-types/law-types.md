# @arxo/law-types

> 标签: computational-law, dsl, law, legal-tech, rules-as-code, types, typescript

## 简介

TypeScript types for Arxo Law Core 0.1, generated from the normative JSON schemas (legal IR, evaluation documents, diagnostics, lockfiles, decision tables, queries), plus the machine-readable registry of LDC diagnostic codes. Types only: no runtime engine
