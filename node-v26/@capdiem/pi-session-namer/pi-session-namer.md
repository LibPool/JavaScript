# @capdiem/pi-session-namer

> 标签: automation, coding-agent, naming, pi, pi-package, rename, session, title

## 简介

Automatic session naming for the Pi coding agent: names each session 0904｜FIX｜登录态刷新丢失-style from the live conversation, rechecks as work evolves, respects manual renames, and toasts every change with undo
