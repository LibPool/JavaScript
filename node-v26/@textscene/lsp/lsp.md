# @textscene/lsp

> 标签: autocomplete, diagnostics, emacs, gamedev, godot, godot4, helix, language-server, language-server-protocol, lsp, neovim, sublime-text, tres, tscn, vim, zed

## 简介

Language server for Godot .tscn scenes and .tres resources: diagnostics, hover, completion, quick fixes, go to definition, find all references, res:// links, document symbols, highlights and folding. Works in any LSP client, such as Neovim, Helix, Zed, Em
