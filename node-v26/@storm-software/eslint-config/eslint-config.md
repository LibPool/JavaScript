# @storm-software/eslint-config

> 标签: eslint, eslint-config, eslintconfig, monorepo, storm, storm-ops, sullivanpj

## 简介

⚡ The eslint-config package is a shared ESLint config that contains a collection of recommended ESLint rule configurations which you can extend from in your own ESLint configs, as well as an Nx-specific lint rule called enforce-module-boundaries.
