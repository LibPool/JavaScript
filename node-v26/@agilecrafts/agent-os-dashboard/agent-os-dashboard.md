# @agilecrafts/agent-os-dashboard

> 标签: agent-os, claude, dashboard, governance

## 简介

Launcher for Cortex Rail (Windows and Linux). Downloads the app from GitHub Releases on first run, then launches it against a project you pick.

- 源码仓库：git+https://github.com/AgileCrafts/cortex-rail.git
