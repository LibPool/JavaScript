# cajon

> 标签: JavaScript

## 简介

A browser module loader that can load CommonJS/node and AMD modules. Built on top of RequireJS.

## 官网

- 官网：http://github.com/requirejs/cajon
- 源码仓库：git+https://github.com/requirejs/cajon.git
