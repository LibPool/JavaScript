# @robinpath/ldap

> 标签: auth, directory, identity, ldap, ldaps

## 简介

LDAP / LDAPS client for RobinPath — search, bind, add/modify/delete, compare, modifyDN, plus user and group helpers. Connections are keyed by the credential vault.
