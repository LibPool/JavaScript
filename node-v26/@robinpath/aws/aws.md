# @robinpath/aws

> 标签: aws, cloud, dynamodb, lambda, s3, secretsmanager, ses, sns, sqs

## 简介

AWS services integration — S3, SES, SNS, SQS, Lambda, DynamoDB, Secrets Manager. Uses @aws-sdk/client-* under the hood and the RobinPath credential vault.
