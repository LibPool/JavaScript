# @inxep/xui

> 标签: ai, pixel-art, ui, xengine, xgui, xml, xui

## 简介

AI-first UI application layer on top of XGUI. Compact .xui XML screens assembled into XGUI hierarchies at runtime, logic/render separation, and offline validation through the XEngine AI Host. Official optional package: listed in Package Manager, not mount
