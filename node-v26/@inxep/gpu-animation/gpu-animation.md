# @inxep/gpu-animation

> 标签: animation-baker, crowd, gpu-animation, instancing, vat, vertex-animation-texture, xengine

## 简介

Animation Baker and Instancing: bake skinned-mesh animations into vertex animation textures (VAT) and render thousands of GPU-instanced animated characters. Official optional package: listed in Package Manager, not mounted until installed.
