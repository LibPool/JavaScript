# @inxep/postprocessing

> 标签: bloom, color-grading, hdr, postprocessing, volume, xengine

## 简介

Unity Post-processing Stack v2 style layer, volume, and profile. Official optional package: listed in Package Manager, not mounted until installed. Drives the engine ImageEffects (Bloom, tonemap, DoF, GTAO, SSR, cinematic).
