# @benbini/send-to-kindle-mcp

> 标签: amazon, ebook, epub, kindle, mcp, model-context-protocol, send-to-kindle

## 简介

MCP server that sends EPUB (and other supported document) files to a Kindle device via Amazon's Send-to-Kindle email feature.
