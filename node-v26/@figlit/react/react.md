# @figlit/react

> 标签: JavaScript

## 简介

**피글리에**로 피그마 프로토타입을 살아 숨쉬게 만들 수 있습니다. 피그마로 디자인한 프로젝트는 피글리에와 함께 완전한 리액트 앱이 됩니다. (다르게 말하자면, 피글리에는 템플릿엔진을 포함한 리액트로 구현된 피그마 렌더러입니다.)
