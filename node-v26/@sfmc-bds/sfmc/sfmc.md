# @sfmc-bds/sfmc

> 标签: bds, cli, minecraft-bedrock, scriptsforminecraftserver, sfmc

## 简介

SFMC all-in-one meta package — CLI + db-server + qq-bridge + bds-tools. One install, then `sfmc` to init and run.
