# @esuyo/esuyo-opencode-session

> 标签: opencode, opencode-plugin, subagents, throughput, tokens, tps, tui, usage

## 简介

OpenCode TUI sidebar showing token usage across a session and its subagents, plus live TPS/AVG/TTFT/GAP throughput in the prompt footer with optional JSONL stats logging.
