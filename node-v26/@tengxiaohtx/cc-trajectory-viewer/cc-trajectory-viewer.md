# @tengxiaohtx/cc-trajectory-viewer

> 标签: agent, claude, claude-code, diff, jsonl, trajectory, viewer, visualizer

## 简介

Visualize Claude Code trajectory (.jsonl session) files in the browser — timeline, tool calls, and code diffs. Open from the CLI or by uploading in the browser.
