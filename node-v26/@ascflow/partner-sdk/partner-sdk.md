# @ascflow/partner-sdk

> 标签: ascflow, embed, hmac, iframe, partner, sdk, sso

## 简介

Official SDK for partners integrating with ASCFlow's iframe SSO. Generates short-lived embed URLs with HMAC-signed requests.
