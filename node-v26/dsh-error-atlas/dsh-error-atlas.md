# dsh-error-atlas

> 标签: agent-memory, cordis-plugin, dsh, dsh-plugin, error-tracking, knowledge-graph, retrospective, webgl

## 简介

Records runtime errors and coding-task retrospectives, collapses noisy shell failures into command fingerprints, distils each lesson into one injected rule, and renders the whole thing as an interactive GPU knowledge graph (WebGL) with lesson links, recur
