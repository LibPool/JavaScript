# @application-kit/oidc

> 标签: nestjs, oauth2, oidc, openid-connect, pkce

## 简介

Вход через провайдера OpenID Connect: порт с реестром провайдеров по имени, адаптер на openid-client (discovery, authorization code с PKCE, state и nonce, проверка id_token) и Nest-модуль
