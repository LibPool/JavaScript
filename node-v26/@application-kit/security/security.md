# @application-kit/security

> 标签: aes-gcm, one-time-token, qrcode, security, totp

## 简介

Примитивы безопасности без доменных понятий: одноразовый секрет (выпуск, хеш, сверка постоянным временем, годность), TOTP по RFC 6238 с защитой от повтора, AES-256-GCM для коротких строк, QR в data-URI
