# @application-kit/bootstrap

> 标签: bootstrap, fastify, nestjs, nestjs-console

## 简介

Бутстрап процессов NestJS: web на Fastify с периметром (доверенные прокси по хопам, request-id в каждом ответе, cookie, ValidationPipe с плоским списком ошибок, graceful shutdown) и CLI на nestjs-console с логгером pino
