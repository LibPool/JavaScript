# @application-kit/typeorm

> 标签: cursor, logging, nestjs, pagination, typeorm

## 简介

Курсорный листинг на TypeORM: контракты листинга, пагинатор, фильтры, ORM-база сущности, конфиг и корневой модуль соединения Postgres, SQL-логгер с маской bind-параметров
