# @sxo/mathematica

> 标签: jupyter, mathematica, sxo, wolfram, wolfram-language

## 简介

Mathematica / Wolfram Language frontend: parse, evaluate, and render via the SXO native addon. Includes wolframscript CLI and Jupyter kernel install helpers.
