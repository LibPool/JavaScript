# @work-well/measure-codegen

> 标签: clinical-quality-language, codegen, cql, ecqm, quality-measures

## 简介

Declarative measure rules → canonical CQL. Zero dependencies: pure string templating with no engine, no runtime and no I/O. Authoring-time only — the emitted CQL is compiled and executed by @work-well/measure-engine, which remains the sole compliance auth
