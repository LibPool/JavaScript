# @hameddk/cursor-spend-collector

> 标签: admin-api, ai-costs, cursor, cursor-ide, spend, usage

## 简介

Pull real spend and usage events from Cursor's Admin API. Per-member spend in cents, granular usage events with model and token data. Pluggable auth, paginated, zero dependencies.
