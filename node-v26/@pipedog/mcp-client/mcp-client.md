# @pipedog/mcp-client

> 标签: conversational-ai, function-calling, mcp, model-context-protocol, pipecat, pipedog, realtime, tools, voice-ai

## 简介

MCP client for pipedog: a port of Pipecat's MCPClient. Connects to MCP servers (stdio, SSE or streamable HTTP) and gives their tools to an LLM service as function-call tools.
