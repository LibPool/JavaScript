# @pipedog/transport-livekit

> 标签: conversational-ai, livekit, pipecat, pipedog, realtime, transport, voice-ai, webrtc

## 简介

LiveKit transport for pipedog: joins a LiveKit room (self-hosted or LiveKit Cloud) as a participant, with audio, video, data messages and SIP DTMF. Media runs on LiveKit's native Node SDK (@livekit/rtc-node).
