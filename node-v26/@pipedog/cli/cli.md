# @pipedog/cli

> 标签: cli, conversational-ai, create, mcp, pipecat, pipedog, scaffold, voice-ai

## 简介

The pipedog command line, the port of Pipecat's CLI: `pipedog init` scaffolds a TypeScript voice bot (runner, services, client, agent guides, docs MCP), and `pipedog eval` runs @pipedog/evals.
