# @pipedog/heygen

> 标签: avatar, conversational-ai, heygen, liveavatar, pipecat, pipedog, realtime, video, voice-ai

## 简介

HeyGen avatar services for pipedog: HeyGenVideoService with LiveAvatar and Interactive Avatar sessions. Control runs over HTTP and WebSocket; avatar media runs on LiveKit's native Node SDK (@livekit/rtc-node).
