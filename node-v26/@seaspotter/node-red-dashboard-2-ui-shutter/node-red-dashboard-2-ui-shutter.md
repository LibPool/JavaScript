# @seaspotter/node-red-dashboard-2-ui-shutter

> 标签: blind, knx, node-red, node-red-dashboard-2, shutter

## 简介

A Node-RED Dashboard 2.0 widget for controlling shutters and venetian blinds: up/stop/down buttons, position and slat sliders, and an animated window graphic.
