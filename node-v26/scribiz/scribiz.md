# scribiz

> 标签: audio, captions, cli, gemini, mcp, speech-to-text, srt, subtitles, transcribe, transcription, video, vtt, youtube

## 简介

Transcribe any video, audio file or link to SRT, VTT, text or Markdown from your terminal, with a free Scribiz account or your own Gemini API key. Also an MCP server.
