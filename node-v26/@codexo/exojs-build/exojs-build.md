# @codexo/exojs-build

> 标签: audioworklet, glsl, rollup-plugin, vite-plugin, web-worker, wgsl, worklet

## 简介

Build-time Vite/Rollup plugins that load ExoJS shader files and inline typed AudioWorklet and Web Worker TypeScript modules as source strings.
