# @drupal-canvas/headless-host

> 标签: JavaScript

## 简介

Host-side implementation of the Drupal Canvas Headless draft-preview protocol, for applications that embed a Canvas headless frontend app.

## 官网

- 源码仓库：https://git.drupalcode.org/project/canvas.git
- npm 页面：https://www.npmjs.com/package/@drupal-canvas/headless-host
