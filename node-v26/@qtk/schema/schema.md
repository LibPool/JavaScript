# @qtk/schema

> 标签: json, json-schema, object, schema, semantic

## 简介

此库是基于semantic-schema，结合团队情况简单封装而成。用于对json数据进行校验．其语法跟semantic-schema库语法大部分相同，请移步[【这里】](https://www.npmjs.com/package/semantic-schema)了解语法。或者直接查看[【测试用例】](/test/)
