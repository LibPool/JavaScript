# @hawkenai/atrium-sdk

> 标签: JavaScript

## 简介

Browser AtriumClient, server AtriumAdmin, and verifyAtriumMcpJwt for partner MCP auth. Mint tokens on your server; the browser client only holds a short-lived user session.
