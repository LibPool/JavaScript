# pi-anon-export

> 标签: anonymize, export, html, jsonl, offline, pi, pi-coding-agent, pi-extension, pi-package, pii, privacy, redact, redaction, screenshot, secrets, session, share, zip

## 简介

Pi extension that exports agent sessions as anonymized JSONL or HTML, matching /export's paths and formats: redacts secrets from your shell rc files, strips or flags screenshots, verifies the result, zips a whole project. Fully offline.
