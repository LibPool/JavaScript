# @adam-rocska/units-and-measurement

> 标签: arithmetic-operations, boilerplate-free, comparison, dimension, javascript, js, math, measurement, measurement-units, measurements library, modular, node, nodejs, numeric-calculations, quantities, scaling, tree-shaking, ts, type predicates, type-safe, types, typescript, unit-aware, unit-conversion, unit-management, unit-operations, units, value extraction

## 简介

A TypeScript library for handling units and measurements with support for multiple formats (tuples, objects, strings, dimensions) and operations (arithmetic, comparison, ratios). Modular, tree-shakable, and designed for safe, boilerplate-free usage.
