# @dongasai/dsh-editor

> 标签: dsh, dsh-plugin, editor, file-manager, file-tree, workspace

## 简介

Edit, create, rename, copy, delete and paste workspace files in the DSH web GUI: an editable document renderer, a file-tree sidebar tool with its own clipboard, and six trusted host routes.
