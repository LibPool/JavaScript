# @nonbot/mcp

> 标签: claude, claude-code, cursor, decision-graph, mcp, mcp-server, model-context-protocol, non.bot, portfolio, product-management, vscode

## 简介

The non.bot MCP server — one server for your portfolios, decision graph, and Runs. Runs over stdio (Claude Code, Cursor, VS Code) with a pat_ token. Built on MCP protocol 2025-11-25.
