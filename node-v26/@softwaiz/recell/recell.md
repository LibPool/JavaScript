# @softwaiz/recell

> 标签: celld, cloudflare-workers, redwoodsdk, rwsdk, vite

## 简介

Normalizes an @cloudflare/vite-plugin build output (RedwoodSDK, or any Vite+Workers project using the same plugin) into a layout celld deploy/dev accepts.
