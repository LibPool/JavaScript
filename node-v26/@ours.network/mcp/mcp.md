# @ours.network/mcp

> 标签: a2a, adapt, claude, e2e, mcp, messaging, model-context-protocol

## 简介

MCP adapter for the shared ours daemon, with application-local identity bookkeeping and secure agent-to-agent messaging tools over stdio.
