# scanwright-mcp

> 标签: claude, cursor, mcp, model-context-protocol, pentest, scanwright, security

## 简介

Connect Claude Desktop, Cursor, Windsurf, Claude Code or any MCP client to Scanwright (scanwright.io) over stdio. One command: npx scanwright-mcp --key sk_sw_...

## 官网

- 官网：https://scanwright.io
- npm 页面：https://www.npmjs.com/package/scanwright-mcp
