# @inso_web/els-vue

> 标签: els, error-monitoring, error-tracking, inso, logging, monitoring, observability, plugin, sentry-alternative, typescript, vue, vue3

## 简介

Vue 3 plugin for the Error Logs Service (ELS): a global errorHandler, the useELS composable and automatic component error reporting.
