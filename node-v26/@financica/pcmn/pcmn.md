# @financica/pcmn

> 标签: accounting, belgian, belgium, bookkeeping, chart-of-accounts, cnc, income-statement, minimum-normalise, pcmn, typescript

## 简介

Zero-dependency Belgian PCMN (Plan Comptable Minimum Normalisé): the class taxonomy that maps account classes to economic categories, plus the statutory charts for enterprises and for associations in all four languages the CNC publishes them in.
