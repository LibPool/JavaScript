# @financica/be-biztax

> 标签: accounting, belgium, biztax, corporate-tax, fps-finance, isoc, typescript, venb, xbrl

## 简介

Belgian corporate income tax returns for Biztax (FPS Finance): build, validate, render and read be-tax XBRL instance documents, and wrap them in a .biztax upload file.
