# @financica/stripe-hosted-invoices

> 标签: accounting, credit-note, e-invoicing, ephemeral-key, hosted-invoice, invoice, receipt, stripe, typescript

## 简介

Read a Stripe invoice, credit note or receipt from its public hosted URL — no API key, using the same ephemeral-key protocol the hosted invoice page uses itself.
