# @rivia-labs/ddd-ts

> 标签: aggregates, architecture, ddd, domain, domain-driven-design, domain-events, entities, error-handling, functional-programming, shared-kernel, typescript

## 简介

A shared foundation for TypeScript projects following our interpretation of DDD, including entities, domain events, aggregates, functional error handling, and other reusable components shared across modules.
