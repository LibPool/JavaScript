# @codenotch/cli

> 标签: cli, cn, codenotch, fullstack, react, runtime, scaffold, typescript

## 简介

The Codenotch CLI ('cn'): scaffold, run, validate, package and deploy full-stack TypeScript Codenotch projects - processes, tables and React apps - on a local Codenotch runtime
