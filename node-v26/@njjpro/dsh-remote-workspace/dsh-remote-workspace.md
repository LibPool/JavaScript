# @njjpro/dsh-remote-workspace

> 标签: JavaScript

## 简介

Device-workspace federation for the dsh web GUI: pair into another DSH instance and browse its projects and sessions from the local sidebar, with each peer session opening in the local center column through a loopback embed proxy
