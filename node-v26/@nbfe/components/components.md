# @nbfe/components

> 标签: antd, components, react

## 简介

1. 针对 B 端系统, 基于 `antd` 高度封装基础组件库, 覆盖业务开发中 `90%` 的场景. 2. 与 [ProComponents](https://procomponents.ant.design) 定位相同, 但实现思路和使用方法完全不同. 3. 与 `Ant Design` 设计体系一脉相承, 无缝对接 `antd` 项目.
