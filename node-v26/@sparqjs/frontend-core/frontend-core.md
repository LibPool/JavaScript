# @sparqjs/frontend-core

> 标签: JavaScript

## 简介

`@sparqjs/frontend-core` 是前端基础包，统一承载前端贡献注册和可信进程内插件生命周期。它不包含 Vue、Schema、Admin 或设计器领域类型，可被 Admin、插件和其他宿主独立安装消费。
