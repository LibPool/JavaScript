# @voila.dev/docs

> 标签: docs, documentation, mdx, openapi, search, vite

## 简介

Framework-free building blocks of a documentation site: a navigation registry, a typo-tolerant search, reader contexts, a link graph check, an OpenAPI reference model and an MDX pipeline for Vite.
