# @digitak/fashion

> 标签: JavaScript

## 简介

**Fashion** is an extension to the [vanilla-extract](https://vanilla-extract.style/) library that makes use of Typescript as a style preprocessor (eg. use Typescript instead of Sass, Less, Postcss, etc...).
