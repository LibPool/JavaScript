# @oc-shopaholic/oc-request

> 标签: OctoberCMS, XMLHttpRequest, october, shopaholic, vanilla js

## 简介

oc-Request is vanilla js based replacement for standard OctoberCMS API. No dependencies. Based on native XMLHttpRequest.
