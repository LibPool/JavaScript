# @arianee/wallet-api-client

> 标签: JavaScript

## 简介

WalletApiClient is a TypeScript client for the Arianee's Wallet API. It provides an easy-to-use interface to interact with all available API routes and handles the authorization process using the Core instance passed to the constructor or a smart asset's
