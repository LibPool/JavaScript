# @senddy/client

> 标签: base, client, privacy, senddy, stablecoin, usdc, wallet, zero-knowledge, zk

## 简介

High-level client for the Senddy private stablecoin protocol. Orchestrates transfers, withdrawals, deposits, syncing, and note consolidation.
