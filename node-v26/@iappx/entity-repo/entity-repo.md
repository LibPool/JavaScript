# @iappx/entity-repo

> 标签: abstraction, axios, context, data-access, data-source, entity, framework, orm, query-builder, repository, rest, transport, typescript

## 简介

A TypeScript library that abstracts data sources and provides a unified context-based access to entities, queries, and transports.
