# @fly_tiger/v-table

> 标签: JavaScript

## 简介

vTiger/VTable是开箱即用的 Table 组件，在element Table 之上扩展了更多便捷易用的功能。为了解决项目中需要写很多 table 的样板代码的问题，所以在其中做了封装了很多常用的逻辑来提升开发类table业务的效率。
