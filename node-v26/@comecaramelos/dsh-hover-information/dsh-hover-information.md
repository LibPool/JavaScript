# @comecaramelos/dsh-hover-information

> 标签: JavaScript

## 简介

DSH plugin: richer session hover cards — corner icons that copy the session id and workspace path, a configurable metrics block (turns, steps, tokens, compactions, context, subagents, …) fed by the hoverInfo projection + Typert remote, all gated by a Sett
