# @metacapsin/tokenlens

> 标签: agent, ai, anthropic, context, llm, openai, profiler, prompt, tokens

## 简介

Provider-agnostic token profiler for LLM agent loops. See exactly where your context tokens go — and how many you waste re-sending the same thing.
