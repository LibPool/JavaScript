# @kuriyona/svg-toolkit

> 标签: flexbox, image-generation, og-image, svg, typescript, yoga-layout

## 简介

A declarative SVG generator powered by yoga-layout. Write a flexbox layout tree in JSON, get positioned SVG elements back.
