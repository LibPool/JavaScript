# @synap-core/room-ui

> 标签: JavaScript

## 简介

Plain-CSS "the Room" channel-surface UI kit — orchestrated multiplayer rooms where humans (squared avatars) and AI teammates (round glowing orbs) coexist. Framework-agnostic, CSS-token injectable.
