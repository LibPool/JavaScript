# @dressbuy/brideb-vendure-admin

> 标签: JavaScript

## 简介

当前库用来提前变异自定`admin-ui`扩展, 因为`vendure/ui-devkit`暂时不支持`mono`架构, 所以当前库我们需要执行如下安装步骤
