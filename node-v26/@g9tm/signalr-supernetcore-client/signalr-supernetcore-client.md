# @g9tm/signalr-supernetcore-client

> 标签: g9, lynx, reconnect, resumable-upload, signalr, supernetcore

## 简介

TypeScript twin of the G9SignalRSuperNetCore .NET client for browsers, Node and Lynx: resilient connection, JWT authorize route, resumable file upload/download, connection quality monitor and error codes.
