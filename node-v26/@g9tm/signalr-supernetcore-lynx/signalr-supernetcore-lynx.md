# @g9tm/signalr-supernetcore-lynx

> 标签: g9, lynx, native-module, signalr, websocket

## 简介

Lynx support for the G9SignalRSuperNetCore TypeScript client: a binary WebSocket native module (Android OkHttp, iOS URLSessionWebSocketTask, Lynxtron/Node), runtime shims and a ready-made G9Client factory for the Lynx background thread.
