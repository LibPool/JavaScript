# @lmliheng/requirements-box

> 标签: adelie-plugin, http, node, penguin-harness, queue, requirements, schedule

## 简介

A requirements box: one keyed page where the user files what they want done, a scheduled task that wakes the agent to work through them, and a per-round report by mail — the service being a single dependency-free Node file with a JSON store and a keyed AP
