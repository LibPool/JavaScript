# @zhunam/pdf-generator

> 标签: JavaScript

## 简介

A client-side PDF generator for Angular. Instead of wiring up pdfmake directly, it exposes a declarative, typed API (`PdfTemplate`) composed from factory functions (`pdfText`, `pdfTable`, `pdfColumn`...), reactive to signals, with a live preview compon
