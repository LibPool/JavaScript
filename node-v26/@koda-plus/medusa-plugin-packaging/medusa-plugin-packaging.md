# @koda-plus/medusa-plugin-packaging

> 标签: admin, b2b, ean, gs1, medusa, medusa-plugin, medusa-v2, moq, packaging, pallet, sscc, wholesale

## 简介

Packaging by Koda Plus: the wholesale packaging ladder of every product (piece, box, pallet), the minimum order quantity and the order step, EAN codes, SSCC labels for pallets and the GS1 check digit, with a store API for the product page.
