# @everruns/bashkit-web

> 标签: agent, ai, bash, browser, interpreter, sandbox, tool, wasm, webassembly

## 简介

Sandboxed bash interpreter for the browser (WebAssembly). Single-threaded — no SharedArrayBuffer, no COOP/COEP headers.
