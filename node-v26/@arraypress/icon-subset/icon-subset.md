# @arraypress/icon-subset

> 标签: astro, astro-integration, bootstrap-icons, harfbuzz, icon-font, performance, subset, tabler-icons, woff2

## 简介

Shrink an icon font (Tabler Icons, Bootstrap Icons, any .prefix-name:before font) to the icons a built site actually uses — CSS rules and font glyphs. With an Astro integration that runs on the finished build.
