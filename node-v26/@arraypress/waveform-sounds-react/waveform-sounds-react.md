# @arraypress/waveform-sounds-react

> 标签: audio, filter, player, presets, preview, react, react-component, sample-pack, samples, search, sound-browser, waveform

## 简介

React component wrapper for @arraypress/waveform-sounds — a searchable, filterable sound list with server-rendered markup the runtime adopts, typed props, callback props and an imperative ref handle.
