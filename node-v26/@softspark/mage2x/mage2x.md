# @softspark/mage2x

> 标签: cli, container, devops, docker, kubectl, kubernetes, magento, magento2, oh-my-zsh, oh-my-zsh-plugin, podman, zsh

## 简介

Run Magento and shell commands inside a container workload over docker, podman or kubectl. Refuses ambiguous targets instead of guessing, and asks before destructive operations on a production context.
