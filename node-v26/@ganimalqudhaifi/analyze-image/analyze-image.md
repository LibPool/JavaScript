# @ganimalqudhaifi/analyze-image

> 标签: analyze, image, llm, opencode, opencode-plugin, vision

## 简介

OpenCode plugin for image analysis using vision-capable LLMs. Adds an analyze_image tool that works with any provider already configured in OpenCode — no separate API keys needed.
