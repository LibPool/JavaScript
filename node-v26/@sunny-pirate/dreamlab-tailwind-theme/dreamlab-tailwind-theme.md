# @sunny-pirate/dreamlab-tailwind-theme

> 标签: JavaScript

## 简介

A reusable TailwindCSS theme package including custom design tokens such as responsive breakpoints (`xs`, `hd`, `4k`) using Tailwind CSS v4 and the new `@theme static` feature.
