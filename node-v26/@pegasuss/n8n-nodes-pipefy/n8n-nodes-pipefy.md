# @pegasuss/n8n-nodes-pipefy

> 标签: bpm, brazil, graphql, kanban, n8n-community-node-package, pipefy, workflow

## 简介

n8n community node for Pipefy — Brazilian workflow management platform (kanban/BPM). Supports Cards, Pipes, Phases and real-time Webhooks via GraphQL API.
