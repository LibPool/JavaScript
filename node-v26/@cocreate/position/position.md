# @cocreate/position

> 标签: collaboration, html5-framework, javascript-framework, low-code, position, realtime, realtime-framework, shared-editing

## 简介

Make any element draggable and movable. Customizable via attributes, great for popups, alerts, multitasking and displaying multiple views.
