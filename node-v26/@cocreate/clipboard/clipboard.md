# @cocreate/clipboard

> 标签: clipboard, collaboration, html5-framework, javascript-framework, low-code, realtime, realtime-framework, shared-editing

## 简介

A simple clipboard component in vanilla javascript. Easily configured using HTML5 data-attributes and/or JavaScript API.
