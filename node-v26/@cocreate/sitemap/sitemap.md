# @cocreate/sitemap

> 标签: cocreate-module, google-news-sitemap, html-parsing, image-sitemap, seo-automation, sitemap-generator, sitemap-sharding, stateless-utility, video-sitemap, xml-sitemap

## 简介

Automated stateless XML sitemap engine with multi-format media extraction (Images, Videos, Google News) and dynamic data-sharding for scalable document architectures.
