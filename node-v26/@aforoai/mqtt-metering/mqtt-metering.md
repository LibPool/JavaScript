# @aforoai/mqtt-metering

> 标签: aedes, aforo, billing, iot, metering, mqtt, pub-sub

## 简介

Aforo MQTT Metering SDK — aedes broker hooks + mqtt.js client wrapper that meters PUBLISH/DELIVER/SUBSCRIBE/CONNECT/DISCONNECT events to Aforo.
