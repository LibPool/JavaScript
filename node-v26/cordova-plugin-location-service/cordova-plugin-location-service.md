# cordova-plugin-location-service

> 标签: android, background, cordova, cordova-android, ecosystem:cordova, geofence, geolocation, location, tracking

## 简介

Battery-aware background location tracking for Android: motion-aware GPS, offline SQLite queue, HTTP sync with exponential back-off, unlimited geofences, and survival across app termination and reboot.
