# @redocly/client-generator

> 标签: OpenAPI, Swagger, TypeScript, client, codegen, fetch, generator

## 简介

Generate typed, zero-dependency TypeScript clients (fetch, auth, retries, middleware, SSE) from OpenAPI descriptions.
