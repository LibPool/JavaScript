# @wulechuan/single-tandem-ajax

> 标签: ajax, axios, non-duplicated-ajax, one-at-a-time, single-tandem, 单串式, 同一时刻仅单一AJAX请求, 避免同时发起多个完全相同的AJAX请求

## 简介

避免同时发起多个完全相同的 AJAX 请求。并支持 TypeScript 语法。
