# @wulechuan/gulp-markdown-to-html

> 标签: JavaScript

## 简介

此为吴乐川的《〈将 MarkDown 代码转换为 HTML 代码的工具〉的针对 Gulpjs 工具链的“包裹”程序》。其调用《@wulechuan/generate-html-via-markdown》之功能，用以将一组 MarkDown 文件逐一转换成对应的 HTML 文件。
