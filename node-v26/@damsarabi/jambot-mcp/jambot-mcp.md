# @damsarabi/jambot-mcp

> 标签: ai, claude, jamprovise, llm, mcp, model-context-protocol, music

## 简介

MCP Server for domain-constrained AI control of the Jamprovise music app. Exposes typed tools for sequence generation and transport control via the Model Context Protocol.
