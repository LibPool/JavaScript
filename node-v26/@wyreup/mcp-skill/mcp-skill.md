# @wyreup/mcp-skill

> 标签: agent, image, mcp, model-context-protocol, offline, pdf, privacy, skill, wyreup

## 简介

MCP-only skill teaching agents how to invoke Wyreup's 72 tools via the @wyreup/mcp server. For agents that already have MCP transport wired up. Smaller token footprint than @wyreup/skill (no CLI section).
