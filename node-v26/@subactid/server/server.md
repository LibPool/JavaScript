# @subactid/server

> 标签: ai-agents, delegation, express, fastify, jwt, oauth, rfc8693, subactid, token-exchange

## 简介

Subact ID for tool servers: validate task tokens against the control plane, enforce per-route scope, introspect high-risk routes, and log who acted for whom. Framework-agnostic, with Express and Fastify adapters.
