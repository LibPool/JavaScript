# @subactid/mcp

> 标签: ai-agents, delegation, mcp, model-context-protocol, oauth, rfc8693, subactid, token-exchange

## 简介

Subact ID for MCP servers: validate task tokens against the control plane's JWKS, enforce per-tool scope, introspect high-risk tools, and log who acted for whom on every call.
