# @snavesutit/jestbench

> 标签: blockbench, e2e, electron, jest, plugin, testing

## 简介

A Jest addon for writing end-to-end tests for Blockbench plugins - runs your plugin inside a real, isolated Blockbench instance and lets tests drive its API and GUI.
