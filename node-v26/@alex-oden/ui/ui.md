# @alex-oden/ui

> 标签: JavaScript

## 简介

React 19 component library that ships every primitive from the NeosPower design system as tree-shakeable ES modules, ready to drop into any Vite + Tailwind v4 project. Radix under the hood, HSL tokens on top, dark-first.
