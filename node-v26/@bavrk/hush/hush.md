# @bavrk/hush

> 标签: analytics, capacitor, expo, feedback, privacy, react-native, self-hosted, telemetry, web

## 简介

In-app feedback and anonymous usage tracking for React Native, Expo and the web, sent to your own hush server. No advertising ids, no IP addresses.
