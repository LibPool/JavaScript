## 简介

Arc module for @classytic/cart — owns the cart + checkout resource layer (get/add/update/remove, guest merge, checkout start/commit/cancel, admin) over a BYO cart engine, exported at fastify.arc.modules.cart. The host injects only the engine, permission g
