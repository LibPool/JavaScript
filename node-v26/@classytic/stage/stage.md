# @classytic/stage

> 标签: coordinate-system, diagram, draggable, engine, geometry, interactive, math, primitives, react, svg, visualization

## 简介

Domain-neutral visual primitive engine for the web. Declarative SVG diagram/math primitives, draggable handles, a math↔pixel coordinate system, a motion core + energy effect defs, theming, pure sim cores, and a small kit of neutral glyph primitives. React
