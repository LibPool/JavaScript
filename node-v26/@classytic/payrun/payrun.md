# @classytic/payrun

> 标签: classytic, commission, compensation, contractor-billing, hrms, mongokit, payroll, payrun, payslip, salary, stipend

## 简介

Universal payroll-run engine — framework-agnostic, subject-polymorphic, calculator-pluggable. One engine for corporate payroll, contractor billing, student stipends, commission payouts. Powered by @classytic/mongokit.
