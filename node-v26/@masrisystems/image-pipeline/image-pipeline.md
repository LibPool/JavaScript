# @masrisystems/image-pipeline

> 标签: cloudflare-r2, exif, exiftool, geotag, image, iptc, local-seo, lqip, optimization, seo, sharp, thumbnail, webp

## 简介

Config-driven image pipeline: WebP + JPEG variants, LQIP thumbnails, GPS/IPTC/EXIF geotagging, keyword-based SEO filenames, and optional S3/R2 upload.
