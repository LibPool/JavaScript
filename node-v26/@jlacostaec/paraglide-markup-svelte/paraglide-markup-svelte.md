# @jlacostaec/paraglide-markup-svelte

> 标签: i18n, inlang, markup, paraglide, svelte, svelte5, tailwindcss

## 简介

Type-safe Svelte 5 renderers for Paraglide messages that contain markup, with a default CSS build and a Tailwind build.
