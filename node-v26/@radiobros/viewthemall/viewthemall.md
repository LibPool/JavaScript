# @radiobros/viewthemall

> 标签: csv, document-viewer, docx, epub, file-preview, markdown, odt, pdf, pptx, typescript, xlsx

## 简介

Preview any file. One library. Framework-agnostic TypeScript library that normalizes every common file format into a unified model, then renders it with a single engine.
