> 标签: agents, anthropic, claude, cognipeer, langchain, langgraph, llm, n8n, observability, openai-agents, opentelemetry, tracing, vercel-ai-sdk

## 简介

Ship agent traces from OpenAI Agents, Claude Agent SDK, LangChain, LangGraph, Vercel AI SDK, n8n and any OpenTelemetry-instrumented agent into Cognipeer Console.
