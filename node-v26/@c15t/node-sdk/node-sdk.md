# @c15t/node-sdk

> 标签: c15t, ccpa, cmp, consent, consent-api, consent-management, consent-records, cookie-consent, gdpr, lgpd, node, nodejs, privacy, sdk, self-hosted-cmp, server-side, typescript

## 简介

Node.js SDK for the c15t consent API. Check GDPR consent before sending email, link users, record consents and publish legal documents from server code.
