# @c15t/cli

> 标签: c15t, ccpa, cli, cmp, codegen, codemod, consent, consent-management, consent-mode-v2, cookie, cookie-banner, cookie-consent, gdpr, iab-tcf, lgpd, migrations, nextjs, privacy, react, scaffold, self-hosted-cmp, tcf, typescript

## 简介

Cookie consent setup CLI for c15t. Scaffolds GDPR cookie banners for React, Next.js and other frameworks, configures hosted, self-hosted or offline mode, and adds consent integrations.
