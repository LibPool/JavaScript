# @mcpfusion/cloudflare

> 标签: ai, cloudflare, edge, llm, mcp, mcpfusion, serverless, wintercg, workers

## 简介

Cloudflare Workers adapter for MCP Fusion. Deploys your MCP server to the edge with zero config — stateless JSON-RPC, cold-start caching, and native env injection.
