# @mcpfusion/n8n

> 标签: ai, automation, connector, llm, mcp, mcpfusion, n8n, workflow

## 简介

n8n connector for MCP Fusion. Auto-discovers webhook workflows and produces ToolBuilders — so AI agents can call your automations natively.
