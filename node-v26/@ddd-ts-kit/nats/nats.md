# @ddd-ts-kit/nats

> 标签: clean-architecture, ddd, domain-driven-design, event-driven, hexagonal-architecture, integration-events, jetstream, nats, transactional-outbox, typescript

## 简介

NATS JetStream provider for integration events: acknowledged publishing with message deduplication for the outbox relay, one durable consumer per consumer, explicit acknowledgement, bounded redelivery and a dead-letter subject.
