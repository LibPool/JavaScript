# @ddd-ts-kit/drizzle

> 标签: clean-architecture, ddd, domain-driven-design, drizzle, drizzle-orm, hexagonal-architecture, postgresql, repository-pattern, transactional-outbox, typescript, unit-of-work

## 简介

Drizzle adapters for the kernel ports on PostgreSQL: unit of work, transactional outbox store, processed-event store, event store, background job store, process store, one schema per context.
