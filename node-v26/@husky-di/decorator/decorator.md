# @husky-di/decorator

> 标签: JavaScript

## 简介

`@husky-di/decorator` adds decorator support to husky-di. It translates TypeScript decorator metadata into `@husky-di/core` resolution behavior, so you can declare dependencies directly on constructor parameters.
