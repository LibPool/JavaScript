# @promptjuggler/browser

> 标签: ai, llm, promptjuggler, sdk, sse, streaming

## 简介

Browser SDK for PromptJuggler — subscribe to live token streams with a thread-scoped credential. Everything here is safe to ship to an end user's browser.
