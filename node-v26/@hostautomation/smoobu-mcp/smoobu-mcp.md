# @hostautomation/smoobu-mcp

> 标签: ai, claude, mcp, model-context-protocol, pms, smoobu, vacation-rental

## 简介

Model Context Protocol (MCP) server for the Smoobu vacation-rental PMS API. Lets Claude read and (optionally) write apartments, reservations, rates and guest messages.
