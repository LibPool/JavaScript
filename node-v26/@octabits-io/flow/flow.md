# @octabits-io/flow

> 标签: ai, dag, durable-execution, llm, orchestration, pg-boss, postgres, workflow, zod

## 简介

Durable DAG workflow engine: Zod-typed steps over Postgres + pg-boss, with an optional AI add-on (token/cost/quota). Layered single package.
