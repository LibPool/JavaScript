# @octabits-io/foundation

> 标签: JavaScript

## 简介

Core utilities: Result types, IoC container, logger, helpers, Zod config fragments, RBAC engine, OIDC/JWT validation, Vault secret loader, a provider-agnostic captcha contract, PII encryption, Drizzle ORM toolkit, and iCal ingestion
