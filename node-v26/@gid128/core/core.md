# @gid128/core

> 标签: browser, crypto, gid, gid128, identifier, ksuid, nanoid, node, public-token, sortable-id, timestamp, ulid, uuid

## 简介

GID-128 sortable 128-bit identifiers with Rust-native Node support, 22-character text, and opaque public tokens.
