# @coatcheck/core

> 标签: agents, ai-agents, browser-automation, cdp, credential-broker, credentials, hmac, https-proxy, mitm, playwright, proxy, request-signing, secrets, security, sidecar, sigv4

## 简介

Credential broker for AI agents: agents hold short-lived tickets; real secrets are swapped in on the wire (HTTPS + browser/CDP), and AWS SigV4 / HMAC requests are re-signed, with unmodified tools.
