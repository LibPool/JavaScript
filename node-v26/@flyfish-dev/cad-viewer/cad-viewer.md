# @flyfish-dev/cad-viewer

> 标签: autocad, cad, cad-viewer, canvas, dwf, dwf-viewer, dwfx, dwg, dxf, frontend, gpu, libredwg, linetype, shx, typescript, viewer, w2d, w3d, wasm, web-worker, webgl, xps

## 简介

A production-oriented browser CAD viewer for DWG, DXF, DWF, DWFx and XPS with worker-backed LibreDWG WASM, WebGL/Canvas rendering, external SHX references and native DWF support.
