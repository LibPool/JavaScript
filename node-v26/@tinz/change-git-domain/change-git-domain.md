# @tinz/change-git-domain

> 标签: JavaScript

## 简介

git 远程仓库从旧地址迁移到新地址，批量修改指定目录下的 git 仓库的远程地址

## 官网

- npm 页面：https://www.npmjs.com/package/@tinz/change-git-domain

- npm registry：https://registry.npmjs.org/@tinz/change-git-domain
