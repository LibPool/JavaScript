# @ahlner/opencode-edenai-catalog

> 标签: edenai, model-catalog, opencode, plugin, provider

## 简介

This OpenCode V2 plugin adds the current model catalog to the Eden AI EU provider. The catalog contains models, capabilities, context limits, and prices.
