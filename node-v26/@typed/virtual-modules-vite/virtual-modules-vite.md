# @typed/virtual-modules-vite

> 标签: JavaScript

## 简介

Vite plugin that integrates [@typed/virtual-modules](../virtual-modules) for virtual module resolution and loading in both dev and build. Enables compile-time code generation—imports like `virtual:config` or `api:./routes` resolve to generated TypeScript
