# @art-design-digital/payload-plugin-menus

> 标签: cms, menu, payload, plugin, react, typescript

## 简介

A Payload plugin for menus. This plugin adds a global collection of menus to your Payload instance. You can create and manage menus in the admin interface, and then render them in your frontend application.
