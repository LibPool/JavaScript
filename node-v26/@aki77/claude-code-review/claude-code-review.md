# @aki77/claude-code-review

> 标签: JavaScript

## 简介

Claude Agent SDK を使ったコードレビュー CLI。**位置解決・検証・フィルタ適用・構造転写は コードで行い、LLM には意味判断のみを任せる**設計により、オーケストレーション分の LLM トークンを削減する。
