> 标签: ats, cli, cv, mcp, mcp-server, model-context-protocol, pdf, react-pdf, resume, yaml

## 简介

CVX — structured input, professional output. YAML content in, pixel-perfect CV PDFs out; swappable themes and layouts, no headless browser. MCP server included. Formerly makecv.
