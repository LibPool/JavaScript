# @qgynisc/dsh-inline-pastes

> 标签: attachment, deepseek, deepseek-harness, dsh, dsh-plugin, inline-image, paste, web-ui

## 简介

把粘贴的图片作为「名字胶囊」插进文字里，悬浮名字即可预览缩略图（DeepSeek Harness Web GUI 客户端插件）
