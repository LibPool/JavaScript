# @anygap/anycode

> 标签: agent, anycode, anygap, cli, coding-agent, llm, mcp

## 简介

AnyCode — a coding-agent CLI for Anygap (anygap.ir): an agentic tool-use REPL with plan mode, approval-with-diff, MCP, themes, and a chalk-rendered terminal UI.
