# @letsping/sdk

> 标签: agent, behavioral-firewall, cryo-sleep, hitl, human-in-the-loop, langgraph, letsping, state-parking, vercel-ai

## 简介

Agent trust layer: behavioral firewall, HITL, and Cryo-Sleep state for AI agents. Works with LangGraph, Vercel AI SDK, and custom runners.
