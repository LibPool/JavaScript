# @wise-old-man/utils

> 标签: api, oldschool, osrs, runescape, wiseoldman, wom

## 简介

A JavaScript/TypeScript client that interfaces and consumes the Wise Old Man API, an API that tracks and measures players' progress in Old School Runescape.
