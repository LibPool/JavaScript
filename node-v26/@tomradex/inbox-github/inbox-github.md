# @tomradex/inbox-github

> 标签: tomrade, tomrade-plugin, types

## 简介

GitHub issues as an inbox source: the issues of a project's repositories, answered with comments and closed once their ticket ships — declarations for full-mode plugins; Tomrade provides the code at run time
