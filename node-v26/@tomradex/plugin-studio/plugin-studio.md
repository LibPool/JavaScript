# @tomradex/plugin-studio

> 标签: tomrade, tomrade-plugin, types

## 简介

Plugin Studio: tools and a playbook for an agent to write, test and hand over a plugin, which loads only at a build a person confirmed — declarations for full-mode plugins; Tomrade provides the code at run time
