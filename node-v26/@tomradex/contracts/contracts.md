# @tomradex/contracts

> 标签: tomrade, tomrade-plugin, types

## 简介

What packages read of each other's services, named once, and the small helpers they share: errorMessage, bestEffort, atomic JSON files. Backend only. — declarations for full-mode plugins; Tomrade provides the code at run time
