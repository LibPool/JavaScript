# @gxx-labs/delivery-board-dsh

> 标签: cordis, dashboard, deepseek-harness, delivery, dsh, dsh-plugin, kanban, project

## 简介

DSH 插件：左侧栏「项目管理」入口 + 多项目交付看板，首页一览各项目进度与关键状态，点入查看详情；数据落到本机 JSON 文件。UI 复用 DSH 设计系统 primitives 与 --dsw-* 令牌。
