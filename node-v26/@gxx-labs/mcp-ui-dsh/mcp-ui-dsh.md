# @gxx-labs/mcp-ui-dsh

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, mcp, model-context-protocol, settings

## 简介

DSH 插件：设置 →「MCP」页签，紧凑可折叠列表 + 表单/JSON 配置 MCP 服务，保存即生效，并展示每个服务已注册的工具。UI 复用 DSH 设计令牌与 primitives。
