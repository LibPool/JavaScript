# @gxx-labs/session-manager-dsh

> 标签: archive, cordis, deepseek-harness, dsh, dsh-plugin, session, settings

## 简介

DSH 插件：设置 →「会话管理」页签，批量管理已归档会话（批量取消归档 / 批量归档 / 彻底删除会话及其磁盘文件）。UI 复用 DSH 设计令牌与 primitives。
