# @mcp-verify/sdk

> 标签: anthropic, claude, mcp, model-context-protocol, testing, validation

## 简介

MCPVerify SDK — captures MCP server protocol traces and ships them to mcpverify.dev for cloud-side validation. Find spec violations, security issues, and compatibility gaps in your MCP server.
