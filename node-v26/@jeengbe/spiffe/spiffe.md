# @jeengbe/spiffe

> 标签: authentication, bun, confluent, deno, identity, javascript, jwt, jwt-svid, kafka, kafkajs, node, nodejs, spiffe, spire, svid, typescript, workload-api, workload-identity, workload-identity-federation, zero-trust

## 简介

SPIFFE Workload API client for Node.js, Deno, and Bun. Fetch and validate JWT-SVIDs from SPIRE, with caching and retries.
