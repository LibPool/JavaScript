# @romanbsd/mnemon-eve

> 标签: agent, eve, eve-memory, memory, mnemon, multi-tenant, rls

## 简介

Eve memory provider backed by Mnemon: organization and per-user memory with PostgreSQL RLS and a Jev write gate.
