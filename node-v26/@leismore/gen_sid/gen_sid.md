# @leismore/gen_sid

> 标签: CLI, Command-Line, Generator, Interface, Node.js, UID

## 简介

Short UID Generator (Command Line Tool). This program generates URL-friendly ( a-z A-Z 0-9 and - _ ) unique ID. DO NOT USE IT WITH CRYPTOGRAPHICAL PURPOSE!
