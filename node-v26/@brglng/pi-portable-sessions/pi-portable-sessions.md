# @brglng/pi-portable-sessions

> 标签: coding-agent, directory, paths, pi, pi-coding-agent, pi-extension, pi-package, portable, sessions

## 简介

Portable session directory names for the Pi coding agent: rename the per-project session storage directory to a machine-independent form (home prefix -> HOME, other roots -> ROOT, remainder URL-encoded), so the same project maps to the same directory name
