# @tayyabcheema777/smart-name

> 标签: dns, hostname, label, naming, project-name, rfc1035, slug, slugify, subdomain

## 简介

Turn free text into a short, DNS-safe slug (RFC 1035, <=63 chars): distill a persona- and filler-stripped project name from an idea, and safely fit two parts into one 63-char DNS label.
