# @voiceflow/cli

> 标签: agents, ai, ai-agents, automation, chatbot, cli, conversational-ai, customer-experience, llm, vf, voice, voiceflow

## 简介

Voiceflow CLI (vf) — command line for Voiceflow, the AI agent platform for customer experience automation. Manage agents, knowledge bases, workflows, tests, and transcripts from your terminal or CI.
