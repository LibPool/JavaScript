# @mitr-analytics/mcp

> 标签: analytics, claude, cookieless, gemini, mcp, mitr, model-context-protocol, privacy

## 简介

Mitr analytics for Claude, Gemini and other MCP clients: list apps, pull reports and funnels, and ask questions about your own data. Cookie-free analytics, one API key.
