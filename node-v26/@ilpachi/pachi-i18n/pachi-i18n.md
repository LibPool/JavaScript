# @ilpachi/pachi-i18n

> 标签: i18n, ilpachi, locale, pachifast, quasar, typescript, vue, vue-i18n, vue3

## 简介

vue-i18n based i18n for Vue/Quasar apps: instance creation, locale detection and persistence, per-package messages and a language selector.
