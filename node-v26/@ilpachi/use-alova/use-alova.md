# @ilpachi/use-alova

> 标签: ajax, alova, csrf, download, http, overlay, upload, vue, vue3

## 简介

Vue 3 wrapper for alova: auth, response pipelines and centralized error handling, with optional notifications, overlay, file helpers and CSRF
