# @wherabouts/sdk

> 标签: address-autocomplete, g-naf, geocoding, geofencing, international, location, openaddresses, overture, reverse-geocoding, webhooks, wherabouts

## 简介

Official TypeScript SDK for the Wherabouts location API — international geocoding, geofencing zones, device tracking, and webhooks over authoritative open address data (G-NAF, Overture, OpenAddresses, and more).
