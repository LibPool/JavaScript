# @vizchat/mdx-compiler

> 标签: JavaScript

## 简介

VizChat MDX → AST 编译器 + allowlist 校验。widget-scripts 以 in-process import 消费；bin/cli.mjs 另提供 stdin/stdout JSON 协议供跨语言进程边界调用。
