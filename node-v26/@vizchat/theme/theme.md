# @vizchat/theme

> 标签: JavaScript

## 简介

VizChat 设计系统 theme 层单一真值：token(@theme) + @custom-variant + @utility + :root/.dark 变量值。CSS-only，无 React 运行时依赖。被 app globals.css、@vizchat/ui、@vizchat/widget-scripts 三方共用。spec docs/superpowers/specs/2026-07-30-widget-style-supply-design.md §3
