# @almateam/app-sdk

> 标签: JavaScript

## 简介

Types, host bridge and the alma-app dev command for apps that run in Alma. Alma builds every app with its own current copy of the SDK; install this for the types and the command.

## 官网

- 官网：https://docs.alma.team/developers/apps
- npm 页面：https://www.npmjs.com/package/@almateam/app-sdk
