# @webitel/api-services

> 标签: api-services, webitel

## 简介

1. `npm run gen:api` - generate API services (both passes, then prune + dedupe) 2. `npm version patch` - bump version 3. `npm run build:types` - build types 4. `npm run format:all` - format code 5. `npm run publish-lib` - publish library
