# @devground/dev-metrics

> 标签: churn, claude-code, conventional-commits, developer-productivity, devground, git, metrics, time-series, tokens

## 简介

Continuous, labelled time-series of how a developer evolves while coding with AI agents: code volume, quality, velocity and efficiency, computed from git history and Claude Code transcripts
