# @alberteinshutoin/lazy-image-win32-x64-msvc

> 标签: JavaScript

## 简介

Web image optimization engine for Node.js with Image Firewall-backed secure upload defaults and smaller JPEG outputs in canonical PNG → JPEG benchmarks, powered by Rust + mozjpeg
