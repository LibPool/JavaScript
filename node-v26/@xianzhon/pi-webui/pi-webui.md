# @xianzhon/pi-webui

> 标签: ai, coding-agent, developer-tools, pi, webui

## 简介

A self-hosted, mobile-friendly web workspace for the Pi coding agent, with persistent sessions, task queues, memory, file editing, terminals, and Git workflows.
