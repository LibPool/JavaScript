# @ophis/plugin-goat

> 标签: agent, ai-agent, cow-protocol, defi, goat, goat-sdk, ophis, rebate, swap

## 简介

GOAT SDK plugin: let an AI agent swap ERC-20s via Ophis (CoW Protocol), with the Ophis partner fee + your referral code in appData so you earn the 8-12% rebate.
