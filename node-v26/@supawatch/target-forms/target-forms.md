# @supawatch/target-forms

> 标签: codegen, forms, postgres, postgresql, react-hook-form, schema, supabase, tanstack-form, typescript

## 简介

Framework-agnostic form field configs generated from live Postgres by supawatch: controls, labels, requiredness, enum options.
