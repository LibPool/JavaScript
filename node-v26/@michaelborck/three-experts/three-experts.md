# @michaelborck/three-experts

> 标签: ai-prompts, claude-code, documentation, product-requirements, slash-commands, software-architecture, ux-design

## 简介

A Node.js npm package that adds custom slash commands to claude-code for generating Product Requirements Documents, User Interface Design Documents, and Software Requirements Specifications using AI-powered expert prompts.
