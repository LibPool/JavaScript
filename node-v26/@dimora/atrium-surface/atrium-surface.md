# @dimora/atrium-surface

> 标签: JavaScript

## 简介

Atrium's dual-surface layer: the host<->UI wire protocol, the postMessage (editor) + SSE (browser) transports, the loopback web host, and the webview DOM bundle. Pure — no vscode. Every Atrium host renders through it.
