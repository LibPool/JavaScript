# @jusor-hub/mcp

> 标签: ai-tools, jusor, mcp, model-context-protocol

## 简介

Model Context Protocol server for Jusor Hub — exposes the Hub API to MCP-aware AI tools (Claude Desktop, Claude Code, Cursor, ChatGPT) so the team can read and write Hub data on behalf of themselves without leaving their AI workflow.
