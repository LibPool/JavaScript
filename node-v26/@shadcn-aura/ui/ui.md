# @shadcn-aura/ui

> 标签: backend-driven, config-driven, dashboard, json-driven, low-code, react, shadcn, shadcn-ui, ui-library

## 简介

JSON-driven UI platform built on shadcn/ui. Pass a theme + JSON config (served by any backend) and render a full platform shell, pages and widgets.
