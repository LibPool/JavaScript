# @frontpanel/css

> 标签: chrome, css, design-system, skeuomorphic, tailwindcss, ui-kit, y2k

## 简介

Early-2000s hardware skin as plain CSS: liquid-chrome bezels, gel buttons, LCDs and LEDs. Tokens, classes and an optional Tailwind 4 entry.
