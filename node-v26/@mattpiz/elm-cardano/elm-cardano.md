# @mattpiz/elm-cardano

> 标签: JavaScript

## 简介

Elm offchain package for Cardano. This project aims to be the friendliest and most productive way of handling an offchain Cardano frontend. It should be a perfect match to [Aiken][aiken] for onchain code.
