# @tomosaigon/dhtfs

> 标签: bittorrent, dht

## 简介

DHTfs is a file storage protocol on top of BitTorrent’s DHT. Posting files is permissionless and the network has the censorship resistant properties of BitTorrent. Every file can be retrieved with a 20 byte hash. While this implementation uses BitTorrent
