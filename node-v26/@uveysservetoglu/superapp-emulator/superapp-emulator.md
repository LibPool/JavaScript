# @uveysservetoglu/superapp-emulator

> 标签: 1de, emulator, kobil, miniapp, mpower, oidc, silent-sso, superapp

## 简介

Composable browser emulator for KOBIL SuperApp MiniApps. Pixel-accurate container chrome, real OIDC/PKCE Silent SSO, the KOBIL MiniApp API (chat, push, signing, payment, TMS) and deep links — as a custom element with a full SDK.
