# @frontmcp/ui

> 标签: agentfront, components, frontmcp, mcp, mcp-apps, model-context-protocol, mui, react, renderers, ui, widgets

## 简介

React components, bridge hooks and content renderers (built on MUI) for FrontMCP tool widgets in ChatGPT, Claude and other MCP Apps hosts
