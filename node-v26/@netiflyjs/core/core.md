# @netiflyjs/core

> 标签: netifly, nodejs, notifications, pubsub, realtime, redis, websocket, websockets

## 简介

Framework-agnostic real-time notification core for Node.js servers, backed by WebSockets and a pluggable transport (Redis by default).
