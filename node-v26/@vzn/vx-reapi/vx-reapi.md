# @vzn/vx-reapi

> 标签: bazel, monorepo, reapi, remote-cache, remote-execution, vx, vx-plugin

## 简介

Bazel Remote Execution API plugin for vx — remote cache (ActionCache + CAS) against NativeLink, BuildBuddy, Buildbarn or bazel-remote.
