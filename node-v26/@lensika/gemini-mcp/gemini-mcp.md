# @lensika/gemini-mcp

> 标签: Gemini, Imagen, Lensika, MCP, Nano Banana, Server

## 简介

MCP server exposing Google Gemini image generation — both Imagen 4 and Gemini 2.5 Flash Image (Nano Banana) with Identity Locking via reference images.
