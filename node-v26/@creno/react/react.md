# @creno/react

> 标签: api-client, appointment-scheduling, booking, calendar, react, scheduling

## 简介

Themeable React booking widget for Creno (https://crenoapp.com): real-time availability, service-type menus, and optional Cloudflare Turnstile bot protection.
