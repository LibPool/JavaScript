# novacrm-mcp

> 标签: ai, claude, claude-code, crm, cursor, e-commerce, gemini, mcp, model-context-protocol, novacrm

## 简介

Servidor MCP (Model Context Protocol) oficial do NovaCRM — conecta IAs como Claude Desktop, Cursor, Claude Code e Gemini CLI à sua loja através da API pública v1.
