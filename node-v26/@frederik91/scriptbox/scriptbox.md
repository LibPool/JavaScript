# @frederik91/scriptbox

> 标签: agents, ai, code-execution, javascript, llm, quickjs, sandbox, typescript, wasm

## 简介

Let an AI model write JavaScript or TypeScript against your Node.js API. ScriptBox runs it in a QuickJS WebAssembly sandbox where it reaches only the methods you register, your schemas and policies check every call, and hard limits stop runaway code.
