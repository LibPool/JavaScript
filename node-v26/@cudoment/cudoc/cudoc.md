# @cudoment/cudoc

> 标签: ast, cudoc, documentation, markdown, mdast, mdx

## 简介

Document ASTs for documentation sites: Markdown compilation and syntax normalization, cross-document embedding, reference checking, datasets and the cudoc CLI.
