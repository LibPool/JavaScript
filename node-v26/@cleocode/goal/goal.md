# @cleocode/goal

> 标签: agent, autonomous, cleo, cleo-goal, goal, goal-mode, harness, opencode, opencode-plugin

## 简介

CLEO Goal: persistent, host-verified goal mode for OpenCode 2 (and any harness through cleo-goal tick), with a structured goal contract and a live TUI.
