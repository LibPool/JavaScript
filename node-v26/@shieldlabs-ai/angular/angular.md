# @shieldlabs-ai/angular

> 标签: angular, device-intelligence, fraud-detection, identification, risk-score, shieldlabs, signals

## 简介

Angular bindings for ShieldLabs device intelligence: a provider that loads the agent once, signals for its state and an identify helper that returns a request ID for your backend.
