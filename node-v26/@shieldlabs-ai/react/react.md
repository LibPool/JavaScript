# @shieldlabs-ai/react

> 标签: device-intelligence, fraud-detection, identification, react, react-hooks, risk-score, shieldlabs

## 简介

React bindings for ShieldLabs device intelligence: a provider that loads the agent once and hooks that return a request ID for every identification.
