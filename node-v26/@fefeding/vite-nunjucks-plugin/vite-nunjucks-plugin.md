# @fefeding/vite-nunjucks-plugin

> 标签: JavaScript

## 简介

🔧 一个专为 Vite 设计的 **轻量级 Nunjucks 模板插件**，支持核心语法：**变量替换**、**条件判断**和**模板包含**，未传入的变量会保持原样不报错。
