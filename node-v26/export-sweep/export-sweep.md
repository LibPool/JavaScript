# export-sweep

> 标签: cli, dead-code, exports, javascript, knip, lint, ts-prune, typescript, unused, unused-exports

## 简介

Find exports nobody imports in TypeScript and JavaScript projects, plus files nothing uses. Follows re-exports, path aliases and dynamic imports. Zero dependencies, works with any TypeScript version.
