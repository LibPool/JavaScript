# @meshioplusplus/wasm

> 标签: fem, finite-elements, gmsh, mesh, obj, scientific-computing, stl, vtk, vtu, wasm, webassembly

## 简介

meshio++ mesh I/O compiled to WebAssembly: read 46 and write 49 mesh formats (incl. MED, CGNS, Exodus) in the browser or Node.js
