# @ibarcarty/mcp-server-google-drive

> 标签: ai, claude, gfm, google-calendar, google-docs, google-drive, google-sheets, google-slides, google-workspace, llm, markdown, mcp, mcp-server, model-context-protocol, shared-drives, tools

## 简介

MCP server for Google Drive, Google Docs, Google Sheets, Google Slides, and Google Calendar with full read/write operations, rich markdown-to-docs formatting, theming, shared drive support, and OAuth2 authentication
