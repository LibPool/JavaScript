# @bdd-suite/runtime

> 标签: bdd, gherkin, jest, mocha, node-test, suite, testing, vitest, yaml

## 简介

The TypeScript runtime of the BDD suite format: suiterun lint, run, list and actions, an in-process linter for editors, and an extension API for adding actions, context keys, options and rules.
