# @ferrow/api-documentation

> 标签: api-documentation, codegen, openapi, swagger, typescript

## 简介

OpenAPI 3.0 generator from code-defined routes: define(method, path, {...}) with a tiny schema notation, emit valid openapi.json plus a markdown reference. Zero dependencies.
