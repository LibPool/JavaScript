# @ferrow/llm-cost-estimator

> 标签: ai-agents, anthropic, billing, cost-tracking, llm, openai, tokens, usage-tracking

## 简介

LLM usage cost accounting — you supply the price table, this accumulates per-model/label cost breakdowns, projections, budget alerts, and CSV/JSON export. Zero runtime dependencies.
