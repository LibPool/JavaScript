# @opaquecash/privacy-pool

> 标签: JavaScript

## 简介

Privacy pool client: deposit commitments, Poseidon Merkle trees, withdrawal witness + Groth16 proof generation, deposit/withdraw tx building, and association-set resolution (chain reconstruction + ENS/IPFS manifest) (spec/privacy-pool.md)
