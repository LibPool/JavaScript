# @geoapify/route-planner-sdk

> 标签: delivery route optimization, delivery scheduling, fleet management, geoapify, last mile delivery, logistics planning, map routing, multi-agent routing, route editor, route optimization, route optimization sdk, route planner, route planning sdk, route visualization, traveling salesman problem, tsp, tsp route planner, vehicle routing problem, vrp

## 简介

TypeScript SDK for the Geoapify Route Planner API. Supports route optimization, delivery planning, and timeline visualization in browser and Node.js
