# @koishi-ce/loader-shim

> 标签: JavaScript

## 简介

上游包名 @koishijs/loader 的下游兼容 shim：供脚手架生成的项目以 npm alias（"@koishijs/loader": "npm:@koishi-ce/loader-shim@^4.6.11"）钉住该名，把 @koishi-ce/plugin-config / plugin-hmr 声明的 loader peer 指回 @koishi-ce/loader，避免 Bun 的 peer 自动安装拉下 npm 官方 loader 副本。版本冻结 4.6.x 线以满足 ^4.6 pee
