# @ts-capture/babel-plugin

> 标签: babel, babel-plugin, ts-capture, type-inference, types, typescript

## 简介

ts-capture Babel plugin — instrument TS/JS at compile time so test runs collect type observations. (0.x — API may change between minor versions.)
