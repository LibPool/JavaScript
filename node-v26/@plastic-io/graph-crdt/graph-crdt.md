# @plastic-io/graph-crdt

> 标签: JavaScript

## 简介

Shared Yjs CRDT schema, codec and reconciler for Plastic-IO graphs.  Used by both the graph editor and the graph server, so it must never import Vue, Pinia, or any browser/node specific API.
