# @scoova/geofences-react-native

> 标签: geofence, geofences, point-in-polygon, polygon, react-native, scoova

## 简介

React Native wrapper around @scoova/geofences — re-exports the standalone client plus a useGeofences() hook + <ScoovaGeofencesProvider/>. No native modules.
