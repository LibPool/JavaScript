# @sadmap/chat-cli

> 标签: agent, bridge, chatgpt, cli, coding-agent, mcp, model-context-protocol, terminal-ui

## 简介

Headless local coding bridge for ChatGPT over MCP: approved-folder filesystem and terminal tools, session recording, multi-agent workers, and a terminal UI. Ships with a Chrome MV3 companion extension.
