# @click-to-source-3d/vite-plugin

> 标签: devtools, inspector, r3f, react-three-fiber, threejs, vite, vite-plugin

## 简介

Inspect any object in a React Three Fiber scene: see the line that created it and edit its values. Vite plugin for Click-to-Source 3D.
