# @simplr-ai/express

> 标签: express, fastify, fraud, hono, identity, middleware, next, server, simplr

## 简介

Drop-in server middleware for Express, Fastify, Hono, and Next.js that auto-runs Simplr fraud/identity checks and ingests edge logs per request. Built on @simplr-ai/node.
