# @hanexis/agentic-sdk-client

> 标签: agentic, ai-agent, llm, mongodb, sdk-client

## 简介

Thin client library for the standalone Hanexis Agentic AI SDK service — start a turn, stream results, and implement the query-callback contract without hand-rolling the HTTP plumbing.
