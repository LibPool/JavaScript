> 标签: agent-tools, ai-agent, defi, function-calling, llm-tools, sperax, sperax-web-browsing, speraxos, tool-calling, web3

## 简介

Search the web and read pages — run a query across search engines, then crawl one page or many to pull their full text into the conversation. — an agent tool for SperaxOS.
