# @wasm-gaming/rsdkv3-wasm

> 标签: JavaScript

## 简介

RSDKv3 (Retro Software Development Kit v3) compiled to WebAssembly, with a JS SDK conforming to the wasm-gaming engine contract. Runs Sonic CD by loading Data.rsdk at runtime.
