# @calldatasdk/sdk

> 标签: calldata, command bus, ethereum, ethers, evm, json, no wallet connect, signed commands, web3

## 简介

Calldata Network SDK: drive any backend on Ethereum with signed JSON commands carried in transaction calldata. Build, sign and send commands, no wallet connection.

- 官网：https://calldata.network
- npm 页面：https://www.npmjs.com/package/@calldatasdk/sdk
