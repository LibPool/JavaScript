# @b0ase/pathd

> 标签: bitcoin, bsv, identity, micropayments, path-protocol, tokens, x402

## 简介

The path client — modular Bitcoin OS runtime. Imports path401 (identity), path402 (content/payment), and path403 (conditions) to serve tokenized applications.
