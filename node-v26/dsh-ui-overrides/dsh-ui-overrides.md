# dsh-ui-overrides

> 标签: css, customization, deepseek-harness, dsh, dsh-plugin, opacity, ui

## 简介

Inject user-owned CSS into the DeepSeek Harness Web UI to override the appearance of any plugin's elements — fully opaque floating panels, custom colors, spacing, anything CSS can target.
