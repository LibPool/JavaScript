# @iden-q/scanner-lib

> 标签: JavaScript

## 简介

Post-quantum cryptography exposure scanner — detects RSA/ECDSA/DSA/DH, weak hashes, and exposed wallet keys/JWTs in files, source code, and TLS certificates.
