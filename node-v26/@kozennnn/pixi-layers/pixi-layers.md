# @kozennnn/pixi-layers

> 标签: JavaScript

## 简介

PixiJS v5 plugin, allows to change rendering order of containers without changing the scene graph.

- 官网：http://www.pixijs.com/
- 源码仓库：git+https://github.com/pixijs/pixi-layers.git
