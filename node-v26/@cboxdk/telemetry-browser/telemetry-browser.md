# @cboxdk/telemetry-browser

> 标签: laravel, observability, opentelemetry, rum, telemetry, tracing, web-vitals

## 简介

Deep browser RUM SDK for cboxdk/laravel-telemetry — page load, Web Vitals, fetch/XHR, errors and SPA routes, correlated with your backend traces.
