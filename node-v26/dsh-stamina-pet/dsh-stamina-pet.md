# dsh-stamina-pet

> 标签: attention, dsh, dsh-plugin, fatigue, inheritance, pet, stamina

## 简介

DSH 体力条桌宠：按注意力状态给每个会话算一条体力条，点一下把会话里的大肥鱼叫到桌面上，再点一下收回。附带一套完整的「传承」流程（四份文件 / 体检 / 归档）。
