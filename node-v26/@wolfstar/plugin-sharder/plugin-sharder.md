# @wolfstar/plugin-sharder

> 标签: cluster, discord, gateway, http-framework, ipc, plugin, sharding, wolfstar, worker-threads

## 简介

Multi-process sharding for @wolfstar/plugin-gateway: spawn shards as processes, cluster workers, or worker threads, and message between them
