# @apollo-tech/expressway

> 标签: api, express, node, openapi, rest, swagger, typescript

## 简介

An npm package using TypeScript that simplifies creating Express APIs by defining classes for each key component (app = ExpressWay, router = Road, route = Lane, etc).
