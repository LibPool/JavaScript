# ed25519-keygen

> 标签: GPG, PGP, RFC 4880, RFC 6637, SSH, TOR, ec, ed25519, elliptic, key generation, onion

## 简介

Generate ed25519 keys for SSH, PGP (GPG), TOR, IPNS and SLIP-0010 hdkey
