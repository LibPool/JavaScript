# entrapulse-polyarchy

> 标签: ai, azure-ad, claude, entra, graph, identity, mcp, mcp-app, microsoft, polyarchy, visualization

## 简介

EntraPulse Polyarchy — an interactive Microsoft Entra ID identity relationship visualization served as an MCP App. The polyarchy Microsoft demoed in 2003 and never shipped, rendered live inside your MCP client.
