# eve-cls-observability

> 标签: agent, cls, eve, llm-observability, observability, opentelemetry, tencent-cloud, tracing

## 简介

Tencent Cloud CLS Agent observability provider for eve agents. Emits CLS Agent Trace spec spans over the native UploadLog API with a zero-dependency client.
