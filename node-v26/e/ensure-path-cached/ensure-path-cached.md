# ensure-path-cached

> 标签: cache, dir, ensure, esm, path, periodic

## 简介

native ES6 ESM module, ensures path exits, shortcut for ensuring periodic dir, uses cache to avoid unnecessarily accessing remote fs, i.e., NFS/EFS
