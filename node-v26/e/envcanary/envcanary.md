# envcanary

> 标签: 12factor, ci-cd, config, configuration, contract, dotenv, drift, env, environment-variables, next, provenance, sarif, secrets, twelve-factor, validation, vite

## 简介

Configuration contract, provenance and drift-detection engine for applications and CI/CD. Discovers env-var usage in code, validates it against a typed contract, and detects missing/extra/unsafe configuration. Secret-safe, zero dependencies, fully offline
