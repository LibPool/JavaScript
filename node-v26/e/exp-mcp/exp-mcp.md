# exp-mcp

> 标签: exp, feature-flags, feature-toggles, mcp, model-context-protocol, rbac

## 简介

MCP server for exp, the feature-flag service: manage projects, environments and flags, toggle per-environment states, preview evaluations, with role-based tool access and audit logging.
