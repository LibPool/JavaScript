> 标签: deliverability, dkim, dmarc, dns, email, mcp, model-context-protocol, smtp, spf, swift

## 简介

Email infrastructure fingerprinting as an MCP server and a CLI. Provider detection, SPF/DKIM/DMARC posture graded A+ to F, header analysis. macOS, zero dependencies.
