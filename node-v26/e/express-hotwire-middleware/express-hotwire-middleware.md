# express-hotwire-middleware

> 标签: JavaScript

## 简介

A lightweight TypeScript middleware for [Express](https://expressjs.com/) to seamlessly handle [Hotwire Turbo](https://turbo.hotwired.dev/) requests. This middleware simplifies detecting Turbo Frame requests and sending Turbo Stream responses.
