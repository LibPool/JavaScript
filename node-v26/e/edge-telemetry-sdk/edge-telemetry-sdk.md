# edge-telemetry-sdk

> 标签: analytics, android, crash-reporting, ios, monitoring, observability, performance, react, react-native, sdk, telemetry, user-profiles, web

## 简介

A lightweight React Native SDK for collecting mobile app telemetry and exporting it to custom backends in JSON format. Built for flexible and developer-friendly observability.
