> 标签: atomic-css, autofix, blocklist, codemod, eslint, eslint-plugin, eslintplugin, nuxt, nuxt-module, shortcuts, themes, unocss, vue

## 简介

Normalizes UnoCSS class attributes from your own uno.config - and proves every rewrite generates identical CSS before it applies one.
