# express-asset-manifest

> 标签: asset, assets, express, expressjs, fingerprint, manifest, path, replace, rev, revision, static, view, views

## 简介

Middleware which resolves requests based on generic filenames to the associated file fingerprint outlined in a manifest file. Now including asset manifest support.
