# eslint-plugin-biological-ui-arch

> 标签: architecture, atomic-design, component-hierarchy, eslint, eslint-plugin, eslintplugin, oxlint, react

## 简介

Lint rules that enforce a biological tier architecture (atoms, molecules, compounds, organelles, cells, tissues) in React UI codebases. Works with oxlint jsPlugins and ESLint flat config.
