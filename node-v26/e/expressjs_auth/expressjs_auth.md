# expressjs_auth

> 标签: authentication, bcrypt, email-verification, express, jsonwebtoken, mongodb, mongoose, mysql, node

## 简介

expressjs_auth is a fast and flexible authentication solution for Express.js, supporting MySQL and MongoDB with JWT and email verification integration.
