# external-svg-sprite-loader

> 标签: svg, webpack, webpack-loader

## 简介

A webpack loader and plugin that generate SVG sprites out of a collection of SVG files used in your JS and CSS files

## 官网

- 源码仓库：http://github.com/bensampaio/external-svg-sprite-loader.git
- npm 页面：https://www.npmjs.com/package/external-svg-sprite-loader
