# embeddedchat-lz-auth

> 标签: JavaScript

## 简介

This is the `embeddedchat-lz-auth` package, designed to simplify authentication processes in applications using EmbeddedChat. It provides a streamlined and easy-to-use API for handling various authentication methods.
