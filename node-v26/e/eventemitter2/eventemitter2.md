# eventemitter2

> 标签: addEventListener, addListener, emit, emits, emitter, event, eventemitter, events, on, once, pub/sub, publish, subscribe

## 简介

A feature-rich Node.js event emitter implementation with namespaces, wildcards, TTL, async listeners and browser/worker support.
