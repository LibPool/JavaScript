# embedpay-vue

> 标签: JavaScript

## 简介

Vue 3 composables and components for EmbedPay payment processing. Provides useEmbedPay composable and EmbedPayButton component with full TypeScript support. Compatible with Vue 3, Nuxt 3, and Vite.
