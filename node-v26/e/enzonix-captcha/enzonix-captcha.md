# enzonix-captcha

> 标签: bot-protection, captcha, client-library, enzonix, javascript, privacy, proof-of-work, recaptcha, typescript

## 简介

Universal CAPTCHA client library for Enzonix - privacy-focused proof-of-work CAPTCHA service with reCAPTCHA v2 compatibility. Works in both TypeScript and JavaScript projects.
