# elysia-nnn-socket

> 标签: bun, elysia, elysia-nnn-socket, elysia-plugin, rooms, socket.io, websocket

## 简介

Socket.IO-style single-endpoint WebSocket plugin for Elysia — file-based rooms with beforeJoin/onJoin/on/onLeave, namespace events, ack protocol
