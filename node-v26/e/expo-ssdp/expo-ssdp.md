# expo-ssdp

> 标签: chromecast, discovery, dlna, expo, expo-module, iot, network, smart-tv, ssdp, upnp

## 简介

Cross-platform Expo native module for SSDP/UPnP device discovery on local networks. Supports iOS and Android with full New Architecture / Turbo Module compatibility.
