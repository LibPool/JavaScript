# eloqube

> 标签: 3d, animation, art, ascii, cli, cube, eloqube, game, interactive, rubik, terminal

## 简介

Eloqube is a fun and interactive package that renders a rotating 3D cube in the terminal using colored ASCII characters.  That's what it is. Useless? Yep. But fun I guarantee you :)
