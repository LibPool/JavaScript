# expo-native-google-signin

> 标签: android, authentication, credential-manager, expo, expo-native-google-signin, google-sign-in, google-signin, ios, oauth, react-native

## 简介

Native Google Sign-In for Expo apps using Android Credential Manager and the iOS GoogleSignIn SDK — no legacy play-services-auth, no @react-native-google-signin/google-signin dependency.
