# exoframe-recipe-wordpress

> 标签: exoframe, exoframe-recipe, wordpress

## 简介

Wordpress deployment template for [Exoframe](https://github.com/exoframejs/exoframe).   Deploys [Wordpress](https://wordpress.com/) backed by [MariaDB](https://mariadb.org/) along with [PHPMyAdmin](https://www.phpmyadmin.net/).
