# eslint-plugin-redosray

> 标签: catastrophic-backtracking, dos, eslint, eslint-plugin, eslintplugin, redos, regex, security

## 简介

ESLint rule that finds ReDoS-vulnerable regexes and dynamically PROVES which ones actually hang — no false positives on scary-but-safe patterns.
