# excel-tools-mcp

> 标签: csv, excel, excel-tools-mcp, mcp, spreadsheet, xlsx

## 简介

Excel/CSV 读写 MCP：读取/写入 .xlsx 与 CSV，提供 read_excel/write_excel/read_csv/write_csv 工具，纯 JS（xlsx 库）无需本地 Office。
