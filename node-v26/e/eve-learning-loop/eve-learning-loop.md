# eve-learning-loop

> 标签: agent, eve, eve-extension, fts, memory, postgres, self-improving, skills, supabase, turso

## 简介

Hermes-style self-improving loop for Vercel Eve agents: bounded cross-session memory, agent-authored skills that resurface as native skills, full-text session recall (Turso/libSQL or Postgres), and a curator lifecycle.
