# eslint-plugin-fta

> 标签: complexity, eslint, eslintplugin, fta, typescript

## 简介

ESLint plugin for FTA (Fast TypeScript Analyzer) complexity analysis. Enforces file-level complexity thresholds based on FTA's scoring system.
