# equity-treasury-agent

> 标签: ai-agent, asset-tokenization-studio, erc-1400, erc-3643, hedera, hedera-agent-kit, langchain, langgraph, tokenization, treasury

## 简介

LLM-powered enterprise treasury agent that deploys and administers tokenized equity and bonds on Hedera (testnet or mainnet) via the @hebx/hak-ats-plugin Hedera Agent Kit plugin.
