# easy-route-management

> 标签: angular, express, front-end, nested-routes, path-management, react-router, routes, routing, spa, typescript

## 简介

Type-safe route management for JavaScript and TypeScript apps. Define nested routes in a single object and generate dynamic paths with parameters for React Router, Express, Angular, or any framework that uses paths.
