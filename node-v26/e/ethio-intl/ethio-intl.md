# ethio-intl

> 标签: amharic, cultural-computing, ethiopia, ethiopian, ethiopian-calendar, ethiopic, geez-numerals, i18n, internationalization, javascript, localization, oromo, react, sdk, tigrinya, transliteration, typescript

## 简介

A modern JavaScript SDK for Ethiopian web applications with Amharic transliteration, Ethiopian calendar conversion, Geez numerals, and multi-language support
