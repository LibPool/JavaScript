# ecdsa-scan

> 标签: cbom, cryptography, ecdsa, jwt, linter, p-256, post-quantum, sarif, secp256k1, security, signature, static-analysis

## 简介

Static analysis for digital-signature code: JWT algorithm confusion, curve mix-ups, signature-encoding bugs, weak nonces, hardcoded keys and disabled certificate checks. Part of the ecdsa.com signature toolkit — https://ecdsa.com
