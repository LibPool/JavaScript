# ergo-agent-api

> 标签: 402, agent, agent-economy, ai-agent, api, blockchain, ergo, express, middleware, pay-per-request, payments

## 简介

Pay-per-API middleware on top of ergo-agent-pay. Verifies Ergo Notes, enforces replay protection, and (optionally) redeems them — usable with Express, Connect, Fastify (via adapter), or as a pure handler.
