# easy-human-sdk

> 标签: avatar, digital-human, easy, sdk, speech-synthesis, tts, voice, websocket

## 简介

数字人网关代理SDK，提供完整的数字人交互功能，包含数字人管理、音色管理、会话管理和TTS语音合成
