# exact-flatten

> 标签: dot-notation, flatten, i18n, nested, object, paths, roundtrip, unflatten, zero-dependency

## 简介

Flatten an object to path/value pairs and get exactly the same object back — keys containing dots, brackets and digits included. Zero dependencies.
