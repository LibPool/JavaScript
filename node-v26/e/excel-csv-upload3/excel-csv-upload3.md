# excel-csv-upload3

> 标签: JavaScript

## 简介

1) `git clone https://github.com/growthforever/nodejs_upload_file.git` <br> 2) `cd nodejs-excel-uploade.js` <br> 3) `npm install` <br> 4) `node app.js` <br> 5) In your browser `http://localhost:3000` <br> 6) Upload excel file and see result <br>
