# eap-web

> 标签: JavaScript

## 简介

这个模板可以帮助你开始在 Vite 中使用 Vue 3 进行开发。 该模板使用 Vue 3 `<script setup>` SFCs，查看 [script setup docs](https://v3.vuejs.org/api/sfc-script-setup.html#sfc-script-setup) 学习更多。
