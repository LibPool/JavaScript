# ems-web-app-seat-time

> 标签: activity timer, angular, angular.io, educational, educational media solutions, ems, media, module, seat time, solutions, timer, tracker, tracking, web app, web application

## 简介

This angular.io component starts a session timer that pauses after periods of inactivity or when the containg web browser loses focus.
