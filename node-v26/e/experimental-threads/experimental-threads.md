# experimental-threads

> 标签: atomics, bun, concurrency, deno, experimental-threads, multi-threading, multithreading, shared-array-buffer, sharedarraybuffer, thread-pool, threading, threads, web-workers, webworkers, worker-pool, worker-threads

## 简介

Highly experimental multithreading runtime in JavaScript using lexical scope analysis and shared memory rehydration. Works in Deno, Bun and Node.
