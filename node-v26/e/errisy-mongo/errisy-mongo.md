# errisy-mongo

> 标签: TypeScript, access, automation, constrains, data, mongoDB, type, wrap

## 简介

a mongoDB typescript wrap to apply type constrains in mongoDB access. You can use errisy-tsc to automatically generate dateset definitions from *.data.ts.
