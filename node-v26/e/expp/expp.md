# expp

> 标签: JavaScript

## 简介

This is node+mongodb developer framework,includes express、mongoose module.    本框架为node+mongodb后端快速开发框架，集成express、mongoose框架，集成登录、注册、权限等用户模块 #### 【启动】   1 依赖 expp    `npm install expp --save`    2 导入    `require('expp').start(path)`    > path：应用程序目录
