# element-form-create

> 标签: element, form-create, vue

## 简介

Element-Form-Create是以Vue.js + ElementUI开发的动态表单组件，可以兼容大部分ElementUI的表单组件；同时支持局部引入组件、表单联动、嵌套表单、表单验证等功能
