# eidolon-hearth

> 标签: claude, claude-code, eidolon, hooks, installer, skills

## 简介

Installs the Eidolon and Setup skills for Claude Code: previews every write, applies only the plan you approved, keeps backups, verifies the bundled files against a lock. Run npx eidolon-hearth for user skills, or npx eidolon-hearth . to wire a project wi
