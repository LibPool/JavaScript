# encrypt-express

> 标签: aes, aes-256-cbc, crypto, decrypt, encrypt, encryption, express, middleware, nodejs, secure

## 简介

Express middleware to encrypt outgoing JSON responses and decrypt incoming JSON request bodies using AES-256-CBC.
