# eve-coder

> 标签: agent, ai, cli, coding-agent, eve

## 简介

A fully-local coding agent built on eve. npm i -g eve-coder, run `eve-coder` in any directory, and a TUI opens that reads/writes your files on this machine (no sandbox).
