# esque-bridge

> 标签: agent, anthropic, bridge, claude, claude-code, esque, failover, ios, mobile, subscriptions

## 简介

Desktop-side receiver for the Esque Agent mobile app. Pairs your phone with a local coding-agent CLI (Claude Code, Codex, Aider, or any custom command) via a tunnel + QR code, so prompts run through your subscription instead of per-token API billing. Atta
