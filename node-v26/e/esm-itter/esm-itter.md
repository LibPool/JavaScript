# esm-itter

> 标签: ESMitter, EventEmitter, EventEmitter2, EventEmitter3, Events, addEventListener, addListener, deno, emit, emits, emitter, event, jsr, once, pub/sub, publish, reactor, subscribe

## 简介

ESMitter is a fork of the popular EventEmitter3 with a focus on EcmaScript module syntax, TypeScript and modern tooling.
