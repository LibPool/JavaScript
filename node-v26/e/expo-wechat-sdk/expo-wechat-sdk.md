# expo-wechat-sdk

> 标签: android, expo, ios, react, react-native, wechat

## 简介

为 Expo 和 React Native 提供微信登录、分享、支付功能的原生模块。基于最新微信 SDK 开发，支持 iOS 和 Android 平台
