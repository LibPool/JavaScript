# eslint-plugin-ai-guard

> 标签: ai, ai-generated-code, async, async-reliability, ci, claude, code-scanning, copilot, cursor, developer-tools, eslint, eslint-plugin, github-actions, github-security, guardrails, linting, llm, pull-request, reliability, sarif, security, static-analysis, workflow

## 简介

GitHub-native guardrails for AI-generated code. ESLint plugin and GitHub Action for detecting async reliability issues, floating promises, empty catch blocks, hardcoded secrets, SQL injection, and more. SARIF-based GitHub Code Scanning integration with PR
