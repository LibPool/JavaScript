# email-local-core

> 标签: cloudflare-workers, email, mail, mcp, model-context-protocol, tools

## 简介

The portable half of Email Local MCP: the email tool vocabulary (~25 MCP tools), the MailProvider contract, and the host seam. Runs on Node and in a V8 isolate (Cloudflare Workers, Deno) — no IMAP, no filesystem, no credential store.
