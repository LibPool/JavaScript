# ep_html_export_using_client_filters

> 标签: JavaScript

## 简介

Exports HTML using client-side routines, including the ability to use client-side filters in the export routine so you only have to write them once (e.g. if you have a client-side filter that hooks into aceGetFilterStack or aceCreateDomLine, you can add those hooks to the server-side as well by adding to ep.json)
