# eslint-plugin-lit-ui-router

> 标签: eslint, eslintplugin

## 简介

ESLint rules that understand lit-ui-router directives: hrefless anchors, inert hrefs, aria-current conflicts and misplaced directives, where a uiSref element part counts as the href it assigns at runtime
