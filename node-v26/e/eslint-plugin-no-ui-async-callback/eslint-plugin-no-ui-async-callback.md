# eslint-plugin-no-ui-async-callback

> 标签: eslint, eslint-plugin, eslintplugin

## 简介

为防止重复点击,antd或其他ui组件禁止使用异步的回调函数

## 官网

- npm 页面：https://www.npmjs.com/package/eslint-plugin-no-ui-async-callback

- 当前版本：0.0.0

- 0.0.0

## 获取地址

- npm 安装：`npm install eslint-plugin-no-ui-async-callback`
- npm registry：https://registry.npmjs.org/eslint-plugin-no-ui-async-callback
- Node 要求：12.x || 14.x || >= 16
