# echoo-cli

> 标签: agent-tools, ai-agent, cli, echoo, llm, macos, openapi, writing

## 简介

Agent-friendly CLI for Echoo's public catalog of AI writing commands, use cases, providers, workflows, glossary, blog posts, and pricing. Read-only, no API key, zero dependencies.
