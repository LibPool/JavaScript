# elaltagent

> 标签: a11y, accessibility, alt-text, courseware, excel, html, wcag

## 简介

Safely apply client-provided alt text from Excel sheets to images across HTML projects. Dry-run by default, deterministic matching, surgical edits, full Excel audit report.
