# ecobrowser

> 标签: accessibility, agent, ai, browser, browser-automation, llm, mcp, mcp-server, playwright, scraping

## 简介

AI-native browser framework — the AI's hands and eyes on the web. Structured (no-pixel) perception, verified self-healing actions, incremental diff perception, a live view — as a TypeScript library and an MCP server.
