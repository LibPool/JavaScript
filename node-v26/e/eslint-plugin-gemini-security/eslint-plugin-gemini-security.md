# eslint-plugin-gemini-security

> 标签: ai-security, appsec, code-quality, cwe, eslint, eslint-plugin, eslintplugin, gemini, genai, google-ai, google-gemini, interlace-security, linting, llm, llm-security, owasp, safety-settings, sast, security, static-analysis, typescript, vulnerability

## 简介

ESLint plugin for Google Gemini SDK security — catches safety thresholds set to BLOCK_NONE, hardcoded API keys, and system instructions assembled from untrusted input.
