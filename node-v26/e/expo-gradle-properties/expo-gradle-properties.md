# expo-gradle-properties

> 标签: android, config-plugin, expo, expo-config-plugin, gradle, gradle.properties, jvmargs, prebuild, react-native

## 简介

Expo config plugin to set arbitrary keys in android/gradle.properties — the generic escape hatch expo-build-properties doesn't have.
