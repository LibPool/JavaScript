# e-vue-esrimap

> 标签: ArcGIS API for JavaScript, shengchangwei, vue

## 简介

基于 vue-cli3 + TypeScript 的二维地图组件，使用的地图 API 是 ArcGIS API for JavaScript v3.x（>=3.14）。
