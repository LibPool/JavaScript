# extrojs

> 标签: browser-extension, chrome-extension, extro, framework, manifest-v3, react, vite

## 简介

Next.js for Chrome extensions. File-based entrypoints, automatic Manifest V3 generation, and React routing in a single Vite-powered CLI.
