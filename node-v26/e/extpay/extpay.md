# extpay

> 标签: browser, chrome-extension, extension, firefox-extension, payments

## 简介

The JavaScript library for https://extensionpay.com - payments for browser extensions, no server needed.

## 官网

- 官网：https://extensionpay.com
- 源码仓库：git+https://github.com/Glench/ExtPay.git
- npm 页面：https://www.npmjs.com/package/extpay
