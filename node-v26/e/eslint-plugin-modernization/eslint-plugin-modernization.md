# eslint-plugin-modernization

> 标签: ai-assistant, auto-fix, code-quality, codemod, ecmascript, es2022, eslint, eslint-plugin, eslintplugin, interlace-quality, legacy-code, linting, llm-optimized, modern-javascript, modernization, refactoring, static-analysis, typescript

## 简介

ESLint plugin for modernizing JavaScript — auto-fixes legacy patterns to ES2022+ (Array.at, template literals, EventTarget, Array.isArray).
