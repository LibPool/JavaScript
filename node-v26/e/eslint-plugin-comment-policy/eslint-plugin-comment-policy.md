# eslint-plugin-comment-policy

> 标签: comment-policy, comments, eslint, eslint-plugin, eslintplugin, typescript

## 简介

ESLint rules enforcing a per-file comment policy: prose-line caps, no change-narrative, no code snippets, no decorative markers, block comments only (JS + TS).
