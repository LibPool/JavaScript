# extended-vlc-player

> 标签: expo, expo-module, iptv, matroska, mkv, mobilevlckit, picture-in-picture, pip, player, react-native, video, vlc

## 简介

React Native video player built on MobileVLCKit (iOS) and libVLC (Android) with true iOS Picture-in-Picture via AVSampleBufferDisplayLayer bridge.
