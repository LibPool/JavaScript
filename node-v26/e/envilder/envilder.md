# envilder

> 标签: automation, aws, azure, azure-key-vault, ci-cd, cli, config, devops, dotenv, env, envfile, environment, environment-variables, github-action, github-actions, key-vault, map-file, multi-cloud, parameter-store, sdk, secret-loader, secret-management, secrets, secure, ssm, twelve-factor

## 简介

Open-source TypeScript CLI, GitHub Action, and runtime SDKs for loading secrets from AWS SSM Parameter Store and Azure Key Vault.
