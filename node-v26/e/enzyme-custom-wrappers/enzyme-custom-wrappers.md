# enzyme-custom-wrappers

> 标签: enzyme, react, tdd, test, testing

## 简介

This is a small library aiming at promoting and simplifying writing of integration tests using Enzyme library. As a name suggests, it let's you create your own wrappers for accessing components (or their elements) and to use it on top of pure Enzyme.
