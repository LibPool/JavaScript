# ex-select

> 标签: element-ui, rollup, vue, vue-virtual-scroller, vuejs

## 简介

> 基于`element-ui`和`vue-virtual-scroller`的下拉选择器，用虚拟列表的方式逐级渲染列表。适用于数据量较大的场景。
