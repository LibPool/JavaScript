# eslint-plugin-no-pl-pr-tailwind

> 标签: eslint, eslint-rule, eslintplugin, rtl, tailwind

## 简介

ESLint rule to disallow Tailwind's pl- and pr- classes in favor of ps- and pe- for RTL support.
