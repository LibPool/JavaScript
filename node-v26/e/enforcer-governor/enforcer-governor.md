# enforcer-governor

> 标签: agent-security, ai-agents, anthropic, audit-log, claude-code, claude-code-hook, cli, cost-control, governance, guardrails, gvnr, llm-cost, llmops, mcp, mcp-server, model-context-protocol, openai, rate-limit, rate-limiting, spend-limit, token-budget

## 简介

GVNR: stops AI agents overspending and running dangerous commands, before the action runs. Per-minute spend caps, allow/deny/escalate on every action, hash-chained receipts, MCP server. Free, self-hosted. Formerly Enforcer Governor.
