# emitteth

> 标签: ethereum, event, javascript, log, smart contract, subscription, web3

## 简介

Offers a wide range of live event subscriptions for the Ethereum blockchain and supports waiting for a number of confirmed blocks. Built-in convenience API for ERC20 and 0x-exchange events
