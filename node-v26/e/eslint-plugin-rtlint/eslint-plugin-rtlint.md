# eslint-plugin-rtlint

> 标签: accessibility, bidi, eslint, eslint-plugin, eslintplugin, i18n, react-native, right-to-left, rtl, writing-direction

## 简介

ESLint rules that catch React Native RTL / bidi layout bugs: textAlign without writingDirection (autofix), direction:'rtl', unpaired I18nManager.forceRTL, and locale/region cross-wiring.
