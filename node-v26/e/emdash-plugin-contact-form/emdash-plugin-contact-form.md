# emdash-plugin-contact-form

> 标签: contact-form, emdash, emdash-plugin, standard-plugin, submissions

## 简介

Contact-form submissions store for EmDash CMS. Standard (sandboxable) plugin: a public submit endpoint, a Block Kit admin page, and a dashboard widget. No build step.
