# el-global-dialog

> 标签: element, vue

## 简介

使用`this.$dialog`的形式使用`el-dialog` ##### 使用方法 ```js import 'el-global-dialog' ``` 在vue文件中 ```js this.$dialog({   title: '标题',   width: '30%',   message: (dialog) => {     return (       <div>Hello World</div>     );   } }) ``` ##### attributes 参数|说明|类型|可选值|
