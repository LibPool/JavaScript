# es-abstract-to-length

> 标签: ECMAScript, ES, ES2009, ES2011, ES2015, ES2016, ES2017, ES5, ES5.1, ES6, ES7, ES8, JavaScript, ToLength, abstract, abstract operation, abstract operations, ecma, internal, internal method, internal methods, length, method, operation, to length, toLength

## 简介

A method to convert an argument to an integer suitable for use as the length of an array-like object. This method follows ECMAScript's specification for the 'ToLength' abstract operation.
