# eslint-plugin-lcom

> 标签: LCOM, cohesion, eslint, eslint-plugin, eslintplugin

## 简介

ESLint plugin to keep your JavaScript classes high cohesive by using LCOM (Lack of Cohesion of Methods) metric.
