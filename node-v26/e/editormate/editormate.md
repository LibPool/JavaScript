# editormate

> 标签: ai-agent, antigravity, claude-code, cursor, developer-tools, discord-bot, remote-control, telegram-bot, vscode, whatsapp

## 简介

Cross-platform background companion daemon and multi-IDE extension bridging mobile messengers (Telegram, Discord, WhatsApp) to desktop AI coding agents (Antigravity, Cursor, VS Code, Windsurf, Claude Code, Aider, Xcode, Neovim) with a bidirectional syntax
