# esbuild-plugin-jso-obfuscator

> 标签: anti-tamper, bundle, code-protection, esbuild, esbuild-obfuscator, esbuild-plugin, javascript, javascript-obfuscator, javascriptobfuscator, javascriptobfuscator-com, minify, obfuscation, obfuscator, protect, source-code-protection

## 简介

Obfuscate and protect your esbuild output with JavaScript Obfuscator. Official esbuild plugin for javascriptobfuscator.com: string encryption, control-flow flattening, member renaming.
