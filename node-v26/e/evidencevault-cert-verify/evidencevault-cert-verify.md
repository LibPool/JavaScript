# evidencevault-cert-verify

> 标签: certificate, cli, ed25519, evidencevault, merkle-proof, offline-verifier, opentimestamps, verification

## 简介

Standalone Node CLI — verifies an EvidenceVault certificate from public artifacts alone (public tenant registry, embedded payload/signatures/merkle-proof, OTS proof). No Cloudflare dependency: this is what a relying party runs to check a certificate witho
