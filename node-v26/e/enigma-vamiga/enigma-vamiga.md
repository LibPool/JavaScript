# enigma-vamiga

> 标签: amiga, bbs, door, emulator, enigma-bbs, vamiga, wasm, webassembly

## 简介

The vAmiga Amiga emulator core as WebAssembly for Node.js: boot, snapshot, restore, drive frame by frame, serial I/O and hard disk persistence. Built for ENiGMA½ BBS Amiga doors.
