# eb-player

> 标签: JavaScript

## 简介

A framework-agnostic TypeScript streaming video/radio player library supporting HLS (hls.js), DASH (dash.js), DRM, Chromecast, EPG, preroll ads, and the EasyBroadcast P2P library.
