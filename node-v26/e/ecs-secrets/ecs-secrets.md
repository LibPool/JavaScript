# ecs-secrets

> 标签: aws, ec2, env, environment, ssm, task definition, variables

## 简介

This package installs a command that pulls secrets from a given EC2 task definition file, with values defined as AWS SSM parameter ARNs, and transcribes the ARNs to their actual SSM values. It will then print the secret values to the screen, or save them
