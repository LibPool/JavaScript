# evalflow-mcp

> 标签: eval, evalflow, llm, mcp, model-context-protocol

## 简介

MCP server for the EvalFlow API — exposes EvalFlow (LLM prompt evaluation) as tools any MCP-capable CLI or AI agent can call.
