# electron-dev-bridge

> 标签: automation, cdp, chrome-devtools-protocol, claude, claude-code, desktop-app, electron, ipc, mcp, model-context-protocol, testing

## 简介

Expose Electron IPC handlers as MCP tools for Claude Code, with 33 built-in CDP tools for DOM automation, screenshots, console/network capture, and multi-window support
