# elysia-xss

> 标签: bun, elysia, elysia-plugin, elysia-plugin-xss, elysia-xss, elysia-xss-plugin, elysia-xss-protect, sanitize, security, xss, xss-filter, xss-protect, xss-protect-elysia, xss-sanitize

## 简介

A plugin for Elysia.js that provides XSS (Cross-Site Scripting) protection by sanitizing request body data.
