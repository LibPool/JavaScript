# envelop-letterbox

> 标签: aes-gcm, anti-scraping, api, ecdh, encryption, express, fetch, middleware, obfuscation

## 简介

Wrap your API requests and responses in encrypted envelopes. Deters casual inspection and scraping. NOT end-to-end security against the end user.
