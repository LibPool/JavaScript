# evolution-mode

> 标签: breathing, cognitive, dsg-plugin, dsh, evolution, plugin-evolution

## 简介

进化模式（evolution-mode）：DSH 插件生态操作系统 — 唯一主链、只沉默不删除、需求优先分层(L1/L2/L3)、显性界面中断、碰撞三分(同构核/桥接缺口/沉默冗余) + 桥接生成 + 压缩评估。
