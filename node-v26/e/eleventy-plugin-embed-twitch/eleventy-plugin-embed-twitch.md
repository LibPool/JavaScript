# eleventy-plugin-embed-twitch

> 标签: 11ty, eleventy, eleventy-plugin, twitch

## 简介

An Eleventy plugin to automatically embed Twitch streams, using just their URLs.

- 官网：https://gfscott.com/embed-everything/
