# excel-graft

> 标签: excel, exceljs-alternative, export, express, ooxml, openxml, report, spreadsheet, template, xlsx

## 简介

Fill real Excel workbooks with data without breaking them: patches the .xlsx XML in place, infers groups/subtotals from sample rows, never triggers the repair prompt.
