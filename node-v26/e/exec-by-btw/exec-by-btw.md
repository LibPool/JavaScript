# exec-by-btw

> 标签: agent, ai, executor, lua, luau, mcp, model-context-protocol, roblox

## 简介

exec by btw — universal MCP server for Roblox. Execute Luau, inspect scripts, spy on remotes. Works on macOS, Linux, Windows with any executor.
