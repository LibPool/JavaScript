# express-auto-docs

> 标签: api-docs, auto-docs, code-reference, documentation, express, internal-docs, mongoose, swagger-alternative

## 简介

Auto-generate a searchable internal documentation portal for any Express + Node + Mongoose codebase. Scans routes, models, and env vars; serves a no-build viewer at /internal-docs.
