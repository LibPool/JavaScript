# eslint-config-stk

> 标签: JavaScript

## 简介

-   crear un archivo `.eslintrc.js` en el proyecto deseado -   dicho archivo debe contener únicamente lo siguiente \* `module.exports = { "extends": ["stk/eslint/node"] }; `
