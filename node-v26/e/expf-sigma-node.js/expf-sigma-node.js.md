# expf-sigma-node.js

> 标签: continuous deployment, feature flags, feature toggles, nodejs, remote configuration, sigma

## 简介

expf-sigma-node.js lets you manage features flags and remote config across web, server side applications. Deliver true Continuous Integration. Get builds out faster. Control who has access to new features.
