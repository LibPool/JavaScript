# egenie-vite-plugin-react

> 标签: JavaScript

## 简介

- 原包@vitejs/plugin-react 不支持直接关闭内置的 fastRefresh,mobx 就会显得很鸡肋 - 此包作为临时方案,待提了 merge request 后会移除 - 此包直接将内部的 skipFastRefresh 设置为 true
