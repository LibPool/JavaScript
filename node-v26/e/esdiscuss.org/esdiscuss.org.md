# esdiscuss.org

> 标签: JavaScript

## 简介

This is the project behind http://esdiscuss.org which aims to produce a readable copy of the [esdiscuss mailing list archives](https://mail.mozilla.org/pipermail/es-discuss/).

## 官网

- 官网：https://github.com/esdiscuss/esdiscuss.org
- 源码仓库：https://github.com/esdiscuss/esdiscuss.org.git
- npm 页面：https://www.npmjs.com/package/esdiscuss.org

- npm registry：https://registry.npmjs.org/esdiscuss.org
- Node 要求：0.10.x
