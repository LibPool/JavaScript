# eoas

> 标签: cli, eas, expo, xprem

## 简介

A CLI tool to manage publishing and OTA updates for the xprem self-hosted server. This is not an official tool from Expo but an open-source project (https://github.com/mercuretechnologies/xprem)

- 源码仓库：git+https://github.com/mercuretechnologies/xprem.git
