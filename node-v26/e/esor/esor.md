# esor

> 标签: auto-batching, customElements, esor, fast, framework, lightweight, performance, reactive, shadowDOM, signals, typescript, web-components

## 简介

Lightweight JavaScript framework for dynamic Web applications based on Web Components with auto-batching and optimized reconciliation
