# express-simple-pass

> 标签: admin, admin-panel, auth, authentication, cookie, express, gate, internal-tools, login, logout, middleware, passkey, password, protect

## 简介

Simple password gate middleware for Express. Protect admin UIs and internal tools without building a full authentication system.
