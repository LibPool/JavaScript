# eslint-plugin-var-import

> 标签: eslint, eslintplugin, import

## 简介

- 安装: ```npm install -D eslint-plugin-var-import``` - **针对痛点**: 使用变量前，要手动import 导入。 - 配置此规则后: 文件直接使用变量, **自动在开头导入变量** - 注意:      * 1, eslint@9 以上版本, api发生变化, 暂未支持(后续...)     * 2, 校正后，前一行后面的注释, 会变到新增行的后面(小概率坑，不碍事哈~)
