# expo-aliyun-oss

> 标签: ExpoAliyunOSS, aliyun, expo, expo-aliyun-oss, react-native

## 简介

阿里云OSS SDK for Expo. 支持创建、删除、上传、下载、删除多个文件、列出所有文件等操作。
