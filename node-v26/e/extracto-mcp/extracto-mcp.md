# extracto-mcp

> 标签: ai, claude, cursor, extraction, extracto, html-to-json, llm, mcp, model-context-protocol, scraper, structured-data, web-scraping

## 简介

Model Context Protocol (MCP) server for Extracto — give Claude, Cursor, and any MCP client the ability to turn a URL plus a schema into validated, typed JSON.
