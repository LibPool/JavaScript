# eslint-plugin-obsidian-minimum-required-version

> 标签: api-version, eslint, eslintplugin, obsidian, obsidian-plugin

## 简介

ESLint plugin that warns when Obsidian plugin code uses APIs newer than the declared minAppVersion.
