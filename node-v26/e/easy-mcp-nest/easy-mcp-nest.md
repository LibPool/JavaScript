# easy-mcp-nest

> 标签: framework, json-rpc, mcp, mcp-server, model-context-protocol, nestjs, tools

## 简介

A NestJS-based framework for building standard Model Context Protocol (MCP) servers with tool execution via JSON-RPC 2.0
