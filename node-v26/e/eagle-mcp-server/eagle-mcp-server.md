# eagle-mcp-server

> 标签: agent, ai, api, design-assets, eagle, image-library, image-management, mcp, model-context-protocol

## 简介

Eagle MCP server - A Model Context Protocol server for accessing Eagle image management tool APIs. Provides AI agents with access to Eagle's powerful image organization and management capabilities.
