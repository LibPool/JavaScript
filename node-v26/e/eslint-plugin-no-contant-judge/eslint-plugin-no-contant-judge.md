# eslint-plugin-no-contant-judge

> 标签: JavaScript

## 简介

构建ESLint插件，对于逻辑表达式进行完善，不能恒为字面量（value: string | boolean | null | number | RegExp正则），标识符或者枚举，支持 " || "、"&&"逻辑表达式判断，并未对" ! "处理，因为存在使用情形，比如（!flag）
