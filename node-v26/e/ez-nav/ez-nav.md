# ez-nav

> 标签: angular, angular-component, angular-header, angular-library, angular-navbar, angular-navigation, angular-ui, bootstrap-navbar, configurable-navbar, custom-navbar, dropdown-menu, dropdown-navigation, ez-nav, header-component, mobile-navbar, navbar, navigation, responsive-navbar, ui-library

## 简介

A responsive, configurable Angular navigation bar component with support for dropdown menus, mobile drawer toggles, and custom layouts. Easily integrate a dynamic navbar using a simple configuration object.
