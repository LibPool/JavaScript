# e-layout

> 标签: component-library, css, every-layout, framework-agnostic, layout, lit, responsive, shadow-dom, ui, web-components

## 简介

A layout-focused Web Component library built with Lit, inspired by the principles of Every Layout. Provides framework-agnostic components for common layout patterns.
