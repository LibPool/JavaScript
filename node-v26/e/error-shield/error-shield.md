# error-shield

> 标签: api-errors, app-error, async-error-handler, custom-error, error-chaining, error-class, error-creators, error-formatting, error-handler, error-handling, error-logging, error-middleware, error-utility, exponential-backoff, express, express-error-handler, express-middleware, http-errors, node-error, nodejs, operational-errors, rest-api, retry, retry-logic, status-codes, structured-errors, typescript, validation-error

## 简介

Comprehensive error handling utility for Node.js & Express.js — custom error classes, async handler wrapper, Express middleware, HTTP error creators, retry logic, error chaining, and TypeScript support.
