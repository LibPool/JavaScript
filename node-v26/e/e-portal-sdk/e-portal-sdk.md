# e-portal-sdk

> 标签: JavaScript

## 简介

**ePortalSDK** est un package JavaScript conçu pour intégrer les fonctionnalités d'authentification et de redirection de votre service [e-Auth](`https://docs.eportal.e-sphereci.com`). Il gère l'ouverture d'une fenêtre popup, l'échange du token via l'URL,
