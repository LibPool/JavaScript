# erest

> 标签: @leizm/web, api, api-doc, express, koa, postman, rest, swagger, typescript, zod

## 简介

Framework-agnostic REST API framework with Zod validation, auto docs & test scaffolding. Express/Koa/@leizm/web adapters as separate packages.
