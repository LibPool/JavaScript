# ecograd-mcp

> 标签: cientometria, dissertacoes, ecograd, mcp, model-context-protocol, teses, ufsc

## 简介

Servidor MCP do acervo acadêmico da UFSC indexado pelo EcoGrad: panorama temático, leitura completa de temas e SQL somente leitura sobre 92 mil registros.
