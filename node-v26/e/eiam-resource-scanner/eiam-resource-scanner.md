# eiam-resource-scanner

> 标签: ESKADENIA, IAM, angular, authorization, checkRole, permissions, resource discovery, resource scanner

## 简介

Reusable Angular resource scanner: discovers the permission codes a page declares through checkRole, enriches them from a resource manifest, and synchronises the resource definition with a backend Resource Scan API. Discovery only - never an authorization
