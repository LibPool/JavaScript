# express-wx

> 标签: Router, Wechat, Weixin, dynamic

## 简介

Express Router for building Wechat Offical Account Message Server easily, supporting loading request (message) handlers dynamically. 快速构建微信公众号消息后端，支持动态加载请求处理逻辑代码。
