# eulerchat

> 标签: area-proportional, chat, community-discovery, embed, euler-diagram, layout, react, set-visualization, venn-diagram, websocket

## 简介

Chat rooms shaped like an Euler diagram: subjects overlap, the overlaps are rooms, and a coordinate is an address. Includes a standalone area-proportional Euler diagram layout engine.
