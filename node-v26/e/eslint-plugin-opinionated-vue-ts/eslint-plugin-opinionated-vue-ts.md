# eslint-plugin-opinionated-vue-ts

> 标签: eslint, eslint-config, eslint-plugin, flat-config, typescript, vitest, vue

## 简介

Comprehensive, opinionated ESLint plugin and flat config for Vue and TypeScript, featuring custom architecture rules and optimized integrations (Prettier, Vitest, Unicorn, Oxlint).
