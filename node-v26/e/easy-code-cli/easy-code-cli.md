# easy-code-cli

> 标签: JavaScript

## 简介

1.easycode createTemp          在当前目录创建项目，不创建目录，直接把git文件复制下来     2.easycode createTemp xxx         在当前目录生成 xxx目录项目，然后在xxx目录下 把git文件复制下来
