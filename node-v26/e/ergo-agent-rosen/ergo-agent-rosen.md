# ergo-agent-rosen

> 标签: agent-economy, agent-payments, ai-agents, cross-chain, ergo, rosen, rosen-bridge, rsUSDC, rsUSDT, stablecoin

## 简介

Cross-chain glue between ergo-agent-pay and Rosen Bridge. Lets agents accept and settle stablecoin payments on Ergo (rsUSDT, rsUSDC, rsBTC, rsETH, …) bridged from Ethereum, Bitcoin, Cardano, Binance, and any chain Rosen watchers cover.
