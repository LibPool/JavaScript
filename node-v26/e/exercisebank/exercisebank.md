# exercisebank

> 标签: ai-fitness, exercise api, exercise database, exercise video api, exercisebank, fitness, fitness api, workout api, workout videos

## 简介

Official client for the ExerciseBank API (exercisebank.net): an exercise video API with 1,492 filmed exercises, joint filters, substitutes and signed media. Server-side only.

- 官网：https://exercisebank.net
- 源码仓库：git+https://github.com/exercisebank/examples.git
- npm 页面：https://www.npmjs.com/package/exercisebank
