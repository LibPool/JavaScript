# element-theme-se-v3

> 标签: JavaScript

## 简介

element-theme-se-v3 是一套遵循施耐德已发布的最新UI设计规范正式版本 QDS UI Kit V3.16.0的主题。它基于element-theme-chalk V2.15.2，对大多数组件都进行了改版定制。
