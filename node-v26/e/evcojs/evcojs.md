# evcojs

> 标签: CQRS, CloudEvents, Command, CommandHandler, EventBroker, EventBus, EventDispatcher, EventSourcing, EventStore, Events

## 简介

CQRS with CloudEvents. Segregate read and write code and use cloud events to exchange data between them.
