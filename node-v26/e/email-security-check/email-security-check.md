# email-security-check

> 标签: bimi, compliance, dane, dkim, dmarc, dns, email, email-authentication, email-security, mta-sts, phishing, scanner, security, spf, spoofing

## 简介

Fast, zero-dependency email security scanner. Checks DMARC, SPF, DKIM, MTA-STS, BIMI, and DANE for any domain.
