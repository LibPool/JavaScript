# exoproc-dummy

> 标签: cross-process, exoproc, native, systems-instrumentation, testing, windows, x64

## 简介

A single shared, long-lived dummy Windows process (default: ping.exe) other exoproc packages and tests spawn once and reuse as a lightweight cross-process target.
