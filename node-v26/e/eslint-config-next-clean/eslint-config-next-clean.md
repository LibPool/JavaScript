# eslint-config-next-clean

> 标签: architecture, eslint, eslintconfig, folder-structure, functional, nextjs, react, tailwind, typescript

## 简介

Neutral ESLint preset for Next.js + TypeScript + Tailwind: enforces one folder structure, functional style, clear names and Tailwind hygiene so garbage code cannot land.
