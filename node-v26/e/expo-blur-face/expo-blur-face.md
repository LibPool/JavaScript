# expo-blur-face

> 标签: anonymize, blur-face, censor, expo, expo-module, face-blur, face-detection, face-recognition, image-processing, mlkit, on-device, privacy, react-native, vision

## 简介

On-device face detection and blurring for React Native / Expo. Uses Vision (iOS) and ML Kit (Android). No server calls, no FFmpeg — just install and blur.
