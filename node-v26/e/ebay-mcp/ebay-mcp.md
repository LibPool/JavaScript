# ebay-mcp

> 标签: ai, ai-tools, api, backend, documentation, ebay, ebay-api, llm, mcp, model-context-protocol, server

## 简介

Model Context Protocol (MCP) server that exposes 100% of eBay's Sell APIs (313 tools across 283 endpoints) to AI assistants like Claude, Cursor, and Cline, covering inventory, order fulfillment, marketing, analytics, and developer tools with OAuth authent
