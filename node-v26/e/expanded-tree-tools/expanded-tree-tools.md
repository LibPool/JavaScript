# expanded-tree-tools

> 标签: JavaScript

## 简介

**要求的数组结构如下** ```js const yourArrayData = [     { id: 1, cj: 1, },     { id: 2, cj: 2, },     { id: 3, cj: 3, },     { id: 4, cj: 2, },     { id: 5, cj: 3, },     { id: 6, cj: 4, }, ] ``` **使用 id 判断唯一值，使用 cj 找到父级节点及子节点**
