> 标签: browser, current, date, deno, deno-edition, deno-entry, denoland, ecmascript, es, esnext, fetch, filter, module, node, ratified, typed, types, typescript, version, versions

## 简介

Get all ECMAScript versions, or the ECMAScript version that was ratified on a specific date.
