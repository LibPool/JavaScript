# expressgo

> 标签: api, app, express, expressgo, framework, restful, router, web

## 简介

Express 是一个简洁灵活的 node 开发框架，ExpressGo 整合了 Express 框架和一些常用的模块，如 mongoose、async、log4js、redis、supertest等，距离实际项目开发更近了一步，也是 node 新手很好的参考项目。
