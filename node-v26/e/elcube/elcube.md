# elcube

> 标签: JavaScript

## 简介

ELCube（逻辑魔方），解决企业变更曲线与软件跟随曲线不匹配的问题。我们追求开发一套快速、 容易的企业级模型方案，让企业更从容，让程序员走出困境。用业务建模的方式解决业务问题， 而不是用技术堆砌的方式绑定企业。
