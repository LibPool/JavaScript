# eleventy-plugin-social-img

> 标签: 11ty, 11ty-plugin, eleventy, eleventy-plugin, social-share-image-generator

## 简介

A plugin for generating social share images at build time. Returns a URL for the image to be used in Twitter & Open Graph meta tags.
