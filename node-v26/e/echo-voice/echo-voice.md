# echo-voice

> 标签: barge-in, echo, push-to-talk, silero, vad, voice, voiceflow, webrtc

## 简介

Echo VoiceFlow client with client-side VAD, turn control (push-to-talk / auto / hybrid, switchable live), signals for proactive agents, local barge-in, waveform and mute. Vanilla core + React hook.
