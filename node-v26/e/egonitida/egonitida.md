# egonitida

> 标签: 3d, agentic, effect, egonitida, engine, foldkit, game-engine, real-time, three, webgpu

## 简介

EgoNitida is a real-time 3D engine built on Effect, Three.js, and Foldkit. The egonitida command is a convenient point of access to EgoNitida resources.
