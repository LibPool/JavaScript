# express-validate-kit

> 标签: JavaScript

## 简介

一个轻量级的 Express 请求验证工具包，支持多种验证库，包括 Joi、Yup、Zod 和 Valibot。

## 官网

- npm 页面：https://www.npmjs.com/package/express-validate-kit

- npm registry：https://registry.npmjs.org/express-validate-kit
- Node 要求：>= 18
