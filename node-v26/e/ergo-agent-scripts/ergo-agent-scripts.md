# ergo-agent-scripts

> 标签: agent-economy, compiled-scripts, ergo, ergoscript, ergotree

## 简介

Canonical ErgoScript sources for v0 predicates plus a typed registry for compiled ergoTrees. Ships sources only; the compile script populates trees via ergo-lib-wasm-nodejs.
