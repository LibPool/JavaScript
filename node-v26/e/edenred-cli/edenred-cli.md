# edenred-cli

> 标签: JavaScript

## 简介

1. npm install edenred-cli -g // 全局安装 2. edenred-cli -V // 查看脚手架版本号 3. edenred-cli list // 查看项目模块列表 4. example：edenred-cli init 模板名 项目目录名
