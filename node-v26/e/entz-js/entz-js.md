# entz-js

> 标签: collaborative, crdt, entz, local-first, loro, spacetimedb, sync, wasm

## 简介

Loro CRDT documents synced through SpacetimeDB: the headless client, SpacetimeAuth login and React providers; editors (entz-editor, entz-rn) plug in as separate packages
