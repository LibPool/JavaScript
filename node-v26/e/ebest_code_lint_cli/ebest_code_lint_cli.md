# ebest_code_lint_cli

> 标签: JavaScript

## 简介

1.vscode 需要安装以下插件 EditorConfig for VS Code|ESlint|Prettier-Code formatter|Style lint 2.把.eslintrc.js 文件中的vueVersions修改成当前项目的vue版本。 3.如果需要ts的验证 把.eslintrc.js文件中的tsVerify改为true。
