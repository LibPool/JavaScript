# emaillint-core

> 标签: compatibility, email, email-client, html-email, lint, linter, outlook, static-analysis

## 简介

Deterministic static analysis engine for HTML emails. Finds unsupported or inconsistently-rendered HTML/CSS before you send a campaign.
