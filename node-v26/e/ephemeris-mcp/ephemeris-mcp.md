# ephemeris-mcp

> 标签: ai-tools, chronos, claude, cursor, demand-forecasting, ensemble, forecasting, foundation-models, llm-tools, mcp, model-context-protocol, prediction, probabilistic-forecasting, time-series, time-series-foundation-model, timesfm, tirex, toto, tsfm, zero-shot-forecasting

## 简介

MCP server for time-series foundation model (TSFM) forecasting: probabilistic forecasts from Chronos-2, TimesFM 2.5, Toto 2, TiRex-2 and IBM Granite models, or an ensemble. Stdio bridge to the remote server.
