# eel-conformance

> 标签: butterchurn, conformance, eel, eel2, milkdrop, ns-eel, projectm, specification, test-suite, visualizer

## 简介

Executable specification of EEL2, the expression language of MilkDrop presets: 82 portable JSON cases, a JSON Schema, and a runner contract any implementation can satisfy.
