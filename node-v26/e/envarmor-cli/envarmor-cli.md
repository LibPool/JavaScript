# envarmor-cli

> 标签: api-key, cli, devtools, dotenv, entropy, env, git-hook, leak-detection, pre-commit, scanner, secrets, security

## 简介

EnvArmor CLI — An offline-first security scanner to prevent API keys, tokens, database credentials, and high-entropy secrets from leaking into Git. Includes git pre-commit hooks, history scanning, and risk exposure estimates. Source code: https://github.c
