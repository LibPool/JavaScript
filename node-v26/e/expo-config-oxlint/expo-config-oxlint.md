# expo-config-oxlint

> 标签: eslint-config-expo, expo, lint, oxc, oxlint, react-compiler, react-hooks, react-native

## 简介

Oxlint preset for Expo apps: Expo's oxlint-config-universe/native plus the React Compiler rules (eslint-plugin-react-hooks) and Expo's lint rules via Oxlint JS plugins
