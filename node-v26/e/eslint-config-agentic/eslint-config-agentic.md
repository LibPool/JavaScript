# eslint-config-agentic

> 标签: agent, ai, eslint, eslint-config, eslintconfig, flat-config, typescript

## 简介

Shareable ESLint flat config for AI-generated TypeScript: type safety, Promise safety, Temporal-only dates, and inlined agent guardrails.
