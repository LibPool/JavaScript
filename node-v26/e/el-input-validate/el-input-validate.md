# el-input-validate

> 标签: AntD, AntDesign, TypeScript, a-input, el-input, element-ui, input, ts, vue

## 简介

基于 vue input 的自定义指令，对输入框进行输入限制 (适用于各种UI组件：如 Element AntDesign ...）并支持TS
