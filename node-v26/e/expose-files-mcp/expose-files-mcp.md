# expose-files-mcp

> 标签: ai-tools, claude, cloudflared, files, mcp, model-context-protocol, ngrok, terminal, tunnel

## 简介

A configurable MCP server that exposes local files and terminal commands, with optional public tunneling via Cloudflare Tunnel or ngrok.
