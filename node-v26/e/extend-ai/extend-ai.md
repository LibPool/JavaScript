# extend-ai

> 标签: data extraction, document ai, document processing, extend, extend.ai, idp, ocr, pdf parsing

## 简介

Official TypeScript/Node.js SDK for Extend (extend.ai) — the document processing API. Parse, extract, classify, split, and edit PDFs and 35+ file types
