# excel-read-plugin

> 标签: excel, excel-plugin, parse, read, sheet, spreadsheet, stream, typescript, vue, vue3, xlsx

## 简介

高性能 Excel(.xlsx) 读取插件。采用 XML 流式解析，内置 @zip.js/zip.js 解包 OOXML 部件，支持数十万行大表内存友好读取、单元格类型与日期时区精确转换、合并单元格识别、按列索引或标题映射 JSON 字段。提供与框架无关的核心类 ExcelReader，以及 Vue3 Composition API 封装。
