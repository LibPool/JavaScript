# express-logg

> 标签: api-logs, console, dashboard, debug, devtools, express, express-middleware, log-viewer, logger, logging, middleware, monitoring, request-logger

## 简介

Capture console output and structured Express request logs in a browser dashboard with filtering, search, themes, and pagination.
