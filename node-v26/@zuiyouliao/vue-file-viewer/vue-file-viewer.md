# @zuiyouliao/vue-file-viewer

> 标签: vue, zyl-ui

## 简介

一个基于vue开发的跨框架、多格式、纯前端渲染的文件浏览解决方案（支持格式：pptx,docx,xlsx,pdf,视频,音频,纯文本和图片）
