# @mathplot/web

> 标签: JavaScript

## 简介

Custom elements for mathplot: <mathplot-plot>, <mathplot-2d>, <mathplot-3d>, <mathplot-heatmap>, <mathplot-bar>, <mathplot-line>, <mathplot-pie> for non-React sites.
