# @northbound-run/search-cloudflare

> 标签: ai-search, autorag, cloudflare, fulltext, hybrid-search, open-mercato, open-mercato-module, rag, search

## 简介

Cloudflare AI Search as a pluggable fulltext driver for Open Mercato: hybrid BM25 + vector retrieval behind the stock FullTextSearchDriver contract, with no search service to operate.
