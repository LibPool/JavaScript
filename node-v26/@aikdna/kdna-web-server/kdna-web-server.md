# @aikdna/kdna-web-server

> 标签: express, judgment-asset, kdna, kdna-web-server, nextjs, server-adapter

## 简介

Node.js server adapter for the KDNA runtime, with route handlers for Next.js and Express. Decryption and license verification remain server-side.
