# @computesdk/aws

> 标签: agentcore, aws, bedrock, cloud, code-execution, code-interpreter, computesdk, ec2, provider, sandbox, spot, ssm

## 简介

AWS providers for ComputeSDK. @computesdk/aws/ec2: on-demand or Spot EC2 instances, commands over SSM Run Command. @computesdk/aws/agentcore: Bedrock AgentCore Code Interpreter sessions
