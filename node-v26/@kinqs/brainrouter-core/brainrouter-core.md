# @kinqs/brainrouter-core

> 标签: agent, brainrouter, core

## 简介

BrainRouter's headless engine — config, durable stores, runtime, orchestration, telemetry, and the agent — shared verbatim by the CLI and the Desktop app so neither reaches into the other's build output.
