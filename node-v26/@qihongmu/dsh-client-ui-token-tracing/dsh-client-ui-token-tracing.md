# @qihongmu/dsh-client-ui-token-tracing

> 标签: JavaScript

## 简介

External user plugin: token-tracing conversation tab (browser half) — per-turn usage summary, turn list, and attempt drill-down over the tokenTracing Remote. No changes to the dsh library.
