# @shayxo.dev/liquidglass

> 标签: backdrop-filter, canvaskit, custom element, glass, liquid glass, web component

## 简介

<liquid-glass>: a framework-independent custom element for the liquidglass material. Refracts live HTML (Chromium) or draws the production shaders through CanvasKit.
