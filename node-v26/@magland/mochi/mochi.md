# @magland/mochi

> 标签: forge, git, git-http, git-lfs, issues, pull-requests, self-hosted, static-site

## 简介

A self-hosted git forge with the shape of GitHub: browsing, in-browser editing, issues, pull requests, Actions-compatible workflows, static sites, and Git LFS, from one small server.
