# @zentauri-ui/zentauri-components

> 标签: animations, charts, component-library, design-system, hooks, nextjs, react, tailwind, tailwindcss, typescript, ui-kit

## 简介

React + Tailwind UI kit with charts, ESM/CJS builds, per-entry exports, and a zentauri-components / zentauri-ui CLI to vendor UI or hook source into your app
