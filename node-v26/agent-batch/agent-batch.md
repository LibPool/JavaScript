# agent-batch

> 标签: agents, ai, batch, cloudflare, cloudflare-workers, durable-objects, pi

## 简介

Run hundreds of one-off agent jobs unattended, each with an output contract. On your own machines first, spilling over to Cloudflare Workers. Name reserved; in development.
