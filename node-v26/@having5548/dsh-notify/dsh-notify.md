# @having5548/dsh-notify

> 标签: deepseek-harness, dsh, dsh-plugin, macos, notification, toast, windows

## 简介

DeepSeek Harness 通用通知插件：新会话 / 待审批 / 任务完成 / 任务中断时，在 GUI 内显示 Telegram 风格应用内通知；前台后台都会响提示音（前台页面内发声，后台由系统原生通知发声），仅通知、不回调。
