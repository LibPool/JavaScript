# @deepcodec/dsh-clock

> 标签: clock, cordis, date, deepseek-harness, dsh, dsh-plugin, plugin, status-bar, time

## 简介

DSH Web clock: shows the current date & time in the bottom status bar (composer dock), with user-configurable format.
