# @sentry/symbolic

> 标签: breakpad, debuginfo, dwarf, elf, macho, pdb, sentry, symbolic, wasm

## 简介

WebAssembly bindings for symbolic — parse debug information files (Mach-O/dSYM, ELF, PE/PDB, Portable PDB, WebAssembly, Breakpad, source bundles).
