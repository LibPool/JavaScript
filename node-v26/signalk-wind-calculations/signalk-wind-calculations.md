# signalk-wind-calculations

> 标签: b&g, calibration, laylines, sailing, signalk-category-instruments, signalk-category-weather, signalk-node-server-plugin, tack loss, true wind

## 简介

Signal K plugin: true/ground wind, current, targets, laylines, tack and gybe loss, wind calibration check, wind shifts, start line bias, next leg and dead reckoning - feeds the B&G performance plugin.
