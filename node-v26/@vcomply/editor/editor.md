# @vcomply/editor

> 标签: Compliance, Paste From Word, Rich Text Editor, Vcomply, WYSIWYG Editor, ckeditor, medium, open source editor, paper, quill, slate, tinymce

## 简介

Vcomply Editor is the rich-text editor package for VComply. A wysiwyg editor with blend in styles, formatting, font families and everything needed to make your rich text edit experience euphoric
