# @sitefig/susbot

> 标签: ai, audit, cli, crawler, gptbot, rfc9309, robots, robots.txt, seo, webassembly

## 简介

robots.txt checker: which search engines and AI crawlers a site lets in, lint findings, exposed paths and diffs (sus.bot). WebAssembly engine for Node and browsers, plus the susbot command.
