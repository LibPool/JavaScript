# @klyratech/visio-editor

> 标签: diagram, editor, klyra, mermaid, npx, open-source, svg, visio, vsdx

## 简介

Runnable, zero-dependency web editor for Mermaid → live SVG preview and one-click export to SVG, high-res PNG, or native Visio (.vsdx). Run it instantly with `npx @klyratech/visio-editor`. An extension of Mermaid; ships no copy of Mermaid.
