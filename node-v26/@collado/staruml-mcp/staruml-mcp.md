# @collado/staruml-mcp

> 标签: diagram, mcp, model-context-protocol, staruml, uml

## 简介

StarUML MCP Server — generate, query, and control StarUML diagrams via MCP tools. Supports 25+ diagram families via built-in API (Mermaid) and Controller extension (REST).
