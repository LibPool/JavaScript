# @gekoai/sdk

> 标签: ai, cli, geko, kazakh, sdk, speech, stt, text-to-speech, tokay, tts, voice

## 简介

Official zero-dependency TypeScript SDK + CLI for the Geko speech API (text-to-speech, with speech-to-text and more coming).
