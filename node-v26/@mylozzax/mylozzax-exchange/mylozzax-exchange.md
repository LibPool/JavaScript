# @mylozzax/mylozzax-exchange

> 标签: cryptocurrency-conversion, cryptocurrency-exchange, lozzax-to-bitcoin, lozzaxtobitcoin, lozztobtc, mylozzax

## 简介

This module is used by the desktop and web versions of the MyLozzax wallet to facilitate the exchange of LOZZ into other cryptocurrencies. It can be used to facilitate transactions where a user converts one cryptocurrency into another.
