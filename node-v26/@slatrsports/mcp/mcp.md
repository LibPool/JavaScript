# @slatrsports/mcp

> 标签: analytics, dfs, mcp, model-context-protocol, slatr, sports

## 简介

Slatr MCP server (local stdio) — reach the Ask Slatr assistant, published rankings, and the NFL lineup optimizer from any MCP-capable AI client. Authenticate with a personal Slatr API key.
