# @swapdk/wdk-protocol-bridge-swapdk-common

> 标签: internal, swapdk, tether, wdk

## 简介

Shared infrastructure for the SwapDK WDK protocol bridge family — HTTP client, error types, route selection, asset utilities, token registry. Not intended to be consumed directly; bridge-specific packages re-export what their users need.
