# @swapdk/wdk-protocol-bridge-swapdk-tron

> 标签: bridge, cross-chain, swapdk, tether, thorchain, trc-20, tron, wdk

## 简介

WDK bridge protocol module for cross-chain swaps from TRON as source chain via SwapDK swap-engine + THORChain (router-contract pattern).
