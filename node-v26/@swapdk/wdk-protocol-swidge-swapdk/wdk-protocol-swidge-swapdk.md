# @swapdk/wdk-protocol-swidge-swapdk

> 标签: bridge, chainflip, cross-chain, mayachain, swap, swapdk, swidge, tether, thorchain, wdk

## 简介

WDK swidge protocol module for arbitrary-asset cross-chain swaps and bridges via the SwapDK swap-engine (THORChain, MAYAChain, Chainflip). Single class covering Bitcoin, EVM, Cosmos-family, Solana, and TRON source chains.
