# @algosuite/vo-mcp

> 标签: claude, claude-desktop, consensus, continue, cursor, mcp, model-context-protocol, ratchet, virtual-office

## 简介

Virtual Office MCP server — open protocol surface for the VO consensus / ratchet tool family. Stdio transport, cross-vendor MCP client compatible (Claude Code, Claude Desktop, Cursor, Continue).
