# codegraph-engine

> 标签: ast, blast-radius, call-graph, code-analysis, dependency-graph, impact-analysis, static-analysis, tree-sitter, variable-lineage

## 简介

AST dependency, call-graph, variable-lineage and blast-radius engine for TypeScript/JavaScript/Python repos, with confidence-labeled edges (resolved/probable/ambiguous) and a React Flow UI.
