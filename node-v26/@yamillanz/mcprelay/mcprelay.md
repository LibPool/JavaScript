# @yamillanz/mcprelay

> 标签: cli, dead-letter-queue, dlq, mcp, middleware, model-context-protocol, observability, proxy, replay, retry

## 简介

The reliability layer for MCP tool calls — local-first policy, observability, and a dead-letter queue with replay for any stdio MCP server.
