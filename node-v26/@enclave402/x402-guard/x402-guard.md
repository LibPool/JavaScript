# @enclave402/x402-guard

> 标签: 402, agent-payments, agentic-commerce, agentkit, base, coinbase, fetch-interceptor, mcp, pre-payment-check, reputation, trust, usdc, verdict, x402, x402-client, x402-fetch

## 简介

Check an x402 seller before your agent pays it. Wraps fetch: on HTTP 402, fetches a signed pay/caution/avoid verdict from a live census of 5,000+ x402 endpoints and blocks on avoid. Zero deps.
