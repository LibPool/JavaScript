# @lztooler/img

> 标签: JavaScript

## 简介

使用前请确认当前node版本是否在16或以上，低版本不兼容。 图片处理的小工具，可以对指定文件夹下的图片进行压缩（支持jpg,png和gif），另外可以将jpg图片转换成png，或者png转换为jpg格式，将来还会添加其他一些比较实用的小功能。暂时没有适配mac端。
