# @licentivo/sdk

> 标签: activation, entitlements, heartbeat, licensing, metering, offline, sdk

## 简介

Licentivo Node.js client with license activation, device credentials, pinned signatures, policy heartbeats, offline grants, floating seats and metered workflows
