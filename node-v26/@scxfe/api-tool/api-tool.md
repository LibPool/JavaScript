# @scxfe/api-tool

> 标签: apifox, codegen, openapi, swagger, typescript

## 简介

根据 Swagger/OpenAPI 3.0 和 Apifox 的接口定义生成 TypeScript/JavaScript 的接口类型及其请求函数代码。
