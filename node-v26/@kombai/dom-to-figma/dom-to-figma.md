# @kombai/dom-to-figma

> 标签: browser, clipboard, converter, design-tools, dom, dom-to-figma, figma, html-to-figma

## 简介

Convert any DOM tree to a Figma clipboard payload, in the browser. Kombai's fork of @figit/dom-to-figma.
