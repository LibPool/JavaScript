# @mezzanine-stack/git-provider-local

> 标签: JavaScript

## 简介

`cms-core` の `GitProvider` を、ローカル専用 HTTP バックエンド（`apps/cms-local-backend`）経由で実装するパッケージ。ブラウザから利用し、`revision` はサーバ定義の SHA-256(hex) です（GitHub blob SHA とは異なる）。
