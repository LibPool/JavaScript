# @ninjavault/cdn

> 标签: cdn, download, fetch, file-storage, ninjavault, object-storage, presigned-url, sdk, typescript, upload

## 简介

Typed, zero-dependency Node.js / TypeScript client for the NinjaVault CDN Server: upload, search, download, delete, public and presigned URLs.
