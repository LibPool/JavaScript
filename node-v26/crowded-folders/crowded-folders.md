# crowded-folders

> 标签: architecture, ci, cli, directory, file-naming, folder-structure, lint, linter, monorepo, project-structure

## 简介

Finds the folders that have become a drawer: too many files in one place, or modules sharing a prefix that are a folder nobody made. Any language, with presets per ecosystem.
