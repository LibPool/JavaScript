# @soofi-xyz/chat-adapter-asana-cdk

> 标签: asana, aws-cdk, cdk, chat-sdk, soofi, webhook

## 简介

AWS CDK construct that provisions an HTTP API endpoint and registers an Asana webhook against the bot's My Tasks user task list. Companion to @soofi-xyz/chat-adapter-asana.
