# @andygo.dev/nestjs-swagger

> 标签: basic-auth, nestjs, openapi, swagger, typescript, versioning

## 简介

Drop-in NestJS Swagger module: basic-auth-protected UI, per-version documents and discriminator examples, configured from a single URI.
