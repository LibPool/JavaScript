# @enkeon/mcp

> 标签: claude, cursor, enkeon, mcp, model-context-protocol, thinkingroot

## 简介

Give any AI agent a living, per-user memory over MCP — hosted URL or one-line stdio bridge to Enkeon (recall, remember, update, forget, use_branch, read).
