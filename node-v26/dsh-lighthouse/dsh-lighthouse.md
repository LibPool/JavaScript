# dsh-lighthouse

> 标签: dashboard, deepseek-harness, downloads, dsh, dsh-plugin, market-registry, observability, pull-request, release-tracker, watchers, 作品看板, 观察区

## 简介

一屏看清每个作品现在什么样：本地版本、GitHub star、市场收没收、下载量和同类排名，还能落一张可截图的卡片。 One screen for every work you have shipped: local version, GitHub stars, market listing, downloads and category rank, plus a ready-to-screenshot card.
