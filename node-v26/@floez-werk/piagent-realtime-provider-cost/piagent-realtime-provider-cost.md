# @floez-werk/piagent-realtime-provider-cost

> 标签: cost, pi, pi-extension, pi-package, statusbar, tokens

## 简介

Pi extension: shows the effective token prices (input/output, per 1M tokens) of the provider/model of the last API call in the status bar.
