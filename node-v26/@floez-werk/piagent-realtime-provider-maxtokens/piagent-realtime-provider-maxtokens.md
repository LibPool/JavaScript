# @floez-werk/piagent-realtime-provider-maxtokens

> 标签: pi-extension, pi-package

## 简介

Pi extension: clamps max_completion_tokens for OpenRouter requests to the smallest provider endpoint limit, so OpenRouter's length filter stops excluding providers.
