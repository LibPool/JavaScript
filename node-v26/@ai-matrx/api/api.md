# @ai-matrx/api

> 标签: ai-matrx, api, client, ndjson, openapi, sse

## 简介

The one way every app talks to every AI Matrx server: generated from the server contract, split by domain so an app loads only the requests it calls. Transport, five credential kinds, organization binding, streams, job follow. No screens, app state or dat
