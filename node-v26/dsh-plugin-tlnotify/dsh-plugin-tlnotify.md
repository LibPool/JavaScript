# dsh-plugin-tlnotify

> 标签: agent, cordis, deepseek-harness, dsh, feishu, im, lark, llm, notification, notify, plugin, qq, qqbot, webhook

## 简介

把 DSH 会话事件（中断 / 结束 / 报错 / 等待操作）聚合到一个 IM 通道，推到 QQ / 飞书，带可点按钮与定向回复
