# @xk5/cli

> 标签: JavaScript

## 简介

Xk5 Cli 是一个藤蔓专用的项目构建工具，通过 Xk5 Cli 可以快速搭建一个配置完整的移动端 Vue 项目。

## 官网

- 源码仓库：https://git.tenvine.cn/frontend/xk5-module.git
- npm 页面：https://www.npmjs.com/package/@xk5/cli
