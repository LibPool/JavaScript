# @vui-rs/vite-plugin

> 标签: sfc, terminal, tui, vite, vite-plugin, vue, vui-rs

## 简介

Vite plugin to compile .vue SFCs for the vui-rs custom renderer — element tags, a TUI v-model transform, and style-block stripping.
