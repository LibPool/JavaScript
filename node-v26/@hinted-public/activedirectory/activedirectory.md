# @hinted-public/activedirectory

> 标签: active directory, ldap

## 简介

ActiveDirectory is an ldapjs client for authN (authentication) and authZ (authorization) for Microsoft Active Directory with range retrieval support for large Active Directory installations. Forked by hinted team
