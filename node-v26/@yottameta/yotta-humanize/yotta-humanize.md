# @yottameta/yotta-humanize

> 标签: agent-skills, yotta-humanize

## 简介

Yuanzhen (元真) — AI-flavor remover for Chinese writing: a detector engine (24 rule classes + wordlists + statistical burstiness) that identifies and rewrites AI-typical Chinese text to make it read more naturally. Triggers when editing/polishing text, remo
