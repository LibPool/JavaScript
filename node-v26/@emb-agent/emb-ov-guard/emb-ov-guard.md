# @emb-agent/emb-ov-guard

> 标签: JavaScript

## 简介

Scopes the personal OpenViking surface by project workspace: inside emb projects (marker .emb-agent at cwd) the personal context services are off for the session and the mcp__openviking__* tool group is not exposed; elsewhere behavior is unchanged.
