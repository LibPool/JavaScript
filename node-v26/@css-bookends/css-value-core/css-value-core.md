# @css-bookends/css-value-core

> 标签: bookends, css, css-values, csstype, typed-css

## 简介

The shared css-value validate/render engine: the table-driven single-value helper factory plus the multi-part helpers, layered on the css-calipers scalar primitives. The per-property books import this engine the way every book imports self-publish.
