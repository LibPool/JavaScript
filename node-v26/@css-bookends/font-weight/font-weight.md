# @css-bookends/font-weight

> 标签: JavaScript

## 简介

Typed font-weight builder (a constrained 1..1000 number plus the 'normal', 'bold', 'lighter', and 'bolder' keywords, throw or clamp) for CSS-Bookends. A book stamped from self-publish.
