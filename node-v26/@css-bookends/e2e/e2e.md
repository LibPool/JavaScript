# @css-bookends/e2e

> 标签: JavaScript

## 简介

Test-only workspace package: end-to-end tests proving the CSS-Bookends gilding pipeline works as a whole (books -> calipers colour -> gilding/Lightning CSS), kept separate from the gilding unit tests.
