# @aemvite/vite-plugin-aem-resources

> 标签: aem, aemvite, clientlib, copy, edge-delivery, resources, vite, vite-plugin

## 简介

Vite plugin that copies an AEM clientlib resources/ tree into the build output, skipping .gitkeep-only / empty sources.
