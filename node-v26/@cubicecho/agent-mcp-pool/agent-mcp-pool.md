# @cubicecho/agent-mcp-pool

> 标签: agent, connection-pool, mcp, model-context-protocol, openai, stdio, streamable-http, tool-calling, typescript

## 简介

A pool of long-lived Model Context Protocol clients, exposing every connected server's tools to an OpenAI-compatible agent loop as `<slug>__<tool>`.
