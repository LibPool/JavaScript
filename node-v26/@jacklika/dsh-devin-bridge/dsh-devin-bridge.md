# @jacklika/dsh-devin-bridge

> 标签: JavaScript

## 简介

Devin Connect as a dsh LLM provider: mounts the `devin` route with a bundled model catalog, credentials.toml or settings token resolution, proxy and HTTP/1.1 transport options, retry policy, and image input.
