# @grodev/claude-chat-react

> 标签: ai, anthropic, chat-widget, chatbot, claude, hook, react, sse, streaming, typescript

## 简介

React component + hook for a drop-in AI chat widget powered by the Claude API. TypeScript, streaming SSE, ~8 KB gzipped, zero runtime dependencies beyond React. Server-side proxy keeps your API key safe.
