# @wycm9527/citrine-tools

> 标签: accessibility, cdp, citrine, contrast, design-system, headless-chrome, visual-regression

## 简介

Citrine 设计系统的验收工具：页面扫描（对比度 / 名称 / 命中区 / 溢出 × 亮暗）、全组件走查（强制 hover / focus 找品牌色泄漏与外来颜色，Element 与 Radix 浮层）、窄屏折叠、Tab 焦点环。无头 Chrome + 原生 CDP，零依赖，Node ≥ 22。
