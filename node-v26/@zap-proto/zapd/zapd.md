# @zap-proto/zapd

> 标签: broker, native-messaging, router, rpc, zap, zapd

## 简介

ZAP universal router — the one shared local broker every ZAP service connects to. Downloads the canonical zap-proto/zapd native binary for your platform; `npx @zap-proto/zapd` to run, `… install-host` to register the browser native host.
