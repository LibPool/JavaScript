# @stratasync/server

> 标签: drizzle, drizzle-orm, fastify, graphql, linear, linear sync engine, linear-sync-engine, local-first, offline-first, postgres, realtime, redis, server, sync, sync-engine, typescript, websocket

## 简介

@stratasync/server: the sync server of Strata Sync, an open-source implementation of Linear's sync engine. Bootstrap streaming, mutations, delta publishing and WebSocket sync on Fastify + Drizzle.
