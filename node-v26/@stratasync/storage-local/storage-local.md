# @stratasync/storage-local

> 标签: browser, linear, linear sync engine, linear-sync-engine, local-first, localstorage, offline-first, realtime, storage, sync, sync-engine, typescript

## 简介

@stratasync/storage-local: localStorage storage adapter for Strata Sync, an open-source implementation of Linear's sync engine. For demos, tests and lightweight apps.
