# @stratasync/client

> 标签: identity-map, indexeddb, linear, linear sync engine, linear-sync-engine, local-first, offline-first, optimistic-updates, outbox, realtime, sync, sync-engine, typescript, undo-redo, yjs

## 简介

@stratasync/client: the sync client of Strata Sync, an open-source implementation of Linear's sync engine. Identity maps, outbox, delta reconciliation, rebase, undo/redo and queries.
