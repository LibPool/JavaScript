# @stratasync/conformance

> 标签: conformance, cross-platform, golden-vectors, linear, linear-sync-engine, local-first, parity, sync, sync-engine, test-vectors, typescript

## 简介

@stratasync/conformance: the language-agnostic conformance corpus for Strata Sync, an open-source implementation of Linear's sync engine. Golden vectors, engine scenarios and a driver protocol every implementation must pass.
