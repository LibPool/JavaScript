# @weibaohui/dsh-tasks

> 标签: cordis, cron, deepseek-harness, dsh, dsh-plugin, plugin, schedule, scheduled-items

## 简介

dsh 插件 · 定时任务：用 cron 表达式定时执行提示词，到点自动开一个新 agent 会话替你干活，也可随时手动立即执行；支持绑定工作区、会话按任务自动命名、cron 即时校验与全屏管理页，执行记录可一键打开对应会话；任务开始/完成/失败可推送到 dsh-im 等 IM 投递插件绑定的聊天渠道，执行结论（agent 最终回复）可随完成通知一并推送；支持免打扰时段（起止时间可配，跨零点友好），时段内推送自动跳过。
