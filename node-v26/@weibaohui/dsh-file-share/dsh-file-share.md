# @weibaohui/dsh-file-share

> 标签: @file, download, dsh, file, file-manager, files, upload, workspace

## 简介

dsh 插件 · 会话工作区文件管理：在对话区加「文件」tab，浏览当前会话工作区的目录树并就地管理（上传/下载/新建文件夹/改名/删除/搜索），文件可 @ 进对话框给 agent 处理。
