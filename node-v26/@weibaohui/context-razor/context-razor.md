# @weibaohui/context-razor

> 标签: context, cordis, deepseek-harness, dsh, dsh-plugin, plugin, razor, token, trim

## 简介

dsh 插件 · 上下文剃刀：把当前会话上下文逐条列出（角色/预览/≈token，cl100k 估算），超阈值标红，勾选后精确裁剪——不经 LLM 总结，删了什么一目了然。
