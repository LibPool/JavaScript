# @weibaohui/dsh-process

> 标签: deepseek-harness, dsh, dsh-plugin, process, workflow, yaml, 工艺

## 简介

dsh 插件 · 工艺管理：「工艺」（Process，多阶段·多环节 agent 工作流模板）的浏览/编辑/校验/导入导出/AI 生成——内置库只读、我的库可写，文件改动实时同步；agent 可通过 process_* 工具读工艺库、按工艺分阶段推进。
