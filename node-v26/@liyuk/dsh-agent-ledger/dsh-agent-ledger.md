# @liyuk/dsh-agent-ledger

> 标签: JavaScript

## 简介

AI 牛马工资单核心：无 UI 的 DSH 本地成本账本。订阅 DSH 生命周期事件，归一化 usage，解析价格，生成可审计、可导出、跨插件消费的 Receipt/Ledger 协议。
