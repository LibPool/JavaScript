# @monochromatic-dev/module-fs-path

> 标签: JavaScript

## 简介

POSIX path operations and upward root discovery (findRoot with marker values: mise monorepo, Git repository, pnpm workspace, named package, file, or directory) for Node, Bun, and browsers over the origin private file system, with an in-memory filesystem f
