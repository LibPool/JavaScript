# @uicast/expr

> 标签: ast, csp, expression, expression-language, interpreter, llm

## 简介

The expression language of uicast documents: JavaScript expressions over JSON data. Closed AST allow-list, runtime membrane, CPU and allocation budget. Never calls new Function, so it needs no unsafe-eval.
