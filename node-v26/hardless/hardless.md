# hardless

> 标签: barcode-scanner, cash-drawer, cli, emulator, escpos, mcp, nfc, point-of-sale, pos, receipt-printer, testing, web-nfc, web-serial, webusb

## 简介

Emulated POS hardware for web app development and testing: receipt printers, cash drawers, barcode scanners and NFC readers. Run it with npx hardless start.
