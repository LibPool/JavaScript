# @ssemble/mcp-server

> 标签: ai-clipping, instagram-reels, mcp, model-context-protocol, shorts, ssemble, tiktok, video, youtube

## 简介

MCP server for Ssemble AI Clipping — create viral short-form videos from any AI assistant. Webhook callbacks for n8n, Zapier, and Make automation.
