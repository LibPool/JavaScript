# @tdacorp/hyle-sdk

> 标签: cms, hyle, markdown, nextjs, tdacorp

## 简介

hyle SDK: a typed client for hyle's resolve endpoint, a hast renderer for React, and a Next.js catch-all page with tag-based revalidation.
