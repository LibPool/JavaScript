# @katana-video/carrot-backends

> 标签: background-removal, browser, carrot, denoise, ml, transcription, translation, webcodecs, webgpu, whisper

## 简介

Model-backed backends for Carrot 🥕: background removal (web-bg-removal), audio denoise (DeepFilterNet/RNNoise), transcription (whisper) and translation (OPUS-MT) — each an optional subpath import that registers itself against the engine's kernel/deriver
