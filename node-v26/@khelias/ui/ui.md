# @khelias/ui

> 标签: css-custom-properties, dark-mode, footer, header, react

## 简介

The KHE site header with its rooms menu and theme toggle, and the site footer: CSS custom properties, HTML-string renderers, React components and framework-free theme and rooms modules; and khe-design-lint, the family design check.
