# @8space-lab/design-system

> 标签: JavaScript

## 简介

8SPACE Design System is the shared visual and interaction language for 8SPACE products. It starts from the 8SPACE logo color, `#006FF4`, and turns it into reusable tokens, React components, layout rules, and component conventions.
