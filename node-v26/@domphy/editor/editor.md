# @domphy/editor

> 标签: domphy, editor, headless, rich-text, tiptap, wysiwyg

## 简介

Domphy Editor - headless rich-text editor with a Tiptap-compatible API, self-contained engine (no ProseMirror), Domphy adapter with bubble menu
