# riskrouter-recorder

> 标签: JavaScript

## 简介

Evidence from where decisions are already logged: keep each record in your own journal, send only its salted digest to a RiskRouter-compatible evidence log.

- 官网：https://riskrouter.eu/integrate#recorders
