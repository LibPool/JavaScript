# @nitro-mlkit/text-recognition

> 标签: expo, machine-learning, mlkit, nitro, ocr, on-device, react-native, text-recognition

## 简介

High-performance on-device text recognition (OCR) for React Native — Google ML Kit + Nitro. Structured blocks/lines/elements, native batch, zero bridge overhead.
