# @azohra/meteo.core

> 标签: meteorology, schema, si-units, units, weather, zod

## 简介

Units, angles, and wind-vector math shared by the meteo packages, with one sign convention platform-wide, plus zod schema primitives, the upstream-failure vocabulary, and schema-artifact rendering.
