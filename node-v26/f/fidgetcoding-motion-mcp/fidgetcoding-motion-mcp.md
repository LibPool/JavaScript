# fidgetcoding-motion-mcp

> 标签: ai, calendar, claude, mcp, motion, productivity, scheduling

## 简介

MCP server for Motion calendar — full calendar event access, availability checking, and task management. Uses Motion's internal API for calendar features the public API doesn't support.
