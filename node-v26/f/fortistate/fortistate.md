# fortistate

> 标签: collaboration, debugging, devtools, fortistate, inspector, ontogenesis, physics, react, real-time, snapshot, state, state-management, vscode-extension, vue

## 简介

🚀 A powerful state management library with collaborative inspector, real-time debugging, store snapshots, and IDE integration. Features include share snapshots, locate stores in code, and team collaboration tools.
