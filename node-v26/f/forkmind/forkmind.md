# forkmind

> 标签: agent-memory, ai-agents, anthropic, branching, context-capsules, context-management, context-offloading, context-window, dag, debugging, encrypted-storage, llm, llm-debugging, llm-observability, local-first, mcp, model-context-protocol, observability, ollama, openai, prompt-engineering, proxy, regression-testing

## 简介

Local-first LLM state branching, debugging & context offloading. Treat AI context windows like a Git repo — capture, branch, and archive context as encrypted DAG capsules.
