# flagstaff

> 标签: agent, ai-agent, animation, boxen, cli, cli-table3, extensible, json, log-update, non-tty, ora, plugin, plugins, progress, render, spinner, terminal

## 简介

The staff the flag flies from. A terminal frame loop with a static projection for agents and screen readers, and a plugin host for spinners, progress, boxes and tables. Drop-in paths for ora, log-update, boxen and cli-table3. No dependency outside the bur
