# fast-confetti

> 标签: animation, browser, canvas-confetti, celebration, confetti, effects, fireworks, particles, typescript

## 简介

Customizable confetti effects for the web — cannon, fireworks, stars, snow, pride and more. TypeScript-first, built on canvas-confetti.
