# fast-financial-charts

> 标签: candlestick, charting, charts, financial, indicators, mcp, react, trading, webgl

## 简介

WebGL2 financial charts for the web: 90 indicators, drawings, multi-pane layouts, live tick streaming, and an MCP tool surface for AI agents. Headless, MIT licensed, and battle-tested in the Pairlens trading terminal.
