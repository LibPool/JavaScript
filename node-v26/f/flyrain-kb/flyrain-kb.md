# flyrain-kb

> 标签: celery, chatbot, django, docker, embedding, knowledge-base, llm, pgvector, rag, scaffold, sse, vector-search, vue3, 大模型, 知识库

## 简介

飞虹智知识库 — 可私有化部署的 RAG 知识库问答平台脚手架与部署 CLI。Django 5 + DRF + Celery + Vue 3 + PostgreSQL/pgvector，混合检索与 SSE 流式问答，一条命令生成项目并用 Docker 拉起全栈。
