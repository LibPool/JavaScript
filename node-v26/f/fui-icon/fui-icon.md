# fui-icon

> 标签: JavaScript

## 简介

这是一个自定义的 Vue 3 组件，该组件用于渲染图标。它根据传入的 icon 、 isCustomSvg 和 className 属性来决定渲染不同类型的图标，支持渲染网络图片、自定义 SVG 图标和使用 remixicon 字体图标。
