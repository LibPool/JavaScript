# finguard-verify

> 标签: ai-governance, audit, ed25519, evidence-pack, regtech, sec, verifier

## 简介

Offline verifier for FinGuard evidence packs (Evidence Pack Spec v1). Recomputes every SHA-256, checks the canonical pack hash, verifies Ed25519 signatures. No network access, no vendor callback.
