# fluid-agents

> 标签: antigravity, claude, claude-code, codex, rate-limit, statusline, usage-limit

## 简介

Keeps your coding agent's usage window open while you are away, resumes a session it failed to continue, and alerts you when either stops working. Claude Code, Codex and Antigravity. Formerly Claude Plus.
