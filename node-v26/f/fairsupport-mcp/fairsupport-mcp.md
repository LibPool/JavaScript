# fairsupport-mcp

> 标签: billing, claude, fairsupport, healthcare, japan, kaigo, mcp, model-context-protocol

## 简介

MCP server for FairSupport (フェアサポート 請求管理). Thin HTTPS proxy — no Firebase setup required, just a fsk_ API key.
