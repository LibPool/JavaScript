# fluid-bg

> 标签: animated-background, backdrop, background, custom-element, fluid, generative-art, gradient, hero, iframe, react, wallpaper, web-component, webgl

## 简介

Drop a live Fluid generative-art background into any page — native WebGL canvas, no iframe. A <fluid-bg> web component, a React wrapper, and a CDN one-liner. Engines generated from the Fluid studio (befluid.xyz) with a CI drift guard.
