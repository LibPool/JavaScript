# ferbotz-rekon

> 标签: admin panel, config, remoteConfig

## 简介

ferbotz-rekon is a robust SDK for hosting and managing remote configurations with essential features, including bucket creation, configuration management, deletion, role-based access control, and free access to all configurations.
