# favicon-env

> 标签: canvas, dev, developer-experience, dx, env, environment, favicon, hue, staging, tanstack-intent, tint

## 简介

Tint your favicon per environment (dev/staging/prod) so you can tell instances apart at a glance. Runtime canvas mode + build-time SVG mode. Zero dependencies.
