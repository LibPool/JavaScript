## 简介

MCP server with 600+ AI-agent tools for invoicing, payroll, booking, accounting, CRM, payments, tax filing (incl. T2 corporate), churn off-ramps, and firm client management. Works with Claude, ChatGPT, Gemini, Cursor, and any MCP client.
