# fjg-side-menu

> 标签: JavaScript

## 简介

Este componente usa clases utility de Tailwind en el template (por ejemplo `bg-gradient-to-br`, `from-gray-800`, `text-white`, `w-72`, etc). Si lo instalas en otro proyecto y no ves el estilo (fondo blanco / layout “sin diseño”), casi siempre es porque **
