# file-contents

> 标签: buffer, content, contents, directory, file, filepath, fs, is, is-directory, is-file, path, plugin, read, read-file, readdir, stat, stats, stream, through, vinyl

## 简介

Set the `contents` property on a file object. Abstraction from vinyl-fs to support stream or non-stream usage.
