# filemanagernode

> 标签: createlog, createtemp, filehandler, filemanagementsystem, filemanager, filemanagerapi, fileoperationstool, fileorganizer, files, filesystemmanager, folder, foldergenerate, foldermanager, folderoperations, logcreate, logmanager, managefolder, nodefilehandler, nodefileutility, nodejs, tempcreate, tempgenerate

## 简介

This is simple global object based file and folder manager for Node.JS to simplify few operations in application/projects that require constant use of local files.
