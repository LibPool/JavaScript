# filetopdf-mcp

> 标签: claude, cline, convert-to-pdf, cursor, document-conversion, docx-to-pdf, filetopdf, html-to-pdf, markdown-to-pdf, mcp, mcp-server, modelcontextprotocol, pdf

## 简介

Model Context Protocol (MCP) server for FileToPDF — convert files, HTML, and Markdown to PDF from any MCP client (Claude, Cursor, etc.). Bring your own API key.
