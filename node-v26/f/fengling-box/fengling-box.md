# fengling-box

> 标签: anysearch, ascii, cli, commit, data, fengling, file, image, qr, search, server, token, toolbox

## 简介

枫铃工具箱 — 多功能命令行工具箱，含多源聚合搜索（内置anysearch无需额外安装）、文件批处理、图片处理、信源核实、token计算、二维码生成、文件服务器等功能
