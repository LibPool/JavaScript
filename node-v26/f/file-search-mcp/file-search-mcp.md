# file-search-mcp

> 标签: ai, claude, code-search, file-search, fuzzy-find, fzf, grep, llm, mcp, model-context-protocol, monorepo, ripgrep

## 简介

A blazingly fast MCP server for searching files in large codebases and monorepos. Features glob search, ripgrep-powered content search, fuzzy find, and directory tree visualization.
