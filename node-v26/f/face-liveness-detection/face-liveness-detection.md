# face-liveness-detection

> 标签: blink, detection, face, face-mesh, liveness, mediapipe, 人脸识别, 活体检测

## 简介

A frontend-only solution for face liveness detection using MediaPipe Face Mesh, with anti-camera-shake protection and face area guidance
