# faaah-error-sound

> 标签: alert, audio, beep, browser, console-error, debug, debugging, developer-tools, devtools, error, error-sound, faaah, mp3, nodejs, notification, side-effect, sound, uncaught-exception, unhandled-rejection, zero-config

## 简介

Zero-config npm package that plays a FAAAH alert sound on any JavaScript error, uncaught exception, or unhandled promise rejection — works in browser and Node.js with no dependencies.
