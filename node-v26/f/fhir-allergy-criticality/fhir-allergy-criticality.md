# fhir-allergy-criticality

> 标签: JavaScript

## 简介

&lt;fhir-allergy-criticallity&gt; adds critically of allergy to page to select from code if the critical nature of occurrence was low/moderate/high.  * Uses select to choose options.  * In typical use, just use &lt;fhir-allergy-criticallity url=""/fhir-al
