# flaglint

> 标签: cli, cncf, codemod, developer-tools, feature-flag-migration, feature-flags, flag-debt, launchdarkly, launchdarkly-migration, migration-tool, nodejs, openfeature, openfeature-migration, static-analysis, typescript

## 简介

Static analysis CLI for finding LaunchDarkly JavaScript/TypeScript flag debt, CI enforcement with baseline mode, and safe OpenFeature migration assistance. No API key required.
