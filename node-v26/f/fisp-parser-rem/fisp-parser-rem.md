# fisp-parser-rem

> 标签: fis rem, fisp px to rem, fisp px2rem, fisp rem, px to rem, px2rem, rem

## 简介

fisp 对px单位的css属性自动转化为rem为单位的fis插件,基于rem的解决方案[rem-core](https://www.npmjs.com/package/rem-core)的二次开发。
