# file-checkpoint-kit

> 标签: checkpoint, filesystem, patch, redo, rollback, undo

## 简介

Node.js library for durable file checkpoints with undo, redo-style restore, preview, and patch-aware rollback.

- npm 页面：https://www.npmjs.com/package/file-checkpoint-kit

- npm registry：https://registry.npmjs.org/file-checkpoint-kit
- Node 要求：>=18
