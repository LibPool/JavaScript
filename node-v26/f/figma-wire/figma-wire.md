# figma-wire

> 标签: agent-skills, claude, codex, cursor, design-to-code, figma, gemini, mcp, model-context-protocol, skills, windsurf, zcode

## 简介

Wire any AI coding agent to Figma: probe/repair the local Dev Mode MCP server across harnesses (ZCode, Claude Code, Codex, Cursor, Windsurf, VS Code, Gemini CLI), parse share links, and call Figma MCP tools from plain bash — no MCP client required.
