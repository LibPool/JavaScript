# figma-ball-knowledge

> 标签: claude-code, claude-plugin, design, figma

## 简介

Figma workflow skills for Claude Code: an orchestrator that parses designer intent, runs discovery against the Figma MCP, and progressively discloses capability files for frames, components, tokens, vectors, documentation, and code.
