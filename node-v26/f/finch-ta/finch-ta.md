# finch-ta

> 标签: JavaScript

## 简介

Finch TA is a technical analysis sub-library for Finch Library. It provides 100+ indicators such as ADX, MACD, RSI, Stochastic, Bollinger Bands, etc. It is based on Tulip Indicators and it will be extended gradually.
