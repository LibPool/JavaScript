# feishu-sso-login

> 标签: auth-server, feishu, lark, oauth, qrcode, scan-login, sso, 企业认证, 扫码登录, 飞书, 飞书扫码

## 简介

一个命令为任意静态网站叠加飞书扫码登录能力。零依赖，自包含认证服务器 + 登录页面，npx feishu-sso-login 即可使用。
