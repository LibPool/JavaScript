# fast-percentile

> 标签: p50, p95, p99, percentile, quantile, statistics

## 简介

Fastest percentile computation in TypeScript / JavaScript for unsorted dataset, 4~7x faster than the second fastest alternative, at all dataset sizes. Powered by quickselect algorithm.
