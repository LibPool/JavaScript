# fexp-file-explorer

> 标签: deepseek, dsh, dsh-plugin, file-explorer, harness, sidebar, workspace

## 简介

DSH 静态 bundle 插件：在左侧工作区浏览目录与文件。双入口（文件浏览/打开目录）、320px 浏览面板、文件预览、一键打开系统资源管理器、文件引用添加到聊天。A static-bundle DSH plugin: workspace file explorer in the left sidebar.
