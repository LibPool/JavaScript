# figqa

> 标签: agent-skill, ai-generated-code, ci, claude-code, design-ops, design-system, design-tokens, fig, figma, headless, kiwi, lint, linter

## 简介

Design-system QA for Figma files, with no Figma. Lint a .fig offline, check generated code against the same design system, and bind hard-coded colours to design tokens by writing the file back. No plugin, no seat, no Enterprise plan.
