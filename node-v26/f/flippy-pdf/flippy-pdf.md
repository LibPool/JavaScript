# flippy-pdf

> 标签: flipbook, issuu, magazine, page-flip, pdf, pdf-viewer, pdfjs, viewer

## 简介

A reusable, framework-free Issuu-style PDF flipbook viewer with two-page spreads, drag-to-flip, and a responsive single-page mode for mobile.
