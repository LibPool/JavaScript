# for-promise

> 标签: async, async-loop, asynchronous, await, control-flow, for-loop, for-promise, forEach, iterator, javascript, loop, nested-loop, promise, sequential, while-loop

## 简介

A lightweight utility to run async loops with full control using Promises — like for, forEach, and while, but smarter.
