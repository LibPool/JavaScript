# fuzzy-vir

> 标签: approximate, clustering, deduplication, fingerprint, fuzzy, jaccard, lsh, minhash, similarity, vir

## 简介

Fuzzy string matching via MinHash + LSH with O(1) lookup, designed for streaming use.
