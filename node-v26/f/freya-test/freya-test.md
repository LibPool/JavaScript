# freya-test

> 标签: JavaScript

## 简介

目录说明： assets 资源目录 build 发布脚本目录 dist 发布目录，重复发布时会清除前一次的文件 egret 白鹭资源和库目录，会拷贝发布后的resource整个目录，libs只会拷贝*.min.js libs javascript库目录，这个目录只会拷贝*.js release 存放发布需要替换的文件目录 src 代码目录
