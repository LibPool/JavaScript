# frc-ui-pro-light

> 标签: Component, React, UI

## 简介

这是宁波团队的前端UI框架, 继承于 `frc-ui-pro`, `frc-ui-pro` 是基于 `antd` 的二次封装, 本代码在其基础上, 加入了新的theme
