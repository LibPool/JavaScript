# frontend-logger-vue

> 标签: JavaScript

## 简介

基于 Sentry 协议的前端结构化日志插件，对接私有化部署的 [GlitchTip](https://glitchtip.com)，自动采集用户操作、HTTP 请求、错误信息，支持手动业务埋点。
