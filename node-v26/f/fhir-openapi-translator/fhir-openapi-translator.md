# fhir-openapi-translator

> 标签: capabilitystatement, code-generation, codegen, fhir, fhir-codegen, fhir-r4, fhir-r5, fhir-to-openapi, healthcare, healthcare-interoperability, hl7, hl7-fhir, openapi, openapi-generator, structuredefinition, swagger, us-core

## 简介

Generate an OpenAPI (Swagger) spec for any FHIR resource (R4/R4B/R5) — for typed model & client codegen in any language. Supports US Core profiles, operations, and CapabilityStatements.
