# fxabsolute-mcp

> 标签: backtesting, candles, claude, forex, market-data, mcp, modelcontextprotocol, trading

## 简介

Connect any coding agent to FXAbsolute's forex, index and crypto candle history — and to a trader's live chart — over MCP.
