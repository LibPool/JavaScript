# fat-docs

> 标签: ai, claude, claude-code, cursor, docs, embeddings, mcp, rag, semantic-search

## 简介

Local semantic search over a project's docs/ folder, exposed as an MCP server. Install once, query from any MCP client (Claude Code, Codex, Cursor, ...) across every project you own.
