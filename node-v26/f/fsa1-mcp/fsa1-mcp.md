# fsa1-mcp

> 标签: agents, excel, filesystem, mcp, spreadsheet, xlsx

## 简介

MCP server for FSA1: read and edit spreadsheets as a file tree. Tabs are folders, cells are files.

## 官网

- 官网：https://fsa1.sh
- 源码仓库：git+https://github.com/fredrikolis/FSA1.git
