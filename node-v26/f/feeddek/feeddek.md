# feeddek

> 标签: YQL, YQL API, atom, feed, jQuery, parser, reader, rss

## 简介

FeedDek is a jQuery plugin for parsing and displaying RSS and Atom feeds. FeedEk uses YQL API to retrieve feeds. You can obtain feeds easily from any domain. No need for server-side scripts.
