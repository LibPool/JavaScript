# franshiro-custom-admin

> 标签: admin, admin-panel, crud, dashboard, drizzle, drizzle-orm, express, vue, vue3

## 简介

Dynamic admin panel for Vue 3 + Express + Drizzle ORM. Auto-generates CRUD from your Drizzle schema; drop in custom Vue components with one line.
