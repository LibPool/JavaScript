# foxlend

> 标签: access-control, ai-agent, containers, cookies, firefox, foxgate, host-allowlist, login, revocation, session-delegation, typescript, webextension

## 简介

Firefox WebExtension library for AI agent login loans, cookie isolation, host allow lists, timed revocation, and foxgate grants.
