# flowarrow

> 标签: animation, arrow, gif, google-slides, mcp, mcp-server, slides, spinner, transparent-gif

## 简介

Generate flowing-arrow / spinner / highlight animation GIFs (transparent, slide-ready) from the CLI or via MCP. CLI/MCP companion of https://flow-arrow.com/
