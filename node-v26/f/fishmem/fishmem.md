# fishmem

> 标签: agents, ai, cloudflare, d1, embeddings, graph, llm, memory, postgres, rag, sqlite, vector

## 简介

Local-first TypeScript memory engine for AI agents with distilled records, source-preserving RAG, hybrid retrieval, and SQLite, Postgres, or Cloudflare storage.
