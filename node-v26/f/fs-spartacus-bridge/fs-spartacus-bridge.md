# fs-spartacus-bridge

> 标签: JavaScript

## 简介

Angular library that provides means to integrate cms data from the FirstSpirit CaaS into the SAP Commerce Cloud Spartacus storefront and manipulate it with FirstSpirit's Omnichannel Manager.
