# flask-feedback

> 标签: agent-skill, ai-agents, claude-code, cursor, human-in-the-loop, mcp, mcp-server, remotion, video-feedback, video-review

## 简介

One-shot setup for Flask (flask.do) - the video feedback MCP server for AI agents. Connects the MCP server to Claude Code and Cursor and installs the flask-review agent skill.
