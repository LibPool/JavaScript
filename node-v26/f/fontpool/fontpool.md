# fontpool

> 标签: claude, font-face, fonts, fontshare, fontsource, google-fonts, mcp, mcp-server, modelcontextprotocol, self-hosted, skill, type-design, typography, unifont, webfonts, woff2

## 简介

MCP server that searches Fontshare, Fontsource and Google as one catalog with categories, tags and foundry descriptions, downloads real woff2 files into your project and writes the @font-face rules.
