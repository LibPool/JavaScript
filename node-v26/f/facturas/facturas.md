# facturas

> 标签: afip, arca, argentina, facturacion-electronica, padron, wsaa, wsfe, wsmtxca

## 简介

SDK de facturación electrónica con ARCA / AFIP para Node.js: facturas, notas de crédito y débito, y Padrón con una sola API.
