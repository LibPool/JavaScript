# fotographia

> 标签: cr2, image, img, jpg, photos, raw

## 简介

A terminal app to convert .cr2 to .jpg extension. Helps to save memory on any Camera's SD card from needing to create duplicate image files. Finally, the small app aims to automate the manual labor of converting the raw images one-by-one.
