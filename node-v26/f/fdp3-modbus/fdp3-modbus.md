# fdp3-modbus

> 标签: fdp3, hvac, modbus, rs485, tcc-net, toshiba, vrf

## 简介

Node.js TypeScript client for the RealTime Control Systems FDP3-Modbus interface (Toshiba TCC-NET VRF/Split air-conditioning bridge)
