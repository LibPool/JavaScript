# foreman-mcp

> 标签: ai-agents, arc, circle, mcp, model-context-protocol, payments, usdc, x402

## 简介

MCP server that gives any AI agent (Claude Code, Cursor, Codex) a spending account, a hiring desk of specialist agents, and a credit line — settled in USDC on Arc.
