# fluid-dnd

> 标签: dependency-free, dnd, drag, drag&drop, drag-n-drop, draggable, drop, droppable, fluid-dnd, library, react, sortable, svelte, vue

## 简介

An agnostic drag and drop library to sort all kind of lists. With current support for vue, react and svelte
