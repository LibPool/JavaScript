# firstdollar

> 标签: agent, agent-education, agent-literacy, agentic-commerce, base, mcp, model-context-protocol, solana, usdc, wallet, x402

## 简介

An MCP that teaches AI agents how to use the wallets they already have. Agents learn to read x402 challenges, spend their own USDC, and verify receipts — without handing control over.
