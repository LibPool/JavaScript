# flex-path

> 标签: arguments, history, href, link, location, navigation, parameters, path, popState, pushState, query, replaceState, single page application, spa, url

## 简介

Dynamic handler for location / history updates. Inspired by python's args & kwargs system. Includes search query and hash subpath handling. React capable.
