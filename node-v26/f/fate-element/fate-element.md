# fate-element

> 标签: element-plus, typescript, vite, vue3, 二次封装, 动态表单

## 简介

FateElement 是一个强大而灵活的 Vue 3 组件库，基于 Element-Plus 构建。通过 TypeScript 和 Vite，它提供了高性能的动态表格、表单生成及命令式弹窗创建服务，让开发更简单高效！
