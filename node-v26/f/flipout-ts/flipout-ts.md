# flipout-ts

> 标签: edge-flip, flipout, geodesic, geodesic-distance, geodesic-path, geometry-central, geometry-processing, intrinsic-triangulation, mesh, three.js, triangle-mesh

## 简介

TypeScript port of FlipOut: fast geodesic paths on triangle meshes via edge flips (Sharp & Crane, SIGGRAPH Asia 2020). Built on geometry-central; works with Three.js.
