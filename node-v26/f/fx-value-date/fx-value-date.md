# fx-value-date

> 标签: business-day, currency, finance, foreign-exchange, forex, forward, fx, settlement-date, spot, trade-date, value-date

## 简介

FX settlement / value-date calculation — spot (T+2 / T+1), tom, forward tenors across two currency holiday calendars, with the USD intermediate-day rule, modified-following, and end-of-month. Zero dependencies (calendars injected).
