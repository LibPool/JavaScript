# fascicle

> 标签: agentic, agents, ai, ai-sdk, anthropic, bedrock, composable, gemini, harness, llm, lmstudio, multi-agent, observability, ollama, openai, openrouter, orchestration, pipeline, streaming, tool-calling, typescript, vercel-ai-sdk, workflow

## 简介

Compose agents like plain values. A TypeScript toolkit that wires LLM calls, tools, and functions into typed steps over eight providers. No framework, no ambient state.
