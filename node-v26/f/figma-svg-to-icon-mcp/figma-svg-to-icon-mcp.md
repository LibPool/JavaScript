# figma-svg-to-icon-mcp

> 标签: claude, copilot, design-system, figma, icons, mcp, model-context-protocol, react, svg, tsx

## 简介

MCP server that extracts SVG icons from Figma and generates React TSX icon components. Works with GitHub Copilot, Claude, and any MCP-compatible AI assistant.
