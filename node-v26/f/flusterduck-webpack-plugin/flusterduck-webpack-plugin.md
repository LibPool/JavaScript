# flusterduck-webpack-plugin

> 标签: auto-inject, build-plugin, bundler-plugin, click-tracking, dead-click, flusterduck, friction, rage-click, ux-analytics, webpack, webpack-plugin, webpack5

## 简介

Webpack plugin for rage click detection and UX friction tracking. Auto-injects Flusterduck SDK into your Webpack build.
