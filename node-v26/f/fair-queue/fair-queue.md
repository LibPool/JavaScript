# fair-queue

> 标签: best-effort, fair-queue, load-balancing, priority-queue, queue, rate-limit, rate-limiting, request-queue, task-queue, throttling, typescript, weighted-queue

## 简介

A fair, queue-based rate-limiting library with configurable selection modes, balancing queue size and wait time to prioritize task processing.
