# fretboard-renderer-core

> 标签: custom-element, fretboard, guitar, music-theory, svg, web-component

## 简介

Platform-agnostic fretboard-diagram parsing, music-theory, and SVG-rendering core for fretboard-renderer (Obsidian plugin) and fretboard-renderer-vscode.
