# freegate

> 标签: deepseek, failover, free, gateway, gemini, groq, llm, llm-gateway, mistral, multi-provider, openai, proxy, self-hosted, vision

## 简介

Free multi-provider LLM gateway with automatic failover. One OpenAI-compatible endpoint routes to many free models (Groq, Mistral, Gemini, NIM, OpenRouter, ZAI, Cerebras, DeepSeek and more). Never pay for LLMs.
