> 标签: agent-skill, ai, claude, claude-code, flutter, flutter_miuix, glass, hyperos, hyperos4, miui, miuix, os4, skill

## 简介

AI agent skill for the flutter_miuix component library (HyperOS / MIUI-style Flutter widgets), including the opt-in HyperOS 4 glass components. Installs a Claude Code / Agent Skill so AI gets correct component usage, patterns, and gotchas.
