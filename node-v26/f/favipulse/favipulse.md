# favipulse

> 标签: badge, environment, favico, favicon, generative, identicon, nextjs, notification, progress, pwa, svg, tinycon, vite-plugin

## 简介

Tiny (<3 KB gz), zero-dependency, typed favicon library: deterministic generative/identicon favicons from a seed with self-drawing animation, badges, progress rings and pulse, plus per-environment (dev/staging/prod) icons. CLI generates svg/ico/png sets +
