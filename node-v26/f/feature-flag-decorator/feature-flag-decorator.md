# feature-flag-decorator

> 标签: JavaScript

## 简介

A simple decorator that will only execute the wrapped method if the given feature flag is set. (e.g.: `@FeatureFlag('DEBUG_COLLISIONS')` will only let a method execute if `process.env.DEBUG_COLLISIONS` has been set to a truthy value)
