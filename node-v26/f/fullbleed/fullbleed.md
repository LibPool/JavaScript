# fullbleed

> 标签: cloudflare-workers, components, fullbleed, html-to-pdf, invoice, jsx, pdf, pdf-generation, reports, rust, webassembly

## 简介

Generate PDFs from HTML/CSS, components or JSX in Node.js, browsers and Cloudflare Workers, with bundled fonts and PNG previews.
