# fastx402-mcp

> 标签: ai-agents, base, mcp, micropayments, model-context-protocol, solana, tools, usdc, x402

## 简介

MCP server for FastX402: 80+ pay-per-call tools for AI agents (media, QR codes, data conversion, dates, crypto and chain reads, web tools), paid per call in USDC with x402 on Base or Solana.
