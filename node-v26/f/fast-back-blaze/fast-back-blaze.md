# fast-back-blaze

> 标签: cloudflare, file-storage, file-upload, nodejs, r2, s3-compatible, storage

## 简介

A Node.js module to simplify BackBlaze R2 interactions, providing an instance-based API for uploads, deletions, and URL generation.
