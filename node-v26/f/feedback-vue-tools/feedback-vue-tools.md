# feedback-vue-tools

> 标签: alert, components, drawer, feedback, loading, message, modal, notification, progress, tooltip, vue

## 简介

Vue 反馈组件库，包括  Modal（对话框）、Drawer（抽屉）、Message（消息提示）、Notification（通知）、Alert（警告）、Progress（进度条）、Loading（加载）、Tooltip（文字提示） 组件.
