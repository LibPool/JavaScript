# fetchbot

> 标签: JSON API, automation, browser, chrome, chromium, crawler, declarative, puppeteer, workflow

## 简介

A library and shell command that provides a simple JSON-API to perform human like interactions and data extractions on any website. Built on top of puppeteer.
