# face-sdk-extractor

> 标签: JavaScript

## 简介

Vue 3 人脸特征提取组件。组件只负责选图、裁剪、人脸检测、SDK 标准 5 点对齐和 512 维特征提取；人员 ID、分组、入库和接口提交由业务层处理。
