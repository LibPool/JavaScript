# fusionrouter-mcp

> 标签: describe, image, mcp, model-context-protocol, opencode, stdio, vision

## 简介

本地 stdio MCP 桥：动态透传远程 opencode-api 的 MCP 工具（describe_image 识图 / web_search 联网搜索），本地图片路径自动转 data URI
