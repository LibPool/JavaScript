# fina-table

> 标签: ag-grid, duckdb, grouping, infinite-scroll, lod, olap, parquet, pivot, react, ssrm, table, theme

## 简介

Self-contained React table for ag-grid Server-Side Row Model OLAP engines (fina-olap) — remembered grouping, infinite scroll, dark/light themes, per-level aggregations and a 4-panel config dropdown.
