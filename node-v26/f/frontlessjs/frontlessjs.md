# frontlessjs

> 标签: JavaScript

## 简介

Install Bun if not installed. ```console curl -fsSL https://bun.sh/install | bash ``` Create a directory, and initialize your project. ```console mkdir myserver cd myserver bun init ``` Install frontlessjs. ```console bun add frontlessjs ```
