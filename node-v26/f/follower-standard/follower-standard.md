# follower-standard

> 标签: audit, authenticity, bot-detection, fake-followers, follower-quality, followers, scorer, social-media, twitter, x

## 简介

An open, transparent scorer for X/Twitter follower authenticity — the reference implementation of the TweetBoost Follower Standard. Pure functions, no network, no secrets.
