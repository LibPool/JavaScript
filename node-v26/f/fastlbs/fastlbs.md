# fastlbs

> 标签: api, aws, aws-lambda, boilerplate, cli, documentation, esbuild, generator, jest, lambda, node, nodejs, openapi, project-generator, rest-api, scaffold, serverless, serverless-offline, swagger, ts-jest, typescript

## 简介

FastLBS CLI to scaffold AWS Lambda APIs in TypeScript, run locally with serverless-offline, test with Jest, and compile to Node.js JavaScript using esbuild.
