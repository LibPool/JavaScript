# finegl-cesium

> 标签: 3D, cesium, finegl, finegl-cesium, geospatial, gis, globe, map, vue, vue3, webgis, webgl

## 简介

finegl-cesium是基于CesiumJS的开源三维地球和地图引擎，修改了部分CesiumJS源码文件，CesiumJS 是一个用于在浏览器中创建 3D 球体和 2D 地图的 JavaScript 库。
