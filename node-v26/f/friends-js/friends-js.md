# friends-js

> 标签: contacts, friends, indexer

## 简介

FriendsJS constructs an indexexed database of contact information, such as email addresses and phone numbers. This enables real-time searching, either by a person's name or by their contact information. ## Installation FriendsJS can be installed with NPM:
