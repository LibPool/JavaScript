# fetch-fun

> 标签: fetch, functional, http, http-client, middleware, pipe, retry, standard-schema, timeout, typed

## 简介

Functional fetch toolkit: pipeable config functions over a plain options object, typed data flow, Standard Schema validation, smart retry and per-attempt timeout. Zero dependencies.
