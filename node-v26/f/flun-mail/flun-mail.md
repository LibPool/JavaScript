# flun-mail

> 标签: aws, email, email-sender, flun, mail, mailer, sendmail, ses, smtp, smtp-pool, transport

## 简介

A powerful and flexible email sending library for Node.js with multiple transport support (SMTP, SMTP Pool, Sendmail, Stream, JSON, SES)
