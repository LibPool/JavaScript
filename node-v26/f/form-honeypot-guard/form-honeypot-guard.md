# form-honeypot-guard

> 标签: altcha, anti-spam, astro, bot, bot-protection, captcha, captcha-alternative, cloudflare, express, fastify, form, hmac, honeypot, nextjs, proof-of-work, rate-limit, react, redis, remix, security, spam, sveltekit, upstash, vite, vite-plugin, webpack, webpack-plugin

## 简介

Block form spam bots without a captcha: honeypot + signed timing tokens + JS proof + optional Altcha-style proof-of-work + rate limiting. Webpack 5 and Vite plugins, a <2 kB client, Express/Fastify/Next/SvelteKit/Remix/Astro helpers, and a React wrapper.
