# front-starter

> 标签: concat, config, environment, front, js, less, minimal, sass, uglify, watch

## 简介

Configure Grunt tasks like a breeze ! Configure Grunt tasks with a config.json file to use Sass, Less, Uglify, Concat, Watch... without editing the Gruntfile.js
