# fta-react-components

> 标签: JavaScript

## 简介

起源于零担专线业务，在保留原有 antd 组件的所有功能下，对一些公用接口和逻辑进行了封装，尽可能减少组件使用时需要处理的逻辑。逐步改善管理后台开发体验。
