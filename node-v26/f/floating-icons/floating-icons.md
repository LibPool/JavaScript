# floating-icons

> 标签: animation, bubble, bubbles, effect, facebook, float, floating, icon, icons, meta, reaction, reactions

## 简介

An easy-to-use npm package that creates a fun floating emojis (or icons) animation effect that can be used to spice-up user interaction or for any other purpose. Works with all frameworks and libraries.
