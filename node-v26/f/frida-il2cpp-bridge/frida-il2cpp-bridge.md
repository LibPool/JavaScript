# frida-il2cpp-bridge

> 标签: dump, frida, frida-gum, frida-gum-bridge, global-metadata, il2cpp, trace

## 简介

A Frida module to dump, trace or hijack any Il2Cpp application at runtime, without needing the global-metadata.dat file.
