# fetchwise

> 标签: backoff, exponential-backoff, fetch, fetch-retry, http, resilient, retries, retry, retry-after, timeout, zero-dependency

## 简介

Tiny, zero-dependency resilient fetch wrapper: retries, exponential backoff, timeouts, Retry-After — plus fetchJson (typed JSON + HttpError). Works in Node, Deno, Bun and the browser.
