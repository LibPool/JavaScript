# figma-mcp-full-server

> 标签: anthropic, api, claude, design, design-tools, figma, image-export, mcp, model-context-protocol, style-extraction, svg

## 简介

A Model Context Protocol (MCP) server for Figma API integration with Claude Desktop. Extract images, styles, SVG data, and design elements from Figma files.
