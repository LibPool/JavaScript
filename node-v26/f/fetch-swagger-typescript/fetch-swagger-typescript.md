# fetch-swagger-typescript

> 标签: JavaScript

## 简介

1. 功能    1.  根据 SwaggerUI doc 接口数据 生成 typescript 接口类型定义，支持cjs, esm方式引用。详细使用方法见根目录examples文件夹 2. 使用方法    1.  npm install fetch-swagger-typescript --save-dev /
