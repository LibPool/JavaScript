# fetch-node-release

> 标签: lts, node, version

## 简介

Fetch latest Node.js release version by keyword such as "stable", "lts/carbon" or "lts/*"

## 官网

- 官网：https://github.com/panva/fetch-node-release
- 源码仓库：git+https://github.com/panva/fetch-node-release.git
- npm 页面：https://www.npmjs.com/package/fetch-node-release

## 获取地址

- npm 安装：`npm install fetch-node-release`
- npm registry：https://registry.npmjs.org/fetch-node-release
- Node 要求：>=4.0.0
