# file-preview-lib

> 标签: JavaScript

## 简介

一款专为 Vue3 设计的多功能文件预览工具库，支持 PDF、Word、Excel（含旧版 XLS）、图片、代码类文件（JSON/XML/SQL/CSV 等）预览，采用模块化设计，易于扩展，风格统一且质感高级。
