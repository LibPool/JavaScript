# fetchui

> 标签: cli, codegen, components, custom-ui, design-system, fetch, frontend, react, snippets, svelte, ui, vue

## 简介

FetchUI is a CLI tool that lets you fetch, copy and inject fully customizable UI components directly into your codebase. No runtime UI library, no lock-in — just your code.
