# ffmpeg-cmd-viewer

> 标签: JavaScript

## 简介

鉴于 FFmpeg 命令经常又臭又长，导致阅读十分困难。所以本项目用来格式化 FFmpeg 命令，以更清晰地阅读命令中的参数。
