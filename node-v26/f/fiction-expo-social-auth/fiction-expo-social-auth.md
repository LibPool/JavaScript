# fiction-expo-social-auth

> 标签: angular, apple-signin, effortless-social-logins, expo, expo-auth, facebook-signin, google-signin, nextjs, oauth, react, react-native, social-auth, social-media-login-provider, svelte, universal, vue, vue3

## 简介

Effortless social authentication for React, React Native (Expo), Vue.js, Svelte, and Next.js. Supports Google, Facebook, and Apple Sign-In with a unified API.
