# foodpanda-ai-mcp

> 标签: ai, anthropic, claude, delivery-hero, food-delivery, foodpanda, llm, mcp, mcp-server, model-context-protocol, modelcontextprotocol, restaurants

## 简介

Unofficial MCP server for foodpanda / Delivery Hero public discovery data — search restaurants, menus, fees and deals across 10 markets. Read-only, no API key, no account, no ordering.
