# flowengine-mcp-app

> 标签: deprecated-alias, flowengine, mcp

## 简介

Renamed to @flowengine.cloud/flowengine-cli. This thin shim re-exports the MCP server so existing `npx -y flowengine-mcp-app` configs keep working unchanged.
