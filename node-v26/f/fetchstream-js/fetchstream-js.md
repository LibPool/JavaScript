# fetchstream-js

> 标签: axios, fetch, incremental, json, jsonpath, parser, performance, progressive, react, sax, stream, streaming, ttfb

## 简介

Drop-in replacement for fetch() and axios.get() for JSON endpoints. Renders data as bytes arrive instead of waiting for the full response. One-line React integration via .live().
