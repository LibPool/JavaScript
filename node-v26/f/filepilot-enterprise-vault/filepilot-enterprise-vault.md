# filepilot-enterprise-vault

> 标签: audit-log, filepilot, kms, microservice, security, vault

## 简介

FilePilot Corporate Vault Integration Microservice. Simulates/proxies HashiCorp Vault API and serves encrypted Connection Profiles with security audit logging and BYOK KMS support.
