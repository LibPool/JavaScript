# fetch-clean-markdown-mcp

> 标签: agent-tool, cloudflare-workers, context-grounding, fetch, html-to-markdown, llm, markdown, mcp, mcp-server, model-context-protocol

## 简介

A stateless remote MCP server deployed as a Cloudflare Worker that fetches URLs and returns clean, LLM-optimized Markdown via Jina AI Reader. Also runnable locally via stdio.
