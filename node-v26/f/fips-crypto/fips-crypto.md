# fips-crypto

> 标签: browser, cryptography, dilithium, fips-203, fips-204, fips-205, kyber, ml-dsa, ml-kem, nodejs, post-quantum, pqc, slh-dsa, sphincs, typescript, wasm, webassembly

## 简介

Post-quantum cryptography library implementing FIPS 203 (ML-KEM), FIPS 204 (ML-DSA), and FIPS 205 (SLH-DSA) with Rust/WASM, typed APIs, integrity checks, and Rust-side secret zeroization.
