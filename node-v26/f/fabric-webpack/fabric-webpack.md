# fabric-webpack

> 标签: HTML5, SVG, canvas, graphic, graphics, node-canvas, object model, parser

## 简介

Object model for HTML5 canvas, and SVG-to-canvas parser. Backed by jsdom and node-canvas.

## 官网

- 官网：http://fabricjs.com/
- 源码仓库：git+https://github.com/kangax/fabric.js.git
- npm 页面：https://www.npmjs.com/package/fabric-webpack

- npm registry：https://registry.npmjs.org/fabric-webpack
