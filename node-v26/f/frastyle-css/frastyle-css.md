# frastyle-css

> 标签: css, flexbox, framework, frastyle, frontend, indonesia, modern, responsive, website

## 简介

Frastyle Framework merupakan sebuah framework Cascading Style Sheets yang dibuat di Indonesia untuk dapat membantu developer dalam mengembangkan antarmuka website Modern dan Responsif. Didukung dengan dokumentasi bahasa Indonesia.
