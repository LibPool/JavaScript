# features-manager

> 标签: AB Testing, Conditional Activation, Configuration, Deployment, Feature Management, Features Manager, Percentage Rollouts, Toggle, TypeScript, User-Specific Rules

## 简介

A lightweight TypeScript-based feature flag manager that enables conditional feature activation based on user-specific rules and percentage rollouts.
