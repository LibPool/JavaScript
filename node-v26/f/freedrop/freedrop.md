# freedrop

> 标签: airdrop, croc, file-transfer, p2p, serverless, webrtc, wormhole

## 简介

Direct file transfer between CLIs and browsers. No server touches your bytes: rendezvous over public MQTT brokers (encrypted), data over WebRTC, end to end.
