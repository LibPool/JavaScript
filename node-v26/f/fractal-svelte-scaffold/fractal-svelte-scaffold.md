# fractal-svelte-scaffold

> 标签: cli, create, cube-css, fractal-agentic, sass, scaffold, svelte, sveltekit, template

## 简介

Scaffold a mature, agent-ready SvelteKit + Svelte 5 + CUBE CSS + indented SASS project. Batteries included, with an on-disk agent CLI.
