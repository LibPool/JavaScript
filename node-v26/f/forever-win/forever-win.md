# forever-win

> 标签: cli, fault tolerant, sysadmin, tools

## 简介

Windows fork of forever, a simple CLI tool for ensuring that a given node script runs continuously (i.e. forever)

## 官网

- 源码仓库：https://github.com/dci-artform/forever-win.git
- npm 页面：https://www.npmjs.com/package/forever-win

- npm registry：https://registry.npmjs.org/forever-win
- Node 要求：>= 0.8.x
