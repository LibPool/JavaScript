# fragrance-dupes

> 标签: dupe, fragrance, jaccard, notes, parfica, perfume, pyramid, similarity, smells-like

## 简介

Zero-dependency 'smells like' scoring for perfumes: note-overlap match % between fragrance pyramids (top/heart/base), distinctive-note selection by global rarity, and dupe ranking — the algorithm behind parfica.com's dupe finder.
