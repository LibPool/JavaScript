# feistly

> 标签: auto-increment, encryption, feistel, format-preserving, hashids-alternative, id-obfuscation, obfuscation, security, sqids-alternative, url-shortener

## 简介

Secure, lightweight library for obfuscating auto-increment IDs with Feistel cipher - prevents ID enumeration attacks while keeping URLs short
