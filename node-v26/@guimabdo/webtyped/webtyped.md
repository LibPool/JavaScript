# @guimabdo/webtyped

> 标签: ASP.NET Web API, C#, TypeScript, angular, fetch, generator, jQuery, transpiler

## 简介

WebTyped is a tool for generating strongly typed TypeScript code from your http://ASP.NET or http://ASP.NET/core Web Apis.
