# @aronvaughan/punchlist

> 标签: agents, ai-agents, claude, delegation, hono, self-hosted, sqlite, task-manager, tasks, todo

## 简介

Agent-first task manager: a Things-style drag-and-drop web app for humans, the same REST API + ready-made skills for AI agents, with claim/finish/report delegation and a review lane
