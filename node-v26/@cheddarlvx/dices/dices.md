# @cheddarlvx/dices

> 标签: JavaScript

## 简介

~'d2()' returns either 1 or 2. ~'d3()' returns 1, 2, or 3. ~'d4()' returns 1, 2, 3 or 4. ~'d6()' returns from 1 to 6. ~'d10()' returns from 1 to 10. ~'d20()'
