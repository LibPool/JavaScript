# @dokki-lab/cli

> 标签: agents, ai-agents, automation, claude-code, cli, codex, collaboration, documents, dokki, mcp, workspace

## 简介

The Dokki command line: every Dokki API and MCP action from a terminal or a script, and the bridge that makes Claude Code, Codex or your own bot a Dokki agent people can @mention.
