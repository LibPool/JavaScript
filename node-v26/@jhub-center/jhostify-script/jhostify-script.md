# @jhub-center/jhostify-script

> 标签: JHub, be-only, framework, from, jhub, jsonly, learning, nohtml, scratch, typescript-only

## 简介

The frontend framework to reduce the use of HTML to none, and be able to use configuration to build the whole website. Made for the JHub project
