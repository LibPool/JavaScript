# @ghostpaw/telegram

> 标签: agent, ai, ai-agent, bot, bot-framework, chatbot, ghostpaw, grammy, llm, llm-tools, local-first, mcp, messaging, multi-agent, node-sqlite, sqlite, telegram, telegram-bot, telegrambot, tools, typescript, webhook

## 简介

Telegram bot channel engine — grammy transport, SQLite message mirror, FTS5 full-text search, markdown rendering, and a structured LLM tool facade. Node 24+, built-in node:sqlite.
