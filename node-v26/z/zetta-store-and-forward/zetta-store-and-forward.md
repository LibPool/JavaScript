# zetta-store-and-forward

> 标签: zetta

## 简介

Buffer device data going to the cloud until a peer is connected or reconnects. This module is an app that plugs into [Zetta](http://zettajs.org) By default this module stores events in an in memory FIFO that starts to overwrite it's self after 100,000 eve
