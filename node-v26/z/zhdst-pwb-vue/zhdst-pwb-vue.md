# zhdst-pwb-vue

> 标签: personal workbench, pwb, zhdst

## 简介

这是一个集成项目，主要实现：<br> 1.布局页面<br> 2.根据权限系统中的菜单以及用户自定义的配置显示系统。<br> 3.固定实现一个首面,首面中显示的内容，从其它系统中引入。<br> 4.此项目是最终交付用户的结果，不被其他项目引用，只引用其他项目。<br>
