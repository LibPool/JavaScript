# zwj_calculator

> 标签: JavaScript

## 简介

帆软考核项目6的四则运算器npm包, 输入为1个包含data和formula属性的对象. 其中formula为计算公式, data为公式中变量对应的值。例子:
{ formula: '(x+y)*z', data: { x: 0.1, y: 0.2, z: 1 } }返回为计算公式的值
