# zero-backend

> 标签: automation, backend, backend generator, boilerplate, cli, express, nodejs, scaffold, typescript, zero

## 简介

A config-driven backend generator that allows developers to define models, features, and structure in a simple config file, and automatically generates a complete, scalable backend with zero repetitive coding.
