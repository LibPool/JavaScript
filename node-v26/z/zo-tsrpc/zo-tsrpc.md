# zo-tsrpc

> 标签: fullstack, grpc, k8w, protobuf, rpc, socket.io, ts, tsbuffer, websocket

## 简介

A TypeScript RPC Framework, with runtime type checking and built-in serialization, support both HTTP and WebSocket.
