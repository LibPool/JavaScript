# zod-timezone-validation

> 标签: canonical, iana, iana-timezone, intl, timezone, timezone-validation, timezones, typescript, tz, tz-database, validation, zod, zod-schema

## 简介

Zod schemas for validating IANA timezone strings: strictly canonical, non-canonical allowed, or coerced to canonical. Uses the native Intl API — zero dependencies, no bundled timezone database.
