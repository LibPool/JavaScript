# zjuvai-cli

> 标签: JavaScript

## 简介

使用 cra 生成项目后，通常需要二次配置，这对于开发者来说不可接受，因此开发了一款脚手架，它支持了对预处理器以及 css 模块化的配置，开箱即用。
