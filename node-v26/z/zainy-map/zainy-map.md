# zainy-map

> 标签: amap, claude-code, codex, map, skill, 高德

## 简介

一条命令装一个地图 skill（Claude Code / Codex）：周边探索、赶车前吃饭。结果上传到 map.zainy.art，回复一个可以转发的链接。

## 官网

- 官网：https://map.zainy.art
- npm 页面：https://www.npmjs.com/package/zainy-map

- npm registry：https://registry.npmjs.org/zainy-map
