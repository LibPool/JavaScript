# zammad-remote-mcp

> 标签: ai, cloudflare-workers, edge, helpdesk, hono, llm, mcp, model-context-protocol, ticketing, zammad

## 简介

Stateless remote MCP server for Zammad — full ticket operations, an intelligent search layer and OAuth 2.1, running on Node.js or Cloudflare Workers from one codebase.
