# zimra-fdms

> 标签: fdms, fiscalisation, fiscalization, invoice, mcp, model-context-protocol, pos, receipt, tax, vfd, zimbabwe, zimra

## 简介

TypeScript SDK for the ZIMRA Fiscalisation Data Management System (FDMS): a portable fiscal core with device registration, mTLS, receipt signing, fiscal days, offline queue and QR codes, plus Node, CLI and MCP adapters
