# zpy-tools

> 标签: base64ToFile, dateDiff, dateFormat, debounce, deepClone, fileSizeConvert, fileSizeFormat, fileToBase64, hasObjectsEqual, markdownToWechatText, sortArray, throttle

## 简介

提供了日期格式化、日期计算、文件格式化、本地缓存处理、Base64转File、File转Base64、节流防抖、数组排序、数据结构转化、Markdown 转为适合微信分享的纯文本、深度比较两个对象是否包含相同的值等相关功能
