> 标签: aa, account-abstraction, agent, cli, wallet, workflow, zksync, zksync-era

## 简介

Local-first zkSync Era and ZK Stack agent CLI with wallet session recovery, workflow orchestration, relay-backed approval, and SED smart-account support.
