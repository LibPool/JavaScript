# zayra-sdk

> 标签: ai, developer-tools, plugins, providers, sdk, tools, zayra

## 简介

Unified developer interface for the ZAYRA AI ecosystem — access to core, memory, tools, plugins, providers, events, and safe config, plus helpers for building custom tools, providers, and plugins.
