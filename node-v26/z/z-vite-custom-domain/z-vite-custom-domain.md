# z-vite-custom-domain

> 标签: /etc/hosts, custom domain, plugin, vite, vite plugin, vite plugin custom domain

## 简介

Allows you to use a custom domain name when developing locally. It does this by modifying your /etc/hosts file. Forked from Lubiah's vite-plugin-custom-domain
