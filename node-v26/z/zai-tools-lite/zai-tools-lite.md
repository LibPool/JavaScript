# zai-tools-lite

> 标签: glm, mcp, pi, pi-coding-agent, pi-extension, pi-package, reader, vision, web-reader, z-ai, zai, zhipu, zread

## 简介

Lean Z.ai tools for pi: URL reader, GitHub zread lookup, and image/video vision. No search tool (use pi-web-access). Minimal token footprint.
