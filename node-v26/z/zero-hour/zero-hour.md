# zero-hour

> 标签: a11y, accessibility, component, countdown, countdown timer, custom elements, custom-elements, date, digital, dom, frontend, library, shadow dom, shadow-dom, sprite, time, timer, typescript, ui, utc, web component, web-component, zero-hour

## 简介

Tiny countdown Web Component. Registers <countdown-timer> that renders a configurable DD:HH:MM:SS countdown to a target date/time (optional UTC offset) and fires a done event at zero.
