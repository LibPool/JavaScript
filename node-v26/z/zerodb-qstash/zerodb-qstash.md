# zerodb-qstash

> 标签: agent-queue, ai-agent, ainative, async-tasks, auto-provisioning, background-jobs, cloud-queue, cron, cron-jobs, event-driven, event-stream, mcp, message-queue, pub-sub, publish-subscribe, pubsub, qstash, qstash-alternative, scheduled-messages, serverless-queue, task-queue, topic-routing, upstash, upstash-qstash, webhook, zerodb

## 简介

Drop-in Upstash QStash replacement backed by ZeroDB event stream. Publish messages, schedule recurring tasks — zero config, auto-provisions on first use.
