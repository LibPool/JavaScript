# zn-plugin-wechat

> 标签: plugin, wechat, zn, zn-plugin, 微信公众号

## 简介

前端基于zeanium-react-web框架, 后端基于zeanium-node框架的微信公众号模块，如需开发微信公众号，只需要在zn项目中安装改插件即可使用
