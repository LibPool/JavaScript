# zoom-by-ironex

> 标签: es5, in, js, lightweight, plugin, vanilla, written, zoom

## 简介

Zoom - lightweight (8Kb) ES5 javascript plugin without any dependencies, compatible with desktop and mobile devices. Supports doubleclick, mousemove, mousewheel, doubletap, touchmove and pinch events.
