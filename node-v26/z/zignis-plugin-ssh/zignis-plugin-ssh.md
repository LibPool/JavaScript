# zignis-plugin-ssh

> 标签: JavaScript

## 简介

zignis-plugin-ssh 顾名思义，这是一个用来管理 ssh 账号的命令行工具，基于 `Zignis`，能够完成添加账户，列表和查询账户，删除账户，登录账户等操作，而且具有一定的安全性
