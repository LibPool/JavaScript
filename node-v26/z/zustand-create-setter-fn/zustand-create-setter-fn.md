# zustand-create-setter-fn

> 标签: create-setter, factory, generics, react-zustand, set-state, setstate, setter-function, state-management, state-setter, state-updater, store-setter, store-updater, type-safe, typescript, update-state, utility, zustand, zustand-utils, zustand-vanilla

## 简介

A fully type safe utility for Zustand that allows you to easily update state using React style `setState` functions (framework agnostic, doesn't require React).
