# zq-compare-version

> 标签: JavaScript

## 简介

```typescript  // 实例出一个 Version 对象，填入两个比较的参数，进行比较，控制台看结果。 const v1 = '1.2.4b', v2 = '1.2.3a'; new Version(v1, v2); // return 1 => v1 大 ```
