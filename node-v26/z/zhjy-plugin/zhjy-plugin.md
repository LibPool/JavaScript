# zhjy-plugin

> 标签: screen, vue

## 简介

你的大屏还需要每次新项目都重新设计吗? ZHJY-UI将大屏界面全面组件化 包含头部，标题，文字，布局，图表，看板，按钮...... 丰富的组件等你来使用！！ <br/>
