# zephyr-framework

> 标签: a2ui, agent-ui, agentic-ui, ai-agent, ai-tools, charts, css, custom-elements, dashboard, llm, mcp, model-context-protocol, ui-framework, vercel-ai-sdk, web-components, zero-js

## 简介

The first UI framework built for AI agents. 14 web components with pure CSS interactions, zero runtime JavaScript. Built-in MCP server, A2UI catalog, and structured Agent API.
