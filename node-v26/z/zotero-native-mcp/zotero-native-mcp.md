# zotero-native-mcp

> 标签: academic-research, anthropic, bibliography, bibtex, citations, claude, claude-code, local-first, mcp, mcp-server, model-context-protocol, offline, reference-manager, zotero, zotero-10

## 简介

MCP server for Zotero 10+. Read and write your library entirely offline through Zotero's native local API. No plugin, no API key, no cloud.
