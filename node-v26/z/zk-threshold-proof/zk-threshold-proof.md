# zk-threshold-proof

> 标签: blockchain, cryptography, privacy, zero-knowledge, zk-proof, zk-threshold, zkp

## 简介

A lightweight SDK to generate and verify ZK proofs that assert a private value is greater than or equal to a threshold.
