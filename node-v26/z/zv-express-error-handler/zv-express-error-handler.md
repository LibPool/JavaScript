# zv-express-error-handler

> 标签: express, middleware, operational errors, uncaught exception, unhandled rejection, utilities

## 简介

Provides a class for handling various operational errors and provides middlewares and utilities to catch async function errors, unhandled rejection, and uncaught exceptions in a node-express with MongoDB application.
