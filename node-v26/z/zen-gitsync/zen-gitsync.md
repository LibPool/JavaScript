# zen-gitsync

> 标签: ai-commit, automation, commit-message, conventional-commits, cron, developer-tools, git, git-auto-commit, git-automation, git-cli, git-gui, git-sync, git-workflow, gitsync, productivity

## 简介

Auto commit, scheduled sync, and visual GUI for Git. Run `g` in any repo for one-key commit & push, AI commit messages, scheduled background sync, and a drag-and-drop workflow builder.
