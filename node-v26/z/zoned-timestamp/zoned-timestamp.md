# zoned-timestamp

> 标签: time-zone, timestamp, zoned-timestamp

## 简介

zoned-timestamp 是一个将某一刻的时间戳，转为特定时区的显示时间的工具.Zoned-timestamp is a tool that converts a certain timestamp to the display time of a specific time zone.
