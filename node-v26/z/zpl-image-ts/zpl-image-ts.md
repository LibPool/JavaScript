# zpl-image-ts

> 标签: barcode, bitmap, esm, gfa, label, label-printer, rgba, typescript, z64, zebra, zpl

## 简介

Image to Zebra ZPL: encode RGBA bitmaps to ^GFA (Z64 + ACS), wrap in ^XA…^XZ with darkness/print-rate/copies. TypeScript-native, isomorphic, tree-shakeable ESM port of metafloor/zpl-image.
