# zigbee2mqtt-mcp

> 标签: home-automation, iot, mcp, model-context-protocol, mqtt, smart-home, zigbee, zigbee2mqtt

## 简介

Model Context Protocol server for administering a Zigbee2MQTT estate: health reporting, network diagnostics, OTA updates, pairing and device management over the MQTT bridge API.
