# zzh-axios

> 标签: JavaScript

## 简介

1.  请求数据拦截器 2.  响应数据拦截器 3.  支持 promiseAPI 4.  支持请求数据和响应数据转换 5.  JSON 数据自动转换 6.  客户端防止 XSRF
