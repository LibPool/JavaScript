# @unified-communications/meeting-sdk

> 标签: JavaScript

## 简介

这是 Unified Communications 的非 iframe Vue SDK。它直接使用短期会议会话连接 Room WebSocket 和 WHIP/WHEP 媒体服务，默认组件提供与平台会议页一致的会议界面，同时允许业务方替换邀请、结束会议、功能开关和外层样式。
