# @mouneshazonde/create-react-tailwind-app

> 标签: JavaScript

## 简介

**@mouneshazonde/create-react-tailwind-app** is a command-line tool that automates the setup of a Create React App project with Tailwind CSS pre-configured. This tool streamlines the process, allowing you to start building your React project with Tailwind
