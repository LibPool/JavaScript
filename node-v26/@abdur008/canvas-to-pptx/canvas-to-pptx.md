# @abdur008/canvas-to-pptx

> 标签: canvas-export, diagram-to-pptx, docx-export, powerpoint-export, pptx-generator, pptxgenjs

## 简介

Enterprise presentation and document exporter that converts canvas node graphs, diagrams, and blueprints into native Microsoft PowerPoint (.pptx) and Word (.docx).
