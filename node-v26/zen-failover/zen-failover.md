# zen-failover

> 标签: chatgpt, failover, opencode, opencode-go, opencode-plugin, quota, rate-limit, subscription

## 简介

OpenCode V2 server plugin: when a subscription provider's usage limit is hit, move every agent, the default model and the active session to its fallback, probe the plan once a minute and come back as soon as it answers again.
