# @lhacenmed/react-native-dropdown-menu

> 标签: DropdownMenu, expo, react-native, react-native-dropdown-menu

## 简介

This an expo module that exposes the native android popup menu api for usage in a react native (Expo) app, it uses Cascade Popup Menu (saket/cascade) to create nice transitions between sub-menus, it's currently for Android users only.
