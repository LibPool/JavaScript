# @voidbase-cloud/plugin-auth

> 标签: auth, cloudflare-workers, voidbase, voidbase-plugin

## 简介

The auth plugin of voidbase: provides auth@1, mounting password, OAuth2, OTP, MFA and passkey sign-in and answering who a request is
