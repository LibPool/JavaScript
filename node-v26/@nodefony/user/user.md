# @nodefony/user

> 标签: argon2, authentication, bcrypt, esm, nodefony, password, typescript, user

## 简介

Contrats utilisateur de Nodefony, indépendants de l'ORM : interface IUser, utilisateurs de base, encodeurs de mot de passe et UserService — consommable sans @nodefony/security
