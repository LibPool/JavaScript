# supabase-grants-check

> 标签: ci, grants, postgres, postgrest, rls, row-level-security, security, supabase

## 简介

See who can reach your Supabase tables and functions through the Data API, and fail CI when a table is open with row level security off or your server key loses new tables after 30 Oct 2026.
