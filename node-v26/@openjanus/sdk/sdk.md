# @openjanus/sdk

> 标签: amount-disclose, babyjub, blockchain, cadence, confidential-transfer, cross-vm, cryptography, flow, groth16, janus-flow, janus-token, openjanus, pedersen, privacy, shielded-transfer, zk

## 简介

Cadence-first privacy primitives for Flow — JanusFlow (native FLOW, recommended), JanusFTCadence (any FungibleToken vault), and JanusERC20 (advanced, ERC20-wrapping on Flow EVM). Pedersen commitments, Groth16 amount-disclose + confidential-transfer proofs
