# @0xarchive/sdk

> 标签: 0xarchive, agents, api, historical-data, hyperliquid, lighterxyz, market-data, orderbook, positions, replay, sdk, trades, trading

## 简介

TypeScript SDK for the 0xArchive market data API for Hyperliquid (perps, HIP-3, HIP-4, spot) and Lighter (mainnet and Robinhood Chain), including account positions
