# sitebrief

> 标签: agent, brief, claude, design-tokens, mcp, model-context-protocol, playwright, website

## 简介

MCP server that studies a website's structure and look and drives a coding agent to rebuild it as an original product: build brief, section images, image slots and a visual compare loop.
