# @acfstandards/agent-bridge

> 标签: acf, ai-agent, bridge, certification, claude, managed-agents, openai

## 简介

ACF Agent Bridge — present any AI agent (Claude Managed Agents, OpenAI agents, self-hosted OpenAI-compatible servers) as an HTTPS endpoint that ACF certification testing can reach
