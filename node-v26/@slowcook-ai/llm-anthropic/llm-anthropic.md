# @slowcook-ai/llm-anthropic

> 标签: adapter, agents, ai, anthropic, claude, llm, slowcook, tdd

## 简介

Anthropic (Claude) LlmClient adapter for slowcook — implements the core LlmClient interface, provider-specific pricing, and Anthropic-tuned system prompts + tool defs for refine / testgen / brew / sift / investigate agents
