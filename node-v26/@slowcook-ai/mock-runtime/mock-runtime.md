# @slowcook-ai/mock-runtime

> 标签: design-contract, mock, next, react, scenarios, slowcook, ui

## 简介

Runtime for slowcook's per-consumer UI mock app — Scenario types, registry, React hooks, ScenarioPicker UI. Imported by the mock/ scaffolding `slowcook init mock` writes. The mock is the design contract: vibe + plate evolve it; brew copies its components
