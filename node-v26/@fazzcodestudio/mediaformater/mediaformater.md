# @fazzcodestudio/mediaformater

> 标签: android, ffmpeg, image, imagemagick, sharp, sticker, termux, webp, whatsapp-bot

## 简介

Sharp-like image/media processing API that actually works on Android/Termux (no native libvips build required). Uses ImageMagick/ffmpeg binaries when available, falls back to pure-JS Jimp.
