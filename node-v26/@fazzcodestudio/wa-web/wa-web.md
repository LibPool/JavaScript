# @fazzcodestudio/wa-web

> 标签: automation, baileys, bot, fazzcodestudio, multi-device, pairing-code, whatsapp, whatsapp-web

## 简介

A WhatsApp Web (multi-device) library — a Baileys-based fork with a friendlier WAClient API, a native-flow Button builder, an interactive/rich message builder, call handling, working pairing codes, and complete docs.
