# zcashflight

> 标签: privacy, qa, security, shielded, testing, wallet, zcash, zec

## 简介

Privacy tests for Zcash apps: catch exposed addresses, amounts, memos and txids in requests and logs, with masked evidence, fixes, and regression checks.
