# @oncortex/cli

> 标签: cli, cortex, import, knowledge-base, markdown, mcp, oncortex

## 简介

The Cortex command line: sign in as you, analyse a folder of markdown, create a brain, import and verify it, upload files as sources, mark your brain as yours, check it is still being fed.
