# @vibingview/cli

> 标签: cli, deploy, hosting, mcp, model-context-protocol, vibingview, vps

## 简介

VibingView command-line interface and stdio MCP bridge: pair with browser approval, deploy apps, read logs, manage env vars and databases, and connect AI editors.
