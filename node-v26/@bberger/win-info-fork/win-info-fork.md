> 标签: app, application, bounds, bundleid, capture, current, focused, id, linux, macos, memory, metadata, name, pid, process, screenshot, title, usage, win, window, windows, x11

## 简介

Get metadata about a program window (title, id, bounds, owner, etc). Works on macOS, X11-based Desktops (Linux, BSD), Windows.
