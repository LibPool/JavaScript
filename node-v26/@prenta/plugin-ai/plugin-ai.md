# @prenta/plugin-ai

> 标签: JavaScript

## 简介

Deterministic content-quality tooling for Prenta CMS: document audit, SEO/readability/accessibility/freshness scores, smart internal links. AI model calls are governed by @prenta/core (Settings > AI).
