# @pacrypto55/wallet-menu

> 标签: dex, orderly, privy, wallet-menu

## 简介

Shared 'Privy Wallet' menu host for Orderly DEXes. Adds one dropdown next to the account widget that other Privy-feature plugins (on-ramp, 2FA, ...) register themselves into, so installing any combination of them still shows exactly one button.
