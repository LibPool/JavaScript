# @rind-ui/angular

> 标签: a11y, accessibility, angular, design-system, directives, headless, headless-ui, signals, state-machine, ui, wai-aria

## 简介

Accessible headless Angular directives: behaviour, keyboard, ARIA and state, styled through data-* attributes. Every component ships a test driver.
