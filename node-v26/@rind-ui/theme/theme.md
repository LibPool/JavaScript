# @rind-ui/theme

> 标签: accessibility, contrast, css, design-tokens, headless, oklch, theme, white-label

## 简介

White-label theme for rind-ui: brand inputs, semantic tokens, variants and a typed theme builder, styled through data-scope / data-part attributes.
