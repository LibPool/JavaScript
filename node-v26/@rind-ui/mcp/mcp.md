# @rind-ui/mcp

> 标签: accessibility, components, headless, headless-ui, llm, mcp, model-context-protocol, react

## 简介

MCP server for rind-ui: lets coding agents list rind-ui's headless React components and read each one's parts, props, data-* attributes, keyboard support and test driver.
