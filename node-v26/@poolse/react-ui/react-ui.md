# @poolse/react-ui

> 标签: chat, chat-components, chat-sdk, chat-ui, conversation-view, css-variables, messaging, nextjs, poolse, react, react-chat, react-components, realtime, realtime-chat, sendbird-alternative, stream-chat-alternative, talkjs-alternative, typescript, ui, ui-components

## 简介

React chat UI components — ConversationView, PoolseInbox, MessageBubble, TypingIndicator, ReactionPicker, ThreadView. CSS-variable theming, render-prop escape hatches. MIT — alternative to Sendbird, Stream, TalkJS, CometChat.
