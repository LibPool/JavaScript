# @poolse/sdk

> 标签: chat, chat-api, chat-sdk, framework-agnostic, headless, in-app-messaging, messaging, messaging-sdk, node, phoenix-channels, poolse, pusher-alternative, realtime, realtime-chat, sdk, sendbird-alternative, stream-chat-alternative, typescript, typescript-sdk, websocket

## 简介

Headless TypeScript chat SDK for the poolse realtime backend. REST + WebSocket client for Node, Bun, Deno, browsers, and React Native. Framework-agnostic, no UI. MIT — alternative to Sendbird, Stream, Pusher, TalkJS, CometChat.
