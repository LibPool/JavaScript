# @jossuealcala/pulse

> 标签: ai-agents, claude-code, codex, gemini-cli, handoff, local-first, multi-agent, opencode

## 简介

One local room where the AI coding agents already installed on your machine (Codex, Claude Code, Gemini CLI, OpenCode) consult a project together, read-only, with durable handoff between them.
