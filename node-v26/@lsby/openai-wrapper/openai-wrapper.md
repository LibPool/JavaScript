# @lsby/openai-wrapper

> 标签: JavaScript

## 简介

一个功能完整的TypeScript库，为OpenAI API提供便捷的高级接口。支持流式调用、结构化输出、函数调用、向量嵌入等功能，内置智能JSON修复和AI智能修复机制。
