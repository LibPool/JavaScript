# @chirag127/styling

> 标签: css-reset, design-system, framework-agnostic, prose, styling, tailwind, typography

## 简介

Framework-agnostic styling foundation: modern CSS reset, prose styles for long-form content, and utility classes. Pure CSS — works in Astro, Next.js, React, Vue, Svelte, or plain HTML. Consumes @chirag127/tokens for theme-aware styling.
