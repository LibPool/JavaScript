# @chirag127/theme

> 标签: css, design-system, framework-agnostic, theme, web-components

## 简介

Ready-to-use framework-agnostic themes built on @chirag127/tokens. Pick an archetype (editorial, marketing, dashboard, docs) and every component — yours or @chirag127/atoms — takes that site's distinct look.
