# @kici-dev/core

> 标签: ci, cicd, continuous-integration, typescript, utilities, workflow

## 简介

Light shared utilities for the KiCI stack (logging, errors, formatting, crypto, zx init, the TypeScript ESM loader hook). No server-side dependencies.
