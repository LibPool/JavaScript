# @miraiclip/registry

> 标签: lower-third, miraiclip, motion-graphics, registry, templates, video

## 简介

Ready-made blocks for Miraiclip videos — lower thirds, callouts, intros, end cards, cursors and caption styles — plus a static JSON registry format and the `miraiclip` CLI (`add`, `catalog`, `build`).
