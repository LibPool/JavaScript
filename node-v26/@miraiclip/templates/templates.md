# @miraiclip/templates

> 标签: ai, batch, personalized-video, templates, video, video-editor, video-generation

## 简介

Parameterized videos for Miraiclip: a template project + a data payload → a hydrated document → export. Batch and personalized video generation, with field schemas that double as validation, UI forms, and LLM tools.
