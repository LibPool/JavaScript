# @miraiclip/screencast

> 标签: auto-zoom, cursor, miraiclip, redaction, screencast, tutorial

## 简介

Turn a screen recording's interaction log into edits: zooms on clicks, a smooth cursor, click ripples, blurred secrets and step callouts. Pure planners that return Miraiclip commands.
