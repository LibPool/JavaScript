# umbot-ydb-adapter

> 标签: alice, alisa, bot-framework, cloud-functions, database, db-adapter, serverless, typescript, umbot, universal-bot, yandex-cloud, yandex-database, ydb

## 简介

YDB (Yandex Database) adapter for the umbot framework: storage for Alice skills and chat bots in Yandex Cloud Functions without a separate database server.
