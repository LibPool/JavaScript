# @blackbelt-technology/pi-dashboard-skill-atlas-plugin

> 标签: JavaScript

## 简介

Dashboard plugin showing every skill pi loads in a folder or globally as a typed relation graph (references, same package, shared tool), rebuilt automatically when skills change.
