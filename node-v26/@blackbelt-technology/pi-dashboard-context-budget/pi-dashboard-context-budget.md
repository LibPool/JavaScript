# @blackbelt-technology/pi-dashboard-context-budget

> 标签: context-window, observability, pi-extension, pi-package

## 简介

Per-turn context budget meter: captures the real provider payload via before_provider_request and attributes it to system-prompt blocks, skill catalogue entries and per-tool schemas. Proves a context trim actually reached the wire.
