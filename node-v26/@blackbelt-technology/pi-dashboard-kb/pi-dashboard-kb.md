# @blackbelt-technology/pi-dashboard-kb

> 标签: bm25, fts5, knowledge-base, markdown, pi, rag, sqlite

## 简介

Directory-based SQLite/FTS5 knowledge base over markdown, queryable by LLM agents. Structural heading chunking, Tier-1 graph, content-hash incremental indexing, near-duplicate dedup, BM25F ranking. Zero runtime deps (node:sqlite).
