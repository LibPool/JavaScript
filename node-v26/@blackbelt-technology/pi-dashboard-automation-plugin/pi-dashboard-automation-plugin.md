# @blackbelt-technology/pi-dashboard-automation-plugin

> 标签: JavaScript

## 简介

Automation plugin for pi-dashboard — schedule-triggered background agent runs with a triage inbox (Codex-Automations-style), built on the dashboard shell slots.
