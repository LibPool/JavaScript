# @blackbelt-technology/pi-dashboard-mcp-client-plugin

> 标签: JavaScript

## 简介

First-party dashboard plugin managing pi's built-in MCP configuration: Pi-global + trusted-folder mcp.json view with live state from `pi mcp list`, validated atomic writes, and global + folder MCP management surfaces.
