# @blackbelt-technology/pi-dashboard-keycloak-resolver-plugin

> 标签: JavaScript

## 简介

Bundled dashboard resolver plugin: validates a Keycloak JWT access token as an OAuth resource server (RFC 9068 + conditional DPoP) and resolves it to an (iss, sub) principal. Fully config-seeded; dashboard core imports nothing Keycloak-specific.
