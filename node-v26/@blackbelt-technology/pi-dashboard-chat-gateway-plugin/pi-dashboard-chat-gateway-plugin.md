# @blackbelt-technology/pi-dashboard-chat-gateway-plugin

> 标签: JavaScript

## 简介

Inbound chat control plane — drive dashboard pi sessions from a chat platform (Discord shipped). Extensible adapter layer; no bridge or server protocol change.
