# @blackbelt-technology/pi-dashboard-browser-plugin

> 标签: JavaScript

## 简介

Dashboard plugin giving agents a browser: a dashboard-owned dedicated Chrome profile, or CDP relayed from the user's real logged-in Chrome (Playwright Chrome Extension, Apache-2.0 vendored relay) to pi sessions: per-profile connect/disconnect, SSO pairing
