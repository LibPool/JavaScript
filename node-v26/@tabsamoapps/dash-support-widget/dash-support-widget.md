# @tabsamoapps/dash-support-widget

> 标签: JavaScript

## 简介

Drop-in web chat widget. One <script> tag per product. Supports anonymous and authenticated threads. Realtime via Supabase Realtime (routed through @tabsamoapps/realtime-router).
