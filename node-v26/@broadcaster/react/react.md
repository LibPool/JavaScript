# @broadcaster/react

> 标签: BroadcastChannel, broadcast, browser, browsing, channel, communicate, connect, connection, context, cross, hook, message, metadata, react, share, tabs, windows, workers

## 简介

React implementation of Broadcaster package. Extension of a Broadcast Channel API. Allows to send messages to multiple windows (tabs, workers, iframes,...) and detect opened windows.
