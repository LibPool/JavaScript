# @aphrody/m3-next-example

> 标签: JavaScript

## 简介

Sample Next.js 16 app on the M3 stack: App Router, Cache Components, proxy.ts, React Compiler, typed routes, Tailwind v4 and Base UI, built and served on Bun through yolo.
