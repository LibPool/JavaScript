# @aphrody/scaffold

> 标签: material-3, scaffold, tauri, tauri-3, template

## 简介

The single project scaffolder of the UI stack: Tauri 3 shell (pins, config, capabilities, icon), M3 web and app templates, the canonical example and a writer that never overwrites. Used by m3 new, m3-next-migrate and web-to-tauri.
