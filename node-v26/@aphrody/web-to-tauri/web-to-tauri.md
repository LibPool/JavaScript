# @aphrody/web-to-tauri

> 标签: parity, pwa, tauri, tauri-3, webview, wrapper

## 简介

Converts a website, web app or built web bundle into a native Tauri 3 app: probes the target, plans a regression-free mode (remote, bundle, sidecar), generates the project and checks parity against the original.
