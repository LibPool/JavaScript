# @traxsharp/state-machine

> 标签: JavaScript

## 简介

Portable, resumable snapshot state-machine engine — the TypeScript twin of Trax.StateMachine. Represents a multi-step flow's state as language-neutral JSON so a client and a C# backend agree on it, with illegal (state, context) pairs unrepresentable and e
