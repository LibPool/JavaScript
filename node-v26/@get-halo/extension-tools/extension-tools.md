# @get-halo/extension-tools

> 标签: JavaScript

## 简介

Shared development tooling for standalone Halo extensions. An extension installs `@get-halo/extension-sdk` as a dependency and `@get-halo/extension-tools` as a dev dependency. Build configuration lives here; the runtime SDK does not depend on esbuild.
