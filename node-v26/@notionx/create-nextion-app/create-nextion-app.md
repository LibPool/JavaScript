# @notionx/create-nextion-app

> 标签: cloudflare, create-nextion-app, d1, nextion, nextjs, notion, notionx, r2, scaffold, turnstile, vinext, workers

## 简介

Scaffold a new vinext (Next.js on Cloudflare Workers + D1 + R2) project backed by @notionx/core, with one-step provisioning of D1 / KV / R2 / Turnstile / Notion / Resend / Google OAuth.
