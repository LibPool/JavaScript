# @aarunyaapps/json-to-types

> 标签: codegen, json-schema, openapi, type-generation, typescript, valibot, zod

## 简介

Infer TypeScript, Zod, Valibot, Yup, JSON Schema, and OpenAPI 3 schemas from any JSON value. Zero dependencies.
