# @mag-cie/mcp-microsoft-todo

> 标签: claude, mcp, microsoft-graph, microsoft-todo, model-context-protocol, tasks, todo

## 简介

MCP server for Microsoft To Do via the Microsoft Graph API. Stdio transport, MSAL device code auth, local install. Compatible with Claude Code, Claude Desktop, Cursor, and any stdio MCP client.
