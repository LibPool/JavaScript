# @fonderie/storage

> 标签: blob, fonderiejs, minio, object-storage, s3, saas, storage, typescript

## 简介

Content-agnostic, provider-abstracted object storage — store any bytes on Postgres, disk, or S3-compatible object storage (S3/MinIO/R2) behind one interface. The low-dependency foundation for media, archives, and more.
