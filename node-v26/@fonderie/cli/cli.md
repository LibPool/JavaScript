# @fonderie/cli

> 标签: ai-agent, claude-code, cli, codex, fonderiejs, lazy, skill

## 简介

The Fonderie CLI — teaches any coding agent the SDK without loading it eagerly. `fonderie skill` writes a lazy skill (a small router + per-package bodies read on demand); `fonderie query` answers what to install for a capability. Zero deps, runs anywhere.
