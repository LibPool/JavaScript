# @fonderie/react-native-customers

> 标签: crm, customers, fonderiejs, hooks, react-native, typescript

## 简介

React Native hooks for Fonderie's customers module — re-exports @fonderie/react-customers (no platform-specific code: no storage, no DOM/RN APIs).
