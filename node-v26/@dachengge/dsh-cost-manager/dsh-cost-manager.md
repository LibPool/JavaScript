# @dachengge/dsh-cost-manager

> 标签: billing, budget, cost, dsh, dsh-plugin, token-usage

## 简介

DSH 成本管理插件：余额/费用/模型能力/任务会话统计 + 防死（硬地板与欠费切换建议）。适配用户绑定的模型，自动扫描会话用量。
