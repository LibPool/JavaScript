# @spekjs/ui

> 标签: graph, openspec, react, sdd, spec-driven-development, timeline, visualization

## 简介

Reusable OpenSpec visualizations — a force-directed spec/change graph and a Gantt-style change timeline. Presentational React components with no router, no data layer and no CSS framework.
