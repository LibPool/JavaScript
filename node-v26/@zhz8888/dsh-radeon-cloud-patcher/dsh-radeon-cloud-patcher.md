# @zhz8888/dsh-radeon-cloud-patcher

> 标签: amd, deepseek-harness, dsh, llm, patcher, provider, radeon, radeon-cloud, reasoning, thinking

## 简介

为 DeepSeek Harness 接入 AMD Radeon Cloud，完整支持模型思考（reasoning）功能。provider 定义由插件自带的补丁层声明，交由 DSH 自带的 dsh-llm-pi-ai 承载，不修改 DSH 本体、不写用户 profile，也不自研适配器。
