# @zhz8888/dsh-ios-simulator-helper

> 标签: deepseek-harness, dsh-plugin, ios, macos, simctl, simulator, xcode

## 简介

iOS Simulator management for DeepSeek Harness: Xcode project discovery and scaffolding, simulator boot/install/launch/terminate, screenshots, logs and optional idb UI automation, ported from the official ZCode ios-simulator plugin, with its parameter page
