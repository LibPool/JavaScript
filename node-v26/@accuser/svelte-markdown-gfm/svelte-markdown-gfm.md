# @accuser/svelte-markdown-gfm

> 标签: gfm, github flavored, markdown, mdast, svelte, sveltekit

## 简介

Transforms Markdown source (as a `string`) or a [Markdown AST](https://github.com/syntax-tree/mdast) into Svelte components.
