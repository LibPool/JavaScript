# project-scan

> 标签: cli, code-analysis, devtools, documentation, project-scan, project-summarizer, test-runner, universal

## 简介

Universal project summarizer & test runner — scans any project for languages, frameworks, databases, cloud services, CI/CD pipelines and runs tests. Works with JavaScript, TypeScript, Python, Go, Rust, Java, Kotlin, PHP, Ruby, Dart, C#, and more.
