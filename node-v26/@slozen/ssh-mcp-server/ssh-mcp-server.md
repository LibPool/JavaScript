# @slozen/ssh-mcp-server

> 标签: JavaScript

## 简介

基于 **Model Context Protocol (MCP)** 的 SSH 服务器，将 SSH 连接、远程命令执行等能力封装为 MCP Tool，供 AI Agent 和 MCP 客户端统一调用。
