# @buckspay/react-native

> 标签: account-abstraction, gasless, mobile, passkey, react-native, sdk, smart-wallet, soroban, stellar, usdc

## 简介

React Native bindings for the Buckspay SDK: native passkey + secure storage + the BuckspayProvider/useWallet/useStellarPay hooks for gasless Stellar (Soroban) USDC payments on mobile.
