# unify-blog-template

> 标签: html, static-site-generator, template, unify, unify-template

## 简介

The blog starter site for unify, the HTML-native static site generator — posts in Markdown, with a post index and an Atom feed generated by scripts/gen.mjs. Scaffold it with: unify init unify-blog-template
