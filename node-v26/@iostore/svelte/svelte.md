# @iostore/svelte

> 标签: JavaScript

## 简介

`@iostore/svelte` 把 io 的响应式状态与 query 运行时包装成标准 Svelte Store 接口，目标是“框架无侵入 + 语义统一”。你可以把它看作 Svelte 版 TanStack Query + io state bridge：既支持查询、无限查询、变更，也支持把 io source/unit 转成 `readable/writable`。
