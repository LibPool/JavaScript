# @turjuman/aws-cdk

> 标签: aws, cdk, construct, dynamodb, i18n, lambda, translation, turjuman

## 简介

Turjuman AWS CDK construct: a composable serverless stack (single-table DynamoDB + Lambda Function URLs) with pre-bundled handlers.
