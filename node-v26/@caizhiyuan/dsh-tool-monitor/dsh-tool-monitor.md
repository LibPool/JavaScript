# @caizhiyuan/dsh-tool-monitor

> 标签: background, deepseek-harness, dsh, dsh-plugin, monitor, websocket

## 简介

DeepSeek Harness plugin: background file/command/WebSocket monitors that wake the owning session on new output and show a live monitor list in the Web session header over a dedicated WebSocket. Host core + Web client half, no build step.
