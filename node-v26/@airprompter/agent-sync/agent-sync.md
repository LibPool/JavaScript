# @airprompter/agent-sync

> 标签: agent, airprompter, encrypted-store, governance, llm, prompts, pull, release

## 简介

Pull and hold AirPrompter agent releases: signed pull-only updates, the encrypted restart-safe slot store, key providers, the apply policy and its windows, and the daemon client.
