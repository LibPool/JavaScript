# @blcklab/anyo-player

> 标签: 3d, anyo, player, sekai64, virtual-world, webgl2, webgpu, webxr

## 简介

Production-ready browser player for Anyo worlds with Sekai64 rendering, lifecycle, input, recovery, navigation, XR, and framework adapters.
