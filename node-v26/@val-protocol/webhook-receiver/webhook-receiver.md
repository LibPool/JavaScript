# @val-protocol/webhook-receiver

> 标签: audit, chain, hmac, receiver, val, verification, webhook

## 简介

Reference signed-webhook receiver for VAL chain-event deliveries. HMAC-SHA256 timing-safe verification with rotation grace, replay protection, family-prefixed event router, chain-field extraction. Zero runtime dependencies.
