# @ghub/agent-protocol

> 标签: JavaScript

## 简介

The server half of the GOpen agents' wire protocol: EdDSA request assertions bound to the audience, method, path and body for a minute, key proofs for rotation, and RFC 7638 key ids. Hand-written on node:crypto, no dependencies.
