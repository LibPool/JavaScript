# @agentdiscoverability/mcp-analytics

> 标签: agentdiscoverability, analytics, mcp, mcp-server, model-context-protocol, observability, telemetry, tool-calls

## 简介

Observe-only analytics for your own MCP server: tool calls, timing, errors and AI-client mix, sent to the AgentDiscoverability collector. End-user identity only through an opt-in identify() hook, no tool-schema changes, fail-open. Fork of the MIT-licensed
