# dsh-composer-enter-newline

> 标签: composer, ctrl-enter, deepseek-harness, dsh, dsh-plugin, enter, keyboard, mobile, newline, shift-enter, swap, tablet, touch

## 简介

dsh Web UI plugin: on touch devices (tablet/smartphone, incl. landscape) swaps the newline and send keys — Enter inserts a newline, Shift+Enter sends. PCs keep the default behavior. (タッチ端末で改行と送信のキーを入れ替え: Enter で改行、Shift+Enter で送信。PC は既定のまま)
