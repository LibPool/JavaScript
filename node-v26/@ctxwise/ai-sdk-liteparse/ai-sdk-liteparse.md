# @ctxwise/ai-sdk-liteparse

> 标签: ai-sdk, attachments, docx, liteparse, llm, middleware, ocr, pdf, pptx, vercel-ai, xlsx

## 简介

Vercel AI SDK middleware that turns chat attachments (PDF, Office, images, scans) into LLM-ready text with LiteParse, in-process with no server, using vision only where OCR is not confident
