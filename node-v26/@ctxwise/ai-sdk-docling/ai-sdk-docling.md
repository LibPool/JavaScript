# @ctxwise/ai-sdk-docling

> 标签: ai-sdk, attachments, docling, docx, llm, middleware, ocr, pdf, pptx, vercel-ai, xlsx

## 简介

Vercel AI SDK middleware that turns chat attachments (PDF, Office, images, scans) into LLM-ready text and images with docling-serve, using vision only where OCR is not confident
