# @phocinae/js

> 标签: classification, decision, local-inference, noul, phocinae, routing, sdk, systemone, typed-decisions, typescript

## 简介

TypeScript client for the local Phocinae decision service (phocinae-server, /v1/systemone). Typed decide/classify/route/score/gate with retry, timeout, abort. Zero runtime dependencies; Node 18+ or browser fetch.
