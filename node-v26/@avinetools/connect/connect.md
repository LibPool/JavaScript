# @avinetools/connect

> 标签: avine, backend, checkout, drm, licensing, sdk, webhooks

## 简介

Official TypeScript/JavaScript SDK for the Avine Connect API, use Avine as your backend for users, licensing, file storage, checkout, webhooks, and stats.
