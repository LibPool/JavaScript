# @dskripchenko/printable-sdk

> 标签: api-client, document-generation, docx, hmac, pdf, printable, sdk

## 简介

Official Node.js SDK for the Printable document-generation service: HMAC-signed integration API client (templates, print-forms, batches, drafts, webhooks).
