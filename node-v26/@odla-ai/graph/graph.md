# @odla-ai/graph

> 标签: code-graph, dependency-graph, graph, odla, odla-ai, static-analysis, traversal

## 简介

A dependency-free property graph with a traversal algebra, plus extractors that build one from a codebase: imports, exported symbols, and the data surfaces modules read and write.
