# dsh-screenshot-native

> 标签: deepseek-harness, dsh, dsh-plugin, screenshot, snipping, windows

## 简介

微信式截图（原生全屏浮层）：打开即隐藏 Harness 窗口、悬停选窗单击截整窗、Shift 切换保留/隐藏、截图直接进输入框；Windows 专用，预编译引擎，无运行时依赖
