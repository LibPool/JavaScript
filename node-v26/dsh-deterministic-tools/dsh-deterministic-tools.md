# dsh-deterministic-tools

> 标签: agent-tools, base64, cidr, color, cordis, csv, deepseek, deepseek-harness, deterministic, developer-tools, diff, dsh, dsh-plugin, dsh-plugins, encoding, hash, hex, json, json-validate, jsonpath, jwt, local-first, no-network, offline, plugin, read-only, receipt, regex, sha256, text-diff, timestamp, tool-calling, unicode, url, yaml

## 简介

DSH plugin: 29 deterministic, offline tools for JSON validation with exact line/column, JSONPath queries, YAML/CSV conversion, text diff, regex capture, encodings, hashes, Unicode, CIDR, JWT structure and timestamps. Every call returns a { result, meta }
