# @cyberistic/jj-mcp-server

> 标签: effect, jj, jjcow, jjw, jujutsu, mcp, model-context-protocol, vcs, workspaces

## 简介

Model Context Protocol server for Jujutsu (jj) version control, built on Effect v4. Optional first-class support for jjCoW (jjw) workspaces.
