# @darcas/keyplex

> 标签: abstract-class, cache, caching, cross-tab, cross-tab-sync, custom-storage, expiration, key-value, key-value-store, local-storage, localstorage, namespace, namespaced-storage, reactive, reactive-storage, session-storage, sessionstorage, storage, ttl, typescript, web-storage, wildcard, wildcard-deletion, zero-dependency

## 简介

A versatile and modular library for managing namespaced key-value storage, with built-in support for localStorage and sessionStorage, and the ability to easily extend for custom storage solutions.
