# @mikeargento/bitgraph-mcp

> 标签: agent, ai-audit, bitgraph, mcp, model-context-protocol, proof

## 简介

MCP server for BitGraph. Make a BitGraph of files or folders (one set, one position for all of it), check whether bytes are on record, and fetch proofs from any MCP client.
