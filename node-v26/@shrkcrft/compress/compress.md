# @shrkcrft/compress

> 标签: ccr, compression, deterministic, sharkcraft, tokens

## 简介

SharkCraft deterministic context-compression engine: content routing, lossless columnar/table compaction, log/search/diff line reduction, and reversible Compress-Cache-Retrieve (CCR). No model inside — every transform is a pure function of its input.
