# @shrkcrft/graph

> 标签: code-intelligence, graph, import-graph, monorepo, sharkcraft, symbol-graph

## 简介

SharkCraft code intelligence graph: files, symbols, packages, imports and exports. Persistent JSONL store; on-disk index queried by every other code-intelligence package.
