# @shrkcrft/quality-gates

> 标签: code-intelligence, pre-merge, quality-gates, sharkcraft

## 简介

SharkCraft quality gates: single aggregator that runs the code-intelligence checks (graph index, boundaries, architecture, impact summary) and emits one pass/fail report. The pre-merge gate for AI-agent-authored changes.
