# @ylubi/screenshot-mcp

> 标签: ai-tools, mcp, model-context-protocol, screenshot

## 简介

MCP server providing screenshot capabilities for AI assistants. Supports window and region capture with three window search methods (handle, title, process name). Includes built-in save functionality and long screenshot with auto-scroll.
