# @shivdev/agent-warden

> 标签: agent-security, ai-security, firewall, guardrails, jailbreak-detection, llm-security, mcp, model-context-protocol, prompt-injection

## 简介

A firewall for AI agents. Detects and blocks prompt injection in email, web pages, documents and MCP tool results before they reach your model.
