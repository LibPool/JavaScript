# @talkwith/embed

> 标签: JavaScript

## 简介

React embed SDK for **TalkWith** — a prebuilt `<VideoRoom />`, headless hooks, and a **server-only** token helper. It wraps LiveKit's tested components (including their Safari/iOS workarounds) so you get a working call with a token and a server URL.
