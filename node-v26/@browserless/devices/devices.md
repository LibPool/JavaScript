# @browserless/devices

> 标签: browserless, desktop, devices, emulation, mobile, responsive, tablet, testing, user-agent, viewport

## 简介

Comprehensive device database for browser testing. Emulate mobile phones, tablets, and desktops with accurate viewport and user agent data.

## 官网

- 官网：https://browserless.js.org/#/?id=devices
- 源码仓库：git+https://github.com/microlinkhq/browserless.git#master
- npm 页面：https://www.npmjs.com/package/@browserless/devices
