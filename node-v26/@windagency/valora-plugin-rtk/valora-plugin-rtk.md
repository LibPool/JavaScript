# @windagency/valora-plugin-rtk

> 标签: cli, hooks, rtk, rust, token-reduction, valora, valora-plugin

## 简介

RTK (Rust Token Killer) integration for Valora — transparently prepends rtk to known-noisy CLI tools, reducing LLM token consumption by 60–90%.
