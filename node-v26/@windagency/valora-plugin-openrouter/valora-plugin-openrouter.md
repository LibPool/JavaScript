# @windagency/valora-plugin-openrouter

> 标签: ai, api-gateway, cloud-llm, llm, open-source, openrouter, provider, typescript, valora, valora-plugin

## 简介

OpenRouter provider plugin for Valora — connects to openrouter.ai for unified access to hundreds of LLM models via an OpenAI-compatible API. Requires OPENROUTER_API_KEY.
