# @aalis/api-doctor

> 标签: aalis, aalis-api

## 简介

诊断子系统契约：检查项注册、报告类型与 `doctor` 描述符，以及插件没起来时「缺」与「在等」的共享判据 `unmetDependencies`（沿依赖链追到根，runtime 的启动告警、诊断、WebUI、终端界面与市场的卸载闸共用）。
