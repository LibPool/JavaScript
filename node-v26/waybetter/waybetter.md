# waybetter

> 标签: betterdiscord, desktop, dom, i18n, plugins, tauri, theming, waybetter

## 简介

wayBetter: the framework for apps that run the apps you already use in a light native (Tauri) window and extend them in place. Page runtime (DOM/request hubs, plugins, plugin UI kit with themed dialogs and toasts, theme API and theme JSON Schema, theme co
