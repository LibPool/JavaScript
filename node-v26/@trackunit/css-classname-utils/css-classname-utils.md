# @trackunit/css-classname-utils

> 标签: JavaScript

## 简介

The `@trackunit/css-classname-utils` package is the home of Trackunit's Tailwind/classname detection utilities. It has no dependency on `eslint` or `@typescript-eslint/utils`, so it can be consumed by any TypeScript project, not just ESLint plugins.
