# @trackunit/react-map-adapter-mapbox

> 标签: JavaScript

## 简介

**Mapbox GL JS** adapter for `@trackunit/react-map`: implements the shared adapter contract from `@trackunit/react-map-adapter-shared` using Mapbox GL.
