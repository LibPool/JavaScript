# @flowertip/search-form

> 标签: configurable-form, element-plus, form-generator, query-form, search-form, vue3, 动态表单, 搜索表单

## 简介

基于 Vue 3 + Element Plus 的可配置搜索表单组件，支持十三种字段类型、响应式布局、远程数据、字段联动、展开折叠、自定义插槽
