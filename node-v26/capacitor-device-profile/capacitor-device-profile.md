# capacitor-device-profile

> 标签: app-lifecycle, capacitor, device-profile, foldable, form-factor, game-dev, haptics, orientation, react, safe-area

## 简介

Mobile and foldable runtime over Capacitor: device profile (phone, foldable-open, tablet, desktop) that re-classifies live on fold and unfold, orientation policy, live safe-area insets, app lifecycle with a back-button stack, and a haptics facade.
