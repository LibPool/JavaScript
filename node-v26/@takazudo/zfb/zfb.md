# @takazudo/zfb

> 标签: content-collections, islands, mdx, preact, react, rust, ssg, static-site-generator, zfb

## 简介

Content-site engine on the web's Request/Response model — prerender to static HTML, serve on Cloudflare Workers, or run as a local content server inside your app. One Rust binary. SDK with islands, content collections, pagination, and config helpers.
