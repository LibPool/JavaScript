> 标签: ai, claude-code, context-engineering, knowledge-graph, lsp, obsidian, spec-driven-development, team, token-optimization

## 简介

Makes one developer's Claude Code setup the whole team's. Pins the toolchain, gates the writes that would drift, and commits the shared context so a fresh clone already has it.
