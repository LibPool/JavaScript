# @descryy/cli

> 标签: JavaScript

## 简介

Descry's command-line surface. First command is `init`, which writes the declarations a multi-repo run needs — the workspace id in .descry/config.json, and a package/pairing declaration when the repo is a monorepo. Neither is ever inferred.
