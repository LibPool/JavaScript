# @descryy/adapter-dart

> 标签: JavaScript

## 简介

Dart adapter, breadth tier, with a shelf_router extractor. Libraries are named by their package: URI, names resolve through imports, show/hide and export chains, and routes are read from Router registrations and @Route annotations.
