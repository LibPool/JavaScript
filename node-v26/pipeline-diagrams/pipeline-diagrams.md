# pipeline-diagrams

> 标签: ai-agents, architecture, data-pipeline, diagram, diagrams-as-code, markdown, mcp, mermaid, svg

## 简介

Diagrams as code for data pipelines: generate whiteboard-proof diagrams from text in your docs, CI and AI agents. Renderer, Mermaid converter, web component, Markdown plugins and an MCP server.
