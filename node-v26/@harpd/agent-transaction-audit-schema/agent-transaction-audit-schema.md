# @harpd/agent-transaction-audit-schema

> 标签: agent-commerce, ap2, audit, compliance, harpd, mpp, payment-schema, x402

## 简介

Canonical, protocol-agnostic audit record for agent payments. Normalizes x402/MPP/AP2 into one schema and validates it. Zero runtime deps.
