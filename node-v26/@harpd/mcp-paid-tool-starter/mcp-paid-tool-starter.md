# @harpd/mcp-paid-tool-starter

> 标签: agent-commerce, harpd, mcp, model-context-protocol, paid-tool, x402

## 简介

Starter SDK for building MCP tools that require payment before they run. definePaidTool + enforcePayment + runPaidTool. Zero runtime deps.
