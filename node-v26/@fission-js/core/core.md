# @fission-js/core

> 标签: JavaScript

## 简介

Добавление элемента. Корневой компонент элемента (а не список). В свою очередь он уже решает что показывать. Список, элемент, создание. Ссылочные элемент (большой пункт). Окно выбора должно быть попапом. Сохранение данных - возврат назад.
