# @solankivishal/react-native-face-liveness

> 标签: android, anti-spoofing, camera, expo, fabric, face-detection, face-liveness, ios, liveness, new-architecture, react-native, turbo-module

## 简介

On-device face liveness (anti-spoofing) detection for React Native. Drop-in camera component that tells real faces from photos, screens and masks, powered by ncnn. New Architecture.
