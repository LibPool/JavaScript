# @aws/n8n-nodes-agentcore

> 标签: agent, agentcore, ai, aws, bedrock, harness, llm, n8n, n8n-community-node-package, verified

## 简介

Verified n8n community node for Amazon Bedrock AgentCore harness. Run production-grade AI agents with isolated microVMs, real browsers, real code execution, and persistent memory, directly from your n8n workflows.
