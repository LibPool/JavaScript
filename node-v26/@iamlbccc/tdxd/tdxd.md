# @iamlbccc/tdxd

> 标签: acp, agent, cli, daemon, opencode, paperclip

## 简介

TDX-Daemon — remote daemon for Paperclip TDX-Adapter: drives ACP agents (opencode) with session-per-process, permission approval loop, usage metering; ships cross-platform tdxd-ctl (init/scaffold/start/stop/status)
