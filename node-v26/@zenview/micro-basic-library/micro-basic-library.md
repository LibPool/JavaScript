# @zenview/micro-basic-library

> 标签: JavaScript

## 简介

micro-basic-library 是通用接口、状态、方法服务，里面封装了如 "Dict" 字典类、“store” mobx 全局状态类、“shared”共享业务方法类、“LMConfig”配置类、“service”公共接口方法类，使用微应用脚手架构建项时目已默认安装，可直接使用。
