# @dakilloth/storybook-wails-mock

> 标签: mock, storybook, testing, wails, wails2

## 简介

Mocks a Wails v2 app's window.go bound methods and window.runtime API so components using them can render in Storybook (or any plain browser/test environment) outside the real Wails runtime.
