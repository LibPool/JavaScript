# @sanqianx/ai-coding-event-bridge

> 标签: JavaScript

## 简介

Durable AI coding event capture bridge core: connectors (Claude Code, Codex, OpenCode, ZCode), normalizer, journal, commit boundaries, consumer cursors, headless conversation query and per-commit conversation sealing.
