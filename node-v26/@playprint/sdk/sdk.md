# @playprint/sdk

> 标签: ai-bots, async-multiplayer, coppa, game-analytics, ghost-ai, legends, player-profiling, playprint, playstyle, telemetry

## 简介

Client for playprint.ai — ghost AI player profiles as a service. Wraps @playprint/core for offline profiling, ships telemetry, retrieves hosted Legends. COPPA-safe per-game identities.
