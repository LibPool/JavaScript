# @amplerun/sdk

> 标签: ai, amplerun, base, gpu, gpu-cloud, inference, llm, sdk, usdc

## 简介

Typed TypeScript client for the AmpleRun GPU marketplace business API (contract v3). Types generated from packages/contracts/openapi.yaml; runtime via openapi-fetch.
