# @assetopt/core

> 标签: asset-optimization, css-minification, esbuild, image-optimization, js-minification, lightningcss, sharp, svg-optimization, svgo, web-performance

## 简介

Pure asset optimization functions for images (sharp), CSS (lightningcss), JS (esbuild), and SVG (svgo). Core engine behind the assetopt CLI.
