# playwright-element-plus

> 标签: e2e, element-plus, playwright, testing, vue, vue3

## 简介

Playwright helpers for testing Vue apps built with Element Plus: selects, date pickers, tables, toasts, uploads and more, without the usual timing and locator traps.
