# @kino-is/sdk

> 标签: api, catalog, cinema, client, film, imdb, kino.is, kinopoisk, movies, sdk, showtimes, tv, typescript

## 简介

Official TypeScript/JavaScript client for the kino.is API — films, series, people, ratings, where-to-watch and live cinema showtimes. Zero runtime dependencies.
