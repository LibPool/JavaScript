# @atmo-dev/contrail-authority

> 标签: atproto, contrail

## 简介

Default space-authority implementation for contrail — member list, invites, app policy, credential issuance. Contrail's binary-membership ACL flavor; for ladder-style access levels see @atmo-dev/contrail-community.
