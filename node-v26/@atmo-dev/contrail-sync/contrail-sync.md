# @atmo-dev/contrail-sync

> 标签: atproto, contrail, realtime, sync, watch

## 简介

Client-side reactive watch-store over contrail's watchRecords endpoints. SSE + WebSocket transports, optimistic updates, optional IndexedDB cache.
