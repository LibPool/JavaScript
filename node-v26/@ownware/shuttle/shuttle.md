# @ownware/shuttle

> 标签: agent, ai, chatbot, discord, ownware, slack, sms, telegram, whatsapp

## 简介

Ownware Shuttle — messaging channel adapters. Each channel (Telegram, Slack, WhatsApp, SMS…) is a thin client of the ownware gateway wire contract: receive → drive the agent → deliver the reply back. One agent, many identities, one thread per person.
