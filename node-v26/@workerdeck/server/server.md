# @workerdeck/server

> 标签: agent, anthropic, claude, claude-code, gateway, server, websocket

## 简介

The WorkerDeck gateway: HTTP + WebSocket session server over @workerdeck/core. Session registry (create/list/attach/interrupt/kill), pluggable auth hook, replay-from-seq attach. Runs anywhere Node runs - needs a real filesystem (no serverless).
