# @vidofy/mcp

> 标签: ai, image-generation, mcp, modelcontextprotocol, text-to-speech, video-generation, vidofy

## 简介

MCP server for Vidofy — generate video, images, audio and speech from Claude, ChatGPT, Cursor or any MCP client. Veo 3.1, Kling 3.0, Flux 2, Seedance 2.5 and 570+ models, billed to your own Vidofy account.
