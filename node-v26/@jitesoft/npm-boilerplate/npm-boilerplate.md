# @jitesoft/npm-boilerplate

> 标签: babel, boilerplate, cli, init, npm, webpack

## 简介

Boilerplate for quick initialization of npm packages. Includes webpack, babeljs and some other base packages.

## 官网

- 源码仓库：git@gitlab.com:jitesoft/open-source/javascript/npm-boilerplate.git
- npm 页面：https://www.npmjs.com/package/@jitesoft/npm-boilerplate
