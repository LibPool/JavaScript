# @valancex/cli

> 标签: cli, scaffold, static-site, valance, vlx

## 简介

vlx, the VALANCE command: make an application (vlx init), serve it as you edit (vlx dev), build it to a static site (vlx build), check it (vlx check). Content, layout, components and styles in, a website out.
