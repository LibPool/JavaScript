# @valancex/port-desktop-vocabulary

> 标签: JavaScript

## 简介

The Desktop PORT's vocabulary as data: the components, props and events a template may use for a native window, and the content layer. Read by the tools that check templates; the PORT itself is the Rust crate valancex-port-desktop.
