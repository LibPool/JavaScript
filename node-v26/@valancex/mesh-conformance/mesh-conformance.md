# @valancex/mesh-conformance

> 标签: conformance, mesh, mprx, test-vectors, valancex

## 简介

MESH's conformance vectors, as data: real programs with their expected render trees, event resolution, and node-identity cases. A renderer checks itself against them; it never copies them.
