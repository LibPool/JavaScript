# @jiihpeeh/svgoo-wasm

> 标签: minify, optimize, optimizer, rust, svg, svgo, svgoo, wasm, webassembly

## 简介

Typed TypeScript bindings for svgoo — the Rust port of SVGO — compiled to WebAssembly (glue-free C ABI, zero JS imports).
