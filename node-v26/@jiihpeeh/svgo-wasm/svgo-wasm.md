# @jiihpeeh/svgo-wasm

> 标签: minify, optimize, optimizer, rust, svg, svgo, svgo-rs, wasm, webassembly

## 简介

Typed TypeScript bindings for svgo-rs — the Rust port of SVGO — compiled to WebAssembly (glue-free C ABI, zero JS imports).
