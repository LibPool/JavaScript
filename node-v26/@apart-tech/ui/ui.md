# @apart-tech/ui

> 标签: JavaScript

## 简介

Apart UI — vendored shadcn bases + thin token-bound wrappers. Visual values live in token-only component CSS keyed off data-* attributes; scheme/density/brand/surface are ambient (never prop-drilled). No CVA, no arbitrary Tailwind, no className passthroug
