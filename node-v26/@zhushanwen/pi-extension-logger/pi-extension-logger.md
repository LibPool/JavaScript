# @zhushanwen/pi-extension-logger

> 标签: logger, logging, observability, pi, pi-package

## 简介

Shared logging helper for Pi extensions — two-channel routing (audit appendEntry / debug file log; the third AI-realtime channel stays with pi native) (shared library, not a Pi extension - no install.mjs needed)
