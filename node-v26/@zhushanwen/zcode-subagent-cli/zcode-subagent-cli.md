# @zhushanwen/zcode-subagent-cli

> 标签: JavaScript

## 简介

zcode subagent engine as an independent CLI package (W5 of subagent-engine-protocolization): speaks engine-protocol v1 over NDJSON stdio, depends only on @zhushanwen/subagent-engine-sdk (never subagent-core)
