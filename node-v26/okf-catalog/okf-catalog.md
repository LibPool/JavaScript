# okf-catalog

> 标签: claude-code, knowledge-catalog, mcp, mcp-server, okf, open-knowledge-format, qmd

## 简介

An MCP server that serves a company's Open Knowledge Format (OKF) bundle to AI agents, with citations, provenance and a publish loop: qmd done right for OKF.
