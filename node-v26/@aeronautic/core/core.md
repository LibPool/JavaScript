# @aeronautic/core

> 标签: aircraft, atmosphere, flight, flight-model, isa, r3f, react-three-fiber, standard-atmosphere, three, three.js, threejs, webgpu

## 简介

The shared ground of the @aeronautic effects: the International Standard Atmosphere and moist air, an aircraft's flight as one mutable store read for free every frame, and six-view depth capture of a model, for three.js and React Three Fiber
