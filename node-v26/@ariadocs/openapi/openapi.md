# @ariadocs/openapi

> 标签: api, ariadocs, documentation, headless, openapi, parser, swagger

## 简介

Headless OpenAPI parser for Ariadocs. Turns OpenAPI 3.0/3.1 documents (JSON or YAML) into a typed, UI-ready model. Runs in Node.js, Bun, Deno, the browser and edge runtimes.
