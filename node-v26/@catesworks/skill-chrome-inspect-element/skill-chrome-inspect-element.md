# @catesworks/skill-chrome-inspect-element

> 标签: JavaScript

## 简介

Deeply inspects a single DOM element via Chrome DevTools MCP, retrieving computed styles, layout box, accessibility properties, and outerHTML, and saving a screenshot for diagnosing layout or CSS…
