# @slates-integrations/loom

> 标签: JavaScript

## 简介

Read metadata for a shareable Loom video, generate embed HTML or a player URL, and replace Loom URLs in text with native embeds. No credentials are required for anonymous oEmbed. Video privacy still controls metadata availability and playback; generating
