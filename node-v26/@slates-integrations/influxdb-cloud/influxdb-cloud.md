# @slates-integrations/influxdb-cloud

> 标签: JavaScript

## 简介

Write and query time-series data with the InfluxDB Cloud TSM/v2 API using line protocol and Flux. Discover organizations and buckets; manage retention, scheduled tasks, dashboards, labels, API-token authorizations, secrets, Telegraf configurations, and DB
