# @slates-integrations/sendloop

> 标签: JavaScript

## 简介

Manage Sendloop subscriber lists, custom fields, audience segments, campaigns, and suppression entries. Add or update subscribers, import contacts in bulk, send or schedule campaigns, and inspect campaign and list performance reports.
