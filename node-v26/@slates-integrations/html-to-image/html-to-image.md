# @slates-integrations/html-to-image

> 标签: JavaScript

## 简介

Generate downloadable PNG, JPG, WebP, and PDF files from HTML/CSS, public webpages, or reusable templates. Browse generated images with cursor pagination, download existing images with optional resizing, manage templates and their versions, request image
