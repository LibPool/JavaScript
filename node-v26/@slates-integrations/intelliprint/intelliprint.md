# @slates-integrations/intelliprint

> 标签: JavaScript

## 简介

Send physical letters and postcards programmatically via a UK-based hybrid mail service. Create and manage print jobs with support for PDF, Word, HTML content, or dynamic templates. Configure postage services including UK First/Second Class, Signed For, S
