# @slates-integrations/signaturely

> 标签: JavaScript

## 简介

Create electronic signature requests from existing Signaturely templates, find documents and signer IDs, download document PDFs, send signing reminders, and inspect the connected account. Supports document search, page or offset pagination, ordered signin
