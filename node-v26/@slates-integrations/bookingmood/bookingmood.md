# @slates-integrations/bookingmood

> 标签: JavaScript

## 简介

Manage vacation rental bookings, rental units, contacts, calendar events, invoices, payments, refunds, coupons, tasks, reviews, and guest messages. Search availability before creating a booking, discover occupancy group IDs, and identify the organizations
