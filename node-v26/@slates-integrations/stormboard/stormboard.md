# @slates-integrations/stormboard

> 标签: JavaScript

## 简介

Create and manage digital whiteboard Storms (workspaces). Create and read ideas (sticky notes), update sections and color legends, manage connectors and tags, send and read chat messages, and manage Storm participation. Duplicate, close, reopen, and favor
