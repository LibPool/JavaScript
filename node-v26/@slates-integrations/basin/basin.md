# @slates-integrations/basin

> 标签: JavaScript

## 简介

Manage Basin form endpoints, submissions, projects, domains, and outbound webhooks. Create and update form configuration, moderate submissions, inspect webhook delivery failures, and re-queue webhook deliveries. Requires a Basin Account API Key and a plan
