# @slates-integrations/grafbase

> 标签: JavaScript

## 简介

Manage Grafbase accounts, federated graphs, branches, and subgraph schemas through the Management API. Discover graph IDs, publish schemas, run schema checks, retrieve schema SDL, and execute custom GraphQL operations. Personal access tokens support Manag
