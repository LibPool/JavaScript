# @slates-integrations/evenium

> 标签: JavaScript

## 简介

Create events and discover event sessions. Browse, create, and update contacts; list a contact’s events; add, retrieve, and update participants; and change registration status. Supports external IDs for CRM workflows and returns custom fields with provide
