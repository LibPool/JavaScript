# @slates-integrations/google-forms

> 标签: JavaScript

## 简介

Create, retrieve, publish, and update Google Forms, surveys, and quizzes. Configure quiz answer keys with point values and automatic feedback. Retrieve form responses and quiz grades, with filtering by timestamp. Set up push notification watches for form
