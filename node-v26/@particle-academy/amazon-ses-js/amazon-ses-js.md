# @particle-academy/amazon-ses-js

> 标签: amazon_ses, api, connector, email, fancy-ui, particle-academy

## 简介

Amazon SES for Node — the service descriptor, its faker, its webhook verification, and one function per operation. Plain HTTP on @particle-academy/fancy-connector-core; no vendor SDK.
