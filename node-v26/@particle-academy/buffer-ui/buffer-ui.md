# @particle-academy/buffer-ui

> 标签: buffer, connector, fancy-flow, fancy-ui, marketing, particle-academy

## 简介

Buffer's authoring surface for fancy-flow — the node kinds, their config schemas and their declared output shapes. React on every host; carries no executor.
