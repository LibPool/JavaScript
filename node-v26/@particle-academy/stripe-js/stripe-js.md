# @particle-academy/stripe-js

> 标签: api, connector, fancy-ui, particle-academy, payments, stripe

## 简介

Stripe for Node — the service descriptor, its faker, its webhook verification, and one function per operation. Plain HTTP on @particle-academy/fancy-connector-core; no vendor SDK.
