# @particle-academy/fancy-query

> 标签: data-fetching, inertia, laravel-echo, react, react-query, reverb, server-state, tanstack-query

## 简介

Server-state for React + Inertia + Reverb apps — a thin wrapper over TanStack Query that adds Inertia page-prop hydration, declarative Echo-event → query invalidation, and auto-invalidating mutations. The value-add is the integrations, not the cache.
