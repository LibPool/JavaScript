# pi-ego

> 标签: browser-automation, ego-browser, ego-lite, extension, pi, pi-coding-agent

## 简介

Persistent browser-session layer for the ego-lite ego-browser skill: screenshot gallery, task-space dashboard, HTML export, and learnings recorder for the Pi coding agent.
