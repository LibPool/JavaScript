# @faraday-academy/runtime

> 标签: JavaScript

## 简介

The Faraday runtime layer (ui, blocks, runtime, styles, world, lms, lib) — a versioned package that generated lessons pin and consume via @faraday-academy/runtime/* (no longer vendored). @faraday-academy/labs previews the same source via the @/faraday ali
