# @tapestry-ui/sortable

> 标签: a11y, dnd, drag-and-drop, headless, preact, reorder, sortable, tapestry-ui, touch, wcag

## 简介

A WCAG 2.1 AA sortable list for Preact — pointer drag, touch from a grip so the page still scrolls, keyboard moves, announcements. Headless: you render, it reorders.
