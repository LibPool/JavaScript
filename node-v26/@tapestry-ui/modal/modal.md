# @tapestry-ui/modal

> 标签: a11y, dialog, headless, modal, panel, preact, tapestry-ui, wcag

## 简介

A WCAG 2.1 AA modal panel for Preact on the native <dialog> element — pinned header, ONE scrollable middle, pinned footer. The drawer's container contract, shipped as a component instead of a README warning.
