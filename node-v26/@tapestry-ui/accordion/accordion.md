# @tapestry-ui/accordion

> 标签: a11y, accordion, collapse, disclosure, headless, preact, squeezebox, tapestry-ui, wcag

## 简介

A nestable, WCAG 2.1 AA accordion (disclosure) for Preact — headless behavior, optional slide, skin via CSS. Forged inside a woven-tapestry game; ships with its container contract, not just its markup.
