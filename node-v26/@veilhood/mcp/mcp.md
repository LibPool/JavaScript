# @veilhood/mcp

> 标签: ai-agents, claude, differential-privacy, mcp, model-context-protocol, robinhood-chain, veil, x402

## 简介

Model Context Protocol server for VEIL — gives any AI agent tools to discover, quote, buy (gasless x402), and verify differentially-private aggregates from the VEIL network.
