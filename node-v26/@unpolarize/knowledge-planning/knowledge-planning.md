# @unpolarize/knowledge-planning

> 标签: JavaScript

## 简介

KP (Knowledge Planning) — a durable, git-backed planning CLI and library over a markdown SSOT (tasks, ideas, plans, goals, thoughts; kanban, calendar, sessions links). Point it at any store directory.
