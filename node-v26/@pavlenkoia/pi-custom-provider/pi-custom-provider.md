# @pavlenkoia/pi-custom-provider

> 标签: openai-compat, pi-extension, pi-package, provider

## 简介

Расширение pi: управление кастомными провайдерами OpenAI-совместимого API (добавление, редактирование, обновление, удаление) и регистрация их моделей в каталоге AI pi.
