# @vibe-visual-editor/vite-plugin

> 标签: claude code, codex, jsx, live edit, mcp, react, visual editor, vite, vite-plugin, vscode

## 简介

Dev-only Vite plugin for Vibe Visual Editor, with React (JSX) support: maps rendered text back to the literals in your source, so the VS Code preview can edit it in place.
