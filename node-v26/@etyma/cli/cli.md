# @etyma/cli

> 标签: cli, i18n, internationalization, localization, messageformat, mf2, validation

## 简介

Command-line validation for Etyma message catalogs. `etyma validate` runs @etyma/tooling's catalog checks against local JSON catalogs, for CI and local use.
