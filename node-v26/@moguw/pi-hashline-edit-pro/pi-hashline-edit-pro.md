# @moguw/pi-hashline-edit-pro

> 标签: anchors, coding-agent, edit, extension, file-editing, hash, hash-anchored, hashline, pi, pi-package, read, replace, stable, undo

## 简介

Hash-anchored read/replace/insert/grep tools for pi-coding-agent. Every line gets a unique 3-char hash (A-Za-z0-9) that stays stable across edits; stale or ambiguous anchors are rejected, never fuzzy-matched. Undo persists across restarts.
