# @stitchapi/swr

> 标签: cache, fetcher, query, react, stitchapi, swr

## 简介

SWR bindings for StitchAPI — useStitchSWR runs a stitch as an SWR fetcher, so SWR owns caching and revalidation while the stitch stays typed, validated, and traced.
