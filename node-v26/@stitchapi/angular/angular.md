# @stitchapi/angular

> 标签: angular, query, rxjs, signals, stitchapi, streaming, tanstack-query

## 简介

Angular bindings for StitchAPI — injectStitch/injectStitchStream expose a stitch's lifecycle as both signals and an RxJS observable over @stitchapi/query-core. Streaming-first: re-render as `delta` chunks arrive. Plus an optional TanStack Query queryOptio
