# @cson-sec/redis-llm-quota

> 标签: ai-security, llm, quota, rate-limit, redis, throttle, token

## 简介

Redis-backed token quota management and multi-dimensional rate limiting for LLM applications. Zero hard dependency on any framework — works with Express, Fastify, Next.js, or standalone Node.js.
