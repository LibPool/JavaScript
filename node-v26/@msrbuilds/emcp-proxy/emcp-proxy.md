# @msrbuilds/emcp-proxy

> 标签: claude, claude-desktop, elementor, mcp, model-context-protocol, proxy, stdio, wordpress

## 简介

stdio↔HTTP proxy that connects MCP clients (Claude Desktop, Claude Code, etc.) to one or many remote WordPress sites running the MCP Tools for Elementor (EMCP) plugin.

- 官网：https://emcptools.com/docs/connecting/claude-desktop/
