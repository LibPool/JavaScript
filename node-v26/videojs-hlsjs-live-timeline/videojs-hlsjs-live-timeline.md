# videojs-hlsjs-live-timeline

> 标签: chapters, custom-element, daterange, dvr, hls, hls.js, live, program-date-time, react, scte-35, video.js, videojs

## 简介

Video.js v10 elements and React components for live HLS with hls.js: clock time from EXT-X-PROGRAM-DATE-TIME, and live chapters from SCTE-35 breaks or a schedule.
