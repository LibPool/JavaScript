# dsh-outsideread-switch

> 标签: cordis, deepseek-harness, dsh, permissions, plugin, sandbox, security

## 简介

Tool-layer fence for one dimension the harness sandbox does not have: whether the model may READ outside the session workspace. Writes stay the sandbox's business. Includes a locale-aware composer switch.
