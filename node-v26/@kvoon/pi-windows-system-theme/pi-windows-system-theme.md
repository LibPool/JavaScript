# @kvoon/pi-windows-system-theme

> 标签: herdr, pi-extension, pi-package, theme, windows

## 简介

Sync Pi's theme with Windows system app mode (light/dark), event-driven via RegNotifyChangeKeyValue. Fixes dark tool/user-message blocks in herdr where OSC 11 / DSR 996 detection times out.
