# @muravitskiy/gatsby-plugin-advanced-sitemap

> 标签: gatsby, gatsby-plugin

## 简介

This is a fork of https://github.com/tryghost/gatsby-plugin-advanced-sitemap.git. Advanced plugin for generating configurable XML sitemaps with linked media for better SEO and human-readable XSL templates.
