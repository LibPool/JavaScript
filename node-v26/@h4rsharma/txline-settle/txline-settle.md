# @h4rsharma/txline-settle

> 标签: anchor, merkle-proof, oracle, prediction-market, settlement, solana, sports-data, txline, txodds, world-cup

## 简介

Unofficial SDK + CLI for TxLINE's on-chain sports oracle: fetch merkle proofs, build provable predicates (disjoint-stat-family enforced), CPI validate_stat_v3 from any Solana program, and independently verify settlements against the live oracle.
