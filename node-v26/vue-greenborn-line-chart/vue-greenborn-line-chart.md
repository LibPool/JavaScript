# vue-greenborn-line-chart

> 标签: chart, estadisticas, grafico, greenborn, line-chart, svg, vue, vue3

## 简介

Gráfico de líneas en SVG para Vue 3, sin librerías de gráficos de terceros: dibuja una o varias series con leyenda, grilla, tooltips por punto y marcas en el eje X. Pensado para paneles de métricas/estadísticas simples (porcentajes, conteos, etc).
