# @gege-mn/gege-linter

> 标签: fvs, linter, mongol-bichig, mongolian, mvs, nnbsp, typography, unicode

## 简介

Linter for traditional Mongolian script (Mongol bichig) text — flags incorrect or legacy Unicode usage: suffix connectors, FVS placement, PUA leftovers.
