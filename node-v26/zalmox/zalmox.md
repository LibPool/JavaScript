# zalmox

> 标签: 3d, ai-agent, cli, game-assets, mcp, unity, vfx, zalmox

## 简介

Zalmox from the terminal and from AI agents: generate game-ready 3D models, VFX flipbooks, textures, skyboxes and terrains. CLI + MCP server.
