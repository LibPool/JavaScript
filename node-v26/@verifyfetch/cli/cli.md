# @verifyfetch/cli

> 标签: ai-models, cd, ci, cli, hash, integrity, manifest, security, sha256, sri, subresource-integrity, verify, verifyfetch, wasm

## 简介

Generate SRI hashes and chunked verification for resumable downloads. Works with WASM, AI models, and any binary files.
