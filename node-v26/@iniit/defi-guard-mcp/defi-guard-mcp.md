# @iniit/defi-guard-mcp

> 标签: aave, approval, base, crypto, defi, honeypot, mcp, modelcontextprotocol, risk, security, token-safety, uniswap, web3-security

## 简介

Safety layer that checks a DeFi token or transaction on Base before you sign: honeypot detection, owner-power (mint/pause/blacklist) bytecode scan, unlimited-approval risk, Aave V3 position health, and gas-aware DEX quotes.
