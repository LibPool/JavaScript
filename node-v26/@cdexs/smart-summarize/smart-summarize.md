# @cdexs/smart-summarize

> 标签: agent, bilibili, epub, extraction, pdf, skill, subtitle, transcription, whisper, youtube

## 简介

Agent skill for intelligent content extraction: YouTube/Bilibili subtitles, web articles, local files (PDF/Word/EPUB/text), and audio/video transcription via whisper.cpp. Extraction only - no LLM calls.
