# @stateres/state-resolver

> 标签: address, geocoding, postal-code, postcode, province, region, state

## 简介

Always resolve a valid province/state code for an address. Waterfall: valid code → region name/alias → postcode derivation → country default. Supports DE, FR, AU, BE, AT, CH, SE, NO, FI, GB, CZ, IL, NZ, SK, IT, ES, NL, BG, HU, PL.
