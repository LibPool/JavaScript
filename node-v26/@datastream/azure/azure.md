# @datastream/azure

> 标签: Azure, Blob Storage, Cosmos DB, Event Hubs, Kafka, Node Stream API, Queue Storage, Service Bus

## 简介

Azure service streaming integrations for Blob Storage, Queue Storage, Service Bus, Event Hubs, and Cosmos DB, plus Entra ID auth for the Event Hubs Kafka endpoint
