# @mayan1124/deploy-cli

> 标签: cli, cloudflare, deploy, hosting, netlify, preview, rollback, s3, static-site, vercel

## 简介

One-command deploys for static sites: local control plane, Netlify, Vercel, Cloudflare Pages, and S3 from a single CLI with an interactive UI, previews, rollback, and a health-check doctor.
