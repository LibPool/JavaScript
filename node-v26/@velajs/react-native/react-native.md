# @velajs/react-native

> 标签: expo, hooks, live-queries, react-native, realtime, vela, websocket

## 简介

React Native / Expo binding for Vela live queries: an AsyncStorage-backed offline mutation store, a native-tuned client factory (bearer fetch + WebSocket auth channel), the react-dom-free @velajs/react hook surface, and a better-auth Expo bridge
