# @velajs/event-source

> 标签: event-log, event-sourcing, materializer, reducer, vela

## 简介

Zero-dependency, platform-neutral event-sourcing runtime for Vela: append-only EventLog, reducer-driven EventSource, typed event/materializer DSLs, and pure table-diff helpers
