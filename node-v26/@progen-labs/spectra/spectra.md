# @progen-labs/spectra

> 标签: ai, angular, cdp, chrome-devtools-protocol, claude-code, frontend, mcp, mcp-server, nextjs, performance, profiler, profiling, progen-labs, react, spectra, svelte, vue, web-vitals

## 简介

Spectra — a Chrome DevTools Protocol profiler that identifies the files, functions and components causing frontend slowness, across React, Vue, Svelte, Angular and Next.js builds.
