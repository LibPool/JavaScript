# @aptxyz/lsb

> 标签: cli, hide, image, least-significant-bit, lsb, png, secret, steganography

## 简介

LSB steganography CLI + Node.js library: hide text or binary payloads inside image least-significant bits with a 48-bit four-corner metadata header
