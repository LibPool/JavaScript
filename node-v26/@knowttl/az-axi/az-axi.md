# @knowttl/az-axi

> 标签: agent, axi, azure, cli, defender-for-cloud, log-analytics, resource-graph, toon

## 简介

Agent-ergonomic CLI for Azure, read-only by default. Resource inventory, RBAC, activity log, Defender for Cloud and Log Analytics through token-efficient TOON output. An AXI (Agent eXperience Interface) over the Azure REST APIs.
