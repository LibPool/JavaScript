# @vetox-bot/vito

> 标签: api-client, currency, discord, payments, sdk, vetox, vetoxbot, vito, webhooks

## 简介

Official Node.js SDK for the Vito API — check balances, charge users, pay users out, and verify webhooks for the Vito virtual currency.
