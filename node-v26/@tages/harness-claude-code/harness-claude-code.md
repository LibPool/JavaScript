# @tages/harness-claude-code

> 标签: claude-code, hooks, instrumentation, mcp, tages

## 简介

Claude Code hooks capture package for the Tages instrumented harness — reads hook JSON on stdin, redacts secrets, and appends to a local SQLite log.
