# @ascii-fx/compiler

> 标签: ascii, ascii-art, ascii-fx, build-tool, cli, font, glyph-atlas, rasterizer

## 简介

Build-time compiler for ASCII FX: deterministic font rasterization, glyph atlases, .asciip/.asciif generation.
