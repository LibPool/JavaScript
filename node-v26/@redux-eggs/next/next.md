# @redux-eggs/next

> 标签: JavaScript

## 简介

_Redux Eggs_ wrapper for [Next.js](https://nextjs.org/) applications. This library works in a similar way to [Next Redux Wrapper](https://github.com/kirill-konshin/next-redux-wrapper).
