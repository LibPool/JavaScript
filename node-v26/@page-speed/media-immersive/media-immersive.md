# @page-speed/media-immersive

> 标签: carousel, feed, hls, immersive, mobile, opensite, page-speed, portal, react, reels, shorts, swipe, tiktok, tree-shakable, vertical-video, video

## 简介

TikTok/Reels/Shorts-style vertical video feed for React. Portal-isolated fullscreen viewer, pointer-driven pager, tappable thumbnail carousel, and a zero-defaults composable API. Built on @page-speed/img and @page-speed/video.
