# @chke/ckui

> 标签: JavaScript

## 简介

`ckui` 是 ck-components 组件库的源码分发 CLI：通过 `ckui add <name>` 把**组件 / Hook / 工具函数的源码**直接写入你的项目（不发 npm 包），样式与多语言完全跟随 element-plus。
