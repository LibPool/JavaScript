# @kosa8/sdk

> 标签: agents, ai-agents, checkpoint, code-execution, egress, fork, isolation, kosa8, microvm, sandbox, sdk

## 简介

Typed TypeScript client for the kosa8 native API: microVM sandboxes for AI agents, with checkpoint, rewind, fork and explore.
