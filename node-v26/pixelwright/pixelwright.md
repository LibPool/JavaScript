# pixelwright

> 标签: ai, claude, claude-code, cursor, design-to-code, figma, mcp, open-source

## 简介

Open-source MCP server that lets AI agents read and edit Figma files through a Figma plugin: no REST API, no token, no seat quota. Unofficial, not affiliated with Figma.
