# @myxo-victor/chexjs

> 标签: Chex, chexjs, framework, signals, ui, vdom

## 简介

A zero-build UI framework with reactive signals, VDOM diffing, routing, state, and a built-in PHP backend bridge — just a script tag, no compiler.
