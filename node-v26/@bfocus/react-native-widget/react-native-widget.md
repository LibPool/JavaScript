# @bfocus/react-native-widget

> 标签: bfocus, chat, expo, helpdesk, react-native, release-notes, support, webview

## 简介

Widget de suporte do bFocus (chamados, chat ao vivo e release notes) para React Native e Expo: botão com badge, pílula de versão, banner de ciência e push.
