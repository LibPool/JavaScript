# @inventhq/tracker-sdk

> 标签: ad-tech, analytics, attribution, click-tracking, clicks, impressions, postbacks, sdk, tracker, tracking

## 简介

TypeScript SDK for tracker-core — generate signed/encrypted tracking URLs, batch-send events, and build click/postback/impression links. Zero dependencies.
