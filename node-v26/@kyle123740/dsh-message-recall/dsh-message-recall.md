# @kyle123740/dsh-message-recall

> 标签: deepseek-harness, delete, dsh, dsh-plugin, message, recall, 删除, 撤回

## 简介

删掉不喜欢的 AI 回复，或删掉已发送的错误提示词 —— 每条消息可撤回 / 删除 / 删除此处及之后。DSH 插件：写 append-only 墓碑，模型上下文与界面同步移除。Per-message recall & delete for DeepSeek Harness sessions.
