# @charles_lindecker/pvzf-console

> 标签: changelog, cli, documentation, fusion, localization, plants-vs-zombies, pvz, translation, trello, tui

## 简介

Translation toolkit for Plants vs Zombies: Fusion. Scans localization files, generates per-locale reports, exports Trello CSVs, and turns the weekly PR recap into contributor documentation.
