# @ripplesdotrun/mcp

> 标签: agent, arc, dual-fill, launchpad, mcp, model-context-protocol, ripples, robinhood-chain, solana

## 简介

Exposes the Ripples agent SDK to AI agents over stdio, signing with keys from your environment. Does not run the agent: the model loop, memory and policy are yours.
