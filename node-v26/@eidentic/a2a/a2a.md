# @eidentic/a2a

> 标签: a2a, agents, ai, eidentic, interop, multi-agent, protocol, typescript

## 简介

Agent-to-Agent (A2A) interoperability for Eidentic — expose an agent as an A2A endpoint or call a remote A2A agent as a tool.
