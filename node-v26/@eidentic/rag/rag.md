# @eidentic/rag

> 标签: agents, ai, chunking, document-loading, eidentic, memory, rag, typescript

## 简介

RAG pipeline utilities for Eidentic — chunk text, ingest documents (PDF / HTML / Markdown), and load content into agent memory.
