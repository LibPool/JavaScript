# @fluxpool/mcp-server

> 标签: ai, claude, cursor, fluxpool, image-generation, mcp, model-context-protocol, video-generation

## 简介

MCP server for Fluxpool.ai — generate images and videos across Flux, Seedream, Seedance, Runway and more from Claude, Cursor, or any MCP client.
