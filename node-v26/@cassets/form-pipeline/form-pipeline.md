# @cassets/form-pipeline

> 标签: cassets, form, form-validation, formdata, html-form, payload, react, typescript, uncontrolled-form, zod

## 简介

DOM-first form-to-payload pipeline for React and browser apps with native validation, coercion, nested payloads, files, and optional Zod validation.
