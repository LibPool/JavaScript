# @kingpepe2/sdk

> 标签: bitcoin-core, blockchain, full-node, json-rpc, kingpepe, kpepe, rpc, sdk, wallet

## 简介

Official KingPepe Core JSON-RPC SDK (TypeScript). A typed RPC client for talking to a KingPepe (KPEPE) node/wallet. Does not store coins or keys.

## 官网

- 官网：https://kingpepe.net
- 源码仓库：git+https://github.com/kingpepe2/king-pepe-source-code.git
- npm 页面：https://www.npmjs.com/package/@kingpepe2/sdk
