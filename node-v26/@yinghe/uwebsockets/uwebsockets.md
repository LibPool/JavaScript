# @yinghe/uwebsockets

> 标签: JavaScript

## 简介

uWebSockets.js precompiled binaries, republished under the @yinghe scope for internal use. JS layer and ABI 115/127/137/141 come from upstream v20.66.0; ABI 83/88/93/102/108 are retained from v20.31.0 so Node <= 18 keeps working.
