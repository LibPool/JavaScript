# dsh-molbio-tools

> 标签: cloning, cordis, deepseek-harness, molecular-biology, plasmid, primer, qpcr, sanger

## 简介

Zero-dependency molecular-biology plugin bundle for the DeepSeek Harness: sequence analysis, primer design (incl. cross-intron qPCR primers, TaqMan hydrolysis/MGB probes with ordering CSV and multiplex compatibility), in-silico PCR, cloning simulation, Sn
