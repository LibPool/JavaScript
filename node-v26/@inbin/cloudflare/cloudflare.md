# @inbin/cloudflare

> 标签: agents, cloudflare, email, email-workers, inbin, inbound-email, mcp

## 简介

Forward Cloudflare email (Email Workers / Agents SDK onEmail) to Inbin: raw RFC-822 in, schema-validated JSON with per-field trust labels out.
