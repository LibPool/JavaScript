# @notion-headless-cms/react-renderer

> 标签: headless-cms, notion, react, renderer, shadcn, tailwindcss, typescript

## 简介

Notion ブロックを React コンポーネントとして直接描画するレンダラ。shadcn/ui + Tailwind v4 ベース。
