# @notion-headless-cms/fetch-blocks

> 标签: block-tree, blocks, fetcher, headless-cms, notion, typescript

## 简介

Notion ブロック children API を再帰的に取得する fetch 戦略。BlockObjectResponse ツリーを返し、react-renderer で描画する。
