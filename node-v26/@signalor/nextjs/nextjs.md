# @signalor/nextjs

> 标签: ai-search, geo, llms-txt, nextjs, schema, signalor

## 简介

Signalor SDK for Next.js — auto-injects schema markup, serves llms.txt + sitemap, and reports deploys to Signalor for GEO scoring.
