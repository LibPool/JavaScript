# @mnemonik/grok-hooks

> 标签: grok, grok-build, hooks, mnemonik

## 简介

Grok lifecycle hooks for Mnemonik host-side gates and session bookkeeping. Uses Grok-native PreToolUse and Stop decisions; passive hooks never claim to inject model context.
