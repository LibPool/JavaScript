# @mnemonik/cursor-hooks

> 标签: cursor, hooks, mnemonik

## 简介

Cursor IDE hooks for Mnemonik memory awareness and host-side grounding gates. Hooks only: does not install skills, rules, AGENTS.md, .mnemonik.json, or MCP config.
