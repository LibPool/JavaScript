# @mnemonik/copilot-hooks

> 标签: github-copilot, hooks, mnemonik, vscode

## 简介

Native VS Code GitHub Copilot lifecycle hooks for Mnemonik: prompt and session recall, file grounding, shell policy gates, MCP ordering, edit tracking, and pre-compaction snapshots. Hooks only; does not install MCP, skills, rules, or project identity.
