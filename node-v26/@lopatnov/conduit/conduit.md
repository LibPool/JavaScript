# @lopatnov/conduit

> 标签: acme, api-gateway, auth, cors, dev-server, health-check, hot-reload, http, http2, https, jwt, load-balancer, load-balancing, middleware, pingora, prometheus, proxy, rate-limiting, reverse-proxy, rust, static-file-server, tls, wasm, web-server, websocket

## 简介

Production-grade reverse proxy and API gateway built on Cloudflare Pingora. TLS, JWT auth, rate limiting, load balancing, caching, Prometheus metrics, hot reload. One config file, one binary, no runtime dependencies.
