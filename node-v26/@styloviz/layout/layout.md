# @styloviz/layout

> 标签: angular, dashboard, layout, sidebar, styloviz, tailwind

## 简介

App-shell and layout primitives — sidebar, topbar, page header, dashboard shell, footers, divider, toolbar, expand, plus copy-to-clipboard and scroll-to-top.
