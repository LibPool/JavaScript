# @geonosis/verify-arch

> 标签: architecture, ci, gate, lint, medusa, monorepo, scanner

## 简介

Whole-graph architecture scans a per-file linter cannot do — unique module names, route collisions, tier direction, dead files — as configurable packs behind one exit code.
