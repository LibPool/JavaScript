# @geonosis/workflows

> 标签: compensation, durable-execution, outbox, saga, workflow

## 简介

A workflow engine with one door: named steps whose compensation travels with them, a body that is a real async function with real values, and a journal contract whose run lifecycle, transactional outbox and reverse-start unwinding are model-checked.
