# @geonosis/design-kit

> 标签: commerce, components, design-kit, react, storefront, themekit, ui

## 简介

Geonosis's design kits in one package: each kit is a subtree imported by its own subpaths (@geonosis/design-kit/<kit>/atoms/…), so an app's bundle holds only the kit it imports. Themed through @geonosis/themekit's CSS variables; knows nothing about Next,
