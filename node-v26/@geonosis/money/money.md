# @geonosis/money

> 标签: currency, decimal, intl, money, rounding

## 简介

Money as an exact decimal: computed exactly, rounded once, half a cent upward — line amounts, sums and rates that never pass through a float, a fixed-decimal string as the one door a wire crosses money through, and a currency table with locale-aware forma
