# dsh-mesh-waker

> 标签: agent, deepseek-harness, dsh, dsh-plugin, lan, mesh, wake

## 简介

DSH client plugin for dsh-mesh: turns a signed, content-free wake ping from the hub into a real session turn, with a settings page, inbox card and history cache.
