# @fendsh/cli-linux-x64

> 标签: JavaScript

## 简介

Native fend binary and guest agent for Linux x64. Installed automatically as an optional dependency of @fendsh/cli.

## 官网

- 官网：https://fend.sh
- 源码仓库：git+https://github.com/Lisovate/fend.git
- npm 页面：https://www.npmjs.com/package/@fendsh/cli-linux-x64
