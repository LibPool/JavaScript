# @freerdp-bridge/express

> 标签: JavaScript

## 简介

Embed the FreeRDP browser bridge in an existing Express 5 application on its HTTP/HTTPS and WebSocket port. Each RDP session runs in a separate native worker. The adapter delegates bounded routing and lifecycle to `@freerdp-bridge/http`.
