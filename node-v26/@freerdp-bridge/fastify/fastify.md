# @freerdp-bridge/fastify

> 标签: JavaScript

## 简介

Mount RDP HTTP and WebSocket routes inside an existing Fastify 5 application, on its existing port. Each session runs a separate native worker; FreeRDP does not run inside Node.js. Package name: `@freerdp-bridge/fastify`.
