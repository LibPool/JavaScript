# @freerdp-bridge/nestjs

> 标签: JavaScript

## 简介

NestJS module for mounting FreeRDP Browser Bridge HTTP/WebSocket routes on the application's existing port. Uses the existing session/media engine and one native C++ worker per session; FreeRDP runs outside Node.js.
