# @luraty/pack-de

> 标签: deutsch, frequency-list, german, language-pack, lemmatization, luraty

## 简介

German language pack for @luraty/engine — 10,000 lemmas ranked from Leipzig news and web text, 15,471 inflected forms lemmatized from Universal Dependencies treebanks.
