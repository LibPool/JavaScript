# @derockit/words-frequency

> 标签: JavaScript

## 简介

An NPM package for common English words frequency based on 20,000 [common words in Project Gutenberg](https://en.wiktionary.org/wiki/Wiktionary:Frequency_lists#Project_Gutenberg).
