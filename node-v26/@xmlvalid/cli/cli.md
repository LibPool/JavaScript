# @xmlvalid/cli

> 标签: ci, dtd, e-invoice, einvoicing, en16931, factur-x, peppol, relaxng, schematron, ubl, validation, validator, xml, xrechnung, xsd, zugferd

## 简介

Validate XML and e-invoices from the command line and CI: XSD, DTD, RelaxNG and Schematron business rules (EN 16931, Peppol, XRechnung, Factur-X) with the xmlvalid.com API.
