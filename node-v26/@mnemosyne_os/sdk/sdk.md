# @mnemosyne_os/sdk

> 标签: ai, electron, layer2, local-ai, memory, mnemosyne, sdk, sovereign, vector

## 简介

Official SDK for building Layer 2 apps on Mnemosyne OS. Connects to the local AI memory runtime over WebSocket or Electron IPC.
