# dsh-dock-vitals

> 标签: amd, apple-silicon, cpu, deepseek-harness, dsh, dsh-plugin, gpu, memory, nvidia, resource-monitor, status-bar, system-monitor

## 简介

Live CPU, memory and GPU readout in the DeepSeek Harness composer status bar: a clickable badge with a details panel, per-metric toggles and three refresh speeds in settings.
