# @zweiundeins/cashctrl-mcp

> 标签: accounting, buchhaltung, cashctrl, claude, erp, mcp, model-context-protocol, switzerland

## 简介

MCP server for the CashCtrl accounting API: 18 read tools over all 376 endpoints, plus four write tools behind an explicit write mode.
