# @mdht/plugin-betterauth-claims

> 标签: better-auth, codegen, effect, standard-schema, zenstack, zmodel

## 简介

ZenStack v3 CLI plugin: generate BetterAuth additionalFields (with a Standard Schema validator) from your ZModel schema's @@auth model.
