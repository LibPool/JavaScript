# @ytrynot/schvalid

> 标签: ajv, ajv-alternative, discriminator, dna, json-schema, json-schema-2020-12, openapi, performance, schema, typescript, validation, validator

## 简介

JSON Schema 2020-12 validator with compiled standalone JS function using DNA bytecodes. OpenAPI 3.1 discriminator support. Close to AJV's speed.
