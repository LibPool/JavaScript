# @medanosol/translation-tool

> 标签: deepl, gui, i18n, language, languages, translation

## 简介

@medanosol/translation-tool is a tool that allows you to translate your i18n files in a simple and fast way. You can manually translate the files or use the Deepl API to translate them automatically.
