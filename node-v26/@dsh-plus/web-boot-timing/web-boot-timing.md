# @dsh-plus/web-boot-timing

> 标签: JavaScript

## 简介

dsh-plus ui plugin: 弱网首屏计时观测——导航/绘制/资源分桶/遮罩移除/首次输入五相报告，输出控制台 + globalThis 钩子 + localStorage 历史对比；纯观测零行为改动，settings 一键关闭
