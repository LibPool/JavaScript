> 标签: cpp.js, cpp.js-package, image, jpeg, jpegturbo, libjpeg-turbo, wasi, webassembly

## 简介

WASI build of the precompiled libjpeg-turbo (JPEG) library, built with cpp.js. Use it together with the main package @cpp.js/package-jpegturbo.
