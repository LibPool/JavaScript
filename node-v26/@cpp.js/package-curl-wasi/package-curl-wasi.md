# @cpp.js/package-curl-wasi

> 标签: cpp.js, cpp.js-package, curl, http, libcurl, networking, wasi, webassembly

## 简介

WASI build of the precompiled libcurl (CURL) library, built with cpp.js. Use it together with the main package @cpp.js/package-curl.
