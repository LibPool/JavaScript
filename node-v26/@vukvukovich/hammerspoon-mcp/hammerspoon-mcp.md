# @vukvukovich/hammerspoon-mcp

> 标签: automation, hammerspoon, lua, macos, mcp, modelcontextprotocol, window-management

## 简介

MCP server for Hammerspoon. Injection-safe argument passing, tiered tool permissions, and Hammerspoon API docs search.
