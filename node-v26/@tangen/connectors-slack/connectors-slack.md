# @tangen/connectors-slack

> 标签: JavaScript

## 简介

The Slack connector pack for Tangen: one Slack workspace connection by OAuth or by bot token, channel picking, a typed chat service and a Flow action. Tangen ships no connectors of its own - install the providers you use
