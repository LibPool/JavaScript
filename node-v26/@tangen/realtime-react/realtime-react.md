# @tangen/realtime-react

> 标签: JavaScript

## 简介

React bindings for @tangen/realtime - a provider, useRealtime, useRealtimeStatus, useRealtimeEvent, usePresence and usePresenceSelector. Selector-based, so a component re-renders only when its slice changes; never a second transport.
