# @jalpi/taskjalpi

> 标签: bug-tracking, bugs, express-middleware, issue-tracker, jalpi, taskjalpi, tasks

## 简介

TaskJalpi client for Node.js — create and manage tasks and typed records (bugs, etc.), and auto-track exceptions as bugs (Express middleware). Wraps the TaskJalpi public API.
