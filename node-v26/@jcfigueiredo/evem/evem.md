# @jcfigueiredo/evem

> 标签: event-emitter, events, middleware, pubsub, server-sent-events, sse, typescript, websocket, wildcard

## 简介

Lightweight TypeScript event emitter with wildcards, priorities, middleware, filters, throttle/debounce, schema validation, event history, and optional WebSocket and Server-Sent Events adapters
