# yoink-bridge

> 标签: bridge, cloudflare-workers, github-issues, linear, standard-webhooks, webhook, yoink

## 简介

Your own bridge from yoink to Linear, GitHub Issues or your own code: an SDK for Cloudflare Workers, Node, Deno and Bun, plus a base Worker you deploy with one click. Signed entries verified, retries deduplicated.
