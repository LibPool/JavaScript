# @ton-primes/agent

> 标签: agent, ai-agent, mcp, nft, number-theory, sdk, ton, ton-blockchain, typescript, web3

## 简介

TypeScript SDK for TON PRIMES: every action a program-player can take, each gated by a live get-method read, with the key signing locally and never leaving the process.
