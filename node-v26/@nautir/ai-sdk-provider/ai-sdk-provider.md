# @nautir/ai-sdk-provider

> 标签: ai, ai-sdk, ai-sdk-provider, gateway, llm, llm-gateway, nautir, vercel-ai

## 简介

AI SDK provider for the Nautir AI Gateway — one wire for every model (Chat Completions, Claude included) with the prompt-cache breakpoint preserved, gateway controls on providerOptions.nautir.*
