# @argentic/chest-mcp

> 标签: agent, argentic, chest, mcp, model-context-protocol

## 简介

The MCP server that lets an assistant work on a Chest with a member's personal access token: tools, logs, database, files, variables, catalogue and GitHub, every write confirmed by a human.
