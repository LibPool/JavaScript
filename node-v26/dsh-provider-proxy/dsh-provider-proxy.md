# dsh-provider-proxy

> 标签: deepseek, dsh, dsh-plugin, llm, proxy, settings

## 简介

DSH 插件：在设置里为每个已启用的 provider 单独配置正向代理（类型 + IP + 端口），未配置的 provider 与其它流量保持直连。
