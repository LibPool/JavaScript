# @use-truapi/core

> 标签: hooks, polkadot, product-sdk, truapi, web3

## 简介

Framework-agnostic runtime for TruAPI hooks: host detection, chain clients, signers, transactions, chat, statements, payments and cloud storage for Polkadot apps.
