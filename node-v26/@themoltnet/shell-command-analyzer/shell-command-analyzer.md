# @themoltnet/shell-command-analyzer

> 标签: bash, security, shell, static-analysis, tool-policy, tree-sitter

## 简介

Isomorphic static analyzer that extracts the executables a shell command runs (resolving wrappers, find -exec, …) and classifies each by risk, for tool-policy enforcement. Fails closed on statically-unresolvable commands.
