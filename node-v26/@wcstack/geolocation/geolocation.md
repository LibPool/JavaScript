# @wcstack/geolocation

> 标签: custom-elements, declarative, framework-agnostic, geolocation, gps, position, wc-bindable, web-components, zero-dependencies

## 简介

Declarative geolocation component for Web Components. Framework-agnostic Geolocation API primitive via wc-bindable-protocol.
