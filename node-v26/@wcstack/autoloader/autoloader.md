# @wcstack/autoloader

> 标签: autoloader, buildless, custom-elements, dynamic-import, import-maps, lazy-loading, mutation-observer, web-components, zero-dependencies

## 简介

Auto-detect and dynamically import undefined custom elements via Import Maps. Zero dependencies, buildless.
