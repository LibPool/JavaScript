# @wcstack/pointer-lock

> 标签: custom-elements, declarative, framework-agnostic, game-input, mouse, pointer-lock, wc-bindable, web-components, zero-dependencies

## 简介

Declarative Pointer Lock component for Web Components. Framework-agnostic Pointer Lock API control via wc-bindable-protocol.
