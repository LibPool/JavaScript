# @wcstack/devtools

> 标签: custom-elements, debugging, declarative, devtools, framework-agnostic, inspector, state-management, web-components

## 简介

In-page DevTools overlay for wcstack. Inspect state trees, bindings/wiring and update timelines via the DevTools Hook Protocol - one script tag, no build step.
