# @wcstack/network

> 标签: adaptive-loading, connection, custom-elements, declarative, framework-agnostic, network-information, wc-bindable, web-components, zero-dependencies

## 简介

Declarative Network Information component for Web Components. Framework-agnostic navigator.connection monitor via wc-bindable-protocol.
