# @wix/himalaya-cli

> 标签: cli, himalaya, himi, sdui

## 简介

himi — the Himalaya authoring CLI. Build a Tier-5 content package on your own machine, push it to the production serve as a draft, preview it on web + Himi Player, and read worker logs back — the remote dev loop. Wraps @himalaya/serve-cli for transport.
