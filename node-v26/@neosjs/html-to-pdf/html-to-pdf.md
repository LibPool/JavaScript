# @neosjs/html-to-pdf

> 标签: html-to-pdf, monitoring, neosjs, pdf, pdf-convert, pdf-generate, performance, typescript

## 简介

高性能HTML转PDF工具，支持中文、图片、表格、分页、水印、自定义页眉页脚和页码，内置性能监控和错误处理
