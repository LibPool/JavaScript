# @neosjs/cli

> 标签: Neos, NeosJS, cli, vue3

## 简介

Neos(奈欧斯)是一个帮助开发者快速地创建 Vue3 应用并自动配置项目编译的脚手架

## 官网

- 官网：https://docs.neosjs.com/cli/
- npm 页面：https://www.npmjs.com/package/@neosjs/cli

## 获取地址

- npm 安装：`npm install @neosjs/cli`
- npm registry：https://registry.npmjs.org/@neosjs/cli
- Node 要求：>= 12.16.1
