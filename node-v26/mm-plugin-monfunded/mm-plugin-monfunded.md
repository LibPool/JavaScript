# mm-plugin-monfunded

> 标签: agent-wallet, metamask, monad, monfunded, oclif-plugin

## 简介

MonFunded for MetaMask Agent Wallet: an AI agent buys a MonFunded assessment, trades it and claims its payouts with the mm CLI, on Monad.
