# @panzhiyue/leaflet-canvaslabel

> 标签: label, leaflet, leaflet-plugin, map

## 简介

用于在矢量数据上显示标签，样式设置基于Canvas标准，还提供了偏移，缩放，旋转，指定显示位置等设置参数。
