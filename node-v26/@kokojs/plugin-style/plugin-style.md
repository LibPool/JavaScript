# @kokojs/plugin-style

> 标签: JavaScript

## 简介

`@kokojs/plugin-style` 提供了预处理 CSS 的能力，支持 Sass 语法，不再支持原有的 precss、sass-like 等语法。

## 官网

- 源码仓库：http://gitlab.qima-inc.com/fe/koko
- npm 页面：https://www.npmjs.com/package/@kokojs/plugin-style
