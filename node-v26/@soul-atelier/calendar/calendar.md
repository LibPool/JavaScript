# @soul-atelier/calendar

> 标签: chinese-calendar, four-pillars, ganzhi, lunar, solar-terms, tyme4ts, 八字, 农历, 四柱, 干支, 节气

## 简介

Chinese calendar engine layer: four pillars (四柱) with 立春/節 boundaries, 建除 duty, lunar labels, and hour slots — a typed interface with a tyme4ts-backed engine, returning @soul-atelier/core GanZhi values.
