# @chainvue/v402-facilitator

> 标签: JavaScript

## 简介

Standalone v402 facilitator daemon: verify/reserve/commit/rollback API, balance state, deposit watching, discovery — NestJS, Pino JSON logs, Prometheus metrics, Zod-validated config.
