# @chainvue/v402-nestjs

> 标签: JavaScript

## 简介

NestJS adapter for v402: PaymentGuard + PaymentInterceptor (two-phase debit), @V402Payment route decorator, V402Module with in-process or facilitator-HTTP verification.
