# @phispira/mcp

> 标签: agent-graph, anchor, fact-checking, mcp, model-context-protocol, verification

## 简介

Phispira anchor node for AI agent graphs — a mechanical, sealed verify_claim tool. Grounds a claim against a deterministic oracle and 7 independent cross-vendor models before certifying it; never certifies on model agreement alone.
