# pool-anything

> 标签: anthropic, api-gateway, api-key-pool, api-proxy, free-tier, gemini, groq, ink-tui, key-rotation, llm-gateway, openai, openrouter, quota, rate-limit, round-robin, self-hosted, sqlite, typescript, usage-tracking

## 简介

Gather free-tier API keys from any provider into one pool and rotate through them — round-robin key selection, usage/quota tracking, and a drop-in HTTP proxy with a built-in web UI. Dependency-free server core, TypeScript + SQLite.
