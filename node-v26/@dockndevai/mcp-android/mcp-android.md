# @dockndevai/mcp-android

> 标签: adb, ai, android, device-control, llm, mcp, mobile, model-context-protocol

## 简介

Model Context Protocol server to control an Android device over ADB — screenshots, taps, typing, app launch, alarms, notifications — safe-by-default with access modes and gated destructive ops.
