# @dockndevai/mcp-mac-control

> 标签: ai, applescript, automation, computer-use, gui-automation, llm, mac, macos, mcp, model-context-protocol, remote-control

## 简介

Model Context Protocol server for FULL macOS control — drive a Mac like a human: shell, AppleScript, files, processes, and human-like GUI (move, click, double/right-click, drag, scroll, type, keys). Full control by default, with an opt-in safe mode.
