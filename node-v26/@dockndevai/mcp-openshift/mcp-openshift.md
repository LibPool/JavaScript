# @dockndevai/mcp-openshift

> 标签: ai, cluster, devops, k8s, kubernetes, llm, mcp, model-context-protocol, oc, openshift

## 简介

Model Context Protocol server for OpenShift / Kubernetes — projects, pods, logs, deployments, routes, builds and more, with username/password (local IdP) or token auth and safe-by-default access modes and guards.
