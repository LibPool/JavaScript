# @dockndevai/mcp-outlook

> 标签: ai, email, exchange, llm, mail, mcp, microsoft-365, microsoft-graph, model-context-protocol, office365, outlook

## 简介

Model Context Protocol server for Microsoft Outlook mail (Microsoft Graph) — read, search, draft, send, reply, forward and organize email plus manage OneDrive files, with browser sign-in and safe-by-default access modes and guards.
