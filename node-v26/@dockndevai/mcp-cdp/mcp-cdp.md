# @dockndevai/mcp-cdp

> 标签: ai, browser-automation, cdp, chrome, chrome-devtools-protocol, devtools, electron, llm, mcp, model-context-protocol

## 简介

Model Context Protocol server that drives an Electron/Chrome app over the DevTools Protocol (CDP) — DOM, console, network, click/type/navigate and gated JS eval — safe by default, cross-OS.
