# @tilr-dev/plugin

> 标签: cordis, plugin, sdk, tilr, tilr-plugin

## 简介

The kit for writing Tilr plugins in their own repos: the plugin API's types, the shared build and CLI (tilr-plugin), the e2e harness with the built core page, shared tsconfig, oxlint and Playwright config, and the repo standard's checks (tilr-plugin verif
