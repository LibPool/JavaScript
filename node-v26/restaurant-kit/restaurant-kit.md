# restaurant-kit

> 标签: admin, cloudflare, cloudflare-workers, cms, menu, r2, react, restaurant, whatsapp

## 简介

Restaurant website kit for React + Cloudflare: public menu, WhatsApp or delivery-app ordering, owner-editable menu CMS, and a Worker API backed by R2.
