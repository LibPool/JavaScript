# @turbodl/cli

> 标签: agent, cli, download, downloader, http, https, multithread, ndjson, resume

## 简介

TurboDL command-line downloader — high-performance multi-threaded HTTP(S) downloads with resume, batch, and NDJSON output. Thin NPM wrapper around the TurboDL JVM CLI.
