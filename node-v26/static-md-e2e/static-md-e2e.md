# static-md-e2e

> 标签: claude, cursor, e2e, end-to-end encryption, markdown, mcp, notes, static.md

## 简介

Local MCP server that lets AI agents read and write end-to-end encrypted static.md notes. Keys and plaintext stay on your computer.
