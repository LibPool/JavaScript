# @quick-dash-engine/core

> 标签: dashboard, engine, parser, quick-dash, quick-dash-engine

## 简介

QuickDashEngine is a TypeScript library for efficient backend dashboard processing. It enables the execution of SQL queries, dynamic mathematical calculations, and optimized execution with concurrency control.
