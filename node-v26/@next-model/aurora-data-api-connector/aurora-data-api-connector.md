# @next-model/aurora-data-api-connector

> 标签: aurora, aws, connector, data-api, database, lambda, next-model, orm, rds, serverless

## 简介

next-model connector for the AWS RDS Data API — the HTTP query interface for Aurora Serverless v1 (PostgreSQL or MySQL). Connection-less, ideal for AWS Lambda.
