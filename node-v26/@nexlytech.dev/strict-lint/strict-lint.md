# @nexlytech.dev/strict-lint

> 标签: architecture, eslint, eslint-plugin, eslintplugin, folder-structure, oxlint, oxlint-plugin, react, shadcn

## 简介

Folder-structure, one-component-per-file and native-element linting for React. One rule core, runs on both ESLint and oxlint.
