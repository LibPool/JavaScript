# @sagaryeole/pg-studio

> 标签: data-viewer, database, database-browser, database-gui, database-viewer, developer-tools, express, local-first, pgadmin-alternative, postgres, postgres-gui, postgresql, read-only, self-hosted, sql, typescript

## 简介

A fast, read-only PostgreSQL browser that runs locally. Browse tables, filter, follow foreign keys, inspect structure and run read-only SQL.
