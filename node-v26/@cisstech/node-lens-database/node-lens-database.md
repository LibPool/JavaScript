# @cisstech/node-lens-database

> 标签: JavaScript

## 简介

Captures your app's database queries, groups them under the request that triggered them, and flags the two problems you can't see from the code: N+1 bursts and slow queries. Works with PostgreSQL, MySQL, MongoDB, and Redis.
