# @cisstech/node-lens-introspection

> 标签: JavaScript

## 简介

For NestJS apps: surfaces the module graph, providers, and routes (plus OpenAPI and GraphQL endpoints) so you can explore an app's structure from the dashboard. It detects the framework and only appears when you're running NestJS.
