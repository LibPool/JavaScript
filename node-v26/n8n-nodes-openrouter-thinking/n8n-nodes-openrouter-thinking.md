# n8n-nodes-openrouter-thinking

> 标签: ai-agent, langchain, llm, n8n, n8n-community-node-package, openrouter, reasoning, reasoning-effort, thinking-mode

## 简介

OpenRouter chat model for n8n with a Reasoning Effort control (none to max), a max tokens option that reaches the request, and reasoning carried across tool calls.
