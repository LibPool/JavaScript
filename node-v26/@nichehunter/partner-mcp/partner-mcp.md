# @nichehunter/partner-mcp

> 标签: facebook-ads, mcp, model-context-protocol, nichehunter, pinterest-ads, tiktok

## 简介

MCP server for the NicheHunter Partner API - lets Claude Desktop, Cursor, Cline, etc. query TikTok Shop, TikTok Ads, Facebook Ads, and Pinterest Ads via natural language.
