# @i2labs/dns

> 标签: DoH, RFC1035, RFC8484, browserify, dns, nodejs

## 简介

Dependency free, browser compatible, NodeJS dns library replacement. Implements RFC8484 and RFC1035. Supports most DNS over HTTPS servers.
