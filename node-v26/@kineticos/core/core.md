# @kineticos/core

> 标签: animation, canvas, cdn, dots, framer, html, interactive, mouse-tracking, particles, physics, shader, webflow, webgl

## 简介

WebGL canvas effects for Webflow and any HTML platform. Attribute-driven. Zero config to full control.
