# @inferencebureau/apps-sdk

> 标签: apps, inferencebureau, sdk, shopify

## 简介

The SDK an Inference Bureau app's code imports: action helpers, metadata types, the records API client, React hooks with AutoTable and AutoForm, and a test harness for its actions.
