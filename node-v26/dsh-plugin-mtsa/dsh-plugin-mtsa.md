# dsh-plugin-mtsa

> 标签: analytics, deepseek-harness, dsh, dsh-plugin, mcp, mts-analytics, mtsa

## 简介

MTS Analytics for DeepSeek Harness: token-managed MCP connection (mcp__mtsa__* tools through the official dsh-mcp-client) plus the "MTS Analytics" agent preset with bundled mtsa-* skills.
