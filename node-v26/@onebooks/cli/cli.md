# @onebooks/cli

> 标签: accounting, cli, developer-tools, hosted-functions, onebooks, scaffold

## 简介

OneBooks developer CLI: sign in to the developer console, list apps, deploy and test hosted functions, and scaffold a new embedded app from a template.
