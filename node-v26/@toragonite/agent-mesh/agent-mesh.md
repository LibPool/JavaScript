# @toragonite/agent-mesh

> 标签: agent, ai, antigravity, claude, cli, codex, cursor, gemini, llm, orchestration

## 简介

One interface to drive Claude, Codex, Antigravity (Gemini), and Cursor coding agents as headless workers — spawn, revise, read quota, route by strength/quota/latency. Unofficial.
