# @zimatech/named-replacer-args

> 标签: String.replace, String.replaceAll, argument, arguments, name, names, parameter, parameters, replacement, replacer

## 简介

Turns the arguments of a replacer function in `String.replace` and `String.replaceAll` into an object with useful names.
