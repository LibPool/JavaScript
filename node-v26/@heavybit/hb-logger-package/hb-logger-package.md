# @heavybit/hb-logger-package

> 标签: OpenTelemetry, logger, logging, monitoring, paginate, pagination, queue, tracing

## 简介

A shared logger package that integrates OpenTelemetry tracing, exception handling, and Winston logging for Node.js applications. It provides a unified interface for logging and tracing, making it easier to monitor and debug applications.
