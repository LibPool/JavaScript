# @hasdata/walmart-mcp

> 标签: ecommerce, hasdata, mcp, model-context-protocol, price-monitoring, product-data, scraper, walmart, walmart-mcp

## 简介

MCP server for Walmart through HasData's hosted API: keyword and category search, product pages with the buy box and other sellers, and the review feed with its filter block. No Walmart developer account. 1,000 free credits every month.
