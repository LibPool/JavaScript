# @hasdata/chatgpt-mcp

> 标签: ai-search, chatgpt, chatgpt-api, chatgpt-mcp, hasdata, llm, mcp, model-context-protocol, scraper

## 简介

MCP server for the ChatGPT Scraper API through HasData's hosted API: send a prompt anonymously and get the answer as markdown with the web sources ChatGPT consulted. No OpenAI account or API key. 1,000 free credits every month.
