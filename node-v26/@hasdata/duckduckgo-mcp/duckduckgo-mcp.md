# @hasdata/duckduckgo-mcp

> 标签: ddg, duckduckgo, duckduckgo-mcp, hasdata, mcp, model-context-protocol, scraper, search, serp

## 简介

MCP server for DuckDuckGo search through HasData's hosted API: ranked organic results, ads in their own array, the Search Assist AI answer, and 37 regions. All as structured JSON. 1,000 free credits every month.
