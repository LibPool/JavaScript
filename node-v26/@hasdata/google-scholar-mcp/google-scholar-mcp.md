# @hasdata/google-scholar-mcp

> 标签: academic, bibliometrics, citations, google-scholar, hasdata, mcp, model-context-protocol, research, scholar-mcp

## 简介

MCP server for Google Scholar through HasData's hosted API: search papers with author and source helpers, year ranges, cited-by and all-versions lookups, plus citation formats and export links. 1,000 free credits every month.
