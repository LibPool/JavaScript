# @hasdata/google-trends-mcp

> 标签: google-trends, google-trends-mcp, hasdata, mcp, model-context-protocol, scraper, seo, trends

## 简介

MCP server for Google Trends through HasData's hosted API: interest over time, interest by region, and rising and top related queries and topics. 1,000 free credits every month.
