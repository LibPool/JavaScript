# @hasdata/hasdata-openclaw-plugin

> 标签: amazon, google, hasdata, openclaw, openclaw-plugin, scraping, serp, zillow

## 简介

HasData plugin for OpenClaw — Google SERP, Google Maps, Amazon, Zillow, Redfin, Airbnb, Yelp, Indeed, and arbitrary web scraping via api.hasdata.com. Requires a HasData API key (HASDATA_API_KEY env var or plugins.entries.hasdata.config.apiKey).
