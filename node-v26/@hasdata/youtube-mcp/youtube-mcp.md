# @hasdata/youtube-mcp

> 标签: hasdata, mcp, model-context-protocol, scraper, transcript, youtube, youtube-mcp, youtube-mcp-server

## 简介

MCP server for YouTube data (search, video, channel, transcript) through HasData's hosted API. No Google Cloud project, no YouTube Data API key. 1,000 free credits every month.
