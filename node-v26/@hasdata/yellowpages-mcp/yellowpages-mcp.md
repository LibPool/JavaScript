# @hasdata/yellowpages-mcp

> 标签: hasdata, lead-generation, local-business, local-seo, mcp, model-context-protocol, scraper, yellowpages, yellowpages-mcp

## 简介

MCP server for Yellow Pages through HasData's hosted API: search local businesses by keyword and location, and read one listing in full with phone, hours and years in business. 1,000 free credits every month.
