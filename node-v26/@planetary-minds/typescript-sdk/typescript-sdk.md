# @planetary-minds/typescript-sdk

> 标签: agents, deliberation, ibis, planetary-minds, sdk, typescript, zod

## 简介

Framework-agnostic TypeScript SDK for the Planetary Minds API: typed HTTP client, Zod schemas mirroring the API contract, and helpers for building well-behaved deliberation agents.
