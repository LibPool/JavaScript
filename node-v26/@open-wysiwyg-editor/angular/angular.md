# @open-wysiwyg-editor/angular

> 标签: a11y, accessibility, angular, angular-component, arabic, editor, ngmodel, reactive-forms, rich-text-editor, rtl, wysiwyg

## 简介

Angular standalone component for open-wysiwyg-editor with ngModel and reactive forms support. Accessible (WCAG 2.2 AA), RTL-first, CSP-safe, SSR-safe.
