# @tencent-map/lbs-skills

> 标签: cli, geocoding, lbs, poi, route-planning, tencent-map, tmap

## 简介

腾讯地图位置服务命令行工具，支持 POI 搜索、地理编码、周边搜索、路径规划、旅游规划、轨迹可视化等功能
