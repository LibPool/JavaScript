# @godcreator/gwb-unit-folder

> 标签: gwb-plugin

## 简介

单元文件夹插件：出生证（unit.json）字段表的正本——建单元、现扫单元容器根读出生证，树里按状态与种类过滤、展开看文件、点文件读原文；「人现在看的是哪个单元」经 unit-folder/selection 事件往外报。服务 gwbUnitFolder；skill 1 份；命令 11 条。
