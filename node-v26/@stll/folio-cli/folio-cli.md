# @stll/folio-cli

> 标签: cli, docx, mcp, ooxml, redline, tracked-changes, word

## 简介

Command line and stdio MCP server for reading, reviewing, and redlining .docx files with folio: tracked-change edits, comments, and comparisons written atomically with version preconditions.
