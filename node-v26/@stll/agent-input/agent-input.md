# @stll/agent-input

> 标签: agent, input, lenient, llm, normalization, parsing, validation

## 简介

Lenient readers for values agents write: dates, date bounds, date-format specs, numbers, booleans, locales, countries, enum and vocabulary values, ids, ELIs, string lists
