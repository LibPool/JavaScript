# @stll/text-search

> 标签: aho-corasick, fuzzy, multi-pattern, orchestrator, regex, text-search

## 简介

Multi-engine text search orchestrator for Node.js and Bun. Routes literals, regex, and fuzzy patterns to the right engine automatically.
