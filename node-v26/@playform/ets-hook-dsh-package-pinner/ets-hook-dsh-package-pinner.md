## 简介

Silent package.json VERSION PINNER: hooks fs/observed — the cordis event every tool-layer file write dispatches — and deterministically rewrites every ranged dependency version to its STATIC version ("^0.3.4" → "0.3.4": one leading ^, ~, or = stripped), i
