# @playform/ets-hook-dsh-normalize-invisible

> 标签: JavaScript

## 简介

The invisible hook: a DeepSeek Harness plugin that hooks the llm/stream waterfall — the interceptable wrapper around EVERY streaming model call — and normalizes the zero-width/invisible character family (U+00AD soft hyphen, U+200B–U+200F zero-width spaces
