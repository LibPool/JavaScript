# @playform/hook-dsh-normalize-fullwidth

> 标签: JavaScript

## 简介

The fullwidth hook: a DeepSeek Harness plugin that hooks the llm/stream waterfall — the interceptable wrapper around EVERY streaming model call — and normalizes the full-width family (the entire FULLWIDTH FORMS range U+FF01–U+FF5E) in model output streams
