# @spinajs/queue-amqp-transport

> 标签: amqp, queue, rabbitmq, spinajs

## 简介

spinajs queue transport based on AMQP 0-9-1 ( RabbitMQ ). Sends & reads queue messages ( jobs & events ) from an amqp compatible broker.
