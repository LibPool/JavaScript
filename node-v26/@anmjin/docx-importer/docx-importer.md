# @anmjin/docx-importer

> 标签: docx, import, lexical, payload, prosemirror, rtl, tiptap, word

## 简介

Convert Word .docx files into Tiptap/ProseMirror JSON (and Payload Lexical state), with embedded images and human-readable import errors
