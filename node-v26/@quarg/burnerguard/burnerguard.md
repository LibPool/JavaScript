# @quarg/burnerguard

> 标签: allowlist, blocklist, burner, burnerguard, disposable, domain, email, email-validation, node, quarg, risk-score, security, spam, tempmail, typescript, validation

## 简介

Detect disposable and burner email addresses. Static blocklist mode with zero dependencies, or connect to the BurnerGuard API for real-time risk scoring.
