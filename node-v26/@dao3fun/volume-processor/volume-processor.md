# @dao3fun/volume-processor

> 标签: JavaScript

## 简介

用于实时和静态分析WAV音频文件的音量。它提供了从WAV文件中提取元数据和计算详细音量指标（包括平均音量、峰值音量和RMS音量）的功能。
