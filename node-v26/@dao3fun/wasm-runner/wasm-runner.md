# @dao3fun/wasm-runner

> 标签: JavaScript

## 简介

一个轻量且易于使用的工具，用于从各种来源（如 URL、Base64 data URI）加载和运行 WebAssembly (Wasm) 模块。为 JavaScript 和 TypeScript 提供了简单的异步 API。
