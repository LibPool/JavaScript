# @kinkai.cloud/vibecheck

> 标签: JavaScript

## 简介

O comando `analyze` (a partir de 0.3.0) analisa código, segredos e dependências, importa cobertura/testes/SARIF e avalia o quality gate. O modo anterior `--gate` continua compatível. Node.js 22+ e Git são necessários.
