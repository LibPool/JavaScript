# @hovatar/platlas-mcp

> 标签: bioinformatics, genomics, gwas, mcp, modelcontextprotocol, phewas, platlas, pleiotropy

## 简介

MCP server for PLATLAS — a GWAS/pheWAS atlas of 1167 phenotypes across 5 ancestry groups on GRCh38.
