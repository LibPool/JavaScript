> 标签: agent-skill, agents, ai, architecture, architecture-diagrams, aws, azure, c4, claude-code, codex, diagrams, diagrams-as-code, kubernetes, llm, svg, system-design

## 简介

The Squinch engine: parse, model, layout and deterministic rendering for architecture diagrams as code, exported as SVG, PNG or interactive HTML — the engine behind the agent skill, the CLI and the playground.
