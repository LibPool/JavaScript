# @nvidia-elements/cli

> 标签: cli, design-system, mcp, model-context-protocol, nvidia, project-scaffolding, web-components

## 简介

Command-line interface for NVIDIA Elements development and tooling, providing interactive prompts, project scaffolding, and integration with AI assistants via Model Context Protocol.
