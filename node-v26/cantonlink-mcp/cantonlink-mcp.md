# cantonlink-mcp

> 标签: bopomofo, cantonese, cli, jyutping, language-learning, mcp, model-context-protocol, yale

## 简介

Learn spoken Hong Kong Cantonese from your AI assistant or terminal: an MCP server and CLI over the CantonLink Community library, with Jyutping, Yale and Bopomofo.
