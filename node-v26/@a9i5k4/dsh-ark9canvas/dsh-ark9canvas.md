# @a9i5k4/dsh-ark9canvas

> 标签: canvas, deepseek-harness, dsh, generation, image, plugin

## 简介

DSH 生图插件 Ark9canvas：Agent 生图(默认需用户批准) + 浮窗生图工作台(比例/透明背景/批量/提示词库/多渠道/生成记录)，OpenAI 兼容图片 API 文生图/图生图。
