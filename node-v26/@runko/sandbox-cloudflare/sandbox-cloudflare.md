# @runko/sandbox-cloudflare

> 标签: JavaScript

## 简介

RunkoFS & RunkoExec 同源工作区：适配 Cloudflare Sandbox（网关形态——`.` 纯 fetch 客户端跑在任意 Node，`./worker` 网关部署在宿主 wrangler 项目）
