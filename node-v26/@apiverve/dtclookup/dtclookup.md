# @apiverve/dtclookup

> 标签: diagnostic trouble codes, dtc codes, dtc lookup, obd2 code lookup, obd2 codes

## 简介

DTC Lookup explains OBD-II diagnostic trouble codes such as P0301 or U0100. It returns the code's system and standard title, which warning light it turns on, and on paid plans the full description, likely causes ranked by likelihood, symptoms, repair diff
