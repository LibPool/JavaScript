# @apiverve/secfilings

> 标签: edgar api, edgar database api, sec api, sec edgar api, sec filings api

## 简介

SEC Filings returns the recent EDGAR filing history for a US public company by ticker - 10-K annual reports, 10-Q quarterlies, 8-K current reports, Form 4 insider filings, S-1 registrations and more - each with its filing date, form type and a direct link
