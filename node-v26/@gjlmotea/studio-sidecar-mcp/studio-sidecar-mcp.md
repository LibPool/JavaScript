> 标签: ai-agent, asset-upload, claude-code, codex, game-development, luau, mcp, mcp-server, model-context-protocol, open-cloud, opencloud, place, roblox, roblox-assets, roblox-open-cloud, roblox-studio, studio-mcp, studiomcp

## 简介

Studio Sidecar: companion MCP server for Roblox Studio's built-in MCP (StudioMCP). Opens places, manages StudioMCP broker and stub processes, guards writes by PlaceId, runs Luau past the 100k output limit, and uploads, updates or archives assets through R
