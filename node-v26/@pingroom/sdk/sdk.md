# @pingroom/sdk

> 标签: agent, ci, mcp, notifications, pingroom, push, sdk, typescript, webhook

## 简介

Official TypeScript/JavaScript SDK for the PingRoom agent API — app pairing, rooms, pings, human-in-the-loop approvals, questions and handoffs, live status, MCP, and webhook verification.

- 官网：https://pingroom.io
- 源码仓库：git+https://github.com/pingroom/sdk.git
- npm 页面：https://www.npmjs.com/package/@pingroom/sdk
