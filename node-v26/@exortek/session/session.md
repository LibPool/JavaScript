# @exortek/session

> 标签: backend, concurrent-session-limit, cookie, csrf, express, fastify, impersonation, node-crypto, revocation, rotation, sealed-cookie, security, session, session-management, step-up-auth, sudo-mode

## 简介

Sealed-cookie session manager for Node.js — rotation, revocation, sudo mode, impersonation, concurrent limits, fingerprint binding, device labels, Redis distributed revocation, and adapters for Fastify and Express.
