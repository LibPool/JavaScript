# @exortek/magic-link

> 标签: auth, backend, email-otp, email-verification, hmac, magic-link, node-crypto, passwordless, security, server-only, single-use

## 简介

Passwordless email-link auth for Node.js — HMAC-signed short-lived tokens (mlink_v1.<payload>.<hmac>), single-use enforcement, opt-in per-email rate limiting, hashed email in payload by default (SHA-256), configurable prefix, memory + Redis stores. Ships
