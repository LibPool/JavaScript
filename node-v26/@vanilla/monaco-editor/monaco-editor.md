# @vanilla/monaco-editor

> 标签: code, editor, monaco, react, text, vscode

## 简介

Fork from @monaco-editor/react. Monaco editor wrapper for easy/one-line integration with React applications (e.g. powered by create-react-app) without need of webpack configuration files
