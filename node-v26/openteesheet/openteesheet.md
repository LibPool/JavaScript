# openteesheet

> 标签: agent, booking, cli, golf, mcp, simulator, tee-times

## 简介

Command-line client for OpenTeeSheet: find tee times and simulator bays, book, cancel, list your bookings, and (venue owners) read today's tee sheet. Same API and same API key as the MCP server.
