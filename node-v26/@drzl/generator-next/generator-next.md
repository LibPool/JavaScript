# @drzl/generator-next

> 标签: codegen, drizzle, drizzle-orm, next, nextjs, server-actions

## 简介

Generate Next.js server actions from a Drizzle schema, one 'use server' module per table, with the FormData readers that turn what a browser posts into what the schemas accept.
