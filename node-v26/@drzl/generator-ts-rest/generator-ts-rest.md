# @drzl/generator-ts-rest

> 标签: codegen, contract, drizzle, drizzle-orm, rest, standard-schema, ts-rest

## 简介

Generate ts-rest contracts from a Drizzle schema, one contract per table plus a root router, with DRZL's own schemas as the body, params, query and response types.
