# @drzl/generator-ai

> 标签: ai, codegen, drizzle, drizzle-orm, standard-schema, tools, vercel-ai-sdk

## 简介

Generate AI SDK tools from a Drizzle schema, one module per table, so a language model is told each column's real bounds before it writes a row rather than after the database refuses one.
