# homebridge-laskomex-doorbell

> 标签: doorbell, esphome, homebridge-plugin, homekit, intercom, laskomex, mqtt, supports-hap

## 简介

HomeKit bridge for a Laskomex intercom fitted with an ESPHome smart module: doorbell notifications, door release and do-not-disturb over MQTT
