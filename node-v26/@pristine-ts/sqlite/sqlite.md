# @pristine-ts/sqlite

> 标签: JavaScript

## 简介

SQLite client for Pristine, backed by Node's built-in [`node:sqlite`](https://nodejs.org/api/sqlite.html) module — **zero external dependencies**, in line with the framework's serverless-first philosophy.
