# @xbear/pi-goal

> 标签: automation, goal, pi, pi-extension, pi-package

## 简介

Pi extension: keeps working on a /goal until the agent marks it complete. Works interactively (/goal) and CLI-only one-shot mode (pi -p "/goal ...").
