# dsh-backdrop-plugin

> 标签: background, deepseek-harness, dsh, dsh-plugin, skin, theme, wallpaper

## 简介

Image-background skin for DeepSeek Harness (web + desktop): import your own light/dark wallpapers through the built-in panel (no artwork bundled). No DSH source changes.
