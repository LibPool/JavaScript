# create-lorekeeper

> 标签: ai-agents, cli, knowledge-base, local-first, lorekeeper, markdown, retrieval, second-brain, wonder-wagon

## 简介

Lorekeeper — an AI-native second brain made of plain Markdown files you own. `lore` is a deterministic, offline CLI that ranks the passages answering a question.
