# @pennsieve-viz/tsviewer

> 标签: JavaScript

## 简介

Vue 3 timeseries viewer and annotator for Pennsieve packages. It renders channel waveforms to canvas, reads data either from a Zarr bundle in the browser or from the `pennsieve-streaming` WebSocket, and supports annotation layers, montages, and per-channe
