# @istarry/dsh-skill-suite

> 标签: JavaScript

## 简介

Skill management for the DeepSeek Harness: the Skills page (browse, toggle, edit, create, delete) over the user skill root, the save_skill authoring tool for the agent, and the bundled skill-creator manual
