# @istarry/dsh-assistant-profile

> 标签: JavaScript

## 简介

助理档案：给 DSH 一份全局人格（名称 / 语言 / 人格提示词）与一份长期记忆，每个新会话的系统提示最前面都带着它；聊天里点一下就能把选中的对话提炼进记忆；侧栏「新会话」上方显示助理名；会话行菜单里可以直接删除一个会话（日志、索引、工作区登记一起）
