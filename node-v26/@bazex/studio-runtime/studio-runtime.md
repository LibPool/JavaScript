# @bazex/studio-runtime

> 标签: bazex, headless-cms, iframe, postmessage, react, studio, visual-editor

## 简介

In-iframe runtime for the Bazex visual editor. Mount inside your tenant web app to make tagged DOM nodes editable from admin.bazex.co/content.
