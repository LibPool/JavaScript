# @segmetrics/cli

> 标签: JavaScript

## 简介

Command-line client for SegMetrics reports. Talks to the SegMetrics MCP server, so every tool is available from your terminal or as a local stdio MCP bridge.

## 官网

- 官网：https://docs.segmetrics.io/article/672-mcp-server
- npm 页面：https://www.npmjs.com/package/@segmetrics/cli

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- npm 安装：`npm install @segmetrics/cli`
- npm registry：https://registry.npmjs.org/@segmetrics/cli
- Node 要求：>=20
