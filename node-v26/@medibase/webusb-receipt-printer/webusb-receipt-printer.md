# @medibase/webusb-receipt-printer

> 标签: epson, escpos, receipt, receiptprinter, star, usb, webusb

## 简介

This is a **fork** of [NielsLeenheer/WebUSBReceiptPrinter](https://github.com/NielsLeenheer/WebUSBReceiptPrinter).   It allows you to print to a USB connected receipt printer using WebUSB.
