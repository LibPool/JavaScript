# @kashscript/kash

> 标签: attest, cli, countersign, did, kash, kashscript, npx, offline, station, trust-list

## 简介

@kashscript/kash — the `kash` CLI, the station kit. Makes a station's own keys, issues a cohort record as a file, countersigns it as the station, checks any record offline, and signs a trust list with the publisher key. Local files only: no server, no upl
