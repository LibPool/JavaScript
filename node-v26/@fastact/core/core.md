# @fastact/core

> 标签: app, application, bun, deno, fastact, fastify, framework, http, nodejs, router, web

## 简介

A fantastic, vanilla-flavored web framework core powered by Fastify. Built for JS purists: strictly 0 decorators, 0 reflect-metadata magic, and 100% predictable asynchronous flow.
