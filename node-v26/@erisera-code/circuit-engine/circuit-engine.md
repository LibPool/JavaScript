> 标签: cascade-layers, classless, css, css-functions, css-scope, custom-properties, design-system, design-tokens, headless, light-dark, no-build, semantic-html, zen-garden

## 简介

The erisera design engine: a headless, class-free CSS system that styles bare semantic HTML by element and tree position, with swappable design instances (circuit, jjhub, noitroidvania, snake and more), light-dark tokens, @scope-isolated facets and cascad
