# @ssp1/plugin-eliza

> 标签: agent, eliza, elizaos, plugin, signals, solana, ssp1

## 简介

elizaOS plugin for SSP-1: an agent commits verifiable trading signals to Solana, checks readiness, reads and verifies its record. Add it to a character's plugins
