# @sahilkathpal/aesthetic-hue-bg

> 标签: JavaScript

## 简介

A library to pull the dominant colour from an image and provide aesthetic background and border stroke colours.   Currently intended for creating backgrounds for link previews based on the favicon, this library supports only **png** and **ico** formats.
