# @bakidev/async-caller

> 标签: 429, async, backoff, concurrency, rate-limiting, retry, retry-after, type safety, typescript

## 简介

Async call wrapper with retry, concurrency limiting, and 429/Retry-After rate limiting on top of a token bucket.
