# @itpyx/payload-auto-translate

> 标签: auto-translate, i18n, lexical, libretranslate, localization, payload, payload-plugin, payloadcms, postgresql, seo-slugs, translation

## 简介

High-performance auto-translation plugin for Payload CMS 3.x with LibreTranslate, Lexical Rich Text AST compression, debounced background worker queue, SEO slugification, and direct PostgreSQL bulk crawler.
