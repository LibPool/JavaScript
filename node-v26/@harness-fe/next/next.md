# @harness-fe/next

> 标签: agent, app-router, harness-fe, mcp, next, next.js

## 简介

Next.js integration for Harness-FE. Drop-in <HarnessScript /> server component that loads the runtime client and seeds window config — no webpack hooks, no SWC plugin, works with App Router + Pages Router + webpack + Turbopack.
