# @harness-fe/dev-cli

> 标签: JavaScript

## 简介

Harness-FE solo dev launcher: one command starts the daemon (loopback) + stdio MCP and prints the agent config. Zero-config glue over @harness-fe/daemon + @harness-fe/mcp-server.
