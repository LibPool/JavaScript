# @cup319/mmpl-model

> 标签: ai-agent, bge, embedding, memory, mmpl, onnx, semantic

## 简介

MMPL (Memory Palace) 语义向量模型 — bge-base-zh-v1.5 quantized ONNX (768d) + tokenizer。供 MMPL Rust 版离线部署使用，放到 DATA_DIR/models/ 即可避免首次启动联网下载。
