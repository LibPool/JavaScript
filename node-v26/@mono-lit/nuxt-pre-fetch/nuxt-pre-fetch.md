# @mono-lit/nuxt-pre-fetch

> 标签: csr, nitro, nuxt, nuxt-module, prefetch, spa, useAsyncData, useFetch

## 简介

Nitro-side API prefetching for Nuxt apps with ssr: false — usePreFetch() reuses data embedded in the SPA shell, no duplicate initial request.
