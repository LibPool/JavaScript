# @meta-adapter/engine-adapter

> 标签: JavaScript

## 简介

> Rubeex 脚本, 适用于游戏引擎运行时的组件，用于 `config.json` 中素材信息和游戏引擎内对应素材节点绑定。也提供实时预览功能的基础组件。
