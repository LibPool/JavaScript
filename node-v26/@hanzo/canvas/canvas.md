# @hanzo/canvas

> 标签: canvas, dashboard, deployments, gui, hanzo, hanzo-ai, hanzoai, paas, react, service-map

## 简介

Pannable/zoomable PaaS project canvas — a board of service nodes with live status, metric sparklines, deploy timelines, an environment switcher, and a service detail drawer. Host-agnostic @hanzo/gui React surface, brand/white-label aware, shared by every
