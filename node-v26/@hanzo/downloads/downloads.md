# @hanzo/downloads

> 标签: catalog, download, hanzo, install

## 简介

Canonical Hanzo download + install catalog — the ONE source of truth for every download link (desktop, mobile, browser, editors, CLI, SDKs) and every integration. Data-first, framework-agnostic, api.hanzo.ai-aware.
