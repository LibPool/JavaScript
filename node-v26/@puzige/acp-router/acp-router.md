# @puzige/acp-router

> 标签: acp, agent, coding-agents, mcp, model-context-protocol, router

## 简介

Generic MCP server for routing coding tasks to local ACP agents. Works with any MCP client (Claude Desktop, Cursor, Windsurf, Codex, etc.).
