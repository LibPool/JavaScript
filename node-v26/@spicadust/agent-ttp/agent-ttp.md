# @spicadust/agent-ttp

> 标签: agent, ai, cli, openai, podcast, text-to-speech, tts

## 简介

Render an agent-authored YAML podcast script to a complete MP3 via OpenAI text-to-speech. The agent writes the script; the CLI is a deterministic renderer.
