# @argszero/dsh-mcp-schema-normalizer

> 标签: cordis, deepseek-harness, dsh, gemini, json-schema, mcp, model-context-protocol, plugin, schema-normalization, tools, union-types

## 简介

A tool parameter declared with a type list (["boolean","string"]), an `anyOf` or a `oneOf` is legal JSON Schema, and third-party MCP servers publish them — a code-search server declaring `anyOf [array|string, null]` on its main parameters is the reported
