# @argszero/cordis-plugin-session-model

> 标签: cordis, deepseek-harness, dsh, model, model-selection, plugin, reasoning-effort, session

## 简介

Session-scoped model and effort selection for dsh. Every entry point that names a model for one session also rewrites the deployment default, so a lane cannot launch on a model without re-pointing every later session in the same DSH home: the session mode
