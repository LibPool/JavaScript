# @argszero/cordis-plugin-session-audit

> 标签: audit, cordis, corruption, deepseek, dsh, plugin, session-log

## 简介

Proactive session-log completeness audit for the dsh harness: audit both the plaintext .jsonl and the .jsonl.zstd concatenated-frame container for seq gaps, index-reuse, format-version drift, unknown-required types (hard-fail on reload), empty text blocks
