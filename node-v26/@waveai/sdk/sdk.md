# @waveai/sdk

> 标签: ai-note-taker, api, meetings, sdk, transcription, wave, wave-ai

## 简介

TypeScript client for the Wave AI Developer API (api.wave.co): sessions, transcripts, search, imports, folders, sharing, webhooks.
