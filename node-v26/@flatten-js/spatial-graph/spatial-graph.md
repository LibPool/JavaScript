# @flatten-js/spatial-graph

> 标签: 2d, cad, flatten-js, geometry, gis, graph, graphology, network, pathfinding, polyline, routing, segments, shortest-path, spatial, typescript

## 简介

Build, query and clean 2D line networks: points as nodes, segments as edges. Shortest paths, nearest-edge snapping, edge splitting, merging and network analysis, on graphology and @flatten-js/core.
