# @kvmfleet/mcp

> 标签: claude-desktop, kvm, kvmfleet, mcp, model-context-protocol, pikvm

## 简介

MCP server for KVM Fleet — let an AI assistant read your fleet, audit log, and compliance state and (opt-in) act on it. Includes curated governance prompts. All calls go through the platform REST API, so RBAC, policy, JIT access, and audit apply.
