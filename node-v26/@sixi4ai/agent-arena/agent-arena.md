# @sixi4ai/agent-arena

> 标签: JavaScript

## 简介

agent-arena: evaluate an AI agent against deterministic failure-mode scenarios over REST, WebSocket, MCP or A2A, and get report.json + SARIF. The engine runs in-process; no model runs anywhere in the open core. Published as one self-contained bundle: no r
