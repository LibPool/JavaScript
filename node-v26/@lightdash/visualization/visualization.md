# @lightdash/visualization

> 标签: JavaScript

## 简介

Headless Lightdash chart engine: turns a saved chart's config and query results into ECharts options, table and big number models

## 官网

- 源码仓库：https://github.com/lightdash/lightdash.git
- npm 页面：https://www.npmjs.com/package/@lightdash/visualization
