# medusajs-documents-plugin

> 标签: invoices, medusa, medusa-documents, medusa-documents-v2, medusa-plugin, pdfkit, plugin, zoho-books

## 简介

Comprehensive document generation and management module for Medusa v2 with Zoho Books integration, PDFKit fallback, QR codes, shortlinks, multi-channel notifications and unified admin hub.
