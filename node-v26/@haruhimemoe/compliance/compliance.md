# @haruhimemoe/compliance

> 标签: beatmap, beatmapset, compliance, mappool, osu, osu!, tournament

## 简介

Check osu! beatmapsets against the content rules for officially supported osu! tournaments. A port of hburn7/omc-api's rules, no network and no dependencies.
