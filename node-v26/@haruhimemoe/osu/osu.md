# @haruhimemoe/osu

> 标签: api-client, beatmap, osu, osu!, osu-api, star-rating

## 简介

osu! API v2 for the haruhime.moe tools: beatmap, beatmapset and user shapes with zod schemas (browser-safe at /shapes), and a server client with token caching, a rate-budget hook, beatmaps, beatmapsets and star ratings with mods.
