# @haruhimemoe/harumin-config

> 标签: discord, harumin, osu, zod

## 简介

The settings contract between the harumin osu! Discord bot and harumin.haruhime.moe: guild settings, /track entries, collection names and the bot's service routes, as zod schemas.
