# @weihannpmgo/pi-ask-user-question

> 标签: ask-user-question, pi, pi-extension, pi-package

## 简介

Pi extension. A structured questionnaire the model can put to you when it would otherwise guess — rendered in Pi's editor slot so the transcript stays scrollable while you answer.
