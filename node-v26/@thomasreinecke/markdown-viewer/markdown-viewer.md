# @thomasreinecke/markdown-viewer

> 标签: cli, documentation, local, markdown, toc, viewer

## 简介

A zero-dependency local markdown viewer with a three-pane layout, sticky ToC scrollspy, dark mode, Mermaid support, and syntax highlighting.
