# @bymax-one/nest-core

> 标签: error-envelope, exception-filter, health-check, metrics, nestjs, openapi, opentelemetry, pagination, prometheus, request-timing, swagger, tracing, typescript

## 简介

Zero-dependency NestJS 11 application foundation kit: error-envelope exception filter, request-timing interceptor, pagination helpers, health endpoints with indicator discovery, an optional Prometheus metrics endpoint with a contribution contract, OpenAPI
