# @randan/tg-bot-kit

> 标签: bot, diagnostics, health, nestjs, telegram

## 简介

Shared runtime plumbing for NestJS Telegram bots: env config, /health, /diag, command menu, admin alerts, timeouts, retries, pollers and a watchdog
