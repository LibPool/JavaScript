# @dpk-pagepilot/page-builder

> 标签: drag-and-drop, mui, no-code, page-builder, page-editor, pagepilot, react, visual-editor, wysiwyg

## 简介

Standalone page-type visual editor — drop <PagePilotEditor> into any React app and get Style/Layout/Inspect/Layers panels, drag-and-drop blocks, undo/redo, dirty-tracked save, multi-section pages, and light/dark themes.
