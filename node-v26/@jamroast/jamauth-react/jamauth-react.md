# @jamroast/jamauth-react

> 标签: JavaScript

## 简介

Framework-agnostic React bindings for jamauth — embedded OIDC authorization-code (PKCE) sign-in/sign-up via an iframe bridge, with credentials handled inside the jamauth.net frame.
