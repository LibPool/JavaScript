# @infino-ai/mcp-server

> 标签: agent-memory, ai, bm25, embeddings, hybrid-search, infino, mcp, model-context-protocol, object-storage, parquet, rag, retrieval, s3, search, semantic-search, sql, vector

## 简介

MCP server for Infino — keyword, semantic, hybrid, and SQL retrieval for AI agents: RAG, persistent agent memory, and search over data stored as plain Parquet on object storage. Local embeddings, no API key.
