# @infino-ai/code-context

> 标签: bm25, claude-code, code-search, codebase-context, coding-agent, cursor, grep, hybrid-search, infino, local-first, mcp, model-context-protocol, semantic-search, sql, tree-sitter

## 简介

Local code search for AI coding agents: a CLI and MCP server with hybrid keyword + semantic search and SQL relevance-ranked aggregation over an index that lives in plain files. No accounts, no keys, no server.
