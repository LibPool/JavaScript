# @open-avc/node-red-openavc

> 标签: audio visual, av control, node-red, openavc, room control

## 简介

Node-RED nodes for OpenAVC: read room state and events, send device commands, run macros, write variables, emit events.

- 官网：https://docs.openavc.com/node-red/
