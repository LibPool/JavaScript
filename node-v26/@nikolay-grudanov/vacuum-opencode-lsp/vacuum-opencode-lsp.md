# @nikolay-grudanov/vacuum-opencode-lsp

> 标签: asyncapi, language-server, linting, lsp, openapi, opencode, plugin, rule-scripts, spectral, vacuum

## 简介

LSP wrapper over vacuum CLI for OpenCode (and any LSP client). Provides real-time OpenAPI/AsyncAPI linting diagnostics with custom ruleset support and Node.js plugin script loading for cross-artifact validation.
