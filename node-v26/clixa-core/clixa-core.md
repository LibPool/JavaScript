# clixa-core

> 标签: calculator, clinical, ethiopia, medical, tnm, who-growth-standards

## 简介

Clinical calculation engine: 63 calculators, medical scores and AJCC/FIGO staging, with Ethiopian calendar support. Pure TypeScript, no DOM, no dependencies.
