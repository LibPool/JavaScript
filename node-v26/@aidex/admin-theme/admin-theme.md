# @aidex/admin-theme

> 标签: admin, ai, css, design-tokens, theme

## 简介

Aidex Admin Theme — shared design tokens (CSS custom properties) powering the AI Control Center UI (@aidex/admin-elements, @aidex/admin-react). CSS-first: no components, no framework dependency, no runtime theme manager.
