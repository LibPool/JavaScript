# @wierdbytes/pi-acp

> 标签: acp, agent, agent-client-protocol, buzz, pi

## 简介

ACP (Agent Client Protocol) adapter for the pi coding agent — bridges buzz-acp (JSON-RPC over stdio) to `pi --mode rpc`.
