# @albertomarturelo/nemo-core

> 标签: JavaScript

## 简介

Shared broker-portal domain core (Vector Capital): config, contracts, auth/session, tasks, seams. A Node library; external side-effects (HTTP, token store, clock, audit) are injected via seams (ADR-003).
