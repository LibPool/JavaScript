# @albertomarturelo/cta-cli

> 标签: banco, bank, bci, cartola, chile, cli, read-only

## 简介

CLI to read your own Chilean bank accounts (balances and movements) from the terminal. Each command is a thin call into @albertomarturelo/cta-core tasks (ADR-003).
