# celld-void

> 标签: adapter, celld, cloudflare, durable-objects, void, wasm, workers

## 简介

Void adapter for celld: deploy Void apps on celld with D1, KV, R2, queues, cron, durable objects, workflows, facets, dynamic workers, wasm and containers.
