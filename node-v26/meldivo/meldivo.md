# meldivo

> 标签: ai-coding-assistant, claude-code, cli, coding-agent, developer-tools, hands-free, kokoro, llm, local-ai, offline, opencode, parakeet, pi-coding-agent, privacy, sherpa-onnx, speech-to-text, text-to-speech, voice-assistant, voice-control, voice-mode

## 简介

Always-on local voice hub for coding agents: talk hands-free to your Pi, OpenCode, and Claude Code sessions from any browser or phone. Private on-device speech (Parakeet + Kokoro). No cloud speech APIs.
