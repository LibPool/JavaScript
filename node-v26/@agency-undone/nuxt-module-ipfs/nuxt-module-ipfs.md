# @agency-undone/nuxt-module-ipfs

> 标签: IPFS, Interplanetary File System, Nuxt, NuxtJS

## 简介

A Nuxt module that enables nuxt routing for both the intended path and IPFS gateway URLs, which include a CID (hash)
