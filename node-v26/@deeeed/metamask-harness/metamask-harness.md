# @deeeed/metamask-harness

> 标签: JavaScript

## 简介

One CLI for operating MetaMask Extension, Mobile, and Core and producing reviewable recipe evidence. Run it inside a checkout; the product, slot, ports, and runtime paths are detected automatically.
