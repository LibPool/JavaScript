# @pokemontcgapi/sdk

> 标签: api, card-prices, japanese-cards, pokemon, pokemon-tcg, sdk, tcg, trading-cards

## 简介

TypeScript client for the pokemontcgapi.com Pokémon TCG API: cards, sets, artists, images and prices with stated provenance.
