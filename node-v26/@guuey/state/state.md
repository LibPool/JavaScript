# @guuey/state

> 标签: guuey, key-value, kv, mcp, model-context-protocol, storage

## 简介

Open-source KV client for MCP servers hosted on guuey.com. Scoped per (user, mcp). The MCP stays stateless from its own POV while the user retains data ownership. Hard caps are the product.
