# @vantagecompute/docusaurus-plugin-pydoc

> 标签: autodoc, documentation, docusaurus, docusaurus-plugin, pydoc, python, sdk-reference

## 简介

Docusaurus plugin that auto-generates SDK reference docs from Python docstrings, by parsing source rather than importing it
