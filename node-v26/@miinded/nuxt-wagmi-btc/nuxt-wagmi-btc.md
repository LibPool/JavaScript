# @miinded/nuxt-wagmi-btc

> 标签: bitcoin, leather, magic-eden, nuxt, nuxt-module, ordinals, phantom, psbt, unisat, wagmi, wallet, xverse

## 简介

Nuxt module that connects Bitcoin wallets (Xverse, Leather, Magic Eden, Phantom, Unisat) behind one wagmi-like API: addresses, message and PSBT signing, BTC transfers.
