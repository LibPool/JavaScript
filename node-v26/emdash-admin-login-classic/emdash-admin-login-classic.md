# emdash-admin-login-classic

> 标签: admin, astro, auth, authentication, cloudflare-workers, emdash, emdash-auth, emdash-cms, emdash-plugin, login, password, wordpress

## 简介

Classic email and password sign-in for the EmDash admin, the way WordPress does it. Passkeys and the email link keep working next to it. No public sign-up.
