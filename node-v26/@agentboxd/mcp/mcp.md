# @agentboxd/mcp

> 标签: agent-email, agentboxd, ai-agents, claude, cursor, email, inbox, llm, magic-link, mcp, mcp-server, model-context-protocol, otp, temporary-email, verification-code

## 简介

MCP server for Agentboxd: give Claude, Cursor or any MCP client real email inboxes. Send, reply, wait for mail, read OTP codes and magic links.
