# @inneranimalmedia/agentsam-platform

> 标签: agentsam, capabilities, capacitor, cross-platform, expo, platform-adapter, pwa, tauri

## 简介

Portable AgentSam platform capability contracts: one capability interface for Web/PWA, Capacitor, Expo, and Tauri Mobile hosts. UI asks for capabilities, never for platforms.
