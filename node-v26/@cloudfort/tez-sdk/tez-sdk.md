# @cloudfort/tez-sdk

> 标签: game, multiplayer, netcode, realtime, sdk, tez, udp

## 简介

Blazing-fast realtime client SDK for the Tez UDP engine — for any game (2D, 3D, VR) and any application or service, in Node.js and the browser.
