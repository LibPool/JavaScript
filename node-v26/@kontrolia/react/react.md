# @kontrolia/react

> 标签: auth, authentication, authorization, kontrolia, rbac, react, sdk

## 简介

React bindings for KontrolIA Auth: <AuthProvider>, <AuthGuard>, <GuestGuard>, <RequireRole>, <RequirePermission> and useAuth().
