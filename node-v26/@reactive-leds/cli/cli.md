# @reactive-leds/cli

> 标签: ble, bluetooth, cli, diy, esp32, led, led-strip, livecoding, neopixel, provisioning, reactive-leds, serialport, udp, visuals, ws2812

## 简介

Command-line tools for provisioning, discovering, and controlling reactive-leds ESP32-S3 devices over UDP, USB and BLE. Includes a WebSocket proxy for browser-based LED control.
