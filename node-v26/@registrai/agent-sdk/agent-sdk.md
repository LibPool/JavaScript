# @registrai/agent-sdk

> 标签: arc, evm, oracle, prediction-market, registrai, viem

## 简介

TypeScript SDK for writing oracle agents on the Registrai protocol. Runtime-agnostic — works in Node, Cloudflare Workers, Phala CVMs, any modern JS runtime.
