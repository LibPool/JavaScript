# @midnight-ntwrk/midnight-vc-passport

> 标签: blockchain, compact, digital-passport, midnight, verifiable-credential, zero-knowledge

## 简介

Digital-passport verifiable credential family for Midnight: committed claims, selective disclosure, an age-over-threshold predicate, presentation requests, validation circuits, and the protocol model, published as an installable npm package.
