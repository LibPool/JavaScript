# @yak/react

> 标签: css-in-js, next.js, react, styled-components, typescript

## 简介

@yak/react is a CSS-in-JS library for React: styled-components syntax with CSS extracted at build time. Works with Next.js, Vite and Rsbuild.

- 源码仓库：https://github.com/galaxuslabs/yak.git
