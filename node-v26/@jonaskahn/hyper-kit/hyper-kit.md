# @jonaskahn/hyper-kit

> 标签: all-in-one, glass, hyper, hyper-plugin, osc7, productivity, tab, tabbar, theme

## 简介

All-in-one power-up cartridge for Hyper Terminal: vertical tab bar, neon accents, command status badges, live PWD tracking, tool inventory panel, drag & drop reorder, and a deep-dark backdrop — every feature toggled on/off from config
