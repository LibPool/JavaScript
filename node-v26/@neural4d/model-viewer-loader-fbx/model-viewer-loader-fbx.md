# @neural4d/model-viewer-loader-fbx

> 标签: JavaScript

## 简介

The FBX `ModelLoader` for Neural4D Model Viewer. It uses the official Three.js `FBXLoader` while delegating external texture transport to Core `ResourceProvider` and `assets-required` resolution.
