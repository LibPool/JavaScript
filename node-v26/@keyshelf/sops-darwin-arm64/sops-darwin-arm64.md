# @keyshelf/sops-darwin-arm64

> 标签: JavaScript

## 简介

The sops 3.13.1 binary for darwin/arm64, bundled for keyshelf. Installed automatically as a platform-specific optional dependency of keyshelf; not intended for direct use.
