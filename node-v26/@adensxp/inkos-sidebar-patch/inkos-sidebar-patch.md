# @adensxp/inkos-sidebar-patch

> 标签: inkos, novel, patch, sidebar, writing

## 简介

InkOS Studio 右侧边栏增强补丁：独立栏目卡片（审稿报告/细纲/场景/大纲/卷纲）+ 事件结构等文件注册。幂等，inkos 升级后可重跑。
