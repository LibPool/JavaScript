# @hecto/assistant

> 标签: JavaScript

## 简介

Framework-free runtime, message, transport, adapter, tool, and generative-UI contracts for Hecto's AI Assistant. Every declared public subpath resolves to its documented runtime names; framework rendering remains outside this package.
