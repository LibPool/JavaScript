# @mcp-registry/mns-mcp-server

> 标签: JavaScript

## 简介

MNS MCP Manager 是一个基于阿里云消息服务（MNS）的管理工具。通过 MCP 框架实现，用户可以通过 MCP Host 配置文件轻松集成并使用。
