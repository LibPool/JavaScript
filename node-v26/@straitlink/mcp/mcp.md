# @straitlink/mcp

> 标签: analytics, app-links, deep-linking, mcp, model-context-protocol, strait, universal-links

## 简介

Strait MCP server: create, inspect and deactivate deep links, read analytics, usage and referrals, check and redeliver webhooks, check App Links / Universal Links files and search the docs from AI tools.
