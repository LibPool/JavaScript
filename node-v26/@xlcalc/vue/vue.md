# @xlcalc/vue

> 标签: excel, formula, grid, sheet, spreadsheet, vue, vue3, workbook, xlcalc, xlsx

## 简介

Vue 3 sheet component for xlcalc workbooks: a windowed grid with styles, formulas and editing over a pluggable sheet source
