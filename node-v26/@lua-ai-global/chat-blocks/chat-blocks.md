# @lua-ai-global/chat-blocks

> 标签: agent, ai, chat, forms, heylua, lua

## 简介

The contract for Lua `:::` chat blocks: what an agent may write and how every chat surface reads it. Starts with the `::: form` engine (Lua Form v1).
