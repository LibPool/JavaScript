# @edgecasehuman/droidsight

> 标签: adb, android, automation, llm, mcp, modelcontextprotocol

## 简介

An MCP server that drives a real Android device over ADB, with a continuous H.264 screen stream so screenshots return from cache instead of a fresh capture.
