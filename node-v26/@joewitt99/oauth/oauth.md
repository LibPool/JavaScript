# @joewitt99/oauth

> 标签: JavaScript

## 简介

Library for interacting with OAuth 1.0, 1.0A, 2 and Echo.  Provides simplified client access and allows for construction of more complex apis and OAuth providers.  With added support to have clientid and clientsecret bound during runtime
