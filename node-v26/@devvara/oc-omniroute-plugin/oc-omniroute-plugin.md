# @devvara/oc-omniroute-plugin

> 标签: ai-agent, ai-gateway, ai-sdk, catalog, coding-agent, model-router, omniroute, openai-compatible, opencode, opencode-plugin, opencode-v2, provider, web-fetch, web-search

## 简介

Independent OpenCode V2 plugin that connects OmniRoute as a custom provider and optionally routes native web search/fetch through OmniRoute REST.
