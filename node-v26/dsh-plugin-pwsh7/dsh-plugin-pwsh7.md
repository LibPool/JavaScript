# dsh-plugin-pwsh7

> 标签: deepseek-harness, dsh-plugin, powershell, powershell-7, pwsh, sandbox, shell, windows

## 简介

Windows DeepSeek Harness bundle that routes the pwsh tool to PowerShell 7, with a Settings page (install status, self-check, route switch, uninstall, system migration), user/system installation and PATH configuration, a Web setup dialog with live download
