# @crossbind/port-sqlite3-wasi

> 标签: crossbind, crossbind-package, database, libsqlite3, sql, sqlite, sqlite3, wasi, webassembly

## 简介

WASI build of the precompiled SQLite3 database engine, built with crossbind. Use it together with the main package @crossbind/port-sqlite3.
