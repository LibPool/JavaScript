# @crossbind/port-expat-wasm

> 标签: crossbind, crossbind-package, expat, libexpat, wasm, webassembly, xml

## 简介

WebAssembly build of the precompiled Expat XML parser library, built with crossbind. Use it together with the main package @crossbind/port-expat.
