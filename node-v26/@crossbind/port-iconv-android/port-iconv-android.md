# @crossbind/port-iconv-android

> 标签: android, charset, crossbind, crossbind-package, encoding, iconv, libiconv, react-native

## 简介

Android build of the precompiled libiconv character-encoding library, built with crossbind. Use it together with the main package @crossbind/port-iconv.
