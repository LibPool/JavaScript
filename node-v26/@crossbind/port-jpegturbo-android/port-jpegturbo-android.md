# @crossbind/port-jpegturbo-android

> 标签: android, crossbind, crossbind-package, image, jpeg, jpegturbo, libjpeg-turbo, react-native

## 简介

Android build of the precompiled libjpeg-turbo (JPEG) library, built with crossbind. Use it together with the main package @crossbind/port-jpegturbo.
