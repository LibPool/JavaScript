# @crossbind/port-lerc

> 标签: android, crossbind, crossbind-package, ios, lerc, libLerc, raster-compression, react-native, wasm, webassembly

## 简介

This package provides the LERC (Limited Error Raster Compression) library compiled with crossbind, enabling seamless usage of LERC raster compression in JavaScript, WebAssembly and React Native projects.
