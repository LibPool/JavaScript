# @crossbind/port-proj-ios

> 标签: crossbind, crossbind-package, gis, ios, libproj, proj, projection, react-native

## 简介

iOS build of the precompiled PROJ coordinate-transformation library, built with crossbind. Use it together with the main package @crossbind/port-proj.
