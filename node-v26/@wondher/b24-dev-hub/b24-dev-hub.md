# @wondher/b24-dev-hub

> 标签: bitrix24, developer-tools, mcp, model-context-protocol, rest-api, sdk

## 简介

MCP server for the Bitrix24 Developer Hub — intelligent search across SDKs, UI components, REST API docs, examples, and templates. Runs over stdio; clones its content cache on first use so `npx @wondher/b24-dev-hub` works anywhere.
