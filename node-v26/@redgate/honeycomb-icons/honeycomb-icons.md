# @redgate/honeycomb-icons

> 标签: JavaScript

## 简介

This package contains the [Honeycomb icons](https://honeycomb.red-gate.com/ui/library/elements/icons), packaged as Material UI [`SvgIcon`](https://mui.com/api/svg-icon/) components.
