# @customyai/sdk

> 标签: customy, machine-tokens, platform, sdk, server

## 简介

The whole Customy platform with one app identity: createCustomy() reads the environment discovery, holds the app's machine tokens and composes Access, Data, Send, Billing, Links, Provisioning and CRM People (plus any discovered product), and emits connect
