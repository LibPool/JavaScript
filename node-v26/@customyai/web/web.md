# @customyai/web

> 标签: auth, cookies, customy, edge, sdk, session, web

## 简介

Customy same-origin session handlers over the standard Request and Response: auth proxy, social sign-in, sign-out, impersonation callback, server session, route protection, cookie names and local session token verification. Node and edge; never in a brows
