# @customyai/embed

> 标签: canary, csp, customy, ed25519, embed, loader, release-train, sri

## 简介

Customy embed loader: a tiny, near-immutable client that fetches a signed manifest, verifies its Ed25519 signature, picks the runtime for the site's release train (canary rollout, kill switch, anti-replay revision) and mounts it with SRI, degrading to las
