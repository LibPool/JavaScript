# @danolekh/gl

> 标签: glsl, shader, shadertoy, webgl, webgl2

## 简介

One WebGL2 context and one animation frame for every live shader on the page: GLSL, Shadertoy and twigl definitions, typed parameters, live inputs, off-screen pausing, adaptive resolution and context-loss recovery. Framework-free.
