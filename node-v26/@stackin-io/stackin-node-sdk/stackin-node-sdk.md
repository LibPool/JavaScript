# @stackin-io/stackin-node-sdk

> 标签: api-client, brasil, brazil, fatura, fiscal, invoice, nf-e, nfe, nfs-e, nfse, nodejs, nota-fiscal, nota-fiscal-eletronica, sdk, sefaz, stackin, typescript

## 简介

Node/TypeScript SDK for stackin — issue, consult and cancel Brazilian fiscal documents (NF-e, NFS-e) via a single Invoice client. No certificates, XML or SOAP.
