# mc-modpack-mcp

> 标签: diagnostics, fabric, forge, mcp, minecraft, model-context-protocol, modpack, pcl

## 简介

MCP server for Minecraft modpack diagnostics. Supports Fabric/Forge mod conflicts, dependency checks, crash analysis, and log parsing.
