# @moxo/sdk

> 标签: api-client, client-portal, embed, embeddable, headless, iframe, moxo, sdk, typescript, workflow

## 简介

Official Moxo Web SDK — embed Moxo flows, tasks, and full portal views inside your app. Auth via short-lived session JWTs minted by your backend.
