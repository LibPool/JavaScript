# @umbra-privacy/store-web

> 标签: JavaScript

## 简介

Persistent storage for a browser wallet: a record store for small structured values and a blob store for large binary ones, over IndexedDB. Data and free functions, no classes. Pre-release (0.x): every API, type and behaviour is subject to change at any t
