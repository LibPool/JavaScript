# @dagstack/plugin-system

> 标签: dagstack, extension, framework, plugin, plugins

## 简介

TypeScript / Node.js implementation of dagstack/plugin-system — orchestration-neutral plugin registry with manifest-driven discovery and a single contract across Python, TypeScript, and Go.
