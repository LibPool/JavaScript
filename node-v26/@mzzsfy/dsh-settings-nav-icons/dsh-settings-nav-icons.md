# @mzzsfy/dsh-settings-nav-icons

> 标签: JavaScript

## 简介

设置弹窗导航分区与插件市场卡片图标替换:按分区显示文本把回退齿轮换成专属图形,市场卡片头像槽换成插件图标,DOM 观察实现,卸载后重载页面恢复官方图标
