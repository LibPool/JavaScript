# @mzzsfy/dsh-shell-select

> 标签: JavaScript

## 简介

Windows shell 接管:替换默认 pwsh 工具为可配置多客户端的 shell 工具(git bash/WSL/cmd/pwsh,自定义路径,默认客户端,模型按名选择)
