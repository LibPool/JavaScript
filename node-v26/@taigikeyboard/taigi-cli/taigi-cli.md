# @taigikeyboard/taigi-cli

> 标签: braille, cli, converter, pe̍h-ōe-jī, phonetic, poj, taigi, taiwanese, tâi-lô, tl, tps

## 简介

Bidirectional converter between Taiwanese phonetic systems: TL (Tai-lo), POJ (Pe-oh-e-ji), TPS (方音符號), and Taiwanese braille, with tone mark / tone number conversion
