# @opencookies/vite

> 标签: JavaScript

## 简介

Vite plugin for OpenCookies. Runs `@opencookies/scanner` against your source on dev start and on every HMR update, and surfaces ungated cookie writes / vendor calls as Vite warnings — or build failures.
