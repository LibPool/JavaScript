# @crossly/buyer-mcp

> 标签: ai-agent, buyer, cart, cashback, claude, crossly, mcp, model-context-protocol, shopping

## 简介

Model Context Protocol server for the Crossly Buyer API — lets an AI agent manage a shopper's cart, orders, wishlists, offers and cashback.
