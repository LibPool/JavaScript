# @thebookdex/mcp

> 标签: agent, mcp, model-context-protocol, skill, thebook, tools, trading, vara

## 简介

MCP server (skill pack) that lets any AI agent trade thebookdex: the non-custodial spot CLOB over real bridged tokens on Vara mainnet, exposed as tools.
