# @hzblj/expo-translation

> 标签: android, expo, expo-module, i18n, ios, language-detection, language-identification, mlkit, offline, on-device, react-native, translate, translation

## 简介

On-device translation for Expo on the platforms' own engines: Apple's Translation framework on iOS (with Google's ML Kit for the languages it lacks, when you turn it on) and ML Kit on Android. Language checks and downloads, language identification, batche
