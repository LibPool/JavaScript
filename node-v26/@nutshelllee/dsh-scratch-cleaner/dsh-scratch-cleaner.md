# @nutshelllee/dsh-scratch-cleaner

> 标签: cleanup, deepseek-harness, dsh, dsh-plugin, scratch, temporary-files

## 简介

DSH host plugin: confines agent scratch scripts to one directory per working directory, and deletes them when each turn ends.
