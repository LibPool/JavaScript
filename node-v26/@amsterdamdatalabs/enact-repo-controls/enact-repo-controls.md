# @amsterdamdatalabs/enact-repo-controls

> 标签: JavaScript

## 简介

Repo-local git workflow conventions (enact-m5 git hooks, commit rules, coverage ratchet, push checks, CI scripts) installed into a repository via core.hooksPath.
