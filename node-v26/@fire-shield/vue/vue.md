# @fire-shield/vue

> 标签: access-control, authorization, caching, composables, deny, directives, fire-shield, guards, plugin, rbac, vue, wildcards

## 简介

Vue adapter for RBAC authorization with composables, directives, and router guards. Features: Plugin system, Advanced audit logging (3 types), Wildcards, Deny permissions, Permission caching, Lazy roles, Memory optimization, RBACAggregator support
