# @usefy/signature-pad

> 标签: bezier, canvas, drawing, e-signature, headless, ink, pointer-events, react, signature, signature-pad

## 简介

Electronic signature pad for React — hand-written ink engine with Bézier smoothing and velocity/pressure-based variable stroke width, undo/redo history, and a zero-dependency headless core
