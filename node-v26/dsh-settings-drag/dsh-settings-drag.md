# dsh-settings-drag

> 标签: deepseek-harness, drag, dsh, dsh-plugin, resize, settings

## 简介

DSH Web 设置面板自由拖动 + 缩放:导航/标题条拖动,右下角握角与右/底边缘缩放,双击归位,位置与尺寸本地记忆。
