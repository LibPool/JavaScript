# @a.nemreen/a11y

> 标签: a11y, accessibility, angular, browser, control-panel, dashboard, frontend, react, typescript, vanilla, vue, wcag, widget, zero-dependency

## 简介

Framework-agnostic accessibility tools widget — profiles, readable experience, visual filters, optional self-hosted dashboard. Works with Angular, React, Vue, and plain HTML.
