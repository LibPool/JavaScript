# @akhatmirzo/ui

> 标签: a11y, accessible, component-library, components, dark-mode, datatable, datepicker, design-system, forms, headless, radix, radix-ui, react, react-components, tailwind, tailwind-v4, tailwindcss, typescript, ui, ui-library, uzbek, uzbekistan

## 简介

Accessible React UI components built on Tailwind CSS v4 and Radix UI: forms, overlays, DataTable, DatePicker, dark mode and Uzbek-ready inputs (phone, card, so'm).
