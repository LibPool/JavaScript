# @openlinkos/ui

> 标签: css, design-system, lucide, openlinkos

## 简介

The OpenLinkOS design system for apps: DTCG design tokens, framework-free CSS for layout and components (per brand, light and dark, accessible by test), and a curated Lucide icon set.
