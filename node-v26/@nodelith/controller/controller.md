# @nodelith/controller

> 标签: controller, javascript, node, typescript

## 简介

Metadata utilities and decorators for building typed HTTP controllers in the Nodelith stack. Works alongside `@nodelith/http` for status/method enums and integrates with `@nodelith/injection` for easy dependency injection composition.
