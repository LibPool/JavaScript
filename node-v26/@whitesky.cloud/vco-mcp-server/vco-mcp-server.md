# @whitesky.cloud/vco-mcp-server

> 标签: agent, claude, cloud, gig, iaas, infrastructure, mcp, mcp-server, model-context-protocol, vco, whitesky

## 简介

MCP server that lets an AI agent manage whitesky.cloud / GIG Cloud customer infrastructure: cloudspaces, VMs, disks, object storage, ingress, DNS and networking. 124 tools; reads are auto-approvable, every change goes through your client’s approval.
