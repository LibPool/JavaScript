# @scrapingisnotacrime/mcp

> 标签: ai-agents, bluesky, github, hackernews, instagram, mcp, model-context-protocol, scraping, tiktok

## 简介

MCP server for the ScrapingIsNotACrime public data API — lets AI agents read Instagram, TikTok, YouTube, GitHub, Hacker News, Bluesky, Twitch, App Store and Linktree data.
