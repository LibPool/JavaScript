# goyondo-mcp

> 标签: ai-agents, goyondo, itinerary, mcp, model-context-protocol, travel, trip-planning

## 简介

MCP server for Goyondo: lets Claude, Codex, Cursor and other MCP clients plan and edit persistent trips, with device-flow sign-in.
