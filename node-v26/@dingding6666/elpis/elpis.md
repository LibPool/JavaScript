# @dingding6666/elpis

> 标签: JavaScript

## 简介

Elpis 是一个基于 Koa 的企业级应用开发框架，同时提供 Vue 3 + Webpack 前端构建能力。 框架会自动加载业务项目中的控制器、服务、路由、路由参数校验、扩展和环境配置，适合快速搭建前后端一体化应用。
