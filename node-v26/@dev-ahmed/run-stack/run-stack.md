# @dev-ahmed/run-stack

> 标签: docker, docker-compose, expo, laravel, local-development, monorepo, vite

## 简介

One command to boot a full local stack in Docker: API, Vite apps, Expo mobile, desktop renderer, database, mail and a status dashboard.
