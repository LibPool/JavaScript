# @okent/accessibility-scanner-keyboard-plugin

> 标签: a11y, accessibility, accessibility-scanner, keyboard, playwright, wcag

## 简介

Keyboard probe plugin for github/accessibility-scanner: focus traps, unreachable controls, removed focus indicators, and focus-order divergence, found by walking the real Tab order.
