# @chartdown/core

> 标签: battlemap, chartdown, hexcrawl, map, markdown, parser, plain-text, ttrpg

## 简介

Chartdown parser and AST — a plain-text, Markdown-inspired language for TTRPG maps. Runtime-dependency-free by rule (ADR 0007).
