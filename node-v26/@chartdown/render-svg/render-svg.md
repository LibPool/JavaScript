# @chartdown/render-svg

> 标签: battlemap, chartdown, hexcrawl, map, renderer, svg, ttrpg

## 简介

Chartdown SVG renderer — deterministic, seeded, themeable rendering of plain-text TTRPG maps. Runtime-dependency-free beyond @chartdown/core (ADR 0007).
