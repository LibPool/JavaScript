# @llhe/tiny

> 标签: JavaScript

## 简介

图片压缩 ## 使用 1. 安装 ``` npm i img-tiny -g ``` 2. 查看版本 ``` tiny --version  // or tiny -v ``` 3. 压缩目录下所有图片【支持jpg|jpeg|png格式】 ``` tiny ``` 4. 压缩目录下指定图片 ``` tiny --imgs a.png // 简写 tiny -i a.png ```
