# dsh-web-service

> 标签: api, deepseek-harness, dsh, dsh-plugin, openai-compatible, remote, rest, sse, web-service

## 简介

Expose DSH over HTTP: 60 REST + SSE routes for workspaces, sessions (streaming, history, stats, todos, cancel), models, settings, API keys, skills and files, plus an OpenAI-compatible /chat/completions and an API Key settings page. · 把 DSH 的能力开放成 REST + S
