# @supersuit/hypercontext-core

> 标签: frontmatter, hypercontext, manifest, markdown, records, self-documenting, supersuit, yaml

## 简介

What every hypercontext record package shares, in one copy: the YAML header codec, the versioned-standard rule and its byte-preserving stamp, and the validator for a standard's manifest.
