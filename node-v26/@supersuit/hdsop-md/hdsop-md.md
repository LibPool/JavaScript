# @supersuit/hdsop-md

> 标签: agents, catalog, frontmatter, hdsop, hypercontext, markdown, records, sop, workflow

## 简介

The written standard for a workflows folder: each workflow map (an HDSOP) and the catalog that scores them, with a checker and a byte-preserving stamp.
