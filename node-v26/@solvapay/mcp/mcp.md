# @solvapay/mcp

> 标签: JavaScript

## 简介

Official @modelcontextprotocol/server adapter for the SolvaPay MCP toolbox (createSolvaPayMcpServer, registerPayableTool) with ./fetch + ./express subpath exports for runtime-specific OAuth bridges.
