# @ora-ai/webmcp-bridge

> 标签: agent-ready, bridge, browser-agents, mcp, model-context, ora, webmcp

## 简介

Bridge a remote MCP server into the page: discover its tools and register them on document.modelContext for in-browser AI agents.
