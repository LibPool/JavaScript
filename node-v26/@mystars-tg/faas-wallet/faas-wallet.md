# @mystars-tg/faas-wallet

> 标签: faas, mystars, payments, stars, telegram, ton, usdt, wallet

## 简介

Opt-in TON wallet + payer for @mystars-tg/faas-sdk — generate/import a wallet and pay a FaaS order invoice — GRAM (ex TON) or USDT (TON) — from your OWN wallet. Node only. Holds keys only in memory; never persists/logs/transmits them.
