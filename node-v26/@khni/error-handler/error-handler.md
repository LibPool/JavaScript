# @khni/error-handler

> 标签: custom-error, error-handler, error-handling, error-serialization, express, http-error, middleware, nodejs, typescript, validation

## 简介

@khni/error-handler is a modular, extensible error handling system for Node.js and TypeScript with custom errors, HTTP errors, serializers, handlers, and mappers.
