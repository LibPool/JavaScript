# @mark1russell7/client-docker

> 标签: automation, containers, devops, docker, docker-compose, procedures

## 简介

Docker and Docker Compose as typed procedures: ps, run, exec, logs (streaming), build, pull, stop, rm, compose up and down, run with argv and no shell injection.
