# @symbo.ls/sdk-bridge-governance

> 标签: JavaScript

## 简介

Governance project glue on top of @symbo.ls/sdk-supabase-bridge — wires PROJECT_GOVERNANCE + PROJECT_FINANCIALS registries, integrations catalog, MCP connectors, prefs, cross-app auth peer routing. Consumed by the workspace app + financials extensions.
