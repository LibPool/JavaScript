# @symbo.ls/analyzing

> 标签: JavaScript

## 简介

Browser-side observability SDK for DOMQL apps — pipes @symbo.ls/analyze events (errors, console, network, perf, lifecycle, state) to the analyzed worker. Faro-compatible manual API (captureError / captureMessage / identify / setContext / addMeasurement).
