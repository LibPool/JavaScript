# @xcwds/plugin-timers

> 标签: countdown, offline-first, pwa, timer, xcwds, xcwds-plugin

## 简介

Timers for @xcwds apps that count against wall-clock end times, so they survive a backgrounded tab and a reload, ring on every page and hold off app updates while running.

- 源码仓库：git+https://github.com/xcwds/xcwds.git
