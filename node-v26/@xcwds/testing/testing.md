# @xcwds/testing

> 标签: playwright, pwa, testing, vitest, xcwds

## 简介

Test an @xcwds app and its plugins: a Vitest kit (test app, fake clock, simulated tabs, worker hooks) and Playwright helpers (hydration, tap targets, a GitHub Pages-like server, fake deploys, a config preset).
