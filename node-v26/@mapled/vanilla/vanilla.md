# @mapled/vanilla

> 标签: cms, headless-cms, html, mapled, script-tag, static-site, vanilla-js

## 简介

The browser runtime of Mapled, the hosted headless CMS for sites built with AI — published content in a plain HTML site: one script tag and data-mapled attributes, no framework and no build step.
