# @rawrus-cdk/fargate

> 标签: JavaScript

## 简介

You should explore the contents of this project. It demonstrates a CDK Construct Library that includes a construct (`FargateConstruct`) which contains an Amazon SQS queue that is subscribed to an Amazon SNS topic.
