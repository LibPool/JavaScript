# @eui/eds-shared

> 标签: JavaScript

## 简介

EDS Shared — framework-agnostic pure-TypeScript primitives (types, unions, constants, helpers) shared across the @eui/eds Angular, @eui/eds-react and @eui/eds-wc projections. No framework dependency.
