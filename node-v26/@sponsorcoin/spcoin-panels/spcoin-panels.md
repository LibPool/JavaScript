# @sponsorcoin/spcoin-panels

> 标签: JavaScript

## 简介

Merit Wallet's independent panel-visibility engine (single write chokepoint, no ExchangeContext dependency) — shared between spcoin-nextjs-front-end and the Merit Wallet browser extension (spCoinExtension).
