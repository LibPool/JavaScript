# @asnl/kotlin

> 标签: browser, compiler, javascript, kotlin, kotlin.js, script, transpiler

## 简介

Write a subset of Kotlin in <script type="text/kotlin"> tags or .js files and run it directly in the browser — no build step, no compiler install.
