# @uk-energy/core

> 标签: elexon, energy, http, neso, rate-limit, sdk, uk

## 简介

Shared HTTP layer for the uk-energy SDKs: retries with jittered backoff, per-host rate limiting, pagination iterators, pluggable cache, recorded-fixture fetch for tests.
