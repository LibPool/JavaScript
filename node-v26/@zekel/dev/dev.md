# @zekel/dev

> 标签: JavaScript

## 简介

Tools for building and checking a game for the Zekel MCP server: AI-vs-AI batches and balance analysis, the desync, relay, assistant and integration bots, the rules checker, and the spoken-text and choice-catalog checks.
