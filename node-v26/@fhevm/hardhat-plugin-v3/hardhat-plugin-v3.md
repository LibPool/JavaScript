# @fhevm/hardhat-plugin-v3

> 标签: JavaScript

## 简介

FHEVM plugin for Hardhat 3: a cleartext FHEVM stack on every development connection, encryption, public and user decryption, error diagnostics, HCU accounting and the fhevm tasks.
