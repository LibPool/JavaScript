# @agentruntimecontrolprotocol/node

> 标签: JavaScript

## 简介

Node.js HTTP server integration for the ARCP WebSocket transport. Wires the WS upgrade handshake onto an existing `http.Server` with Host-header DNS-rebinding protection.
