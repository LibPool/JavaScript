# @agentruntimecontrolprotocol/bun

> 标签: JavaScript

## 简介

Bun runtime helpers for the Agent Runtime Control Protocol (ARCP). Uses Bun's native WebSocket server (Bun.serve) to terminate ARCP connections; no external dependency on `ws`.
