# @schedjs/daemon

> 标签: background-jobs, cron, daemon, docker, http-runner, job-queue, job-scheduler, nodejs, queue, scheduler, self-hosted, sqlite, task-scheduler, typescript

## 简介

Self-hosted cron scheduler daemon for Node.js — SQLite + HTTP runner + tasks.json in one process (binary schedd)
