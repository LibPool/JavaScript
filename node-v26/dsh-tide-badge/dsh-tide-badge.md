# dsh-tide-badge

> 标签: balance, billing, composer, deepseek-harness, dsh, dsh-plugin, holiday, off-peak, peak, valley, 余额, 峰谷, 计费

## 简介

DSH 输入框下方的计费时段与余额药丸：常显账户余额与本次对话花费（余额差值记账）、峰价/谷价（含中国法定节假日与周末规则）、下一次切换倒计时（桌面端账号登录态优先，API Key 兜底）。
