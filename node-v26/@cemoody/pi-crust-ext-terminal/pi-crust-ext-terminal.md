# @cemoody/pi-crust-ext-terminal

> 标签: pi-crust, pi-crust-extension, pi.dev, pty, terminal

## 简介

Browser terminal (PTY) for pi-crust, as a sidebar activity view. Streams a real shell over the realtime gateway.
