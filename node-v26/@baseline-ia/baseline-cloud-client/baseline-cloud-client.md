# @baseline-ia/baseline-cloud-client

> 标签: baseline, baseline-cloud, claude-code, cli, kiro, opencode, plugin, telemetry

## 简介

Optional addon — connects any CLI to a self-hosted baseline-cloud instance for telemetry, openspec lifecycle tracking, and post-commit git hooks.
