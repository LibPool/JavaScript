# cueflick

> 标签: agents-md, ai, ai-agents, animation, camera, claude, codex, copilot, cursor, custom-element, demo, explainer, gemini, llm, motion-graphics, product-film, saas, video, walkthrough, web-component

## 简介

Cueflick: product films for software, written as data. One JSON clip describes app screens, a directed camera, and motion-graphics characters; Cueflick plays it in any web page or records it to video. Any AI agent can write one.
