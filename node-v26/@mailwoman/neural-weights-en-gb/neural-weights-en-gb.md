# @mailwoman/neural-weights-en-gb

> 标签: JavaScript

## 简介

Mailwoman neural-classifier weights for locale 'en-gb'. Data-only overlay — shares the base model.onnx + tokenizer.model from @mailwoman/neural-weights-en-us (they are byte-identical); ships only the gb-specific data siblings — pair-index-gb.bin and postc
