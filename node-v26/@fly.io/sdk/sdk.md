# @fly.io/sdk

> 标签: api, client, fly, fly.io, machines

## 简介

TypeScript client for the Fly Machines REST and GraphQL APIs. Vendored fork of supabase/fly-admin with native fetch, exec, releaseLease, and metadata support.
