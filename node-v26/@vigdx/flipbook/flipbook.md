# @vigdx/flipbook

> 标签: angular, flipbook, page-flip, pdf, pdf-viewer, pdfjs, viewer

## 简介

Angular PDF flipbook viewer with page-curl animation, tiled rendering, zoom, search and virtualized spreads, built on pdf.js
