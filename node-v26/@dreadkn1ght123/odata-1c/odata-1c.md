# @dreadkn1ght123/odata-1c

> 标签: JavaScript

## 简介

Storage-agnostic toolkit for extracting raw data from 1C OData endpoints: discovery, SSRF-guarded origin-pinned fetching, cursor/offset pagination, retry, $expand flattening, and DataVersion change-token tracking.
