# @talocode/maillane

> 标签: cli, email, gmail, maillane, mcp, oauth, sdk, smtp, talocode

## 简介

Gmail OAuth email API — send transactional emails from any hosting, no SMTP ports needed. CLI, SDK, MCP server, and REST API included.
