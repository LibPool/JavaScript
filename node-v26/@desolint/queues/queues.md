# @desolint/queues

> 标签: bullmq, queue, redis, worker

## 简介

Generic BullMQ queue/worker factory with a lazy-loaded worker registry and graceful shutdown. No root export — import only what you need: @desolint/queues/config, /services, /lifecycle.
