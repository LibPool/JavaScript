# @uptimizr/mcp

> 标签: 3d, agent, ai, analytics, mcp, model-context-protocol, uptimizr

## 简介

Read-only Model Context Protocol (MCP) server over an Uptimizr collector's query API — let an agent ask questions of your own 3D analytics, on your own infrastructure.
