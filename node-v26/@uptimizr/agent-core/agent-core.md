# @uptimizr/agent-core

> 标签: 3d, agent, ai, analytics, llm, mcp, tool-calling, uptimizr

## 简介

Framework-agnostic, browser-safe core for Uptimizr analytics agents — the single read-only tool catalog over the collector query API, a headless LLM provider-adapter interface, and the tool-calling loop.
