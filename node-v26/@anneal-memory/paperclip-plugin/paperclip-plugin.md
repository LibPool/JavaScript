# @anneal-memory/paperclip-plugin

> 标签: ai-agents, anneal-memory, mcp, memory, paperclip, paperclip-plugin

## 简介

anneal-memory as a Paperclip plugin — first-class four-layer memory (episodic + continuity + Hebbian + limbic) with immune system. Wraps the anneal-memory Python MCP server as a per-agent subprocess.
