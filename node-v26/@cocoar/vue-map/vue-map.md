# @cocoar/vue-map

> 标签: geo, leaflet, map, vue, vue3

## 简介

Interactive Leaflet map component for Vue 3. Data-driven and standalone — it knows nothing about markdown or any embedding layer; a consumer feeds it resolved map data.
