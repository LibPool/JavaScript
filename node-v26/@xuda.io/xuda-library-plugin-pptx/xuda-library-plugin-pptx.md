# @xuda.io/xuda-library-plugin-pptx

> 标签: ai, office, plugin, powerpoint, pptx, presentation, slides, xuda

## 简介

Create and edit PowerPoint presentations (.pptx) from a prompt or a structured deck spec, with AI generated pictures embedded, and read existing decks back as an outline
