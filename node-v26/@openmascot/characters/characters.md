# @openmascot/characters

> 标签: animation, character, clips, dance, emotes, mascot, openmascot, pseudo-3d, rigging, svg

## 简介

Ready-made OpenMascot characters (Echo, Pip, Riff) and the shared clip library. Import one character per subpath to keep bundles small.
