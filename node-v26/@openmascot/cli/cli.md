# @openmascot/cli

> 标签: animation, character, cli, frame-sheet, mascot, openmascot, pseudo-3d, resvg, rigging, svg

## 简介

OpenMascot command line: validate rigs, lint clips, render frames and build frame sheets (contact sheets) for reviewing animations.
