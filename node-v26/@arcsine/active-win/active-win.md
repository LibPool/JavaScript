# @arcsine/active-win

> 标签: active, app, application, bounds, bundleid, capture, current, focused, id, linux, macos, memory, metadata, name, pid, screenshot, title, usage, win, window, windows, x11

## 简介

Get metadata about the active window (title, id, bounds, screens, owner, etc). Works on macOS, X11-based Desktops (Linux, BSD), Windows.
