# @enigmax/dashboard

> 标签: assets, dashboard, enigma, savings, tokens, ui

## 简介

Local browser dashboard UI for enigma: the static page and chart assets enigma serves on its loopback dashboard (savings, real tool usage, in-browser settings). Installed on demand by enigma-cli; not a runtime dependency.
