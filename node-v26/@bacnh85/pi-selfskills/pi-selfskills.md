# @bacnh85/pi-selfskills

> 标签: pi-extension, pi-package, self-improvement, skills

## 简介

Pi extension for skill self-improvement — one skill_manage tool (list/read/patch/create/write/delete/restore) to patch gaps in loaded skills and create new ones, with a writable-root allowlist, SDK validation, and content-addressed backups.
