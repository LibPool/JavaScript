# @bacnh85/pi-budget

> 标签: budget, cap, cost, pi, pi-package, spend

## 简介

Spend cap enforcement for Pi — halts the agent when session cost exceeds a --budget USD limit. Companion to pi-sub (which renders usage); this one enforces.
