# @armoryworks/drive-mcp

> 标签: anthropic, claude, google-docs, google-drive, google-sheets, mcp, model-context-protocol

## 简介

MCP server exposing Google Drive, Docs, and Sheets write operations (move, rename, delete, in-place edit) that the official Google Drive MCP doesn't.
