# @strixgov/execution-authority

> 标签: ai-agents, ed25519, execution-authority, governance, strix, verifiable

## 简介

The external SDK for the Strix Execution Authority Boundary: ask Strix for bounded authority over one exact proposed action, redeem it immediately before the handler runs, report the outcome, and independently verify the signed evidence. Zero shared code
