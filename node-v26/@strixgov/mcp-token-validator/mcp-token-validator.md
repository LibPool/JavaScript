# @strixgov/mcp-token-validator

> 标签: agent-security, ai-agents, capability-enforcement, ed25519, execution-token, governance, mcp, model-context-protocol, strix, verifier

## 简介

Independent validator for Strix execution_authorization_v1 tokens. Drop into your first-party MCP server, network proxy, or credential-broker wrap to enforce Mode 3 (capability-enforced) governance — no Strix runtime dependency, no network calls. Verifies
