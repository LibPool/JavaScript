# dmk-bus

> 标签: event-bus, framework-agnostic, pubsub, rpc, vue3, 事件总线

## 简介

框架无关的事件总线。支持发布/订阅、请求-响应 RPC、作用域自动清理（onScopeDispose），Vue 已适配（dmk-bus/vue）。
