# @mergeline/agent

> 标签: ai-agents, claude-code, codex, kanban, mcp, pocketbase, task-board

## 简介

The agent's side of a Mergeline board: an MCP server and the `board` CLI. Works with any agent tool that runs MCP servers or shell commands.
