# @sentrei/www-mosh-lol

> 标签: JavaScript

## 简介

This project is a fork of [nouns.wtf](https://nouns.wtf), but aims to position itself a cross-blockchain experiment. We will utilize the Moshes as a symbol for a parachain future.
