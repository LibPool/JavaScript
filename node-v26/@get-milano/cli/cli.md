# @get-milano/cli

> 标签: bindings, cli, ddui, document-driven-ui, json-schema, milano, validation

## 简介

Milano Document-Driven UI: the producer's command line. Validates documents with the gate the engines run, and generates the document schema and typed bindings from a vocabulary.
