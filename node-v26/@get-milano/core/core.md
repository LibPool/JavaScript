# @get-milano/core

> 标签: ddui, document-driven-ui, milano, server-driven-ui

## 简介

Milano Document-Driven UI: the contract engine in TypeScript. Documents in, resolved trees out, validated by a strict gate. No UI toolkit, no dependencies.
