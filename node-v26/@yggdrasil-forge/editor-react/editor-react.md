# @yggdrasil-forge/editor-react

> 标签: JavaScript

## 简介

The Yggdrasil Forge Studio — full visual editor UI for progression trees: canvas, inspector, cards view, play mode, synchronized code panel. The application layer over @yggdrasil-forge/editor-core.
