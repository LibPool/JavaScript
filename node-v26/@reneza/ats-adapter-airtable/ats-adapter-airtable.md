# @reneza/ats-adapter-airtable

> 标签: agent-context, agent-memory, agentic, airtable, airtable-agent-memory, airtable-api, airtable-mcp, ats-adapter, claude-code, context-engineering, hybrid-search, mcp, rag, retrieval, rrf

## 简介

Airtable adapter for Agentic Task System. Expose any Airtable base as agent-queryable records through ATS retrieval, RRF fusion, and MCP — a table is a project, a record is a task. Adapter, not migration.
