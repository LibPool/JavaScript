# @iconmind/mcp

> 标签: agents, ai, icon-set, iconmind, icons, llm, mcp, mcp-server, model-context-protocol, rag, svg

## 简介

MCP server for IconMind — lets an AI assistant search the real icon set instead of guessing names. Offline, bundled data, instant start.
