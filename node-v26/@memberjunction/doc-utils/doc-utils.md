# @memberjunction/doc-utils

> 标签: JavaScript

## 简介

This library provides functionality for dynamically retreiving documentation from the official MemberJunction object model documentation site, parsing it, and caching elements in memory for performance. Use this whenever you need dynamic access to the MJ
