# @memberjunction/ng-base-forms

> 标签: angular, edit, entity, forms, memberjunction, primeng, record

## 简介

MemberJunction: Generic Angular form components for rendering and editing entity records. Provides configurable toolbar, modern form fields (PrimeNG unstyled), collapsible panels with IS-A inheritance support, and event-driven navigation. Zero Explorer de
