# @memberjunction/markdown-core

> 标签: ast, markdown, marked, memberjunction, react-native

## 简介

MemberJunction: Framework-agnostic markdown engine (marked config + custom extensions). Emits HTML or a token AST so it can be rendered by Angular (ng-markdown), React Native, or any other UI layer.
