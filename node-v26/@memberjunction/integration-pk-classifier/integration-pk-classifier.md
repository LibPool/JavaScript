# @memberjunction/integration-pk-classifier

> 标签: JavaScript

## 简介

Lightweight soft-PK classifier for integration objects. Cascades: universal convention (vendor-level hint) → naming heuristic → statistical uniqueness sampling → one-shot LLM. Built from scratch — does NOT depend on DBAutoDoc. Narrow scope: PK only. Hones
