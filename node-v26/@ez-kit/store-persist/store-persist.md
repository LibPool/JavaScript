# @ez-kit/store-persist

> 标签: indexeddb, localstorage, persist, react, sessionstorage, state-management, store, typescript, url-state

## 简介

Source-agnostic persist engine for the @ez-kit store packages: URL / storage / IndexedDB as state, bound to any store manager through a StorePort.
