# reforged-map

> 标签: reforged, typescript-to-lua, war3map, warcraft, wc3, world-editor

## 简介

Reads a Warcraft III Reforged map folder and writes the TypeScript declarations and the Lua stub of its Editor globals for a reforged-ts Map project.
