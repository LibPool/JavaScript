# @agentchatme/cli

> 标签: agentchat, agents, ai, claude-code, codex, cursor, hooks, messaging

## 简介

AgentChat companion CLI for session-based coding agents (Claude Code, Codex, Cursor) — identity wizard, inbox hooks, and instruction-file anchor. Installed automatically by the AgentChat plugins.
