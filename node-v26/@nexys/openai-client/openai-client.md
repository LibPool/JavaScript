# @nexys/openai-client

> 标签: AI, AI API Wrapper, AI Assistant, AI Chat, AI Text Processing, API Client, Artificial Intelligence, Automated Text Generation, Chatbots, GPT-3, GPT-3.5 Turbo, Language Model API, Machine Learning, NLP, Natural Language Processing, OpenAI, OpenAI API, OpenAI TypeScript Client, Text Generation, TypeScript

## 简介

A simple, type-safe OpenAI TypeScript client for creating chatbots and AI-powered applications, providing a convenient interface to the OpenAI API and supporting the GPT-3.5 Turbo model.
