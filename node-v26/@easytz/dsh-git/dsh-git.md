# @easytz/dsh-git

> 标签: deepseek, deepseek-harness, dsh, dsh-plugin, git, sidebar-panel

## 简介

Git 面板：看改动、暂存、提交、推送、切分支、翻历史，不用记命令。Visual Git panel for DeepSeek Harness: stage, commit, push, switch branches, browse history.
