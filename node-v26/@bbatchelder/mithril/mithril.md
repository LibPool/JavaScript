# @bbatchelder/mithril

> 标签: blueprint, blueprintjs, components, cva, design-system, radix-ui, react, shadcn, tailwindcss, ui

## 简介

A modern, pixel-faithful reimplementation of Palantir Blueprint's design language — built on React 19, Radix primitives, Tailwind v4, and CVA. Distributed both as a conventional npm package and shadcn-style as owned source.
