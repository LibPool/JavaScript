# @atthebunga/gurmukhi-legacy

> 标签: anmollipi, asees, converter, gurbani, gurbaniakhar, gurmukhi, legacy-font, punjabi, unicode

## 简介

Convert legacy Gurmukhi font text (AnmolLipi/GurbaniAkhar, Asees, Joy, AnandpurSahib, Satluj, SONY) to Unicode, and Unicode back to AnmolLipi
