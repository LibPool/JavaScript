# @radost-it/trace-graph

> 标签: entity-resolution, graph, graphology, knowledge-graph, louvain, no-dom, react-native

## 简介

Incremental knowledge-graph core: stable entity ids, idempotent merge, degree centrality, Louvain communities and size capping. Pure JavaScript, no DOM.
