# libreoffice-mcp

> 标签: converter, docx, libreoffice, mcp, pdf, pptx, uno, xlsx

## 简介

MCP server that drives a local LibreOffice instance over UNO: convert, export, read and edit Writer/Calc/Impress documents.

## 官网

- npm 页面：https://www.npmjs.com/package/libreoffice-mcp

- npm registry：https://registry.npmjs.org/libreoffice-mcp
- Node 要求：>=18
