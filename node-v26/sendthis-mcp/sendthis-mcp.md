# sendthis-mcp

> 标签: ai-agent, claude, file-transfer, mcp, model-context-protocol, sendthis

## 简介

Send files from your computer to SendThis from Claude Code, Claude Desktop, Cursor and other AI agents, and get a share link back.

- 官网：https://sendthis.com
- npm 页面：https://www.npmjs.com/package/sendthis-mcp
