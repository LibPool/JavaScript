# @ascribed/review

> 标签: ascribe, docs-as-code, documentation, markdown, pull-request, review

## 简介

A toolchain for documentation written as code. This package reviews pages as readers see them: changed blocks marked on the rendered page, and a pull request's review threads beside them.
