# @glowbox/split-flap

> 标签: departure-board, display, electromechanical, glowbox, retro, solari, split-flap, splitflap

## 简介

Electromechanical split-flap display component — Solari-style flap cards falling from the drum, forward-only wrap-through cascades, optional card-slap sound, in the glowbox family.
