# @artisanpack-ui/bookings-js

> 标签: JavaScript

## 简介

Framework-agnostic JavaScript core for the ArtisanPack UI bookings package, plus ready-made React and Vue booking widgets: typed public API client, date and timezone helpers, shared types, and the BookingWidget and ManageBooking components.
