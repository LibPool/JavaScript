# @hs-x/hubspot-cli

> 标签: JavaScript

## 简介

Dev-time HubSpot developer-account client and dev-session driver. Counterpart to @hs-x/hubspot — wraps @hubspot/local-dev-lib for CLI and control-plane executors.
