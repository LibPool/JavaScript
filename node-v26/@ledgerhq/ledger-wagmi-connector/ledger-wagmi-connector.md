# @ledgerhq/ledger-wagmi-connector

> 标签: JavaScript

## 简介

`@ledgerhq/ledger-wagmi-connector` is a connector for the popular [wagmi](https://github.com/wagmi-dev/wagmi) library based on the Ledger Connect Kit, [@ledgerhq/connect-kit](https://github.com/ledgerhq/connect-kit).

## 官网

- npm 页面：https://www.npmjs.com/package/@ledgerhq/ledger-wagmi-connector

## 历史版本号

- 1.0.0
- 1.0.0-beta.1

## 获取地址

- npm registry：https://registry.npmjs.org/@ledgerhq/ledger-wagmi-connector
- Node 要求：>=14
