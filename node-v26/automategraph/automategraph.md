# automategraph

> 标签: engine, execution, graph, isomorphic, json, orchestration, script-loader, state-machine, typed-edges, workflow

## 简介

Isomorphic execution engine for graph definitions: typed conditional edges, deep-equality routing, an explicit Next/goto router, a function registry, and graph documents that load their own scripts. Zero runtime dependencies.
