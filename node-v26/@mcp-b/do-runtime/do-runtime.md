# @mcp-b/do-runtime

> 标签: actors, browser, cloudflare, durable-objects, opfs, sqlite, typescript, workerd

## 简介

Cloudflare's Durable Object runtime (workerd), ported to TypeScript: actors with input/output gates, SQLite storage, facets and alarms, running in the browser and in Node.
