> 标签: accessibility, data-grid, datagrid, design-system, filtering, paging, react, sorting, table, typescript, virtual-scroll

## 简介

React data grid from the OGE UI suite: data-driven columns with render props, multi-column sorting, a typed filter row with an operator menu, global search, paging with a full pager, row and column virtualization, windowed remote loading and infinite scro
