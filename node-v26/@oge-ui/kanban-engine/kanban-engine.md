# @oge-ui/kanban-engine

> 标签: drag-and-drop, headless, kanban, kanban-board, swimlanes, typescript, wip-limit

## 简介

Framework-free engine behind the OGE UI Kanban board, shared by its Angular and React render layers: card normalization and field write-back, swimlane grouping, search, drag hit-testing and edge auto-scroll math, per-column virtual windows, WIP arithmetic
