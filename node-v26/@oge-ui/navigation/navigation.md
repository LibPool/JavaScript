# @oge-ui/navigation

> 标签: angular, breadcrumb, drawer, hierarchy, menu, menubar, navigation, pager, pagination, paging, signals, standalone-components, stepper, tree, treeview, virtual-scroll

## 简介

Signal-based Angular navigation family: OgeTreeView with flat or nested data and APG treeview keyboard support, OgeDrawer whose modality follows its layout mode, OgeStepper with async leave guards, OgeMenubar — a WAI-ARIA APG menubar with nested submenus
