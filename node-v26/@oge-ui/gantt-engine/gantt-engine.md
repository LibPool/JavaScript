> 标签: critical-path, gantt, gantt-chart, headless, project-management, scheduling, typescript

## 简介

Framework-free engine behind the OGE UI Gantt chart, shared by the Angular and React render layers: task-tree model with field mapping and summary roll-ups, calendar-true time scales, forward auto-scheduling on work calendars, the critical-path pass, orth
