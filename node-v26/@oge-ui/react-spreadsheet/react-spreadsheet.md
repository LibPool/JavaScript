# @oge-ui/react-spreadsheet

> 标签: accessibility, excel, excel-viewer, react, spreadsheet, typescript, viewer, workbook, xlsx

## 简介

React spreadsheet viewer from the OGE UI suite that shows .xlsx workbooks the way Excel does: Excel-measured column widths, row heights, fonts, number formats, borders, fills, conditional formats, frozen panes, merges, pictures, charts, notes and hyperlin
