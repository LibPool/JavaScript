# @oge-ui/kanban

> 标签: angular, cards, drag-and-drop, kanban, kanban-board, signals, standalone-components, swimlanes, task-board, wip-limit

## 简介

Signal-based Angular Kanban board: swimlanes, WIP limits, per-column virtualization, drag & drop with Escape-cancel, keyboard card moving with live announcements, built-in edit dialog and context menu — the only Angular-native Kanban. Source-available com
