# @oge-ui/buttons

> 标签: angular, button, button-group, dropdown-button, signals, split-button, standalone-components

## 简介

Signal-based Angular button family: OgeButton with async single-flight actions and hold-to-confirm, OgeButtonGroup selection and OgeDropDownButton.
