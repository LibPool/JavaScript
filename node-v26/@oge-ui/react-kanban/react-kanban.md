# @oge-ui/react-kanban

> 标签: accessibility, drag-and-drop, kanban, kanban-board, react, swimlanes, task-board, typescript, wip-limit

## 简介

React Kanban board from the OGE UI suite: columns and swimlanes over a plain card array with field mapping, WIP limits, per-column virtualization, drag & drop with Escape-cancel and edge auto-scroll, Ctrl+Arrow keyboard card moving with live announcements
