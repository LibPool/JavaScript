# @whatworks/payload-rbac

> 标签: JavaScript

## 简介

Role based access control plugin for Payload. Roles live in the database with a per-collection Create/Read/Update/Delete permission matrix, can be predefined in code and seeded on init, and are enforced across all collections and globals.
