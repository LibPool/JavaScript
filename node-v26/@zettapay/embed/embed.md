# @zettapay/embed

> 标签: checkout, embed, on-chain, qr, rpc, solana, solana-pay, usdc, vanilla, zettapay

## 简介

ZettaPay lean embed.js — ~5KB vanilla drop-in that reads Solana on-chain invoices via public RPC and detects payment with zero runtime dependencies. Mainnet by default; auto-detects testnet via flag.
