# @colixsystems/filestore-client

> 标签: appstudio, client, files, filestore

## 简介

Typed client for the AppStudio Filestore subsystem (folders, file archive, previews, presigned object streaming, sharing, trash) at /filestore/*, plus BankID file signing at /signatures and signing rounds at /signing-rounds. snake_case JSON wire contract,
