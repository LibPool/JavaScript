# dsh-theme-swiss-international

> 标签: deepseek-harness, dsh, dsh-bundle, dsh-plugin, international-typography, swiss, theme

## 简介

Swiss International Style (Internationale Typographie) theme for the DeepSeek-Harness Web UI: paper-and-ink palette, one signal red, hairline rules, square corners, flush-left grotesque type.
