# @tracichick/quickbooks-mcp

> 标签: accounting, api, mcp, model-context-protocol, quickbooks

## 简介

MCP server for QuickBooks Online — accountant engine with read/write tools, audit-safe journal-entry reversal, and built-in operating instructions. Fork of quickbooks-mcp by laf-rge (MIT), with modifications.
