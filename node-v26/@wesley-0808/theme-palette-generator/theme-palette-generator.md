# @wesley-0808/theme-palette-generator

> 标签: JavaScript

## 简介

> 输入一个主色 HEX，自动生成 10 级色阶、14 级中性色阶、浅色 / 深色双模式，并直接输出可落地的 **TDesign CSS 变量**（`--td-brand-color` / `--td-gray-color` 等）。
