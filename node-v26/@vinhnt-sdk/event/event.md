# @vinhnt-sdk/event

> 标签: event, event-bus, eventsourcing, pubsub, replay, vnt

## 简介

Typed event definitions and event bus for VNT Agent - defineEvent registry, built-in run/system/webhook events, in-memory and global event buses with durable replay
