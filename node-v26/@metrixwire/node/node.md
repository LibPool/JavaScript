# @metrixwire/node

> 标签: apm, bun, elysia, express, fastify, koa, metrixwire, monitoring, n+1, nestjs, performance

## 简介

Zero-config APM SDK for Node.js & Bun — auto-traces every request (Express, Fastify, Koa, NestJS, Hapi, Elysia) plus pg, mysql2, Prisma, ioredis, BullMQ & outbound HTTP.
