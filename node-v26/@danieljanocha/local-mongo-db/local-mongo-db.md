# @danieljanocha/local-mongo-db

> 标签: atlas, cli, local-database, mongodb, mongodump, mongorestore, podman, snapshot

## 简介

Reusable CLI for managing a local MongoDB container (podman) with snapshots, pull/push to a hosted Atlas, and configurable env-var injection.
