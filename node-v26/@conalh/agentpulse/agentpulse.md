# @conalh/agentpulse

> 标签: agent, agent-gov, agent-monitoring, ai, ci-gate, claude-code, codex, cursor, dashboard, governance, ink, no-llm, observability, terminal, transcript, tui

## 简介

Live trajectory verdict for AI coding agent sessions. Reads Claude Code / Cursor / Codex transcripts locally, classifies what the agent is doing, renders it as plain English. No LLM, no cloud, no telemetry.
