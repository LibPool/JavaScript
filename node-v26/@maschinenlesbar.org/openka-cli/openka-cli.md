# @maschinenlesbar.org/openka-cli

> 标签: bundestag, cli, kleine-anfrage, landtag, open-data, parlament, reproducible

## 简介

OpenKA — German parliamentary Kleine Anfragen from 17 incompatible systems in one reproducible, machine-readable schema. Deterministic runtime: no generative model on the line.
