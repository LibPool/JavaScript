# antlion-lacewing

> 标签: dpop, fapi, jwt, lacewing, oauth, rfc9449, security, typescript

## 简介

DPoP (RFC 9449) proof verification for Lacewing: one call checks the access token, the proof and the key binding together, or rejects the request.
