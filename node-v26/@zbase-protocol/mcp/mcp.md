# @zbase-protocol/mcp

> 标签: agents, base, claude, mcp, model-context-protocol, privacy, solana, x402, zbase, zk

## 简介

MCP server for zBase — private x402 agent-payment demos on Base. Lets Claude Desktop / Cursor / any MCP-compatible client call zBase from natural language.
