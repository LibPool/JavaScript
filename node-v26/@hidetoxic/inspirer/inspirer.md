# @hidetoxic/inspirer

> 标签: anthropic, chinese, claude, cli, dictionary, ink, language-learning, llm, translation, tui

## 简介

Inspirer — a TUI dictionary tool. Look up any word/phrase/sentence (any language → Chinese explanation), find idiomatic ways to express something in a target language, and keep everything in a searchable local history. Powered by an LLM.
