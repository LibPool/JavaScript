# @ai-router-sdk/redis

> 标签: ai, distributed, rate-limiting, redis, router

## 简介

Redis-backed RateLimitStore for @ai-router-sdk/core — shared rate-limit state across replicas. No hard dependencies: bring your own ioredis/node-redis client.
