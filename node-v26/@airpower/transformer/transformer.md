# @airpower/transformer

> 标签: AirPower, bean, bean-copy, class, class-transformer, oop, transformer, typescript

## 简介

AirPower-Transformer 是一个基于 TypeScript 的数据转换器，提供了从 JSON 对象到 类实例 对象之间互相转换的系列装饰器和方法。
