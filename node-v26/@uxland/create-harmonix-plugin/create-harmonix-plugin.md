# @uxland/create-harmonix-plugin

> 标签: create, harmonix, microfrontends, plugins

## 简介

Create a Harmonix plugin with React, Lit or Angular, running in the Harmonix demo shell: npm create @uxland/harmonix-plugin.

- 官网：https://harmonixframework.dev/docs/packages/create-harmonix-plugin/
