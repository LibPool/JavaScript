# @uxland/create-etc-hes-plugin

> 标签: JavaScript

## 简介

Crea un plugin de Harmonix per a l'aplicació de Primària (React, Lit o Angular) amb el sandbox ja configurat: npm create @uxland/etc-hes-plugin.
