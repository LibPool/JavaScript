# omni-admin-mcp

> 标签: admin, claude, cursor, mcp, model-context-protocol, omniai

## 简介

MCP server for the OmniAI admin API: one admin token that reaches every dashboard endpoint, plus reports — over stdio, streamable HTTP or SSE.
