# cascade-setup

> 标签: cascade, claude-code, codex, coordination, cursor, mcp, model-context-protocol, multi-agent, setup, vscode

## 简介

Connect every AI agent tool on your machine (Claude Code, Codex, Cursor, VS Code) to Cascade in one command, so agents claim shared work before acting and never collide.
