# @churnkey/mcp

> 标签: churnkey, claude, cursor, mcp, model-context-protocol, retention, subscription

## 简介

Model Context Protocol server for Churnkey. Lets an AI assistant read your retention data and manage cancel flows, offers, and recovery campaigns.
