# @info-esportes/react-boleto-barcode

> 标签: barcode, boleto, interleaved-2-of-5, itf, react, svg

## 简介

React component for rendering Interleaved 2 of 5 (ITF) barcodes as SVG, with a helper for Brazilian bank boleto linha digitável conversion.
