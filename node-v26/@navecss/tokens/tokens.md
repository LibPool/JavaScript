# @navecss/tokens

> 标签: css, design-system, design-tokens, dtcg, w3c-design-tokens

## 简介

DTCG 2025.10 design tokens for Nave: seed-derived semantic colours, typography, spacing, and the rest of the token layer, built by a first-party DTCG 2025.10 reader.
