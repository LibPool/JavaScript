# @doubao-dev/template

> 标签: JavaScript

## 简介

Doubao Apps Widget 模板库，用于快速开发卡片类 widget。模板把标题栏、内容区、信息区和操作区组合成稳定的卡片结构，开发者在 Widget 函数组件里选择模板并传入业务数据即可。
