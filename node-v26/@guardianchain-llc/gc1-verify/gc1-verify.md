# @guardianchain-llc/gc1-verify

> 标签: air-gapped, blockchain, cryptographic-proof, ed25519, evidence, gc1, guardianchain, offline, verification

## 简介

Offline verification tool for GC-1 evidence capsules. Works without network connectivity. Verifies Ed25519 signatures, Merkle proofs, and canonical hashes.
