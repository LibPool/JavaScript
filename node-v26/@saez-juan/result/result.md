# @saez-juan/result

> 标签: JavaScript

## 简介

Pequena utilidad para modelar resultados de operaciones con el patron "error-as-values", inspirada en `Result` de Rust. Evita excepciones para el flujo normal y hace explicito el manejo de errores.
