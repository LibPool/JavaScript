# dsh-memvault

> 标签: context-injection, core-memory, deepseek-harness, dsh, dsh-plugin, kv-cache, long-term-memory, mcp, memory, memvault, panel, sqlite, system-prompt

## 简介

DeepSeek Harness plugin: inject MemVault core memory blocks into the system prompt, extract finished turns as one windowed pass, and show, edit, trace, review and replay all of it in a memory panel
