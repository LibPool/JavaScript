# @ph-qa/midscene-cli

> 标签: JavaScript

## 简介

Midscene CLI (内部分支)：在官方 v1.7.1 基础上新增 aiScenario 造数动作，可在 YAML flow 里像 ai:/sleep: 一样直接调用 AI 场景造数
