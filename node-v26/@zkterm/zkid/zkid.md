# @zkterm/zkid

> 标签: blockchain, cairo, cryptography, ed25519, identity, multi-chain, privacy, proof-of-ownership, smart-contract, solana, stark-curve, starknet, zero-knowledge, zkid

## 简介

Privacy-preserving cryptographic identity system with Ed25519 proofs, AES-256-GCM encryption, and multi-chain blockchain verification (Solana + Starknet). Includes Cairo smart contract for on-chain proof storage.
