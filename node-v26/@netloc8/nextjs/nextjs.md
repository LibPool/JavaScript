# @netloc8/nextjs

> 标签: app-router, cookie-consent, eu-detection, gdpr, geo-blocking, geoip, geolocation, ip-geolocation, locale-redirect, location-detection, middleware, netloc8, next, next-plugin, nextjs, proxy, server-components, ssr, timezone

## 简介

Next.js geolocation plugin. Server-side proxy, getGeo() for Server Components, useGeo() hook, GeoGate, and locale-based redirects.
