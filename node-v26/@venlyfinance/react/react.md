# @venlyfinance/react

> 标签: headless, hooks, payments, react, settlement, stablecoin, venly

## 简介

Headless React layer for the Venly Finance and Fundflow APIs: provider, TanStack Query hooks, and flow state machines for regulated money movement. Runs with zero credentials in mock mode.
