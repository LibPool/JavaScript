# @janiscommerce/n8n-nodes-janis-commerce

> 标签: catalog, ecommerce, janis, janis-commerce, n8n, n8n-community-node-package, oms, pricing, wms

## 简介

n8n community node for Janis Commerce: trigger for Janis webhooks and actions to consume the Janis Commerce API (orders, products, SKUs, prices, stock).
