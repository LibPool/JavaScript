# @tagflow/cloudflare

> 标签: affiliate, amazon-associates, cloudflare-workers, geniuslink-alternative, onelink-alternative

## 简介

Cloudflare Worker adapter for localized Amazon affiliate links: mountable handler, 302 semantics, optional Analytics Engine click logging.
