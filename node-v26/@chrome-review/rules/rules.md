# @chrome-review/rules

> 标签: chrome-extension, mv3, rules, static-analysis

## 简介

Rules engine for chrome-review: permission-diff, remote-hosted-code detection, host-scope analysis, confidence tiering. Consumes @chrome-review/parser output.
