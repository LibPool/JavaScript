# @zhanghanxuan/dsh-notify

> 标签: deepseek-harness, desktop-notification, dsh, dsh-plugin, notification, notify, toast, webhook

## 简介

DSH notify plugin: browser notifications, in-page toast, sound, tab-title badge and webhook when a session finishes, needs approval, or waits for an answer.
