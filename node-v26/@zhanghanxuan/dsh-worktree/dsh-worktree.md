# @zhanghanxuan/dsh-worktree

> 标签: deepseek-harness, dsh, dsh-plugin, git, git-worktree, parallel-agents, workspace, worktree

## 简介

DSH worktree plugin: pick an existing git worktree, or create one (from an existing branch or a brand-new branch), and open it in a new session.
