# @yoyaflow/yoya-compiler

> 标签: build-time, compiler, vite, yoya-ui

## 简介

yoya-ui build-time compiler: shape-only analysis and emission for the yoya-ui DSL. It knows no component names — it consumes @yoyaflow/yoya-core interface tables and an optional component registry.
