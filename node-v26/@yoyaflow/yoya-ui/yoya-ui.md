# @yoyaflow/yoya-ui

> 标签: frontend, ui, vanilla-js, vite, web-components

## 简介

A browser-native JS UI library with declarative HTML authoring: component library, router, i18n, theming and layout, works with or without a build tool, SSR-ready.
