# @mcsherrylabs/evolver-mcp

> 标签: JavaScript

## 简介

MCP server over a configurable Evolver node — read the chain, sign a transfer, administer what you own, write to a channel, submit a signed transaction. Wraps @mcsherrylabs/evolver-client; implements no wire format of its own.
