# @bintangtimurlangit/tokopedia-mcp

> 标签: discovery, ecommerce, indonesia, marketplace, mcp, model-context-protocol, product-search, reviews, tokopedia

## 简介

A zero-config MCP server for discovering Tokopedia — product search with full dynamic filtering, product detail, variants, rating summaries, promo campaigns, customer reviews, category browsing, and shop info. No login required.
