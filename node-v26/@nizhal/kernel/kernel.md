# @nizhal/kernel

> 标签: JavaScript

## 简介

Schema helpers, mutators, sync rules, and contract emission for [Nizhal](https://github.com/octalpixel/nizhal) — a self-host, no-WAL offline-sync toolkit for Postgres. This is the transport-free core you share between server and client: define your tables
