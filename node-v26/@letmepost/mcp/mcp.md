# @letmepost/mcp

> 标签: agents, letmepost, mcp, model-context-protocol, publishing-api, social-media

## 简介

MCP server for letmepost.dev. Autogenerates a tool per OpenAPI operation so agents can drive the entire publishing API — posts, media, accounts, webhooks, API keys — without bespoke wrappers.
