# clicksplain

> 标签: ai, developer-tools, llm, onboarding, shadow-dom, tooltip, ui-explainer, widget

## 简介

Drop-in AI widget that explains any UI element on click. Ships the browser widget, LLM connectors, and a runtime-agnostic server handler; no hosted backend.
