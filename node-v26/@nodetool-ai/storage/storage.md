# @nodetool-ai/storage

> 标签: JavaScript

## 简介

Storage abstraction layer for NodeTool providing a uniform interface over multiple storage backends: local file system, in-memory (for tests), Amazon S3 (and S3-compatible services), and Supabase Storage.
