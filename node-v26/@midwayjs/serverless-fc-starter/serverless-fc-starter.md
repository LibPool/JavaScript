# @midwayjs/serverless-fc-starter

> 标签: JavaScript

## 简介

本模块用于包裹无法定制运行时的 FaaS 平台，比如阿里云 FC。

- npm 页面：https://www.npmjs.com/package/@midwayjs/serverless-fc-starter
