# picshrink-browser

> 标签: browser, compress, compression, dng, image, jpeg, nef, offscreencanvas, photo, raw, web-worker, webp

## 简介

Fast, private, in-browser photo compression with RAW (NEF, DNG, CR2, ARW, PEF) support. Runs in a Web Worker with OffscreenCanvas. Zero dependencies.

## 官网

- 官网：https://compresspics.org
