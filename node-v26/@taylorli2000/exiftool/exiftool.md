# @taylorli2000/exiftool

> 标签: browser, documents, exif, exiftool, files, images, iptc, media, metadata, node, universal, wasm, webassembly, xmp, zeroperl

## 简介

This is a fork of @uswriting/exiftool to provide cjs compatibility. ExifTool powered by WebAssembly to extract and write metadata from files in browsers and Node.js environments using zeroperl
