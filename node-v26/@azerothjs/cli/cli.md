# @azerothjs/cli

> 标签: azerothjs, build, cli, command-line, dev-server, scaffold

## 简介

AzerothJS command line - one verb per job: dev (the fullstack conductor), check, build, doctor, info. Detects your project's shape, composes the tools you already have, and prints exactly what it runs
