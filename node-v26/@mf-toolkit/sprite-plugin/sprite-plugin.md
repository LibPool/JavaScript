# @mf-toolkit/sprite-plugin

> 标签: icons, microfrontend, optimization, rollup, sprite, svg, vite, webpack

## 简介

SVG sprite generator that statically analyzes your code and builds optimized sprites containing only the icons your microfrontend actually uses.
