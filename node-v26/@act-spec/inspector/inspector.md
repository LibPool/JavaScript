# @act-spec/inspector

> 标签: JavaScript

## 简介

PRD-601 inspector CLI + library for the ACT (Agent Content Tree) v0.1 wire format. Subcommands: fetch, walk, diff, token-budget. Reuses @act-spec/validator for parsing and structural checks (PRD-601-R1).
