# @opencharacter/text

> 标签: character-sheet, i18n, icu-messageformat, ocf, open-character-format, rpg, tabletop, ttrpg

## 简介

Open Character Format (OCF) wording helper: turns engine output (choices, pauses, options, issues, roll summaries and dice) into finished text from pack and spec messages.

## 官网

- 官网：https://opencharacterformat.org
- 源码仓库：git+https://github.com/pixelqueue/opencharacter.git
- npm 页面：https://www.npmjs.com/package/@opencharacter/text
