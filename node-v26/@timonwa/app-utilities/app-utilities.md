# @timonwa/app-utilities

> 标签: browser, format, helpers, intl, react-native, typescript, utilities

## 简介

Typed helper functions for building apps — formatting, strings, files, and slugs. Zero dependencies, universal by default, with browser-only APIs behind a separate entry point.
