# @ronaldroe/micro-flow-editor

> 标签: automation, drag-and-drop, flow-builder, logic-flow, low-code, micro-flow, n8n-alternative, no-code, scheduler, visual-editor, webhook, workflow

## 简介

A visual, drag-and-drop builder for @ronaldroe/micro-flow logic flows, with a server that runs them (manual, webhook and schedule triggers), execution history in any SQL database, and a runtime to run exported flows in your own app.
