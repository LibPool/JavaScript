# @quarklab/rad-ui

> 标签: cli, components, persian, quarklab, rad-ui, radix-ui, react, tailwindcss, ui

## 简介

A CLI for adding Rad UI components to your project. Beautiful Persian-themed React components built on Radix UI and Tailwind CSS.
