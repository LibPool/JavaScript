# @kiliannnnn/qrify

> 标签: astro, canvas, component, custom-element, generator, html, qr, qr-code, qrcode, qrify, ssr, svg, web-component

## 简介

QR code generator for the web: a zero-dependency UTF-8 encoder, an SSR-friendly SVG renderer, and a <qr-code> custom element.
