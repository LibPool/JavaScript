# java-polycall

> 标签: ffi, ffm, java, libpolycall, panama, peer-to-peer, polycall

## 简介

Java binding for the Polycall binding ABI v1 (Foreign Function & Memory API, JDK 22+). Source distribution of a Maven project; not a JavaScript library.
