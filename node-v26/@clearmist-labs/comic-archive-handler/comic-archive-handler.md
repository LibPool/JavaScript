# @clearmist-labs/comic-archive-handler

> 标签: 7z, archive, asar, cba, cbr, cbt, cbz, comic, comicinfo, metroninfo, phash, rar, tar, zip

## 简介

Detect, convert, and manipulate comic book archives: container conversion, edit metadata, image re-encoding, perceptual + content hashing.
