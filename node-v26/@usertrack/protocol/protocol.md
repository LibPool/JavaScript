# @usertrack/protocol

> 标签: analytics, growth, hmac, protocol, saas, usertrack

## 简介

UserTrack native integration protocol (v1): HMAC-SHA256 request/response signing, nonce cache, wire types. WebCrypto only, zero dependencies.
