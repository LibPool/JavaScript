# @usertrack/node

> 标签: analytics, authjs, convex, drizzle, growth, metrics, next-auth, prisma, saas, usertrack

## 简介

UserTrack SDK for Node and edge runtimes: a signed metrics handler for any app (Prisma, Drizzle, Convex, Auth.js or custom) plus a fire-and-forget lifecycle event client. Aggregate counts only, no PII.
