## 简介

Next-level LLM code review: version-aware skills, static hints and self-critique for fewer false positives. Works with Claude Code, Codex, Copilot, Gemini, the Anthropic API, AWS Bedrock and OpenAI-compatible APIs (Ollama, OpenRouter, …).
