# @taskadence/mcp

> 标签: agents, ai, claude, mcp, model context protocol, modelcontextprotocol, stdio, taskadence

## 简介

The TasKadence MCP server for clients that start a local process: a stdio proxy to the remote server (npx -y @taskadence/mcp).
