# @imenam/mcp-organizer

> 标签: agent, ai, kanban, mcp, model-context-protocol, tasks

## 简介

MCP server with a multi-user web GUI to organize tasks in personal and shared spaces; requests to the AI are queued and processed by the connected agent, every agent action is logged and undoable.
