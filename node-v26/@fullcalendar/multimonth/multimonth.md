# @fullcalendar/multimonth

> 标签: calendar, event, full-sized, fullcalendar, month

## 简介

FullCalendar v6 only (in v7, this plugin is built into each framework package, e.g. @fullcalendar/react/multimonth). Display a sequence or grid of multiple months

## 官网

- 官网：https://fullcalendar.io/docs/multimonth-grid
- 源码仓库：git+https://github.com/fullcalendar/fullcalendar.git
- npm 页面：https://www.npmjs.com/package/@fullcalendar/multimonth
