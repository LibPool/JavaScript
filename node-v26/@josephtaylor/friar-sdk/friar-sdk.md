# @josephtaylor/friar-sdk

> 标签: defi, dlmm, friar, liquidity, lp, mcp, robinhood-chain, uniswap-v4

## 简介

TypeScript SDK for Friar: a dynamic-fee LP venue and position manager on Robinhood Chain (4663). Reads, position planning, unsigned transaction builders, and the underlying bin math.
