# dsh-prompt-crafter

> 标签: deepseek-harness, dsh, dsh-plugin, prompt

## 简介

提示词优化按钮（完全免费）：一键把输入改写成更清晰的提示词。内置免费模型通道，零配置零费用，不可用时自动回退到对话模型。
