# @sharptrick/parley-postgres

> 标签: agent-messaging, mcp, message-bus, parley, postgres, postgresql

## 简介

@sharptrick/parley-postgres — self-hosted networked SQL backend (BIGSERIAL seq = cursor, LISTEN/NOTIFY = subscribe). Slots between SQLite (local floor) and Redis (broker) against the frozen Parley seam.
