# @sharptrick/parley-matrix

> 标签: agent-messaging, matrix, mcp, message-bus, parley

## 简介

@sharptrick/parley-matrix — first external-network backend (matrix-js-sdk: room->topic, sync token->cursor, sync loop->subscribe, history->fetchRecent). Skeleton against the frozen Parley seam — planned v0.4.
