# @sharptrick/parley-zulip

> 标签: agent-messaging, mcp, message-bus, parley, zulip

## 简介

@sharptrick/parley-zulip — self-hosted chat backend with the closest native fit (globally monotonic message id = cursor, stream+topic = topic, event queue long-poll = subscribe) against the frozen Parley seam.
