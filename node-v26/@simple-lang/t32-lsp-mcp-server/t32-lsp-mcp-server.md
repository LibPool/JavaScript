# @simple-lang/t32-lsp-mcp-server

> 标签: cmm, language-server, lsp, mcp, mcp-server, practice, trace32

## 简介

TRACE32 CMM language server via MCP — parse, diagnostics, completions, hover, symbols, and CLI validation for PRACTICE scripts. Native binary, no Node.js runtime needed.
