# @mrfentmen/vndb-mcp

> 标签: anime, database, galgame, mcp, visual-novel, vndb

## 简介

Use this MCP server to VNDB, the Visual Novel Database. Search VNs, characters, releases, tags, ratings. Tools include search vns, get vn, search characters
