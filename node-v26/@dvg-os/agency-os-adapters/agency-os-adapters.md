# @dvg-os/agency-os-adapters

> 标签: JavaScript

## 简介

agency-os provider adapters: HubSpot, Brevo, Meta, kie.ai, YouTube, Google Maps, Google Ads, scraper. Each adapter has its own resilience layer and kill-switch gates.
