# @sahinur/forgedata

> 标签: cli, fake-data, faker, generator, mock, mock-data, react, schema, seed, test-data, typescript, zod

## 简介

A modern, modular, tree-shakable, zero-dependency fake data generator for TypeScript and JavaScript. A production-ready alternative to Faker.js with React integration and a CLI.
