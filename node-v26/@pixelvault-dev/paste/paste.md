# @pixelvault-dev/paste

> 标签: cdn, clipboard, drag-and-drop, image, paste, pixelvault, textarea, upload

## 简介

Paste-and-host: drop, paste, or select an image in any textarea and get a hosted CDN URL back. Backed by PixelVault publishable keys.
