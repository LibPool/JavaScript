# @ai2web/react

> 标签: ai, ai-agents, ai-readiness, ai2web, badge, component, react, react-hooks

## 简介

React bindings for AI2Web: useDiscover / useValidate / useNegotiate hooks and an embeddable AI Readiness <Ai2wBadge>.
