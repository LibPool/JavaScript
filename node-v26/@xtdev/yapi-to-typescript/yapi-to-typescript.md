# @xtdev/yapi-to-typescript

> 标签: codegen, typescript, yapi

## 简介

根据 YApi 的接口定义生成 TypeScript/JavaScript 的接口类型及其请求函数代码。

## 官网

- 源码仓库：https://gitlab.tanjiu.cn/tfe/arch/yapi-to-typescript.git
- npm 页面：https://www.npmjs.com/package/@xtdev/yapi-to-typescript
