# @helipod/fleet

> 标签: JavaScript

## 简介

Multi-node fleet mode for Helipod: run several `helipod serve` nodes against one Postgres database, with a lease-elected writer, read/sync nodes serving from embedded replicas, and sharded write scale-out.
