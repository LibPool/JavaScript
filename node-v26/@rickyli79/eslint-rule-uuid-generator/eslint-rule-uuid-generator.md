# @rickyli79/eslint-rule-uuid-generator

> 标签: autofix, eslint, eslint-plugin, eslintrule, uuid, uuid-v7

## 简介

ESLint rule that replaces configurable placeholder string literals (e.g. 'UUID#7') with fresh v4/v7 UUIDs via autofix.
