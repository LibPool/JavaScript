# @subaud-tools/pi-usage

> 标签: pi, pi-extension, pi-package, rate-limit, statusline, usage

## 简介

Pi extension that reports provider usage/rate-limit budgets (Codex, Anthropic OAuth, etc.) via /usage, with a live statusline widget.
