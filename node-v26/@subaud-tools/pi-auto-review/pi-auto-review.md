# @subaud-tools/pi-auto-review

> 标签: pi, pi-extension, pi-package, sandbox, security

## 简介

Fail-closed, model-backed approval broker for Pi: deterministically hard-denies dangerous operations, reviews dangerous boundaries with a reviewer model, and issues one-shot expiring grants that OS sandbox adapters must consume before retrying.
