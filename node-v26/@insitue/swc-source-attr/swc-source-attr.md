# @insitue/swc-source-attr

> 标签: babel, insitue, instrumentation, jsx, nextjs, react, source, swc, swc-plugin

## 简介

SWC plugin that stamps every JSX element with data-insitue-source="file:line:col" so the InSitue cloud agent can resolve captures to exact source coordinates.
