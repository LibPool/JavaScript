# @k3_2o/pi-secrets

> 标签: agent, pi, pi-package, redaction, secrets, security

## 简介

A pi extension that reversibly obfuscates credentials before they reach the provider: keyed $$PLACEHOLDER$$ substitution, built-in credential patterns, and a user secrets.yml for custom redaction.
