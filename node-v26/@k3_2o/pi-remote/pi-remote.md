# @k3_2o/pi-remote

> 标签: coding-agent, pi, pi-coding-agent, rpc, server, websocket

## 简介

A thin server runtime for Pi Coding Agent — WebSocket-first, HTTP as sugar. Turns pi --mode rpc into a network service.
