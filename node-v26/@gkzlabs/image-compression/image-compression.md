# @gkzlabs/image-compression

> 标签: avif, browser, compression, demo, exif, framework-agnostic, heic, image, live-demo, offscreen-canvas, webcodecs, webp, worker, zero-dependency

## 简介

Framework-agnostic image compression for the browser. Zero dependencies — pure web APIs (WebCodecs, OffscreenCanvas, Worker). AVIF/WebP/JPEG output, target-size mode, HEIC decode. Works with any frontend framework (Angular, React, Vue, Svelte) or vanilla
