# @shanelevs/pi-memory-auto

> 标签: agent-memory, markdown, memory, memory-index, persistent-memory, pi, pi-coding-agent, pi-extension, pi-package, two-tier-memory

## 简介

🧠 Memory extension for the pi coding agent — memories stored as body + 1-3 keywords, a unique keyword table injected into every session, keyword lookup the agent drives itself, duplicate-merging consolidation every N memories. Zero heavy deps.
