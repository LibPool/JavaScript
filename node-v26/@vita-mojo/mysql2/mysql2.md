# @vita-mojo/mysql2

> 标签: client, mysql, server

## 简介

Vita Mojo fork of mysql2 (upstream 3.23.3) adding the connectionLifeTime pool option: recycles pooled connections by age so they rebalance onto DB nodes added by autoscaling
