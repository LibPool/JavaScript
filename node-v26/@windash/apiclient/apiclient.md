# @windash/apiclient

> 标签: apiclient, auth, saas, users, windash

## 简介

Cliente oficial de windash: consulta los datos gestionados por la plataforma (usuarios, roles, avisos, actividades) de tu proyecto con una API fluida estilo dbcube.

## 官网

- npm 页面：https://www.npmjs.com/package/@windash/apiclient

- npm registry：https://registry.npmjs.org/@windash/apiclient
