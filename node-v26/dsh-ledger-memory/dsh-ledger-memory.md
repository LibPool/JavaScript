# dsh-ledger-memory

> 标签: agent, compaction, context, deepseek-harness, dsh, dsh-plugin, handoff, ledger, memory, traceability, triage

## 简介

台账记忆（Ledger Memory）—— 给 DSH 一个项目自己的记忆载体：活跃台账每回合自动注入、只追加的回合流水与活动日志（L0–L4，含逐字存档）、关键决策/目标树/经验教训的卡片化记忆，压缩前抓逐字胶囊、压缩后连台账一起注回，把对话锁定到某个项目目录（跨重启保持），以及跨会话的交接单闭环。可回溯、可追查。★ 1.6.0：记忆目录下沉（记忆集中在 <项目名>-ledger-memory/，与源码物理隔离，V3 项目默认不自动暂存）；新增自定义扩展记忆（6 种模式）；设置面板重做为 4 页（滑块开
