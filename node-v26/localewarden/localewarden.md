# localewarden

> 标签: ai-translation, app-store, arb, chatgpt, cli, fastlane, flutter, gpt, i18n, i18next, json, l10n, llm, locales, localization, machine-translation, next-intl, openai, react-intl, translation, translation-quality, vue-i18n

## 简介

Incremental AI translation for JSON locale files: translates only what changed, never overwrites hand edits, and checks every result before writing it.
