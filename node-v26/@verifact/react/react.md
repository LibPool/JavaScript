# @verifact/react

> 标签: enterprise-ui, evidence, hallucination-detection, provenance, react, web-crypto

## 简介

React components for claim verification: source vault, claim-to-span inspector, hallucination gate and certificate inspector, plus a command bar and a precompiled scoped stylesheet.
