# @charlietyn/nest-rest-generic-mikroorm

> 标签: controller, crud, generic, mikro-orm, nestjs, rest, service

## 简介

Generic NestJS REST base classes and query tooling for MikroORM, preserving the observable API of rest-generic-class and the sibling TypeORM/Sequelize packages.
