# @ignifx/editor-mcp

> 标签: agent, game-engine, ignifx, ignifx-editor, mcp, model-context-protocol

## 简介

MCP server for the ignifx editor: the stdio command agent clients (Claude Code, Codex CLI, Cursor, VS Code) run to reach a running ignifx editor over loopback, with readable errors while the editor is down. Node-only.
