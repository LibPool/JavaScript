# @flowot/pi-pition

> 标签: journal, notes, notion, personal-knowledge-management, pi, pi-coding-agent, pi-extension, pi-package

## 简介

Notion 个人记录助手 — 把 Notion 数据库变成 pi agent 的持久化存储（page列表透明、属性追加合并、区间事件记录、5阶段引导配置）。
