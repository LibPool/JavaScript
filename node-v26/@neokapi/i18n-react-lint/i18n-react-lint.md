# @neokapi/i18n-react-lint

> 标签: eslint, i18n, lint, neokapi-i18n, oxlint, react

## 简介

Authoring-time lint rules for neokapi-i18n. Same rule objects run under ESLint and oxlint (via jsPlugins). Catches unextractable patterns (t(variable), string concat in translatable attrs, label strings hidden in data arrays) that the build-time extractor
