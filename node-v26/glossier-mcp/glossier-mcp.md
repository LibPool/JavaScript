# glossier-mcp

> 标签: beauty, glossier, makeup, mcp, skincare

## 简介

Query the Glossier catalog (glossier.com, NYC): search beauty and skincare, newest arrivals, enriched product details (shades/sizes), price stats, below-median deals, and category counts.
