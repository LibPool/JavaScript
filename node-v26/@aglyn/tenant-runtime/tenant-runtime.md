# @aglyn/tenant-runtime

> 标签: JavaScript

## 简介

The server-side runtime that serves a published Aglyn site: the host-event seam that plugins listen on, and the screen-composition pipeline that turns a stored screen into the node tree a page renders. Install it if you are running Aglyn's tenant server,
