# remesso-sdk

> 标签: agents, celo, payments, recurring-payments, remittances, stablecoins, viem, webhooks

## 简介

Recurring and agent payments on Celo: schedules a payer signs once, agent payments capped on-chain by their human, payment requests, payment events and signed webhooks. TypeScript, on viem.
