# @bafx/utils

> 标签: JavaScript

## 简介

Small, typed TypeScript utilities for functional-style code: array helpers, timezone-aware date helpers, `pipe` / `compose` / `curry`, an `Either` type for error handling, type guards, and a few general helpers.
