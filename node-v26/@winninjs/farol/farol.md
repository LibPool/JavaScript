# @winninjs/farol

> 标签: code-review, diff-coverage, github-action, go, pull-request, python, react, risk, static-analysis, typescript

## 简介

Tells code reviewers how much attention a pull request needs and where to look first: what the change reaches, a merge risk score and a review plan. TypeScript/React, Go and Python. Shadow mode: never blocks.
