# @serialpilot/parser-hdlc

> 标签: framing, hdlc, mavlink, parser, ppp, serial, serialpilot, stream, transform

## 简介

Transform-stream parser that emits one unframed payload per HDLC 0x7E flag boundary. Wraps @serialpilot/hdlc.
