# @nightjarhq/api-types

> 标签: api, json-schema, nightjar, openapi, types, typescript

## 简介

Generated TypeScript types for the Nightjar /v1 API — OpenAPI 3.1 (REST) + JSON Schema (WS event stream). Source of truth is core/spec, emitted from Rust (ADR-016). Do not hand-edit generated files; run `pnpm generate`.
