# @tigersheep/dsh-lark-bot

> 标签: bot, cordis, deepseek-harness, dsh, dsh-plugin, feishu, lark, lark-cli

## 简介

DeepSeek Harness 飞书机器人插件：每个飞书聊天对应一个真实 DSH agent 会话（工具/skill/多轮），收到消息贴表情确认并自动回复，工具授权走飞书交互卡片；支持白名单/触发规则/权限档位与连接开关。
