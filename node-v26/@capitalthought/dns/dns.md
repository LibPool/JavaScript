# @capitalthought/dns

> 标签: JavaScript

## 简介

Shared DNS / domain primitives for Capital Thought projects — zone-check (CZDS), whois/rdap, DNS-record CRUD, email-auth (SPF/DKIM/DMARC + ramp), nameservers, variants. Single source of truth for marc + mikey + domains.
