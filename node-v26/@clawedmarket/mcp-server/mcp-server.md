# @clawedmarket/mcp-server

> 标签: ai-agent, base, claude, commerce, crypto, mcp, model-context-protocol, shopping, stablecoin, usdc

## 简介

MCP server for ClawedMarket — lets AI agents search, compare, and buy products with USDC on Base. Compatible with Claude Desktop, Cursor, Windsurf, Cline, Continue, Zed, and any MCP client.
