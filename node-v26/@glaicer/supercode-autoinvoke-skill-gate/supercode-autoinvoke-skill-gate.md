# @glaicer/supercode-autoinvoke-skill-gate

> 标签: autoinvoke-skill-gate, opencode, opencode-plugin, skills

## 简介

OpenCode plugin (v1 + v2) that hides Explicit-only skills (Claude Code, Codex, OpenCode portable markers) from the model-facing skill catalog while keeping explicit invocation working
