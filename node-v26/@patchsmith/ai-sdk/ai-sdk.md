# @patchsmith/ai-sdk

> 标签: JavaScript

## 简介

Use `createTools` from `patchsmith/ai-sdk` (or `@patchsmith/ai-sdk`) to let an AI SDK model list, create, and edit Patchsmith apps through the app agent's MCP endpoint. Requires AI SDK 7 and Node.js 22 or newer.
