# @nikitph/flux-ui

> 标签: accessible, ai, animation, components, framer-motion, gesture, motion, physics, primitives, react, scroll, spring, streaming, tailwindcss, ui

## 简介

A motion-first, physics-based React component library. 40 composable primitives that turn animation from a feature into a language.
