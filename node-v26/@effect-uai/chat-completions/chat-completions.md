# @effect-uai/chat-completions

> 标签: ai, chat-completions, effect, gateway, llm, openai, openrouter

## 简介

Reusable OpenAI Chat Completions (`/chat/completions`) LanguageModel base for @effect-uai/core. Point it at any compatible gateway (OpenRouter, Groq, Together, self-hosted).
