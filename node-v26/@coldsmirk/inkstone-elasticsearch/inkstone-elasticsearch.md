# @coldsmirk/inkstone-elasticsearch

> 标签: autocomplete, codemirror, completion, editor, elasticsearch, kibana, monaco

## 简介

Elasticsearch request editing intelligence for Monaco and CodeMirror: the console spelling (a method and a path, the body after), endpoint and index completion, body keys by context — a bare `_search` body included — request markers, and a drop-in React r
