# @coldsmirk/tsconfig

> 标签: tsconfig, tsconfig-base, typescript

## 简介

Opinionated TypeScript configs: strict, ESM-first. `/base` (bundler resolution), `/node` (nodenext), and `/react` (base + JSX + DOM).
