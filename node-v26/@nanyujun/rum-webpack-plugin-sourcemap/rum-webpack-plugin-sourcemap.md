# @nanyujun/rum-webpack-plugin-sourcemap

> 标签: error-tracking, monitoring, rum, source-map, sourcemap, upload, webpack, webpack-plugin

## 简介

RUM 前端性能监控平台的 Webpack 插件：webpack build 完成后自动把产物 *.map 上传到 collector，可选上传后删除本地 map。
