# @dax-side/jwt-abstraction

> 标签: access-token, auth, authentication, express, jsonwebtoken, jwt, middleware, refresh-token, typescript, zero-config

## 简介

Stop writing the same JWT auth code in every project. Separate secrets for access and refresh tokens.
