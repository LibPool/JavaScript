# @quanhuzeyu/koishi-plugin-qz-siliconflow

> 标签: ai, chatbot, koishi, plugin

## 简介

koishi插件，支持openaiAPI格式的平台接入，如果你使用控制台将可以同时使用多个平台配置；支持分群组配置，为console界面深度优化，易于配置参数
