# @ajperezbau/msw-devtools

> 标签: devtools, mock, msw, testing, vue

## 简介

A powerful browser-based UI for managing Mock Service Worker (MSW) handlers. Framework-agnostic — works with Vue, React, Svelte, and Vanilla JS.
