# @pillar-ui/core

> 标签: a11y, accessibility, design-system, pillar-core, storybook, typescript, ui-components

## 简介

@pillar-ui/core is a lightweight and comprehensive UI component library packed with reusable and customizable UI components designed for modern web development. Our components adhere to best practices, ensuring a consistent and accessible user experience
