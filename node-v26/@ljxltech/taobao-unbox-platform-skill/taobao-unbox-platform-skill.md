## 简介

One-line installer for the taobao-unbox skill (Claude Code / OpenClaw / Codex / DeepSeek Harness / Hermes / generic .agents/skills/). npx @ljxltech/taobao-unbox-platform-skill install → skill 落地。从淘宝/天猫商品链接抽取 itemId、拉详情、下载素材、生成二次创作资产（多角度合成图 / 主播形象 / 分镜线稿）。
