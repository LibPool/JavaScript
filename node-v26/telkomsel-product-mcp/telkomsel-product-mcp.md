# telkomsel-product-mcp

> 标签: indonesia, llm-tools, mcp, mcp-server, model-context-protocol, next.js, nextjs, packages, product-catalog, rag, streamable-http, telkomsel

## 简介

Telkomsel product catalogue as an MCP server: run it over stdio, or mount it in a Next.js route with one import. Read-only, no API key required.
