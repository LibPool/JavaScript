# @epistemic-record-format/validator-yaml-markdown

> 标签: claims, epistemic-record-format, erf, evidence, provenance, validator

## 简介

Reference validator for the Epistemic Record Format (YAML/Markdown serialization): loads a corpus against the schema and computes every derived reading from the specification text.
