# @haikit/core

> 标签: agent, agentic-ui, ai, chat, generative-ui, haikit, llm, tool-calling, tool-use

## 简介

The haikit contract layer: declare a UI surface once, implement it on the server and in the browser. Isomorphic, zero runtime dependencies.
