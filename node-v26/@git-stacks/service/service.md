# @git-stacks/service

> 标签: JavaScript

## 简介

The Node.js interactive authority for git-stacks. It owns revisioned projections, typed operations, events, signals, filesystem reconciliation, native-keyring/protected-fallback identities, signed certificate rollover, pinned WebTransport, directly truste
