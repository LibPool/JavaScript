# @aistupidlevel/router

> 标签: ai, anthropic, benchmarks, byok, deepseek, gemini, llm, model-routing, openai, router

## 简介

Client for the AI Stupid Level Smart Router: one OpenAI-compatible endpoint that routes every request to the model measuring best for it, on continuously re-run benchmarks, with your own provider keys.
