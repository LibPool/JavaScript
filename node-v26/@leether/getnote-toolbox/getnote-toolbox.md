# @leether/getnote-toolbox

> 标签: deepseek-harness, dsh-plugin, getnote, knowledge-base, notes

## 简介

A native DeepSeek Harness Host plugin for GetNote (得到大脑): search, save, read, and organize notes, tags, and knowledge bases.
