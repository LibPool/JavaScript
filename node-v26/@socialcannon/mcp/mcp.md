# @socialcannon/mcp

> 标签: claude, hermes, mcp, model-context-protocol, social-media, socialcannon

## 简介

MCP server for SocialCannon — publish, schedule and manage social posts (Twitter/X, Facebook, Instagram, LinkedIn, TikTok, YouTube) from any MCP-compatible agent.
