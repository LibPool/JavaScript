# semver-gauge

> 标签: changelog, ci, cli, conventional-commits, github-action, lint, release, sarif, semver, version

## 简介

CI gate that checks your version bump matches the changes since the last release (Conventional Commits: breaking/feat/fix) and that CHANGELOG.md has a real entry for the new version. Text/JSON/SARIF/Markdown, allowlist with expiry, GitHub Action. One depe
