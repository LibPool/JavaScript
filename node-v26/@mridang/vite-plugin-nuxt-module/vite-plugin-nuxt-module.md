# @mridang/vite-plugin-nuxt-module

> 标签: nuxt, nuxt-module, vite, vite-plugin

## 简介

A Vite plugin that builds a Nuxt module the way @nuxt/module-builder does: a bundled module with declarations, a per-file runtime, module.json and types.d.mts
