# @janrevis/express-react-scaffold

> 标签: JavaScript

## 简介

A simple utility to scaffold a full stack javascript project with Express backend and React frontend. Generated projects allow a wide range of options for your project, from a simple project deployed on Heroku to a fully dockerized app and development env
