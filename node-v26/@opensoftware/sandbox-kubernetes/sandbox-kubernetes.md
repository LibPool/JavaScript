# @opensoftware/sandbox-kubernetes

> 标签: JavaScript

## 简介

sandbox-kubernetes: runs isolated, resource-limited sandboxes as kubernetes-sigs/agent-sandbox claims, each reaching out only through its own iron-proxy egress pod that refuses other hosts, puts in the real secrets and allows only the declared MCP tools.
