# @axle-keys/cad-engine

> 标签: agent, cad, geometry, mcp, opencascade, parametric, replicad, step, stl

## 简介

Run Axle Keys model code locally: build parametric CAD, get the same verdict axlekeys.com gives, export STEP/STL. Offline; warm rebuilds in tens of milliseconds.
