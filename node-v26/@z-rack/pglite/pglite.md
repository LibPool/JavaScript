# @z-rack/pglite

> 标签: JavaScript

## 简介

z-rack のデータベースバックエンドとして [PGlite](https://github.com/electric-sql/pglite)（WASM 版 PostgreSQL）を利用するためのパッケージです。`IDatabaseClient` インターフェースを実装した `Pglite` クラスを提供します。
