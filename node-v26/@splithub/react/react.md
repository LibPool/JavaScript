# @splithub/react

> 标签: a-b-testing, ab-testing, ai-agents, analytics, event-tracking, experiments, funnels, hooks, mcp, product-analytics, react, react-hooks, split-testing, splithub, tracking, web-analytics

## 简介

A/B testing and web analytics in React: show a variant, track any event, identify users. No flicker, nothing fetched on render. For React Native and Expo, see @splithub/react-native.
