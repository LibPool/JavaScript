> 标签: AI, AI Agent, Agent, DX API, GenAI, GenAI Agent, MCP, MCP Server, Model Context Protocol, Pega, Pega DX API, Pega GenAI, Pega Infinity

## 简介

MCP Server enabling conversational AI interaction with Pega Infinity applications. Bridge GenAI agents, IDEs, and AI assistants to Pega DX APIs for natural language case management, workflow automation, and business process operations.
