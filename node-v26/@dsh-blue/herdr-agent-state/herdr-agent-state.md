# @dsh-blue/herdr-agent-state

> 标签: agent-state, cordis, deepseek-harness, dsh, herdr, integration, pane, plugin

## 简介

dsh plugin: report agent state (working/blocked/idle, labeled with the current tool), session reference and log path, and session metadata (title, model, context-usage tokens, state labels) to Herdr via its pane socket integration. Works in any dsh profil
