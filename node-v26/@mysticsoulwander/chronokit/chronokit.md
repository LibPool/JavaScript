# @mysticsoulwander/chronokit

> 标签: appointments, calendar, clinic, crm, es-modules, recurring-events, resource-scheduling, scheduler, timeline, vanilla-js

## 简介

Calendar + resource scheduler in plain JavaScript (ES modules, no framework). Day/week/month/timeline views, clinic session and appointment views with outcome capture, drag & drop, recurring events, undo/redo and backend sync.
