# @czlonkowski/n8n-nodes-librus

> 标签: librus, n8n-community-node-package, synergia

## 简介

Dwa węzły n8n do pobierania wiadomości z Librus Synergia i uruchamiania automatyzacji po nowych wiadomościach oraz po dodaniu lub zmianie wydarzeń w terminarzu.
