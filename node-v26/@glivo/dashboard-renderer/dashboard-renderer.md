# @glivo/dashboard-renderer

> 标签: dashboard, glivo, react, renderer, widgets

## 简介

Glivo portable dashboard renderer — consumes a Dashboard document + DashboardHostProtocol, renders everywhere a browser engine runs (desktop app, kiosk, cloud, mobile shell). ZERO desktop dependencies by contract: no Bun / Node / Electrobun imports, ever.
