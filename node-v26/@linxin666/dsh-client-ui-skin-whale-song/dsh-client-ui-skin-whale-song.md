# @linxin666/dsh-client-ui-skin-whale-song

> 标签: JavaScript

## 简介

Hot-pluggable 鲸吟 (whale-song) skin for the dsh web GUI: deep-sea whale-goddess ambience — text-free ocean art backdrop with live theme scrim, ice-blue/cyan/navy palette with gold-thread accents, translucent panes
