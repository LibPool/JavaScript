# @linxin666/dsh-liangshen

> 标签: JavaScript

## 简介

LiangShen (梁神) agent preset plus its composer lever for the dsh web GUI. The host half declares the bundled preset to the harness's agent-preset registry at activation (declare = enabled), so the preset is selectable for new sessions without writing anyth
