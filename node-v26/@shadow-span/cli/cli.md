# @shadow-span/cli

> 标签: appsec, ci, devsecops, iac, pre-commit, sast, sca, secrets, security, vulnerability-scanner

## 简介

Run Shadow Span's application-security checks (SAST / SCA / secrets / IaC) in your own pipeline — pre-commit and CI. Engines run locally, your source never leaves your infrastructure, and findings are normalized to Shadow Span's format and optionally repo
