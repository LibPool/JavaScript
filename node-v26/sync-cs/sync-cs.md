# sync-cs

> 标签: deepseek, dsh-plugin, github, rest, sync

## 简介

DSH 多机自动同步：用 GitHub 私有仓库同步记忆/会话/插件配置，AES-256-GCM 加密，REST 传输（无需 git/SSH），打开自动拉取、回合结束自动推送，左侧栏手动同步按钮。
