> 标签: depup, latest, nanostores, patched, preact, react, react native, security, state, state manager, store, svelte, updated-dependencies, vue

## 简介

A tiny (372 bytes) state manager for React/Preact/Vue/Svelte with many atomic tree-shakable stores (with updated dependencies)
