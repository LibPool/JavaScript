# @depup/testcontainers

> 标签: depup, docker, latest, patched, security, testcontainers, testing, updated-dependencies

## 简介

Testcontainers is a NodeJS library that supports tests, providing lightweight, throwaway instances of common databases, Selenium web browsers, or anything else that can run in a Docker container (with updated dependencies)
