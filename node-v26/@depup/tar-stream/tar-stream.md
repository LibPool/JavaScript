# @depup/tar-stream

> 标签: depup, latest, patched, security, tar-stream, updated-dependencies

## 简介

tar-stream is a streaming tar parser and generator and nothing else. It operates purely using streams which means you can easily extract/parse tarballs without ever hitting the file system. (with updated dependencies)
