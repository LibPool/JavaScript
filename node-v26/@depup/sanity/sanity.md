# @depup/sanity

> 标签: cms, content, depup, headless, latest, patched, realtime, sanity, security, updated-dependencies

## 简介

Sanity is a real-time content infrastructure with a scalable, hosted backend featuring a Graph Oriented Query Language (GROQ), asset pipelines and fast edge caches (with updated dependencies)
