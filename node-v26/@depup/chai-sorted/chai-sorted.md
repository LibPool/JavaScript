# @depup/chai-sorted

> 标签: chai, chai-plugin, chai-sorted, depup, latest, patched, security, sort, updated-dependencies

## 简介

Chai JS Plugin for testing if an array has sorted values (strings, numbers, booleans). Very helpful when writing tests for features that implement Array.prototype.sort() (with updated dependencies)
