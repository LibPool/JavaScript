# minevo3d

> 标签: 3d-character, character-viewer, minecraft, minecraft-cape, minecraft-skin, react, react-component, skin-viewer, threejs, typescript, webgl

## 简介

Animated 3D Minecraft character viewer for React and vanilla JS with real bendable arms and legs, skins, capes, and animations. Built on three.js.
