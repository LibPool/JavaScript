# @gamesolutionslab/server_authentication

> 标签: JavaScript

## 简介

The aim of this package is to provide an easy way to authenticate users on node.js servers.     Authentication for browser to server can happen via `Google` and `JWT`.     Authentication for application to server can happen via `JWT`.
