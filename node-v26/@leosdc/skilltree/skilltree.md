# @leosdc/skilltree

> 标签: ai, claude, copilot, cursorrules, developer-tools, gemini, prompt-engineering, rules, skilltree, windsurf

## 简介

Modular skill tree compiler and AI rules manager for developer workspaces. Integrates dynamically with Cursor, VS Code, Windsurf, Claude Code, and Antigravity.
