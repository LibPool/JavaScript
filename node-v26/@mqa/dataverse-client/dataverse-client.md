# @mqa/dataverse-client

> 标签: cds, client-credentials, crm, dataverse, dynamics-365, dynamics-crm, dynamics-crm-webapi, msal, web-api

## 简介

V1-compatible Dataverse / Dynamics 365 Web API client for Node.js. Drop-in replacement for dynamics-web-api@1.x with a cached MSAL client-credentials token provider.
