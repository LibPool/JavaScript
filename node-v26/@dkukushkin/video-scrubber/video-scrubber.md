# @dkukushkin/video-scrubber

> 标签: drag, pointer-events, react, scrub, scrubber, swipe, video

## 简介

Drag-to-scrub HTML video: pointer and touch scrubbing with infinite wrap, optional autoplay, a framework-agnostic core and a React adapter.
