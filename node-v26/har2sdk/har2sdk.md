# har2sdk

> 标签: api, claude, codegen, devtools, graphql, har, mcp, mock-server, model-context-protocol, openapi, reverse-engineering, sdk, sdk-generator, typescript

## 简介

Turn browser network traffic (HAR) into a typed TypeScript SDK, an OpenAPI 3.1 spec and a mock server. Local, deterministic, no API key. Ships an MCP server so Claude can name and document every endpoint.
