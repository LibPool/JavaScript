# heading-beacon

> 标签: accessibility, github-action, h1, heading, heading-hierarchy, heading-structure, headings, html, sarif, seo, static-site

## 简介

Audit heading structure in your built static site: exactly one visible H1, no skipped levels, no empty, generic, duplicate, image-only or overlong headings, H1 vs title agreement and site-wide duplicate H1s. Text/JSON/SARIF/Markdown, allowlist with expiry
