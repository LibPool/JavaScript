# @playfast/tsagent

> 标签: TypeScript, agent, cli, language-service, refactoring, tsagent

## 简介

Agent-oriented TypeScript language service CLI: symbol maps, find-refs, rename, dead code, type intelligence, diagrams, speculative checks, and a session daemon — built on the native TypeScript compiler port (typescript-go).
