# @vaibot/claudecode-circuitbreaker-plugin

> 标签: agent-safety, ai-agents, audit, circuit-breaker, claude-code, governance, guardrails, hooks, plugin, provenance, vaibot

## 简介

VAIBot governance plugin for Claude Code — intercepts tool calls, classifies risk, enforces policy, and creates tamper-evident audit receipts with on-chain provenance anchoring.
