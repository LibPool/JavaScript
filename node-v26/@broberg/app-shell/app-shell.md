# @broberg/app-shell

> 标签: app-shell, broberg, notifications, preact, sidebar, topbar, user-menu

## 简介

The fleet's app shell: collapsible sidebar (phone: rail or drawer), top bar with the notification bell and user menu as standard, page header and tabs. Framework-free core + Preact (Stack B). Styled on @broberg/theme tokens. Avatar from BrobergID, initial
