# @broberg/fleet-client

> 标签: JavaScript

## 简介

Typed client for the broberg fleet HTTP API (buddy + cardmem). One import instead of hand-rolling fetch + Bearer + payload — typed end-to-end from @broberg/fleet-contracts.
