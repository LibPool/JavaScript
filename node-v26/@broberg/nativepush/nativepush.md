# @broberg/nativepush

> 标签: android, apns, broberg, capacitor, critical-alerts, fcm, firebase, ios, notifications, push

## 简介

Push to NATIVE apps for the broberg.ai fleet — Apple APNs (token auth, HTTP/2, critical / time-sensitive) and Google FCM HTTP v1 (high-priority, data-only) behind one sender with @broberg/webpush's contract: never throws, dead tokens to prune, failed with
