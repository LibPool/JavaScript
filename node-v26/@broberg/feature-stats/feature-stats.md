# @broberg/feature-stats

> 标签: analytics, broberg, counters, feature stats, feature usage, gdpr, hono, nextjs, no cookie, privacy, usage

## 简介

Which features are actually used: aggregate per-day counters (feature, day, count) with no user id, session, IP, path or cookie. Framework-free core, a SQL store for libSQL/Turso and Postgres, and thin Hono / Next / browser-beacon bindings.
