# @vuvanhieu/todaycode-base-game-engine

> 标签: JavaScript

## 简介

Game-agnostic, deterministic engine base (Engine contract, FrameDriver, seeded RNG, integer vec2, replay envelope). Games implement this contract in their own repos.
