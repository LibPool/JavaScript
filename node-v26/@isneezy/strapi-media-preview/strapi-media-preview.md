# @isneezy/strapi-media-preview

> 标签: cms, excel, media, pdf, preview, strapi, thumbnails, video, word

## 简介

A custom field for strapi that automatically generates thumbnails for uploaded PDF documents, Excel sheets, Word documents, and videos
