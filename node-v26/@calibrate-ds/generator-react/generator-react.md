# @calibrate-ds/generator-react

> 标签: calibrate, codegen, component-generator, design-system, design-to-code, design-tokens, figma, react, typescript

## 简介

Calibrate React generator — emits typed React components, CSS token files, and composite types from a DesignSystemModel. Implements the IGenerator interface for the Calibrate pipeline.
