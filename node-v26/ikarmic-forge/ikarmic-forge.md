# ikarmic-forge

> 标签: agent, ai, claude, cli, code-assistant, gemini, gpt, llm, mcp, ollama, openrouter, repl

## 简介

IKarmic AI Forge CLI: run AI coding agents from your terminal. Multi-model (OpenAI, Anthropic, Google, Ollama, OpenRouter), MCP, sandbox, project memory, plan mode, context compaction.
