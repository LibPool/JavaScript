# @joinhottub/depwatch

> 标签: cli, dependencies, inventory, monorepo, npm, outdated, pnpm, semver, workspaces, yarn

## 简介

Brand-neutral dependency-inventory core + CLI for JS/TS monorepos: scan declared dependencies, enrich with the latest published version, flag what's outdated, and export to CSV.
