# @keicoin/wallet

> 标签: balances, game, inventory, kei, wallet

## 简介

In-game wallet for Kei: mountable balance/inventory/claims panel, plus the headless summary API underneath it.

- 官网：https://keicoin.org#wallet
- 源码仓库：git+https://github.com/keicoin-org/kei-transaction.git
