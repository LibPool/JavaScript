# nacatamalon

> 标签: 2d, 3d, game-engine, gamedev, hooks, pixel-art, retro, typescript, webgl2, webgpu

## 简介

A retro-first 2D and 3D game engine for the web, on WebGPU with a WebGL2 fallback, written with hooks and plain functions.
