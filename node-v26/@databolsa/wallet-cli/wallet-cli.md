# @databolsa/wallet-cli

> 标签: carteira, cli, databolsa, wallet

## 简介

CLI da Wallet do DataBolsa (carteiras por workspace) — um comando por operação do contrato OpenAPI da Wallet. Autentica com a chave de API da plataforma (db_live_...).
