# @databolsa/credit-sdk

> 标签: credit, credito-privado, databolsa, fidc, openapi, sdk, typescript

## 简介

SDK TypeScript tipado para a API da mesa de crédito do DataBolsa (Credit Desk), gerado a partir do contrato OpenAPI do Credit.
