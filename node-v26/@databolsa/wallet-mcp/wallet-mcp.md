# @databolsa/wallet-mcp

> 标签: carteira, databolsa, mcp, model-context-protocol, wallet

## 简介

Servidor MCP da Wallet do DataBolsa (carteiras por workspace) — tools geradas a partir do contrato OpenAPI da Wallet. Autentica com a chave de API da plataforma (db_live_...).
