# @c2n/flow

> 标签: dag, diagram, flow, flowchart, graph, lit, pipeline, web component

## 简介

`c2-flow` draws a pipeline or dependency graph on a pannable, zoomable canvas: steps with a status, smooth edges, a built-in auto layout, draggable nodes saved to `localStorage`, a hover card and a context menu.
