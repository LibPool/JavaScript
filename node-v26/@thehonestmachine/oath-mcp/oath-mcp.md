# @thehonestmachine/oath-mcp

> 标签: accountability, ai-agents, certificate-transparency, merkle, oath, transparency

## 简介

An MCP server that swears AI agents under the OATH protocol: take an oath, log adjudicated actions, confess failures, and keep a verifiable ledger — in one config line.
