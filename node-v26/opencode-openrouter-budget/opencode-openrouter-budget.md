# opencode-openrouter-budget

> 标签: budget, cost, opencode, opencode-plugin, openrouter, plugin, spend, usage

## 简介

OpenCode plugin that surfaces real OpenRouter spend: per-request costs in the session sidebar, the model the router picked, key budget, and account credits
