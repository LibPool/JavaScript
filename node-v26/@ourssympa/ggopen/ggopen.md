# @ourssympa/ggopen

> 标签: cli, launcher, monorepo, projects, vscode, workspace

## 简介

CLI multi-plateforme pour lister ses projets (regroupés par source) et les ouvrir dans VS Code : backend + front, en workspace multi-root ou fenêtres séparées.
