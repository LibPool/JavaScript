# @jkudish/jev-browser

> 标签: agent, automation, browser, jev, mcp, model-context-protocol, playwright, typesafe

## 简介

A Jev-driven browser agent: give it a task and a start URL; typed Choice actions, stop/stuck safety gates, the final page, an auditable step trace, and a screenshot. MCP server, CLI, or library.
