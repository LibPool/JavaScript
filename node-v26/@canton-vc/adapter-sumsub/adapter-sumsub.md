# @canton-vc/adapter-sumsub

> 标签: adapter, canton, canton-vc, kyc, sumsub

## 简介

Sumsub KYC provider adapter for canton-vc. Wraps Sumsub's applicants API with per-request HMAC authentication (X-App-Access-Sig over ts+method+path+body) and the multi-algorithm webhook digest scheme (X-Payload-Digest), behind the vendor-agnostic KycProvi
