# @serpcheap/next

> 标签: app-router, google, next, nextjs, search, serp, serpapi

## 简介

Next.js helpers for the serp.cheap SERP API — server-side key handling, result caching via unstable_cache with per-query tags, Server Actions, and App Router route handlers.
