# @shekhardtu/hee-sdk

> 标签: custom-domains, edge, hee, lets-encrypt, multi-tenant, saas, tls

## 简介

Client library for the Hee custom-domain edge. Each SaaS product backend imports this to register / remove / list customer domains.
