# @archstone/provider-sql

> 标签: ai-agents, archstone, cdl, database, llm, mcp, model-context-protocol, postgres, provider, sql

## 简介

SQL provider for Archstone (ADR-0012) — binds a capability directly to Postgres, isolation enforced by RLS + transaction-scoped session identity, never by binding-author discipline.
