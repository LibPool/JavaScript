# @ohto/nuxt-gtm-ecommerce

> 标签: JavaScript

## 简介

A Nuxt 3 module that extends [`@zadigetvoltaire/nuxt-gtm`](https://github.com/zadigetvoltaire/nuxt-gtm) with a **typed API for Google Analytics 4 (GA4) ecommerce events**.
