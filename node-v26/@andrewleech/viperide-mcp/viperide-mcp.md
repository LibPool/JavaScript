# @andrewleech/viperide-mcp

> 标签: circuitpython, embedded, ide, mcp, micropython, repl, serial, viperide

## 简介

MCP server for controlling ViperIDE, a MicroPython/CircuitPython IDE. Connects to devices via USB serial, manages files, executes code, and provides full REPL access.
