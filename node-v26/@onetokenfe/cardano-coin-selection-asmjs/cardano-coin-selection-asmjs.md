# @onetokenfe/cardano-coin-selection-asmjs

> 标签: coin selection

## 简介

Minimal implementation of Cardano coin selection algorithms (see [CIP-2](https://cips.cardano.org/cips/cip2/)) developed solely for OneTokenHQ. Under the hood it leverages Cardano Serialization Lib via WASM module.
