# @tomosull/gridsome-source-wordpress

> 标签: gridsome, tomosull, wordpress

## 简介

Tomosull Fork of gridsome-source-wordpress 4.13 - WordPress source for Gridsome with image processing support. This fixes minor issues with the original plugin; namely 403 and image alt tags not loading.
