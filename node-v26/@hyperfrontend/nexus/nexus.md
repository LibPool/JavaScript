# @hyperfrontend/nexus

> 标签: browser, communication, contract-validation, cross-origin, cross-window, event-driven, hub-spoke, iframe, message-broker, message-channel, micro-frontend, microfrontend, origin-security, postmessage, typescript, window-messaging

## 简介

Secure cross-window communication library for micro-frontends with contract-validated messaging, origin-based security policies, and connection lifecycle management.
