# @chrisdudek/yg

> 标签: agentic-guardrails, agents-md, ai-agents, ai-assisted-development, ai-coding, architecture-enforcement, claude-code, claude-md, cli, code-guardrails, coding-agents, developer-tools, rule-engine, yggdrasil

## 简介

Say it once: a rule you write holds in every session after. Your AI coding agent gets only the rules that touch the file it is editing, and must satisfy them before it moves on. Free local checks, keyless CI. Works with Claude Code, Cursor, Copilot, Codex
