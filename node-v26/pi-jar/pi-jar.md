# pi-jar

> 标签: goal, model-roles, multi-agent, pi-extension, pi-package, pi-theme, plan-mode, terminal

## 简介

A warm, role-aware Pi terminal workspace with switchable profiles, animated UI, plan and goal workflows, tasks, change review, model roles, background shells and subagents.
