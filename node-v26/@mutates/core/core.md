# @mutates/core

> 标签: ast, mutations, typescript

## 简介

🔧 **@mutates/core** is the essential package of the Mutates toolset, providing the core functionality to manipulate the Abstract Syntax Tree (AST) of TypeScript files. It serves as the backbone for other specialized packages within the Mutates ecosystem.
