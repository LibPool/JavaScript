# @filingstudio/client

> 标签: 10-K, 10-Q, api-client, citations, edgar, filings, finance, provenance, sec

## 简介

Server-side client for the Filing Studio API: search SEC filings, resolve traces, verify claims. One call per door, typed results, your key never in a URL.
