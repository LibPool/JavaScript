# @ngjoy.dev/signalstate

> 标签: SignalState, angular, angular 16, angular signals, angular state management, ngrx alternative, reactive programming, redux alternative, state management

## 简介

SignalState is a smart, lightweight, and robust state management library for Angular 16+ applications, leveraging the power of Angular signals. No dependencies. No hooks. Just simple and powerful state management.
