# @wizeworks/silicaui-behaviors

> 标签: behaviors, design-system, runtime, silica, vanilla

## 简介

Silica UI's framework-agnostic runtime for the behavior marker contract — scans data-sui-* markers and wires interactivity for any host that renders plain markup.
