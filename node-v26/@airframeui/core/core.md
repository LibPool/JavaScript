# @airframeui/core

> 标签: accessibility, airframe, airframeui, css, design-system, design-tokens, machine-readable, ui

## 简介

Airframe UI Core, a structural UI design system for humans and AI. Machine-readable by design. Structure primitives, shells, design tokens, and accessible CSS patterns.
