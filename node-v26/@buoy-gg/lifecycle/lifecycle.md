# @buoy-gg/lifecycle

> 标签: appstate, background, debugging, deep-link, devtools, expo, lifecycle, low-power-mode, memory-warning, react-native, react-native-devtools, state-restoration, testing

## 简介

Lifecycle and interruption simulator for React Native: see what your app does when people leave it and come back. Background, interruptions, memory warnings, deep links, appearance, battery and relaunch.
