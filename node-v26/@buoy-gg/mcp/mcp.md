# @buoy-gg/mcp

> 标签: ai-agents, debugging, devtools, expo, flipper-alternative, llm, mcp, model-context-protocol, react-native, react-native-devtools

## 简介

MCP server for Buoy. Lets AI coding tools read and drive your running app (free account for the basic tools, Pro for the rest), and use the web in Chrome with Buoy Web (free, no account).
