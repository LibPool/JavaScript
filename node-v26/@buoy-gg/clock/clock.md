# @buoy-gg/clock

> 标签: clock, date, debugging, devtools, expo, fake-timers, mock-date, react-native, react-native-devtools, testing, time-travel

## 简介

Clock override for React Native: travel to any date, freeze or speed up time, and jump ahead while firing due timers. Test expirations, countdowns and renewals without touching the device clock.
