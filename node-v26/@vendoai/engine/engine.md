# @vendoai/engine

> 标签: agent, ai, vendo

## 简介

npx-fetched Agent SDK runner: harness job in, final agent text out. Not a dependency of any Vendo package — init's last-resort engine rung fetches it via `npm exec` at a pinned version so its ~250MB Claude Code binary never lands in a host app's install.
