# @selfbadge/sdk

> 标签: api, cli, identity, person, schema.org, selfbadge, verification

## 简介

The SelfBadge API in TypeScript: find people, read verified profiles and organizations, and the partner API. Includes the selfbadge command-line tool. No runtime dependencies.
