# @simnode/core

> 标签: JavaScript

## 简介

Simulation harness for SimNode. Orchestrates all modules: virtual clock, seeded PRNG, scheduler, HTTP/TCP interceptors, virtual filesystem, and fault injector. Provides `Simulation` class with `scenario()`, `run({ seeds })`, and `replay({ seed, scenario }
