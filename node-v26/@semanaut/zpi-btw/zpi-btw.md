# @semanaut/zpi-btw

> 标签: pi-package

## 简介

pi extension: /btw — ask a one-off side question answered by a separate model call, streamed into the live transcript and never written to the session. Minimal by design: no state, no branches, no config. Streaming and markdown rendering included; develop
