# @chonksxyz/studio

> 标签: canvas, drawing, editor, grid, keyboard-shortcuts, pixel-art, selection, undo

## 简介

A dependency-free toolkit for building pixel art studios: configurable grids, undo/redo history, draw and erase input, multi-cell selection with drag-to-move, configurable keyboard shortcuts, image export, and design persistence.
