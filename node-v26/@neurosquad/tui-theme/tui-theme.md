# @neurosquad/tui-theme

> 标签: JavaScript

## 简介

The NeuroSquad look for terminal UIs: palette with colour-depth downgrade, status glyphs, borders, the >S wordmark, harness logos (kitty / iTerm2 / sixel or glyphs) and frame-based animations.
