# onesignal-mcp

> 标签: mcp, mobile, notifications, onesignal, push

## 简介

Query the OneSignal API (free tier; use a current v2 Organization API key for ONESIGNAL_USER_KEY and the app REST API key for ONESIGNAL_APP_KEY, Basic auth).
