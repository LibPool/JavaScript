# @deph/cli

> 标签: audit, cyclonedx, dependencies, license, sarif, sbom, security, vulnerability

## 简介

Audit npm, pip and cargo dependencies for vulnerabilities, outdated versions and disallowed licenses, against a policy file in your repo.
