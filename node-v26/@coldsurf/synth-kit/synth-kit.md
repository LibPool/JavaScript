# @coldsurf/synth-kit

> 标签: audio, generative-music, music, synth, synthesizer, web-audio

## 简介

Color-blind Web Audio synthesis engines (wall, drumkit, bass, dub chamber, mixer strip) behind a VST-style engine/preset model. Browser-first; see README for offline-rendering caveats.
