# @analytickit/sdk-browser

> 标签: JavaScript

## 简介

Browser client for AgentGraph / AnalyticKit — pageview autocapture, event tracking, and a sliding visitor/session id, as a <12KB gzipped UMD/ESM bundle.

- 官网：https://analytickit.com
