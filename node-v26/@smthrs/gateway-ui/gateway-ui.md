# @smthrs/gateway-ui

> 标签: JavaScript

## 简介

Reusable React components for Smithers Gateway UIs — drop-in run lists, approval panels, node trees, event logs and launch controls built on @smthrs/gateway-react hooks. Use these to build a custom workflow UI under .smithers/ui/<workflow>.tsx.
