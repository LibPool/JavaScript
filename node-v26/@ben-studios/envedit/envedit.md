# @ben-studios/envedit

> 标签: JavaScript

## 简介

`envedit` is a simple CLI application used to manage environments. It allows you to create, edit, and delete custom environments, as well as control the variables within them. It is designed to be a simple and easy-to-use tool for managing environments.
