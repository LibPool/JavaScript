# dsh-plugin-skill-autoroute

> 标签: agent, cordis, deepseek-harness, dsh, dsh-plugin, llm, routing, skill, skill-router

## 简介

Automatic skill routing for DeepSeek Harness: every received user instruction gets exactly one routing pass over the live skill catalog, injected as a ranked brief, an auto-loaded SKILL.md body, or a forced router-skill call.
