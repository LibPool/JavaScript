# @violetice/string-to-ascii

> 标签: Violet_Ice紫冰, ascii, char, epub, string, violetice

## 简介

本项目的唯一功能是将字符串转换为 ASCII 编码，以此帮助 epub 小说绕过内容检测。

- 源码仓库：https://github.com/violetice/string-to-ascii.git
- npm 页面：https://www.npmjs.com/package/@violetice/string-to-ascii
