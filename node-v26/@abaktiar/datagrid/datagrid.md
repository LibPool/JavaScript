# @abaktiar/datagrid

> 标签: bulk-actions, context-menu, csv-export, customizable-buttons, data-table, datagrid, excel-export, filtering, floating-action-dock, floating-buttons, glassmorphism, material-design, pagination, react, responsive, row-selection, sorting, table, tanstack-table, typescript, virtualization

## 简介

A powerful, feature-rich React DataGrid component with TypeScript support, built on TanStack Table. Features customizable floating action dock, Excel/CSV export, and advanced row selection.
