# @smushytaco/rtlcss-webpack-plugin

> 标签: JavaScript

## 简介

Webpack plugin to use in addition to [extract-text-webpack-plugin](https://github.com/webpack/extract-text-webpack-plugin) to create a second css bundle, processed to be rtl.
