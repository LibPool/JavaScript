# @remnic/coding-graph

> 标签: codebase, coding-graph, extraction, knowledge-graph, memory, remnic, sqlite, symbols, tree-sitter, wasm

## 简介

Web-tree-sitter powered symbol-extraction engine + SQLite knowledge-graph store for codebase memory (Tier 1: TypeScript, TSX, JavaScript, Python, Go, Rust, Java, C, C++, C#, Ruby, PHP, Kotlin, Swift, Bash). Optional companion of @remnic/core — install onl
