# @wjmpantig/docusaurus-plugin-dbml

> 标签: JavaScript

## 简介

Render [DBML](https://dbml.dbdiagram.io/docs/) schemas as interactive diagrams in your Docusaurus site. Write a fenced code block, get a diagram.
