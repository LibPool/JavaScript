# @dokiworld/app-sdk

> 标签: JavaScript

## 简介

`@dokiworld/app-sdk` 是嵌入式游戏或 World App 与 DokiWorld 之间的版本化、类型安全契约。SDK 统一负责消息信封、生命周期身份校验、清理、标准 `dokiworld.app/2` 契约，以及现有 `dokiworld.game/1` 和 World v1 协议的兼容适配。
