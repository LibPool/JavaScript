## 简介

Vercel AI SDK tools for Arenza — drop-in tools you can pass to streamText / generateText so any agent (ChatGPT, Claude, Gemini, Perplexity, Copilot, Grok) can read AI visibility metrics, GEO opportunities, and brand mention data.
