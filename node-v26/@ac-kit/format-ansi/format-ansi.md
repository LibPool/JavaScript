# @ac-kit/format-ansi

> 标签: ansi, color, escape-codes, sgr, terminal

## 简介

ANSI/VT100/xterm escape sequences: stripping, cursor movement, OSC 8 hyperlinks, and SGR colour and style with colour-depth-aware downsampling.
