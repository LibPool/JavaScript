# @ac-kit/app-terminal

> 标签: ansi, color-depth, portable, terminal, tty

## 简介

The Terminal descriptor a rendering sink needs — interactivity, dimensions, colour depth, resize events, alt-screen support — injected rather than read from process.stdout.
