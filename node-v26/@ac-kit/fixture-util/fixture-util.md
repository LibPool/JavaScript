# @ac-kit/fixture-util

> 标签: checksum, fixtures, test-vectors, testing

## 简介

Infrastructure for packages that fetch a pinned, checksummed test-vector corpus: fetch-and-verify, zip extraction, a manifest-driven setup runner and fixture-directory resolution.
