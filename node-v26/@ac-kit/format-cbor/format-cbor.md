# @ac-kit/format-cbor

> 标签: binary, cbor, codec, edn, rfc8949

## 简介

CBOR (RFC 8949) codec: a binary encoder and decoder including an incremental one, a diagnostic-notation lexer, parser and printer, and a JSON bridge.
