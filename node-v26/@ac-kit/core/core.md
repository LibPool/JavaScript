# @ac-kit/core

> 标签: esm, portable, type-guards, typescript, utilities

## 简介

Foundational JavaScript and TypeScript extensions with no domain knowledge: guards, type helpers, collection and string utilities, JSON, pattern matching, promises, time, errors and a byte cursor.
