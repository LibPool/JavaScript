# @quadcore-lib/products-server

> 标签: JavaScript

## 简介

CRUD de productos para e-commerce, sobre NestJS + TypeORM. Lectura pública (storefront), escritura `admin`. Precio numérico, stock, imágenes, SKU único y soft-delete.
