# @quadcore-lib/storefront-ui

> 标签: JavaScript

## 简介

Componentes React listos para un storefront: `ProductCard`, `ProductGrid`, `CartDrawer`, `CheckoutForm`, `OrderTracker`. Construidos sobre los hooks de `@quadcore-lib/storefront-core` — este paquete es opcional y opinado, para proyectos que quieran arranc
