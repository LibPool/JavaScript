# @quadcore-lib/coupons-server

> 标签: JavaScript

## 简介

Cupones de descuento para e-commerce. Validación **pública** en el checkout, gestión **admin**. Soporta porcentaje/monto fijo, compra mínima, máximo de usos y vigencia.
