# @quadcore-lib/jobs-server

> 标签: JavaScript

## 简介

Cola de trabajos con **driver intercambiable** para procesos async (mails, webhooks, exportaciones). Módulo `@Global()`: inyectá `JobsService`. Trae `InMemoryQueueDriver` por defecto (ejecuta en proceso); reemplazalo por un driver BullMQ/Redis en prod.
