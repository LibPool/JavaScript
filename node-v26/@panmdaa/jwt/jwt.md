# @panmdaa/jwt

> 标签: auth, ecdsa, hmac, jwa, jws, jwt, panmdaa, rsa, token, typescript, zero-dependencies

## 简介

Zero-dependency TypeScript library for signing and verifying JSON Web Tokens (HMAC, RSA, ECDSA) based on RFC 7519/7515/7518
