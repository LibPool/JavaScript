# @aiquants/mssql

> 标签: deadlock, mssql, retry, sqlserver, transaction, typescript

## 简介

What SQL Server refuses, and how to stay inside it: retry a transaction only when it was the deadlock victim (keeping the cause the ORM destroys), split statements to fit the 2100-parameter limit, and read offset-less timestamps as UTC. No dependencies.
