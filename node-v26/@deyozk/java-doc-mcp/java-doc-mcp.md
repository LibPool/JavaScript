# @deyozk/java-doc-mcp

> 标签: ai, claude, cursor, documentation, java, javadoc, mcp, model-context-protocol, search

## 简介

MCP server that lets AI agents fetch, search and explore any publicly hosted JavaDoc website. Run locally with npx, works with any javadoc site.

- npm 页面：https://www.npmjs.com/package/@deyozk/java-doc-mcp
