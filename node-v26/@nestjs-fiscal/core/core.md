# @nestjs-fiscal/core

> 标签: JavaScript

## 简介

O pacote `core` contém as interfaces, entidades de domínio e os casos de uso base para emissão e assinatura de documentos fiscais. Ele define os contratos que as outras camadas do sistema deverão seguir.
