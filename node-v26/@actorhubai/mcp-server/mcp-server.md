# @actorhubai/mcp-server

> 标签: actorhub, ai, claude, consent, licensing, likeness, mcp, model-context-protocol, talent

## 简介

MCP server for ActorHub.ai, the platform where brands license verified real people for AI advertising. Lets Claude and other AI assistants check whether a face belongs to a verified person, and what they consented to, before generating.
