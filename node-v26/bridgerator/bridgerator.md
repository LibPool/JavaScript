# bridgerator

> 标签: ai-assistant, apps-sdk, bridge, chatgpt, chatgpt-connector, desktop-automation, local-files, mcp, mcp-server, model-context-protocol, openai, powershell, remote-files, windows

## 简介

Connect ChatGPT to your Windows PC: files, search and terminal through an outbound-only bridge with folder limits. No inbound ports, no admin rights.
