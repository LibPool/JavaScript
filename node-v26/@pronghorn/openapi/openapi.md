# @pronghorn/openapi

> 标签: bun, docs, nolly, openapi, plugin, pronghorn, swagger, zod

## 简介

OpenAPI 3.1 document generation and Swagger UI for Pronghorn, built directly from your routes' Zod schemas via z.toJSONSchema.
