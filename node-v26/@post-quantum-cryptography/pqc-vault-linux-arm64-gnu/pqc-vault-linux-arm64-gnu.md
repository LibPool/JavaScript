# @post-quantum-cryptography/pqc-vault-linux-arm64-gnu

> 标签: dilithium, encryption, hybrid, kyber, libcrux, ml-dsa, ml-kem, napi-rs, post-quantum, pqc, x25519

## 简介

Hybrid post-quantum encryption (X25519 + ML-KEM-768) and signatures (ML-DSA-65) for Node.js — libsodium-style API over the formally-verified libcrux backend.
