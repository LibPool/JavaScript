# @dokieli/web-access-control

> 标签: access control, acl, authorization, n3-patch, sparql-update, turtle, typescript, w3c, wac, web access control, web standards

## 简介

Web Access Control (WAC) client library: WAC-Allow header interpretation, effective ACL resource discovery, authorization queries, and pure ACL patch planning. The library allows clients to use their own RDF parsers and HTTP stacks.
