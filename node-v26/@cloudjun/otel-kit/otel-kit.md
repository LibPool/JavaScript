# @cloudjun/otel-kit

> 标签: logging, metrics, nestjs, observability, opentelemetry, otel, otlp, signoz, tracing, winston

## 简介

Zero-config OpenTelemetry bootstrap for Node.js services: traces, logs (winston), metrics over OTLP/HTTP. Works with SigNoz, Grafana, or any OTLP backend. Optional NestJS middlewares.
