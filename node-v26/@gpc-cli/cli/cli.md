# @gpc-cli/cli

> 标签: aab, android, android-publishing, apk, ci-cd, cli, devops, fastlane-alternative, google-play, google-play-api, google-play-console, google-play-console-cli, managed-google-play, play-console, play-developer-api, play-store, release-automation, rollout, typescript, upload

## 简介

GPC — Google Play Console CLI. 234 API endpoints including Managed Google Play. Upload AABs, manage releases, monitor vitals, publish private enterprise apps. Fastlane alternative for Android.
