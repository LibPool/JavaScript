# @shakil.rana.selisegroup/ckeditor5-line-limit

> 标签: ckeditor, ckeditor 5, ckeditor5, ckeditor5-feature, ckeditor5-plugin, line-count, line-limit, word-count, word-wrap

## 简介

A CKEditor 5 plugin that hard-wraps lines at a fixed number of characters, enforces a strict line limit and counts words, characters and lines.
