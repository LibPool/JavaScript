# @arrislink/dsh-compactor

> 标签: client-plugin, compaction, context-compression, deepseek-harness, dsh, llm, token-monitor

## 简介

DSH 客户端插件:实时 token 监控条、`/compact` 斜杠命令、自动触发压缩。解决“已达输出 token 上限、回答被截断、继续按钮无效”问题。
