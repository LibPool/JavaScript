> 标签: a11y, accessibility, angular, css, design-system, design-tokens, drift, less, linter, react, sarif, scss, static-analysis, svelte, tailwind, tailwindcss, tokens, vue

## 简介

Design-system enforcement engine for AI-generated code — parses CSS, SCSS, LESS, JSX, Vue, Angular, Svelte, and backend templates and checks them against your design tokens.
