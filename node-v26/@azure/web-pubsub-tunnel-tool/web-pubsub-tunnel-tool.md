# @azure/web-pubsub-tunnel-tool

> 标签: JavaScript

## 简介

A local tool to help tunnel Azure Web PubSub traffic to local web app and provide a vivid view to the end to end workflow.

## 官网

- 官网：https://github.com/azure/azure-webpubsub
