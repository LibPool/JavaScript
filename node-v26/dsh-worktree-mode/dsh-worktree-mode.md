# dsh-worktree-mode

> 标签: deepseek-harness, dsh, dsh-plugin, git, isolation, parallel-agents, worktree, worktree-mode, 隔离

## 简介

Worktree isolation as a session mode for DeepSeek Harness: one switch at task start buys an independent copy, an independent branch and a new session — no management panel to open. · 把 git worktree 做成 DSH 的「隔离运行」开关：发起任务时自动建独立副本 + 独立分支 + 新会话。
