# @struktek/mcp-bridge

> 标签: claude-code, codex, mcp, model-context-protocol, prompt, prompt-engineering, struktek

## 简介

Stdio MCP bridge for the Struktek VS Code extension. Serves your prompt templates to an agent as prompts, tools and resources — through the running extension when it is up, straight from disk when it is not.
