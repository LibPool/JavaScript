# @depraved/web-search-mcp

> 标签: ai-agent, mcp, mcp-server, search-api, web-fetch, web-search

## 简介

通用 Web Search MCP 服务器：多引擎搜索/抓取、多 Key 轮换与自动 fallback，stdio + Streamable HTTP 双模传输，附独立 Web 配置管理页，可接入任意 AI Agent。
