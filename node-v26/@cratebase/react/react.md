# @cratebase/react

> 标签: JavaScript

## 简介

First-party React hooks for @cratebase/client: a CratebaseProvider/useCratebase context, typed useRecords/useRecord/useInfiniteRecords/useMutation/useAuth/usePresence/useSubscription, and a createCratebaseHooks<Schema>() factory for collection-name-to-rec
