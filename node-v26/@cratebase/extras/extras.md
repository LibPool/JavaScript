# @cratebase/extras

> 标签: JavaScript

## 简介

Optional client extensions for Cratebase endpoints the official `pocketbase` SDK has no first-class surface for (vector search, MCP tool schemas, the LLM chat gateway, a client-side presence pattern). Bolts onto an existing PocketBase client instance rath
