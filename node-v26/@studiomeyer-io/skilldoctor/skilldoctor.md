# @studiomeyer-io/skilldoctor

> 标签: agent-skills, agents-md, ai-agents, claude, claude-code, linter, prompt-injection, sarif, security, supply-chain

## 简介

Linter and security scanner for AI-agent skill and instruction files (Claude Code SKILL.md, AGENTS.md, subagents). Prints an A-F grade, supports --fix, emits JSON + SARIF, ships as a GitHub Action.
