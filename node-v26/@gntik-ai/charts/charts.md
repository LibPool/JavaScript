# @gntik-ai/charts

> 标签: JavaScript

## 简介

Recharts 3 charts themed by the gntik-ui brand tokens: area, bar, line, combo, donut, bar list, funnel, sankey, radar, heatmap and mini bars, with token ramps, empty/loading/error states, threshold and annotation lines, a range brush and live series.

- npm 页面：https://www.npmjs.com/package/@gntik-ai/charts
