# @yidingdian/raft-cloud-sdk

> 标签: JavaScript

## 简介

raft 中间件北向客户端 SDK：经 queue binding(appCmdQ/recvQ) 消费 raft 暴露的 Thing，封装读写/批量/订阅与 raft 私有 *Ex 扩展
