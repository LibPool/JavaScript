# @waifucorp/aag

> 标签: ai-agents, code-graph, knowledge-graph, mcp, tree-sitter

## 简介

AboveAllGraphs — code knowledge graph that installs itself, stays fresh, and works with every coding agent. This package only downloads the prebuilt Rust binary for your platform; nothing is compiled.
