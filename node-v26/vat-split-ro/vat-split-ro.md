# vat-split-ro

> 标签: 394, declaration, e-factura, fiscal, romania, tax, vat

## 简介

Romanian VAT split library — largest-remainder method for splitting gross amounts into net + VAT per rate group (0%, 5%, 9%, 19%), conforming to eFactura vendor reference (HG 602/2025)
