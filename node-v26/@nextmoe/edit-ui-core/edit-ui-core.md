# @nextmoe/edit-ui-core

> 标签: diff, edit-ui, nextmoe, schema, typescript, wiki

## 简介

NextMoe edit-ui framework-free core — the wire/schema types of the schema-driven edit surface plus the pure diff, formatting and badge helpers. No Vue, no DOM framework.
