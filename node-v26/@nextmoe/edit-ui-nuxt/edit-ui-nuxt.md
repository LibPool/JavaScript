# @nextmoe/edit-ui-nuxt

> 标签: edit-ui, nextmoe, nuxt, nuxt-module, schema-form, vue

## 简介

NextMoe edit-ui Nuxt module — auto-imports the @nextmoe/edit-ui-vue components under a configurable prefix (default `Edit`), so a Nuxt app uses <EditSchemaForm> with no import.
