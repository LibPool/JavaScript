# @kodaeditor/angular

> 标签: angular, angular-component, angular-editor, docx, editor, html-editor, ngmodel, prosemirror, rich-text-editor, word-paste, wysiwyg

## 简介

Angular wrapper for KodaEditor: a WYSIWYG rich-text editor that keeps Word and Excel formatting on paste.
