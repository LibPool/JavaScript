# @wuilmerj24/country-code

> 标签: Android, JavaScript, NativeScript, TypeScript, iOS

## 简介

A NativeScript plugin to display country codes with flags. Use it in a modal or generate a fully customizable list for your app. Perfect for phone number inputs, country selection, and internationalization.
