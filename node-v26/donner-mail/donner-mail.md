# donner-mail

> 标签: ai-agent, claude, cli, email, fts5, full-text-search, local-first, mcp, mcp-server, privacy, search, sqlite, thunderbird

## 简介

Local full-text index for Thunderbird mail. Fast search, threads and SQL over your mailbox for AI agents — an index layer on top of thunderbird-cli.
