# @react-cards-opening/effects

> 标签: animation, canvas, celebration, confetti, effects, fireworks, gamification, gsap, loot-box, particles, react, screen-shake, shockwave, typescript

## 简介

64 effects for React, made to be stacked: particles on a canvas (sparks, confetti, embers, flames), light (rays, flares, lightning, a sigil), shockwaves and screen effects (shake, glitch, impact frames). One name each. GSAP inside, one stylesheet.
