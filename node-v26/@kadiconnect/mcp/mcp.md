# @kadiconnect/mcp

> 标签: business-card, digital-business-card, kadiconnect, mcp, model-context-protocol, qr-code

## 简介

MCP server for KadiConnect: create a digital business card, tracked links and analytics from any MCP client. Bridges stdio to the hosted server at https://kadiconnect.com/mcp.
