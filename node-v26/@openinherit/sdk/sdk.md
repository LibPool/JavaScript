# @openinherit/sdk

> 标签: api-client, bequest, code-generation, data-interchange, esm, estate, estate-planning, hey-api, inherit, inheritance, kinship, legal-tech, legaltech, open-data, open-standard, openapi, openapi-3.1, probate, succession, trusts, typescript, typescript-sdk, wills

## 简介

INHERIT estate planning SDK — TypeScript types, API client stubs, and validation for the open estate data interchange standard. Generated from OpenAPI 3.1 via hey-api. Supports estate, bequest, kinship, trust, executor, and 21 jurisdiction extension types
