# @roxy-agent/agents

> 标签: agent, ai-safety, audit, claude, codex, cursor, guardrail, human-in-the-loop, mcp, model-context-protocol, policy, proxy

## 简介

MCP server that proxies all agent actions, classifies risk, enforces natural-language policies, and logs to a local SQLite audit DB. View activity in the hosted dashboard at roxy-agent-web.vercel.app.
