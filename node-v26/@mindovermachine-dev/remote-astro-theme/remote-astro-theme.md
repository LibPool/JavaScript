# @mindovermachine-dev/remote-astro-theme

> 标签: astro, cli, documentation, remote-theme, starlight, theme

## 简介

CLI that builds/serves an Astro/Starlight site from a content-only repo, using a theme referenced by git ref or local path (Jekyll remote_theme-style).
