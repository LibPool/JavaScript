# @nrwlia/enet-node

> 标签: enet, networking, nodejs

## 简介

Node bindings for Growtopia's ENet. It is **NOT** ready for production. Inspired from [StileDevs' growtopia.js](https://github.com/StileDevs/growtopia.js) Contributions are welcome.
