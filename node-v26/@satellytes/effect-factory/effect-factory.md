# @satellytes/effect-factory

> 标签: JavaScript

## 简介

A helping hand for a fixed life cycle of our effects. The factory contains a runner that will take care of mounting und unmounting the effects. There is a global ESC Key handler as well as an api to control the current effect with an API.
