# @opendpp/eori

> 标签: customs, digital-product-passport, dpp, ec, economic-operator, eori, eori-validation, eos, esm, espr, european-commission, vat

## 简介

EORI number validation against the European Commission's official EOS validation web service, plus pure offline EORI syntax/parse helpers (ESM, Node >=26). From the OpenDPP Digital Product Passport service.
