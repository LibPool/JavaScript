# @seifer-webapp-factory/organizations

> 标签: JavaScript

## 简介

organizations — zevende capability-module: verticale, pluggable full-stack multi-tenancy (organisaties/teams: lidmaatschap, rollen, uitnodigingen, groepen, org-context) die de kits samenbindt via één contract. Eigendom is host-gedeclareerd per resource-ty
