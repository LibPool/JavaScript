# @fluentui-contrib/react-data-grid-react-window-grid

> 标签: JavaScript

## 简介

A variant of the Fluent UI [DataGrid](https://react.fluentui.dev/?path=/docs/components-datagrid--default) that is virtualized 2 dimentionally using [react-window](https://react-window.vercel.app/#/examples/grid/variable-size).
