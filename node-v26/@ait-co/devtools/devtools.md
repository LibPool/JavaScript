# @ait-co/devtools

> 标签: apps-in-toss, devtools, mini-app, miniapp, mock, sdk, simulator, testing, toss, vite-plugin, webpack-plugin

## 简介

Browser development tools for Apps in Toss mini-apps — mock SDK, floating devtools panel, and universal bundler plugin. devDependency only; contributes nothing to a production bundle
