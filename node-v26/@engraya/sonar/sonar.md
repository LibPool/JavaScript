# @engraya/sonar

> 标签: a11y, accessibility, charts, dashboard, data-visualization, kpi, react, sparkline, svg

## 简介

Accessibility-first React dashboard kit — zero-dependency SVG charts where every chart ships an aria summary and a hidden data table, plus KPI tiles, grids and filter primitives. Themeable via CSS variables; pairs with @engraya/fathom-ui.
