# @swp/wallet-sdk

> 标签: cryptocurrency, sdk, swipe, swp, wallet

## 简介

SwpWallet.js é um SDK para NodeJS, desenvolvido pela Swipe com o objetivo de facilitar a integração com a Swipe Wallet.
