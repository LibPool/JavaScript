# @fileconcat/cli

> 标签: ai, chatgpt, claude, cli, concatenate, context, file-concat, files, gemini, llm, repomix

## 简介

Privacy-first CLI for concatenating files into LLM context, with built-in text extraction for PDF, Office, RTF, Jupyter notebooks, SRT/VTT captions and EML messages
