# @kibamail/haraka

> 标签: email, haraka, kbmta, kibamail, server, smtp

## 简介

An SMTP Server project. A fork of Haraka by Matt Sergeant <helpme@gmail.com> (http://baudehlo.com/) with very little modifications to remove the disk based queue driver.

## 官网

- 官网：http://haraka.github.io
- 源码仓库：git://github.com/kibamail/haraka.git
- npm 页面：https://www.npmjs.com/package/@kibamail/haraka
