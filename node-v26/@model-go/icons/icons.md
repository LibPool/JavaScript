# @model-go/icons

> 标签: brand-icons, llm, model-icons, modelgo, vendor

## 简介

ModelGo 模型广场厂牌图标库：厂牌图标（SVG）+ vendor 别名索引 + 厂牌主色，一处维护，控制台与运营后台共用。
