# @rqt/namecheap-web

> 标签: api, domain, domains, namecheap, namecheap-web, rqt, web

## 简介

An API To Namecheap.com Via The Web Interface, With An Ability To Log In Using 2-Factor Auth To Whitelist IPs And Check Whois And Coupons.
