# @sometic/data-table

> 标签: a11y, data-grid, data-table, javascript, pagination, sometic, ssr, typescript, virtualization

## 简介

Framework-free data table and grid state for Sometic: columns, sorting, filtering, pagination, bulk selection, URL sync, and virtual window math.
