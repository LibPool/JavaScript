# @lingua-api/react-intl

> 标签: JavaScript

## 简介

Write source strings inline with [react-intl](https://formatjs.github.io/docs/react-intl). Ids are content hashes, so there are no keys to invent: `t(message, values)` takes the message text itself (no namespaces). `lingua extract && lingua translate` pop
