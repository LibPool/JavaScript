# @lingua-api/next-intl

> 标签: JavaScript

## 简介

Write source strings inline with [next-intl](https://next-intl.dev). Each message is looked up in the next-intl catalog by its content hash (`messageId(message, context)`); when the translation is missing, the inline message is formatted with next-intl's
