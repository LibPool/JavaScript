# afriradar

> 标签: ai-agents, kenya, mcp, micropayments, mutual-funds, nigeria, sec-nigeria, solana, usdc, x402

## 简介

Buy African fund data (SEC Nigeria weekly, CMA Kenya quarterly) per request, paid in USDC on Solana over x402. SDK, CLI and MCP server for the AfriRadar Data API.

## 官网

- 官网：https://api.afriradar.com
- 源码仓库：git+https://github.com/Risingtell/afriradar-api.git
