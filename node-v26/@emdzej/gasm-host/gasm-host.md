# @emdzej/gasm-host

> 标签: emulator, game, gamedev, gasm, runtime, wasm, webassembly, webgpu

## 简介

Run gasm games (portable WebAssembly games) in the browser or Node: the gasm ABI host with WebGPU, WebSocket networking, storage and a headless runner
