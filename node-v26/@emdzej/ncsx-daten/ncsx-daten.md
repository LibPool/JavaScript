# @emdzej/ncsx-daten

> 标签: JavaScript

## 简介

Parser for BMW NCSEXPER DATEN binary-frame files (BR_REF.DAT, *SGET.000, *SGVT.000, *.Cxx, etc.). Spec: ../../docs/daten-format.md
