# @emdzej/j2534-webserial

> 标签: browser, diagnostics, j2534, openport, passthru, tactrix, transport, typescript, web-serial

## 简介

Browser Web Serial API transport for @emdzej/j2534-driver. Talks to the Tactrix OpenPort 2.0 directly from Chrome/Edge — no native dependencies, runs in any modern Chromium-based browser.
