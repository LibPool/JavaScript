# @emdzej/j2534-serial

> 标签: cdc-acm, diagnostics, j2534, node, openport, passthru, serial, serialport, tactrix, transport, typescript

## 简介

Node.js CDC ACM serial transport for @emdzej/j2534-driver. Talks to the Tactrix OpenPort 2.0 via /dev/cu.usbmodem* (macOS) / /dev/ttyACM* (Linux) / COMx (Windows) — no sudo required.
