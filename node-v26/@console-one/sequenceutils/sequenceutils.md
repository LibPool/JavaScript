# @console-one/sequenceutils

> 标签: agent, policies, react, sequence, substrate, tools, transport

## 简介

Companion utilities for @console-one/sequence: agent loop, indexSpec policies, base tools (fs/http/schedule), WebSocket transport, and React UI hooks. Each area is a separate subpath import.
