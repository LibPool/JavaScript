# @lark-apaas/dataloom

> 标签: JavaScript

## 简介

面向 `@lark-apaas` 的浏览器端 Dataloom SDK，当前聚焦于 `service` 与 `storage` 两部分能力。该包由原 `@data-loom/js` 相关能力迁移并精简而来，仅保留当前客户端实际需要的功能。
