# @lark-apaas/coding-design-lint

> 标签: buildless, design-html, lint, miaoda, oxlint

## 简介

Miaoda design-html lint engine — own HTML layer (script extraction + platform contract rules) + oxlint for JS/JSX. Consumed by miaoda-cli `miaoda lint` via machine-level cache; never installed into user projects.
