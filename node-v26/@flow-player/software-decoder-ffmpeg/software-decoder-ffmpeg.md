# @flow-player/software-decoder-ffmpeg

> 标签: esm, ffmpeg, flow-player, h265, hevc, software-decoder, wasm

## 简介

FFmpeg (ffdecoder) WASM software decode backend for @flow-player/browser-runtime: prebuilt adapter + decode worker, drop-in HEVC software decoding.
