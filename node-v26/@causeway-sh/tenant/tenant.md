# @causeway-sh/tenant

> 标签: JavaScript

## 简介

Tenant-program helpers — parameterised by tenantProgramId. PDA derivers, status pollers, completed-signature decoders, plus instruction builders for the standard initiate-send ABI shipped with Causeway's reference tenant.
