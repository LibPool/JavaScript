# @eldrajs/theme-nuxt

> 标签: cms, eldra, headless, nuxt, nuxt-module, theme

## 简介

Nuxt module for Eldra themes: wires @eldrajs/vite-plugin-theme, the gateway client, draft overlays and the Studio preview bridge into a Nuxt 4 site.
