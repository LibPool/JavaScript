# @eldrajs/vite-plugin-theme

> 标签: cms, eldra, theme, vite, vite-plugin

## 简介

Vite plugin for Eldra themes: scans blocks/*/block.json, validates them, emits the theme manifest and the virtual modules the runtime reads (blocks, manifest, block fields, breakpoints, tokens CSS).
