# @gtmi/mcp-status-callback

> 标签: callback, mcp, relay, twilio, webhook, websocket, wss

## 简介

Public HTTPS callback URLs for local development via a Twilio-account-authenticated WSS relay. No ngrok, no local HTTP listener.
