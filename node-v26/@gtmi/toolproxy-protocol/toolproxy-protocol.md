# @gtmi/toolproxy-protocol

> 标签: gtmi, mcp, protocol, tunnel, zod

## 简介

Wire protocol for the Twilio MCP tool-proxy tunnel (connector ⇄ controller): Zod schemas for protocol majors 1, 2 and 3, derived types, a version-negotiating frame parser, and tool-name helpers.
