# @forgesworn/moneyer

> 标签: bearer-notes, bitcoin, cln, lightning-network, lnd, lnurl, lnurlcash, lud-03, lud-06, lud-12, lud-25, mint, nostr, sqlite, typescript

## 简介

An LNURLcash (LUD-25) mint - strikes Lightning bearer notes. Independent implementation, cln/lnd funding sources, SQLite, zero HTTP framework.
