# @forgesworn/tessera-kit

> 标签: binary-fuse, filter, membership, nostr, presence, privacy, schnorr

## 简介

Privacy-preserving membership-presence filter — build, test, sign, and serialize a non-enumerable Binary Fuse filter so clients answer "is this person here?" locally.
