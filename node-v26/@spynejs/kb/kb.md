# @spynejs/kb

> 标签: agent-knowledge-base, ai-agents, documentation, framework, frontend, knowledge-base, llm-context, spynejs

## 简介

The SpyneJS Generative Grammar — what AI agents read to write well-formed SpyneJS. Content-only package: cards (the operations), records (the constructions), the mental model, and the trees that route any task to them; versioned with framework releases.
