# @fullstacktechnyc/passwordless-oauth

> 标签: auth, authentication, github, google, oauth, oidc, passwordless, self-hosted, sign-in

## 简介

Optional, off-by-default OAuth login plugin for @fullstacktechnyc/passwordless-core — Google (OIDC) + GitHub. Dependency-free (fetch + WebCrypto).
