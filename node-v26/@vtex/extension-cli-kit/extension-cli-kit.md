# @vtex/extension-cli-kit

> 标签: JavaScript

## 简介

Shared contract of the vtex extension CLI: Finding, the error envelope, exit codes, CommandDefinition, the kind provider contract (KindProvider and its types, version 0) and the bundled envelope schemas (accounts.yaml, extension.yaml, asset.yaml).
