# @pbroom/color-kit

> 标签: apca, color, color-engine, color-picker, color-space, contrast, display-p3, gamut, oklch, react

## 简介

A queryable color-space engine for building color tooling: OKLCH-canonical conversion, contrast, gamut geometry, and plane queries, with React bindings as one consumer
