# @microtoll/mcp

> 标签: documentation, end-to-end-encryption, mcp, mcp-server, model-context-protocol, scaffold

## 简介

Microtoll Engine inside your coding tool: docs search, page reading and a project scaffold over the Model Context Protocol (stdio). Zero dependencies, no network, nothing runs but what is in src/.
