# @microtoll/mailbox

> 标签: JavaScript

## 简介

Pairwise unlinkable delivery: direct invitations dropped under a mailbox label only the two parties can compute, signed with the recipient and the mailbox bound in, sealed to the recipient. Web Crypto only.
