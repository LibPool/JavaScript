# @scene-grid/engine

> 标签: audio, audio-engine, game-audio, scenegrid, web-audio-api, webaudio

## 简介

High-performance AudioWorklet-based runtime engine for SceneGrid, handling low-latency signal routing, polyphony culling, and orchestration.
