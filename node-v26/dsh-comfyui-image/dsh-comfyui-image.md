# dsh-comfyui-image

> 标签: comfyui, cordis, deepseek-harness, dsh, dsh-plugin, image-generation, img2img, inpaint, remove-background, stable-diffusion, text2img, 图片生成

## 简介

DSH 图片生成插件：本地 ComfyUI 后端，对外只暴露一个统一的 generate_image 工具（文生图 / 图生图 / 局部重绘 / 背景移除）。A DSH image-generation plugin backed by a local ComfyUI server.
