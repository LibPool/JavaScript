# @kpanks/browser

> 标签: agent, browser, cdp, playwright, praetor

## 简介

Praetor-native browser agent runtime. DOM-first via Chrome DevTools Protocol (lazy playwright-core peer). Stagehand-shaped natural-language act() over CDP. Vision fallback via PraetorScreen for canvas / anti-bot pages.
