# @hackolade/sharp

> 标签: avif, crop, dzi, embed, gif, image, jp2, jpeg, libvips, png, resize, svg, thumbnail, tiff, vips, webp

## 简介

Re-published version to have all prebuilds defined as npm packages without platform constraints for cross building an Electron application - High performance Node.js image processing, the fastest module to resize JPEG, PNG, WebP, GIF, AVIF and TIFF images
