# @meyvoid/core

> 标签: JavaScript

## 简介

MeyVoid generic core — sigils, eye tracking, QR, maps, backgrounds, tokens, money, images, Supabase factories, Zustand persist, auth gate, UI primitives. Source-only, no build.
