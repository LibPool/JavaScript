# @cmrenus/oxlint-plugin-boundaries

> 标签: architecture, boundaries, dependency-rules, lint, monorepo, oxc, oxlint, oxlint-plugin

## 简介

Config-driven cross-package / element-type boundaries enforcement for oxlint — a resolver-less JS plugin. Each repo declares its own element table and allow-matrix in `.oxlintrc.json` settings.
