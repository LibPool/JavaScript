# @pattern-js/mod-email-smtp

> 标签: driver, email, mod, nodemailer, pattern, smtp

## 简介

SMTP driver for @pattern-js/mod-email, built on nodemailer — any relay, your own server, or a local catcher. Host/port/user are account options in admin → System → Email; the password comes from the vault or an env var.
