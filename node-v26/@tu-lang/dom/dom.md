# @tu-lang/dom

> 标签: custom-elements, dom, hydrate, mount, runtime, tu, tu-lang

## 简介

Browser-only Tu runtime — mount/hydrate/defineCustomElement plus typed re-exports of DOM globals (`document`, `Event`, `HTMLElement`, …). Importing from this package is the explicit opt-in to the DOM platform.
