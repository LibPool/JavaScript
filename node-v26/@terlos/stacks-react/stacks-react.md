# @terlos/stacks-react

> 标签: hooks, payments, privacy, react, stacks, zk-stark

## 简介

React bindings for Stacks Shield: a provider, hooks for the private balance and paying privately (amounts or payment requests), payment status polling, and a pay-with-Stacks-Shield link.
