# @pedep/ngx-kitsu

> 标签: JavaScript

## 简介

Angular 13+ port of the [kitsu](https://github.com/wopian/kitsu) jsonapi client, based on Angular's HttpClient and [kitsu-core](https://github.com/wopian/kitsu/tree/master/packages/kitsu-core).
