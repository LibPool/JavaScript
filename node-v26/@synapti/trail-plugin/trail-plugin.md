# @synapti/trail-plugin

> 标签: ai, change-control, claude-code, claude-code-plugin, code-review, hooks, live-capture, pr, trail

## 简介

Trail v0.2 live-hook capture — Claude Code plugin. Subscribes to PostToolUse, UserPromptSubmit, SessionStart, SessionEnd hooks and builds the packet incrementally. Augments (does not replace) the post-hoc @synapti/trail-capture CLI.
