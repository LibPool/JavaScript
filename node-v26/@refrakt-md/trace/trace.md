# @refrakt-md/trace

> 标签: JavaScript

## 简介

CLI plugin for Refrakt Trace — GitHub device-flow login and related commands, loaded by @refrakt-md/cli as refrakt planhub <verb> (the canonical refrakt trace <verb> alias lands in v2.0.0).
