# @sofa-design/nav-ui

> 标签: JavaScript

## 简介

Sofa-nav-ui is a React UI navigation component library based on the Sofa Design design system. It is mainly used for developing navigation bars and sidebars in enterprise-level backend products, providing a unified interaction for switching between tenant
