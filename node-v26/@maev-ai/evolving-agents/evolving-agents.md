# @maev-ai/evolving-agents

> 标签: cognition, knowledge-graph, maev, memory, openclaw, plugin

## 简介

MAEV — Memory Architecture for Evolving Agents. Currently ships the OpenClaw memory plugin: knowledge graph, multi-hop retrieval, lifecycle management, and experiential learning via a maev server.
