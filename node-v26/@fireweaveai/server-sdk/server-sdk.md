# @fireweaveai/server-sdk

> 标签: bun, control-points, deno, feature-flags, fireweave, progressive-delivery, release-engineering, server

## 简介

Fireweave release-engineering SDK for server runtimes (Node, Bun, Deno): control points and target registration. Zero runtime dependencies (spec v0.1.0).
