# @omostan/angularjs-file-upload-model

> 标签: angular, angular-js, angularjs, directive, file, file-picker, file-upload, filePicker, fileUpload, upload

## 简介

AngularJS directive used for picking up file(s) on input of type file to be made available in the $scope and assigned to the binded model
