# @realitycollective/service-framework-native

> 标签: hermes, native, openxr, realitycollective, runtime-adapter, service-framework, session, typescript, visionos, webxr

## 简介

Native host bindings for the Reality Collective TypeScript Service Framework: a runtime adapter and byte I/O over the host object a native XR app installs.
