# @uengage.io/platform-sdk

> 标签: audit, business, events, hmac, platform, realtime, sdk, uengage, upsell

## 简介

Client SDK for the uEngage platform API (audit, business, zones, wallet, upsell, auth, events). Single createClient(...) factory; OAuth2 client_credentials, static Bearer, or legacy session-token auth modes. Browser-safe realtime client at the /realtime s
