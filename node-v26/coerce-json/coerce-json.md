# coerce-json

> 标签: ai, ajv, anthropic, coerce, coercion, json, json-schema, llm, openai, repair, schema, structured-output, validation, zod

## 简介

Zero-dependency repair & schema coercion for LLM JSON output — turn almost-valid model output into a value that fits your Zod (or JSON Schema) schema, and get every fix logged.
