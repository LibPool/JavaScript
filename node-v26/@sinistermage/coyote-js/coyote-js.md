# @sinistermage/coyote-js

> 标签: framework, jsx, no-vdom, reactive, router, signals, store, web-worker

## 简介

A from-scratch, TypeScript-native, fine-grained reactive UI framework: signals, a no-VDOM JSX renderer, a client router, a typed worker-RPC pool, and a fine-grained store.
