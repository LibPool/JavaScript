# @liujia307/falinks

> 标签: agents, ai, claude-code, cli, codex, iterm2, mcp, multi-agent, orchestration

## 简介

把多个终端 AI CLI（Claude Code、Codex…）编排成一间办公室：分屏真实窗口里的员工，通过 MCP 总线互相对话协作，外加一个控制台。
