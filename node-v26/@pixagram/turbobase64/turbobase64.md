# @pixagram/turbobase64

> 标签: 128bits, C, SIMD, alternative, b64, base64, decode, encode, fast, javascript, optimization, performance, simd

## 简介

Fast, strict base64 for JavaScript: the engine's native Uint8Array.toBase64/fromBase64 where they exist, a scalar asm.js kernel everywhere else, plus a SIMD128 (SIMD.js-style) transcription of the Muła–Lemire vectorized algorithm.
