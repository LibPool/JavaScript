# matterbridge-homewizard-power

> 标签: apple-home, electrical-sensor, energy, homewizard, matter, matterbridge, p1, plugin

## 简介

Matterbridge plugin that reads HomeWizard P1 / kWh / socket / battery measurements and exposes them as Matter Electrical Sensors for Apple Home energy.
