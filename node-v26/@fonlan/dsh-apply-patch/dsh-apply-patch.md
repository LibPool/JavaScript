# @fonlan/dsh-apply-patch

> 标签: apply-patch, codex, deepseek-harness, dsh, plugin, sandbox, tool

## 简介

DSH plugin: a codex-style apply_patch tool (*** Begin Patch / *** Update File / *** Add File / *** Delete File) injected into the model toolset through DSH's built-in sandbox, with a settings card to choose injection scope (off / GPT models only / all mod
