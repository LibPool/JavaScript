# claude-tabs

> 标签: accounts, claude, claude-code, cli, multi-account, profiles, usage, vscode

## 简介

Many Claude Code accounts on one Mac: one CLAUDE_CONFIG_DIR profile per account, shared memory, usage of every account, per-tab switching.
