# @blendededge/simple-koa-shopify-auth

> 标签: auth, koa, middleware, shopify

## 简介

A better, simplified version of the (no longer supported) @Shopify/koa-shopify-auth middleware library. It removes the use of cookies for sessions (which greatly smooths the auth process), replaces a deprecated API call, and supports v2 of the official @s
