# @ausca/ai-sdk

> 标签: agents, ai-sdk, ausca, payments, tools, vercel, x402

## 简介

Vercel AI SDK tools that pay for HTTP 402 APIs over x402 instead of carrying API keys. Works with any x402 v2 resource; Ausca is the default example.
