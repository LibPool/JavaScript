# @dawipong/mcp-undraw

> 标签: ai, claude, illustrations, mcp, modelcontextprotocol, open-source-art, svg, undraw

## 简介

MCP server for unDraw — search and fetch free SVG illustrations from inside any MCP client, with auto-refreshing local catalog and on-demand color customization
