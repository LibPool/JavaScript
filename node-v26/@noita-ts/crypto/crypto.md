# @noita-ts/crypto

> 标签: JavaScript

## 简介

Hashes (MD5, SHA-1, SHA-256, SHA-384, SHA-512, and their HMAC) and secure random bytes for unsafe Noita mods, from the CNG of Windows (bcrypt.dll), and Ed25519 signature verification (SSH signatures too) in plain Lua, without a DLL to ship.
