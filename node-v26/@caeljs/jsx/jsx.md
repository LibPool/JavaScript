# @caeljs/jsx

> 标签: async, dom, framework, jsx, lightweight, reactive, router, spa, ssr, static

## 简介

ASYNC JSX/SSR framework for building modern web applications with component-based templates. It offers a lightweight virtual DOM, intelligent routing system, and reactive components with no external dependencies. Designed to generate optimized static webs
