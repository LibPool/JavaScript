# @betterfeedback/react-native

> 标签: betterfeedback, bug-report, expo, feedback, react-native, screenshot

## 简介

Screenshot-triggered in-app feedback for React Native / Expo apps — take a screenshot, describe the bug (type or hold-to-dictate), it lands in your betterfeedback dashboard with AI triage. Zero UI footprint, dev/testing only.
