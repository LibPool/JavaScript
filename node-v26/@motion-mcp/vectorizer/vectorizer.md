# @motion-mcp/vectorizer

> 标签: JavaScript

## 简介

Video-to-vector pipeline: ffmpeg frame extraction, deterministic median-cut quantization, contour tracing into layered SVG, and temporal keyframe reduction into a flipbook SceneDoc.
