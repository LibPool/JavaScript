## 简介

This is a CMake file formatter, spiritually inspired by [Christopher Chedeau's](https://blog.vjeux.com/) excellent [Javascript formatter, Prettier](https://prettier.io). Having also had to deal with [clang-format](https://clang.llvm.org/docs/ClangFormatSt
