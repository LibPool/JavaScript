# dsh-whale-files

> 标签: android, deepseek-harness, dsa, dsh, dsh-plugin, dsha, file-manager, file-transfer, no-root, zip-upload

## 简介

鲸鲸文件箱：给手机端 DSHA 用户的无 root 文件传输与管理插件——绕开 Android 存储隔离，在设置页里传文件、传 zip 目录、移动、重命名、预览，一键存到手机 Download/DSHA
