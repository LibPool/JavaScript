# @molecare/rn-trace

> 标签: debugging, event-loop-lag, js-thread, performance, re-render, react, react-native, tracing, typescript

## 简介

Find out why a tap did nothing: JS-thread stalls, slow tap-to-response, repeat taps and the props behind re-renders, for React Native and React. Plain TypeScript, no native code, readable in release builds.
