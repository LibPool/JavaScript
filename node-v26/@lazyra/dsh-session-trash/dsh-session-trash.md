# @lazyra/dsh-session-trash

> 标签: cordis, deepseek-harness, dsh, plugin, recycle-bin, restore, session, trash

## 简介

Recoverable session deletion for DeepSeek Harness: move sessions to a trash folder, restore them from a UI page, and purge automatically after 7 days.
