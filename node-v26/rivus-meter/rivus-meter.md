# rivus-meter

> 标签: agents, http-402, metering, payments, streaming-payments, tempo, usage-billing

## 简介

Pay-per-second billing for compute and APIs on Tempo: meter an endpoint in a few lines, pay for one from an agent, refund whatever isn't used.
