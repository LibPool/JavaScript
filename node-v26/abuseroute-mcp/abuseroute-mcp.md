# abuseroute-mcp

> 标签: abuse, abuse-contact, cert, mcp, mcp-server, model-context-protocol, phishing, rdap, security, soc, takedown

## 简介

MCP server for the AbuseRoute API: gives AI assistants a lookup_domain tool that returns the registrar and hosting-network abuse contacts for a domain.
