# @farbi/mcp

> 标签: ai, claude, farbi, image-generation, mcp, model-context-protocol, stdio

## 简介

Connect any stdio MCP client (Claude Desktop, …) to the Farbi MCP server — generate, edit and publish images from your AI tools.
