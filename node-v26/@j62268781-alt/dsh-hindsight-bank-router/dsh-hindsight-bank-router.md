# @j62268781-alt/dsh-hindsight-bank-router

> 标签: agent-memory, bank, bank-router, deepseek, deepseek-harness, dsh, dsh-plugin, hindsight, memory

## 简介

把 Hindsight 编码插件的 bank 身份锚定到远程仓库名，而不是本地目录名 —— 让同一仓库在不同克隆目录名下共享同一个记忆库。Anchors Hindsight coding-agent memory banks to the remote repository name instead of the local directory name, so every clone of a repo shares one bank.
