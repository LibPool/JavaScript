# @sebas-dv/shadcn-theme-editor

> 标签: css-variables, live-preview, oklch, shadcn, shadcn-ui, tailwind-v4, tailwindcss, theme, theme-editor

## 简介

Run the shadcn Theme Editor companion server for any dev setup (Next.js, or as a standalone). Serves the live overlay and writes theme changes to your CSS.
