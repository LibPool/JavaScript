# @sebas-dv/shadcn-theme-editor-overlay

> 标签: live-preview, oklch, overlay, shadcn, shadcn-ui, shadow-dom, theme-editor

## 简介

Framework-agnostic, Shadow-DOM overlay UI for editing shadcn theme tokens live. Talks to the companion server's scan/apply API.
