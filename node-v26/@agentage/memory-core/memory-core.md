# @agentage/memory-core

> 标签: agent-memory, agentage, ai-memory, git, knowledge-base, markdown, mcp, memory, model-context-protocol, notes, storage, vault

## 简介

Markdown memory engine for AI agents: read, write, search and version notes in a git-backed vault. One storage-agnostic contract, a bare-git store, a multi-vault container and an @vault/path router - the local engine behind agentage Memory and @agentage/s
