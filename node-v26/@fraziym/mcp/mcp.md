# @fraziym/mcp

> 标签: agent, ai, axoniz, fraziym, mcp, tool-use, tools, xorvoid

## 简介

Fraziym MCP — shared agent toolbelt. Hardcoded, importable tool groups that wrap @fraziym/axoniz tool classes (files, shell, web, code, axodex) plus git, for the axo ecosystem's agents.
