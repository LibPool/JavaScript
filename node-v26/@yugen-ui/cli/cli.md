# @yugen-ui/cli

> 标签: cli, components, react, registry, scaffold, tailwindcss, templates, yugen-ui

## 简介

CLI for Yugen UI: create an app from a template, set up Yugen UI in an existing project, add component source from the registry and diagnose the setup.
