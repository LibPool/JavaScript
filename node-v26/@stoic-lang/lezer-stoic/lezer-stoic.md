# @stoic-lang/lezer-stoic

> 标签: JavaScript

## 简介

This is a Stoic grammar for [Lezer](https://lezer.codemirror.net/). Lezer is a JavaScript-based system heavily inspired by tree-sitter: [good read](https://marijnhaverbeke.nl/blog/lezer.html).
