# mexicoapi

> 标签: banxico, clabe, cli, cliente http, cnbv, curp, código postal, días hábiles, fix, inegi, isr, mexico, méxico, nss, rfc, salario mínimo, sat, sepomex, udis, uma

## 简介

Validadores, datos oficiales y cliente HTTP de MéxicoAPI: CLABE, RFC, CURP, NSS, días hábiles, FIX, UDIS, UMA, salario mínimo e ISR. Con CLI y descarga local de los códigos postales de SEPOMEX. Sin dependencias.
