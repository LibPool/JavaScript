# @foleyjs/core

> 标签: audio feedback, haptics, interaction sounds, microinteractions, sound design, sound effects, sound set, ui sound library, ui sounds, web audio

## 简介

Sound effects for the interface, performed live. 28 interaction cues synthesized with Web Audio — zero dependencies, zero audio files.
