# @ultratestbro/wdk-protocol-swidge-router

> 标签: bridge, cross-chain, swap, swidge, wdk

## 简介

WDK swidge (cross-chain swap+bridge) protocol — NEAR Intents, LI.FI, THORChain, Omniston behind one router. Conforms to @tetherto/wdk-wallet SwidgeProtocol.
