# @teral-americas/react-native-screen-shield

> 标签: android, expo, expo-module, flag-secure, ios, privacy, react-native, screen-capture, screen-recording, screenshot, security

## 简介

Bloquea capturas de pantalla, grabación y mirroring en iOS y Android. En iOS deja un placeholder de marca horneado en la imagen capturada en lugar de un rectángulo negro.
