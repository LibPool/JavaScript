# @pubid/pubid

> 标签: conformance, identifier, iec, ieee, iso, nist, pubid, standards

## 简介

TypeScript PubID identifiers: resolution, normalization and canonical hashes for every identifier in the pubid-testsuite corpus (41 standards bodies), with a conformance runner mirroring the Ruby reference
