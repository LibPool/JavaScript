# @rudderjs/ai

> 标签: JavaScript

## 简介

Rudder's AI integration: re-exports the agnostic agent engine from @gemstack/ai-sdk and adds the Rudder-specific bindings (AiProvider, ORM-backed stores, doctor check, make:agent/ai:eval CLI).
