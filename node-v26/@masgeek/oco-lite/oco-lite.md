# @masgeek/oco-lite

> 标签: ai, cli, commit, commit-message, conventional-commits, git, local-llm, ollama

## 简介

Minimal, dependency-free git commit message generator using a local Ollama model. Single-line, per-file, per-hunk, or grouped-by-related-change commits, with breaking-change detection.
