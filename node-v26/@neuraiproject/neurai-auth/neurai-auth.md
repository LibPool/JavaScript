# @neuraiproject/neurai-auth

> 标签: auth, cacao, caip-122, express, fastify, neurai, neurai-connect, sign-in

## 简介

Verify Sign-in-with-Neurai logins on a Node backend: login transactions bound to the browser pre-session, atomic CACAO verification with neurai-message.
