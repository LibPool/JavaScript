> 标签: bottom-sheet, calendar, date-picker, dropdown, emoji-picker, expo, picker, range-picker, react-native, react-native-web, select, time-picker, wheel-picker

## 简介

Beautiful, fully customizable pickers for React Native in pure JS: wheel, time, date (calendar + wheel + range), select and emoji. No native code, works with Expo and React Native Web.
