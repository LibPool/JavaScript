# @attenlabs/sas-js

> 标签: attention, audio, realtime, sas, sd-attention, vad, video, websocket

## 简介

Browser JS SDK for the SD Attention Server (SAS). Streams microphone + webcam to the inference server and emits typed events for predictions, VAD, conversation state, and speech audio ready for downstream LLM use.
