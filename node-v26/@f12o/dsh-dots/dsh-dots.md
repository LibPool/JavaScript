# @f12o/dsh-dots

> 标签: agents, automation, deepseek-harness, dots, dsh, plugin

## 简介

Persistent named agents (dots) for DeepSeek Harness: a root-level panel, private workspaces, home sessions, memory, schedules, and multi-host control.
