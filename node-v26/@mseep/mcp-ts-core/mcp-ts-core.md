# @mseep/mcp-ts-core

> 标签: agent, agent-native, ai, ai-agent, bun, cloudflare-workers, declarative, framework, mcp, mcp-framework, mcp-server, model-context-protocol, mseep, observability, opentelemetry, tools, typescript

## 简介

Agent-native TypeScript framework for building MCP servers. Declarative definitions with auth, multi-backend storage, OpenTelemetry, and first-class support for Bun/Node/Cloudflare Workers.
