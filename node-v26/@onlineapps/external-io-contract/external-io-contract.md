# @onlineapps/external-io-contract

> 标签: contract, correlation, envelope, external-io, hmac, webhook

## 简介

Shared contract for external HTTP I/O — correlation grammar, HMAC webhook signing, and JSON Schemas for outbound/inbound envelopes. Consumed by api_gateway, api_delivery_dispatcher and pdke_orion-grit.
