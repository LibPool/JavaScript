# @onlineapps/conn-orch-cookbook

> 标签: connector, cookbook, json-schema, microservice, orchestration, parser, validator, workflow

## 简介

Cookbook toolkit for all services - unified wrapper over core (parsing/validation), router and template helpers. Execution belongs to conn-orch-orchestrator; the cookbook-executor lane was removed.
