> 标签: JavaScript

## 简介

# @wen-moon-ser/moonshot-sdk Moonshot SDK for Solana helps calculate moonshot token prices at any point in the bonding curve. The package also allows the users to generate buy and sell transactions, provide the slippage amount and fix it to a trading side
