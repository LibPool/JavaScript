# @recoengine/eval

> 标签: evaluation, map, metrics, mrr, ndcg, offline-evaluation, ranking, recommendation, recommendation-engine, recommender, recsys, typescript

## 简介

Offline evaluation for recoengine: time-based splits and ranking metrics (nDCG, precision/recall@k, MAP, MRR, catalogue coverage, intra-list diversity).
