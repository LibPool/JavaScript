# @dev-to/react-plugin

> 标签: JavaScript

## 简介

一个用于 **Vite + React** 的“宿主桥接”插件：在 Vite Dev Server 上暴露稳定的桥接入口（contract/init/runtime/debug），让非 Vite 页面（例如 Electron、旧系统、微前端容器）也能加载并热更新 Vite 侧的 React 组件。
