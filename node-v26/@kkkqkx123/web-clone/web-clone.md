# @kkkqkx123/web-clone

> 标签: archive, cli, codegen, html, playwright, puppeteer, scraper, snapshot, web-clone, webpage

## 简介

Single-execution web page snapshot tool: downloads and bundles a webpage into a single HTML file or directory bundle, with optional component extraction and multi-framework code generation.
