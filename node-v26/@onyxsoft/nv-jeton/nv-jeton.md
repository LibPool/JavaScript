# @onyxsoft/nv-jeton

> 标签: JavaScript

## 简介

Selector genérico de **selección múltiple** (typeahead remoto + modal paginado de dos paneles). Contraparte multi-select de `nv-searcher`. Sin lógica de negocio: toda entidad se inyecta por configuración (`JetonConfig<T>` + `JetonDataSource<T>`).
