# @docen/editor

> 标签: add-ins, components, docen, document, editor, fluent-ui, office, office-js, pagination, ribbon, task-pane, web-components, word, wysiwyg

## 简介

Assembly layer for docen editors — bundles a Fluent UI host (ribbon, panes, status bar) with the @docen/docx engine into turnkey <docen-document> web components, with Office.js-style add-ins and Office-style pagination
