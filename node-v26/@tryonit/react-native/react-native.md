# @tryonit/react-native

> 标签: ar, augmented-reality, beauty-filter, camera, ecommerce, expo, expo-go, face-filter, face-tracking, glasses-try-on, jewelry-try-on, mediapipe, react-native, shopify, try-on, virtual-makeup, virtual-try-on, webview

## 简介

Virtual try-on for React Native and Expo (Expo Go, dev builds and bare apps): makeup, beauty filters, face stickers, glasses, hats, earrings, watches, rings and hair color on the phone camera. Same asset manifests as TryOnIt for the web. Free, open source
