# @lyra_wang/dsh-terminal-context

> 标签: context, dsh, dsh-plugin, terminal

## 简介

把 DSH 侧边栏当前显示的内容（终端 / 浏览器面板）交给 Agent，作为它判断当前处境的上下文。
