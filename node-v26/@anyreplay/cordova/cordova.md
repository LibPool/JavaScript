# @anyreplay/cordova

> 标签: anyreplay, cordova, cordova-android, cordova-ios, ecosystem:cordova, session-replay

## 简介

Session replay for Cordova apps: records the app's web view with @anyreplay/browser, plus the app id, version, lifecycle flushing, durable storage and the app's own styles, fonts and images.
