# @falcon-framework/sdk

> 标签: auth, authentication, connect, falcon, identity, react, sdk, sign-in, single sign-on, sso, unified authentication

## 简介

FALCON SDK — use Falcon Auth as your identity provider. Drop-in React components for sign-in, sign-up, and user management. Like Clerk, but self-hosted.
