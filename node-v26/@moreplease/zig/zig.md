# @moreplease/zig

> 标签: compiler, toolchain, zig, zigc, ziglang

## 简介

Installs the official Zig compiler for your platform from ziglang.org's signed releases. The package version is the Zig version plus a packaging revision.

## 官网

- 源码仓库：https://github.com/more-please/zig.git
- npm 页面：https://www.npmjs.com/package/@moreplease/zig
