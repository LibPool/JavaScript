# @toolshed-hq/builder

> 标签: JavaScript

## 简介

The AI builder agent core of Toolshed: a provider-agnostic chat loop that edits a module's source through a `Workspace` and verifies its work. See `docs/ARCHITECTURE.md` section 8 and `docs/ROADMAP.md` (AI provider policy).
