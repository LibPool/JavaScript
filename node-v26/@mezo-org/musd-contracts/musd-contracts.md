# @mezo-org/musd-contracts

> 标签: JavaScript

## 简介

MUSD is Mezo's native stablecoin, 100% backed by Bitcoin reserves and designed to maintain a 1:1 value with the US dollar. MUSD loans are secured by Bitcoin collateral.
