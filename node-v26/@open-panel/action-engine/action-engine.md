# @open-panel/action-engine

> 标签: actions, automation, macropad, openpanel, stream-deck

## 简介

Action registry and execution engine for OpenPanel, plus the built-in actions: shell, hotkeys, open app/URL, page navigation, folders, multimedia keys and profile switching.
