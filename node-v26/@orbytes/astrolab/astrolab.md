# @orbytes/astrolab

> 标签: astro, astro-integration, component-lab, dev-toolbar, feedback, orbytes

## 简介

The orbytes component lab and pin board — an Astrobook shell for Astro sites (live/used-by pills, a viewport configurator, responsive and cull marks, a parameters panel) plus a dev-only click-to-ticket feedback board at /pin.
