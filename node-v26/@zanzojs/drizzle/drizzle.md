# @zanzojs/drizzle

> 标签: @zanzojs/core, authorization, drizzle, drizzle-orm, rebac, zanzibar

## 简介

Drizzle ORM adapter for Zanzo ReBAC. Zero-config Zanzibar Tuple Pattern with parameterized SQL.
