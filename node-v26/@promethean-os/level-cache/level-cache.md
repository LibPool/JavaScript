# @promethean-os/level-cache

> 标签: JavaScript

## 简介

A tiny, embedded, **functional-style** cache on top of `level`: - **No server**, no daemon. - **TTL** via per-record expiry. - **Lazy eviction** + explicit `sweepExpired()`. - **Namespaces** without extra deps. - Pure helpers; no hidden stateful loops.
