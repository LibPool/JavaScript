# @promethean-os/eidolon-field

> 标签: JavaScript

## 简介

Runs an 8-dimensional vector field on a constant tick and persists each tick's field snapshot to MongoDB. Configure the connection with `MONGO_URL`, `DB_NAME`, and `COLLECTION` environment variables.
