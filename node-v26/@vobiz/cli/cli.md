# @vobiz/cli

> 标签: ai-agents, cli, ivr, mcp, rcs, sip-trunking, sms, telephony, vobiz, vobizxml, voice-api

## 简介

Official Vobiz CLI: voice calls, in-call control, conferences, SMS/MMS/RCS, phone numbers, SIP trunks, VobizXML, call records, sub-accounts and the Vobiz Agent Skills, from your terminal and CI.
