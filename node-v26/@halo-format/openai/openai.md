# @halo-format/openai

> 标签: ai-agents, context, halo, openai, openai-agents, tool-results

## 简介

Halo host adapter for the OpenAI Agents SDK: a call_model_input_filter that swaps large tool results for a shape map (out of context) plus a single halo_fetch navigation tool. installHalo() wires it in one call.
