# @ewaiter/sdk

> 标签: JavaScript

## 简介

The headless entry point for eWaiter. `createClient(config)` returns a framework-agnostic `Controller` that you wire into any UI runtime (React, Solid, Vue, vanilla DOM) using that runtime's own reactivity primitive.
