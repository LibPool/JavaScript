# @devanboo/mcp-memory

> 标签: embeddings, mcp, memory, model-context-protocol, opencode, rag, sqlite

## 简介

Agent memory over the OpenCode session history, served over MCP (stdio). Downloads the CGO-free Go binary for your platform on first run.
