# @sawala/sebar-client

> 标签: email, sawala, sawala-cloud, sawala-tech, sebar, transactional, typescript

## 简介

Server-side TypeScript client for Sebar — Sawala Cloud's email send API. Authenticates with a secret key; runs on any server runtime, never the browser.
