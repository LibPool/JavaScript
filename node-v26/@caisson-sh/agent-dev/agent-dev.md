# @caisson-sh/agent-dev

> 标签: JavaScript

## 简介

Agentic-Dev package: the composition of the governed engine-neutral agent kernel + local hybrid memory + a thin multi-harness emitter. Composes base seams down-only — no vendor SDK, no LLM call, no harness substrate.
