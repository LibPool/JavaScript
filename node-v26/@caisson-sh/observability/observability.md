# @caisson-sh/observability

> 标签: JavaScript

## 简介

Vendor-neutral OpenTelemetry bootstrap: env-gated NodeSDK + OTLP/HTTP exporter, HTTP/fetch/pg auto-instrumentation, and span-attribute scrubbing. Inert until OTEL_EXPORTER_OTLP_ENDPOINT is set.
