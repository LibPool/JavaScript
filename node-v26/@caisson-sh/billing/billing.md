# @caisson-sh/billing

> 标签: JavaScript

## 简介

Billing seam: raw-body HMAC webhook signature verification (Stripe, Paddle, LemonSqueezy, Polar), the BillingProvider port + config-type contracts, and the provider-agnostic DomainBillingEvent schema. Drivers/parsers/idempotency live in @caisson-sh/billin
