# @yschdxm/dsh-windows-notify

> 标签: approval, click-to-focus, cordis, deepseek-harness, dsh, dsh-plugin, notification, notify, question, session-jump, toast, toast-notification, windows

## 简介

Native Windows toast notifications for DeepSeek Harness: task completion, approval, questions, sign-in; click a toast to focus the app and jump back to that conversation.
