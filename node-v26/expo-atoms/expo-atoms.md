# expo-atoms

> 标签: android, atom, atomic, expo, expo-go, expo-updates, hooks, ios, jotai, react, react-native, recoil, state, state-management, typescript, web

## 简介

Primitive and flexible atomic state management for Expo & React Native. 100% TypeScript, no native code — works in Expo Go and expo-updates on iOS, Android and web.
