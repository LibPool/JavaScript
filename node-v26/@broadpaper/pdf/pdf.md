# @broadpaper/pdf

> 标签: broadpaper, chromium, document-generation, headless-chrome, pdf, pdf-generation, playwright, report, report-designer, reporting

## 简介

BroadPaper PDF renderer: headless Chromium printing of the paged document, with an HTTP server, SSRF guard and a browser print fallback.
