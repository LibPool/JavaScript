# @gachadex/sdk

> 标签: gachadex, perpetuals, perps, sdk, solana, tcg, trading

## 简介

Typed client for the GachaDex perpetual-futures exchange: Sign-In-With-Solana auth, delegated trade-only keys, orders, positions, and live WebSocket streams.
