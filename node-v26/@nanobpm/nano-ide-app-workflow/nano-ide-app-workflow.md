# @nanobpm/nano-ide-app-workflow

> 标签: nano-ide-app, nano-ide-ext, nanobpm

## 简介

Code-first durable workflow app pack for the Nano RAD IDE: @nanobpm/workflow starters (imperative replay + declarative human-in-the-loop signal) whose executable BPMN model is derived from ordinary async code (ADR 0044/0045).
