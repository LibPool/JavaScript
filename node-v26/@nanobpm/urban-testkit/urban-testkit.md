# @nanobpm/urban-testkit

> 标签: bpmn, e2e, nanobpm, testing, urban, wasm

## 简介

Generic, in-CI e2e test kit for Urban apps: a WASM-backed EngineClient adapter and a reusable engine contract suite. Install as a devDependency of your Urban app — the WASM engine never lands in production installs of @nanobpm/urban.
