# @ramplab/cli

> 标签: claude, cli, codebase, developer-experience, documentation, onboarding

## 简介

Press a guided reading of any codebase from the command line, where every claim carries a code anchor checked against the source. Runs on your own machine, on the Claude Code login you already have.
