# @plist/plist

> 标签: apple, binary, browser, ios, macos, nextstep, node, openstep, parse, parser, plist, propertylist, serialize, typescript, xml

## 简介

TypeScript library for parsing and serializing XML, OpenStep/NextStep and binary Property Lists, in browser and node.js.
