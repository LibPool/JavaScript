# @antelopejs/dms-ai

> 标签: ai, antelopejs, assistant, claude-code, codex, dms, dms-module

## 简介

AI development assistant for the AntelopeJS DMS: a chat panel next to every page and a coding agent that edits the project in reviewable, undoable change sets.
