# @antelopejs/dms-builder

> 标签: antelopejs, builder, codegen, dms, dms-module, page-editor

## 简介

Visual and programmatic editing of an AntelopeJS DMS project: every page edit is an AST rewrite of the project sources, typechecked before it is written.
