# @antelopejs/dms-automation

> 标签: antelopejs, automation, dms, dms-module, workflow

## 简介

Visual automation builder for the AntelopeJS DMS: procedures as node graphs started by schedules, webhooks, manual runs or DMS events, with a trace for every run.
