# @pounceai/bob-control

> 标签: agent-orchestration, ibm-bob, mcp, sqlite, task-board, worker

## 简介

Bob Control: MCP server + CLI + worker that runs IBM Bob (and any MCP-capable agent) unattended against a SQLite task board.
