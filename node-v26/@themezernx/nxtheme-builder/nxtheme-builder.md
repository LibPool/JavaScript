# @themezernx/nxtheme-builder

> 标签: JavaScript

## 简介

TypeScript/JavaScript package to create and parse Nintendo Switch `.nxtheme` files, creating ZIP archives and reading both ZIP and legacy SARC/Yaz0 archives.
