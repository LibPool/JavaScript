# @dotnetjunky/adaptivecards

> 标签: adaptive, adaptivecards, bot, cards, microsoft

## 简介

Adaptive Cards Javascript library for HTML Clients. This library is a fork of the official adaptivecards package but it removes the Caoursel control in order to avoid dependency on the 'swiper' package.
