# @wolfcoded/nestjs-bufconnect

> 标签: bufbuild, bufconnect, gRPC, microservices, nestjs

## 简介

NestJs BufConnect is a custom transport strategy for NestJs microservices that integrates with the Buf's gRPC implementation.
