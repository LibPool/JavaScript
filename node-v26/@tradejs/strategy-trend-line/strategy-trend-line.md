# @tradejs/strategy-trend-line

> 标签: ai, backtesting, binance, bybit, claude, codex, coinbase, crypto, plugin, strategy, tradejs, trading

## 简介

Trendline family for TradeJS: TrendLine trades breakouts while ReverseTrendLine trades rejections using shared geometry and risk controls.
