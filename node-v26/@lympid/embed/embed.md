# @lympid/embed

> 标签: JavaScript

## 简介

Lympid Embed widget SDK — init/open/close/destroy for the Lympid-hosted modal iframe (connect/sign-in, KYC, and in-widget registration flows). apps/partner-api's embed login models (connected, lympid-code) plus apps/whitelabel's embed mode are the server/
