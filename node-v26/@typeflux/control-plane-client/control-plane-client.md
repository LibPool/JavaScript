# @typeflux/control-plane-client

> 标签: JavaScript

## 简介

Generated TypeScript client for the Typeflux control-plane HTTP API. Types are derived from the normative contract (contracts/controlplane/openapi.v1.json); never hand-edit src/schema.ts. The major version is locked to the contract's API major.
