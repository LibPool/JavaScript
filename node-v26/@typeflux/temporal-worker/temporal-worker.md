# @typeflux/temporal-worker

> 标签: JavaScript

## 简介

Opt-in Temporal worker integration for the Typeflux TypeScript SDK — registers typed AI activities and bootstraps a @temporalio worker + client. Keeps @typeflux/temporal dependency-light.
