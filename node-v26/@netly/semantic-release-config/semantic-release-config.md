> 标签: .releaserc.json, changelog, git, github, github-package-registry, github-publish, npm, npm-publish, publish, release, release.config.js, releaserc, semantic-release, semantic-release-config

## 简介

Sharable configuration for semantic-release, extends experience for publishing to NPM & Github: generates release-notes, changelog, publishes new version with Github actions.
