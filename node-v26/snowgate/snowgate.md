# snowgate

> 标签: ai-agents, claude-code, codex, devops, mcp, model-context-protocol, playwright, servicenow, update-set, yallaflow

## 简介

Let AI coding agents (Claude Code, Codex) carry out ServiceNow tasks safely: a guarded MCP gateway, read-only REST, per-task instance targets and update sets, inside YallaFlow projects.
