# bentocal

> 标签: availability, bentocal, calendar, free busy, google calendar, microsoft outlook, scheduling

## 简介

The BentoCal API client for Node.js, Bun, Deno and edge runtimes: connect Google and Microsoft calendars, find availability, write events, verify webhooks.
