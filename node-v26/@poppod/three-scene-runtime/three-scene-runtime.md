# @poppod/three-scene-runtime

> 标签: 3d, glb, gltf, scene, three.js, typescript, unity, webgl

## 简介

TypeScript runtime for loading and rendering scenes exported by the Unity Three.js Scene Exporter (scene.json + GLB) with Three.js
