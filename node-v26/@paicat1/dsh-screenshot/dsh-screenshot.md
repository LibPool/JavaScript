# @paicat1/dsh-screenshot

> 标签: JavaScript

## 简介

Standalone screen capture for DeepSeek Harness (dsh): browser hotkeys plus an agent-facing capture+read tool. Forked out of @liustack/modlens#48 (upstream declined the feature).
