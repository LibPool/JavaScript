# @bumail/acme

> 标签: JavaScript

## 简介

An ACME client (RFC 8555) on fetch and Web Crypto: obtainCertificate for the whole HTTP-01 flow, AcmeClient for each request, an HTTP-01 responder for Bun.serve, and the primitives: a CSR for DNS names, flattened JWS with ES256 and RS256, the JWK thumbpri
