# @payvia-sdk/sdk

> 标签: chrome-extension, monetization, payments, paypal, saas, subscriptions, typescript

## 简介

A lightweight JavaScript SDK for connecting your Chrome Extension / SaaS app to PayVia, for accepting PayPal and Tranzila payments and managing subscriptions, license validation, tier-based feature gating, trial management and monthly / yearly / lifetime
