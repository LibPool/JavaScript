# dsh-project-manager

> 标签: deepseek-harness, dsh, dsh-plugin, kanban, landfill-project, memory, project-management, session

## 简介

Project board + landfill memory for DeepSeek Harness: sessions opened from a card auto-load the complete, latest project memory; persist by the rules, same-name detection, merge, and per-group filing with undoable migration.
