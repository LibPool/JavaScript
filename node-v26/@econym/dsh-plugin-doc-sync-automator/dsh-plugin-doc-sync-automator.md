# @econym/dsh-plugin-doc-sync-automator

> 标签: JavaScript

## 简介

sync_bilingual_pair tool: splice a changed section of an English doc into its .zh.md mirror behind a NEEDS-TRANSLATION marker, keeping the bilingual pair structurally valid without machine translation
