# @searchmindai/event-tracking-url-patterns

> 标签: analytics, event-tracking, searchmindai, url-patterns

## 简介

Tracks e-commerce events by matching page URL patterns (product, cart, checkout, etc.), built on @searchmindai/event-tracking-commons.
