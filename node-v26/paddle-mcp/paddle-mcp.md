# paddle-mcp

> 标签: billing, mcp, paddle, payments, saas

## 简介

Query the Paddle Billing API (sandbox key; set PADDLE_API_KEY, Bearer; optional PADDLE_BASE_URL for sandbox-api.paddle.com): products, product details, prices.
