# @mnemonica/strategy

> 标签: ai, chrome-devtools-protocol, debug-protocol, hot-swap, inheritance, live-debugging, mcp, mnemonica, typescript, websocket

## 简介

MCP server that lets AI agents inspect, define, and hot-swap Mnemonica types inside a running Node.js process — CDP bootstrap, then a WebSocket construction channel
