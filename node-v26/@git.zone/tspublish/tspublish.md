# @git.zone/tspublish

> 标签: automation, developer-tools, git, modularity, module-management, monorepo, npm, package, publish, typescript

## 简介

A tool to plan and prepare multiple, concise, and small packages from monorepos, specifically for TypeScript projects within a git environment.
