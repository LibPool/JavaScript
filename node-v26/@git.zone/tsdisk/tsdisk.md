# @git.zone/tsdisk

> 标签: alerts, cache, cargo, cleanup, diagnostics, disk, disk-usage, docker, du, git-worktree, monitoring, pnpm, qcow2, systemd, vm

## 简介

Keeps Linux disk usage in check: measures and explains filesystem use, classifies caches, worktrees and VM images, previews and applies audited owner-tool cleanup, and checks free-space thresholds with trends and alerts.
