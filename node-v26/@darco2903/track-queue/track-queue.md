# @darco2903/track-queue

> 标签: JavaScript

## 简介

`Track Queue` is a TypeScript library that provides a strongly-typed queue with tracking capabilities. It allows to define a queue of items and track the current position, previous items, and next items in the queue. This can be useful in various scenario
