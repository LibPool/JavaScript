# pi-interactive-only

> 标签: guard, interactive, pi, pi-coding-agent, pi-extension, pi-package, print-mode

## 简介

Pi extension that refuses to run Pi in non-interactive modes (print/JSON/RPC), forcing interactive-only usage.
