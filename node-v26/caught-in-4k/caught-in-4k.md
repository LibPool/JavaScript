# caught-in-4k

> 标签: agent, agent-skill, ai-agent, claude-code, codex, ffmpeg, flicker, keyframes, mcp, mcp-server, screen-recording, skill, ui-testing, video, vision, visual-testing, whisper

## 简介

Your agent said done. It never watched it run. caught-in-4k turns UI recordings into frames an agent can see: what changed, what flickered, what never moved. CLI, MCP server and agent skill.
