# thefaceanalysis-mcp

> 标签: claude, face-analysis, face-shape, facial-measurements, fwhr, mcp, model-context-protocol

## 简介

MCP server for The Face Analysis: face measurement statistics, face/eye/lip/nose types, methodology and a face shape classifier, from Claude, Cursor, ChatGPT or any MCP client.
