# @wvanderdeijl/fate-editor

> 标签: angular, bootstrap4, editor, material, rich-text, rich-text-editor, typescript, wysiwyg, wysiwyg-editor

## 简介

A rich text editor (wysiwyg) natively written for angular (>= v2) with footprint and flexibility in mind. Fork of original fate-editor which does not support angular beyond v9.
