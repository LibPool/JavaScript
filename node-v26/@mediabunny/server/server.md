# @mediabunny/server

> 标签: JavaScript

## 简介

Adds full video and audio decoder and encoder support to Mediabunny for use in server-side environments (Node, Bun, Deno). Based on NodeAV.

## 官网

- 官网：https://mediabunny.dev/guide/extensions/server
- 源码仓库：git+https://github.com/Vanilagy/mediabunny.git
- npm 页面：https://www.npmjs.com/package/@mediabunny/server
