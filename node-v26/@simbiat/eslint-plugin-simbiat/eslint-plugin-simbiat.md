# @simbiat/eslint-plugin-simbiat

> 标签: class-fields, custom-elements, eslint, eslint-plugin, eslintplugin, typescript

## 简介

Custom ESLint rules used in simbiat.eu project: class-field initializers, custom-element constructor constraints, and typed querySelector.
