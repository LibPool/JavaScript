# @panelwave/mcp

> 标签: claude, graphic-novel, mcp, model-context-protocol, panelwave

## 简介

Local MCP bridge for PanelWave: connects Claude Desktop, Claude Code, Cursor and other MCP clients to the hosted PanelWave MCP server and adds local file tools (list, read, upload a folder of panels).
