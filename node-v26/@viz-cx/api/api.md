# @viz-cx/api

> 标签: api, blockchain, sdk, typescript, viz, viz-blockchain

## 简介

Type-safe TypeScript SDK for the VIZ site API (api.viz.cx): blocks, profiles, richlist, signed webhooks, and the live op WebSocket.
