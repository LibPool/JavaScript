# @latitude-data/openclaw-telemetry-cli

> 标签: cli, installer, latitude, openclaw, telemetry

## 简介

One-shot installer for the @latitude-data/openclaw-telemetry OpenClaw plugin. Configures credentials, plugins.allow, and the gateway-restart prompt against ~/.openclaw/openclaw.json.
