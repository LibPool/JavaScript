# @subtitledb/core

> 标签: api, ass, captions, imdb, srt, subtitle, subtitles, tmdb, vtt, webvtt

## 简介

Client for The Subtitle Database, a free subtitle API for films and series. No key needed. Lookups, matching, downloads and WebVTT conversion, with no dependencies. Runs in browsers and Node 20.3 or newer, as an ES module.
