# ramosedb

> 标签: alchemy, cloudflare, database, datalog, datomic, durable-objects, effect, graph-database, immutable, ramosedb, realtime, workers

## 简介

RamoseDB — an immutable, Datomic-inspired graph database for Cloudflare (Workers + Durable Objects + R2), built on Effect. One package: portable authoring (`ramosedb/db`), Alchemy resources (`ramosedb`), the offline-first browser client (`ramosedb/client`
