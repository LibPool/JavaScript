# delentia-guard

> 标签: ai-agent, audit, claude, cursor, guardrails, mcp, model-context-protocol, policy

## 简介

Enforcing proxy for MCP tool calls: every tools/call is checked against an FDIA policy before it reaches the server, with a hash-chained audit log.
