# @metano-ai/agent-sdk

> 标签: agent, ai, guardrails, mcp, observability, telemetry, vercel-ai-sdk

## 简介

First-party SDK to instrument custom AI agents (Vercel AI SDK / plain TypeScript) and report telemetry to Metano Agent Observatory.
