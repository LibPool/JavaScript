# @tencentcloud/roomkit-web-vue3

> 标签: conference, javascript, tuiroomkit, webrtc

## 简介

腾讯云 TUIRoomKit 音视频房间 UI 组件库（Vue3 版本）。提供会前预检与会中两套完整的 UI 视图组件，覆盖桌面端与 H5 移动端，并配套完整的会议生命周期控制 API，帮助开发者快速将多人音视频会议能力集成到现有 Vue3 项目中。
