# @tencentcloud/chat-uikit-vue2

> 标签: IM, WebSocket, chat, messaging, tencent, tencentcloud, uikit, uni-app, 即时通信, 通信

## 简介

TUIKit 是基于 IM SDK 实现的一套 UI 组件，其包含会话、聊天、群组、个人资料等功能，基于 TUIKit 组件您可以像搭积木一样快速搭建起自己的业务逻辑。
