# @cubertimer/scrambler

> 标签: kociemba, react-native, rubiks-cube, scramble, speedcubing, two-phase, wca

## 简介

Random state scrambles for speedcubing puzzles, following the WCA method. Pure TypeScript, no dependency, works in React Native.
