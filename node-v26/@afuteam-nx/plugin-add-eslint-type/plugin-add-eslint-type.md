# @afuteam-nx/plugin-add-eslint-type

> 标签: @afuteam-nx, @afuteam/eslint-plugin-fe, eslint, nx, nx-plugins

## 简介

给定代码仓库源码，智能识别代码仓库技术栈，输出仓库应当使用哪种 `AFUEslintType` 类型，进行代码质量检测。
