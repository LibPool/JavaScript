# @mafesoftware/pruebas-fuentes

> 标签: detectores, devkit, fuentes, pruebas, vitest

## 简介

Detectores de reglas de código fuente (heurísticas por regex/tokens) para correr dentro de un test de vitest de la app consumidora: guardas de "use server", fragmentos sql con or suelto, ?? 0 en plata, setHours, server-only en datos, imports de datos en "
