# @mafesoftware/compras

> 标签: JavaScript

## 简介

Compras de obra, núcleo puro: ciclo de vida de un pedido de compra (requisicion), cuadro comparativo de cotizaciones (armarComparativo) y ciclo de vida + totales con IVA de una orden de compra. Aritmetica de Cantidad (decimal como string) compartida por l
