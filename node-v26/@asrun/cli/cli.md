# @asrun/cli

> 标签: asrun, assemblyscript, cairn, cli, toolchain, wasm

## 简介

asrun — zero-config AssemblyScript toolchain. Thin shell: the native binary ships in @asrun/cli-<platform>-<arch> optionalDependencies and npm installs only the one for your platform (TOOL-006, ADR-0012).
