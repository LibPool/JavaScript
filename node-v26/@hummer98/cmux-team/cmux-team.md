# @hummer98/cmux-team

> 标签: claude-code, cli, cmux, multi-agent, orchestration, parallel, team

## 简介

Multi-agent development orchestration with Claude Code + cmux. Spawn, monitor, and integrate parallel sub-agents visually in terminal panes.
