# react-native-spotlight-walkthrough

> 标签: coachmark, expo, narration, onboarding, react-native, reanimated, spotlight, text-to-speech, tooltip, tour, tts, walkthrough

## 简介

Interactive spotlight walkthroughs for React Native: pass-through targets, animated gesture simulations, audio/TTS narration, show-once persistence and a fully themeable UI.
