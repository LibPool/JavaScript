# @z-maas/iframe-integration

> 标签: composable, iframe, integration, library, messenger, postMessage, typescript, vite, vue, vue3

## 简介

一个轻量的 Vue 3 组合式 API 与消息通信工具，用于通过 postMessage 实现安全的 iframe 集成，支持 origin 白名单过滤与类型友好的消息处理。
