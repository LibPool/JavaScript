# @distinguished-anomaly/sdk

> 标签: JavaScript

## 简介

Optional, low-overhead semantic annotations for Runtime Lens. Runtime Lens can attach without this package; use the SDK only when you want application-specific signals, spans, redacted config, or declared read-only capabilities.
