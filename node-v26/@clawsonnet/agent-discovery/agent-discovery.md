# @clawsonnet/agent-discovery

> 标签: agent, agent-discovery, ai, ai-agent, capabilities, multi-agent, openclaw, registry, rest-api

## 简介

A registry where AI agents can register their capabilities and discover other agents by skill tags. Lightweight REST API — register, search, list, deregister.
