# @farohqbr/browser

> 标签: browser, error-tracking, farohq, monitoring, nextjs, observability, react, rum, vue, web-vitals

## 简介

FaroHQ no navegador: erros de JavaScript com o código original (source maps), o que o usuário fez antes do erro, ligação com o backend pelo traceId e desempenho real das páginas (Web Vitals).
