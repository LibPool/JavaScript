> 标签: automation, bun, cicd, deplix, deploy, devops, frontend, nextjs, nginx, node, nuxt, pm2, react, self-hosted, vue, webhook

## 简介

Deplix - A self-hosted CI/CD web panel for frontend project deployment. Install globally and run 'deplix start' to launch.
