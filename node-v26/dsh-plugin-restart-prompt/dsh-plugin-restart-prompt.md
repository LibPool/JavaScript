# dsh-plugin-restart-prompt

> 标签: cordis, deepseek, deepseek-harness, dsh, dsh-plugin, plugin-management, restart

## 简介

Restart prompt after DSH plugin changes: an install, update or uninstall is detected, then DSH restarts in one click — silently, with no console window, and the prompt can show what changed. · DSH 插件变动后提示「重启 DSH」，一键静默重启（无黑框），并可展开本次改动差异。
