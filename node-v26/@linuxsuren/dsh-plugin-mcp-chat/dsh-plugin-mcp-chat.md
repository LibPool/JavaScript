# @linuxsuren/dsh-plugin-mcp-chat

> 标签: deepseek-harness, dsh, mcp

## 简介

Multi-MCP-server chat plugin for DeepSeek Harness: manage MCP servers in the Web settings UI (with live tool counts); every MCP tool becomes mcp__<server>__<tool>.
