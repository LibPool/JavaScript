# shibaox-mem-opencode

> 标签: context, local-first, memory, opencode, opencode-plugin, shibaox, sqlite

## 简介

shibaox-mem for OpenCode. Persistent memory across sessions: what each session learns, the next one is told. One local binary, no daemon, no LLM in the loop; your plan is never spent on memory.
