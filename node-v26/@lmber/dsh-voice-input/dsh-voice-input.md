# @lmber/dsh-voice-input

> 标签: asr, cordis, deepseek-harness, dsh, mimo, speech-recognition, voice-input

## 简介

Voice input for DeepSeek Harness: a composer microphone button that records in the browser and transcribes on the host through Xiaomi MiMo ASR.
