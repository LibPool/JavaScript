# @beebozy/dillithium-sdk

> 标签: ckb, cryptography, dilithium, ml-dsa, nervos, post-quantum, sdk, typescript, wasm

## 简介

Browser-safe TypeScript SDK for the CKB Dilithium lock script: ML-DSA-65 key generation, lock args derivation, transaction hash signing, and witness serialization.
