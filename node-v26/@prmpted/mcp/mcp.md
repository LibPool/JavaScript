# @prmpted/mcp

> 标签: ai, builds, claude, mcp, model-context-protocol, prompted

## 简介

MCP server that lets your AI agent post your builds to Prompted (prmpted.com). Your agent writes the draft; you add screenshots and publish.

## 官网

- 官网：https://prmpted.com
- npm 页面：https://www.npmjs.com/package/@prmpted/mcp

- npm registry：https://registry.npmjs.org/@prmpted/mcp
