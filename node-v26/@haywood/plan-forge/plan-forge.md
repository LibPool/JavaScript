# @haywood/plan-forge

> 标签: adversarial-review, ai-agents, claude-code, code-planning, codex, plan-review, skill

## 简介

Adversarial plan review between AI coding agents: one model drafts an implementation plan, another reviews it, and unresolved blocker/major findings drive full-plan revisions until approval or an auditable human handoff.
