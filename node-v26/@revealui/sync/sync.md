# @revealui/sync

> 标签: collaborative, electricsql, real-time, revealui, sync

## 简介

Real-time sync layer wrapping ElectricSQL and Yjs CRDT — offline queue, shape cache, conflict resolution, collaborative documents. Ships with RevealUI.
