# @interglade/secure-crypto

> 标签: aead, aes, aes-gcm, chacha20-poly1305, crypto, decryption, encryption, isomorphic, pbkdf2, react-native, scrypt, typescript, universal, xchacha20

## 简介

Universal encryption for React Native, browsers and Node. XChaCha20-Poly1305 and AES-256-GCM with a versioned, self-describing envelope format.
