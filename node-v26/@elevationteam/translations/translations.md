# @elevationteam/translations

> 标签: angular, elevationteam, i18n, javascript, nodejs, react, translations, typescript

## 简介

An agnostic and flexible translation library for web and mobile projects. It allows for easy initialization, custom language configuration, and AI-based automatic translation. Compatible with React, Next.js, React Native, and more.
