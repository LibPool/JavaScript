# @chartlite/mcp

> 标签: agents, ai, chartlite, charts, mcp, model-context-protocol, svg, visualization

## 简介

Model Context Protocol server for Chartlite — render charts to SVG from a JSON spec. Zero-dependency, ~15KB core, agent-native.
