# @deepfirstsearch/agent-pay-agentkit

> 标签: agentkit, ai-agents, base, coinbase, payments, usdc, x402

## 简介

Coinbase AgentKit action provider: agents fetch x402 APIs while the owner's Agent Safe policy decides every payment (no payee or amount in the model's hands)
