# @firsttx/prepaint

> 标签: bootstrap, csr, inline-script, prepaint, react, view-transitions, visual-cache

## 简介

Boot-time visual snapshot replay for CSR apps, backed by IndexedDB and designed to reduce revisit blank time before the React app mounts.
