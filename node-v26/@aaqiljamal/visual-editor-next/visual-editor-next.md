# @aaqiljamal/visual-editor-next

> 标签: css-modules, next, styled-components, tailwind, visual-editor

## 简介

Visual-edit for Next.js — one install. withVisualEditor() wires the SWC-compatible stamping loader + auto-mounts the overlay; a one-line Route Handler does AST writes inside your dev process.
