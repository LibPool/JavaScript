# @aaqiljamal/visual-editor-server

> 标签: ast, css-modules, styled-components, tailwind, visual-editor

## 简介

Node-side AST mutator for visual-editor: Tailwind className, CSS Modules, styled-components. Used by @aaqiljamal/visual-editor-next as a library, or standalone via the `visual-editor-server` CLI.
