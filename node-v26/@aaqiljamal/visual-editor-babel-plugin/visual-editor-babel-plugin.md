# @aaqiljamal/visual-editor-babel-plugin

> 标签: babel-plugin, next, react, visual-editor

## 简介

Babel plugin: stamps data-oid + data-css-module-* + data-styled-* attributes on JSX elements so the visual-editor overlay can map runtime DOM back to source.
