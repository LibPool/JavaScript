# @kuralle-syrinx/cli

> 标签: agent, cli, speech, syrinx, testing, voice, voice-agent

## 简介

Agent-facing CLI for Syrinx — run a turn or a text exchange with deterministic, machine-readable (--json) output and exit codes. Not a console: no REPL, no chat loop, no microphone.
