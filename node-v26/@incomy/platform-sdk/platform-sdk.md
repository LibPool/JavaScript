# @incomy/platform-sdk

> 标签: JavaScript

## 简介

Auto-generated TypeScript client for the Incomy platform APIs (currently **Hub**), produced from each service's OpenAPI spec and published to npm. Consumed by the `web` frontend as `import { hub } from "@incomy/platform-sdk"`.
