# @polar/plugin-reverse-geocoder

> 标签: OpenLayers, POLAR, ol, plugin, reverse geocoder

## 简介

ReverseGeocoder plugin for POLAR that adds a ui-less reverse geocoding mechanism that can be adresses via store interactions.
