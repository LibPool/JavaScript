# @delegus/scenarios

> 标签: JavaScript

## 简介

The Delegus test library: machine-executable scenarios (a written permission, a setup, an attack, and a pass condition decided at the tool boundary) for testing what an AI agent can do when told not to. Used by Delegus Test and Delegus Check. Data only: e
