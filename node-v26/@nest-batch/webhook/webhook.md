# @nest-batch/webhook

> 标签: batch, dead-letter, hmac, hmac-sha256, nestjs, observer, webhook

## 简介

Webhook delivery observer for @nest-batch/core. Subscribes to BATCH_EVENT.* and POSTs HMAC-SHA256-signed JSON envelopes to one or more URLs with exponential-backoff retry and dead-letter logging. Uses native fetch (Node 20+); no HTTP client peer dep.
