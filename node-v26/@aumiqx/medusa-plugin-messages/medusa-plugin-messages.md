# @aumiqx/medusa-plugin-messages

> 标签: b2c, chat, marketplace, medusa, medusa-plugin, medusajs, messaging, sse

## 简介

Self-hosted messaging for Medusa v2 marketplaces — customer↔vendor and vendor↔admin threads with Server-Sent Events real-time push, unread tracking, and zero external SaaS.
