# @gohead-cms/client

> 标签: client, cms, gohead, headless-cms, nextjs, sdk, typescript

## 简介

Typed JavaScript/TypeScript client for the GoHead headless CMS: content, singletons, media, locales, GraphQL, webhooks, plus a CLI for type generation and content models as code.
