# versions-le

> 标签: cli, consistency, dependencies, letools, monorepo, nolindnaidoo, semver, versions, versions-le

## 简介

Find where one dependency is constrained inconsistently across a repository's package.json, Cargo.toml, pyproject.toml, go.mod and GitHub workflows. Never crosses an ecosystem.
