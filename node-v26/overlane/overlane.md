> 标签: agents-md, ai-agents, claude-code, cli, cloudflare, code-index, codex, coding-agents, mcp, overlane

## 简介

Overlane: connect a GitHub project to your coding agents. One portable CLI with project memory, tasks, a code index, guardrails and the Claude Code and Codex plugin.
