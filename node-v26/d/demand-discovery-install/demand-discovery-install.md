# demand-discovery-install

> 标签: claude, claude-desktop, demand-discovery, installer, mcp, model-context-protocol, startup-validation

## 简介

One-command installer for the Demand Discovery AI™ MCP server in Claude Desktop. Works on Windows (direct install + Microsoft Store), macOS, and Linux. Run with: npx demand-discovery-install
