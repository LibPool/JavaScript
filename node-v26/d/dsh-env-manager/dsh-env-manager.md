# dsh-env-manager

> 标签: deepseek-harness, dotenv, dsh, dsh-plugin, env, environment, 环境变量

## 简介

环境变量管理：扫描代码引用的环境变量与 .env 比对检测缺失/未使用，并从 .env 生成脱敏的 .env.example
