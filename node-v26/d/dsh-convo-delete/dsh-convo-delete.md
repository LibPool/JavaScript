# dsh-convo-delete

> 标签: conversation, cordis, deepseek-harness, delete, dsh, plugin, session

## 简介

DSH Web GUI 会话删除插件：会话列表行悬停出现删除按钮，确认后永久删除对话（删哪些由用户判断，不做任何自动判定）
