# dsh-pwa-icon

> 标签: deepseek, dsh, dsh-plugin, icon, manifest, pwa

## 简介

DSH PWA 图标：把 Web GUI 安装/添加到桌面时的应用图标换成指定图片（覆盖 manifest 的 icons 并注入 apple-touch-icon）。
