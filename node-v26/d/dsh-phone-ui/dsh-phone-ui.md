# dsh-phone-ui

> 标签: cordis, deepseek, deepseek-harness, dsh, mobile, plugin, responsive, ui

## 简介

DeepSeek Harness 移动端 UI 适配插件（纯 Client）：动态 Cordis 代码片段 + 正式 client 插件两种形态。窄屏下侧边栏全宽抽屉 + 复刻 DeepSeek 网页版式顶栏。各区域拆分为独立 feature，可在 DSH 设置页单独开关，改动即时生效。
