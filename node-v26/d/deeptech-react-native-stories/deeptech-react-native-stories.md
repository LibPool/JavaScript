# deeptech-react-native-stories

> 标签: android, animated, deeptech, instagram-stories, ios, react-native, react-native-stories, social, status, stories, story, typescript, whatsapp-stories

## 简介

Instagram-like story UI component for React Native. Features include horizontal story tray, 3D cube animation, stories viewer with progress bar, camera, video support, liking, replying, sharing, and swipe gestures.
