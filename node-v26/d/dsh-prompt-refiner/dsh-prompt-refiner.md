# dsh-prompt-refiner

> 标签: cordis, dsh, dsh-plugin, dynamic-plugin, prompt, prompt-refiner

## 简介

DeepSeek Harness 输入栏「提示词精炼」插件：✨ 一键把模糊草稿改写为目标/背景/步骤/要求/[假设] 结构化提示词；成本可路由（默认模型可换成便宜的优化模型）、结果缓存、token 用量统计落盘。静态版为功能主体，动态版免安装尝鲜。
