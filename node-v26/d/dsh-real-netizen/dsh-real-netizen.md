# dsh-real-netizen

> 标签: ai-companion, companion, cordis, deepseek-harness, dsh, dsh-plugin, memory, persona, proactive

## 简介

把「真实网友」装进 DeepSeek Harness：侧边栏出现她的头像，点开就是她本人；agent 也能用 her_state / her_recall / her_say。
