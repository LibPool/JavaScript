# dsh-dhe-allow

> 标签: allow, allowlist, approval, cordis, cordis-plugin, deepseek, deepseek-harness, dsh, dsh-plugin, escalation, permission, plugin, sandbox, workspace-write

## 简介

DSH plugin: automatic approval for configured directories and commands — stop the sandbox-escalation popups you already trust, keep the rest. · DSH 自动权限审批插件：按允许目录与「以某命令开头」的允许命令自动放行工作区写模式下的越权审批弹窗，并在审批卡片上提供「始终允许」按钮。
