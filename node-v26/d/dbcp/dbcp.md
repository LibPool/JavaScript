# dbcp

> 标签: aws, cloud, csv, database, dump, elasticsearch, gcp, gcs, json, leveldb, mongodb, mysql, parquet, postgres, s3, shard, stream, tfrecord

## 简介

Dump Mysql, Postgres, SQLServer, and ElasticSearch databases directly to AWS S3, Google Cloud Storage, or Azure.
