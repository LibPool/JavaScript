# dsh-rules-manager-client

> 标签: agent, commands, cordis, deepseek-harness, dsh, dsh-plugin, rules, settings

## 简介

DeepSeek Harness (dsh) settings panel: '规则、命令与技能' — visual rule editing, slash command list, user-defined custom command management (with {input} argument support, disable/enable), skill management (view/disable/enable/delete-to-trash), and backup restore
