# dsh-openwolf

> 标签: agenda, agent-tools, code-map, code-map-agent, codegraph, cordis, deepseek-harness, dsh, plugin

## 简介

A compact code-map 'second brain' for DeepSeek Harness: pre-indexed project maps, per-file digests, session digests, read/write interception, and AGENTS.md injection so the agent stops re-reading whole files.
