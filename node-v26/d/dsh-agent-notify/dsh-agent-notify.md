# dsh-agent-notify

> 标签: deepseek, dsh, dsh-plugin, harness, notification, notify, toast, web, windows

## 简介

DSH Web GUI 任务完成通知：agent 完成任务或需要你输入/批准时，弹出 Windows 系统级通知（浏览器 Notification API，无网页内弹窗、无合成音），点击气泡直达会话。纯浏览器端插件（host half 为空）。
