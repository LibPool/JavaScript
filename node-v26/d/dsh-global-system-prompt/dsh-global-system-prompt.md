# dsh-global-system-prompt

> 标签: agents-md, cc-switch, cordis, deepseek-harness, dsh, dsh-bundle, dsh-plugin, global-prompt, system-prompt

## 简介

cc-switch-style global prompt for DeepSeek Harness (dsh 0.1.5): one user-editable block injected into the system prompt of every conversation, mirrored into each session project's AGENTS.md, and naming the harness's user-global AGENTS.md by absolute path
