# deep-cleaner

> 标签: array, clean, cleaner, deep, deep-clean, deep-cleaner, delete, empty, null, object, recursive, recursively, string, strip, undefined

## 简介

Recursively remove deeply nested properties and/or falsey values (excluding 0), empty objects, and empty arrays.
