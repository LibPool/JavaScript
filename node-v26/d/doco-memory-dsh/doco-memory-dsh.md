# doco-memory-dsh

> 标签: ai-agents, deepseek-harness, doco, dsh, knowledge-base, memory, plugin

## 简介

Doco memory plugin for DeepSeek Harness — turn your Doco knowledge base into a centralized, cross-device agent memory (recall / remember / context / init per Doco Memory Layout spec v1).
