# dsh-deepseek-cost

> 标签: billing, cordis, cost, deepseek, deepseek-harness, dsh, usage

## 简介

DeepSeek API 费用统计插件:自动读取模型名称、token 用量与时段,按官方价格计算当前任务的 API 总费用并显示在 Web 聊天页
