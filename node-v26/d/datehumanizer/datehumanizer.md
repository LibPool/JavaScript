# datehumanizer

> 标签: date, date formatter, date humanizer, date to text, format, friendly date display, human, human readable date, humanize date, i18n, internationalization, javascript date format, lightweight date library, relative, relative time, time, time ago, timestamp to words

## 简介

Lightweight and fast JavaScript library to humanize dates and timestamps into natural language like '5 minutes ago', 'Yesterday', or 'in 3 hours'.
