# dsh-chat-export

> 标签: chat-export, deepseek-harness, dsh, dsh-plugin, export, markdown, session, transcript, 对话导出, 导出文字稿

## 简介

Readable transcript export for DeepSeek Harness: turn any Session into a Markdown / HTML / ZIP transcript with reasoning blocks, tool calls and results, images and usage — from the Session header or the /export-md command.
