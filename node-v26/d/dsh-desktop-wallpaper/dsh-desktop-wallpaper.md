# dsh-desktop-wallpaper

> 标签: background, client-plugin, deepseek-harness, desktop, dsh, plugin, wallpaper

## 简介

Purpose-built for DSH Desktop 的壁纸插件：把本地文件夹当壁纸库（或直接用内置示例图），面板内手动点选，暗化 / 模糊 / 透出三条滑杆可拖，并按区域差异化透出（顶部原生菜单栏与底部输入卡片保持不透明、左侧栏比主内容区少透出 15% 并额外压暗 20%）。
