# dsh-keep-running

> 标签: deepseek-harness, dsh, plugin, quota, rate-limit, resume, watchdog

## 简介

Watchdog plugin for DeepSeek Harness: on a 429/quota error, auto-resume the task via a recurring system-reminder until it succeeds.
