# dsh-file-finder

> 标签: command-palette, deepseek-harness, dsh, dsh-plugin, file-search

## 简介

File finder for DSH: search by name or content, preview images, video, audio, PDF, HTML and Markdown, and edit text files with syntax colours, line numbers and in-file find.
