# dsh-skin-switcher

> 标签: deepseek-harness, dsh, plugin, skin, theme, webui

## 简介

DSH Web GUI 皮肤切换器：在设置界面列出已安装的皮肤并提供一键切换按钮。切换通过 ~/.dsh/cordis.patch.yml managed section 实现，DSH 配置监视器热重载，无需重启服务器。
