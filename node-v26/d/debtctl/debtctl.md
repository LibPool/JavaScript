# debtctl

> 标签: ci, cli, dependencies, npm, overrides, pnpm, resolutions, tech-debt, typescript, yarn

## 简介

Govern npm overrides, pnpm.overrides, and yarn resolutions as documented technical debt. Fails CI when overrides go stale.
