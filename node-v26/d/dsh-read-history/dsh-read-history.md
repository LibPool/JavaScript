# dsh-read-history

> 标签: claude-code, codex, conversation, deepseek-harness, dsh, history, import, plugin

## 简介

Import Claude Code / Codex CLI conversation history into DeepSeek Harness (DSH): each conversation becomes a native DSH session under its original workspace.
