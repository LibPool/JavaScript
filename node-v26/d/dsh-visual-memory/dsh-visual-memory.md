# dsh-visual-memory

> 标签: agent-memory, deepseek-harness, dsh, dsh-plugin, image-memory, multimodal, visual-memory

## 简介

Lossless visual memory for DSH agents: verbatim content-addressed image storage, an explicit-attention ledger, labelled comparison sheets, and exact pixel reads — no second vision model in the loop.
