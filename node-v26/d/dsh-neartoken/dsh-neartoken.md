# dsh-neartoken

> 标签: JavaScript

## 简介

Sign in to a New API deployment (NearToken) from the settings page; the plugin creates the API token, inserts itself as a model provider with a three-level model / group / reasoning-effort picker, and mounts a generate_image tool for the site's picture mo
