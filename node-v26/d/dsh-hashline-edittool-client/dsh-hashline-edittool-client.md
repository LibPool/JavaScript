# dsh-hashline-edittool-client

> 标签: client-plugin, deepseek-harness, diff-card, dsh, dsh-plugin, hashline, web-ui

## 简介

Companion dsh web client plugin for dsh-hashline-edittool: renders hashline-branded read/edit tool cards (line:anchor gutters, applied multi-hunk diffs with anchor hints) from persisted presentationMeta. Issue #71 direction B.
