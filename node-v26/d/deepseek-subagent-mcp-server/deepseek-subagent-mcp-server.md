# deepseek-subagent-mcp-server

> 标签: agent, codex, deepseek, deepseek-v4, mcp, subagent

## 简介

MCP server that delegates sub-tasks to DeepSeek as a sub-agent via the OpenAI-compatible /chat/completions endpoint (DeepSeek-V4).
