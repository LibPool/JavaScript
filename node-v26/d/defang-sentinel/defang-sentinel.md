# defang-sentinel

> 标签: cli, cti, defang, dfir, github-action, incident-response, ioc, malware-analysis, markdown, phishing, refang, sarif, security, threat-intelligence

## 简介

Defang and refang IOCs (hxxps://evil[.]com) in text, logs and reports with several styles, and a CI check that fails when threat reports, tickets or docs contain live, clickable or half-defanged URLs, domains, IPs or emails. CLI, library and GitHub Action
