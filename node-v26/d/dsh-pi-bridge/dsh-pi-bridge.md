# dsh-pi-bridge

> 标签: bridge, compatibility, cross-host, deepseek-harness, dsh, dsh-plugin, pi, pi-extension, pi-package, plugin-loader

## 简介

One plugin, two hosts: installs into the pi coding agent and into DeepSeek Harness, and bridges the ecosystems. In DSH a pi_install tool turns pi packages into native DSH tools, commands and skills; in pi a /dsh-install command turns DSH plugin bundles in
