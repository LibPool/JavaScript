# dsh-phocinae

> 标签: approval-gate, cordis-plugin, decision-model, deepseek-harness, dsh, dsh-plugin, escalation, local-inference, phocinae, pre-tool-use, tool-routing

## 简介

Local non-generative decision layer for DeepSeek Harness: the phocinae_ask / phocinae_gate tools backed by a Phocinae-Largha-150M-v1 server, plus a fail-closed approval gate on tools/pre-execute with a calibrated-confidence escalation signal
