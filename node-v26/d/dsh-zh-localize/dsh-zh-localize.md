# dsh-zh-localize

> 标签: chinese, deepseek-harness, dsh, i18n, localize, plugin, zh

## 简介

DSH 中文化自定义插件：界面语言为中文时，翻译权限预设（Read Only / Workspace Write / Full access）、内置命令描述与提示等界面英文文案
