# dsh-hash-checksum

> 标签: checksum, dsh, hash, plugin

## 简介

Hash & checksum plugin for DeepSeek Harness: md5/sha1/sha256/sha512 for text and files (streamed, constant memory), checksum verification with prefix parsing and length-mismatch hints. Zero runtime dependencies.
