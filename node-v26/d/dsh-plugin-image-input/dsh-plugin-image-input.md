# dsh-plugin-image-input

> 标签: JavaScript

## 简介

图片转文字输入插件：给无视觉能力的纯文本 LLM（DeepSeek 等）提供图片输入接管。输入框粘贴/拖拽图片后一键转为结构化文字描述；视觉 API 配置在设置页填写，支持任意 OpenAI 兼容视觉模型（qwen-vl / gpt-4o / glm-4v 等）。多模态模型下自动让位，不劫持原生图片通道。
