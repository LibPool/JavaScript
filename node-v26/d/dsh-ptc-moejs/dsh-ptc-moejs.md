# dsh-ptc-moejs

> 标签: deepseek-harness, dsh, dsh-plugin, javascript, moejs, ptc, typescript

## 简介

PTC runtime for the DeepSeek Harness that runs model-written programs in moejs, a pure-Go JavaScript engine, inside a long-lived sidecar process under dsh's file sandbox
