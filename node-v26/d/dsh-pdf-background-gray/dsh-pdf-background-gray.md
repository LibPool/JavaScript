# dsh-pdf-background-gray

> 标签: background-removal, deepseek-harness, dsh-plugin, image-processing, pdf, skill

## 简介

PDF 去底灰技能（remove-pdf-background-gray）的 DSH 插件化分发：去除扫描 PDF 的灰色/米白底色，保持原始分辨率、页面几何与抗锯齿文字边缘；核心为单文件 Python 脚本（pypdf + Pillow + numpy），无损 Flate 压缩。
