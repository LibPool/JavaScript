# dsh-reasoning-bridge

> 标签: browser-automation, chatgpt, deepseek-harness, dsh, reasoning, skill

## 简介

Reasoning Bridge for dsh: hand high-cost reasoning to web AI (ChatGPT first, multi-target), keep local evidence, adoption gate, edits, and tests in dsh. Contract-based Packet/Result, versioned risk consent, SHA-256 run receipts.
