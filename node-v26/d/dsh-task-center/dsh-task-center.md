# dsh-task-center

> 标签: deepseek-harness, dsh-plugin, kanban, scheduler, tasks

## 简介

The task-center plugin set for DeepSeek Harness in one package: task ledger, model tools, human commands, wake patrol, quota-resume guard, idle-session mining, the reaper, scheduled sends, the parallel fleet, and the web kanban.
