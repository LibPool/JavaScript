# diagview

> 标签: chart, d3, diagram, export, flowchart, framework-agnostic, graphviz, interactive, mermaid, pan, plantuml, svg, viewer, visualization, zoom

## 简介

A lightweight framework-agnostic viewer for SVG diagrams (Mermaid, Graphviz, etc). Adds interactive Zoom, Pan, Search, Export, and Presentation Mode.
