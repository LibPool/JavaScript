# dsh-web-relay

> 标签: caddy, deepseek-harness, dsh, dsh-plugin, relay, remote-access, reverse-tunnel, self-hosted, ssh-tunnel

## 简介

把内网主机上的 dsh web 经一台公网中继交给远程设备：SSH 反向隧道、受限中继账号、网关口令与 DSH 权威注册
