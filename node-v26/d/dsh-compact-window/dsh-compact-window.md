# dsh-compact-window

> 标签: always-on-top, compact, deepseek, deepseek-harness, dsh, dsh-plugin, harness, sticky, window

## 简介

Small-window mode for the DSH desktop app: turn the main window into a 425px-wide, always-on-top sticky window. 把 DSH 桌面窗口切成置顶的便签式小窗。
