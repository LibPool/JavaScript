# dsh-visual-deck

> 标签: background, cordis, deepseek-harness, dsh, dsh-plugin, skin, splash, startup-animation, video, wallpaper

## 简介

DeepSeek Harness 的启动动画与会话背景管理器：导入本地图片/视频，视频设为启动动画（带声音、可调音量与播放时机），图片或视频设为会话背景（强度/模糊/临时开关）。
