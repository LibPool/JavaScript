# duration-translation

> 标签: JavaScript

## 简介

The Time Unit Translator is a lightweight npm package for translating time units with ease. Convert seconds, minutes, hours, days, and months into localized forms in any language. Customize translations and formatting effortlessly. Open source and user-fr
