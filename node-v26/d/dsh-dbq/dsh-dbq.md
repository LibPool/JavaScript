# dsh-dbq

> 标签: database, deepseek-harness, dsh, dsh-plugin, mysql, postgres, sql, sqlite

## 简介

DSH 插件：数据库连接查询——4 个模型工具（db_connections/db_tables/db_describe/db_query）+ 设置页 + 查询结果卡片，内置 Go 网关 dbq.exe 执行只读 SQL（Windows）
