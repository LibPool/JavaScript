# dsh-dialog-width

> 标签: chat-ui, cordis, deepseek, deepseek-ai, dialog-width, dsh, plugin

## 简介

DSH plugin: control the conversation column width — a pixel-value input (600–1600 px) with presets, plus a switch to toggle between plugin-driven width and DSH's native drag handles. Requires DSH v0.1.2-rc.1+.
