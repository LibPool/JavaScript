# dsh-ui-deepdiving

> 标签: animation, deep-diving, deepdiving, deepseek-harness, dsh-plugin, effects, shimmer, water-flow

## 简介

Curated effects and wording for the dsh web 'Deep diving…' turn status: six pure-CSS flowing-light presets (water flow default, stock sweep, breath, rainbow, pulse, aurora) with per-effect knobs, custom status wording, speed that follows generation, light
