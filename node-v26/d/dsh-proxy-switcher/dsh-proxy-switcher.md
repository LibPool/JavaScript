# dsh-proxy-switcher

> 标签: cordis, deepseek-harness, deepseek-harness-plugin, dsh, dsh-plugin, hot-switch, proxy, socks5

## 简介

Hot-switch the outbound proxy of a running DeepSeek Harness (dsh): direct / system-env / custom proxy, multiple saved proxies, switchable from the dsh settings page with no restart.
