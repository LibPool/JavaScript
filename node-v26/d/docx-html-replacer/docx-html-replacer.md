# docx-html-replacer

> 标签: document, document-generation, docx, docx-generation, docx-template, formatting, html, html-to-docx, mail-merge, office, ooxml, openxml, placeholder, replacement, report-generation, rich-text, template-engine, templating, text-replacement, word, word-template

## 简介

Open-source rich-text (HTML) placeholder replacement for DOCX templates. Automatically detects HTML vs plain text and converts to native Word formatting.
