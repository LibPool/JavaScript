# dsh-select-to-chat

> 标签: client-plugin, composer, deepseek, deepseek-harness, dsh, plugin, quote, selection, 对话框, 选中

## 简介

选中文字 → 添加到对话框：在 dsh Web 任何文字上拖选一段文本，即出现「添加到对话框」浮标，点击后把选中文字填入对话输入框。
