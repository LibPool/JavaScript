# dsh-deepseek-webchat

> 标签: deepseek, deepseek-harness, dsh, harness-plugin, plugin, sidebar, webchat

## 简介

Embeds the official chat.deepseek.com web app in a DSH sidebar tab through the desktop shell's native browser guest, binds one DeepSeek conversation per DSH Session, and sends selected DSH context into the DeepSeek composer as a blockquote.
