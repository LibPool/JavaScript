# dsh-web-auth-gate

> 标签: auth, bundle, cordis, deepseek-harness, dsh, gate, password, plugin

## 简介

In-process password gate for the DeepSeek Harness Web UI (dsh): the gate owns the announced (CLI-passed) port, serves the login page from an internal loopback port, and forwards authenticated traffic to the internal webserver — a single exposed port. Ship
