# dsh-gadgets

> 标签: conversation, deepseek-harness, dsh, notify, plugin, skin, theme, ui

## 简介

Lightweight DeepSeek Harness tweaks, one install: dsh-skin (custom appearance) + dsh-tidy (conversation folding, nav rail & total-token badge) + dsh-task-alerts (task-done / approval chime + popup).
