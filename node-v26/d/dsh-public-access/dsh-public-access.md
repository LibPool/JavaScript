# dsh-public-access

> 标签: auth, authentication, deepseek, dsh, harness, nginx, proxy, public-access, remote-access, reverse-proxy, web-ui

## 简介

DeepSeek Harness plugin - public/LAN access (0.0.0.0 + trusted hosts) with login auth, adapted to dsh 0.1.x browser-token auth
