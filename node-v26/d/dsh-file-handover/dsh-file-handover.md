# dsh-file-handover

> 标签: automation, deepseek-harness, dsh, dsh-plugin, file-dialog, file-picker, ui-automation, uia, upload, windows, 手, 文件对话框

## 简介

把本机文件递给会话或网页，不弹系统文件对话框。 Hand a local file to a session or a page without opening the native file dialog.
