# dsh-session-billing

> 标签: billing, cordis, cost, deepseek-harness, dsh, dsh-plugin, tokens

## 简介

Per-session LLM cost meter for the DeepSeek Harness Web UI: folds provider usage into uncached input / cache read / cache write / output per model and prices it against DeepSeek and Xiaomi MiMo pay-as-you-go rates (DeepSeek peak-idle tiering included).
