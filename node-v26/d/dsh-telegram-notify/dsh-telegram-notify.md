# dsh-telegram-notify

> 标签: deepseek-harness, dsh, dsh-plugin, notifications, settings, telegram

## 简介

Push DSH turn, error, question, plan-review and approval events to a Telegram chat, with a Settings page for the bot token, chat id and event toggles.
