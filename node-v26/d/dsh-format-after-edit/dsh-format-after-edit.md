# dsh-format-after-edit

> 标签: agent, biome, deepseek, deepseek-harness, dsh, dsh-plugin, format, formatter, gofmt, prettier, ruff, rustfmt

## 简介

DeepSeek Harness plugin that runs your project's formatter (Prettier, Biome, dprint, Ruff, Black, gofmt, rustfmt, clang-format or your own) on every file the agent edits.
