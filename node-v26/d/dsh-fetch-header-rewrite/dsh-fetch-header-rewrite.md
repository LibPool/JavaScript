# dsh-fetch-header-rewrite

> 标签: cordis, dsh, header-rewrite, plugin, user-agent

## 简介

Rewrite outbound HTTP request headers (User-Agent, custom) for any dsh provider/gateway request, with optional prefix/regex rules.
