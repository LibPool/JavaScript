# dexterquery

> 标签: conditions, filter, filter-builder, mysql, query-builder, react, react-component, segment, segmentation, sql, typescript, where-clause

## 简介

A React query builder for people who do not write query languages: the user describes what they want in a sentence, and you get back a MySQL WHERE predicate with parameterised values.
