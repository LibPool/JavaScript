# dom-particle-system

> 标签: dom, js, particle, particles

## 简介

A 20kb lightweight, fast & powerful JavaScript particle library. It allows for individual particle control, and complete emitter systems.  Can pass descrete values, arrays of values, or pass functions that control specific parameters
