# dsh-background

> 标签: background, deepseek-harness, dsh, dsh-plugin, wallpaper

## 简介

DeepSeek Harness Web 背景图片插件:在设置-通用-外观中填写本地图片路径即可替换网页背景,提供实时预览与可调蒙层强度
