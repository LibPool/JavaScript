# dsh-dbpulse

> 标签: database, dba, deepseek, deepseek-harness, dsh, dsh-plugin, mongodb, monitoring, mysql, postgresql, redis, sql-server, sqlite

## 简介

DeepSeek Harness 数据库监控插件：数据库监控模式 agent preset + 专业监控面板。引擎无关的指标采集（内置 MySQL / PostgreSQL / SQLite / SQL Server / MongoDB / Redis），浏览器面板展示连接数、缓存命中、慢查询、会话、锁等待与复制延迟，可扩展更多数据库引擎。
