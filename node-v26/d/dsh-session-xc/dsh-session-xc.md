# dsh-session-xc

> 标签: deepseek-harness, dsh, plugin, session, workspace

## 简介

DSH web plugin: 工作区可见会话数 + 已完成未读会话数 + 已归档会话入口与恢复/删除 + 批量删除已归档会话 + 跨工作区移动会话 + 只看活跃会话筛选 + 新会话首轮自动起名（配置："会话增强"设置卡片）。
