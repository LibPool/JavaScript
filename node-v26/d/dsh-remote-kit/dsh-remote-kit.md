# dsh-remote-kit

> 标签: cordis, deepseek-harness, dsh, headless, mobile, plugin, remote-access

## 简介

Remote-access kit for a DSH (DeepSeek Harness) web instance running in a headless container: mobile UI polish, old-browser polyfills, loopback-equivalent trust for public entries, and headless directory picking. One `dsh plugin add` registers all four.
