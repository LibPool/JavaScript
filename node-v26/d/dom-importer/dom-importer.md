# dom-importer

> 标签: component-loader, dom, dynamic-import, framework-agnostic, intersection-observer, lazy-load, loader, mutation-observer, progressive-enhancement, spa, vanilla-js

## 简介

Scans the DOM and dynamically imports JavaScript modules when matching elements are found. Supports lazy loading, lifecycle hooks, and SPA-friendly DOM watching.
