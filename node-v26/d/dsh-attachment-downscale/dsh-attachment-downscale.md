# dsh-attachment-downscale

> 标签: attachment, compression, cordis, deepseek-harness, downscale, dsh, dsh-plugin, image, plugin

## 简介

附件自动降级：DSH 图片准入（单边 ≤2000px / ≤3.5MB / ≤4000万像素）超限图片不再拒绝，用 sharp 自动缩小/重编码后入库，用户上传手机原图不再踩线。
