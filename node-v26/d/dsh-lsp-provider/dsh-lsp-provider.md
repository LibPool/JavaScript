# dsh-lsp-provider

> 标签: deepseek-harness, dsh, dsh-plugin

## 简介

Provide a real LSP provider for the dsh `ctx.lsp` capability seam, backed by a real language server over stdio JSON-RPC 2.0 (typescript-language-server), plus an `lsp_query` model tool.
