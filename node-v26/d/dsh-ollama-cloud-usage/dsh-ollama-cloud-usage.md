# dsh-ollama-cloud-usage

> 标签: api-key, deepseek-harness, dsh, dsh-plugin, ollama, ollama-cloud, quota, usage

## 简介

DeepSeek Harness plugin: show Ollama Cloud remaining quota (session/weekly) as a Settings section beside Account & Balance, with an in-page API key editor. · DSH 插件：在设置页“账号与余额”下方显示 Ollama Cloud 剩余额度，并支持在页面内填写 API Key。
