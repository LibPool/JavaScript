# dnsdoctor-mcp

> 标签: ai-agent, deliverability, dkim, dmarc, dns, dnssec, domain-health, email, mcp, model-context-protocol, mx, spf, x402

## 简介

Email & domain deliverability doctor: live SPF, DKIM, DMARC, MX and DNS health check for any domain, as an MCP tool and a pay-per-call x402 endpoint. Tells an AI agent if mail from a domain will land in inbox or spam, and exactly what DNS records to fix.
