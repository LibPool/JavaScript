# dsh-settings-params

> 标签: deepseek-harness, dsh, environment, plugin, settings

## 简介

集中管理注入宿主的环境变量，并支持按白名单热重载那些启动时只读一次环境变量的插件（如 dsh-sql），免重启即可读取新值。
