# dsh-scheduled-actions

> 标签: cordis, cron, deepseek-harness, dsh, dsh-plugin, schedule, scheduled-actions

## 简介

Host-level scheduled actions for DeepSeek Harness — create, verify, and run actions on a schedule (one-shot, interval, daily, weekly, cron, on-startup) with a JSON store and a Settings UI.
