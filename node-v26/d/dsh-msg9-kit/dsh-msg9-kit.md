# dsh-msg9-kit

> 标签: agent, contacts, cordis, deepseek-harness, dsh, inbox, messaging, msg9, outbox, plugin

## 简介

dsh (DeepSeek Harness) msg9 kit: one msg9.io inbox per workspace. Model tools (send/receive/read/contacts/resolve) plus a /msg9 command in the agent, and a ✉ sidebar icon that opens the same mailbox in the GUI — inbox, outbox and address book, with an unr
