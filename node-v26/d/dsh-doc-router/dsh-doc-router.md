# dsh-doc-router

> 标签: columns, cordis, deepseek-harness, document-routing, docx, dsh, dsh-plugin, layout, markdown, multi-column, pdf, pymupdf, reading-order, xlsx

## 简介

DeepSeek Harness document-routing tools: sniff a file's real format and a PDF's page layout, then extract with the right pipeline — layout-aware Markdown for multi-column papers, MarkItDown for everything else, images for scans.
