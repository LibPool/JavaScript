# dsh-deepseek-balance-tide

> 标签: balance, deepseek, deepseek-harness, dsh, off-peak, peak, plugin, pricing

## 简介

DeepSeek Harness (DSH) 插件：在侧栏显示 DeepSeek API 余额，在聊天输入框下方显示峰谷（高峰/空闲）时段并提供官方定价入口。
