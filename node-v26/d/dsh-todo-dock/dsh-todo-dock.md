# dsh-todo-dock

> 标签: checklist, deepseek-harness, dsh, dsh-bundle, dsh-plugin, sidebar, tasks, todo

## 简介

DSH 右侧栏的轻量待办：一行一件、勾掉即完成、可折叠已完成；本地存储，Agent 也能加/勾/删（todo_panel 工具）。
