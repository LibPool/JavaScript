# dsh-api-mock

> 标签: deepseek-harness, dsh, dsh-plugin, mock, mock-server, openapi, 接口, 模拟

## 简介

接口模拟服务器：解析 OpenAPI 3.x（JSON/YAML），生成零依赖可运行的 Node Mock 服务器，并按 schema 确定性生成示例数据，前端联调无需等后端
