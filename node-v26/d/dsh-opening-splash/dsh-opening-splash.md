# dsh-opening-splash

> 标签: animation, deepseek-harness, dsh, dsh-plugin, opening, splash

## 简介

DeepSeek Harness opening splash: plays the DSH software-opening animation full screen when the Web UI boots, then fades into the app (skippable, speed and frequency configurable)
