# dsh-mnn-chat

> 标签: deepseek-harness, dsh, dsh-plugin, llm-provider, mnn, mnn-chat, openai-compatible

## 简介

MNN Chat 自定义 API 服务接入 DSH：把手机端 MNN Chat（MnnLlmChat）的 OpenAI 兼容 HTTP 服务注册成 DSH 的一个 LLM provider，可在大龙虾里直接对话
