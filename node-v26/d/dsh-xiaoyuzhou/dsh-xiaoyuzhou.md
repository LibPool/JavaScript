# dsh-xiaoyuzhou

> 标签: deepseek-harness, dsh, dsh-plugin, player, podcast, xiaoyuzhou, 小宇宙, 播客

## 简介

DeepSeek Harness 小宇宙播客插件：Host 侧免登录解析小宇宙播客/单集并代理音频流（Range/seek），浏览器侧提供播放条/订阅/搜索（登录解锁）/shownotes 阅读的播放面板，并注册 podcast_play 模型工具
