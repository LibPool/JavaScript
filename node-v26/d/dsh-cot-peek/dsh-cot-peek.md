# dsh-cot-peek

> 标签: chain-of-thought, cot, deepseek-harness, dsh, dsh-plugin, reasoning, thinking, translation

## 简介

思考小窗：贴边深呼吸箭头、思考增量翻译；设置页可选官方 Bing/Google/DeepSeek 或自定义 OpenAI 兼容端点，支持拉取模型列表与连接测试，本地端点走宿时代理绕过 CORS。
