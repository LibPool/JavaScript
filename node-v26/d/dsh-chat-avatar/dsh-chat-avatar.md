# dsh-chat-avatar

> 标签: avatar, deepseek-harness, dsh, dsh-plugin, ui

## 简介

DSH Web 头像插件：在每轮 AI 回复左侧与你的每条输入右侧各显示一个头像，可上传、调尺寸、选圆形或方形框。
