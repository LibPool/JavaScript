# dsh-fullscreen-input

> 标签: composer, cordis, deepseek-harness, dsh, dsh-plugin, fullscreen, ime, input, multiline

## 简介

给 DSH 的输入框加一个全屏输入面板：在整屏空间里写多行文本，可拖动标题栏移动、可拖边框改大小，引用与附件都与主输入框共用同一份草稿。Enter 换行、仅 Ctrl+Enter 发送，因此中文输入法下 Shift+Enter 也不会被误判成发送。
