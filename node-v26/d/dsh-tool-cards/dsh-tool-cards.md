# dsh-tool-cards

> 标签: chat-ui, deepseek-harness, dsh, dsh-plugin, generative-ui, interactive, plugin, react

## 简介

Interactive cards for DeepSeek Harness replies, rendered from a tool result: sliders, selects, forms, charts and tables, with a submit action that flows back to the agent as a real user message.
