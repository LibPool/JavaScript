# dsh-chat-width

> 标签: JavaScript

## 简介

DSH Web 消息宽度调节插件：自主调节 AI 回复展示宽度（0804+ 覆盖 --dsh-chat-content-width 变量，0803 自动转换硬编码 736px），设置页提供预设/自定义输入，localStorage 持久化。配置即安装，零核心改动。
