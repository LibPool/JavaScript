# digital-handler

> 标签: digital-handler, num-handler, 播放数数值缩写, 阅读数数值缩写

## 简介

一个数值缩写处理工具，可以快速实现，例如：1000 = 1k ，10000 = 1w等的数值缩写转换，支持自定义。
