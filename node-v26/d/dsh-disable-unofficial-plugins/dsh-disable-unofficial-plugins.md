# dsh-disable-unofficial-plugins

> 标签: deepseek-harness, dsh, dsh-plugin, plugin, web-ui

## 简介

DSH Web UI plugin: a checkbox-style switch at the right end of the Plugins → Installed group header that lets you choose which unofficial plugins to disable or enable — all selected by default, disable/enable only (never uninstall), and once everything is
