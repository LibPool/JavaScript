# dsh-github-publisher

> 标签: deepseek-harness, dsh, github, npm, plugin, publish, release, 发布, 自动发布

## 简介

DeepSeek Harness 全自动 GitHub 发布插件：一句「发布 dsh-xxx」即自动 bump 版本、npm pack、commit/push、打 tag、创建 GitHub Release（附 .tgz）、并触发 npm 发布。
