# dsh-bash-terminal-ts

> 标签: deepseek-harness, dsh, git-bash, mingw64, msys2, plugin, powershell, shell, terminal, typescript, windows, wsl

## 简介

DSH plugin: one shell tool that runs commands through PowerShell, Git Bash, MSYS2, or WSL on Windows, with a user-chosen default terminal in the Web UI settings. TypeScript rewrite of MAXeaglet/dsh-bash-terminal with working MSYS2/MINGW64 support.
