# dsh-voice-chat

> 标签: deepseek-harness, dsh, edge-tts, mimo, plugin, stt, tts, voice, voice-chat, xiaomi

## 简介

豆包式语音对话客户端插件：麦克风按钮→语音转文字发送→回复自动朗读（支持 Edge TTS / MiMo TTS / 自定义 TTS）。
