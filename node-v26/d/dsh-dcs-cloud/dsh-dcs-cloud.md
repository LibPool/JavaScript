# dsh-dcs-cloud

> 标签: bgi, bioinformatics, cordis, dcs, dcs-cloud, deepseek, dsh, genomics, harness, plugin, spatial-omics, stomics

## 简介

DeepSeek Harness 插件：接入 BGI Research 的 dcs CLI，面向 DCS Cloud 的基因组/时空组学生信研究编排 —— 数据检索、Genpilot 流程复用、DCS 原生 skill/专家、在线容器、离线任务投递、脚本审计与学术报告生成。
