# dsh-arabic

> 标签: arabic, bidi, deepseek-harness, dsh, dsh-plugin, i18n, localization, rtl

## 简介

Arabic experience for DeepSeek Harness: bidi-safe RTL rendering for mixed Arabic/English content plus a full Arabic UI language pack registered through the official locale service.
