# dsh-release-evidence

> 标签: attestation, ci, deepseek-harness, dsh, dsh-plugin, merkle, provenance, release-evidence, supply-chain

## 简介

Aggregate DSH plugin release evidence (lifecycle tests, regression evals, compatibility, quality budgets) into one signed, independently verifiable pack. Does not run the tests — proves which ones ran and that their reports were not altered.
