# dapp-wallet

> 标签: Dapp, Wallet, 钱包, 钱包工具

## 简介

这是一个 DAPP 钱包工具，主要是以钱包工具扩展，目前支持 MetaMask、CoinBase、Okx、TronLink、UniSat钱包工具，也可以根据自己需要进行扩展，已经为您准备好了最基础的代码，只要引用和自己的处理逻辑即可。
