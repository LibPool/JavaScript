# dsh-clipboard-bridge

> 标签: clipboard, copy, cordis, deepseek, dsh, harness, paste, plugin, vscode

## 简介

DSH 插件：在 VS Code 内嵌的 DSH Web 输入框里恢复 Cmd/Ctrl+C/V/X/A 复制/粘贴/剪切/全选（经扩展主机的原生剪贴板中转）。
