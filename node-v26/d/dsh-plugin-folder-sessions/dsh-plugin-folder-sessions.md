# dsh-plugin-folder-sessions

> 标签: deepseek-harness, dsh, dsh-plugin, folder, session, workspace

## 简介

DSH plugin: the New Session button creates a fresh session workspace folder under a configurable root, and renaming an auto-created workspace renames its folder too.
