> 标签: courier, delivery, dpd, dpd-poland, dpd-polska, labels, logistics, parcel, pickup, sdk, shipment, shipping, soap, soap-api, tracking, type-safe, typescript, waybill

## 简介

Modern, type-safe TypeScript SDK for DPD Polska SOAP API. Complete label management, real-time shipment tracking, and pickup scheduling with 100% test coverage.
