# dsh-plugin-blender

> 标签: 3d, blender, bpy, cad, deepseek-harness, dsh, dsh-plugin, modeling, render

## 简介

Let DeepSeek Harness model in Blender: drive it live through a bundled addon so the user watches every step, or headless from the terminal. Includes an auto-staged preview render so the agent can look at its own work and fix it.
