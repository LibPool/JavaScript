# demf-dtm-entity

> 标签: JavaScript

## 简介

The Digital Twin Entity microfrontend is dedicated to the creation and configuration of an Entity Schema in the context of a Digital Twin Model. It is designed to be used within the Digital Twin Modeller (DTM) tool and can be integrated as a microfrontend
