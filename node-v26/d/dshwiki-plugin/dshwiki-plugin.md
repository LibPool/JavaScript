# dshwiki-plugin

> 标签: deepseek-harness, dsh, dsh-plugin, plugin-directory, wiki

## 简介

DSH Wiki 情报面板：在 dsh 侧边栏直接查看 DeepSeek Harness 插件精选、排行榜与大事记（数据来自 dshwiki.com）

- 源码仓库：git+https://github.com/ai798-Lab/dshwiki-plugin.git
- npm 页面：https://www.npmjs.com/package/dshwiki-plugin
