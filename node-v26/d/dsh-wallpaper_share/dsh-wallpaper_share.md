# dsh-wallpaper_share

> 标签: background, deepseek-harness, dsh, plugin, wallpaper, wallpaper-engine

## 简介

Sync active Wallpaper Engine wallpapers(image/video/scence/app)to DeepSeek Harness Web UI as a customizable dynamic background.
