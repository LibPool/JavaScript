# dms-auth-check-npm

> 标签: authentication, authorization, express-middleware, jwt, microservice, permissions, rbac

## 简介

Shared Express middleware for verifying DMS Identity Service JWTs and enforcing permission-based authorization (requirePermission, requireAnyPermission, requireAllPermissions) across microservices.
