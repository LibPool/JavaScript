# dsh-dingtalk

> 标签: deepseek-harness, dingtalk, dingtalk-robot, dsh, dsh-plugin, webhook

## 简介

钉钉群机器人单向通知工具（DeepSeek Harness 插件）：agent 推送 Markdown / 纯文本消息到钉钉群，支持加签安全模式。
