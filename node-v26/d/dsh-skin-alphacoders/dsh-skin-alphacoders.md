# dsh-skin-alphacoders

> 标签: alphacoders, cordis, deepseek, deepseek-harness, dsh, dsh-plugin, skin, theme, wallpaper

## 简介

DSH skin plugin: Alphacoders popular wallpapers as the DeepSeek Harness Web GUI background (gallery, search, local upload, per-theme wallpapers, favorites, auto-change, history, glass blur)
