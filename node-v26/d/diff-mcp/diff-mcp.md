# diff-mcp

> 标签: compare, diff, json, jsondiffpatch, mcp

## 简介

MCP server to compare text or data and get a readable diff (supports text, json, jsonc, yaml, toml, etc.)

## 官网

- 官网：https://github.com/benjamine/jsondiffpatch
- 源码仓库：git+https://github.com/benjamine/jsondiffpatch.git
- npm 页面：https://www.npmjs.com/package/diff-mcp
