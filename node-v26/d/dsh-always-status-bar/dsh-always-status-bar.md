# dsh-always-status-bar

> 标签: deepseek-harness, dsh, dsh-plugin, status-bar, ui, web

## 简介

DSH Web UI plugin: keep the native per-message status line (date | time, run duration, TTFT, tokens/s) always visible without hovering
