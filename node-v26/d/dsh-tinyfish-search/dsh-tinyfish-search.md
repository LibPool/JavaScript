# dsh-tinyfish-search

> 标签: deepseek-harness, dsh, plugin, search, tinyfish, web-search

## 简介

TinyFish-backed web search provider for DeepSeek Harness (ctx.web): makes the built-in web_search tool run on the TinyFish Search API
