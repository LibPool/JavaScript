# dsh-excel-slim

> 标签: deepseek-harness, dsh, excel, openpyxl, plugin, token, xlsx, 压缩, 汽配, 省钱, 缓存

## 简介

DeepSeek Harness 超大 Excel 瘦身插件：大表（100MB+ 汽配表）读一次即生成压缩摘要 + 磁盘归档，跨会话复用，excel_slim / excel_query / excel_cache 三个工具替代反复整表 dump，大幅减少 token 消耗。
