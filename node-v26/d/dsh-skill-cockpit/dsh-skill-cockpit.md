# dsh-skill-cockpit

> 标签: cordis, deepseek-harness, dsh, dsh-bundle, dsh-plugin, panellist, skill-cockpit, skill-manager, skills

## 简介

Skill cockpit for DSH: one page in the app-level nav (official sidebar.panellist seat, order 5) that lists every skill this machine actually exposes (all six skill-root kinds, not just ~/.dsh/skills), explains why a skill is invisible (dropped:* / missing
