# dsh-header-balance

> 标签: account, balance, credit, deepseek, deepseek-harness, dsh, dsh-plugin

## 简介

会话页头部的余额芯片。点击跳转充值页，悬停看赠送与充值的拆分。每 60 秒与窗口获得焦点时刷新；未配置密钥、密钥失效、余额不足、限流、超时、断网、响应异常各自给出提示。密钥只在宿主侧读取。
