# dsh-long-drawio

> 标签: cordis, cordis-plugin, deepseek-harness, diagrams, document-preview, drawio, dsh, offline

## 简介

在 DSH 右侧栏「文档预览」里直接渲染 .drawio（draw.io）图：内置官方 viewer，零 npm 依赖、无安装期脚本，默认离线、只读、零出网；可在「设置 → 插件」填自己的 draw.io 实例以取样式/模具。 | Render .drawio diagrams in the DSH sidebar document preview with draw.io's bundled viewer — zero npm dependencies, offline & read-only by d
