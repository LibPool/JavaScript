# dsh-pwa

> 标签: deepseek-harness, dsh, dsh-plugin, mobile, pwa

## 简介

Phone-first PWA for DeepSeek Harness: mounts at /m on dsh web and talks to the same /api as the desktop GUI — sessions, streaming chat, approvals, agent questions. iOS + Android, zero install on the phone.
