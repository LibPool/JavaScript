# docs-index

> 标签: claude, cli, docs, documentation, fts5, indexer, markdown, mcp, scraper, sqlite

## 简介

A Cursor-style @Docs for the terminal: index any docs site into a local SQLite + FTS5 store, then search, read, and serve it to Claude over MCP — no re-fetching, no embeddings provider.
