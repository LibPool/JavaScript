# domainsweep

> 标签: availability, brand-name, cli, domain, domain-name, name-generator, rdap, tld, whois

## 简介

Find free domain names: checks a name and its lookalike variants across TLDs in your priority order (RDAP, WHOIS, DNS; no API key).
