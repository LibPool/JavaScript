# dsh-workflow-ran

> 标签: cordis, deepseek-harness, dsh, file-organizer, plugin, workflow

## 简介

DSH 工作流插件包：file-organizer（按文件类型自动整理文件夹并生成报告）等命名工作流。安装后 /workflow file-organizer "路径" 即可使用。
