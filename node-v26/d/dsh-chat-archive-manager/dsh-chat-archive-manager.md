# dsh-chat-archive-manager

> 标签: archive, chat, cordis, deepseek-harness, dsh, dsh-plugin

## 简介

在设置页提供「归档管理」页面：按工作区浏览、批量归档、恢复，以及需要二次确认的永久删除，不额外创建 Workspace。
