# dsh-glm-meter

> 标签: deepseek-harness, dsh, dsh-plugin, quota, usage, zai-coding-cn

## 简介

Provider quota widget for the DSH web surface, built for the 0.2.1-rc.2 host line: collapsed capsule expanding into a Harness-native card. Host half resolves keys via ctx.credentials and queries zai-coding-cn / zai / zhipu / deepseek quota endpoints over
