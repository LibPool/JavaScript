# dsh-warm

> 标签: cache-warming, deepseek-harness, dsh, host-plugin, plugin, prompt-cache

## 简介

DeepSeek Harness host plugin: prompt-cache warmer. While a session's agent loop is blocked inside a tool execution (bash, wait_agent, job_output, ...), re-dispatches the session's last conversation request through the llm waterfall with max_tokens=1 every
