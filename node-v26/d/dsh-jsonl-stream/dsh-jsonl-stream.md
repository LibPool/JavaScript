# dsh-jsonl-stream

> 标签: dsh, json, jsonl, ndjson, plugin, projection, sample, stream

## 简介

JSONL/NDJSON stream plugin for DeepSeek Harness: parse line-delimited JSON with bad-line tolerance, sample records (head/tail/random/evenly) with reproducible seeds, and project nested fields via dot paths. Zero runtime dependencies, read-only.
