# dsh-badges

> 标签: badges, composer, cordis, deepseek-harness, dock, dsh, plugin

## 简介

Unified composer-dock badge host: feature plugins register badge descriptors and this plugin renders them as one horizontal row. Two descriptor modes: projection (legacy, reads a session projection key) and fetch (no session events: initial GET + toggle-r
