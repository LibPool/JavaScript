# dsh-web-mermaid

> 标签: deepseek-harness, diagram, dsh, markdown, mermaid, plugin

## 简介

DeepSeek Harness (DSH) Web 插件：把聊天 Markdown 中的 ```mermaid 围栏代码块离线渲染为 Mermaid 图表（SVG）。mermaid 运行时随插件内置，不依赖任何在线 CDN。
