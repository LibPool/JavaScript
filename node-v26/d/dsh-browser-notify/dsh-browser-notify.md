# dsh-browser-notify

> 标签: dsh, dsh-plugin, notification, notify, web-notification

## 简介

DSH 浏览器通知插件：agent 回合结束、向你提问或请求授权时，用浏览器系统通知提醒你（仅当页面不在前台时）
