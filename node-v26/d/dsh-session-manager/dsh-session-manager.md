# dsh-session-manager

> 标签: archive, deepseek-harness, dsh, migration, move, plugin, preset, session, workspace

## 简介

DSH Web 会话管理：删除、归档、跨工作区移动、迁移预设；收藏、待看、搜索、排序、设置优先级，添加标签和备注；批量处理。欢迎至 GitHub 提意见。
