# dchub-mcp-server

> 标签: ai-agents, data-center, datacenter, dchub, energy, fiber, mcp, mcp-server, model-context-protocol, power-grid, site-selection

## 简介

DC Hub MCP launcher: DCPI (Data Center Power Index) scores where data centers can get grid power across 300+ markets, plus live grid, fiber and site-selection data for AI agents (94 tools). Connects stdio MCP clients to dchub.cloud/mcp.
