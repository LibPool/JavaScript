# dsh-code-scan

> 标签: code-scan, deepseek, dsh, dsh-plugin, harness, security, semgrep

## 简介

DeepSeek Harness 插件：为 Agent 增加 code_scan 工具，用 semgrep 扫描代码并输出按文件/行号/严重级别分组的中文报告
