# dsh-mobile-compat

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, mobile, responsive, touch

## 简介

为窄屏触控设备提供版本锁定的移动端适配：侧边栏抽屉、全屏设置、输入区与安全区修正。
