# demiurge-hypnos

> 标签: agents-md, claude-code, claude-md, codex, consolidation, cursor, demiurge, memory, rules, windsurf

## 简介

Agents' memory rots. HYPNOS consolidates it in their sleep: every change a diff, nothing ever deleted. Cross-agent: Claude Code, Codex, Cursor, Windsurf.
