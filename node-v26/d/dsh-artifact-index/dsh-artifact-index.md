# dsh-artifact-index

> 标签: artifacts, deepseek-harness, dsh, dsh-plugin

## 简介

Artifact index endpoint for the DeepSeek Harness web GUI: serves the JSON index contract and the file bytes that the dsh-artifacts sidebar tab reads.
