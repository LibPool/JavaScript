# docling.rs-cuda

> 标签: bun, converter, cuda, docling, document, docx, gpu, markdown, napi, pdf

## 简介

CUDA build of docling.rs for Node.js / Bun (Linux x64). Same API as the docling.rs package; binaries are downloaded from the matching GitHub release at install time.
