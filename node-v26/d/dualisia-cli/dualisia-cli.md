# dualisia-cli

> 标签: brasil, cbs, dualisia, fiscal, ibs, nfe, reforma-tributaria

## 简介

CLI oficial do Dualisia: apura CBS e IBS de XMLs de NF-e e consulta os dados do escritório pela API REST.
