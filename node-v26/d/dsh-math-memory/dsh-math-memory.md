# dsh-math-memory

> 标签: agent, deepseek, dsh, math, memory, notes, obsidian

## 简介

Obsidian side-panel math memory agent for DeepSeek Harness: layered long-term memory, idea memo with proactive review reminders, unified note_recall retrieval plus dedicated note search/create/backlink tools. Ships as both a dsh plugin and an Obsidian com
