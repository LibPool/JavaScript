# dsh-devlaunch

> 标签: deepseek-harness, devserver, dsh, dsh-plugin, launcher

## 简介

One-click dev-process launcher for the DSH web GUI: per-workspace launch configs (frontend / backend / other command groups), a session-header start button, and an in-session console tab streaming live process output over SSE. Host half spawns and supervi
