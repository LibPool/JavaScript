# dsh-whale-usage

> 标签: balance, deepseek-harness, dsh, dsh-plugin, usage, whale, widget

## 简介

桥接后的新产物：把 dsh-whale-widget（桌面鲸鱼挂件）与 dsh-usage-stats（用量统计）合并为一个自包含插件，并在挂件上提供「记账 / 实时令牌 / 应用用量」配置界面。不改原插件包，对上游更新免疫。
