# dsh-cursor-mcp

> 标签: cursor, deepseek-harness, dsh, dsh-plugin, mcp

## 简介

Cursor MCP servers (from ~/.cursor/mcp.json) re-packaged as DeepSeek Harness mcp-client rows (8 servers; HTTP secrets read at load time from the Cursor config).
