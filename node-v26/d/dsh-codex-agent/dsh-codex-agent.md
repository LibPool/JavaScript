# dsh-codex-agent

> 标签: agent, codex, cordis, deepseek-harness, dsh, entity, plugin

## 简介

Codex 长驻实体插件：通过 codex app-server --stdio（JSON-RPC）维护长驻进程，暴露 chat / startConversation / pull 接口（多轮会话、流式），供编排层（multi-role-debate）或直接对话调用。
