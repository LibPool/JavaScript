# dsh-greeting-prefix

> 标签: deepseek-harness, dsh, dsh-plugin, greeting, 前缀

## 简介

回答前缀插件：每次回复前先输出「好的，画卿晚主人!」，通过系统提示词注入规则，仅对顶层会话生效
