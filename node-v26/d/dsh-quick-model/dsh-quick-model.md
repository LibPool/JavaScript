# dsh-quick-model

> 标签: deepseek-harness, dsh, dsh-plugin, llm, models, provider, settings, web

## 简介

DSH web plugin: replaces the Settings → Models page with a one-stop panel — pick a preset or paste a baseURL + API key, fetch the model list from the endpoint, tick what you want, and save. Writes llm-pi-ai providers and credentials for you.
