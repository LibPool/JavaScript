# dsh-unified-agent-memory

> 标签: deepseek, dsh, dsh-plugin, harness, knowledge-base, memory, multi-agent, obsidian

## 简介

Unified agent memory for DeepSeek Harness — one shared Obsidian vault for every agent (dsh, Codex, Claude, Hermes). Ships the dependency-free Python core (search/promote/adjudicate/forget), a vault template, and a dsh plugin with memory_search / memory_sh
