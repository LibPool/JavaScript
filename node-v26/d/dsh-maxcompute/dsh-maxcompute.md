# dsh-maxcompute

> 标签: data-analysis, deepseek-harness, dsh-plugin, maxcompute, odps, sql

## 简介

MaxCompute (ODPS) data analysis plugin for DeepSeek Harness: metadata browsing, cost-gated SQL execution, background jobs and result export.
