# dsh-pathfix

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, normalizer, pathfix

## 简介

Host-layer DeepSeek Harness plugin that normalizes whitespace and trailing newlines in tool path and pattern parameters.
