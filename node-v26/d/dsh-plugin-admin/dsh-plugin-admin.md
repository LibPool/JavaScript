# dsh-plugin-admin

> 标签: admin, commands, cordis, dsh, dsh-plugin, hooks, mcp, session, subagent

## 简介

dsh web UI admin plugin: extension-plugin marketplace tab, MCP server & session-history settings pages, subagent management (named delegation-tool instances with persona/tool-filter/model config, plus external CLI backend mounting), slash-command & Claude
