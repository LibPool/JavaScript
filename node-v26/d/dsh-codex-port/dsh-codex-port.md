# dsh-codex-port

> 标签: codex, deepseek-harness, dsh, dsh-plugin, migration, plugin, skills

## 简介

DSH 技能移植工具插件：把 ~/.codex 里的 Codex 官方插件（170+ 个）一键移植为 DSH 技能（codex_list / codex_port / codex_status），frontmatter 自动转换、名称清洗、幂等跳过。
