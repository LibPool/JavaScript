# dsh-ears-prosody

> 标签: audio, deepseek-harness, dsh, dsh-plugin, emotion, paralinguistic, prosody, tone, voice, 声学, 语气, 语音

## 简介

给 DeepSeek Harness 加一双耳朵：把音频变成「怎么说的」而不是「说了什么」。本地声学层零依赖；带一个微信式「按住说话」录音键，落盘后自动转写内容（宿主语音服务优先，本地 SenseVoice 兜底）。
