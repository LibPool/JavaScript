# d3ja-vue

> 标签: JavaScript

## 简介

d3ja-vue is a vue component library for data visualization based on [D3.js](https://www.npmjs.com/package/d3). For now, most of the components are adaptation of Mike Bostock's D3 demonstration in [Observable notes](https://observablehq.com/@mbostock).
