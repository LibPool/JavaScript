# dream-cycle

> 标签: agent-evaluation, benchmark, capability-gate, eval, harbor, repo2rlenv, rl-environment

## 简介

Dream Cycle v0: synthesize a post-cutoff eval corpus from any GitHub repo (repo2rlenv pr_diff), calibrate with oracle/nop agents via harbor, gate with falsification, and run a reactive capability radar. The radar proposes; the human decides.
