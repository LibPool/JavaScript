# dsh-lit-search-mcp

> 标签: bibtex, citation, crossref, deepseek-harness, dsh-plugin, literature, mcp-server, model-context-protocol, openalex, semantic-scholar

## 简介

MCP server for academic literature search, citations (GB/T 7714 / APA) and BibTeX — wraps dsh-lit-search (Crossref + OpenAlex + Semantic Scholar, no API key).
