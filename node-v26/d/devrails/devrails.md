# devrails

> 标签: agents-md, ai, claude-code, cli, copilot, cursor, gemini, guardrails, llm, tool-agnostic

## 简介

Tool-agnostic guard-rails for AI-assisted development: one source of truth, synced to Claude Code, Cursor, Copilot, Gemini, and AGENTS.md, with deterministic enforcement via git hooks and CI.
