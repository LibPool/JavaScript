# dsh-plugin-restart

> 标签: bundle, cordis, deepseek-harness, dsh, electron, plugin, powershell, relaunch, restart, windows

## 简介

One-click DSH restart: a restart button that can live in several seats (with presets), an automatic end-of-reply prompt after a plugin change, and a detached supervisor that relaunches the DeepSeek Harness desktop app.
