# dsh-doc-share

> 标签: deepseek-harness, dsh, pdf, plugin, report, share

## 简介

DSH 对话报告化分享插件：生成带封面、摘要统计与章节排版的精美报告，导出为 PNG 图片 / 单 HTML 文件 / PDF。
