# dsh-image-vision

> 标签: cordis, deepseek-harness, dsh, image, ocr, skill, vision

## 简介

DeepSeek Harness plugin: gives text-only models (e.g. DeepSeek) image-reading ability via any OpenAI-compatible vision API. Registers the vision_query tool, DSH credentials integration, and the image-vision skill.
