# dsh-shared

> 标签: JavaScript

## 简介

DSH 插件共享工具包：Host-header 信任围栏、HTTP JSON 读写、配置持久化（cordis.patch.yml）、项目根解析、异步与消息工具、原子写。多插件共用实现，消除复制粘贴（issue #45）。
