# deepseek-balance-dsh

> 标签: balance, deepseek, deepseek-balance, deepseek-harness, dsh, dsh-plugin, monitor, npm, plugin, usage

## 简介

DeepSeek balance monitor for DeepSeek Harness: real-time topped-up balance, period consumption (per model) and token usage (cache-hit input / cache-miss input / output), plus peak/off-peak price reminder (Liang Wenfeng / Liang Wengu).
