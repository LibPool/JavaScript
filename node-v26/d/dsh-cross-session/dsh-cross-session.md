# dsh-cross-session

> 标签: cross-session, deepseek, dsh, harness, multi-agent, orchestration, plugin

## 简介

Cross-session messaging for DeepSeek Harness: spawn durable top-level sessions, send tasks to them over the same channel they reply on, without blocking the caller.
