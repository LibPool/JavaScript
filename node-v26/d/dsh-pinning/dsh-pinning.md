# dsh-pinning

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, pinning, security, supply-chain, trust, versions

## 简介

Version pinning for DeepSeek Harness: Pin DeepSeek Harness plugins to versions you have reviewed; silent upgrades are blocked until you diff and approve them. Name reserved; first release in development.
