# dsh-reasoning-dial

> 标签: custom-api, deepseek-harness, dsh-plugin, llm-pi-ai, reasoning-effort

## 简介

让任意自定义 API 模型都能声明并选择推理等级：直接编辑 llm-pi-ai 等自定义 provider 目录里每个模型的 reasoningEfforts，把官方那套 Off/Low/Medium/High/XHigh/Max 拨盘扩展到任何自定义 API 模型上。
