# dsh-file-browser

> 标签: cordis, deepseek-harness, dsh, file-browser, file-tree, plugin

## 简介

DeepSeek Harness 可视化文件浏览插件:会话头部按钮 + 右侧抽屉,浏览当前对话工作目录的文件树、查看文件内容、git 状态标记,支持选中文本提问。
