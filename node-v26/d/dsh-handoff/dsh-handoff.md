# dsh-handoff

> 标签: dsh-plugin, export, handoff, session

## 简介

DSH 插件：**会话交接一键导出**。把当前会话的目标、已完成/未完成、关键文件与统计，导出为一份**确定性的 Markdown 交接文档**。纯 ESM、零依赖、无构建。
