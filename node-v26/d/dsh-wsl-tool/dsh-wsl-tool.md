# dsh-wsl-tool

> 标签: deepseek-harness, dsh, dsh-plugin, interop, linux, shell, windows, wsl

## 简介

Model-facing WSL tools for DeepSeek Harness: run Linux commands from Windows with background jobs, stdin, path translation, destructive-command guard and WSL capability diagnostics.
