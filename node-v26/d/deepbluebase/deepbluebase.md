# deepbluebase

> 标签: agent, agentic-payments, ai, base, btc, crypto, deepblue, mcp, polymarket, sentiment, signals, solana, trading, usdc, x402

## 简介

JavaScript/TypeScript client for the DeepBlue Trading API — pay-per-call crypto signals, sentiment, and Polymarket analytics via x402 (USDC on Base/Solana). Includes free-demo mode (5 calls/day per IP, no wallet).
