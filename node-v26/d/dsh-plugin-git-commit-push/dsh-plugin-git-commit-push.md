# dsh-plugin-git-commit-push

> 标签: deepseek-harness, dsh, dsh-git, dsh-git-commit, dsh-git-push, dsh-plugin

## 简介

0 Token Git 提交推送插件，一次调用完成，按 Conventional Commits 为每个变更文件自动生成提交信息并按 type(scope) 拆成多次提交后一次推送到Git，必要时询问打标签。One-call Conventional-Commits git workflow for DeepSeek Harness: survey + one commit per type(scope) + optional tag + push, plus a /git-commit-push sla
