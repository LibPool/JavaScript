# dsh-checklists

> 标签: agent, checklist, cordis, deepseek-harness, dsh, dsh-plugin

## 简介

Session-scoped checklists for DeepSeek Harness: the agent tracks work as a tree, the model always sees a compact digest, and a read-only sidebar tab mirrors it.
