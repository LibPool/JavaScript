# dsh-tokensaver

> 标签: agent, compaction, deepseek, dsh, memory, plugin, token

## 简介

DSH plugin: reversible memory layer (CCR) + auto context compaction to save tokens. Bridges the TokenSaver Python CLI into DeepSeek Harness.
