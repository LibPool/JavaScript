# dsh-prompt-setting

> 标签: deepseek-harness, dsh, dsh-plugin, prompt, settings, system-prompt, ui

## 简介

DeepSeek Harness 默认 System Prompt 管理插件：在 Web GUI「设置」里浏览、检索并覆盖最终装配进每轮会话的系统提示词。
