# dsh-conversation-link

> 标签: agent, conversation, conversation-link, cordis, cross-session, deepseek, deepseek-harness, dsh, dsh-plugin, guardrails, multi-agent, peer-messaging, plugin, supervision, supervisor

## 简介

DeepSeek Harness（DSH）对话互通插件：让同一进程里的对话互相发现、直接发消息、盯进度、设护栏——不用先绑定，也不用开子代理。Peer messaging, supervision, and tool guardrails between conversations.
