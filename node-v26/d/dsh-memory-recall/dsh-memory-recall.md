# dsh-memory-recall

> 标签: deepseek-harness, dsh, dsh-plugin, hermes, memory, recall, session-search

## 简介

Persistent memory for dsh in the style of Hermes Agent: a memory tool that keeps a user profile and the model's own notes, delivered to every chat as a logged context message — at the start, after a change and after compaction — and a session_search tool
