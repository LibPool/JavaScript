# dsh-solution-explorer

> 标签: deepseek-harness, dsh-plugin, file-explorer, git, sidebar, source-control

## 简介

DSH Web GUI right sidebar, replaced end to end: VS Code-style file explorer plus full source control (git status, stage/unstage/discard, commit, diff, commit graph, fetch/pull/push sync, branch/remote management, git init, multi-repo switch, color-coded s
