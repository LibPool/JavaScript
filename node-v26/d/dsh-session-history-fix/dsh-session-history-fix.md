# dsh-session-history-fix

> 标签: agent-teams, deepseek, deepseek-harness, dsh, dsh-desktop, electron, fix, history, plugin, session

## 简介

Fix DSH Desktop / DeepSeek Harness 'history unavailable ... SessionFormatUnsupportedError' caused by out-of-repo plugin session events (dsh-agent-teams, dsh-message-edit, dsh-web-search-exa) not being in the core event vocabulary
