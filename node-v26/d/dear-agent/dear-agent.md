# dear-agent

> 标签: agent, ai-agent, ai-diary, claude, cursor, daily-journal, diary, diary-mcp, journal, journal-keeper, journal-mcp, journaling, life-journal, life-log, local-first, mcp, memory, model-context-protocol, openclaw, personal-journal, personal-memory, voice-journal

## 简介

Dear Agent — your AI agent keeps your diary for you. A local-first MCP server + skill that lets any AI agent maintain a human's daily life journal from text, photos, and voice notes. You never open an app or write a word.
