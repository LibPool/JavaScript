# dsh-api-gateway

> 标签: api, cordis, deepseek-harness, dsh, gateway, plugin

## 简介

DSH 业务系统 HTTP API 网关：随 DSH 启动常驻，默认关闭，可通过侧边栏图标或设置页手动启用，为业务系统提供任务提交、会话、用户、工作区、记忆等 HTTP API。
