# dsh-todo-audit

> 标签: audit, comment, dsh, fixme, plugin, scan, todo

## 简介

TODO audit plugin for DeepSeek Harness: scan source trees for TODO/FIXME/HACK/XXX style comments across languages, filter by tag, extension and depth, and aggregate reports by tag, extension, directory and file. Zero runtime dependencies, read-only.
