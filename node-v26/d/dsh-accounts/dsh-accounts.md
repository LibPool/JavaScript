# dsh-accounts

> 标签: auth, authentication, authorization, dsh, dsh-plugin, login, multi-tenant, postgresql, user-management, workspace-isolation

## 简介

DSH 多租户账户与授权插件：PostgreSQL 存储 + admin 管理 API + 每账户独立工作目录（独立插件，不改 DSH 核心）
