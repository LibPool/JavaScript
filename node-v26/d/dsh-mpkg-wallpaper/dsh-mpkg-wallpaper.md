# dsh-mpkg-wallpaper

> 标签: background, dsh, dsh-plugin, mpkg, wallpaper-engine, web-ui

## 简介

DSH Web 壁纸引擎 Wallpaper Engine mpkg 背景插件：浏览器内直接解析 .mpkg（preview.gif 动态背景/内嵌 mp4 视频/多时段切换），整屏统一虚化/对话框/弹层/遮罩独立虚化、镜头缩放平移、时钟、冲突检测。
