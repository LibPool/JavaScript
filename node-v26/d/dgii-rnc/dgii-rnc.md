# dgii-rnc

> 标签: dataset, dgii, dominican republic, nodejs, registry, rnc, tax

## 简介

Node.js library to query and periodically update the Dominican Republic’s DGII RNC taxpayer registry.  This package abstracts away the original API server and exposes a simple programmatic interface for downloading, parsing and searching the DGII RNC data
