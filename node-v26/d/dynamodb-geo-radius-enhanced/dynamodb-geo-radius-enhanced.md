# dynamodb-geo-radius-enhanced

> 标签: JavaScript

## 简介

An enhancement to rh389/dynamodb-geo.js, for dynamodb geospatial querying. Enhanced the radius query to sort by distance in ascension. Added a flag to change distance calculation to simple plane calculation.
