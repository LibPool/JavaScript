# date-fns-hijri

> 标签: calendar, converter, date-fns, fcna, functional, gregorian, hijri, islamic, typescript, umm-al-qura

## 简介

date-fns-style utility functions for Hijri calendar operations. Wraps hijri-core with a functional API for converting, formatting, and validating Hijri dates.
