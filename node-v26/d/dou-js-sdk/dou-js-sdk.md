# dou-js-sdk

> 标签: JavaScript

## 简介

DOU-JS-SDK是一个用于JS前端的SDK，第三方开发者可以通过该SDK将DOU钱包整合到前端，从而允许用户使用其DOU账户进行登陆、签名、交易等操作。
