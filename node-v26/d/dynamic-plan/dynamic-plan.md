# dynamic-plan

> 标签: ai-agent, claude-code, codex, hermes, mdx, opencode, pi, planning, skill, slash-command, wireframe

## 简介

Generate interactive .mdx implementation plans with Figkit-style wireframes, Mermaid diagrams, and decision forms. Works as a slash command in Claude Code, Codex, OpenCode, Hermes, and Pi.
