# dsh-zh-hant

> 标签: deepseek, deepseek-harness, dsh, dsh-plugin, i18n, locale, traditional, traditional-chinese, zh-hant, zh-tw

## 简介

Traditional Chinese (繁體中文) language pack for DeepSeek Harness (DSH): registers a zh-Hant locale and ~2,700 generated dictionaries across every namespace the web GUI uses, with a switch in Settings → General → Language
