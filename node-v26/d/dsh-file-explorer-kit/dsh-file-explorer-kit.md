# dsh-file-explorer-kit

> 标签: cordis, deepseek-harness, dsh, file-browser, file-explorer, plugin

## 简介

dsh (DeepSeek Harness) file explorer: browse the active session's workspace and preview files (Markdown/image/PDF/text/binary) right inside the chat GUI — a standard Cordis bundle plugin (read-only /dsh-files host routes on ctx.webServer + a conversation.
