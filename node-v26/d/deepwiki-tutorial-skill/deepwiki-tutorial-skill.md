# deepwiki-tutorial-skill

> 标签: ai-agent, deepwiki, documentation, mermaid, project-analysis, skill, tutorial

## 简介

基于 DeepWiki 风格，为本地项目自动生成完备的技术教程文档。支持项目扫描、智能文件筛选、Mermaid 图表生成。
