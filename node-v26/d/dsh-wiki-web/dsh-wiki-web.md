# dsh-wiki-web

> 标签: deepseek-harness, dsh, knowledge-base, obsidian, self-hosted, wiki

## 简介

Self-hosted web UI for your Markdown wiki vault: browse, BM25 search, link graph, lint dashboard — no Obsidian, no database. Standalone, or pair with dsh agent plugins.
