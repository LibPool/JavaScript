# decisionmatrix-mcp

> 标签: ahp, ai, ai-agents, claude, cursor, decision-analysis, deterministic, llm, mcda, mcp, mcp-server, model-context-protocol, topsis, weighted-scoring

## 简介

DecisionMatrix MCP — deterministic multi-criteria decision analysis for AI agents: score, rank & explain options with weighted-sum, weighted-product, or TOPSIS. Runs over stdio (npx) or as a remote server.
