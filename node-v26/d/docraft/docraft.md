# docraft

> 标签: cli, document-generation, docx, markdown, odt, pages, pdf, placeholder, template

## 简介

CLI tool that detects {{PLACEHOLDER}} fields in docx, odt, pages, pdf and markdown documents and fills them in interactively or via automation.
