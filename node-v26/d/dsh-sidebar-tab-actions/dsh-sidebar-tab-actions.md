# dsh-sidebar-tab-actions

> 标签: deepseek-harness, dockkit, dsh, plugin, sidebar, tabs

## 简介

右侧栏标签页右键菜单增强：在「关闭」之外增加「关闭其他 / 关闭左侧 / 关闭右侧 / 关闭全部」，范围限定在右键所在的窗格。
