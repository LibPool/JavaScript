> 标签: binary-analysis, bundle, cordis, cordis-plugin, deepseek, deepseek-harness, dsh, dsh-plugin, ghidra, mcp, rea, reverse-engineering

## 简介

One-plugin bundle: provisions Node/REA/JDK/Ghidra for you, then registers the upstream REA MCP server as mcp__rea__* tools. · 一体包：自动准备 Node/REA/JDK/Ghidra，并把上游 REA 的 MCP 服务接入 DeepSeek Harness。
