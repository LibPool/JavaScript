# dsh-plugin-mcp-session-meta

> 标签: deepseek-harness, dsh, dsh-plugin, mcp, mcp-client, session

## 简介

DeepSeek Harness MCP client bridge that carries the calling Agent's session id in tools/call params._meta, so MCP servers can tell which conversation is calling.
