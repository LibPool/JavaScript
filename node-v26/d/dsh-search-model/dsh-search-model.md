# dsh-search-model

> 标签: dsh-plugin, dsh-search-model, jsoncode

## 简介

DeepSeek Harness Web 客户端插件：接管 composer 的【模型与推理等级】座位，在「模型」子列表首位插入一个大小写不敏感的连续子串模糊搜索框（div>input），实时过滤已配置模型；弹框宽度锁定防抖动。
