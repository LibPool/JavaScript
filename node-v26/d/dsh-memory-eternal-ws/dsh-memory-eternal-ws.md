# dsh-memory-eternal-ws

> 标签: deepseek-harness, dsh, dsh-plugin, knowledge-base, knowledge-graph, markdown, memory, per-project, plugin, rag, second-brain, vault, workspace

## 简介

记忆核心（工作区版 memory-eternal-ws）：按 DSH 工作区自动切库的本地 Markdown 记忆库插件。每个项目用自己的 .dsh/memory-vault，跨项目知识走全局库。fork 自 dsh-memory-eternal v0.7.0，保留自动沉淀 / 自动召回 / 知识卡 / 知识图谱 / 审核中心 / 回收站 / 配置页全部功能。
