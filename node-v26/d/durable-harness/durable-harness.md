# durable-harness

> 标签: agent, agents, ai, claude-code, codex, durability, durable, harness, libfx, nextjs, opencode, pi, vercel, workflow, workflow-sdk, world

## 简介

Durable coding-agent harnesses (Claude Code, Codex, OpenCode, Pi) on a Workflow SDK World: the session is a run, its event log the source of truth, and a crash resumes the turn from the log on another machine.
