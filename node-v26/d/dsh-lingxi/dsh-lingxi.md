# dsh-lingxi

> 标签: companion, cordis-plugin, deepseek-harness, desktop-pet, dsh, dsh-plugin, lingxi

## 简介

Lingxi (灵犀) for the DeepSeek Harness (dsh) - the desktop cat that reacts to how the work FEELS: five model tools (task/say/react/state/remember) over the pet bridge, a settings page with live bridge status, and an agent identity of its own.
