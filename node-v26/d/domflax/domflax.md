# domflax

> 标签: css, dom, html, jsx, optimizer, tailwind, unplugin, vite-plugin, webpack-plugin

## 简介

Compile-time DOM flattener and semantic CSS compressor — fewer DOM nodes, smaller class sets, identical rendered UI.
