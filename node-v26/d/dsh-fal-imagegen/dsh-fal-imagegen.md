# dsh-fal-imagegen

> 标签: agent-tools, deepseek-harness, dsh, dsh-plugin, fal, fal.ai, image-generation, image-to-image, text-to-image

## 简介

fal.ai native image generation for DSH: a FAL_KEY settings card that follows DSH's language (zh/en, English default) plus Agent tools (fal_generate_image async / fal_edit_image / fal_get_image_task / fal_list_image_models) that call queue.fal.run directly
