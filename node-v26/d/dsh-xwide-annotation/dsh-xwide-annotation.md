# dsh-xwide-annotation

> 标签: JavaScript

## 简介

DSH Web selection-annotation plugin: select assistant text, annotate (optional), and press Enter to send the annotation block with your message — the model replies to each annotation by number, with hoverable chips in the reply. X-WIDE fork adds a color s
