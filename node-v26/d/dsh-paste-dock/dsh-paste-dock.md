# dsh-paste-dock

> 标签: attachment, deepseek-harness, dock, dsh, dsh-plugin, paste

## 简介

dsh-paste-dock — DeepSeek Harness 插件:大段文本粘贴自动存为 pastes/*.txt,输入框上方 dock 卡片管理,草稿内只留最小徽标。
