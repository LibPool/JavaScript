# dnv-vista-sdk

> 标签: dnv, dnvgl, iso-19847, iso-19848, maritime, vis

## 简介

The Vista SDK packages codify the rules and principles of DNV Vessel Information Structure (VIS) and ISO19848/19847 standards to enable and support users and implementers.
