# dsh-acrylic

> 标签: acrylic, css-tokens, deepseek-harness, dsh, dsh-plugin, fluent, plugin, theme, web-gui, win10, windows

## 简介

Windows 10 (Fluent) acrylic theme for the DSH Web GUI and desktop app: Win10 light/dark --dsw-* token palette, site-wide square corners, and bounded backdrop-filter acrylic on the sidebar, task board and right-hand file panel. Dual-half plugin: a browser
