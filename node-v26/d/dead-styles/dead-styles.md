# dead-styles

> 标签: css-in-js, dead-code, jss, knip, makeStyles, mui, static-analysis, tss-react, unused-css

## 简介

Find unused CSS-in-JS classes (tss-react / MUI makeStyles / JSS) and unused global Sass/SCSS/CSS classes across your whole project, not just one file
