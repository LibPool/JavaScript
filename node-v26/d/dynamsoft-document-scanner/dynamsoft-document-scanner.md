# dynamsoft-document-scanner

> 标签: camera, document scanning, dynamsoft, javascript, js, passport, scanner, ui, vision

## 简介

Dynamsoft Document Scanner (DDS) is a ready-to-use SDK for capturing and enhancing document images with automatic border detection, correction, and customizable workflows.
