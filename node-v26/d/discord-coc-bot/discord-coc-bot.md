# discord-coc-bot

> 标签: bot, dice, discord, roleplaying

## 简介

A Discord bot that contains commands useful for Call of Cthulu text roleplaying, based on RPbot by Gawdl3y (https://github.com/Gawdl3y/discord-rpbot/)
