# dsh-look

> 标签: accessibility, agent, context-aware, deepseek-harness, dsh, macos, ocr

## 简介

Scene-awareness probe for DeepSeek Harness: a privacy-first `look` tool that reads the frontmost non-self window (app / AX / local OCR) on macOS, plus summon-hotkey snapshot capture.
