# dsh-desktop-app

> 标签: china-mirror, deepseek-harness, desktop, dsh, skill, tauri, windows

## 简介

DSH 桌面壳「小南梁」技能包：把 DeepSeek Harness 封装成 Tauri 2 桌面应用（macOS+Windows），含托盘常驻、任务通知、鲸鱼娘桌宠、国内镜像加速、Windows 无管理员工具链
