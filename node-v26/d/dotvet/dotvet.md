# dotvet

> 标签: ci, cli, devsecops, dotenv, env, jwt, linter, secrets, security, validation

## 简介

Zero-config environment variable security scanner and quality gate CLI. Validates presence, bans placeholders, and enforces secret strength (e.g. JWT >= 32 chars).
