# dapp-browser-mcp

> 标签: claude, dapp, ethereum, evm, mcp, metamask, model-context-protocol, playwright, wallet, web3

## 简介

MCP server that gives any agent a Chromium + MetaMask so it can interact with EVM dApps — connect wallets, switch chains, read receipts, classify UI state. Auto-downloads MetaMask on first launch.
