# declick

> 标签: agents, automation, claude-code, cli, graphql, har, mcp, openapi, postman, sqlite, swagger, ui-automation, web-automation, windows

## 简介

Compile an API, an MCP server, or a database into a CLI your agent can run. Ten engines, one output contract.
