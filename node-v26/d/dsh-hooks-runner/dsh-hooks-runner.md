# dsh-hooks-runner

> 标签: agentmemory, cordis, deepseek-harness, dsh, hooks, lifecycle, plugin

## 简介

DSH event bridge to agentmemory hook scripts (stdin JSON protocol, Claude-hooks compatible); silent-failure degradation. Script directory and fallback cwd are env-resolved (DSH_HOOKS_SCRIPTS_DIR / DSH_HOOKS_FALLBACK_CWD).
