# dtns-rpc-fast

> 标签: android, datachannel, download, file-transfer, node, opfs, p2p, rpc, upload, webrtc

## 简介

Upload-as-reverse-download WebRTC RPC framework with dynamic chunking, server-driven retransmission and resumable transfer.
