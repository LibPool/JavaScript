# dsh-plugin-wwrs-ffmpeg

> 标签: deepseek-harness, dsh, dsh-plugin, ffmpeg, media

## 简介

Local media processing DSH plugin (open source): probe/transcode/concat/slice/mux/burn-subtitles via local ffmpeg/ffprobe. Sole runtime dependency is @deepseek-ai/dsh-tools (defineTool DSL); binaries resolved config > env > package .bin > PATH.
