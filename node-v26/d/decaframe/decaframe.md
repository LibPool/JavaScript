# decaframe

> 标签: agent, claude, cursor, deck, export, mcp, one-pager, presentation, report, slides

## 简介

Agents author, humans edit: presentations, reports and one-pagers from an MCP server, with a WYSIWYG editor and a one-file HTML export.
