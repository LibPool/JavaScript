# dsh-todo-float

> 标签: deepseek-harness, dsh, dsh-plugin, floating-card, session, sidebar, todo, ui

## 简介

Float the conversation to-do list as a collapsible card in the top-right corner of the session, switchable back to the stock panel from Settings.
