# ddys-dingtalk-bot

> 标签: api, bot, ddys, dingding, dingtalk, interactive-card, stream, webhook

## 简介

Official DingTalk bot integration for the DDYS API with custom robot webhooks, enterprise bot callbacks, Stream mode adapters, interactive cards, access control, diagnostics, and cache support.
