# danskadresseapi-sdk

> 标签: address, adresse, autocomplete, bbr, dagi, danmark, datavask, dawa, denmark, geocoding, replikering, webhook

## 简介

Officiel JavaScript/TypeScript SDK for DanskAdresseAPI — drop-in DAWA replacement. Taler DAWA-fladen (/dawa) med BBR, statistik og batch som udvidelser, replikering-iterator, webhook-verify og React hooks.
