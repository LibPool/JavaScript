# dsh-schedule-later

> 标签: deepseek-harness, dsh, dsh-plugin, reminder, schedule, scheduled-send, skill, timer, tools

## 简介

Schedule a message into a dsh chat for later: a Schedule button in the message box with a date and time picker, a sidebar panel of pending messages across chats, delivery as a normal user message even with the browser closed, and schedule_message, list_sc
