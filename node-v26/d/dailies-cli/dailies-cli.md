# dailies-cli

> 标签: ai-agent, browser-automation, dailies, demo-video, playwright, pull-request, qa, screencast, testing

## 简介

Dailies CLI. Records a browser session as ordered steps — trace, video, HAR, console — renders a self-contained report, and can cut the recording into a narrated demo film.
