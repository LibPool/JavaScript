# dsh-memory-pyramid

> 标签: agent-memory, cordis, deepseek-harness, dsh, dsh-plugin

## 简介

给 DeepSeek Harness 补上时间轴记忆：定宽只追加的事实日志 + agent 自己维护的摘要金字塔，固定阅读预算下 recall 成本不随记忆量增长。
