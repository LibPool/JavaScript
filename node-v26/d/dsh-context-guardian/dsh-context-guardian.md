# dsh-context-guardian

> 标签: compaction, context-management, context-window, deepseek-harness, dsh, dsh-bundle, dsh-plugin, local-llm, ollama, recall

## 简介

Context Guardian as a native DeepSeek Harness (DSH) bundle: deterministic, seq-pointer-preserving compaction with model-facing recall and search. Companion to dsh-tool-guardian.
