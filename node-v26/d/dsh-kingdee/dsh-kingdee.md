# dsh-kingdee

> 标签: bos, deepseek-harness, dsh, erp, kingdee, kingdee-cloud, kingdee-starry-sky, plugin, webapi

## 简介

Kingdee Cloud Starry Sky secondary-development plugin for DeepSeek Harness (DSH). Typed tools over the Kingdee Cloud WebAPI, credential-safe config, and a companion domain skill.
