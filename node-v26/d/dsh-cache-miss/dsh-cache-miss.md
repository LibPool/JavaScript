# dsh-cache-miss

> 标签: deepseek-harness, dsh, dsh-plugin, prompt-cache

## 简介

DSH web plugin: a yellow one-line cache-miss notice under the first assistant reply of each turn, when that turn's first request rebuilt the prompt cache.
