# dsh-tinyfish-websearch

> 标签: deepseek-harness, dsh, plugin, search, tinyfish, web-search

## 简介

dsh bundle plugin: replaces the default web_search provider with TinyFish (ctx.web seam), with a Settings → TinyFish 搜索 key form
