# dsh-aloof

> 标签: aloof, deepseek-harness, dsh, dsh-plugin, oa

## 简介

把 Aloof 的办公审批接成 DeepSeek Harness 的原生工具：查待办、看可发起的审批、读表单字段、发起单子。写操作先过 dsh 的审批闸门。
