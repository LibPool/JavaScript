# dsh-plugin-devkit

> 标签: cordis, deepseek-harness, devkit, dsh, dsh-plugin, plugin-development, scaffold

## 简介

开发者工具包：一键生成合规 dsh 插件脚手架（默认 TypeScript，可选 JavaScript）、按三条硬规则校验 schema、生成社区注册表发布条目。
