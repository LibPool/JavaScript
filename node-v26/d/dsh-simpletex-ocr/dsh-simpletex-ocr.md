# dsh-simpletex-ocr

> 标签: JavaScript

## 简介

SimpleTex 专用 OCR/公式识别工具 simpletex_recognize：task=formula 返回 LaTeX（含置信度），task=text 返回 Markdown，task=auto 按问题关键词路由。GUI 设置卡热配置 token/端点/上限。
