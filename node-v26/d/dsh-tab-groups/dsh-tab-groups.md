# dsh-tab-groups

> 标签: browser-extension, chrome-extension, deepseek-harness, dsh, dsh-plugin, tab-groups, tabs

## 简介

Automatically group every DeepSeek Harness (DSH) Web GUI tab into one browser tab group. One package, two faces: the Chromium extension owns all grouping behaviour, and the DSH plugin mirrors it to a fixed path, detects it in the Web GUI, guides installat
