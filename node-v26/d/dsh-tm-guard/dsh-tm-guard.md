# dsh-tm-guard

> 标签: autonomous-agent, deepseek-harness, dsh, dsh-plugin, macos, permission-gate, sandbox, security, time-machine

## 简介

Time-Machine-backed autonomous agent permission gate for DeepSeek Harness (dsh). Allows TM-rollback-able operations, blocks everything else.
