# dsh-nl-model-switch

> 标签: deepseek-harness, dsh, dsh-plugin, model-switch, natural-language

## 简介

Switch the current DSH session's model with a natural-language sentence, on web, TUI, or IM bridges (WeChat, Feishu, etc.).
