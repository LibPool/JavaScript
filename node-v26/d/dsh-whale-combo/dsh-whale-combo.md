# dsh-whale-combo

> 标签: balance, deepseek-harness, dsh, dsh-plugin, token-monitor, whale

## 简介

在鲸鱼娘旁显示毛玻璃拟态的状态气泡（余额 ¥ / 今日 ¥ / 缓存命中 / 峰谷，本轮在悬停提示里），并在每次计费时播放命中·输出·未命中扣费弹幕；Ctrl+Alt+D 可显示 damage-pulse 原悬浮卡。数据合并自 dsh-damage-pulse 与 dsh-whale-widget。
