# dsh-mobile-webui

> 标签: dsh, dsh-plugin, mobile, responsive, webui

## 简介

Mobile-viewport fixes for the dsh web GUI: overlay drawer sidebar, code-block scrolling, dvh/safe-area composer, 44px touch targets
