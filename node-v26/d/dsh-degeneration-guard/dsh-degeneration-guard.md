# dsh-degeneration-guard

> 标签: deepseek-harness, degeneration, dsh, dsh-plugin, loop, plugin, reasoning, repetition, 复读, 退化

## 简介

DeepSeek Harness 插件：检测思考段复读并自动打断、自动续跑。通用重复检测，不依赖白名单；支持行内重复开关、可编辑拦截提示词与聊天内提示。
