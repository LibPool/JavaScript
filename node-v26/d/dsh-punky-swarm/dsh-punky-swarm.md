# dsh-punky-swarm

> 标签: cluster, deepseek-harness, dsh, gates, governance, multi-agent, orchestration, plugin, swarm, tier3

## 简介

dsh-punky-swarm — dsh 插件（DeepSeek Harness）· punky 署名 · 集群治理（swarm governance）引擎：单机多子 agent 治理，wavePlan 三层 DAG + 引擎级门禁（Entry / Plan Contract / Exit / Complete）+ 状态机 + 锁/mailbox + 会话隔离 + 国标 AIP 兼容 + 全能力治理增强。附蟛蜞模式预设与 jiufeng-team 角色指引。
