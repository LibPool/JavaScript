# dsh-test-report

> 标签: ci, dsh, junit, plugin, report, tap, test, testing

## 简介

test report toolkit for DeepSeek Harness: parse_junit (parse JUnit XML), parse_tap (parse TAP protocol), summarize (pass rate / slowest cases / failure clustering). Zero runtime dependencies, read-only.
