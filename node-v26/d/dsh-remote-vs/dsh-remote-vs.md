# dsh-remote-vs

> 标签: deepseek-harness, dsh, dsh-plugin, remote-development, remote-editor, sftp, ssh, terminal, vscode

## 简介

VSCode-style remote development for DSH: SSH host manager (key/password), helper deploy pipeline with version check, remote file explorer + editor + terminal in dsh-better-sidebar.
