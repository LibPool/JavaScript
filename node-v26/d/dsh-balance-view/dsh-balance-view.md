# dsh-balance-view

> 标签: balance, deepseek, dsh, harness, plugin

## 简介

显示当前 DeepSeek API Key 对应账号的账户余额（/balance 命令 + 输入框上方常驻面板，支持轮询 / 对话后 / 手动刷新）
