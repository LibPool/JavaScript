# dsh-opencode-quota

> 标签: deepseek, deepseek-harness, dsh, dsh-plugin, monitor, opencode, opencode-go, quota, usage

## 简介

Quota monitor for the DeepSeek Harness Web GUI: OpenCode Go plan usage + DeepSeek API balance/usage, as a draggable bottom-left monitor window (host face proxies APIs, keys stay on disk).
