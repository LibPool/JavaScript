# dsh-session-rows

> 标签: conformance, contract, fixture, harness-free, rows, session

## 简介

The rules every producer of session rows must obey -- the vocabulary, the text rules, the source rule -- and the conformance fixture that pins them. Imports no dsh code and no harness code.
