# dunjn-mcp

> 标签: campaign, claude, dunjn, game-master, mcp, model-context-protocol, rpg, ttrpg

## 简介

Stdio bridge for the Dunjn MCP server: relays stdio JSON-RPC to https://app.dunjn.io/api/mcp/v1 over HTTPS with a personal API key.
