# dsh-sidebar-toggle

> 标签: deepseek-harness, dsh, dsh-plugin, flat-list, group-by, sessions, shortcut, sidebar, toggle, web-ui, workspace, 会话列表, 侧边栏, 分组切换, 工作区, 平铺视图, 快捷键

## 简介

Quickly toggle the DeepSeek Harness Web UI sidebar grouping between workspace and flat list via Alt+R or by clicking the section header title (Sessions / Workspaces). dsh Web GUI 侧边栏分组快捷切换插件：支持按 Alt+R 快捷键或直接点击侧边栏分组标题（会话 / 工作区）在工作区分组与平铺会话列表间一键切换。
