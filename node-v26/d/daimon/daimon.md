# daimon

> 标签: ai-tools, angular, claude-code, cli, dev-server, mcp, nx, process-manager, storybook, tui, vite

## 简介

Local dev-server manager for 20+ frameworks (Angular/Nx/Next.js/Vite/Django/Rails/.NET/Flutter/Deno/Bun…) — dev servers, tests, crash forensics, and full-text search behind a TUI, loopback HTTP API, JSON CLI, and MCP server for Claude Code
