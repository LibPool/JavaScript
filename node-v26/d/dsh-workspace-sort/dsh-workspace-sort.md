# dsh-workspace-sort

> 标签: bundle, deepseek-harness, dsh, plugin, sidebar, workspace

## 简介

DeepSeek Harness (DSH) bundle: re-sort sidebar workspaces by last activity once per day, stable within the day (侧边栏工作区顺序每日按最近活动刷新，当天稳定)
