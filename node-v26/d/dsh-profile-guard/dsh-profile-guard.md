## 简介

Safety net for the dsh CLI plugin path: preflight installs, snapshot healthy profiles, auto-rollback on boot failure, hot-mount plain-insert plugins without restart, and one-command phone access URL. (① install insurance ② preflight gate ③ hot-mount ④ rem
