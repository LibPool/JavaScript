# dependabot-for-git

> 标签: bitbucket, dependabot, dependencies, dependency update, dependency updates, gitlab

## 简介

Runs dependabot/cli update jobs against Bitbucket Cloud or GitLab repos and turns the results into real pull/merge requests.
