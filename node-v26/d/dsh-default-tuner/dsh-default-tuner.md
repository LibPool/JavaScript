# dsh-default-tuner

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, session-title, settings

## 简介

在 DSH Web 设置里新增「默认设置覆盖」分区，把官方插件写死在 bundle 里的默认值变成可配置项：会话标题长度、标题模型输入上限等。
