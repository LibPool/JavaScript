# dsh-project-kanban

> 标签: deepseek-harness, dsh, dsh-plugin, kanban, plugin

## 简介

DeepSeek Harness 项目看板（双端）：浏览器看板 UI + 8 个 kanban_* 模型工具，按工作区（项目）隔离，磁盘持久化
