# dyscalculia-mcp

> 标签: dyscalculia, education, learning-disability, mathematics, mcp, model-context-protocol, prevalence, research, statistics

## 简介

MCP server for Dyscalculia.io: sourced dyscalculia prevalence figures with sample size, year, age and reference, the reference list with DOIs, the chart and table datasets, and a description of the five number-skill screening games. Read-only.
