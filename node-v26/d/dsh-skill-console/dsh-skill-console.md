# dsh-skill-console

> 标签: deepseek-harness, dsh, dsh-plugin, skill, skill-manager, skills

## 简介

DeepSeek Harness 技能控制台：在 Web GUI 里浏览全部本地技能、一键启用/停用、删除到可恢复回收站，以及从本地路径或 GitHub 仓库导入技能。
