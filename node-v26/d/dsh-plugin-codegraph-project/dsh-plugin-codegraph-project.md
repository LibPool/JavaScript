# dsh-plugin-codegraph-project

> 标签: code-intelligence, codegraph, cordis, deepseek-harness, dsh, mcp, plugin

## 简介

Project-scoped CodeGraph for DeepSeek Harness: launches codegraph's MCP server through npx, shares one instance per project root across sessions, selects the global codegraph version, and injects its tools only into workspaces that actually have an index
