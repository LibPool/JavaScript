# dsh-remote-workspace

> 标签: client-plugin, deepseek-harness, dsh, dsh-plugin, remote-workspace, ssh

## 简介

Open an SSH host as a DeepSeek Harness workspace: a headless execution-world server runs on the remote machine while the agent loop, models and credentials stay local.
