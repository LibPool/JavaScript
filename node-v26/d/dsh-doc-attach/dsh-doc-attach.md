# dsh-doc-attach

> 标签: agent-tools, cordis, deepseek-harness, doc, document-qa, docx, dsh, dsh-plugin, pdf, ppt, pptx, rag

## 简介

Drag-and-drop document reading for DeepSeek Harness: land PDF / Word / PowerPoint files in the workspace and give the agent outline, search and read tools so it can answer questions from them.
