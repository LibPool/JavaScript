# dsh-dict-7

> 标签: chinese, dictionary, dsh, en-zh, offline, plugin, wordbook

## 简介

DSH 离线中英词典插件：会话内选中文字右键弹出释义（英→中/中→英），含发音（拼音/IPA + 🔊）、加入单词本；侧边栏一键打开单词本。词典数据 CC-CEDICT（约 12.5 万词条）+ CMU 词典转 IPA，全离线自包含。
