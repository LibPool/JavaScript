# defuscator

> 标签: deobfuscation, deobfuscator, javascript, malware-analysis, obfuscator, reverse-engineering, sarif, security, static-analysis, unpacker

## 简介

Static JavaScript deobfuscation and risk triage. Unpacks obfuscator.io string arrays, P.A.C.K.E.R., JSFuck, JJEncode and source maps, and emits JSON or SARIF - without ever executing the analyzed code.
