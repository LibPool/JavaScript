# debugtrace-js

> 标签: debug

## 简介

debugtrace-js is a library that outputs trace logs when debugging JavaScript programs; it can be used in Node.js, Bun, and Deno, as well as in browsers such as Chrome, Edge, Firefox, and Safari.
