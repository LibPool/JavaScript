# dsh-declutter

> 标签: declutter, deepseek-harness, dsh, dsh-plugin, rule-table, view

## 简介

DSH 界面收纳插件：把已经失败却后来成功的轮次、空轮、编辑产生的合成轮收起来——只改视图属性，完全可逆，绝不改会话日志；规则表化 + 逐条自检。
