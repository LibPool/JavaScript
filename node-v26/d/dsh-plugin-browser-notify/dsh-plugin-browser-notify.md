# dsh-plugin-browser-notify

> 标签: JavaScript

## 简介

DSH 浏览器通知插件：任务完成或需要审批时，通过浏览器系统通知 + 页内 toast 提醒用户。官方 bundle 插件，dsh plugin --profile web add：github:Caxson/dsh-plugin-browser-notify#main
