# dsh-ui-sound

> 标签: deepseek-harness, dsh, dsh-plugin, sound-effects, ui-sfx, web-audio

## 简介

DSH Web UI sound effects (community port of dsh-plugin-uisfx for DeepSeek Harness 0.2.0): semantic cues for interface interaction and task-status changes, with a per-scenario settings page and durable preferences.
