# darksadasyt-imgbb-scraper

> 标签: JavaScript

## 简介

`darksadasyt-imgbb-scraper` is a lightweight Node.js module to upload images to [ImgBB](https://imgbb.com/) and retrieve direct image URLs along with full metadata.
