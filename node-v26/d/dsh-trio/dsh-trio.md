# dsh-trio

> 标签: agent, browser, deepseek-harness, dsh, dsh-plugin, github, gitlab, mcp, playwright

## 简介

DSH 全家桶:浏览器自动化 + MCP Server + GitHub/GitLab 集成 + 原生 UI 嵌入面板。One install, three superpowers: browser automation, an MCP server that exposes your DeepSeek agents to any MCP client, and GitHub/GitLab automation.
