# drop-pic

> 标签: angular, dropzone, image drag and drop, image preview, image upload

## 简介

`DropPic` is an Angular library that provides a drag-and-drop interface for uploading and managing images. It includes a standalone component (`DropPicComponent`) and a service (`DropPicService`) to handle image previews, reordering, and file management.
