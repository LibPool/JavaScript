# dynamsoft-label-recognizer-data

> 标签: CNN, Convolutional-Neural-Networks, dynamsoft, dynamsoft-capture-vision, dynamsoft-label-recognizer, javascript, sdk, typescript

## 简介

This package includes Convolutional Neural Networks (CNN) model files and other resources designed to support character recognition capabilities of the dynamsoft-label-recognizer package.
