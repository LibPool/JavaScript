# dsh-niao-quick-open

> 标签: deepseek, deepseek-harness, dsh, dsh-plugin, editor, finder, quick-open, ui-enhancement, workspace

## 简介

UI enhancement suite for DeepSeek Harness: one-click workspace open (Finder/editor), auto-discovered default editor, DeepSeek-web-style user-message nav rail, session to-do marks, flat-list polish, and hard restart. · DeepSeek Harness 界面增强插件：工作区一键打开、编辑器自动
