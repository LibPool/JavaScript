# dsh-mimo-voice

> 标签: deepseek-harness, dsh, dsh-plugin, mimo, tts, voice, xiaomi

## 简介

Xiaomi MiMo TTS voice plugin for DeepSeek Harness: speak a chosen line through the local speakers, with API key / voice design / preview controls in settings.
