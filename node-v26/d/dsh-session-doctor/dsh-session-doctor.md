# dsh-session-doctor

> 标签: corruption, deepseek-harness, doctor, dsh, repair, session

## 简介

Session doctor for DeepSeek Harness: scan stored session logs for load-blocking corruption (loader-mirror validation) and losslessly repair the supported shape drift (bare-string tool-result content → text blocks), with per-file backup. 会话体检与修复插件。
