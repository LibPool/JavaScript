# dsh-composer-keys

> 标签: composer, deepseek-harness, dsh, dsh-plugin, enter, hotkeys, keybindings, newline, send, 发送, 快捷键, 换行, 输入框

## 简介

为 DeepSeek Harness Web 的聊天输入框自定义发送、换行与打断键位，并提供可隔离切换的键位方案（内置 2 套 + 自定义 ≤3 套）；适配 DSH 0.1.7-rc.1（兼容 ≤0.1.6），默认保持 DSH 原生行为，忙碌时的排队/转向语义仍由原生「繁忙时 Enter 键行为」设置决定。Customizable send/newline/interrupt key bindings with isolated scheme presets for the DeepSeek Harnes
