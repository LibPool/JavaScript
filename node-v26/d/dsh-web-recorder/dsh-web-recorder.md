# dsh-web-recorder

> 标签: DSH, browser, deepseek, deepseek harness, dsh-plugin, recorder, web recorder

## 简介

Browser-recording tools for DSH: attaches over CDP to an already-open browser window (e.g. a Playwright MCP browser with a debugging port) or launches a headed browser, records real clicks, inputs, navigation and network requests in a user-guided session,
