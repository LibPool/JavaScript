# drivelift

> 标签: claude-code, google-docs, google-drive, google-sheets, llm, mcp, model-context-protocol, upload

## 简介

Lift local files into Google Drive as native Docs/Sheets/Slides — a bring-your-own-OAuth-client MCP server and CLI for LLM agents (Google Drive only, drive.file scope, guided setup).
