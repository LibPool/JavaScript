# dsh-universal-attachments

> 标签: attachments, deepseek-harness, drag-and-drop, dsh-plugin, file-upload, folder-upload, remote-upload

## 简介

⭐ 支持拖拽上传文件/文件夹到 DSH 窗口任意位置；支持远程上传，字节直传服务器会话工作区——部署在服务器上的 DSH 也能像本地一样拖了就发。
