# decap-cms-widget-ai-chat

> 标签: ai, assistant, chat, cms, content, decap, openrouter, widget

## 简介

Content assistant (AI Chat) widget for Decap CMS with content-aware prompting, chat history, secure key encryption, and support for hundreds of models on OpenRouter.
