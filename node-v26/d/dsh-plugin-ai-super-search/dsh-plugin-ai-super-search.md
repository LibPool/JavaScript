# dsh-plugin-ai-super-search

> 标签: JavaScript

## 简介

DSH 超级搜索 toolkit：集成 TinyFish 免费结构化检索、AnySearch (咸鱼君/mcxianyujun) REST 检索、Bing 免 Key 爬取、Jina 与 DuckDuckGo，彻底接管 DSH 原生 web_search，零 Token 消耗。
