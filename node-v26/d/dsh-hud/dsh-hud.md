# dsh-hud

> 标签: deepseek-harness, dsh, hud, pi-agent-hud, plugin, status-bar

## 简介

DeepSeek Harness 的 HUD 状态栏插件：在输入区下方常驻显示会话实时信息（状态 / 上下文占用 / 令牌用量 / 轮次步数 / 计时 / 用时），模拟 pi-agent-hud 的显示体验。
