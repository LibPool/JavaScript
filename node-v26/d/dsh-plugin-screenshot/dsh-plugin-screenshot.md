# dsh-plugin-screenshot

> 标签: deepseek-harness, dsh, dsh-plugin, screenshot, snipping, windows

## 简介

DeepSeek Harness 截图插件：输入框入口、隐藏/保留本窗口截图、窗口边缘自动吸附框选、截图直接插入对话框
