# directus-extension-endpoint-gamecenter-signup

> 标签: directus, directus-custom-endpoint, directus-extension

## 简介

Allows an Apple GameCenter client app to post an Apple signed playerId to create a user in Directus and returns OAuth2 tokens for it. This is a directus.io endpoint extension.
