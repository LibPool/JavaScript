# dsh-remote-wire

> 标签: deepseek, deepseek-harness, dsh, e2e-encryption, miniprogram, protocol, remote-control, tweetnacl, websocket, wechat

## 简介

Wire protocol for DSH Remote Control: sealed-record crypto, KDF, pairing URI, control frames, payload catalog, keep-awake command builder. Pure functions — no I/O, no timers, no platform symbols.
