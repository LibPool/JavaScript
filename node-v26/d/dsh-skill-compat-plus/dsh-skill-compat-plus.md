# dsh-skill-compat-plus

> 标签: agent, claude-code, codex, compat, deepseek, deepseek-harness, dsh, plugin, skill-provider, skills, zcode

## 简介

Mount Claude Code / Codex / ZCode skill directories into DeepSeek Harness as read-only skill providers — frontmatter field mapping, name slug normalization, hot reload. 技能兼容层：把 ~/.claude/skills、~/.codex/skills、~/.zcode/skills 等外部技能目录挂进 dsh
