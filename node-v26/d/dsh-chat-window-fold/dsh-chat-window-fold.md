# dsh-chat-window-fold

> 标签: chat-window, client-plugin, deepseek-harness, dsh, fold, web-ui

## 简介

Fold and expand the dsh web chat window automatically: event-cycle checkpoints (every 25 session events, from N=75) fold older loaded pages beyond the recent 50 rows when the viewport sits at the bottom; scrolling to the very top appends up to 50 earlier
