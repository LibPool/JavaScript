# dg-cell-mvi-vue

> 标签: JavaScript

## 简介

UI-library-neutral Vue 3 adaptation of dg-cell-mvi-crud: the useCrud composable + the UiRegistry interface/injection keys + UI-neutral helpers (DgRender/exportCsv/cellResolve). Zero UI-library dependency — the concrete Element impl lives in the Element UI
