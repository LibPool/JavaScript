# dsh-publish-plugin

> 标签: deepseek-harness, dsh, dsh-plugin, github, npm, publish

## 简介

Publish a DeepSeek Harness plugin to npm and GitHub in one flow: /publish-dsh-plugin command + publish_plugin tool. 一键把 DSH 插件发布到 npm 与 GitHub（双平台必发）。
