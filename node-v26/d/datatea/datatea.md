# datatea

> 标签: JavaScript

## 简介

datatea是一个非常简单的数据操作类库,它提供了一些方法来简化对数组和对象的操作，比如升序降序排列，随机取值。调用方法后返回的数据结构往往与传入时的一致，比如调用shuffer方法后返回一个被打乱的数组或对象，这里是数组或者对象取决于传入的是数组还是对象。datatea的所有操作均不会改变原来的数据结构。 ## 使用 你可以使用npm安装 ```  npm install datatea  --save ``` 使用时 ``` const datatea =  require('datatea') v
