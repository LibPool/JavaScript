# dsh-plugin-canvas

> 标签: canvas, codeg-plus, deepseek-harness, dsh, dsh-plugin, infinite-canvas, sessions, whiteboard

## 简介

Infinite session canvas for the DeepSeek Harness web GUI, modeled on codeg-plus's 无限会话 board: regions bound to workspaces and agent presets, pinned session cards, sticky notes, drag-to-group, alignment guides and auto-arrange. 参考 codeg-plus 无限画布语义的 dsh 插件
