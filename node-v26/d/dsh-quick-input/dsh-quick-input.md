# dsh-quick-input

> 标签: bilingual, client-plugin, composer, deepseek, deepseek-harness, dsh, dsh-plugin, i18n, presets, quick-input, quick-phrases, snippets

## 简介

应声 · 快捷输入：输入框左侧的九宫格快捷短语面板，点一格就把预设文字插到光标处。9-grid quick-phrase pad docked left of the composer: click a cell to insert preset text at the caret. UI follows the DSH language (中文 / English).
