# dsh-prompt-drift

> 标签: deepseek-harness, drift, dsh-plugin, security, supply-chain, system-prompt

## 简介

System-prompt surface drift gate for DeepSeek Harness: baselines every section contributed to the assembled system prompt and warns loudly when a plugin or preset upgrade silently adds, removes, or rewrites what the model is told
