# dsh-git-idea

> 标签: commit-graph, deepseek-harness, dsh, dsh-plugin, git, idea, ui, vcs

## 简介

A git plugin for DSH modelled on IDEA's VCS: a git icon beside the permission mode in the composer with the branch and pending-change count, a branch switcher on hover, an IDEA-style VCS panel on click, and a settings page. Registers no model tools.
