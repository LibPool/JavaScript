# dsh-prompt-optimize-plugin

> 标签: cordis, dsh, dynamic-plugin, prompt-optimize

## 简介

对话输入栏提示词优化 DSH 插件:发送按钮左侧的优化按钮 + 输入框正上方的优化对比面板。v0.0.3 修复优化结果混入思维链(reasoning 回退移除、过程性表述清洗、长度护栏)。Host 半部经 webServer 路由提供优化,Client 半部为模块加载器工厂包。
