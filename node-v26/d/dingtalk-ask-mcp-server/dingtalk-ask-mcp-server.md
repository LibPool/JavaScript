# dingtalk-ask-mcp-server

> 标签: ask-human, claude-code, codex, dingtalk, human-in-the-loop, mcp, model-context-protocol, 钉钉

## 简介

Human-in-the-loop MCP server：把 code agent（Claude Code / Codex）的决策与命令审批推送到钉钉，阻塞等你在手机回复。离开电脑也能远程拍板。
