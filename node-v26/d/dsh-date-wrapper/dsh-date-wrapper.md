# dsh-date-wrapper

> 标签: context, date, deepseek-harness, dsh, plugin, time, timezone

## 简介

Minimal date line for the DeepSeek Harness runtime-context snapshot: 'Current date: 2026-09-08 Asia/Shanghai Tuesday' (46 chars, ~12 tokens) - a cordis host plugin, no dsh source changes, no PR required
