# dsh-shared-terminal

> 标签: deepseek-harness, dsh, plugin, pty, shared, terminal

## 简介

ONE shared persistent terminal for DeepSeek Harness: the same PTY is driven by the user in the Web GUI (xterm.js panel) and by the agent (shared_terminal_* tools). Both read, both type.
