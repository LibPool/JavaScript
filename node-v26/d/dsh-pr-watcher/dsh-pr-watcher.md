# dsh-pr-watcher

> 标签: JavaScript

## 简介

GitHub pull-request watcher for DeepSeek Harness (DSH): a host service that polls PR status through the gh CLI and notifies agent sessions when configured conditions are met, plus model-facing tools to query and register watches.
