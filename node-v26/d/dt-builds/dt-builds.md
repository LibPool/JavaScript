# dt-builds

> 标签: app-designer, datatalks, dt, element-ui

## 简介

低代码大屏设计平台，DataTalks旨让更多的人看到数据可视化的魅力，帮助非专业的工程师通过图形化的界面轻松搭建专业水准的可视化应用，满足您会议展览、业务监控、风险预警、地理信息分析等多种业务的展示需求。
