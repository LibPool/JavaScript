# datcrazy-remote

> 标签: agent-mesh, broker, coding-agent, datcrazy, datcrazy-remote, mobile, pi, pi-coding-agent, pi-extension, pi-package, qr-pairing, remote-control, uds, websocket

## 简介

datcrazy-remote: branded fork of remote-pi. Mobile remote control and local agent mesh for the Pi coding agent, isolated under its own config namespace and defaulting to the self-hosted datcrazy relay.
