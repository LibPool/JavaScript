# dsh-tool-pwsh-safe

> 标签: deepseek-harness, dsh, plugin, powershell, pwsh, tool

## 简介

Elbow-proof PowerShell for DeepSeek Harness: run multiline pwsh scripts via -EncodedCommand, immune to quoting/escaping pain.
