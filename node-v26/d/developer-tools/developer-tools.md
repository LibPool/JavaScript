# developer-tools

> 标签: JavaScript

## 简介

Developer Tools provides eslint, git precommit-hooks, nyc, and mocha. NPM scripts for linting, validating modules, validating dependencies, code coverage (json, xunit, cobertura, lcov), and coverage badge.
