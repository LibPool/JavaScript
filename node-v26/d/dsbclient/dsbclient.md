# dsbclient

> 标签: JavaScript

## 简介

A module which uses my [dsbapi library](https://github.com/TheNoim/DSBAPI) to filter only for the important information returned by the [getData()](https://github.com/TheNoim/DSBAPI#DSB+getData) Method.
