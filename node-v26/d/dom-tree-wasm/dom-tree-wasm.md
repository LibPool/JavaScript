# dom-tree-wasm

> 标签: JavaScript

## 简介

A Wasm bindgen over dom-tree-rs providing wasm module to parse and create tree data structure for a given HTML string.

- 源码仓库：https://github.com/iamsaquib8/dom-tree-rs/tree/main/dom-tree-wasm
