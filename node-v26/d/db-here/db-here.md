# db-here

> 标签: clickhouse, database, embedded, local-development, memcached, minio, mongodb, mysql, opensearch, postgres, postgresql, redis

## 简介

Per-project embedded databases (PostgreSQL, MySQL, Redis, MongoDB, MinIO, ClickHouse, OpenSearch, Memcached) with local binaries and data — zero OS setup.
