# dsh-suggest-reply

> 标签: JavaScript

## 简介

DSH web plugin: a better-sidebar tab that reads the latest assistant line and generates four style-distinct reply candidates (帮我想想) with a one-shot off-loop completion. Independent from the main session: no context inheritance, a fresh round per generatio
