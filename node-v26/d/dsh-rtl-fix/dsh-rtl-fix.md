# dsh-rtl-fix

> 标签: JavaScript

## 简介

Proper RTL rendering for DeepSeek Harness web chat: any line containing RTL scripts renders fully RTL (right-aligned, correct bidi word order) even when it embeds English words, plus RTL-aware composer input.
