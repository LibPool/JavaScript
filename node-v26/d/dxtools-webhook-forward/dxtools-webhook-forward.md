# dxtools-webhook-forward

> 标签: dxtools, localhost public url, webhook, webhook forward, webhook inspect

## 简介

1. Access https://www.dxtools.dev and enable request forwarding 2. Run `npx dxtools-webhook-forward` on terminal to start forwarding webhook events
