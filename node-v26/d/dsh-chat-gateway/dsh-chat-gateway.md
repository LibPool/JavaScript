# dsh-chat-gateway

> 标签: bot, deepseek-harness, dingtalk, dsh, feishu, im, onebot, plugin, qq, wecom

## 简介

Multi-channel message gateway for the dsh web GUI: connects 钉钉(Stream) / 飞书(长连接) / 企业微信(自建应用回调) / QQ(OneBot 反向WS) bots to a dsh agent with per-conversation sessions (群聊/单聊历史隔离) — every channel gets its own card in an independent 「消息通道」 settings section. I
