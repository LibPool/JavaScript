# dsh-web-fetch-fakeip

> 标签: clash, deepseek, dsh, dsh-bundle, dsh-plugin, fake-ip, harness, mihomo, proxy, ssrf, tun, web-fetch

## 简介

fake-ip-aware WebFetchProvider for the DeepSeek Harness web seam — keeps the web_fetch tool working under mihomo/Clash fake-ip DNS without disabling fake-ip or setting proxy environment variables.
