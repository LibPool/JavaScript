# dungeondraft-mcp

> 标签: battlemap, claude, dd2vtt, dnd, dungeondraft, foundry-vtt, mcp, model-context-protocol, ttrpg, uvtt

## 简介

MCP server for Dungeondraft: read, edit and export .dungeondraft_map files, and convert Universal VTT (.dd2vtt) exports into Foundry VTT scenes
