# dsh-cloudflare-browser-run

> 标签: browser, browser-run, cloudflare, cordis, deepseek-harness, dsh, dsh-plugin

## 简介

DeepSeek Harness plugin: web browsing tools (markdown / screenshot / pdf / crawl) powered by Cloudflare Browser Run — real headless Chrome with JS rendering, login sessions and WebMCP support.
