# dsh-dictation-hotkey

> 标签: dictation, dsh, dsh-plugin, push-to-talk, sensevoice, speech-to-text, voice-input, web-ui

## 简介

Press-to-talk dictation: a key combination records in the DSH Web page, DSH's own speech engine transcribes, and the text lands in the composer.
