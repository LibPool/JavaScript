# devkit-ai

> 标签: JavaScript

## 简介

Install the Devkit-AI plugins (typescript-rules, jsdoc-standards, commit-commands) into Claude Code, Cursor, or OpenCode. No model lock-in: source files are runtime-neutral, and the installer translates per-target.
