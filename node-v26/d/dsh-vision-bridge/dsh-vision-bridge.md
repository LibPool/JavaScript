# dsh-vision-bridge

> 标签: bridge, deepseek, gpt-4o, kimi, mcp, multimodal, openai-compatible, qwen-vl, vision

## 简介

给任意 OpenAI 兼容的文本模型（如 DeepSeek）加视觉能力：一个本地 OpenAI 兼容代理，图片交给视觉模型描述、文字交给文本模型推理。
