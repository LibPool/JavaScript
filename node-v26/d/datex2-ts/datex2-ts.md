# datex2-ts

> 标签: data-model, datex-ii, datex2, its, json-schema, mobility, napcore, traffic, typescript

## 简介

Dev-friendly TypeScript data model for DATEX II v3 (JSON encoding): generated types, discriminated-union friendly model, immutable editing helpers and metadata-driven validation.
