# dsh-session-eva-status

> 标签: deepseek-harness, dsh, dsh-plugin, eva, session, sidebar, status

## 简介

DSH Web UI plugin: colors sidebar Session rows by their official status — blue rail = pending interaction, red rail = the selected session, purple rail = finished but unviewed, static rainbow title = pinned. Reads official Client services only; no polling
