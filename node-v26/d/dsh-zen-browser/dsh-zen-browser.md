# dsh-zen-browser

> 标签: browser-automation, deepseek-harness, dsh-plugin, firefox, webdriver-bidi, zen-browser

## 简介

DeepSeek Harness plugin that drives Zen Browser (Firefox) over the native WebDriver BiDi endpoint: sessions, navigation, screenshots, page text.
