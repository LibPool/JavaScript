# defun

> 标签: applicatives, code-generation, functional-programming, functors, higher-kinded-types, hkt, logic-derivation, monads, type-classes, type-level, typescript

## 简介

A minimalistic yet powerful logic derivation engine for TypeScript, enabling automatic generation of comprehensive APIs from minimal core implementations.
