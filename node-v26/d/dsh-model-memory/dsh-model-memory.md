# dsh-model-memory

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, model-memory, plugin, reasoning-effort, thinking-level

## 简介

DSH 自定义模型思考等级管理、渠道重试策略与偏好记忆插件：原生设计语言、全档位思考配置、渠道级重试控制与无感隔离式跨会话偏好记忆。
