# devground-init

> 标签: agents-md, boilerplate, cli, commitlint, devground, eslint, husky, prettier, scaffold, typescript

## 简介

Interactive CLI to scaffold devground development standards (ESLint, Prettier, TypeScript, commitlint, husky, AGENTS.md, ADRs) in any Node/TypeScript/Next.js project
