# dsh-plugins-workspace-allowlist

> 标签: JavaScript

## 简介

Web/交互面按项目文件夹的可见性控制：workspace 注册白名单 + 可选 fs 路径过滤。挂 web profile（需要 workspaceRegistry 服务）。
