# dynamic-auth-web-component

> 标签: JavaScript

## 简介

Este es una libreria para poder integrar la sdk de dynamic.xyz como web component para utilizarla en cualquier proyecto sin importar el framework y/o libreria utilizada para implementar el proyecto.
