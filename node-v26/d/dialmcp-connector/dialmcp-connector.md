# dialmcp-connector

> 标签: ai-agents, call-automation, dialmcp, mcp, mcp-server, model-context-protocol, phone-calls, remote-mcp, telephony, voice-ai

## 简介

Open-source connector for DialMCP — the hosted MCP server that lets AI agents place real phone calls from your own verified number.
