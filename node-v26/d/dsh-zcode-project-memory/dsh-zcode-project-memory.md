# dsh-zcode-project-memory

> 标签: deepseek-harness, dsh, dsh-plugin, long-term-memory, memory, project-memory, zcode

## 简介

Unofficial community port of ZCode's project memory to DeepSeek Harness: project-scoped long-term memory with a save_project_memory tool plus automatic recall of project memory into the system prompt.
