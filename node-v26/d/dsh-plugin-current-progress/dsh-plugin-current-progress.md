# dsh-plugin-current-progress

> 标签: context, cordis, cordis-plugin, deepseek, deepseek-harness, dsh, dsh-plugin, progress, session

## 简介

Keeps a CURRENT_PROGRESS.md file in each session's working directory: asks at session start whether to create it, reads it instead of asking when it already exists, and appends one entry after every turn.
