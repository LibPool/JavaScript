# dota-wiki-api

> 标签: ancients, defense, dota, dota 2, dota2, esports, liquipedia, valve

## 简介

A module to communicate with Liquipedia's Dota 2 Wiki to fetch Team Info, DPC Rankings, Dota Game Schedules, and more!
