# dsh-git-lite

> 标签: client-plugin, deepseek-harness, devtools, dsh, git, git-ui, web

## 简介

DSH Web 右侧栏的轻量 Git 面板，直接调用本机 git：改动、行内 diff、拉取、两阶段确认推送、提交、分支、stash。A lite Git tab for the DeepSeek Harness Web sidebar, driven by your local git.
