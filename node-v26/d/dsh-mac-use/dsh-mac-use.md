# dsh-mac-use

> 标签: agent, automation, computer-use, deepseek-harness, dsh, keyboard, macos, mouse, plugin, screen

## 简介

Computer-use for DeepSeek Harness on macOS: let an agent see the screen, drive the mouse and keyboard, and open apps and URLs — no helper binary, permissions come from the Harness app itself.
