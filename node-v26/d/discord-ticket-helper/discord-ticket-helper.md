# discord-ticket-helper

> 标签: JavaScript

## 简介

HTML-транскриптор каналов Discord и тикет-систем. Генерирует красивые самодостаточные HTML-файлы с полной историей переписки, эмбедами, вложениями, компонентами и Markdown-разметкой.
