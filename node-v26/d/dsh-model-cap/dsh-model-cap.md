# dsh-model-cap

> 标签: deepseek, deepseek-harness, dsh, dsh-plugin, model, openai-compatible, provider

## 简介

DSH 提供商与模型高级管理台：设置页独立导航「提供商配置」，管理提供商（地址/协议/Key 凭据）与模型（增删改/拉取/批量删除/识图声明/推理档位/拖动排序/连通测试），直写 llm-pi-ai 命名空间热生效。自包含：模板组件已内联，无外部依赖。
