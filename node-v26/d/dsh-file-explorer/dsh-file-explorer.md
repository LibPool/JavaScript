# dsh-file-explorer

> 标签: deepseek-harness, dsh, file-explorer, glassmorphism, macos-style, plugin, workspace

## 简介

Workspace file explorer for DeepSeek Harness Web: resizable split tree + preview layout, type-based coloring, syntax highlighting, edit/save, plus an Apple-style glass UI and quick settings bar. DSH 工作区文件浏览器:左右分栏文件预览、按类型着色、语法高亮、可编辑,附毛玻璃界面与快速设置栏。
