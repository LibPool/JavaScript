# dsh-treekeeper

> 标签: deepseek, deepseek-harness, dsh, dsh-plugin, leak-detection, process-manager, process-tree

## 简介

DSH 运行时进程树对账与治理：把当前宿主的任务账本与本机真实进程树对账，标出未归属/泄漏/孤儿进程并守卫式树杀。Runtime process-tree reconciliation for DeepSeek Harness: join the current host's job ledger with the live OS process tree, surface unattributed/leaked/orphaned children, and kill trees behind creat
