# danmukuku

> 标签: JavaScript

## 简介

1. **Frame都和视框同大小，（width:100%）, 发射后移动两阶段  -100%，  -300%， 完毕销毁。** 2. 只有Slide Frame模式 3. 可以初始化多个Slide Frame模式的层 4. 共用TraceManager
