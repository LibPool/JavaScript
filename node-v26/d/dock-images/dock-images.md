# dock-images

> 标签: deepseek-harness, dock, dsh, dsh-plugin, image, plugin, viewer, web-ui

## 简介

Image viewer for the dock file explorer: renders PNG, JPEG, GIF, WebP, BMP, SVG, ICO and AVIF files.
