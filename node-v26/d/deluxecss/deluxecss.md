# deluxecss

> 标签: css, gradient, image-to-css, palette, pixel-art, quantize, recolor, web-component

## 简介

Convert any image into pure CSS pixel-art with a live-controllable color palette (CSS custom properties). CLI + library + zero-dependency Web Component.
