# dsh-plugin-notify

> 标签: alert, deepseek, dsh, dsh-plugin, harness, notification, notify, tts, voice

## 简介

DeepSeek Harness 插件：通知出口——agent 通过桌面通知 / 中文语音播报 / 提示音主动联系用户（长任务完成、出错、呼叫用户回来）。Windows 本机零依赖。
