# dsh-client-ui-enter-newline

> 标签: composer, deepseek-harness, dsh, dsh-plugin, enter, newline

## 简介

DSH Web client plugin: an "Enter inserts a newline only" checkbox beside the composer's model selector, which suppresses Enter-to-send while checked.
