# dsh-plugin-easy2restart

> 标签: deepseek-harness, dsh, dsh-plugin, relaunch, restart

## 简介

DSH plugin: double-click the sidebar restart button to fully relaunch DeepSeek Harness; it is greyed out while an agent session is running. （中文：DSH 重启插件：双击侧边栏重启按钮即可整体重启 DeepSeek Harness，会话运行时按钮置灰禁用。）
