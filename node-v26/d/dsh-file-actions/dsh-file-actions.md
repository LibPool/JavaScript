# dsh-file-actions

> 标签: cordis, deepseek, dsh, files, harness, plugin, sidebar

## 简介

给官方右侧栏 Files 文件树加行内 ⋯ 菜单：复制文件地址 / 在文件管理器中显示。以 extension 档接管 tab kind `files`（不改官方包，卸载即恢复官方实现）。
