# dsh-edit-diff

> 标签: deepseek-harness, diff, dsh, dsh-plugin, edit, review

## 简介

质量 diff：接管 edit/write 及 extraTools 配置的其他工具卡片，行级去重与行内高亮，消除相同内容在删除与新增两区的重复；兼容 PTC 模式，标准可安装的 dsh 客户端插件
