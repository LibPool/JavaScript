# dsh-history-cleanup-plugin

> 标签: archive, cleanup, deepseek-harness, dsh, dsh-plugin, history, session

## 简介

DeepSeek Harness 会话清理插件：注册 history_cleanup 工具，盘点 / 归档 / 永久删除历史会话，并清掉悬空的归档 id。
