# dsh-graph-host

> 标签: deepseek-harness, dsh, dsh-plugin, goals, graph, kanban, plugin

## 简介

dsh-graph 的 host 半边：把 dsh-graph 核心层包装为 DSH cordis 插件，向 agent 暴露 graph_* 目标生命周期工具（建卡/判据/迁移/派发/评审/交付）。
