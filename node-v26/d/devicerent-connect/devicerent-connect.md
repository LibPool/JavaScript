# devicerent-connect

> 标签: adb, android, appium, automation, ci, device-farm, devicerent, espresso, maestro

## 简介

Make a rented DeviceRent phone show up as a local adb device, so Appium / Espresso / Maestro / gradle just work against it.

## 官网

- 官网：https://devicerent.net/account/automation
- 源码仓库：git+https://github.com/DeviceRent-net/devicerent.net.git
- npm 页面：https://www.npmjs.com/package/devicerent-connect
