# dsh-better-subagent

> 标签: agent, deepseek, deepseek-harness, dsh, dsh-plugin, model, plugin, subagent, subagents

## 简介

Better subagents for DeepSeek Harness: choose the default subagent model, see each subagent conversation's model in its header, and wait for subagents with a blocking wait_subagents tool instead of sleeping or polling.
