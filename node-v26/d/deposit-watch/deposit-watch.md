# deposit-watch

> 标签: crypto, deposit, erc20, evm, qr, react, sdk, solana, spl, wallet, web3

## 简介

Drop-in frontend SDK: show a QR deposit modal for a set of (address, token, chain) targets and resolve as soon as a deposit lands. Works in any FE stack, with first-class React bindings.
