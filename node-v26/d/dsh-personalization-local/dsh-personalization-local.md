# dsh-personalization-local

> 标签: JavaScript

## 简介

DSH 个性化设置插件：在「设置」页新增「个性化」分区，管理称呼/职业/自我介绍与 Chat 回复偏好，保存后注入到每个新对话的系统提示词。
