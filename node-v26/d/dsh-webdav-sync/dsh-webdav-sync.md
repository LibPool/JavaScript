# dsh-webdav-sync

> 标签: backup, cordis, deepseek, dsh, nextcloud, nutstore, plugin, sync, webdav

## 简介

用 WebDAV 在多台电脑之间同步 DSH 的配置：模型供应商与模型、已安装插件、其余 profile 配置、附加目录与 API 密钥。整个备份在离开本机前用口令加密（AES-256-GCM + PBKDF2），以分片三方合并的方式在服务端保留一个加密文件。
