# dsh-youtube-plugin

> 标签: agent-teams, dsh, dsh-bundle, ocr, speech-to-text, transcript, youtube

## 简介

Deep, token-efficient YouTube understanding for DSH: captions or local GPU speech-to-text, scene keyframes with local OCR/VLM, transcript search/map, one disk cache, one loopback diagnostic route.
