# dsh-as-aistudio

> 标签: ai-studio, aistudio, deepseek-harness, delete, dsh, dsh-plugin, edit, markdown, rerun, turn

## 简介

Google-AI-Studio-style turn controls for DeepSeek Harness, in one install: edit a prompt and re-run it, re-run a reply in place, delete a turn from the model context, and render sent prompts as Markdown. Self-contained: the plugin list shows this one row;
