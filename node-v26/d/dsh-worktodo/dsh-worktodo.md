# dsh-worktodo

> 标签: checklist, deadline, deepseek, deepseek-harness, dsh, dsh-plugin, due-date, overdue, panel, priority, sidebar, task, task-management, todo, todo-list, work, worktodo, 工作待办, 待办

## 简介

DSH 工作待办面板（社区插件，非官方）：归你所有、跨会话持久的工作待办——优先级 / 截止日期 / 项目 / 已过期与本周视图，agent 通过 worktodo_* 工具读写同一份列表。官方 todo_write 属于单个会话且只能整表替换，这份列表属于人。Human-owned cross-session work todo list for DeepSeek Harness: priorities, due dates, projects, overdue/week views and workt
