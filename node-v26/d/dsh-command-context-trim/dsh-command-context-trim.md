# dsh-command-context-trim

> 标签: compaction, context, context-window, deepseek-harness, dsh, local-model, plugin, trim

## 简介

Model-free /trim for DeepSeek Harness — drop the oldest, least valuable span of context on demand (the `/trim` command) or automatically when a request hits the model's context wall, without any model call.
