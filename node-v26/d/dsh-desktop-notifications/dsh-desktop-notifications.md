> 标签: cordis, deepseek, deepseek-harness, desktop-notifications, dsh, dsh-plugin, notification, notifications, notify, plugin, toast, windows, 插件, 桌面通知, 通知

## 简介

Windows desktop toast notifications for DeepSeek Harness (DSH): approval requests, user questions, run completion, errors and sign-in prompts — every toast led by the conversation name.
