# dsh-reef

> 标签: agent, browser, deepseek-harness, dsh, dsh-plugin, github, gitlab, mcp, playwright

## 简介

DSH 插件全家桶:浏览器自动化 + MCP Server + GitHub/GitLab 自动评审 + 原生嵌入面板。One install, five modules for DeepSeek Harness: browser automation, an MCP server exposing your agents to any MCP client, GitHub & GitLab automation, and a native in-app panel.
