# dsh-image-to-text

> 标签: cordis, deepseek-harness, dsh, image, image-upload, multimodal, ocr, text-only, vision

## 简介

DSH plugin that lets text-only (non-multimodal) models send and read images: bypasses the image admission gate, rewrites image blocks to local paths, and OCRs/describes them via configurable vision API providers (image_to_text tool).
