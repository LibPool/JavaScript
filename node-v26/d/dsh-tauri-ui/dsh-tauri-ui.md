# dsh-tauri-ui

> 标签: deepseek-harness, dsh, dsh-plugin, plugin, tauri

## 简介

`dsh-tauri-ui` 为 DSH 提供 Tauri 风格的客户端界面扩展。目前包含将设置对话框改造成左侧停靠设置栏的功能。
