# deepseek-harness-pets

> 标签: deepseek-harness, dsh-plugin, pet, petdex, pixel-art

## 简介

DeepSeek Harness 桌宠插件：像素鲸鱼/机械章鱼随评测与回合状态在 DSH Web UI 中动起来；宠物资产兼容 Petdex 格式。
