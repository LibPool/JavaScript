> 标签: claude, confluence, cursor, git, jira, mcp, postgresql, qdrant, rag, semantic-search

## 简介

MCP server for domain RAG search — connects to Qdrant + PostgreSQL + Code Search API for hybrid search across Jira, Confluence, Git commits, and server-side code repositories
