# dsh-image-forge

> 标签: comfyui, cordis, deepseek-harness, dsh, dsh-plugin, image-edit, image-generation, qwen, qwen-image, text-to-image

## 简介

DeepSeek Harness plugin: Qwen-Image 文生图 / 参考图编辑，把官方提示词契约的 wh_ratio 做成一等参数；后端 api（云端 key）/ comfyui（本机 ComfyUI），默认 auto；成果按画板归档。
