# dsh-budget-handoff

> 标签: budget, cost-control, deepseek-harness, dsh, dsh-plugin, handoff

## 简介

DeepSeek Harness 会话预算插件：按官方价目表实时算账，预算耗尽时拦截任务并落盘交接快照；价目表算不出的模型改由 Token 上限把关。
