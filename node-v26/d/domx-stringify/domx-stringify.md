# domx-stringify

> 标签: DOM, HTML, highlight, markup, string

## 简介

DOMx extension that makes it easy to convert DOM structures to strings, both plain and marked up for highlighting.

- 官网：http://esha.github.io/domx-stringify/
- 源码仓库：git://github.com/esha/domx-stringify.git
