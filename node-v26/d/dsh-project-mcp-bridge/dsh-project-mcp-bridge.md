# dsh-project-mcp-bridge

> 标签: cordis, deepseek-harness, dsh, mcp, plugin

## 简介

Per-project MCP loading for DeepSeek Harness: sessions of a project automatically get the MCP servers declared in its .dsh/mcp.json (mcpServers JSON shape, shared with Claude Code / Cursor / VS Code). Client bridge — consumes MCP servers, not an MCP serve
