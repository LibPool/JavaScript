# dsh-cloudflare-codemode

> 标签: ai-gateway, cloudflare, cloudflare-api, code-mode, d1, deepseek, deepseek-harness, devops, dns, dsh, dsh-plugin, dsh-plugins, harness, infrastructure, kv, mcp, mcp-client, oauth, pages, plugin-market, r2, workers, workers-scripts, zero-trust

## 简介

把 Cloudflare 官方 Code Mode MCP 接入 DeepSeek Harness：AI 通过 search / execute 两个工具动态访问 2,500+ Cloudflare API，覆盖 Workers、DNS、R2、KV、D1、Pages 等全部产品，并附带可视化设置面板。
