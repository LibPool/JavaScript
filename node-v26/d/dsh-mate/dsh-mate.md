# dsh-mate

> 标签: deepseek-harness, dsh, dsh-plugin, harmonyos, mobile, remote, remotely-control

## 简介

DSH Mate（求索伴侣）电脑端桥插件：为鸿蒙 App 提供配对、移动 REST API 与事件推送，远程查看与操作 DeepSeek Harness。
