# did-siop

> 标签: DID, DID_SIOP, Identity_Wallet, OpenIDConnect, OpenID_SIOP, SIOP, Self_Issued_OpenIDConnect_Provider, Self_Soverign_Identity

## 简介

A library containing core functionality for DID based Self Issued OpenID Connect authentication. Contains both Relying Party and Provider components.
