# dsh-auth-gate

> 标签: access-control, auth, authentication, deepseek-harness, dsh, dsh-plugin, login, password, rate-limiting, security, self-hosted, token, totp, two-factor

## 简介

Login gate for DeepSeek Harness (dsh) web instances: password or shared-token sign-in, optional TOTP two-factor, session cookies, rate limiting, self-service password change and a user-management CLI
