# demomotion

> 标签: agentic, ai-agents, automation, demo-videos, devtools, llm-tools, mcp, model-context-protocol, playwright, product-demos, screen-recording, typescript, video-as-code, video-generation

## 简介

MCP server that lets an AI agent operate your web app, record it deterministically and render a polished product-demo MP4 — no human in the edit.
