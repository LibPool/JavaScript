# dsh-ru-ui

> 标签: deepseek-harness, dsh, dsh-plugin, i18n, locale, localization, russian, translation

## 简介

Russian interface translation for DeepSeek Harness (DSH): registers complete ru dictionaries for the DSH platform and its plugins, adds Russian to the language picker, and activates it on first run. Translation only - no typography, spell-check or layout-
