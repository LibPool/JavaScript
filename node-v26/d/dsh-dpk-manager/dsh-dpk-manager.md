# dsh-dpk-manager

> 标签: deepseek-harness, dpk, dsh, package-manager, plugin

## 简介

DPK manager for DeepSeek Harness — pack, verify and install local DSH plugin packages (.dpk) from the Plugins-page panel and the in-session dpk tool
