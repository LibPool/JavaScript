# dsh-easy-lsp

> 标签: deepseek-harness, deepseek-harness-plugin, dsh-plugin, easy-lsp, language-server, language-server-protocol, lsp, lsp-manager

## 简介

DSH 语言服务器(LSP)图形化管理插件：自持 LSP 引擎(跳转/引用/hover/诊断/符号/重命名/格式化/代码操作/调用层级)+ 一键安装器 + 主动诊断注入,配置持久化到 settings.yaml,变更实时生效。
