# dsh-locale-es

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, espanol, i18n, locale, localization, spanish, translation

## 简介

Spanish (es) language pack for the DeepSeek Harness Web UI — a community DSH client plugin adding Español to Settings → General → Language.
