# dsh-mcp-skill-panel

> 标签: agent, cordis, deepseek-harness, dsh, mcp, panel, plugin, skill

## 简介

MCP 与技能管理面板：设置页展示 MCP 服务器与 Skill 目录，随时启停释放上下文占用；可选 AI 中间层（dsh_mcp_search/dsh_mcp_call）按需使用 MCP。
