# dsh-weekly-hot

> 标签: JavaScript

## 简介

Weekly hot DSH plugins ranking panel: trending (7/30/90-day star-growth) and curated topic leaderboards, rendered as a self-healing sidebar entry below the New Session button in the dsh web GUI.
