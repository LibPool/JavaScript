# docusaurus-theme-pixelite

> 标签: css, documentation, docusaurus, docusaurus-theme, openapi

## 简介

A Docusaurus 3 theme that reworks the classic preset's typography and layout: a flat type scale, borderless inline code, dark code blocks in both colour modes, a centred three-column assembly, and OpenAPI reference styling.
