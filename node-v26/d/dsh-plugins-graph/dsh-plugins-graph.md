# dsh-plugins-graph

> 标签: agent-orchestration, deepseek, deepseek-harness, dsh, editor, graph, langgraph, persistence, plugin, state-graph, subagent, visualization

## 简介

LangGraph-style `graph` model tool for DeepSeek Harness — runs state graphs of subagent and pure-JS nodes with static and conditional edges, first-class cycles, and unbounded loops. Ships a web tool card visualizing live execution plus an interactive Grap
