# dsh-cost-hud

> 标签: balance, cost, deepseek, deepseek-harness, dsh, hud, monitor, plugin, spend, token

## 简介

Real-time API spend & balance HUD for the DeepSeek Harness web GUI: a draggable floating card showing session/total cost, context occupancy and account balance, with per-model breakdown.
