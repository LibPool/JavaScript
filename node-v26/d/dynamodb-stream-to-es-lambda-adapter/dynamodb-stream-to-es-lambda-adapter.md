# dynamodb-stream-to-es-lambda-adapter

> 标签: dynamodb, dynamodb streams, elasticsearch, lambda, replication

## 简介

The package allows you to create and configure a lambda handler that will replicate data from DynamoDB Stream into Elasticsearch
