# dsh-tool-epub

> 标签: deepseek-harness, dsh-plugin, ebook, epub, epub3, opf, publishing, zip, 电子书

## 简介

Read, build and take apart EPUB 3 books from DeepSeek Harness: inspect metadata and reading order, assemble a book from chapters, and split one back into per-chapter files. No external dependency.
