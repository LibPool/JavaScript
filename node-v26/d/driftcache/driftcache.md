# driftcache

> 标签: cache, consistent-hashing, distributed-cache, failover, hash-ring, hot-key, lru, pub-sub, redis, sharding

## 简介

Distributed cache router with consistent hashing, tiered L1/L2 caching, pub/sub invalidation, health-checked failover, and hot-key replication.
