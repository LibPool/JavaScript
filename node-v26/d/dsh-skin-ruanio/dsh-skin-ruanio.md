# dsh-skin-ruanio

> 标签: deepseek-harness, dsh, plugin, skin, theme

## 简介

自定义图片皮肤生成器（DSH 插件，自包含）：上传图片 → 生成独立皮肤包（@linxin666/dsh-custom-skin）。内嵌皮肤中心核心（/api/skin-center/* state/apply/bundle，源自 @linxin666/dsh-client-ui-skin-center BSD-3-Clause）；若外部皮肤中心已安装则自动复用其 API。
