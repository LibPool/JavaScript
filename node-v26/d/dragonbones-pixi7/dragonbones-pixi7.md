## 简介

* Clone or download [DragonBonesJS](https://github.com/DragonBones/DragonBonesJS/). * Install [Node.JS](https://nodejs.org/). * Open `DragonBonesJS/Pixi/5.x/` in command. * $ `npm install` * $ `npm run build`
