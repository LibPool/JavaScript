# decl-lang

> 标签: configuration, decl, declarative, formatter, json, language, lsp, schema, validation

## 简介

Decl — a declarative language for describing, generating, and validating structured data. CLI (check / evaluate / validate / fmt), canonical formatter, and LSP server.
