# dsh-ros2-state

> 标签: deepseek-harness, dsh, dsh-plugin, ros2, sidecar, state

## 简介

dsh-ros2 control-plane state client — long-lived UDS connection to the dsh-ros2-sidecar data plane, so the Agent reads reduced, fresh robot state in milliseconds (logic-direct / physically-separated). Provides state_get / state_snapshot tools + a StateCli
