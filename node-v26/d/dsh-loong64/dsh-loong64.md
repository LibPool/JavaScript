# dsh-loong64

> 标签: agent, cli, cordis, deepseek-harness, dsh, loong64, loongarch, loongson, plugin, 龙芯

## 简介

DeepSeek Harness (dsh) for LoongArch64 — one-command npm install, carrying the native pieces upstream never published for linux-loong64: a source-built libvips 8.19.0, a source-built sharp, and the missing node-addon-system platform package.
