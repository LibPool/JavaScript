# dtsintergen

> 标签: JSON Schema, OpenAPI, TypeScript, dtsgen, dtsgenerator

## 简介

TypeScript d.ts file generator for JSON Schema files, with generation of intersection types. Fork of horiuchi/dtsgenerator.
