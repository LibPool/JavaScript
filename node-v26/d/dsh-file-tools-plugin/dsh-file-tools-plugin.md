# dsh-file-tools-plugin

> 标签: deepseek-harness, dsh, dsh-plugin, file-tools, fs

## 简介

DeepSeek Harness 文件工具插件：注册 open_folder / append_json_file 两个工具，供 Agent 与被限制了工具范围的子代理打开文件夹、把结果追加进 JSON 文件。
