# dsh-llm-trace

> 标签: cordis, debug, deepseek-harness, dsh, dsh-plugin, llm, observability, plugin, trace, wire

## 简介

DeepSeek Harness plugin that captures the raw HTTP request and response bodies of model provider calls, shows the request body as a collapsible size-annotated JSON tree in a Conversation View tab and on a loopback viewer page, and assembles SSE responses
