# dsh-sms-webhook

> 标签: deepseek-harness, dsh, dsh-plugin, sms, webhook

## 简介

SMS forwarding webhook for DeepSeek Harness: receives pushes from SMS Forwarder apps, stores them, and exposes sms_recent / sms_search tools.
