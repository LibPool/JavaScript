# docen

> 标签: canvas, components, converter, docen, document, docx, editor, format-conversion, markdown, microsoft-word, office, ooxml, pagination, prosemirror, rich-text, tiptap, typescript, unified-api, web-components, word, wps, wysiwyg

## 简介

The full docen canvas web-component editor plus headless Markdown/DOCX conversion in one package. Re-exports @docen/docx (converters + engine) and @docen/editor (<docen-document>).
