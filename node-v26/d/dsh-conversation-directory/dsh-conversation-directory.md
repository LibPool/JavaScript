# dsh-conversation-directory

> 标签: conversation, deepseek-harness, directory, dsh, outline, timeline

## 简介

DSH 本对话目录：右下角悬浮入口打开当前会话的时间线式轮次目录，支持搜索与点击跳转定位（自动加载更早历史、轮首对齐、落地高亮）。
