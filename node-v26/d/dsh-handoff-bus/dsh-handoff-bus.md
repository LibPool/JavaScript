# dsh-handoff-bus

> 标签: bus, cross-session, deepseek-harness, dsh, dsh-plugin, handoff, multi-agent, session

## 简介

Cross-session message bus for DeepSeek Harness GUI conversations: deliver instructions and reports directly between the main conversation and sub-conversations.
