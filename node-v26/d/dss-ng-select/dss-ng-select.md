# dss-ng-select

> 标签: JavaScript

## 简介

- **bindLabel="lb_name"**     The property from your API response object that will be shown as the **display label** in the dropdown.     → Example: if API returns `{ lb_id: 101, lb_name: 'John' }`, then "John" appears in the dropdown.
