# dsh-auto-translate

> 标签: deepseek-harness, dsh, dsh-plugin, i18n, on-device, onnxruntime, plugin, transformers.js, translate, translation, wasm

## 简介

Zero-token on-demand translation for the DeepSeek Harness web GUI: hover a block to translate it in place, drag-select text for a popup or in-place translation. Never auto-translates the page.
