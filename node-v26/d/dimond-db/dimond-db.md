> 标签: acid, caching, cursor, database, document-database, embedded, filesystem, hooks, indexing, json, lightweight, local, middleware, mongodb, node-database, nosql, offline, query, schema-validation, storage, transactions, wal

## 简介

A high-performance embedded database engine for Node.js with MongoDB-like API, advanced indexing, transactions, and caching. No external database server required.
