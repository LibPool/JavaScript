# docs-overlay-mermaid

> 标签: accessibility, architecture-beta, dark-mode, diagram, docs, docs-as-code, docs-overlay, documentation, flowchart, mermaid, ssr, svg

## 简介

Mermaid to modern technical SVG: a semantic diagram model and a DOM-free renderer, so diagrams ship as HTML instead of a browser bundle.
