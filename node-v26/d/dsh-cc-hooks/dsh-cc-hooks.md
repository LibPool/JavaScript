# dsh-cc-hooks

> 标签: claude, claude-code, deepseek-harness, dsh, hooks

## 简介

Run unmodified Claude Code hooks in DSH with per-session discovery: project .claude/hooks + global ~/.claude/hooks + plugin dirs. All five handler types execute (command/http/mcp_tool/prompt/agent) through @deepseek-ai/dsh-hook-protocol (11/31 wired event
