# dsh-papercut

> 标签: dsh, dsh-plugin, explainer, papercut, remotion, tts, video, windows

## 简介

Papercut explainer films, end to end: script -> local TTS -> word-level captions -> Remotion render, natively on Windows (no WSL, no ffmpeg install).
