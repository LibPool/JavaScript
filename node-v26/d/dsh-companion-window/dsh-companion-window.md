# dsh-companion-window

> 标签: burnout, companion, cordis-plugin, deepseek-harness, dsh-plugin, wellbeing

## 简介

陪聊窗口 —— 一个只在项目真的卡住时才出现的搭话窗口。它读工作区元数据（文件改动、深浅、节奏），不读文件内容；会话侧读你说过的话。逐条可核的清单见 README。
