# dsh-workspace-memories

> 标签: agent-memory, ai-agent, cordis, deepseek, deepseek-harness, dsh, dsh-plugin, llm

## 简介

Per-workspace persistent memory for DeepSeek Harness: a sidebar panel to manage Markdown memory files, automatic injection into every session of the workspace, and an agent tool to save new memories
