# docs-drift

> 标签: ci, cli, docs, docstring, documentation, drift, jsdoc, lint, readme

## 简介

Find documentation that drifted out of sync with the code: JSDoc, docstrings, README code blocks, Git history. CLI and CI companion to the Drift VS Code extension.
