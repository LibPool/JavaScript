# dsh-opensheet-sidebar

> 标签: better-sidebar, circuit-breaker, csv, deepseek-harness, dsh, plugin, preview, sheets, spreadsheet, table, tsv, workbook, xlsx

## 简介

DSH web plugin (dsh-better-sidebar consumer): render CSV/TSV/PSV files and xlsx/xlsm workbooks as a structured, sortable, filterable table in the right sidebar — with sheet tabs and a circuit breaker (rows/cols/cells plus the two zip-container gates) so n
