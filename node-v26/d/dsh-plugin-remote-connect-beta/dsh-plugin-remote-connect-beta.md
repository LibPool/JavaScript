# dsh-plugin-remote-connect-beta

> 标签: cordis-plugin, deepseek-harness, dsh, remote, tunnel

## 简介

让 DSH Harness 可从局域网或公网访问：本机反向代理（含手机适配与访问密钥门）+ ssh 反向隧道 + 服务器配置生成与前置检查。
