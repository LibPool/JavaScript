# dsh-plugin-wallpaper-engine-yhz

> 标签: background, deepseek-harness, dsh, dsh-plugin, theme, wallpaper, wallpaper-engine

## 简介

Wallpaper Engine backgrounds for the DSH web GUI: render your local Wallpaper Engine wallpapers behind the chat — Scene and Web in real time through the bundled WebWallGL engine, Video played directly — with iOS-style liquid glass, adjustable blur/scrim/b
