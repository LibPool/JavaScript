# dsh-style-tweaks

> 标签: chat-ui, column-width, cordis, css, deepseek, deepseek-ai, dsh, layout, plugin, responsive, style, tweaks, workspace

## 简介

DSH plugin: collection of opt-in style tweaks for DSH's UI — precise conversation column-width control (px stepper, presets, plugin-vs-native toggle, side margin), a configurable first-open width for the right Sidebar as a percentage of the session frame,
