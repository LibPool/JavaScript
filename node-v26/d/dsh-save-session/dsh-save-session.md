# dsh-save-session

> 标签: deepseek, deepseek-harness, dsh, dsh-plugin, export, html, markdown, session

## 简介

DSH（DeepSeek Harness）插件：会话标题栏一键导出当前会话 —— 「保存 MD」下载纯净 Markdown，「保存 HTML」下载带左侧目录、表格与代码块渲染的网页。自动过滤模型思考过程与工具调用记录，只保留用户与助手的正文，适合归档、分享与撰写报告。
