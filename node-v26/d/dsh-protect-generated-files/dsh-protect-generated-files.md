# dsh-protect-generated-files

> 标签: agent, codegen, deepseek, deepseek-harness, dsh, dsh-plugin, generated, guard, lockfile

## 简介

DeepSeek Harness plugin that stops hand edits to generated files (lockfiles, protobuf/codegen output, files marked @generated or DO NOT EDIT) and tells the model which source to edit and what to run instead.
