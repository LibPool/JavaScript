# dsh-session-timeline

> 标签: deepseek-harness, dsh, plugin, session, timeline, ui

## 简介

DeepSeek Harness 会话左侧虚线时间轴：横短横线波浪、当前消息定位（scroll-spy）、点击跳转、圆角预览 tooltip、可收起/展开。
