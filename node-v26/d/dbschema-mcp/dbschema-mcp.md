# dbschema-mcp

> 标签: coding-agent, database, mcp, model-context-protocol, postgres, postgresql, schema

## 简介

MCP server exposing database table definitions (columns, constraints, indexes, comments) to coding agents. PostgreSQL first, extensible dialects.
