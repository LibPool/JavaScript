# drengr-js

> 标签: analytics, electron, fetch, network, observability, react-native, redaction, xhr

## 简介

Zero-code network analytics for JavaScript runtimes (Web, React Native, Electron) — one call captures every fetch/XHR exchange with secret/PII redaction in-process, no track() calls.
