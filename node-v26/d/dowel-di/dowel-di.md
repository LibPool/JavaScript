# dowel-di

> 标签: angular, container, dependency-injection, di, inject, ioc, provide, react, ssr, typescript, vue, zero-dependency

## 简介

Token-based DI for libraries that ship to vue, react and angular. One declaration per token, native angular DI, zero deps, SSR-safe.
