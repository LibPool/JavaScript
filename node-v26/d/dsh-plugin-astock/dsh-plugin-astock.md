# dsh-plugin-astock

> 标签: a-share, deepseek-harness, dsh, dsh-plugin, market-data, stock, technical-indicators, tushare

## 简介

A-share (Chinese stock market) data plugin for DeepSeek Harness: 10 tools covering quotes, K-lines and technical indicators for one stock, whole-market snapshots and daily bars for screening, plus financial statements, money flow and convertible bonds. Fi
