# dsh-menu

> 标签: context-menu, deepseek, dsh, dsh-plugin, file-manager, harness, web-ui, workspace-files

## 简介

Custom right-click context menu for the sidebar workspace files tree: new folder, rename, reveal in file manager, open in browser, open in VS Code, copy path, streaming ZIP download, and delete.
