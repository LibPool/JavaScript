# dsh-prompt-suggestions

> 标签: autocomplete, deepseek, deepseek-harness, dsh, dsh-plugin, next-prompt, prompt-suggestions, suggestion, tab-completion

## 简介

DeepSeek Harness 输入框的下一句建议：助手回复完，空输入框里出现一句灰色建议，按 Tab 填入。Prompt suggestions for the DSH composer.
