> 标签: UI, component, custom-hook, frontend, navigate, navigation, page-navigation, paginate, pagination, pagination-hook, react, react-hooks, router, routing, useContext, useEffect, useReducer, useRef, useState

## 简介

`data-paginate` is a React hook for handling pagination with an array of data. It provides an easy way to paginate data with simple navigation functions.
