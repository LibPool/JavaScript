# doodleppl

> 标签: bayesian, bugs, doodlebugs, doodleppl, editor, graphical-models, ppl, stan, widget

## 简介

Embed the DoodlePPL graphical model editor anywhere: a typed mount class over the compiled editor, with callbacks for graph state and generated BUGS/Stan code.
