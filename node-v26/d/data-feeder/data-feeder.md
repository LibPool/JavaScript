# data-feeder

> 标签: agent-data, ai-agent, api-cache, data-feed, data-freshness, mcp, mcp-server, model-context-protocol, remote-agent, scheduled-fetch, x402

## 简介

Declarative data feeds for AI agents. YAML config → MCP server with caching, scheduling, and auth. Stop writing custom MCP servers for each API.
