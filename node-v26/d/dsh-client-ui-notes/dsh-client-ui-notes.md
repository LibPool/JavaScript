# dsh-client-ui-notes

> 标签: deepseek-harness, dsh, editor, markdown, notes, plugin

## 简介

DSH 笔记插件：主面板阅读器 + 备忘录，支持 Markdown 左编右渲、txt 编辑、文件树与置顶。
