# dsh-mini-window

> 标签: client-plugin, compact, deepseek-harness, dsh, mini-window, plugin

## 简介

DSH 小窗模式：?dsh-mini=1 触发的紧凑单栏对话视图，另附可选的独立小窗进程（悬浮球 + 无边框浮窗）。
