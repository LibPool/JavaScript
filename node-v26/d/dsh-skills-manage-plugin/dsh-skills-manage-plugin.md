# dsh-skills-manage-plugin

> 标签: claude-code, deepseek-harness, dsh, plugin, skills

## 简介

DeepSeek Harness plugin for managing Claude Code-style skills: a Settings UI to author, edit, enable and delete skills, plus slash-command (/name) invocation and .claude/skills discovery.
