# dsh-plugin-mobile-bridge

> 标签: cloudflare-tunnel, deepseek-harness, dsh, dsh-plugin, mcode, mobile, qrcode, remote-control

## 简介

Mobile remote-control bridge for DeepSeek Harness: a token-authenticated REST+SSE surface over dsh's own /api, a pairing QR panel in the web GUI, and LAN / tunnel / relay carriers so the MCode phone app can drive a desktop dsh. 让手机 App（MCode）遥控桌面 dsh 的承接插
