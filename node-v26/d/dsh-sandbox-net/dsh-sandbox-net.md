# dsh-sandbox-net

> 标签: deepseek, dsh, dsh-bundle, dsh-plugin, egress, fetch, harness, network, sandbox

## 简介

Give a sandboxed DeepSeek Harness agent network egress: one fetch tool that runs the request in the host process, against a configurable host allowlist, while the sandbox keeps its write boundary.
