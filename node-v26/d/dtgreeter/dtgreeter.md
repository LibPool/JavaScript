# dtgreeter

> 标签: afternoon, daytime, evening, greet, greeting, morning, night, time, user, utility

## 简介

A utility function that returns a greeting according to the users daytime , Good morning | afternoon | evening | night. Can recieve an optional parameter which is the name of the user.
