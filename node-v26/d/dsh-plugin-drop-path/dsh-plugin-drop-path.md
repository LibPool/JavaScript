# dsh-plugin-drop-path

> 标签: cordis, deepseek, drag-and-drop, dsh, dsh-plugin, folder, harness, path

## 简介

DSH 文件夹拖拽：把一个文件夹拖进 DSH，输入框里显示它的绝对路径（@路径/ 引用块），而不是被当成附件上传。
