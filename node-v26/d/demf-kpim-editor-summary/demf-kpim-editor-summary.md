# demf-kpim-editor-summary

> 标签: JavaScript

## 简介

The KPIM Editor Summary microfrontend shows resume all the informations regarding the selected KPI and give the access to update its informations. The KPIM Editor Summary works within the KPIM tool in which it is mounted, and is an access point to the KPI
