# dmk-loading

> 标签: accessibility, async, concurrency, framework-agnostic, loading, mask, overlay, react, spinner, transition, vue3, zero-import, 加载, 并发, 指令, 无框架依赖, 遮罩

## 简介

框架无关的过渡动画加载库。装完即用，页面零 import：请求前后调 openLoading()/closeLoading() 即可，遮罩的显示、定位、并发计数、防闪烁全部由库内部接管。core 纯 TS 零运行时依赖，Vue/React/UniApp/鸿蒙 共享同一套逻辑。
