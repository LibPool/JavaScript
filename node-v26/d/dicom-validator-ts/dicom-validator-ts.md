# dicom-validator-ts

> 标签: dicom, dicom-standard, healthcare, medical-imaging, validator

## 简介

A TypeScript library for validating DICOM files against the DICOM standard (PS3.3, PS3.6). Provides both a programmatic API and CLI tool.
