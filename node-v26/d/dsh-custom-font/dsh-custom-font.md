# dsh-custom-font

> 标签: deepseek, dsh, dsh-plugin, font, harness, theme, typography, windows

## 简介

自定义 DeepSeek Harness 界面字体/字号/加粗/颜色：像 Word 一样在设置里改，所见即所得，自动保存。Windows 下自动读取系统已装字体库。
