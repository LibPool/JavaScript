# dsh-vision-mcp

> 标签: ai, image, llm, mcp, model-context-protocol, multimodal, ocr, read-image, vision

## 简介

Give your text-only LLM eyes: an MCP server that reads images via external OpenAI-compatible vision models (OpenAI, Qwen-VL, GLM, Gemini, Grok, Ollama...) with automatic provider fallback on rate-limit/errors.
