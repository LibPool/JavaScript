# dsh-media-gen

> 标签: cordis, deepseek, deepseek-harness, dsh, dsh-plugin, image-generation, image-to-video, text-to-video, video-generation

## 简介

DSH 生图+生视频整合插件：统一多供应商目录（OpenAI 兼容 images/chat 网关、DashScope 通义万相、火山 Seedance、Google Veo、Sora 风格 /v1/videos 异步任务含 input_reference 图生视频），提供 image_generate / generate_video / animate_image 工具，对话内联显示、图片与视频画廊、统一设置面板。Fork 合并自 dsh-image-generation 与 dsh-video-gen
