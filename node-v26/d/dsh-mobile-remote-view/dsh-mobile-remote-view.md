# dsh-mobile-remote-view

> 标签: bundle, deepseek-harness, dsh, mobile, plugin, remote, small-screen

## 简介

Rotates the DSH Web GUI a quarter turn and turns the sidebar, conversation and right panel into full-screen pages for phone-sized remote screens
