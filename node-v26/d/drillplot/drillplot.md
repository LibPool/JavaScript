# drillplot

> 标签: coaching, court, custom-element, diagram, diagram-editor, drill, esm, json-schema, pickleball, svg, svg-editor, typescript, web-component

## 简介

Pickleball drill diagram editor (a web component) and SVG renderer: draw players, cones and numbered shots on a to-scale court, then export editable SVG.
