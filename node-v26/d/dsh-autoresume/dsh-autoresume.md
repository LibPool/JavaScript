# dsh-autoresume

> 标签: auto-continue, automation, deepseek-harness, dsh, dsh-plugin, resume, session

## 简介

dsh web 重启后自动向固定开发会话注入「继续」：只服务目标会话，完成态不动作，避免重复注入。
