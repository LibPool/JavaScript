# dsh-mdvault

> 标签: deepseek-harness, document-viewer, dsh, dsh-plugin, dsh-web, file-preview, markdown, mermaid, obsidian, pdf, spreadsheet, wikilinks

## 简介

Workspace document vault for the dsh web GUI: a conversation '文档' tab with an all-type file tree (Markdown/PDF/HTML/code/Excel·CSV/images), full GFM rendering via the platform MarkdownText (tables, task lists, footnotes, KaTeX math, highlighted code fence
