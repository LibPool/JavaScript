# dsh-openrouter-providers

> 标签: deepseek, dsh, dsh-plugin, harness, openrouter, provider-routing

## 简介

OpenRouter Provider List — 填写 OpenRouter 请求使用的提供商列表与量化位数限制，作为 provider.only / provider.order / provider.quantizations 注入。配置由插件自持（$DSH_HOME/openrouter-providers.json），不依赖 settings 命名空间注册，因此同时适配 DSH 0.1.5-rc.1 ~ 0.1.7-rc.1。配置入口：DSH >= 0.1.6-alpha.2 在侧栏「插件」页
