# dsh-session-remover

> 标签: agent, batch-delete, batch-deletion, cleanup, context-menu, conversation, conversation-delete, cordis, cordis-plugin, deepseek, deepseek-harness, delete-conversation, delete-session, dsh, dsh-plugin, dsh-plugins, llm, recycle-bin, session, session-delete, session-remover, sidebar, subagent, web, windows, 会话管理, 侧栏, 删除会话, 删除对话, 回收站, 批量删除

## 简介

DSH 插件：在侧栏会话行的「…」菜单中增加「删除对话」与「批量删除…」，将对话及其子代理会话移入 Windows 回收站，可从回收站还原。
