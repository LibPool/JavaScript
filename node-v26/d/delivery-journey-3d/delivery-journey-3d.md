# delivery-journey-3d

> 标签: 3d, animation, delivery, logistics, order-tracking, react, react-three-fiber, three

## 简介

Interactive 3D order-delivery journey for React: pick a delivery type, pick a vehicle, drive the parcel station by station. Built on three.js and React Three Fiber.
