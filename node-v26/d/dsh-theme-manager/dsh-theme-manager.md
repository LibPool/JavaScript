# dsh-theme-manager

> 标签: deepseek-harness, dsh, dsh-plugin, theme, theme-manager, themes, ui-theme

## 简介

Two-level theme manager for DeepSeek Harness Web: pick a culture/scene, a national flag, a developer palette, or a bold high-contrast pairing first, then a style (58 built-in: China·Ink Wash, Japan·Ukiyo-e, Developer·Catppuccin, High Contrast·Black & Gold
