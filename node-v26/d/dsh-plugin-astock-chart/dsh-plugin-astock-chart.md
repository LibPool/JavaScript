# dsh-plugin-astock-chart

> 标签: a-share, candlestick, chart, deepseek-harness, dsh, dsh-plugin, web-ui

## 简介

Draws the candlesticks in the reply: a web-client card that renders astock_data results as an OHLC chart with volume, instead of a table of numbers.
