# dazzle-react-native

> 标签: agent, android, anthropic, chat-agent, claude, dazzle, edge-ai, embedded-database, embedding, foundation-models, hnsw, ios, litert-lm, llama-cpp, llm, on-device, openai, react-native, redis, valkey, vector-search

## 简介

Dazzle SDK for React Native — embedded in-process database with HNSW vector search and a ChatAgent runtime for on-device LLM agents. Includes five swappable LLMClient adapters (LlamaCpp, LiteRT-LM, FoundationModels, OpenAI-compatible, Anthropic). Same lib
