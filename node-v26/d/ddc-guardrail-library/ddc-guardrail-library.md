# ddc-guardrail-library

> 标签: JavaScript

## 简介

You should explore the contents of this project. It demonstrates a CDK app with an instance of a stack (`CdkAssertErrorStack`) which contains an Amazon SQS queue that is subscribed to an Amazon SNS topic.
