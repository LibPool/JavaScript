# document-processing-cleaner

> 标签: document background remover, document cleaner, image scanner, opencv, tensorflow

## 简介

📄 react-document-cleaner A React hook-based utility for processing document images in the browser using DeepLab (TensorFlow.js) and OpenCV.js. This tool segments paper-like regions, applies masks, deskews, and extracts the clean document for use in OCR,
