# decius-css

> 标签: affineui, css, dark-theme, dcc, design-system, desktop, framework, icons, scss, synth, tools, ui

## 简介

A CSS framework for digital content creation (DCC) tools, synths, and pro desktop interfaces. Built for affineui; runs in any browser.
