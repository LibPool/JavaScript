# dsh-task-dispatch-table

> 标签: deepseek, dsh, dsh-plugin, harness, task-dispatch

## 简介

一个 dsh host 层插件：用一张任务定义表驱动周期性任务，按时间窗与依赖把任务派发成独立会话执行（调度层零大模型介入）
