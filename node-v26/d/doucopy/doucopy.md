# doucopy

> 标签: agent-communication, agent-link, ai-agents, claude-code, cli, codex, cross-machine, cursor, doucopy, mcp

## 简介

Connect AI agents from different accounts (or a small trusted circle) so one can ask the other questions answered from its own memory. CLI, MCP, terminal REPL.
