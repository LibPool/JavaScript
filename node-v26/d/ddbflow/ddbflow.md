# ddbflow

> 标签: access-patterns, aws, aws-sdk, aws-sdk-v3, batchwrite, builder, conditionexpression, documentclient, dynamodb, dynamodb-expressions, dynamodb-query-builder, expression-builder, expressionattributenames, filterexpression, fluent, keyconditionexpression, lambda, no-orm, pagination, params, prepared-query, projectionexpression, query-builder, serverless, transactwrite, type-safe, typescript, updateexpression

## 简介

Fluent, type-safe DynamoDB params builder: kill the ExpressionAttributeNames/Values boilerplate without adopting an ORM. Zero dependencies, works with AWS SDK v2 and v3.
