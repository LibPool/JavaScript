# dsh-plugin-doc-upload

> 标签: attachment, deepseek, document, docx, dsh, dsh-plugin, plugin, upload, web

## 简介

DeepSeek Harness 文档上传插件：拖放本地文档到工作区并自动在输入框生成路径引用，与文字一起发送。
