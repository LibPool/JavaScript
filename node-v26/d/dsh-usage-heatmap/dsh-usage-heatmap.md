# dsh-usage-heatmap

> 标签: dsh, dsh-plugin, heatmap, statistics, token, usage

## 简介

模型用量统计面板：累计 Token/峰值/最长会话/连续天数指标卡 + GitHub 风格 Token 热力图（日/周/累计切换）+ 活动洞察，数据来自本地 DSH 用量聚合
