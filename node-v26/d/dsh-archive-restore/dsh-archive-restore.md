# dsh-archive-restore

> 标签: archive, deepseek-harness, dsh, plugin, restore, session

## 简介

归档管理：在设置页列出已归档会话（显示标题、支持多选），一键恢复并自动重启 Web GUI。Restore archived DSH sessions from the settings page with title list, multi-select and auto-restart.
