# dsh-network-proxy

> 标签: deepseek, deepseek-harness, dsh, dsh-plugin, network, proxy, 网络代理

## 简介

DSH 网络代理管理插件：在设置界面随时切换 跟随系统 / 手动代理 / 直连 三种网络出口模式，修改后立即生效。 / DSH network proxy plugin: switch between system / manual / direct proxy modes from the settings UI, applied live.
