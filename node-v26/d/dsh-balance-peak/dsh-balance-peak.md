# dsh-balance-peak

> 标签: balance, deepseek-harness, dsh, peak-valley, plugin, 余额, 峰谷

## 简介

DeepSeek Harness 输入框上方右上角：DeepSeek 账户余额 + 高峰/低谷时段徽章（可微调位置）。余额经服务端代理（复用 DEEPSEEK_API_KEY）读取，key 不出服务端。
