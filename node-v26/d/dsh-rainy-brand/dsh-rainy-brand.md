# dsh-rainy-brand

> 标签: brand, deepseek-harness, dsh, dsh-plugin, wordmark

## 简介

DSH web 插件：侧栏字标、空白会话大标题与「预览版」标签的用户可编辑品牌配置，外加按选择器的 CSS 注入，保存在当前 profile 配置，改完即时生效
