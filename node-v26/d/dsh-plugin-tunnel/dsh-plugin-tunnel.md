# dsh-plugin-tunnel

> 标签: cloudflare, cordis, dsh-plugin, tunnel

## 简介

Cloudflare Named Tunnel 生命周期插件 —— 让任意 dsh 插件的 loopback 看板按需、限时、可撤销地对外暴露
