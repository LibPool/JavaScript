# denoify

> 标签: CommonJs, cjs, deno, transpile

## 简介

For NPM module authors that would like to support Deno but do not want to write and maintain a port.

## 官网

- 官网：https://denoify.land
- 源码仓库：git://github.com/garronej/denoify.git
- npm 页面：https://www.npmjs.com/package/denoify
