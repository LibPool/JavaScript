# dsh-prts-endfield

> 标签: 550c, arknights, deepseek-harness, dsh, dsh-plugin, endfield, prts, skin, theme

## 简介

《明日方舟：终末地》主题 + PRTS / 550C 控制台皮肤的合并插件（非官方）：终末地炭黑 + 警戒黄 HUD、开屏动画、对话区背景、侧栏电力储备，叠加皮肤的四套磷光配色、扫描线与等宽字体；设置里只有一页「终末地 · PRTS」。
