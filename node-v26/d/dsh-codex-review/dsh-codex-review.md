# dsh-codex-review

> 标签: codex, deepseek-harness, dsh, plugin, review, subagent

## 简介

A deterministic /review command for DeepSeek Harness: a reviewer subagent pinned to a subscription-backed Codex model, with a settings card, one reviewer session per chat, and /review reset to forget it.
