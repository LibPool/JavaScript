# dsh-mermaid-render

> 标签: JavaScript

## 简介

DSH 对话 Mermaid 图表渲染插件：mermaid/mmd 代码块自动渲染为图表卡片（预览/代码切换），引擎按需加载。DSH web plugin: render mermaid/mmd code blocks into diagram cards, on-demand engine loading.
