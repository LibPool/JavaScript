# datafordeler-dar-mcp

> 标签: addresses, adresser, danmark, dar, datafordeler, datafordeleren, dawa, denmark, geocoding, mcp, model-context-protocol

## 简介

MCP server for Danish addresses from Danmarks Adresseregister (DAR) on Datafordeleren. The replacement for DAWA, which closed on 1 October 2026.
