# dg-cell-mvi-element-plus

> 标签: JavaScript

## 简介

Element Plus view layer for @dg-cell-mvi: the Fs* components that render el-* + elementUiRegistry (the Element impl of dg-cell-mvi-vue's UiRegistry). Re-exports useCrud + the crud contract so pages import everything from one place.
