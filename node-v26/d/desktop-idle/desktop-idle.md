# desktop-idle

> 标签: afk, away, desktop, electron, idle

## 简介

Node/Electron module to detect idle desktop users(users away from keyboard) in macOS, Windows, Linux, FreeBSD and OpenBSD

## 官网

- 官网：https://github.com/bithavoc/node-desktop-idle
- 源码仓库：git+ssh://git@github.com/bithavoc/node-desktop-idle.git
