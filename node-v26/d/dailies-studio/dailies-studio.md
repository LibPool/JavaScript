# dailies-studio

> 标签: JavaScript

## 简介

The ship vehicle: a dev server booted inside the user's project (Vite middleware mode) so their deps, aliases and assets resolve natively. Component discovery, contract extraction with HMR re-extraction, sidecar meta, document persistence, scaffold/eject.
