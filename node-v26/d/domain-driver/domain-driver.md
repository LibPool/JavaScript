# domain-driver

> 标签: cli, domain-driven, express, fastify, hono, nestjs, nextjs, node, react, scaffolding, tanstack, tanstack-start

## 简介

CLI scaffolding tool for domain-driven feature folders in Next.js, React, Node, NestJS, and TanStack Start projects, with per-action files, bespoke actions, and agent guidance
