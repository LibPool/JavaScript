# dsh-guard-hooks

> 标签: cordis, deepseek-harness, dsh, hooks, plugin

## 简介

Claude Code-style user-configurable hooks for DeepSeek Harness (DSH): PreToolUse interception, format-on-save, desktop notifications, audit log, webhook push
