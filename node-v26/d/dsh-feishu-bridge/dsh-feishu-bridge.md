# dsh-feishu-bridge

> 标签: agent, bridge, cordis, deepseek-harness, dsh, feishu, lark, streaming

## 简介

Bridge Feishu (Lark) private chat (text + images with vision analysis) into DSH agent sessions: stable one-session mapping, explicit new-session command, cardkit typewriter streaming.
