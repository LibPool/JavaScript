# dd-vue-calendar

> 标签: CTTQ, Calendar, DD, DUODUO, calendar, cttq, dd, duoduo, vue, vue.js

## 简介

一个干净的轻量级移动端日历插件，用于在Vue.js中显示带农历的日历。包括高亮显示的日期区域、节假日、今天、单选日期、多选日期段等。
