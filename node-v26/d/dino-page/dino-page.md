# dino-page

> 标签: JavaScript

## 简介

**dino-page** là CLI tool giúp tự động tạo page React + Redux theo template chuẩn, hỗ trợ PlopJS, giúp tăng tốc phát triển dự án với cấu trúc code thống nhất.
