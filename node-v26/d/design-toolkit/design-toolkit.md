# design-toolkit

> 标签: ai, claude-code, design, devtools, figma, prompt, radius, spacing, vibe-coding

## 简介

A minimal toolbar for dialing in design while vibe coding: tweak text, radius, spacing and layout on localhost, copy one prompt for your coding agent.
