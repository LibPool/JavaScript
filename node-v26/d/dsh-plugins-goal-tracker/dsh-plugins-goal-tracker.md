# dsh-plugins-goal-tracker

> 标签: deepseek-harness, dsh, goal, opencode, plugin

## 简介

OpenCode-style goal tracker for the DSH web GUI: composer-dock tracker with phase badge, round stepper, progress bar, live elapsed time, completion-policy modes, full controls (pause/resume/clear/edit/create, unlimited rounds; no manual complete button),
