# dsh-local-plugin-manager

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, link-plugin, local-plugin, plugin-development

## 简介

面向插件开发者：在「设置 > 插件开发」里管理当前 web profile 中以 link: 挂载的本地源码插件，查看源路径与 loader 行，并快速启停或移除。
