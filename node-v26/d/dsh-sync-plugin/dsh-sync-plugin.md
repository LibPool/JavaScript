# dsh-sync-plugin

> 标签: backup, deepseek-harness, dsh, dsh-plugin, github, multi-device, session-sync, sync, workspace-sync

## 简介

DeepSeek Harness 多电脑同步：通过自己的 GitHub 仓库同步会话、附件、设置和工作区文件。Sync DSH sessions, settings and workspace files across computers.
