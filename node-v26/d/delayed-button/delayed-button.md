# delayed-button

> 标签: JavaScript

## 简介

功能：将获取短信、邮箱等验证的非业务操作封装，让程序更专注业务，而不是按钮内容和是否可用的控制。组件不提供样式，用户可根据自己引入的框架来进行样式渲染。
