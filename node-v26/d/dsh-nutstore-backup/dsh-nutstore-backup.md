# dsh-nutstore-backup

> 标签: backup, deepseek-harness, dsh, dsh-plugin, jianguoyun, nutstore, restore, sync, webdav

## 简介

坚果云（Nutstore WebDAV）备份插件：在 DSH 设置里登录坚果云，增量备份会话记录、插件配置与工作区记忆，并在新机器上一键恢复。
