# @metaharness/field-memory

> 标签: agent, associative-memory, attractor-memory, field-memory, metaharness, routing, ruvector

## 简介

Governed packed-multihead attractor memory for agent routing. Encodes verified aggregate outcomes as a cost-aware routing field without exposing raw episodes or requiring a native vector dependency.
