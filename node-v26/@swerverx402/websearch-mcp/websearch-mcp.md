> 标签: ai-agent, claude, headless-browser, langchain, markdown, mcp, mcp-server, model-context-protocol, scraper, swerver, usdc, web-scraping, x402

## 简介

MCP server that lets an agent search and scrape the web and pay for it itself — per request in USDC on Base via x402. No API keys.
