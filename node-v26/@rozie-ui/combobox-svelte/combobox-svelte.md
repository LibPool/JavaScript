# @rozie-ui/combobox-svelte

> 标签: accessibility, aria, autocomplete, combobox, component, headless, rozie, rozie-ui, select, svelte, typeahead

## 简介

Idiomatic Svelte headless WAI-ARIA combobox / autocomplete (text input + popup listbox, client/async filtering, full keyboard navigation, aria-activedescendant) — one accessible Rozie source compiled to Svelte.
