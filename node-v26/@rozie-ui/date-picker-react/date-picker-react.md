# @rozie-ui/date-picker-react

> 标签: accessibility, aria, calendar, component, date, date-picker, datepicker, headless, react, rozie, rozie-ui

## 简介

Idiomatic React headless WAI-ARIA single-date calendar (month grid, prev/next nav, weekStartsOn, min/max/disabledDates, roving keyboard focus) — one accessible Rozie source compiled to React.
