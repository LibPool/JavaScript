# @rozie-ui/number-field-solid

> 标签: accessibility, aria, component, form, headless, number-field, numeric-input, rozie, rozie-ui, solid, spinbutton, stepper

## 简介

Idiomatic Solid headless WAI-ARIA numeric stepper / spinbutton (clamp, step snapping, keyboard, press-and-hold acceleration, Intl.NumberFormat, optional scrub) — one accessible Rozie source compiled to Solid.
