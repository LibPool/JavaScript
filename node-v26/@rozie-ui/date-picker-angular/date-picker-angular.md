# @rozie-ui/date-picker-angular

> 标签: JavaScript

## 简介

Idiomatic Angular headless WAI-ARIA single-date calendar (month grid, prev/next nav, weekStartsOn, min/max/disabledDates, roving keyboard focus, ControlValueAccessor) — one accessible Rozie source compiled to Angular.
