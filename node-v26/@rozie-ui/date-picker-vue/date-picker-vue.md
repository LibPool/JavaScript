# @rozie-ui/date-picker-vue

> 标签: accessibility, aria, calendar, component, date, date-picker, datepicker, headless, rozie, rozie-ui, vue

## 简介

Idiomatic Vue headless WAI-ARIA single-date calendar (month grid, prev/next nav, weekStartsOn, min/max/disabledDates, roving keyboard focus) — one accessible Rozie source compiled to Vue.
