# @rozie-ui/resizable-solid

> 标签: accessibility, aria, component, headless, layout, panel, resizable, resize, rozie, rozie-ui, solid, split-pane, splitter

## 简介

Idiomatic Solid headless accessible two-panel splitter / resizable pane (pointer-drag + pointer capture, role=separator keyboard control, min/max clamp, two-way size, start/end/handle slots) — one accessible Rozie source compiled to Solid.
