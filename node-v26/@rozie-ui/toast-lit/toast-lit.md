# @rozie-ui/toast-lit

> 标签: accessibility, aria, component, headless, lit, notification, rozie, rozie-ui, snackbar, toast, toaster

## 简介

Idiomatic Lit headless, accessible toast / notification host (queue, auto-dismiss, hover-pause, positioning, imperative show/dismiss/clear handle) — one accessible Rozie source compiled to a Lit custom element.
