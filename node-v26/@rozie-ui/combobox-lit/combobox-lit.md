# @rozie-ui/combobox-lit

> 标签: accessibility, aria, autocomplete, combobox, component, headless, lit, rozie, rozie-ui, select, typeahead

## 简介

Idiomatic Lit headless WAI-ARIA combobox / autocomplete (text input + popup listbox, client/async filtering, full keyboard navigation, aria-activedescendant) — one accessible Rozie source compiled to a Lit custom element.
