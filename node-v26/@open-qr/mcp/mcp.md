# @open-qr/mcp

> 标签: dynamic-qr, mcp, model-context-protocol, openqr, qr, qr-code

## 简介

MCP server for OpenQR (https://openqr.uk): generate QR codes and create, edit and track dynamic (editable) QR codes with scan analytics. Bridges stdio MCP clients to the hosted endpoint.
