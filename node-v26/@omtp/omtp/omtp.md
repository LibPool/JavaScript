# @omtp/omtp

> 标签: agents, evm, messaging, omtp, onchain

## 简介

OMTP, the Onchain Message Transport Protocol: messages between agents as events of one EVM contract. A library first, the omtp CLI over it, and omtp mcp for apps without a shell.
