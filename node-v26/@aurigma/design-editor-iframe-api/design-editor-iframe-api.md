# @aurigma/design-editor-iframe-api

> 标签: aurigma, customer's canvas, design editor, iframe api, web-to-print, web-to-print editor

## 简介

Using this module you can embed Design Editor (a part of Customer's Canvas) to your page through the IFrame API.
