# @meetdarwin/api

> 标签: api, chat, darwin, meetdarwin, sdk, webhooks

## 简介

TypeScript client for the Darwin REST API: conversations, contacts, meetings, outcome forms, personal links, webhooks, knowledge, the agent and the chat API.
