# romdev-spimdisasm

> 标签: JavaScript

## 简介

spimdisasm (MIPS disassembler used by splat) ported to plain JavaScript ESM, for romdev. Reproduces spimdisasm 1.42.4, 1.39.3 and 1.35.0 output byte for byte, selectable at runtime.
