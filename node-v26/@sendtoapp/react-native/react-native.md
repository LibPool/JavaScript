# @sendtoapp/react-native

> 标签: app-links, deep-links, deferred-deep-linking, expo, react-native, sendtoapp, universal-links

## 简介

Deep links for React Native and Expo: one HTTPS link that opens the right screen, with the config plugin that wires up Universal Links and App Links.
