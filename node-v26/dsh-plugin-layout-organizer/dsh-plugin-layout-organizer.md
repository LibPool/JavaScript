# dsh-plugin-layout-organizer

> 标签: cordis, deepseek-harness, dsh, dsh-bundle, dsh-plugin, layout, reorder, sidebar, stash

## 简介

Drag-and-drop reordering, official/third-party dividers and a stash panel for the buttons DSH renders in the sidebar, the sidebar footer, the conversation tabs, the composer dock and Settings. Only display position changes; the plugin registry is untouche
