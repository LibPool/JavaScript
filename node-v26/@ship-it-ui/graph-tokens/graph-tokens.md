# @ship-it-ui/graph-tokens

> 标签: design-system, design-tokens, graph, shipit

## 简介

Token-resolution helpers for Ship-It graph adapters. Reads `--color-*` CSS variables at runtime and coerces them to sRGB strings that non-DOM renderers (Cytoscape, React Flow) can parse.
