# @dloizides/ui-icons

> 标签: dloizides, icons, react, react-native, react-native-svg, svg

## 简介

Lightweight inline-SVG icon component + icon-path registry (react-native-svg) for the dloizides.com RN-web portfolio. Zero font loading, brand-agnostic.
