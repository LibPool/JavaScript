# @dloizides/site-template-kit

> 标签: framework-neutral, json-schema, landing-page, site-config, template, tenant

## 简介

Framework-neutral Template Contract for dloizides.com landing/site templates: the TenantSite config types (relocated from kefi-landings), the TemplateManifest, a manifest registry loader, the JSON Schema generated from the types, and an ajv validator. No
