# @pi-harness/plugin-docker-sandbox

> 标签: cordis, pi-harness, pi-harness-plugin, plugin

## 简介

Run descriptor-safe argv commands with local-only Docker images, no container network, a read-only workspace by default, fixed CPU, memory, and PID limits, sanitized output, strict panel reporting, and cancellation cleanup.
