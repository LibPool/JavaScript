# @pi-harness/plugin-git-time-capsule

> 标签: cordis, pi-harness, pi-harness-plugin, plugin

## 简介

Capture the current unstaged tracked Git diff as a byte-exact, validated undo capsule without external diff or textconv helpers, then reverse-apply it only after explicit confirmation.
