# @pi-harness/plugin-hol-guard

> 标签: cordis, pi-harness, pi-harness-plugin, plugin

## 简介

Audit tool arguments and preflight text for destructive commands, sensitive paths, credentials, and remote exfiltration. Advisory only: reports risk, does not block execution.
