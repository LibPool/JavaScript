# @pi-harness/plugin-at-file

> 标签: cordis, pi-harness, pi-harness-plugin, plugin

## 简介

Attach a bounded 256 KiB strict UTF-8 workspace file using canonical workspace path confinement and no-follow regular-file reads, framing it as offline, read-only, untrusted model context with closing-tag neutralization and cancellable sequential executio
