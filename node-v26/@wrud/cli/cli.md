# @wrud/cli

> 标签: ai-agents, claude-code, cli, cost-optimization, llm, local-first, observability, session-recording

## 简介

Run wrud locally with one command - a local-first recorder for AI-agent sessions (tools, models, cost, insights). `npx @wrud/cli`.
