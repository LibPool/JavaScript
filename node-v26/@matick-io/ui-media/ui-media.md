# @matick-io/ui-media

> 标签: JavaScript

## 简介

Frame-accurate playback of video, audio and stills: a shared media context, stage, video and image surfaces, transport controls, hotkeys and audio peaks. Drives a ui-timeline Timeline placed inside it.
