# @jev-harness/cli

> 标签: ci, cli, developer-tools, gate, jev, system-one, typesafe

## 简介

Unified `jev` CLI for TypeSafe Jev (System One): ask, models, eval, plus the `jev-gate` post-run gate check for CI and subagents.
