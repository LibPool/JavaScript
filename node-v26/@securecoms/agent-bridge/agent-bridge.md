# @securecoms/agent-bridge

> 标签: JavaScript

## 简介

Attached runtimes should include the inbound `message_id` as `in_reply_to` on their outbound `send` frame/request. After the encrypted send publishes, the bridge retains a bounded, 15-minute content-free receipt and exposes it at the bearer-gated loopback
