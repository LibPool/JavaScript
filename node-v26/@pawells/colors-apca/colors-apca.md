# @pawells/colors-apca

> 标签: accessibility, apca, color-science, colors, contrast, wcag

## 简介

APCA (Accessible Perceptual Contrast Algorithm) contrast calculation for @pawells/colors — opt-in W3-licensed accessibility contrast utility, kept separate so the MIT-licensed core package carries no field-of-use restrictions.
