# @pawells/nestjs-server

> 标签: bootstrap, cors, lifecycle, microservices, nats, nestjs, server, shutdown

## 简介

NestJS application bootstrapper with lifecycle management, CORS, optional TLS/security headers, NATS microservice transport, opt-in health checks, and graceful shutdown
