# @pawells/colors

> 标签: color, color-blindness, color-conversion, color-science, color-space, colors, contrast, css-color-4, delta-e, gamut-mapping, hsl, lab, oklch, rgb, typescript, wcag

## 简介

TypeScript color space management and conversion library — 30+ color spaces (RGB/HSL/CMYK, perceptual Lab/OKLab, wide-gamut/HDR, Munsell) via BFS-dispatched conversion, plus ΔE, WCAG contrast, CVD simulation, gamut mapping, blending, CCT, and CSS Color 4
