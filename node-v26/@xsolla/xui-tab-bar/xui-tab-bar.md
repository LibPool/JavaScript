# @xsolla/xui-tab-bar

> 标签: JavaScript

## 简介

A pill-shaped, segmented-style tab bar that adapts the React Navigation bottom-tab API. Implements the WAI-ARIA Tabs pattern with roving tab index and arrow-key navigation.
