# @docs.plus/extension-hypermultimedia

> 标签: audio, docs.plus, embed, floating-ui, image, loom, multimedia, prosemirror, rich-text-editor, soundcloud, spotify, tiptap, tiptap-extension, twitter, video, vimeo, x, youtube

## 简介

Tiptap extension for embedded multimedia: images, audio, video, YouTube, Vimeo, SoundCloud, Spotify, Loom, and X — with resize, captions, and a media toolbar
