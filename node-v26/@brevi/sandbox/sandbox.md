# @brevi/sandbox

> 标签: JavaScript

## 简介

The execution environment brevi runs coding agents in. One `Sandbox` holds one run's workspace; the orchestrator creates it, pushes a checkout in, execs the agent, pulls artifacts out, and destroys it.
