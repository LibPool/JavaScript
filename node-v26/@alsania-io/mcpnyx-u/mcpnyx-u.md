> 标签: alsania, bridge, http, mcp, modelcontextprotocol, nyx, proxy, remote, server, sse, stream, streamableHttp, websocket

## 简介

MCPNyx Unified - Advanced MCP server with API key authentication. Run multiple MCP stdio/SSE servers through unified streamableHttp/SSE/WS endpoint, plus an OpenAI-compatible /v1 facade backed by Alsania and any OpenAI-compatible agent (openclaw, nanoclaw
