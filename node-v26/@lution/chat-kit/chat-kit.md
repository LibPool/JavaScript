# @lution/chat-kit

> 标签: chat, express, sequelize, socket.io, typescript, websocket, ws

## 简介

Framework-agnostic chat backend (Sequelize models, service, REST routes, Socket.IO / ws real time, migrations) that runs inside your own Node app and your own database.
