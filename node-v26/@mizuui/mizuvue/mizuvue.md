# @mizuui/mizuvue

> 标签: component library, mizu-vue, primevue, ui library, vue, vue.js, vue3

## 简介

Mizu is an open source UI library for Vue featuring a rich set of 80+ components, a theme designer, various theme alternatives such as Material, Bootstrap, Tailwind, premium templates and professional support.
