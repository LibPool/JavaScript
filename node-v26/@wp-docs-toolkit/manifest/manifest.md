# @wp-docs-toolkit/manifest

> 标签: documentation, handbook, manifest, validation, wordpress, wporg-markdown

## 简介

Validates a handbook manifest.json for the wporg-markdown importer on developer.wordpress.org: path-keyed entries, parents first, no slug takeovers, GitHub blob sources, one H1 per file, no raw block markup.
