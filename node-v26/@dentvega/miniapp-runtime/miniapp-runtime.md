# @dentvega/miniapp-runtime

> 标签: microfrontends, miniapp, module-federation, react-native, repack

## 简介

Host-side runtime for Re.Pack miniapp platforms: resolve → verify (integrity + Ed25519 signature) → mount → fallback. Headless; bring your own ChunkLoader and UI.
