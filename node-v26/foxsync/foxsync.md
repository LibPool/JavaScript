# foxsync

> 标签: browser-agent, cloudflare-workers, device-pairing, encrypted-messaging, firefox, indexeddb, mozilla, peer-to-peer, phone-approval, typescript, web-crypto, webrtc

## 简介

Encrypted WebRTC device pairing, phone approvals, and signed reconnects for Firefox browser agents, with IndexedDB storage and an optional Cloudflare relay.
