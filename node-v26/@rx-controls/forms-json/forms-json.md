# @rx-controls/forms-json

> 标签: JavaScript

## 简介

The Forms v2 JSON loader: ControlDefinition and SchemaField in, the same JSX a hand-written form would be out, plus a list of everything it could not carry across. The only package that reads a ControlDefinition, and the only one that depends on jsonata.
