# @moluoxixi/hooks

> 标签: JavaScript

## 简介

基于 Vue 3 与 TanStack Query 的 CRUD 场景化组合式函数。包只管理查询、提交、分页、筛选和选择状态，实际网络请求由业务传入，不绑定 Axios、Fetch 或具体后端协议。
