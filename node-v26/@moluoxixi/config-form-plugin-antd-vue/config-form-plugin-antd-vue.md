# @moluoxixi/config-form-plugin-antd-vue

> 标签: JavaScript

## 简介

ConfigForm 的 Ant Design Vue runtime adapter。核心包的字段组件默认使用 `modelValue/update:modelValue` 作为绑定协议；本 adapter 通过 `getDefaultField(field)` 生命周期把 Ant Design Vue 字段组件映射到对应的 `valueProp/trigger`，并通过 `readonlyAdapters` 提供只读展示映射。包名与 `createAntdVuePlugin` 保留既有命名，但它不是
