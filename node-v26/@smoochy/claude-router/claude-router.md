# @smoochy/claude-router

> 标签: ai, anthropic, anthropic-proxy, claude, claude-5, claude-code, cost-optimization, cost-tracking, haiku, llm, llm-gateway, llm-proxy, model-router, model-routing, opus, orchestration, proxy, router, sonnet, subagents

## 简介

Claude API cost router for Claude Code: routes each call to Haiku, Sonnet, Opus or Fable, with a route/observe/off switch, a CI-generated model and price list, and a security-gated release per version
