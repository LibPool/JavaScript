# @ngsrv/cli

> 标签: dev-server, localhost, localtunnel, ngrok, ngsrv, preview, tunnel, webhook

## 简介

Expose localhost to the internet with a public HTTPS URL. npx-friendly wrapper around the ngsrv CLI.
