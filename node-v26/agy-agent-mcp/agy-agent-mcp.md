# agy-agent-mcp

> 标签: agy, antigravity, antigravity-cli, claude-code, cli-agent, coding-agent, delegation, gemini, headless, mcp, mcp-server, model-context-protocol, opencode, subagent, subagents

## 简介

Zero-dependency MCP server for subagent-style task delegation to the Antigravity (agy) CLI: headless runs, live stream transcripts, git-audited file scope. Works with OpenCode, Claude Code, and any MCP client.
