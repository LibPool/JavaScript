# @srvzr/cards

> 标签: cards, components, react, srvz, ui

## 简介

Self-contained SRVZ / SRVZr card components (Events, Services, Rentals, Stints, Menus, Work Orders). Props-only, no external data dependencies, mobile/desktop variants.
