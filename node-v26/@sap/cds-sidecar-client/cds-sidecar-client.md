# @sap/cds-sidecar-client

> 标签: CAP, CDS

## 简介

CLI for extensibilty support for the [SAP Cloud Application Programming Model (CAP)](https://cap.cloud.sap). Intended to be used as part of [@sap/cds-dk](https://www.npmjs.com/package/@sap/cds-dk) only.
