# @mdxui/json

> 标签: json, json-ld, mdxld, mdxui, schema

## 简介

Structural output for MDXLD documents: JSON, JSON-LD, JSON Schema, MCP tool and OpenAPI schemas. Not a text register (ui-9ml4.2) — a face of its own. Received from mdx.org.ai with history (ui-9ml4.1).
