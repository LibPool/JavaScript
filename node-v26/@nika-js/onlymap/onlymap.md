# @nika-js/onlymap

> 标签: agent, cartography, custom-elements, data-visualization, dataviz, deck.gl, deckgl, declarative, geoarrow, geojson, geospatial, gis, heatmap, layers, llm, map, maplibre, mapping, maps, react, typescript, visualisation, visualization, web-components, webgl

## 简介

Declarative deck.gl maps for HTML and React — interactive WebGL mapping with GeoJSON/CSV/Arrow data, MapLibre basemaps, widgets, popups, and live streams from a custom-element manifest or typed React components. TypeScript, no build step.
