# knos-settle

> 标签: escrow, github-actions, knos, oidc, payments, solana, x402

## 简介

JavaScript client for knos-pay, knos-meter and knos-oidc on Solana: addresses, audiences, instructions, account layouts, and three calls for an agent platform (quote, eligible, statement). No dependencies.
