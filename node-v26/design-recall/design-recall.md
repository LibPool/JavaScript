# design-recall

> 标签: claude, ddr, design, mockup, prototype

## 简介

Design-driven process tooling for Claude Code / Cowork: versioned HTML mockups + Design Decision Records in a self-contained .design-recall/ folder. Works in any project, with or without git, and never touches the project's own repo.
