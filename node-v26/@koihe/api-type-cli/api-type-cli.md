# @koihe/api-type-cli

> 标签: @koihe, @koihe/api-type-cli, api, api-type-cli, swagger, type-cli

## 简介

一个可以根据用户自定义的配置文件，自动请求 Swagger 文档数据，并解析处理自动生成 API 接口类型定义的快捷工具库。
