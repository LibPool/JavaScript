# @tanglydocs/theme-geist

> 标签: docs, tangly, theme

## 简介

Geist Tangly theme. Modern dev-tool aesthetic (Vercel/Linear/Stripe family). Hairline borders, mono UI labels, restrained grayscale, near-black/white CTAs. UI shell from @tanglydocs/theme-ui.
