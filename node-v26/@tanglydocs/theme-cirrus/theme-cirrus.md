# @tanglydocs/theme-cirrus

> 标签: docs, tangly, theme

## 简介

Cirrus Tangly theme. Dense infrastructure-docs aesthetic (Cloudflare/Fastly family). Compact 13px sidebar, tight leading, hairline rules under headings, orange links with soft underlines, pill CTAs. UI shell from @tanglydocs/theme-ui.
