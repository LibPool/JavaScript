# search-mcp-hub

> 标签: codebuddy, cursor, mcp, mcp-server, model-context-protocol, search, web-search

## 简介

One MCP server, multiple coding-agent search providers (Cursor + CodeBuddy). Pure protocol clients, zero deps, per-call provider routing.
