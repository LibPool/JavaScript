# isa-auth-server

> 标签: auth, bff, express, isa-auth, nextjs, oauth2, passkey, siwe, token-exchange, world-id

## 简介

Backend token exchange & verification adapters for isa-auth, supporting OAuth code exchange, SIWE Web3, World ID proof, Passkey assertion, and multi-framework handlers (Express, Next.js, Fastify)
