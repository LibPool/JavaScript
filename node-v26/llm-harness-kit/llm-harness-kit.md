# llm-harness-kit

> 标签: agent, evals, harness, llm, structured-output, tool-calling

## 简介

A small, provider-agnostic agent harness: tool calling, agent loop, context trimming, structured outputs, timeouts and retries, plus evals for non-deterministic runs. Zero dependencies.
