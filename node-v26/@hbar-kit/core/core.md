# @hbar-kit/core

> 标签: bigint, hashgraph, hbar, hedera, hts, mirror-node, tinybar, typescript

## 简介

Zero-dependency Hedera primitives for TypeScript: network config, bigint money (tinybars & HTS decimals), id/timestamp parsing, errors.
