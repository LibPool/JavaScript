# dsh-plugin-compat-check

> 标签: agent-skills, compatibility, cordis, deepseek, deepseek-harness, dsh, dsh-plugin, health-check, plugin

## 简介

Checks installed DSH plugins against the current DSH version, with source locations, runtime evidence and coverage limits. Includes a compatibility panel and agent tool.
