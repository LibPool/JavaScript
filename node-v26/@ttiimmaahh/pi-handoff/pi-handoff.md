# @ttiimmaahh/pi-handoff

> 标签: coding-agent, compaction, context, handoff, pi, pi-extension, pi-package

## 简介

Proactive context-handoff for the pi coding agent: at a context-usage threshold, auto-write a structured session handoff doc and offer to reload it in a new session.
