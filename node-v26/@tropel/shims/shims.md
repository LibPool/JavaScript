# @tropel/shims

> 标签: k6, load-testing, postman, shims, tropel

## 简介

The tropel JS shim bundle — pm/bru scripting API, chai, lodash, CryptoJS, exec, and the k6 family. The same sources the tropel runtime embeds (ShimBundle::default()), published for embedders.
