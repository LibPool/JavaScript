# @camtomlabs/eslint-plugin-malix

> 标签: design-system, eslint, eslint-plugin, eslintplugin, malix

## 简介

ESLint plugin for the Malix Design System. Enforces usage of canonical <Button>, <Input> components over raw HTML elements.
