# @tengence/search-mcp

> 标签: ai, claude, dataset, full-text-search, mcp, model-context-protocol, saas, search, tengence

## 简介

Tengence Search MCP server: initialize search apps, push data and search via official APIs (thin wrapper, lazy auto-registration). 通智搜索 MCP 服务器：初始化 + 推送 + 搜索（薄封装，启动自动注册）
