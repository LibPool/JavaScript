# @attrichart/core

> 标签: attribution, chart, charts, dataviz, flow, funnel, marketing, multi-touch, sankey, svg, typescript, visualization

## 简介

Overlapping attribution flow charts. A Sankey-style diagram that renders multi-touch membership as visible overlap instead of double-counting or fractional splitting.
