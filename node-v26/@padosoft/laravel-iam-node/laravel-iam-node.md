# @padosoft/laravel-iam-node

> 标签: abac, authorization, fail-closed, iam, jwks, laravel, oauth2, oidc, padosoft, pdp, rbac, rebac

## 简介

Thin, fail-closed TypeScript/Node client for the Laravel IAM control plane (PDP decisions/check + JWKS token verification).
