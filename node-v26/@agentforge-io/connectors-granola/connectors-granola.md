# @agentforge-io/connectors-granola

> 标签: JavaScript

## 简介

Granola connector for AgentForge — list meetings, search notes, fetch transcripts and extract action items from the authorized user's Granola workspace (AI notetaker). Uses the public REST API with a user-pasted API key.
