# @loopmessagesdk/loopmessage-sdk

> 标签: apple, bun, iMessage API, imessage, loopmessage, messaging, sms, typescript, webhook

## 简介

Send real iMessages (blue bubbles) from your backend. Fully-typed TypeScript SDK for the Loop Message cloud API. Covers send, campaigns, webhooks, opt-ins, reactions, and voice. Zero dependencies. Bun + Node.js.
