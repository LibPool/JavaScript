# @c3-oss/slack-mcp-server

> 标签: context, mcp, model, model context protocol, protocol, slack, slack-api

## 简介

Model Context Protocol (MCP) server for Slack Workspaces. Supports Stdio and SSE transports, proxy settings and does not require any permissions or bots being created or approved by Workspace admins.
