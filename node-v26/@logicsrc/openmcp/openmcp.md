# @logicsrc/openmcp

> 标签: catalog, directory, logicsrc, mcp, model-context-protocol, relay, webhooks

## 简介

OpenMCP: an open catalog of MCP relays. A reference catalog server, and a client that speaks REST, MCP and webhooks.
