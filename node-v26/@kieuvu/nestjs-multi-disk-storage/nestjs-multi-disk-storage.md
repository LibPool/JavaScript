# @kieuvu/nestjs-multi-disk-storage

> 标签: azure-blob-storage, file, flystorage, flysystem, fs, google-cloud-storage, in-memory, nest, nestjs, s3, storage, typescript

## 简介

A NestJS module for managing multiple storage disks with support for Local, Amazon S3, Google Cloud Storage, Azure Blob Storage, In-Memory, and custom storage adapters, inspired by Laravel's storage system.
