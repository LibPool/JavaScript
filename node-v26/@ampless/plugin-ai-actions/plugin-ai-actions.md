# @ampless/plugin-ai-actions

> 标签: ai, ampless, ampless-plugin, cms, llm, markdown, plugin

## 简介

AI actions plugin for ampless — injects a View as Markdown link (and optional opt-in Open in Claude / Open in ChatGPT links) after (or before) the post content
