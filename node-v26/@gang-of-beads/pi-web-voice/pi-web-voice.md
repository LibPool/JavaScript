# @gang-of-beads/pi-web-voice

> 标签: dictation, pi-package, pi-web, pi-web-plugin

## 简介

PI WEB plugin for voice dictation: a Dictate button in the composer that turns speech into prompt text through Azure Speech, with the subscription key kept on the machine.
