# @zax360/openapi-cli

> 标签: cli, openapi, zax360, zhianxin, 职安心

## 简介

职安心开放平台命令行：线索推送、企业/岗位 sync、Webhook 监听、已签名 GET/POST（与开放网关验签规则一致）。Node 18+。
