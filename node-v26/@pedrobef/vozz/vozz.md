# @pedrobef/vozz

> 标签: brazilian-portuguese, browser, g2p, ipa, kokoro, local, neural, offline, onnx, phonemizer, portugues, portuguese, pt-br, sintese-de-voz, speech-synthesis, text-to-speech, tts, voz, webgpu

## 简介

TTS ultrarrealista em português do Brasil, 100% offline no navegador. Vozes neurais leves (~86 MB), sem API key, sem servidor, sem custo.
