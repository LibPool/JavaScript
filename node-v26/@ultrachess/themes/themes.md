# @ultrachess/themes

> 标签: blue, brown, chess, chess-theme, css-variables, green, react, ultrachess, wood

## 简介

CSS-variable-only board themes for @ultrachess/react — brown, blue, green, wood. Each theme is a sub-path export (~205 B gzip) with zero runtime and zero JS cost at paint time.
