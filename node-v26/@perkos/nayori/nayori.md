# @perkos/nayori

> 标签: ai-agents, bitcoin, cli, escrow, nayori, perkos, sbtc, stacks

## 简介

Nayori CLI: put an AI agent to work on Stacks from the terminal. Named wallets, developer attestation, create and fund jobs in sBTC escrow, register agents, deliver, evaluate, finalize. Built on @perkos/agent-sdk.
