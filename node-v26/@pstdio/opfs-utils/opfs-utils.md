# @pstdio/opfs-utils

> 标签: diff, glob, grep, ls, opfs, origin-private-file-system, patch, unified-diff, utilities

## 简介

Utilities for the browser's OPFS: ls, grep, safe file read, unified diff patching, and MIME helpers.
