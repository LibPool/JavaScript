# @spikard/wasm

> 标签: async, cloudflare-workers, deno, edge, fetch-api, framework, http, router, typescript, wasm, webassembly

## 简介

Spikard HTTP framework for WebAssembly and edge runtimes with full TypeScript support, targeting browsers, Deno, Cloudflare Workers, and Node.js.
