# @ymys4ever/opencode-throughput-v2

> 标签: benchmark, latency, llm, monitoring, opencode, opencode-plugin, performance, throughput, tps, ttft

## 简介

Real-time LLM performance monitoring plugin for OpenCode V2. Tracks TTFT, TPS, latency, token usage and cost per model with toast notifications and JSONL logging.
