# @lssm/integration.communication-os-runtime

> 标签: JavaScript

## 简介

Governed approve→send→event+audit orchestrator that closes the CommunicationOS hexagon: an approved approval (never the agent) is the only path that resolves a ChannelAdapter, and reconciliation does not redispatch a provider-accepted send while audit/eve
