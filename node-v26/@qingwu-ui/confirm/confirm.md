# @qingwu-ui/confirm

> 标签: accessibility, confirm, dialog, framework-agnostic, modal, morph, qingwu, ui-component, zero-dependency

## 简介

Framework-agnostic confirmation dialog for Qingwu UI — morphs from the trigger control, elastic scale same-origin transition, async confirm with loading state, mutual-exclusion singleton, zero dependencies
