# @qingwu-ui/scroll-fab

> 标签: back-to-top, fab, floating, progress-ring, qingwu, scroll, scroll-to-bottom

## 简介

Framework-agnostic floating scroll fab for Qingwu UI - hold-to-progress ring flips between scroll-to-bottom and back-to-top, rAF eased scrolling with user interrupt, touch first-class
