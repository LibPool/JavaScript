# @sights/admin

> 标签: JavaScript

## 简介

This package privides a set of basic UI module(`setting`、`login`) for `admin` platform applicaton. it can be extends by end-user project. It also can be used as `demo` which demonstrates how to integrate `@sights/layout` framework.
