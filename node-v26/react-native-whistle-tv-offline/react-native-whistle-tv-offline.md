# react-native-whistle-tv-offline

> 标签: 10-foot-ui, amazon-developer-hackathon-2026, android-tv, fire-os, fire-tv, google-tv, offline-stt, react-native, speech-to-text, voice-recognition, whistle-engine, zero-passive-listening

## 简介

Lightweight (~16.9 MB) 100% offline speech-to-text engine for Amazon Fire TV & Android TV with native C++ JNI circular buffering and zero cloud latency.
