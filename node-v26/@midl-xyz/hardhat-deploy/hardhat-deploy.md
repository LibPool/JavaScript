# @midl-xyz/hardhat-deploy

> 标签: JavaScript

## 简介

A hardhat plugin to deploy contract to the MIDL ecosystem. Use this plugin alongside with [hardhat-deploy](https://github.com/wighawag/hardhat-deploy) to get the best experience.
