# @fairseal/verify

> 标签: ai, anchor, audit, ed25519, fairseal, merkle, openrng, provenance, veo, verification, verify

## 简介

Independent verification for FairSeal anchor receipts and VEO-2 objects — structure, integrity, Ed25519 signatures, and on-chain Merkle anchors. ESM + CJS, Node >= 18.
