# @bezysoftware/firebase-ui-shadcn

> 标签: JavaScript

## 简介

The shadcn package exposes React components via the [Shadcn Registy](https://ui.shadcn.com/docs/registry), allowing users to take advantage of Firebase UI for Web logic but bringing their own UI via Shadcn.
