# @karthikrajkumar.kannan/get-things-done

> 标签: agentic, ai, bidirectional, claude, claude-code, code-generation, codex, copilot, cursor, documentation, drift-detection, gemini, llm, reverse-engineering, spec-driven, technical-design, windsurf

## 简介

Bidirectional spec-driven agentic framework — Forward (idea to code to deploy), Backward (code to docs), Sync (drift detection and reconciliation). The first framework that goes both ways.
