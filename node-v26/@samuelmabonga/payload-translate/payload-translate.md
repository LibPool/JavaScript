# @samuelmabonga/payload-translate

> 标签: deepl, google-translate, i18n, localization, payload, payload-plugin, payloadcms, translation

## 简介

Payload CMS plugin that auto-translates localized fields via DeepL or Google Cloud Translate, with an admin 'Translate now' button.
