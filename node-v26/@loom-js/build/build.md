# @loom-js/build

> 标签: build, cli, esbuild, loomjs, prerender, ssg

## 简介

The loom build tool: `loom build` / `loom dev` / `loom prerender` over a declarative `loom.config.ts` — esbuild assembly, one HTML shell per route, and a prerender phase with app hooks.
