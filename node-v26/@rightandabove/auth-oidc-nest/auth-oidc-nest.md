# @rightandabove/auth-oidc-nest

> 标签: JavaScript

## 简介

NestJS module for OIDC **authorization-code** login: IdP redirect, callback, auto-provision into the host’s user store, JWT in an HTTP-only cookie, and `GET /auth-oidc/me` for the SPA.
