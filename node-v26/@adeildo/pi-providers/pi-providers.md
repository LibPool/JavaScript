# @adeildo/pi-providers

> 标签: anthropic, claude, openai-compatible, pi, pi-coding-agent, pi-extension, pi-package, prompt-caching, subscription

## 简介

Provider features for Pi. Bills Anthropic OAuth requests to the Claude Pro or Max plan, keeps several accounts per provider, keeps the prompt cache warm while you are away, and adds OpenAI-compatible endpoints from /login.
