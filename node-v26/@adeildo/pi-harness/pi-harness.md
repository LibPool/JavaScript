# @adeildo/pi-harness

> 标签: anthropic, compaction, permission, pi, pi-coding-agent, pi-extension, pi-package, statusline, theme

## 简介

Every adeildo Pi extension in one install: the permission dialog, the look, the providers, the questions, the skill calls the session tasks and the context pruning. Each is its own extension, so pi config turns one off.
