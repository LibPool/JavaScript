# astro-feedback-board

> 标签: astro, astro-component, cloudflare-workers, feedback, gdpr, withastro

## 简介

Anonymous, moderated feedback for Astro sites: a feedback button, inline question cards and a public board, backed by a Cloudflare Worker.
