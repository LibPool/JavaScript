# @jdickey1/mcp-gmail

> 标签: claude-code, gmail, google-api, mcp, model-context-protocol

## 简介

Read-only Gmail MCP server. Searches and reads messages over the official Gmail API. Designed to be small, auditable, and easy to set up.
