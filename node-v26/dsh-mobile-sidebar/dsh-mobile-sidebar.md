# dsh-mobile-sidebar

> 标签: deepseek-harness, drawer, dsh, dsh-plugin, mobile, responsive, sidebar

## 简介

Give the whole left column back to the conversation on narrow screens: below the 1024px auto-collapse breakpoint the sidebar is removed from the frame entirely (no 56px icon rail), and a header button opens it as an overlay drawer with a tap-anywhere scri
