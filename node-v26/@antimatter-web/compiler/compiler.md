# @antimatter-web/compiler

> 标签: accessibility, accessibility-tree, agent-tools, ai-agents, antimatter, browser-automation, cdp, chrome-devtools-protocol, compiler, llm, mcp, model-context-protocol, playwright, typescript, web-automation

## 简介

Compiles a rendered page's accessibility tree (via Chromium/CDP) into signed, typed Antimatter MCP tool schemas. Deterministic and LLM-free.
