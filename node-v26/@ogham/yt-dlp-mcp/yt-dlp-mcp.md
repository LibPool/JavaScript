# @ogham/yt-dlp-mcp

> 标签: llm, mcp, metadata, model-context-protocol, subtitles, transcript, youtube, yt-dlp

## 简介

MCP server that extracts YouTube (and yt-dlp-supported) transcripts, metadata, comments, chapters, and media — auto-acquires a cooldown-pinned, checksum-verified yt-dlp binary for zero system install.
