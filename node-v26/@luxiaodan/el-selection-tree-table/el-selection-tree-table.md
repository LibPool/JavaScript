# @luxiaodan/el-selection-tree-table

> 标签: JavaScript

## 简介

基于element-ui table组件二次封装的树表格组件，主要解决element-ui中数表格中checkbox无法进行父子组件联动的问题，其中还包含了element-ui中的分页组件，needReverse参数用于配置是否需要在分页过程中保持每一页的选中状态和expand状态
