# @inksnow/c2web

> 标签: claude, claude-code, cloudflared, mobile, node-pty, phone, pty, remote-control, tunnel, websocket

## 简介

Remote-control your local Claude Code session from your phone or browser — node-pty session resume + single-page web + pairing-code auth + free tunnel. 用手机/浏览器遥控本机 Claude Code 会话。
