# @r3pos/ecom-core

> 标签: ecommerce, http, idempotency, pagination, r3, r3pos, sdk, webhooks

## 简介

Isomorphic (browser + Node 20+) HTTP core for the R3 Ecom Platform API: API-key auth, retries, idempotency, typed errors, cursor pagination, and webhook signature verification. Zero runtime dependencies — Web-standard globals only.
