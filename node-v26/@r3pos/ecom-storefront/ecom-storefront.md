# @r3pos/ecom-storefront

> 标签: browser, catalog, checkout, ecommerce, r3, r3pos, sdk, storefront

## 简介

Browser-side SDK for the R3 Ecom Platform API. Used with a PUBLISHABLE key (r3_pk_…) in a customer-facing shop: catalog and inventory reads, order creation, and checkout. Exposes nothing a publishable key cannot do. Built on @r3pos/ecom-core.
