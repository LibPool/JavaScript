# @ludengke95/smart-bookmark-mcp

> 标签: bookmark, chrome-extension, claude-desktop, cursor, mcp, model-context-protocol, windsurf

## 简介

MCP (Model Context Protocol) bridge server for the Smart Bookmark Chrome extension. Exposes your bookmarks/groups/tags to AI clients (Cursor, Claude Desktop, WorkBuddy, Windsurf, CherryStudio, Dify) over Native Messaging, Stdio proxy, and Streamable HTTP.
