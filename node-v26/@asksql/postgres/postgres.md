# @asksql/postgres

> 标签: ai, ask-database, database, database-chat, llm, natural-language, nl2sql, pg, postgres, postgresql, sql, sql-generation, text-to-sql, text2sql

## 简介

PostgreSQL connector for AskSQL. Full schema introspection (tables, views, indexes, triggers, functions, enums, FKs) + read-only session enforcement.
