# @asksql/server

> 标签: ai, anthropic, ask-database, backend, database, database-chat, express, llm, natural-language, nl2sql, ollama, openai, sidecar, sql, sql-generation, sse, text-to-sql, text2sql

## 简介

AskSQL server sidecar: credential-holding HTTP handler with auth hook, server-side SQL guard, audit log. Framework-agnostic + Express/Next adapters.
