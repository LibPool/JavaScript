# valyro-ui

> 标签: accessibility, component-library, components, css-variables, dark-mode, design-system, react, react-17, react-18, react-19, rsc, themes, ui, valyro

## 简介

Free React components for React 17, 18 and 19: buttons, forms, navigation, overlays, tables and basic charts in the Vercel, Liquid Glass and High Contrast themes. Plain CSS, self-hosted fonts, ESM + CommonJS.
