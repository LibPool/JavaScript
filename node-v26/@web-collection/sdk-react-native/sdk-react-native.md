# @web-collection/sdk-react-native

> 标签: apm, monitoring, observability, react-native, web-collection

## 简介

Web Collection React Native SDK：移动端宿主适配层 + 移动端指标采集（冷启动 / 帧率卡顿 / 崩溃 / 前后台会话 / 网络），上报链路 100% 复用 @web-collection/sdk 平台内核。
