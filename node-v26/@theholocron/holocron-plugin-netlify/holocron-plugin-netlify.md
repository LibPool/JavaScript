# @theholocron/holocron-plugin-netlify

> 标签: deployment, holocron, netlify, plugin

## 简介

Holocron plugin for Netlify. Implements the deployment capability against Netlify's REST API, plus exports verifyToken + AUTH_HINT for `holocron auth`.
