# @theholocron/holocron-plugin-axiom

> 标签: axiom, holocron, logs, plugin

## 简介

Holocron plugin for Axiom. Implements the logs capability against Axiom's REST API — dataset provisioning and connectivity checks, plus verifyToken + AUTH_HINT for `holocron auth`.
