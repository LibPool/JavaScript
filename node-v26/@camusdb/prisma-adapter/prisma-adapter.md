# @camusdb/prisma-adapter

> 标签: JavaScript

## 简介

Prisma driver adapter for CamusDB. Runs Prisma Client queries and Prisma Migrate against a CamusDB cluster.

- npm 页面：https://www.npmjs.com/package/@camusdb/prisma-adapter
