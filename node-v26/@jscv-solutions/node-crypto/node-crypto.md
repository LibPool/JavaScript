# @jscv-solutions/node-crypto

> 标签: aes-256-gcm, argon2, bcrypt, crypto, encryption, hmac, nodejs, pbkdf2, scrypt, sha-256, sha-512

## 简介

Ready-to-use cryptography utilities for Node.js: authenticated encryption, digests, HMAC, password hashing, key derivation, secure random generation and constant-time comparison.
