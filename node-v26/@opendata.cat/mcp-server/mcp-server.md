# @opendata.cat/mcp-server

> 标签: catalunya, dades-obertes, mcp, opendata

## 简介

MCP server for querying Catalan public open data — 15 portals + radio archive (radioteca.cat): government, Spanish stats, CORA research, Catalònica heritage (~2.2M items)
