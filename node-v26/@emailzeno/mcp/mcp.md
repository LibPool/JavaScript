# @emailzeno/mcp

> 标签: ai, chatgpt, claude, cursor, email-verification, emailzeno, mcp, model-context-protocol

## 简介

Model Context Protocol server for emailzeno — verify emails, manage jobs, and push to autoresponders from any MCP client (Claude Desktop, Claude Code, Cursor, ChatGPT, OpenCode).
