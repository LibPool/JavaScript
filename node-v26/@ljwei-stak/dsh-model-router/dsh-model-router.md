# @ljwei-stak/dsh-model-router

> 标签: JavaScript

## 简介

Model Router for official DeepSeek Harness Desktop: cost-aware task routing, dependent work packages and official vendor CLI discovery, installation and execution. GAL is available separately as @ljwei-stak/dsh-galgame.
