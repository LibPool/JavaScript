# @adelie/use-wps-office

> 标签: addon, adelie-plugin, docx, mcp, office, penguin-harness, wps

## 简介

Adelie inside WPS Writer: a dependency-free bridge that hosts a WPS add-on panel, lets the Agent read and edit the open document through MCP tools, and registers the add-on with WPS's own local publish service — loopback only.
