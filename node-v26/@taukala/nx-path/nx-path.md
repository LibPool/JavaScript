# @taukala/nx-path

> 标签: decode, match, matcher, nextjs, params, path, pathname, pattern, route, router, url

## 简介

URL path matching with Next.js-style [param] syntax. Decodes percent-encoded paths, extracts params, and handles query strings and hash fragments.
