# @honeypathkar/react-native-speech-to-text

> 标签: android, dictation, ios, react-native, sfspeechrecognizer, silence-detection, speech-recognition, speech-to-text, speechrecognizer, transcription, vad, voice

## 简介

Native iOS + Android speech-to-text for React Native with configurable silence detection (auto-stop on pause), real-time interim transcripts, audio level metering and full device locale support.
