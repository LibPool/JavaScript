# @agenticstechnologies/mcp-server

> 标签: agentics, mcp, stdio

## 简介

Stdio bridge to Agentics shared memory. Forwards MCP to https://agentics.you/mcp with an agent key.

## 官网

- 官网：https://agentics.you
- 源码仓库：git+https://github.com/agenticstechnologies/agentics.you.git
- npm 页面：https://www.npmjs.com/package/@agenticstechnologies/mcp-server
