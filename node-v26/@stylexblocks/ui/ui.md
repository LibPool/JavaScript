# @stylexblocks/ui

> 标签: design-system, react, stylex, tokens

## 简介

StyleX Blocks design system: oklch tokens, semantic tokens, recipes, and themes as uncompiled StyleX source. Compile in your app with @stylexjs/unplugin (externalPackages).
