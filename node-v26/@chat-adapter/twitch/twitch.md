# @chat-adapter/twitch

> 标签: adapter, ai-agent, ai-sdk, bot, chat, chat-sdk, chatbot, eventsub, helix, messaging, twitch, twitch-chat, vercel

## 简介

Twitch adapter for Chat SDK: read and reply in Twitch channel chat with EventSub webhooks and the Helix Chat API, plus whispers
