# @vyana-dev/merchant-sdk

> 标签: agent-commerce, agent-payment-protocol, agent-signup-protocol, app, asp, ed25519, vyana

## 简介

Vyana merchant SDK — verify Agent Signup (ASP) requests and Agent Payment (APP) tokens, sign ACR/AOC + payment/delivery/settlement receipts and quotes, with zero copied crypto.
