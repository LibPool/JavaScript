# @getvitops/emdash

> 标签: JavaScript

## 简介

EmDash CMS native plugin for the Vitops design system — Portable Text block types editors can insert from the admin, rendered with the design-system web components and CSS framework.

- 源码仓库：git+https://github.com/getvitops/design-system.git
