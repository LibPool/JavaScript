# @2kw/responses-transport

> 标签: 2kw, backbone, chat-transport, embeddable-chat, error-normalization, open-responses, openai-compatible

## 简介

Shared chat transport for the Open Responses API — an async-iterable client over POST /v1/responses, plus a normalizer that folds backbone's three error envelopes into one shape.
