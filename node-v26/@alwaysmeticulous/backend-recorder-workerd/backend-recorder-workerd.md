# @alwaysmeticulous/backend-recorder-workerd

> 标签: JavaScript

## 简介

Meticulous backend recorder shim for Cloudflare Workers (workerd). Reports inbound and outbound HTTP capture events to a local Meticulous recorder sidecar during development recording.
