## 简介

Host-side macOS notifications for DeepSeek Harness: ask_user_question / approval / reply-finished, delivered via a vendored signed notifier app — immune to hidden-renderer notification loss. 宿主侧 macOS 系统通知：提问/审批/回复完成，经签名通知 App 投递，免疫渲染进程隐藏丢通知。
