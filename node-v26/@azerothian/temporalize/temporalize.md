# @azerothian/temporalize

> 标签: JavaScript

## 简介

Generate Temporal activities, workflows and per-queue workers from an @azerothian/ormize instance — the durable-execution analogue of @azerothian/gqlize (GraphQL) and @azerothian/nestize (REST)
