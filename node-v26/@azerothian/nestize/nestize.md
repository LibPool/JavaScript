# @azerothian/nestize

> 标签: JavaScript

## 简介

Generate a NestJS REST API + Swagger/OpenAPI from an @azerothian/ormize instance — the REST analogue of @azerothian/gqlize (GraphQL)

## 官网

- 官网：https://github.com/azerothian/gqlize
- 源码仓库：git+https://github.com/Azerothian/gqlize.git
- npm 页面：https://www.npmjs.com/package/@azerothian/nestize
