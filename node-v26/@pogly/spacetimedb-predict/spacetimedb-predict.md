# @pogly/spacetimedb-predict

> 标签: client-side-prediction, multiplayer, optimistic-updates, react, realtime, spacetimedb

## 简介

Optimistic updates / client-side prediction for SpacetimeDB clients: predictions layered over the client cache, rebased on every server change, rolled back when the server says no. React hooks, and a ctx.db shim to run a TS module's own reducer logic as t
