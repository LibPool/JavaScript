# @sapiom/sandbox-preview

> 标签: deploy, preview, sandbox, sapiom, sdk

## 简介

Client-side flow for deploying a web-app preview to a Sapiom sandbox — provision, upload, deploy to a live URL. Shared by the CLI and MCP packages.
