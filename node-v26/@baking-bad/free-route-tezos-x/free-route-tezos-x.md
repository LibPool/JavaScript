# @baking-bad/free-route-tezos-x

> 标签: defi, dex, erc20, etherlink, free-route, marketplace, michelson, nft, objkt, swap, tezos, tezos-x

## 简介

SDK for free-route swaps on Tezos X — turn any ERC20/XTZ swap into ready-to-sign Tezos operations, signed from the Michelson side.
