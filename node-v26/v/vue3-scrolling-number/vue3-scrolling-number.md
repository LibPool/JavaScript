# vue3-scrolling-number

> 标签: TypeScript, number, scroll, vue3, vue3-scroll-number

## 简介

一个仅支持 vue3 的滚动数字组件, 也是少有的任何时候都顺着一个方向滚动的数字组件.组件会自动记住上次的数字(即 from),不需要开发者处理 from 的动态值.
