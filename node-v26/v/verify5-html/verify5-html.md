# verify5-html

> 标签: v5验证, 反爬虫, 拖动验证, 拼图验证, 滑块验证, 行为验证, 防刷验证

## 简介

V5验证公共类库. V5验证是新一代的客户端识别及验证码控件，通过多项智能检测及分析黑科技，识别恶意刷单脚本和机器人(Robot)，帮助企业应用和互联网平台构筑数据安全防线
