# vue3-safe-img

> 标签: blurred-backdrop, broken-image, directive, echo-pillarboxing, fallback, image, placeholder, safe-image, vue, vue3

## 简介

Vue 3 image fallback with optional YouTube-style blurred backdrop. Ships a v-safe-img directive, a <SafeImg> component, and a useSafeImg composable.
