# vue-cli-plugin-bootstrap-breakpoint-indicator

> 标签: bootstrap, breakpoint, debugging, indicator, responsive, vue

## 简介

Vue-cli plugin that displays a small indicator of the current Bootstrap breakpoint (e.g. XS, SM, MD, LG or XL).
