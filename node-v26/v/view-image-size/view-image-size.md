# view-image-size

> 标签: bmp, cur, dimensions, gif, height, icns, ico, image, jpeg, png, psd, resolution, size, svg, webp, width

## 简介

An in-browser module to get dimensions (i.e. width, height, type) of an image file (by using a DataView).
