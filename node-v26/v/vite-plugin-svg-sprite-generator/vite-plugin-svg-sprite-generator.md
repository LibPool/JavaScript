# vite-plugin-svg-sprite-generator

> 标签: sprite-generator, svg, svg-sprite, vite, vite-plugin, zero-dependencies

## 简介

A fast, zero-dependency SVG sprite generator for Vite 5–8+ and Node.js >= 18.5. Supports single/folders modes, watch reloading, and smart attribute inheritance.
