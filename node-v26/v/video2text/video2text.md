# video2text

> 标签: JavaScript

## 简介

本项目实现了本地批量视频（mp4）自动转音频、上传腾讯云COS、调用火山引擎ASR自动转文字并保存为txt的全流程。适用于短视频内容转写、自动听写等场景。
