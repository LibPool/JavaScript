# vue-virtual-bi-table

> 标签: column-virtualization, data-grid, data-table, table, typescript, virtual-scroll, virtualization, vue, vue3

## 简介

A two-axis virtualized data table for Vue 3 — virtualizes both rows and columns to stay smooth across tens of thousands of rows and dozens of columns. Drag-to-reorder, resizable, sticky columns, sorting, selection, and slot-driven cells.
