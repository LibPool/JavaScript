# vite-plugin-html-entry-menifest

> 标签: cdn, html, manifest, vite, vite-plugin

## 简介

自动扫描 Vite 构建产物生成 manifest.json，并将 index.html 中的入口脚本替换为动态加载引导脚本（支持 CDN 托管）
