# vue-smart-state

> 标签: broadcast, composable, composition-api, cookie, cross-tab, debounce, expiry, localStorage, migration, nuxt, persisted-state, persistent, react-usestate, sessionStorage, ssr, standard-schema, state, state-management, storage, ttl, typescript, useState, validation, vue, vue3, zod

## 简介

A type-safe, reactive, persistent and cross-tab synced useState composable for Vue 3 — with TTL, versioned migrations, schema validation, custom storage (cookies included) and SSR safety.
