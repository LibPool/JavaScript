# vivid-mcp

> 标签: ai, claude, image-generation, mcp, model-context-protocol, video-generation, vivid

## 简介

MCP server for VIVID (vividai.tv): generate images, videos, voice and music, edit timelines, record UI walkthroughs, browse your assets and jobs from Claude, Cursor or any MCP client.

## 官网

- 官网：https://vividai.tv
- 源码仓库：git+https://github.com/loopotv/vivid-mcp.git
- npm 页面：https://www.npmjs.com/package/vivid-mcp
