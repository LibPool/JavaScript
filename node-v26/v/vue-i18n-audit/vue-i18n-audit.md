# vue-i18n-audit

> 标签: audit, cli, hardcoded-text, i18n, internationalization, lint, missing-translations, translation, vue, vue-i18n, vuejs

## 简介

CLI tool to audit Vue.js applications for i18n translation completeness. Detects missing translations and hardcoded text.
