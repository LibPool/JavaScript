# vue-chat-kit

> 标签: chat, chat-component, component, im, vue, vue3, websocket

## 简介

一个功能完整的 Vue 3 聊天组件库，支持 WebSocket 实时通信、文件上传、好友管理等功能。独立封装，无需额外 CSS 框架依赖。
