# vsmeta-to-jpeg

> 标签: JavaScript

## 简介

Extract embedded JPEG images from Synology .vsmeta files.

## 官网

- npm 页面：https://www.npmjs.com/package/vsmeta-to-jpeg

- npm registry：https://registry.npmjs.org/vsmeta-to-jpeg
- Node 要求：>=18
