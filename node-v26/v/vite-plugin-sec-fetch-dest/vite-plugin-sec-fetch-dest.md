# vite-plugin-sec-fetch-dest

> 标签: dev-server, nitro, safari, sec-fetch-dest, tanstack-start, vite, vite-plugin

## 简介

Vite plugin that patches missing Sec-Fetch-Dest headers for IP/Safari access. Fixes TanStack Start + Nitro dev server module loading failures.
