# vite-plugin-taro

> 标签: alipay, mini-program, react, taro, tiktok, vite, vite-plugin, vpt, wechat

## 简介

Vite 8 plugin for building one React/Taro codebase for WeChat, Alipay, TikTok, and H5 targets.
