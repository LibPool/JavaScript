# vweatherstation-mcp

> 标签: hurricanes, kalshi, mcp, polymarket, prediction-markets, temperature, weather, x402

## 简介

MCP server for VWeatherStation — settlement-grade weather data for prediction markets (Polymarket/Kalshi): general weather plus temperature, rain, wind, snow, hurricanes and forecast confidence, paid per call via x402 (USDC on Base).
