# vinyl-commonjs-dependencies

> 标签: common-js, gulp, gulpfile, gulpfriendly, require, streams, vinyl, vinyl-adapter

## 简介

A vinyl adaptor for for commonjs dependency trees. Get all files that a script depends on.
