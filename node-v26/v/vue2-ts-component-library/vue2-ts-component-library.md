# vue2-ts-component-library

> 标签: TypeScript, ts, vue2, 组件库

## 简介

vue2 + ts 的常用组件库，不涉及UI框架的（gitee: https://gitee.com/moumumu/vue2-ts-component-library.git），已有的组件有 字体图标、Vconsole、签名、图片预览、高德地图-web服务（PC+移动）等。如有问题，欢迎反馈，我的邮箱：weituanbing@163.com
