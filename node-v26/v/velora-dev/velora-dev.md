# velora-dev

> 标签: JavaScript

## 简介

Local dev sandbox CLI that spins up a database and runs the Velora CMS server against it for plugin authors.

## 官网

- 官网：https://velora-cms.com
- 源码仓库：git+https://github.com/velora-cms/velora-devkit.git
- npm 页面：https://www.npmjs.com/package/velora-dev
