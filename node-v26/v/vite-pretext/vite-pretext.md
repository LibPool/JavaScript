# vite-pretext

> 标签: canvas, cls, line-breaking, performance, pretext, text-layout, text-measurement, typography, vite, vite-plugin

## 简介

A zero-configuration Vite plugin that measures text off the main thread in a Web Worker (via @chenglou/pretext): reserve height to stop layout shift, shrink-wrap to content width, style by wrapped line count, or read measurements with zero forced layout.
