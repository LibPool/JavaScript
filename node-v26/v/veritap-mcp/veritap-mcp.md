# veritap-mcp

> 标签: agent-tools, ai-agents, business-verification, claude, due-diligence, fact-checking, listing-verification, llm-tools, mcp, model-context-protocol, real-world, verification

## 简介

MCP server for checking whether a real-world fact can be verified before an AI agent acts on it — businesses, listings, objects, places. Free to check, no auth.
