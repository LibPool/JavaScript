# vite-zip-upload-plugin

> 标签: JavaScript

## 简介

`vite-zip-upload-plugin` 是一个用于 Vite 项目的插件，能够在构建完成后自动打包构建产物并将其上传到远程服务器进行部署。该插件简化了构建和部署流程，提高了开发效率。
