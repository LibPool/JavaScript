# vite-plugin-iconify-vue-offline

> 标签: JavaScript

## 简介

vue-element-plus-admin 项目的icon采用线上图标, 打包后部署在纯内网环境无法渲染icon, 使用此插件可以在 build 时候将用到的icon动态打包到项目中
