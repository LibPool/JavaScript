# virtual-components

> 标签: JavaScript

## 简介

基于 Vue 3 的虚拟表格组件（JavaScript 实现，附带完整 TypeScript 类型声明），支持排序、列筛选、选择、行列拖拽、调整列宽、自定义单元格和滚动同步。
