# vite-plugin-styletyper

> 标签: css-modules, dts, sass, scss, styletyper, typescript, vite, vite-plugin

## 简介

Vite plugin that writes a per-class TypeScript declaration (.d.ts + .d.ts.map) next to every *.module.{scss,css,sass} on save and build. Native-speed toolchain (Dart Sass via sass-embedded + Lightning CSS). Powered by styletyper.
