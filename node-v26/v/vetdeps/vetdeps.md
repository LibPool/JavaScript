# vetdeps

> 标签: advisory, agent, ai, ai-agent, audit, claude-code, cli, cursor, dependencies, dependency-security, devsecops, hallucinated-package, malicious-package, malware, mcp, npm, npm-audit, osv, preinstall, security, slopsquat, slopsquatting, supply-chain, supply-chain-attack, supply-chain-security, typosquat, typosquatting, vulnerability, zero-dependencies

## 简介

Tells you whether a package you are about to install is the one you think it is. Catches typosquats, AI-hallucinated package names and known malware. Zero dependencies, zero telemetry.
