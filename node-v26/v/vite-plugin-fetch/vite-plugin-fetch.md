# vite-plugin-fetch

> 标签: cors, fetch, plugin, proxy, vite, vue

## 简介

The vite-plugin-fetch plugin addresses CORS (Cross-Origin Resource Sharing) issues encountered when using the Fetch API in JavaScript.
