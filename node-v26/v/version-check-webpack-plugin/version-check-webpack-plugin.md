# version-check-webpack-plugin

> 标签: cache-control, version-checker, version-update

## 简介

A webpack plugin to generate dynamic-version json file and inject version-check function into frontend dist assets. 一个用于给前端代码动态生成版本json文件和注入检测版本脚本的Webpack插件。
