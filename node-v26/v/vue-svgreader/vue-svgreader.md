# vue-svgreader

> 标签: JavaScript

## 简介

这是一个基于VUE的SVG文件阅读器插件，实现自定义水印、自定义尺寸、放大、缩小、滚动、翻页、全屏等功能

- 源码仓库：git+https://github.com/flywin8/vue-svgreader.git
