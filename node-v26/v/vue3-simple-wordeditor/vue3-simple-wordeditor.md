# vue3-simple-wordeditor

> 标签: editor, rich-text, tiptap, vue, vue3, word-editor, wysiwyg

## 简介

基于 Vue 3 + TipTap 3 构建的富文本编辑器组件，支持图片编辑、亮暗主题、样式自定义
