# vanauto-mcp-campers

> 标签: campers, caravan, mcp, mcp-server, model-context-protocol, motorhome, poland, vanauto

## 简介

Read-only MCP server for VanAuto (vanauto.pl): search camper sale and rental listings, view specs and photos, compare prices, explore marketplace accessories.
