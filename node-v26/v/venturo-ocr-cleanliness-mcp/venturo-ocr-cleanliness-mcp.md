# venturo-ocr-cleanliness-mcp

> 标签: kopi-studio, mcp, model-context-protocol, venturo

## 简介

MCP server for the Kopi Studio cleanliness app (Venturo OCR Cleanliness) — wraps the REST API so an assistant can read reports and edit rosters by prompt.
