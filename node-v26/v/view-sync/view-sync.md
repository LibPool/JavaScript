# view-sync

> 标签: alpine, alpine alternative, alpinejs, dom, html5, input sync, sync, view, x-model

## 简介

Lightweight alternative to Alpine.js' `x-model` attribute, that is CSP friendly (no 'unsafe-eval' needed).
