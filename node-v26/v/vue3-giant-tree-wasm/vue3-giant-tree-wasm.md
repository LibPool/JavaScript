# vue3-giant-tree-wasm

> 标签: assemblyscript, large-data, million-nodes, mptt, tree, treeview, virtual-list, virtual-scroll, virtual-tree, vue, vue-component, vue3, vue3-component, wasm, webassembly

## 简介

A WebAssembly-accelerated Vue 3 virtual tree component for 100K–1M nodes: virtual scrolling, fuzzy search, checkbox/radio selection modes, and MPTT-based subtree operations.
