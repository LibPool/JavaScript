# vite-plugin-agent-eyes

> 标签: ai-agent, auth, cookie, debugging, git-hooks, guard, interaction-trace, pre-commit, proxy, self-healing, telemetry, vite, vite-plugin, webhook

## 简介

给 AI agent 的自愈遥测层：结构化运行时日志（API/错误/交互/代理 header）+ 本地 cookie 修复 + 登录态画像 + 提交前风险门禁。Agent-readable runtime telemetry, interaction traces, auth profile hints, and pre-commit guard for Vite dev.
