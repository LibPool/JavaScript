# viralhunt-mcp

> 标签: buzzsumo-alternative, mcp, model-context-protocol, scheduler, social-media, trending, viralhunt

## 简介

MCP server for ViralHunt.io: find trending/viral content across TikTok, Instagram, X, Facebook, Pinterest, Bluesky, Douyin, Reddit, Mastodon, Tumblr, Hacker News and news RSS; learn the best time to post per network from measured viral posts; get top hash
