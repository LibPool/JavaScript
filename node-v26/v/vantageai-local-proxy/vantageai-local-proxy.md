# vantageai-local-proxy

> 标签: ai, anthropic, cost-tracking, llm, openai, privacy, proxy

## 简介

Secure local proxy for LLM cost tracking — keeps API keys and prompts local, sends only anonymized stats to VantageAI dashboard
