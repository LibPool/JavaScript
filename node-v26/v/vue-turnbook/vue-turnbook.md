# vue-turnbook

> 标签: 3d, book, flipbook, page-flip, page-turn, three.js, threejs, turn.js, vue3, 翻页

## 简介

基于 Three.js 的 Vue 3 书本翻页组件：真实纸张卷曲、双页跨页、封面封底开合、折角拖拽、纸叠与页面热区
