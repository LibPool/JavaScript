# vue-timewise

> 标签: component, picker, range, time, time-picker, timepicker, vue, vue3

## 简介

A standalone, dependency-free, themeable time picker for Vue 3. Single & range mode, 12/24h, min/max limits, steps, smart dropdown positioning, keyboard input.
