# vision-support

> 标签: agent-skill, claude-code, codex, fallback, image-recognition, multimodal, pi-agent, vision

## 简介

为非多模态大模型（deepseek、GLM、mimo 等）提供图片识别能力的 Agent Skill。支持多图识别、多模型回退、19+ 平台。
