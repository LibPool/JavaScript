# vite-plugin-open-in-editor

> 标签: cursor, devTools, editor, open-in-editor, plugin, qwik, vite

## 简介

Vite plugin to open files directly in any editor (Cursor, VSCode, etc) from Alt+Click or Qwik dev tools.
