> 标签: avif, image, image-compression, image-optimize, sharp, vite, vite-plugin, vite-plugin-avif, vite-plugin-image-optimize, vite-plugin-webp, webp

## 简介

Vite plugin that generates AVIF and WebP images and optimizes all image assets during the build process for better performance.
