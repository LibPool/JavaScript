# vrv-quill-editor

> 标签: JavaScript

## 简介

``` 富文本编辑器的二次封装，基于 quill-editor 二次封装。 添加了图片上传功能； ``` ## 安装 ```bash npm install vrv-quill-editor ``` ## 使用 ```js import VrvQuillEditor from 'vrv-quill-editor/lib/vrv-quill-editor.umd.js' // axios为可选，需要在全局引入axios vue.use(VrvQuillEditor, { axios }) ```
