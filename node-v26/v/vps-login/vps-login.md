# vps-login

> 标签: cli, devops, passwordless, ssh, ssh-config, ssh-key, vps

## 简介

Guided one-command setup for passwordless SSH login to a VPS. Generates a key, installs it on the remote host, writes/updates an SSH config alias, and verifies the connection. Also supports listing and removing configs it manages.
