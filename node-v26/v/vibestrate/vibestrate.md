# vibestrate

> 标签: agent-orchestration, ai-cto, aider, claude-code, codex, gemini, git-worktree, local-first, model-independence, multi-agent, opencode, orchestrator, shared-flows, supervised-ai

## 简介

Vibestrate (BETA) is the missing piece of vibe-coding: an open-source, supervised coding flow that swaps Claude Code, Codex, Gemini, or local models across shared crews with approval gates and local run logs.
