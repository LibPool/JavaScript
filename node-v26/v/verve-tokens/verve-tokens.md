# verve-tokens

> 标签: css-variables, design-tokens, material-3, material-design, material-you

## 简介

Framework-agnostic Material 3 Expressive design tokens — dynamic color, typography, shape, elevation, motion, and state layers as typed TS constants and generated CSS custom properties.
