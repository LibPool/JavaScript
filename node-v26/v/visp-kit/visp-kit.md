# visp-kit

> 标签: agent, ai, ai-coding, cli, code-quality, code-review, developer-tools, evidence, gates, policy-as-code, spec-driven

## 简介

Stops AI-written code reaching review without proof. Declares scope before editing, blocks out-of-scope changes, and records evidence a human can check.
