# v-auth-image

> 标签: authorization, data-uri, directive, headers, image, src, token, v-auth-image, vue-auth-image

## 简介

Vue directive to load and display secured images by custom headers. 基于 Vue 的权限图片获取查看，提供加载成功或失败回调。
