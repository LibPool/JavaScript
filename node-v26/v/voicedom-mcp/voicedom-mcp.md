# voicedom-mcp

> 标签: ai-agents, annotations, browser-extension, claude, codex, cursor, mcp, model-context-protocol, voicedom

## 简介

MCP companion server for the VoiceDOM browser extension — exposes the DOM annotations and voice notes you capture in the browser to AI coding agents (Claude Code, Cursor, Codex).
