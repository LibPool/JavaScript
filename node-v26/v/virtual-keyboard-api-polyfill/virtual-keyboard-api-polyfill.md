# virtual-keyboard-api-polyfill

> 标签: ios, keyboard-inset, polyfill, ponyfill, safari, virtual-keyboard, virtualkeyboard, visualviewport, wkwebview

## 简介

Polyfill/ponyfill for the VirtualKeyboard API, targeting Safari/iOS, Firefox, and WKWebView. Reports keyboard geometry via the standard API shape, computed from visualViewport.
