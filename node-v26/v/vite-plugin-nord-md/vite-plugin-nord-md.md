# vite-plugin-nord-md

> 标签: JavaScript

## 简介

A Vite plugin that compiles Markdown files into [Nord](https://docs.nordjs.dev) components — with GFM, YAML frontmatter, and custom `:::directive` blocks that render registered components inline.
