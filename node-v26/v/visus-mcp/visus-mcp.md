# visus-mcp

> 标签: anthropic, claude, mcp, pii-redaction, prompt-injection, security, web-fetch

## 简介

Security-first MCP server. Sanitizes web content before it reaches your LLM — strips prompt injection, redacts PII, and reduces token consumption by up to 70%.
