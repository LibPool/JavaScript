# vue-tab-recorder

> 标签: MediaRecorder, ffmpeg.wasm, getDisplayMedia, mp4, screen-recorder, tab-recording, vue, vue3

## 简介

Vue 3 headless 页签录屏 composable：MediaRecorder 录制（页签音频+麦克风混音），Chrome 126+ 原生 MP4 直出，Chrome 84+ 经 ffmpeg.wasm 转码 MP4
