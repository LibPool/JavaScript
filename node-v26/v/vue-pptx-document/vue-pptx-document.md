# vue-pptx-document

> 标签: flexbox, powerpoint, pptx, pptxgenjs, presentation, renderer, slides, vue, vue3, yoga

## 简介

Create PowerPoint files with Vue 3 components: a custom Vue renderer on top of PptxGenJS, with absolute or flexbox (Yoga) layout and a live HTML preview.
