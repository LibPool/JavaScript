# vaco-components-library

> 标签: Boilerplate, V. Alexander, components, material design, react, react-component, redux, toolkit

## 简介

A set of React components implementing Google's Material Design specification with the power of CSS Modules and SASS. Based off the `react-toolbox` repository.
