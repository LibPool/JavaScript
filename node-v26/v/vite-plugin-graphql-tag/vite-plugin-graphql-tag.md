# vite-plugin-graphql-tag

> 标签: JavaScript

## 简介

A Vite plugin that pre-compiles `gql` tagged template literals at build time. This removes the runtime GraphQL parse cost and avoids shipping `graphql-tag` parsing logic to the client. Supports Vite 7 and Vite 8.
