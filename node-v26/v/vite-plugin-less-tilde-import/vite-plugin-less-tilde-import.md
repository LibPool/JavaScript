# vite-plugin-less-tilde-import

> 标签: JavaScript

## 简介

Add support for import less or css file in node_modules using ~ symbol in less file. for instance, `@import '~packages_from_node_modules';`. This kind of syntax originally supported by webpack. Therefore, some third-party component libraries use this way
