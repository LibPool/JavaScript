# vibeshare

> 标签: cli, ephemeral, expiring, firebase, hosting, html, preview, share, static-site, vibe-coding

## 简介

Deploy a local HTML file or folder to a public, auto-expiring URL via Firebase Hosting preview channels. Bring your own free Firebase — no central server.
