# vue-fullscreen-container

> 标签: JavaScript

## 简介

全屏容器会初始化容器默认高宽以及缩放比，当容器尺寸或者浏览器窗口大小发生改变的时候会自动计算缩放比，从而保证容器中的内容不会变形
