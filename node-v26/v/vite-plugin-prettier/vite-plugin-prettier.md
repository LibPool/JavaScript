# vite-plugin-prettier

> 标签: JavaScript

## 简介

在开发项目中经常使用prettier,但是prettier的配置颇为麻烦，如果在vscode中使用需要先 - 安装vscode插件 - 配置prettierrc.js文件 - 项目package.json中写入依赖 - 还要切换编辑器的默认格式化插件，设置保存自动格式化 - 这些东西表面上看是呈离散状态的，给新手使用造成很大的困惑，如果我们把prettier集成在vite插件中会不会更简单一些呢 #### 安装
