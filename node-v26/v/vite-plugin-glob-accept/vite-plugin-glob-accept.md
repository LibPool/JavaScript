# vite-plugin-glob-accept

> 标签: hmr, hot module replacement, hot reload, vite, vite-plugin

## 简介

```ts import.meta.hot.accept([   './a.js',   './b.js',   './c.js',   './d.js',   './e.js',   './f.js' ], dosomething) // replace with import.meta.hot.accept(['./*.js'], dosomething) ```
