# vite-plugin-codegen

> 标签: codegen, module, plugin, virtual, vite

## 简介

A plugin for Vite (v4 and higher) to generate useful modules at bundle-time.

- 源码仓库：git+https://github.com/FlorianRappl/codegen-js.git
