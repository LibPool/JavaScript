# vitest-environment-prisma-tx

> 标签: prisma, prisma orm, test, test isolation, testing, transaction, vitest

## 简介

Vitest environment for Prisma designed for fast integration tests: seed your database once with production-like data, then run each test in a transaction that is rolled back after execution. Tests remain isolated without expensive reseeding.
