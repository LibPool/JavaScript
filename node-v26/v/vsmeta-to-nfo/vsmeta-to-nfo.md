# vsmeta-to-nfo

> 标签: JavaScript

## 简介

Convert Synology .vsmeta files to Kodi/Jellyfin compatible NFO files.

## 官网

- npm 页面：https://www.npmjs.com/package/vsmeta-to-nfo

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install vsmeta-to-nfo`
- npm registry：https://registry.npmjs.org/vsmeta-to-nfo
- Node 要求：>=18
