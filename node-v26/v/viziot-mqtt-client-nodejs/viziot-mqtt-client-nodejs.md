# viziot-mqtt-client-nodejs

> 标签: iot, mqtt, mqtt-client, typescript, viziot

## 简介

Promise-based MQTT client for the VizIoT.com IoT platform, written in TypeScript with first-class support for both TypeScript and JavaScript (CommonJS/ESM) projects.
