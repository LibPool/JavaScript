# vite-plugin-build-pack

> 标签: build, clean-output, glob, pack, vite, vite-plugin, zip

## 简介

Vite plugin: clean output by glob, zip build dir (name-version.zip), auto-increment version in build.config.json

## 官网

- npm 页面：https://www.npmjs.com/package/vite-plugin-build-pack

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install vite-plugin-build-pack`
- npm registry：https://registry.npmjs.org/vite-plugin-build-pack
- Node 要求：>=16.0.0
