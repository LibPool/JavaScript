## 简介

SDK oficial de JavaScript/TypeScript de Invoka: API de facturación electrónica del SRI de Ecuador para programadores (facturas, notas de crédito y débito, guías de remisión, retenciones 2.0 y 1.0, liquidaciones de compra, consultas al SRI, créditos, empre
