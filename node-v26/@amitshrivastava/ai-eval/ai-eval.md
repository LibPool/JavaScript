# @amitshrivastava/ai-eval

> 标签: ai, anthropic, eval, evaluation, llm, openai, openrouter, prompt, regression, testing

## 简介

Open-source LLM eval harness. Run prompts against test cases with contains/regex/llm-judge assertions, get a JSON report, catch regressions in CI.
