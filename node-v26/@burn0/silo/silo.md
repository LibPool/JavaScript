# @burn0/silo

> 标签: agent-evaluation, agents, ai, benchmark, cli, environment, evals, local-first, reinforcement-learning, sandbox, simulation, tool-use, typescript

## 简介

Local-first framework for simulating environments and evaluating AI agents against them, with tools, tasks, and verifiers defined as TypeScript in your own repo.
