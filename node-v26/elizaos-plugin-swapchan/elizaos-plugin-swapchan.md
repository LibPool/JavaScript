# elizaos-plugin-swapchan

> 标签: aggregator, bridge, cross-chain, defi, dex, elizaos, elizaos-plugin, evm, plugin, solana, swap

## 简介

elizaOS plugin: best-price same-chain and cross-chain swap quotes and unsigned transactions via SwapChan (Jupiter, 0x, CoW, LI.FI, Relay, KyberSwap, Velora, Across, deBridge, THORChain). No API key.
