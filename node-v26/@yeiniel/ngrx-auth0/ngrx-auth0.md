# @yeiniel/ngrx-auth0

> 标签: JavaScript

## 简介

NgrxAuth0 is an [Angular](https://angular.io) module that provides  authentication using [Auth0](https://auth0.com) and implements its interface in  the form of an NgRx store feature.
