# dsh-sync-webdav

> 标签: backup, deepseek-harness, dsh, dsh-plugin, sync, webdav

## 简介

DSH WebDAV 配置同步插件：把 ~/.dsh 与应用级设置加密备份到 WebDAV，支持 Windows/Linux/macOS 跨平台互相恢复（profile 自动重映射）
