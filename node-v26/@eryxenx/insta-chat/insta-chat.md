# @eryxenx/insta-chat

> 标签: api, bot, chat, direct, dm, eryxenx, insta, insta-chat, instagram, messenger, unofficial

## 简介

Unofficial Instagram Chat API for Node.js | Build Instagram DM bots on personal accounts — send messages, media, voice notes, reactions, edit & unsend, listen for incoming chats. No browser at runtime
