# @elysia-ai/kernel

> 标签: JavaScript

## 简介

Elysia A.I. 通用子框架内核：类型化事件总线、阶段化管线编排（DAG+优先级）、请求级上下文、生命周期相位、插件 manifest 兼容治理、trace 与测试 harness。零依赖、宿主无关，可独立于 AI 领域被任何 Koishi/cordis 应用复用。
