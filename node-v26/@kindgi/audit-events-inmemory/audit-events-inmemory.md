# @kindgi/audit-events-inmemory

> 标签: JavaScript

## 简介

Reference in-memory `AuditEventBinding` adapter for dev + tests. Implements the full `@kindgi/audit-events` contract (idempotent append, cursor-paginated query, per-kind purge) and pins down the cursor shape and ordering durable adapters match, so consume
