# @yeyuan98/mem0-mcp

> 标签: agent, ai, claude, cursor, long-term-memory, mcp, mem0, memory, model-context-protocol, opencode, self-hosted

## 简介

MCP (Model Context Protocol) server that fronts a self-hosted Mem0 REST API. Stdio transport, 10 memory tools, single source of truth = your pgvector store.
