# uptime-kuma-mcp

> 标签: mcp, monitoring, self-hosted, uptime, uptime-kuma

## 简介

Query your Uptime Kuma instance (self-hosted; set UPTIME_KUMA_URL; optional UPTIME_KUMA_TOKEN): public status, Prometheus metrics. Endpoints per official docs.
