# @steady-thread/acey-mcp

> 标签: claude, coaching, fitness, mcp, model-context-protocol, sms, steady-thread

## 简介

MCP server + guided installer for the Steady Thread coach agent surface. Lets a coach drive Steady Thread (clients, scheduled messages, weekly focus, memory, AI generation) from their own Claude Code / Codex via a scoped Personal Access Token.
