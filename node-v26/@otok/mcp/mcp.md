# @otok/mcp

> 标签: ai, campaigns, email-marketing, mcp, model-context-protocol, newsletters, otok

## 简介

Official MCP (Model Context Protocol) server for the oToK marketing platform — exposes the public /v1 API to AI assistants, starting with the email-marketing surface (email campaigns + smart newsletters).
