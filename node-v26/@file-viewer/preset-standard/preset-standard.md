# @file-viewer/preset-standard

> 标签: document-preview, file-viewer, on-demand-renderer, renderer-preset, self-hosted, standard-profile

## 简介

Stable common-format File Viewer preset with modern Office, PDF/OFD, text, image, media, archive, and email support without specialist or legacy-heavy capabilities.
