# @shell-finance/sdk

> 标签: confidential-orders, dark-pool, deepbook, nautilus, seal, shell-finance, sui

## 简介

Client SDK for Shell Finance — a confidential dark pool on Sui. Seal-encrypted order envelopes + PTB builders. Nitro enclave matching, atomic peer-to-peer settlement, multi-source price discovery (DeepBook, Pyth, fixed NAV).
