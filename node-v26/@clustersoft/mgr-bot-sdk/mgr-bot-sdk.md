# @clustersoft/mgr-bot-sdk

> 标签: bot, bot-api, bot-framework, chatbot, clustersoft, mgr, sdk

## 简介

Official bot framework for ClusterSoft Messenger (MGR) — a typed, zero-dependency SDK with long-polling and webhook transports, middleware, and inline keyboards.
