# @kubohiroya/turbowarp-named-functions

> 标签: extension, functions, json-schema, scratch, tools, turbowarp, typescript, vite

## 简介

Named, JSON-in/JSON-out functions for TurboWarp that can be called by name, synchronously or asynchronously, and exported as tools.
