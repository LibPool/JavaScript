# @dunlin/feedback

> 标签: annotation, bug-reporting, dunlin, feedback, react, react-component, screenshot, user-feedback, visual-feedback, widget

## 简介

React feedback widget wrapper for Dunlin Feedback. Drop-in component for collecting visual feedback with screenshots, element annotations, and inline comments.
