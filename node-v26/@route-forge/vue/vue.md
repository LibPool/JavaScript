# @route-forge/vue

> 标签: JavaScript

## 简介

Route Forge 的 Vue 3 集成：插件 + composable（useForge/useForgeApi/useForgeRoute）+ 组件（ForgeRoute/ForgeLink）/ Vue 3 integration for Laravel named routes: plugin + composables (useForge / useForgeApi / useForgeRoute) + components (ForgeRoute / ForgeLink)
