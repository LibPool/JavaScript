# @gabrielangelo/arduino-sd-manager

> 标签: arduino, file-system, iot, johnny-five, microsd, sd-card, sd-manager, serialport

## 简介

Simple and robust Node.js interface to manage MicroSD cards connected to Arduino via serial port. Designed as a lightweight alternative when working with Johnny-Five or pure SerialPort.
