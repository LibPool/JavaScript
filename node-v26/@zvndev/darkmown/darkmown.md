# @zvndev/darkmown

> 标签: framework, markdown, reactive, static-site, wd, whateverdown, zero-js

## 简介

Darkmown — the markdown framework. Plain .md stays plain; rename to .wd for loops, state, includes, and tiny reactive islands. Zero JS on static pages.
