# @tbook/local-client

> 标签: JavaScript

## 简介

Interactive coding environment that runs inside browser. Can be run using **npx tbook serve** and then accessing http://localhost:4005 in browser.

- npm 页面：https://www.npmjs.com/package/@tbook/local-client
