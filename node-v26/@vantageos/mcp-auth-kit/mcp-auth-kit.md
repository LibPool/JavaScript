# @vantageos/mcp-auth-kit

> 标签: clerk, jwt, mcp, oauth, oauth2.1, resource-server, vantagepeers

## 简介

MCP OAuth 2.1 resource-server facade — 401 challenge, RFC 9728 Protected Resource Metadata, RFC 8414 Authorization-Server discovery, RS256 JWKS verification, audience/issuer binding. Reuses @vantageos/cloud-identity unchanged for tenant/scope resolution d
