# @vantageos/mcp-doctor

> 标签: audit, conformance, linter, mcp, model-context-protocol, static-analysis

## 简介

Static MCP conformance checker: audits an MCP server source tree against the MCP 2026-07-28 standard and emits a conformance-diff table (file:line | present | absent | non-conforming | verdict).
