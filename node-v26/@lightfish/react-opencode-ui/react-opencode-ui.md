# @lightfish/react-opencode-ui

> 标签: agents, ai, assistant-ui, chat, opencode, react, ui

## 简介

OpenCode chat UI kit for React, built on assistant-ui. Runtime hooks + pre-compiled Tailwind styles, works with or without Tailwind in the host app.
