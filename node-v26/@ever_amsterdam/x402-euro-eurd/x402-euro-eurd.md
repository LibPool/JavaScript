# @ever_amsterdam/x402-euro-eurd

> 标签: ai-agents, ethereum, eurd, eurq, mica, payments, polygon, quantoz, stablecoin, usdq, x402

## 简介

Fetch wrapper that automatically pays x402 challenges using Quantoz EURO (off-chain), EURD on Algorand, and EURQ/USDQ on Ethereum/Polygon (EIP-2612 permit)
