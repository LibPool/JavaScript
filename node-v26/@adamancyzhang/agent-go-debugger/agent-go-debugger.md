# @adamancyzhang/agent-go-debugger

> 标签: agent, breakpoint, cli, debugger, delve, dlv, go, golang, remote-debugging

## 简介

Remote debugging CLI for Go targets via Delve headless — breakpoints, stepping, goroutines, stack/locals/eval for AI agents. Self-contained binaries per platform; no Go toolchain needed.
