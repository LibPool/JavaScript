# @wepy-act/cli

> 标签: JavaScript

## 简介

适用于需要快速开发的活动类型小程序，在原wepy基础上调整修改编译流程，支持js压缩、图片压缩、雪碧图自动合成、css本地图片转base64等，并提供创建新活动项目、一键封版、一键清空等命令。
