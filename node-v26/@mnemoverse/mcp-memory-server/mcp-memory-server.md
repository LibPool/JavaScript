# @mnemoverse/mcp-memory-server

> 标签: agent-memory, ai, ai-agent, chatgpt, claude, claude-code, cross-tool, cursor, hosted-memory, long-term-memory, mcp, mcp-server, memory, memory-rooms, mnemoverse, model-context-protocol, persistent-memory, shared-memory, vendor-neutral, vscode

## 简介

Hosted AI agent memory over MCP that learns from outcomes — feedback re-ranks recall — with shared rooms for multi-agent work; one key or OAuth across Claude Code, Cursor, VS Code & ChatGPT, no infra to run
