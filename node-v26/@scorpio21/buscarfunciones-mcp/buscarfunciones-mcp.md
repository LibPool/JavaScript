# @scorpio21/buscarfunciones-mcp

> 标签: classes, code analysis, codebase, functions, llm, mcp, modelcontextprotocol, resources, tools

## 简介

Una implementación en TypeScript del Model Context Protocol (MCP) para análisis de código. Este servidor permite que los LLMs interactúen con bases de código.
