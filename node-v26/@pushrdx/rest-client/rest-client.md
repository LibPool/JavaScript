# @pushrdx/rest-client

> 标签: jsx, rest, rxjs, ts, typescript

## 简介

REST Client using RxJS Observables. Idea is from https://github.com/troyanskiy/ngx-resource. Some classes are from angular2 http module. The aim was to create an independent library, which can be used in non-angular projects.
