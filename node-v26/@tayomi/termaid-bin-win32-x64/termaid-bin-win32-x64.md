# @tayomi/termaid-bin-win32-x64

> 标签: JavaScript

## 简介

Unofficial prebuilt termaid binary (win32-x64). termaid is by Fabio Souto (https://github.com/fasouto/termaid); this package only redistributes a compiled binary.

- npm 页面：https://www.npmjs.com/package/@tayomi/termaid-bin-win32-x64
