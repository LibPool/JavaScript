# @tayomi/termaid-bin

> 标签: binary, diagram, mermaid, prebuilt, termaid, terminal

## 简介

Unofficial prebuilt binaries of termaid (Mermaid diagrams as Unicode art in the terminal). termaid is by Fabio Souto; this package only redistributes compiled binaries.
