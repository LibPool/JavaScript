# @myceliumhq/sig

> 标签: agent, cli, mcp, messaging, signal, signal-cli

## 简介

Agent-facing CLI for Signal messenger (built on signal-cli). Also ships a standalone MCP server and an ingestion daemon for shell-less hosts.
