# @adaskothebeast/hierarchical-convert-to-temporal

> 标签: converter, date, duration, iso8601, json, temporal, typescript

## 简介

Deep, in-place conversion of ISO 8601 strings in JSON payloads into Temporal values, plus a Temporal backend for the Typewriter runtime.
