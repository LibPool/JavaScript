# @beezping/integration-issues

> 标签: beezping, feedback, github, gitlab, integration, issues, typescript

## 简介

Issue tracker integration for Beezping — one issue per feedback on GitHub, GitLab or your own tracker, kept in sync through @beezping/server lifecycle hooks
