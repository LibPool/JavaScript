# cron-llm

> 标签: agent, cron, litellm, llm, mcp, structured-output

## 简介

Runtime for scheduled LLM jobs: structured calls through an OpenAI-compatible gateway, a bounded tool loop, MCP servers as child processes, and Discord delivery
