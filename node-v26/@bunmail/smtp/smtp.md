# @bunmail/smtp

> 标签: bun, deliverability, dkim, email, mail, mx, smtp, starttls

## 简介

Direct-to-MX SMTP client for Bun. First-class TLS observability + cert-validation reporting + DKIM signing. Zero npm dependencies.
