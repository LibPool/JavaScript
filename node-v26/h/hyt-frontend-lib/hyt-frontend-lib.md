# hyt-frontend-lib

> 标签: JavaScript

## 简介

Vue 3 数学编辑与预览组件。包名是 `hyt-frontend-lib`，导出 `HytMathEditor`、`HytMathRender` 和 `HytMathSimpleRender`。
