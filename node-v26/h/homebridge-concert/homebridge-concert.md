# homebridge-concert

> 标签: audiocontrol, avr, concert, concert-xr, homebridge-plugin, homekit, supports-hap, xr-8s

## 简介

Homebridge plugin for AudioControl Concert XR receivers — power/standby, volume-preset, and source-preset HomeKit switches over LAN IP control
