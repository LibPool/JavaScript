# heyihub-api-mcp

> 标签: bilibili, douyin, heyi, kuaishou, mcp, model-context-protocol, paid-api, social-media-api, xhs, xiaohongshu

## 简介

MCP server for the Heyi paid social data APIs (Xiaohongshu, Douyin, Bilibili, Kuaishou). One-call install via `npx -y heyihub-api-mcp`; ships with 69 tools that proxy the `/api/external/` paid endpoints with Bearer API Key billing.
