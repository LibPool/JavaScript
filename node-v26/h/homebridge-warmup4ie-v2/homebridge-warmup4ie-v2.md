# homebridge-warmup4ie-v2

> 标签: homebridge-plugin, homebridge-warmup4ie, homekit, myheating, supports-hap, thermostat, underfloor-heating, warmup, warmup-6ie, warmup-7ie, warmup-element, warmup-terra, warmup4ie

## 简介

Homebridge plugin for Warmup Wi-Fi underfloor-heating thermostats (4iE, 6iE, 7iE, Element, Terra). Maintained fork of homebridge-warmup4ie with fixes for Homebridge 2.0 and the broken Off control in 0.1.0–0.1.1.
