# hls-engine

> 标签: abr, adaptive-bitrate, hls, http-live-streaming, m3u8, media-source-extensions, mp4, mpeg-ts, mse, player, streaming, transmuxer, video

## 简介

Full HLS playback engine built from scratch — M3U8 parsing, MPEG-TS transmuxing, ABR, and MSE pipeline. Zero runtime dependencies.
