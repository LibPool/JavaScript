# handlebars-i18n-cli

> 标签: cli helper, deepL automatic translation, extract translations from i18next templates, handlebars translation, handlebars-i18n, i18next JSON

## 简介

Extract translation keys from handlebars templates and form JSON from it, generate automatic translations via DeepL
