# hooktunnel

> 标签: ngrok, proxy, tunneling, webhook

## 简介

A simple CLI tool for proxying Git provider webhooks (GitHub, GitLab, Bitbucket) in internal or intranet environments. Automatically forwards webhook messages using ngrok, enabling seamless development and testing.
