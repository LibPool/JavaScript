# homebridge-mynest

> 标签: homebridge-plugin, homekit, nest, nest-eco, nest-protect, nest-thermostat, smoke-detector, temperature-sensor, thermostat

## 简介

Homebridge plugin for Nest thermostats (with Eco Mode), Nest Protect, and Nest Temperature Sensors using a Nest Account access token
