# homebridge-http-advanced-platform

> 标签: accessory, advanced, api, cache, homebridge, homebridge-http-advanced-accessory, homebridge-plugin, homekit, http, https, json, jsonpath, platform, polling, rest, sensor, supports-hap, switch, xml, xpath

## 简介

Connect HTTP/HTTPS devices and REST APIs to HomeKit with JSON/XML mapping, polling and shared cached reads. A platform conversion of staromeste's homebridge-http-advanced-accessory with support for existing accessory configurations.
