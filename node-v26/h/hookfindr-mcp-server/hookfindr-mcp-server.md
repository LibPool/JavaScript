# hookfindr-mcp-server

> 标签: anthropic, captions, claude, hookfindr, mcp, model-context-protocol, srt, subtitles, tiktok, transcribe, video, youtube

## 简介

MCP server for HookFindr — transcribe, get metadata, export SRT, and analyze hooks for any short-form video URL (TikTok, YouTube, Instagram Reels, X, Twitch) from inside Claude Desktop, Cursor, or any MCP-compatible client.
