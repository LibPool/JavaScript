# htmx-ui-plugin-versions

> 标签: archive, docs, htmx, htmx-ui, htmx-ui-plugin, versioning, versions

## 简介

Versioned docs for htmx-ui-engine sites: frozen snapshots of older releases served under /docs/v<id>, a version switcher, an old-version banner and CLI commands to name and archive versions.
