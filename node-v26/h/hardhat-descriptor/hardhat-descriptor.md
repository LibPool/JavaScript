# hardhat-descriptor

> 标签: anthropic, claude, clear-signing, erc-7730, ethereum, hardhat, hardhat-plugin

## 简介

Hardhat 3 plugin that uses Claude to generate ERC-7730 clear-signing descriptors from your compiled contracts.
