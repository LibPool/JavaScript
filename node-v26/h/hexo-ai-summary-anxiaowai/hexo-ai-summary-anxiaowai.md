# hexo-ai-summary-anxiaowai

> 标签: ai, blog, chatgpt, hexo, hexo-plugin, markdown, openai, summary

## 简介

这是一个 Hexo 插件，用于自动生成文章的摘要。支持腾讯混元、OpenAI 或任何兼容 OpenAI 协议的模型接口，支持并发处理、自定义摘要字段、摘要覆盖控制等功能。 ## 功能特点
