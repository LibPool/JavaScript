# hetzner-mcp

> 标签: ai-agent, claude, dedicated-server, hcloud, hetzner, hetzner-cloud, iac, infrastructure, mcp, model-context-protocol, provisioning, robot, storage-box

## 简介

Model Context Protocol server for the full Hetzner platform. Cloud (servers, networks, volumes, firewalls, load balancers, IPs, DNS), Storage Box, and Robot dedicated servers. Spin up and manage every part of Hetzner from any MCP client.
