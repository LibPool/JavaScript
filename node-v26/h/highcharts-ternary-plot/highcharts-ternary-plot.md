# highcharts-ternary-plot

> 标签: barycentric, black-label, chart, composition-chart, data-visualization, highcharts, highcharts-addon, highcharts-plugin, highmaps, highstock, ternary, ternary-chart, ternary-plot, triangle-diagram, triangular-chart, visualization

## 简介

Ternary / triangular plot plugin for Highcharts. Visualize three-component composition data with barycentric diagrams. TypeScript support included.
