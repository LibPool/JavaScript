# hybrid-crypto-express

> 标签: AES-GCM, RSA, decryption, encryption, express, hybrid, microservice, redis, security

## 简介

Hybrid encryption for Express: RSA-OAEP key exchange and AES-256-GCM payloads. Redis-backed session store required (no in-memory AES sessions). Middleware for decryptRequest, encryptResponse, and crypto routes.
