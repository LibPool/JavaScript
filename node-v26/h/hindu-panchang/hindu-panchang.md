# hindu-panchang

> 标签: calender, hindu, vedic

## 简介

यह NPM पुस्तकालय तिथि (चंद्र चरण), नक्षत्र, करण, योग, राशि (राशि चक्र चिह्न) और अयनांश की गणना करता है। यह मास (हिंदू माह) और ऋतु (मौसम) की भविष्यवाणी भी कर सकता है। This NPM library calculates Tithi (Moon phase), Nakshatra, Karna, Yoga, Raasi (Zodiac Sig
