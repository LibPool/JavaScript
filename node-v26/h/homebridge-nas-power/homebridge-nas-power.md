# homebridge-nas-power

> 标签: homebridge, homebridge-plugin, macos, nas, nas-power, ssh, wake-on-lan, wol

## 简介

Homebridge plugin to control NAS or Mac power via Wake-on-LAN and SSH shutdown. Works with any Linux-based NAS or macOS machine. Includes SSH host key verification.
