# household-sim

> 标签: alexa, harness, mcp, model-context-protocol, streamable-http, testing, voice

## 简介

Test a voice add-on's MCP server the way a household uses it: several people with their own credentials, a model choosing the tools, devices sending events, and pass/fail checks you can run in CI.
