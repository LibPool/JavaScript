# halias

> 标签: alias, bash, cli, dotfiles, fzf, productivity, shell, shortcut, zsh

## 简介

Hyper alias — manage shell aliases and functions with an interactive CLI. Search, edit, track usage, and back up — all without touching .zshrc.
