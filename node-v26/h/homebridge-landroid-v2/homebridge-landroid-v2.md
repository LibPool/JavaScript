# homebridge-landroid-v2

> 标签: ferrex, homebridge-plugin, kress, landroid, landxcape, lawn-mower, mower, robot-mower, supports-hap, worx

## 简介

Homebridge plugin for Worx Landroid (and Kress, Ferrex, Landxcape) robotic lawn mowers. Maintained v2 fork with the Worx cloud API fixes.
