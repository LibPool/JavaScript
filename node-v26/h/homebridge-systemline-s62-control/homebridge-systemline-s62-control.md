# homebridge-systemline-s62-control

> 标签: audio, globalcache, homebridge-plugin, input, ip2sl, itach, multi-room, multiroom, rs232, s6.2, source, systemline, volume

## 简介

Homebridge plugin for the Systemline S6.2 multi-room audio system. Each zone appears as a TV accessory with source selection and volume control via a Global Cache iTach IP2SL RS232 interface.
