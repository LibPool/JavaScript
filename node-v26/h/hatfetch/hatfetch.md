# hatfetch

> 标签: agent, ai, anti-bot, claude, cloudflare, crawler, cursor, markdown, mcp, model-context-protocol, proxy, residential-proxy, scraper, web-scraping

## 简介

Give any LLM agent the power to read any website — even the ones that block bots. An MCP server that returns clean Markdown and handles blocks automatically via residential proxies.
