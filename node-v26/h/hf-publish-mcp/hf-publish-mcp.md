# hf-publish-mcp

> 标签: ai, fine-tuning, huggingface, llm, mcp, model-card, model-upload

## 简介

MCP server for the fine-tuner's publish workflow on Hugging Face Hub — upload models with resumable retry, inspect repos, and maintain model cards. GGUF quantization is included but experimental.
