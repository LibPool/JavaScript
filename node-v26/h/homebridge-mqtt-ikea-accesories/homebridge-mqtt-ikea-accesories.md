# homebridge-mqtt-ikea-accesories

> 标签: homebridge-plugin

## 简介

Integration of  [zigbee2mqtt](https://github.com/Koenkk/zigbee2mqtt.io) and homebridge for Ikea lightbulbs. Currently only Ikea TRADFRI LED1545G12 is supported. Other models might work but with no guarantee.
