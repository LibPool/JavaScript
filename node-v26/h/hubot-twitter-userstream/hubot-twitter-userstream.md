# hubot-twitter-userstream

> 标签: JavaScript

## 简介

hubot-twitter-userstream is an adapter for Hubot that allows you to use the hubot with Twitter on user TL.

## 官网

- 源码仓库：git@github.com:hoo89/hubot-twitter-userstream.git
- npm 页面：https://www.npmjs.com/package/hubot-twitter-userstream
