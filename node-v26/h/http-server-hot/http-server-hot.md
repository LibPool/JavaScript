# http-server-hot

> 标签: http、http-server、热更新、热编译、nginx

## 简介

http-server-hot用来对传统项目（jquery官网类，非单页面应用）开启一个http服务并实现当前目录下的资源（html、css、js）热更新；可以快速配置api代理，解决跨域带来的烦恼
