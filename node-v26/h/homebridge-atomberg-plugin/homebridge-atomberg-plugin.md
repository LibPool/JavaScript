# homebridge-atomberg-plugin

> 标签: aris, atomberg, fan, homebridge, homebridge-atomberg, homebridge-atomberg-plugin, homebridge-plugin, homekit, lan-control, renesa, smart fan, smart light, studio

## 简介

Homebridge plugin for Atomberg smart fans and lights — LAN-first UDP control, full LED triad (on/brightness/colour temp), single-tile Home app UI, command throttling, and Home Assistant coexistence.
