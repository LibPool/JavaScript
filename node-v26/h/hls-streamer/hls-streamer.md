# hls-streamer

> 标签: aac, audio, audio-streaming, ffmpeg-free, flac, hls, http-live-streaming, m4a, m4v, media, mov, mp3, mp4, nodejs, ogg, on-demand, streaming, typescript, video, video-streaming, vorbis, wav

## 简介

Lightweight HLS streaming from media files (MP3, AAC, M4A, OGG, FLAC, WAV, MP4, MOV, M4V) on demand, without temporary files or ffmpeg dependency
