# homebridge-netatmo-weather

> 标签: homebridge-plugin, netatmo, weather

## 简介

Homebridge plugin that exposes Netatmo Weather Station modules (indoor/outdoor temp, humidity, CO₂) plus a blind_lux recommendation sensor, all via cloud — no device-LAN reachability required
