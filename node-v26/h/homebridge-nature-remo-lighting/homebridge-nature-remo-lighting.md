# homebridge-nature-remo-lighting

> 标签: dimming, homebridge, homebridge-plugin, homekit, light, nature-remo

## 简介

Homebridge plugin for Nature Remo light devices with simple 3-level brightness control (off / low / full) and minimal API requests.
