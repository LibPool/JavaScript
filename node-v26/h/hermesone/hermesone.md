# hermesone

> 标签: hermesone

## 简介

Installer and updater for the Hermes One desktop app, and a registry installer (`add`) for skills, MCP servers, agents, and workflows.

- 源码仓库：git+https://github.com/hermesonehq/hermesonejs.git
