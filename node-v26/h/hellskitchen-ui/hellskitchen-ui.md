# hellskitchen-ui

> 标签: angular, angular-charts, angular-components, angular-library, angular-table, animated-background, component-library, csv-export, data-table, signals, ssr, standalone, ui-components, virtual-scroll, webgl

## 简介

Angular UI component library for Angular 19-22: a data table with sorting, filtering, virtual scroll and CSV export, line and bar charts, a themeable button, and eight animated WebGL backgrounds. Standalone, signal-based, SSR-safe.
