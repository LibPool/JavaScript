# header-parsers

> 标签: authorization, content-encoding, content-length, content-type, date, header, host, http, parser, range, semantics

## 简介

A collection of TypeScript header parsers, compliant with [RFC 9110: HTTP Semantics](https://www.rfc-editor.org/rfc/rfc9110).
