# hexo-ai-summary-liushen

> 标签: ai, blog, chatgpt, front-matter, hexo, hexo-generator, hexo-plugin, markdown, openai, summary

## 简介

Hexo 插件：使用 AI（如 ChatGPT 或腾讯混元）自动为 Markdown 博文生成摘要，并将摘要写入 front-matter，可控制并发请求。
