# homebridge-cmdswitch3

> 标签: cmdswitch, cmdswitch2, cmdswitch3, command-switch, dimmer, homebridge-plugin, openssh, remote-control, shell, shell-command, ssh, ssh-commands, ssh-switch, supports-hap, switch

## 简介

Local shell and remote SSH switches and dimmers for Homebridge 2. Maintained cmdSwitch2 successor with sequential commands and optional quiet logging.
