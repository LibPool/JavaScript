# homebridge-am43-blinds

> 标签: a-ok, am43, blind, homebridge-plugin, homekit, motor, shade, slide, zemismart

## 简介

DEPRECATED A homebridge plugin to control AM43 based shade motors in HomeKit. These include the A OK and Zemismart bluetooth based motors. This plugin requires a Homebridge host that supports Bluetooth 4.0
