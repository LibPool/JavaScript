# http-to-https-cors-anywhere

> 标签: cors, cross-domain, http-proxy, proxy

## 简介

HTTP to HTTPS CORS Anywhere is a reverse proxy which adds CORS headers to the proxied request. Request URL is taken from the path. The proxy can be exposed over HTTP and will always hit HTTPS servers
