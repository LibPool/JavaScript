# hexo-red0orange-admonition

> 标签: JavaScript

## 简介

主要实现的功能： 1. 实现与Obsidian中的Admonition兼容的渲染，即Obsidian的md文件能够直接放入这里面且渲染成功(颜色配置在style.css中自定义即可)。 2. 实现Latex数学公式在Admontion中的正常渲染（如果觉得字体大小不合适可以在style.css中自定义）。
