# hikeon-kite-util

> 标签: JavaScript

## 简介

1. Install candle lib using npm i -S @hikeon/hikeon-kite-util 2. Import the candle lib in your code using require('@hikeon/hikeon-kite-util'); and assign to a const variable which can be used later
