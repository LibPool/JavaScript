# homebridge-homematicip-cp

> 标签: hmip, homebridge-plugin, homekit, homematic, homematicip

## 简介

P-Black CP build of the Homematic IP Homebridge plugin, based on the original homebridge-homematicip project by marcsowen. Includes Homebridge 2.x compatibility and CP-specific Apple Home improvements.
