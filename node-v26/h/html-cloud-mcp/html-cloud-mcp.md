# html-cloud-mcp

> 标签: JavaScript

## 简介

MCP server for html.cloud — let Claude and other AI assistants share generated HTML as a private, end-to-end encrypted link, and update it later at the same link. No account, server stores only ciphertext.

## 官网

- 源码仓库：git+https://github.com/viljamilaurila/html-cloud.git
