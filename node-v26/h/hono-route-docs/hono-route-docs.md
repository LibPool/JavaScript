# hono-route-docs

> 标签: api, documentation, hono, openapi, rest, scalar, swagger

## 简介

Lightweight OpenAPI 3.1 spec generator for Hono with a fluent router API. Works with raw JSON Schema, Zod, Valibot, and any Standard Schema library.
