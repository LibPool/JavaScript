# hl7-bridge-mcp

> 标签: fhir, healthcare, hl7, hl7v2, interoperability, mcp, model-context-protocol

## 简介

MCP server to parse, map and validate clinical messages between HL7 v2.x and FHIR R4/R6, with human-readable error explanations
