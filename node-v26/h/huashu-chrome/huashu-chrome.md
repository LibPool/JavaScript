# huashu-chrome

> 标签: ai-agent, browser-automation, chrome, claude-code, codex, cursor, mcp

## 简介

让任何 AI agent 操控你自己的 Chrome——带着全部登录态。MCP + Chrome 扩展，Claude Code / Codex / Cursor / Gemini CLI 通用。
