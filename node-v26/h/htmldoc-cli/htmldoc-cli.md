# htmldoc-cli

> 标签: html, htmldoc, markdown, publish, share

## 简介

Share a local HTML or Markdown file as an unlisted htmldoc.space link that lives 30 days and can be updated in place.

## 官网

- 官网：https://htmldoc.space
- 源码仓库：git+https://github.com/ajaxray/htmldoc-cli.git
- npm 页面：https://www.npmjs.com/package/htmldoc-cli
