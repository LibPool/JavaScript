# homebridge-nad-amplifier

> 标签: amplifier, bluos, homebridge-plugin, mqtt, nad, supports-hap

## 简介

Homebridge plugin to control a NAD BluOS amplifier (e.g. M33) from Apple Home, via MQTT.
