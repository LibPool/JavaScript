# html-to-flutter

> 标签: claude, claude-code, codegen, converter, flutter, html, prototype, skill, ui

## 简介

Installs the HTML→Flutter skill (HTML prototypes + API/requirement docs → Flutter app) into a project's .claude/skills folder.
