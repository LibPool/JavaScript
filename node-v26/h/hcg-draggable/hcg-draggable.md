# hcg-draggable

> 标签: axis-lock, drag, drag-and-drop, draggable, grid-snap, javascript, move-element, no-dependencies, pointer-events, ui-component, vanilla-js

## 简介

Lightweight dependency-free vanilla JavaScript library to make any element draggable, with drag handles, axis locking, grid snapping, containment, revert, and touch/pen support via Pointer Events.
