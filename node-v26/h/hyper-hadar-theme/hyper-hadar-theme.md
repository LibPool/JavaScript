# hyper-hadar-theme

> 标签: Hadar, hadar-theme, hyper, hyper-theme

## 简介

Un tema oscuro inspirado en la constelación de Centauro, diseñado para proporcionar una experiencia visual cómoda y relajante al trabajar en la terminal durante la noche.
