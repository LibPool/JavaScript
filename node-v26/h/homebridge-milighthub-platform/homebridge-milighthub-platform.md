# homebridge-milighthub-platform

> 标签: easybulb, esp8266, eulight, homebridge, homebridge-plugin, lamp, led, lighteu, limitlessled, milight, milighthub, mqtt

## 简介

Homebridge plugin to control Milight (EULight, Easybulb, LimitlessLED) lamps with the ESP8662 Milight Hub using MQTT or HTTP
