# hivekeep-plugin-twilio-sms

> 标签: channel, hivekeep, hivekeep-plugin, sms, twilio, webhook

## 简介

Send and receive SMS via the Twilio REST API and webhooks. Channel adapter (outbound via Messages API, inbound via signed webhooks).
