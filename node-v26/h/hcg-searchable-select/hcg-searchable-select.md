# hcg-searchable-select

> 标签: accessible, aria, autocomplete, combobox, dropdown, filter, hcg-select, no-dependencies, searchable, searchable-select, select, vanilla-js

## 简介

Pure vanilla JavaScript searchable select dropdown. No dependencies. Progressively enhances a native <select> with type-to-search, match highlighting, and keyboard navigation.
