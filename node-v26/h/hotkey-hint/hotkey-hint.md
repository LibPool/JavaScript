# hotkey-hint

> 标签: hint, hotkey, keyboard, overlay, shortcut, zero-dependency

## 简介

Keyboard shortcut manager with a beautiful overlay. Register hotkeys, reveal them with ?, handle sequences and groups — in 5 lines. Zero dependencies.
