# hazo_embed

> 标签: JavaScript

## 简介

App-agnostic embeddable-widget toolkit — reserved-param contract, iframe snippet generation, HMAC+DB embed keys, and a postMessage auto-resize runtime. Consumers supply the widget component + tool registry.
