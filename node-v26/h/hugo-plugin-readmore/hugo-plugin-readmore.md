# hugo-plugin-readmore

> 标签: gitbook-plugin-openwrite, gitbook-plugin-readmore, github, gohugo-plugin-readmore, hexo-plugin-readmore, hugo-plugin-readmore, opensource, openwrite, readmore, vip

## 简介

Hugo 整合 OpenWrite 平台的 readmore 插件,实现博客的每一篇文章自动增加阅读更多效果,关注公众号后方可解锁全站文章,从而实现博客流量导流到微信公众号粉丝目的.
