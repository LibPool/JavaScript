# har-gen-api

> 标签: api, har, mock, vite

## 简介

一款基于浏览器 `.har` 文件自动生成前端 Mock 接口文件的工具。 提供 **Vite 插件** 与 **CLI 命令**，帮助你在开发过程中快速搭建本地 Mock 服务，无需手动编写重复的接口数据。
