# hueframe

> 标签: color, color-extraction, color-palette, colour, contrast, css-variables, dark-mode, design-tokens, dominant-color, image-palette, oklab, palette, theme, theme-generator, typescript

## 简介

Turn image colors into light and dark website themes. Extract palettes, adjust contrast, and export CSS variables or JSON design tokens. Zero runtime dependencies.
