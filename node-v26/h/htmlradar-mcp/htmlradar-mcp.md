# htmlradar-mcp

> 标签: claude-code, cursor, docsend-alternative, html, htmlradar, mcp, mcp-server, model-context-protocol, modelcontextprotocol, tracked-link

## 简介

MCP server for HTMLRadar — publish the HTML your agent just wrote as a tracked link, then ask whether the recipient read it.
