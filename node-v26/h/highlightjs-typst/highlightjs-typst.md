# highlightjs-typst

> 标签: code-highlighting, highlight.js, highlightjs, hljs, markup, syntax-highlighting, typst

## 简介

Custom highlight.js language definition for Typst markup + code, plus a thin highlight(source) wrapper. Follows the official highlight.js third-party grammar template structure so it can be listed in SUPPORTED_LANGUAGES.md.
