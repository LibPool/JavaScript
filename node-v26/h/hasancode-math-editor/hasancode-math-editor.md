# hasancode-math-editor

> 标签: editor, latex, latex-editor, math, math-editor, rich-text-editor, shadcn, tiptap, typescript

## 简介

A powerful, rich-text math editor component for React built on top of Tiptap, Shadcn UI, and Tailwind CSS. It provides a beautiful interface for writing both standard rich text and advanced mathematical equations (LaTeX) with live previews.
