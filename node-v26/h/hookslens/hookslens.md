# hookslens

> 标签: dashboard, debugging, devtools, fetch, hooks, monitoring, nextjs, observability, react, swr, timeline

## 简介

Real-time fetch monitoring for Next.js apps with timeline visualization and duplicate detection. Optionally tracks SWR hook intent to catch parameter mismatches.
