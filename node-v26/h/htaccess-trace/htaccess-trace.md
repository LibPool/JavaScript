# htaccess-trace

> 标签: apache, cli, htaccess, mod_rewrite, redirect, rewritecond, rewriterule

## 简介

Trace an Apache .htaccess rewrite from the command line: which RewriteRule fired, which RewriteCond failed, and what the URL became.
