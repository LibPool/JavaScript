# handlebars-commonjs

> 标签: handlebars, html, mustache, template

## 简介

Fork of `handlebars` to allow CommonJS. Will be obsolete once `handlebars` publishes > 1.0.12, because CommonJS support is in master.

## 官网

- 官网：http://www.handlebarsjs.com/
- 源码仓库：git://github.com/spikebrehm/handlebars.js.git
- npm 页面：https://www.npmjs.com/package/handlebars-commonjs

## 历史版本号

- 当前版本：1.0.13

- 1.0.13

- npm registry：https://registry.npmjs.org/handlebars-commonjs
- Node 要求：>=0.4.7
