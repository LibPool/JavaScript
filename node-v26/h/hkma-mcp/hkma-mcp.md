# hkma-mcp

> 标签: banking, hibor, hkma, hong-kong, hong-kong-monetary-authority, mcp, model-context-protocol, open-data

## 简介

MCP server for the official HKMA Open API — Hong Kong bank ATM/branch search, HIBOR and HKD interest rates. No credentials, no scraping.
