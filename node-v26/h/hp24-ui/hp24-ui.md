# hp24-ui

> 标签: combobox, dropdown, multi-select, nextjs, react, select, typescript, ui

## 简介

A zero-config, prop-driven Dropdown for React — single/multi-select, searchable, accessible. No CSS import, no Tailwind setup; works in React, Next.js, and any bundler.
