# highland-kinesis-firehose

> 标签: aws, firehose, highland, kinesis

## 简介

`highland-kinesis-firehose` is highland-based library for streaming objects into [Amazon Kinesis Firehose](https://aws.amazon.com/kinesis/firehose/).
