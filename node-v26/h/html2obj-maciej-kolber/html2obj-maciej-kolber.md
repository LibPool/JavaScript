# html2obj-maciej-kolber

> 标签: convert, html, jsdom, object, parser

## 简介

This is a JavaScript module for parsing HTML strings and converting them into structured objects. It uses the JSDOM library to create a DOM environment and then recursively parses HTML nodes and their children.
