# homebridge-phidget22

> 标签: homebridge-plugin, phidget, phidget22, sensor

## 简介

Homebridge dynamic platform plugin that exposes Phidget22 channels and dictionary keys as HomeKit accessories. Supports local USB and Phidget Network Server connections.
