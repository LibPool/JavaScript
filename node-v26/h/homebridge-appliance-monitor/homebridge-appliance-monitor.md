# homebridge-appliance-monitor

> 标签: eve-energy, homebridge-plugin, homekit, matter, power-monitoring, shelly, supports-hap, thread, washing-machine

## 简介

Homebridge plugin that watches the power draw of Matter smart plugs and tells HomeKit when an appliance is running or finished
