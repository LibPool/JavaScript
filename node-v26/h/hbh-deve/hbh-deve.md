# hbh-deve

> 标签: custom-view-engine, dev-tools, dynamic-routing, express, express-middleware, file-based-routing, hot-reload, html, js-views, layout-system, live-reload, markdown, pug, server-side-rendering, ssr, view-engine

## 简介

Flexible SSR view engine and dynamic route loader for Express.js with support for Pug, HTML, Markdown, and JS-based views. Includes file-based routing, hot reload, and customizable layout rendering.
