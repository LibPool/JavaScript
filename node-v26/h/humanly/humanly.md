# humanly

> 标签: agent-skills, agents, ai, claude, codex, copilot, cursor, opencode, prose, skill.md, tokens, writing

## 简介

Make every AI agent write humanly: clean (no AI tells), lean (fewer tokens), honest. One Agent Skill (SKILL.md), installed into every tool's skills directory via npx.
