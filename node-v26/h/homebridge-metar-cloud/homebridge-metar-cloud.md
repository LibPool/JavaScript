# homebridge-metar-cloud

> 标签: aviation, cloud, cloudiness, homebridge-plugin, metar, shading, supports-hap, weather

## 简介

Homebridge plugin exposing one HomeKit occupancy sensor that auto-selects the nearest airport with usable METAR cloud data around your location — free NOAA data, no API key.
