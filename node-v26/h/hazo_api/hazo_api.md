# hazo_api

> 标签: api, hazo, openapi, request-context, response-envelope, swagger, zod

## 简介

Foundation-layer toolkit for hazo_* HTTP APIs: response envelopes, error codes, Zod→OpenAPI generation, Swagger UI, and request context.
