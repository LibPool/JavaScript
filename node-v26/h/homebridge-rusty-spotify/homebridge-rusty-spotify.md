# homebridge-rusty-spotify

> 标签: homebridge-plugin, homekit

## 简介

[Spotify](https://www.spotify.com) plugin for [Homebridge](https://github.com/homebridge/homebridge) written in Rust. The plugin requires a Spotify Premium account.
