# homebridge-thermex

> 标签: cooker-hood, extractor, fan, homebridge-plugin, hood, light, thermex, voicelink

## 简介

Homebridge plugin for Thermex hoods with the VoiceLink/ESP local WebSocket API (fan, lights, Decolight, filter monitoring)
