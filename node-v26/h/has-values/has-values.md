# has-values

> 标签: array, boolean, empty, find, function, has, hasOwn, javascript, js, key, keys, node.js, null, number, object, properties, property, string, type, util, utilities, utility, value, values

## 简介

Returns true if any values exist, false if empty. Works for booleans, functions, numbers, strings, nulls, objects and arrays.
