# homebridge-mitsubishi-heatpump-ca

> 标签: canada, heat-pump, heatercooler, homebridge-plugin, hvac, kumo, local-control, mini-split, mitsubishi, mlz, msz, supports-hap

## 简介

Homebridge plugin for Mitsubishi ductless heat pumps (MLZ/MSZ) on Canadian accounts, which the Comfort v3 API cannot serve: one v2 cloud sign-in for credentials, then LAN-only control. US accounts keep using v3.
