# hubot-gtalk3

> 标签: github hubot gtalk adapter

## 简介

A fork of a fork of GTalk adapter for hubot. So far the only difference is that it can send an array of messages each as a separate chat message rather than a single wall of text.

- 源码仓库：git://github.com/britt/hubot-gtalk.git
