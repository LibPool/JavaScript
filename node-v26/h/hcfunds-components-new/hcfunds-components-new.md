# hcfunds-components-new

> 标签: JavaScript

## 简介

**支持以下功能：** * 支持表格列可以拖动顺序 * 支持表格列可以隐藏和显示 * 支持表格支持多列排序 * 支持拖动后的顺序、列宽和是否显示缓存到localStorage * 支持同一页面多个页面 * 支持工具栏外部排版 * 支持动态列
