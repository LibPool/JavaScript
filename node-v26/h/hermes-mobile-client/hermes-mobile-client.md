# hermes-mobile-client

> 标签: agent, ai, chat, expo, hermes, hermes-agent, mobile, react-native, websocket

## 简介

Клиент протокола Hermes Mobile Adapter: подключение приложения, бота или веб-клиента к Hermes Agent по WebSocket (текст, медиа, карточки-вопросы, стриминг)
