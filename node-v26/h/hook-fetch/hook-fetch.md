# hook-fetch

> 标签: axios, fetch, hook-fetch, hook-fetch-plugin, hook-fetch-plugin-error, hook-fetch-plugin-request, hook-fetch-plugin-request-transform, hook-fetch-plugin-response, hook-fetch-plugin-response-transform, hook-fetch-plugin-retry, hook-fetch-plugin-timeout, http, https, request, typescript

## 简介

A lightweight and modern HTTP request library developed based on the native Fetch API of the browser, providing a user-friendly interface similar to Axios and powerful extensibility.
