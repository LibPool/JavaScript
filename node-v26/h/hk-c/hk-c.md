# hk-c

> 标签: 3d, cesium, gis, hk-c, sdk

## 简介

基于 Cesium.js 的业务封装 SDK（业务项目需通过 CDN 引入 Cesium.js），仓库内自带文档/测试站点与底图配色 Studio 占位页。

- npm 页面：https://www.npmjs.com/package/hk-c
