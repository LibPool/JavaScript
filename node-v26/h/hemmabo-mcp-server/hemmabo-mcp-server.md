## 简介

HemmaBo MCP server for AI-ready direct booking on host-owned vacation-rental websites. AI agents discover host booking pages and verify signed stay offers (VRP · Ed25519/JWKS). HemmaBo is the host-owned trust layer for vacation rentals: every host runs 0%
