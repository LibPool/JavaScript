# hueshift-mcp

> 标签: accessibility, ai, claude, color, color-palette, contrast, cursor, design-tokens, mcp, model-context-protocol, oklch, palette, tailwind, wcag

## 简介

MCP server for generating OKLCH color palettes, semantic UI tokens, and accessibility-checked color scales. Use with Claude Code, Cursor, Windsurf, or any MCP client.
