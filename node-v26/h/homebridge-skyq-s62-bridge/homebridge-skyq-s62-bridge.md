# homebridge-skyq-s62-bridge

> 标签: globalcache, gnome, homebridge-plugin, ip2sl, itach, multiroom, now playing, rs232, s6.2, sky, sky q, skyq, systemline

## 简介

Homebridge plugin that polls Sky Q boxes and forwards now-playing data to a Systemline S6.2 via a Global Cache iTach IP2SL RS232 bridge. Reconstructs the Sky Gnome RS232 protocol so the S6.2 touch screen displays channel and programme information.
