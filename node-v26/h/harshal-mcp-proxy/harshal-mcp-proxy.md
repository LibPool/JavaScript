# harshal-mcp-proxy

> 标签: ai, claude, coding-agent, gateway, mcp, model-context-protocol, opencode, pi, proxy, response-shielding, schema-deferral

## 简介

MCP gateway with schema deferral + response shielding. Replaces 12+ MCP servers with 6 tools, saves ~99% context tokens and ~2.7GB RAM via shared HTTP daemon mode.
