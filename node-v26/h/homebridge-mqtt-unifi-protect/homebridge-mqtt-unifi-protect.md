# homebridge-mqtt-unifi-protect

> 标签: alarm, homebridge, homebridge-plugin, homekit, mqtt, security, unifi

## 简介

Homebridge plugin that creates a HomeKit Security System using MQTT events from UniFi Protect sensors.
