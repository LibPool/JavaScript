# humanfx-wallet-cli

> 标签: JavaScript

## 简介

Local-custody CLI for a HumanFX agentic wallet: generate/import a key that never leaves this machine, check balance, send tokens, execute arbitrary calldata. The private key never appears in any command's output — only addresses, balances, and tx hashes d
