# honeybee-compiler

> 标签: bee-compiler, honey-bee, honeybeeJS, honeybeeJS-compiler, i4w, import-for-web, javascript

## 简介

A compiler for transforming honeybeeJS code to plain JavaScript. The compiler is currently in experimental mode.
