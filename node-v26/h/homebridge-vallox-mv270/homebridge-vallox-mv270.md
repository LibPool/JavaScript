# homebridge-vallox-mv270

> 标签: homebridge-plugin, mv270, vallox, ventilation

## 简介

Homebridge plugin for Vallox MV 270 ventilation units — optimized for HomeKit with humidity, all temperature sensors, profiles and fireplace fan control.
