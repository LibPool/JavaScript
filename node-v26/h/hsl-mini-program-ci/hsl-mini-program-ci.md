# hsl-mini-program-ci

> 标签: alipay-mini, mini-app, mini-program, mini-program-ci, mp-mini

## 简介

Mini-Program-CI 是一个基于支付宝小程序 CLI、微信小程序 CLI工具功能增强的应用, 适用于本地项目 CLI 上传、批量矩阵账号上传、项目内设置环境变量等场景，兼容支付宝、微信原生项目与 Uni-app 项目
