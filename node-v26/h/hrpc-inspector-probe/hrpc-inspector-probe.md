# hrpc-inspector-probe

> 标签: JavaScript

## 简介

L1 transport taps and L2 collector for the hrpc inspector: WebRTC/WebSocket/Hyperswarm taps, ring buffer, correlator, sampler, batch flusher, central redactor, and a hybrid logical clock for the multi-peer timeline.
