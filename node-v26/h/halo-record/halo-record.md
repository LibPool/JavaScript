# halo-record

> 标签: agents, ai, attestation, audit, compliance, hash-chain, runtime-records, tamper-evident

## 简介

Open, tamper-evident audit trails for AI agents — hash-chained Runtime Records, dependency-free, verifiable by anyone. Chain-format compatible with the Python halo-record package.
