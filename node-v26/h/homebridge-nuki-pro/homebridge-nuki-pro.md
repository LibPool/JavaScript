# homebridge-nuki-pro

> 标签: homebridge, homebridge-nuki, homebridge-plugin, nuki, nuki-4, nuki-smart-lock, nuki-smart-lock-pro

## 简介

Plugin for using Nuki devices in homebridge. Fork with Smart Lock 3.0/4.0 Pro (device type 4) support and night lock switch.
