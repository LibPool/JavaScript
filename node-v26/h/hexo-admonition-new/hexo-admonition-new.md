# hexo-admonition-new

> 标签: admonition, hexo

## 简介

A Hexo plugin that adds customizable admonition blocks (note, info, warning, etc.) with icons and styles. Hexo 插件，支持自定义提示块（如 note、info、warning 等），并提供图标和样式设置。
