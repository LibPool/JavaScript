# hast-plugin-external-title

> 标签: astro, external-links, hast, hast-plugin, html, link-title, markdown, metadata, satteri, satteri-plugin, title, tooltip

## 简介

Sätteri hast plugin that fetches the page title of external links and sets it as the `title` attribute, with pluggable caching.
