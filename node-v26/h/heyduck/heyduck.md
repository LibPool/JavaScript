# heyduck

> 标签: automation, cli, cli-tool, command-line, developer-tools, duckduckgo, fast-search, json-output, nodejs, productivity, scraper, search, search-engine, terminal, web-search

## 简介

A fast CLI tool to search DuckDuckGo and instantly get keyword-based results with links, formatted output, JSON support, and customizable result limits.
