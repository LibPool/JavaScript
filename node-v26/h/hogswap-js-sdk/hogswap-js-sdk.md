# hogswap-js-sdk

> 标签: aggregator, algorand, defi, dex, hogswap, liquihog, stamm, swap

## 简介

Official JavaScript SDK for the HOGSWAP v1 router API — multi-DEX swap quotes, LP flows, market data, and x402 payments (pay any Algorand invoice with any asset) on Algorand.
