# @datepicker-suggest/core

> 标签: autocomplete, datepicker

## 简介

Core package for datepicker-suggest: it contains logic for generating suggestions based on an input text. It is used internally by [@datepicker-suggest/react](../datepicker-suggest-react/README.md) to build a selection input in React.
