# @matrix-js/multipart-mixed

> 标签: JavaScript

## 简介

Promise-based `multipart/mixed` parser, with support for Streams. Originally developed and tested for federated [Matrix](https://matrix.org) media downloads [[spec]](https://spec.matrix.org/v1.14/server-server-api/#get_matrixfederationv1mediadownloadmedia
