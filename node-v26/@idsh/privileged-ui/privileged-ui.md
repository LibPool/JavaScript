# @idsh/privileged-ui

> 标签: bundle, client, cordis, deepseek-harness, dsh, loopback, privileged, remote

## 简介

Re-enable the loopback-only privileged surface (settings page, durable settings persistence) for a dsh Web profile served to a non-loopback origin, for the authorities the deployment declares — the deliberate exception the self-hosted image used to carry
