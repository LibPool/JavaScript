# @khushwant.r/promptguard

> 标签: ai, api keys, claude, claude-code, credentials, cursor, dlp, firewall, hook, prompt, secrets, security

## 简介

Secret firewall for AI prompts. Scans prompts for API keys and secrets and blocks them before they're sent to Cursor or Claude Code, via a local prompt hook.
