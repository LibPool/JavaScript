# @endevops/effect-codec-xml

> 标签: codec, decode, effect, effect-schema, entities, entity-decoder, ncname, nmtoken, qname, xml, xml-codec, xml-naming, xml-parser, xml-serialization

## 简介

A round-trip Effect Schema codec for XML, with the entity decoder and XML name validators it reads documents with. Derives an XML representation from any Effect Schema and reads it back, with attributes as `@`-prefixed fields.
