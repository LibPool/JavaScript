# @endevops/peppol-schema

> 标签: bis-billing, credit-note, e-invoicing, e-procurement, effect, invoice, openpeppol, peppol, peppol-bis, schematron, typescript, ubl, validation, xml

## 简介

TypeScript Effect Schema models for PEPPOL BIS Billing 3.0 — decode, validate and encode Invoice, Credit Note, Invoice Response and Message Level Response XML, with generated code lists, Schematron rules and identifier validations
