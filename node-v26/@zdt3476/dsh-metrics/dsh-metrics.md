# @zdt3476/dsh-metrics

> 标签: deepseek, deepseek-harness, dsh-plugin, observability, token-usage, usage-statistics

## 简介

统计所有经过 DeepSeek Harness 的模型调用 Token 用量：按模型/供应商/项目/会话/日期拆分，带总览统计、活跃热力图、自适应趋势图表与自更新。
