# @mcp-devices/plugin-api

> 标签: mcp, mcp-devices, microkernel, plugin-api

## 简介

Public plugin contract for mcp-devices microkernel. Provides Capability enum, SourcePlugin/PluginManifest/PluginContext types, EventBus topics. Versioned independently of the product.
