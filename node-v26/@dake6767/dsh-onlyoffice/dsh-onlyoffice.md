# @dake6767/dsh-onlyoffice

> 标签: deepseek-harness, docx, dsh-plugin, onlyoffice, pptx, xlsx

## 简介

DSH web plugin: open .docx/.xlsx/.pptx from the sidebar file manager in an embedded OnlyOffice editor (static SDK, no Document Server).
