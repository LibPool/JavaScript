# @itchenliang/picture-rollup-postimage-plugin

> 标签: picture, plugin, postimage, storage, uploader

## 简介

轻快图片管理系统的插件：使用rollup开发的postimage存储图片上传插件，支持设定图片过期时间和是否缩放图片功能。
