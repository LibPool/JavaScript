# lin-prompt-polish

> 标签: deepseek-harness, dsh, efficiency, plugin, prompt, prompt-engineering

## 简介

在输入框左侧加一个 ✨ 润色 按钮：用一次辅助 LLM 调用把你的草稿改写成清晰、可执行的提示词，就地替换、绝不自动发送。Button-only, no auto-rewrite.
