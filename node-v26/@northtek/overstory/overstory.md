# @northtek/overstory

> 标签: citations, codebase, documentation, knowledge-tree, local-first, mcp, provenance, raptor, verified

## 简介

Turn any repo or docs folder into a living knowledge tree where every claim carries a verifiable receipt. Local-first: your code never leaves your machine.
