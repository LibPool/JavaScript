# @lovince/themes

> 标签: css-variables, dark-mode, design-system, tailwindcss, themes

## 简介

Light and dark themes for Lovince UI — semantic colour roles over @lovince/tokens, emitted as CSS custom properties and a Tailwind v4 theme.
