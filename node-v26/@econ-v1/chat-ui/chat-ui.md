# @econ-v1/chat-ui

> 标签: chat, framework-free, node-client, shadow-dom, stage

## 简介

Framework-free chat UI for Node client stages and shell surfaces: streamed replies, tool rows, approval cards and browser-tool calls over one injected transport.
