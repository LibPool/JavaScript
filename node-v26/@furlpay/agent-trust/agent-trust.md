# @furlpay/agent-trust

> 标签: agentic-payments, ai-agents, furlpay, http-message-signatures, mandates, rfc-9421, tap, trusted-agent-protocol, virtual-cards, x402

## 简介

Trusted-Agent-Protocol-aligned trust layer for agentic payments — Ed25519 agent identity, user-signed spend mandates (budget/MCC/expiry/single-use), replay-safe booking tokens, and RFC 9421 HTTP message signatures. Zero dependencies.
