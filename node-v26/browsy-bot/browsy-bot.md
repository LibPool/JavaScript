# browsy-bot

> 标签: agent, browser automation, browsy, cdp, chrome devtools, memorius, opencode, opencode-plugin

## 简介

Zero-middleware Chrome DevTools Protocol browser automation. CDP core plus adapters: OpenCode plugin, MCP server, CLI. Navigate, screenshot, and evaluate page JS in live tabs with memorius-powered learning.
