# @simdad/tass-project

> 标签: JavaScript

## 简介

TASS reproducible project container (.tassproj): deterministic timestamp-free archive of a run's config, corpus provenance, lexicon snapshots, and results; integrity-verified load; byte-identical re-run; compare-runs diff.
