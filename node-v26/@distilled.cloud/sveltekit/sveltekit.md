# @distilled.cloud/sveltekit

> 标签: cloudflare, sveltekit, vite, workers

## 简介

SvelteKit integration for Cloudflare Workers: wrangler-free in-memory adapter, programmatic build with a workerd re-bundle pass, and dev via SvelteKit's own Vite server.
