# @distilled.cloud/octane

> 标签: cloudflare, octane, tsrx, vite, workers

## 简介

OctaneJS integration for Cloudflare Workers: the project's own `vite build` driven programmatically (Octane's plugin builds client + server and its Cloudflare adapter emits the Worker entry), wrangler-free.
