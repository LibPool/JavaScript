# @cortejojicoy/admin-kit

> 标签: admin, admin-panel, app-router, crud, dashboard, jwt, launcher, nextjs, oauth, pages-router, permissions, pluggable, rbac, sidebar

## 简介

Next.js admin toolkit — pluggable CRUD endpoints, a three-axis access model (catalog/entitlement/permission), launcher + sidebar panels, and a markdown docs generator.
