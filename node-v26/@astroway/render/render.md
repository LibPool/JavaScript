# @astroway/render

> 标签: astrology, astroway, birth-chart, chart-wheel, horoscope, natal-chart, svg, vedic, zodiac

## 简介

The SVG chart renderers behind api.astroway.info /v1/render/*: natal, bi- and tri-wheels, Vedic charts, aspect grid, cosmogram, moon phase, timeline, biorhythm, eclipse path, star map. Pure functions, chart data in, SVG string out, no DOM and no Node APIs
