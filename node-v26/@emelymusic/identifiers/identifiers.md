# @emelymusic/identifiers

> 标签: check digit, dpid, ean, grid, ipi, isni, isrc, iswc, metadata, music, upc, validation

## 简介

Validation, normalization and check-digit arithmetic for music industry identifiers: ISWC, ISNI, IPI name/base, ISRC, UPC/EAN, GRid, DPID, LC, IPN. Structured failure reasons, zero dependencies, runs in Node and the browser.
