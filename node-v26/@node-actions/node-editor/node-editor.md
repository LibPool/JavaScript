# @node-actions/node-editor

> 标签: ast, canvas, editor, node-actions, node-canvas, react

## 简介

A SUPERFÍCIE do editor de actions: o binding entre a linguagem e o @node-canvas, o preset, o tema e o componente. Recebe uma Action — o AST — e desenha. É o único lugar do monorepo que conhece chip, aside e NodeView.
