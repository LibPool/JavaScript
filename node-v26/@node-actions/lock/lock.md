# @node-actions/lock

> 标签: merkle, node-actions, resume, stamp, versioning

## 简介

O CARIMBO do node-actions: o hash do artefato que uma execucao roda. Merkle por action sobre o fecho, para uma fita saber a que programa ela pertence.
