# @node-actions/printer

> 标签: codegen, jit, node-actions, printer, tslite

## 简介

O JIT do node-actions: a action vira TEXTO JS e roda por new Function. Espinha em controle de fluxo nativo, expressao emitida pelo @tslite/codegen.
