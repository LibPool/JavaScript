# @utdk/agent

> 标签: agent, harness, runtime, tool-use, utdk

## 简介

Shared agent-runtime contract for UTDK: one run/get/cancel surface over any harness or vendor agent loop, a normalized effort ordinal, declared capabilities, and sandbox-shaped file ops so a workspace mount works unchanged
