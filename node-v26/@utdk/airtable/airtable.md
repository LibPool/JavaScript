# @utdk/airtable

> 标签: airtable, generated, openapi, utdk

## 简介

Generated UTDK provider client for Airtable REST API. Airtable is a low-code platform for building collaborative apps. The REST API allows you to create, read, update, and delete records in Airtable bases, manage tables and fields, and automate workflows.
