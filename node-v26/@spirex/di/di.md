# @spirex/di

> 标签: composite module, container, dependency, dependency injection, dependency inversion, di, factory, fail-fast, flexible, injection, injector, internal module, inversion of control, ioc, javascript, lazy, lifecycle, middleware, modern, modular, module composition, resolver, scope, singleton, spirex, type-safe, typescript

## 简介

Powerful, type-safe, flexible, and lightweight dependency injection library for JS/TS. Immutable container, internal module types, composite modules, scope data, extensible middleware.
