> 标签: angular, bridge, container, dependency injection, dependency inversion, di, fail-fast, flexible, injection, injector, inversion of control, ioc, javascript, modern, modular, spirex, type-safe, typescript

## 简介

Allows using SpireX/DI as a domain-level service container while accessing services via standard Angular DI API.
