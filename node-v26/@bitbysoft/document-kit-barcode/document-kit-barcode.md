# @bitbysoft/document-kit-barcode

> 标签: JavaScript

## 简介

Barcode/QR extraction plugin for BitBySoft DocumentKit — detects barcodes across a session's processed pages via a replaceable BarcodeProvider. Depends on the enhance plugin at registration time, not at compile time.
