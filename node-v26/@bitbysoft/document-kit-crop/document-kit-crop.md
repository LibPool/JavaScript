# @bitbysoft/document-kit-crop

> 标签: JavaScript

## 简介

Document crop plugin for BitBySoft DocumentKit — crops a captured page via a replaceable CropProvider, preserving existing metadata. Depends on the camera plugin at registration time, not at compile time.
