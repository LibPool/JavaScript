# @bitbysoft/document-kit-domain-core

> 标签: JavaScript

## 简介

Reusable, business-agnostic mechanics shared by BitBySoft DocumentKit's domain plugins (invoice, receipt, passport, driver-license, and future ones): metadata storage, typed accessors, and generic validation helpers. Contains zero document-specific fields
