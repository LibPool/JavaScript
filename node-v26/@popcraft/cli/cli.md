# @popcraft/cli

> 标签: JavaScript

## 简介

The PopCraft command line: edit .popcraft files headlessly, call the REST API, publish to the marketplace and manage the desktop app's local plugins, themes, fonts, skills and agents.

## 官网

- 官网：https://popcraft.app/docs/api/cli
- 源码仓库：git+https://github.com/getpopcraft/popcraft-app.git
- npm 页面：https://www.npmjs.com/package/@popcraft/cli
