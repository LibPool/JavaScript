# thistripbtw-mcp

> 标签: agent, ai-agent, claude, itinerary, map, mcp, mcp-server, model-context-protocol, modelcontextprotocol, travel, trip

## 简介

Persistent, shareable travel workspaces for AI agents. Hand someone a complete, editable travel plan as a private map link. No account, no API key, no card.
