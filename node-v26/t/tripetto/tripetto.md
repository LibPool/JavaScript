# tripetto

> 标签: builder, form, form builder, form kit, forms, survey, surveys, tripetto

## 简介

Visual form builder to rapidly create and edit smart flowing forms and surveys on a self-organizing drawing board.

- 官网：https://tripetto.com
- 源码仓库：git+https://gitlab.com/tripetto/builder.git
- npm 页面：https://www.npmjs.com/package/tripetto
