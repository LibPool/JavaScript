# tallyguard

> 标签: ai, cli, denial-of-wallet, express, idempotency, nextjs, rate-limiting, sarif, sast, security, static-analysis, stripe, typescript

## 简介

Deterministic static analyzer that flags missing rate limits and unsafe money-handling in web app source code before it ships.
