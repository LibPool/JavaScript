# ts-alias

> 标签: alias, aliases, convert, file, filename, json, module, module-alias, parse, path, replace, transform, tsconfig, tsconfig.json, typescript, webpack

## 简介

Parse module aliases from tsconfig ; Apply / remove them from pathnames ; Generate config for webpack & module-alias.
