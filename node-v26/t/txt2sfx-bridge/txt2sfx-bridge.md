# txt2sfx-bridge

> 标签: mcp, procedural-audio, sfx, sound-effects, soundline, txt2sfx, web-audio

## 简介

Local daemon that puts an MCP coding agent in the same room as the txt2sfx playground: validate, render, measure and audition soundline without hosting anything.
