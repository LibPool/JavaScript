# today-lunch-mcp-mcp

> 标签: JavaScript

## 简介

一个轻量 MCP 服务与 CLI，用于在 Builder 中交互选择午餐：支持按口味（酸/甜/辣/麻/清淡/咸香）、菜系分类、素食与避忌等条件，随机返回备选。
