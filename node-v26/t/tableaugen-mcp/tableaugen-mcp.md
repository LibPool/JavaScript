# tableaugen-mcp

> 标签: analytics, bi, business-intelligence, dashboards, data-visualization, mcp, model-context-protocol, tabgen, tableau, tableaugen, twb, twbx, workbook-generator

## 简介

Generate production-ready Tableau workbooks (.twb / .twbx) from natural language and a CSV. Official MCP server for TabGen (tableaugen.com).
