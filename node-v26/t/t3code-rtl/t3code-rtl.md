# t3code-rtl

> 标签: arabic, bidi, bidirectional-text, cli, electron, farsi, i18n, localization, patch, persian, right-to-left, rtl, t3-code, t3code, unicode

## 简介

Right-to-left (RTL) support for T3 Code: patches the app so Persian (Farsi) and Arabic chat messages read right to left.
