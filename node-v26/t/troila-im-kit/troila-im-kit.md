# troila-im-kit

> 标签: im, im-kit, troila, troila-im, troila-im-kit

## 简介

Kit调试Lib步骤 1. 全局安装`yalc`:  `yarn global add yalc`    2. cd path to DakaImLib && `yalc publish` 3. cd path to DakaImKit && `yalc add DakaImLib` && `yarn install` 4. 以后Lib更新后，cd path to DakaImLib 执行 `yalc push`，Kit会自动更新 (note:如果在kit的`node server`保持状态下，刷新无效，
