# ts-trim-declarations

> 标签: api, beta, bundle, declaration, extractor, internal, rollup, transform, transformer, typescript

## 简介

Custom transformer for [TypeScript](https://www.typescriptlang.org/) that removes type declarations with `/** @internal */` JSDoc comments (or whatever other tags you specify!). Inspired by [`@microsoft/api-extractor`](https://api-extractor.com/).
