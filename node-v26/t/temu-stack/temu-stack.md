# temu-stack

> 标签: JavaScript

## 简介

Installer/updater for the private temu-video-stack monorepo (Claude Code skills /top5, /tovar and the temuvid backend). Contains no stack code — it clones the private repo with your own GitHub token.

## 官网

- npm 页面：https://www.npmjs.com/package/temu-stack

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install temu-stack`
- npm registry：https://registry.npmjs.org/temu-stack
- Node 要求：>=22
