# timesolver

> 标签: date, datetime, dayjs-alternative, format, immutable, parse, profiler, time, timestamp, tree-shakable, typescript, validate, zero-dependency

## 简介

Tiny immutable date utilities for JavaScript and TypeScript: format, parse, validate and compare native Date objects with one token grammar. Zero dependencies.
