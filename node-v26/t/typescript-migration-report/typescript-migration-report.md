# typescript-migration-report

> 标签: code metrics, code migration, code report, codebase analysis, javascript, javascript percentage, js to ts, js to typescript, migration, ts migration, typescript, typescript conversion, typescript migration, typescript migration report, typescript percentage, typescript report, typescript tools

## 简介

An npm library that helps you calculate the percentage of TypeScript and JavaScript files in your codebase, assisting in tracking progress during migration from JavaScript to TypeScript.
