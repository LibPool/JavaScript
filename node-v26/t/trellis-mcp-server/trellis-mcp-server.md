# trellis-mcp-server

> 标签: JavaScript

## 简介

Local MCP stdio proxy that lets CLI coding agents (Claude Code, Codex, Gemini CLI, Cursor) report progress into a linked Trellis project. See docs/PHASE_3_MCP_DESIGN.md.
