# tape-six-playwright

> 标签: browser, bun, chromium, cross-runtime, deno, es-modules, esm, firefox, harness, headless, iframe, nodejs, parallel, playwright, tap, tape-six, tape6, test, test-runner, testing, unit-test, webkit

## 简介

Playwright-based browser test runner for tape-six. Runs each test file in its own browser context (Chromium, Firefox, or WebKit). Works with Node, Deno, and Bun.
