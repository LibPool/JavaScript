# ts-downstream-boilerplate

> 标签: api, boilerplate, circuit-breaker, nodejs, typescript

## 简介

A Node.js + TypeScript boilerplate for calling downstream APIs using Controller → Service → Adapter pattern with Circuit Breaker.
