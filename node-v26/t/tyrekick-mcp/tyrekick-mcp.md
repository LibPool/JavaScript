# tyrekick-mcp

> 标签: ai-agents, feedback, mcp, model-context-protocol, tyrekick

## 简介

MCP server for Tyrekick — pull reviewer feedback from your Cloudflare Worker into Claude Code (or any MCP client) and resolve it as you fix things.
