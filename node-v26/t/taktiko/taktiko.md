# taktiko

> 标签: agent, ai, claude, cli, codex, daemon, kimi, taktiko

## 简介

Taktiko daemon — pairs your machine with a Taktiko server and runs your local agent CLIs (Claude Code / Codex / Kimi) for each dispatched turn.
