# taperng-sdk

> 标签: drand, randomness, tapeout, taperng, verifiable-randomness, xlayer

## 简介

Verifiable randomness on X Layer, driven by a TapeOut circuit. A request-centered TypeScript SDK for the TapeRNG on-chain randomness primitive.
