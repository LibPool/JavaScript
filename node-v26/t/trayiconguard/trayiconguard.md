# trayiconguard

> 标签: cli, notification-area, notifyiconsettings, portable, system-tray, taskbar, tray, tray-icons, windows, windows-10, windows-11, zero-dependencies

## 简介

Keep every Windows 10/11 notification-area (system tray) icon visible — downloaded, SHA-256-verified TrayIconGuard binary plus a thin wrapper CLI.
