# tgo-cli

> 标签: cli, nuxtjs, template, vuejs, webpack, 脚手架

## 简介

TGO-cli 是一套基于 SSR 快速搭建 TGO 开发环境的脚手架工具，基于 nuxtjs 和 vant移动端UI组件库，使用 pm2 做负载均衡。
