# typescript-to-lua-dev

> 标签: lua, transpiler, tstl, typescript

## 简介

A generic TypeScript to Lua transpiler. Write your code in TypeScript and publish Lua!

- 官网：https://typescripttolua.github.io/
- 源码仓库：git+https://github.com/TypeScriptToLua/TypeScriptToLua.git
- npm 页面：https://www.npmjs.com/package/typescript-to-lua-dev
