# to-double-quotes-cli

> 标签: cli, cli-app, code, convert, double, double-quotes, doublequotes, matching, normalize, quote, quotes, replace, string, text

## 简介

Convert matching single-quotes to double-quotes: I 'love' unicorns => I "love" unicorns
