# themeguard

> 标签: color, css, custom-properties, design-tokens, linter, theme

## 简介

Audits a project's CSS colour variables: value collisions between roles, dead tokens, ramps that collapse between themes, and families a theme tunes everywhere except the members it silently inherits.
