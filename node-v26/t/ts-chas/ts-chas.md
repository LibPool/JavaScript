# ts-chas

> 标签: async, error-handling, flow, functional, guard, monads, option, pipe, result, schema, tagged-errors, task, typescript, utility, validation

## 简介

A functional programming and utility library for TypeScript that provides tools for explicit error handling, schema validation & generation, and asynchronous operations.
