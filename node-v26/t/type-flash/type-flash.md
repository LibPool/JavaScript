# type-flash

> 标签: interface, json, json-to-ts, ts, ts类型定义, ts类型生成器, type, type-flash, type-flasherator, type-inference, typescript, typescript-generator, 接口类型生成, 类型推断, 类型生成, 自动生成ts类型

## 简介

极速智能的 TypeScript 类型生成器，支持深度解析对象 / JSON / 接口返回，一行代码搞定，让类型定义一键生成，彻底告别手写类型的繁琐。
