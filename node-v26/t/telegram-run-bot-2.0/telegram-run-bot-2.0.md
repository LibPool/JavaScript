# telegram-run-bot-2.0

> 标签: run

## 简介

This is the telegram-run-bot package! You can use it to run a Telegram bot in JavaScript. The Telegram bot code must be stored in the bot file.js or this package won't work. To run the file, enter the node command. cli.js run file_name.js
