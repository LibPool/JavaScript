# toon-adaptive

> 标签: ai, developer-tools, json, llm, prompt-engineering, serialization, tiktoken, token-optimization, token-oriented-object-notation, tokens, toon, typescript

## 简介

Decides whether a JSON payload should go to an LLM as TOON or stay JSON, using real token measurement instead of guesswork.
