> 标签: ai-agents, claude-code, codex, cursor, distributed-compute, dmi, kv-cache, mcp, mcp-server, ramulator, research, verilator, verilog

## 简介

DMI (Decentralized Mass Intelligence): turn the coding agent you already run into a research node. Install the MCP server, work tasks in the background, or run a compute node that scores submissions for credit.
