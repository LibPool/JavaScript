# tsx-component-generator

> 标签: React, cli, front-end, generator, javascript, typescript

## 简介

If you enjoy using CLI tools, this module will help you quickly create React TSX components. It automatically generates a `.tsx` file with styled-components declared and a basic component structure ready to use—all in one step.
