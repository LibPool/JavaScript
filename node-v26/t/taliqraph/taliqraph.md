# taliqraph

> 标签: agents, ai, anthropic, automation, claude-code, cli, skill, workflow

## 简介

Run workflows made of AI agents, scripts and approval gates, defined as plain files. A CLI, a programmatic API, and a SKILL.md that teaches your own agent the format.
