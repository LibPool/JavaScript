# t-dock-manager

> 标签: JavaScript

## 简介

​		基于Vue3 + Vite构建的一款容器布局管理工具，在Vue3项目中，为前端程序提供类似Visual Studio的窗口停靠、悬浮、自动隐藏以及布局管理功能。
