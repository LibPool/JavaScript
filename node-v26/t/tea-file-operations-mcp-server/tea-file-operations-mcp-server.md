# tea-file-operations-mcp-server

> 标签: ai-assistant, cursor, file-operations, mcp, model-context-protocol

## 简介

MCP 服务器，通过 NestJS API 提供文件操作工具：读取、写入、删除、修改文件和读取所有代码，支持递归目录列表
