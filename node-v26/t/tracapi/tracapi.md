# tracapi

> 标签: collision, dom, framework-agnostic, html, intersection, mutation, observer, performance, position, resize, tracker, tracking, transform

## 简介

Effortlessly let HTML elements observe, follow, synchronize with, and react to other HTML elements. A framework-agnostic, zero-dependency tracking engine built on native browser APIs.
