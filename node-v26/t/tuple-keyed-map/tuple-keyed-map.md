# tuple-keyed-map

> 标签: cache, composite-key, data-structure, garbage-collection, map, memoize, multi-key, trie, tuple, weakmap

## 简介

A Map keyed by tuples whose entries are garbage-collected when their object components die — WeakMap edges for objects, Map edges for primitives, and a single-walk getOrInsert.
