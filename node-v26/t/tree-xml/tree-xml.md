# tree-xml

> 标签: code, html, tree, tree xml, viewer, xml, xml tree, xml viewer, xml格式化, xml预览, 代码查看

## 简介

tree-xml是一个树形xml代码查看器，利用element-ui中的tree组件与htmlparser2把xml代码以树视图展示，可自定义元素标签、属性、文本等样式
