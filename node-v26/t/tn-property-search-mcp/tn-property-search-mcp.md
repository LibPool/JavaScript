# tn-property-search-mcp

> 标签: arcgis, assessor, gis, knoxville, mcp, model-context-protocol, nashville, parcel, property, public-records, real-estate, tennessee

## 简介

MCP server for Tennessee property records: statewide assessment data for 86 counties via the Comptroller's TPAD, parcel geometry, and county adapters for Davidson (Nashville), Knox and Williamson. No API keys required.
