# texlyre-busytex

> 标签: bibtex, browser, busytex, latex, lualatex, pdf, pdflatex, synctex, wasm, webassembly, xelatex

## 简介

Run LaTeX compilation (pdflatex, xelatex, lualatex) in the browser using WebAssembly (TeX Live 2026)
