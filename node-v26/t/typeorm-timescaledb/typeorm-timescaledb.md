# typeorm-timescaledb

> 标签: hypertable, nestjs, orm, postgres, postgresql, time-series, timescale, timescaledb, typeorm

## 简介

Pre-1.0 TypeORM integration for TimescaleDB: typed hypertables, columnstore, retention, reviewable migrations, and a typed hyperfunction query layer with stable toolkit aggregates.
