# torna-sdk

> 标签: b+tree, b-tree, clob, orderbook, parallel, sealevel, solana, sorted-index, torna, web3

## 简介

Torna client SDK (TypeScript) -- the PathPlanner for the parallel, ordered, on-chain B+ tree index on Solana. Resolves the exact account set off-chain so node indices, PDA bumps, paths, and split spares never leak to the integrator.
