# ts-node-yeelight

> 标签: xiaomi, yeelight

## 简介

Typescript implementation of the original library by [jamesblanksby](https://github.com/jamesblanksby/node-yeelight). Offers a few classes to interact with Xiaomi Yeelight devices in one's local network.
