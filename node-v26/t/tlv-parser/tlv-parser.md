# tlv-parser

> 标签: clean-architecture, esmodule, parser, solid, tag-length-value, tlv, typescript

## 简介

Zero-dependency recursive TLV (Tag-Length-Value) parser, written in TypeScript and compiled to pure ES modules. Supports raw TLVNode[] or nested object keyed by tag.
