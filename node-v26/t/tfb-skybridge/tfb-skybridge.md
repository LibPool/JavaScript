# tfb-skybridge

> 标签: admission-control, agent, app-store, cli, content-security-policy, csp, merkle, pre-ship, sandbox, skybridge, supply-chain, tfb, transparency-log

## 简介

Proof-carrying admission for third-party agent apps. The dev CLI: run the discriminator on your own code; verdict in milliseconds with the exact seed × payload × call site that caused any catch.
