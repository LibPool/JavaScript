# trust-attest-server

> 标签: agent-commerce, attestation, endpoint, mcp, model-context-protocol, trust, x402

## 简介

MCP server for the tokenizen.nl trust layer: an AI agent proves it controls an endpoint (ACME-style, via endpoint-attest), a passive check reads what that endpoint's own response says about authentication, and the outcome is returned as a signed, content-
