# tapi-sdk

> 标签: JavaScript

## 简介

**tapi-sdk** is a lightweight, modern, and fully-typed JavaScript/TypeScript SDK for interacting with the [twitterapi.io](https://docs.twitterapi.io/api-reference/endpoint) API.
