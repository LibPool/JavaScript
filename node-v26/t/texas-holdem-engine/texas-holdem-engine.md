# texas-holdem-engine

> 标签: ai, engine, evaluator, holdem, nlhe, poker

## 简介

No-Limit Hold'em engine: pure-JS state machine (blinds, side pots, showdown) + Monte Carlo AI. Zero deps, ESM, runs in Node and the browser.
