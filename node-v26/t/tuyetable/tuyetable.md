# tuyetable

> 标签: ProTable, antd, curd, react, table

## 简介

對 umi 的 ProTable 進行了拓展和美化樣式和邏輯，新增 “增”、“刪”、“改”，實現了真正意義上的 CURD，能夠大幅提高前端開發人員的效率。
