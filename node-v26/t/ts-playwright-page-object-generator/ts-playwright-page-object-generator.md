# ts-playwright-page-object-generator

> 标签: accessibility, e2e-testing, page-object, playwright, test-automation, test-generation, typescript, ui-testing, web-testing, webdriver

## 简介

A powerful tool for automatically generating Playwright Page Objects from web pages. Focuses on interactive elements by default and generates clean, maintainable TypeScript code.
