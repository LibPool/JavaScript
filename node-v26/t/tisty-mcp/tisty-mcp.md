# tisty-mcp

> 标签: documents, local-first, markdown, mcp, notes, tasks, tisty

## 简介

Starts the MCP server of the Tisty app installed on this computer: notes, documents and tasks as plain Markdown on your own disk.

## 官网

- 官网：https://www.tisty.app/docs/assistants-and-mcp/
- 源码仓库：git+https://github.com/rgdevment/mcp-plugins.git
- npm 页面：https://www.npmjs.com/package/tisty-mcp
