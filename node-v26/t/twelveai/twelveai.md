# twelveai

> 标签: agent, ai, banking, chatbot, conversational-banking, fintech, twelveai

## 简介

Official SDK for TwelveAI - AI infrastructure for conversational banking. One call runs the whole chat protocol: routing, grounded tool calls, client-fetch hand-offs, confirmations, and request verification.
