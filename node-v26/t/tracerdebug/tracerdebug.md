# tracerdebug

> 标签: debug, log, logger, trace

## 简介

A powerful and customizable logging library integrated with debug for node.js. support color console with timestamp, line number, method name, file name and call stack. you can set transport to file, stream, database(ex: mongodb and clouddb, simpledb). ke
