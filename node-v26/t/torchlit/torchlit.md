# torchlit

> 标签: guided-tour, lit, onboarding, shadow-dom, spotlight, tooltip, torchlit, tour, walkthrough, web-components

## 简介

Lightweight guided-tour & onboarding library built on Lit web components. Shadow DOM aware, framework-agnostic, tiny footprint.
