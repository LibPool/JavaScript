# ts-canon

> 标签: ast-grep, biome, codemod, format, lint, oxlint, preset, shared-config, toolchain, typescript, vitest

## 简介

Shared TypeScript toolchain: one dependency for lint, format, doctor, and migrate, with biome/tsconfig/vitest presets and ast-grep rules
