# townshipcanada

> 标签: alberta, british-columbia, canada, coordinates, dls, dominion-land-survey, geocoding, geospatial, gps, land, legal-land-description, manitoba, national-topographic-system, nts, ontario, saskatchewan, survey, township

## 简介

Official TypeScript SDK for the Township Canada API — convert Canadian legal land descriptions (DLS, NTS, Geographic Townships) to GPS coordinates and back.

## 官网

- 官网：https://townshipcanada.com/api
- 源码仓库：git+https://github.com/townshipcanada/typescript-sdk.git
- npm 页面：https://www.npmjs.com/package/townshipcanada
