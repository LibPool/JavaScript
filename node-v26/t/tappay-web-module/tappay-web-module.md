# tappay-web-module

> 标签: aftee, apple-pay, bnpl, checkout, credit-card, dark-mode, direct-pay, easy-wallet, google-pay, jko-pay, line-pay, modal, payment, payments, pi-wallet, samsung-pay, sdk, taiwan, tappay, tpdirect

## 简介

A well-structured, zero-dependency, themeable web module that wraps the TapPay TPDirect SDK to enable 18 payment methods (Direct Pay, Google Pay, Apple Pay, Samsung Pay, LINE Pay, JKO Pay, and regional Asian wallets) with a drop-in dark/light checkout UI
