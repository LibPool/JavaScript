# td-languages-names

> 标签: constants, endonym, exonym, internationalization, language-list, language-names, language-selector, languages, locale, localization, native-names, translation, typescript

## 简介

TypeScript/JavaScript library with 232 language names in English and in their native script (e.g. 日本語, Polski, العربية). Includes bidirectional maps and typed constants and language selectors.
