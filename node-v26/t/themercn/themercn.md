# themercn

> 标签: JavaScript

## 简介

A live editor for a shadcn Theme's design tokens. Mount one `<Themer>` next to your app, open it with the floating button or `Ctrl+Shift+E`, and edit colours, fonts, radius, spacing, letter spacing and shadows on the page you are looking at. When you like
