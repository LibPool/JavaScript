# typescript-ubl

> 标签: e-invoicing, invoice, oasis, typescript, ubl, ubl-2.1, xml, xsd

## 简介

Strongly typed OASIS UBL 2.1 for TypeScript: generated types for all 65 document types, with validation, XML serialization and XML parsing.
