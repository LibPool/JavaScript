# turnlock

> 标签: JavaScript

## 简介

Durable finite-state-machine runtime for TypeScript. Snapshot-authoritative state, in-band stdout protocol, POSIX-grade I/O discipline. Host-agnostic: suspends by terminating its process and resumes from disk.
