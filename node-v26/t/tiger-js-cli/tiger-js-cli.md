# tiger-js-cli

> 标签: ai-agent, cli, static-analysis, tiger

## 简介

Command-line tools for a Tiger app: tiger check (diagnostics), tiger map (a structured JSON map of the app), and tiger skill install (the Tiger Skill for Claude Code).
