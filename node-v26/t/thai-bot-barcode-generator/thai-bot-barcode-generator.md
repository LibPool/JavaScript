# thai-bot-barcode-generator

> 标签: barcode, bot-barcode, code128, emvco, payment, promptpay, qr-code, thai, thailand

## 简介

Library for generating QR Code and Barcode from BOT Barcode input. Supports both file output and blob/data URL format.
