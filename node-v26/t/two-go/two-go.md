# two-go

> 标签: api, assertions, e2e, expect, fluent, http, integration, json-schema, lodash, rest, service-test, testing, utilities

## 简介

Zero-dependency fluent service/API testing library: chainable HTTP requests, Jest-style + HTTP assertions, and a lodash-inspired utility belt. Works standalone or inside node:test, Jest, Vitest, and Mocha.
