# tw-id-num

> 标签: Taiwan, 中華民國, 台灣, 統一證號, 身份證字號

## 简介

Check or generate Taiwan ID numbers. 檢查或是產生中華民國國民身分證統一編號(即身份證字號，而非營業人統一編號)，支援新式外來人口統一證號。也特別支援舊式外來人口統一證號的檢查。
