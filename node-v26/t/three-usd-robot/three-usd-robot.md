# three-usd-robot

> 标签: articulation, isaac-sim, kinematics, openusd, robot, robotics, three, threejs, urdf, usd

## 简介

Kinematic OpenUSD robot loader for Three.js — load Isaac Sim / OpenUSD robot assets, extract joints and links, and control articulations in the browser.
