# tib-graphview

> 标签: Ontology Lookup Service, biojs, ebi, network, ols, ontology, visualisation

## 简介

This widget is a flexible and dynamic ontology visualisation. It can be seen in action on the new Ontology Lookup Service (OLS) provided by the EMBL-EBI.
