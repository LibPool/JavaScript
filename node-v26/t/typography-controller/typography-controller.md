# typography-controller

> 标签: accessibility, custom-elements, design-system, frontend, javascript, typography, ui, ui-library, web-components

## 简介

A framework-agnostic Web Component that provides a beautiful typography control panel with sliders for font size, letter spacing, word spacing, line height, contrast, and font family.
