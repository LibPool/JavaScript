# toolshape

> 标签: anthropic, claude, convert, function-calling, gemini, json-schema, llm, mcp, model-context-protocol, openai, tool-calling, tool-calls, tool-results, tools

## 简介

Convert LLM tool definitions, tool calls and tool results between OpenAI, Anthropic, Gemini and MCP formats, including the JSON Schema fixes each one needs (strict mode, Gemini's schema subset, tool names). Zero dependencies.
