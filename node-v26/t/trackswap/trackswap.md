# trackswap

> 标签: encoder, geolocation, geospatial, gps, gpx, node, parser, route, track, trackswap, typescript, waypoint, xml

## 简介

A typed, adapter-based toolkit for decoding, normalizing and transcoding FIT, GPX and TCX data.
