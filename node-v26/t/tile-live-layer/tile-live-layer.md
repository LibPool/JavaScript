# tile-live-layer

> 标签: config, expo, feature-flags, react-native, tile

## 简介

Remote feature-flag / config SDK for Tile (Expo / React Native) apps. Fetches a per-(app,env) JSON layer from the CDN, caches it, and resolves typed flags with a 4-layer fallback.
