# tailwind-turbine

> 标签: css, grouping, plugin, plugins, tailwind, tailwindcss, utility-classes

## 简介

Turbine is the original and ultimate Tailwind CSS config preprocessor, enabling the development and usage of plugins that effortlessly reach outside your `plugins` array with minimal effort.
