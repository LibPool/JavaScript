# tezga-sdk

> 标签: e-invoice, ekasa, fiscal-receipt, fiscalization, gosimple, pos, sdk, sef, serbia, suf, tezga, typescript, v-pfr

## 简介

Official JavaScript/TypeScript SDK for the Tezga Fiscal API: issue and fiscalize legal receipts in Serbia (eKasa / SUF) over a single REST API, no L-PFR hardware. A GoSimple product.
