# terminal-game-io

> 标签: angular, angular6, ascii game, escape codes, node escape codes, node game, nodejs game, terminal game, terminal keypress, terminal render frame, typescript

## 简介

It has never been easier to start writing ASCII games in NodeJs or browser. This package handles for you basic input (keyboard events) and output (ASCII 'frame').
