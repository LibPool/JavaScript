# tywrap

> 标签: ast, bindings, bridge, bun, code-generation, codegen, deno, ffi, interop, node, numpy, pandas, pyodide, python, python-wrapper, rpc, scipy, subprocess, typed-bindings, typescript, wrapper

## 简介

Generate TypeScript bindings for Python libraries with precise types where tywrap can resolve them — Node.js, experimental Deno, Bun, and browsers via Pyodide.
