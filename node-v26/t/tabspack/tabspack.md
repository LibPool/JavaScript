# tabspack

> 标签: bookmarks, browser tabs, export, import, json schema, session, tab session, tabs, tabspack

## 简介

Read, validate and write TabsPack files: every open browser tab in one open, documented JSON file. The reference reader and writer from the TabsPack extension.
