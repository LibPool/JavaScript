# threesmap

> 标签: 3d, geojson, heatmap, map, three, threejs, vue, vue3, 地图, 数据可视化

## 简介

纯 three.js 实现的 Vue 3 3D 地图组件，不依赖 TresJS / R3F，内置示例数据、贴图与图层开关，零配置即可运行。
