# tlp-icons-data

> 标签: icon-data, icons, svg, tlp-icons

## 简介

The full tlp-icons set: one JSON file with every icon's SVG, motion, category, tags and source, plus one ES module per category (icons/<category>.js) and the offline single-file bundle (tlp-icons.all.js).
