# turbo_exif

> 标签: JavaScript

## 简介

A library for writing metadata to jpg / webp / tiff / png. Unlike the javascript libraries out there, that convert to base64 and still aren't able to add metadata to the image, or are limited to formats to which they can add metadata to, the turbo_exif.js
