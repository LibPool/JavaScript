# token-police-langchain

> 标签: ai, budget, cost-control, enforcement, firewall, langchain, llm, opentelemetry, token, tokenpolice

## 简介

LangChain token-capture companion for the TokenPolice Node.js SDK. Install alongside token-police to enable automatic LangChain instrumentation.
