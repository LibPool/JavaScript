# thing-it-device-microcontroller

> 标签: Arduino, IoT, Uno, thing-it

## 简介

[thing-it-node] Device Plugin for microcontroller functionality provided e.g. via an Arduino but also the GPIOs of a Raspberry Pi or C.H.I.P..
