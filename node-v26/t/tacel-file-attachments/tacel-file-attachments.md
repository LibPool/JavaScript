# tacel-file-attachments

> 标签: attachments, download, electron, file, ipc, permissions, preview, tagging, upload

## 简介

A reusable file attachments component for Electron apps. Supports upload, preview, download, delete, rename, tagging, and per-user/per-file permissions. Inline DOCX preview supported via a host-provided docxToHtml async callback.
