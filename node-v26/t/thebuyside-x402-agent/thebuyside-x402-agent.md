# thebuyside-x402-agent

> 标签: agent-payments, agents, base, crypto-payments, mcp, model-context-protocol, mpp, pay.sh, solana, stablecoin, usdc, x402

## 简介

Buyer-side MCP gateway for x402 and MPP (pay.sh) — let any agent pay any metered API on Base or Solana without seeing a 402 or a wallet.
