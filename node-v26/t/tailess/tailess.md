# tailess

> 标签: breakpoints, clsx, cn, postcss, responsive, tailwind, tailwind-merge, tailwindcss, typescript, utilities, utils, variants, vite

## 简介

Write Tailwind classes as a readable object, grouped by breakpoint and state — fully typed, and wired into Tailwind so it actually works.
