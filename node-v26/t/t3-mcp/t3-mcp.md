# t3-mcp

> 标签: agent-orchestration, ai-agents, claude, codex, mcp, model-context-protocol, t3-code, t3code

## 简介

Bearer-authenticated HTTP MCP server that lets any agent spawn and manage T3 Code agent threads, paired with a T3 pairing link.
