# tutorloop

> 标签: claude, codemirror, education, exercise, learning, mcp, mcp-apps, mcp-server, pyodide, sqlite, tutor, typescript

## 简介

Graded coding exercises inside a chat. The assistant writes the lesson and the hidden tests, the widget runs them in the browser, and a failed attempt goes back into the conversation so the tutor explains your specific mistake. Python, JavaScript, TypeScr
