# tui-mermaid

> 标签: JavaScript

## 简介

Render mermaid diagram text as Unicode box-drawing art for terminals. TypeScript port of xAI grok-build's mermaid renderer.

## 官网

- npm 页面：https://www.npmjs.com/package/tui-mermaid
