# tkyodrift

> 标签: ai-evaluation, ai-monitoring, cli-tool, concept-drift, cosine-similarity, drift-detection, embedding, euclidean-distance, huggingface, lexical-drift, machine-learning, model-drift, model-evaluation, monitoring, population-stability-index, scalars, semantic-drift, transformers, vector-embedding, xenova

## 简介

Lightweight CLI tool and library for detecting AI model drift using embeddings and scalar metrics. Tracks semantic, conceptual, and lexical change over time.
