# texdown

> 标签: JavaScript

## 简介

TeXdowN is a lightweight alternative to LaTeX for writing short texts with math equations. While TeXdowN is heavily influenced by Markdown it is **NOT** Markdown + MathJax.  TeXDown is a work in progress.
