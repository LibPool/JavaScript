# taskfoundry

> 标签: ai, automation, azure-devops, bitbucket, cli, developer tools, devops, diff, git, github, gitlab, openai, productivity, task, task generation

## 简介

Generate task content and commit messages from your Git diffs — in Markdown or JSON — powered by Groq, OpenAI, or your own local model.
