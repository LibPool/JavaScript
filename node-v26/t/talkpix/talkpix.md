# talkpix

> 标签: ai-video, api-client, lip-sync, photo-animation, talking-avatar, talking-head, talking-photo, talkpix, text-to-speech, text-to-video

## 简介

Official Node.js client for the TalkPix API: turn one portrait photo and a script or audio clip into a lip-synced talking video.

## 官网

- 官网：https://www.talkpix.ai/developers
- 源码仓库：git+https://github.com/talkpixai/talkpix-node.git
- npm 页面：https://www.npmjs.com/package/talkpix
