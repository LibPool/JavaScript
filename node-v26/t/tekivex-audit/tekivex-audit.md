# tekivex-audit

> 标签: a11y, accessibility, audit, lint, react, security, static-analysis, tekivex-ui, wcag, xss

## 简介

Static-analysis CLI that scans a React project for security + accessibility regressions. Ships with tekivex-ui but works against any React codebase.
