# todesk-web-terminal-sdk

> 标签: JavaScript

## 简介

一个基于 xterm.js 和 socket.io 的 Web 终端工具库，支持 React、Vue 和 UMD 调用方式。所有依赖已打包到库内，无需额外安装。

- npm 页面：https://www.npmjs.com/package/todesk-web-terminal-sdk
