# thnet

> 标签: client, ipv6, networking, server, thnet

## 简介

thnet is a Node plugin for ipv6 homenet tunneling solution. thnet means Tijee Home Network.

## 官网

- 官网：https://bitbucket.org/tijee/thnet
- 源码仓库：git+https://bitbucket.org/tijee/thnet.git
- npm 页面：https://www.npmjs.com/package/thnet

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- npm 安装：`npm install thnet`
- npm registry：https://registry.npmjs.org/thnet
- Node 要求：>=0.8.0
