# tenglo

> 标签: aspnet, aspnet-core, compiler, components, csharp, dotnet, framework, fullstack, razor, reactive, ssr, tenglo

## 简介

The full-stack reactive framework for .NET. Write components in C#, ship plain JavaScript to the browser, and get your HTTP API generated for you.
