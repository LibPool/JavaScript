# takealot-seller-api-sdk

> 标签: ecommerce, marketplace, seller-api, south-africa, takealot

## 简介

TypeScript SDK for the Takealot Seller API (offers, stock, sales/orders). Generated from the official Swagger spec at https://seller-api.takealot.com/api-docs/swagger.json. Zero runtime dependencies, works in browsers and Node 18+.
