# threenative-blender-mcp

> 标签: agents, blender, fbx, gltf, mcp, model-context-protocol, threenative

## 简介

Drives an installed Blender headlessly so a downloaded .fbx becomes a GLB a ThreeNative game loads. Ships no Blender.
