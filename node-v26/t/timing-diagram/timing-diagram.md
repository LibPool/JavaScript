# timing-diagram

> 标签: sequence, timing, 时序图

## 简介

timing-diagram是一个VUE时序图组件，用HTML+CSS+js元素来实现视图， 因此可根据UI要求自定义样式，组件捕捉了点击事件，详情可查看使用示例。
