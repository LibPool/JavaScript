# toader-cli

> 标签: agents, ai, anthropic, claude, cli, multi-agent, toad

## 简介

Issue-driven multi-agent software factory CLI, built on TOAD. An orchestrator triages issues, agent teams implement them in git worktrees, QA gates verify.
