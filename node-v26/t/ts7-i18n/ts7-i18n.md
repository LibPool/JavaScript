# ts7-i18n

> 标签: i18n, internationalization, nextjs, no-codegen, react, template-literal-types, tsgo, type-safe, typescript, typescript-7

## 简介

Typed i18n for TypeScript 7 — zero codegen, zero TypeScript-compiler-API usage, param types inferred from template-literal string types. A drop-in-shaped replacement for typesafe-i18n's LL accessor pattern.
