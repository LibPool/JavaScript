# tabris-decorators

> 标签: JavaScript

## 简介

This module provides __data binding__ and  __dependency injection__ for [Tabris.js](http://tabrisjs.com) based on [TypeScript decorators](http://www.typescriptlang.org/docs/handbook/decorators.html).
