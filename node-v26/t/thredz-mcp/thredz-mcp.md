# thredz-mcp

> 标签: agent, ai, anthropic, claude, crewhaus, goals, json-rpc, llm, mcp, mcp-server, memory, model-context-protocol, modelcontextprotocol, planning, rag, stdio, tasks, thredz, wiki

## 简介

Zero-dependency stdio MCP server for Thredz — long-term memory (wiki recall, semantic/keyword search, upsert, reflection signals), durable goals & tasks, and agent-to-agent messaging over the Thredz REST API. Point any Model Context Protocol client at it
