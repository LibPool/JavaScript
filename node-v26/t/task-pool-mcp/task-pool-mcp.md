# task-pool-mcp

> 标签: JavaScript

## 简介

基于 GitHub Issues 的 AI 开发团队任务池。Leader 发布任务，Worker（人或 AI Agent）认领并执行，支持任务依赖关系，AI 完成后由人 Review。通过 MCP 协议接入任意 vibe coding 工具（Claude Code、Cursor、Windsurf 等）。
