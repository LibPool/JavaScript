# tmp-site

> 标签: cli, deploy, hosting, static-site, tmp.site

## 简介

Publish a static site to a temporary tmp.site URL — anonymous, no account. Deployments expire on their own, and the record that lets this machine manage one is kept under ~/.tmp-site. Run it as npx tmp-site <command>, or as tmp <command> after npm i -g tm
