# telegram-bot-test-server

> 标签: bot-api, e2e, fake, grammy, integration-testing, mock, mock-server, moderation, telegraf, telegram, telegram-bot, telegram-bot-api, test-server, testing

## 简介

A local Telegram Bot API server for end-to-end tests: groups, members, moderation, buttons, webhooks and a live chat viewer. No Telegram account needed.
