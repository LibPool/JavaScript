# token-oracle

> 标签: anthropic, ccusage, claude, claude-code, cli, forecast, grok, token-usage, tokens, usage, xai

## 简介

Forecast when you'll hit your Claude Code / Grok token limits — offline from local logs, optionally browser-verified. Python CLI, runnable with npx/bunx.
