# ts-import-patch

> 标签: Add .js to compiled ts, Add .js to ts compiled source in node with esm, ESM with ts, import fix, import patch, transpiled ts import fix

## 简介

A simple script that adds the '.js' extension to js imports compiled from ts while using ESM in node
