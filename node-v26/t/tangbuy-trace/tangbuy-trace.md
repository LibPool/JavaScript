# tangbuy-trace

> 标签: JavaScript

## 简介

`tangbuy-trace` 是一个用于跟踪用户行为事件的 JavaScript 库，支持 Web 和 H5 平台。该库旨在帮助开发者轻松记录用户在页面中的操作，并将这些操作日志发送到指定的服务器。
