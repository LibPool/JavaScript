# test-palindrome

> 标签: check, javascript, js, learn-enough, palind, palindrome, palindrome-checker, palindrome-test, string, text, txt

## 简介

Checks if a string is a palindrome, and returns "true" if it is a palidrome, and "false" if it is not a palindrome.
