# typeid-unboxed

> 标签: guid, typeid, uuid, uuidv7

## 简介

Alternative unboxed implementation of the TypeID specification in TypeScript. TypeIDs are type-safe, K-sortable, and globally unique identifiers inspired by Stripe IDs
