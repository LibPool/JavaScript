# tinypdf-mock

> 标签: api, backend, backoff, chaos, cors, fault-injection, frontend, http, mock, mock-server, rest, retry, testing

## 简介

Local mock API server with fault injection (503s, 429 + Retry-After, timeouts, dropped connections), a live request log and a browser control page. Zero dependencies.

- 官网：https://tinypdf.in/rest-api-playground.html
