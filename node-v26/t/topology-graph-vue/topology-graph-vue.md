# topology-graph-vue

> 标签: component, graph, large-data, network, performance, pixijs, topology, visualization, vue, vue3, webgl

## 简介

基于 PixiJS v8 的高性能 Vue 3 拓扑图组件库，支持 50,000+ 节点以 60 FPS 流畅渲染
