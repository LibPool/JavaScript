# thicket-cli

> 标签: agent, api, claude-code, cli, connector, notifications, project-management, thicket

## 简介

Official command-line interface for Thicket (thickethq.com): projects, to-dos, messages, docs and files, boards, chat, search, reports, notifications, cheers, and the local agent connector, from your terminal or through AI agents.
