# tulih-editor

> 标签: contenteditable, editor, html-editor, rich-text-editor, text-editor, tulih-editor, typescript, wysiwyg

## 简介

A lightweight, zero-dependency WYSIWYG rich text editor for the browser, built on contenteditable with a modular plugin system. ~50 plugins, written in TypeScript.
