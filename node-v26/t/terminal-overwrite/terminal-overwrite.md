# terminal-overwrite

> 标签: animation, bar, cli, console, log, logger, logging, output, overwrite, progress, refresh, shell, stdout, term, terminal, update

## 简介

Log by overwriting the previous output in the terminal. Useful for rendering progress bars, animations, etc.
