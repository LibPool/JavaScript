# truescrape

> 标签: agent-skill, api, cli, instagram, mcp, scraping, social-media, tiktok, truescrape, youtube

## 简介

CLI for the TrueScrape API: public social media data from every platform in the catalogue, from the terminal or as an MCP server for agents.
