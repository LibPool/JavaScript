# tinyremote

> 标签: automation, cli, end-to-end-encryption, macos, p2p, remote-control, screenshot, ssh

## 简介

A real remote terminal for your own machines, gated by SSH keys and end-to-end encrypted. Run Claude Code, vim or any command, take screenshots, move the mouse and keyboard.
