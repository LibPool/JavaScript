# thrift-browserify

> 标签: JavaScript

## 简介

node.js bindings for the Apache Thrift RPC system. This build contains fixes for using thrift with Browserify

## 官网

- 官网：http://thrift.apache.org/
- 源码仓库：https://github.com/cameronr/thrift
- npm 页面：https://www.npmjs.com/package/thrift-browserify
