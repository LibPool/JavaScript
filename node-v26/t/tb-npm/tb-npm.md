# tb-npm

> 标签: cnpm, npm, taobao, tnpm

## 简介

Call npm using Taobao registry with '--registry=https://registry.npm.taobao.org'

- 源码仓库：git+https://github.com/Emeryao/tnpm.git

- Node 要求：>=6.0.0
