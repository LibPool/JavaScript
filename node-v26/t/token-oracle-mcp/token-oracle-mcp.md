# token-oracle-mcp

> 标签: anthropic, budget, cost, google, llm, mcp, openai, optimization, pricing, tokens

## 简介

Returns real-time cost estimates and model recommendations for LLM API calls. Compares pricing across OpenAI, Anthropic, Google, and open-source providers. Helps agents optimize spend and stay within budget constraints. Hosted stdio bridge package.
