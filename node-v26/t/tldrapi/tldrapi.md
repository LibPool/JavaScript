# tldrapi

> 标签: abstract, ai, llm, nlp, summarize, summarizer, summary, tldr, tldrapi

## 简介

Official Node.js/TypeScript SDK for the TLDRapi summarization API. Summarize text at 5 quality tiers with 20+ built-in voice styles.
