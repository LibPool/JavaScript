# tally-provenance

> 标签: ci, evm, provenance, smart-contracts, supply-chain, tally, verification

## 简介

Ask whether a smart contract's source is vouched for, on any EVM chain. A Tally lookup library and a CI check that tally.json agrees with the chain.
