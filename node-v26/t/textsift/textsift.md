# textsift

> 标签: bpe, browser, ner, openai, pii, privacy, privacy-filter, redaction, token-classification, tokenizer, wasm, webassembly, webgpu

## 简介

Local-first PII detection + redaction running openai/privacy-filter on-device. Same engine in browser (WebGPU), Node native (Metal/Vulkan/Dawn), CLI, pre-commit hook, and GitHub Action.
