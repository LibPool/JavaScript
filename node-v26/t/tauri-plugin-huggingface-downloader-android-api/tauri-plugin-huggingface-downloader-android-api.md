# tauri-plugin-huggingface-downloader-android-api

> 标签: android, downloader, huggingface, kotlin, model-downloader, rust, tauri, tauri-plugin, whisper

## 简介

A lightweight Tauri 2.0 Android plugin for downloading large files from Hugging Face repositories. Features real-time progress tracking via optimized callbacks, background thread execution, and safe stream management for high-performance model handling.
