# timmz

> 标签: JavaScript

## 简介

Compteur du temps écoulée dans exécution d'un projet la première fonction "timespent" est un compteur basé sur l'horodatage qui permet d'enregistrer le temps écoulé entre l'ouverture du serveur et sa fermeture ensuite il enregistre le temps dans un fichie
