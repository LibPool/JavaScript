# ts-interpreter.js

> 标签: cli, compiler, eval, evaluate, evaluator, interpreter, javascript, js, runtime, ts, ts-compiler, ts-interpreter, ts-runtime, tsi-cli, typescript, typescript compiler, typescript interpreter, typescript runtime

## 简介

This package will allow you to use `require` on any `.ts` files from any `.js` files using our runtime compiler!
