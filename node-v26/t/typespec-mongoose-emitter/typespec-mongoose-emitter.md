# typespec-mongoose-emitter

> 标签: JavaScript

## 简介

This package contains a Mongoose emitter and decorators for TypeSpec. The emitter generates Mongoose-specific code based on TypeSpec models, while the decorators provide additional functionality for customizing the generated code.
