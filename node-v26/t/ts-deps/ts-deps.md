# ts-deps

> 标签: Build-Pipeline, Dependencies, TypeScript

## 简介

TypeScript related dependencies and libraries to setup/scaffold typical build/lint/format/test pipeline and CI/CD pipeline using babel, jest, prettier, eslint and semantic-release. Meant to be added as dev dependency.
