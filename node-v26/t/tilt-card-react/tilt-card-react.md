# tilt-card-react

> 标签: 3d, animation, card, device-orientation, glare, gyroscope, hover, microinteraction, parallax, perspective, react, react-hook, reduced-motion, tilt, ui, zero-dependency

## 简介

3D parallax tilt for React — pointer tilt with glare and depth layers on desktop, gyroscope tilt on mobile. A tiny hook + card component, zero dependencies, React 18 & 19.
