# thoughtml

> 标签: argumentation, cli, command-line-utilities, dsl, parser, parser-implementations, reasoning, text-processing

## 简介

A plain-text language for reasoning you can check — reference parser and CLI toolchain (check, fmt, explain, diff, guide, stream, and the mirror).
