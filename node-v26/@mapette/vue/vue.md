# @mapette/vue

> 标签: bottom-sheet, cluster, map, maplibre, maplibre-gl, photo, pilgrimage, popover, vue

## 简介

Vue 3 components for @mapette/core: MapView, MapExplorer (full-screen map with side panel / bottom sheet), MapFooter, photo pins and popovers.
