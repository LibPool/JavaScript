# @wilsonguenther/queryguard

> 标签: error-tracking, instrumentation, monitoring, nextjs, observability, postgrest, rls, sdk, supabase, typescript

## 简介

Drop-in observability SDK for Supabase apps. Catches silent failures, RLS 403s, slow queries, and regressions — by Wilson Guenther.
