# perfume-database

> 标签: chatgpt, claude, fragrance, fragrance api, mcp, mcp server, model-context-protocol, perfume, perfume api, perfume database, perfume mcp, perfume-notes, scento

## 简介

Scento Perfume API: a free perfume and fragrance API and MCP server over Scento's verified perfume database. Perfume portraits, notes, raw materials, houses and families, every answer tied to a page on scento.com. No key, no account.
