# @divvi/mcp-server

> 标签: ai, anthropic, assistant, blockchain, claude, copilot, cursor, divvi, integration, javascript, mcp, mcp-server, model-context-protocol, referral, sdk, typescript, web3

## 简介

A Model Context Protocol (MCP) server that enables AI assistants to automatically integrate the @divvi/referral-sdk into JavaScript/TypeScript blockchain applications.
