# @keith9681/dsh-sidebar

> 标签: JavaScript

## 简介

DSH web plugin: a VSCode-like right sidebar (explorer / editor / terminal / git / browser), isolated per conversation session. Exposes a service for other plugins to register sidebar tabs and file viewers. Fork of dsh-better-sidebar with read-only-by-defa
