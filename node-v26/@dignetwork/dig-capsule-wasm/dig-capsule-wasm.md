# @dignetwork/dig-capsule-wasm

> 标签: JavaScript

## 简介

DIG read-crypto for the browser and Node: URN reconstruction, AES-256-GCM-SIV decryption, and merkle inclusion-proof verification, compiled to WebAssembly. The published, installable form of the dig-capsule-wasm crate (roadmap #16 — stop vendoring).
