# @makerx/verify

> 标签: ai, back-pressure, cli, code-quality, complexity, knip, maintainability, typescript, verification, verify

## 简介

A growing collection of code verifications that give AI coding agents back-pressure against writing hard-to-maintain code. Ships a CLI that orchestrates native + external checks by convention, plus a scaffolder for the checks and agent commands.
