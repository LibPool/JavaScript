> 标签: content-editor, editor-sdk, html-editor, json-first, markdown-editor, react, react-rich-text-editor, readonly-renderer, rich-text-editor, tiptap, tiptap-react, wysiwyg

## 简介

React Rich Text Editor for Tiptap with a batteries-included, JSON-first editor SDK, built-in UI, readonly rendering, and HTML/Markdown import-export.
