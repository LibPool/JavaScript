# @kutlaytunc/us3-core

> 标签: barycentric, delaunay, math, navprovider, r3f, react-three-fiber, us3, weightsolver

## 简介

The shared foundation for us3: pure in-house math (scalar helpers, 1D bracketing, 2D Delaunay barycentric) plus the two swap interfaces — NavProvider (navmesh-agnostic AI) and WeightSolver (drei-swappable blend layer). Zero runtime dependencies.
