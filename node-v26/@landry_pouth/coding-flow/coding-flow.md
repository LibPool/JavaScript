# @landry_pouth/coding-flow

> 标签: agents, ai, claude-code, evidence, governance, workflow

## 简介

AI-native engineering workflow that makes Claude Code reliable on real projects: plan, implement, and verify with executed proof that the tests actually ran and passed — not the agent's word. Optional evidence & audit layer for teams that need governance.
