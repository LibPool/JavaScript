# @signalgate/nextjs

> 标签: antifraud, fingerprint, nextjs, react, sdk, signalgate

## 简介

SignalGate antifraud frontend SDK wrapper for Next.js / React — a "use client" provider + hook that loads the pinned browser fingerprint SDK from the CDN and hands back a never-throws getPayload()
