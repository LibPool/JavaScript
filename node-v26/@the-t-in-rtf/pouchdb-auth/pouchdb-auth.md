# @the-t-in-rtf/pouchdb-auth

> 标签: auth, authentication, couch, couchdb, pouch, pouchdb, users

## 简介

A PouchDB plug-in that simulates CouchDB's authentication daemon. Includes a users db that functions like CouchDB's.
