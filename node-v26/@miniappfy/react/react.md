# @miniappfy/react

> 标签: JavaScript

## 简介

React runtime for [MiniAppfy](https://docs.miniappfy.dev) mini-apps — re-exports the React hooks and types the platform provides at runtime (`useState`, `useEffect`, `useRef`, …).
