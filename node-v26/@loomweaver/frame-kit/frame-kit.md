# @loomweaver/frame-kit

> 标签: custom-elements, design-tokens, frame-plugin, iframe, loomweaver, web-components

## 简介

LoomWeaver: open-source plugin platform for Angular workbenches. The frame kit: the <lw-*> custom elements, the compiled .lw-* class contracts and Penpal, served as static assets to sandboxed iframe plugins.
