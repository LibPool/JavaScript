# @fairco.in/core

> 标签: bip32, bip39, bip44, bitcoin-fork, cryptocurrency, faircoin, hd-wallet, multisig, p2sh

## 简介

FairCoin protocol primitives: HD wallets, transactions, P2PKH + P2SH multisig scripts, address encoding. Pure TypeScript, no React Native.
