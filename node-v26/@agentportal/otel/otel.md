# @agentportal/otel

> 标签: agent, agentportal, ai, cli

## 简介

OpenTelemetry bridge for agentportal: turns diagnostics_channel runs/events/usage into OTel spans following GenAI semantic conventions. @opentelemetry/api is a peer dependency.
