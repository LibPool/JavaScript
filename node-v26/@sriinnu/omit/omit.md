# @sriinnu/omit

> 标签: agent-skill, ai, claude-code, code-quality, coding-agent, cursor, minimalism, pre-commit, secrets-detection

## 简介

Omit needless code. Editorial discipline for AI coding agents: draft less, cite everything, cut last: enforced by hooks, a pre-commit gate, and a PR bot, whatever agent writes the code.
