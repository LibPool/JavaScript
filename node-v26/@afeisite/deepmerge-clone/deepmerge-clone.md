# @afeisite/deepmerge-clone

> 标签: clone, copy, deep, deepmerge, extend, merge, prototype-pollution, recursive, security

## 简介

A fork of deepmerge for deep (recursive) merging of JavaScript objects, with the prototype pollution vulnerability (CVE-2022-25883) fixed
