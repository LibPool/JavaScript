# @genready/mcp-server

> 标签: ai-readiness, ai-search, claude, cursor, genready, geo, llms-txt, mcp, model-context-protocol, website-analysis

## 简介

GenReady MCP server: scan websites for AI readiness and get a fix checklist your coding agent can act on, from Claude Desktop, Claude Code, Cursor, Windsurf or any stdio MCP client.
