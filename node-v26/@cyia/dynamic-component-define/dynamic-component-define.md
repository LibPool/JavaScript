# @cyia/dynamic-component-define

> 标签: JavaScript

## 简介

- 它可以在动态创建组件时(`createComponent`),额外添加指令 - 它允许手动指定投影选择器投影到指定位置 - 它可以动态创建 html 元素并挂载指令
