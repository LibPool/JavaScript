# @standard-search-params/react

> 标签: arktype, hooks, query-params, react, react-hooks, search-params, standard-schema, url, valibot, validation, zod

## 简介

A React hook that reads URL search params and validates them per-key against any Standard Schema-compliant validator (Zod, Valibot, ArkType, ...).
