# @slnknrr/num-im

> 标签: arbitrary-base, arbitrary-precision, base-conversion, bigint, bignum, bit-manipulation, checksum, exact-arithmetic, gcd, modexp, modular-arithmetic, number-theory, numeric, primality, radix, rational, regex, validator

## 简介

Numbers as text, in any base, without lying. Exact string-first arithmetic past 2^53 — bases 2–36 or a custom alphabet, canonical forms, modular arithmetic, number theory, bit metrics, and regex validators.
