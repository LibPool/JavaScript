# @storybloq/storybloq

> 标签: agentic-development, ai-development, claude-code, cli, codex, mcp, openai-codex, project-management, session-continuity, storybloq

## 简介

Project memory for Claude Code and Codex. Storybloq stores tickets, issues, handovers, and lessons in a .story/ folder inside your repo so every session starts where the last one left off. Pairs with the Storybloq Mac app on the App Store.
