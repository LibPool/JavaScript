# @waldrop/sdk

> 标签: blob, decentralized, sdk, seal, storage, sui, waldrop, walrus

## 简介

Read-only TypeScript SDK for Waldrop - list and fetch your Walrus-stored blobs registered through the Waldrop on-chain registry.
