# @dcl/renderer-protocol

> 标签: JavaScript

## 简介

- Add `GOOGLE_PROTOBUF_REFSTRUCT_COMPATIBILITY_MODE` compiler variable to enable compilation without reflection (C# 7.3, or pre-roslyn. May work better for il2cpp pipelines)
