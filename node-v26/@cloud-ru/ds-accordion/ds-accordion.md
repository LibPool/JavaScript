# @cloud-ru/ds-accordion

> 标签: JavaScript

## 简介

Аккордеон дизайн-системы — контейнер Accordion и три уровня раскрываемых блоков CollapseBlock с общими токенами view, backgroundPredefined и chevronPosition.
