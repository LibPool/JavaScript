# @sisylabs/plugin-todo

> 标签: sisyphus, sisyphus-plugin, task-manager, todo

## 简介

Sisyphus reference plugin: rule-based todo manager. Stores tasks in plugin storage, exposes a side-region task-list view and matching card type.
