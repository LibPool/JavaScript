> 标签: emoji, emoji-keyboard, emoji-picker, expo, fabric, flashlist, new-architecture, react-native, reaction-picker, web

## 简介

Universal (iOS · Android · Web), New-Architecture-first emoji keyboard & reaction picker for React Native and Expo. Bundled Emoji 17.0 data, FlashList v2, deep theming, first-class web parity — one package, no extra data dependency.
