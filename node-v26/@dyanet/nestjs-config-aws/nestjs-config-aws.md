# @dyanet/nestjs-config-aws

> 标签: aws, aws-integration, config-factory, config-module, configuration, configuration-management, environment-variables, integration, nestjs, nestjs-config, parameter-store, secrets-manager, ssm, typescript, zod

## 简介

AWS-integrated configuration management for NestJS applications with support for environment variables, AWS Secrets Manager, and AWS Systems Manager Parameter Store. Provides an injectable ConfigService and an awsConfigLoader factory for @nestjs/config.
