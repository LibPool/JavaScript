# @ycstudios/token-tab

> 标签: ccusage, claude, claude-code, macos, menubar, tokens, usage

## 简介

Claude Code and Codex usage in the macOS menu bar. Reads the local logs; nothing leaves your machine — no network calls, no content read, and you can verify both.
