# @gonk/tool-registry-mcp

> 标签: JavaScript

## 简介

MCP adapter — exposes a ToolRegistry or Orchestrator over the Model Context Protocol, over stdio or (via the @gonk/tool-registry-mcp/http subpath) streamable-HTTP for remote clients.
