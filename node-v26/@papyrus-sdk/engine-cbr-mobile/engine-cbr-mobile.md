# @papyrus-sdk/engine-cbr-mobile

> 标签: cbr, comic, mobile, papyrus, rar, react-native

## 简介

Assets opcionais para habilitar CBR no `MobileDocumentEngine` sem adicionar o worker/WASM do libarchive ao pacote base de UI React Native. O HTML/runtime continua vindo de `@papyrus-sdk/ui-react-native`; este pacote não o duplica.
