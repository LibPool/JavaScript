# @madenowhere/phaze-language-tools

> 标签: JavaScript

## 简介

Language services for .phaze files. Volar-based language plugin + language server, used by the phaze VSCode extension and (eventually) by `phaze check` for headless type-checking. Same pattern as @astrojs/language-server and @vue/language-server.
