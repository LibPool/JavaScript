# mgi-mind

> 标签: ai-agents, knowledge-graph, mcp, mcp-server, memory, qdrant

## 简介

Local memory server for AI agents over MCP: hybrid search, a fact graph with a duel rule, quarantine and a hash-chained audit log. Installs the prebuilt mgimind binary.
