# @postman/postman-plugin

> 标签: agent-plugin, claude-code, codex, cursor, factory.ai, kimi, opencode, pi, pi-package, postman

## 简介

Postman's API engineering skills for coding agents: a Pi package, and an npx installer that sets up Claude Code, Codex, Cursor, Kimi Code, Factory Droid, OpenCode and Pi.
