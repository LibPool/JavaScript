# @uixerbhx/chat-sdk

> 标签: admin, api, chat, livechat, nextjs, react, vite, webhook, widget

## 简介

JavaScript SDK for LiveChat: the widget for React / Next.js and any framework, a server helper for identity hashes, and a typed admin API client with webhook signature verification.
