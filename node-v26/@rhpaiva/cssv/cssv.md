# @rhpaiva/cssv

> 标签: css, cssv, csv, custom-element, llm, spreadsheet, styled-table, table, web-component

## 简介

A table's data and its look in one plain-text file: CSV with a CSS style block on top. Reference implementation of CSSV v1 (Comma-Separated Styled Values) and the <cssv-table> element.
