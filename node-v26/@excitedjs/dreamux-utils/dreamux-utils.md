# @excitedjs/dreamux-utils

> 标签: JavaScript

## 简介

Pure shared utilities for Dreamux providers and host: neutral config-validation primitives, OS/filesystem helpers, and completion-body resolution. Depends on nothing: not on @excitedjs/dreamux core, and not on @excitedjs/dreamux-types, which is the type s
