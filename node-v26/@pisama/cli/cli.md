# @pisama/cli

> 标签: agents, ai, atif, failure-detection, harbor, mcp, observability, vercel-ai-sdk

## 简介

CLI for Pisama. `init` patches your project, `verify` round-trips a verification trace, `mcp` runs the MCP server, `analyze-atif` runs Pisama detectors on Harbor trajectories (locally via --local, or against the hosted API).
