# @pisama/sdk

> 标签: agent, ai, ai-sdk, failure-detection, observability, tracing, vercel

## 简介

Catch silent failures in your AI agents. TypeScript SDK for Pisama, the failure detector for vibe-coded agents (Cursor, Claude Code, LangGraph, Vercel AI SDK).
