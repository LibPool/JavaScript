# @chainplatform/pin

> 标签: @chainplatform/layout, @chainplatform/pin, react, react-device-detect, react-native, react-native-passcode, react-native-pin, react-native-pin-lock, react-native-web

## 简介

A lightweight second-layer security module for React Native / React Native Web. Provides a PIN lock overlay that can be triggered globally, with support for setting/resetting PIN.
