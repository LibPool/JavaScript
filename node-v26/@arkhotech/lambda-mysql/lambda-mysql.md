# @arkhotech/lambda-mysql

> 标签: aws, lambda, mysql

## 简介

Permite mantener una conexión abstracta con la base de datos y consultas de queries con manejo de error al estilo Promise, utiliza 4 variables de entorno para la conexión disponibles en README
