# geogridapi-mcp

> 标签: geogrid, google-business-profile, google-maps, heatmap, local-seo, mcp, mcp-server, model-context-protocol, rank-tracker

## 简介

MCP server for GeoGridAPI: Google Maps geo-grid rank tracking for local SEO (rank heatmaps, competitors, trends, schedules) in Claude, Cursor and any MCP client.
