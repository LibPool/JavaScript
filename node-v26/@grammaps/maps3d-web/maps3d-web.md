# @grammaps/maps3d-web

> 标签: 3d, buildings, gltf, indoor, mahalmaps, map, maplibre, maplibre-gl, three, traffic

## 简介

SDK карты MahalMaps для MapLibre GL: объёмные здания, 3D-объекты, пробки, рельеф, планы этажей, клик по объектам и выделение здания.
