# @narai/aws-agent-connector

> 标签: agent, aws, claude, connector, lambda, rds, s3

## 简介

Read-only AWS connector: Lambda, RDS, S3, DynamoDB, CloudWatch. Built on @narai/connector-toolkit with an approval gate and hardship logging. JSON-envelope CLI + library API.
