# @narai/jira-agent-connector

> 标签: agent, claude, connector, jira

## 简介

Read-only Jira connector: JQL search, issue details, project metadata. Built on @narai/connector-toolkit with an approval gate and hardship logging. JSON-envelope CLI + library API.
