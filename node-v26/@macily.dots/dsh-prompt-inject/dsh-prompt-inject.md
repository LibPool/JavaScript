# @macily.dots/dsh-prompt-inject

> 标签: agent-preset, deepseek-harness, dsh-plugin, persona, prompt-variable

## 简介

DSH plugin: register a configurable prompt variable so agent presets that use complete:true personas (which drop every other system-prompt section) can still receive an injected text block.
