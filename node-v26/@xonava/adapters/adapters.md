# @xonava/adapters

> 标签: adapters, cache, cloudflare-d1, drizzle, express, fastify, framework, hono, mysql, postgresql, server, storage

## 简介

Adapters for the server framework: PostgreSQL, MySQL, and Cloudflare D1 persistence via Drizzle, Express, Fastify, and Hono HTTP bindings, and cache and storage adapters.
