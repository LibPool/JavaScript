# @humanauth/cli

> 标签: JavaScript

## 简介

The official command-line interface for [HumanAuth](https://humanauth.ai). Manage tenants, humans, groups, webhooks, receipts, and devices — and verify receipt JWS payloads offline with the bundled `@humanauth/verifier`.
