# streamotter

> 标签: browser, gateway, kafka, live-data, realtime, socket.io, state-sync, streamotter, typescript, websocket

## 简介

StreamOtter in one install: the CLI and local workbench, the Node.js gateway, and the browser SDK, for live Kafka state in the browser that is either verifiably live or visibly stale.
