> 标签: accessibility, animation, cairn, cairnjs, command-palette, data-table, form-validation, overlays, reactive, signals, state-management, ui-framework, web-components, zero-dependencies

## 简介

Zero-dependency, high-performance UI framework with fine-grained reactivity, granular modular imports, zero shared runtime, complete motion suite, declarative form validation, and overlays.
