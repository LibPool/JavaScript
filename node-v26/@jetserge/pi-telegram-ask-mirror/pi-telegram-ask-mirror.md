# @jetserge/pi-telegram-ask-mirror

> 标签: ask-user-question, human-in-the-loop, pi-extension, pi-package, telegram

## 简介

Mirrors Pi's ask_user_question questionnaire onto Telegram inline keyboards while keeping the local TUI overlay live. First surface to answer wins.
