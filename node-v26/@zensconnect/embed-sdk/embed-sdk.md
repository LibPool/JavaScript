# @zensconnect/embed-sdk

> 标签: JavaScript

## 简介

ZensConnect embed SDK: vanilla ZensConnect.init() iframe controller (React-free root entry) plus the <ZensConnectMeeting/> React component at @zensconnect/embed-sdk/react. Legacy ZensZoom.* / <ZensZoomMeeting/> names kept as back-compat aliases. embed.js
