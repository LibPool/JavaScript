# @archont561/bun-test-utils

> 标签: bdd, bun, bun-test, fixtures, playwright, property-based-testing, snapshot-testing, test-utils, testing

## 简介

General-purpose test extension for the Bun test runner covering unit, integration, and e2e tests — Playwright-style typed fixtures composed with test.extend(), with scopes and LIFO teardown, plus BDD, property-based testing, snapshots, HTTP record/replay,
