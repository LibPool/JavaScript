## 简介

免费开源的天地图 JS API 4.0 轻量封装：核心层（纯地图能力）+ 组件层（开箱即用的搜索面板/工具栏），PC / H5 通用，React / Vue 可用，样式已内联无需单独引入 CSS，高德/百度地图的免费替代方案
