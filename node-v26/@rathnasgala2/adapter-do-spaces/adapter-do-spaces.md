# @rathnasgala2/adapter-do-spaces

> 标签: JavaScript

## 简介

Managed DigitalOcean Spaces deployment adapter: two-bucket website binding, exact SigV4 request catalog, private generation-prefixed staging, replace-in-place activation with a marker-last pointer write, and credential-free public verification.
