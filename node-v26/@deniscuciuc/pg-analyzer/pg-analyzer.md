# @deniscuciuc/pg-analyzer

> 标签: analyzer, cli, database, dba, devops, indexes, performance, postgres, postgresql, slow-queries

## 简介

CLI tool that analyzes PostgreSQL databases for performance issues — indexes, slow queries, table bloat, connections and cache health.
