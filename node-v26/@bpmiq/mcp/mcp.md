# @bpmiq/mcp

> 标签: bpm, bpmn, dmn, mcp, model-context-protocol, process-documentation

## 简介

Read-only MCP server exposing a BPM content repo's processes — discovered from bpmiq.yml, derived from the BPMN — to any MCP client.

- 源码仓库：git+https://github.com/Miragon/bpm-iq.git
