# dsh-plugin-ecustcic-quota

> 标签: deepseek-harness, dsh-plugin, ecustcic, modelgate, quota, sidebar

## 简介

在 DSH 侧边栏显示 ecustcic（ai.ecustcic.com）的周期配额：每个受限维度一行进度条，数字与重置倒计时放在悬停提示里；密钥自动复用已指向该站点的模型供应商，无需额外配置。
