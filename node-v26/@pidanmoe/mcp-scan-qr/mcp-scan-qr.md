# @pidanmoe/mcp-scan-qr

> 标签: fastmcp, mcp

## 简介

这是一个基于 [FastMCP](https://github.com/fastmcp/fastmcp) 框架构建的 MCP (Model Context Protocol) 工具包，用于从图像中扫描二维码。
