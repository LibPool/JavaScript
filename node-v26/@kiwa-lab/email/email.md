# @kiwa-lab/email

> 标签: aws-ses, email, kiwa, mock, postmark, resend, sendgrid, testing

## 简介

Email provider mock harness for kiwa — Resend / SendGrid / Postmark / AWS SES を統一 interface で invoke する in-process mock。 send / template render / delivery event / bounce / webhook signature verify までを real provider と同じ signature で叩ける test infra。
