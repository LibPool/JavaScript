# @kiwa-lab/go-lib

> 标签: chi, echo, fiber, gin, go, kiwa, mock, testing

## 简介

Go web framework mock harness for kiwa — gin / echo / fiber / chi を統一 interface で invoke する in-process mock。 handler dispatch / middleware chain / request-response cycle / route matching を Go 実 framework の signature を再現した TypeScript test infra で叩く。
