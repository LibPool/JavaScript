# @kiwa-lab/date

> 标签: date, date-fns, dayjs, kiwa, luxon, mock, temporal, testing

## 简介

Date arithmetic + format mock harness for kiwa — date-fns / dayjs / Luxon / Temporal を統一 interface で invoke する in-process mock。 addDays / diffDays / formatDate / parseDate / timezoneConvert を real provider と同じ signature で叩ける test infra。
