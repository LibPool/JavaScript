# @kiwa-lab/notification

> 标签: apns, fcm, in-app, kiwa, mock, notification, push, sms, sns, testing, twilio

## 简介

Notification provider mock harness for kiwa — FCM / APNs (push) / Twilio (SMS) / AWS SNS を統一 interface で invoke する in-process mock。 sendPush / sendSMS / sendInApp / multi-channel dispatch / delivery event を real provider と同じ signature で叩ける test infra。
