# @kiwa-lab/trpc

> 标签: kiwa, middleware, mock, mutation, procedure, query, router, subscription, testing, trpc, trpc-v10, typed-client

## 简介

tRPC endpoint mock harness for kiwa — router / procedure (query / mutation / subscription) / middleware chain / typed client を in-process mock で invoke する。 real tRPC v10 と同じ signature で叩ける test infra、 context injection / middleware error propagation / typ
