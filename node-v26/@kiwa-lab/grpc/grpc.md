# @kiwa-lab/grpc

> 标签: connect-rpc, grpc, grpc-js, kiwa, mock, nice-grpc, protobuf, stream, testing, twirp, unary

## 简介

gRPC service mock harness for kiwa — @grpc/grpc-js / nice-grpc / twirp / ConnectRPC を統一 interface で invoke する in-process mock。 unary / server-stream / client-stream / bidi 全 4 RPC pattern + metadata + status code + deadline を real gRPC と同じ signature で叩ける
