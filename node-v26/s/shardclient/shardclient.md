> 标签: API, Discord, JavaScript, Node.js, bot, chat, chatbot, client, development, discord.js, discord.js extension, framework, library, shard, shard-client, shardclient

## 简介

ShardClient is an easy to use discord.js extension that creates a client and handles commands, events, and message components.
