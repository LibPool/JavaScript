# sugar-cubed

> 标签: JavaScript

## 简介

### Features - Structured around squares instead of columns - Dynamically adds another square if content spills over the first(horizontally or vertically) - Simple plugable nav bar - Move from page to page with animated 3d structure (think rubiks cube) -
