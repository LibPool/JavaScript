# sns-simulator

> 标签: JavaScript

## 简介

A library for testing AWS Lambda flows through SNS topics. A very quick project, so there is more that it doesn't do than it does - right now it **only supports Lambdas**, `SNS.createTopic()`, `SNS.publish()` and  `SNS.subscribe()`.
