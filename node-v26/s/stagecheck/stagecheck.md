# stagecheck

> 标签: ci, diff, install-scripts, malware, npm, npm-stage, provenance, release, review, security, staged-publishing, supply-chain

## 简介

Review npm releases before they go live: diffs a staged (or any) package version against the last one and flags supply-chain red flags such as new install scripts, credential access, obfuscated code and exfiltration endpoints. Zero dependencies.
