# safebyok-fastkey

> 标签: argon2, argon2id, e2ee, safebyok, vault, wasm, webassembly

## 简介

A WebAssembly key deriver for safebyok: Argon2id through hash-wasm, under the same keyDeriverSpecs and labels as the core's pure-JavaScript deriver, deriving the same bytes.
