# stripe-connect-reckon

> 标签: balance, connect, marketplace, payouts, reconciliation, stripe, stripe-connect

## 简介

Read-only financial-risk monitor for Stripe Connect: flags negative-balance risk, failed payouts, unreconciled refunds and event gaps before they cause damage. Unofficial, not affiliated with Stripe.
