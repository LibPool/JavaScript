# schema-env

> 标签: adapter, ai, ai-assisted, ai-collaborator, ai-developed, ai-enhanced, async, asynchronous, automated-development, config, configuration, dotenv, dotenv-expand, env, environment, extensible, gpt, joi, llm, node, nodejs, process.env, schema, secrets, secrets-management, secure, security, settings, startup, type-safe, typescript, validate, validation, variables, yup, zod

## 简介

Type-safe environment variable validation for Node.js using Zod schemas or custom adapters. Load .env files, expand variables, fetch async secrets, and validate process.env at startup.
