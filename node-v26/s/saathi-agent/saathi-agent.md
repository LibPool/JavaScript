# saathi-agent

> 标签: monitoring, observability, server-saathi, sre

## 简介

Tier 1 companion for Server Saathi — real logs, memory/event-loop metrics, and consented git-revert for any Node/Bun service. Zero inbound access; the agent always dials out.
