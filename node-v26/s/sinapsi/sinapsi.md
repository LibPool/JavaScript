# sinapsi

> 标签: angular, animation, canvas, custom-elements, framework-agnostic, motion, network-graph, plexus, react, ssr, svelte, vue, web-components

## 简介

A framework-agnostic, SSR-safe Web Component that renders an animated 3D network graph with a configurable palette, motion, and semantic JSON nodes.
