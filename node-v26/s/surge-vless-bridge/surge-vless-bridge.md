# surge-vless-bridge

> 标签: cli, external-proxy, macos, macos-proxy, proxy, reality, sing-box, subscription-converter, surge, surge-mac, vless, vless-subscription, xtls, xtls-rprx-vision

## 简介

Surge Mac VLESS support via sing-box: a Node.js CLI that converts VLESS subscriptions (including REALITY / XTLS Vision nodes) into Surge external proxy entries and policy groups.
