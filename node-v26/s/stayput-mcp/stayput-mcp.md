# stayput-mcp

> 标签: exif, local, mcp, mcp-server, merge-pdf, model-context-protocol, pdf, privacy

## 简介

Local MCP server for PDF and photo tasks: merge, split, rotate, number, images to PDF, inspect and strip photo metadata. Files never leave your machine.
