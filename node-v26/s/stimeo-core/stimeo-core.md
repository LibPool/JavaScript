# stimeo-core

> 标签: hotwire, rails, stimeo, stimeo-ui, stimulus

## 简介

Alias of stimeo-ui — the open-source (Core) component set of Stimeo UI. Prefer stimeo-ui; this package reserves the Core name and re-exports the real library.
