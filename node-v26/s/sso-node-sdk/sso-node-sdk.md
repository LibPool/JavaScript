# sso-node-sdk

> 标签: jwks, jwt, oauth2, oidc, pkce, sdk, sso

## 简介

Portable SSO relying-party SDK for Node.js — OIDC/OAuth 2.0 authorization code + PKCE, fail-closed local JWT validation via JWKS (RS256-only, kid allowlist, cannot be silently disabled)
