# sirdas

> 标签: anonymization, cli, llm, markdown, mcp, ocr, pdf, privacy, scanned-pdf

## 简介

Sırdaş CLI: PDF→Markdown for AI, local PII anonymization and PDF tools that never upload your files. Also launches the local MCP server (sirdas mcp).
