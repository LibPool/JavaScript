# solid-countup

> 标签: animation, count-up, counter, countup, intl, number, solid-js, solidjs

## 简介

A Solid component that animates a number from one value to another — a take on CountUp.js that renders declaratively, follows props reactively, and formats through Intl.NumberFormat.
