# sandboxbox

> 标签: claude-code, cli-tools, cross-platform, environment-isolation, linux, macos, npm, npx, playwright, portable, process-isolation, sandbox, windows

## 简介

Lightweight process containment sandbox for CLI tools - Playwright, Claude Code, and more. Pure Node.js, no dependencies.
