# supabase-security-mcp

> 标签: audit, claude, cursor, mcp, model-context-protocol, postgres, rls, row-level-security, security, supabase

## 简介

MCP server that audits a Supabase project's security from Claude, Cursor or any MCP client: anon-key probe, RLS policy audit, and a two-account cross-tenant test.
