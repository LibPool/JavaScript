# shuibao-water-history-skill

> 标签: agent-skill, conversation-history, customer-service, juxieyun, shuibao

## 简介

Agent skill：水宝会话历史数据直连查询（钉钉水宝 / 网页水宝全平台），覆盖会话列表、对话详情与消息；所有接口返回落盘、stdout 只回摘要，批量导出一个会话一个文件，避免大 JSON 撑爆上下文或无法打开
