# scriptex

> 标签: latex, pdf, screenplay, txt

## 简介

Turns screenplays as plain text files into LaTeX files using the excellent screenplay LaTeX class, found at http://www.ctan.org/tex-archive/macros/latex/contrib/screenplay.
