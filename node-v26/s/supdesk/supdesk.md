# supdesk

> 标签: api, changelog, client, cloudflare-workers, deno, edge, feedback, helpdesk, sdk, server-side, supdesk, waitlist

## 简介

Server-side TypeScript client for the SupDesk API. Runs in Node, Deno, Bun, and Cloudflare Workers. Not for browser use — the API key is a secret.
