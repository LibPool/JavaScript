# sharesecure-mcp

> 标签: claude, codex, end-to-end-encryption, file-sharing, mcp, model-context-protocol

## 简介

Local MCP server for ShareSecure: assistants share and receive files end to end encrypted on your own computer, without the file or its key passing through the AI or the server
