# sass7in1-scaffold

> 标签: cli, nextjs, react, sass, sass-architecture, scaffold, scss, vite

## 简介

CLI tool to scaffold a robust Sass 7-in-1 architecture with best practices for Next.js, React, and Vite React projects, including automatic setup of folder structure, Sass partials, and main stylesheet imports.
