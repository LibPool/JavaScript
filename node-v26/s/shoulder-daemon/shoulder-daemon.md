# shoulder-daemon

> 标签: advisor, context, facts, hooks, memory, opencode, opencode-plugin

## 简介

Context advisor for coding agents. Watches the session over HTTP hooks, keeps a store of facts, and injects the relevant ones back in when they matter. Starts the daemon itself; nothing else to install.
