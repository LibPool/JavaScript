# simdjson.cxx

> 标签: cxx, high-performance, json, library, parser, simdjson

## 简介

Parsing gigabytes of JSON per second : used by Facebook/Meta Velox, the Node.js runtime, ClickHouse, WatermelonDB, Apache Doris, Milvus, StarRocks; Daniel Lemire (2018).
