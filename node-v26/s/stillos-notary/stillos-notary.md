# stillos-notary

> 标签: agent, agent-payments, bankruptcy, distress, mcp, notary, ofac, sanctions-screening, sec-edgar, signed-receipt, trust, usdc, verification, x402

## 简介

Programmatic attestation infrastructure for backend and institutional integration. Submit a claim via a single HTTP call; receive a cryptographically signed (Ed25519), independently verifiable verdict settled against real external ground truth — on-chain
