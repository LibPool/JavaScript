# stockportfolio-mcp

> 标签: claude, cursor, edgar, filings, financial-data, financial-statements, mcp, mcp-server, model-context-protocol, sec

## 简介

MCP server for filing-grounded US stock data — financials, SEC filing timelines, comparisons and fund profiles, every value with the URL of the filing it came from.
