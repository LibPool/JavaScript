# soul-prefetch

> 标签: cache deduplication, concurrent control, performance, prefetch, spa, vite

## 简介

在用户导航到指定的路由后，在浏览器空闲时，利用并发控制(默认最多同时进行3个prefetch)预请求可能需要的资源，从而加速后续页面的加载
