# soap-asanak-sms

> 标签: Asanak, NodeJS, SMS, SOAP

## 简介

Node.js library to send SMS via the Asanak SOAP API, not based on any third-party network libraries and does not use any SOAP library; it handles all requests and responses purely with raw Axios HTTP calls.
