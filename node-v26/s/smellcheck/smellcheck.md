# smellcheck

> 标签: ai, ai-slop, copyediting, editing, llm, prompts, prose, smell-check, style-guide, voice, writing

## 简介

Smell-check your prose. Installable writing rule set for AI agents that sprays the performative, faux-profound register off prose. Core bans, smell audit, claims review, genre overlays. Prose, not code smells.
