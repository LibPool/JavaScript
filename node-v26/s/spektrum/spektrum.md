# spektrum

> 标签: data-binding, declarative, esm, history, no-dependencies, reactive, state-management, time-travel, tiny, ui

## 简介

Tiny reactive engine with HTML bindings and time-travel. ~13kB minified, zero runtime deps, agent-native.
