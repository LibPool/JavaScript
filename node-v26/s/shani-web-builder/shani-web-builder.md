# shani-web-builder

> 标签: bootstrap, cli, project-generator, scaffolder, sveltekit

## 简介

Bootstrap a new Shani web app with the canonical SvelteKit + Tailwind v4 + TypeScript setup: sv create, canonical configs, workspace packages, all wired up.
