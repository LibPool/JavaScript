# shellosort

> 标签: 2018, array, binary, bitonic, gap, math, shellsort

## 简介

ShellOsort uses the cuts 1, 1, 3, 12, 64, 405, 3312, 44370, 2209839, 623492664 and insertion sort to sort sub-arrays which match for the different cuts
