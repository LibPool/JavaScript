# shadcn-token-bridge

> 标签: claude-code, css-variables, design-tokens, oklch, shadcn, tailwind, tailwindcss, theme

## 简介

Turn raw design tokens into a correct shadcn/ui + Tailwind v4 theme — without the spacing, radius, shadow and type drift.
