# smtp-checker

> 标签: cli, diagnostics, email, mail, smtp, smtp-check, smtp-test, starttls, tls, zero-dependency

## 简介

Zero-dependency CLI to verify SMTP settings: connection, TLS, authentication and a test message. Presets for Gmail, Yandex, Mail.ru, Outlook, SES and other providers.
