# secenv-cli

> 标签: cli, devops, dotenv, env, environment-variables, git, github-actions, secrets, secrets-manager

## 简介

Zero-dependency CLI to manage environment secrets from a central private Git repository. Generates .env files, resolves shared secrets, and syncs to GitHub Actions.
