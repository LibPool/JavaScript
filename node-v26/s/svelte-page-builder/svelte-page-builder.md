# svelte-page-builder

> 标签: cms, drag-and-drop, editor, no-code, page-builder, ssr, svelte, svelte5, sveltekit, visual-editor

## 简介

A Svelte 5 page builder with a drag-and-drop Studio editor, prebuilt and custom components, custom fields, and an isomorphic (SSR/SSG/CSR) runtime renderer.
