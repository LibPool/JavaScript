# ssh-backend-mcp

> 标签: backend, codex, mcp, opencode, remote, server, sftp, ssh, trae

## 简介

MCP server that lets AI agents (opencode / codex / Trae) read, write and run commands on a remote SSH server, so backend code lives on the server while frontend stays local.
