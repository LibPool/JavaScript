# semkeep

> 标签: claude, code-search, embeddings, mcp, semantic-search

## 简介

Semantic + structural code intelligence for AI agents, as a local MCP server: find code by meaning, jump to definitions, see who-calls-what, with auto-fresh indexing and notes anchored to symbols. Offline-capable, no API key.
