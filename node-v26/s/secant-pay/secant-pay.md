# secant-pay

> 标签: base, checkout, crypto-payments, payments, secant, solana, solana-pay, stablecoin, usdc, x402

## 简介

Multichain USDC payment SDK for Secant Pay — hosted Solana + Base rail, embeddable checkout, agent (x402) payments, and a self-hosted Base gateway.
