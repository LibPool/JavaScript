# skillpass

> 标签: agent, ai, claude-code, cli, codex, skill-passport, skills

## 简介

Validation-first installer for AI agent skills: search the SkillPass directory, inspect a skill's passport, and install hash-verified skills and packs for Claude Code, Codex, and more.
