# savingslast-mcp

> 标签: 72t, chatgpt, claude, cursor, finance, mcp, mcp-server, model-context-protocol, retirement, retirement-calculator, rmd, roth-conversion, sepp, social-security

## 简介

MCP server for savingslast.com: retirement drawdown, IRS 72(t) SEPP, RMD, Roth conversion, Social Security and state-tax calculators, plus search over every page. Zero dependencies.
