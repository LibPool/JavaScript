# skillpack-cli

> 标签: agentic-workflows, agents, ai, ai-agents, assistant, boilerplate, chatgpt, claude, cli, copilot, cursor, cursorrules, developer-experience, laravel, nextjs, prompt-engineering, scaffold, skills, tooling

## 简介

CLI interativo para inicializar, gerenciar e atualizar a estrutura de agentes de IA (.agents/AGENTS.md e SKILL.md) no seu projeto. Padronize instruções para Claude, Cursor, Copilot, ChatGPT com suporte a múltiplos frameworks como Next.js e Laravel.
