# star-cloud-uni

> 标签: JavaScript

## 简介

星云SDK-Uni版是一款专为Uniapp开发者打造的智能锁SDK，旨在简化与智能锁与星云平台的交互。通过封装底层操作，使接入者无需关注锁的操作逻辑，能够将更多精力集中在业务开发中。
