# sippreep

> 标签: JavaScript

## 简介

HF文件作为BIMViewer标准格式文件，支持2d/3d。 BIMViewer 组件是由 Sippreep.Initializer、Sippreep.Viewing、Sippreep.Extensions 三个模块组成，最终目标是为开发者简化对 BIMViewer 组件的初始化过程，只需一个主入口文件即可。
