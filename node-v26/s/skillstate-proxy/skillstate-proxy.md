# skillstate-proxy

> 标签: agent, anthropic, context-management, llm, long-horizon, openai-compatible, prompt-compression, proxy, skillstate, token-savings

## 简介

Drop-in token-savings proxy for long-horizon LLM agents. Cuts prompt tokens 60-95% via SKILL.state structured state (arXiv:2608.26263, EMNLP 2026). Model-agnostic: works with OpenAI, Anthropic, Venice, OpenRouter, vLLM, Ollama, any OpenAI-compatible upstr
