# swarm-harness

> 标签: acp, agent, ai, ai-agent, anthropic, claude, claude-agent-sdk, cli, codex, coding-agent, multi-agent, openai, orchestration, swarm, tui

## 简介

Multi-agent coding agent CLI: one agent is a tool, N coordinated agents are the product. Built on Anthropic's Claude Agent SDK with swarm/team orchestration, multi-provider support, and a Bun-native interactive TUI.
