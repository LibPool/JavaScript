# soft-cache

> 标签: cache, cache timeout, caching, map timeout, soft cache, soft map, timed cache, timed map, week cache, week map

## 简介

A soft cache, key value pair,for node that contains a timeout on how long things stay on cache, default size is 1000 elements and 60 minutes to timeout
