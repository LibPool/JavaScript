# sently

> 标签: aws-ses, brevo, bun, channel-first, cloudflare-workers, deno, dkim, edge, email, esm, fcm, hostinger, mailer, mailgun, messaging, nodemailer, nodemailer-alternative, oauth2, postmark, push, resend, runtime-agnostic, sendgrid, ses, sms, smtp, transactional-email, twilio, web-push, whatsapp, zero-dependencies

## 简介

Runtime-agnostic channel-delivery library for Node.js, Bun, Deno, and Cloudflare Workers. One sender shape, one error model, and one retry path across email, SMS, WhatsApp, and push — with pluggable provider transports.
