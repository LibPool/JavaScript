# sy-validator

> 标签: JavaScript

## 简介

``` function validateEmail(emailValue, pattern) {   if(emailValue.match(pattern)) {     return true   } else {     return false   } } ``` * emailValue - will take the value of the input * pattern - accepts regular expressions
