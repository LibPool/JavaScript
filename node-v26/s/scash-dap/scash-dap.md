# scash-dap

> 标签: bitcoin, blockchain, dap, data, onchain, protocol, scash, storage

## 简介

**Scash-DAP** 是一种轻量级、无状态、抗审查的链上数据存储协议。它利用比特币（及 Scash）原生 SegWit (P2WSH) 机制，将任意数据伪装成标准的区块链地址，从而实现绕过 `OP_RETURN` 限制的永久数据存证。
