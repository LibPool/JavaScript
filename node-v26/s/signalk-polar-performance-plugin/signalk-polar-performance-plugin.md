# signalk-polar-performance-plugin

> 标签: signalk-category-chart-plotters, signalk-category-instruments, signalk-node-server-plugin, signalk-webapp

## 简介

Calculates live sailing performance from the active polar selected in a polar management plugin (e.g. signalk-polar-management).
