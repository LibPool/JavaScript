# sparkicons

> 标签: angular, font, icon, spark, sparkicons, sparkng, sparkuix, svg, ui

## 简介

SparkIcons - free MIT-licensed icon font (314+ icons) for SparkNG (Angular), SparkUIX and any web project. CSS + fonts only, no framework dependency.
