# super-tinypng-pro

> 标签: compress, tinypng

## 简介

优化了super-tinypng 1. 使任务具有持续重试的功能   2. 将成功压缩的原始文件进行了删除，以区分哪些文件还没有成功被压缩   3. 优化了输出的日志提示
