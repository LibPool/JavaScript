# solid-route-progress

> 标签: loading-bar, loading-indicator, navigation, navigation-api, nprogress, progress, progress-bar, route-progress, solid, solid-router, solid-start, solidjs, solidstart, tailwindcss, top-loader

## 简介

Route progress bar for SolidJS and SolidStart: the thin loading bar along the top of the page. The loading drift is one CSS transition; about 2.8 kB, no dependencies, Tailwind v4 friendly.
