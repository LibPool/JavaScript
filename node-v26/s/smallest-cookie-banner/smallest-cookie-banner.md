# smallest-cookie-banner

> 标签: banner, ccpa, consent, cookie, gdpr, minimal, privacy, smallest, tiny, typescript

## 简介

The smallest legally compliant cookie consent banner. ~7KB gzipped. Auto-detects EU for GDPR, implied consent elsewhere. Scoped Web Components with Shadow DOM.
