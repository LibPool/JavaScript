# systa-mcp

> 标签: ai-agent, claude, mcp, model-context-protocol, systa, talep-takip

## 简介

MCP stdio server for SysTa (Talep Takip Sistemi) — lets AI agents (Claude, Codex) use the SysTa REST API via a scoped API key. Zero npm dependencies (native Node).
