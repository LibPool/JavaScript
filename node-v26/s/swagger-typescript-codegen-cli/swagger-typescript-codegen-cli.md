> 标签: openapi, rest, restful, swagger, swagger-typescript-codegen, typescript

## 简介

## Intro A cli wrapper for [swagger-typescript-codegen](https://github.com/mtennoe/swagger-typescript-codegen). Provides the functionality to generate client ts codes from swagger json|yaml.
