# subswitch

> 标签: ai, anthropic, claude, claude-code, cli, codex, developer-tools, llm, openai, proxy, subagent, subswitch

## 简介

Local subscription-routing proxy for Claude Code — route a single subagent to a different model (OpenAI Codex) while every other request stays on Claude. Per-subagent routing, no API keys.
