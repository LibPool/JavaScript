# specpi-lancet-guard

> 标签: guardrails, lancet, onnx, pi-coding-agent, pi-package, security

## 简介

Local, CPU-only command guard for Pi: the LANCET classifier scores shell calls on your machine, with no API key and no network after a one-time checksum-verified model download
