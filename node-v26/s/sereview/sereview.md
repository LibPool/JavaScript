# sereview

> 标签: claude, claude-code, code-review, diff, pull-request, review, security, static-analysis

## 简介

Deterministic code-review scaffolding for Claude Code: turn a PR diff into a review packet (parse · bundle · rule-match). The host Claude Code session is the reviewer — no API key, no LLM SDK.
