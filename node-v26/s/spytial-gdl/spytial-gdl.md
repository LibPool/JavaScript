# spytial-gdl

> 标签: constraint-layout, diagram, gdl, graph, markdown, mermaid, spytial, visualization

## 简介

A small graph description language (GDL) with inline spatial @annotations, rendered as live Spytial constraint diagrams in Markdown or anywhere.
