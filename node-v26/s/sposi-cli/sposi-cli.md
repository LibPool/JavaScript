# sposi-cli

> 标签: api-client, casamento, cli, marketplace, sposi, wedding, wedding-planning

## 简介

Command-line client for the public SPOSI API (sposi.com.br) — read-only Brazilian wedding-vendor, blog, glossary and platform data.
