## 简介

One command to put your coding agents on Sideren: it finds the agents on your machine, asks for your key and a model, writes each agent's own config and checks it live. Claude Code, Codex, pi, oh-my-pi, ZCode, Hermes, OpenCode, Kilo Code, Aider, Crush, Go
