# spect8-mcp

> 标签: JavaScript

## 简介

Spect8 local MCP server: captures tool events + token usage from Cursor, Codex CLI and Claude Code via passive log tailing + deterministic hooks (no agent cooperation needed), with self-healing install. Posts HMAC-signed batches to the Spect8 ingest API.
