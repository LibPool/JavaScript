# sybase-conn-stream

> 标签: database, java, jtds, sql, sybase

## 简介

Um wrapper node.js simples em torno de um aplicativo java/jconnect que fornece acesso fácil aos bancos de dados Sybase sem ter que instalar odbc ou freetds.
