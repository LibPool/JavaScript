# slc-wp-mcp-bridge

> 标签: ai, blocks, claude, full-site-editing, gutenberg, mcp, model-context-protocol, website-builder, wordpress

## 简介

Design WordPress sites with AI (Claude Code or any MCP client) using native blocks. Build and test locally, then deploy live. Companion connector for the SLC WP MCP Bridge plugin.
