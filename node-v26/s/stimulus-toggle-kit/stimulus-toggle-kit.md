# stimulus-toggle-kit

> 标签: hotwired, stimulus, toggle, turbo

## 简介

A Stimulus controller for dynamic element toggling based on user input. Supports dropdowns, checkboxes, and radio buttons to show or hide elements based on configured data attributes.
