# songphracharoen

> 标签: JavaScript

## 简介

เพิ่มหน้า "ทรงพระเจริญ" เข้าไปในเว็บคุณภายใน 1 นาที โดยไม่ต้องเขียนโค้ดเพิ่ม ลดเวลาพัฒนาเว็บของนักพัฒนารัฐบาลให้ไปทำอะไรที่มีประโยชน์กว่านี้ให้ประชาชน จะได้คุ้มภาษีหน่อย
