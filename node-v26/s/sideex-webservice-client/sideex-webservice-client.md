# sideex-webservice-client

> 标签: Playback, Record, Selenium, SideeX, Test Automation, Web, WebDriver

## 简介

SideeX WebService Client API for NodeJS handles the transfer of test suites to a self-hosted SideeX WebService server and returns the test reports.
