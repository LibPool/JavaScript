# sitepreflight

> 标签: accessibility, audit, checklist, cli, meta-tags, open-graph, pre-launch, seo

## 简介

Pre-launch checklist for websites. Run one command on a URL and see what you forgot: meta tags, social previews, favicon, sitemap, robots.txt, alt text, heading order.
