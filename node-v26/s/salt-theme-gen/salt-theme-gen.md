# salt-theme-gen

> 标签: accessibility, apca, color, color-blindness, color-science, css-variables, dark-mode, design-system, design-tokens, dtcg, generator, nextjs, oklch, palette, perceptual, platform-agnostic, react, react-native, salt, tailwind, theme, tonal-palette, typescript, wcag

## 简介

One color → 150+ design tokens. OKLCH-based theme generator with CSS variables, Tailwind config, DTCG export, APCA contrast, tonal palettes, and color blindness simulation. Zero deps, strict TypeScript.
