# signalk-livedepth-tiles

> 标签: bathymetry, depth, live-depth, signal-k, tiles

## 简介

Shared gridded bathymetry tile algorithm (Web-Mercator XYZ quadtree, sparse codec, min-pool) for the LiveDepth server plugin and chart client.
