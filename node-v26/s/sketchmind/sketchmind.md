# sketchmind

> 标签: agent, canvas, diagram, drawing, excalidraw, json, latex, llm, mathjax, streaming, tldraw

## 简介

An infinite drawing canvas whose native file format is LLM-friendly JSON — LLMs draw diagrams, math, and image annotations onto it, streaming in as they generate.
