# stdunits

> 标签: JavaScript

## 简介

Parse and normalize units so 0.1cm 0.001m and 0.039in all become 1mm.

## 官网

- 源码仓库：em/units.js
- npm 页面：https://www.npmjs.com/package/stdunits
