# snowfox-util

> 标签: JavaScript

## 简介

当前最新版本: 1.0 ## components #### numToCapital * 将数字转化为中文大写汉字   * 参数1 数字或者带有逗号的字符数字   * 参数2 0或1      * 1: 零壹贰叁肆伍陆柒捌玖拾     * 0: 零一二三四五六七八九十 #### rules * 正则类 * 方法   * getRules 返回正则对象   * promulgator 写入正则     * 参数1 对象的key 字符串类型 (如果和正则类的对象池中的key相同则替
