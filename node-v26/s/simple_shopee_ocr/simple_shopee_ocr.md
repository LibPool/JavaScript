# simple_shopee_ocr

> 标签: gemini, groq, invoice, llm, ocr, shipping-label, shopee, spx, thermal, typescript, vietnam, vision

## 简介

OCR pipeline for Shopee / SPX-style thermal shipping labels (A6/A7): preprocess image, call a vision LLM, return typed JSON (tracking code, order id, recipient, products, COD, weight). Consumer app passes the photo as Buffer or base64 (or data URL)—no sam
