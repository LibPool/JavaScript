# semmet-angular-basic

> 标签: angular, e2e, ng-generate, playwright, schematics, signals, standalone, style-guide

## 简介

Plain UI delivery dev kit in Angular: schematics that generate components, compositions, tests, and delivery scaffolds as native editable Angular code, following only the official Angular style guide.
