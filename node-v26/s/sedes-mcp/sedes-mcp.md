# sedes-mcp

> 标签: formation, llc, mcp, model-context-protocol, registered-agent, sedes, shopify

## 简介

MCP server for US LLC formation — which state to form in, formation quotes with real state filing fees, and direct checkout links. Standalone: no API keys, no database, no runtime network calls.
