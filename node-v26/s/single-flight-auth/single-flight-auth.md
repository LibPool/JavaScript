# single-flight-auth

> 标签: auth, broadcastchannel, fetch, jwt, race-condition, refresh-token, single-flight, token-refresh, web-locks

## 简介

Single-flight access-token refresh within and across browser tabs. Fixes the "random 401" caused by refresh-token rotation races.
