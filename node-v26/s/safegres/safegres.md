# safegres

> 标签: audit, auditor, ci, database, dba, devsecops, explain, grants, index, indexing, linter, performance, policy, postgres, postgresql, query-performance, rls, row-level-security, safegres, sarif, security, static-analysis

## 简介

Postgres security and performance auditor: RLS, grants and effective-access analysis plus index and policy-cost checks, scored on two independent axes. One connection, no framework.
