# sass-modern-mq

> 标签: JavaScript

## 简介

> [**Sass Modern MQ**](https://github.com/maximelebreton/sass-modern-mq) is a mixin that helps you to create simple and accurate media queries by rethinking layouts as **landscape**, **square** and **portrait**
