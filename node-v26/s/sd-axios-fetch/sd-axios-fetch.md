# sd-axios-fetch

> 标签: ajax, api, axios, browser, compatibility, drop-in, fetch, http, https, isomorphic, node, promise, replacement, request, rest, typescript, zero-dependency

## 简介

A zero-dependency, drop-in replacement for Axios.js built entirely on the native Fetch API. Full API compatibility with modern web standards.
