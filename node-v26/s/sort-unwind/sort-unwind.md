# sort-unwind

> 标签: argsort, inverse-permutation, parallel-arrays, permutation, reorder, sort, typescript, undo, unshuffle, unsort

## 简介

Sort an array and get the inverse permutation (argsort) to undo it, or apply the same sort order to parallel arrays
