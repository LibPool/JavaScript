# signalk-espos-manager

> 标签: esp32, espos, firmware, marine, ota, signalk-category-utility, signalk-node-server-plugin, signalk-webapp

## 简介

Finds espOS devices on the boat network, mirrors signed firmware from a project registry, and drives over-the-air updates — with a browser flasher for a freshly bought board.
