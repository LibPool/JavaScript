# spec-lane

> 标签: ai-agent, cli, code-review, delivery, developer-tools, estimation, spec-driven-development, workflow

## 简介

A local-first delivery-lane orchestrator: Intent -> Spec/Critic -> Implement -> Verify -> Done, with cost estimation/calibration, a resource-aware next-task view, a spec-consensus gate, and a knowledge lens for review lessons.
