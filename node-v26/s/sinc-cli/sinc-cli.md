# sinc-cli

> 标签: JavaScript

## 简介

- **chalk**: 终端字体样式 - **commander**: 解析命令行 - **download-git-repo**: 下载并提取 git 仓库，用于下载模板 - **figlet**: 创建脚手架 Logo - **fs-extra**: 文件处理 - **inquirer**: 命令行界面与用户交互 - **log-symbols**: 命令行界面状态图标 - **ora**: 显示 loading 动画效果 - **shelljs**: 基于 nodejs 的 she
