# swiper-pagination

> 标签: JavaScript

## 简介

这是一个 vue2 版本的分页组件，用于在应用程序中实现分页功能。它的特殊之处在于使用鼠标滚轮、鼠标推拽、甚至触摸屏上下滑动时切换上一页/下一页。
