# slush-js-skeleton

> 标签: bower, mocha, module, node, npm, slush, slushgenerator

## 简介

Generate node and/or browser skeleton. Readme.md + package.json + bower.json + gulpfile.js + mocha test harness (with browser support) + jshint + jscoverage.
