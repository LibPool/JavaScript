# switchboard-agents

> 标签: ai-agents, claude-code, cursor, falkordb, graph, mcp, mcp-server, multi-agent

## 简介

Coordinate AI coding agents (Claude Code, Cursor) through a shared FalkorDB import graph: claims, conflict checks, memory, an MCP server and editor hooks.
