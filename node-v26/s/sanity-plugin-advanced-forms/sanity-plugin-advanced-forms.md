# sanity-plugin-advanced-forms

> 标签: form-builder, forms, mailgun, sanity, sanity-plugin

## 简介

Advanced form builder for Sanity: a Gravity-Forms-style form document with a flexible field palette, a submissions inbox tool, and a framework-agnostic submission handler (Sanity storage + Mailgun notifications).
