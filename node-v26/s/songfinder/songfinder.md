# songfinder

> 标签: audio-analysis, bpm-detection, camelot-wheel, cli, dj, harmonic-mixing, isrc, key-detection, music-metadata, music-recognition, playlist, shazam-alternative, song-finder, song-identification, what-song-is-this

## 简介

Identify any song from a URL or audio file, then get its BPM, musical key, Camelot code and harmonically compatible tracks. CLI and typed client for the free Song Finder API — zero dependencies, no API key.
