# sysml-diagram

> 标签: ci, diagram, kerml, mbse, sysml, sysml v2

## 简介

Headless SysML v2 / KerML diagram renderer — export the same diagrams the VS Code extension draws to standalone SVG, from a terminal or a CI pipeline.
