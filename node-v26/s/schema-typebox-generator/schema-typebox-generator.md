# schema-typebox-generator

> 标签: drizzle, elysia, generator, jsdoc, schema, typebox, typescript, validation

## 简介

自动从 Drizzle Schema 文件中解析 JSDoc @typebox 注释并生成 TypeBox 配置的工具库

## 官网

- 官网：https://github.com/pori/schema-typebox-generator
- npm 页面：https://www.npmjs.com/package/schema-typebox-generator

- 1.0.0

- npm registry：https://registry.npmjs.org/schema-typebox-generator
- Node 要求：>=18
