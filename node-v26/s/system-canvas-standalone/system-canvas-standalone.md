# system-canvas-standalone

> 标签: canvas, cdn, diagram, iife, json-canvas, standalone, svg

## 简介

Self-contained browser bundle for system-canvas. Drop-in <script> tag with React inlined; renders a fully interactive canvas into any DOM element.
