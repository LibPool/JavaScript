# statswhatshesaid

> 标签: analytics, hyperloglog, nextjs, privacy, self-hosted, stats, unique-visitors, zero-dependencies

## 简介

A super minimal one-line drop-in unique-visitors-per-day stats library for Next.js. In-memory, zero dependencies, runs in both Edge and Node runtimes.
