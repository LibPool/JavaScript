# sangjog

> 标签: annotation, api, api first, api-first approach, auth, authentication, framework, http, rest, rest framework, restful, sangjog, ts, typescript, web

## 简介

Sangjog(Communication) is a server application framework made for typescript in Node js platform. Sangjog(communication) is mainly used to create pure rest API. You can also create UI in the same server if you want but API and UI will be loosely coupled.
