# symbra

> 标签: ai-agents, blast-radius, call-graph, claude-code, code-intelligence, codex, cursor, knowledge-graph, mcp, sqlite, tree-sitter

## 简介

Local-first, live code intelligence for AI coding agents. Weaves your codebase into a queryable symbol graph (SQLite + tree-sitter, zero native deps, zero LLM) and serves it over MCP.
