# signalk-stw-heel-correction

> 标签: calibration, heel, paddlewheel, racing, sailing, signalk, signalk-category-utility, signalk-node-server-plugin, speed-through-water

## 简介

Signal K plugin that corrects speed through water for heel angle from a 2D interpolation table, republishing it under its own source so source priorities can rank it above the raw paddlewheel
