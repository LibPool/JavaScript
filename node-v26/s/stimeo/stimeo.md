# stimeo

> 标签: hotwire, rails, stimeo, stimeo-ui, stimulus

## 简介

Alias of stimeo-ui — the headless, accessibility-first Stimulus UI framework for Ruby on Rails. Prefer stimeo-ui; this package makes `npx stimeo` and `import from "stimeo"` resolve to the real library.
