# sophotron

> 标签: mcp, model-context-protocol, open-access, openalex, philarchive, philosophy, philpapers, research, semantic-scholar, sophotron, unpaywall

## 简介

Sophotron — an MCP server for philosophy-paper search & retrieval: Semantic Scholar + OpenAlex + Unpaywall, a cached PhilArchive harvest, and PhilPapers taxonomy browsing.
