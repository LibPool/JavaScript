# s402

> 标签: agent-payments, ai-agent, escrow, http-402, m2m, machine-to-machine, micropayments, payments, protocol, streaming, sui, web3, x402

## 简介

s402 — Chain-agnostic HTTP 402 wire format. Types, HTTP encoding, and scheme registry for six payment schemes. Wire-compatible with x402. Zero runtime dependencies.
