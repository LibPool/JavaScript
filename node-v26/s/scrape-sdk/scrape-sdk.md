# scrape-sdk

> 标签: agent-skills, ai-agents, crawler, firecrawl, jina, markdown, mcp, scraper, tavily, tinyfish, vercel-ai-sdk, web-scraping

## 简介

TypeScript client to scrape URLs to markdown with failover across Firecrawl, TinyFish, Jina, Tavily, Spider, Browserbase, and local Cheerio
