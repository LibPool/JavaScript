# suparisma

> 标签: expo, hooks, mobile, nextjs, prisma, react, react-native, realtime, supabase, typescript

## 简介

Opinionated typesafe React realtime CRUD hooks generator for all your Supabase tables, powered by Prisma. Works with Next.js, Remix, React Native, and Expo.
