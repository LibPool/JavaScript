# sqlite-wasm-viewer

> 标签: browser, database, inspector, opfs, opfs-viewer, sql, sqlite, sqlite-wasm, sqlite-wasm-viewer, viewer, wasm

## 简介

Browser SQLite OPFS viewer for @sqlite.org/sqlite-wasm: inspect OPFS-backed databases, run SQL, and filter tables.
