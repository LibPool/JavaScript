# string-to-date-convert

> 标签: JavaScript

## 简介

This library was generated with [Angular CLI](https://github.com/angular/angular-cli) version 13.0.0. Purpose of this library is to convert any string format of date into Date Type in input fields. Currently this is a TS based solution.
