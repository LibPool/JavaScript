# strapi-plugin-slugify-transliteration

> 标签: plugin, slug, slugify, strapi, strapi plugin, strapi-plugin

## 简介

A plugin for Strapi forked from strapi-plugin-slugify, use transliteration to support Universal Unicode to Latin transliteration.
