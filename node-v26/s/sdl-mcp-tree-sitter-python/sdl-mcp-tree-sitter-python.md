# sdl-mcp-tree-sitter-python

> 标签: sdl-mcp, tree-sitter, tree-sitter-python, wrapper

## 简介

sdl-mcp peer-range wrapper around tree-sitter-python. Re-exports upstream unchanged with a permissive tree-sitter peer range (>=0.21.0 <1.0.0) so installs of sdl-mcp avoid ERESOLVE peer-dependency warnings.
