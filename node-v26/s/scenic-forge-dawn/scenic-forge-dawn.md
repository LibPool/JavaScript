# scenic-forge-dawn

> 标签: csg, dawn, generative-art, headless, node, path-tracing, sdf, webgpu

## 简介

Render a scenic-forge scene to an image file from Node, by path-tracing it on WebGPU through Dawn — no browser, headless or otherwise.

- npm 页面：https://www.npmjs.com/package/scenic-forge-dawn
