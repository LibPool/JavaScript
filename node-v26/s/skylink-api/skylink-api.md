# skylink-api

> 标签: adsb, airports, api-client, aviation, aviation-weather, flight-tracking, metar, notam, sdk, skylink, taf

## 简介

Official TypeScript/JavaScript SDK for the SkyLink API — aviation data: live ADS-B, weather, airports, charts, NOTAMs, flight status and more.
