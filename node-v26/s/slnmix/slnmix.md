# slnmix

> 标签: ai, legacy, llm, msbuild, repomix, sln, vb.net, vbproj, visual-studio

## 简介

Repomix 互換フォーマットで .sln / .vbproj を 1 ファイルにエクスポートする CLI。ディレクトリ走査ではなくソリューションの論理構成(Link・DependentUpon 解決済み)に基づく。レガシー VB.NET / Shift_JIS 対応。
