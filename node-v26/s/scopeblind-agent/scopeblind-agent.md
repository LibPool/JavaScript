# scopeblind-agent

> 标签: ai-agent, api-security, bot-protection, cryptographic-identity, device-identity, dpop, llm-gateway, mcp, proof-of-possession, rate-limiting, rfc-9449, scopeblind

## 简介

Agent identity SDK for ScopeBlind. DPoP proof-of-possession for AI agents, CLIs, and MCP servers. Generates holder-binding commitments for signed decision receipts.
