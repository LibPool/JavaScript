# sg-widgets-core

> 标签: autodesk, flow-production-tracking, headless, shotgrid, typescript, vfx

## 简介

Headless, framework-agnostic model of Flow Production Tracking (ShotGrid) fields, filters, statuses and a client adapter, for building widgets.
