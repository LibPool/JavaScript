# sevdesk-mcp

> 标签: accounting, beleg, buchhaltung, invoice, mcp, model-context-protocol, reverse-charge, sevdesk, umsatzsteuer, vat

## 简介

MCP server for the sevDesk accounting API — full endpoint coverage plus bookkeeping audit tools (VAT/§13b reverse-charge checks, duplicate detection, folder↔sevDesk diff, subscription gap detection).
