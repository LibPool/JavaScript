# sonovault-mcp

> 标签: ai, beatport, claude, isrc, iswc, mcp, mcp-server, modelcontextprotocol, music, music-api, music-metadata, spotify

## 简介

MCP server for the SonoVault music metadata API. Search 93M+ tracks, artists, and releases; get genre, label, release dates, ISRC/ISWC codes, and cross-platform IDs.
