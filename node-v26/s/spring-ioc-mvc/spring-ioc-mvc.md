# spring-ioc-mvc

> 标签: JavaScript

## 简介

- 1.原生js实现了注解和java的Spring框架( [spring-ioc](https://gitee.com/woaianqi/spring-ioc) ) - 2.高度还原java的SpringMvc框架 - 3.可以直接注入Npm包到Spring容器
