# shit-agent-proxy

> 标签: 429, claude-code, exponential-backoff, proxy, rate-limit, retry

## 简介

Transparent retry proxy for Claude Code API 429/5xx errors. Sleep & retry at proxy layer so Claude Code never sees the failure.
