# seatwatch

> 标签: agent, alamo-drafthouse, amc, claude-skill, movie-tickets, seat-alert, seat-availability

## 简介

Sold-out movie? Watch the seat map and get pinged the moment a cancellation opens up — AMC & Alamo Drafthouse, per-seat status, best-seat ranking, seats-together search. Agent-friendly JSON CLI with a Claude skill installer.
