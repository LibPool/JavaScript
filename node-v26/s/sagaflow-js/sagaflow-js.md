# sagaflow-js

> 标签: cloudflare-workflows, compensation, durable-execution, idempotency, orchestration, outbox, saga, typescript, workflow

## 简介

Sagas for TypeScript — compensating workflows that run inline in a request or durably on a workflow engine. Cloudflare Workflows adapter included.
