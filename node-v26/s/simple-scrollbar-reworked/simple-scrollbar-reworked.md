# simple-scrollbar-reworked

> 标签: custom-scrollbar, scrollbar, simple-scrollbar, simple-scrollbar-adds, simple-scrollbar-fixed, tiny-scrollbar, vanilla-js

## 简介

Very simple vanilla javascript library for creating a custom scrollbar cross-browser and cross-devices. Addings by TorusHelm. Forked from https://github.com/buzinas/simple-scrollbar
