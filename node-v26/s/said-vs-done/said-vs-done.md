# said-vs-done

> 标签: compliance, documentation-drift, english, german, i18n, polish, privacy-policy, promises, spanish, static-analysis

## 简介

Reads the promises a project makes to its customers — in Polish, English, German or Spanish — and checks whether anything in the code keeps them. Said against done.
