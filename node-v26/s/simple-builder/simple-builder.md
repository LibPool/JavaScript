# simple-builder

> 标签: builder, cjs, escape, esm, identifier, insert, mysql, mysql2, parameterized, pg, placeholders, postgres, postgresql, prepared-statements, query, query-builder, sql, sql-builder, sql-injection, sql-template, tagged-template, template-literal, typescript, update, where-in, zero-dependency

## 简介

Tiny SQL builder that keeps your SQL visible. A safe sql`` tagged template plus the classic ? partials API, both returning { text, values } for pg, mysql and mysql2. Always-parameterised values, quoted identifiers, object expansion for INSERT/UPDATE/WHERE
