# spacer

> 标签: ajax, dialog, form-submission, form-validation, jquery-validation, resource-manager, table, validation

## 简介

A powerful realtime client-side validation for input fields based on JQuery, simple dialog API and extra helpful tools for: inputs, form submission, ajax, web navigation, tables and arrays
