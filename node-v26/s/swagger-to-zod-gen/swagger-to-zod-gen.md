# swagger-to-zod-gen

> 标签: openapi, react-hook-form, swagger, typescript, validation, zod

## 简介

Genera tipi TypeScript + schemi Zod da uno spec OpenAPI 3.x / Swagger (file o URL) per validazione React Hook Form. Messaggi errore personalizzabili e validazioni cross-field (x-validate).
