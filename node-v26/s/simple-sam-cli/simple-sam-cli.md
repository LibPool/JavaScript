# simple-sam-cli

> 标签: aws, cli, cloudformation, merge, package, sam, template, tool, yaml, yml

## 简介

This is a CLI tool to make the AWS SAM CLI simpler to use. One line command to make a bucket if not exist, merge multiple cloudformation files, packaging, deploy and create the Cloudformation stack.
