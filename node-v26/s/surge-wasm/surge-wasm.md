# surge-wasm

> 标签: cheminformatics, constitutional isomers, isomers, molecular formula, nauty, structure generator, surge, wasm, webassembly

## 简介

Enumerate every constitutional isomer of a molecular formula. The surge C program compiled to WebAssembly and embedded, so it runs in a browser with nothing to install and nothing to fetch.
