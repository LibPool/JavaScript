# seekstone

> 标签: ai, chatgpt, claude, claude-code, claude-obsidian, connect-claude-to-obsidian, cursor, knowledge-base, llm, markdown, mcp, mcp-server, model-context-protocol, note-taking, notes, obsidian, obsidian-ai, obsidian-mcp, personal-knowledge-management, pkm, search, second-brain, vault

## 简介

The Obsidian MCP server that needs no plugin, no running Obsidian app — and doesn't blow your context window. Filesystem-direct: single-digit-ms keyword search, ~26 ms local semantic search, ~2 KB payloads, 21 tools.
