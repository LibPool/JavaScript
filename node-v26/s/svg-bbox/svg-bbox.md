# svg-bbox

> 标签: bbox, bounding-box, browser, cdn, cli, headless-chrome, inkscape, minified, puppeteer, sprite-sheet, svg, svg-export, svg-extraction, svg-render, svg-to-png, svg-tools, text-to-path, umd, visual-bounds

## 简介

A set of tools to compute and to use a SVG bounding box you can trust (as opposed to the unreliable .getBBox() scourge)
