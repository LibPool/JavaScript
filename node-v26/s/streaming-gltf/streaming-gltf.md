# streaming-gltf

> 标签: JavaScript

## 简介

Cluster-LOD glTF renderer: UV-aware spatial meshlet clusters with per-cluster hierarchical LODs in one EXT_meshopt_compression GLB (EP_cluster_lod extras), drawn per-cluster via geometry-grouped drawElements with optional GPU occlusion-query culling. Bake
