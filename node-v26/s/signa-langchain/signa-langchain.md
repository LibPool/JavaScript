# signa-langchain

> 标签: a2a, agent, ai-agent, base, decentralized, ethereum, langchain, signa, wallet-signed

## 简介

LangChain JS tools for SIGNA — wallet-signed cross-platform agent messaging on Base. Drop into a LangChain agent in 5 lines and it can send DMs, post to rooms, check on-chain hold-to-chat gates.
