# seif-mcp

> 标签: ai-provenance, ai-quality, data-classification, ed25519, mcp, model-context-protocol, opentimestamps, seif, transparency-log

## 简介

MCP server for the SEIF Protocol — provenance signing, transparency log, and data classification tools for AI agents (Cursor, Claude Code, Claude Desktop). Thin Node wrapper around the canonical Python implementation.
