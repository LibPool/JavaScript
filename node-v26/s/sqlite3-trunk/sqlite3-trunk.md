# sqlite3-trunk

> 标签: JavaScript

## 简介

Asynchronous, non-blocking SQLite3 bindings. This is a trunk version of sqlite3 working with Node 0.11.4+ (pre-0.12).

## 官网

- 官网：http://github.com/mapbox/node-sqlite3
- 源码仓库：git://github.com/mapbox/node-sqlite3.git
- npm 页面：https://www.npmjs.com/package/sqlite3-trunk
