# sourcery-eval

> 标签: agent, benchmark, eval, exa, firecrawl, llm, mcp, rag, retrieval, tavily, web-search

## 简介

Find the best search API for your agent. Same query, same model, same judge, swap only the retrieval provider: Firecrawl, Tavily, Exa, Bright Data, keyless baseline.
