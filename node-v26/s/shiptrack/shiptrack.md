# shiptrack

> 标签: ai-agent, antigravity, claude-code, cli, codex, otopilot, shiptrack

## 简介

ShipTrack Otopilot runner: runs your coding agent (Claude Code, Codex, Antigravity) on your own machine for steps you send from ShipTrack.
