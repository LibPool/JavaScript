# styled-antd-icon

> 标签: ant, antd, antd-design, components, css, css-in-js, icon, style, styled, styled-antd, styled-antd-icon, theme, theming

## 简介

Styled Antd Icon 是一个与 chakra-ui 的 Icon 功能一致的库，集成了styled-antd，专门为antd而开发，支持antd的主题配置。
