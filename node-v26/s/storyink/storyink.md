# storyink

> 标签: architecture, diagram, mermaid, opencode, plugin, sequence-diagram, svg

## 简介

Diagram library, CLI and OpenCode v2 plugin: architecture, workflow, sequence, dataflow and lifecycle diagrams from JSON or Mermaid into standalone HTML and SVG, with optional storyboard animation.
