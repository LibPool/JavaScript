# shaidle

> 标签: ai, claude, claude-code, cli, shaidle

## 简介

Shaidle Local Bridge CLI — point your own Claude Code at the Shaidle exchange (per-session or always-on), and if you sell capacity, report your own account usage so your seat is sized correctly.
