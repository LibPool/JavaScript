# starlight-mcp

> 标签: astro, astro-integration, cloudflare-workers, documentation, llm, mcp, model-context-protocol, starlight, starlight-plugin, withastro

## 简介

Give your Astro or Starlight docs site an MCP server — search_docs, get_doc and list_docs over stateless streamable HTTP. Astro integration, pure fetch handler, and Cloudflare static-assets glue included.
