# static-resource-hash-webpack-plugin

> 标签: JavaScript

## 简介

基于WebPack HTML/CSS/JS/Image Hash功能。实现逻辑为 当所有文件生成后，通过查找文件引用来更新Hash后的文件名。不支持动态路径引用。
