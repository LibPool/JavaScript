# skilltrigger

> 标签: claude-code, evals, measurement, skill-description, skills, trigger-rate

## 简介

How often a Claude Code skill's description makes the model load it, on prompts that should trigger it and near-misses that should not, measured behind gates that refuse to report a number they cannot trust.
