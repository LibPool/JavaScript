# sparqlc-cli

> 标签: JavaScript

## 简介

CLI utilities for `sparqlc`: - **`sparqlc-tsc`**: A drop-in `tsc` replacement that provides type-checking and emit support for `.rq` and `.ru` SPARQL imports compiled with `sparqlc`. - **`sparqlc`**: A standalone command-line compiler to compile a SPARQL
