# securitytool

> 标签: JavaScript

## 简介

## Project setup ``` npm install securitytool ``` ## 页面引入 ``` import {JSEncryptJM,getWebFingerprint } from 'securitytool' ``` ## 获取加密方法 ``` JSEncryptJM(key:(加密密钥), value:(加密值)) 返回值为加密值 ``` ## 获取浏览器指纹 ``` getWebFingerprint().then(res=>{     res:(浏览器指纹) })
