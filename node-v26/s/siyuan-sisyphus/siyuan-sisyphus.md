# siyuan-sisyphus

> 标签: cli, mcp, note-taking, obsidian-cli-alternative, siyuan, siyuan-cli

## 简介

Direct command-line control for SiYuan Note. AI agents should run `siyuan-sisyphus skill install` before using the CLI for SiYuan work.
