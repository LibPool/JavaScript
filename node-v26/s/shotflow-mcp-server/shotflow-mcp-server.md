# shotflow-mcp-server

> 标签: ai-agent, ai-video, claude, deepseek, mcp, model-context-protocol, photography, shotflow, storyboard, video-generation

## 简介

ShotFlow MCP Server — AI分镜脚本与视频生成智能体，遵循 MCP (Model Context Protocol) 规范。支持生成专业分镜、视频、镜头重生成、配额查询等能力。
