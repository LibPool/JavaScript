# signalk-tuya

> 标签: boat, lan, local, marine, signalk-category-digital-switching, signalk-category-hardware, signalk-node-server-plugin, smart-life, smart-plug, smartlife, switch, tinytuya, tuya

## 简介

Tuya WiFi sockets as native Signal K — switch state, metering and control over the local LAN protocol 3.3. No MQTT, no cloud in the control path.
