# scrapme-flow

> 标签: couchdb, flow, inversify, pg-boss, queue, retry, scraping, workflow

## 简介

Scraping flows of injectable commands (retries + timeout each), defined in TypeScript, run on pg-boss queues (Postgres), progress in CouchDB. Scrapes through scrap-anything. The monitor is a separate app.
