> 标签: anthropic, incomplete, json, json-repair, llm, openai, parse, partial, partial-json, stream, streaming, structured-output, tool-calls, typescript, vercel-ai

## 简介

Parse JSON while an LLM is still streaming it. Repairs incomplete JSON into the best value so far. Zero dependencies, 459 bytes.
