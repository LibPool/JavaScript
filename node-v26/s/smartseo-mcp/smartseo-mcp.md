# smartseo-mcp

> 标签: google-search-console, mcp, model-context-protocol, seo, shopify, smartseo

## 简介

stdio bridge for the Smart SEO (Shopify) MCP server. Lets Claude Desktop and other stdio-only MCP clients query your store's Google Search Console data.
