# specky-sdd

> 标签: ai-agent, claude, copilot, ears-notation, mcp, requirements, sdd, spec-driven-development, specification

## 简介

Specky — Spec-Driven Development CLI toolkit. 58 MCP tools, 13 agents, 22 prompts, 14 skills, 16 hooks. Unified `specky` CLI installs to Claude Code, GitHub Copilot, Cursor, or OpenCode on macOS, Linux, and Windows.
