# secure-upload-fastify-sdk

> 标签: fastify, multipart, plugin, resumable, sdk, smart-upload, upload

## 简介

Fastify plugin SDK for resumable / multipart / smart uploads. Pluggable storage (Local / S3 / OSS / COS), pluggable repository (Prisma or custom), optional bridge to secure-crypto-top-zod-sdk.
