# snapfit-sdk

> 标签: browser, canvas, client-side, crop, file upload, heic, image compress, image optimization, image processing, image resize, passport photo, typescript, webp

## 简介

Universal client-side image processing SDK. Resize, compress, convert, and AI-crop images in the browser — zero server, zero latency.
