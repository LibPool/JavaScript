# sass-token-importer

> 标签: dart-sass, design-tokens, dtcg, importer, json, sass, scss, style-dictionary, tokens

## 简介

A custom Importer for Dart Sass that imports JSON design tokens (W3C DTCG & Style Dictionary) and converts them to SCSS variables or maps at compile time.
