# smart-naive-table

> 标签: admin, crud, data-table, naive-ui, smart-table, table, vue, vue3

## 简介

Columns-driven data table for Vue 3 + Naive UI: auto search form, remote pagination adapter, dict cell rendering, persistent column settings, density toggle, i18n via labels.
