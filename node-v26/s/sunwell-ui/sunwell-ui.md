# sunwell-ui

> 标签: JavaScript

## 简介

Sunwell UI is a UI library for the Sunwell system landing page, designed for rapid Vue development. It is based on the Moon design system, as seen in the [Figma file link](https://www.figma.com/file/S3q1SkVngbwHuwpxHKCsgtJj/Moon---Components-Tailwind?node
