# svg-flatten

> 标签: circle, ellipse, flatten, flattener, g, line, path, polygon, polyline, rect, shape, svg, transform

## 简介

Turns SVG shapes (polygon, polyline, rect, g) into SVG paths. It can merge groups and apply transforms.
