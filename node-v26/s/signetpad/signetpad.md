# signetpad

> 标签: canvas signature, digital signature, handwritten signature, headless, nextjs, nuxt, react native signature, react signature pad, signature, signature pad, signature-pad, signetpad, svelte signature pad, sveltekit, svg signature, typescript, undo-redo, vector signature, vue signature pad

## 简介

SignetPad is a headless TypeScript signature pad for React, Vue, Svelte, and React Native. Capture vector signatures, undo strokes, and export SVG, PNG, JPEG, or WebP.
