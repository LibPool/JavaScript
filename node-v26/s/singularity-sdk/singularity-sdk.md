# singularity-sdk

> 标签: agent, bitcoin, blockchain, claude, cosmos, evm, mcp, sdk, singularity, solana, web3

## 简介

Build blockchain applications on Singularity Agent — one typed client over EVM, Solana, Bitcoin and Cosmos, with watch primitives, an agent-tool bridge, and a custody seam the SDK never crosses.
