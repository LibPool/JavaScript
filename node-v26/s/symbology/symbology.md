# symbology

> 标签: aztec, barcode, code 128, data matrix, ean, gs1, isbn, pdf417, qr, upc, usps onecode

## 简介

🔖 Generates 1D, 2D, and composite barcodes in png, svg, or eps formats. Supports 50+ symbologies.
