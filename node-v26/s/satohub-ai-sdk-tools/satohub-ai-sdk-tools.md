# satohub-ai-sdk-tools

> 标签: ai-sdk, crypto, onchain-agents, satohub, tools, vercel-ai-sdk, web3

## 简介

Vercel AI SDK tools for Sato Hub: search the scored onchain-agent index, run a Preflight check before installing or trading, get a swap-venue recommendation with the fee disclosed, and turn a goal into a build plan of real listings. Read-only and non-cust
