# solr-zkcli

> 标签: SolrCloud, solr, zkcli, zkcli.bat, zkcli.sh, zookeeper

## 简介

A node.js wrapper for the Solr's ZooKeeper CLI zkcli.sh to manage SolrCloud configuration parameters
