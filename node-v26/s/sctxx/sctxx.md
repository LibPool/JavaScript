# sctxx

> 标签: agent, claude-code, cli, codex, context, handoff, llm

## 简介

Turn a coding-agent session transcript (Claude Code, Codex CLI, Pi) into a compact, verified, provenance-linked handoff artifact any other agent can continue from.
