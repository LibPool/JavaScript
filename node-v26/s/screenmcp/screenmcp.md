# screenmcp

> 标签: automation, gui-testing, mcp, model-context-protocol, screen, screenshot, ui-automation, vision, windows

## 简介

MCP server that lets an AI agent see and drive the Windows screen for autonomous debugging/testing (screenshots, OCR-free UI inspection, mouse, keyboard, window and process control).
