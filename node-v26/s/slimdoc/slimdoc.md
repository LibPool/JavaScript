# slimdoc

> 标签: cleanup, cli, docx, llm, markdown, pdf, pptx, tokens, transcript, whitespace

## 简介

Shrink any document — Word, PowerPoint, PDF, Markdown, HTML, RTF or pasted text — into clean, token-cheap input for an LLM.
