# spawn-agent

> 标签: JavaScript

## 简介

Spawn any locally-installed coding agent (Claude Code, Codex, Cursor, Copilot, Gemini, OpenCode, Droid, Pi) as a Vercel AI SDK provider over the Agent Client Protocol.
