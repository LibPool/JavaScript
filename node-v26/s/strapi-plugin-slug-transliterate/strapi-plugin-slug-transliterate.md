# strapi-plugin-slug-transliterate

> 标签: plugin, slug, slugify, strapi, strapi plugin, strapi-plugin, transliterate

## 简介

A plugin for Strapi Headless CMS that provides the ability to slugify fields by transliteration based on strapi-plugin-slugify.
