# scrollbox

> 标签: ecosystem:jquery, inertia, infinite-scrolling, jquery-plugin, kinetic, momentum, scroll, scrollbar, scrolling, touchscreen, trigger, ui

## 简介

A lightweight jQuery custom scrollbar plugin, that triggers event when reached the defined point.
