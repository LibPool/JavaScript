# smart-cache-sqlite

> 标签: better-sqlite3, cache, express, invalidation, lru, offline-first, sqlite, ttl

## 简介

Camada de cache inteligente para SQLite com TTL, LRU, invalidação por tabela, triggers e estratégias cache-first/network-first/stale-while-revalidate.
