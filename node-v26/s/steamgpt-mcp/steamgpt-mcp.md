# steamgpt-mcp

> 标签: ai-agents, faceit, mcp, mcp-server, modelcontextprotocol, steam, steam-api, steamid, steamid64, vac

## 简介

MCP server for Steam data: profiles, SteamID conversion, VAC and game bans, FACEIT stats, friends. Free remote server at steamgpt.net; this package is a stdio proxy for clients without native Streamable HTTP support.
