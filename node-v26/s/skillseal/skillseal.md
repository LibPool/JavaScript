# skillseal

> 标签: agent-skills, content-addressed, ed25519, filecoin, integrity, ipfs, mcp, provenance, skills, supply-chain

## 简介

Install an agent skill from one line that proves what it is: the contents' fingerprint, the publisher's key, and their signature. Checks every byte before anything is written, and installs as a plain Agent Skills folder that any agent already reads.
