# sql-dev-inspector

> 标签: debug, devtools, drizzle, express, inspector, mysql, mysql2, n+1, nitro, nuxt, sql, transaction

## 简介

Dev-only SQL inspector for Node apps that talk to MySQL through mysql2 (Drizzle, Knex, Sequelize, TypeORM…): see which SQL each request ran, how transactions and subqueries nest, N+1 and slow queries. Terminal tree, web UI and a floating in-app launcher.
