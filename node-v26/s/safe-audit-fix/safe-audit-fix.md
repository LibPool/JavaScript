# safe-audit-fix

> 标签: audit, fix, mcp, model-context-protocol, npm, safe, security, vulnerabilities

## 简介

Safely fix npm audit vulnerabilities: one fix at a time, test after each, auto-revert anything that breaks. Usable as a CLI or as an MCP server for AI assistants.
