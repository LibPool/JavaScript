# sdk-dss

> 标签: converter, csv, datasheet, dss, parser, spreadsheet, xls, xlsm, xlsx

## 简介

Pure JS library for DSS (Data Sheet Standard) parsing, serialization, and conversion to/from CSV/XLSX/XLS/XLSM. No dependencies.
