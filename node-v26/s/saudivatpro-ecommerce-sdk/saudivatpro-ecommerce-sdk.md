# saudivatpro-ecommerce-sdk

> 标签: compliance, credit-note, e-invoicing, ecommerce, invoicing-sdk, ksa, phase-2, saudi-vat, vat, zatca

## 简介

Official Node.js SDK for Saudi VAT Pro — turn e-commerce orders into ZATCA Phase 2 compliant invoices in a few lines of code. No XML, digital signing, or CSID handling required; the hosted platform does it for you.
