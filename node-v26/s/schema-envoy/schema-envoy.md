# schema-envoy

> 标签: ajv, function-calling, gemini, json-schema, llm, mcp, openai, schema-conversion, structured-outputs, tool-calling

## 简介

Convert a JSON Schema to an LLM provider's accepted subset and get a report of every value whose validity changed.
