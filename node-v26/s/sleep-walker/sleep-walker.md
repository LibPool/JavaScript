# sleep-walker

> 标签: browser-automation, cli, deterministic-replay, e2e-testing, llm-agent, playwright, record-replay

## 简介

Sleep-walker: an agent-in-the-loop Playwright CLI that learns a flow once, then replays it with the model asleep — zero-LLM, deterministic, verified.
