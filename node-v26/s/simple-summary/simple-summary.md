# simple-summary

> 标签: algorithm, language, lex, natural, nlp, processing, shortener, simple, simple summarize, simple summary, string, summarization, summarize, summarizer, summary, text, text summarization, text summary

## 简介

Summarize a block of text; nothing more; nothing less. This module allows for a simple require of a library to do text summarization on a string. Can include a string with multiple paragraphs.
