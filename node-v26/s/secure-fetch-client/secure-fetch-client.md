# secure-fetch-client

> 标签: aes-gcm, angular, api, axios alternative, browser, cache, client, encryption, fetch, fetch wrapper, frontend, http client, jwt, lru cache, mock api, mock json, node, react, react query, rest, secure api client, streaming, swr, testing, token refresh, typescript, vue, webcrypto

## 简介

Secure, robust, and fast API utility library for Angular, React, and Vue. Simplifies API calls, supports mock JSON APIs for testing, and integrates smoothly with modern apps. Includes JWT, LRU cache, streaming, and optional AES-GCM encryption.
