# streamcut

> 标签: ai-sdk, anthropic, chunk, claude, llm, markdown, openai, segmenter, sentence, sentence-splitter, sentence-tokenizer, stream, streaming, text-to-speech, transformstream, tts

## 简介

Split streaming LLM output into sentences or Markdown blocks as soon as each one is complete. For text-to-speech, live translation and chunked rendering. Handles abbreviations, decimals, code fences, lists and CJK. Zero dependencies.
