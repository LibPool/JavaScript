# sqlite-forkdb

> 标签: branching, sqlite, sqlite-extension, testing

## 简介

The forkdb SQLite extension (branch-per-test databases), prebuilt for Linux x64, macOS arm64 and Windows x64, with load() for node:sqlite and better-sqlite3
