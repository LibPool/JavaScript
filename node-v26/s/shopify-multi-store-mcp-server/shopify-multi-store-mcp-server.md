# shopify-multi-store-mcp-server

> 标签: agent-skill, ai-agent, claude, codex, cursor, ecommerce, ecommerce-reporting, graphql, inventory-management, mcp, mcp-server, model-context-protocol, multi-store, order-management, shopify, shopify-admin-api, shopify-graphql, shopify-mcp, shopify-multi-store

## 简介

Multi-store Shopify Admin MCP server for Claude, Codex, Cursor, and VS Code. Search products, compare inventory and catalogs, run reports, and make guarded updates.
