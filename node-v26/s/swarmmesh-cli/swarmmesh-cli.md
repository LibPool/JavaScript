# swarmmesh-cli

> 标签: agent-coordination, agent-swarm, ai-agents, bm25, cli, fastapi-interop, mcp, model-context-protocol, multi-agent, shared-context, shared-memory, swarmmesh, typescript, websocket

## 简介

Shared-context and memory coordination server for swarms of parallel AI agents. HTTP + WebSocket mesh server, CLI, and MCP server implementing the SwarmMesh protocol, interoperable with the Python implementation.
