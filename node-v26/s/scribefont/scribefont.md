# scribefont

> 标签: bezier, font, handwriting, onnx, opentype, truetype, ttf, typography

## 简介

Handwriting image-to-font & web canvas multi-contour vectorizer, calligrapher style extraction, and zero-dependency binary TrueType (.ttf) compilation.
