# secure-iam-lint

> 标签: aws, blast-radius, devsecops, fail-closed, iam, iam-policy, policy-analysis, sarif, security

## 简介

Client-side AWS IAM policy blast-radius analyzer with a fail-closed headless CLI, SARIF 2.1.0 output, and a GitHub Action. Reports potential blast radius, not effective permissions.
