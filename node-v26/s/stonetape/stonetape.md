# stonetape

> 标签: anthropic, cassette, ci, deterministic, fixtures, llm, mock, openai, record, replay, testing, vcr, vercel-ai-sdk, vitest

## 简介

Record once. Replay forever. Deterministic tests for LLM apps — record real LLM API interactions, replay them in CI: zero tokens, zero flakiness.
