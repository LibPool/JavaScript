# stylelint-config-octobox

> 标签: config, lint, octobox, style, stylelint

## 简介

Octobox's stylelint config based on Thomas Ricci's styleguide. This is not meant to be used standalone, and should only be used in an Octobox app.

## 官网

- 官网：https://www.octobox.thomasricci.dev
- 源码仓库：git+https://github.com/tom-ricci/octobox.git
- npm 页面：https://www.npmjs.com/package/stylelint-config-octobox
