# spec2md

> 标签: ai-agent, api, codegen, context, documentation, llm, markdown, mcp, nestjs, openapi, swagger

## 简介

Convert an OpenAPI/Swagger spec (file or live URL) into a clean Markdown API reference and a compact, token-efficient MCP context file for AI coding agents.
