# sdk-f3

> 标签: JavaScript

## 简介

A função `startPaymentV2` é utilizada para iniciar um processo de pagamento dentro de um aplicativo React Native. Ela recebe parâmetros relacionados à transação e retorna uma promessa com o resultado da operação.
