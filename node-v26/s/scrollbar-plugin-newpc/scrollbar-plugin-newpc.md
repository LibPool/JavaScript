# scrollbar-plugin-newpc

> 标签: JavaScript

## 简介

Highly customizable custom scrollbar jQuery plugin, featuring vertical/horizontal scrollbars, scrolling momentum, mouse-wheel, keyboard and touch support user defined callbacks etc.
