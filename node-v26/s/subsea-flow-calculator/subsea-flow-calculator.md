> 标签: api-1111, deepwater, flow-assurance, gulf-of-mexico, hydrate, mcp, model-context-protocol, offshore, pipeline, subsea

## 简介

Model Context Protocol (MCP) server for deepwater subsea pipeline engineering: API RP 1111 collapse pressure limit states, hydrostatic gradients to 3,500m, Towler-Mokhatab hydrate equilibria, and Hammerschmidt MEG dosage calculations.
