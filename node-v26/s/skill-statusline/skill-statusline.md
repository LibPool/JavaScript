# skill-statusline

> 标签: ai-coding, anthropic, claude, claude-code, cli, context-window, developer-tools, prompt, status-bar, statusline, terminal, themes, token-tracking

## 简介

Rich, themeable statusline for Claude Code — accurate context tracking, 5 themes, 3 layouts, token/cost/GitHub/skill display. Node.js renderer on Windows (no bash overhead), pure bash on Unix.
