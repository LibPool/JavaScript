# shadow-html-renderer

> 标签: framework-agnostic, html, html-rendering, renderer, script-execution, shadow-dom, style-isolation, typescript, vanilla-js

## 简介

A powerful and flexible framework-agnostic library for rendering HTML content into Shadow DOM with style isolation and full script execution support
