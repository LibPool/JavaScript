# stricttest

> 标签: isolation, node-test, rlsbl, sandbox, security, testing

## 简介

An always-on test-isolation floor for Node suites: throwaway HOME and XDG directories, an isolated git config and identity, transport lockdown, credential stripping, and sandbox enforcement
