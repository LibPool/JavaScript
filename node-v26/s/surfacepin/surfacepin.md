# surfacepin

> 标签: ci, hash, lockfile, mcp, prompts, resources, surface, tools

## 简介

Lock exact hashes of what an MCP server shows a model (tools, resources, prompts, titles, initialize instructions) and fail CI on silent drift. Offline files or live --stdio; field-level diff.
