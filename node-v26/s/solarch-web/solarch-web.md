# solarch-web

> 标签: indexeddb, mutations, offline-first, react, realtime, solarch, sync, web-sdk

## 简介

Official offline-first Web SDK for Solarch with IndexedDB local storage, durable mutation outbox, causal FIFO sync, and React hooks.

- 官网：https://solarch.in/
