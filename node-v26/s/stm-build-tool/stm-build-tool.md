# stm-build-tool

> 标签: build for deployment, build tool, css uglify, js uglify, linter, live reload, scss watch

## 简介

This is my attempt at building a very basic task-runner to clean up my workflow.
The idea is to minimise dependencies. I'm avoiding Grunt/Gulp/Brunch/Yeoman/etc.
