# screenshot-studio-mcp

> 标签: app-store, ios, localization, mcp, modelcontextprotocol, screenshots

## 简介

MCP server that lets an AI agent drive the Screenshot Studio project you have open on your Mac — inspect it, patch it, translate it, and see the rendered slide.
