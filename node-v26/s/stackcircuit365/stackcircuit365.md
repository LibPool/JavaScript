# stackcircuit365

> 标签: deployment, devops, github, healthcheck, incident-detection, nextjs, release-safety, rollback, sre, vercel

## 简介

Every release has a safety circuit. A free, self-hostable release-recovery service (and library) that detects bad GitHub-to-Vercel deployments, attributes the regression, and safely rolls back to the last verified-healthy release — with email/Slack alerts
