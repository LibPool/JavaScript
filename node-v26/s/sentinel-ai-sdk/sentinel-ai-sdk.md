# sentinel-ai-sdk

> 标签: analytics, breadcrumbs, error-reporting, error-tracking, frontend, javascript, monitoring, observability, react, sentinel, session-replay, telemetry, typescript

## 简介

Lightweight, zero-dependency frontend observability SDK. Automatically captures errors, user breadcrumbs, and session context, then sends them to your Sentinel AI dashboard.
