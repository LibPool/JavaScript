# selfstore

> 标签: argon2id, backup, browser-storage, crdt, e2e-encryption, encryption, google-drive, indexeddb, local-first, offline-first, privacy, sync, typescript, webdav, zip

## 简介

Local-first storage for browser apps: an IndexedDB working copy, portable encrypted ZIP backups (AES-256-GCM over Argon2id), durable homes (disk, Google Drive, WebDAV) and a serverless multi-device merge.
