# sharingan-eyes

> 标签: animation, canvas, eye-tracking, eyes, naruto, react, sharingan, typescript, ui-component

## 简介

Animated, fully customizable Sharingan eyes rendered on a canvas. Zero dependencies, framework-agnostic, with an optional React wrapper.
