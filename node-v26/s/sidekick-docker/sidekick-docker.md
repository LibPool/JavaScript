# sidekick-docker

> 标签: cli, containers, dashboard, devops, docker, docker-compose, docker-management, terminal, tui

## 简介

Interactive Docker dashboard (TUI), plus scriptable ps, logs, images, volumes, networks, stats, df and inspect commands
