# signalk-n2k-switch-alias

> 标签: signalk-category-digital-switching, signalk-node-server-plugin

## 简介

Creates an alias for a n2k switch. For example a Maretron CMK12 switch bank has its own instance that needs to control a different switch bank with its own instance.
