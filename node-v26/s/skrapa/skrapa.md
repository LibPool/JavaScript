# skrapa

> 标签: jsx, npx, ssg, static-site, static-site-generator, typescript, zero-config, zero-dependency

## 简介

Build static sites with TypeScript JSX templates and TypeScript client-side code. No framework, no virtual DOM, no config. A single zero-dependency script, run with npx.
