# sonorant-react

> 标签: formants, pitch, react, sonorant, speech, transgender-voice, visualization, voice

## 简介

Reusable React visualizations for Sonorant voice-analysis frames: a pitch/resonance pad, longitudinal trend chart, confidence-bearing summary and voice-quality meters. No acoustic maths — it draws what the Rust core measured.
