# singpay-sdk

> 标签: airtel money, gabon, mobile money, moov money, paiement, payment, sdk, singpay

## 简介

SDK non-officiel pour l'intégration facile des paiements SingPay (Airtel Money, Moov Money, Carte Bancaire) au Gabon.
