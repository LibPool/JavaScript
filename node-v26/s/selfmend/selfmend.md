# selfmend

> 标签: bdd, cucumber, e2e, end-to-end, flaky-tests, jest, locators, mocha, offline, playwright, playwright-test, runner-agnostic, self-healing, selfhealing, test-automation, testing

## 简介

Self-healing Playwright locators for any framework that drives a Playwright Page: Cucumber, Mocha, Jest, plain scripts, or @playwright/test. Fully offline, no API key, no telemetry, never a false-green test.
