# signalk-openwrt

> 标签: 4g, 5g, cellular, lte, marine, mmcli, modemmanager, openwrt, signal, signalk-node-server-plugin

## 简介

Connects to an OpenWrt 4G/5G router via ubus and publishes cellular signal metrics (RSSI, RSRP, RSRQ, SNR, quality) to SignalK paths
