# slicecss

> 标签: JavaScript

## 简介

SliceCSS is a css framework utilizing concepts started with other RWD frameworks such as Bootstrap, materialize and W3CSS who have paved the way for other framewors. Like W3CSS, SliceCSS depends mainly on CSS for it's core functionality with vanilla javas
