# softquantus

> 标签: qcos, quantum, quantum-computing, sdk, softquantus

## 简介

SoftQuantus client suite for TypeScript and JavaScript: installs and re-exports the QCOS TypeScript SDK (@softquantus/softqcos-sdk).
