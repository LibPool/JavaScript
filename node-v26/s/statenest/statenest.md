# statenest

> 标签: ai-agents, claude-code, cli, coding-agent, developer-memory, developer-tools, local-first, mcp, multi-machine, project-context

## 简介

A local-first memory and control layer for coding agents. Recognises the git repository you open your agent in, restores what you were doing, records what the session achieved, and syncs it across your machines through a private git repository you own.
