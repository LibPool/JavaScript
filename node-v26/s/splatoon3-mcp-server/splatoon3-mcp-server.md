# splatoon3-mcp-server

> 标签: ai, claude, mcp, model-context-protocol, splatoon, splatoon3

## 简介

MCP server providing Splatoon 3 schedule, weapon, and ranking data to AI assistants. Supports English, Chinese, and Japanese localization.
