# san-cli-init

> 标签: loader, san, san-cli, san.js

## 简介

san-cli-init 是 [San](https://github.com/baidu/san) CLI 工具中创建项目的核心功能部分。 是一个 [command 插件](https://ecomfe.github.io/san-cli/#/cmd-plugin)。
