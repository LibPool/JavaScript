# skill-automation

> 标签: HITL, mcp-gateway, security, skill-router, skill-search

## 简介

MCP 技能调度与搜索安全网关：技能路由（模糊匹配/澄清/HITL）、Prompt 注入防护、三态技能搜索（HIT/LOW/REJECT + 建议词引导 + 安装指引）、stdio + HTTP/SSE 双传输
