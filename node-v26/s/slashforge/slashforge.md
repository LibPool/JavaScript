# slashforge

> 标签: agents, ai, ai-coding-assistant, anthropic, claude, claude-code, cli, code-review, developer-tools, setup, slash-commands, workflow

## 简介

Workflow slash commands for AI coding agents — /slashforge:setup, /slashforge:code, /slashforge:investigate, /slashforge:review-pr. Currently supports Claude Code.
