# sync-to-wiki

> 标签: JavaScript

## 简介

Confulence wiki 本身提供的可视化编辑器较为复杂，在进行一些简单文档（基本文档 + 代码块）的编写时效率较低，并且不支持导入/导出 markdown 格式的文档。

## 官网

- npm 页面：https://www.npmjs.com/package/sync-to-wiki

- 1.0.1
