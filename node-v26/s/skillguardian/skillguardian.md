# skillguardian

> 标签: agent, ai, claude, mcp, prompt-injection, scanner, security, skills, static-analysis, supply-chain

## 简介

Security scanner for AI agent skills, plugins, and MCP configs. Catches prompt-injection, secret-exfiltration, and hidden-command patterns before you install them.
