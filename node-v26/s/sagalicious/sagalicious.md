# sagalicious

> 标签: api-orchestration, atomic, command-pattern, compensating-transactions, compensation, coordinator, database-transactions, distributed-transactions, eventual-consistency, microservices, orchestration, resilience, rollback, saga, saga-pattern, transaction-orchestration, transactions, two-phase-commit, typescript, workflow

## 简介

Orchestration-based Saga pattern implementation for TypeScript. Coordinate distributed transactions across databases, microservices, and APIs with automatic compensation on failure.
