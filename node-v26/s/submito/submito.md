# submito

> 标签: agent-skills, ajax, fetch, form, formdata, intl-tel-input, recaptcha, sweetalert2, turnstile, validation, vanilla

## 简介

Vanilla JS AJAX form submission: live validation, captchas, phone input and response dialogs. Zero dependencies.
