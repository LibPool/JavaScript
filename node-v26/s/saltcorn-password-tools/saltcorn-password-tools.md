# saltcorn-password-tools

> 标签: bcrypt, cram-md5, dovecot, hash, password, pbkdf2, saltcorn, saltcorn-plugin, sha512-crypt, zxcvbn

## 简介

Saltcorn plugin: hash plaintext passwords (BLF-CRYPT / SHA512-CRYPT / PBKDF2 / CRAM-MD5) with configurable Dovecot-compatible prefix and integrated password-strength meter (zxcvbn + rule checks).
