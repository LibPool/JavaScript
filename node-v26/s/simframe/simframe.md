# simframe

> 标签: agent, android, claude, claude-code, emulator, ios, mcp, model-context-protocol, screenshot, simctl, simulator, xcode

## 简介

Always-warm iOS Simulator and Android emulator frames: agents read the screen in ~20ms instead of waiting on screenshots. MCP server + CLI.
