# svgaplayer-tt

> 标签: JavaScript

## 简介

专为字节跳动小程序开发的 SVGA 播放器，已在 iOS 及 Android 手机上测试通过，由于字节跳动开发工具限制，暂不支持在开发工具预览。

## 官网

- npm 页面：https://www.npmjs.com/package/svgaplayer-tt

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install svgaplayer-tt`
- npm registry：https://registry.npmjs.org/svgaplayer-tt
