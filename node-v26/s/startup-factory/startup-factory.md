# startup-factory

> 标签: boiletplate, create, development, faster, framework, init, sass, startup, template

## 简介

Setup a web platform environment with boilerplate code. Includes: template engine, signup/registration system, job/tasks server, nginx configuration, automatic sass compiler/js minifier, S3 uploader...
