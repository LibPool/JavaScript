# sd-theme-transformer

> 标签: design-system, design-tokens, style-dictionary

## 简介

[This repository is based on e.uid's design system offline class](https://github.com/simseonbeom/offline-class/blob/main/build-theme.js)<br /> This plugin converts design tokens into esm, cjs, css and scss variables.
