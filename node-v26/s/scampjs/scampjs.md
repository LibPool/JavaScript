# scampjs

> 标签: design-tool, framework, hono, preact, scamp, vite

## 简介

The Scamp framework: structure, styles, and logic in separate files, on Vite, Preact, and Hono. scamp dev, scamp build with adapters, API routes, scamp add drizzle, and the templates export.
