# solid2-agent-kit

> 标签: agents-md, ai-agents, claude-code, cursor, skills, solid, solid-2, solid-js

## 简介

Teach AI coding agents (Cursor, Claude Code) to write correct Solid 2.0 instead of React or Solid 1.x — always-applied rules, an agent skill, and a mechanical pattern gate.
