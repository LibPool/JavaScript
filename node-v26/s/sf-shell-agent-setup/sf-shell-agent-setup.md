# sf-shell-agent-setup

> 标签: agent, ai, frontend, setup, shell

## 简介

脚手架工具，用于快速搭建和启动sf-shell-ai-agent和shell-agent-chat-ui开发环境，并自动打开浏览器和直接显示后端日志
