# silent-dto

> 标签: class-validator, dto, eslint, eslint-plugin, eslintplugin, mapped-types, mass-assignment, nest, nestjs, security, static-analysis, typescript, validation, validationpipe

## 简介

ESLint rule + CLI that finds NestJS @Body() parameters where ValidationPipe silently skips validation — Partial<T>, unknown, inline types and import() types all erase to Object.
