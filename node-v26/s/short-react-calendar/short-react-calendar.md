# short-react-calendar

> 标签: calendar react, date, date-picker, month-picker, one week calendar, short react calendar

## 简介

Clone from https://github.com/wojtekmaj/react-calendar.git. Support to display one week calendar that contains current day. Support expand / colapse calendar.
