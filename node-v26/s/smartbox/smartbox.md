# smartbox

> 标签: effect, javascript, jquery, lightbox, modal, plugin, responsive, ui, window

## 简介

smartbox is a popup layer plugin based on jquery.It supports drag、asynchronous access to html、asynchronous access to pictures, support iframe、 simple and diverse styles.
