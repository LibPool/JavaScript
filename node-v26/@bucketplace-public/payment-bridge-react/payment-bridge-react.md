# @bucketplace-public/payment-bridge-react

> 标签: JavaScript

## 简介

- 결제 프로세스를 쉽게 통합할 수 있도록 설계된 React SDK입니다. - 다양한 결제 수단을 지원하며, 결제 인증 프로세스를 간편하게 처리할 수 있습니다. - 본 문서는 `SDK의 적용 방법`에 대해 설명합니다.
