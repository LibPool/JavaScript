# @iovano/cangaroo

> 标签: animation, boxes, canvas, collision, matrix, motion, sprite, starfield

## 简介

This package provides a set of particle effects and animations based on pure javascript. You can use and edit them as you like. However, please credit the author if you use this library for public/commercial projects. Donations are welcome, too.
