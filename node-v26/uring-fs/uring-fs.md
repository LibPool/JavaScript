# uring-fs

> 标签: async, filesystem, fs, io_uring, liburing, libuv, linux, napi, non-blocking, performance, uring-fs

## 简介

True asynchronous Linux io_uring filesystem I/O for Node.js with zero libuv thread-pool usage, automatic tick batching, and pluggable fallback backends.
