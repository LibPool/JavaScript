# @rendkit/cli

> 标签: agentic, ai, cli, copilotkit, generative-ui, rendkit, scaffold, shadcn

## 简介

The Rendkit catalog CLI — `rendkit init` scaffolds config + a <RndProvider> into your app, `rendkit doctor` checks the setup (config, adapter, @copilotkit boundary, portable-schema guards). Components are added with `npx shadcn add @rendkit/<name>`.
