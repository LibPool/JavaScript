# @shipworthy/openapi-react-query

> 标签: JavaScript

## 简介

Typed [TanStack Query](https://tanstack.com/query) hooks for React, driven by the `paths` type generated from an OpenAPI document. You pass your generated `paths` interface once, then call hooks with a URL path such as `"/pets/{pet_id}"`. TypeScript infer
