# @agentpulsehq/core

> 标签: ai-agents, content-signals, crawler, express, hono, llm, markdown, middleware, nextjs

## 简介

Detect AI agents, serve them clean Markdown, declare Content Signals and send telemetry to AgentPulse. Adapters for Hono, Express and Next.js 16.
