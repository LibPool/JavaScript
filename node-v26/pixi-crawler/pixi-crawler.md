# pixi-crawler

> 标签: debug, fps, gpu, hud, performance, pixi, pixi-silk, pixi.js, pixijs, profiler, spine, telemetry

## 简介

Drop-in performance crawler for PixiJS 8: per-frame phase timing, workload counters, true GPU time, Spine profiling with live pose metrics, telemetry, and a HUD + frame inspector drawn with pixi-silk.
