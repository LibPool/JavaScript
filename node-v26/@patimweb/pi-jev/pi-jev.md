# @patimweb/pi-jev

> 标签: calibration, confidence, decision, guardrail, jev, pi-extension, pi-package, system-one, token-optimization, triage, typesafe, verification

## 简介

Typed decision layer for the pi coding agent. Jev answers bounded questions with calibrated probabilities, so pi filters, verifies and gates cheaply instead of spending frontier tokens and turns on it.
