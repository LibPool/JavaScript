> 标签: ai-app-builder, ai-apps, app-builder, app-runtime, atomic-writes, bounded, full-stack, node, policy, realtime-backend, sdk, server, typescript, webhooks

## 简介

Node and server SDK for Bounded, the full-stack app builder and runtime for AI-built apps: keypair-authenticated data, files and search, functions, realtime, webhook verification, and atomic writes.
