# @clubplanner/partner-api-mcp

> 标签: club-management, clubplanner, fitness, gym, mcp, model-context-protocol

## 简介

Model Context Protocol server for the Club Planner Partner API. Lets MCP-aware AI tools (Claude Desktop, Cursor, Zed, …) call a Club Planner platform's partner API with a configured X-API-Key.
