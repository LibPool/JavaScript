# @liaogn/react-drag-resize-rotate

> 标签: drag, draggable, react, resizable, resize, rotatable, rotate

## 简介

React component for dragging, resizing, and rotating DOM elements. Simple, dependency-free, supports nesting / aspect-lock / flipping.
