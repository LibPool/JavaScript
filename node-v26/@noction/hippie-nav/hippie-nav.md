# @noction/hippie-nav

> 标签: actions, flexsearch, keyboard shortcut, navigation, routing, search, utility, vue router, vue.js

## 简介

The "hippie-nav" module is a lightweight and dependency-free utility designed to navigate through routes in Vue.js applications using Vue Router. It enables seamless navigation and allows for the execution of custom actions associated with specific routes
