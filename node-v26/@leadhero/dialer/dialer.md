# @leadhero/dialer

> 标签: call-through-api, dialer, leadhero, telnyx, webrtc

## 简介

LeadHero call-through-API client: place calls, answer the agent leg, manage mic/speaker devices, and receive live pickup/AMD events. Framework-agnostic.
