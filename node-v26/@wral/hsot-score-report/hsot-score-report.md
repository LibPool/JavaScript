# @wral/hsot-score-report

> 标签: JavaScript

## 简介

Lit web component for the HighSchoolOT "Report a Score" page: an anonymous form, driven by an api-forms document, that e-mails the HSOT desk through the HSOT stage of api-forms. Purely an e-mail — a person reads every report before a score is entered.
