# @relai-fi/subscriptions-react

> 标签: drop-in, payments, pricing, pricing-table, react, recurring, relai, solana, stablecoin, subscriptions, ui, usdc

## 简介

Drop-in React UI for RelAI subscriptions — a Stripe-style pricing table and subscribe button for recurring USDC billing on Solana. Wallet-agnostic, themeable, no API key in the browser.
