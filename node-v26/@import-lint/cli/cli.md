# @import-lint/cli

> 标签: cli, eslint, import, javascript, jsdoc, lint, linter, typescript

## 简介

Enforces directory-level encapsulation in TypeScript/JavaScript: tag an export @package and only files in or below its directory can import it. Fast Rust CLI, no TypeScript compiler or ESLint needed (a port of eslint-plugin-import-access)
