# @devsahu/loggify

> 标签: JavaScript

## 简介

A tiny, colorful, emoji-enhanced logger for Node.js projects — powered by [chalk](https://github.com/chalk/chalk). Perfect for CLI tools, debug logs, or just having some fun in your terminal.
