# @younggichoi/claude-secretmode

> 标签: anthropic, claude, claude-code, ephemeral, incognito, macos, no-history, privacy, ramdisk, secret

## 简介

Leave-no-trace ephemeral Claude Code sessions on macOS — runs Claude Code on a RAM disk so transcripts, prompt history and snapshots never touch disk and evaporate on exit.
