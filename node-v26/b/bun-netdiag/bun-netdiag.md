# bun-netdiag

> 标签: arp, bun, diagnostics, dns, ffi, netstat, network, ping, routing, traceroute, typescript, wifi, win32, windows

## 简介

Syscall-grade network diagnostics for Bun on Windows — routing table, socket→PID map, no-admin ICMP ping/traceroute, ARP, DNS, live throughput, and WiFi — decoded from binary structs, zero native dependencies, no netsh/ping.exe/wmic scraping.
