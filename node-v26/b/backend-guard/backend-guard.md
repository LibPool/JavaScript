# backend-guard

> 标签: backend-security, cors, express, helmet, ip-blacklist, joi, middleware, nestjs, nestjs-module, nestjs-security, rate-limit, request-logging, security, validation, xss, zod

## 简介

All-in-one security middleware for Express.js, Fastify and NestJS — helmet, cors, rate-limit, XSS protection, input validation, request logging & IP blacklist in a single config.
