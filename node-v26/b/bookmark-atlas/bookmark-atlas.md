# bookmark-atlas

> 标签: bookmarks, fts5, github-stars, knowledge-base, mcp, pi, pi-package, sqlite

## 简介

Local SQLite knowledge base for your GitHub stars and X bookmarks, with full-text search, a CLI, an MCP server, and a pi search palette.
