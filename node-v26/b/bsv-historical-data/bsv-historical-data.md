# bsv-historical-data

> 标签: bitcoin-sv, blockchain, bsv, crypto, csv, dataset, difficulty, historical-data, mining, rich-list

## 简介

Weekly Bitcoin SV (BSV) network snapshots as JavaScript: top 100 rich list and mining difficulty history, parsed from the open bitcoinsv-data CSV repository.

## 官网

- 官网：https://bitcoinsv.it/rich-list/
- 源码仓库：git+https://github.com/bitcoinsv-data/bitcoin-sv-historical-data.git
- npm 页面：https://www.npmjs.com/package/bsv-historical-data
