# br-data-kit

> 标签: boleto, br-data, brasil, brl, cep, cli, cnh, cnpj, cpf, documentos-br, ibge, ie, pispasep, placa, react-hooks, react-native, renavam

## 简介

Kit completo de utilitários brasileiros: validação, máscaras, formatação BRL, CEP/CNPJ com cache e fallback, IBGE, boleto, hooks React Native e CLI — zero dependências.
