# bigquery-local

> 标签: bigquery, duckdb, emulator, gcp, local-development, nodejs, sql, testing, typescript

## 简介

Node.js + DuckDB local emulator for the Google BigQuery REST API. Drop-in for testing, CI, and local dev — with working PATCH.
