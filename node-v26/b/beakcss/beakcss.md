# beakcss

> 标签: classless, css, css-variables, framework, minimal, no-sass, picocss-fork, semantic

## 简介

Beak CSS — a classless-only fork of Pico CSS. Pure CSS, cascade layers, no SASS, CSS variables for colors and measures.
