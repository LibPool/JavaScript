# blogwright-analytics

> 标签: analytics, cloudfront, firehose, iceberg

## 简介

Traffic analytics for blogwright: CloudFront access logs routed through Firehose into an Iceberg table, with a local dashboard. Installed on demand with `blogwright plugin add analytics`, never shipped with the CLI.
