# bangla-pdf

> 标签: bangla, bengali, bijoy, harfbuzz, opentype, pdf, pdf-lib, shaping, unicode

## 简介

Correctly shaped Bangla (Bengali) text in PDFs, and reading it back out. HarfBuzz shaping, Type0/Identity-H CID fonts with /ActualText so copy-paste returns the original Unicode.
