# blazze

> 标签: API Request Caching, CLI, Directory router, Express JS, Nodejs, REST APIS, Site builder, Typesafe, Typesafe APIS, Web server, blazze.js, javascript, swc, typescript

## 简介

The express framework for the web. Write Typesafe API's with no configuration and boiler-plate with dynamic directory based routing and intuitive CLI.
