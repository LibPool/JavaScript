# brpix-api-node

> 标签: api, client PSP, gerencianet, nodejs, pix, qrcode

## 简介

Essa é uma lib para fluxo de pagamento com o PIX. Utiliza para os testes o (PSP) endpoint da [GERENCIANET.COM.BR](https://gerencianet.com.br/pix/)
