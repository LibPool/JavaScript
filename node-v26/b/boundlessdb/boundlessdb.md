# boundlessdb

> 标签: cqrs, dcb, dynamic-consistency-boundaries, event-sourcing, event-store, postgresql, sqlite, typescript

## 简介

A DCB-inspired event store library for TypeScript — with support for SQLite, PostgreSQL, in-memory
