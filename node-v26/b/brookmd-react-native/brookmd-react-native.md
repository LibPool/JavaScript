# brookmd-react-native

> 标签: ai, android, ios, jsi, llm, markdown, react-native, rust, streaming, turbomodule, uniffi

## 简介

Streaming markdown for React Native. Rust core over uniffi (JSI TurboModule), incremental parse, RN-native renderer.
