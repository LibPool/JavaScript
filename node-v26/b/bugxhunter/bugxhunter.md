# bugxhunter

> 标签: ai-agent, bug-bounty, code-review, opencode, pentest, security, vulnerability-scanner

## 简介

BugXHunter: an AI security-testing agent with a sandboxed runner, a passkey-sealed key vault and read-only GitHub access. `npx bugxhunter` runs it on your machine.
