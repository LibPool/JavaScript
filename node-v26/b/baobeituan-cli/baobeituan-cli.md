# baobeituan-cli

> 标签: JavaScript

## 简介

宝贝团脚手架，可快速创建PC项目、H5项目、微信小程序、淘宝小程序、支付宝小程序等。 这是参考[vue-cli@v2](https://github.com/vuejs/vue-cli/tree/v2)来写的一个脚手架
