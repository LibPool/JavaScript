# buddyx

> 标签: agent, agent-skill, ai, buddyx, claude, claude-code, cursor, delegation, opencode, orchestrator, skill, sub-agents

## 简介

CLI to install the BuddyX skill — a master orchestrator that plans, routes to specialized sub-agents, fans out in parallel, verifies through a review gate, and reports — into AI coding assistants like Claude Code and opencode.
