# bettertouchtool

> 标签: automation, bettertouchtool, btt, floating-menu, macos, shortcuts, streamdeck, touchbar

## 简介

Official, typed JavaScript/TypeScript client for BetterTouchTool's scripting API (webserver, unix socket, or in-process). AI generated & maintained by folivora.AI. Successor to the unmaintained `btt` package.
