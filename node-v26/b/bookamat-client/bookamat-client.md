# bookamat-client

> 标签: accounting, agent, api-client, austria, bookamat, bookkeeping, cli, typescript

## 简介

TypeScript client and CLI for the bookamat API (Austrian bookkeeping) — one descriptor per resource, agent-friendly CLI with JSON I/O.
