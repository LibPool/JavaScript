# botbuilder-wit-remade

> 标签: botbuilder, bots, chatbots, nlp, wit.ai

## 简介

Fork of botbuilder-wit with modifications for last version of Wit.ai. Provides Wit.ai NLP integration for the Microsoft Bot Builder SDK. Supports caching with Redis and Memcached.
