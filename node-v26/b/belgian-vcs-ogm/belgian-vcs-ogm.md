# belgian-vcs-ogm

> 标签: gestructureerde mededeling, mededeling, ogm, structured message, vcs

## 简介

OGM, 'overschrijving met gestructureerde mededeling', is a structured message often added to belgian bank transfers to enable automatic processing. This package enables the generation and validation of these structured messages
