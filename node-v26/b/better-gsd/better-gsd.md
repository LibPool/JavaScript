# better-gsd

> 标签: autonomous, better-gsd, bgsd, claude-code, claude-code-plugin, gsd, installer, launcher, orchestration, verification

## 简介

One-line launcher for bgsd: installs the bgsd Claude Code plugin from the public GitHub marketplace and sets up the gsd-core engine. Run with npx better-gsd@latest.
