# bb_pix

> 标签: JavaScript

## 简介

- Criar cobrança PIX QRCode - Atualizar cobrança - Consultar status PIX (pendente, pago, cancelado...) - Consultar lista de PIXs pagos (informa o intervalo de tempo e retorna tds os PIXs pagos)
