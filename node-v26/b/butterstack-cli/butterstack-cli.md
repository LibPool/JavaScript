# butterstack-cli

> 标签: butterstack, ci-cd, cli, gamedev, perforce, unreal-engine

## 简介

Fast, scriptable, zero-dependency command line interface for the ButterStack game development pipeline: auth, projects, tasks, builds, and asset approvals.
