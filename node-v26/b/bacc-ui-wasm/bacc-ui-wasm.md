# bacc-ui-wasm

> 标签: JavaScript

## 简介

Rust/WebAssembly visualization primitives for baccarat data produced by [bacc-rs](https://github.com/soltez/bacc-rs) and [bacc-ts](https://github.com/soltez/bacc-ts).
