# bloxcloud

> 标签: Roblox

## 简介

NOTE: THIS ISN'T PROPERLY MAINTAINED, it's mostly for personal use. Adapts the Roblox Open Cloud API for NodeJS, just a simple module that probably isn't going to be well maintained. Just puts all the functions found in the Roblox Open Cloud into NodeJS,
