# balage-core

> 标签: ai-agent, anthropic, browser-automation, browser-use, computer-use, confidence-score, dom-parser, element-detection, firecrawl, form-detection, login-detection, mcp, page-analysis, playwright, stagehand, ui-testing, web-agent, web-scraping

## 简介

Detect login forms, search bars, and checkout flows from URLs or HTML. Firecrawl + Playwright auto-detection. No browser required.
