> 标签: agents, ai, botverse, claude, conversion, document, llm, mcp, model-context-protocol, transcoding, video

## 简介

Botverse for AI agents and the command line — video transcoding, video/audio conform + splice (slates, bumpers, end cards, joined clips), document conversion (incl. PowerPoint/Excel/Word → PDF), transcription, and multi-step workflows chaining these opera
