# bitcoinjs-lib-wrapper

> 标签: bitcoin, bitcoinjs-lib, blockchain, javascript, library, typescript, wallet, wrapper

## 简介

A Typescript/JavaScript wrapper for bitcoinjs-lib [v3.3.2], simplifying hd wallet, bech32 wallet and legacy wallet operations and adding types
