# brily-flow-react

> 标签: analytics, autocapture, brily, funnel, pageview, product-analytics, react

## 简介

React Provider + hook for Brily Flows. Wraps brily-flow so you can <BrilyFlowProvider token="..."> at the root and useBrilyFlow() anywhere.
