# beam-overlay

> 标签: beam, glsl, lidar, overlay, proximity, radar, range-sensor, robotics, sensor, shader, three, threejs, ultrasonic, visualization, webgl

## 简介

Three.js overlay for directional range-sensor detection volumes (ultrasonic, radar, IR, ToF) with correct multi-beam surface culling via GLSL
