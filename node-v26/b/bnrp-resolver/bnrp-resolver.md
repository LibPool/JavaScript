# bnrp-resolver

> 标签: bitcoin, bnrp, btc-names, btcname, identity, inscriptions, name-resolution, ordinals

## 简介

Bitcoin Name Resolution Protocol (BNRP) resolver. Resolves .btc, .sats, .unisat, .x, .xbt, .sat names to on-chain identity records.
