# bitcoinlib-rn

> 标签: JavaScript

## 简介

A modern, lightweight Bitcoin utility library for React Native and Expo environments. Built on top of the latest cryptographic primitives, with zero Node.js dependencies, and fully compatible with mobile and web platforms.
