# benchpress-guard

> 标签: agents, ai, ai-agents, ai-sdk, benchpress, guardrails, policy, receipts, reliability, safety, tool-calling, tools, vercel-ai-sdk

## 简介

Code-enforced tool policy for Vercel AI SDK agents: classify every tool call, refuse what the policy does not allow before execute runs, and keep JSONL receipts. The Benchpress guard, byte-compatible with the Python shims.
