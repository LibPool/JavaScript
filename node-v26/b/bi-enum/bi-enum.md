# bi-enum

> 标签: bidirectional, enum

## 简介

BiEnum 是一种静态枚举方案，是 TypeScript 原生枚举（enum）的加强版。BiEnum is a static enumeration scheme, which is an enhanced version of TypeScript's native enum.
