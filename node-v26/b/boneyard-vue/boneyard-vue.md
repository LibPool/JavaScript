# boneyard-vue

> 标签: loading, placeholder, skeleton, skeleton-screen, vue, vue3, zero-layout-shift

## 简介

Pixel-perfect skeleton loading screens for Vue 3. Wrap your component in <BoneyardSkeleton> and boneyard snapshots the real DOM layout.
