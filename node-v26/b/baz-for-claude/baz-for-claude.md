# baz-for-claude

> 标签: agentic, ai-agent, baz, claude, claude-code, feedback, frame-accurate, motion-graphics, remotion, video, video-review

## 简介

Frame-accurate video feedback for AI coding agents. Pause a hosted video, type a note, and it lands in your agent's context with the exact frame number and a still of that frame.
