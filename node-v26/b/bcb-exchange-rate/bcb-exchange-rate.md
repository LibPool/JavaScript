# bcb-exchange-rate

> 标签: api, banco, bcb, brasil, brazil, brl, central, central-bank, currency, do, exchange-rate, exchange-rates, forex, fx, official-rates, typescript

## 简介

Official Banco Central do Brasil (Brazil) daily exchange rates — 156 currencies vs BRL, history since 2016. Zero-dependency Node.js/TypeScript client.
