# beckyos

> 标签: agent, ai, ai-agents, becky, beckyos, claude, cli, codex, coding-agent, developer-tools, llm, multi-agent, sdlc

## 简介

Becky — a multi-agent coding OS. 15 agents, a 14-phase SDLC, three hard gates, and loop modes that stop on runtime proof, never on an agent saying "done."
