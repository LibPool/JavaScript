# brixpackager

> 标签: brix, bundler, cli, desktop-app, lightweight, packaging, webview2

## 简介

Brix is a lightweight CLI tool that packages web apps into standalone Windows executables using native WebView2. Features include custom protocol asset serving, embedded backend support, SHA-256 verification, and installer generation.
