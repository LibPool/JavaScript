# basic-ftp-fixed

> 标签: async, await, fix, ftp, ftps, ipv6, promise, tls, tls1.3, typescript, vsftpd

## 简介

Fork of basic-ftp with fixes for TLS 1.3 upload failures (vsftpd 426 bug) and passive mode listener leaks.
