# browsebrowsebrowse

> 标签: agent-skill, browser-automation, cdp, chrome-headless-shell, claude-code, cli, headless-chrome, pdf, puppeteer, screenshot

## 简介

Headless Chrome CLI for coding agents. Screenshots, PDFs, rendered HTML/text and page JS from the shell — cold by default, optionally daemonised. Sibling of domdomdom, which does DOM work with no browser at all.
