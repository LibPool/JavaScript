# boarding-pass-kit

> 标签: airline, barcode, bcbp, boarding-pass, heic, iata, qr-code

## 简介

Parse IATA BCBP v8 boarding pass barcodes from strings or PNG/JPEG/HEIC images (QR, Aztec, PDF417)
