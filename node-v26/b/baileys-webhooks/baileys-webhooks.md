# baileys-webhooks

> 标签: baileys, event-dispatcher, http, nodejs, webhooks, whatsapp, whatsapp-bot

## 简介

Drop-in webhook dispatcher for Baileys WhatsApp bots with HMAC signing, retries, and timeout handling
