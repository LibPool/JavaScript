# brainferno-mcp-bridge

> 标签: adobe, after-effects, audition, automation, claude, illustrator, mcp, media-encoder, model-context-protocol, photoshop, premiere-pro, video

## 简介

MCP server that lets an AI assistant drive Adobe Photoshop, After Effects, Premiere Pro, Illustrator, Audition and Media Encoder software. Independent project, not affiliated with Adobe.
