# bojuvue

> 标签: component-library, download-button, platform-detection, typescript, vite, vitepress, vitepress-components, vitepress-theme, vue, vue3

## 简介

Vue 3 components including a download button that serves each visitor the right build for their OS. Works in any Vue 3 app; VitePress-aware variants included.
