# breach-gate

> 标签: api-security, ci-security, cisa-kev, dast, deploy-gate, devsecops, epss, exploit-verification, github-actions, openapi, owasp, vulnerability-scanner

## 简介

API deploy gate. Blocks a deployment only on proven exploitation, with EPSS and CISA KEV prioritisation and published precision numbers.
