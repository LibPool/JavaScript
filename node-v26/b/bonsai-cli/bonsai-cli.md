# bonsai-cli

> 标签: dead-code, depcheck, javascript, knip, monorepo, rust, static-analysis, typescript, unused, unused-dependencies, unused-exports, unused-files

## 简介

Fast dead-code detector for JavaScript/TypeScript monorepos: unused files, unused exports, unused dependencies. Single Rust binary, no Node toolchain needed.
