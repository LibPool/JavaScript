# baloosearch-mcp

> 标签: ai, baloo, baloosearch, claude, file-search, kde, mcp, model-context-protocol, semantic-search

## 简介

A Model Context Protocol (MCP) server that provides file search functionality using KDE's baloosearch tool. Allows AI assistants to search your files using natural language queries.
