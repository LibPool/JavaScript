# builders-diary

> 标签: ai-builder, claude, cursor, mcp, portfolio, skill

## 简介

Record what you actually judged in a work session — a local, judgment-first portfolio for AI-native builders. Installs a skill into Claude Code, Cursor, Windsurf, Codex, or Antigravity.
