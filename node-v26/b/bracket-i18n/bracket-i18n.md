# bracket-i18n

> 标签: cli, gemini, gender, i18n, internationalization, intl, localization, machine-translation, nextjs, plural, react, translation, typescript

## 简介

AI-assisted i18n for TypeScript: write [[text]] inline, get IDs and optional machine drafts, then review via CSV/pending/lock — plus [[--n]] / [[--g]] / [[--n --g]] and plural/gender resolution.
