# better-auth-adapter-prisma8

> 标签: adapter, auth, authentication, better-auth, database, postgresql, prisma, prisma-8, prisma-next, typescript

## 简介

Better Auth database adapter for Prisma 8 (Prisma Next, contract-first) — built from scratch against the db.orm runtime, not a port of the classic Prisma Client adapter.
