# babel-plugin-autotrack-debugger

> 标签: JavaScript

## 简介

在指定的地方中打上log，观看项目代码运行到了哪里。使用场景：非语法类型的 bug 控制台不报错，难以定位到问题。此插件用于辅助定位代码运行情况。
