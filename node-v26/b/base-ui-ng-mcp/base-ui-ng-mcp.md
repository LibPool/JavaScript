# base-ui-ng-mcp

> 标签: angular, base-ui, base-ui-angular, cli, mcp, model-context-protocol, tailwindcss

## 简介

Base UI (Angular) MCP server — stdio or Streamable HTTP (--http). List, search, init, doctor, diff, update, and add Angular + Tailwind components (Pro with BASE_UI_LICENSE_KEY). Not MUI Base UI.
