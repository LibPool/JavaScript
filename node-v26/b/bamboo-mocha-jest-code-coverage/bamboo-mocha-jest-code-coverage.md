# bamboo-mocha-jest-code-coverage

> 标签: bamboo, code, coverage, jest, mocha, parser, test

## 简介

Formats Jest code coverage report for Bamboo's Mocha Test Parser, so Bamboo can consume Jest code coverage reports.
