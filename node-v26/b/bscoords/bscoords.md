# bscoords

> 标签: base station, bts, cellid, cepp2gps, cid, coordinate, geolocation, google, gsm, lac, latitude, location, longitude, lte, mcc, mnc, mozilla location service, mozlocation, mylnikov, opencellid, umts, yandex

## 简介

Get location based on (MCC, MNC, LAC, CellID) using Google, Yandex, OpenCellID, cell2gps, Mylnikov Geo and Mozilla Location Service
