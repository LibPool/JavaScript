# browxai

> 标签: agentic, ai-agent, browser-automation, browser-control, cdp, mcp, model-context-protocol, playwright

## 简介

MCP-native, model-agnostic control for agents over one tool surface. Eight engines in three families: five browsers including real Safari and Chrome on an Android device, native apps on an Android emulator and the iOS Simulator, and a running desktop Elec
