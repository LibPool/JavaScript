# bankmcp

> 标签: banking, chatgpt, claude, enable-banking, mcp, mcp-server, model-context-protocol, open-banking, personal-finance, psd2, self-hosted

## 简介

BankMCP™: self-hosted, read-only MCP server that lets any AI assistant (Claude, ChatGPT, Mistral, Cursor, or a local model) answer questions about your own bank accounts via open banking (Enable Banking, PSD2)
