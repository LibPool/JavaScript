# banyan-cli

> 标签: claude-code, cli, developer-tools, git-worktree, mcp, monorepo, multi-repo, tmux, workflow

## 简介

tmux + git worktrees + Claude Code. Run N AI agents in parallel across N repos with isolated worktrees, dev ports, and docker stacks per feature.
