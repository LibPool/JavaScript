# brickssnap

> 标签: JavaScript

## 简介

BricksSnap ist ein Next.js Tool, das sofort importierbare **Bricks Builder JSON-Templates** generiert. Du kannst vorgefertigte Sections nutzen oder per Prompt ganze Layouts erzeugen und direkt als Bricks-kompatible JSON exportieren.
