# bookkeeper-cli

> 标签: JavaScript

## 简介

BookKeeper（`bk`）是一个 **strongly opinionated** 的 CLI 工具，用于管理在同一台机器上并行运行多个 git worktree 时所需的本地资源与基础设施。

## 官网

- npm 页面：https://www.npmjs.com/package/bookkeeper-cli

## 历史版本号

- 0.0.14

## 获取地址

- npm 安装：`npm install bookkeeper-cli`
- npm registry：https://registry.npmjs.org/bookkeeper-cli
- Node 要求：>=20
