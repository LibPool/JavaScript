# beacon-agents

> 标签: agent, ai-agents, claude, claude-code, collision-avoidance, coordination, cursor, developer-tools, hooks, mcp, parallel, presence

## 简介

Real-time presence and collision-avoidance for parallel AI coding agents. See what every Claude Code / MCP / CLI agent is touching — and never let two agents clobber the same file again.
