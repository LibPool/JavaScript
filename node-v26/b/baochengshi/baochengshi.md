## 简介

[toc] ## 操作指南 1. 首先注册一个npm账号 2. 打开文件(最好不要在系统c盘里的文件),进行初始化 npm init生成配置文件，并更改相关配置 3. 整理好要发布的包后，运行npm login 登录用户名 (bcs) 密码 4. 直接执行npm publish发包(可能会报npm的错，需要将淘宝镜像改掉即可，运行npm config set registry=http://registry.npmjs.org)
