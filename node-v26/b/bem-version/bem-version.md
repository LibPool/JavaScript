# bem-version

> 标签: JavaScript

## 简介

Version helper link `npm version` as a bem-tools command extension. Works with package.json and bower.json files.

- 官网：http://github.com/bem/bem-version
- 源码仓库：git://github.com/bem/bem-version.git
- npm 页面：https://www.npmjs.com/package/bem-version
