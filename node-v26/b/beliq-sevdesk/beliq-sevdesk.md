# beliq-sevdesk

> 标签: beliq, conversion, cron, e-invoice, einvoice, en16931, factur-x, peppol, sevdesk, validation, worker, xrechnung, zugferd

## 简介

Self-hostable worker that polls sevDesk for e-invoices, converts each to the formats a counterparty needs, and validates them against beliq's authority-pinned, drift-checked rules. The sevDesk token never leaves your environment.
