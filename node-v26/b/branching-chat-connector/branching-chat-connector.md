# branching-chat-connector

> 标签: JavaScript

## 简介

本机「陪读」连接器：把你已登录的 Claude（Agent SDK）或 Codex CLI（App Server）暴露成 OpenAI 兼容接口，供 Branching Chat 的「claude-cli / codex-cli（本机）」模型调用。只监听 127.0.0.1，不收集任何密钥。
