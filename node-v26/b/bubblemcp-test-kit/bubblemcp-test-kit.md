# bubblemcp-test-kit

> 标签: agent, agent-testing, assertions, chaos-testing, ci, cli, fault-injection, json-schema, mcp, mock, model-context-protocol, prompt-injection, regression-testing, security, test, testing, tool-poisoning

## 简介

Testing toolkit for Model Context Protocol (MCP) servers and the agents that use them — fluent assertions, regression baselines, agent tool-call trace testing, failure injection, and security scanning. No account, no backend required.
