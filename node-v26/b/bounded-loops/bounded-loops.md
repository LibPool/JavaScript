# bounded-loops

> 标签: agent-loops, ai-agents, ai-reliability, bounded-loops, gate, loop-engineering, mcp

## 简介

npx launcher for the bounded-loops graph engine: 69 loop folders, 65 keyless, independent gates and receipt-backed runs. Requires Python 3.11+.
