# beeshell

> 标签: JavaScript

## 简介

<p align="center">     <h3 align="center">beeshell 2.0</h3>     <p align="center">     一个 React Native 应用的基础组件库，基于 0.53.3 版本，提供一整套开箱即用的高质量组件，包含 JS 组件和复合组件（包含 Native 代码），涉及 FE、iOS、Android 三端技术，兼顾通用性和定制化，支持自定义主题，用于开发和服务企业级移动应用。     </p> </p>
