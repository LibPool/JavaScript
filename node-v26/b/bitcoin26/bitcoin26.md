# bitcoin26

> 标签: JavaScript

## 简介

Bitcoin26 is a live rate index of famous cryptocurrency *bitcoin*, it shows realtime price of bitcoin in currency USD or provided by user. #HowToUse Run *bitcoinrate* command in terminal to see live rate of bitoin as a colorfull output.
