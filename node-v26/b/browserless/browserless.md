# browserless

> 标签: JavaScript

## 简介

The headless Chrome/Chromium driver on top of Puppeteer. Take screenshots, generate PDFs, extract text and HTML with a production-ready API.

- 源码仓库：git+https://github.com/microlinkhq/browserless.git#master
