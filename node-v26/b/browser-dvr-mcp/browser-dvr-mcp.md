# browser-dvr-mcp

> 标签: agent-tools, ai-agents, browser, browser-automation, cdp, chrome, chrome-devtools-protocol, claude, debugging, dvr, flight-recorder, har, llm, mcp, mcp-server, model-context-protocol, observability, playwright-alternative, puppeteer, session-replay, time-travel-debugging, web-debugging

## 简介

A DVR and time-travel debugger for AI browser agents (MCP). Records every session — screen, DOM, network, console, storage — with provenance, so an agent can rewind to the moment it broke and see exactly what happened.
