# bitrock-wallet-ripple-lib

> 标签: JavaScript

## 简介

A JavaScript API for interacting with Ripple in Node.js and the browser. This is a modified version of ripple-lib with version number following ripple-lib releases.

## 官网

- 官网：https://github.com/ripple/ripple-lib#readme
- 源码仓库：git://github.com/ripple/ripple-lib.git
- npm 页面：https://www.npmjs.com/package/bitrock-wallet-ripple-lib
