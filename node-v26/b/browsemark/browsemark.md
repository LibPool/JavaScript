# browsemark

> 标签: cli, docs-as-code, documentation, live-reload, markdown, markdown-viewer, mermaid, prd, spec-driven, viewer, wiki-links

## 简介

Browse and annotate your codebase docs in the browser. Annotations flow to AI coding agents via MCP. Zero config.
