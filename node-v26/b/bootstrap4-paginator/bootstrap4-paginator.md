# bootstrap4-paginator

> 标签: bootstrap, bootstrap4, pagination, paginator

## 简介

Bootstrap4 Paginator is a jQuery plugin that simplifies the rendering of Bootstrap v4 Pagination component. It provides methods to automates the update of the pagination status and also some events to notify the status changes within the component.
