# botify-eslint-import-resolver-webpack

> 标签: eslint, eslint-plugin-import, jsnext, modules, webpack

## 简介

Resolve paths to dependencies, given a webpack.config.js. Plugin for eslint-plugin-import. Forked from Ben Mosher's repo to create a new release used at Botify.
