# best-calendar

> 标签: calendar, count down, 日历

## 简介

this calendar lib encapsulation calendar's algorithm for get calendar data, have not DOM, you can customization style by yourself. 一个可以自己定制样式的日历库，没有dom操作， 只封装了日历的算法，得到需要的日历数据。
