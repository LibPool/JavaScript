# bento-deck

> 标签: hotkey, mac-app, macos, macro, menubar, open-source, productivity, stream-deck, swiftui

## 简介

A minimal, fun, open-source soft Stream Deck for macOS. No hardware, no subscription. Built in SwiftUI.
