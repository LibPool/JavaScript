# brandpilot-mcp

> 标签: brandpilot, design-system, designflow, mcp, model-context-protocol

## 简介

MCP server for BrandPilot (DesignFlow): browse public design systems, pull a design's continuation bundle and prompt pack, and hand finished external work back - natively from Claude Code, Claude Desktop, Cursor or any MCP client.
