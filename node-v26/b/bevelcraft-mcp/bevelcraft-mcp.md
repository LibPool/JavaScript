# bevelcraft-mcp

> 标签: bevelcraft, cad, claude, mcp, model-context-protocol

## 简介

MCP server for BevelCraft in the browser: lets Claude Code and other MCP clients model in the BevelCraft window you have open.

- 官网：https://bevelcraft.com
- npm 页面：https://www.npmjs.com/package/bevelcraft-mcp
