# babel-plugin-pointer

> 标签: accessibility, babel, babel-plugin, click, css, cursor, jsx, pointer, react, ui, ux, vue, vue3

## 简介

A Babel plugin that automatically adds cursor: pointer to elements with click events. Supports Vue 3 and React with intelligent CSS detection.
