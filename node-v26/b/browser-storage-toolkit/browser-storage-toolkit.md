# browser-storage-toolkit

> 标签: browser, browser-storage, cookie, cookies, local-storage, localstorage, nextjs, session-storage, sessionstorage, ssr, ssr-safe, storage, storage-wrapper, typescript, utility

## 简介

A lightweight, SSR-safe, unified browser storage toolkit for Cookies, localStorage, and sessionStorage. Built with TypeScript. Zero dependencies.
