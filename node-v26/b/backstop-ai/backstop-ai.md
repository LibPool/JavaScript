# backstop-ai

> 标签: audit, budget, cache, circuit-breaker, fallback, guardrails, llm, openai

## 简介

In-process LLM guardrails for the OpenAI SDK — drop-in budget, priority admission, AIMD concurrency, circuit breaker, retry, fallback chains, caching, hooks, audit, and agent guardrails, mirroring the Python backstop.wrap().
