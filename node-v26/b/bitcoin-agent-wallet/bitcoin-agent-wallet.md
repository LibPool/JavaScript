# bitcoin-agent-wallet

> 标签: agent, autonomous, bitcoin-schema, bitcoin-sv, brc-100, brc-29, brc-42, bsv, keychain, messagebox, peerpay, wallet

## 简介

BRC-100 native wallet primitive for autonomous agents on BSV. Wraps @bsv/wallet-toolbox with OS-keychain identity storage, standard PeerPay funding via @bsv/message-box-client, and a broadcast() primitive for arbitrary Bitcoin Schema / locking scripts.
