# byte-parser

> 标签: byte-parser, file-size, parse-byte, size-parser

## 简介

Parse byte string to byte number, e.g. 1.2 Kb -> 1228.8, Kb, Mb, Gb, Tb, Pb, Eb, Zb, Yb supported.
