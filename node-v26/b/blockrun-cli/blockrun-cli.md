# blockrun-cli

> 标签: ai, blockrun, cli, crypto, micropayments, usdc, wallet, x402

## 简介

Command-line access to real-time markets, research, web search, and crypto data — 18 commands, no API keys, pay per call via x402 USDC micropayments on Base/Solana.
