# blockmate

> 标签: LLM, agent, educhain, langgraph, typescript

## 简介

BlockMate is a collection of LangChain agents and tools for building Educational Decentralized Applications. It provides a set of pre-built agents and tools that can be easily integrated into your own applications, allowing you to quickly build and deploy
