# better-firebase-functions

> 标签: cloud-functions, cold-start, firebase, gen2, lazy-loading, optimization, serverless

## 简介

Automatically export and optimize Firebase Cloud Functions with lazy-loading cold-start optimization. Zero dependencies, supports Gen 1 and Gen 2.
