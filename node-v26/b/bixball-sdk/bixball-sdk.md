# bixball-sdk

> 标签: BixInit, bixball, bot, haxball, headless, multiplayer, webrtc

## 简介

BixBall headless SDK — host public rooms/bots from Node.js (BixInit). Connect to any BixBall lobby with BIXBALL_WS.
