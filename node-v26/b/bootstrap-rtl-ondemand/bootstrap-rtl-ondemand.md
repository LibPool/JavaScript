# bootstrap-rtl-ondemand

> 标签: arabic, bootstrap, css, farsi, hebrew, persian, rtl, theme, twitter

## 简介

Right-to-left (RTL) theme for Twitter Bootstrap 3.x activated with html dir="rtl" attribute on-the-fly.
