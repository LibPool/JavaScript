# bpd-core

> 标签: JavaScript

## 简介

BPD-Core 是 web 形式的 bpmn 设计器，BPD-Core 仅提供建模和渲染， 不提供相应页面

## 官网

- 官网：https://github.com/ctank/bpd-core#readme
- 源码仓库：git+https://github.com/ctank/bpd-core.git
- npm 页面：https://www.npmjs.com/package/bpd-core

- 1.0.0
- 1.1.0-beta.3

## 获取地址

- npm 安装：`npm install bpd-core`
- npm registry：https://registry.npmjs.org/bpd-core
- Node 要求：>= 6.0.0
