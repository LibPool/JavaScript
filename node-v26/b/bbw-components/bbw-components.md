# bbw-components

> 标签: JavaScript

## 简介

1. 复制`src/components/Empty`文件夹 2. 修改.vue和.js中的文件名和组件名 3. 编写组件代码 4. 在build/entrys.ts中添加入口 5. 在src/components.ts中添加入口 6. 打包后的css在lib/assets目录下
