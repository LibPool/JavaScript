# balance-dsh

> 标签: balance, billing, cost, deepseek, deepseek-harness, dsh, dsh-plugin, token, usage

## 简介

查询 DeepSeek 余额并显示当前会话 token 消耗。DeepSeek 账户余额 + 会话 token/费用显示，含高峰/空闲峰谷计费。
