# bahrawy-calendar

> 标签: apple-calendar, caldav, calendar, drag-and-drop, google-calendar, outlook, react, recurrence, shadcn, tailwind, zustand

## 简介

A keyboard-first, beautifully animated calendar component for React. Provider integrations, recurrence engine, drag-and-drop, conflict detection — all in one package.
