# billion-context

> 标签: acp, agent, ai, aider, anthropic, claude-code, codex, compression, context, cursor, openai, pi-package, proxy

## 简介

Context-compression proxy that lets AI coding agents run for days — billions of tokens through one context window. Sits between any agent (Claude Code, Codex, Cursor, Aider, …) and its model API, folding consumed conversation into reversible, prefix-cache
