# bql.sh

> 标签: agents, at-least-once, bun, database, durable, hrana, libsql, message-bus, message-queue, multi-tenant, pubsub, realtime, replication, request-reply, sqlite, wal, work-queue

## 简介

SQLite as a multi-tenant database server for Bun — WAL shipping, hook-driven realtime, an FFI driver — and the durable bus that runs work against it.
