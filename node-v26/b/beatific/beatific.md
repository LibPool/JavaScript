# beatific

> 标签: backend, bcrypt, compression, docker, helmet, jsonwebtoken, jwt, mongo, mongoose, npm

## 简介

No need to install mongoose, bcrypt, jsonwebtoken, helmet, compression, morgan. This library does every functionality of them for you. 
 And it can generate dockerfile for project as well.
