# bookshelf-advanced-serialization

> 标签: JavaScript

## 简介

Plugin for Bookshelf.js supporting advanced serialization behavior, including by (1) model access permissions, (2) the application context in which serialization occurs, and (3) the relations that should be loaded on the model before serializing.
