# bauajs

> 标签: framework, loadbalancer, metrics, microservices, pubsub, resilience, router, security, tracing

## 简介

Zero-dependency, ultra-lightweight Node.js microservices framework supporting routing, resilience, tracing, metrics, pub/sub, load balancing, and security.
