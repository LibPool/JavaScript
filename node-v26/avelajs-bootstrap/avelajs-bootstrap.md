# avelajs-bootstrap

> 标签: JavaScript

## 简介

Componentes de Avela con el diseño de Template Pro (Bootstrap 5.3): admin, dashboard, material y landing. El estado interactivo vive en el servidor; no se carga JavaScript de Bootstrap.
