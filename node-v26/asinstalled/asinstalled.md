# asinstalled

> 标签: ci, engines, node-version, npm-pack, npm-publish, package-testing, packaging, prepublish, provenance, release, smoke-test, tarball

## 简介

Test your npm package the way users receive it: pack it, install the tarball into a clean project, and run it on every Node version your engines field promises. Also checks your docs against package.json, and the published artifact against the build.
