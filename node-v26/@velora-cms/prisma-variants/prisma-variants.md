# @velora-cms/prisma-variants

> 标签: JavaScript

## 简介

Generates per-dialect Prisma schema variants (PostgreSQL, MySQL, SQLite) from Velora's canonical schema.prisma.

- 官网：https://velora-cms.com
- 源码仓库：git+https://github.com/velora-cms/velora-starter.git
