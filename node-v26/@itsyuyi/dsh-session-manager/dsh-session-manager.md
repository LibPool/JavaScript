# @itsyuyi/dsh-session-manager

> 标签: deepseek, deepseek-harness, dsh, dsh-plugin, session-delete, session-management, sidebar, workspace

## 简介

DeepSeek Harness plugin: workspace session management — a durable “Delete session” action with a host-styled confirmation dialog, right in the sidebar session menu.
