# @kamimen/shinbun-components

> 标签: css, custom-elements, japanese, newspaper, tategaki, vertical-writing, web-components

## 简介

Web Components for laying out Japanese newspaper pages (新聞の紙面) with HTML tags alone. Built on shinbun-css, no runtime dependencies
