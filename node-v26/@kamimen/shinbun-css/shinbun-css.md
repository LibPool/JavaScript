# @kamimen/shinbun-css

> 标签: css, css-framework, japanese, jlreq, multi-column, newspaper, tategaki, typography, vertical-writing, writing-mode, 新聞, 日本語, 組版, 縦書き

## 简介

日本の新聞紙面（縦組み・段組み・段抜き見出し）のための、依存なしの CSS。CSS for Japanese newspaper layout: vertical writing, dan (column) grid, and column-spanning headlines.
