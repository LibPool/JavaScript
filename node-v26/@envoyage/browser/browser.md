# @envoyage/browser

> 标签: ai-agent, automation, browser, cdp, cloudflare-workers, envoyage, mcp, sse

## 简介

Thin, Workers-safe client for the Envoyage browser-driving engine. fetch + SSE only in the core path; drive a real remote browser (CF Browser Run or any Chrome), watch it live, and hand off to a human.
