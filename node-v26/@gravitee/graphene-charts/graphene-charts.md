# @gravitee/graphene-charts

> 标签: charts, d3, data-visualization, design-system, graphene, gravitee, observability, react, shadcn, tailwind

## 简介

Theme-compliant data visualization components for the Graphene design system. Built on D3, styled with Tailwind, and designed to inherit the Graphene token system out of the box.
