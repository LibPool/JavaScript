# @gravitee/graphene-chat

> 标签: agent, ai, chat, chatbot, conversation, design-system, graphene, gravitee, react, shadcn, sse, streaming, tailwind

## 简介

Chat and conversational AI components for the Graphene design system. Streaming agent UI (full-page and embeddable widget) built on Graphene core, styled with Tailwind.
