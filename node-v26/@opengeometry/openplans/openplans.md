## 简介

Browser-native TypeScript library for architectural BIM authoring. One class — OpenPlans — to place walls, doors, windows, floors, levels, grids, and dimensions, then export to IFC, PDF, or DXF. Three.js renderer with an OpenGeometry WebAssembly kernel. N
