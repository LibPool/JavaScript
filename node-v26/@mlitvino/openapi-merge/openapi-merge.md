# @mlitvino/openapi-merge

> 标签: bundle, combine, merge, openapi, openapi3, specification, swagger

## 简介

Merge multiple OpenAPI 3.0 documents into a single deterministic specification, with governed conflict resolution for paths, components, and operationIds, plus $ref integrity preservation.
