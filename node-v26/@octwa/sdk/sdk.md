# @octwa/sdk

> 标签: blockchain, capability-based-auth, dapp, hfhe, homomorphic-encryption, octra, octwa, sdk, typescript, wallet, web3

## 简介

Official TypeScript SDK for integrating dApps with OctWa Wallet Extension. RFC-O-1 compliant provider API with typed access to Octra RPC, transactions, contracts, and privacy methods.
