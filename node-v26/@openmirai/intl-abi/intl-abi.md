# @openmirai/intl-abi

> 标签: JavaScript

## 简介

The stable catalog, descriptor, diagnostic, and wire contracts used by Mirai Intl. This is a lower-level package for compiler, runtime, and tooling authors; most applications should install [`@openmirai/intl`](https://www.npmjs.com/package/@openmirai/intl
