# @bpinternal/overwatch

> 标签: automation, ci, claude, codemod, codex, coding-agent, control-loop, daytona, github, pull-request

## 简介

Headless library for building control loops: scheduled bots that scan a repo for a class of anomaly, fix a few instances with a coding agent, and open a PR — no server, UI, or persistent process.
