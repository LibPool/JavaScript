# @legioncodeinc/nectar

> 标签: code-graph, daemon, honeycomb, nectar, semantic-memory

## 简介

Nectar: a semantic memory layer over a source tree. The hiveantennae daemon mints a stable identity (a nectar) and an LLM-minted description for every file, served through the hybrid recall Honeycomb already uses.
