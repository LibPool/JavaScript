# @codeyantram/cli

> 标签: JavaScript

## 简介

A terminal-based AI coding assistant. CodeYantram brings an LLM agent into your terminal — chat with the model, and let it read, search, edit, and execute against your project — all with full streaming, a built-in approval gate for anything that mutates,
