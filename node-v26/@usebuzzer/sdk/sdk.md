# @usebuzzer/sdk

> 标签: api, buzzer, helpdesk, mcp, sdk, support

## 简介

The Buzzer REST API client for TypeScript and JavaScript: one typed method per public operation, identity tokens for the chat widget, and a contact-support tool for your MCP server. No dependencies.
