# @pantoken/plugin-custom-icons

> 标签: JavaScript

## 简介

pantoken plugin: vendored custom icon glyphs (e.g. product/brand icons not in the InstUI set) as --instui-icon-<name> image tokens, usable via the same -icon-<name> painter class.
