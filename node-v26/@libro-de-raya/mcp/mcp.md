# @libro-de-raya/mcp

> 标签: cfdi, claude, cursor, facturacion, mcp, mexico, modelcontextprotocol, sat, windsurf

## 简介

Servidor oficial de Model Context Protocol (MCP) para Libro de Raya. Digitalización de tickets, facturación CFDI 4.0 y organización de comprobantes fiscales en México para cualquier entorno o cliente compatible con MCP.
