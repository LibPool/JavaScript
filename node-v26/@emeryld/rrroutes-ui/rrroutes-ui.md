# @emeryld/rrroutes-ui

> 标签: JavaScript

## 简介

Headless, fully-typed React helpers for consuming RRRoutes endpoints: query/feed/mutation boundaries, skeleton state, and a typed zod form binder. Renders nothing of its own — works identically on web and React Native.
