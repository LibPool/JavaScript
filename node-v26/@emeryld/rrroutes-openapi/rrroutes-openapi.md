# @emeryld/rrroutes-openapi

> 标签: JavaScript

## 简介

RRRoutes docs + “try it” playground, shipped as static assets plus a thin Express helper. The UI is React-based and reads the serialized registry you provide (no OpenAPI YAML needed).
