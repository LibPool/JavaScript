# @sakuzu/maplibre-gl-draw-ui

> 标签: draw, drawing, editor, map, maplibre, maplibre-gl, toolbar, ui

## 简介

The standard user interface of @sakuzu/maplibre-gl-draw: a toolbar of drawing tools and keyboard shortcuts over the map, with a plain JavaScript API.
