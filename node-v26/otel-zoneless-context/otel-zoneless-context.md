# otel-zoneless-context

> 标签: async-await, browser, context-manager, esbuild-plugin, opentelemetry, rollup-plugin, vite-plugin, webpack-plugin, zoneless

## 简介

OpenTelemetry context manager for the browser without zone.js, plus a bundler plugin that rewrites the awaits in your code so the active context comes back after each one
