# @shival99/z-ui-init

> 标签: angular, bootstrap, cli, scaffold, setup, tailwindcss, z-ui

## 简介

Bootstrap an Angular project to consume @shival99/z-ui: Tailwind v4, themes, icons, fonts, and providers wired up in one command.
