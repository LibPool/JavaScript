# glyphfox-universe

> 标签: glyphfox, icon-search, iconify, icons, svg, vite-plugin, webpack-plugin

## 简介

One glyphfox API over more than 400,000 open license icons from established sets: a prefix:name resolver, search, license metadata on every icon, style transforms and offline bundling.
