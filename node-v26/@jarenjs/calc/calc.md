> 标签: calculator, expression, finance, headless, jaren, json, parser, plot, svg, units

## 简介

A native, headless multi-mode calculator (standard / programmer / scientific / financial / converter) with x·y and x·y·z plotting rendered as pure-vnode SVG through @jarenjs/view — a two-stage expression compiler (parseExpression ⇄ toExpression), built on
