# @jarenjs/mermaid

> 标签: ast, diagram, flowchart, headless, jaren, json, mermaid, parser, sequence, svg

## 简介

A native, headless Mermaid clone: diagrams-as-code parsed to a geometry-free JSON AST and rendered as pure-vnode SVG through @jarenjs/view — SSR-able, structurally shared, bidirectional (parseMermaid ⇄ toMermaid)
