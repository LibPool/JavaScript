# @buckeyestudio/toh-fs-sandbox

> 标签: JavaScript

## 简介

Sandbox-enforcing implementation of the TheOpen Harness filesystem seam: fences write/edit by the per-call sandbox mode (read-only denies mutation, workspace-write contains it to the workspace + temp roots) while reads pass through
