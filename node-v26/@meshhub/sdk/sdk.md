# @meshhub/sdk

> 标签: api, booking, meshhub, sdk, shipping, travel

## 简介

Official TypeScript SDK for the MeshHub tenant API — search, book, pay, and track orders across travel, shipping, car-rental, hotel, and salon suppliers.
