# ballotdata

> 标签: api, ballot, ballotdata, civic, elections, endorsements, sdk, server-sent-events, voting

## 简介

Official JavaScript and TypeScript client for the BallotData API: U.S. ballots, endorsers, endorsements, officeholders, and the live Endorsement Stream.
