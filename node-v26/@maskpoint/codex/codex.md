# @maskpoint/codex

> 标签: JavaScript

## 简介

Maskpoint for Codex CLI: pushes preservation instructions into Codex's own compaction prompt where its configuration allows, and re-injects a masked-history artifact after compaction. Assisted augmentation, never replacement.
