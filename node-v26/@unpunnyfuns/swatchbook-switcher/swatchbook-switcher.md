# @unpunnyfuns/swatchbook-switcher

> 标签: design-tokens, dtcg, react, swatchbook, theme-switcher

## 简介

Framework-agnostic theme-switcher UI for swatchbook — axis pills, preset pills, color-format selector. Consumed by the Storybook addon toolbar and any React host that knows how to set data-attributes on the document.
