# @cathode-ui/mcp

> 标签: ai, cathode, claude, cursor, design-system, mcp, model-context-protocol, react

## 简介

Model Context Protocol server for Cathode UI. Lets AI coding agents (Claude Code, Cursor, Copilot) discover and query the 45-primitive Cathode design system without scraping source. Exposes cathode_list_components, cathode_get_component, cathode_get_token
