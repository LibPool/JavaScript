# @well1791/pi-sm

> 标签: pi, pi-coding-agent, pi-package, rename, session, session-manager, tui

## 简介

Lite session manager for the pi coding agent — a TUI to browse, search, rename, fork, hide, and delete sessions, plus a /rn command.
