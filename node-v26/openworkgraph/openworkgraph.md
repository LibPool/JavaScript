# openworkgraph

> 标签: JavaScript

## 简介

万象画布（OpenWorkgraph）是基于无限画布思想的全能可视化智能体工作台产品，除了图、文、视频生成、软件开发等工作，还能组织各种用途的 Agent 工作流。
