# @react-zone-map/react

> 标签: hooks, nextjs, react, realtime, seat-map, seating, seatmap, stadium, svg, venue, websocket

## 简介

React bindings (provider, hooks) + DOM/SVG renderer for react-zone-map. The provider and hooks are platform-agnostic and are reused by @react-zone-map/react-native.
