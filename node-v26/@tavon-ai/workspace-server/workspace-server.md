# @tavon-ai/workspace-server

> 标签: agent, diff, file-tree, git, git-status, handler, http, workspace

## 简介

Framework-agnostic HTTP handler exposing a workspace directory: file tree, file contents, git status and diffs. Companion to @tavon-ai/pi-ai-sdk-bridge.
