# @trustbench/mcp

> 标签: agent-payments, audit, ed25519, mcp, model-context-protocol, non-custodial, rankings, receipt, trustbench, x402

## 简介

Native MCP server for TrustBench. Exposes provider rankings, receipt lookup, and Ed25519 receipt verification (lookup + offline modes) as agent-callable tools in Claude Desktop, Grok, Kimi, Cherry Studio, and any MCP-compatible host.
