# @gurps-sheet/combat-engine

> 标签: JavaScript

## 简介

Combat engine for GURPS 4th Edition: rules-faithful melee with Dodge, Parry and Block, shock, major wounds and stun, a dice manager, roll modifiers, a resettable combat state machine, and a gurps-combat CLI.
