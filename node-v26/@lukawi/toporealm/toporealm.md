# @lukawi/toporealm

> 标签: agents, cli, daemon, graph, toporealm, workflow

## 简介

TopoRealm 1.0 — single-owner daemon graph workspace (aggregate: toporealm CLI + toporeald daemon). Minimal core, two-layer modules, one local graph shared by humans and agents.
