# @lukawi/toporealm-module-host

> 标签: JavaScript

## 简介

TopoRealm 1.0 module host: discovery/loading (module.yaml v2 + modules.yaml bindings), dependency topo-sort, activate scheduling, registration freeze, catalog aggregation, command dispatch. Depends only on daemon-core pipeline entry + protocol.
