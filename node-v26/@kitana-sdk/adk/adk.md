# @kitana-sdk/adk

> 标签: adk, agent, ai, claude, google-adk, kitana

## 简介

Google ADK (JS) model adapter for Kitana — lets LlmAgent route through Claude CLI / Codex CLI / Ollama / API-key failover instead of Gemini/Vertex.
