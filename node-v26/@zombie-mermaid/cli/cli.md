# @zombie-mermaid/cli

> 标签: ascii, cli, diagram, mermaid, svg, zombie-mermaid

## 简介

Command-line interface for zombie-mermaid: render Mermaid diagrams as SVG, ASCII, HTML or PNG from the shell (npx @zombie-mermaid/cli diagram.mmd).
