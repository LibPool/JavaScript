# @trytilde/sdk-langchain-node

> 标签: JavaScript

## 简介

Core history and delivery live in `@trytilde/sdk`. This package converts typed context to LangChain messages and tools, following Dispatch's core/framework separation. It works with `langchain` v1 (`createAgent`) and `@langchain/core` 1.x.
