# dsh-deepseek-web-free

> 标签: cordis-plugin, deepseek-harness, dsh, dsh-plugin, llm-provider

## 简介

Unofficial DeepSeek Web LLM provider for DeepSeek Harness (fork of y-wi/dsh-deepseek-web) with fixes for DSH 0.2.x. 非官方 DeepSeek 网页端 Provider，dsh-deepseek-web 的 fork，适配 DSH 0.2.x。
