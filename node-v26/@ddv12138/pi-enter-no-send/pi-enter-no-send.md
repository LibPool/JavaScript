# @ddv12138/pi-enter-no-send

> 标签: autocomplete, editor, pi-extension, pi-package, slash-command

## 简介

pi extension: while a slash-command autocomplete menu is open, Enter accepts the completion without submitting (like Tab), so you can keep typing after selecting a skill/command
