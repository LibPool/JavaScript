> 标签: ai-agents, anthropic, claude, claude-code, cli, code-analysis, developer-tools, knowledge-graph, local-first, mcp, model-context-protocol, multi-agent, open-source, tree-sitter

## 简介

CLI engine for Monomind — an open-source MCP server for Claude Code, OpenCode, Antigravity, Kimi Code, and Codex, with a codebase knowledge graph (tree-sitter + SQLite), persistent memory, multi-agent task coordination, and session hooks. Apache 2.0 licen
