# @fundamental-engine/vanilla

> 标签: Fundamental, canvas, dom, field, particles, physics, reciprocal, typescript, vanilla

## 简介

Framework-free TypeScript wrapper for Fundamental — the reciprocal DOM-physics field as a typed FieldField class + mountField(), with no custom-element registration and no framework dependency.
