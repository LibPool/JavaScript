# @hesperia/language-server

> 标签: JavaScript

## 简介

The Hesperia language server provides authored-source diagnostics, hover types, completions, definitions, and document symbols through the Language Server Protocol. It shares project preparation and checking with Hesperia's CLI, including unsaved document
