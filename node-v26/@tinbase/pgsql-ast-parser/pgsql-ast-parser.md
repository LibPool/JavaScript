# @tinbase/pgsql-ast-parser

> 标签: ast, database, db, node, parser, pg, pgsql, postgres, postgresql, sql

## 简介

Fork of pgsql-ast-parser with extended grammar (dollar-quoted strings, array slicing, GRANT/roles, triggers, MERGE, partitioning, ...). Tracks oguimbal/pgsql-ast-parser; pending upstream PR #174.
