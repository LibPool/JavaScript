# @i-scope/dap-adapter

> 标签: ajs, autoscope, dap, debug-adapter-protocol, debugger, i-scope, iscope, iscope-debugger, jscript, oscilloscope

## 简介

Debug Adapter Protocol (DAP) implementation for iScope .ajs scripts running in Oscilloscope.exe. Ships both a stand-alone stdio DAP server (npx iscope-debug-server) and an embeddable AjsDebugSession class. Implements breakpoints, step, stack trace, scopes
