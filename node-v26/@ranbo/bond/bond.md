# @ranbo/bond

> 标签: JavaScript

## 简介

1. 从本地或远程拉取 swagger 接口文件，自动生成对应接口调用方法以及接口结构体 2. 支持多个 swagger 进行合并。 3. 支持简单接口的 mock 数据生成，当后端未指定数据 example 时也能根据字段名给出更贴合业务场景的 mock 数据。
