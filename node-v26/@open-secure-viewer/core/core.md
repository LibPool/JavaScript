# @open-secure-viewer/core

> 标签: annotation, annotations, apryse-alternative, drm, irm, pdf, pdf-viewer, pdfium, pdfium-wasm, pdftron-alternative, pspdfkit-alternative, redaction, secure-pdf, secure-pdf-viewer, viewer, wasm, watermark, xfdf

## 简介

Framework-agnostic secure PDF viewer SDK powered by Google PDFium WASM. Drop-in replacement for Apryse/PDFTron WebViewer, zero license fees.
