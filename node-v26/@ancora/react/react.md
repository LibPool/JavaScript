# @ancora/react

> 标签: ai, ai-sdk, chat, message-list, pin, react, scroll, stick-to-bottom, streaming, tanstack, usechat, virtual-list, virtualization

## 简介

Pixel-stable virtualized message list for AI chat and streaming logs. Bottom-pin holds under token streaming; reading mode never shifts. The MIT alternative to VirtuosoMessageList.
