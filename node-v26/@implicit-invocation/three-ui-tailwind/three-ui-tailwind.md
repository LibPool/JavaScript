# @implicit-invocation/three-ui-tailwind

> 标签: metro, tailwind, tailwindcss, three, ui, vite

## 简介

Tailwind CSS v4 authoring for three-ui: classes compile to three-ui style data, no DOM CSS and no runtime CSS parsing.
