# @arex95/phalanx

> 标签: admin, admin-panel, authentication, axios, csrf, encryption, jwt, realtime, rest-api, sse, tanstack-query, typescript, vue, vue3

## 简介

Headless framework for admin panels on Vue: typed REST services with derived TanStack queries and mutations, declarative actions, session handling with an HttpOnly refresh cookie, resilient realtime connections, encrypted browser storage and typed errors.
