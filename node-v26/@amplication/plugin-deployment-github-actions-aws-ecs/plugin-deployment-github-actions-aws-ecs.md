# @amplication/plugin-deployment-github-actions-aws-ecs

> 标签: JavaScript

## 简介

Adds a GitHub Actions workflow for the packaging to AWS Elastic Container Registry (ECR) and publishing to AWS Elastic Container Service (ECS). This plugin requires the ECR & ECS to be present and passed as configuration.
