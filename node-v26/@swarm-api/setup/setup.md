# @swarm-api/setup

> 标签: ai-agents, base, mcp, model-context-protocol, swarmapi, usdc, wallet, x402

## 简介

One-shot CLI for SwarmApi: generate or import a Base wallet (hex or BIP-39), fund with USDC on Base (send, exchange withdraw, or testnet faucet), and write an MCP config block for Claude Desktop / Cursor / Cline / Zed.
