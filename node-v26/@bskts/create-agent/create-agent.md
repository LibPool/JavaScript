# @bskts/create-agent

> 标签: agent, bskts, create, robinhood-chain, scaffold

## 简介

Set up a bskts trading agent in one command: npm create @bskts/agent. Writes a starter script and a fresh agent key to .env; the owner approves its limits in bskts.
