# @motion-script/latex

> 标签: animation, latex, math, motion script, motion-script

## 简介

Animated LaTeX math for Motion Script, rendering formulas to glyph paths via MathJax and morphing them token by token.

- 源码仓库：git+https://github.com/motion-script/motion-script.git
