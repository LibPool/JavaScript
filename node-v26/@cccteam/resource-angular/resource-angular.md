# @cccteam/resource-angular

> 标签: JavaScript

## 简介

**@cccteam/resource-angular** is the Angular binding of [`@cccteam/resource`](../resource/README.md), the framework-neutral client for generated APIs. It is a comprehensive Angular library developed by the [cccteam](https://cloudcomputingconsultants.com/)
