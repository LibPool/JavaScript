# @maintainerd/maintainerd-sdk-javascript

> 标签: auth, browser, isomorphic, maintainerd, node, oauth2, oidc, pkce, sdk

## 简介

Isomorphic JavaScript/TypeScript SDK for maintainerd — auth (OAuth2 login, M2M credentials, token verification) and API access. Works in browsers and Node.js; framework-agnostic (no React).
