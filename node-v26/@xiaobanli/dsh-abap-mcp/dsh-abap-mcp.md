# @xiaobanli/dsh-abap-mcp

> 标签: abap, adt, deepseek, dsh, dsh-plugin, harness, mcp, sap

## 简介

DeepSeek Harness plugin: connect SAP ABAP ADT over MCP with a read-only-by-default permission model, configured from the Settings page. · DSH 插件：通过 MCP 连接 SAP ABAP ADT，默认只读 + 7 类写权限开关，设置页卡片配置。
