# @horizon-ark-studio/arkware

> 标签: android, arkware, desktop, gtk, linux, native-shell, pwa, spa, webkitgtk, webview

## 简介

Package any SPA as a thin native shell. One `arkware` CLI: `arkware android emit-flavor` authors Gradle config for main's Android WebView shell, `arkware linux build` scaffolds and cmake-builds main's real native C shell (GTK + WebKitGTK, Linux desktop on
