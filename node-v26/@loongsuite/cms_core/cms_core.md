# @loongsuite/cms_core

> 标签: JavaScript

## 简介

CMS Core 是 CMS 可观测性 SDK 的核心基础包，提供所有其他包依赖的基础类型、接口、常量和工具函数。它是整个 SDK 架构的基石，定义了追踪、上下文、传播等核心概念。
