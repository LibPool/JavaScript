# @loongsuite/cms_propagators

> 标签: JavaScript

## 简介

CMS Propagators 提供上下文传播器和传播管理器，实现分布式追踪中的上下文信息在服务间的传递。支持 W3C Trace Context、W3C Baggage 等标准协议，以及组合传播功能。
