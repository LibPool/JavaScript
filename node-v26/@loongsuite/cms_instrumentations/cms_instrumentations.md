# @loongsuite/cms_instrumentations

> 标签: JavaScript

## 简介

CMS Instrumentations 提供官方内置的自动埋点插件集合，用于自动拦截和监控 Node.js 应用程序中的各种操作。通过自动埋点，无需修改业务代码即可获得完整的追踪数据。
