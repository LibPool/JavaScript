# @masks/server

> 标签: JavaScript

## 简介

A masks client for servers: signing people in with the handshake and the code flow, sessions for Next.js, Auth.js, Express, and Hono, client credentials, the device flow, token exchange, DPoP, enrollment, introspection, and checking access tokens.
