# @evenfall/gba

> 标签: deterministic, emulator, game-boy-advance, gba, rust, wasm, webassembly

## 简介

Deterministic, cycle-aware Game Boy Advance emulator as WebAssembly, with a worker-based browser SDK and a synchronous core for Node
