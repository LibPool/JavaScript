# @vebgen/g11n

> 标签: g11n, i18n, internationalization, localization, translation

## 简介

The package builds on [formatjs](https://formatjs.io/) and [react-intl](https://formatjs.io/docs/react-intl) to provide a complete solution for small web applications and libraries. The package is designed to be used with [React](https://reactjs.org/).
