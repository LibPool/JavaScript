# @hy-tech/ws-player

> 标签: audio, browser, media, mediaSource, player, video, wasm, web

## 简介

基于websocket协议的web端播放器,支持实时流和回放流,支持原生video播放或者软解播放,通过私有流媒体协议传输,传输内容为裸流数据
