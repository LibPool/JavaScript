# @hallencj/weather-maker

> 标签: css, effect, overlay, rain, react, snow, storm, vue, weather, web-audio

## 简介

Scoped, dependency-free rain / storm / snow overlays with synthesized sound. CSS visuals, Web Audio sound, click-through. Vanilla + Vue + React.
