# @parser-kit/core

> 标签: ast, dsl, grammar, lexer, parser, parser-combinator, parsing, pratt, precedence-climbing, tokenizer, type-inference, typescript

## 简介

A zod-like parser toolkit: lexers, combinators and Pratt tables are plain values, and the AST types are inferred from the grammar.
