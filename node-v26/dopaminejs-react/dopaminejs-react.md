# dopaminejs-react

> 标签: achievements, dopaminejs, gamification, hook, levels, react, rewards, streaks, xp

## 简介

React bindings for DopamineJS: a useRewards() hook and a RewardsProvider for XP, levels, achievements and daily streaks
