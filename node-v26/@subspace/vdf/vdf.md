# @subspace/vdf

> 标签: crypto, emscripten, vdf, wasm, webassembly

## 简介

This repository is a port of [VDFs by POA Network](https://github.com/poanetwork/vdf) to WebAssemnbly, so that it runs in any modern browser or Node.js environment.
