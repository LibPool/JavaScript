# @pdfree/pdf2read-core

> 标签: liquid-mode, mobile-reading, pdf, pdf-reflow, pdfjs, reading-mode, reflow

## 简介

Reflow a fixed-layout PDF into structured reading blocks (headings/paragraphs/lists/tables) — the same extraction engine behind pdfree.io's Read PDF tool, runnable locally. Your files never leave your machine.
