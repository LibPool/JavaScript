# @rx-angular/rebundle

> 标签: angular, bundler, esbuild, nx, plugin, rolldown

## 简介

@rx-angular/rebundle is an esbuild bundler plugin for Angular, optimized for reducing the amount of bundles.

- 源码仓库：git+https://github.com/rx-angular/rx-angular.git
