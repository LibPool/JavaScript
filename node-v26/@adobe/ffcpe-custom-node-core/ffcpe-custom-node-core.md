# @adobe/ffcpe-custom-node-core

> 标签: adobe, creative-production, custom-action, enterprise, ffcpe, firefly, wintertc

## 简介

WinterTC-aligned SDK for FFCPE (Firefly Creative Production for Enterprise) custom actions — Workflow Builder HTTP contract, JobStore, JobOrchestrator, runWorkerJob, IMS inbound auth, submit/status handlers.
