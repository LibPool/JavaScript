# @camy/cli

> 标签: agent, camy, cli, terminal

## 简介

Camy in your terminal: the same agent, memory, and cloud computer you use at camy.ai, as one binary you can pipe, script, and schedule.

## 官网

- 官网：https://camy.ai
- 源码仓库：git+https://github.com/trycamy/cli.git
- npm 页面：https://www.npmjs.com/package/@camy/cli
