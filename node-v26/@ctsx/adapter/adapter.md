# @ctsx/adapter

> 标签: JavaScript

## 简介

adapter 是一个简单，高效以声明的方式批量适配处理数据的工具，它能帮你对数据进行各种常见的适配转换，使得转换后的数据结构或者数据格式符合业务要求
