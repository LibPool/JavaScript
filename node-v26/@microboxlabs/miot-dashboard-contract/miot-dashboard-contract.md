# @microboxlabs/miot-dashboard-contract

> 标签: contract, dashboard, dashboards, json-schema, openapi, zod

## 简介

The wire contract for MIOT embeddable dashboards: the persisted document's schema, the role and capability vocabulary, and the OpenAPI specification. Depends on neither the UI nor the server.
