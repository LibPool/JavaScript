# dsh-branch-conversation

> 标签: branch-conversation, conversation-tree, cordis, deepseek-harness, dsh, dsh-plugin, flowchart

## 简介

DeepSeek Harness 插件：在官方侧边栏中新增一个「分支对话」页，用流程图管理主对话节点、原生分支、子对话与文件节点。原生分支继承上下文与工作区（DSH 官方 fork）；子对话不继承上下文，只继承模型人设与权限。
