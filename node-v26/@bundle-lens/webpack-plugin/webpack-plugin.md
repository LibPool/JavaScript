# @bundle-lens/webpack-plugin

> 标签: brotli, bundle-analysis, bundle-lens, chunks, encryption, manifest, sqlite, webpack, webpack-plugin

## 简介

BundleLens webpack 5 plugin: writes a per-build SQLite database of chunk data (size, source modules, emitted files + contentHash) during processAssets. Re-exports the @bundle-lens/core query/store surface.
