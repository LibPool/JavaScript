# @nickpaustian/helm

> 标签: gamepad, input, keybindings, kinetic, pinch, pointer-events, touch, typescript, wheel

## 简介

Input for interactive web apps: mouse, touch, pen, wheel, trackpad pinch and keys landing on one force vector in units tuned once per app, with key-to-action bindings built for rebinding, and small physics for the feel
