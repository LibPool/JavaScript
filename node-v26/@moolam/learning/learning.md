# @moolam/learning

> 标签: JavaScript

## 简介

Internal component of Sutra SDK — applications should install sutra-sdk. Learning substrate contracts: turn-trajectory schema (B9 metadata + C0 training fields), parse boundary for corpus/gym/critic pipelines.
