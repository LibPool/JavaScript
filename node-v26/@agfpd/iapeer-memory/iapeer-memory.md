# @agfpd/iapeer-memory

> 标签: JavaScript

## 简介

iapeer-memory — peer memory for the iapeer ecosystem: vault, memoryd (index/search/MCP over HTTP), context fragments, role doctrines. The package IS the system; session surfaces are direct per-peer files merged into each peer's cwd. See docs/README.md.
