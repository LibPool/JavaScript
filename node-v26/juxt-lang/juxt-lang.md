# juxt-lang

> 标签: agent-skills, ai-agents, claude-code, cli, codex, cursor, cve-2026-109618, cve-2026-109619, json-schema, juxt, juxt-lang, llm, local-llm, ollama, php, php2shell, security, spec-driven-development, token-optimization

## 简介

Juxt-lang CLI: typed IR + JSON Schema for .juxt programs, drift check against your repo, a token-saving tiered router (cache -> compiled -> local model -> frontier) with measured receipts, plus Juxt mode for any coding agent and the php2shell fix.
