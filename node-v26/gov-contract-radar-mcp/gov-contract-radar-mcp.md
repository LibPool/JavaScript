> 标签: 8a, ai-agent, federal-contracts, govcon, government-contracts, hubzone, mcp, model-context-protocol, naics, procurement, rfp, sam.gov, sdvosb, set-aside, wosb

## 简介

GovContract Radar MCP server — live US federal contract opportunities from SAM.gov: search by NAICS, daily digest, near-expiry recompete radar. Remote MCP endpoint, works in Claude, Cursor, Windsurf and any MCP client.
