# @vertixara/dsh-prompt-manager

> 标签: deepseek-harness, dsh, dsh-plugin, prompt, prompt-template, system-prompt

## 简介

DeepSeek Harness 的分层提示词管理器：全局、工作区、会话级提示词档案，内置段落与上下文的禁用/覆盖，子代理作用域，以及完整的 Web 管理界面。
