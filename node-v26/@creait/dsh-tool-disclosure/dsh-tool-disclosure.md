# @creait/dsh-tool-disclosure

> 标签: context, cordis, deepseek-harness, dsh, mcp, plugin, progressive-disclosure, tools

## 简介

Progressive tool disclosure for DeepSeek Harness: rarely-used tool groups cost one catalog line instead of their full schemas until the model loads them with tool_search.
