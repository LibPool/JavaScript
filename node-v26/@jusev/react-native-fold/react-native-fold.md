# @jusev/react-native-fold

> 标签: android, dual-screen, expo, fold, foldable, foldingfeature, hinge, ios, iphone-duo, jetpack-windowmanager, layout, react-native, reserved-regions, safe-area, split-view

## 简介

Foldable and shared-display layout signals for React Native. iPhone Duo and iOS 27.1 reserved regions, plus Android folds via Jetpack WindowManager: where the fold is, which half is which, and which edge your toolbar belongs on.
