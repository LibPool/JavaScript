# dsh-plugin-computer-use

> 标签: automation, computer-use, deepseek-harness, desktop, dsh, dsh-plugin, input, screenshot

## 简介

computer-use v2.5：Ubuntu/GNOME Wayland 自动检测并启用原生后端；内置 WinRects 扩展安装与诊断命令，驱动最低 0.28.3。基于 Cua Driver 进程内 SDK 的跨平台桌面操作。13 个工具（截图/窗口列表/缩放/光标/移动/点击/拖拽/滚动/输入/按键/打开应用/连续动作/等待）。v2.4.1 适配 dsh 0.2.0：审批探测改走公有 overrideOf/session 覆盖 + 部署默认策略，任何探测形状失效时保守放行，杜绝 danger-fu
