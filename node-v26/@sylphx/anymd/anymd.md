# @sylphx/anymd

> 标签: ai-agents, anymd, cli, document-conversion, docx, docx-to-markdown, epub, html-to-markdown, llm, markdown, markitdown-alternative, mcp, model-context-protocol, ocr, pdf, pdf-to-markdown, pptx, rag, rust, transcription, xlsx

## 简介

Any file → clean Markdown for AI agents: PDF, Word, PowerPoint, Excel, EPUB, HTML and web pages, images (OCR), audio and video (metadata, subtitles, transcripts). A fast Rust MCP server and CLI that runs on your machine. No API key.
