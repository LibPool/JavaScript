# @ivorpad/mercadona

> 标签: agent, algolia, cli, grocery, mercadona, shopping

## 简介

Unofficial, agent-friendly CLI for tienda.mercadona.es — search the catalog, read prices, build a cart, and check out. Ships a prebuilt Go binary.
