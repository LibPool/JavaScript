# @empressaio/atom-contract

> 标签: MCP, O&G, agent, atom, contract, empressa, hauska, oil-gas, substrate, typed-data

## 简介

The typed-data substrate every Empressa atom satisfies: identity, context interface, composition declaration, and history anchoring. Peer to the Hauska SDK (`@hauska-sdk/*`); consumed directly by every product surface and MCP server.
