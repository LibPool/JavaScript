# @kimjay112/cipherwire-node

> 标签: e2ee, encryption, express, logging, middleware, nestjs

## 简介

Cipherwire middleware for Node.js (Express, NestJS, Connect): decrypts request bodies, encrypts responses and streams request logs to the dashboard without blocking.
