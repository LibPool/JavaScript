# @nor-data/nabolag-mcp

> 标签: entur, green-space, kollektivtransport, mcp, model-context-protocol, nabolag, neighborhood, nibio, noise, norway, real-estate, ssb, stoy, stoysone, transit, vegvesen

## 简介

MCP server for Norwegian neighborhood data: public-transport coverage (Entur), road-noise zones (Statens vegvesen), and green-area access (NIBIO + SSB). Open data, no API keys.
