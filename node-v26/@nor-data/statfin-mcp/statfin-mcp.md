# @nor-data/statfin-mcp

> 标签: finland, json-stat, mcp, model-context-protocol, open-data, pxweb, statfin, statistics, statistics-finland, tilastokeskus

## 简介

MCP server for official statistics from Statistics Finland (Tilastokeskus) StatFin database via the PxWeb API: search 3000+ tables, read table metadata and fetch data as JSON-stat2. No API key required.
