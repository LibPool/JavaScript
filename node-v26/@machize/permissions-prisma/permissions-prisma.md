# @machize/permissions-prisma

> 标签: machize, permissions, postgresql, prisma, rbac, store, typescript

## 简介

Prisma-backed implementation of the @machize/permissions AccessStore — the production reference backend (PostgreSQL/MySQL). Bring your own PrismaClient; ships a reference schema.
