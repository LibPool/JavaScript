# @machize/tenancy-sqlite

> 标签: machize, multi-tenant, sqlite, store, tenancy, typescript

## 简介

Durable, SQLite-backed implementation of the @machize/tenancy TenantSource, on Node's built-in node:sqlite. Zero external dependencies.
