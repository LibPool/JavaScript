# @machize/subscriptions-prisma

> 标签: billing, machize, postgresql, prisma, store, subscriptions, typescript

## 简介

Prisma-backed implementations of the @machize/subscriptions stores (subscriptions, atomic usage metering, webhook idempotency) — the production reference backend (PostgreSQL/MySQL). Bring your own PrismaClient; ships a reference schema.
