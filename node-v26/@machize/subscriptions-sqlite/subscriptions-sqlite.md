# @machize/subscriptions-sqlite

> 标签: billing, machize, sqlite, store, subscriptions, typescript

## 简介

Durable, SQLite-backed implementations of the @machize/subscriptions stores (subscriptions, atomic usage metering, webhook idempotency) built on Node's built-in node:sqlite. Zero external dependencies.
