# @machize/exports

> 标签: csv, export, machize, reporting, saas, typescript

## 简介

Data exports for Machize: render typed export definitions to CSV/TSV/JSON/NDJSON (native, zero-dep) through a pluggable formatter seam, designed to run async via @machize/queue.
