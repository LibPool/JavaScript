# @syair/codewiki

> 标签: ai, code-navigation, codebase, developer-tools, documentation, drift-detection, mdx, wiki

## 简介

Generates and maintains a Notion-style wiki for a local codebase, with citations back to code that stay accurate as the code drifts.
