# @y0usaf/pi-jev

> 标签: classification, guardrails, jev, pi-extension, pi-package, typesafe

## 简介

TypeSafe Jev as a decision layer for Pi: judges mutating tool calls before they run, reads tool output for secrets and failure class after, and exposes jev_ask for typed calibrated answers instead of prose
