# @dih-fbn/mcp

> 标签: JavaScript

## 简介

A unified API abstraction over the MCP SDK. It aggregates tools from multiple MCP servers into OpenAI's format, automatically orchestrates tool calls and responses, and injects resources directly into chat messages.
