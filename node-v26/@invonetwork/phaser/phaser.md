# @invonetwork/phaser

> 标签: game-economy, in-game-purchases, invo, loyalty, phaser, phaser4, virtual-currency

## 简介

INVO game economy for Phaser 4: wallet, premium currency via INVO hosted checkout, item shop, soft-currency earnings and loyalty events, with a drop-in UI over your game canvas.
