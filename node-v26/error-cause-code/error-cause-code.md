# error-cause-code

> 标签: alerting, cause, cause-chain, cloudflare-workers, drizzle, drizzle-orm, edge, error, error-cause, error-chain, error-classification, error-code, error-fingerprint, error-grouping, error-handling, esm, extract-error-code, http-error, http-status, logging, monitoring, nested-error, pg-error, postgres, postgresql, root-cause, sentry, sqlstate, status-code, typescript, unwrap-error, wrapped-error, zero-dependency

## 简介

Extract a single error code (code or HTTP status) from an error and its cause chain — e.g. the Postgres SQLSTATE hidden inside a Drizzle ORM error. Zero dependencies.
