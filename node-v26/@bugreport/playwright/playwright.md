# @bugreport/playwright

> 标签: allure, bug-report, flaky-tests, playwright, qa, reporter, test-report

## 简介

Playwright reporter: a full test report (steps, retries, trends, flaky tests, traces, video) where every failed test becomes a Bug Report the developer can replay live.

## 官网

- 官网：https://bugreport.site
