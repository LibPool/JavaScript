# @splists/splist

> 标签: backend, chunk, cli, command, console, doc, docs, documentation, heading, list, markdown, md, split, table-of-contents, terminal, text-processing, toc, utility, zero-dependency

## 简介

Split massive Markdown and text files into manageable chunks with an auto-generated TOC. A powerful CLI and local Web GUI utility for text processing.
