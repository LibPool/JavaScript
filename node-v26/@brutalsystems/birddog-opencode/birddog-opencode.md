# @brutalsystems/birddog-opencode

> 标签: agents, birddog, monitoring, observability, opencode, opencode-plugin

## 简介

opencode plugin for birddog — publishes a session's state so birddog can observe it from outside. Read-only: it reports, and never acts on the session.
