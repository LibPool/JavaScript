# @getfoyer/review-core

> 标签: JavaScript

## 简介

Frozen contract for Foyer run artifacts (RunArtifact v0.1) — the shared shape consumed by the GitHub App, the CLI, the hosted report, and PR-comment writers. Also ships the cross-cutting semantic-context builder used by code review.
