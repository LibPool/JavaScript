# @kuttidb/client

> 标签: database, key-value, kuttidb, queue, stream

## 简介

KuttiDB Node.js client: binary wire protocol over TCP, TLS, and Unix sockets with queues, exchanges, streams, atomic operations, and managed local server lifecycle. Zero dependencies.
