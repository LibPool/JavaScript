# @vennyx/soliconfig-cli

> 标签: cli, dotenv, dotenvx, env, remote-config, secrets, soliconfig, vennyx

## 简介

CLI for soliconfig — manage encrypted .env secrets and Remote Config from your terminal and CI. Installs the `soliconfig` command (Bun runtime).
