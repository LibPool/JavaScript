# @webfrank/node-red-contrib-matter2mqtt

> 标签: home-automation, matter, matter2mqtt, mqtt, node-red, thread

## 简介

Node-RED nodes for the matter2mqtt bridge: discover Matter devices by NodeLabel and receive MeasuredValue readings converted to engineering units.
