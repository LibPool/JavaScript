# @aplopes/notedeck-app-sdk

> 标签: JavaScript

## 简介

Build NoteDeck on-device apps in AssemblyScript: a scene-graph UI SDK that compiles (via WebAssembly) to a sandboxed NDVM app the NoteDeckOS compositor renders, plus the `notedeck` CLI (build, install, dev loop). The wire ABI is generated from the firmwar
