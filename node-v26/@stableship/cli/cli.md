# @stableship/cli

> 标签: ci, cli, qa, release-gate, sarif, security, stableship, supabase

## 简介

Stableship from the terminal and CI: release status, findings, scoped checks, why a finding blocks, fix briefs and plans, rules, SARIF for code scanning, and a pre-push hook.
