# @openwop/agent-host

> 标签: agent, claude-code, openwop, terminal

## 简介

The Claude Code companion for openwop-app (ADR 0785): pairs this machine with a workspace by device code, hosts your own `claude` in a terminal the web app shows, and runs tasks the app dispatches. Connects OUT only; never listens.
