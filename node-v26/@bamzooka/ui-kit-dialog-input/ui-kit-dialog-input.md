# @bamzooka/ui-kit-dialog-input

> 标签: JavaScript

## 简介

This library is used to prompt the user with a dialog that contains inputs. It uses [McDynamicFormModule](../dynamic-form/README.md) to display the inputs based on `McQuestion`.
