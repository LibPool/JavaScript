# @guidobuilds/loopback-setup

> 标签: claude-code, codex, installer, loopback, mcp, opencode

## 简介

Ephemeral installer for loopback — registers the remote MCP endpoint and copies the feedback-detector skill + /harness-feedback command into your AI coding agent (Claude Code, OpenCode, Codex). One-shot via `npx`; no persistent CLI.
