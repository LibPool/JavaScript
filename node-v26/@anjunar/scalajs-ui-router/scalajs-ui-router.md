# @anjunar/scalajs-ui-router

> 标签: JavaScript

## 简介

The TypeScript routing API of Scala JS UI 1.0: route tables, nested outlets and navigating links, projected onto the ui.router.Router that runs in the Scala.js runtime published as @anjunar/scalajs-ui-bridge.
