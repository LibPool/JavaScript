# @frapx/tool-capture

> 标签: 16-bit-png, capture, export, png-sequence, shader, webgl, zip

## 简介

Browser frame export for @frapx/fx-canvas, @frapx/fx-passes and @frapx/fx-particles — deterministic PNG sequences (8-bit or 16-bit) written to a folder or a ZIP, with no dependencies.
