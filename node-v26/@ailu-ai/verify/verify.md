# @ailu-ai/verify

> 标签: JavaScript

## 简介

Offline, independent verifier for an Ailu Certificate of Execution — re-checks the Ed25519 signature, walks the attestation chain, AND re-derives the run from the capsule alone. `npx @ailu-ai/verify capsule.json`.
