# @nilvn/plugins

> 标签: adv, galgame, nilvn, plugins, visual-novel

## 简介

The first-party NilVN plugins — text / character / screen / object effects, sprite animation, keyframe choreography, replays, the in-game menu — as runtime modules, manifests and a batteries-included engine bundle
