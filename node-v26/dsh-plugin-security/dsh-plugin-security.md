# dsh-plugin-security

> 标签: audit, cordis-plugin, deepseek-harness, dsh-plugin, malware-screening, npm-audit, plugin-security, security, supply-chain-security, tool-call-gate, vulnerability

## 简介

Plugin security review for DeepSeek Harness: dependency advisories, contextual static evidence, a call-time gate for high-risk plugins, and reversible review-gated enforcement.
