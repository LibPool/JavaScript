# publish-gauge

> 标签: exports, github-action, lint, npm, pack, package-json, prepublish, publish, sarif, tarball, types

## 简介

Check what npm publish will actually ship before you publish: packs the tarball and verifies entry points, exports and bin targets exist and load, types resolve, no secrets or junk are included, and size stays within budget. Text/JSON/SARIF/Markdown, allo
