> 标签: auto-detect, comma, csv, data, delimited, file, filereader, jquery-plugin, multi-threaded, parse, parser, parsing, pipe, stream, tab, text, thread, threading, worker, workers

## 简介

Fork of papaparse that adds a byte offset config option. Fast and powerful CSV parser for the browser that supports web workers and streaming large files. Converts CSV to JSON and JSON to CSV.
