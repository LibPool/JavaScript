# @llein/api-error-sanitizer

> 标签: api-error, axios-error, cloudflare-error, error-normalizer, error-sanitizer, fetch-error, laravel-error, nestjs-error, react-hook, toast-error, typescript, utility, zero-dependency

## 简介

Ultra-lightweight, zero-dependency API error normalizer and sanitizer for Axios, Fetch, NestJS, Laravel, and Cloudflare HTML crashes into clean UI-ready toast objects.
