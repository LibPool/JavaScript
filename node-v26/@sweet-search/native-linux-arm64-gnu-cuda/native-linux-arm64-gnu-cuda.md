# @sweet-search/native-linux-arm64-gnu-cuda

> 标签: JavaScript

## 简介

Sweet Search native binaries for Linux arm64 (glibc) with NVIDIA CUDA backend (candle-cuda + flash-attn) — Jetson Orin, Grace Hopper, and arm64 server GPUs
