# @moksa/plugin-commerce-documents

> 标签: JavaScript

## 简介

出貨單、揀貨單與訂單明細：瀏覽器列印或存成 PDF，中文字型與斷行、A4／A5／80mm 熱感紙、物流單號條碼、批次列印，需搭配 @moksa/emdash-shop 網站整合套件。
