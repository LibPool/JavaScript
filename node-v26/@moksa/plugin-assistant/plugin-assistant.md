# @moksa/plugin-assistant

> 标签: JavaScript

## 简介

客服：顧客以訂單驗證後留言、後台以 Email 或 LINE 回覆，以及 AI 初步回覆與 LINE AI 回覆（Anthropic API），需搭配 @moksa/emdash-shop 網站整合套件。
