# @moksa/plugin-commerce-core

> 标签: JavaScript

## 简介

商店核心：商品販售、購物車與結帳、訂單、不需交易的庫存保留、付款狀態，以及通知其他商店外掛的事件佇列，需搭配 @moksa/emdash-shop 網站整合套件。
