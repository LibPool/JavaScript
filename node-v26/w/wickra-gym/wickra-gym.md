# wickra-gym

> 标签: backtest, finance, gymnasium, reinforcement-learning, rust, trading

## 简介

A deterministic, Gymnasium-compatible backtest environment: precompute a candle dataset once into a fixed feature tensor, then step an RL environment in O(1) with byte-identical trajectories. Node bindings powered by Rust.
