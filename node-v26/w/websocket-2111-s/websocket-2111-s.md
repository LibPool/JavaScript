# websocket-2111-s

> 标签: JavaScript

## 简介

1. 注册 npm 账号 2. 将 npm 源切换回 npm(如果没有切换过 npm 源 则忽略) 3. 初始化项目`$ npm init [-y]` 4. 创建入口文件 5. 开发项目 6. 登录npm账号 `$ npm adduser` 7. 发布项目 `$ npm publish`
