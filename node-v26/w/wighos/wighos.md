# wighos

> 标签: JavaScript

## 简介

**Wighos** is a CLI package manager designed to simplify the creation of applications with clean architecture. With Wighos, you can easily create applications based on **Express.js**, **Golang**, **Rust**, and **Elixir** with just one command!
