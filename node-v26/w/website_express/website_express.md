# website_express

> 标签: website、express、http、https

## 简介

一款基于express、http、https、connect-history-api-fallback、fs、path、process插件开发的网站服务器模块，尽最大化简单、便捷地使用express插件的功能，方便通过node JS平台搭建所需的网站站点。
