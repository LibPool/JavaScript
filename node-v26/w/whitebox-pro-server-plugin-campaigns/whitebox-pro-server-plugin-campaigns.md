# whitebox-pro-server-plugin-campaigns

> 标签: JavaScript

## 简介

WhiteBox server — campaigns plugin. Plan & execute email/SMS campaigns to audiences. Mikser upserts campaign content; the UI attaches audiences (many-to-many) and sends. v1 is dry-run.
