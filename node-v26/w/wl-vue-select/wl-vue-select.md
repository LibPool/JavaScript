# wl-vue-select

> 标签: select tree-select 全选下拉框 树形下拉框 select-all el-select vue elementUi

## 简介

提供带全选快捷操作的下拉框和树形下拉框功能，基于el-select和el-tree实现 El-select based select with full selection
