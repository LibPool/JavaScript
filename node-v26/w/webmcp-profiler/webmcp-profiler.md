# webmcp-profiler

> 标签: agents, benchmark, instrumentation, mcp, modelcontext, observability, performance, profiler, webmcp

## 简介

Drop-in performance analyser for WebMCP tool surfaces: per-call spans, payload and token accounting, host-gap ledger, live overlay, an agent-readable report tool, and an agentless bench. Zero dependencies.
