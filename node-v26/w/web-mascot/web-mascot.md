# web-mascot

> 标签: animation, browser, desktop-pet, embed, mascot, neurolings, pet, shimeji, shimeji-ee, sprite, typescript, web

## 简介

Embeddable browser mascot engine: run Shimeji-format mascot packs inside any web page (NeurolingsCE-Qt web port).
