# webpack-dns-prefetch

> 标签: JavaScript

## 简介

收集项目中的所有域名,注入到 html 中,进行 DNS 预加载

## 官网

- npm 页面：https://www.npmjs.com/package/webpack-dns-prefetch

- npm registry：https://registry.npmjs.org/webpack-dns-prefetch
- Node 要求：>=10.16.0
