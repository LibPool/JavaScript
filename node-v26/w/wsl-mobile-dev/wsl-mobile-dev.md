# wsl-mobile-dev

> 标签: adb, android, dev-client, emulator, expo, metro, react-native, usbipd, windows, wsl, wsl2

## 简介

Reconcile the WSL2 state that Expo and React Native dev builds need on Android: usbipd, adb server, reverse tunnels, Metro hostname.
