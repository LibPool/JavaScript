# wstp-node

> 标签: kernel, mathematica, native-addon, wolfram, wolframscript, wstp

## 简介

Native Node.js addon for Wolfram/Mathematica WSTP — kernel sessions with evaluation queue, streaming Print/messages, Dialog subsessions, and side-channel WstpReader
