## 简介

* git clone https://gitlab.com/logi95/wonderpool-app-driver-eject.git * cd wonderpool-app-driver-eject * npm install * cd ios * pod install * sudo gem install cocoapods -v 1.5.3 * pod install * 컴파일을 위해 ios/wonderpool-app-driver.xcworkspace 오픈 * 컴파일 오류 부분
