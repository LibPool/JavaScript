# webkit-touch-scroll-fix

> 标签: bug, drag, fix, hack, iOS, scroll, touch, webkit

## 简介

Fixes the iOS 11.3 bug that makes touch events cause the window to scroll.  This can be an issue for drag and drop libraries.
