# wolt-mcp

> 标签: cart, delivery, grocery, mcp, modelcontextprotocol, shopping, wolt

## 简介

MCP server for Wolt shopping: search grocery products near you, plan a single-store cart, and write it to your Wolt basket. Your MCP client's model does the reasoning — no API key needed here.
