# whats-this-pr

> 标签: agent, claude-code, code-review, diff, pull-request, review, skill

## 简介

Turn a pull request into a guided review page: an interactive before/after diagram of the behaviour it changes, the diff cut into ordered steps with notes, and the risks to check.
