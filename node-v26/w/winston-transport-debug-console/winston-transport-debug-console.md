# winston-transport-debug-console

> 标签: console, debug, debug-console, devtools, expandable, inspectable, inspector, inspector-console, logger, logging, node-inspector, object-inspection, vscode, vscode-debug, winston, winston-transport

## 简介

A Winston transport that makes logs visible in inspector clients (like VS Code’s Debug Console) with support for fully inspectable objects.
