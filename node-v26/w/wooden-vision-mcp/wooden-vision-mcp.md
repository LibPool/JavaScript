# wooden-vision-mcp

> 标签: image-recognition, mcp, model-context-protocol, multimodal, screenshot, vision

## 简介

A generic MCP server that lets a text-only LLM agent 'see' images by sending them to any OpenAI-compatible multimodal model (e.g. gpt-4o, glm-4.6v, qwen-vl).
