# webpack-remove-code-blocks

> 标签: blocks, remove code, remove code blocks, strip code, webpack, webpack-loader, webpack-remove-blocks, webpack-strip-blocks

## 简介

A webpack plugin that removes marked blocks of code from any code processed by webpack.
