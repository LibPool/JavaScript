> 标签: 3d, ai, animation, blender, cli, deepseek, gpt-4o, llm, openai, pbr, procedural, scene-compiler, textures, typescript, video-generation, world-model

## 简介

Wallermax H1 — Procedural 3D scene compiler. Text + reference image + final image -> semantic World Model -> Blender -> MP4. Native Node.js + TypeScript web server.
