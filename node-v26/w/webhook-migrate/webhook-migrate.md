# webhook-migrate

> 标签: JavaScript

## 简介

Reads a local backup of a [webhook][webhook] site, the same one that is produced by `wh preset-data-all`. Writes a copy of the local backup, with all of the files re-uploaded to the new webhook instance. Used to migrate files from one instance of webhook,
