# wit-breaking

> 标签: breaking-changes, ci, compatibility, component-model, wasm, webassembly, wit

## 简介

Detects breaking changes between two versions of a WebAssembly Component Model WIT interface -- the equivalent of buf breaking / oasdiff for WIT.
