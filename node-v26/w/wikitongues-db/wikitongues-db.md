# wikitongues-db

> 标签: bcp47, dataset, glottolog, iso639-3, languages, linguistics, oral-history, search, videos, wikitongues

## 简介

Lightweight, zero-dependency database and query library mapping ISO 639-3, Glottolog and BCP 47 language classifications to Wikitongues oral history video recordings.
