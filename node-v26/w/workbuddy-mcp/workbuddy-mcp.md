# workbuddy-mcp

> 标签: agent, claude-code, codebuddy, codex, cursor, mcp, subagent, workbuddy

## 简介

把 WorkBuddy（codebuddy CLI）包装成 MCP Server，让 Claude Code / Codex / Cursor / OpenCode 等任意 MCP 客户端把它当子 Agent 调用
