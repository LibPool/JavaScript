# webpage-channel

> 标签: broadcast channel, broadcastchannel, browser messaging, cross-context communication, cross-window communication, iframe messaging, iframe通信, inter-tab communication, postMessage, postmessage, rpc, web worker messaging, worker通信, 多标签页通信, 跨页面通信

## 简介

A lightweight library for cross-context communication between browser tabs, iframes, and web workers using broadcast channels and postMessage.
