# web-bluetooth-printer

> 标签: bluetooth, esc-pos, escpos, kasir, pos, printer, receipt, struk, thermal, web-bluetooth, web-usb

## 简介

Cetak langsung ke thermal printer (ESC/POS) via Web Bluetooth & Web USB — tanpa aplikasi pihak ketiga. Support 58mm & 80mm, struk transaksi, dan buka laci kasir.
