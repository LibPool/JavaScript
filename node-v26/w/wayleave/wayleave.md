# wayleave

> 标签: 402, access-control, agent-identity, agent-payments, agent-traffic, ai-agents, api-monetization, bot-detection, connect, ed25519, express, http-402, http-message-signatures, micropayments, middleware, monetization, rate-limiting, rfc9421, web-bot-auth, x402, zero-dependencies

## 简介

Know which AI agents cross your API — verified by signature, not guessed from an IP. Sorts every request into four lanes, prices the non-human ones with HTTP 402, and never charges a human. Zero dependencies.
