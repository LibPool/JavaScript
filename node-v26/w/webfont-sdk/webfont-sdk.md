# webfont-sdk

> 标签: canvas-font, chinese-font, font-face, font-subset, incremental-font, webfont

## 简介

Web 字体按需加载 SDK —— 只加载实际用到的字符，增量去重、无闪烁，支持 DOM(CSS) 与 Canvas(FontFace) 两种模式，内置服务端 REST API 客户端
