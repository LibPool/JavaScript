# winter-avatar

> 标签: 2d, 3d, avatar, bust, cosmic-fi, full-body, head, isometric, minecraft, renderer, skin, winter-avatar, winteravatar

## 简介

Standalone Minecraft skin renderer library for Node.js - renders 2D and 3D isometric avatars from Minecraft skins
