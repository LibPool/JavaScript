# wynkjs

> 标签: api, backend, brotli, bun, bun-framework, compression, decorators, dependency-injection, elysia, express, expressjs alternative, fast, framework, gzip, http, middleware, nestjs, nestjs alternative, plugins, rest-api, server, typescript, typescript-decorators, web-framework, wynk, wynkjs

## 简介

A high-performance TypeScript framework built on Elysia for Bun with elegant decorator-based architecture, built-in compression, and plugin system - 10x faster than Express/NestJS
