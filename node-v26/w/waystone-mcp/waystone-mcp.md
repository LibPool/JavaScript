# waystone-mcp

> 标签: agents, browser-automation, mcp, model-context-protocol, playwright, recorder, waystone

## 简介

MCP server for Waystone, the browser action recorder. Launches `waystone mcp` from a managed Python environment so clients can use `npx waystone-mcp` with nothing else installed.
