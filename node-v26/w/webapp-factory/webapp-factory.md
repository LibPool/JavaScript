# webapp-factory

> 标签: JavaScript

## 简介

webapp-factory — verzamelpackage. De backend-foundation-collectie (domein-loze, herbruikbare backend-kits: config, http, persistence, ...) is bereikbaar onder de subpath `webapp-factory/backend-foundation`.
