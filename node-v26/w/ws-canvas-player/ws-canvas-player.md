# ws-canvas-player

> 标签: JavaScript

## 简介

🎥 A Vue 3 component for rendering real-time MJPEG or JPEG frames from a WebSocket stream onto a `<canvas>`, with fullscreen support and keyboard shortcuts. Ideal for video monitoring dashboards.
