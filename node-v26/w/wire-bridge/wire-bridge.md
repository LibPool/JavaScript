# wire-bridge

> 标签: bridge, islands, laravel, livewire, preact, react, solid, state, svelte, vue

## 简介

Framework-independent bridge that shares one mounted Livewire component's state with any frontend renderer. Preact, React, Solid, Svelte and Vue adapters included.
