# wslport

> 标签: cli, eaddrinuse, kill-port, port, windows, wsl, wsl2, wslrelay

## 简介

Find what is holding a TCP port on Windows, following wslrelay.exe into the WSL distro to name the real process. 查出是誰佔用了 port，連 WSL 裡的行程都追得到。
