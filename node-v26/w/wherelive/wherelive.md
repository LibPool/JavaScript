# wherelive

> 标签: firebase, firestore, frontend, listener, realtime-database, typed-query

## 简介

Typed where/select/listen for Firebase apps: filter rows you already hold, or listen to only the attributes you selected, with one description. Built for the frontend, runs unchanged in Node.
