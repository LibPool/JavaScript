# wame-mcp

> 标签: chrome-extension, claude, mcp, modelcontextprotocol, wame, whatsapp, whatsapp-web

## 简介

MCP server that gives your local Claude read access to WhatsApp Web through the WaMe Chrome extension. Runs on loopback; your messages never leave your machine.
