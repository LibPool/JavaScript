# wayang-ui

> 标签: JavaScript

## 简介

### What is it? `wayang-ui` is a small, simple scaffolding for building web components. It comes with three exports; the `WebComponent` class for building visual elements, the `Presenter` class used to attach behaviors, and the `Mixin` class for extending
