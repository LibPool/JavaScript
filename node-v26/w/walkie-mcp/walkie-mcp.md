# walkie-mcp

> 标签: ai-agents, cli, mcp, model-context-protocol, notifications

## 简介

stdio MCP wrapper for Walkie — forwards newline-delimited JSON-RPC from stdin to a remote Walkie /mcp (Streamable HTTP) endpoint.
