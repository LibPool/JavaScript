# wb-browser-runtime

> 标签: browser-automation, browserbase, cdp, playwright, wb, workbooks

## 简介

Browser sidecar runtime for wb — Playwright over CDP (Browserbase, browser-use) via the wb-sidecar/1 line-framed JSON protocol.
