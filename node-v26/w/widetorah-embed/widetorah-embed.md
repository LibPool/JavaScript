# widetorah-embed

> 标签: api, embed, judaism, scripture, shadow-dom, verse, widetorah, widetorah.com, widget, zero-dependencies

## 简介

Embed WideTorah scripture widgets on any website. Lightweight (~5KB gzipped), zero dependencies, Shadow DOM isolation, 3 themes (light/dark/sepia).

## 官网

- 官网：https://widget.widetorah.com
- 源码仓库：git+https://github.com/dobestan/widetorah-embed.git
