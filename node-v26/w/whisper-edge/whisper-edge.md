# whisper-edge

> 标签: agent, cloudflare-workers, dane, deno, dnssec, edge, egress, identity, ipv6, lambda, netlify, proxy, rdap, serverless, supabase, vercel, verify, whisper, zero-dependency

## 简介

Dependency-free Whisper agent-identity SDK for serverless & edge runtimes (Cloudflare Workers, Vercel, Deno, Netlify, AWS Lambda, Supabase). Keyless verify/resolve/RDAP, the full control plane with an API key, and REAL egress from an agent's routable /128
