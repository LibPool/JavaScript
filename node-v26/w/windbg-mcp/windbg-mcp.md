> 标签: cdb, crash-dump, debugger, kd, kernel-debugging, mcp, model-context-protocol, windbg, windows

## 简介

MCP server that drives cdb.exe/kd.exe (WinDbg): crash dump analysis, live user-mode debugging, and kernel debugging
