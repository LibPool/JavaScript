# wub

> 标签: JavaScript

## 简介

`wub` is a tool designed to take the pain and repetition out of configuring `webpack`. `wub` is quite simply a function that takes the *presets* you specify and combines them into a valid webpack config. These *presets* enable features you want from webpa
