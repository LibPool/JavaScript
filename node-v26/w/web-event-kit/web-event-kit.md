# web-event-kit

> 标签: abort-signal, addEventListener, attachEvent, browser, cordova, event, event-listener, ie, once, passive, pointer-events, polyfill, pwa, touch-events, vendor-prefix, webview

## 简介

TypeScript event listener unifier — one add/remove interface that behaves identically across modern browsers, legacy IE (attachEvent), Cordova, and iOS WebKit, with vendor-prefix resolution, once/passive/signal emulation, and pointer→touch synthesis.
