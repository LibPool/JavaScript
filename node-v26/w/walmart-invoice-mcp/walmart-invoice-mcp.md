# walmart-invoice-mcp

> 标签: browser-extension, claude, invoice, mcp, model-context-protocol, orders, walmart

## 简介

MCP server for the Walmart Invoice Exporter browser extension (REQUIRED — the server has no data of its own). Lets Claude Code, Claude Desktop, and other MCP clients read your locally saved Walmart order history, and optionally start collection/invoice fe
