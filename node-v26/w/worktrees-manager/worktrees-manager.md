# worktrees-manager

> 标签: dashboard, dev-tools, git, worktree, worktrees

## 简介

Dashboard local para gestionar git worktrees: crear/borrar con puerto automático, arrancar/parar su entorno de dev con logs en tiempo real, ver cambios sin commitear y su PR asociada.
