# weavr-sdk

> 标签: banking-as-a-service, embedded banking, fintech, managed accounts, managed cards, open banking, payments, sdk, typescript, weavr

## 简介

Production-grade, fully-typed TypeScript SDK for the Weavr Multi embedded banking API (Managed Accounts, Managed Cards, Corporates, Consumers, Transfers, Sends, Bulk, Back Office, and more).
