# whalewatch-agent

> 标签: agent, collector, logs, metrics, monitoring, observability, opentelemetry, otel, systemd, whale

## 简介

Server monitoring for Whale. Installs a pinned OpenTelemetry Collector as a systemd service that ships this server's metrics, processes, containers and logs to Whale.

- 官网：https://whale.balajitech.xyz/docs/
