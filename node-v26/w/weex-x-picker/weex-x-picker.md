# weex-x-picker

> 标签: Android, IOS, Layout, Vue, Web, Weex, WeexComponent, picker

## 简介

weex-x-picker 支持 single(单选)，area(区域)，section(区间)，date(日期)，time(时间), linkage(联动), 平台支持 IOS，Android，Web
