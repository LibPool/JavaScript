# whitebox-pro-sms-twilio

> 标签: JavaScript

## 简介

Twilio provider for whitebox-pro-server-plugin-sms — send (Messages API), inbound + delivery-status webhooks, X-Twilio-Signature verification. No SDK (raw REST).
