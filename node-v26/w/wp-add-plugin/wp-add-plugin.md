# wp-add-plugin

> 标签: automation, cli, plugin, wordpress

## 简介

A CLI tool to automate the setup of new WordPress plugins with React.js setup. It simplifies the process by taking inputs and replacing boilerplate code, saving developers time and effort. No more manual editing of plugin names, text domains, or other rep
