# web-jszipp

> 标签: archive, browser, compression, decompression, deflate, security, typescript, web-streams, zip, zip64

## 简介

Fast, compact, and defensive ZIP reader and writer for modern browsers, with optional cr86ff68/cr61ff58 legacy builds, safe defaults, Web Streams, ZIP64, metadata, and unsafe-archive guards.
