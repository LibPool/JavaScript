# white-label-router

> 标签: accessibility, browser, client-side-routing, framework-independent, history-api, html-first, incremental-adoption, javascript, navigation, node, progressive-enhancement, router, routing, server-rendered, server-side, serverless, typescript, universal

## 简介

Framework-independent TypeScript router for progressive enhancement in browser, server-rendered, and Node.js applications, with scoped links, guards, and accessible navigation.
