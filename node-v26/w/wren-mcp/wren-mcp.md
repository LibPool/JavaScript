# wren-mcp

> 标签: agent, claude, email, gmail, mcp, model-context-protocol

## 简介

The MCP stdio shim for Wren — the open-source agent gateway to your own email. Connects Claude Code, Claude Desktop, or any MCP client to a running Wren app over a local socket.
