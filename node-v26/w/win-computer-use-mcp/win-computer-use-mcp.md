# win-computer-use-mcp

> 标签: computer-use, desktop-automation, keyboard, mcp, modelcontextprotocol, mouse, nut-js, screenshot, windows

## 简介

Windows桌面自动化 MCP 工具：Agent 通过截图获取画面、以截图像素坐标控制鼠标键盘、再截图验证，形成电脑操作闭环
