# web-record-js

> 标签: 百度语音语义识别, 语音处理, 语音转码

## 简介

Web浏览器前端语音处理框架，完成语音提取，语音PCM编码转换，语音播放的功能。集成百度语音语义处理接口，实现语音识别，语音合成和语义识别的功能
