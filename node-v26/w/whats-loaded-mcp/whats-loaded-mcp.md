# whats-loaded-mcp

> 标签: agents, claude, claude-code, context-window, mcp, model-context-protocol, skills, token-budget

## 简介

MCP server that shows what is consuming your agent's context window before the conversation starts — skill descriptions, memory files and their imports, and configured MCP servers — ranked, with duplicates called out.
