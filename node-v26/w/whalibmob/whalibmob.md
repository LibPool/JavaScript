# whalibmob

> 标签: android, automation, channels, chatbot, companion, e2e, e2ee, encryption, groups, ios, media, messaging, mobile, multi-device, pairing-code, qr-code, signal-protocol, sms-registration, whatsapp, whatsapp-api, whatsapp-bot, whatsapp-client, whatsapp-mobile, whatsapp-web

## 简介

Node.js library for WhatsApp — register a number over SMS, or link as a companion by QR. Signal E2E encryption, media, groups, channels.
