# wp-env-opossum

> 标签: apple-container, container, opossum, phpunit, testing, wordpress, wp-env

## 简介

A drop-in @wordpress/env replacement that runs the wp-env test environment on Apple's native `container` runtime via opossum — no Podman or Docker Desktop VM.
