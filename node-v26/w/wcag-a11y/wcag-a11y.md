# wcag-a11y

> 标签: a11y, accessibility, ai, anthropic, aria, audit, auth, cli, fix, gemini, openai, playwright, screen-reader, wcag, wcag2, wcag21, wcag22

## 简介

WCAG 2.1/2.2 accessibility auditor with AI-powered fixes. Crawls your dev server with Playwright, runs 40+ checks, and uses AI (12 providers) to generate fix prompts or patch source files directly. Supports authenticated sessions via Playwright storageSta
