# weblive2d

> 标签: api, live2d, model, web, widget

## 简介

1. 将 `Live2D` 完全 `cdn` 化，目录结构简单，便于编辑、添加和删除模型。 2. 为以 `CDN` 方式加载的 `Live2D` 模型，添加模型皮肤顺序切换的功能。 3. 将项目配置文件拆分成 `<link>` 与 `<script>` 标签的形式便于网站引入。
