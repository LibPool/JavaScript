# wickchart-layouts

> 标签: chart, charting, layouts, persistence, trading, web-component, wickchart, workspace

## 简介

Named workspace persistence for wickchart — save/restore whole chart setups (type, indicators, theme, view, drawings, positions, alerts) to localStorage. Opt-in plugin, zero dependencies.
