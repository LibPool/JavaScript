# weaver-agent

> 标签: agent, ai-agent, autonomous-coding, cli, coding-agent, langchain, langgraph, llm, typescript

## 简介

Weaver — Coding agent dệt plan, code và test thành phần mềm chạy được. Xây dựng với LangGraph: Planner → Analyzer → Coder → Tester → Reviewer, tự sửa khi test fail.
