# wrongsynapse

> 标签: bm25, cognitive-memory, embeddings, fts5, knowledge-graph, local-first, mcp, memory, rag, sqlite, tree-sitter, vector-search

## 简介

Local-first Cognitive Memory Operating System and MCP server for autonomous AI coding agents. Tri-hybrid retrieval: ONNX semantic embeddings + SQLite FTS5/BM25 + hierarchical knowledge graph, fused with Reciprocal Rank Fusion. Zero cloud.
