# whisper-ggml-header

> 标签: cli, ggml, model, n_text_ctx, validation, whisper, whisper.cpp

## 简介

Read and validate the header of a Whisper GGML model. Catches the n_text_ctx=1024 mis-conversion that makes whisper.cpp refuse to load a file. No dependencies.
