# wascan

> 标签: barcode, ean, qr-code, rxing, scanner, upc, wasm, webassembly

## 简介

Production-ready barcode and QR code scanner for web browsers. Handles camera access, streaming, and file input automatically. Works across all modern browsers and platforms. Built with Rust and WebAssembly.
