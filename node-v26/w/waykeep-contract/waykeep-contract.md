# waykeep-contract

> 标签: cairn, contract, hooks, mcp, memory

## 简介

Integration contract for Waykeep (formerly Cairn) — normalized hook event types, client identity, memory vocabulary, portable round-trip format, and hook-socket routes. Types and constants only; zero dependencies.
