# webcrypto-ratchet

> 标签: double-ratchet, e2ee, ml-kem, post-quantum, pqxdh, signal-protocol, triple-ratchet, webcrypto, x3dh

## 简介

PQXDH key agreement + Triple Ratchet (Double Ratchet + continuous ML-KEM ratchet) session encryption, built on the standard WebCrypto API plus @noble/post-quantum for the ML-KEM steps WebCrypto doesn't yet support.
