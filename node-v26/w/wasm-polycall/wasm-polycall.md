# wasm-polycall

> 标签: ffi, host-imports, libpolycall, peer-to-peer, polycall, wasi, wasm, webassembly

## 简介

WebAssembly binding for Polycall: a Node.js host that implements the "polycall" imports of wasm32 guests by calling the real native Polycall core (binding ABI v1).
