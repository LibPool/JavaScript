# watchmcp

> 标签: claude-code, cursor, mcp, model-context-protocol, registry, security, supply-chain

## 简介

Supply-chain watchtower for MCP servers. Snapshots the official registry daily, keeps the history it forgets, and alerts when a server you have installed silently changes.
