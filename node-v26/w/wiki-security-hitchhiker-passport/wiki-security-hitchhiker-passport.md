# wiki-security-hitchhiker-passport

> 标签: federated-wiki, hitchhiker, passportjs, security, wiki

## 简介

wiki-security-passportjs 0.14.0, unmodified, plus the hitchhiker client bootstrap appended to client/security.js — loads wiki-ux.js and the terms interceptor on every page. OAuth login is upstream's. See README for how to re-fork on a new upstream.
