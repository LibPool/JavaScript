# webpack-tsx

> 标签: express-tsx

## 简介

使用`webpack`和`typescript react`开发需要安装很多依赖, 所以就把自己 在`webpack`开发中常用的一些包放在这里,免得一次次手动输入包名进行安装,  此外还有一些基本配置

## 官网

- npm 页面：https://www.npmjs.com/package/webpack-tsx

## 历史版本号

- 当前版本：0.0.3

- 0.0.3

## 获取地址

- npm 安装：`npm install webpack-tsx`
- npm registry：https://registry.npmjs.org/webpack-tsx
