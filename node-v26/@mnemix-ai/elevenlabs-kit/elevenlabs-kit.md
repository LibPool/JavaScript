# @mnemix-ai/elevenlabs-kit

> 标签: caller-id, conversational-ai, elevenlabs, elevenlabs-agents, enrichment, memory, mnemix, voice-agent

## 简介

Mnemix integration kit for ElevenLabs Agents — conversation-initiation enrichment on the inbound-phone path, an inline session-context builder for outbound/Register-Call/SDK sessions, and post-call memory write-back.
