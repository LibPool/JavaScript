# @hubrella/sdk

> 标签: authentication, credits, hubrella, jwt, knowledge-base, sdk, sso

## 简介

Plug-in SDK for Hubrella tools: verify SSO tokens, gate by plan, spend shared credits, and read/write the shared knowledge base.
