# @barrysande/pesapal-sdk

> 标签: api-client, east-africa, kenya, mpesa, payments, pesapal, typescript

## 简介

An unofficial typed Node.js client for the Pesapal API 3.0, supporting payments, subscriptions, transaction status, IPN registration, refunds, and order cancellation.
