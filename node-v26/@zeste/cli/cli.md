# @zeste/cli

> 标签: cli, cmp, consent management, cookie banner, cookie consent, ePrivacy, gdpr, google consent mode, headless, rgpd, tarteaucitron

## 简介

zeste CLI: detects a project's services and copies an editable consent banner, preferences and placeholder into your project. Ready-made for Svelte, React and Vue with Bits UI, Radix, Reka UI, Ark UI and shadcn; zeste itself works with any UI
