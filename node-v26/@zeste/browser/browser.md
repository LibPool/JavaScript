# @zeste/browser

> 标签: cmp, consent management, cookie banner, cookie consent, ePrivacy, gdpr, google consent mode, headless, rgpd, tarteaucitron, wordpress

## 简介

zeste as a <script> tag, for sites without a JavaScript framework: consent engine, the tarteaucitron catalog and a ready-made banner. Drop-in replacement for tarteaucitron.js
