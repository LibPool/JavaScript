# @enterprisestandard/redis-core

> 标签: JavaScript

## 简介

Redis adapter interface and store implementations for Enterprise Standard. Use with @enterprisestandard/redis (node-redis), @enterprisestandard/ioredis, or a custom RedisAdapter.
