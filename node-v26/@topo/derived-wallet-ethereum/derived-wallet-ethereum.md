# @topo/derived-wallet-ethereum

> 标签: JavaScript

## 简介

A light-weight add-on package to the [@topo/wallet-adapter-react](../wallet-adapter-react/) that enables the functionality to use an EVM wallet as a Native Aptos Wallet
