# @omgbase/oqx-syntax

> 标签: codemirror, grammar, monaco, monarch, omgbase, oqx, prism, query-language, shiki, syntax-highlighting, textmate, tmlanguage, vscode

## 简介

Syntax highlighting assets for OQX (omgbase Query eXpressions): TextMate grammar, Monaco Monarch grammar, language configuration and metadata, with Shiki, Monaco and VS Code adapters — all generated from one lexical vocabulary
