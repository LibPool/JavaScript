# @noresign/paboot

> 标签: agent, claude-code, codex, daemon, headless, self-hosted, sse

## 简介

One client for all your agents — run the agents on your machine headless and stream normalized events over HTTP/SSE: session resume, tool-call approval, multi-agent runs.
