# nou-cli

> 标签: agent, ai, claude, cli, coding-assistant, llm, ollama, tui

## 简介

Nou: an IDE-style AI coding assistant for your terminal. Local (Ollama, LM Studio) and cloud (Claude, OpenAI, Gemini...) models, live diffs, git-aware, built-in editor.
