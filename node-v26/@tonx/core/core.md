# @tonx/core

> 标签: JavaScript

## 简介

TONX.js SDK (`@tonx/core`) makes onboarding to the TON blockchain seamless with TON API tools, leveraging the power of [TONX API](https://tonxapi.com/) to help you launch your dApp quickly.
