# @apidojo/x-scraper

> 标签: apify, scraper, social-media, tweets, twitter, twitter-scraper, x, x-scraper

## 简介

The fastest and cheapest way to scrape tweets from X (Twitter). Wraps the Apify Twitter Scraper Lite actor with a developer-friendly API.
