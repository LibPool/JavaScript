# @eddocu/hmml

> 标签: binary, container, format, hmml, html, hypermedia, image, webp

## 简介

HyperMedia Markup Language - a tiny binary format where an image is HTML, SVG and a 3D space. Markup as text + images as raw bytes (no base64) in one file; ~2 KB reader. The native target for AI-generated media.
