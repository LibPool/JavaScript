# @voltro/plugin-presence

> 标签: framework, typescript, voltro

## 简介

Ephemeral realtime presence — who is online in a channel, with heartbeat + live roster + per-member metadata (cursor, status — client-supplied and relayed verbatim; identity fields belong in the server-side resolveMember hook). Held in memory, owner-parti
