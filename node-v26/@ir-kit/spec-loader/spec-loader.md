# @ir-kit/spec-loader

> 标签: asyncapi, ir-kit, loader, openapi, spec, typespec

## 简介

Universal spec loader for OpenAPI, AsyncAPI, and TypeSpec. Detects format by extension + content sniff and dispatches to the per-format loader, returning a discriminated `{ kind, document }` result.
