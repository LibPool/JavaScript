# @holoscript/vm-bridge

> 标签: agent, bridge, cognitive, holoscript, spatial, uaal, vm

## 简介

Bridge between HoloVM (spatial scenes) and uAAL VM (cognitive agent cycles). Enables agents that perceive, reason about, and mutate 3D scenes.
