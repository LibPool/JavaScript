# @ryancormack/acp-debugger

> 标签: acp, agent, agent-client-protocol, ai, debugger, inspector, jsonrpc, llm

## 简介

Browser-based inspector for the Agent Client Protocol. Launches an ACP agent over stdio and shows every JSON-RPC message in both directions.
