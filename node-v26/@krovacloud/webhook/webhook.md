# @krovacloud/webhook

> 标签: constant-time, express, fastify, hmac, hmac-sha256, krova, krova-cloud, nextjs, replay-protection, security, signature, signature-verification, verify, webhook, webhooks

## 简介

Verify Krova Cloud outbound webhook signatures — HMAC-SHA256, constant-time comparison, replay protection. Express, Next.js & Fastify helpers. Zero runtime dependencies.
