# @roku-sdk/slideshow

> 标签: JavaScript

## 简介

Horizontal slideshow engine for Roku SceneGraph TypeScript apps. Supports eager, virtual, and pooled rendering modes with animated transitions, focus integration, and composable chrome (chevrons, progress dots).
