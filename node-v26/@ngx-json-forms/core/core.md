# @ngx-json-forms/core

> 标签: angular, angular-21, angular-form, angular-forms, angular21, conditional-fields, dynamic-form, dynamic-forms, form, form-builder, form-engine, form-generator, form-renderer, form-validation, forms, json-form, json-forms, json-schema, json-schema-form, multi-step-form, ngx, ngx-json-forms, reactive-forms, schema-driven, schema-form, signal-forms, signals, stepper, typescript, wizard

## 简介

JSON-driven Angular form engine. Build dynamic, reactive Angular forms from a JSON config — validation, conditional fields (showWhen), computed values, multi-step wizard, FormArray repeaters, persistence — without writing template code. Pair with @ngx-jso
