# @nestjs-redisx/counters

> 标签: atomic, counters, incr, nestjs, quota, redis, sequences, statistics

## 简介

Atomic counters and sequences plugin for NestJS RedisX — fleet-wide increments, window counters with first-write TTL, and monotonic ID sequences
