# @augusto1024/dingr

> 标签: audio, javascript, pcm, procedural-audio, sound-effects, synthesizer, typescript, wav

## 简介

A JavaScript and TypeScript sound effects library: synthesize deterministic audio, compose note sequences, and export WAV files without samples or runtime dependencies.
