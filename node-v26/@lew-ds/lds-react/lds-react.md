# @lew-ds/lds-react

> 标签: components, design-system, lds, react

## 简介

React bindings for the Lew Design System — wraps @lew-ds/lds's framework-free templates and controllers as React components, for React-based consumers (Claude Design, Claude Code) without changing @lew-ds/lds itself.
