## 简介

A fork of agentmap adding PHP/Laravel support — the repo map your coding agent is forced to use. Estimated ~98% fewer context tokens to understand a PHP/Laravel or TS/JS codebase. A queryable, ranked code-relationship map (tree-sitter-php + ts-morph): Pag
