# @sfgartland/better-pi-voice

> 标签: cli, coding-agent, deepgram, dictation, hold-to-talk, keyterms, parakeet, pi, pi-extension, pi-package, speech-to-text, voice

## 简介

Streaming voice input for pi: Deepgram (nova-3, repo-aware keyterms) or local Parakeet, with Claude-Code-style recovery so speech is never lost.
