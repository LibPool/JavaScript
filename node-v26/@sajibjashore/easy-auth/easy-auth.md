> 标签: auth, authentication, authorization, bcrypt, express, express-auth, google-oauth, jwt, login, middleware, node-auth, oauth, passport, rbac, role-based-access, session, token

## 简介

A lightweight, Passport.js-inspired authentication library for Express.js. Strategy-based auth with Local, JWT, and Google OAuth built-in.
