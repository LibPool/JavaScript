# @ilukanets/gulp-to-jst

> 标签: JavaScript

## 简介

> A [gulp](http://gulpjs.com/) plugin to compile [underscore](http://underscorejs.org/#template) / [lodash](http://lodash.com/docs#template) templates into a single file.
