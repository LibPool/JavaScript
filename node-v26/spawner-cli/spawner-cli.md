# spawner-cli

> 标签: claude-code, cli, codex, coding-agents, cursor, devops, docker-compose, ephemeral-environments, mcp, mcp-server, preview-environments, review-apps, self-hosted

## 简介

The CLI and MCP server of Spawner, an open source, self-hosted preview environment manager: a copy of your app for each git branch, on your own server, with its own URLs, database and logs.
