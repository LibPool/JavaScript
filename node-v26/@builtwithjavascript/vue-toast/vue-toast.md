# @builtwithjavascript/vue-toast

> 标签: JavaScript

## 简介

**Lightweight toast notification plugin for Vue 3, styled with Tailwind CSS.**   Supports grouped notifications, preset types (info, success, error, etc.), timeouts, and sticky messages.
