# @launchstack/mongo

> 标签: collections, crud, database, document-mapping, launchstack, mongo-client, mongo-repo, mongodb, orm, repository, type-safety, typesafe, typescript, typescript-library, wrapper

## 简介

A typesafe MongoDB library by LaunchStack, providing a fully typesafe and lightweight wrapper over the official MongoDB driver, with simplified CRUD operations and customizable collection definitions.
