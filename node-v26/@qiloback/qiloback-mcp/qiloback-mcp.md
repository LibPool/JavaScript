# @qiloback/qiloback-mcp

> 标签: ai, backend, claude, cursor, delixon, fastapi, mcp, model-context-protocol, qiloback

## 简介

QiloBack MCP server — orchestrate the QiloBack platform from any MCP-compatible AI client (Claude Desktop, Claude Code, Cursor, Windsurf, ChatGPT Desktop). Spawns the Python qiloback-mcp package; uvx is the recommended runtime.
