# opencode-quota-gui

> 标签: analytics, claude, copilot, dashboard, gemini, github, google, gui, opencode, plugin, quota, sessions, usage

## 简介

opencode-quota-gui is a local dashboard for OpenCode quota, token usage, sessions, and provider limits. Supports GitHub Copilot, OpenAI (Plus/Pro), Chutes AI, Synthetic, Google AGY, and Z.ai coding plans.
