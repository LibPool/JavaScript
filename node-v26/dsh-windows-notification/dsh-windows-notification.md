# dsh-windows-notification

> 标签: cordis, deepseek, deepseek-harness, dsh, dsh-plugin, notification, notifications, plugin, toast, windows

## 简介

Native Windows toast notifications for DeepSeek Harness: smart turn-complete/error summaries, approval actions and agent-question options under the DSH desktop app identity, with a demo option and a settings page for both runtimes.
