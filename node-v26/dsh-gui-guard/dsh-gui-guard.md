# dsh-gui-guard

> 标签: click, computer-use, coordinates, deepseek-harness, dpi-scaling, dsh, dsh-plugin, gui-automation, reliability, sendkeys, windows, 坐标, 窗口, 自动化

## 简介

先确认这个窗口现在能不能安全操作，再动手点击或输入——最小化、不在前台、DPI 缩放都替你处理掉。 Windows window-operation reliability layer: probe whether a window is minimized, in the foreground or DPI-scaled, then click and type with the coordinate space handled.
