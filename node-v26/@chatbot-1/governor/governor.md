# @chatbot-1/governor

> 标签: distributed, rate-limiter, rate-limiting, redis, sliding-window, throttle, token-bucket

## 简介

A distributed rate limiting library implementing token bucket, sliding window log, and sliding window counter algorithms. Local (in-memory) and Redis-backed distributed modes.
