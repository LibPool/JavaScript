# @liuovo/pi-kit

> 标签: developer-tools, extension, pi, pi-package

## 简介

Personal Pi enhancement kit for Pi 1.1.0: compact tool UI, Open TUI shell and interactive settings, native codemode rendering, optional FFF integration, title status and image generation.
