# secure-vibe-runtime

> 标签: convex, csrf, nextjs, rate-limit, secure-vibe-coding, security

## 简介

The runtime security pieces of Secure Vibe Coding OS (secrets loading, CSRF, rate limiting, security log) as one package, so every app built from the template gets fixes by updating it.
