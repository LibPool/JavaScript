# @stowage/adapter-s3

> 标签: adapter, aws, cloud-storage, cloudflare, file-storage, object-storage, r2, s3, storage, stowage

## 简介

stowage adapter for one bucket of AWS S3 or Cloudflare R2, speaking the S3 wire protocol without an SDK.
