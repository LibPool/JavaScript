# @hubprox/cart

> 标签: cart, crm, ecommerce, hubpro, pinia, redux, tracking, zustand

## 简介

Auto-Cart-Tracking für HubPro CRM — wrappt Zustand/Redux/Pinia-Stores und feuert hubprox:cart:added + hubprox:cart:changed Events ohne manuellen Code im Cart-Store.
