# ds-skillmarket

> 标签: deepseek, dsh, dsh-plugin, github, harness, marketplace, skills

## 简介

Skill 集市 for DeepSeek Harness — 聚合 GitHub 上符合规范的 Agent Skills：星标/下载量一目了然，一键安装到 ~/.dsh/skills；支持查看已安装技能、本地新建与 URL 导入。Browse, install, create and import agent skills.
