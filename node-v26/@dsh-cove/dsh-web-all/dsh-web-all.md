# @dsh-cove/dsh-web-all

> 标签: JavaScript

## 简介

DSH Web GUI 全家桶插件（实体版）：按 dsh 注入位置组织的单一插件——侧栏（sidebar）/ 设置（settings）/ 会话区（conversation）/ 浮层（flyout）四个位置模块统一编排，host 半区按服务域承载各能力。安装一个插件即全家桶全部能力。
