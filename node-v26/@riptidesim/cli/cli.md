# @riptidesim/cli

> 标签: agent-based, defi, litesvm, riptide, simulation, solana

## 简介

Riptide CLI — deterministic multi-agent simulator for Solana programs. Runs hundreds of adversarial personas against your code in LiteSVM and maps the knife edge before mainnet does.
