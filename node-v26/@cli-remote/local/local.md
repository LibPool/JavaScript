# @cli-remote/local

> 标签: ai, claude, cli, codex, pty, remote, terminal

## 简介

Local PTY agent for cli-remote — exposes your local CLI tools (claude/codex/kimi-cli/shell) to the mobile web client via a self-hosted hub.
