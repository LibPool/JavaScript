# @jipika/dsh-workspace-files

> 标签: deepseek-harness, dsh, dsh-plugin, explorer, file-tree, sidebar, workspace

## 简介

Left-sidebar file switch: hover a workspace row, click the folder icon, and its session list becomes a lazy file tree.
