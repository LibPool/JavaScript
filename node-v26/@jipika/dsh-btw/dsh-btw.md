# @jipika/dsh-btw

> 标签: btw, deepseek-harness, dsh, dsh-plugin, session, side-question, slash-command

## 简介

A native /btw slash command for DeepSeek Harness: ask a side question about the current session and get an answer that never enters the conversation history, never interrupts the running turn, and has no tool access.
