# @centurionwebsite/mcp

> 标签: ai-agent, blockchain, centurion, evm, mcp, model-context-protocol, read-only

## 简介

Read-only Model Context Protocol server for the Centurion chain. Gives an AI coding agent live chain state over stdio, with no keys, no signing, and no transaction broadcast.
