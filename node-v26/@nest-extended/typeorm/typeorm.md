# @nest-extended/typeorm

> 标签: JavaScript

## 简介

This package provides powerful TypeORM integrations for the **NestExtended** ecosystem, offering a robust service layer with built-in pagination, filtering, soft delete capabilities, exception filters, and query utilities. Supports **PostgreSQL**, **MySQL
