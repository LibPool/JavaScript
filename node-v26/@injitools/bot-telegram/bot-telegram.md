# @injitools/bot-telegram

> 标签: bot, chatbot, inji, telegram, telegram-bot-api, typescript

## 简介

Telegram provider for @injitools/bot: a Bot API client (long polling, SOCKS proxy, MarkdownV2 auto-escaping) and the MultiBot social provider on top of it.
