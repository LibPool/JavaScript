# @iamsaroj/smart-ui

> 标签: ag-grid, components, forms, lexical, react, shadcn, tailwindcss

## 简介

Config-driven React 19 component library: Smart* shadcn/ui wrappers, declarative form/search engines, AG Grid data grids, tree, transfer list, calendar, and a Lexical rich-text editor.
