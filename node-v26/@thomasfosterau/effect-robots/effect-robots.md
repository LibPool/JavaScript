# @thomasfosterau/effect-robots

> 标签: effect, rfc9309, robots-exclusion, robots.txt, typescript, web-crawler

## 简介

The Robots Exclusion Protocol (RFC 9309) for Effect: parse, encode and match robots.txt, evaluate a crawl decision with the §2.3.1 failure posture over a pluggable cache, and build the robots.txt a site serves.
