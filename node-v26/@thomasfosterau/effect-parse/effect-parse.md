# @thomasfosterau/effect-parse

> 标签: effect, nom, parser, parser-combinators, typescript, winnow

## 简介

Parser combinators for Effect, ported from Rust's nom and winnow: text, bytes, bits and token streams, streaming input, compiled parsers and Schema integration
