# @pionne/react-native

> 标签: crash-reporting, error-monitoring, expo, observability, pionne, react-native

## 简介

Mobile-first error monitoring SDK for React Native + Expo. Auto-captures JS crashes, unhandled rejections, breadcrumbs (console + fetch), screenshots. Release Health (crash-free user rate), in-app feedback widget, bundle ID auto-pinning, PII scrubber, sou
