# @pionne/node

> 标签: crash-reporting, error-monitoring, express, fastify, nestjs, node, nodejs, observability, pionne

## 简介

Error monitoring SDK for Node.js — Pionne. Auto-captures uncaught exceptions and unhandled rejections, ships runtime context (Node, OS, hostname, pid), and tracks Release Health (crash-free user rate per release).
