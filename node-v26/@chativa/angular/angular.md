# @chativa/angular

> 标签: angular, chat, chativa, web-component, wrapper

## 简介

Chativa Angular — standalone components (chativa-chat-iva, chativa-chat-bot-button, chativa-genui-message), an NgModule and ChativaService wrapping the Chativa chat widget for Angular 16+ apps.
