# @chativa/vue2

> 标签: chat, chativa, nuxt, nuxt2, vue, vue2, web-component, wrapper

## 简介

Chativa Vue 2 — Vue 2.7 / Nuxt 2 wrapper components (ChatIva, ChatBotButton, GenUIMessage) and a Vue.use() plugin for the Chativa chat widget. Maintenance-mode package for legacy Vue 2 codebases.
