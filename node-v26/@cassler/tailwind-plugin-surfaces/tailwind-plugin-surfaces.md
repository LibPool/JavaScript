# @cassler/tailwind-plugin-surfaces

> 标签: JavaScript

## 简介

This plugin add a `.box-*` utility class for quickly applying a "surface style" to elements. This works exactly the same as `.bg-*` while also configuring the containers `backgroundColor` and `borderColor`, as well as the `color` rule for child headings,
