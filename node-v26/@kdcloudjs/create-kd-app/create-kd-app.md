# @kdcloudjs/create-kd-app

> 标签: JavaScript

## 简介

一个前端提供的快速开发页面的脚手架。   苍穹平台现支持前后端分离，支持依据开放平台提供的API独立开发应用。前端开发人员可以基于提供的API，独立完成开发任务，与后台解耦，开发效率更快。
