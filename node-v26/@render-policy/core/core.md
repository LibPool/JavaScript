# @render-policy/core

> 标签: agent, dompurify, exfiltration, llm, markdown, mcp, sanitize, sanitizer, security, streaming, trusted-types, xss

## 简介

Render agent-generated Markdown/HTML safely: sanitize into a DocumentFragment, insert with replaceChildren (never innerHTML), enforce a URL/host policy, stay Trusted Types compatible, handle streaming.
