# @vibedout/capability

> 标签: capability, cloudflare, d1, guest-id, hmac, magic-link, workers

## 简介

Signed, scoped, expiring action links (manage/cancel a booking, claim a tag, edit a page) plus a signed guest-id cookie, replacing the three independently-invented HMAC/random-token schemes audited in docs/05-identity/research/05.06-R01-magic-links-guest-
