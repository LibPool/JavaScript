# @vibedout/realtime

> 标签: cloudflare, durable-objects, partysocket, presence, realtime, websocket, workers

## 简介

Realtime rooms for Cloudflare Workers: a RealtimeRoom Durable Object base class on the WebSocket Hibernation API (Zod message protocol, presence derived from the sockets' attachments, numbered events in SQLite with catch-up, rate limits, broadcast over RP
