# @builder6/oidc-provider

> 标签: JavaScript

## 简介

Builder6 OIDC Provider 模块为 Builder6 平台提供 OpenID Connect (OIDC) 身份提供者（Identity Provider, IdP）功能，允许 Builder6 作为认证服务器为其他应用提供单点登录（SSO）服务。
