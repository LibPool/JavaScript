# @builder6/docs

> 标签: JavaScript

## 简介

Builder6 Docs 模块是一个完整的文档管理和在线编辑系统，集成了 OnlyOffice 编辑器、实时协作、文档版本管理和权限控制等功能。该模块为 Builder6 平台提供企业级的文档管理解决方案。
