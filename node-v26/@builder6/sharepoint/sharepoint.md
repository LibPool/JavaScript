# @builder6/sharepoint

> 标签: JavaScript

## 简介

Builder6 SharePoint 模块为 Builder6 平台提供文档处理和 Microsoft 365 集成能力，支持 Word 文档与 XML 互转、AI 文档审阅以及 SharePoint Online/OneDrive 集成。
