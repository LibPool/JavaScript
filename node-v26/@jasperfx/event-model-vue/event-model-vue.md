# @jasperfx/event-model-vue

> 标签: JavaScript

## 简介

Vue renderer for a JasperFx.Events EventModelDescriptor. Lives beside the descriptor it draws, so every viewer — Stoat's design-time canvas, CritterWatch's runtime canvas — renders one descriptor the same way.
