# @tinypoly/cpu-renderer

> 标签: cpu, global-illumination, glsl, node, rasterizer, renderer, software-rendering, three, threejs, web-worker

## 简介

Software renderer for Three.js scenes: a multi-worker CPU rasterizer with a GLSL interpreter, BVH shadows, diffuse global illumination and denoising.
