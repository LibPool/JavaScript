# @getparallel/parx

> 标签: agent, ai, automation, cli, coding-agent, developer-tools, getparallel, parallel, parx, terminal

## 简介

parx: the coding agent of Parallel in your terminal. Reads and edits your project, runs commands and tests, and does coding tasks end to end. Mac, Windows and Linux.

## 官网

- 官网：https://getparallel.net/docs/apps/parx
