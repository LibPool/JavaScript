# @stackpro/ngx-smart-query-builder

> 标签: angular, builder, query

## 简介

A modernized Angular 4+ query builder based on jQuery QueryBuilder. Support for heavy customization with Angular components and provides a flexible way to handle custom data types along with search for columns availability.
