# @pepperui/css

> 标签: components, css, design-system, mobupps, pepper-ui

## 简介

Pepper UI components as framework-free CSS — the Mobupps design system for Paggy, the site's Blade and prototype pages and the quarter builder (DL-7). Every class is built on @pepperui/tokens; no literal colour anywhere (item 2.2.4, stylelint).
