# @basaltkit/storage-azure

> 标签: azure, basalt, blob, storage, typescript

## 简介

Azure Blob Storage driver for @basaltkit/storage — put/get/list/delete/SAS URLs over @azure/storage-blob, with an injectable client for testing.
