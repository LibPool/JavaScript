# @basaltkit/comments-prisma

> 标签: basalt, comments, postgresql, prisma, store, typescript

## 简介

Prisma-backed implementation of the @basaltkit/comments CommentStore — the production reference backend (PostgreSQL/MySQL). Bring your own PrismaClient; ships a reference schema.
