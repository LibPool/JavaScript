# @basaltkit/activity-sqlite

> 标签: activity, basalt, sqlite, store, typescript

## 简介

Durable, SQLite-backed implementation of the @basaltkit/activity ActivityStore (activity feed), on Node's built-in node:sqlite. Zero external dependencies.
