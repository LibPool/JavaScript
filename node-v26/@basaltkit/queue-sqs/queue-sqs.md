# @basaltkit/queue-sqs

> 标签: aws, basalt, queue, sqs, typescript

## 简介

Amazon SQS driver for @basaltkit/queue: native delayed delivery, app-level retries with backoff and a dead-letter queue (no priority — SQS has none).
