# @basaltkit/notifications-sqlite

> 标签: basalt, notifications, sqlite, store, typescript

## 简介

Durable, SQLite-backed implementation of the @basaltkit/notifications InAppStore (in-app notifications), on Node's built-in node:sqlite. Zero external dependencies.
