# @basaltkit/queue-rabbitmq

> 标签: amqp, basalt, queue, rabbitmq, typescript

## 简介

RabbitMQ driver for @basaltkit/queue: AMQP jobs with retries, backoff, delayed delivery and priority via dead-letter queues.
