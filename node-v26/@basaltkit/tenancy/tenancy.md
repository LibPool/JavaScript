# @basaltkit/tenancy

> 标签: basalt, multi-tenancy, multi-tenant, saas, typescript

## 简介

Multi-tenancy for Basalt: pluggable tenant resolvers (subdomain, domain, header, route), tenant context via AsyncLocalStorage and lifecycle hooks.
