# @basaltkit/subscriptions-prisma

> 标签: basalt, billing, postgresql, prisma, store, subscriptions, typescript

## 简介

Prisma-backed implementations of the @basaltkit/subscriptions stores (subscriptions, atomic usage metering, webhook idempotency) — the production reference backend (PostgreSQL/MySQL). Bring your own PrismaClient; ships a reference schema.
