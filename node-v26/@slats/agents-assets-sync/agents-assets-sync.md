# @slats/agents-assets-sync

> 标签: agents, agents-md, assets, claude, claude-code, cli, codex, docs, inject, skills

## 简介

Shared CLI engine that lets consumer packages inject their agent docs (skills, rules, commands) into Claude Code and Codex asset locations via a thin bin/inject-agents-settings wrapper.
