# @itentialopensource/swagger-ui

> 标签: JavaScript

## 简介

This is a fork of https://github.com/swagger-api/swagger-ui which resolves non-dev security vulnerabilities by using `@itentialopensource/remarkable` instead of `remarkable`. These modifications are necessary to resolve upstream security vulnerabilities.
