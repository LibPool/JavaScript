# baconservices-mcp

> 标签: agent-payments, base, image-optimization, mcp, remove-background, usdc, x402

## 简介

MCP server that lets an AI agent buy Bacon Services image operations (remove background, optimize for the web) per call in USDC over x402, with local spending limits.
