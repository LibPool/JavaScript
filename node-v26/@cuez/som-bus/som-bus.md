# @cuez/som-bus

> 标签: broadcast, ibc, kafka, kafkajs, newsroom, som, story-object-model

## 简介

Typed Kafka adapter (over kafkajs) for the Story Object Model (SOM) v0.3 bus: validated publish/subscribe and a staging approve/reject gate.
