# @deadyet/vault

> 标签: aes-256-gcm, dead-mans-switch, deadyet, encryption, offline-decryption, pbkdf2, vault, webcrypto

## 简介

Standalone zero-dependency WebCrypto implementation and offline CLI for the Dead Yet? DY1 encrypted vault format (AES-256-GCM + PBKDF2-HMAC-SHA256).
