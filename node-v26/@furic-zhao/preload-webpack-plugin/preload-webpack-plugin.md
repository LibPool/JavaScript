# @furic-zhao/preload-webpack-plugin

> 标签: html-webpack-plugin, plugin, preload, script, webpack

## 简介

A webpack plugin for injecting <link rel='preload|prefecth'> into HtmlWebpackPlugin pages, with async chunk support
