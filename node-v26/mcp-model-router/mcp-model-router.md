# mcp-model-router

> 标签: eval, litellm, llm, mcp, model-context-protocol, model-routing, openrouter

## 简介

MCP-palvelin, joka valitsee mallin tehtävätyypin mukaan, näyttää LiteLLM/OpenRouter-kulutuksen ja vertailee malleja eval-ajoilla. Täydentää LiteLLM:ää, ei korvaa sitä.
