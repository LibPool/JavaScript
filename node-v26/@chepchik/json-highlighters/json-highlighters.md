# @chepchik/json-highlighters

> 标签: ast, code-editor, contenteditable, json, json-editor, json-viewer, parser, react, react-component, regex, syntax-highlighting, tokenizer

## 简介

Три подхода к живой редактируемой подсветке JSON в React: regex, AST-токенизатор с позициями и AST внутри contentEditable.
