# @chepchik/dom-template

> 标签: abortsignal, component, dom, spa, state, template

## 简介

Tiny mini-component system for the real DOM: mount an HTML string, collect [ref] elements into a typed object, and layer component()/state/composition on top — no Virtual DOM, no diffing, cleanup driven by AbortSignal.
