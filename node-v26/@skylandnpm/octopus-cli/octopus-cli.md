# @skylandnpm/octopus-cli

> 标签: JavaScript

## 简介

Octopus CLI 是一个命令行工具，用于与 Octopus Mission 任务管理系统进行交互。通过 CLI，您可以方便地管理任务、待办事项和附件，支持多账号配置和自动化脚本集成。
