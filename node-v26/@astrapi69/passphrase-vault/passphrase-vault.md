# @astrapi69/passphrase-vault

> 标签: aes-gcm, encryption, passphrase, pbkdf2, vault, webcrypto

## 简介

Passphrase-based authenticated encryption of a small JSON value using WebCrypto only (PBKDF2-HMAC-SHA-256 + AES-GCM-256)
