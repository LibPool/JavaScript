# @currency-formatter/price-formatter

> 标签: currency, currency formatter, format, formatter, price, price formatter

## 简介

A simple, lightweight JavaScript API to format price. Price formatter allows you to format a float value representing price by providing pattern. Pattern example {cCUR }{n-}#{t,}##{t,}###{t,}##{t,}##(t,}###{d.}##
