# @choigawoon/mlua-lsp

> 标签: language-server, lsp, lua, maplestory-worlds, mlua, msw

## 简介

Fast, cross-platform LSP server for mLua (MapleStory Worlds scripting). Persistent TCP daemon with sub-second responses.
