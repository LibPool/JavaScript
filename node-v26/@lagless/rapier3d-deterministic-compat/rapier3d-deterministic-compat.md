# @lagless/rapier3d-deterministic-compat

> 标签: deterministic, dynamics, joints, netcode, physics, real-time, rigid, rollback

## 简介

3-dimensional physics engine - JS bindings with BVH snapshot determinism fix (parry#403). Compatibility package with inlined webassembly as base64.
