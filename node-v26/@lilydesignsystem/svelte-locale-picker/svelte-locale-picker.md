# @lilydesignsystem/svelte-locale-picker

> 标签: design, lily, locale, picker, svelte, system

## 简介

Lily Design System Svelte 5 locale picker: an icon button opening an APG listbox that sets lang and dir on the document. Headless, SSR-safe, no CSS.
