# @lilydesignsystem/vue-link-picker

> 标签: design, home, lily, link, navigation, picker, system, vue

## 简介

Lily Design System Vue 3 link picker: an icon button (a home icon) opening a disclosure of app-defined page links. Headless, SSR-safe, no CSS.
