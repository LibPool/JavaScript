# @lilydesignsystem/angular-data-grid

> 标签: angular, data, design, grid, headless, lily, system, table

## 简介

Lily Design System Angular interactive data grid composing the headless DataTable family: sort, filter, selection, pagination, resize, reorder, cell editing, virtualization, export to CSV, TSV and Excel, and twelve cell types. Headless, SSR-safe, no CSS.
