# @lilydesignsystem/vue-filter

> 标签: design, filter, lily, mongodb, odata, query-builder, sql, system, vue

## 简介

Lily Design System Vue 3 filter: a headless filter builder (conditions and groups over text, number, date, choice and yes/no fields; and / or / not) that outputs JSON, SQL, MongoDB, OData or a predicate. Headless, SSR-safe, no CSS.
