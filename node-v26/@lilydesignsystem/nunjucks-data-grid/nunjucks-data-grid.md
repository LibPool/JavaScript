# @lilydesignsystem/nunjucks-data-grid

> 标签: data, design, grid, lily, nunjucks, system

## 简介

Lily Design System Nunjucks data grid: sort, filter, selection, pagination, editing, virtualization, export and twelve cell types. Headless, SSR skeleton, no CSS.
