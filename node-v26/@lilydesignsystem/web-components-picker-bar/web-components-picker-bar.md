> 标签: design, html, lily, locale, picker, picker-bar, share, system, text-size, theme

## 简介

Lily Design System - HTML custom element picker bar: composes lily-theme-picker, lily-locale-picker, lily-text-size-picker, and lily-share-picker into one page-header row.
