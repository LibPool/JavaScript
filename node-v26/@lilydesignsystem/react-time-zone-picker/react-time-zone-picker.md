# @lilydesignsystem/react-time-zone-picker

> 标签: design, lily, picker, react, system, time-zone

## 简介

Lily Design System React time zone picker: an icon button opening an APG listbox that sets data-time-zone on the document. Headless, SSR-safe, no CSS.
