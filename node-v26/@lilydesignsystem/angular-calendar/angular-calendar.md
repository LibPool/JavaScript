# @lilydesignsystem/angular-calendar

> 标签: angular, calendar, design, grid, lily, system

## 简介

Lily Design System Angular 20 calendar: a week, four-week and month calendar composing the headless CalendarTable family plus the sibling date-time-picker's civil-date arithmetic. Headless, SSR-safe, no CSS.
