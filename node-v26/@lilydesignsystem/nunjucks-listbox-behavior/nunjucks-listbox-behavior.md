# @lilydesignsystem/nunjucks-listbox-behavior

> 标签: aria, design, keyboard, lily, listbox, nunjucks, system

## 简介

Lily Design System Nunjucks shared listbox keyboard behaviour: the WAI-ARIA APG active-descendant contract (clamp, typeahead, paging) factored out of the theme/locale/text-size/motion picker client.js files. Behaviour only, no markup, no CSS.
