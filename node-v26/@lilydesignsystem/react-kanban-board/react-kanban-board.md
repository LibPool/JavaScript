# @lilydesignsystem/react-kanban-board

> 标签: board, design, grid, kanban, lily, react, system

## 简介

Lily Design System React kanban board: composes the headless KanbanTable family plus IconButton/Listbox for a keyboard-accessible per-card move menu. Headless, SSR-safe, no CSS.
