# @lilydesignsystem/angular-kanban-board

> 标签: angular, board, design, grid, kanban, lily, system

## 简介

Lily Design System Angular 20 kanban board: composes the headless KanbanTable grid with an IconButton/Listbox per-card move menu. Headless, SSR-safe, no CSS.
