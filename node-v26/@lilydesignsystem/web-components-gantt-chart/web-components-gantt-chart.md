# @lilydesignsystem/web-components-gantt-chart

> 标签: chart, design, gantt, grid, html, lily, system, timeline

## 简介

Lily Design System - HTML custom element Gantt chart: composes the headless <lily-gantt-table> plus <lily-date-time-picker> (twice, start/end) for keyboard-accessible task rescheduling. Headless, SSR-safe, no CSS.
