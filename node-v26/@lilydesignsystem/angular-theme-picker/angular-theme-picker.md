# @lilydesignsystem/angular-theme-picker

> 标签: angular, design, lily, picker, system, theme

## 简介

Lily Design System Angular 20 theme picker: an icon button opening an APG listbox that swaps a theme stylesheet and sets data-theme. Headless, SSR-safe, no CSS.
