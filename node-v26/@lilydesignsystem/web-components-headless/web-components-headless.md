# @lilydesignsystem/web-components-headless

> 标签: a11y, accessibility, aria, custom-elements, design, headless, lily, system, wcag, web-components

## 简介

Lily Design System headless components as native autonomous custom elements (Web Components). Partial catalog (30 of 491, plan P7-T6) proving the pattern: light DOM, zero CSS, WCAG 2.2 AAA target.
