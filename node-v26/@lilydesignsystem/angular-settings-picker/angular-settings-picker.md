# @lilydesignsystem/angular-settings-picker

> 标签: angular, cog, design, dropdown, lily, menu, picker, system

## 简介

Lily Design System Angular settings picker: an icon button (a cog icon) opening a dropdown of whatever the app provides. Headless, SSR-safe, no CSS.
