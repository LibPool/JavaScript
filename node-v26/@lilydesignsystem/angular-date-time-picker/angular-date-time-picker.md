# @lilydesignsystem/angular-date-time-picker

> 标签: angular, date, design, lily, picker, system, time

## 简介

Lily Design System Angular 20 date and time picker: a typeable text field paired with an APG date-picker dialog. Headless, SSR-safe, no CSS.
