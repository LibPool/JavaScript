# @lilydesignsystem/nunjucks-search-picker

> 标签: design, lily, nunjucks, picker, search, system

## 简介

Lily Design System Nunjucks search picker: a magnifying-glass icon button opening a search field with a ⏎ submit button that navigates to /?<query>. Headless, SSR-safe, no CSS.
