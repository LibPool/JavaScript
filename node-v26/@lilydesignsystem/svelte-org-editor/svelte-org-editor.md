# @lilydesignsystem/svelte-org-editor

> 标签: design, emacs, lily, org, org-mode, svelte, system, textarea, toolbar

## 简介

Lily Design System Svelte 5 Org editor: a textarea with a toolbar of buttons for Emacs Org mode text effects, tasks, priorities, planning, properties, drawers and contacts. Headless, SSR-safe, no CSS.
