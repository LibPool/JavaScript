# @lilydesignsystem/react-search-picker

> 标签: design, lily, picker, react, search, system

## 简介

Lily Design System React search picker: a magnifying-glass icon button opening a search field with a ⏎ submit button that navigates to /?<query>. Headless, SSR-safe, no CSS.
