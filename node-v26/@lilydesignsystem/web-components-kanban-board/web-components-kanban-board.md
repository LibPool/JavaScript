# @lilydesignsystem/web-components-kanban-board

> 标签: board, design, grid, html, kanban, lily, system

## 简介

Lily Design System - HTML custom element kanban board: composes the headless <lily-kanban-table> plus <lily-icon-button> for a keyboard-accessible per-card move menu. Headless, SSR-safe, no CSS.
