# @lilydesignsystem/vue-markdown-editor

> 标签: design, editor, lily, markdown, system, textarea, toolbar, vue

## 简介

Lily Design System Vue Markdown editor: a textarea with a toolbar of rich-text buttons (bold, italic, link, headings, lists, quote, code) that write Markdown. Headless, SSR-safe, no CSS.
