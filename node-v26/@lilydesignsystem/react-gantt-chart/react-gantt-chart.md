# @lilydesignsystem/react-gantt-chart

> 标签: chart, design, gantt, grid, lily, react, schedule, system

## 简介

Lily Design System React Gantt chart: composes the headless GanttTable family plus two composed date-time-picker instances for keyboard-accessible task editing. Headless, SSR-safe, no CSS.
