# @lilydesignsystem/angular-gantt-chart

> 标签: angular, chart, design, gantt, grid, lily, schedule, system

## 简介

Lily Design System Angular 20 Gantt chart: composes the headless GanttTable grid with two composed date-time-picker instances for keyboard-accessible date editing. Headless, SSR-safe, no CSS.
