# @lilydesignsystem/angular-motion-picker

> 标签: angular, design, lily, motion, picker, reduced-motion, system

## 简介

Lily Design System Angular 20 motion (reduced-motion) picker: an icon button opening an APG listbox that sets data-motion on the document, defaulting to the OS's own prefers-reduced-motion signal. Headless, SSR-safe, no CSS.
