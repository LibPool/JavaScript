# @lilydesignsystem/nunjucks-kanban-board

> 标签: board, design, grid, kanban, lily, nunjucks, system

## 简介

Lily Design System Nunjucks kanban board: a keyboard-and-pointer-accessible kanban board (WAI-ARIA APG Grid, per-card move menu, drag-and-drop supplementary). Headless, SSR-safe, no CSS.
