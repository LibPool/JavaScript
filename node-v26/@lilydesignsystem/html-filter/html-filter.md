# @lilydesignsystem/html-filter

> 标签: custom-element, design, filter, html, lily, mongodb, odata, query-builder, sql, system

## 简介

Lily Design System HTML filter: a <filter-builder> custom element, a headless filter builder (conditions and groups over text, number, date, choice and yes/no fields; and / or / not) that outputs JSON, SQL, MongoDB, OData or a predicate. No CSS.
