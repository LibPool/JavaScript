# @urlpipe/sdk

> 标签: api-client, headless-chrome, html, lighthouse, markdown, metadata, scrape, screenshot, urlpipe

## 简介

Official JavaScript and TypeScript client for the URLpipe API: turn any URL into Markdown, HTML, a screenshot, metadata, a summary and more.
