# @roundhouseai/x402

> 标签: agent, base, cli, eip-3009, http-402, mcp, ows, payments, usdc, x402

## 简介

One command for the whole x402 payment loop. Request, 402, sign via OWS, retry, receipt — with spend limits and a local ledger.
