# @vymalo/opencode-devtools

> 标签: ai-sdk, base64, cron, crypto, csv, datetime, http, jwt, math, opencode, opencode-plugin, utilities, yaml

## 简介

OpenCode plugin of everyday developer utilities the model can call locally: math (precise arithmetic, unit & base conversion, stats), codec (base64/hex/url, JWT decode, gzip), crypto (hash/hmac, uuid/ulid, random, keypairs), datetime (parse/format/diff, t
