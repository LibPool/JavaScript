# @vymalo/opencode-lightbridge

> 标签: gateway, oauth2, observability, opencode, opencode-plugin, opentelemetry, otel, otlp, project, token-exchange

## 简介

Umbrella OpenCode plugin for ADR-0012: one shared credential (TokenRuntime) drives both the LLM gateway bearer and OTEL export, so a developer authenticates once and every egress rides the same project-scoped token.
