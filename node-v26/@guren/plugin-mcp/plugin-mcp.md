# @guren/plugin-mcp

> 标签: ai-agents, bun, framework, fullstack, guren, mcp, model-context-protocol, typescript

## 简介

Production MCP endpoint for Guren applications: serves the agent tools derived from routes that declare .agent() over the Model Context Protocol, with rate limiting.
