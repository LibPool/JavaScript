# @guren/cli

> 标签: ai-agents, bun, claude-code, cli, codegen, framework, fullstack, guren, scaffold, typescript

## 简介

CLI for the Guren framework: scaffolding (make:*, add), migrations, codegen, and the check, audit and gate commands a coding agent runs to verify its work.
