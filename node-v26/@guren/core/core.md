# @guren/core

> 标签: ai-agents, bun, bun-framework, drizzle, framework, fullstack, guren, hono, inertia, laravel, mvc, react, typescript

## 简介

Guren: the Bun-first fullstack TypeScript framework. Laravel-style MVC on Hono, Drizzle ORM and Inertia.js + React. Develop on Bun; deploy to Bun, AWS Lambda (Node.js), Vercel or Cloudflare Workers.
