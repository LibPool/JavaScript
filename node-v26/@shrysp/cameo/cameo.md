# @shrysp/cameo

> 标签: agent, ai, animation, assistant, avatar, cameo, character, expressive, react

## 简介

Cameo: an expressive little device character for AI interfaces: it blinks, follows the cursor, listens, thinks and speaks. Framework-free engine with a React component.
