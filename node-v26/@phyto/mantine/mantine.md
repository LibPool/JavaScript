# @phyto/mantine

> 标签: adapter, e2e, mantine, phyto, testing

## 简介

Phyto translation layer for Mantine — namespaced sub-driver (driver.mantine.*) for library-specific verbs like waitForNotification. ARIA-standardized interactions are owned by phyto's built-in DOM adapter.
