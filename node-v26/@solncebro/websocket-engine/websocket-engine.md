# @solncebro/websocket-engine

> 标签: browser, heartbeat, node, react-native, reconnect, relay, typescript, websocket

## 简介

Reliable WebSocket client with reconnect, heartbeat and typed messages, and a reusable signal relay (server + client) under ./relay
