# @rtorcato/supabase-common

> 标签: esm, postgrest, ssr, supabase, tree-shakeable, typescript

## 简介

Tree-shakeable TypeScript helpers for Supabase: a dependency-free structural core plus framework-agnostic client factories behind an optional @supabase/ssr peer.
