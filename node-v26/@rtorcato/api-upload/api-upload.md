# @rtorcato/api-upload

> 标签: api, aws, express, multer, multer-s3, nodejs, s3, typescript, upload

## 简介

Promise-based S3 file upload for Express via multer-s3 — public/private ACL, cache-control, deterministic keys, typed errors.
