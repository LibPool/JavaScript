# @mcp-com-ai/shared-utils

> 标签: JavaScript

## 简介

Shared HAPI utilities: HAPI_HOME resolution, logger, config loader, errors, runtime detection, secrets. Consumed by the CLI, the core engine, and all first-party plugins.
