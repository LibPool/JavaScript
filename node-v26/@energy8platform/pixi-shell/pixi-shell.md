# @energy8platform/pixi-shell

> 标签: casino, energy8, game-shell, igaming, pixijs

## 简介

PixiJS rendering of the Energy8 branded game shell — a 1:1 port of the renderer-agnostic DOM shell (control bar, menu, settings, game info, buy bonus) drawn entirely in Pixi v8.
