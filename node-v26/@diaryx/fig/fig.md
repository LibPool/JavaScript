# @diaryx/fig

> 标签: comment-preserving, config, cross-format, frontmatter, json, json5, jsonc, parser, toml, wasm, webassembly, yaml, zon

## 简介

JSON, JSONC, JSON5, YAML, TOML, INI, dotenv, .properties, NestedText, ZON, plist and fig parsing, comment-preserving editing, and cross-format serialization: a Rust core compiled to WebAssembly, with each format a WebAssembly module of its own, a package
