# @jordyvanvorselen/pi-bare-worktrees

> 标签: bare, coding-agent, extension, git, pi, pi-package, worktree

## 简介

Git worktrees for --bare checkouts in pi: one worktree per task, shared env links, protected branches, and a worktree tool the agent uses itself.
