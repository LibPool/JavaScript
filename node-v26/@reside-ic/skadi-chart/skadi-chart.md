# @reside-ic/skadi-chart

> 标签: JavaScript

## 简介

This charting library provides a structured and thin wrapper around [d3](https://d3js.org) to provide an fully flexible and extensible interface to plot customised graphs that out-of-the-box solutions haven't prepared for.
