# @dui-toolkit/plugin-diff

> 标签: ansi, cli, diff, side-by-side, terminal, unified-diff

## 简介

Diff viewer for @bdocs/dui — render unified and side-by-side diffs with syntax-colored additions, deletions, and context in the terminal.
