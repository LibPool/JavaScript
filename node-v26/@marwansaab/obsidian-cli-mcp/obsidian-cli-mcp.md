# @marwansaab/obsidian-cli-mcp

> 标签: JavaScript

## 简介

Cross-platform MCP server bridging MCP clients to the Obsidian Integrated CLI binary on macOS, Linux, and Windows hosts. Typed tools: append_note, backlinks, context_search, delete, files, find_and_replace, find_by_property, links, move, obsidian_exec, op
