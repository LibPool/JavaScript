# @ashlr/lexicon

> 标签: claude-code, dictation, lexicon, mcp, speech-to-text, vocabulary, voice

## 简介

Personal lexicon for voice-to-agents. Fixes the words STT gets wrong (Ashler -> Ashlr.AI) before your agent sees the prompt.
