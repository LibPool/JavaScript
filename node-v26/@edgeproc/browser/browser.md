# @edgeproc/browser

> 标签: browser, content-addressed, ed25519, integrity, local-first, offline-first, opfs, signed-bundle, typescript, web-worker, zstd

## 简介

For web developers: load data into a browser tab only if it's provably yours and unaltered, then keep using it offline.
