# @deident/core

> 标签: de-identification, fhir, gdpr, healthcare, hipaa, ner, phi, pii, presidio, privacy, redaction, transformers.js

## 简介

Framework-agnostic, client-side PII/PHI de-identification engine: deterministic detectors + contextual NER, stable placeholders, in-memory vault, and rehydration for safe cloud-LLM round-trips. FHIR / HL7 v2 / C-CDA aware.
