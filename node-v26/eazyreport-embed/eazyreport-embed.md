# eazyreport-embed

> 标签: designer, eazyreport, embed, iframe, invoice, report, report-designer, template-editor

## 简介

Embed the EazyReport Visual Designer inside your own web app via a secure, domain-locked iframe. Load a template, let users edit it in place, and save back to your backend.
