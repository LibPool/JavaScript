# @moorage/plugin-analytics

> 标签: analytics, cms, consent-mode, cookie-banner, cookie-consent, emdash, emdash-cms, emdash-plugin, facebook-pixel, ga4, gdpr, google-analytics, google-tag-manager, gtm, hubspot, meta-pixel, microsoft-clarity

## 简介

Google Analytics, Google Tag Manager, Meta Pixel and Clarity for EmDash, with a cookie consent banner that holds them back until the visitor agrees.
