# dsh-realtime-audio-ws

> 标签: audio, cordis, deepseek-harness, dsh, dsh-plugin, realtime, voice, websocket

## 简介

The host end of the client half's transport: a WebSocket upgrade route that bridges microphone audio in and agent speech out.
