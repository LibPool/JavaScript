# @e-sig/hsm-pkcs11

> 标签: cloudhsm, cryptoki, esign, esignature, hsm, pades, pdf, pkcs11, pkcs7, self-contained, softhsm, yubihsm

## 简介

PKCS#11 HSM adapter for @e-sig/core — keep the RSA signing key inside AWS CloudHSM, YubiHSM 2, SoftHSM2, or any Cryptoki token via the ExternalSigner seam; the private key never enters process memory.
