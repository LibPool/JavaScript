# @asksoma/location

> 标签: JavaScript

## 简介

AskSoma location stack — city geocode (Open-Meteo → Nominatim → Photon), Google Maps link parse, IANA/TZ helpers, GPS detect, and React LocationSearch (Leaflet). No Google Places API key.
