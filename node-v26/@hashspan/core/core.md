# @hashspan/core

> 标签: ai-agents, blockchain, evm, observability, opentelemetry, otel, payments, tracing, transactions

## 简介

OpenTelemetry transaction tracker behind the hashspan adapters: a send and a confirm span for each transaction an AI agent or service sends.
