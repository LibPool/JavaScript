# docling-serve-client

> 标签: docling, docling-document, docling-serve, markdown, pdf, pdf-to-markdown

## 简介

Typed docling-serve client: PDF to docling Markdown or DoclingDocument JSON, sync and async. In-memory, zero-dependency, never throws.
