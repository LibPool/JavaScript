# @elo-ads/web-sdk

> 标签: JavaScript

## 简介

The Elo web SDK for rendering in-chat, conversation-aware ads in React apps. It fetches an ad for the current conversation, renders it natively in the format the server chose for your slot, and handles render + viewable-impression tracking for you.
