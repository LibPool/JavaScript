# @jsxiaosi/eslint-config

> 标签: eslint-config

## 简介

基于 ESLint Flat Config 的共享配置。默认包含 JavaScript、TypeScript、JSON、YAML、TOML 和 Markdown 规则，可按需开启 Vue、React 和 Prettier 支持。
