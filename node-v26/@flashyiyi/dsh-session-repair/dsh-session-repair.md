# @flashyiyi/dsh-session-repair

> 标签: deepseek-harness, dsh, dsh-plugin, ignorable, jsonl, session, session-repair, zstd

## 简介

DSH session log repair: scans zstd session logs for event types the host does not know and marks them ignorable with a compliant frame rewrite (backup included). Skips archived sessions by default, caches per-file verdicts, and is read-only in scan mode.
