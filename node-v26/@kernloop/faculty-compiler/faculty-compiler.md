# @kernloop/faculty-compiler

> 标签: JavaScript

## 简介

Kernloop Layer 2 — the context compiler faculty (spec §5.1). Deterministically assembles a Brief from a TaskContract plus caller-supplied source material, under hard token budgets with priority-ordered drop and mandatory provenance. Pure function: no file
