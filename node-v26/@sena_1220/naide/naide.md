# @sena_1220/naide

> 标签: ai, chatgpt, claude, code-generation, dsl, language, llm, naide, nodejs, transpiler

## 简介

NAIDE - Node AI Development Environment. A language optimized for AI code generation that transpiles to Node.js. Standard mode (~40% fewer tokens) and X mode (~80% fewer tokens).
