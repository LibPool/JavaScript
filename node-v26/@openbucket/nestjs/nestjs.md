# @openbucket/nestjs

> 标签: aws-s3, bucket, file-upload, minio, minio-alternative, nestjs, nestjs-module, object-storage, object-store, presigned-url, s3, s3-compatible, s3-server, self-hosted, storage

## 简介

Self-hosted, S3-compatible object store for NestJS: S3 API, presigned file uploads & an admin console you embed in your app or run standalone — a lightweight MinIO alternative.
