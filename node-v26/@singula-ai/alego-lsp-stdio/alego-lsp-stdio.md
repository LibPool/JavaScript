# @singula-ai/alego-lsp-stdio

> 标签: JavaScript

## 简介

Generic stdio language-server provider for the Alego LSP capability seam (ctx.lsp) — spawns configured servers, translates JSON-RPC, and serves transient-open goToDefinition/findReferences/goToImplementation/hover queries in the host filesystem namespace
