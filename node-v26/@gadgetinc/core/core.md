# @gadgetinc/core

> 标签: JavaScript

## 简介

This package contains core types and interfaces that all Gadget client implementations must conform to. `@gadgetinc/core` defines the contracts for API clients, connections, model managers, records, and operations that are shared across all generated Gadg
