# @nodari-pruidze/form-builder-js

> 标签: form, form-builder, json-schema, multi-step, nextjs, react, react-hook-form, tailwindcss, wizard, zod

## 简介

JSON-driven React forms with Zod validation, conditional fields, multi-step wizards or one-page sections, file uploads, repeating groups and server-side re-validation. Styled with Tailwind CSS v4.
