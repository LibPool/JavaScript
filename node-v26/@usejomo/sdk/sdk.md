# @usejomo/sdk

> 标签: agents, arbitrum, erc-5564, privacy, robinhood-chain, stealth-address, viem

## 简介

The privacy layer for Robinhood Chain: private transactions for ETH and any token, from any app or agent. ERC-5564 stealth addresses, encrypted memos, scanning and stealth spending.
