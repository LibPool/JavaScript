# @vocweb/opencode-advisor

> 标签: advisor, agent, code-review, opencode, opencode-plugin, watchdog

## 简介

A live advisor for opencode: a second model that watches your session and sends advice while the agent is still working. A port of oh-my-pi's advisor.
