# @hive-mind/cli

> 标签: ai, cli, harvest, hive-mind, memory, wiki-compiler

## 简介

Command-line tools for hive-mind: recall, save, harvest, compile-wiki, maintenance. Designed to run from SessionStart/Stop hooks and nightly cron.
