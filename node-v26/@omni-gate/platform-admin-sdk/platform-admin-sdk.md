# @omni-gate/platform-admin-sdk

> 标签: desktop, native-bridge, omnigate, sdk, tauri, typescript

## 简介

Browser-side SDK for web apps loaded by omni-platform-desktop's embedded HTTP server: detects whether the page is running inside the OmniGate desktop app (Tauri) or a plain browser, and provides a generic, Android-JavascriptInterface-style bridge for call
