# @craftedstudios/shaders

> 标签: avatar, avatars, border, button, cursor, gradient, multiplayer, outline, react, shader, shaders, web-component, webgl

## 简介

Live shaders for product UI: avatars from any name, email or user ID, presence cursors, and outlines for buttons and cards. One WebGL context for the whole page, a PNG export and a React entry.
