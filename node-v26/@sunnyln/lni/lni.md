# @sunnyln/lni

> 标签: bitcoin, lightning, lnurl, nwc, typescript

## 简介

Lightning Node Interface. Connect to CLN, LND, Phoenixd, NWC, Strike, Speed and Blink. Supports BOLT11, BOLT12, LNURL and Lightning Address.
