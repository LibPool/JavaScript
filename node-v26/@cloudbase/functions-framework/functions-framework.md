# @cloudbase/functions-framework

> 标签: JavaScript

## 简介

一个基于 `Koa` 托管 Node.js 云函数的框架，使用该框架可以将函数部署至容器环境中，或在本地调试。Node.js 最小依赖版本 `>=18.0.0`。
