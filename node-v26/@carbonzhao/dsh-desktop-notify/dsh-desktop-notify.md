# @carbonzhao/dsh-desktop-notify

> 标签: deepseek-harness, desktop-notification, dsh, dsh-plugin, notifications, toast, windows

## 简介

DSH 桌面通知：所有 DSH 前端失焦时，对决策/授权/意外中断/任务完成发 Windows 通知（标题=会话标题，点击复用已有页面切回对话）
