# @rcs-surveys/agent-toolkit

> 标签: agent, cli, mcp, rcs, surveys

## 简介

RCS Surveys-branded agent skins for the RCS Surveys gateway: an MCP server (rcs-surveys-mcp) and a CLI (rcs-surveys). A thin alias over @rcs-campaigns/agent-toolkit — same gateway, same tool catalog.
