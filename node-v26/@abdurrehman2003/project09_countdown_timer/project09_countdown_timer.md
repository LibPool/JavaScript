# @abdurrehman2003/project09_countdown_timer

> 标签: JavaScript

## 简介

This TypeScript-based countdown timer app lets users set a countdown in minutes via Inquirer. It displays the remaining time in real-time, updating every second, and notifies the user when the time is up.
