# xenocept-plugin-aeor-gemini

> 标签: gemini, google-ai, ocr, plugin, vision, xenocept, xenocept-plugin

## 简介

Xenocept plugin for Google Gemini — OCR (extracts on-screen text and an AI-generated scene description from session screenshots) plus an MCP-stdio bridge for use from Gemini CLI's plugin/MCP config. Requires a Google AI Studio API key for OCR.
