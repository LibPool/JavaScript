# xrkh-better-sidebar-plugin-office

> 标签: xrkh-better-sidebar, xrkh-plugin

## 简介

XRKH web plugin: Office file previewers (.docx/.xlsx/.pptx) for xrkh-better-sidebar. Registers docx/xlsx/pptx viewers through ctx.betterSidebar.registerFileViewer (docx-preview / Univer / SheetJS / pptx-renderer).
