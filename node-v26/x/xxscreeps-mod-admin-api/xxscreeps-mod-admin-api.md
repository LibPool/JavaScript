# xxscreeps-mod-admin-api

> 标签: admin, screeps, screepsmod, xxscreeps

## 简介

Administrative HTTP API for xxscreeps: game control, terrain editing, structure placement, and read-only store/user inspection, served under /admin behind a shared-secret token.
