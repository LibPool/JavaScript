# xc-createdoc

> 标签: JavaScript

## 简介

- 使用之前需要安装node，npm - 进入项目根目录命令行输入node document.config.js 创建目录及初始化文件 - 命令行输入可接受参数例如 node document.config.js project。project为项目名称
