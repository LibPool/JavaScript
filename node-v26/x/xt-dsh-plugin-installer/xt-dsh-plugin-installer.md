# xt-dsh-plugin-installer

> 标签: cli, deepseek-harness, dsh, plugin-installer, skillhub

## 简介

动态安装 DeepSeek Harness 注册中心（skillhub）上的插件：install-all 一键安装全部，install <coordinate> 按唯一标识安装单个（支持 skill/harness/plugin 包），执行时请求后端接口查询已发布插件清单并生成安装命令，再逐个下载安装。
