# xotp

> 标签: 2fa, authenticator, google-authenticator, hotp, multi-factor authentication, one-time password, otp, otp generator, time-based one-time password, totp, two-factor authentication, two-step authentication

## 简介

One-Time Password (HOTP/TOTP) library for Node.js, Deno and Bun, with support for Google Authenticator.
