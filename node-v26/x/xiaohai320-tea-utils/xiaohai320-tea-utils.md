# xiaohai320-tea-utils

> 标签: JavaScript

## 简介

`xiaohai320-tea-utills` 是一个轻量级的HTTP客户端库，提供了对GET、POST、PUT、DELETE等HTTP方法的支持，并包含请求重试和超时设置等功能。
