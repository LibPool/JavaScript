# x12i-downloads

> 标签: JavaScript

## 简介

A React dashboard that discovers every public package in the `@x12i` npm scope and calculates cumulative downloads since April 1, 2026.

## 官网

- npm 页面：https://www.npmjs.com/package/x12i-downloads

## 历史版本号

- 当前版本：0.1.1

- 0.1.1

## 获取地址

- npm 安装：`npm install x12i-downloads`
- npm registry：https://registry.npmjs.org/x12i-downloads
- Node 要求：>=22.13.0
