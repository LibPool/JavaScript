# xhr.js

> 标签: XMLHttpRequest, ajax, client-side, http.js, request, requests, restful, xhr

## 简介

xhr.js is a library(<2Kb) to make AJAX/HTTP restful requests from client-side JavaScript with XMLHttpRequest.
