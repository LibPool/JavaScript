# xingweb

> 标签: typescript

## 简介

* 内置通用数据库连接，避免常见的数据库初始和引用的循环依赖错误问题 * 满足快速启动项目需要数据库的业务需求 * 统一路由入口的开发模式（按经验更好理解和管理） * 也可自定义路由
