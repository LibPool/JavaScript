# xlsx-relaxed-parsing-rows

> 标签: JavaScript

## 简介

A fork of sheetjs's js-xlsx but with slightly relaxed parsing rules to read corrupt xlsx files, including accounting for blank rows

- npm 页面：https://www.npmjs.com/package/xlsx-relaxed-parsing-rows
