# xron-mcp

> 标签: JavaScript

## 简介

A lightweight MCP middleware that wraps any existing MCP server and automatically compresses JSON tool responses using XRON before they reach the LLM. This reduces token consumption by 60-80% for data-heavy tool outputs like BigQuery queries or Google Ads
