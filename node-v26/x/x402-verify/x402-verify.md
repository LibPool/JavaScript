# x402-verify

> 标签: agent-payments, bounded-verification, conformance, did-web, ed25519, eddsa, evidence, jws, offers, opentimestamps, payments, receipts, usdc, verification, x402

## 简介

Zero-dependency verifier for x402 Signed Offers & Receipts: compact JWS (EdDSA/Ed25519), did:web resolution, local revision-1 schema checks, explicit result statuses, and optional anchored key history.
