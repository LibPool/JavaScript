# x402-anychain

> 标签: eip-3009, evm, facilitator, payments, permit2, usdg, x402, yield

## 简介

Self-hosted x402 facilitator for ANY EVM chain. Add a chain by adding an RPC. First-class support for yield-bearing (NAV-up) settlement assets.
