# xmediajs

> 标签: getUserMeida组件, h5大头照拍摄, h5录音, h5拍照, h5证件拍摄

## 简介

基于HTML5的getUserMedia API的实现的拍照js库，支持添加引导框并自动裁剪，支持扫描抓拍效果，支持图片压缩和旋转，同时支持降级使用input file进行拍摄。
