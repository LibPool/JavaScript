# xmldefuse

> 标签: CDATA, CLI, HTML, XML, apos, cdata, cli, defuse, encode, entities, entity, html, htmlspecialchars, xml, xmlencode, xmlentities

## 简介

Encode the predefined XML entities (amp, lt, gt, apos, quot). Opt-out CharRef 39 for HTML. Bonus: Encode CDATA.
