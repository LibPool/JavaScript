# xshellz

> 标签: agents, code-execution, gvisor, sandbox, ssh, vm, xshellz

## 简介

Official TypeScript/Node SDK for xShellz sandboxes — spawn throwaway, gVisor-isolated Linux boxes and run commands in them.
