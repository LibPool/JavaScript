# xaq-cli

> 标签: agents, ai, email, gmail, mcp, self-hosted, webhooks

## 简介

Self-hosted Gmail broker for AI agents (formerly agentinbox): one place for credentials, MCP tools, real-time webhooks, guardrails, and a web console.
