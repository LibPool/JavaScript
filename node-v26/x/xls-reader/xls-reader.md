# xls-reader

> 标签: biff, biff8, browser, cfb, excel, excel-reader, legacy-excel, node, ole2, parser, read-excel, read-xls, sheetjs-alternative, spreadsheet, spreadsheet-parser, typescript, xlrd, xls, xls-parser, xls-reader, xls-to-json, zero-dependency

## 简介

Zero-dependency .xls (BIFF8 / Excel 97-2003) reader for Node and the browser — a lightweight SheetJS alternative that returns each worksheet as typed cells.
