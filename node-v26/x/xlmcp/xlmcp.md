# xlmcp

> 标签: automation, claude, com, excel, mcp, model-context-protocol, powershell, spreadsheet

## 简介

Excel automation MCP server via PowerShell COM. 48 tools — session pooling, chunked parallel I/O, virtual clipboard. Windows only.
