# xiaoyibao-clinical-trials

> 标签: ai, api, clinical-trials, clinicaltrials-gov, healthcare, llm, mcp, medical, model-context-protocol, research

## 简介

MCP server developed by xiao-x-bao for ng clinical trials from ClinicalTrials.gov API v2. Supports searching by keywords, disease, location with intelligent defaults (recruiting trials from past 3 months).
