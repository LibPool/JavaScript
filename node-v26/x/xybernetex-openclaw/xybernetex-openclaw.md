# xybernetex-openclaw

> 标签: agent-safety, ai-agents, control-plane, openclaw, openclaw-plugin, prompt-injection, xybernetex

## 简介

Xybernetex Supervisor for OpenClaw: holds destructive actions nobody asked for, checks the agent's work against acceptance checks (experimental), undoes fixes that break what worked, and stops runaway runs. Runs locally, MIT, no account needed.
