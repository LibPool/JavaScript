# xygo-skills

> 标签: agent-skills, ai, claude, cursor, skills, xygo, xygoadmin

## 简介

Installer for XYGo Admin AI Skills (Agent Skills). Detects your AI editors and installs the XYGo skills into each editor's skills directory.
