# x402-crypto-mcp

> 标签: agent, bitcoin, crypto, ethereum, mcp, price, x402

## 简介

Crypto market data via x402 pay-per-call: prices, convert, candles, indicators, sentiment, yields, gas, tx status, balances, ERC-20, ENS, block height. 23 stdio + 26 HTTP tools.
