# xlh_element

> 标签: JavaScript

## 简介

xlh的 模仿element实现的组件库 实现了如下组件 1. my-alert 2. my-input 3. my-link 4. my-button 5. my-form 6. my-label 7. my-switch 8. my-dialog 9. my-message
