# xhr-fetch-interceptor

> 标签: fetch, interceptor, monkey, tampermonkey, xhr

## 简介

A lightweight JavaScript library for intercepting and modifying XHR and Fetch requests, perfect for browser extensions and Tampermonkey scripts
