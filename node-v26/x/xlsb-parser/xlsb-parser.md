# xlsb-parser

> 标签: binary, browser, excel, excel-binary, parser, spreadsheet, workbook, xlsb, xlsb-parser, xlsx

## 简介

Pure-JS XLSB (Excel Binary Workbook) parser. No native addons. Works in browsers and Node.js 20+.
