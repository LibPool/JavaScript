# xbrowser-plugin-chrome-bridge

> 标签: JavaScript

## 简介

让 xbrowser **直接控制你的 Chrome/Chromium**——浏览器装上 login-bridge 扩展后，xbrowser 经本地 WS 通道下发命令（导航/取值/点击/填充/截图），**无需开 --remote-debugging-port**，登录态就是你浏览器里的真实登录态。
