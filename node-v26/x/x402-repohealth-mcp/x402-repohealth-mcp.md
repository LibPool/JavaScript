# x402-repohealth-mcp

> 标签: abandonment, claude, dependency-risk, github, maintenance, mcp, model-context-protocol, repo-health, x402

## 简介

Free MCP server that computes a GitHub repo maintenance/abandonment health score (0-100) + verdict from live GitHub data. Open twin of the paid x402-gated repohealth HTTP API.
