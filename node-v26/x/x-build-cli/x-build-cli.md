# x-build-cli

> 标签: html5, less, node, sass, scaffolding, stylus, template, webpack

## 简介

X-BUILD一套基于Webpack(v4.21.0)快速搭建H5场景开发环境的脚手架，只需要几分钟的时间就可以运行起来。
