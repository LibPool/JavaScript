# xliffai

> 标签: AI, ChatGPT, Claude, Gemini, Mistral, Ollama, Qwen, XLIFF, Z.ai, cli, localization, machine-translation, translation

## 简介

Translate XLIFF files with AI, batching groups of segments per request and proposing results as <mtc:match> candidates
