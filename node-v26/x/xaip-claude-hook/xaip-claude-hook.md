# xaip-claude-hook

> 标签: ai-agent, claude, claude-code, hook, mcp, reputation, telemetry, trust, xaip

## 简介

Claude Code hook that warns before low-trust MCP calls and emits signed XAIP receipts — turns your normal MCP usage into live trust data.
