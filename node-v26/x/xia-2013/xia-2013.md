# xia-2013

> 标签: JavaScript

## 简介

1.注册npm账号 2.查看是否安装nrm `nrm ls` 3.切换源到npm `nrm use npm` 4.项目初始化 `npm init -y` 5.创建项目说明(不是必备) readme.md 6.创建入口文件 index.js    ① 引入模块   ② 读文件   ③ 写文件   ④ 导出读写模块 7.登录npm `npm adduser`
