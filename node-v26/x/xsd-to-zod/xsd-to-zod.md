# xsd-to-zod

> 标签: code-generation, schema, typescript, validation, xml, xml-parsing, xsd, zod

## 简介

Turn XSD schemas into type-safe Zod parsers for XML, with a metadata-driven runtime for parseXml/serializeXml round-trips.
