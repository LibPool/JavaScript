# @rikaidev/yomi

> 标签: chat, e2ee, line, mcp, messaging, model-context-protocol

## 简介

Open-source personal LINE MCP server for AI agents. Read, reply, send images, and search LINE conversations locally with Letter-Sealing E2EE.
