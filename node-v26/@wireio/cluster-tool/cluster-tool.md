# @wireio/cluster-tool

> 标签: JavaScript

## 简介

Core library and CLI for creating, running, and tearing down multi-chain WIRE test clusters. Ships the `wire-cluster-tool` binary, the declarative orchestration engine (`ClusterBuildPhaseGroup` → `ClusterBuildPhase` → `ClusterBuildStep` → `Report`) shared
