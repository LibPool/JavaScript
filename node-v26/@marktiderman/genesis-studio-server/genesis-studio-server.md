# @marktiderman/genesis-studio-server

> 标签: JavaScript

## 简介

Genesis Data Studio server handler — a web-standard Request → Response handler that reads and edits a Postgres or Supabase database AS the signed-in user: schema discovery with per-user column rights, version-checked edits, and an audit entry in the same
