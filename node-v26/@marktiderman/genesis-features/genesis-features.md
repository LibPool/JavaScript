# @marktiderman/genesis-features

> 标签: JavaScript

## 简介

A typed feature registry: defineFeatures and defineFlags in one code file that running code imports, generators for AGENTS.md and JSON, a stale-output check, and a FeatureList page. Part of the Genesis framework.
