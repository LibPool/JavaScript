# @obinexusltd/obix-component-checkbox

> 标签: accessibility, checkbox, component, dop, form, indeterminate, obix, tristate

## 简介

OBIX ObixCheckbox — a checkbox with a real tri-state (true / false / "mixed"), aria-checked, and disabled-safe actions. Data-Oriented, zero dependencies.
