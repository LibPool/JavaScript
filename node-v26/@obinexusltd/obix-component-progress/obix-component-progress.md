# @obinexusltd/obix-component-progress

> 标签: accessibility, component, dop, feedback, loading, obix, progress, progressbar

## 简介

OBIX ObixProgress — a role="progressbar" with a determinate value / min / max or an indeterminate busy state, plus optional aria-valuetext. Data-Oriented, zero dependencies.
