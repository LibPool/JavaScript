# @obinexusltd/obix-core-streams

> 标签: compatibility, host, obix, obix-core, streams

## 简介

Web Streams + Uint8Array byte boundary with Node adapters: backpressure, streaming UTF-8 decode, abort/error propagation and lock/close ownership.
