# @obinexusltd/obix-component-select

> 标签: accessibility, component, dop, form, listbox, multiselect, obix, optgroup, select

## 简介

OBIX ObixSelect — a native <select> with optgroup support, single or multiple selection, a placeholder option, and an open flag for a custom popup layer. Data-Oriented, zero dependencies.
