# @obinexusltd/obix-core-scheduler

> 标签: compatibility, host, obix, obix-core, scheduler

## 简介

Injected monotonic clock, opaque timer tokens, cancellation/disposal and interval-overrun policy. Bridges the frozen OBIX Timer contract.
