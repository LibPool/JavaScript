# @oprt/tailwind

> 标签: design-system, design-tokens, tailwindcss, tailwindcss-plugin

## 简介

OPERATOR design system plugin for Tailwind CSS 4: token-backed colors, spacing, control sizes, type, motion and container-query utilities. Install it with @oprt/tokens, which defines the custom properties it emits.
