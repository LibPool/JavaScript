# @tarhnama/markdown

> 标签: docx, editor, markdown, outline, persian, prosemirror, rtl

## 简介

Flat outline blocks <-> Markdown, with YAML frontmatter, Obsidian-style ^block-id markers and [[wikilinks]]. Runs in Node with no DOM.
