# @antprofuse/saddle-islands-backend

> 标签: JavaScript

## 简介

基于 Spec、正式physical输入、后端契约、DB、共享外部协议和独立后端测试实现 Saddle 业务后端，维护契约到唯一后端入口的工程脉络。框架技术规则另消费官方 Saddle Skill，不重新设计协议或实现 Java 下游。
