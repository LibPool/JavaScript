# @antprofuse/saddle-profusecontract

> 标签: JavaScript

## 简介

在已明确宿主接入和真实外部合同的前提下，实现 adapt 对应的 ProfuseContract 业务适配组件，消费唯一 external-contract-proto 并验证字段映射。不研发 Saddle 后端、不修改不可控 SOFA 服务、不把组件当完整宿主应用。
