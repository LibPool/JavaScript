# @ploykit/client

> 标签: api-client, ploykit, websocket

## 简介

API + WebSocket 客户端：CSRF/工作区上下文请求层与 wsx 实时客户端（零 react 依赖）。产物为 ESM（相对导入无扩展名，消费方需经 vite/esbuild 等打包器解析）；exports 的 development 条件指向源码，供 monorepo 开发期（vite dev / tsc customConditions / vitest）直出消费。
