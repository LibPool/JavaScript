# @ploykit/ui

> 标签: JavaScript

## 简介

React 前端壳：登录/工作区/计费的 Headless Hook + 默认页面。产物为 ESM（相对导入无扩展名，消费方需经 vite/esbuild 等打包器解析）；exports 的 development 条件指向源码，供 monorepo 开发期直出消费。
