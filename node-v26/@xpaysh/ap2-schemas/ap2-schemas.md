# @xpaysh/ap2-schemas

> 标签: agent-payments-protocol, agentic-commerce, ai-agents, ap2, json-schema, mandates, verifiable-credentials

## 简介

JSON Schemas for the Agent Payments Protocol (AP2), pinned to upstream spec versions. Consumed by xpaysh/agentic-commerce-for-* plugins. Vendor-neutral; tracks google-agentic-commerce/AP2.
