# @keyline-icons/react-native

> 标签: expo, icon-set, icons, react-native, react-native-svg, svg

## 简介

Icons on one 24×24 grid, as React Native components in four styles: stroke, two-tone, duotone and fill, each in rounded or sharp corners. Drawn through react-native-svg, works in Expo.
