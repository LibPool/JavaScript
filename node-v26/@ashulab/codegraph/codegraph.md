# @ashulab/codegraph

> 标签: call-graph, cli, codegraph, dependency-graph, javascript, knowledge-graph, static-analysis, typescript

## 简介

Builds a code knowledge graph (multi-language, pluggable connectors) so an agent navigates relationships without grepping everything. TS/JS resolved with the type-checker, MCP server, and an offline Graph Explorer.
