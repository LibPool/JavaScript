# @luminous-money/ledger-graphs-ui

> 标签: accounting, charts, echarts, ledger, react, reports

## 简介

React charts for @luminous-money/ledger-graphs-api's datasets, drawn with Apache ECharts: spending against a budget and a simulated month, cash flow, breakdowns, net worth.
