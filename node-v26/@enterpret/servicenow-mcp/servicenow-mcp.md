# @enterpret/servicenow-mcp

> 标签: ai-tools, claude, cmdb, cursor, itom, itsm, mcp, model-context-protocol, servicenow, windsurf

## 简介

Enterpret's fork of onlyflowstech/servicenow-mcp. 17 tools over the ServiceNow Table API; adds a SERVICENOW_OAUTH_BEARER env mode so a broker-supplied (Nango) OAuth token is used for auth.
