# @messagebird/sdk

> 标签: api, bird, email, realtime, sdk, sms, verify, webhooks, whatsapp

## 简介

The official TypeScript SDK for the Bird API: email, SMS, WhatsApp, verification, and Realtime on one typed client.

## 官网

- 官网：https://bird.com/docs/sdks/typescript
- 源码仓库：git+https://github.com/messagebird/bird-sdk-typescript.git
- npm 页面：https://www.npmjs.com/package/@messagebird/sdk
