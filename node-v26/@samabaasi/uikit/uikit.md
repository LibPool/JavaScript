# @samabaasi/uikit

> 标签: admin, components, dashboard, data-table, design-tokens, dynamic-form, headless, odata, odata-v4, react, ui-kit

## 简介

Self-contained, OData-native React UI kit: components, data binding (DataState), OData v4 client ($filter/$apply/$batch/Functions/Actions), DynamicForm with rules engine, and app templates (List/Crud/Dashboard/MasterDetail/Report).
