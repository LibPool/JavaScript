# @useorgx/orgx-gateway-sdk

> 标签: gateway, orgx, plugin-peer, protocol, websocket

## 简介

Client SDK for OrgX Gateway Protocol v1/v2/v3. Each editor plugin is a self-sufficient peer that opens its own authenticated WebSocket to OrgX server and implements this protocol directly. No central broker.
