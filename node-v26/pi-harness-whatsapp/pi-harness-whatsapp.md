# pi-harness-whatsapp

> 标签: baileys, openvino, pi, pi-extension, pi-package, speech-to-text, supertonic, tts, voice, whatsapp, whisper

## 简介

Talk to Pi from WhatsApp: images, files and optional voice notes in and out, automatic replies, group chats, poll menus to control Pi.
