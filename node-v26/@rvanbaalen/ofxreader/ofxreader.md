# @rvanbaalen/ofxreader

> 标签: agent, bank, cli, finance, llm, mcp, ofx, qfx, transactions

## 简介

CLI for reading and querying OFX 2.x (XML) financial files. Built for LLM/agent use: deterministic JSON output and a self-documenting --llm mode.
