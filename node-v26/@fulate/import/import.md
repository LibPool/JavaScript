# @fulate/import

> 标签: JavaScript

## 简介

`@fulate/import` 负责把当前支持的外部格式映射为 Fulate canonical creation input。它不是旧 Fulate 版本兼容层，不提供旧 schema 协商、自动迁移或整树 validation；解析后的声明格式直接交给当前 owner。
