# @fulate/echart

> 标签: JavaScript

## 简介

`@fulate/echart` 提供 `EChartsShape`、`EChartsProperties`、`EChartsPool` 和 clipboard plugin。图表实例在 Worker surface 中运行，Fulate 场景只保存 authored/runtime 图表配置，不把 Worker pool 或 surface identity 写入 JSON、History 或 clipboard。
