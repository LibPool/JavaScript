# @gnldev/channels

> 标签: agent, ai, chatbot, durable, exactly-once, llm, slack, telegram, typescript

## 简介

Agents on Slack and Telegram: a signed webhook in, a durable job per message (a platform retry is the same job), the agent run once, the reply sent once — no Redis, the store is the queue.
