# @gnldev/auth

> 标签: agent, ai, ai-sdk, api-keys, authentication, durable, exactly-once, llm, rbac, typescript

## 简介

Auth contract (AuthProvider) + free role-based default (bearer/basic, read/write). Open-core seam: @gnldev/auth-ee plugs into the same interface.
