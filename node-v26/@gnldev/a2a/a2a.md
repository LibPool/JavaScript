# @gnldev/a2a

> 标签: a2a, agent, agent2agent, ai, ai-sdk, durable, exactly-once, json-rpc, llm, remote-agents, typescript

## 简介

Agent2Agent (A2A) for GNL: serve your agents to any A2A client (agent card + JSON-RPC message/send, tasks/get, tasks/cancel) and call remote agents — GNL or standard A2A — as an AI SDK tool. Deterministic task ids: a retried call is answered once by a GNL
