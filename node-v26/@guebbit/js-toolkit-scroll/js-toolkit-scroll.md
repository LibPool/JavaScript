# @guebbit/js-toolkit-scroll

> 标签: JavaScript

## 简介

Scroll-driven DOM helpers with no framework and no runtime configuration: sticky and auto-hiding headers, classes toggled at scroll thresholds, IntersectionObserver wrappers, and lazyloading for `<img>`, `<picture>` and `<video>`.
