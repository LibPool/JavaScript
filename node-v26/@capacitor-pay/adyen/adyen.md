# @capacitor-pay/adyen

> 标签: adyen, capacitor, native, payments, plugin, tap-to-pay

## 简介

Capacitor plugin wrapping Adyen's Tap to Pay SDK for in-app NFC card payments. Adyen provider for capacitor-pay.
