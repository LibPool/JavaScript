# @zeroxsolutions/typeid

> 标签: JavaScript

## 简介

TypeID codec toolkit - encode/decode the type-prefixed, K-sortable id format over uuid v7, plain typed errors, and an optional zod codec adding .typeid(prefix) to z.uuid(); shared across ZeroXSolutions services and the edge gateway.
