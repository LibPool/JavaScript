# @quark-fw/plugin-uploads

> 标签: images, quark, s3, uploads

## 简介

File uploads for the Quark framework: local/S3 storage, image variants via sharp, cached image serving route, authorize/onSaved hooks (published as raw TS sources; consumers run tsx)
