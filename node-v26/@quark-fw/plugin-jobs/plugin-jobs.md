# @quark-fw/plugin-jobs

> 标签: jobs, quark, queue, redis

## 简介

Redis-backed job queue for the Quark framework: define/enqueue with retries, backoff, delayed jobs and a dead-letter list (published as raw TS sources; consumers run tsx)
