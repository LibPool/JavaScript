# @dkplus/media-cli

> 标签: 4k-image-generation, agnes, ai, audio, azure-openai, bananarouter, cli, doubao, face-cover, face-masking, ffmpeg, file-upload, gpt-image, gpt-image-2, grid-caption, grid-locate, image, image-compression, image-to-image, image-to-pdf, image-to-video, media, merge-pdf, minimax, modelscope, pdf, qwen-image, qwen-image-turbo, seedream, sharp, srt, storyboard, subtitle, suno, tencent-cos, text-to-image, text-to-music, text-to-speech, text-to-video, video, video-generation, watermark, whisper

## 简介

通用插件化 Node CLI：图片压缩与文字水印（sharp）、人脸遮罩/打码（Apple Vision 本地检脸）、宫格分镜定位与每格加字幕、图片合并 PDF（sharp + pdf-lib）、视频胶片图/音视频转化（ffmpeg）、SRT 字幕（whisper.cpp）、Azure/BananaRouter gpt-image-2 与 ModelScope Qwen-Image、豆包 Seedream 生图、Agnes 生图与生视频、MiniMax 语音/音乐/视频生成、腾讯云 COS 文件上传换公网
