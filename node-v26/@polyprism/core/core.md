# @polyprism/core

> 标签: codegen, esm, polyprism, prisma, prisma-7, prisma-generator

## 简介

Prisma schema IR, reader, annotation parser, and naming layer powering PolyPrism's Prisma 6 & 7 generators. Pure ESM, zero third-party runtime deps.
