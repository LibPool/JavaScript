# @agentoria/embed

> 标签: agentoria, chat, embed, no-build, vanilla, widget

## 简介

Zero-build chat UI for agentoria: a vanilla-DOM composer, session drawer, and a floating widget you can drop in with one script tag. No bundler, no framework.
