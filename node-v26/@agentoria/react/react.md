# @agentoria/react

> 标签: agent, agentoria, ai, ai-agent, chat, headless, hooks, llm, react

## 简介

Headless React hooks for agentoria: useAgentChat (SSE transport) and useToolCalls (derived tool-call rows). Renders nothing.
