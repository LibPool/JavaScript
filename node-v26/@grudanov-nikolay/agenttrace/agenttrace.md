# @grudanov-nikolay/agenttrace

> 标签: JavaScript

## 简介

Local-first trace debugger for AI agents — Kolya's fork of @raindrop/workshop. Installable via npm on Linux x64 and Windows x64; ships pre-compiled Bun binaries (no Bun required at runtime). Distributed as the `raindrop` CLI.
