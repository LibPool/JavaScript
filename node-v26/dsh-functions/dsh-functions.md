# dsh-functions

> 标签: deepseek-harness, dsh, dsh-plugin, functions, menu, restart, 命令面板

## 简介

功能栏：给 DSH 客户端顶端加一个可扩展的「功能」标签，插件一行注册就能加一键功能；自带了重启 DSH 功能（不再需要单独装 dsh-function-restart）
