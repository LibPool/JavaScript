# @nettrek/c2pa-hls-bridge

> 标签: c2pa, hls.js, streaming, video

## 简介

A lightweight integration layer that connects **C2PA verification** with **HLS.js** at fragment-level.   It enables real-time validation of signed media segments using C2PA manifests while streaming via HLS.
