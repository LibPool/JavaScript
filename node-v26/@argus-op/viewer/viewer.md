# @argus-op/viewer

> 标签: JavaScript

## 简介

Argus's local dashboard: six answer cards scoping a live dependency graph, with a file tree, detail drawer, and activity scrubber. Bun.serve backend, Preact frontend bundled by Bun.build — no web framework.
