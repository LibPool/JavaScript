# @dlr-eoc/ngx-ukis-ui-clarity

> 标签: @dlr-eoc, clarity design ui, layers, schematics

## 简介

This project includes schematics to add a base UKIS-Layout to an angular application. The Layout is based on Clarity so [add this first](https://clarity.design/get-started/developing/angular)!
