# @asyntai/mcp

> 标签: ai, asyntai, chatbot, claude, customer-support, mcp, model-context-protocol, modelcontextprotocol, oauth

## 简介

Connect any local MCP client to your Asyntai account. Bridges stdio to the hosted Asyntai MCP server and handles the OAuth sign-in for you.
