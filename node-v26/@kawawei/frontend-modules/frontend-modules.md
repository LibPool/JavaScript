# @kawawei/frontend-modules

> 标签: JavaScript

## 简介

本目錄包含提供給外部系統引用的核心 **CaaS (Component as a Service)** Web Components 模組。這些組件完全封裝於 Shadow DOM 中，實現了對宿主系統的「零侵入性」集成。
