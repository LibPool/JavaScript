# @mnemoscale/sdk

> 标签: agents, llm, memory, mnemos, sdk

## 简介

TypeScript SDK for the Mnemos memory API: zero-dependency fetch client with typed errors, retry/backoff, and session/polling helpers mirroring the Python SDK.
