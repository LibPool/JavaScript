# @rmdes/indiekit-endpoint-auth

> 标签: indieauth, indiekit, indiekit-plugin, indieweb

## 简介

IndieAuth authentication and authorization endpoint for Indiekit with profile scope support. Grants and verifies access tokens and authenticates users.
