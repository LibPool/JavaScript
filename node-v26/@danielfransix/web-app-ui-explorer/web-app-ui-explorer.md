# @danielfransix/web-app-ui-explorer

> 标签: bundler, component-gallery, crawler, create-react-app, design, playwright, proxy, screens, screenshots, storybook-alternative, ui, ui-explorer, vite, vite-plugin, web-app, web-app-ui-explorer, webpack

## 简介

Explore every screen and state of a web app: an automatic crawler, a source-driven explorer, a flow canvas and thumbnails. Works with any bundler and any front-end framework, or none.
