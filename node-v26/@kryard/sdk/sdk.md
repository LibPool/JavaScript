# @kryard/sdk

> 标签: 7702, account-abstraction, eip-7702, gasless, hpke, key-export, key-management, kryard, paymaster, relayer, secp256k1, signing, sponsored-transaction, turnkey, turnkey-compatible, viem, wallet-infrastructure

## 简介

Client for Kryard's Turnkey-compatible wallet infrastructure: X-Stamp'd key creation, secp256k1 signing (raw payload + EVM transaction), HPKE private-key export, and the managed EIP-7702 relay (sponsored execute with optional ERC-20 gas).
