# consulti

> 标签: b2b, cli, consulti, email-verification, lead-enrichment

## 简介

Command-line client for the Consulti.ai API: email verification, B2B lead search and enrichment, Instagram search, lists and credits. JSON output and stable exit codes for scripts and AI agents.
