# @whydiff/core

> 标签: cascade-layers, clustering, css-diff, deterministic, dom-diff, layout-diff, render-tree, root-cause, style-diff, tree-matching, visual-diff, whydiff

## 简介

Matches two render-tree snapshots, finds the cause of each changed pixel region and groups causes by CSS rule. No browser, no model, no I/O.
