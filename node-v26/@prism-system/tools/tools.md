# @prism-system/tools

> 标签: JavaScript

## 简介

Published tooling for @prism-system design systems: search and inspect the npm registry (read-only), explicitly install (npm/pnpm), and configure/validate consumers with prism-ds. No postinstall, no source copying, no publishing.
