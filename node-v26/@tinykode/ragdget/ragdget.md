# @tinykode/ragdget

> 标签: browser, client-side, embeddings, faq, hnsw, rag, semantic-search, transformers, vector-search, widget

## 简介

Embeddable FAQ widget with client-side semantic search. No server needed. Powered by HNSW and Transformers.js.
