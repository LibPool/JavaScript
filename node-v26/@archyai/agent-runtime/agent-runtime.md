# @archyai/agent-runtime

> 标签: agent-runtime, agent-tools, archy, code-grounding, local-first, mcp, middleware, model-agnostic

## 简介

Archy agent-runtime middleware — intercept built-in Read/Grep/Bash/Edit/commit tool calls and surface structured suggestions that route the agent to the indexed plane (no model coupling, no execution).
