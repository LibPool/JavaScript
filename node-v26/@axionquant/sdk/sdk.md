# @axionquant/sdk

> 标签: axion, axionquant, crypto-api, cryptocurrency, earnings, economic-data, etf, financial-api, financial-data, forex-api, fred, futures-api, market-data, nodejs, quant, quantitative-finance, sdk, sec-filings, stock-api, stock-market-api, trading-api, typescript

## 简介

Official TypeScript/JavaScript SDK for the AxionQuant financial data API. Real-time and historical stock, crypto, forex, futures, and economic data, plus SEC filings, earnings, and company financials.
