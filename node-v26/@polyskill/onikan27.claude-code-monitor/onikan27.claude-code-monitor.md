# @polyskill/onikan27.claude-code-monitor

> 标签: JavaScript

## 简介

Claude Codeの複数セッションをリアルタイム監視するmacOS専用CLIツール。Ink（React for CLI）を使用したTUIとファイルベースの状態管理で動作する。
