# @rebind.gg/client-ts

> 标签: automation, hid, input, keyboard, mouse, rebind, remote-control, websocket

## 简介

TypeScript client for the Rebind Remote Access WebSocket protocol. Typed, auto-reconnecting, zero runtime dependencies.
