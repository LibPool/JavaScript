# @samchon/evidence-graph

> 标签: evidence, jsdoc, lint, provenance, traceability, ttsc, typescript

## 简介

Evidence-graph lint contributor for @ttsc/lint: declare provenance with a JSDoc @evidence tag and fail the build when it is missing or dangling.
