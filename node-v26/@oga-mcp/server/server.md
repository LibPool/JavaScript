# @oga-mcp/server

> 标签: location-intelligence, mcp, model-context-protocol, onegoodarea, postcode, property, uk

## 简介

MCP server for OneGoodArea: UK area intelligence inside Claude Desktop, Cursor, and any MCP-compatible client. Returns server-composed briefs (summary + per-dimension reasoning + confidence + data sources) from the deterministic engine.
