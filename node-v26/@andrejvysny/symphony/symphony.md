# @andrejvysny/symphony

> 标签: ai, automation, claude, claude-code, cli, coding-agent, git-worktree, orchestrator, symphony

## 简介

Agent-agnostic coding-agent orchestrator — delegate tickets to local coding agents (Claude Code, codex, opencode) in isolated git worktrees, driven by a local file task store.
