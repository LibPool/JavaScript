# @stroq/cli

> 标签: agent-security, ai-agents, claude-code, cursor, firewall, guardrails, llm-security, mcp, prompt-injection

## 简介

Local action firewall for AI agents: scans what the agent reads, taints the session, blocks dangerous follow-up actions
