# @softgenio.tech/thor-sdk

> 标签: ai, gateway, llm, sdk, thor, typescript

## 简介

Official TypeScript SDK for Thor, a multi-tenant AI gateway. Thin server-side HTTP client with retries, idempotency and SSE streaming. ESM and CommonJS.
