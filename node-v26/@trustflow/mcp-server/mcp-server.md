# @trustflow/mcp-server

> 标签: did, did:web, llms.txt, mcp, trustflow

## 简介

Trustflow MCP server. Stdio tools for Trustflow Systems domain audits, did:web keys, and signed llms.txt. Binary: agentic-trust-mcp. Scaffold with npx @trustflow/cli@latest init.
