# @0xhoneyjar/quests-ui

> 标签: freeside, primitives, quests, react, unstyled

## 简介

Unstyled React primitives for quest UIs — slot-based composition, zero CSS, zero design tokens. Consumers (cubquests-dashboard · per-world bots · future Farcaster Mini App) ship their own skin. Per Cycle Q SDD §6 + PRD D2 anti-pattern guard.
