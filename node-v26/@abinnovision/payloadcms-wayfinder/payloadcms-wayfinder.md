# @abinnovision/payloadcms-wayfinder

> 标签: link-field, payload, payloadcms, permalinks, routing, urls

## 简介

Editor-authored URL routing for Payload: collection-to-path patterns, document-to-href building, path-to-document resolution and a routing-aware link field.
