# @brownnrl/geomlib

> 标签: canvas, constructions, education, elements, euclid, geometry, mathematics

## 简介

Interactive Euclidean geometry constructions in the browser — a TypeScript port of David E. Joyce's 1996 Java Geometry Applet.
