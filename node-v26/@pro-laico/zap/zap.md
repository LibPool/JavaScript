# @pro-laico/zap

> 标签: JavaScript

## 简介

Zod with Atomic Payload extensions - a registry-aware schema layer used across the Atomic Payload packages and templates. Re-exports zod and adds the `z.ap` helper class for registering and retrieving schemas typed against AtomicRegistry.
