# @pro-laico/payload-fonts

> 标签: font, fonts, next-font, payload, payloadcms, plugin, woff2

## 简介

Custom fonts for Payload CMS: a Font typeface collection that subsets uploaded files to served WOFF2s, an optional fontSet global, an export endpoint + CLI that writes the active fonts to disk for next/font/local, and declarative seeding.
