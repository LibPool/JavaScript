# @pro-laico/payload-revalidate

> 标签: cache, cacheTag, nextjs, payload, payloadcms, plugin, revalidate, revalidateTag

## 简介

Surgical Next.js cache revalidation for Payload CMS: auto-attached hooks that bust exactly the tags a change touches, cached finders that fetch AND tag in one call inside 'use cache' getters, and a dependency map showing what revalidates when.
