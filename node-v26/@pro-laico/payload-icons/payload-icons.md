# @pro-laico/payload-icons

> 标签: icons, payload, payloadcms, plugin, svg, svgo, upload

## 简介

SVG icons for Payload CMS: an Icon upload collection that optimizes and sanitizes SVGs on save (svgo + viewBox tightening + currentColor theming), a drop-in <Icon name> server component that fetches and inlines the SVG, and one-line declarative seeding vi
