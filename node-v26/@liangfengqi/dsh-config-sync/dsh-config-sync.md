# @liangfengqi/dsh-config-sync

> 标签: backup, config, deepseek-harness, dsh, dsh-plugin, git, multi-device, sync

## 简介

DSH 多端配置同步插件：把 DSH_HOME 的配置面文件（设置/插件清单/技能）纳管到私有 Git 仓库，多端捕获、推送、拉取、应用与回滚；插件依赖按 pnpm-lock 确定性重建。
