# @w3rd-player/core

> 标签: angular, custom-elements, dash, hls, lit, react, video-player, vue, web-components

## 简介

Framework-agnostic video player as a Web Component (Lit). Native + HLS + DASH playback with custom controls. Works with vanilla JS, Vue, React and Angular.
