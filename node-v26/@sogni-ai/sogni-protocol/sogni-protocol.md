# @sogni-ai/sogni-protocol

> 标签: json-schema, language-neutral, openai-tools, protocol, schemas, sogni

## 简介

Language-neutral protocol artifacts for the Sogni ecosystem: tool schemas, prompts, OpenAI tool manifests, and enums. Consumed by every Sogni SDK (TypeScript, Swift, and future Python/Kotlin/Rust SDKs) so contracts stay in lockstep across languages.
