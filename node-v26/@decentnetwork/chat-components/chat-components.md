# @decentnetwork/chat-components

> 标签: agent, beagle, carrier, chat, components, decentnetwork, forms, interactive, typescript

## 简介

Interactive forms in chat — the shared schema between an agent that asks and a client that renders. Declarative components ride inside the message text, so any transport that carries chat carries forms; no HTML, no URLs, no scripts. Zero dependencies, bro
