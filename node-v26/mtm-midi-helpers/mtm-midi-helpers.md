# mtm-midi-helpers

> 标签: circuit-playground, launchpad, midi, midi-fighter, p5, p5js, pipsqueak, processing, trinkey, web-midi

## 简介

More than Music with MIDI: one class per MIDI device for p5.js and the browser. PipSqueak, Midi Fighter, Launchpad Mini MK3, Circuit Playground, Trinkeys, and AnyMidi for everything else. Web MIDI, no dependencies.
