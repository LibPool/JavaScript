# @mudah-cli/tui

> 标签: fullscreen, layout, terminal, tui, typescript, widgets

## 简介

Full-screen terminal UI toolkit: alt-buffer Program, Row/Column/Split layout, diff rendering, mouse, Kitty keyboard, focus-managed widgets.
