# @mudah-cli/audio

> 标签: alsa, audio, cli, pcm, pipewire, terminal, typescript

## 简介

Play PCM through the OS mixer from a Mudah app (streaming output and one-shot WAV). Optional: apps that never import it never load an audio backend.
