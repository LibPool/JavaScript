# @bambr-io/create-js-playground

> 标签: JavaScript

## 简介

Scaffold a Bambr JS playground (Vite + vite-node, no HTML) and install deps automatically.

## 官网

- npm 页面：https://www.npmjs.com/package/@bambr-io/create-js-playground

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install @bambr-io/create-js-playground`
- npm registry：https://registry.npmjs.org/@bambr-io/create-js-playground
- Node 要求：>=18
