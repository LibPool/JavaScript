# @ostanin/podman

> 标签: api, client, containers, docker, libpod, podman, typescript

## 简介

Typed Podman client for Node.js. Full libpod API — containers, images, pods, networks, volumes, secrets, exec, manifests, kube, artifacts, quadlets.
