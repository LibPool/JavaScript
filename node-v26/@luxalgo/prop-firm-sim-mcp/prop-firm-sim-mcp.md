# @luxalgo/prop-firm-sim-mcp

> 标签: mcp, model-context-protocol, monte-carlo, prop-firm, trading, trading-challenge

## 简介

MCP server exposing the open-source prop-firm challenge simulator to AI agents: firm rulesets with citations, Monte Carlo simulation, optimal risk sweeps, cross-firm comparison, and bootstrap simulation from a real trade series.
