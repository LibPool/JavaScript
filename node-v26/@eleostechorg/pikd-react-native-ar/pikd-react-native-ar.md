# @eleostechorg/pikd-react-native-ar

> 标签: 3d, arcore, arkit, augmented-reality, geospatial, pikd, react-native, sdk

## 简介

React Native bridge for the PIKD native AR SDK, providing ARKit and ARCore sessions, geospatial placement, navigation, interactions and physics.
