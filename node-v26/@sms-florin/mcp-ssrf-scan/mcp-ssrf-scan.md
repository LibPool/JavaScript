# @sms-florin/mcp-ssrf-scan

> 标签: ai-agents, mcp, model-context-protocol, scanner, security, ssrf, static-analysis

## 简介

A static scanner for MCP servers that catches the exact bug class behind most real MCP SSRF reports: a tool handler making an outbound request to a caller-controlled URL with no host validation.
