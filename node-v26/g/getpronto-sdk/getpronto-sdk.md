# getpronto-sdk

> 标签: ai-tools, cdn, file-upload, getpronto, image-hosting, image-transformation, mcp

## 简介

A JavaScript/TypeScript SDK for the GetPronto API. This SDK allows you to manage files and images on the GetPronto platform.
