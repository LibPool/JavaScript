# grafana-mcp

> 标签: agent, ai, bun, grafana, logging, loki, mcp, mcp-server, modelcontextprotocol, observability, prometheus, tempo

## 简介

Project-level read-only Grafana MCP server: Loki/Prometheus/Tempo/Alerts with test-prod switching and per-project context. Zero deps, runs on bun.
