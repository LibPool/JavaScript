# gridmapper

> 标签: allocation, cartogram, geographic, grid, linear-programming, mip, spatial, visualization

## 简介

A JavaScript library for allocating geographic points to a grid using Mixed Integer Programming (MIP). Inspired by Jo Wood's Grid Map Allocation.
