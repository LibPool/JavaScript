# google-apis-cli

> 标签: analytics, cli, ga4, google, google-ads, gtm, indexing, search-console, tag-manager

## 简介

One CLI (gapi) for Google Ads, GTM, GA4 (Admin+Data), Search Console, and Indexing. One login, all scopes, read+write.
