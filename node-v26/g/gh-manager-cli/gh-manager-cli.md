> 标签: archive-repos, cli, delete-repos, developer-tools, github, github-api, github-cleanup, github-cli, github-manager, github-tools, graphql, ink, interactive-cli, management, productivity, react-ink, repo-manager, repository, repository-cleanup, terminal, terminal-ui, tui

## 简介

TUI terminal app to manage GitHub repos. Clean up your account in 5 minutes. Archive, delete, rename repos with keyboard shortcuts. Alternative to clicking through github.com
