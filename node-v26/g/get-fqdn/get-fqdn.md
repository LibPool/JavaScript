# get-fqdn

> 标签: address, dns, domain, domains, fetch, fqdn, fully, get, host, hostname, hostnames, ip, ipv4, ipv6, lookup, machine, name, os, qualifie, qualified, qualify

## 简介

Lookup the fully qualified domain name ("FQDN") of the current server's IP (default) or a custom IP.  90x faster than `hostname -f` and works with Node v6.4+.
