# guilded

> 标签: guilded, guilded-api, guilded.gg, guilded.js, guildedjs

## 简介

A Node.js library for the Guilded.gg (https://www.guilded.gg/) API written in TypeScript, usable in either JavaScript or TypeScript projects.
