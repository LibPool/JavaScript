# get-env-cli

> 标签: assert, cli, cli-app, environment, exist, exists, get-env, node_env, variable

## 简介

A command line wrapper for the npm [get-env package](https://www.npmjs.com/package/get-env), with an option for asserting that a particular environment be set.
