# google-services-mcp

> 标签: calendar, contacts, docs, drive, forms, gmail, google, mcp, meet, model-context-protocol, oauth, sheets, slides, tasks, youtube

## 简介

MCP server for Google consumer services — Gmail, Calendar, Meet, Drive, Contacts, Tasks, Sheets, Docs, Slides, YouTube, Forms — with multi-account OAuth support.
