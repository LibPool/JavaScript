# git-archaeo

> 标签: cli, code-analysis, code-archaeology, developer-tools, git, git-blame, git-history, provenance, typescript

## 简介

Trace why a line of code exists — through moves, renames, and refactors — back to the commit, PR, issue, and review that introduced it, with honest confidence scoring.
