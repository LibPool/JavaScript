# graphql-ormify-client

> 标签: client, fetch, graphql, hasura, orm, ormify, query-builder, typescript

## 简介

一个强大的 GraphQL 客户端库，提供类型安全的查询构建和执行功能,目前已兼容 Hasura 和 和 Zion 的 GraphQL 服务
