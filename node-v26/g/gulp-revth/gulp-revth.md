# gulp-revth

> 标签: asset, assets, cache, expire, gulpplugin, hash, optimize, rev, revision, static, version, versioning

## 简介

Static asset revisioning by appending content hash to filenames: unicorn.css => unicorn-2015_01_02_03_04_45.css
