# ghost-reveal

> 标签: animate on scroll, aos, aos alternative, astro, blur fade, ghost-reveal, intersectionobserver, nextjs, react, reveal, scroll, scroll animation, scroll-driven animations, ssr, svelte, tiny, vanilla, view timeline, vue, web animations api, zero dependencies

## 简介

Tiny (~2 KB gzip) zero-dependency scroll-reveal library with premium blur-fade defaults. Web Animations API + IntersectionObserver, no CSS file, SSR-safe, AOS-compatible data attributes.
