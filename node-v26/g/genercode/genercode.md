# genercode

> 标签: JavaScript

## 简介

npm install genercode -g genercode genercode -u *****配置接口地址，没有配置接口地址使用config.json的地址 genercode -p *****配置生成代码的存放目录地址，没有配置目录存放地址就默认生成在当前目录
