# getorset-anything

> 标签: get-or-set, getorset-anything, getset, getter-setter, javascript, js-map, map, map-get-or-set, map-setter, map-util, mapgetset, obj-set-get, obj-util, object-get-or-set, object-setter, setget, setter-getter, typescript

## 简介

Gets a value from a Map/Obj or sets an initial value when not found and returns that. TypeScript supported.
