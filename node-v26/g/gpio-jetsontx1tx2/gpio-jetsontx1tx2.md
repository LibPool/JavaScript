# gpio-jetsontx1tx2

> 标签: gpio, jetson, tx1, tx2

## 简介

This is a package for read and write functions of the gpio pins on the jetson tx1/tx2 in node in the same fashion as raspberry pi and beaglebone.

## 官网

- 源码仓库：https://github.com/airobotUAV/airobot_npm/tree/master/gpio-jetson-tx1-tx2
