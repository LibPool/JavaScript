# grapplehook-cli

> 标签: aria2c, cli, downloader, ffmpeg, mp4, transcode, video, youtube, youtube-downloader, yt-dlp

## 简介

Download videos from the command line (yt-dlp + ffmpeg + aria2c), with an optional editor-friendly mp4 transcode.
