# godot-kit

> 标签: agent-skills, claude-skill, debugger, game-dev, gdscript, godot

## 简介

Agent Skills installer for Godot 4.x - installs a HTTP-bridge debugging skill (runtime scene tree, live eval, editor control) into an existing Godot project, no CLI binary required
