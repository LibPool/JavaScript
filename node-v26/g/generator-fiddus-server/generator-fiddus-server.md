# generator-fiddus-server

> 标签: express, expressjs, mongodb, mongoose, node, nodejs, yeoman-generator

## 简介

Yeoman generator for a Node.js/Express.js/MongoDB based, REST API server. It comes with authentication and logging out of the box.
