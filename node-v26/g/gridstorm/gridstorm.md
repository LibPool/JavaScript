## 简介

GridStorm — The complete data grid platform in one npm install. 100% free, MIT-licensed. Core engine + 45+ plugins (sorting, filtering, grouping, pivoting, formulas, time-travel, CRDT collab, LLM-backed NL query, anomaly detection, more) + React/Vue/Svelt
