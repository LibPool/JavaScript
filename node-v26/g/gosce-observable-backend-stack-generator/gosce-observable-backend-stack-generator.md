# gosce-observable-backend-stack-generator

> 标签: a2a, ai-agent, getvda, mcp, observable-backend-stack-generator

## 简介

Generate a production observability stack as docker-compose: Prometheus (scrape config + alert rules), Grafana (provisioned datasource + dashboard), Alertmanager and node-exporter. Add db/cache images
