# graylog-logs-mcp

> 标签: claude, claude-code, graylog, logging, logs, mcp, model-context-protocol, observability

## 简介

MCP server for Graylog: search logs by source, severity and any field, count top values, histograms, and pull the context around a message. Graylog 3.x to 6.x.
