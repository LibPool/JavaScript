# gatsby-head-style-boss

> 标签: " flash prevention", css, darkmode, gatsby, gatsby-plugin, head, stylesheet

## 简介

Gatsby plugin to manage multiple CSS style sheets in the head. Inline local or remote style sheets at build time. Optional components to toggle dark mode, select from multiple styles or show stylesheet statuses. Prevents transition flash with IIFE. Option
