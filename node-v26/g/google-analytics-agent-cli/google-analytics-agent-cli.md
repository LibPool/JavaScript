# google-analytics-agent-cli

> 标签: JavaScript

## 简介

CLI + Claude Code skill for AI-agent-driven Google Analytics 4 admin operations (custom dimensions, metrics, key events). Closes the gap where the GA4 web UI is the only interface for property configuration.
