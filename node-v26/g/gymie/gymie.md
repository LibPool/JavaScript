# gymie

> 标签: javascript, nodejs, openai-gym, python, reinforcement-learning, tensorflowjs

## 简介

WebSocket client that consumes an API wrapping OpenAI Gym or gym-like environments such as Gym Retro or Unity ML-Agents.
