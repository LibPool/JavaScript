# git-sb3

> 标签: diff, git, git-extension, sb3, scratch, scratchblocks, turbowarp, version-control

## 简介

A git extension for version-controlling Scratch .sb3 projects: diffable unpack/pack, readable git diffs, and visual scratchblocks diff reports. Run as `git sb3`.
