# gs-rollup-plugin-vue-dts

> 标签: JavaScript

## 简介

替代官方 Vue 类型生成的 Rollup 插件，用于生成简洁、可读且对编辑器友好的 TypeScript 声明文件。 通过在生成阶段重建 `.d.ts` 结构，避免官方输出中的复杂嵌套与冗余，从而提升类型提示、跳转与补全体验。
