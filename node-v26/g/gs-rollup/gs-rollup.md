# gs-rollup

> 标签: @types/rollup, build tool, grain-sand, gs-rollup, rollup, 打包工具

## 简介

这是一个 rollup 的简单包装器，主要快速打包TS模块，大多数情况下可以零配置打包。会自动拷贝文档并重建 package.json 到打包目录。
