# grapplehook-core

> 标签: aria2c, core, download, ffmpeg, grapplehook, transcode, video, youtube, yt-dlp

## 简介

Framework-agnostic core for grapplehook: orchestrates yt-dlp + ffmpeg + aria2c to fetch video info and download/transcode videos, with structured progress and cancellation.
