# grunt-svg-sprite-studio

> 标签: css, gruntplugin, less, scss, sprite, stylus, svg, svg-sprite, svgo, xmp

## 简介

Production-ready Grunt task to convert SVG icons into SVG symbol sprites with SCSS/LESS/Stylus/CSS stylesheets and XMP metadata.
