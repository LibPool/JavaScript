> 标签: ai, automation, cli, commit-messages, gemini, git

## 简介

A minimal, terminal-native CLI tool built with **Node.js**.   It allows users to automatically generate professional, one-sentence commit messages instantly based on code changes using AI.   Automates the git actions (add -> commit -> push) with a singl
