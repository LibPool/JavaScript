# gulp-find-glob

> 标签: JavaScript

## 简介

gulpで、複数ファイルをgulp.pipeとかしたいとき、`js/*.js`みたいなのが書けるモジュールと書けないモジュールがあったから、実装しちゃえ！ということで実装しました。   globを使っています。
