# gremlin-mcp

> 标签: apache-tinkerpop, database, graph, graphdb, gremlin, mcp, model-context-protocol, tinkerpop

## 简介

The official Apache TinkerPop MCP server for Gremlin that allows for fetching status, schema, and querying using Gremlin for any TinkerPop-compatible graph database (TypeScript implementation).

## 官网

- 官网：https://tinkerpop.apache.org/
- 源码仓库：git+https://github.com/apache/tinkerpop.git
