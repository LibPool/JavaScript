# graphile-storage-registry

> 标签: constructive, graphile, graphql, plugin, postgraphile, postgres, registry, storage

## 简介

Registry-derived storage plane discovery for PostGraphile v5 — pairs @storageFiles/@storageBuckets codecs through their actual foreign-key relations and derives the canonical upload surface names, so no table name is ever load-bearing
