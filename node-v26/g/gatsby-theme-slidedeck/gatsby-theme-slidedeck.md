# gatsby-theme-slidedeck

> 标签: gatsby, gatsby-plugin, gatsby-theme, presentation, slidedeck, slideshow

## 简介

`gatsby-theme-slidedeck` generates a slide deck for each `.deck.mdx` file in the project's `deck` directory.
