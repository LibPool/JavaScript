# gulp-ng-lang2js

> 标签: angular, angularjs, gulpplugin, i18n, internationalization, l10n, lang2js, localization, ng-lang2js, translate

## 简介

A Gulp plugin which generates AngularJS modules, which pre-load your JSON language files into the $translationCache. This way AngularJS doesn't need to request the actual JSON files anymore.
