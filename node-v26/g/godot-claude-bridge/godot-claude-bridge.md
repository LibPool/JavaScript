# godot-claude-bridge

> 标签: claude, dap, game-development, gdscript, godot, lsp, mcp, model-context-protocol

## 简介

MCP host exposing Godot to Claude across four planes (CLI, live editor, LSP+DAP, runtime) with elicitation-gated destructive tools, progress-streamed jobs, captured console output, and MCP resources.
