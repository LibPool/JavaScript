# git-history-viewer

> 标签: JavaScript

## 简介

A node application that allows you to retrieve git history for all git repos nested in a directory ## Usage ``` git-history-viewer --help ``` ``` git-history-viewer --directory . --start-date 2018-10-01 --end-date 2018-11-01 ```
