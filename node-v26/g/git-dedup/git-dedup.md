# git-dedup

> 标签: cli, clone, coding-agents, git, git-wrapper, object-pool, shared-storage, submodule, vscode, worktree

## 简介

Faster checkouts, a fraction of the disk space: share one copy of Git history across clones, worktrees, and submodules
