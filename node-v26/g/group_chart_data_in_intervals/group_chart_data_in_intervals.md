# group_chart_data_in_intervals

> 标签: Javascript, data, grouping, interval, sales, timestamp

## 简介

This package solves an issue I experienced lately when I want to group a large number of sales records in yearly, monthly, weekly and daily intervals for displaying on charts and graphs.Package considers intervals with no sales. Enjoy every byte!!!
