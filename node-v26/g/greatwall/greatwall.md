# greatwall

> 标签: JavaScript

## 简介

1. 打开 index.html 可以浏览示例目录. Note: index.html 只是作为信息结构的作用, 跳转以后都是单独的 SPA 或者其他任何技术结构. 每个示例自包含, 但是可以通过统一构建. 2. 每个示例作为一个应用目录放到 app 下面 3. 通过脚手架 russel:front 可以生成一个完整的示例脚手架 4. 开发服务器使用 augustine 作为 web server 5. 通过构建脚本进行统一构建操作.可以按照约定各自输出到对应的输出目录下. 6. 拟支持的示例技术结构包括
