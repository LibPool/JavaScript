# gitgraf

> 标签: ai, claude, codex, coding-agent, cursor, git, mcp, model-context-protocol, security

## 简介

Point your coding agents at GitGraf. Writes one MCP entry into every agent on the machine and exits. No daemon, no hooks, nothing that keeps running.
