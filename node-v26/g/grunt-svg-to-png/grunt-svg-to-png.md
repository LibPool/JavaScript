# grunt-svg-to-png

> 标签: grunt, gruntjs, gruntplugin, image, phantom, phantomjs, png, rasterise, rasterize, svg

## 简介

Grunt plugin to rasterize SVG to PNG images using PhantomJS. Fork of grunt-svg2png by dbushell.
