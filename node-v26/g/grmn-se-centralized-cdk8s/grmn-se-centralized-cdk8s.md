# grmn-se-centralized-cdk8s

> 标签: JavaScript

## 简介

A TypeScript/JavaScript framework for defining, composing, and managing Kubernetes resources using [cdk8s](https://cdk8s.io/). This project provides both a CLI and a library for flexible, type-safe, and reusable Kubernetes manifest generation.
