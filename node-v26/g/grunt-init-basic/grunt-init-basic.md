> 标签: assemble, generator, grunt handlebars, grunt init, grunt plugin, grunt task, grunt templates, gruntplugin, handlebars, init, markdown, site generator, yeoman, yeoman generator, yo

## 简介

grunt-init template for a very basic project. includes nodeunit tests, jshint, watch, clean, and assemble for converting readme to a simple gh-pages index page.
