# glytch

> 标签: agent, board, canvas, claude, claude-code, mcp, prompting-machine

## 简介

Run coding agents from the Prompting Machine board. Connects your machine to prompt.glytch.ai, launches a session in its own worktree when you press Run, and streams what it does back to the canvas.
