# gmbox-cli

> 标签: JavaScript

## 简介

1. 安装 Node JS 2. 打开一个命令行终端，在其中输入```npm install gmbox-cli -g``` 3. 执行 ```gmbox -v```，如果可以输出版本号，则表示执行成功
