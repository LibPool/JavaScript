# gulp-spawn-shim

> 标签: cli, exec, gulpplugin, shell, spawn

## 简介

Thin wrapper (shim) of Node.js's child_process.spawn() with respect to gulp (vinyl file streams) by binding to stdin, stdout, and stderr.
