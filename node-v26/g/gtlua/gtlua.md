# gtlua

> 标签: 6502, 65c02, 8-bit, ahead-of-time, aot, blitter, cartridge, cc65, fantasy-console, game-development, gamedev, gametank, gtr, homebrew, lua, pico-8, pico8, retro, retrogaming, rom, wasm, webassembly

## 简介

Write GameTank games in a PICO-8-flavored Lua that ahead-of-time compiles to native 65C02. Bundled cc65 WASM toolchain + emulator, .gtr cartridges, no native tools.
