# ghost-storage-cos

> 标签: cos, ghost, ghost storage, ghost-storage-adapter, qcloud, 腾讯云对象存储

## 简介

This Ghost custom storage module allows you to store media file with Tencent Cloud Cos instead of storing at local machine.
