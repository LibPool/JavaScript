# gulp-image-sans-guetzli

> 标签: compress, gif, gulpplugin, image, img, jpeg, jpg, minify, optimize, png, svg

## 简介

Optimize PNG, JPG, GIF, SVG images with gulp task. Fork of original gulp-image, without the unsupported guetzli package.
