# gobiz-pay

> 标签: gobiz, gojek, gopay, indonesia, merchant, payment, qris

## 简介

TypeScript module for interacting with the GoBiz (GoPay Merchant) API: transaction history, real-time payment monitoring, and dynamic QRIS.
