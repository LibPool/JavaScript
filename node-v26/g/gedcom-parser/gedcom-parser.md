# gedcom-parser

> 标签: JavaScript

## 简介

Simple parser for [gedcom](https://en.wikipedia.org/wiki/GEDCOM) files.   Advantage is in one loop processing a file what increase performance and extensibility of the base class allowing you to change the default data format.
