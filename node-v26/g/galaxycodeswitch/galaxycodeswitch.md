# galaxycodeswitch

> 标签: ai, assistant, auto-approve, claude, codex, coding, configuration, galaxycode, setup, yolo

## 简介

一键配置 Claude Code、Codex 和 GalaxyCode 的命令行工具，场景式引导，支持 YOLO 全自动模式，兼容 Linux/macOS/Windows/Termux
