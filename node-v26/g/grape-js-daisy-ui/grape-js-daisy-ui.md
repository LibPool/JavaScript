# grape-js-daisy-ui

> 标签: css, daisyui, drag-and-drop, dy-prefix, frontend, grapesjs, grapesjs-plugin, javascript, tailwind-ui, tailwindcss, ui-components, user-interface, visual-editor, web-design

## 简介

A library that integrates DaisyUI components directly into GrapesJS, enabling easy design and customization of user interfaces using Tailwind CSS with the 'dy-' prefix.
