# grunt-tinypng-extended

> 标签: avif, compress, gruntplugin, image, img, jpeg, minify, photo, picture, png, tinypng, webp

## 简介

Grunt plugin for compressing PNG, JPEG, WebP, AVIF, and other images with the official TinyPNG API, featuring caching, retries, parallel processing, metadata preservation, and summaries.
