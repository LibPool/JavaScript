# glm-acp-agent

> 标签: acp, agent, coding-agent, glm, zhipu

## 简介

ACP agent in TypeScript that uses the Z.AI / Zhipu AI GLM Coding Plan models (GLM-5.3, GLM-5.3 Flash, GLM-5 Turbo, GLM-4.7) as the reasoning core
