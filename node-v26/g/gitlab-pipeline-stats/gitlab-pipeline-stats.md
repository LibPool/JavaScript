# gitlab-pipeline-stats

> 标签: ci, devops, gitflow, github-flow, gitlab, pipeline, stats, trunk-based

## 简介

Quick GitLab pipeline stats: avg, p50, p95, and max per job and group. Groups are configured via presets for different release flows.
