# g-ocr

> 标签: bbox, cpu, deutsch, document, german, invoice, ocr, onnx, text-recognition

## 简介

GOCR — small, CPU OCR: document -> text + bounding boxes as JSON. ~30 MB, no GPU. Node port of the g-ocr Python package.
