# gmr-cli

> 标签: git, git-multi-remote, git-multi-remote-cli, gmr-cli, multi-remote

## 简介

Git Multi Remote CLI is a command-line tool for managing multiple remote git repositories. It provides a simple and easy-to-use interface that allows users to add, switch, delete and list repositories without interfering with each other. It makes it easy
