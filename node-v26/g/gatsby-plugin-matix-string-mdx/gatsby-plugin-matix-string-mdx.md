# gatsby-plugin-matix-string-mdx

> 标签: JavaScript

## 简介

The goal of this plugin is to create nodes as compiled html from an input string. There is already the plugin `gatsby-plugin-mdx` which does exactly this but works for an mdx file only. Often, we use  mdx format as strings like in the case of the markdown
