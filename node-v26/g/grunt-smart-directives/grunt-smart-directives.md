> 标签: condition, conditional, conditions, directive, directives, grunt, gruntplugin, macro, macros, postprocess, postprocesser, pragma, preprocess, preprocesser, process

## 简介

Use the directives this package provides or create custom directives. Add them via customisble tags to source file comments, to 'conditionally' preprocess your source code files to targeting multiple environments from a single code base. Inspired by C pre
