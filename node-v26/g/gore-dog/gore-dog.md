# gore-dog

> 标签: JavaScript

## 简介

> gore --save "https://github.com/search?q={github}"   > gore -s "https://github.com/search?q={github}" # open url > gore github gore > auto open: https://github.com/search?q=gore # view list > gore --list  [,string] > gore -l [,string]
