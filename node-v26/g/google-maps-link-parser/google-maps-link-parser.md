# google-maps-link-parser

> 标签: bun, coordinates, geocoding, google-maps, maps, maps-url, shortlink, typescript, url-parser, url-unfurl

## 简介

Bun-first TypeScript library for parsing, normalizing, unfurling, and optionally enriching public Google Maps URLs.
