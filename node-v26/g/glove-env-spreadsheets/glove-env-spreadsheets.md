# glove-env-spreadsheets

> 标签: JavaScript

## 简介

Spreadsheet stdlib adapter for glove-working-environment. Bridges exceljs into the agent's virtual filesystem as env:spreadsheets — describe a workbook, read sheets as records, write and append rows, bridge to and from CSV. Paths in, paths out; cell value
