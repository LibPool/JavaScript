# goodreads-quote-scraper

> 标签: JavaScript

## 简介

A nightmarejs based webscraper for collecting quotes of a given author from [goodreads.com](https://www.goodreads.com/quotes/search?utf8=%E2%9C%93&q=george+bernard+shaw&commit=Search). The quotes are then saved as a prettified json file in your root direc
