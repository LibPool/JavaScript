# guessit-js

> 标签: codec, episode, filename, guessit, media, metadata, movie, parser, release, resolution, scene, subtitle, tv, typescript, video

## 简介

Extract metadata (title, year, season, episode, codec, language, etc.) from media filenames — TypeScript port of Python guessit
