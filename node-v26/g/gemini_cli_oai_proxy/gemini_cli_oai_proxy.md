# gemini_cli_oai_proxy

> 标签: JavaScript

## 简介

通过 **OpenAI 兼容的 API** 提供 **Google Gemini 1.5 Pro** (或 Flash) 服务。   与已经支持 OpenAI 的客户端即插即用，例如 SillyTavern、llama.cpp、LangChain、VS Code 的 *Cline* 扩展等。
