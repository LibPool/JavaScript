# git-wik

> 标签: claude, code-intelligence, context-engineering, developer-tools, github, knowledge-graph, mcp, sqlite

## 简介

MCP server that builds a local relation graph of a GitHub repo's conversation history and serves token-efficient intelligence to Claude Code.
