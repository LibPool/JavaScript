# git-ingest

> 标签: ai-tools, automation, binary-detection, chatgpt-ready, cli, clipboard, code-ingestion, code-review, codebase-analysis, command-line-tool, cross-platform, developer-tools, documentation, file-processing, file-utilities, gitignore-support, llm-ready, nodejs, npm, open-source, performance, project-analysis, project-tree, streaming, text-generation

## 简介

Fast, AI-ready CLI tool that converts entire codebases into structured text files. Perfect for feeding projects to LLMs, code reviews, and documentation. Features streaming architecture, smart filtering, and cross-platform clipboard integration.
