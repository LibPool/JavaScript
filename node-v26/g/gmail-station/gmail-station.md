# gmail-station

> 标签: JavaScript

## 简介

Gmail provider for [`mailbox-station`](https://www.npmjs.com/package/mailbox-station). Wraps `@googleapis/gmail`, OAuth2 refresh, the `users.watch` lifecycle, Pub/Sub pull ingress, and a pure MIME parser.
