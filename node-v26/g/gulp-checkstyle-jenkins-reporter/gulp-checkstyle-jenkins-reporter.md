# gulp-checkstyle-jenkins-reporter

> 标签: checkstyle, gulp, jenkins, jscs, jshint, npm, reporter

## 简介

Advanced reporter for gulp-jshint and gulp-jscs to be used by Jenkins (Hudson). Writes output to an xml file.
