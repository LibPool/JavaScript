# gitleash

> 标签: agent, ai, aider, claude-code, codex, cursor, git, guardrail, hook, pre-commit, safety

## 简介

Keep your AI coding agent on a leash: a zero-config git hook that blocks reckless commits and force-pushes — huge diffs, deleted tests, hardcoded secrets, CI edits — before they land.
