# grunt-git-changedfiles

> 标签: JavaScript

## 简介

Grunt plugin to generate a list of the files that have changed in your Git working tree.

## 官网

- 源码仓库：git://github.com/causata/grunt-git-changedfiles.git
- npm 页面：https://www.npmjs.com/package/grunt-git-changedfiles
