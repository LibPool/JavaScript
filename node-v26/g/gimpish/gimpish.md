# gimpish

> 标签: agent, background-removal, canvas, cli, compositing, image, image-editing, layers, llm

## 简介

Agent-native image composition: a CLI + scene.json contract + live browser editor, built for LLM workflows. Layers, masks, local background removal, deterministic rendering.
