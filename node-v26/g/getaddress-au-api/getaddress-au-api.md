# getaddress-au-api

> 标签: address, address-lookup, australia, australian, autocomplete, getaddress, gnaf, postcode

## 简介

Node.js client for the getAddress() Australian address API: autocomplete, full G-NAF address look-up, nearest addresses, suburb and postcode locations, typeahead, validate, distance, and usage. The same shape as the UK getaddress-api package.
