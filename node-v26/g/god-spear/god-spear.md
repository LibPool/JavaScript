# god-spear

> 标签: JavaScript

## 简介

A minimal security gate for AI projects: - **Spear-Core**: explicit trust-boundary rules with **hard fail-fast** checks - **Spear-Trace**: tamper-evident **hash-chained** action trace (black-box logging) - **Reports**: JSON + HTML, generated locally and i
