# gitography

> 标签: analytics, cli, contributors, developers, git, heatmap, html, report, statistics, visualization, wrapped, zero-dependency

## 简介

Spotify Wrapped for your Git repository. A zero-dependency CLI that turns any repo's history into a beautiful, self-contained interactive HTML report.
