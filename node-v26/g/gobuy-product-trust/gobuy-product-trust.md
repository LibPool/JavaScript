# gobuy-product-trust

> 标签: ai-agents, e-commerce, mcp, mcp-server, product-trust, reviews

## 简介

Marketplace-evidence trust scores for AI agents — a 0-100 Evidence Score with observed/missing signals for Amazon, Walmart, Target, and Best Buy listings. Public streamable HTTP endpoint at https://mcp.gobuy.ai/mcp, no API key.
