# githubrelay

> 标签: claude-code, cli, codex, copilot, gateway, llm, opencode

## 简介

One-line installer for GitHub Model Relay. Turns your GitHub Copilot subscription into a local API for Claude Code, Codex, OpenCode, and Pi.
