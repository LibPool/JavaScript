# git-team-report

> 标签: blame, cli, code-quality, dashboard, git, report, team

## 简介

Generate a graphical team git & code-quality report from any repo. Numbers are pulled live from git; grades and findings live in a config you edit. Incremental: each build shows only what changed since the last one.
