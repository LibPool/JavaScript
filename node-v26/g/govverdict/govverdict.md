# govverdict

> 标签: JavaScript

## 简介

Cross-tool meta-reviewer for the agent-gov suite. Ingests JSON reports from ScopeTrail, PolicyMesh, CapabilityEcho, TaskBound, and SessionTrail; dedupes findings; renders one consolidated review.
