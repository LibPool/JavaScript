# gnews-scraper

> 标签: Google News API, Google News scraper, crawler, data scraping, gnews, gnews scraper, gnews-scraper, google, google crawler, google news, news, news crawler, news scraper, scraper, scraping, scraping library, web crawler, web crawling, web scraping

## 简介

GNewsScraper is a TypeScript package that scrapes article data from Google News based on a keyword or phrase. It returns the results as an array of JSON objects, making it convenient to access and use the scraped information
