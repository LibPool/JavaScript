# grunt-croc-qunit

> 标签: CROC, Istanbul, code coverage, codecoverage, grunt, gruntplugin, phantomjs, qunit, testing

## 简介

Run QUnit unit tests in headless PhantomJS with code coverage support via Istanbul. Despite grunt-contrib-qunit it has no direct dependency on phantomjs module
