# git-mailmap

> 标签: author, check-mailmap, committer, contributor, git, gitmailmap, identity, javascript, mailmap, parser, typescript

## 简介

Parse, resolve, and serialize Git .mailmap files in JavaScript and TypeScript to canonicalize author and committer identities.
