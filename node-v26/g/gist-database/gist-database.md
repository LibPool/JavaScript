# gist-database

> 标签: gist, gist key value store, gist-database, gist-db, gistdb, github-database, key value, simple key value

## 简介

Transform gist into your personal key/value data store. Pair this with Next.js and incremental static regeneration to add dynamic content to your static site. Built with TypeScript.
