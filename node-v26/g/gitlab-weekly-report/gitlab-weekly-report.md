# gitlab-weekly-report

> 标签: JavaScript

## 简介

从 GitLab 提交记录自动生成中文工作周报，支持 **MCP 模式**（Claude Code 原生调用）和 **CLI 模式**（命令行直接运行）。

## 官网

- npm 页面：https://www.npmjs.com/package/gitlab-weekly-report
