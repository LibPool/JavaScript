# gazekit

> 标签: a11y, accessibility, assistive-technology, erişilebilirlik, eye-tracking, gaze, göz-takibi, hands-free, mediapipe, webcam

## 简介

Cihaz üstü göz takibiyle web sitelerinde erişilebilir gezinme (scroll, geri/ileri) — tek seferlik kalibrasyon, MediaPipe tabanlı, tüm tarayıcılarda çalışan, framework-bağımsız erişilebilirlik kütüphanesi.
