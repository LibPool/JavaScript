# gammarouter

> 标签: front-proxy, proxy, reverse-proxy, routing

## 简介

Routes incoming requests to aplications running in less privileged ports. Can be configured during runtime via its REST api. Check also the package gammarouter-api for a nodejs client and a CLI tool
