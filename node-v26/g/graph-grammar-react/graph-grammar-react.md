# graph-grammar-react

> 标签: d3, editor, graph-editor, graph-grammar, graph-rewriting, react, visualization

## 简介

Embeddable React editor for the graph-grammar engine: a complete visual graph-rewriting workbench (rule editor + live D3 canvas) and the building blocks to compose your own.
