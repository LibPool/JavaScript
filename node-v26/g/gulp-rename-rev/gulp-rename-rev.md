# gulp-rename-rev

> 标签: gulp, gulp rename, gulp rev, gulpplugin, rename, rev

## 简介

gulp插件，文件根据特定的格式进行修改版本号，例如：a.js->a-1.1.1.js,b-1.2.3.min.js->b-1.3.3.min.js
