# gitignore-reader-x

> 标签: check-ignore, eslint, excludesfile, git, gitignore, gitmodules, glob, ignore, info-exclude, matcher

## 简介

Reads gitignore rules the way git does: from every source, with exact semantics. Gives a fast matcher and patterns for ESLint's ignores
