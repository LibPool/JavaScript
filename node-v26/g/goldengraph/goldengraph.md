# goldengraph

> 标签: communities, edge, entity-resolution, goldengraph, graph, knowledge-graph, neighborhood, wasm

## 简介

GoldenGraph knowledge-graph engine — build / query / community over resolved entities. Edge-safe TypeScript surface over the same pyo3-free Rust kernel as the Python/C bindings, via opt-in WebAssembly.
