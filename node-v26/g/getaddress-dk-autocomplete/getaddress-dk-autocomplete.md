# getaddress-dk-autocomplete

> 标签: address, address-autocomplete, address-lookup, adresse, autocomplete, danish, dar, dawa, dawa-autocomplete2, denmark, getaddress, postnummer

## 简介

Danish address autocomplete for any text input, powered by the getAddress() DAWA-compatible address API. Built on DAWA's own dawa-autocomplete2 widget: pass a domain token and keep your existing options and select handler.
