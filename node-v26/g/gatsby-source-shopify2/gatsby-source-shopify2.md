# gatsby-source-shopify2

> 标签: gatsby, gatsby-plugin, gatsby-source-plugin, shopify

## 简介

Gatsby source plugin for building websites using Shopfiy as a data source. This is based on the original plugin along with some bug fixes for gatsby v2 and downloading images for products.
