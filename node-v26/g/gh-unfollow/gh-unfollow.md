# gh-unfollow

> 标签: batch-unfollow, bulk-unfollow, cli, cross-platform, developer-tools, followers, following-cleanup, github, github-api, github-following, github-tools, mass-unfollow, rate-limiting, unfollow, zero-dependencies

## 简介

Bulk unfollow GitHub users with premium terminal UI and smart rate limiting. Features: whitelist, inactive cleanup, non-mutual, interactive, backup/restore.
