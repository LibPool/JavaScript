# geiger-scan

> 标签: agent-security, ai-agents, audit, mcp, scanner, security, supply-chain

## 简介

A Geiger counter for AI agents: one read-only command that inventories every agent, harness, MCP server, plugin, and AI extension on a machine — and what each can touch.
