# gswrx-uilib

> 标签: JavaScript

## 简介

The gswrx-uilib is a component library for Angular which contains reusable components made and used internally in gswrx. gswrx-uilib has been made open-source for the purpose of providing (reusable) components to developers in the open-source community,
