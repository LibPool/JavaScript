# glow-card-react

> 标签: a11y, animation, card, cursor, glow, glow-card, hover, pointer, react, spotlight, ui

## 简介

Cursor-tracking glow card effect for React — a tiny, dependency-free spotlight that follows the pointer. Works with React 18 and 19.
