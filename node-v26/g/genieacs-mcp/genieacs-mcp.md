# genieacs-mcp

> 标签: acs, cpe, cwmp, genieacs, mcp, model-context-protocol, tr-069

## 简介

MCP server that bridges any GenieACS (TR-069 ACS) instance, exposing device data, firmware management, and CPE actions over JSON-RPC
