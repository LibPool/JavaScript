# goo-buddies

> 标签: agent, ai, animation, avatar, blob, canvas, chatbot, jelly, llm, mascot, physics, react, slime, soft-body, status

## 简介

Squishy soft-body slime buddies for React that show what your AI agent is doing: thinking, searching, listening, speaking and more. 2D canvas, spring-mass physics, no WebGL, zero runtime dependencies.
