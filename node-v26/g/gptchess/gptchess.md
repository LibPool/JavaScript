# gptchess

> 标签: API wrapper, Artificial intelligence, Board state, CLI application, Chess AI, Chess engine, Chess programming, Chessboard, Command-line interface, GPT-3, Game development, Game logic, Move generation, Move suggestion, NPM package, OpenAI

## 简介

GPTChess is an npm package that provides a chess AI powered by the OpenAI GPT-3 model. It allows you to generate AI moves based on the current chessboard state.
