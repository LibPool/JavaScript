# getseatbelt

> 标签: ai, cli, e2e, merge, playwright, qa, seatbelt, testing

## 简介

QA for AI-coded apps, before you merge. A local-first CLI that opens a real visible browser, replays your critical flows, captures evidence, and returns a merge verdict plus a paste-ready fix prompt for Claude Code / Cursor / Codex.
