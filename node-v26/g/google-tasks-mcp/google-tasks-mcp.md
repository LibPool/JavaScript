# google-tasks-mcp

> 标签: agent, claude, google-tasks, llm, mcp, model-context-protocol, tasks, todo

## 简介

MCP server for Google Tasks with full task-list CRUD and a change-harvesting diff tool. One auth command, then npx-runnable anywhere.
