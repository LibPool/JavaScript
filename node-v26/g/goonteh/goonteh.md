# goonteh

> 标签: dnd, drag-and-drop, mobile, pointer-events, react, react-native, solid-js, solidjs, svelte, touch, vue

## 简介

Tiny pointer-based drag-and-drop that works on touch and never shows the no-drop cursor. Framework-agnostic core plus SolidJS, React, Vue, Svelte, native DOM, and React Native adapters.
