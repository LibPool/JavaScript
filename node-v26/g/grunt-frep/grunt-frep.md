# grunt-frep

> 标签: find, grunt task, gruntplugin, javascript find and replace, regex, regex find and replace, regex search replace, regular expression, regular expression find and replace, replace, replace text in javascript

## 简介

A find and replace Grunt plugin, based on frep. Replace strings with an array or object of RegExp or string replacement patterns.
