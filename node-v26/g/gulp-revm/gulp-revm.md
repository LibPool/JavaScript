# gulp-revm

> 标签: asset, assets, cache, expire, gulpplugin, hash, optimize, rev, revision, revving, static, version, versioning

## 简介

Static asset revisioning by appending content hash to filenames: unicorn.css => unicorn.css?d41d8cd98f
