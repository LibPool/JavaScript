# gh-issue-tracker

> 标签: bug-report, deduplication, edge, error-reporter, error-tracking, fingerprinting, github-issues, screenshot, sentry-alternative

## 简介

Lightweight error tracking and user bug reports that create GitHub Issues instead of sending to SaaS. Screenshot capture, deduplication, fingerprinting, and rate limiting built-in. Edge-native, zero deps.
