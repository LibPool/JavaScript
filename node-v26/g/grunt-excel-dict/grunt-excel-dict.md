# grunt-excel-dict

> 标签: excel, grunt, gruntplugin, language, locale, multilanguage, translate, translation, vocabulary, xlsx

## 简介

Generate file for translations, the supported modes are as follows: Excel to Json/Json to Excel; Excel to Properties/Properties to Excel
