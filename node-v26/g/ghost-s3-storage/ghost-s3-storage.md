# ghost-s3-storage

> 标签: amazon, aws, blog, ghost, plugin, s3, storage

## 简介

Store Ghost's media at AWS S3 storage. Modified version of ghost-s3 (https://www.npmjs.org/package/ghost-s3) and ghost-aws-s3 (https://github.com/kimar/ghost-aws-s3)
