# git-service-adapter

> 标签: adapter, cloud configuration, configuration, environment, environment management, environment variables, git, github, remote, remote config

## 简介

A configurable plug-and-play wrapper around the GitHub v3 API that allows applications to leverage GitHub as a remote configuration storage service.
