# gdocs-comments-mcp

> 标签: ai-agent, anchored-comments, browser-automation, claude, comments, copilot, cursor, document-review, gdocs, google-docs, google-drive, google-workspace, inline-comments, mcp, mcp-server, model-context-protocol, modelcontextprotocol, playwright

## 简介

MCP server that adds range-anchored (inline) comments to Google Docs — the one comment operation the Google Docs/Drive APIs cannot do — by driving a real logged-in Docs session with Playwright.
