# gatsby-theme-tosh

> 标签: gatsby, gatsby-plugin, gatsby-theme

## 简介

A retro [Gatsby Theme](https://gatsbyjs.org/docs/themes) based on old Macintosh UIs. Built with [Theme UI](https://theme-ui.com).
