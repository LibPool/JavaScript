# glassparency

> 标签: apple, backdrop-filter, glass, glassmorphism, liquid-glass, react, react-three-fiber, refraction, three, ui, webgl

## 简介

Apple-style Liquid Glass for the web: real refraction of the page (WebGL + live SVG filters), squircle rims, specular light, liquid morphing, light/dark themes and an automatic CSS fallback. React hooks plus a no-React script for any site.
