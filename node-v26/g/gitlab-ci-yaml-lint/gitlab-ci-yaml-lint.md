# gitlab-ci-yaml-lint

> 标签: log, log manager, logger, logging, utils

## 简介

Replacement for [gitlab-ci-lint](https://www.npmjs.com/package/gitlab-ci-lint) that does not use deprecated packages. (as of 07/02/2022). Please read it's readme or use `gitlab-ci-lint --help` to see all options
