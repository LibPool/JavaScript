# gulp-replace-placeholder-image

> 标签: JavaScript

## 简介

Release all .jpg/.jpeg/.png/.gif/.svg to placeholder image, others will be copied by default.

- npm 页面：https://www.npmjs.com/package/gulp-replace-placeholder-image

- Node 要求：>=8.0.0
