# greekumipsum-cli

> 标签: cli, generator, greek, greekum, ipsum, lorem, lorem-ipsum

## 简介

Generate random greek paragraphs, words, sentences and characters. Uses the Greekum Ipsum script by Krzysztof Szewczyk.
