# geotager

> 标签: avif, batch, cli, command-line, exif, exif-cli, geotag, geotagging, gps, heic, jpeg, location, lossless, metadata, mp4, png, privacy, remove-exif, strip-exif, tiff, webp

## 简介

Read, write and remove EXIF GPS geotags from the command line: photo and video location metadata for JPEG, HEIC, PNG, WebP, TIFF, MP4. Nothing is uploaded.
