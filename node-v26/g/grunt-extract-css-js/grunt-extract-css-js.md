# grunt-extract-css-js

> 标签: gruntplugin

## 简介

自动合并页面中的所有外链javascript 和css，并分别生成一个独立的javascript 和css文件

- 官网：https://github.com/slalx/grunt-extract-css-js
- 源码仓库：git://github.com/slalx/grunt-extract-css-js.git
- npm 页面：https://www.npmjs.com/package/grunt-extract-css-js
