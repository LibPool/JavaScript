# grunber-mcp-server

> 标签: ai-tools, anthropic, claude, grunber, junk-removal, llm, mcp, model-context-protocol, web-scraping

## 简介

Servidor MCP com ferramentas de saudação e consulta ao site da Grunber. Inclui 2 ferramentas: saudação multilíngue e web scraping do site Grunber.
