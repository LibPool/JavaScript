# grunt-webdriver

> 标签: bdd, cucumber, grunt, gruntplugin, jasmine, mocha, plugin, saucelabs, selenium, tdd, webdriver, webdriverio, webdriverjs

## 简介

grunt-webdriver is a grunt plugin to run selenium tests with the WebdriverIO test runner
