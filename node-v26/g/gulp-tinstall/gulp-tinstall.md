# gulp-tinstall

> 标签: bower, gulpplugin, install, npm

## 简介

Automatically install npm and bower packages if package.json or bower.json is found in the gulp file stream respectively

- 官网：https://github.com/slushjs/gulp-install
- 源码仓库：git://github.com/slushjs/gulp-install
- npm 页面：https://www.npmjs.com/package/gulp-tinstall
