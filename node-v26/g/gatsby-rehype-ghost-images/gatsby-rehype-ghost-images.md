# gatsby-rehype-ghost-images

> 标签: gatsby, gatsby-plugin, ghost, ghost-cms, html, jamify, rehype

## 简介

Gatsby rehype plugin that rewrites absolute image links to relative image links coming from a Ghost CMS.
