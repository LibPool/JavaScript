# gulp-node-debug

> 标签: debug, gulpplugin, node-debug, node-inspector

## 简介

This project is not maintained anymore! ---- Run node-debug from your gulp build: 1. Runs node-inspector. / 2. Runs the supplied script in debug mode / 3. Opens the user's browser, pointing it at the inspector.
