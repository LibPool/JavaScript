# govee-h6006-web

> 标签: ble, bluetooth, govee, h6006, music-reactive, rgb, smart-bulb, web-bluetooth

## 简介

Browser SDK to control a Govee H6006 RGB bulb over Web Bluetooth (no app, no cloud), including a music-reactive engine driven by Web Audio.
