# gitbap-try

> 标签: clone, gitbap, github, korean, sandbox, try

## 简介

깃밥(gitbap) — 아무 GitHub 레포나 안전하게 한 줄로 clone·설치·실행. 콘텐츠 안전 스캔 → 샌드박스 clone → 스택 자동감지 설치 → 실행법 안내.
