# gatsby-remark-a11y-emoji

> 标签: a11y, emoji, gatsby, gatsby-plugin, remark

## 简介

Gatsby Plugin to make Emoji in Markdown accessible. Wraps Emoji in a <span>-Tag with role and aria-label attributes.
