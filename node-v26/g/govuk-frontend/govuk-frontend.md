# govuk-frontend

> 标签: design system, frontend, govuk, template

## 简介

GOV.UK Frontend contains the code you need to start building a user interface for government platforms and services.

## 官网

- 官网：https://frontend.design-system.service.gov.uk/
- 源码仓库：git+https://github.com/alphagov/govuk-frontend.git
- npm 页面：https://www.npmjs.com/package/govuk-frontend
