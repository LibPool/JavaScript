# gbaudio

> 标签: apu, audio, chiptune, dmg, emulator, game-boy, gameboy, synthesizer, wav

## 简介

Game Boy APU (DMG sound) emulator and audio compiler in TypeScript: a port of stoneface86/gbapu, plus a compiler for register command streams, offline PCM rendering and WAV export.
