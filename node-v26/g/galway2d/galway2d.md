# galway2d

> 标签: 2d-materials, computational-chemistry, crystallography, dft, materials-science, vasp

## 简介

2D Materials DFT Toolkit CLI — University of Galway. Search 550+ materials, generate VASP INCAR/KPOINTS, validate POSCAR files.
