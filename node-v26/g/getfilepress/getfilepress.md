# getfilepress

> 标签: JavaScript

## 简介

FilePress — file-based Markdown blog engine. Link this package from a content-only site (config + posts), then run `filepress build`.

- 源码仓库：git+https://github.com/Catalyst-Forge-LLC/filepress.git
