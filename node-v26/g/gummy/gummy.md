# gummy

> 标签: JavaScript

## 简介

A type-safe PostgreSQL schema builder and CRUD layer for [Kysely](https://github.com/kysely-org/kysely), with built-in validation and [Zod](https://github.com/colinhacks/zod) schema generation.
