# grunt-file-blocks-copy

> 标签: TypeScript, css, fileblocks, gruntplugin, html, insert, prep, prepare, script

## 简介

A Grunt task that prepares an HTML, JavaScript or Typescript file by inserting or removing tags into marked blocks for each file that matches a source pattern. This is a fork, the original not work.
