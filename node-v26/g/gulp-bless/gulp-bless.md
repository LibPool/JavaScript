# gulp-bless

> 标签: JavaScript

## 简介

CSS post-processor which splits CSS files suitably for Internet Explorer < 10. Bless + Gulp = gulp-bless.

## 官网

- 官网：http://github.com/BlessCSS/gulp-bless
- 源码仓库：git://github.com/BlessCSS/gulp-bless.git
- npm 页面：https://www.npmjs.com/package/gulp-bless
