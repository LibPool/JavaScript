# gatsby-source-strapi-v5-graphql

> 标签: gatsby, gatsby-plugin

## 简介

Source plugin for pulling documents into Gatsby-v4 from a Strapi-v5 API using the Strapi GraphQL plugin. (Fork of gatsby-source-strapi-graphql)
