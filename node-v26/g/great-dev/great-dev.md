# great-dev

> 标签: cache-clear, chokidar, cli, dev-tool, development, file-watcher, file-watcher-cli, hot-reload, nodemon, typescript

## 简介

A CLI tool similar to nodemon that watches files for changes, clears cache, and hot reloads only changed files.
