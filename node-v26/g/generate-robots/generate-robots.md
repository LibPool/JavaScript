# generate-robots

> 标签: boilerplate, build, cli, cli-app, command-line, create, dev, development, framework, front, frontend, generate, generate-generator, generate-plugin, generategenerator, generateplugin, generator, init, initialize, new, plugin, project, projects, robots, scaffold, scaffolder, scaffolding, template, templates, webapp, yeoman, yo

## 简介

Generate a robots.txt for a web project (uses the robots.txt from HTML5 Boilerplate). This can be run from the command line when Generate is installed globally, or used as a plugin in another generator.
