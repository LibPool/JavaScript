# greybook-mcp

> 标签: claude-code, coding-agents, greybook, mcp

## 简介

Greybook for coding agents — when your agent hits an unexpected failure, it checks Greybook for what is working right now. Read-only advisory MCP server; opt-in anonymous outcome reporting; everything sent is logged locally, byte-exact.
