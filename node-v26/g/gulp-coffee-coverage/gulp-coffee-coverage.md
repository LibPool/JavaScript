# gulp-coffee-coverage

> 标签: coffee, coffee-coverage, coffee-script, coverage, gulp, gulpplugin, script

## 简介

gulp plugin for coffee-coverage. Compiles CoffeeScript into JavaScript with coverage logic provided by coffee-coverage.
