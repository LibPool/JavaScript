# generator-greg-react-webpack

> 标签: gergely vizvari, react, webpack, yeoman-generator

## 简介

1. npm install 2. npm run dev -> simple compiling for dev 3. npm run watch -> simple compiling for dev with watch 5. npm run build -> minified dist compiling
