# gulp-tsconfig

> 标签: gulpplugin, tsconfig, tsconfig.json, typescript

## 简介

Simple gulp plugin that creates a TypeScript project file ('tsconfig.json') for a given glob of sources. Supports ordering of project files via globs, too.
