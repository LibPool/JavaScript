# grokbotfun

> 标签: ai-agent, cursor, deploy, grok, mcp, modelcontextprotocol, pump.fun, pumpfun, solana, token

## 简介

MCP server that lets AI agents (Grok Bot, Cursor, Claude Code, etc.) deploy tokens on pump.fun — create + optional dev buy in one transaction
