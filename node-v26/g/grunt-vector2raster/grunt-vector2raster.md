# grunt-vector2raster

> 标签: app icons, convert, gruntplugin, phantomjs, raster images, svg, targeted sizes

## 简介

Converts svg's to multiple sizes of whatever image fileformat Phantom.js supports. Ideal for creating all the (phonegap) App icons you need based on one svg.
