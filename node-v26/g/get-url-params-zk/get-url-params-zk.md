# get-url-params-zk

> 标签: JavaScript

## 简介

**（1） 指定参数名称，返回该参数的值 或者 空字符串** **（2） 不指定参数名称，返回全部的参数对象 或者 {}** **（3） 如果存在多个同名参数，则返回数组** **（4） 不支持URLSearchParams方法** # get-url-params-zk **对数组进行格式化：如去重，去除所有有重复元素的元素，去除元素其它重复的元素**
