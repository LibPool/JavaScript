# github-actions-updater

> 标签: actions, cli, dependencies, github-actions, ncu, updater, version-check, workflow

## 简介

ncu for GitHub Actions — scans .github/workflows for outdated remote uses: references and reports or updates them, with a polished colorful CLI.
