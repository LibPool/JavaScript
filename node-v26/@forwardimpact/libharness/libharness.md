# @forwardimpact/libharness

> 标签: agent, eval, facilitator, orchestration, supervisor, trace

## 简介

Autonomous agent team harness — coordinate a lead and participant agents in one async session, with eval, benchmark, and trace tooling to prove the changes worked.
