> 标签: ai, base, defi, honeypot, langchain, langchainjs, langgraph, pre-trade, token-safety, tool, trading-agent, x402

## 简介

Pre-trade token-safety gate for Base trading agents (LangChain.js tool): honeypot, sellability, admin-control and liquidity-vs-size checks via Grey Ridge /gate/swap, paid inline with x402 USDC ($0.008/call). Fails closed. Call before every swap.
