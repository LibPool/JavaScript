# @grey-ridge/x402-data-api-mcp

> 标签: JavaScript

## 简介

MCP stdio client for the x402-data-api — exposes crypto, chain, security, and enrichment tools via MCP protocol over stdin/stdout. Uses @x402/fetch + @x402/evm + viem for automated x402 micropayments (installer supplies their own wallet key).
