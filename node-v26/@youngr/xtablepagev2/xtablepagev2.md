# @youngr/xtablepagev2

> 标签: JavaScript

## 简介

xtablepage适用于vue2环境，依赖elementUI相关内容。 提供快速搭建包含顶部搜索、底部分页、新增、修改删除等功能的基础表格页面。 具体使用方式可参考安装后node包内的example文件夹
