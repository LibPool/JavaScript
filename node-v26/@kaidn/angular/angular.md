# @kaidn/angular

> 标签: JavaScript

## 简介

Angular bindings for Kaidn device intelligence. A DI service over @kaidn/fp, built from runtime API only so no Angular compiler is involved.

- 官网：https://kaidn.io/docs/quickstart/angular
- 源码仓库：git+https://github.com/Kaidn-io/kaidn-js.git
