# @springbird/effect-temporal

> 标签: durable-execution, effect, saga, temporal, typescript, workflow

## 简介

Run `effect/unstable/workflow` programs (Workflow / Activity / DurableClock / DurableDeferred) on a Temporal engine, plus durable mailboxes, updates, queryable state, versioning, schedules, and Nexus operations.
