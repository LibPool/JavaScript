# @gitcade/library

> 标签: behaviors, entity-component, game-components, gitcade, systems

## 简介

GitCade Component Library — game-agnostic, param-driven parts for the GitCade SDK: behaviors, systems, entities, UI, FX, and generated assets (art, audio, tilesets).
