# uk-drone-airspace-mcp

> 标签: airspace, claude, drone, flight-restriction-zone, mcp, model-context-protocol, notam, rights-of-way, uas, uk

## 简介

MCP server answering where a drone can legally take off and fly in the UK: NATS flight restriction zones, live NOTAMs, public rights of way and landowner rules
