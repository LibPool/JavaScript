# @nxgt/janus-telemetry

> 标签: authentication, identity, janus, observability, telemetry, typescript

## 简介

Observability for @nxgt/janus on @nxgt/telemetry: a span per flow and per permission check, and the security events worth an audit trail — never a login, an e-mail, a password, a session token, a one-time token or a session id
