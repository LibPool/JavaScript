# @nxgt/mail-presets

> 标签: email, i18n, maizzle, templates, transactional, vue

## 简介

Ready transactional e-mails for a Maizzle project built with @nxgt/mail-ui and @nxgt/mail-i18n — verify-email, reset-password, sign-in-code, magic-link, new-sign-in, welcome, invitation… in en and fr — with their built HTML as samples.
