# @nxgt/telemetry-hono

> 标签: hono, middleware, observability, opentelemetry, telemetry, traceparent, tracing, typescript

## 简介

A Hono middleware for @nxgt/telemetry: one server span per request, W3C traceparent continuation, and the route as the span name
