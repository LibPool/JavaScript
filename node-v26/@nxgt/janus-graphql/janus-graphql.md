# @nxgt/janus-graphql

> 标签: authentication, authorization, directives, envelop, graphql, graphql-yoga, identity, janus, typescript

## 简介

GraphQL for @nxgt/janus: an envelop plugin with the signed-in user on the context, fields guarded by @authenticated, @fresh and @permission, and every error with the status it deserves
