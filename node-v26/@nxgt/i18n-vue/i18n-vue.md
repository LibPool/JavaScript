# @nxgt/i18n-vue

> 标签: i18n, icu, messageformat, nuxt, vite, vue

## 简介

i18n for a Vue or Nuxt app on @nxgt/i18n's conventions: ICU catalogues checked for missing keys and argument kinds, t() typed and completed in templates, reactive locale switching, and a Nuxt module that resolves the locale on the server.
