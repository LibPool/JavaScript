# @nxgt/janus-webhooks-redis

> 标签: janus, queue, redis, standard-webhooks, typescript, webhooks

## 简介

The Redis queue for @nxgt/janus-webhooks on @nxgt/redis: deliveries that outlive the process, claimed atomically under a lease
