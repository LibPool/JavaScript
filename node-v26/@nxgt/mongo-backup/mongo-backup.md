# @nxgt/mongo-backup

> 标签: backup, bun, change-streams, gridfs, mongodb, restore, snapshot, typescript

## 简介

MongoDB for @nxgt/backup: a full backup read at one cluster time, incremental ones from the change stream, and a restore that lands each collection whole or not at all
