# @nxgt/janus-kit

> 标签: authentication, authorization, identity, janus, mongodb, postgresql, redis, typescript

## 简介

@nxgt/janus wired in one call, one subpath per database — PostgreSQL through Drizzle, MongoDB — with sessions in Redis, telemetry, a health check and a close
