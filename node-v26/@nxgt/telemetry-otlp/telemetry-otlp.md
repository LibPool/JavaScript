# @nxgt/telemetry-otlp

> 标签: collector, logging, observability, opentelemetry, otlp, telemetry, tracing, typescript

## 简介

An OTLP/HTTP JSON exporter for @nxgt/telemetry: logs and traces to any OpenTelemetry collector, over fetch, with no OpenTelemetry SDK
