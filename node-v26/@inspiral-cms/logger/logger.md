# @inspiral-cms/logger

> 标签: grafana, inspiral, logger, loki, promtail, structured-logging, supabase

## 简介

Unified structured logger for Inspiral platform (UI, MCP, Workers). Logs to Supabase, stdout (Promtail/Loki), and optionally Loki API.
