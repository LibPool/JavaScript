# @fluojs/websockets

> 标签: fluo, gateway, realtime, upgrade, websocket, ws

## 简介

Decorator-based WebSocket gateway authoring core for Fluo, with explicit Node, Bun, Deno, and Cloudflare Workers raw websocket bindings on dedicated subpaths.
