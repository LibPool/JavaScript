# @selimeselime/docforge-mcp

> 标签: agent-payments, base, chart, document-generation, docx, invoice, mcp, pdf, pptx, usdc, x402, xlsx

## 简介

MCP server for DocForge — machine-payable document & media generation (PDF, DOCX, XLSX, PPTX, charts, invoices, diagrams, screenshots) over x402 (USDC on Base). Free capability discovery; optional auto-pay wallet.
