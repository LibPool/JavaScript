# @derkatzelp/vuetemplateorganizer

> 标签: Vue, Vue SFC, build tool, code formatting, configuration, development tool, front-end, node, npm, template, template blocks, template organizer, template sorting, tooling, web development, workflow optimization

## 简介

VueTemplateOrganizer is a tool that allows you to configure the sorting of Template blocks in Vue Single File Components (SFCs).
