# leanpdf

> 标签: browser, compress, compression, downscale, image, jpeg, low-memory, pdf, sharp, streaming

## 简介

Small, low-memory, streaming PDF toolkit for browsers, Node and Bun. First tool: shrink PDFs by recompressing their images, copying everything else byte for byte.
