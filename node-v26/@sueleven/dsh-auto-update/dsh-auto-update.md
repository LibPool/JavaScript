# @sueleven/dsh-auto-update

> 标签: auto-update, deepseek-harness, dsh, dsh-plugin, plugin-manager

## 简介

DSH 插件：每次打开 DeepSeek Harness 时自动检查已下载并启用的插件有没有新版本，在界面上列出并询问是否更新，确认后更新到最新版。
