# @exadev/process-graph-store-contract

> 标签: conformance, contract, orpc, process-model, store

## 简介

The persistence port for process models and run overlays as an oRPC contract: versioned procedures with Zod inputs and outputs, an in-memory fake and a conformance kit every store adapter runs.
