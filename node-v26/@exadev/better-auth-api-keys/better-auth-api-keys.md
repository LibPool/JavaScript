# @exadev/better-auth-api-keys

> 标签: api-key, api-keys, authentication, better-auth, better-auth-plugin, cloudflare-workers, hmac

## 简介

A better-auth plugin for long-lived API keys: checksummed keys checked offline, stored only as a peppered HMAC, found with one indexed lookup, with a throttled last-used write and no session hook.
