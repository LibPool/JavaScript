# @ngx-docs-markdown-kit/parser-md-image

> 标签: angular, docs, image, markdown

## 简介

Extension de @ngx-docs-markdown-kit/parser-md que reconoce un fence con lang="image" (src/alt/align/width/caption) y expone el componente de Angular que lo renderiza como figura enriquecida. Opcional: sin este paquete, un ![alt](url) normal sigue funciona
