# @snapsite/cms-editor

> 标签: cms, editor, headless, in-page, react, snapsite, supabase

## 简介

Embeddable headless-CMS editor for @snapsite client sites — CMSProvider, EditableText, EditableImage, EditableSection, MediaPicker, Shadow-DOM toolbar.
