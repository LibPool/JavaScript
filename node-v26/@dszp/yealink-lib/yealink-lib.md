# @dszp/yealink-lib

> 标签: cloudflare-workers, integration, provisioning, rps, voip, yealink, ymcs

## 简介

Portable, Node-free toolkit for Yealink's device-management cloud (YMCS and RPS, one Open API): OAuth2 client-credentials auth with the timestamp/nonce headers, split read/write API clients, and skip/limit/autoCount pagination. Runs unchanged in a Cloudfl
