# @nevescloud/mcp-rtc-bridge-tab

> 标签: bridge, browser, mcp, model-context-protocol, p2p, webmcp, webrtc

## 简介

Browser library that takes a remote MCP-RTC server's tools and re-exposes them via WebMCP, so any local Claude with a WebMCP consumer (e.g. the Anthropic Chrome extension) can call them — no Node bridge required.
