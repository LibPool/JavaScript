# @drxiaozhi/jspulse

> 标签: alsa, android, audio, bun, buninu, ffi, opensl-es, pulseaudio, termux

## 简介

A Bun/JavaScript implementation of PulseAudio’s native protocol for Linux and Android, with ALSA audio, native OpenSL ES, and direct ioctl mixer control
