# @agentstxtdev/herald-schema

> 标签: agentic-web, agents-json, agents-txt, json-schema, schema, zod

## 简介

Zod schemas for the agents.json wire format, with JSON Schema 2020-12 derivation. Single source of truth for runtime validation, TypeScript types, and the public agents.json JSON Schema served by agents-txt.com.
