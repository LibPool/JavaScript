# @delicious-ai/bidlens-capacitor

> 标签: JavaScript

## 简介

Capacitor bridge for <bidlens-widget>: native iOS and Android photo picking that keeps the EXIF/LiDAR/GPS metadata the web view strips. Import it once and the widget uses it wherever the plugin is available.
