# @g3-cscec/app-runtime

> 标签: JavaScript

## 简介

1. 消费 no-code 搭建的页面，打接口（入参pageCode）获取页面的 ui-meta 2. 迭代页面的 meta 数据，调用各个组件提供的 bind 方法，逐步转换 meta 数据 3. 将转换完毕的 meta 数据，交给 G3Parse 渲染 4. 完成内部组件注册
