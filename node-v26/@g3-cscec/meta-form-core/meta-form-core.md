# @g3-cscec/meta-form-core

> 标签: JavaScript

## 简介

## 概述 - 基于 @formily/core、@formily/reactive-react 结合 ant Form 组件封装的 G3Form - @formily/core 提供表单值搜集、管理的能力 - @formily/reactive-react 提供响应式监听字段变化，以及联动重新渲染表单字段的能力 - ant Form、FormItem 提供表单布局、同时支持 Row、Col 嵌套布局
