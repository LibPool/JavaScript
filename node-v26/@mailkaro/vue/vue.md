# @mailkaro/vue

> 标签: drag-and-drop-email, email-builder, email-editor, email-templates, embeddable, mjml, newsletter-builder, unlayer-alternative, vue, vue-email-editor, vue3, white-label

## 简介

White-label, embeddable drag-and-drop email editor for Vue 3 — a drop-in for vue-email-editor and an Unlayer alternative. Loads from a hosted iframe (no editor code ships), and renders email-safe HTML + MJML from the API.
