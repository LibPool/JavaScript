# @hhxhhxhhx/hhx-mcp-audit

> 标签: JavaScript

## 简介

一个用于**前端工程依赖安全审计**的 MCP Server：在 Cursor 里调用 `auditPackage` 工具，即可对指定项目（本地路径或 GitHub 仓库）做依赖漏洞审计，并输出一份可直接阅读/分享的 Markdown 报告。
