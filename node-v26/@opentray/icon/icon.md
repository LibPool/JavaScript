# @opentray/icon

> 标签: app-icon, icns, ico, opentray, squircle, wasm

## 简介

Shared OpenTray app-icon generation kernel: glyph defaults, composition, squircle tiling, and ICNS/ICO/Linux PNG encoding on a WebAssembly image stack.
