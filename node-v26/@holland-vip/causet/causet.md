# @holland-vip/causet

> 标签: cli, git, merge, provenance, rebase, source-control, vcs, version-control

## 简介

An experimental causal source-control layer over Git, as the cst command: records how changes move between Git histories, with verifiable receipts, declared provenance, and portable metadata. Prebuilt for Windows x64 and Linux x64 (glibc).
