# @biks2013/cli-agent

> 标签: agent, ai, cli, langchain, langgraph, llm, react-agent

## 简介

Generic LangGraph ReAct agent that wraps external CLI binaries, auto-introspects their --help trees, and exposes the full bash/file/web cross-cutting toolkit backed by all eight standard LLM providers.
