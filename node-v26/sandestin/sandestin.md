# sandestin

> 标签: capability, cugel, function-reference, iframe, post-robot, postmessage, rpc, serdes, serialization, serialize, structured-clone, worker

## 简介

Serialize values across any boundary with functions and promises kept live. Pass a callback across, get back a reference that calls home; structured-clone native, JSON optional, lifetime and security in your hands.
