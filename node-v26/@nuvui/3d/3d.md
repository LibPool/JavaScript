# @nuvui/3d

> 标签: JavaScript

## 简介

A 3D model viewer for @nuvui/react, on react-three-fiber and three.js: glTF, GLB and STL files, from an address or picked by the person, turned with a pointer, a finger or the keyboard. Needs React 19.
