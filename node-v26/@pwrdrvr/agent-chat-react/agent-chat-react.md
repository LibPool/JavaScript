# @pwrdrvr/agent-chat-react

> 标签: acp, agent, chat, codex, presentational, react, ui

## 简介

Presentational React chat UI for agent-kit: renders agent-core neutral thread shapes and emits user intents. Props in, callbacks out — no IPC, bus, or transport.
