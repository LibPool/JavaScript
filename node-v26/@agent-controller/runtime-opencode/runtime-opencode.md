# @agent-controller/runtime-opencode

> 标签: adl, agent, agent-controller, ai-agents, anthropic, llm, opencode, runtime-adapter

## 简介

opencode runtime adapter for agent-controller — runs an ADL CompiledSpec against an opencode session via @opencode-ai/sdk and emits the NDJSON wire-event stream.
