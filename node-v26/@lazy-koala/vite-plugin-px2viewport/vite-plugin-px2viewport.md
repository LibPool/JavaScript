# @lazy-koala/vite-plugin-px2viewport

> 标签: adaptation, mobile, plugin, px-to-viewport, px2viewport, vite, vue, vw

## 简介

A Vite plugin that converts px units to vw for mobile viewport adaptation, supporting CSS, Vue SFC inline styles.
