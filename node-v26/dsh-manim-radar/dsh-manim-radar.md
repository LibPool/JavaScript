# dsh-manim-radar

> 标签: animation, data-visualization, deepseek-harness, dsh, dsh-plugin, manim, manim-radar, radar-chart, spider-chart

## 简介

DeepSeek Harness plugin: an agent skill for rendering animated radar (spider) charts with manim-radar — build, morph, compare, overflow and 3D dodecahedron reels from a JSON spec.
