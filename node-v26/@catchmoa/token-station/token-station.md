# @catchmoa/token-station

> 标签: gateway, model-routing, opensquilla, proxy, relay, router, token

## 简介

Token relay station — OpenSquilla 模型路由引擎的独立实现：ML 分类器 + 8 层 gate 策略 + HTTP 中转代理，为 Claude Code 提供多提供商 token 中转
