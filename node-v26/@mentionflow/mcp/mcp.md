# @mentionflow/mcp

> 标签: ai-visibility, claude, geo, llm-seo, mcp, mentionflow, model-context-protocol

## 简介

Ask Claude about your MentionFlow AI-visibility data. One line in your config: npx @mentionflow/mcp. Bridges Claude Desktop and other stdio MCP clients to MentionFlow's MCP server with your API key.
