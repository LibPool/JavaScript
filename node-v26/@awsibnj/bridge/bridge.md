> 标签: ajax, axios, bridge, cache, certificate-pinning, client, cookie, decompression-bomb, deduplication, dns-cache, encryption, fast, fetch, hmac, http, http2, https, idempotency, idn-homograph, integrity, lightweight, middleware, mtls, prototype-pollution, proxy, request, retry, secure, security, signing, ssrf, strict-security, tls

## 简介

A powerful, secure, and lightning-fast HTTP client for Node.js and browsers. Axios-compatible API with zero dependencies, automatic retry, TLS/mTLS, certificate pinning, HMAC request signing, response integrity verification, request deduplication, caching
