# @crewhaus/cloud-adapter-render

> 标签: JavaScript

## 简介

One-click deploy adapter for Render — generates a render.yaml blueprint + a Render-tuned Dockerfile and wraps the Render Deploy API for daemon target shapes (Section 44)
