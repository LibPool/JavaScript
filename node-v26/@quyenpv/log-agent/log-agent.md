# @quyenpv/log-agent

> 标签: alloy, log-shipper, logging, loki, mida, pm2

## 简介

MIDA log shipper agent — chạy Grafana Alloy (trong Docker) trên mỗi server PM2, tail ~/.pm2/logs và đẩy log JSON (từ @mida/logger) lên Loki trung tâm.
