# @icedesign/custom-codemirror-block

> 标签: block, ice, react

## 简介

CodeMirror是一款功能强大的代码高亮插件，他不仅提供了高亮功能，其丰富的方法属性也封装了缩进、自动换行、获取编辑文本、设置编辑文本、回退功能等多种实用效果
