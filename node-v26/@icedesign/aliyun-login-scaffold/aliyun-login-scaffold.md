# @icedesign/aliyun-login-scaffold

> 标签: JavaScript

## 简介

该模板风格类似于阿里云官网，适用于有注册登录类的管理后台，默认只内置了注册和登录页面，可根据实际业务场景选择其他物料进行开发。

## 官网

- 官网：https://alibaba.github.io/ice/scaffold-preview/ice-aliyun-login/index.html
- npm 页面：https://www.npmjs.com/package/@icedesign/aliyun-login-scaffold

- npm 安装：`npm install @icedesign/aliyun-login-scaffold`
- npm registry：https://registry.npmjs.org/@icedesign/aliyun-login-scaffold
