# @icedesign/scaffold-create-react-app

> 标签: JavaScript

## 简介

该模板基于 create-react-app 创建，使用 react-app-rewired 进行自定义配置，支持按需引入 ICE 基础组件，添加区块，主要适用于 0 到 1 开始搭建项目
