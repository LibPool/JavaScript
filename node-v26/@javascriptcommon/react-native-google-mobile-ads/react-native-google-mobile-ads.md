# @javascriptcommon/react-native-google-mobile-ads

> 标签: ad consent, admob, banner ad, gdpr, google ads, interstitial, mobile ads, react, react-native, rewarded ad

## 简介

Fork of react-native-google-mobile-ads migrated to the GMA Next-Gen SDK on Android (iOS keeps the classic Google Mobile Ads SDK). Banner, interstitial and app-open supported; native ads and rewarded are not migrated on Android.
