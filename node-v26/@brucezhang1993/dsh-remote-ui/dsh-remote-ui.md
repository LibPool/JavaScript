# @brucezhang1993/dsh-remote-ui

> 标签: JavaScript

## 简介

DSH Desktop 0.2.1-alpha.2 的远程管理界面，由主插件 bundle 一起安装。 从「插件 → DSH Remote Everywhere」或侧栏「远程设备」进入。 提供双向人工配对、设备管理和公网隧道控制；密钥和运行时留在宿主。 浏览器源码直接使用宿主 ModuleLoader 和共享 React，无独立应用或额外构建。
