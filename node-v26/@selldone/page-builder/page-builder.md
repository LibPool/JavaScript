# @selldone/page-builder

> 标签: JavaScript

## 简介

Selldone in-line page builder, built with Vue3, aims to replace Webflow, Wix, and EditorX as an open-source project. It's part of the Selldone business OS platform.

## 官网

- 官网：https://selldone.com
- 源码仓库：git+https://github.com/selldone/pagebuilder.git
