# @laikacms/astro

> 标签: astro, astro-integration, astro-loader, content-layer, content-management, headless-cms, laikacms

## 简介

Astro integration for Laika CMS: Content Layer loaders for astro:content, live collections for runtime reads, and a dev-server JSON:API backed by a repository of your choice.
