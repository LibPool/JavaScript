# @surea11y/binding-base

> 标签: a11y, accessibility, binding, internal, surea11y, wcag

## 简介

Shared, driver-agnostic scaffolding for surea11y's framework bindings (Playwright, Puppeteer, Selenium, WebdriverIO, Cypress) -- not useful on its own.
