# @ionic/capacitor-cordova-compat

> 标签: JavaScript

## 简介

Helper library to easily wrap Capacitor plugins to enable them to work in Cordova (the opposite direction from Capacitor's built-in Cordova compatibility)

- 官网：https://github.com/ionic-team/capacitor-cordova-compat#readme
- 源码仓库：git+https://github.com/ionic-team/capacitor-cordova-compat.git
- npm 页面：https://www.npmjs.com/package/@ionic/capacitor-cordova-compat
