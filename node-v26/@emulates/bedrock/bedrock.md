# @emulates/bedrock

> 标签: agentcore, aws, bedrock, converse, emulates, eventstream, llm, nova-sonic, service, titan

## 简介

Stateful, scriptable emulator of AWS Bedrock Runtime (Converse, ConverseStream, InvokeModel incl. Titan embeddings, Nova Sonic bidirectional streams over h2c) and AgentCore InvokeHarness, with exact event-stream framing.
