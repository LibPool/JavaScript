# @emulates/klaviyo

> 标签: email-marketing, emulates, events, json-api, klaviyo, service

## 简介

Stateful emulator of the Klaviyo events API: JSON:API event create (Ordered Product, Placed Order), event reads, unique_id dedupe, JSON:API errors and an outbox.
