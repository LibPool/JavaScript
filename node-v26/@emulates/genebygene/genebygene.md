# @emulates/genebygene

> 标签: emulates, gene-by-gene, genebygene, genomics, gxg, lab, nucleus, service

## 简介

Stateful emulator of Gene by Gene's Nucleus API v2 and auth host: tokens with credential blocking, catalog, shipping quotes, orders, kits, demographics, three-layer cancel, results with presigned downloads and S3 writes, subscriptions, and GxG-signed webh
