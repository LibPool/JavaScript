# @dbosoft/nextjs-app-core

> 标签: JavaScript

## 简介

Building blocks for dbosoft management apps: app shell with organization switcher and user menu, operation steps, schema-driven forms, fields that save on leave, and diffs; the general pieces come from @dbosoft/react-uicore with the texts filled from next
