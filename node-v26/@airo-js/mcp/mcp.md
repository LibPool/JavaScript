# @airo-js/mcp

> 标签: agent, airo, framework, mcp, model-context-protocol, tools

## 简介

Airo MCP — tool manifest emission + dispatch. Cartridges declare MCP tools via @airo-js/cartridge-kit; this package advertises and invokes them against the same post-Transformer snapshot the views render.
