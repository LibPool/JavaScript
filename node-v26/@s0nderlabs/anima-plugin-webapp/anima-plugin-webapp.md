# @s0nderlabs/anima-plugin-webapp

> 标签: 0g, agent, anima, gateway, plugin, relay, webapp, websocket

## 简介

Web-app gateway plugin for anima — a dumb reverse-tunnel client that lets a browser reach the agent from anywhere through the existing gateway HTTP+SSE contract
