# @s0nderlabs/anima-relay

> 标签: 0g, agent, anima, gateway, relay, tunnel, websocket

## 简介

Dumb reverse-tunnel relay for anima — lets a browser reach an on-chain agent from anywhere; the daemon dials out, the relay only pipes signed bytes
