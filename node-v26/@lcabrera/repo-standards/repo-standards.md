# @lcabrera/repo-standards

> 标签: adr, commit-convention, conventional-commits, git-hooks, monorepo, pull-request

## 简介

The gates that keep a repository's commits, branches, pull requests, issues, coordination register, architecture decisions and published packages to one enforced shape — as commands, so any repository can run them.
