# @faizalmunna/brainstem

> 标签: agent-skills, ai, claude-code, codex, mcp, model-context-protocol, repo-intelligence

## 简介

npm wrapper for brainstem, a portable AI engineering brain (repo intelligence, memory, skills) exposed over MCP to any coding agent. This is an installer/launcher for the real Python implementation, not a Node reimplementation -- see README.md.
