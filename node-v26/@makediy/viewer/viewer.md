# @makediy/viewer

> 标签: JavaScript

## 简介

Self-contained PCB Gerber viewer component for React 19 applications. Wraps `@sctg/tracespace-view` into a single drop-in component with MakeDIY branding, reduced chrome, and scoped styling.
