# @cratis/scene.blueprint.bookings

> 标签: blueprint, bookings, cratis, react, scene, ui

## 简介

Bookings for shared rooms, equipment and vehicles: a booking calendar, a booking list, a booking page, the resources and a wizard that books one in four steps.
