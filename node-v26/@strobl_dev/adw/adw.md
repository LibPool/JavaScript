# @strobl_dev/adw

> 标签: agents, ai-workflow, claude-code, codex, opencode, skills

## 简介

Single-source agent & skill definitions for Claude Code, Codex, and OpenCode, generated per project from a small config. Language-agnostic: usable in any repo (incl. C#/.NET) via npx; only requires Node to run the generator.
