# @lenorin/dsh-tauri-launcher

> 标签: JavaScript

## 简介

DSH Web 插件：基于 Tauri 2 的 DeepSeek Harness 桌面启动器，自动联动桌面快捷方式，exe 路径与探测窗口可配置。
