# @killki/mock-fast

> 标签: api, api-mocking, auth, cli, contract-testing, cors, dev-server, development, docker, dsl, error-injection, express, fake-api, faker, fixtures, handlebars, http-mock, json-server, latency, mock, mock-api, mock-server, mockoon, mocks-server, prototyping, rate-limit, rest, rest-api, stub, templating, test-server, testing

## 简介

Zero-config HTTP mock server with a small, scalable JSON DSL — nested routes, inherited auth, error injection, variable latency, per-user rate limiting, Faker templating, hot reload, and one-command Docker deploy. A lightweight json-server / Mockoon alter
