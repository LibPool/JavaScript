# @anchrd/connectors

> 标签: JavaScript

## 简介

One MCP server for every external service a company connects (GlitchTip, GitHub, …). Callers sign in with a Gate token; each connector is an interface of the Gate service `connectors`, each tool a function on it, so Gate roles decide who may use which too
