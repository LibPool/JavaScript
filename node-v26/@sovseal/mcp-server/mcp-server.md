> 标签: aes-256-gcm, ai-agent, ai-memory, claude, cursor, encryption, local-first, mcp, mem0-alternative, memory, model-context-protocol, privacy, sovseal, zero-knowledge

## 简介

Give Claude, Cursor, and every MCP client one shared memory that never leaves your machine. On-device embeddings, 10 ms recall, encrypted sync.
