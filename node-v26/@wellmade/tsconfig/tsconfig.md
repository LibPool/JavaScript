# @wellmade/tsconfig

> 标签: tsconfig, typescript, wellmade

## 简介

Wellmade's shared TypeScript configs — strict by default, with `node` / `dom` env variants and `nestjs` / `nestjs-spec` / `react` / `vitest` framework presets. The bedrock the lint rules sit on.
