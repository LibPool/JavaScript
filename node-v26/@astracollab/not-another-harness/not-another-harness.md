# @astracollab/not-another-harness

> 标签: agent, ai-sdk, coding-agent, harness, llm, pi-style

## 简介

not another harness — a small, transparent coding-agent harness. Pi-style minimal capped tools, a manual agent loop with streaming events, token budgets, mid-run compaction, and JSONL sessions. Bring any AI SDK v5 model.
