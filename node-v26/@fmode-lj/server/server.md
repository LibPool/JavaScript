# @fmode-lj/server

> 标签: JavaScript

## 简介

Parse 服务端封装:parse-server(原生能力直通,config 即原生选项)+ 动态云函数引擎(vm 沙箱,契约兼容 fmode/functions.md)+ PsqlService + 官方 Cloud Hooks;替代 @fmode/studio 闭源封装。配套客户端见 @fmode-lj/parse-client
