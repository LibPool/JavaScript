# @sorenllm/opencode-computer-use

> 标签: accessibility, computer-use, cua, cua-driver, desktop-automation, opencode, opencode-plugin

## 简介

Desktop computer use for opencode via trycua/cua's cua-driver (MCP stdio): one consolidated `computer` tool (capture som/vision/ax + element-addressed click/type/key/scroll/drag), screenshots returned to the model as image attachments, semantic verdicts,
