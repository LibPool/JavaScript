# @kervan/core

> 标签: ai-agents, mcp, mcp-server, model-context-protocol, tools, typescript, zod

## 简介

A thin, typed layer over the official MCP TypeScript SDK: define MCP tools with Zod schemas, validated arguments, timeouts and masked errors.
