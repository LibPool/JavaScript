# @izagood/avcs

> 标签: agentic, agents, ai-agent, ai-native, content-addressed, deterministic, mcp, mcp-server, model-context-protocol, operation-graph, vcs, version-control

## 简介

Agentic Version Control System — an AI-native VCS where intent, session, operation, evidence and decision are first-class objects and code is a materialized projection of an operation graph.
