# @alpacka/scroll

> 标签: agent-skill, dom, infinite-scroll, lenis-alternative, page-transition, raf, scroll, smooth-scroll, virtual-scroll, webgl, wheel

## 简介

Smooth wheel over the browser's own scroll, and a virtual scroll for full-WebGL pages, on one rAF clock — named locks, page-transition pin, infinite columns and strips. Ships an agent skill.
