# @shopify/cli-plugin-ngrok

> 标签: JavaScript

## 简介

Enables the creation of ngrok tunnels from `shopify app dev`, allowing previews from any device

- npm 页面：https://www.npmjs.com/package/@shopify/cli-plugin-ngrok
