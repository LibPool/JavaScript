# @morlay/dsh-reference

> 标签: context, dsh, dsh-plugin, reference

## 简介

Reference expansion for dsh: `@path` / `skill:name` in a user message expand into injected content at pre-step. Independent of the injection channel; the reference parser it reuses is inlined into the artifact, so this package ships without a client-side
