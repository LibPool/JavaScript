# @morlay/mydsh-profile

> 标签: bundle-entry, dsh, dsh-bundle, dsh-plugin

## 简介

我的 dsh 个人配置项：界面语言、欢迎提示版本、默认模型与对话视图——只按行 id 配值，不插行、不禁行，也不指定新会话挂哪份 agent preset。
