# @morlay/dsh-prompt-reminder

> 标签: dsh, dsh-plugin, preset, reminder, system-prompt

## 简介

Demotes the system-prompt sections a reduced prompt leaves out into <system-reminder> user messages, so tool guidance stops diluting the system prompt while it stays in force.
