# @morlay/session-rdb

> 标签: branch, dsh, dsh-plugin, dsh-session-rdb, rdb, rewind, session-rdb

## 简介

RDB durable session backend for DeepSeek Harness: implements both session-persistence and session-branch (rewind / retry / fork) providers.
