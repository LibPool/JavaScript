# @zibby/agent-graph-memory

> 标签: agent, embeddings, knowledge-graph, llm, mcp, memory, pgvector, postgres, sqlite, temporal

## 简介

A growable, time-aware memory graph for AI agents. SQLite by default (zero runtime dependencies), Postgres optionally, configurable embeddings. JS API, CLI, MCP server, HTTP server.
