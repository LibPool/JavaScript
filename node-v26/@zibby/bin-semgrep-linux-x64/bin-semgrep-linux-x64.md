# @zibby/bin-semgrep-linux-x64

> 标签: JavaScript

## 简介

Vendored semgrep 1.169.0 binary for linux/x64. Redistribution of the OSS Semgrep engine (semgrep-core) from Semgrep, Inc. (https://github.com/semgrep/semgrep) fetched from the official upstream release artifact and sha256-pinned by Zibby at publish time.
