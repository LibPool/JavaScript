# @zibby/ui-memory

> 标签: agent-memory, ai, browser-automation, browser-testing, dolt, knowledge-base, memory, playwright, selector-cache, ui-agent

## 简介

Version-controlled UI agent memory — cross-run selector cache, page fingerprints, navigation graph. Used today by zibby test, designed to power any agent that drives a UI. Powered by Dolt.
