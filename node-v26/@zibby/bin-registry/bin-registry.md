# @zibby/bin-registry

> 标签: binary, on-demand, registry, sha256, supply-chain, zibby

## 简介

The binary registry: sha256-pinned, on-demand delivery of a tool or harness binary from Zibby's own CDN into a local cache. Pure mechanism — it knows nothing about any particular tool — plus the pins for the HARNESS engines (codex, gemini) the agent image
