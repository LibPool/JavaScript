# @trisigma-tech/node-js

> 标签: continuous deployment, feature flags, feature toggles, nodejs, remote configuration, trisigma

## 简介

Node.js server SDK. Lets you manage features flags and remote config across web, server side applications. Deliver true Continuous Integration. Get builds out faster. Control who has access to new features.
