# @bilzo/node-ts-ocr

> 标签: character, nodejs, ocr, optical, pdf, recognition, tesseract, typescript

## 简介

A simple wrapper around command-line utils to assist in PDF / Image OCR (Optical Character Recognition) processing using Tesseract.
