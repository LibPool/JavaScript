# @eventor-run/sdk

> 标签: api-client, eventor, openapi, sdk, typescript

## 简介

Cliente HTTP tipado da Management API do Eventor (auth em camadas, retry, paginação, upload). Núcleo consumido pelo CLI e pelo MCP.
