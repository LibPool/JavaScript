# @kikojs/router

> 标签: JavaScript

## 简介

基于 `@kikojs/dom` 的声明式路由。支持 path / hash / memory 三种模式、嵌套路由、路由守卫、`Link` / `Outlet` 导航原语与路由 hooks。
