# @breezil/hypixel-api

> 标签: api-client, breezil, hypixel, hypixel-api, minecraft, typescript

## 简介

Typed Hypixel API client: fetch, TTL cache, rate-limit and cooldown handling, always-on computed stats, and injected config + UUID resolver so it runs standalone or embedded.
