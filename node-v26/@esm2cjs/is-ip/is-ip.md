# @esm2cjs/is-ip

> 标签: address, check, detect, find, internet, ip, ipv4, ipv6, is, match, pattern, protocol, regex, regexp, string, test, text, validate

## 简介

Check if a string is an IP address. This is a fork of sindresorhus/is-ip, but with CommonJS support.
