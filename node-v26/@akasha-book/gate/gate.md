# @akasha-book/gate

> 标签: JavaScript

## 简介

阿卡夏之书门控：数据目录写入守卫（规则工厂 + ruleId + 试匹配同源）+ 系统提示注入来源态约定（akasha:protocol）+ 自我层（akasha:self，每会话自动核对「我是谁」）+ 自我行（akasha:self-line，每回合 runtime context，近场常驻——自我不是规则，不该靠提醒活着）
