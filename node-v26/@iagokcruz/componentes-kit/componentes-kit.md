# @iagokcruz/componentes-kit

> 标签: components, datagrid, design-system, layout, react, theming, ui

## 简介

Kit de componentes React com tema customizável via CSS variables: DataGrid, Layout com menu e rodapé colapsáveis, e uma popup de configurações de cores com correção automática de contraste.
