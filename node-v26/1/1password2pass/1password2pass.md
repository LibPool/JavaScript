# 1password2pass

> 标签: 1password, pass

## 简介

1password2pass is a tool to import passwords from 1password keychain to pass (passwordstore.org)

- 官网：https://github.com/phoenixlzx/1password2pass
- 源码仓库：git://github.com/phoenixlzx/1password2pass.git
