# 10xgraph-client

> 标签: 10xgraph, 10xscale, agent, agentflow, ai-agents, api-client, client-side-tools, llm, memory, multi-agent, nodejs, react, realtime-audio, remote-tools, sdk, sse, streaming, threads, typescript, websocket

## 简介

TypeScript client for the 10xGraph API server: invoke and stream agent graphs, manage threads, memory and files, run client-side tools, and realtime audio. Formerly @10xscale/agentflow-client.
