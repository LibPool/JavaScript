# @insler/serde-json

> 标签: JavaScript

## 简介

Standalone SuperJSON-based JSON Serde for @insler RPC, preserving rich types (Date/Map/Set/BigInt).

- 源码仓库：git+https://github.com/mattinsler/insler.git
- npm 页面：https://www.npmjs.com/package/@insler/serde-json
