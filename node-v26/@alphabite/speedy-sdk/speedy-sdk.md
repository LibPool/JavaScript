# @alphabite/speedy-sdk

> 标签: api, bulgaria, courier, delivery, logistics, sdk, shipment, shipping, speedy, tracking, typescript

## 简介

Unofficial TypeScript SDK for the Speedy shipping API (Bulgaria). Promise-based, fully typed, dual CJS/ESM.
