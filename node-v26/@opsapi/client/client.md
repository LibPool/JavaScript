# @opsapi/client

> 标签: api-client, entitlements, licensing, openapi, opsapi, property, typescript, webhooks

## 简介

Typed client for the OpsAPI REST API: auth (incl. 2FA), workspaces, typed requests for every endpoint, pagination, retries, webhook verification, billing entitlements and licences.
