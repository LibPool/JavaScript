# @imagetalk/mcp

> 标签: claude, claude-desktop, image-search, imagetalk, mcp, mcp-server, modelcontextprotocol, stdio

## 简介

Stdio MCP server that wraps the ImageTalk backend REST API for use with Claude Desktop and other MCP clients.
