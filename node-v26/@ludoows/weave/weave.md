# @ludoows/weave

> 标签: bidirectional-sync, dom, frontend, no-virtual-dom, progressive-enhancement, proxy, reactive, reactive-programming, state-management, type-safe, typescript, ui, zero-dependencies

## 简介

A modern TypeScript reactive library that makes any existing HTML reactive without compilation, custom attributes, or Virtual DOM
