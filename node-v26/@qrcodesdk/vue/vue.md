# @qrcodesdk/vue

> 标签: code, esm, module, modules, qr, qr-code, qrcode, types, typescript, vue

## 简介

@qrcodesdk/vue provides Vue components for rendering QR codes as SVG, PNG-backed image elements, and canvas elements.
