# @qrcodesdk/svelte

> 标签: code, esm, module, modules, qr, qr-code, qrcode, svelte, types, typescript

## 简介

@qrcodesdk/svelte provides Svelte components for rendering QR codes as SVG, PNG-backed image elements, and canvas elements.
