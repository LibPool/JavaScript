# @uptickproject/faucet-plugin

> 标签: faucet, plugin, react-native, uptick, web3

## 简介

Uptick faucet (test token) plugin SDK: token auth, claim requests, and Cloudflare Turnstile human verification. Server-side signs the transfer; App only calls the SDK.
