# @codehacks/virtual-console

> 标签: console, debug, debugging, devtools, eruda, ios, mobile, object-inspector, remote-debugging, repl, vconsole, vite, vite-plugin, webview, wkwebview

## 简介

DevTools-style console for the places that don't have DevTools — iOS WebViews, Android WebViews, any page where console.log goes nowhere.
