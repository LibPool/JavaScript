# @stmol/dsh-prompt-lib

> 标签: deepseek-harness, deepseek-harness-plugin, dsh, dsh-plugin, plugin, prompt-library, prompts

## 简介

User-defined prompt library for DeepSeek Harness: a Prompts page in Settings and a composer picker that injects the chosen prompts into a session and its subagents
