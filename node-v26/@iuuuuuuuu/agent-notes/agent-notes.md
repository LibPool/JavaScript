# @iuuuuuuuu/agent-notes

> 标签: adr, agent-notes, decision-record, deepseek-harness, dsh, dsh-plugin, skill

## 简介

DSH 决策笔记（Agent Notes）：把「为什么这样改、放弃了什么」沉淀成可机械校验的仓库笔记，提供 Skill、会话级开关、真门禁与上游合并。
