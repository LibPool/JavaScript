# @pg-access/cli

> 标签: authorization, cli, migration, policy, postgres, postgresql, rls, row-level-security, supabase

## 简介

Command-line interface for pg-access: generates PostgreSQL RLS migrations from a pgaccess.config file, and checks a live database for drift.
