# @dylanzbot/bilibili-mcp

> 标签: bilibili, mcp

## 简介

MCP server for Bilibili: download videos/audio and transcribe speech to text locally (faster-whisper). No cloud, no login. Plug into Claude / Cursor / DeepSeek Harness.
