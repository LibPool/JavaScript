# kastorflow-notebooklm-mcp

> 标签: ai-agents, claude, cursor, gemini-notebook, kastorflow, mcp, mcp-server, model-context-protocol, notebooklm, notebooklm-api, notebooklm-mcp

## 简介

KastorFlow NotebookLM MCP: a free, local MCP server for NotebookLM (Gemini Notebook). Connect Claude, Cursor and other AI agents to your notebooks through the KastorFlow Chrome extension. Not affiliated with Google.
