# @vectros-ai/react

> 标签: auth, cognito, mfa, mui, react, reference-app, vectros

## 简介

Vectros React toolkit — the auth stack, Vectros API token cache, MFA, and UI primitives shared by the Vectros reference apps (admin-app, app.vectros.ai). Provider-agnostic by design: swap Cognito for Auth0/Clerk/OIDC behind a single adapter.
