# @fiadatech/agent

> 标签: claude-code, codebase-map, coding-agent, fiada, hooks, mcp

## 简介

Shows what your coding agent is doing on Fiada's map of your codebase: a tool hook and an MCP server for Claude Code, Cursor and Codex.
