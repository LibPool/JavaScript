# @brashkie/signalis-noise

> 标签: aes-gcm, chacha20poly1305, cryptography, curve25519, e2e-encryption, handshake, noise, noise-protocol, signalis

## 简介

The Noise Protocol Framework (XX, IK, NK patterns) built on @brashkie/signalis-core. Curve25519 + SHA-256 with selectable ChaCha20-Poly1305 or AES-GCM. Verified against the official Noise test vectors.
