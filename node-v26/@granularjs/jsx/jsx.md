# @granularjs/jsx

> 标签: automatic-runtime, granular, granularjs, jsx, jsx-runtime, react-replacement, tsx

## 简介

Optional automatic JSX runtime for @granularjs/core. Enables writing JSX (.jsx / .tsx) that compiles directly to Granular tag function calls.
