# @marg-adk/verdict

> 标签: agent-framework, agents, calibration, decisions, llm, mcp, typescript

## 简介

Verdict — typed decisions with calibrated probabilities for agents (an open-source alternative to a decision-model API): rules, Laya over the System One protocol, LLM logprobs, cascade, calibration, an MCP server and a System One-compatible HTTP server.
