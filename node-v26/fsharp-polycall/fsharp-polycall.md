# fsharp-polycall

> 标签: dotnet, ffi, fsharp, libpolycall, pinvoke, polycall

## 简介

F#/.NET P/Invoke binding for the Polycall binding ABI v1 (polycall >= 1.1.0). Source distribution of a .NET 8 project; not a JavaScript library.
