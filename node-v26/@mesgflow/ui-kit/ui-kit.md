# @mesgflow/ui-kit

> 标签: angular, angular-components, component-library, design-system, signals, tailwindcss, ui-kit

## 简介

Independent Angular component kit (button, select, dialog, table, sidebar, and more) built on a Tailwind v4 design token system. See README.md for setup and prerequisites.
