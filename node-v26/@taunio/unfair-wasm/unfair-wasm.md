# @taunio/unfair-wasm

> 标签: conversion, document, docx, odt, office, pdf, wasm, webassembly

## 简介

LibreOffice-class document conversion engine compiled to WebAssembly (wasm-bindgen). Convert between formats, auto-detect sources, and list capabilities — from Node.js or the browser, no LibreOffice required.
