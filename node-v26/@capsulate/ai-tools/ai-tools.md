# @capsulate/ai-tools

> 标签: agent, ai, capsulate, crewai, langchain, llamaindex, sandbox, tools, vercel-ai-sdk

## 简介

Capsulate tools for AI agent frameworks: drop-in sandbox tools (launch, run code, files, computer-use, checkpoint and rollback) for the Vercel AI SDK (v4 and v5), LangChain, LlamaIndex, and CrewAI.
