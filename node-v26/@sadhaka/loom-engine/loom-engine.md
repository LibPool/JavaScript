# @sadhaka/loom-engine

> 标签: browser, director-events, ecs, game-engine, isometric, sse, typescript

## 简介

Browser-first 2D / 2.5D game engine. Canvas2D, ECS, render-graph stages, Director-bridge SSE integration. Built from scratch in TypeScript for TheWorldTable.ai.
