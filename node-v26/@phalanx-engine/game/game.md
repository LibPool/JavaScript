# @phalanx-engine/game

> 标签: deterministic, lockstep, phalanx

## 简介

Game-facing facade for Phalanx Engine 0.3. Root re-exports runtime and the explicit ecs surface. Math, physics, abilities and advanced helpers are subpath exports.
