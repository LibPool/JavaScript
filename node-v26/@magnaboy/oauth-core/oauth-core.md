# @magnaboy/oauth-core

> 标签: JavaScript

## 简介

The provider-agnostic half of every OAuth client in this repo: `@magnaboy/irltk-sdk`, `@magnaboy/streamable-sdk` and `@magnaboy/powerchat-sdk` all build on it.
