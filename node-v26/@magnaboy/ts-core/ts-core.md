# @magnaboy/ts-core

> 标签: JavaScript

## 简介

The small things every script reaches for and nobody wants to write again: a cancellable sleep, a debouncer with no timer in it, guards that say what the value actually was, and command-line number parsing that refuses what `Number` would quietly accept.
