> 标签: custom-element, custom-element-builder, custom-elements, custom-elements-v1, javascript-library, template, template-engine, template-literal, typescript, typescript-library

## 简介

The package is part of the `<ceb/>` library. It bundles the main features of the library related to the Custom Elements (v1) specification.
