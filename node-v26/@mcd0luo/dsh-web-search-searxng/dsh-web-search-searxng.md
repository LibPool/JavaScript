# @mcd0luo/dsh-web-search-searxng

> 标签: JavaScript

## 简介

Self-hosted SearXNG web-search provider for the DeepSeek Harness web seam (ctx.web): queries the local SearXNG JSON API and maps results to WebSearchSource.
