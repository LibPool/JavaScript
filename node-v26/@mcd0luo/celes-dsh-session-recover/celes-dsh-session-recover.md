# @mcd0luo/celes-dsh-session-recover

> 标签: JavaScript

## 简介

会话异常自动重启：监听官方 agent/error 事件，按可配置的异常匹配规则向异常终止的会话注入恢复消息并驱动新一轮（自动续跑）；内置按会话计数上限、冷却窗口与日志留痕。host-only（依赖 schemastery 定义 Config schema）。
