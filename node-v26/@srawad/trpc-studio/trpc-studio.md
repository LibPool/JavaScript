# @srawad/trpc-studio

> 标签: cli, devtools, introspection, openapi, swagger, trpc, typescript, ui

## 简介

Swagger-like UI for tRPC — auto-generated input forms, Try It Out execution, output type visualization, and a CLI for static type extraction
