# @nucleushq/marqpdf-mcp

> 标签: ai-agents, claude, compress-pdf, cursor, mcp, model-context-protocol, ocr, pdf

## 简介

MarqPDF as a local MCP server: let Claude, Cursor or any MCP agent compress, OCR, convert, merge and protect PDFs on your computer.
