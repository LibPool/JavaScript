# reanimated-liquid-glass-tab-bar

> 标签: blur, bottom-tabs, expo, expo-router, glassmorphism, liquid-glass, react-native, react-navigation, reanimated, tab-bar

## 简介

A floating, frosted-glass tab bar for React Native, built with Reanimated: a pill that collapses to the active tab on scroll, plus an optional always-visible bubble tab
