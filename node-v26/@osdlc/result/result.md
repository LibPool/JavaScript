# @osdlc/result

> 标签: cause, discriminated-union, either, error-handling, errors, failure, result, typescript

## 简介

A plain-object Result type and a human-friendly Failure shape for TypeScript: ok/err, map, andThen, match, attempt, and a thrown FailureError. Zero dependencies.
