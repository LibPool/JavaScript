# @osdlc/cli-tool

> 标签: argv, cli, commander, dev-link, launcher

## 简介

What a standalone CLI needs before it does anything of its own: an injectable stdout/stderr seam, one exit-code rule, flags declared once so the parser and the help text cannot disagree, and running an installed tool from a development checkout.
