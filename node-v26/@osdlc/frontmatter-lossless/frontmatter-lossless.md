# @osdlc/frontmatter-lossless

> 标签: bom, byte-identical, crlf, front-matter, frontmatter, lossless, markdown, round-trip, split, typescript, yaml

## 简介

Byte-exact Markdown frontmatter framing: split a note into verbatim YAML and body with source offsets, and put it back together byte for byte. BOM, CRLF and fence bytes are kept. No dependencies.
