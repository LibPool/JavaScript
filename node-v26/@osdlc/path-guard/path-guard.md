# @osdlc/path-guard

> 标签: containment, path, path-traversal, sandbox, security, symlink, typescript

## 简介

Path containment guard: lexical validation of a root-relative path, then a symlink-aware proof, bound to one filesystem, that it stays inside its root, plus open-then-verify reads. Twin of the Rust `path-guard` crate.
