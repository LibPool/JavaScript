# @osdlc/command-seam

> 标签: abort, child-process, cli, dependency-injection, exec, mock, process-group, spawn, stdio, subprocess, test-seam, testing, timeout, typescript

## 简介

Injectable subprocess runner for Node: capture, stream and managed-process runners, hard timeouts, failures as results.
