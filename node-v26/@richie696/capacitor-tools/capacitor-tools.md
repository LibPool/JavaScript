# @richie696/capacitor-tools

> 标签: app-lifecycle, capacitor, device-info, electron, native, plugin, tools

## 简介

Capacitor 工具插件，提供应用生命周期、设备信息、版本更新、音量控制、Toast、网络监测等通用能力（支持 iOS/Android/Web/Electron）。
