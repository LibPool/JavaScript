# @caspian-vega/nano-macro-contracts

> 标签: contracts, macro-store, nanostores, operators, rxjs-like, state-management, store

## 简介

Lightweight, opinionated contracts built on top of nanostores: defineStore (chain-composed macro-stores with state, async resources, computes and actions) and a small set of RxJS-like store operators.
