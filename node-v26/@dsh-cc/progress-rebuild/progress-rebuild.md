# @dsh-cc/progress-rebuild

> 标签: JavaScript

## 简介

Structured progress state + post-compact context rebuild: derives a typed per-session progress brief from session events (goal fold, todo snapshot, verified bash receipts, last user message) and re-injects it after a successful compaction/end; default ON
