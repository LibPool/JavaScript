# @dsh-cc/edit-recovery-hint

> 标签: JavaScript

## 简介

Edit recovery hint: on an edit-tool not-found failure of a multi-line old_string, append a fixed static recovery-advice message to the same tool result as additionalContexts; user-layer-only setting
