# @dsh-cc/tool-notebook-edit

> 标签: JavaScript

## 简介

NotebookEdit model tool that edits Jupyter notebook (.ipynb) cells over the ctx.fs seam, aligned with Claude Code's NotebookEditTool replace/insert/delete, cell addressing, and read-before-write semantics
