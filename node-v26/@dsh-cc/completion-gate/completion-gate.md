# @dsh-cc/completion-gate

> 标签: JavaScript

## 简介

Completion gate: records hashed tool-execution receipts (plus an optional privacy-scrubbed bash command head) and, when enabled, nudges at turn-stopping when the final assistant message claims done-ness (tests pass / committed / pushed / build succeeded)
