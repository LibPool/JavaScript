# @blackrocksoul/analytics-client

> 标签: analytics client, custom transport, event analytics, event queue, event tracking, ga4, google analytics 4, measurement protocol, persistent queue, retry, session tracking, telemetry

## 简介

A transport-agnostic analytics client for tracking events with queues, storage, sessions, and retries. Includes a Google Analytics 4 Measurement Protocol transport and supports custom transports.
