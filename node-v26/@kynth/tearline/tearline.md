# @kynth/tearline

> 标签: custom-element, custom-elements, dom-to-image, dom-to-png, png-export, receipt, receiptify, shadow-dom, share-image, thermal-receipt, web-component, zero-dependencies

## 简介

Wrap any HTML in one tag and it prints out as a thermal receipt. Save it as a PNG. Zero dependencies, no build step.
