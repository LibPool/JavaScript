# @llmnative/react

> 标签: admin, admin-panel, ai-assisted, ai-first, backoffice, crud, dashboard, framework, internal-tools, provider-agnostic, react, schema-driven, tailwind, typescript, vite

## 简介

LLM-native React framework for deterministic UI generation. Data-driven by default, schema-driven optional. Ultra-low token consumption — built for AI agents, not just humans.
