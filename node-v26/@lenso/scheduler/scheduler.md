# @lenso/scheduler

> 标签: JavaScript

## 简介

`@lenso/scheduler` decides **when to enqueue**. The existing `@lenso/tasks` queue remains the only worker, retry budget and task-state authority. No worker, timer, HTTP endpoint, CLI operation or Manage surface starts on import/setup.
