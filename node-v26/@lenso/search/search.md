# @lenso/search

> 标签: JavaScript

## 简介

PostgreSQL keyword search over a separate, bounded projection. Ordinary async `upsert(scope, document)`, `delete(scope, {id,type})` and `query(scope, input)`. No listener, migration, scan, worker, cache or client is started by import, construction or plug
