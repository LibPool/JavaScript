# @camera.ui/camera-ui-ncnn

> 标签: alpr, camera-ui-plugin, detection, face, face-detection, license-plate, lpd, ncnn, object, ocr

## 简介

NCNN detection backend for camera.ui. Runs object detection, face detection and recognition, and license plate recognition with OCR.
