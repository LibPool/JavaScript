# @referalli/next

> 标签: affiliate, middleware, next, nextjs, referalli, referral, webhooks

## 简介

Next.js kit for Referalli: middleware that captures ?ref= into a first-party cookie, getReferral() for server code, webhook route handlers and signup attribution.
