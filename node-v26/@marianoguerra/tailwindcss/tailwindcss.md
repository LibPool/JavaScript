# @marianoguerra/tailwindcss

> 标签: compiler, css, moonbit, tailwindcss

## 简介

A MoonBit implementation of the Tailwind CSS v4 compiler, compiled to JavaScript. Compiles Tailwind v4 CSS fully in memory (no filesystem access).
