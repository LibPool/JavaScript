# dsh-knowledge-tree

> 标签: bundle, cordis, cordis-plugin, deepseek-harness, dsh, knowledge-management, knowledge-tree, plugin, skills

## 简介

Knowledge tree plugin for DeepSeek Harness — collect loose knowledge as leaves and let the agent organize them into your own knowledge tree.
