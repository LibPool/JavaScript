# @esmx/pkg-wrapper

> 标签: cjs-to-esm, esmx, module-federation, virtual-module, wrapper

## 简介

Builds federation-entry wrappers (`esmx://<spec>` virtual modules) that expose every named export of a CJS or ESM package as static ESM re-exports — used by @esmx/rspack, @esmx/rsbuild, and @esmx/vite to give CJS packages like React proper named exports a
