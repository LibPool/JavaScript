# @esmx/rspack-react

> 标签: Build Tool, Development Experience, High Performance, Hot Module Replacement, Module Linking, React, Rspack, SSR, TypeScript

## 简介

A high-performance React integration for Esmx microfrontend framework, providing React support with SSR and Module Linking capabilities.
