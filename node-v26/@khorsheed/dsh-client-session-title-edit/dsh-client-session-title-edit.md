# @khorsheed/dsh-client-session-title-edit

> 标签: cordis, dsh, dsh-plugin, session, title

## 简介

Session title editing in the web GUI chat header: an edit control beside the title that renames the current session through the official session.rename RPC (the user-sourced title pins against automatic regeneration)
