# @khorsheed/dsh-local-agent-tool-subagent

> 标签: cordis, dsh, dsh-plugin, local-agent, subagent

## 简介

Family-owned subagent delegation tool over the ctx.subagents seam with optional one-shot resume: the model may pass the dsh child session id returned by the first delegation to continue the same CLI conversation in a later round
