# @vectorvesper/motion

> 标签: animation, devtools, frame-budget, frame-loop, motion, motion-primitives, performance, pointer, primitives, profiler, raf, react, requestAnimationFrame, runtime, scheduler, scroll

## 简介

Motion primitives on one shared frame loop — a sensor layer, a frame-budget governor, and React hooks for fast, coordinated interactive sites. Zero dependencies.
