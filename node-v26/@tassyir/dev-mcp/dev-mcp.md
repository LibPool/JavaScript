# @tassyir/dev-mcp

> 标签: ai-agent, claude-code, mcp, model-context-protocol, tassyir, tassyir-app

## 简介

An MCP server for the AI agent that builds your Tassyir app: the guides, the Admin API and webhook schemas, manifest validation, the starter, and test webhooks and dev stores through your tassyir login.
