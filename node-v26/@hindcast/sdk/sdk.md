# @hindcast/sdk

> 标签: debugging, hindcast, recorder, rrweb, self-hosted, session-replay

## 简介

Browser session-replay recorder for Hindcast — records DOM events (rrweb), masks in the browser, and ships to your own self-hosted ingest.
