# @cromology/shared-components

> 标签: JavaScript

## 简介

Setup ``` npm ci ``` Dev ``` npm run dev  ``` Build for production ``` mode=build npm run build ``` - `shared.js` & `shared.css` are the one used for shared components (Color-Picker, etc ...)
