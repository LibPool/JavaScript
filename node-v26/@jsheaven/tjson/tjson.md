# @jsheaven/tjson

> 标签: JSON, TJSON, Typed JSON, Typed JSON parser, Typed JSON stringify

## 简介

A TypeScript library that extends JSON to handle additional JavaScript data types like Date, Set, Map, BigInt, RegExp, and more.
