# @brucecheung666/dsh-subagent-panel

> 标签: deepseek-harness, dsh, dsh-plugin, panel, session, subagent

## 简介

DeepSeek Harness 插件：对话区左侧可收起的子 Agent 面板，只整合当前会话的 subagent 谱系（根会话/自己/子 agent）。
