> 标签: browser, client-side, code-viewer, document-preview, document-viewer, docx, epub-viewer, excel-viewer, file-preview, file-viewer, markdown-viewer, office-viewer, pdf-viewer, powerpoint-viewer, pptx, react, react-component, react-file-viewer, word-viewer, xlsx

## 简介

React file viewer for 20+ formats—PDF, DOCX, PPTX, XLSX, EPUB, Markdown, code and media—rendered entirely in the browser with no server uploads.
