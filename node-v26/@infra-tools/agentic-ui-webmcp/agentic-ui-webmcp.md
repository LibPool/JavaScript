# @infra-tools/agentic-ui-webmcp

> 标签: JavaScript

## 简介

WebMCP adapter for @infra-tools/agentic-ui — exposes the host app's ToolRegistry to an in-browser agent via the navigator.modelContext proposal. Tools register/unregister reactively; every inbound call is scope- and approval-gated. Optional plugin; stays
