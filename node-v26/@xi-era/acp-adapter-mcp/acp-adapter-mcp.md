# @xi-era/acp-adapter-mcp

> 标签: acp, adapter, agent, bridge, iot, mcp

## 简介

ACP (Agent-Component-Protocol) <-> MCP bidirectional bridge — expose ACP components as MCP tools for Claude/Cursor, and wrap MCP tools as ACP components.
