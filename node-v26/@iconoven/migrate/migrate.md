# @iconoven/migrate

> 标签: JavaScript

## 简介

Moves a codebase from Lucide, Heroicons or Hugeicons (and old IconOven names) to IconOven.

## 官网

- 官网：https://iconoven.com
- npm 页面：https://www.npmjs.com/package/@iconoven/migrate

- 0.0.0-stage

- 0.1.1

## 获取地址

- npm 安装：`npm install @iconoven/migrate`
- npm registry：https://registry.npmjs.org/@iconoven/migrate
- Node 要求：>=22
