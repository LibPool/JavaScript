# @jokerdpf/ilive-meeting-mcp

> 标签: bach, ilive, livestream, mcp, meeting, model-context-protocol

## 简介

MCP server for the iLive livestream platform OPEN-API (apply / modify / cancel meetings, query meeting info and reports, hospital MDM code lookup), with EMCP current-user identity via OUS. stdio and stateless Streamable HTTP.
