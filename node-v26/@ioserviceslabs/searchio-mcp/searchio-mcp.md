# @ioserviceslabs/searchio-mcp

> 标签: llm, mcp, model-context-protocol, scraping, search

## 简介

searchio MCP server for LLM clients — npx-ready launcher. Runs the all-in-one Docker image when Docker is present, otherwise falls back to a local pip install of searchio.
