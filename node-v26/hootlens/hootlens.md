# hootlens

> 标签: ai-agents, claude-code, cursor, heatmaps, hootlens, mcp, nextjs, replay, source-locations, vite

## 简介

Make Hoot Lens automatic for your site and your coding agents: adds the tag, a project file, agent instructions and MCP config, plus build plugins that point snags at source files.
