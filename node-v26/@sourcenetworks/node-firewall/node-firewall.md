# @sourcenetworks/node-firewall

> 标签: JavaScript

## 简介

Node-firewall configures the access control policies of a Linux based router that has been configured to act as a shared wireless hotspot. It interfaces directly with IPTables and is easily extendable to allow a user control over their router from a NodeJ
