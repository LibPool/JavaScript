# @statedelta/actions-openapi

> 标签: JavaScript

## 简介

Gera OpenAPI 3.1 a partir das actions (IR estático, SEM runtime): rotas das actions `entry` + metadado `@route`, security dos grants, e TODA a semântica em `x-actions-*` (Specification Extensions). Schema das props injetável (Jast). Consumidor do @statede
