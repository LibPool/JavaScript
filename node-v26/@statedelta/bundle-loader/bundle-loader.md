# @statedelta/bundle-loader

> 标签: bundle, integrity, loader, registry, statedelta, trust, typescript

## 简介

Code-bundle acquisition for StateDelta — resolves a bundle key to a verified, loaded module from a versioned manifest (registry → integrity → import, under a trust policy)
