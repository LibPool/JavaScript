# @tuoyuan/code-editor

> 标签: code-editor, code-formatter, code-highlighter, component, editor, javascript, json, monaco-editor, sql, syntax-highlighting, typescript, vue, vue3

## 简介

基于 Monaco Editor 的 Vue3 代码编辑器组件，支持 JavaScript、JSON、SQL 语言的高亮、格式化和压缩，内置工具栏、状态栏、主题切换、全屏模式等功能
