# @huma-protocol/sdk

> 标签: attestation, ed25519, huma, scoring, sybil, verify

## 简介

Verify Ed25519-signed HUMA score reports offline. Zero-dep except @noble/ed25519. The signer (scanner) and the future HTTP API both emit reports this SDK can verify.
