# @reventlessdev/reventless-map

> 标签: JavaScript

## 简介

Geo view mode (MapView, MapMode, GeoInput) for Reventless AutoUI, built on @reventlessdev/rescript-maplibre. Optional add-on: non-geo apps never load it.
