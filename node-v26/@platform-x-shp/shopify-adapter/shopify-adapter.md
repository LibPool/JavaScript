# @platform-x-shp/shopify-adapter

> 标签: JavaScript

## 简介

Shopify commerce adapter — Admin API client, read-model mappers, tenant-config resolution, and Keycloak/PlatformX auth verification, consumed by hep-ecommerce-service. Self-contained: does not depend on shp-auth-client.
