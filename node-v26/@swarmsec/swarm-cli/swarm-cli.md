# @swarmsec/swarm-cli

> 标签: ai-security, appsec, claude, claude-code, codex, cursor, mcp, mcp-server, penetration-testing, pentest, recon, sarif, security

## 简介

Free AI penetration-test scanner that runs in your terminal. An MCP server for Claude Code, Codex, and Cursor: specialist agents read your source and map your live domain's footprint. No account, no API key.
