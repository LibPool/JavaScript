# koishi-plugin-billboard-data

> 标签: biliboard, chatbot, koishi, plugin, ranking, vocaloid, weekly

## 简介

🎵 对接 VincentZyuApps/billboard-data 数据源，提供术力口周榜与期数查询、查歌与查P主战绩检索 📊 支持多端精美海报渲染 ✨
