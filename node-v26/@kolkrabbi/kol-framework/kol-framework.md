# @kolkrabbi/kol-framework

> 标签: app-shell, design-system, kol, kolkrabbi, react

## 简介

KOL app shell — sidenav, layout, theme toggle, footer, heroes + brand color layer. SideNav takes nav data as props so the tree stays app-local.
