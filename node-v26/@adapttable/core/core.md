# @adapttable/core

> 标签: data-table, datagrid, headless, headless-ui, infinite-scroll, responsive-table, rtl, server-side-pagination, table, typescript, url-state, virtualized-table

## 简介

Framework-neutral AdaptTable engine — models, state, URL sync, and a unified client/server TableSource. Zero UI-kit or React imports.
