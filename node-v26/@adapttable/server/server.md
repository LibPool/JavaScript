# @adapttable/server

> 标签: adapttable, data-table, nextjs, query, react, remix, server, typescript, validation

## 简介

Parse and validate an AdaptTable query on the server — one typed contract from the URL to your backend, for Next.js route handlers, Remix loaders and Server Actions.
