# @x-otto/trace-view

> 标签: JavaScript

## 简介

Structured trace event view model — transforms raw `TraceEvent` streams into timeline/waterfall/causal-graph views. Shared between Web and TUI consumers. Extracted from `@x-otto/agent` when `web-ui`/`web-trace` were deleted (2026-07-17).
