# @x-otto/plugin-otto-wire-protocols

> 标签: JavaScript

## 简介

Three standard wire protocol implementations (anthropic-messages/openai-responses/openai-completions) — runtime support for provider plugins. Publishable standalone so non-CLI hosts (e.g. desktop apps depending only on @x-otto/coding) can install it witho
