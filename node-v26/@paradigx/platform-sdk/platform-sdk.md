# @paradigx/platform-sdk

> 标签: admin-gate, internal-api, logto, paradigx, sdk

## 简介

Server-side helpers for Paradigx products (paradigx, tokenroute, botu, fieryeye and future apps) to talk to the paradigx platform: internal API client + admin role gate.
