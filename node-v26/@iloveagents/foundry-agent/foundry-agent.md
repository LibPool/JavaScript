# @iloveagents/foundry-agent

> 标签: ag-ui, agent, agent-framework, azure-foundry, foundry-ui, msal, zustand

## 简介

Cross-runtime AG-UI transport for Foundry UI — AGUIRunner protocol engine, vanilla zustand stores, optional MSAL auth subpath, service-fetch factory. Zero React, zero DOM.
