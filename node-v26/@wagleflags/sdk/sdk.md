# @wagleflags/sdk

> 标签: feature-flags, feature-toggles, react, remote-config, typescript, wagle

## 简介

Wagle feature-flag SDK for TypeScript and React: seed once, stream updates, evaluate flags locally with zero per-eval network hop.
