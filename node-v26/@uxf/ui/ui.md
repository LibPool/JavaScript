# @uxf/ui

> 标签: JavaScript

## 简介

React UI component library (Tailwind CSS) for UXF projects. Each component is a subpath import — e.g. `import { Button } from "@uxf/ui/button"` — and ships with its own README under `packages/ui/<component>/`.
