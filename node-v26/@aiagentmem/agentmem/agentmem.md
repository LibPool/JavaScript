# @aiagentmem/agentmem

> 标签: agent, ai, capture, claude-code, cli, codex, cursor, gemini, observability, opencode, redaction, session

## 简介

Session collector for coding agents (Claude Code / Codex / Cursor / Gemini / OpenCode): read-only capture → on-device redaction → HMAC-signed upload. Local WAL, resumable, dead-letter replay. Zero runtime dependencies.
