# @alfalab/miniapp-sdk

> 标签: JavaScript

## 简介

SDK для Mini App внутри контейнера Super App. Обеспечивает коммуникацию между веб-приложением и нативной стороной (Android, iOS, iframe) через единый bridge-интерфейс.
