# @alfalab/arui-scripts-artifacts

> 标签: JavaScript

## 简介

CLI и библиотека для сборки артефактов поставки приложений на arui-scripts: docker-образ и tar-архив с генерируемыми Dockerfile, nginx-конфигом и start-скриптом
