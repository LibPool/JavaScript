# @moduflow/remote-sdk

> 标签: JavaScript

## 简介

Contributor remote runtime: hosted routing, `useRemoteData*`, host events API, remote permission helpers. Re-exports `@moduflow/contracts` for Path A DX — install **`@moduflow/contracts` as a peer** alongside this package.
