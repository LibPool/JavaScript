# @tabnas/feed

> 标签: atom, feed, parser, rdf, rss, tabnas, xml

## 简介

Parses RSS (0.90, 0.91, 0.92, 1.0, 2.0) and Atom (0.3, 1.0) feeds into a typed structure, defaulting to a normalized Atom shape.
