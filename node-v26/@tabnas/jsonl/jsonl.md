# @tabnas/jsonl

> 标签: json, json-lines, jsonl, ndjson, parser, streaming, tabnas

## 简介

This plugin allows the [Tabnas](https://github.com/tabnas/parser) parsing engine to parse JSON Lines (JSONL / NDJSON): one standard-JSON value per line.
