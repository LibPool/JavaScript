# @novatic/auth

> 标签: app-router, authentication, bff, iron-session, nextjs, oidc, openid-connect, pkce, typescript

## 简介

Self-contained OIDC auth for Next.js (App Router) with encrypted sessions, automatic token refresh and a mountable auth BFF.
