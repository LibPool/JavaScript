# @xtrata/sdk

> 标签: bitcoin, clarity, inscriptions, nft, sbtc, sip-009, sip-010, stacks, xtrata

## 简介

TypeScript SDK for the Xtrata contract-native inscription protocol on Stacks: read clients, mint/collection/market workflow planners, safe spend caps, sponsored-transaction client, and multi-asset payment helpers.
