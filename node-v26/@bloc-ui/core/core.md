# @bloc-ui/core

> 标签: accessible, angular, angular-components, bloc-ui, component-library, lightweight, standalone-components, tailwind, themeable, typescript, ui-library

## 简介

Lightweight Angular component library — button, checkbox, input, radio, spinner, toggle, and more with secondary entry points for tree-shaking.
