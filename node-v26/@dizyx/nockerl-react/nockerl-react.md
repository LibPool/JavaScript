# @dizyx/nockerl-react

> 标签: JavaScript

## 简介

React components for the Nockerl design system: token-pure, with SSR-safe injected styles. Source of truth: dizyx/nockerl-design. Pair with @dizyx/nockerl-tokens for the CSS custom properties.
