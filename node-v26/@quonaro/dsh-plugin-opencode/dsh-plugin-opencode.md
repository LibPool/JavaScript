# @quonaro/dsh-plugin-opencode

> 标签: cordis, deepseek-harness, delegation, dsh, dsh-plugin, opencode, subagent

## 简介

OpenCode CLI inside DeepSeek Harness: an `opencode` delegation tool, a /opencode command, and an `opencode` LLM provider route — all over the ctx.subprocess seam, with `opencode models` discovery.
