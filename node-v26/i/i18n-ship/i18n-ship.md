# i18n-ship

> 标签: ai-translation, aws, copilot, cursor, gpt, i18n, i18n-ship, internationalization, json, l10n, locale, localization, multilingual, openai, s3, sync, translate, translation

## 简介

Ship i18n translations to AWS S3 from your codebase. Auto-translate with AI, sync across environments, and install agent rules for GitHub Copilot & Cursor.
