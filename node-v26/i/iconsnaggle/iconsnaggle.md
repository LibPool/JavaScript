# iconsnaggle

> 标签: JavaScript

## 简介

Extract favicons, `link[rel="shortcut icon"]`, `link[rel="icon"]`, `link[rel="apple-touch-icon"]`, and `link[rel="og:image"]` icons.

- npm 页面：https://www.npmjs.com/package/iconsnaggle
