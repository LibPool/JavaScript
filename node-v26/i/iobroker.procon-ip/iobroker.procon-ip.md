# iobroker.procon-ip

> 标签: ProCon.IP, ioBroker, pool, pool-digital, procon, swimming

## 简介

Adapter for basic support of the ProCon.IP pool control. Intended for integration with your voice assistant (eg. via the `cloud` adapter for Alexa or `yahka` for Apple HomeKit with Siri).
