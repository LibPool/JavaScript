# insight-ui-dinero

> 标签: bitcore-dinero, blockchain, blockexplorer, dinero, front-end, insight

## 简介

An open-source frontend for the Insight API. The Insight API provides you with a convenient, powerful and simple way to query and broadcast data on the Dinero network and build your own services with it.
