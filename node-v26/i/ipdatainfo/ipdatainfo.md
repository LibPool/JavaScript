# ipdatainfo

> 标签: geoip, ip-api, ip-geolocation, ip-lookup, ipdata, threat-intelligence

## 简介

Official Node.js/TypeScript client for the ipdata.info IP geolocation, ASN, and threat-intelligence API.

## 官网

- 官网：https://ipdata.info
- 源码仓库：git+https://github.com/IPDataInfo/ipdata-node.git
- npm 页面：https://www.npmjs.com/package/ipdatainfo

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- npm 安装：`npm install ipdatainfo`
- npm registry：https://registry.npmjs.org/ipdatainfo
- Node 要求：>=18
