# intentic

> 标签: agent-orchestrator, ai-agents, claude-code, codex, coding-agents, git-worktree, intentic, parallel-agents, sandbox, self-hosted

## 简介

intentic, an open-source orchestrator for parallel coding agents (Claude Code, Codex, Cursor, Gemini), each in a sandbox on your own machine. Run `npx intentic` for how to install it.

- 官网：https://intentic.dev
- 源码仓库：git+https://github.com/intentic/intentic.git
- npm 页面：https://www.npmjs.com/package/intentic
