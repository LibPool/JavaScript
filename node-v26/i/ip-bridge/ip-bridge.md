# ip-bridge

> 标签: bridge, mongodb, proxy, static-ip, tcp, vercel

## 简介

TCP proxy that gives serverless apps (Vercel) a static outgoing IP for MongoDB Atlas

## 官网

- 官网：https://github.com/amide-init/ip-bridge
- 源码仓库：git+https://github.com/amide-init/ip-bridge.git
- npm 页面：https://www.npmjs.com/package/ip-bridge

- npm 安装：`npm install ip-bridge`
- npm registry：https://registry.npmjs.org/ip-bridge
- Node 要求：>=18
