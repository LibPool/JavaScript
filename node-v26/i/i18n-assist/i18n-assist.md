# i18n-assist

> 标签: JavaScript

## 简介

i18n-assist is an ESM-based tool library that leverages TypeScript AST (Abstract Syntax Tree) technology to recognize and parse .ts and .tsx files. By reading and modifying AST nodes, i18n-assist can automatically generate new code with i18n content
