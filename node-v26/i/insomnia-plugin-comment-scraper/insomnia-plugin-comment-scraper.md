# insomnia-plugin-comment-scraper

> 标签: comment-scraper, comments, csv, hacker-news, insomnia, insomnia-plugin, markdown, reddit

## 简介

Copy a Reddit or Hacker News comment thread from an Insomnia response as CSV or Markdown, with reply depth, timestamps, comment links and Reddit scores where shown.
