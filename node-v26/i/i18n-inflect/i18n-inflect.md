# i18n-inflect

> 标签: agreement, article, declension, grammar, hungarian, i18n, inflection, korean, l10n, localization, morphology

## 简介

Grammatical inflection and agreement for i18n — articles, case suffixes, particles — in the browser, Node.js, and Cordova. API inspired by Apple's Morphology / automatic grammar agreement.
