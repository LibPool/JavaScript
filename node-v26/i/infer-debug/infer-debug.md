# infer-debug

> 标签: breakpoint, cdp, chrome-devtools, debug, debugging, devtools, express, fastify, kubernetes, nestjs, node-inspector

## 简介

Framework-agnostic in-process debug proxy: attach Chrome DevTools to header-marked requests of a running Node.js app via a spawned debug child. Adapters for NestJS, Express, Fastify, or plain http.Server.
