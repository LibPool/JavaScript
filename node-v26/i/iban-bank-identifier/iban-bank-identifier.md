# iban-bank-identifier

> 标签: angular, banco, bank, bic, browser, esm, france, germany, iban, italy, mod97, netherlands, nib, portugal, react, sepa, spain, swift, validation

## 简介

Identifica o banco a partir de um IBAN, usando bases de dados JSON incorporadas (PT, ES, FR, IT, NL, DE). Inclui validação mod-97. Sem chamadas de rede. ESM + CommonJS, pronto para Node e browser (React, Angular, Vite, webpack).
