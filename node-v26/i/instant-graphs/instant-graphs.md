# instant-graphs

> 标签: ai-context, claude, claude-code, codex, graph, hand-drawn, knowledge-graph, rough.js, skill, visualization

## 简介

Turn a natural-language description of a system into a hand-drawn (Rough.js) relationship diagram and an AI-readable graph JSON.
