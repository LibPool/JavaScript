# incajs

> 标签: cross-platform, custom-renderer, desktop-app, electron-alternative, framework-agnostic, gpui, gui, incajs, incarnative.js, quickjs, rust, tauri-alternative, vue, vue3, webview-free

## 简介

Incarnative.js — a GPU-native, Webview-free desktop application framework powered by GPUI and QuickJS. Framework-agnostic core, with first-class Vue 3 support via the incajs/vue subpath.
