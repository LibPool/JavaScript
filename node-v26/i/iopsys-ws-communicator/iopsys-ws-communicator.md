# iopsys-ws-communicator

> 标签: JavaScript

## 简介

Helper library for openWrt ubus communication over WebSocket using RPC. Can be uses together with [OpenWrt WebSocket Daemon (OWSD)](https://dev.iopsys.eu/iopsys/owsd).
