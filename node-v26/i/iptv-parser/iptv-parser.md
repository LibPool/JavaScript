# iptv-parser

> 标签: epg, iptv, m3u, m3u8, parser, playlist, xmltv

## 简介

Robust IPTV M3U/M3U8 playlist parser with IPTV-specific tags (tvg-*, group-title, EXTGRP, EXTVLCOPT, KODIPROP, catchup, etc.).
