# image-enhancer-mcp

> 标签: claude, image-enhancer, mcp, model-context-protocol, shopify

## 简介

stdio MCP server — the merchant's Claude (Desktop + Code) talks to Image Enhancer through this. Bridges stdio JSON-RPC to the app's HTTP /mcp endpoint with the merchant's ie_ token.
