# invisible-chars

> 标签: ai-text, bidi, chatgpt, clean-text, hidden-characters, invisible, invisible-characters, nbsp, non-breaking-space, sanitize, trojan-source, unicode, zero-width, zero-width-space, zwj, zwnj, zwsp

## 简介

Detect and remove invisible Unicode characters: zero-width spaces, bidi controls, variation selectors, tag characters. Knows which ones are safe to strip and which carry meaning.
