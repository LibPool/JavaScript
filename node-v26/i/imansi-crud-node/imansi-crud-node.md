# imansi-crud-node

> 标签: api, auth, crud, express, imansi, nodejs, permisos, postgresql, seguridad

## 简介

Capa CRUD segura y orientada a recursos para el ecosistema Imansi. Integración nativa con imansi-auth-node e imansi-permisos-node. PostgreSQL, sin ORM.
