# img-pdf-viewer

> 标签: angular, angular-component, document-viewer, fast, image-viewer, ngx, pdf-viewer, pdfjs, preview, responsive, typescript

## 简介

A powerful, responsive Angular library for viewing PDF documents and images (PNG, JPEG, WebP) with advanced features like zoom, rotation, and pagination. Built on PDF.js.
