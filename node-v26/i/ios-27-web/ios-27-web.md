# ios-27-web

> 标签: dynamic-island, ios, liquid-glass, nextjs, react, siri, threejs, ui-components, webgl

## 简介

High-fidelity iOS 27 concept recreation on the web featuring WebGL Siri fluid dynamics, Liquid Glass optics, Dynamic Island physics, and interactive device hardware.
