# interval-bins

> 标签: bins, bioinformatics, boundaries, calculation, interval, javascript

## 简介

binEvenLengthRound() : Calculate the bin size for even-sized bins to span the given interval. binBoundaries() : Generate an array of even-sized bins to span the given interval.
