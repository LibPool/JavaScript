# inject_solve_unount

> 标签: ES6 装饰器, 解决组件销毁时，内存溢出报错问题, 适合 React 框架

## 简介

solve the error of 'Warning: Can't perform a React state update on an unmounted component. This is a no-op, but it indicates a memory leak in your application. To fix, cancel all subscriptions and asynchronous tasks in the componentWillUnmount method.'
