# icon-lint

> 标签: ai-agent, claude-code, cli, codex, consistency, design-system, icon-lint, icon-set, icons, linter, svg, svg-icons

## 简介

Zero-config linter that infers an icon set's own conventions (viewBox, stroke, caps, joins, paint style) and flags the icons that drift from them
