# idiscovery

> 标签: auto vote, master slave, service discovery

## 简介

node中间件，支持服务自动发现，服务间通信，自动推选master服务，master服务crash后自动重新推选可用的服务作为master服务，支持added，removed，elected等事件监听。

## 官网

- npm 页面：https://www.npmjs.com/package/idiscovery

- npm registry：https://registry.npmjs.org/idiscovery
