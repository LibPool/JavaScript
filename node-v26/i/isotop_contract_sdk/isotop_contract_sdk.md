# isotop_contract_sdk

> 标签: JavaScript

## 简介

**isotop_contract_sdk** 是一个提供了接口：createUser, queryUser, writeCall, readCall, getTransactionByHash的 npm 包，用于创建账户，查询用户在链上账户地址，写入合约方法，读取合约方法以及根据交易查询交易信息等功能。
