# imbrace-vibe-code

> 标签: cli, deploy, faas, fission, hono, imbrace, serverless, vite

## 简介

Create, deploy and run apps and scripts on iMBRACE Fission: scaffold a React/Vite + Hono app (or py/js/go scripts), upload the source and the cluster builds and serves it.
