# impactwave

> 标签: blast radius, cli, code analysis, code impact, dependency analysis, developer tools, git, impact analysis, node, static analysis, testing, typescript

## 简介

Blast radius analyzer CLI for TypeScript: find which exported symbols your Git changes modify, who consumes them, what tests cover them, and get a deterministic risk score before merging.
