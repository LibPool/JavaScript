# ip-geo-locator

> 标签: country, express, geoip, geolocation, ip, ip-address, location, middleware, x-forwarded-for

## 简介

Extract a client's IP address from an HTTP request and resolve its geographic location. Zero runtime dependencies, pluggable providers, Express middleware included.
