# infinite-faq

> 标签: accordion, ai, ai-sdk, faq, nextjs, openrouter, react, streaming, tailwind

## 简介

AI-powered infinite FAQ. Static Q&A plus an ask-anything input that streams answers into the list. Full-stack and fully Tailwind-designable.
