# ids-le

> 标签: cli, identifier, ids-le, letools, nanoid, nolindnaidoo, objectid, snowflake, ulid, uuid

## 简介

Find every identifier in a codebase: UUID, ULID, NanoID, MongoDB ObjectId and Snowflake, with the key path and the decoded time. Refuses rather than guesses.
