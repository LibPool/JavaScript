# icf.js

> 标签: browser, icf, icx, indent-comma-format, parser, schema, serializer, zero-dependency

## 简介

Zero-dependency browser & Node library (TypeScript) to parse, validate, build, write, and index Indent Comma Format (ICF) and generate ICX companion indexes. Implements ICF spec v1.1 and ICX spec v1.2.
