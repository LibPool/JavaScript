# i18n-auto-localizer

> 标签: ai, automated-translation, cli, github-action, github-actions, i18n, i18next, internationalization, l10n, llm, locale, localization, next-intl, openrouter, react-i18next, translation, typescript, vue-i18n

## 简介

GitHub Action and CLI that scans JS/TS source for in-use i18n translation keys (react-i18next, vue-i18n, next-intl) and auto-generates missing locale translations via any LLM on OpenRouter, without ever overwriting existing translations.
