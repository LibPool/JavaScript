# i18n-easy

> 标签: i18n, 中文国际化, 代码转换, 国际化, 国际化工具, 国际化文件生成, 翻译, 翻译管理

## 简介

一个一键国际化工具，用于将代码中的中文转换成国际化写法，并将翻译内容写入指定的语言文件中。提高开发效率，简化国际化流程。
