# inpage-wallet

> 标签: browser-extension, cip-30, dapp, eip-1193, eip-6963, wallet, wallet-standard, web3, webview

## 简介

Headless, brand-neutral wallet injection and request routing for dApp pages. EIP-6963, Wallet Standard, CIP-30, TronLink, XRPL and BTC providers over a pluggable transport.
