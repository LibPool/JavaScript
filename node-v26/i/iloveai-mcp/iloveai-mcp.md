# iloveai-mcp

> 标签: agents, ai, claude, cursor, markdown, mcp, model-context-protocol

## 简介

MCP server exposing I Love AI's content tools (URL/PDF/YouTube → Markdown, summaries, prompts, OCR and more) to agents like Claude and Cursor.
