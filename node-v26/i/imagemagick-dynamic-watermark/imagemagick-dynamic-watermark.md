# imagemagick-dynamic-watermark

> 标签: crop and watermark, easy crop, icon watermark, image over image, image watermark, node watermark, smart crop, smart watermark, watermark

## 简介

Dynamic Watermark is npm watermark module to add watermark over image. It can add image as well as text watermark on given positions
