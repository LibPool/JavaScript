# iso-building-generator

> 标签: buildings, deterministic, gamedev, generator, isometric, procedural, seeded, sprites, svg, tileset

## 简介

Seeded procedural generator for detailed isometric SVG buildings, with a CSS motion layer. Zero dependencies, no build step.
