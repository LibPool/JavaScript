# igniteui-react-fdc3

> 标签: UI components, data adapter, fdc3, financial data, infragistics, openfin, openfin fdc3, react, visualization

## 简介

Ignite UI React FDC3 data adapter generates financial data for received FDC3 intents as well as sending messages to other FDC3-enabled apps using OpenFin's FDC3 service.
