# image-to-gif-converter

> 标签: animated-gif, animation, converter, gif, image-processing, image-to-gif, images, library, nodejs, sharp

## 简介

A powerful Node.js library for creating animated GIFs from image collections with customizable dimensions, frame timing, and quality settings
