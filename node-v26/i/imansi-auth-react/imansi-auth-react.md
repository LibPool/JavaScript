# imansi-auth-react

> 标签: 2fa, autenticacion, auth, espanol, github, google, headless, hooks, imansi, jwt, login, oauth, react, registro, spanish

## 简介

Hooks de autenticación para React: login, registro, 2FA, OAuth (GitHub y Google), recuperación de contraseña y gestión de sesiones. Sin componentes visuales. Compatible con imansi-auth-node.
