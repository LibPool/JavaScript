# i18n-dynamic-translate

> 标签: api-translation, auto-translate, dynamic-content, i18n, i18next, internationalization, localization, metadata, runtime-translation, translation

## 简介

Automatic translation library for i18next and Node.js i18n with support for DeepL and LibreTranslate.
