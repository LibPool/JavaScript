# is-es6-generators

> 标签: check, es2015, es6, es7, function, functions, generator, generatorfunction, generators, is, is-function, is-generator, is-generator-function, next, validate

## 简介

Check whether a value is a `Generator` or `GeneratorFunction`. The `co` way, more strict checking. Always return boolean true or false, never null or undefined.
