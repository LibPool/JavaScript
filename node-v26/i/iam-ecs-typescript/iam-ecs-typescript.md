# iam-ecs-typescript

> 标签: ecs, framework, game

## 简介

使用 TypeScript 实现的一个 ECS 系统。目前用于 Cocos Creator，不过因为没有依赖任何 Cocos Creator 的接口，所以也可以用在任何其他支持 TS/JS 的引擎中。
