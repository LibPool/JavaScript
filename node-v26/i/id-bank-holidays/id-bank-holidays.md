# id-bank-holidays

> 标签: bank-holidays, bank-indonesia, business-days, holidays, indonesia, public-holidays

## 简介

A lightweight, dependency-free TypeScript library for Indonesian public holidays and bank holidays based on the official Bank Indonesia calendar.
