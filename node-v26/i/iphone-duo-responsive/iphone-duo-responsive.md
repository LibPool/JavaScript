# iphone-duo-responsive

> 标签: apple, foldable, iphone-duo, nextjs, react, responsive, safari, viewport, vite

## 简介

Make React / Next.js / Vite apps responsive to Apple's foldable iPhone Duo (folded/unfolded viewport states) via a runtime heuristic, since Safari does not implement the CSS Viewport Segments API.
