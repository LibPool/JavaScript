# iconr

> 标签: css, datauri, fallback, png, svg

## 简介

CLI tool that consumes a directory of SVG images and outputs a CSS file of inlined data as well as a directory of PNG images for fallback if necessary.

## 官网

- 官网：https://github.com/okize/iconr/
- 源码仓库：git+https://github.com/okize/iconr.git
- npm 页面：https://www.npmjs.com/package/iconr
