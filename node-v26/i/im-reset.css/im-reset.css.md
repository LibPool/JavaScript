# im-reset.css

> 标签: css, reset, 重置样式

## 简介

一份重置样式表：在 normalize.css 的基础上，根据一些使用习惯进行了归零设置，且设置所有元素的 box-sizing 为 border-box，外加一个 clearfix 类。
