# installgnomeicons

> 标签: applications, gnome, icons, linux, png, resize

## 简介

A simple script to resize an icon to all the sizes available in the .local/share/icons directory for gnome on linux

## 官网

- 官网：https://githb.com/VenRoot/icon_resize
- 源码仓库：git+https://github.com/VenRoot/icon_resize.git
- npm 页面：https://www.npmjs.com/package/installgnomeicons
