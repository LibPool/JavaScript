# ictpbx-mcp

> 标签: ai-agent, claude, ictcore, ictpbx, ip-pbx, mcp, model-context-protocol, pbx, sip, telephony, voip

## 简介

Model Context Protocol server for ICTPBX. Lets AI assistants read PBX state — extensions, DID numbers, SIP trunks, tenants and live statistics — over the ICTCore REST API.
