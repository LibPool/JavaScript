# ical-browser

> 标签: RFC 5545, alarm notifications, calendar library, event scheduling, iCalendar generator, icalendar events, ics file generator, journal entries, timezone support, todo management

## 简介

A library for generating iCalendar (ICS) files in Node.js and the browser, supporting events, todos, journals, alarms, and timezones.
