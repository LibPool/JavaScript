# iwantmymtg-mcp

> 标签: claude, magic-the-gathering, mcp, model-context-protocol, mtg

## 简介

MCP server for I Want My MTG - query cards/sets and manage your collection from Claude Desktop, Claude Code, Cursor, and other MCP clients.
