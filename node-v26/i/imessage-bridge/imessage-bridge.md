# imessage-bridge

> 标签: agentic, amqp, applescript, azure, entra, imessage, macos, messages.app, oauth, openclaw, service-bus

## 简介

OAuth-only iMessage bridge: producer enqueues to AMQP 1.0 (Azure Service Bus by default), Mac agent sends via Messages.app. Identity-only auth, no SAS, no PATs.
