# i18n-sharpen

> 标签: ast, astro, cli, extractor, hardcoded-strings, i18n, internationalization, l10n, localization, missing-keys, pruner, react, static-analysis, svelte, translation, typescript, unused-keys, validator, vue

## 简介

AST-based static analysis for i18n — finds missing keys, unused keys, dynamic patterns, and hardcoded strings across TS, JS, Vue, Svelte, and Astro.
