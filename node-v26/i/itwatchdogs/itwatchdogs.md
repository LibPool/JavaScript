# itwatchdogs

> 标签: JavaScript

## 简介

A library in Node.js for interfacing climate sensors from IT Watchdogs (MiniGoose, WeatherGoose, SuperGoose, RelayGoose...)

## 官网

- 源码仓库：git://github.com/devoncrouse/node-itwatchdogs.git
- npm 页面：https://www.npmjs.com/package/itwatchdogs

## 历史版本号

- 当前版本：0.0.1

- 0.0.1

## 获取地址

- npm 安装：`npm install itwatchdogs`
- npm registry：https://registry.npmjs.org/itwatchdogs
- Node 要求：>=0.10
