# insight-ui-monoeci

> 标签: bitcore-monoeci, blockchain, blockexplorer, front-end, insight, monoeci

## 简介

An open-source frontend for the Insight API. The Insight API provides you with a convenient, powerful and simple way to query and broadcast data on the Monoeci network and build your own services with it.
