# imagestep

> 标签: api, automation, image, image-generation, imagestep, mcp, n8n, remove-background, upscale

## 简介

ImageStep SDK — the image step for your automations: generate, edit, remove backgrounds, upscale, convert and read metadata through one API key, one job handle and one stable URL.
