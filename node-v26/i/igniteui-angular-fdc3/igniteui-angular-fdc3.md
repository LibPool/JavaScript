# igniteui-angular-fdc3

> 标签: UI components, angular, data adapter, fdc3, financial data, infragistics, openfin, openfin fdc3, visualization

## 简介

Ignite UI Angular FDC3 data adapter generates financial data for received FDC3 intents as well as sending messages to other FDC3-enabled apps using OpenFin's FDC3 service.
