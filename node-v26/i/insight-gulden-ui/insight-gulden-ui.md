# insight-gulden-ui

> 标签: blockchain, blockexplorer, front-end, gulden, guldencore, insight

## 简介

An open-source frontend for the Insight API. The Insight API provides you with a convenient, powerful and simple way to query and broadcast data on the gulden network and build your own services with it.
