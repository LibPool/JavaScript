# insight-ui-rpg

> 标签: blockchain, blockexplorer, front-end, insight, rpgcoin, rpgcore

## 简介

An open-source frontend for the Insight API. The Insight API provides you with a convenient, powerful and simple way to query and broadcast data on the rpgcoin network and build your own services with it.
