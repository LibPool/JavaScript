# image-caption

> 标签: annotate, annotation, bounding-box, canvas, fabric, fabricjs, image, image-annotation, image-caption, image-labeling, image-marker, label, labeling, labeling-tool, vue, vue-component, vue3, 图片标注, 在线图片标注, 数据集标注, 标注

## 简介

Vue 3 image annotation component based on fabric.js — draw rect / circle / polygon annotations on images with zoom, undo/redo, echo and PNG export. 基于 fabric.js 的 Vue3 在线图片标注组件
