# iphone-dimensions

> 标签: apple, dataset, device, dimensions, iphone, screen, size, specs

## 简介

Apple's published dimensions for every iPhone since 2007, with model identifiers: height, width, depth, weight, display and pixel density, in mm and inches, each row cited to Apple's tech specs.

## 官网

- 官网：https://iphonesize.com/data
- 源码仓库：git+https://github.com/iPhoneSize/iphone-dimensions.git
