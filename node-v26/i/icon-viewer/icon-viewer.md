# icon-viewer

> 标签: JavaScript

## 简介

随着项目体量的变大，`assets`中的图标会变的越来越多，其中嵌套的文件夹也会越来越深，找一个已经存在的图标变得越来越难，本插件可以获取 `assets` 文件夹下的所有图标，并且按照路径分类显示!
