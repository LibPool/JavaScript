# img2asciix

> 标签: ASCII

## 简介

一个零依赖、体积小的轻量JavaScript图片转 ASCII 库，支持浏览器、Nodejs及小程序，甚至是跨端应用（Uniapp、Electron ）。支持自定义字符集、Web Worker 多线程，一键生成高还原度字符画，可用于 CLI 工具、前端特效、日志水印、Discord/Slack Bot 等场景，API 简洁，开箱即用。
