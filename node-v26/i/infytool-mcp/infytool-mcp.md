# infytool-mcp

> 标签: convert, image-tools, infytool, mcp, model-context-protocol, pdf, svg

## 简介

Discovery MCP server for InfyTool — search 180+ free, in-browser file tools and get deep-link URLs. Discovery only: no files are ever uploaded or processed.
