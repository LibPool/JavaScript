# iiif-gallery-image

> 标签: dzi, gallery, iiif, iiif-presentation-3, openseadragon, tiff

## 简介

Generate IIIF presentation 3.0 JSON and IIIF image 2.0 services. Supports custom types for specific resource annotations and gallery images from a collection of images.
