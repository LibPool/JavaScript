# iuri-cli

> 标签: agent, chatgpt, claude-code, cli, playwright, tui

## 简介

Agente/CLI estilo Claude Code que dirige ChatGPT/Gemini/Grok/DeepSeek pelo navegador (sem API paga), com TUI, modo plano, imagens e modelo auxiliar local.
