# inteligir

> 标签: agent, local-first, markdown, notes, obsidian, vault

## 简介

The `inteligir` binary: `serve` runs the whole local server — vault, index, agent, API — and every other verb is an oRPC client against a running one. Agent-facing by design: every leaf takes --json, the server serves the manual, and agent shells get INTE
