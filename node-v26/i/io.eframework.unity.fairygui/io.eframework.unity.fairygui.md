# io.eframework.unity.fairygui

> 标签: eframework, fairygui, unity

## 简介

基于 FairyGUI 的拓展模块，提供了画布组件、资源包管理等核心功能，支持自定义加载器、自动处理包依赖关系以及编辑器扩展等特性。
