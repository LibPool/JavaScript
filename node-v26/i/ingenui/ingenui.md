# ingenui

> 标签: ai, generative-ui, incremental, jsx, llm, markdown, react, streaming

## 简介

Lightweight Generative UI framework: stream AI-generated Markdown with ui+jsx code fences into a live React tree, with an actions convention and structured feedback for the model.
