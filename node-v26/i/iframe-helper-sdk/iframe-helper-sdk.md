# iframe-helper-sdk

> 标签: bridge, browser, cross-domain, cross-origin, embed, iframe, iframe-bridge, origin-validation, post-message, postmessage, rpc, sandbox, type-safe, typescript, window-messaging

## 简介

TypeScript SDK for secure cross-domain iframe embeds with a strict postMessage bridge, origin validation, handshakes, RPC-style requests, events, and typed contracts.
