# i18n-auto-plugin

> 标签: auto-translate, i18n, react-i18n, translate, vue-i18n, 国际化, 翻译, 自动翻译

## 简介

自动国际化工具:扫描项目中的中文文本,通过翻译 API 生成多语言包,构建时将中文字符串替换为 `_i18n(hash)` 调用。支持 Vue3/React + Vite/Webpack/Rspack/Rolldown。
