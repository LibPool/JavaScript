# img-squeeze

> 标签: avif, compress, image, image-compress, jpeg, png, programmerhasan, resize, sharp, webp

## 简介

Tiny Node.js tool to compress images by quality/size/resize with sharp. Supports JPG, PNG, WebP, AVIF.

## 官网

- npm 页面：https://www.npmjs.com/package/img-squeeze

- 1.0.0

## 获取地址

- npm 安装：`npm install img-squeeze`
- npm registry：https://registry.npmjs.org/img-squeeze
- Node 要求：>=18
