> 标签: api-client, esports, iracing, iracing-api, iracing-data-api, iracing-data-client, motorsport, oauth2, racing, sdk, sim-racing, typescript

## 简介

Fully-typed HTTP Client for the iRacing Data API with automatic code generation, opt-in caching, smart authentication, and comprehensive error handling.
