# i18n-ai-extract-translate

> 标签: cli, extract, gemini, i18n, i18next, locale, translation

## 简介

Extract translatable strings from a React/JS codebase (and optionally a Python backend) into i18next JSON locale files, then auto-translate the missing entries with Gemini.
