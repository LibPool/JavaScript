# @sntlr/docs-shell

> 标签: docs, documentation, mdx, next, nextjs, registry, shadcn, shell, static-site, versioned-docs

## 简介

Static documentation sites with versioned docs, i18n, search and a theme panel, from a folder of MDX. Optional component-registry module (see @sntlr/registry-shell).
