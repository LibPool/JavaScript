# @sntlr/registry-shell

> 标签: components, docs, next, nextjs, registry, shadcn, shell, ui

## 简介

Generic Next.js viewer for component registries. Drop a registry-shell.config.ts into your registry and get a full docs/components/blocks site on localhost:3000.
