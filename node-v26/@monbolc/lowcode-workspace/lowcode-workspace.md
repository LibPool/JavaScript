# @monbolc/lowcode-workspace

> 标签: engine, lowcode, resource, window, workspace

## 简介

Workspace, EditorWindow, Resource for SapuLowcodeEngine (L5). Single-window — multi-doc is achieved by multi-mount, not by an in-tree tab bar.
