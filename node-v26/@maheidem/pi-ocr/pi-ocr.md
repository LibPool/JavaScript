# @maheidem/pi-ocr

> 标签: ocr, pdf, pi-extension, pi-package, tui, vision-model

## 简介

Pi extension: OCR PDFs (page-split) and images via a configurable vision model, with raw-text + verdict returns and auditable JSON sidecars.
