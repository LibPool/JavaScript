> 标签: components, feedback, form-builder, layout, react, ui, waysnx

## 简介

WaysNX UI Kit aggregate - a curated core set of five libraries (ui-core, ui-form-builder, ui-layout, ui-feedback, ui-grid-builder) in one install; other libraries install directly
