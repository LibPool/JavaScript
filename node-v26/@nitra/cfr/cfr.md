# @nitra/cfr

> 标签: config-connector, flux, fluxcd, gcp, gitops, kcc, kubernetes, kustomize, lint

## 简介

Kubernetes and GCP inventory utilities: validate Kustomize resources and reconcile live GCP coverage across Config Connector, OpenTofu state, and explicit ownership catalogs.
