# dsh-chat-digest

> 标签: agent-session, automation, chat-logs, cordis-plugin, deepseek-harness, digest, dsh, dsh-bundle, dsh-plugin, panel, qq, wechat

## 简介

Turn chat logs into a panel list maintained by a resident agent. Includes a zero npm-dependency core and an optional WeChat/QQ ingestion pipeline. Installs as a DSH profile bundle.
