# @granturismo/devicespecs

> 标签: api, client, devicespecs, gsmarena, hardware, mobile, phone, sdk, specs, typescript

## 简介

A strongly-typed, modern TypeScript/JavaScript client library for the DeviceSpecs API. Query structured, clean, and normalized specifications, chipsets, and physical metrics for over 12,000 mobile devices.
