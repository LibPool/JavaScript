# @kernlbase/orion

> 标签: agent, agent-runtime, durable-execution, event-sourcing, fork, llm, replay, trajectory

## 简介

An inspectable, recoverable, replayable, trajectory-native agent runtime. Agent runs are durable objects you can inspect, replay without cost, and fork from any point.
