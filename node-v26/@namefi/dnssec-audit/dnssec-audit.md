# @namefi/dnssec-audit

> 标签: dns, dnssec, doh, nsec, nsec3, pure-js, rfc4034, rfc5155, rrsig, trust-anchor, typescript

## 简介

Pure-TS DNSSEC chain-of-trust exporter and offline validator (NSEC + NSEC3). Works in Node and the browser.
