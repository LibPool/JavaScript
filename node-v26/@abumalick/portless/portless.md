# @abumalick/portless

> 标签: development, local, localhost, proxy

## 简介

Fork of portless with multi-label TLD support (e.g. --tld dev.example.com). Tracks upstream vercel-labs/portless. See https://github.com/vercel-labs/portless/pull/277 for the upstream patch this fork carries.
