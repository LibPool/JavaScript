# @gemboss/post-purchase-kit

> 标签: JavaScript

## 简介

Bản xem trước trang post-purchase Shopify: chạy chính extension post-purchase-offer của gemtheme, vẽ cây component Shopify thành HTML. Build từ gemtheme, không sửa ở đây.
