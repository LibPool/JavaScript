# @sparkelf/dsh-better-sidebar

> 标签: JavaScript

## 简介

Better Sidebar for DSH — file tree, editor, changes, tasks and side chat in one column, separate for every conversation. Also exposes a service other plugins use to register sidebar tabs and file viewers.
