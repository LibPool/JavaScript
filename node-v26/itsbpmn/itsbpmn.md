# itsbpmn

> 标签: alurkerja, bpmn, bpmn-as-code, camunda, camunda7, cli

## 简介

Write AlurKerja BPMN as small JSON and Groovy files, build one consistent .bpmn, and pull, push and deploy it to AlurKerja Studio
