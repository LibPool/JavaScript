# @daytona/claude-toolsets

> 标签: agent, anthropic, browser, browser-use, claude, computer-use, cua, daytona, sandbox, toolset, typescript

## 简介

Daytona sandbox drivers for the Anthropic SDK's computer and browser toolsets — hand one to the SDK's tool runner and Claude drives a desktop or a Chromium running in an isolated Daytona sandbox
