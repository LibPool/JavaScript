# @nuwax-ai/nuwax-grok

> 标签: agent, ai, cli, grok, tui

## 简介

Grok Build CLI — an agentic coding tool powered by a native Rust binary. This package is a thin launcher; the actual binary is provided by per-platform optional dependencies.
