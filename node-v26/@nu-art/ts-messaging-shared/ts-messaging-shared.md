# @nu-art/ts-messaging-shared

> 标签: TacB0sS, infra, nu-art, thunderstorm, ts-messaging, typescript

## 简介

A messaging module for Thunderstorm framework that provides topic-based messaging system with support for different message types (text, image, video) and discussion management features
