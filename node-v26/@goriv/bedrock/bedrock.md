# @goriv/bedrock

> 标签: bbp, intigriti, poc, research, security

## 简介

Security research PoC for Intigriti BBP (Rivian program). Mirror of internal package name @rivian/bedrock referenced in Rivian production bundles. The @rivian npm scope is trademark-protected; @goriv (matches goriv.co internal TLD) was claimable. DNS-only
