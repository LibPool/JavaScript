# gpu-observatory

> 标签: cluster, dashboard, gpu, gpu-monitoring, hpc, monitoring, nvidia, nvidia-smi, self-hosted, slurm

## 简介

Self-hosted, push-based dashboard showing which user and process is using every NVIDIA GPU across your hosts, plus CPU, memory, disk and Slurm.
