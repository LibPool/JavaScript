# @stapel/geo-react

> 标签: JavaScript

## 简介

React pair for stapel-geo: the human half of a location. A picker a product mounts once and gets a map, search-as-you-type, the browser's position prompt and a draggable pin that turns into a real address — instead of two raw fields called latitude and lo
