# @stapel/vocabularies-react

> 标签: JavaScript

## 简介

Reference vocabularies too large to inline into a category schema: term typeahead and code-to-label resolve behind the VocabularyClient seam, plus the antd term controls — an inline select and a picker-sheet field.
