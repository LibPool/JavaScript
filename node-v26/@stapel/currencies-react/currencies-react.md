# @stapel/currencies-react

> 标签: JavaScript

## 简介

React pair for stapel-currencies: the Money layer of the fleet. One formatter (Intl.NumberFormat, per locale, per currency's minor units), one converter (decimal-string BigInt math in parity with the backend's services.convert), and an opt-in /default ant
