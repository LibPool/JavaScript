# @hyper63/adapter-couchdb

> 标签: JavaScript

## 简介

This adapter connects the hyper63 service framework `data` port to the couchdb database. When using this adapter, you will need to configure three environment variables, one for the `server-admin` credentials, so that the adapter can create/delete databas
