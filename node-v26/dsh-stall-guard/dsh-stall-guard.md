# dsh-stall-guard

> 标签: cordis, deepseek, deepseek-harness, download, dsh, dsh-plugin, github, harness, mirror, monitor, network, plugin, proxy, reliability, retry, timeout, watchdog, web

## 简介

DSH 卡顿守卫：下载类命令（git clone / pnpm install / pip / curl）超时后自动中止，并把「换个下载源重试」的提示写进工具结果给智能体看，解决 GitHub 在国内网络不稳导致智能体一直干等的问题。另可按工具类型自定义超时秒数，并附一个只在卡顿时唤醒的 DeepSeek 监督员。
