# @antora/epub-extension

> 标签: antora, antora-extension, asciidoc, asciidoctor, documentation, epub, generator

## 简介

An Antora extension that uses Assembler to merge pages into assembly files, export them to the EPUB format, and publish them with the site.

## 官网

- 官网：https://antora.org
- 源码仓库：git+https://gitlab.com/antora/antora-assembler.git
- npm 页面：https://www.npmjs.com/package/@antora/epub-extension
