# @idle-runner/worker

> 标签: @idle-runner/worker, INP, abortsignal, core-web-vitals, generator, idle-runner, main-thread, off-main-thread, offload, performance, postMessage, rpc, structured-clone, transferable, typescript, web-worker, worker, worker-thread

## 简介

Send heavy work to a Web Worker and await the result: a named task registry, AbortSignal cancellation, transferables and generator chunking. Zero dependencies.
