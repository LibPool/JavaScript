# @idle-runner/react

> 标签: @idle-runner/react, INP, core-web-vitals, hooks, idle, idle-runner, main-thread, nextjs, performance, react, react-hooks, requestIdleCallback, safari, scheduler, task-queue, typescript

## 简介

React hooks (useIdleTask, useIdleValue, useIdleCallback, useIdleEffect) to defer and time-slice non-urgent work off the main thread with requestIdleCallback — works on Safari, where it never shipped.
