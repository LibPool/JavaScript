# @idle-runner/core

> 标签: @idle-runner/core, INP, browser-performance, core-web-vitals, generator, idle, idle-runner, main-thread, performance, requestIdleCallback, requestidlecallback-polyfill, safari, scheduler, task-queue, task-scheduler, time-slicing, typescript, web-vitals

## 简介

Idle runner that defers and time-slices non-urgent work off the main thread, like requestIdleCallback but Safari-safe. Zero dependencies.
