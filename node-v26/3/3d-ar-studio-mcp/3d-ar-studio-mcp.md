# 3d-ar-studio-mcp

> 标签: 3d, ar, augmented-reality, glb, mcp, model-context-protocol, quick-look, scene-viewer, text-to-3d, three.ws, webxr

## 简介

MCP server for 3D AR Studio: generate 3D models, search a free CC0 library, arrange them into one scene, and hand back a link that opens the whole arrangement in augmented reality on a phone.
