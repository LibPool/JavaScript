# 3bodycalc

> 标签: 3Body, ThreeBody

## 简介

《三体》真人电视剧，魏成同款三体问题计算器。三体问题是天体力学中的基本力学模型。它是指三个质量、初始位置和初始速度都是任意的可视为质点的天体，在相互之间万有引力的作用下的运动规律问题。本工具出现在剧中第16集03:50处。
