# @baryodev/barako-client

> 标签: api, barakocms, client, cms, content, headless, sdk, typescript

## 简介

Typed TypeScript client for the barakoCMS headless API. Framework-agnostic (Node, browser, edge), API-key or JWT auth with refresh, tenant handling, and typed content/schema resources.
