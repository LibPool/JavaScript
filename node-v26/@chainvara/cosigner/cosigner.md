# @chainvara/cosigner

> 标签: chainvara, cosigner, crypto, custody, mpc, treasury, wallet

## 简介

Chainvara API co-signer: your own machine approves every transfer and holds your half of every split and MPC key. One file, no dependencies, Node.js 20+.

## 官网

- 官网：https://www.chainvara.com/guides/cosigner
- 源码仓库：git+https://github.com/G0TZEth/chainvara-cosigner.git
- npm 页面：https://www.npmjs.com/package/@chainvara/cosigner
