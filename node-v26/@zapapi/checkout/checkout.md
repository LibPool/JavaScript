# @zapapi/checkout

> 标签: bitcoin, checkout, lightning, payments, typescript, webln, widget, zapapi

## 简介

Drop-in Lightning checkout widget for ZapAPI — one script tag, instant payments. TypeScript-first, zero runtime deps, WebLN + QR fallback.
