# @prsgoo/integration-open-elevation

> 标签: elevation, geo, open-elevation, pulsebridge, pulsebridge-plugin

## 简介

PulseBridge integration plugin for Open-Elevation — look up terrain elevation for a batch of coordinates via an on-demand action.
