# @a-sync/opencv4nodejs

> 标签: async, computer vision, cv, detection, face, learning, machine, network, neural, opencv, recognition, typescript

## 简介

Asynchronous OpenCV 3.x nodejs bindings with JavaScript and TypeScript API. (This fork defaults to disabled auto build, and checks for OPENCV4NODEJS_ENABLE_AUTOBUILD)
