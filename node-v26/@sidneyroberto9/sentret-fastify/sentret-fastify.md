# @sidneyroberto9/sentret-fastify

> 标签: authentication, cookie, drizzle, fastify, fastify-plugin, postgres, sentret, session

## 简介

Cookie-based session authentication for Fastify 5 on PostgreSQL, with an optional inactivity hub. Port of the sentret-session Java library.
