# @yoonpay/mcp

> 标签: mcp, model-context-protocol, orange-money, payments, senegal, wave, xof, yoon

## 简介

MCP server for Yoon, a self-hosted payment gateway for African payment providers: lets an AI assistant read your payments, subscriptions and invoices.
