# @openreceive/elements

> 标签: bitcoin, bolt11, checkout, custom-elements, lightning, nwc, openreceive, payments, web-components

## 简介

Bitcoin Lightning checkout for any website using custom elements, with optional USDT, USDC, SOL and ETH swaps.
