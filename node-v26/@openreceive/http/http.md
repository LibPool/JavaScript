# @openreceive/http

> 标签: JavaScript

## 简介

Node.js HTTP routes and payment storage for Bitcoin Lightning checkout, with optional USDT, USDC, SOL and ETH swaps.

- 官网：https://openreceive.org
- 源码仓库：git+https://github.com/openreceive/openreceive.git
- npm 页面：https://www.npmjs.com/package/@openreceive/http
