# @ts-ioc-container/entity-framework

> 标签: change-tracking, dependency-injection, entity, identity-map, ioc, repository, ts-ioc-container, unit-of-work

## 简介

A unit of work over plain DTOs for ts-ioc-container: an identity map per repository, snapshot change tracking, and one flush for a scope's changes. No query language, no ORM.
