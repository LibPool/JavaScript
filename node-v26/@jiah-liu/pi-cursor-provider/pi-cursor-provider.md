# @jiah-liu/pi-cursor-provider

> 标签: ai, cursor, custom-provider, llm, pi, pi-package

## 简介

Pi Coding Agent custom provider that routes requests through the Cursor Agent CLI — use your Cursor subscription models (Claude, GPT, Gemini, Grok…) inside Pi.
