# @bubblav/strapi-plugin-bubblav

> 标签: bubblav, chatbot, strapi, strapi-plugin

## 简介

Connect your Strapi content to BubblaV, the AI chatbot for your website. Adds a Settings page that walks you through creating a read-only API token and opens the BubblaV connect flow.
