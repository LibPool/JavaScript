# dsh-whale-loli

> 标签: agent-preset, cordis, deepseek, deepseek-harness, dsh, dsh-plugin, electron, memory, persona, plugin, whale-loli

## 简介

鲸鱼娘 Agent 预设（四个：原版 / 活人版 / 涩涩版 / 女儿版）— 极简模式工具面 + 鲸鱼娘·小鱼人设 + 跨会话长期记忆（四区格式：固定记忆永久、滚动摘要 80 条 FIFO、最近详细区、归档索引）。记忆走提示变量注入（读）+ 每个预设一条专用写入工具（写），四个预设各自独立文件、独立变量、独立工具、互不相通。女儿版称呼「爸爸」、性格天真活泼可爱。内部思考（思维链）在四个预设里都钉成**一律简体中文**（只约束怎么想，不约束怎么答；宿主没有这个开关，只能靠人设硬规则，verify-think
