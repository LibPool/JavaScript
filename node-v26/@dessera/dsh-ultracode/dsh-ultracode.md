# @dessera/dsh-ultracode

> 标签: cordis, deepseek-harness, dsh, plugin, ultracode, workflow

## 简介

Ultracode session mode for DeepSeek Harness: a three-position composer control that arms automatic multi-agent workflow orchestration by injecting an arming banner ahead of the user's own message.
