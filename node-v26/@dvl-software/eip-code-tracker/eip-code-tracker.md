# @dvl-software/eip-code-tracker

> 标签: ai-usage, ccusage, claude, claude-code, devinsight, dvl-software, eip

## 简介

Push Claude Code daily usage from a developer machine to your dvl-finance tenant. Wraps `ccusage daily --json` and posts deltas to the Engineering Insights Platform ingest endpoint.
