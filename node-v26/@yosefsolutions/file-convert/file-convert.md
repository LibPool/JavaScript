# @yosefsolutions/file-convert

> 标签: ghostscript, imagemagick, keynote to image, keynote to pdf, libreoffice, odp to image, pdf to image, ppt to image, ppt to pdf, pptx to image, pptx to pdf

## 简介

The package export ppt, pptx, odp and key files to pdf and/or img(png, jpg, jpeg and etc...).
