# @tonyakitori/trackly

> 标签: cli, invoicing, mcp, mcp-server, time-tracking, toggl

## 简介

Time-tracking CLI with workspaces, projects, tags, rates, PDF/CSV reports, PDF invoices, and an MCP server.
