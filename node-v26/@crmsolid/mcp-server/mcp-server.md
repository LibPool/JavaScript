# @crmsolid/mcp-server

> 标签: ai-agent, claude, crm, dm, instagram, mcp, mcp-server, model-context-protocol, scheduler, social-media, whatsapp

## 简介

Manage every social media DM and post from your AI assistant, over MCP. Stdio Model Context Protocol server for CRM Solid: Instagram, Facebook, X, LinkedIn, TikTok, YouTube, Threads, Pinterest, Reddit, Bluesky, Telegram and WhatsApp inboxes plus scheduled
