# @uoe-eng/tabularasa

> 标签: JavaScript

## 简介

`Tabularasa` is a Vue plugin which acts as a wrapper around a variety of [PrimeVue](https://www.primefaces.org/primevue/) widgets to provide a Search-List-Detail interface.
