# @form-create/iview4

> 标签: @form-create, components, dynamic-form, form, form-builder, lowcode, view-design, vue, 低代码, 动态表单

## 简介

ViewDesign版本低代码表单|FormCreate 是一个可以通过 JSON 生成具有动态渲染、数据收集、验证和提交功能的低代码表单生成组件。支持6个UI框架，适配移动端，并且支持生成任何 Vue 组件。内置20种常用表单组件和自定义组件，再复杂的表单都可以轻松搞定。
