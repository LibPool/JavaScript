# dsh-abort-polyfill

> 标签: AbortSignal, deepseek-harness, dsh, ios, plugin, polyfill, webkit

## 简介

DSH client plugin: install AbortSignal.any, Promise.withResolvers and other Safari 17.4-era APIs before other client plugins load (older iOS WebKit).
