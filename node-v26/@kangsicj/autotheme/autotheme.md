# @kangsicj/autotheme

> 标签: dark-mode, dark-theme, ios, light-mode, safari, tampermonkey, userscript, userscripts

## 简介

Automatic dark / light theme for every website — the site's own theme first, a built-in Theme Reader engine as fallback. Userscript for the iOS Userscripts app and Tampermonkey.
