# @markell12/textract

> 标签: csv, doc, docx, dxf, epub, extract, gif, html, jpg, markdown, odg, ods, odt, otg, ots, ott, pdf, png, potx, pptx, rtf, text, textract, xls, xlsb, xlsm, xlsx, xltx, xml

## 简介

Extracting text from files of various type including html, pdf, doc, docx, xls, xlsx, csv, pptx, png, jpg, gif, rtf, text/*, and various open office. (Fixed new line bug for pptx)
