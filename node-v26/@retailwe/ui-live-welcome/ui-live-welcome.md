# @retailwe/ui-live-welcome

> 标签: JavaScript

## 简介

用户行为提示组件，**组件已内置队列处理逻辑，每2.2s执行一次动画，可以有效防止消息堆积问题**。同时可以自定义配置信息，修改动画文案和背景。
