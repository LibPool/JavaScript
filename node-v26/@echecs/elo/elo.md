# @echecs/elo

> 标签: chess, elo, expected score, fide, initial-rating, k-factor, no-dependencies, performance-rating, ranking, rating, typescript

## 简介

ELO rating system calculator following FIDE rules. Computes K-factor, expected score, rating delta, performance rating, and initial rating for unrated players. Zero dependencies, strict TypeScript.
