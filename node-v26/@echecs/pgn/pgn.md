# @echecs/pgn

> 标签: chess, game, no-dependencies, notation, parser, pgn, pgn-parser, portable game notation, serializer, typescript

## 简介

Parse and stringify PGN (Portable Game Notation) chess games. Zero dependencies, strict TypeScript, no-throw parse API.
