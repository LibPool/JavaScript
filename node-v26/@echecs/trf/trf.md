# @echecs/trf

> 标签: arbiter, chess, fide, no-dependencies, pairing, parser, swiss, tournament, tournament report file, trf, typescript

## 简介

Parse and stringify FIDE Tournament Report Files (TRF) from chess pairing software. Zero dependencies, strict TypeScript.
