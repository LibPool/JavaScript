# @woladi/sortai

> 标签: ai, apple-vision, automation, cli, finder-tags, macos, ocr, ollama, tagging

## 简介

Automatically tag and describe your files using Apple Vision OCR + local Ollama or cloud LLM — writes native Finder tags and comments searchable in Spotlight
