# @kadal/theme-neon

> 标签: dark, kadal-deck, kadal-theme, launch, neon, presentation, slides, synthwave, theme

## 简介

Neon, a theme for Kadal Deck (@kadal/deck). A dark synthwave theme for meetups and launches: a sunset horizon, glows that stay legible, and a solid print fallback.
