# @kadal/theme-folio

> 标签: editorial, essay, kadal-deck, kadal-theme, keynote, presentation, serif, slides, theme

## 简介

Folio, a theme for Kadal Deck (@kadal/deck). An editorial serif theme for essays and keynotes: warm paper, a high-contrast display serif, generous whitespace.
