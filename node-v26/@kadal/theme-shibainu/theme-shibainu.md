# @kadal/theme-shibainu

> 标签: kadal-deck, kadal-theme, presentation, slides, slidev-port, theme

## 简介

Shibainu: Slidev's shibainu theme, ported to Kadal Deck. Soft blobs in a shiba's browns, Titillium Web, fourteen layouts; dark.
