# @eventfabric/mediator-opentelemetry

> 标签: command, command-bus, eventfabric, mediator, metrics, observability, opentelemetry, otel, tracing, typescript

## 简介

OpenTelemetry adapter for @eventfabric/mediator: a CommandBus middleware that emits tracing spans + counters + duration histograms per command, plus observable gauges for the command idempotency table.
