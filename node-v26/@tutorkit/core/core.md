# @tutorkit/core

> 标签: education, p2p, peer-connection, tutoring, typescript, video-call, webrtc

## 简介

Framework-agnostic TypeScript core for TutorKit: P2P WebRTC peer connections, screen share, quality auto-degradation, reconnection, and talk-time analytics for 1:1 tutoring sessions.
