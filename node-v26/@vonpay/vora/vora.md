# @vonpay/vora

> 标签: card, checkout, loader, payments, types, vonpay, vora

## 简介

TypeScript types and a loader for Vora.js, the Von Payments browser SDK. Loads the script from js.vonpay.com; the payment code itself is never bundled.

## 官网

- 官网：https://docs.vonpay.com
- 源码仓库：git+https://github.com/Von-Payments/vonpay.git
- npm 页面：https://www.npmjs.com/package/@vonpay/vora
