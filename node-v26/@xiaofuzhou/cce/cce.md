# @xiaofuzhou/cce

> 标签: anthropic, ccr, claude, claude-code, cli, deepseek, env, glm, kimi, launcher, moonshot, picker

## 简介

Per-process Claude Code env launcher with default args management (global + per-env), interactive picker, shell completion, and env-leak protection. One command to inject provider env (DeepSeek/Kimi/GLM/CCR/...) and start claude.
