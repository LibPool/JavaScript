# dsh-as-mcp-server

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, mcp, mcp-server, streamable-http

## 简介

Exposes DSH as an MCP server over Streamable HTTP: streaming thinking/tool/file notifications, shared intent, a floor lock that physically denies DSH writes while held, mid-turn alert injection, and review delegation.
