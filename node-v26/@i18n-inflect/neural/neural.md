# @i18n-inflect/neural

> 标签: JavaScript

## 简介

Neural inflection fallback runtime for i18n-inflect — tiny char-level seq2seq models over a swappable inference engine (onnxruntime-web, onnxruntime-node, or the cordova-plugin-boogie-onnx native bridge).
