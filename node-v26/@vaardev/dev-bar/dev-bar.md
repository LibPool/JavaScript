# @vaardev/dev-bar

> 标签: JavaScript

## 简介

A drop-in developer toolbar component for React apps. Starts out as a small square button (bottom-right by default); clicking it expands into a horizontal toolbar of developer-configured tools, where each tool button opens its own pane of custom content.
