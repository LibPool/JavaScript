# @zaogaogwc/dsh-plugin-manager

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, mod-manager, plugin-manager

## 简介

DSH Web GUI Mod 管理器：按预设/来源包/分类三级浏览，批量热开关、变更预览与撤销、AI 筛选，以及基于任意现有预设创建新预设。
