# @amxts/core

> 标签: amxmodx, assemblyscript, counter-strike, cs16, game-server, typescript, webassembly

## 简介

Counter-Strike 1.6 plugins in TypeScript: compiled ahead of time and run inside AMX Mod X, next to Pawn plugins.
