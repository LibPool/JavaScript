# @frica/id-sdk

> 标签: africa, authentication, frica, frica-id, identity, oauth2, oidc, pkce, sign-in-with-frica, sso

## 简介

Official TypeScript/JavaScript SDK for Sign in with Frica ID. OAuth 2.1 PKCE authorization, user management, and seamless authentication for Web and Node.js.
