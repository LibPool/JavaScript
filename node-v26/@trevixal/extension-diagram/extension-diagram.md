# @trevixal/extension-diagram

> 标签: diagram, editor, extension, mermaid, rich-text, rich-text-editor, trevixal, typescript, wysiwyg

## 简介

Diagrams for the Trevixal editor: Mermaid (and other text-to-diagram) code blocks rendered to a live preview through a pluggable renderer.
