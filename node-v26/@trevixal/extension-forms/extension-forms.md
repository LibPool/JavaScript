# @trevixal/extension-forms

> 标签: editor, extension, forms, mail-merge, pdf-forms, rich-text, rich-text-editor, trevixal, typescript, wysiwyg

## 简介

Forms and mail merge for the Trevixal editor: content controls (text, checkbox, dropdown, date, signature), PDF form export, and one document per row of a CSV or JSON file.
