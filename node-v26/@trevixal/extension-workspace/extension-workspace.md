# @trevixal/extension-workspace

> 标签: documents, editor, extension, rich-text, rich-text-editor, tabs, trevixal, typescript, workspace, wysiwyg

## 简介

Workspace for the Trevixal editor: a document store with folders, templates, recents and favourites, a tab strip, a split view and a live preview.
