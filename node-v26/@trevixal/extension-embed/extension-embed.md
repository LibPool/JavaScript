# @trevixal/extension-embed

> 标签: attachments, editor, embed, extension, rich-text, rich-text-editor, trevixal, typescript, video, wysiwyg, youtube

## 简介

Media embeds for the Trevixal editor: video, audio, YouTube/Vimeo and iframe embeds, file attachments and link preview cards.
