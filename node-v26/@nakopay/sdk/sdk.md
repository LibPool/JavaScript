# @nakopay/sdk

> 标签: bitcoin, btcpay, crypto, invoices, lightning, litecoin, monero, nakopay, payments, webhooks

## 简介

Official NakoPay SDK for Node.js and TypeScript. Accept Bitcoin, Lightning, Litecoin, Monero and more with a Stripe-style API.
