# create-drobek-module

> 标签: drobek, drobek-module, mcp

## 简介

Scaffold a drobek platform module: npm create drobek-module@latest <name> — routes, SDK, a migration, SKILL.md, vitest + PGlite tests and the checkSkill gate.
