# @touchque/create

> 标签: 2fa, create, init, mfa, passkeys, scaffold, touchque

## 简介

Add TouchQue to an existing project in one command: detects Node, Python, PHP or Go and writes the setup file, .env.example entries and (optionally) the MCP config and agent skill.
