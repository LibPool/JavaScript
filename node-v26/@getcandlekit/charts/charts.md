# @getcandlekit/charts

> 标签: candlestick, charting-library, charts, data-visualization, drawing-tools, financial-charts, fintech, indicators, lightweight-charts, ohlc, react, replay, stock-market, technical-analysis, trading, tradingview

## 简介

Tree-shakeable financial charting toolkit: candlestick/OHLC/line/area/volume, drawing tools, pluggable indicators, measurement tools, and a deterministic replay engine. Built on lightweight-charts. Framework-agnostic core + optional React bindings.
