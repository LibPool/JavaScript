# tailwindshades-cli

> 标签: cli, color, oklch, palette, shades, tailwind, tailwind v4, tailwindcss, theme

## 简介

Generate Tailwind CSS color palettes (50–950) from any color, for Tailwind v4, v3, v2 and v1
