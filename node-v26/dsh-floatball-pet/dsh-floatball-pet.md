# dsh-floatball-pet

> 标签: cordis, deepseek-harness, dsh, floating-ball, pet, plugin

## 简介

DeepSeek Harness 悬浮球插件：悬浮球 + 灵动岛（余额 / 运行时间）+ 设置面板，点击悬浮球唤起 DSH。
