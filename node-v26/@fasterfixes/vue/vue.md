# @fasterfixes/vue

> 标签: annotation, bug-reporting, feedback, nuxt, qa, screenshot, user-feedback, visual-feedback, vue, vue-plugin, widget

## 简介

Vue plugin for the FasterFixes feedback widget. Reviewers annotate elements and submit visual feedback on your Vue or Nuxt app.
