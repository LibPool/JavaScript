# @hi-dsh/tailscale

> 标签: deepseek, deepseek-harness, dsh, remote-access, serve, tailnet, tailscale, zero-config

## 简介

Tailnet-only remote access for a loopback-bound dsh web server: identity-gated loopback proxy plus an automatic tailscale serve HTTPS route. 让 dsh 在不暴露任何对外端口的前提下，从你的 Tailscale 虚拟局域网内安全访问。
