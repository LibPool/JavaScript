## 简介

```bash 全局安装: pnpm add @swiftcrab/rapper -g 安装: pnpm add @swiftcrab/request 登录: `rapper login` 更新接口: `rapper update 或 rapper up` 登出: `rapper logout` 查看版本: `rapper --version` ```
