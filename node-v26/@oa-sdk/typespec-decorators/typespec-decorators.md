# @oa-sdk/typespec-decorators

> 标签: JavaScript

## 简介

Trusted, narrow TypeSpec authoring helpers for OA SDK's versioned extension contract. The package deliberately does not expose a generic decorator for arbitrary `x-oa-sdk-*` JSON.
