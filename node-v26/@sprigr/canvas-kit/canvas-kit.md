# @sprigr/canvas-kit

> 标签: canvas, company-graph, dashboard, mcp, sprigr, websocket, whiteboard

## 简介

Build a live canvas of a Sprigr company: graph builder, company events socket client, agent socket frame types, webhook signing and event-forwarder helpers.
