> 标签: ai, ai-agents, calculator, economics, energy, llm, mcp, modelcontextprotocol, proof-adjusted-autonomy, revocation-exposure, token-cost

## 简介

MCP server for AI economics: token cost, context windows, agent-hour cost, LLM energy, joules per verified task, Proof-Adjusted Autonomy, revocation exposure and more. Wraps the free piszczek.pl/tools API — no key required.
