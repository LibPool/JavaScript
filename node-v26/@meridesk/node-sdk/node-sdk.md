# @meridesk/node-sdk

> 标签: customer-support, helpdesk, identity-verification, knowledge-base, meridesk, sdk, tickets

## 简介

Official Node.js SDK for Meridesk — integrate customer support (tickets, customers, knowledge base articles, secure widget identity verification) into your backend using an API key.
