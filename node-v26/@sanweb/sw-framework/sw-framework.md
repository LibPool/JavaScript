# @sanweb/sw-framework

> 标签: accessibility, css, framework, vanilla-js, view-transitions, zero-dependency

## 简介

Framework web nativo e sem dependencias: CSS modular, componentes acessiveis, transicoes de pagina via View Transitions API e efeitos SW-FX progressivos.
