# @salesforce/ui-bundle-template-base-angular-app

> 标签: JavaScript

## 简介

Base Angular app template — an Angular UI Bundle with Angular CLI, @angular-builders/custom-esbuild, TypeScript, Tailwind, Spartan NG (shadcn/ui for Angular), and the Salesforce UI Bundle plugin. Used as the foundation for feature apps when applying patch
