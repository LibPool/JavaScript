# @munichremarkets/component-library

> 标签: JavaScript

## 简介

This package provides the _Component Library_ by Munich Re Markets containing components that are common to many or all of the Munich Re Markets widgets. It is used as a dependency of the widget packages, so you do not have to install it directly.
