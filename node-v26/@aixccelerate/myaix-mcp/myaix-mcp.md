# @aixccelerate/myaix-mcp

> 标签: JavaScript

## 简介

Local stdio MCP shim for myaix.link — handles auth and large file uploads for Cursor, VS Code, Codex, and any stdio-only MCP host.

## 官网

- 官网：https://myaix.link
- npm 页面：https://www.npmjs.com/package/@aixccelerate/myaix-mcp
