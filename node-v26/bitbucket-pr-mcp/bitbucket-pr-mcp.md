# bitbucket-pr-mcp

> 标签: bitbucket, bitbucket-cloud, claude, claude-code, code-review, mcp, model-context-protocol, pull-request, pull-request-comments

## 简介

MCP server for Bitbucket Cloud pull requests: create and update PRs, read and reply to comments, inline comments, resolve threads, approve or request changes, merge and decline.
