# @sumomok/dsh-balance

> 标签: balance, deepseek-harness, dsh, dsh-plugin, spend

## 简介

Account balance and spend for the DeepSeek Harness web GUI: a sidebar chip that follows the current session's provider, a provider picker over the providers this deployment can currently show a balance for, and per-session/today/month/all-time spend price
