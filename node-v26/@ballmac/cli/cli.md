# @ballmac/cli

> 标签: ballmac, components, react, shadcn, shadcn-ui, tailwindcss, three-way-merge, update, vitest

## 简介

Keep Ballmac UI components up to date without losing your changes, and install their tests. Works next to the shadcn CLI.
