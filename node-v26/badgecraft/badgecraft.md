# badgecraft

> 标签: achievement, award, badge, cli, enamel, metal, pbr, png, react, svg, svg-to-png, vue, web-component, webgl, webp

## 简介

Interactive 3D badges from any SVG, in metal, enamel, glitter, pearl and more, for React, Vue, Web Components and JavaScript, with a web Studio and image export CLI.
