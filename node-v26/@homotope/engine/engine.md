# @homotope/engine

> 标签: bitmap-to-vector, centerline, dxf, eps, image-tracing, jpg-to-svg, pdf, png-to-svg, potrace-alternative, raster-to-vector, svg, typescript, vectorization, vectorize, vectorizer, web-worker

## 简介

Raster-to-vector engine (PNG/JPEG → SVG, DXF, PDF, EPS, centerline) in pure TypeScript: no DOM, no dependencies, runs in a Web Worker and in Node.
