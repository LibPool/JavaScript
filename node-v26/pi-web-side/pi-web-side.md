# pi-web-side

> 标签: btw, pi, pi-coding-agent, pi-extension, pi-package, pi-web, side-question

## 简介

/side: ask side questions in pi without touching the main conversation. Works in Pi Web (@agegr/pi-web), RPC mode and the TUI; optional right-side side-chat panel for Pi Web (userscript).
