# @ssunil/n8n-nodes-puppeteer-service

> 标签: basecamp, browser, chromium, n8n-community-node-package, pdf, puppeteer, screenshot

## 简介

Puppeteer node for n8n. Runs Chrome DIRECTLY inside n8n — no external server needed. Auto-installs Chromium on first run. Supports Basecamp login, PDF download, screenshots.
