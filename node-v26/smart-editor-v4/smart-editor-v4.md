# smart-editor-v4

> 标签: JavaScript

## 简介

Smart Editor v4 是基于 Vue 3 和 Tiptap 3 的业务富文本编辑器，用于直接替代 Smart Editor v3。当前版本使用 Tiptap 3.30.5，保留 v3 的主要业务节点、持久化字段、编辑交互和历史数据约定。
