# cortico-world-web-pro

> 标签: coopanion, cortico, cortico-world, search, web

## 简介

联网 Pro：给 Coopanion / Cortico 桌宠的多源联网搜索与正文阅读扩展。AnySearch 主力，Bing/搜狗/360 兜底，Defuddle 提取正文。
