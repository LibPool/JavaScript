# @tbolp/pi-skill-manager

> 标签: coding-agent, pi, pi-extension, pi-package, skill-manager, skills

## 简介

Interactive Pi extension to manage skill loading: per-skill toggles at global and per-project scope, with project-level three-state (disable/enable/inherit).
