# @comark/react

> 标签: ai, ai-chat, comark, components, generative-ui, intelligent-ui, llm, markdown, markdown-renderer, mdc, mdx, nextjs, react, renderer, streaming, streaming-markdown

## 简介

React renderer for Comark. Render Markdown with components at runtime, with streaming support for AI output. Works with Next.js and Server Components.
