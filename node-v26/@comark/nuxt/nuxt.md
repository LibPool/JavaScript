# @comark/nuxt

> 标签: ai, ai-chat, comark, components, llm, markdown, markdown-renderer, mdc, nuxt, nuxt-module, renderer, streaming, streaming-markdown, vue

## 简介

Nuxt module for Comark. Render Markdown with components at runtime, with auto-imported components and streaming support for AI output.
