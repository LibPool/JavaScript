# @cyberskill/cyberos

> 标签: agents, cyberos, gates, hitl, mcp, tasks, workflow

## 简介

Run the CyberOS ship-tasks workflow in any repo - install, gates, and an MCP server, wired for every popular coding agent (Claude Code, Codex, Cursor, Gemini, Antigravity, Grok CLI, zcode, Command Code, Copilot, Windsurf).
