# rawstate-idb

> 标签: broadcastchannel, cache, indexeddb, local-first, migrations, offline, persistence, rawstate, state, store, typescript

## 简介

Saves a rawstate store to IndexedDB, loads it at start and keeps browser tabs in sync. Atomic writes, versions and migrations. About 3 KB gzipped.
