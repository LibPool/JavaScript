# @lumaform/orb

> 标签: ai-assistant, ambient, animation, generative, glsl, orb, shader, three, threejs, webgl

## 简介

WebGL runtime for ambient, reactive AI-assistant orbs: 45 shader engines, a modulation rack, and a versioned config format.
