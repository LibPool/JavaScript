# @ascendenceai/cortena-extensions-auth

> 标签: JavaScript

## 简介

The server-side auth middleware of §2 and §4: cortena-auth JWT verification (RS256 via JWKS, HS256 fallback), requireOrgMatch, the licence check that fails closed, and the org-role guards.
