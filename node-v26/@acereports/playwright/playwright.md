# @acereports/playwright

> 标签: ace-reports, acereports, api-testing, flaky-tests, html-report, playwright, playwright-reporter, playwright-test, reporter, test-automation, test-report, testing, typescript

## 简介

Ace Reports for Playwright Test: zero-setup HTML test reports that automatically capture every API request and response, screenshots on failure, steps, logs, retries and flaky tests.
