# @acereports/core

> 标签: ace-reports, acereports, api-testing, flaky-tests, html-report, playwright, reporter, test-automation, test-report, testing, typescript

## 简介

The engine behind Ace Reports: one self-contained HTML test report per run, with API calls, screenshots, logs, retries and flaky tests. Use it through @acereports/playwright, @acereports/jest, @acereports/vitest or @acereports/cucumber.
