# @jainil_desai/fleet

> 标签: agents, claude, claude-code, cost, dashboard, iterm, macos, subagents

## 简介

A local dashboard for every Claude Code session on your Mac: live agents, subagents, workflows, cost, plan limits, session history, and a launcher that opens real terminals.
