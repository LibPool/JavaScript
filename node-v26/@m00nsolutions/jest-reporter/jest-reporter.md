# @m00nsolutions/jest-reporter

> 标签: MCP, TMS, automation, integration-test, jest, m00n, m00nreport, reporter, streaming, test, test case management, test management, test-reporting, test-results, testing, unit-test

## 简介

Official Jest reporter for M00N Report, an AI-native test management platform. Results, retries and failures land in M00N Report while the suite is still running.
