# @thulpar/sdk

> 标签: JavaScript

## 简介

Thulpar check API client for Node: checks, sentence-level stream guarding, provider formats (OpenAI, Anthropic, Gemini) read and written back, holds and approvals, trajectory normalisation, and adapters for the Vercel AI SDK, the OpenAI and Anthropic SDKs
