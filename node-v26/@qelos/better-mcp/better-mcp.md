# @qelos/better-mcp

> 标签: claude, cursor, mcp, middleware, model-context-protocol, proxy, stdio

## 简介

Stdio MCP proxy: fans out to multiple upstream MCP servers and wraps every call in a middleware pipeline (logging, redaction, oversize-response offloading, and user hooks).
