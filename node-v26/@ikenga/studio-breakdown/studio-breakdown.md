# @ikenga/studio-breakdown

> 标签: agent-skills, ai-filmmaking, claude, claude-code, ikenga, script-breakdown, skills, storyboard, studio, video

## 简介

Turn a script into a populated Studio storyboard in one pass — segment into shots (cells) and extract characters/locations/props as reusable seed-locked anchors. Agent-driven via the com.ikenga.studio MCP; generates nothing (no spend) — it proposes a boar
