# @betacade/sdk

> 标签: analytics, betacade, game, html5, itch.io, leaderboard, playtest, web-games

## 简介

The Betacade library for web games: the same window.wt on Betacade and anywhere else (itch.io, your own site), with play data, saves, leaderboards and sign-in.
