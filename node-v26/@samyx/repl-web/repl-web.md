# @samyx/repl-web

> 标签: cli, command-line, custom-elements, express, hono, interactive, nestjs, repl, rpc, typescript, vue, web, web-ui

## 简介

A web UI + REPL-RPC layer for @samyx/repl-builder: serve a Vue custom-elements UI and relay commands over HTTP, framework-agnostic (Express, Hono, NestJS, Bun, edge)
