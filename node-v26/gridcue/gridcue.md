# gridcue

> 标签: ai, command-bar, data-grid, datagrid, filter, jev, llm, natural-language, react, shadcn, table, tanstack-table

## 简介

Ask data grids in plain language: validated, previewable, undoable filter, sort, group, and column changes. Headless core, React, TanStack Table, Jev provider.
