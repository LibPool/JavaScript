# @aws-blocks/bb-lambda-compute

> 标签: api-gateway, aws-blocks, compute, lambda, serverless

## 简介

The Lambda-backed **compute** for AWS Blocks: a `NodejsFunction` fronted by its own API Gateway REST API, backing the handler code an app's Building Blocks run on.
