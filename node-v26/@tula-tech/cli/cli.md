# @tula-tech/cli

> 标签: auth, authentication, cli, self-hosted, tula, user-management

## 简介

The tula command line: `tula dev`, `tula doctor`, `tula policy test`, `tula mcp`, and `tula diff` / `tula apply`, which keep an environment's settings and OAuth providers in step with tula.config.ts.
