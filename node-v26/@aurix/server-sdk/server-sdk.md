# @aurix/server-sdk

> 标签: JavaScript

## 简介

Server-side (backend) SDK for the Aurix voice platform REST API: token issuance, channels, moderation, webhooks, SSE. Generated from api/openapi.json.

- 官网：https://github.com/aurix-voice/aurix/tree/main/sdk/server/node
- 源码仓库：git+https://github.com/aurix-voice/aurix.git
