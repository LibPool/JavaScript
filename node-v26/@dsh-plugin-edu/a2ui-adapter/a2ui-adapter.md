# @dsh-plugin-edu/a2ui-adapter

> 标签: a2ui, cordis, deepseek, dsh, plugin

## 简介

A2UI host-side plugin for dsh: registers the a2ui_render tool (model authors an A2UI document, tool persists it to tool/result.meta) and injects the A2UI teaching section
