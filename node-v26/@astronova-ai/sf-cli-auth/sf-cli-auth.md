# @astronova-ai/sf-cli-auth

> 标签: auth, cli, llm, salesforce, sfdx

## 简介

Node helper that reads {accessToken, instanceUrl} from an already-authenticated Salesforce CLI org for use with @astronova-ai/sf-llm-core.
