# @ms.dev/ui-library

> 标签: JavaScript

## 简介

A reusable UI component library built with **React**, **TypeScript**, **Vite**, **Tailwind CSS**, **Storybook**, and **Jest**. This library is designed for rapid UI development, theming, and easy integration into multiple projects.
