# wp-agent

> 标签: JavaScript

## 简介

A TypeScript CLI and library that gives coding agents structured control of WordPress and Playwright screenshots for visual verification. It uses the WordPress REST API for pages, media, plugins, and discovery. The optional WordPress bridge provides regis
