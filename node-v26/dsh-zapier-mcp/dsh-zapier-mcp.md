# dsh-zapier-mcp

> 标签: automation, deepseek-harness, dsh, dsh-bundle, dsh-plugin, mcp, model-context-protocol, zapier

## 简介

Connect your hosted Zapier MCP server (mcp.zapier.com) to DeepSeek Harness with a Settings page for the Zapier MCP token.
