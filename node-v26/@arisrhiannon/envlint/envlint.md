# @arisrhiannon/envlint

> 标签: ci, cli, configuration, dotenv, dotenv-linter, env, env-schema, environment-variables, github-actions, linter, secret-detection, secrets, validator

## 简介

Zero-dependency CLI + library that lints .env files against .env.example: missing/duplicate/empty keys, unsafe .gitignore, secrets leaked into examples, and schema-as-comments type validation. Runs on Node, built for CI.
