> 标签: ai-agent, damage-control, defender, pi, pi-extension, pi-package, protection, security

## 简介

Defense-in-depth protection for Pi coding agent. Blocks dangerous commands and protects sensitive files — fork of Serhioromano/pi-defender with defaultMode support.
