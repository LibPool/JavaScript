# omp-artifacts

> 标签: artifacts, kitty, oh-my-pi, omp, omp-extension, pi-package, preview, terminal

## 简介

Artifacts inside oh-my-pi (omp): the agent queues HTML, Markdown, code, images and PDFs; you read them in the terminal with kitty graphics.
