# @venizia/ignis-boot

> 标签: artifact-index, build-time, code-generation, decorators, dependency-injection, di, ignis, ioc, typescript, venizia

## 简介

Build-time artifact index generator for IGNIS applications: scans decorated classes with the TypeScript AST and emits one static registration file per package, so bun build --compile sees plain imports.
