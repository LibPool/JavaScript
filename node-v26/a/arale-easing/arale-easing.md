# arale-easing

> 标签: utility

## 简介

Easing 是动画的平滑函数扩展包。由于 jQuery 自带的比较少，通过这个包可以增加更多平滑函数。

## 官网

- 官网：http://aralejs.org/easing/
- 源码仓库：git+https://github.com/aralejs/easing.git
- npm 页面：https://www.npmjs.com/package/arale-easing

## 历史版本号

- 当前版本：1.1.0

- 1.1.0

## 获取地址

- npm 安装：`npm install arale-easing`
- npm registry：https://registry.npmjs.org/arale-easing
- Node 要求：>=4.0.0
