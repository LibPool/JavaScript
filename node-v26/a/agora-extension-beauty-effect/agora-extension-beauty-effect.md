# agora-extension-beauty-effect

> 标签: JavaScript

## 简介

`agora-extension-beauty-effect` adds real-time beauty effects to video tracks created with the Agora RTC Web SDK. It provides skin lightening, smoothing, sharpening, redness adjustment, and contrast control through the SDK media processor pipeline.
