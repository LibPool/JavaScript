# a11y-magnifier

> 标签: a11y, accessibility, assistive-technology, low-vision, magnifier, no-dependencies, screen-magnifier, typescript, wcag, zoom

## 简介

Zero-dependency, cursor-following screen magnifier widget for the web — built for low-vision accessibility on news sites and content-heavy pages.
