# australian-law-mcp

> 标签: australia, citations, federal-register-of-legislation, law, legal, legislation, mcp, model-context-protocol, point-in-time

## 简介

MCP server for the Federal Register of Legislation: search Australian Commonwealth law, read it as it stood on any date, and check citations against the official register
