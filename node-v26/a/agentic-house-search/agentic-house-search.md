# agentic-house-search

> 标签: mcp, modelcontextprotocol, neighbourhood, open-data, postcode, property, uk

## 简介

MCP server for UK neighbourhood research: a full postcode report (demographics, crime, deprivation, prices, fibre, 5G, transport, amenities, schools, planning constraints) plus a searchable registry of the 45 open datasets behind it.
