# ai-usage-inspector

> 标签: claude, claude-code, cline, codex, cost, cursor, dashboard, hook, kilo-code, observability, openai, opencode, roo-code, tokens, usage

## 简介

Zero-dependency tool that records every AI coding-agent prompt (tokens, model, mode, cost, context %) from Claude Code, OpenAI Codex, Cursor, OpenCode, and VS Code agents (Cline, Roo Code, Kilo Code), and shows it in a local dashboard.
