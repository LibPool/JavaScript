# asciikit-mcp

> 标签: asciikit, claude, design, mcp, patterns, ui, ux, wireframe

## 简介

AsciiKit MCP server - gives your coding agent senior-designer judgment. Describe what you're building; get wireframes, flows, and a Build Kit (journey + PRD + DESIGN.md) it builds from instead of generic slop.
