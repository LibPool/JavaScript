# angular-trello-api-client

> 标签: api, client, satellizer, trello

## 简介

An angular Trello client bypassing the Trello client.js (based on jQuery). This client uses [Satellizer](https://github.com/sahat/satellizer) for authentication. Meant to be used with [webpack](https://webpack.github.io/).
