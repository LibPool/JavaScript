# agent-input-sanitizer

> 标签: agent, ansi, confusables, edit-repair, exfiltration, homoglyph, invisible-characters, llm, prompt-injection, rag, redaction, sanitize, security, tool-output, unicode

## 简介

Defend an agent against hidden-content injection: strip payload-capable invisible Unicode and ANSI, splice out human-invisible HTML, and flag data-exfil URLs in untrusted text before any model sees it.
