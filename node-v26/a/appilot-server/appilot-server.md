# appilot-server

> 标签: agent, appilot, identity, relay, server, webmcp

## 简介

Appilot server SDK: the identity relay a host application runs in its own backend. Exchanges the host's session for a short-lived Appilot widget token without the widget secret ever reaching a browser. Node-only, zero runtime dependencies.
