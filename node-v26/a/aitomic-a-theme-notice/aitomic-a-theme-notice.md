# aitomic-a-theme-notice

> 标签: JavaScript

## 简介

Theme notices based on CSS only lightbox. Include the template stored in folder 'control' using macro `{include '../path-to-latte-template'}` and pass variables $title, $content, $id, $show (boolean values).
