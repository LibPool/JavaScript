# ai-garcon

> 标签: claude-code, codex, llm, observability, proxy, tokens, usage

## 简介

Observability for coding agents: a local pass-through proxy that records what Claude Code, Codex and other agents spend in tokens, with a dashboard and optional cross-device sync.
