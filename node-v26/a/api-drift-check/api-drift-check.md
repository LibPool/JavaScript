# api-drift-check

> 标签: api, ci, contract-testing, drift-detection, mcp, monitoring, openapi

## 简介

Self-hosted checker for API Drift Monitor -- runs in your own CI, diffs your live API against its spec, and posts only the pass/fail result (never credentials) to your dashboard.
