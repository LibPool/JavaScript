# autonomagic-marketplace

> 标签: agentic-payments, ai-agents, base, bazaar-discovery, ethereum, machine-payments, marketplace, plugin-loader, usdc, x402

## 简介

Open plugin marketplace primitive for x402 — drop a JS file, the agent hot-reloads it as a paid HTTP endpoint in 400ms. Bazaar-discovery compliant.
