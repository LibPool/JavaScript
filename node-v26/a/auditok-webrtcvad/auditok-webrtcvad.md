# auditok-webrtcvad

> 标签: auditok, libfvad, speech-detection, vad, voice-activity-detection, wasm, webrtc

## 简介

WebRTC voice activity detector (libfvad compiled to WebAssembly, ~30 KB) as a frame validator for auditok: speech-specific detection with proper event shaping. Zero dependencies, runs in Node and browsers.
