# aicp-mcp

> 标签: ai-content-pipeline, claude, fanorate, mcp, model-context-protocol, wordpress

## 简介

Local MCP server for the Fanorate AI Content Pipeline. Exposes the AICP REST API (format, validate, image upload, submit) as MCP tools + article-authoring prompts, so Claude Desktop can create Fanorate articles even where it can't make outbound API calls
