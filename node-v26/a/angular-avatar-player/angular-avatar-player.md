# angular-avatar-player

> 标签: angular, animation, assistant, avatar, avatar-generator, chat, component, lip-sync, lipsync, svg

## 简介

Animated SVG avatar component for Angular. Blinking, eye movement, head idle motion and lip sync, rendered as pure vector SVG with no images or runtime assets.
