# ampersand-router

> 标签: clientside, history, router

## 简介

Clientside router with fallbacks for browsers that don't support pushState. Mostly lifted from Backbone.js.

- 官网：https://github.com/ampersandjs/ampersand-router
- 源码仓库：git://github.com/ampersandjs/ampersand-router.git
