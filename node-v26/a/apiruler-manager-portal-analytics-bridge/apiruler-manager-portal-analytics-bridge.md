# apiruler-manager-portal-analytics-bridge

> 标签: JavaScript

## 简介

This package is a Vue plugin that supplies the necessary mechanisms for analytics components to reach Konnect dev portal query APIs to obtain data.  This is the only supported way for analytics dashboards (created using the `DashboardRenderer` component)
