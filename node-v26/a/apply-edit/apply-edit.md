# apply-edit

> 标签: agent, coding-agent, edit, llm, oldString, search-replace, str_replace, text-edit, tool, whitespace

## 简介

Apply LLM-generated oldString/newString edits safely: tolerant matching with ambiguity refusal, match reports, re-indentation and CRLF/BOM preservation.
