# adonis-debugbar

> 标签: adonis, adonis-debugbar, adonis-debugger, adonis-devtools, adonis-profilerr, adonis-query-debugger, adonis-query-logger, adonis-timeline, adonisjs, adonisjs-debugbar, debug-toolbar, debugbar, development, devtools, explain, inertia, profiler, queries, sql, timeline, vue

## 简介

Per-request debug bar for AdonisJS: timing, SQL queries, route info, session, views, messages, exceptions and timeline markers. Works with any frontend stack.
