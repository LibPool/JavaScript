# admiral-cli

> 标签: cli, commands, framework, parameters, parsing

## 简介

A Command Line Framework (CLI) framework for Node.js. Admiral has features like other CLI frameworks, but adds validation and some callbacks in key places. Less configuration, stronger validation.
