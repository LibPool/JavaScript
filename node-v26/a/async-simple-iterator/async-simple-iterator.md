# async-simple-iterator

> 标签: after, after-each, async, async-simple-iterator, base, basic, before, before-each, control, control-flow, each, emit, emits, emitter, flow, fn, function, hooks, iterator, lib, settle, settling, simple, system, util, utils

## 简介

Making simple iterator for [async][] lib that adds beforeEach, afterEach, error hooks and support for settling. It also emits `beforeEach`, `afterEach` and `error` events.
