# adventure_arc

> 标签: JavaScript

## 简介

AdventureArc is a CLI-based adventure game where you face zombies, skeletons, and aliens. Use text commands to drink potions, attack, or run for your life. Every choice impacts your survival in this thrilling command-line journey.
