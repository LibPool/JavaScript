# agent-authority

> 标签: a2a, agent, agent-authority, agentic, ai-agents, authority, authorization, biscuit, capability, capability-based-security, capability-tokens, delegation, ed25519, least-privilege, llm, macaroons, mandate, mcp, mcp-server, oauth, on-behalf-of, permissions, revocation, spiffe, tool-calling

## 简介

Authorization for AI agents: verifiable, scoped, revocable capability tokens (mandates) with attenuable delegation, for MCP and A2A. The reference implementation of agent authority — zero-dependency TypeScript & Python.
