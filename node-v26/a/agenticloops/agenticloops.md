# agenticloops

> 标签: agentic-loop, agentic-loops, ai-agent, automation, claude, cron, loop, scheduler, skills

## 简介

Install and run agentic loops — recurring AI agents defined in a single LOOP.md file. One file defines it; any harness can run it.
