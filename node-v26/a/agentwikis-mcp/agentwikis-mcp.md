# agentwikis-mcp

> 标签: agents, documentation, knowledge-base, llms-txt, mcp, model-context-protocol

## 简介

MCP server for Agent Wikis (agentwikis.com) — maintained, agent-readable knowledge bases with calibrated search and provenance. Read-only; free without a key, and an Agent Wikis Pro key adds the XL tier.
