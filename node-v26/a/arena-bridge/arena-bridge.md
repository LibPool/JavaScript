# arena-bridge

> 标签: agent, agent-mode, arena, automation, cdp, chrome, macos, mcp, mcp-server, peekaboo, remote-control, sandbox, self-hosted

## 简介

Give a cloud AI agent (Arena.ai Agent Mode, Claude, Cursor, ...) controlled access to your own machine over HTTP/MCP: files, shell, Chrome and the macOS desktop, with an approval gate, trust windows and an audit log.
