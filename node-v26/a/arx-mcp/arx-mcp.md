# arx-mcp

> 标签: JavaScript

## 简介

Launcher for the Ageless MCP servers (marketer, backend-read, funnel-author). Downloads the platform binary from the private GitHub release — requires GH_TOKEN (see INSTALL.md; custody: AWS Secrets Manager).
