# astro-shotpipe

> 标签: astro, astro-component, og-image, open-graph, shotpipe, social-cards, social-image, withastro

## 简介

Dynamic Open Graph images for Astro via Shotpipe — zero build-time cost, zero-signup setup. URLs are signed locally at build time and rendered lazily on first crawler hit.
