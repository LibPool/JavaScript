# anki-apkg-parser

> 标签: anki, apkg

## 简介

Nodejs helper for parsing Anki `.apkg` files. You can unpack the deck and get list of notes, cards, media files, models. This library uses `sqlite` as a dependency, so you can make any SQL queries yourself
