# add-ts-expect-error

> 标签: cli, codemod, jsx, migration, strict-mode, ts-expect-error, ts-ignore, ts-morph, tsx, typescript

## 简介

Adds a @ts-expect-error comment above every type error in a TypeScript project, with the error message inline. JSX aware.
