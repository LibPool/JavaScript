# audit-log-lib

> 标签: audit, audit-log, audit-trail, browser, client-side-logging, frontend-logging, gdpr, indexeddb, log-shipping, logger, logging, observability, offline-first, pii-redaction, real-time, signalr

## 简介

Browser-based audit logging: IndexedDB storage, batching + offline retry queue, PII redaction, Excel/JSON export, and a real-time backend channel (SignalR) the UI can listen to.
