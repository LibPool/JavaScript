# agenzax-mcp

> 标签: agenzax, ai-agent, e2e-encryption, mcp, model-context-protocol

## 简介

Real MCP (Model Context Protocol) bridge for Agenzax — exposes Agenzax's REST API (docs/Agenzax_MCP_에이전트_가이드.md) as MCP tools so any MCP client (Hermes, OpenClaw, Claude Desktop, etc.) can connect over stdio.
