# agent-memory-bridge

> 标签: agent-memory-bridge, ai-agent, claude-mem, coding-agent, context-injection, cross-engine, cross-session, memory, memory-bridge, memory-recall, persistent-memory, pi-coding-agent, pi-extension, pi-mono, pi-package, pi-skill

## 简介

Cross-session memory for pi-coding-agent (pi-mono). A thin client for the local claude-mem worker: records tool activity, injects relevant past context, and registers a memory_recall search tool. Share memory across pi, Claude Code, Cursor, Codex and Open
