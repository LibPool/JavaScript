# async-itertools

> 标签: async, channel, generator, iterable, iterator, itertools, tee, transducer, zip

## 简介

Asynchronous iterator building blocks — transducers, channels, tee, zip, exhaust, and friends — forming an iterator algebra for JavaScript, inspired by Python's itertools.
