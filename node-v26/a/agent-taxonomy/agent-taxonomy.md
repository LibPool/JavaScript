# agent-taxonomy

> 标签: ai-agents, binomial, classification, evolution, genome, lamarckian, llm, multi-agent, naming, openclaw, species, taxonomy

## 简介

Evolutionary taxonomy framework for AI agents. Classify any agent into a biological species with binomial nomenclature, rarity tiers, evolution stages, and portrait prompts. Like Pokédex for AI agents.
