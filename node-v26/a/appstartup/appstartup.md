# appstartup

> 标签: JavaScript

## 简介

此node模块是用来，创建一个Cordova模板工程中。主要功能有：检查当前系统的环境是否满足要求、创建Cordova工程、添加Android和iOS工程、添加基础插件、自动生成一个默认的Android的keystore签名.SDK需要下载Android Support Repository
