# apple-music-amp-lib

> 标签: JavaScript

## 简介

A small api wrapper for Apple Music's internal AMP API. Unlike the public Apple Music API, much of the AMP-API can be used without serious authentication (bearer tokens are handled by amp-lib automatically, making it practically keyless).
