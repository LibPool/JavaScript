# aura-cardea

> 标签: chat-ui, deepseek-harness, dsh, dsh-bundle, dsh-plugin, fold, tool-calls

## 简介

AuraCardea — folds one Turn's intermediate chat rows (tool calls, reasoning, context injections, retries) into one line per kind, with live status, success/failure counts, per-kind duration and inline details.
