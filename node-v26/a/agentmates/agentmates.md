# agentmates

> 标签: agent, agent-to-agent, agentmates, claude-code, collaboration, debugging, mcp

## 简介

Agent-to-agent questions between Claude Code terminals. Your agent asks a teammate's agent about their repo, their logs, their environment — instead of asking them to paste output.
