# agentsocks

> 标签: agent-messaging, ai-agents, claude-code, cli, codex, cross-session, inter-agent, mcp

## 简介

Let Claude Code and Codex sessions on one machine message each other, through Claude Code's own cross-session inbox (cc-socks) and Codex's hooks, MCP and queue.
