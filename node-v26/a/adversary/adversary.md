# adversary

> 标签: adversarial, boundary-value-analysis, edge-cases, equivalence-partitioning, fixtures, i18n, injection, json-schema, openapi, qa, test-data, testing, unicode, zod

## 简介

Generate explained adversarial test inputs - boundary values, i18n/Unicode edge cases, and injection strings - from a schema. Every case says which technique produced it and why it might break your code.
