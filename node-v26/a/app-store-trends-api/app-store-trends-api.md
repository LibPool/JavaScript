# app-store-trends-api

> 标签: analytics, android, app-analytics, app-downloads, app-store, app-store-api, growth-rate, ios, mobile, trendsmcp

## 简介

Android app download trends via REST API (AppBrain). Pass the Android bundle ID. Weekly series, period-over-period growth, plus live App Store / Google Play charts via getTopTrends. Powered by trendsmcp.ai
