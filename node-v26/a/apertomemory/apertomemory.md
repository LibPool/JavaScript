# apertomemory

> 标签: ai, amem, apertomemory, cbor, cose, encryption, memory, portability

## 简介

TypeScript implementation of the ApertoMemory format (format_version 2): portable, client-side-encrypted, user-owned AI memory with signed, author-bound provenance (draft-ferro-apertomemory)
