# aurelia-rxjs

> 标签: async, aurelia, aurelia-binding, aurelia-binding-behavior, aurelia-binding-function, binding, rxjs, rxjs5

## 简介

An Aurelia plugin that makes it possible bind to Rx Observables and Rx Subjects or use them as Binding Signals.
