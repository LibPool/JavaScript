# asma-mfw-esmloader

> 标签: JavaScript

## 简介

Native-ESM widget loader — the transport-agnostic successor to asma-qiankun-react-loader. Loads widgets by import()ing an ES module that exports mount(); createDualLoader dispatches per-app between this and the legacy qiankun loader with no global flag.
