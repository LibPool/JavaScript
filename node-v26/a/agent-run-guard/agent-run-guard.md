# agent-run-guard

> 标签: agent, claude-code, codex, crush, gemini-cli, guardrails, opencode, rate-limit, runtime-guard

## 简介

Cross-harness runtime guard that blocks runaway agent behaviour (repeats, budgets, error storms, dangerous commands). Dependency-free, stdlib-only.
