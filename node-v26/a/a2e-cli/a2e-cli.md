# a2e-cli

> 标签: a2e, agent, agent-auditing, auditing, cli, llm, terminal

## 简介

Conversational terminal client for A2E, the Agent Auditing Engine: a chat-driven assistant that reads datasets, experiments and scores from a running A2E server, launches audit runs and compares results.
