# appsgolem-mcp

> 标签: ai, appsgolem, cutter, mcp, model-context-protocol, video, youtube

## 简介

MCP server for the AppsGolem YouTube cutter API — cut clips programmatically, or let an AI agent do it. TypeScript/Node port of the Python appsgolem-mcp.
