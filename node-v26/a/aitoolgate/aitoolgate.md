# aitoolgate

> 标签: agent, agents, anthropic, gateway, llm, local, middleware, monitoring, observability, openai, policy, proxy, self-hosted, telemetry, token-usage, tool-calling, tool-calls

## 简介

Local, zero-runtime-dependency LLM model proxy (OpenAI/Anthropic compatible) for AI agents: inspects and rewrites tool calls, tracks per-tool token usage and latency, applies policy rules live without restart, and ships a real-time local dashboard.
