# ai-chat-widget-vanilla

> 标签: ai-chat, chat, chatbot, es5, firefox53, openai, react, umd, vue, vue2, vue3, widget

## 简介

框架无关的智能问答悬浮组件（原生 JS，零依赖）。悬浮图标统一入口，对话框支持拖拽/缩放/全屏，OpenAI 兼容多模型流式问答，深蓝/标准/深绿三套主题，兼容 Firefox 53。
