# animateJs

> 标签: animatejs, animation, css3, html5, javascript

## 简介

css3移动端动画，动画方式很简单只需要添加指定方式的class即可实现很酷炫的动画，组件引入了<a href="http://www.dowebok.com/demo/2014/98/" target="_blank">animate.css</a>，目前只有里面的动画方式。组件可以用于酷炫的活动页面，页面交互动作等。
