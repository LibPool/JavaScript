# airportmodule

> 标签: JavaScript

## 简介

How to use: \ Step 1 : Install airport module package running the command "npm install airport module --save"\ Step 2 : require the module at the start of your file\ Step 3 : Use the function findAirportDetails to get details of the airport whose code
