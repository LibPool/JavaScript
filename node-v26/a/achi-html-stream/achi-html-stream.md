# achi-html-stream

> 标签: async rendering, html, html escaping, html rendering, html templating, performance, server-side rendering, service worker rendering, ssr, streaming html, tagged template, template literals, xss protection

## 简介

An HTML streaming library for multi-page progressive web apps that renders HTML in service workers and also works with Node.js and other JavaScript runtimes
