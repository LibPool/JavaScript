# ag-grid-playwright

> 标签: ag-grid, frontend testing, playwright, test util, testing

## 简介

Test ag-grid using Playwright in a simple, consistent, and extensive way. You can test simple rows and columns or extend it to test ag-grid from playwright in it's entirety including ag-grid enterprise.
