# agent-control-plane-core

> 标签: adapter, agent, claude, claude-code, codex, control-plane, guardrail, hooks

## 简介

Vendor-neutral control-plane contract for coding agents: a normalized ToolCallEvent/Verdict schema with per-agent adapters (Claude Code, Codex, Amp, Gemini CLI) and a conformance suite.
