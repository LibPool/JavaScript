# agent-remote

> 标签: agent, claude-code, hyperdht, p2p, remote-shell, sdk, ssh-alternative

## 简介

Peer-to-peer remote shell over HyperDHT. No ports, no firewall, no servers. SDK and CLI — run via npx or bunx anywhere.
