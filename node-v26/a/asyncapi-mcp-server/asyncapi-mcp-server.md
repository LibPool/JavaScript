# asyncapi-mcp-server

> 标签: ai, asyncapi, asyncapi-mcp, code-generation, mcp, model-context-protocol

## 简介

AsyncAPI MCP server — Model Context Protocol server for working with AsyncAPI: parse and validate documents, list templates, and generate code and docs (via @asyncapi/parser and @asyncapi/generator) for any MCP-compatible client
