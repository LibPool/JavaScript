# anicca-doc-view

> 标签: document, document-viewer, docx, docx-viewer, image, image-viewer, office, office-viewer, pdf, pdf-viewer, powerpoint, pptx, pptx-viewer, viewer, wasm, webassembly, word, xlsx

## 简介

Universal document viewer for the web by Anicca Code Studio. Framework-agnostic viewer powered by a WebAssembly engine for high-fidelity rendering across PDF, DOCX, PPTX, XLSX, and images.
