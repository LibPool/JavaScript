# astro-html-editor

> 标签: astro, code-editor, developer-tools, html-editor, html-preview, live-preview, local-first, nodejs, self-hosted, ssr, vanilla-js, web-editor

## 简介

Self-hosted HTML editor with live preview. Paste HTML, see results instantly. Files persist to server filesystem via Astro SSR — no localStorage, no framework islands.
