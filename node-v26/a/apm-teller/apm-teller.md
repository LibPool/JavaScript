# apm-teller

> 标签: agent-package-manager, apm, claude-code, codex, marketplace

## 简介

Local GUI and convention miner for Microsoft APM marketplace repos (vaults). Mines implicit team conventions from PR reviews with Claude Code / Codex and promotes them into APM packages.
