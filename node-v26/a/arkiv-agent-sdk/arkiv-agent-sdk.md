# arkiv-agent-sdk

> 标签: agent, arkiv, erc-8004, memory, sdk, state, web3

## 简介

Portable agent memory + state on Arkiv. Read and write ERC-8004 agent sessions, messages, snapshots and memory entities from any TypeScript app.
