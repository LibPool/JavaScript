# axagroup

> 标签: agent, axagroup, carplay-moto, cli, colombia, exploradoras-led, maxima, mcp, shopify

## 简介

Official CLI for the AXA Group Store (MAXIMA): CarPlay screens for motorcycles, auxiliary LED driving lights and truck lighting. Search the catalogue, check prices in COP and stock, build a cart, and call the store's MCP server — no API key required.
