# agentlet-core

> 标签: agents, ai, bookmarklet, browser-automation, browser-extension, excel-export, form-filling, plugin-system, web-automation

## 简介

Side panel framework for web apps you cannot change: read and fill forms, export tables to Excel, capture the page and call an AI model, from a bookmarklet or extension
