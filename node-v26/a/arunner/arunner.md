# arunner

> 标签: agent, ai, batch, claude, harness, orchestration, runner

## 简介

agent runner - batch-orchestrate AI coding agents from one session: one idempotent tick, no server, no daemon, no admin rights. (0.0.1 reserves the name; the harness ships shortly.)
