# anilink-api-wrapper

> 标签: anilist, anilist-api, anilist-graphql, anilist-mutation, anilist-query, api, myanimelist, wrapper

## 简介

A typed TypeScript wrapper that unifies the AniList GraphQL and MyAnimeList REST APIs behind one calling convention: one params object and one options object per operation, with normalized errors, retries, pacing, and caching shared across providers.
