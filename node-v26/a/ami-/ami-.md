# ami-

> 标签: action, asterisk, event, interface, manager, nami, node, response

## 简介

An asterisk manager interface client, uses EventEmitter to communicate events, will allow you to send actions, and receive responses (and associated events), and also receive async events from serveri based on https://github.com/marcelog/Nami
