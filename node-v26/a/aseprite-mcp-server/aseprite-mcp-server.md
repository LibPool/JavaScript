# aseprite-mcp-server

> 标签: animation, aseprite, claude, codex, cursor, mcp, model-context-protocol, pixel-art, sprite

## 简介

Model Context Protocol server for Aseprite: let Claude, Codex, Cursor and other MCP clients create and animate pixel art. Runs with npx, no Python required.
