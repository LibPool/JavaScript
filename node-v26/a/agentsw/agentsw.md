# agentsw

> 标签: cc-switch, claude-code, cli, codex, coding-agent, deepseek-harness, model-provider, models.dev, opencode, provider-switcher

## 简介

CLI provider switcher for coding agents: manage OpenAI/Anthropic-protocol providers in one place and sync them, with models.dev metadata, into Claude Code, Codex, omp, pi, prime-agent, opencode, Hermes, WorkBuddy and DeepSeek Harness
