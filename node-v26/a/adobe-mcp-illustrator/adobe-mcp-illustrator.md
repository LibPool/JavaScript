# adobe-mcp-illustrator

> 标签: adobe, design-automation, extendscript, illustrator, macos, mcp, model-context-protocol, vector, windows

## 简介

MCP server for Adobe Illustrator: documents, artboards, layers, shapes, paths, typography, colour, effects, symbols, Image Trace, data sets, actions, export and printing through ExtendScript
