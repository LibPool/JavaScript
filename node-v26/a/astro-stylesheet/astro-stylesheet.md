# astro-stylesheet

> 标签: astro, astro component, astro stylesheet, css sanitizer, open props

## 简介

Astro StyleSheet <link> Component, This single Component provides the interface to apply a single stylesheet or many stylesheets in one place, have it also apply relevant sanitize.css scripts through use of a single Prop
