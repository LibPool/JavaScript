# agent-queue

> 标签: agent, agents, ai, backlog, claude, codex, llm, orchestration, queue, task-queue, workflow

## 简介

A tiny file-based work queue for AI agents. A planner writes decision-ready tasks, a worker claims one at a time and completes with verification, and every move is logged.
