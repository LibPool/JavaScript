# automation-mcp

> 标签: automation, cucumber, mcp, playwright, testing

## 简介

A Model Context Protocol (MCP) server that enables running Cucumber tests with Playwright automation. This server provides tools to execute Cucumber feature files with corresponding step definitions and retrieve the results, including screenshots.
