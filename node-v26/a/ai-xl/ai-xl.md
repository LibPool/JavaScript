# ai-xl

> 标签: JavaScript

## 简介

AI-XL adalah package Node.js yang memungkinkan kamu mengakses berbagai model AI seperti **Gemini, GPT-4o, Groq, Simsimi, dan DocsAI** melalui API publik.
