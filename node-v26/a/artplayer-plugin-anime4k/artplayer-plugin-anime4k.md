# artplayer-plugin-anime4k

> 标签: anime, anime4k, artplayer, artplayer-plugin, super-resolution, upscaling, video, webgpu

## 简介

Real-time Anime4K upscaling for ArtPlayer, on WebGPU. Auto-benchmarks the device, steps down when the GPU cannot keep up.
