# angular-starter

> 标签: angular, angular2, angular4, typescript, webpack

## 简介

An Angular Webpack Starter kit featuring Angular (Router, Http, Forms, Services, Tests, E2E, Coverage), Karma, Protractor, Jasmine, Istanbul, TypeScript, and Webpack by AngularClass
