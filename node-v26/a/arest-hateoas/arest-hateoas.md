# arest-hateoas

> 标签: cloudflare-workers, code-generation, hateoas, mcp, rest, state-machine, wasm, workflow

## 简介

AREST engine: FORML2 readings compile to a database, constraint rules, state machines, and a REST API. One function, one β-reducer over Backus's FFP algebra, WASM-compiled.
