# ajax-mock-middleware

> 标签: express, middleware, mock, webpack-dev-server

## 简介

A middleware that implements mock data based on express and webpack-dev-server, enabling front-end staff to mock near-real interface data without the server's outgoing interface, and to refresh the browser in real time when the mock file changes
