# anonymize-ip

> 标签: anonymize, anonymous, hide, ip, ips, mask, masks, numbers, util, utils

## 简介

Hide last ip numbers for given ip, like `129.89.5.243` -> `129.89.x.xxx` or `79.100.175.45` to `79.100.xxx.xx`. Or replace them with custom mask.
