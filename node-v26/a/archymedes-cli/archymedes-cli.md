# archymedes-cli

> 标签: agent, ai, anthropic, archymedes, cli, coding-agent, openai, terminal

## 简介

Archymedes CLI — a coding agent that shows its work. Runs against your working tree or an isolated remote sandbox, with guarded approvals, git checkpoints, and exact, measured cost accounting.
