# aws-entra-login

> 标签: aws, aws-azure-login, aws-console, azure-ad, cli, credential-process, developer-tools, device-code-flow, iam-roles, microsoft-entra-id, saml, sso, sts

## 简介

Modern, zero-fragility Microsoft Entra ID (Azure AD) and AWS SSO (IAM Identity Center) authentication CLI tool supporting Authenticator number matching, Device Code flow, AWS Console federation, multi-account batch login, and AWS credential_process.
