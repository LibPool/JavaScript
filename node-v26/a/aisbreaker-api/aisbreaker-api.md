# aisbreaker-api

> 标签: JavaScript

## 简介

This package contains AIsBreaker which provides an easy-to-use and service-agnostic API to access different AI services (like OpenAI/ChatGPT API, Open-Assistant API, Google Bart API and many more) in a uniform way. More details: https://aisbreaker.org/
