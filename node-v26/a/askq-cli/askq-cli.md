# askq-cli

> 标签: askuserquestion, claude, cli, gui, mcp, prompt, tauri

## 简介

Native GUI for AskUserQuestion-style multiple-choice prompts (CLI + MCP server) for AI coding agents. Pops a window, prints the chosen answers as JSON.
