# anon-pi

> 标签: agent, anonymity, cli, netcage, pi, privacy, proxy, socks5h, tor

## 简介

Launch pi inside a netcage: anonymized web egress through a socks5h proxy, one direct hole for a local model, seeded pi config on the host.
