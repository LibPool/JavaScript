# as-blake

> 标签: assemblyscript, blake, blake3, cryptography, hash, simd, swar, wasm, webassembly

## 简介

Portable, SIMD-accelerated BLAKE3 for AssemblyScript - SWAR and degree-4 SIMD, dispatched at compile time.
