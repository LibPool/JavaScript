# agent-docx

> 标签: ai-agents, docx, legal-drafting, legal-tech, libreoffice, markdown, microsoft-word, pagination, redline, tracked-changes, typescript, wordprocessingml

## 简介

Agent-first legal Markdown-to-DOCX compiler with deterministic page and line constraints, native redlines, embedded revisions, and optional Word validation.
