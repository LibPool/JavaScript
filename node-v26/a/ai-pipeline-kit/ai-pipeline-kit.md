# ai-pipeline-kit

> 标签: accessibility, agentic, ai, claude, cli, code-review, frontend, orchestrator, pipeline, scaffold

## 简介

Scaffolds a model-agnostic, multi-station AI delivery pipeline (intake -> architect -> SDET -> developer -> QA -> classifier -> specialists -> reviewer -> release) into any frontend project.
