# aifra

> 标签: ai-deployment, aifra, coding-agents, html-presentation, mcp, static-preview, static-site

## 简介

Temporary 48-hour static previews for coding agents. Local CLI/MCP uploads prebuilt files; no builds or backend execution.

- 官网：https://aifra.ru/en/docs/publish/
- 源码仓库：git+https://github.com/nickbasharin/aifra-integrations.git
