# autopilot-mcp

> 标签: autopilot, browser-automation, claude-code, mcp

## 简介

MCP server wrapper for Autopilot — exposes ax_navigate, ax_screenshot, ax_accessibility, ax_execute, ax_wait, ax_text to Claude Code
