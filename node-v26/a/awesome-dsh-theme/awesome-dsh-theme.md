# awesome-dsh-theme

> 标签: deepseek, dsh, harness, theme, wallpaper, wallpaper-engine

## 简介

A theme studio for DeepSeek Harness: original-path media, categorized Wallpaper Engine videos, native HD Scene snapshots and live Web wallpapers.
