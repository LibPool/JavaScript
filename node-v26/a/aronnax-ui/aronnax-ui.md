# aronnax-ui

> 标签: accessibility, component-library, css, dark-mode, design-system, design-tokens, rails, tailwind, tailwindcss, ui-components

## 简介

A Tailwind CSS v4 design system: semantic light/dark tokens, component classes, and vanilla-JS behaviors driven by data attributes. Framework-agnostic (Rails, plain HTML, or any JS toolchain).
