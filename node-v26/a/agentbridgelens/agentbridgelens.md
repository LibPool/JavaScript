# agentbridgelens

> 标签: ai-agent, browser, cdp, chrome-extension, claude, debugging, mcp, model-context-protocol, source-map

## 简介

MCP server bridging AI coding agents to a real Chrome browser via the AgentBridgeLens extension — DOM inspection, screenshots, network/console capture, source-map tracing, visual overlays, multi-tab targeting.
