# api-docs-mcp-server

> 标签: api-docs, claude, cursor, llm, mcp, model-context-protocol, openapi, swagger

## 简介

MCP server exposing OpenAPI/Swagger API documentation as MCP tools (overview / search / detail / dump / refresh). Framework-agnostic, works with Express or plain Node http.
