# audionaut-mcp

> 标签: agent, audio, audio-editor, claude, daw, mcp, mcp-server, modelcontextprotocol, multitrack

## 简介

MCP server for the Audionaut multitrack audio editor - lets Claude and other agents edit .audium projects. Requires the Audionaut app (Mac App Store / GitHub Releases)
