# ableton-als

> 标签: ableton, ableton-live, als, audio, backwards-compatibility, browser, daw, downgrade, gzip, live-10, live-12, live-set, music-production, parser, xml, zero-dependency

## 简介

Read, edit, validate and version-convert Ableton Live Set (.als) files. Zero dependencies — runs in Node, Deno, Bun, Workers and the browser.
