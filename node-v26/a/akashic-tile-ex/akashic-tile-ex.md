# akashic-tile-ex

> 标签: JavaScript

## 简介

**akashic-tile-ex**は [akashic-tile](https://github.com/akashic-games/akashic-tile)と比べて、描画をChipSetに委ねる事で、[WOLF RPGエディター](https://www.silversecond.com/WolfRPGEditor/)のオートタイル等にも対応した多機能なタイル描画ライブラリです。
