# archangel.js

> 标签: archangel, bot, commands, discord, discord.js, discordjs, hybrid, hybrid-commands, prefixed, slash

## 简介

A powerfull package to make hybrid commands for Discord.js. You can create prefixed commands and slash commands in the same file.
