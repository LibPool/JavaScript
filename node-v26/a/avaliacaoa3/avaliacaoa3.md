# avaliacaoa3

> 标签: JavaScript

## 简介

Este projeto é uma aplicação Node.js desenvolvida como parte de uma avaliação acadêmica. O sistema consiste em uma API que controla o registro dos alunos, responsáveis, instrutores, turmas e matrículas para as aulas do Projeto IESSA, no Complexo Tenístico
