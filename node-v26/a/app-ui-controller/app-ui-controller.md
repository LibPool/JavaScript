# app-ui-controller

> 标签: admin, feature-flags, manifest, mobile, phone-preview, react, toggle, ui-controller

## 简介

Interactive mobile phone preview with manifest controls for admin panels. Compose mobile UI screens in JSX with show/hide radio buttons mapped to nested manifest paths.
