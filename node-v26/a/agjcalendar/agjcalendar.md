# agjcalendar

> 标签: agjcalendar, agjjquery, calendar, date, dates, ecosystem:jquery, javascript, jquery, jquery-plugin

## 简介

agjCalendar is a plugin for the jQuery Javascript library to deal with calendars, dates and date ranges
