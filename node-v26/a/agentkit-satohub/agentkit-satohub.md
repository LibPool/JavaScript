# agentkit-satohub

> 标签: action-provider, agentkit, agents, ai, coinbase-agentkit, onchain-agents, preflight, satohub, web3

## 简介

Coinbase AgentKit action provider for Sato Hub: run a Preflight check on a repo, package, MCP endpoint, ERC-8004 agent or token before your agent installs, connects to, pays or trades it, and search the scored onchain-agent index. Keyless, read-only, neve
