# as-table

> 标签: ASCII, array as table, array format, array table, as table, columns, console, grid, layout, log, object as table, object table, print, print object, print table, sheet, stringify, table, tablefy, terminal, text, text table, tty

## 简介

A simple function that print objects / arrays as ASCII tables. Handles ANSI styling and weird 💩 Unicode emoji symbols – they won't break the layout.
