# ai-link-sdk

> 标签: AiLinkSdk, ai-link-sdk, ailink, ble, body-fat, expo, expo-module, react-native, scale

## 简介

AILink BLE height and body fat scale SDK for React Native / Expo. Provides the HeightBodyFatScale class, React hooks, a Zustand-backed connection store, and an Expo config plugin for Android BLE permissions.
