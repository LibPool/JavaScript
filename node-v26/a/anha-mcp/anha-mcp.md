# anha-mcp

> 标签: agent, ai-agent, anha, mcp, model-context-protocol, oauth, stdio

## 简介

Connect any MCP client to ANHA over stdio. Handles OAuth (self-registration, PKCE, token refresh) so no key is ever pasted.

- 源码仓库：git+https://github.com/breakdisk/anha-vault.git
