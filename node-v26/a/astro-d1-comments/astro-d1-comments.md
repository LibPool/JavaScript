# astro-d1-comments

> 标签: astro-component, astro-integration, cloudflare, cloudflare-workers, comments, d1, turnstile, withastro

## 简介

Self-hosted comments for Astro sites on Cloudflare Workers: D1 storage, Turnstile spam protection, pending-by-default moderation with a built-in admin page and CLI.
