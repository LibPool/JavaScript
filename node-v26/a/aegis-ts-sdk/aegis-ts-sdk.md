# aegis-ts-sdk

> 标签: aegis-http, aegis-ts-sdk, gnupg, gpg, openpgp, sdk

## 简介

Aegis Http is an autonomous, End-to-End Encrypted (E2E) HTTP gateway architecture built on top of standard GPG (GNU Privacy Guard).
