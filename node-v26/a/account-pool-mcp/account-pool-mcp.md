# account-pool-mcp

> 标签: agent, claude, claude-code, concurrency, lease, mcp, model-context-protocol, parallel, playwright, playwright-mcp, qa, resource-pool, test-accounts

## 简介

MCP server that brokers exclusive, crash-safe leases on a pool of credentials across unrelated agent sessions. Stops concurrent Claude/agent QA runs from grabbing the same test account.
