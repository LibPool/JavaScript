# agnostic-query

> 标签: database-agnostic, drizzle, kysely, postgresql, query, query-builder, runtime-agnostic, schema, sql, tanstack-intent, type-safe, typescript

## 简介

Type-safe fluent builder for portable query schemas. Runtime-agnostic, database-agnostic — the same QuerySchema drives Drizzle, Kysely, db0, or raw SQL.
