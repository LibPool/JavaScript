# agentix-cli

> 标签: a2a, agent, ai, bring-your-own-key, claude, claude-code, cron, mcp, mesh, multi-agent, opencode, orchestrator, self-hosted, swarm, telegram, whatsapp

## 简介

AI operations layer for small and medium businesses. Routes Telegram, WhatsApp, GitLab, GitHub, crons, webhooks, and mesh tasks to AI agents. Web wizard for operators, CLI for engineers. Self-hosted.
