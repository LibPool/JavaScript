# anjal

> 标签: agents, ai, anjal, api, email, imap, inbox, intent-signals, linkedin, myagentmail, outreach, sdk, smtp

## 简介

TypeScript SDK for the Anjal API (formerly MyAgentMail): email + LinkedIn intent infrastructure for AI agents. Send/receive email, manage drafts, run LinkedIn intent signals + historical searches with plain-English firing rules.
