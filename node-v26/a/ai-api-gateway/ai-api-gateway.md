# ai-api-gateway

> 标签: JavaScript

## 简介

AI 大模型 API 聚合网关：把多个上游 AI API（OpenAI/Claude/Gemini/兼容接口）聚合为一个 OpenAI 兼容出口，支持模型可用性探测、虚拟分组、用量统计与价格同步。
