# agent-core-mcp

> 标签: ai-agents, csv, deterministic, diff, hash, json, mcp, mcp-server, model-context-protocol, no-dependencies, regex

## 简介

Deterministic computation tools for AI agents: exact diffing, hashing, JSON querying, calendar arithmetic, regex extraction with ReDoS analysis, CSV parsing, similarity scoring, unit and base conversion. Zero dependencies, zero network, read-only.
