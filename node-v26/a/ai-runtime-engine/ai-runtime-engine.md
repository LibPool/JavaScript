# ai-runtime-engine

> 标签: agent, ai, ai-runtime, anthropic, cli, gemini, groq, llm, mcp, ollama, openai, openrouter, orchestration, provider-agnostic, router, runtime, typescript

## 简介

AI Runtime — a provider-agnostic AI runtime and orchestration platform. Point it at whatever AI providers you have; it routes each task to the best available model. Ships the `ai-runtime` CLI and the `Runtime`/`AI` library API.
