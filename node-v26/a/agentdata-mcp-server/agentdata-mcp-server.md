# agentdata-mcp-server

> 标签: agentdata, ai-agent, b2b, claude, company-data, cursor, email-finder, free, mcp, model-context-protocol, sales-intelligence, tech-stack

## 简介

AgentData MCP server: free company data for AI agents. 128M companies with tech stacks, web signals, email addresses with verification status, people and switch signals, from Claude, ChatGPT, Cursor or any MCP client.
