# a4phone

> 标签: JavaScript

## 简介

Claude Code / Codex / ZCode / DSH 远程手机交互：任务完成通知（含 AI 最后输出）、提问/权限请求手机点选或文字作答、远程续聊（ntfy.sh，含 DSH 会话续聊）
