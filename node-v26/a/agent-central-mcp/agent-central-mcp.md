> 标签: agent-central, amazon-ads-mcp, amazon-seller-central-mcp, model-context-protocol

## 简介

Name reservation for Agent Central. Agent Central is a hosted MCP server, so there is nothing to install: connect your MCP client to https://mcp.agentcentral.to/mcp.
