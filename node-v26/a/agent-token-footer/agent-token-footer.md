# agent-token-footer

> 标签: cache-hit, claude-code, cli, codex, cost, hook, prompt-cache, token-cost, tokens, usage

## 简介

Per-turn token and cost footer for Claude Code and Codex. Claude defaults to a native Stop hook (zero extra model calls); Codex defaults to an inline instruction block, because its hook message never lands inside the turn. Covers both CLI and Desktop on e
