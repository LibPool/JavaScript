# autocad-site-mcp

> 标签: autocad, cad, claude, dwg, dxf, mcp, model-context-protocol

## 简介

MCP connector for autocad.site: lets Claude, Cursor and other AI clients draw CAD (DXF/SVG/STL, 2D and 3D) through the hosted autocad.site engine
