# auditai-mcp

> 标签: authorization, claude-code, cursor, idor, mcp, model-context-protocol, nextjs, rls, security, supabase

## 简介

MCP server for Claude Code and Cursor: checks what your live Supabase database lets a stranger do, scans a Next.js + Supabase app for cross-tenant reads, RLS gaps and service-role misuse, and lets your own coding agent confirm and fix what it finds. No AP
