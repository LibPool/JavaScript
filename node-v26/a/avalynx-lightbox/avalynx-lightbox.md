# avalynx-lightbox

> 标签: avalynx, bootstrap, bootstrap5, component, lightbox

## 简介

AvalynxLightbox is a simple, lightweight, and easy-to-use lightbox library. Based on Bootstrap >=5.3 without any framework dependencies.
