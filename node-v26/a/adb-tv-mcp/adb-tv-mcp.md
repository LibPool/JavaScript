# adb-tv-mcp

> 标签: adb, ai-agent, android-tv, automation, claude, google-tv, mcp, model-context-protocol, smart-tv, tcl

## 简介

MCP server that controls Android TVs and Android devices through ADB: screen capture, remote input, applications, files, and Android 11 wireless pairing.
