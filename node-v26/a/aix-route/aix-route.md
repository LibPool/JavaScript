# aix-route

> 标签: agent, chain-of-thought, delegation, deterministic-horizon, llm, reasoning, routing, tool-use

## 简介

Deterministic Horizon routing — decide when an agent should keep reasoning with the LLM vs. delegate to a tool. Pure-TypeScript port of the aix-route Python policy.
