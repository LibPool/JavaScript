# agentgauge

> 标签: ai-agent, claude-code, cli, codex, cost-analysis, llm, observability, token, tui

## 简介

Open-source CLI that breaks down where your AI coding agent burns tokens — per-section, per-tool, with cost & compressible-noise estimates. Reads local Claude Code / Codex session logs and refreshes pricing from LiteLLM.
