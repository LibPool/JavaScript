# arkanalysis

> 标签: arkanalyzer, arkts, call-graph, code-review, context-extraction, git, harmonyos, ohos

## 简介

Standalone ArkTS/HarmonyOS commit-context extractor: given a git commit, prints the changed source line ranges plus call-chain and referenced-resource context as JSON.
