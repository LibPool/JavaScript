# agent-docs-kit

> 标签: adr, agent, changelog, decision-record, documentation, frontmatter, lint

## 简介

Documentation templates and a frontmatter linter for repos that coding agents work in. Skills install separately with `npx skills add dafrimer/agent-docs-kit`.
