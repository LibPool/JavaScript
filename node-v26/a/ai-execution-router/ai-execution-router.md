> 标签: ai, amazon-bedrock, anthropic, aws, bedrock, claude, converse, execution, gemini, google, google-genai, governance, llm, multi-provider, nvidia-nim, ollama, openai, openai-compatible, router, typescript, vendor-neutral, vertex-ai

## 简介

A deterministic execution engine for LLM calls. One function: complete(). Speaks the Anthropic, OpenAI-compatible and Google Gemini/Vertex AI wire formats. The router executes, the controller decides.
