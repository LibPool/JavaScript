# awesome-md-to-pdf

> 标签: cli, converter, markdown, mermaid, pdf, puppeteer, typescript

## 简介

Awesome editorial Markdown → PDF. Convert Markdown files in a directory to beautifully styled PDFs (Claude/Anthropic-inspired design) with mermaid, code highlighting, math, and more.
