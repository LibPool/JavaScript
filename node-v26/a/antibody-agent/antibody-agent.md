# antibody-agent

> 标签: agent-skills, ai-agents, claude-code, failure-analysis, guardrails, llm, machine-learning, self-improvement

## 简介

Turn AI agent failures into tested guardrails. Mines failed session transcripts with a learned detector, distills preventive rules, proves each with an A/B replay test, ships signed SKILL.md bundles.
