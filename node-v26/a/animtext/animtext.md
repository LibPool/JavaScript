# animtext

> 标签: animation, animtext, cssanimation, letter-split, letters, split-text, text animation, text effects, text-animation, textfx, typography

## 简介

AnimText is a JavaScript library for letter, word, & line animations. Easily create dynamic text effects with simple HTML data attributes.
