# adwarp

> 标签: ai-agent, claude, cli, google-ads, linkedin-ads, mcp, mcp-server, model-context-protocol

## 简介

Open-source ad agent for LinkedIn Ads and Google Ads. Drafts campaigns, audiences and reports from Claude Code, Cursor, Codex or other MCP clients that can run a local server.
