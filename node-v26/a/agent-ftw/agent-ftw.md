# agent-ftw

> 标签: agent, agents, ai, anthropic, claude, json-schema, llm, ollama, openai, pipeline

## 简介

A small TypeScript framework for structured, multi-phase LLM agents with JSON-schema deliverables, conserved turn budgets, and governed coordinator/sub-agent trees.
