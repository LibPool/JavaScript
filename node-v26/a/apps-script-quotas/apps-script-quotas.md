# apps-script-quotas

> 标签: apps-script, clasp, cli, custom-functions, gas, google-apps-script, google-sheets, limits, quotas, triggers, urlfetchapp

## 简介

Every Google Apps Script quota and limit as data, checked against Google's page daily. CLI tells you which limit your script hits first and explains quota errors.
