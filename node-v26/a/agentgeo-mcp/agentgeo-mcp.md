# agentgeo-mcp

> 标签: agentgeo, ai-search, mcp, model-context-protocol

## 简介

Zero-dependency MCP stdio server for AgentGEO: fetch raw AI answer records (answer text, sources, provider metadata) and load the eight built-in GEO analysis skills. All ranking, sentiment, and scoring runs agent-side.
