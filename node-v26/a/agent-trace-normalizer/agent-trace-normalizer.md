# agent-trace-normalizer

> 标签: adapter, anthropic, genai, llm, normalization, observability, openai, opentelemetry, tokens

## 简介

Normalize raw LLM provider responses (OpenAI / Anthropic / AWS Bedrock / Google Gemini) into a canonical usage record — the adapter front-end for GenAI cost and tracing pipelines.
