# a11y-assist-mcp

> 标签: JavaScript

## 简介

Design-system-agnostic accessibility MCP server for AI agents: scoped entry points (APG patterns, ARIA roles) with ACT/WCAG drill-down, plus Playwright + axe-core verification.
