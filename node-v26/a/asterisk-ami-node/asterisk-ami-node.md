# asterisk-ami-node

> 标签: ami, asterisk, asterisk-ami, asterisk-manager, cti, manager-interface, no-dependencies, pbx, sip, telephony, typescript, voip

## 简介

Dependency-free Asterisk Manager Interface (AMI) client for Node.js. TypeScript types, event streaming, auto-reconnect, ESM and CommonJS.
