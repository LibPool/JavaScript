# aichatctl

> 标签: automation, chatgpt, claude, cli, gemini, notebooklm, podcast

## 简介

CLI to drive the Claude.ai, ChatGPT, Gemini, and NotebookLM web UIs: sync project files, seed chat sessions, and create podcasts.
