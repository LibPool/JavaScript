# apimatic-coin-gecko-api

> 标签: JavaScript

## 简介

CoinGecko Public API V3 provides comprehensive cryptocurrency market data including real-time prices, market caps, trading volumes, exchange information, and historical charts for thousands of cryptocurrencies across multiple currencies and asset platform
