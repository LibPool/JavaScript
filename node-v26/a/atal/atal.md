# atal

> 标签: alert, atal, attractive, icon, message, msg, popup, promise

## 简介

Attractive Alert (Atal) - 一个美观易用、高度可定制的 JavaScript 弹框库，提供丰富的动画图标和类 Promise 的链式调用接口。
