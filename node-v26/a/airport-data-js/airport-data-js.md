# airport-data-js

> 标签: FAA, ISOCountryCodes, aircodes, airport, airports, amadeus, aviation, city, codes, continent, country, flight, flightaware, flightradar24, geography, iata, icao, radarbox, timezones, travel

## 简介

A comprehensive TypeScript library providing easy retrieval of airport data based on IATA, ICAO, city codes, country codes, and continents. Includes LLM tool definitions for AI integration.
