# archaeologist-live

> 标签: changelog, claude, documentation, git, github-action, history, llm, onboarding, openai

## 简介

The self-documenting repo: a GitHub Action + CLI that absorbs every merged PR into a living HISTORY.md with Chesterton's Fences. Works with Anthropic or OpenAI, bring your own key, zero dependencies.
