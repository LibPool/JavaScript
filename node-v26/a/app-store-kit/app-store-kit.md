# app-store-kit

> 标签: agent-skill, app-review, app-store, app-store-connect, aso, claude, claude-code, creative-director, custom-product-pages, in-app-events, ios, ipados, panorama, product-page-optimization, screenshot-design, screenshots, skill

## 简介

A Claude skill that takes an iOS/iPadOS app from code to the App Store and keeps it updated: code pre-check against Apple's rules, product page in every language, screenshots, build upload, and App Store Connect filled through the official API.
