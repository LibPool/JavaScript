## 简介

AX = Agent eXperience — what UX and DX were for humans, AX is for agents. The base toolkit for consuming and implementing agent-first (.ax) surfaces per AXP, the Agent eXperience Protocol (https://apis.ax/axp): markdown-first content negotiation, typed BL
