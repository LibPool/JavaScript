# alterforge

> 标签: cli, docker, generator, graphql, grpc, microservice, nodejs, scaffold, sequelize

## 简介

Alterforge is a developer-friendly CLI that scaffolds scalable microservice architectures with Node.js, GraphQL, gRPC, Sequelize, and Docker — in seconds. Build, modify, and deploy modular backends with zero setup hassle.
