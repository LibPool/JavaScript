# argelander-providers

> 标签: JavaScript

## 简介

Standalone StateProviders for Argelander: near-earth SGP4/TLE and pre-sampled state playback behind the frozen SPEC-PROVIDER seam, with worker port marshalling. Reserved pre-release.
