# adapter-edge

> 标签: adapter, cloudflare-workers, deno, edge, fetch, handler, serverless, vercel-edge

## 简介

A lightweight adapter for running framework-agnostic handlers on edge runtimes (Cloudflare Workers, Vercel Edge, Deno, etc.).
