# apricot-terminal

> 标签: JavaScript

## 简介

Ayudante local de Apricot HQ: corre tu Claude Code (tu suscripción) en tu Mac y lo conecta al Estudio por Supabase Realtime. `apricot-terminal install` para emparejar.
