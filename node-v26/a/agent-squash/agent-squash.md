# agent-squash

> 标签: agent-skills, agent-squash, agents.md, claude, claude-code, codex, cursor, gemini-cli, opencode, symlink, vendor-lock-in

## 简介

One source of truth for every coding agent: CLAUDE.md and .claude/skills stay real, AGENTS.md, GEMINI.md, .agents/skills and every agent's global files become symlinks into them. Agent-scoped sections via <opencode> … </opencode> tags. Zero vendor lock-in
