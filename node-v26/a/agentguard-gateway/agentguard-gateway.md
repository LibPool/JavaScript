# agentguard-gateway

> 标签: ai-agents, firewall, governance, human-in-the-loop, mcp, model-context-protocol, policy, security

## 简介

Self-hosted firewall for AI agents — a transparent MCP gateway that intercepts every tool call, applies an allow/deny/ask policy with human-in-the-loop approval, and streams an audit trail to your own control plane.
