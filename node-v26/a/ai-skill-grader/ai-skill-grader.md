# ai-skill-grader

> 标签: SKILL.md, agent-skills, ai, claude-code, cline, codex, cursor, run-safety, security, skills, windsurf

## 简介

Install the AI Skill Grader — a plain-English run-safety read (and script block) for the skills your coding agent runs. Works with Codex, Claude Code, Cursor, Cline, and Windsurf.
