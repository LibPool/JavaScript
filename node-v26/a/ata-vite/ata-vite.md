# ata-vite

> 标签: ata-validator, codegen, json-schema, typescript, vite, vite-plugin

## 简介

Vite plugin that compiles JSON, JS, and TS schema files to ata-validator standalone modules with TypeScript types. The Vite entry of @ata-project/unplugin.
