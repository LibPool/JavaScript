# auto-mock-data

> 标签: api, development, fake-data, faker, mock, mock-api, mock-data, mock-server, prototyping, rest, synthetic-data, testing

## 简介

Generate realistic synthetic mock data and ready-to-use local REST APIs for 98 built-in categories with full CRUD, pagination, search, filters, seeded data, custom schemas, scenarios and OpenAPI mode. Categories: users, customers, employees, students, tea
