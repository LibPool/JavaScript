# affixio-agent-guard

> 标签: affixio, agent, agent-guard, ai-agent, ai-security, guardrail, llm, llm-security, local-first, mcp, policy, tool-calling

## 简介

Free, local-first guard that checks an LLM agent's tool calls against policy before execution. Simulated local receipts only — not cryptographic attestation.
