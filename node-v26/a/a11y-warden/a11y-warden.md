# a11y-warden

> 标签: a11y, accessibility, alt-text, aria, contrast, github-action, sarif, static-site, wcag, wcag22

## 简介

WCAG 2.2 accessibility audit of static HTML for CI: alt text, form labels, button/link names, inline colour contrast, lang, title, landmarks, ARIA roles/references, aria-hidden focus traps, tabindex, iframe titles, zoom and autoplay, with a baseline file.
