# agentic-speech

> 标签: cartesia, cli, dry-run, elevenlabs, mcp, mp3, openai, sdk, speech-synthesis, text-to-speech, typescript, wav

## 简介

Generate MP3 and WAV speech with ElevenLabs, OpenAI, and Cartesia through a TypeScript SDK, CLI, or MCP server with dry-run previews.
