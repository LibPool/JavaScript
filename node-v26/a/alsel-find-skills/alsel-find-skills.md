# alsel-find-skills

> 标签: agent-skills, alsel, amazon, claude, claude-code, ec, japanese, rakuten, seo, skill-discovery

## 简介

日本語の意図から Agent Skills (Claude Code / Codex / Gemini CLI / claude.ai) を発見する CLI。Agent Skills by ALSEL の 10,000 件超インデックスを内蔵(うち 7,000 件超は寛容ライセンスで全文ダウンロード可)。

## 官网

- 官网：https://agent-skills.jp/find-skills
- 源码仓库：git+https://github.com/takehirosaito/agent-skills-jp.git
