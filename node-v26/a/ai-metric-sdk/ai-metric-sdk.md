# ai-metric-sdk

> 标签: analytics, anthropic, claude, cost-tracking, llm, observability, openai

## 简介

Drop-in analytics wrapper for OpenAI and Claude — routes chat completions through your AI-Metric proxy for cost, token, and latency tracking, with zero other code changes.
