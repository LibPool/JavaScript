# api-init-templete

> 标签: API, Express, JWT, MongoDB, Mongoose, Nodejs, REST, cors, tool

## 简介

Ferramente geradora de templetes inciais para o desenvolvimento de REST APIs em nodejs, juntamente com MongoDB, JWT, Mongoose,entre outras ferramentas já preconfiguradas.
