# anny-js

> 标签: 3d, animation, anny, avatar, body-model, browser, forward-kinematics, lbs, mediapipe, pose, skinning, webgl

## 简介

Live 3D body animation in the browser — FK + LBS for the Anny body model (Apache 2.0). Drives 163 bones from MediaPipe Pose at < 2 ms.
