# agelin

> 标签: agents, ai-agents, anthropic, benchmark, claude, claude-code, linter, quality, subagent

## 简介

Quality scorer & benchmark harness for Claude Code subagents (".claude/agents/*.md"). Like ESLint, but it tells you if the subagent actually works.
