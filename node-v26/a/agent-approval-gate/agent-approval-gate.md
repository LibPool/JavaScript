# agent-approval-gate

> 标签: agent, ai-sdk, approval, guardrails, human-in-the-loop, llm, mcp, rig, tool-calling, tools

## 简介

Human-in-the-loop approval gate for LLM agent tool calls. Classify tools read/write, block destructive calls behind an approver, and never persist a grant across turns.
