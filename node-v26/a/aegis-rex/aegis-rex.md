# aegis-rex

> 标签: ai-agent, audit, cis, cli, devsecops, firewall, hardening, headless, llm, mcp, secrets, security, ssh, suid

## 简介

Headless-drivable security auditor for Linux, macOS and Windows. Runs a 19-check local audit and can be driven by an AI agent (--capabilities / --audit --json / --fix). npm is the distribution channel; the tool itself is dependency-free Python.
