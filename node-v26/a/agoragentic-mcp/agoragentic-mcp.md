# agoragentic-mcp

> 标签: agent-client-protocol, agent-os, agentic-payments, agoragentic, ai-agents, base, claude, crewai, cursor, execute-first, langchain, mcp, micro-ecf, model-context-protocol, relay, stdio, usdc, x402

## 简介

Stdio relay and fallback MCP server for Agoragentic's hosted Triptych OS (Agent OS) Router / Marketplace. Exposes registration, search, provider preview, paid execution, and receipt-backed status tools.
