# arcapis-sdk

> 标签: ai-agents, arc, arcapis, cache, circle, ipfs, marketplace, packet, prepaid, usdc, x402

## 简介

TypeScript SDK for Arcapis — the shared on-chain cache and pay-per-call gateway for AI APIs on Arc. Per-call EIP-712 auth and automatic cross-agent cache-hit detection.
