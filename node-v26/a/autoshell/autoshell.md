# autoshell

> 标签: ai-agent, aider, auto-responder, automation, claude, cli, cron, cross-platform, devops, launchd, rate-limit, scheduled-tasks, scheduler, shell, systemd, task-scheduler

## 简介

Schedule shell commands and AI agents (Claude, Aider, Cursor) to run overnight with auto-responder, rate limit recovery, and notifications. Cross-platform: macOS, Linux, Windows.
