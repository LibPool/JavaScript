# acryl-dsh-editor-plugin-web

> 标签: acryl-package, dsh, dsh-plugin, editor, monaco

## 简介

DSH web plugin: a VS Code-style code editor view (file tree, Monaco, ripgrep search/replace, Markdown preview, git diff).
