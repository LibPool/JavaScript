# annotepage-mcp

> 标签: annotation, annotepage, encryption, feedback, mcp, model-context-protocol, review

## 简介

The assistants' access to annotepage notes: an MCP server and a command-line utility that fetch and decrypt review remarks, answer them, and mark a note resolved with the version the fix ships in.
