# agentify-openapi

> 标签: ai-agents, llm, mcp, model-context-protocol, openapi, swagger, tools

## 简介

Turn any OpenAPI/Swagger spec into an agent-ready MCP server. Point it at a spec and every operation becomes a tool an agent can call.
