# ace-go-linter

> 标签: JavaScript

## 简介

Ace Go Linter is an extension for the Ace Linters suite, providing Language Server Protocol (LSP) support for go. It  integrates seamlessly with Ace Linters, enhancing your Ace editor with linting and analysis capabilities based on the LSP standard.
