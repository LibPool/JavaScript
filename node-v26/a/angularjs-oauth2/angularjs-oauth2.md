# angularjs-oauth2

> 标签: angularjs, authentication, authorization, directive, identity, oauth2, openid, openidconnect

## 简介

Bower and npm package for allowing an AngularJS application to authenticate with an OAuth 2 / Open ID Connect identity provider using the implicit flow.
