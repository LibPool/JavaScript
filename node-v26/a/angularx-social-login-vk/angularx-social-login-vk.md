# angularx-social-login-vk

> 标签: angular, angular-social-login, facebook-authentication, google-authentication, social-authentication, social-login, vk-authentication, vkontakte, vkontakte-authentication

## 简介

Social login and authentication module for Angular 4-7. Supports authentication with Google, Facebook, LinkedIn, Vkontakte (VK). Can be extended to other providers also.
