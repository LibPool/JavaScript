# asdf-fox

> 标签: hibp, password, password-strength, pwned-passwords, security, zxcvbn

## 简介

Inspectable password-strength analysis built on a bundled zxcvbn-ts baseline, a contemporary vocabulary overlay, targeted structural detectors, and opt-in Pwned Passwords checks.
