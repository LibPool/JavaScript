# angular-flex-short

> 标签: JavaScript

## 简介

Библиотека создана для упращения flexbox верстки. Базировалась на библитеке angular-material.css Для простоты были убраны везде повторяющиеся слова layout. И сменилась способ адаптации под экраны.
