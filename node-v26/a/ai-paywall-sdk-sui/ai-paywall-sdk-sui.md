# ai-paywall-sdk-sui

> 标签: ai, bot-detection, express, http-402, micropayments, move, paywall, sui, web3

## 简介

Drop-in HTTP 402 AI paywall on SUI. Gate content with two lines of Express middleware — SUI micropayments arrive directly in your on-chain account, no API key, no custodian.
