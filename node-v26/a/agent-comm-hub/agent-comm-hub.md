# agent-comm-hub

> 标签: agent, ai, cli, communication, hub, mcp, multi-agent, streamable-http

## 简介

Generic multi-peer MCP hub: any MCP-capable agent (MiniMax Code, Claude Code, opencode, Codex, Gemini CLI, DSH, ...) connects to one local streamable-http endpoint and they chat, delegate tasks, and acknowledge in real time
