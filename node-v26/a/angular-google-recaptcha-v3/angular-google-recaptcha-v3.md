# angular-google-recaptcha-v3

> 标签: angular, angular v22, angular-forms, angular-google-recaptcha-v3, angular-signals, captcha, control-value-accessor, google-recaptcha, ng-recaptcha, recaptcha, recaptcha-enterprise, recaptcha-v2, recaptcha-v3

## 简介

A modern, standalone Google reCAPTCHA library for Angular supporting v2, v3, enterprise, reactive forms, and signals. Fully compatible with Angular versions 17.1–22
