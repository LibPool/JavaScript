# arka-cdn

> 标签: arkiv, cdn, chunked-upload, decentralized, encryption, p2p, storage

## 简介

ArkaCDN – high-level CDN client for the Arkiv network: chunked uploads, multi-wallet, P2P AES encryption, browser + Node compatible.
