# agent-atlas-cli

> 标签: ai-agents, claude, claude-code, cli, d3, developer-tools, mcp, skills, visualization

## 简介

Scans your AI coding setup and turns it into an interactive mind map — see what your agents and skills are good at, what you never use, and what's missing. Read-only, local-only.
