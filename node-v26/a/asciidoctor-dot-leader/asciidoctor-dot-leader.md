# asciidoctor-dot-leader

> 标签: asciidoc, asciidoctor, asciidoctor.js, dot-leader, extension, inline-macro

## 简介

Asciidoctor.js extension providing an inline dot:leader['left','right'] macro for TOC-style dot leaders in HTML5 output.
