# apostrophe-proxy-auth

> 标签: apostrophe, authentication, basic auth, cms, cosign, shibboleth, weblogin

## 简介

Log into Apostrophe via weblogin, cosign, shibboleth, basic auth, etc. with an Apache reverse proxy server
