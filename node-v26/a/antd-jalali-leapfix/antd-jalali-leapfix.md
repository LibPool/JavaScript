# antd-jalali-leapfix

> 标签: ant, ant5, calendar, datepicker, dayjs, jalali, khorshidi, persian, shamsi

## 简介

A wrapper for ant-design datepicker and calendar to support Jalali calendar type with dayjs. In this version of the package, the leap year (kabise — سال کبیسه) bug is fixed.
