# agent-monitor-kit

> 标签: agent, claude-code, codex, macos, memory, monitoring, ollama, swap

## 简介

三件套本机监控：服务红绿灯+访问流水(9000) / Claude+Codex 会话呼吸灯(8812) / 内存·Swap 实时水位+Ollama 控制(8813)。零 Python 依赖，macOS 一键启停，排查 agent 使用期间的内存飙升。
