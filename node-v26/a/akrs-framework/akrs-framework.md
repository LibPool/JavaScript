# akrs-framework

> 标签: agents, ai, ai-agents, akrs, framework, knowledge-routing, llm, prompt-engineering, workflow

## 简介

AKRS (Adaptive Knowledge Routing System) — a framework for building AI execution workflows that let inexpensive models execute reliably by delivering the smallest correct knowledge, to the correct agent, at the correct moment.
