# apidom-validate-cli

> 标签: apidom, apidom-validate, asyncapi, cli, openapi, swagger, validator

## 简介

CLI tool that validates OpenAPI / AsyncAPI files with the same diagnostics as editor.swagger.io (via @swagger-api/apidom-ls)
