# ao-wallet-kit

> 标签: ao, arlinkauth, arweave, hooks, metamask, permaweb, react, wallet, web3

## 简介

A simplified wallet connection library for AO (Arweave/AO) applications. Similar API to ArweaveWalletKit with auto-prepared signers.
