# all-social-media-api

> 标签: all-social-media-api, comments, cross-post, delete-post, facebook, get-recent-posts, instagram, linkedin, marketing, meta-ads, nodejs, reply, social-media, threads, whatsapp

## 简介

Post to Facebook, Instagram, LinkedIn, Threads, and WhatsApp from Node.js: cross-post content, images, PDF documents, fetch recent posts with comments, reply to comments in batch, create Meta ads, and delete posts.
