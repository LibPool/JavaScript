# ambi

> 标签: ambidextrous, async, asynchronous, browser, deno, deno-edition, deno-entry, denoland, es2022, es5, exec, execute, export-default, fire, flow, flow control, module, node, promise, promised, promisefy, promisify, sync, synchronous, typed, types, typescript

## 简介

Ambi lets you execute any function ambidextrously; providing you the ability to execute any function (be it synchronous, asynchronous, returns, callbacks, promises) as if it returned a promise.
