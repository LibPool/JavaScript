# antitone

> 标签: a-share, agent, antitone, cli, finance, market-data, news, skill, stock

## 简介

Antitone 财经情报 CLI + Skill：A股/港股/美股的行情、新闻、板块题材、涨停龙虎榜、早晚报与信号回测（16 个只读工具）。装上 Skill，Agent 会自己判断何时调用。
