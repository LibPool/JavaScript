# anyapi-mcp

> 标签: anyapi, data-api, mcp, modelcontextprotocol, scraping, web-scraping

## 简介

Local stdio MCP server for AnyAPI - hundreds of scraping and data APIs behind one key, priced per request in USD. Proxies to the hosted AnyAPI MCP server.
