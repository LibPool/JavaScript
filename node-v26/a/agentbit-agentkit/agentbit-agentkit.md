# agentbit-agentkit

> 标签: agent, agentkit, ai-agent, base, coinbase, mcp, onchain, router, usdc, x402

## 简介

Coinbase AgentKit action provider for the AgentBIT Router — give your agent one tool that runs any of 14,000+ x402 tools and returns the result. Pay-per-call in USDC on Base.
