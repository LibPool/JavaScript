# agent-pet

> 标签: codex-pets, companion-pet, pet, pixel-art, react, shadow-dom, spritesheet, vanilla-dom, widget

## 简介

Tiny animated companion-pet widget for any web app. Self-hosted, no backend, ~10 KB gzip vanilla DOM. Drives 9 distinct atlas animations from a simple JS API.
