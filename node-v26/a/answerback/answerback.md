# answerback

> 标签: agent, clack, cli, inquirer, interactive, non-tty, prompt, prompts, terminal

## 简介

The answerback. Prompts that are flags first, so agents answer before they are asked and non-TTY callers get an error naming the flag, never a hang. Drop-in path for inquirer and clack.
