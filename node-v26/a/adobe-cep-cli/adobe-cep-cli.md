# adobe-cep-cli

> 标签: JavaScript

## 简介

### `adobe-cep-cli serve <source> <name> [headless]` 开启开发模式    - source 源代码 folder，需要是有完整的插件代码结构 - name dev 插件在插件目录的 folder 名 - headless 是否用无头浏览器调试，false 时会自动打开 chrome
