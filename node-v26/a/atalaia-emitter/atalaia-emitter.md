# atalaia-emitter

> 标签: agents, ai-governance, atalaia, observability

## 简介

Report your AI agent's runs to a Dypsis Atalaia deployment - one function, one HTTP POST, fire-and-forget. Never throws, never blocks, zero dependencies.
