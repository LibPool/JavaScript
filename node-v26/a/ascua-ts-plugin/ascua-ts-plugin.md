# ascua-ts-plugin

> 标签: ascua, editor, plugin, tsserver, typescript

## 简介

Plugin del language service de TypeScript para Ascua: errores de tipos, autocompletado de props e ir a la definición dentro de las plantillas.

## 官网

- 官网：https://ascua.gitweave.run/docs/tipos/
- 源码仓库：git+https://github.com/rvielma/ascua.git
- npm 页面：https://www.npmjs.com/package/ascua-ts-plugin
