# arkmap-js

> 标签: arkadia, arkdelta, arkmap, dat, map, mapper, mud, mudlet, mudlet-map

## 简介

Mudlet map toolkit for Node.js and the browser: read/write .dat and .arkmap maps, validate, XXH3-64 checksums, map diff, .arkdelta edit deltas (validate/build/apply, Ed25519 signature verification), routing, transports, waypoint route codes, token-indexed
