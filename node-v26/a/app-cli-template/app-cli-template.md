# app-cli-template

> 标签: JavaScript

## 简介

这是一个自定义前端脚手架；使用该脚手架工具，我们只要只需要简单的命令就可以从代码库中下载项目到我的本地，不用每次git clone url链接地址（这个地址可能记不住），或者每次重开项目都要拷贝到其他文件夹
