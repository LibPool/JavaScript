# aba-payway-mcp

> 标签: aba, aba-bank, cambodia, claude, claude-code, cursor, gemini-cli, khqr, mcp, model-context-protocol, payment-gateway, payway, windsurf

## 简介

Unofficial, open-source MCP server for ABA PayWay (developer.payway.com.kh) — purchase checkout, KHQR generation, transaction lookup/list, refunds, payment links, and exchange rates. Works with Claude Code, Claude Desktop, Cursor, Windsurf, Cline, VS Code
