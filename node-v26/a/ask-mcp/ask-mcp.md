# ask-mcp

> 标签: ai, claude, cursor, gemini, grok, mcp, model-context-protocol, openrouter

## 简介

A powerful MCP server providing access to multiple AI models (Grok, Gemini, Kimi, Qwen, GLM) through OpenRouter. Perfect for Cursor, Claude Desktop, and other MCP clients.
