# agent-retro

> 标签: analytics, claude-code, codex, coding-agent, developer-productivity, mcp, telemetry, transcripts

## 简介

Retrospectives for your coding-agent sessions: reads local Claude Code, Codex, pi, opencode, Continue, Zed and Cursor logs, finds what you work on and where tokens, time and failures go, and recommends concrete changes. Local dashboard, versioned export,
