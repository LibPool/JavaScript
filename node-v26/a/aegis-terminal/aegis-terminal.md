# aegis-terminal

> 标签: aegis, aegiscloud, cli, llm, terminal

## 简介

AEGIS terminal host — the shared tool surface in your shell, over the same thin transport and tool registry as the MCP plugin and the desktop app. Ships transport + UI only; no brain.
