# agy-discord-notify

> 标签: agent-skill, agy, alerts, antigravity, antigravity-skill, build-notifications, cli, devtools, discord, discord-bot, discord-notification, discord-webhook, nodejs, notification, notifications, notify, push-notification, skill, terminal, webhook, zero-dependency

## 简介

Discord notifications for Google Antigravity (AGY). A zero-dependency skill, CLI, and lifecycle hook that sends messages, file attachments, and rich embeds to a Discord webhook.
