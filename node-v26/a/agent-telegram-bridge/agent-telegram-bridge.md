# agent-telegram-bridge

> 标签: agent, ai-agent, bot-api, claude-code, cli, long-polling, mcp, telegram

## 简介

Мост между ИИ-агентом и Telegram Bot API: очередь входящих для агента, отправка с гейтами и журналом, кнопки, опросы, вложения — CLI, программный API и режим канала Claude Code, без зависимостей
