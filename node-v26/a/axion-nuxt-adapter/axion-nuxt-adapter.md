# axion-nuxt-adapter

> 标签: JavaScript

## 简介

Provider-swappable adapter for the agent-portal backend. The app imports only the domain interfaces; which backend actually answers (real Axion, mock fixtures, or a future replacement) is chosen by env config, never by app code.
