# alcedo-cli

> 标签: bilibili, cli, douyin, parser, tiktok, video, youtube

## 简介

Rust 视频平台解析命令行：给一条分享链接，返回媒体地址、图集、封面、作者和可用清晰度

- npm 安装：`npm install alcedo-cli`
- npm registry：https://registry.npmjs.org/alcedo-cli
- Node 要求：>=16
