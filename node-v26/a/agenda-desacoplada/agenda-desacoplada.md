# agenda-desacoplada

> 标签: JavaScript

## 简介

Este projeto visa a integração por terceiros á agenda eletrônica da onlineclinic. Se você já possui uma conta na nossa plataforma, você pode utiliza-la em seu site. Atualmente, por instância só é posível realizar agendamentos para um médico em uma clínica
