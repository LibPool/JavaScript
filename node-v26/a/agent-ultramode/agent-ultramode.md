# agent-ultramode

> 标签: best-of-n, coding-agent, llm-as-a-verifier, opencode, opencode-plugin, plugin, repair, self-repair, ultra, verifier

## 简介

Best-of-N for coding agents with a same-model verifier, verifier-guided repair, and adaptive early-exit: run your task N times in isolated git worktrees, verify, repair the winner past the best-of-N ceiling, and apply it. A /ultra command for opencode.
