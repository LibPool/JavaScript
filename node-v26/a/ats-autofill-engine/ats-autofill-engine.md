# ats-autofill-engine

> 标签: ats, autofill, chrome-extension, form-autofill, form-filler, framework-agnostic, greenhouse, hexagonal-architecture, job-application, lever, mv3, react-controlled-input, typescript, workday, zod

## 简介

Deterministic form autofill engine for ATS job applications (Greenhouse, Lever, Workday). Framework-agnostic core with browser adapters. Chrome MV3 and Node compatible.
