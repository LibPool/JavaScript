# aead-wasm

> 标签: aead, assemblyscript, authenticated-encryption, chacha20, chacha20-poly1305, cipher, constant-time, cross-platform, crypto, cryptography, decryption, encryption, file-encryption, hchacha20, high-performance, isomorphic, mac, message-authentication-code, poly1305, rfc-8439, rfc8439, security, stream-cipher, streaming, symmetric, typescript, wasm, webassembly, xchacha20, xchacha20-poly1305, zero-alloc, zero-gc

## 简介

AEAD ChaCha20-Poly1305 / XChaCha20-Poly1305 ultra-rápido en WebAssembly (AssemblyScript): ~1M ops/s, ~300 MB/s en streaming de archivos, zero-alloc (0% GC), verificación de tags constant-time y cifrado in-place. RFC 8439.
