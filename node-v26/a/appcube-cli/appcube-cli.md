# appcube-cli

> 标签: appcube, automation, cli, deployment, huawei, mcp, metadata, model-context-protocol

## 简介

AI-native CLI for automating AppCube metadata operations — scripts, objects, APIs, service permissions, applications, and profiles. Includes MCP server for AI-agent integration.
