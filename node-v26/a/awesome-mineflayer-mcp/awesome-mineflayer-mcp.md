# awesome-mineflayer-mcp

> 标签: agent, bot, llm, mcp, minecraft, mineflayer, model-context-protocol

## 简介

Production-ready MCP server exposing standalone-equivalent control of a Mineflayer Minecraft bot: movement, mining, crafting, inventory, combat, chat, containers, lifecycle, and event streaming.
