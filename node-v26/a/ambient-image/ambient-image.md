# ambient-image

> 标签: colored css shadows, css ambience, css3, es6, javascript, vue, vuejs

## 简介

<code>ambient-image</code> is a Vue component that can be used to add colored shadows to images. As shown on the demos below the shadow accepts the colors of the image creating beautiful and fully configurable ambience via handy props for blur, elevation,
