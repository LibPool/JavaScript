# app-settings-js

> 标签: app-settings, configuration, feature-flags, isomorphic, preferences, remote-config, sdk, settings, typescript

## 简介

TypeScript SDK for the App Settings API: role-based, layered application settings. No dependencies; runs in browsers, Node, Bun and Deno.
