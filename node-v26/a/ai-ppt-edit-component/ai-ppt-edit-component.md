# ai-ppt-edit-component

> 标签: ai, components, editor, ppt, vue

## 简介

本目录是从 `src/views/ppt-editor` 抽离出来的 **纯 JS 版本** 编辑器组件包。已包含 Editor 相关的页面、组件、composables、stores、shared、configs、apis、assets 等文件，支持作为独立依赖直接接入任意 Vue 3 项目。
