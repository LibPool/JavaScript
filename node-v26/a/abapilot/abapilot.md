# abapilot

> 标签: abap, ai, ecc, mcp, mcp-server, model-context-protocol, s4hana, sap

## 简介

MCP connector for AI-assisted ABAP development on SAP ECC and on-premise S/4HANA. Requires a licensed ABAPilot backend.
