# atomic-quantum-engine

> 标签: bitmask, bloom-filter, browser, css-selector, dom, dom-query, frontend, high-performance, performance, queryselector, sharedarraybuffer, spatial-query, web-worker

## 简介

High-performance CSS selector engine built on BigInt bitmasks, SharedArrayBuffer, dual Bloom bucket indexing, and off-thread Web Worker matching. Up to 40× faster than querySelectorAll on large DOMs with high query frequency.
