# autoconverter

> 标签: automation, handbrake, itunes, transcoding

## 简介

Automatically HandBrake convert videos that are added to a directory, move to iTunes directory, and add to iTunes library

- 源码仓库：https://github.com/qrpike/NodeJS-Auto-Convert---add-to-iTunes.git
- npm 页面：https://www.npmjs.com/package/autoconverter
