# alphai-sdk

> 标签: alphai, api, financial-news, fintech, insider-trading, sdk, sec-form-4, sentiment, stock-news, trading, typescript

## 简介

Typed TypeScript client for the AlphAI REST API — relevance-scored, ticker-linked financial news and SEC Form 4 insider data. Runs in Node, browsers, edge, Deno, and Bun with zero runtime dependencies.
