# aws-testing-framework

> 标签: automation, aws, aws-sdk, bdd, ci-cd, cloudwatch, correlation, cucumber, end-to-end-testing, integration-testing, lambda, monitoring, s3, serverless, sqs, step-functions, test-framework, testing, typescript, workflow-testing

## 简介

A comprehensive BDD framework for testing AWS serverless architectures with TypeScript and Cucumber. Supports S3, SQS, Lambda, Step Functions, and CloudWatch integration testing.
