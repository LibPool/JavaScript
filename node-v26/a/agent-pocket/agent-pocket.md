# agent-pocket

> 标签: agent, claude, claude-code, daemon, ios, remote-control, websocket

## 简介

Daemon that bridges Claude Code sessions on your Mac to the Agent Pocket iOS app — remote control, permission approvals, and session monitoring with end-to-end encryption.
