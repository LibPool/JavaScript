## 简介

AIXX MCP server — one API key to every AI model (Claude/GPT/Gemini/DeepSeek/Qwen/GLM) + image & video generation. Unified AI gateway, OpenAI-compatible. Works with any MCP client (CodeBuddy, Claude Code, Cursor, Cline).
