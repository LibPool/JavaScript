# abnt-citation

> 标签: abnt, academic, academico, artigo, bibliography, brazil, brazilian, citacoes, citation, citation-js, citeme, csl, dissertacao, formatacao, mendeley, monografia, nbr-10520, nbr-6023, normas-abnt, reference, referencias, tcc, tese, universidade, zotero

## 简介

Brazilian ABNT citation formatter (NBR 10520:2023 + NBR 6023:2025) - correctly handles person names (Title Case) vs institutional names (UPPERCASE). Extracted from CiteMe.
