# austria-property-mcp

> 标签: austria, grunderwerbsteuer, immobilien, kaufnebenkosten, mcp, mcp-server, mietrechtsgesetz, model-context-protocol, real-estate, rendite, underwriting

## 简介

MCP server for Austrian residential property: purchase costs (Grunderwerbsteuer, Grundbuch, broker cap), buy-to-let underwriting with rental income tax (AfA, Liebhaberei) and MRG rent-cap checks, every number cited to its legal source.
