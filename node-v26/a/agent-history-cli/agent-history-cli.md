# agent-history-cli

> 标签: agent, claude-code, codex, history, kanban, local-first, search, session-manager, task-board, transcript

## 简介

Every agent session, one board. A local-first task board + searchable librarian for your Claude Code and Codex sessions — live status, full-text search over every transcript, click-to-jump, and one-click resume.
