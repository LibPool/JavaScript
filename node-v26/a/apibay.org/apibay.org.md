# apibay.org

> 标签: apibay, apibay.org, thepiratebay, thepiratebay api, torrent, torrent api

## 简介

A TypeScript wrapper for the apibay.org API, providing an easy-to-use interface for fetching torrent data from The Pirate Bay.
