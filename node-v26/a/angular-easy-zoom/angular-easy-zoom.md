# angular-easy-zoom

> 标签: angular, angular 6, angular 7, image zoom, simple image zoom

## 简介

EasyZoom is inspired by angular2-image-zoom and JQuery libraries such as jQuery Zoom and elevateZoom-plus but a pure Angular2+ implementation of similar concepts.
