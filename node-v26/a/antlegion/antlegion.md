# antlegion

> 标签: agents, ai-agents, antlegion, append-only, blackboard, coordination, fact-bus, multi-agent, stigmergy

## 简介

AntLegion — a shared world-state log for AI agents. This is a convenience alias: `npx antlegion` boots @antlegion/bus (and `npx antlegion demo` runs the three-act demo).
