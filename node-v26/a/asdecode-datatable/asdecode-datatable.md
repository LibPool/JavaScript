# asdecode-datatable

> 标签: JavaScript

## 简介

DataTable en vue js 3 fonctionnant avec une api laravel 10 - pagination (backend) - filtre (backend) - trie (backend) - recherche (backend) - vue carte / tableau - selection multiple
