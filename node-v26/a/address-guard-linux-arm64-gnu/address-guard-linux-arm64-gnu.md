# address-guard-linux-arm64-gnu

> 标签: address, address-poisoning, checksum, eip-1191, eip-55, ethereum, evm, napi-rs, solana, tron, validation, wallet, wasm, web3

## 简介

Fast, safety-first address validation for EVM, Solana and TRON — not just 'is it valid?' but 'is it safe to send funds here?'. Rust core, Node (napi) + browser (WASM).
