# @n0n3br/dead-link-hunter

> 标签: 404, broken-links, cli, crawler, developer-tools, documentation, html, link-checker, markdown

## 简介

Zero-dependency CLI that hunts broken links in local .html/.md files: checks external URLs, reports 404s, timeouts, DNS failures and redirect chains.
