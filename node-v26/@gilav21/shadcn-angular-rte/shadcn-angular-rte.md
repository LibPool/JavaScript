# @gilav21/shadcn-angular-rte

> 标签: angular, rich-text-editor, shadcn, tailwind, wysiwyg

## 简介

Compiled Angular rich-text editor from shadcn-angular: base editor + all 13 addons (RTE_FULL). Same ui-* selectors and inputs as the CLI copy model.
