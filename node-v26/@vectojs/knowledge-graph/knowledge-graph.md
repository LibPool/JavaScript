# @vectojs/knowledge-graph

> 标签: graph, knowledge-graph, rdf, typescript, vectojs

## 简介

RDF-driven knowledge-graph domain layer on @vectojs/graph3d: adapter contract, typed entities, 2D/3D mode, onDemand a11y.
