# @vectojs/layout

> 标签: bidi, layout-engine, line-breaking, text-layout, typescript, vectojs

## 简介

Standalone text/box layout engine for VectoJS: line breaking, BiDi-aware inline layout, exclusion flow, glyph measurement, and an off-main-thread layout worker.
