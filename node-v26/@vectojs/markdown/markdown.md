# @vectojs/markdown

> 标签: canvas, latex, markdown, marked, tex, typescript, vectojs

## 简介

Canvas-native Markdown (and TeX math) rendering for VectoJS: a Markdown entity plus CodeBlock, built on @vectojs/ui components with marked + @vectojs/tex.
