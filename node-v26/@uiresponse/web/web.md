# @uiresponse/web

> 标签: generative-ui, orthen, react, ui-response, uir

## 简介

UI Response's product web app: the chat→page Generate surface and the first-party renderer. Runs standalone against @uiresponse/server, or embeds into a host with <UIResponseGenerate/>.
