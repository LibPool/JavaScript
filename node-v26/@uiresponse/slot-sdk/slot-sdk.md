# @uiresponse/slot-sdk

> 标签: generative-ui, orthen, react, slot, ui-response, uir

## 简介

React SDK for UI Response delivery slots: a UIResponseSlot renders a validated generated view, plain text, or your existing fallback — decided per ask.
