# @matthiasnordwig/matrix-mcp

> 标签: citations, claude, documents, local, mcp, mcp-server, pdf, rag, semantic-search

## 简介

Matrix MCP server for Claude Code and other MCP clients: local semantic search over PDF and document folders with citations to file, page and passage, tables across documents and cross-references between provisions.
