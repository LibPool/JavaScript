# @gggdomi/rrh-auth

> 标签: redux api authentication, redux auth, redux authentication, redux authentication helper, redux helper, redux jwt, rrh

## 简介

Plugin for RRH to help with authentication workflow. Store credentials, authenticate requests and redirect to login if needed.
