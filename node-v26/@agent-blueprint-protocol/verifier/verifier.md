# @agent-blueprint-protocol/verifier

> 标签: a2a, agent, conformance, interoperability, mcp, protocol, verifier

## 简介

Installable verifier for the Agent Blueprint Protocol: canonical-bytes, digest, signature, bounds, and conformance-corpus verification. Non-authorizing — evidence, never a decision.
