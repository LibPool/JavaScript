# @ninomae/mcp-app-server

> 标签: ai-agent, chatgpt, claude, cloudflare-workers, cursor, mcp, mcp-server, model-context-protocol, oauth, oauth2, oauth2.1, pkce, storage-agnostic

## 简介

Turn your existing app into an OAuth 2.1-protected MCP server. Bring your own identity, tools and storage; users connect Claude, ChatGPT, Cursor or any MCP client to their own data.
