# @hexmillionaire/repo-fixtures

> 标签: bug-report, claude-code, cli, codex, fixtures, git, git-fixtures, git-status, merge-conflict, reproduction, submodule, test-fixtures, testing

## 简介

Create small real Git repos (staged changes, renames, merge conflicts, Unicode paths, submodules) for reproducible bug reports and dev-tool tests. Zero dependencies.
