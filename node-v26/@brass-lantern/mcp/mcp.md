# @brass-lantern/mcp

> 标签: coding-agent, interactive-fiction, mcp, model-context-protocol, text-adventure

## 简介

A Model Context Protocol server for brass-lantern: lets a coding agent audit, play and read the docs for the text-adventure world it is writing.
