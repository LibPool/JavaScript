# @drietsch/sketch

> 标签: animation, cursor, demo, deterministic, gui, hand-drawn, mockup, sketch, svg, timeline, wireframe

## 简介

API-first library for sketching hand-drawn GUI mockups and animating how they are used. Deterministic SVG output.
