# s3-test-server

> 标签: aws, emulator, mock, s3, server, storage, test

## 简介

A modern, lightweight Amazon S3 emulator for local development and testing. Compatible with AWS SDK v2 and v3, Signature V2/V4, path-style and virtual-host-style addressing, streaming (aws-chunked) uploads and flexible checksums.
