# @ernestbies/react-timer-hook

> 标签: clock, countdown, react, react-hook, react-hooks, react-native, time, timer, useStopwatch, useTime, useTimer

## 简介

React timer hook is a custom react hook built to handle timers(countdown), stopwatch and time logic/state in your react component.
