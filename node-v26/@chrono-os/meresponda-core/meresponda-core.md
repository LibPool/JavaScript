# @chrono-os/meresponda-core

> 标签: JavaScript

## 简介

Me Responda — schema (Zod) + motor de fluxo + registry de tipos de campo. Puro, sem dependências de framework; compartilhado entre o backend (NestJS) e o frontend (Next.js).
