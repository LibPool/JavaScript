# @chrono-os/meta-capi

> 标签: capi, chrono-os, conversions-api, facebook, meta, pixel

## 简介

Meta Conversions API (server-side): hash de PII no padrão da Meta, deduplicação por event_id, fbc/fbp, Lead e Purchase. Nunca lança; zero dependências de runtime.
