# shardflux

> 标签: ai-agents, cli, code-execution, microvm, sandbox, sdk, serverless, shardflux, vm, workspace

## 简介

Shardflux: serverless VMs without lifecycle code. The TypeScript SDK (import { Shardflux } from 'shardflux') and the shard CLI in one package.
