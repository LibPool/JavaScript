# pi-deepread

> 标签: deepseek, exa, llm-tools, pdf, pi, pi-coding-agent, pi-package, web-search

## 简介

Full-text web search and document reading for Pi: DeepSeek need_content search, Exa fallback for 公众号/YouTube/V2EX, and local anymd conversion for PDF/Office/EPUB/images.
