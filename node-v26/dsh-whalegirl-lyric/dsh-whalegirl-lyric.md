# dsh-whalegirl-lyric

> 标签: desktop-lyrics, dsh, dsh-plugin, lx-music, lyrics, whalegirl

## 简介

DSH Web GUI 插件：鲸鱼娘形象 + 洛雪音乐歌词气泡，支持会话标题栏逐字歌词带、播放控制与 SSE 即时同步。
