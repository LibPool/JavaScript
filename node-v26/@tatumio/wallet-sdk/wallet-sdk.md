# @tatumio/wallet-sdk

> 标签: api-client, blockchain, mpc, sdk, tatum, typescript, wallet, wallets, web3

## 简介

TypeScript SDK for Tatum-hosted MPC wallets — wallet generation, signing, sending, backup/recovery, and custodian/client management.
