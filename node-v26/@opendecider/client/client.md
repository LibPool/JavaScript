# @opendecider/client

> 标签: agents, ai, ai-sdk, classification, guardrails, llm, mastra, opendecider, prompt-injection, routing

## 简介

OpenDecider for TypeScript: typed decisions, routing and a prompt guard from small open decision models served by opendecider serve, Ollama or LM Studio, with tools for the Vercel AI SDK and Mastra.
