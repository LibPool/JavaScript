# @opendecider/web

> 标签: ai, browser, classification, guardrails, onnx, opendecider, prompt-injection, routing, webassembly, webgpu

## 简介

OpenDecider on the device: opendecider-nano in the browser (WebGPU or WebAssembly), Node, Bun or Deno, so the text never leaves it. Typed decisions, routing and a prompt guard with the API of @opendecider/client.
