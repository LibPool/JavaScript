# @aghoz/history-file

> 标签: append-only-log, durability, eventsource, live-updates, persistence, push, real-time, realtime, replay, server-push, server-sent-events, sse, streaming, typescript

## 简介

Disk-backed history for aghoz — makes SSE replay survive a process restart, so a deploy does not make every connected client refetch.
