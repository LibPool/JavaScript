# @aghoz/server

> 标签: authorization, eventsource, express, hub, live-updates, node, nodejs, polling, pubsub, push, real-time, realtime, server-push, server-sent-events, sse, streaming, typescript, websocket-alternative

## 简介

In-process resumable edge event streams for Node.js and Express — mounts as a route so your existing auth runs first. Replay and explicit gaps, zero dependencies.
