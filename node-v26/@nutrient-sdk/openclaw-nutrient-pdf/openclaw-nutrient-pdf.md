# @nutrient-sdk/openclaw-nutrient-pdf

> 标签: ai-pdf, extraction, llm-pdf, nutrient, openclaw, openclaw-plugin, pdf, pdf-extraction, pdf-table-extraction, pdf-to-markdown, pdfjs-alternative, structured-markdown, table-extraction

## 简介

Explicit Nutrient-powered PDF extraction tool and CLI for OpenClaw. Adds an on-demand nutrient_pdf_extract tool and an openclaw nutrient-pdf CLI for high-fidelity table, heading, and reading-order extraction.
