# @bavimail/toolkit

> 标签: ai-agents, bavimail, email, email-api, langchain, mcp, toolkit, tools, vercel-ai-sdk

## 简介

Bavimail Toolkit — first-party LangChain and Vercel AI SDK integrations for the Bavimail email API. Wraps the official `bavimail` TypeScript SDK into framework-native tool definitions.
