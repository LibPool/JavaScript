# @flitt/api

> 标签: api, discord-bot, events, fivem, flitt, game-server, garrys-mod, gmod, minecraft, realtime, sdk, votes, webhooks, websocket

## 简介

Official TypeScript / JavaScript client for the Flitt Public API: servers, players, firewall, commands, Discord linking, votes, reviews, webhooks and real-time events (FiveM, Garry's Mod, Minecraft).

## 官网

- 官网：https://flitt.me/docs/public-api
