# @shelf-ui/mcp

> 标签: ai, claude, cursor, llm, mcp, model-context-protocol, shadcn, shelf-ui, ui-components

## 简介

Model Context Protocol (MCP) server for Shelf UI – search components, get install commands, and fetch component schemas from the Shelf UI registry.
