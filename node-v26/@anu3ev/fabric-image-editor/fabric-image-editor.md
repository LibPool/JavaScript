# @anu3ev/fabric-image-editor

> 标签: canvas, fabricjs, image-cropping, image-editor, image-manipulation, typescript, undo-redo

## 简介

TypeScript image editor library built on FabricJS, allowing you to create instances with an integrated montage area and providing an API to modify and manage state.
