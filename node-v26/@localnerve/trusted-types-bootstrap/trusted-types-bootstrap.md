# @localnerve/trusted-types-bootstrap

> 标签: bootstrap, content security policy, csp, sanitize, trusted types, web security, xss

## 简介

Page-level Trusted Types bootstrap for web apps: one import + config call replaces the per-app inline bootstrap script. Optional DOMPurify-backed sanitizer policy sub-path.
