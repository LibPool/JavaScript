# @darudb/darudb-darwin-x64

> 标签: darudb, database, embedded-database, encrypted-database, encryption, file-database, local-database, napi, native, offline, rust, storage, typescript

## 简介

An embedded database that keeps an application's data in one local file. The Node.js binding of the DaruDB engine.
