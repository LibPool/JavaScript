# healix-runner

> 标签: acp, ai, allure, claude, copilot, healix, live, mcp, parallel, test-runner, wdio, webdriverio

## 简介

The Healix web runner: run WebdriverIO specs in parallel and watch each one live in a browser, answer maintenance pauses, ask Claude Code or GitHub Copilot about a failure, and read the Allure results.
