# @turbodocx/embed

> 标签: custom-element, digital-signature, embedded-signing, esignature, iframe, postmessage, react, turbodocx, turbosign, web-component

## 简介

TurboSign embedded-signing widget - a framework-agnostic web component and a React component that frame an embed URL, pin the origin, and surface the turbosign:completed event
