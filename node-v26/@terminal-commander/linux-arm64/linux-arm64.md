# @terminal-commander/linux-arm64

> 标签: binary, terminal-commander

## 简介

Terminal Commander prebuilt Rust binaries for linux/aarch64. Internal platform package consumed by the `terminal-commander` root wrapper via optionalDependencies; do not depend on this package directly.
