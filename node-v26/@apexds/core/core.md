# @apexds/core

> 标签: BFS, BST, DFS, algorithms, binary search, binary search tree, breadth-first, data structures, depth-first, dijkstra, directed graph, doubly linked list, graph, linked list, merge sort, queue, quick sort, randomized binary search tree, shortest path, singly linked list, stack, undirected graph

## 简介

Lightweight & modular collection of data structures for TypeScript. Features Directed/Undirected Graphs, Advanced Pathfinding (Dijkstra, BFS/DFS), Randomized BST (Treap-based), and optimized presenters. Zero-dependency, ESM-first, and fully tree-shakeable
