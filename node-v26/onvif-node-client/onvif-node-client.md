# onvif-node-client

> 标签: backchannel, g711, ip-camera, onvif, rtsp, speaker, typescript, ws-discovery

## 简介

Modular ONVIF client library for Node.js (TypeScript): WS-Discovery scan, discovery, events, and audio backchannel.
