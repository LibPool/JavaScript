# @toki0413/plugin-sdk

> 标签: JavaScript

## 简介

Saturday 引擎插件脚手架：给一份引擎描述符，生成过契约（potentialProviderContract）+ 过 conformance 的引擎插件包（descriptor + codec 装配，作者不写 provider 代码）。
