# @hnss/psi-plugin-llm

> 标签: JavaScript

## 简介

`Model` 的实现。类型从 `@hnss/psi-compose` 导入，运行时不依赖 `@hnss/psi-core`。传输使用 `openai` 这个 SDK 的 Chat Completions 流。`@hnss/psi-core` 不导入该 SDK。
