# fontsketch

> 标签: autohinting, cff, create your own font, font, font compiler, font creator, font editor, font generator, font hinting, font maker, font parser, glyph, handwriting font, icon font, kerning, make a font from handwriting, opentype, otf, svg to font, truetype, ttf, typography, variable font, web fonts, woff, woff2

## 简介

Create your own font in the browser or Node: draw or scan handwriting, then export TTF, OTF, WOFF and WOFF2 with kerning, accents, autohinting and variable weight axes. A font compiler, parser and font editor toolkit written in plain JavaScript.
