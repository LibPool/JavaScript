# @nodesandbox/event-bus

> 标签: ampq, architecture, bus, event, event-bus, event-driven, message-queue, nodejs, publish, queue, rabbit, rabbitmq, subscribe, typescript

## 简介

A RabbitMQ-based event management library for Node.js, providing message publishing, subscription, and rerouting of unroutable messages with support for persistence and idempotency.
