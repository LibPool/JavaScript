# @sheetsdata/mcp

> 标签: components, datasheets, eda, electronics, embedded, hardware, mcp, model-context-protocol, oauth, pcb

## 简介

MCP server for electronic component datasheets — specs, pinouts, package data on demand. OAuth 2.0 supported (API key fallback). No PDFs required.

## 官网

- 官网：https://sheetsdata.com
- 源码仓库：git+https://github.com/octoco-ltd/sheetsdata-mcp.git
- npm 页面：https://www.npmjs.com/package/@sheetsdata/mcp
