# @dbcube/studio

> 标签: database, dbcube, gui, mongodb, mysql, orm, postgres, sqlite, studio

## 简介

Dbcube Studio — a local database GUI (browse, edit, visualize) for PostgreSQL, MySQL, SQLite and MongoDB. Launch with `npx dbcube studio`.
