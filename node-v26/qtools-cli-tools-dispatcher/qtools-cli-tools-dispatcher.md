# qtools-cli-tools-dispatcher

> 标签: cli, command-line, dispatcher, qtools, tools.d

## 简介

Chassis for multi-tool Node.js command line programs: argument parsing, JSON on stdin, tools.d discovery, generated help, table output and pipe-safe exit
