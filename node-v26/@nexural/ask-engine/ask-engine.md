# @nexural/ask-engine

> 标签: JavaScript

## 简介

Federation-wide doc collector + FTS5 search engine. Powers `nx ask`. Walks warehouses + ADRs + constitution + recipe THREAT_MODELs/DECISIONS, indexes into local sqlite FTS5, returns ranked excerpts. Phase 11.2 per ADR-0012 §5.
