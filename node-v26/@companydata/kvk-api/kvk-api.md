# @companydata/kvk-api

> 标签: b2b-data, business-register, company-data, company-search, dutch, handelsregister, kamer-van-koophandel, kvk, kvk-api, kvk-nummer, netherlands, sdk, typescript

## 简介

KVK API wrapper: Dutch company data from the KVK Handelsregister with full addresses, phone, email, website and firmographics, through one REST call. A thin layer over @companydata/companydata-sdk, pinned to NL.
