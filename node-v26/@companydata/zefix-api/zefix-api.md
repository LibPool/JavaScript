# @companydata/zefix-api

> 标签: b2b-data, business-register, company-data, company-search, firmen, handelsregister, sdk, swiss, switzerland, typescript, uid, zefix, zefix-api

## 简介

Zefix API wrapper: Swiss company data from the Zefix central business name index with full addresses, phone, email, website and firmographics, through one REST call. A thin layer over @companydata/companydata-sdk, pinned to CH.
