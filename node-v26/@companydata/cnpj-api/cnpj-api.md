# @companydata/cnpj-api

> 标签: b2b-data, brazil, brazilian, business-register, cnpj, cnpj-api, company-data, company-search, consulta-cnpj, empresas, receita-federal, sdk, typescript

## 简介

CNPJ API wrapper: Brazilian company data from the CNPJ register (Receita Federal) with full addresses, phone, email, website and firmographics, through one REST call. A thin layer over @companydata/companydata-sdk, pinned to BR.
