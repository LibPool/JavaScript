# markdown-design-doc-viewer

> 标签: architecture, design doc, design document, docs as code, documentation, flowchart, front matter, git diff, html export, markdown, markdown preview, mermaid, mermaid preview, preview, sequence, sequence diagram, specification, uml, シーケンス図, フローチャート, 仕様書, 基本設計書, 設計書, 詳細設計書, 電文定義

## 简介

Preview design documents written in Markdown: mermaid sequence diagrams and flowcharts side by side with their linked step descriptions, a document header from the front matter, a table of contents, GitHub alerts and task lists.
