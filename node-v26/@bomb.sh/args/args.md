# @bomb.sh/args

> 标签: args, cli, minimist, yargs

## 简介

A <1kB library for parsing CLI flags. Inspired by Deno's `std/cli` [`parseArgs`](https://github.com/denoland/std/blob/main/cli/parse_args.ts) module.
