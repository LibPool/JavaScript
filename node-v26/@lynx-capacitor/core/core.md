# @lynx-capacitor/core

> 标签: bridge, capacitor, lynx, native-module, reactlynx

## 简介

Capacitor bridge reimplemented over the Lynx NativeModule API. Drop-in replacement for @capacitor/core so unmodified @capacitor/* plugins run on Lynx.
