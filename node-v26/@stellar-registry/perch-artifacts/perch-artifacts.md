# @stellar-registry/perch-artifacts

> 标签: JavaScript

## 简介

Perch's consumable artifacts as files: deployment manifests, the Noir ZK recovery circuits and their manifest, test vectors, document and program limits, and the scripts that fetch the deployed wasm and install the pinned ZK toolchain
