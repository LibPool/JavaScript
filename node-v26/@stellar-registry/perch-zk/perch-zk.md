# @stellar-registry/perch-zk

> 标签: JavaScript

## 简介

Proof helpers for Perch ZK recovery: commitments, Merkle witnesses from pool leaves, a trust-free pool indexer, circuit inputs, and UltraHonk proving in the browser or Node
