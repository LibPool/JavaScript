# @nautili/ai-sdk-provider

> 标签: ai, ai-sdk, ai-sdk-provider, gateway, llm, llm-gateway, nautili, vercel-ai

## 简介

AI SDK provider for the Nautili AI Gateway — one wire for every model (Chat Completions, Claude included) with the prompt-cache breakpoint preserved, gateway controls on providerOptions.nautili.*
