# @frontify/fondue-sdk

> 标签: agent-skill, design-system, fondue, frontify, mcp, sdk

## 简介

Machine-readable SDK for Frontify Fondue — components, icons, tokens — exposed as a navigable graph. Designed for MCP servers, CLI tools, AI agents, and other integrations.
