# @microsoft/powerbi-desktop-bridge-cli

> 标签: cli, microsoft, pbip, pbir, powerbi

## 简介

CLI for Power BI Desktop Bridge automation: discover running Desktop instances, reload PBIR reports, and capture page screenshots over the named-pipe bridge.
