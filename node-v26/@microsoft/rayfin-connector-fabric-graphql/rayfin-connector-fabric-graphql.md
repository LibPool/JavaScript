# @microsoft/rayfin-connector-fabric-graphql

> 标签: connector, graphql, rayfin, sql

## 简介

Experimental Cat A GraphQL-backed connector types for the Rayfin SDK. Provides the entity-oriented marker (GraphQLBackedConnector) and CRUD operation gating used by the typed client.connectors.<name>.<Entity>.select(...).execute() surface.
