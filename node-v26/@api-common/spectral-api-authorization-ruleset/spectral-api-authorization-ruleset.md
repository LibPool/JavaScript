# @api-common/spectral-api-authorization-ruleset

> 标签: api-authorization, api-commons, api-security, dpop, fapi, governance, linting, oauth, oauth-metadata, openapi, ruleset, spectral

## 简介

A curated, owned, grounded Spectral ruleset for the API Authorization Profile — lint your OpenAPI and OAuth Authorization Server metadata against OAuth 2.1 / FAPI 2.0 at two tiers (normal/high). An API Commons tool.
