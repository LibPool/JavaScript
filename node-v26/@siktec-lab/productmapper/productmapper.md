# @siktec-lab/productmapper

> 标签: amazon, asin, barcode, catalog, ean, gtin, product-data, productmapper, sdk, upc

## 简介

Official TypeScript/JavaScript client for the ProductMapper API. Resolve UPC, EAN, GTIN, ASIN or free-text titles into live Amazon catalog listings.
