# @estos/asn1ts

> 标签: asn.1, asn1, ber, bitstring, bmpstring, decoder, encoder, generalizedtime, octetstring, parser, schema, sequence, set, universalstring, utctime, utf8string, validation

## 简介

ASN1.ts is a cross platform ASN1 library written in typescript. It supports encoding and (schema supported) decoding of ber encoded asn1 structures.
