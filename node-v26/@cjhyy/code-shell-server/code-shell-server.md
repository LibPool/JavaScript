# @cjhyy/code-shell-server

> 标签: JavaScript

## 简介

CodeShell server transport layer — mobile remote HTTP/WS host, pairing, passcode gate, tunnel, rooms, uploads, and session/attachment services. Electron-free; precursor of the auth gateway.
