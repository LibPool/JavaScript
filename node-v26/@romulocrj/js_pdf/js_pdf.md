# @romulocrj/js_pdf

> 标签: clearscript, dart_pdf, esm, no-dependencies, pdf

## 简介

JavaScript port of DavBfr/dart_pdf. Dependency-free PDF composition for pure ECMAScript hosts (browser importmap, ClearScript, Node).
