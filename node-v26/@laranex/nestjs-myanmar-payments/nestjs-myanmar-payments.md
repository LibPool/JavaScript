# @laranex/nestjs-myanmar-payments

> 标签: aya-pay, cybersource, kbzpay, laranex, mmqr, myanmar, nest, nestjs, nestjs-myanmar-payments, payment-gateway, payments, wave-pay, wave-pay-mini-app, yoma

## 简介

NestJS integration for Myanmar payment gateways: KBZ Pay, Wave Pay, Wave Pay Mini App, AYA Pay, Yoma MMQR and CyberSource. Built on Node Myanmar Payments. Injectable module, verified callbacks and test fakes.
