# @appforge-ci/cli

> 标签: JavaScript

## 简介

`appforge` — the customer-facing CLI: sign up/log in, manage apps, trigger/watch builds, buy build-token top-ups, start an in-browser device-test session. No fleet commands — that's a separate tool, `appforge-admin` (`packages/admin-cli`), for the platfor
