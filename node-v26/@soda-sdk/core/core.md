# @soda-sdk/core

> 标签: anchor, chain-signatures, ecdsa, ethereum, mpc, rlp, secp256k1, soda, solana

## 简介

SODA SDK: derivation, RLP encoding, and a Sepolia client. Lets a Solana program request external-chain signatures via SODA.
