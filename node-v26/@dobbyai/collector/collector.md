# @dobbyai/collector

> 标签: agents, ai, collector, compliance, dobby, gemini, google-genai, governance, langchain, llm, mastra, observability, telemetry, traceparent, vercel-ai, w3c

## 简介

Telemetry collector for AI agents — Node.js / TypeScript port. Streams every run, LLM call, tool invocation, and chain step from LangChain.js / Mastra / Vercel AI SDK / Google GenAI (Gemini) — or a manual API — to the Dobby AI Control Plane for governance
