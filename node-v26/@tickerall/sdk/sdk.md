# @tickerall/sdk

> 标签: algorithmic trading, backtesting, broker api, copy trading, forex, forex api, hosted, live ticks, market data, metatrader, metatrader 4, metatrader 5, metatrader api, mt4, mt4 api, mt5, mt5 api, no vps, rest api, sdk, tickerall, trading api, trading bot, websocket

## 简介

Official TypeScript/JavaScript SDK for TickerAll — the hosted MetaTrader (MT4 & MT5) REST + WebSocket API. Place trades, stream live ticks, read candles, copy-trade, and manage broker accounts from your code, with no VPS or terminal.
