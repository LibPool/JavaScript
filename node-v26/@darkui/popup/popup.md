# @darkui/popup

> 标签: JavaScript

## 简介

* 基于react弹窗组件 * 支持自定义进场离场动画 * 支持自定义弹窗背景效果 * 支持top，left，right，bottom方向弹出 * 支持Show命令式调用 * 支持弹窗队列功能 * 提供toast/dialog/actionSheet，ui组件 * 提供核心api，自定义拓展任意框架/ui 弹窗组件的Show/Queue功能
