# @praxsuite/sdk

> 标签: authentication, baas, backend, database, praxsuite, sdk, typescript

## 简介

Praxsuite SDK for TypeScript and JavaScript. Auth, queries, files and server-authoritative endpoints for browsers, Node, Deno, Bun and React Native. Zero dependencies.
