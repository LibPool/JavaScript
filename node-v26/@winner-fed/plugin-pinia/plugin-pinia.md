# @winner-fed/plugin-pinia

> 标签: JavaScript

## 简介

@winner-fed/plugin-pinia 是一个为 Vue3 项目集成 Pinia 状态管理库的插件。该插件提供了自动配置、Store 自动发现和导出等功能，让您能够快速在项目中使用 Pinia 状态管理。
