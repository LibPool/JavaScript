# @relaystation/mcp

> 标签: agent, ai-tools, baton, courier, mcp, model-context-protocol, relaystation

## 简介

MCP wrappers for Relaystation. The `relaystation-mcp` bin gives any MCP-compatible host (Claude Desktop, Cursor, Cline, Continue, Cowork) the Courier communication tools (ask_operator / notify_operator / message_agent / ...); the `relaystation-mcp-baton`
