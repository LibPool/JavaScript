# @orshot/colorshot

> 标签: color, color conversion, color input, color parser, color picker, colorshot, css colors, display-p3, eyedropper, framework-agnostic, gradient, gradient picker, oklch, react, react color picker, react gradient picker, swatches, vue, vue color picker, vue3, wcag contrast

## 简介

Color and gradient picker for React and Vue. Solid, linear, radial and conic gradients, every CSS color format including OKLCH and Display P3, accessible and themeable.
