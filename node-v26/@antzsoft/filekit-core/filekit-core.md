# @antzsoft/filekit-core

> 标签: antz, filekit, multipart, presigned, storage, upload

## 简介

FileKit core — isomorphic wire-protocol types, upload policy (MIME/size) defaults and validation, and error codes shared by all FileKit SDKs. Zero dependencies.
