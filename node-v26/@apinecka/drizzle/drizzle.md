# @apinecka/drizzle

> 标签: drizzle, drizzle-orm, nestjs, postgres, postgresql

## 简介

NestJS module for Drizzle ORM over Postgres: a DI-friendly connection wrapper, a lock-coordinated migration runner, and test-database helpers. Bring your own schema.
