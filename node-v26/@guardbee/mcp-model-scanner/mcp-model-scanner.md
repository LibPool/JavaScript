# @guardbee/mcp-model-scanner

> 标签: ai-security, devtools, guardbee, llm-security, mcp, model-security, pickle, safetensors, security, supply-chain

## 简介

MCP server that scans ML model files (PyTorch, pickle, safetensors, Keras/H5, ONNX) for supply-chain risks — malicious pickle deserialization gadgets, disguised/malformed safetensors headers, Keras Lambda-layer RCE, and ONNX external-data path traversal
