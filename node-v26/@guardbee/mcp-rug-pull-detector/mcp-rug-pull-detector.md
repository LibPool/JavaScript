# @guardbee/mcp-rug-pull-detector

> 标签: ai-security, devtools, guardbee, mcp, mcp-security, rug-pull, security, tool-drift

## 简介

MCP server that connects to another MCP server (stdio or Streamable HTTP), baselines its tools/list response, and detects 'rug pulls' — a tool silently changing description, schema, or annotations after it was already approved
