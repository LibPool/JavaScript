# @guardbee/security-suite

> 标签: cli, dependency-audit, devtools, dns, guardbee, mcp, secret-scanner, security, ssl

## 简介

MCP security suite: every GuardBee scanner from one install, one MCP server with the tools you pick (OWASP MCP Top 10, secrets, prompt injection, toxic flows, supply chain, TLS/DNS) and a CLI that runs any of them
