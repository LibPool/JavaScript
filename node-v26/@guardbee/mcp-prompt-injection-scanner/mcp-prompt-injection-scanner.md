# @guardbee/mcp-prompt-injection-scanner

> 标签: ai-security, devtools, guardbee, guardrails, llm-security, mcp, prompt-injection, prompt-injection-detection, rag-security, sast, security, security-scanner

## 简介

Prompt injection scanner for documents, web pages and RAG content: instruction overrides, spoofed chat roles, hidden text and data-exfiltration attempts, as a CLI and an MCP server
