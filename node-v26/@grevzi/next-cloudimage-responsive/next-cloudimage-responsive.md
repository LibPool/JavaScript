> 标签: cloudimage, crop, image, image CDN, image compression, image management, image optimization, image resizing, image resizing and CDN, images, jpeg xr, jpg optimization, lazy loading, next, react, resize, responsive images, web acceleration, webp

## 简介

Cloudimage Responsive will smartly resize, compress and accelerate images across the World in your site for all devices. The plugin supports lazy loading technique with fancy animation on image load.
