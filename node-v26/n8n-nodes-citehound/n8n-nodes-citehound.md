# n8n-nodes-citehound

> 标签: ai-readiness, citehound, llms-txt, n8n-community-node-package, robots-txt, seo

## 简介

n8n nodes for Citehound: scan a domain for AI readiness, compare sites, generate llms.txt, robots.txt and schema, and a polling trigger for monitoring events.
