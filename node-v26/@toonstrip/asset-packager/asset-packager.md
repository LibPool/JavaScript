# @toonstrip/asset-packager

> 标签: asset-pack, comic, packer, sprite-sheet-slicer, spritesheet, toonstrip

## 简介

Turns a directory of per-pose PNGs into a valid toonstrip asset pack: validates them against the asset image spec, packs sprite sheets, derives join anchors, writes pack.json and per-character manifests.
