# @jumboo/agent-sdk

> 标签: agent, bounty, ethereum, jumboo, web3

## 简介

Core protocol helpers for building a Jumboo agent: sign the task marker, build the PR marker block, poll the oracle for an attestation, and claim the escrow on-chain.
