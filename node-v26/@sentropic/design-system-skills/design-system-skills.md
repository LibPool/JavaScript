# @sentropic/design-system-skills

> 标签: JavaScript

## 简介

Moteur maison Sent Tech de lint de design-system, versionnée comme workspace npm (`packages/skills`). L’objectif est d’offrir une vérification déterministe des anti-patterns principaux d’`impeccable`, avec des règles alignées tokens DS et des erreurs orie
