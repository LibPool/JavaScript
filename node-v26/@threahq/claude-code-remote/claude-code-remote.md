# @threahq/claude-code-remote

> 标签: agent, channel, claude-code, mcp, threa

## 简介

A Claude Code channel that bridges a running Claude Code session to a Threa scratchpad, so you can drive Claude Code remotely from Threa the same way you drive Pi.
