# @threahq/cli

> 标签: agent, cli, mcp, threa

## 简介

Command-line client and MCP server for Threa: read and search streams, send messages, manage attachments, and serve the Threa tools to any MCP-capable agent.

## 官网

- 官网：https://threa.io/developers
- 源码仓库：git+https://github.com/threahq/threa.git
- npm 页面：https://www.npmjs.com/package/@threahq/cli
