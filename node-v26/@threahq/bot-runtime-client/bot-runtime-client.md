# @threahq/bot-runtime-client

> 标签: agent, bot, e2ee, runtime, socket.io, threa

## 简介

Protocol client for Threa's bot runtime: the /bot WebSocket transport (presence, claim renewal, trace steps, work nudges) with an HTTP fallback, plus the sealed-turn crypto an end-to-end-encrypted bot needs.
