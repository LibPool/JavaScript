# @thermal-label/escpos-core

> 标签: epson, esc-pos, escpos, label-printer, thermal-label

## 简介

Driver-complete Epson ESC/POS protocol encoder for bitmap label printing — bitmap raster + paper handling + print-area control + realtime status, anchored on Epson's published spec.
