# @sanvika/geolocation

> 标签: geolocation, india, ip, location, sanvika

## 简介

Sanvika ecosystem geolocation SDK — fully centralized via geolocation.sanvikaproduction.com. IP lookup, reverse/forward geocoding, Places autocomplete + details, Maps JS loader. Zero Google API keys in consumer projects.
