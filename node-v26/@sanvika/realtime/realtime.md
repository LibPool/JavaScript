# @sanvika/realtime

> 标签: chat, pusher, realtime, sanvika, socket.io, websocket

## 简介

Sanvika ecosystem realtime SDK — Pusher server singleton, Socket.IO chat hook, channel utilities. Bundles pusher/pusher-js/socket.io-client so consumer projects don't need to install them.
