# @ds-contracts/emitter-web-components

> 标签: JavaScript

## 简介

ds-contracts emitter plugin — contract → vanilla Custom Elements (shadow DOM, constructable stylesheets, zero runtime dependencies), with a deterministic custom-elements.json manifest emitted from the same contract.
