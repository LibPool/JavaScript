# @loamss/sdk

> 标签: capsule, loamss, mcp, model-context-protocol, permission-framework, personal-data, sdk

## 简介

TypeScript SDK for building Loamss capsules — sandboxed extensions that run inside a user's Loamss runtime — and for Path-B apps that pair with a user's Loamss over MCP-over-HTTP.
