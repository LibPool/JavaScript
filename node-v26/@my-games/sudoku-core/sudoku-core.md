# @my-games/sudoku-core

> 标签: backtracking, browser, cjs, core, cross-framework, esm, game, game-engine, generator, h5, iife, mobile-web, puzzle, solver, sudoku, typescript, umd, zero-dependencies

## 简介

Framework-agnostic Sudoku game engine with a backtracking solver and unique-puzzle generator; ships ESM, CJS, UMD and IIFE builds. 无框架依赖的数独引擎，四格式产出。
