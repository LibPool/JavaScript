# @svelte-fui/tailwindcss

> 标签: JavaScript

## 简介

This project's Tailwind CSS preset for the Fluent Design System makes it simple to create modern, accessible, and customizable user interfaces. This integration enables developers to construct the desired look and feel without spending hours writing code.
