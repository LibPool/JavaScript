# @purestack/ts-css

> 标签: JavaScript

## 简介

Type-safe CSS builder for TypeScript. `ts-css` lets you define selectors, declarations, media queries, and CSS variables with a fluent API, then serialize to CSS (optionally via Prettier). It is designed for generating styles in build tools or server-side
