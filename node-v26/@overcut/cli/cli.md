# @overcut/cli

> 标签: ai-agents, claude-code, cli, codex, cursor, mcp, overcut, workflow-automation

## 简介

Command-line interface for Overcut: sign in, connect your coding agent to Overcut's MCP server, and manage API tokens from the terminal.
