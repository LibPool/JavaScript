# @wzrhine/agent

> 标签: JavaScript

## 简介

Agent UI components for WzRhineLab UI: workbench shell, conversations, messages, composer, tools, approvals, questionnaires, terminals, artifacts and agent motion. View-models in, actions out; no runtime, transport or SDK dependency.
