# kokoro-aegis

> 标签: ai-generated-code, checklist, claude-code, kokoro-os, qa, static-analysis

## 简介

Find the holes in AI-made apps before you ship: static checks plus a hand-check table built from your code and spec. No AI, no server, your code never leaves your machine.
