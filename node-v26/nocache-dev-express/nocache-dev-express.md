# nocache-dev-express

> 标签: cache-control, cdn, express, middleware, nocache.dev

## 简介

Express middleware that sends correct Cache-Control headers (hashed assets, static files, HTML, private pages) and registers nocache.dev monitors.

## 官网

- 官网：https://nocache.dev/docs/api
- npm 页面：https://www.npmjs.com/package/nocache-dev-express

## 历史版本号

- 当前版本：1.0.0

- 0.0.0-stage
- 1.0.0

## 获取地址

- npm 安装：`npm install nocache-dev-express`
- npm registry：https://registry.npmjs.org/nocache-dev-express
- Node 要求：>=18
