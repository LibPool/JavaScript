# @yummybait/uniswap-tx-builder-mcp

> 标签: base, defi, ethereum, liquidity, mcp, model-context-protocol, uniswap, unsigned-transactions

## 简介

Keyless MCP server that builds unsigned Uniswap v3 liquidity-position transactions (collect, close, mint, increase, wrap/swap via Universal Router) and simulates them — you sign with your own wallet.
