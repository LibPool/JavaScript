> 标签: compatibility, find-dom-node, finddomnode, migration, react, react-quill, react-transition-group, react19, vite, vite-plugin, webpack, webpack-plugin

## 简介

Vite and webpack 5 plugin restoring findDOMNode for legacy React dependencies (react-transition-group, react-quill, ...) under React 19+, without modifying their source.
