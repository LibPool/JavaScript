# react-native-flex-toast

> 标签: alert, new-architecture, notification, react-native, snackbar, toast, turbo-module

## 简介

Fully customizable toasts for React Native: themes, stacking, queueing, custom renderers, promise toasts, and an optional native overlay that works on the old and new architecture.
