# react-eternal-list

> 标签: infinite list, infinite scroll, js list, light weight list, list, list renderer, optimised list, react eternal list, react infinite list, react list

## 简介

This package can render infinite list items without memory issues as it is using binary tree algorithm to hide and show elements.
