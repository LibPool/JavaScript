# react-chatbot-deepai

> 标签: chatbot, deepai, openai, react, react chatbot, react-chatbot-kit

## 简介

Simple react chatbot component built on OPENAI's models. It relies on react-chatbot-kit for the chatbot UI and adds custom features such as open/close.
