# rasso-plugin-mockup

> 标签: JavaScript

## 简介

简易P图与精装相框工作台：拖放图片即刻套用艺术相框、复古拍立得、浏览器与移动端模型，支持胶片滤镜调色与画幅裁剪，一键导出 2x 高清图或写入剪贴板
