# rnrun

> 标签: bundler, dev-server, expo, expo-go, hmr, metro, react-native

## 简介

Drop-in replacement for the Expo dev server with a tiny memory footprint. Powered by browser-metro and pre-bundled packages from esm.reactnative.run.

## 官网

- 官网：https://reactnative.run
- 源码仓库：git+https://github.com/RapidNative/reactnative-run.git
- npm 页面：https://www.npmjs.com/package/rnrun
