# rn-fluid-calendar

> 标签: android, animation, calendar, customizable, dark-mode, date-picker, dot, ios, marking, modern, multi-select, period, react-native, typescript

## 简介

A modern, highly customizable React Native calendar with dark/light mode, 5 animation types, flexible marking, and full developer control over styles, fonts, and layout.
