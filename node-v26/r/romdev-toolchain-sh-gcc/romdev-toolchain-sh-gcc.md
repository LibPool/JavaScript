# romdev-toolchain-sh-gcc

> 标签: JavaScript

## 简介

sh-elf-gcc toolchain (cc1 / as / ld / objcopy / objdump) for romdev Dreamcast (SH-4) C builds + disassembly, bundled as WASM.
