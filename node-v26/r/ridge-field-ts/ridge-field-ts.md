# ridge-field-ts

> 标签: anisotropic, biometrics, deterministic, fingerprint, friction-ridge, generative, svg

## 简介

Deterministic synthetic-fingerprint synthesis: an anisotropic particle-relaxation model (Düring et al. 2019) that grows genuine friction ridges from a seed profile. Framework-agnostic, zero runtime dependencies.
