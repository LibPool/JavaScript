# react-native-leap

> 标签: ai, expo, gguf, inference, leap, lfm, lfm2, liquid-ai, llm, nitro, on-device, react-native

## 简介

On-device LFM2 / LFM2.5 inference for React Native & Expo via Liquid AI's LEAP SDK. Streaming chat, thinking models, constrained JSON, function calling — powered by Nitro Modules.
