# rapier-html

> 标签: ai-agents, chatgpt, claude, cli, diff, drawing, html, llm, local-first, markdown, markdown-editor, mcp, mermaid, mobile-first, offline-first, rapier, review, send-back, single-file, svg-editor, watercolor

## 简介

One command turns a Markdown file into one offline HTML file: the whole Rapier editor with the document inside. Opens in any browser, phone or desktop, with no install or account. Write, draw and paint watercolor, then Send back the edits to your AI agent
