# recursive_minifier

> 标签: minify

## 简介

recursive_minifier is package that will minify(uglify, compress) all js (including es6+) and css ## Installation ``` npm install recursive_minifier ``` ## Usage ``` node minify.js "path/to/minify" ``` it is that simple ### Maintenance Most probably I will
