# react-native-loading-image

> 标签: JavaScript

## 简介

基于React Native官方组件Image封装的具备加载生命周期视觉反馈的组件,具体实现功能如下： * 网络图片Pending状态渲染，提供闪烁动画、loading.gif两种方式 * 网络图片Error状态渲染 * 继承官方Image组件的所有属性
