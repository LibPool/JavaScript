# rss-feed-widget

> 标签: accessible, dark-mode, feed, no-dependencies, rss, rss-reader, rss-widget, vanilla-js, wcag, widget

## 简介

A lightweight, zero-dependency RSS feed widget built with vanilla JavaScript. Turn any RSS feed into a beautiful, responsive card grid with images, filtering, dark mode, and skeleton loading.
