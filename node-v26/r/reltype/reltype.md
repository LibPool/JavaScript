# reltype

> 标签: camelcase, crud, cursor-pagination, database, fluent, orm, pagination, pg, postgres, postgresql, query-builder, relational, repository-pattern, snake-case, streaming, type-safe, typescript

## 简介

Type-first relational modeling for PostgreSQL in TypeScript. Fluent query builder with automatic camelCase ↔ snake_case conversion, CRUD, streaming, cursor pagination, and hooks.
