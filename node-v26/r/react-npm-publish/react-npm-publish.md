# react-npm-publish

> 标签: JavaScript

## 简介

This project is based on [create-react-app](https://github.com/facebook/create-react-app), in this project you can create your own UI library, and publish it to [NPM](https://www.npmjs.com/).

## 官网

- npm 页面：https://www.npmjs.com/package/react-npm-publish

## 获取地址

- npm 安装：`npm install react-npm-publish`
- npm registry：https://registry.npmjs.org/react-npm-publish
