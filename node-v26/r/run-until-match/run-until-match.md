# run-until-match

> 标签: child-process, cli, cmd, command, exit-on-match, kill-on-match, match, output-watcher, pattern-match, process-control, run, stdout, stdout-watch, until, wait-for, wait-for-output

## 简介

A small Node.js CLI utility that runs a command and terminates it when its output matches a given string.
