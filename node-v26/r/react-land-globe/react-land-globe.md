# react-land-globe

> 标签: 3d, canvas, dotted-globe, earth, globe, interactive, map, markers, react, world

## 简介

Globo terráqueo interactivo en canvas para React: continentes punteados, rotación automática, marcadores con glow y arrastre. Cero dependencias, SSR-safe.
