# react-fatless-form-web

> 标签: checkbox, checkbox-group, controlled-input, dom, file-upload, form, form-bindings, form-hooks, form-library, form-management, form-submit, form-validation, forms, headless, html-form, input-bindings, multi-select, number-input, react, react-form-web, select, text-input, typescript, useCheckboxField, useFileField, useSelectField, useTextField, web, yup

## 简介

Web (DOM) bindings for react-fatless-form - useTextField, useNumberField, useCheckboxField, and useFormSubmit, each wired for plain HTML elements. Re-exports the entire core API, so this is the only package a web app needs to import from.
