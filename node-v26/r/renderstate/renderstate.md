# renderstate

> 标签: playwright, react, screenshot, storybook-alternative, typescript, ui-states, visual-testing

## 简介

Deterministic UI-state renderer for React screens. Discover components, derive prop states from TypeScript, screenshot each, emit a manifest. The board is its first viewer.
