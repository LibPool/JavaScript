# renesis

> 标签: AI image detection, backend, box, dropbox, express, file uploader, google drive, preview, progress, realtime, resumable uploads, s3, tus, websocket

## 简介

Renesis AI extensible file upload widget with support for Image Detection drag&drop, resumable uploads, previews, restrictions, file processing/encoding, remote providers like Dropbox and Google Drive, S3 and more :dog:
