# reborn-voxcpm

> 标签: claude, claude-code, korean, skill, tts, voice-cloning, voice-design, voxcpm

## 简介

오픈소스 음성 모델 VoxCPM2(OpenBMB/VoxCPM · Apache-2.0)의 보이스디자인·음성복제 사용법을 한국어 안내 스킬로 넣어 줍니다. 옵션으로 pip install voxcpm 도 대신 돌립니다. 본체는 제작자의 것이며 대신 만들지 않습니다.
