# react-zlib-js

> 标签: Brotli, Core, Gzip, Nodejs, Zlib, Zstd, compression, deflate, inflate, react-native

## 简介

Pure JavaScript implementation of the Node.js zlib core module: Gzip, Deflate/Inflate, Brotli and Zstd decompression, for React Native and the browser. API-compatible with Node.js 22.x LTS.
