# rspark

> 标签: JavaScript

## 简介

RSpark, based on rspack, is a high-performance Server-Side Rendering framework that is as fast as a spark. Harnessing the efficiency of rspack, it swiftly generates and delivers rendered content, ensuring rapid responses to requests.
