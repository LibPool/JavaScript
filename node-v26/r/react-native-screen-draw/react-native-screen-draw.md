# react-native-screen-draw

> 标签: draw, native, react, react-native, react-native-screen-draw, react-native-sketch, react-native-svg, sketch, svg

## 简介

react-native-screen-draw allows you to draw / sketch on both iOS and Android devices and sync the drawing data between users. Of course you can save as image.
