# reborn-plugin5

> 标签: claude, claude-code, context7, cursor, korean, mcp, playwright, skillui, strix, supabase, vibe-coding

## 简介

영상에서 소개한 바이브 코딩 플러그인 5종(Playwright CLI · Supabase MCP · Strix · SkillUI · Context7)을 붙이기 전에 이 컴퓨터를 먼저 재 주는 안내 스킬입니다. 다섯 줄은 공개돼 있지만 준비물이 서로 다릅니다 — Strix 는 도커가 떠 있어야 하고 LLM 키가 따로 들며, Supabase 는 읽기전용을 켜야 지우는 도구가 안 열리고, Playwright 는 CLI 판과 MCP 판이 다릅니다. 도커·노드·
