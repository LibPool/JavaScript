# reborn-adcheck

> 标签: ads, advertising, audit, claude, claude-ads, claude-code, korean, ppc, skill

## 简介

광고비를 쓰기 전에 클로드에게 2차 의견을 받는 클로드 코드 스킬 AgriciDaniel/claude-ads(MIT · v2.0.2)를 고정 판으로 받아 스킬·에이전트만 스킬 폴더에 놓고, 파일이 실제로 늘었는지 다시 셉니다. 한국어 안내 스킬이 같이 깔립니다. --check 가 깔기 전에 이 컴퓨터를 재 줍니다. 저장소는 남이 만든 오픈소스이고 저희는 제휴 관계가 없습니다 — 저희가 만든 것은 설치기와 한국어 안내 하나뿐입니다. 기본은 읽기전용이라 광
