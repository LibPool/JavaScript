# react-native-wifi-security

> 标签: android, captive-portal, ios, network-security, open-wifi, public-wifi, react-native, react-native-wifi, security, unsecured-wifi, wifi, wifi-security

## 简介

Blocks a React Native app on open (password-less), WEP, Enhanced Open and captive-portal Wi-Fi. Drop-in wrapper with native Android and iOS Wi-Fi security detection, a ready gate screen and an HTTP guard.
