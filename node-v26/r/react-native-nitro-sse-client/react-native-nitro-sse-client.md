# react-native-nitro-sse-client

> 标签: eventsource, http2, nitro, nitro-modules, okhttp, react-native, server-sent-events, sse, urlsession

## 简介

Native Server-Sent Events (SSE) client for React Native, built with Nitro Modules — reuses the platform's HTTP/2 connection pool across reconnects (URLSession on iOS, OkHttp on Android) and reports real TCP/TLS/TTFB timing per connection.
