# react-native-chess-kit

> 标签: 60fps, chess, chess-board, chessboard, gesture-handler, performance, react-native, reanimated

## 简介

High-performance chess board for React Native. Single gesture handler, ~40 components, 0 re-renders during drag. Built on Reanimated + Gesture Handler.
