# repolith

> 标签: agents, cli, git, lockfile, mcp, monorepo, multi-repo, polyrepo, vscode, workspace

## 简介

Make a set of independent git repos feel like one monorepo — TOML manifest, atomic lockfile hash, parallel git dispatch, a VS Code extension, and an MCP server for AI agents.
