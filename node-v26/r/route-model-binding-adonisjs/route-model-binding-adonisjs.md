# route-model-binding-adonisjs

> 标签: adonis route model binding, adonisjs, adonisjs binding, adonisjs models, adonisjs route

## 简介

Route Model Binding. When you inject a model ID into a route, you will often look to retrieve the model that corresponds to that ID. This package provides a convenient solution for Adonis.
