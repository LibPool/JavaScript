# rn-camera-roll-fetcher-ios

> 标签: ios, react-native

## 简介

A lightweight React Native TurboModule that converts iOS ph:// asset URIs (from the Photos framework) into actual local file URIs (file://). Useful when working with image/video pickers, uploads, or any feature where you need the real file path instead of
