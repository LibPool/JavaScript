# rock-clients

> 标签: bybit, cjs, crypto, esm, exchange, library, rest-client, trading, typescript

## 简介

Zero-dependency TypeScript clients for crypto exchanges (Bybit v5 first). Static classes, public/private x spot/futures split, per-call context.
