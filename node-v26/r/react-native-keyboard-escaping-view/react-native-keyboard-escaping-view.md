# react-native-keyboard-escaping-view

> 标签: keyboard, keyboard-avoiding-view, react-native, scrollview

## 简介

A view сorrectly responding to the appearance of the keyboard, on Android and OS. And a component that monitors keyboard events and scrolls content during its appearance and removal.
