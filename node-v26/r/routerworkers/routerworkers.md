# routerworkers

> 标签: cloudflare, cloudflare-workers, cors, edge-computing, http-router, middleware, response-helpers, rest-api, route-groups, router, serverless, typescript, validation, web-framework, workers

## 简介

Um roteador moderno e minimalista para Cloudflare Workers com TypeScript, response helpers, route groups, CORS e validação built-in.
