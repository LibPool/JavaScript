# readdir-sorted

> 标签: a-to-z, alphabetical, array, async, asynchronous, compare, directory, enumerate, file, files, fs, list, locale, order, promise, readdir, sort, sorted

## 简介

Like `fs.promise.readdir()`, but sorts the result based on `String#localeCompare()`
