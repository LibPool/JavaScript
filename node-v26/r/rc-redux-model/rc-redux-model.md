# rc-redux-model

> 标签: dva, model, react, redux

## 简介

react状态管理，提供一种更加舒适的写法，让你简洁优雅的去写状态管理；借鉴 dva 的数据流方案，参考 redux-thunk，内部实现中间件；提供默认行为 action，调用此 action 可直接修改 state 里的任意值，开发更加方便简洁，支持 Immutable，让你从毫无意义的重复工作中解脱
