# react-ai-helmet

> 标签: aeo, ai, json-ld, llms.txt, react, robots.txt, schema, seo

## 简介

AI readability toolkit for React — schema components, AI region hints, and a CLI that generates llms.txt, llms-full.txt and robots.txt.
