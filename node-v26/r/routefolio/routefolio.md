# routefolio

> 标签: api, api-docs, cli, documentation, express, generator, jsdoc, openapi, routefolio, swagger

## 简介

CLI tool for automatic Express.js API documentation generation from JSDoc comments. Generates OpenAPI 3.1, HTML, and Markdown docs.
