# rtl-text-tools

> 标签: arabic, bidi, cross-browser, diacritics, digits, ellipsis, farsi, hebrew, i18n, ie11, kurdish, l10n, normalization, pashto, persian, punctuation, punjabi, quranic, right-to-left, rtl, sindhi, text-processing, typescript, unicode, urdu, uyghur

## 简介

Cross-browser RTL text utility — fixes digits, punctuation, ellipsis, and bidi markers for Arabic, Hebrew, Persian, Urdu, and other RTL scripts. Supports IE11+.
