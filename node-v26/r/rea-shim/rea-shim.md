# rea-shim

> 标签: ghidra, launcher, mcp, reverse-engineering, stdio

## 简介

Unofficial personal-use one-line MCP launcher for rea: resolves a JDK 21+ and Ghidra, then serves upstream rea-agents over stdio at run time. Ships no upstream code. All credit to the original rea authors.
