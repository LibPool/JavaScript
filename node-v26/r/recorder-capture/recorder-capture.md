# recorder-capture

> 标签: react-screen-recorder, react-screencapture, react-screenshot, recorder-with-voice, screen-recorder, screen-recording-with-audio

## 简介

Using this library, you can record a screen with audio, stream a user cam, and take a screenshot of a webpage.
