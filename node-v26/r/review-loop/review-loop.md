# review-loop

> 标签: ai-agents, annotation, astro-integration, code-review, copy-review, developer-tools, express-middleware, review, vite-plugin

## 简介

Bridge between human reviewers and coding agents — annotate rendered pages in-browser and export location-aware feedback. Works with Astro, Vite, and Express.
