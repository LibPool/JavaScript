# react-native-app-shield

> 标签: app-shield, jailbreak, privacy, react-native, root-detection, screen-recording, screenshot, security

## 简介

A React Native library for app security and privacy protections including screenshot blocking, screen recording detection, app background blur, and root/jailbreak detection.
