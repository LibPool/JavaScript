## 简介

영상에서 소개한 addyosmani/agent-skills(엔지니어링 스킬 25종 + 슬래시 명령 9개)를 깔기 전에 이 컴퓨터를 먼저 재 주는 안내 스킬입니다. 까는 명령은 한 줄이 맞지만, 클로드 코드 플러그인 경로는 저장소를 SSH 로 클론해서 키가 없으면 publickey 오류로 멈추고, 스킬 하나만 깔면 공유 references 가 안 따라옵니다. 어느 길로 가야 하는지 실제로 재서 알려 줍니다.
