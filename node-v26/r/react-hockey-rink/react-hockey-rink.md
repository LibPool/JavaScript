# react-hockey-rink

> 标签: data-viz, heatmap, hockey, nhl, react, rink, shot-chart, sports

## 简介

An interactive, themeable ice rink shot chart for React — dots, heat maps, zoom/pan, and period/player filtering, with pixel-accurate NHL rink markings.
