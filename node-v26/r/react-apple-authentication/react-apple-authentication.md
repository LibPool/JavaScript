> 标签: apple-authentication, expo, expo-apple-authentication, expo-web, native, official, react, react-apple-authentication, react-native, react-native-apple-authentication, react-native-web

## 简介

This library provides Apple authentication for iOS 13+. It does not yet support lower iOS versions, Android, or web.
