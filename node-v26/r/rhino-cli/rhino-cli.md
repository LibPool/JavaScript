# rhino-cli

> 标签: JavaScript

## 简介

以docz为文档系统，针对react为开发语言的组件库脚手架。开箱即用， 开发者无需关系文档、打包构建等繁琐的流程，只需专注于组件开发上。

## 官网

- 源码仓库：http://git.code.oa.com/cloud-tencent-UI/rhino-cli.git
- npm 页面：https://www.npmjs.com/package/rhino-cli
