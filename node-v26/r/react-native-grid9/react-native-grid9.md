# react-native-grid9

> 标签: draw, grid9, lottery, react native, turntable

## 简介

react native 版本九宫格抽奖组件，支持Android&iOS <br> 纯js实现 不依赖任何第三方 <br> 按照帧率配置播放动画 任何动画属性都可以更改 同时提供默认配置 <br> 支持抽中跳过逻辑 <br>
