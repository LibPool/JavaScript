> 标签: android, country-input, country-picker, country-selector, dial-code, flags, ios, modal, phone-input, picker, react-native, react-native-paper, typescript

## 简介

A customizable React Native Paper country picker with automatic phone masking, digit limits, searchable modal, flags, and dialing codes.
