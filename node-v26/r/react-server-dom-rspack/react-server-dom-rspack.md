# react-server-dom-rspack

> 标签: react

## 简介

React Server Components bindings for DOM using Rspack. This is intended to be integrated into meta-frameworks. It is not intended to be imported directly.

- 官网：https://react.dev/
- 源码仓库：git+https://github.com/facebook/react.git
