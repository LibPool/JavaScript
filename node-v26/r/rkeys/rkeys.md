# rkeys

> 标签: X11, chord, chords, key, keyboard, keypad, keys, keystroke, macro, remote control, tablet, virtual keyboard

## 简介

A platform for creating tablet/HTML5 virtual-keyboard apps to send keystrokes to remote X11
