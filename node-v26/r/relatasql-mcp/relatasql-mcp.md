# relatasql-mcp

> 标签: database, mcp, model-context-protocol, relatasql, sql

## 简介

Official Model Context Protocol server for RelataSQL — lets LLM clients list database connections, inspect schemas, and execute SQL queries through a user's RelataSQL workspace.
