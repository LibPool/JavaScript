# react-native-ruler-date-picker

> 标签: android, date-picker, gesture-handler, haptics, ios, react-native, reanimated, ruler, scroll-picker

## 简介

A performant, customizable ruler-style date picker for React Native — 60 FPS Reanimated 3 physics, dual-speed haptic feedback, and windowed tick rendering.
