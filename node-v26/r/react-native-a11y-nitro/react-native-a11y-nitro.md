# react-native-a11y-nitro

> 标签: a11y, accessibility, accessibilityState, accessibilityValue, android, ios, nitro, nitro-modules, react-native, screen-reader, talkback, voiceover

## 简介

An accessibility toolkit for React Native built with React Nitro Modules. Provides announcement control and enhanced native views to improve screen reader and keyboard interactions.
