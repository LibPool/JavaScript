# react-router-tsx

> 标签: react, router, typesafe

## 简介

A lightweight, type-safe wrapper around React Router that eliminates magic strings and enforces type-checked routes. Define routes as structured objects, get auto-completion for links & params, and ensure runtime type safety—all with a clean, intuitive AP
