# rsih-opencode

> 标签: agent, harness, opencode, opencode-plugin, rsih

## 简介

RESEARCH PREVIEW — RSIH deep harness plugin for OpenCode: injects your certified rules into the system prompt and adds context-matched in-flight enforcement, via OpenCode's plugin API. Reads ~/.config/opencode/rsih-opencode.json.
