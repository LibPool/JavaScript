# react-native-snitch

> 标签: android, beta-testing, bug-report, expo, expo-config-plugin, feedback, ios, qa, react-native, screen-recording, screenshot, testflight, turbo-module

## 简介

Snitch for React Native and Expo: testers hold three fingers on the screen to send a bug report with a screenshot and the last seconds of screen video to your own server.
