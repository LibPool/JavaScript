# react-mosaic-loader

> 标签: animation, canvas, diamond, dot-matrix, dots, geometric, grid, hexagon, image, loader, loading, mosaic, placeholder, react, react-component, sampling, skeleton, spinner, squircle

## 简介

React image-sampling loader — Mosaic grid of animated dots from image or gradient. Use as loader, placeholder, or visual effect. Supports circle, squircle, diamond, hexagon, and more.
