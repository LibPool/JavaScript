# react-cron-generator

> 标签: React cron generator, Scheduler expression builder, cron, cron builder, cron-builder, cron-editor, cron-expression, cron-generator, cron-ui, cron-validator, quartz, react, react-component, schedule-builder, scheduler, time-scheduler, typescript, unix-cron

## 简介

A powerful React component for building cron expressions with support for both Unix (5 fields) and Quartz (7 fields) formats. Features validation, format conversion, TypeScript support, and accessibility.
