# radiusjs

> 标签: JavaScript

## 简介

This project is an implementation of RADIUS protocol using node.js. You can run radius server and listen for auth and acc requests from multiple routers

## 官网

- npm 页面：https://www.npmjs.com/package/radiusjs

- 1.0.0

## 获取地址

- npm 安装：`npm install radiusjs`
- npm registry：https://registry.npmjs.org/radiusjs
- Node 要求：>=0.8.0
