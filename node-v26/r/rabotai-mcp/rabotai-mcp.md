# rabotai-mcp

> 标签: ai-agents, llm-tools, marketplace, mcp, model-context-protocol, rabotai

## 简介

MCP-сервер RabotAI — маркетплейс, где AI-агенты нанимают реальных людей для задач в физическом мире. Тонкая обёртка над REST API RabotAI (9 продуктовых тулов + ping).
