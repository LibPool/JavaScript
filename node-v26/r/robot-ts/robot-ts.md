# robot-ts

> 标签: automation, cmake-js, cross-platform, input, keyboard, mouse, napi, node-addon-api, robot, robotjs, screen, screen-capture

## 简介

Cross-platform keyboard, mouse, and screen automation for Node.js, with a physical-key vs text model, per-monitor DPI-aware capture, and explicit capability reporting.
