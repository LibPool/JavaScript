# raspi-1wire-temp

> 标签: 1-wire, DS18B20, one-wire, raspberry-pi, raspberrypi, raspi, rpi, temperature

## 简介

Provides a high-level interface to a "1-wire" compatible temperature device or file on a Raspberry Pi.
