# react-native-graphify

> 标签: accessibility, android, area-chart, bar-chart, box-plot, chart, charts, data-visualization, donut-chart, drilldown, expo, gauge, graph, histogram, ios, line-chart, pie-chart, polar-chart, radar-chart, react-native, react-native-skia, reanimated, scatter-plot, skia, streaming, tooltip, typescript, visualization, waterfall, wind-rose

## 简介

Skia-powered charts for React Native. 15+ chart types with a UI-thread touch cursor, pan/zoom, streaming, drilldown, statistical series and a real screen-reader layer. No WebView, one API for iOS and Android.
