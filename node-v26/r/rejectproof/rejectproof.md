# rejectproof

> 标签: app-review, app-store, expo, flutter, ios, ipa, lint, preflight, privacy-manifest, react-native, rejection, xcode

## 简介

Scan an iOS .ipa for App Store rejection risks before you submit — privacy manifest, permission strings, crash-on-launch, dead links, private API and 40 more checks. Runs locally.
