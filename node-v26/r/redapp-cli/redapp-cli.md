# redapp-cli

> 标签: cli, dapp, scaffold, web3

## 简介

A streamlined CLI that bootstraps a full-stack Web3 dApp in seconds — powered by Next.js, TailwindCSS, Wagmi, Reown AppKit, Solidity, and Foundry.
