# rh-tailwind-global

> 标签: JavaScript

## 简介

**RH Tailwind Global Components** is a collection of reusable UI components built with **React**, **TypeScript**, and **Tailwind CSS**, powered by **Vite**.   The library is designed to help you build modern, consistent interfaces quickly and efficiently.
