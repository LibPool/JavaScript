# romdev-maxmod

> 标签: JavaScript

## 简介

Pure-JS Maxmod soundbank compiler for GBA - a faithful port of devkitPro mmutil. Parses .xm/.mod/.it/.s3m and emits a Maxmod MAS soundbank (.bin + .h) you link into a GBA ROM and play with mmStart(). No native binary, no devkitPro.
