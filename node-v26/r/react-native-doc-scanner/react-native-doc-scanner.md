# react-native-doc-scanner

> 标签: document-scanner, id-scanner, mrz, ocr, onnx, opencv, passport-scanner, react-native, vision-camera

## 简介

Real-time AI document scanner for React Native — VisionCamera + ONNX Runtime document detection, OpenCV quality analysis, and PaddleOCR (RapidOCR/ONNX) field extraction for passports, driving licences, and ID cards.
