# react-native-headless-calendar

> 标签: android, calendar, date-picker, date-range-picker, datepicker, expo, gregorian-calendar, headless-calendar, hijri-calendar, ios, jalali-calendar, multi-calendar, persian-calendar, react-native, react-native-calendar, swipeable, swipeable-calendar

## 简介

A fast, headless, calendar-system-agnostic (Gregorian, Hijri, Jalali, or your own) React Native calendar for building fully custom date pickers, range pickers, and multi-date calendars.
