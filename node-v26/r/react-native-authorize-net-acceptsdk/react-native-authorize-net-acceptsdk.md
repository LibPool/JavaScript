# react-native-authorize-net-acceptsdk

> 标签: acceptsdk, authorize.net, react-native

## 简介

`react-native-authorize-net-acceptsdk` is a package that allows you to: Fetch token by sending `card detail` to `AcceptSDK` for iOS and Android. You need to use this token to get the values of `DATA DESCRIPTOR` and `DATA VALUE` from the token.
