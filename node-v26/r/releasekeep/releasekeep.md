# releasekeep

> 标签: compliance, cra, cyber-resilience-act, cyclonedx, kev, sbom, security.txt, vulnerability

## 简介

Cyber Resilience Act (EU 2024/2847) records for installed and distributed software, regenerated on every release: scope verdict, CycloneDX SBOM, OSV and CISA KEV scan, document templates.
