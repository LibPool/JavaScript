# react-native-tv-audio-description

> 标签: a11y, accessibility, audio-description, fire-tv, mse, react-native, tv, vega

## 简介

Speak AI-generated audio description in the gaps between dialogue, on the TV itself: duck the film, play the cue, restore — driven from the remote, with three verbosity levels.
