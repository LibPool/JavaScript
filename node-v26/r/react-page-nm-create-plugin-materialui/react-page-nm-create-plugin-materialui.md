# react-page-nm-create-plugin-materialui

> 标签: JavaScript

## 简介

With `react-page-nm-create-plugin-materialui` its easy to create new plugins with custom properties. It uses [uniforms](https://uniforms.tools) to create the form based on a JSONSchema you provide and will show it in a bottomToolbar similar to the other
