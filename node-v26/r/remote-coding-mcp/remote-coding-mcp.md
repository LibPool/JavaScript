# remote-coding-mcp

> 标签: agentic-coding, ai-agent, ai-coding, claude, code-assistant, fastmcp, filesystem-mcp, gemini, gpt, llm-tools, mcp, model-context-protocol, ngrok, openai, remote-coding, remote-mcp

## 简介

A zero-config MCP server that lets any AI (Gemini, Claude, GPT) read and write code directly on your machine over the internet via ngrok or VS Code port forwarding.
