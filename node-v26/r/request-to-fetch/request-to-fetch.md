# request-to-fetch

> 标签: cli, codemod, deprecated, fetch, jscodeshift, migration, refactor, request, undici

## 简介

Codemod that rewrites the deprecated request package to native fetch. Converts callbacks to async/await, flags what it cannot safely convert instead of guessing.
