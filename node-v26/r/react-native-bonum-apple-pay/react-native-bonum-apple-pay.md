# react-native-bonum-apple-pay

> 标签: ios, react-native

## 简介

A React Native module by Bonum for adding cards to Apple Wallet. This package provides an easy-to-use interface for integrating Apple Wallet functionality into your React Native applications, allowing users to add payment cards directly to their Apple Wal
