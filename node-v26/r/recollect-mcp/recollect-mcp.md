# recollect-mcp

> 标签: ai-agents, claude, codex, cursor, fts5, gemini, mcp, memory, model-context-protocol, session-handoff, sqlite

## 简介

Local-first, cross-agent memory for AI coding agents (Claude, Codex, Gemini, Cursor, …) — one SQLite file, MCP over stdio or HTTP, FTS5 search, multi-machine sync.
