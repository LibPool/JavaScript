# react-file-viewer-ts

> 标签: JavaScript

## 简介

React File Viewer 是一个轻量级、高效的 TypeScript 组件，专为在 React 应用程序中预览常见文件格式而设计。支持 PDF、Excel、DOCX、CSV 和 TXT 等多种文件格式，提供简洁的 API 和响应式设计。
