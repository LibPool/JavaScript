# react-auto-thumbnail

> 标签: android, avassetimagegenerator, canvas, filmstrip, first-frame, frame-extraction, ios, mediametadataretriever, mp4, poster, react, react-native, scrubbing, thumbnail, upload, video, video-frame, video-preview, video-thumbnail, web

## 简介

Video thumbnails for React and React Native. Grab the first frame worth showing, or any time you name — '50%', '00:01:23', 2.5s, 2s before the end. Works on iOS, Android and web with no FFmpeg and no dependencies.
