# react-local-state-management-helper

> 标签: helper, react, reducer, state management

## 简介

`React Local State Management Helper` is a lightweight npm package for React that simplifies state management using the useReducer hook. It saves developers time by providing a convenient way to define reducers for multiple states without repetitive code.
