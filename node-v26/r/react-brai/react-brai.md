# react-brai

> 标签: hook, inference, llama, local-ai, mistral, phi, react, web-llm, webgpu

## 简介

The zero-latency fault tolerant WebGPU runtime for React. Run Llama-3, Phi-3, and Gemma directly in the browser with privacy-first local inference.
