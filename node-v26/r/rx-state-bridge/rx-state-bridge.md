# rx-state-bridge

> 标签: angular, hooks, loading, observable, operators, react, rxjs, signals, state, vue

## 简介

Framework-agnostic RxJS operators that bridge async streams with UI state primitives (React Hooks, Angular Signals, Vue Refs) — declarative loading, error and success feedback with zero boilerplate.
