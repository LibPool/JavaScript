# relaxcss

> 标签: css, css-variables, dark-mode, jit, plugin, postcss, rtl, tailwind, utility

## 简介

A Tailwind-like JIT CSS engine and PostCSS plugin with plugin system, variants, dark mode, RTL, and CSS variable support.
