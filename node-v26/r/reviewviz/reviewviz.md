# reviewviz

> 标签: agent-skill, claude, claude-code, openreview, peer-review, rebuttal, response-letter, review, visualization

## 简介

Visualize peer-review comments for a rebuttal: a self-contained, offline HTML page of the original reviews highlighted in place, colour-coded by action, grouped into priority-ordered rebuttal points each with an editable draft. Ships as a Claude Code skil
