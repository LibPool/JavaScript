# rpc-server-scf

> 标签: api-gateway, cloud-function, framework, rpc, scf, serverless, tencent, 云函数, 网关, 腾讯云

## 简介

A zero-config RPC server framework for Tencent Cloud Serverless (SCF). 为腾讯云云函数设计的、支持中间件机制的 RPC 服务端框架。
