# ravenbrightcss

> 标签: CSS, CSS components, CSS custom properties, CSS library, CSS utility classes, CSS variables, Figma tokens, UI components, atomic CSS, design system, design tokens, front-end, functional CSS

## 简介

Modern, zero-config & style agnostic CSS library with utility classes, reusable design tokens, minimal components & built-in dark mode to help you build static sites faster without hassle.
