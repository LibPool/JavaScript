# riposte

> 标签: API, ENVELOPE, LIVIO, MICRO, MICROSERVICE, REPLY, RESPONSE, RIPOSTE, SERVER, SERVICE

## 简介

Creates predictable API response objects by placing errors, warnings, and data in a well defined envelope.
