# romdev-platform-sync32

> 标签: JavaScript

## 简介

sync32 SDK tree for romdev: crt0, ram/xip linker scripts and sync32.h, so a Cortex-M33 .s32 cart builds from source with no sibling checkout. The ARM compiler itself is the WASM arm-none-eabi toolchain shipped in romdev-platform-gba.
