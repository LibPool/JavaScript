# react-native-place-autocomplete-picker

> 标签: android, ios, react-native

## 简介

A fully native, high-performance and easy to use Google Place Autocomplete picker for React Native. Built with the new architecture with Turbo Modules and the new Google Places SDK for maximum performance and a seamless native feel on both iOS and Android
