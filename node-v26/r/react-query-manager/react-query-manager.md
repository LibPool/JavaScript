# react-query-manager

> 标签: auto-cache, cache, cache-invalidation, cache-management, mutation, optimistic-update, query, query-management, react, react-query, react-query-helper, reactjs, rollback, tanstack, undo

## 简介

This is a library to simplify the work with @tanstack/react-query. It offers unified style for keys in the cache, ability to cancel a request. automatic cache refresh after mutation.
