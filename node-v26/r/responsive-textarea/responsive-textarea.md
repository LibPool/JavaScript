# responsive-textarea

> 标签: component, mobile, pc, react, responsive, scroll, textarea, typescript, vite

## 简介

A responsive textarea React component that has fixed height with internal scrolling on PC, and auto-adjusts height with page scrolling on mobile, built with Vite.
