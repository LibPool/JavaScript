# react-native-profile-sticky-tab

> 标签: flash-list, react-native, reanimated, sticky-header, tab-view

## 简介

A React Native library for creating sticky headers and collapsible profile sections with synchronized scroll across FlatList, FlashList, and ScrollView. Built with Reanimated.
