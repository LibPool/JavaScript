# react-smart

> 标签: JavaScript

## 简介

## 简介 一套纯JS实现的ReactNative快速开发组件库，无需任何原生工程代码，即可达到Android/iOS双平台一致的UI效果。 ### 使用 `yarn add react-smart`   或   `npm install react-smart --save`   ## 特性 - 路由   - Actions   - Router   - Scene - 浮动层   - Toast 轻提示   - Spin 页面加载   - SpinProgress 页面进度加载   - Dialog
