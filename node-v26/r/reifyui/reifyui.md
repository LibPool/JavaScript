# reifyui

> 标签: agent, agentic, ai, assistant, components, copilot, generative-ui, genui, llm, react, streaming, tool-calling

## 简介

The open-source rendering & interaction layer for agentic applications. Stream and render any agent's output as polished, application-native UI — model-agnostic, framework-agnostic, design-system-native. The foundation for building generative-UI and agent
