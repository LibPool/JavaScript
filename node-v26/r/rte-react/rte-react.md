# rte-react

> 标签: contenteditable, editor, html-editor, react, react-editor, rich-text-editor, rte, text-editor, tiptap, toolbar, typescript, wysiwyg

## 简介

A lightweight, fully-typed React rich text editor with a configurable toolbar. Outputs HTML. Works with React 17+.
