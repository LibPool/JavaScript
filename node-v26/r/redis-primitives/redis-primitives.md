# redis-primitives

> 标签: distributed-lock, distributed-systems, fencing-token, ioredis, leader-election, rate-limiter, redis, sliding-window

## 简介

Distributed lock with fencing tokens, sliding-window rate limiter, and leader election on a single Redis instance. Tests demonstrate the failure modes.
