# react-progress-uploader

> 标签: component, drag-drop, file-upload, progress, react, typescript, upload, uploader

## 简介

一个功能完整、类型安全的 React 文件上传组件库，支持拖拽上传、实时进度显示、文件类型限制、取消上传等特性。
