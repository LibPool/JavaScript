# react-abortable

> 标签: abort, abortcontroller, abortsignal, cancellation, hooks, react, server-actions, transition

## 简介

Unified AbortSignal cancellation for React hooks, transitions, and server actions. RFC-style addition designed to live alongside (or be merged into) react.
