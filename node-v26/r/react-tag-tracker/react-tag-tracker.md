# react-tag-tracker

> 标签: analytics, custom-events, dataLayer, events, google-tag-manager, gtm, react, react-hook, react-provider, tracking, typescript

## 简介

A React provider that simplifies tracking custom events and sends them to window.dataLayer, streamlining integration with GTM.
