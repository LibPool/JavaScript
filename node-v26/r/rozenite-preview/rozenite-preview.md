# rozenite-preview

> 标签: component-preview, debugging, developer-tools, devtools, hot-reload, live-preview, plugin, react-native, react-native-devtools, react-native-plugin, react-native-preview, rozenite, rozenite-plugin, ui-preview

## 简介

A Rozenite plugin that lets you select React Native components in DevTools and preview them live on your simulator. Ideal for rapid UI development, component testing, and debugging complex apps.
