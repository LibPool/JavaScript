# react-next-editor-js

> 标签: docx, editor, nextjs, offline-first, pdf, prosemirror, react, rich-text, word-processor, wysiwyg

## 简介

A comprehensive, performant, secure, configurable and pluggable Word-style rich document editor for React/Next.js, built directly on ProseMirror, with DOCX/PDF/text export and offline-first persistence.
