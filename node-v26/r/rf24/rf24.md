# rf24

> 标签: arduino, nrf24l01, raspi, transceiver, wireless

## 简介

Well-behaved async wrapper around C++ RF24 library. Control nRF24L01+ wireless radio communications from a server with SPI/GPIO ports (e.g. Raspberry Pi)
