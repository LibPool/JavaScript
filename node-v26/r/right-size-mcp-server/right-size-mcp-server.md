# right-size-mcp-server

> 标签: aws, cloudwatch, ecs, elasticache, mcp, pricing, rds, right-sizing

## 简介

MCP server for AWS right-sizing: resolve resources by tag, fetch CloudWatch metrics, and estimate pricing for ECS, RDS, and ElastiCache.
