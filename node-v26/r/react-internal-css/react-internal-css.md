# react-internal-css

> 标签: constructable stylesheets, dynamic loading, head, internal css, lazy loading, react, react-helmet, server rendering, ssg, ssr, style

## 简介

Include internal stylesheets in React component instead of extracting into separate files. Provides drop-in server rendering support.
