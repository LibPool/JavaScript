# reelo-mcp

> 标签: claude, codex, flow, mcp, montage, reels, video

## 简介

Reelo — монтажёр рилсов для твоего агента. MCP-сервер: сервис режет, придумывает раскадровку и рисует сториборды, части рендерит Google Flow на твоём аккаунте.
