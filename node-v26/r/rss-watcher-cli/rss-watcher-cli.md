# rss-watcher-cli

> 标签: JavaScript

## 简介

A fast, TypeScript-native RSS/JSON feed reader with a built-in [MCP](https://modelcontextprotocol.io/) server. Built on [Bun](https://bun.sh/) and SQLite.
