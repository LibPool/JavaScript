# react-native-credify-plugin

> 标签: android, ios, react-native

## 简介

Plugin for RN applications that utilizes Credify Collection SDK to collect data from device, supports only android platform.

## 官网

- 官网：https://docs.credify.live/docs/credit-scoring/sdk/react-native
- npm 页面：https://www.npmjs.com/package/react-native-credify-plugin
