# react-native-safe-async-storage-af

> 标签: JavaScript

## 简介

Wrapper around AsyncStorage that writes large values to the filesystem using [react-native-fs](https://github.com/johanneslumpe/react-native-fs). This is to avoid the dread "android java.lang.IllegalStateException: Couldn't read row 0, col 0 from CursorWi
