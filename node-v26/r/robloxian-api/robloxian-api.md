# robloxian-api

> 标签: gamepass, noblox, roblox, roblox-api, robloxian-api, roproxy

## 简介

An advanced, modern, lightweight, and structured Roblox API wrapper for Node.js. Optimized for bots and web apps with failover proxies, rate-limit retries, and full TypeScript typings.
