# range-source-web

> 标签: byte-range, byte-source, cache, cache-api, http-range, indexeddb, media-cache, offline, opfs, partial-content, range-requests, range-source, storage, streaming, video, video-cache, video-streaming

## 简介

Range source and storage manager for video and other partial content on the web: reads files by offset through HTTP range requests, Blobs or your own source, and keeps what was read in OPFS, IndexedDB, the Cache API or memory under one size cap.
