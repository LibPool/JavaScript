# repocontext-tool

> 标签: agent, ai, cli, code-search, context, mcp, tokens, tree-sitter, typescript

## 简介

Local-first, explainable project memory for AI coding agents. Installs the repoctx CLI — offline, deterministic, no telemetry, no LLM or embedding calls.
