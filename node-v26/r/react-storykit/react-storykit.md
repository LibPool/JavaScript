# react-storykit

> 标签: instagram-stories, react, status, status-ring, stickers, stories, story, storykit, tailwind, typescript, viewer

## 简介

Modern headless & styled stories status component kit for React. Segmented status rings, interactive Instagram stickers, smooth dual-buffer transitions, and gestures.
