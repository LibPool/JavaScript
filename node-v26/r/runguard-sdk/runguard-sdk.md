# runguard-sdk

> 标签: browser, cloudflare-workers, error-reporting, error-tracking, nodejs, observability, production-monitoring, runguard, runtime-errors, typescript

## 简介

RunGuard SDK – capture runtime errors in Node, Cloudflare Workers, and the browser, and send them to RunGuard.
