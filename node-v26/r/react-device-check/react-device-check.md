## 简介

Lightweight, accurate React hooks for device detection in any React app, CSR or SSR. Detect device type (mobile/tablet/desktop) and OS (iOS/Android/Windows/macOS/Linux) with zero dependencies. SSR-safe in Next.js, handles iPad-as-Mac masquerading, Samsung
