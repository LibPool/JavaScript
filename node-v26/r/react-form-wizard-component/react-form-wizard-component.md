# react-form-wizard-component

> 标签: a11y, accessible, app-router, checkout, form, form-builder, form-validation, form-wizard, guided-form, headless, multi-step, multi-step-form, nextjs, onboarding, react, react-component, react-form, react-hook-form, react17, react18, react19, step-by-step, step-form, stepper, typescript, wizard, wizard-component, wizard-form, zod

## 简介

Accessible multi-step form wizard for React 17, 18 and 19. Zero dependencies, TypeScript-first, modern styling with automatic dark mode, styled or headless, with per-step validation for Zod and react-hook-form.
