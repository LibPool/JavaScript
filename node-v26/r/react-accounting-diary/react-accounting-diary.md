# react-accounting-diary

> 标签: accounting, accounting-software, bookkeeping, component, csv, dark-mode, diary, double-entry, excel, export, finance, financial, headless, hook, i18n, journal, jpeg, json, ledger, ledger-view, pdf, png, react, react-component, typescript, validation

## 简介

Lightweight React component for accounting diaries with export to PNG, JPEG, PDF, CSV, Excel, JSON. Features headless hook, ref API, ledger view, validation callbacks, i18n, dark mode, search, edit transactions.
