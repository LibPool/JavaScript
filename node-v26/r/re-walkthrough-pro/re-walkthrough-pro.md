# re-walkthrough-pro

> 标签: ai-video, apify, claude, claude-code, ffmpeg, higgsfield, listing-video, property-video, real-estate, real-estate-marketing, seedance, skill, walkthrough, zillow

## 简介

Claude Code skill that turns a Zillow listing into a cinematic, room-by-room property walkthrough video — Apify scrapes the photos, Higgsfield animates each room, ffmpeg stitches the final cut. Built to sell to real estate agents.
