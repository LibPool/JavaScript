# remark-kroki-a11y

> 标签: a11y, accessibility, accessibility-testing, c4, diagram-as-code, diagrams, diagrams-as-code, docusaurus, graphviz, kroki, mermaid, plantuml, remark, remark-plugin, uml, uml-diagram

## 简介

Remark plugin for Docusaurus that adds accessible source code details and natural language descriptions to Kroki diagrams (PlantUML, Mermaid, C4, GraphViz, etc.)
