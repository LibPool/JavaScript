# rn-bundle-swapper

> 标签: android, apk, apksigner, bundle, ci, codesign, hermes, hotswap, ios, ipa, jsbundle, metro, patch, react-native, swap, zipalign

## 简介

Cross-platform utility for swapping or updating the JavaScript bundle inside existing React Native Android APKs and iOS .app/.ipa files.
