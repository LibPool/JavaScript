# remote-fileshare

> 标签: ai-agent, claude-code, codex, file-server, file-sharing, file-transfer, npx, remote, screenshot, self-hosted, ssh, upload, uvx, zero-dependency

## 简介

Send screenshots and files from your browser to Claude Code, Codex CLI and other AI agents running on a remote Linux server, and download what they produce. One command, password, HTTPS, zero dependencies. 远程文件共享：在远程 Linux 机器上用 Claude Code、Codex CLI 写代码时，
