# react-dom-transfer

> 标签: animation, dom, fiber, flip, move, no-unmount, player, preserve-state, react, reparent, stateNode, transfer, transition, video

## 简介

Move DOM elements between containers without unmounting React components. Preserves video playback, iframe state, and all DOM state during transfer with optional FLIP animations.
