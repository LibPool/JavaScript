> 标签: ci-cd, continuous-delivery, e2e-testing, github-actions, gitlab-ci, go-no-go, kadeep, kadeep-studios, localization, qa, quality-gate, releasegate, test-automation

## 简介

KaDeep Release Gate for CI/CD: runs the KaDeep Studios checks your policy requires for every commit and returns a go / no-go, not a test report. Works with GitHub Actions, GitLab CI, CircleCI and more.
