# rom-weaver

> 标签: bps, chd, cli, ips, patch, rom, rom-hack, rvz, z3ds

## 简介

Convenience alias for @rom-weaver/cli, the canonical package. Installs the CLI under the unscoped name so `npx rom-weaver` works.
