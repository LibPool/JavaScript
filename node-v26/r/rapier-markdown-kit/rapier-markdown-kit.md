# rapier-markdown-kit

> 标签: ai-agents, authorship, commonmark, css, document, gfm, images, line-breaking, markdown, merge, rapier, renderer, self-contained, stylesheet, svg, text-layout, will

## 简介

Read, render and write Self-contained Markdown: one .md file that carries its pictures, drawings and layout, and that any Markdown app can read. HTML renderer, stylesheet, text layout, Will/1 agent permissions, and an edit history with authorship and offl
