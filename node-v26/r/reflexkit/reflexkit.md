# reflexkit

> 标签: agent-runtime, coding-agent, loop-detection, opencode, opencode-plugin, reflex, system1

## 简介

Fast reflex layer (System 1) for coding agents. OpenCode plugin: stuck detection, progress scoring, tool risk policies, completion and context relevance — deterministic first, no LLM in the loop.
