# react-native-animated-codes

> 标签: animated-barcode, animated-codes, animated-qr, animated-qrcode, aztec, barcode, barcode-generator, bwip-js, code128, code39, customizable, datamatrix, ean13, gradient, gs1, logo, maxicode, pdf417, qr, qr-code, qr-generator, qrcode, react-native, reanimated, svg, upc

## 简介

Fully customizable animated QR codes and barcodes (100+ formats: EAN, UPC, Code 128, Code 39, ITF, Data Matrix, PDF417, Aztec, MaxiCode, postal...) for React Native (Android & iOS), built on react-native-svg and react-native-reanimated.
