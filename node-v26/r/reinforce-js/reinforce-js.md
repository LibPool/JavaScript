> 标签: agent, ai, artificial intelligence, artificial neural network, bellman, deep learning, deep-q-network, deepmind, deterministic policy gradients, dqn, dynamic programming, neural network, q-learning, recurrent, reinforce, reinforcement, reinforcement learning, sarsa, solver, temporal difference

## 简介

A collection of various reinforcement learning solver. The library is an object-oriented approach (baked with Typescript) and tries to deliver simplified interfaces that make using the algorithms pretty simple.
