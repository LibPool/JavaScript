# reactant-analyzer

> 标签: abstract-interpretation, hooks, linter, react, static-analysis

## 简介

Static analyzer for React hook bugs (infinite loops, missing deps, derived state, …) based on abstract interpretation. WASM build — identical behavior in Node and in the browser.
