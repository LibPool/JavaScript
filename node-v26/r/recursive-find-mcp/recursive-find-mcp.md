# recursive-find-mcp

> 标签: agent, cli, crawler, find, mcp, mcp-server, model-context-protocol, search, skill, website-search

## 简介

Ctrl+F for whole websites, for agents: search a page and every page it links to, get back only the matching pages with snippets. MCP server, CLI (rfind) and agent skill.
