# react-webcam-pro

> 标签: android, camera, getUserMedia, ios, mobile, react, react-camera, react-camera-pro, react-webcam, react19, typescript, webRTC, webcam

## 简介

Universal camera component for React — supports React 16-19, videoConstraints, mirror photo capture, TypeScript, and iOS/Android/webcam. Community-maintained fork of react-camera-pro.
