# remark-mdx-mermaid

> 标签: diagram, flowchart, graph, markdown, mdx, mermaid, remark, remark-mdx-mermaid, remark-plugin, svg, unified

## 简介

A remark plugin for MDX that converts mermaid code blocks into <Mermaid> React components and renders them using a useMermaid hook.
