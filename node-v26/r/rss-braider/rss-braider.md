# rss-braider

> 标签: aggregator, atom, blogs, braider, combiner, distribution, feed, feed builder, feeds, json, podcasts, rss, syndicate, syndication, wordpress, xml

## 简介

Braid/aggregate/combine RSS feeds into a single RSS (or JSON) document. Optionally process through specified plugins.
