# rfb-sdk

> 标签: firecracker, forkd, rfb, sandbox

## 简介

RFB Node.js/TypeScript SDK: unified RfbClient facade over the forkd controller (HTTP/JSON) and the forkd guest (TCP NDJSON + ZBRT v1 binary frames) — mirror port of the Rust reference implementation
