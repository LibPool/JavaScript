# rpgjs-inventory

> 标签: JavaScript

## 简介

It's a plugin of [RPG JS](https://rpgjs.dev/) engine that gives possibility to manage inventory.\ Example implementation: [inventory](https://github.com/dominx99/rpgjs-plugins/blob/master/examples/inventory)
