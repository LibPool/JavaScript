# react-native-motion-lightbox

> 标签: android, carousel, expo, gallery, gesture-handler, image-gallery, image-viewer, ios, lightbox, photo-gallery, pinch-zoom, react-native, react-native-component, react-native-lightbox, reanimated, swipe, thumbnails, typescript, zoom

## 简介

A React Native lightbox and image gallery that opens out of the photo you tap and closes back into it: swipe, pinch zoom, swipe down to close, thumbnails, video. Reanimated and Gesture Handler, works with Expo.
