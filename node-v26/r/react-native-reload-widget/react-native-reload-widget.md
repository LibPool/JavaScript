# react-native-reload-widget

> 标签: android-widget, app-extension, appwidget, ios-widget, native-module, react-native, react-native-module, refresh, reload, turbo-module, typescript, widget, widgetkit, widgets

## 简介

react-native-reload-widget is a lightweight and efficient React Native module that reloads your app's home screen widgets on demand, on iOS and Android.
