# rn-upgrade-doctor

> 标签: 16kb, android, cli, doctor, new-architecture, react-native, upgrade

## 简介

One command to see what breaks when you upgrade a React Native app: dependencies, New Architecture, Android/iOS config and 16 KB page-size checks.
