# react-storage-utils

> 标签: JavaScript

## 简介

Thư viện lưu trữ dữ liệu cho React/SPFx sử dụng **IndexedDB** (idb v5) và **AES encryption**. Hỗ trợ lưu trữ objects, single files, hoặc arrays of files. Tương thích với **React 16+** và **SharePoint Framework (SPFx)**.
