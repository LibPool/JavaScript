# react-native-firebase-local-cache

> 标签: Android, AsyncStorage, React Native, cache, data store, firebase, iOS, key value store

## 简介

Speed up the apparent load time of screens in your app by caching content. Wraps the Firebase 'on' and 'once' methods to make caching easy!
