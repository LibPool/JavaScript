# rn-responsive-typography

> 标签: android, cross-platform, design-system, expo, font, font-size, ios, line-height, mobile-typography, react-native, responsive, responsive-design, text, text-scaling, typography, ui

## 简介

rn-responsive-typography is a lightweight React Native utility library that standardizes font sizes and line heights across your app for consistent typography. Easily define and reuse scalable text styles to maintain visual harmony and improve readability
