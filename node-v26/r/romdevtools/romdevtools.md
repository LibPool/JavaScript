# romdevtools

> 标签: agent, atari, cheats, claude, commodore-64, emulator, game-boy, genesis, homebrew, libretro, mcp, model-context-protocol, msx, nes, pc-engine, retro, reverse-engineering, romhacking, snes, wasm

## 简介

Tool server giving coding agents full control of homebrew ROM development AND reverse-engineering/romhacking across 18 retro platforms (NES, SNES, GB, Genesis, Atari, C64, PC Engine, MSX, GameTank, sync32, PlayStation, N64, Dreamcast, ...) via WASM toolch
