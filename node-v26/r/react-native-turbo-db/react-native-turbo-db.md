# react-native-turbo-db

> 标签: asyncstorage-alternative, embedded-database, encrypted-storage, jsi-storage, key-value-store, mmkv-alternative, offline-database, react-native, react-native-database, react-native-jsi, react-native-storage, relational-database, sql-query-engine

## 简介

react-native-turbo-db is a high-performance JSI database and AsyncStorage alternative for React Native, featuring a full SQL query engine, encrypted storage, WAL persistence, B+tree indexing and offline-first local database support.
