# relaybell-mcp

> 标签: claude, cursor, mcp, model-context-protocol, push-notifications, relaybell, web-push

## 简介

MCP server for relaybell: let AI assistants (Claude, Cursor, VS Code, Windsurf) read your web push stats and audience, and send notifications with a confirm step.

## 官网

- 官网：https://relaybell.com/docs/ai-assistants
- npm 页面：https://www.npmjs.com/package/relaybell-mcp
