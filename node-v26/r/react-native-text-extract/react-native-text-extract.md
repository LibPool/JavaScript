# react-native-text-extract

> 标签: document-parsing, docx, expo, ocr, pdf, react-native, text-extraction

## 简介

Extract text from PDF, DOCX, XLSX, CSV, TXT, and more in React Native/Expo apps. Zero-dependency on-device extraction for simple formats, automatic API fallback for PDF and complex documents.
