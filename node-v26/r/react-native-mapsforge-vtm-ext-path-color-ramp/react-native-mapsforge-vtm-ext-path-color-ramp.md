# react-native-mapsforge-vtm-ext-path-color-ramp

> 标签: android, color-ramp, maps, mapsforge, opengl, path, react-native, shader, slope, thematic, vtm

## 简介

Per-segment color-ramp path rendering extension for react-native-mapsforge-vtm. Renders paths with colors mapped from data values (slope, elevation, speed, etc.) via a 1D color-ramp texture in the OpenGL fragment shader. Android only.
