# retry-simulator

> 标签: api, backoff, developer-tools, frontend, mock-network, network, retry, simulation, testing, typescript

## 简介

A lightweight TypeScript utility for retrying async functions with configurable backoff strategies like fixed, linear,and exponential retries.
