# rig-parts

> 标签: ai, ai-agents, anime, character-parts, character-rigging, cli, layer-decomposition, live2d-alternative, psd, rigging, see-through, skeletal-animation, spine, spine-2d, spine2d, weighted-mesh

## 简介

AI-authored 2D character parts from one anime painting and its See-through layer decomposition: measured parts, weighted-mesh rig specs, verified through rig-c before anything is written. A CLI for agents that cannot see the image.
