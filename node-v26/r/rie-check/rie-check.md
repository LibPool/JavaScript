# rie-check

> 标签: circular-dependencies, github-action, import-cycles, mcp, typescript

## 简介

Fail a pull request that makes TypeScript runtime import cycles worse than its base branch, with the import line behind every loop. Also an MCP server that gives coding agents the import graph.
