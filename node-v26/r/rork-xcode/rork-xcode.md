# rork-xcode

> 标签: apple, builder, parser, pbxproj, property-list, xcode, xcodeproj, zero-dependency

## 简介

Zero-dependency Xcode project (pbxproj) and scheme (xcscheme) parser, builder, and object model that runs identically in every JavaScript runtime
