# react-hot-keys

> 标签: hotkey, hotkeys, hotkeys-js, hotkeysjs, key, keyboard, keypress, keys, react-hot-keys, react-hotkey, shortcuts

## 简介

React component to listen to keydown and keyup keyboard events, defining and  dispatching keyboard shortcuts.
