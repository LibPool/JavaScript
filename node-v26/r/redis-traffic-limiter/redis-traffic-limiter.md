# redis-traffic-limiter

> 标签: backend, fixed-window, limiter, nodejs, rate-limiter, redis, sliding-window, traffic

## 简介

A lightweight Redis-based rate limiter for Node.js supporting Fixed Window and Sliding Window algorithms.
