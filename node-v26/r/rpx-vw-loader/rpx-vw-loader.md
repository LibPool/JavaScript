# rpx-vw-loader

> 标签: rpx, rpx转vw, vw

## 简介

把css文件中的rpx转为vw；使用场景：小程序中的css文件，放到H5移动端；获取移动端自适应开发，省去手动计算vw值；webpack自动计算出vw
