# recapfy-mcp

> 标签: mcp, model-context-protocol, recapfy, solana, x402, youtube

## 简介

MCP server that exposes Recapfy's x402 endpoints (ask about a YouTube video, get its transcript) as tools. Each user runs it locally with their own Solana wallet and pays per call.
