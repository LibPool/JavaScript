# ryurew-svelte-adapter-firebase

> 标签: cloud-functions, cloud-run, firebase, serverless, ssr, svelte, sveltekit, sveltekit-adapter

## 简介

Adapter for Svelte apps that integrates a Firebase Hosting Website with Cloud Functions or Cloud Run for server side rendering.
