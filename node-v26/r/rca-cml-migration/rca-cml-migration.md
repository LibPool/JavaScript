# rca-cml-migration

> 标签: constraint-model-language, force, revenue-cloud, salesforce, salesforcedx, sf, sf-plugin, sfdx, sfdx-plugin

## 简介

Salesforce CLI plugin for safely exporting, importing, and migrating Revenue Cloud Constraint Model Language (CML) models between orgs, with dry-run validation and explicit write safeguards.
