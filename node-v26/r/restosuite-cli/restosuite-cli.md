# restosuite-cli

> 标签: agent, bo-agent, cli, mcp, oauth, restosuite

## 简介

RestoSuite CLI — 通过 OAuth(PKCE) 浏览器登录，用命令行 / MCP 访问 RestoSuite 商户中心的智能体能力（login / ask / mcp 等）。

## 官网

- 官网：https://www.restosuite.io
- npm 页面：https://www.npmjs.com/package/restosuite-cli
