# realtimeclipboard

> 标签: cli, clipboard, clipboard-sync, end-to-end-encrypted, online-clipboard, pipe, share-text, ssh

## 简介

Live clipboard sharing. Static frontend of native ES modules — development needs no build, and `npm run build` exists only to assemble the deploy. Nothing here is needed to READ the app.
