# reloop-role-intel-mcp

> 标签: ai-agents, capability-intelligence, career, hiring, job-ads, job-description, job-search, mcp, model-context-protocol, pay-transparency, reloop, skills-based-hiring

## 简介

MCP server for the ReLoop.me Role Intel API: capability intelligence for job ads. Free quick check of any job ad in ~10 s (no key), plus full reads of true seniority, capability mix, operating style and requirement inflation. Reads roles, never people.
