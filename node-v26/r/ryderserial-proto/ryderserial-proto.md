# ryderserial-proto

> 标签: JavaScript

## 简介

RyderSerial is a library to facilitate communications between an application and Ryder device. It is written in JavaScript. It is built in an async/await pattern and makes extensive use of Promises. It does not currently feature command-specific methods,
