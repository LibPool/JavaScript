# ranui

> 标签: component, component-library, components, custom-element, custom-elements, design, framework-agnostic, pwa, ran, ranui, shadow-dom, ssr, typescript, ui, ui-library, web components, web-components

## 简介

A framework-agnostic Web Components UI library built on native custom elements, with TypeScript types, light/dark theming, SSR and PWA support.
