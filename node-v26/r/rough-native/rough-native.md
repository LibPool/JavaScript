# rough-native

> 标签: canvas, concurrent-rendering, graphics, hand drawn, hand-drawn, memory-management, performance, react-18, react-hooks, react-native, react-native-canvas, react-native-svg, sketchy, svg

## 简介

Create graphics using HTML Canvas or SVG with a hand-drawn, sketchy, appearance. Features comprehensive React hooks, memory management, and React 18 concurrent rendering support.
