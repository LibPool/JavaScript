> 标签: agent-skills, ai数聚, claude-code, clinical-trial, ctms, data-processing, edc, mcp, rdmp, skill, skills, zcode

## 简介

RDMP-AI数聚 数据处理 Skill：对已获取的 RDMP 数据做本地处理，覆盖数据理解、质量检查、基础分析、规范输出。只处理用户提供或 MCP 已返回的数据，不连接 RDMP、不发起查询。
