# react-native-agent-jet

> 标签: agent, automation, claude-code, cursor, expo, ios-simulator, mcp, react-native, testing

## 简介

Lets coding agents see and drive your running React Native / Expo app: semantic element tree, presses, typing, navigation, state, logs and network over MCP, with zero production footprint.
