# react-mongol

> 标签: cyrillic, fvs, i18n, mongol-bichig, mongolian, mvs, react, traditional-mongolian, transliteration, unicode, vertical-text, writing-mode

## 简介

Show Cyrillic Mongolian websites in traditional script (Mongol bichig) with one toggle; React primitives for vertical layout, mixed-script orientation and Unicode-correct text.
