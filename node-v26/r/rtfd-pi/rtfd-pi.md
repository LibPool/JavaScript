# rtfd-pi

> 标签: documentation, extension, mcp, pi, pi-package, rtfd

## 简介

Native pi extension that fetches real-time docs from PyPI, npm, crates.io, GoDocs, DockerHub, GitHub, GCP, Zig, and LogScale.
