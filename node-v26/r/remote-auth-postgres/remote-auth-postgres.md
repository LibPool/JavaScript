# remote-auth-postgres

> 标签: JavaScript

## 简介

Armazene sessões do WhatsApp Web no PostgreSQL usando `RemoteAuth` com suporte à biblioteca [`whatsapp-web.js`](https://github.com/pedroslopez/whatsapp-web.js).
