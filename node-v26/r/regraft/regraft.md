# regraft

> 标签: boilerplate, cherry-pick, cli, devex, drift, git, github-template, monorepo-alternative, scaffolding, template, template-sync, upstream

## 简介

Keep repositories created from a GitHub template up to date with it. Cherry-picks the template's new commits onto repos that share no common ancestor with it.
