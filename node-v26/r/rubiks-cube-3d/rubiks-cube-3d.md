# rubiks-cube-3d

> 标签: 3d, cube, interactive, matter-js, physics, react, rubiks, three, threejs

## 简介

A realistic, physics-driven, interactive 3D Rubik's cube built with three.js and Matter.js. Ships as a React component and as a standalone script for any website.
