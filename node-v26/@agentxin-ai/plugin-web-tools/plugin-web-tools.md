# @agentxin-ai/plugin-web-tools

> 标签: JavaScript

## 简介

`@agentxin-ai/plugin-web-tools` adds web fetching and internet search capabilities to [AgentXin AI](https://github.com/agentxin-ai/agentxin) agents. The middleware provides two LangChain tools — `web_fetch` for retrieving web page content and `web_search`
