# @bitspark/ontos-data-json

> 标签: JavaScript

## 简介

ontos-data-json/1 — the named, total projection of a domain-JSON document to an ontos/data value. TypeScript peer of data/json/go. Depends on @bitspark/ontos-core and @bitspark/ontos-data.
