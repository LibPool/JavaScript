# @bitspark/ontos-data

> 标签: JavaScript

## 简介

ontos/data (L2) canonical embeddings (ontos-data-v1: int, utf8-text, bool, list, map, set, decimal, null). Depends on @bitspark/ontos-core and @bitspark/ontos-codec.
