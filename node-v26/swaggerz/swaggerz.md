# swaggerz

> 标签: api-client, axios, codegen, fetch, openapi, react-query, swagger, tanstack-query, tree-shaking, typescript

## 简介

Generate fully typed, documented, tree-shakeable API clients from Swagger 2.0 and OpenAPI 3.0/3.1/3.2 specifications.
