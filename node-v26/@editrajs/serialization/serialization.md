# @editrajs/serialization

> 标签: JavaScript

## 简介

Schema-aware HTML and Markdown conversion for Editra. Use `@editrajs/serialization/browser` in browsers and `@editrajs/serialization/node` on Node. Node consumers install the optional `jsdom@27.4.0` peer; conversion owns a jsdom instance and requires call
