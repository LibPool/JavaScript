# @gengwg/agentlens

> 标签: agent, claude-code, cursor, llm, observability, opencode, tracing

## 简介

Local observability for coding-agent harnesses: fleet view and trace viewer for Claude Code, OpenCode, dsh, Cursor Agent, Antigravity, TrueForge and more.
