# @rtq/mobile

> 标签: approval, approval-host, mobile, pairing, request-approval, rtq, runtime, security

## 简介

RTQ mobile approval host transport: pairing + rtq-approval-v1 approval service and HTTP endpoints. Transport is untrusted; all security is in the signed protocol.
