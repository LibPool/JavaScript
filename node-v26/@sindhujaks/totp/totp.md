# @sindhujaks/totp

> 标签: 2fa, authentication, hotp, mfa, rfc4226, rfc6238, totp, two-factor

## 简介

Zero-dependency TypeScript implementation of TOTP/HOTP two-factor authentication (RFC 6238 / RFC 4226), verified against the official test vectors.
