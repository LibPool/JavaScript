# cooldown-check

> 标签: bun, ci, cooldown, dependency age, dependency cooldown, exclude-newer, lockfile, malware, min-release-age, minimumReleaseAge, npm, npmMinimalAgeGate, package age, pnpm, pypi, python, security, supply chain, supply-chain-security, yarn

## 简介

Fail CI when npm or PyPI dependencies are younger than your supply-chain cooldown (npm min-release-age, pnpm minimumReleaseAge, Yarn npmMinimalAgeGate, Bun minimumReleaseAge, uv exclude-newer). Checks package.json + lockfiles, requirements.txt and pyproje
