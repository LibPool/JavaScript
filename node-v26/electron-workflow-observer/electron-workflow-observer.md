# electron-workflow-observer

> 标签: cdp, e2e-testing, electron, event-loop, freeze-detector, ipc, memory-leak, performance, playwright, profiling, stall-detection

## 简介

App-neutral, privacy-preserving performance profiling and workflow observation for Electron (IPC latency, event-loop stalls, memory sampling, and Playwright fixture).
