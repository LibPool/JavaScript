# @camstack/addon-smtp-nodemailer

> 标签: addon, camstack, camstack-addon, email, nodemailer, smtp

## 简介

SMTP email provider addon for CamStack — wraps `nodemailer` and registers a `smtp-provider` cap collection entry. Used by magic-link login + notifier addons.
