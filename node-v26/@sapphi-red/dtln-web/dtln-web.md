# @sapphi-red/dtln-web

> 标签: JavaScript

## 简介

Use [DTLN real time speech denoising model](https://github.com/breizhn/DTLN) and [DTLN-aec model for real-time acoustic echo cancellation](https://github.com/breizhn/DTLN-aec) in web.
