# deputy-mcp

> 标签: agent, browser, chrome-extension, claude-code, codex, cursor, mcp, webmcp

## 简介

Deputy's MCP bridge: Claude Code, Codex, Cursor and any MCP client use the pages in your browser as typed tools. Needs the Deputy Chrome extension; free to start, Deputy Pro adds 17 tools and hosted models.
