# @amritk/lynx-secure-storage

> 标签: encrypted-shared-preferences, keychain, keystore, lynx, mjst, native-module, secure-storage, token, typescript

## 简介

Encrypted key-value storage for Lynx: Keychain on iOS, EncryptedSharedPreferences on Android, and a promise-shaped facade that reaches them from the main thread.
