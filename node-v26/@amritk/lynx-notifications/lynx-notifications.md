# @amritk/lynx-notifications

> 标签: apns, fcm, lynx, mjst, native-module, notifications, push-notifications, typescript

## 简介

Local and remote push notifications for Lynx: an Android and iOS native module, and a promise-shaped facade that reaches it from the main thread.
