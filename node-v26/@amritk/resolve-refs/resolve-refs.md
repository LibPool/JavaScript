# @amritk/resolve-refs

> 标签: $ref, dereference, json-schema, mjst, openapi, ref, resolver, typescript

## 简介

Resolve and inline JSON Schema / OpenAPI $refs — internal, cross-file, and remote — with session caching and a default-deny SSRF guard.
