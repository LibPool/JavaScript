# @visiq/openclaw-plugin

> 标签: action-governance, agent-governance, ai-governance, audit-trail, openclaw, plugin, retrieval-governance, visiq

## 简介

VisIQ agent-governance plugin for the OpenClaw CLI — action governance on every tool call, retrieval governance on its configured retrieval tools, and audit-trail reporting, wired into OpenClaw's own tool hooks.
