# @tarekeldeeb/quran-madina-react-native

> 标签: arabic, madina, mushaf, quran, quran-madina-html, react-native, webview

## 简介

React Native component for quran-madina-html: Quran pages that look like the printed Madina Mushaf, as real text, in a WebView on iOS and Android. Works offline.
