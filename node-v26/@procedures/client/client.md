# @procedures/client

> 标签: client, dsl, http, json-rpc, mcp, middleware, procedures, rpc, server, streaming, type-safe, typescript, websocket, workflow, zod

## 简介

Procedures as data for TypeScript: define typed procedures once and call them in process, over HTTP, WebSocket, the CLI or MCP. Streaming, middleware, retries, caching and a JSON program format.
