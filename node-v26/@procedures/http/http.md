# @procedures/http

> 标签: allowlist, fetch, http, ndjson, procedures, server-sent-events, sse, ssrf

## 简介

HTTP as procedures: request, JSON, NDJSON and server-sent events, with a host allowlist that refuses private addresses, size limits and the deadline of the call.
