# @procedures/git

> 标签: automation, git, procedures, rpc, version-control

## 简介

Git as 45 typed procedures: status, diff, log, show, blame, commit, push, pull, branch, tag, merge, rebase, worktree, stash and more, run with argv, async and abortable.
