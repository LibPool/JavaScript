# @procedures/mcp-server

> 标签: ai-tools, claude, mcp, mcp-server, model-context-protocol, procedures, tools

## 简介

Model Context Protocol server transport: serve typed procedures as MCP tools to Claude and other MCP clients, with streaming progress, list_changed and an expose policy.
