# @sarthakpranesh/mcp-lazy-proxy

> 标签: JavaScript

## 简介

Lazy MCP proxy: exposes get_mcp_tools / call_mcp_tool meta-tools that load backend MCP servers on demand, so only two tool schemas are injected into the model context.
