# @xanui/core

> 标签: animation, breakpoints, color-scale, css-in-js, css-props, design-system, oncss, portal, react, react-hooks, responsive, ssr, styling, tag, theme, theming, transitions, typescript, ui, ui-primitives

## 简介

A styling-engine-agnostic UI primitive layer for React — write CSS as props with a single <Tag> component, theme with color-scale generation, and ship SSR-safe styles out of the box.
