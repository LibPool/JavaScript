# @puralex/ai-doc-system

> 标签: agent-skills, ai-agents, claude, docs, docs-as-code, documentation, frontmatter, gate, lint

## 简介

Tier a repository's docs by authority, validate frontmatter, generate an agent-readable index, and enforce it with a blocking gate.
