# @pipeworx/mcp-nl-rechtspraak

> 标签: mcp, mcp-server, model-context-protocol, nl-rechtspraak, pipeworx

## 简介

Netherlands court decisions (uitspraken en conclusies) — search by court, legal domain and date, resolve by ECLI, read the full original Dutch text. Separate from @pipeworx/nl-wetten (statutes) — this pack is case law.
