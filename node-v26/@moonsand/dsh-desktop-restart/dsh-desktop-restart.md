# @moonsand/dsh-desktop-restart

> 标签: deepseek-harness, dsh, dsh-plugin, electron, reload, restart

## 简介

Sidebar-foot Reload UI and Restart App buttons: reload refreshes the interface and client plugins only, restart relaunches the DeepSeek Harness desktop app together with its Host.
