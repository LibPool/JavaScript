# @sgrsoft/vpe-core-sdk

> 标签: JavaScript

## 简介

VPE Player를 초기화하고 설정을 검증하는 Core SDK입니다. Access Key 검증, 서버 옵션 동기화, MA 리포트 동기화, 다국어 메시지, 옵션 정규화를 제공합니다.
