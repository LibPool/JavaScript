# @better-compute/driver-sdk

> 标签: bare-metal, better-compute, driver, grpc, mtls, out-of-process, plugin, sdk

## 简介

bcx, the better-compute out-of-process driver protocol: serveDriver runs a defineDriver object as a plugin, externalDriver hosts one over auto-mTLS gRPC.
