# cortico-world-soft-voice

> 标签: coopanion, cortico-world, local-voice, qwen3-tts, tts, vulkan

## 简介

轻核语音 · Qwen3-TTS 超轻量高速语音引擎 · Asryto：离线合成、核显/独显可选、流式播放、气泡同步与低功耗休眠。RTX 4050 实测专用显存约 1 GiB；无需语音 API key，模型需另行部署。
