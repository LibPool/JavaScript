# @enrahitu/toolchain

> 标签: JavaScript

## 简介

EnRaHiTu build toolchain: the vendored Encore build drivers (dev/build/bundle) plus the encore-runtime.node and tsparser-encore binaries delivered as per-platform packages. Pins upstream encoredev/encore v1.57.9. No encore CLI.
