# @fillament/webmcp

> 标签: agent, ai, browser, fillament, form, mcp, model-context-protocol, webmcp

## 简介

Expose Fillament forms as WebMCP tools so in-browser AI agents can read, fill, and (optionally) submit them — derived from the form's validation schema. Targets the W3C Web Model Context API with an @mcp-b/transports bridge for today's browsers.
