# @txco/nitro-preset

> 标签: analog, nitro, nitro-preset, nuxt, static, thanks-computer, txco, web-abi

## 简介

Nitro preset for Thanks, Computer (txco): builds a Nuxt or other Nitro app as a Web ABI build — your site as public/, the ops it needs as ops/, its server as server/, and txco-web.json — for `txco apply` to install.
