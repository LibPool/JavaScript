# @txco/vite-plugin

> 标签: spa, static, thanks-computer, txco, vite, vite-plugin, web-abi

## 简介

Vite plugin for Thanks, Computer (txco): after `vite build`, writes a Web ABI build — your dist/ as public/, the ops a browser-routed app needs as ops/, and txco-web.json — for `txco apply` to install.
