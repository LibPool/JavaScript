# @txco/web-abi

> 标签: conformance, fetch, thanks-computer, txco, web-abi

## 简介

The TxCo Web ABI kit: the txco-web.json schema and validator, the envelope ↔ Fetch bridge every runner uses, a harness that checks a build's server/ Fetch handler, and the ops and manifest writer producers share.
