# @maxr0ssi/glide-web-ui

> 标签: JavaScript

## 简介

Browser-based demo of Glide's hand gesture detection algorithms. Runs the full TouchProof detection pipeline in-browser using MediaPipe's WebAssembly hand landmarker.
