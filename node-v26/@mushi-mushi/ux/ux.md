# @mushi-mushi/ux

> 标签: claude-code, coding-agent, cursor, mushi-mushi, playwright, screenshots, ui-review, ux, visual-regression

## 简介

Local visual UX loop: maps a running app's pages, tabs and dialogs, runs your coding agent on each one against screenshot baselines, and shows before/after diffs, regressions and a pairwise judge.
