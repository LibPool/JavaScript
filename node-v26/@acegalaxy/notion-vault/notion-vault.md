# @acegalaxy/notion-vault

> 标签: config, dotenv, env, notion, secret-management, secrets, vault

## 简介

Load secrets from Notion vault databases into process.env. Supports multi-DB query, project/env filtering, alias expansion, in-memory TTL cache, and bootstrap row pattern.
