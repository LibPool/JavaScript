# dsh-compact-relay

> 标签: compaction, context, context-window, deepseek-harness, dsh, dsh-plugin, handoff, plugin

## 简介

DeepSeek Harness 上下文指示器插件：提供容量监控、压缩预览与确认、九段式交接单生成及消息锁定功能。 · Context indicator for DSH: preview-then-confirm compaction, 9-section session handoff, and pinned messages.
