# @upupjs/vanilla

> 标签: camera, drag-and-drop, dropbox, dropzone, file-upload, file-uploader, google-drive, javascript, one-drive, presigned-url, s3, typescript, upload, uploader, vanilla-js, web-components

## 简介

Framework-free DOM file uploader (lit-html) with cloud-drive sources, resumable uploads, theming, and ICU i18n.
