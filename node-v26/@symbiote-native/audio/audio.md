# @symbiote-native/audio

> 标签: angular, audio, expo-audio, react, react-native, recording, solid, svelte, symbiote-native, vue

## 简介

expo-audio wrapped for SymbioteNative — one framework-agnostic core, built once and reachable from the React, Vue, Svelte, Solid, and Angular adapters. AudioPlayer / AudioRecorder / AudioPlaylist / AudioStream shared-object classes, audio-session config,
