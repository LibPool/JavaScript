# @symbiote-native/local-auth

> 标签: angular, biometrics, expo-local-authentication, face-id, react, react-native, solid, svelte, symbiote-native, vue

## 简介

expo-local-authentication wrapped for SymbioteNative — one framework-agnostic core, built once and reachable from the React, Vue, Svelte, Solid, and Angular adapters. FaceID/TouchID on iOS, the Fingerprint/Biometric API on Android.
