# @symbiote-native/notifications

> 标签: angular, expo-notifications, notifications, push-notifications, react, react-native, solid, svelte, symbiote-native, vue

## 简介

expo-notifications wrapped for SymbioteNative — one framework-agnostic core, built once and reachable from the React, Vue, Svelte, Solid, and Angular adapters. Permissions, device/Expo push tokens, scheduling, presentation, badges, Android channels/channe
