# @symbiote-native/reanimated

> 标签: angular, animation, react, react-native, reanimated, solid, svelte, symbiote-native, vue, worklets

## 简介

react-native-reanimated 4 and react-native-worklets for SymbioteNative — one framework-agnostic core over the upstream hook helpers, reachable from the adapters. Shared values, animated styles, layout animations and CSS animations on the UI thread.
