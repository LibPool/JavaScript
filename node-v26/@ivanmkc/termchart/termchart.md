# @ivanmkc/termchart

> 标签: ascii, cli, diagram, flowchart, mermaid, terminal, unicode

## 简介

Push native diagrams, charts, dashboards & live status to the termchart viewer (browser/iPad) in real time — the CLI for the live canvas your AI draws on; also renders deterministic Mermaid → ASCII/Unicode in the terminal.
