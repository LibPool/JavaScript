# @rendobar/mcp

> 标签: agent, ai, captions, claude, cursor, ffmpeg, image-generation, mcp, mcp-server, model-context-protocol, rendobar, transcode, video, video-editing

## 简介

Rendobar: serverless media processing and generation for AI agents. Transform video, audio and images with FFmpeg, compose from a timeline, burn captions and compress to a budget. Generate and edit images from a text prompt, and upscale on a diffusion mod
