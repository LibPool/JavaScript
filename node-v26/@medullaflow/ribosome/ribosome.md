# @medullaflow/ribosome

> 标签: dependency-resolution, devtools, mcp, mcp-registry, mise, workflow

## 简介

Standalone dependency resolver: tool/runtime versions via mise-en-place, MCP servers via the MCP Registry. Designed for embedding in workflow orchestrators.
