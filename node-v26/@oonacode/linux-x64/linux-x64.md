# @oonacode/linux-x64

> 标签: JavaScript

## 简介

OonaCode native binaries for Linux x64: oona (CLI + headless host service), the pinned oonaclaude engine sidecar, local web UI assets. Installed automatically as an optional dependency of `oonacode`.

- 源码仓库：git+https://github.com/oonak-ai/oonacode.git
