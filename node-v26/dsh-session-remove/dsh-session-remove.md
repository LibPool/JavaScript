# dsh-session-remove

> 标签: cordis, deepseek-harness, delete, dsh, dsh-plugin, session

## 简介

Stop or permanently delete DeepSeek Harness sessions from the sidebar session menu: cancels running turns, subagents, background jobs and reminders, then removes the log, subagent session logs, projection cache and workspace record, with an optional clean
