# @degoke/browserbay

> 标签: ai-agents, automation, browser, cdp, chromium, devtools, playwright, puppeteer

## 简介

Self-hosted browsers for AI agents and automation: a relay, browser nodes that dial out to it, and a client. Deploy it anywhere, point any project at it.
