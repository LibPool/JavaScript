# @firelab/perf

> 标签: adaptive-resolution, android-tv, babylonjs, fire-tv, fps, games, gpu-detection, performance, pixijs, quality-tiers, three.js, tv, webgl

## 简介

Keep TV web games smooth: GPU/chip detection mapped to quality tiers, adaptive resolution that holds a target fps, an on-screen meter, and the window.firelab hook for the FireLab tester. Dependency-free, no build step.
