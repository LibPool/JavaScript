# @deessejs/errors

> 标签: custom-error-types, error-handling, errors, esm, exception, exception-chaining, hierarchical-errors, monorepo, nodejs, python-style-errors, standard-schema, typescript

## 简介

Lightweight, type-safe error handling for TypeScript — Python-style exception chaining, hierarchical inheritance, and rich error semantics. Function-based API, ESM-only, designed for first-class interoperability with @deessejs/fp.
