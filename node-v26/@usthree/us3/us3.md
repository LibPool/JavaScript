# @usthree/us3

> 标签: animation, behaviour-tree, blendspace, game-ai, navmesh, perception, r3f, react-three-fiber, state-machine, three, us3

## 简介

us3 — composable, R3F-native game-AI + animation runtime. Umbrella that re-exports @usthree/core + @usthree/ai (behaviour tree, perception, navigation, EQS) + @usthree/anim (blend-space + state-machine animation graph) + @usthree/react (R3F bindings).
