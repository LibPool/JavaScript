# @kevinmichaelchen/oxlint-plugin-graphql

> 标签: cli, eslint, graphql, graphql-eslint, lint, oxlint, oxlint-plugin

## 简介

GraphQL linting for Oxlint: lint GraphQL embedded in JS/TS via an Oxlint JS plugin and standalone .graphql files via a CLI, reusing @graphql-eslint's rule implementations unchanged.
