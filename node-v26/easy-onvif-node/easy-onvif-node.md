# easy-onvif-node

> 标签: dart, ip-camera, nvr, onvif, ptz, rtsp, ws-discovery

## 简介

ONVIF client for Node.js, compiled from the Dart `easy_onvif` package with dart2js. Supports WS-Discovery over UDP multicast and the Device / Media / PTZ SOAP surface.
