## 简介

Official MCP server for Old Family Recipe — let Claude, ChatGPT, Cursor and any Model Context Protocol AI assistant save, search, and preserve family recipes (with provenance) in your cookbook. Includes OCR import of handwritten recipe cards, Sage AI chat
