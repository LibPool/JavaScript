# @juvio15/pi-seek

> 标签: pi-extension, pi-package

## 简介

pi-seek is an extension for Pi. It connects Pi to the DeepSeek V4 Flash and V4 Pro models. It uses the DeepSeek Responses API and the DeepSeek beta API.
