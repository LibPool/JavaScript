# agent-layers

> 标签: agent-skills, agents, agents.md, ai, antigravity, claude-code, codex, copilot, cursor, dotfiles, gemini-cli, mcp

## 简介

Manage instructions, skills, commands, MCP servers and settings for AI coding agents (Claude Code, Codex, Gemini CLI, Antigravity, Copilot, Cursor, ...) as a base layer that follows you to every machine and project layers you can drop when a project ends.
