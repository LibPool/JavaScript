# @data-club/ai-hub-server

> 标签: JavaScript

## 简介

Server package for the data-club ai-hub: Web-Standard Fetch handlers, Letta integration, SSE wire protocol, RBAC, admin endpoints. Mounts into per-customer Next.js wrappers via createNextRouteHandler. See docs/SPECIFICATIONS.md §6.
