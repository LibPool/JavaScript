# @tokcalc/mcp-server

> 标签: capacity-planner, gpu, h100, h200, inference, llm, mcp, model-context-protocol, tokcalc, vllm

## 简介

tokcalc MCP server — open-source LLM serving capacity planner for AI agents. stdio + stateless HTTP transport with bearer API key auth + KV-backed rate limiting + public hosted endpoint. 11 read-only tools: estimate_capacity, compare_gpus, recommend_topol
