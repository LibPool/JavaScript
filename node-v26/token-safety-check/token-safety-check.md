# token-safety-check

> 标签: ai-agent, base, crypto, ethereum, mcp, rug-check, solana, token, x402

## 简介

Rug check any token on Base, Ethereum, Arbitrum, Optimism, Polygon or Solana: a 0-100 risk score with plain reasons. Pays $0.01 per check in USDC on Base via x402. Includes an MCP server.
