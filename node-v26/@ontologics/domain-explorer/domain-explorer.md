# @ontologics/domain-explorer

> 标签: DDD, documentation, documentation-generator, domain-driven-design, ontologic, typescript

## 简介

Generate an interactive HTML domain model from an Ontologic codebase: aggregates, value objects, events, typed errors, invariants, repositories and use cases.
