# @here.build/chunked-websocket

> 标签: JavaScript

## 简介

Transparent WebSocket message chunking — a transport-layer wrapper that splits >1 MiB messages into reassemblable chunks so workerd accepts them. Application code (Yjs, comments, awareness, …) sees a normal WebSocket. Adapted from partykit's y-partykit/sr
