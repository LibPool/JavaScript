# @kreeptales/pixel-glyph

> 标签: bitmap, crisp-edges, font, icon, pixel-art, react, retro, sprite, svg

## 简介

Crisp pixel-art glyphs from bitmap strings: one SVG rect per run, crispEdges, palettes as CSS variables, no seams at fractional scales.
