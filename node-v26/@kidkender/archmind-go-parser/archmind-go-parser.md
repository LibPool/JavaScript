# @kidkender/archmind-go-parser

> 标签: archmind, gin, go, golang, parser, static-analysis

## 简介

Static analysis parser for Go/Gin projects — extracts routes, middleware chains (including runtime skip-lists), and auth patterns into ArchMind IR graphs.
