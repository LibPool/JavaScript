# @hasna/shortlinks

> 标签: agentic, ai-agents, cli, custom-domains, hasna, shortlink, shortlinks, url-shortener

## 简介

Open-source shortlink manager with local SQLite or hosted /v1 storage, custom-domain provisioning through the Domains API, click tracking, CLI, MCP, redirect server, and SDK
