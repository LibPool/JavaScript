# @hasna/economy

> 标签: ai, budget, claude, cli, codex, cost, economy, gemini, mcp, tracking

## 简介

AI coding cost tracker — CLI + MCP server + REST API for Claude Code, Codex, OpenCode, Cursor, Pi, and Hermes, with legacy Gemini CLI session and Gemini API billing ingestion
