# @lymit/core

> 标签: edge, rate-limit, rate-limiting, sliding-window, token-bucket

## 简介

Pure rate-limit algorithms (fixed window, sliding window, token bucket), config resolution and a block cache. Zero dependencies, zero I/O. The algorithms inside @lymit/sdk and the Lymit edge.
