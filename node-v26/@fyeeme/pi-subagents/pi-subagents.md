# @fyeeme/pi-subagents

> 标签: dispatch, fan-out, multi-agent, pi, pi-package, subagent

## 简介

General-purpose subagent fan-out for pi: a `subagent` tool (single/parallel) spawning real pi subprocesses, three-source agent discovery (user/project/bundled), plus the shared dispatch core (spawnAgent, per-call abort, maxTurns budget, concurrency ceilin
