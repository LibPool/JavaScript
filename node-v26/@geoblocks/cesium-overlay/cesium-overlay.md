# @geoblocks/cesium-overlay

> 标签: JavaScript

## 简介

An HTML layer over a CesiumJS scene, and pins: elements kept on a point of the world as the camera moves. A tool's line and label, a character's speech bubble, a place's card: plain HTML and CSS, crisp at any zoom, laid over the canvas.
