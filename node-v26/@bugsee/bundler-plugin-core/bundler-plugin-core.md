# @bugsee/bundler-plugin-core

> 标签: JavaScript

## 简介

Shared bundler-plugin core — collects build context and drives the Rust bugsee-cli (sourcemaps inject + debug-files upload). The engine under @bugsee/vite-plugin / @bugsee/webpack-plugin.
