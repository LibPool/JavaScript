# @onehazel/connect-adapter

> 标签: adapter, igaming, onehazel, pam, wallet, webhook

## 简介

Mount in front of a stock PAM: a framework-free (req: Request) => Promise<Response> handler that implements the OneHazel Operator Contract v1 envelope from a declarative JSON config, with Express, Fastify, Hono and node:http bindings and a standalone prox
