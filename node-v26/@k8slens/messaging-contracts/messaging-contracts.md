# @k8slens/messaging-contracts

> 标签: JavaScript

## 简介

Contracts (channels, window ids, tokens and listener factories) for messaging between the windows of Lens Desktop: send a message to a window, ask a window a question, follow a value a window holds. The extension-facing surface of @lensapp/window-messagin
