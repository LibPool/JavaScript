# pocket-tailor

> 标签: eslint, fix, message, plugin, presentation, rule, suggestion, wrapper

## 简介

Wrap existing ESLint plugins so their rules' reports can be tailored: rewrite messages and add fixes or suggestions, while the upstream plugin keeps sole ownership of detection.
