# @psse-cpu/fixed-size-array

> 标签: array, data-structures, fixed-size

## 简介

JS/TS package to emulate fixed-size arrays from C/C++/Java and even Dart.  Only used in SE-1222 (Data Structures) exercises.  Not for production use.
