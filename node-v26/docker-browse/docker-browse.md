# docker-browse

> 标签: JavaScript

## 简介

CLI tool to browse docker registries using Docker Registry HTTP API V2: https://docs.docker.com/registry/spec/api/

## 官网

- 官网：https://bitbucket.org/atlassianlabs/docker-browse#readme
- 源码仓库：git+ssh://git@bitbucket.org/atlassianlabs/docker-browse.git
- npm 页面：https://www.npmjs.com/package/docker-browse
