# @axiom-studio/vibeflow-setup

> 标签: ai-agents, bootstrap, mcp, setup, vibeflow

## 简介

One-command VibeFlow setup: downloads vibeflow-cli, installs tmux, and configures the VibeFlow MCP server for your coding agents.
