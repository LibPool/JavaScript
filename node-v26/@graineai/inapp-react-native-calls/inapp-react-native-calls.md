# @graineai/inapp-react-native-calls

> 标签: ai-agent, android, callkit, calls, graine, in-app-agent, ios, react-native, voice-ai, voip

## 简介

WhatsApp-style calls with your Graine agent in React Native — CallKit and VoIP pushes on iOS, a ringing call screen on Android, the call carrying on with the screen off.
