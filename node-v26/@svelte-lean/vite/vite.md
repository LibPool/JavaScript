# @svelte-lean/vite

> 标签: code-splitting, svelte, svelte-lean, svelte5, sveltekit, tree-shaking, vite, vite-plugin

## 简介

Vite integration for Svelte Lean: discovers data-slean behaviors in Svelte markup at build time and injects only the registration modules that are used.
