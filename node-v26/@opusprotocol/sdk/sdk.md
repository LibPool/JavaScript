# @opusprotocol/sdk

> 标签: agentic-economy, ai-agents, machine-payments, mpp, opusprotocol, recurring-payments, robinhood-chain, subscriptions, usdg, x402

## 简介

The official Opus Protocol SDK: recurring payments, spending allowances, and metered usage for autonomous agents, settled in USDG on Robinhood Chain.
