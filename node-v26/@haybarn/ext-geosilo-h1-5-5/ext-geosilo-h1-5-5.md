# @haybarn/ext-geosilo-h1-5-5

> 标签: duckdb, extension, geosilo, haybarn

## 简介

Compact geometry encoding using delta-encoded coordinates. Achieves 3-4x smaller geometry storage and wire transfer compared to WKB.
