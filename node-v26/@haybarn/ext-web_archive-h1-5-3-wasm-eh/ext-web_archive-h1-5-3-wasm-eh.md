# @haybarn/ext-web_archive-h1-5-3-wasm-eh

> 标签: duckdb, duckdb-wasm, extension, haybarn, wasm, web_archive

## 简介

WebAssembly (eh) build of the Haybarn extension 'web_archive' for duckdb-wasm. Built against haybarn 1.5.3. Pick the variant (mvp/eh/threads) matching your duckdb-wasm bundle.
