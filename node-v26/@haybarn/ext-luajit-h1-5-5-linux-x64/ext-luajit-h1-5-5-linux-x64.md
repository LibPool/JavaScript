# @haybarn/ext-luajit-h1-5-5-linux-x64

> 标签: JavaScript

## 简介

Haybarn extension 'luajit' for linux/x64 (glibc). Built against haybarn 1.5.5. Installed automatically by the @haybarn/ext-luajit-h1-5-5 meta-package; use that, not this leaf, in your dependencies.
