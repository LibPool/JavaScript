# @haybarn/ext-cloudfront-h1-5-3-linux-arm64

> 标签: JavaScript

## 简介

Haybarn extension 'cloudfront' for linux/arm64 (glibc). Built against haybarn 1.5.3. Installed automatically by the @haybarn/ext-cloudfront-h1-5-3 meta-package; use that, not this leaf, in your dependencies.
