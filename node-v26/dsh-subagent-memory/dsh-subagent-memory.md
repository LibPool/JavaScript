# dsh-subagent-memory

> 标签: JavaScript

## 简介

Subagent-scoped memory for DeepSeek Harness: memory_add/list/get tools for a delegated child's own notes, a cascade delete when the child settles, an adjacency-checked service API (ctx.agentMemory read/write/summary) for the delegating parent or other hos
