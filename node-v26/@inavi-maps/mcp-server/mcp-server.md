# @inavi-maps/mcp-server

> 标签: ai, api-documentation, claude, documentation, geocoding, html-template, inavi, korean-maps, llm, map-visualization, maps, mcp, model-context-protocol, navigation, openapi, poi, reverse-geocoding, route, search, south-korea, stdio, typescript, web-map-sdk

## 简介

Documentation MCP server for iNavi Maps (South Korea) - API specifications, Web JS SDK reference, and render-ready HTML map templates. Provides the specs an AI needs to write correct code; it does not call the APIs itself.
