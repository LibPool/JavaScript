> 标签: ai-agents, claude, claude-code, cli, cursor, gemini-cli, llm-security, mcp, mcp-security, mcp-server, model-context-protocol, package-manager, prompt-injection, security, sigstore, supply-chain-security, tool-poisoning, vscode, windsurf

## 简介

MCP security guard and package manager: block prompt injection, tool poisoning and rug-pulls in Model Context Protocol servers at runtime; trust-scored installs for Claude Desktop, Claude Code, Cursor, VS Code, Windsurf, Gemini CLI.
