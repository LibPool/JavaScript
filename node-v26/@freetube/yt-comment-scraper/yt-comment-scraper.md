# @freetube/yt-comment-scraper

> 标签: comment scraper, comment-scraper, comments, youtube, youtube comment scraper, youtube comments, youtube without api, youtube-comment-scraper, youtube-comments, youtube-fetch, youtube-fetcher, youtube-grabber, youtube-scraper

## 简介

Scrapes the comments of any YouTube video without YouTube API access. Uses the default YouTube Ajax calls to get the comment data.
