# @cinadmin/game-sdk

> 标签: ar, cinadmin, game, runtime, sdk, websocket

## 简介

Official runtime SDK for CinAdmin AR games (TypeScript/JS). Token-exchange auth, discover/join, and the v2 runtime WebSocket.
