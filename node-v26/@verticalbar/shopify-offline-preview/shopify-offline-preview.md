# @verticalbar/shopify-offline-preview

> 标签: cli, liquid, offline, preview, shopify, theme

## 简介

Unofficial offline preview for Shopify Online Store 2.0 themes: a dev server with an inspector, a CLI with JSON output and a browser playground.
