# @kira905/dsh-task-board-local

> 标签: deepseek-harness, dsh, dsh-client, dsh-plugin, task-board

## 简介

Self-maintained DSH Web task board (forked from @linxin666/dsh-client-ui-task-board 0.3.4, detached from upstream): human acceptance gate, card kinds (once/recurring/interactive), and editable notes on executed cards.
