# @vaultcompass/dep-guard-core

> 标签: dependency-security, lockfile, npm-audit, package-hallucination, supply-chain-security, typosquatting

## 简介

Offline dependency-risk engine: diffs a manifest/lockfile change and scores it for typosquats, lockfile tampering, install-script acquisition, and hallucinated package names.
