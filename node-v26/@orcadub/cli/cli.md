# @orcadub/cli

> 标签: agents, cli, dubbing, mcp, orcadub, orcarouter, skills, translation, video

## 简介

OrcaDub CLI — install the OrcaDub agent Skill or dub video via OrcaRouter (model orca/dub). Also runs as an MCP server with no subcommand.
