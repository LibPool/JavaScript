# @nestm/agentportal

> 标签: agentportal, agents, capsuleos, esm, nestjs, nestjs-12, nestm, streaming

## 简介

NestJS 12 integration for AgentPortal with typed portals, managed CapsuleOS execution, and native streaming HTTP responses.
