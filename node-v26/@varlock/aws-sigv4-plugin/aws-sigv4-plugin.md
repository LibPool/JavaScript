# @varlock/aws-sigv4-plugin

> 标签: .env, aws, config, credential-proxy, dotenv, env, env vars, environment variables, plugin, request-signing, signature-v4, sigv4, varlock, varlock-plugin

## 简介

Varlock plugin adding AWS SigV4 request re-signing to the credential proxy (the agent signs with placeholder credentials; the proxy re-signs with the real keys)
