# @mcfso/mcp-admin

> 标签: deepseek-harness, dsh, mcp, model-context-protocol, plugin

## 简介

DeepSeek Harness 的 MCP 工具管理插件：宿主半边连接 MCP 服务器并把工具注册为模型原生工具，客户端半边在设置面板提供「MCP 服务器」管理界面
