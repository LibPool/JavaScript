> 标签: agent-skills, c4, claude-code, codex, cursor, diagrams, elk, github, mcp, project-management

## 简介

gh-wat-dis: agent skills for system-design-rich GitHub issues, PRs and milestones. Installs skills into your harness, wires the GitHub MCP server, renders C4 diagrams to SVG, and grounds PRs in change-impact facts.
