# @maniclang/scene

> 标签: animation, canvas, manic, react, scene-editor, typescript, visual-editor

## 简介

Shared foundation for Manic visual editors: scene document, manic source codec, deterministic timeline, and the React scene editor. Used by Manic Workbench and Manic Web.
