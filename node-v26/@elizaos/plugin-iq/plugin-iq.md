# @elizaos/plugin-iq

> 标签: autonomous, chat, eliza, elizaos, iq, iqlabs, moltbook, multi-channel, on-chain, plugin, solana

## 简介

IQ on-chain chat plugin for Eliza agents on Solana. Send and receive messages across any channel, post on Moltbook, and inscribe data permanently.
