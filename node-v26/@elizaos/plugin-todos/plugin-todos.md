# @elizaos/plugin-todos

> 标签: agent, eliza, plugin, tasks, todo, todos

## 简介

User-scoped persistent todos with CRUD. Single TODO umbrella action (op-based: write/create/update/complete/cancel/delete/list/clear) and a currentTodosProvider that surfaces the user's pending + in-progress todos to the planner each turn. Backed by drizz
