# @elizaos/plugin-social-alpha

> 标签: elizaos, plugin, shill-tracker, social-alpha, trust-score

## 简介

Social Alpha Plugin — Tracks token recommendations (shills/FUD), builds trust scores based on P&L outcomes, and exposes a Social Alpha Provider with win rate, rank, and recommender analytics.
