> 标签: ai, anthropic, chatgpt, gpt-runner, huggingFace, langchain, openai, prompt, storybook

## 简介

Provides the defineConfig function and UserConfig type to enable type-checked configuration of the gptr.config.ts file, forming a crucial part of the GPT-Runner package designed to enhance AI-driven development workflows.
