# @pylonts/api-client

> 标签: JavaScript

## 简介

浏览器端 token 体系客户端（全请求 HMAC 签名 + 令牌会话），配合 [`@pylonts/fastify`](https://gitee.com/xmecard/ts-libs) 的 token 鉴权链使用（见 `dsl/docs/token.md`）。
