# @voidly/pay-mcp

> 标签: agent-pay, agent-payments, agent-to-agent, agentic-payments, ai-payments, anthropic-mcp, autonomous-agents, base, claude-code, claude-desktop, cursor, facilitator, http-402, mcp, mcp-server, model-context-protocol, stablecoin, stdio-transport, usdc, voidly, voidly-pay, voidly-pay-mcp, windsurf, x402

## 简介

Public MCP connector for Voidpay marketplace discovery, scoped creator drafts and publishing, original-only recovery, and owner-browser checkout handoff. Hosted authorization and payment enforcement remain private. No wallet keys or autonomous payments.
