# @voidly/pay-cli

> 标签: agent-economy, agent-payments, agent-to-agent, ai-payments, autonomous-agents, base, ci, cli, command-line, ed25519, shell, stablecoin, usdc, voidly, voidly-pay, voidly-pay-cli, x402, x402-paywall

## 简介

Command-line interface for voidpay. Whoami, balance, transfer, escrow, x402 quote/verify, webhook subscribe, activity feed, plus `voidly-verify-receipt` — an offline, zero-dependency receipt verifier that needs no network and no trust in Voidly.
