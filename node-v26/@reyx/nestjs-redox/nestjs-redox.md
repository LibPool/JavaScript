# @reyx/nestjs-redox

> 标签: expressjs, fastify, nestjs, nodejs, open-api, redoc, swagger

## 简介

This NestJS module enables to auto-generate beautiful API docs using Swagger and Redoc. It supports NestJS 10, ExpressJS and Fastify.
