# @nemoir/web-runtime

> 标签: agent, browser, compiler, llm, nemoir, runtime, webllm, workflow

## 简介

TypeScript runtime core for NemoIR — execute compiled agent workflows in the browser as structured state machines with tool orchestration, policy enforcement, model-backed stage execution, and live event streaming.
