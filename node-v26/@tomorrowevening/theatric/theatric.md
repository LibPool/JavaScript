# @tomorrowevening/theatric

> 标签: JavaScript

## 简介

An easy to use [Tweakpane](https://cocopon.github.io/tweakpane/)/[Leva](https://github.com/pmndrs/leva)-like library for React, built on top of [Theatre.js](github.com/theatre-js/theatre).
