# @binarynoir/vitepress-auto-navbar

> 标签: docs, documentation, nav, navbar, vitepress, vitepress-plugin

## 简介

Automatically generate a VitePress 2 navbar config from your docs folder structure, with per-directory ordering, titles, hiding, and exclusion files.
