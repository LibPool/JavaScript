# @binarynoir/vitepress-blog

> 标签: blog, docs, documentation, feed, markdown-it, markdown-it-plugin, pagination, rss, rss-feed, tags, vitepress, vitepress-plugin

## 简介

Turn any VitePress 2 page into a blog post with frontmatter. A main blog, folder-scoped section blogs, sticky posts, pagination, keyword filters and an RSS feed for each.
