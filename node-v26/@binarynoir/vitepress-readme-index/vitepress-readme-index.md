# @binarynoir/vitepress-readme-index

> 标签: docs, documentation, index, markdown-it-plugin, migration, readme, rewrites, vitepress, vitepress-plugin, vuepress

## 简介

Migrate from VuePress to VitePress without renaming every README.md: each folder's README.md is served as its index page, and links to it keep working.
