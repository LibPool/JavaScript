# @binarynoir/vitepress-markdown-tags

> 标签: badge, docs, documentation, markdown-it, markdown-it-plugin, tags, vitepress, vitepress-plugin

## 简介

Write inline status tags like ((tag|Done|green)) in VitePress 2 Markdown and get styled badge components, with code blocks left untouched.
