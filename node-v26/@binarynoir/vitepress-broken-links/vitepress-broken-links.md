# @binarynoir/vitepress-broken-links

> 标签: broken-links, dead-links, docs, documentation, links, markdown-it, markdown-it-plugin, vitepress, vitepress-plugin

## 简介

Stop dead links from failing a VitePress build: each one renders as text with a popover that explains what is wrong and where.
