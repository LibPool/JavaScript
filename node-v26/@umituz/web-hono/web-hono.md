# @umituz/web-hono

> 标签: api-client, cache, cloudflare-workers, crud, crud-factory, database-lifecycle, drizzle, drizzle-orm, edge, hono, hono-api, neon, postgres, reactive-store, rest-api, seed, serverless, snapshot, spa-fallback, store, typescript, validation, workers, zod

## 简介

API backend platform for Cloudflare Workers + Neon Postgres: createApi skeleton + error envelope layer, full-CRUD resource factory (opt-in create/remove, list params), schema→client type bridge (ClientRow), apiFetch/apiWrite client, reactive fetch-backed
