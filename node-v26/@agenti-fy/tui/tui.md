# @agenti-fy/tui

> 标签: agenti-fy, cli, ink, monitoring, tui

## 简介

Terminal UI for monitoring an agenti-fy fleet. Shows live agent status, recent jobs, token/cost breakdowns, and supports halt/resume + per-agent reset. Run with `npx @agenti-fy/tui` against your coordinator URL.
