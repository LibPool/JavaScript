# @andy8647/pi-toolbox

> 标签: mcp, pi-extension, pi-package, syntax-highlighting, tool-rendering

## 简介

Rounded transparent tool boxes for pi coding agent — frames every tool (including MCP), bash syntax highlighting, click a box to expand it alone
