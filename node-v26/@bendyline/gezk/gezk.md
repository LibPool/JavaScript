# @bendyline/gezk

> 标签: embeddings, file-format, gezk, knowledge, rag, sqlite, zod

## 简介

The gezk knowledge-catalog format: manifest and registry schemas, id grammars, knowledge:// references, vector quantization, SQLite DDL, canonical JSON, and Ed25519 manifest signatures.
