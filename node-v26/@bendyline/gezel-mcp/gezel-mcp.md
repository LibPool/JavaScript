# @bendyline/gezel-mcp

> 标签: agents, ai, gezel, local-first, mcp, model-context-protocol, tools

## 简介

Gezel's Model Context Protocol server: gives gezels and other MCP clients access to memory, workspace files, artifacts, tasks, and team tools.
