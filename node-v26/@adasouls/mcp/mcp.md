# @adasouls/mcp

> 标签: adasouls, ai-agents, alma, mcp, model-context-protocol

## 简介

MCP server for AdaSouls: lets MCP-compatible AI agent runtimes check policy and execute economic actions through AdaSouls -- a thin adapter over @adasouls/sdk.
