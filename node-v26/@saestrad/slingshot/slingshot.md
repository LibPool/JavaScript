# @saestrad/slingshot

> 标签: agent-skills, ai-agents, anthropic, claude, claude-code, context-engineering, llm, token-optimization

## 简介

Slingshot helps Claude Code get more done for fewer tokens. It sharpens fuzzy requests into clear specs and sends each task to the cheapest model that can handle it, then reuses what worked so the next session starts smarter. Automatic once installed.
