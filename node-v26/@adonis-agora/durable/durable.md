# @adonis-agora/durable

> 标签: adonis, adonisjs, agora, dashboard, durable, opentelemetry, replay, saga, tanstack-intent, telescope, testing, workflow

## 简介

Durable cross-app workflows for AdonisJS — deterministic replay engine, AdonisJS binding, ace commands, dashboard, OpenTelemetry, Telescope, testing harness and Redis admission, all in one package. Part of the Agora ecosystem.
