# @adonis-agora/media-dashboard

> 标签: admin, adonis, adonisjs, agora, buckets, console, dashboard, media, resumable, s3, tanstack-intent, upload

## 简介

Media-management dashboard for @adonis-agora/media — browse buckets, watch resumable uploads in progress, upload, and copy/move/delete objects across buckets. A React SPA served by a thin AdonisJS provider, themed to Agora design tokens. Part of the Agora
