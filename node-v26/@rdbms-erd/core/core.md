# @rdbms-erd/core

> 标签: database, ddl, erd, rdbms, schema, sql

## 简介

`@rdbms-erd/core` is the headless model/DDL package for rdbms-erd. It provides document types, validation/serialization, logical->physical type defaults, DDL generation, diagnostics, and host-extensible database metadata.
