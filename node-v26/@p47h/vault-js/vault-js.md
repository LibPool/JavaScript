# @p47h/vault-js

> 标签: argon2, ed25519, encryption, indexeddb, local-first, privacy, security, vault, wasm

## 简介

Secure, local-first cryptographic storage for browser environments. Argon2id + XChaCha20Poly1305 + Ed25519 backed by WASM.
