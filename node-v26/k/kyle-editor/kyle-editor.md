# kyle-editor

> 标签: editor, richtext, vue3, wechat, 富文本编辑器

## 简介

轻量、美观的微信公众号风格富文本编辑器（纯前端，支持图片/视频分片上传、HTML 源码模式），可通过 <script> 引入或作为 Vue 3 组件安装。
