# karuzip-mcp

> 标签: JavaScript

## 简介

Karuzip MCP server (stdio): inspect, test, extract and create archives with a preview-then-confirm write gate. Windows x64 and macOS (Apple silicon / Intel).

## 官网

- 官网：https://karuzip.com/en/
- npm 页面：https://www.npmjs.com/package/karuzip-mcp

- npm registry：https://registry.npmjs.org/karuzip-mcp
