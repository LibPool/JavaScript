# konfigs-sdk

> 标签: CMS, Configuration, Management, config, dynamic configs, dynamic configurations, feature flag, konfig, nodejs, reactjs, rule engine, segmentation

## 简介

This packages allows you to connect to konfigs app (https://konfigs.io) and allows you to pull your configs for consumption by your systems.
