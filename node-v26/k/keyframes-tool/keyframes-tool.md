# keyframes-tool

> 标签: animation tool, animations tool, css to javascript, css3 to javascript, keyframes object, keyframes-tool, keyframes-tool.js, web animations, web animations api, web animations api tools

## 简介

Keyframes-tool is a NodeJs command line tool which convert CSS Animations to a keyframes object suitable for Web Animations API.
