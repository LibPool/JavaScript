# kaspa-simple-mcp

> 标签: blockchain, crypto, kaspa, mcp, model-context-protocol

## 简介

A read-only MCP server for Kaspa — balance, UTXOs, transactions, network info, health, supply, hashrate, marketcap, and virtual chain. Supports mainnet and testnet-10.
