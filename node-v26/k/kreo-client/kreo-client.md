# kreo-client

> 标签: baas, backend, firebase-alternative, kreo, postgres, realtime, rest, supabase-alternative

## 简介

Official KREO JavaScript / TypeScript client — a tiny, typed, dependency-free wrapper over the KREO API (Postgres + instant REST, auth, realtime, cache & storage).
