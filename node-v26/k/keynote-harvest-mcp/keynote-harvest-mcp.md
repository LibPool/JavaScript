# keynote-harvest-mcp

> 标签: assets, harvest, keynote, mcp, model-context-protocol, pdf, poppler, slides

## 简介

MCP server that harvests slide decks into previews, extracted text, embedded-image assets, and a versioned manifest. PDF-first on any platform; native .key export via Keynote on macOS.
