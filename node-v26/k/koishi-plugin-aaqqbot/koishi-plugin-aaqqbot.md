# koishi-plugin-aaqqbot

> 标签: allianceauth, chatbot, eve-online, koishi, onebot, plugin, qq

## 简介

配合 AllianceAuth 插件 aa-qqbot，用 QQ 机器人管理联盟 QQ 群成员：审批入群、定时巡检、提醒与移出、同步群名片
