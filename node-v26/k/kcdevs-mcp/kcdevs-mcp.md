# kcdevs-mcp

> 标签: developer-jobs, hiring, job-board, jobs, kansas-city, mcp, model-context-protocol, software-jobs

## 简介

MCP server for the Kansas City software-developer job market — search live KC dev jobs, look up hiring companies, and pull salary/demand stats. Powered by kcdevs.com.
