# kalvi-nfse

> 标签: cbs, cclasstrib, cst, dps, ibs, lc-214, nfse, reforma-tributaria, sdk

## 简介

SDK TypeScript para a API Kalvi: classificação e pré-validação de NFS-e para IBS/CBS (CST, cClassTrib, alíquotas, rejeições). Plano gratuito de 200 chamadas/mês, sem cartão.
