# katazuku-shukatsu

> 标签: agent, automation, human-in-the-loop, job-hunting, local-first, shukatsu, sqlite

## 简介

Local-first, human-in-the-loop automation core for Japanese shukatsu (new-grad job hunting). SQLite single-writer data model, semantic layer, and a schema-driven settings UI.
