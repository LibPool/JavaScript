# knex-tools

> 标签: database, filtering, knex, mysql, orm, pagination, postgresql, query-builder, sorting, sql, sqlite, transactions

## 简介

A utility library that extends Knex.js with query building capabilities, filtering, pagination, sorting, and transaction management.
