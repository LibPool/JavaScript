# kronajs

> 标签: code-folding, collapsible, config, configuration, diff, diff-viewer, dotenv, editor, hcl, ini, json, json-diff, json-viewer, json5, jsonc, properties, react, side-by-side, terraform, toml, tree-view, typescript, viewer, xml, yaml, yaml-diff

## 简介

Collapsible tree view, side-by-side diff and in-place editing for JSON, YAML, TOML and INI/.env config files — a React component.
