# kidnap-console

> 标签: cli, command line, command line interface, console, consoles, log, log capture, log testing, logging, logs, mock, mocking, mocks, stub, stubbing, stubs, tdd, terminal, terminals, test, test-driven development, testing, trap, trapping, traps, unit test, unit testing

## 简介

Capture and store a function's log outputs and return value, and stops its output from reaching the CLI. Makes console log testing a breeze.
