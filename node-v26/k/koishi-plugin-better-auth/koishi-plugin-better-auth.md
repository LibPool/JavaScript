# koishi-plugin-better-auth

> 标签: authentication, bot, chatbot, console, koishi, login, plugin

## 简介

基于 `@koishijs/plugin-auth` ，新增批量会话管理、登录限流、登录提醒等功能，适用于公网部署的 Koishi 控制台
