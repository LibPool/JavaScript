# keelrun-core-native-darwin-arm64

> 标签: JavaScript

## 简介

Prebuilt keel-core-native addon for macOS aarch64 (darwin-arm64). Optional dependency of keelrun-core-native — installed automatically on a matching platform, ignored otherwise. See scripts/napi-prebuild.sh.
