# koishi-plugin-emoji-like

> 标签: chatbot, emoji, keyword, koishi, llonebot, onebot, plugin, qq, reaction

## 简介

QQ表情回应/贴表情插件，支持关键词匹配和随机触发，表情库为QQ表情和Emoji表情。目前仅在 LLOneBot 下测试，需启用 HTTP 服务。
