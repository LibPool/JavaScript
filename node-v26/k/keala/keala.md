# keala

> 标签: bun, fetch, framework, hono, http, koa, middleware, onion, router, server, sse, typescript, web, websockets, zero-dependency

## 简介

keala — Koa's ergonomics at Hono's speed: dual-mode onion framework for Bun 1.4+ (runs under Node too). Zero dependencies, precompiled middleware chains, hybrid static/trie router, Bun-native route sinking, signed cookies, SSE, WebSockets.
