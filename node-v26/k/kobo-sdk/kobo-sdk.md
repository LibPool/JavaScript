# kobo-sdk

> 标签: JavaScript

## 简介

A TypeScript SDK for seamlessly interacting with the [KoboToolbox](https://www.kobotoolbox.org/) API, abstracting its complexities.  **Optimized for TypeScript, with full type definitions.**
