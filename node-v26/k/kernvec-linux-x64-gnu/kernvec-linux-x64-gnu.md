# kernvec-linux-x64-gnu

> 标签: embeddings, hnsw, napi-rs, rag, similarity-search, vector-database, vector-search

## 简介

Embedded, local-first vector database for Node.js/TypeScript — SQLite for vectors. No server, no Docker, no external daemon.
