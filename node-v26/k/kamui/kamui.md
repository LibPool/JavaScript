# kamui

> 标签: angular, astro, component-library, components, css, css-framework, dark-mode, design-system, framework-agnostic, nextjs, nuxt, qwik, react, solidjs, svelte, sveltekit, tailwind, tailwind-css-4, tailwindcss, theme, ui, ui-components, vue, vue3

## 简介

Modern CSS component library built on Tailwind CSS 4. Framework-agnostic with zero JavaScript runtime. Works with Vue, React, Astro, Svelte, Angular, and more.
