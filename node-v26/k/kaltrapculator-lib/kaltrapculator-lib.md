# kaltrapculator-lib

> 标签: a11y, calculator, custom-element, i18n, input, keyboard, number-format, shadow-dom, vanilla-js, web-component

## 简介

Zero-dependency Web Component that turns any <input> into a calculator-assisted field. Keyboard-first, 3 themes, i18n-ready, 5.9 KB gzipped.
