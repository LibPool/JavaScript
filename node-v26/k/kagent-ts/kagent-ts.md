# kagent-ts

> 标签: agent, agents, ai, framework, llm, openai, plan-solve, react, tool-use, typescript

## 简介

A production-grade TypeScript agent framework with multi-paradigm agent loops, multi-agent orchestration, tool governance, session persistence, streaming, memory extraction, skill precipitation, and prompt-injection defense.
