# kwtsms

> 标签: api, bulk-sms, client, kuwait, kwtsms, nodejs, otp, sms, sms-gateway, typescript

## 简介

JavaScript/TypeScript client for the kwtSMS SMS API (kwtsms.com). Send SMS, validate numbers, check balance. Zero runtime dependencies.
