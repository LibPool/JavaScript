# kdxf-web

> 标签: JavaScript

## 简介

该模块提供了与科大讯飞语音识别API的集成，实现实时语音转写功能。通过WebSocket连接，将麦克风采集的音频数据发送至科大讯飞服务器，并接收返回的识别结果。
