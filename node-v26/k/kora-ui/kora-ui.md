# kora-ui

> 标签: component-library, design-system, design-tokens, kora, kora-ui, palette, react, react-components, tailwind, tailwindcss, themes, typescript, ui, ui-library

## 简介

React UI component library styled with Tailwind CSS. Ships primitives + 6 opinionated themes (default, vintage, futuristic, electric, oceanic, botanical).
