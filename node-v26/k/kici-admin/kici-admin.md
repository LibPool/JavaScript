# kici-admin

> 标签: admin, ci, cicd, cli, continuous-integration, orchestrator, pipelines, self-hosted, typescript, workflow

## 简介

Administration CLI for a KiCI customer-deployable orchestrator. Manage runs, agents, peers, sources, secrets, event log, and database schema.
