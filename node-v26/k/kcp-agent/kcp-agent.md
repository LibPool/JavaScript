# kcp-agent

> 标签: agent, ai, kcp, knowledge-context-protocol, mcp, rag

## 简介

Reference agent that consumes the Knowledge Context Protocol end-to-end — a deterministic, fail-closed navigation planner plus optional LLM synthesis.
