# koishi-plugin-xui-api

> 标签: 3x-ui, chatbot, koishi, plugin, v2ray, xray, xui, 流量, 节点

## 简介

3x-ui / X-UI 面板 API 插件 — 查询服务器状态、入站、客户端、用户流量、在线用户、用户组、活跃入站、Xray状态；支持创建/删除用户、重置流量、启停Xray等管理操作
