# koishi-plugin-cs-lookup-vincentzyu-fork

> 标签: chatbot, koishi, plugin

## 简介

🎮 查询Steam API 获取玩家的CS2库存并渲染为图片，🔗 支持SteamID 绑定与解析，🌐 可配代理与双API自动回退，💾 内置图片缓存，🎨 支持深色主题/水印/自定义字体等丰富渲染选项
