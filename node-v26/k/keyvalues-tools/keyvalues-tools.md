# keyvalues-tools

> 标签: bun, counter-strike, cs2, csgo, dota2, gameinfo, garrys-mod, gmod, keyvalues, kv1, kv3, nodejs, parser, serializer, source-engine, sourcemod, steam, tf2, typescript, valve, vdf, vdf-parser, vdf-to-json, zero-dependency

## 简介

Zero-dependency TypeScript parser and serializer for Valve KeyValues (VDF / KV1), for Node.js and Bun. Comments, platform conditionals, #base includes, duplicate-key arrays, schema validation and a CLI.
