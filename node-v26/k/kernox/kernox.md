# kernox

> 标签: ecs, entity-component-system, event-driven, framework, game, game-engine, javascript, kernox, modular, prototypes, real-time, typescript

## 简介

Kernox is a simple javascript framework designed to build highly decoupled real-time applications. Inspired on the Entity-Component-System architecture, Kernox lets you define entities based on prototypes with multi-inheritance, allocated within collectio
