# koishi-plugin-esp32-to-galaku

> 标签: ble, esp32, esp32s3, galaku, koishi, koishi-plugin, plugin, serial

## 简介

Koishi plugin that sends GALAKU control commands to an ESP32-S3 bridge through a local PowerShell TCP-to-serial bridge.
