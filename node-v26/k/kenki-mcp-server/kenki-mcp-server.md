# kenki-mcp-server

> 标签: ai, claude, claude-desktop, health, kenki, mcp, mcp-server, openclaw

## 简介

MCP server for Kenki.ai — gives any MCP-compatible AI (Claude, OpenClaw, etc.) read/write access to your health data
