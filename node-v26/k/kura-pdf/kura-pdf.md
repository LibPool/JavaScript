# kura-pdf

> 标签: accessibility, archival, factur-x, pdf, pdf/a, pdfa, pdfua, pdfx, preflight, signing, xrechnung, zugferd

## 简介

Kura, the open source PDF standards and preflight engine by BentoPDF: convert any PDF to PDF/A, PDF/UA, PDF/X, PDF/E or PDF/VT, check it, run print preflight, sign it and build e-invoices. Native engine for Node.js.
