# kybase-mcp

> 标签: agent-memory, knowledge-base, markdown, mcp, model-context-protocol, pgvector, semantic-search

## 简介

Persistent markdown memory for AI agents over MCP. Runs standalone with an embedded Postgres — no Docker, no server.
