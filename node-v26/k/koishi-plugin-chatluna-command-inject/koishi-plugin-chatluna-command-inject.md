# koishi-plugin-chatluna-command-inject

> 标签: chatbot, chatluna, chatluna-plugin, command, commands, context-manager, custom-command, debug, injection, koishi, onebot, plugin, prompt, prompt-renderer, variable, 主插件, 伪装插件, 变量注入, 指令变量, 指令统计, 提示词注入, 系统提示词, 自定义命令, 角色扮演, 调试模式

## 简介

Koishi 指令变量注入插件，读取机器人已注册的指令，为 ChatLuna 主插件与伪装插件提供全部/已修改/已停用/已隐藏/根指令/强制启用/长期未使用/从未执行/单条详情/数量统计/最近撤销11类提示词变量，并支持系统提示词自动注入与聊天自定义命令
