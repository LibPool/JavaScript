# koishi-plugin-ll-sentinel

> 标签: alert, koishi, monitor, plugin, probe, sentinel, tcp, uptime, watchdog

## 简介

李浅浅自用插件。Koishi plugin: 端点可用性值守 —— 对指定 host:port 做 TCP 建连探测，首次探测记基线，连续 N 次确认「不通 → 通」后才推送提醒；支持多端点、自定义间隔与防抖、状态查询与历史翻转记录。
