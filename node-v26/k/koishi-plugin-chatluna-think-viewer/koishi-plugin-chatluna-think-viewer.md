# koishi-plugin-chatluna-think-viewer

> 标签: character, chatluna, guard, koishi, moderation, recall, think

## 简介

通过命令/关键词查看 chatluna-character 最近一次回复的 <think> 思考内容，并在消息格式异常时自动拦截/撤回。
