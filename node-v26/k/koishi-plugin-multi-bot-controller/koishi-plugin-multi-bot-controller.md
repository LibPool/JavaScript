# koishi-plugin-multi-bot-controller

> 标签: assignee, bot, bot-controller, chatbot, koishi, message-dispatcher, multi-bot, plugin

## 简介

Multi-bot response controller - manages the response behavior of multiple bots in the same channel by automatically adjusting the assignee field in the channel table, supporting keyword and command-based filtering rules
