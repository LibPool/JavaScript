# knex_conn_release

> 标签: build, builder, cockroachdb, database, db, mssql, mysql, oracle, postgres, postgresql, query, querybuilder, sql, sqlite3

## 简介

A batteries-included SQL query & schema builder for PostgresSQL, MySQL, CockroachDB, MSSQL and SQLite3 uses tarn_release which is patched to free connection on release
