# kordoc

> 标签: biff8, converter, document, docx, hancom, hangul, hwp, hwpx, korean, markdown, mcp, model-context-protocol, ocr, parser, pdf, print, puppeteer, xls, xlsx

## 简介

Parse Korean documents (HWP3-5, HWPX, HWPML, PDF, XLS(X), DOCX) to Markdown — CLI + MCP server with lossless patch/roundtrip, form-filler, document diff, print & layout-preserving SVG renderer
