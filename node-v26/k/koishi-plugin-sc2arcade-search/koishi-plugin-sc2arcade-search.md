# koishi-plugin-sc2arcade-search

> 标签: StarCraft II, chatbot, koishi, plugin, sc2arcade

## 简介

提供星际争霸2游戏大厅相关查询功能的 Koishi 插件，支持房间状态查询、战绩查询、地图绑定等功能。
