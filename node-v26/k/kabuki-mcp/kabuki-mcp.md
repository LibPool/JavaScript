# kabuki-mcp

> 标签: diff-chain, embodied-ai, mcp, model-context-protocol, mujoco, robotics, simulation, world-model

## 简介

MCP stdio shell for the kabuki world control plane: a fail-closed load/observe/act/verify/replay loop where world revisions only advance after physics verification by an organoid deployment.
