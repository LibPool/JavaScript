# koacrab

> 标签: app, application, crab, express, framework, http, koa2, koacrab, middleware, node web, web

## 简介

> 前身是hzl.php（未开源）, 后基于express重构后，随着koa2的出现，使用到了async/await，不再需要经过Babel,就能很好的解决了回调的问题，所以使用Koa2进行改版升级，并于老婆的生日那天开源。
