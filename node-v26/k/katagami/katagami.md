# katagami

> 标签: ai-assisted-development, ai-coding, coding-agents, compile-time, dependency-injection, di, di-container, ioc, javascript, type-inference, type-safe, typescript

## 简介

Type-safe dependency injection for TypeScript, with inferred types and scope checks for AI-assisted development. No decorators or reflect-metadata.
