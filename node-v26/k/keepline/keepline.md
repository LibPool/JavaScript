# keepline

> 标签: esm, heartbeat, observability, react, react-hooks, realtime, reconnect, reconnecting-websocket, standard-schema, typescript, usewebsocket, websocket, websockets, zod

## 简介

Typed, dependency-free WebSocket client with resilient reconnection, heartbeats, queues, schema validation, subscriptions, observability, and React 18+ bindings.
