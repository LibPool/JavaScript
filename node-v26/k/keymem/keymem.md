# keymem

> 标签: agent, agent-memory, ai-memory, associative-memory, bge-m3, embeddings, knowledge-graph, llm, long-term-memory, mcp, mcp-server, mem0-alternative, memory, memory-layer, model-context-protocol, rag, reranker

## 简介

Associative memory for LLM agents — a key-graph memory layer (MCP server) that recalls by association, not just vector similarity. A graph-based alternative to vector-store agent memory.
