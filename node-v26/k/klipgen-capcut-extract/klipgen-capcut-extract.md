# klipgen-capcut-extract

> 标签: ai-training-data, capcut, capcut-draft, capcut-export, draft_content, extract, video-editing

## 简介

Package one human-cut CapCut project into a single folder — every footage/audio/image/sticker file plus the full structured record (timeline, transcript, layers, per-clip settings, raw draft, coverage). Run with npx; installs nothing else. Not affiliated
