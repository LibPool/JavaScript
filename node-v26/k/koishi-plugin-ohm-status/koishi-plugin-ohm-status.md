# koishi-plugin-ohm-status

> 标签: daliy, score, zerobot

## 简介

通过读取OpenHardwareMonitor的WebAPI返回的JSON数据，在Koishi中获取宿主机的CPU、主板、内存和硬盘的温度、负载与频率数据，支持智能过滤无效传感器节点
