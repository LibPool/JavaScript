# knighkit

> 标签: module, nodejs, package, 模块化开发, 自动打包

## 简介

knighkit 是自动化，模块开发，并支持自动打包，支持远程调试的前端开发框架。 目的是减少前端开发过程中的重复工作，使你更关注程序本身。
