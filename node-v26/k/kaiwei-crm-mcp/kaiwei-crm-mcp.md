# kaiwei-crm-mcp

> 标签: JavaScript

## 简介

凯伟 CRM MCP 的 STDIO 桥：把 Accio Work 等本地 STDIO MCP 客户端桥接到远程 CRM HTTP MCP（Streamable），token 走 env。纯转发，不含业务逻辑。

## 官网

- npm 页面：https://www.npmjs.com/package/kaiwei-crm-mcp

- 1.0.0

## 获取地址

- npm 安装：`npm install kaiwei-crm-mcp`
- npm registry：https://registry.npmjs.org/kaiwei-crm-mcp
- Node 要求：>=18
