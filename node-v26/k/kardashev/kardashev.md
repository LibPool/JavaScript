# kardashev

> 标签: CAISO, ERCOT, ISO, ISONE, LMP, MISO, NYISO, PJM, RTO, SPP, carbon intensity, curtailment, electricity, energy, energy data api, grid, interconnection queue, power grid data, wholesale electricity prices

## 简介

Free, open-source JavaScript/TypeScript client for the Kardashev Labs US grid data API - LMP, load, fuel mix, carbon intensity, curtailment, and interconnection queues across 7 US ISOs. No API key required.
