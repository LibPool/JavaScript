# kongbrain

> 标签: ai-agent, bge-m3, cognitive-architecture, context-engine, embeddings, graph-database, knowledge-graph, llm, memory, openclaw, openclaw-plugin, persistent-memory, surrealdb, vector-search

## 简介

Graph-backed persistent memory engine for OpenClaw. Replaces the default context window with SurrealDB + vector embeddings that learn across sessions.
