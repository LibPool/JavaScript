# koishi-plugin-quote-book

> 标签: chatbot, koishi, plugin

## 简介

这是一个支持笔名系统的摘抄本插件，用户可以创建笔名后记录好词好句，并通过漂流瓶方式随机获取他人摘抄，所有数据都会持久化保存。
