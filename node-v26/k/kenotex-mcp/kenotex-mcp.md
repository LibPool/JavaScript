# kenotex-mcp

> 标签: calendar, check-in, claude, habit, kenotex, llm-tools, mcp, model-context-protocol, todo

## 简介

MCP server for Kenotex ── expose local todo/event/habit/category/reminder CRUD + check-ins to any MCP-compatible LLM client (Claude Desktop, Cursor, Zed, OpenClaw, etc.)
