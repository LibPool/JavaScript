# kura-pdf-wasm

> 标签: accessibility, archival, factur-x, pdf, pdf/a, pdfa, pdfua, pdfx, preflight, wasm, webassembly, xrechnung, zugferd

## 简介

Kura, the open source PDF standards and preflight engine by BentoPDF, compiled to WebAssembly: runs on any platform and in browsers, no native binaries.

- 官网：https://kura.bentopdf.com
- 源码仓库：git+https://github.com/alam00000/bentopdf-kura.git
