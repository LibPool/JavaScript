# kill-port-safe

> 标签: address already in use, cli, cross-platform, eaddrinuse, free port, kill, kill port, kill-port, lsof, netstat, port, port 3000, port in use, process

## 简介

Kill the process on a port (3000, 8080, any). Zero-dependency drop-in replacement for kill-port: fast, exact port matching, shows what it killed, works on Windows, macOS, Linux and Docker.
