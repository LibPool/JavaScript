# knowuswell-mcp

> 标签: ai-assistant, claude, friendship-quiz, mcp, model-context-protocol, quiz

## 简介

MCP server for the KnowUsWell friendship quiz — let AI assistants host the two-player quiz: 16 behaviour questions, four-letter roles, 16 pair types.
