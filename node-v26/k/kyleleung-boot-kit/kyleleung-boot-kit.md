# kyleleung-boot-kit

> 标签: JavaScript

## 简介

🚀 一个基于 TypeScript 5.6 的 Node.js 服务端开发框架，采用 **最新装饰器语法** 封装，默认使用 **Express 4.26**，支持模块注入、配置管理、请求处理等特性，适用于快速构建中大型后端服务。
