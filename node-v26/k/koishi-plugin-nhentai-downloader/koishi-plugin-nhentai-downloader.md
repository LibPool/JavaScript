# koishi-plugin-nhentai-downloader

> 标签: chatbot, comic, downloader, koishi, manga, menu, nhentai, plugin, search

## 简介

nhentai 漫画插件，提供搜索、下载、打包发送漫画作品的功能，支持 PDF/ZIP 加密。更新API支持
