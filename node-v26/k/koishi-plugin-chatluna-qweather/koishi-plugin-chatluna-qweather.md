# koishi-plugin-chatluna-qweather

> 标签: air-quality, chatluna, forecast, koishi, minutely, precipitation, qweather, weather

## 简介

为 ChatLuna 提供和风天气查询工具，支持城市搜索、天气预报、分钟级降水和空气质量
