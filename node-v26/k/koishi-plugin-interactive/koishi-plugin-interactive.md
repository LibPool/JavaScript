# koishi-plugin-interactive

> 标签: game, interactive, koishi, plugin, qqbot

## 简介

多功能互动型QQ机器人插件，支持猜数字、每日签到、幸运抽奖、积分商店、排行榜、成就系统、个人资料、随机互动、将军系统、修仙系统、每日提醒等功能
