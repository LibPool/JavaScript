# koishi-plugin-simc

> 标签: chatbot, koishi, plugin, simc, simulationcraft, warcraft

## 简介

本地 SimulationCraft 模拟插件（简化版 Raidbots）：QuickSim / GearCompare / TopGear / Advanced，调用本机 SimC 二进制，不依赖任何网页 API。
