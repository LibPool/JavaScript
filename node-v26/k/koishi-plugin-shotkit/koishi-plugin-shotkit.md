# koishi-plugin-shotkit

> 标签: bot, chatbot, html, koishi, plugin, png, puppeteer, render, renderer, screenshot, service, shotkit, webkit, webp

## 简介

shotkit 渲染服务：用 ShotKit 的 WebKit 内核把 HTML、本地文件或 URL 渲染成 PNG / WebP，不需要浏览器，调用方式与 ctx.puppeteer 同形
