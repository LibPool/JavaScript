> 标签: back, bug, connect, endless, express, fix, header, helper, hotfix, http, koa, loop, middleware, patch, plugin, prevent, prevention, recursive, redirect, redirecting, redirection, referer, referrer, route, session

## 简介

Prevent redirect loops with sessions since HTTP referrer header is unreliable and ensures sessions are saved upon redirect
