# kendo-ui-react-jquery-fixed-events-multiselect

> 标签: Components, Kendo, React, UI, Widgets, jQuery

## 简介

The Kendo UI for jQuery DatePicker widget wrapped as a React component. This fork fixes events not being unbound.
