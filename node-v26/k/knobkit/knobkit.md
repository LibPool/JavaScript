# knobkit

> 标签: declarative, events, framework, isomorphic, rapid-prototyping, react, ui, web-app, widgets

## 简介

Create TypeScript webapps in minutes. Ship, host and share everywhere — declare widgets, write event handlers, done. The same file runs in the browser or on a stateless Node server.
