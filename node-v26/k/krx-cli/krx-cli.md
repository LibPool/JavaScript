> 标签: agent, ai, bond, cli, derivative, etf, finance, korea-exchange, korean-stock-market, kosdaq, kospi, krx, market-data, mcp, mcp-server, stock, 시세, 주식, 한국거래소

## 简介

CLI & MCP server for KRX (Korea Exchange) Open API — query Korean stock market data (KOSPI, KOSDAQ, ETF, bonds, derivatives) from terminal or AI agents
