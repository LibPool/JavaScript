# kfg

> 标签: backend, bun, config, configuration, deno, dot-env, env, json, laravel-rules, node, performance, schema, settings, tracing, type-safe, typebox, typescript, validation

## 简介

Powerful, type-safe configuration system for Node.js, Bun, and Deno. Built on TypeBox with Laravel-style rules and smart environment tracing.
