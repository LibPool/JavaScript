# kiln

> 标签: JavaScript

## 简介

node-kiln ========= **Overview:** Provides Kiln API functionality. Very little here at the moment.  You can login but can't do anything. `kiln.watchActivity()` works well, but you have to deal with the objects returned by Feedparser yourself.
