# kotii-templates

> 标签: JavaScript

## 简介

a lightweight template provider for the Kotii ecosystem.It delivers ready-to-use **SSR (Server-Side Rendering)** and **SPA (Single-Page Application)** templates, supporting both **JavaScript** and **TypeScript** project setups
