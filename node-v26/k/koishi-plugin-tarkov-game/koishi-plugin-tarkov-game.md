# koishi-plugin-tarkov-game

> 标签: koishi, plugin, tarkov

## 简介

一个受到 Escape from Tarkov 启发的 Koishi 游戏插件。在游戏中，玩家可以探索不同的地点，搜索物资，收集物品，并在市场中进行交易。
