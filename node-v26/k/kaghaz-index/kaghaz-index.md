# kaghaz-index

> 标签: anthropic, claude, langchain, llm, pdf, rag, retrieval, tree-index, vectorless

## 简介

Vectorless, reasoning-based RAG. Builds hierarchical tree indices from PDFs and retrieves via LLM-driven tree search.
