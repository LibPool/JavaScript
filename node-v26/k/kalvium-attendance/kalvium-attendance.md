# kalvium-attendance

> 标签: attendance, automation, cli, internship, kalvium, worklog

## 简介

Automatically mark your daily Kalvium internship attendance (worklog) at a set time. Works on macOS, Linux and Windows.

## 官网

- npm 页面：https://www.npmjs.com/package/kalvium-attendance

- 1.0.0

- npm registry：https://registry.npmjs.org/kalvium-attendance
- Node 要求：>=18
