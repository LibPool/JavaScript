# koishi-plugin-triple-sos

> 标签: chatbot, koishi, plugin

## 简介

Triple-SOS 是由 forever豪3 开发的开源且具备图形化界面的自动三元齐次轮换不等式配方器。这个插件的主要功能只是调用了一下它的API。
