# keycombo-parse

> 标签: hotkey, keyboard, keyboardEvent, keycombo, shortcut

## 简介

Use an easy-to-read key combo string to capture keyboard events. For example: `⇧ ⌥ ⌘ + K` → `e.shiftKey && e.altKey && e.metaKey && e.code === 'KeyK'`
