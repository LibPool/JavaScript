# keybridge

> 标签: 2fa, agent, claude-code, mcp, npm-publish, passkey, secure-enclave, touch-id, webauthn

## 简介

Safe WebAuthn bridge for npm publishing from agents: the agent initiates, the human approves via Touch ID - the ceremony runs in an invisible windowless WKWebView.
