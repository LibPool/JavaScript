# agent-control-panel

> 标签: agent-control-panel, agent-monitoring, agents, ai, ai-agents, anthropic, control-plane, gemini, kill-switch, llm, observability, openai

## 简介

Agent Control Panel SDK for Node.js: monitor AI agents in production and pause, resume, stop or swap their model without redeploying. Fail-open, signed commands.
