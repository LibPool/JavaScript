# @place-ts/data

> 标签: collection, crud, data, place, place-ts, reactive

## 简介

Data primitives over @place-ts/reactivity. v0.1 ships a single primitive: collection<T>(state, options?) — keyed CRUD over a State<T[]> with reactive lookups + optional sorting. Replaces the hand-rolled CRUD shape that repeats per-entity in real apps.
