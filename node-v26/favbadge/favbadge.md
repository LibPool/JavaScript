# favbadge

> 标签: app-badge, badge, count, favicon, favicon-badge, framework-agnostic, hook, notification, react, tab, title, unread

## 简介

Show an unread count on the favicon and in the tab title, like "(3) Inbox". Zero dependencies, works with any framework, React hook included.
