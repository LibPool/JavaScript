# @amatiasq/peer-connection

> 标签: JavaScript

## 简介

WebRTC without the ceremony: one class that owns the `RTCPeerConnection`, the ICE gathering and the local/remote descriptions. You still have to carry the `offer` and the `answer` between the two peers yourself — that is what a signalling server is for.
