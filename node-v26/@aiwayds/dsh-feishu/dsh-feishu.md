# @aiwayds/dsh-feishu

> 标签: bot, deepseek-harness, dsh, dsh-plugin, feishu, lark, remote

## 简介

dsh plugin: drive an existing dsh session from Feishu/Lark — round cards, interactive resume, ask-user cards, steer (outbound-only WebSocket bot)
