# @aiwayds/dsh-jev-core

> 标签: classification, decision-model, dsh, jev, llm, typesafe

## 简介

Shared TypeSafe Jev decision-model client for the dsh ecosystem: strict response validation, keychain-first key resolution, typed fail-open errors. Jev-optional by design.
