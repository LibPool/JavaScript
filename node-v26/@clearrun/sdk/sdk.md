# @clearrun/sdk

> 标签: clearrun, client, honesty, sdk, verdict

## 简介

ClearRun public SDK. HostedApiClient + MockKernelClient implementing the HonestyKernelClient boundary. Depends only on @clearrun/core-types; runs standalone against the mock with the closed kernel absent.
