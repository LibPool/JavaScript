# @normapi/client

> 标签: e-invoice, e-rechnung, en16931, factur-x, invoice, kosit, validation, xrechnung, zugferd

## 简介

Validate German e-invoices (XRechnung UBL/CII, ZUGFeRD/Factur-X PDF) against the official KoSIT rule set via the NormAPI service.
