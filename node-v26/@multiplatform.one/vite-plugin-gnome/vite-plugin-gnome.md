# @multiplatform.one/vite-plugin-gnome

> 标签: gjs, gnome, gtk4, multiplatform.one, react-gnome, tamagui, vite-plugin

## 简介

Vite plugin that makes Tamagui render under react-gnome (GTK4/GJS) — bundle patches for @tamagui/core's native lazy-init chains, the sheet/portal native builds, the hover/animation gates, plus the Tamagui-specific resolver aliases. Pairs with @react-gnome
