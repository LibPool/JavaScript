# @neetru/db-authz

> 标签: JavaScript

## 简介

Motor unico de autorizacao por usuario final para o mundo nosql-vm (MongoDB) do Neetru Core DB. Decide se um usuario final de um produto SaaS pode ler/escrever uma colecao e impoe o filtro de propriedade. Funcao pura, zero dependencias, fail-closed em tod
