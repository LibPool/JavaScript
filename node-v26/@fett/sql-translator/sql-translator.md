# @fett/sql-translator

> 标签: compatibility-layer, database, mongodb, mysql, postgresql, sql, sqlite

## 简介

SQL 兼容层：以 SQL 为统一查询语言的数据库兼容层（MySQL 5/8 / PostgreSQL / SQLite / MongoDB），支持 Node ≥ 22.5 与 Bun，内置连接池、任务队列（多线程）、结构检出
