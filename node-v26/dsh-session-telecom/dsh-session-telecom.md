# dsh-session-telecom

> 标签: cross-session, deepseek-harness, dsh, dsh-plugin, session

## 简介

DSH session communication: read existing transcripts, copy session IDs, message live or saved sessions, and inspect token usage. Uses host runtime services without installing a second DSH core.
