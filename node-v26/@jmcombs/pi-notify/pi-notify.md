# @jmcombs/pi-notify

> 标签: ghostty, iterm2, kitty, notifications, osc, pi-extension, pi-package, terminal-notifications, wezterm

## 简介

Terminal-emulator notifications (OSC 777/9/99) for the Pi coding agent — alerts you when Pi finishes a turn or blocks on ask_user. Works in Ghostty, iTerm2, WezTerm, Kitty, etc. Zero OS binaries or dependencies.
