# @renaudcerrato/opencode-jbcontext

> 标签: code-search, context, jbcontext, jetbrains, opencode, plugin, semantic-search

## 简介

OpenCode plugin that keeps the current project directory indexed by JetBrains Context (jbcontext) for semantic code search.
