# wpops

> 标签: application-password, cli, content-management, multi-site, navigation-menu, rest-api, wordpress, wp, wp-json

## 简介

WordPress REST operations toolkit — manage posts, pages, media, menus, comments, users, custom types, revisions, blocks, templates, widgets, settings and plugins from the CLI. Multi-site, safety-first, zero dependencies.
