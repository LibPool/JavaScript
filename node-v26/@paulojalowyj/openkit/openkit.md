# @paulojalowyj/openkit

> 标签: agents, ai, cli-tool, code-review, coding-assistant, development-tools, no-install-needed, npx-only, opencode

## 简介

Use 'npx @paulojalowyj/openkit init' (not npm install). OpenKit is a CLI tool for OpenCode Agent System - 15 specialized agents, 33+ skills, validation scripts.

Quick Start:
1. Install: npx @paulojalowyj/openkit init
2. Start OpenCode: opencode
3. Use wo
