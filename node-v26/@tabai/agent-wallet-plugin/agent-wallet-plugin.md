# @tabai/agent-wallet-plugin

> 标签: agent-wallet, ai-agent, billing, credit, metamask, monad, oclif-plugin, post-paid, usdc

## 简介

Tab commands for the MetaMask Agent Wallet CLI (mm): discover priced Services on Monad, call one on credit, read the Open Tab, and settle, authorise or register a metering delegate with the wallet's own policy-gated key.
