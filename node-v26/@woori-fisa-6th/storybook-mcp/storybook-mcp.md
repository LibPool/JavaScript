# @woori-fisa-6th/storybook-mcp

> 标签: JavaScript

## 简介

이 서버는 **Model Context Protocol (MCP)** 을 통해   AI 에이전트(**Cline, Roo Code, Claude Desktop** 등)가   로컬 **Storybook 컴포넌트 명세를 직접 읽고 분석**할 수 있도록 돕는 도구입니다.
