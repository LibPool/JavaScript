# @chenbz/wmp-watermark

> 标签: JavaScript

## 简介

**wmp-watermark** 是一款微信小程序水印**自定义组件**，通过canvas合成图片和文字水印，自动铺满水印至整个图片，结合了懒加载一起使用，可大大优化加载速度。
