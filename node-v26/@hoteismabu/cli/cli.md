# @hoteismabu/cli

> 标签: JavaScript

## 简介

Este Gerador de Projetos via CLI é uma ferramenta de linha de comando projetada para acelerar o processo de inicialização de novos projetos. Com ele, você pode facilmente gerar a estrutura básica de um projeto a partir de templates predefinidos, personali
