# @jeremymcs/patchdeck

> 标签: ai-agent, automation, babysitter, claude, code-review, codex, developer-tools, github, pr-management, pull-request

## 简介

Autonomous GitHub PR and issue workbench that watches repos, triages review feedback, and dispatches agents to fix code locally
