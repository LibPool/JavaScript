> 标签: ai, anthropic, api, automation, claude, event-registry, eventregistry, llm, mcp, media-monitoring, model-context-protocol, news, news-api, newsapi, newsapi-ai, nubiia

## 简介

MCP server for the NewsAPI.ai (Event Registry) news intelligence API: article and event search, entity autosuggest, trending concepts and token usage for AI assistants like Claude. Built by Nubiia.
