# @nubiia/mcp-borme

## 简介

MCP server for the BORME (Boletín Oficial del Registro Mercantil) through the OpenMercantil API: company search and reports, officers, daily summaries, sectors, public procurement and mercantile-law norms for AI assistants like Claude. Built by Nubiia.
