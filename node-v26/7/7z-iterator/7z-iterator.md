# 7z-iterator

> 标签: 7z, 7zip, Symbol.asyncIterator, archive, asyncIterator, decompress, extract, iterator, lzma, lzma2, seven-zip, stream

## 简介

Extract contents from 7z archives using an iterator API. Pure JavaScript, works on Node.js 0.8+
