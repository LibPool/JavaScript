# @talend/scripts-publish-local

> 标签: JavaScript

## 简介

This package provide a CLI: 'talend-publish-local'. This CLI give you a way to handle a local instance of [verdaccio](https://verdaccio.org) and configure your environment to point yarn and npm on it. Once you stop it (ctrl+c) it reconfigures npm and yarn
