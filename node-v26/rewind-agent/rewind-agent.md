# rewind-agent

> 标签: acp, agent, ai-agents, ascii-art, debugging, diff, discord, gemini-cli, meme, mutation, replay, zed

## 简介

Rewind - replay agent runs, mutate one variable, see what would have happened. Replay + mutate + diff for agent traces.
