# @osuki-dev/muqun-theme

> 标签: accessibility, cli, color-scheme, contrast, muqun, terminal, theme, wcag

## 简介

Build and check Muqun themes from a terminal — init, validate, pack, unpack, and explain the opacity floor of a .muqun-theme package. Runs on Bun.
