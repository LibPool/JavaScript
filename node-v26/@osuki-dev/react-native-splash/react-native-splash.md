# @osuki-dev/react-native-splash

> 标签: android, expo, intro, ios, launch-screen, nitro, nitro-modules, onboarding, react-native, reanimated, splash, splash-screen

## 简介

Splash and intro screens for React Native and Expo. The native launch screen hands off to your own React view and Reanimated animation without a flash. Nitro Modules, Swift + Kotlin, no AppDelegate or MainActivity edits.
