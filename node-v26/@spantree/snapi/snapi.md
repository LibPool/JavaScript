# @spantree/snapi

> 标签: cli, data, graphql, introspect, restore, snapshot, strapi, strapi v4, sync, v4

## 简介

Snapi is a CLI tool that snapshots content from one Strapi CMS 4 installation to restore to another

- 官网：https://github.com/Spantree/snapi
- 源码仓库：git+https://github.com/Spantree/snapi.git
- npm 页面：https://www.npmjs.com/package/@spantree/snapi
