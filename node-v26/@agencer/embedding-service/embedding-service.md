# @agencer/embedding-service

> 标签: JavaScript

## 简介

Local sentence-transformer embedding service for Agencer operatives. Ships a bundled Python Flask server (all-MiniLM-L6-v2, 384-dim) plus a TypeScript client with graceful-absence semantics.
