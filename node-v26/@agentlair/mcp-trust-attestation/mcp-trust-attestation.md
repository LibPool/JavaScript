# @agentlair/mcp-trust-attestation

> 标签: agentlair, ai-agent, attestation, bhc-s, hono, mcp, middleware, model-context-protocol, sep-2133, trust

## 简介

Drop-in Hono middleware that mounts AgentLair's BHC-S behavioral trust descriptor and per-subject attestation endpoint on any HTTP-transport MCP server in 3 lines. Implements the SEP-2133 unofficial extension dev.agentlair/trust-attestation (BHC-S spec ur
