# @agentlair/audit-logger

> 标签: agent-monitoring, agentlair, ai-agent, anthropic, audit, claude, crewai, langchain, logging, observability

## 简介

Framework-agnostic agent action logger. Logs locally by default. Connect to AgentLair for persistent, queryable audit trails.
