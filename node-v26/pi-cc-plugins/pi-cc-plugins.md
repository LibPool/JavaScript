# pi-cc-plugins

> 标签: claude-code, extension, history, pi-package, prompt, summary

## 简介

Small Claude Code behaviours for the Pi coding agent: Ctrl+C keeps the cleared prompt for Up to bring back, and a one-line summary closes every agent run.
