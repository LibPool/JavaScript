# @oasts/binding-linux-x64-gnu

> 标签: api-client, codegen, compiler, fetch, msw, napi-rs, openapi, openapi3, rust, swagger, tanstack-query, typescript, zod

## 简介

OpenAPI-to-TypeScript compiler with fully typed errors, compile-time auth checks, and a zero-dependency fetch client — plus first-party Zod, TanStack Query, and MSW artifacts.
