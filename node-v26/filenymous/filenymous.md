# filenymous

> 标签: ci, cli, e2ee, encryption, file-sharing, file-transfer, nodejs, p2p, privacy, send-files, webrtc, wetransfer-alternative

## 简介

End-to-end encrypted peer-to-peer file sharing from the terminal or CI (WebRTC, AES-256-GCM, no account, no server storage). Interoperates with https://filenymous.eu/app/

- 官网：https://filenymous.eu/app/fonctionnalites/cli-npm/
- 源码仓库：git+https://github.com/Geoking2104/Filenymous.git
