# @gblin-protocol/agent-treasury

> 标签: agent, agentkit, base, gblin, mcp, treasury, usdc, x402

## 简介

A treasury for AI agents on Base: operating cash in USDC, surplus parked in GBLIN, and USDC pulled back just in time when an x402 invoice arrives. Library and CLI.
