# cz.xprees.codenames

> 标签: Codename, GDPR, Name Generator, Pseudonym, Unity

## 简介

Deterministic, human-friendly codenames (e.g. kind-edison) generated from any seed string. Use them instead of free-text names in logs and analytics.
