# @henols/vice-mcp

> 标签: 6502, 6510, c64, commodore-64, mcp, reverse-engineering, vice

## 简介

VICE emulator MCP server for C64 reverse-engineering: a stdio MCP server that proxies vice tools to a host VICE MCP server.
