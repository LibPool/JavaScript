# @aiphotostudio/mcp

> 标签: ai-photo-studio, mcp, model-context-protocol, photo-studio, self-care

## 简介

MCP server for Self Care (Photo Studio): products, free previews, material tuning, shader node graphs, model, texture and background uploads, paid silo shots (Blender only with no AI at all, or with the AI pass and four AI variants), product, room and roo
