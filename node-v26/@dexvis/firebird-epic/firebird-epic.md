# @dexvis/firebird-epic

> 标签: JavaScript

## 简介

ePIC experiment pack for the Firebird event display: the epic:// alias, ePIC datasets, TGeo cleanup rules and cut lists, geometry themes and post-processors, camera views and the collision intro, installed with one withEpic() call.
