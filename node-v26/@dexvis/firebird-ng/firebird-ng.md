# @dexvis/firebird-ng

> 标签: angular, event-display, firebird, particle-physics, three, webgpu

## 简介

Angular library of the Firebird event display: provideFirebird() and its with*() features, the display pages and <firebird-display>, the display services, and the code of the geometry and ROOT file workers.
