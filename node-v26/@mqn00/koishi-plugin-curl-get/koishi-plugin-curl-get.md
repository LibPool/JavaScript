# @mqn00/koishi-plugin-curl-get

> 标签: chatbot, curl, http, koishi, neri, plugin

## 简介

一个 Koishi 插件，可以发送 curl 请求，支持绑定命令、Cookie、User-Agent，并返回响应结果。
