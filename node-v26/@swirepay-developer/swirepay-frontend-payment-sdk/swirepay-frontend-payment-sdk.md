# @swirepay-developer/swirepay-frontend-payment-sdk

> 标签: svelte

## 简介

A framework-agnostic set of web components (Svelte 5 under the hood), distributed as a standalone bundle — embed them the same way you'd drop in a Stripe Elements `<script>` tag, no build step or framework required on the consuming page.
