# remote-fs-node

> 标签: agent, binding, cloud, drop-in, fs, http, mock-fs, remote, sftp, ssh

## 简介

Node.js fs-compatible module backed by HTTP. Drop-in replacement for require('fs') that routes all operations to a remote server via process.binding('fs') interception.
