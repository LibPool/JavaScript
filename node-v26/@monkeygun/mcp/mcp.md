# @monkeygun/mcp

> 标签: JavaScript

## 简介

MCP server for Monkeygun — every tool the Monkeygun agent has (inspect a source, quote, make/edit/render videos, library, channels, series that listen, publish) over the Monkeygun API with your API key.
