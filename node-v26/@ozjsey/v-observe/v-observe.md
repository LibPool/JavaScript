# @ozjsey/v-observe

> 标签: breakpoints, directive, dom-diff, in-view, intersection-observer, lazy-load, mutation-observer, observe, resize-observer, responsive, scroll, visibility, vue, vue3

## 简介

Vue 3 directive owning IntersectionObserver + ResizeObserver + MutationObserver in one binding — cross-observer gating, threshold-crossed events, diff payloads, unified state attribute
