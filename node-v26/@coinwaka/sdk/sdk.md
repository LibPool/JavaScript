# @coinwaka/sdk

> 标签: checkout, coinwaka, coinwaka-pay, crypto, kenya, m-pesa, merchant, mpesa, payment-links, payments, sdk, typescript, usdc, usdt, webhooks

## 简介

Official TypeScript and JavaScript SDK for the Coinwaka API. Build Coinwaka Pay, M-Pesa checkout, crypto settlement, payment links, webhooks, and merchant integrations.
