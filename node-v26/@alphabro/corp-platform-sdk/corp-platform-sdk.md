## 简介

앱용 얇은 SDK — 프록시가 넣은 신원 헤더·서명 토큰을 읽고 검증함. 인증하지 않음 (corp-platform 04-8 6절, 04-7 5절). 빌드한 JS + .d.ts로 npmjs.org에 공개 배포 (@alphabro/corp-platform-sdk — 토큰 없이 받음, T-515). 플랫폼 부품 저장소(ui/r — 테마·부품, corp-platform ui add가 읽음)도 같이 실림 — 코드가 아니라 파일이라 런타임 의존성은 그대로 없음
