# @loopingai/a2a-protocol

> 标签: a2a, agent2agent, ai-agents, eddsa, jwks, jwt, wire-contract, zero-trust

## 简介

Zero-dependency wire contract for Looping's A2A authentication: the claim names, well-known paths, and audience rule shared by token issuers and agent runtimes.
