# @loopingai/core

> 标签: a2a, agent2agent, agents-sdk, ai-agents, cloudflare-workers, durable-objects, eddsa, jwks, workflows, zero-trust

## 简介

Shared, mandatory foundation for Looping agents on Cloudflare Workers: zero-trust A2A, durable task lifecycle, delegation and subagent runtime, test harness.
