# @overstart/wslpath-fish

> 标签: cli, conversion, fish, path, shell, skill, windows, wsl

## 简介

wslpath-fish 是一个 Fish shell 插件，用于在 Windows 路径和 WSL 路径之间快速转换

- 官网：https://github.com/overstart/wslpath-fish#readme
- 源码仓库：git+https://github.com/overstart/wslpath-fish.git
- npm 页面：https://www.npmjs.com/package/@overstart/wslpath-fish

- 1.0.0

## 获取地址

- npm 安装：`npm install @overstart/wslpath-fish`
- npm registry：https://registry.npmjs.org/@overstart/wslpath-fish
- Node 要求：>=14.0.0
