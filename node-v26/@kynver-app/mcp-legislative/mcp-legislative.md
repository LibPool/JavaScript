# @kynver-app/mcp-legislative

> 标签: JavaScript

## 简介

Kynver Legislative Intelligence MCP server — search, read, track, and get alerted on U.S. state and federal legislation: bills, sponsors, roll calls, amendments, hearing calendars, tracked-bill workflow, and alerts.
