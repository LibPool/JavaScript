# @rbtrqa/cli

> 标签: agent, ai, email, mcp, model-context-protocol, qa, skills, testing, validation, webpage

## 简介

ArbiterQA — agent-native QA for emails and webpages. Installs the ArbiterQA skill (and Cursor MCP entry) and logs you in. Remote MCP: https://api.arbiterqa.com/mcp
