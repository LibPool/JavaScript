# rs3-api-extended

> 标签: lua, plugin, rs3, runescape, typescript-to-lua

## 简介

Runtime helpers for RuneScape 3 plugins written in TypeScript: definePlugin, event subscription, and the vars shim. Compiled to readable Lua and bundled into your plugin by rs3-plugin.
