# @imeshsan2008/fbdl

> 标签: JavaScript

## 简介

A tool that fetches downloadable links and captions from Facebook links using Puppeteer with stealth mode to bypass detection. It allows you to retrieve media URLs and associated captions for further processing or downloading.
