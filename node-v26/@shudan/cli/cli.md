# @shudan/cli

> 标签: agentic, agents, claude-code, cli, codex, cursor, expo, kanban, mobile, react-native, shudan, workflow

## 简介

CLI that installs a shared agentic workflow (.ai/ playbook + Codex/Claude/Cursor adapters) into Expo apps and orchestrates multi-agent runs via a Tauri desktop board.
