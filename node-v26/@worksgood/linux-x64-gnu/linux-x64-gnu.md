# @worksgood/linux-x64-gnu

> 标签: JavaScript

## 简介

Prebuilt WorksGood binaries (worksgood, wg, nex) for x86_64-unknown-linux-gnu. Installed automatically as an optional dependency of @worksgood/cli.

## 官网

- 官网：https://github.com/graphwork/wg
- 源码仓库：git+https://github.com/graphwork/wg.git
- npm 页面：https://www.npmjs.com/package/@worksgood/linux-x64-gnu
