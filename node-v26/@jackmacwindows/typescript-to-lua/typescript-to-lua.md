# @jackmacwindows/typescript-to-lua

> 标签: lua, transpiler, tstl, typescript

## 简介

A generic TypeScript to Lua transpiler. Write your code in TypeScript and publish Lua! (With ComputerCraft support)

- 官网：https://typescripttolua.github.io/
