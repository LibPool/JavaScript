# @hclonely/artitalk

> 标签: JavaScript

## 简介

Artitalk 是一个轻量级说说/动态发布组件，适合嵌入个人博客或静态站点。当前版本保留前端组件用法，并提供基于 Vercel + Neon Postgres 的服务端实现，用于替代 LeanCloud 依赖。
