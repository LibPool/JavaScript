# @srsholmes/svelte-code-input

> 标签: JavaScript

## 简介

Svelte Code Input is a small component for SvelteJS that allows you to create a lightweight text area component which will automatically syntax highlight the code you type in it. It is designed for basic use cases where you want to display code to the use
