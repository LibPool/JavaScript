# typedmailer

> 标签: amazon-ses, brevo, email, email-client, email-library, email-provider, email-sending, mail, mailer, mailgun, node, nodemailer, postmark, resend, sendgrid, ses, smtp, transactional-email, type-safe, typescript

## 简介

A type-safe Node.js email library with one API for Resend, Brevo, Postmark, SendGrid, Mailgun, Amazon SES, or SMTP.
