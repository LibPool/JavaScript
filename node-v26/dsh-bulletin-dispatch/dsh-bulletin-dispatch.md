# dsh-bulletin-dispatch

> 标签: JavaScript

## 简介

跨桌投递：认桌（读会话标题的 NN- 前缀）+ 按桌投递（单子挂在「桌」上，谁先来谁取走）+ 会话回收 + 给人看的状态表。一个包、多功能、可逐个开关。
