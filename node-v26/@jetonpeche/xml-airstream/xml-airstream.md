# @jetonpeche/xml-airstream

> 标签: ast, decorators, high-performance, json-to-xml, lexer, object-mapper, parser, serializer, state-machine, stream, streaming, typescript-decorators, xml, xml-parser, xml-to-json, zero-dependency

## 简介

High-performance, zero-dependency streaming XML parser and serializer. Features a state-machine lexer and decorator-based object-document mapping (ODM) for TypeScript.
