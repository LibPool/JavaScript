# @rendral/mcp

> 标签: html-to-pdf, mcp, model-context-protocol, og-image, pdf, rendral, screenshot

## 简介

MCP server for Rendral — HTML/URL to PDF, screenshots, OG images, PDF merge, watermark, split, page ops, form filling, encryption, compression and background jobs — as tools for any MCP-compatible AI agent.
