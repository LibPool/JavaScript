# @stoutmusclenugget/create-emitter

> 标签: JavaScript

## 简介

This package provides a flexible API for creating an event emitter that forces events to execute and resolve in the order in which they are called. This emitter supports both synchronous and asynchronous event handling, ensuring that events are processed
