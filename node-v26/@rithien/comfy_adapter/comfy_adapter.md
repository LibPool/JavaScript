# @rithien/comfy_adapter

> 标签: clusterio, clusterio-plugin, comfyfactorio, discord, factorio, factorio-polska

## 简介

Clusterio plugin: parses Comfy/factorio-polska scenario stdout tags ([DISCORD*], [ANTIGRIEF-LOG], [DATA-SET/GET], [JAIL], [TRUST]) and bridges to Discord + JSON datastore; global player-status (SQLite: ban/jail/trusted veterans) enforced lazily on join
