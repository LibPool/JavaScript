# @codebam/dsh-opensandbox

> 标签: agent, container, cordis, deepseek-harness, dsh, opensandbox, sandbox

## 简介

Run DeepSeek Harness command execution in OpenSandbox containers: an OpenSandbox-backed ctx.subprocess and container-world ctx.sandbox for dsh.
