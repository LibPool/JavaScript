# alpha-video-gpu-web

> 标签: alpha, alpha-video, animation, astc, canvas, ktx2, react, texture-compression, transparency, transparent-animation, transparent-video, video-player, webgl, webgl2, zstd

## 简介

Transparent (alpha) animations in a <canvas> from ASTC texture arrays in KTX2 files, drawn with WebGL 2, for plain JS/TS and React. Streams by range requests, with seeking and offline storage; the zstd decoder is bundled inline.
