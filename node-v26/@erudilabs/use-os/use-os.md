# @erudilabs/use-os

> 标签: alma, almamater, component, hooks, react, tailwind, ui, use-os

## 简介

use-os detects user&#x27;s os. Possible values are: undetermined, macos, ios, windows, android, linux. If os cannot be identified, for example, during server side rendering undetermined will be returned.
