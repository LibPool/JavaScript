> 标签: nestjs, parser, shortcode-parser, shortcodes, tpoxa, tpoxa-shortcodes, typescript, wordpress, wordpress-shortcodes

## 简介

WordPress-compatible [shortcode] parser for Node.js with an optional NestJS integration. Node.js equivalent of the PHP library tpoxa/shortcodes
