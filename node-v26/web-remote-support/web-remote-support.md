# web-remote-support

> 标签: JavaScript

## 简介

SDK สำหรับให้เจ้าหน้าที่ช่วยดูและควบคุมหน้าเว็บลูกค้า เมื่อลูกค้ายอมรับคำขอ ตัว SDK ไม่มี UI บังคับ: นำรหัส สถานะ และคำขออนุญาตไปแสดงด้วย HTML, Vue, React หรือ framework ที่ใช้อยู่ได้
