# @mythwork/protocol

> 标签: JavaScript

## 简介

Spec-first TypeScript definition of the Mythwork host <-> inner-app postMessage protocol: envelope types, handshake constants, the full method map, the event map, and the pure data types they reference. Also carries the per-project database wire contract
