# @shopkit/app-sdk

> 标签: apps-platform, iframe, ratio, rpc, sdk, shopkit

## 简介

The in-iframe library merchant-app developers npm-install. Reads init payload from window.__RATIO_APP_INIT__, exposes typed Promise-returning RPC, auto-injects the session JWT on fetch() calls to whitelisted origins.
