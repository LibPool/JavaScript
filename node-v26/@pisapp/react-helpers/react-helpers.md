# @pisapp/react-helpers

> 标签: JavaScript

## 简介

React 18+ helper for PIS v7 — compileComponent(). Bridges the Vue-reactive ctx to React so mutations to ctx fields re-render the mounted component; hosts the JSX tag augmentation.
