# @turtle.tech/mcpkit

> 标签: agents, mcp, model-context-protocol, tools, trellis, web, webmcp

## 简介

First-class WebMCP for Trellis — a type-safe facade over the browser document.modelContext API with a shared tool-descriptor registry, register/unregister lifecycle, discovery + execution client, and op-log provenance.
