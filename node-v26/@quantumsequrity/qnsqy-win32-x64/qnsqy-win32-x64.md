# @quantumsequrity/qnsqy-win32-x64

> 标签: cryptography, post-quantum, pqc, prebuilt-binary, qnsqy, quantum-safe, win32, windows, x64

## 简介

Prebuilt QNSQY binary for Windows x86_64. Installed automatically as an optional dependency of the `qnsqy` package. Do not install directly.
