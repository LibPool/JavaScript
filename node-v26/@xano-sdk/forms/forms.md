# @xano-sdk/forms

> 标签: backend, form-builder, forms, public, share-links, xano, xanosdk

## 简介

Public forms and read-only share links for a private Xano SDK app: a form builder, public forms validated server-side against the published schema (honeypot, minimum fill time, size caps, redis rate limit) into a triage inbox, and scoped, expiring, revoca
