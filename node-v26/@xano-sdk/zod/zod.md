# @xano-sdk/zod

> 标签: codegen, toolchain, validation, xano, xanosdk, zod

## 简介

Generates zod schemas for every endpoint, realtime channel, and realtime message input in a Xano SDK project's routes.gen.ts, from the same description as its TypeScript input types, so the two cannot drift.
