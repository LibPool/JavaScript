# @xano-sdk/chatbot

> 标签: agent, ai, ai-actions, backend, chat, chatbot, codegen, conversation, llm, xano, xanoscript, xanosdk

## 简介

Plug-and-play Xano AI chatbot (conversation/message tables + a Xano AI agent + chat endpoints) and inline AI actions on records (summarise, draft, extract with server-side validation), as typed Xano SDK defs.
