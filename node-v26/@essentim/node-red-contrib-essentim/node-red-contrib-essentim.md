# @essentim/node-red-contrib-essentim

> 标签: node-red

## 简介

Repository für ein Node-RED-Plugin. Es stellt eine Verbindung zur essentim Cloud her, um die flexible Verarbeitung von Daten aus der essentim Cloud zu ermöglichen.

## 官网

- npm 页面：https://www.npmjs.com/package/@essentim/node-red-contrib-essentim

- npm registry：https://registry.npmjs.org/@essentim/node-red-contrib-essentim
- Node 要求：>=22.0.0
