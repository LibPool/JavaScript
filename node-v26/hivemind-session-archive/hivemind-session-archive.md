# hivemind-session-archive

> 标签: archive, opencode, opencode-plugin, session, transcript

## 简介

OpenCode V2 plugin: persist the current session tree into a deterministic, project-scoped JSONL transcript archive plus a SQLite index, from a read-only view of the host session database.
