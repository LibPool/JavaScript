# alexa-echo-mcp

> 标签: alexa, alexa-remote2, echo, macos, mcp, model-context-protocol

## 简介

Small MCP server that drives your own Amazon Echo devices through the unofficial Alexa app session (alexa-remote2): speak a message, run a routine by name, or send a text command
