# @diegopetrucci/pi-openai-fast

> 标签: codex, fast, openai, pi, pi-package

## 简介

A pi extension that enables OpenAI Codex Fast mode for ChatGPT-auth GPT-5.5 and GPT-5.6 Codex variants by injecting the priority service tier.
