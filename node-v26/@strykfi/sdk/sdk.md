# @strykfi/sdk

> 标签: black-scholes, cash-secured-put, covered-call, defi, delta-neutral, options, premium-harvest, solana, structured-products, stryk, theta-vault, vault

## 简介

TypeScript SDK for STRYK -- the Solana structured products vault framework. Read vault snapshots, price options with Black-Scholes, and simulate premium harvest strategies.
