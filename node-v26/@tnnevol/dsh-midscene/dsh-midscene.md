# @tnnevol/dsh-midscene

> 标签: bridge, browser-automation, e2e, midscene, openai-compatible, ui-testing

## 简介

Hosts a loopback OpenAI-compatible bridge that exposes every model configured in DSH (official routes, plugin routes, and user-declared providers) so Midscene browser automation can drive pages with natural language without holding any credential itself.
