# @tnnevol/dsh-failover-search

> 标签: failover, fallback, fetch, search, tavily, tinyfish, web-search

## 简介

Composite DSH web-search provider that fails over TinyFish → Tavily → official DeepSeek, spreads requests across multiple accounts per platform, and shows platform usage on the plugin page.
