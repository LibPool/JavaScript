# @saketek/saki-builder

> 标签: agents, code-review, opencode-plugin, planning, safety-hooks, skills, tdd, workflow

## 简介

A personal-scale shared toolkit for AI coding agents: research→plan→build→qa→review skills, safety hooks, adversarial reviewers, domain agents, and an execution protocol. OpenCode plugin edition of the saki-builder Claude Code plugin.
