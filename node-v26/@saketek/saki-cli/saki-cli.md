# @saketek/saki-cli

> 标签: agent, claude, cli, codex, headless, omp, opencode, orchestrator

## 简介

Headless command line for the saki build orchestrator — drive a PRD → plan → build → QA → review journey from a terminal, on claude, codex, opencode or omp.
