# @yeetlaunch/yeet-amm-sdk

> 标签: amm, dex, sdk, solana, yeetamm, yeetlaunch

## 简介

TypeScript SDK for the YeetAMM program — PDA derivation, instruction builders, account decoding, error decoding, and a thin REST client. Pricing is served by the YeetLaunch API; no curve math is included.
