# @blotout/qinto-sdk-app

> 标签: JavaScript

## 简介

Qinto app SDK: the authoring surfaces for Qinto platform apps — defineApp (server) and defineBrowserApp (browser) plus their hook, context, and action types. Zero runtime dependencies.
