# @malipetek/dsh-ai-workspace

> 标签: cordis, deepseek-harness, dev-server, dsh, dsh-plugin, logs

## 简介

Managed dev processes for a project folder: start them in the background, capture their logs, show them in a panel, and tell the agent to read those logs instead of re-running build/dev commands.
