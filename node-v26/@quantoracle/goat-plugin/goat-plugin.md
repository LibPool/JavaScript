# @quantoracle/goat-plugin

> 标签: ai-agent, base, black-scholes, crossmint, evm, goat-plugin, goat-sdk, kelly-criterion, monte-carlo, onchain-agent, options-pricing, quant-finance, solana, x402

## 简介

Deterministic quant finance plugin for the GOAT SDK (Crossmint's onchain agent toolkit) — Black-Scholes, Kelly, Monte Carlo, full risk audit, hedge recommender, options, risk, DeFi tools. 15 tools across 4 opt-in bundles. Multi-chain (EVM + Solana) via x4
