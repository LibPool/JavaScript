# @crowdin/cli

> 标签: Automation, CI/CD, CLI, Client, Command-line interface, Crowdin, Integration, Localization, Sync, Synchronization, Translation, Translation management

## 简介

Crowdin CLI is a command line tool that allows you to manage and synchronize your localization resources with your Crowdin project
