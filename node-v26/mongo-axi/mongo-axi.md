# mongo-axi

> 标签: agent, axi, cli, mongo, mongodb, read-only, toon

## 简介

Read-only MongoDB CLI for agents - schemas inferred from samples, capped find/aggregate/count/distinct/explain in token-efficient TOON. No JavaScript is evaluated; write stages are refused and every command is checked against a read allowlist before it is
