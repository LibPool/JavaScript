# @prioritysupport.mobi/psmdoc

> 标签: Documentation, and, easy, versioned

## 简介

Generate documents, websites, mobile apps (offline), and PDFs from psmdoc structured files, adding support for multiple versions and languages to keep them updated and maintained from a single source. (DEVELOPMENT STATUS).
