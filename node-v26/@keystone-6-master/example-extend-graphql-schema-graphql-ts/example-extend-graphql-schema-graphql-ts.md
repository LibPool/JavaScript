# @keystone-6-master/example-extend-graphql-schema-graphql-ts

> 标签: JavaScript

## 简介

This project demonstrates how to extend the GraphQL API provided by Keystone with custom queries and mutations using [graphql-ts](https://github.com/Thinkmill/graphql-ts). It builds on the [Blog](../blog) starter project.
