# @castlabs/prestoads-dashjs-plugin

> 标签: JavaScript

## 简介

Adapts a [dash.js](https://github.com/Dash-Industry-Forum/dash.js) player for PRESTOads, so ad playback events are derived from the player rather than reported by hand. DASH `EventStream` breaks are scheduled off the media timeline.
