# @libster/smart-state

> 标签: empty-state, error-state, loading, react, smart-component, state-management, typescript, ui-component

## 简介

A production-ready React component that automatically renders the correct UI based on application state — loading, error, empty, offline, unauthorized, forbidden, notFound, maintenance, or success.
