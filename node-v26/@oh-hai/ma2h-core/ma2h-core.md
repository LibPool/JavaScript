# @oh-hai/ma2h-core

> 标签: JavaScript

## 简介

OH HAI — shared MA2H reference core (vendored crypto/lifecycle/validation): JCS canonicalization, detached HMAC signing, AES-256-GCM state-seal, ajv envelope validators, id generators, conformance-vector runner. Consumed by @oh-hai/server, @oh-hai/scripts
