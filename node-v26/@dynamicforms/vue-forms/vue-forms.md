# @dynamicforms/vue-forms

> 标签: data entry, dynamicforms, form-management, form-state, forms, reactive, typescript, validation, vue, vue3

## 简介

A Vue.js library for form state management with built-in validation, conditional logic, nested structures, and a rich event system. UI-agnostic and TypeScript-first.
