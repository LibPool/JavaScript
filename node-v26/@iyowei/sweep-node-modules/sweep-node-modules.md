# @iyowei/sweep-node-modules

> 标签: bun, cleanup, cli, disk-usage, node-modules, nodejs

## 简介

工作区级 node_modules 清理工具: 一次扫描多个根目录, 跨项目列出体积, 确认后批量删除。
