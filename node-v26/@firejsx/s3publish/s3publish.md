# @firejsx/s3publish

> 标签: JavaScript

## 简介

Simple, small FireJSX plugin, which puts exported files from FireJSX to a S3 Bucket

## 官网

- 源码仓库：https://github.com/eAdded/FireJSX-S3Publish.git
- npm 页面：https://www.npmjs.com/package/@firejsx/s3publish
