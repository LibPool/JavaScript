# rasso-plugin-disk-cleaner

> 标签: JavaScript

## 简介

磁盘大文件定位与安全空间清理器：可视化层级分析目录空间占用、一键检索超大孤儿文件与废弃缓存、移入安全隔离回收区释放宝贵磁盘空间
