# @floegence/flowersec-node-native-linux-arm64-gnu

> 标签: JavaScript

## 简介

This package contains the Linux arm64 glibc prebuilt used by `@floegence/flowersec-node-native`. Applications should use `@floegence/flowersec-core/node` rather than importing this package directly.
