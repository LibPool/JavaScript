# @grafloria/vue

> 标签: dashboard, dashboard-layout, diagram, flowchart, graph, layout, node-editor, svg, vue, vue3, workflow-editor

## 简介

Vue 3 bindings for Grafloria Diagrams and Grafloria Dashboards — an MIT diagram and dashboard engine: routing, auto-layout, undo, collaboration and dashboard layouts, native in Vue.
