# superlytics

> 标签: analytics, attribution, error-tracking, nextjs, opentelemetry, revenue, superlytics

## 简介

Superlytics helpers: visitor ids for checkout metadata, a server client with error reporting, server-side experiment assignment, Next.js crawler and error reporting, one-line Next.js OpenTelemetry export, and a source map upload CLI.
