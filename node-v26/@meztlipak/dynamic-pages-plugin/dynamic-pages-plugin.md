# @meztlipak/dynamic-pages-plugin

> 标签: dynamic, ejs, html, multi-page, plugin, webpack

## 简介

Webpack plugin that auto-discovers page entries and emits EJS-rendered HTML files, injecting the compiled JS/CSS assets for each entry point.
