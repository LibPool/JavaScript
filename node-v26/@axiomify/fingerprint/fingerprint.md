# @axiomify/fingerprint

> 标签: axiomify, bot-detection, fingerprinting, fraud-prevention, http-headers, request-fingerprint, session-security

## 简介

Server-side request fingerprinting for Axiomify — confidence-scored client identification from headers, IP, and TLS hints.
