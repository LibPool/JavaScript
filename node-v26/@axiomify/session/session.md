# @axiomify/session

> 标签: authentication, axiomify, cookies, session, session-store, signed-cookies

## 简介

Cookie sessions for Axiomify — signed session cookies, pluggable stores (memory shipped, Redis/DB via SessionStore interface), rolling expiry and ID regeneration.
