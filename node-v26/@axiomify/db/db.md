# @axiomify/db

> 标签: axiomify, database, di, drizzle, mysql, postgres, prisma, sqlite

## 简介

Database integration for Axiomify — register any client (Prisma, Drizzle, pg, mysql2, better-sqlite3) through DI with health checks, graceful shutdown and vault-scoped credentials.
