# @ripdotfun/cardos-sdk

> 标签: card prices, cardos, gacha, mystery pack, one piece, pokemon, rip.fun, sdk, tcg

## 简介

Official TypeScript SDK for the CardOS APIs — gacha / mystery packs, instant packs, custodial wallets, buybacks, redemptions, webhooks, and the Card Data catalog.
