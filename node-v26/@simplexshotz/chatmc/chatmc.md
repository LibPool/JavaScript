# @simplexshotz/chatmc

> 标签: chat, get, mc, minecraft

## 简介

This module implements several functions to enable the easy use and interaction with in-game Minecraft chat. This module supports the Vanilla, Badlion, and Lunar clients. There are no dependencies.
