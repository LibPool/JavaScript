# @vttforge/core

> 标签: foundry-vtt, foundryvtt, sdk, typescript, vtt

## 简介

Runtime for Foundry VTT v14+ systems and modules: registerSystem, registerModule, typed data models, sheet bases, settings, migrations, error registry.
