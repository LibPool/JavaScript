# @tombruce/agent-bridge

> 标签: agent, bridge, claude, cli, codex, cursor, gemini, llm

## 简介

本地 coding-agent CLI 的统一桥接层：检测（detect）、调用（invoke）、协议解析（parse）。零 API key，复用本机已登录 CLI 会话。
