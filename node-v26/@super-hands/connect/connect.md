# @super-hands/connect

> 标签: components, design-system, design-tokens, mcp, superhands

## 简介

Connect the coding agents on this machine to your team's Superhands MCP server — with `start`, from a machine that has no Superhands account at all. Refresh it later with `update` (no token needed), and take it back off again with `uninstall`. Writes each
