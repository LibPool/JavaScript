# @vocabulary/sh

> 标签: JavaScript

## 简介

This package contains a snapshot of the SHACL vocabulary with the addition of an unofficial rendition of the latest [SHACL Advanced Features](https://w3c.github.io/shacl/shacl-af/)  draft.
