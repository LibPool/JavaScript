# @marrowdev/cli

> 标签: change-tracking, cli, crawler, flux, marrow, monitoring, ndjson, web-scraping

## 简介

Marrow data CLI — read / scout / search / crawl / batch / screenshot / monitor / usage from your shell. Flux NDJSON by default (pipes into flux-tools / hsh-bash), --md for humans, --sections to build a RAG corpus. Thin wrapper over the Marrow edge API.
