# ai-sdk-harness-network

> 标签: ai, ai-sdk, ai-sdk-harness, allowlist, claude-code, codex, coding-agent, cursor, egress, github-copilot, harness, network, network-policy, opencode, sandbox

## 简介

The hosts an AI SDK harness agent's sandbox may reach: trusted lists for the forges, registries, toolchains and container registries of the whole ecosystem, the hosts of each harness and model provider, and a closed network policy built from them.
