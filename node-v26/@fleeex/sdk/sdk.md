# @fleeex/sdk

> 标签: fleeex, llm, metering, openai, proxy, sdk, wallet

## 简介

Thin fleeex wrapper over the OpenAI SDK: preconfigured base URL, key and x-fleeex-user header, plus billing helpers. The wire stays iso-OpenAI, so dropping back to the raw OpenAI SDK is always possible.
