# @zandoh/keysmith

> 标签: a11y, accessibility, chords, framework-agnostic, headless, hotkeys, keybindings, keyboard-shortcuts, remapping, sequences, shortcut-manager, shortcuts, wcag

## 简介

Keyboard shortcut manager for the web: commands, scopes, sequences, and user remapping. Fast, headless, accessible, framework agnostic.
