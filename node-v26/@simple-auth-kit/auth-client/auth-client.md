# @simple-auth-kit/auth-client

> 标签: JavaScript

## 简介

Shared, framework-agnostic auth API client for the simple-auth-kit backend. Used by all 4 client apps (admin-nextjs, admin-react, mobile-expo, mobile-bare-rn) — the auth flow and API contract are identical across them, only the injected TokenStorage adapt
