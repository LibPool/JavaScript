# @spikedpunch/create-align

> 标签: align, architecture, bootstrap, conformance, create, dependency-graph, scaffold, static-analysis

## 简介

Bootstrap align (architecture-conformance verification) into an existing repo: installs @spikedpunch/align-cli and @spikedpunch/align-core as local devDependencies, lockstep-pinned to this package's own version, then delegates to `align init`.
