# @lumifai/harness-model-claude-oauth

> 标签: JavaScript

## 简介

Mastra model gateway that bills Anthropic requests to a Claude subscription (Pro, Max, Team, or Enterprise) instead of a console API key. Registering it lets any harness model string of the form `claude-oauth/anthropic/<model-id>` run against `api.anthrop
