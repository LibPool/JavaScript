# @quantumverifi/clerk

> 标签: JavaScript

## 简介

Customer-side QuantumVerifi Bridge handler for Clerk (Next.js App Router). Secret-free delegated-ticket auth: verify QuantumVerifi's signed request and return only a short-lived Clerk sign-in ticket.
