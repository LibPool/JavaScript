# @quantumverifi/auth-protocol

> 标签: JavaScript

## 简介

QuantumVerifi ↔ customer Bridge wire contract (delegated-ticket auth). v1: raw-JSON-body HMAC-SHA256, verified over the raw request bytes. Byte-compatible with internal/gatekeeper/delegation/authprotocol (Go).
