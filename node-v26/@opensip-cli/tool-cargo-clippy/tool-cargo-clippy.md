# @opensip-cli/tool-cargo-clippy

> 标签: cargo-clippy, clippy, code-quality, external-tool-adapter, linting, opensip-cli, rust, scanner, static-analysis

## 简介

External Tool Adapter for cargo clippy — wraps Rust lint diagnostics as an opensip-cli tool. Determinism caveat: cargo clippy only re-emits diagnostics for crates it recompiles; a warm target/ cache can yield zero findings. Use a cold cache or set CARGO_T
