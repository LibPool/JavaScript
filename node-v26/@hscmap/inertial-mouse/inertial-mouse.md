# @hscmap/inertial-mouse

> 标签: JavaScript

## 简介

Inertial Mouse for TypeScript * Wraps native MouseEvent and emit pseudo mousemove events with inertial smooth motion. * [Working Demo](https://michitaro.github.io/inertial-mouse)
