# @linksanctuary/mcp

> 标签: claude, imessage, links, mcp, model-context-protocol, sanctuary

## 简介

MCP server for Sanctuary — lets AI assistants ask about the links (and, with the Profile switch on, the context) from your iMessage conversations, without ever handing them your messages. Companion to the Sanctuary macOS app.
