# @crafter/sismo-cli

> 标签: agent-first, cli, colombia, earthquakes, igp, open-data, peru, sgc, sismos

## 简介

Datos sísmicos públicos de Perú (IGP) y Colombia (SGC) desde terminal, con procedencia trazable, JSON, GeoJSON y exit codes estables.
