# @forgeax/engine-wgpu-wasm

> 标签: JavaScript

## 简介

Merged wgpu 29 + naga 29 wasm-bindgen crate exposing RHI + shader-pipeline raw bindings to JS; consumed by @forgeax/engine-rhi-wgpu + @forgeax/engine-naga thin shells. AI engine users do not import this package directly.
