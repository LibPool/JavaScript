# @mavware/bug-surveillance

> 标签: browser, camera, computer-vision, indexeddb, motion-detection, object-tracking, offline, pest-control, surveillance

## 简介

Overnight bug surveillance from a browser camera: detection, tracking, a local night store, analytics and replay, with no server required.
