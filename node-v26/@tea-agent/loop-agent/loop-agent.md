# @tea-agent/loop-agent

> 标签: JavaScript

## 简介

> Console SSH 管理：终端面板内可维护主机、扫描并固定 SHA256 主机指纹、使用系统凭据库保存密码/私钥口令、测试连接和执行远程命令；Operator Chat 同时提供 `ssh_list`、`ssh_test`、`ssh_exec`、`ssh_transfer` 受控工具。文件传输的本地路径被限制在当前工作区。
