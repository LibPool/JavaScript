# @nazarf/qrforge

> 标签: cloudflare-workers, dynamic-qr, qr, qrcode, svg

## 简介

Runtime-agnostic QR code generation — works on Cloudflare Workers, Node, and browsers. Pure SVG core, zero DOM dependency.
