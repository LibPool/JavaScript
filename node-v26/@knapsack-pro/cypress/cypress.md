# @knapsack-pro/cypress

> 标签: CI, automation, cypress, cypress.io, e2e, end-to-end, integration, knapsack, knapsack pro, parallelisation, runner, test, test suite parallelisation, testing

## 简介

Knapsack Pro Cypress splits Cypress.io tests across CI nodes and makes sure that tests will run in optimal time on each CI node.
