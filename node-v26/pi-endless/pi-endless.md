# pi-endless

> 标签: endless-chat, memory, optchat, pi-extension, pi-package

## 简介

One chat that never ends, for pi: the chat itself is the memory (Taelin's OptChat/UniiChat recipe). Opt-in per conversation; zoom, search and date tools; nothing is ever lost.
