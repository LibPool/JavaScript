# @clarkchan/trajectory-reader

> 标签: client-plugin, deepseek-harness, dsh, interpret, trajectory

## 简介

轨迹解读 · Trajectory Reader — a DeepSeek Harness web client plugin that adds a new 轨迹解读 tab beside 对话/轨迹. It segments the session by user turns and, per round, highlights the condensed 用户需求 and how the assistant fulfilled it (规划/调研/实现/验证/委派 action summaries,
