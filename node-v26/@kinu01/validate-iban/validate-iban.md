# @kinu01/validate-iban

> 标签: banking, cloudflare-workers, commonjs, esm, iban, iso-13616, iso-7064, mod-97, sepa, typescript, validation, validator

## 简介

IBAN validator. ISO 13616 structure plus ISO 7064 mod-97-10 check digits. Zero dependencies, TypeScript types, ESM and CommonJS. Runs on Node, Cloudflare Workers and in the browser.
