# @kinu01/re-anchor

> 标签: anchoring, annotation, approximate, commonjs, esm, fuzzy, highlight, range, selector, text-position, text-quote, typescript, w3c-annotation

## 简介

Find a quote in a text (or on a page) again after it changed: W3C TextQuote + TextPosition selectors over normalised text, exact match first, context scoring among duplicates, bounded approximate search, and an honest null when the quote is gone. Optional
