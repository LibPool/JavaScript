# @ceyhuncicek/pixel-snap-cli

> 标签: cli, pixel-art, pixel-snap, png, sprite

## 简介

Pixel-snap PNGs in a folder: reduces to pixel-art resolution then upscales back to original size via nearest-neighbor.
