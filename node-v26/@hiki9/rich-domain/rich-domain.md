# @hiki9/rich-domain

> 标签: Base Aggregate, Base Entity, Base Value Object, Business Logic, Clean Architecture, Complexity, DDD, DDD-Utils, Domain Driving Design, Domain Events, NodeJS, Typescript, Use Cases

## 简介

Rich Domain is a library that provides a set of tools to help you build complex business logic in NodeJS using Domain Driven Design principles.
