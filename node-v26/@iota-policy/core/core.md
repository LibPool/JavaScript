# @iota-policy/core

> 标签: agent-policy, agents.yaml, ai-agent, iota, permissions, policy-engine, security

## 简介

iota policy engine: parse agents.yaml, merge layers tighten-only, evaluate operations to allow | deny | ask. Pure, synchronous, no I/O.
