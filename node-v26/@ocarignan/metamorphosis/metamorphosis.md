# @ocarignan/metamorphosis

> 标签: animation, font, glyph-morph, glyph-morphing, icon, icon-morph, icon-morphing, letter, morph, morphing, react, spring, svg, text, text-morph, transition

## 简介

Morphing animation library — morphing text, line-drawn icons, and per-character font-outline glyphs. Framework-agnostic core + React adapters (text/icon are dependency-free; glyph morphing uses fontkit).
