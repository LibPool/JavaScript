# @servicetitan/anvil2-charts-kit

> 标签: JavaScript

## 简介

Anvil2 web chart host: declarative <Chart>, palette helpers, and EChartsOption types. Install echarts as a peer; import from this package, not from anvil2-charts-core or echarts.
