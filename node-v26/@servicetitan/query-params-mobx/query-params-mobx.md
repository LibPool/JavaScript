# @servicetitan/query-params-mobx

> 标签: micro-frontend, mobx, mobx-store, nuqs, observable, query-params, search-params, state-management, typescript, url-state

## 简介

MobX-native library that syncs observable store state with the URL query string. Provides declarative, type-safe URL state management with parser builders, adapters, and automatic serialization.
