# @argus-profiler/mcp

> 标签: argus, claude, mcp, model-context-protocol, profiling, unity

## 简介

Model Context Protocol server for Argus profiling captures. Lets your local Claude (Desktop or Code) analyse Unity profiling data using your own Claude subscription — no Argus-side LLM token spend.
