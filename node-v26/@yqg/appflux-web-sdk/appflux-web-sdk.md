# @yqg/appflux-web-sdk

> 标签: JavaScript

## 简介

`AppFluxTool` 是一个用于管理设备 ID 和请求拦截的工具类，它能够在应用启动时自动绑定设备 ID，且能够通过拦截 XMLHttpRequest 和 fetch 请求来修改请求头和请求 URL，适用于调试和测试环境。
