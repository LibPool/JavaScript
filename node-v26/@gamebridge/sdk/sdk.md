# @gamebridge/sdk

> 标签: account, auth, cloudbase, gamebridge, sdk

## 简介

GameBridge 游戏客户端 SDK：平台账号（注册/登录/匿名/跨应用授权）浏览器直连 CloudBase Auth，含演示降级模式。
