# @daxu8972/dsh-git

> 标签: cordis, deepseek, dsh, git, plugin

## 简介

DSH 外置 Git 插件：git 工具（status/diff/log/add/commit/pull/push/switch/restore/stash 等）+ VSCode/IDEA 式可视化 Git 面板（变更/提交/分支管理/储藏/历史浏览）。
