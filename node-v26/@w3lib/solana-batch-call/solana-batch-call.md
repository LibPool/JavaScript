# @w3lib/solana-batch-call

> 标签: batch, batch-transfer, getMultipleAccounts, json-rpc, metaplex, orca, raydium, solana, spl-token, swap, token-2022

## 简介

Batched Solana reads: SOL / SPL / Token-2022 balances, token metadata, NFTs; batch transfer, collect and program calls (packed transactions, fee payer). Auto-batching JSON-RPC, getMultipleAccounts chunking, RPC failover. No Solana SDK dependency.
