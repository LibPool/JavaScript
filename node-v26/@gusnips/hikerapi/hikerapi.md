# @gusnips/hikerapi

> 标签: api-client, hikerapi, instagram, scraping, social-media, typescript

## 简介

Unofficial TypeScript SDK for the HikerAPI Instagram data API: profiles, posts, reels, stories, comments, followers, hashtags, locations and search
