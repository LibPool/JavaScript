# @gusnips/cnpj

> 标签: brasilapi, brazil, cnpj, company, lookup, receita-federal, typescript

## 简介

Look up a Brazilian company by CNPJ, the new CNPJ with letters too. Your own registry server first if you have one, then Minha Receita, BrasilAPI, cnpj.ws and ReceitaWS, all mapped to one record. Uses only fetch: runs in Node, Bun, browsers and Workers.
