# @mieditor/sveltekit

> 标签: JavaScript

## 简介

`@mieditor/sveltekit` 是面向 SvelteKit 的 UI Editor 集成包。它基于 `@mieditor/svelte`，并默认使用 Vite 中间件注入运行时和编辑面板，更适合 SvelteKit 的 HTML 输出方式。
