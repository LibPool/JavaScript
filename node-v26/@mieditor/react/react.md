# @mieditor/react

> 标签: JavaScript

## 简介

`@mieditor/react` 为 React + Vite 项目提供 UI Editor 开发期集成。插件会在 JSX/TSX 中注入 `data-mi-editor-id`，收集元素样式元数据，并提供编辑面板所需的开发服务器接口。
