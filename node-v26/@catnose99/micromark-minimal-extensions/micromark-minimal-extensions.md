# @catnose99/micromark-minimal-extensions

> 标签: JavaScript

## 简介

最小構成の micromark 拡張セットです。HTTPS から始まる URL の自動リンク化と、パイプ区切りのテーブル構文（整列指定付き）のみをサポートします。
