# @npm-zenwork/990embedding

> 标签: 8868, 990ez, 990pf, 990t, embedded-sdk, form990, irs, nonprofit-tax, tax-form, zenwork

## 简介

Embeddable IRS Form 990 series tax-form UI SDK (990, 990-T, 990-EZ, 990-PF, 990-N, 8868) — single JavaScript bundle, similar in spirit to Stripe.js.
