# @originallyus/feedback-web-sdk

> 标签: JavaScript

## 简介

Feedback SDK is a JavaScript library to collect user feedback through web browsers. The SDK supports multiple feedback form types including NPS, Satisfaction, Comment, Poll, and External Survey.
