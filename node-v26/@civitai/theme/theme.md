# @civitai/theme

> 标签: civitai, css-variables, design-tokens, dtcg, mantine, theme

## 简介

Framework-agnostic --civitai-* design tokens, derived build-time from civitai's real Mantine theme. CSS + typed JS + W3C DTCG.
