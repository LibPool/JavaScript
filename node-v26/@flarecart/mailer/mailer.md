# @flarecart/mailer

> 标签: cloudflare-email, email, mailer, mailgun, postmark, resend, sendgrid, transactional-email, workers

## 简介

Transactional email through interchangeable transports — Cloudflare Email (a Worker's send_email binding), Resend, Postmark, Mailgun, SendGrid, plus memory and log for development. One message shape, checked before it leaves; failures say whether a retry
