# @flarecart/r2-storage

> 标签: cloudflare-r2, cloudflare-workers, content-disposition, direct-upload, multipart-upload, presigned-url, r2, s3, signed-url, storage

## 简介

A Cloudflare R2 bucket behind one storage interface: the binding reads, R2's S3 API signs presigned downloads that save under the file's name, create-only presigned uploads, multipart, and copies inside the bucket. The bytes go between the browser and R2,
