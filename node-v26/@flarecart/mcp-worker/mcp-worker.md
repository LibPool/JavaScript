# @flarecart/mcp-worker

> 标签: ai-agents, cloudflare-workers, mcp, model-context-protocol, stateless, streamable-http, tools

## 简介

An MCP server in a fetch handler — Cloudflare Workers, Deno, Bun, Hono. Stateless Streamable HTTP with JSON responses, an auth hook, and tool results and errors a model can read.
