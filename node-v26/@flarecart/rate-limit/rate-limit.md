# @flarecart/rate-limit

> 标签: circuit-breaker, cloudflare, d1, rate-limit, rate-limiting, sliding-window, throttle, workers

## 简介

Sliding-window rate limits with an atomic store (memory or Cloudflare D1), named rules, a circuit breaker for total load, and Cloudflare's rate-limiting bindings. The JS twin of SugarCommerce's PHP rate-limit.
