# @lingjing-agent/tools

> 标签: JavaScript

## 简介

Built-in tools for @lingjing-agent/core, one package: main entry is cross-runtime web tools (web_search/read_feed/fetch_json/web_fetch, zero node: imports); the ./node subpath adds Node-only tools (fs/shell/glob/grep) and the Readability extractor.
