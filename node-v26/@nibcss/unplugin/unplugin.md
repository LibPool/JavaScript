# @nibcss/unplugin

> 标签: atomic-css, attributes, css, nib, utility-css

## 简介

Build-time NibCSS: extract [nib] attributes, emit static CSS, HMR. Works with Vite, Webpack, Rspack, Rollup, esbuild.
