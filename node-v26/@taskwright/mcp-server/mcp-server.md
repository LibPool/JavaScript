# @taskwright/mcp-server

> 标签: JavaScript

## 简介

Taskwright MCP server — exposes Taskwright operations as tools to any MCP-capable agent (Claude Code, Codex, Gemini, Cursor). Used by the chat-assistant Job role; can also be installed standalone in a user's local agent.
