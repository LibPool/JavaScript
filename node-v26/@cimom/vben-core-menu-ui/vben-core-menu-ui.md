# @cimom/vben-core-menu-ui

> 标签: JavaScript

## 简介

Menu UI 组件是一个基于 Vue 3 的高度可定制化菜单组件，支持垂直和水平布局、折叠模式、主题切换等功能，适用于各种导航菜单场景。
