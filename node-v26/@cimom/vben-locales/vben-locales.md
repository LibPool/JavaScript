# @cimom/vben-locales

> 标签: JavaScript

## 简介

国际化（i18n）工具包，提供了多语言支持功能，基于 vue-i18n 实现，支持动态加载语言包和语言切换。

- 源码仓库：git+https://github.com/vbenjs/vue-vben-admin.git
