# @cimom/vben-preferences

> 标签: JavaScript

## 简介

用户偏好设置管理包，提供了一套完整的用户偏好设置管理机制，用于存储和管理用户的主题、语言、布局等偏好设置。该包继承了 `@cimom/vben-core-preferences` 的所有能力，并允许在应用级别覆盖默认偏好设置。
