# @cimom/vben-core-shadcn-ui

> 标签: JavaScript

## 简介

Shadcn UI 组件是一个基于 Vue 3 的 UI 组件库，提供了丰富的基础组件和高级组件，采用了现代化的设计风格，支持主题定制和响应式设计。
