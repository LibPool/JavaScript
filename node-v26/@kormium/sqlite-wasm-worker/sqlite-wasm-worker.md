# @kormium/sqlite-wasm-worker

> 标签: JavaScript

## 简介

Standalone Worker RPC endpoint over kormium/sqlite-wasm-kt's SqliteWasmConnection. Built by :sqlite-wasm-kt-worker. Raw ESM (not webpack-bundled) so a consumer's own bundler can trace and emit @sqlite.org/sqlite-wasm's asset dependencies itself.
