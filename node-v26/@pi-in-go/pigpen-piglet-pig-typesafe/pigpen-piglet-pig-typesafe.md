# @pi-in-go/pigpen-piglet-pig-typesafe

> 标签: go, pig-piglet, pigpen

## 简介

The typesafe_evaluate tool and /typesafe command (Go port of pi-typesafe). Off until enabled; content goes to api.typesafe.ai unless the own-model backend (the model PiG is configured with) is selected.
