# @pi-in-go/pigpen-pi-typesafe-api

> 标签: jev, library, pig-package, pigpen, typesafe

## 简介

Typed Go API for extension authors, a port of pi-typesafe's library half: one admission rule, request and spend caps, key store and auth state, judgment backends (TypeSafe, OpenRouter, Command Code, custom endpoint, own model), Ask, batching, calibration.
