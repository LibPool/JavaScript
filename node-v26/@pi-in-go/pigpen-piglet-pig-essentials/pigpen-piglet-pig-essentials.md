# @pi-in-go/pigpen-piglet-pig-essentials

> 标签: go, pig-piglet, pigpen

## 简介

A fast single-binary PiG with the essentials, no Node: web search and fetch (rpiv-web-tools), sub-agents (tintinweb pi-subagents, a tested slice), Claude Code-style task tracking (tintinweb pi-tasks), structured questions (rpiv-ask-user-question), the pon
