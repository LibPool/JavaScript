# @pi-in-go/pigpen-permissions

> 标签: extension, permissions, pig-package, pigpen, policy, security

## 简介

Go port of pi-permission-system: allow, ask and deny rules for tool calls, with last-match-wins wildcard patterns and a tool_call gate (partial: the rule engine and tool-name gating, not the approval dialog, bash parsing or path rules)
