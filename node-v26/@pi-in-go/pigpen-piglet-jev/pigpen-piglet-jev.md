# @pi-in-go/pigpen-piglet-jev

> 标签: go, pig-piglet, pigpen

## 简介

PiG with Jev, a typed judge for tool calls and tool output (destructive? leaks data? beyond scope? secret in the output?). Off until you run /jev on, which shows what leaves the machine first; it fails open.
