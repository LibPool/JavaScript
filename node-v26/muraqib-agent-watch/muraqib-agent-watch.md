# muraqib-agent-watch

> 标签: agent-security, ai-agent, ai-safety, mcp, model-context-protocol

## 简介

Free, instant capability check for any MCP server: lists what it can actually do (money, files, outbound messages, destructive actions, credentials) and flags tools that don't state their own safeguard, so you know what to review before trusting an AI age
