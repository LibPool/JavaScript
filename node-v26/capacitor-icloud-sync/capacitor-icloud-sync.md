# capacitor-icloud-sync

> 标签: backup, capacitor, cloudkit, icloud, ios, native, plugin, save-data, sync

## 简介

Silent, automatic iCloud backup for Capacitor apps. No sign-in screen, no account creation — just uses whatever iCloud account is already signed into the device, scoped automatically to that account via CloudKit's private database.
