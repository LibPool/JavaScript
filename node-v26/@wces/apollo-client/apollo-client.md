# @wces/apollo-client

> 标签: JavaScript

## 简介

A simple package that re-export [@apollo/client](https://www.npmjs.com/package/@apollo/client) and [graphql-tag](https://www.npmjs.com/package/graphql-tag) as es6 modules compatible with web-components.
