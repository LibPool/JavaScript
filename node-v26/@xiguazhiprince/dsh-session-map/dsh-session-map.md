# @xiguazhiprince/dsh-session-map

> 标签: deepseek-harness, dsh, dsh-plugin, fork-tree, git, session, visualization

## 简介

Session map: a turn-tree canvas over every DSH session — users' turns are nodes, sessions are coloured lines and tags, and forks leave from the exact inherited turn — as a Conversation tab and two right-sidebar tabs. Also adds a Settings → Clone from Git
