# retoucher

> 标签: ai-agent, claude-code, codex, cursor, figma, figma-plugin, mcp

## 简介

Your coding agent, inside Figma. Leave notes on Figma layers; Claude Code, Codex or Cursor edits the file and answers in the panel.
