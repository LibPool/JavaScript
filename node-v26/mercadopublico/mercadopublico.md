# mercadopublico

> 标签: chile, chilecompra, compras-publicas, licitaciones, mercadopublico, sdk

## 简介

SDK TypeScript para la API de Mercado Público (ChileCompra): v1, Compra Ágil v2 y OCDS en un solo modelo, con control de cuota.
