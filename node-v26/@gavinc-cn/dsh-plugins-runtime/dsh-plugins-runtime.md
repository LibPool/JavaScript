# @gavinc-cn/dsh-plugins-runtime

> 标签: bundle, cordis, deepseek-harness, dsh, plugin, runtime

## 简介

DSH 插件组合包（runtime bundle）：8 个宿主（node）侧组件（记忆、git/文件守卫、只读闸门、路径规则闸门、写入守卫、重开会话再注入等），每个是一行独立开关；面向 Web GUI 的组件见 @gavinc-cn/dsh-plugins-ui。
