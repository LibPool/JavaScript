# @ekwo-ai/xaf

> 标签: accounting, audit-file, auditfile, bookkeeping, import, migration, parser, xaf, xml

## 简介

Reads an XML Audit File Financial (XAF, versions 3.2 and 4.0) — the accounts, the parties, the opening balance and every transaction of a year — into plain objects in TypeScript: amounts as decimal strings, the file's own totals checked, and what does not
