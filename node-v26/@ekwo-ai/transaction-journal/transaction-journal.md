# @ekwo-ai/transaction-journal

> 标签: accounting, bookkeeping, csv, general-ledger, import, journal, migration, parser, transaction-journal

## 简介

Reads a transaction journal saved as CSV — each transaction a run of rows under one date, type and number, closed by its total — with the list of accounts exported beside it, into plain objects in TypeScript: amounts as decimal strings, and what does not
