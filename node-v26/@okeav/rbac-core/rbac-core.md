# @okeav/rbac-core

> 标签: access-control, authorization, capabilities, permissions, rbac, scopes

## 简介

Standalone, pluggable RBAC engine for Node.js/TypeScript backends — accountType/accountSubType/role/userType/capabilities permission model, wildcard scope matching, and framework middleware. Bring your own scope catalogue and identity claims.
