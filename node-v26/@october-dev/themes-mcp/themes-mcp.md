# @october-dev/themes-mcp

> 标签: ai, claude, copilot, cursor, design-system, mcp, model-context-protocol, october, themes, ui, windsurf

## 简介

MCP server for injecting curated design system themes into AI-generated UI. Makes any AI coding tool produce beautiful, non-generic interfaces.
