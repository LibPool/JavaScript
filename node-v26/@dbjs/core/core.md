# @dbjs/core

> 标签: JavaScript

## 简介

@dbjs/core is a lightweight, type‑safe, in‑memory relational database written in TypeScript. It lets you create tables with typed columns and run SQL‑like queries (filtering, sorting, pagination, distinct values) without any external persistence layer.
