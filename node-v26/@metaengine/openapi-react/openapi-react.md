# @metaengine/openapi-react

> 标签: api, client, code-generator, codegen, fetch-api, hooks, metaengine, openapi, openapi-generator, react, react-18, react-19, react-query, swagger, tanstack-query, typescript, typescript-react, useMutation, useQuery

## 简介

Generate TypeScript/React services and models from OpenAPI specifications with TanStack Query (React Query) hooks, useQuery, useMutation, and native fetch API for React 18+
