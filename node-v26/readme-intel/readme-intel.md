# readme-intel

> 标签: cli, developer-tools, documentation, drift-detection, github-action, onboarding, readme, readme-analyzer, static-analysis, typescript

## 简介

Deterministic README analyzer for GitHub repos. Extracts commands, env vars, tech stack, and API endpoints with source-line evidence. Catches README drift in PRs. No LLM.
