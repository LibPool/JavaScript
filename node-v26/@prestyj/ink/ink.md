# @prestyj/ink

> 标签: JavaScript

## 简介

Ink 6.8.0 vendored with the EZ Coder TUI patch (atomic insertBeforeFrame / bottom-anchored frames) baked in so published consumers get the patched renderer. Forked from ink by Vadim Demedes (MIT).
