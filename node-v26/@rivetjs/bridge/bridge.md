# @rivetjs/bridge

> 标签: JavaScript

## 简介

Framework bridges for Rivet: components of other frameworks (React, Preact adapters) as islands inside a resumable Rivet page.

- 源码仓库：git+https://github.com/N1XUS/rivetjs.git
- npm 页面：https://www.npmjs.com/package/@rivetjs/bridge
