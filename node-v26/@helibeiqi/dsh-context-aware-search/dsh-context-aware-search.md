# @helibeiqi/dsh-context-aware-search

> 标签: context-aware, cordis, credibility, deepseek, deepseek-harness, dsh, rerank, web-search

## 简介

Context-aware web search for DeepSeek Harness (dsh): rewrites queries with session context, reranks and credibility-tags results, and offers one-click source summarization across multiple backends.
