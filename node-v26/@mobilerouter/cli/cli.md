# @mobilerouter/cli

> 标签: ai-sdk, cli, cloudflare-workers, expo, ios, iphone, llm, openrouter, react-native, relay

## 简介

The mobilerouter command line (mmr): set up the relay that keeps your OpenRouter key off the phone, check that a deployed relay works, and see what answers cost. Run it with `npx -p @mobilerouter/cli mmr`. Every command can print JSON for coding agents.
