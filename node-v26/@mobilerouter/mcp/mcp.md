# @mobilerouter/mcp

> 标签: ai-sdk, claude-code, coding-agent, expo, ios, iphone, llm, mcp, model-context-protocol, openrouter, react-native

## 简介

Lets a coding agent (Claude Code, Cursor and others) set up, check and read the costs of a mobilerouter relay through the Model Context Protocol. A thin wrapper over the mmr command line.
