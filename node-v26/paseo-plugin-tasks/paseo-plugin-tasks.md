# paseo-plugin-tasks

> 标签: agents, delegation, kanban, paseo, paseo-plugin, tasks, tracker

## 简介

Paseo plugin: Linear-style task tracker with projects, folders, subtasks, comments, agent preset delegation, comment steering, and CLI/MCP report-back.
