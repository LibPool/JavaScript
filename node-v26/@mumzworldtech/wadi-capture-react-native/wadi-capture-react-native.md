# @mumzworldtech/wadi-capture-react-native

> 标签: analytics, clevertap, events, expo, react-native, typescript, wadi

## 简介

Wadi Capture React Native — a tiny first-party event SDK for the Mumzworld iOS/Android app (Expo / React Native), replacing clevertap-react-native. TypeScript, with ESM and CommonJS builds. Sends to the wadi-infra proxy (POST /a1).
