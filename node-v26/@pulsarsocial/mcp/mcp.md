# @pulsarsocial/mcp

> 标签: instagram, mcp, modelcontextprotocol, pulsarsocial, scheduling, social-media, tiktok, uptrended, youtube

## 简介

stdio bridge to the PulsarSocial remote MCP server — schedule and publish social posts to Instagram, Facebook, TikTok, X, Pinterest and YouTube from any MCP client.
