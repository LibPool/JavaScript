# @miadi/recording-client

> 标签: api-client, capture, gmtermux, miadi, pixel-recorder, recording

## 简介

HTTP access to a recording service — the canonical /api/recordings envelope plus the pixel dialect gmtermux serves today, and a dependency-free fetch client that normalizes both. Drives a recorder from any process that does not own the microphone.
