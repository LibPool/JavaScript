# @miadi/hooks-gateway

> 标签: events, gateway, hooks, idempotency, miadi

## 简介

Optional event gateway boundary for Miadi hook events: HTTP ingress for hooks-core envelopes, idempotency ledger, stream publishing, and worker dispatch.
