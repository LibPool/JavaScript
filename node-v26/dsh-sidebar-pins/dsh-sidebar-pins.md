# dsh-sidebar-pins

> 标签: deepseek-harness, dsh, dsh-plugin, pinned-sessions, session-pin, sidebar

## 简介

Pinned-sessions block for the DeepSeek Harness sidebar: a collapsible pinned panel above the Settings row, hover pin buttons on session rows and a session-header toggle. Pins live in the plugin's own settings namespace and are migrated once from dsh-sessi
