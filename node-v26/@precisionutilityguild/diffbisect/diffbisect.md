> 标签: ai-agent, bisect, ddmin, delta-debugging, dirty-working-tree, git-bisect-hunks, git-hunks, regression, which-change-broke-the-test

## 简介

Delta debugging over git change regions — which hunks of your dirty diff broke the test? These, isolated, at commit-below granularity where git bisect cannot reach.
