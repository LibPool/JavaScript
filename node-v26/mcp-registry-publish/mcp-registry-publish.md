# mcp-registry-publish

> 标签: github-action, mcp, mcp-registry, model-context-protocol, semantic-release

## 简介

Publish a server.json to the MCP registry from CI: retries the registry's transient failures and skips a version it already lists. A GitHub Action and an npm package.
