# @stagecaptions/srt-to-vtt

> 标签: accessibility, captions, cli, srt, srt-to-vtt, subrip, subtitle-converter, subtitles, vtt, vtt-to-srt, webvtt

## 简介

A command line tool and JavaScript library that converts subtitle files between SubRip (.srt) and WebVTT (.vtt) formats.

- 官网：https://stagecaptions.io
- 源码仓库：git+https://github.com/stagecaptions/srt-to-vtt.git
