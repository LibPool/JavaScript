# striatum

> 标签: agents-md, claude-code, codex, conventions, cursor, rules, skills

## 简介

Rule library for Claude Code, Codex and Cursor: skills, reviewer agents and portable coding rule blocks, with a CLI that syncs the blocks into AGENTS.md and tool rule files
