# @soberis/gkd-subscription

> 标签: JavaScript

## 简介

基于 [GKD 订阅模板](https://github.com/gkd-kit/subscription-template) 构建的个人 GKD 订阅规则，用于 Android 设备自动跳过广告、关闭弹窗等。
