# @attache/cli

> 标签: ci, config, envoy, envoyproxy, lint, route-matching, sarif, service-mesh, validation, xds

## 简介

Check an Envoy config from the command line. Findings that point at a line, in a form CI can read — no Envoy binary, no network, any platform Node runs on.
