# @fence.dev/agent-signing

> 标签: JavaScript

## 简介

Sign an agent's outbound HTTP requests per RFC 9421 / the Web Bot Auth draft's exact wire conventions — the interop signer half of Fence's M·1 agent-signing story. Signer-only: never parses or verifies a third-party signature.
