# @scom82/yandex-search-mcp

> 标签: keyword-research, mcp, model-context-protocol, search-api, seo, web-search, wordstat, yandex, yandex-cloud

## 简介

Unofficial MCP server for the Yandex Cloud Search API v2 — Wordstat (topRequests/dynamics/regions/regionsTree) + Yandex Web Search, with date normalization, int64 handling and a file cache.
