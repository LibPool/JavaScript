# @rackwave/mcp-server

> 标签: audio, claude, cursor, fx, mcp, model-context-protocol, rackwave, web-audio

## 简介

Headless Rackwave as an MCP server: any MCP client (Claude, Cursor, etc.) can list FX devices, validate a chain, and export drop-in Web Audio code — no browser UI required.
