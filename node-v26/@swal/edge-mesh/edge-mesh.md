# @swal/edge-mesh

> 标签: crdt, local-first, mesh, ml-dsa, ml-kem, p2p, post-quantum, webrtc, yjs

## 简介

Owner-controlled P2P mesh for the browser: Yjs CRDT sync over WebRTC with post-quantum (ML-DSA-65, ML-KEM-768 + ECDH) signed security state
