# @antadesign/plot

> 标签: JavaScript

## 简介

Canvas charts for React, Preact, and browser custom elements. Create scatter, line, bar, area, rectangle, and rule series, or draw custom marks. `Plot` handles sizing, rendering, tooltips, zooming, and panning.
