# @vhop/2key-ratchet

> 标签: cryptography, diffie-hellman, ecc, encryption, integrity, messaging, secp256r1, session, webcrypto

## 简介

2key-ratchet is an implementation of a Double Ratchet protocol and X3DH in TypeScript utilizing WebCrypto.
