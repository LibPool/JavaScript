# @pathrule/signals

> 标签: errors, instrumentation, observability, pathrule, runtime, signals

## 简介

Pathrule Signals: a small, failure-isolated runtime instrumentation SDK. Send runtime errors and events to your own HTTP collector, Pathrule Local or Pathrule Cloud.
