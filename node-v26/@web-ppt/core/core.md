# @web-ppt/core

> 标签: animation, browser, chart, client-side, drawingml, emf, encryption, math, no-server, office, omml, ooxml, open-xml, pict, powerpoint, ppt, pptx, presentation, quickdraw, renderer, slides, smartart, svg, typescript, viewer, wmf

## 简介

Render .pptx and .ppt entirely in the browser — no server, no Office, no upload. OOXML and binary OfficeArt into one JSON schema, out as SVG.
