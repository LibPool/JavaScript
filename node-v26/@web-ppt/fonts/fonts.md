# @web-ppt/fonts

> 标签: browser, cjk, font, font-substitution, metric-compatible, powerpoint, ppt, pptx, subset, typescript, unicode-range, webfont

## 简介

Font substitution and on-demand web-font loading for PowerPoint decks: metric-compatible free substitutes plus a unicode-range slice loader. Zero font bytes in the package.
