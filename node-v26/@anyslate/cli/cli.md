# @anyslate/cli

> 标签: ai, anyslate, claude-code, cli, lifecycle-hooks, mcp, memory

## 简介

AnySlate CLI - lifecycle hooks, git/CI capture, and manual checkpoints for AI memory. Validates its connection at login, diagnoses itself with `anyslate doctor`, backs off and circuit-breaks rather than retrying, and fails open without failing silent.
