> 标签: broadnet, cpaas, fcm, geofencing, notifications, push-notifications, pwa, service-worker, vapid, web-push, webpush

## 简介

Broadnet Web Push SDK — framework-free (loads via <script> or ESM/CJS/UMD), FCM/OneSignal-style. Foreground + background + closed-tab notifications, delivery/engagement receipts, tags/attributes/segmentation, foreground geofencing, and full PWA support. T
