# @contentive/cli

> 标签: cli, cms, contentive, headless-cms, liquid, theme, typescript

## 简介

The Contentive CLI: pull a workspace's Liquid theme onto disk, edit it in your own editor with your own git, preview it locally against live content, and push it back to staging.
