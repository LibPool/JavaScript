# @contentive/sdk

> 标签: cms, contentive, graphql, headless-cms, nextjs, sdk, typescript

## 简介

Typed JS/TS client for the Contentive headless CMS: a dependency-light Delivery GraphQL client, TipTap/portable-text renderers (React/HTML/plain), a Next.js adapter, a sitemap helper, and the `cms typegen` codegen CLI.
