# @chalk-format/library-server

> 标签: chalk, chalk-format, education, media-library, postgres, r2, registry, s3

## 简介

A Chalk library server: the registry API over Postgres and S3-compatible storage (Cloudflare R2, MinIO, AWS S3), with a conformance check. Includes the chalk-library command.
