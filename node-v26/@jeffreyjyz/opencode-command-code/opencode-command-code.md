# @jeffreyjyz/opencode-command-code

> 标签: ai-sdk, command-code, opencode, plugin, provider

## 简介

Command Code provider + usage dashboard for opencode: two providers (Anthropic wire for Claude, OpenAI wire for everything else) against api.commandcode.ai, live model list, plan gating, /cmd-usage. Requires the cmduse CLI for usage rendering.
