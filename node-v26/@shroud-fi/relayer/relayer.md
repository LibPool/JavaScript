# @shroud-fi/relayer

> 标签: base, eip-2612, eip-7702, gasless, gelato, privacy, shroudfi, stealth-address

## 简介

Gasless sweep client for ShroudFi. ERC-20 via Gelato 1Balance + EIP-2612 permit, native ETH via EIP-7702 delegated relayer.
