# @recursica/adapter-tester

> 标签: playwright, recursica, storybook, testing, visual-regression

## 简介

Visual regression tester between Recursica adapters — usable inside the Recursica monorepo, or installed standalone as a devDependency in any adapter repo to diff its Storybook against Mantine as the source of truth.
