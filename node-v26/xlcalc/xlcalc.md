# xlcalc

> 标签: calculation, deterministic, excel, formula, formula-engine, recalculation, spreadsheet, sumifs, workbook, xlookup, xlsx

## 简介

Excel-style formula engine for workbooks: compiles a book's formulas to JavaScript, recalculates incrementally, hashes values deterministically, and checks its function whitelist against Excel semantics
