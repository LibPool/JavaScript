# @swiftbrowser/wasm-sdk-icu-data

> 标签: JavaScript

## 简介

ICU's data for the Swift SDK for WebAssembly's Foundation: the whole icudt76l.dat package, which @swiftbrowser/cli trims to an app's languages (Swift 6.4.0).
