# @orellbuehler/play-console-mcp

> 标签: ai, android, androidpublisher, google-play, llm, mcp, model-context-protocol, play-console, releases, reviews

## 简介

Model Context Protocol server for the Google Play Console: read and reply to user reviews, inspect and promote release tracks, and query crash/ANR vitals over the official Google Play Developer and Play Developer Reporting APIs.
