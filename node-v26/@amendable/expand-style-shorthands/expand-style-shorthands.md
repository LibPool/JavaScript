# @amendable/expand-style-shorthands

> 标签: JavaScript

## 简介

This expands style shorthand syntax (`padding: 1`) into long-hand syntax (`paddingTop: 1, paddingRight: 1, paddingBottom: 1, paddingLeft: 1`).
