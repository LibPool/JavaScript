# @worca/app

> 标签: ai-agents, autonomous-coding, claude-code, orchestrator, pipeline, worca

## 简介

Worca — deterministic multi-agent pipeline that drives Claude Code (headless) through Plan -> Refine -> Implement -> Review, with a CLI, an installable /worca skill, and a web UI.
