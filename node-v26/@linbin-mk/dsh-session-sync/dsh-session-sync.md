# @linbin-mk/dsh-session-sync

> 标签: cordis, cross-machine, deepseek, deepseek-harness, dsh, dsh-plugin, git, multi-machine, session, session-sync, sync, typescript

## 简介

Git-backed session sync plugin for DeepSeek Harness: keeps sessions of mapped projects in sync across machines through one git repository, served to the web settings page through its own same-origin HTTP API
