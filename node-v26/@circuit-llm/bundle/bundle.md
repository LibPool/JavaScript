# @circuit-llm/bundle

> 标签: JavaScript

## 简介

Circuit SDK agent bundles — build, sign, verify, and unpack content-addressed (sha256) signed agent bundles. The canonical codec shared by the Circuit agent cloud and the circuit CLI.
