# @circuit-llm/plugins

> 标签: ai-agent, circuit, defi, eliza-plugin, elizaos, onchain-data, solana, solana-agent-kit, x402

## 简介

Drop-in adapters that expose the Circuit Data API (pay-per-call in CIRC via x402) to agent frameworks: an ElizaOS plugin and a Solana Agent Kit action set. One dependency turns any agent into a Circuit data consumer.
