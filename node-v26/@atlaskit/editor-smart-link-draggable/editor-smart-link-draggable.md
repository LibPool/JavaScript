# @atlaskit/editor-smart-link-draggable

> 标签: JavaScript

## 简介

Drag-and-drop support for smart link cards. Provides a draggable wrapper component, shared constants, types, and utilities for smart link DnD between editor/renderer (drag sources) and the content tree (drop target).
