# @peppa_q/pi-collapse-tools

> 标签: cli, collapse, compact, developer-tools, earendil, earendil-works, pi, pi-coding-agent, pi-plugin, terminal, tool, tool-call, tool-renderer, tui, ux

## 简介

Pi plugin that collapses built-in tool calls (bash, read, edit, write, grep, find, ls) into a single compact row with an expand badge.
