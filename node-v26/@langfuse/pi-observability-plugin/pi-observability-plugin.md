# @langfuse/pi-observability-plugin

> 标签: langfuse, observability, opentelemetry, pi, pi-extension, pi-package, tracing

## 简介

Langfuse observability extension for the pi coding agent — traces prompts, agent turns, model generations, and tool calls to Langfuse.
