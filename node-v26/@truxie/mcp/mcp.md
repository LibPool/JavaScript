# @truxie/mcp

> 标签: adapter, dependency-injection, mcp, model-context-protocol, oauth, rbac, truxie

## 简介

Model Context Protocol adapter for truxie — exposes opt-in controller routes to an MCP client as four generic tools, dispatched in-process through the application's own guard chain
