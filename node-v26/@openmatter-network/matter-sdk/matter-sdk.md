# @openmatter-network/matter-sdk

> 标签: JavaScript

## 简介

TypeScript SDK for MatterChain and the OpenMatter platform: one apiKey, every pallet. A metadata-driven chain client (tx / query / runtimeApi) plus threshold Secrets, re-exporting @openmatter-network/matter-sdk-core.
