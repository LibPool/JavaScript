# @fortmesa/yarnstatic

> 标签: npm-registry, offline-install, s3, verdaccio, yarn, yarn-berry

## 简介

Node.js CLI port of yarnstatic (check/fetch/serve/version) -- an alternative to the Go binary for environments with Node but not Go. Bundles yarn-plugin-yarnstatic-s3 for direct-S3 installs with no daemon.
