# @hansenexus/mechanics

> 标签: acceptance-criteria, acceptance-testing, agents, behaviour-driven, behaviour-specs, claude-code, cli, coverage, docket, documentation, mcp

## 简介

Behaviour specs with a coverage ratchet: one markdown file per behaviour, a committed manifest, CI-gated against drift, verified per wave. Ships a stdio MCP server and the docket/1 run protocol.
