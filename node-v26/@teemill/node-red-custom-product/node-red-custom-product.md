# @teemill/node-red-custom-product

> 标签: node-red

## 简介

This node connects Node-RED to the Teemill API, and enables you to create a flow that will take any image then put it on a t-shirt. The Node accepts images in Base64 format and will return a custom product URL where people can buy that image on a real pro
