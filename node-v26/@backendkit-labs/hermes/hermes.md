# @backendkit-labs/hermes

> 标签: JavaScript

## 简介

Control plane for a fleet of agents: a validated fleet.yaml, connectors (in-process, agent-protocol), run store with reconciliation, roles and approval, and the fleet_* / agent_* tools for @backendkit-labs/agent-core
