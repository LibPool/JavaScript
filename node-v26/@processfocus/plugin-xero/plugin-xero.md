# @processfocus/plugin-xero

> 标签: JavaScript

## 简介

Xero Sales Invoice plugin for Process Focus business processes. Process authors receive one `XeroInvoiceStep` that issues a single authorised accounts-receivable invoice. Custom Connection authentication, REST transport, Xero wire schemas, catalog default
