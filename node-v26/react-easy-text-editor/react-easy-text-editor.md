# react-easy-text-editor

> 标签: contenteditable, editor, html-editor, react, react-editor, react-text-editor, rich-text-editor, text-editor, typescript, wysiwyg, wysiwyg-editor

## 简介

A React rich text (WYSIWYG) editor inspired by Jodit: plugin toolbar, tables, tabbed code blocks with syntax highlighting, dark mode, HTML source view, and a read-only viewer component.
