# @justweb3/poap-plugin

> 标签: JavaScript

## 简介

The **@justweb3/poap-plugin** extends the **JustWeb3 Widget** with **Proof of Attendance Protocol (POAP)** functionalities, allowing users to **view poaps** directly within your dApp.
