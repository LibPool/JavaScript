# @justweb3/dentity-plugin

> 标签: JavaScript

## 简介

The **@justweb3/dentity-plugin** extends the **JustWeb3 Widget** with **Dentity** functionalities, allowing users to **view verifications** for ENS domain owners directly within your dApp.
