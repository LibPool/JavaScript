# @lssm-tech/integration.communication-channel-slack

> 标签: JavaScript

## 简介

CommunicationOS Slack channel adapter: inbound normalization (Events API + signing-secret verify), outbound send (chat.postMessage), and best-effort erasure (chat.delete).
