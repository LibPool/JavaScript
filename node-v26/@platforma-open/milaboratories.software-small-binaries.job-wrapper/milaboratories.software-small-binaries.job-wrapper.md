# @platforma-open/milaboratories.software-small-binaries.job-wrapper

> 标签: JavaScript

## 简介

Job container entrypoint replacing job-script.sh: runs the command, mirrors its streams, prunes the workdir, writes the completion marker and collects CPU/RAM usage from the container cgroup into .pl/usage.json
