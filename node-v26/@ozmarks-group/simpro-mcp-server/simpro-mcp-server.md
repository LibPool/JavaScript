# @ozmarks-group/simpro-mcp-server

> 标签: JavaScript

## 简介

Unofficial MCP server exposing Simpro operations (quotes, jobs, customers, catalog, aggregations) over stdio and streamable HTTP. Not affiliated with, endorsed by, or supported by Simpro.
