# @407dev/site-services

> 标签: JavaScript

## 简介

Per-site runtime data plane for client sites: a publishable Hono sub-app, mounted at `/_api/*` (and `/_ev` for analytics ingest) inside a site's own Astro-on-Cloudflare deployment, backed by that site's own D1 + KV. Provides contact forms, first-party dua
