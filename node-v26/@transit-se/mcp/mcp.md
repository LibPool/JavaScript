> 标签: gtfs, kollektivtrafik, lokaltrafik, mcp, model-context-protocol, public-transport, sl, stockholm, sverige, sweden, trafiklab, transit

## 简介

MCP server for Swedish public transit (Trafiklab, GTFS-RT). Real-time departures, service alerts, and stop lookups as AI-callable tools.
