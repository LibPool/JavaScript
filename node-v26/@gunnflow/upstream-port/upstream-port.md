# @gunnflow/upstream-port

> 标签: backend, bff, cockpit, gunnflow, port, upstream

## 简介

The Gunnflow BFF's single upstream wiring port: the transport-shaped interface an in-process upstream implements, plus a small error class for an unsupported detail surface.
