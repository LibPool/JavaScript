# @yyyu-star/arcade-kit

> 标签: chacha20, cloudflare, durable-objects, game, multiplayer, room, turn-based, websocket, workers

## 简介

Multiplayer toolkit for small Cloudflare Workers games: Durable Object game rooms, room create/join entry points, browser client, daily write quota, ChaCha20 RNG, platform or standalone (guest) identity. 小游戏共用的联机底座
