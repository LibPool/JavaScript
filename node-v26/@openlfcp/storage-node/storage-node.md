# @openlfcp/storage-node

> 标签: end-to-end-encryption, lfcp, local-first, node, openlfcp, sqlite, storage

## 简介

Durable Node.js storage for LFCP clients: SQLite (better-sqlite3) and a file secret store. Node only.
