# @pubber-subber/aws-sns

> 标签: adapter, amazon, aws, events, messaging, pub-sub, pubsub, sns, typescript

## 简介

AWS SNS publish-only adapter for @pubber-subber. Pair with @pubber-subber/aws-sqs via compose() for full duplex.
