# @pubber-subber/aws-sqs

> 标签: adapter, amazon, aws, events, messaging, pub-sub, pubsub, sqs, typescript

## 简介

AWS SQS subscribe-only adapter for @pubber-subber. Pair with @pubber-subber/aws-sns via compose() for SNS→SQS fan-out.
