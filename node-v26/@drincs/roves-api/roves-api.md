# @drincs/roves-api

> 标签: bridge, game, indexeddb, ipc, roves, save, save-game, servo, steam, steamworks, webview

## 简介

JS/TS bridge for talking to Roves (the Servo-based embedded game shell) from web content — no Tauri required.
