# @canvora/cli

> 标签: agents, ai, canvora, carousel, design, image-generation, mcp, openclaw, social-media, visuals

## 简介

CLI for Canvora (canvora.ai): turn any idea, URL, doc, or PDF into on-brand visuals in 100+ formats, native in 150+ languages. Built for AI agents and automation.
