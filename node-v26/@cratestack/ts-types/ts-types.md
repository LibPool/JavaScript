# @cratestack/ts-types

> 标签: cratestack, cstack, rpc, trpc-links, types

## 简介

Shared TypeScript interfaces for CrateStack's generated RPC client (RpcLink, RpcLinkRequest, wire frame shapes). Types only — compiles to near-empty JS.
