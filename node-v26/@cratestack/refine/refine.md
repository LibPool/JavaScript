# @cratestack/refine

> 标签: admin-panel, cratestack, cstack, dataProvider, refine, refinedev

## 简介

A refine.dev DataProvider over CrateStack's generated TypeScript client (REST or RPC) — the safe end-user admin-UI surface that goes through the generated API (policy, validation, @version concurrency, audit), unlike cratestack-studio's direct-to-database
