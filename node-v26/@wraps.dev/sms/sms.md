# @wraps.dev/sms

> 标签: aws, end-user-messaging, messaging, node, nodejs, notifications, otp, pinpoint, send-sms, sms, sms-api, sms-sdk, text-message, typescript, verification-code, wraps

## 简介

Send SMS via AWS End User Messaging with TypeScript. Batch sending, opt-out management, phone number provisioning, and segment calculation. Your AWS account, no vendor lock-in.
