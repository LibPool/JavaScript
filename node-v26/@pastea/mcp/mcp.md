# @pastea/mcp

> 标签: ai-tools, claude, claude-code, claude-desktop, clipboard, clipboard-history, codex, cursor, local-mcp, mac, macos, mcp, mcp-server, model-context-protocol, pastea, stdio

## 简介

Local MCP server bridge for Pastea — give Claude Desktop, Claude Code, Cursor, Codex and other AI tools access to your Mac clipboard history. Runs on your Mac; pairs with one click in Pastea.
