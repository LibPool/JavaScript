# @super-harness/server

> 标签: agent, agents, ai, harness, language-model, llm, mastra, multi-agent, orchestration, streaming, subagent, super-line, supervisor, tool-calling, typescript

## 简介

Batteries-included super-line binding for Super Harness: the harness() plugin and standalone serve() expose a core Harness over a super-line server with durable harness.* collections, the wire contract, and HITL suspension/approval broadcast.
