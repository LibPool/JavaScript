# react-native-alpha-video

> 标签: alpha, android, av1, ios, metal, opengl, player, react-native, react-native-web, transparency, transparent-video, video, vp8, vp9, webm

## 简介

Transparent video for React Native: VP8, VP9 or AV1 WebM with alpha on iOS and Android, decoded by a C++ core (libvpx, dav1d for AV1) or the Android hardware decoder, drawn with Metal and OpenGL ES. On the web, alpha-video-web shows the alpha in every bro
