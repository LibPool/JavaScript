# @heyramzi/canvas

> 标签: canvas, diagram, freehand, pen, plugin, svelte, svelte-flow, svelte5, sveltekit, whiteboard, xyflow

## 简介

A Svelte 5 canvas on xyflow with a hand-drawing pen, a plugin API for custom cards and ops, and headless ops for servers and CLIs.
