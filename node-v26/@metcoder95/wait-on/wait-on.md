# @metcoder95/wait-on

> 标签: available, cli, cross-platform, delay, exist, files, fork, http, linux, osx, portable, ports, ready, sockets, tcp, unix, wait, win32, windows

## 简介

wait-on is a cross platform command line utility and Node.js API which will wait for files, ports, sockets, and http(s) resources to become available
