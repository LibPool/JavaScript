# @unbound-ai/unbound-observer

> 标签: JavaScript

## 简介

Local MCP observability — wrap Claude / Cursor / Windsurf MCP servers through a proxy, capture schema + invocations to ~/.unbound/registry.db, view in a built-in dashboard.
