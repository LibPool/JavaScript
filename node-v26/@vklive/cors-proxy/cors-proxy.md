# @vklive/cors-proxy

> 标签: cors, proxy, vklive

## 简介

Локальный CORS-прокси без зависимостей: форвардит запросы на указанный хост (generic ?url=), добавляя CORS-заголовки и пробрасывая Authorization/Private-Token. Запускается одной командой npx.
