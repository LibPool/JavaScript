# @blankline/dropstone-sdk

> 标签: agent memory, agent sdk, agentic, ai agent, ai coding agent, aider, claude code alternative, cli, codex, coding agent, coding agent sdk, cross-surface memory, developer tool, dropstone, dropstone cli, dropstone sdk, javascript sdk, llm, memory across sessions, openai compatible, persistent memory, shared memory, typescript sdk

## 简介

Dropstone SDK — the official TypeScript SDK for the Dropstone agent runtime. Programmatic access to the agent server, with one cross-surface memory (Continuity) shared across CLI, chat, and SDK.
