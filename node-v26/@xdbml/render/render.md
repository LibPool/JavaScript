# @xdbml/render

> 标签: dbml, diagram, erd, renderer, svg, xdbml

## 简介

Framework-free SVG renderer for xDBML diagrams, shared by the playground, the hosted render API, and the MCP server.

## 官网

- 官网：https://xdbml.org
- 源码仓库：git+https://github.com/xdbml/xdbml-spec.git
