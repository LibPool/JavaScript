# @coordination-network/expo-identity-keystore

> 标签: android-keystore, expo, hardware-backed-keys, p-256

## 简介

Expo Module wrapping the Android Keystore for hardware-backed P-256 keys (sign, signDigest, ECDH), plus an in-memory SoftwareKeystore for iOS/Expo Go/jest.
