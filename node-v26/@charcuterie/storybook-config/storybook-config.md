# @charcuterie/storybook-config

> 标签: JavaScript

## 简介

The shared Storybook setup for the fleet: theme-axis toolbars (scheme/variant/density), the first-paint seed, and the a11y + controls defaults, so every app's Storybook themes light/dark the same way.
