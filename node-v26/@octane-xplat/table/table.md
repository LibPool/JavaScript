# @octane-xplat/table

> 标签: android, cross-platform, data-grid, datagrid, ios, nativescript, octane, table, tanstack, web, xplat

## 简介

Headless data grid for Octane xplat — @tanstack/table-core row model (sorting, filtering, pagination, selection, grouping) rendered through shared VirtualList on web, iOS, Android, and macOS
