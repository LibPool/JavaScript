# @changepacks/cli

> 标签: N-API, NAPI, Rust, changelog, changepacks, napi-rs, node-addon, node-addon-api, package management, package management system, package manager, version control, version control system, version management, versioning

## 简介

changepacks is a CLI tool that helps you efficiently manage versioning and changelogs in multi-language projects. It provides unified support for various package management systems including Node.js, Python, Rust, and more.
