# @eggmasonvalue/pi-subagent

> 标签: agents, fault-tolerant, isolated-context, observability, orchestration, pi, pi-package, resume, steerable, subagent, subagents

## 简介

Thin Pi subagent primitive: one synchronous call for isolated context, live progress, timeout supervision, resumable sessions, and per-task model/tool control.
