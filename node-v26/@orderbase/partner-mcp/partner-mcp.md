# @orderbase/partner-mcp

> 标签: claude, connectbase, mcp, model-context-protocol, orderbase, partner-api, telecom

## 简介

MCP (Model Context Protocol) server for the OrderBase partner API. Exposes the partner sandbox as agent-callable tools for Claude Code, Cursor, Cline, Windsurf, and other MCP clients.
