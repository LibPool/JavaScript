# @makibm/twixer

> 标签: arbitrary, audit, cli, lint, magic-numbers, tailwind, tailwind-v4, tailwindcss

## 简介

Find Tailwind v4 arbitrary-value classes (e.g. text-[13px], bg-[#abc]) and suggest the matching default token from your @theme.
