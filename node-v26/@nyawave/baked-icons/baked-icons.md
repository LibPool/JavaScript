# @nyawave/baked-icons

> 标签: build-time, icon, iconify, icons, nextjs, react, rsc, ssr, svg, turbopack, vite, vite-plugin, webpack

## 简介

Iconify-compatible React <Icon> whose icons are baked into your bundle at build time. Zero runtime fetching, SSR/RSC friendly. Vite + Next.js (Turbopack/webpack).
