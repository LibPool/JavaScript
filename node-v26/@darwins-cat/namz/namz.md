# @darwins-cat/namz

> 标签: audio, codec, dsp, float32, guitar, nam, neural-amp-modeler

## 简介

Lossless codec for NeuralAmpModeler .nam files — ~5.5x smaller, bit-exact float32, deterministic. Byte-identical to the C++ reference.
