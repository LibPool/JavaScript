# @gravito/stream

> 标签: gravito, job, kafka, orbit, queue, redis, sqs, worker

## 简介

Lightweight, high-performance queue system for Gravito framework. Supports multiple brokers (Database, Redis, Kafka, SQS) with zero runtime overhead.
