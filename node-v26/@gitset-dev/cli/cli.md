# @gitset-dev/cli

> 标签: ai, automation, byoai, cli, commit, git, github, pull-request, readme-generator, release-notes

## 简介

Gitset CLI — drafts commits, PRs, issues, READMEs and release notes with your own AI key. Fully local: your code and keys never touch a Gitset server. Draft. Refine. Ship.
