# @peridotvault/pid-solana

> 标签: JavaScript

## 简介

PeridotID Solana adapter — passkey-based smart-account authority. The **only** package allowed to import `@solana/web3.js` (ADR 007 §8). Pure functions and adapters for building, signing, and submitting smart-account transactions without a wallet.
