# @cardog/corgi

> 标签: automotive, automotive-api, browser, car-data, cloudflare, cloudflare-workers, fast, lightweight, nhtsa, nodejs, offline, pattern-matching, performance, sqlite, typescript, validation, vehicle-data, vehicle-identification, vehicle-lookup, vin, vin-decoder, vin-validation, vpic

## 简介

Fast, offline VIN decoding for Node.js, browsers, and Cloudflare Workers. Powered by the NHTSA VPIC database.
