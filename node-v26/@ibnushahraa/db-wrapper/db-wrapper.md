# @ibnushahraa/db-wrapper

> 标签: database, mysql, postgres, sqlite, validation, wrapper

## 简介

A database-agnostic wrapper with built-in error handling, validation, and helper methods for MySQL, PostgreSQL, and SQLite. Lightweight, production-ready, and developer-friendly
