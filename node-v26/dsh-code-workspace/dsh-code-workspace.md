# dsh-code-workspace

> 标签: code-workspace, deepseek-harness, dsh, dsh-plugin, multi-root, vscode, workspace

## 简介

DeepSeek Harness plugin: VS Code-compatible multi-root workspaces. A .code-workspace file is the single source of truth — its `folders` become writable roots of the session, exactly as in VS Code / Trae / Cursor.
