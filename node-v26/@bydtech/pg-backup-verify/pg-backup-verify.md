# @bydtech/pg-backup-verify

> 标签: backup, cli, disaster-recovery, pg_dump, pg_restore, postgres, postgresql, restore, verify

## 简介

Prove a Postgres backup restores: restore the dump into a scratch database, compare every table's row count against the source, and drop the scratch database again.
