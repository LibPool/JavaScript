# @diqye/react-zod

> 标签: auto-validation, dark-mode, data-binding, data-linkage, form-library, form-validation, no-ui-code, out-of-the-box, react, react-form, react-hook, schema-driven, tailwindcss, useZodForm, zod, zod-schema

## 简介

React 开箱即用表单库，深度整合 Zod Schema，调用 useZodForm 传入 Schema 就能直接渲染表单 holder，无需编写 UI 代码，自动实现 Zod 数据校验，兼容 TailwindCSS 样式且支持暗黑模式，表单数据联动一步到位
