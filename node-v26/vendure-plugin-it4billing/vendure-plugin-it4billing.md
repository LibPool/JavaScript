# vendure-plugin-it4billing

> 标签: fatura, faturacao, invoice, invoicing, it4billing, plugin, portugal, saft-pt, vendure, vendure-plugin, vendure.io

## 简介

Vendure plugin that issues certified invoice-receipts in IT4Billing (Portugal) for orders, without a browser, and stores the PDF for customers to download
