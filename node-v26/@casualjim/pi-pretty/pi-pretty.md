# @casualjim/pi-pretty

> 标签: pi, pi-extension, pi-package, pretty-print, shiki, syntax-highlighting, terminal

## 简介

Pretty terminal output for pi built-in tools: shiki-highlighted read previews, ls tree with icons, FFF-accelerated find/grep, prompt editor and activity indicators.
