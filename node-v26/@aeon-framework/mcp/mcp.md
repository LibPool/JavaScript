# @aeon-framework/mcp

> 标签: JavaScript

## 简介

Aeon MCP server: gives AI coding assistants tools for real code generation, docs/API search, project conventions, project inspection, and template-binding explanation — Aeon's answer to Angular's `ng mcp`.
