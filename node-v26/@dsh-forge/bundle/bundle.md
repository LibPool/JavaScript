# @dsh-forge/bundle

> 标签: JavaScript

## 简介

DSH extension suite host bundle: cross-session mailbox, agent teams, model delegation & routing policy, runtime injector, skill manager, dynamic-plugin boot, and the plugin/skill manager client packages.
