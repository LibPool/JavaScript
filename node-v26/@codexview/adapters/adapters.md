# @codexview/adapters

> 标签: adapter, agent, ai, claude-code, codex, codexview, transcript

## 简介

Stateless adapters that convert AI coding agent transcript logs (Codex exec JSONL, Codex rollouts, AgentWeb codex-team status, Claude Code, OpenCode, GitHub Copilot, and live transcripts) into the CodexView ChatStreamEvent schema. Zero runtime dependencie
