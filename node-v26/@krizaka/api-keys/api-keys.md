# @krizaka/api-keys

> 标签: api-keys, authentication, krizaka, rotation, scopes

## 简介

API keys for every Krizaka product: created, rotated, revoked and authenticated behind a store port. The key is shown once, only a hash of its random part is kept, scopes and rules are data, refusals have stable codes. No framework, no database client, no
