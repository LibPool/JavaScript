# @krizaka/tokens

> 标签: brand, css-variables, dark-mode, design-system, design-tokens, dtcg, krizaka, react-native, theme, theming

## 简介

The Krizaka semantic design tokens (--kz-*) and the brand themes (Krizaka, Orazaka, Orochia, Yasakia, Yororis, Yomizaka, Kachizaka, Akinaza): one DTCG source compiled to CSS (dark, light, media invariants), typed constants and React Native themes.
