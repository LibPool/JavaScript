# @krizaka/i18n

> 标签: cli, i18n, krizaka, messages, plural, react, translation, typed-keys

## 简介

The i18n engine of every Krizaka app: typed message keys and placeholders from en.json, format(), plurals through @krizaka/intl, <Rich> (<b>, <a>), a React provider, and the krizaka-i18n CLI that checks catalogues and finds hard-coded strings.
