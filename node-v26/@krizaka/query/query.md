# @krizaka/query

> 标签: fetch, hydration, krizaka, offline, problem-details, react-native, react-query, server-sent-events, server-state, tanstack-query

## 简介

Server state for every Krizaka app: TanStack Query v5 with the Krizaka defaults, a typed fetch that reads RFC 9457 Problem Details, typed query keys, live invalidation from a realtime stream, App Router hydration and an offline persister for Expo.
