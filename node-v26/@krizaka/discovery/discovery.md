# @krizaka/discovery

> 标签: ed25519, expo, krizaka, react-native, remote-config, service-discovery, signed-manifest

## 简介

Service discovery for every Krizaka mobile app: load a signed manifest of backend addresses (Ed25519 over canonical JSON), allow-list the hosts, cache it, fall back cached → baked default → legacy host, and honour minimum version and maintenance — so a UR
