# @krizaka/payments

> 标签: checkout, gst, idempotency, krizaka, payments, qst, stripe, subscription, webhook

## 简介

Payments for every Krizaka product, vendor behind a port: the Stripe adapter (Checkout, customer portal, price read by lookup key, verified webhook), idempotent event application, a locale-aware price formatter and a catalogue setup that creates products,
