# @krizaka/organize

> 标签: avatar, collections, krizaka, multi-tenant, organize, tags

## 简介

The « organize » block of every Krizaka product: a name, an avatar, a description, tags, collections and an undeletable default collection for any entity — rules, a store over PostgreSQL, and a conformance kit. No ORM, no framework: you pass a query funct
