# @zackrobertstech/n8n-nodes-auvik

> 标签: n8n-community-node-package

## 简介

n8n community node for the Auvik API. Interact with network inventory, alerts, billing, statistics, SNMP poller settings, and ASM data. Requires a valid Auvik user and API key with appropriate role permissions.
