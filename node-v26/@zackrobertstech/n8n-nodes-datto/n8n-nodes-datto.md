# @zackrobertstech/n8n-nodes-datto

> 标签: n8n-community-node-package

## 简介

Interact with the Datto REST API to manage BCDR devices, agents, assets, alerts, SaaS domains and seats, and DTC assets. Authenticates via Basic Auth using your Datto public and secret keys.
