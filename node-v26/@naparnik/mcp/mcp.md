# @naparnik/mcp

> 标签: claude, mcp, model-context-protocol, montage, naparnik, reels, subtitles, video

## 简介

MCP-сервер Напарника: монтаж вертикального видео на машине пользователя — паузы, субтитры, герой на новом фоне, звук. Видео никуда не уезжает.
