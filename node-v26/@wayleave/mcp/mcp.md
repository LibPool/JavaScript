# @wayleave/mcp

> 标签: abuse-prevention, ai-agents, cost-control, mcp, mcp-server, middleware, model-context-protocol, rate-limiting, runaway-agent, security, spend-limit, tool-calls, wayleave, zero-dependencies

## 简介

Stop your MCP server being drained by a runaway agent. Per-tool rate limits, concurrency caps, spend ceilings and repeat-loop detection, in one line. Zero dependencies.
