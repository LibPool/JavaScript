# @chisme/pino-cloudwatch

> 标签: JavaScript

## 简介

A [Pino](https://getpino.io) transport that ships logs to **AWS CloudWatch Logs from a worker thread**, built for **long-running processes** (servers, ECS tasks, daemons). The main thread never blocks on `PutLogEvents`; batching, backpressure, and AWS I/O
