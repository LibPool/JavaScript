# @frappe-ui/styles

> 标签: components, design-system, frappe, frappe-ui, headless, tailwind, ui

## 简介

Unofficial community port — Prebuilt stylesheet for frappe-ui-universal — every utility the component recipes emit, plus the token variables. For apps that do not run Tailwind themselves.
