# @frappe-ui/tokens

> 标签: components, design-system, frappe, frappe-ui, headless, tailwind, ui

## 简介

Unofficial community port — Design tokens for frappe-ui-universal: raw palettes, semantic ink/surface/outline tokens, CSS custom properties and a Tailwind preset.
