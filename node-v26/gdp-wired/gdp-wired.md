# gdp-wired

> 标签: automatic-prover, formal-verification, gdp-ts, invariants, lean, policy, rate-limiting, state-machine, theorem-prover, theorem-proving, verification

## 简介

An automatic prover for stateful rules (budgets, caps, windows, workflows, policies): laws proven with no proof to write, checked again in Lean, counterexamples found on the GPU, the rule shipped as code
