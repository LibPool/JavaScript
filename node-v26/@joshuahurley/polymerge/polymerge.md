# @joshuahurley/polymerge

> 标签: 3d, cli, diff, git, glb, gltf, merge, mesh, obj, stl, three-way-merge, viewer

## 简介

Structural diff and three-way merge for 3D models (STL, OBJ, glTF/GLB), with a browser viewer and git drivers.
