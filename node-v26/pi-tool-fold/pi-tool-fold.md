# pi-tool-fold

> 标签: collapse, fold, pi-extension, pi-package, transcript, tui

## 简介

Fold completed tool calls in the pi transcript into a single "Worked for 1m 04s" line, toggled with a keybinding. Display-only: sessions and tool state are untouched.
