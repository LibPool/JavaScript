# bun-as-vite

> 标签: bun, bun-build, bun-serve, code-splitting, defineConfig, hmr, proxy, react-compiler, react-refresh, tailwindcss, vite

## 简介

Run Vite-configured React and web apps on Bun natively with zero config rewrite. Full drop-in replacement for Vite defineConfig with Bun.build and Bun.serve.
