# @dornick/parsers-pdf

> 标签: JavaScript

## 简介

Lazy pdf.js parser for Dornick. Extracts text from PDF uploads under /user/files/<id>/parsed/.

## 官网

- npm 页面：https://www.npmjs.com/package/@dornick/parsers-pdf
