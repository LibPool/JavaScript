# @aero-js/diagnostics

> 标签: JavaScript

## 简介

Structured `AeroDiagnostic` types, terminal/browser formatters, PostCSS/CSS error bridging, Effect Cause mapping, and dev SSR error transport (`x-aero-diagnostics`).
