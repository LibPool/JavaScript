# @parqlet/transport-cloud-run

> 标签: JavaScript

## 简介

Cloud Run ClientTransport. Plain HTTPS to a Cloud Run service URL with an Authorization: Bearer <google-id-token> header supplied by a caller-provided resolver. Stdlib only — no googleapis / google-auth-library dep.
