# @memohai/icon

> 标签: JavaScript

## 简介

本文定义图标层的目标契约。品牌图标通过 `@memohai/icon` 导出；界面图标通过 `@memohai/icon/ui` 导出，手写源码在 `src/ui/`，不受品牌生成器重写。Upload、Connector、Cloud、Computer 和 Settings 已接入该入口；其余界面图标按需迁移。
