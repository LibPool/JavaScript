# @ebowwa/node-codegen

> 标签: JavaScript

## 简介

Single-source-of-truth codegen. Reads server NODE_DEFINITIONS at runtime (Bun imports TS directly, no build step) and derives the frontend FALLBACK_PALETTE, Swift wire constants, and a cross-language reference dictionary. --check flag diffs against commit
