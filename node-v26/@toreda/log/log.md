# @toreda/log

> 标签: browser, commonjs, esm, lightweight, log, log-groups, log-levels, logger, logging, node, serverless, toreda, transport, transports, typescript

## 简介

TypeScript logger with custom transports, per-group log levels, and ESM + CommonJS builds for Node, browser, and serverless environments.
