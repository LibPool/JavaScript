# @minvws/mgo-hcim-ui

> 标签: JavaScript

## 简介

This package contains functionality for transforming Mgo resources into Health Ui Schemas. It is uses by the [HCIM package][packages-hcim] to provide Health UI Schemas for HCIM FHIR data.
