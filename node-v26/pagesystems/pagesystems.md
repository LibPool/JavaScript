# pagesystems

> 标签: JavaScript

## 简介

Send the person a hosted web page (flight picker, form, ...) and get their answer back in your agent's conversation. A thin client for the Page Systems API, with tools for eve, the AI SDK, OpenAI Agents, Claude Agent SDK, LangChain and Mastra.
