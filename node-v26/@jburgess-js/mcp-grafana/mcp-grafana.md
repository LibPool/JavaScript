# @jburgess-js/mcp-grafana

> 标签: dashboard, dashboards-as-code, grafana, lint, mcp, model-context-protocol, observability-as-code, panel, prometheus, promql

## 简介

Strongly-typed Grafana dashboard & panel builders, a structural lint surface, a semantic dashboard diff, and scaffold/audit/review recipes — over MCP. Targets Grafana 12.x.
