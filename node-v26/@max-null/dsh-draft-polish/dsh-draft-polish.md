# @max-null/dsh-draft-polish

> 标签: composer, deepseek-harness, draft, dsh, dsh-plugin, llm, polish, ssid

## 简介

DSH 草稿润色：发送按钮左侧 ✨ 一键调用 LLM 润色输入框草稿，可选携带会话上下文帮助模型理解意图；走 DSH llm 渠道，会话进行中也能用
