# @theaiinc/realm-host

> 标签: android-auto, desktop-head-unit, host, realm

## 简介

Narrow, allowlisted host-process launcher for Realm — a deliberate exception to "agent never works directly on the host machine", scoped to specific binaries only (initially: Android Emulator + Desktop Head Unit)
