# @cohesivity/init

> 标签: agent-native, ai-agents, backend, cohesivity, quickstart, skill

## 简介

Set up Cohesivity in a project: install the agent skill, create a managed backend tenant, write the project config. Run with `npx @cohesivity/init`.
