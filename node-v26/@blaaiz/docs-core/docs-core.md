# @blaaiz/docs-core

> 标签: api-playground, docs, documentation, framework, mdx, openapi, react

## 简介

Neutral, self-hostable documentation framework core — navigation parsing, OpenAPI merging, MDX doc components, and a hardened try-it proxy. Config and content live in each consuming site.
