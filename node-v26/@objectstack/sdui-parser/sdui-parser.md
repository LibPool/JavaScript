# @objectstack/sdui-parser

> 标签: adr-0080, jsx, objectstack, parser, sdui

## 简介

ObjectStack constrained JSX-source → SDUI SchemaNode tree compiler (parse, never execute). Isomorphic, zero React. ADR-0080.
