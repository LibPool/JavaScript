# @activeledger/sdk-web

> 标签: activeledger, blockchain, browser, distributed ledger technology, dlt, ledger, react-native, sdk, smart contracts, web

## 简介

Activeledger SDK for browsers and React Native - secp256k1 signing via @noble/curves (audited, pure JS, no native/WebCrypto dependency)
