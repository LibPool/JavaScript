# @nepali-date-picker/core

> 标签: bikram, bikram-sambat, calendar, converter, date, date-converter, kotlin-multiplatform, nepal, nepali, sambat

## 简介

Bikram Sambat (Nepali) date conversion and formatting engine. Compiled from the Kotlin Multiplatform :core module, so BS↔AD tables and formatting match the Kotlin, Android, and Python builds exactly.
