# @localmode/litert

> 标签: ai, gemma, google, language-model, litert, litert-lm, llm, local-first, offline, privacy, text-generation, wasm, webgpu

## 简介

LiteRT-LM provider for @localmode - Google's on-device LLM inference engine with WebGPU/CPU support, runs .litertlm models (Gemma 4, Qwen3)
