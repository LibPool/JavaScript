# @dailies-studio/bridge

> 标签: JavaScript

## 简介

The async postMessage protocol between an editor chrome and a preview stage. Built once because there are TWO synchronous bridges (the editor's __studio and the scene editor's __sceneStudio) and same-origin policy forbids driving either across origins.
