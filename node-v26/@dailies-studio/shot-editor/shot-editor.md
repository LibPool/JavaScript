# @dailies-studio/shot-editor

> 标签: JavaScript

## 简介

The shot editor chrome: a prebuilt React app served static at /shot by the merged studio server, so user tooling can never break it. The 3D stage lives in src/stage and is served ONLY through the project's Vite (pinned three stack, project assets) via /sh
