# @propellerads/input

> 标签: JavaScript

## 简介

One field for text, passwords and numbers, and a textarea in the same box. Built the way [Button](../Button/README.md) is: one stylesheet, the behaviour from [Base UI](https://base-ui.com/react/components/input), every value from [@propellerads/tokens](..
