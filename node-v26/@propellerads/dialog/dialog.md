# @propellerads/dialog

> 标签: JavaScript

## 简介

`Dialog` is the blocking window: the page stays where it is, the dialog takes the focus and the keyboard, and nothing else answers until it is done. It is built the shadcn way — one stylesheet, variants picked by [class-variance-authority](https://cva.sty
