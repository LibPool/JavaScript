# @rn-security/auditor

> 标签: devsecops, masvs, mobile-security, owasp, react-native, sast, security, static-analysis

## 简介

Static application security analysis for React Native projects: file discovery, rule engine, findings, fingerprints and suppression. Developer and CI tooling — never shipped inside a mobile application.
