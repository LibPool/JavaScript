# @bluemeat0724/dsh-md-viewer

> 标签: JavaScript

## 简介

Markdown workspace viewer plugin for the DeepSeek Harness web GUI: renders any workspace's Markdown with the md-viewer engine (marked + highlight.js + mermaid into a self-contained offline snapshot) and browses the result in an embedded overlay; agent too
