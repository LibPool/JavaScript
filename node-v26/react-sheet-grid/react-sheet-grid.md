# react-sheet-grid

> 标签: canvas, datagrid, excel, formula, google-sheets, grid, react, sheet, spreadsheet, table

## 简介

A Google Sheets-style spreadsheet grid for React: canvas rendering, one million rows at 60fps, formulas, undo/redo, sorting, filtering and Vietnamese IME support.
