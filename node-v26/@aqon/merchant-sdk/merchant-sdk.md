# @aqon/merchant-sdk

> 标签: aqon, hmac, merchant, payment, tron, usdt, webhook

## 简介

AQON merchant backend SDK — HMAC v2 signing, payment and connect requests, payment confirmation polling and webhook signature verification. Zero runtime dependencies (Node >=18 built-ins only). ESM + CommonJS + TypeScript types.
