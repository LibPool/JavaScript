# @huicai/cli

> 标签: agent, ai, cli, coding-agent, huicai, openai-compatible, terminal

## 简介

在终端运行的智能体 CLI：以 HuiCai_AI 平台的 OpenAI 兼容 /v1 为模型后端，在用户本机执行文件/命令工具。
