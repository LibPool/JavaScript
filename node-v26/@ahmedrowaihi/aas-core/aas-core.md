# @ahmedrowaihi/aas-core

> 标签: aas, asyncapi, codegen, events, shared

## 简介

Shared AsyncAPI 3.0 parsing primitives for codegen — thin wrapper around @asyncapi/parser exposing a uniform parseSpec entry point. Mirror of @ahmedrowaihi/oas-core for the AsyncAPI track.
