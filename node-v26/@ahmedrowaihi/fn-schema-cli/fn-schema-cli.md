# @ahmedrowaihi/fn-schema-cli

> 标签: cli, codegen, function-signature, json-schema

## 简介

CLI wrapper for fn-schema. Thin orchestrator over @ahmedrowaihi/fn-schema-core with the TypeScript extractor pre-registered. Loads optional fn-schema.config.{ts,js,json} via c12.
