# @ahmedrowaihi/openapi-ts-k6

> 标签: k6, load-testing, openapi, openapi-ts, plugin

## 简介

Thin @hey-api/openapi-ts plugin that delegates to @ahmedrowaihi/k6-gen. Use if you already drive codegen through openapi-ts.config.ts; otherwise reach for @ahmedrowaihi/k6-toolkit.
