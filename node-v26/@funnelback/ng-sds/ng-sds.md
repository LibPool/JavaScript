# @funnelback/ng-sds

> 标签: angular, design, funnelback, ng, ngx, squiz, system

## 简介

`@funnelback/ng-sds` is Bootstrap 5 based library that aims to implement the [Squiz Design System specification](https://designsystem.squiz.net/) in Angular.
