# @loopthink/n8n-nodes-loopthink

> 标签: loopthink, mcp, n8n-community-node-package, runner

## 简介

Run loopthink MCP tools from inside your own network. The node reaches out to loopthink, claims tool calls, executes them against your internal HTTP APIs and returns masked results — no inbound connection required.
