## 简介

面向全国所有省份的通用高考志愿填报建议器 Agent Skill：省份快速学习协议现查现学任意省当年规则，默认保守冲稳保三档，输出可直接录入本省志愿系统的草表。位次锁定推演、官方源+历年+多源交叉验证、零杜撰。A universal China Gaokao college-application advising Agent Skill (SKILL.md format).
