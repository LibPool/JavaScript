# @doeixd/incremental

> 标签: builder, composition, exhaustive, foldkit, incremental, object-builder, type-level, type-safety, typescript

## 简介

A typed fold over object contributions: build an object piece by piece, know its exact shape at every step, and prove when it is complete.
