# @ngxviewbuilder/plugin-logic-map

> 标签: angular, dependency-graph, form-builder, logic, low-code, plugin, view-builder

## 简介

Logic map plugin for the NGX View Builder designer: every condition, calculation, event and data source of a view on one canvas, so anyone can see how a large form works.
