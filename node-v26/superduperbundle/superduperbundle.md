# superduperbundle

> 标签: api client, deals, game keys, game prices, price comparison, steam, superduperbundle

## 简介

Client for the free SuperDuperBundle Game Price API: lowest listed PC game key prices by name, Steam app ID or store URL.

## 官网

- 官网：https://superduperbundle.com/tools/api/
- 源码仓库：git+https://github.com/superduperbundle/game-price-api.git
