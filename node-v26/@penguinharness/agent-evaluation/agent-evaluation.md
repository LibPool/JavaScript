# @penguinharness/agent-evaluation

> 标签: penguin-plugin, penguinharness, skills

## 简介

Agent Evaluation: design and calibrate a capability Benchmark for an agent (or import a published Benchmark package), and run and privately score its cases one isolated execution at a time — the measurements the Default RSI Toolkit's optimization loop run
