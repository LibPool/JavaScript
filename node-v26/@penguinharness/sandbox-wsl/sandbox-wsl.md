# @penguinharness/sandbox-wsl

> 标签: bubblewrap, network-isolation, path-masking, penguin-plugin, penguinharness, sandbox, windows, wsl

## 简介

WSL sandbox backend for PenguinHarness on Windows: commands run in a dedicated WSL2 distro under bubblewrap, with Windows interop switched off.

## 官网

- 源码仓库：git+https://github.com/Prism-Shadow/penguin-harness.git
- npm 页面：https://www.npmjs.com/package/@penguinharness/sandbox-wsl
