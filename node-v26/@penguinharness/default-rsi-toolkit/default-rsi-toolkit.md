# @penguinharness/default-rsi-toolkit

> 标签: penguin-plugin, penguinharness, skills

## 简介

The Default RSI Toolkit: the trial → reflect → improve loop as one Skill — improve an agent from its measured Benchmark results, round after round, with a snapshot before every round. It measures through the agent-evaluation Skill of the Agent Evaluation
