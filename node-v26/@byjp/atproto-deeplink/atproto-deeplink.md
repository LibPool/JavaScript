# @byjp/atproto-deeplink

> 标签: at-uri, atproto, bluesky, deeplink, lexicon, microcosm

## 简介

Resolve at:// URIs into website/app URIs via the me.byjp.atproto.deeplink lexicons, using microcosm for record & identity lookups.
