# @jinsiyu/dshcs-vscode-server

> 标签: JavaScript

## 简介

The VS Code server tree from code-server 4.136.2 (lib/vscode + browser assets), repacked so pnpm installs it without any build script. The code-server Node layer is replaced by the plugin launcher.
