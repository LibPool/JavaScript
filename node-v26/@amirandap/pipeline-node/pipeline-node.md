# @amirandap/pipeline-node

> 标签: document-extraction, openai, pdf-split, purchase-orders, responses-api, structured-outputs

## 简介

The purchase-order extraction layer in Node: live prompt/schema loading with the is_active guard, catalogues rendered per run, the Responses API request builder with its precheck, token-usage parsing and the free header signal for safe document splitting.
