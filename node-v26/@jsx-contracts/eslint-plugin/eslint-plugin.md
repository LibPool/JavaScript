# @jsx-contracts/eslint-plugin

> 标签: composition, contracts, design-system, eslint, eslint-plugin, eslintplugin, jsx, react, slots

## 简介

ESLint plugin that enforces JSX composition contracts — declared slot and subtree rules for how components may be nested.
