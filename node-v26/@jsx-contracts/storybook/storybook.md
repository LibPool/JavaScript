# @jsx-contracts/storybook

> 标签: composition, contracts, design-system, documentation, jsx, react, slots, storybook

## 简介

The ContractDocs Storybook doc block for JSX composition contracts — renders the @jsx-contracts/authoring description IR as documentation sections and tables inside a Storybook story.
