# @capacitor/local-llm

> 标签: ai, android, capacitor, ios, llm, local-llm, machine-learning, native, on-device, plugin

## 简介

A Capacitor plugin for running on-device LLMs, with support for text generation, image generation, and session management on iOS and Android.
