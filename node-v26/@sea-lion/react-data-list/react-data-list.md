# @sea-lion/react-data-list

> 标签: JavaScript

## 简介

DataList 是一个用于展示键值对列表的组件，通常用于展示属性、配置和详细信息。支持水平/垂直方向、多种尺寸、自定义对齐方式、标签颜色，以及响应式布局。
