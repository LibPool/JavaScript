# @geckovision/gecko

> 标签: agent-security, agent-tools, ai-agents, api-integration, cli, gecko, knowledge-graph, mcp, openapi, solana

## 简介

The knowledge graph for APIs your agent can trust — map any API into a verified graph your agent traverses instead of guessing, and simulate any action to a receipt before money moves.
