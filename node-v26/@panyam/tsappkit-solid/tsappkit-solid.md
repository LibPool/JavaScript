# @panyam/tsappkit-solid

> 标签: component, island, lifecycle, solid, solid-js, tsappkit

## 简介

Solid adapter for @panyam/tsappkit: mount Solid islands inside the tsappkit component lifecycle. The framework-specific reactivity lives here so tsappkit core stays framework-neutral.
