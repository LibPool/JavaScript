# finecss

> 标签: css, miniprogram, rpx, tailwind, uni-app, utility-css, weapp

## 简介

rpx-first utility CSS engine for uni-app (WeChat mini-program / App / H5). p-1 = 1rpx, JIT on-demand generation, tiny output.
