# @sp-treeview/element

> 标签: aria, checkbox, custom-elements, dropdown, lit, multiselect, tree, tree-select, tree-view, treeview, web-components

## 简介

Native Web Components <sp-tree> and <sp-tree-select>: WAI-ARIA tree, checkbox/radio selection with cascade, lazy loading, search, dropdown field with chips. Works in React, Vue, Svelte, Angular, plain HTML.
