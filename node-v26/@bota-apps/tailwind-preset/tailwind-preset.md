# @bota-apps/tailwind-preset

> 标签: bota-apps, design-tokens, postcss, preset, tailwind, tailwindcss, theme, typescript

## 简介

The @bota-apps Tailwind preset (design tokens), a ready-made PostCSS config, and the theme CSS variables (light + dark) that the components render against.
