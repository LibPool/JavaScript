# @pubinfo/module-rbac

> 标签: JavaScript

## 简介

Pubinfo 的权限与后台管理模块。它既提供 RBAC 相关页面和组件，也负责根据配置注册权限管理路由、初始化路由视图数据，并建立模块内部的 WebSocket 同步能力。
