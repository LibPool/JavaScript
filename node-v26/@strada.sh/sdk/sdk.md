# @strada.sh/sdk

> 标签: error-tracking, observability, opentelemetry, otel, sdk, strada, tracing

## 简介

OTel-first Strada SDK. Sentry-like error capture and auto-instrumentation for Node.js and browsers, powered by OpenTelemetry.
