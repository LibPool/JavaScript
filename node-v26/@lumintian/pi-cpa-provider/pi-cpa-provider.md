# @lumintian/pi-cpa-provider

> 标签: cliproxyapi, codex, cpa, pi-extension, pi-package

## 简介

Pi provider extension for one or more CLIProxyAPI (CPA) instances: per-instance model discovery, Codex Responses over WebSocket/SSE, and per-model Fast.
