# @wjunhere/dsh-prompt-lab

> 标签: deepseek-harness, dsh, dsh-plugin, inspector, system-prompt, tools

## 简介

会话顶栏的提示词与工具检查器：查看每轮实际发送的系统提示词、工具定义与请求载荷，并能编辑追加指令与工具描述。
