# @cyberneurova/dsh-catalog

> 标签: JavaScript

## 简介

CyberNeurova live-catalog plugin for the DeepSeek Harness: fetches GET /models and maps it to the dsh-llm adapter catalog (with optional llm model-discovery wiring)
