# @stdlib/stats-base-ndarray-snanmskmax

> 标签: float32, mask, masked, math, mathematics, max, maximum, ndarray, single-precision, statistics, stats, stdlib, stdmath

## 简介

Calculate the maximum value of a one-dimensional single-precision floating-point ndarray according to a mask, ignoring NaN values.
