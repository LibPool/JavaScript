# @stdlib/math-strided-special-smskcbrt

> 标签: array, cbrt, cube, cubic, element-wise, float, float32, float32array, flt, mask, masked, math, math.cbrt, mathematics, missing, missing values, na, ndarray, power, root, single-precision, stdlib, stdmath, strided, vector

## 简介

Compute the cube root for each element in a single-precision floating-point strided array according to a strided mask array.
