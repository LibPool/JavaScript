# @stdlib/stats-base-ndarray-dnanmidrange

> 标签: math, mathematics, max, midrange, min, ndarray, range, statistics, stats, stdlib, stdmath

## 简介

Compute the mid-range of a one-dimensional double-precision floating-point ndarray, ignoring NaN values.
