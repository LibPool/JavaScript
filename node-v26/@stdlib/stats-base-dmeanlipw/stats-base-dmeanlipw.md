# @stdlib/stats-base-dmeanlipw

> 标签: arithmetic mean, array, average, avg, central tendency, double, float64, float64array, math, mathematics, mean, one-pass, pairwise, pw, statistics, stats, stdlib, stdmath, strided, strided array, typed, welford

## 简介

Calculate the arithmetic mean of a double-precision floating-point strided array using a one-pass trial mean algorithm with pairwise summation.
