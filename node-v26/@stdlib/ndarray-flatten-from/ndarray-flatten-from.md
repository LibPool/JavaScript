# @stdlib/ndarray-flatten-from

> 标签: array, copy, flat, flatten, flatten-from, matrix, multidimensional, ndarray, reshape, stdlib, tensor, transform

## 简介

Return a copy of an input ndarray where all dimensions of the input ndarray are flattened starting from a specified dimension.
