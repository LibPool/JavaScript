# @stdlib/blas-ext-base-wasm-dnanasumors

> 标签: abs, absolute, array, blas, double, extended, float64, float64array, l1-norm, l1norm, manhattan, math, mathematics, norm, ors, statistics, stats, stdlib, stdmath, strided, strided array, sum, summation, taxicab, total, typed, wasm, webassembly

## 简介

Calculate the sum of absolute values (L1 norm) of double-precision floating-point strided array elements, ignoring NaN values and using ordinary recursive summation.
