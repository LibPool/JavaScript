# @stdlib/stats-base-ndarray-dnanmeanwd

> 标签: arithmetic mean, average, avg, central tendency, math, mathematics, mean, nan, ndarray, statistics, stats, stdlib, stdmath, welford, welfords algorithm

## 简介

Compute the arithmetic mean of a one-dimensional double-precision floating-point ndarray, ignoring `NaN` values and using Welford's algorithm.
