# @stdlib/stats-base-ndarray-snanmskrange

> 标签: mask, masked, math, mathematics, nan, ndarray, range, single-precision, statistics, stats, stdlib, stdmath

## 简介

Calculate the range of a one-dimensional single-precision floating-point ndarray according to a mask, ignoring NaN values.
