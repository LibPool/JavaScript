# @stdlib/stats-nanminabs

> 标签: domain, extent, extremes, math, mathematics, min, minimum, ndarray, range, statistics, stats, stdlib, stdmath

## 简介

Compute the minimum absolute value along one or more ndarray dimensions, ignoring `NaN` values.
