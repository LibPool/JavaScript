> 标签: blas, compensated, double, extended, float64, float64array, math, mathematics, ndarray, pairwise, statistics, stats, stdlib, stdmath, sum, summation, total

## 简介

Compute the sum of a one-dimensional double-precision floating-point ndarray, ignoring `NaN` values and using pairwise summation.
