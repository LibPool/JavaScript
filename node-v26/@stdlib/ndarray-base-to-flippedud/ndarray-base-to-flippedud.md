# @stdlib/ndarray-base-to-flippedud

> 标签: base, data, flip, flipud, matrix, ndarray, numpy.flipud, reverse, rows, slice, stdlib, stdtypes, structure, types, updown, vector, view

## 简介

Return a new ndarray where the order of elements along the second-to-last dimension of an input ndarray is reversed.
