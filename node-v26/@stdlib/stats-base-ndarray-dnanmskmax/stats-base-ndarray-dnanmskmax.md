# @stdlib/stats-base-ndarray-dnanmskmax

> 标签: domain, extent, extremes, mask, masked, masked array, math, mathematics, max, maximum, ndarray, range, statistics, stats, stdlib, stdmath

## 简介

Compute the maximum value of a double-precision floating-point ndarray according to a mask, ignoring `NaN` values.
