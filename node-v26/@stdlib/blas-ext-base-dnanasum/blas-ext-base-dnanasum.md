# @stdlib/blas-ext-base-dnanasum

> 标签: abs, absolute, array, blas, double, extended, float64, float64array, l1-norm, l1norm, manhattan, math, mathematics, norm, statistics, stats, stdlib, stdmath, strided, strided array, sum, summation, taxicab, total, typed

## 简介

Calculate the sum of absolute values (L1 norm) of double-precision floating-point strided array elements, ignoring NaN values.
