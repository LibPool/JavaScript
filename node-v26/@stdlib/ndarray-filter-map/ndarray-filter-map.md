# @stdlib/ndarray-filter-map

> 标签: apply, array, copy, extract, filter, for-each, map, ndarray, reject, select, stdlib, strided, take, transform

## 简介

Filter and map elements in an input ndarray to elements in a new output ndarray according to a callback function.
