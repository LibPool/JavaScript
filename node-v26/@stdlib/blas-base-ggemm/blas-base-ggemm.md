# @stdlib/blas-base-ggemm

> 标签: algebra, array, blas, gemm, ggemm, level 3, linear, math, mathematics, matmul, matrix, matrix multiplication, multiplication, ndarray, stdlib, stdmath, subroutines

## 简介

Perform the matrix-matrix operation `C = α*op(A)*op(B) + β*C` where `op(X)` is either `op(X) = X` or `op(X) = X^T`.
