# @beatzball/create-litro

> 标签: cli, create, elena, fast-element, fullstack, lit, nitro, scaffold, ssg, ssr, starter, template, typescript, web-components

## 简介

Scaffold a new Litro app — fullstack SSR, Markdown blog, or docs site. Pick Lit, FAST Element, or Elena via --adapter; built on web components and the Nitro server.
