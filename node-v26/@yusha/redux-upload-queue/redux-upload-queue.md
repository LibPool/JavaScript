# @yusha/redux-upload-queue

> 标签: JavaScript

## 简介

- 可创建多个上传队列，每个队列独立管理 - 批量上传 - 取消上传 - 批量上传过程中失败，重新以失败的地方开始上传 - 上传进度监听
