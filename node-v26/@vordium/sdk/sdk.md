# @vordium/sdk

> 标签: eip-712, perpetuals, sdk, vordex, vordium

## 简介

TypeScript and JavaScript SDK for Vordium Chain and the Vordex perpetuals exchange: signing, orders, session keys, agents, TWAP, margin mode and live feeds.
