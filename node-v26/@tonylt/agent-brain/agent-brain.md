# @tonylt/agent-brain

> 标签: agent, coding-agent, memory, pi, pi-package, self-evolution

## 简介

Long-term memory and self-evolution for coding agents: cross-session Markdown memory, a confidence-graded user profile, an append-only evolution log, and automatic closeout reflection. Currently supports the pi coding agent; codex and Claude Code adapters
