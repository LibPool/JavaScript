# @oc-health-sync/health-sync

> 标签: apple-health, health, healthkit, openclaw, openclaw-plugin, sqlite

## 简介

Receives Apple HealthKit data from the oc-health-sync iOS app, stores it locally in SQLite, and provides agent tools for health data analysis.
