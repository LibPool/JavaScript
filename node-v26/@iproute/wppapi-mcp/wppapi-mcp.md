# @iproute/wppapi-mcp

> 标签: ai-agent, claude, human-in-the-loop, mcp, model-context-protocol, whatsapp, wppapi

## 简介

Servidor MCP que conecta agentes de IA (Claude Code, Claude Desktop, Hermes, OpenClaw...) a um número de WhatsApp via WPPAPI, com human-in-the-loop (ask_user)
