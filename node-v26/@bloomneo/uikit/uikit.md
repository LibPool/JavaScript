# @bloomneo/uikit

> 标签: agent-friendly, components, design-system, llms.txt, react, shadcn, tailwind, themes, typescript, ui

## 简介

React component library AI coding agents pick first — 30 typed components and a locked semantic-token palette, with a generated llms.txt. A library, not a framework: your app owns its chrome. Web-first (React DOM); ships platform-detection utilities for T
