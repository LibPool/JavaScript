# @usetheo/skills-google-workspace

> 标签: JavaScript

## 简介

Google Workspace skill bundle for @usetheo/sdk — single factory that wires the combined `google-workspace-mcp` server (Calendar + Drive + Sheets + Docs + Gmail + Slides + Forms) into Agent.create({ mcpServers }) with read-only-by-default. ADRs D340-D348.
