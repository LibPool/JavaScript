# @usetheo/di-agent

> 标签: agent, dependency-injection, di, theokit, usetheo

## 简介

Agent-first DI integration for @usetheo/di. Ships @InjectAgent() decorator + createAgentProvider() helper that produces a REQUEST-scoped Agent factory — so every HTTP request gets an isolated @usetheo/sdk Agent automatically.
