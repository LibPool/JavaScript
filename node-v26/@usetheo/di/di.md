# @usetheo/di

> 标签: container, decorators, dependency-injection, di, inversion-of-control, ioc, theokit, typescript, usetheo

## 简介

Lightweight TypeScript dependency injection container for the theokit ecosystem (foundation for @usetheo/orm + @usetheo/http-decorators). NestJS-compatible API with @Injectable, @Inject, @Module + 3 scopes (SINGLETON/TRANSIENT/REQUEST) + agent-aware via @
