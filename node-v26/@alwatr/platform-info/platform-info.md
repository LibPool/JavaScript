# @alwatr/platform-info

> 标签: ECMAScript, alwatr, browser, cross-platform, deno, esm, is-browser, is-deno, is-electron, is-node, is-nwjs, is-web-worker, javascript, module, nanolib, node, nodejs, nwjs, platform, platform-detection, platform-info, typescript, util, utility, utils, web-worker

## 简介

This module provides a way to detect the current platform where the script is running. It defines a constant `platformInfo` which holds the information about the current platform.
