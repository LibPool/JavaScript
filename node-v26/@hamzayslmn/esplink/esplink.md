# @hamzayslmn/esplink

> 标签: esp32, esp32-s3, firmata, gpio, i2c, iot, spi, web-bluetooth, web-serial

## 简介

Drive every ESP32 peripheral from JavaScript over USB serial, Bluetooth or Wi-Fi — in the browser (Web Serial / Web Bluetooth) or Node.
