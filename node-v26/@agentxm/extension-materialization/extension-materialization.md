# @agentxm/extension-materialization

> 标签: JavaScript

## 简介

AXM extension materialization: the per-extension-type manager contract and implementations, canonical package staging, registry materialization, and the install/uninstall/authored closure recipes for the axm CLI. Unstable and unsupported — use the axm.sh
