# @agentxm/workspace-conventions

> 标签: JavaScript

## 简介

Engineering conventions for Nx and pnpm TypeScript workspaces: an ESLint flat-config preset that enforces capability boundaries and a staged commit gate for Git pre-commit hooks. Engineering support, not part of the runtime. Unstable and unsupported.
