# @awacloud/fonts

> 标签: apple-aat, browser, cff, color-fonts, embed-pdf, font-subset, gpos, gsub, opentype, otf, sfnt, truetype, ttf, variable-fonts, woff, woff2

## 简介

Browser-safe TrueType / OpenType reader, writer and subsetter — OT v1.9 + TT RM05 hinting, hardened against malformed-font parser attacks. Zero runtime dependency beyond @awacloud/fw.
