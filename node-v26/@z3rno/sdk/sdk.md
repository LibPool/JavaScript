# @z3rno/sdk

> 标签: JavaScript

## 简介

TypeScript/Node bindings for z3rno, built with [napi-rs](https://napi.rs) — native compiled bindings over `z3rno-engine`, not a thin HTTP client. The SDK *is* the engine.
