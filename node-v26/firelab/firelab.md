# firelab

> 标签: adb, android-tv, devtools, fire-os, fire-tv, firetv, games, mcp, model-context-protocol, performance, testing, webgl, webview

## 简介

Test and tune apps and games on real Fire TV and Android TV devices: an MCP server for AI agents, a CLI and a live dashboard, plus a WebView performance sweep.
