# @d3ara1n/pi-mesh

> 标签: pi, pi-extension, pi-package

## 简介

Agent mesh for pi — peer discovery + cross-instance transport. The neutral foundation that pi-peek-agent, chat-room, and other multi-instance workflows build on. Self-sufficient: install alone to discover peers and self-introduce a role.
