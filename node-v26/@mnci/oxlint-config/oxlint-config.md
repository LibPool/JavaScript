# @mnci/oxlint-config

> 标签: lint, mnci, nx, oxc, oxfmt, oxlint

## 简介

The shared oxlint + oxfmt config every mnci-generated monorepo can use — the same lint and style opinion as @mnci/eslint-config, on the Rust toolchain, with the rules oxlint lacks bridged from the real ESLint plugins.
