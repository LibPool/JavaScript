# blueprint-runtime

> 标签: automation, blueprint, ci, cli, integromat, linter, low-code, make, make-blueprint, make-scenario, make.com, makecom, no-code, offline, regression-testing, scenario-testing, test-runner, testing, validator, workflow-automation

## 简介

Test Make.com (Integromat) scenarios offline: run exported blueprints locally, replay real Make runs and catch broken mappings before deploy. CLI test runner and blueprint validator, CI ready.
