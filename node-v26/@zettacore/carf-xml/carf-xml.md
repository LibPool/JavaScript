# @zettacore/carf-xml

> 标签: carf, crypto-asset reporting framework, dac8, oecd, tax, xml, xsd

## 简介

Build, validate and explain OECD Crypto-Asset Reporting Framework (CARF) XML messages, exactly as the official OECD XML Schema defines them.
