# @autlantic/checkout

> 标签: android, autlantic, billing, checkout, ios, payments, react-native, usdc

## 简介

Autlantic Billing mobile Checkout presenter for React Native. Opens hosted checkoutUrl via ASWebAuthenticationSession (iOS) and Chrome Custom Tabs (Android). No API keys.
