# @fooxe/dsh-memory

> 标签: claude-code, deepseek-harness, dsh, dsh-plugin, memory

## 简介

Hierarchical Claude Code-style persistent memory for DeepSeek Harness: user + project (git-shared) scopes, session-start auto-injection, MEMORY.md index guards. Pure files, zero dependencies.
