# dsh-vidlens

> 标签: asr, deepseek-harness, dsh, dsh-plugin, sound-events, tool, transcript, video, vidlens

## 简介

VidLens for DeepSeek Harness: turn a public video into an evidence table (timecoded transcript, sampling sheets, sound events, comments) without downloading the whole file. 18 native tools backed by the local vidlens Python core.
