# @duro-app/ui

> 标签: JavaScript

## 简介

Duro's components, written with [react-strict-dom](https://github.com/facebook/react-strict-dom): one source for the web and for React Native. Component docs, props and recipes: `npx @duro-app/cli <Name>`, or the repository's `CLAUDE.md`.
