# @agentghost/sdk

> 标签: agents, ai, authorization, guard, jev, middleware, tools, typesafe

## 简介

Intent-aware authorization middleware for AI agent tools. Wraps tool execution in an ALLOW / ASK / DENY check powered by Jev.
