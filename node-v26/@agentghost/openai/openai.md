# @agentghost/openai

> 标签: agents, ai, anthropic, authorization, guard, openai, tools

## 简介

AgentGhost guard for OpenAI and Anthropic function/tool calling. Wrap the tool dispatcher with intent-aware ALLOW / ASK / DENY authorization.
