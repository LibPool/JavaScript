# @gatedpath/contract-kit

> 标签: JavaScript

## 简介

Contract kit v1 for Redbelly Network: a gated ERC-20 on OpenZeppelin 5.x with both-party eligibility, a compliance role with justified forced transfers, pause, an issuer registry with time-boxed mint permissions, and the Safe plus timelock admin pattern.
