## 简介

One payments plugin for Vendure: Stripe, Adyen, PayPal, Mollie, Square, Braintree, GoCardless, Checkout.com, Coinbase Commerce, bank transfer and pay-later behind a single contract — a hosted checkout page, wallets, 3-D Secure, captures, refunds, disputes
