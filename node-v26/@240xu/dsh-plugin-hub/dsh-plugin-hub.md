# @240xu/dsh-plugin-hub

> 标签: dsh-plugin

## 简介

One-line DSH plugin bundle: aggregates websearch, message-ops, session-lazy-view and session-search with per-row failure isolation. 一键安装的 DSH 插件聚合包。
