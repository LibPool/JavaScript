# @auditrxyz/sdk

> 标签: agent, agentkit, audit, auditr, coinbase, eip-3009, security, usdc, web3, x402

## 简介

TypeScript SDK for the Auditr x402 API. Pay per call in USDC for audits and monitoring. Run x402 settlements through the Auditr-hosted facilitator: 25 free Solana settles/month + $10 USDC top-up, gas pass-through.
