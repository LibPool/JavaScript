# loupe-mcp

> 标签: claude, codex, cursor, design-qa, figma, loupe, mcp

## 简介

MCP server for Loupe: compare a Figma frame with a live page, and check accessibility and responsive layout (including localhost), so Claude Code, Codex or Cursor can fix what it finds.
