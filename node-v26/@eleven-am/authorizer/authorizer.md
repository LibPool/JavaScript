# @eleven-am/authorizer

> 标签: JavaScript

## 简介

Authorization for NestJS applications using [CASL](https://casl.js.org/). Defines permissions via decorators, checks them automatically through a guard, and exposes the built CASL ability to handlers. Works across HTTP, GraphQL, and PondSocket transports
