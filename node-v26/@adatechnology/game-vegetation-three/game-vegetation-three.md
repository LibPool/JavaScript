# @adatechnology/game-vegetation-three

> 标签: game, plants, test-room, three, threejs, trees, vegetation

## 简介

The vegetation test module for the shared test room: the 18 plants of the Viveiro as destructible items (separable pieces, joints, real wood thickness, sway clips), its 13 scenarios and the nursery lot with the walker that bends the plants.
