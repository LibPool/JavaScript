# @adatechnology/game-vfx

> 标签: deterministic, effects, explosion, game, particles, vfx

## 简介

Renderer-free visual effects, deterministic and testable in Node: the Explosion Lab's layer compositor (flash, fireball that cools into smoke, shock wave, dust, shrapnel, glowing debris, marks, mushroom, lingering fire) with its 16 profiles, seeded random
