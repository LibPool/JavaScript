# @adatechnology/game-infection

> 标签: deterministic, epidemic, game, infection, seeded, simulation, zombie

## 简介

Deterministic abstract epidemic model by regions (anything that spreads by contact with a delay: zombies, plague, rumours). Knows nothing about any game.
