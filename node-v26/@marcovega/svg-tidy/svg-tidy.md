# @marcovega/svg-tidy

> 标签: cli, icons, minify, npx, optimize, svg, svgo, svgomg

## 简介

Optimize SVG icons in a directory using SVGO. Writes a .svgtidy.json config on first run so you can customize and commit settings per project.
