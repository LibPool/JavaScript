# web-terrarium

> 标签: demo, desktop, electron, mock-server, nextjs, nodejs, offline, vite

## 简介

Package a Node.js web app (Next.js, Vite, Express) and its local servers, such as a mock backend, as a Windows or Mac desktop app (Electron).
