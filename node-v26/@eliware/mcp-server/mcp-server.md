# @eliware/mcp-server

> 标签: ai-tools, authentication, dependency-injection, dynamic-tools, esm, mcp, mcp-server, model-context-protocol, nodejs, oauth2, pkce, stateless, stdio, streamable-http, tls, tool-discovery, zod

## 简介

Pure-ESM Node.js MCP server with automatic tool discovery, Streamable HTTP and stdio transports, TLS, Zod schemas, injectable context, bearer authentication, and generic OAuth2 support.
