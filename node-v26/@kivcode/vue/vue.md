# @kivcode/vue

> 标签: kiv, page-builder, visual-editor, vue, vue3

## 简介

Vue 3 renderer for the Kiv visual page-builder — a component per node type, plus KivRenderer/KivNodeRenderer to walk and render a KivDocument.
