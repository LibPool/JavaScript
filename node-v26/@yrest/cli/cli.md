# @yrest/cli

> 标签: api-mock, cli, crud, db.yml, fake-api, fake-backend, fastify, frontend, frontend-development, json-server, json-server-alternative, mock, mock-api, mock-server, prototyping, rest, rest-api, testing, typescript, yaml, yaml-rest, yaml-server, yml, yrest

## 简介

YAML-powered json-server alternative. Zero-config REST API mock server with full CRUD, relations, filters and snapshots from a db.yml file.
