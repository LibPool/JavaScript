# @rarcifa/cronos-evm-client

> 标签: blockchain, crc20, crc721, cronos, ethereum, evm, nodejs

## 简介

A Node.js client library for interacting with the Cronos EVM, facilitating operations on both CRC20 and CRC721 tokens.
