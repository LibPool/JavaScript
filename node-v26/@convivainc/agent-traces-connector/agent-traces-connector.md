# @convivainc/agent-traces-connector

> 标签: baggage, conviva, observability, opentelemetry, otel, tracing

## 简介

OpenTelemetry helper that copies allowlisted W3C baggage entries (e.g. c3.*) onto every span and ensures the baggage propagator is registered.
