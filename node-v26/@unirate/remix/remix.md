# @unirate/remix

> 标签: currency, currency-converter, exchange-rates, fintech, forex, fx, loader, money, react-router, react-router-7, remix, unirate

## 简介

Remix / React Router 7 integration for the UniRate currency-exchange API. Server-side loader utilities, a proxy resource-route handler that keeps your API key server-side, and createUniRate() factory for use in loaders and actions. Zero runtime deps.
