# koishi-plugin-anime-schedule

> 标签: anilist, anime, bangumi, bangumi-data, calendar, chatbot, koishi, schedule, subscription

## 简介

番剧时间表与订阅提醒：提供日 / 周 / 季三表，支持定时推送、指定订阅、搜索和详情展示
