# @spectastic/schema

> 标签: ast, ci, html, linter, parse5, sarif, spec-driven-development, specs, spectastic, typescript, validator

## 简介

Spec-html validation schema and engine. The TypeScript module form of the spec-* vocabulary's grammar — used by @spectastic/cli, MCP servers, and editor extensions.
