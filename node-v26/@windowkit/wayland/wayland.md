# @windowkit/wayland

> 标签: compositor, wayland, wayland-client, wayland-protocol, xdg-shell

## 简介

Pure JavaScript Wayland client: the wire protocol, proxies generated from protocol XML, and file descriptor passing. A fork of wayland-client.
