# @stretis/piper-sdk

> 标签: api, automation, integration, oauth, openapi, sdk

## 简介

Node.js SDK for indie automation platforms: list app/action nodes for your picker UI, render their input forms, and turn filled forms into ready-to-fire API requests. Node-for-node port of piper_sdk.py.
