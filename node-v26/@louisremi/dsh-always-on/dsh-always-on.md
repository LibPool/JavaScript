# @louisremi/dsh-always-on

> 标签: container, deepseek-harness, docker, download, dsh, dsh-plugin, editor, monaco, remote

## 简介

DeepSeek Harness plugin for harnesses running in a container, with no access to your local file system: download buttons instead of "Show file location", a "Show files" shortcut, and an in-sidebar Monaco file editor, all through the browser.
