# @louisremi/dsh-docker-adapter

> 标签: deepseek-harness, download, dsh, dsh-plugin

## 简介

DeepSeek Harness plugin: replaces the "Show file location" buttons with "Download file" buttons, for Harnesses running on a remote host (NAS, Docker, server).
