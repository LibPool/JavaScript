# @nullifyads/agent-guard

> 标签: ai-agents, browser-agents, clickjacking, computer-use, playwright, prompt-injection, security

## 简介

Stops AI browser agents from being clickjacked: every Playwright click lands on what is visible, or is refused with a reason the agent can act on.
