# @form-making/ui

> 标签: JavaScript

## 简介

Form-making internal UI primitives: shadcn-vue + Tailwind v4 components & ConfigProvider. Not a general-purpose UI library; API is stable for first-party consumers only (core/designer/renderer/platform-web/examples).
