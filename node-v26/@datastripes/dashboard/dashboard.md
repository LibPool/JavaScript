# @datastripes/dashboard

> 标签: JavaScript

## 简介

Zero-backend, in-memory dashboard builder (drag-and-drop grid, JSON-driven widgets, ECharts rendering) with drop-in components for React, Vue, Angular, and vanilla Custom Elements, shipped as one package with one subpath per framework.
