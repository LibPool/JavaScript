# @dawn-studio/theme

> 标签: dark-mode, dawn-studio, light-mode, localStorage, theme

## 简介

Dark/light theme for Dawn Studio apps: localStorage persistence, data-theme + theme-color sync, FOUC-prevention head script. Vanilla, zero deps.
