# @8bitscript/examples

> 标签: JavaScript

## 简介

The example programs that ship with the toolchain: hello-world, the 0.2.0 goal program, joystick, the controller test app, fancy, the raster showpiece, and swarm, the moving-objects showpiece — listed in the editor's launcher beside your own projects.
