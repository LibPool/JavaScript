# @8bitscript/raster

> 标签: JavaScript

## 简介

Per-scanline raster effects, named by what the picture does at a line — a border split, a background band, a horizontal wobble — rather than by which register to write. Resolves per target to that machine's own rasterline implementation; #fact(video.raste
