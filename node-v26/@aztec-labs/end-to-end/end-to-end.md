# @aztec-labs/end-to-end

> 标签: JavaScript

## 简介

This package holds Aztec's end-to-end (e2e) tests: full-stack scenarios that spin up an Aztec node (or several), a PXE, and an L1 (anvil) and exercise the system the way a real deployment would. It is the integration layer above the per-package unit tests
