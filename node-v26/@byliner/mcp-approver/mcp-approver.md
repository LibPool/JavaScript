# @byliner/mcp-approver

> 标签: approval, byliner, human-in-the-loop, mcp, modelcontextprotocol, review

## 简介

MCP server letting a human approver read their Byliner approval queue. Read-only — decisions are made in the dashboard, never through a tool call.
