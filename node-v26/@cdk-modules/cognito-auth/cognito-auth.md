# @cdk-modules/cognito-auth

> 标签: JavaScript

## 简介

This module provides authentication and authorisation mechanisms for human stakeholders that use the system. It uses Amazon Cognito to enable you to store your own user base within your deployment, and allows you to define RBAC policies for individual use
