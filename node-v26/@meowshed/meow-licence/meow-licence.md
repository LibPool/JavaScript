# @meowshed/meow-licence

> 标签: meowpaw, pi-package

## 简介

Adds the licence header a repository declares to each file Claude Code creates, never rewrites one, and checks that every tracked file is covered by the licensing declared in REUSE.toml, in .meowpaw/profile.toml or in its files' headers. It keeps up to 38
