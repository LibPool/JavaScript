# @meowshed/meow-starlark

> 标签: meowpaw, pi-package

## 简介

Detects Bazel and Buck workspaces from what git tracks, names the build system that evaluates the Starlark before it binds anything, prints a stages table bound from the buildifier configuration and the workspace file the repository committed with Bazel's
