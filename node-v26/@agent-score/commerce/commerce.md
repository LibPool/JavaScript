# @agent-score/commerce

> 标签: 402, agent-commerce, agentic-payments, agentscore, ai-agent, base, express, fastify, hono, identity, kyc, machine-payments-protocol, middleware, mpp, nextjs, solana, stripe, tempo, trust, x402

## 简介

Agentic commerce SDK: identity middleware (Hono, Express, Fastify, Next.js, Web Fetch) + payment helpers + 402 builders + discovery + Stripe multichain. The full merchant-side toolkit for AgentScore-powered agentic commerce.
