# @sashaid/email-mcp

> 标签: claude, claude-code, email, imap, mcp, model-context-protocol, smtp

## 简介

MCP server for multi-account email over IMAP/SMTP — search, read, send, triage, with 1Password and Microsoft 365 OAuth support.
