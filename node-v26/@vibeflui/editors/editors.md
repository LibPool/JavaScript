# @vibeflui/editors

> 标签: codemirror, editor.js, editorjs, fluikit, form generator, json to ui, markdown, richtext, schema ui, schema-driven, schema-driven ui, table list generator, tiptap, ui generator, vibe coder, vibe coding, vibeflui, vibeflui antd, vibeflui/antd

## 简介

Rich-text (TipTap), code (CodeMirror), markdown (react-md-editor), and Editor.js (with full block-tool wiring) field adapters for VibeFlui / FluiKit.
