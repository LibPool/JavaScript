# agent-virtual-world

> 标签: 3d, ai-agent, claude, cline, cursor, llm-agent, llm-tools, mcp, metaverse, model-context-protocol, virtual-world

## 简介

Let your AI walk into a live 3D virtual world: observe the scene, talk to real human players, and be seen by them — over MCP (Claude Desktop / Cursor / Cline). Zero-credential guest mode: just set AGENT_HOST.
