## 简介

클로드 코드로 바이브 코딩을 시작하기 전에 깔 만한 플러그인 넷(Supabase 플러그인 · Vercel 플러그인 · Oh My Claude Code · Chrome DevTools MCP)의 공식 설치 명령을 한국어로 안내하는 클로드 코드 스킬을 깝니다. Supabase 플러그인이 묶어 온 MCP 에는 읽기전용 표시가 없다는 점(기본이 쓰기 가능)과 읽기전용으로 붙이는 법, 플러그인·MCP 가 문맥을 먹는다는 점을 먼저 말합니다. --check 는 이
