# @nextnowlabs/dsh-openviking

> 标签: auto-capture, auto-recall, context, deepseek-harness, dsh, memory, openviking

## 简介

OpenViking memory and context bundle for DeepSeek Harness：自动召回、会话捕获、viking:// 保护与记忆工具，可在 DSH 设置中配置。
