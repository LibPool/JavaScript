# @rick427/react-native-face-verify

> 标签: android, biometrics, face-recognition, face-verification, identity, ios, mlkit, react-native, rekognition, vision-camera

## 简介

Face verification library for React Native — compares a reference image against a live front-camera capture using ML Kit quality checks and AWS Rekognition or a custom endpoint
