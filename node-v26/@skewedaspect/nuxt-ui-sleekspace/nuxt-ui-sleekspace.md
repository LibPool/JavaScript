# @skewedaspect/nuxt-ui-sleekspace

> 标签: dark-theme, nuxt-ui, sci-fi, sleekspace, tailwindcss, theme, vite, vue

## 简介

Restyles Nuxt UI v4 with the SleekSpace design system: beveled corners, OKLCH ramps, glows, self-hosted Titillium Web, and runtime color schemes.
