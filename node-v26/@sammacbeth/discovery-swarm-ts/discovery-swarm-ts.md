# @sammacbeth/discovery-swarm-ts

> 标签: JavaScript

## 简介

A pluggable implementation of [discovery-swarm](https://github.com/mafintosh/discovery-swarm). Enables multiple different _introductors_, _announcers_ and _transports_ to be specified at runtime and used to discover and connect to peers.
