# @retorna-tech/retorna-gateway-sdk

> 标签: b2b, cpg, gateway, oauth2, payments, remittances, retorna, sdk, typescript

## 简介

Retorna Gateway SDK — SDK oficial para integrar Retorna Gateway (B2B API) en aplicaciones Node.js y TypeScript. Autenticación OAuth2 y firma de requests, cotizaciones, órdenes, rutas, billeteras y reportes mediante una interfaz fluida y tipada.
