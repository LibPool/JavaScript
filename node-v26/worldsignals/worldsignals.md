# worldsignals

> 标签: agents, ai-agents, cli, cloudevents, companies, cve, events, mcp, outages, tenders, vulnerabilities, webhooks

## 简介

WorldSignals for code and AI agents: real-world events (new companies, tenders, vulnerabilities, outages, AI models) as one standard stream. Command line tool now; SDK and MCP server next.
