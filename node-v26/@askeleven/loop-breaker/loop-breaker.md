# @askeleven/loop-breaker

> 标签: ai-agents, auto-submitted, autoresponder, bounce, email, mail-loop, mcp, mcp-server, out-of-office, rfc3834, sms

## 简介

Stop your agent replying to an autoresponder, a bounce, or another bot. Checks a thread before every reply for the signs of a loop, on any channel, with an optional ledger across threads. CLI, library, and MCP server. Zero dependencies.
