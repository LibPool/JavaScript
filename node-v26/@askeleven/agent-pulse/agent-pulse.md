# @askeleven/agent-pulse

> 标签: ai-agents, alerting, cron, dead-mans-switch, heartbeat, liveness, mcp, mcp-server, monitoring, watchdog

## 简介

Know your agent stopped working before your customer does. Alerts on missing activity, failure streaks and undelivered messages from a JSONL event log. CLI, library, and MCP server. Zero dependencies.
