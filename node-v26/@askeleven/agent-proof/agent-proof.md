# @askeleven/agent-proof

> 标签: agents, ai-agents, demo-video, ffmpeg, observability, playwright, screen-recording, social-video

## 简介

Record an AI agent doing a real task as one uncut vertical video, with captions placed by the agent's own step events. No staging, no edits, no voiceover.
