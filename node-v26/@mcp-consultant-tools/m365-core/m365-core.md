# @mcp-consultant-tools/m365-core

> 标签: device-code, mcp, microsoft-graph, model-context-protocol, msal

## 简介

Internal shared library for delegated (sign-in as the user) Microsoft Graph servers - device-code sign-in, encrypted MSAL token cache and feature switches
