# @mcp-consultant-tools/outlook

> 标签: email, mcp, microsoft-graph, microsoft365, model-context-protocol, outlook

## 简介

MCP server for Outlook mail as the signed-in user (device code) - read, search and download attachments, with drafts, send and delete behind off-by-default switches
