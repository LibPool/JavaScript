# @maolon/pi-relay

> 标签: agents, events, pi, pi-coding-agent, pi-extension, pi-package, relay, session-mail

## 简介

Session mail and a durable local event relay for Pi: let Pi sessions message each other, and let external CLIs and extensions wake a session with events.
