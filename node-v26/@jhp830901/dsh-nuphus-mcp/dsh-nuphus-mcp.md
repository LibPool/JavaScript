# @jhp830901/dsh-nuphus-mcp

> 标签: JavaScript

## 简介

nuphus-mcp bridge for dsh: desktop + browser automation (36 tools) via a persistent stdio MCP child process. Tools registered from static data generated from the server's tools/list.
