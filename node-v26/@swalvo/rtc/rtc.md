# @swalvo/rtc

> 标签: rtc, sdk, swalvo, video, voice, webrtc

## 简介

Official browser SDK for the Swalvo hosted platform — join a room, publish camera/microphone, subscribe to remote media. Hides SDP/ICE/STUN/TURN/SFU behind a small typed API.
