# @usepagelet/runtime

> 标签: agent, html, katex, markdown, mermaid, pagelet, runtime

## 简介

The Pagelet runtime — one tag that renders self-contained HTML pagelets (Markdown, Mermaid, KaTeX, charts, toolbar).
