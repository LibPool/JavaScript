# counterhound

> 标签: ai, bug-finding, claude-code, codex, fast-check, fuzzing, hypothesis, property-based-testing, testing

## 简介

An AI bug hunter whose every report is a failing test you can run: LLM-written property-based tests, deterministic repros, independent review.
