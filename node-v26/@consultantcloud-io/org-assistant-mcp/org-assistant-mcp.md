# @consultantcloud-io/org-assistant-mcp

> 标签: chrome-extension, claude, codex, cursor, mcp, model-context-protocol, salesforce, salesforce-cli

## 简介

MCP server for ConsultantCloud Org Assistant: lets AI coding agents list, add and import Salesforce org workspaces from the Chrome extension and the Salesforce CLI. Never exposes passwords or tokens.
