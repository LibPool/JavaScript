# @iota/identity-wasm

> 标签: JavaScript

## 简介

WASM bindings for IOTA Identity - A Self Sovereign Identity Framework implementing the DID and VC standards from W3C. To be used in JavaScript/TypeScript

## 官网

- 官网：https://www.iota.org
- 源码仓库：git+https://github.com/iotaledger/identity.git
- npm 页面：https://www.npmjs.com/package/@iota/identity-wasm
