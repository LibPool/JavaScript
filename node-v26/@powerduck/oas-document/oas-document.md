# @powerduck/oas-document

> 标签: api-docs, api-documentation, documentation, oas, oas3.2, openapi, powerduck, react, swagger, tree

## 简介

Production-grade OpenAPI documentation component. Pass an OAS document and get a full API documentation UI with tree navigation, auto-upgrade to OAS 3.2, and code examples.
