# @powerduck/code-to-openapi

> 标签: api, ast, code-scan, code-to-openapi, express, openapi, reverse-engineering, sse, typescript

## 简介

Scan a local codebase into OpenAPI 3.2 with a language-neutral AST engine, pluggable language and framework packs, and an optional AI gap resolver.
