# @seedgrid/pulse-subscriber-react

> 标签: pulse, react, realtime, sdk, seedgrid, subscriber, websocket

## 简介

SDK de referência (React + TypeScript) para assinar o SeedGrid Pulse: conecta no WebSocket, assina canais/grupos, recebe mensagens e envia ack. Protocolo realtime v1.
