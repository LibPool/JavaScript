# @justfortytwo/runner

> 标签: claude, headless, justfortytwo, runner, subprocess

## 简介

Thin wrapper around headless `claude -p --output-format json` for use by fortytwo daemons and bridges.

## 官网

- 官网：https://forty-two.it
- 源码仓库：git+https://github.com/justfortytwo/runner.git
- npm 页面：https://www.npmjs.com/package/@justfortytwo/runner
