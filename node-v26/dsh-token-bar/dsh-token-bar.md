# dsh-token-bar

> 标签: cache, client-plugin, cordis, deepseek, deepseek-harness, dsh, dsh-plugin, token, usage, web

## 简介

A per-turn token usage strip for DeepSeek Harness: a segmented bar plus a written legend in every reply's icon row, showing this turn's uncached input / cache read / output split.
