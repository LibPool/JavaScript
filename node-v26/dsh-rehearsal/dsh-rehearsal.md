# dsh-rehearsal

> 标签: compatibility, deepseek-harness, dsh, keyless, migration, rehearsal, session, upgrade

## 简介

Upgrade rehearsal CLI for DeepSeek Harness (dsh): static peer-graph pre-flight plus keyless real-session migration and write-round drills against a candidate dsh version, in a throwaway DSH_HOME. Keyless by design; reports carry no message bodies and no u
