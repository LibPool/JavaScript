# @atlasauth/solid

> 标签: JavaScript

## 简介

SolidJS bindings for [Atlas](https://atlasauth.net). Wraps the framework-agnostic `@atlasauth/js` client in Solid's fine-grained reactivity: drop in `<AtlasProvider>`, read auth state through accessors, and gate UI with control components — the Solid peer
