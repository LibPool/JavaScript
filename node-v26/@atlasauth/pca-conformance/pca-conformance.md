# @atlasauth/pca-conformance

> 标签: agent authorization, ai agents, conformance, differential testing, pca, proof-carrying authority, test vectors

## 简介

Canonical PCActn conformance vectors + a differential harness so every PCA verifier implementation (the 9 language SDKs, the zkVM, the TS core) provably agrees on accept/reject for the same inputs.
