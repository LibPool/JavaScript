# @atlasauth/passport

> 标签: atlas, atlasauth, authentication, jwt, oauth2, oidc, passport, passport-strategy, pkce

## 简介

Passport.js strategies for Atlas — an OIDC authorization-code strategy for interactive login and a bearer/JWT strategy for API routes, both wrapping @atlasauth/backend.
