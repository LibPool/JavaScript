# @atlasauth/pca-rotate

> 标签: agent authorization, ai agents, key rotation, pca, proof-carrying authority, reissue, revocation

## 简介

Key rotation + subtree revocation for PCA: rotate an agent holder key or a principal/root key by re-issuing the chain under new keys, and revoke-and-reissue a compromised delegation subtree, emitting revocation records.
