# @atlasauth/pca-gnap

> 标签: agent authorization, ai agents, gnap, grant negotiation, pca, proof-carrying authority, rfc 9635

## 简介

GNAP (RFC 9635) bridge for PCA, defining an agent-GNAP profile: map a GNAP grant request/response + continuation to an attenuated PCA capability, with GNAP continuation mapped to FROST/CIBA step-up and key-bound (jwsd) requests.
