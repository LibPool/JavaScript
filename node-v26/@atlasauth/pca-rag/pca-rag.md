# @atlasauth/pca-rag

> 标签: agent authorization, ai agents, document filtering, fine-grained authorization, pca, proof-carrying authority, rag, retrieval

## 简介

FGA-for-RAG for PCA: retrieval-time, per-principal document filtering driven by the PCA policy engine, with the filtering decision captured in the proof trace (provable: the model only saw authorized data).
