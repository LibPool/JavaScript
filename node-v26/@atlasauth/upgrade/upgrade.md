# @atlasauth/upgrade

> 标签: JavaScript

## 简介

CLI codemods to migrate a Clerk, Auth.js (NextAuth), Supabase Auth, Auth0 or Better Auth codebase to Atlas, and to move across Atlas SDK versions.
