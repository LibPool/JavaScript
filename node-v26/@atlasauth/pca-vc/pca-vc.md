# @atlasauth/pca-vc

> 标签: agent authorization, ai agents, did, http message signatures, pca, proof-carrying authority, sd-jwt, verifiable credentials

## 简介

Emit the PCA agent passport as a W3C Verifiable Credential 2.0 (SD-JWT) bound to a DID, and sign requests per RFC 9421 HTTP Message Signatures (Web Bot Auth Signature-Agent).
