# @atlasauth/pca-dpop

> 标签: agent authorization, ai agents, dpop, mtls, pca, proof of possession, proof-carrying authority, rfc 8705, rfc 9449

## 简介

Sender-constrained proof-of-possession for PCA: RFC 9449 DPoP proofs and RFC 8705 mTLS cnf binding, tying a PCActn to the holder key/channel for OAuth PoP interop.
