# @atlasauth/pca-webauthn

> 标签: agent authorization, ai agents, fido2, passkeys, pca, proof-carrying authority, step-up, webauthn

## 简介

Phishing-resistant human co-sign for PCA FROST step-up via WebAuthn/FIDO2 passkeys: verify an authenticator assertion as the principal/guardian approval.
