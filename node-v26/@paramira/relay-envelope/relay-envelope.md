# @paramira/relay-envelope

> 标签: end-to-end-encryption, onion-encryption, paramira, relay

## 简介

Two-layer encrypted envelope for a peer-to-peer message carried through a group's own relay — an outer layer any group member can open (proving 'this is a legitimate forward'), sealing an inner layer only the named recipient can open.
