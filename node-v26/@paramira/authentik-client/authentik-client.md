# @paramira/authentik-client

> 标签: api-client, authentik, openapi, paramira, sso

## 简介

A small typed client for the Authentik API (users, groups, invitations, flows and a headless flow runner, OAuth sources and connections, blueprints), pinned to Authentik 2026.2.3
