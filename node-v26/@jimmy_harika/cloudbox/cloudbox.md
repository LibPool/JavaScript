# @jimmy_harika/cloudbox

> 标签: cloudflare, component, convex, presigned, r2, s3, storage, upload

## 简介

Reusable Cloudflare R2 storage for Convex apps — named buckets, presigned uploads, object metadata. Plug in for images, gifs, stickers, video, covers, social assets.
