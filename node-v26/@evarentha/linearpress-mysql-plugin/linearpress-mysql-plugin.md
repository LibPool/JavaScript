# @evarentha/linearpress-mysql-plugin

> 标签: evarentha, linearpress, mysql-plugin, plugin

## 简介

将 MySQL 作为主数据库：后台配置连接、从 SQLite 迁移数据，重启后 MySQL 替代默认 SQLite。
