# @evarentha/linearpress-import-from-wordpress

> 标签: evarentha, import-from-wordpress, linearpress, plugin

## 简介

从 WordPress WXR 导出 XML 导入文章、媒体、用户、分类、评论与站点信息；保留现有数据、覆盖冲突。
