# @zzalai/leafer-point-annotation

> 标签: annotation, image-processing, leaferjs, point, vue3

## 简介

A Vue3 component for point annotation and brush painting on images using LeaferJS, supporting COCO/YOLO/JSON export, designed for AI model training dataset annotation
