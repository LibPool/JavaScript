# @ianflanagan1/ts-baseline

> 标签: eslint, eslint-config, prettier, static analysis, tsconfig, typescript

## 简介

Shared TypeScript strictness: an ESLint config with a no-unused-result rule, a tsconfig base, a Prettier config, and a check that a project still follows them
