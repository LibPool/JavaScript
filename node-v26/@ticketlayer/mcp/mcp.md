# @ticketlayer/mcp

> 标签: agent, mcp, modelcontextprotocol, ticketing, ticketlayer

## 简介

Ticketlayer's MCP server - bring your own agent. Exposes the permissioned Backstage API as MCP tools under the caller's own credential, over stdio or Streamable HTTP.
