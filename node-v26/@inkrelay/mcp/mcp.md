# @inkrelay/mcp

> 标签: ai-agents, cloud-printing, escpos, inkrelay, mcp, mcp-server, model-context-protocol, pdf, printing, remote-printing, zpl

## 简介

MCP server for the InkRelay printing API: list printers, print PDFs, ZPL labels and ESC/POS receipts, and follow print jobs
