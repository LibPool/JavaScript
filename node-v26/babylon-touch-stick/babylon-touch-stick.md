# babylon-touch-stick

> 标签: babylonjs, gamepad, input, mobile, touch, virtual-joystick

## 简介

Babylon.js virtual joystick with a directional output vector (cubic response curve). Minimal, leak-free drop-in replacement for babylonjs-touchstick's TouchStick.
