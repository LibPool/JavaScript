# @trustycap/cli

> 标签: agents, capabilities, cli, metering, nextjs, production-readiness, trustycap, webhooks

## 简介

The TrustyCap command line. npx @trustycap/cli productionize scans an application for production gaps, add installs a transparent remediation, verify proves it. A thin client over the same API the SDKs use.
