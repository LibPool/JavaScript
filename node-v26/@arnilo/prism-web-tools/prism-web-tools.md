# @arnilo/prism-web-tools

> 标签: JavaScript

## 简介

Unified web tools family for Prism: bounded Brave/Exa/Firecrawl web research, Playwright browser automation with egress policy and quarantine, and Obscura browser-engine tools over a host-installed binary.
