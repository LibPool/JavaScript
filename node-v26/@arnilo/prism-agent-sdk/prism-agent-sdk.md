# @arnilo/prism-agent-sdk

> 标签: agent, assembly, prism, sdk, tool-plane

## 简介

Assembly-only agent SDK: one defineAgent(config) call wires Prism's tool planes, skills, instructions, MCP bridges, hooks, and session stores into a runnable agentic loop — every plane optional and replaceable.
