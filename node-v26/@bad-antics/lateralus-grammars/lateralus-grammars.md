# @bad-antics/lateralus-grammars

> 标签: grammar, lateralus, ltl, metapackage, syntax, tmlanguage

## 简介

Scoped meta-package — TextMate grammars for the Lateralus programming language family. Installs all five dialect grammars and snippets in one go. Identical to `lateralus-toolkit` but uses the `@lateralus` org scope.
