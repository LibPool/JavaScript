# @indiekit/endpoint-syndicate

> 标签: indiekit, indiekit-plugin, indieweb, syndication

## 简介

Syndication endpoint for Indiekit. Provides an endpoint you can ping to check that recently published posts have been posted to configured syndication targets.

## 官网

- 官网：https://getindiekit.com
- 源码仓库：git+https://github.com/getindiekit/indiekit.git
- npm 页面：https://www.npmjs.com/package/@indiekit/endpoint-syndicate
