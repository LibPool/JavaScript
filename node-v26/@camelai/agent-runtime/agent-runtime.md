# @camelai/agent-runtime

> 标签: JavaScript

## 简介

SDK for the camelAI hosted agent runtime: define tools in your app, and the runtime runs the model loop, history and sandbox.

## 官网

- 官网：https://agents.camelai.dev
- 源码仓库：git+https://github.com/qaml-ai/agent-runtime.git
- npm 页面：https://www.npmjs.com/package/@camelai/agent-runtime
