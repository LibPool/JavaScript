# @terminal-fi/swappa

> 标签: JavaScript

## 简介

Swappa is a framework for finding and executing best routes for swapping cERC20 tokens. Framework consists of two parts: * @terminal-fi/swappa: JavaScript library that can be used to find best swap routes. * SwappaRouterV1 smart contract: That can be used
