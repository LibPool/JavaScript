# dsh-plugin-ui-zoom

> 标签: accessibility, deepseek, dsh, dsh-plugin, harness, ui, zoom

## 简介

Whole-interface zoom for DeepSeek Harness: 70%–160% via Ctrl+wheel, the DSH shortcut center, or an inline pill — with content-width compensation so zooming out shows more text instead of a narrower strip.
