# @scodigis/generator-btp-on-premise-scripts

> 标签: claude-code, cloud-foundry, destination, fiori, sap, sapbtp, sapui5, yeoman-generator

## 简介

Adds scripts to run and deploy a SAPUI5 / SAP Fiori elements app through an on-premise SAP BTP destination (cf ssh tunnel to the connectivity proxy).
