# @musd-kit/react

> 标签: bitcoin, cdp, defi, hooks, mezo, musd, react, stablecoin, trove, viem, wagmi

## 简介

wagmi-idiomatic React hooks for MUSD on Mezo (Mezo MUSD SDK), over @musd-kit/core. Consumes any wagmi context (e.g. @mezo-org/passport).
