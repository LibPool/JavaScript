# @kabuzz/mcp-server

> 标签: ai-agent, kabuzz, marketplace, mcp, resale

## 简介

MCP server for the Kabuzz AI-native resale marketplace. Enables any MCP-compatible AI agent to list, browse, negotiate, purchase, and message on Kabuzz.
