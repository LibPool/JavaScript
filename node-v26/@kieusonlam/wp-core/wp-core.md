# @kieusonlam/wp-core

> 标签: headless, headless-wordpress, mysql, next.js, nodejs, orm, sequelize, typescript, wordpress, wp

## 简介

Sequelize-based ORM for the WordPress database — read and write posts, meta, terms, options, menus, attachments, users, comments, plus shortcodes and phpass/bcrypt auth, directly from Node.js / TypeScript.
