# @kieusonlam/wp-woocommerce

> 标签: ecommerce, headless, headless-wordpress, nodejs, order, product, typescript, woocommerce, wordpress

## 简介

Product, Order, Customer, Item, Coupon models for WordPress + WooCommerce databases — read prices, stock, line items, billing/shipping addresses, and order history directly from MySQL in Node.js / TypeScript.
