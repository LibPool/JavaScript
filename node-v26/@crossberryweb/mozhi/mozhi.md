# @crossberryweb/mozhi

> 标签: fullstack, interpreter, language, mozhi, web

## 简介

Mozhi programming language interpreter — native web, JSON, fs, math, SQLite, templates. Install once, get both commands: `mozhi` and the short alias `mz` (identical behavior).
