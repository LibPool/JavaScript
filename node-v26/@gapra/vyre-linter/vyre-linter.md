# @gapra/vyre-linter

> 标签: a11y, apca, design-tokens, dtcg, linter, vyre, wcag

## 简介

Linter for Vyre design tokens and skill output. Validates DTCG 2025.10 schema, broken alias refs, WCAG/APCA contrast, and UX rule compliance.
