# @miragon/slidev-validator

> 标签: design-system, linter, miragon, slidev, validator

## 简介

The Miragon Slidev deck validator: a configurable design-system linter (stable rule IDs, off/warn/error severities, extends/overrides/exceptions) shipped as a versioned CLI so central guardrail improvements reach decks over npm instead of a frozen copy.
