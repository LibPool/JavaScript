> 标签: shiroko-devs, whatsapp, whatsapp-api, whatsapp-chat, whatsapp-group, whatsapp-library, whatsapp-system, whatsapp-web

## 简介

Node.js library for interacting with the unofficial WhatsApp API. It provides a solid foundation for developers looking to build bots and automations, with a focus on community and accessibility. It includes examples and documentation for ease of use.
