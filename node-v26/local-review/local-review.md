# local-review

> 标签: ai-agents, claude-code, code-review, coding-agents, git, local-first, pull-requests, review, stacked-diffs, stacked-prs

## 简介

Review a stack of local commits like a stack of GitHub PRs, before any of them is pushed. Comments live in plain YAML files your coding agent can read and reply to.
