# @supercomment/cli

> 标签: claude, claude-code, cli, code-review, mcp, supercomment, visual-feedback

## 简介

SuperComment CLI — authorize your machine and run the local MCP server so your coding agent (Claude Code) can read and resolve visual review comments.
