# @vyaz/converters

> 标签: converter, html, markdown, svg, table-layout, text-layout

## 简介

Convert a formatted-HTML fragment or Markdown into a @vyaz/core TextFrame — inline formatting, lists, tables (colspan/rowspan, nested tables), images/SVG as inline boxes, clickable links.
