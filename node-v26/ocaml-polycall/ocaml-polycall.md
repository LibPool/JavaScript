# ocaml-polycall

> 标签: dune, ffi, libpolycall, native, ocaml, polycall

## 简介

OCaml binding for the Polycall C library, binding ABI v1 (polycall >= 1.1.0). Source distribution of a dune project; not a JavaScript library.
