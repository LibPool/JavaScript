# @thyn-ai/sqai-mcp

> 标签: agents, deterministic, mcp, model-context-protocol, read-only, sqai, structured-data

## 简介

SQAI (Structured Query AI) MCP server — the three governed, deterministic, read-only tools (listSources, queryData, explainQuery) over stdio for any MCP host.
