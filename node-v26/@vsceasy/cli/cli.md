# @vsceasy/cli

> 标签: cli, framework, react, rpc, scaffold, vscode, vscode-extension, webview

## 简介

Build VS Code extensions fast — React UI + typed RPC bridge between extension and webview + file-based routing for panels, commands, menus, tree views, and subpanels.
