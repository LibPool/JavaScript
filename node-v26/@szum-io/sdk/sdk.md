# @szum-io/sdk

> 标签: chart, chart-api, chart-generator, chart-image, chart-image-api, chart-in-email, charts, data-visualization, dataviz, email-chart, grammar-of-graphics, png, server-side-rendering, svg, szum, typescript

## 简介

Render charts from a JSON config – SVG or PNG, embeddable in emails, PDFs, Slack, or any <img> tag. Official TypeScript SDK for Szum.
