# skilladopt

> 标签: SKILL.md, agent-skills, ai-agents, claude-code, cli, codex, coding-agents, skills

## 简介

Don't install agent skills. Adopt them. Fit third-party SKILL.md files to your codebase, keep the evidence for every change, and know exactly what to re-check when your project or the upstream skill changes.
