# chamber-copilot

> 标签: acp, agent-client-protocol, chamber, cli, copilot, delegation, extension, orchestration

## 简介

Drive a child Copilot CLI process from another agent's session over the Agent Client Protocol (ACP). Ships as both a standalone Copilot CLI extension and a delegation library for embedding hosts.
