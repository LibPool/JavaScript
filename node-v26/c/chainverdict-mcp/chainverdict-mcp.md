# chainverdict-mcp

> 标签: agents, base, mcp, usdc, x402

## 简介

Local MCP proxy to ChainVerdict's hosted endpoint — auto-syncs the full live tool set (on-chain data, verdicts, compliance, verification, security). x402/USDC on Base, no API keys.
