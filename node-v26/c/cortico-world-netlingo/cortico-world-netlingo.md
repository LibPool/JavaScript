# cortico-world-netlingo

> 标签: cortico, cortico-world, meme, slang, 梗, 梗图, 网络用语, 网络语言, 群聊

## 简介

让 Coo 可以自己总结、自己上网搜索并保存梗到本地的扩展,建议搭配各大佬的 QQ 接入扩展使用;也可以当作一个互联网接口使用,查网络用语、热榜与评论区。
