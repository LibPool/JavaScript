# claude-worker

> 标签: agent, anthropic, claude, claude-code, cli, dashboard, server

## 简介

Turnkey claude-worker instance: `npx claude-worker` runs the session gateway and the full dashboard on one port. The @claude-worker/* packages are the libraries you embed; this is the service you run.
