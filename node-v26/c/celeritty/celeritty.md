# celeritty

> 标签: alacritty, custom-element, pty, terminal, terminal-emulator, wasm, webgpu, xterm

## 简介

Terminal emulator for the web. ANSI parsing in Rust (alacritty_terminal) compiled to WebAssembly, rendered with WebGPU.
