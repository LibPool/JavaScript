# chromium-tabs

> 标签: chrome, chromium, headless, react, tab-groups, tab-strip, tabs

## 简介

Chrome's TabStripModel, ported to TypeScript with React bindings. Pinning, tab groups, opener-aware activation, multi-select, drag-reorder.
