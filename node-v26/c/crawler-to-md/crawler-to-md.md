# crawler-to-md

> 标签: cli, context, converter, crawler, directory, documentation, generator, git, llm, markdown, node, repository, scraper, web

## 简介

A CLI tool to crawl websites, clone Git repos, or scan local directories and consolidate content into a single Markdown file.
