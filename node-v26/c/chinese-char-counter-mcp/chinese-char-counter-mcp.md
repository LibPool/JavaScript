# chinese-char-counter-mcp

> 标签: ai-agent, character-count, chinese, cjk, mcp, model-context-protocol, modelscope, stdio, word-count

## 简介

MCP server (stdio) that counts Chinese characters in a text, excluding punctuation, whitespace, Latin letters and digits.
