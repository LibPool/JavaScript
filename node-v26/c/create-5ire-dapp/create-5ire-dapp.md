# create-5ire-dapp

> 标签: 5ire-testnet, blockchain, hardhat, react, smart-contract

## 简介

A full-stack starter template with React & Truffle or Hardhat to develop, deploy, and test Solidity smart contracts on the 5ire testnet network.
