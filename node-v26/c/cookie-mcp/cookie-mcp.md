# cookie-mcp

> 标签: ai-agents, cookie-chain, defi, mcp, model-context-protocol, solana, stdio, trading

## 简介

MCP server + library for Cookie Chain — read market data, swap, launch tokens, and manage liquidity from any AI agent. Signs locally or hands verified transactions to the user's own wallet.
