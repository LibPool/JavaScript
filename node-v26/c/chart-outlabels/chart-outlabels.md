# chart-outlabels

> 标签: chart.js, chartjs, data-labels, doughnut, labels, outlabels, pie, plugin, visualization

## 简介

Chart.js v4 plugin that draws out-of-slice labels (radial connector + accent bar + two-line text) on single-dataset pie/doughnut charts.
