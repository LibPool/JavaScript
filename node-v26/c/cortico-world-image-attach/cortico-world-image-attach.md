# cortico-world-image-attach

> 标签: cortico, cortico-world

## 简介

Cortico World: 把电脑里任意一张图片发进对话，可以配合有搜图能力的扩展，将找到的图片直接发在对话里。

## 官网

- npm 页面：https://www.npmjs.com/package/cortico-world-image-attach

- 0.1.0
- 0.1.1

- npm registry：https://registry.npmjs.org/cortico-world-image-attach
- Node 要求：>=22
