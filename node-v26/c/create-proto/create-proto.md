# create-proto

> 标签: create, design-tool, expo, ios, proto, prototyping, react-native, scaffold, simulator

## 简介

Scaffold a new Proto prototype: `npm create proto@latest myapp`. Describe a screen, watch your prototype run natively on iPhone — designer-first, paired with Claude Code.
