# check-deps-update-time

> 标签: JavaScript

## 简介

## 介绍 生成 deps 更新时间的 json 文件，帮助排查导致 ci 出现错误的依赖，往往是新更新的依赖可能坏了，所以用这个脚本去生成一个更新时间的降序列表。
