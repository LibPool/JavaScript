# chanjs-hono

> 标签: chanjs-hono, hono drizzle, hono mvc, hono mysql, hono postgres, hono sqlite, nodejs mvc

## 简介

chanjs-hono 基于 Hono + Drizzle ORM 研发的轻量级 MVC 框架，API 镜像 chanjs，支持 pgsql / mysql / sqlite。
