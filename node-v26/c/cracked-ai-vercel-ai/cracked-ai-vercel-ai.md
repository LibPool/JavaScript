# cracked-ai-vercel-ai

> 标签: agents, ai, ai-sdk, api, cracked, llm, mcp, scraping, tool-router, tools, vercel

## 简介

Vercel AI SDK tool() factory for Cracked, the agent tool router: crackedTools({ apiKey, capabilities }) returns a tools map for generateText / streamText covering 50,000+ tools behind one key.
