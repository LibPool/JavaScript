# creo-edit

> 标签: contenteditable, creo, editor, rich-text, text-editor, virtualization, wysiwyg

## 简介

Row-based rich-text editor framework on a controlled contentEditable, built on Creo. Cursor state separate from document state, CRDT-friendly fractional row ordering, O(1) per-keystroke renders, optional virtualization, first-class mobile.
