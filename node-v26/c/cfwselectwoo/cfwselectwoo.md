# cfwselectwoo

> 标签: autocomplete, dropdown, multiselect, select, tag, tagging, typeahead

## 简介

cfwselectwoo is a fork of selectWoo which is a fork of select2. It adds the ability to exclude certain elements from the enhanced select.
