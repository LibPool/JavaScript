# com.joyixir.gamemanager

> 标签: gamemanagemet, gamemanager, helper, level, unity, unity3d

## 简介

A simple unity game management system to handle loading a game, its levels and saving the levels data such as score, gained money, level number. Also it provides enough public Actions for other classes to do things based on game status changes like listen
