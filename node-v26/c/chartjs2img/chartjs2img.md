# chartjs2img

> 标签: chart, chart.js, chartjs, headless-chromium, image, jpeg, llm, png, puppeteer, skia, skia-canvas, visualization, webp

## 简介

Render Chart.js charts to images via a TypeScript API, CLI, or HTTP server. Two engines: skia-canvas by default (no browser) or headless Chromium for full fidelity. Chart.js 4.4 + 12 plugins bundled.
