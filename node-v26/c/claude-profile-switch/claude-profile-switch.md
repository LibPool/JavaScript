# claude-profile-switch

> 标签: account, anthropic, claude, claude-code, cli, profile, session, switcher

## 简介

Switch between multiple saved Claude Code accounts/sessions, with live usage limits. Installs the `claude-switch` command (macOS, Linux, Windows).

- npm 页面：https://www.npmjs.com/package/claude-profile-switch
