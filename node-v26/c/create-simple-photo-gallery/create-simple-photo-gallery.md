# create-simple-photo-gallery

> 标签: astro, create, github-pages, photo-gallery, photography, scaffold

## 简介

Scaffold a simple-photo-gallery site: a fork-free photo gallery for Astro + GitHub Pages. Run `npm create simple-photo-gallery@latest`.
