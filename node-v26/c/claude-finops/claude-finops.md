# claude-finops

> 标签: analytics, budget, claude, claude-code, cli, codex, cost, cursor, dashboard, finops, gemini-cli, spend, tokens, usage

## 简介

Local FinOps dashboard for Claude Code: what you used, what it cost, why it cost that much, and what to change. Reads your own transcripts, no API key, no data leaves the machine.
