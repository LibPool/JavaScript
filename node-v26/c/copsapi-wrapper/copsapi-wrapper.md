# copsapi-wrapper

> 标签: api, api-wrapper, autohost, cops, critical force, critical ops, criticalops, esports, matchmaking

## 简介

Typed, quota-aware client for the Critical Ops Public API v2: profiles, leaderboards, match history, weapon stats, server status and autohosted custom games with a live room watcher.
