# campus-connect

> 标签: campus-connect, clipboard, installer, lan, local-network, remote-desktop

## 简介

Installs Campus Connect — clipboard, files, chat, calls and remote desktop across your own network. Downloads the right build for your machine from GitHub releases.

## 官网

- 官网：https://vijayapardhu.github.io/Clipboard/
- 源码仓库：git+https://github.com/Vijayapardhu/Clipboard.git
- npm 页面：https://www.npmjs.com/package/campus-connect

- npm registry：https://registry.npmjs.org/campus-connect
- Node 要求：>=16
