# canvas-marker-layer-cyy

> 标签: canvas-marker

## 简介

A custom canvas marker layer, based on [Leaflet.Canvas-Markers](https://github.com/eJuke/Leaflet.Canvas-Markers), add **`userDrawFunc`** option to support custom canvas marker style.
