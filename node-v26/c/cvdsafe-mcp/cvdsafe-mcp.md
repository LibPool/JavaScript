# cvdsafe-mcp

> 标签: a11y, accessibility, colorblind, colorblind-safe, cvd, image, llm, mcp, model-context-protocol, palette, tool

## 简介

MCP server that lets an LLM (Claude, Cursor, etc.) check whether a palette OR an image is colorblind-safe, simulate color-vision deficiency, and check WCAG contrast — built on the published OpticQuiz engine (Machado 2009 + CIEDE2000).

## 官网

- 官网：https://opticquiz.com/checker/
- 源码仓库：git+https://github.com/vince-gonzalez/opticquiz.com.git
