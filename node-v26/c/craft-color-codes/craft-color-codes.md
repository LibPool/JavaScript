# craft-color-codes

> 标签: artkal, ciede2000, color-codes, color-palette, cross-stitch, delica, diamond-painting, dmc, embroidery-floss, fuse-beads, hama, hex, lego, map-art, mard, mcp, mcp-server, minecraft, miyuki, nabbi, perler, pixel-art, red-heart, rgb, seed-beads, yarn

## 简介

Hex and RGB for 3,689 craft colour codes: Perler, Hama, Artkal, Nabbi and MARD fuse beads, Miyuki Delica, DMC floss and diamond drills, Red Heart yarn, LEGO and Minecraft. JSON, CSV, a CIEDE2000 matcher and an MCP server.
