# cpmesh-mcp

> 标签: ai-agents, clipboard, cpmesh, mcp, model-context-protocol

## 简介

MCP server that lets AI agents use cpmesh end-to-end-encrypted clipboard sync: share text to the user's devices, read and search clipboard history, manage devices.
