# check-pqc

> 标签: compliance, hybrid, kyber, ml-kem, post-quantum, pqc, security, tls, tls13, x25519mlkem768

## 简介

Check if a host is post-quantum (PQC) ready — TLS 1.3 + ML-KEM hybrid key exchange. CLI wrapper over checkpqc.app.
