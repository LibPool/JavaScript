# create-hope

> 标签: create-hope, hope, hoped, 搭建组件库框架

## 简介

hope是一个 Vue3 组件库开发环境框架，采用最新的 Vite4  + TypeScript 为技术栈，支持按需加载、单元测试、自动打包与发布等功能，让我们能更专注于业务组件的开发
