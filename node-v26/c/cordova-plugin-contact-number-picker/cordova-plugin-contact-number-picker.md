# cordova-plugin-contact-number-picker

> 标签: android, contact, cordova-android, cordova-ios, ecosystem:cordova, ios, number, phone, phonegap, picker

## 简介

PhoneGap plugin for native contact picker on Android and iOS. The picker shows only name and phone numbers.
