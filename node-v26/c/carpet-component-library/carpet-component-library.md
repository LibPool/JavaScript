# carpet-component-library

> 标签: CARPET, component, library, vue, vue3

## 简介

A loom is a device used to weave cloth and tapestry with yarn or threads. LOOM (Library Of interactiOn Modules) is a "UI-interpreter" used to model, configure and "execute" UIs with reusable encapsulated interaction modules. It is built with Vue 3 and Vit
