# cvexp

> 标签: a4, cv, generator, json-resume, pdf, puppeteer, react, resume, tailwind

## 简介

Render a resume JSON file to a polished A4 PDF (and matching HTML). React SSR + Tailwind v4 + headless Chrome. Single template, zero theming.
