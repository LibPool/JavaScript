# create-adsights-ads

> 标签: JavaScript

## 简介

Scaffolder for a new @adsights-ai/ads-framework project. Run via `npx create-adsights-ads@latest <dir>` to bootstrap compositions/, ads.config.ts, .claude/skills, and the ads:* scripts in a buyer project.
