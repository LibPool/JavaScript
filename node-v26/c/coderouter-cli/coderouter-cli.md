# coderouter-cli

> 标签: ai, anthropic, claude-code, cli, codex, coding-agent, llm, openai, openrouter, router

## 简介

A coding-agent router that picks the best model for each task, runs edits in git-worktree sandboxes, and works with your existing Claude Code / Codex CLI or any API key (OpenAI, Anthropic, OpenRouter, ...).
