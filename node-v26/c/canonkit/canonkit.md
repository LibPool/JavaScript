# canonkit

> 标签: agents, ai, architecture, claude, claude-code, code-review, codex, subagents

## 简介

A versioned agent team for Claude Code and Codex. Installs 10 core agents and 5 opt-in domain specialists, each owning a domain and classifying its own risk.
