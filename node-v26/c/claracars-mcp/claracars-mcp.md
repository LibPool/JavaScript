# claracars-mcp

> 标签: automotive, car-import, cars, isv, mcp, model-context-protocol, portugal, used-cars

## 简介

MCP server for Clara Carros — search used & imported cars in Portugal, calculate import tax (ISV), estimate resale value, and get in touch. Thin wrapper over the public claracars.pt API.
