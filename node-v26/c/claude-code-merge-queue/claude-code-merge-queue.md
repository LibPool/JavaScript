# claude-code-merge-queue

> 标签: ai-agents, claude-code, coding-agent, git-worktree, merge-queue, monorepo-tooling, parallel-agents

## 简介

The local, zero-cost merge queue for parallel Claude Code agents. Plugs into Claude Code's native worktree isolation; one build at a time, one landing at a time, zero races.
