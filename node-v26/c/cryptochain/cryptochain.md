# cryptochain

> 标签: avalanche, binance smart chain, bitcoin, blockchain, crypto, cryptocurrency, cryptography, ethereum, evm, multichain, polygon, solana, wallet, waves

## 简介

A cryptochain library that supports Ethereum, Bitcoin, Solana, Waves and other EVM compatible blockchains E.g. Binance Smart Chain, Polygon, Avalanche etc.
