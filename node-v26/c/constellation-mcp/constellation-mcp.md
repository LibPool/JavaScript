# constellation-mcp

> 标签: agent-tools, competitive-intelligence, mcp, mcp-server, model-context-protocol, openapi, product-strategy, scaffold, specs

## 简介

MCP server that turns any model into a specialised web-product agent: investigates a target on its own, produces verifiable specs (SQL, OpenAPI, Gherkin, task graph), and closes the loop by comparing an implementation to its reference and naming every gap
