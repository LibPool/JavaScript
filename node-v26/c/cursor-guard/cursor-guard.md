# cursor-guard

> 标签: agent-skill, ai-safety, code-protection, cross-platform, cursor, cursor-ide, git-backup, recovery, snapshot

## 简介

Protects code from accidental AI overwrite or deletion in Cursor IDE — mandatory pre-write snapshots, review-before-apply, local Git safety net, and deterministic recovery. | 保护代码免受 Cursor AI 代理意外覆写或删除——强制写前快照、预览再执行、本地 Git 安全网、确定性恢复。
