# chain-syncer

> 标签: blockchain, chain-state, ethereum, ethersjs, sync, web3

## 简介

chain-syncer is a JS module which allows you to synchronize your app with any ethereum-compatible blockchain/contract state. Fast. Flexible. Reliable.
