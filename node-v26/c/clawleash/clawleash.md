# clawleash

> 标签: ai-agent, claude, claude-code, devtools, hooks, human-in-the-loop, mobile, ntfy, permission, pwa, remote-approval, tailscale

## 简介

Approve or deny Claude Code permission prompts from your phone — so long autonomous runs never stall while you're away from the desk. Self-hosted, token-gated, over Tailscale or LAN.
