# create-espkg

> 标签: CLI, javaScript npm package generator, next.js npm package generator, npm package builder, npm pkg creator, package, react npm package generator, typescript npm package generator

## 简介

A CLI tool designed to streamline the creation of Npm packages with built-in support for JavaScript/TypeScript and React/Next.js projects.
