# coffeenode-tides

> 标签: JavaScript

## 简介

CoffeeNode Tides is a (Xe)(La)TeX source generator to produce typographically appealing and moderately complex tidal calendars. I started this project a while ago for fun, so it's not fully usable as yet, but maybe someone can make use of it.
