# cra-template-josh-ts

> 标签: cra-template, create-react-app, cypress, eslint, prettier, react, template, typescript

## 简介

A quick start CRA template for TypeScript React projects containing setup for React, TypeScript, ESLint, Prettier, Emotion CSS-in-JS, Cypress automated testing, and a README briefly explaining how to use each.
