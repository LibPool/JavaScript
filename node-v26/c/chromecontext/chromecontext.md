# chromecontext

> 标签: ecosystem:jquery, event, jquery-plugin, menu, ui

## 简介

jQuery plugin to create Chrome-styled context menus (right-click menus) for any element.

## 官网

- 官网：https://github.com/travishorn/jquery-chromeContext
- 源码仓库：https://github.com/travishorn/jquery-chromeContext.git
