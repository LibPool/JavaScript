# create-revup-dev

> 标签: cli, create-react-app, create-vite, react, revup, scaffold, structured, tailwind-v4, typescript, vite

## 简介

A modern CLI to scaffold React + Vite projects with structured folders, TypeScript/JS, Tailwind CSS v4, path aliases, and preset libraries.
