> 标签: ai-agent, claude, contractor, license, mcp, model-context-protocol, state-licensing, verification

## 简介

Real-time contractor license verification across all 50 US states + DC plus 8 major-city portals (Chicago, NYC, Philadelphia, Detroit, Atlanta, Dallas, Las Vegas, Nashville). MCP server for Claude Desktop, Claude Code, Cursor, Windsurf, and other AI agent
