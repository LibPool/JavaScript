# cron-fast

> 标签: browser, bun, cli, cloudflare-workers, command-line, cron, crontab, deno, esm, fast, human-readable, javascript, lightweight, node, nodejs, parser, performance, recurring, schedule, scheduler, task, timezone, tree-shakeable, typescript, validator, workerd, zero-dependencies

## 简介

Fast and tiny JavaScript/TypeScript cron parser with timezone support - works in Node.js, Deno, Bun, Cloudflare Workers, and browsers. Zero dependencies.
