# circle-loader

> 标签: UI, circle-loader, loader, loading overlay, loading screen, loading spinner, spinner

## 简介

A simple, lightweight loader component that can be programmatically started and stopped. It dynamically adds a loading spinner to the DOM and removes it when loading is complete.
