# cesium_custom_popup

> 标签: cesium, cesium_custom_popup, custom_popup, gis, popup

## 简介

基于cesium开发的一个自定义弹窗类,可以实例化创建普通弹窗,媒体弹窗,交互弹窗,实时更新弹窗。可以自定义DIY弹窗样式。实时变更弹窗位置以。实时变更弹窗内容功能。自定义弹窗事件
