# callwright

> 标签: mcp, model-context-protocol, phone-calls, retell, voice-agent

## 简介

A voice agent that places phone calls (reservations, appointments, inquiries) on your behalf, shaped by LLM direction + grounding. Runs fire-and-forget on Retell; an MCP server lets an LLM shape the grounding before each call.
