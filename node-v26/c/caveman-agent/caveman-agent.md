# caveman-agent

> 标签: ai-coding-agent, caveman, llm, opencode, pi, token-optimization, token-reduction

## 简介

Token-efficient communication mode for AI coding agents. Cuts ~65% output tokens while keeping full technical accuracy. Supports pi and OpenCode.
