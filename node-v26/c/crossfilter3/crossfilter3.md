# crossfilter3

> 标签: analytics, arrow, crossfilter, crossfilter2, crossfilter3, dashboard, filtering, visualization, wasm, worker

## 简介

Fork of crossfilter2 adding Arrow streaming, WASM-accelerated filters, declarative dashboard runtimes, and Web Worker support.
