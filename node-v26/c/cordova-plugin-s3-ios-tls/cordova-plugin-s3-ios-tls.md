# cordova-plugin-s3-ios-tls

> 标签: Amazon, ForwardSecrecy, aws, ios9, s3, tls

## 简介

cordova plugin for ios9 apps to add key 'NSExceptionRequiresForwardSecrecy' with value 'NO' for Amazon AWS (S3) hosts
