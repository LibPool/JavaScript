# canonjson

> 标签: cache-key, canonical, canonicalize, deterministic, hash, jcs, json, rfc8785, signing, stable, stringify

## 简介

RFC 8785 (JCS) canonical JSON serialization and stable hashing of any JS value. Zero dependencies, ~1 KB.
