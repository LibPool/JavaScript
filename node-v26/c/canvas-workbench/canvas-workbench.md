# canvas-workbench

> 标签: canvas, design, dsh, dsh-bundle, dsh-plugin, excalidraw

## 简介

本地生图工作台,零订阅费:开自己的 API 生图(任意 OpenAI 兼容接口,零订阅),画布排版+修图/擦除/去背景/OCR/转矢量,可编辑 PSD/AI 交付,Photoshop/Illustrator 图层级双向桥接
