# com.elestrago.unity.entitas-redux

> 标签: ecs, entitas, redux

## 简介

Entitas Redux is a fast, accessible, and feature-rich ECS framework for Unity. Bundled Roslyn source generators emit a typed API for your contexts and components at compile time.
