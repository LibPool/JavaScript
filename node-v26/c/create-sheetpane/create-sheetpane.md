# create-sheetpane

> 标签: JavaScript

## 简介

`npm create sheetpane` — a working sheetpane app in vanilla, React, Next.js, Vue, Angular or Svelte: the sheet and its errors panel, a sample file and rules file, one test, and the agent skills.
