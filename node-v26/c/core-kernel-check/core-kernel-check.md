# core-kernel-check

> 标签: claude-code, core-kernel, ddd, lint, typescript

## 简介

Verificador com tipos para projetos que usam o core-kernel: pega os erros que compilam mas quebram (ids em SQL, status por texto de erro, throw/new Date() no domínio...)
