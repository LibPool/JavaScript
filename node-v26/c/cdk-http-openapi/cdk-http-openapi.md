# cdk-http-openapi

> 标签: API, Api Gateway, cdk, constructs, http, lambda, openapi, reusable cdk constructs

## 简介

CDK Construct that lets you build AWS Api Gateway Http Api, backed by Lambdas, based on a OpenAPI spec file.
