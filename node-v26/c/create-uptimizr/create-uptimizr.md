# create-uptimizr

> 标签: 3d, analytics, cli, create, scaffold, starter, uptimizr

## 简介

Scaffold a self-host of the Uptimizr OSS 3D-analytics collector — Docker-free, single-file DuckDB by default, or backed by Postgres / ClickHouse / SQL Server. Run with `npm create uptimizr@latest`.
