# chat-state-dynamodb

> 标签: aws, bot, chat, chat-sdk, dynamodb, lambda, slack, state-adapter

## 简介

DynamoDB state adapter for Chat SDK: thread subscriptions, distributed locks and caching on a single table, no Redis, no VPC
