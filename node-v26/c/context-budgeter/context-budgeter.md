# context-budgeter

> 标签: ai, anthropic, chat, context-window, llm, messages, openai, prompt, tokens, trim, truncate, typescript

## 简介

Fit a chat message history into a model's context window — a tiny, zero-dependency, tokenizer-agnostic trimmer with pluggable strategies (keep-system, drop-oldest, middle-out, summarize) and a guarantee it never exceeds the budget or drops a pinned messag
