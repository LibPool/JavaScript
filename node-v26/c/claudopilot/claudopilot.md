# claudopilot

> 标签: agent, ai, automation, autonomous, claude, claude-code, cli, codegen, orchestrator

## 简介

Autonomous parallel execution loop for Claude Code — feed it a dependency-annotated roadmap and it builds every eligible phase concurrently, each in its own git worktree, merging green work and parking red.
