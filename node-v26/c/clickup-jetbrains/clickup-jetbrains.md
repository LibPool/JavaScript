# clickup-jetbrains

> 标签: clickup, clickup-jetbrains, jetbrains, tasks

## 简介

Clickup-jetbrains makes your tasks from ClickUp (task management tool) available in your Jetbrains IDE

## 官网

- npm 页面：https://www.npmjs.com/package/clickup-jetbrains

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install clickup-jetbrains`
- npm registry：https://registry.npmjs.org/clickup-jetbrains
- Node 要求：>=16.0.0
