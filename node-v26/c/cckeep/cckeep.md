# cckeep

> 标签: agent, claude-code, cli, coding-agent, launchd, reconnect, remote-control, systemd, tmux, watchdog

## 简介

Keeps Claude Code Remote Control from silently going dead. Re-arms the disconnects that still need a manual /remote-control — local, tmux-native, zero dependencies.
