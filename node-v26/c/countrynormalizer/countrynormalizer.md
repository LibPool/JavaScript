# countrynormalizer

> 标签: alpha-2, alpha-3, calling-code, continent, countries, country, country-code, country-data, country-flag, country-list, country-lookup, country-name, country-normalize, country-normalizer, country-phone, demonym, dialing-code, flag, flag-emoji, i18n, internationalization, iso-3166, iso3166, l10n, localization, phone-code, tld, top-level-domain, typescript

## 简介

ISO 3166 country data lookup and normalization. Convert between alpha-2, alpha-3, ISO numbers, country names, calling codes, flag emojis, TLDs, continents, and demonyms.
