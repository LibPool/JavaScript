# cortico-world-memory

> 标签: agent, bm25, cortico, cortico-world, memory, vector-search

## 简介

Cortico World 扩展：五层记忆（事实库/知识库/反思/人格/档案）+ 三级记忆底座 + Hybrid Recall 向量混合检索（移植自 E:/qq_bot 的记忆系统与 memory_server 向量 sidecar，qq_bot 源码零改动）。
