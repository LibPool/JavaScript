# convertisseur-ia-mcp

> 标签: docx, markdown, mcp, modelcontextprotocol, offline, pdf, tokens, xlsx

## 简介

Connecteur MCP local : convertit PDF, Word, Excel, PowerPoint, CSV, HTML, JSON, RTF et code en Markdown leger avant lecture par l'IA (jusqu'a -98 % de tokens). 100 % hors ligne.
