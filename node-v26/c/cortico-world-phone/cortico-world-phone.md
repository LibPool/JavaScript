# cortico-world-phone

> 标签: cortico, cortico-world, qq, voice-call

## 简介

Cortico World:电话 —— QQ 语音通话(走 QQ 自带的 AVSDK):她接得起真来电、听得见对方、说得出自己的话、挂断。★ 非即插即用:装之前先把它交给一个 coding agent,从 AGENTS.md 读起(真能力在另一台登着 QQ 的机器上)。作者已跑通并验证过的是服务器端那一套(NapCat);本机(Windows)那条路没有完全验证过 —— 社区里有人做过,可到 Cortico 社区群咨询。耳朵=本机语音识别,嗓子=TTS。
