# claude-transplant

> 标签: account-switching, accounts, claude, claude-code, claude-code-sessions, claude-desktop, claude-max, claude-pro, claude-team, history, migrate, multi-account, session-history, sessions, sidebar, transfer

## 简介

Claude Desktop shows an empty Code sidebar after you switch accounts. This moves the session history to the account you are using. macOS, menubar or CLI.
