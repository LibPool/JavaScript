# create-fonderie-app

> 标签: cli, create, fonderie, fonderie-js, saas, scaffold, starter

## 简介

Zero-prompt scaffold for a Fonderie-powered SaaS backend. Run `npx create-fonderie-app my-saas` and get a working TypeScript Express backend pre-wired with Fonderie.
