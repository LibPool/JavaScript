# create-tinywidgets

> 标签: components, local-first, react, styling, tiny, ui

## 简介

The CLI to build a new app using TinyWidgets, a collection of tiny, reusable, UI components - wrapped in a helpful app layout with header, side bar, dark mode, and more.
