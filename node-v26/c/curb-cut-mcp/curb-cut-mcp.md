# curb-cut-mcp

> 标签: accessibility, accommodations, mcp, modelcontextprotocol, salesforce, workplace

## 简介

MCP server for Curb Cut: workplace accommodation options, published cost evidence, and request drafts. It looks up and it drafts; it never sends anything on anyone's behalf.
