# compylar

> 标签: JavaScript

## 简介

Compylar is a local Knowledge Compiler for AI coding agents. It analyzes a TypeScript or JavaScript repository, records evidence-backed repository facts, and creates task-specific context packs that an agent can use without rediscovering the whole codebas
