# crypto-token-kit

> 标签: access token, aes, authentication, encryption, hmac, jwt alternative, refresh token, revocable token, secure auth, secure token, session, session management, stateless auth, token, token rotation

## 简介

A modular, encrypted, DB-agnostic token system with optional refresh token support. Built as a secure alternative to JWT with built-in session management, revocation, and rotation capabilities.
