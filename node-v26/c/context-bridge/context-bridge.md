# context-bridge

> 标签: communication, context, invoke

## 简介

上下文桥（Context Bridge）是一种支持不同 JavaScript 执行环境之间相互调用的机制。Context Bridge is a mechanism that enables different JavaScript execution contexts to invoke each other.
