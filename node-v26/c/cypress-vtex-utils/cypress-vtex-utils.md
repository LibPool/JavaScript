# cypress-vtex-utils

> 标签: automation, chrome, chromium, cypress, cypress-plugin, electron, har, http-archive, qa, qatools, testing, typescript

## 简介

The Cypress plugin for generating HTTP Archive (HAR) and Console files is a tool that allows developers and QA engineers to capture detailed information about network requests made during the execution of Cypress tests.
