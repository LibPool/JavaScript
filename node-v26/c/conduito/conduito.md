# conduito

> 标签: JavaScript

## 简介

Conduito — a cooperative frontend API protocol over postMessage. The flagship: @conduito/core (the protocol) + @conduito/frame (iframe), with @conduito/port (Web Worker / MessagePort) at conduito/port.
