# calcsuite-react

> 标签: acecbm, calculator, decimal, emi, finance, india, loan, react, sip, tax, us

## 简介

Decimal-exact, offline-first financial calculator library for React — India (₹) & US ($). ~55 calculators, scientific calculator, live FX, export, launcher/dialog. The financial-calculator module of AceCBM (Ace Cloud Business Management).
