# cracked-ai-mastra

> 标签: agents, api, cracked, llm, mastra, mcp, scraping, tool-router, tools

## 简介

Mastra createTool() factory for Cracked, the agent tool router: crackedTools({ apiKey, capabilities }) returns a typed tools map for any Mastra Agent covering 67,000+ tools behind one key, priced per call.
