# cupertino-terminal

> 标签: electron, encrypted, macos, p2p, remote-terminal, ssh, terminal, wsl, xterm, zsh

## 简介

Open-source terminal that brings the macOS Terminal look to Windows, macOS and Linux — WSL/zsh, 10 themes, glass/opacity, ZeroLink P2P encrypted remote terminal (SSH-like), bilingual TR/EN UI.
