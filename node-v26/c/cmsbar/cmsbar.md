# cmsbar

> 标签: astro, cms, git, github, inline-editing, nextjs, nuxt, react-router, sveltekit, tanstack-start, vite

## 简介

CMSBar installer - scaffold or add the Git-as-CMS editing bar to your repo (Next.js, React Router 7, TanStack Start, Vite SPA, Astro, SvelteKit, Nuxt). You own the code.
