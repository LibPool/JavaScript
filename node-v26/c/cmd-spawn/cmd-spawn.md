# cmd-spawn

> 标签: buffer, buffered, buffered-spawn, exec, execute, node, path_ext, spawn, typescript

## 简介

Run shell commands as string. Typescript(+typings) ES6 module. Node 6+ spawn with promises, buffered and unbuffered output
