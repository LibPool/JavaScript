# create-monorepo-turbo

> 标签: boilerplate, cli, eslint, expo, generator, javascript, monorepo, nestjs, nextjs, prettier, react, react-native, turborepo, typescript, workspaces

## 简介

CLI para criação de monorepositorios JavaScript/TypeScript com suporte a múltiplos apps (Next.js, Expo, NestJS) e pacotes compartilhados já pré-configurados (eslint, prettier, tsconfig, ui, hooks, etc.).
