# create-a4ui

> 标签: a4ui, create, scaffold, solid-js, starter

## 简介

Scaffold a new A4ui app (Solid + Vite + Tailwind) with `npm create a4ui@latest`.

## 官网

- 官网：https://a4ui.pages.dev/
- 源码仓库：git+https://github.com/A4uikit/a4ui.git
- npm 页面：https://www.npmjs.com/package/create-a4ui
