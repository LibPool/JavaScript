# clockify-sdk-ts-115

> 标签: api-client, clockify, local-generator, openapi, sdk, time-tracking, typescript

## 简介

Unofficial, community-built — not affiliated with CAKE.com or Clockify. TypeScript SDK for the Clockify API, generated locally from the canonical OpenAPI and wrapped with a publishable package layout.
