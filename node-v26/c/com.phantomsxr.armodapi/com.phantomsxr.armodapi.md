# com.phantomsxr.armodapi

> 标签: API, ARMOD

## 简介

AR-MOD API is an indispensable code script interface in the AR-MOD framework.
It allows us to write complex scripts to produce our AR creative interactive content.
The content developed by this API is common to all applications that use AR-MOD.
