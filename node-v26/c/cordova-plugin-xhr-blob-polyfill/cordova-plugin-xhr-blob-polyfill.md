# cordova-plugin-xhr-blob-polyfill

> 标签: blob, chrome, ecosystem:cordova, polyfill, xhr

## 简介

A Cordova plugin which provides Blob return type support for XMLHttpRequest in iOS (pre iOS7) and Android (pre-KitKat)
