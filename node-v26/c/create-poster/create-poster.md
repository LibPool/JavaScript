# create-poster

> 标签: JavaScript

## 简介

新一代海报生成组件： - 生成速度快于html2canvas - 生成图片质量高于html2canvas - 代码结构更好,不需要html元素和css,性能更优 - 组件更小，只有4kb ### 引入 #### es6: ``` npm install create-poster --save import createPoster from 'create-poster'; ``` #### 全局： ``` import "create-poster/esm.js"; ```
