# crumbtrail-core

> 标签: ai-agents, browser-sdk, bug-reporting, coding-agent, crumbtrail, debugging, desktop, developer-tools, error-boundary, error-tracking, javascript, observability, react, redaction, session-replay, tauri, telemetry, typescript

## 简介

Capture the console, network, DOM and state around a bug and hand it to a coding agent as evidence. Zero-dependency browser SDK, with optional React and Tauri adapters on the crumbtrail-core/react and crumbtrail-core/tauri subpaths. See https://crumbtrail
