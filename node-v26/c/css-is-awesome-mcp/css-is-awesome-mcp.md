# css-is-awesome-mcp

> 标签: JavaScript

## 简介

Zero-install MCP server for css-is-awesome (cia) — npx css-is-awesome-mcp, no manual sdk/zod install. Same 30-tool surface as the server bundled with css-is-awesome itself.
