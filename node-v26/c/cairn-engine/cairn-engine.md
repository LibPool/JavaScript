# cairn-engine

> 标签: agentic, agentic-testing, ai, automation, browser, chrome-devtools, deterministic, e2e, llm, mcp, playwright, qa, regression-testing, self-healing, test-automation, testing

## 简介

An agentic-testing engine — browser tests an AI discovers once, replays deterministically with zero LLM calls, and heals when they break.
