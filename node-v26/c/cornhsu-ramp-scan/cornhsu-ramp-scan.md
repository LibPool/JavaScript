# cornhsu-ramp-scan

> 标签: a11y, accessibility, axe-core, cli, crawler, i18n, nvda, ramp, site-audit, wcag, 台灣, 網站無障礙規範

## 简介

全站無障礙檢測 CLI — 爬掃整個網站並對應台灣「網站無障礙規範」，是 Ramp（ramp-a11y）擴充套件的命令列版。Full-site web-accessibility scanner CLI mapped to Taiwan's Website Accessibility Guidelines.
