# css-vue-plugin

> 标签: JavaScript

## 简介

Expande la funcionalidad para agregar estilos css a los componentes Vue. Al usar este plugin tiene acceso a la propiedad **$style** en la cual puede definir los estilos del componete.  Los estilos se tiene que definir en el ciclo **beforeCreate** .
