# cordova-locktask

> 标签: cordova, cordova-android, ecosystem:cordova, kiosk, kiosk mode, locktask

## 简介

A Cordova plugin to create an application that uses Android's LockTask mode for COSU (corporate-owned, single-use) devices. Use of this plugin allows the developer to block user access to hardware keys and other system functionality. To enable "kiosk mode
