# cordova-plugin-webview-camera-permissions

> 标签: camera, cordova, ecosystem:cordova, getUserMedia, permissions, webview, wkwebview

## 简介

Makes WebView camera (getUserMedia) permission work on Android and iOS. Not a camera API - it makes the browser's own one work inside a Cordova WebView.
