# convex-multiplayer-cursors

> 标签: convex, convex-component, cursors, multiplayer, presence, react, realtime

## 简介

Figma-style real-time multiplayer cursors for Convex: a reusable component (room presence with heartbeat/TTL, batched cursor trails) plus a React overlay with interpolated replay.
