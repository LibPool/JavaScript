# c64lua

> 标签: 6502, 6510, 8-bit, ahead-of-time, aot, c64, c64-ultimate, cc65, commodore, commodore-64, d64, demoscene, game-development, gamedev, homebrew, lua, pico-8, pico8, prg, retro, retrogaming, rom, sid, vice, wasm, webassembly

## 简介

Write PICO-8-flavored Lua, get a Commodore 64 .prg / .d64. The C64 member of the luacretro Lua-to-C console SDK family.
