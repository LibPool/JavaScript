# craft-harness

> 标签: agent, agent-loop, deepseek, function-calling, harness, llm, nodejs, openai, tool-calling, typescript

## 简介

A deterministic, provider-neutral agent harness for Node.js: agent loop, tool harness, append-only session log and model adapters.
