# copilot-mock-server

> 标签: copilot, demo, github-copilot, mitm, mock, proxy, sse, websocket

## 简介

Local MITM proxy that intercepts GitHub Copilot Chat traffic and replays scripted responses via WebSocket and SSE for deterministic demos
