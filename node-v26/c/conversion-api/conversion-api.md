## 简介

Install Conversion API (CAPI) integrations via Tracklution. Alias of the `tracklution` package: forwards to its CLI and prints agent-readable install instructions. Real install goes via the Tracklution MCP at https://mcp.tracklution.com/mcp. Protocol: htt
