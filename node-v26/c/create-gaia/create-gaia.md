> 标签: claude, claude-code, gaia, playwright, react, react-router, scaffold, storybook, tailwindcss, typescript, vitest

## 简介

Scaffold a new GAIA React project. A Claude-native React Router 7 workflow with TypeScript, Tailwind v4, Vitest, Playwright, and Storybook.
