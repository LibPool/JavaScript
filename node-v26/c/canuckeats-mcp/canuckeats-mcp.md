# canuckeats-mcp

> 标签: canada, doordash, food-delivery, mcp, restaurant, ubereats

## 简介

Order food delivery from 17,000+ Canadian restaurants via UberEats and DoorDash. Browse menus, build carts, and place real orders across 89 Canadian cities.
