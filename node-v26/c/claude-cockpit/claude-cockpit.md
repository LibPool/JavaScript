# claude-cockpit

> 标签: ai-tools, claude-code, dashboard, developer-tools, lit, session-viewer, websocket

## 简介

A visual cockpit for Claude Code sessions — browse history, stream live chat, approve tools, track costs. Personal learning artifact, published as-is. Unofficial third-party tool. Not affiliated with or endorsed by Anthropic.
