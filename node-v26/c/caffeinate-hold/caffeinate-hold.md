# caffeinate-hold

> 标签: caffeinate, cordis, deepseek-harness, dsh, macos, plugin, sleep-prevention

## 简介

DSH (DeepSeek Harness) host plugin: keeps macOS awake via caffeinate while any agent or background job is running, and releases it when everything is idle.
