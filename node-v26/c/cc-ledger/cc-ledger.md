# cc-ledger

> 标签: billing, claude-code, freelance, gst, india, invoicing, opentelemetry

## 简介

Per-client cost tracking for Claude Code, converted to INR, built for solo freelancers who bill by client and want a real invoice number - no Grafana, no Prometheus, no Docker.
