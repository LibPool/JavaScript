# cloudpanel-server

> 标签: Blueprint, CloudPanel, Express, HTTP, Jobs, MariaDB, MySql, Node, Redis, Server, Template, WSS, WebSocket

## 简介

Blueprint to create a Node.js server that runs on CloudPanel. Includes MySql/MariaDB & Redis interfaces, express HTTP interfaces, and WSS interface.
