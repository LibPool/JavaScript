# call-engine-test

> 标签: JavaScript

## 简介

tuicall-engine-webrtc 是基于腾讯云 [即时通信 IM](https://cloud.tencent.com/document/product/269/42440) 和 [实时音视频 TRTC](https://cloud.tencent.com/document/product/647/16788) 两项付费 PaaS 服务构建出的音视频通信组件，支持双人和多人场景下的音视频通话。
