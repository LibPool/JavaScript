# concurrent-browser-mcp-session

> 标签: automation, browser, concurrent, debugging, json-recording, mcp, parallel, playwright, replay, session-recording

## 简介

A concurrent browser MCP server with session recording & replay - supports multiple parallel browser instances and captures all actions as JSON
