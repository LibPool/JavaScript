# cc-stacktracer

> 标签: adonisjs, apm, clickhouse, distributed-tracing, error-monitoring, error-tracking, express, fastify, logging, monitoring, nodejs, observability, opentelemetry, prisma, spans, stacktrace, structured-logging, telemetry, tracing, typescript

## 简介

Observability SDK for Node.js — captures errors, structured logs, distributed traces and database spans, and ships them to a CC StackTracer ingestion API.
