# chillmodal

> 标签: alert, confirm, dark-mode, dialog, framework-agnostic, modal, popup, vanilla-js, zero-dependency

## 简介

Zero-dependency modal library with focus trap, ESC key support, and dark/light mode. Framework-agnostic.
