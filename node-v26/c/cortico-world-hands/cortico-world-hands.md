# cortico-world-hands

> 标签: accessibility, automation, cortico, cortico-world, hands

## 简介

Cortico World: hands for the desktop pet — looks at the phone screen, then taps, swipes, pinches, drags, types and presses keys through whatever actuator the device actually has
