# create-express-auth-app

> 标签: 2fa, auth, boilerplate, cli, create, express, generator, jwt, mongodb, postgresql, scaffold, typescript

## 简介

Scaffold a ready-to-run Node/Express JWT authentication backend (MongoDB or PostgreSQL, JavaScript or TypeScript, optional Google OAuth and TOTP 2FA) with one command.
