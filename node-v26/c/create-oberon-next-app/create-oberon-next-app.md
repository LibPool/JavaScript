# create-oberon-next-app

> 标签: JavaScript

## 简介

A tool that sets up a next.js project from scratch, with all oberon default dev tooling (linters, git hooks, deployment scripts) applied.

- 官网：https://bitbucket.org/oberon_interactive/oberon-frontend-template#readme
