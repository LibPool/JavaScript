# code-sandbox-web

> 标签: JavaScript

## 简介

CodeSandbox 是一个在线代码编辑及实时预览的 UI 组件，支持浏览器环境下编写 `html/js/css/ts/vue/react` 等类型的代码并在沙盒环境下实时运行预览。
