# clipswitch

> 标签: cli, clipboard, clipboard-history, clipboard-manager, copy-paste, desktop, electron, global-shortcuts, linux, macos, paste, system-tray, tray, windows

## 简介

Minimalist clipboard history for Linux, Windows and macOS: remembers the text and images you copy, pin favorites, opens with a global shortcut, tray icon and CLI.
