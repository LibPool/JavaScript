# claude-discord-bot

> 标签: agent, bot, claude-code, daemon, discord, gateway, mcp

## 简介

Drive Claude Code from Discord — machine-level agent gateway daemon. One bot routes to N CC workspaces via channel binding (`/use <workspace>`).
