# changelog-zero

> 标签: bump, changelog, cli, conventional-changelog, conventional-commits, git, keep-a-changelog, release, semver, version

## 简介

Changelog generator for Conventional Commits with zero dependencies. Groups commits since the last tag, picks the next version, links commits and issues, and updates CHANGELOG.md and package.json.
