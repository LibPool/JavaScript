# claude-presence

> 标签: claude-code, coordination, inter-process, lock, mcp, model-context-protocol, multi-session, presence

## 简介

Minimal MCP server for inter-session coordination between parallel Claude Code instances: presence registry, resource locks, broadcast inbox.
