# canton-agent-mcp

> 标签: agent, canton, canton-network, cip-0103, mcp, model-context-protocol, payments, wallet, walletconnect

## 简介

MCP server that lets AI agents pay on the Canton Network through a human's mobile wallet: the agent asks, the human approves on their phone, hardware signs.
