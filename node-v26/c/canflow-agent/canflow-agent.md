# canflow-agent

> 标签: ai-agent, automation, canflow, claude-code, codex, issues, kanban

## 简介

Autonomous QA loop that verifies Canflow bug reports with Claude Code / Codex, fixes confirmed bugs, and moves the cards as it works.
