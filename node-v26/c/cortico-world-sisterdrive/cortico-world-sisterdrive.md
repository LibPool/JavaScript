# cortico-world-sisterdrive

> 标签: cortico, cortico-world

## 简介

Cortico World for Teach my little sister how to drive: a BepInEx plugin turns game calls into events and feeds the bot's voice to the game. 此乃直播测试验证之后的world，和其他 Persona / 非直播场景的兼容性有待测试。
