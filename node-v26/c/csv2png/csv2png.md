# csv2png

> 标签: csv, png

## 简介

提供将csv压缩成png图片的功能，以及将压缩后的png还原成csv文件。

- 官网：https://github.com/hanks-tan/csv2png#readme
- 源码仓库：git+https://github.com/hanks-tan/csv2png.git
- npm 页面：https://www.npmjs.com/package/csv2png
