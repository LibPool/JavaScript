# cubx-resource-resolver

> 标签: JavaScript

## 简介

Purpose to optimize the loading of Cubbles resources in the browser. - Download and merge to a single file all direct referenced javascript resources   - Download and merge to a singe file the html import files and include the merged javascript file - Dow
