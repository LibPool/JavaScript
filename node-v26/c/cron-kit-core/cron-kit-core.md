# cron-kit-core

> 标签: cron, cron-expression, cron-parser, crontab, next-run-time, quartz, scheduler, spring

## 简介

零依赖的 Cron 表达式引擎：解析、校验、中文描述、可视化配置互转与最近执行时间计算，支持 Quartz / Spring / Linux Crontab / Node Cron 四种语法。
