# claude-power-setup-installer

> 标签: claude, claude-code, developer-tools, installer, rag

## 简介

One-command installer for a Claude Code power-user setup: rtk, graphify, qrag (local-first RAG over your codebase), qoff (local MLX model offload), context-discipline hooks, and portable config templates.
