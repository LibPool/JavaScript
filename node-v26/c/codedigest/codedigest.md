# codedigest

> 标签: CLI, LLM, Node.js, code, digest

## 简介

CodeDigest is a simple single-file Node.js command-line tool that consolidates an entire code repository (directory structure and text-based files) into a digest file for easy consumption by your preferred LLM (Large Language Model).
