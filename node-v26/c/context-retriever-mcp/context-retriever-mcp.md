# context-retriever-mcp

> 标签: claude-code, embeddings, local-first, mcp, rag, retrieval, semantic-search

## 简介

Local vector retrieval MCP server for coding agents: semantic code search, session-transcript memory, and a live token-savings counter. 100% on-device.
