# compact-mcp

> 标签: ast, babel, claude-code, cursor, mcp, model-context-protocol, react, react-ast, token-optimization, typescript

## 简介

MCP server that gives Claude Code deep React intelligence via live Babel AST analysis. Maps component trees, traces re-render blast radius, and extracts dependency chains — all from real AST, not guesswork.
