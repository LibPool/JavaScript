# codex-trajectory

> 标签: codex, ds, ledger, session, tokens, tool-calls, trajectory, transcript, visualization

## 简介

Fold Codex session transcripts into a DSH-style trajectory view — turn-aware event ledger, timeline overview, tool-call folding, token usage, search, and inspector. Run directly via npx.
