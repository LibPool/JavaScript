# callman-mcp

> 标签: api, callman, claude, codex, cursor, gemini, mcp, model-context-protocol, postman, testing

## 简介

MCP server for Callman: lets Claude Code, Claude Desktop, Cursor, Codex and Gemini CLI manage collections, requests, environments, test scenarios and system-design diagrams in your Callman workspace — cloud or on-prem.
