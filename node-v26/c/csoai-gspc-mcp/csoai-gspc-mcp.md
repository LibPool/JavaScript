# csoai-gspc-mcp

> 标签: AI governance, EU AI Act, agent verification, agent-verification, ai-governance, attestation, csoai, ed25519, eu-ai-act, gspc, mcp, measurement, model safety, model-context-protocol, model-safety, provenance, x402

## 简介

Stdio MCP server for Council of AI's GSPC board and signed measurement evidence. Twelve tools: eight free readers and four x402-metered evidence tools. Measurement only, never certification. Zero runtime dependencies.
