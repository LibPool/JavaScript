# cocopit

> 标签: anthropic, bun, claude, claude-code, codex, codex-cli, console, dashboard, openai, terminal, usage

## 简介

A local-first web console for Claude Code and OpenAI Codex CLI — usage & cost analytics, session browsing, multi-account management, quota, config views, and a built-in web terminal.
