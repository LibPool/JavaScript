# costkey

> 标签: ai, anthropic, azure, cost, gemini, google, llm, monitoring, observability, openai, sentry, tokens, tracing, tracking

## 简介

Sentry for AI costs. Track every LLM call's cost, tokens, latency, prompts, and tool metadata with one CLI command.
