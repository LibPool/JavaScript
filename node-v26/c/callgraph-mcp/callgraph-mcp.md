# callgraph-mcp

> 标签: call-graph, code-analysis, flowmap, mcp, model-context-protocol, static-analysis

## 简介

MCP server for codebase call-flow analysis. Local, deterministic, language-agnostic. Powered by @codeflow-map/core.
