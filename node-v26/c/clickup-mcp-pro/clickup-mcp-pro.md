# clickup-mcp-pro

> 标签: ai, automation, claude, claude-code, clickup, mcp, model-context-protocol, project-management, tasks

## 简介

The most complete ClickUp MCP server — 161 typed tools covering the entire ClickUp v2/v3 API (tasks, lists, docs, chat, goals, sprints, time tracking, webhooks, guests) plus a clickup_raw escape hatch and a readonly safety mode.
