# csvdb

> 标签: JavaScript

## 简介

Read-only document store based on a text/csv documents. Can be used, for example, to use Google Spreadsheets as a source database

## 官网

- 官网：https://github.com/eladb/node-csvdb
- 源码仓库：git://github.com/eladb/node-csvdb.git
- npm 页面：https://www.npmjs.com/package/csvdb
