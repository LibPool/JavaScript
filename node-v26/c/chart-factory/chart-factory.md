# chart-factory

> 标签: chart, charts, d3, data-visualization, dataviz, design-tokens, responsive-charts, svg, visualization

## 简介

Token-driven, responsive D3 chart library: area, line, slope, bar, scatter, dot charts and sortable tables that fill their container by default.
