# cloudmindmaps-mcp

> 标签: ai, claude, cloudmindmaps, freemind, freeplane, mcp, mind-map, mindmap, mindmapping, mm, model-context-protocol, modelcontextprotocol

## 简介

Model Context Protocol (MCP) server that lets Claude and other AI assistants create, list, and read mind maps on CloudMindMaps (FreeMind/Freeplane .mm format).

## 官网

- 官网：https://cloudmindmaps.app/mcp
- 源码仓库：git+https://github.com/jan-rezab/cloudmindmaps.git
- npm 页面：https://www.npmjs.com/package/cloudmindmaps-mcp
