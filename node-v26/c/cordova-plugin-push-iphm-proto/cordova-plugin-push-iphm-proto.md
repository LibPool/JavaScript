# cordova-plugin-push-iphm-proto

> 标签: cordova-amazon-fireos, cordova-android, cordova-blackberry10, cordova-ios, cordova-windows, cordova-windows8, cordova-wp8, ecosystem:cordova

## 简介

This is fork of https://github.com/phonegap-build/PushPlugin to support AWS SNS registration.
	This plugin allows your application to receive push notifications on Android, iOS, WP8 and Windows8 devices.
    Android uses Google Cloud Messaging.
