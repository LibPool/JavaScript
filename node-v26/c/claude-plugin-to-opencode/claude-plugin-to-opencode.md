# claude-plugin-to-opencode

> 标签: AGENTS.md, SKILL.md, agent-skills, claude-code, converter, hooks, migration, opencode, plugin, skills

## 简介

Port a Claude Code plugin to OpenCode, as a plugin: skills with rewritten path anchors and host-valid names, a generated OpenCode plugin that runs the PreToolUse hooks and carries the MCP servers and permission rules, rules file. Installs under ~/.config/
