# cse-bridge

> 标签: cse, customsearch, drop-in-replacement, google-api, google-custom-search, migration, pagemap, search-api, searxng, self-hosted, structured-data

## 简介

Self-hosted drop-in replacement for Google's Custom Search JSON API (shut down 2027-01-01) that speaks the customsearch/v1 wire format on top of your own SearXNG instance. Change one base URL, keep your code.
