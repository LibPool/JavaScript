# capacitor-token-vault

> 标签: android, auth, capacitor, capacitor-plugin, ios, keychain, keystore, masvs, owasp, refresh-token, secure-storage, token, zero-dependencies

## 简介

Capacitor plugin that keeps auth tokens in iOS Keychain, Android Keystore, and sessionStorage on the web. Zero runtime dependencies.
