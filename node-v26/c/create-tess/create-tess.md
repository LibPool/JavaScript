# create-tess

> 标签: agent-orchestration, agents, claude-code, cli, create-tess, scaffold, tess, tess-os

## 简介

Gamified first-run wizard for Tess OS — npm create tess. Name yourself, choose a world, pick a starter squad of real agents, name your conductor, and land inside a working agent OS.
