# cordova-kendo-ui-tabstrip-template

> 标签: cordova:template, ecosystem:cordova, kendo ui

## 简介

Cordova template for creating Kendo UI based hybird mobile apps. This is a tabstrip template i.e. app navigation will be done using Tabstrip.
