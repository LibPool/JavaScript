# campaingames.oauth

> 标签: JavaScript

## 简介

> 提供生成用户信息的功能。 > * 如果在微信中，根据微信用户信息，生成window.campaignUser对象； > * 如果在浏览器中，根据浏览器信息，生成window.campaignUser对象； > * 如果在吉秀APP中，根据APP用户信息，生成window.campaignUser对象；（须在吉秀后台配置，跳转的URL带accessToken参数）
