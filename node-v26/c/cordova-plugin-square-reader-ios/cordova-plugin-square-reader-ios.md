# cordova-plugin-square-reader-ios

> 标签: cordova-ios, ecosystem:cordova, square, square-reader

## 简介

Fork of https://github.com/sudhirdhumal289/SquareCordovaIntegration, with a few updates for the newer versions of Cordova (8+). Provide functionality to integrate the Square Reader SDK integration in an iOS app.
