# cosmos-sql

> 标签: cosmos-db-sql, cosmos-sql, cosmosdb, cosmosdb sql, sql

## 简介

cosmos-db-sql is a wrapper around azure cosmos db sql. The intent is to provide more syntactic sugar than the default documentdb.
