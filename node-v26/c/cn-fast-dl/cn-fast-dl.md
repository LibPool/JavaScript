# cn-fast-dl

> 标签: accelerate, china, download, github, mirror, multi-thread, proxy, range

## 简介

国内 GitHub 大文件多线程加速下载工具：自动测试并选择最快国内代理，16 线程分段并行下载，绕过单连接限速

## 官网

- 源码仓库：git+https://gitee.com/light_111/cn-fast-download.git
- npm 页面：https://www.npmjs.com/package/cn-fast-dl

- 0.1.0

## 获取地址

- npm 安装：`npm install cn-fast-dl`
- npm registry：https://registry.npmjs.org/cn-fast-dl
- Node 要求：>=16
