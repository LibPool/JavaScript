# create-softwarefactory

> 标签: agents, ai, cli, create, mastra, scaffold, software-factory

## 简介

Create a Mastra Software Factory project: an agent-powered software delivery environment built on Mastra. Run `npm create softwarefactory` to scaffold, configure integrations, and get started.
