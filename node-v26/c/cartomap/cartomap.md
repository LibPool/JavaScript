# cartomap

> 标签: ai, architecture, claude-code, codebase, context, cursor, documentation, knowledge-graph, memory

## 简介

A living project memory for AI coding — an always-current, git-tracked map of your codebase so AI assistants (and humans) instantly know what's what.
