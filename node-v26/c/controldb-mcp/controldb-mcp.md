# controldb-mcp

> 标签: controldb, data catalog, gobierno de datos, mcp, metadata, model context protocol

## 简介

Servidor MCP de metadata de ControlDB: expone el gobierno de datos (catálogo, tablas, PII, score) de una organización como herramientas de solo lectura.
