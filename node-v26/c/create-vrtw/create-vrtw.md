# create-vrtw

> 标签: boilerplate, cli, frontend, javascript, react, scaffold, starter, tailwindcss, typescript, vite

## 简介

Zero-config CLI to scaffold a modern Vite + React (TS/JS) project with Tailwind CSS v4, Bootstrap 5, or none, plus optional extras: react-icons, React Router, Redux Toolkit, Zustand, Axios – and auto-cleaned boilerplate.
