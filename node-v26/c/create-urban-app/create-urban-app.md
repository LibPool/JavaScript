# create-urban-app

> 标签: create-urban-app, nano-app, nanobpm, rad, scaffold, urban

## 简介

Scaffold a runnable Urban app (nano.app.json + processes/forms/db/workers, or a code-first defineFlow app) that runs on both Node and Deno via @nanobpm/urban. The create-react-app of Urban (ADR 0052).
