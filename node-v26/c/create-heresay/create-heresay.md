# create-heresay

> 标签: bug-report, bug-reporting, coding-agent, create, feedback, feedback-widget, firebase, heresay, in-app-feedback, ios, macos, mcp, sdk, self-hosted, swiftui, user-feedback, web-sdk

## 简介

Set up your own Heresay: in-app feedback that every report gets a hearing. Creates a Firebase project in your Google account and deploys the dashboard, API and SDK to it.
