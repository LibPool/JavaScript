# claude-code-rename

> 标签: anthropic, ccr, claude, claude-code, cli, developer-tools, migration, rename, resume, session-management, session-recovery, transcript

## 简介

CLI to recover Claude Code sessions (e.g. /resume) after renaming, moving, or copying a project folder. Dry-run, atomic, merge-aware.
