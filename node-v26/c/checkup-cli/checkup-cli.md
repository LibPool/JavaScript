## 简介

Lazy-senior-engineer rules for AI coding agents: a stdlib-first decision ladder that keeps generated code minimal. Installs itself into Gemini CLI/Antigravity, Trae, Claude Code, Cursor, GitHub Copilot, and Windsurf/Devin.
