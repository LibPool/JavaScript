# codemirror-visimark

> 标签: codemirror, codemirror6, highlighting, lint, markdown, visimark

## 简介

A CodeMirror 6 extension for VisiMark: marks every computed value in a Markdown document, flags the ones that disagree with their formulas, reports findings as lint diagnostics, and highlights `vmark` blocks.
