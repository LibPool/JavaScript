# clap-ts

> 标签: arg-parser, argument-parser, bun, clap, cli, command-line, flag-parser, man-page, node, shell-completions, subcommands, type-safe, typescript

## 简介

A type-safe CLI argument parser for TypeScript, inspired by Rust's clap crate. Full clap-style parsing, validation, help, subcommands, shell completions, man pages and markdown docs, with zero dependencies.
