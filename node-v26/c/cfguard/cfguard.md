# cfguard

> 标签: billing, circuit-breaker, cloudflare, cost, d1, durable-objects, workers

## 简介

Real-time cost circuit breaker for Cloudflare Workers: meters D1/KV/R2/Durable Objects usage in-process and stops runaway bills within seconds.
