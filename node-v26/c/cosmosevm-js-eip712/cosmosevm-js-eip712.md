# cosmosevm-js-eip712

> 标签: authz, cosmos, cosmos-evm, eip712, eth_signTypedData_v4, feegrant, kiichain, metamask

## 简介

EIP-712 typed-data builder for signing a caller-chosen batch of Cosmos SDK authz/feegrant grants with an EVM wallet (MetaMask) on KiiChain and other cosmos/evm-based chains
