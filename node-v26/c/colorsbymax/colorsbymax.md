# colorsbymax

> 标签: accessibility, colors, colours, contrast, dark-mode, palette, react, tailwind, theme, theme-switcher, wcag

## 简介

A live theme switcher for any website: site themes, 700+ palettes, for light/dark modes and WCAG contrast checks.
