# cb-gelios-library

> 标签: JavaScript

## 简介

Компоненты и утилиты проекта gelios (ui). Разработка и анализ (обзор) компонентов ведется через storyBook, т.е. здесь не нужно виртуальный дом строить Компоненты разрабатываются изолированно При обновлении пакета, просто поменяйте минорную версию в pac
