# cordova-plugin-fetch

> 标签: cordova, cors, fetch, plugin, proxy

## 简介

The cordova-plugin-fetch plugin addresses CORS (Cross-Origin Resource Sharing) issues encountered when using the Fetch API in JavaScript.
