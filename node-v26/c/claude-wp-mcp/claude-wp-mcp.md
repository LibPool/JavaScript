# claude-wp-mcp

> 标签: ai-agent, claude, claude-code, claude-desktop, llm-tools, mcp, model-context-protocol, wordpress, wp-rest-api

## 简介

MCP server that lets Claude (and any other MCP client) read and manage a WordPress site over the WP REST API — posts, pages, categories, tags, media, users.
