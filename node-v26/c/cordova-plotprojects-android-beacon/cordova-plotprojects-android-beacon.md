# cordova-plotprojects-android-beacon

> 标签: beacons, cordova-android, ecosystem:cordova, ibeacons, location, notification, plot, plotprojects

## 简介

Use the Plot library for Location Based Notifications in your Cordova/PhoneGap app. This is an additional plugin for iBeacon support for Android.
