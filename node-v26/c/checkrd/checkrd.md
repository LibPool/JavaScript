# checkrd

> 标签: agents, ai, anthropic, kill-switch, llm, observability, openai, policy, proxy, security

## 简介

Policy enforcement, kill switch, and telemetry for AI agent API calls. Intercepts fetch(), evaluates against a signed policy in a WASM sandbox, and emits signed telemetry.
