# crypto-containers

> 标签: crypto, crypto-container, cryptography, library

## 简介

JavaScript library to encrypt plain text or raw data into a crypto container and decrypt crypto container with randomly generated an encryption key. Encryption and decryption derive by reassembling encryption key which was split into shares by Shamir's Se
