# create-evestack

> 标签: agent, ai, composio, dashboard, eve, postgres, self-hosted

## 简介

Run AI agents on your own machine. One command gives you the whole stack: durable Postgres sessions, a Docker sandbox, memory, approvals, schedules, 1,000+ tool integrations, and a dashboard that drives the agent.
