# chenswap-mcp

> 标签: aggregator, ai-agents, bebop, claude, cursor, defi, dex, kyberswap, lifi, mcp, model-context-protocol, odos, paraswap, swap

## 简介

MCP server for chenswap.chitacloud.dev — compare DEX quotes across 5 aggregators (KyberSwap, ParaSwap, Odos, LI.FI, Bebop) with LLM reasoning. No API key, no wallet connection, read-only quotes.
