# create-safqi-theme

> 标签: generator, safqi, scaffold, storefront, theme

## 简介

Scaffold a standalone Safqi storefront theme (runtime or zero-build variant) built on @safqi/storefront-core, with the theme conventions and a drift-free THEME-REFERENCE generator embedded.
