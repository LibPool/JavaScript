# cbundle

> 标签: AI, CLI, ChatGPT, LLM, cbundle, codebase, codebundle, consolidate, documentation, language model, review

## 简介

A CLI tool for consolidating a codebase into a single, organized text file for easy sharing with ChatGPT or other LLMs.
