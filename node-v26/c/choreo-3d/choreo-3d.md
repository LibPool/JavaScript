# choreo-3d

> 标签: 3d-tilt, choreography, cinematic, creative-development, framer-motion, gsap, next-js, parallax, pinned-sections, react, scroll-animation, scrolltrigger

## 简介

Scroll choreography + 3D tilt + parallax primitives for React. Cinematic chapter pinning, multi-depth scroll layers, background morphing, iOS-safe video, and reduced-motion fallbacks. Built on GSAP ScrollTrigger + Framer Motion.
