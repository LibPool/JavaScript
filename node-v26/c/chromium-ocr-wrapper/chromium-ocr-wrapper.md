# chromium-ocr-wrapper

> 标签: chrome, chromium, cli, ocr, pdf, pdf-ocr, screen-ai, searchable-pdf

## 简介

CLI tool that converts image-only PDFs to searchable PDFs using Chrome's built-in OCR (PDFSearchify/Screen AI)
