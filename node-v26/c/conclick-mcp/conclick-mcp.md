# conclick-mcp

> 标签: analytics, claude-code, codex, conclick, cursor, mcp, model-context-protocol

## 简介

MCP server for Conclick analytics — let Cursor, Claude Code, Codex and other agents query visitors, inspect revenue, manage websites and connect payment providers from a prompt.
