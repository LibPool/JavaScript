# com.sludgyparrot.vr

> 标签: OpenXR, Parrot Code, Sludgy Parrot, Unity, VR, Virtual Reality, XR, XR Interaction Toolkit

## 简介

A collection of virtual reality utilities, XR Interaction Toolkit extensions, and development tools for building immersive VR experiences in Unity. Includes helpers for locomotion, interactions, input, performance, and platform integration.
