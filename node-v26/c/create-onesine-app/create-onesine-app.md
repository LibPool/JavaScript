# create-onesine-app

> 标签: JavaScript

## 简介

**Un CLI TypeScript pour créer rapidement des projets React/Vite/Tailwind/Zustand/Shadcn privés.** Clone ton starter privé et initialise automatiquement ton projet avec Git, dépendances, et configuration prête à l’emploi.
