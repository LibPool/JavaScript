# claude-translate

> 标签: claude, claude-code, cyrillic, hooks, mcp, plugin, russian, tokens, translation

## 简介

Save tokens on Cyrillic text in Claude Code: cheap Haiku translate tier, lazy EN doc cache via PreToolUse hook, CLAUDE.md sync, MCP
