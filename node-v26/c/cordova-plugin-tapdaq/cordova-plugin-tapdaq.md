# cordova-plugin-tapdaq

> 标签: ads, advertising, cordova, cordova-android, cordova-ios, cross, cross-promotion, direct, ecosystem:cordova, marketing, promotion, retention, tapdaq

## 简介

Tapdaq is a cross promotion tool for mobile apps. We help you to retain users across your app portfolio and to trade installs with other developers.
