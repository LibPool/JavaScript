# create-wp-ai-plugin

> 标签: agentic, claude-code, create, plugin, scaffold, wordpress

## 简介

Scaffold a new WordPress plugin from wp-agentic-kit, configured for agentic engineering with Claude Code. Run via `npm create wp-ai-plugin <target>`.
