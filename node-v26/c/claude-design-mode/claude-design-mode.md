# claude-design-mode

> 标签: ai-agent, claude, claude-code, design-mode, design-tokens, developer-tools, devtools, inspector, react, vite-plugin

## 简介

Click an element in your running app and your coding agent edits the exact line that rendered it. Dev-time inspector, Vite plugin, and token-aware design sidebar for Claude Code and other agents.
