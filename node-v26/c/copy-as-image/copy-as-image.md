# copy-as-image

> 标签: browser, clipboard, copy, dom-to-image, frontend, html2canvas, image, screenshot

## 简介

一个强大且可配置的库，用于将网页 DOM 元素复制为图片到剪贴板，并提供优雅的回退方案。
