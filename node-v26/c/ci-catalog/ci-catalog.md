# ci-catalog

> 标签: catalog, ci-cd, dag, docs, gitlab, gitlab-ci, pipeline, visualization

## 简介

dbt-docs-style catalog generator and DAG viewer for GitLab CI/CD pipelines: parse a repo of templates into a static, browsable manifest with per-ref run simulation.
