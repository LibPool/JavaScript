# claude-session-recall

> 标签: agent-memory, ai-coding-assistant, anthropic, claude, claude-code, claude-code-skill, compaction, context-window, transcript

## 简介

Read your Claude Code session's own transcript. See how many times it was compacted, and whether a fact you are relying on was ever measured or only inherited from a summary.
