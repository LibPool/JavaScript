# csstruth

> 标签: ai-agents, chrome-devtools-protocol, claude-code, css, layout, layout-testing, mcp, model-context-protocol, responsive, visual-testing

## 简介

Hard ground truth for CSS — extracts the browser's rendered layout as deterministic, diffable text so coding agents stop guessing. MCP server + CLI.
