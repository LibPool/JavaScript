# convert-imports

> 标签: alias, cli, imports, javascript, typescript

## 简介

A **zero-dependency [Node.js](https://nodejs.org/)** script that automatically converts **relative import paths**   (e.g., `../../utils/helpers`) to **alias-based imports** (e.g., `@/utils/helpers`) in **any JavaScript/TypeScript project**.
