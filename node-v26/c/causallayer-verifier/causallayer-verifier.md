# causallayer-verifier

> 标签: ai-liability, causallayer, certificate, deterministic, ed25519, faultkey, merkle, verification

## 简介

Client-side verification CLI for CausalCertificateV1 — Ed25519 signature, Merkle tree, hash consistency, issuer trust, and anchor status checks.
