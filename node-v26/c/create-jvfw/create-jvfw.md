# create-jvfw

> 标签: JavaScript

## 简介

创建目录初始化,目录需要为空文件夹 ``` mkdir jv-egg-boilerplate ``` 进入对应文件夹 ``` cd jv-egg-boilerplate ``` 创建脚手架 ``` npm init jvfw ``` 项目初始化 ``` npm i ``` 执行启动脚本 ``` npm run dev ```
