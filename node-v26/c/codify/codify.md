# codify

> 标签: automated-installation, codify, configuration-as-code, oclif, system-automation, system-configuration

## 简介

Codify is a configuration-as-code tool that declaratively installs and manages developer tools and applications. Check out https://dashboard.codifycli.com for an editor.
