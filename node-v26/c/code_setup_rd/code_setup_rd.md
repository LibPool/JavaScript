# code_setup_rd

> 标签: boilerplate, cli, express, mongoose, nodejs, scaffold, sequelize, typescript

## 简介

CLI tool to scaffold a Node.js/Express backend boilerplate with Sequelize (MySQL/PostgreSQL) or Mongoose (MongoDB), in JavaScript or TypeScript.
