# credit-matrix

> 标签: CRediT, JATS4R, authorship, contributor roles taxonomy, scholarly publishing

## 简介

CRediT (Contributor Roles Taxonomy) statements and exports: JATS4R XML, CSV, JSON, Markdown and a heatmap SVG, with a CLI and a <credit-matrix> element.
