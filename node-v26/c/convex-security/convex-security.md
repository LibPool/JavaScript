# convex-security

> 标签: access-control, ai-agents, auditor, baas, backend-as-a-service, convex, data-exposure, devsecops, security, security-audit, serverless

## 简介

Audit any Convex backend for public functions reachable without auth — and PROVE each leak live by calling the public HTTP API anonymously and returning the real rows. No deploy key needed for the keyless scan.
