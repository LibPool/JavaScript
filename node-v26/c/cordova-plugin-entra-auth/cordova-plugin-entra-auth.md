# cordova-plugin-entra-auth

> 标签: authentication, azure-ad, cordova, cordova-entra-auth, ecosystem:cordova, entra, msal, oauth

## 简介

Microsoft Entra ID authentication for Cordova apps, via the official Microsoft Authentication Library (MSAL) for iOS (Android planned). Authentication only — no Microsoft Graph or SharePoint functionality.
