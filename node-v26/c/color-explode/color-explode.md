# color-explode

> 标签: color-explode, css, postcss, postcss-plugin

## 简介

PostCSS plugin that takes hex/rgb/hsl color variables and explodes them into their component parts.

## 官网

- 源码仓库：https://github.com/crcarrick/color-explode
- npm 页面：https://www.npmjs.com/package/color-explode

- 1.0.0

- npm registry：https://registry.npmjs.org/color-explode
- Node 要求：>=18.2.0
