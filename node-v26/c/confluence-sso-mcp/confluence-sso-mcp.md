# confluence-sso-mcp

> 标签: atlassian, confluence, confluence-cloud, confluence-server, cursor, mcp, model-context-protocol, sso

## 简介

Model Context Protocol (MCP) server for Atlassian Confluence: browser SSO cookies for REST API access (with background session keep-alive and stale-cookie cleanup)—works with any reachable site you configure (Cloud or Data Center).
