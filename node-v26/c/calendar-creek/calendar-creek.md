# calendar-creek

> 标签: JavaScript

## 简介

* 基于 Vue 开发的轻量级、多作用的日历组件 * 占用内存小，性能高，作用强，可扩展 * 全部由Vue实现，没有引入第三方库 * 不仅可以获取日期，还可以根据需求来获取时间 * 可以获取年 - 月 - 日 时 : 分 : 秒 ,可以单独获取其中几个，也可以获取全部，使用起来十分方便
