# contextable

> 标签: cast, casting, change, class, context, contextable, contextify, database, db, document, error, errors, field, fields, form, handle, handling, history, map, mapping, model, modeling, odm, orm, storage, structure, structuring, tracking, type, valid, validate, validating, validation, validator

## 简介

Simple, unopinionated and minimalist framework for creating context objects with support for unopinionated ORM, object schemas, type casting, validation and error handling.
