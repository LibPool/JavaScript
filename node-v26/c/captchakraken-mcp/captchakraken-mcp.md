# captchakraken-mcp

> 标签: api-keys, captcha, captchakraken, claude, llm-tools, mcp, model-context-protocol

## 简介

MCP server for the CaptchaKraken account: sign in with GitHub, mint and revoke API keys for the captcha-solving endpoint, and read your usage and balance. Writes the key to disk so the solver needs no environment variables.
