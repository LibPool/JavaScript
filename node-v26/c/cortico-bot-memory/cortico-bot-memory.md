# cortico-bot-memory

> 标签: agent-memory, bm25, cortico-bot, cortico-kit, embedding, memory, memory-management

## 简介

Cortico bot 模板:在 Persona 层面复现五层长期记忆(事实库/知识库/反思/人格/档案 + 三级底座 + 混合检索),记忆归 bot 私有,经系统前缀注入、对话实时沉淀,无需 world。
