# cascade-verify

> 标签: audit, cascade, ed25519, hash-chain, offline, receipts, verify

## 简介

Offline, zero-dependency verifier for Cascade receipt bundles (formats v1 and v2, session keys, anchors): hash chain, Ed25519 signatures, exclusivity, zero tokens, anchors.
