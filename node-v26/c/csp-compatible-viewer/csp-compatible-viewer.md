# csp-compatible-viewer

> 标签: angular, csp, docx, file-viewer, html, mammoth, pdf, preview, sheetjs, xlsx

## 简介

CSP-safe Angular file preview for PDF, images, HTML, Word (.docx), and Excel (.xlsx/.csv). Fetches via connect-src and renders blobs client-side — no iframe framing of third-party origins.
