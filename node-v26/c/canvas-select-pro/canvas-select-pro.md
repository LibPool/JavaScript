# canvas-select-pro

> 标签: annotation, canvas, circle, dot, grid, line, marker, polygon, rect, 圆, 多边形, 折线, 标注, 点, 电子围栏, 矩形, 网格

## 简介

一个用于图片标注的javascript库，基于canvas，简单轻量，支持矩形、多边形、点、折线、圆形、网格。
