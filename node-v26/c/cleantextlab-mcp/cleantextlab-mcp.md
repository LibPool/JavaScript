# cleantextlab-mcp

> 标签: claude, cursor, developer-tools, hex-converter, json-formatter, mcp, mcp-server, model-context-protocol, sanitize-url, sql-formatter, text-tools, token-counter

## 简介

24 deterministic text tools for AI agents — URL sanitizer, JSON/SQL/YAML formatters, hex/base64/hash, token counter, cron explainer, and more. Runs locally over stdio; no API key, no network.
