# cnj-utils

> 标签: JavaScript

## 简介

Pacote que contém funções para geração e verificação dos digitos verificadores da numeração única, utilizada para organizar os processos no poder judiciário brasileiro. Saiba mais em http://www.cnj.jus.br/programas-e-acoes/pj-numeracao-unica
