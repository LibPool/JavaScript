# cap-mcp-bridge

> 标签: ai, cap, claude, llm-tools, mcp, model-context-protocol, odata, odata-v4, sap, sap-cap

## 简介

MCP server that turns any SAP CAP or OData v4 service into LLM tools by reading its OData metadata document. No per-service code.
