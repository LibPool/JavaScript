# create-wails-ui

> 标签: desktop, react, scaffolder, shadcn, tailwind, vite, wails, wails3

## 简介

Scaffolder for Wails 3 desktop apps: React + Vite + TypeScript + Tailwind + shadcn/ui with desktop defaults, interface presets, batteries and an optional OpenCode desktopizer
