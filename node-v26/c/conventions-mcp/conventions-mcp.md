# conventions-mcp

> 标签: claude, claude-code, embeddings, mcp, memory, model-context-protocol, sqlite, vector-search

## 简介

Cross-session memory for coding conventions and standing instructions, so your AI coding assistant stops forgetting them between sessions. Local SQLite + embeddings, hybrid search, MCP over stdio.
