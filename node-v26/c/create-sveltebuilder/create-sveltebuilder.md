# create-sveltebuilder

> 标签: boilerplate, create, drizzle, scaffold, starter, supabase, svelte, svelte5, sveltebuilder, sveltekit, template

## 简介

Scaffold a production-ready SvelteKit app with SvelteBuilder — i18n, accessible UI components, and domain modules, pre-wired to Supabase or Drizzle.
