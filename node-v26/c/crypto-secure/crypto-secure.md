# crypto-secure

> 标签: aes-gcm, ecdh, encryption, express, forward-secrecy, hybrid-encryption, middleware, p-256, rsa

## 简介

Hybrid encryption (ECDH P-256 + AES-256-GCM) with Express middleware for automatic request/response encryption. Also supports RSA-2048 OAEP.
