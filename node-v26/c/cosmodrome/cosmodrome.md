# cosmodrome

> 标签: agents, ai, antigravity, artifacts, claude-code, cli, codex, copilot, opencode, profiles, research, tmux, tui

## 简介

Claude Code-style interface for all your AI coding agents: channels per profile and agent, slash commands, artifacts, and separate work/private logins.
