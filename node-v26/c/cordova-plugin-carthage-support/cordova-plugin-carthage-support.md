# cordova-plugin-carthage-support

> 标签: JavaScript

## 简介

本プラグインはCarthageで導入したライブラリを使用してCordovaプラグインを開発するためのプラグイン。   Xcodeの`Build Phases`へ`Run Script`の設定を行う。
