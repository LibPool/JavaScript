# cf-usage-guard

> 标签: alerts, billing, circuit-breaker, cloudflare, cost-protection, d1, discord, guard, kv, overage, queues, r2, slack, usage, workers

## 简介

Automatic usage protection for Cloudflare Workers. Monitors account-level resource consumption, trips a guard before you hit billing overages, and sends alerts via Discord/Slack/custom webhooks.
