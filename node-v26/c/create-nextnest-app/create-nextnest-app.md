# create-nextnest-app

> 标签: better-auth, boilerplate, create-nextnest-app, nestjs, nextjs, scaffold, shadcn, starter

## 简介

Scaffold a Next.js + NestJS app with Better Auth (email/password, Google OAuth, 2FA) and shadcn/ui pre-wired.
