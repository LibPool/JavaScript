# cev-node

> 标签: calibration, candle, cev, classification, classifier, decision, llm, local-llm, metal, napi, native, online-learning, qwen, routing, system-one

## 简介

Typed, calibrated decisions from a small local LLM in one forward pass: is this true, which of these, which level. The cev engine in-process as a native addon (Metal, Accelerate, multi-core CPU), with a decision log, feedback and online learning.
