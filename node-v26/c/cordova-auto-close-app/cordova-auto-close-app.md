# cordova-auto-close-app

> 标签: cordova-android, ecosystem:cordova

## 简介

This plugin helps to close the Cordova app at a given time. This may help for  programs, which does hold updates locally and performs js updates only when the user logs in again. Closing the app at nighttime does force a fresh login next morning.
