# codex-claude-bridge

> 标签: anthropic, claude, code-review, codex, gemini, google, mcp, openai

## 简介

MCP server for automated code review in Claude Code — OpenAI Codex or Google Gemini reviews your plans and diffs inline, with automatic failover between providers.
