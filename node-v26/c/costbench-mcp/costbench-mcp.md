# costbench-mcp

> 标签: mcp, model-context-protocol, pricing, saas, tco

## 简介

stdio shim for the CostBench MCP server — software pricing, hidden costs, TCO and comparison tools (bridges npx/claude-desktop to the remote streamable-HTTP endpoint)
