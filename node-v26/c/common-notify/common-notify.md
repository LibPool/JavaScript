# common-notify

> 标签: JavaScript

## 简介

安装 ``` yarn add common-notify --dev ``` 使用 ``` <template>  <div>    <Notify content="this is notify information"></Notify>  </div> </template> import Notify from 'common-notify'; export default {     commonpents: {         Notify     } } ```
