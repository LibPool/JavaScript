# css2lottie

> 标签: after-effects, after-effects-alternative, animation, bodymovin, cli, converter, css, css-animation, css-to-lottie, html-to-lottie, keyframes, lottie, lottie-converter, lottie-generator, lottie-json, lottie-web, lottiefiles, motion-design, playwright, svg, svg-animation, svg-to-lottie, transitions, web-animations

## 简介

Convert HTML + CSS animations (@keyframes, transitions) and inline SVG into Lottie JSON. CSS to Lottie converter, no After Effects required.
