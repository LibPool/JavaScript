# cortex-ai-memory

> 标签: ai, claude, cline, coding-assistant, context, copilot, cursor, developer-tools, mcp, memory

## 简介

Persistent memory for AI coding assistants. Auto-captures decisions, patterns, and context from Claude Code sessions. Works with Cursor, Cline, Copilot via MCP. Never re-explain your codebase again.
