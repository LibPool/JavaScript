# crx-auto-reload-plugin

> 标签: auto-reload, chrome-extension, crx, webpack-plugin

## 简介

A webpack plugin to auto reload while developing chrome extension. 一个用于开发Chrome扩展时监视文件修改并自动重载的Webpack插件。
