# cordova-plugin-amap

> 标签: amap, cordova-android, cordova-ios, ecosystem:cordova, geo, maps

## 简介

Amap Maps native SDK for Android and iOS.
This plugin allows your application to use the native Amap Maps views instead of the Amap Maps JavaScript API v3.
The native map view is faster, use less network usage, display 3D views, and even work on offline n
