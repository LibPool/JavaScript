# compress-edge

> 标签: browser, compress, compression, compression-streams-api, decompress, deflate, gzip, streams, typescript, web-api, wrapper

## 简介

Lightweight wrapper over the Compression Streams API for compressing and decompressing data with gzip, deflate and deflate-raw.
