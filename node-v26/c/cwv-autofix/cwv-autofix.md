# cwv-autofix

> 标签: accessibility, audit, auto-fix, cli, core-web-vitals, cwv, lighthouse, performance, seo

## 简介

Automated Core Web Vitals auditor and auto-fixer CLI. Crawls sitemaps, runs Lighthouse audits, diagnoses issues, proposes AST code fixes, and re-validates performance.
