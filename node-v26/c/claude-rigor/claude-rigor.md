# claude-rigor

> 标签: agent, ai, anti-hallucination, claude, claude-code, evidence, guardrails, hooks, llm, rigor

## 简介

Guardrail hooks for Claude Code that enforce evidence over assertion: block edits made without a stated goal, and catch speculative language ("probably", "should work") before the agent stops.
