# construction-scheme-modify

> 标签: agent-skills, claude, claude-code, construction, docx, engineering, skills, word, 修改意见, 施工方案

## 简介

修改施工方案/专项方案（Word .docx）并编写修改意见回复的 Agent 技能。按意见逐条定位修改、输出修改稿与固定格式回复，识别矛盾数值/模板残留/废止规范，图片零改动；支持 WPS 老格式（.doc/.wps）输入（COM 转换）与渲染级验证（转 PDF）。| Agent skill that revises construction schemes (Word .docx) per review comments and produces a formal modification reply
