# computed-css-diff

> 标签: cli, computed-style, css, diff, migration, playwright, refactor, scss, tailwind, visual-regression

## 简介

Headless computed-style diffing for CSS refactors. Captures getComputedStyle across viewports on two builds and diffs the values, so a stylesheet migration (e.g. SCSS to Tailwind) can be verified element-by-element.
