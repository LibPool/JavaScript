# covergen

> 标签: anthropic, bun, claude, cli, coverage, jest, lcov, llm, rspec, test-generation, vitest

## 简介

Coverage-gated LLM test generation. Generates candidate tests, keeps only those that build, pass repeatedly, and strictly raise coverage.
