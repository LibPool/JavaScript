# cartoon-eyes

> 标签: animated-eyes, animation, avatar, blinking, cartoon, cursor-following, eye, eye-pair, eye-tracking, eyes, googly, googly-eyes, mascot, mouse-follow, react, react-component, svg, svg-animation

## 简介

Dependency-free React components for customisable animated SVG cartoon eyes: blinking, random wandering and controlled cursor-following movement, as a single eye or a synchronised pair
