# cpf-obfuscator-validator

> 标签: cpf, lgpd, nodejs, obfuscator, validator

## 简介

O `cpf-obfuscator-validator` é uma biblioteca Node.js projetada para validar e obfuscar números de CPF (Cadastro de Pessoas Físicas), oferecendo uma solução eficaz para a verificação da validade de CPFs e para a proteção desses dados através da obfuscação
