# chrome-devtools-pattern-detector

> 标签: ai-tools, chrome-devtools, console-errors, mcp, memory-leak, network-monitoring, observability, pattern-detection, sdet, web-vitals

## 简介

MCP server that adds a pattern detection intelligence layer on top of Chrome DevTools MCP. Detects repeated console errors, slow/failed network requests, Core Web Vitals regressions, broken resource loads, and memory leaks — with actionable suggestions.
