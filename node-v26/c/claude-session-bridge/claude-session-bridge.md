# claude-session-bridge

> 标签: claude, claude-code, mcp, model-context-protocol, orchestration, session-bridge

## 简介

MCP message bus that bridges multiple Claude Code sessions (frontend / backend / infra) within a project. Send results from one session, auto-receive them in another.
