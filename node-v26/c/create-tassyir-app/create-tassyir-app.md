# create-tassyir-app

> 标签: create, scaffold, starter, tassyir, tassyir-app, template

## 简介

Start a Tassyir app: npm create tassyir-app@latest. A Node server with an embedded page, webhooks and the Admin API, ready for AI coding agents (AGENTS.md, CLAUDE.md, a Claude Code skill).
