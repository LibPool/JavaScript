# conditional-custom-prompt

> 标签: deepseek, dsh, dsh-plugin, harness, prompt, system-prompt

## 简介

A conditional custom System Prompt store for DeepSeek Harness: keep any number of named prompts, switch each on or off, and stack the enabled ones into the system prompt as a single `custom-prompt` section; with nothing enabled, nothing at all is injected
