# cesium-wind-arrows-3d

> 标签: 3d, arrow, cesium, globe, gpgpu, visualization, webgl2, wind, wind-field

## 简介

CesiumJS 三维风场箭头图层：多层 (u,v,w) 风场驱动的 3D 箭头场，WebGL2 GPGPU 实现，支持高度层切换与运行时换数据
