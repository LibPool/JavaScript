# coderwoman-slider

> 标签: carousel, coderwoman-slider, gallery, react, react carousel, react gallery, react siema, react slider, react-siema, siema, slider

## 简介

ReactSiema is a lightweight carousel plugin for React. It's a wrapper based on decent library [Siema](https://github.com/pawelgrzybek/siema).
