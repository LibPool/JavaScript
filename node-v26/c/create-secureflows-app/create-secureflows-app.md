# create-secureflows-app

> 标签: create-app, react, scaffold, secure-flows, secureflows, starter, vite

## 简介

Scaffold a working secureFlows integration (React + TypeScript + Vite) with hosted login, an unguarded callback route, and correct session handling already wired up.
