# cursify

> 标签: distort, magik, xiao

## 简介

Takes a local file and "cursifies" it, making it weird and distorted. Uses https://github.com/dragonfire535/xiao's util/canvas module for the distortions, this package uses that as a base and allows end users to easily use that package for a specific purp
