# cordova-plugin-requestreview

> 标签: cordova-ios, ecosystem:cordova, ios, rating, review

## 简介

Cordova plugin to ask the user to rate or review your app, if appropriate. The system handles the entire process for you. Supports iOS 10.3 and greater.
