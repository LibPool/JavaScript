# controljs

> 标签: GUI, HTML, ajax, javascript, rest

## 简介

JavaScript control base class for both server and client side GUI development. Control is the opposite of templating.

- 源码仓库：git://github.com/ewoudj/control.git
- npm 页面：https://www.npmjs.com/package/controljs
