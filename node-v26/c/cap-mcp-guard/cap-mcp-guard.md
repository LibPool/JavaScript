# cap-mcp-guard

> 标签: CAP, CDS, ai-agent, cap, cds-plugin, mcp, odata, opentelemetry, plugin, policy, sap

## 简介

A CDS plugin — the trust layer for AI agents accessing SAP CAP business data — request interception, policy enforcement, field masking/pseudonymization, and OpenTelemetry-native observability for MCP-enabled applications.
