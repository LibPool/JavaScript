# capacitor-levelplay

> 标签: ads, android, banner, capacitor, capacitor-plugin, capacitor7, capacitor8, ilrd, impression-data, interstitial, ios, ironsource, levelplay, mediation, native, native-ads, plugin, rewarded, rewarded-video, swift-package-manager, unity, unity-ads, unity-levelplay

## 简介

Capacitor 7 and 8 plugin for Unity LevelPlay (ironSource) ads on Android and iOS: rewarded, interstitial, banner and native ads, impression-level revenue, segments, ad-unit API, Swift Package Manager first, ATT and GDPR / CCPA / COPPA consent.
