# claude-memory-lint

> 标签: JavaScript

## 简介

Structural checks for a Claude Code MEMORY.md memory archive: closed size budget, required frontmatter, per-line provenance markers, perishable-state tracking, a personal-data/secrets scan, and a suppression-instruction detector judged by effect.
