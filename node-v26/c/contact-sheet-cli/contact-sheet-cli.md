# contact-sheet-cli

> 标签: batch, cli, contact-sheet, diff, html, image-review, proof-sheet, qa

## 简介

Generate a self-contained HTML contact sheet for reviewing an image-processing batch: columns of folders, rows matched by filename, so you can eyeball original vs processed side by side.
