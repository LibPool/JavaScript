# cdkit-cli

> 标签: cli, node

## 简介

cdkit-cli 是一个简单的命令行工具，旨在为日常工作提供快速便捷的命令。它支持多种实用功能，如快速创建项目、一键集成 Jeecg 代码等。👩‍💻👨‍💻
