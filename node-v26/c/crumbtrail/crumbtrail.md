# crumbtrail

> 标签: ai-agents, bug-reporting, cli, codegen, coding-agent, crumbtrail, debugging, developer-tools, install, observability, session-replay, setup, wizard

## 简介

Set up Crumbtrail in one command: npx crumbtrail detects your framework, wires in the SDK and verifies the first event. Also the library the hosted product uses for detection and injection planning, on the crumbtrail/install and crumbtrail/testing subpath
