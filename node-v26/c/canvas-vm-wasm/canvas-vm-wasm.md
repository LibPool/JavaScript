# canvas-vm-wasm

> 标签: compiler, esoteric, interpreter, piet, runtime, visual-programming, vm, wasm, webassembly

## 简介

A serious Piet runtime for JavaScript/TypeScript. Execute visual programs (images as code) with WebAssembly performance. Includes compiler, debugger, and step execution.
