# create-zigg-layout

> 标签: JavaScript

## 简介

Template ini merupakan boilerplate untuk proyek frontend menggunakan Svelte dengan Vite sebagai bundler, serta TailwindCSS yang dikombinasikan dengan DaisyUI sebagai UI framework.
