# catching-jit-tests-vitest

> 标签: cli, git-diff, llm, mutation-testing, openrouter, regression-testing, test-generation, testing, typescript, vitest

## 简介

For every PR/diff, you need to: generate tests against the parent branch that pass, run those same tests against the PR branch, and harvest the ones that now fail ("weak catches"). The hard part is everything around that — making the test generation diff-
