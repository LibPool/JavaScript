# chook-xml-reporter

> 标签: JavaScript

## 简介

JUnit compatible XML reporter of tests for [chook](https://github.com/markdalgleish/chook) - the headless, framework-agnostic unit test runner. The results are intended to be used by Continuous Integration Servers, such as Jenkins.
