# codebase-atlas

> 标签: ast, codebase, compodoc, dead-code, dependency-graph, documentation, madge, nextjs, react, storybook, ts-morph, typescript, vite

## 简介

Atlas — scan a frontend codebase and auto-discover, analyze, and document every reusable asset (components, hooks, utils, contexts, stores, routes) using AST semantics — Storybook + Compodoc + Madge + auto-generated docs for modern frontends.
