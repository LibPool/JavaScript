> 标签: ai-video-editor, batch-edit, capcut, capcut-api, capcut-automation, capcut-draft, capcut-editor, capcut-json, capcut-project, capcut-srt, capcut-subtitles, capcut-template, cli, draft_content, draft_info, jianying, long-video-to-shorts, mcp, srt-export, subtitle-editor, video-automation, video-editing, video-to-shorts

## 简介

Independent, unofficial CLI to create and edit CapCut projects — build drafts from scratch, add video/audio/text, subtitles, timing, speed, volume, templates, cut long-form to shorts. No API needed. Not affiliated with ByteDance.
