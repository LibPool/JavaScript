# canvas-text-layer

> 标签: a11y, accessibility, aria, canvas, ctrl-f, dom-mirror, fabric, find-in-page, konva, pdfjs, screen-reader, text-layer, text-selection, tldraw, wcag

## 简介

The DOM text-mirror technique from Mozilla PDF.js, extracted as a 13 KB framework-agnostic library. Makes canvas-rendered text searchable (Ctrl+F), selectable, copyable, and fully readable by screen readers. Works with any canvas — Konva, Fabric.js, tldra
