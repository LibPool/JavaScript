# crx-hotreload

> 标签: automatic reload, chrome, chrome extension, chrome plugin, crx, crx-hotreload, extension, file monitor, hot, hot reload, plugin, reload, restart on code change, watch, watchdog

## 简介

Watches for file changes in your Chrome extension's directory. When a change is detected, it reloads the extension and refreshes the active tab (to re-trigger the updated scripts).
