# cordova-plugin-appsflyer

> 标签: appsflyer, cordova, cordova-android, cordova-ios, ecosystem:cordova

## 简介

Cordova plugin for integration with AppsFlyer SDK. It's a fork with some changes of the official version from AppsFlyer.
