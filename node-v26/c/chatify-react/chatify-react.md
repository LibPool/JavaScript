# chatify-react

> 标签: AI

## 简介

chatify-react is an npm package containing react-components to easily bridge the gap between OpenAI's ChatGPT and your client. It comes fully equipped with a `ChatProvider` and a `ChatView` Component that is supposed to help you easily integrate ChatGPT i
