# clickspex

> 标签: chrome-extension, codegen, css, design-to-code, devtools, tailwind, ui

## 简介

Inspect and edit UI in the browser, then apply the changes to your source code. Local bridge, source indexer, and patch-preview CLI for the Clickspex extension.
