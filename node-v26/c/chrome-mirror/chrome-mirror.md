# chrome-mirror

> 标签: browserless, cdp, chrome, devtools-protocol, mirror, puppeteer-alternative, remote-browser, screencast

## 简介

Mirror a Chrome browser to a web viewer via CDP — multi-tab, zoom, remote host, no detection
