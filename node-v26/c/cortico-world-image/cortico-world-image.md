# cortico-world-image

> 标签: coopanion, cortico, cortico-world, gpt-image, image, image-generation, openai-compatible, text-to-image

## 简介

Image Studio（图片工坊）—— 给 Coopanion 桌宠的 cortico World 扩展：用任意 OpenAI 兼容的图片接口画图/改图、落盘成作品库、把图贴进控制台「对话」页，并自带一套自动重打的自愈补丁。 / A cortico World extension that draws through any OpenAI-compatible image API, keeps pictures on disk and shows them in the console.
