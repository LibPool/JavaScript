# coiote-to-lwm2m-asset-tracker-v2

> 标签: AVSystem, Asset Tracker v2, LwM2M, coiote

## 简介

Convert the LwM2M JSON encoding written by AVSystem's Coiote Azure integration to LwM2M Asset Tracker v2 JSON encoding
