# chartjs4vue

> 标签: JavaScript

## 简介

Plugin Vue 3 untuk menampilkan chart berbasis Chart.js 4 dengan dukungan datalabel, tooltip kustom, legend, stacked chart, chart campuran, serta format angka otomatis.
