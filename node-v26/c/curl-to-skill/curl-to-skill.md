# curl-to-skill

> 标签: agent, ai-skill, api, claude, claude-code, codegen, curl, developer-tools, sdk, skills

## 简介

Turn one curl command from API docs into a working agent skill — a SKILL.md plus a runnable script — in one shot. Zero dependencies, free.
