# clipwright

> 标签: demo, docs-as-code, documentation, how-to, playwright, screen-recording, screencast, tutorial, video

## 简介

Code-driven how-to videos: a TypeScript scene in, an MP4 with an animated cursor, captions and smooth zoom out. Built on Playwright.
