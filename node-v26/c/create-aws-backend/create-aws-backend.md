> 标签: api-boilerplate, aws, aws-backend, aws-lambda, aws-sdk, backend, backend-boilerplate, backend-generator, boilerplate, cli, create-app, dynamodb, express, express-typescript, generator, lambda, nodejs, npx, project-generator, rest-api, scaffolding, serverless, starter-kit, typescript

## 简介

CLI to scaffold your Express + TypeScript backend in seconds — the folder structure, the middleware and even the database configuration (for DynamoDB and soon more!) is set up automatically. No need to rebuild your backend setup for every project.
