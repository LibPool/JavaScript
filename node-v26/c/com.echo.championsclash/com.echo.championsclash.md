# com.echo.championsclash

> 标签: championsclash, echo, event, tournament

## 简介

Time-limited single-elimination 1v1 tournament event module for Echo games. Player races simulated bots in timed score rounds through a bracket to the Grand Final; losing a round ends the attempt. Daily/weekly/duration trigger schedule, attempts per windo
