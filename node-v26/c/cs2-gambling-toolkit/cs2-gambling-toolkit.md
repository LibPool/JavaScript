# cs2-gambling-toolkit

> 标签: counter-strike, cs2, expected-value, gambling, hmac, provably-fair, skin-gambling, verifier

## 简介

Open-source verifier and calculators for CS2 gambling: provably-fair roll verification (HMAC-SHA256), case-opening expected value, and bonus wagering cost. Zero dependencies.
