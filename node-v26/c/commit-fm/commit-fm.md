> 标签: ai-agents, animated-svg, developer-tools, dynamic-readme, github-actions, github-profile, github-profile-readme, mcp, now-playing, profile-readme, readme, svg, widget

## 简介

A now playing style banner for your GitHub profile README, rendered as an SVG by a scheduled GitHub Action. Zero runtime dependencies, no server, no model calls.
