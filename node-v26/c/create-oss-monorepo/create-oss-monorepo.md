# create-oss-monorepo

> 标签: boilerplate, cli, create, generator, monorepo, open-source, scaffold

## 简介

Scaffold a new open-source monorepo (apps/ + packages/, GitHub templates, CI, licensing, contributor docs) with one interactive command.
