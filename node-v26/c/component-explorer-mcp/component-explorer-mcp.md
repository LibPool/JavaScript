# component-explorer-mcp

> 标签: ai, claude, components, design-system, mcp, model-context-protocol, react, typescript

## 简介

MCP server that scans a React + TypeScript project (read-only), classifies and lists its components, extracts portable code, and re-themes them — over the same engine as the Component Explorer web gallery.
