# car-registration-api-nigeria

> 标签: Nigeria, car, license, registration

## 简介

Get car information from a Nigerian number plate. An account username is required, which you can get from http://ng.carregistrationapi.com/

## 官网

- 源码仓库：http://ng.carregistrationapi.com/
- npm 页面：https://www.npmjs.com/package/car-registration-api-nigeria

- 1.0.4
