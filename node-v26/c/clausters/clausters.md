# clausters

> 标签: audio, audioworklet, dsp, faust, osc, supercollider, synthesis, webassembly, webgpu

## 简介

Clausters in the browser: the audio engine in an AudioWorklet, the GUI host on a canvas, web components that boot standalone bundles, and the OSC/connection seam of the TypeScript client — no server process needed.
