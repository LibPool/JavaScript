# circlekey

> 标签: cryptography, e2ee, end-to-end-encryption, groupvault, zero-knowledge

## 简介

Reference TypeScript implementation of the GroupVault Protocol — end-to-end encrypted group data storage for small teams with a zero-knowledge backend.
