# cloudflarest-ts

> 标签: cdn, cloudflare, httping, ip, latency, speedtest, tcping, 优选

## 简介

测试各个 CDN 或网站所有 IP 的延迟和速度，获取最快 IP (IPv4+IPv6)。XIU2/CloudflareSpeedTest 的 TypeScript 重写版
