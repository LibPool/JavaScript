# capacitor-local-notifications-dismiss

> 标签: android, capacitor, dismiss, native, notifications, plugin

## 简介

The Local Notifications forked, including API with dismiss detection support on Android - provides a way to schedule device notifications locally with the ability to detect when notifications are dismissed.
