# cordova-credify-plugin-sms

> 标签: cordova, cordova-android, credify-sdk

## 简介

Plugin for Cordova applications that utilizes Credify Collection SDK to collect SMS and Device Info from device, supports only android platform.

## 官网

- 官网：https://docs.credify.live/docs/credit-scoring/sdk/cordova
- 源码仓库：git+https://github.com/apache/cordova-credify-plugin.git
- npm 页面：https://www.npmjs.com/package/cordova-credify-plugin-sms
