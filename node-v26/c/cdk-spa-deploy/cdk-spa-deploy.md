# cdk-spa-deploy

> 标签: aws, cdk, cloudfront, deploy, spa, website

## 简介

This is an AWS CDK Construct to make deploying a single page website (Angular/React/Vue) to AWS S3 behind SSL/Cloudfront as easy as 5 lines of code.
