# chart-js-fabric

> 标签: JavaScript

## 简介

This package allows you to include charts (using Chart.js) into your fabric canvases with support for all features (e.g. events, rotation, scale, etc.).

- 源码仓库：git@github.com:yassipad/chart-js-fabric.git
