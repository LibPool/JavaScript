# codedog-ui

> 标签: component-library, components, design-tokens, ui, uni-app, uni_modules, vue, vue3, 小程序, 移动端, 组件库, 设计令牌, 跨端, 骨架屏

## 简介

面向 uni-app 的跨端 UI 框架。一套 Vue3 代码同时覆盖 H5 移动端、H5 PC 浏览器、微信小程序与 Electron 桌面套壳；通过 Design Tokens + 平台适配层 + 双形态组件三层架构，让同一组件在手机与 PC 上呈现各自的交互形态。
