# cc-doctor

> 标签: anthropic, claude, claude-code, cli, config, configuration, devtools, diagnostics, doctor, hooks, lint, linter, mcp, secret-detection, secrets-scanner, security, settings, static-analysis

## 简介

Diagnostic CLI that scans a repo's Claude Code configuration (.claude/settings.json, hooks, .mcp.json, CLAUDE.md) for common misconfigurations and accidentally committed secrets.
