# create-okona-game

> 标签: create, game, html5, multiplayer, okona, party-game, phone-controller, scaffold

## 简介

Scaffold a phone-controlled multiplayer HTML5 game for Okona: lobby, join code, six seats, and a game.js to make yours.

## 官网

- 官网：https://okonaonline.com/developers/docs.html#html5
- npm 页面：https://www.npmjs.com/package/create-okona-game
