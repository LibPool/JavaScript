# create-rindle

> 标签: create, ivm, local-first, rindle, scaffold, sqlite, sync, tanstack

## 简介

Scaffold a new SQL-first Rindle app on TanStack Start — `npm create rindle@latest`. The migrations are the source of truth; the @rindle/client schema is generated from them, and the browser runs the in-process wasm IVM engine.
