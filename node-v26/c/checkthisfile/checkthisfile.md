# checkthisfile

> 标签: ai-agents, checksum, checkthisfile, cli, document-verification, file-integrity, manifest, offline, sha256, version-history, website-text

## 简介

Offline file integrity for applications and coding agents: SHA-256, exact-file comparison and portable folder manifests. No network, account or telemetry.
