# cardano-tessera-respond

> 标签: cardano, cip-179, custom-element, governance, poll, survey, web-component

## 简介

The embeddable <tessera-respond> custom element: renders the CIP-179 answering UI from a survey definition + responder identity, validates and (for sealed surveys) timelock-encrypts in-widget, and emits a ready-to-attach label-17 payload back to the host.
