# claude-pin

> 标签: anthropic, bookmark, claude, claude-code, cli, pin, plugin, resume, session

## 简介

Pin Claude Code sessions so they survive the --resume window. Adds /pin, /unpin, /pins, /note slash commands plus the cpin CLI with an interactive picker.
