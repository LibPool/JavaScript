# cornerstone-websocket-image-loader

> 标签: blob, cornerstone, imaging, websocket

## 简介

参考cornerstone-web-image-loader，内部不再进行网络数据请求，采用websocket通信等方式，直接将得的数据作为参数，转化为图片，支持png/jpg

- npm 页面：https://www.npmjs.com/package/cornerstone-websocket-image-loader
