# color-engine-mcp

> 标签: accessibility, color, contrast, gamut, mcp, model-context-protocol, oklch, srgb, wcag

## 简介

stdio MCP server exposing six pure, in-memory CSS-color tools: parse, convert, WCAG contrast, sRGB gamut mapping, OKLCH color-ramp generation, and contrast solving.
