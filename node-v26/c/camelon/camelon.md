## 简介

Runtime-agnostic server-rendered hypermedia framework: a web-standard fetch handler + @kitajs/html JSX + Datastar. File-based routing, route contracts from your TypeScript types (OpenAPI + runtime validation), dev error overlay. Runs on Node, Deno, Bun, a
