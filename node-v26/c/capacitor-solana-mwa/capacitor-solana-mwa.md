# capacitor-solana-mwa

> 标签: android, capacitor, mobile-wallet-adapter, mwa, seed-vault, solana, solana-mobile

## 简介

Solana Mobile Wallet Adapter for Capacitor. Native transport, so it needs no cleartext-traffic exemption -- unlike the JS MWA libraries, which cannot connect from a Capacitor WebView without one.
