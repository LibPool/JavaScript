# crawlens

> 标签: astro, audit, crawler, nextjs, pagerank, prerender, seo, sitemap, static-site, tanstack

## 简介

Build-time SEO auditor for prerendered sites — 169 checks, link graph, PageRank, and JSON reports. Zero network requests.
