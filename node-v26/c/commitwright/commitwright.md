# commitwright

> 标签: ai, anthropic, claude, codex, commit, commit-message, git, llm, ollama, openai

## 简介

Generate ticket-prefixed git commit messages from staged changes using Ollama, OpenAI, Anthropic, the Claude Code CLI, or the Codex CLI. Custom prompt templates and persistent global config.
