# concealotron

> 标签: object obfuscation obfuscator logging

## 简介

concealotron helps you conceal an object. It takes an object and returns a copy that has all of the string fields truncated. This is useful for when you want to log an object but it contains sensitive ids, e.g. database fields or secrets. Non string field
