# claude-schema

> 标签: ai, anthropic, claude, json-schema, llm, structured-output, type-safe, typescript, zod

## 简介

Type-safe structured outputs for the Anthropic Claude API — define schemas with Zod, get back validated, fully-typed objects with zero JSON errors.
