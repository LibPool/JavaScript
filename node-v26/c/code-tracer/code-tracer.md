# code-tracer

> 标签: JavaScript

## 简介

提供一种在 Terminal 环境下对代码位置的执行堆栈进行跟踪，并提供nodejs版本提供核心模型中提供的方法github库上的链接访问，该插件主要用于对源代码研究和代码执行逻辑的学习及跟踪的需要。
