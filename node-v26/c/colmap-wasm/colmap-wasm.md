# colmap-wasm

> 标签: camera-poses, colmap, gaussian-splatting, glomap, photogrammetry, sfm, sift, structure-from-motion, wasm, webassembly, webgpu

## 简介

Unofficial WebAssembly build of COLMAP 4.2.1 (SIFT, geometric verification, view-graph calibration, global mapper) for the browser, with exact SIFT matching on WebGPU
