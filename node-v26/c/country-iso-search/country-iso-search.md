# country-iso-search

> 标签: alpha-2, alpha-3, countries, country, country-codes, iso, iso-3166, iso-3166-1, m49, un-m49

## 简介

Resolve country names, codes, and aliases to canonical ISO 3166-1 alpha-3 codes.
