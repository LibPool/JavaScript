# cordis-plugin-sofagent-rollback

> 标签: cordis-plugin, dsh, sofagent

## 简介

给宿主加上快照回溯——Agent 出错时按 git 快照逆序撤销本次改动（seam: agent/error）——桥接 @sofagent/core restoreSnapshot / @sofagent/core listSnapshots
