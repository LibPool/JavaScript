# cowork-qa-mcp

> 标签: browser-automation, llm-tools, mcp, model-context-protocol, playwright, qa

## 简介

MCP server that runs goal-driven Playwright browser sessions and exposes the full action trace plus aria-snapshots so the calling LLM can verify whether the goal was met.
