# comptab

> 标签: argparse, autocomplete, bash, cli, compdef, compgen, completion, completions, fish, generator, help, shell-completion, tab-completion, terminal, zsh

## 简介

Generate bash/zsh/fish tab-completions for ANY CLI from its own --help. Deterministic, dependency-free, offline — no curated spec, no LLM.
