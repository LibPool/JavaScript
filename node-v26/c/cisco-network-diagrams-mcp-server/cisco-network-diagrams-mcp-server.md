# cisco-network-diagrams-mcp-server

> 标签: cisco, icons, mcp, model-context-protocol, network-diagram, topology

## 简介

MCP server exposing the 308 official Cisco Systems Corporate Iconography icons (RGB-fixed) for building network topology diagrams.
