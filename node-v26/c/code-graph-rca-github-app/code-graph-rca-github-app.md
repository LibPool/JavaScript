# code-graph-rca-github-app

> 标签: ai-agent, code-graph, code-review, github-action, github-app, pull-request, rca

## 简介

GitHub PR-review for code-graph-rca — works as a GitHub App (hosted webhook) OR as a GitHub Action (no hosting). Posts ranked causal candidates + blast-radius comments on every PR.
