# cupbearer

> 标签: byok, failover, gateway, llm, openai, proxy, router

## 简介

The local LLM gateway that never hands your task to a model that can't handle it. One OpenAI-compatible endpoint over your own free-tier and paid provider keys, with key pooling, failover, and quality-gated routing.
