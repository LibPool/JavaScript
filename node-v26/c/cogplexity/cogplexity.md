# cogplexity

> 标签: cognitive-complexity, complexity, eslint, eslint-plugin, eslintplugin, svelte, typescript

## 简介

Licence-clean ESLint rule for cognitive complexity (G. Ann Campbell's specification) on TypeScript, JavaScript and Svelte. One rule, zero runtime dependencies, no build step.
