# cache-control-fetch

> 标签: cache, cache-control, fetch, javascript

## 简介

Generate a cache control response header from multiple fetch calls. To be used when the cache control header you want to return to the client is dependent on the API calls you are making. At the moment only public/private, no-store, no-cache and max-age s
