# cpuid-git

> 标签: cpu, os, system

## 简介

Simple to use wrapper around LibCPUID. Gives extremely detailed information about the CPU(s) your code is running on.

## 官网

- 源码仓库：git://github.com/terorie/cpuid-node.git
- npm 页面：https://www.npmjs.com/package/cpuid-git

- npm registry：https://registry.npmjs.org/cpuid-git
- Node 要求：>=0.8.0
