# create-vnp-app

> 标签: create, css-modules, lightweight, navigo, puter, reactive, router, scaffold, spa, starter, state-management, vanjs, vite, vnp

## 简介

Scaffold a new VNP Stack project (VanJS + Navigo + Puter) — lightweight SPA with built-in state management, auto page discovery, CSS Modules, and a multi-mode Vite build pipeline.
