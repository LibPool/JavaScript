# claude-code-backup

> 标签: anthropic, backup, claude, claude-code, cli, devtools, github, macos, memory, settings, sync

## 简介

Backup and auto-sync Claude Code memory, settings, and CLAUDE.md files to a private GitHub repo — with real-time file watching and macOS launchd auto-start
