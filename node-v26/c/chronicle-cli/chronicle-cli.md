# chronicle-cli

> 标签: ai, claude-code, cli, codex, cost, cursor, local-first, opencode, sessions, tokens

## 简介

Local-first session manager + Insights analytics for AI coding sessions: import Claude Code, Codex, Cursor & OpenCode, play back to the exact Git snapshot, redact secrets. npx chronicle-cli, local-first: no account, no telemetry, one opt-out plan-window r
