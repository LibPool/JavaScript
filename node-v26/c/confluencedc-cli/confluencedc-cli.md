# confluencedc-cli

> 标签: JavaScript

## 简介

Command-line interface for [Confluence Data Center](https://developer.atlassian.com/server/confluence/confluence-rest-api-summary/). 26 commands across 7 domains — pages, comments, attachments, labels, search, users, and access tokens.
