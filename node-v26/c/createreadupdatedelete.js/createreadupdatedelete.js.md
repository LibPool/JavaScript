# createreadupdatedelete.js

> 标签: activerecord, crud, orm, websql

## 简介

Simple ORM/ActiveRecord for WebSQL that covers 90% of use cases. Supports 1:1, 1:many and many:many relations, indexes, fixtures and migrations.
