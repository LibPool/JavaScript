# cloud-resource-logger

> 标签: aws, cli, dynamodb, ec2, ecs, eks, iam, lambda, logger, rds, resource, s3

## 简介

CLI tool for listing AWS resources such as EC2 instances, S3 buckets, Lambda functions, and DynamoDB tables.
