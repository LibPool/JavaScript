> 标签: absolute, clean, clean-stack, cleanstack, cwd, mapper, paths, plugin, process, relative, relative-paths, relatives, stack, stacktrace, trace, utils, working

## 简介

Meant to be used with [clean-stacktrace][] as mapper function. Makes absolute paths inside stack traces to relative paths.
