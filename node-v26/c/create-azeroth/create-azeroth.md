# create-azeroth

> 标签: azerothjs, create, fullstack, scaffold, starter, template

## 简介

Scaffold an AzerothJS app - frontend, backend, or fullstack - with the framework's canon wired in: azeroth CLI verbs, eslint rules, typecheck gate, and a working dev loop. Run `npm create azeroth@latest`
