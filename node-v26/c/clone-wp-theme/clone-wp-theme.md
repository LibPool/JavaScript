# clone-wp-theme

> 标签: Flynt, Sage Vite, Wordpress Theme, sage, theme, vite, wordpress

## 简介

A CLI tool for creating WordPress themes (Flynt as well as Sage-Vite  ) by selecting from predefined templates and cloning repositories.
