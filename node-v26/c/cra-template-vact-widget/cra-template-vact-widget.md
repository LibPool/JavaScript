# cra-template-vact-widget

> 标签: JavaScript

## 简介

在终端中，cd到指定目录，该目录存放二次开发控件。例： ```shell D:\\vact-widgets ``` ## 使用命令创建控件模板 在终端中使用命令创建模板，命令如下： ```shell npx create-react-app jgtest --template vact-widget ``` 待命令执行完成后，即在D:\\vact-widgets目录下创建了一个jgtest的vact控件。 请参考目录中README.md文件，完成控件开发和部署。
