# coras-mcp

> 标签: ai, claude, coras, diagram, mcp, model-context-protocol, risk-analysis, security, threat-modeling, threat-modelling

## 简介

MCP server that turns a description in plain language into a CORAS risk or threat diagram, in the file format of the SINTEF Threat Modelling Tool (which it ships with).
