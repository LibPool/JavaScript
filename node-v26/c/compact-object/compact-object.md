# compact-object

> 标签: array, arrays, empty, find, has, hasOwn, key, keys, nested, object, omit, properties, property, recurse, recursive, recursively, value

## 简介

Similar to omit-empty, recursively omits empty properties, but also compacts/flattens nested arrays in an object.
