# create-microservices-app

> 标签: b2b-saas, boilerplate, cloudflare, cloudflare-d1, cloudflare-saas, cloudflare-workers, create-app, d1, edge, edge-saas, fullstack, hono, microservices, multi-tenant, saas, saas-boilerplate, saas-starter, saas-template, scaffold, sveltekit, sveltekit-saas, workers, workers-saas

## 简介

Scaffold a Cloudflare-native SaaS app in one command — Workers, D1, SvelteKit or Hono, with verified auth, booking, payment & email modules.
