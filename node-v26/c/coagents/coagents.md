# coagents

> 标签: agents, claude-code, codex, collaboration, kanban, mcp, model-context-protocol

## 简介

CoAgents Connector: connect Claude Code or Codex to a self-hosted CoAgents team service over MCP (tasks, leases, handoffs, artifacts, search).
