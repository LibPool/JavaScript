> 标签: agent, claude-code, coauthr, codex, gemini, kurcz, review

## 简介

Sign in your terminal to Coauthr (coauthr.co) — the collaborative artifact for Claude Code and other agents. Installs the coauthr skill for Claude Code, Codex, Gemini and any agent that reads ~/.agents/skills.
