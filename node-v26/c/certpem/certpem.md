# certpem

> 标签: altnames, asn1, cert, cert.pem, certificate, expired, expires, expiresAt, issued, issuedAt, notAfter, notBefore, subject, x509

## 简介

Read basic info (subject, altnames, expiresAt, issuedAt) from a cert.pem / x509 certificate (tls / ssl / https)
