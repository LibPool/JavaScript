# carryforward

> 标签: agent-memory, agents, claude-code, context-engineering, cursor, evaluation-model, jev, mcp, mcp-server, memory, model-context-protocol, session, typesafe, typesafe-ai, vercel-ai-gateway

## 简介

MCP server that carries what one session learned into the next. A per-project ledger written as things happen, scored per task by TypeSafe's Jev evaluation model via the Vercel AI Gateway.
