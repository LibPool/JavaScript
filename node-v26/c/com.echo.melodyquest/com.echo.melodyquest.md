# com.echo.melodyquest

> 标签: echo, event, melodyquest, mission

## 简介

Daily Mission & Check-in event module for Echo games. Players complete missions to earn Sound Waves that fill stage chests, progressing toward a Grand Prize. Supports duration and weekly-schedule modes, auto/manual start, pluggable mission-type evaluators
