> 标签: ai-agent, claude, claude-code, claude-code-hooks, database, guardrails, hooks, pre-commit, safety, seatbelt, secret-scanning, yolo

## 简介

Run Claude Code in --dangerously-skip-permissions (YOLO) mode safely: block irreversible database deletes and secret commits before they happen.
