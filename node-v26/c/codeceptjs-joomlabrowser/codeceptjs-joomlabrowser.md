# codeceptjs-joomlabrowser

> 标签: codeceptJS, codeceptjs, codeceptjs-joomlabrowser, joomlaBrowser

## 简介

Joomla Browser Helper in CodeceptJS for Joomla Developers to write their system e2e tests in CodeceptJS, supports WebdriverIO, Puppeteer, Appium
