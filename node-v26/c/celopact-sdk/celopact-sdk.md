> 标签: agent-commerce, ai-agents, celo, celopact, erc-8004, escrow, milestone, stablecoin, web3

## 简介

Milestone-based escrow SDK for AI agent-to-agent commerce on Celo. ERC-8004 identity, optimistic release, dispute resolution.
