# claude-code-token-tracker

> 标签: anthropic, api-usage, claude, claude-code, cli, statusline, token

## 简介

A TUI display of the percentage of your 5hr and 7d window you've used up, and represents it as 2 bars at the bottom of your terminal, and has a money tracker if you use Claude Code on an API credit based plan
