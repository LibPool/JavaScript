# crc-strava-mcp

> 标签: ciclismo, cycling, ftp, mcp, potencia, strava, training, tss, vo2max

## 简介

Servidor MCP para Strava con capa analitica determinista (CRC): NP, IF, TSS, curvas de potencia, desacople, zonas y VO2max estimado.
