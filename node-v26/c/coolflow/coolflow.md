# coolflow

> 标签: claude-code, code-review, frontend, skills, workflow

## 简介

团队 AI 前端工作流：强制流程 + 自动检索技能 + 知识沉淀闭环。npm 全局安装后 coolflow init 写入 ~/.claude，所有项目生效。
