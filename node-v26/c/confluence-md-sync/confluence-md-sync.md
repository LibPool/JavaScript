# confluence-md-sync

> 标签: atlassian, confluence, docs-as-code, macros, markdown, publish, storage-format, sync

## 简介

Publish Markdown to Confluence (Data Center & Cloud): idempotent page sync, attachment dedup, tables and a pluggable macro system
