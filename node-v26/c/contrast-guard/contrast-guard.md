# contrast-guard

> 标签: a11y, accessibility, ci, color, computed-style, contrast, design-review, design-system, design-tokens, oklch, theme, ui-audit, visual-regression, wcag

## 简介

配色与视觉的双层护栏：check 静态查对比度（零依赖，反推该改成多少），measure 渲染后查视觉程度（字号集中度/灰阶层数/动效覆盖率）
