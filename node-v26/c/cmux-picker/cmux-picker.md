# cmux-picker

> 标签: ai, chrome-extension, claude-code, cmux, coding-agent, devtools, dom, element-picker, native-messaging

## 简介

Pick a DOM element on any page in Chrome and send it, with a prompt, to a coding agent running in cmux.
