# cordova-md-nfc

> 标签: cordova, cordova-android, cordova-blackberry10, cordova-windows, cordova-wp8, ecosystem:cordova, ndef, nfc

## 简介

Near Field Communication (NFC) Plugin. Read and write NDEF messages to NFC tags and share NDEF messages with peers.
