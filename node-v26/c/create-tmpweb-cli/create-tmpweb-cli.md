# create-tmpweb-cli

> 标签: JavaScript

## 简介

1. 新建一个空文件夹为应用根目录 2. 使用pnpm初始化，pnpm init 3. 安装脚手架，pnpm add create-tmpweb-cli， 4. 执行安装命令，npx create-tmpweb-cli，输入应用名，等待安装 5. 运行应用，pnpm run dev
