# cordova-device-information-plugin

> 标签: account details, android, cordova-android, device information, ecosystem:cordova, phone number, telephony manager

## 简介

AKA DeviceInformation Plugin, this plugin will get most of the information available through Android's Telephony Manager and Account Manager classes. Adapted for npm
