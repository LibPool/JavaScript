# casecraft

> 标签: camelcase, camelcase-snake-case, case-conversion, case-utils, dotcase, human-readable, javascript-utilities, js-utils, kebabcase, lowercase, mixedcase, nospaces, pascal-case, pascalcase, pathcase, reverse-case, screaming-kebab-case, screaming-snake-case, slugcase, snakecase, spongebob-case, string-conversion, title-case, train-case, uppercase

## 简介

A lightweight utility for converting strings between common naming conventions like camelCase, PascalCase, snake_case, kebab-case, and dot.case.
