# cs-pdf-signature-viewer

> 标签: firma, pdf, pdfjs, signature, vue

## 简介

Visualizador de PDF en Vue 3 que permite posicionar (arrastrar/redimensionar) una firma simulada sobre el documento para previsualizar dónde quedaría.
