# crmcare

> 标签: account-engagement, agents, campaign, campaign-as-code, cli, crm.care, hubspot, json-schema, marketing, mcp, spec, yaml

## 简介

The crm.care campaign spec (campaign/0.1): the schema and types, a typed builder, a client for the REST twin, and the crmcare CLI — validate, plan, import, export and apply a campaign as a file.
