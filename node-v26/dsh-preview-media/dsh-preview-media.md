# dsh-preview-media

> 标签: audio, deepseek-harness, dsh, dsh-plugin, media, preview, video

## 简介

Video and audio preview for DeepSeek Harness: play mp4/mov/mkv/webm and mp3/flac/wav in the right-Sidebar document preview, streamed over an authenticated HTTP Range route (plus a loopback origin so the desktop app can seek) without loading the whole file
