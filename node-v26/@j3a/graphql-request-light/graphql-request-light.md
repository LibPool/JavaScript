# @j3a/graphql-request-light

> 标签: apollo, fetch, graphql, graphql-client, request

## 简介

> **_NOTE:_**  This is pretty much the same as [graphql-request](https://github.com/jasonkuhrt/graphql-request) except: > - There is no runtime dependency on `graphql`. This can reduce your bundle by nearly 200k (parsed) > - In exchange, documents passed
