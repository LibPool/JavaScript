# @arcora/agent-commerce

> 标签: ai-agent, arcorapay, crosschain, mcp, payments, stablecoin, usdc

## 简介

One command to turn an AI agent into an Arcorapay merchant, plus an MCP server it serves — sell from a catalog and invoice in USDC, payable cross-chain from Base.
