# @johardi/stepback

> 标签: agent-output, annotation, claude-code, codex, coding-agent, hooks, review, second-screen, sub-agent

## 简介

Review coding agent responses in your browser, ask a read-only sub-agent about a snippet, and send back only the conclusions you choose.
