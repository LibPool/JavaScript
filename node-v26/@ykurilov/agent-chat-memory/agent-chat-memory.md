# @ykurilov/agent-chat-memory

> 标签: JavaScript

## 简介

Долгая память агента: заметки о человеке и его правила («отвечай на ты», «не предлагай npm») переживают чаты. Агент сам решает, что запомнить, по ходу разговора; человек видит записи на экране памяти и правит их. Отдельное расширение: приложению, которому
