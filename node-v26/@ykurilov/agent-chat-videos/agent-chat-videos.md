# @ykurilov/agent-chat-videos

> 标签: JavaScript

## 简介

Видео от агента: инструменты `find_videos` и `show_video` поверх каталога приложения (YouTube и Kinescope), карточка с плеером в ленте. Отдельное расширение: приложению без видео пакет не нужен.
