# @theseus.run/jsx-md-beautiful-mermaid

> 标签: agents, ascii, beautiful-mermaid, diagrams, jsx, llm, markdown, mermaid, tsx

## 简介

Mermaid component for @theseus.run/jsx-md. Renders diagrams as ASCII art via beautiful-mermaid — for terminals, LLM prompts, and anywhere SVG doesn't go.
