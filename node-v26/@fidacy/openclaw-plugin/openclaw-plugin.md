# @fidacy/openclaw-plugin

> 标签: ed25519, fidacy, firewall, mandate, openclaw, openclaw-plugin, payments, trust, verdict

## 简介

The AI Agent Firewall for OpenClaw. Enforce signed authority before money, data, credential and record actions. Free account-owned API key required.
