# @samebits/dsh-web-search-openrouter

> 标签: citations, deepseek-harness, dsh, dsh-plugin, grounding, openrouter, responses-api, server-tools, web-search, web_search

## 简介

Grounded web search for DeepSeek Harness through OpenRouter-compatible gateways: the built-in web_search tool runs on the same endpoint and key as your chat models, returns citeable sources, and is configurable from the Plugins settings page.
