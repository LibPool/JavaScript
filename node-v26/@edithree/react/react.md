# @edithree/react

> 标签: animation, blendspace, drei, edithree, r3f, react-three-fiber, three

## 简介

React Three Fiber bindings for edithree: <AnimatedCharacter>, useAnimController and a movement-signal bridge for driving blendspaces from a character controller or NPC.
