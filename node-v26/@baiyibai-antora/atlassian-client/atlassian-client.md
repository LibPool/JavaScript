# @baiyibai-antora/atlassian-client

> 标签: atlassian, client, confluence, confluora, jira, rest

## 简介

Minimal zero-dependency Atlassian Cloud REST client (basic auth, JSON, multipart, v2 cursor pagination) shared by the Confluora packages
