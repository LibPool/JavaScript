# @archi-code/criteria-adapters

> 标签: DDD, browser, criteria, in-memory, indexeddb, mongodb, node, repository, search

## 简介

Runs `@archi-code/criteria` searches on a storage engine. Each adapter is its own entry point, so an application loads only the one it uses and the adapters never depend on each other's code:
