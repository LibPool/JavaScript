# @glowitd/ui

> 标签: accessibility, component-library, dark-mode, design-system, nextjs, radix-ui, react, shadcn, tailwindcss, typescript

## 简介

An open-source design system and component library for Next.js App Router apps, built on Tailwind CSS and shadcn/ui.
