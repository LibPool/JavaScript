# @univerxyz/dsh-dsov-plugin

> 标签: deepseek, dsh, dsh-plugin, overview, ui, usage, web

## 简介

DSH Web GUI plugin: first-position 【概览】tab in the right panel (context window / session metrics with active-only 1s runtime / per-model usage & cost analysis) plus a settings entry 【DeepSeek 开放平台】that opens platform.deepseek.com. Web profile only, theme-a
