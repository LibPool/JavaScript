# @hiveku-apps/sync

> 标签: claude, claude-code, cli, codex, hiveku, mcp, olympus

## 简介

Sync a Hiveku account's memory/rules/skills + coder projects into a local folder, and ship projects (push/deploy/pull-env) from the terminal. Pairs with the Hiveku MCP at core.hiveku.com/mcp so Claude Code can drive Hiveku tools per-folder.
