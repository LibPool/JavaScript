# @banbolee/dsh-rtk

> 标签: bundle, dsh, plugin, rtk, shell

## 简介

General-purpose RTK integration for DeepSeek Harness: a plain function plugin that decorates the mounted shell executor's `execute` entry point through `rtk rewrite` and compresses model-facing grep output through `rtk pipe`. Decorates the live `ctx.shell
