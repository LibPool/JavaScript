# @gramota/holder

> 标签: eudi, holder, oid4vci, oid4vp, sd-jwt-vc, verifiable-credentials, wallet

## 简介

Headless EUDIW holder/wallet — receive credentials, store them, build presentations. Pure Node, no UI, IETF SD-JWT-VC §6 compliant.
