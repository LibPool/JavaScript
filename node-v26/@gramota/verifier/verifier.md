# @gramota/verifier

> 标签: eidas, eudi, oid4vp, relying-party, sd-jwt-vc, verifiable-credentials, verifier

## 简介

Relying-party verifier for the EU Digital Identity Wallet. One client, one method, full IETF SD-JWT-VC + KB-JWT spec compliance.
