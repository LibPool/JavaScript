# dsh-ipynb-preview

> 标签: deepseek-harness, dsh, dsh-plugin, ipynb, jupyter, katex, notebook

## 简介

Render Jupyter .ipynb notebooks in the DSH document preview, with syntax highlighting, LaTeX math, and zoomable figures, instead of showing raw JSON
