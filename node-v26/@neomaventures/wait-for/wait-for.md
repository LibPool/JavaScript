# @neomaventures/wait-for

> 标签: docker-compose, healthcheck, http, readiness, tcp, testing, typescript, wait

## 简介

Wait for a TCP port or HTTP endpoint to accept traffic. Host-side readiness polling for tests, with no agent inside the target.
