# @lucasngucii/argus

> 标签: agent, ai, claude-code, cli, gate, guardrail, mcp, permission, security

## 简介

A local-first governance and observability gate for AI coding agents: classify each shell command, file write, and MCP tool call by severity and allow/ask/deny it.
