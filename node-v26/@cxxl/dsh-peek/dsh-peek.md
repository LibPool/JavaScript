# @cxxl/dsh-peek

> 标签: artifact, deepseek-harness, dsh-plugin, file, html, image, markdown, preview

## 简介

DSH Web 内嵌文件预览：点击对话里本轮生成的产物文件（HTML / SVG / Markdown / 图片 / PDF / 代码 / CSV / 字体等）就地预览，不另开浏览器标签、也不用在本地打开文件。
