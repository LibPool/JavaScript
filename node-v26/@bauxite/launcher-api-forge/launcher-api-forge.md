# @bauxite/launcher-api-forge

> 标签: JavaScript

## 简介

> Provides high-level API for managing Forge Minecraft client instances. > Works as a plugin for `launcher-api`. > Designed to be consumed by `launcher-ui` and `launcher-cli`.
