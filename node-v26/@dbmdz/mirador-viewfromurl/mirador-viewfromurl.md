# @dbmdz/mirador-viewfromurl

> 标签: iiif, mirador

## 简介

Modifies Mirador to dynamically update the URL to reflect the currently selected view type (image, book, etc), manifest and canvas and to reconstruct a Mirador session from such an URL hash.
