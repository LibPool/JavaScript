# @sbissoli/mcp-provenance

> 标签: attribution, data-provenance, mcp, open-data, provenance

## 简介

Contrato de proveniência para servidores MCP: todo retorno de tool carrega fonte, endpoint, período, data de extração e licença, em dois modos (concise/detailed), com serialização determinística
