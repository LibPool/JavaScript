# @open-neko/plugin-magic-link

> 标签: JavaScript

## 简介

Passwordless email sign-in for OpenNeko. Implements the auth contract with manual provisioning: an admin creates each user (email and role) in OpenNeko first, and only those users can request a single-use, HMAC-signed sign-in link. Holding a mailbox never
