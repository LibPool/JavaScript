# @neosmithai/cli

> 标签: anthropic, claude, claude-code, cline, codex, continue, jetbrains, junie, llm, neosmith, openai, openclaw, opencode, router

## 简介

Route AI coding agents (Claude Code, Codex, Continue, Cline, OpenCode, OpenClaw, Junie CLI, JetBrains AI) through the NeoSmith router — same experience, ~60% lower inference cost.
