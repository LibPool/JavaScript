# @vdegenne/material-color-helpers

> 标签: JavaScript

## 简介

- Provides `applyThemeString` and `applyTheme`. - Provides `themeFromSourceColor`(through `@vdegenne/material-color-helpers/material.js`) which can be used to supply a theme object to `applyTheme`.
