# @alimzen/relayo-nestjs

> 标签: bounces, email, nestjs, relayo, sms, webhooks

## 简介

NestJS module for Relayo: RelayoModule, an injectable RelayoService, @OnRelayoEvent handlers and an optional webhook controller.
