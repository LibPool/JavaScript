# @c0dingbear/termius-vault

> 标签: decrypt, export, indexeddb, ssh, termius, vault

## 简介

Read the Termius local vault: decrypt the IndexedDB store and reconstruct the complete saved-host list (address, port, identity, key, connect-chain) from Termius' normalized model — including hosts never connected to.
