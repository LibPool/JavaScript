# @hermesihq/node

> 标签: express, hermesi, nextjs, notifications, sdk, server

## 简介

Server-side client for Hermesi: publish events and read what became of them, keep subscribers in sync, send a direct message, mint subscriber tokens and preference links. No dependencies; Node 20 and later.
