# @mooncellwiki/prts-design-vue

> 标签: JavaScript

## 简介

PRTS Design 的 Vue 3 实现：输出与 CSS 实现相同的 .ak-* 结构，自带状态、键盘与可访问性；不带样式——prts.wiki 上由皮肤 / skins.arknights.components 模块提供，站外用 @mooncellwiki/prts-design-css
