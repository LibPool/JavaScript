# @a1exk-dev/ctui

> 标签: claude-code, mod, plugin, sidebar, tui

## 简介

A mod for Claude Code: a docked sidebar with git, context, limits, todo, skills, MCP and agent sections, plus agent and shell toasts and a /ctui settings menu for plugins and themes.
