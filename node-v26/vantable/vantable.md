# vantable

> 标签: accessibility, accordion, aria, bulk-actions, column-filters, column-resize, csv, dark-mode, dashboard, data-table, datatable, export, filter, grid, i18n, no-dependencies, pagination, pdf, responsive, row-selection, search, sorting, sticky-header, table, typescript, vanilla, vanilla-js, virtual-scroll, virtualization, wai-aria, xlsx, zero-dependency

## 简介

Zero-dependency vanilla-JS data table for dashboards: client & server pagination, sorting, search, rich column types (links, copy, status, tags, images), inline & modal editing, row actions, accordion master/detail rows, CSV export (XLSX/PDF via adapters)
