# @upgather/sdk

> 标签: JavaScript

## 简介

The core Upgather SDK: a typed HTTP/API client for talking to Upgather backends (Strapi and the Upgather platform), with pluggable auth, resilient error handling, request interceptors, backend adapters, and higher-level services.
