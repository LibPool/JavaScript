# @vitral/chat

> 标签: ai, assistant, chat, chatbot, copilot, vitral

## 简介

Framework-free chat for Vitral: the engine (messages, grouping, streaming, the composer) and a DOM renderer with roving focus and live announcements, which the Vue, React and Angular components wrap.
