# @vitral/taskboard

> 标签: board, drag-and-drop, kanban, taskboard, vitral

## 简介

Framework-free task board for Vitral: the engine (columns, lanes, moves, limits) and a DOM renderer with accessible drag and drop, which the Vue, React and Angular components wrap.

- 源码仓库：git+https://github.com/vitralui/vitral.git
- npm 页面：https://www.npmjs.com/package/@vitral/taskboard
