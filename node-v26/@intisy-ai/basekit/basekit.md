# @intisy-ai/basekit

> 标签: accounts, ai-proxy, basekit, canonical-ir, config, intisy-ai, loader, oauth, routing

## 简介

The shared foundation of the intisy-ai AI-proxy ecosystem: config, logging and app detection, canonical IR, provider accounts, the routing engine, and the app-loader engine, as one package with a subpath per module.
