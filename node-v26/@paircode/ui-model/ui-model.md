# @paircode/ui-model

> 标签: paircode

## 简介

3D/CAD 面板：3D 预览（iframe srcdoc 挂自包含 WebGL 预览，可拖拽旋转/缩放/线框）/ 部件表（类型·面数·体积·尺寸·材质）/ 参数与驱动 / 9 项判据 / 产物清单（数据来自 tool-model 的 model.json、model.preview.html、model.verify.json）
