# @rhizogrip/spore

> 标签: agents-sdk, ai-agents, ai-agents-framework, linux-app, llm-agents, rust, self-hosted

## 简介

A runtime for AI agents you run on your own Linux machines: kernel-confined, spend-limited, recorded, and driven from Node, the command line or HTTP.
