# @dsh-plugins/dsh-llm-hub

> 标签: agy, api-keys, balance, claude, codex, cost, dashboard, deepseek, deepseek-harness, dsh, dsh-plugin, failover, harness, key-rotation, model-discovery, quota, rate-limit, routing, subagent, tokens, usage

## 简介

DSH 模型管理层：网关可达性探测、模型目录拉取、DeepSeek + MiniMax/智谱/Moonshot/StepFun 余额与配额、本月用量统计、余额预警、Provider 健康看板，再把本机装好的 codex / claude / agy 注册成子代理（装了才出现）。零运行时依赖，不改动 DSH 安装。
