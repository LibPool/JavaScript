# @o3co/auth-provider-second-factor

> 标签: 2fa, authorization-server, identity-provider, mfa, nodejs, oauth2, oidc, openid-connect, self-hosted, totp, typescript

## 简介

Multi-factor authentication for auth-provider, a self-hosted OAuth 2.0 authorization server and OpenID Connect provider for Node.js: TOTP, codes sent by mail, recovery codes and their management.
