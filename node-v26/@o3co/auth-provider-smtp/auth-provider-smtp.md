# @o3co/auth-provider-smtp

> 标签: authorization-server, email, identity-provider, nodejs, oauth2, oidc, openid-connect, self-hosted, smtp, typescript

## 简介

SMTP mail sender for auth-provider, a self-hosted OAuth 2.0 authorization server and OpenID Connect provider for Node.js.
