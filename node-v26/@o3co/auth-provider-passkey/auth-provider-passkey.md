# @o3co/auth-provider-passkey

> 标签: authorization-server, identity-provider, mfa, nodejs, oauth2, oidc, openid-connect, passkey, passwordless, self-hosted, typescript, webauthn

## 简介

Passkeys and WebAuthn for auth-provider, a self-hosted OAuth 2.0 authorization server and OpenID Connect provider for Node.js: passkey registration, passwordless login and WebAuthn as a second factor.
