# rielpay

> 标签: aba, bakong, cambodia, khqr, payment, payment-gateway, payway, qr, rielpay

## 简介

Official Node.js SDK for RielPay — accept KHQR payments from every bank in Cambodia (ABA, ACLEDA, Wing, Bakong).

## 官网

- 官网：https://rielpays.com/docs#sdk-node
- 源码仓库：git+https://github.com/sarundev/rielpay-node.git
- npm 页面：https://www.npmjs.com/package/rielpay
