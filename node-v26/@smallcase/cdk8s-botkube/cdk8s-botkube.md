# @smallcase/cdk8s-botkube

> 标签: cdk

## 简介

`cdk8s-botkube` is an open-source construct library for cdk8s to deploy a configurable instance of BotKube to your Kubernetes cluster. BotKube is a messaging bot for monitoring and debugging Kubernetes clusters. You provide the configuration for BotKube,
