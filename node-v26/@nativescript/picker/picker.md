# @nativescript/picker

> 标签: Android, JavaScript, NativeScript, TypeScript, iOS

## 简介

A NativeScript plugin that provides a custom TextField which lets you pick a value from a list opened in a modal popup.

- 官网：https://github.com/NativeScript/plugins
- 源码仓库：git+https://github.com/NativeScript/plugins.git
