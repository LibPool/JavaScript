# @omdp/dsh-archived-sessions

> 标签: archived-sessions, deepseek-harness, dsh, dsh-plugin, session-management

## 简介

Archived-sessions manager for the DeepSeek Harness web UI: list / unarchive / delete / detail from Settings. · DSH 归档会话管理：设置页查看、释放、删除已归档会话（含按树删除子会话与孤儿清理）。
