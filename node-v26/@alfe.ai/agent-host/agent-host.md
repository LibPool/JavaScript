# @alfe.ai/agent-host

> 标签: agent, ai-agents, alfe, bridge, chat, codex, gemini, grok, llm

## 简介

Chat bridge that makes a terminal-agent runtime (Codex, Gemini CLI and Grok Build today) reachable from Alfe chat, on the agent's provider key, the local CLI login, or Alfe AI credits
