# @noy-db/ui-suai

> 标签: data-table, noy-db, nuxt, nuxt-module, schema-driven, suai, vue

## 简介

Flagship rendering fork of @noy-db/ui for Nuxt: schema-driven list + detail components with full multi-palette theming, progressively adopting SUAI components. Domain-free; consumes collection.describe().
