# @noy-db/in-liff

> 标签: deep-link, in-liff, liff, line, line-login, noy-db

## 简介

LIFF (LINE Front-end Framework) shell binding for noy-db — boot + shell context detection across LIFF/browser/PWA, LINE ID-token lifecycle with re-login on expiry, share-link deep-link ingestion, and the external-browser escape hatch with the platform han
