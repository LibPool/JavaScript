# @cognitiveproof/webauthn-prf-identity

> 标签: c2pa, did, ed25519, prf, webauthn

## 简介

Derive a per-profile Ed25519 identity key in the browser from a WebAuthn PRF extension output, and compute the did:jwk issuer identifier expected by c2pa-rs-javascript-library's ICA signing path.
