# @iamfj/n8n-nodes-paperless-ngx

> 标签: dms, document-management, n8n-community-node-package, ocr, paperless, paperless-ngx

## 简介

n8n community node to automate Paperless-ngx document management: consume documents, correspondents, tags, document types and storage paths from your Paperless-ngx instance.
