# @wenbin_wb/dsh-bridge

> 标签: bot, cloudflare, deepseek-harness, dsh, dsh-plugin, feishu, mobile, qq, qr-code, qrcode, remote, remote-access, smartphone, tablet, telegram, tunnel, websocket, wechat

## 简介

手机扫码即可在移动端/公网继续用 DeepSeek Harness，人不在电脑前也能接着干。一键局域网二维码、Cloudflare 公网隧道、自建隧道与微信 / QQ / 飞书 / Telegram Bot（多工作区/会话持久化/媒体/卡片审批/流式输出），无需自己搭公网服务器。
