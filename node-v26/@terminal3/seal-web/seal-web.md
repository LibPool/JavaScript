# @terminal3/seal-web

> 标签: jwe, passkey, t3n, web-components, webcrypto

## 简介

T3n sealed delivery in the browser - open items sealed to a device-bound key, and fill signed forms whose answers only their named recipients can read, with no runtime dependencies
