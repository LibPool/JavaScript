# @typetorch/framework

> 标签: dependency-injection, hot-reload, hot-swap, rbxts, roblox, roblox-ts, typetorch

## 简介

TypeTorch framework for roblox-ts: hot-swappable modules (dependency injection, lifecycle, troves), guarded networking, hot assets and the in-game dev menu. Ships inside every TypeTorch artifact.
