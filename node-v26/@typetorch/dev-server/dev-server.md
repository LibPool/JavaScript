# @typetorch/dev-server

> 标签: claude, claude-code, cloudflare-tunnel, dev-server, roblox, roblox-ts, typetorch

## 简介

TypeTorch remote-claude: lets allowlisted devs prompt Claude Code on your machine from inside a live Roblox dev server, behind a Cloudflare Quick Tunnel with JWT auth.
