# @magicteams_ai/agentprofile

> 标签: agent-memory, ai-agents, claude-code, cursor, mcp, skills

## 简介

Your agent's identity, everywhere. One profile — skills, credentials, memory — synced to every agent tool. Run `npx agentprofile` to connect all your tools in under a minute.
