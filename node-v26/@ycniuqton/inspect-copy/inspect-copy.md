# @ycniuqton/inspect-copy

> 标签: ai, alt-click, clipboard, component, cursor, debug, devtools, fiber, inspector, react, vue

## 简介

Zero-config Alt+click component inspector for React & Vue 3. Hover to outline, click to copy a describable component handle (name + ancestor breadcrumb + text) to your clipboard — built for pasting into AI coding tools, issues, and chat. No Babel/SWC/Vite
