# s3m-maplibre

> 标签: 3d-tiles, bim, gis, iserver, mapbox, mapbox-gl, maplibre, maplibre-gl, photogrammetry, s3m, s3mb, supermap, three, webgl

## 简介

SuperMap S3M 三维模型格式的 MapLibre / Mapbox 原生渲染图层：浏览器内直接解析 .s3mb 瓦片，无需转 3D Tiles，支持多数据集叠加、白膜/按高度/按单体/动态扫描着色、单体级 GPU 拾取与属性查询。
