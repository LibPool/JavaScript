# @elisym/wallet

> 标签: ai-agents, elisym, keypair, mcp, payments, solana, spl-token, usdc, wallet, web3

## 简介

Wallet library for AI agents - hard spend limits, transfer policies, two-step agent tools, and an MCP server mode. Solana first: SOL + SPL transfers, encrypted key storage
