# @better-iam/nuxt

> 标签: abac, access-control, authentication, authorization, iam, multi-tenant, nitro, nuxt, nuxt-module, rbac, typescript, vue

## 简介

Nuxt module for Better IAM: the IAM API in Nitro, server-rendered sessions, page guards with definePageMeta, and auto-imported composables.
