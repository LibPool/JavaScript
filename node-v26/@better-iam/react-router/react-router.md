# @better-iam/react-router

> 标签: abac, access-control, authentication, authorization, iam, multi-tenant, rbac, react, react-router, remix, typescript

## 简介

React Router framework-mode integration for Better IAM: root middleware, guarded loaders and actions, and an IAM API resource route.
