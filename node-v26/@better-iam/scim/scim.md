# @better-iam/scim

> 标签: abac, access-control, authentication, authorization, iam, multi-tenant, provisioning, rbac, rfc7644, scim, scim2, typescript, user-provisioning

## 简介

SCIM 2.0 provisioning for Better IAM: connection-scoped Users and Groups endpoints with RFC 7644 filters, PATCH, Bulk, and ETags.
