# @codestrategie/a11y-widget

> 标签: a11y, accessibility, accessibility-widget, custom-element, lit, wcag, web-component

## 简介

Framework-agnostic accessibility widget as a web component (Lit): text size, contrast, read aloud, reading mask, page structure and more – fully themeable, no tracking.
