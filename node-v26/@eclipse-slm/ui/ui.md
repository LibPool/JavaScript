## 简介

- Install Nodejs from [Nodejs Official Page](https://nodejs.org/en/) - Open the terminal and navigate to the project - Run `npm install` or `yarn install` if you use [Yarn](https://yarnpkg.com/en/) - Run `npm run dev` or `yarn serve` to start a local deve
