# @kidlab/dsh-kid-process

> 标签: dsh, dsh-plugin, kid, process

## 简介

给小朋友的进程启蒙插件：一个包 = 一张 🐝 工人点名卡片 + 四个模型工具（proc_count / proc_busiest / proc_family / proc_badge），零第三方依赖、无构建步骤。
