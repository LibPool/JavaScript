# @kanonak-protocol/canonical

> 标签: canonical-form, content-address, kanonak, sdk, sha256

## 简介

The Kanonak canonical form + content hash (canonicalFormVersion "1") — the TypeScript port of kanonak.org/canonical-form, verified byte-for-byte against the shared golden vectors. The identity primitive every generated SDK content-addresses through.
