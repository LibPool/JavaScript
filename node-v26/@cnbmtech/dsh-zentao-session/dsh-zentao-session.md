# @cnbmtech/dsh-zentao-session

> 标签: cordis, deepseek-harness, dsh-bundle, dsh-plugin, zentao, 禅道

## 简介

ZenTao (禅道) session-based tools and panel for DeepSeek Harness: my bugs, tasks and stories across browse scopes, bug confirm/resolve, remark post and remark edit, plus drag-to-chat Markdown references. Works with legacy ZenTao versions that lack REST API
