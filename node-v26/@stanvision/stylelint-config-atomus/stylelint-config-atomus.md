# @stanvision/stylelint-config-atomus

> 标签: ai-agents, atomus, css, design-system, design-tokens, stylelint, stylelint-config, stylelint-plugin

## 简介

Stylelint config and rules for the Atomus design system: no raw colours outside token definitions, no primitive tokens in component CSS, and colour, radius and spacing values from var(--…) tokens.
