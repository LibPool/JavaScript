# @wishcbg/bobcode

> 标签: bob, taiwan

## 简介

基於店家同步功能的需求，讓店家能夠在不同的店家之間同步各項功能設定，並且能夠檢視各項功能的異動情況。 規劃出一套店家設定即程式碼的機制，讓店家能夠以 config file (.sac) 來定義各項功能設定，並且能夠還原店家各項功能設定。 暫且稱這個機制為「Settings as Code」「店家設定即程式碼」。
