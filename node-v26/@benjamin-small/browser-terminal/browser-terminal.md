# @benjamin-small/browser-terminal

> 标签: pipeline, repl, rust, shell, structured-data, terminal, tmux, wasm, webassembly, xterm

## 简介

A terminal/tmux experience for any web page, powered by a Rust/WASM core with structured-value pipes.
