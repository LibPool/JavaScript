# dsh-commandcode-quota

> 标签: balance, command-code, commandcode, deepseek-harness, dsh, dsh-plugin, quota, status-bar, usage

## 简介

Command Code balance and quota panel for DeepSeek Harness: a status row under the composer showing balance and the 5-hour, weekly and monthly windows.
