# @ahoo-wang/wow-generator

> 标签: api, client, codegen, cqrs, ddd, fetch, generator, http, openapi, openapi3, rest, swagger, typescript, wow, wow-generator

## 简介

Generates TypeScript models, Fetcher decorator clients and Wow command and query clients from a local or remote OpenAPI 3 document. The Wow clients follow the CQRS model of the Wow DDD framework (https://github.com/Ahoo-Wang/Wow).
