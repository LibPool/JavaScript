# @nifrajs/edge

> 标签: bun, cloudflare-workers, deno-deploy, edge, fetch, nifra, router, serverless, typescript, vercel-edge

## 简介

Compact fetch-handler server for edge and serverless runtimes (Cloudflare Workers, Vercel Edge, Deno Deploy, Bun). Keeps the server().get().post() DX and the full request trust boundary - bounded body read, Content-Length pre-reject, prototype-pollution g
