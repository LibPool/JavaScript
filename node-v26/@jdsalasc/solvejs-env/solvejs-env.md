# @jdsalasc/solvejs-env

> 标签: env parser, env validator, environment variables, javascript env utilities, solvejs, typed env, typescript env utilities, zero dependency

## 简介

Typed TypeScript environment variable parsing for strings, numbers, booleans, enums, arrays, JSON, URLs, DSNs, and required config checks.
