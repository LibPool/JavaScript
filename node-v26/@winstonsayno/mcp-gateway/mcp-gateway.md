# @winstonsayno/mcp-gateway

> 标签: ai, ai-agents, claude, deepseek, developer-tools, function-calling, gateway, grok, llm, mcp, model-context-protocol, observability, openai, proxy, typescript

## 简介

MCP gateway for AI models (OpenAI, Grok, DeepSeek, Claude and other function-calling LLMs) and for web pages and apps: one authenticated, observable endpoint in front of your MCP servers with routing, scopes, rate limits and metrics.
