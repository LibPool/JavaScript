# @dittli/tts-core

> 标签: browser, lightweight, offline-tts, onnx, onnxruntime-web, speech-synthesis, text-to-speech, tts, webassembly

## 简介

DittliTTS inference engine for the browser — ONNX Runtime Web. Install a language pack (@dittli/tts-en, @dittli/tts-de) alongside this to synthesise speech.
