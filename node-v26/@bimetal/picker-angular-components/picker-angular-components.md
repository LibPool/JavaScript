# @bimetal/picker-angular-components

> 标签: angular, autocomplete, combobox, components, multi-select, picker

## 简介

Angular picker / combobox — single/multi select, type-to-filter, chips, keyboard, theming. A thin standalone-component binding over the canonical picker controller (owned controller OR options/config).
