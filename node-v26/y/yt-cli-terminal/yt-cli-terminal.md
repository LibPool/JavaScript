# yt-cli-terminal

> 标签: cli, mpv, music, terminal, tui, video, youtube, yt-dlp

## 简介

Cyberpunk terminal YouTube video player (ytplayer) and music player (ytmusic). Installs prebuilt binaries from GitHub releases.
