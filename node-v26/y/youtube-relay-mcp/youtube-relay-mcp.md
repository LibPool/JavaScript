# youtube-relay-mcp

> 标签: agent, claude, cli, code-execution, mcp, search, transcript, youtube

## 简介

Code-execution-based YouTube tool — CLI (ytrelay) + MCP shim + Claude Code skill. Search YouTube, fetch transcript/title/description, get an embeddable video ID.
