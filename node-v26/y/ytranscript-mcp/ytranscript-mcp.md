# ytranscript-mcp

> 标签: captions, claude, cursor, mcp, mcp-server, model-context-protocol, subtitles, transcript, whisper, youtube, youtube transcript

## 简介

MCP server for YouTube transcripts. Works from any cloud, no proxies. Transcribes videos without captions. Built on the yTranscript API.
