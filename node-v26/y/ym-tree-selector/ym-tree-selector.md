# ym-tree-selector

> 标签: JavaScript

## 简介

`YmTreeSelector` 是一个基于 Vue 3 和 Element Plus 的树形选择器组件，支持多选和单选模式，适用于需要从树形结构数据（支持10W+数据）中进行选择的场景。
