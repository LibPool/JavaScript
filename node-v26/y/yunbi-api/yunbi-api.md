# yunbi-api

> 标签: JavaScript

## 简介

Open source developed Nodejs API for the exchange market www.yunbi.com  - This allow user to connect to public(unauthenticated) and private(authenticated) apis to view prices, check balance and trade from the module. - Include most of Yunbi API except f
