# yzhanimageviewer

> 标签: Image, Picture, Viewer, jQuery, 微信朋友圈, 插件, 看图

## 简介

给网站和H5应用增加 像微信朋友圈一样的看图功能，可看大图，双击双指缩放，滑动切换图片，点击返回。jQuery plugin for viewing images like Wechat Moments
