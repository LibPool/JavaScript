# ysagc-agent

> 标签: agent, ai, automation, file, local, sandbox, shell, tool, websocket, workspace

## 简介

Local execution agent for ysagc: a state-agnostic, safety-bounded worker that connects to a platform backend over WebSocket, executes tool instructions inside an authorization root, and reports results back.
