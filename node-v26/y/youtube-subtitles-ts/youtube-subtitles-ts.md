# youtube-subtitles-ts

> 标签: api, auto-generated, captions, closed-captions, innertube, node, nodejs, scraper, srt, subtitles, transcript, translation, typescript, video, webvtt, youtube, yt

## 简介

Fetch YouTube video transcripts and subtitles. No API key required. Supports SRT, WebVTT, multiple languages, auto-generated captions, and translations.
