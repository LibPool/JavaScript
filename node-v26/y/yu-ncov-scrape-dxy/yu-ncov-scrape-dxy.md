# yu-ncov-scrape-dxy

> 标签: macoolka, ncov, ncov-2019

## 简介

`yu-ncov-scrape-dxy` is a library for scrape ncov-2019 data from https://ncov.dxy.cn/ncovh5/view/pneumonia. 从丁香园中获取ncov-2019国家、省份、城市数据
