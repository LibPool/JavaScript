# youiyoux

> 标签: ai-agents, audit, claude-code, codex, components, design-system, mcp, react, shadcn, tailwind, ui

## 简介

Your agent rebuilds components you already have. youiyoux catches it: npx youiyoux turns any repo into a shareable report of near-duplicate components, hardcoded token values and off-library imports, with the fixes.
