# yhadmin

> 标签: JavaScript

## 简介

- 前后端分离，可以适配多个后台服务 - 基于配置，登录，菜单，页面等后台管理的地方都是在配置文件中配置，尽量少的写代码 - 封装通用组件 - 可脱离后端
