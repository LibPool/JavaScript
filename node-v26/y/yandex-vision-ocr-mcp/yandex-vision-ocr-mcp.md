# yandex-vision-ocr-mcp

> 标签: claude, claude-desktop, cursor, handwritten-text, mcp, model-context-protocol, ocr, opencode, pdf-ocr, text-recognition, vision, yandex, yandex-cloud, yandex-vision

## 简介

MCP server exposing Yandex Vision OCR (printed, handwritten, tables, markdown, math) for images and PDFs as tools for LLM clients.
