# yookassa-sdk

> 标签: SBP-pay, T-pay, checkout, commerce, e-commerce, ecommerce, integration, javascript, node, nodejs, online-payment, online-payments, online-shopping, pay-connector, payment, payment-processing, payments, receipts, refunds, sberpay, sdk, typescript, yandexpay, yookassa, yookassa-sdk, yookassa-ts, yookassa-ts-sdk

## 简介

Интерфейс для интеграции с YooKassa, позволяет выполнять различные операции, такие как создание платежей, возвратов, чеков и управление ими. Написан на TypeScript.
