# ysz-ui

> 标签: horizontal, ui, vertical, vite, vue, vue3, vuejs, vueui, ysz-ui

## 简介

这是一个基于`vite vue3`搭建的`PC端`组件库。它记录**日常开发**中遇到的需求组件,或是在**技术社区**中所遇到、值得去实现的组件。
