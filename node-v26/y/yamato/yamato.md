# yamato

> 标签: auth, oauth, passport, server, user

## 简介

A framework for user authorization and authentication, principle like simov/grant or jaredhanson/passport, but also including server schema adjust refered from oauthjs/koa-oauth-server,  powered by oauth2, javascript
