# yats-toolkit

> 标签: ai, claude, cli, code-indexer, code-navigation, code-search, codebase-intelligence, context-window, copilot, cursor, developer-tools, embeddings, knowledge-graph, llm, mcp, model-context-protocol, neo4j, qdrant, rag, semantic-search, token-reducer, token-saver

## 简介

YATS — Yet Another Token Saver. One-command MCP server that indexes your codebase into a knowledge graph so AI agents (Claude, Cursor, Copilot) can search and navigate it without burning tokens.
