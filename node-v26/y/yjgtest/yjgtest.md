# yjgtest

> 标签: JavaScript

## 简介

* 简单实现一个ssr，要求页面返回结果如下。 * 尽可能做到将Vue SSR Example作为变量传入 ``` <body>   <div id="app"><div>Vue SSR Example</div></div> </body>  ``` * 在server.js中，实现ssr的服务端逻辑，处理页面和模板入参后，返回html页面到前端。
