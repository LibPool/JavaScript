# ynrm

> 标签: NPM, YARN, registry

## 简介

NPM/YARN registry manager can help you easy and fast switch between different npm registries, now include: cnpm, taobao, nj(nodejitsu), rednpm, edunpm.

## 官网

- 官网：https://blog.mengfei0053.com/blog/npm-resource-manager
- 源码仓库：git://github.com/mengfei0053/ynrm.git
- npm 页面：https://www.npmjs.com/package/ynrm
