# @sapporta/server

> 标签: api, crud, drizzle, framework, hono, openapi, rest, sapporta, sqlite, typescript, zod

## 简介

Sapporta server — schema-as-code tables, auto-generated CRUD, route primitives, and an OpenAPI-emitting Hono app, all wired up with Drizzle and SQLite.
