# @kylebrodeur/mcp-mac-setup

> 标签: claude-code, claude-desktop, cursor, fnm, linux, macos, mcp, model-context-protocol, nvm, pnpm, vscode

## 简介

Fix stdio MCP server launches when Node/pnpm is managed via nvm or fnm — works with VS Code, Cursor, Claude Code, Claude Desktop, and any host reading the standard { "mcpServers": { ... } } JSON config.
