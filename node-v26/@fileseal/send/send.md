# @fileseal/send

> 标签: encryption, file-sharing, fileseal, gdpr, mcp, model-context-protocol, one-time-link, secure-send

## 简介

MCP server that delivers a file to a person as a one-time, AES-256 encrypted, auto-deleting download link via the FileSeal Secure Send API.
