# @agentgates/paygates

> 标签: 402, agent payments, api monetization, express middleware, micropayments, paywall, stablecoin, usdc, x402, x402 middleware

## 简介

Put a price on any route. Charge in USDC from inside your handler with a price your code computes; x402 middleware for a fixed-price route. Settles on Base, Polygon, Arbitrum, Ethereum and Solana.
