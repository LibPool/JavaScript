# @yeastcloud/dsh-anchor

> 标签: agent, anchor, compaction, context, deepseek-harness, dsh, dsh-plugin, persona, plugin, prompt, system-prompt

## 简介

定锚（Anchor）· DeepSeek Harness 会话指令定锚插件：为新会话注入一段可自由组合的指令，并在会话被压缩或过长后自动重锚同一段原文，避免人设与规则被挤出上下文。
