# @kubb/plugin-swr

> 标签: code-generation, codegen, data-fetching, hooks, kubb, meta-framework, react, swr, typescript, use-swr, use-swr-mutation

## 简介

Generate type-safe SWR hooks with Kubb. Covers useSWR and useSWRMutation with full TypeScript support.
