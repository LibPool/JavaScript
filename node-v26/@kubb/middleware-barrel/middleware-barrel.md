# @kubb/middleware-barrel

> 标签: barrel, codegen, kubb, middleware, typescript

## 简介

Barrel-file middleware for Kubb. Automatically generates index.ts re-export files per plugin output directory and an optional root barrel after all plugins complete.

- 源码仓库：git+https://github.com/kubb-labs/kubb.git
