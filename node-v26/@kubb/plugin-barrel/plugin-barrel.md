# @kubb/plugin-barrel

> 标签: barrel, codegen, kubb, meta-framework, plugin, typescript

## 简介

Barrel-file plugin for Kubb. Automatically generates index.ts re-export files per plugin output directory.

## 官网

- 官网：https://kubb.dev/plugins/plugin-barrel
- 源码仓库：git+https://github.com/kubb-labs/kubb.git
