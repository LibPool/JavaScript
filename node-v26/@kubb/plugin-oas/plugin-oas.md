# @kubb/plugin-oas

> 标签: api-specification, code-generator, codegen, kubb, oas, openapi, openapi-v3, plugins, rest-api, schema-parser, schema-processing, swagger, typescript

## 简介

OpenAPI Specification (OAS) plugin for Kubb, providing core functionality for parsing and processing OpenAPI/Swagger schemas for code generation.
