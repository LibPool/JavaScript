# @kubb/plugin-zod

> 标签: code-generation, codegen, kubb, meta-framework, parse, runtime-validation, schema, typescript, validation, zod

## 简介

Generate Zod validation schemas with Kubb for runtime data parsing and type safety. Pairs with @kubb/plugin-ts for end-to-end type coverage.
