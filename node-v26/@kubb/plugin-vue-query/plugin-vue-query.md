# @kubb/plugin-vue-query

> 标签: JavaScript

## 简介

Generate type-safe TanStack Query (Vue Query) composables with Kubb. Covers useQuery, useMutation, useInfiniteQuery, and queryOptions with Vue 3 Composition API support.
