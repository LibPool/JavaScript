# @geoicons/vanilla

> 标签: areas, countries, country-map, dom, geography, geography-icons, geoicons, icons, iso-3166, iso-3166-2, javascript, map, maps, provinces, states, subdivisions, svg, svg-icons, territories, tree-shakable, vanilla, world-map

## 简介

799 geographic map SVG icons (255 countries & territories + 167 world areas + 377 subdivisions) as tree-shakable vanilla-JS DOM factories — no framework, returns a live <svg>; control weight and fill, themed via currentColor.
