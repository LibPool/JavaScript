# @hamolus/types

> 标签: cloudflare, dto, hamolus, schema, types, zod

## 简介

Shared, versioned data contracts for Hamolus: Zod schemas, TypeScript interfaces and API DTOs for collections, fields, records, media, files, panels, auth and scope.
