# @oaverify/yaml

> 标签: oas, openapi, openapi-3.0, openapi-3.1, openapi-3.2, openapi-loader, openapi-validator, spec-loader, swagger, validation, validator, yaml

## 简介

YAML readers for @oaverify/core: load hand-authored .yaml/.yml OpenAPI specs from disk or over HTTP, plus a synchronous loadSpecSync.
