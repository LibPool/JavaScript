# @boxcc/maildeno-editor

> 标签: custom-element, drag-and-drop, email-builder, email-editor, email-template, mjml, react-email, vue, web-component, wysiwyg

## 简介

An open-source, framework-agnostic email template editor. Drag-and-drop block editing, HTML/MJML/React Email/JSON export, and a pluggable ESP-conditional-logic engine with zero required backend.
