# @xyng/yuoshi-backend-adapter-argonauts

> 标签: JavaScript

## 简介

This repository contains a package to adapt [yUOShi](https://github.com/juliandierker/yUOShi) to a Stud.IP-Instance that has the [xyng/yuoshi-studip-plugin](https://github.com/xyng/yuoshi-studip-plugin) extension installed.
