# @xyng/yuoshi-backend-adapter

> 标签: JavaScript

## 简介

This repository contains interfaces, abstract classes and some useful helper-methods required to implement an adapter for [yUOShi](https://github.com/juliandierker/yUOShi) to your arbitrary api.
