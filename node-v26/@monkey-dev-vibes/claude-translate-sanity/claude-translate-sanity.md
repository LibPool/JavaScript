# @monkey-dev-vibes/claude-translate-sanity

> 标签: ai, anthropic, checkpoint, claude, cms, i18n, localization, pipeline, portable-text, sanity, translation

## 简介

Two-pass Claude translation pipeline for Sanity CMS documents. Verdict states, Portable Text-safe extraction, refiner pass, deterministic translation IDs, checkpoint resumability.
