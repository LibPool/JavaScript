# @ggui-ai/chat-self-hosted

> 标签: chat, ggui, mcp, self-hosted, storage-adapter

## 简介

Chat storage adapter for self-hosted ggui servers. Implements the FullChatStorageAdapter contract against the @ggui-ai/mcp-server persistent-thread HTTP + SSE surface.
