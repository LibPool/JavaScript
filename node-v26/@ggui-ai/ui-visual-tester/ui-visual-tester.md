# @ggui-ai/ui-visual-tester

> 标签: ggui, playwright, testing, ui, validation

## 简介

Behavioral validator for GGUI-generated component code. Renders a component in real Chromium via Playwright, clicks each action declared in its contract, and verifies the action actually does something — mutating bound state or dispatching to the agent. C
