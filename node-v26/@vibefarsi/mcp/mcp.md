# @vibefarsi/mcp

> 标签: farsi, mcp, persian, react, rtl, tailwind

## 简介

MCP server for VibeFarsi. Gives Cursor, Claude Code, and Windsurf Persian RTL design rules and registry components so they stop emitting Inter, Latin digits, and LTR layout.

- 官网：https://vibefarsi.ir
- 源码仓库：git+https://github.com/TronIsHere/vibafarsiui.git
