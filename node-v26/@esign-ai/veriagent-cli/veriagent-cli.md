# @esign-ai/veriagent-cli

> 标签: JavaScript

## 简介

VeriAgent CLI 是统一安装入口，用于在当前终端为 OpenClaw 或 Hermes 安装并初始化 VeriAgent 插件。

## 官网

- npm 页面：https://www.npmjs.com/package/@esign-ai/veriagent-cli

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install @esign-ai/veriagent-cli`
- npm registry：https://registry.npmjs.org/@esign-ai/veriagent-cli
- Node 要求：>=18
