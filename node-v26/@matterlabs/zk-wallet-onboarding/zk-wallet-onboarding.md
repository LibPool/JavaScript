# @matterlabs/zk-wallet-onboarding

> 标签: ethereum, wallet, web3, zksync, zkwallet

## 简介

Onboard zkSync users users to web3 by allowing them to select a wallet, get that wallet ready to transact and have access to synced wallet state. Forked from @bnc-onboard
