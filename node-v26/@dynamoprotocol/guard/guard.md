# @dynamoprotocol/guard

> 标签: budget, fail-closed, hard-cap, http-402, litellm, metering, proxy, spending-cap, x402

## 简介

One command puts a hard budget cap in front of any OpenAI-compatible endpoint, enforced by a running dynamo-core (402 fail-closed, signed vouchers).
