# @pilates/widgets

> 标签: cli, ink, pilates, react, select, spinner, terminal, text-input, tui, widgets

## 简介

Interactive widgets for Pilates: TextInput, TextArea, Select, MultiSelect, Tabs, Table, Spinner, ProgressBar. Built on @pilates/react.
