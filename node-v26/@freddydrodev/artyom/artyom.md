# @freddydrodev/artyom

> 标签: commands, cortana, googleNow, recognition, siri, speech, voice

## 简介

Artyom is a Robust Wrapper of the Google Chrome SpeechSynthesis and SpeechRecognition that allows you to create a virtual assistent
