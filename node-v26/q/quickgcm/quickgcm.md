# quickgcm

> 标签: aes-gcm, crypto, cryptosubtle, gcm, password, pbkdf2, subtle

## 简介

A simple wrapper for the WEB Crypto API, to rapidly use AES-GCM mode encryption with PBKDF2 for a password
