# quicrtc

> 标签: agent, ai, computer-use, multi-modal, quic, quicrtc, real-time, streaming, webtransport

## 简介

Real-time transport for AI agent sessions over QUIC/WebTransport. TypeScript client, wire-compatible with the Go server.
