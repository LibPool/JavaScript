# queryforge

> 标签: connection-pooling, database, database-management, fluent-api, mysql, nodejs, orm, parameterized-queries, postgresql, prepared-statements, query-builder, sql, sql-query-builder, sqlite, transaction-management, type-safe, typescript

## 简介

A powerful, type-safe SQL query builder for Node.js with support for MySQL, PostgreSQL, and SQLite. Features fluent API, transaction management, and connection pooling.
