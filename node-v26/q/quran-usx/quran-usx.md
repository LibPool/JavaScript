# quran-usx

> 标签: arabic, data-standard, islam, milestone-markup, mushaf, qiraat, quran, quranic-data, riwayat, scripture, usfm, usx, xml

## 简介

QUSX (Qur'an Unified Scripture XML) — a milestone-based XML data standard for the Qur'an, modeled on the Bible's USX/USFM standard. v0.1 research prototype, not a finished standard.
