# qris-gatepay

> 标签: gatepay, indonesia, payment, payment-gateway, qris, qris-gatepay

## 简介

SDK resmi QRIS GatePay (Node.js, zero-dependency) — buat transaksi QRIS, cek status, batalkan, verifikasi webhook HMAC.

## 官网

- 源码仓库：git+https://github.com/premitry/gatepay.git
- npm 页面：https://www.npmjs.com/package/qris-gatepay
