# quick-caps-cli

> 标签: agent, cli, design-tokens, dom, mcp, mcp-server, model-context-protocol, page-capture, playwright, web-scraping

## 简介

Distill any rendered web page into a few hundred tokens of numbered regions and actions, or capture it to disk - a CLI and MCP server for agents.
