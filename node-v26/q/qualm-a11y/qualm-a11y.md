# qualm-a11y

> 标签: a11y, accessibility, ast, ci, code-quality, linter, react, sarif, static-analysis, typescript, wcag

## 简介

Static accessibility linter for React/TypeScript that catches regressions in CI. Render-independent AST analysis: finds WCAG defects in component source with 100% coverage, and fails the build only on new defects via --diff-branch.
