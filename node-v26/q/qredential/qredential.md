# qredential

> 标签: age-verification, base45, eudi-wallet, identity, jwt, kb-jwt, key-binding, mdl, offline, qr, rfc9901, sd-jwt, selective-disclosure, status-list, token-status-list, verifiable-credentials

## 简介

Verify a digital credential from a QR code with no network connection. SD-JWT selective disclosure, offline revocation, zero dependencies.
