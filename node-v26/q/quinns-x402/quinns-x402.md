# quinns-x402

> 标签: JavaScript

## 简介

Opinionated x402 pay-per-call wrapper for Express APIs and MCP servers. Put an endpoint behind HTTP 402 in minutes: PayAI facilitator, USDC on Base, bazaar discovery indexing, settlement logging, and fail-open verification out of the box.
