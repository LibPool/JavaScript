# qrflow

> 标签: dynamic qr code, mcp, qr, qr code, qr code api, qr code generator, qrcode, qrflow, scan analytics, short link, webhooks

## 简介

QRFLOW.codes API client: create QR codes, change where dynamic codes point after printing, print them on your own domain, read scan analytics, verify webhooks. Zero dependencies; Node, Bun, Deno, Workers.
