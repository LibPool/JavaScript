# @pompeii-labs/emulate-aws

> 标签: JavaScript

## 简介

S3, SQS, IAM, and STS emulation with AWS SDK-compatible S3 paths and query-style SQS/IAM/STS endpoints. All responses use AWS-compatible XML.
