# @istar-ts/agent

> 标签: agent, goal-model, istar, istar2, llm, mcp, pistar, tool-calling

## 简介

A framework-free tool-calling loop between an OpenAI-compatible chat model and istar-ts tools (MCP or @istar-ts/actions), with propose/auto approval and a key-free transcript.
