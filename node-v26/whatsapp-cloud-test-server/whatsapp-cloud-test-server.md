# whatsapp-cloud-test-server

> 标签: meta, test-server, testing, webhooks, whatsapp, whatsapp-business, whatsapp-cloud-api

## 简介

A local test server for the WhatsApp Business Platform Cloud API, for testing text messaging, message statuses and webhooks without real accounts
