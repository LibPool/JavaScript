# @astram/migrate

> 标签: JavaScript

## 简介

Astram framework — the code-table migration runner. Timestamped up()/down() migrations tracked in a schema_migrations table, applied as raw parameterized SQL through a deploy-time DDL account (never the runtime pool). Exposes migrate / migrate:revert / mi
