# @astram/sdk

> 标签: JavaScript

## 简介

Astram framework — the frontend SDK. Projects the principal's authorization facts to the UI so frontend and backend agree by construction (§11.4); classifies allow/deny/temporarily-unavailable (ADR-0016) and surfaces step-up (ADR-0017). Platform-agnostic
