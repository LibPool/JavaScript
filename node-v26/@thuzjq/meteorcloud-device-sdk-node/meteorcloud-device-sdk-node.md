# @thuzjq/meteorcloud-device-sdk-node

> 标签: JavaScript

## 简介

MeteorCloud device SDK for Node.js: account authorization (OAuth 2 + PKCE browser bind, private_key_jwt renewal, DPoP), account-scoped queries, and chunked direct-PUT uploads that declare their own camera
