# @inversealtruism/csd-tx

> 标签: JavaScript

## 简介

Compute Substrate transaction builder — coin selection, fee sizing, buildSend/Propose/Attest, signTx, node-submit JSON. p2pkh-only, SafeInteger-guarded.
