# @slaw-ai/adapter-utils

> 标签: JavaScript

## 简介

Shared utilities for Slaw adapters: process spawning, environment injection, sandbox/SSH transport, workspace sync, and the round-trip helpers that move code between the local execution-workspace cwd and wherever the agent actually runs.
