# @algovoi/substrate-guard

> 标签: agentic-payments, algovoi, dos, hardening, input-validation, jcs, rfc8785

## 简介

Deterministic input-bounds / DoS hardening gate for the AlgoVoi JCS substrate; runs before canonicalization and fails closed on well-formed but resource-hostile payloads with named reject codes; the bounds in force are content-addressed (profileRef)
