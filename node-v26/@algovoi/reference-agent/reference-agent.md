# @algovoi/reference-agent

> 标签: agent, agentic-payments, algovoi, base, jcs, reference-implementation, rfc8785, settlement-attestation, x402

## 简介

Apache 2.0 reference implementation of an agent that emits an AlgoVoi settlement-attestation-v1 receipt for a Base chain transaction. TypeScript port; byte-for-byte parity with the Python algovoi-reference-agent.
