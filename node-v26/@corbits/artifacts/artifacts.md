# @corbits/artifacts

> 标签: artifacts, content-store, corbits, drizzle, hono, interchange, intx, postgres, uploads

## 简介

Artifacts, versions and uploads with a pluggable ContentStore, mountable onto any Interchange host. Requires @intx 0.4.0 or newer.
