# @corbits/codex-provider

> 标签: codex, corbits, inference, interchange, oauth, openai, responses

## 简介

OpenAI Codex (Login with ChatGPT) as an Interchange inference provider, with OAuth token exchange, a Responses-protocol adapter, and a content-type repair for the ChatGPT backend.
