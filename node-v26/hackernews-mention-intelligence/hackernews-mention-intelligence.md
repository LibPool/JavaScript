# hackernews-mention-intelligence

> 标签: ai-agents, buzz, hacker-news, hackernews, hn, mcp, mention-tracking, mindshare, model-context-protocol, usdc, x402

## 简介

Remote MCP server for Hacker News mention intelligence: who is talking about a topic/company, before the market sees it. Free snapshot; paid change detection in USDC via x402 on Base. Use npx hackernews-mention-intelligence to print client config.
