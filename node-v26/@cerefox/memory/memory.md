# @cerefox/memory

> 标签: agents, anthropic, claude, knowledge-base, mcp, modelcontextprotocol, pgvector, rag, supabase

## 简介

Cerefox — user-owned shared memory for AI agents. CLI + stdio MCP server + web UI + ingestion for a knowledge base on your own Supabase project (or fully self-hosted with Cerefox Local).
