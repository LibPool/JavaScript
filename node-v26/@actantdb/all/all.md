# @actantdb/all

> 标签: actantdb, agent, guard, ledger, policy, replay

## 简介

ActantDB — every primitive in one import. Or install just the piece you need: @actantdb/core for storage, @actantdb/policy for Guard, @actantdb/mastra for the agent wrapper, etc.
