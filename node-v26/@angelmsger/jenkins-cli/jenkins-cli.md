# @angelmsger/jenkins-cli

> 标签: agent, build, ci, ci-cd, claude, cli, console, jenkins, jobs, pipeline

## 简介

Inspect Jenkins from the command line for coding agents: discover jobs and builds, read status, console logs, pipeline stages, test failures and SCM changes, and trigger or stop builds, with structured JSON output.
