# @zocomputer/agent-sdk

> 标签: agent, ai, eve, llm, tools

## 简介

A standard library for eve agents: workspace file tools (read/edit/write/glob/grep), a backgroundable bash with bounded output, async task orchestration, and rich-filetype reads (PDF, DOCX, spreadsheets) — one createStdlib call.
