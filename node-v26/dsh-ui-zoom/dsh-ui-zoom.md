# dsh-ui-zoom

> 标签: accessibility, deepseek, dsh, dsh-plugin, harness, settings, ui-scale, zoom

## 简介

Ctrl+wheel page zoom for DeepSeek Harness (60–180%, remembered) with a layout-consistent metric shim, popovers that stay in place, a root-scroll lock and a bottom-right Settings entry.
