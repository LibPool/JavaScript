# @qaweem321/no-ssrf

> 标签: dns-rebinding, edge, ip, ipv6, private-ip, security, ssrf, url, webhook

## 简介

Stop user-supplied URLs from reaching your server's own network. Zero dependencies, runs anywhere; DNS-rebinding-safe requests for Node.
