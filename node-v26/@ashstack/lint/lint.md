# @ashstack/lint

> 标签: eslint-config, expo, lint, linter, oxc, oxlint, react, react-native, typescript

## 简介

ashStack shared oxlint configuration and custom rules. Entries: core, react, react-native, with per-library rule groups auto-detected from your dependencies. Consume from oxlint.config.mts.
