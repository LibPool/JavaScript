# @linter-extension/group-issues

> 标签: JavaScript

## 简介

- add a script in your `package.json` file `test:lint`. The script will execute the next: "./node_modules/.bin/eslint --max-warnings=0 -f ./lint-formatter.js 'path to ypur JavaScript files' > results.json" - run `npx @linter-extension/group-issues`
