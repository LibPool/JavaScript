# @centralkg/map-react

> 标签: central.kg, cluster, map, maplibre, maplibre-gl, marker, nextjs, polyline, react

## 简介

React (and Next.js) components for @centralkg/map — declarative <Map>, <Marker>, <Polyline>, <Cluster> and an account-bound <LayerPanel> over MapLibre GL + central.kg vector tiles.
