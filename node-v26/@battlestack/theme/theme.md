# @battlestack/theme

> 标签: battlestack, design-system, design-tokens, nuxt, nuxt-ui, nuxt4, tailwind, theme

## 简介

Battlestack Design System Nuxt — the Nuxt UI theme: token values for light and dark, brand assets, and the Logo lockup. No components; Nuxt UI is the component library.
