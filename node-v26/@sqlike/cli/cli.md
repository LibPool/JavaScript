# @sqlike/cli

> 标签: cli, duckdb, linter, mariadb, mysql, postgres, sql, sqlike, sqlite, sqlserver, static-analysis

## 简介

CLI for sqlike — deterministic SQL static analysis and query-equivalence checking. A thin remote client that tokenizes locally and forwards to the sqlike API.
