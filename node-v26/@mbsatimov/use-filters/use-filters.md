# @mbsatimov/use-filters

> 标签: faceted-search, filters, headless, hooks, nuqs, pagination, query-params, querystring, react, search-params, table-filters, typescript, url-state

## 简介

Headless, URL-synced filter state for React. Declare filters once, get typed params, resolved filter state, and nuqs-backed URL sync back — bring your own UI.
