# @ohos-npm-ports/parcel-watcher

> 标签: JavaScript

## 简介

A native C++ Node module for querying and subscribing to filesystem events. Used by Parcel 2. — OpenHarmony (OHOS) port: source-built openharmony-arm64 binding embedded at the upstream fallback path, index.js unchanged.
