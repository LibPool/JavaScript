# @ohos-npm-ports/sharp

> 标签: avif, crop, dzi, embed, gif, image, jp2, jpeg, libvips, png, resize, svg, thumbnail, tiff, vips, webp

## 简介

High performance Node.js image processing, the fastest module to resize JPEG, PNG, WebP, GIF, AVIF and TIFF images — OpenHarmony (OHOS) port, built from source against a native libvips 8.18.6 with full JPEG2000 (jp2k) codec support.
