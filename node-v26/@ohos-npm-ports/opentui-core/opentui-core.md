# @ohos-npm-ports/opentui-core

> 标签: JavaScript

## 简介

OpenTUI is a TypeScript library on a native Zig core for building terminal user interfaces (TUIs) — OpenHarmony (OHOS) port: JS bundle rebuilt from upstream v0.5.8 source; the openharmony-arm64 native core is provided by the @opentui/core-openharmony-arm6
