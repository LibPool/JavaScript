# @ohos-npm-ports/parcel-watcher-openharmony-arm64

> 标签: JavaScript

## 简介

OpenHarmony (OHOS) arm64 platform binding for @parcel/watcher — source-built inotify backend, main is a shim re-exporting watcher.node (bundler module-table embedding requires a JS entry)
