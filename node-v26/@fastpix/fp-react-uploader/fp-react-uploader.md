> 标签: chunked upload, drag and drop upload, fastpix react uploader, fastpix uploads, pause resume upload, react component, react file upload, react uploader, react uploads sdk, resumable uploads, upload progress, video upload, web uploads

## 简介

FastPix React Uploader is a customizable React component for chunked, resumable file uploads with drag-and-drop, progress, and pause/resume.
