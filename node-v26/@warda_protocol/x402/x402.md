# @warda_protocol/x402

> 标签: agent, agent-payments, http-402, kaspa, payments, spending-limits, warda, x402

## 简介

Pay HTTP 402 (x402) invoices from a Warda grant on Kaspa, so an agent's spending limits are enforced by consensus rather than by the process holding the key.
