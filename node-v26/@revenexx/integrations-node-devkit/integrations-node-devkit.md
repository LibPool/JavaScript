# @revenexx/integrations-node-devkit

> 标签: devkit, integrations, nodes, revenexx, testing

## 简介

Local development kit for Revenexx integration node packages — a mock Integrations API for previewing nodes/credentials/templates in the Cockpit UI, plus a unit-testing harness. Dev/CI only, never bundled.
