# @revenexx/storage-nuxt-image

> 标签: cdn, image, image-optimization, nuxt, nuxt-image, nuxt-image-provider, responsive-images, revenexx, storage

## 简介

Nuxt Image provider for the revenexx Storage CDN. Build optimized, on-the-fly image URLs against your own domain's /cdn/ endpoint.
