# @exige/web-scanner-sdk

> 标签: JavaScript

## 简介

@exige/web-scanner-sdk is a client-side web document scanner SDK. ML document finding, OCR, and redaction run in the browser. The public demo is the only path that does not need an account. A hostname you control needs a signed license key.
