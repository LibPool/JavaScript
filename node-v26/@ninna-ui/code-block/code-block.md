# @ninna-ui/code-block

> 标签: accessible, code-block, copy-to-clipboard, dark-mode, data-slot, line-numbers, ninna-ui, react, syntax-highlighting, tailwindcss, tailwindcss-v4, ui

## 简介

Syntax-highlighted code block React component for Ninna UI - copy-to-clipboard, line numbers, automatic dark mode, zero external dependencies. Tailwind CSS v4.
