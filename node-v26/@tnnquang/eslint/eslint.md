# @tnnquang/eslint

> 标签: angular, autofix, consistent-type-imports, enforce-path-alias, eslint, eslint-flat-config, eslint-plugin, javascript, linting, nestjs, nextjs, no-arrow-component, no-arrow-function, no-barrel-imports, no-namespace, nuxt, react, tree-shaking, typescript, vue

## 简介

Opinionated ESLint plugin for modern TypeScript projects. Enforces explicit imports, function declarations, path aliases, and consistent type imports across React, Vue, Angular, NestJS, Next.js, and Nuxt.
