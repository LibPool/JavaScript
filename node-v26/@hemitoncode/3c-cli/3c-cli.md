# @hemitoncode/3c-cli

> 标签: 3c, ai-coding, claude-code, documentation, scaffold, skills, spec, spec-driven-development

## 简介

One-off installer that sets up the 3C spec-governance framework (Invariants → Contracts → Enforcement) in any repo: docs scaffold, Claude Code skills, validator, and CLAUDE.md context.
