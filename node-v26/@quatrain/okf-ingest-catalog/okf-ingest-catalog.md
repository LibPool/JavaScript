# @quatrain/okf-ingest-catalog

> 标签: JavaScript

## 简介

Agnostic ingestion and decomposition engine for encyclopedic catalogs, plant floras, dictionaries, pharmacopeias, and ordered entry collections into OKF v0.2 atomic entities
