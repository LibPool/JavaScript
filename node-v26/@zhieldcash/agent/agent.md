# @zhieldcash/agent

> 标签: agent wallet, ai agent, mcp, model context protocol, privacy, robinhood chain, zhield

## 简介

A shielded wallet for AI agents: an MCP server that funds an agent through Zhield Cash on Robinhood Chain, so nothing on-chain links it to its owner. The model never sees a note or a key.
