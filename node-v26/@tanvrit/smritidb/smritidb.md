# @tanvrit/smritidb

> 标签: ai-memory, associative-memory, content-addressable, hyperdimensional-computing, semantic-search, smriti, sparse-distributed-memory, storage, vector-database, vector-symbolic-architectures

## 简介

An open biology-inspired associative memory layer. Storage that remembers by partial cue, degrades like a hologram, and consolidates with use. TypeScript reference implementation.
