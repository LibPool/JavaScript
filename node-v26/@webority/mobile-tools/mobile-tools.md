# @webority/mobile-tools

> 标签: android, cli, icons, ios, prebuild, react-native, webority

## 简介

Dev-time CLI for Webority React Native apps: one prebuild, a dependency guard, a device-aware run, per-environment launcher icons and over-the-air deploys, the same on Windows and macOS.
