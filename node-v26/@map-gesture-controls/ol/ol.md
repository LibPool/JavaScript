# @map-gesture-controls/ol

> 标签: a11y, accessibility, browser, computer-vision, gesture-control, gesture-navigation, gesture-recognition, gis, hand-gesture, hand-gestures, hand-tracking, hands-free, interaction, kiosk, map, map-controls, maps, mediapipe, no-touch, ol, openlayers, openlayers-map, openlayers-plugin, touchless, touchless-navigation, wasm, webcam

## 简介

Control OpenLayers maps with hand gestures via MediaPipe webcam hand tracking. Pan, zoom, and rotate with no backend.
