# @muovi/mcp-server

> 标签: argentina, claude, home-services, latam, llm-tools, local-services, mcp, model-context-protocol, muovi, service-marketplace

## 简介

Model Context Protocol (MCP) server that exposes Muovi's public /v1 API to LLM agents (Claude Desktop, Cursor, Claude Code). Read-only, stdio mode.
