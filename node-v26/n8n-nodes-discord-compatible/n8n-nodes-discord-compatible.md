# n8n-nodes-discord-compatible

> 标签: chat, discord, fluxer, messaging, n8n, n8n-community-node-package

## 简介

n8n community node that mirrors the built-in Discord node (Message, Channel, Member + Webhook) against any Discord-compatible API, selected by a configurable base URL (Discord, Fluxer, Spacebar).
