# @tillstack/shield-cloudflare

> 标签: cloudflare, edge, rate-limit, security, tilldev, tillshield, waf, workers

## 简介

TillShield inline WAF for Cloudflare Workers — evaluate, block, challenge and rate-limit requests at the edge, with an optional KV-backed distributed rate limiter.
