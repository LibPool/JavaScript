# @tillstack/tillgate

> 标签: bot, captcha, human-check, proof-of-work, tilldev, tillgate, widget

## 简介

TillGate browser widget — the client half of a privacy-first human check. Solves a proof-of-work challenge in a Web Worker and mints a short-lived pass token for your forms.
