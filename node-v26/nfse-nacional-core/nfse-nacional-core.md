# nfse-nacional-core

> 标签: adn, certificado-digital, nfs-e, nfse, nfse-nacional, sefin

## 简介

Cliente do ADN (NFS-e Nacional): certificado A1, distribuição por NSU, leitura do XML e criptografia do certificado em repouso, extensível por plugins
