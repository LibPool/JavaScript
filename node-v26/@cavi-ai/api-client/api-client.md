# @cavi-ai/api-client

> 标签: agent, agents, anthropic, api-client, cavi, claude, claude-managed-agents, codex, esm, fetch, gateway, hermes, llm, managed-agents, mcp, openai, openclaw, opencode, provider-agnostic, react, responses, rpc, runtime, sse, stateful-agents, typescript, websocket

## 简介

Provider-agnostic TypeScript client for AI agent runtimes — one RuntimeClient contract spanning Claude (incl. Claude Managed Agents, beta), Codex via OpenAI Responses, Antigravity (AGY), Hermes, OpenClaw, and OpenCode, with HTTP + WebSocket RPC, SSE, mani
