# paceline

> 标签: agents, claude-code, claude-code-plugin, hooks, mcp, pacing, rate-limit, throttle

## 简介

Your agents take turns. A Claude Code plugin that enforces a minimum gap between calls to the same external host, machine-wide, across every session, subagent and script.
