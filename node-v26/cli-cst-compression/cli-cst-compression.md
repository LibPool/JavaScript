# cli-cst-compression

> 标签: brotli, compress, compression, decompress, deflate, gzip, promise, zip, zlib

## 简介

Tiny Promise-based compression helper for Node.js (gzip, deflate, brotli) built on the native zlib module. Zero dependencies.
