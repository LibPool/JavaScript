# @jykim0507/hd-map

> 标签: JavaScript

## 简介

HD 정밀지도(PMTiles)를 MapLibre GL JS로 렌더링하는 Vue 3 컴포저블 라이브러리. 도로 중심선·보호구역·안전표지·노면표시 등 정밀지도 레이어를 함수 한 줄로 켜고 끌 수 있다.
