# @hank-warren/pi-agents

> 标签: agents, pi, pi-extension, pi-package, rpc, subagents

## 简介

Subagents for Pi that look like Pi: each agent is its own pi --mode rpc process with your extensions and AGENTS.md, rendered with Pi's own components, watchable and steerable, with optional budgets and git worktrees.
