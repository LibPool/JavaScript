# @hank-warren/pi-ask-user-question

> 标签: coding-agent, pi, pi-extension, pi-package, prompt, questionnaire, tui

## 简介

Structured questionnaire tool for Pi with numbered options, digit hotkeys and Tab-to-comment, composed from the shared permission-selector component.
