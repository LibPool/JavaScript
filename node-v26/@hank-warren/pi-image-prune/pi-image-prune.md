# @hank-warren/pi-image-prune

> 标签: anthropic, cliproxyapi, coding-agent, images, pi-extension, pi-package, request-too-large

## 简介

Prune old images from Pi requests so image-heavy sessions stay under a provider's request size limit, with per-model limits for proxies such as CLIProxyAPI.
