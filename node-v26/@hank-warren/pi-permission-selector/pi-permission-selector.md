# @hank-warren/pi-permission-selector

> 标签: coding-agent, permissions, pi-package, select, tui

## 简介

OptionSelector: a composable Pi TUI selector with numbered options, digit hotkeys, and inline notes, shared by pi-auto-permissions and pi-ask-user-question.
