# @dsh-so/mcp

> 标签: agent, deepseek, dsh, mcp, model-context-protocol, plugin-registry

## 简介

MCP server exposing dsh.so machine-readable DSH plugin data: registry index, security scans, install verification (L1-L5), npm download and star trend boards.
