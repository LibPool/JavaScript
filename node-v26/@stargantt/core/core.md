# @stargantt/core

> 标签: gantt, gantt-chart, plugin-architecture, project-management, scheduling, timeline, typescript, zero-dependencies

## 简介

StarGantt micro-kernel: plugin host, services, extension points, events, commands. Knows nothing about tasks, dates, or drawing. Zero runtime dependencies.
