# @quilla-fe-kit/errors

> 标签: error-hierarchy, errors, frontend, typed-errors, typescript

## 简介

Typed error hierarchy for FE projects: QuillaFeError base + HTTP/network/business-rule subclasses with code, context, cause, JSON serialization, and a cross-realm Symbol.for brand. Zero runtime dependencies.
