# @quilla-fe-kit/auth-react

> 标签: auth, authentication, frontend, guard, jwt, rbac, react, typescript

## 简介

React adapter for @quilla-fe-kit/auth: AuthProvider with pluggable signIn/signOut, JWT-claim → Principal decoder, RequireAuth and ScopeGuard route/render guards, useAuth + useHasScope hooks. Zero external runtime deps; React as peer.
