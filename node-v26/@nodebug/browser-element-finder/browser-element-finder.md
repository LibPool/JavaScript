# @nodebug/browser-element-finder

> 标签: browser-automation, element-finder, selenium, testing, webdriver

## 简介

Robust, agent-friendly JavaScript library for identifying DOM elements by semantic type and/or text content, with full support for shadow DOM, iframes, and browser automation workflows (Selenium, Playwright, Puppeteer).
