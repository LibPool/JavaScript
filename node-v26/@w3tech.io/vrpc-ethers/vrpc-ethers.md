# @w3tech.io/vrpc-ethers

> 标签: attestation, ed25519, ethereum, ethers, rpc, tdx, verifiable

## 简介

ethers v6 drop-in for Ankr's verifiable RPC — VrpcProvider verifies every JSON-RPC response (Ed25519) inside _send, fail-closed.
