# @fclwtt/anydoc-mcp

> 标签: anydoc, document-converter, docx-to-markdown, firecrawl, markdown, mcp, mcp-server, pdf-to-markdown

## 简介

MCP server wrapping Firecrawl anydoc — convert documents (docx/pptx/xlsx/pdf/odt/rtf/epub/csv) to clean GitHub-Flavored Markdown. Pure local, no API key.
