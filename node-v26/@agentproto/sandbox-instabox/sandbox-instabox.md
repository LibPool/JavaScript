# @agentproto/sandbox-instabox

> 标签: agentic, agentproto, aip-36, instabox, open-standard, sandbox

## 简介

@agentproto/sandbox-instabox — InstaBox `SandboxProvider` for @agentproto/sandbox. Boots an InstaBox VM, installs an always-on systemd unit for the agentproto daemon, publishes the daemon port as the account's public edge URL, and exposes its MCP endpoint
