# @agentproto/catalog-sync

> 标签: agentproto, catalog-sync, codegen, generator, model-catalog

## 简介

Build-time generator framework for @agentproto/model-catalog. Generates *.generated.ts from pinned provider sources (LLM, image, video, audio, voice).
