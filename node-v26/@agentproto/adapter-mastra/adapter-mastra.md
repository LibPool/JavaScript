# @agentproto/adapter-mastra

> 标签: adapter, agentproto, aip-14, mastra, open-standard, tool

## 简介

Generic Mastra adapter for AIP-14 ToolHandles. Wraps any `@agentproto/tool` ToolHandle into a Mastra createTool() handle so apps drop in tools authored once and used by any framework.
