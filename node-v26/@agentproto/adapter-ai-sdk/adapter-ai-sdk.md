# @agentproto/adapter-ai-sdk

> 标签: adapter, agentproto, ai-sdk, aip-30, open-standard, tool, vercel-ai

## 简介

AI SDK adapter for AIP-30 ToolImplementations. Wraps any `@agentproto/driver` ToolImplementation into a Vercel AI SDK Tool ready to drop into `streamText({ tools })`, `generateText`, or any downstream consumer that speaks the AI SDK tool surface.
