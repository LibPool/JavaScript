# @agentproto/adapter-openclaw

> 标签: acp, adapter, agent-cli, agentproto, aip-45, openclaw

## 简介

@agentproto/adapter-openclaw — AIP-45 AGENT-CLI adapter for OpenClaw. Spawns `openclaw acp` and bridges OpenClaw's Gateway session over stdio JSON-RPC.
