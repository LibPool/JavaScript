# @agentproto/define-doctype

> 标签: agentic, agentproto, aip-56, defineX, doctype, open-standard, scaffold

## 简介

agentproto/define-doctype — meta-factory for AIP `defineX(definition)` constructors. Centralises the cross-spec invariants every define-* shares (id shape, description length, top-level freeze, error-message prefix); leaves spec-specific defaulting + nest
