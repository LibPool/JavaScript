# @agentproto/workflow

> 标签: agentic, agentproto, aip-15, defineWorkflow, open-standard, workflow

## 简介

@agentproto/workflow — AIP-15 WORKFLOW.md reference implementation. A markdown + frontmatter format for declaring a multi-step agent workflow's abstract orchestration shape — its steps, branching, parallelism, approval gates, suspend/resume, and compensat
