# @agentproto/adapter-jcode

> 标签: adapter, agent-cli, agentproto, aip-45, jcode, print, rust

## 简介

@agentproto/adapter-jcode — AIP-45 adapter for 1jehuang/jcode, a RAM-efficient Rust coding agent. Spawns `jcode run` in headless mode.
