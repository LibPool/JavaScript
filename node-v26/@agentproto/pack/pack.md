# @agentproto/pack

> 标签: agentic, agentproto, definePack, open-standard, pack

## 简介

@agentproto/pack — PACK.md reference implementation (AIP-64, specs/aip-64.mdx). A bundle that assembles a plugin, apps, knowledge, and a playbook into one installable unit.
