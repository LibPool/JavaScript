# @agentproto/events-channel

> 标签: agentproto, channel, claude-code, mcp, mcp-events, webhook

## 简介

@agentproto/events-channel — a Claude Code channel that makes a session a subscriber of agentproto MCP Events (events/subscribe over a signed webhook, delivered into the session as <channel> notifications).
