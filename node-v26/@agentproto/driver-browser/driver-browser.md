# @agentproto/driver-browser

> 标签: agentic, agentproto, browser, cdp, defineBrowser, open-standard, provider

## 简介

Browser provider kit: defineBrowser (manifest + launch), the BrowserInstance and BrowserDriver ports, a provider registry, a provider-kit lister, and a typed capability gate (browser:unsupported).
