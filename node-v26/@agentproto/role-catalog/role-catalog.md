# @agentproto/role-catalog

> 标签: agentic, agentproto, aip-47, open-standard, role, role-catalog

## 简介

Reference catalogue of AIP-47 ROLE.md builtins — 15 starter roles (executive, specialist, coordinator) covering common AI-company positions. Composed via @agentproto/role; consumed via BuiltinRoleSource.
