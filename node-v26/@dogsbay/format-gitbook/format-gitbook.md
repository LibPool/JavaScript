# @dogsbay/format-gitbook

> 标签: JavaScript

## 简介

GitBook format plugin for Dogsbay — imports GitBook Git Sync (and legacy gitbook-cli) corpora into TreeNode[] by translating the Git Sync markdown dialect to Dogsbay-MD.
