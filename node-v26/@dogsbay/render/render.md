# @dogsbay/render

> 标签: JavaScript

## 简介

Render one Dogsbay Markdown file to one self-contained HTML page: themed, light and dark, accessible, nothing external. A single bundled file with no dependencies, for people and agents (npx -y @dogsbay/render doc.md -o doc.html)
