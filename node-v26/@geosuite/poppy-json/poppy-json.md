> 标签: ai-agents, generative-engine-optimization, geo, mcp, oauth, openapi, personal-agent, personal-agent-protocol, poppy, poppy.json, rfc8414, well-known

## 简介

Checker and generator for poppy.json, the /.well-known discovery file of the Personal Agent Protocol by Sierra and Meta. CLI, library and web page, zero dependencies.
