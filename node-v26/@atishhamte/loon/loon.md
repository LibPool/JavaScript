# @atishhamte/loon

> 标签: ai, compression, data-format, encoder, encoding, gpt, json, language-model, llm, loon, token-optimization, typescript

## 简介

LOON (LLM Optimised Object Notations) - An encoder-only library that reduces token consumption by ~40-50% compared to minified JSON through schema optimization and intelligent formatting
