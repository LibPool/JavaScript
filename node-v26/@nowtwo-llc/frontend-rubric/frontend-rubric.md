# @nowtwo-llc/frontend-rubric

> 标签: assessment, browser, criteria, dom, editor, education, grading, rubric, standards, typescript

## 简介

A dependency-light rubric editor for the browser: criteria, weighted grading scales, standards alignment and drag-to-reorder, rendered straight into a host form.
