# @orbitalfee/mcfo-sdk

> 标签: eip-1559, ethereum, ethers, fees, gas, orbital-fee, viem

## 简介

Orbital Fee fee selection for Ethereum transactions: a typed client for the Orbital Fee API plus an ethers/viem submission helper. Never handles private keys.
