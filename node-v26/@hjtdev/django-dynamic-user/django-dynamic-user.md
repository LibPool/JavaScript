# @hjtdev/django-dynamic-user

> 标签: JavaScript

## 简介

Swappable User/Profile/Setting data layer SDK for django-dynamic-user — typed hooks over both the self-service (/api/v1/users) and admin (/api/v1/admin/users) surfaces, generated from the backend's own OpenAPI schema.
