# @dharun7/agentloops

> 标签: adaptive, agent-framework, agent-loop, agent-loops, agent-orchestration, agent-routing, agentic, agentic-ai, agents, ai, ai-agent, ai-agents, autonomous-agents, claude-code, dispatcher, llm, llmops, loop-engineering, multi-agent, multi-agent-systems, orchestration, routing

## 简介

Adaptive multi-agent orchestration for AI agents: route work to typed specialist agents, learn from outcomes, mine patterns, and run propose-dispatch-verify-retry agent loops. Zero-dependency TypeScript library + CLI with a Claude Code hook generator.
