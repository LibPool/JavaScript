# @sharpee/story-runtime-baseline

> 标签: baseline, interactive-fiction, manifest, sharpee

## 简介

Story Runtime Baseline manifest (ADR-178). Declares the canonical set of packages a .sharpee story bundle may import. Used by a host to install the baseline transitively and by the story build to validate bundles against the contract.
