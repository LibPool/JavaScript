# @adobedjangir/commerce-admin-web-kit

> 标签: admin-ui-sdk, adobe-io, aio, app-builder, commerce-admin, exc-app, react

## 简介

Framework-level building blocks for Adobe App Builder / Admin UI SDK web UIs: design-token theme, a configurable action client, and an Experience Cloud shell mount helper.
