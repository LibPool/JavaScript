# @adobedjangir/commerce-admin-snapshots

> 标签: adobe-io, aio, app-builder, commerce-admin, rollback, snapshot

## 简介

Snapshot + rollback add-on for @adobedjangir/commerce-admin-management. Capture point-in-time copies of schema + values, restore wholesale (auto pre-restore backup included).
