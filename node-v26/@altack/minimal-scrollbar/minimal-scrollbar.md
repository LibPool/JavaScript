# @altack/minimal-scrollbar

> 标签: JavaScript

## 简介

An Angular directive to fix Windows's "mid-nineties" scrollbars.   No extra configuration, no required markup and also minimal size (3.8 KB MINIFIED, 1.2 KB GZIPPED)
