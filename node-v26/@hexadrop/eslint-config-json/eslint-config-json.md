# @hexadrop/eslint-config-json

> 标签: eslint, eslint-config, json, jsonc, lint

## 简介

JSON slice of the hexadrop ESLint config: jsonc plugin, jsonc parser and canonical sort-keys for package.json and tsconfig.json.
