> 标签: aws-s3, azure-blob, azure-blob-storage, b2, backblaze-b2, blob-storage, cloudflare-r2, digitalocean-spaces, file-storage, gcs, google-cloud-storage, minio, multipart-upload, object-storage, presigned-url, r2, s3, s3-compatible, signed-url, storage, streaming, typescript, wasabi

## 简介

Universal, zero-dependency object storage for Node.js. One typed API for local disk, Amazon S3, Cloudflare R2, Backblaze B2, MinIO, Azure Blob, Google Cloud Storage and Wasabi.
