# @marufme/device-key

> 标签: browser-api, browser-detection, client-detection, client-side, device-analyzer, device-checker, device-fingerprint, device-identification, device-identify, device-info, device-insight, device-inspector, device-profiling, hardware-detection, lightweight, modular, network-detection, os-detection, tree-shakeable, typescript, user-agent, web-detection

## 简介

A lightweight, modular TypeScript library for comprehensive device detection, fingerprinting, and information gathering in browsers. Features tree-shakeable modules for OS detection, browser analysis, network info, device fingerprinting, and more.
