# @mockzilla/mcp

> 标签: ai-tools, api-mocking, api-simulation, api-testing, ci-cd, claude, claude-code, claude-desktop, cursor, developer-tools, gemini-cli, mcp, mock, mock-server, mockzilla, model-context-protocol, openapi

## 简介

MCP server for Mockzilla (github.com/mockzilla/mockzilla-mcp). Lets Claude, Cursor, and Gemini CLI install the Mockzilla CLI, run local mock servers from OpenAPI specs, and mock individual endpoints, no account needed. Log in from the agent to deploy host
