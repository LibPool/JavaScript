# node-red-contrib-raspi5-stepper

> 标签: 28byj-48, gpio, motor, node-red, node-red-contrib, raspberry-pi, raspberry-pi-5, stepper, stepper-motor, uln2003

## 简介

Raspberry Pi 5 28BYJ-48 stepper motor with ULN2003 driver, pure JavaScript Node-RED node with selectable GPIOs, direction, steps or turns, half/full/wave step
