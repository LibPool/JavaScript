# @inkless/mdbrowse

> 标签: cli, github, grip, live-reload, markdown, mermaid, preview, readme, shiki, viewer

## 简介

Browse a folder of Markdown locally as a GitHub-styled site. Sidebar nav, ⌘K file search, live reload, mermaid + math, shiki dual-theme highlighting, programmatic API — fully offline, no GitHub API calls.
