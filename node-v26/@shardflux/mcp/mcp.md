# @shardflux/mcp

> 标签: ai-agents, mcp, mcp-server, microvm, model-context-protocol, sandbox, serverless, shardflux, vm, workspace

## 简介

Shardflux MCP server (stdio): serverless VMs for your agent. Open a persistent workspace by key, run commands, edit files, use git, a browser and a desktop in it. Uses your scoped Shardflux API key.
