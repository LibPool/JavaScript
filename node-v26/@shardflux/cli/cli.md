# @shardflux/cli

> 标签: ai-agents, cli, microvm, sandbox, serverless, shard, shardflux, vm, workspace

## 简介

shard: the Shardflux command line for serverless VMs. Create an account, set up keys and billing, then open, run commands in, move files to, suspend, resume and fork the workspaces your product gives its customers.
