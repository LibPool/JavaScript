# @shardflux/sdk

> 标签: agent-infrastructure, ai-agents, code-execution, computer-use, microvm, sandbox, sdk, serverless, shardflux, tools, vm, workspace

## 简介

Shardflux TypeScript SDK: serverless VMs without lifecycle code. Give each customer of your product a persistent Linux microVM opened by key, and give your agent workspace tools (exec, files, processes, PTY, git, browser, computer use).
