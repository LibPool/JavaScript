# @wasmpeg/cpu

> 标签: audio, decode, encode, ffmpeg, video, wasm, webgpu

## 简介

WebGPU-accelerated FFmpeg compiled to WebAssembly (CPU-only build, no WebGPU binary — smaller download for Node/server use)
