# @wacando/agent

> 标签: agents, mcp, omemo, wacando, xmpp

## 简介

Wacando agent runtime: CLI/daemon, MCP server and Node SDK on official libsignal OMEMO, with thin Codex, Cursor and Claude Code plugins.
