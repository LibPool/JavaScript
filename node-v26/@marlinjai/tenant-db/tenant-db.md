# @marlinjai/tenant-db

> 标签: isolation, kysely, lumitra, multi-tenancy, postgres, schema-per-tenant

## 简介

Shared multi-tenant isolation core: schema-per-tenant_group routing, the tenantSchema resolver chokepoint, db factories, connection factories, and the provisioning + migration runner for the Lumitra suite.
