# @marlinjai/contacts-core

> 标签: contacts, crm, kysely, lumitra, multi-tenancy, postgres

## 简介

The shared contact model of the Lumitra suite: persons and organizations per company in one contacts database, with duplicate detection, customer numbers, merge, erasure and the migration runner.
