# @lacspace/password

> 标签: argon2-alternative, auth, bcrypt-alternative, breach-check, diceware, entropy, hash, haveibeenpwned, k-anonymity, owasp, passphrase, password, password-generator, password-hashing, password-policy, password-strength, password-verify, pbkdf2, phc, pwned, salt, secure-password, security, typescript, verify, zxcvbn

## 简介

Password hashing & verification — PBKDF2-HMAC-SHA256 (OWASP iterations) with a portable PHC string, a zxcvbn-style strength estimator, k-anonymity breach check, policy evaluator and cryptographic passphrase/password generators. Isomorphic over Web Crypto.
