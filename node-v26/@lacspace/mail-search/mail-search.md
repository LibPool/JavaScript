# @lacspace/mail-search

> 标签: ast, email, filter, gmail, imap, mail, parser, query, search, search-operators, typescript, webmail

## 简介

Gmail-style mail search parser that returns a neutral AST instead of a database query: from:, to:, cc:, subject:, has:attachment, is:unread/read/starred/replied/suspicious/verified/list/important, in:, label:, category:, filename:, before:/after: (YYYY-MM
