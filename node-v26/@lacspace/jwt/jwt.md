# @lacspace/jwt

> 标签: auth, clock-tolerance, csrf, ed25519, eddsa, edge, es256, es384, es512, hs256, hs384, hs512, jose, jsonwebtoken, jwk, jwks, jwt, key-rotation, keyset, oidc, refresh-token, rs256, sign, token, token-rotation, typescript, web-crypto

## 简介

JSON Web Tokens (HS/RS/ES/EdDSA) with JWKS-by-kid key rotation, strict expiry/issuer/audience/subject/jti checks + secure random & CSRF tokens. Isomorphic over Web Crypto — Node, edge, browser.
