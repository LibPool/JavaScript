## 简介

A tiny, zero-dependency, runner-agnostic fluent assertion library — expect(...).toEqual/.toThrow/.resolves, 35+ matchers (toBeOneOf, toBeWithin, toBeSorted, toIncludeSameMembers, type & string matchers), asymmetric matchers, expect.extend and a deep-equal
