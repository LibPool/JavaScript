# @lacspace/otp

> 标签: 2fa, authenticator, backup-codes, base32, google-authenticator, hotp, mfa, otp, otpauth, otpauth-uri, parse-otpauth, recovery-codes, sha256, sha512, speakeasy-alternative, time-based-otp, totp, totp-verify, two-factor, two-factor-authentication, typescript, web-crypto

## 简介

TOTP & HOTP two-factor auth, Google Authenticator compatible — generate secrets, compute/verify codes, parse/build otpauth:// QR URIs and issue single-use recovery codes. Built on Web Crypto: runs on Node, edge and browser. Zero-dependency, isomorphic.
