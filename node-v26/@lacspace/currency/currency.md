# @lacspace/currency

> 标签: currencies, currency-codes, currency-format, currency-symbols, iso-4217, isomorphic, minor-units, money, typescript, zero-dependency

## 简介

ISO 4217 currencies — codes, numeric codes, minor units, names, symbols and the countries that use them, plus Intl-free formatting. Zero-dependency, isomorphic.
