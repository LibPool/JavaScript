## 简介

A fast, zero-dependency token estimator, LLM cost calculator and context-budget manager — good-enough approximation of GPT/Claude/Gemini token counts without the 3 MB tiktoken/wasm. Context-window usage, batch estimation and cross-model cost comparison. I
