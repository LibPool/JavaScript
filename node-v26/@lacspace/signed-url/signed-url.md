# @lacspace/signed-url

> 标签: clock-tolerance, edge, expiring-url, hmac, ip-binding, isomorphic, key-rotation, magic-link, magic-link-auth, nonce, one-time-token, presigned-url, secure-download, signed-claims, signed-token, signed-url, tamper-proof, typescript, unsubscribe-link, url-signing, web-crypto

## 简介

HMAC-signed, expiring URLs & tokens over Web Crypto — secure download links, magic-login links, unsubscribe links and one-time-action tokens. Tamper-proof, timing-safe, zero-config. Isomorphic (Node, edge, browser).
