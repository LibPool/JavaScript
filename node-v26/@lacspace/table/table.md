# @lacspace/table

> 标签: accessible, ag-grid-alternative, column-resizing, csv-export, data-table, datagrid, filtering, nextjs, pagination, react, react-table, row-selection, sorting, table, tanstack-table-alternative, typescript, zero-dependency

## 简介

A dependency-free React data table — sorting, filtering, global search, pagination, row selection, column resizing, pinned columns, expandable rows, grouping and CSV export. The whole table engine is pure functions you can use without rendering anything,
