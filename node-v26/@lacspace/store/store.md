# @lacspace/store

> 标签: computed, derived-state, global-state, logger, middleware, persist, react, selector, slices, ssr, state-management, store, subscribe-with-selector, typescript, usesyncexternalstore, vanilla-store, zero-dependency, zustand

## 简介

Minimal global state for React in ~1KB — create a store, use selectors, no provider. Built on useSyncExternalStore with persist/logger middleware, computed values, slice composition, and a React-free vanilla core. Zero-dependency, SSR-safe, fully typed.
