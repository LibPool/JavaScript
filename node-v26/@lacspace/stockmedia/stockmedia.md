# @lacspace/stockmedia

> 标签: attribution, b-roll, free-license, isomorphic, newsroom, pexels, pixabay, stock-media, stock-photos, stock-video, typescript, zero-dependency

## 简介

Search and download free-licence stock video clips and photos from the official Pexels and Pixabay APIs, normalized to one shape with licence + one-line attribution per asset. Pooled bring-your-own API keys, orientation/resolution/duration/safe-search fil
