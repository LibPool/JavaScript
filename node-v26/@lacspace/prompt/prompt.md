# @lacspace/prompt

> 标签: ai, anthropic, chat-messages, context-window, few-shot, injection-guard, isomorphic, json-output, llm, output-format, prompt, prompt-engineering, prompt-injection, prompt-registry, prompt-template, prompt-versioning, provider-agnostic, structured-output, template, token-budget, token-estimate, type-inference, type-safe, typescript, zero-dependency

## 简介

A tiny, typed prompt-engineering toolkit — build, compose and render LLM prompts and chat messages with real type safety. Variable names are inferred from the template string, so .render() is type-checked. Zero-dependency, isomorphic, provider-agnostic.
