# @lacspace/query

> 标签: backoff, cache, data-fetching, dedupe, invalidate-queries, optimistic-update, prefetch, query-cache, query-invalidation, react, react-query, retry, ssr, stale-while-revalidate, swr, typescript, usemutation, usequery, zero-dependency

## 简介

Tiny data fetching for React with a shared cache, request de-duplication, stale-while-revalidate, focus/reconnect revalidation, retry/backoff, query invalidation, subscriptions and mutations. useQuery + useMutation in ~2KB. Zero-dependency, SSR-safe, full
