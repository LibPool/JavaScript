# @lacspace/form

> 标签: async-validation, contact-form, dirty-tracking, field-array, form, form-handling, form-reducer, form-state, form-validation, formdata, honeypot, isomorphic, nextjs, server-actions, spam-protection, type-safe, typescript, useactionstate, usesyncexternalstore, validation, zero-dependency

## 简介

End-to-end form handling for the server — turn FormData into typed, validated data with a honeypot + timing spam guard, and get back your data or per-field errors ready to re-render. Shaped for Next.js Server Actions. Zero-dependency, isomorphic.
