## 简介

Secure HTTP headers & a typed Content-Security-Policy builder — HSTS, CSP nonces/hashes, Permissions-Policy, COOP/COEP/CORP, Reporting-Endpoints, report-only + strict/API presets. Framework-agnostic + Next.js. Zero-dependency, isomorphic.
