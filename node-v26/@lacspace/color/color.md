# @lacspace/color

> 标签: accessibility, chroma-alternative, color, color-harmony, colour, complement, contrast, darken, hex, hsl, hsv, invert, lighten, mix, named-colors, oklab, oklch, palette, rgb, shades, tints, typescript, wcag, zero-dependency

## 简介

Parse, convert, manipulate and check colours — hex/rgb/hsl/hsv/oklch + CSS names, lighten/darken/mix/invert/complement, palettes & harmonies, and WCAG contrast for accessible UIs. Zero-dependency, isomorphic.
