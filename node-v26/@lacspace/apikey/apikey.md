# @lacspace/apikey

> 标签: api-key, api-key-generation, apikey, auth, bearer, checksum, expiry, fingerprint, hashing, key-rotation, permissions, prefixed-key, revocation, scopes, secret, secret-key, security, sha-256, token, typescript

## 简介

Issue & verify API keys the right way — prefixed high-entropy keys, store only the SHA-256 hash, constant-time verify, last-4 display. Isomorphic over Web Crypto.
