# @posthaste/mcp-server

> 标签: ai-agent, email, mcp, model-context-protocol, posthaste, transactional-email

## 简介

Model Context Protocol server for Posthaste — lets an AI agent send mail, read delivery status and inspect sending reputation through a scoped API key.
