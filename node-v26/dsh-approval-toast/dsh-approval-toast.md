# dsh-approval-toast

> 标签: approval, cordis, deepseek, deepseek-harness, dsh, dsh-plugin, notification, toast, windows

## 简介

Windows toast notifications for DeepSeek Harness approvals: approve or reject from the notification while DSH is in the background, with an in-app fallback; plus turn completion and error notifications.
