# monad-browser

> 标签: accessibility-tree, agents, ai-agents, browser, browser-automation, cdp, chrome, chrome-devtools-protocol, cli, headless, mcp, snapshot

## 简介

Headless, turnkey browser CLI for AI agents: compact AX snapshots with @refs, warm daemon, raw CDP. No Playwright.
