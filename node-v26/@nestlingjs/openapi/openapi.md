# @nestlingjs/openapi

> 标签: esm, nestling, openapi, schema, swagger, typescript

## 简介

Документ OpenAPI 3.1 из тех же деклараций endpoint'ов, которые обслуживают запросы: конвертеры схем приходят данными, зависимости от валидатора нет
