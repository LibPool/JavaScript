# @walletkit/wagmi-v1-link

> 标签: JavaScript

## 简介

Link is a set of simple and beautiful UI components that you can use to onboard your app using email or social logins. All wallets created with Link are powered by WalletKit's Smart Wallets - each wallet is gasless, secure, and recoverable.
