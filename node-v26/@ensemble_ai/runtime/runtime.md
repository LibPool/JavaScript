# @ensemble_ai/runtime

> 标签: JavaScript

## 简介

Ensemble shared run-core (D-01): the engine surface that @ensemble_ai/cli and @ensemble_ai/mcp adapt over. No adapter/CLI/MCP dependency lives here.
