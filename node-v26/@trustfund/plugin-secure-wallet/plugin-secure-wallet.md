# @trustfund/plugin-secure-wallet

> 标签: account-abstraction, agent-wallet, eliza, erc-4337, guardrails, spending-limits, viem, web3

## 简介

Opt-in spending guardrails and a transparent, self-directed convenience fee for autonomous agent wallets in the Eliza framework. No fees by default; no hardcoded fee recipient.
