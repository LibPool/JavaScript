# @delightstack/auth

> 标签: argon2, auth, authentication, cloudflare, delightstack, durable-objects, jwt, oauth, passkey, sveltekit, webauthn, workers

## 简介

Edge-native authentication for Cloudflare Workers — JWT sessions, Argon2id password hashing, OAuth, passkeys (WebAuthn), and SvelteKit guards, backed by Durable Objects.
