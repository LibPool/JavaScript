# @delightstack/images

> 标签: cdn, cloudflare, containers, delightstack, image-processing, images, sharp, thumbhash, workers

## 简介

Image processing for Cloudflare — on-the-fly variants, face-aware cropping, thumbhash placeholders, and PDF/SVG handling via Cloudflare Containers + Sharp.
