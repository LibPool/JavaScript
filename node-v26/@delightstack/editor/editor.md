# @delightstack/editor

> 标签: block-editor, delightstack, editor, prosemirror, rich-text, svelte, svelte5, wysiwyg

## 简介

A delightful rich text / block editor for Svelte 5 built on ProseMirror — slash commands, drag & drop blocks, magnetic resize, optimistic uploads, and an extensible block system.
