# @oceanalt/metamask-agent-wallet

> 标签: agent-payments, agent-wallet, eip-3009, metamask, oclif-plugin, pre-signing, x402

## 简介

MetaMask Agent Wallet (mm) plugin: check x402 payment signatures, token transfers and approvals with OceanAlt before MetaMask signs them. Allow, ask a human, or block. No keys, no custody.
