# humanforge

> 标签: 2d, 3d, arkit, avatar, avatar-creator, blendshapes, expo, glb, hijab, makehuman, metaperson-alternative, mixamo, modest-fashion, react, react-native, selfie-to-avatar, svg, threejs

## 简介

Open-source avatar SDK for React and React Native: realistic MakeHuman-based 3D humans (CC0) and a women-first 2D avatar creator (Forge2D) with hijabs, modest wear and a rules engine.
