# @unhosted-ai/mcp-server

> 标签: claude-desktop, cursor, llama-cpp, local-first, mcp, model-context-protocol, unhosted, zed

## 简介

MCP server that exposes a running unhosted daemon's local-first capabilities (memory, web fetch, vram-pool status) as tools to MCP-aware clients like Claude Desktop.
