# @shallbay/dsh-token-stats

> 标签: dashboard, deepseek-harness, dsh, plugin, token, usage

## 简介

Harness-wide token usage dashboard: aggregates billed token usage across all sessions (uncached input / cache read / cache write / output) with peak/off-peak CNY cost estimation, served at /token-stats with live refresh at /api/token-stats/refresh. Client
