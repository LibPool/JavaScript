# @fhirstarter/backend

> 标签: access-token, backend-services, client-credentials, ehr, fhir, fhir-auth, fhir-client, fhirclient, healthcare, hl7, interoperability, jwks, jwt, jwt-assertion, oauth, oauth2, r4, smart, smart-backend-services, smart-on-fhir, token, token-refresh

## 简介

Server-side SMART on FHIR Backend Services (client credentials) auth engine. Owns JWT assertion, JWKS, and a proactive refresh loop, then hands off a flat token surface any FHIR client can spread in.
