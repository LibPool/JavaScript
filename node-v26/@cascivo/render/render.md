# @cascivo/render

> 标签: agent, ai, cascivo, design-system, generative-ui, json, react, renderer

## 简介

Render a JSON view config with real cascivo components — the runtime behind the MCP scaffold_view / validate_view tools, plus machine mode for views. Docs offline: npx @cascivo/docs
