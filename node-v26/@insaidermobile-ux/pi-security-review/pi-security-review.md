# @insaidermobile-ux/pi-security-review

> 标签: pi-extension, pi-package, security, security-review, vulnerability

## 简介

Security review for pi. Read-only agents find vulnerabilities, separate agents challenge each attack path, and a findings store keeps results across runs.
