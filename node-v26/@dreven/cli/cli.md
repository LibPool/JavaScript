# @dreven/cli

> 标签: a11y, accessibility, audit, mcp, model-context-protocol, wcag

## 简介

Audit a web page for accessibility on your own machine, inside your own signed-in session, and send the evidence to your Dreven account. A command line and an MCP server for Claude Code, Codex and other MCP clients.
