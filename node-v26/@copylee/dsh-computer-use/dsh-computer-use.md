# @copylee/dsh-computer-use

> 标签: ai-agent, computer-control, computer-use, cordis, deepseek, deepseek-harness, desktop-automation, dsh, dsh-plugin, rpa, screenshot, ui-automation, windows

## 简介

DeepSeek Harness Computer Use 插件（Windows）：让 AI 看屏幕、点鼠标、敲键盘操控电脑；控制时屏幕泛起橙色光晕并显示“DeepSeek Harness 正在操控你的电脑”，按 Esc 暂停 / 继续。
