# @pracht/adapter-netlify

> 标签: adapter, functions, isg, netlify, pracht, preact, serverless, ssg, ssr, vite

## 简介

Netlify Functions adapter for deploying Pracht apps with SSR, SSG, ISG, Markdown negotiation, and durable CDN caching.
