# @pracht/test

> 标签: api-routes, loaders, middleware, pracht, preact, testing, vitest

## 简介

First-party testing utilities for Pracht apps: typed factories for loader, API, and middleware args, a middleware chain runner, form submission helpers, and minimal response readers.
