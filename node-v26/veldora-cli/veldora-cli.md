# veldora-cli

> 标签: ai-agents, base, brreg, cli, doffin, enhetsregisteret, exchange-rates, finland, kartverket, lovdata, nordic, norges-bank, norway, prh, ted, tenders, usdc, x402

## 简介

Command line client for Veldora: Norwegian companies, public tenders and contract awards, addresses, laws and NOK exchange rates, plus Finnish companies. Paid per request with x402 (USDC on Base); no API key.
