# @aicoaches/velocity-widget-kit

> 标签: JavaScript

## 简介

The Velocity chat-widget kit: the shared UI code (styles, the host adapter and the widget scripts) that Velocity's show_widget cards load from cdn.jsdelivr.net. UI code only: no data, no secrets.
