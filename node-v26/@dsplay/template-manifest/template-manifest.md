# @dsplay/template-manifest

> 标签: JavaScript

## 简介

Statically scans a DSPLAY HTML template's source for its dsplay_template variables and captures its dsplay-data.js as example preview data, producing template-variables.json + template-example-data.json for the CMS to auto-detect variables and seed defaul
