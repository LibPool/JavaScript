# @nomeelnoj/pi-prompt-timer

> 标签: pi-extension, pi-package, prompt-cache, status, timer

## 简介

Live prompt-timing extension for pi coding agent — shows elapsed thinking time and an idle timer that warns at the 5-minute cache TTL.
