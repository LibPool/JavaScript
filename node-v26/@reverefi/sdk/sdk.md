# @reverefi/sdk

> 标签: attestations, bgs, cctp, cgc, eas, escrow, graded cards, polygon, psa, sgc, slabs, tag, usdc

## 简介

Revere: offers addressed to a graded slab's cert. The standard's reference library — cert keys, resolve, offers, and the transactions to make, accept and fund them.
