# @stackline/cfb

> 标签: cfb, compound-file, compression, mht, nodejs, npm-package, office, ole, parser, sheetjs, stackline, typescript, writer, zip, zip64

## 简介

Drop-in replacement for cfb 1.2.2: read and write compound files (OLE/CFB), ZIP and MHT containers, with fixes for hangs, ZIP64, CVE-2024-22363 and bugs the original never released
