# docusaurus-plugin-ondocs

> 标签: ai, ai-search, ask-ai, docs-search, docusaurus, docusaurus-plugin, docusaurus-theme, llms-txt, mcp, mcp-server, rag, search

## 简介

The ondocs Docusaurus plugin, under the name Docusaurus users search for: open-source Ask AI for your docs, with an MCP server for agents. Cited answers on your own model key, from one static index, with no vendor and no vector database.
