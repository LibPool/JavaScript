# @antonve/presentr

> 标签: JavaScript

## 简介

presentr is a minimal Bun HTTP server for storing HTML and Markdown documents and serving them back by key. HTML documents are returned exactly as stored, while Markdown documents are rendered to HTML with GitHub-flavored Markdown support. Each namespace
