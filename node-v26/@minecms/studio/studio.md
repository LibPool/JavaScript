# @minecms/studio

> 标签: admin, cms, headless-cms, minecms, react, studio

## 简介

MineCMS Studio — админка на Vite 8 + React 19 + TanStack Router/Query/Form + tRPC. Динамический UI по schemas-as-code. Пакет содержит готовый production-бандл админки и helper для отдачи статики из @minecms/server.
