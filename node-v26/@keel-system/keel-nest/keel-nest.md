# @keel-system/keel-nest

> 标签: agents, codegen, dsl, keel, nestjs

## 简介

Generador NestJS para diseños Keel: valida el diseño agnóstico y genera services/<servicio>-nest/ con el scaffolding transversal al stack. Equivalente a keel-spring: el mismo diseño produce servidores con el mismo contrato observable.
