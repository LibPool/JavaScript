# micro-canvas-confetti-native

> 标签: animation, celebration, coins, confetti, expo, particles, react-native, rewards, typescript

## 简介

Tiny React Native confetti and coin bursts — same physics as micro-canvas-confetti-physics, plus image coins and a collect flight into a target. Views + Image only, no native modules.
