# @rutvikmakvana/backend-launcher

> 标签: auth, backend, cli, express, mongodb, multer, nestjs, scaffold, typescript

## 简介

Scaffold a TypeScript Express or NestJS backend with one command, then add feature modules (auth, file-upload) on demand.
