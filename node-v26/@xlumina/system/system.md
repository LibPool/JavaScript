# @xlumina/system

> 标签: design-system, design-tokens, light-dark, lumina, responsive-grid, surface-treatment, theme

## 简介

The portable Lumina design-system brain: tokens, eras, light/dark schemes, responsive grid, seeded variation, surface treatments, and mobile-vs-web interaction rules. Framework-agnostic, zero runtime dependencies.
