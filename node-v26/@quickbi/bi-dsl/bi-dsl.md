# @quickbi/bi-dsl

> 标签: JavaScript

## 简介

QuickBI DSL 包：基于 [valibot](https://valibot.dev/) 的运行时 schema + 反推 TypeScript 类型，描述图表、看板、分析单元、OLAP 查询的契约。
