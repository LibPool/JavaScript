# @inrupt/vocab-solid-rdfjs-rdfdatafactory

> 标签: JavaScript

## 简介

Bundle of vocabularies that includes the following:

 - acl: [Generator provided] - Web Access Control Vocabulary

 - acp: A vocabulary to structure policy-based access controls for the Solid ecosystem.

 - solid: The Solid Terms vocabulary defines terms
