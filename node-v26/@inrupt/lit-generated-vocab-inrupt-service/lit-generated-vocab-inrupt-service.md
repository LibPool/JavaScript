# @inrupt/lit-generated-vocab-inrupt-service

> 标签: JavaScript

## 简介

Bundle of vocabularies that includes the following:

  inrupt_notification: The Inrupt notification vocabulary.

  inrupt_websub: The Inrupt WebSub vocabulary.
