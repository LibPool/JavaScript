# @jterrazz/test

> 标签: api-testing, browser-mode, cli-testing, component-testing, e2e, golden-files, hexagonal, integration-testing, msw, oxlint, test-framework, testcontainers, testing, vitest, website-testing

## 简介

Declarative testing framework for HTTP APIs, CLIs, background jobs, websites, mobile apps and rendered components — one entry point, real infrastructure and a real browser, golden-file assertions, plus an oxlint convention plugin.
