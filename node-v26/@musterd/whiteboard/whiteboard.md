# @musterd/whiteboard

> 标签: agents, brainstorm, claude-code, codex, cursor, mcp, squig, whiteboard

## 简介

A shared whiteboard for a person and an agent to brainstorm on. The person draws in Squig's editor; the agent draws and reads through MCP tools; every item is labelled with who put it there.
