# @cubis/verifyme-better-auth

> 标签: better-auth, email, otp, passwordless, sms, verifyme

## 简介

Verifyme for Better Auth: sign users in with codes Verifyme sends and checks, or deliver Better Auth's own codes through Verifyme — with the end user's IP carried to your firewall.
