# @statusmap/core

> 标签: dashboard, feature-health, playwright, roadmap, status, test-coverage, vitest

## 简介

Honest, test-aware project status maps: the typed definition contract, the status policy (health math + proof-level ladder), the rollup engine, and vitest/playwright test-artifact ingestion. Framework-agnostic, zero runtime dependencies.
