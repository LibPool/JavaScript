# @anarkisti/dab

> 标签: mcp, model-context-protocol, pixel-art, sprite, sprite-editor, vite-plugin

## 简介

dab on a folder of character-grid sprites: a Vite plugin serving the pixel editor and the folder to it, an MCP server for drawing with a model, and the format itself for a game to read sprites with.
