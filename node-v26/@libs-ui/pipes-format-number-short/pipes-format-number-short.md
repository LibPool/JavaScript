# @libs-ui/pipes-format-number-short

> 标签: JavaScript

## 简介

> Rút gọn số lớn: `2.380.000.000` → `2,38 Tỷ` · `450.000.000` → `450 Triệu`. Nhãn bậc khai sẵn cho VI/EN, số chữ số thập phân và ngưỡng rút gọn cấu hình được.
