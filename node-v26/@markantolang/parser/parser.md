# @markantolang/parser

> 标签: ast, canonical, commonmark, formatter, gfm, markanto, markdown, markdown-parser, parser

## 简介

Reference implementation of Markanto, a Markdown variant for robust, canonical, agent-ready documents — a tolerant parser, a canonical formatter, and a semantic-AST validator. Zero runtime dependencies.
