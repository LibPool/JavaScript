# @ntgcalls/darwin-arm64

> 标签: JavaScript

## 简介

A Library for creating group calls and P2P calls with WebRTC and MTProto (prebuilt binary for darwin-arm64)

## 官网

- 官网：https://pytgcalls.github.io/
- 源码仓库：git+https://github.com/pytgcalls/ntgcalls.git
- npm 页面：https://www.npmjs.com/package/@ntgcalls/darwin-arm64
