# @codefusion-cc/r2

> 标签: cloudflare, cloudflare-workers, r2, s3, sigv4

## 简介

Cloudflare R2 through its S3 API: SigV4 signing on WebCrypto, a client for objects, listings, copies and multipart uploads that resolves with results, R2's keys from a Cloudflare API token, and R2 in memory for tests
