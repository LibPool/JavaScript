# @gorules/into-md

> 标签: browser, converter, document, docx, llm, markdown, odp, ods, odt, office, pdf, pptx, rtf, wasm, webassembly, xls, xlsx

## 简介

Convert DOCX, PPTX, XLSX, XLS, ODS, ODT, ODP, RTF and PDF to Markdown in the browser or Node.js with a small WebAssembly module
