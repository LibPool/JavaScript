# @shiftyasan/mcp-server

> 标签: ai-agent, constraint-optimization, mcp, model-context-protocol, scheduling, shift-scheduling, shift-yasan, shiftyasan

## 简介

Model Context Protocol (MCP) server for the Shiftyasan public solver API. Lets AI agents call the shift scheduling solver from MCP-aware hosts (Claude Desktop, Cursor, Continue, etc.). Public beta — the API and this package may change.
