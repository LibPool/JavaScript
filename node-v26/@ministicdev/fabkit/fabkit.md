# @ministicdev/fabkit

> 标签: arc, button, expo, fab, floating-action-button, react-native, reanimated, speed-dial

## 简介

A floating action button toolkit for React Native + Expo — one action pinned over content, or a speed dial that unfolds in a column or an arc.
