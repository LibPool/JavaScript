# @one-nexty/icons-native

> 标签: JavaScript

## 简介

Jeu d'icônes Nexty pour React Native. Mêmes noms et mêmes tracés que @one-nexty/icons, rendus avec react-native-svg. Cibles : iOS, Android et web via react-native-web.
