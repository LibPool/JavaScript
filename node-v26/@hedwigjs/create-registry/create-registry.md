# @hedwigjs/create-registry

> 标签: create-package, hedwig, initializer, registry, scaffold, topics

## 简介

Initializer for a Hedwig topics-registry package. Scaffolds a standalone TypeScript workspace with codegen, types, and helpers — no runtime dependency on @hedwigjs/*.
