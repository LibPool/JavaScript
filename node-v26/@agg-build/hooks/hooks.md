# @agg-build/hooks

> 标签: agg, agg-build, agg-market, hooks, kalshi, polymarket, prediction-market, prediction-markets, react, react-hooks, siwe, siws, tanstack-query, trading

## 简介

React hooks and providers for the AGG prediction market aggregator. Wraps @agg-build/sdk with TanStack Query, shared session state, and live WebSocket data.
