# @korso/shepherd

> 标签: agent, claude, coordination, mcp, model-context-protocol

## 简介

Shepherd MCP server — gives any MCP-capable agent (Claude Code, Codex, etc.) advisory cross-session coordination tools (work/done/announce/sync, plus link/unlink/decline) backed by the shared Shepherd hub. Joins the workspace automatically and ships stand
