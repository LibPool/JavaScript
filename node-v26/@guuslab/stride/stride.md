# @guuslab/stride

> 标签: cli, cms, extism, pdk, plugin, self-hosted, stride, wasm, website-builder

## 简介

Stride: a CMS and visual web builder in one binary. The stride CLI (serve a site, back it up, check a machine, scaffold plugins and themes) and the TypeScript plugin kit at @guuslab/stride/pdk.
