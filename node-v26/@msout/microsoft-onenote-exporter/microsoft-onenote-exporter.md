# @msout/microsoft-onenote-exporter

> 标签: cli, export, markdown, microsoft, obsidian, onenote, playwright

## 简介

Log in, list and export Microsoft OneNote notebooks as Obsidian Markdown - one CLI over @msout/microsoft-webauth, @msout/microsoft-onenote-list-notebooks and @msout/microsoft-onenote-export-notebook.
