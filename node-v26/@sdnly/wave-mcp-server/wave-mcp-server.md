# @sdnly/wave-mcp-server

> 标签: claude, invoicing, mcp, model-context-protocol, wave, waveapps

## 简介

Unofficial MCP server for Wave (waveapps.com) invoicing: customers, invoices, products and payments, with a preview-then-confirm step for anything that sends or records money.
