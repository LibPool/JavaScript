# @zukhruf/ui

> 标签: button, components, react, shadcn, shadcn-ui, tailwindcss, ui

## 简介

React components built from the components of @zukhruf/shadcn, such as TheButton: a button with a delayed loading spinner, an icon and a tooltip.
