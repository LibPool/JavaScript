# @jdesignlab/box

> 标签: JavaScript

## 简介

Box는 스타일링을 위한 기본적인 UI 컴포넌트입니다. 기본적으로 `div`로 렌더링되며, `as` 속성을 사용하여 원하는 요소로 변경할 수 있습니다.
