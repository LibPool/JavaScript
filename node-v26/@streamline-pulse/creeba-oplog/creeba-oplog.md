# @streamline-pulse/creeba-oplog

> 标签: crdt, creeba, hybrid-logical-clock, local-first, lww, op-log

## 简介

Portable op-log for local-first apps: hybrid logical clock, operation journal and LWW convergence. Persistence-agnostic — the app plugs an OpStore and a Projection (Prisma, SQLite, Drizzle, raw SQL…). No native or ORM dependency. Pairs with @streamline-pu
