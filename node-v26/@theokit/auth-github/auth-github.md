# @theokit/auth-github

> 标签: auth, github, oauth, oauth2, theokit, theokit-plugin

## 简介

GitHub OAuth 2.0 provider for @theokit/sdk/server/auth. Plugs into defineAuth({ providers: [github({...})] }).
