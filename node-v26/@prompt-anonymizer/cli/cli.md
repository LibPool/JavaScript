# @prompt-anonymizer/cli

> 标签: anonymization, cli, llm, pii, privacy

## 简介

A buddy check for PII before it reaches an LLM - consistent, reversible labels. Node CLI (npx prompt-anonymizer) built on @prompt-anonymizer/core.
