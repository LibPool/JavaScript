# @designflow/qcmantra

> 标签: canvas, drawing, excalidraw, excalidraw-embed, react, whiteboard

## 简介

Single publishable package that re-exports the Excalidraw editor and all of its core building blocks (common, element, math, utils, fractional-indexing, laser-pointer) through one entry point.
