# kuaidi100-tracking-mcp

> 标签: express, kuaidi100, mcp, tracking, workbuddy-connector

## 简介

MCP Server for Kuaidi100 express tracking: carrier recognition, single/batch tracking query, anomaly detection, price and time estimation. Works out of the box via Kuaidi100 free quota; optional API key.
