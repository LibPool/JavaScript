# @ion-drive/plugin-redis

> 标签: cache, ion-drive, message-bus, plugin, redis, streams

## 简介

Ion Drive plugin: Redis cache and (opt-in) Redis Streams message bus — swaps the platform's CacheProvider for multi-node coherence and can replace the Postgres outbox bus for broker-based event delivery.
