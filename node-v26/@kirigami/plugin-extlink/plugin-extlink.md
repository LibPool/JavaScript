# @kirigami/plugin-extlink

> 标签: embed, kirigami, kirigami-plugin, link-preview, opengraph, plugin

## 简介

<extlink> authoring tag for Kirigami — a SCRAPER-backed external link preview card, cached to disk so a rebuild never re-crawls a resolved URL.
