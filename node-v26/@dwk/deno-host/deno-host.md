# @dwk/deno-host

> 标签: cloudflare-workers, d1, deno-deploy, durable-objects, libsql, queue, r2, s3, shim, turso

## 简介

Deno Deploy host building blocks for the @dwk packages — external libSQL/Turso presented behind the Cloudflare D1Database and SqlStorage (Durable Object SQLite) interfaces, KV-backed Durable Object and Queue emulation, and an S3-compatible R2Bucket adapte
