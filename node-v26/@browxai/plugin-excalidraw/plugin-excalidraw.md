# @browxai/plugin-excalidraw

> 标签: ai-agent, browser-automation, browxai, browxai-plugin, canvas, excalidraw, mcp

## 简介

Excalidraw canvas-app adapter plugin for browxai — surfaces scene/viewport/add/delete/scroll over the `window.excalidrawAPI` page-side global.
