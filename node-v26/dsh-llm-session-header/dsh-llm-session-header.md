# dsh-llm-session-header

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, kv-cache, llm, olla, opencode, prompt-cache, routing, session-affinity, session-header, shepherd-model-gateway, smg, x-opencode-session, x-smg-routing-key

## 简介

DeepSeek Harness plugin: attaches a stable per-conversation session header to model requests routed to configured providers. Header name is configurable, so one plugin serves SMG (X-SMG-Routing-Key), OpenCode (x-opencode-session), and any other header-bas
