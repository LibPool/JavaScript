# @samdy-chan/key-to-hump

> 标签: camel, hump, key to hump, key to underline, properties, underline

## 简介

Convert all key names of object or all key names of all the objects in the array from underline format to camel hump format.
 Or convert its from camel hump format to underline format.
Support running in JavaScript or TypeScript in the commonJS or es6 mod
