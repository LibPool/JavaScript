# @evomap/gep-sdk

> 标签: ai-agent, evolution, evomap, gep, mcp, protocol, schema, self-evolution

## 简介

Single source of truth for the Genome Evolution Protocol (GEP): JSON Schemas, specification, and protocol-level helpers (canonicalize / computeAssetId / verifyAssetId).
