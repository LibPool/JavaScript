# @buildtovalue/audit

> 标签: attestation, audit, bpmn, ledger, process-mining, xes

## 简介

Demonstrable integrity for bpmn-react governance: hash-chain ledger verification (verifyLedger), canonical promotion attestations (attestVersion) and XES export for process mining. Zero runtime dependencies.
