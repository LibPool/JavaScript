# @buildtovalue/soundness

> 标签: bpmn, deadlock, process-analysis, soundness, verification

## 简介

Structural soundness analysis for bpmn-react: deadlock/livelock/dead-branch detection over the process graph (O(V+E), no state-space search), delivered as plugin-compatible validation rules. Zero runtime dependencies.
