# @buildtovalue/anchor-rfc3161

> 标签: anchor, bpmn, rfc3161, timestamp, trust

## 简介

RFC 3161 timestamp anchor adapter (Handoff 8): anchors the ledger chain head to a TSA timestamp token via a HOST-injected transport (the library never does network). Implements the AnchorAdapter contract from @buildtovalue/identity. Zero runtime dependenc
