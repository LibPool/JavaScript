# @buildtovalue/conformance

> 标签: bpmn, conformance, corpus, interoperability, omg

## 简介

OMG BPMN 2.0 conformance tooling for bpmn-react: interoperability corpus, element-by-element conformance matrix and generated CONFORMANCE.md. Zero runtime dependencies.
