# @bluweo/mcp

> 标签: ai, bluweo, claude, mcp, model-context-protocol

## 简介

Connect a local MCP client (Claude Desktop, Cursor, any stdio client) to Bluweo: a small bridge to the remote Bluweo MCP server, with sign-in in your browser.

## 官网

- 官网：https://www.bluweo.com/en/connect-ai
- npm 页面：https://www.npmjs.com/package/@bluweo/mcp
