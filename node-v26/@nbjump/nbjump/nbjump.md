# @nbjump/nbjump

> 标签: JavaScript

## 简介

`Nbjump` 是由 Vue 驱动的多端开发框架，其语法规范完全遵循 Vue，支持一套代码同时运行到百度小程序、微信小程序以及 H5 Web 端。
