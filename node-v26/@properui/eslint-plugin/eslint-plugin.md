# @properui/eslint-plugin

> 标签: a11y, design-system, eslint, eslint-plugin, eslintplugin, lint, properui, rtl, tailwindcss

## 简介

ESLint rules that keep AI- and human-written Proper UI code on semantic tokens: raw Tailwind palette classes, arbitrary values, dark: variants and physical directional properties.
