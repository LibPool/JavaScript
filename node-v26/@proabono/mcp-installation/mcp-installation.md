# @proabono/mcp-installation

> 标签: billing, mcp, modelcontextprotocol, proabono, saas, subscription

## 简介

Local MCP server that installs ProAbono into a website, from the developer IDE: hosted pages, rights synchronization, catalogue introspection, customers, subscriptions, usage and invoicing.
