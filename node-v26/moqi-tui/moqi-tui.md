# moqi-tui

> 标签: agent, deepseek, dsh, moqi, terminal, tui

## 简介

Moqi — the unspoken understanding between you and your harness. A terminal app for DeepSeek Harness: bordered composer, live token counter, slash palette, markdown transcript with syntax-highlighted code.
