# @almiris/pushdep

> 标签: concurrent executor, dependency, executor, job, message queue, node, nodejs, process, process manager, queue, task, task executor, typescript, workflow

## 简介

A concurrent executor for hierarchical tasks (tasks that *depend* on other tasks). It can also be used as a message queue, a workflow engine or a process manager.
