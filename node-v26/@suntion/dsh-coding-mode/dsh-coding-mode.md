# @suntion/dsh-coding-mode

> 标签: dsh-plugin

## 简介

DSH coding mode: the `coding` agent preset (coding-only tool roster) plus the host-plane tool mask that keeps browser, scheduling, goal, workflow, plugin-manager and skill-authoring tools out of it.
