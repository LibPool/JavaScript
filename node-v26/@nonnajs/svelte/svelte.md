# @nonnajs/svelte

> 标签: dependency-injection, di, ioc, nonna, svelte, svelte5, zero-reflection

## 简介

Svelte bindings for @nonnajs/di - setInjector() context helper plus useInjection()/useOptionalInjection()/useAllInjections()/useInjector() functions for zero-reflection dependency injection in Svelte apps.
