# @nonnajs/compiler

> 标签: aot, compiler, dependency-injection, di, nonna

## 简介

Ahead-of-Time TypeScript TypeChecker-based dependency compiler for @nonnajs/di. Infers constructor dependencies at build time with zero runtime reflection.
