# @sync-subscribe/core

> 标签: JavaScript

## 简介

Shared types, filter matching, and sync token utilities for `sync-subscribe`. Used internally by `@sync-subscribe/client` and `@sync-subscribe/server` — you generally don't need to install this directly unless you're building a custom transport or server
