# @gogitcms/plugin-hello

> 标签: JavaScript

## 简介

Example CMS plugin: a route + sidebar link, a user-menu link, and a plugin:shout field component. Plain ESM with no build step, so both hosts (SPA bundling and desktop runtime import) load it as-is.
