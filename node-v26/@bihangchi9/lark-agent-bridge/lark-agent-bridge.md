# @bihangchi9/lark-agent-bridge

> 标签: agent-bridge, bot, codex, coding-agent, deepseek, deepseek-harness, dsh, dsh-plugin, feishu, lark, traex

## 简介

Feishu/Lark bridge for local coding agents — one group, one conversation, one pinned runtime. Bridges dsh, CLI agents (traex/codex), an IDE window, or a custom agent behind one gateway.
