# lanhu-image-downloader

> 标签: JavaScript

## 简介

下载蓝湖设计稿的切图到本地, just 省点力气。 * 支持下载整个项目 * 支持下载某个组 * 支持下载某个设计稿 * 支持中文转英文命名 * 支持下载1倍图或者2倍图 * 支持下载后调整尺寸
