# local-executor

> 标签: agent, ai-coding, claude-code, cli, codex, cursor, gemma, local-llm, ollama, qwen, windsurf

## 简介

Set up a planner → local executor → auditor AI coding pipeline: installs Ollama, picks a right-sized open-weight model for your hardware, and installs the skill into Claude Code, Codex CLI, Cursor, and Windsurf.
