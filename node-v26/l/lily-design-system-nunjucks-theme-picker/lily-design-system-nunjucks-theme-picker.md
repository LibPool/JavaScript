# lily-design-system-nunjucks-theme-picker

> 标签: design, lily, nunjucks, picker, system, theme

## 简介

Lily Design System Nunjucks theme picker: an icon button opening an APG listbox that swaps a theme stylesheet and sets data-theme. Headless, SSR-safe, no CSS.
