# lazy-cf7-assets

> 标签: contact-form-7, wordpress

## 简介

Lazyloads Contact Form 7's JavaScript only if there is a form on the page. Use on a WordPress website with Contact Form 7 plugin active and its JavaScript manually dequeued.
