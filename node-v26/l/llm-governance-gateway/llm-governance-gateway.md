# llm-governance-gateway

> 标签: ai-gateway, cost-governance, llm, llm-judge, rate-limit, spend-cap, structured-output, vercel-ai-sdk, zod

## 简介

Governed structured-output LLM pipeline: rate limit → spend caps (per-user + global circuit breaker) → cache → provider-chain failover → Zod validation → usage logging → LLM-judge, with a deterministic mock provider for CI.
