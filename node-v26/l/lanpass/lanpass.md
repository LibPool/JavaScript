# lanpass

> 标签: mcp, ngrok-alternative, port-forwarding, remote-access, reverse-tunnel, socks5, tunnel, zero-trust, 内网穿透, 端口转发

## 简介

别再问对方 IP 了。发一条命令，对方跑一下，就能访问你机器上你指定的端口。到期自动断，撤销立即生效。
