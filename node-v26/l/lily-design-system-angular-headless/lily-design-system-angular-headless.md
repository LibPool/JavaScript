# lily-design-system-angular-headless

> 标签: angular, aria, design-system, headless, lily, wcag

## 简介

Lily Design System Angular headless component library: all 491 catalog components as standalone, signal-based, OnPush components. Unstyled, accessible, zero CSS. Targets WCAG 2.2 AAA.
