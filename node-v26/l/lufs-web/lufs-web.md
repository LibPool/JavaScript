> 标签: audio, audio-analysis, broadcast, bs.1770, bs1770, ebu-r128, loudness, lra, lufs, mastering, streaming, true-peak, web-audio

## 简介

Bit-exact BS.1770-4 Integrated LUFS, LRA, and True Peak measurement for the browser, Web Workers, and Node. Zero dependencies. Pure ES module. Pulled from luvlang.studio's production mastering chain.
