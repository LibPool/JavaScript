# loopyourself

> 标签: agent, claude-code, issues, linear, opencode, todo

## 简介

A framework-agnostic Agent todo plugin. Local issue system natively compatible with Linear terminology — manage Linear Issues alongside local ones when the Linear MCP is enabled.
