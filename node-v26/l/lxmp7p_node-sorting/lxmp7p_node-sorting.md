# lxmp7p_node-sorting

> 标签: JavaScript

## 简介

Модуль для Node.JS, который преобразует массив чисел в строку по примеру: [1,2,3,7,8,9,15,17,19,20,21] -> '1-3,7-9,15,17,19-21'
