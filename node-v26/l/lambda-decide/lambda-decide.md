# lambda-decide

> 标签: aws-lambda, calibration, cdk, decision-model, jev, system-one, typescript

## 简介

Typed, calibrated System One decisions (Choice / Score / Noul) for AWS Lambda: client, confidence gating, and a CDK gateway construct for Jev or any /v1/systemone backend.
