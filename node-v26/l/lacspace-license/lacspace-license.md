# lacspace-license

> 标签: apache-2.0, attribution, ci, cli, compatibility, compliance, copyleft, copyright, detect-license, gpl-compatibility, header, licence, license, license-check, license-compatibility, license-detection, license-fix, license-generator, license-header, license-manager, mit, notices, oss, source-header, spdx, spdx-detect, third-party-notices, typescript, zero-dependency

## 简介

Keyless licence manager for your codebase — generate a LICENSE from an SPDX id, add/refresh per-file licence headers, build THIRD-PARTY-NOTICES, and gate CI that everything matches. Zero dependencies.
