# llm-stream-guards

> 标签: chatbot, guardrails, llm, output-filter, prompt-injection, security, streaming

## 简介

Deterministic output guards for a streamed LLM reply: untrusted links, made-up emails, phone numbers and prices, quoted system prompts and code, stopped before they reach the screen.
