# lateralus-cli

> 标签: cli, compiler, language, lateralus, ltl

## 简介

npm-side launcher for the Lateralus programming language toolchain. Delegates to the PyPI `lateralus-lang` package; install once, call `lateralus` or `ltlc` from anywhere.

## 官网

- 官网：https://lateralus.dev
- 源码仓库：git+https://github.com/bad-antics/lateralus-lang.git
- npm 页面：https://www.npmjs.com/package/lateralus-cli

## 获取地址

- npm registry：https://registry.npmjs.org/lateralus-cli
