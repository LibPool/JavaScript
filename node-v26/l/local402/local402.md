# local402

> 标签: 402, agents, ai-agents, cli, mcp, payment, paywall, proxy, testing, x402

## 简介

One-command local paywall for AI agents. Drop an x402-style HTTP 402 paywall in front of any local server or MCP tool — simulated, instant, no blockchain.
