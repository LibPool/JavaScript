# lime-survey-exp-manager

> 标签: JavaScript

## 简介

The lime survey Expression Manager is a js module that provides functionality for parsing and highlighting expressions in a text area. It can be used to provide suggestions to users while they are typing identifiers, function names, and suffixes in an exp
