# lp-file-archiver

> 标签: archive, file-bundling, gcs, loopengine, loopengine-ability, zip

## 简介

A loopengine ability: a create_zip_archive tool that bundles local files and/or http(s) URLs into one zip archive, saved locally or to GCS with a real signed URL, plus a skill on when to use it.
