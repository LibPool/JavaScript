# lite4mariadb

> 标签: browser, database, embedded, indexeddb, innodb, mariadb, mysql, pglite, sql, wasm, webassembly

## 简介

MariaDB embedded server (with InnoDB) compiled to WebAssembly — run real MariaDB in the browser and Node.js. A PGlite-style API for MariaDB.
