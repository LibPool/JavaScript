# layerone-mcp

> 标签: ai-agent, claude, docx, eidas, esignature, factur-x, layerone, mcp, model-context-protocol, pades, sign

## 简介

Serveur MCP LayerOne — expose les API DocX (génération de documents, PDF, factures Factur-X) et Sign (signature électronique eIDAS/PAdES) aux agents IA (Claude, ChatGPT, Cursor…).
