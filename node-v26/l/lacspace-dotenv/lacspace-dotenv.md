# lacspace-dotenv

> 标签: aes-256-gcm, ci, cli, codegen, decrypt, diff, dotenv, dotenv-cli, encrypt, env, environment-variables, expand, interpolation, json, lint, linter, pre-commit, redact, run, secret-scanner, secrets, typescript, yaml

## 简介

Lint, diff, sync, type, run, encrypt and protect your .env files — catch missing keys, duplicates, syntax slips, unresolved ${refs} and committed secrets; run commands with a merged env; encrypt/decrypt, compare environments, generate .env.example, export
