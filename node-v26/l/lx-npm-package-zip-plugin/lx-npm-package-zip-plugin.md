# lx-npm-package-zip-plugin

> 标签: JavaScript

## 简介

一个简单的webpack插件，该插件的功能是：将webpack输出的所有文件，打包压缩成一个zip压缩包，然后放进构建目录里。该插件接收一个配置参数filename，表示最终生成的压缩包文件名称。
