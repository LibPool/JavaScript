# langchain-lyceum

> 标签: agent-tools, ai-agent-infra, context-window, langchain, langchainjs, llm-cost-optimization, token-optimization

## 简介

Drop-in token compression for LangChain.js agents — wrap your tools and The Lyceum dedupes repeated reads, caps runaway output, and strips machine noise before it burns your context window.
