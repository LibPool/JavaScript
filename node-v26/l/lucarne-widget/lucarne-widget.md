# lucarne-widget

> 标签: browser, glassmorphism, iframe, injection, overlay, shadow-dom, widget

## 简介

The reusable glassmorphic in-page widget infrastructure: a shadow-DOM + sandboxed-iframe injector, a versioned identity-stamped envelope, a Node-side WidgetHost (push/onIntent/every), a framework-free iframe runtime (createWidget), an optional Preact adap
