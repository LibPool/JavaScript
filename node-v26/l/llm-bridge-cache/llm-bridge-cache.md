# llm-bridge-cache

> 标签: anthropic, api-bridge, cache, claude, glm, gpt, kimi, llm, moonshot, openai, openai-compatible, opencode, prompt-cache, prompt-caching, proxy, sillytavern

## 简介

A zero-dependency local API bridge for OpenAI, Anthropic, GLM (Z.ai), and Kimi (Moonshot AI). Accepts Chat Completions, Anthropic Messages, and OpenAI Responses formats, with prompt injection and prompt-cache keepalive.
