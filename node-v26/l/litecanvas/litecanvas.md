# litecanvas

> 标签: 2d, canvas, creative coding, game, gamedev, html5, javascript, js13k, micro, tiny

## 简介

Lightweight HTML5 canvas 2D game engine suitable for small projects and creative coding. Inspired by PICO-8 and p5.js/Processing.

## 官网

- 官网：https://litecanvas.js.org
- 源码仓库：git+https://github.com/litecanvas/game-engine.git
- npm 页面：https://www.npmjs.com/package/litecanvas
