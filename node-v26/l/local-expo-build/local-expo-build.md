# local-expo-build

> 标签: aab, android, apk, build, cli, eas, expo, gradle, ios, ipa, keystore, react-native, signing, xcodebuild

## 简介

One-stop CLI for local Expo builds. Android (stable) → AAB/APK with EAS-synced versionCode and managed signing. iOS (experimental, macOS) → IPA via xcodebuild with auto export-options.plist.
