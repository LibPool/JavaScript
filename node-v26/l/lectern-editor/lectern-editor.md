> 标签: agents, ai, ai-slides, chatgpt, claude, claude-code, coding-assistant, deck, drag-and-drop, google-slides-alternative, html-slides, keynote, llm, local-first, no-telemetry, offline, powerpoint-alternative, presentation, presentation-editor, reveal.js, revealjs, slide-editor, slides, visual-editor, wysiwyg

## 简介

Visual drag-and-drop editor for AI-generated slide decks. Ask Claude, ChatGPT or any coding agent for a presentation, then fix the layout yourself — the reveal.js HTML file is the document. Offline, no account, no telemetry.
