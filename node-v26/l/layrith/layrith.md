# layrith

> 标签: JavaScript

## 简介

LAYRITH CLI is a Bun-based natural language coding assistant that runs inside your terminal. It is built for interactive project work: reading code, editing files, resuming sessions, switching models, and working against OpenAI-compatible or Anthropic-com
