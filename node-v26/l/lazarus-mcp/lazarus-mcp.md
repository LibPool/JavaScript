# lazarus-mcp

> 标签: agent, ai, education, french, langage, lazarus, mcp, model-context-protocol

## 简介

Serveur MCP du langage LAZARUS : permet à n'importe quel agent IA (Claude, etc.) d'ÉCRIRE et d'EXÉCUTER du code LAZARUS pour de vrai — sortie console, dessins SVG, mémoire persistante.
