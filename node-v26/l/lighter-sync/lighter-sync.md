# lighter-sync

> 标签: animation, avatar, lip-sync, phoneme, text-to-speech, tts, viseme, web-audio

## 简介

Lightweight, zero-dependency lip-sync library for browser-based avatar animation. Synchronizes TTS audio with viseme keyframes using script-informed waveform analysis.
