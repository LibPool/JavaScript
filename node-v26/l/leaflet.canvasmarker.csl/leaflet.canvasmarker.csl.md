# leaflet.canvasmarker.csl

> 标签: JavaScript

## 简介

在Canvas上绘制Marker,而不是每个marker插件一个dom节点,极大地提高了渲染效率。主要代码参考自 https://github.com/eJuke/Leaflet.Canvas-Markers 和 https://gitee.com/panzhiyue/Leaflet-CanvasMarker
