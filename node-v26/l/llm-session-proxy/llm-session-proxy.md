# llm-session-proxy

> 标签: anthropic, claude-code, codex, header-injection, llm, local-proxy, openai, opencode, opencode-go, proxy, reverse-proxy, session-id, sse, trae, x-opencode-session

## 简介

A configurable local reverse proxy for LLM APIs: generates or forwards session IDs, injects arbitrary headers, and rewrites model aliases and request paths. Zero dependencies. Built so clients that cannot send a required session header (such as x-opencode
