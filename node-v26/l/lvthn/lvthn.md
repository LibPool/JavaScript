# lvthn

> 标签: aead, armor, binary, chacha20, cli, command-line, cross-platform, crypto, cryptography, encryption, file-encryption, key-derivation, keyfile, keygen, passphrase, scrypt, security, serpent, serpent-256, simd, stream-encryption, terminal, wasm, xchacha20, xchacha20-poly1305

## 简介

Command-line file encryption with paranoid-grade ciphers. Serpent-256-CBC and XChaCha20-Poly1305, WASM-SIMD accelerated, powered by leviathan-crypto.
