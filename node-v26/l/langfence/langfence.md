# langfence

> 标签: ai, chrome-ai, gemini-nano, guardrail, i18n, language, language-detector-api, llm, translator-api

## 简介

Client-side language guardrail for AI output in the browser. Detects and corrects language drift in LLM responses using Chrome's built-in Translator and Language Detector APIs.
