# linepay-offline-v2

> 标签: linepay, linepay-offline, nodejs, offline, 賴配

## 简介

a linepay  Node.js SDK for integrating Linepay Offline Payment API. 提供 Linepay 線下交易 API 封裝，支援付款、退款、取消、查詢等功能。
