# lading

> 标签: archive, arns, arweave, filecoin, ilp, mcp, toon, walrus, x402

## 简介

Archive broker for agents on TOON. One channel, several storage networks (Arweave, Walrus, Filecoin), every leg answers with the network's own receipt or buys nothing, and a signed bill of lading named on ArNS. Hosted behind an x402 door with an MCP shim
