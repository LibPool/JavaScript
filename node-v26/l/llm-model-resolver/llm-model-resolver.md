# llm-model-resolver

> 标签: claude, config, gemini, grok, llm, model, openrouter, resolver

## 简介

Resolve the current model ID for xAI, Anthropic, Gemini and OpenRouter at runtime. Config-file-driven: include/exclude patterns, pins, and fallbacks live in YAML/JSON, not in code.
