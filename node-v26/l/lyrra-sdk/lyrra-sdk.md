# lyrra-sdk

> 标签: cloudflare-workers, error-tracking, express, heartbeat, hono, lyrra, monitoring, nextjs, observability, rum, sdk

## 简介

Official Lyrra SDK — drop-in observability (errors / RUM / heartbeat) with one install. Works in browser, Node, Next.js, Express, Hono, and Cloudflare Workers.
