# language-loop

> 标签: agents, ai-agent, claude-code, codex, cursor, evals, i18n, internationalization, l10n, localization, next-intl, plugin, react-i18next, translation, vibe-coding, vue-i18n

## 简介

A localization loop for vibe-coding agents. Scans code, extracts i18n keys, translates only what changed, and automatically holds unsafe translations back.
