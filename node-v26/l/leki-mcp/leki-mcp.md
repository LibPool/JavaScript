# leki-mcp

> 标签: ai-agent, apteka, claude, drug-prices, leki, lista-lekow-refundowanych, mcp, medicines, model-context-protocol, nfz, open-data, poland, refundacja, zamienniki

## 简介

MCP server for Polish medicines: official prices of refunded drugs, patient co-payment, cheaper substitutes, free drugs for 65+/children/pregnant, prescription status and leaflets. No API key.
