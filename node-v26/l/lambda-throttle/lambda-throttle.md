# lambda-throttle

> 标签: aws, dynamodb, lambda, middy, nodejs, rate-limit, serverless, sqs, throttle

## 简介

Rate limiting for AWS Lambda functions with DynamoDB-backed persistence, per-key configurable limits, and SQS batch integration.
