# langgraph-inspector

> 标签: agent, ai, debugger, devtools, langchain, langgraph, langgraphjs, llm, state-graph, visualization

## 简介

Live terminal debugger and offline ASCII graph renderer for LangGraph.js — no LangSmith account, no network calls.
