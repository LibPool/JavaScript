# loopgen

> 标签: agents-md, ai-agents, attestation, audit, ci, claude-code, cli, codex, cursor, developer-tools, governance, loop-engineering, provenance, sigstore, slsa, supply-chain, typescript, verification

## 简介

The vendor-neutral verification & provenance gate for AI-generated code — bring your own agent. Local runs leave tamper-evident evidence; CI runs produce a verifiable, signed attestation (Sigstore/SLSA) you can gate merges on.
