# leakcheck

> 标签: chi-square, data-contract, data-drift, data-leakage, data-quality, drift, kolmogorov-smirnov, machine-learning, mlops, monitoring, psi, target-leakage, train-test-overlap, validation

## 简介

Leakage, drift and data contract checks for ML datasets in TypeScript - target leakage, train/test overlap and future-dated features; PSI, KS and chi-square drift between windows; schema, range, grain and freshness contracts; profiles and Markdown reports
