# logisheets-core

> 标签: excel, formula, headless, isomorphic, spreadsheet, typescript, workbook, xlsx

## 简介

UI-free LogiSheets logic — runs in the browser or on Node. Depends on logisheets-web only for types; the engine Client is injected by the host.
