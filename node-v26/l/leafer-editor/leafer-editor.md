# leafer-editor

> 标签: 2d, canvas, engine, graphic, html5, leafer, leafer editor, leafer-editor, leafer-ui, leaferjs, leaferui, renderer

## 简介

**leafer-editor** 在 [leafer-ui](https://github.com/leaferjs/leafer-ui) 的基础上，集成了 图形编辑器、视图控制 、滚动条、箭头、HTML 插件，适用于在线图形编辑的场景。
