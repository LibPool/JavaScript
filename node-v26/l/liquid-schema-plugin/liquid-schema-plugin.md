# liquid-schema-plugin

> 标签: liquid, shopify, webpack

## 简介

This plugin allows Shopify section schema to be imported from JavaScript or JSON files into Liquid sections. It is compatible with any Webpack based build system. This allows you to build partials that can be shared across multiple sections and applied in
