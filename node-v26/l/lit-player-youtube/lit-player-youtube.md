# lit-player-youtube

> 标签: lit, lit player youtube, lit youtube, lit-player, lit-player-youtube, lit-youtube, player, player youtube, react, react player, react youtube, youtube, youtube player

## 简介

LitPlayerYoutube is a lightweight and customizable Web Component built with Lit that provides a simple way to embed and control YouTube videos using the official YouTube API.
