# linkpeek-client

> 标签: favicon, link-preview, link-unfurl, metadata, oembed, og, opengraph, scraper, twitter-card, unfurl, url-preview

## 简介

Tiny zero-dependency client for the LinkPeek link preview & OpenGraph metadata API — title, description, images, favicon, feeds & oEmbed from any URL
