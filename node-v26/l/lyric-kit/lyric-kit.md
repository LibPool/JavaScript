# lyric-kit

> 标签: karaoke, krc, lrc, lyric, lyrics, parser, qrc, subtitles, ttml, yrc

## 简介

A lightweight, zero-dependency toolkit for parsing, serializing, and processing lyrics across multiple formats (LRC, TTML, QRC, YRC, KRC, LyS, SRT, ASS).
