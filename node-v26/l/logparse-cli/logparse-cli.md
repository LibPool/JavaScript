# logparse-cli

> 标签: analyze, apache, cli, filter, grep, json, log, nginx, parser, statistics, syslog, tail

## 简介

Parse, filter, and analyze log files from the terminal. Supports Apache, Nginx, JSON, and syslog formats with auto-detection, regex search, statistics, and colorized output.
