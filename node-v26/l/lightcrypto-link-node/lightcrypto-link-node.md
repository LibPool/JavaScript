# lightcrypto-link-node

> 标签: aes-256-gcm, alfe, blind-index, crypto, encryption, field-level-encryption, lightcrypto, mongodb, mongoose, sm4

## 简介

Lightweight application-level field encryption (ALFE) for Node.js/Mongoose and MongoDB with blind index, structured type encryption (DOC/COL/MAP), multi-KMS/SM-crypto support, and BSON format compatibility with the Java LightCrypto-Link ecosystem.
