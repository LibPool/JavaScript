# llm-sizer

> 标签: apple-silicon, benchmark, inference, linux, llm, mac, mlx, ollama

## 简介

Benchmark memory bandwidth, disk speed, and LLM inference performance (MLX on macOS, Ollama on Linux) to find the optimal model size
