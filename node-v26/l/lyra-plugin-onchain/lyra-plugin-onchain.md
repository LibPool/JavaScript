# lyra-plugin-onchain

> 标签: JavaScript

## 简介

The single on-chain plugin import for Lyra. Currently a v1 pass-through of lyra-plugin-onchain-one; the v2 (Wormhole bridge) half is deferred until it ships with npm-safe v1/v2 coexistence.
