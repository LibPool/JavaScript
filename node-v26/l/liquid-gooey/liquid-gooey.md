# liquid-gooey

> 标签: animation, gooey, liquid, metaball, react, spring, svg-filter

## 简介

Liquid UI effects for React: Morph (gooey merge, jelly shape change, contact dissolve), Move (liquid-rubber trails), Melt (two images running molten into each other) and Bend (bodies that bow with velocity). SVG-filter silhouette layer + crisp content lay
