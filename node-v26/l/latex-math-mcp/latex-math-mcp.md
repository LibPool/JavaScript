# latex-math-mcp

> 标签: claude, claude-code, cmyk, indesign, latex, math, mcp, model-context-protocol, opentype-math, pdf, spot-color

## 简介

MCP server that typesets LaTeX math with OpenType MATH fonts into placeable PDF (CMYK / spot colour), SVG and PNG, with baseline metrics
