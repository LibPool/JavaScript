# lanzap

> 标签: airdrop, cli, download, file-sharing, http-server, lan, local-network, qr, share, transfer, upload, wifi

## 简介

Share files and folders over your local network in one command. Starts a tiny Python server with a drag-and-drop web page, optional password.
