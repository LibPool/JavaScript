> 标签: abandoned, audit, cli, dependencies, dormant, lastseen, maintenance, mortality, npm, supply-chain

## 简介

Check your project's dependencies against the free lastseen.dev register — the "last seen alive" / mortality state of npm packages, MCP servers, and GitHub Actions. Zero runtime dependencies.
