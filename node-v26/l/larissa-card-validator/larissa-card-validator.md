# larissa-card-validator

> 标签: JavaScript

## 简介

** Esta biblioteca se destina a validação de cartões de credito, para uso em aplicações web. ** Na versão atual é capaz de fazer a verificação de validade de numero de cartões de credito atraves do numero passado como parametro.
