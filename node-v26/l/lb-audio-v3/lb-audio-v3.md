# lb-audio-v3

> 标签: PC, audio, component, components, mobile, player, ui, vue, vue3

## 简介

基于 Vue3 的音乐播放器小组件 拥有 播放/暂停、上/下一首、音量调节、播放顺序调节、歌词显示功能，后续将支持多种音频可视化特效，敬请期待...
