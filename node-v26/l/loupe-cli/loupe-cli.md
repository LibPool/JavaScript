# loupe-cli

> 标签: a11y, accessibility, axe, design, design-qa, lens, lighthouse, mcp, playwright

## 简介

loupe: deterministic design and accessibility detection with a real-browser render loop, exposed as an MCP server and WebSocket bridge for your CLI agent.
