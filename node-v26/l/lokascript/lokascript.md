## 简介

Name placeholder — LokaScript ships as @lokascript/semantic (multilingual parsing) on the @hyperfixi/core engine. In Vite projects, @hyperfixi/vite-plugin serves `import 'lokascript'` as a virtual module and this package is never loaded.
