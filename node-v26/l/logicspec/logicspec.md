# logicspec

> 标签: design, diagram, documentation, dsl, feature, mermaid, specification, workflow, yaml

## 简介

A small YAML DSL for describing application feature logic — validate it, visualize it with Mermaid, and use it as a behavioral source of truth for humans and AI coding agents.
