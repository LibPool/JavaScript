# lowstorage

> 标签: R2, S3, aws, cloudflare, database, db, digitalocean, edge, json, lambda, lowdb, minio, minio-s3, r2-s3, r2-worker, storage, wasabi, worker

## 简介

Simple, micro-dependency, pseudo-database using Apache Avro serialization on S3-compatible storages, inspired by lowdb.
