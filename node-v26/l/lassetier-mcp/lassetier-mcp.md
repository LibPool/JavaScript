# lassetier-mcp

> 标签: game-assets, isometric, lassetier, mcp, model-context-protocol, pixel-art

## 简介

MCP server for Lassetier — generate and convert game assets (isometric, top-down, pixel art) from AI agents like Claude Code.

## 官网

- 官网：https://lassetier.com/docs/api
- npm 页面：https://www.npmjs.com/package/lassetier-mcp

- npm registry：https://registry.npmjs.org/lassetier-mcp
