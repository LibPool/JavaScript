# labelixa

> 标签: barcode, cli, cpcl, epl, label, linter, printing, thermal-printer, tspl, zebra, zpl

## 简介

Render, validate and convert Zebra ZPL (and EPL/TSPL/CPCL) label code via the Labelixa API — SDK and CI-friendly CLI, no printer required.
