> 标签: collection, connector, database, db, db2, entity, framework, ibm, informix, light, management, microsoft, model, mongodb, ms, my, mysql, object, odm, oracle, orm, pdo, postgres, postgresql, propel, rdbms, redshift, relational, server, simple, sql, sqlite, system, typescript, wrapper

## 简介

Super simple ORM node.js wrapper for relational databases. It does not depends on any specific driver, so you can connect to mysql, ms server and so on... Try it!
