# lumalou

> 标签: ble, fisher-price, gld09, lumalou, reverse-engineering, web-bluetooth

## 简介

Local BLE protocol core for the Fisher-Price Lumalou (reverse-engineered MPID). Isomorphic: browser (Web Bluetooth) and Node.
