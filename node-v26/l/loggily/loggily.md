# loggily

> 标签: browser, bun, debug, json-logger, logger, logging, namespace, node, observability, optional-chaining, spans, structured-logging, tracing, typescript, zero-dependency

## 简介

Debugs, logs, and spans — one API. Disabled logs skip argument evaluation entirely via optional chaining. ~3KB, zero dependencies.
