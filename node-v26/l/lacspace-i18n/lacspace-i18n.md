# lacspace-i18n

> 标签: auto-sync, cli, convert, coverage, format-conversion, gettext, i18n, i18next, icu, icu-messageformat, internationalization, interpolation, json, l10n, locale, localization, messageformat, missing-keys, plural, po, properties, react-intl, select, sync, translation, translations, typescript, unused-keys, vue-i18n, yaml, zero-dependency

## 简介

Find missing, unused and untranslated locale keys, diff locales, validate ICU MessageFormat, convert between JSON/YAML/.properties/gettext .po, and auto-sync translations — a keyless i18n linter. Zero dependencies.
