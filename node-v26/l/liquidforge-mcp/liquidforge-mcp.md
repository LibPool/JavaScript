# liquidforge-mcp

> 标签: agent, claude, codex, cursor, liquid, liquidforge, mcp, model-context-protocol, shader, three, webgl

## 简介

MCP server for Liquidforge — recommends and renders liquid 3D looks, reads a site's colours, and writes the React component or a Webflow, Framer or HTML embed.
