# legion-init

> 标签: eslint, init, legion, oxlint, scaffold, setup

## 简介

The front door for LEGION-STANDARDS tooling: detects a repo's package manager, linter, framework and agents, then wires the Legion plugin, Prettier config, tsconfig and audit script without overwriting anything.
