# lumea-liquid-glass

> 标签: apple, backdrop-filter, button, component, frosted, glass, glassmorphism, liquid glass, liquid-glass, react, svg, ui, visionos

## 简介

Sculpted liquid glass for the web. One drop-in React button that works at any size and any shape — circle, pill, rounded, sharp, or per-corner radii. Zero CSS imports, SSR-safe, ~9 kB gzipped.
