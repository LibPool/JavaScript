# lizhi-web-sdk

> 标签: easinote, en, enow, live, lizhi, whiteboard

## 简介

互动白板开放平台 SDK 让您不用复杂的编程即可实现在线 ppt 等文档解析、课件预览、直播互动的能力，本文档主要介绍如何通过各平台 SDK 进行快速接入.
