# lingolint

> 标签: ci, cli, i18n, i18next, icu, internationalization, json, l10n, lint, linter, localization, placeholders, qa, translation, translations

## 简介

ESLint for app translations. Catch missing keys, broken placeholders, HTML mismatches and untranslated strings before they reach production.
