# llm-egress-guard

> 标签: anthropic, audit, budget, claude, cost-control, dlp, egress, llm, pii, privacy, redaction, secrets, typescript

## 简介

A fetch wrapper that inspects every prompt before it leaves the machine: redacts or refuses secrets and PII, enforces a spend budget, and writes down what was sent.
