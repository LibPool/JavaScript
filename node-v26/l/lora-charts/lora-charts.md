> 标签: angular, area-chart, bar-chart, charts, d3, data-visualization, gauge, heatmap, line-chart, pie-chart, scatter, svg, treemap, wordcloud, worldmap

## 简介

A modern Angular chart library built with D3.js — bar, line, area, pie, scatter, heatmap, treemap, gauge, word cloud, and world map components.
