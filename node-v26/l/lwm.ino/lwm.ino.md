# lwm.ino

> 标签: arduino, atmel, leo, pinoccio

## 简介

Atmel Lightweight Mesh for Arduino ---------------------------------- This is an Arduino port of the Atmel LWM network stack. Most of the code is taken as-is, with some small tweaks to make it work with the Arduino stack.
