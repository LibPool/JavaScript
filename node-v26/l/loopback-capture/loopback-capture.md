# loopback-capture

> 标签: audio, audio-capture, child-process, linux, loopback, low-level, napi, native, nodejs, pcm, per-process, pipewire, sound, system-audio, wasapi, windows, windows-audio

## 简介

A native N-API addon that delivers system or application audio as Node.js `Buffer` objects on Windows and Linux.
