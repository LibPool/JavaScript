# lucida-tagger

> 标签: audio, flac, metadata, tagging, vorbis

## 简介

Adding tags to audio files in JS (works in-browser). Currently only supports `flac` files, but ogg vorbis is planned. mp3 support may be added with a 3rd party dependency.
