# librsvg-prebuilt

> 标签: cairo, cross-platform, graphic, graphics, image, images, librsvg, prebuilt, render, rendering, renders, svg, windows

## 简介

Prebuilt librsvg binding. Parse SVG files and render them as PNG, PDF, SVG, or raw memory buffer images.
