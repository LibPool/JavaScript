> 标签: ai-search, chatgpt, claude, generative-engine-optimization, geo, linkaudit, mcp, model-context-protocol, perplexity, seo

## 简介

MCP server for LinkAudit — scan any website's AI-search visibility (ChatGPT, Perplexity, Gemini), get ready-to-paste fix files, and lint GEO/citability scores in CI.
