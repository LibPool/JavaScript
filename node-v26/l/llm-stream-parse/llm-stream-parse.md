# llm-stream-parse

> 标签: ai, anthropic, llm, openai, parser, server-sent-events, sse, streaming

## 简介

Parse streaming LLM responses (SSE/chunks) into clean text, JSON, and tool calls. Works with OpenAI, Anthropic, and any SSE stream.
