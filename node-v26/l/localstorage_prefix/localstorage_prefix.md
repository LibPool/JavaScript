# localstorage_prefix

> 标签: JavaScript

## 简介

- 在使用locastorage存储的时候为了避免命名的冲突，最好有一个命名空间的管理，可以加上前缀进行管理； - 封装了set和get的操作，并且支持直接传递对象进行存储 `_local.set('key_1', {a:1})`
