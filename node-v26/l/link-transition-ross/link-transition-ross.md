# link-transition-ross

> 标签: animation, animations, component, fade, link-transition, navigation, page-transition, react, react-component, react-router, react-router-dom, router, slide, transition, typescript, view-transition, zoom

## 简介

A React component and hook for animated page transitions using view transitions API. Supports fade, slide, and zoom effects for smooth navigation in React Router apps.
