# live-tweaks

> 标签: css-variables, custom-properties, design-system, design-tokens, devtools, live-editing, theming

## 简介

Live design-tweaks panel for your own running app: edit CSS design tokens in a floating panel, watch the UI update live, round-trip the changes back to source.
