# linearpress

> 标签: blog, cms, cordis, ejs, evarentha, express, linearpress, plugin, server-rendered, sqlite, typescript

## 简介

A server-rendered blogging system powered by TypeScript, Express 5, EJS and SQLite with a Cordis plugin architecture.
