# llm-orchestrator

> 标签: agents, claude-code, codex, kilo, llm, mcp, opencode, orchestration

## 简介

Write /task once — it plans the work, shards it across parallel subagents, gates every phase and verifies before claiming done. Claude Code, Codex, OpenCode, Kilo.
