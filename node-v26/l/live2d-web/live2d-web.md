# live2d-web

> 标签: avatar, cubism, lipsync, live2d, live2d-cubism, pixi-live2d-display, react, vtuber, webgl, webgl2

## 简介

Unofficial Live2D Cubism runtime for JavaScript and React. Brings its own WebGL2 renderer, no Pixi required.
