# litectx

> 标签: act-r, activation, blast-radius, bm25, code-graph, context, fts5, impact-analysis, local-first, recall, ripgrep, sqlite, tree-sitter

## 简介

Lite, local-first memory across kinds for AI agents: a code+context graph with ranked recall and impact (blast-radius) views, plus a write path for facts/episodes. SQLite + FTS5, tree-sitter + ripgrep edges, embeddings opt-in. CLI and stdio MCP server inc
