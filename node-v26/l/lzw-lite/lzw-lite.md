# lzw-lite

> 标签: Compression, IndexDB, Javascript, LZW, Lossless, Typescript, algorithim, js, ts

## 简介

A tiny, text-based LZW implementation for JS with built-in optimizations. Useful for IndexDB storage with minimal overhead.
