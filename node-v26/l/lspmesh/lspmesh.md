# lspmesh

> 标签: aggregator, biome, claude, claude-code, language-server, lsp, mcp, model-context-protocol, tailwindcss, typescript

## 简介

LSP aggregator + MCP server — fronts multiple language servers (TypeScript, Tailwind, Biome) behind one LSP/MCP endpoint.
