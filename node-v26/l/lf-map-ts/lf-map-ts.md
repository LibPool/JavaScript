# lf-map-ts

> 标签: JavaScript

## 简介

### 简介 这是一个基于Leaflet地图组件的TS封装。 注意：项目处于实验阶段，不能在产品环境中使用。 仅实现以下功能： + 加载行政区划geojosn。 + 鼠标悬浮高亮显示行政区域。 + 自定义边界、行政区域默认及行政区域高亮颜色。
