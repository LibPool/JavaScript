# lwc-jsconfigurer

> 标签: jsconfig, lightning-web-components, lwc, salesforce, sfdx, vscode

## 简介

Keep a Salesforce LWC project's jsconfig.json compilerOptions.paths in sync with the c/* imports actually used, so VS Code resolves every c/* import.
