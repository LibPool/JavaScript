# lily-design-system-svelte-picker-bar

> 标签: design, lily, locale, picker, picker-bar, share, svelte, system, text-size, theme

## 简介

Lily Design System Svelte 5 picker bar: composes theme-picker, locale-picker, text-size-picker, and share-picker into one page-header row. Headless, SSR-safe, no CSS.
