# lishellos

> 标签: android-style, desktop, launcher, terminal, textual, tui

## 简介

LishellOS - 终端里的手机桌面启动器：把 $PATH 指令变成应用图标，方向键启动、组合命令、搜索、翻页，Pixel 风格 4x4 桌面。
