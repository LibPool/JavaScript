# lit-search

> 标签: academic, arxiv, cli, crossref, dblp, doaj, europe-pmc, literature, openalex, papers, pubmed, research, search, semantic-scholar

## 简介

Academic literature search CLI and MCP server for Semantic Scholar, OpenAlex, arXiv, CrossRef, CORE, Europe PMC, DBLP, and DOAJ. Outputs reproducible metadata JSON, literature pool JSON, and BibTeX. MCP tools: search_literature, get_paper, resolve_citatio
