# logpilot-node

> 标签: error-tracking, express, logging, logpilot, monitoring, observability

## 简介

Zero-dependency Node.js SDK for LogPilot AI. Captures unhandled exceptions and Express.js errors and reports them asynchronously to the LogPilot backend.
