# lib2027

> 标签: claude, documentation, knowledge-base, llm, mcp, rag, search

## 简介

Local knowledge library for people and AI agents: drop in a folder, search by meaning + morphology + exact API names; web UI and MCP server for Claude Code, pi and others. Single Rust binary, no Python, no database; GPU or CPU.
