# logsphere

> 标签: dashboard, express, logger, logging, middleware, monitoring, rotating-logs, structured-logging

## 简介

A ready-to-use, professional Node.js logging system with a built-in web dashboard, log rotation, sensitive data redaction, and beautiful console output.
