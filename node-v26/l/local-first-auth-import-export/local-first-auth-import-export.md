# local-first-auth-import-export

> 标签: authentication, backup, decentralized-identity, did, export, import, keypair, local-first, local-first-auth, web-app

## 简介

Import and export a Local First Auth profile (public + private keypair) as a portable JSON file. Lets users bring an existing identity into a mini app, or back one up, instead of creating a new profile.
