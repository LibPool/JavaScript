# loopeix

> 标签: ai-agents, claims-check, claude-code, cli, code-review, codex, evidence, local-first, provenance, receipts, signed-receipts, verification

## 简介

Design, run, and verify repeatable AI work loops locally, with tamper-evident evidence and truthful reports. Flagship add-on: the Claims Check, a lie detector for agent pull requests with signed, offline-verifiable receipts.
