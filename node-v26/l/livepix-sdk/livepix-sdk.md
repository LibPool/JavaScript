# livepix-sdk

> 标签: livepix, npm, sdk

## 简介

O **LivePix SDK** permite uma integração fácil e eficiente com a API LivePix, oferecendo suporte para TypeScript e Node.js. Com ele, você pode gerenciar contas, pagamentos, transações, saldos e muito mais.
