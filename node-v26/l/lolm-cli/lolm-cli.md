# lolm-cli

> 标签: agent, ai, byok, cli, coding-agent, llm, local-first, lolm, nfet, terminal-ui

## 简介

Open-source local computer-use agent: full-screen terminal with live streaming, stoppable tasks, a visible plan, inline diffs, context compaction, 60+ typed tools, provider-agnostic BYOK, and real LOLM-NFET control.
