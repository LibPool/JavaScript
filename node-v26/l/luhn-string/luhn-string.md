# luhn-string

> 标签: before, checksum, invalid, luhn, next, random, string, valid, validate

## 简介

A library to generate strings that end with a checksum 'digit'. Digits in the string are in the range 0-9B-DF-HJ-NP-TV-XZ. All uppercase.
