# localmd

> 标签: cli, editor, local, markdown, notes

## 简介

A local markdown editor with live preview, toolbar formatting, and folder-backed .md file storage. No install, no build step, no internet needed after install.

## 官网

- npm 页面：https://www.npmjs.com/package/localmd
