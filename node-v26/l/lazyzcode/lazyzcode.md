# lazyzcode

> 标签: agent-workflow, ai-coding, cli, coding-agent, developer-tools, discipline, evidence, goal-loop, plan-gate, plugin, zcode

## 简介

AI coding-workflow discipline layer for ZCode: plan, execute, take evidence, never stop half-done. Plugin + lightweight CLI (lzy).
