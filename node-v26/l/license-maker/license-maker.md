# license-maker

> 标签: apache, bsd, cli, devtools, generator, gpl, license, mit, open-source, oss

## 简介

Generate LICENSE files from the command line. Supports MIT, Apache-2.0, GPL-3.0, BSD-2, BSD-3, ISC, MPL-2.0, Unlicense, and more.
