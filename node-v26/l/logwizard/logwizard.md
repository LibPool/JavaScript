# logwizard

> 标签: access-logs, console-logger, custom-logger, debug-logger, error-logs, file-logger, log-rotation, logger, logging, nodejs

## 简介

A lightweight Node.js logging utility with file logging, daily log rotation, console output, and customizable separators.
