# lingshu-nodejs-sdk

> 标签: JavaScript

## 简介

这是LingShuChain客户端的NodeJS SDK，提供了访问LingShuChain节点的NodeJS API，支持节点状态查询、部署和调用合约等功能，基于NodeJS SDK可开发区块链应用。

## 官网

- npm 页面：https://www.npmjs.com/package/lingshu-nodejs-sdk

- 1.0.0

## 获取地址
