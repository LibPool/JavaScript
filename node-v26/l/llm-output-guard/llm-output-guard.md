# llm-output-guard

> 标签: ai, degenerate, fallback, guardrails, llm, reliability, resilience, retry, validation

## 简介

Detect degenerate LLM output that arrives with a 200 OK. Zero dependencies, deterministic, composes with any retry or fallback layer.
