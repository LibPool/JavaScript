# lacspace-size

> 标签: baseline, brotli, brotli-size, build-size, bundle-analyzer, bundle-composition, bundle-size, bundlesize, ci-gate, cli, compression, dist-size, fail-over, file-size, glob, gzip, gzip-size, markdown-report, pr-comment, regression, size-breakdown, size-budget, size-diff, size-limit, size-report, size-summary, sizerc, treemap, typescript, zero-dependency

## 简介

Measure build-output & bundle size as raw + gzip + brotli, enforce size budgets in CI, diff against a saved baseline, break a bundle down into a byte-composition treemap, and post a PR-comment size table. Zero dependencies.
