# line-diff-wasm

> 标签: JavaScript

## 简介

The goal of this project is to generate a diff between two source texts which can be used to render an editor's "gutter" markers. It generates "add", "remove", and "modify" markers similar to those rendered in most modern IDEs for git diffs.
