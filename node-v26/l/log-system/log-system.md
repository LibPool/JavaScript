# log-system

> 标签: JavaScript

## 简介

描述：前端日志上传系统，      数据缓存使用indexDB，      发布使用XHR（XMLHttpRequest），      采用操作循环队列————依次存/取DB操作      可选择webworker进行日志相关的操作。目的是减少对主程序的影响。
