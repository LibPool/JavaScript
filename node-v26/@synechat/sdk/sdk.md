# @synechat/sdk

> 标签: JavaScript

## 简介

Cliente ESM oficial para backends Node.js e Bun. `Client` / `RestClient` usam a API pública `/api/v1/bot`; `OAuthClient` usa `/api/v1/oauth2` para consentimento de pessoas.
