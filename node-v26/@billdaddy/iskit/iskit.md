# @billdaddy/iskit

> 标签: is, isempty, isplainobject, isstring, predicate, runtime-type, type-guard, type-narrowing, typescript, validation, zero-dependency

## 简介

Tiny, type-safe predicates — isString/isNumber/isPlainObject/isEmpty and more, all narrowing TypeScript type guards. Zero dependencies.
