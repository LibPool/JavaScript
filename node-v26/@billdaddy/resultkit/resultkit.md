# @billdaddy/resultkit

> 标签: either, error-handling, maybe, monad, neverthrow-alternative, option, result, rust, trycatch, type-safe, typescript, zero-dependency

## 简介

Tiny, type-safe Result and Option for TypeScript — fluent methods, .ok/.some narrowing, tryCatch/tryCatchAsync, and combinators. Zero dependencies.
