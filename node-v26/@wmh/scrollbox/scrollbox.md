> 标签: carousel, es6, jquery, marquee, modern, no-dependencies, scroll, scrollbox, scroller, ticker, typescript, vanilla-javascript, vanilla-js, zero-dependencies

## 简介

Modern vanilla JavaScript scrollbox plugin for carousels and marquees. Zero dependencies. jQuery wrapper included for backward compatibility.
