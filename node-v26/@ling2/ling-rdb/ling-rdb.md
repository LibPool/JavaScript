# @ling2/ling-rdb

> 标签: cordis, dameng, database, kingbase, kysely, migration, mybatis-plus, mysql, oracle, orm, postgres

## 简介

Relational database hub for cordis-based hosts: named database registry, migrateRdb versioned DDL runner, MyBatis-Plus-style semantic layer (mbp), a Kysely statement-builder layer (orm), dialect rendering kit, and mysql/postgres/oracle/dm/kingbase provide
