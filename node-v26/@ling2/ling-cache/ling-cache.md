# @ling2/ling-cache

> 标签: cache, cachekey, cordis, distributed-lock, ioredis, redis, ttl

## 简介

Cache hub for cordis-based hosts: named cache-store registry with TTL semantics, the verbatim Ling CacheKeyUtil key replica, an in-memory store, a distributed lock, and an ioredis-backed provider.
