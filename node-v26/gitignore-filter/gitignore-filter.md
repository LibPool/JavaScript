# gitignore-filter

> 标签: e18e, fdir, git, gitignore, glob, globby, ignore, prettierignore, tinyglobby

## 简介

Respect .gitignore (and .prettierignore, etc.) exactly like git does, with tinyglobby, fdir or fs.glob. Tested against git itself.
