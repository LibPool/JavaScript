# @cubiczan/agent-governance

> 标签: ai-agents, audit-ledger, compliance, governance, hitl, risk-policy

## 简介

Governance and audit layer for AI agents that move capital: canonical risk policy engine, CHP decision gate with HITL, and a signed append-only audit ledger.
