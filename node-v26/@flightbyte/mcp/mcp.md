# @flightbyte/mcp

> 标签: ai, aviation, flight-status, flight-tracking, flightbyte, flights, mcp, mcp-server, model-context-protocol, webhooks

## 简介

MCP server for FlightByte, the flight status API with signed webhooks: look flights up, watch them with webhook subscriptions, and search the docs from any AI assistant.
