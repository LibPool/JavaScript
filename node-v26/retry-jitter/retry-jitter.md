# retry-jitter

> 标签: abort, abortsignal, async, backoff, exponential-backoff, fetch, jitter, promise, retry

## 简介

Retry async functions with exponential backoff, jitter, and AbortSignal support. Zero dependencies, fully typed, ESM + CJS.
