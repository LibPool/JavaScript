# uidna-schema

> 标签: design-tokens, json-schema, reverse-engineering, schema, ui, zod

## 简介

The UI DNA document schema: Zod schema, JSON Schema and TypeScript types for describing a user interface down to the token, the component and the state transition, with provenance on every value.
