# use-nigeria-location-state-coordinate

> 标签: Airports, Capital, Geo Political Zone, LGAs, Land Mass, Nigeria, States, Universities

## 简介

A lightweight utility for Nigerian states, LGAs, and coordinates. Custom hooks that provides you the list of all States, LGAs, Airports, Universities in Nigeria.
