# universal-context-mode

> 标签: ai-tools, claude-code, compression, context-window, copilot, cursor, mcp, model-context-protocol, windsurf

## 简介

Stop losing context to large outputs — MCP server that compresses tool outputs. Works everywhere: Claude Code, Cursor, Windsurf, Copilot, and any MCP-compatible IDE.
