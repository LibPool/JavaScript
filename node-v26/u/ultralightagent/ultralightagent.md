# ultralightagent

> 标签: agent, ai, cli, mcp, mcp-bridge, mcp-server, model-context-protocol, serverless, stdio, tool-discovery, ultralight, ultralightagent

## 简介

Ultralight — local stdio MCP bridge + CLI. Connect any computer-access agent (Claude Code, Claude Desktop, Cursor) to the Ultralight platform, with local filesystem tools, plus build/deploy/manage Agents from your shell.
