# uk-land-registry-mcp

> 标签: conveyancing, hmlr, house-price-index, inspire, land-registry, mcp, model-context-protocol, open-data, price-paid, property, uk

## 简介

MCP server for HM Land Registry open data: sold prices, UK House Price Index, corporate and overseas property ownership, INSPIRE title boundaries and due-diligence flags.
