# usesteady

> 标签: ai-workflow, approval-gate, ci-cd, developer-cli, human-in-the-loop, long-running-workflows, resume-token, survivable-execution, workflow-inspection, workflow-runner

## 简介

Inspect workflows before execution. UseSteady inspects a workflow, shows the exact SYSTEM WILL operation, and waits for approval before each interactive step. Resume from a visible token without inheriting prior approval.
