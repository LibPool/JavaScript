# uicean

> 标签: a11y, accessible, combobox, command-palette, component-library, components, dark-mode, data-table, datepicker, design-system, headless, react, react-19, registry, shadcn, tailwind-v4, tailwindcss, typescript, ui, ui-kit

## 简介

A flat, shadow-free React 19 + Tailwind CSS v4 design system. 96 components and 82 icons — forms, tables, popovers, sheets, comboboxes, a calendar and a command palette — light and dark, five accent themes, one --radius token.
