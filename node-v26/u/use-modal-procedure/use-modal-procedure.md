> 标签: async, async-await, await, confirm-dialog, dialog, discriminated-union, frontend, headless, hooks, modal, modal-hook, multi-step, procedure, promise, promise-modal, react, react-hook, react-hooks, typescript, ui-patterns, use-modal, wizard

## 简介

Headless React hook to await modal results with async/await. Multi-step yields, typed ProcedureResult, zero dependencies. No provider required.
