# userstory-playwright-skill

> 标签: agent-skills, claude-code, codex, copilot, e2e, excel, kilocode, opencode, playwright, qa, testing, user-stories

## 简介

Agent skill that derives user stories from a website codebase into Excel, tests them with Playwright, and writes bugs back into the sheet. Works with Claude Code, Codex, Kilo Code, OpenCode and GitHub Copilot CLI.
