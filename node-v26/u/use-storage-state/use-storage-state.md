# use-storage-state

> 标签: Storage, hook, hooks, local storage, localStorage, persistent, react, session storage, sessionStorage, state, store, useState

## 简介

React hook that you can wire with any Storage compatible API like `localStorage`, `sessionStorage`, or a custom one.
