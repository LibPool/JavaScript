> 标签: audit, cli, dependencies, dependency-management, devdependencies, interactive, npm, npm-audit, npm-outdated, outdated, overrides, package-manager, security, semver, terminal, tui, update, upgrade, upgrade-interactive, vulnerabilities, vulnerability, yarn

## 简介

An interactive dependency upgrader for npm projects, inspired by `yarn upgrade-interactive` (Yarn Berry / Yarn 4), with built-in vulnerability warnings.
