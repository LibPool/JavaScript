# unlose

> 标签: ai-agents, backup, claude-code, cli, codex, developer-tools, end-to-end-encryption, recovery, restore, session

## 简介

Encrypted backup and native recovery for Claude Code and Codex sessions. Get a session back after an update wipe, a reinstall, or a dead laptop.
