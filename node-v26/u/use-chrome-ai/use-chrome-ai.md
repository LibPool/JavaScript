# use-chrome-ai

> 标签: ai, built-in-ai, chrome, edge, gemini-nano, llm, on-device, prompt-api, summarizer, translator

## 简介

Headless, framework-agnostic primitives for the browsers' built-in AI APIs in Chrome and Edge (Prompt, Summarizer, Writer, Rewriter, Proofreader, Translator, Language Detector). Zero dependencies.
