# umi-request-progress

> 标签: XMLHttpRequest, ajax, axios, download progress, fetch, middleware, progress, umi-request, umi-request middleware, umi-request 中间件, upload progress, 上传进度, 下载进度, 中间件, 网络请求

## 简介

umi-request-progress 是 网络请求库 umi-request 的一个内核中间件，扩展了 umi-request 使其支持 上传进度 和 下载进度
