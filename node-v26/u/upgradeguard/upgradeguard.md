# upgradeguard

> 标签: adb, android, apk, cli, e2e, maestro, migration, regression, testing, upgrade

## 简介

Find Android bugs that only happen when existing users update your app. Installs the old APK, builds real user state with Maestro, upgrades in place with adb install -r, and reports whether the upgrade is safe.
