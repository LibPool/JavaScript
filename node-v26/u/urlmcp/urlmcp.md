# urlmcp

> 标签: ai-tools, code-generation, llm, mcp, mcp-server, model-context-protocol, scraper

## 简介

Self-contained MCP server that turns any website into a runnable MCP server, in-process. Host-as-brain by default (no API key); optional OpenAI/Anthropic/Gemini/Groq/Ollama/... or a custom inference URL.
