# ugc-vz-mcp

> 标签: creator, dach, germany, influencer, mcp, modelcontextprotocol, ugc

## 简介

MCP stdio bridge to the UGC VZ creator directory (DACH) - search real UGC creators, inspect profiles, trigger brand outreach. Free, no API key.
