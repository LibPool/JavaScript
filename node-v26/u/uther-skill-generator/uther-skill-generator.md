# uther-skill-generator

> 标签: ai-agents, anthropic, claude, cli, developer-tools, gemini, generator, skills

## 简介

CLI instalável globalmente que abre uma interface web local para gerar skills de agentes de IA (Claude, Antigravity, etc.) com streaming ao vivo.
