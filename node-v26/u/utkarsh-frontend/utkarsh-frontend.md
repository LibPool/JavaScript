# utkarsh-frontend

> 标签: cli, react, scaffold, shadcn, tailwind, typescript, vite

## 简介

Scaffold a React + Vite + TypeScript app with Tailwind, shadcn/ui, zustand, react-hook-form, react-router-dom and TanStack Query pre-installed.
