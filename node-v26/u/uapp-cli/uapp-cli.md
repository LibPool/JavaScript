# uapp-cli

> 标签: mobile, uapp, uniapp, vue

## 简介

fork自，uapp源自跨平台开发的最佳实践。uapp通过集成 uni-app, electron, tauri，让开发者仅需维护一套代码，就能横扫所有平台。用uapp可以无限制重构一切软件。
