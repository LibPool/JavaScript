## 简介

Framework-agnostic agent skill loader, shipping the ux-expert-rakibulism skill. Drop-in for Claude Agent SDK, LangChain, OpenAI Assistants, CrewAI, AutoGen, Cursor, AGENTS.md-compatible tools (Codex/OpenCode/Antigravity), and any AI agent runtime.
