# uemoa-bank-resolver

> 标签: afrique, bank, bank-lookup, bceao, benin, bic, burkina, cote-divoire, guinee-bissau, iban, iban-validation, mali, niger, rib, senegal, togo, uemoa, umoa, west-africa

## 简介

Identify the bank behind any UEMOA / BCEAO IBAN or RIB (Bénin, Burkina, Côte d'Ivoire, Guinée-Bissau, Mali, Niger, Sénégal, Togo). Validation, decomposition and offline bank lookup. Zero runtime dependencies.
