# uic-form3

> 标签: data conversion, data input, data output, event handling, form, jquery plugin, modified state, valid state

## 简介

uicForm3 is a jQuery plugin, that manages data input and output between html forms and javascript, triggers several events on data modification and validation and allows to reset, wipe and clear the form. uicform3 is compatible with any kind of form struc
