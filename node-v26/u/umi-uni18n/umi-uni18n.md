# umi-uni18n

> 标签: JavaScript

## 简介

删除项目中所有的 FormattedMessage 和 formatMessage，并将其替换，如果从 locale 中读取到了 id，将使用 locale 中。如果没有使用 defaultMessage，两者都不存在将会将 id 替换到项目中。
