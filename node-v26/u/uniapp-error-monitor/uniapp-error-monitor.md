# uniapp-error-monitor

> 标签: error, error-handling, error-reporting, javascript, monitor, tracking, uniapp, vue3, wechat-miniprogram

## 简介

专门为UniApp环境设计的错误监控和上报工具，支持全局错误捕获、Promise错误捕获、网络错误捕获等
