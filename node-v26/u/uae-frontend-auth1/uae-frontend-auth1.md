# uae-frontend-auth1

> 标签: JavaScript

## 简介

Makes use of the following APIs: - **/user/device** for device uuid creation - **/user/visit** for visit creation - **/user/ip** for session verification and ip data retrieval - **/user/enquiries** for enquiry data retrieval
