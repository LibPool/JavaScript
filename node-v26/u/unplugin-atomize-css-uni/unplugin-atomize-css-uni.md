# unplugin-atomize-css-uni

> 标签: JavaScript

## 简介

此插件为了解决 `uniapp` 中使用 `TailwindCSS` 或 `UnoCSS`，遇到原子化 css 语法编译到微信小程序 `wxss`，不支持`\[`、`\]`、`#`、`:`、`%`的问题,会将这些不能被 `wxss` 识别的 `class` 转换成以下的形式
