# unspoken

> 标签: array, arrayify, compress, contract, decompress, deserialize, game, messagepack, msgpack, network, object, object-to-array, schema, serialize, server, socket, uncompress

## 简介

Pack network messages more efficiently. Compress keyed objects into keyless arrays. Decompress arrays back into usable objects.
