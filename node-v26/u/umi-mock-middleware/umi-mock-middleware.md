# umi-mock-middleware

> 标签: JavaScript

## 简介

umi-mock-middleware是从umi代码中单独摘取出了mock中间件相关的独立代码，使之可以在React之外的环境，比如Vue中使用。功能更独立，更专一，使用更方便。

## 官网

- 源码仓库：https://gitee.com/li-xiaoyin/easy-mock-node.git
- npm 页面：https://www.npmjs.com/package/umi-mock-middleware
