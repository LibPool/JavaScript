# unlock-abi-0-1

## 简介

The ABI (application binary interface) for version 0.1 of Unlock-protocol's PublicLock and Unlock contracts. This is mostly an upgrade on V0 with the addition of ERC721 compatibility. These are built out of commit 90d2192c inside the main unlock repositor
