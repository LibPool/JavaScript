# @plinthjs/vite-plugin

> 标签: framework, laravel, mason, typescript, vite-plugin

## 简介

Mason Vite plugin: the laravel-vite-plugin equivalent: input entries, build manifest, dev hot file, and full-reload refresh. Pairs with @plinthjs/vite.
