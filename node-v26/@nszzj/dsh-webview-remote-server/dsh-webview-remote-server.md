# @nszzj/dsh-webview-remote-server

> 标签: deepseek-harness, dsh, dsh-plugin, proxy, remote, webview

## 简介

A password-protected LAN entry point for DSH — an authenticated reverse proxy plus a Settings panel, so a phone or tablet can use your DSH over the local network. Companion client: github.com/ns-zzj/dsh-webview-remote
