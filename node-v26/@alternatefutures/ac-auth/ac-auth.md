# @alternatefutures/ac-auth

> 标签: alternate-clouds, oauth2, oidc, openid-connect, pkce, sign-in

## 简介

Sign in with Alternate Clouds, framework-free: OpenID Connect discovery, PKCE, token exchange, single-flight refresh with rotation, a JWKS cache that survives issuer outages, session grace, typed claims and the device flow.
