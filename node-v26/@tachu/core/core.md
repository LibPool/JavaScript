# @tachu/core

> 标签: agent, agentic, ai, bun, dag, engine, llm, orchestrator, registry, scheduler, tachu, typescript

## 简介

Agentic engine core (release candidate) — descriptor registry, 9-phase execution pipeline, prompt assembler, task scheduler, safety & observability modules, with built-in direct-answer and tool-use (agentic loop) sub-flows.
