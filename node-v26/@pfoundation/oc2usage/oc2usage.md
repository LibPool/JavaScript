# @pfoundation/oc2usage

> 标签: opencode, opencode-plugin

## 简介

OpenCode plugin that shows provider usage limits (Anthropic Claude, Grok, OpenCode Go, Meta, OpenAI) in the TUI footer and a /usage dialog
