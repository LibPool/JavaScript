# @extol-work/notary

> 标签: ans, attestation, ed25519, extol, notary

## 简介

TypeScript reference implementation of the Attestation Notary Specification (Notary Spec) v0.2.1, Layers 1 and 2. Canonical byte serialization, RFC 8785 payload hashing, Ed25519 PureEdDSA signature verification. Ported from github.com/extol-work/notary @
