# @rayspec/adapter-openai-tts

> 标签: JavaScript

## 简介

The OpenAI text-to-speech adapter behind the provider-neutral [`@rayspec/tts-port`](https://github.com/rayspec-labs/rayspec/tree/main/packages/kernel/tts-port) contract: one REST call to `/v1/audio/speech`, no provider SDK, the credential resolved lazily
