# @babelkit/mcp-server

> 标签: babelkit, claude, claude-code, cursor, i18n, localization, mcp, model-context-protocol

## 简介

BabelKit MCP server — connect Claude Code, Cursor, Windsurf, and other MCP clients to BabelKit for end-to-end localization (extract, push, translate, pull) without leaving the editor
