# @pritam_awatade/lazy-ui

> 标签: JavaScript

## 简介

LazyUI is a modern UI library focused on creating glowing and animating components to enhance your web applications. Our goal is to provide developers with visually appealing and interactive components that are easy to integrate and customize.
