# @huiliyi37/dsh-sdk-client

> 标签: JavaScript

## 简介

TypeScript client SDK for driving a Tianshu Harness runtime subprocess over stdio JSON-RPC: the DeepSeekHarness high-level turns API and the lower-level HarnessClient
