# @upstash/agentkit-eve-extension

> 标签: agent, ai, chat-history, eve, extension, memory, redis, search, upstash, vercel

## 简介

Upstash AgentKit as an eve extension: long-term memory tools, Redis Search tools, and searchable durable chat history on Upstash Redis — mounted with one file.
