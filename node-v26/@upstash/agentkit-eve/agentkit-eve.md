# @upstash/agentkit-eve

> 标签: agent, ai, box, cache, eve, memory, sandbox, tools, upstash, vercel

## 简介

Upstash AgentKit adapter for the Vercel Eve agent framework: memory tools, an Upstash Redis memory backend and provider for eve memory slots, Redis-Search tools, a rate-limit gate, an Upstash Box sandbox backend, and cached tools.
