# react-native-nfc-locator

> 标签: android, antenna, ios, nfc, react-native, turbomodule

## 简介

Shows where a phone's NFC antenna is, with an explicit confidence level. TypeScript resolver chain, React Native UI and a TurboModule for platform signals.
