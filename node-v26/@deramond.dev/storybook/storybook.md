# @deramond.dev/storybook

> 标签: deramond, design-system, storybook-addon, storybook-theme

## 简介

A Storybook addon that puts the manager and the docs pages on @deramond.dev/tokens: one dark theme, self-hosted fonts, the site's own brand title and mark.
