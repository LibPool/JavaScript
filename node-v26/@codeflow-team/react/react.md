# @codeflow-team/react

> 标签: agent, codeflow, elkjs, graph, monaco-editor, react, react-flow, visual-programming, workflow, xyflow

## 简介

React canvas for CodeFlow graphs — React Flow nodes with ELK hierarchical layout, node inspector, Monaco code panel and diagnostics, wired to the core patch engine.
