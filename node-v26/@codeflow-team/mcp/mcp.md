# @codeflow-team/mcp

> 标签: adapter, agent, codeflow, json-schema, mcp, model-context-protocol, tools

## 简介

Turn MCP tool schemas into CodeFlow ToolDefinitions — safe name slugging, cursor paging, inline $ref resolution. Zero runtime dependency on the MCP SDK.
