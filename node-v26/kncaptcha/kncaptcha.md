# kncaptcha

> 标签: anti-bot, bot-protection, captcha, equihash, pow, privacy, proof-of-work, typescript, vue

## 简介

Privacy-friendly proof-of-work captcha: memory-hard Equihash puzzles solved in the browser, verified in microseconds by the server. Vanilla JS widget and Vue 3 component.
