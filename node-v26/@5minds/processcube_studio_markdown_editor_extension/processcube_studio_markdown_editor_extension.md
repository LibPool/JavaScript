# @5minds/processcube_studio_markdown_editor_extension

> 标签: JavaScript

## 简介

Die Markdown File Editor Extension ist eine Erweiterung für das ProcessCube Studio, die es ermöglicht Markdown Dateien im Studio über den Solution Explorer auszuwählen und direkt im Studio zu bearbeiten.
