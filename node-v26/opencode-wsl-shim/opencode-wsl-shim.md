# opencode-wsl-shim

> 标签: opencode, opencode-plugin, toolchain, windows, wsl, wsl2

## 简介

opencode plugin: route toolchain calls (git, cargo, node, python, ...) to native Windows .exe binaries when running inside WSL — workspace-aware, per-tool config, automatic fallback
