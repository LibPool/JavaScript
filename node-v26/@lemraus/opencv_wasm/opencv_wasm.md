# @lemraus/opencv_wasm

> 标签: opencv, wasm

## 简介

OpenCV WASM binaries built from OpenCV 3.4.5 source files and Emscripten. ALLOW_MEMORY_GROWTH is enabled and USE_PTHREADS is disabled.
