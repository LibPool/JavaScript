# @sipgate/ai-flow-sdk

> 标签: ai-flow, ai-phone-assistant, api, communication, conversational-ai, gdpr, real-time, sdk, sipgate, speech-to-text, telephony, text-to-speech, typescript, voice, voice-agent, voice-ai, voicebot, webhook, websocket

## 简介

Official TypeScript SDK for sipgate flow — the GDPR-compliant, EU-hosted real-time voice and telephony layer for AI phone agents. Connect phone calls to your own AI agents (speech-to-text, text-to-speech, instant barge-in).
