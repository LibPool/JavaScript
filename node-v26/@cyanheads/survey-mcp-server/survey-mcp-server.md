# @cyanheads/survey-mcp-server

> 标签: agent, ai, ai-agent, authentication, cloudflare-workers, conversational-surveys, data-collection, declarative-tools, dependency-injection, error-handling, hono, llm-integration, mcp, mcp-server, model-context-protocol, multi-tenancy, observability, opentelemetry, skip-logic, survey, survey-platform, typescript, zod

## 简介

Transform LLMs into intelligent interviewers. MCP server for conducting dynamic, conversational surveys with structured data collection. Features skip logic, session resume, multi-tenancy, and pluggable storage backends.
