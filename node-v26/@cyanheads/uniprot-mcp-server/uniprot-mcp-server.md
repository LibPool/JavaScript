# @cyanheads/uniprot-mcp-server

> 标签: ai-agent, annotation, bioinformatics, bun, id-mapping, mcp, mcp-server, model-context-protocol, protein, proteome, proteomics, sequence, stdio, streamable-http, swiss-prot, taxonomy, typescript, uniprot, uniprotkb

## 简介

Search UniProtKB by protein function, fetch curated records, map IDs across databases, and pull reference proteomes, taxonomy, and sequences via MCP. STDIO or Streamable HTTP.
