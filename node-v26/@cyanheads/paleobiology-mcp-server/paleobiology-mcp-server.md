> 标签: ai-agent, biodiversity, bun, deep-time, fossils, geologic-time, mcp, mcp-server, model-context-protocol, paleobiology, paleontology, pbdb, stdio, streamable-http, typescript

## 简介

Search fossil occurrences, resolve taxon fossil ranges, plot diversity through deep time, and look up the geologic time scale via MCP. STDIO or Streamable HTTP.
