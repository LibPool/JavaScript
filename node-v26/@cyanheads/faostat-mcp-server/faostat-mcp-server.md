# @cyanheads/faostat-mcp-server

> 标签: agricultural-statistics, agricultural-trade, agriculture, bun, crop-production, dataframe, duckdb, fao, faostat, food-balances, food-security, mcp, mcp-server, model-context-protocol, sqlite, stdio, streamable-http, typescript

## 简介

Global food & agriculture statistics from the UN FAOSTAT bulk-download corpus, served from a local SQLite mirror with a DataCanvas SQL surface, via MCP. STDIO or Streamable HTTP.
