# @netkitty/analysis

> 标签: deep-packet-inspection, dpi, flow, flow-analysis, follow-tcp-stream, netkitty, network, network-analysis, packet-analysis, pcap, stream-reassembly, tcp, tcp-stream, wireshark

## 简介

Streaming cross-packet network analysis over the netkitty codec: TCP stream reassembly, flow tracking and Wireshark-style follow-stream, off a worker.
