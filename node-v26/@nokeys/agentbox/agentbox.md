# @nokeys/agentbox

> 标签: access-control, ai-agents, claude-code, credential-broker, cursor, github, gitlab, identity, security

## 简介

AgentBox by NoKeys: everything your agent needs, nothing it shouldn't have. A governed workspace for AI agents with identity, policy, approvals, and audit; credentials never enter the workspace.
