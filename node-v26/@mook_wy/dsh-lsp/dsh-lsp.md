# @mook_wy/dsh-lsp

> 标签: JavaScript

## 简介

LSP 客户端插件（DeepSeek Harness / Cordis）：为 AI 代理提供语言服务器协议能力——悬停、跳转定义、查找引用、诊断、文档符号、调用层级
