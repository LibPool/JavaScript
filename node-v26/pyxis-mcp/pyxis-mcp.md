# pyxis-mcp

> 标签: ai-agent, analytics, mcp, model-context-protocol, privacy, product-analytics

## 简介

MCP server for Pyxis, privacy-first product analytics: lets an AI agent read your dashboard's numbers with a read-only token, locally over stdio or hosted over HTTP.
