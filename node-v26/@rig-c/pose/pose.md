# @rig-c/pose

> 标签: 2d, ai-agents, body-18, cli, coco, keypoints, motion-retargeting, pose, retarget, rig-c, rigc, skeletal-animation

## 简介

Puts motion from a body-18 pose sequence onto a rig built with rig-c: bone keys in rig-c's motion format, checked through rig-c's gate before anything is written. A CLI for agents that cannot see the rig.
