# @brika/icon-studio

> 标签: brika, cli, favicon, gradient, icon, icon-generator, iconify, icons, lucide, monogram, simple-icons, svg

## 简介

Generate square SVG plugin icons from the command line: 200k+ glyphs, gradients, monograms, film grain.
