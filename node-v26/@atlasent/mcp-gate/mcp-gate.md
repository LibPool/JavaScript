# @atlasent/mcp-gate

> 标签: ai-agent, authorization, circuit-breaker, fail-closed, guardrail, mcp, model-context-protocol, security

## 简介

Local, fail-closed MCP stdio gate with metadata-only activity evidence. Blocks every tool call until you write a rule. No account, no network, no dependencies.
