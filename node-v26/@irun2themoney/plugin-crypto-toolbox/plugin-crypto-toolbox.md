# @irun2themoney/plugin-crypto-toolbox

> 标签: agent, blockchain, crypto, elizaos, plugin, web3, x402

## 简介

Zero-dependency Web3/crypto toolkit for ElizaOS agents: balances, token info, tx decode, ENS, chain status, Chainlink price, payment verification, and crypto-address validators. No API keys.
