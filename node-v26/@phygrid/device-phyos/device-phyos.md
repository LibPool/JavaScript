# @phygrid/device-phyos

> 标签: JavaScript

## 简介

For local development, ensure the process can write to /etc/phyos.env if on a mac ``` sudo echo 'LOCAL' > /etc/phyos.env sudo chmod 666 /etc/phyos.env ```
