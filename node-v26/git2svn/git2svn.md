# git2svn

> 标签: bidirectional, cli, git, mirror, subversion, svn, sync, 双向同步

## 简介

Git ↔ SVN 双向镜像 CLI：把 Git 分支同步到 SVN，或把 SVN 内容提交回 Git，支持项目清单、增量工作副本、非交互模式与变更统计
