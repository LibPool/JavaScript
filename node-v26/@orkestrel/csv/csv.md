# @orkestrel/csv

> 标签: csv, parser, renderer, rfc4180, tsv, typescript

## 简介

A typed CSV toolkit — RFC 4180 parsing and rendering with typed rows, dialect control, and structural database interop. Part of the @orkestrel line.
