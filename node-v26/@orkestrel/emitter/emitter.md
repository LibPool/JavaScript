# @orkestrel/emitter

> 标签: emitter, event-emitter, events, hooks, typed-events, typescript

## 简介

A typed, synchronous event emitter — listener isolation with an error hook, once/off/clear/destroy, and no scheduler or listener cap. Part of the @orkestrel line.
