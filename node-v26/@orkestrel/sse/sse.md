# @orkestrel/sse

> 标签: event-stream, eventsource, parser, server-sent-events, sse, streaming, typescript

## 简介

A typed Server-Sent Events parser — incremental, spec-compliant parsing of event-stream chunks into typed events with data, event, id, and retry fields. Part of the @orkestrel line.
