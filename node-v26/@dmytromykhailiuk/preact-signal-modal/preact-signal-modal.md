# @dmytromykhailiuk/preact-signal-modal

> 标签: accessibility, action-sheet, animation, bottom-sheet, dialog, focus-trap, ionic, modal, overlay, preact, preact-signals, sheet, signals, type-safe, typescript, web-animations, zero-dependencies, zero-rerender

## 简介

Signal-driven modals for Preact: imperative createModal() with an awaitable result, a declarative <Modal isOpen> component, Ionic-identical Web Animations API transitions, sheet modals with breakpoints, focus trap and zero re-renders.
