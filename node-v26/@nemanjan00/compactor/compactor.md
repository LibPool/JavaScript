# @nemanjan00/compactor

> 标签: agent, compaction, context, llm, pi, pi-extension, pi-package

## 简介

Context management for coding agents: offload big tool results, collapse finished work into summaries with an index, compact with a summary that keeps what the rest needs, and find any of it again. Harness-neutral core, with an adapter for the pi coding a
