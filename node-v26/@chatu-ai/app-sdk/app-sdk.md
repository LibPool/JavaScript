# @chatu-ai/app-sdk

> 标签: ai, app-sdk, auth, builder, chatu, kv, llm, nextjs, storage

## 简介

Runtime SDK for apps generated by ChatU Builder: kv, db (with atomic writes), storage, auth (app users, roles), ai (OpenAI-compatible LLM relay), pay and caps (enterprise capability center) with platform / byo / edgeone / sqlite / memory drivers selected
