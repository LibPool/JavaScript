# @sensei-studio/webhooks

> 标签: JavaScript

## 简介

Sensei Studio inbound webhook verifier. Framework-neutral, zero-runtime-dependency signature verification + envelope parsing for receivers. Generated envelope types from the frozen Webhook Delivery Contract 1.0.0. ESM-only, WebCrypto-only.
