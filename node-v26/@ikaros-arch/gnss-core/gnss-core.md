# @ikaros-arch/gnss-core

> 标签: ecef, emlid, gga, gnss, gps, gst, nmea, rtk, utm

## 简介

NMEA-0183 parsing and normalisation to LLH / ECEF / projected coordinates with accuracy and RTK status. The pure core of gnss-server, reusable in browsers and native shells.
