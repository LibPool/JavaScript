# @gwynnnplaine/pi-github

> 标签: extension, github, pi, pi-agent, pi-package

## 简介

Read GitHub issues, PRs, diffs, checks & code from inside Pi — via the gh CLI. Chronological markdown, image extraction, PR review workflows.
