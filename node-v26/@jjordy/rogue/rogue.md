# @jjordy/rogue

> 标签: custom-elements, declarative-shadow-dom, fine-grained, hydration, jsx, reactive, signals, ssr, vite-plugin, web-components

## 简介

JSX → web components compiler with fine-grained reactivity, file-system routing, and SSR/hydration. Vite plugin + tiny runtime.
