# @bwndlct/zcode-claw-adapter

> 标签: adapter, app-server, claw, claw-orchestrator, custom-engine, stream-json, zcode

## 简介

Claw Orchestrator custom engine that runs ZCode app-server as the coding session owner, translating Claw stream-json to the ZCode Protocol.
