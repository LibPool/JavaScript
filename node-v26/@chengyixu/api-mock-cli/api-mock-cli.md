# @chengyixu/api-mock-cli

> 标签: api, api-testing, cli, mock, mock-server, proxy, record, replay, testing, typescript

## 简介

Record real API responses and replay them as a mock server. Proxy, save, edit, diff, and generate TypeScript types from API recordings.
