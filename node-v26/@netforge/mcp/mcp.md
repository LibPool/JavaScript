# @netforge/mcp

> 标签: ai agents, browser game, coding agents, game engine, llms-txt, mcp, mcp server, model context protocol, multiplayer, net-forge, playtest, three.js

## 简介

MCP server for Net Forge: lets AI coding agents list templates, scaffold a game, search the engine docs, validate a game module, run headless bot playtests and play the game locally. No chain, no keys.
