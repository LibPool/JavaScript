# @netforge/template-dungeon

> 标签: ai-agents, browser-game, dungeon-crawler, game-engine, game-template, gamedev, html5-game, mcp, multiplayer, net-forge, roguelike, threejs, typescript

## 简介

Co-op dungeon crawler game template for Net Forge: 4 players, procedural rooms, loot and permadeath runs (CRYPTWICK).
