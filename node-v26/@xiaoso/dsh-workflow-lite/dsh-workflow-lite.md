# @xiaoso/dsh-workflow-lite

> 标签: deepseek, deepseek-harness, dsh, dsh-plugin, dsh-plugins, react-flow, soft-orchestration, workflow

## 简介

Lightweight agent workflow for DeepSeek Harness: one workflow = one JSON (React Flow native) with prompts inline, compiled into a dispatch plan the model executes itself. No execution engine; optional per-workflow run state kept by the model in a YAML fil
