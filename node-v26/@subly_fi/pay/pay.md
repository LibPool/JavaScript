# @subly_fi/pay

> 标签: ai-agents, kamino, mcp, payments, solana, usdc, x402

## 简介

Subly client for compatible x402 Solana USDC exact APIs, using spendable Kamino vault yield. Includes an MCP server and CLI with local-key, Circle, and Privy signing.
