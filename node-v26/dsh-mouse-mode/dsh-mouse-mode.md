# dsh-mouse-mode

> 标签: accessibility, deepseek-harness, dsh, dsh-plugin, mouse, mouse-only

## 简介

DSH Web 客户端的纯鼠标操作模式：长按中键开关；模式内 侧键·后退＝下一个会话、长按侧键·后退＝新建对话、侧键·前进＝上一个会话、滚轮切会话、中键单击＝语音输入、左/右键批准或拒绝确认框。所有手势可在插件设置里改绑。
