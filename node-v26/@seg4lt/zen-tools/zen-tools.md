# @seg4lt/zen-tools

> 标签: desktop, installer, tauri, zen tools, zen-tools

## 简介

One-line installer for the Zen Tools desktop app. Downloads the official release and bypasses macOS Gatekeeper quarantine on unsigned builds. This version tracks the installer wrapper, not the app — `npx @seg4lt/zen-tools` always pulls the latest Zen Tool
