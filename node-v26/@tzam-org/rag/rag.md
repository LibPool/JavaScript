# @tzam-org/rag

> 标签: JavaScript

## 简介

Envio de documentos ao RAG do BoxAI, inclusive muito grandes: chunker determinístico em stream (corte UTF-8 seguro, ids estáveis, sobreposição, metadados herdados), contrato com ACL obrigatória validada no cliente e cliente de ingestão com partes retomáve
