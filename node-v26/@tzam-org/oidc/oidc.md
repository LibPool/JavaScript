# @tzam-org/oidc

> 标签: JavaScript

## 简介

OIDC agnóstico, sem dependências: provedor (authorization code + PKCE S256 obrigatório, código de uso único, id_token RS256, discovery, JWKS, userinfo, logout back-channel) e cliente (PKCE, validação do id_token e do logout token). Assinatura com node:cry
