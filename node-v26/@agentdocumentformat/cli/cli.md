# @agentdocumentformat/cli

> 标签: adf, agent, agent-document-format, agents, ai, cli, daemon, llm, mcp, tui

## 简介

ADF CLI: the ADF (Agent Document Format) daemon, command line and terminal app. Run your agents headless: `adf daemon`, then `adf`.
