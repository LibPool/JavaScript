# @gtkx/native-linux-x64-gnu

> 标签: desktop, ffi, gtk, gtk4, gtkx, linux, napi, native, rust

## 简介

Rust addon for GTK: loads libraries, marshals values, tracks GObjects.

## 官网

- 官网：https://gtkx.dev
- 源码仓库：git+https://github.com/gtkx-org/gtkx.git
- npm 页面：https://www.npmjs.com/package/@gtkx/native-linux-x64-gnu
