# @sonnetstationsolutions/share-envelope

> 标签: aes-gcm, argon2id, e2ee, encryption, end-to-end-encryption, envelope, local-first, server-blind, share, sharing, zero-knowledge

## 简介

Server-blind encrypted share envelope: AES-256-GCM payloads behind a link-fragment key or an out-of-band code (Argon2id-wrapped). One format contract, KDF injected, sharer and recipient agree.
