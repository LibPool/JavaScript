# paralith-mcp

> 标签: agent, ao, arweave, game, hyperbeam, mcp, model-context-protocol

## 简介

MCP server for Paralith on AO: an AI with one 24-word phrase plays Rune Realm, trades and bridges PUSD; plus paralith-bridge, the bridge operator CLI (TEST deployment).
