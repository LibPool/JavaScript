# @streamapp/desktop-win32-x64

> 标签: JavaScript

## 简介

stream-desktop binary for Windows x64 — loaded by @streamapp/desktop (Stream Desktop)。bin/ 里还带着读屏用的 PP-OCRv5 模型三件（ocr-det.onnx / ocr-rec.onnx / ocr-rec-dict.txt）与 ONNX Runtime 1.20.1 的动态库（onnxruntime.dll，另有它依赖的 VC++ 运行时三件 msvcp140 / vcruntime140 / vcrunti
