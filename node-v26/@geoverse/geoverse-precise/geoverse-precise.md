# @geoverse/geoverse-precise

> 标签: bd09, buffer, cgcs2000, gcj02, geodesic, gis, turf, wasm

## 简介

Ellipsoid-accurate spatial analysis in WebAssembly: geodesic measurement, China CRS (GCJ-02 / BD-09 / CGCS2000) transforms, geodesic buffers and robust overlay. turf-style API.
