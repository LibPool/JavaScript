# @cloudbusiness/gl-importer-mcp

> 标签: accounting, importer, mcp, model-context-protocol, quickbooks, synder, xero

## 简介

MCP server for the Synder Importer REST API. Imports CSV/XLSX accounting data into QuickBooks Online or Xero.

## 官网

- 官网：https://importer.synder.com
- 源码仓库：git+https://github.com/SynderAccounting/gl-importer-plugin.git
