# @paxalabs/mcp

> 标签: mcp, model-context-protocol, ocr, paxa, text-to-speech, thai, translation, tts

## 简介

Official MCP server for the Paxa Labs API: Thai, English, and Mandarin text to speech with local playback, speech to text with subtitles, translation to Thai, document OCR, and field extraction.
