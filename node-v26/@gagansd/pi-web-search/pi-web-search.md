# @gagansd/pi-web-search

> 标签: exa, jev, parallel, pi, pi-extension, pi-package, web-search

## 简介

Search the web and public code from Pi, with citations. web_search, code_search, and opt-in multi_search — keyless by default, no vendor lock-in.
