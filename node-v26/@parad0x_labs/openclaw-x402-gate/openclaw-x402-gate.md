# @parad0x_labs/openclaw-x402-gate

> 标签: micropayments, monetization, openclaw, openclaw-plugin, parad0x-labs, payments, paywall, solana, usdc, x402

## 简介

Charge other agents for your OpenClaw skill or API with x402 micropayments on Solana. Mint a 402 challenge, verify the payment, then serve. Funds go straight to your own wallet address — the skill never holds keys or custody.
