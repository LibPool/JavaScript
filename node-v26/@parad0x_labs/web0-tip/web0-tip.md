# @parad0x_labs/web0-tip

> 标签: null, parad0x-labs, solana, tipping, web0, x402

## 简介

Tip any wallet on Solana (USDC / $NULL / SOL), bound to what's being tipped — phase 0 of the Web0 social substrate. Non-custodial; 100% reaches the recipient.
