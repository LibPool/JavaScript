# @oxvoinsights/types

> 标签: analytics, oxvo, oxvo-insights, oxvoinsights, types, typescript

## 简介

TypeScript types for the OXVO Insights browser SDK. Use them to type window.oxvoinsights when you load OXVO Insights with a script tag.
