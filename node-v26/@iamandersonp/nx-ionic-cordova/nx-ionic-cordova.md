# @iamandersonp/nx-ionic-cordova

> 标签: cordova, ionic, nx

## 简介

Nx plugin for Ionic/Cordova workspaces: scaffolds apps, runs native Cordova CLI commands scoped to one app, and maps Ionic CLI hooks to Nx targets.
