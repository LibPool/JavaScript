# @inforahul/rn-background-location-service

> 标签: android, background, corelocation, foreground-service, ios, location, offline-queue, permissions, react-native, sync

## 简介

React Native background location tracking that continues when the app is backgrounded or killed (platform permitting), when GPS and location permission are allowed
