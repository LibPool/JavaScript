# @noverax/courier-solid

> 标签: api-client, bff, courier, proxy, session, solid, solid-start, solidjs, ssr, type-safe, typescript

## 简介

SolidStart adapter for Courier: an API route that proxies typed calls to any backend, with the user's session in queries, server functions and actions
