# @noverax/courier-hono

> 标签: api-client, bff, bun, cloudflare-workers, courier, deno, edge, hono, proxy, session, sse, type-safe, typescript, web-standards, websocket

## 简介

Hono adapter for Courier on Web Standards: proxy typed calls to any backend from Node.js, Bun, Deno or Cloudflare Workers, with the user's session, SSE and WebSockets
