# @noverax/courier-next

> 标签: api-client, app-router, bff, courier, csrf, next, nextjs, proxy, route-handlers, server-actions, server-components, session, type-safe, typescript

## 简介

Next.js adapter for Courier: one App Router route that proxies typed calls to any backend, createAction for Server Actions, and the user's session in Server Components and Route Handlers
