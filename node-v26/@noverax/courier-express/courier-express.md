# @noverax/courier-express

> 标签: api-client, bff, courier, csrf, express, express-middleware, nodejs, proxy, session, sse, type-safe, typescript, websocket

## 简介

Express adapter for Courier: one route that proxies typed calls to any backend, with the user's session, CSRF protection, SSE, WebSockets and graceful shutdown
