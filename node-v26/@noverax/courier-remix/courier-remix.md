# @noverax/courier-remix

> 标签: actions, api-client, bff, courier, loaders, proxy, react-router, remix, session, ssr, type-safe, typescript

## 简介

React Router and Remix adapter for Courier: a resource route that proxies typed calls to any backend, with the user's session in loaders and actions
