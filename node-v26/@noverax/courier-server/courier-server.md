# @noverax/courier-server

> 标签: bff, courier, docker, http-server, kubernetes, proxy, server, sse, standalone, type-safe, typescript, websocket

## 简介

Standalone server for Courier: your typed API's proxy over HTTP, SSE and WebSocket on its own port — for static and serverless front ends, Docker and Kubernetes
