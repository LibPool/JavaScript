# @noverax/courier

> 标签: api-client, bff, courier, edge, end-to-end-types, fetch, http-client, middleware, proxy, realtime, rest, rpc, server-components, sse, standard-schema, type-safe, typescript, validation, websocket, zod

## 简介

Type-safe HTTP for any backend: define your API once in plain TypeScript and call it from server code and the browser — validated, with middleware, SSE, WebSockets and a secure proxy, no codegen
