# @volter/twin-smtp

> 标签: JavaScript

## 简介

Local SMTP twin (RFC 5321 submission server: EHLO/AUTH/MAIL/RCPT/DATA over raw TCP, messages folded into the twin ledger, twin-only HTTP inspect sidecar) built on @volter/world-core.
