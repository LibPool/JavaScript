# @volter/world-access

> 标签: access, jwks, jwt, twin, world

## 简介

How a World decides what a request may do: the grant, and passes a platform signs for a person (ES256, Web Crypto only). Runs in Node, Bun and Cloudflare; docs/contributing/architecture.md, "The hosted product".
