# @volter/twin-xai

> 标签: grok, llm, responses, twin, xai

## 简介

xAI API twin (Protocol 3): chat completions and responses (streamed and not; tools, JSON output, reasoning) on the World's scenario or the kernel wire's labeled stub (the twin runs no model); Console API keys. Built on @volter/world-core.
