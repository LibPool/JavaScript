# @eater-altria/token-meter-local

> 标签: cordis, dsh, plugin, statistics, token, usage

## 简介

Token Meter Local - 实时统计全部会话（含已归档/已删除）的 token 消耗与人民币花费估算（LiteLLM 快照 / OpenRouter / 自定义价格三级兜底，历史天按当天最后使用的模型归因），设置页提供时间区间、指标卡、GitHub 风格蓝色热力图与随区间联动的模型价格管理
