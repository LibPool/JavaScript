# @linked.cm/messaging

> 标签: chat, linked, messaging, rdf, semantic-web

## 简介

A shape-agnostic, transport-agnostic LINKED messaging engine — the Messaging seam, an in-memory store, and a themeable chat client. Transports (e.g. @linked.cm/matrix) implement the same interface.
