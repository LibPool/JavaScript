# @sovgut/state

> 标签: browser, cache, cookie, cookies, event-emitter, frontend, in-memory, local-storage, localstorage, memory-storage, observer, persistence, pubsub, react, reactive, session-storage, sessionstorage, state, state-management, storage, store, type-safe, typescript, web-storage

## 简介

Type-safe, synchronous state management for the browser with a unified API over localStorage, sessionStorage, cookies, and in-memory storage, plus a built-in observer for change events.
