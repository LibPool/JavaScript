# @iamcoder18/huly-cli

> 标签: ai-agent, cli, huly, huly-cli, issue-tracker, openclaw, self-hosted, skill

## 简介

AI-agent-first CLI for self-hosted Huly. Automate issues, projects, channels, docs, calendar & time tracking — no browser, no MCP, no Playwright.
