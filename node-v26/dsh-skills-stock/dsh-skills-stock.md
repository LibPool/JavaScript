## 简介

DSH 原生 A 股量化投研技能包：适配自 KStock 2.0 桌面端精选技能体系（41 个技能：个股研究 / 选股与策略 / 场景编排 / 品种专项 / 市场全景 / 数据查询 / 图表呈现），激活即注册为 runtime skill，配 workspace 侧边栏「投研工作台」（策略/因子/选股/报告四库 + 数据源凭据配置）。
