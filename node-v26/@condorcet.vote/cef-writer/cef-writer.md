# @condorcet.vote/cef-writer

> 标签: cef, condorcet, condorcet-election-format, condorcet.vote, election, typescript, voting, writer

## 简介

Streaming TypeScript writer that produces valid Condorcet Election Format (CEF) documents line by line. A faithful port of CondorcetVote/CEF-Writer.
