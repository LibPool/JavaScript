# @zmaui/color

> 标签: @zmaui/color, color, theme

## 简介

基于色彩理论的智能配色方案生成库，支持和谐模式、自适应辅助色、色阶调色板及亮暗主题，提供 Vue/Vitarx/UniApp/Web 多框架集成。
