# wyro-check

> 标签: ai-agents, architecture, backend, ci, claude-code, code-review, cursor, fastapi, lint, mcp, mcp-server, nextjs, prisma, static-analysis, typescript

## 简介

Check a backend's architecture from its source. Reads TypeScript, Python and Prisma/TypeORM/Mongoose schemas, then fails the build on architecture violations.
