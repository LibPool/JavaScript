# @xmmtr/dsh-file-menu

> 标签: context-menu, dsh, dsh-plugin, explorer, file-menu, open-with, reveal-in-folder

## 简介

DSH Web plugin: right-click menu on file references in the transcript — copy absolute path, reveal in Explorer, open with any registered app.
