# @giime/crx

> 标签: axios, chrome-extension, crx, giime, mv3

## 简介

面向基于 giime 的 Chrome 扩展（MV3）插件：axios 与登录协调器。popup / options / contentScript / background 共用同一套代码；contentScript 经 background 自动桥接。
