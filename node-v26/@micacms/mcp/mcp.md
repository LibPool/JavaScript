# @micacms/mcp

> 标签: agents, cms, mcp, mica

## 简介

The Mica tools for agents over the Model Context Protocol: read the model and the content, save drafts, publish when allowed. Composed by @micacms/editor locally and @micacms/self-hosted behind OAuth.
