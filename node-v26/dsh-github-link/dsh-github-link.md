# dsh-github-link

> 标签: deepseek-harness, dsh, dsh-plugin

## 简介

Hover cards for GitHub / GitLab / Gitee URLs plus click-to-open in the DSH sidebar browser, scoped to the conversation transcript (GenUI blocks included).
