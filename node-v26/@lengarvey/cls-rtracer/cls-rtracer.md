# @lengarvey/cls-rtracer

> 标签: cls, express, fastify, hapi, koa, logging, request, request id

## 简介

Express & Koa middlewares and Fastify & Hapi plugins for CLS-based request id generation, batteries included. Fork with zero runtime dependencies (native crypto.randomUUID).
