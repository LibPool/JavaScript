# @sroool/djinn_hands

> 标签: agent, claude, client, codex, djinn, mcp

## 简介

TypeScript client for djinn (AI as a service over the Claude Code and Codex CLIs), plus djinn-hands, the tool server that lets djinn's agent jobs work inside your container.
