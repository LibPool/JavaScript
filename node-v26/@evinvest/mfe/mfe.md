# @evinvest/mfe

> 标签: JavaScript

## 简介

Host contract for EV microfrontends: registry manifest, bundle loader, ev:navigate / ev:signed-in / signout events, apiVersion and host-mode attributes, plus a light-DOM React RemoteElement. Mirrors the producer side in the mfe module of the ev_lib crate.
