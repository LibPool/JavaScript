# @reticlehq/core

> 标签: ai-agents, mcp, protocol, reticle, testing

## 简介

The Reticle foundation: the shared wire contract — types, zod schemas, constants, messages, and the isomorphic kernel that every Reticle package (browser SDK, server, kits, test harness) imports. Depends only on zod.
