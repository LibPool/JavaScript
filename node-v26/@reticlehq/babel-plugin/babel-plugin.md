# @reticlehq/babel-plugin

> 标签: babel-plugin, devtools, react, reticle, source

## 简介

Babel plugin that stamps data-reticle-source="file:line:col" on JSX host elements so @reticlehq/react can map a DOM node to its source (works on React 19, which dropped _debugSource).
