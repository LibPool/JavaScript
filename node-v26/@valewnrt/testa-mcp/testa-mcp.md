# @valewnrt/testa-mcp

> 标签: agent, e2e, ios, mcp, simulator, testa, testing

## 简介

npx launcher for the Testa MCP server (iOS Simulator E2E driver for AI agents). Requires the native `testa` binary — install it with Homebrew.
