# linkbreakers-mcp

> 标签: lead-capture, linkbreakers, mcp, model-context-protocol, qr-code

## 简介

Local stdio bridge to the Linkbreakers MCP server (https://mcp.linkbreakers.com) for MCP clients that only run local servers.
