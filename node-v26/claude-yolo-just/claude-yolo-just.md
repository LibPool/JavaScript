# claude-yolo-just

> 标签: anthropic, claude, claude-code, cli, dangerously-skip-permissions, permissions, wrapper, yolo

## 简介

Minimal, auditable launcher that runs Claude Code with permission prompts skipped (claude --dangerously-skip-permissions). Adds only the official flag — no patching, no auto-update, zero dependencies.
