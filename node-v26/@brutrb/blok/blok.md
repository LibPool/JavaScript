# @brutrb/blok

> 标签: accessibility, brutalist, css, custom-elements, design-system, progressive-enhancement, ui, web-components

## 简介

BLOK is a UI component framework and CSS library to create simple, usable, and accessible web apps following a brutalist/minimalist web design
