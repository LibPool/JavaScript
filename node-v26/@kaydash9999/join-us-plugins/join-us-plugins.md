## 简介

join-us — Claude Code + Codex CLI plugin: joinus-style contribution workflow skills (PR + Copilot review, multi-PR dev merge, per-PR/monthly reports, GitHub Wiki publish, pre-PR code review). Install via Claude Code marketplace, or `npm i -g @kaydash9999/
