# @toolars/local-tools

> 标签: cli, hash, json, json-format, local-first, mcp, mcp-server, model-context-protocol, privacy, sha256, stdio, toolars

## 简介

Toolars local-tools experiment: a local stdio CLI and MCP server for strict JSON formatting and SHA-256 hashing. Zero runtime dependencies, no network access, no telemetry.
