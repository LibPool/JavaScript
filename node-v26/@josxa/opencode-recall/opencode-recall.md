# @josxa/opencode-recall

> 标签: chatml, embeddings, history, ollama, opencode, opencode-plugin, recall, search, semantic-search

## 简介

OpenCode plugin that adds semantic + lexical recall over your local session history, with cursor-paginated ChatML transcript reads.
