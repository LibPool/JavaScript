# @mnemora/anthropic

> 标签: JavaScript

## 简介

LLMProvider の Anthropic 実装。zod スキーマを Anthropic のネイティブ構造化出力（output_config.format: json_schema）へ翻訳する。EmbeddingProvider は実装しない（Anthropic は埋め込み API を提供していないため。docs/architecture.md §4）。
