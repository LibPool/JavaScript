# @mnemora/bullmq

> 标签: JavaScript

## 简介

BullMQ で runtime.tick() を駆動する役。outbox は Postgres のまま正本——BullMQ はジョブの中身を持たず、「いま tick して」の合図だけを運ぶ（docs/decisions/0325-bullmq-tick-driver.md）。
