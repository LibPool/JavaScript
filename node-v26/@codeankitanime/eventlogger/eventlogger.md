# @codeankitanime/eventlogger

> 标签: analytics, browser-events, click-tracking, custom-analytics, event-logging, event-tracker, front-end-logger, frontend-analytics, geo-tracking, interaction-logger, ip-tracking, javascript-logger, logging, react-logger, session-tracking, user-activity, user-tracking, web-logger

## 简介

A lightweight JavaScript event tracker that logs user interactions (clicks, inputs, scrolls, etc.) along with browser, OS, and optional geolocation/IP metadata. Ideal for building custom front-end analytics.
