# @vishakhashedge/rca-data-migrator

> 标签: custom-objects, data-migration, product-migration, rca, revenue-cloud-advanced, salesforce

## 简介

Zero-dependency Salesforce data migration CLI. In-memory processing with custom object support. Guided object registration, describe-based field discovery, and automatic lookup resolution. No local data storage.
