# 2faguide-rehype-image-dimensions

> 标签: astro, cls, core-web-vitals, dimensions, hast, height, image, lazy-loading, markdown, mdx, rehype, rehype-plugin, unified, width

## 简介

rehype plugin that adds real width/height, loading and decoding to local markdown & MDX images at build time — zero dependencies, zero runtime JS. Extracted from the 2faguide.com build pipeline.
