# @farmslot/adapter-web

> 标签: adapter, agentic-engineering, cdp, chrome, farmslot, recipe

## 简介

Web platform adapter for Farmslot recipes: resolve and launch an isolated Chromium, own its CDP port, load unpacked extensions, and keep macOS focus.

- 官网：https://farmslot.io/docs/reference/adapter-web
- 源码仓库：git+https://github.com/deeeed/farmslot.git
