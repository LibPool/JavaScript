# @cloudflare/pubsub

> 标签: cloudflare, mqtt, pubsub, workers

## 简介

Useful functions for writing serverless functions around Cloudflare's Pub/Sub service (https://developers.cloudflare.com/pub-sub/)

## 官网

- 官网：https://developers.cloudflare.com/pub-sub
- 源码仓库：git+https://github.com/cloudflare/pubsub.git
- npm 页面：https://www.npmjs.com/package/@cloudflare/pubsub

## 历史版本号

- 当前版本：0.0.1

- 0.0.1

## 获取地址

- npm 安装：`npm install @cloudflare/pubsub`
- npm registry：https://registry.npmjs.org/@cloudflare/pubsub
- Node 要求：>=14
