# dsh-molbio-panel

> 标签: cordis, deepseek-harness, dsh-client, molecular-biology, panel, plasmid

## 简介

Browser panel for the DeepSeek Harness Web GUI: a Molbio tab in the right sidebar that draws plasmid maps and sequence logos from workspace sequence files, using the same computation modules as the dsh-molbio-tools plugin.
