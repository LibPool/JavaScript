# @creaditor/cdtr-auth

> 标签: auth, creaditor, drop-in, embed, web-components

## 简介

Embeddable <cdtr-auth> web component. Holds a cdtr-studio JWT inside an iframe-scoped vault and proxies API calls for sibling drop-ins via the @cdtr/signal bus.
