# @teaspoon-ai/openclaw-teaport-realtime

> 标签: kokoro, openclaw, openclaw-plugin, pipecat, realtime-voice, stt, teaport, tts, voice, voxtral

## 简介

OpenClaw realtime-voice provider bridging gateway-relay to an external Pipecat speech-to-speech server (on-device Voxtral STT + LLM + TTS with heard-grounded barge-in).
