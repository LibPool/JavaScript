# @jantimon/web-performance-debugger

> 标签: chrome, cli, forced-reflow, inp, layout, layout-thrashing, performance, profiling, puppeteer, reflow

## 简介

Drive Chrome or Firefox (Puppeteer), or profile Node in-process, to attribute layout, style, and paint work, rendering counts, CPU self-time, and allocation back to source lines, with isolated timing and CI gating
