# dsh-windows-session-notification

> 标签: attention, cordis, deepseek-harness, dsh, dsh-plugin, notification, plugin, taskbar-badge, toast, windows

## 简介

DSH plugin: cross-session "needs attention" notifications on Windows — actionable toasts, tiered sounds and a taskbar badge, only for sessions you are not watching.
