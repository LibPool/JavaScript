# @linkdesk/ui

> 标签: components, linkdesk, ui

## 简介

@linkdesk/ui——LinkDesk 共享 UI 组件的类型契约 + dev 解析体。L9 集中供给：组件代码与样式在运行时由壳池 vendor 单实例供给（壳改一处全生态跟随）；npm i 装的是类型与本地解析体，插件源码不 import 本包 css（lint 腿 check-ui-css-import 判红）。版本号与壳同号锁步（E6#124 重锚）。
