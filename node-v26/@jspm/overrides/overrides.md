# @jspm/overrides

> 标签: JavaScript

## 简介

This repo contains the `package.json` overrides used for npm registry packages as processed by `jspm.dev`, `jspm.io` as well as in local package management.

## 官网

- npm 页面：https://www.npmjs.com/package/@jspm/overrides

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm registry：https://registry.npmjs.org/@jspm/overrides
