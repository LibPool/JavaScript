# react-isokit

> 标签: claude-code, figure, illustration, interactive, isometric, react, skill, sound, svg, web-audio

## 简介

Interactive isometric line figures for React: rounded boxes, faces you can draw on, keys you can press, and optional synthesized sound. Plus a Claude Code skill that draws them.
