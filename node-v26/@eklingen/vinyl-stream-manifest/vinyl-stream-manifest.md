# @eklingen/vinyl-stream-manifest

> 标签: gulp, manifest, manifest.json, stream, utilities, vinyl

## 简介

Vinyl-stream utility -aka Gulp plugin- to generate a manifest.json for consumption by, for example, a webserver.
