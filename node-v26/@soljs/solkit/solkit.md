# @soljs/solkit

> 标签: JavaScript

## 简介

`@soljs/solkit` is the backend runtime and Vite integration for full-stack Sol applications. It renders the same compiled root component on the server, injects managed `Head` output into the document, and hydrates the server tree in the browser. Developme
