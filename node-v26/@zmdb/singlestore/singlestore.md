# @zmdb/singlestore

> 标签: database, migrations, mysql, orm, singlestore, typescript, zmdb

## 简介

SingleStore vertical for zmdb: MySQL-family compilation, storage-aware migrations, catalog introspection, and mysql2 driver binding.
