# @zmdb/cockroach

> 标签: cockroachdb, database, migrations, orm, postgresql, typescript, zmdb

## 简介

CockroachDB vertical for zmdb: PostgreSQL-family dialect overrides, migrations, catalog introspection, retries, and a pg-protocol driver.
