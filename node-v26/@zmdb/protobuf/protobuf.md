# @zmdb/protobuf

> 标签: aot, grpc, protobuf, serialization, typescript, zmdb

## 简介

Zero-dependency protobuf calls, typed gRPC service artifacts, and the wire runtime targeted by zmdb's ahead-of-time compiler.
