# @zmdb/sql

> 标签: mysql, postgres, query-builder, sql, sqlite, typescript, zmdb

## 简介

SQL-first, dialect-aware query compiler with reads, writes, joins, aggregates, full-text search, set operations, and schema-object DDL.
