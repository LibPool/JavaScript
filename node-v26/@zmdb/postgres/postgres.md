# @zmdb/postgres

> 标签: database, migrations, orm, postgres, postgresql, typescript, zmdb

## 简介

The complete PostgreSQL vertical for zmdb: dialect, migrations, catalog introspection, node-postgres driver, cursors, and cancellation.
