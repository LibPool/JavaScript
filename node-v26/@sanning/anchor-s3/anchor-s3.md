# @sanning/anchor-s3

> 标签: anchoring, arweave, audit-trail, provenance, s3, sanning

## 简介

Anchor-as-you-store for S3: wrap your S3 client so every putObject also sends a signed evidence envelope for the object to Sanning and writes the envelope and its record beside the object as a .provenance.json sidecar. Also the S3 destination for the SDK
