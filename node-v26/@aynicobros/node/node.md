# @aynicobros/node

> 标签: ayni, aynicobros, bolivia, checkout, cobros, pagos, payments, qr, sdk

## 简介

Server-side client for ayni cobros. Creates charges with your secret key and hands back the hosted-checkout link to redirect a payer to.
