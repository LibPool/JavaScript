# @draco-rust/decoder

> 标签: 3d, compression, decoder, draco, mesh, point-cloud, wasm, webassembly

## 简介

Draco geometry decoder in WebAssembly, a safe Rust port of Google Draco: meshes, point clouds and older bitstreams, each as its own small entry.
