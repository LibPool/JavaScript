> 标签: athena, clinical-data, concept-mapping, fhir, healthcare, icd10, loinc, medical-vocabularies, ohdsi, omop, omophub, rxnorm, sdk, snomed, vocabulary-mapping

## 简介

Official OMOPHub Node.js / TypeScript SDK for the OHDSI medical vocabularies API - search, lookup, map, and navigate concepts across SNOMED, ICD10, RxNorm, LOINC, and more.
