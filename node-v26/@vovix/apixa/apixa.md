# @vovix/apixa

> 标签: api-client, apixa, baas, backend-as-a-service, cloudflare, database, storage

## 简介

TypeScript client for the Apixa API: db, storage, kv, queues, functions, browser, mail, auth, sandbox and apps. fetch only, zero dependencies.
