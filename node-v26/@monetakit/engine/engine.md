# @monetakit/engine

> 标签: billing, cloudflare-workers, monetakit, rating, subscriptions

## 简介

Self-managed billing engine (rating + period processing) for edge runtimes — the TS twin of the Go engine, kept in lockstep by shared conformance vectors. Runs on Cloudflare Workers (Cron + D1).
