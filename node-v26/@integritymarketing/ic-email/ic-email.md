# @integritymarketing/ic-email

> 标签: JavaScript

## 简介

SendGrid Dynamic Template generator — 3 platforms x 8 types of table-based HTML, with every hex derived from @integritymarketing/ic-tokens at build time so an email can never drift from the palette. Publishes the built templates plus manifest.json for who
