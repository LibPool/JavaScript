# @synoi/verify

> 标签: audit, cryptography, ed25519, receipts, synoi, verify

## 简介

Independent verifier for SynOI Decision Receipts: hybrid Ed25519 + ML-DSA-65, Node and browser, no account. Fully offline when you hold the receipt JSON and the signing public key; the receipt-ID CLI is a network lookup.
