# @synoi/sraid

> 标签: canonical-object-format, canonicalization, cdro, content-addressed, ed25519, ml-dsa, post-quantum, sraid, synoi

## 简介

SRAID reference implementation: canonical JSON serializer, content-addressed OIDs, hybrid Ed25519 + ML-DSA-65 signature verification, lineage, and shape validators. No storage, no transport, no policy.
