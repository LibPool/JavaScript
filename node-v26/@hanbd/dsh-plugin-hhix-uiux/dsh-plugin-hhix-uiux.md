## 简介

HHIX/MBCM UI 设计工作台：一条 /hhix-init 就把一个文件夹变成完整的产品设计工程（内置 DESIGN.md、组件库、hhix-ui-design 技能、git 仓库，以及起服务/开浏览器/校验工具），并把每一步执行过程打印出来
