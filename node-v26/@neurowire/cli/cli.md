# @neurowire/cli

> 标签: atom, cli, feed, json-feed, markdown, mesh, neurowire, nwf, rss

## 简介

Neurowire command-line tool: turn any blog, feed, or mesh into NWF, Atom, JSON Feed, Markdown.
