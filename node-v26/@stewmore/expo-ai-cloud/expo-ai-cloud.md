# @stewmore/expo-ai-cloud

> 标签: ai, cloud, expo, fallback, react-native

## 简介

Cloud fallback adapter for the Expo AI Runtime. POSTs to a configurable backend (OpenAI / Anthropic / Gemini / Bedrock / custom) with streaming via expo/fetch.
