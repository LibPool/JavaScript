# react-thai

> 标签: accessibility, address, autocomplete, bahttext, buddhist-calendar, buddhist-era, datepicker, headless, postcode, react, thai, thai-id, thailand

## 简介

Accessible React components for Thai forms: Buddhist-calendar (พ.ศ.) date picker and Thai address autocomplete, plus Thai ID, phone and baht-text helpers.
