# dsh-compaction-guard

> 标签: ai-agents, compaction, deepseek-harness, deterministic, dsh-plugin

## 简介

Compaction integrity for DeepSeek Harness: constraints extracted from the compacted range are verified against the summary — what the agent was told to remember and silently forgot is reported loudly. Zero LLM calls in the trust path
