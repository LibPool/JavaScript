# @inariwatch/capture-mcp

> 标签: capture, dev-mode, inariwatch, mcp, model-context-protocol, stdio

## 简介

Local MCP dev-mode server for @inariwatch/capture. Reads recent errors from .inariwatch/errors.jsonl and exposes them over stdio JSON-RPC 2.0 so editors (Cursor, Claude Code, Continue) can debug locally without hitting the cloud. Spec: SKYNET_MASTER_PLAN.
