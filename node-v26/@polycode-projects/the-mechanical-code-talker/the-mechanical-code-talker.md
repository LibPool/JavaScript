> 标签: ace, chatbot, cli, code-navigation, controlled-natural-language, deterministic, eliza, knowledge-graph, nlp, no-llm, offline, ontology, owl, parry, provenance, rdf, wink-nlp

## 简介

The Mechanical Code Talker (tmct) — a tolerant, offline, $0 chat surface that guides you toward precision queries about a software repository. ELIZA/PARRY-style but domain-obsessed with code. No model calls; indexes a repo on request (tmct index) or reads
