# @nera-static/plugin-sitemap

> 标签: nera, nera-plugin, robots.txt, seo, sitemap, sitemap.xml, static-site-generator

## 简介

A plugin for Nera static site generator to generate a sitemap.xml for every rendered page, plus a robots.txt pointer to it.
