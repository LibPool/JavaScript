# @nera-static/plugin-contact-form

> 标签: contact-form, form, jamstack, mailto, nera, nera-plugin, no-backend, static-site-generator

## 简介

A plugin for the Nera static site generator that renders a backend-free contact form which builds a mailto: link from configurable fields on submit.
