# @tum-far/ubii-msg-formats

> 标签: JavaScript

## 简介

Hi. This is the repository for Ubii message formats. It contains everything about **what** ubii nodes and devices say to each other. If you are interested in how they communicate with each other, please see - https://zeromq.org/, https://zguide.zeromq.o
