# @bonusround/mcp

> 标签: ads, bonusround, bonusround.io, claude, cursor, game-monetization, mcp, mcp-server, model-context-protocol, playable-ads, three.js, threejs, webgl

## 简介

MCP server for Bonus Round (bonusround.io): monetize your three.js game with one line of code. Lets AI coding agents register a game (no account needed), get the install snippet and verify the integration. The SDK is the bonusround npm package.
