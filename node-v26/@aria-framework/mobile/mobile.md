# @aria-framework/mobile

> 标签: JavaScript

## 简介

Aria App Framework — mobile module. The phone half of an Aria app (Expo / React Native): an API client for the shared /api/v1 contract (tokens in SecureStore, single-flight refresh, Entra PKCE sign-in, authed downloads + cache, multipart upload), an AuthP
