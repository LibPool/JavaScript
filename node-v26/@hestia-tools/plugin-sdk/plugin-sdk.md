# @hestia-tools/plugin-sdk

> 标签: ai-agent, governance, hestia, mcp, plugin, trust, web4

## 简介

Hestia Plugin Authoring Kit — author Hestia plugins for any AI agent client. Wraps R6/R7 record building, Soft LCT session identity, policy query, credential vault, and witness chain emission.
