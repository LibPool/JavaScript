# @konce-pt/chat

> 标签: chat, design-system, grouping, koncept-ui, kpt, messages

## 简介

Chat core for Koncept UI — message grouping, day separators, date-label kinds and send-status arithmetic. Framework-free TypeScript, zero runtime dependencies.
