# @konce-pt/icons

> 标签: design-system, icons, koncept-ui, kpt, svg, tabler, tabler-icons

## 简介

Icon data and the SVG rendering core for Koncept UI — built-in set plus the full Tabler Icons set (MIT) on a subpath. Pure TypeScript, zero runtime dependencies.
