# @starsguest/dsh-client-ui-wallpaper

> 标签: JavaScript

## 简介

Wallpaper theme plugin: XPage-style backdrop (image/video wallpaper, dim and blur knobs) plus separate glass-panel transparency for the conversation surfaces, with a light token palette override
