# @iforge.it/mssql-mcp

> 标签: claude, database, mcp, model-context-protocol, mssql, sql-server

## 简介

Minimal unrestricted MCP server for Microsoft SQL Server. One tool — execute_sql — runs any SQL query without limitations.
