# @superjsorg/compiler

> 标签: compiler, javascript, null-safety, pattern-matching, sum-types, superjs, type-checker, typescript

## 简介

The Super.js compiler — a null-safe, sum-typed superset of JavaScript that compiles to plain JS. Programmatic compile/transform API.
