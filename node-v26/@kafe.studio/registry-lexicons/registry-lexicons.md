# @kafe.studio/registry-lexicons

> 标签: atproto, cms, fair, kafecms, lexicons, plugin-registry

## 简介

Generated TypeScript types for KafeCMS plugin registry lexicons (com.kafecms.experimental.*). EXPERIMENTAL: NSIDs and shapes will change.
