# dsh-xcode-mcp

> 标签: deepseek, deepseek-harness, dsh, dsh-bundle, dsh-plugin, ios, macos, mcp, mcpbridge, swift, xcode

## 简介

Apple Xcode MCP bridge for DeepSeek Harness — bridges `xcrun mcpbridge` into native `mcp__xcode__*` tools. Configuration-only bundle: no code, no dependencies.
