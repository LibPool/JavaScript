# @ab-png123/dsh-plugin-update-check

> 标签: deepseek-harness, dsh, dsh-bundle, dsh-market, dsh-plugin, notifier, update-check, updates

## 简介

DSH 启动时自动检查已安装插件是否有新版本，并用系统通知 / Dock 角标提示（可独立运行）。
