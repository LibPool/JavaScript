# @brain-bbqs/ui

> 标签: JavaScript

## 简介

The shared page shell of the BBQS companion web apps: theme tokens and toggle, header account menu, brand watermarks and footer, the What's New changelog modal, human-subjects gate, dropzone, and typed element lookups. Plain DOM, no framework.
