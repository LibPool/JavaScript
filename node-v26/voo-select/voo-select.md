# voo-select

> 标签: bootstrap, bootstrap-select, dropdown, form, multiselect, searchable, select, virtual-scroll, vue, vue3

## 简介

Vue 3 port of bootstrap-select: multiselect, search and virtual scrolling for Bootstrap selects, with zero jQuery.
