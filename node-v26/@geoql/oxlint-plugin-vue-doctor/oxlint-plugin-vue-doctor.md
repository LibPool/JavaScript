# @geoql/oxlint-plugin-vue-doctor

> 标签: JavaScript

## 简介

oxlint JS plugin for Vue 3 anti-patterns and AI-slop detection. Pairs with oxlint's built-in vue plugin via jsPlugins. TypeScript, ESM.
