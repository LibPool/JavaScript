# @saiisback/git-secure

> 标签: decrypt, encrypt, encryption, git, git-hooks, hooks, husky, secret-management, secrets, security, sensitive-files, vault

## 简介

A lightweight NPM utility that automatically encrypts sensitive files before git commits and decrypts them after checkout
