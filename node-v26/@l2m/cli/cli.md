# @l2m/cli

> 标签: agent-skills, brd, claude-code, cobol, copilot, frd, legacy, mainframe, modernization, requirements, srd, traceability

## 简介

Legacy to modern: analyze legacy code (COBOL, CICS, JCL, DB2 and more) and generate versioned, traceable BRD, FRD, SRD and RTM documents with Claude Code, GitHub Copilot, Codex or Gemini.
