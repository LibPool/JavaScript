# @larose-ui/tokens

> 标签: design-system, larose, larose-internal, react, saas, ui-platform

## 简介

[Internal] Design-token engine and CSS variables — bundled into @larose-ui/styles; use directly only for advanced JS theming. Prefer @larose-ui/react, @larose-ui/vue, @larose-ui/svelte, or @larose-ui/runtime-* in apps.
