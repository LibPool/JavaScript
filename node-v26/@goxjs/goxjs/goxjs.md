# @goxjs/goxjs

> 标签: bytecode-vm, go, gui, interpreter, javascript, jsx, runtime

## 简介

Gox — 用 Go 从零实现的 JavaScript 运行时（lexer → parser → 字节码 VM），单二进制零外部依赖
