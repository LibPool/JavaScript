# @xleddyl/nuxt-cms

> 标签: cms, drizzle, graphql, headless-cms, libsql, nitro, nuxt, nuxt-module, postgres, self-hosted, sqlite, turso

## 简介

Lightweight CMS that ships with your Nuxt app: runs on the Nitro server, content types defined in code, /cms admin panel, GraphQL API, SQLite or Postgres. No external CMS needed!
