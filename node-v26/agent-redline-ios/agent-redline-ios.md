# agent-redline-ios

> 标签: claude-code, codex, debugging, ios, mcp, swiftui

## 简介

Installs Redline on your Mac: point at UI in a Debug build of your iOS app and send a note with a snapshot to the Claude Code or Codex chat working on it.
