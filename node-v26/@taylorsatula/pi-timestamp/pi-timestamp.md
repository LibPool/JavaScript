# @taylorsatula/pi-timestamp

> 标签: pi-package

## 简介

Timestamp injection extension for Pi — appends the current wall-clock time to the tail of user messages and vocalizations just-in-time (cache-safe, no synthetic tool calls), so the model always knows what time it is.
