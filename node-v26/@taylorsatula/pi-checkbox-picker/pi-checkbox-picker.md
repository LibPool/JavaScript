# @taylorsatula/pi-checkbox-picker

> 标签: pi-package

## 简介

Interactive checkbox picker tool for Pi — presents a grouped list of items the user cherry-picks with SPACE and submits as one subset. For 'which of these do we act on?' decisions, where single-choice radios are the wrong instrument.
