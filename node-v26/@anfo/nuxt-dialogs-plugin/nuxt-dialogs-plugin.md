# @anfo/nuxt-dialogs-plugin

> 标签: dialog, dialogs, drawer, nuxt, nuxt-module, nuxt3, nuxt4, vue, vue3

## 简介

Nuxt module that auto-scans a directory for Vue dialog/drawer components and exposes them through a fully type-safe virtual module (virtual:dialogs). Dialog apps automatically inherit the Nuxt app context (Pinia, i18n, UI libraries, global components).
