# @bratel/prebuild-install

> 标签: addon, binaries, bindings, c, c++, devops, module, napi, native, prebuilt

## 简介

A command line tool to easily install prebuilt binaries for multiple version of node/iojs on a specific platform, build tool and bindings loader for node-gyp that supports prebuilds
