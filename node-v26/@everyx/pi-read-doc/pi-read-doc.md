# @everyx/pi-read-doc

> 标签: pi-package

## 简介

Enhanced read for pi – office docs (docx/pdf/pptx/xlsx etc.) via anydoc, header-only, OCR for scanned pages (Firecrawl or local rapidocr, in the order you configure).
