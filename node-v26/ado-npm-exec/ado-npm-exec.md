# ado-npm-exec

> 标签: auth, azure-artifacts, azure-devops, entra-id, mcp, npm, npm-exec, npx

## 简介

Run a package from a private Azure DevOps (Azure Artifacts) npm feed with silent Microsoft Entra ID auth. Zero dependencies. Built for MCP stdio server configs.
