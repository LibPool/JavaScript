> 标签: automation, chatgpt, claude, cursor, desktop, filesystem, mcp, pty, remote-mcp, terminal

## 简介

Secure remote MCP bridge for connecting AI assistants to user-owned computers with local permissions, file integrity guards, managed processes, and real PTY sessions.
