# @studio-sadola/flexaudio-win32-arm64-msvc

> 标签: audio, capture, loopback, napi-rs, recording

## 简介

Flexible cross-platform audio capture (microphone, system loopback, per-process) for Node.js, via native N-API bindings to the flexaudio Rust library.
