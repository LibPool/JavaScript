# @kaditang/402sentinel-mcp

> 标签: ai-agents, base, counterparty, mcp, risk, usdc, x402

## 简介

MCP tools for x402 payment safety — vet the counterparty (risk score, allow/review/block, spending policy) AND vet the payment itself (buyer-side firewall: routing/drain/injection). Thin client for 402sentinel.com.
