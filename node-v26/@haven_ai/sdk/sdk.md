# @haven_ai/sdk

> 标签: 402, agent-payments, agentic-commerce, ai-agent, budget, haven, mcp, non-custodial, payments, spending-limit, usdc, web3, x402

## 简介

TypeScript SDK for Haven — give AI agents budgeted, non-custodial payment ability. Pay x402 (HTTP 402) APIs in USDC within on-chain-enforced spending limits; the agent never holds funds or keys.
