# portfolio-agent-widget

> 标签: chat-widget, groq, portfolio, recruiter, resume, web-component

## 简介

A drop-in chat widget that lets recruiters ask questions about you, professionally, and hands them your scheduling link at the right moment. Framework-agnostic Web Component + a plain Node backend helper.
