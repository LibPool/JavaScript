# @euginejs/renderer-server

> 标签: eugine, html, renderer, server-rendering, ssr

## 简介

Deterministic, browser-API-free HTML renderer for Eugine documents. Safe to run in Node.js server contexts (e.g. Next.js Server Components) without loading the visual editor.
