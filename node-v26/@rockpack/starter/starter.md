# @rockpack/starter

> 标签: boilerplate, cli, csr, react, rockpack, scaffolding, ssr, typescript, webpack, zero-config

## 简介

CLI scaffolding tool for React apps with zero-config CSR and SSR setup, Webpack, Jest, and ESLint
