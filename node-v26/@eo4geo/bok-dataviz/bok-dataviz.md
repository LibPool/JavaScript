# @eo4geo/bok-dataviz

> 标签: Body of Knowledge, bok, circle packing, eo4geo, jsonld, parse

## 简介

EO4GEO-bok-dataviz is an script to parse EO4GEO BoK and visualize it in a circle packing d3 layout
