# @syncrea/exprit-cli

> 标签: calculator, cli, expr-eval, expression, expression-evaluator, exprit, repl

## 简介

Command-line interface for exprit: evaluate safe expressions from the terminal, pipe them through stdin, or explore them in a REPL.
