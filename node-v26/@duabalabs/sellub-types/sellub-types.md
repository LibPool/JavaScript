# @duabalabs/sellub-types

> 标签: JavaScript

## 简介

Shared TypeScript types and DTOs for the Sellub commerce platform. Consumed by sellub-client, sellub-react, sellub-react-native, sellub-webhooks and every internal sellub-server plugin.
