# @brandonkal/url-purify

> 标签: JavaScript

## 简介

`@brandonkal/url-purify` is a JavaScript library that cleans URLs by removing tracking parameters and other unnecessary elements. It also normalized and detects the ID in YouTube links. It is forked from the [ClearURLs](https://github.com/ClearURLs/Addon/
