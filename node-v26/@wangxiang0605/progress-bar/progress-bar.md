# @wangxiang0605/progress-bar

> 标签: pi, pi-extension, pi-package, progress, status

## 简介

Pi extension: Shows a 0–100% progress bar above the input while tools run or the model generates; it uses percentages printed by commands when available, falls back to elapsed/timeout or smooth growth, and fills to 100% on completion. / Pi 扩展：在输入框上方显示 0–1
