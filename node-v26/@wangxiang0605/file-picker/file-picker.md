# @wangxiang0605/file-picker

> 标签: file-picker, pi, pi-extension, pi-package, ui

## 简介

Pi extension: Adds a "Pick file" button above the input; it opens the system file dialog and inserts the selected path into the input (any file type, no upload). / Pi 扩展：在输入框上方添加「选择文件」按钮，点击弹出系统文件对话框，选中的路径直接填入输入框（不限类型、不上传）。
