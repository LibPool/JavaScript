# decisium

> 标签: cucumber, decision-model, e2e, gherkin, jev, playwright, semantic-testing, testing

## 简介

Semantic UI testing with decision models: plain-English Gherkin Steps executed by Jev in a real browser, pass/fail decided by code, record/replay cassettes
