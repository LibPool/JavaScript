# @plumbox/oprf

> 标签: discovery, oprf, plum, plum-box, plumbox, privacy, ristretto255, voprf, zero-knowledge

## 简介

Zero-knowledge box discovery for Plum: find a user's box from (email, password) via an OPRF, without the relay learning the email, the password, or which box.
