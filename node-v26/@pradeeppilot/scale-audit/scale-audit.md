# @pradeeppilot/scale-audit

> 标签: audit, ci, cli, code-review, concurrency, database, express, github-action, linter, n+1, nextjs, nodejs, pagination, performance, prisma, scale, static-analysis, timeout, typescript

## 简介

Static scale-readiness audit for public Node.js/TypeScript repos. Clones a repo (read-only) and reports what will break as traffic/users grow.
