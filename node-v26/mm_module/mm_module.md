# mm_module

> 标签: catalog, install, manager, mm_kernel, mm_mod, module, npm, uninstall

## 简介

内核模块管理框架件：基于 npm 实现模块的搜索、安装、卸载与清单编排，并按声明的层级分层装载与声明体检（不注册能力）
