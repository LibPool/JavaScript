# @stwrd-auth/react

> 标签: authentication, bff, hooks, oauth2, oidc, react, sessions, stwrd

## 简介

stwrd SDK for React (backend-for-frontend profile): a session provider, hooks and components that read the session from the /auth/session endpoint.
