# @dm2233/agent-data-mcp

> 标签: ai-agents, claude, fact-check, market-data, mcp, model-context-protocol, usdc, verification, x402

## 简介

MCP server that gives an agent a fact-checking and market-data companion: verify a claim, check a price or yield, read a live web page — pay-per-call in USDC over x402, no API key.
