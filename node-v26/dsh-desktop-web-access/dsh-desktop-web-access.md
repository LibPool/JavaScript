# dsh-desktop-web-access

> 标签: access-token, deepseek-harness, desktop, dsh, dsh-plugin, lan, remote-access, tunnel, web

## 简介

DSH desktop plugin: surface and copy the Web GUI launch-token URL (loopback + LAN) so the desktop app's built-in Web server can be opened from another device.

## 官网

- npm 页面：https://www.npmjs.com/package/dsh-desktop-web-access
