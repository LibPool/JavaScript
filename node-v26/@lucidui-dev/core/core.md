# @lucidui-dev/core

> 标签: agents, ai, charts, components, dataviz, llm, no-build, reactive, signals, ui

## 简介

Lucid UI from lucidui.dev: a small, dependency-free UI runtime for the web, built for people and AI agents. Not the AppNexus React lucid-ui.
