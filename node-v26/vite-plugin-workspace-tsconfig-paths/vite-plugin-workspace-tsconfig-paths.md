# vite-plugin-workspace-tsconfig-paths

> 标签: monorepo, multi-repo, paths, tsconfig, vite, vite-plugin, workspaces

## 简介

Vite plugin that maps tsconfig `paths` per importing file's workspace — the file that issues the import decides which tsconfig (and thus which alias rules) applies. Supports cross-repository `extends` chains with TypeScript-native semantics.
