# @danypops/themetic

> 标签: color-theory, oklch, theme, wcag

## 简介

Deterministic pi color-theme generation: palette generation, token-role assignment, and a WCAG contrast/color-harmony quality gate. No model, no Pi dependency — pure functions over a caller-supplied seed-hue list. The Pi extension and skill live in @danyp
