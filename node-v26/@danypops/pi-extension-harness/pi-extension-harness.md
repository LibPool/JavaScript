# @danypops/pi-extension-harness

> 标签: jiti, pi, pi-extension, test-harness, testing

## 简介

A lightweight, in-process test host for Pi extensions -- unit-test hooks, tools, and commands without booting a real AgentSession, LLM, or I/O. Analogous to ESLint's RuleTester: ships the testing primitives so extension authors stop hand-rolling ad-hoc fa
