# @mcmcjs/doodleppl

> 标签: bayesian, bugs, codegen, doodlebugs, doodleppl, graphical-models, juliabugs, ppl, stan

## 简介

Turn a DoodlePPL graph into probabilistic model code (BUGS/JuliaBUGS, Stan); the shared codegen for the DoodlePPL editor and the MCMC.js CLI.
