# @mcmcjs/charts

> 标签: ascii, braille, charts, cli, plot, svg, terminal, unicode, visualization

## 简介

A dependency-free plotting engine: render line, scatter, bar, interval, and density plots to the terminal (braille/block/ASCII) or SVG from one figure model.
