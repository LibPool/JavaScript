# @mcmcjs/plots-gl

> 标签: bayesian, mcmc, parallel-coordinates, plots, regl, scatter3d, splom, visualization, webgl

## 简介

Interactive WebGL renderers for MCMC plots (3D scatter, scatter-plot matrix, parallel coordinates), backed by regl.
