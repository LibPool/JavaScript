# @rcs-templates/agent-toolkit

> 标签: agent, cli, mcp, messaging, rcs, templates, twilio, whatsapp

## 简介

Agent skins for the rcs-templates gateway: an MCP server (rcs-mcp / wa-mcp) and a CLI (rcs / wa) over one shared client.
