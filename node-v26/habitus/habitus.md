# habitus

> 标签: agent, claude-code, cli, codex, deepseek-harness, habitus, memory, opencode, pi, zcode

## 简介

Habitus command line: install the Habitus memory and reminder plugins into coding agents (Codex, Claude Code, OpenCode, pi, ZCode, DeepSeek Harness), check and query the local Habitus service.
