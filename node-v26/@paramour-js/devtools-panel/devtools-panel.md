# @paramour-js/devtools-panel

> 标签: devtools, nextjs, routing, tanstack-devtools, type-safe, typescript

## 简介

Paramour devtools: a TanStack Devtools panel showing live route observations — wire vs parsed values, codec shapes, default/catch attribution, decode issues, and editable search params.
