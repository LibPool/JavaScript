# @centralping/ergo

> 标签: api-security, fast-fail, http, json-api, middleware, opentelemetry, owasp, rest-api, security, security-headers, streaming, tracing

## 简介

A Fast Fail REST API toolkit for Node.js -- composable middleware with structured Negotiation, Authorization, Validation, and Execution stages.
