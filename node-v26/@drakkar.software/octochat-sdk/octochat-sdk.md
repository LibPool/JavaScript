# @drakkar.software/octochat-sdk

> 标签: JavaScript

## 简介

Headless, reusable OctoChat core — chat-domain logic (identity, encrypted Starfish sync, registry, spaces/rooms, messages, DMs, formatters) with no UI and no platform lock-in.
