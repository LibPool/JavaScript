# @theunipay/username

> 标签: alias, payments, resolver, stealth, uda, unipay, username, web3

## 简介

UniPay usernames — a shareable @name that resolves to a UniPay UDA via a SIGNED, self-authenticating record. No resolver (hosted or not) can forge a mapping; pluggable transport (hosted now, on-chain later).
