# @md2docx/list

> 标签: automation, bullet-points, converter, document-generation, docx, export, markdown, markdown-to-docx, mdast, mdast-to-docx, nested-lists, numbered-lists, open-source, ordered-list, remark, rich-text, text-processing, typescript, unified, unordered-list, web-development

## 简介

Plugin to convert ordered and unordered lists from Markdown (MDAST) to DOCX. Supports nesting, custom bullets, and numbering styles.
