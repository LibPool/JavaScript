# @webboxes/blends-core

> 标签: JavaScript

## 简介

The ACRYL Blends format (blends.acryl.dev/v1alpha1): parse, validate, resolve, compile, lock and inspect Blueprint and Blend manifests. Host-independent: no Cordis, DSH or surface dependencies.
