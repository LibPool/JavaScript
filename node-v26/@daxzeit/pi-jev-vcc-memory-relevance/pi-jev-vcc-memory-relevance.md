# @daxzeit/pi-jev-vcc-memory-relevance

> 标签: jev, memory, pi-extension, pi-package, relevance

## 简介

Logit-scored memory relevance for the Pi coding agent — ranked hints (priors, not verdicts) over your long-term memory index, via JEV (default) or a fully local scorer
