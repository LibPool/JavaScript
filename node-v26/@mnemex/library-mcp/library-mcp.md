# @mnemex/library-mcp

> 标签: annas-archive, claude, knowledge-management, llm, mcp, model-context-protocol, playwright, project-gutenberg

## 简介

MCP server to search and download books from Project Gutenberg and Anna's Archive into your LLM wiki. Includes a Playwright-based search that works against Anna's current client-side-rendered pages.
