# @dpdfe/axios

> 标签: JavaScript

## 简介

-   支持配置策略同一个请求，最多发送一次，如果发送多次，自动取消上次请求 -   支持配置策略同一个请求，最多发送一次，触发多次，不发送本次请求 -   提供取消页面所有请求的方法
