# @inoo-ch/payload-image-optimizer

> 标签: blur-placeholder, client-resize, filename-strategy, image, payload, payloadcms, plugin, sharp, thumbhash, webp

## 简介

Payload CMS plugin: client-side pre-resize, ThumbHash blur placeholders, filename strategies, bulk regeneration UI, and Next.js display components — on top of Payload's native sharp pipeline
