# @pikiloom/kernel

> 标签: agent, ai, claude, codex, orchestrator, pty, tui, websocket

## 简介

Heterogeneous coding agents (Claude / Codex / Gemini / ACP) -> an interaction-friendly, accumulating session snapshot + control handle, over pluggable surfaces (IM, Web, tunnel, TUI). The reusable core pikiloom itself is built on.
