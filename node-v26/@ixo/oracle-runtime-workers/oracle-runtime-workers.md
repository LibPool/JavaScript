# @ixo/oracle-runtime-workers

> 标签: JavaScript

## 简介

QiForge oracle runtime for Cloudflare Workers — Durable Object per user (SQLite in WASM over DO storage), Matrix E2EE gateway Durable Object, Hono HTTP/SSE shell.
