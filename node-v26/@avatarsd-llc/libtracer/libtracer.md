# @avatarsd-llc/libtracer

> 标签: graph, iot, protocol, sensor, tlv

## 简介

TypeScript core for libtracer — a lightweight decentralized graph-based networking protocol. Native pure-TS implementation (in-process codec; no transports), conformance-gated against the shared vectors.
