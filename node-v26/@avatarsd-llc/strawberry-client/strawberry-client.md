# @avatarsd-llc/strawberry-client

> 标签: esp32, gorshok, grow-controller, protobuf, strawberry, strawberry-client, websocket

## 简介

Open-source, framework-free TypeScript client for the Strawberry (Gorshok-v4) grow controller WS+protobuf interface. One library for the web UI SPA, the Pulumi deploy provider, the strawberry-cli, and a Claude Code agent-skill.
