# @leitwerk-dev/gitlab-repo-change

> 标签: JavaScript

## 简介

`@leitwerk-dev/gitlab-repo-change` plans, implements, reviews, and publishes a repository change as a new GitLab merge request. Load `gitlab`, `coding`, and this extension on the server and worker. The extension is opt-in.
