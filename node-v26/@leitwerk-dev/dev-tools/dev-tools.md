# @leitwerk-dev/dev-tools

> 标签: JavaScript

## 简介

`@leitwerk-dev/dev-tools` provides the `leitwerk-dev` CLI for an extension workspace. Install it alongside matching `@leitwerk-dev/server`, `@leitwerk-dev/ui` and SDK versions. Node 26, npm and POSIX are required. Git is needed only for source mode.
