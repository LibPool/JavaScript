# @leitwerk-dev/gitlab

> 标签: JavaScript

## 简介

`@leitwerk-dev/gitlab` supplies GitLab v4 API access and repository-scoped HTTPS Git authentication from one server-owned profile. Load this optional extension on the server and worker.
