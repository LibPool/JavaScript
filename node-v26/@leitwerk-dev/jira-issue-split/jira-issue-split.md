# @leitwerk-dev/jira-issue-split

> 标签: JavaScript

## 简介

`@leitwerk-dev/jira-issue-split` creates one reviewed child ticket per applicable GitLab repository. Epics create Stories or Tasks; other issue types create native Jira subtasks. Existing subtasks cannot be split because Jira does not support nested subta
