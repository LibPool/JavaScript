# @keystrokehq/brave-search

> 标签: brave, brave-search, integration, keystroke, web-search

## 简介

Official Keystroke integration for the [Brave Search API](https://api-dashboard.search.brave.com/app/documentation), covering web, news, image, and video search plus suggestions, spellcheck, local search, grounded LLM context, and AI answers.
