# @nseaprotector/coelho-prosemirror

> 标签: angular, comments, editor, markdown, mentions, paste, prosemirror, react, rich-text, richtext, slash-commands, text-editor, typescript, vue, wysiwyg, wysiwyg-editor

## 简介

A ProseMirror rich text editor on a schema you own: anchored comments, @mentions and / commands, Markdown import and paste, HTML import that runs nothing. Framework-free, for React, Vue, Angular or plain JS.
