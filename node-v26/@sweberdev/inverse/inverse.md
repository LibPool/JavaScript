# @sweberdev/inverse

> 标签: 312k-bgb, 356a-bgb, cancellation-button, compliance, consumer-law, kuendigung, kuendigungsbutton, nextjs, shopify, vanilla-js, widerruf, widerrufsbutton, withdrawal-button, wordpress

## 简介

Withdrawal button (§ 356a BGB) and cancellation button (§ 312k BGB) for any web app: validation, server-side receipt with date and time, acknowledgement e-mail, deadlines and a page checker. Includes a framework-free form for plain HTML via a <script> tag
