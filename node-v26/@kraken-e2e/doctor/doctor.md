# @kraken-e2e/doctor

> 标签: JavaScript

## 简介

Pure check-execution engine for kraken doctor. Inputs (HostInfo, driver gate statuses, driver-contributed checks) are injected by the CLI — this package never reads process.platform and never knows Appium (ADR-0001 §5.13)
