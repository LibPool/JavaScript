# @metataro/zumen

> 标签: ai-agent, architecture-diagram, claude-code, diagram, diagram-as-code, drawio, floor-plan, mcp, mcp-server, mermaid, svg, tauri, yaml

## 简介

AI-editable diagrams as code: an AI agent draws from YAML via MCP (Claude Code and others), a human fixes the layout, and the fix survives regeneration. Renders SVG; exports Mermaid and draw.io.
