# json-csv-flatten

> 标签: converter, csv, csv-to-json, deep-flatten, dot-notation, flatten, json, json-to-csv, nested, nested-json, unflatten

## 简介

Flatten deeply nested JSON objects into CSV-ready flat objects (dot notation) and unflatten them back. Handles arrays, depth limits, circular protection, and edge cases.
