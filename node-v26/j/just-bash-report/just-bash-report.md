# just-bash-report

> 标签: agent-shell, charts, dashboard, html-invoice, html-report, invoice, just-bash, llm-tools, report, rss, ssg, static-site-generator

## 简介

Generate self-contained HTML dashboards, invoices, and static sites from agent data. just-bash plugin with pure HTML generators (use without just-bash). Charts, KPIs, tables, brand theming, i18n.
