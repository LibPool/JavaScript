# js-feed-freshness-canary

> 标签: canary, freshness, measurement, no-op, observability, registry

## 简介

Synthetic metadata-only package used to measure how quickly an npm release becomes visible through public registry feeds, mirrors, and downstream indexes. Contains no code and should not be depended on.
