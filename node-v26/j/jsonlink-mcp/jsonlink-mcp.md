# jsonlink-mcp

> 标签: ai-agents, jsonlink, markdown, mcp, metadata, model-context-protocol, screenshot, web-scraping

## 简介

MCP server for JsonLink: give AI agents web access — URL to Markdown, link metadata, screenshots, links and images from any URL.
