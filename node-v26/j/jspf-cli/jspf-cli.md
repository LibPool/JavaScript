> 标签: conversion, convert, convertor, json, jspf, m3u, m3u8, parse, parser, parsing, playlist, pls, validate, validation, xspf

## 简介

JSPF CLI is a command line utility (CLI) relying on the JSPF format to convert and validate playlist files.
