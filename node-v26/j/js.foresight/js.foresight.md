# js.foresight

> 标签: cursor-prediction, element-hitslop, fast-prefetch, foresight, interaction-prediction, javascript-prefetch, keyboard-prefetching, keyboard-tracking, mobile-prefetch, mouse-trajectory, prefetching, smart-prefetch, tab-prefetching, vanilla-javascript

## 简介

Predicts where users will click based on mouse movement, keyboard navigation, and scroll behavior. Includes touch device support. Triggers callbacks before interactions happen to enable prefetching and faster UI responses. Works with any framework.
