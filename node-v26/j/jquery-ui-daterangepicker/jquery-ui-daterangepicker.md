# jquery-ui-daterangepicker

> 标签: date picker, date range picker, jquery, jquery ui

## 简介

jQuery UI widget similar to the date range picker used in Google Analytics; supports multiple months, custom preset ranges and smart positioning; ThemeRoller-ready and mobile-friendly.
