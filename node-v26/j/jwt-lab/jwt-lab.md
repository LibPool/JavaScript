# jwt-lab

> 标签: ai-agent, authentication, cli, jose, json-web-token, jwe, jwk, jwks, jws, jwt, jwt-audit, jwt-cli, jwt-debugger, jwt-decoder, jwt-encoder, jwt-inspector, jwt-keygen, jwt-linter, jwt-mcp, jwt-tool, jwt-verifier, llm-tool, mcp, mcp-server, model-context-protocol, oauth, openid, security, token

## 简介

jwt-lab – A fast, secure, beautiful JWT CLI tool and MCP server for developers & AI agents. Encode, decode, verify, inspect, audit, and generate keys for JSON Web Tokens.
