# jev-orchestrator

> 标签: agent, coding-agent, jev, orchestrator, pi-extension, pi-package, pi-typesafe

## 简介

Adaptive task orchestration for Pi: Jev (typesafe) typed judgments drive ROUTE / CHECK / FINAL with per-category completion contracts, bounded correction loops, and tunable request budgets.
