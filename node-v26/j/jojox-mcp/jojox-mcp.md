# jojox-mcp

> 标签: ai, claude, code-review, cursor, mcp, model-context-protocol, security, sicurezza

## 简介

Server MCP di JoJoX: 58 controlli di sicurezza per codice generato da AI (pattern matching deterministico, nessun LLM, nessun dato inviato fuori dal tuo editor). Si collega a Claude Code, Claude Desktop, Cursor e altri agenti compatibili con il Model Cont
