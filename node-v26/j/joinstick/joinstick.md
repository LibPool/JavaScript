# joinstick

> 标签: browser-game, controller, couch-coop, game-controller, gamepad, html5, html5-game, local-multiplayer, mobile-controller, multiplayer, party-game, phone-controller, phone-gamepad, qr, qr-code, self-hosted, smartphone-controller, touch-controls, virtual-gamepad, websocket

## 简介

Use phones as gamepads for HTML5 browser games: scan a QR, play. Self-hosted and open source, no accounts, no app install.
