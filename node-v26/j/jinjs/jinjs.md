# jinjs

> 标签: compiler, html, jinjs, language, pwilang, templating, xml

## 简介

A templating language in the Jinja(python)/Twig(php) family for Javascript.
It's objective is to compile document templates into Javascript functions
Comes with a CLI tool to use it on static documents and not only for the web.
Is also made in tandem with Pwilang, which can then be (optionally) used to make HaML-like templates.
