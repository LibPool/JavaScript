# json-assertion

> 标签: JavaScript

## 简介

Utility functions compatible with mocha and jasmine to compare large JSON files. Instead of the error message printing two large JSON files, e.g. "expected Object({...}) to be Object({...})", you get an easy to read diff-type output.
