# jquery-accessible-carrousel-aria

> 标签: ARIA, Accessibility, Carrousel, Tab panel, Tabs, a11y

## 简介

The jQuery plugin will transform a simple list of div’s and hx into a fantastic-shiny carrousel system, using ARIA.
