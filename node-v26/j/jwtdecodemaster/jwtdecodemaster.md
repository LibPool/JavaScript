# jwtdecodemaster

> 标签: authentication, browser, decode, json-web-token, jwt, jwt-decode, nodejs, token, typescript, zero-dependency

## 简介

Lightweight, zero-dependency JWT decoder for Node.js and browsers. Decode JWT tokens without verification.
