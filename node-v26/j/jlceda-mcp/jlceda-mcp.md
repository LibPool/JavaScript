# jlceda-mcp

> 标签: JavaScript

## 简介

本项目用于在 **嘉立创EDA 专业版本地客户端** 中，通过“扩展桥接”的方式提供一个可被 LLM 调用的 **MCP Server**，从而实现原理图自动化（器件库搜索/放置/连线/导出等）。
