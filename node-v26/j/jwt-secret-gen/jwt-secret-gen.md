# jwt-secret-gen

> 标签: auth, bun, cli, dotenv, env, generator, hs256, hs384, hs512, jwt, secret, security, token

## 简介

Generate cryptographically secure JWT secrets(interactively or via CLI flags). Works with HS256, HS384, HS512.
