# jquery.tabbable

> 标签: :focusable, :tabbable, focus, jQuery, tab

## 简介

Simple utility for selecting the next / previous 'tabbable' element. Includes and uses the ':tabbable' and ':focusable' selectors from jQuery UI Core.
