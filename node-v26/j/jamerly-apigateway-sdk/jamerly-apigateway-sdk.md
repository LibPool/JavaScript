# jamerly-apigateway-sdk

> 标签: aes, api-gateway, jamerly, sdk

## 简介

JavaScript/TypeScript SDK for the Jamerly API Gateway: X-Biz-Id routing, AES-256-CBC payload encryption and the unified response envelope.
