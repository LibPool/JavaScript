> 标签: ajax, data, datagrid, datatable, ecosystem:jquery, jquery, jquery-datagrid, jquery-plugin, jquery.datagrid, local data, plugin, remote data, table

## 简介

A jquery plugin to render datagrid. Works with local or remote data. Designed to be adaptive, simple to use and extendable.
