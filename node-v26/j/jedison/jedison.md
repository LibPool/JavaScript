# jedison

> 标签: admin-ui, cms, editor, form, form-builder, form-generator, framework-agnostic, headless, json, json-schema, json-schema-form, schema, validation, vanilla-js

## 简介

Framework-agnostic JavaScript library that generates and validates forms from JSON Schema, with zero runtime dependencies.
