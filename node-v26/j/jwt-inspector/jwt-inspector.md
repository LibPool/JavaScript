# jwt-inspector

> 标签: auth, cli, jwe, jwks, jws, jwt, lint, security, token

## 简介

A security-hardened, developer-friendly command-line tool for decoding, verifying, validating, linting, diffing, and generating JSON Web Tokens (JWTs).
