# jarvis-agent-cli

> 标签: agent, ai, cli, coding-assistant, jarvis, llm, mcp, ollama, openrouter, rag

## 简介

Jarvis Agent in your terminal — the same agentic engine as the VS Code extension, as a CLI. Multi-provider agentic chat (local or cloud), tools + HITL, checkpoints, RAG, specialized agents, workflows and Auto-TDD.
