# jig-ui

> 标签: accessibility, ai-agents, claude-code, codex, css, cursor, design-system, design-tokens, opencode, ui

## 简介

A design system for coding agents. 130 numbered UI rules, brand x mode design tokens, and an installer for Claude Code, Codex, Cursor and opencode.
