# jev-router-mcp

> 标签: acp, ai-agent, claude, claude-code, codex, jev, mcp, model-routing, typesafe, zed

## 简介

Jev - intelligent AI router and supervisor: classifies coding tasks, picks the best-fit model (Claude/Codex/Gemini/DeepSeek), and supervises tool calls through a Tool Gate. Runs as a Zed ACP external agent (jev-acp) or as an MCP server any MCP-compatible
