# jpbank-number-converter

> 标签: JavaScript

## 简介

ゆうちょ銀行（Japan Post Bank）のキャッシュカードに記載されている記号・番号から、他行とのやりとりに使用する口座番号・支店名・支店番号に変換するライブラリ

- npm 页面：https://www.npmjs.com/package/jpbank-number-converter
