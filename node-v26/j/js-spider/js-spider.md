# js-spider

> 标签: browser, crawl, front-end, javascript, spider, web

## 简介

JSpider 3 is a Chrome DevTools crawler framework that includes full crawler support.
JSpider 3 是在 Chrome Devtools 中进行爬虫的爬虫框架, 这个框架包括了完整的爬虫支持。
