# jokeware

> 标签: foss, gpl, javascript, jokeware, prank, satire

## 简介

A joke package that randomly opens links from safe sites (like YouTube, Wikipedia, and other sources that are similiar). The name JokeWare is a play on the word 'Maleware'. This package is only for a funny prank and has no malicious intentions behind it.
