# jdcodec

> 标签: ai-agents, browser-automation, claude-code, cursor, llm, mcp, model-context-protocol, pii-redaction, playwright, playwright-mcp, privacy, token-compression

## 简介

JD Codec — local MCP proxy that compresses browser-agent snapshots ~80%+ via a cloud codec, with on-device PII redaction. The privacy-first connector for Playwright MCP and any MCP-capable agent.
