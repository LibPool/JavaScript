# js-upload-file

> 标签: file, javascript, upload, 分片上传, 并发上传, 文件上传, 文件续传

## 简介

前端文件上传插件，支持分片上传，并发上传，文件续传，暂停上传，含多种上传事件，事件回调支持异步方法，高度可控及自定义化
