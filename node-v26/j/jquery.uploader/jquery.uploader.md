# jquery.uploader

> 标签: bootstrap, file, jquery, jquery-plugin, jquery.uploader, upload

## 简介

Simple HTML5 file uploader, a plugin tool for jQuery which change completely file input and make it with multiple file selection, drag&drop support, different validations, thumbnails, etc
