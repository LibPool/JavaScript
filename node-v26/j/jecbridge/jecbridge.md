# jecbridge

> 标签: ai, chatgpt, claude, coding-agent, cursor, llm, local, mcp, mcp-server, model-context-protocol, tunnel

## 简介

Connect any local code project to any AI (ChatGPT, Claude, Cursor) over MCP — read, edit, run and build, with automatic checkpoints and undo.
