# josk

> 标签: CRON, agenda, agent, cluster, high load, highload, horizontal scaling, job, jobs, manager, mongo, mongodb, redis, redisdb, schedule, scheduler, servers, task, task manager, task scheduler, tasks

## 简介

Tasks/CRON scheduler and manager for horizontally scaled multi-server applications. Supports Redis, MongoDB, PostgreSQL adapters.
