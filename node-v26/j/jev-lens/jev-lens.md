# jev-lens

> 标签: coding-agent, compression, context, jev, prompt-cache, tool-output, typesafe

## 简介

jev picks what a coding agent gets to see of a large tool result: views built from the output's own lines, chosen by TypeSafe's judgment model, full text recallable. Host-independent core used by pi-jev-lens and the Claude Code plugin.
