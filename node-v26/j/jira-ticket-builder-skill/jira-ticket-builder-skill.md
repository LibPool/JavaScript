# jira-ticket-builder-skill

> 标签: agile, ai-agent, anthropic, architecture-diagram, atlassian, business-analysis, chatgpt, claude, claude-code, claude-skill, custom-gpt, jira, llm, mcp, product-management, requirements-engineering, requirements-to-jira, scrum, traceability-matrix, user-stories

## 简介

Turns rough bug reports, feature asks, or full requirements documents into structured Jira tickets or a multi-page requirements portal with diagrams (business flow, architecture, UI flow, customer journey). Ships as a Claude Skill and as portable instruct
