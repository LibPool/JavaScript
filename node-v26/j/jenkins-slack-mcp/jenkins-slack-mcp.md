# jenkins-slack-mcp

> 标签: amazon-q, build, ci, ide, jenkins, mcp, model-context-protocol, slack

## 简介

MCP server to trigger Jenkins builds from any IDE. Auto-discovers jobs, browser login, Slack DM notifications.
