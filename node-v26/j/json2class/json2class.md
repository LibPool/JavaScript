# json2class

> 标签: arkTs, class, cli, code build, code generation, config, dart, deserialization, json, json2class, json5, serialization, transform, typescript

## 简介

json2class is a CLI tool to generate class objects from JSON or JSON5, supporting serialization and deserialization.
