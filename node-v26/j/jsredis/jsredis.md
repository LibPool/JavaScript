# jsredis

> 标签: Map, Set, WeakMap, WeakSet, cache, database, es2015, es6, fast, in-memory, lightweight, memdb, memory, performance, redis

## 简介

A lightweight, high performance in-memory database based on redis. Makes use of the latest ES2015 features (such as Map).
