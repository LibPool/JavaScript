# jquery.jold.external-hrefs

> 标签: JavaScript

## 简介

A jQuery plugin that opens all external links (links that link to another domain / hostname) in a new tab.

## 官网

- 官网：https://github.com/joldnl/jquery.jold.external-hrefs
- npm 页面：https://www.npmjs.com/package/jquery.jold.external-hrefs
