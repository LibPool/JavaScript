# jest-environment-shipchain

> 标签: JavaScript

## 简介

When including Google's Protocol Buffers in a project that uses Jest for testing, errors can occur during serialization/deserialization between `Buffer` <--> `UInt8Array` data.  This issue has been described here: https://github.com/facebook/jest/issues/4
