# jobtracker-agents

> 标签: JavaScript

## 简介

Installs jobtracker's agents (job-scorer, resume-reviewer, tailor-application) for whichever coding agent(s) you use, and offers to install its skills too.

## 官网

- npm 页面：https://www.npmjs.com/package/jobtracker-agents

- npm registry：https://registry.npmjs.org/jobtracker-agents
- Node 要求：>=18
