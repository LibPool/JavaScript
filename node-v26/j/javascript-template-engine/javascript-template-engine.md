# javascript-template-engine

> 标签: handlebars, helpers, lightweight, mustache, mustache-compatible, partials, performance, string-template, template, templating, typescript

## 简介

A fast, more-powerful-than-Mustache TypeScript template engine: helpers/filters, partials (with indentation), conditionals, loops, Mustache sections, lambdas, and safe HTML-escaping.
