# js-custom-scroll

> 标签: custom scroll, javascript custom scroll, javascript scroll, javascript scrollbar, js custom scroll

## 简介

This vertical scroll works on all browsers (ie10+) and mobile devices. It was written on pure js, uses es6 standards. Also, it supports scrolls inclusion.
