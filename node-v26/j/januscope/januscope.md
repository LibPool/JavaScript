# januscope

> 标签: ai, anthropic, claude, guardrails, janus, januscope, llm, mcp, middleware, model-context-protocol, openai, policy, proxy

## 简介

Local MCP policy proxy with response redaction, call auditing, tool restrictions, and schema context. Wrap an existing server with a YAML policy.
