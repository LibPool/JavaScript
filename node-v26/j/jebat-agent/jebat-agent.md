# jebat-agent

> 标签: agent, ai, copilot, gateway, integration, jebat, multi-agent, setup

## 简介

Jebat Agent — 30-second setup for AI agent workspace with 8 local LLM models (Gemma 4, Qwen2.5, Hermes3, Phi-3), IDE integration, multi-agent orchestration, markdown rendering, and enterprise security.
