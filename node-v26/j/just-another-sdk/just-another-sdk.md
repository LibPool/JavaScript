# just-another-sdk

> 标签: agent, agents, ai, anthropic, llm, openai, openrouter, sdk, tool-calling, typescript

## 简介

A TypeScript agent SDK with zero runtime dependencies. Define an agent, give it tools, run the loop, get a typed result.
