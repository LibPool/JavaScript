# jev-axi

> 标签: agent, axi, classification, cli, jev, llm, toon, triage, typesafe

## 简介

Agent-ergonomic CLI for TypeSafe's Jev: offload snap judgments (choice, score, yes/no) over files and stdin to a fast calibrated model.
