# jev-debtgate

> 标签: ast, ci, cursor, jev, mcp, static-analysis, technical-debt, typesafe

## 简介

Jev-powered technical debt gate for coding agents and CI. Collects git/file metrics locally, asks TypeSafe Jev typed questions, then applies confidence policy.
