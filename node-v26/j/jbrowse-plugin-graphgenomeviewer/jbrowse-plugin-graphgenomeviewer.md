# jbrowse-plugin-graphgenomeviewer

> 标签: bandage, gfa, graph, jbrowse, jbrowse2, pangenome

## 简介

JBrowse 2 graph genome (pangenome) view: rGFA reference-anchored layouts, the Bandage force-directed engine, and haplotype lanes read from a gbz-base database
