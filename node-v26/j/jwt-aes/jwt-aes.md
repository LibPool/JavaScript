# jwt-aes

> 标签: encryption, jwt, security

## 简介

This package provides an encrypted version of JSON Web Tokens (JWT). There are two versions: one for encryption with AES 256 and one for encryption with RSA 2048. Encryption with AES is faster but you have to store your key on every server.
