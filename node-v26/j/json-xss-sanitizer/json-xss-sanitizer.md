# json-xss-sanitizer

> 标签: express, koa, middleware, sanitizer, security, xss

## 简介

Express 4.x middleware which sanitizes user input data (in req.body, req.query, req.headers and req.params) to prevent Cross Site Scripting (XSS) attack.
