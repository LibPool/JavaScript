# jbolaltci

> 标签: lojban, lojbau, lujvo, parser

## 简介

Parse Lojban text, look up each term's meaning, and decompose lujvo into their component gismu, using the camxes grammar, latkerlo-jvotci, and the lensisku dictionary API.
