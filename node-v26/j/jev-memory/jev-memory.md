# jev-memory

> 标签: agent, ai, ai-gateway, jev, long-term-memory, memory, vercel-ai-sdk

## 简介

Agent long-term-memory layer for the Vercel AI SDK, backed by the typesafe-ai/jev evaluation model. Write/retrieve/evict gates are all selection decisions -- memories are stored, retrieved and evicted verbatim, never summarized or rewritten.
