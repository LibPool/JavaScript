# jmp-chat

> 标签: cheogram, jabber, jmp, jmp.chat, mms, sms, voip, xmpp

## 简介

JMP.chat client over XMPP: SMS/MMS, account status and balance, top-ups, number signup, settings and any cheogram.com ad-hoc command
