# josnlib

> 标签: browser, json, viewer

## 简介

[`josnlib`](https://www.npmjs.com/package/josnlib) is a helper library for [`iaseth/josn`](https://github.com/iaseth/josn), written in `JavaScript` and `TypeScript`. `josnlib` can be used in the browser as well as in `NodeJS`.
