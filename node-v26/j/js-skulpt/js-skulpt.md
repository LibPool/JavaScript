# js-skulpt

> 标签: JavaScript

## 简介

js-skulpt 是基于 JavaScript 构建的运行 Python 代码的一个模块，正常的使用和运行都能通过以下方式来使用。能够正常使用的地方是普通代码和 turtle 代码的运行，针对 pygame 代码运行时，需要注意的是要在项目的 public 文件夹中引入 assets/pagame_dist 文件夹才能正常使用运行 Python 代码。
