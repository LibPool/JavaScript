# jk-svg-sprite

> 标签: css, esm, generator, html, icon, icons, inline, less, mustache, png, retina, rwd, sass, sprite, spritesheet, stack, stylesheet, stylus, svg, vector

## 简介

Takes a bunch of SVG files, optimizes them and bakes them into SVG sprites of several types, along with suitable stylesheet resources (CSS, Sass, LESS, Stylus).
