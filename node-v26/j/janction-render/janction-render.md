# janction-render

> 标签: 3d-rendering, ai-agent, blender, bpy, claude, cloud-rendering, codex, cursor, gltf, gpu, mcp, mcp-server, model-context-protocol, render-farm, rendering

## 简介

Blender scenes and 3D models (GLB, FBX, USD, OBJ, STL) rendered on cloud GPUs from Claude Desktop and other stdio-only MCP clients: product shots, 360-degree turntables, animations and stills. No local GPU or Blender; free to start.
