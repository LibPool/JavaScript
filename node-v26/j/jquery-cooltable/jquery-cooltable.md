# jquery-cooltable

> 标签: JSON, cellrendering, customsorting, ecosystem:jquery, grid, html, jquery-plugin, sorting, table

## 简介

very very cool jQuery plugin for creating tables with sorting, filtering, custom cell rendering, custom css, custom sorting support,dynamic row remove, dynamic row append.
