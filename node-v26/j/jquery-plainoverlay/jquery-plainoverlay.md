# jquery-plainoverlay

> 标签: busy, customizable, ecosystem:jquery, form, iframe, input, jquery-plugin, loading, overlay, progress, simple, ui, window

## 简介

The simple jQuery Plugin for customizable overlay which covers a page, elements or iframe-windows that is specified.
