# jsfullpage_scroll

> 标签: fullpage, horizontal scroll, javascript, jsfullpage, jsfullpage_scroll, plugin, scroll, vertical scroll

## 简介

A simple full-page scrolling plugin in vanilla JavaScript that supports both **vertical** and **horizontal** scrolling.
