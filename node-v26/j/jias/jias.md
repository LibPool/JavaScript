# jias

> 标签: jia-tools, tools, util, utils

## 简介

``` npm install jias ``` ## 导入 ```angular2html const jias = require('jias') ``` ## 从URL中解析参数 ```js jias.getParams('www.npmjs.com?a=b') ``` ## 判断要查询的数组是否至少有一个元素包含在目标数组中 ```js jias.hasOneOf([1],[1,2,3]) ``` ## 判断字符串中是否有某个字符 ```js jias.oneOf('1','123') ```
