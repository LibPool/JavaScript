# js-colormaps-es

> 标签: JavaScript

## 简介

The idea of this project is simple: make the [colormaps of Python's matplotlib library](http://matplotlib.org/examples/color/colormaps_reference.html) available in JavaScript. I came up with it because I needed a colormap in JavaScript for a side project
