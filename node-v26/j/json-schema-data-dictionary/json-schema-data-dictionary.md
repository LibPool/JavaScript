# json-schema-data-dictionary

> 标签: biomedical, bm25, codebook, data-dictionary, embeddings, epidemiology, html-table, hybrid-search, json-schema, metadata, onnx, semantic-search, transformers.js, vector-search, web-component, webgpu

## 简介

Turn interlinked JSON Schema documents that describe a tabular JSON dataset into a flat, spreadsheet-like data dictionary and an embeddable, searchable HTML table.
