# jervis-mediapipe

> 标签: accessibility, camera, computer-vision, face-landmarks, face-tracking, gesture-recognition, gestures, hand-tracking, interaction, mediapipe, touchless, virtual-keyboard, web-worker

## 简介

Production-oriented MediaPipe runtime and camera interaction SDK for the Web: hand and face tracking in workers, gesture semantics, DOM actions, and a camera-driven virtual keyboard.
