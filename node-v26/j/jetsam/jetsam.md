# jetsam

> 标签: ai-agents, audit, claude-code, context, mcp, tokens

## 简介

Find what your AI coding setup should throw overboard. Local-only diagnosis of harness waste — MCP schema costs, dead skills, cache busts, compaction churn, zombie processes — with safe, reversible fixes. Zero network calls, zero runtime dependencies.
