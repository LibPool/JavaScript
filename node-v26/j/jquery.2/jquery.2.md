# jquery.2

> 标签: JavaScript

## 简介

Alias for the most current version of jQuery 2.x, to allow for installing both jQuery 1 and 2 in the same project.

## 官网

- npm 页面：https://www.npmjs.com/package/jquery.2

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install jquery.2`
- npm registry：https://registry.npmjs.org/jquery.2
