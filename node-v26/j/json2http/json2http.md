# json2http

> 标签: arkTs, class, cli, code build, code generation, config, dart, deserialization, http, http request, https, json, json2class, json2http, json5, serialization, transform, typescript

## 简介

json2http is a CLI tool that depends on json2class for generating code from JSON or JSON5, enabling HTTP-based requests.
