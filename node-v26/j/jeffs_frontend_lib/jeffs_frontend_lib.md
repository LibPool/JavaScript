# jeffs_frontend_lib

> 标签: JavaScript

## 简介

Frontend library written from scratch with Typescript. Aims to provide declarative DOM/data reactivity with features similar to those in Vue.js. WIP. Not documented. Use React/Vue/Angular/similar instead.
