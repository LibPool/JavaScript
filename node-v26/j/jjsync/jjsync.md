# jjsync

> 标签: alternative, anotations, comments, js, json, jsos, package.js, package.json, package.jsos, sync, synchronize

## 简介

watches two files, a json and a js, ( defaults are ```package.json``` and ```package.jsos``` ) and makes them sync'ed
