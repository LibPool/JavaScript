# joplin-plugin-notesheet

> 标签: excel, joplin-plugin, spreadsheet, univer, xlsx

## 简介

Spreadsheets for Joplin. A Joplin note can be a full spreadsheet powered by the Univer SDK — formulas, formatting, sort, filter, charts, and .xlsx import/export.
