# jquery-mosaic

> 标签: ecosystem:jquery, gallery, jquery-plugin, mosaic

## 简介

A jQuery plugin by Tin.cat that builds responsive mosaics of images or any other content fitted to match heights in multiple rows while maintaining aspect ratios.

## 官网

- 官网：https://jquery-mosaic.tin.cat
- 源码仓库：git+https://github.com/tin-cat/jquery-mosaic.git
- npm 页面：https://www.npmjs.com/package/jquery-mosaic
