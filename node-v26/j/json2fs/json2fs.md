# json2fs

> 标签: JavaScript

## 简介

The use case for such CLI comes from kubernetes world. Sometimes we need to store secrets as key-value files. Here is the example from SAP world: https://www.npmjs.com/package/@sap/xsenv#usage-in-kubernetes The input however sometimes come as a JSON file.
