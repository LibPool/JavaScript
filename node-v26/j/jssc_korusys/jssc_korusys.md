# jssc_korusys

> 标签: JavaScript

## 简介

Modified version of jssc module which is a JavaScript serial connection library that uses Java. Edited by Korusys to provide raw data instead of a string. Full credit to OP! see jssc for original (https://www.npmjs.org/package/jssc)
