# json-to-equation

> 标签: addition, arithmetic, constants, division, equation, evaluate, exponentiation, json, library, math library, mathematics, multiplication, nested expressions, operations, precision, subtraction, tree structure

## 简介

A TypeScript-based library for evaluating nested arithmetic expressions in JSON format, utilizing high-precision Big.js calculations.
