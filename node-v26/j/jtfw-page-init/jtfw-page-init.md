# jtfw-page-init

> 标签: JavaScript

## 简介

项目用于jiazheng多页应用，帮助快速初始化页面。 目前支持以下4个项目 ``` jiazheng-aunt-h5 jiazheng-business jiazheng-custom jiazheng-union ```
