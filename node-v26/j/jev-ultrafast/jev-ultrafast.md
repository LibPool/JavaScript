# jev-ultrafast

> 标签: ai-agents, browser-agent, cdp, headless, jev, openrouter

## 简介

Browser agent that acts in ~0.5s per step via Jev. Headless-ready, works on your OpenRouter key. Python env bootstrapped on first run.
