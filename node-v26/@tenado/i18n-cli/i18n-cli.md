# @tenado/i18n-cli

> 标签: auto, cli, globalization, i18n, internationalization, intl, languages, locale, react, translation, vue, 全球化, 国际化, 多语言, 本地化, 翻译

## 简介

i18n-cli是一个自动国际化脚本，通过执行命令，自动提取代码里面的中文，自动调用百度或谷歌翻译接口，自动将翻译结果以 key-value 形式存入*.json 语言包里
