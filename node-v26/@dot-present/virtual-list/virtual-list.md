# @dot-present/virtual-list

> 标签: JavaScript

## 简介

在处理海量数据列表时，传统的滚动列表会导致性能问题，因为浏览器需要渲染所有 DOM 节点，而用户只能看到可见区域。虚拟列表组件通过只渲染可视区域内的少量 DOM 节点，通过动态计算起始/结束索引来模拟完整滚动效果，从而支持海量数据的高性能滚动。
