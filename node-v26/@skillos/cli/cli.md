# @skillos/cli

> 标签: base, cli, command-line, siwa, siwb, skillos, tournament, x402

## 简介

Official command-line interface for the SkillOS protocol — list tournaments, submit scores, fund prize pools, register ERC-8004 agents, and fetch x402-paywalled tier data from your terminal.
