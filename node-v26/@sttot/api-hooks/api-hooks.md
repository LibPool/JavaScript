# @sttot/api-hooks

> 标签: JavaScript

## 简介

在 React 中轻松且规范地定义 API 请求、一键创建钩子函数，包含状态跟踪、请求中断和请求刷新，并方便进行错误处理和批量请求与进度跟踪。
