# @mujtababhatti2/react-native-full-calendar

> 标签: android, appointments, calendar, day-view, event-calendar, full-calendar, ios, react-native, scheduling, timezone, typescript, week-view

## 简介

A customizable React Native calendar library for Android and iOS with TypeScript, timezone-aware day and week views, timed events, and scheduling callbacks.
