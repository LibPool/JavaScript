# @zeusk8s/sdk-instance

> 标签: api-client, eks, gke, k3s, kubernetes, sdk, zeus, zeusk8s

## 简介

JavaScript client SDK for the Zeus instance API (cluster/environment/infrastructure management). Works in the browser (session-cookie auth) and Node.js (service-token auth).
