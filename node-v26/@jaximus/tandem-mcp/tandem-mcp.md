# @jaximus/tandem-mcp

> 标签: agent, ai, canvas, claude, codex, collaboration, cursor, mcp, model-context-protocol, openai, tandem

## 简介

MCP server for Tandem — the shared state layer for parallel agent sessions: a durable task queue Claude Code, Cursor, Codex, or any MCP-aware session can claim from without colliding.
