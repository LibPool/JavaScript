# @12-apps/thermal-printing

> 标签: JavaScript

## 简介

Receipt printing for the two ways a thermal printer is attached, behind ONE fixed-width document. Isomorphic line model and wrapping (./), four type sizes, inverted bands, boxes, label/amount rows and raster images, the ESC/POS encoder with its CP850 code
