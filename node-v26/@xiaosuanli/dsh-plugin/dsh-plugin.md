# @xiaosuanli/dsh-plugin

> 标签: ai-video, conversational-video, deepseek-harness, dsh-plugin, novel-to-video, text-to-video, video-generation, video-remake, xiaosuanli, 小说转视频, 视频复刻, 视频生成

## 简介

让用户在 DeepSeek Harness（DSH）中通过自然语言对话生成、修改并导出 AI 视频，支持故事/小说转视频与参考视频复刻。
