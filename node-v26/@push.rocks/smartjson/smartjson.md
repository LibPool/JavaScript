# @push.rocks/smartjson

> 标签: JSON handling, JSON parsing, JSON stringifying, TypeScript support, base64 encoding, buffer handling, data decoding, data deserialization, data encoding, data serialization, typed JSON

## 简介

A library for handling typed JSON data, providing functionalities for parsing, stringifying, and working with JSON objects, including support for encoding and decoding buffers.
