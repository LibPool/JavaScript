# @push.rocks/websetup

> 标签: JSON-LD, OpenGraph, SEO, TypeScript, dynamic content, meta tags, smart delay, smart promise, structured data, tag management, web development, website setup

## 简介

A library for setting up basic properties of a web page including meta tags, OpenGraph tags, JSON-LD structured data, with support for dynamic content.
