# @push.rocks/smartslicer

> 标签: 3d printing, 3mf, bambu lab, gcode, klipper, orcaslicer, prusa, slicer

## 简介

Headless 3D-print slicing for Node.js with the OrcaSlicer CLI: system printer, process and filament profiles, G-code and Bambu Lab .gcode.3mf output.
