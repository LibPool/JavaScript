# @push.rocks/smartstate

> 标签: AbortSignal, TypeScript, asynchronous state, batch updates, computed state, context protocol, cumulative notification, middleware, observables, reactive programming, state action, state management, state notification, state selection, web components, web storage

## 简介

A TypeScript-first reactive state management library with middleware, computed state, batching, persistence, and Web Component Context Protocol support.
