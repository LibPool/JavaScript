# @maximmelnyk/cdk-s3-static-website-construct

> 标签: JavaScript

## 简介

You should explore the contents of this project. It demonstrates a CDK Construct Library that includes a construct (`CdkS3StaticWebsiteConstruct`) which contains an Amazon SQS queue that is subscribed to an Amazon SNS topic.
