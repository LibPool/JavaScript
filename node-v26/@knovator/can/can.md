# @knovator/can

> 标签: ACL, Can, Knovator, Permission, Role-based Structure, Security, authorization, chavda-bhavik, permission management

## 简介

Mostly in Admin Panel there is different roles and according to that each role have different access of routes or functionally. To achieve this we usually write too many condition get it through. In this package include methods like hasAccessOf, hasAccess
