# @wirehop/wirehop

> 标签: agent, ai-agent, fleet, mcp, mcp-server, mesh, modelcontextprotocol, networking, p2p, remote-access, ssh-alternative, vpn

## 简介

WireHop — secure peer-to-peer remote access and private networks. Single binary, no accounts, no port forwarding, no coordination server. Includes an MCP server so AI agents can reach and operate your machines.
