# @drugovlab/relay-sdk

> 标签: contact-form, email, events, form, form-backend, forms, leads, notifications, relay, telegram, typescript, webhook, zod

## 简介

TypeScript SDK for Relay: send form submissions and other events from websites, apps and servers to messengers, email and external systems, with zod validation and configuration as code.
