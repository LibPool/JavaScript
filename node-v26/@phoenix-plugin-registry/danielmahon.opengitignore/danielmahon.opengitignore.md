# @phoenix-plugin-registry/danielmahon.opengitignore

> 标签: JavaScript

## 简介

This extension will try to find and open the .gitignore file which Brackets hides by default.

## 官网

- 官网：https://github.com/danielmahon/brackets-opengitignore
- npm 页面：https://www.npmjs.com/package/@phoenix-plugin-registry/danielmahon.opengitignore
