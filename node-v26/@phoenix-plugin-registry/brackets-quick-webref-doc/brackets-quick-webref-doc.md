# @phoenix-plugin-registry/brackets-quick-webref-doc

> 标签: doc, search, webref

## 简介

Это расширение для Brackets позволяет искать документацию по html и css, на сайте https://webref.ru. Оно является форком расширения Quick MDN Doc (автор: Renan Veroneze <veroneze.renan@gmail.com>)
