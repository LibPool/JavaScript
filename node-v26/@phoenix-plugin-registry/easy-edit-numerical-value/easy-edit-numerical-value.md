# @phoenix-plugin-registry/easy-edit-numerical-value

> 标签: CSS, HTML, JavaScript, Preview, document, numerical, value

## 简介

Edit numerical value of CSS, HTML and JavaScript easier by + or - Key (also need Alt or Ctrl or Cmd).  You can see the element moving in the Live Preview.
