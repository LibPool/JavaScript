# @phoenix-plugin-registry/brackets-thymeleaf-code-hint

> 标签: Thymeleaf, hint, html, html5, thymeleaf

## 简介

Extend Brackets HTML code hints and collif's Brackets-HTML5CodeHints with Thymeleaf elements like th:if, th:text and attributes such as th:class, th:include, th:replace
