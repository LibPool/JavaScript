# @phoenix-plugin-registry/important-css

> 标签: JavaScript

## 简介

Add !important property to your CSS code by a keyboard shortcut. Default is a combination 'Shift-Ctrl-Z'. Select your CSS code and use the shortcut. In the newest version (1.0.4) you can just use the shortcut in a single line without selection!
