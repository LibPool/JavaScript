# @phoenix-plugin-registry/globexdesigns.brackets-jscs

> 标签: checker, code, javascript, jscs, linter, linting, style

## 简介

Adds JSCS support to Brackets. JSCS is a code style linter for programmatically enforcing your style guide. You can configure JSCS for your project in detail using over 120 validation rules.
