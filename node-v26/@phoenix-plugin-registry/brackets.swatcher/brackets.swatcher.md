# @phoenix-plugin-registry/brackets.swatcher

> 标签: less, photoshop, sass, scss, swatch

## 简介

Generates CodeHints/Colorpalettes from importing via LESS/SASS Files, Images (Colorpicker) or Adobe Swatchfiles (*.aco, *.ase)
