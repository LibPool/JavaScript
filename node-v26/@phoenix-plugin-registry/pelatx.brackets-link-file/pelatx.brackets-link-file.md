# @phoenix-plugin-registry/pelatx.brackets-link-file

> 标签: audio, cdn, copy files, css, drag, drop, file, image, javascript, libraries, link, php, project, tags, video

## 简介

Easily link your files (PHP, JavaScript, CSS, images, audio, video, fonts) into the focused document (HTML, PHP, CSS). It allows to copy several files in one time to any project folder or download from CDN and get them tagged automatically.
