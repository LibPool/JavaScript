# @phoenix-plugin-registry/brackets-sass

> 标签: hints, sass, scss

## 简介

An extension for Brackets to show all SASS hints in the code editor (including local/global variables, functions, mixins, keywords, parameters). It also supports "@import" directive to load assets from other files.
