# @phoenix-plugin-registry/pflynn.anti-lint-js

> 标签: JavaScript

## 简介

Disables Brackets' built-in JSLint checker and replaces it with a simple, plain-old JS syntax checker.

- 官网：https://github.com/peterflynn/anti-lint-js
