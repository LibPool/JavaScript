# @phoenix-plugin-registry/mryakobo.timequota

> 标签: measure, mryakobo, tid, tidsräknare, time, time waste, waste

## 简介

NOTE: Restart Brackets when install has finished. Measures how much time you've wasted on the currently open project. Adds View > Time Quota and an indicator that, when hovered, displays the quota.
