# @richardmcquiston01/dashboard-widgets-toolkit

> 标签: accessibility, chart, dashboard, gauge, kpi, layout, react, svg, typescript, vue, widgets

## 简介

Framework-agnostic dashboard widget toolkit: typed widget definitions and data payloads (KPI, gauge, table, bar list, alert list, chart), user layout (order, hide, minimise), and React renderers. Bring your own data providers.
