# @richardmcquiston01/makertool-image2outline

> 标签: cnc, contour, dxf, image-tracing, laser-cutting, maker, svg, vector-outline, vectorize

## 简介

Framework-agnostic TypeScript package that generates a vector outline (SVG and/or DXF) of an object from an image.
