# @beeranked/keyword-analyzer

> 标签: content-analysis, keywords, ngram, on-page-seo, seo, text-analysis, tf

## 简介

See the words and phrases a web page actually emphasises, and exactly where each one appears: title, meta description, URL, headings, intro, image alt text and link anchors. Counts and placements only, no fabricated search-volume numbers.
