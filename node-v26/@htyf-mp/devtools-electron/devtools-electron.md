# @htyf-mp/devtools-electron

> 标签: JavaScript

## 简介

Electron 主进程开发环境 Reporter。它不依赖 renderer 或 IPC，直接采集主进程 Console、Fetch、Node HTTP/HTTPS 和 WebSocket。Axios、got 及多数 Node SDK 最终使用的 `http.request`/`https.request` 默认会被统一采集。
