# @salient-ai/jira-cli

> 标签: atlassian, claude-code, cli, issue-tracker, jira, jira-cli, sprint

## 简介

Command-line interface for JIRA Cloud — issues, sprints, comments, worklogs, attachments, and more, with JSON I/O. Built for scripting and LLM tool use (e.g. Claude Code).
