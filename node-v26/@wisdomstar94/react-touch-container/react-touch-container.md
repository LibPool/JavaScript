# @wisdomstar94/react-touch-container

> 标签: JavaScript

## 简介

touch 또는 mousedown 이벤트를 이용하여 사용자가 터치 했는지 아닌지 여부를 알 수 있도록 해주는 기능을 제공하는 리액트용 `component` 를 제공합니다. <br /> 해당 컴포넌트는 PC와 Mobile 환경에서 모두 사용가능하며 Mobile 환경인 경우에는 멀티 터치 상황에서도 동작하도록 설계되었습니다.
