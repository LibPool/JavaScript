# @eherledan/blockui

> 标签: BlockUI

## 简介

Simulate synchronous ajax by blocking - not locking - the UI. This plugin lets you block user interaction with the page or with a specific element on the page. Also great at displaying modal dialogs. Compatible with jQuery 3.7+
