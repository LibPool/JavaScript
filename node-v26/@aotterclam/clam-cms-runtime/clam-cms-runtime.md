# @aotterclam/clam-cms-runtime

> 标签: JavaScript

## 简介

Runtime engine for clam-cms: dispatcher + entry-writer + view executor + content-ops + render pipeline + auth + MCP. Defines adapter-agnostic ports. MUST NOT import D1Database / KVNamespace types.
