# @pyreon/native-router-kotlin

> 标签: JavaScript

## 简介

PRIVATE / EXPERIMENTAL — Kotlin runtime implementing @pyreon/router's API surface (RouterProvider / RouterView / PyreonLink / useNavigate / useParams) for Android Compose. Parallel to @pyreon/native-router-swift. Phase C2 of the PMTC multiplatform router
