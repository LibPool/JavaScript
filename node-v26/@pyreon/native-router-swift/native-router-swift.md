# @pyreon/native-router-swift

> 标签: JavaScript

## 简介

PRIVATE / EXPERIMENTAL — SwiftPM package implementing @pyreon/router's API surface (RouterProvider / RouterView / Link / useNavigate / useParams) on top of SwiftUI's NavigationStack. Phase C1 of the PMTC multiplatform router story.
