# mexicoapi-mcp

> 标签: banxico, clabe, curp, código postal, días hábiles, fix, inegi, isr, mcp, mcp server, mexico, model context protocol, méxico, nss, rfc, salario mínimo, sat, sepomex, tipo de cambio, udis, uma

## 简介

Servidor MCP por stdio, de solo lectura, con datos oficiales de México: estados y municipios, bancos y CLABE, RFC, CURP, NSS, tipo de cambio FIX, UDIS, días hábiles, UMA, salario mínimo, ISR y códigos postales.
