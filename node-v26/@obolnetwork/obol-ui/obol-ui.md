# @obolnetwork/obol-ui

> 标签: JavaScript

## 简介

Obol Network's shared React component library, built with [Stitches](https://stitches.dev/) and organised using [Atomic Design](https://bradfrost.com/blog/post/atomic-web-design/) principles.
