# @kodespire/brotli-js

> 标签: br, brotli, compression, decompression, napi, react-native, stream, wasm

## 简介

Brotli compression for Node.js, Bun, Deno, browsers, edge runtimes and React Native. Native bindings to the official google/brotli library with a WebAssembly fallback.
