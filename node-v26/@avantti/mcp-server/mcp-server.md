# @avantti/mcp-server

> 标签: avantti, fintech, mcp, model-context-protocol, pagamentos, payments, pix

## 简介

Servidor MCP oficial da Avantti Finance — permite que assistentes de IA criem cobranças PIX, cartão, boleto e realizem transferências PIX via API.
