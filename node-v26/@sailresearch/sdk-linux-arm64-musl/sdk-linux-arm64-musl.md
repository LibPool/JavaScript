# @sailresearch/sdk-linux-arm64-musl

> 标签: ai-agents, sail, sailbox, sandbox, sdk, vm

## 简介

TypeScript SDK for Sail sandboxes (Sailboxes). Create, exec in, and manage sandboxes from agent harnesses on Node and Bun.
