# @oshon-ai/cli

> 标签: cli, components, design-system, oshon, oshon-ai, react, shadcn-style, tailwind

## 简介

Oshon CLI — shadcn-style component-add tool. `npx @oshon-ai/cli add button` copies a component into your codebase from the live registry at https://oshon.ai/r.
