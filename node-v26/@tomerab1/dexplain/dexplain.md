# @tomerab1/dexplain

> 标签: build, buildkit, cache, cli, devtools, docker, docker-build, dockerfile, explain, layers

## 简介

EXPLAIN for Docker builds and images — collects build/image facts, runs a deterministic rule engine, emits ranked findings for Claude to reason over.
