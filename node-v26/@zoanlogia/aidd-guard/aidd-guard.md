# @zoanlogia/aidd-guard

> 标签: acceptance-criteria, ai-driven-development, aidd, ci, jest, spec-driven-development, traceability, vitest

## 简介

Deterministically report which AIDD acceptance criteria are covered by a Vitest or Jest test. Never runs the tests, never calls an LLM.
