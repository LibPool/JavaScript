# @guangda88/lingsearch

> 标签: mcp, model-context-protocol, multi-agent, search, searxng, sourcegraph, unified-search

## 简介

Unified search MCP server: routes queries between local sources (SQLite memory, PostgreSQL KB, code grep) and external providers (AnySearch, SearXNG, Sourcegraph) with automatic fallback.
