# @infinilabs/ai-answer

> 标签: JavaScript

## 简介

一个用于展示 AI 回答的 React 组件。基于 `@ant-design/x-markdown` 构建，支持 Markdown 渲染、长文本自动折叠、流式输出展示、深色模式以及底部操作栏。
