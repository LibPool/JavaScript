# @ahtmljs/astro

> 标签: agent-web, ahtml, ai, astro

## 简介

AHTML adapter for Astro — .well-known/ahtml.json, snapshot routes with content negotiation, MCP emission, and llms.txt for any Astro site. Built on the @ahtmljs/extract plugin API.
