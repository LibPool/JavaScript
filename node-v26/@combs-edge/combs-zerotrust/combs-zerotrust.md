# @combs-edge/combs-zerotrust

> 标签: aes-gcm, combs, e2e-encryption, ecdh, webcrypto, zero-trust

## 简介

Zero-trust crypto core for Combs Engine — identity, sealed envelopes, at-rest keystore, capability tokens. Pure WebCrypto; browser, Node and Deno.
