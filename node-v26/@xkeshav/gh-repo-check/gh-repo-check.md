> 标签: GitHub, cli, community files, community health files, discussion templates, gh-repo-check, health files, health-check, issues templates, open source, repo-health-check

## 简介

This is a cli tool which help your GitHub repository to make it community supportive by adding necessary health files and customized templates for issues and discussions tab which boost your project for better contribution.
