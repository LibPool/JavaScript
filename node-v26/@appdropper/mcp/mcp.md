# @appdropper/mcp

> 标签: apk, appdropper, beta-testing, build-distribution, claude-code, copilot, cursor, flutter, ipa, mcp, mcp-server, model-context-protocol, react-native

## 简介

MCP server for App Dropper. Lets Claude Code, Cursor, VS Code Copilot and other MCP clients upload .apk and .ipa builds and return the tester install link.
