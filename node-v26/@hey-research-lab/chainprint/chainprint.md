# @hey-research-lab/chainprint

> 标签: cli, developer-tools, evm, hey-research, robinhood-chain, static-analysis, typescript

## 简介

Detects evidence that a source repository targets Robinhood Chain (chain id 4663) and explains a deterministic confidence. A marker is evidence, not identity.
