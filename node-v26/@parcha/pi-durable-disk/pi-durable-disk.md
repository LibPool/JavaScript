# @parcha/pi-durable-disk

> 标签: agent, archil, disk, durable, fence, lease, pi, pi-durable, supervisor

## 简介

The agent is the workspace: its conversation and its files live together in one directory on a disk. Mount it on any Linux host or container, release it, and mount it elsewhere: the agent carries on.
