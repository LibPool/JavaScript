# @deot/docs

> 标签: JavaScript

## 简介

`@deot/docs` 是 `@deot/docs` 工具链的聚合包。公共入口导出 `Dever`、`Locale`、`Renderer` 与 `Theme` 命名空间，分别用于文档服务、界面国际化、页面渲染/装修和主题协议。
