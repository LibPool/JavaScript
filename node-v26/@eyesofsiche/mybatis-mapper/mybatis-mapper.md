# @eyesofsiche/mybatis-mapper

> 标签: mapper, mybatis, mysql, node.js, sql, xml

## 简介

Maintained fork of mybatis-mapper. Generates SQL from MyBatis3 Mapper XML in Node.js. Supports Dynamic SQL.
