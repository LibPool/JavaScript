# cdk-serverless-idp

> 标签: aws-cdk, cdk, construct, dynamodb, identity-provider, idp, keycloak-alternative, lambda, multi-tenant, oauth2, oidc, openid-connect, saas, serverless

## 简介

AWS CDK construct: a multi-tenant OpenID Connect identity provider on Lambda + DynamoDB that costs nothing while nobody is signing in. Realms per customer, applications per SaaS, post-login hooks.
