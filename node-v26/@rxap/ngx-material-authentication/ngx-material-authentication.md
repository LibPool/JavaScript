# @rxap/ngx-material-authentication

> 标签: angular, angular-material-authentication, material, ngx, packages, rxap

## 简介

This package provides Angular Material components and services for user authentication, including login, reset password, and loading functionalities. It offers pre-built forms, methods, and UI components to streamline the implementation of authentication
