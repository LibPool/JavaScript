# @formwright/ui-core

> 标签: disposal, dom, formwright, headless, memory-leak, signals

## 简介

Headless DOM foundation shared by every Formwright renderer: scoped disposal, reactive bindings, and the behaviours components are built from. Zero dependencies outside @formwright/reactive.
