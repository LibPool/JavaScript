# @gaphub/feed

> 标签: atom, blog, feed, generator, json, opml, parser, rss, syndication, wrapper, xml

## 简介

@gaphub/feed is a RSS, Atom, JSON feed and OPML generator/parser for Node.js, making content syndication simple and intuitive!
