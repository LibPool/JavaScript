> 标签: ci, ci-cd, cli, commit-message, developer-tools, git-hooks, github-actions, guardrails, husky-alternative, lint, pull-request, quality-checks, required-status

## 简介

Run and maintain project quality checks (lint, tests, audit, Git Guardian rules) locally and in GitHub Actions with one required status. Config-driven CI runner with JSON reports.
