# @momiji-rs/termshot

> 标签: ansi, asciinema, png, pty, screenshot, terminal, tui

## 简介

A screenshot tool for terminal output you already have: replays a PTY log or asciinema cast into a PNG, text or JSON of the final screen, headless.
