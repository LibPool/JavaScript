# @astrake/lumora-server

> 标签: api, astrake, bun, framework, hono, lumora, rest, sqlite, sse, typescript, websocket

## 简介

Slim Bun + Hono framework — typed config, file-based resources, auto-generated REST/SSE/WebSocket endpoints, JWT auth, SQLite, and an interactive init wizard.
