# @z2net/bffi

> 标签: bffi, bun, codegen, ffi, loader, native, rust, typed

## 简介

Bun-only bffi integration for TypeScript: config-driven pipeline (cargo build, api.gen generation, platform binary resolution) and a typed loader for bffi-rs native modules.
