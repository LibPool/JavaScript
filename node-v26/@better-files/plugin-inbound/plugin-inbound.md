# @better-files/plugin-inbound

> 标签: better-iam, data-room, email, inbound, typescript, upload

## 简介

Email to a data room for Better Files: per-folder drop addresses whose attachments become documents, with sender allow-lists, expiry and provider authentication (Postmark adapter included)
