# @alternayte/queuebox-inbox

> 标签: inbox, outbox, postgresql, queuebox, sqlserver, transactional

## 简介

A pull-inbox worker for QueueBox. It claims, renews, completes, retries and dead-letters messages, and it runs the completion inside the handler's own transaction.
