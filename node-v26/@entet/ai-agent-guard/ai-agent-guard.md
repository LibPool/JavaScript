# @entet/ai-agent-guard

> 标签: ai, ai-agent, claude, claude-code, cli, codex, cursor, devsecops, mcp, prompt-injection, secret-scanner, secrets, security, static-analysis

## 简介

Scan a project for leaked secrets, risky MCP configs, and unsafe automation before handing it to an AI coding agent (Claude Code, Cursor, Codex). Zero dependencies, runs locally.
