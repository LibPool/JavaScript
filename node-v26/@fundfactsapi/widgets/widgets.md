# @fundfactsapi/widgets

> 标签: ETF, ISIN, SRRI, TER, charts, factsheet, fund data, fundfacts, holdings, react, widgets

## 简介

React widgets for FundFacts API payloads: growth chart, donut, weight bars, key-fact tiles, SRRI risk scale, profile chips, calendar and annualised returns, and a complete factsheet from one response. Zero dependencies, inline styles, themeable with CSS v
