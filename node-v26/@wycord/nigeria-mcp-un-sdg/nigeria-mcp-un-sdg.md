# @wycord/nigeria-mcp-un-sdg

> 标签: development, mcp, model-context-protocol, nigeria, poverty, sdg, statistics, united-nations

## 简介

Nigeria's UN Sustainable Development Goals indicators (poverty, under-5 mortality, electricity and water access, primary-school completion) as MCP tools. Backed by the UN SDG Global Database API, keyless. A Wycord product, built by Braynex Services Ltd.
