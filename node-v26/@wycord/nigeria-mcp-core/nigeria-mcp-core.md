# @wycord/nigeria-mcp-core

> 标签: ai-agents, api, data, mcp, model-context-protocol, naija, nigeria, zod

## 简介

Core runtime for the Nigeria MCP data-lane servers: MCP server builder, normalized Zod schemas, typed provider seam, and shared fetch/cache/error helpers. A Wycord product, built by Braynex Services Ltd.
