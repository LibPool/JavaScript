# @brink-lang/editor

> 标签: codemirror, editor, ink, interactive-fiction, narrative

## 简介

The brink ink-language CodeMirror 6 editor: syntax-aware extensions, inline rename, code actions, folding, completions, project search, and per-view document sessions for building an ink IDE in the browser.
