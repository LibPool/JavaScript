# @voyant-travel/workflows-orchestrator-cloudflare

> 标签: JavaScript

## 简介

Cloudflare Worker + Durable Object adapter for @voyant-travel/workflows-orchestrator. Dispatches workflow-step requests to tenant Workers via a Workers-for-Platforms dispatch namespace.
