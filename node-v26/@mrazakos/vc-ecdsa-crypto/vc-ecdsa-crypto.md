# @mrazakos/vc-ecdsa-crypto

> 标签: crypto, ecdsa, ethereum, fast-crypto, mobile-crypto, secp256k1, signing, verifiable-credentials, verification

## 简介

Fast ECDSA cryptographic utilities for Verifiable Credentials - 100-1000x faster than RSA on mobile devices. Smart contract ready with Ethereum address-based public keys.
