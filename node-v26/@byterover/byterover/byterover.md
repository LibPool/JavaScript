# @byterover/byterover

> 标签: byterover, byterover-mono, context-engine, openclaw, openclaw-plugin

## 简介

ByteRover context engine plugin for OpenClaw (mono build) - in-process recall plus the brv_record tool for durable ByteRover memory writes.
