# @milesverse/sdk

> 标签: JavaScript

## 简介

MilesVerse JavaScript SDK: token exchange against a registered platform application, silent refresh, and a typed client for the catalogue, sessions and progress APIs. Framework-agnostic — Angular, React, or plain fetch environments.
