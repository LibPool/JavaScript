# @jujiuyey/ledger-vue

> 标签: data-table, datagrid, table, tanstack-table, virtualization, vue

## 简介

Vue-native <DataTable> on TanStack Table and TanStack Virtual: sorting, filtering, pagination, selection, pinning, inline editing, and adaptive row virtualization. The Vue port of @coldsmirk/ledger-mantine.
