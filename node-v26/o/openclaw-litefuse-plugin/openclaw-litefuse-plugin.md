# openclaw-litefuse-plugin

> 标签: langfuse, litefuse, llm, observability, openclaw, openclaw-plugin, tracing

## 简介

OpenClaw plugin for reporting AI agent execution traces to Litefuse. Supports multi-target and self-hosted Litefuse.
