# opencode-headroom-plugin

> 标签: aws-bedrock, context-compression, headroom, llm, opencode, opencode-plugin, token-optimization

## 简介

OpenCode v2 plugin that transparently compresses large tool results via Headroom at the message level — works with any provider, including AWS Bedrock.
