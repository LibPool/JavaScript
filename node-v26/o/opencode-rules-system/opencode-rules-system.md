# opencode-rules-system

> 标签: claude, coding-standards, conventions, opencode, opencode-plugin, rules

## 简介

OpenCode plugin - Auto-load rules from .claude/rules/ and .opencode/rules/ with conditional glob matching, frontmatter parsing, and system prompt injection
