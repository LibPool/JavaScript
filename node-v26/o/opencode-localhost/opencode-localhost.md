# opencode-localhost

> 标签: gguf, gpu, llama-server, llama.cpp, local-models, opencode, opencode-plugin, self-hosted, vllm

## 简介

Run local models in opencode. llama.cpp as a provider, with live GPU, VRAM and CPU telemetry in the sidebar.
