# ooxml.js

> 标签: codec, docx, ooxml, opc, pptx, round-trip, xlsx, zod

## 简介

Type-safe, lossless round-trip conversion between OOXML packages (docx, pptx, xlsx) and JSON, built on Zod 4 codecs.
