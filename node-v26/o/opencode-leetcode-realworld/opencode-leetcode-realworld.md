# opencode-leetcode-realworld

> 标签: algorithms, interview, leetcode, opencode, opencode-plugin, practice

## 简介

OpenCode plugin that turns a LeetCode problem into a realistic software-engineering assignment, so you practice applying the underlying algorithm instead of solving the puzzle.
