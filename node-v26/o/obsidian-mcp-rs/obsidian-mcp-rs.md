# obsidian-mcp-rs

> 标签: ai, ai-assistant, claude, cross-platform, cursor, knowledge-base, llm, markdown, mcp, mcp-server, model-context-protocol, note-taking, notes, npx, obsidian, obsidian-plugin, obsidian-vault, rust, stdio, vault

## 简介

Rust MCP server for Obsidian vaults — read, write, search notes via Model Context Protocol. Works with Claude, Cursor, and any MCP client.
