# opengeometry

> 标签: aec, bim, browser-cad, cad, cad-kernel, geometry, ifc, opengeometry, parametric-modeling, step, stl, three.js, threejs, wasm, webassembly

## 简介

CAD kernel for the web built with Rust, WebAssembly, and Three.js for browser CAD, AEC/BIM, and geometry-heavy tools.
