# opencode-sonar-fix

> 标签: code-quality, github, opencode, opencode-plugin, pull-request, sonar, sonarqube, static-analysis

## 简介

OpenCode plugin + slash command that fetches NEW SonarQube issues introduced by the current PR and lets the agent fix them automatically.
