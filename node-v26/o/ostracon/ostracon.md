# ostracon

> 标签: ast, code-archaeology, decision-history, git, history, provenance, tree-sitter, typescript

## 简介

從 git history 重建程式碼的決策演化史：何時誕生、被哪幾次改動重塑、理由是什麼、哪些做法試過又被推翻。結構層零 LLM。
