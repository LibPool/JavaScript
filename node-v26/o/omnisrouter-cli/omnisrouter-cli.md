# omnisrouter-cli

> 标签: claude-code, codex, cursor, llm-router, llm-routing, omnisrouter

## 简介

Thin installer that wires Claude Code, Codex, and Cursor to a running OmnisRouter (self-hosted, transparent LLM routing proxy).
