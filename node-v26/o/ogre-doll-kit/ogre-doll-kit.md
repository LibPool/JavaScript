# ogre-doll-kit

> 标签: JavaScript

## 简介

关节式切件骨架成品包(酒鬼巨汉):肩肘腕/髋膝踝三层骨骼,idle/walk/run/attack/jump 五个动作,Cocos Creator 3.8。npm 装包后跑 ogre-doll-sync 把资源同步进工程 assets/resources/。
