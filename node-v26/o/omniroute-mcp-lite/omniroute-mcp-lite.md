# omniroute-mcp-lite

> 标签: mcp, omniroute, stdio, web-fetch, web-search

## 简介

Thin zero-dependency stdio MCP proxy exposing only OmniRoute's web_search + web_fetch tools (keeps agent context at ~630 tokens instead of 14k).
