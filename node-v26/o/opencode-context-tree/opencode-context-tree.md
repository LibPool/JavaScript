# opencode-context-tree

> 标签: branch, context-engineering, context-tree, crop, merge, opencode, opencode-plugin, trajectory, tui

## 简介

Pi-style context tree for OpenCode: branch, merge (human-confirmed decision records), crop, undo, plus a DeepSeek-Harness-style trajectory view
