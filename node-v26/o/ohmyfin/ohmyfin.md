# ohmyfin

> 标签: banking, bic, correspondent-banking, iban, ohmyfin, payment-validation, ssi, swift, swift-code, tracking, trackmyswift, transaction

## 简介

Official Node.js SDK for Ohmyfin API - SWIFT transaction tracking, validation, and SSI data (previously known as TrackMySwift)
