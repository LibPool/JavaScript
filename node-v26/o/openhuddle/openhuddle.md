# openhuddle

> 标签: agents, ai, brainstorm, claude-code, code-review, codex, collaboration, cursor, mcp, multi-agent, multiplayer, vibe-coding

## 简介

Multiplayer mode for AI coding agents. Your team's Claude Code, Codex and Cursor agents brainstorm and review together, share one master prompt and task board, and never edit each other's files.
