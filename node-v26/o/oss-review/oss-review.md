# oss-review

> 标签: ai, claude, compliance, license, mcp, model-context-protocol, npm-audit, open-source, oss, sbom, secretlint, secrets, security, vulnerability

## 简介

Model Context Protocol (MCP) server for open source release readiness reviews. Scans repositories for secrets, license violations, security vulnerabilities, and sensitive internal references customisable to your organization.
