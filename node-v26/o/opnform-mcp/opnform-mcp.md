# opnform-mcp

> 标签: ai, anthropic, claude, form-builder, forms, llm, mcp, model-context-protocol, modelcontextprotocol, opnform, stdio, streamable-http

## 简介

Model Context Protocol (MCP) server for OpnForm — manage forms, submissions, workspaces, users and integrations from Claude and any MCP client. Runs locally via npx (stdio) or remotely over Streamable HTTP.
