# opsdraw-mcp

> 标签: architecture, claude, devops, diagram, kubernetes, mcp, mermaid, model-context-protocol, terraform

## 简介

MCP server for OpsDraw: let AI assistants create, edit, validate and lay out Mermaid architecture diagrams and import infrastructure code (Terraform, OpenTofu, Kubernetes, Proxmox and more).
