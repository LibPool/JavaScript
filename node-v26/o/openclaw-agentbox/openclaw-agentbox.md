# openclaw-agentbox

> 标签: agentbox, inference, jupiter, llm, openclaw, openclaw-plugin, pay-per-use, payment, pump-fun, solana, token-swap, usdc, wallet, x402

## 简介

OpenClaw plugin for pay-per-use LLM inference via x402 USDC payments on Solana. Includes wallet management, token swaps, and token launching.
