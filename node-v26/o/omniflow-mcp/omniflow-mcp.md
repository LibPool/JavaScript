## 简介

MCP server for Google Flow (Veo 3 / Omni 1.1): batch video generation from Claude Code and Claude Desktop through the OmniFlow Chrome extension. The missing Google Flow API — prompts, queue, keyframes, auto-download on your own Google AI plan.
