# obfuscate-my-code

> 标签: Javascript, Typescript, encode, encoding, hash, hashing, minified, minifier, minify, obfuscate, obfuscator, project

## 简介

You can use this to obfuscate (AND, OR) minify your project files so it can't be easily stolen or to make it very hard to read.
