# opentransitinformation

> 标签: accessibility, diagram, geojson, gtfs, maps, svg, transit, transport, wasm

## 简介

Deterministic transit diagrams, OpenStreetMap geographic context and accessible offline interactive maps powered by Rust and WebAssembly.
