# orchestra-agents

> 标签: agents, ai, anthropic, claude, multi-agent, orchestrator, swarm

## 简介

Multi-agent orchestrator on the Claude API: one conductor plans, sub-agents execute in parallel, adversarial critics attack, the conductor synthesizes one deliverable.
