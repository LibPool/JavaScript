# orc-camp-assets

> 标签: asset-pack, assets, orc-camp, pixel-art, pixellab, sprites

## 简介

Optional PixelLab.ai pixel-art asset pack for the orc-camp dashboard (sprites, portraits, backgrounds, tiles, objects, UI). Install globally alongside orc-camp to render real sprites instead of CSS placeholders.
