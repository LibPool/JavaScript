# opencode-agent-plugins

> 标签: agent-plugins, cli, mcp, opencode, plugin, skills

## 简介

Agent Plugins client for OpenCode: load, validate, and register Agent Plugins (skills + MCP servers) and manage their lifecycle via CLI.
