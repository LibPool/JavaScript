# omp-smart-approve

> 标签: approval, extension, oh-my-pi, omp, plugin, prompt-injection, security

## 简介

An LLM safety judge in front of tool calls OMP would otherwise auto-approve. Hard-blocks clear attacks and clear mistakes, escalates genuine uncertainty to a human.
