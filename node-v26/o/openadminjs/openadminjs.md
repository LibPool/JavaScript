# openadminjs

> 标签: admin, cli, generator, monorepo, nestjs, nextjs, openadminjs, prisma, scaffold

## 简介

CLI scaffold generator for OpenAdminJS monorepos (NestJS, Prisma, Next.js). Not a runtime library — use npx openadminjs create.
