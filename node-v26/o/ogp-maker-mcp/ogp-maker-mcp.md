# ogp-maker-mcp

> 标签: budoux, japanese, mcp, modelcontextprotocol, og-image, ogp

## 简介

MCP server that generates Japanese OGP images (1200x630) with natural line breaking (BudouX) and kinsoku shori. 日本語が崩れないOGP画像を生成するMCPサーバー。
