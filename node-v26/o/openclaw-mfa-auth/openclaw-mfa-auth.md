# openclaw-mfa-auth

> 标签: JavaScript

## 简介

`mfa-auth` 是一个提供多因素身份验证（MFA）的安全扩展插件。它主要用于保护敏感操作和验证首次对话的用户身份,确保系统的安全性和可控性。
