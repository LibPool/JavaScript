# oxlint-plugin-organize-imports

> 标签: imports, linter, organize-imports, oxc, oxlint, oxlint-plugin, sort-imports, typescript

## 简介

Oxlint plugin that organizes imports the way the editor's 'Organize Imports' does, via the TypeScript language service (5/6) or the tsgo language server (7)
