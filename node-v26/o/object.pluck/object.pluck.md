> 标签: check, is, is-object, isobject, javascript, key, keys, object, plain, pluck, prop, properties, property, props, type, type-of, typeof, util, utilities, utility, utils, value, values

## 简介

Like pluck from underscore / lo-dash, but returns an object composed of specified properties, with values unmodified from those of the original object.
