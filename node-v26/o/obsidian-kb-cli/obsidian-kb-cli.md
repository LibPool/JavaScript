# obsidian-kb-cli

> 标签: karpathy, knowledge-base, lint, llm, obsidian, wiki

## 简介

CLI for the Karpathy-style LLM-wiki workflow on Obsidian vaults — lint, bootstrap, index, log. Companion to the obsidian-kb skill.
