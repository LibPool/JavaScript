# openssl-file

> 标签: buffer, cipher, decipher, decrypt, decryption, encrypt, encryption, file, openssl, ssl, stream, symmetric

## 简介

A Javascript library for node, to enable it to encrypt and decrypt files in a openssl compatible way.
