# omp-deck

> 标签: ai, bun, coding-agent, kanban, llm, oh-my-pi, omp, react, self-hosted, tailscale, tailwind

## 简介

Cockpit web UI for the omp (oh-my-pi) coding agent — multi-session chat, kanban, cron routines, inbox, messaging bridges, and a marketplace browser. Designed to be served loopback-only behind a Tailscale gate or SSH tunnel.
