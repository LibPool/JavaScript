# operon-sandbox

> 标签: JavaScript

## 简介

Host-side sandbox lifecycle for operon-agents: create, snapshot, pause and destroy a vendor sandbox, and hand the framework a Machine driven by the vendor SDK directly (native per-command timeout, incremental output, real kill).
