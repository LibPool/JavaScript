# opencode-cross-session-messaging

> 标签: cross-device, cross-session, messaging, multi-agent, opencode, opencode-plugin, relay

## 简介

OpenCode plugin for cross-session messaging — local file IPC or cross-device relay via HTTP polling. Sessions discover, ask, and reply across machines.
