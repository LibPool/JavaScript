# obsidian-dsh-acp

> 标签: acp, agent, agent-client-protocol, deepseek-harness, dsh, obsidian

## 简介

Expose DeepSeek Harness (DSH) over the Agent Client Protocol (ACP) for Obsidian Agent Client (and other ACP clients). Install as a Custom Agent in Obsidian, or as a cordis plugin in a DSH profile, to drive DSH right from Obsidian — list/resume/fork sessio
