# orbbox

> 标签: agent, ai, eve, flue, linux, orbstack, sandbox, vm

## 简介

OrbStack-backed Linux VM sandboxes for AI agents: create, exec (with streaming), file IO, isolate. Supports Vercel Eve and Flue agent frameworks.
