# openwindow-cli

> 标签: agent, ai, cli, coding-agent, openrouter, scaffolding, terminal

## 简介

OpenWindow CLI — a terminal coding agent powered by OpenRouter, with Blitz/Omega/Maximus speed tiers, project-scaffolding templates, and an opt-in 'openwindow setup' command for saving your API key permanently. Reads, writes, and deletes files and runs sh
