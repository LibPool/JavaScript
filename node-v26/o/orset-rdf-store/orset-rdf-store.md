# orset-rdf-store

> 标签: conflict-free, crdt, eventual-consistency, offline-first, or-set, rdf, rdf-1.2, rdfjs, triple-store

## 简介

A proof-of-concept RDFjs-compliant triple store with state-based OR-Set (add-wins) CRDT semantics, enabling conflict-free concurrent writes to RDF datasets over HTTP
