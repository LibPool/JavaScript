# opencode-notify-crossx

> 标签: cross-platform, desktop, notification, opencode, opencode-plugin, wsl

## 简介

Cross-platform desktop notifications for opencode — pings when run finishes or input is needed. Focus-aware, WSL + macOS + Linux. No sound by default, visual toast only.
