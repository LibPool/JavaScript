# openapi-axios-sdk

> 标签: axios, code-generator, codegen, hey-api, openapi, openapi3, sdk, sdk-generator, swagger, ts, typescript

## 简介

Generate fully-typed Axios SDKs from OpenAPI / Swagger specs. Multi-spec runtime isolation (BASE / token / headers don't pollute each other), incremental cache, defineConfig + CLI. Built on top of @hey-api/openapi-ts.
