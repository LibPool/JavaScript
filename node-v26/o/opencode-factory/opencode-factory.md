# opencode-factory

> 标签: agents, factory, opencode, opencode-factory, opencode-plugin

## 简介

OpenCode Factory: a lightweight OpenCode V2 agent pack — eight agents (foreman, machinist, sage, explorer, librarian, reviewer, advisor, curator), argument-based workflow commands, two skills, a read-only project-context plugin, and the ocf installer CLI.
