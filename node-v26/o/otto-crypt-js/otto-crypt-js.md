# otto-crypt-js

> 标签: aead, aes-gcm, argon2id, encryption, hkdf, interop, laravel, siv, streaming, x25519

## 简介

OTTO Crypt JS: AES-256-GCM + HKDF-SIV style streaming AEAD compatible with Laravel OTTO package; includes X25519 and Argon2id via libsodium.
