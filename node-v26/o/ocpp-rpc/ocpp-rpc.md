# ocpp-rpc

> 标签: ocpp, ocpp rpc, ocpp websockets, ocpp-j, ocpp1.6, ocpp1.6j, ocpp2.0.1, ocpp2.0.1j, ocpp2.1, rpc, rpc client, rpc server, wamp, websocket rpc, websockets

## 简介

A client & server implementation of the WAMP-like RPC-over-websocket system defined in the OCPP protocols (e.g. OCPP1.6-J and OCPP2.0.1).
