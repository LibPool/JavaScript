# omora-sdk

> 标签: base, erc20, ethereum, launchpad, omora, uniswap-v4, viem

## 简介

TypeScript SDK for the Omora launchpad on Base — read pool/fee state and submit buy, sell, launch, and fee-claim transactions against the real deployed contracts.
