# ollama-vue-demo

> 标签: JavaScript

## 简介

- 本地部署ollama来提供服务，使用vue3来渲染UI，实现简单的对话模式。整个项目非常简单，非常适合学习js请求流式数据及自动码字的交互实现。   [](https://tdesign.tencent.com/chat/components/chat-loading  这块的页面也可以优化) ## 基本介绍
