# openinstaflow

> 标签: instagram, instagram-graph-api, mcp, meta, model-context-protocol, openinstaflow

## 简介

OpenInstaFlow — an MCP server for the Instagram Graph API (profile, media, insights, publishing, Pages, DMs). Bring your own Meta token.
