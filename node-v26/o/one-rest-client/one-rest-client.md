# one-rest-client

> 标签: JavaScript

## 简介

OneRestClient allows you to quickly bootstrap a ONE Framework REST client for your JavaScript application using your preffered HTTP Client (we recommend *[Axios](https://axios-http.com/docs/intro)*).
