# onvif-dashboard

> 标签: annke, cctv, dashboard, hikvision, ip-camera, nvr, onvif, surveillance, webrtc

## 简介

Web dashboard for ONVIF cameras (Hikvision, Annke): discovery, live video over WebRTC, motion recording and settings, all on your own network.
