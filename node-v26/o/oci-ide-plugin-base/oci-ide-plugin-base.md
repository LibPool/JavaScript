# oci-ide-plugin-base

> 标签: OCI, OCI Toolkit, Oracle, Typescript, node, plugins, vscode

## 简介

OCI Plugin base is a common library used to share the generic functionalities across the OCI service plugins which comprises of functionalities like File System, Authprovider, Monitoring, etc
