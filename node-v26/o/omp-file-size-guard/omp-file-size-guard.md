# omp-file-size-guard

> 标签: ai-agent, ci, claude-code, code-quality, file-size, guardrails, oh-my-pi, opencode, pi, pre-commit

## 简介

AI-agent extension that blocks and reports oversized files, with per-project exemptions and first-run onboarding. Adapters for omp, pi, and opencode.
