# opfs-leader

> 标签: broadcastchannel, leader-election, local-first, multi-tab, opfs, sqlite, wasm, web-locks, worker

## 简介

One tab owns the worker, every tab can call it. Web Locks leader election and single-writer query routing for OPFS-backed browser databases. Zero dependencies.
