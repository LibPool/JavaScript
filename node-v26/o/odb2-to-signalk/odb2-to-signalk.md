# odb2-to-signalk

> 标签: elm327, engine, marine, obd2, signalk-category-hardware, signalk-category-instruments, signalk-node-server-plugin

## 简介

Signal K server plugin with companion WebApp that reads OBD-II/ELM327 data, decodes supported PIDs, and publishes configurable Signal K mappings.
