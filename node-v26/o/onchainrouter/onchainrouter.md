# onchainrouter

> 标签: ai-agents, arc, circle, hedera, mcp, micropayments, x402

## 简介

Sell an API to AI agents over x402 on Hedera and Arc, or pay for one. Server wrapper, paying client, and a wallet MCP for chat clients.
