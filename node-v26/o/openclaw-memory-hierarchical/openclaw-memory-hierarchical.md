# openclaw-memory-hierarchical

> 标签: ai-memory, autobiographical, conversation-memory, hierarchical-memory, memory, openclaw, openclaw-plugin

## 简介

Hierarchical (2048-style) autobiographical memory plugin for OpenClaw. Multi-turn Context Manager pattern for natural memory formation.
