# opentechalyzer

> 标签: builtwith-alternative, claude, cli, cms-detection, competitive-intelligence, fingerprinting, mcp, model-context-protocol, osint, tech-stack, technology-detection, wappalyzer-alternative, website-analysis

## 简介

Free, open source website technology detection. Identifies the full stack of any URL from headers, cookies, rendered DOM, JS globals, sourcemap dependencies, DNS records, certificate transparency, well-known probes and favicon hashes.
