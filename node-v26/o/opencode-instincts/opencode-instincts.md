# opencode-instincts

> 标签: continuous-learning, ecc, instincts, opencode, opencode-plugin

## 简介

OpenCode V2 plugin that observes session activity and distils it into ECC-compatible instincts, plus slash commands for the ECC instinct-cli.py workflow.
