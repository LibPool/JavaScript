# opencode-auto-nudge

> 标签: agent, auto-continue, notifications, opencode, opencode-plugin, rate-limit, retry, watchdog

## 简介

Keeps OpenCode agent sessions alive: auto-retries rate-limited, timed-out, overloaded or empty model turns with capped backoff, then gives up loudly instead of silently stalling. Plays distinct sounds for task completed, failure, and human-decision-needed
