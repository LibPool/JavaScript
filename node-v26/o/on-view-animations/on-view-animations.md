# on-view-animations

> 标签: angular, animation, css-animation, data-attribute, framework-agnostic, intersection-observer, lightweight, on-view, react, scroll-animation, svelte, vanilla-js, vue

## 简介

A lightweight JavaScript library for scroll-triggered animations using HTML data attributes and the native IntersectionObserver API.
