# outcome-mcp

> 标签: agent-payments, claude, escrow, keeperhub, mcp, model-context-protocol, settlement, verification, x402

## 简介

MCP server that lets an agent verify it was actually paid: reads the receipt instead of trusting the status byte, with on-chain idempotency, escrow settlement and execution diagnosis.
