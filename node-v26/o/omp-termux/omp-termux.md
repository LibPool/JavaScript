# omp-termux

> 标签: ai, android, coding-agent, glibc, native, oh-my-pi, omp, proot-free, termux

## 简介

Install omp (oh-my-pi) natively on Termux (Android) — no proot, no containers. Official omp binaries bridged to Termux's native glibc.
