# openclaw-plugin-saga

> 标签: agent, harness, llm-orchestration, long-running, long-running-tasks, openclaw, openclaw-plugin, saga, workflow

## 简介

Saga — long-running task harness for OpenClaw. Continue-site coordinator with skill-routed trigger, loose stage-spec, cascading recovery, and a data-driven deep evaluator. Zero core modifications.
