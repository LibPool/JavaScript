# org.madmobile.cordovaplugins.zbarscanner

> 标签: barcode, cordova-android, cordova-ios, cszbar, ecosystem:cordova, qr, qr code, scanner, zbar

## 简介

This plugin integrates with the [ZBar](http://zbar.sourceforge.net/) library, exposing a JavaScript interface for scanning barcodes (QR, 2D, etc).
