# ogftrta

> 标签: automation, es6, gulp, js, jsx, node, pug, react, sass, scss, stylus, webpack

## 简介

gulp and webpack config that handles most of my use cases. It handles continuous compilation of static js, pug and sass (or stylus) files and optionally restarts the node server with nodemon.
