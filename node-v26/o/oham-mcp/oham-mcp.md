# oham-mcp

> 标签: agent-tools, mcp, modelcontextprotocol, oham, tsb, video

## 简介

OHAM as a native tool for any MCP agent (Claude, Cursor, ...): check the install, inspect, decode frames/windows to images, excerpt stills, convert wire forms, and serve — over the sealed .tsb format. No SDK; the CLI binary rides in as one dependency.
