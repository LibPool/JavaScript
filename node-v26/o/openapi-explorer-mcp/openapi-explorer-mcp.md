# openapi-explorer-mcp

> 标签: api-explorer, claude-code, mcp, model-context-protocol, openapi, swagger, typescript-types

## 简介

MCP server for any OpenAPI 3 spec: search endpoints, inspect request and response shapes, generate TypeScript types, and call endpoints with credentials mapped to the spec's security schemes.
