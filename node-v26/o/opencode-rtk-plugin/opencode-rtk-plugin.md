# opencode-rtk-plugin

> 标签: ai-coding-agent, context-window, llm, opencode, opencode-plugin, opencode-v2, rtk, shell, token-optimization, token-savings

## 简介

OpenCode v2 plugin that rewrites shell commands through rtk to cut LLM token usage by 60-90%.
