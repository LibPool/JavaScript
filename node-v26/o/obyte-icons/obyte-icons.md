# obyte-icons

> 标签: JavaScript

## 简介

You can access the icons via jsdelivr at the link: `https://cdn.jsdelivr.net/npm/obyte-icons@latest/build/IUSD.svg`. To get inverted icons, add -INV to the name (ex. IUSD-INV.svg).
