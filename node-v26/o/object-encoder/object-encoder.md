# object-encoder

> 标签: decode, deserialize, encode, json, object, serialization, serialize

## 简介

object-encoder supports encoding class instances into plain JavaScript objects that contain the field information required to restore the source type. 对象编码器支持将类实例编码为包含还原源类型所需字段信息的普通 JS 对象。
