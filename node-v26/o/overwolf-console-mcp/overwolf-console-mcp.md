# overwolf-console-mcp

> 标签: ai, analytics, claude, mcp, model-context-protocol, overwolf, stats

## 简介

Local stdio MCP server that wraps the Overwolf Developer Console statistics API, so MCP clients (Claude Desktop, etc.) can fetch an app's analytics on demand.
