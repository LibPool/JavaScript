# open-nfse

> 标签: brasil, cbs, danfse, dps, fiscal, ibs, icp-brasil, mtls, nbs, nfse, nfse-gov-br, nfse-nacional, nota-fiscal, nota-fiscal-servico, receita-federal, reforma-tributaria, sefin, typescript, xmldsig

## 简介

Biblioteca TypeScript/Node.js para o Padrão Nacional de NFS-e (nfse.gov.br): consulta, distribuição, emissão síncrona, cancelamento e substituição — direto na API oficial da Receita Federal.
