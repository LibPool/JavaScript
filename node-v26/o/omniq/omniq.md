# omniq

> 标签: background processing, concurrent workers, distributed workers, fifo queue, grouped queue, job scheduling, lease queue, node redis driver, omniq, redis job queue, redis lua queue, redis queue, task processing, typescript redis, valkey queue

## 简介

TS / Node.js library for OmniQ, the language agnostic queue ecosystem with parallel limits, draining and much more. Publish and consume in your favorite language like Python, Go, Node (TS or Vanilla), PHP and any other you want to.
