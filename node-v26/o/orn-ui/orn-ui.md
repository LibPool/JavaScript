# orn-ui

> 标签: agents, ai, atomic-design, component-library, components, dark-mode, design-system, expo, expo-sdk-54, expo-sdk-55, expo-sdk-56, expo-sdk-57, llm, react-native, theming, typescript, ui, zero-dependencies

## 简介

React Native / Expo component library: 50 typed components, light/dark theming, zero runtime dependencies. Verified on Expo SDK 54-57. Agent-friendly: one component instead of hundreds of lines of hand-written UI.
