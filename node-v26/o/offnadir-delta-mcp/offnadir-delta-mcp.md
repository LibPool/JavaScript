# offnadir-delta-mcp

> 标签: geoint, geospatial, intelligence, mcp, model-context-protocol, off-nadir-delta, osint, satellite

## 简介

Local (stdio) MCP server for Off-Nadir Delta — live, geolocated world-event intelligence, a Daily World Brief, satellite-imagery search, and an OSINT/GEOINT analyst. Forwards to the hosted server with your API key.
