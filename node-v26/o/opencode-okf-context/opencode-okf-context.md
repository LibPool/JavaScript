# opencode-okf-context

> 标签: agent, context-management, context-window, knowledge-base, knowledge-management, llm, okf, open-knowledge-format, opencode, opencode-plugin, progressive-disclosure

## 简介

OpenCode plugin: progressive disclosure + auto-unload for OKF (Open Knowledge Format) knowledge bundles. Inspired by DCP's outbound-only context transformation.
