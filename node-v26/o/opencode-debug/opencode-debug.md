# opencode-debug

> 标签: ai-agent, browser-debugging, cursor-debug, debug, debug-agent, debugging, instrumentation, opencode, opencode-agent, opencode-plugin, probe, runtime-debugging

## 简介

Cursor-style debug agent for OpenCode — inject probes into CLI and browser apps, capture runtime data via HTTP, analyze and fix bugs automatically.
