# opalinx

> 标签: cobs, led, led-controller, neopixel, opalinx, serialport, ws2811, ws2812, ws2812b

## 简介

JavaScript client library for Opalinx (Optimized Protocol for Addressable LEDs), with browser Web Serial and Node.js serial transports.
