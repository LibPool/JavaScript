# openapi-to-bruno

> 标签: JavaScript

## 简介

this is a simple cli tool to convert an openapi file to a bruno collection. code is 99% copied from the [bruno project](https://github.com/usebruno/bruno).

## 官网

- npm 页面：https://www.npmjs.com/package/openapi-to-bruno
