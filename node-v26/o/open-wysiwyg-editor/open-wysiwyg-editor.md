# open-wysiwyg-editor

> 标签: a11y, accessibility, angular, arabic, astro, atag, csp, custom-element, editor, html-forms, nextjs, nuxt, preact, prosemirror, react, rich-text-editor, rtl, solid, svelte, trusted-types, vanilla-js, vue, wcag, web-component, wysiwyg

## 简介

Accessible (WCAG 2.2 AA / ATAG 2.0), RTL-first, CSP-safe rich text editor for any website: plain JavaScript, HTML forms, the <owe-editor> web component, and React, Next.js, Vue, Nuxt, Angular, Svelte, Solid and Astro. MIT, no license key, no telemetry.
