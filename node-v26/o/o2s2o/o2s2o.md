# o2s2o

> 标签: Date, JSON, Map, RegExp, Set, TypeScript, class revival, dehydrate, deserializer, hydrate, localStorage, serializer

## 简介

o2s2o: Object → Storage (JSON) → back to Object. Safe, readable de/serializer with class revival and built-ins.
