# openclaw-snowluma

> 标签: JavaScript

## 简介

OpenClaw channel plugin for QQ via SnowLuma. Built entirely on @snowluma/sdk — three configurable receive modes (mention/keyword, digest, realtime coalescing), active quote & forward-message resolution, and agent tools for chat history and group members.
