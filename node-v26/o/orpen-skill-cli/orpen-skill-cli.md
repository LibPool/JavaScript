> 标签: agents, ai, claude-code, cli, code-review, codex, coupling-analysis, ddd, domain-analysis, franco, graphify, knowledge-graph, mcp-bootstrap, registry, skills, sql-auditor

## 简介

CLI for installing audited skills/agents from the Orpen registry into local AI coding agents (Claude Code, Codex). Current catalog: mcp-bootstrap, sql-auditor, coupling-analysis, domain-analysis, franco, graphify.
