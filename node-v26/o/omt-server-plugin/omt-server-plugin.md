# omt-server-plugin

> 标签: JavaScript

## 简介

A plugin for [@web/dev-server](https://modern-web.dev/docs/dev-server/overview/) to bundle webworkers when using `new Worker('my-worker.js', { type="module" });` on browsers which do not currently support it.
