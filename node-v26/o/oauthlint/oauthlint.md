# oauthlint

> 标签: ai-code, appsec, cli, code-scanning, devsecops, github-action, jwt, linter, oauth, oauth2, oauthlint, oidc, pkce, sast, security, semgrep, static-analysis, vibe-coding

## 简介

Catch the OAuth, OIDC, JWT, and MCP security bugs AI coding tools produce. CLI for the oauthlint-rules Semgrep pack, low false positives, CWE/OWASP-mapped fixes.
