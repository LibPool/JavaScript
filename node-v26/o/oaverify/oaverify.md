# oaverify

> 标签: api-validation, cli, command-line, oas, openapi, openapi-3.0, openapi-3.1, openapi-3.2, openapi-cli, openapi-validator, request-validator, response-validator, spec-validation, swagger, validation, validator, yaml

## 简介

Command-line OpenAPI validator (3.0/3.1/3.2): validate requests, responses, and examples against a spec, resolve and lint documents, and compile standalone validators. Library API lives in @oaverify/core.
