# opencode-better-eyesight

> 标签: clipboard, image, opencode, opencode-plugin, screenshot, vision

## 简介

Vision plugin for opencode: ask any model opencode has access to about images (clipboard, files, URLs, session attachments), with parent-prompt forwarding, session history and caching.
