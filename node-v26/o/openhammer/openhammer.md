# openhammer

> 标签: agent, ai, claude, claude-code, cli, cursor, filesystem, mcp, model-context-protocol, remote-control, shell, tunnel

## 简介

Standalone MCP server (no LLM) exposing shell + filesystem tools to a remote agent over Streamable HTTP. Run it on a laptop or deploy it on a server to give any authenticated MCP client controlled computer access.
