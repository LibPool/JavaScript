# openfilm

> 标签: agents, animation, claude-code, codex, motion-graphics, render, video

## 简介

The open source AI video agent: films as web pages, the manual that teaches your coding agent to make them, the `openfilm` command, and Studio, the editor to change anything in them.

## 官网

- 官网：https://openfilm.dev
- 源码仓库：git+https://github.com/openfilm/openfilm.git
- npm 页面：https://www.npmjs.com/package/openfilm
