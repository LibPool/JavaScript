## 简介

OpenClaw skills-only plugin: an eval-driven Skill Factory (generator + assessor + splitter + TDD/eval engine + screenshot bridge + orchestrator). Aligns with Anthropic skill-creator and outperforms it on dependency-freeness, speed (static fast-path) and O
