# omp-openviking-memory

> 标签: context-database, mcp, memory, oh-my-pi, omp, openviking, pi

## 简介

Long-term semantic memory for Oh My Pi via OpenViking — auto-recall/capture, 11 viking:// tools, tree/write/edit, slash commands.
