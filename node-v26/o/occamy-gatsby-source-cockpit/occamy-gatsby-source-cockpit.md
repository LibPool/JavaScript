# occamy-gatsby-source-cockpit

> 标签: cockpit, cockpit-cms, fika, gatsby, gatsby-plugin, gatsby-source-plugin, headless-cms, occamy, productions

## 简介

This is a Gatsby version 5.x.x source plugin that feeds the GraphQL tree with Cockpit Headless CMS collections and singletons data. Actually, it supports querying raw texts (and any trivial field types), Markdown, images, galleries, assets, sets, repeater
