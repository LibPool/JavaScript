# oc-relocate

> 标签: bunx cli, fresh clone, move opencode sessions, new path, npx cli, opencode, opencode sqlite database, relocate opencode sessions, repo moved

## 简介

Move and relocate opencode sessions when a repository's local path changes: repo moved or renamed, or a fresh clone at a new path.
