# opencode-keep-awake

> 标签: keep-awake, opencode, opencode-plugin, systemd, systemd-inhibit

## 简介

OpenCode server plugin: holds a systemd sleep/idle inhibitor while any session is generating, so your PC does not sleep mid-prompt.
