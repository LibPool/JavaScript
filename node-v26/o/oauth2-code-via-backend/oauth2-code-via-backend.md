# oauth2-code-via-backend

> 标签: Authorization Code Grant, OAuth2, backend API support, non-standard flow

## 简介

Encapsulating the opinioned non-standard flow of OAuth2 authorization code grant for front-end projects, which communicate with the authorization server via a backend API indirectly.
