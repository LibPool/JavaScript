# overscan

> 标签: css, custom-elements, fui, sci-fi, terminal, ui-kit, web-components

## 简介

A themeable sci-fi/FUI web component kit for control screens. Custom elements plus a CSS layer, ten dark themes, and readouts that refuse to invent.
