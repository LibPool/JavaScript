# opencode-show-tools

> 标签: browser, excel, image, opencode, plugin, spreadsheet, viewer, xlsx

## 简介

OpenCode plugin with showExcel and showImage tools: render .xlsx as an HTML table opened in the default browser, and open images with the default OS viewer.
