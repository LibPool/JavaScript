# openclaw-channels-csdn-setup

> 标签: csdn, csdn-im, openclaw, setup

## 简介

One-shot installer: openclaw plugins install csdn-im@latest + merge channels.csdn-im into openclaw.json. Requires OpenClaw peer range as published in csdn-im (see csdn-im package.json openclaw.compatibility).

- 源码仓库：git+https://gitlab.csdn.net/messagecenter/openclawplugin.git
