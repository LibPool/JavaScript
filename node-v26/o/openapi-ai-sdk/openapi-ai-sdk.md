# openapi-ai-sdk

> 标签: ai, capability-contracts, gateway, llm, openai, router

## 简介

TypeScript SDK for openapi.ai — a drop-in extension of the OpenAI client, plus capability contracts: schema-frozen interfaces called like functions.
