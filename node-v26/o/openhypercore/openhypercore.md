# openhypercore

> 标签: canvaskit, compositing, ffmpeg, motion-graphics, remotion, rendering, scene-graph, server-side-rendering, skia, video

## 简介

Lightweight, GPU-free video composition + rendering engine: a JSON scene-graph IR, CanvasKit/Skia (wasm) or native (Rust + skia-safe) renderer, and an FFmpeg encoder — with a CLI for scripted/agent use.
