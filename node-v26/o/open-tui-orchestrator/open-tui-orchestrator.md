# open-tui-orchestrator

> 标签: agent, automation, claude, cli, codex, multi-agent, orchestrator, parallel, tui, windows

## 简介

Split a multi-part agent request into a verified TODO ledger, then run the parallel blocks in hidden or visible TUI windows of the agent CLI you already use (Windows).
