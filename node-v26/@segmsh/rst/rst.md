# @segmsh/rst

> 标签: JavaScript

## 简介

reStructuredText processor for [segm.sh](https://segm.sh). This package parses `.rst` files (including Sphinx documentation) into a document (AST + segments) and stringifies them back, treating prose as translatable segments while leaving everything else
