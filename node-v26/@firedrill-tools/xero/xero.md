# @firedrill-tools/xero

> 标签: JavaScript

## 简介

Synthetic Xero Accounting API 2.0 (subset) Tool for Firedrill: organisation, chart of accounts, tax rates, contacts, sales invoices and bills, and payments over deterministic local state.
