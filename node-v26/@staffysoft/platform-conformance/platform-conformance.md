# @staffysoft/platform-conformance

> 标签: JavaScript

## 简介

Platform Conformance merge gate for StaffySoft product repos — per-repo enforcement levels (.platform-conformance.yml), PR-template checkbox checks, coverage-delta test gate, and the portfolio#9 leaderboard updater.
