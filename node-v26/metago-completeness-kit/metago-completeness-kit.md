# metago-completeness-kit

> 标签: agent, completeness, governance, metago, quality-gate, verification

## 简介

元构完整性治理套件（MetaGO Completeness Kit）— 把"完整性"从主观断言变成可安装、可配置、可强制生效的机器检查。验证引擎 + 活基线 + 完整性雷达 + 缺口登记册 + 强制门（hooks/CLI）。适用于任何 Agent 与任何交付物（架构方案/代码/文档/报告）。
