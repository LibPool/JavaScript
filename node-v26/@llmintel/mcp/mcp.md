# @llmintel/mcp

> 标签: anthropic, bedrock, deprecation, llm, mcp, model-context-protocol, model-lifecycle, openai

## 简介

MCP server for AI model lifecycle data — check whether a model id is deprecated or retiring, and what to migrate to, across OpenAI, Anthropic, Azure, AWS Bedrock, Google, and Cohere.
