# @charlie404/filemanager

> 标签: cropperjs, custom-elements, file-manager, image-cropper, laravel, lit, media-library, symfony, web-components

## 简介

Framework-agnostic file manager custom element with server-side image cropping, metadata editing and automatic theme adaptation (daisyUI bridge).
