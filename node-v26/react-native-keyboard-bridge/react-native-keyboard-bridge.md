# react-native-keyboard-bridge

> 标签: android, custom-keyboard, ime, input-method, ios, keyboard, keyboard-extension, react-native, swipe-typing, word-prediction

## 简介

Design a mobile system keyboard with ordinary React Native components. Single install: JS bridge, Android native module (autolinked), iOS native module (real React Native, Hermes+JSI+Fabric) + setup CLI, gestures, and word prediction all in one package.
