# dsh-weather-panel

> 标签: alerts, deepseek-harness, dsh, dsh-plugin, open-meteo, sidebar, typhoon, weather, weather-forecast

## 简介

DeepSeek Harness 侧边栏天气面板：网络自动定位、5 天与 24 小时预报、逐小时降水、中央气象台预警与台风路径（纯浏览器端，无需 API Key）
