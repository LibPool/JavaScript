# @whalewatch/node

> 标签: apm, logging, metrics, observability, opentelemetry, otel, tracing, whale

## 简介

One-line auto-instrumentation for Node.js apps. Ships logs, metrics and traces to Whale.

- npm 页面：https://www.npmjs.com/package/@whalewatch/node
