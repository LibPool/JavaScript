# @silakagent/mcp

> 标签: browser-automation, claude, cursor, e2e, mcp, model-context-protocol, qa, silak, testing

## 简介

MCP (Model Context Protocol) server yang mengekspos kemampuan Silak Agent — otomasi browser, sesi/tab, hingga testing/QA (roster tool silak_*) — ke AI coding assistant (Claude Code, Cursor) lewat bridge lokal ke extension.
