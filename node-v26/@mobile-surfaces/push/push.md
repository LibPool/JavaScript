# @mobile-surfaces/push

> 标签: activitykit, apns, broadcast, live-activity, mobile-surfaces, push

## 简介

Typed APNs client for Mobile Surfaces snapshots. HTTP/2, JWT, push-to-start, iOS 18 broadcast channels.
