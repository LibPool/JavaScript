# @jgengine/core

> 标签: agent-first, game-engine, game-framework, jgengine, multiplayer, typescript, typescript-game-framework

## 简介

jgengine core — pure-TypeScript game framework SDK (npm @jgengine/core). Entity stores, commands, combat, inventory, multiplayer seams. Zero dependencies. Not an ECS. Agent skills ship in the tarball. https://jgengine.com
