# paired-mcp

> 标签: bonding-curve, claude, mcp, model-context-protocol, robinhood-chain, token-launchpad, tokenized-stocks

## 简介

Launch coins paired with tokenized stocks on Robinhood Chain from any MCP client. Stdio bridge to the paired.exchange remote MCP server.
