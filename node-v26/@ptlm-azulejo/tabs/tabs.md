# @ptlm-azulejo/tabs

> 标签: JavaScript

## 简介

The `Tabs` component organizes related content into multiple sections, allowing users to switch between views without leaving the current page. Tabs can display labels, icons, and notification badges, making them ideal for dashboards, settings pages, prod
