# @flow-as-code/cdk

> 标签: amazon-connect, aws, aws-cdk, contact-center, contact-flow, infrastructure-as-code, ivr, typescript

## 简介

CDK binding for @flow-as-code/core: materialize FlowDoc refs as CloudFormation tokens; FlowSet construct with module version/alias publishing; a CDK stack scaffold generator on the /scaffold subpath.
