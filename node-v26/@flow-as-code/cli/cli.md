# @flow-as-code/cli

> 标签: amazon-connect, aws, contact-center, contact-flow, infrastructure-as-code, ivr, typescript

## 简介

CLI over @flow-as-code/core: lint, codegen, synth, render, emit, the local studio server, and export, simulate, and diff against a live Amazon Connect instance.
