# @flow-as-code/core

> 标签: amazon-connect, aws, contact-center, contact-flow, infrastructure-as-code, ivr, typescript

## 简介

Typed builder, synthesizer, codegen, lint engine, map and binder materialization, export reverse-mapping, and simulate client for Amazon Connect Flow language. IaC-agnostic; references are abstract tokens.
