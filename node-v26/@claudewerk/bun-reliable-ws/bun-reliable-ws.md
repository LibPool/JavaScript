# @claudewerk/bun-reliable-ws

> 标签: backoff, bun, handshake, jitter, keepalive, reconnect, reliable, websocket

## 简介

Reliable, self-healing WebSocket connection for Bun: staged handshake, pluggable auth + capability negotiation, keepalive, backoff reconnect, graceful drain, delivery acks, deterministic duplicate-connection tiebreak. Zero required runtime deps.
