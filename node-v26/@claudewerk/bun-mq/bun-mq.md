# @claudewerk/bun-mq

> 标签: at-least-once, bun, dead-letter-queue, durable, idempotency, message-queue, queue, sqlite

## 简介

Transport-agnostic in-process message queue for Bun: per-message QoS, idempotency/dedupe, opt-in durable SQLite storage, dead-letter queue, named queues. Zero required runtime deps.
