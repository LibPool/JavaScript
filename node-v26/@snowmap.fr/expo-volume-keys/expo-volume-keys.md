# @snowmap.fr/expo-volume-keys

> 标签: android, expo, hardware-keys, react-native, volume, volume-buttons

## 简介

Use the hardware volume buttons as input on Android. While a listener is subscribed the keys are consumed, so they stop changing the volume.
