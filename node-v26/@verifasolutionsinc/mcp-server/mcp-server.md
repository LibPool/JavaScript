# @verifasolutionsinc/mcp-server

> 标签: identity-verification, kyc, liveness, mcp, model-context-protocol, sanctions, verifa

## 简介

Run Verifa identity verification from any MCP client. Local stdio server that proxies to the hosted Verifa MCP endpoint with your API key.
