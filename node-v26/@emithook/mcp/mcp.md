# @emithook/mcp

> 标签: ai-agents, email, emithook, mcp, model-context-protocol, webhooks

## 简介

Emithook MCP server — scoped query + write tools over @emithook/sdk for AI agents. Write tools enforce the key scope + explicit confirmation; never widen scope; never log secrets.
