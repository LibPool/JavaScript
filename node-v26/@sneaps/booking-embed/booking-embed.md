# @sneaps/booking-embed

> 标签: appointment, booking, cal.com, calendar, calendly, emdash, emdash-plugin, scheduling

## 简介

Booking widgets for EmDash sites: a floating button, any element as a trigger, and an inline calendar block, for cal.com and Calendly (native plugin).
