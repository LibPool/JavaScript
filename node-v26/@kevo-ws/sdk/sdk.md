# @kevo-ws/sdk

> 标签: JavaScript

## 简介

Embedded wallet infrastructure for web applications. Drop in authentication (email OTP, Google, X, Apple), automatic EVM and Solana wallet creation, and signing — all without users ever managing seed phrases.
