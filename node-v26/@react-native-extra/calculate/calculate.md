# @react-native-extra/calculate

> 标签: calculate, css, css-calc, css-units, html, javaScript, react, react-native, sass, scss, typeScript

## 简介

The library makes it possible to perform a calculation with css units (the supported units are vh, vw, vmax, vmin, rem, px, cm, mm, in, pt, pc), you can also calculate rotation units such as degrees and grads, radians and turns
