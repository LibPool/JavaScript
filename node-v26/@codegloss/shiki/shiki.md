# @codegloss/shiki

> 标签: annotated-code, code-annotation, codegloss, rehype, rehype-plugin, shiki, syntax-highlighting

## 简介

Shiki integration for codegloss — rehype plugin that renders every fenced code block as a <code-gloss> element, plus the Shiki highlighter adapter
