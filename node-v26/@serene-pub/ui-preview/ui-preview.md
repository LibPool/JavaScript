# @serene-pub/ui-preview

> 标签: JavaScript

## 简介

The Serene Pub surface harness: a SvelteKit dev server that renders the UI surfaces a package announces — frame panels in a real opaque-origin sandbox, components in the host document — with hot reload. Launched by `serene-pub ui`.
