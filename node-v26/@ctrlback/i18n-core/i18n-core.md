# @ctrlback/i18n-core

> 标签: esm, gettext, i18n, internationalization, l10n, localization, messageformat, mf2, translation, typescript

## 简介

Core internationalization runtime: a constructible tr() factory plus the catalog model, built on MessageFormat 2.0.
