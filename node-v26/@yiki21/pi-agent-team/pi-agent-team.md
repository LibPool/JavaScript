# @yiki21/pi-agent-team

> 标签: agent-mesh, agent-team, coding-agent, gossip, memberlist, multi-agent, pi, pi-coding-agent, pi-extension, pi-package, subscription, swim, tailscale, watch

## 简介

Turn several machines running the Pi coding agent into one team over your tailnet. Three transports (broker / mesh / SWIM), one shared API and conformance suite.
