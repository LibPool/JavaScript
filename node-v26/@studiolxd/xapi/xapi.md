# @studiolxd/xapi

> 标签: angular, e-learning, experience-api, headless, lrs, react, statements, svelte, tin-can, vanilla, vue, xapi

## 简介

Framework-agnostic xAPI (Experience API / Tin Can) client for browsers, Node and any LRS, with thin adapters for React, Vue, Angular and Svelte.
