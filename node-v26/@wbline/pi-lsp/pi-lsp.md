# @wbline/pi-lsp

> 标签: diagnostics, language-server, lint, lsp, pi-extension, pi-package

## 简介

On-demand LSP diagnostics and source fixes across 25+ languages, plus built-in CLI lint runners (ruff, biome, shellcheck) — aggregated into one check report for the Pi coding agent.
