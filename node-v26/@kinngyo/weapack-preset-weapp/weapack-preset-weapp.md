# @kinngyo/weapack-preset-weapp

> 标签: JavaScript

## 简介

微信小程序构建预设，提供一组可直接用于 `@kinngyo/weapack` 的默认配置。预设按文件类型拆分 pipeline，支持静态资源复制、JavaScript/TypeScript 转译、Less 编译和 Sass 编译，并默认启用文件级增量监听。
