# @bossforce.ai/mcp-make

> 标签: JavaScript

## 简介

MCP server for the **Make** (formerly Integromat) **API v2**. List, inspect, run, and monitor automation scenarios. A good fit for kicking off and checking on automations from an agent workflow.
