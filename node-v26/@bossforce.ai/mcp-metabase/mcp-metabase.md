# @bossforce.ai/mcp-metabase

> 标签: JavaScript

## 简介

MCP server for the [Metabase](https://www.metabase.com/) **REST API**, using API key authentication. A good fit for listing databases and saved questions, running a saved question, or running ad-hoc native SQL from an agent.
