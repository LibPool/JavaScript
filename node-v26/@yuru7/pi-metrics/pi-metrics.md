# @yuru7/pi-metrics

> 标签: metrics, pi-coding-agent, pi-extension, pi-package, tps, ttft

## 简介

A Pi extension that prints one dim metrics line when a run settles (elapsed, TPS, TTFT, tokens) and shows the live elapsed time in the working indicator
