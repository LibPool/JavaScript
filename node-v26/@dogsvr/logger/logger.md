# @dogsvr/logger

> 标签: dogsvr, logger, ndjson, pino, worker-threads

## 简介

High-performance NDJSON logger for the @dogsvr/* ecosystem, built on pino. Two-mode (inline / central isolate) for K8s + bare-metal compatibility.
