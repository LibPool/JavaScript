# @cancore/mcp

> 标签: agent, cancore, canton, mcp, model-context-protocol, trading, wallet

## 简介

An MCP server that lets an AI agent ask a Cancore wallet owner for a trade. The agent queues a request; the person approves and signs it in their own wallet. No key ever reaches the agent.
