# @lovalingo/lovalingo

> 标签: automatic-routing, i18n, internationalization, language-router, localization, lovable, react, react-router, translation, vibe-coded, weglot-alternative, wpml-alternative

## 简介

React and Next.js translation runtime: an i18n alternative for Lovable, Claude Code, and Codex projects with localized URLs, SEO, and zero-flash rendering.
