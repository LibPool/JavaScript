# @igorskyflyer/uarray

> 标签: array, igorskyflyer, index, indices, negative, uarray, utility

## 简介

🎉 Provides UArray, an Array type that supports negative indices/indexes, just wrap your regular JavaScript array with UArray() and you are all set! 🙌
