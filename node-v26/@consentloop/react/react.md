# @consentloop/react

> 标签: ccpa, cmp, consent-management, consent-mode-v2, consentloop, cookie-banner, cookie-consent, gdpr, google-consent-mode, hooks, privacy, react, react-cookie-consent

## 简介

React bindings for ConsentLoop — the fastest cookie consent (CMP) for the web. Provider, useConsent hook and <ConsentGate>. GDPR & CCPA, Google Consent Mode v2, zero layout shift.
