# @chrischall/realty-core

> 标签: JavaScript

## 简介

Pure, dependency-free realty-domain helpers — address tokenisation + match scoring, USPS street-suffix variants, locality alias remap, free-text address parsing + alternates; mortgage, affordability & rent-vs-buy calculators; feature extraction; tax/HOA/d
