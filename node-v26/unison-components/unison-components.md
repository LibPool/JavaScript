# unison-components

> 标签: components, design-system, design-tokens, figma, react-native, react-native-web, tailwind, unison, uniwind

## 简介

A React Native component library whose props mirror Figma's design vocabulary. Renders on web through React Native Web and on iOS and Android through React Native; the code the Unison Figma plugin generates against.
