# @honua/mcp-server

> 标签: ai-agent, arcgis, feature-service, geospatial, gis, maplibre, mcp, model-context-protocol, ogc-api, typescript

## 简介

Platform-free MCP server for geospatial services: expose discovery, query, and analysis over any public ArcGIS/Esri FeatureServer or OGC API endpoint to any MCP client, with no platform lock-in
