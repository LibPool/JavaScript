# @kozmoai/backstage-plugin-home-markdown

> 标签: JavaScript

## 简介

A React component that renders a markdown file from GitHub as a Homepage component. You'll need to log in to GitHub to be able to fetch the markdown. You can configure the plugin to point to a remote markdown file in GitHub and it will fetch that markdown
