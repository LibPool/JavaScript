# @ajx2/menu

> 标签: menu, mobile-menu, navigation, overlay, react, tailwindcss, ui

## 简介

This Menu component is a reusable, context-based navigation system built with React and Tailwind CSS. It provides a modern mobile-first menu experience with smooth animations, reliable scrolling, and flexible alignment.
