# @smithy-hono/data-core

> 标签: JavaScript

## 简介

Runtime-agnostic persistence port for smithy-hono default CRUD (Web-standard APIs only, ARCH-01). The DataStore<T> interface, a dev-only in-memory implementation, and a shared conformance suite.
