# @smithy-hono/mcp-core

> 标签: JavaScript

## 简介

Runtime bridge exposing a generated smithy-hono service as an MCP (Model Context Protocol) server. Web-standard APIs only (ARCH-01): turns the operation metadata registry + emitted Zod schemas into MCP tools over a stateless Streamable-HTTP JSON-RPC endpo
