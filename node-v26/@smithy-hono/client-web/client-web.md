# @smithy-hono/client-web

> 标签: JavaScript

## 简介

Browser auth helper for smithy-hono services. Drives the security-core OIDC cookie-session flow (login redirect, callback exchange, CSRF synchronizer token, logout) from a single-page app and wires it into the GENERATED typed client via its `fetch`/`heade
