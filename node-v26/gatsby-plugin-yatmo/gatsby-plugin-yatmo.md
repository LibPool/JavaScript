# gatsby-plugin-yatmo

> 标签: gatsby, gatsby-plugin, listing, map, neighbourhood, poi, points-of-interest, property, proptech, react, real-estate, seo, yatmo

## 简介

Add real estate maps, points of interest and neighbourhood data to Gatsby sites: the plugin loads the Yatmo web components and declares your key once, and re-exports the YatmoMap, YatmoPois and YatmoNeighbourhoodText React components for property pages. T
