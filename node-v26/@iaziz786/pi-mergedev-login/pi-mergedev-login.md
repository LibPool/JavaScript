# @iaziz786/pi-mergedev-login

> 标签: extension, glm, merge-dev, pi-package, zai

## 简介

Pi extension that adds the Merge Dev gateway (docs.merge.dev/merge-gateway) as a model provider via its OpenAI Responses API, hosting a single model: GLM 5.3 Flash.
