# @iaziz786/omp-jev-decision

> 标签: classifier, decide, extension, jev, judge, omp, pi-package, router, typesafe

## 简介

omp extension that adds a `decide` tool backed by TypeSafe System One (Jev): typed choice / noul / score questions over any state, answered with probabilities and confidence.
