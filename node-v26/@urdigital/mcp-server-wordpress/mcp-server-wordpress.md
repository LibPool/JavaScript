# @urdigital/mcp-server-wordpress

> 标签: claude, cms, content, mcp, model-context-protocol, wordpress

## 简介

MCP server for WordPress: posts, pages, categories, tags, media, comments, users, generic custom post types, settings, and read-only plugin/theme visibility, via the core REST API.
