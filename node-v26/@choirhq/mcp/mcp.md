# @choirhq/mcp

> 标签: JavaScript

## 简介

MCP server for Choir — brings the user's own Claude (Claude Code, Claude Desktop) into their Choir workspace: post messages, read channels, file and update backlog items. Bring-your-own-Claude: no Anthropic key on Choir's side.
