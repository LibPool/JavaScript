# @thirdweb-dev/thirdweb-cli

> 标签: JavaScript

## 简介

The thirdweb CLI is your one-stop-shop for publishing custom contracts for the world to use. The CLI uploads all necessary data to decentralized storage and makes it available to deploy via the thirdweb sdk or thirdweb dashboard.
