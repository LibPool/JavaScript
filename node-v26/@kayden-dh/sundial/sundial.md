# @kayden-dh/sundial

> 标签: api, api-deprecation, cli, deprecated, deprecation, lint, migration, scanner, static-analysis, stripe

## 简介

API deprecation scanner: warns when your code uses deprecated or removed API features and tells you what to use instead. Currently supports Stripe.
