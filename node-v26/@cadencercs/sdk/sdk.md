# @cadencercs/sdk

> 标签: agent, ai-agent, conversational, google-rbm, messaging, rbm, rcs, sms, twilio

## 简介

Agent-native RCS messaging with automatic SMS fallback. Open a conversation, get typed replies, and let the channel flip handle itself.
