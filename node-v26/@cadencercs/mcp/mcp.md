# @cadencercs/mcp

> 标签: ai-agent, claude, mcp, messaging, model-context-protocol, rbm, rcs, sms

## 简介

MCP server for Cadence — agent-native RCS messaging with automatic SMS fallback. Open conversations, handle replies, and take a brand through carrier onboarding, as tools.
