## 简介

Generic image analysis MCP server — works with ANY OpenAI-compatible multimodal endpoint (Z.ai GLM Coding Plan, OpenAI, OpenRouter, Ollama, LM Studio, vLLM…). One tool: analyze_image — accepts LOCAL file paths (base64 data URI) or remote URLs, up to 4 ima
