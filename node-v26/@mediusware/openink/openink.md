# @mediusware/openink

> 标签: hand-drawn, mockup, prototype, roughjs, sketch, static-site-generator, ux, wired-elements, wireframe

## 简介

Describe screens in YAML, get a clickable hand-drawn wireframe prototype (static HTML, PDF, PNG). Built on wired-elements and RoughJS.
