# @mvpaint/engine

> 标签: 2d, canvas, msdf, renderer, scene-graph, text-rendering, vector, webgl2, webgpu

## 简介

A 2D scene-graph renderer for the browser, built natively for WebGPU with a WebGL2 fallback.
