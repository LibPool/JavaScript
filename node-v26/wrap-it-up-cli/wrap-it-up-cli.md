# wrap-it-up-cli

> 标签: ai-memory, claude-code, cli, context-engineering, developer-tools

## 简介

A context-engineering /wrap-it-up command for Claude Code: a plain-markdown, per-repo brain that closes the loop between sessions - decisions, lessons, and a compressed hot.md bridge, auto-loaded at the next session's start.
