# @memydev/ops-sdk

> 标签: deployments, idempotency, memyops, openapi, operations, platform, typescript

## 简介

Official TypeScript and JavaScript client for the MemyOps platform API: solutions, applications and their lifecycle operations, with idempotent creates, typed problem errors and a polling helper.
