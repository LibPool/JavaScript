# @zanreal/medusa-admin-kit

> 标签: admin, column-registry, dashboard, data-table, extensible, medusa, medusa-plugin, medusa-v2, products

## 简介

Medusa v2 toolkit for an extensible admin products list. Sibling plugins register their own columns through a shared registry and they all render in one products table, instead of each plugin shipping a separate page.
