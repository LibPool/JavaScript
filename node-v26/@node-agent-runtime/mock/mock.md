# @node-agent-runtime/mock

> 标签: agent, mock, node-agent-runtime, provider, testing

## 简介

Mock provider package of the Agent runtime: MockProvider — a deterministic, keyless rule-based model for demos, tests and offline runs. Demo/test asset; kept out of the core to keep the engine lean (M6 P1 review, P0).
