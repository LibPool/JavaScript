# @node-agent-runtime/host

> 标签: agent, host, node-agent-runtime, orchestration, session

## 简介

C8 host package of the Agent runtime: Session/Task/Run lifecycle (SessionManager) plus the assembled product surface (memory + artifact + sandbox + policy). Depends on @node-agent-runtime/core and the C3~C5 packages; the core never imports this package.
