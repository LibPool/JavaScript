# @msafdarawan/strapi-plugin-form-builder

> 标签: dynamic-forms, form-builder, plugin, strapi, strapi-plugin

## 简介

A reusable Form Builder plugin for Strapi v5 that allows admins to create dynamic forms, manage form fields, and collect submissions.
