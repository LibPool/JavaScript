# @telehostnet/maps

> 标签: delivery, geocoding, latam, maplibre, maps, openstreetmap, osrm, react-native, routing, venezuela

## 简介

Cliente TypeScript de TeleHost Maps — rutas, giro a giro en español, búsqueda de negocios y direcciones en América Latina, España y EE.UU. Funciona en React Native, navegador y Node.
