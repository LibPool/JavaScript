# @dvmkit/sdk

> 标签: agent-payments, ai-agents, cashu, digital-vending-machine, dvm, hono, lightning, mpp, pay-per-use, x402

## 简介

SDK for building Digital Vending Machines: pay-per-use HTTPS services AI agents can find, pay, and call with no account or API key
