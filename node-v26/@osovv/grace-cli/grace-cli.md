# @osovv/grace-cli

> 标签: bun, cli, grace, knowledge-graph, lint, python, semantic-markup, typescript

## 简介

GRACE 4 CLI for .grace linting, status snapshots, module health, verification queries, semantic markup, and artifact navigation with a Bun-powered grace binary.
