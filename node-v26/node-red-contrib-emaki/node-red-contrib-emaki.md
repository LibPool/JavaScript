# node-red-contrib-emaki

> 标签: ai-video, emaki, image-generation, image-to-video, node-red, seedance, seedance-2-5, text-to-video

## 简介

Node-RED node for emaki (emaki.ai), the Japanese-language AI video generator for Seedance 2.5 and Seedance 2.0: prompt in, video or image URL out.
