# @lit-material/simple-list

> 标签: lit, lit-material, material-design, material-design-3, navigation, simple-list, web-components

## 简介

Material Design 3-styled simple list web components (lit-material-simple-list, lit-material-simple-list-item) — a plain, lightweight list of links, no ripple or leading/trailing icons.
