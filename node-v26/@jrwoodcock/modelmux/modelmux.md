# @jrwoodcock/modelmux

> 标签: claude, codex, llm, mcp, model-context-protocol, modelmux, multi-agent, perplexity

## 简介

MCP server that lets Claude Code, Codex, and Perplexity call each other as tools. Supports text, code, images, and PDFs passed by file path.
