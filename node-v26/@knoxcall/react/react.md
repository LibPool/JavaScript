# @knoxcall/react

> 标签: elements, iframe, knoxcall, react, tokenization

## 简介

Hosted fields for React: <SecureField> embeds a KnoxCall-served iframe that captures one sensitive value and returns a vault token, so the value never enters your page JavaScript.
