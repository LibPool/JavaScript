# @oracle/coherence

> 标签: Coherence, Oracle Coherence, gRPC, node

## 简介

The JavaScript Client for Oracle Coherence allows Node applications to act as cache clients to a Coherence Cluster using Google's `gRPC` framework for the network transport.
