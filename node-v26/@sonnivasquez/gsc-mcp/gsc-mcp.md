# @sonnivasquez/gsc-mcp

> 标签: claude, google-search-console, gsc, mcp, seo

## 简介

Local Google Search Console MCP server, read-only by default (29 tools: 24 canonical gsc_* plus 5 legacy). GSC_ACCESS_MODE=full enables three Google write operations; legacy access settings remain compatible. OAuth, service accounts, Bun and Node.
