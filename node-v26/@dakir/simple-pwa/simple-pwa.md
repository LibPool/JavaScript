# @dakir/simple-pwa

> 标签: adaptive, cli, custom elements, data sync, framework, global state, indexeddb, javascript, manifest, offline, offline-first, progressive web app, progressive web apps, pwa, reactive, responsive, routing, service worker, state management, store, sync, web app, web application, web components

## 简介

Modern framework for creating adaptive, reactive Progressive Web Applications (PWA) with offline support. Built on Web Components with easy IndexedDB integration, responsive routing, and a reactive store for offline-first applications.
