# @youneed/server-plugin-pubsub-kafka

> 标签: JavaScript

## 简介

Kafka adapter for @youneed/server-plugin-pubsub: KafkaPubSub over topics, via the official `kafkajs`. Pub/sub only (pair with a KV adapter for state).
