# @youneed/server-plugin-pubsub-postgres

> 标签: JavaScript

## 简介

Postgres adapter for @youneed/server-plugin-pubsub + -store: PostgresKV (table) and PostgresPubSub (LISTEN/NOTIFY), via the official `pg` driver.
