# mdip-agent-kit

> 标签: agent-identity, ai-agent, did, did:mdip, hyperswarm, keychain, mdip, self, selfid, verifiable-credentials

## 简介

Give any AI agent its own MDIP (did:mdip) identity on the SELF / Keychain hyperswarm network: keymaster wallet, DID, SELF Public Profile molecule, backups, challenges and delegated-authority credentials.
