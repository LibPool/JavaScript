# @forinda/kickjs-storage

> 标签: files, kickjs, minio, nodejs, presigned-url, r2, resumable-upload, s3, storage, tus, typescript, uploads

## 简介

File storage for KickJS — one interface over memory, local disk, and S3-compatible buckets (AWS S3, Cloudflare R2, MinIO), with signed URLs and no SDK
