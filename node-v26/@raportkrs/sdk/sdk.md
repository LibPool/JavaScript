# @raportkrs/sdk

> 标签: api, krs, nip, polska, raportkrs, spolki, sprawozdania finansowe

## 简介

Klient TypeScript/JavaScript publicznego API RaportKRS (api.raportkrs.pl) — dane o polskich spółkach z KRS, finanse, osoby, zdarzenia, webhooki.
