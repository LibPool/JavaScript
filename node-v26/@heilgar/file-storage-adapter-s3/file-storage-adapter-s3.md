> 标签: adapter, adapter-pattern, aws, aws-s3, cloud-storage, file-storage, localstack, minio, nodejs, object-storage, presigned-url, s3, signed-url, storage, typescript

## 简介

AWS S3 (and S3-compatible: LocalStack, MinIO) file storage adapter for Node.js — unified API shared with the filesystem and Vercel Blob adapters.
