# @dakaio/sequelize-transactional

> 标签: asynclocalstorage, decorator, nestjs, postgres, sequelize, sequelize-typescript, transaction, transactional

## 简介

@Transactional() for Sequelize without injecting a connection: nested calls join one transaction, currentTransaction() reaches it anywhere, and the database's clock is one now() for every server.
