# @extra-wallet/balance-recovery

> 标签: JavaScript

## 简介

**Balance Recovery CLI** allows you to check balances of your mnemonic on different networks and addresses. Command line version of [Wallet Recovery Tool](https://wallet-recovery-tools.extrawallet.app/)
