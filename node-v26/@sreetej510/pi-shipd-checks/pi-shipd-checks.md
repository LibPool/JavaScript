# @sreetej510/pi-shipd-checks

> 标签: checks, pi, pi-extension, pi-package, review, shipd

## 简介

Pi extension that runs a strict, multi-agent fairness review of a benchmark task's agent_prompt.md, test.patch, and solution.patch, plus behavioral test-gap analysis, via /checks.
