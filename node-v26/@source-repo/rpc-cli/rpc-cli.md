> 标签: cli, contract-testing, industrial, iot, mcp, mqtt, rpc, socket.io, typescript, websocket

## 简介

Source RPC tooling: extract a contract from TypeScript, check it against a build or a live device, and browse, tap, fake, record and bench a live network
