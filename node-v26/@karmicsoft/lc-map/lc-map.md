# @karmicsoft/lc-map

> 标签: bounds, geo, headless, karmicsoft, leaflet, lightcode, map, maplibre, zoom

## 简介

Headless map view model — points → bounds, centre, zoom. No map library, no DOM. A LightCode brick.
