# @timely-sandbox/client

> 标签: agent, code-execution, gvisor, kubernetes, sandbox

## 简介

믿을 수 없는 코드를 격리된 환경에서 실행하는 클라이언트. 샌드박스를 띄우고 명령을 실행하고 파일을 주고받습니다. 의존성 없음, Node 20+.
