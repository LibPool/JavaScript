# @atusy/tsudoi-language-server

> 标签: JavaScript

## 简介

The framework for assembling a Language Server from one TypeScript config. Tsudoi owns the LSP transport, lifecycle, documents, capability advertisement, cancellation, and streaming; your config supplies only the handlers it needs.
