# @atusy/tsudoi-adapter-efm-config

> 标签: JavaScript

## 简介

Runs the linters and formatters from your existing [efm-langserver](https://github.com/mattn/efm-langserver) `config.yaml` under [tsudoi](https://github.com/atusy/tsudoi-language-server), without restating one tool definition.
