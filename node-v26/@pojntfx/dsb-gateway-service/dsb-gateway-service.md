# @pojntfx/dsb-gateway-service

> 标签: JavaScript

## 简介

A simple gateway microservice to the proprietary "Digitales Schwarzes Brett" service used in German schools. Uses @pojntfx-incubator/dsb-gateway-core to get the data.
