# @alsharif/outboxer-studio

> 标签: desktop-app, electron, nativefier, outboxer, website-to-app, windows

## 简介

Launcher for Advanced Outboxer Studio, which turns websites and HTML/CSS/JS projects into Windows desktop apps: downloads the portable release, verifies it and starts it.
