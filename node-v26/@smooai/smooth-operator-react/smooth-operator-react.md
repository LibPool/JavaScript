# @smooai/smooth-operator-react

> 标签: agent, ai, chat, rag, react, smooth-operator, websocket

## 简介

React bindings for smooth-operator — headless hooks + CSS-variable-themed components for the schema-driven WebSocket protocol. Use the hooks for a fully custom UI, or drop in <SmoothChat> and theme it with --smooth-* CSS variables.
