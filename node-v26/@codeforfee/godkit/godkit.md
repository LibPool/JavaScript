# @codeforfee/godkit

> 标签: agent, agent-memory, agents, antigravity, claude-code, codex, cursor, godkit, handoff, orchestration, skills

## 简介

One shared harness for every AI agent. Any agent entering your repo reads the same board, map and thread — so nothing is redone and nobody edits the same file twice.
