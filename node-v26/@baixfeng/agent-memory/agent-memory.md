# @baixfeng/agent-memory

> 标签: fts5, fuzzy-search, mcp, memory, model-context-protocol, persistent, sqlite, toon

## 简介

An MCP (Model Context Protocol) server providing persistent memory storage with full-text search capabilities. Built with SQLite/FTS5, it enables AI assistants to store, retrieve, and manage knowledge locally with efficient fuzzy search.
