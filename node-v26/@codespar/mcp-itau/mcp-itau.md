# @codespar/mcp-itau

> 标签: arrecadacao, banking, boleto, brazil, cobranca, extrato, itau, mcp, pix

## 简介

MCP server for Itaú Unibanco — Brazil's largest private bank. Pix, Cobrança (boleto), Arrecadação, and Extrato via Itaú's Developer Portal APIs (OAuth2 + mTLS).
