# @henlii/dsh-update

> 标签: JavaScript

## 简介

DSH plugin: check the DeepSeek Harness release channels (npm dist-tags + GitHub release tags) from the Web GUI, browse and search the version history, upgrade the running install to the channel's newest or to any pinned version, and restart the service —
