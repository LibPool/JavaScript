# @fiori/ui5-ts

> 标签: JavaScript

## 简介

This extension brings a tiny command which will allow you to serve your TS middleware on your UI5 server without compilation. It's using embedded ts-node esm loader allowing us to resolve _.js references to _.ts files on the fly.
