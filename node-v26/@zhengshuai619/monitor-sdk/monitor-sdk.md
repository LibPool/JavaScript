# @zhengshuai619/monitor-sdk

> 标签: JavaScript

## 简介

前端监控平台的 Web SDK，对外提供统一的 `init` 能力，并在内部默认集成多种采集插件（错误、性能、白屏、网络、PV/UV），帮助你快速为项目接入前端监控。
