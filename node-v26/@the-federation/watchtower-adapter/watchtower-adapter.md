# @the-federation/watchtower-adapter

> 标签: JavaScript

## 简介

Generic disposable translator adapter for Federation Watchtower. Currently bridges external behavioral/enforcement systems (reference integration: Character Kit) and @federation-watchtower/sdk. Owns no policy; normalizes upstream activity into downstream
