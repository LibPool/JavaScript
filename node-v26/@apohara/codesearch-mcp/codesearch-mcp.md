# @apohara/codesearch-mcp

> 标签: bm25, code-search, mcp, model-context-protocol, rag, sqlite, stdio, vector-search

## 简介

stdio MCP server wrapper for apohara-codesearch: hybrid (BM25 + vector) local code search exposed over the Model Context Protocol. Downloads the matching prebuilt binary from the GitHub Release on install.
