# opencode-fusion-mode

> 标签: delegation, fusion, multi-model, opencode, opencode-plugin, subagents

## 简介

Fusion mode for OpenCode 2: your agent leads, a persistent sidekick implements decided work, and read-only and light subagent lanes take bounded work, each on the model tier you choose.
