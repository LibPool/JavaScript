# @krawlup/analytics-tag

> 标签: analytics, conversion-tracking, cookieless, first-party, gdpr, krawlup, privacy, seo, web-analytics

## 简介

First-party, cookieless website analytics for krawlup. Injects the krawlup tag (t.js) and exposes a typed trackEvent/getSessionId API. No cookies, DNT-honoring, session-only state.
