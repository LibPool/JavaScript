# @varsten/anthropic

> 标签: anthropic, claude, fail-open, fallback, llm, varsten

## 简介

Fail-open wrapper around the Anthropic SDK. Optimize through Varsten when it is healthy; fall back directly to Anthropic when Varsten is unavailable, so an outage costs you savings, not uptime.
