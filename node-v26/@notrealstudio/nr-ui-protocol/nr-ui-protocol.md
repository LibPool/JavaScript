# @notrealstudio/nr-ui-protocol

> 标签: JavaScript

## 简介

Универсальный протокол UI ⇄ бэкенд (v1): wire-типы + маппинг-хелперы, без движка. Модель сообщения ре-экспортируется из @notrealstudio/nr-chat-store.
