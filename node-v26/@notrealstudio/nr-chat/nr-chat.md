# @notrealstudio/nr-chat

> 标签: append-only, chat, chat-format, conversation, json5, llm, parser, serializer, streaming, transcript

## 简介

Atomic %role + JSON5 chat format: parser, canonical emitter, byte-exact in-place editing. Runs in Node, browsers, GAS and userscripts.
