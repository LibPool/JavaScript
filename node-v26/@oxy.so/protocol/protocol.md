# @oxy.so/protocol

> 标签: canonical-json, crypto, did, oxyhq, protocol, signed-records

## 简介

Oxy Protocol — the app-agnostic base substrate: signed-record envelope, canonical JSON, signature/verification, and platform crypto. Reused by any Oxy app to decentralize its own content.
