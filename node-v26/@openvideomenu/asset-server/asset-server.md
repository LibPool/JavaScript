# @openvideomenu/asset-server

> 标签: JavaScript

## 简介

Proof-of-concept LAN server that hands menu manifests and menu art to TV apps. Read-only; serves only files a manifest names as menu art; never media.

## 官网

- 官网：https://openvideomenu.org/
- 源码仓库：git+https://github.com/tyson133-prog/openvideomenu.git
- npm 页面：https://www.npmjs.com/package/@openvideomenu/asset-server
