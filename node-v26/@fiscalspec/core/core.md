# @fiscalspec/core

> 标签: cbs, dfe, fiscal, ibs, nfce, nfe, reforma-tributaria, validacao

## 简介

Motor de validação do FiscalSpec: interpreta rulesets versionados (dados) contra XML de NF-e e emite resultados com proveniência completa.
