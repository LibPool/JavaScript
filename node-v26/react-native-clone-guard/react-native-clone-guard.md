# react-native-clone-guard

> 标签: android, anti-tampering, app-cloning, clone-detection, expo, multibox, parallel-space, react-native, security

## 简介

Detect Android app cloners (MultiBox, Parallel Space, Dual App…) by comparing libc and raw syscalls. Expo and bare React Native.
