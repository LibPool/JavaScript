# @r-tek/colr_pickr

> 标签: alpha, color, color picker, color-picker, colorpicker, colour, custom colors, hex, hsl, hsla, lightweight, picker, rgb, rgba, save colors, ui, ux, vanilla, vanilla-js

## 简介

Colr Pickr, a vanilla JavaScript color picker component built with SVGs, with features like saving colors. Similar design to the chrome-dev-tools color picker.
