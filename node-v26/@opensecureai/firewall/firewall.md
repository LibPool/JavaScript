# @opensecureai/firewall

> 标签: ai-security, firewall, genai, guardrails, llm, owasp, pii, prompt-injection, redaction, security

## 简介

Dependency-light LLM guardrail that decides whether text should be allowed, flagged, or blocked before it reaches a model — composing prompt-injection detection with PII/secret redaction under a configurable policy.
