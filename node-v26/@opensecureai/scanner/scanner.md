# @opensecureai/scanner

> 标签: ai-security, genai, guardrails, jailbreak, llm, owasp, prompt-injection, security

## 简介

Dependency-free heuristic scanner that detects prompt-injection, jailbreak, and data-exfiltration patterns in untrusted text before it reaches an LLM.
