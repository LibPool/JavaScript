# @inobit/pi-subagent-presets

> 标签: coding-agent, model, pi, pi-coding-agent, pi-extension, pi-package, presets, subagents, thinking

## 简介

Batch-configure the model and thinking level of pi-subagents agents per project, plus the main agent defaults, and export the result as a reusable global profile blueprint.
