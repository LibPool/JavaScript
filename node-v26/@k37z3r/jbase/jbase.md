# @k37z3r/jbase

> 标签: ajax, data-utilities, dom-manipulation, framework, immutable, isomorphic, javascript, jbase, jquery-alternative, micro-framework, server-side-rendering, ssr, typescript

## 简介

Ditch the legacy bloat. jBase is a blazing-fast, SSR-ready micro-framework combining an elegant DOM chaining API with powerful, immutable data utilities. Fully typed, modular, and built for modern web & Node.js environments.
