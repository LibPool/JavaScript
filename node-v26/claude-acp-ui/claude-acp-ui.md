# claude-acp-ui

> 标签: acp, claude, claude-code, claude-code-plugin, mod, terminal, tui

## 简介

A Claude Code mod that restyles the terminal like an ACP chat: prompt and tool cards, inline diffs, a status band, footer stats and a /dash pane
