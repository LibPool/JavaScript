# @reformer/builder

> 标签: cli, form-builder, forms, json-schema, low-code, react, reformer, schema-builder, visual-editor

## 简介

Visual form-schema builder for the @reformer ecosystem — a bundled offline SPA you run via npx to build ReFormer JSON form schemas in the browser
