# @3sln/pdfium-wasm

> 标签: emon, pdf, pdfium, render, wasm, webassembly

## 简介

pdfium's WebAssembly build (bblanchon/pdfium-binaries chromium/8076) as an ES module and a .wasm file: the renderer @3sln/emon/pdfium uses by default. Not emon's code; pdfium and the libraries inside it carry their own licences (LICENSE, licenses/).
