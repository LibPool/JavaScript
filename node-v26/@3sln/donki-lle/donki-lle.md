# @3sln/donki-lle

> 标签: custom elements, donki, handwriting, language learning, llm, stroke order, text to speech, web components

## 简介

Language-learning custom elements for LLM-built lessons: text to speech with an in-browser neural fallback, stroke-order writing practice, Donki deck sharing, and sending results back to the chat.
