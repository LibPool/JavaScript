# @atelye/management

> 标签: JavaScript

## 简介

Server-side SDK for the Atelye platform's management API: atlyt_ token authentication, the mandatory tenant header, idempotency-per-intent with reveal-once handling, and keyset pagination as async iterators. Node only.
