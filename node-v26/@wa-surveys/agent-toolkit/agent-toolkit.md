# @wa-surveys/agent-toolkit

> 标签: agent, cli, mcp, surveys, whatsapp

## 简介

WhatsApp Surveys-branded agent skins for the WhatsApp Surveys gateway: an MCP server (wa-surveys-mcp) and a CLI (wa-surveys). A thin alias over @rcs-campaigns/agent-toolkit — same gateway, same tool catalog.
