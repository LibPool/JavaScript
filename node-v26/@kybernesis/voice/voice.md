# @kybernesis/voice

> 标签: agent, eve, eve-channel, kybernesis, realtime, voice

## 简介

Give a KYBER Studio agent its own realtime voice: the floating orb speaks as the agent and delegates every real request back to the agent's own session. The agent holds its own OpenAI key.
