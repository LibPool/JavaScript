# @pith-hash/pith-h264

> 标签: avc, decoder, h264, hashing, video

## 简介

H.264/AVC baseline-subset decoding SDK: Annex-B NAL/SPS/PPS, CAVLC slices, in-loop deblocking via the pith-h264 Rust cdylib (koffi, prebuilt)
