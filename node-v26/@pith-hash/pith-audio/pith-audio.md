# @pith-hash/pith-audio

> 标签: audio, decoder, fingerprinting, hashing, pcm, wav

## 简介

Audio fingerprinting SDK: RIFF/WAVE decode, spectral-peak signatures and delta-t matching via the pith-audio Rust cdylib (koffi, prebuilt)
