# @otter-sh/cli

> 标签: JavaScript

## 简介

The `otter` CLI — a Bun-native ELT tool for extracting from sources, loading into Postgres, and running `.sql` models as a DAG. Think "dbt-shaped workflow, no Python, no Jinja runtime, no `pg`/`postgres.js`/`better-sqlite3`."
