# @ishibashi0112/comparison-grid

> 标签: bom, compare, comparison, datagrid, diff, grid, react, react19, spreadsheet, typescript

## 简介

React 19 製の構成比較コンポーネント(2 構成 / 基準対各構成の N 構成)。リストをキーで突き合わせ、指定フィールドの差分を @ishibashi0112/spreadsheet-grid 上でハイライト表示します。型・データ・列定義・比較設定を渡すだけで差分表示が組み上がり、合成コンポーネント(ComparisonLayout)でペインの配置と数を自由に組めます。
