# @notchip/expo-panoramic-stitcher

> 标签: 360, expo, expo-module, opencv, panorama, react-native, stitching

## 简介

360° / wide panorama image stitching for Expo (SDK 56+) via Swift + Kotlin, powered by OpenCV. No manual OpenCV download required.
