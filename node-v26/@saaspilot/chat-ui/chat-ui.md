# @saaspilot/chat-ui

> 标签: chat, saaspilot, ui

## 简介

SaaS Pilot Chat UI is a collection of pre-built UI components that can be used to integrate a SaaS Pilot chatbot into your software. The purpose of this library is to allow developers to easily integrate SaaS Pilot chatbot into their software.
