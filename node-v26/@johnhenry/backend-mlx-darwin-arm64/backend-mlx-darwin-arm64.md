# @johnhenry/backend-mlx-darwin-arm64

> 标签: apple-silicon, metal, mlx, mlx-c, native, prebuilt

## 简介

Prebuilt MLX runtime for @johnhenry/backend-mlx on macOS/Apple Silicon: libmlxc, libmlx, libjaccl and mlx.metallib (Apple MLX 0.32.2, mlx-c v0.6)
