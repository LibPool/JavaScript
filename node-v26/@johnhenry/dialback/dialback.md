# @johnhenry/dialback

> 标签: http, proxy, request, response, reverse, reverse-proxy, reverse-tunnel, socket, websocket

## 简介

Reverse proxy HTTP requests over web sockets -- an agent dials out, the server dials back through that connection to reach it
