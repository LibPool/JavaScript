# @johnhenry/browsermesh-priority-mux

> 标签: browser, head-of-line-blocking, mesh, multiplexing, priority, scheduler, websocket

## 简介

Application-level priority scheduler that chunks and interleaves messages to prevent head-of-line blocking on single-stream transports (WebSocket) for BrowserMesh
