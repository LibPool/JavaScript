# @johnhenry/window-algebra

> 标签: anchor-positioning, css-grid, functional, layout, reducer, tiling, window-manager

## 简介

A functional window manager for the browser: pure state updates, a small layout algebra that derives a presentation tree, and CSS (flex, grid, anchor positioning, container queries) as the final layout solver.
