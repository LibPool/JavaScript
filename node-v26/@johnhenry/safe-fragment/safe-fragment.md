# @johnhenry/safe-fragment

> 标签: custom-elements, dompurify, html-sanitizer, innerHTML, sanitize-html, sanitizer, security, trusted-types, web-components, xss

## 简介

Framework-agnostic Web Components for rendering HTML-like source into live DOM only after applying an explicit versioned security profile -- never innerHTML/insertAdjacentHTML on untrusted input.
