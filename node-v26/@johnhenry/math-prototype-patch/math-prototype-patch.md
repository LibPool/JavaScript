# @johnhenry/math-prototype-patch

> 标签: complex-number, monkey-patch, number-prototype, typescript

## 简介

OPT-IN, collision-checked Number.prototype patch adding @johnhenry/math's ComplexNumber fluent arithmetic to plain numbers. Never merged into core @johnhenry/math -- see the README before using.
