# @johnhenry/canvas-fx

> 标签: canvas, custom-elements, dithering, html-in-canvas, image-effects, no-build, palette, pixel-art, web-components

## 简介

Pixel effects for images, video, canvases, and live HTML, written as HTML: <pixel-canvas effects="mosaic(4) palette(gameboy)">. Custom elements shipped as source, no build step.
