# @johnhenry/math-plus-scalar-types

> 标签: JavaScript

## 简介

Thin re-export of @johnhenry/math scalar types (ComplexNumber, Rational, Decimal) plus tensor-boundary converters — the single import point for @johnhenry/math types in Math Plus
