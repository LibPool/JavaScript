# @svayam-opensource/gov-work

> 标签: agentic, cli, gov, gov-work, governance, prj

## 简介

gov-work — the OSS project/workflow CLI for the Governed Agentic Development Framework (Node/TypeScript). Manages projects, workspaces, and credentials; enterprise catalog/deploy is the separate gov-cicd CLI. Succeeds the legacy bash @svayam-opensource/pr
