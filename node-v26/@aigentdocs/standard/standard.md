# @aigentdocs/standard

> 标签: agents-md, ai-agents, ddd, docs-as-code, documentation, spec-driven-development

## 简介

The AIGentDocs docs-as-code standard: living domain documentation for AI coding agents. This package is a build-time copy of docs/standard/ in the AIGentDocs repository; its version mirrors the standard's changelog.yaml.
