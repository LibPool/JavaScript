# @backs/config-parser

> 标签: chokidar, config, ini, json, jsonc, reload, toml, xml, yaml, yml

## 简介

A config parser you can use in your apps. It supports hot-reloading, yaml, ini, toml, xml, json and jsonc. Also supports custom parsers
