# @trempel/kit

> 标签: game, kit, pixijs, playables, trempel

## 简介

Trempel kit: a game kit on top of Trempel scenes — services (contracts with a mandatory mock: wallet, iap, leaderboard, your own), platform adapters (web, YouTube Playables, mock), game loop, tweens and clips, event player, state machine, event bus, scree
