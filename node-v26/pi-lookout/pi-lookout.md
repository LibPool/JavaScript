# pi-lookout

> 标签: bash, betterleaks, jev, pi-coding-agent, pi-extension, pi-package, typesafe

## 简介

Pi extension: watches long bash commands and stops them early when Jev judges that the output shows a failure needing intervention and continuing no longer helps.
