# @reliquary/eslint-config

> 标签: eslint, eslint-config, eslintconfig, flat-config, react, typescript

## 简介

Shareable, framework-agnostic ESLint 9 flat config — TypeScript, stylistic and import-hygiene rules. Add @reliquary/eslint-config-react for React projects.
