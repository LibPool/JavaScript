# @jdtzmn/port

> 标签: developer-tools, docker-compose, git-worktree, local-development, localhost, parallel-agents, port-conflict, reverse-proxy, traefik

## 简介

Port CLI runs Docker Compose services in parallel Git worktrees—no port conflicts, with Traefik-routed local branch domains.
