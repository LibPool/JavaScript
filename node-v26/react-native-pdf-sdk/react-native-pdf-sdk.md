# react-native-pdf-sdk

> 标签: android, cad, drawings, ios, nitro, pdf, react-native, tiled, viewer, zoom

## 简介

A PDF SDK for React Native: a viewer that draws in tiles with the platform's own renderer, built for drawings metres wide.
