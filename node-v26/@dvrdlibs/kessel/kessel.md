# @dvrdlibs/kessel

> 标签: ast, estree, fast, javascript, jsx, parser, tsx, typescript

## 简介

Fast JavaScript/TypeScript/JSX/TSX parser. ESTree-compatible ASTs. 8% faster than OXC at the npm boundary.
