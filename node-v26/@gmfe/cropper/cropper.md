# @gmfe/cropper

> 标签: JavaScript

## 简介

`@gmfe/cropper` 是基于 [cropperjs](https://github.com/fengyuanchen/cropperjs) 封装的图片裁剪组件，提供弹窗模式和组件模式两种使用方式。支持图片预览、固定比例裁剪、自定义裁剪尺寸等功能。
