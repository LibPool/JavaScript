# @jotter/websocket

> 标签: WebSocketConnect, reconnect websocket, reconnecting, websocket, websocket client, websocket connect, websocket keep alive

## 简介

Modern and useful WebSocket API wrapper class with additional features such as auto-reconnect, message queuing and Keep-alive detection.
