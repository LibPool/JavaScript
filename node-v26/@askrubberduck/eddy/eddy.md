# @askrubberduck/eddy

> 标签: actions, commands, cqrs, derived-state, effects, flux, react, reducer, redux, redux-alternative, selectors, state, state-management, state-manager, store, typescript, zero-dependency, zustand

## 简介

A domain-sliced state manager: declared actions, procedural commands, derived views that live in state, and named scopes. No redux, no zustand, no dependencies.
