# @nx-devkit/nx-cloud

> 标签: cache, nx, nx-cloud, nx-cloud-rotate, nx-plugin, remote-cache

## 简介

Nx plugin that adds an nx-cloud-rotate target to the workspace root — rolls over to a fresh Nx Cloud organization when quota is exhausted.
