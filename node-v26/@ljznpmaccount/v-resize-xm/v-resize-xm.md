# @ljznpmaccount/v-resize-xm

> 标签: JavaScript

## 简介

实现一个函数同时支持hook和自定义指令 去监听dom宽高变化 新建文件夹，src文件夹下index.ts 1.pnpm init 生成package.json包说明文件 2.tsc --init 生成tsconfig.json文件 3.生成vite.config.ts,index.d.ts(打包声明文件)文件 4.pnpm i vue -D,pnpm i vite -D(安装两个依赖) 5.编写函数 6.配置vite.config.ts 7.配置index.d.ts 8.配置packa
