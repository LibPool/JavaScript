# @cloud-atlas/yishan-it

> 标签: JavaScript

## 简介

面向多主体的个税零申报辅助工具，提供申报流程的可视化教学展示，帮助用户理解申报步骤与操作方法，并辅助完成预填、申报与归档。业务方案与执行授权由用户决定，一闪提供教学展示与自动化操作能力。
