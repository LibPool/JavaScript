# @openmono/protocol

> 标签: JavaScript

## 简介

Cluster wire protocol shared by all Feno clients (daemon, web, iOS, lark): frame envelopes, ACP/agent shapes, discriminated unions, error codes, HLC, and the canonical user-preferences schema rendered by every client's Settings UI.
