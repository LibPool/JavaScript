# @tubeagentkit/langchain-getyoutubetranscript

> 标签: agents, captions, document-loader, langchain, langchain-js, langchainjs, llm, rag, subtitles, tools, transcript, youtube, youtube-search, youtube-transcript, youtube-transcripts

## 简介

YouTube transcript tools and document loader for LangChain.js: get YouTube video transcripts with timestamps and search YouTube from agents and RAG pipelines, via the GetYouTubeTranscript API.
