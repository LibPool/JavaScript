# @algosoftltd/fleet-agent

> 标签: agent, algosoft, fleet

## 简介

The AlgoSoft OS server agent. Dials out to the OS over a websocket — no inbound ports, no tunnel, no firewall rules — and performs a fixed set of named operations.
