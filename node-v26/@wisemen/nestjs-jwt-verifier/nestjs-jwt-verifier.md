# @wisemen/nestjs-jwt-verifier

> 标签: JavaScript

## 简介

Shared JWT verification helpers for NestJS applications. The package provides a plain `JwtVerifier` class plus a `JwtVerifierModule` that can register one or more named verifier instances in Nest DI.
