# @wisemen/wise-date

> 标签: JavaScript

## 简介

✔ dayjs and Moment inspired interface for dealing with calendar dates (no time component) \ ✔ support for +infinity and -infinity dates \ ✔ support for typeorm \ ✔ Immutability – Wisedate is fully immutable, meaning no state bugs. \ ✔ TypeScript Support –
