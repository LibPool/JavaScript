# @chatcode/cco-better-sidebar

> 标签: JavaScript

## 简介

ChatCode CLI Web plugin: a VS Code-like right sidebar (explorer / editor / terminal / git / browser), isolated per conversation session. Exposes a service for other plugins to register sidebar tabs and file viewers.
