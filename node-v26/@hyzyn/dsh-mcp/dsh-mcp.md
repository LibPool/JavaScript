# @hyzyn/dsh-mcp

> 标签: JavaScript

## 简介

DSH Web GUI 的 MCP 服务器配置插件：官方设置 → 插件 里的「MCP 服务器配置」卡片，托管 ~/.dsh/cordis.patch.yml 的 MCP 区块，保存后经 HMR 热加载为 mcp__<server>__<tool> 工具（支持 stdio / streamable-http、连接测试、启用停用）。
