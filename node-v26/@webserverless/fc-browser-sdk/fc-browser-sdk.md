# @webserverless/fc-browser-sdk

> 标签: JavaScript

## 简介

`fc-browser-sdk` 可以在浏览器端使用的函数计算 SDK，在浏览器中使用本包，会存在 AK 泄露的风险，万不可使用主账号的 AK。
