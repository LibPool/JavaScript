# @samasante/liquid-glass

> 标签: apple, chromatic-aberration, cross-browser, displacement-map, feDisplacementMap, firefox, frosted-glass, glass, glassmorphism, headless, lens, liquid-glass, live-dom, react, refraction, safari, svg-filter, ui

## 简介

A headless React liquid-glass lens that refracts the live DOM. Apple-style Liquid Glass that works in Chrome, Safari, and Firefox. Zero runtime dependencies.
