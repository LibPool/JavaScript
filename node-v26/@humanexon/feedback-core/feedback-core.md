# @humanexon/feedback-core

> 标签: JavaScript

## 简介

框架无关的反馈领域核心。对宿主零假设（仅依赖 `zod`）。它持有契约、聚类/聚合逻辑，以及框架无关的前端逻辑。宿主只需实现几个 port 并传入 `ViewerContext`。
