# @eidolondb/mcp

> 标签: JavaScript

## 简介

`@eidolondb/mcp` is a stdio Model Context Protocol (MCP) server that exposes EidolonDB memory operations to MCP-compatible clients. It lets tools like Cursor, Claude Code, and Windsurf store, query, ingest, and format memory context through a single MCP e
