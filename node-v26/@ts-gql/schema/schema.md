# @ts-gql/schema

> 标签: JavaScript

## 简介

An experimental GraphQL schema definition API designed around type safety inspired by [Nexus](https://github.com/graphql-nexus/nexus/) and [gqtx](https://github.com/sikanhe/gqtx).
