# @bigin-io/renderer-core

> 标签: JavaScript

## 简介

The framework-agnostic half of both renderers: theme derivation, section chrome, SEO, i18n routes, the image-variant planner, media transform URLs, markdown, icons, and the form/analytics/search mounts
