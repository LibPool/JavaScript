# @massiv-oss/grpc-fake-server

> 标签: buf, connect, fake, grpc, grpc-web, mock, protobuf, testing

## 简介

A fake gRPC server that returns responses from Protobuf schemas, with a buf plugin that generates typed admin clients for tests.
