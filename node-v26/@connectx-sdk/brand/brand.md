# @connectx-sdk/brand

> 标签: anp, brand, connectx, css, did, tokens

## 简介

The framework-agnostic connectx brand layer: token CSS, the mark's geometry, and the small display helpers every framework binding renders it with. Imported by @connectx-sdk/react and @connectx-sdk/vue so the brand has one source of truth.
