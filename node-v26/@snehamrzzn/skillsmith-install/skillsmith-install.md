# @snehamrzzn/skillsmith-install

> 标签: agent, claude, cursor, installer, skill, skillsmith

## 简介

One-line installer for Skillsmith-authored agent skills (Claude / Cursor / generic). Fetches a shared skill by its short ID and writes the SKILL.md to the right place.
