# @kanava/editor

> 标签: block-editor, document-editor, editor, headless, notion, prosemirror, rich-text, typescript, wysiwyg

## 简介

Headless block editor engine built on ProseMirror. Provides document model, commands, pagination, and layout primitives for building rich text editors.
