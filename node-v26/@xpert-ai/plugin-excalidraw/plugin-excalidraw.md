# @xpert-ai/plugin-excalidraw

> 标签: JavaScript

## 简介

Collaborative Excalidraw plugin with Agent-created diagrams, Yjs multiplayer editing, interactive HTML Artifact sharing, reviewable versions, DiagramIR, and an editable workbench.
