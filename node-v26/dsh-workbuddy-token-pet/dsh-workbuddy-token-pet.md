# dsh-workbuddy-token-pet

> 标签: context, deepseek, dsh, dsh-plugin, harness, pet, token, widget

## 简介

浮动桌宠：实时显示当前会话的 token 占用与每步消耗，并统计 WorkBuddy 消耗的积分与账户剩余额度（积分需另装 dsh-workbuddy-bridge）。A floating pet for DeepSeek Harness showing live context occupancy, per-step token spend, and the WorkBuddy credits each step was billed plus the remaining balance.
