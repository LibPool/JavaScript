# @electron-stagewright/plugin-clock

> 标签: ai-agent, clock, electron, mcp, stagewright, testing

## 简介

Clock plugin for Electron Stagewright: deterministic virtual time (install, freeze, and advance the clock) for testing time-dependent UI.
