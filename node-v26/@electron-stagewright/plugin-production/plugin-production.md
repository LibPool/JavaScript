# @electron-stagewright/plugin-production

> 标签: ai-agent, code-signing, electron, mcp, notarization, production, stagewright

## 简介

Production validation plugin for Electron Stagewright: validate packaged macOS apps for bundle structure, plist metadata, URL schemes, updater feeds, crash capture, signing, notarization, and Gatekeeper.
