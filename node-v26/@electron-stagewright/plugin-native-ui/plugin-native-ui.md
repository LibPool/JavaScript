# @electron-stagewright/plugin-native-ui

> 标签: ai-agent, electron, macos, mcp, menu, native-ui, notifications, stagewright, testing, tray

## 简介

Native UI plugin for Electron Stagewright: read, assert, invoke app menus, capture shown notifications, and read or fire system-tray events.
