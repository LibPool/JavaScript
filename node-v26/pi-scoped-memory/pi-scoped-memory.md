# pi-scoped-memory

> 标签: memory, multi-tenant, pi-extension, pi-package

## 简介

Scope-agnostic long-term memory extension for pi: remember/recall/forget tools plus frozen-snapshot injection into the system prompt. The plugin only knows a directory; the host owns identity.
