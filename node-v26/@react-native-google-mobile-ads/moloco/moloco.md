# @react-native-google-mobile-ads/moloco

> 标签: admob, gam, google-mobile-ads, mediation, moloco, react-native

## 简介

Moloco Google Mobile Ads (GAM) mediation adapter for react-native-google-mobile-ads. Links the official Google mediation adapter on Android and iOS; does not add JS ad APIs.
