# @whatcha/cli

> 标签: cli, diary, journal, whatareyoudo, whatcha

## 简介

Official command-line client for what-are-you-do-ing (whatareyoudo.ing) -- login (password or personal access key), list diaries, write and read entries, switch profiles, read and write the Experience Wiki, with images.
