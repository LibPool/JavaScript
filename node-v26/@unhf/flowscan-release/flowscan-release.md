# @unhf/flowscan-release

> 标签: JavaScript

## 简介

FlowScan Release 是一个现代化的版本管理工具，提供了完整的版本升级和 Git 标签管理功能。它基于业界标准的 [Semantic Versioning (SemVer)](https://semver.org/) 规范，确保版本管理的可靠性和一致性。
