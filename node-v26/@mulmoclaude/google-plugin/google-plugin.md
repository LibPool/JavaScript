# @mulmoclaude/google-plugin

> 标签: claude-code, google, google-calendar, google-drive, google-tasks, gui-chat-protocol, mulmoclaude, mulmoclaude-plugin, mulmoterminal, oauth

## 简介

Google integration tool for MulmoClaude and MulmoTerminal — operates the user's locally linked Google account: Calendar (list, sync, create, update, delete), Tasks and Drive, as one kind-discriminated `google` tool. Server-only; no Vue View.
