# @mulmoclaude/skill-bridge

> 标签: JavaScript

## 简介

Skill staging→active mirror rule for MulmoClaude and MulmoTerminal. The agent writes skill drafts under data/skills/<slug>/ (no .claude/ permission gate); this mirrors the allowlist (SKILL.md, schema.json, templates/<safe path>) into .claude/skills/<slug>
