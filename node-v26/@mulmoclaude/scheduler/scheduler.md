# @mulmoclaude/scheduler

> 标签: JavaScript

## 简介

Cron tick engine (dependency-ordered task-manager) + persistence/catch-up adapter over @receptron/task-scheduler, shared by MulmoClaude and MulmoTerminal. Workspace root, atomic writer, and logger are injected; the host supplies its own system tasks.
