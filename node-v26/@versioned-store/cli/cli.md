# @versioned-store/cli

> 标签: admin, cli, config-versioning, kill-switch, operator, rollback, versioned-store

## 简介

A descriptor-driven operator CLI for @versioned-store: one uniform verb set (list/add/promote/revert/seed/sync/diff/health) over every store domain, with a gated promote and an audit-sink drain, so no consumer hand-rolls an admin surface.
