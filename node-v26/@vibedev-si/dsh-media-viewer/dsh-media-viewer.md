# @vibedev-si/dsh-media-viewer

> 标签: audio, deepseek-harness, dsh, dsh-better-sidebar, dsh-plugin, file-viewer, gallery, html, lightbox, preview, quick-look, right-sidebar, vibedev, video

## 简介

右侧栏媒体预览：从文件树点开图片、视频、音频先浮动预览（可一键在新标签页打开），直接预览视频、音频和 HTML（大文件可拖进度条，HTML 默认允许脚本），文件夹媒体画廊（多选后加入影视工作台画布）；用 DSH 自带的右侧栏，装了 dsh-better-sidebar 时也在其中可用 · A floating quick preview for images, video and audio opened from the file tree, inline video, audio and HTML p
