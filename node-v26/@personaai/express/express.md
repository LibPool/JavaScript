# @personaai/express

> 标签: adapter, ag-ui, agents, express, persona, persona.hasanraiyan.me, runtime

## 简介

Express adapter for the Persona runtime (persona.hasanraiyan.me) — mounts @personaai/runtime as an Express Router. Server-side only.
