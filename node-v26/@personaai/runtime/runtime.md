# @personaai/runtime

> 标签: ag-ui, agents, persona, persona.hasanraiyan.me, runtime

## 简介

Framework-agnostic runtime engine for Persona (persona.hasanraiyan.me) — the shared engine every framework adapter (@personaai/express, @personaai/nextjs, ...) wraps. Server-side only.
