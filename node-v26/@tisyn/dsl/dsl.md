# @tisyn/dsl

> 标签: JavaScript

## 简介

`@tisyn/dsl` parses Tisyn Constructor DSL text into IR by calling the real `@tisyn/ir` constructor functions. The parser is the inverse of `print()` — it round-trips between text and IR.
