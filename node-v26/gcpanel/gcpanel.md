# gcpanel

> 标签: angular, angularjs, cli, compile, dev-server, i18n, jade, pipeline, pug, reverse-proxy

## 简介

CLI for AngularJS frontend projects: compile pipeline (jade/pug + i18n + concat), watch mode, dev server with reverse proxy, production build and web UI panel
