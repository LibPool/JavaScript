# @dshtrading/connector-hithink

> 标签: JavaScript

## 简介

同花顺（问财）OpenAPI A 股与期货数据连接器（BYOK，凭证 ref 为 HITHINK_FINANCE_API_KEY）：实现 tradingCnMarketData 与 tradingFuturesMarketData 行情服务（ticker / K 线 / 基本面 / 集合竞价 / 连板池）；仅数据面，无交易通道、不注册工具。
