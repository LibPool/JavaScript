# @dshtrading/connector-yahoo

> 标签: JavaScript

## 简介

US market connector plugin for dsh-trading: public market data from the Yahoo Finance v8 chart API implementing the @dshtrading/api contracts (unofficial API, no key; personal use per Yahoo terms of use)
