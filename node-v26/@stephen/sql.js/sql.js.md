# @stephen/sql.js

> 标签: RDBMS, data, database, emscripten, query, relational, sql, sqlite, stand-alone, statement

## 简介

SQLite package with support for opening and writing databases, prepared statements, and more. This package is a fork of sql.js with built-in es module and typescript support.
