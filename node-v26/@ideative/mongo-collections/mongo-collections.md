# @ideative/mongo-collections

> 标签: api, api-handler, api-routes, endpoint, error, error-handling, error-serialization, errors, next, nextjs, payload, zod

## 简介

Mongo Collections - Strongly-typed MongoDB collections with optional document transformers (substituers), domain errors, and a small service layer. Built on the official mongodb driver.
