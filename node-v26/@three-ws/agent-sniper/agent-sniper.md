# @three-ws/agent-sniper

> 标签: 3d-agent, ai-agent, mcp, memecoin, pumpfun, sniper, solana, trading-bot, x402

## 简介

Lightweight, embeddable pump.fun sniper engine for 3D AI agents — multi-agent, multi-user, with pluggable wallet/store/RPC adapters. Library + CLI + MCP server + x402 paid API.
