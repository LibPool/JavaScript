# @three-ws/page-agent

> 标签: 3d, ai-agent, avatar, lipsync, narrator, page-guide, readyplayerme-alternative, rigged, talking-avatar, text-to-speech, three.js, viseme, web-component, webgl

## 简介

Drop a rigged 3D AI agent onto any website that talks visitors through the page. A diverse catalog of skeleton-rigged, lipsync-capable avatars, a built-in picker so visitors choose their guide, and a one-line embed. Powered by three.ws.
