# @three-ws/herald-mcp

> 标签: agent, alerts, avatar, herald, mcp, notifications, three.ws, tts

## 简介

Let an AI agent tell its human something in person: a 3D character walks onto the browser tab they have open and says it out loud. Announce a line, report a finished task with the right urgency, or check the rail. Account-scoped over the live three.ws API
