# @three-ws/avatar-stream

> 标签: 3d, avatar, glb, gltf, level-of-detail, lod, meshopt, progressive, range-requests, streaming, three.js, three.ws

## 简介

Progressive 3D over plain HTTP. Pack a GLB into a layered A3S stream whose first 50 KB is already a complete, skinned, spec-valid avatar, then refine it in place with byte-range requests. No custom server, no WebSocket, no new codec.
