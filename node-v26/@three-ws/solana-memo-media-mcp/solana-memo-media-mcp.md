# @three-ws/solana-memo-media-mcp

> 标签: data-uri, mcp, onchain-media, solana, spl-memo, three.ws

## 简介

Extract, validate, and display image data URIs embedded in Solana SPL Memo instructions. Read-only, local decoding, no key required.
