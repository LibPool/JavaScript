# @dreki-gg/taskman

> 标签: cli, planning, tanstack-intent, tasks

## 简介

Standalone task-management engine + CLI over a JSONL plan ledger (default .taskman/plans/, configurable via .taskmanrc) — the plan-mode core, usable from any Node harness
