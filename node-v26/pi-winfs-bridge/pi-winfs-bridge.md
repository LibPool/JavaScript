# pi-winfs-bridge

> 标签: 9p, drvfs, extension, filesystem, performance, pi, pi-coding-agent, pi-package, windows, wsl, wsl2

## 简介

Make Windows drives fast for Pi running inside WSL2: routes read/edit/ls/find/grep through a native Windows helper instead of drvfs/9p.
