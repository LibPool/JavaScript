# @ngocbaongo/quickshare

> 标签: airdrop, android, clipboard-sync, cross-platform, file-transfer, ios, macos, quickshare, windows

## 简介

Bi-directional clipboard and file transfer between macOS, Windows, iOS, and Android over local Wi-Fi and Cloudflare Tunnel.
