# @kumikijs/icons

> 标签: ai-first, heroicons, icons, kumiki, svg

## 简介

Kumiki built-in icon set — Heroicons solid SVG path data, keyed by name. Auto-bundled by @kumikijs/vite and the kumiki CLI.
