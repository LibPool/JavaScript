# @mosvera/runtime

> 标签: aesthetic-infrastructure, ai, json-schema, mosvera, runtime

## 简介

TypeScript/JavaScript runtime for Mosvera. Load aesthetic registries, resolve named compositions, compile neutral tokens, validate schemas, and apply merge/compile semantics.
