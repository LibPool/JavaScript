# @dwkerwin/seed-project-renamer

> 标签: bootstrap, initialization, project, rename, seed, template

## 简介

A utility for bootstrapping seed projects by consistently renaming all references across files, supporting multiple naming conventions and explicit source project specification via --from parameter
