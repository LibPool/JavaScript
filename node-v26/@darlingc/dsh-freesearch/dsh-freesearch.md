# @darlingc/dsh-freesearch

> 标签: bing, deepseek-harness, dsh, dsh-plugin, duckduckgo, exa, free, keenable, perplexity, search, tavily, web-search

## 简介

Free web search for DeepSeek Harness: 11 engines (Bing/DuckDuckGo/AnySearch/SearXNG/Exa/Tavily/Keenable keyless + Gemini grounding) + time filtering + platform search + web_fetch, with web settings UI.
