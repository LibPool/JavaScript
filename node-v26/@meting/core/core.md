# @meting/core

> 标签: api, baidu, kugou, kuwo, lightweight, lyrics, music, music-api, netease, no-dependencies, nodejs, search, streaming, tencent

## 简介

A powerful music API framework to accelerate development - Node.js port. Support Netease, Tencent, Kugou, Baidu, Kuwo music platforms.
