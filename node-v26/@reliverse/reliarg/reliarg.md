# @reliverse/reliarg

> 标签: JavaScript

## 简介

A zero-dependency CLI argument parser built for clarity, predictability, and modern TypeScript devs. @reliverse/reliarg handles booleans, aliases, default values, strict/loose modes, arrays, negated flags, and more — without the weird edge cases.
