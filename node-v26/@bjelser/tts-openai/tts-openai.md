# @bjelser/tts-openai

> 标签: JavaScript

## 简介

The OpenAI TTS provider plugin for docent. Wraps the official `openai` npm package's `audio.speech.create()` and exposes it through @bjelser/kit's TtsProviderPlugin contract.
