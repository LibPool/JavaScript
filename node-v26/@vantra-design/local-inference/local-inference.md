# @vantra-design/local-inference

> 标签: browser-ai, design-system, local-inference, tts, vantra, webgpu, webllm

## 简介

Shared browser-side inference runtime: WebGPU detection, WebLLM engine wrapper, and Kokoro TTS — used by @vantra-design/ask-design-system and @vantra-design/screenreader-empathy.
