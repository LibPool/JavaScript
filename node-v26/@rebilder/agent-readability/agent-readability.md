# @rebilder/agent-readability

> 标签: agent-readability, agents, ars, llms-txt, scoring, seo, spec

## 简介

The Agent Readability Score (ARS 0.2). A pure, deterministic scorer at "." — no network, no clock, no randomness, no LLM — and a server-only probe at "./probe". Zero runtime dependencies.
