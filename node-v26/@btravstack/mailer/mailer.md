# @btravstack/mailer

> 标签: dependency-injection, email, mailer, smtp, typescript, unthrown

## 简介

A Mailer port for @btravstack/core: a recording adapter a spec asserts against, an SMTP adapter, and a composition that spans, counts and logs every send
