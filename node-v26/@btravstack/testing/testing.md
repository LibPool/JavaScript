# @btravstack/testing

> 标签: dependency-injection, fixture, kernel, testing, typescript, unthrown, vitest

## 简介

Test the applications @btravstack/core boots: an in-memory runtime, a fake clock, a boot fixture that stops what it started, and a tap into a running graph
