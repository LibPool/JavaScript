# @btravstack/temporal-worker

> 标签: graceful-shutdown, lifecycle, runtime, temporal, typescript, unthrown, worker

## 简介

The Temporal worker runtime for @btravstack/core: one unit per activity attempt, and a drain that honours the kernel's deadline
