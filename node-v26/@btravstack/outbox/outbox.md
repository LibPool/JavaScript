# @btravstack/outbox

> 标签: dependency-injection, outbox, postgres, prisma, typescript, unthrown

## 简介

The transactional outbox relay for @btravstack/core: a poll loop that publishes committed facts in outbox order, a per-tenant claim so replicas take turns rather than race for the same rows, and a Prisma 8 store
