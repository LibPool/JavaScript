# @alaarab/ogrid-react-xlsx-browser

> 标签: browser, esm, excel, no-bundler, ogrid, spreadsheet, vendor, xlsx

## 简介

Self-contained browser ESM bundle of @alaarab/ogrid-react-xlsx. React + ReactDOM + ExcelJS + every @alaarab/ogrid-* dep included with local lazy chunks. Copy dist/ into a static vendor/ directory and `import()` from a no-bundler app.
