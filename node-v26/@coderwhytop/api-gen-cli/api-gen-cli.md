# @coderwhytop/api-gen-cli

> 标签: api, apipost, cli, generator, javascript, typescript, yapi

## 简介

一个强大的 API 代码生成器，支持 YApi 和 APIPost 平台，能够自动生成 TypeScript/JavaScript API 函数和类型定义。
