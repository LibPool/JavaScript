# @layermetry/image-editor

> 标签: ai, brand-kit, canvas, design-editor, editor-sdk, embeddable, graphic-design, image-editor, layermetry, multi-page, pdf-export, photo-editor, png, react, stickers, svelte, templates, typescript, vue, web-component, white-label

## 简介

Embeddable image and design editor SDK for web apps: templates, text, shapes, stickers, brand kits, multi-page designs, AI generation, and in-browser export to PNG, JPG and PDF. React, Vue, Svelte or plain JavaScript.
