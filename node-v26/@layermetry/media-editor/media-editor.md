# @layermetry/media-editor

> 标签: ai, canvas, captions, design-editor, editor-sdk, embeddable, image-editor, layermetry, media-editor, photo-editor, react, svelte, templates, timeline, typescript, video-editor, vue, web-component, webcodecs, white-label

## 简介

Embeddable image and video editor SDK for web apps: templates, text, stickers, captions, AI generation, timeline, and in-browser export to PNG, JPG, PDF, MP4, WebM and GIF. React, Vue, Svelte or plain JavaScript.
