# @agentworkforce/persona-repo-router

> 标签: agentworkforce, codebase, dispatch, orchestration, persona, relayfile, routing

## 简介

AgentWorkforce repo-router persona pack — codebase navigator that maps all sibling repos, determines which repo(s) an issue requires changes in, and spawns codex implementer + claude reviewer agents pointed at the correct repos. Handles multi-repo issues
