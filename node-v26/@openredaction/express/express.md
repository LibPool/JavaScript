# @openredaction/express

> 标签: JavaScript

## 简介

Express middleware and route handlers for PII detection and redaction. Inspects request bodies, optionally auto-redacts fields, and attaches results to `req.pii`. Express is a peer dependency (`>=4.18 || >=5`).
