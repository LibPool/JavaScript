# obix-compiler-dop

> 标签: compiler, dop, lowering, obix, vue

## 简介

The DOP lowering of the .obix compiler: the Vue frontend artifacts (canonical SFC, script setup, template) lowered into the canonical, frontend-neutral OBIX DOP IR of obix-compiler-ir — with the source provenance kept in a separate document and the origin
