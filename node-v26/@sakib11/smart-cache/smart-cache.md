# @sakib11/smart-cache

> 标签: async-cache, cache, caching, distributed-cache, file-cache, function-cache, lru, memoize, memory-cache, redis, stale-while-revalidate, storage-adapter, ttl, typescript

## 简介

A flexible caching library that automatically caches results of async functions with multiple pluggable storage backends (memory, Redis, filesystem, custom).
