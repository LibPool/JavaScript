# @labelzoom/sdk

> 标签: barcode, dpl, epl, ipl, label, labelzoom, pdf, sbpl, tspl, zebra, zpl

## 简介

Official Node.js/TypeScript SDK for the LabelZoom API. Converts barcode labels between ZPL, EPL, IPL, TSPL, DPL, SBPL, PDF, LabelZoom XML/JSON and raster images.
