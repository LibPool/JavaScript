# n8n-nodes-bluebubbles

> 标签: bluebubbles, imessage, n8n, n8n-community-node-package

## 简介

n8n community nodes for BlueBubbles (self-hosted iMessage server): credential, action node (messages, chats, attachments, contacts, scheduled messages) and auto-subscribing webhook trigger
