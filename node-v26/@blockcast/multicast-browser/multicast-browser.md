# @blockcast/multicast-browser

> 标签: adapter, browser, iwa, multicast, window.multicast

## 简介

Browser/extension/IWA adapter for the frozen v1 window.multicast contract: structural provider resolution plus readiness observation collection. Its only dependency is @blockcast/multicast-contract, which is itself dependency-free and consumed type-only.
