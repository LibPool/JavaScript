# @akku-work/consent-auth

> 标签: authenticated, cmp, consent, dpdp, gdpr, preference-management, privacy, react, react-hooks, sdk

## 简介

Akku Consent - SDK for authenticated web applications, with optional React bindings. Identity travels only inside a host-signed subject token.
