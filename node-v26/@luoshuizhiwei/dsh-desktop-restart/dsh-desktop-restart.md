# @luoshuizhiwei/dsh-desktop-restart

> 标签: deepseek-harness, desktop, dsh, dsh-plugin, electron, restart

## 简介

DeepSeek Harness desktop restart plugin: five entries (sidebar panel / sidebar footer / conversation header / slash command / settings row) restart the whole Electron app through a detached helper; restarts are hard-blocked while a plugin install/update i
