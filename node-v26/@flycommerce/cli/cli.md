# @flycommerce/cli

> 标签: cli, ecommerce, embedded-apps, flycommerce, sdk

## 简介

The FlyCommerce command line: create apps, point them at the platform, run them on the emulator or on a real store through a tunnel, release versions with changelogs from your commits, manage secrets and deploy tokens, and submit for review.
