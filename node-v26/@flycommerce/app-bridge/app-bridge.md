# @flycommerce/app-bridge

> 标签: app-bridge, ecommerce, embedded-apps, flycommerce, sdk

## 简介

Run a FlyCommerce app inside the merchant dashboard: session tokens, navigation, title bar, dialogs and dashboard context. Includes React hooks and a server-side session token verifier.
