# @anthnyalxndr/gtm-client

> 标签: google-tag-manager, gtm, oauth, tagmanager

## 简介

Authenticated, throttled Google Tag Manager API v2 client: OAuth with a shared credential directory, retry with backoff, and typed helpers for accounts and containers.
