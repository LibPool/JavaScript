# @anthnyalxndr/gtm-apply

> 标签: google-tag-manager, gtm, infrastructure-as-code, tagmanager

## 简介

Declarative apply tool for Google Tag Manager: plan and reconcile a container against a JSON spec in the shape of a GTM container export.
