# @statewalker/webrun-builder

> 标签: JavaScript

## 简介

Project-free signal-driven build engine (BuildEngine<THost>): schedules dataflow builders over @statewalker/webrun-dataflow, drives file-backed update/transaction stores, and detects source changes over a FilesApi. Host-agnostic, with a local structural L
