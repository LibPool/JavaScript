# @1x402/mcp

> 标签: 1x402, agents, mcp, model-context-protocol, usdc, x402

## 简介

MCP server for 1x402 — discover, top up credits, and route paid x402 calls as agent tools, signed by a local wallet. Ships a guided `install` command.
