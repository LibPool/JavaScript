# @nosistech/korvin

> 标签: agentic-ai, ai-agent, governance, nosistech, security, telegram-bot, voice

## 简介

Open-source, self-hosted AI agent framework for low-cost hardware. Voice-first. Memory-persistent. Model-agnostic. No lock-in.
