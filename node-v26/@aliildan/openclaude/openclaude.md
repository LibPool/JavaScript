# @aliildan/openclaude

> 标签: anthropic, claude, claude-code, cli, llm, ollama, proxy, router

## 简介

Tiny multi-provider router for Claude Code: mix Anthropic Claude (subscription auth), Ollama Cloud, and local Ollama with per-duty model assignments.
