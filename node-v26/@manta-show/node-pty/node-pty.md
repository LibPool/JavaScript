# @manta-show/node-pty

> 标签: forkpty, openpty, pseudoterminal, pty, terminal, tty

## 简介

Fork pseudoterminals in Node.JS. Vendored fork of node-pty@1.1.0-beta34 (pinned for macOS 26 posix_spawnp compat) with a non-fatal postinstall: the npx node-gyp tooling step no longer breaks global installs.
