# @suku/suku-ethereum-node-api-client-lib

> 标签: JavaScript

## 简介

This is the SUKU Ethereum Node API Client Lib that can be used to handle REST calls to the [SUKU Ethereum Node API](https://github.com/SukuLab/suku-ethereum-node-api).
