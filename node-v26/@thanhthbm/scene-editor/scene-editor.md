# @thanhthbm/scene-editor

> 标签: JavaScript

## 简介

Embeddable three.js scene editor exported as a library. Designed to be mounted in a Frappe Desk/FormView (Vue page) for editing machine figures & building factory 3D layouts, with external event bindings via websocket / Frappe API.
