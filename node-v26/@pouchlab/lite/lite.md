# @pouchlab/lite

> 标签: database, db, embeddable, nodejs, offline-first, orm, sync, ultra fast

## 简介

A very simple but yet fast json and files storage engine that's embeddable,syncs  [`pouchlite`](https://github.com/pouchlabs/pouchlite).
