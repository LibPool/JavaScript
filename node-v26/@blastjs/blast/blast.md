# @blastjs/blast

> 标签: JavaScript

## 简介

Blast is a powerful library for creating user interfaces by writing reactive HTML templates. Compared to using a combination of traditional templates and jQuery, Blaze eliminates the need for all the "update logic" in your app that listens for data change
