# @quartz-community/canvas-page

> 标签: canvas, json-canvas, obsidian, page-type, quartz, quartz-plugin

## 简介

JSON Canvas (Obsidian .canvas) page type plugin for Quartz v5. Renders interactive canvas visualizations with nodes and edges.
