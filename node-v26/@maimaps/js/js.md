# @maimaps/js

> 标签: geocoding, loccode, maiaddy, maimaps, maps, routing

## 简介

Maimaps core JavaScript/TypeScript SDK: search, routing, reverse geocoding, point details, loccode, and map style helpers over the keyed /sdk/v1 API.
