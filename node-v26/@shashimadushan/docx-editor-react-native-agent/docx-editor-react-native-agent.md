# @shashimadushan/docx-editor-react-native-agent

> 标签: agent, ai, docx, editor, expo, plugin, react-native, webview

## 简介

AI agent plugin for @shashimadushan/docx-editor-react-native — adds the "@" mention / "Edit with AI" agent to the mobile DOCX editor. Install it only if you want an agent; don't, and none of its code is in your app bundle.
