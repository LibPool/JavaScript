# @shashimadushan/docx-editor-collaboration

> 标签: collaboration, docx, editor, hocuspocus, presence, realtime, tiptap, yjs

## 简介

Real-time multi-user collaboration for @shashimadushan/docx-editor-editor. Yjs-based live editing, presence/online-users, live cursors, and invite/share-link UI — backend-agnostic, ships a self-hosted Hocuspocus reference server.
