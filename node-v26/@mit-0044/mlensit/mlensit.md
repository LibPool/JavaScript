# @mit-0044/mlensit

> 标签: architecture, cli, code-quality, offline, static-analysis, test-generation, typescript

## 简介

Offline Static Code Intelligence Platform: analyze a TypeScript/JavaScript project, generate and run tests, and produce reports — entirely through static analysis, no network calls, no AI at runtime.
