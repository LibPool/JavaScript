# @imshaikot/orbit-code-server

> 标签: claude-code, dependency-graph, orbit, visualization

## 简介

Orbit Code in your browser: the Orbit host for one folder in a Node process on 127.0.0.1, which the web client at orbit-code.imshaikot.com/web-client/ connects to.
