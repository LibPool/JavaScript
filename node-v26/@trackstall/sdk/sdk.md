# @trackstall/sdk

> 标签: attribution, meta-capi, mmp, mobile-measurement, react-native, skadnetwork, tiktok-events-api

## 简介

TrackStall client SDK (React Native / JS / web): clicks, install match, install referrer, ATT/IDFA, and attribution events with offline buffering + retry. Self-contained build — @trackstall/core, js-sha256 and uuid are inlined.
