# @stellayazilim/mcp-starlight

> 标签: astro, astro-integration, documentation, mcp, modelcontextprotocol, starlight

## 简介

Give any Astro Starlight docs site an MCP server. Build-time catalog + stdio server over npx — no hosting required, works on GitHub Pages. Locale- and version-aware.
