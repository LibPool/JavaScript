# @ngshade/ui

> 标签: accessibility, angular, angular-cdk, components, design-system, shadcn, shadcn-ui, tailwindcss, ui

## 简介

Accessible Angular components in the shadcn/ui style: composable parts, Tailwind CSS v4 under the hood (prefix ns:), themed with CSS variables. Your app does not need Tailwind.
