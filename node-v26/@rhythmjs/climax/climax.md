# @rhythmjs/climax

> 标签: cli, documentation, help, middleware, rhythm

## 简介

General-purpose building blocks for Rhythm CLIs. Currently: command documentation and --help output (doc-only middlewares plus a module that renders help from the cli's registered commands).
