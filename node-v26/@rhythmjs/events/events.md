# @rhythmjs/events

> 标签: bun, event-bus, event-emitter, events, pubsub, rhythm, typed-events, wildcard

## 简介

Fully typed event bus for Rhythm on the native node:events engine (Bun-optimized): template-literal-typed wildcard subscriptions, dual emit semantics, and AbortSignal unsubscription. Zero dependencies.
