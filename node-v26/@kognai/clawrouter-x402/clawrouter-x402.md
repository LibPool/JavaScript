# @kognai/clawrouter-x402

> 标签: base, clawrouter, kognai, model-router, viem, x402

## 简介

ClawRouter v2 — Kognai's viem-backed x402 ModelRouter implementation. Injected into @kognai/orchestrator-core's router seam at startup, so core never depends on viem; products that don't route on-chain simply don't install this package.
