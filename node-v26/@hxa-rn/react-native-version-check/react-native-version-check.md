# @hxa-rn/react-native-version-check

> 标签: harmony, harmonyos, react-native

## 简介

为 React Native 应用提供版本检查能力：通过原生模块读取当前应用版本信息，联网查询应用商店最新版本，基于 semver 判断是否需要更新并生成应用商店链接
