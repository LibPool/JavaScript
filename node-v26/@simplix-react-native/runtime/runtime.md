# @simplix-react-native/runtime

> 标签: expo, react-native, runtime, simplix-react

## 简介

Expo runtime glue for simplix-react-native: secure token store adapters, Boot mutator assembly, app boot (error dialog, i18n registration, msw/native wiring)
