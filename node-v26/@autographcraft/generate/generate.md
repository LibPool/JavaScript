# @autographcraft/generate

> 标签: api-generator, autographcraft, cli, code-generation, codegen, graphql, graphql-api, graphql-schema, scaffolding, typescript

## 简介

CLI that generates a complete GraphQL API - resolvers, typedefs, TypeScript types, and database schema - from GraphQL schema files
