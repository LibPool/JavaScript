# @inflatable-cookie/longhorn-tauri

> 标签: JavaScript

## 简介

The Tauri host edge: `invoke`/`listen` transport plus the per-domain adapters that bind a Longhorn client to a Tauri command surface. Peers on `@inflatable-cookie/longhorn` and `@tauri-apps/api`.
