# @chronatum/ts-sdk

> 标签: ai-disclosure, chronatum, creation-history, music, provenance, verification

## 简介

TypeScript SDK for the Chronatum API — verify credentialed audio, inspect the structured production record, and run partner review workflows. Generated from the Chronatum TypeSpec model.
