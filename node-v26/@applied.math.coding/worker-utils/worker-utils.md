# @applied.math.coding/worker-utils

> 标签: JavaScript

## 简介

* A small package that intends to facilitate the use of <b>workers</b> in the browser.<br><br> * It supports the use of <b>ownership transferal</b>, <b>shared data</b> and <b>structured clones</b>.<br><br> * It provides utilities like <b>mutex</b> for s
