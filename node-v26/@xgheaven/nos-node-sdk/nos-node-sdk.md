# @xgheaven/nos-node-sdk

> 标签: nos, nos-node-sdk

## 简介

NOS Node.js SDK实现了NOS对象操作接口，基于此SDK能方便快速地实现JavaScript应用程序来使用NOS的对象存储服务。
