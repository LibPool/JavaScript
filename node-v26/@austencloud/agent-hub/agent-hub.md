# @austencloud/agent-hub

> 标签: agent, claude, claude-code, cli, codex, launcher, taskbar, windows, windows-terminal

## 简介

Windows taskbar popover that asks "Claude or Codex?" and opens the chosen agent in the project you clicked, in its own tinted Windows Terminal window.
