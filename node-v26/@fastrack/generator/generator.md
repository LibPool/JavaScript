# @fastrack/generator

> 标签: JavaScript

## 简介

CLI: `fastrack new <service>`, `fastrack gen resource|controller|service|repository [--db mssql|oracle]`. Generated structure: src/routes, schemas, services, repositories, di. Explicit, boring code.
