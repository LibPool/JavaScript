# @fastrack/starter-actuator

> 标签: JavaScript

## 简介

Endpoints: `/live` (process alive), `/ready` (readiness + contributors), `/health` (full health), `/info` (version/build/env), `/metrics` (Prometheus). Other starters register health contributors.
