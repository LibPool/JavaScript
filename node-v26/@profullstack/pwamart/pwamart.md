# @profullstack/pwamart

> 标签: app-store, cli, hqtui, installer, progressive-web-app, pwa, tui

## 简介

pwamart from the terminal: search the web-app store, install PWAs as app windows, publish your own, and browse it all in an hqtui TUI.
