# @profullstack/deploy

> 标签: batch, concurrency, deploy, fleet, flock, oom, rollout, semaphore

## 简介

Deploy in batches, 3 at a time: a box-wide deploy gate (bash + flock) every deploy takes a slot from, and a batch runner for rolling one change out to many repos. Zero dependencies.
