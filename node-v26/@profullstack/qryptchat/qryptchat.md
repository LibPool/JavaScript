# @profullstack/qryptchat

> 标签: chat, cli, e2ee, mcp, ml-kem, post-quantum, qrypt.chat, tui

## 简介

qc: qrypt.chat in your terminal. A full-screen end-to-end encrypted chat client (ML-KEM-1024), plus a scriptable CLI and an MCP server.
