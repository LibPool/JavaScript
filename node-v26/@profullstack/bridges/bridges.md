# @profullstack/bridges

> 标签: account-linking, bridge, bun, coinpay, edge, forum, hono, nextjs, oauth, oauth2.1, oidc, pkce, silent-sign-in, single-sign-on, sso

## 简介

Let a host site's signed-in users use an app automatically: an account bridge over OAuth 2.1 authorization code + PKCE S256, with silent sign-in. Host handlers and app client are fetch-style (Request in, Response out), stateless (sealed codes), dependency
