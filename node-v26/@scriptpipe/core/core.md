# @scriptpipe/core

> 标签: dag, data-pipeline, etl, orchestration, pipeline, pipelines, scripts, typescript, workflow

## 简介

TypeScript-native pipeline organization for Node.js: turn loose scripts into layered pipelines with named assets, derived execution order, and simple steps.
