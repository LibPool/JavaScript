# citeproof-mcp

> 标签: citations, claude, mcp, model-context-protocol, prisma, systematic-review

## 简介

Audit layer for AI literature reviews: run the CiteProof MCP server over stdio with npx. Records PRISMA counts, screening decisions, evidence checks and citation checks supplied by your research agent.
