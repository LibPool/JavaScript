# @walletconnect/pay-react

> 标签: JavaScript

## 简介

Thin React binding over @walletconnect/pay-state — the headless WC Pay runtime. Exposes usePaymentSession (useSyncExternalStore-based) returning the public PaymentSnapshot view-model and domain actions, with zero XState leak.
