# react-native-delivery-engine

> 标签: android, avaudioplayer, corelocation, delivery, fcm, foreground-service, fused-location, ios, location-tracking, notification-channel, order-buzzer, react-native, rider

## 简介

Reusable delivery-partner engine for React Native: looping new-order buzzer (sound + vibration), foreground location tracking, and notification-channel + FCM order-push plumbing. Android (Kotlin) and iOS (Swift).
