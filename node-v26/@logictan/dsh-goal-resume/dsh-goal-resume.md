# @logictan/dsh-goal-resume

> 标签: deepseek-harness, dsh, goal, plugin, restart, session

## 简介

DSH plugin that re-arms the active goals a restart left stopped, one pass a short delay after boot. DSH 重启后自动恢复未完成目标子插件。
