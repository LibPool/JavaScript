# @bossjob-ds/ai

> 标签: JavaScript

## 简介

Bossjob Design System — AI-chat primitives (Bubble, Conversations, Prompts, ThoughtChain, Attachments, Welcome). Bossjob's DS-tokenized take on the Ant Design X pattern family (ADR-0022). Composes @bossjob-ds/react + tokens; never raw values.
