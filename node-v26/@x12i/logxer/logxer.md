# @x12i/logxer

> 标签: console, correlation, debug-capture, file, json, logging, logxer, node, opentelemetry, pii, privacy, sanitization, scope-record, scoping, security, shadow-logging, story-output, test-logging, tracing, trails, typescript, yaml

## 简介

Standardized logging gateway for Node.js with PII sanitization, correlation trails, Shadow Logging for test/debug capture, scoping, story output, and multi-format output (JSON/YAML/text)
