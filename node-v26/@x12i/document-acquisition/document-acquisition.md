# @x12i/document-acquisition

> 标签: acquisition, canonical-document, csv, docx, email, epub, html, json, markdown, ocr, odt, pdf, pptx, rtf, x12i, xlsx

## 简介

Turns office, web, text, email, EPUB, image, RTF, and structured JSON or XML bytes into the CanonicalDocument accepted by @x12i/document-normalizer. In-process and offline.
