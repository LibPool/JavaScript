# @hashborn/agent

> 标签: ai-agent, attestation, hash-based-signature, hashborn, merkle, post-quantum, pqc-rh, robinhood-chain, wots

## 简介

Give a server-side AI agent a Hashborn (protocol pqc-rh) post-quantum identity: derive it from a wallet key, register an agent and sign and anchor its actions on Robinhood Chain, never reusing a one-time key.
