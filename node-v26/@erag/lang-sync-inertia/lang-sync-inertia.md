# @erag/lang-sync-inertia

> 标签: frontend-translations, i18n, inertia, inertiajs, internationalization, language-sync, laravel, laravel-inertia, laravel-localization, laravel-translations, localization, pluralization, react, reactive-translations, svelte, translation-helper, translations, typescript, vue, vue3

## 简介

Laravel Inertia.js translation and localization package for Vue 3, React, and Svelte with reactive language switching, translation helpers, nested keys, placeholders, pluralization, and TypeScript support
