# @kbmjj123/json-editor

> 标签: client-side, codemirror, custom-element, json, json-editor, json-tree, json-viewer, vue, vue3, web-component

## 简介

A JSON editor and read-only tree view for the web — CodeMirror 6 editing, live validation with error line locating, and a searchable tree. Vue 3 component, custom element, or plain script tag.
