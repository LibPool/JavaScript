# @ramplex/clujo

> 标签: async-jobs, cluster-safe, concurrent-tasks, cron, dependency-management, distributed-locking, javascript, job-automation, node, redis, single-execution, sync-jobs, typescript

## 简介

Schedule functions on a cron-like schedule. Built in distributed locking to prevent overlapping executions in a clustered environment.
