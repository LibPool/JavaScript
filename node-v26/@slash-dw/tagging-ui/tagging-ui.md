# @slash-dw/tagging-ui

> 标签: JavaScript

## 简介

React UI for slash-dw/tagging-kit — TagAutocomplete + hooks (debounce, Fuse.js, LRU cache, AbortController). Multi-tenant, multi-locale, headless.
