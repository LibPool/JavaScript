> 标签: agent, ai, exa-alternative, firecrawl-alternative, free, jina-alternative, local, mcp, mcp-server, model-context-protocol, no-api-key, puppeteer, readability, searxng, self-hosted, tavily-alternative, web-reader, web-scraper, web-search, web-search-mcp

## 简介

Hugin MCP — 100% local, 100% free MCP server for web search and web reading. No API keys needed. Self-hosted alternative to Tavily, Exa, Jina Reader, Firecrawl, and Brave Search API.
