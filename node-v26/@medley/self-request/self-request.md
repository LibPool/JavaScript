# @medley/self-request

> 标签: medley, plugin, request, self-request, test, testing

## 简介

Medley plugin that augments an app to be able to make HTTP requests to itself for testing purposes

- 官网：https://github.com/medleyjs/self-request
- 源码仓库：git+https://github.com/medleyjs/self-request.git
