# @magclaw/team-sharing

> 标签: JavaScript

## 简介

One-command MagClaw Team Sharing setup for Codex and Claude Code: npx @magclaw/team-sharing@latest setup --server-url https://magclaw.multiego.me --channel <channel-path>.
