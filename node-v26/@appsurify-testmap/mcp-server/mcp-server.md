# @appsurify-testmap/mcp-server

> 标签: appsurify, mcp, mcp-server, model-context-protocol, qa, test-coverage, testing, testmap

## 简介

MCP server for Appsurify TestMap — exposes test-coverage analytics (context resolution, ranked coverage gaps, element context, zero-coverage pages) to AI agents.
