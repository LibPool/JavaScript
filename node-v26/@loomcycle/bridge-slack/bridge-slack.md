# @loomcycle/bridge-slack

> 标签: agent, ai, bot, bridge, loomcycle, slack

## 简介

Slack bot for loomcycle interactive agents (RFC EQ): each Slack user chats with a loomcycle agent as their own loomcycle user, with streamed DM replies, steering, question and review cards in Block Kit, and a workspace allow-list.
