# n8n-nodes-imagestep

> 标签: automation, convert, image, image-generation, imagestep, n8n, n8n-community-node-package, remove-background, resize, upscale

## 简介

ImageStep for n8n — the image step for your automations: generate, edit, remove background, upscale, resize, convert and read metadata as one node, plus a webhook trigger for finished jobs.
