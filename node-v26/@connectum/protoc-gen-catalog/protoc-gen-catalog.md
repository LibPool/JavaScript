# @connectum/protoc-gen-catalog

> 标签: buf, codegen, connectrpc, connectum, grpc, protobuf, protoc-plugin, service-catalog

## 简介

Buf/protoc plugin that generates a Connectum service catalog (ctx.call / ctx.stream typing) from proto files.
