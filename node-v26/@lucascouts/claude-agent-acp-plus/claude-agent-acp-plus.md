# @lucascouts/claude-agent-acp-plus

> 标签: acp, agent, anthropic, claude, code, sdk, typescript

## 简介

ACP adapter for the Claude Agent SDK with VS Code-parity UX for Zed and other ACP clients — checkbox multi-select questions, refusal consent dialog, dynamic agent name. Fork of claude-agent-acp.
