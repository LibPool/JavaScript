# @luckymachines/contracts

> 标签: chainlink, ethereum, gambling, solidity, vrf

## 简介

Lucky Machines contracts for betting dapps. Includes multi-draw and automatic payout on win. Only allows bets on machines that have been sufficiently funded.  Utilizes Chainlink VRF for provable fairness.
