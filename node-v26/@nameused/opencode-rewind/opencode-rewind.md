# @nameused/opencode-rewind

> 标签: checkpoint, claude-code, opencode, opencode-plugin, rewind

## 简介

Claude Code style /rewind for opencode — git-free, prompt-based snapshots. Each user prompt is snapshotted to .opencode/rewind/snapshots and can be restored via /rewind.
