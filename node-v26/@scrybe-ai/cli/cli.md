# @scrybe-ai/cli

> 标签: cli, editor, markdown, mcp, mermaid, scrybe

## 简介

Scrybe CLI — the `scrybe` binary (headless render / lint / mermaid / edit + MCP-native live-tab driver). Delivers the prebuilt Rust binary for your platform, no Rust toolchain or pip required.
