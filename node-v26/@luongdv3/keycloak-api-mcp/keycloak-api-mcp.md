# @luongdv3/keycloak-api-mcp

> 标签: bearer-token, keycloak, mcp, model-context-protocol, oauth2, rest-api

## 简介

Generic MCP server that logs in to Keycloak (password grant), manages the access-token lifecycle, and exposes a general call_api tool that auto-injects the Bearer token.
