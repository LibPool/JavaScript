# @unclecat/mcp-multi-db

> 标签: database, mariadb, mcp, model-context-protocol, mysql, parameterized-queries, postgresql, sql, sqlserver

## 简介

MCP server for MySQL/MariaDB, PostgreSQL, and SQL Server with parameterized queries, per-alias safety modes, and bilingual docs.
