# @taojimu/meta-view

> 标签: JavaScript

## 简介

适用于使用[淘积木 meta](https://mos.m.taobao.com/taojimu/docs#/meta)来快速生成配置应用所需要的 [JSON Schema](http://json-schema.org/) 以及 form 表单。
