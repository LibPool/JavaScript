# @proactive-agent/adapters

> 标签: JavaScript

## 简介

ProactiveAgent host adapters: unified harness adapter layer for proactive memory & suggestions across agent hosts (Claude Code, Kimi Code, Cursor, Cline, Codex). Zero-runtime-dependency.
