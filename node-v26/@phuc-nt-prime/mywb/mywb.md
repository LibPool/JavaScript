> 标签: agent, architecture-diagram, cli, diagram, mcp, mcp-server, tldraw, whiteboard

## 简介

Headless CLI and MCP server for .mywb whiteboard documents: read and apply record-level changes, scaffold boards from a model, and expose a running My Whiteboard app to coding agents
