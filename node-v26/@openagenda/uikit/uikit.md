# @openagenda/uikit

> 标签: JavaScript

## 简介

OpenAgenda's shared UI kit, built on [Chakra UI v3](https://chakra-ui.com/). Provides the theme (tokens, semantic tokens, recipes), components, and snippets used across OpenAgenda apps.
