# @kiranharidas/chat-kit

> 标签: agent, ai, chat-ui, chatbot, react, sse, websocket

## 简介

Config-driven React chatbot UI component library: pluggable transports (SSE/WebSocket/HTTP), multi-session, themeable via design tokens.
