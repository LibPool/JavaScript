# @pareeshy/browser-storage

> 标签: browser, indexeddb, localstorage, sessionstorage, storage, typed-storage

## 简介

Unified browser storage abstraction for localStorage, sessionStorage, and IndexedDB with typed schemas, custom serialization, and clean async API.
