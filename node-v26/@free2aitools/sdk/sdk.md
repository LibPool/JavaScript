# @free2aitools/sdk

> 标签: ai-discovery, fni, free2aitools, model-evidence, rest-sdk

## 简介

Free, public TypeScript SDK for the Free2AITools AI discovery / evidence / identity REST API. Retrieves candidates, evidence, and FNI rankings; the caller makes the final decision.
