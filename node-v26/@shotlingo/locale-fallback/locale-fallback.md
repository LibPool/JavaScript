# @shotlingo/locale-fallback

> 标签: app-store, app-store-connect, app-store-optimization, aso, bcp47, google-play, i18n, l10n, locale, locale-fallback, localization, screenshot

## 简介

Resolve any BCP-47 locale tag to the nearest one App Store Connect or Google Play Console actually supports, with the full fallback chain. Zero dependencies, no network calls.
