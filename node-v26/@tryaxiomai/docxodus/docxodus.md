# @tryaxiomai/docxodus

> 标签: agent, comparison, converter, diff, document, document-comparison, docx, docx-editor, docx-to-html, docx-viewer, html, llm, markdown, ooxml, openxml, react, redline, track-changes, tracked-changes, wasm, webassembly, word

## 简介

Render, edit, diff and project Word .docx files in the browser — DOCX to HTML, a block editor, Word-grade redlines with tracked changes, and anchor-addressed markdown for LLM agents. WebAssembly, no server.
