# @skunkworksai/ui-kit

> 标签: JavaScript

## 简介

A React component library built on [shadcn/ui](https://ui.shadcn.com), Tailwind CSS v4, and Radix UI. Exports brand-wrapped `App*` primitives and pre-composed blocks for building product UIs.
