# @muzi3/type-easier

> 标签: alias, autocomplete, chinese, exit, extension, pi, pi-package, quit, slash

## 简介

Pi extension bundle: /exit command (alias for /quit) plus Chinese「、」slash-command completion — type「、」to trigger slash autocomplete just like「/」.
