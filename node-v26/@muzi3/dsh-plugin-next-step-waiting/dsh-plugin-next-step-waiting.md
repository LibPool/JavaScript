# @muzi3/dsh-plugin-next-step-waiting

> 标签: cordis, deepseek-harness, detector, dsh, dsh-plugin, external-action, wait

## 简介

DSH plugin: wait_for_condition tool — pause and wait for an external action to complete, or ask the user whether to continue. Pluggable detectors (shell command polling / sub-agent judgement) with round-based human check-ins.
