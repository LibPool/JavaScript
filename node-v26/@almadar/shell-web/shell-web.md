# @almadar/shell-web

> 标签: almadar, components, hooks, react, shell, ui

## 简介

Almadar TS shell web renderer pack: the browser host ports of the kernel (transports, stores, client kernel, http/oauth/os ports) and the React render substrate (components, hooks, providers, preview runtime, themes, Tailwind preset) the generated web app
