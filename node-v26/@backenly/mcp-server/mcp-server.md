# @backenly/mcp-server

> 标签: agentic, ai, backend, backenly, claude, claude-code, cline, cursor, mcp, model-context-protocol

## 简介

Backenly MCP server — gives Claude Code, Cursor, Codex, Cline, and Claude Desktop direct access to your Backenly backend (tables, APIs, brain chat, runtime data).
