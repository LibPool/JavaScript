# @ingram-tech/mcp-client

> 标签: agents, client, mcp, model-context-protocol, streamable-http, tools

## 简介

A stateless MCP client for the tool edge: tools/list and tools/call over Streamable HTTP, with tasks, input requests and x-mcp-header. No sessions.
