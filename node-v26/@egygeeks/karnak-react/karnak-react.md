# @egygeeks/karnak-react

> 标签: JavaScript

## 简介

A thin React wrapper over the Karnak web components (`@egygeeks/karnak-web`). It renders `<karnak-screen>` and `<karnak-section>` and provides the client to them; the elements subscribe to their screen themselves, so React does not re-render per tree.
