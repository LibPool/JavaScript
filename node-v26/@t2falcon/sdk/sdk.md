# @t2falcon/sdk

> 标签: JavaScript

## 简介

Falcon platform SDK contract — facades/tokens/ports for host<->micro-app integration: session (auth/context), theme, language, notifier, user-details, OTP and tenant-theme gateways, the window SDK types, and the runtime theming service.
