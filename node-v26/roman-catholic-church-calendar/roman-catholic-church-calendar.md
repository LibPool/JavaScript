# roman-catholic-church-calendar

> 标签: calendarium-romanum, catholic, church-calendar-api, general-roman-calendar, liturgical-calendar, liturgical-year, liturgy, roman-catholic

## 简介

Roman Catholic liturgical calendar (General Roman Calendar, US and Czech propers) as a zero-dependency TypeScript library and drop-in replacement for the Ruby church-calendar-api v0 JSON API.
