# @aparte/secrets-cli

> 标签: aparte, api-key, ci, cli, credentials, password, pre-commit, sarif, secret-scanning, secrets, security

## 简介

Scan files or a commit for passwords, API keys and tokens with a 196 KB model: npx, pre-commit, CI (text, JSON, SARIF). No network.
