# @aparte/provider-ai-sdk

> 标签: ai, ai-sdk, anthropic, bridge, google, llm, provider, vercel-ai-sdk

## 简介

Bridge any Vercel AI SDK model into aparté — bring your own @ai-sdk/* package (Anthropic, Google, OpenAI, 25+ vendors) and aparté renders it.
