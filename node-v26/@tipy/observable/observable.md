> 标签: event-bus, event-emitter, framework-agnostic, listener, middleware, notify, observable, observer, pubsub, reactive, state, state-management, subscription, typescript, zustand

## 简介

A powerful, type-safe, framework-agnostic Observable implementation for managing state and event subscriptions. Similar to Zustand but more flexible.
