# @aivi/channel-discord

> 标签: JavaScript

## 简介

Discord channel module: gateway, DM/thread routing, sending, slash commands, and report threads. It implements the host's `ChannelModule` contract; the host owns the inbox, bindings, engine, and turn runner.
