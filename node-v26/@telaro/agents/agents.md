# @telaro/agents

> 标签: ai-agents, buzz, goat, sendai, solana, telaro, verxio

## 简介

Telaro Solana-native agent-kit adapters bundle. Wrap a SendAI / GOAT / BUZZ / Verxio runtime so every tx-emitting action auto-records on Telaro. One install, one import per kit.
