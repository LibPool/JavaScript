# @ctxr/kit

> 标签: agent-skills, agents, agents-md, ai, bundles, claude-code, cli, codex, commands, ctxr, output-styles, rules, skills

## 简介

Universal CLI for Agent Skills artifacts (Claude Code, Codex CLI, OpenCode): install, validate, update, and scaffold skills, agents, commands, rules, output-styles, and bundles under .agents/ with auto discovery mirrors at .claude/ and ~/.codex/.
