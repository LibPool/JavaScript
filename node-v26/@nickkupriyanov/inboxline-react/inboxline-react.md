# @nickkupriyanov/inboxline-react

> 标签: bell, dark-theme, headless, inbox, notification-center, notifications, react, unread-count

## 简介

Themable, accessible React notification inbox: bell popover and feed layouts, a shared unread counter, cursor pagination and optimistic read state on top of @nickkupriyanov/inboxline-core.
