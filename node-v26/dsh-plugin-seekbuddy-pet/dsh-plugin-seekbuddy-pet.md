# dsh-plugin-seekbuddy-pet

> 标签: JavaScript

## 简介

In-window Live2D pet for DeepSeek Harness: the SeekBuddy character rendered inside the DSH shell overlay, with drag physics feedback, head pats and thinking/sleep states.
