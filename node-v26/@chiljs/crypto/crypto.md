# @chiljs/crypto

> 标签: aes-gcm, e2ee, ecdh, encryption, handoff, upload

## 简介

Optional end-to-end encryption for CHIL. ECDH P-256 + HKDF + AES-GCM, recipient key held non-extractable in IndexedDB.
