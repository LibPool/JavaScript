# @hxql/dsh-persona-manager

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, persona, system-prompt

## 简介

Persona manager for DeepSeek Harness: create, edit, and freely switch multiple system personas, with a global default and per-session overrides. · DSH 人设管理插件：添加并保存人设词，自由切换多人设，支持全局默认与会话级覆盖。
