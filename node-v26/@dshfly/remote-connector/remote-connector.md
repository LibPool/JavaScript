# @dshfly/remote-connector

> 标签: cordis, deepseek-harness, dsh, dshfly, e2ee, remote

## 简介

DSH Fly remote connector as a DeepSeek Harness (DSH) cordis plugin — outbound relay tunnel + E2EE endpoint + loopback proxy into dsh web
