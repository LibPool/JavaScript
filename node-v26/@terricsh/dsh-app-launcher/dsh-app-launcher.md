# @terricsh/dsh-app-launcher

> 标签: cordis, deepseek, dsh, launcher, workspace

## 简介

Workspace launcher for DeepSeek Harness Web GUI: open the current workspace as a folder, a terminal, or with a tool (VS Code / opencode / custom), with Windows system icons.
