# @iss-ai/ppt-board

> 标签: canvas, database, dexie, editor, engine, presentation, slides, vue

## 简介

A fully-featured presentation and editing host application built on vue-canvas-core, integrating NaiveUI, a plugin system, and a unified local Dexie database.
