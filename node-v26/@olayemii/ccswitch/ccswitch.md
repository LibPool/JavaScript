# @olayemii/ccswitch

> 标签: account-switcher, anthropic, bedrock, claude, claude-code, cli, credentials, profiles

## 简介

Switch between Claude Code accounts and profiles (login, API key, Bedrock, custom Anthropic-compatible endpoints) globally or per-shell, with expiry tracking and liveness probes.
