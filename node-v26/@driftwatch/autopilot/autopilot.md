# @driftwatch/autopilot

> 标签: ai-agent, autopilot, drift-detection, slack, telegram, webhook

## 简介

Slack, Telegram, and generic-webhook notifiers plus inbound-webhook signature verification for DriftWatch Autopilot. Companion to @driftwatch/sdk — bring these in only if you use those channels.
