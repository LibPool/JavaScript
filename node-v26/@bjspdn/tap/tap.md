# @bjspdn/tap

> 标签: JavaScript

## 简介

A CLI that orchestrates Claude Code agents to execute software engineering work items through TDD. Describe what to build; tap creates tickets and drives agents through RED → GREEN → REFACTOR until each task is completed.
