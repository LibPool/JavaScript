# @cjgammon/gamekit

> 标签: 2d, flixel, game-engine, multiplayer, typescript, webgpu, zero-dependency

## 简介

A 2D multiplayer game engine for the web, written in TypeScript from scratch. Zero runtime dependencies, Flixel-inspired, WebGPU renderer.
