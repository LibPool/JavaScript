# @wallets-e2e/core

> 标签: bitcoin, blockchain, browser-extension, e2e, ethereum, evm, leather, playwright, stacks, wallet, web3

## 简介

Drive real browser-extension wallets in Playwright end-to-end tests: launches the extension-loaded context, resolves the extension ID, defines the WalletDriver port, and confirms transactions on-chain. The base for @wallets-e2e/metamask and @wallets-e2e/l
