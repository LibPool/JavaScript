# @sqlrooms/duckdb-config

> 标签: JavaScript

## 简介

A central configuration and type definitions package that maintains base DuckDB configuration schemas and Zod schema definitions for SQLRooms. It provides TypeScript types and interfaces along with essential constants and utilities used for managing DuckD
