# @ninesols/aca-cli

> 标签: agent-skills, ai-agents, alibaba-cloud, aliyun, auto-deploy, cli, cloud-assistant, deployment, ecs, iis, powershell, ssl-certificates, windows-server

## 简介

通过阿里云云助手在 Windows ECS 上自动发布 IIS 站点和 Windows 服务，也能回退、执行 PowerShell、检查和更换 SSL 证书，附带 Agent Skill 供 Claude Code、Codex 等 AI Agent 调用
