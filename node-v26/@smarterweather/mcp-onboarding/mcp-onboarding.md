# @smarterweather/mcp-onboarding

> 标签: agent, developer-tools, mcp, model-context-protocol, onboarding, smarterweather

## 简介

stdio bridge to the Smarter Weather developer onboarding MCP server (sw-onboarding). Thin wrapper around mcp-remote with SmarterWeather URL defaults, local start_trial / CLI trial+login (.env sink), proxy sinks for create/rotate, and an opt-in OAuth mode
