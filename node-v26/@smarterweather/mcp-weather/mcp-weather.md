# @smarterweather/mcp-weather

> 标签: forecast, mcp, model-context-protocol, smarterweather, weather, weather-api

## 简介

stdio bridge to the Smarter Weather hosted MCP server (sw-mcp). Thin wrapper around mcp-remote with SmarterWeather URL defaults; resolves the API key from env/.env and passes Authorization via SMARTERWEATHER_AUTH_HEADER (never on argv).
