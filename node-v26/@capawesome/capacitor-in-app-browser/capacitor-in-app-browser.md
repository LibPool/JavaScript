# @capawesome/capacitor-in-app-browser

> 标签: browser, capacitor, capacitor-plugin, custom tabs, in-app browser, inappbrowser, native, open url, plugin, safari view controller, webview

## 简介

Capacitor plugin to open URLs in the external browser, the system browser or an embedded web view on Android, iOS, and Web.
