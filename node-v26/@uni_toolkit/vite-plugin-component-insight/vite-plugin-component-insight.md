# @uni_toolkit/vite-plugin-component-insight

> 标签: analysis, component, miniprogram, plugin, uni-app, vite, vue3

## 简介

一个用于 uni-app Vue3 项目的 Vite 插件，用于分析组件被哪些页面使用、使用了多少次，并结合主包与分包关系在控制台输出建议。
