# @uni_toolkit/vite-plugin-sourcemap

> 标签: alipay, miniprogram, plugin, source-map, sourcemap, uni-app, vite, vue3, weixin

## 简介

一个用于 uni-app Vue3 小程序项目的 sourcemap 开关插件，可按 `NODE_ENV` 或在所有环境下开启 `build.sourcemap`。
