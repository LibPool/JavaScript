# @r1ck404/fast-brotli-wasm

> 标签: brotli, brotli-wasm, compression, decompression, drop-in, wasm

## 简介

Faster drop-in replacement for brotli-wasm 3.0.1: the same Rust brotli crates with a rewritten encoder hot path and a new decoder, byte-identical output (q11 3-4.5x faster)
