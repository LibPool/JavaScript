# @calebcall/camera-ui-notify

> 标签: camera-ui-plugin, gotify, local, notifications, notifier, ntfy, webhook

## 简介

A fully-local, multi-backend camera.ui notifier plugin: delivers notifications to ntfy, Gotify, Pushover, Telegram, Discord, Grafana, or a generic webhook, entirely on your own hardware with no cloud dependency.
