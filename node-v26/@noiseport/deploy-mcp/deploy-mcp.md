# @noiseport/deploy-mcp

> 标签: JavaScript

## 简介

Local **stdio Model Context Protocol** server that installs and brings up a Noiseport instance from a chat client, then hands off to [`@noiseport/mcp`](../mcp) (the Ops server). Separate from the Ops server on purpose: this one can **run Docker on a host*

## 官网

- npm 页面：https://www.npmjs.com/package/@noiseport/deploy-mcp
