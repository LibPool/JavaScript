# @geotager/core

> 标签: avif, coordinates, exif, exif-parser, exif-writer, geolocation, geotag, geotagging, gps, heic, image-metadata, jpeg, location, lossless, metadata, mp4, png, privacy, quicktime, remove-exif, strip-exif, tiff, webp

## 简介

Read, write and remove EXIF GPS geotags: photo and video location metadata for JPEG, HEIC, AVIF, PNG, WebP, TIFF and MP4. Lossless, Node and browser.
