# @ariada-org/mcp-server

> 标签: a11y, accessibility, ai-tools, claude, eaa, eupl, european-accessibility-act, mcp, model-context-protocol, wcag

## 简介

Model Context Protocol (MCP) server exposing the ariada OSS accessibility scanner pipeline as discoverable tools for AI coding assistants. Open source under EUPL-1.2.
