# @ariada-org/vpat-html-renderer

> 标签: JavaScript

## 简介

Renders VPAT 2.5 INT JSON reports into self-contained, WCAG 2.2 AA-conformant, print-friendly HTML for procurement, regulatory audit, and vendor-website publication.
