# lunato

> 标签: ai, animation, chat, counter, emoji, flip, icon, llm, morph, number, react, reduced-motion, solid, streaming, svelte, text, vue, waapi, zero-dependency

## 简介

The motion layer for AI interfaces: streamed answers, agent status, live captions and rewrites, where only the words that changed move. One function, zero dependencies.
