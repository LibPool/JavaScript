# @preepo/allykit

> 标签: a11y, accessibility, allykit, dyslexia, high-contrast, screen-reader, typescript, wcag, wcag2.2, widget, zero-dependency

## 简介

AllyKit — a lightweight, zero-dependency accessibility toolkit for any webpage. Text size, contrast modes, dyslexia font, screen reader, ADHD focus mode, and more.
