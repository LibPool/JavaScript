# @hangxingliu/repl

> 标签: JavaScript

## 简介

A command-oriented REPL built on `node:readline`, compatible with Node.js 22+ and Bun 1.4+. Commands are tokenized and dispatched to registered handlers, never evaluated as JavaScript.
