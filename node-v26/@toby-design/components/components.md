# @toby-design/components

> 标签: JavaScript

## 简介

Token-driven React 컴포넌트 라이브러리입니다. 모든 스타일이 Design Token(CSS Variables)을 참조하며, `data-attribute` 패턴으로 variant/size를 관리합니다.
