# dsh-janitor

> 标签: ai-agents, cleanup, deepseek-harness, deterministic, dsh-plugin

## 简介

Deterministic artifact lifecycle for DeepSeek Harness: scans plan docs and scratch scripts left behind by agent sessions, returns a reviewable cleanup plan — the janitor is never an agent
