# @scopeveil/sdk

> 标签: anthropic, cost, latency, llm, observability, openai, privacy

## 简介

Privacy-first cost & latency observability for LLM apps. The SDK ships only metadata: prompt content never leaves your process. Cost is computed server-side from raw tokens, clients never report dollar amounts.
