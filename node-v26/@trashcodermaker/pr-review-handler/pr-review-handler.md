# @trashcodermaker/pr-review-handler

> 标签: agent-skill, agentskills, code-review, github, pr-review, skill

## 简介

Systematically process GitHub PR review comments: triage for validity, fix code, and post replies. Agent skill usable from any agent harness (Pi, Claude Code, Cursor, Gemini CLI, OpenCode, etc.).
