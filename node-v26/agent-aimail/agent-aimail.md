# agent-aimail

> 标签: agent-mail, aimail, deepseek-harness, dsh, email, openclaw, pi, plugin

## 简介

AIMail agent mail SDK — single package for OpenClaw / dsh (DeepSeek Harness) / Pi hosts. Host detection at startup, per-host activation. 15 mail tools, inbound delivery (HMAC), board/skill resources, agent-level addressing.
