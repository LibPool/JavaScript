# prismcrawl

> 标签: amazon, api-client, bing, google, maps, prismcrawl, reviews, sdk, search, serp, serp-api, web-scraping

## 简介

Official TypeScript and JavaScript client for the PrismCrawl API: search results, places, app stores, products, and reviews as structured JSON.
