# dsh-weixin-pro

> 标签: bundle, clawbot, deepseek-harness, file, ilink, image, media, plugin, streaming, video, wechat, weixin

## 简介

微信 ClawBot (iLink) 通道插件：把微信消息接入 DeepSeek Harness 会话，按用户隔离、原生注入与回发，支持图片/文件/视频收发与 1GB 级流式传输。
