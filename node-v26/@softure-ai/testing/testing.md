# @softure-ai/testing

> 标签: JavaScript

## 简介

SOFTURE AI test tools: a Vitest preset and setup file that pins the test time zone and shifts the test clock to TEST_TODAY, Playwright helpers and a per-test client address for black-box tests of an app, a scripted fake fetch, and source guards for archit
