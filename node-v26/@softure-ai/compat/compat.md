# @softure-ai/compat

> 标签: backward-compatibility, ci, cli, oasdiff, openapi, release

## 简介

Backward-compatibility check between two git refs of a server release: OpenAPI, SQL migrations, seed scripts, persisted enums, configuration and message contracts
