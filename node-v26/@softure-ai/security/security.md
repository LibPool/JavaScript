# @softure-ai/security

> 标签: JavaScript

## 简介

SOFTURE AI security module: fixed-window rate limits in Postgres with buckets from configuration, client-IP resolvers, size-capped request body readers, HMAC-signed request helpers and SSRF-guarded outbound requests and page fetches.
