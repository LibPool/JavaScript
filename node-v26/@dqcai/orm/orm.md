# @dqcai/orm

> 标签: adapter, database, mariadb, mongodb, multi-database, mysql, orm, postgresql, query-builder, sqlite, sqlserver, typescript

## 简介

A powerful, multi-database TypeScript ORM library supporting PostgreSQL, MySQL, MariaDB, SQLite, SQL Server, and MongoDB.
