# @openacid/adapter-0g-storage

> 标签: 0g, 0g-storage, agent, ai, galileo, openacid, receipts, storage-adapter

## 简介

Write-through StorageAdapter for @openacid/acid backed by 0G Storage on Galileo testnet — receipts persist as content-addressed blobs.
