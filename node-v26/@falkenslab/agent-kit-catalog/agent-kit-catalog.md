# @falkenslab/agent-kit-catalog

> 标签: agent-kit, catalog, claude-code, marketplace, plugins

## 简介

A Claude Code marketplace's extensions as one catalog.json, for a page or a client to show them: name, version, topics, install commands and images. No dependencies.
