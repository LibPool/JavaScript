# @k-table/sheet-report

> 标签: JavaScript

## 简介

kt 报表富包：.ktl 报表文件渲染（DOM 表格）、分页预览（页眉页脚每页重复）、浏览器原生打印、矢量 PDF 客户端（依赖 @k-table/sheet-core + @k-table/ktl，React 为 peer）
