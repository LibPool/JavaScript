# @trendcraft/chart

> 标签: candlestick, canvas, charting-library, financial-charts, headless, ohlc, react-chart, realtime, sparkline, stock-chart, technical-analysis, trendcraft, typescript, vue-chart

## 简介

Zero-dependency Canvas charting for TypeScript — candlestick & financial charts that work on plain OHLC data, with React/Vue wrappers and a headless API. Auto-places TrendCraft indicators when paired.
