# @mariodefe/sap-datasphere-mcp

> 标签: ai, analytics, claude, cloud, data-privacy, data-warehouse, datasphere, etl, gdpr, mcp, model-context-protocol, oauth, odata, pii-masking, sap

## 简介

MCP server for SAP Datasphere — 39 tools (49 with diagnostics), Smart Query, Streamable HTTP, and built-in config-driven PII/sensitive-field masking (fail-closed, audit-logged, GDPR-ready).
