# @hetznercloud/ngx-prepare-test-environment

> 标签: JavaScript

## 简介

Provides the helper function `prepareTestEnvironment` to speed up your tests. It is inspired by the blogpost [Angular Unit Testing performance](https://blog.angularindepth.com/angular-unit-testing-performance-34363b7345ba).
