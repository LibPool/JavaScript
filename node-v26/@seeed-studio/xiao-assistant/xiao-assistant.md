## 简介

MCP server + CLI for Seeed Studio XIAO boards: verified pinouts for 17 boards (ESP32-C5, nRF54LM20A...), 64 compile-checked examples, fuzzy + Chinese search, flashing troubleshooting. Works with Claude, Cursor, or standalone.
