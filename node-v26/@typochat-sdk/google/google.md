# @typochat-sdk/google

> 标签: JavaScript

## 简介

Proxy-aware [Google Generative AI](https://ai.google.dev/) (Gemini) provider for the [Vercel AI SDK](https://sdk.vercel.ai). All requests are routed through your proxy — no provider API keys needed on the client.
