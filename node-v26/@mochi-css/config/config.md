# @mochi-css/config

> 标签: JavaScript

## 简介

This package is part of the [Mochi-CSS project](https://github.com/Niikelion/mochi-css). It provides the shared configuration layer - types, config file loading, and config resolution - used by all Mochi-CSS integrations (Vite, PostCSS, Next.js).
