# @one-crop-image/angular

> 标签: angular, aspect-ratio, canvas, crop, cropper, drag-and-drop, filters, image, image-crop, image-cropper, ngx, rotate, standalone-component, zoom

## 简介

A powerful Angular standalone image cropping component with rotation, mirroring, zoom, filters, aspect-ratio presets, undo/redo history, drag-and-drop upload, and accessible controls. Exports cropped images as PNG, JPEG, or WebP with size constraints.
