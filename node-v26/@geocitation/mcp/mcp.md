> 标签: aeo, claude-code, geo, geocitation, mcp, model-context-protocol, seo

## 简介

MCP server exposing GEOCitation AEO/GEO semantic audit tools (Market Intelligence, Gap Analysis, audit history) to Claude Code, Claude Desktop, and any MCP-compatible client.
