# @brambledd/bramble-memory

> 标签: agent, deepseek-harness, dsh, memory, sqlite

## 简介

Persistent memory plugin suite for DeepSeek Harness: cross-session evidence store, decision cues, lesson distillation, temporal events, targeted unlearning. Zero config, zero native dependencies.
