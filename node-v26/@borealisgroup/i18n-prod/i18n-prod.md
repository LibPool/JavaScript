# @borealisgroup/i18n-prod

> 标签: JavaScript

## 简介

This package is related to [i18n-dev](https://github.com/borealisgroup/borealis/tree/master/packages/i18n-dev), it does the same except that it will use local localization files and it is not auto uploading missing keys. It also has a smaller bundle size
