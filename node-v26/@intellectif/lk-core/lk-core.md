# @intellectif/lk-core

> 标签: assessment, edtech, elearning, exam, grading, h5p, lms, quiz, rubric, scoring, standard-schema, tin-can, typescript, xapi

## 简介

Framework-free assessment core: activity validation, pure scoring, rubric & deferred grading, weighted assessment composition, exam attempt plans, and xAPI 1.0.3. Custom activity types take any Standard Schema.
