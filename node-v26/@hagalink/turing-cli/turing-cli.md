# @hagalink/turing-cli

> 标签: JavaScript

## 简介

CLI for the Turing backend (okupaciones / squatting intelligence) — incidents, reports, alerts, dashboard, forecasts, support tickets, tenant rules, users, assistant and API tokens over @hagalink/turing-sdk. Runnable via npx.
