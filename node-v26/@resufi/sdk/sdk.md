# @resufi/sdk

> 标签: arbitrum, base, defi, ethereum, resu, tranches

## 简介

Zero-dependency TypeScript SDK for the Resu protocol — read pool state and build transactions for tranched vaults, baskets, index baskets, and USDC zaps.
