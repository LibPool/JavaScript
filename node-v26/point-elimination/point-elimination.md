# point-elimination

> 标签: adaptive, blue-noise, point, point-cloud, points, poisson-disc, poisson-disk, progressive, sample-elimination, sampling, typed-array

## 简介

Eliminate 1D, 2D or 3D points: weighted sample elimination to an exact count with progressive ordering, and greedy elimination by minimum distance, both with adaptive spacing.
