# @hope_phenom/dsh-plugin-notify

> 标签: cordis, deepseek-harness, dsh, notification, toast, tray

## 简介

Desktop notifications when a DeepSeek Harness turn ends: bundled Python/PowerShell notifier, custom command fallback, and its own Settings page.
