# @pascal-app/geometry-script

> 标签: JavaScript

## 简介

Compiles AI-authored three.js and Blender (bpy) geometry scripts into GLB artifacts with a Pascal manifest. Runs in a browser worker, Bun or Node — no DOM, no React.
