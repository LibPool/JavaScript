# @animastor/web-generator-sse

> 标签: animastor, domain-logic, frontend, generator, ports-and-adapters, preact, progress, reconnect, sse, stream, web-ui

## 简介

SSE stream orchestration for Animastor generation progress. Manages the reconnect loop, epoch-guarded event routing, and error handling. The host owns the AbortController and SSE connection; this package consumes the stream and routes events through @anim
