# @animastor/web-generator-config

> 标签: animastor, config, domain-logic, frontend, generator, layer-config, ports-and-adapters, preact, web-ui

## 简介

Layer-config load/persist domain logic for Animastor web frontend. Pure functions that fetch and save book layer configuration (audio/image/video/vbook toggles, analysis mode/parallelism) through injected identity and transport ports. No host stores, sign
