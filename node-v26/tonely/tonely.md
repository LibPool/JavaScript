# tonely

> 标签: audio-feedback, micro-interactions, nextjs, no-assets, notification-sound, react, sonner, sound-effects, ssr-safe, svelte, toast, typescript, ui-sounds, vue, web-audio, web-audio-api

## 简介

UI sound effects for web apps (success, error, click, toggle) synthesized with the Web Audio API. No audio files, ~2.5 KB, SSR-safe. React, Next.js, Vue, Svelte.
