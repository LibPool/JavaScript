# @3f-consulting/spec-controller-core

> 标签: bdd, double-entry, evidence, gherkin, reconciliation, spec-controller

## 简介

The pure, embeddable reconciliation core behind spec-controller — Gherkin/@SCN parse, the evidence model, reconcile primitives, and renderers. No CLI, no I/O.
