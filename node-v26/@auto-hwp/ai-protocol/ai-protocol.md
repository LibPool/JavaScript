# @auto-hwp/ai-protocol

> 标签: hwp, hwpx, intent, isomorphic, llm, prompt, protocol

## 简介

Vendor-neutral LLM protocol for auto-hwp chat-editing: EditRequest/EditResponse types, buildDocContext (R5 fence), buildSystemPrompt (INTENT-SCHEMA excerpt, allowed-intent subset), validateRequest/validateResponse (whitelist + structure). Pure, isomorphic
