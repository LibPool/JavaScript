# @supersynth/core

> 标签: additive, audio, audioworklet, browser, dsp, instruments, midi, native, orchestra, organ, piano, pipe-organ, resynthesis, rust, sampler, sound, synth, synthesis, wasm, web-audio, webassembly

## 简介

Acoustic instrument sounds for Node.js and browsers: spectral models analysed from freely licensed recordings (piano, 16 pipe organs and a harmonium, strings, winds, brass, mallets), played by a Rust engine, native or WebAssembly
