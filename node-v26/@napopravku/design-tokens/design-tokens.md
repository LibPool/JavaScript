# @napopravku/design-tokens

> 标签: JavaScript

## 简介

Данный репозиторий содержит настройки (tokens) дизайн системы. Токены вытаскиваются напрямую из Figma проекта Napopravku и могут быть использованы для построения интерфейсов и UI kit
