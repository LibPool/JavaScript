# @tanzhenxing/zx-movable

> 标签: component, drag, draggable, movable, uni-app, uniapp, vue3, 可拖拽, 惯性滑动, 拖拽, 移动, 组件, 缩放

## 简介

基于uni-app官方movable-area和movable-view封装的高性能可拖拽组件，支持多种拖拽方向、双指缩放、惯性滑动等功能
