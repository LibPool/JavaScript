# @tanzhenxing/zx-rolling-text

> 标签: 文本翻滚动效组件

## 简介

`zx-rolling-text` 文本翻滚动效组件，可以用于数字的动态翻滚效果，也支持非数字文本内容的列表翻转。它旨在提供一种视觉上吸引人的方式来展示变化的数值或文本。
