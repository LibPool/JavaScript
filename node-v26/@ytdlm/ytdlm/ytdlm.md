# @ytdlm/ytdlm

> 标签: audio-stream, discord-bot, discord-music, lavaplayer, opus, sabr, ump, webm, ytdlm

## 简介

Real-time SABR UMP WebM/Opus audio streaming & seekable downloading library, CLI, and HTTP gateway for Discord music bots (Node.js, Python, Java, Rust).
