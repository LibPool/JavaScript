# @keycloak/keycloak-admin-ui

> 标签: JavaScript

## 简介

This project is the next generation of the Keycloak Admin UI. It is written with React and [PatternFly 4](https://www.patternfly.org/v4/) and uses [Vite](https://vitejs.dev/guide/).

## 官网

- 官网：https://www.keycloak.org/
- 源码仓库：git+https://github.com/keycloak/keycloak.git
- npm 页面：https://www.npmjs.com/package/@keycloak/keycloak-admin-ui
