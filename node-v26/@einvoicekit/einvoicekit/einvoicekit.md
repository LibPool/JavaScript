# @einvoicekit/einvoicekit

> 标签: cii, e-invoice, einvoice, en16931, factur-x, facturx, peppol, ubl, validation, validator, xrechnung, zugferd

## 简介

Validate any EN 16931 e-invoice (Factur-X, ZUGFeRD, XRechnung, UBL, CII) against the full official rule set. One command, no key needed to start.
