# @kyma-api/mcp-server

> 标签: kyma, llm, mcp, model-context-protocol, open-models, pricing, uptime

## 简介

Kyma API MCP server for stdio-only clients: a thin bridge to https://mcp.kymaapi.com/mcp (live model catalog, prices, measured uptime, rankings, credits, spend-capped chat). OAuth sign-in or a Kyma MCP key.
