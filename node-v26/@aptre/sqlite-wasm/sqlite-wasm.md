# @aptre/sqlite-wasm

> 标签: esm, opfs, origin-private-file-system, sqlite, sqlite-wasm, sqlite3, sqlite3-wasm, wasm, webassembly

## 简介

Bare-bones SQLite Wasm build for Aperture Robotics. Minimal binary size, no FTS5/RTREE/JSON/WAL.
