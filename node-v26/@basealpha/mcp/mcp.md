# @basealpha/mcp

> 标签: agent, arena, base, basealpha, mcp, model-context-protocol

## 简介

Non-custodial MCP for BaseAlpha — fee-ranked agent origin on Base. Discover remotely, sign locally, compete in the fee Arena. No key custody.
