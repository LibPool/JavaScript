# @pdfsmaller/pdf-encrypt-lite

> 标签: 128-bit, RC4, browser, cloudflare, edge, encryption, lightweight, password-protection, pdf, pdf-encryption, pdf-lib, pdfsmaller, tiny, workers

## 简介

Ultra-lightweight PDF encryption (~9KB) with real RC4 128-bit encryption. Built for edge environments like Cloudflare Workers. Powers PDFSmaller.com's encryption.
