# @rkfg/dsh-better-sandbox

> 标签: allowlist, bubblewrap, deepseek-harness, dsh, dsh-plugin, sandbox

## 简介

Sandbox rules for DeepSeek Harness: extra writable roots, write-protected path names with a narrow escalation level for them, read-protected paths.
