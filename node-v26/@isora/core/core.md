# @isora/core

> 标签: 2.5d, agent-simulation, depth-sorting, deterministic, digital-twin, isometric, isometric-engine, isometric-projection, pathfinding, scene-graph, simulation, typescript

## 简介

Isometric scene engine: JSON scene model, projection, depth sorting, pathfinding and deterministic people simulation (routines, commands). No DOM, framework-agnostic.
