# kokoro-kami

> 标签: csv, excel, game-design, kokoro-os, markdown, parameters, table

## 简介

Make a table from one sentence (Markdown + CSV, uses your own Anthropic API key) — and turn the tunable numbers in your code into an Excel sheet and back, with no AI.
