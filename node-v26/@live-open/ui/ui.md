# @live-open/ui

> 标签: JavaScript

## 简介

这是一套符合直播互动开放平台设计指南的 UI 组件库，帮助开发者更容易地打造高质量的、用户体验一致的、符合设计规范的直播小插件，是基础组件的重要补充。
