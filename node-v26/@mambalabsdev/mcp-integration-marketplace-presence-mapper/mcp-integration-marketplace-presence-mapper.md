## 简介

MCP server for Integration and Marketplace Presence Mapper. Find which app marketplaces list a company: one row per company with its listings on HubSpot, Salesforce AppExchange, Slack, Zapier, Shopify, Atlassian, Chrome Web Store, Microsoft, Google Worksp
