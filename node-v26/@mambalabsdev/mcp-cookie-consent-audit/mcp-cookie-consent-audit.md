# @mambalabsdev/mcp-cookie-consent-audit

> 标签: apify, clay, consent-management, cookie-consent, eprivacy, gdpr, global-privacy-control, mcp, model-context-protocol, privacy-compliance

## 简介

MCP server for Cookie Consent Audit. Check a website's cookie consent behavior from an EU address: consent platform, reject on the first layer, cookies and trackers before consent and after reject, and Global Privacy Control response. Runs on Apify. Clay-
