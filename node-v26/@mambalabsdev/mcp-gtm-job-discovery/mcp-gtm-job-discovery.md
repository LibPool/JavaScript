# @mambalabsdev/mcp-gtm-job-discovery

> 标签: apify, clay, hiring-signals, job-postings, mcp, model-context-protocol

## 简介

MCP server for the Mamba Labs Job Posting Monitor actor on Apify. Finds companies hiring for your role keywords across job boards and returns one flat, firmographic enriched row per posting.
