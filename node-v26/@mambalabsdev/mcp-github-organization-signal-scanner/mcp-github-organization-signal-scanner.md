# @mambalabsdev/mcp-github-organization-signal-scanner

> 标签: apify, clay, developer-tools, github, mcp, model-context-protocol, open-source, technographics

## 简介

MCP server for the Mamba Labs GitHub Organization Signal Scanner actor on Apify. Resolve a company domain to its GitHub organization with repo, language and activity signals.
