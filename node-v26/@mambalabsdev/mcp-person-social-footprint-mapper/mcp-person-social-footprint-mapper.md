# @mambalabsdev/mcp-person-social-footprint-mapper

> 标签: apify, bluesky, clay, github, lead-generation, mcp, model-context-protocol, person-enrichment, sales-research, social-profiles

## 简介

MCP server for Person Social Footprint Mapper. Find a person's public GitHub, Bluesky, personal site, Substack, and X profiles from their name and company domain, with a match confidence per platform. No emails or phones. Runs on Apify. Clay-ready output.
