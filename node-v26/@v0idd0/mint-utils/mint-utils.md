# @v0idd0/mint-utils

> 标签: api-client, csv, dns, image-convert, json-schema, mcp, pdf, qr-code, rdap

## 简介

Client for the mint utilities API (data.voiddo.com): PDF, image, QR, CSV/Excel, JSON/YAML conversion, HTML to PDF, DNS/RDAP and other lookups. Zero dependencies, fetch based.

## 官网

- 官网：https://data.voiddo.com
- npm 页面：https://www.npmjs.com/package/@v0idd0/mint-utils
