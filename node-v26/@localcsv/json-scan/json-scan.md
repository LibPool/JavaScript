# @localcsv/json-scan

> 标签: csv, json, lossless, numbers, parser, precision, scanner

## 简介

A raw-preserving JSON scanner: every number stays the text its author wrote, with the span of every value, plus an audit of exactly what JSON.parse would rewrite.
