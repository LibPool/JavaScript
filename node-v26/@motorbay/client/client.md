# @motorbay/client

> 标签: api, client, denmark, dmr, motorbay, motorregister, vehicle

## 简介

TypeScript client for the Motorbay API: Danish vehicle data from Motorstyrelsen's public weekly extract. Typed from the OpenAPI document.
