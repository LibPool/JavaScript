# @magicblock-labs/magicsvm

> 标签: JavaScript

## 简介

Node.js bindings for MagicSVM. Tests can target both a **base** ledger and an **ephemeral** ledger for [Ephemeral Rollup](https://docs.magicblock.gg/) flows.
