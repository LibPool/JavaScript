# @nxmad/sequelize-typescript-migration

> 标签: makemigration, migrate, migration, sequelize, typescript

## 简介

It is based on [sequelize-typescript](https://www.npmjs.com/package/sequelize-typescript), not supports "sequelize" based model codes. and you need prior knowledge of migration of Sequelize.
