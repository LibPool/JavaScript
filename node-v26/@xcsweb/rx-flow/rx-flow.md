# @xcsweb/rx-flow

> 标签: debug, debugger, devtools, observable, reactive, rxjs, time-travel, vconsole, visualization

## 简介

RxJS 流调试控制台：import 一次，右下角悬浮球点开看 Observable 数据流的实时动画、中途值、错误与管道拓扑。RxJS 之于 Redux DevTools。
