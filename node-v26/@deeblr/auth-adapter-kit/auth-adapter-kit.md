# @deeblr/auth-adapter-kit

> 标签: JavaScript

## 简介

The Universal Adapter System for Deeblr Auth: adapter registry, factory, manager, capability detection, extended repository interfaces, and a reusable conformance test suite every adapter can be validated against.
