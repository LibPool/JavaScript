# @itcode-dev/react-components-library-starter

> 标签: JavaScript

## 简介

- **React Components Library Starter**는 React 컴포넌트 라이브러리를 개발하고 배포하기위한 스타터팩입니다. - **TypeScript**, **SCSS** 기반의 React 컴포넌트를 구현할 수 있습니다. - **Rollup.js** 빌더를 사용합니다. - **Storybook**을 통해 컴포넌트를 테스트할 수 있습니다.
