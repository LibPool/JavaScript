# @cw-game/react-ui

> 标签: cwg, react, ui

## 简介

The UI kit for [CW Game](https://cw-game.ru/), a browser-based MMO about cats. The package provides a shared theme, components, and icons to keep the game's interfaces and supporting applications visually and functionally consistent.
