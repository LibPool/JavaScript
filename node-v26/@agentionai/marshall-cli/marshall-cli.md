# @agentionai/marshall-cli

> 标签: JavaScript

## 简介

A terminal coding agent optimised for **open weights** and local inference. Point it at llama.cpp or Ollama and the whole loop runs on your own hardware: no key, no account, no cloud. Nothing is written to disk without your approval. Cloud providers work
