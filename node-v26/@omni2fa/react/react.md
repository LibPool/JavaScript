# @omni2fa/react

> 标签: 2fa, headless, hooks, mfa, react, totp, webauthn

## 简介

Omni2FA — headless React adapter. Thin hooks (useTotpEnrollment, useChallenge, useMethods) subscribed to @omni2fa/core actors. No business logic — bring your own UI, or use @omni2fa/react-mui for a styled drop-in.
