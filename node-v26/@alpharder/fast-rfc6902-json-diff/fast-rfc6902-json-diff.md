> 标签: array-diff, diff, javascript, json, json-diff, json-patch, json-pointer, lcs, move-detection, myers, rfc6901, rfc6902, typescript, zero-dependencies

## 简介

The fastest RFC 6902 JSON diff generator. Compact array diffs, optional move detection and zero runtime dependencies. Built for Node.js and Bun.
