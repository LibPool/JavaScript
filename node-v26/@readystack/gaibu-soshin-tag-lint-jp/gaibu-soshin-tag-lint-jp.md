# @readystack/gaibu-soshin-tag-lint-jp

> 标签: GA4, html, lint, タグマネージャ, プライバシー, 公表事項, 外部送信規律, 電気通信事業法

## 简介

同梱の54行の採用サイトHTML（外部送信タグ4本＋GTMコンテナ1つ）で公表もれ6件を行番号つきで名指し。電気通信事業法27条の12（2023年6月16日施行）の公表4項目を15 checksで照合します。
