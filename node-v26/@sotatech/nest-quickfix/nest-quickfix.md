# @sotatech/nest-quickfix

> 标签: exchange, financial, financial-trading, fix, fix-client, fix-engine, fix-protocol, fix-server, high-performance, market-data, messaging, nestjs, nestjs-module, nodejs, order-management, quickfix, session-management, tcp, trading, typescript

## 简介

A powerful NestJS implementation of the FIX (Financial Information eXchange) protocol. Provides high-performance, reliable messaging for financial trading applications with built-in session management, message validation, and recovery mechanisms.
