# @facturador-mcp-sii.cl/mcp

> 标签: boleta-electronica, chile, claude, dte, factura-electronica, facturacion, mcp, model-context-protocol, sii

## 简介

Servidor MCP para la API de facturación electrónica SII Chile de Facturador Pulsando. Conecta un agente de IA (Claude, etc.) a la emisión y consulta de DTE.
