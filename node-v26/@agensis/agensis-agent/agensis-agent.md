# @agensis/agensis-agent

> 标签: agensis, agent, claude-code, codex, coding-agent, cursor, daemon, workspace

## 简介

Relay host for agensis workspace agents. Prefers ACP harnesses when installed (same adapters as desktop); falls back to classic coding CLIs. Ships as a single minified bundle.
