# @apitraffic/sails

> 标签: apitraffic, apm, logging, monitoring, observability, sails, sails-hook, sailsjs, waf

## 简介

Sails hook for ApiTraffic: request capture, the ApiTraffic firewall and the APM bridge, installed with one dependency.
