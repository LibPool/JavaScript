# @keenskills/page-as-data

> 标签: accessibility, agent-skill, ai-agent, chrome-devtools-protocol, claude-code, codex, copilot, cursor, debugging, layout, llm, nextjs, react, responsive, screenshot, wcag

## 简介

Read a web page as data instead of a screenshot: what is on screen, what broke behind it, and layout defects at phone and desktop widths. For developers and AI coding agents; installs itself as a skill for Claude Code, Codex, Gemini CLI, Cursor, Windsurf,
