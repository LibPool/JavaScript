# @skillforge/agent

> 标签: agent-native, ai-agent, ai-skills, brand-design, content-writing, freelance, localhost, mcp, sidecar, skillforge

## 简介

SkillForge agent sidecar — a tiny localhost HTTP proxy that lets any AI agent activate and run professional skills (content writing, brand design, GEO optimization) in the current conversation. No MCP restart needed.
