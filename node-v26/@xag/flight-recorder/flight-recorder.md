# @xag/flight-recorder

> 标签: debugging, deterministic, nondeterminism, observability, record, regression, replay, simulation, testing

## 简介

Record an app's tool calls at their nondeterminism boundary; replay them deterministically against the real code. Tape format v1, shared with the Python implementation.
