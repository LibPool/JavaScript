# @fvc/icons

> 标签: design-system, fe-vis-core, fvc, icon-set, icons, react, react-component, svg, ui

## 简介

`@fvc/icons` provides the FE-VIS icon set as React SVG components. Icons are grouped into 14 categories and accessed through a single `Icon` namespace. Every icon is wrapped in `React.lazy` — only the category chunk that is actually rendered gets download
