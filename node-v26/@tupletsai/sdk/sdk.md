# @tupletsai/sdk

> 标签: analytics, audio, diarization, pii, sdk, speech-to-text, transcription, tuplets, typescript

## 简介

Official TypeScript SDK for the Tuplets transcription API — submit jobs, poll results, direct uploads, diarization, PII redaction, and analytics.
