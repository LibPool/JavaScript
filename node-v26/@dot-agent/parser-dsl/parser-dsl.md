# @dot-agent/parser-dsl

> 标签: agent, agents, dot-agent, dsl, fsm, llm, parser, scxml, wasm

## 简介

Unified DSL parser for dot-agent — parses .behavior and .description files using tree-sitter, providing structured ASTs for compiler, LSP, and runtime consumption
