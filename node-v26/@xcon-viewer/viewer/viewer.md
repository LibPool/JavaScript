# @xcon-viewer/viewer

> 标签: document, json, llm, markdown, renderer, sketch, tagless, ui, viewer, web-component, xcon, xcon-viewer, xml

## 简介

XCON viewer-only renderer. Renders XCON documents safely — scripts are blocked by design. Embed UI in Markdown, share from anyone, open anywhere.
