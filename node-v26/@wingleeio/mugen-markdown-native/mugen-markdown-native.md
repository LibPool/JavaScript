# @wingleeio/mugen-markdown-native

> 标签: gfm, incremental, markdown, mugen, react-native, streaming, virtualization

## 简介

Measurable markdown for mugen on React Native — the web pipeline (incremark, theme, tokenizer) with native primitives painting pretext's materialized lines.
