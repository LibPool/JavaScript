# @wingleeio/ori-core

> 标签: block-editor, crdt, editor, local-first, rich-text, virtualization, yjs

## 简介

Framework-agnostic local-first note-editor runtime: Y.Doc block model, virtualization, a custom-node schema and the Pretext-backed EditorController.
