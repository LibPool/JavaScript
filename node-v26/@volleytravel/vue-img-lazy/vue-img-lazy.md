# @volleytravel/vue-img-lazy

> 标签: JavaScript

## 简介

A [Vue.JS](https://vuejs.org) component for lazy loading images as they come into view on the page. Uses [vanilla-lazyload](https://github.com/verlok/lazyload) under the hood.
