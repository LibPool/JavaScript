# @better-captcha/preact

> 标签: captcha, friendly-captcha, hcaptcha, preact, recaptcha, turnstile

## 简介

Preact wrappers for CAPTCHA providers that share the same lifecycle, render flow, and control handle so you can swap vendors easily.
