# @zilijonas/foliark

> 标签: browser, offline, pdf, pdf-editor, pdf-redaction, pdf-render, pdf-sanitize, pdf-text-extraction, privacy, pymupdf-alternative, redact, rust, typescript, wasm, webassembly

## 简介

Rust/WebAssembly PDF SDK for the browser: extract text, render, edit, redact and sanitize PDFs offline. A PyMuPDF alternative. AGPL-3.0.
