# @kindred7/dsh-usage-stats

> 标签: deepseek-harness, dsh, plugin, statistics, tokens, usage

## 简介

Usage statistics plugin: adds a Usage Statistics section in DSH settings with cumulative/peak token counters, daily streaks, a 1-year activity heatmap, and per-model usage charts
