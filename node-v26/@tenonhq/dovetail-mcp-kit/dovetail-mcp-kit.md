# @tenonhq/dovetail-mcp-kit

> 标签: JavaScript

## 简介

Shared MCP tool-registration kit for Dovetail MCP servers — annotation presets, the actionable+retryable error contract, JSONL telemetry, and registerTool plumbing (incl. outputSchema → structuredContent).
