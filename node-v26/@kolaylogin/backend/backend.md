# @kolaylogin/backend

> 标签: auth, authentication, jwt, kolaylogin, sdk, webhooks

## 简介

Framework-agnostic server-side SDK for KolayLogin: session JWT verify, cookie helpers, webhook signature verification, and Stripe payments client.
