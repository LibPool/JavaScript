# @nonos/nox-staking-sdk

> 标签: credential, eip-712, nonos, nox, operator, safe, staking

## 简介

Local-first TypeScript SDK for NOX staking. Nox / NoxLive client, EIP-712 receipts, namespaces, tiers, and pinned mainnet deployment.
