# @perryts/redis

> 标签: aot, bun, client, cluster, driver, llvm, native, nodejs, perry, perryts, pubsub, redis, resp, resp2, resp3, tls, typescript, valkey, wire-protocol

## 简介

Pure-TypeScript Redis / Valkey wire-protocol driver. Runs on Node.js and Bun, and compiles to a native binary via Perry (LLVM). Zero native dependencies.
