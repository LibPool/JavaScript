# @perryts/mysql

> 标签: aot, bun, caching-sha2-password, database, driver, llvm, mariadb, mysql, mysql-native-password, native, nodejs, perry, perryts, tls, typescript, wire-protocol

## 简介

Pure-TypeScript MySQL/MariaDB wire-protocol driver. Runs on Node.js and Bun, and compiles to a native binary via Perry (LLVM). Zero native dependencies.
