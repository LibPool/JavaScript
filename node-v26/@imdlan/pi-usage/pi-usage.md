# @imdlan/pi-usage

> 标签: deepseek, glm, kimi, moonshot, openrouter, pi-extension, pi-package, quota, usage, zai

## 简介

Extension for Pi (a minimal agent harness) to view usage and quota for AI providers: Z.ai / GLM Coding Plan, Kimi Coding Plan, DeepSeek, and OpenRouter. Not affiliated with any provider; trademarks belong to their owners.
