# @slippay/mcp

> 标签: agent-payments, agentic-commerce, mcp, model-context-protocol, proof-carrying, soroban, spending-limit, stellar, x402

## 简介

Give your agent's checkout a limit it can prove. SlipPay MCP server: pay, re-verify the bound, check status.
