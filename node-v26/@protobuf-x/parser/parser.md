# @protobuf-x/parser

> 标签: ast, editions, lexer, parser, proto, proto2, proto3, protobuf, protocol-buffers, typescript

## 简介

Zero-dependency .proto file parser with full proto2/proto3/editions 2023 support. Produces a typed AST.
