# @zakkster/lite-auth

> 标签: auth, authentication, broadcastchannel, cross-tab, jwt, lite, reactive, session, signal, signals, token-refresh, zero-dependency

## 简介

Session-as-a-signal authentication for the lite-* ecosystem: a reactive User|null with cross-tab logout, pluggable backends, and leader-only token refresh. Zero runtime dependencies.
