# @zakkster/lite-ui-fx

> 标签: a11y, animation, button, canvas, game, knob, microinteraction, recipe, slider, toggle, ui, zero-gc

## 简介

Canvas-hijacked UI components with a pluggable recipe system: 57 built-in recipes across toggles, buttons, sliders, knobs, loaders, checkboxes, counters and ratings, in three mount modes (hijack, decorate, grouped controls) plus a lite-headless skin adapt
