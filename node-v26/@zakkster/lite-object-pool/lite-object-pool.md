# @zakkster/lite-object-pool

> 标签: game, garbage-collection, gc, lightweight, memory, object-pool, particles, performance, pool, preallocate, reuse, zero-dependency

## 简介

Tiny, fast, zero-dependency object pool with O(1) acquire/release, double-release protection, and auto-expansion for games and particle systems.
