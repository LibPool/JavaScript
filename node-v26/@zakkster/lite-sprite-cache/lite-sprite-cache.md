# @zakkster/lite-sprite-cache

> 标签: assets, cache, canvas, deduplication, engine, gamedev, html5, imagebitmap, ios-safari, lite-tools, loader, lru, memory-management, off-thread, sprite-cache, texture-manager, vram, webgl, zero-gc

## 简介

Zero-GC off-thread ImageBitmap loader with strict VRAM limits, URL deduplication, and LRU eviction to prevent mobile browser crashes.
