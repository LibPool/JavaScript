# @e-volv/logs

> 标签: error-tracking, logging, logs, observability, opentelemetry, tracing

## 简介

e-volv SDK for Node.js, browsers and edge runtimes — feature flags evaluated locally (e-volv Launch) plus logs, traces and error capture (e-volv Observer), with agent integrations.
