# @e-volv/logs-react-native

> 标签: crash-reporting, error-tracking, logging, logs, observability, react-native, tracing

## 简介

e-volv Observer SDK for React Native — logs, traces, JS crash capture and traceparent propagation. A wrapper with no transport of its own: finished events cross the native module into the Android (io.e-volv:logs-android) and iOS (e-volv-logs-swift) client
