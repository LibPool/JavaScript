# @e-volv/flags-client

> 标签: e-volv, feature-flags, launch

## 简介

e-volv Launch — the runtime-agnostic client flags core: context fitting and fingerprinting, the evaluated-values store, polling, cache envelopes and exposures. Shared by the browser entry of @e-volv/logs and the React Native JavaScript fallback.
