# @lineai/agent-memory

> 标签: agent-platform, claude, gcs, lineai, memory

## 简介

Per-user agent memory with directory semantics. GCS-backed, with filesystem and tool adapters so the same memory is reachable from Claude Agent SDK channels and tool-only channels alike.
