# @zygapp/kintone-vue3-component

> 标签: component, kintone, vue, vue3

## 简介

Vue 3 用 kintone UI コンポーネントは、kintone カスタマイズを簡略化するためのツールです。事前定義されたコンポーネントやカスタマイズ性、アクセシビリティ対応により、効率的で使いやすい UI を構築できます。
