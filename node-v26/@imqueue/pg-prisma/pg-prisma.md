# @imqueue/pg-prisma

> 标签: access-control, audit, imqueue, microservices, middleware, nodejs, postgres, postgresql, prisma, prisma-extension, prisma-next, rpc, soa, soft-delete, typescript

## 简介

Prisma Next (8.x) / Postgres toolkit for Node.js & TypeScript microservices — query middlewares (soft-delete, authorship, audit, access-scope) derived from the emitted contract, row archiving and change-notify triggers (the @imqueue framework)
