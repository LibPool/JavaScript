# debug-to-file

> 标签: JavaScript

## 简介

[debug-to-file](http://github.com/131/debug-to-file) is tiny, no dependecy  helper to dump [debug](http://github.com/visionmedia/debug) traces to a file (through `DEBUG_FILE` env var).
