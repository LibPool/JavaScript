# @m2m-monster/sdk

> 标签: agents, ai-agents, m2m-split, mcp, payments, solana, x402

## 简介

m2m.monster SDK: non-custodial agent-to-agent payments over x402 (m2m-split) on Solana. Agents sign locally.
