# @stockmandigital/automessage-mcp

> 标签: automessage, claude, claude-code, imessage, mcp, model-context-protocol

## 简介

MCP server for autoMessage — gives Claude, Codex, and any MCP client the ability to send iMessages, read conversation history, manage drafts, and resolve contacts via the autoMessage REST API.
