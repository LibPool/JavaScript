# @estoc/daemon

> 标签: agent, daemon, decentralized-identity, did, didcomm

## 简介

The Estoc daemon: an agent and its vault behind one RPC interface the UI talks to. The same core runs in a browser worker (OPFS) and as a Node process (`estoc-daemon`, a folder on disk, a WebSocket the app connects to).
