# @ailuracode/alpine-collection

> 标签: alpine, alpinejs, collection, controller, filter, group, headless, paginate, sort

## 简介

Framework-agnostic collection primitives for Alpine.js — filtering, sorting, grouping, pagination, and active-item navigation over a stable key registry.
