# @cavelang/act

> 标签: JavaScript

## 简介

CAVE action templates (spec §25) — named, parameterized governed writes: in-band declarations, CAVE-Q preconditions validated against current belief, atomic templated appends with BECAUSE/VIA lineage, and out-of-band side-effect hooks.
