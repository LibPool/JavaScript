# ckeditor5-elements-schema

> 标签: ckeditor, ckeditor 5, ckeditor5, ckeditor5-feature, ckeditor5-plugin

## 简介

Element schema for CKEditor 5: declare elements in the model schema from a simple definition, e.g. a JSON file, with three types of elements and a validation.
