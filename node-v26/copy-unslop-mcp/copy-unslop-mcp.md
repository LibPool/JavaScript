## 简介

MCP server + agent skill that audits copywriting for AI slop (stock phrases, empty adjectives, em-dash tics, fake social proof, generic CTAs) in English and Bahasa Indonesia, with readability scoring and SEO/microcopy length checks. Works with Claude Code
