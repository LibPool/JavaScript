# @anonfeedback/widget

> 标签: anonfeedback, anonymous, feedback, widget

## 简介

Embeddable anonymous feedback widget for Anonfeedback (anonfeedback.io). Framework-agnostic, ~10 KB, shadow-DOM isolated.

## 官网

- 官网：https://anonfeedback.io
