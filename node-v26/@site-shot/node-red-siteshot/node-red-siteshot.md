# @site-shot/node-red-siteshot

> 标签: node-red, screenshot, site-shot, website screenshot

## 简介

Node-RED node that captures a public web page as a PNG or JPEG screenshot with the Site-Shot API.

- 官网：https://www.site-shot.com/
- 源码仓库：git+https://github.com/site-shot/node-red-siteshot.git
