# @systemix/token

> 标签: api-key, auth, crypto, generator, hmac, node, rsa, secure-token, session-token, signed-token, systemix, token, typescript, utility

## 简介

A cryptographically secure token generator and signed-token module for API keys, session tokens, and auth. Zero dependencies, pure Node.js.
