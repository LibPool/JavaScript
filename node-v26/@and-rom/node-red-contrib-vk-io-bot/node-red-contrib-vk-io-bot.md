# @and-rom/node-red-contrib-vk-io-bot

> 标签: bot, node-red, vk-io

## 简介

This package contains a receiver and a sender node which act as a Telegram Bot. The only thing required is the `token` that can be retrieved by the https://vk.com/club${id}?act=tokens.
