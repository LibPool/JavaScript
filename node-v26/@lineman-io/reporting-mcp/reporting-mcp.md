# @lineman-io/reporting-mcp

> 标签: claude-code, cost-analytics, lineman, mcp, reporting

## 简介

Pointer plugin for the Lineman Reporting MCP server. Ask natural-language questions about your Lineman spend, budgets, ROI, and cost centres from Claude Code or Claude Desktop.
