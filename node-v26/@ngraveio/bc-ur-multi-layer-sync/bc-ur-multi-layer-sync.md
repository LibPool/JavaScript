# @ngraveio/bc-ur-multi-layer-sync

> 标签: Blockchain Commons, bc-ur, cbor, coin, crypto, sync, wallet, watch-only

## 简介

Provides BC-UR types for syncing multiple coins and accounts from cold wallets to watch only wallets.
