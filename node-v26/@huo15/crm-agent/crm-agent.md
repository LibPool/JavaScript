# @huo15/crm-agent

> 标签: acquisition, crm, finance, huo15, lead-generation, lvhuo, openclaw, plugin, sales, sales-enablement, tax, 绿火

## 简介

绿火 — 拓客 / 获客 / CRM 销售员智能体。行业领域包可插拔，v0.1 内置 finance_tax 财税领域包（代账 / 审计 / 税务筹划 / IPO 辅导）；本身不直连 Odoo，所有 CRM 写入动作由 @huo15/huo15-huihuoyun-odoo 执行（odoo_crm_create / odoo_crm_update / odoo_create_activity / odoo_message_post 等），二者解耦协同，与辉火云 Odoo19 企业版 CRM 一起工作。
