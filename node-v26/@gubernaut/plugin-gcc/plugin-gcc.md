# @gubernaut/plugin-gcc

> 标签: ai-agents, elizaos, gcc, governance, gubernaut, plugin, web3

## 简介

ElizaOS plugin: route agent LLM calls through the Gubernaut local proxy — a deterministic runtime governor with runaway-loop hard-stop and cost containment.
