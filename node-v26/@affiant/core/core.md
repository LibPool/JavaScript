# @affiant/core

> 标签: affiant, affidavit, agent-tools, ai-agents, approval-workflow, audit-trail, guardrails, human-in-the-loop, provenance, tool-calling

## 简介

The Affiant gate for TypeScript: every database write an AI agent proposes becomes an Affidavit a person approves, amends or rejects - or a policy approves with nobody present, on the record.
