# @corpus-core/isix

> 标签: colicam, image-hash, isix, perceptual-hash, wasm

## 简介

Canonical ISIX perceptual image hash and media hash (same implementation as Colicam / Flutter). Browser-only; requires WasmGC (current Chromium).
