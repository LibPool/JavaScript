# @rudevich/agentic-flow

> 标签: agents, agents-md, claude-code, confluence, figma, jira, mcp, scaffold, skills

## 简介

Scaffolds an agentic/ directory (skills, agents, hooks, tasks) with .claude and CLAUDE.md symlinks, and seeds a ticket-to-subtasks pipeline
