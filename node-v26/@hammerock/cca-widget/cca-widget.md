# @hammerock/cca-widget

> 标签: auction, cca, continuous-clearing-auction, embed, react, uniswap, viem, widget

## 简介

Embeddable React component (and <script> tag) showing a live Uniswap CCA auction with a bid form. Ethereum, Base, Unichain, Arbitrum and their testnets.
