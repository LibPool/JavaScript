# @hammerock/cca-agent

> 标签: agent, auction, bidding, cca, cli, continuous-clearing-auction, uniswap, viem

## 简介

Command-line bidding agent for Uniswap Continuous Clearing Auctions (CCA): guided setup, live status, dry runs and capped live bidding. Mainnet bidding is opt-in.
