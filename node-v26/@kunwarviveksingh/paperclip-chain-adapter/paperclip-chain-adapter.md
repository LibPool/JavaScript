# @kunwarviveksingh/paperclip-chain-adapter

> 标签: adapter, ai-agent, fallback, llm, openrouter, paperclip, paperclip-adapter

## 简介

Deterministic explicit-chain fallback adapter for Paperclip: runs a fixed ordered list of backends and uses the first available. No implicit/trending model switching — per-role determinism.
