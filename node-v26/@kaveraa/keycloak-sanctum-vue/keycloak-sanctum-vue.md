# @kaveraa/keycloak-sanctum-vue

> 标签: authentication, keycloak, laravel, oidc, sanctum, sso, vue, vue-router, vue3

## 简介

Vue 3 client for Keycloak login (SSO) with a Laravel API: Sanctum token, user, roles, router guard, authenticated fetch and inactivity logout.
