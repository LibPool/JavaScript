# @inadigital-ui/vue-chart

> 标签: JavaScript

## 简介

Wrapper sederhana untuk ApexCharts di Vue 3. Package ini sudah termasuk `vue3-apexcharts` dan `apexcharts`, sehingga Anda tidak perlu menginstall dependencies tersebut secara terpisah.
