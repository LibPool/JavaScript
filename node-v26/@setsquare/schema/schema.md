# @setsquare/schema

> 标签: JavaScript

## 简介

The Setsquare wire contract. Zod definitions that generate every other representation — JSON Schema, OpenAPI, typed clients. Published because @setsquare/review-sdk depends on it at runtime (P1-17.8).
