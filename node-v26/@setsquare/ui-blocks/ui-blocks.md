# @setsquare/ui-blocks

> 标签: a11y, accessibility, atag, authoring-tool, content-editor, page-builder, puck, react, wcag

## 简介

A page builder for @setsquare/ui on Puck: pages made from blocks, with every task by drag, by press and by keyboard, and accessibility checks that run on the rendered page.
