# @setsquare/review-cli

> 标签: accessibility, cli, playwright, setsquare

## 简介

The setsquare CLI: project setup and read-only coverage auditing for Playwright suites. Installed transitively by @setsquare/review-sdk, so one install links the setsquare binary.
