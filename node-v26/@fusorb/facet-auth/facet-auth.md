# @fusorb/facet-auth

> 标签: auth-ui, authentication, mfa, oauth, passkeys, react

## 简介

Domain-customizable auth components: ArcProvider, SignIn/SignUp, Guard, MfaDialog, and 5 domain presets (fintech, med, edu, enterprise, default). Wired to @fusorb/facet-sdk.
