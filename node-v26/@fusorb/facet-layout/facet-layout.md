# @fusorb/facet-layout

> 标签: app-shell, dashboard, layout, react, sidebar, topbar

## 简介

Domain-configurable app shell: Sidebar, Topbar, AuthLayout, ConsoleLayout, LandingLayout, PageHeader, TenantSwitcher, and 5 domain presets (fintech, med, edu, enterprise, default).
