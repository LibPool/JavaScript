# @surayaorg/capture

> 标签: agent-sdk, brain, capture, claude-code, observability, suraya

## 简介

Capture SDK for the Suraya brain. Track A automatic capture via Claude Code Agent SDK hooks (PostToolUse / UserPromptSubmit / Stop) plus the shipObservation transport for direct emission. Writes typed observations to a local .observations.jsonl and POSTs
