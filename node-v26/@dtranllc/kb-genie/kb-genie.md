# @dtranllc/kb-genie

> 标签: chunking, cursor-plugin, ingestion, kb-genie, knowledge-base

## 简介

Cursor plugin that turns raw technical documents into an agent-optimized knowledge base. This package is a companion CLI that initializes a knowledge-base folder template.
