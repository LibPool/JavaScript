# @wevna/sdk

> 标签: backend, dashboard, debugging, devtools, express, fastify, instrumentation, local-first, nestjs, nodejs, observability, postgres, redis, runtime, typescript

## 简介

Local-first runtime dashboard for Node.js backends: watch HTTP, SQL, Redis and console activity live, correlated per request.
