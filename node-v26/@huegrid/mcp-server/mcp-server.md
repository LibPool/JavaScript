# @huegrid/mcp-server

> 标签: ai, claude, color-extraction, css, cursor, design, gradient, huegrid, mcp, mcp-server, model-context-protocol, shader, webgl

## 简介

MCP server for HueGrid — search 1,800+ gradient presets, generate code (CSS/React/Vue/Svelte/Swift), extract colors from images, and browse the community gallery. Works with Claude, Cursor, Windsurf, and any MCP-compatible AI tool.
