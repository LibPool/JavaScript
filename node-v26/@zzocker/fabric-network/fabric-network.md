# @zzocker/fabric-network

> 标签: blockchain, hyperledger

## 简介

SDK for writing node.js applications to interact with Hyperledger Fabric. This package encapsulates the APIs to connect to a Fabric network, submit transactions and perform queries against the ledger.

## 官网

- 官网：https://www.hyperledger.org/projects/fabric
- 源码仓库：git+https://github.com/hyperledger/fabric-sdk-node.git
- npm 页面：https://www.npmjs.com/package/@zzocker/fabric-network
