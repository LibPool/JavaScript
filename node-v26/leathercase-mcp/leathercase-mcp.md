# leathercase-mcp

> 标签: fiction, mcp, model-context-protocol, screenwriting, writing

## 简介

Connect an AI agent to Leathercase, the desktop app for novelists and screenwriters. A stdio MCP server that forwards to Leathercase running on this computer.
