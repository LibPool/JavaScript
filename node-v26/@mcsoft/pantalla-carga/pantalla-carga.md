# @mcsoft/pantalla-carga

> 标签: library, loading, mcsoft, react, spanish

## 简介

Componente de React que muestra un mensaje en medio de la pantalla para indicar que la aplicación esta cargando, cubre toda la pantalla y no permite la interacción con la interfaz mientras esta visible.
