# pi-durable-memory

> 标签: JavaScript

## 简介

Hierarchical long-term memory for Pi Durable agents on Cloudflare Durable Objects: one object per scope with an append-only log, a binary summary tree, bounded wake, full-text recall and zoom. Injected summarizer.
