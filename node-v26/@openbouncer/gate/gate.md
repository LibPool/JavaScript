# @openbouncer/gate

> 标签: agentic-web, agents, captcha, cloudflare-for-agents, llm, mcp, openbouncer, react, reverse-captcha

## 简介

Reverse-captcha gate for the agentic web — a React wrapper that admits verified AI agents and politely turns humans away. Three lines to install.
