# permission-guard-pi

> 标签: access-control, audit-log, extension, permissions, pi, pi-coding-agent, pi-package, safety

## 简介

Layered, configurable file-access control for pi-coding-agent. Dual region (project_inner / project_outer) x three-tier permissions (read_write / read_only / unread), with session- and persistent-grant memory, audit log, and default-sensitive-path fallbac
