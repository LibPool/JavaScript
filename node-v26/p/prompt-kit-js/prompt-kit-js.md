# prompt-kit-js

> 标签: ai, anthropic, groq, llm, openai, prompt, prompt-engineering, template, token-estimator, typescript

## 简介

Lightweight, versioned prompt template manager for LLM apps — variable injection, template registry, and a rough token-count estimator. Framework/provider agnostic (OpenAI, Groq, Anthropic, anything).
