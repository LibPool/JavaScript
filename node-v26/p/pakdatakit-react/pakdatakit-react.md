# pakdatakit-react

> 标签: cnic, form, hooks, iban, input, input-mask, mobile, pakdatakit, pakistan, phone, qr, raast, react

## 简介

React inputs and hooks for Pakistani CNIC, mobile numbers and IBANs that format as you type, plus a Raast payment QR component, built on pakdatakit
