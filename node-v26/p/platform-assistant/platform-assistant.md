# platform-assistant

> 标签: JavaScript

## 简介

可复用的浮动智能体助手组件（Vue 3 + Element Plus）：可拖拽悬浮球、流式对话、Markdown 渲染，API 地址/请求头可配置，支持 npm 与 UMD 引入。

## 官网

- npm 页面：https://www.npmjs.com/package/platform-assistant
