# pi-cliproxyapi-autoconnect

> 标签: autoconnect, autodiscover, cliproxy, cliproxyapi, model-discovery, openai-compatible, pi-extension, pi-package, provider

## 简介

Independent CLIProxyAPI provider for pi: sign in with your CLIProxyAPI domain and API key, auto-discover OpenAI-, Gemini-, or Anthropic-compatible endpoints, and register models in /model.
