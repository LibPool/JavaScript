# pi-gpu-cost

> 标签: cost, energy, gpu, nvidia, nvidia-smi, pi-extension, pi-package

## 简介

Track GPU power draw & electricity cost per pi session (NVIDIA GPUs only, via nvidia-smi). pi must run on the same machine as the GPU — it samples the local nvidia-smi and has no remote mode.
