# pi-say

> 标签: accessibility, pi, pi-package, speech, text-to-speech, tts, voice

## 简介

Spoken output for pi: a say tool that speaks short sentences through local TTS (Kokoro/Piper HTTP server, macOS say, or espeak-ng).
