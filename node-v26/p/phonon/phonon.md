# phonon

> 标签: css, desktop, framework, front-end, mobile, responsive, sass, web

## 简介

Phonon is an open source HTML, CSS and JavaScript agnostic framework that allows to create a website or a hybrid Web app.

## 官网

- 官网：https://phonon-framework.github.io
- 源码仓库：git+https://github.com/phonon-framework/phonon.git
- npm 页面：https://www.npmjs.com/package/phonon
