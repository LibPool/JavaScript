# papersprocket-mcp

> 标签: html-to-pdf, mcp, model-context-protocol, papersprocket, pdf, render

## 简介

PaperSprocket-native MCP server. Exactly two tools: render_html_to_pdf (binary PDF) and check_balance. Credentials come from server-side env/.env only — never caller-supplied tool arguments.
