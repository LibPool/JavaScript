# pdf-img-convert-canvas-v3

> 标签: convert, es6, esm, image, img, module, pdf, png

## 简介

A simple module to convert PDF files into image buffers (without filesystem usage). This is a temporary ad-hoc solution. Please, use original pdf-image-convert package if possible. This one solves 'canvas' library installation issues on some systems.
