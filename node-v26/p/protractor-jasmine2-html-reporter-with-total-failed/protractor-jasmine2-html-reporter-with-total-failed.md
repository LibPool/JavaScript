# protractor-jasmine2-html-reporter-with-total-failed

> 标签: bdd, end2end, functional testing, html, jasmine, jasmine 2, protractor, reporter, screenshot, test

## 简介

HTML reporter for Jasmine and Protractor. It generates a HTML report with screenshots and  also includes a summary with total failed specs and total failed suites.
