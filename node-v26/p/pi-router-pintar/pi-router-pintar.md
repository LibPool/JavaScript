# pi-router-pintar

> 标签: agent, ai, pi, pi-extension, pi-package, routing, smart-router

## 简介

Fork of beettlle/pi-smart-router (Translate: pi-router-pintar). Auto-model router middleware for pi. Adds reliable loop-escalation failure detection via is_error/status and classifies gpt-5.5+ as frontier-cloud.
