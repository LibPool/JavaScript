# pronounr

> 标签: gender, neopronouns, nlp, pronouns, text-replacement

## 简介

Context-aware third-person pronoun replacement for English text. Swap one person's pronouns to any supported set (incl. neopronouns), with POS-based disambiguation of syncretic forms.
