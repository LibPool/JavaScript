# pn532.js

> 标签: 13.56MHz, NFC, PN532, RFID, browser, chrome, libnfc, mifare classic, web bluetooth, web serial

## 简介

pn532.js is a JavaScript library for PN532 base on Web Bluetooth and Web Serial.
