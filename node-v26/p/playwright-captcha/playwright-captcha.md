# playwright-captcha

> 标签: automation, browser automation, captcha, death by captcha, node, playwright, playwright captcha, playwright captcha solver, playwright sdk, recaptcha, rpa, text captcha, typescript, web automation

## 简介

Simple and lightweight Node.js SDK for Playwright that facilitates the automation of text CAPTCHA and reCAPTCHA in enterprise browser automation workflows.
