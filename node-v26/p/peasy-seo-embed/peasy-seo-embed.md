# peasy-seo-embed

> 标签: audit, embed, meta-tags, peasy, peasyseo.com, robots, search-engine, seo, shadow-dom, sitemap, widget, zero-dependencies

## 简介

Embed PeasySEO widgets on any website. Lightweight (<8KB gzipped), zero dependencies, Shadow DOM isolation, 3 themes.
