# paperclip-docs

> 标签: ai-agents, docs, docs-search, documentation, knowledge-base, offline-docs, okf, open-knowledge-format, paperclip, paperclip-plugin, paperclipai

## 简介

Serve an Open Knowledge Format (OKF) corpus to Paperclip agents as governed, read-only tools — search, read, browse, and report the snapshot's age — with a per-organization source registry, host-side rebuild requests, and optional semantic retrieval.
