> 标签: browser, bun, canvas, chainable, computer-vision, contours, edge-detection, image-processor, modular, open-cv, opencv-js, perspective-transformation, pipeline, threshold, type-safe, web

## 简介

A type-safe, modular, chainable image processing library built on top of OpenCV.js with a fluent API leveraging pipeline processing.
