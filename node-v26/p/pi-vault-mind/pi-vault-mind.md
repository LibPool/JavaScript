# pi-vault-mind

> 标签: agent-tools, file-watcher, graph, hitl, jsonl, knowledge-base, knowledge-graph, lance, lancedb, notebooklm, obsidian, obsidian-vault, passive, pi-extension, pi-package, pi-skills, pkm, search, semantic-search, subagent, subagents, vault-mind

## 简介

Passive Obsidian vault extension for pi. Watches @agent markers, dispatches forked subagents (Miner, Broadcaster, Heavy-Lifter), stores in LanceDB with vector + FTS + graph. Multi-agent 'Drop & Forget' workflow for the pi agent ecosystem.
