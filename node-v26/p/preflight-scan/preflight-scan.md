# preflight-scan

> 标签: api-key, app-store, cost-control, expo, openai, pre-launch, react-native, secrets, security, supabase, vibe-coding

## 简介

Pre-launch checks for AI-built apps: leaked keys, runaway API cost, open endpoints and store-submission blockers. Runs locally, sends nothing.
