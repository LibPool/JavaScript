# pg-binder

> 标签: esm, jsonb, object-mapper, pg, pg-binder, postgres, postgresql, typescript

## 简介

Bind JavaScript objects to safe PostgreSQL queries – turn your plain objects into fully parameterized SQL with zero hassle.
