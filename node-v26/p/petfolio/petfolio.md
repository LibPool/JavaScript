# petfolio

> 标签: animated, avatar, companion, desktop-pet, mascot, petfolio, pixijs, shimeji, widget

## 简介

Drop-in animated desktop pet for any website. Shimeji-style PixiJS companion with auto-pilot, dragging, and 46 animation frames.
