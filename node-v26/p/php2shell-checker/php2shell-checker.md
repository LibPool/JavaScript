# php2shell-checker

> 标签: cve, patch, php, php2shell, security, vulnerability

## 简介

Passive PHP patch-status check for PHP2Shell (CVE-2026-109618 / CVE-2026-109619). Read-only — reads advertised version headers or `php -v`, never probes or exploits.
