# pdf-digestor

> 标签: ai, json, langchain, llm, markdown, openai, parse, pdf, rag, text-extraction, token-saver, tokens

## 简介

Extract and transform PDF text into LLM-optimized formats (JSON, Markdown, plain text, log) to reduce token waste.
