# prerender-multi-page-jsdom

> 标签: JavaScript

## 简介

本插件主要用于多页面渲染预渲染模式，主要代码源于@prerenderer/prerenderer（主要支持SPA渲染），经过改造而成。 使用JSDOM预渲染
