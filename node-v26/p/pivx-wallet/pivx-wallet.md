# pivx-wallet

> 标签: payments, pivx, sapling, sdk, shield, wallet

## 简介

Standalone PIVX wallet SDK: local key management, shielded (SHIELD/Sapling) scanning, balances, and transaction building. The node is only a chain-data source.
