# prompt-parse-js

> 标签: JavaScript

## 简介

> prompt主要构成是关键词和参数。这个工具主要完成了将关键词跟进逗号分隔成一个一个的参数项，并且将最后的参数解析成对一个对象。后面的参数会覆盖前面的参数。 > 分隔符兼容中英文逗号，中文顿号，中英文分号等。
