# pomelots-admin-web

> 标签: JavaScript

## 简介

pomelots-admin-web is a web console for [pinus](https://github.com/node-pinus/pinus). it is based on [pomelots-admin](https://github.com/node-pinus/pomelots-admin). it is just an web console example, you can implement your style like web console.
