# pethost

> 标签: api, client, deploy, docker, docker compose, hosting, paas, pethost, sdk

## 简介

TypeScript and JavaScript SDK for Pethost, the agent-first cloud for everything you build: deploy Docker Compose projects to a machine of your own, read their logs and requests, run commands in their containers.
