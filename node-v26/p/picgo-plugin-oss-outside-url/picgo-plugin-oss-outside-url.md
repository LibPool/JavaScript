# picgo-plugin-oss-outside-url

> 标签: picgo, picgo-gui-plugin, picgo-plugin

## 简介

将OSS的私有资源链接转成外链的PicGo插件，支持阿里云OSS、腾讯云COS、七牛云Kodo
注意：该插件没有充分测试网址后缀的场景，设置了网址后缀可能会导致非预期的结果发生
