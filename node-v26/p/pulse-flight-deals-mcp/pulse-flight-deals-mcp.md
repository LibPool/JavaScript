# pulse-flight-deals-mcp

> 标签: airfare, flight-deals, flights, mcp, model-context-protocol, stdio, travel

## 简介

MCP server that lets an AI agent judge whether a flight price is actually a deal, grounded in observed fare history. Answers 'is $X for this route a good price?' with real numbers an LLM cannot produce on its own.
