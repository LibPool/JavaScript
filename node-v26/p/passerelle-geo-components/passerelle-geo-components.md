# passerelle-geo-components

> 标签: cartography, custom-elements, geospatial, grist-widget, maplibre, qgis, scene-manifest, storymap, three-js, web-components

## 简介

Web Components pour cartes MapLibre + composants controllers pilotes - brique commune multi-projet avec contract SceneManifest V0.3.1. Zero dependance runtime, ES module, encapsulation Shadow DOM.
