# pi-context-engineer

> 标签: context-engineering, fovea, pi, pi-fabric, pi-package

## 简介

Context governor for Pi Fabric and Pi Fovea: taint-gates data flow, budgets selection, compresses results, offloads payloads, and records context cost.
