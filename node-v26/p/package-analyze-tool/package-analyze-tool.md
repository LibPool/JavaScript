# package-analyze-tool

> 标签: analyze, package, tool

## 简介

`analyze-tool`将从`package-lock.json`文件出发，通过递归分析所有位于`node_modules`目录中的`package.json`文件，来生成依赖关系数据，并利用 Echarts 进行可视化渲染。
