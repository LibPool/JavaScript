# postern-mcp

> 标签: email, mailbox, mcp, model-context-protocol, postern

## 简介

Model Context Protocol server for Postern: read tools over the mailbox API (search/list/get/thread), plus optional send tools (mailbox_send / mailbox_reply) behind a send-scoped token.
