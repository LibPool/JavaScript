# prettier-plugin-hug-call-arguments

> 标签: call-arguments, callback, code-style, formatter, prettier, prettier-plugin, typescript

## 简介

Prettier plugin: hug the last call argument even when it's wrapped in another call, e.g. app.delete("/x", catchAsync(async (req, res) => { ... })). Fixes https://github.com/prettier/prettier/issues/11080
