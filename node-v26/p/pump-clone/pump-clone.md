# pump-clone

> 标签: bot, launchpad, memecoin, nlp, oddballer, pump.fun, solana, themes

## 简介

Watch pump.fun CREATE events, score them for net-new themes, and mirror the interesting ones 1:1 onto a protected-curve launchpad — with optional first buy and borrow.
