# pi-multi-agent-mode

> 标签: agents, delegation, multi-agent, pi-package, subagents

## 简介

Codex-style collaboration for Pi: spawn_agent, followup_task, send_message, wait_agent, list_agents, and interrupt_agent. Named agent trees, configurable child model, history forks, mailboxes, and a packaged multi-agent-mode skill.
