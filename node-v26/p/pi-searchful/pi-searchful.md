# pi-searchful

> 标签: ai-tools, pi, pi-extension, pi-package, retrieval, search, web-search

## 简介

Tiered web-search and URL-retrieval extension for Pi. Routes search via Jev to Exa/Brave/Tavily and retrieves URLs via Trafilatura/Jina/crawl4ai.
