# pinyin-pro

> 标签: pinyin, 中文, 声母, 拼音, 汉字, 音调, 韵母, 首字母

## 简介

准确率和性能最优异的汉字转拼音库。获取中文拼音、韵母、声母、声调、首字母，支持拼音匹配
