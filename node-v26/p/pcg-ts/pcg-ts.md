# pcg-ts

> 标签: ai-agents, deterministic, instancing, node-graph, noise, pcg, procedural-generation, scattering, threejs, typescript

## 简介

Deterministic procedural content generation for TypeScript: domain attributes, node graphs, deferred fields, hierarchical streaming. Optional three.js interop.
