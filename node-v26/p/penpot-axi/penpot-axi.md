# penpot-axi

> 标签: agent, axi, cli, design, mcp, penpot, toon

## 简介

Agent ergonomic CLI over the Penpot MCP. Inspect, read, export, and script Penpot designs with token-efficient TOON output. Prefer this over the raw Penpot MCP tools.
