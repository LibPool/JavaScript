# pcf-eureka-client

> 标签: eureka, netflix, registry, service

## 简介

JS implementation of a client for Eureka (https://github.com/Netflix/eureka), the Netflix OSS service registry. This is forked from Storytel/pcf-eureka-client (https://github.com/Storytel/pcf-eureka-client) to add OAuth2 related enhancements for Pivotal C
