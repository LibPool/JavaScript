# pi-session-trace

> 标签: pi, pi-coding-agent, pi-extension, pi-package, session, timeline, trace, trajectory

## 简介

Live + replayable session trajectory for pi — dsh-style turn timeline with TTFT/decode split, backed by pi's session JSONL so history is never lost
