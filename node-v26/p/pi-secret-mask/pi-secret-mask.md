# pi-secret-mask

> 标签: extension, mask, pi, pi-coding-agent, pi-package, redaction, secret, security

## 简介

Mask secrets before they reach LLM providers: placeholders in provider payload, real values in bash/write, output masked back. 中文文档见 README.zh-CN.md
