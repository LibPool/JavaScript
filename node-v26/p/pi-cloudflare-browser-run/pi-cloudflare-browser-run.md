# pi-cloudflare-browser-run

> 标签: agent, browser, browser-run, cloudflare, pi, pi-extension

## 简介

Pi extension: web browsing tools (markdown / screenshot / pdf / crawl) powered by Cloudflare Browser Run. Headless Chrome on CF's network — JS-rendered pages, login sessions, WebMCP-capable.
