# personal-config

> 标签: agent, claude-code, cli, coding-agent, handoff, ledger, setup-wizard, working-standard

## 简介

A terminal wizard that sets up an agent-driven working style in your repos — a ledger, a board, a working standard, and the rules your agent reads before it writes code.
