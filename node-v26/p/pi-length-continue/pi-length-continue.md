# pi-length-continue

> 标签: auto-continue, max-tokens, pi-extension, pi-package, unattended

## 简介

Auto-continue when a response is truncated by the model's per-response output token limit (stop_reason=length). Detects the truncation at agent_end and sends the 'continue exactly where you stopped' itself — no more dead stops on unattended rigs.
