# pi-prose-watch

> 标签: ai-detection, extension, jev, pi, pi-coding-agent, pi-package, prose, typesafe, writing

## 简介

An AI-tone check for pi that runs only while the agent drafts prose: arm a file with prose_watch, and every write or edit to it is judged by Jev, with a likely-AI verdict attached to the tool result
