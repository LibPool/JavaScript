# pi-cli-mcp

> 标签: claude-code, coding-agent, delegation, mcp, model-context-protocol, pi, pi-coding-agent, subagent

## 简介

MCP server that delegates coding tasks to your locally installed pi CLI. Wraps the real binary instead of bundling its own copy of the agent, so it inherits your providers, models and extensions. Sessions survive restarts, calls are cancellable, and each
