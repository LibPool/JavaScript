# portreeve

> 标签: abuse-prevention, card-testing, fake-signups, fraud, trial-abuse

## 简介

Node/TypeScript SDK for Portreeve — abuse firewall for indie SaaS. Allow/review/block verdicts on signups, trials, and checkouts.
