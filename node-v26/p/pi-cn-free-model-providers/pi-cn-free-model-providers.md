# pi-cn-free-model-providers

> 标签: china, cli, deepseek, extension, free-models, mainland-china, model-providers, opencode, pi, pi-package, zen

## 简介

pi (AI coding agent CLI) extension for mainland-China users: curated access to free-first model providers including OpenCode Zen, SenseNova, SiliconFlow, ModelScope, NVIDIA NIM, Cloudflare, and Agnes AI. Providers support Pi-managed auth.json credentials
