# pgbouncer-insights

> 标签: cli, dashboard, monitoring, observability, pgbouncer, postgres, postgresql

## 简介

A CLI observability dashboard for PgBouncer — live pool/client/server stats and scriptable SHOW-command output, with cached connection profiles.
