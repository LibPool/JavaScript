# payperscreen-mcp

> 标签: aml, compliance, crypto, kyc, mcp, model-context-protocol, ofac, sanctions, screening, x402

## 简介

MCP server for PayPerScreen: sanctions, crypto wallet, email and IP screening for AI agents, paid per check in USDC over x402. No account or API key.
