# patchdrift

> 标签: ci, cisa, cve, kev, patch-management, security, vulnerability

## 简介

Check a list of CVE ids, package coordinates or product versions for records that changed after you closed the ticket: the fix version moved, the affected range was extended, a product was added, the score was revised, the record was withdrawn, or CISA's
