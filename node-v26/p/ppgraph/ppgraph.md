# ppgraph

> 标签: cli, dataverse, graph, mcp, power-apps, power-automate, power-platform, sharepoint

## 简介

Builds a dependency graph of a Power Platform environment: which SharePoint list triggers which flow, what those flows write back, and which app uses what.
