# promptlint-mcp

> 标签: ai, claude, cost-optimization, linter, llm, mcp, model-context-protocol, prompt, prompt-engineering, tokens

## 简介

Static linter for AI prompts. Detects contradictions, redundancy, ambiguity, and fluff. Ships as a CLI and an MCP server.
