# pi-terminal-signals

> 标签: extension, ghostty, iterm2, kitty, osc, pi, pi-coding-agent, pi-package, progress, semantic-prompts, terminal, wezterm

## 简介

Pi extension that communicates agent lifecycle to the terminal via OSC 9;4 (progress) and OSC 133 (semantic prompts).
