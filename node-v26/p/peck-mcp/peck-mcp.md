# peck-mcp

> 标签: agent, bitcoin-schema, bitcoin-sv, brc-100, bsv, mcp, peck, social-graph

## 简介

MCP server giving any LLM a BRC-100 identity, an OS-keychain-resident BSV wallet, and tools for reading + writing the shared Bitcoin Schema social graph (peck.to + 50 other apps). Runs as stdio for local installs or StreamableHTTP for hosted deployments.
