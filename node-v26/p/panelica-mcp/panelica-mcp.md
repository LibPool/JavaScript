# panelica-mcp

> 标签: ai, automation, control-panel, devops, hosting, mcp, model-context-protocol, panelica, sysadmin

## 简介

MCP server exposing the Panelica hosting panel External API to AI assistants. Manage accounts, domains, databases, email, DNS, SSL, FTP, security, and server resources through natural language.
