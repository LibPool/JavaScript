# postext-cli

> 标签: book, cli, epub, markdown, pdf, postext, typesetting

## 简介

The postext command line: PDF, HTML, EPUB, page images and Word files from a .postext book or loose Markdown, in one self-contained executable for Linux, macOS and Windows.
