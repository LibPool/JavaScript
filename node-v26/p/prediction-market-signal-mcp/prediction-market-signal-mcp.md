# prediction-market-signal-mcp

> 标签: agent, betting-markets, claude, cursor, forecasting, kalshi, mcp, model-context-protocol, odds, polymarket, prediction-markets, sentiment, x402

## 简介

MCP server for Polymarket + Kalshi prediction-market odds, movers, history, gaps, and X/Twitter sentiment — no API key, no subscription. Pays per call in USDC on Base via x402 from your own wallet.
