# pi-deck-vision

> 标签: image, ocr, pi-extension, pi-package, vision

## 简介

Vision bridge extension for Pi: converts images to text descriptions so text-only models (e.g. DeepSeek) can see them. Forked from PiDeck (github.com/ayuayue/PiDeck).
