# pareto-resource-execute-unrestricted

> 标签: JavaScript

## 简介

a library that implements the execute-unrestricted-api and thus provides program execution functionality for pareto packages. This resource is not sandboxed and thus gives a package the ability to execute any programs without any restrictions. The sandbox
