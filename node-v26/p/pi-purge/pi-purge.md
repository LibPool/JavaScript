# pi-purge

> 标签: pi, pi-coding-agent, pi-extension, pi-package, prompt-engineering, prompt-evaluation, system-prompt

## 简介

pi extension: switch a session between pi's stock system prompt, a trimmed variant, and a bundled or custom persona prompt - for prompt-engineering experiments
