# pi-status-widget

> 标签: footer, nerd-fonts, pi, pi-coding-agent, pi-extension, pi-package, statusbar, statusline, tui

## 简介

Pi extension. A footer/statusline with four presets, emoji or nerd font icons, and a thinking-level segment whose color tracks the level.
