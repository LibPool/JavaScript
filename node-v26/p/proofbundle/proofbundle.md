# proofbundle

> 标签: ai-evaluation, ed25519, evidence-integrity, merkle, offline-verification, receipts

## 简介

Offline-verifiable receipts for AI evaluation results. Reference implementation is Python (PyPI: proofbundle); this package is its JavaScript home and currently provides pointers to the canonical project.
