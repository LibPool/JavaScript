# pi-voice-mode

> 标签: accessibility, dictation, pi, pi-extension, pi-package, speech-to-text, typeless, voice

## 简介

为 Pi 增加全局 /voice 开关，让模型可靠理解 Typeless 等外部语音转写输入。
