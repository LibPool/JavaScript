# pdfglyph-client

> 标签: api, html-to-pdf, pdf, pdf-generation, pdfglyph, screenshot, sdk

## 简介

Official Node.js client for the PDFGlyph API — render HTML and CSS to pixel-perfect PDFs with one API call.
