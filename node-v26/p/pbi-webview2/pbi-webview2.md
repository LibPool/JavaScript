# pbi-webview2

> 标签: cdp, mcp, modelcontextprotocol, playwright, power-bi, power-bi-desktop, powerbi, ui-testing, webview2

## 简介

MCP server that drives the LIVE Power BI Desktop report canvas (WebView2) over CDP — switch pages, click slicers, fire bookmarks, read cards/matrices as data, judge cross-filters, run the Performance Analyzer, and screenshot, with no reload and no OCR.
