# promise-faker

> 标签: async, fake, fake-promise, promise, promise-faker, promise-sync, promise.all, promise.reject, promise.resolve, promise.sync, sync, sync-promise

## 简介

Provides promise-like APIs but runs synchronously. This module is useful for controlling flows.
