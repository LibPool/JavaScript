# prisma1-node-client

> 标签: JavaScript

## 简介

This is a fork of the original Prisma 1 client that has the follow modifications  * Only TS/JS Lib (Flow, Go, etc removed) * Updated for graphql 15+ * Updated for TS 4.5+
