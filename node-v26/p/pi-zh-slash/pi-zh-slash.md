# pi-zh-slash

> 标签: autocomplete, chinese, i18n, ime, pi-extension, pi-package, slash, 顿号

## 简介

Chinese slash commands for Pi: type 、设置 instead of /settings. Aliases, IME, and autocomplete without switching input source.
