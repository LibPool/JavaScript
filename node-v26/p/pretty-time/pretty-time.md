# pretty-time

> 标签: convert, date, format, formatting, hour, hrtime, micro, milli, minute, nano, nanosecond, pretty, second, time, week

## 简介

Easily format the time from node.js `process.hrtime`. Works with timescales ranging from weeks to nanoseconds.
