# pi-branch-context

> 标签: branch, context, extension, git, pi, pi-coding-agent, pi-package, scope

## 简介

Keeps LLM work scoped to the current git branch: injects a branch scope context file (.pi/branches/<branch>.md) into the prompt and gates out-of-scope implementation work behind a blocking user choice dialog.
