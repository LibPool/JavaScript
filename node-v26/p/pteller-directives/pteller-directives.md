# pteller-directives

> 标签: JavaScript

## 简介

手输数据后进行自动补全,可向左插入补全或者向右插入补全, ### 使用方法:          在input上使用 v-autoCompletion="{value:'a',digit:8,alignment:0}" ### 传递参数：     v-autoCompletion="{value:'a',digit:8,alignment:0}"      v-autoCompletion="{value:0,digit:8,alignment:0}"      不传参数则写为v-autoCom
