# pyramid-sort

> 标签: attributes, formatter, imports, jsx, length, organize, pyramid, sort, tsx

## 简介

Sort your imports, attributes, types, objects & CSS by line length — short lines on top, long lines on the bottom. Clean pyramid-shaped code.
