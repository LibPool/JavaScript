# paraplex-mcp

> 标签: 3d, animation, claude, claude-code, mcp, model-context-protocol, motion design, paraplex

## 简介

Connect Claude Code (or any MCP client) to the Paraplex tab you have open: build and edit 3D motion design scenes with the assistant's tools, look at frames, export.
