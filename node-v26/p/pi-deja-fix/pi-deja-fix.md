# pi-deja-fix

> 标签: coding-agent, failed-fixes, pi, pi-extension, pi-package, regression

## 简介

Déjà-vu for failed fixes: fingerprints edits, links them to test outcomes, and blocks the agent from re-applying a fix that already failed.
