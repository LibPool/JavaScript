# payload-theme

> 标签: admin, admin-dashboard, admin-panel, admin-theme, admin-ui, branding, cms, command-palette, dark-mode, dashboard, i18n, nextjs, payload, payload-cms, payload-plugin, payload-theme, payloadcms, shadcn, theme, ui, white-label

## 简介

A shadcn-style theme for the Payload CMS admin panel — dashboard with sparklines, ⌘K command palette, grouped icon sidebar, live theme customizer, dark mode, 8 languages. One accent color, two lines of setup.
