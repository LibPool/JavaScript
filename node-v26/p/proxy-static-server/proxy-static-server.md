# proxy-static-server

> 标签: JavaScript

## 简介

proxy-static-server是一个本地静态文件代理的cli工具,通常用于 vue 项目打包后产生的静态文件即 dist 目录的代理工作,可以快捷简单的代理目标目录到指定服务器
