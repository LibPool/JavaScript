# posci-miner

> 标签: 0xbitcoin, cli, erc20, ethereum, fair-launch, miner, mining, posci, pow, proof-of-work, webgpu

## 简介

CLI miner for POSCI (Proof of Scientist) — Bitcoin-style PoW token on Ethereum mainnet. CPU + WebGPU (via headless Chrome) + hybrid modes. Anti-MEV: hash includes msg.sender.
