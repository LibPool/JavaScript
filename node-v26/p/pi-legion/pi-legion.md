# pi-legion

> 标签: agents, centurion, legion, pi, pi-extension, pi-package, rpc, subagents

## 简介

Pi Legion v2: recursive centurion trees on headless Pi RPC; shared SQLite WAL legion.db. Four-stage planning/implementing/reviewing/verifying state machine, parent/child/sibling legion_mail, three-layer /legion UI, upward MR trees, squad resume.
