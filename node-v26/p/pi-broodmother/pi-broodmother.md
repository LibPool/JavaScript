# pi-broodmother

> 标签: agent, delegation, effect, pi, pi-coding-agent, pi-extension, pi-package, subagent

## 简介

Pi extension. Delegate a batch of read-only research tasks to child agents, with dependency edges between them, a model and thinking effort you pick, and a two-way channel back to the parent.
