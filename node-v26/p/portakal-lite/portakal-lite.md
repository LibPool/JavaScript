# portakal-lite

> 标签: label, label-printer, printer, receipt, thermal-printer, tsc, tspl, typescript, zero-dependency, zpl

## 简介

Standalone TSC/TSPL2 + ZPL II label compiler with SVG preview and receipt layout helpers. Zero dependencies, no transport layer — you get a printer-ready string.
