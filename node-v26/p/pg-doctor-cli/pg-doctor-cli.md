# pg-doctor-cli

> 标签: cli, database, dba, devops, diagnostics, postgres, postgresql

## 简介

A portable Postgres diagnostic CLI: bloat, long-running queries, lock chains, connection saturation, and replication lag checks against any Postgres instance.
