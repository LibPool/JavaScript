# prime-deepseek-search

> 标签: agent-skill, deepseek, pi-package, pi-skill, prime-agent, search, skill, web-search

## 简介

Native web search for Prime Agent using DeepSeek's server side search. Kernel-callable skill (await deepseek_search), no extension tool. Install with: prime-agent package install npm:prime-deepseek-search
