# postcss-purgefonts

> 标签: compress, css, font, font-face, fontface, fontmin, fonts, glyph, glyphs, icon, icon-font, iconfont, minify, postcss, postcss-plugin, purgefonts, web-font, webfont

## 简介

PostCSS plugin PurgeFonts to minimize the size of font files by removing unused font glyphs from fonts, especially icon fonts such as FontAwesome
