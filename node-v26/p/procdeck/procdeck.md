# procdeck

> 标签: cli, dev-server, multiplexer, process-manager, pty, reverse-proxy, terminal, xterm

## 简介

Interactive dev-process multiplexer with a web UI: terminal panes in a browser tab, declarative dependencies, assigned ports and a *.localhost reverse proxy.
