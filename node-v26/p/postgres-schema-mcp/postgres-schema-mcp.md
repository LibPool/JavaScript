# postgres-schema-mcp

> 标签: ai, claude, database, llm, mcp, model-context-protocol, postgres, postgresql, read-only, schema

## 简介

Read-only MCP server for PostgreSQL. Browse schemas, follow foreign keys, search columns across hundreds of tables, run capped SELECTs, and export an offline data dictionary. Writes are rejected and there are tests that prove it.
