# paperclip-plugin-line

> 标签: agents, chatbot, line, line-messaging-api, paperclip, paperclip-plugin, webhook

## 简介

Bidirectional LINE Messaging API integration for Paperclip: verified webhook intake, agent sessions per LINE user, outbound LINE push tools, and inbound media relay.
