# pi-background-run

> 标签: agent, ai, background, bgrun, extension, oh-my-pi, omp, pi, pi-coding-agent, pi-package

## 简介

Run long shell commands detached in the background for pi and oh-my-pi (omp); get woken on completion. Output lands in a file; context stays clean.
