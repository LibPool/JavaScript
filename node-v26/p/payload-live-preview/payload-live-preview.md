# payload-live-preview

> 标签: astro, astro-cms, astro-integration, astro-live-preview, astro-payload, cms, framework-agnostic, headless, headless-cms, lexical, live-preview, nextjs, nuxt, payload, payload-cms, payload-live-preview, preview, react, ssr, sveltekit, vue

## 简介

Live preview for Payload CMS on server-rendered and static frontends (Astro, Next.js, SvelteKit, Nuxt, plain HTML): DOM patches, server-rendered fragments, React and Vue hooks. Strict by default, zero dependencies.
