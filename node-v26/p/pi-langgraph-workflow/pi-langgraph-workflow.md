> 标签: agent-workflow, coding-agent, extension, fan-out, fanout, langgraph, langgraph-like, orchestration, pi, pi-coding-agent, pi-extension, pi-package, workflow, workflows

## 简介

A generic Pi extension that implements LangGraph-like workflows with transitions, joins, dynamic fan-out, and configurable node runners.
