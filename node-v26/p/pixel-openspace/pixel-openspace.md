# pixel-openspace

> 标签: cron, dashboard, github-actions, launchd, monitoring, pixel-art, systemd

## 简介

Your scheduled jobs (launchd, cron, systemd timers) and GitHub Actions workflows as pixel-art workers in an open space, in your browser.
