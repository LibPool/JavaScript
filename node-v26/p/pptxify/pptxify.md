# pptxify

> 标签: JavaScript

## 简介

Convert PDF pages to high-quality image-based PPTX files in the browser or with the local CLI.

## 官网

- 官网：https://tshzhu.github.io/pptxify/
- 源码仓库：git+https://github.com/tshzhu/pptxify.git
- npm 页面：https://www.npmjs.com/package/pptxify
