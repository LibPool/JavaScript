# playwright-e2e-mcp

> 标签: accessibility, agent-skills, ai, automation, axe-core, ci, claude-code-plugin, e2e, end-to-end-testing, flaky-tests, free, gemini-cli-extension, github-action, mcp, model-context-protocol, open-source, playwright, selectors, testing, wcag

## 简介

MCP server and agent skill that run, diagnose and fix failing Playwright end-to-end tests: root-cause grouping, trace analysis, verified locator fixes, flaky and test-order verdicts, WCAG accessibility audits
