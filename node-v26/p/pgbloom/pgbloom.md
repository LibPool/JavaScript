# pgbloom

> 标签: auth, bloom-filter, cache, counters, crud, events, leader-election, locks, nodejs, orm, otp, postgres, postgresql, pubsub, queue, rate-limit, scheduler, typescript

## 简介

PGBloom is a PostgreSQL-first infrastructure toolkit for JavaScript and TypeScript providing caching, Pub/Sub, queues, distributed locks, leader election, scheduling, rate limiting, events, counters, Bloom filters, CRUD models, authentication, and OTP.
