# productcraft

> 标签: auth, email, mail, openapi, productcraft, sdk, social, waitlist

## 简介

All-in-one Node.js / TypeScript SDK for the ProductCraft platform — Auth, Mail, Waitlist, Social, Platform-Auth, and Trawl from a single import. Install per-product packages (`@productcraft/auth`, ...) if you only need one.
