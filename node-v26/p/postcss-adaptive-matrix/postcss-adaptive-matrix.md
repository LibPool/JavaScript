# postcss-adaptive-matrix

> 标签: accessibility, adaptive, clamp, component-library, container-query, design-tokens, desktop, fluid-typography, mobile, postcss, postcss-plugin, px-to-vw, responsive, viewport

## 简介

Responsive CSS compiler for PostCSS 8 with per-design canvases, optional fluid bounds, rem-aware typography, container units, component-library routing, and CLI diagnostics.
