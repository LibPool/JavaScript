# pixel-bit

> 标签: 16-bit, 8-bit, 8bit, arcade, crt, css, css-framework, design-system, game, game-ui, gamedev, pixel, pixel-art, pixel-ui, retro, retro-ui, retrogaming, ui, ui-framework

## 简介

Retro pixel-art UI framework in plain CSS. Buttons, panels, dialogue balloons, HP bars, key prompts and icons for games and 8-bit style sites. Zero dependencies, themeable with CSS variables.
