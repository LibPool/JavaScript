# pageboy

> 标签: claude-code, cross-encoder, embeddings, fts5, mcp, model-context-protocol, rag, readability, reranker, sqlite, sqlite-vec

## 简介

Turn any web article into a queryable MCP server. SQLite + FTS5 + optional local embeddings and cross-encoder reranking.
