# permaura

> 标签: agents, ai, capabilities, gateway, mcp, permaura, permissions, security

## 简介

Run the Permaura gateway with one command. Give your AI agents permission, not keys. `npm i -g permaura` then `permaura start --pair <code>` installs the gateway, starts it, and connects it to your permaura.com account.
