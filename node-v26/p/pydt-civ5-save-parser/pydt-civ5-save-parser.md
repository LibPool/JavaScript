# pydt-civ5-save-parser

> 标签: Civ5, file, parser, save

## 简介

Civ5 save file parser allows you to parse out the useful information of a civ5 save file to read which turn it is, which player is up, and which civs are playing as well as modify the player's password and AI/Human setting.
