# pi-auto-name-session

> 标签: extension, naming, pi, pi-coding-agent, pi-extension, pi-package, session, session-name

## 简介

Automatically names Pi sessions from the first user prompt by having the agent itself call a name_session tool, so an unnamed session gets a short descriptive title without a separate model request.
