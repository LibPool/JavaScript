# parallax-designer-mcp

> 标签: ai-tools, mcp, model-context-protocol, parallax, parallax-designer, parallax-scene

## 简介

MCP server that lets any AI assistant turn a website/section into a Parallax Designer scene, open it in the editor, and read it back

- 官网：https://www.parallaxdesigner.com
