# pi-secret

> 标签: api-keys, credentials, env, masked-input, pi, pi-extension, pi-package, redaction, secrets, security, tokens

## 简介

Keep API keys, tokens and passwords out of the model's context: the agent uses {{sec:NAME}} refs, the value is expanded only for the command that needs it.
