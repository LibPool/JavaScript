# pretty-toc-alpha

> 标签: TOC, Table of Contents, markdown, plugin, satteri

## 简介

A Table of Contents generation plugin for the Satteri markdown parser library. This package serves as a pre-release test for pretty-toc. Please install pretty-toc for the stable version.
