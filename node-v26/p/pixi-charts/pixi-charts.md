# pixi-charts

> 标签: charting, charts, d3, data-visualization, dataviz, heatmap, performance, pixi, pixijs, scatter, streaming, typescript, visualization, webgl

## 简介

A WebGL-rendered TypeScript charting library built on PixiJS and D3 submodules. Renders tens of thousands of points at 60fps and stays interactive at 100k+ where Canvas-based libraries stall.
