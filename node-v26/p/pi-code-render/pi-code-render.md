# pi-code-render

> 标签: code-blocks, code-rendering, coding-agent, pi, pi-coding-agent, pi-extension, pi-package, terminal-ui, tui

## 简介

Render fenced code blocks in Pi's transcript as styled, flush-edge cards with one-click copy and a raw-text toggle.
