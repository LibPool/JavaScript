# pragmasearch

> 标签: algolia-alternative, e-commerce, embeddings, hybrid-search, local-first, react, search, semantic-search, transformers.js, vector-search

## 简介

Open-source local-first semantic search engine. Drop in a products JSON, get hybrid (keyword + meaning) search with zero cloud, zero API keys, $0.
