# polytheme

> 标签: css, css-variables, custom-properties, dark-mode, design-system, design-tokens, postcss, postcss-plugin, tailwind, tailwindcss, theme, theming

## 简介

A Tailwind-first PostCSS plugin that turns a single line of CSS into every theme — light, dark, brand, and beyond.
