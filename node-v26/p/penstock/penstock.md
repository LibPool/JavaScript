# penstock

> 标签: backend, compensation, orchestration, pipeline, rollback, saga, steps, typescript, workflow

## 简介

Composable, testable backend workflows for Node.js — use-cases, pipelines, steps, and engines, with first-class reverse-order rollback. Zero runtime dependencies.
