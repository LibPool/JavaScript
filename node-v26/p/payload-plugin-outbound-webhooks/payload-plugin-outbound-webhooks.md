# payload-plugin-outbound-webhooks

> 标签: cms, payload, payload-plugin, payloadcms, webhooks

## 简介

Generic outbound webhooks for Payload CMS: fire signed HTTP callbacks on collection create/update/delete, delivered durably via the Jobs Queue.
