# pi-request-stats

> 标签: compaction, cost, pi, pi-coding-agent, pi-package, pricing, stats, throughput, timing, tokens-per-second

## 简介

Pi extension reporting per-request time split into thinking/answer/tool-call generation vs tool execution, per-phase tokens-per-second, compaction counts, and estimated request cost.
