# postcss-pseudo-hover

> 标签: any-hover, any-pointer, css, feature, hover, media, media-feature, pointer, postcss, postcss-any-hover-media-feature, postcss-hover, postcss-hover-media-feature, postcss-plugin, postcss-plugin-any-hover, postcss-plugin-hover, postcss-pseudo-any-hover, postcss-pseudo-hover, query, touch

## 简介

PostCSS plugin that extracts and wraps rules containing `:any-hover` pseudo-classes in `@media (any-hover: hover) {}` media queries
