# payload-plugin-mcp

> 标签: ai, anthropic, claude, cms, headless-cms, mcp, model-context-protocol, payload, payload-plugin, payloadcms, plugin

## 简介

A PayloadCMS plugin that integrates with MCP (Model Context Protocol) to enable AI model communication and context sharing within PayloadCMS applications
