# pi-web-research

> 标签: kagi, llms-txt, pi, pi-extension, pi-package, readability, web-research, web-search, wyna

## 简介

Token-saving web research for the pi coding agent — a sub-agent pipeline distills search results and pages into cited briefings instead of dumping them into context. Kagi + Wyna backends, SSRF-guarded, privacy-focused.
