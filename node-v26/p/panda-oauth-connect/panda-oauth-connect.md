# panda-oauth-connect

> 标签: JavaScript

## 简介

`panda-oauth-connect` 是一个用于 `pandabuy` 平台的 OAuth 授权连接库，它提供了一种简单的方式来集成授权登录功能到您的 Web 应用中。
