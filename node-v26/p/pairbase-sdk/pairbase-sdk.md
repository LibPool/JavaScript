# pairbase-sdk

> 标签: chainlink, ethers, launchpad, robinhood-chain, synthetics, uniswap-v2

## 简介

Client SDK for Pairbase on Robinhood Chain: launchpad, Uniswap V2-compatible pools, backed-asset vault, and Chainlink-priced synthetics.
