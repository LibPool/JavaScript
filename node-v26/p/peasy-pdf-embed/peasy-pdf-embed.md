# peasy-pdf-embed

> 标签: compress, convert, document, embed, merge, pdf, peasy, peasypdf.com, shadow-dom, split, widget, zero-dependencies

## 简介

Embed PeasyPDF widgets on any website. Lightweight (<8KB gzipped), zero dependencies, Shadow DOM isolation, 3 themes.

- 官网：https://widget.peasypdf.com
