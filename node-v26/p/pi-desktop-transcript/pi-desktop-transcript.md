# pi-desktop-transcript

> 标签: activity, coding-agent, compact, pi, pi-coding-agent, pi-extension, pi-package, preset, transcript, tui

## 简介

Configurable desktop-style process view for the Pi coding agent: four presets from focus to native, per-tool display rules, a live activity area and a compact process summary.
