# pi-everything

> 标签: everything, extension, file-search, index, local-first, pi, pi-coding-agent, pi-package, search, windows

## 简介

Instant machine-wide file search for the pi coding agent on Windows — native tools (search, content grep, folder size, syntax reference, status) backed by the Everything index via es.exe
