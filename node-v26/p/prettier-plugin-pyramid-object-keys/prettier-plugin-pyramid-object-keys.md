# prettier-plugin-pyramid-object-keys

> 标签: interfaces, object-keys, prettier, prettier-plugin, pyramid, sort-keys, typescript

## 简介

Prettier plugin that arranges object keys, interface properties, and destructuring in pyramid order (shortest first, longest last)
