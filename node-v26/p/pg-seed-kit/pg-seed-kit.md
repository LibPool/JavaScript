# pg-seed-kit

> 标签: database, drizzle, migration, orm, postgres, postgresql, prisma, seed, seeder, sequelize, toolkit, typeorm

## 简介

A lightweight, zero-dependency seeder toolkit for Postgres that works with Prisma, Drizzle, TypeORM, and Sequelize.
