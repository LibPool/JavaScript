## 简介

Fast zero-dependency Persian (Jalali / Shamsi) date engine for JavaScript and TypeScript with browser script tags, CDN, React, Next.js, Vue, Angular, Svelte, jQuery, Laravel, WordPress, and Day.js plugin support.
