# p6-barrier

> 标签: cdk

## 简介

P6Barrier is an `AWS CDK Construct` that deploys a `Custom Resource` which will poll until `AWS Lambda Function` `isReady` returns true. Ideal for running code AFTER an `RDS` or `EKS` is ready.
