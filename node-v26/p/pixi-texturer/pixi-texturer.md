# pixi-texturer

> 标签: displayobject, graphics, packing, pixi, pixijs, render-texture, spritesheet, text, texture-atlas

## 简介

Pack multiple DisplayObjects into one texture atlas for PixiJS — like a spritesheet from dynamic content.
