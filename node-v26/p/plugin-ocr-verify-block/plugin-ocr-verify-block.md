# plugin-ocr-verify-block

> 标签: block, ocr, pdf, pdfjs, verify

## 简介

Verify OCR JSON data against PDF attachments with PDF.js, editable OCR fields, accept/reject actions, history, callback, API, and future Skill Hub integration.
