# prettier-plugin-tailwind-variants

> 标签: class-sorting, formatting, prettier, prettier-plugin, tailwind, tailwind-variants, tailwindcss, variants

## 简介

A Prettier plugin for Tailwind Variants that formats class arrays while preserving structure, then sorts them with prettier-plugin-tailwindcss
