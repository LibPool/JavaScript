# pageturn

> 标签: animation, astro, astro-integration, cross-document-view-transitions, morph, mpa, multi-page, navigation, no-dependencies, page-transition, page-transitions, shared-element-transition, transitions, vanilla-js, view-transition-api, view-transitions

## 简介

Page transitions between real page loads, in every browser: a default move, moves named in CSS or written in code, a picture that morphs into the next page, and returns on Back. No router, no swapped DOM.
