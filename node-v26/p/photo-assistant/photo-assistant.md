# photo-assistant

> 标签: CSS filters, CSS grid gallery, draw image to canvas element, filter images, image editing, image gallery, image handler, image storage, photo editing, photo filter, photo gallery, photo sorting, photo storage

## 简介

Photo Assistant is a dependency-free, lightweight library that offers simple photo editing, sorting (by alphabetical order), storage, canvas creation and gallery displaying functionality for HTML img elements.
