# preactjs-pdf

> 标签: pdf, pdf creator, pdf renderer, preact-pdf, preactjs-pdf, react-pdf

## 简介

这是一个 Preact 库，用于通过基于组件的方法创建 PDF 文档，类似于 @react-pdf/renderer。
