# password-crack-time

> 标签: argon2, bcrypt, brute-force, crack-time, entropy, gpu, hashcat, keyspace, ntlm, password, security, sha256, zero-dependency

## 简介

Zero-dependency password strength engine. Compute keyspace, entropy (bits), and average crack time across 6 algorithms and 5 hardware tiers with real GPU benchmarks. All math runs client-side — no server, no tracking.
