# penpal

> 标签: communication, iframe, iframes, message-channel, message-port, port, postMessage, promise, service-worker, service-workers, shared-worker, shared-workers, web-worker, web-workers, window, windows, worker, workers

## 简介

Penpal simplifies communication with iframes, workers, and windows by using promise-based methods on top of postMessage.
