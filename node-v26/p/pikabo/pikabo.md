# pikabo

> 标签: automation, chrome-extension, manifest-v3, mcp, playwright, testing

## 简介

Automated testing for Chrome extensions — loads unpacked extensions into a real browser, drives popup/options/content scripts/service worker, and generates reports with screenshots.
