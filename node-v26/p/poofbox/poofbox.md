# poofbox

> 标签: cypress, disposable-email, e2e, email, email-testing, inbox, magic-link, mcp, otp, playwright, temp-mail, temporary-email, testing, verification-code

## 简介

Disposable inboxes for tests and AI agents: create an address, wait for the verification email, get the code or link. Client for Poofbox Mail (poofboxmail.com).

## 官网

- 官网：https://poofboxmail.com/playwright-email-testing
- npm 页面：https://www.npmjs.com/package/poofbox
