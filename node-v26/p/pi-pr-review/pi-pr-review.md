# pi-pr-review

> 标签: ai-code-review, ai-review, automation, code-quality, code-review, code-reviewer, developer-tools, github, github-pr, llm, multi-agent, parallel, pi, pi-coding-agent, pi-extension, pi-package, pr-review, pull-request, pull-request-review, review, subagents

## 简介

Parallel AI code review for GitHub pull requests in the Pi coding agent, with model-agnostic tiered subagents, structured findings, optional verification, and host-gated COMMENT or qualified APPROVE publishing.
