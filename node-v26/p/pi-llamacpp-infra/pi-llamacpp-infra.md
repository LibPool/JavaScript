# pi-llamacpp-infra

> 标签: discovery, llama.cpp, llamacpp, lm-studio, lmstudio, local-models, metrics, pi-package, tailscale, thinking, vision

## 简介

Discovery, metrics and control of llama.cpp-family servers for pi (llama.cpp, ZINC, DwarfStar/ds4, lucebox, LM Studio): scan machines (localhost, LAN, Tailscale), register models, live metrics, per-model thinking budgets, vision detection, native config U
