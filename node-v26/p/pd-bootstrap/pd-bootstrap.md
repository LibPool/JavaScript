# pd-bootstrap

> 标签: JavaScript

## 简介

This is a very thin wrapper around the React Bootstrap library (https://react-bootstrap.github.io/) so you can use Bootstrap inside [Pagedraw](https://pagedraw.io).

## 官网

- npm 页面：https://www.npmjs.com/package/pd-bootstrap
