# peeky-search

> 标签: ai-search, bm25, claude, content-extraction, cursor, html-extraction, information-retrieval, mcp, mcp-server, model-context-protocol, searxng, web-search

## 简介

MCP server for web search that returns verbatim passages from sources instead of summaries. Passage-level ranking with source authority, no LLM in the loop.
