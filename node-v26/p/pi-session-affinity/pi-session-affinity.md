# pi-session-affinity

> 标签: ai-agents, coding-agent, kv-cache, litellm, llm, pi, pi-coding-agent, pi-extension, pi-package, prefix-cache, prompt-caching, session-affinity, vllm

## 简介

Faster pi on self-hosted and gateway-routed models: keeps each conversation on the inference engine that holds its prompt cache with a per-session routing header, plus an optional post-compaction boundary request.
