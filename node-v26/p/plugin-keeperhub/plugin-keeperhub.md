# plugin-keeperhub

> 标签: agent, ai-agent, dry-run, eliza, elizaos, ethereum, evm, human-in-the-loop, idempotency, keeperhub, onchain, plugin, web3

## 简介

Deterministic onchain execution for ElizaOS agents. The agent composes and dry runs; a human approves; KeeperHub executes the exact reviewed plan.
