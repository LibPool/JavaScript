# pageindex

> 标签: ai, bun, deno, document, information-retrieval, llm, markdown, multi-runtime, nodejs, ocr, openai, pageindex, pdf, rag, reasoning, retrieval, tree-index, vectorless

## 简介

Vectorless, reasoning-based RAG for document understanding. Multi-runtime (Node.js, Bun, Deno). PDF and Markdown support with OCR.
