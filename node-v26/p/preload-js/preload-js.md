# preload-js

> 标签: createjs, preload, preloadjs, webpack

## 简介

PreloadJS for webpack, PreloadJS makes preloading assets & getting aggregate progress events easier in JavaScript. It uses XHR2 when available, and falls back to tag-based loading when not. http://createjs.com/
