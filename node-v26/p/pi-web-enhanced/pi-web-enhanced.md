# pi-web-enhanced

> 标签: anysearch, brave, duckduckgo, exa, extension, fetch, firecrawl, pi, pi-coding-agent, pi-package, querit, scraping, serpapi, tavily, tinyfish, web-search

## 简介

Web search, URL fetching, GitHub repo cloning, and local PDF extraction for Pi coding agent. Supports Exa, Tavily, AnySearch, TinyFish, SerpApi, Firecrawl, Brave, Querit, and DuckDuckGo, with weighted-provider balanced search and all-provider enhanced sea
