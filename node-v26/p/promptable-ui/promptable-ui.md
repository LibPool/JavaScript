# promptable-ui

> 标签: ai, dashboard, data-visualization, generative-ui, llm, mcp, natural-language, prompt, react, recharts, widgets

## 简介

AI-customizable dashboard widgets for React. Users describe what they want in natural language; your LLM or MCP server returns a WidgetConfig; the package renders it. Bring your own LLM.
