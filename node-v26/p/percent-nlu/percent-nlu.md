# percent-nlu

> 标签: browser, calculator, intent-classification, machine-learning, natural-language, nlp, nlu, offline, on-device, percent, percentage, percentage-calculator, porcentagem, porcentaje, tiny-model, tool-calling, transformer

## 简介

Tiny on-device model that understands percentage questions in English, Portuguese and Spanish and returns the right calculator tool call. Runs in the browser in ~1 ms, no server.
