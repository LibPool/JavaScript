# pi-doc-review

> 标签: ai, claude-code, codex, document-review, glimpse, markdown, pi, pi-coding-agent, pi-package, review, slash-command

## 简介

Native Markdown document review window for AI coding agents (pi, Claude Code, Codex CLI). Opens a Glimpse window that renders Markdown, lets the user leave selection and document comments, edit the raw Markdown, and returns feedback to the agent.
