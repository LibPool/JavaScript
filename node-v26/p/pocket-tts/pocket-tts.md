# pocket-tts

> 标签: cpu, kyutai, onnx, pocket-tts, speech-synthesis, streaming, text-to-speech, tts, voice-cloning

## 简介

Streaming Pocket TTS for Node.js — cloud mode (Kyutai API, 24 built-in voices) and local mode (ONNX runtime with zero-shot voice cloning).
