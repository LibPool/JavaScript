# plugin-syndicate

> 标签: agent-gameplay, ai-agents, eliza, elizaos, elizaos-plugin, game, oracle-api, strategy, tcg, the-syndicate, trading-cards, undesirables

## 简介

Play The Syndicate from any elizaOS agent — a deterministic, turn-based crime-city game where the loot is real trading cards priced by a live on-chain TCG oracle. Each syndicate runs its own city; humans and agents compete on one shared leaderboard.
