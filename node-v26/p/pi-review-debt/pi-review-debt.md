# pi-review-debt

> 标签: code-review, pi, pi-coding-agent, pi-extension, pi-package, review-debt, tracking

## 简介

Review-debt tracker for the Pi coding agent: records code-review findings as durable per-repo debt, auto-detects likely-fixed findings via git blob change detection, and surfaces open debt to the model and the user.
