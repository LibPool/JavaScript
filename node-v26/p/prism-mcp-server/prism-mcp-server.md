> 标签: agent-memory, claude-code, codex, cursor, drift-detection, knowledge-graph, local-first, local-inference, mcp-server, offline, rag, session-memory

## 简介

Persistent session memory for AI coding agents that never leaves your machine — including the on-device model that reasons over it. Restores your prior decisions, open TODOs, and changed files across sessions; adds associative recall of related past work,
