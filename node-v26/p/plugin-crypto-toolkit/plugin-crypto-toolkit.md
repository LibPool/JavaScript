# plugin-crypto-toolkit

> 标签: Security, certificate, crypto, encryption, pgp, signature

## 简介

Generate and manage crypto keys (PGP, RSA, Ed25519, SSH), encrypt/decrypt/sign/verify files through file manager, create CSR and self-signed X.509 certificates. Private keys are stored as NocoBase secret environment variables.
