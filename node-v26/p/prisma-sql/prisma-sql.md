# prisma-sql

> 标签: cloudflare, d1, generator, optimizer, performance, postgresql, prisma, query, sql, sqlite, typescript

## 简介

Prerender Prisma queries to SQL and run them through postgres.js or better-sqlite3. Same Prisma API and types, lower read overhead.
