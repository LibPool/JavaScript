# pingtrace

> 标签: cli, network, network diagnostics, network engineering, network tools, network troubleshooting, ping, traceroute

## 简介

A terminal-first CLI designed for rapid network troubleshooting, combining ping and traceroute with a clear, intuitive output enriched by DNS and ipinfo.io data.
