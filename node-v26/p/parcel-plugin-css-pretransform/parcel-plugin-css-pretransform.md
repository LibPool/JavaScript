# parcel-plugin-css-pretransform

> 标签: JavaScript

## 简介

Modify parcel to transform CSS assets earlier, before imports, enabling bundle-wide transforms with postcss-imports

- 官网：https://github.com/sj26/parcel-plugin-css-pretransform
