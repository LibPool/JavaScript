# postale-mcp

> 标签: ai, claude, codex, email, email-hosting, llm, mcp, model-context-protocol, postale, postale.io

## 简介

MCP server for the postale.io email hosting API — manage domains, mailboxes, aliases, DNS/DKIM, branding and logs from any MCP-compatible AI agent.
