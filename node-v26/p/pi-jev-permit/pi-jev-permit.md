# pi-jev-permit

> 标签: approval, gate, jev, permission, pi-coding-agent, pi-extension, pi-package, security, typesafe

## 简介

A Jev (TypeSafe System One) permission gate for the Pi coding agent: it judges every bash / write / edit call before it runs, behind a config allow/deny floor and a local read-only fast path.
