# pmc-dashboard-designer

> 标签: JavaScript

## 简介

大屏渲染底座与可视化设计器组件库，基于 Vue 3 + TypeScript 构建。   提供产线布局画布、区域渲染、流程连线、统计卡片、文本标注及 JSON 可视化配置编辑器等组件，**不含任何业务逻辑（HTTP/SignalR）**，可作为纯 UI 底座嵌入任意项目。
