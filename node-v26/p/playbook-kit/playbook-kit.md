# playbook-kit

> 标签: agent-skills, ai-enablement, chatgpt, claude-code, codex, copilot, cursor, gemini, playbooks, prompts

## 简介

Write a team playbook once, run it in every AI assistant: Claude Code, Codex, GitHub Copilot, Cursor, Gemini CLI, ChatGPT and Microsoft 365 Copilot. No server, no API key.
