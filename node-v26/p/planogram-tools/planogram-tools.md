# planogram-tools

> 标签: cabinet, editor, npx, planogram, retail, shelf

## 简介

可视化编辑/生成卧柜(chest cabinet) planogram JSON 的 npx 工具：定义柜体尺寸 → 划分列(shelf) → 划分 basket → 填充 products(skuId)，支持双向导入渲染与手动调整。
