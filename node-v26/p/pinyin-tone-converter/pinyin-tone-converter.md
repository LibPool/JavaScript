# pinyin-tone-converter

> 标签: JavaScript

## 简介

A simple Javascript plugin to convert pinyin with numbers to tone marks. This plugin is based on the [Quizlet Pinyin Converter](https://github.com/quizlet/pinyin-converter)

## 官网

- npm 页面：https://www.npmjs.com/package/pinyin-tone-converter

- 1.0.0

- npm registry：https://registry.npmjs.org/pinyin-tone-converter
