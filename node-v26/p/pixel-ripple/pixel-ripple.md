# pixel-ripple

> 标签: animation, pixel, reactjs, ripple, style, text, ui, web

## 简介

A zero-dependency, lightweight HTML5 Canvas framework that converts typography into interactive retro pixel-grids. Features real-time spring physics, ambient neon glow, custom glyph registration, and CRT scanline emulation—configured entirely via HTML dat
