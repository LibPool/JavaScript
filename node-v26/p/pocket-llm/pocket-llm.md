# pocket-llm

> 标签: browser, llm, on-device, prompt-api, wasm, webgpu, webllm, wllama

## 简介

On-device LLM sessions for any browser — Chrome's Prompt API, WebLLM, or wllama, picked by feature detection, smallest model first.
