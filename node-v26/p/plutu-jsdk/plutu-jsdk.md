# plutu-jsdk

> 标签: adfali, gateway, libya, payment, plutu, sadad, sdk, tlync, أدفع_لي, سداد, ليبيا

## 简介

The official-like simplified SDK for Plutu.ly payment gateway in Libya. Supports Sadad, Adfali, Cards, and T-Lync.
