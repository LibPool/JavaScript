# prozorro-sale-mcp-server

> 标签: auctions, claude, mcp, model-context-protocol, open-data, privatization, prozorro, prozorro-sale, ukraine

## 简介

Read-only MCP server for Prozorro.Sale — search, inspect and analyse Ukrainian state asset auctions (privatisation, land, lease, timber, subsoil, arrested assets)
