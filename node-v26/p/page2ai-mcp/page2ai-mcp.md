# page2ai-mcp

> 标签: ai, claude, html-to-markdown, llm, markdown, mcp, model-context-protocol, page2ai, webpage-to-markdown

## 简介

npx wrapper for @page2ai/mcp — MCP server that converts any web page to clean Markdown. Processing is local and SSRF-guarded; no external APIs, no telemetry.
