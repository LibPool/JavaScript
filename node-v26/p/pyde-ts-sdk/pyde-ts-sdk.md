# pyde-ts-sdk

> 标签: blockchain, commit-reveal, falcon-512, layer-1, mev-resistant, mysticeti, post-quantum, pyde, pyde-network, pyde-ts-sdk, sdk, typescript, wasmtime, webassembly

## 简介

TypeScript SDK for Pyde — the blockchain network. Connects dapps, wallets, indexers, and backend services to a Pyde node. Post-quantum crypto via pyde-crypto-wasm; type-safe ABI; wallet adapter pattern.
