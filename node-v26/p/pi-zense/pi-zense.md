# pi-zense

> 标签: agent, harness, pi, pi-package, signature, theme, zense

## 简介

Spec-gated, human-signed SDLC harness for pi (zense = a pun on the Thai word for sign) — sub-agents, dual eval, escalation gates — plus the Zense dark theme.
