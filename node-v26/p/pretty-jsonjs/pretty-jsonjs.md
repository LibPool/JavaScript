# pretty-jsonjs

> 标签: JavaScript

## 简介

Pretty JSON is a JSON to HTML Library, it can be used to 📊 display data from json file or data from an API without directly typing HTML.

## 官网

- npm 页面：https://www.npmjs.com/package/pretty-jsonjs

- npm registry：https://registry.npmjs.org/pretty-jsonjs
- Node 要求：>=10
