# p5-server

> 标签: creative coding, live reload, p5, p5.js, web server

## 简介

p5.js development server with live reload, automatic library inclusion, and airplane mode, with CLI to create sketch files.

## 官网

- 官网：https://osteele.github.io/p5-server/
- 源码仓库：git+https://github.com/osteele/p5-server.git
