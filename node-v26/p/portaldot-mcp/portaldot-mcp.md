# portaldot-mcp

> 标签: ai-agent, blockchain, claude, mcp, model-context-protocol, polkadot, portaldot, substrate, web3

## 简介

The first MCP server for Portaldot — 34 onchain tools (balances, transfers, tokens, staking, identity, contracts) for the Portaldot Substrate chain, over stdio for any MCP client (Claude Code, Cursor, Claude Desktop).
