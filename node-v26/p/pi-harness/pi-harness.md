# pi-harness

> 标签: agent, ai, pi-coding-agent, pi-harness, server, sse

## 简介

The top-level harness for the Pi ecosystem. Run pi-coding-agent and other Pi packages headlessly as a background HTTP/SSE server. Built with gratitude for Mario Zechner's pi-mono.
