# pi-cc-shim

> 标签: anthropic, anyrouter, claude-code, pi-extension, pi-package, relay

## 简介

🛂 Use Claude models in pi through relays that only accept Claude Code traffic (e.g. anyrouter). In-process request shim, no proxy.
