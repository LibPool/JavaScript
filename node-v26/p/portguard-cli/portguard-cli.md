# portguard-cli

> 标签: available-port, cli, developer-tools, eaddrinuse, free-port, kill-port, port, port-checker, port-finder, port-killer, port-range, port-scanner, range-scanner

## 简介

A lightweight Node.js utility and CLI tool that detects busy ports, finds available ports, and optionally kills blocking processes.
