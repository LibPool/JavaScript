# payzu-mcp-pix

> 标签: ai-tools, antigravity, bacen, brl, claude, claude-code, cursor, fintech, gemini, mcp, model-context-protocol, payzu, pix

## 简介

MCP server for PayZu Pix Processamento API. 29 tools: Pix charges, withdrawals, transfers, callbacks, MED infractions. Works with Antigravity, Claude Code, Claude Desktop, Cursor, Windsurf.
