# persian-holidays

> 标签: calendar, events, gregorian, hijri, holidays, iran, jalali, persian

## 简介

A unified calendar events engine for Persian, Islamic, and international dates, providing bilingual event data(English & Persian), holiday classification, and a powerful query system for fixed and relative events.
