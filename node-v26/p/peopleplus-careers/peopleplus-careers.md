# peopleplus-careers

> 标签: ats, careers, jobs, peopleplus, recruitment, sdk

## 简介

Framework-agnostic TypeScript client for the PeoplePlus Public Careers API. List jobs, show a job, and submit applications. Zero runtime dependencies.
