# prompt-injections

> 标签: ai-security, injection, input-validation, jailbreak, llm, llm-security, owasp, prompt-injection, prompt-injections, rag, sanitization, sanitize, security, security-scanner

## 简介

Catch prompt injection attacks in text: a zero-dependency, extensible scanner for instruction override, role hijack/jailbreaks, data exfiltration, fake delimiters, indirect injection and encoded/obfuscated payloads
