# pi-agy-mode

> 标签: agy, antigravity, gemini, pi, pi-package

## 简介

Antigravity (agy) mode for pi: agy-style system prompt and tool names (view_file, run_command, manage_task, schedule, ...) for Gemini models, with native background tasks and timers
