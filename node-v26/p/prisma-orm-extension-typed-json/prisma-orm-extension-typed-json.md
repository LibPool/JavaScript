# prisma-orm-extension-typed-json

> 标签: extension, json, jsonb, postgres, prisma, prisma-8, prisma-json-types-generator, typed-json, typescript

## 简介

Typed JSON and typed text columns for Prisma 8 with no validator dependency. The prisma-json-types-generator idea, as a Prisma 8 extension.
