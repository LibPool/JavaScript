# pi-md-reader

> 标签: docs, markdown, pager, pi, pi-extension, pi-package, reader, tui

## 简介

Read Markdown files inside Pi with a paged overlay reader: contents panel, search, scrollbar, and reload — rendered with Pi's own Markdown theme.
