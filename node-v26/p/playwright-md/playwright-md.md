# playwright-md

> 标签: acceptance-testing, bdd, e2e, gauge, markdown, playwright, spec, test-runner, testing

## 简介

Write Playwright tests as readable Markdown specs. A lightweight, Gauge-flavored spec layer on top of the Playwright test runner.
