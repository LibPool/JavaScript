# payapi-noodlejs

> 标签: JSONSelect, cross domain, cross-domain, html, json, proxy, rate limit, scraper, selectors, web service

## 简介

noodle is a proxy server which serves for cross domain data extraction from web documents for any client. This is forked from git://github.com/dharmafly/noodle.git solely to make dependency security upgrades.
