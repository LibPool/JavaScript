# @demonbloodx2/bricks

> 标签: loading-bar, navigation-progress, nextjs, pwa, react, router-agnostic, service-worker, update-prompt

## 简介

Small React parts that attach to an app you already have: a progress bar under the header while a page loads, and a prompt when a new build is deployed. No framework, no dependencies.
