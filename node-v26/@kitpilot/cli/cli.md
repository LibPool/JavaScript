# @kitpilot/cli

> 标签: ai, byok, cli, coding-agent, copilot, llm

## 简介

KitPilot — a model-agnostic CLI AI coding agent. BYOK by default, with an optional bridge that borrows GitHub Copilot from a running VS Code host.
