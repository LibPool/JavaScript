# dsh-time-reminder

> 标签: clock, cordis, cron, deepseek-harness, dsh, plugin, reminder, timer

## 简介

DSH 插件：可调精度的时钟上下文（off/cron/turn/fine）+ 会话内计时器（可见性可跨父子代理） + 跨重启可用倒计时器
