# @alpic80/rivet-ai-sdk-provider

> 标签: ai, rivet

## 简介

This is the [Rivet](https://rivet.ironcladapp.com) provider for the [Vercel AI SDK](https://sdk.vercel.ai/docs) giving you access to run your Rivet Graphs as a supported LM.
