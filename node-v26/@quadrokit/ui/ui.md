# @quadrokit/ui

> 标签: JavaScript

## 简介

Shared **React** UI for QuadroKit templates: Tailwind **preset**, global **CSS variables** (light/dark + theme presets), and a few **shadcn-style** primitives (Radix Slot, CVA, `cn()`).
