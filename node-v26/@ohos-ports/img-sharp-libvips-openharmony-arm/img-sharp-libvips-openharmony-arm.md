# @ohos-ports/img-sharp-libvips-openharmony-arm

> 标签: JavaScript

## 简介

Natively compiled libvips 8.18.3 for use with sharp on OpenHarmony (musl) 64-bit ARM, built from source for aarch64-unknown-linux-ohos with OHOS clang
