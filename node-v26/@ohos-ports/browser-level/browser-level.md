# @ohos-ports/browser-level

> 标签: abstract-level, harmonyos, indexeddb, level, leveldb, ohos-ports, openharmony

## 简介

An abstract-level database for browsers, backed by IndexedDB. Ported to HarmonyOS (openharmony): injects the fake-indexeddb polyfill when the runtime lacks a global IndexedDB API (e.g. Node.js on HarmonyOS), so databases work out of the box.
