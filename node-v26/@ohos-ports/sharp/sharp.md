# @ohos-ports/sharp

> 标签: avif, crop, dzi, embed, gif, image, jp2, jpeg, libvips, png, resize, svg, thumbnail, tiff, vips, webp

## 简介

High performance Node.js image processing, the fastest module to resize JPEG, PNG, WebP, GIF, AVIF and TIFF images [ohos-ports: openharmony-arm64 native (libvips 8.18.3) + soname-variant/RPATH symlink self-healing]
