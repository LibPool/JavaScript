# @ohos-ports/rust-verkle-wasm

> 标签: JavaScript

## 简介

WebAssembly verkle cryptography primitives (bandersnatch/fr) for HarmonyOS Node.js, with JS glue fixes for fr_sqrt (Tonelli-Shanks) and commit_scalar_values input normalization
