# @ohos-ports/img-sharp-libvips-openharmony-x64

> 标签: JavaScript

## 简介

Prebuilt libvips and dependencies for use with sharp on OpenHarmony arm64 (compiled from libvips 8.18.6 source with OHOS SDK clang)
