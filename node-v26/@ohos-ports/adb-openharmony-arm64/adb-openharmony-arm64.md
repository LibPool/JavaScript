# @ohos-ports/adb-openharmony-arm64

> 标签: adb, arm64, binary, harmonyos, openharmony

## 简介

Android adb binary for OpenHarmony (aarch64), self-compiled from smaeul/android-tools with OHOS clang 15. Self-contained: bundles libcrypto.so.4 + libc++_shared.so resolved via $ORIGIN/lib RUNPATH.
