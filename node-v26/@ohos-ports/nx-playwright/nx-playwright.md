# @ohos-ports/nx-playwright

> 标签: Angular, CLI, Front-end, Jest, Monorepo, Nest, Node, Playwright, React, Testing, Web

## 简介

The Nx Plugin for Playwright contains executors and generators allowing your workspace to use the powerful Playwright integration testing capabilities. (OpenHarmony port of @nx/playwright)
