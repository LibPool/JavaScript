# @ohos-ports/dynatrace-react-native-plugin

> 标签: android, dynatrace, ios, mobile, monitoring, performance, react-native

## 简介

This plugin gives you the ability to use the Dynatrace Mobile agent in your react native application. (HarmonyOS port)
