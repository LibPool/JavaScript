# @ohos-ports/rspress-plugin-auto-nav-sidebar

> 标签: JavaScript

## 简介

A plugin for rspress to generate navbar and sidebar config automatically. (HarmonyOS/openharmony-arm64 native port: real @rspack/binding@1.3.12 compiled for openharmony-arm64)
