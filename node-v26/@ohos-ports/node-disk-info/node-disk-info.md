# @ohos-ports/node-disk-info

> 标签: disk, disk info, disks, electron, free space, hard drive, harddisk, info, node, npm, volumes

## 简介

Node module to get disk information in Windows, Linux, Mac, FreeBSD & OpenBSD. It works with Electron.
