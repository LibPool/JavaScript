# @ohos-ports/go-npm

> 标签: JavaScript

## 简介

Distribute and install Go binaries via NPM (OpenHarmony port: openharmony->linux platform mapping, arm64->arm64 arch mapping)

## 官网

- 官网：https://github.com/sanathkr/go-npm
- 源码仓库：git+https://github.com/ohos-ports/ohos-ports.git
- npm 页面：https://www.npmjs.com/package/@ohos-ports/go-npm
