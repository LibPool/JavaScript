# @ohos-ports/graphviz

> 标签: dot, graphviz

## 简介

Node.js interface to the GraphViz graphing tool (OpenHarmony/HarmonyOS port: bundles openharmony-arm64 GraphViz 12.2.1 dot/gvpr binaries)

## 官网

- 官网：http://algorithmique.net/
- 源码仓库：git+https://github.com/ohos-ports/ohos-ports.git
- npm 页面：https://www.npmjs.com/package/@ohos-ports/graphviz
