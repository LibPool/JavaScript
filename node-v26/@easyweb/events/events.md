# @easyweb/events

> 标签: amqp, events, microservices, publisher, rabbitmq, subscriber

## 简介

Shared RabbitMQ event layer for Easyweb microservices: resilient connection manager, typed publisher/subscriber base classes, exchange and routing-key registry
