# @hizexai/herald-sdk

> 标签: campus, herald, hizex, line, messaging, notifications, sdk

## 简介

Client for the HiZex Herald API: messages, topics, identity (CRM sync), signed events and executive metrics. Zero dependencies, Node 22+.
