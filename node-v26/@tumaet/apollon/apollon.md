# @tumaet/apollon

> 标签: angular, diagram-editor, react, uml, uml-editor, yjs

## 简介

Embeddable UML modeling editor. Mounts into any DOM node — works inside Angular, Vue, Svelte, vanilla JS, or React hosts.
