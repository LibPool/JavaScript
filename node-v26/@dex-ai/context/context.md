# @dex-ai/context

> 标签: JavaScript

## 简介

Index-and-pointer context management — indexes all tool outputs into a LanceDB hybrid (BM25 + vector) knowledge base for zero-loss compression. Provides ctx_search for on-demand semantic + keyword retrieval. Zero config.
