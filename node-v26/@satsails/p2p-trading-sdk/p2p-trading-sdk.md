# @satsails/p2p-trading-sdk

> 标签: bitcoin, escrow, non-custodial, p2p, sails, sdk

## 简介

Sails P2P Trading SDK — the single typed client a wallet/fintech imports to reach every Sails Protocol module (OpenIdentity, OpenLiquidity, OpenP2P, OpenSettlement, OpenReputation) over HTTP/WebSocket. See docs/SDK_GUIDE.md.
