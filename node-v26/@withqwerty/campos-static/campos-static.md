# @withqwerty/campos-static

> 标签: campos, data-visualization, export, football, og-image, png, sharp, soccer, ssr, static, svg, typescript

## 简介

Node-side static export for Campos charts — render chart specs to SVG or PNG via react-dom/server and sharp.
