# @spazio-genesi/attest-mcp

> 标签: attestation, mcp, model-context-protocol, proof-of-existence, sha256

## 简介

MCP server + CLI for Spazio Genesi's digital attestation service — attest, verify and check digital works with full privacy (files never leave your device). EU-based, GDPR-first, EU-hosted data.
