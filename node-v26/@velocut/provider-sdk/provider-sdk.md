# @velocut/provider-sdk

> 标签: JavaScript

## 简介

Host-neutral contracts for independently packaged audio/video/image model providers. The root contracts have no runtime imports of React, renderer, filesystem or model SDK. The optional `./declarative` entry uses Ajv and YAML for data-defined model adapte
