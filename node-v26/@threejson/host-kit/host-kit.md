# @threejson/host-kit

> 标签: scene-host, three.js, threejson

## 简介

Framework-agnostic scene-host runtime shared by ThreeJSON's editor/player/shower/threebox apps: settings schemas/stores, AI turn orchestration, scene file IO, i18n, and viewport helpers. No React or other UI framework dependency.
