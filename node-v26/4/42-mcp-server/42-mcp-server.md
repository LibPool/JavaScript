> 标签: 42, 42-api, 42-mcp-server, ai, ai-agent, llm, mcp, model-context-protocol

## 简介

A [Model Context Protocol](https://modelcontextprotocol.io) server designed by [Mateo LBS](https://github.com/MatLBS) to interact with the [42 API](https://api.intra.42.fr). It lets AI assistants look up 42 students' profiles, progression, teams, and coal
