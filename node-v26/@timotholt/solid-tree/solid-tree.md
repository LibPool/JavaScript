# @timotholt/solid-tree

> 标签: a11y, accessible, drag-and-drop, headless, realtime, solid, solid-js, solidjs, supabase, tree, tree-view, treeview, virtual, virtualized, wai-aria

## 简介

Accessible, fast, fully featured tree view for SolidJS: virtualization, async/realtime data sources, Supabase locking, multi-select, rename, checkboxes, drag-and-drop, and a headless API.
