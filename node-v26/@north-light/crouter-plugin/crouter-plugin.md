# @north-light/crouter-plugin

> 标签: JavaScript

## 简介

Author a crtr HTTP plugin from one typed TypeScript command tree. The definition creates the Fetch handler, `commands.json`, and the archive that `crtr pkg plugin install --endpoint` accepts. You do not write a manifest, route table, or `plugin.json`.
