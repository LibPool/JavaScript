# tollai

> 标签: agents, bot-detection, proof-of-work, rate-limiting, security, toll

## 简介

Universal zero-dependency cognitive toll: proof-of-work, sessions, dwell and anti-burst that distinguishes humans from autonomous agents. Framework-agnostic core with adapters for node-http, Express, Vercel, Cloudflare and Firebase.
