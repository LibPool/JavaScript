# @zfgcta/dsh-global-prompt

> 标签: agents-md, deepseek-harness, dsh, dsh-plugin, global-instructions, plugin, settings, system-prompt

## 简介

DeepSeek Harness plugin: edit the user-global instructions file (~/.dsh/AGENTS.md) from the Web settings UI. Maintained, installable fork of couplingartist/dsh-global-prompt — ships prebuilt lib/, declares dsh 0.2.x-compatible peers/engines, and installs
