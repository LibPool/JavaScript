# @atomichub/atomicassets

> 标签: antelope, atomicassets, atomichub, atomicmarket, blockchain, eosio, nft, sdk, wax

## 简介

JavaScript/TypeScript SDK for the AtomicAssets NFT standard on Antelope chains: read NFT data, serialize attribute data, and build v2 contract actions
