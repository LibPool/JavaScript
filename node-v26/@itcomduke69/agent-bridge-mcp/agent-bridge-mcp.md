# @itcomduke69/agent-bridge-mcp

> 标签: agent, claude-code, kimi-code, mcp, message-bridge

## 简介

个人 MCP 中心服务器：让后端 Claude Code 与前端 Claude/kimi-code 等 agent 自动互传消息、共享频道与工作上下文，免去手动复制粘贴
