# @riskregister/mcp-server

> 标签: JavaScript

## 简介

Model Context Protocol server for riskregister.com — exposes the public v1 REST API as MCP tools. Ships two transports: stdio (riskregister-mcp) for local desktop AI clients (Claude Desktop, Cursor, etc.) and HTTP+SSE (riskregister-mcp-http) for remote MC
