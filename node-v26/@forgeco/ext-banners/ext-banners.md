# @forgeco/ext-banners

> 标签: JavaScript

## 简介

Forge extension (BAN, S5-BANNERS-V2): the banners app. A banner is a COMPOSE-KERNEL block instance — the operator drops the `banner` block into a storefront slot and its per-instance config IS the banner: a style (carousel | mosaic), an ordered media list
