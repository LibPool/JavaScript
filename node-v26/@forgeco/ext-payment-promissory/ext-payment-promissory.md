# @forgeco/ext-payment-promissory

> 标签: JavaScript

## 简介

Forge extension (S7-PAYMENTS): the B2B 'faturado'/promissory payment method (VTEX Promissory model). The order is placed without an external charge (initiate returns a notice, never approves); the merchant settles it manually via the settle action → order
