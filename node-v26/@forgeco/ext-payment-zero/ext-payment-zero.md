# @forgeco/ext-payment-zero

> 标签: JavaScript

## 简介

Forge extension (PAY-ZERO-ORDER): the payment app for an order with NOTHING TO CHARGE. Same shape as the promissory app (the order is placed without an external charge), opposite settlement: immediate, because there is nothing to wait for. No external I/O
