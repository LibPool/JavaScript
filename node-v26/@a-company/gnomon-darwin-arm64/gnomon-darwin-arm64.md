# @a-company/gnomon-darwin-arm64

> 标签: arm64, gnomon, macos, paradigm

## 简介

Gnomon for macOS on arm64: the signed, notarized, relocatable Gnomon.app (bundled Node, kernel, helper, voice I/O) as a ditto zip with its sha256 (TD-2026-10-21-758). Installed as an optional dependency of @a-company/gnomon; you never install it directly.
