# @a-company/gnomon

> 标签: daemon, gnomon, kernel, paradigm

## 简介

Gnomon — the Paradigm 8.0 kernel: one daemon per user owning sessions, identity, the hash-chained log, approvals and the localhost web endpoint (docs/specs/gnomon.md). ZERO runtime dependencies (G-SEC-01).
