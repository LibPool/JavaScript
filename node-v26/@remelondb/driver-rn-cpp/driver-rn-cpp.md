# @remelondb/driver-rn-cpp

> 标签: database, offline-first, remelondb, sqlite, sync, watermelondb

## 简介

Optional React Native driver for remelonDB: pure C++ TurboModule with bundled SQLite (pinned version, no Expo dependency; requires a native build). Default driver: @remelondb/driver-rn.
