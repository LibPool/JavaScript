# @sophonsai/worklog-mcp-server

> 标签: JavaScript

## 简介

Worklog MCP Server 将 Worklog 日志平台连接到支持 MCP（Model Context Protocol）的 AI 客户端，让你可以直接通过自然语言查询和管理工作日志。
