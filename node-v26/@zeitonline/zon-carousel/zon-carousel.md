# @zeitonline/zon-carousel

> 标签: a11y, accessibility, carousel, custom-elements, light-dom, ui, web-component, zeitonline

## 简介

Accessible <zon-carousel> web component with light-DOM slides, controls, dots and autoplay support. Single source of truth for the ZEIT Online carousel.
