# @nmtjs/proxy

> 标签: JavaScript

## 简介

- transport-agnostic (like WebSockets, WebTransport, .etc) - format-agnostic (like JSON, MessagePack, BSON, .etc) - binary data streaming and event subscriptions - contract-based API - end-to-end type safety - CPU-intensive task execution on separate work
