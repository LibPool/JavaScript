# @contextq/edge

> 标签: JavaScript

## 简介

ContextQ Edge -- offline-first agent-memory replica (SQLite + sqlite-vec + FTS5) that boots from a Memory Interchange Format (MIF) export and syncs with a parent ContextQ instance via hybrid-logical-clock CRDT reconciliation
