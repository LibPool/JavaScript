# @bucksbox/capacitor-sdk

> 标签: JavaScript

## 简介

Capacitor bridge for the BucksBox Android SDK — launches the sdk/websdk widget flows (AEPS, DMT, UPI, merchant signup/onboarding) in a native WebView shell, plus the websdk API client for UPI, AEPS, DMT and merchant onboarding and UIDAI RD fingerprint cap
