# @smooth-reading/core

> 标签: accessibility, fixation, html, intl-segmenter, readability, reading, saccade, streaming, text, typography, unicode

## 简介

Zero-dependency guided fixation reading: emphasise the first part of every word so the eye gets an artificial fixation point. Unicode-aware, streaming, ESM + CJS.
