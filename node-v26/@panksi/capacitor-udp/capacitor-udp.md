## 简介

NOT WORKING PROTOTYPE! UDP Plugin for CapacitorJS inspired by the UDP Plugin of https://github.com/unitree-czk/capacitor-udp. General Idea behind this repo is to implement this plugin in such a way that it can be imported to Capacitor V3+ since Plugins i
