# chaink9-mcp

> 标签: ai-agents, base, bsc, ethereum, honeypot, mcp, model-context-protocol, pancakeswap, rug-pull, token-security, uniswap, x402

## 简介

MCP server for ChainK9: token risk checks on BNB Smart Chain, Ethereum and Base. It buys and sells the token on a private fork of the chain to catch honeypots, hidden taxes and owner traps. Paid per call in USDC on Base with x402.
