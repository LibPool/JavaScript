# @czap/cloudflare

> 标签: cloudflare, czap, edge, liteship, typescript, workers

## 简介

Run LiteShip on Cloudflare Workers: a site adapter with a KV-backed edge cache and the Astro middleware glue that caches boundaries at the edge.
