# @czap/worker

> 标签: czap, liteship, off-main-thread, offscreen-canvas, typescript, web-worker

## 简介

Move LiteShip's heavy work off the main thread: compositor and render workers plus a lock-free ring buffer that stream state and frames without janking the UI.
