# @homie-rocks/diagnostics

> 标签: JavaScript

## 简介

Checks whether a WebGL frame actually has a picture in it: pure blank/flat/tear tests, a pipeline log for bug reports, a watchdog that steps the renderer down a fallback ladder, and probe fault hooks.
