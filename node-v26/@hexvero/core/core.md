# @hexvero/core

> 标签: asar, diff, electron, hexvero, ipc, reverse-engineering, static-analysis

## 简介

Zero-dependency static parsers behind hexvero, the Electron release diff: app.asar, JavaScript bundles, IPC and contextBridge, plus ELF, PE, Mach-O, APK and more. Never runs what it reads.
