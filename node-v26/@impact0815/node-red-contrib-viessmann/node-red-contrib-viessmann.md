# @impact0815/node-red-contrib-viessmann

> 标签: heating, heizung, home-automation, iot, node-red, smarthome, vicare, viessmann, vitoconnect, vitodens

## 简介

Node-RED nodes for the Viessmann IoT API (ViCare / Vitoconnect): fully automatic login, automatic discovery of data points, reading and safeguarded writing. English and German.
