# @azghr/extricate

> 标签: ai, clean, extract, extraction, fence, json, llm, locate, markdown, model, parse, prose

## 简介

Extract the first (or every) valid JSON value embedded in text or markdown fences from an LLM reply. Locates and parses; does not repair.
