# @redknox/dsh-google-search-plugin

> 标签: bundle, deepseek-harness, dsh, gemini, google, grounding, plugin, web-search

## 简介

DeepSeek Harness profile bundle that registers a Google search provider (Gemini google_search grounding) on the ctx.web seam for the web_search tool and activates it as the default search route on install
