# @gradii/nest-fedaco

> 标签: JavaScript

## 简介

[NestJS](https://nestjs.com/) module for [Fedaco ORM](https://www.npmjs.com/package/@gradii/fedaco). Integrates Fedaco into NestJS applications with dependency injection support.
