# tdw-chat

> 标签: chat, chat-widget, cjs, customer-support, esm, floating-button, framework-agnostic, livechat, typescript, widget, zero-dependency, 客服, 对话组件

## 简介

零依赖、框架无关的悬浮对话组件：一行 initChat() 在页面上挂出悬浮按钮与对话弹窗，ESM + CJS 双格式，UI 可用 CSS 完全重构。
