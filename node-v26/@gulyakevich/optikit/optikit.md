# @gulyakevich/optikit

> 标签: avif, cli, faststart, favicon, ffmpeg, filenames, icons, image-optimization, optical-alignment, poster, sharp, slugify, svg, thumbnail, transliteration, trim, video, web-safe, webp

## 简介

CLI utility to optimize web assets — images, video (faststart, posters), og-image, favicon, svg, PNG trim, web-safe file names — and optically centre icons.
