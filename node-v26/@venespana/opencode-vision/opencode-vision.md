# @venespana/opencode-vision

> 标签: accessibility, image, mcp, minimax, opencode, opencode-plugin, vision

## 简介

OpenCode plugin: vision for text-only models — intercepts pasted images, materializes to disk, routes to a VisionBackend, injects description back into chat context.
