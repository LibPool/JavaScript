# @onepointfour-packs/flaredeck-agent

> 标签: agent, automation, claude, coding-agent, flaredeck, gemini, kanban, mcp

## 简介

Run a FlareDeck agent on your own machine: it picks up cards assigned to it, works each one in a checkout of its own, and reports back on the card.
