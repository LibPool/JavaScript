# @luisangeltech/ini-toolkit

> 标签: cleaning, config, ini, parser, rdp, regex, sql, toolkit

## 简介

Regex-based toolkit for parsing and cleaning INI configuration files with embedded SQL and RDP report-designer syntax (sections, comments, key/value pairs, WITH (NOLOCK) hints, WizardSituaciones expressions).
