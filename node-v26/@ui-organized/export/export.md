# @ui-organized/export

> 标签: css, design-tokens, dtcg, export, style-dictionary

## 简介

Export pipeline — resolves a DTCG project document (via @ui-organized/resolver, the authoritative oracle) into CSS custom properties with per-mode semantics. Style Dictionary + sd-transforms parity tested.
