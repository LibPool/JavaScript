# @danmat/accept-query

> 标签: accept-query, content-negotiation, header, http, media-type, q-value, query, query-method, rfc-10008, rfc10008

## 简介

Parse, build, and content-negotiate the Accept-Query HTTP header (RFC 10008) for the QUERY method. Zero dependencies, fully typed.
