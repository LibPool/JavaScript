# @this-npm-test-org/graphql-connection-driver

> 标签: amodal, amodal-connection-driver, graphql

## 简介

Community ConnectionDriver for GraphQL endpoints — introspects the schema at load time, walks operations against a policy file, and scrubs nested-JSON responses (redact / neverRetrieve / denied).
