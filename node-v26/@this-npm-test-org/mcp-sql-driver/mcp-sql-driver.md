# @this-npm-test-org/mcp-sql-driver

> 标签: amodal, amodal-driver, mcp, model-context-protocol, sql-driver

## 简介

MCP-backed SqlDriver — talks to any MCP server exposing a SQL query tool. Reduced capabilities (no transactions, no per-session role context) but works against any MCP-protocol DB server.
