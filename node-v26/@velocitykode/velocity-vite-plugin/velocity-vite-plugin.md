# @velocitykode/velocity-vite-plugin

> 标签: inertia, velocity, velocitykode, vite, vite-plugin

## 简介

Vite plugin for Velocity Framework apps - manages public/hot, sets build defaults, and wires entrypoints so the framework's bond/vite Go helper resolves the right URLs in dev and prod.
