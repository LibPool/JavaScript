# @braidlabs/sw

> 标签: cache, micro-frontends, offline, service-worker, version-skew

## 简介

Braid service worker — skew-aware asset serving for composed pages: each fragment gets its own build-keyed cache partition, so a page already open keeps getting the chunks it was built against after a deploy lands. Ships as a handler to compose into an ex
