# @effected/lockfiles

> 标签: bun, effect, effected, lockfile, npm, pnpm, schema, workspaces, yarn

## 简介

Pure lockfile parsing for bun, npm, pnpm and yarn Berry into one unified Effect schema model, with pure integrity checking against workspace manifests.
