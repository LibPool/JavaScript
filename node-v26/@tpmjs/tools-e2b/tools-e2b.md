# @tpmjs/tools-e2b

> 标签: ai, cloud, code-execution, code-interpreter, e2b, sandbox, tpmjs

## 简介

E2B cloud sandbox tools for AI code execution. Create sandboxes, run code in multiple languages, manage files, and control sandbox lifecycle.
