# @nearcade/launcher-detect

> 标签: battlenet, cross-platform, deep-link, epic-games, game-launcher, heroic, launcher-detection, lutris, origin, protocol, steam, ubisoft

## 简介

Detect installed game launchers (Steam, Heroic, Lutris, Epic, Ubisoft, Origin, Battle.net) and launch games via their protocol URLs — cross-platform (Linux, Windows, macOS).
