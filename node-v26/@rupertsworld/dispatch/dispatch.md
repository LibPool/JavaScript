# @rupertsworld/dispatch

> 标签: JavaScript

## 简介

Dispatch is an MCP server that schedules work for a running coding agent by sending it a message at the right time. Ask your agent to review your tasks every morning or check on a long-running build in 20 minutes. Dispatch currently works with Claude Code
