# @phcdevworks/spectre-components

> 标签: accessible-components, component-library, design-system, framework-agnostic, lit, phcdevworks, spectre, spectre-components, web-components

## 简介

@phcdevworks/spectre-components is the web-component layer of the Spectre system. It provides accessible, framework-independent interface components built on Spectre's shared design contracts.
