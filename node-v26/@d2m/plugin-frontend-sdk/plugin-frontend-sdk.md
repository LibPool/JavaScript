# @d2m/plugin-frontend-sdk

> 标签: JavaScript

## 简介

`@d2m/plugin-frontend-sdk` 是 D2M 前端插件作者使用的稳定类型包。它定义 active frontend manifest、插件入口模块、运行上下文、路由、前端资源、诊断、兼容性结果和宿主 capability 契约，不暴露宿主内部 router、全局状态、权限审批或后端授权实现。
