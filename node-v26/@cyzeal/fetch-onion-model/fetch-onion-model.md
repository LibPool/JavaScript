# @cyzeal/fetch-onion-model

> 标签: ajax, fetch, request

## 简介

一个基于 Web Fetch Api 的轻量级 Http 请求增强工具，支持浏览器与 Node 环境，类似于 koa 的洋葱模型，以中间件形式扩展功能。
