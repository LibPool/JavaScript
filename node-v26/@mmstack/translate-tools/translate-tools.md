# @mmstack/translate-tools

> 标签: angular, export, import, localize, mmstack, translate

## 简介

Build-time tooling for [`@mmstack/translate`](https://www.npmjs.com/package/@mmstack/translate): export your TypeScript-authored namespaces to JSON for translators / TMS platforms, then import the translations back as generated `createTranslation` modules
