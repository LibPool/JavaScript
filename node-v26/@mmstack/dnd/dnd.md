# @mmstack/dnd

> 标签: angular, dnd, drag, drag-and-drop, drop, pragmatic-drag-and-drop

## 简介

Signals-first drag & drop for Angular. Make any element draggable or a drop target with a **typed payload**, read every bit of drag state as a `Signal`, and build reorderable lists — single or cross-list — on the same primitives. Choose the engine per ele
