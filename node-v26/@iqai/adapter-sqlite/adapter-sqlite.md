# @iqai/adapter-sqlite

> 标签: JavaScript

## 简介

A wrapper around [better-sqlite3](https://github.com/JoshuaWise/better-sqlite3) for use with the [ElizaOS](https://github.com/elizaos/elizaos) framework.
