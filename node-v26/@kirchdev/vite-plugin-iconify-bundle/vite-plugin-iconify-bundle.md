# @kirchdev/vite-plugin-iconify-bundle

> 标签: bundle, iconify, icons, kirchdev, ssr, tree-shaking, virtual-module, vite, vite-plugin

## 简介

Vite plugin that bundles only the Iconify icons your source actually uses — no runtime API calls, no whole collections.
