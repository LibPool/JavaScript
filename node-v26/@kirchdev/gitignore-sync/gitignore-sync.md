# @kirchdev/gitignore-sync

> 标签: cli, developer-tools, dotfiles, git, gitignore, kirchdev, nodejs

## 简介

CLI that keeps a repo's .gitignore maintained — curated blocks inside a managed region, re-rendered idempotently, nothing outside it touched.
