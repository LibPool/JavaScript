# @ilq/grapesjs-angular

> 标签: angular, drag-and-drop, grapesjs, page-builder, site-builder, wysiwyg

## 简介

Angular 20+ wrapper for the GrapesJS web builder framework. Signals-based, standalone, zoneless-compatible.
