# @adamtools/apifinder

> 标签: Api-list, Apifinder, Endpointscanner, Nextjs-Api, api-documentation-generator, api-finder, documentation, endpoints, route-discovery

## 简介

Finds all api endpoints of any nextjs project and adds them into README.md , makes api documentation easier
