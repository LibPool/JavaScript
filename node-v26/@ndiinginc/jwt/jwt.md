# @ndiinginc/jwt

> 标签: JavaScript

## 简介

Library JWT ringan berbasis modul `crypto` bawaan Node.js — tanpa dependency eksternal. Mendukung sign, decode, dan verify token dengan berbagai algoritma HMAC, RSA, ECDSA, dan RSA-PSS.
