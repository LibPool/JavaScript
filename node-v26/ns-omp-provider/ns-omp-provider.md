# ns-omp-provider

> 标签: devin, grok, kiro, oauth, oh-my-pi, omp, omp-plugin, pi, provider, xai

## 简介

OMP (oh-my-pi) plugin: Kiro, Devin, and Grok providers from @ngosangns/ns-pi-provider, wrapped for OMP's provider/extension API.
