# @metabindai/agent-ui

> 标签: agent, assistant-ui, chat, mcp, mcp-ui, metabind

## 简介

Prebuilt, drop-in React chat UI for the Metabind agent proxy: the assistant-ui runtime, MetabindAgentTransport, and MCP UI tool rendering. Configure with your Metabind project + key and render <AgentChat />. Works standalone or embedded via the iframe bri
