# @0xdoublesharp/lru-cache-clustered

> 标签: cache, cluster, ipc, lru, lru-cache, mru, promise, typescript

## 简介

Shared in-memory LRU caches for Node.js cluster workers, with atomic counters, coordinated fetches, and optional local caching.
