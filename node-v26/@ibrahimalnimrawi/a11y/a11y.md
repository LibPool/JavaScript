# @ibrahimalnimrawi/a11y

> 标签: a11y, accessibility, arabic, color-blind, contrast, dyslexia, rtl, screen-reader, widget

## 简介

A drop-in accessibility widget for any website: text scaling, dyslexia fonts, contrast, colour-blind filters, reading mask, magnifier, keyboard navigation and read-aloud. Vanilla JS, no dependencies, English and Arabic built in.
