# @jspsych-contrib/plugin-flanker

> 标签: attention, cognitive-control, eriksen, flanker, jsPsych, response-inhibition, selective-attention

## 简介

A jsPsych plugin for the Eriksen Flanker Task. Displays a configurable flanker array with precise SOA timing and supports arrows, letters, numbers, or custom stimuli. Includes keyboard and mobile-friendly button response modes.
