# dsh-llm-omp-transports

> 标签: cursor, devin, dsh, dsh-plugin, llm, oh-my-pi, transport

## 简介

DSH transport plugin: serves providers whose wire protocols only oh-my-pi's own transport code can speak (Cursor and Devin), by registering its own routes on the dsh-llm seam.
