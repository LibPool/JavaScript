# @noctcore/eslint-plugin-llm

> 标签: ai-sdk, anthropic, eslint, eslint-plugin, eslintplugin, llm, noctcore, openai, prompt-injection, security

## 简介

ESLint rules for code that calls LLM SDKs: model output treated as untrusted input before it reaches a dangerous sink.
