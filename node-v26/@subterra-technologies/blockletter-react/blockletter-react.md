# @subterra-technologies/blockletter-react

> 标签: editor, email, email-builder, newsletter, react

## 简介

Blockletter's accessible React newsletter editor: canvas, block palette, inspector, brand kit, templates and a live preview. Ships one compiled stylesheet; no Tailwind needed.
