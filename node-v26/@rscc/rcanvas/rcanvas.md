# @rscc/rcanvas

> 标签: JavaScript

## 简介

웹 페이지에 임베드해서 사용할 수 있는 HTML5 캔버스 기반 판서/주석(annotation) 위젯입니다. 호스트 엘리먼트만 넘겨주면 자체 툴바·서브메뉴·컬러 피커까지 그 안에 그려 넣습니다. Vanilla JS로 작성되어 있으며 별도의 프레임워크 의존성이 없습니다.
