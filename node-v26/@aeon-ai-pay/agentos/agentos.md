# @aeon-ai-pay/agentos

> 标签: agent-os, agent-skills, agentos, ai-image, bsc, crypto-payment, evm, image-generation, x402

## 简介

AEON AgentOS — platform-level execution system for AI Agents. Connects skill invocation, task execution, authorized payment and settlement. Currently open: AI image generation via x402 protocol with USDT on BSC.
