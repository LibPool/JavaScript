# @protonspy/scc

> 标签: agents, ai, claude, claude-code, cli, codex, coding-agent, opencode, sdd, spec-driven-development

## 简介

Spec-driven development for coding agents — a single Go binary that turns the SDD workflow into a mechanically validated contract. Works with Claude Code, Codex, and opencode.
