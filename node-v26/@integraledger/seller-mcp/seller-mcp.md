# @integraledger/seller-mcp

> 标签: agentic-commerce, ai-agent, lcp, legal-context-protocol, mcp, model-context-protocol, paid-tools, x402

## 简介

The Model Context Protocol seller face for x402 — wrap an MCP tool handler so its call is gated by a settled payment, with the payment and the receipt riding MCP's own _meta extension point. A library mount in the seller's own process; no SDK dependency,
