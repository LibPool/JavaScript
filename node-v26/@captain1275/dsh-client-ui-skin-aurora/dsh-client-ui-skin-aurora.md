# @captain1275/dsh-client-ui-skin-aurora

> 标签: JavaScript

## 简介

极光（Aurora）皮肤：支持自定义背景图片（URL / 透明度 / 模糊）与极光渐变背景，半透明毛玻璃面板，浅色 / 深色两套调色板。
