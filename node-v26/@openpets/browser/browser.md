# @openpets/browser

> 标签: automation, browser, chrome, devtools, opencode, plugin, puppeteer, web-scraping

## 简介

Control Chrome browser via DevTools Protocol. Navigate, search, extract content, take screenshots, and automate interactions without needing a separate MCP server.
