# @openpets/graph-microsoft

> 标签: m365, microsoft-graph, office365, opencode, openpets, plugin, teams

## 简介

Comprehensive Microsoft Graph API plugin focused on Teams functions including user profiles, teams, channels, messages, chats, and online meetings.
