# @openpets/folding-at-home

> 标签: distributed-computing, folding-at-home, opencode, openpets, plugin, science

## 简介

Query Folding@Home project data, user statistics, team rankings, and work unit information. Supports public read-only access to the Folding@Home API with optional account management via passkey authentication.
