# @ai-gui/plugin-topology

> 标签: ai, aigui, animation, architecture, cluster, diagram, failover, llm, plugin, svg, topology

## 简介

Infrastructure topology diagrams for AIGUI — nodes in hosts and racks, links, states, laid out automatically, with steps that play a process: messages moving, nodes failing over.
