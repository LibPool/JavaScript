# @ai-gui/mcp

> 标签: 3d, aigui, chart, claude-code, llm, mcp, model-context-protocol, visualization

## 简介

An MCP server that lets an agent draw AIGUI blocks — charts, diagrams, maths, 3D scenes, orbits, molecules, data walls — as PNGs or as a live page in the browser.
