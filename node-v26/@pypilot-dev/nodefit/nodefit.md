# @pypilot-dev/nodefit

> 标签: compatibility, doctor, engines, language-server, native, node, node-gyp, nvm, prebuild

## 简介

Finds the Node.js version every dependency of a project supports, and catches native modules with no prebuilt binary before node-gyp fails.
