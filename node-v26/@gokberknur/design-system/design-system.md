# @gokberknur/design-system

> 标签: accessibility, components, css, custom-elements, dark-mode, design-system, design-tokens, framework-agnostic, geist, lit, theming, ui, web-components

## 简介

A personal, minimal & editorial design system: framework-agnostic gok-* web components + design tokens, built with Lit. One green accent, Geist, WCAG AAA, light/dark.
