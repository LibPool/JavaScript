# @smoothglue/dev-console

> 标签: JavaScript

## 简介

A powerful 💪, draggable 🖱️ developer console for React applications ⚛️. This tool provides an in-app overlay to inspect network traffic 🚦, view console logs 📜, and execute custom commands ⚡ without needing to open the browser's developer tools 🛠️.
