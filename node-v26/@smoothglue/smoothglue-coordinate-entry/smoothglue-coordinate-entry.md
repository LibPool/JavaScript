# @smoothglue/smoothglue-coordinate-entry

> 标签: JavaScript

## 简介

A robust 🏗️, type-safe 🛡️ React UI component library for interacting with and parsing geospatial coordinates 🗺️ in various formats. This library provides ready-to-use input fields, poppers, and utility hooks for seamless coordinate management in Smooth
