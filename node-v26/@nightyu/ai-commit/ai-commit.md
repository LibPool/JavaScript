# @nightyu/ai-commit

> 标签: ai, cli, commit, conventional-commits, git, gitmoji, openai

## 简介

AI-generated git commit messages from your staged changes. Agent mode (pi SDK) or single-request chat/responses over any OpenAI-compatible API. Conventional Commits, Gitmoji, multi-language, confirm/edit before commit.
