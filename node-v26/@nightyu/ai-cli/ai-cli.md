# @nightyu/ai-cli

> 标签: ai, cli, exchange-rate, openai, pi, translate

## 简介

Terminal AI sidekick: ask anything (`ai`), smart CN/EN translation (`ai -t`), live exchange rates (`ai -huilv`) — powered by the pi SDK over any OpenAI-compatible endpoint.
