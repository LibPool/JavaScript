# @cli42/lib

> 标签: arc42, biz42, cli, diff, git, pdt42, react, web

## 简介

The shared language engine of the *42 documentation CLIs (arc42, biz42, pdt42): Markdown and AsciiDoc parser, schema-driven model with id schemes, validation engine with generic rules, Mermaid syntax check, authoring guidance, semantic diff, Git snapshots
