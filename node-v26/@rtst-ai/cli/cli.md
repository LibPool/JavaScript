# @rtst-ai/cli

> 标签: agent, ai, cli, image-generation, llm, oclif, rtst, text-to-image, text-to-video, video-generation

## 简介

Command-line client for the rtst AI image and video generation API. JSON output, async job polling, and automatic file uploads, built for both humans and LLM agents.
