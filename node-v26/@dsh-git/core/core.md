# @dsh-git/core

> 标签: abstraction, deepseek, dsh, dsh-plugin, git, harness, service, types

## 简介

Service Definitions and vocabulary types for the Git capability seam: the abstract gitLocal (plumbing/porcelain) and gitPlatform (hosted-platform registry) services, plus the shared GitError taxonomy.
