# @dsh-git/platform

> 标签: adapters, deepseek, dsh, dsh-plugin, git, harness, rate-limit, registry

## 简介

gitPlatform provider: the registry/dispatcher that holds one adapter per hosted platform, detects the host from a repo's remote URL, and applies rate-limit backoff and a read cache.
