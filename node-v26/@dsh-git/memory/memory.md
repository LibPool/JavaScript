# @dsh-git/memory

> 标签: context, deepseek, dsh, dsh-plugin, harness, memory, self-evolving

## 简介

Self-evolving git memory: a durable, cross-session store of environment facts, per-project conventions, error signatures + resolutions, and user-stated preferences. Auto-captures git tool failures, scrubs secrets, and injects a bounded digest into the sys
