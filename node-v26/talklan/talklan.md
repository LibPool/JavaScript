# talklan

> 标签: JavaScript

## 简介

Temporary local-network communication room. Start a server, scan the QR, talk. No cloud, no account, no internet required.

## 官网

- npm 页面：https://www.npmjs.com/package/talklan

- npm 安装：`npm install talklan`
- npm registry：https://registry.npmjs.org/talklan
- Node 要求：>=20
