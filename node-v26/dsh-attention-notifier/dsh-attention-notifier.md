# dsh-attention-notifier

> 标签: attention, cordis, deepseek-harness, dsh, notification, plugin, toast, windows

## 简介

Notifies you when DeepSeek Harness needs attention: approval prompts, questions, task completion, and errors — with a Windows toast whose button brings the window back.
