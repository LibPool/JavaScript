# @geohar/pi-plan

> 标签: cribsheet, extension, pi, pi-coding-agent, pi-extension, pi-mono, pi-package, plan

## 简介

Pi extension: a plan sidebar. Consumes `plan-item` snapshots (from the cribsheet plan source) and renders the plan — dep-ordered plans and (later) the live agent fleet — as a TUI widget.
