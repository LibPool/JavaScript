# @geohar/opencode-svg-mcp

> 标签: mcp, opencode, opencode-plugin, plugin, sharedserver, svg, svg-mcp

## 简介

OpenCode plugin: run the svg-mcp MCP server via sharedserver and register its endpoint with OpenCode. Stands down when a combiner already serves svg-mcp.
