# @moderno-ui/lint

> 标签: JavaScript

## 简介

ESLint plugin + CLI over @moderno-ui/lint-core's shared rule engine — the same hardcoded-color/prop-validity/raw-Ark/data-part/reimplemented-primitive checks validate_usage runs, for human contributors and CI.
