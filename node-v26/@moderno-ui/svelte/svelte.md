# @moderno-ui/svelte

> 标签: JavaScript

## 简介

Svelte 5 bindings for Moderno (and the docs island runtime): Ark UI headless behaviour + @moderno-ui/core CVA (props → data-attributes), styled entirely by the shared components.css.
