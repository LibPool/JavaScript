# @mgdm/ironman

> 标签: JavaScript

## 简介

pnpm 支持工作区协议（workspace protocol）来声明本地包的依赖关系： ```json {   "dependencies": {     "package-a": "workspace:*"   } } ``` 在子包的 package.json 中声明依赖其他本地包时，可以使用 workspace 协议。
