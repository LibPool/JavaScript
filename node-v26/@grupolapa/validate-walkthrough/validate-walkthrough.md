# @grupolapa/validate-walkthrough

> 标签: JavaScript

## 简介

Valida una entrega de recorrido 3D para el configurador de UONDR: manifiesto entrega.json, modelos glTF por zona, lightmaps, cámaras, renders de referencia y mapas de acabados.
