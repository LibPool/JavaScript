# @dashforge/tw

> 标签: JavaScript

## 简介

**A props-driven React UI library on top of Tailwind CSS.** Every utility that matters for the public API becomes a typed prop — `size`, `color`, `variant`, `layout`, … — so you write components that read like a design system and render output that's pure
