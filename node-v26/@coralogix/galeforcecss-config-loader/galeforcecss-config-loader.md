# @coralogix/galeforcecss-config-loader

> 标签: config, galeforcecss, tailwind, tailwindcss

## 简介

Load and resolve a tailwind.config.{js,cjs,mjs,ts} file into the JSON shape GaleforceCSS's Rust compiler consumes.
