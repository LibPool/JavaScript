# @dshapp/dsh-claude-subscription

> 标签: anthropic, claude, claude-code, cordis-plugin, deepseek-harness, dsh, oauth

## 简介

DeepSeek Harness (DSH) bundle: shares a Claude Code (Pro/Max/Team) subscription credential with the harness, so the built-in Anthropic provider runs on the subscription instead of a separate API key.
