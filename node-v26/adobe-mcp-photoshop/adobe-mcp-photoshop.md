# adobe-mcp-photoshop

> 标签: adobe, design-automation, extendscript, image-editing, macos, mcp, model-context-protocol, photoshop, windows

## 简介

MCP server for Adobe Photoshop: documents, image size and canvas, layers, selections, adjustments, filters, type, export and history through ExtendScript
