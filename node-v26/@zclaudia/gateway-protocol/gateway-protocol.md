# @zclaudia/gateway-protocol

> 标签: gateway, protocol, websocket, zclaudia

## 简介

Canonical wire types and constants for Gateway Protocol v4: handshake, registry, heartbeat, control plane, channels, topics, streaming HTTP, plus auth/admin/notification service DTOs. Zero dependencies.
