# @mzimt625/datapulse-sdk-web-plugin-utm

> 标签: JavaScript

## 简介

渠道追踪与广告归因插件。解析 `utm_source/medium/campaign/term/content`、广告点击 ID 和显式配置的自定义渠道参数，并生成当前、首次和最近一次渠道属性。
