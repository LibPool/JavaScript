# @mzimt625/datapulse-sdk-web-plugin-amp

> 标签: JavaScript

## 简介

Google AMP 页面不能运行普通 Web SDK。本包生成 `<amp-analytics>` 所需的 JSON 配置，通过 DataPulse `/api/v1/amp.gif` 协议采集页面可见和元素点击事件。
