# @mzimt625/datapulse-sdk-web-plugin-autotrack

> 标签: JavaScript

## 简介

Web 辅助点击插件。插件不会由 Web SDK 自动安装；即使显式安装，默认也只监听带 `data-dp-track` 的元素，发送 `$WebClick`。业务关键行为应使用具名事件或可视化埋点规则，不应依赖全量点击反推业务意图。
