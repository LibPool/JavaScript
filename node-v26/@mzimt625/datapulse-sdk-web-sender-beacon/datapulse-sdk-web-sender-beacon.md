# @mzimt625/datapulse-sdk-web-sender-beacon

> 标签: JavaScript

## 简介

使用 `navigator.sendBeacon` 发送事件，适合页面卸载阶段。负载使用可跨域发送的 `text/plain` JSON，浏览器不支持或队列拒绝时可回退到自定义 Sender。
