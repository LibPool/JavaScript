# @animacamos/core

> 标签: animacamos, camera, core, frames, realtime, typescript, video, webcam, webrtc

## 简介

Platform-neutral TypeScript core of animaCAM-OS. Primitives for real-time video / camera applications: Session, Device, VideoFormat, VideoFrame, FrameHub (latest-frame-wins fan-out), CameraOutput contract, events and errors. Framework-agnostic — no React,
