# @sns-parse/cli

> 标签: bilibili, cli, douyin, downloader, parser, sns-parse, twitter, video

## 简介

sns-parse 命令行兼容层：像 you-get 一样在终端解析/下载全平台视频与图集（引擎与配置声明均来自 @sns-parse/core 与已安装的 platform-*/ext-* 碎片包）
