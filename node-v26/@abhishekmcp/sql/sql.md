# @abhishekmcp/sql

> 标签: claude, mcp, modelcontextprotocol, postgres, sql, sqlite

## 简介

MCP server for SQL databases — read-only querying and schema introspection over Postgres and SQLite, with a gated write mode, from any MCP client.
