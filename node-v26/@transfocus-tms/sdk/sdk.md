# @transfocus-tms/sdk

> 标签: api-client, logistics, sdk, tms, transfocus, transport

## 简介

Official Node.js/TypeScript client for the Transfocus TMS public API (v1 and v2): typed resource clients, partner password-grant authentication with token refresh, retries, pagination and structured logging.
