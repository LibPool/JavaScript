# @narthia/jira-client

> 标签: api, atlassian, client, esm, jira, jira-api-client, jira-client, jira-rest-api, jira-rest-client, narthia, narthia-jira, narthia-rest, nodejs, openapi, rest, rest-api, sdk, secure, tree-shakeable, type-safe, typescript, zero-dependencies

## 简介

A fully typed, tree-shakeable Jira REST API client generated from Atlassian's OpenAPI specs. Covers the Jira platform (v2/v3), Jira Software, and Jira Service Management. ESM-only with zero runtime dependencies.
