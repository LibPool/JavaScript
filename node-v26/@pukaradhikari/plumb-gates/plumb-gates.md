# @pukaradhikari/plumb-gates

> 标签: ci-gate, data-freshness, docs-drift, documentation, link-checker

## 简介

Plumb gate CLI — versioned gate logic (crawl, freshness) run against a thin repo-local config. Fixes propagate to every plumbed repo on version bump.
