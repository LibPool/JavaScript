# @dtst/tts

> 标签: agent, audio, mcp, model-context-protocol, openai, openrouter, speech, text-to-speech, tts

## 简介

MCP server for text-to-speech through any OpenAI-compatible API (OpenAI, OpenRouter, LiteLLM, local). Saves audio to the paths the agent asks for.
