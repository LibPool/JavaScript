# @ghds/react-native

> 标签: components, design-system, ghds, hand-drawn, mobile, react-native, sketchy

## 简介

React Native component library for GHDS — hand-drawn (sketchy) Button/Card/Input built with @shopify/restyle + react-native-svg, themed from @ghds/tokens.
