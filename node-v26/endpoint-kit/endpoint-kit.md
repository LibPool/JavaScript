# endpoint-kit

> 标签: api, axios, client, codegen, fetch, ofetch, openapi, pagination, repository, sse, standard-schema, type-safe, typescript, zod

## 简介

Declare backend endpoints once with Zod (or any Standard Schema) and get a fully typed API client for fetch, axios or ofetch
