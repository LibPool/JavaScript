# @tsdoctor/bundle

> 标签: api-extractor, bundle, documentation, effect, esm, manifest, provenance, typescript

## 简介

The tsdoctor bundle spec: layered bundle discovery, the versioned tsdoctor.json sidecar manifest, provenance-carrying resolution and canonical input hashing for API documentation bundles.
