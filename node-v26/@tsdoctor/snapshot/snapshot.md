# @tsdoctor/snapshot

> 标签: content-hash, documentation, effect, incremental-build, snapshot, sqlite

## 简介

Incremental-build snapshot tracking for static documentation pipelines: a schema-versioned SQLite store of per-file content hashes and timestamps, built on @effected/store, plus the pure SHA-256 content-hashing helpers that feed it.
