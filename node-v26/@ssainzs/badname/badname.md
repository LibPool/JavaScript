# @ssainzs/badname

> 标签: ci, codex, developer-tools, filesystem, fixtures, fuzzing, nfc, nfd, normalization, testing, unicode

## 简介

A maintained corpus of pathological file paths — Unicode normalization, reserved names, bidi, control chars — plus a harness to test any tool against them.
