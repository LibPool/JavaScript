# @aburi/framework-next

> 标签: JavaScript

## 简介

Aburi Next.js framework plugin: recognizes the App Router special files (page / layout / route / template / loading / error / not-found) and the "use client" / "use server" module directives, emitting framework:next:* extKinds and boundary flags
