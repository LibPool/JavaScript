# @krisnile/kppt

> 标签: kppt, markdown, meeting, offline, ppt, presentation, report, reveal-js, slides

## 简介

轻量、可完全离线运行的 Markdown 网页演示工具，基于 reveal.js，下载后即可编辑和放映。
