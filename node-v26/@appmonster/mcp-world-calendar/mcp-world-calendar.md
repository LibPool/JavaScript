# @appmonster/mcp-world-calendar

> 标签: business-days, calendar, deadline, holidays, mcp, model-context-protocol, public-holidays, weekend, working-days

## 简介

MCP server for public holidays and business-day math in 200+ countries and regions: is it a working day, add N business days, count working days, local weekends (Fri–Sat etc.). No keys, offline.
