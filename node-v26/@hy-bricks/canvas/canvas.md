# @hy-bricks/canvas

> 标签: binding, canvas, drag-drop, hypercard, layout-engine, low-code, vue3

## 简介

HyperCard 画布 — 多组件实例编排 / 自由布局 / 拖拽 / 连线 / 属性面板。受控组件,SDK 边界守住:不 fetch / 不知后端 / 不开 Drawer。
