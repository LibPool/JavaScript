# @ikrong/fonttools

> 标签: browser, build-tool, colr, font, fonttools, node, nodejs, opentype, pyftsubset, pyodide, subset, ttx, varLib.instancer, wasm, web-worker, woff2

## 简介

fontTools for the browser and Node.js — pyftsubset / ttx / varLib.instancer running on Pyodide (WASM CPython). In the browser it lives in a Web Worker; in Node it runs on the calling thread. No server, no local Python.
