# @siphon-project/control

> 标签: ari, b2bua, control, esl, sip, telephony, voip, websocket

## 简介

TypeScript client for the SIPhon external control plane (siphon-control.v1) — an ARI/ESL-class rail for driving handed-over calls out of process.
