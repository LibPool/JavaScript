# @tracsa-dj/mcp

> 标签: analytics, claude, consent, mcp, model-context-protocol, server-side-tracking, tracsa

## 简介

MCP server for TRACSA: lets an AI assistant read your tracking status, analytics, sites, events and call log, and send test events, from your own TRACSA server.
