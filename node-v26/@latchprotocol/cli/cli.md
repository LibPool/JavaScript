# @latchprotocol/cli

> 标签: airdrop, amm, cli, defi, devnet, dex, foundry, hooks, latch, latchprotocol, launchpad, scaffold

## 简介

The latch command: launch tokens on locked pools, create hosted Launchpad and DEX sites, airdrops, splits and locks, check a chain with latch doctor, and scaffold hooks and front ends. MIT; signs only with an encrypted keystore, never a raw key.
