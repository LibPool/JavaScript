# @latchprotocol/sdk

> 标签: amm, concentrated-liquidity, defi, dex, ethereum, hooks, latchprotocol, launchpad, robinhood-chain, sdk, typescript, viem

## 简介

MIT TypeScript SDK for LatchProtocol — deployed contract addresses, pool key/id derivation, hook permission bitmaps, typed events, and the Latch registry. Build hooks without importing GPL Solidity.
