# @scopebond/gateway

> 标签: ai-agents, gateway, mcp, policy, proxy, receipts, scopebond

## 简介

Scopebond Gateway — a policy-enforcement proxy for AI agents: prevent (deny out-of-policy, fail closed), prove (Ed25519-countersigned scopebond:receipts), kill switch. HTTP + MCP ingress on Hono.
