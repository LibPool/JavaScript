# @scopebond/mcp

> 标签: ai-agents, mcp, model-context-protocol, policy, proxy, scopebond

## 简介

Scopebond MCP proxy — one policy for every Model Context Protocol tool call, in front of the servers an agent uses. In-path enforcement with a signed PEP-authorized receipt.
