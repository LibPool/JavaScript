## 简介

MCP server for Gemini image generation ("Nano Banana" / "Nano Banana Pro"). Supports a Gemini API key from AI Studio, a Vertex AI / Gemini Enterprise Agent Platform API key (Express Mode), and Application Default Credentials (ADC).
