# @convariance/core

> 标签: ai-participant, claude-code, diarization, live-transcription, mcp, transcript

## 简介

The convariance engine core: the versioned wire protocol, the BridgeSession transcript/signal/delegation state machine, the pluggable Classifier seam, and the sub-speaker segmenter. Zero dependencies, isomorphic (Node, workerd, browsers).
