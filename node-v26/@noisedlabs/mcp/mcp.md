# @noisedlabs/mcp

> 标签: ai-agent, ai-operator, autopilot, claude, keeper, langgraph, mcp, model-context-protocol, noised, post-quantum, qsl-1, quantum-security-layer, solana, token-launch

## 简介

Noised MCP server: lets AI agents (Claude, LangGraph, any MCP client) read Noised launches, rules and autopilots, simulate them, and build unsigned autopilot transactions inside the on-chain bounds. It never signs and never holds keys.
