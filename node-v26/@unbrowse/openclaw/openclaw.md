# @unbrowse/openclaw

> 标签: browser, mcp, openclaw, openclaw-plugin, scraping, unbrowse, web

## 简介

Unbrowse for OpenClaw: websites as APIs. Hosted discover, run, scrape and cloud-browser tools, a web_fetch provider, and a hook that replaces the built-in browser for web pages.
