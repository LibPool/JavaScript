# @nodii/grpc-interfaces

> 标签: dsar, grpc, interfaces, nodii, proto, service-definition, tenant-snapshot

## 简介

Canonical gRPC interface contracts for the Nodii stack. Ships the vendored .proto bytes + runtime-loaded @grpc/grpc-js ServiceDefinitions for nodii.dsar.v1.DataLifecycleService and nodii.tenant.v1.TenantSnapshotService so consumer services can server.addS
