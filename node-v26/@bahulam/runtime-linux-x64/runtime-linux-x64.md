# @bahulam/runtime-linux-x64

> 标签: bahulam, bahulam-code, internal, runtime

## 简介

Bahulam Code — bundled Python runtime (PyArmor-obfuscated framework + agent app) for linux x64. Installed as an optional dependency of @bahulam/code; the CLI resolver spawns bin/bahulam-agent from this package on matching platforms.
