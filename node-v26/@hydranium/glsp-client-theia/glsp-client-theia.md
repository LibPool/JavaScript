# @hydranium/glsp-client-theia

> 标签: diagram, glsp, hydranium, langium, language-server, lsp, theia

## 简介

Theia-coupled client primitives for GLSP heads built on @hydranium/glsp-server. Provides the action dispatcher, channel logger, and connection-handler bases that Theia-based adopters extend; companion of @hydranium/glsp-server.
