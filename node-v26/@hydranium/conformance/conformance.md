# @hydranium/conformance

> 标签: conformance, hydranium, langium, language-server, lsp, testing

## 简介

Protocol conformance kit (TCK) for hydranium adopters. Per-head slices (/data, /lsp, /glsp) of fixture-parameterized, protocol-only smoke checks an adopter runs against its own server.
