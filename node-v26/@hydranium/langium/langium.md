# @hydranium/langium

> 标签: hydranium, langium, language-server, lsp

## 简介

Augmented re-export of the Langium API for the hydranium framework: the single chokepoint where hydranium pins the Langium version and layers its type/namespace augmentations. ~99% passthrough today.
