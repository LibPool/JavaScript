# @dsh-toolbox/harness-patch

> 标签: JavaScript

## 简介

Plugin: apply the local session-area management patch to an installed DeepSeek Harness — drag-organization across workspaces/ungrouped/archived, archived folder, cross-directory moves, and resilience to corrupt logs. One command applies everything; idempo
