# @haroonwaves/blog-kit-react

> 标签: blog, blog-engine, blog-kit, markdown, nextjs, nextjs-blog, react, server-components, ssg

## 简介

React components and hooks for rendering markdown content. Includes content renderer with syntax highlighting, content cards, lists with built-in search, filtering, and customization.
