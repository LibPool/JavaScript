# @wrepinski/node-red-smart-thermostat

> 标签: adaptive, air-conditioning, boost, cooling, heating, home-assistant, hvac, mqtt, node-red, pid, schedule, smart-home, temperature, thermostat, zigbee

## 简介

Smart thermostat node with adaptive PID control, weekly schedules, boost mode, and Home Assistant MQTT integration. Supports Zigbee radiator valves and AC units.
