# @accessmeru/node

> 标签: JavaScript

## 简介

Access Meru server SDK for Node 20+, Deno and Supabase Edge: verify access/ID tokens, requireAuth, token exchange and webhook handlers, a Supabase session exchange, the Management API client, roles and permissions (requirePermission, sync-catalog CLI).
