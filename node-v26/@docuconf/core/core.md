# @docuconf/core

> 标签: configuration, contract, cue, docuconf, kubernetes

## 简介

Shared runtime of the docuconf JavaScript SDKs (@docuconf/t3, @docuconf/nestjs): contract writer, file checks, violations, durations, and contract-first validation.
