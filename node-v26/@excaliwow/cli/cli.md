# @excaliwow/cli

> 标签: cli, diagrams, drawing, excalidraw, excaliwow

## 简介

Command-line client for Excaliwow — create, read, render, and edit Excalidraw-style diagrams from your terminal or scripts, with a --json mode for piping.
