# @1start/ai-kit

> 标签: ai, analytics, bun, fallback, hono, llm, openai, session, streaming

## 简介

1start.net 的 LLM 中间层 SDK：多 provider 客户端、turn buffer 会话层、请求记账。一个包、四个入口，模块间只靠接口耦合。
