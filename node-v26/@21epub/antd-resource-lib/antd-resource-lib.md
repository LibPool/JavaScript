# @21epub/antd-resource-lib

> 标签: JavaScript

## 简介

基于 antd 5、jotai 与 ky 的素材库组件与工具集，支持 Modal 与 Panel 两种形态，并使用 `@tanstack/react-query` 获取与缓存数据。
