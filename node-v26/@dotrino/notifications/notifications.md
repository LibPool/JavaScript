# @dotrino/notifications

> 标签: cross-app, custom-element, dotrino, notifications, pwa, web-component, web-push

## 简介

Notificaciones compartidas del ecosistema Dotrino: controlador data-agnostic (permiso del navegador + preferencias por categoría con scope por app + disparo), el Web Component <dotrino-notifications> (panel de ajustes), helper de Web Push ligado al vault
