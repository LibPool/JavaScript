# @dotrino/theme

> 标签: css, design-tokens, dotrino, theme

## 简介

El tema del ecosistema Dotrino («Cool & Cozy»): colores claro y oscuro, tipografías Quicksand y Comfortaa empaquetadas, y las variables de los componentes compartidos. Una sola hoja para todas las apps.
