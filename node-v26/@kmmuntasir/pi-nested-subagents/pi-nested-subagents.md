# @kmmuntasir/pi-nested-subagents

> 标签: agent, autonomous, nested, nesting, pi, pi-extension, pi-package, subagent, verification

## 简介

A pi extension that brings Claude Code-style autonomous sub-agents to pi, with safe configurable nesting depth and built-in ground-truth verification. Fork of tintinweb/pi-subagents.
