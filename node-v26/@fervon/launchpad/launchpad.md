# @fervon/launchpad

> 标签: dashboard, dev-server, developer-tools, local-first, localhost, monorepo, port, process-manager, project-launcher, self-hosted

## 简介

Local-first dashboard to discover, launch and monitor every dev project in a folder — auto-detected, no port clashes, live logs. Binds 127.0.0.1 only.
