# @unrlzd/sdk

> 标签: builder-codes, dex, memecoin, near, near-intents, near-protocol, sdk, swap, trading, typescript, unrlzd

## 简介

TypeScript SDK for trading on NEAR from UNRLZD trading accounts: quotes, guardrails, checked signing, 24/7 orders and builder codes, in the browser or on a server.
