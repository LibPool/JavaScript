# mindlm-mcp

> 标签: claude, cli, cursor, markmap, mcp, mcp-server, mind-map, mindlm, mindmap, model-context-protocol, outline, pdf-to-mindmap, text-to-mindmap, url-to-mindmap

## 简介

MCP server + CLI that turns text, web pages and PDFs into interactive mind maps (Markdown outline → standalone markmap HTML). Zero API key required.
