# @scryb-editor/viewer

> 标签: html, prosemirror, read-only, renderer, rich-text-editor, server-side-rendering, ssr, tiptap, typescript, wysiwyg

## 简介

SSR-safe renderer that turns Tiptap JSON into an HTML string with no DOM and no client-side editor, for read-only pages
