# @scryb-editor/core

> 标签: accessibility, contenteditable, editor, headless, i18n, prosemirror, rich-text-editor, tiptap, typescript, wysiwyg

## 简介

Headless core for the Scryb rich text editor: a configured Tiptap factory, formatting commands, i18n and an accessibility checker
