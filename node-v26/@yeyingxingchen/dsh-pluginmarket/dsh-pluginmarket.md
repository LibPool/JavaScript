# @yeyingxingchen/dsh-pluginmarket

> 标签: deepseek-harness, dsh, empty, plugin, scaffold

## 简介

An empty plugin scaffold for the DeepSeek Harness (DSH) ecosystem. It installs and loads without doing anything — a clean starting point for your own plugin.
