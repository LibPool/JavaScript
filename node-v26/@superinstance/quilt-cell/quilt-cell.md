# @superinstance/quilt-cell

> 标签: 16-dial, cell, fnv-1a, polyformalism, quilt, shape-rag

## 简介

The Quilt cell as a JavaScript library. 16-dial Q1.15 vectors, FNV-1a 64-bit state hash, byte-exact with the Python/C/Rust/Verilog/VHDL ports.
