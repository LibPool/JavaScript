# @igarasy/br-payments

> 标签: boleto, br-code, brazil, brcode, cnpj, cnpj-alfanumerico, codigo-de-barras, cpf, febraban, linha-digitavel, payments, pix, qrcode

## 简介

Zero-dependency TypeScript toolkit for Brazilian payments: Pix BR Code (generate, parse, validate), Pix keys, boleto barcodes and digitable lines, CPF and CNPJ (including alphanumeric CNPJ).
