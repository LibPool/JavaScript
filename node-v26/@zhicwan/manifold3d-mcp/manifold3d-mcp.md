# @zhicwan/manifold3d-mcp

> 标签: 3d-printing, cad, claude-code, copilot-cli, llm, manifold-3d, mcp

## 简介

MCP server that lets an LLM build 3D models with manifold-3d, with live three.js preview and STL/3MF export.
