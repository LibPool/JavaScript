# @rightkit/settings-ui

> 标签: JavaScript

## 简介

Settings panel frame, search and standard sections (appearance, updates, license, legal, diagnostics, models, API keys, about) persisted through rightkit-app-settings. The panel shell and primitives (/core) need only React.
