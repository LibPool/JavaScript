# @easy-pwa/pwa-install-polyfill

> 标签: app, application, beforeinstallprompt, beforeinstallpromptevent, build, easy, home, install, ios, light, polyfill, progressive, pwa, screen, tool, web

## 简介

Polyfill for enabling the BeforeInstallPrompt event (in PWA context) on browsers which do not support it.
