# dsh-gitea

> 标签: deepseek-harness, dsh, dsh-plugin, forgejo, git, gitea, worktrees

## 简介

Gitea/Forgejo integration for DeepSeek Harness: 96 first-class tools for issues, pull requests, reviews, releases, CI, packages, wiki and worktrees (133 registered names with compatibility aliases), plus a settings UI and a live Git status chip.
