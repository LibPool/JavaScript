# @ethan-utils/zustand

> 标签: ethan-utils, npm, react, react hooks, react state management, state management, zustand

## 简介

封装 Zustand create 函数，一个带有 immer、可选持久化（persist）和选择性订阅（subscribeWithSelector）功能的 zustand store，支持 React 17+
