# @pandi-coding-agent/pandi-improve-prompt

> 标签: pi, pi-extension, pi-package, prompt, prompt-engineering

## 简介

Extensión de Pi que agrega el comando /improve-prompt: reescribe un borrador de prompt torpe en uno más claro y accionable, y luego ofrece enviarlo como tu próximo mensaje.
