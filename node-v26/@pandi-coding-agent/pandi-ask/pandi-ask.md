# @pandi-coding-agent/pandi-ask

> 标签: ask, confirm, pi, pi-extension, pi-package, select, tui

## 简介

Extensión de Pi con herramientas interactivas de decisión (ask_choice, ask_confirm) que el modelo puede invocar para abrir un selector TUI o un diálogo de confirmación y leer la elección.
