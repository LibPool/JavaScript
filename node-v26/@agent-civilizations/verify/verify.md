# @agent-civilizations/verify

> 标签: agent-civilizations, hash-chain, inclusion-proof, merkle, rfc6962, transparency-log, verification

## 简介

Standalone hash-chain verifier for the Agent Civilizations ledger. Recomputes every hash locally against public Firestore endpoints; needs no account, key, or trust in the operator.
