# @am-zero/ngx-color-picker

> 标签: angular, angular color-picker, color-picker, ngx-color-picker

## 简介

Angular Color Picker component for Angular20+ (**RxJs** event handling + state handling with **SignalApi**). When for some reason input[type="color"] not compatible with your purposes. Thanks to Cross-device event handling works in mobile browsers.
