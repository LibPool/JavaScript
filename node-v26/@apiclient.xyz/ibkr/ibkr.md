# @apiclient.xyz/ibkr

> 标签: api client, flex query, flex web service, ibkr, interactive brokers, portfolio, statement, typescript

## 简介

A read-only client for the Interactive Brokers Flex Web Service: fetches Activity Flex Query statements with IBKR's request protocol, rate limits and error codes, parses their XML into typed records, and checks a query has what a booking needs
