# jew-guard

> 标签: jev, opencode, opencode-plugin, prompt-injection, security, system-one, typesafe

## 简介

Opencode-only security guard: every tool call risk-scored and every tool result scanned by Jev (TypeSafe System One) over the Console gateway with your existing OpenCode credential. Zero-config: no keys, no key files.
