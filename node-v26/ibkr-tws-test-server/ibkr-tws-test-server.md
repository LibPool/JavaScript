# ibkr-tws-test-server

> 标签: ib-gateway, ibkr, interactive-brokers, test-server, testing, trading, tws, tws-api

## 简介

A local test server for the Interactive Brokers TWS API socket protocol, for testing trading programs: contracts, historical bars, market data, accounts, positions and the order lifecycle
