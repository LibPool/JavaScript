# @propersloth/parallax-threejs

> 标签: claude-code, claude-code-plugin, glsl, graphics, shader-debugging, three.js, visual-regression-testing, webgl

## 简介

Three.js/GLSL debugging for Claude Code — correlates scene graph, console, GL state, and pixels into one diagnosis. Plus SHA-indexed visual regression testing.
