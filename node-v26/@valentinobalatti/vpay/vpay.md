# @valentinobalatti/vpay

> 标签: checkout, dlocal, latam, mercadopago, payments, paypal, psp, routing, stripe

## 简介

One API for Stripe, Mercado Pago, PayPal and dLocal: route each payment to a PSP by country, currency, method or anything else, with normalized statuses and webhooks. Server lib + browser checkout.
