# @fringeworks/style-layouts

> 标签: css, layout, style

## 简介

`@fringeworks/style-layouts` is a library some will find handy, specialized in controlling child element layout with CSS.\ It returns class names and CSS custom properties as an object based on the given options. Framework-agnostic and SSR-compatible.
