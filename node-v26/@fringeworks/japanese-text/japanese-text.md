# @fringeworks/japanese-text

> 标签: full-width, half-width, hiragana, japanese, kana, katakana, normalize, shift_jis

## 简介

A library some will find handy, for converting and checking Japanese text, such as kana, full-width and half-width characters, and Shift_JIS.
