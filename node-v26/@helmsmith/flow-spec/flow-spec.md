# @helmsmith/flow-spec

> 标签: agent, dag, flow, json-schema, orchestration, validator, wire-contract, workflow

## 简介

The Helmsmith flow wire contract: flow/step/edge types, catalog validator (join-hazard analysis included), expression evaluator, JSON-Schema subset, conformance fixtures, and the generated schema artifact. Browser-safe, zero runtime dependencies.
