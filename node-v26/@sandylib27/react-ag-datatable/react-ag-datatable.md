# @sandylib27/react-ag-datatable

> 标签: ag-grid, column-menu, data-grid, datatable, filter, number-filter, pagination, radix-ui, react, set-filter, shadcn, table

## 简介

Production-ready React DataTable wrapping AG Grid Community with enterprise-grade features: searchable set filters, number filters, column header menus, integrated pagination, API mode with loading states, and a classical theme.
