# @massivescale/tsp-ts-client-models

> 标签: client, codegen, emitter, sdk, typescript, typespec, typespec-emitter

## 简介

TypeSpec emitter that generates a typed, publishable TypeScript client package: models, request types, endpoint utilities, and a fetch-based HTTP client.
