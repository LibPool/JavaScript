# @rythra/connector-seyfert

> 标签: JavaScript

## 简介

Official **Seyfert** connector for [Rythra](https://github.com/Ekretos/Rythra). Bridges Seyfert gateway events and voice states with Rythra's framework-agnostic audio runtime.
