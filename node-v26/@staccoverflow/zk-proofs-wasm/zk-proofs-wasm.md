# @staccoverflow/zk-proofs-wasm

> 标签: JavaScript

## 简介

wasm-bindgen wrapper around solana-zk-sdk proof generators (PubkeyValidity, ZeroCiphertext, CiphertextCommitmentEquality, BatchedRangeProof{U64,U128}, BatchedGroupedCiphertext3HandlesValidity) for Token-22 ConfidentialTransfer
