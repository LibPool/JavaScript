# @hy-sde-org/dsh-zstd-frame

> 标签: agent, checksum, deepseek, dsh-plugin, frame, harness, torn-frame, zstandard, zstd

## 简介

Zstandard frame primitives (scan / compress / decompress / multi-frame decoder) shared by the DeepSeek Harness session persistence backend and project memory bank, as a standalone npm package.
