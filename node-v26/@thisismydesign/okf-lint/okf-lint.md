# @thisismydesign/okf-lint

> 标签: frontmatter, knowledge-catalog, lint, linter, markdown, okf, open-knowledge-format, validator

## 简介

An opinionated linter for Google's Open Knowledge Format (OKF) knowledge catalogs — errors for spec violations, warnings for missing-but-useful conventions.
