# @usecreable/mcp

> 标签: claude-desktop, mcp, model-context-protocol, proxy, stdio, usecreable

## 简介

Thin stdio↔HTTP bridge connecting stdio MCP clients (e.g. Claude Desktop) to the hosted usecreable MCP server.
