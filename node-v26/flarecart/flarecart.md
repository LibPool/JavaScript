# flarecart

> 标签: checkout, cloudflare-workers, digital-downloads, ecommerce, license-keys, r2, stripe

## 简介

Sell digital files and licence keys from a static site: Stripe Checkout, your own R2 bucket, one Cloudflare Worker.
