# @multiplechain/sui

> 标签: blockchain, crypto, multiple-chain, web3

## 简介

MultipleChain aims for easy access by simplifying the complex structure of many blockchains. For example, each blockchain network has a different structure for transfer initiation or transaction data. You may need to learn new things from scratch for each
