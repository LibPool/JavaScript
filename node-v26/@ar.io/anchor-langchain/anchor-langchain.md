# @ar.io/anchor-langchain

> 标签: agents, ai, anchoring, ar.io, arweave, audit-trail, langchain, provenance

## 简介

Anchor your LangChain.js agent's run tree as it executes: one callback handler turns every chain/LLM/tool step into a Merkle-batched, individually inclusion-proofed provenance record on ar.io — prompts and outputs are hashed locally and never uploaded.
