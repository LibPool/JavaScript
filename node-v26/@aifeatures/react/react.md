# @aifeatures/react

> 标签: JavaScript

## 简介

React components for aifeatures sites: form CAPTCHA (Cloudflare Turnstile), headless payments (product price, buy button, order confirmation), and cookie consent (geo-adaptive banner, category-gated scripts, preferences)
