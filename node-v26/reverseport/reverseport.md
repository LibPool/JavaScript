# reverseport

> 标签: agent-skills, agents, android, binary-analysis, claude-code, clean-room, cli, codex, cursor, decompiler, disassembler, electron, game-dev, ghidra, godot, hopper, ida, mcp, mcp-server, migration, model-context-protocol, porting, reverse-engineering, static-analysis, threejs, unity, unreal

## 简介

Reverse engineer anything. Port it anywhere. One CLI and MCP server that lets coding agents take apart apps, games, binaries and websites — decompile, trace, compare builds, recon without files — and rebuild or port them to Godot, Unity, Unreal, three.js
