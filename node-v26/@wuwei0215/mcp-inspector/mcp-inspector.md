# @wuwei0215/mcp-inspector

> 标签: JavaScript

## 简介

MCP Inspector 是一款运行在测试人员电脑上的 MCP Tool 调试工作台。当前版本支持无认证与 OAuth 的 Streamable HTTP MCP Server，并以类似接口调试工具的方式组织连接、Tools、请求参数、结果和协议详情。
