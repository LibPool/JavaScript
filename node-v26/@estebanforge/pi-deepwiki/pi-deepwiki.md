# @estebanforge/pi-deepwiki

> 标签: ai, codebase-docs, coding-agent, deepwiki, documentation, github, pi-extension, pi-package

## 简介

DeepWiki (deepwiki.com) docs tool for Pi. Adds deepwiki_wiki_structure and deepwiki_ask_question tools that query the hosted DeepWiki MCP service over plain HTTP. No MCP adapter required. AI-powered documentation for any public GitHub repository.
