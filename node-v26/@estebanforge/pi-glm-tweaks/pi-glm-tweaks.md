# @estebanforge/pi-glm-tweaks

> 标签: glm, glm-5.2, glm-5.3, glm-5.3-flash, mcp, pi-extension, pi-package, reasoning_effort, thinking, thinking-mode, web-search, z-ai, zai

## 简介

Pi-native tweaks for Z.AI's GLM coding models (glm-5.2, glm-5.3, glm-5.3-flash, and [1m] variants). Restricts the Pi thinking-level UI to the modes each model supports on the wire, wires the native thinkingFormat:"zai" translation, and auto-clamps hidden
