# @elaraai/east-plugin

> 标签: claude-code, codex, east, elara, mcp, plugin

## 简介

East's agent plugin runtime — the example index generator, the example search and its MCP tools, the search-first hooks and the Codex skill adapter — for a Claude Code or Codex plugin that builds on East's.
