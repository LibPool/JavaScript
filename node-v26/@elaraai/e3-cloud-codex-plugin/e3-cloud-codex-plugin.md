# @elaraai/e3-cloud-codex-plugin

> 标签: apps, e3, e3-cloud, east, elara, typescript

## 简介

e3 cloud - apps for hosted e3 workspaces with @elaraai/e3-cloud-ui, files from buckets as inputs with @elaraai/e3-cloud-files, the e3-cloud CLI and @elaraai/e3-cloud-client: skills, example search and the search-first hooks
