# @gaonjs/adapter-mongo

> 标签: JavaScript

## 简介

Gaon 선택형 문서형(MongoDB) 어댑터 — collection()·mongoSchema() (Mongoose 기반 · SQL model() 과 나란한 문서형 축). mongoose 는 optional peer 로 opt-in.
