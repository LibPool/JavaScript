# @sjhmars/happy-bridge

> 标签: bridge, companion, deepseek-harness, dsh, dsh-plugin, happy, happy-app, mobile, pairing, qr-code, remote, remote-control

## 简介

Remote-control bridge: pair a running dsh web/desktop client with the Happy mobile app by QR code, then remote-control the same harness sessions from the phone (send messages, read replies, approve tool calls, switch models)
