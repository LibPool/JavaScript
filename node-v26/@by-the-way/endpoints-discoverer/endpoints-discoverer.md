# @by-the-way/endpoints-discoverer

> 标签: api, discovery, dynamic, node, routes

## 简介

Automate API route detection by scanning a folder, matching files with a predefined pattern, and generating a dynamic object mapping routes, HTTP verbs, and module exports.
