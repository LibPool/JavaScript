# @sioma/copilot

> 标签: ai-sdk, assistant, browser, copilot, sioma

## 简介

Browser-runtime copilot SDK for Sioma. The agent loop runs in the page on the Vercel AI SDK (injected model, never imported), grounded per turn by a Sioma cell: focus -> streamText -> outcome. Optional /ui entry ships a framework-free chat widget.
