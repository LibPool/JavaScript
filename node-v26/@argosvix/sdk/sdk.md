# @argosvix/sdk

> 标签: ai-cost-tracking, ai-monitoring, anthropic, argosvix, gemini, llm, mistral, observability, openai, transparent-proxy

## 简介

Drop-in observability wrapper for OpenAI, Anthropic, Gemini, Mistral SDK clients. One-line wrap() = cost / latency / quality records.
