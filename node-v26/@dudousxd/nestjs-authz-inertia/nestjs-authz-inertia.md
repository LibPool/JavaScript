# @dudousxd/nestjs-authz-inertia

> 标签: abilities, authorization, authz, can, inertia, inertia.js, nestjs

## 简介

Inertia.js integration for @dudousxd/nestjs-authz — share a user's abilities as props so client `can()` checks need no network request.
