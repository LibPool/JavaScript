# @dudousxd/adonis-authkit-client

> 标签: adonisjs, authentication, authkit, jwt, oauth2, oidc, openid-connect, relying-party

## 简介

AdonisJS OIDC/OAuth2 relying-party (client) toolkit: session-based authentication against an OpenID Connect identity provider, with JWT/PAT user resolvers and OpenTelemetry metrics.
