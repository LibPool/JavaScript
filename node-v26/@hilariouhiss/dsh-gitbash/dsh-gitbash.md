# @hilariouhiss/dsh-gitbash

> 标签: bash, deepseek-harness, dsh, dsh-plugin, gitbash, shell, windows

## 简介

Git Bash as a first-class shell on Windows for DeepSeek Harness — a realm-scoped `ctx.shell` executor plus the standard `bash` tool, wired to the real Git for Windows bash.exe instead of PATH's WSL launcher.
