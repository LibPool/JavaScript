# @agenticprimitives/admission

> 标签: a2a, admission, agent-authority, agentic, agentic-primitives, agentic-trust, agenticprimitives, ai-agents, authorization, edge, primitives

## 简介

Agentic Primitives Edge admission contracts: transport evidence, application authentication, canonical actor resolution, admission grants, and exact MCP invocation authorization. Zero runtime dependencies; admission is never authority.
