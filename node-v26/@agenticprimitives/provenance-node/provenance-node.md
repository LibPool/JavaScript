# @agenticprimitives/provenance-node

> 标签: agentic, agenticprimitives, conformance, primitives, prov-o, provenance, rdfc, shacl

## 简介

Node-side reference bindings of the provenance ports (spec 414 §5): the W3C RDFC-1.0 canonicalizer, SHACL validation over the published run shapes, a directory store, and the `ap conform provenance` suite (C1–C6) any binding is run through.
