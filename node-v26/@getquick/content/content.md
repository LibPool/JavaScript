# @getquick/content

> 标签: JavaScript

## 简介

The configured content runtime for WordPress HTML and WPGraphQL. This slice provides pure helpers, the configured WordPress client, durable delivery and installed SQL migrations, and event/refresh HTTP handlers. It is released as a pair with the Composer
