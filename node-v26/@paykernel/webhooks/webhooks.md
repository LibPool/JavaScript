# @paykernel/webhooks

> 标签: deduplication, idempotency, paykernel, payment-webhooks, payments, typescript, webhook-inbox, webhooks

## 简介

Storage-agnostic webhook inbox engine for @paykernel/core: claim, dedupe, retry, lease-fenced processing outcomes (no HTTP hardcoding).
