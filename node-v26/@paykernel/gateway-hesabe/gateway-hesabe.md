# @paykernel/gateway-hesabe

> 标签: gateway, hesabe, kuwait, mena, paykernel, payments, typescript

## 简介

Portable Hesabe gateway adapter for @paykernel/core: encrypted checkout, transaction enquiry, merchant refunds, and enquiry-verified webhooks.
