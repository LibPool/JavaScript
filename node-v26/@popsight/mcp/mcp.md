# @popsight/mcp

> 标签: ai-visibility, local-first, mcp, model-context-protocol, popsight, seo

## 简介

Local-first read-only Model Context Protocol server for Popsight. Attaches to the desktop app's SQLite DB in read-only mode and exposes 12 tools so AI assistants (Claude Desktop, Cursor, Claude Code) can read your runs, prompts, citations, and metrics dir
