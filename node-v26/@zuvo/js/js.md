# @zuvo/js

> 标签: auth, baas, postgres, realtime, storage, supabase, supabase-js, zuvo

## 简介

Zuvo JavaScript client — thin wrapper over @supabase/supabase-js for Auth, Database, Realtime, and Storage. Protocol-compatible with Supabase clients against Zuvo project URLs.
