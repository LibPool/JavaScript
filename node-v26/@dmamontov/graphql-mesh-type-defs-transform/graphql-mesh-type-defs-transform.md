# @dmamontov/graphql-mesh-type-defs-transform

> 标签: JavaScript

## 简介

Type Defs Transform - is a transformation plugin for GraphQL Mesh that allows you to extend and modify your existing GraphQL schema. This transform provides a powerful way to add new types, extend existing ones, or even introduce new queries and mutations
