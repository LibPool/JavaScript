# dsh-agvideo

> 标签: JavaScript

## 简介

常驻版 Agnes AI 视频生成工具（原动态插件 agvid-1 / agvid-video 固化交付）：注册 generate_video 模型工具，支持 text / keyframe / reference 三模式，自动轮询至完成，视频卡在会话内以 240px 上限显示。
