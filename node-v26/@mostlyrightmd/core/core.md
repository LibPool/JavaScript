# @mostlyrightmd/core

> 标签: ai-agents, backtesting, json-schema, kalshi, local-first, machine-learning, ml-training, polymarket, prediction-markets, quant-research, schema-versioned, sdk, time-series, typescript, weather, weather-data

## 简介

TypeScript SDK core for quants, ML pipelines, and AI agents: types, schemas, validators, temporal-safety primitives, and the research() join over weather data + prediction-market settlements. Local-first, no hosted backend.
