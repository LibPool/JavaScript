# @ng-linguo/eslint-plugin

> 标签: angular, eslint, eslintplugin, i18n, ng-linguo

## 简介

ESLint flat-config presets for ng-linguo consumers — teaches Angular template rules about the [t] directive so translator-safe markup lints clean.
