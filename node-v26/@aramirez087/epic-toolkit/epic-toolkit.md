# @aramirez087/epic-toolkit

> 标签: JavaScript

## 简介

Run multi-session epics as a **directed acyclic graph**, with **parallel siblings executing in their own git worktrees** and merging back into a coordinator trunk branch wave by wave. Works with both **Claude Code** and **OpenCode**.
