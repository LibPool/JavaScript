# @kuttystack/preact-browser-store

> 标签: indexdb, kutty, kuttystack, localstorage, npm, preact-browser-store

## 简介

A lightweight, reactive storage orchestration layer for Preact and React. Manage **LocalStorage**, **IndexedDB**, and custom providers with a unified API and automatic UI synchronization.
