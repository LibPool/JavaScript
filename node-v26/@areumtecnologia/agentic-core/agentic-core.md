# @areumtecnologia/agentic-core

> 标签: agent, agentic-loop, ai, autonomous, chatbot, customer-service, google-gemini

## 简介

Framework profissional para orquestração de Agentes Autônomos em Node.js com suporte multi-provedor (Gemini, OpenAI, Anthropic, Ollama, Nvidia), streaming em tempo real, auto-RAG de memória, políticas de segurança, failover automático e telemetria nativa.
