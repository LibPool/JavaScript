# @anoobsuresh0/react-go-stack-app

> 标签: cli, docker, fullstack, go, golang, postgresql, react, scaffold, starter, template

## 简介

CLI to scaffold production-ready full-stack apps with Go (Gin or stdlib), React 19 (Vite + TypeScript + Tailwind + shadcn/ui), PostgreSQL, and Docker with optional Google OAuth
