## 简介

Deterministic agent harness for pnpm monorepos that ship a Next.js 16 web app AND an Expo (React Native) mobile app over one shared Supabase backend: Claude Code hooks, security-invariant lint gates, RLS isolation tests, cross-surface parity and design-to
