# @adviverse/react

> 标签: ads, adslot, adviverse, nextjs, react

## 简介

React components for Adviverse ad slots — <AdSlot />, <AdScript />, <AdRefresh />. One import, no dangerouslySetInnerHTML, no currentScript workarounds.
