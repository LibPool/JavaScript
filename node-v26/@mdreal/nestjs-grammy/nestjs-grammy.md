# @mdreal/nestjs-grammy

> 标签: bot, decorators, dependency-injection, grammy, grammyjs, nestjs, polling, telegram, telegram-bot, typescript, webhook

## 简介

NestJS module for building Telegram bots with grammY — decorator-driven handlers, multi-bot support, dependency injection, and polling/webhook runtimes.
