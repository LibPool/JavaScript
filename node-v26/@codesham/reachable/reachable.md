# @codesham/reachable

> 标签: dependencies, npm, osv, reachability, sca, security, static-analysis, vulnerability

## 简介

Tells you which dependency vulnerability alerts your JavaScript code can actually trigger: reachable, unreachable, or cant_tell, with evidence for each.
