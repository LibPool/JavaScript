# @authfly/node

> 标签: JavaScript

## 简介

Authfly adapter for the TypeScript runtimes (React, Vue, Svelte, Solid hosts on Node/Bun/Deno): OIDC authorization code + PKCE against Stalwart via the Authfly hosted sign-in, ID token verification, signed session cookies, and a client of the Authfly JSON
