# @lim324/dsh-session-manager

> 标签: JavaScript

## 简介

Full session management for the DSH web UI: delete (with trash/restore/purge), restore archived sessions, activity stats, continue/pause, fork to a new chat, unread markers, and open log folders. Plus a global context compaction threshold. No harness chan
