# @lim324/dsh-surface

> 标签: JavaScript

## 简介

surface-fork plugin for the DSH Web GUI: continue a session in a lightweight NEW session seeded from the latest compaction checkpoint to a target turn (surface re-seed), implemented as a standalone bundle plugin with zero edits to the deepseek-harness pac
