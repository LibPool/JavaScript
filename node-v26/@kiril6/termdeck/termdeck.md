# @kiril6/termdeck

> 标签: ai-agents, claude-code, cli, codex, coding-agents, dashboard, gemini-cli, git-worktree, localhost, node-pty, pty, shell, terminal, tmux, web-terminal, xterm

## 简介

Local-first browser cockpit for running AI coding agents (Claude Code, Codex, Gemini) and shells in floating windows backed by real PTYs. Git worktree per agent, approval alerts, sessions that survive restarts.
