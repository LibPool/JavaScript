# @artscript/core

> 标签: ai, ai agents, art script, artscript, claude, compiler, framework, fullstack, language, llm, reactive, signals, web, web framework

## 简介

ArtScript (Art Script): a full-stack web framework and language for AI agents. Apps built and changed for half the cost of React, with 5 KB of JavaScript.
