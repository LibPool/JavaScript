# @tiaohsun/vue-rich-text-editor

> 标签: editor, prosemirror, rich-text-editor, tiptap, vue, vue3, wysiwyg

## 简介

A thin, batteries-included Vue 3 wrapper around Tiptap v3 — editor component, toolbar, bubble menus, i18n, HTML/JSON output.
