# @megen-lebar/dsh-runtime-updater

> 标签: deepseek-harness, dsh, runtime, settings, updater

## 简介

仅适用于 megen-lebar Electron 封装的 DeepSeek Harness 的 Windows runtime 管理器：查看安装和备份，并安全删除旧版本。
