# @nqmcreative/ui

> 标签: component-library, components, design-system, runes, svelte, svelte5, sveltekit, tailwind-v4, tailwindcss, ui

## 简介

Svelte 5 + Tailwind CSS v4 component library — three styles (matte, paper, sprout), 70 components each, one shared behaviour core. Icons by @lucide/svelte.
