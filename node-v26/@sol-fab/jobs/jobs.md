# @sol-fab/jobs

> 标签: jobs, postgres, queue, sol

## 简介

Sol's durable Postgres job queue for TypeScript workers -- a transactional, dedupe-keyed enqueue and a leased runner, mirroring sol-jobs. A library, not a primitive: host it from an ordinary @sol-fab/worker binary.
