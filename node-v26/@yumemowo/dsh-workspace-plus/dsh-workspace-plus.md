# @yumemowo/dsh-workspace-plus

> 标签: cordis, deepseek-harness, dsh-plugin, sidebar, web-ui, workspace

## 简介

为 dsh Web 侧边栏提供两级分组：工作区分组（把一组工作区打包管理，只出现在列表最外层）与会话分组（每个工作区内部的会话归类）。
