# @mojskin/vue-shortcut-manager

> 标签: hotkey, keyboard, shortcut, vue

## 简介

A powerful keyboard shortcut manager for Vue 3 applications with support for multi-key bindings, conditional execution, element targeting, navigation, and auto-generated help dialogs. Perfect for complex forms, dashboards, and productivity tools.
