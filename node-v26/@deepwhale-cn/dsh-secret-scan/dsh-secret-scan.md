# @deepwhale-cn/dsh-secret-scan

> 标签: api-key, chinese, credential, deepseek-harness, devsecops, dsh, leak, plugin, pre-commit, private-key, secret-scan, security, skill, token

## 简介

密钥与敏感信息扫描：提交前、发布前把代码里的 API Key、令牌、私钥、凭据文件、内部域名找出来 —— 输出默认打码，可作为 pre-commit / CI 卡口。
