# @ps-aux/deployers

> 标签: JavaScript

## 简介

Simple glue tools which make use of SSH, Docker, Docker Compose, Kubernetes (tbd), Handlebars ... to present simple and clean interface for application deployment while enforcing standard and (hopefully) best practices.
