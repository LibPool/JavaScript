# @systemfsoftware/all

> 标签: cell-architecture, effect, effect-ts, oxlint, oxlint-config, preset, schema, typescript, workflow

## 简介

Complete oxlint preset for Effect and cell architecture: bundles all custom rule plugins (workflow, schema, entrypoint, property testing, test placement, hygiene) with type-aware correctness settings in a single config.
