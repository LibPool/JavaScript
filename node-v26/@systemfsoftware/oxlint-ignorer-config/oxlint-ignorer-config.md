# @systemfsoftware/oxlint-ignorer-config

> 标签: ignorer, oxlint, oxlint-config, stryker

## 简介

The lint preset for an ignorer package: one path per decision, no casts on foreign data, and no StrykerJS runtime behind an ignorer
