# @hevcjs/dashjs-plugin

> 标签: browser, codec, dash, dashjs, dashjs-plugin, h.265, h265, hevc, media-source-extensions, mediasource, mpeg-dash, mse, ott, plugin, streaming, transcoding, video, wasm, webassembly

## 简介

dash.js plugin for HEVC/H.265 playback — transparently intercepts MSE to decode HEVC streams via @hevcjs/core
