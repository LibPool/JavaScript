# @scampjs/adapter-cloudflare

> 标签: adapter, cloudflare, pages, scamp, scampjs, workers

## 简介

Deploy a Scamp framework project to Cloudflare Workers (with static assets) or Pages: scamp build writes dist/_worker.js and a wrangler.jsonc.
