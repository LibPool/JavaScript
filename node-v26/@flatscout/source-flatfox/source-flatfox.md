# @flatscout/source-flatfox

> 标签: JavaScript

## 简介

A Flatscout **source** plugin that fetches Swiss rental listings from [Flatfox](https://flatfox.ch)'s public REST API (`https://flatfox.ch/api/v1/public-listing/`) and emits canonical `RawListing` records into the Flatscout pipeline.
