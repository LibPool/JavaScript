# @flatscout/source-immobilier-ch

> 标签: JavaScript

## 简介

Source plugin for [immobilier.ch](https://www.immobilier.ch). HTML-scraping plugin built on the site's public sitemap + embedded JSON-LD blocks. No anti-bot, no auth.
