# dsh-kimi-assemble

> 标签: browser-automation, computer-use, deepseek-harness, desktop-automation, dsh, dsh-bundle, dsh-plugin, kimi, kimicu, webbridge

## 简介

Native DeepSeek Harness tools for the Kimi browser extension (WebBridge) and KimiCU desktop control: kimi_browser_* drives the user's real logged-in browser, kimi_cu_* observes and operates Windows desktops.
