# @podkst/mcp-server

> 标签: ai, mcp, mcp-server, model-context-protocol, podcast, podkst, text-to-speech, tts

## 简介

Official MCP server for podkst.ai: generate AI podcasts (two-host dialogue, monologue, script-to-audio) from any MCP client over stdio.
