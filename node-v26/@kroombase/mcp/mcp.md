# @kroombase/mcp

> 标签: ai, claude, cursor, database, kroombase, mcp, model-context-protocol, postgres, storage, vscode

## 简介

KroomBase MCP server — connect Claude, Cursor, VS Code or any MCP client to your KroomBase backend. One session token reaches every project, its API key, SQL and storage.
