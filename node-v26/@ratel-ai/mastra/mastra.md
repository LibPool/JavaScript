# @ratel-ai/mastra

> 标签: ai-agents, context-engineering, framework-adapter, mastra, ratel, tool-calling

## 简介

Mastra adapter for Ratel — adapts the context-engineering core to @mastra/core tool and message shapes, with a per-turn recall input processor.
