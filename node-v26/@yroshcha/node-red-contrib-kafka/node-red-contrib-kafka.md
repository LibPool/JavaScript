# @yroshcha/node-red-contrib-kafka

> 标签: JavaScript

## 简介

Node-RED Kafka nodes: Send, Receive, and Schema validation with modern KafkaJS. Fork of @oriolrius/node-red-contrib-kafka adding Protobuf + Confluent Schema Registry support to the producer node.
