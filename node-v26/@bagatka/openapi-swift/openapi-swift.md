# @bagatka/openapi-swift

> 标签: codegen, effect, http-api, ios, openapi, openapi-3.1, swift, swift-client

## 简介

Writes a typed Swift 6 client of an HTTP API from its OpenAPI 3.1 document, such as Effect's HttpApi writes, on Foundation alone.
