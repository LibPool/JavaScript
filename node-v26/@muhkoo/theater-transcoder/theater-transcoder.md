# @muhkoo/theater-transcoder

> 标签: ffmpeg, hls, muhkoo, transcode, worker

## 简介

Drain a Muhkoo Theater transcode queue with NATIVE ffmpeg. Run it on any machine signed in as you to add transcoding power to your library.
