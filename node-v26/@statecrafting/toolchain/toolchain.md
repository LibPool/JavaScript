# @statecrafting/toolchain

> 标签: JavaScript

## 简介

The Encore build toolchain: the vendored Encore build drivers (dev/build/bundle), the app-model extractor (enrahitu-extract), and the encore-runtime.node and tsparser-encore binaries delivered as per-platform packages. Pins upstream encoredev/encore v1.57
