# @vouch-protocol-official/expo-sonic

> 标签: audio-watermark, did, ed25519, expo, expo-module, react-native, rust, sonic, uniffi, vouch, watermark-detection

## 简介

Expo native module wrapping the Vouch Sonic Core (Rust/UniFFI) for real on-device audio watermark detection and Ed25519 signature verification on iOS + Android.
