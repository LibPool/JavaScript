# @qorpiq/mcp-server

> 标签: cin, company-data, din, india, kyb, mca, mcp, ministry-of-corporate-affairs, model-context-protocol, qorpiq

## 简介

MCP server for Indian company and director data (MCA registry): CIN, LLPIN, DIN lookups, MCA status and new incorporations, powered by QorpIQ.
