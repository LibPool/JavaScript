# @lace-cloud/host

> 标签: JavaScript

## 简介

Vscode-free host library for talking to a `lace engine` process from Node.js. Provides the gRPC-JS transport, server lifecycle, handshake parser, RPC error classifier, and the Subscribe stream handler.
