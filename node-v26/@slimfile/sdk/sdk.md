# @slimfile/sdk

> 标签: api, compress, compression, docx, image, jpeg, office, pdf, png, pptx, sdk, slimfile, webp, xlsx

## 简介

Official JavaScript/TypeScript SDK for the SlimFile API — compress images, PDFs, and Office documents programmatically with up to 95% file size reduction.
