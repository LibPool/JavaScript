# @imba_wallet/agent-mcp-docs

> 标签: agent-api, agentic-wallet, docs, esim, gift-cards, imba, mcp, prepaid-visa

## 简介

Read-only MCP for IMBA prepaid Agent API: Visa prepaid, eSIM, gift-card, and KYT playbooks and policy. No deposit, buy, or withdraw. Convert at tier 1 is a separate request.
