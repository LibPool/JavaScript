# @js2mail/mcp

> 标签: ai, claude, cursor, email, form, js2mail, mcp, model-context-protocol

## 简介

Model Context Protocol server for JS2Mail — lets AI assistants provision contact-form endpoints and API accounts without making the user sign up first.
