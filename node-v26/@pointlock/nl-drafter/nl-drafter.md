# @pointlock/nl-drafter

> 标签: JavaScript

## 简介

NL → YAML draft assistant (03 §4.1/§4.1.1). Lives outside the trust boundary: it only drafts *.flow.yaml and asks structured elicitation questions; `pointlock compile` is the sole enforcer.
