# @yiyunet/dsh-mcp-client-manager

> 标签: deepseek-harness, dsh, dsh-plugin, mcp, mcp-client, settings-panel

## 简介

在 设置 → 侧栏 提供「MCP 客户端」面板：列出/添加/改写/启停 @deepseek-ai/dsh-mcp-client 的 MCP 行；受管行写入自有层 $DSH_HOME/cordis.patch.yml，手写行走官方 configEditor/pluginManager 通道。零构建、零运行依赖。
