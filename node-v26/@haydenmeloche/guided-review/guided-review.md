# @haydenmeloche/guided-review

> 标签: ai, claude, cli, code-review, codex, github, pull-request, terminal, tui

## 简介

Review GitHub pull requests as a guided tour in your terminal: chapters that follow the code's flow, tests beside each change, and one review to submit.
