# @crosshatch/ai-provider

> 标签: ai, crosshatch, data, integrations, personalization, vercel

## 简介

The **[Crosshatch provider](https://sdk.vercel.ai/providers/ai-sdk-providers)** for the [Vercel AI SDK](https://sdk.vercel.ai/docs) contains language model support for the Crosshatch API.
