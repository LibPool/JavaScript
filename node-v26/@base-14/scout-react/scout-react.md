# @base-14/scout-react

> 标签: base14, logs, metrics, observability, opentelemetry, otel, react, react-native, real-user-monitoring, rum, scout, tracing, web-vitals

## 简介

Zero-config OpenTelemetry RUM for React and React Native. Auto-captures clicks, navigation, errors, lifecycle, network, performance, and web vitals.
