# dsh-devlog-auto

> 标签: agent, cordis, deepseek-harness, developer-log, devlog, dsh, plugin

## 简介

DSH (DeepSeek Harness) plugin: auto-write a first-person dev log at agent/turn-stopping. Turns context + memory into a narrative log for the developer's own review.
