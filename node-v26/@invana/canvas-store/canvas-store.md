# @invana/canvas-store

> 标签: canvas, crdt, reactive, state, store, telemetry

## 简介

State machinery of the Invana canvas — the immer-backed ReactiveStore engine + adapters (zustand now, Yjs later), history, picking (rbush), telemetry, and the CanvasStore factory. The vocabulary and contracts live one floor below in @invana/canvas-core.
