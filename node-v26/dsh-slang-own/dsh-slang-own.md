# dsh-slang-own

> 标签: corpus, deepseek-harness, dsh, dsh-plugin, meme, slang, 语料库, 黑话

## 简介

网络黑话与隐晦词语料库：本地倒排索引支持中文全称/拼音首字母/别名互查，常驻注入高频速查表，提供 slang_lookup / slang_add / slang_stats 三个工具，词条可自建沉淀。
