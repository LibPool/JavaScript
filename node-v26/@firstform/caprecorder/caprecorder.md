# @firstform/caprecorder

> 标签: cap, capture, cross-platform, headless, napi, recorder, rust, screen-recording, screencapture, system-audio, video, window-capture

## 简介

A headless screen recording library powered by Cap, built with Rust and exposed to Node.js via NAPI. High-performance screen and window capture with system audio recording support.
