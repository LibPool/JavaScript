# @fortemi/graph

> 标签: canvas, community-detection, fortemi, graph, graph-layout, knowledge-graph, svg, visualization

## 简介

Framework-agnostic graph tooling for fortemi: pure TypeScript helpers for community-graph layout, filtering, color assignment, degree sizing, bounds/fit, neighborhood expansion, and static snapshot serialization, plus an optional controller subpath for da
