# @tournamental/create-app

> 标签: create-app, plugin, scaffold, starter, tournamental

## 简介

One-command scaffolder for Tournamental plugins and extensions. Run with `npm create @tournamental/app` or `pnpm create @tournamental/app`.

## 官网

- 官网：https://tournamental.com/build
- 源码仓库：git+https://github.com/0800tim/tournamental.git
- npm 页面：https://www.npmjs.com/package/@tournamental/create-app
