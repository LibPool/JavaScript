# @mirage-cli/sms-cli

> 标签: android-sms-gateway, cli, messaging, mirage, sms

## 简介

SMS inbox CLI — list, read, send, reply, search messages via an SMS Gateway-backed Cloudflare Worker. Mirage / Cloudflare-Worker compatible.
