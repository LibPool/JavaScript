# @mirage-cli/call-cli

> 标签: call, cli, elevenlabs, mirage, telephony, tts

## 简介

Phone call + audio injection CLI — make calls with TTS or pre-uploaded audio via an Android-bridge Cloudflare Worker. Mirage / Cloudflare-Worker compatible.
