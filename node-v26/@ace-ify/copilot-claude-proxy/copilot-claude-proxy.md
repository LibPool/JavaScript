# @ace-ify/copilot-claude-proxy

> 标签: ai, anthropic, claude, copilot, github, openai-compatible, proxy

## 简介

Local compatibility proxy that accepts Anthropic-style POST /v1/messages calls and forwards them to GitHub Copilot's OpenAI-compatible endpoint. Ideal for using Claude Code with Copilot models.
