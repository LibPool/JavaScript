# @tempoventures/mcp-tool

> 标签: JavaScript

## 简介

defineTool() for MCP servers: every tool gets a mandatory class (cteni, zapis, nevratne, odeslani) that sets MCP annotations and _meta, plus a consistency check and a catalog generator.
