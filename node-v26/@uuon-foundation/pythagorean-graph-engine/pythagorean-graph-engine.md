# @uuon-foundation/pythagorean-graph-engine

> 标签: ["pythagorean-tree","fractal","three-js","procedural-generation","graph-engine","webgl","recursive-geometry","uuon"]

## 简介

Interactive 3D Pythagorean tree engine. Recursive topology with F=(P,E,R,C) procedural compression. Runs in browser, no install. UUON Foundation.
