# @mgong/mcp-to-skills

> 标签: agent, anthropic, claude, claude-code, cli, cursor, mcp, model-context-protocol, skills

## 简介

Discover MCP servers configured for Claude Code and turn them into Skills (SKILL.md + per-tool JSON schemas) for Claude / Cursor.
