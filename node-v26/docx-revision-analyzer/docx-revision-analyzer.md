# docx-revision-analyzer

> 标签: academic-integrity, ai-detection, chart, cli, docx, flow, revision-history, svg, track-changes, visualization, word

## 简介

Analyze Word (.docx) Track Changes history: chart edit activity over time, draw how paragraphs flow across editing sessions, and score suspiciously abrupt, paste-like insertions (possible AI-generated text). / 変更履歴(Track Changes)付きWordファイル(.docx)から、編集の時系列
