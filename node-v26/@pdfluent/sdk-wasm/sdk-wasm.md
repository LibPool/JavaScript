# @pdfluent/sdk-wasm

> 标签: acroform, annotate, browser, edit-pdf-text, find-and-replace, forms, pades, pdf, pdf-editor, pdf-text-replace, pdfluent, redact, sdk, wasm, xfa

## 简介

PDFluent browser SDK — find and replace PDF text programmatically while preserving fonts and layout, plus edit, annotate, redact, sign and validate PDFs (including XFA), entirely client-side via WASM.
