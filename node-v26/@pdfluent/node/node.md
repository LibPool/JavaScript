# @pdfluent/node

> 标签: acroform, annotations, compliance, edit-pdf-text, encryption, find-and-replace, forms, napi, pdf, pdf-a, pdf-text-replace, pdfluent, redaction, render, rust, signature, text-extraction, xfa

## 简介

PDF SDK for Node.js — find and replace PDF text while preserving fonts and layout, plus rendering, text extraction, forms, annotations, redaction, encryption, and PDF/A compliance.
