# @webpieces/openapi-generator

> 标签: docs, mcp, openapi, typescript, webpieces

## 简介

Render an ApiDocModel to OpenAPI 3.1.0 — the canonical internal document and the customer-published one, JSON and YAML, from one generation pass. Ships the wp-openapi bin.
