# @aztec/cdb

> 标签: JavaScript

## 简介

Generated TypeScript server bindings for the Cdb IPC service: wire types, the `Handler` interface, and `handleRequest`/`dispatch`. The byte transport is provided by the consumer — e.g. `UdsIpcServer` from `@aztec/ipc-runtime`.
