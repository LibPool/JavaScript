# @avee1234/skillbridge

> 标签: agent, antigravity, claude-code, codex, converter, cursor, mcp, portable, skills, sub-agents

## 简介

Write an agent skill once, run it on any agent harness. Converts a portable skill.sb.md (skills, sub-agents, MCP, hooks, args, permissions) into native files for Antigravity, Claude Code, Codex, and Cursor.
