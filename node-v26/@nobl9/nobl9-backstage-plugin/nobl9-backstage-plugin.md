# @nobl9/nobl9-backstage-plugin

> 标签: JavaScript

## 简介

This plugin is one of two [Backstage](https://backstage.io) plugins to support [Nobl9](https://nobl9.com) SLOs in your Backstage installation. It allows you to easily access the most up-to-date metrics for any SLO within Backstage, such as the Burn Rate,
