# @molecule/api-project-archive-object-storage

> 标签: archive, backup, molecule, object-storage, parts, project, restore, tar, verification

## 简介

Object-storage project archive provider for molecule.dev — standard tar.gz artifacts of generic ArchiveParts (source, database dumps, git bundles: nothing privileged) persisted through @molecule/api-uploads under the storage id the uploads bond mints, ver
