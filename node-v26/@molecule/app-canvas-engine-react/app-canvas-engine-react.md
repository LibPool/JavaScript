# @molecule/app-canvas-engine-react

> 标签: canvas, design-canvas, design-tool, molecule, react, vector

## 简介

Vector design-tool canvas engine — rect/ellipse/line/path/text/group, multi-select + alignment + group/ungroup, snap-to-grid, undo/redo, blend modes. Thin wrapper consuming @molecule/app-feature-canvas-react.
