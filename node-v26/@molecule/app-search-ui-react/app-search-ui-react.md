# @molecule/app-search-ui-react

> 标签: molecule, quick-search, react, results, search, search-box

## 简介

React search UI for @molecule/app-client-search — a search box with filter chips and tips, a ranked results list with matched terms marked, and a quick-search dialog; styled through the ClassMap
