# @molecule/api-emails-inbound-agentmail

> 标签: agentmail, emails, inbound, molecule, svix, webhook

## 简介

AgentMail inbound email provider — verifies Svix-signed AgentMail webhooks and parses message.received payloads into normalized InboundEmail, replying through the AgentMail API.
