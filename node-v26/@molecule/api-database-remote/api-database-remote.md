# @molecule/api-database-remote

> 标签: database, molecule, mysql, postgresql, remote, sqlite

## 简介

Remote-database driver for database-admin flagship — connects to user-supplied Postgres/MySQL/SQLite databases for inspection, schema browsing, and query execution.
