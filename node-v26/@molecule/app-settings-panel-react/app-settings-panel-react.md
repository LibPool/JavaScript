# @molecule/app-settings-panel-react

> 标签: molecule, panel, react, settings

## 简介

Composable settings panel — a SettingsContainer + family of section sub-components (Account, Auth, Notifications, Billing, Devices, ThisDevice, LogOutDelete). Apps compose via JSX children, picking which sections to include and what order.
