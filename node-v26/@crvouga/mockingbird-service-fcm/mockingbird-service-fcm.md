# @crvouga/mockingbird-service-fcm

> 标签: fcm, firebase, firebase-admin, messaging, mockingbird, service

## 简介

Stateful emulator of the Firebase Cloud Messaging HTTP v1 send API used by firebase-admin: fixture projects and registration tokens, an outbox, and a device inbox.
