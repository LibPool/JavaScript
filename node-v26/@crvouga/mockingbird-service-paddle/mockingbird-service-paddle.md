# @crvouga/mockingbird-service-paddle

> 标签: billing, emulator, mockingbird, paddle, payments, service, subscriptions, webhooks

## 简介

Stateful emulator of the Paddle Billing API (customers, addresses, businesses, products, prices, transactions with computed totals, subscriptions with pause/resume/cancel and renewals, events) with Paddle-Signature webhooks and admin routes that simulate
