# @crvouga/mockingbird-service-redis

> 标签: emulator, mockingbird, redis, resp

## 简介

In-process Redis RESP server for tests: strings, hashes, lists, sets, sorted sets, streams, transactions, pub/sub, and a Lua subset, with an injected clock. Not an HTTP emulator.
