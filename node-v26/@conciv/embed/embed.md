# @conciv/embed

> 标签: ai, chat, conciv, embed, solid-js

## 简介

Internal to @conciv/it (installed automatically, do not install directly). Also powers the @conciv/react and @conciv/preact wrapper components. The conciv embed bundle: mounts the conciv router app into a Shadow DOM on the host page and starts the page pl
