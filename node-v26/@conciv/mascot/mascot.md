# @conciv/mascot

> 标签: conciv, mascot

## 简介

Internal to @conciv/it (installed automatically, do not install directly). The conciv robot mascot: the rigged layer assets and a framework-free GSAP rig (createFabRobotRig) shared by the widget FAB and the site.
