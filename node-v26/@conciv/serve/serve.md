# @conciv/serve

> 标签: conciv, hono, server

## 简介

Internal to @conciv/it (installed automatically, do not install directly). conciv's @hono/node-server serve() wrapper that bakes overrideGlobalObjects:false so a co-hosted engine never clobbers the host's global Response/Request.
