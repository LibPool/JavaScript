# @colonayush/datumrag

> 标签: ai-agents, datum, mcp, rag, retrieval, retrieval-augmented-generation, search

## 简介

Node/TypeScript client for Datum, a retrieval substrate for AI agents. Talks to a running `datum serve-http` server; does not embed the framework itself (Python + PostgreSQL by design).
