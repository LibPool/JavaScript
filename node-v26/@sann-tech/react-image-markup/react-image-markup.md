# @sann-tech/react-image-markup

> 标签: annotation, canvas, drawing, form, form-filling, handwriting, image-editor, ink, markup, palm-rejection, pen, react, signature, stylus

## 简介

React component for filling paper-style forms and annotating images on an HTML5 canvas — handwriting with real pen pressure, typed fields, and a flattened image export at the original resolution.
