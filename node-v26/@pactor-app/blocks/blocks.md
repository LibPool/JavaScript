# @pactor-app/blocks

> 标签: blocks, composite, dsl, pactor, react, server-driven-ui

## 简介

Pactor blocks: composite block components built from @pactor-app/ui primitives (Login / EntityCard / CardList / RecordingPage / SiteFooter / rule & expression editors) with block component registry for the Renderer
