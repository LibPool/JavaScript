# @openagentsinc/atif

> 标签: JavaScript

## 简介

Canonical in-repo ATIF (Agent Trajectory Interchange Format, ATIF-v1.7) schema, validators, and public-safety tripwire shared by trace producers (qa-runner) and consumers (the trace ingest API).
