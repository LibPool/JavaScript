# @dasidev/dasui-pro

> 标签: admin, configuration-driven, dashboard, dasi, dasi-ui, dasidev, enterprise, framework, tailwindcss, template, typescript, vue3

## 简介

A starter Vue 3 + TypeScript framework for building configurable, enterprise-ready web apps. It ships with a configuration-driven architecture, unified components, and type-safe development. Forms are powered by Vueform, which serves as the built-in form
