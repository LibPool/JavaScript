# @tapwithus/tapsdk

> 标签: ble, bluetooth, gestures, tap, tapband, tapstrap, tapxr, web-bluetooth

## 简介

Web Bluetooth SDK for Tap Strap, TapXR, and TapBand (same BLE API; TapBand coming soon). Chrome or Edge; HTTPS or localhost.
