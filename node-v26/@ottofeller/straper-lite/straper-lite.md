# @ottofeller/straper-lite

> 标签: JavaScript

## 简介

Run straper like this: ```sh npx -p @ottofeller/straper strape \     -s <store1name,store2name — names of stores> \     -l <10 — limit the number of scraped products, optional> \     -d <./screenshots — path, optional> ```
