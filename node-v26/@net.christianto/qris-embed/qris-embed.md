# @net.christianto/qris-embed

> 标签: aspi, indonesia, payment, qr-code, qris, qris-mpm, react, react-component, ssr, svg

## 简介

React component that renders the ASPI QRIS MPM display (Lengkap, Ringkas, Dasar) around a QRIS code, as a single SVG.
