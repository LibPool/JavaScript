# @veecode-platform/backstage-plugin-about-backend-dynamic

> 标签: JavaScript

## 简介

Backend plugin for the VeeCode DevPortal "About" page. Exposes a `/info` endpoint that returns system details (OS, memory, Node.js version, Backstage and DevPortal versions).
