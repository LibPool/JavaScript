# @keboola/codemirror-lang-sql

> 标签: autocomplete, bigquery, codemirror, codemirror6, keboola, language-support, snowflake, sql

## 简介

SQL language support for CodeMirror 6 — multi-dialect (Snowflake, BigQuery) keyword + schema-aware autocompletion used by the Keboola platform.
