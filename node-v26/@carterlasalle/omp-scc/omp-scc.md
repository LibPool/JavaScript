# @carterlasalle/omp-scc

> 标签: coding-agents, context-engineering, oh-my-pi, scc, system-context

## 简介

System Context Compiler (SCC): injects evidence-backed system context into Oh My Pi sessions — startup architecture once per session, task context per prompt, post-edit incremental index, and compaction checkpoint/rehydration.
