# @markays/sass-vars-loader

> 标签: js, json, loader, sass, scss, ts, typescript, variables, vars, webpack

## 简介

Async fork from @epegzz/sass-vars-loader - A SASS vars loader for Webpack. Load global SASS vars from JS/JSON/Typescript files or from Webpack config.
