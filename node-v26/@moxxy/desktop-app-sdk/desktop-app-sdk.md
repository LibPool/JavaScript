# @moxxy/desktop-app-sdk

> 标签: app-sdk, desktop, electron, mini-apps, moxxy, sandbox

## 简介

The contract for moxxy desktop mini-apps: the moxxy-app.json manifest schema + capability list, the host<->app bridge protocol, and the tiny browser client an app imports to call host services over postMessage. Lets anyone (or an agent) build a sandboxed
