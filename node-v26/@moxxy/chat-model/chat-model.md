# @moxxy/chat-model

> 标签: agent, chat, markdown, moxxy

## 简介

UI-framework-neutral chat model: the event→block fold (tool/result pairing, skill + subagent + live-tool grouping), formatting helpers, a markdown AST, and a chunked append log. Shared by the Ink TUI, the desktop renderer, and future channels.
