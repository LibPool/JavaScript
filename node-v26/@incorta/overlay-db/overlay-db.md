# @incorta/overlay-db

> 标签: branch, cli, datafusion, overlay, parquet, postgres, postgresql, proxy, what-if, write-back

## 简介

A PostgreSQL wire-protocol endpoint that serves reads from an upstream Postgres and keeps INSERT/UPDATE/DELETEs in a local, branchable Parquet overlay — merged into query results on the fly, never written back upstream.
