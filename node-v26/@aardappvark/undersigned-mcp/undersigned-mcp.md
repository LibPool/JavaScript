# @aardappvark/undersigned-mcp

> 标签: mcp, model-context-protocol, reviews, seeker, solana, undersigned

## 简介

MCP server for the Undersigned review ledger: publisher desk (inbox, profiles, store mirror, reply hand-off to the Seeker, optional local signing, live watch) plus every Undersigned API route as tools.
