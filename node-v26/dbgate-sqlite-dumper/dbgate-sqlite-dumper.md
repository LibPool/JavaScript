# dbgate-sqlite-dumper

> 标签: .dump, backup, better-sqlite3, cloudflare, d1, database, dump, restore, sql, sqlite, sqlite3

## 简介

Standalone, client-agnostic SQLite SQL dump and restore library for Node.js, compatible with the native sqlite3 .dump command, with adapters for better-sqlite3 and Cloudflare D1
