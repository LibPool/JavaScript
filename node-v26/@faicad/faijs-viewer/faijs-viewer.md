# @faicad/faijs-viewer

> 标签: cad, fai, faijs, manifold, occt, three, viewer, zip

## 简介

Read + execute + tessellate a project .fai.zip for any third-party host. v1 API: openFaiZip(bytes, { wasm: { occtUrl, manifoldUrl, brepkitUrl } })
