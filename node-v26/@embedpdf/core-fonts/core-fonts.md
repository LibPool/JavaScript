# @embedpdf/core-fonts

> 标签: JavaScript

## 简介

The 14 standard PDF fonts as the engine draws them: PDFium's built-in faces as OpenType programs a browser can load, and the advances, ascent and descent the engine lays text out with. Pure TypeScript, DOM-free.
