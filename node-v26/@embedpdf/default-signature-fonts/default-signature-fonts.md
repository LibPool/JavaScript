# @embedpdf/default-signature-fonts

> 标签: JavaScript

## 简介

Three handwriting fonts for typed signatures and initials, Allura, Great Vibes and Caveat (SIL Open Font License), as TrueType files and as lazy modules any bundler code-splits, for @embedpdf/plugin-signature to draw a typed mark with.
