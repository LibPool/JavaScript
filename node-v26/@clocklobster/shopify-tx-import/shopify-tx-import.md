# @clocklobster/shopify-tx-import

> 标签: accounting, bookkeeping, sales, shopify, typescript, webhooks

## 简介

Import Shopify sales records for bookkeeping. Pure order-to-ledger adapter, Admin webhook verification, and nightly backfill polling. Sales records only — no invoicing, carts, checkout, or agent-order code.
