# @clocklobster/stripe-tx-import

> 标签: balance-transactions, bookkeeping, sales, stripe, typescript, webhooks

## 简介

Import Stripe sales records for bookkeeping. Maps Stripe balance transactions to provider-neutral SalesRecords, verifies sales webhooks (signal-then-poll), and backfills history page-by-page. Sales only — no invoices, credit notes, or subscriptions.
