# @automatalabs/acp-server

> 标签: JavaScript

## 简介

Connection-pinned ACP V1 proxy for the backends configured through `@automatalabs/acp-agents`. The `agentprism-acp-server` executable defaults to stdio and can also listen for Streamable HTTP and WebSocket clients on one endpoint.
