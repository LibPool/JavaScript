# @meldcrypto/react-native-sdk

> 标签: android, crypto, ios, meld, mercuryo, onramp, react-native

## 简介

React Native wrapper for the Meld SDK (iOS + Android) — embed a crypto on/off-ramp provider widget (Mercuryo card).
