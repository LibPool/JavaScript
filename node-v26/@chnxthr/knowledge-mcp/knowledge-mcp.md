# @chnxthr/knowledge-mcp

> 标签: claude, google-drive, mcp, mcp-gateway, mcp-server, model-context-protocol, plugins, rag, slack

## 简介

Build your own MCP server from plugins. Auth (API keys, OAuth), per-user permissions, audit log, SQLite or Supabase state, and built-in Google Drive, Slack, GitHub and Railway connectors.
