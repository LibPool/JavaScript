# @flowboost/mcp

> 标签: claude-code, codex, flowboost, google-ads, mcp, wolfy

## 简介

One-shot installer that connects Claude Code and Codex to Flowboost: registers the flowboost MCP server (OAuth sign in) and installs the flowboost-analyst and flowboost-data-retrieval sub-agents or skills.
