# @cueplusplus/mcp

> 标签: JavaScript

## 简介

CUE++ ID — the MCP servers over the access-management model: a framework-agnostic MCP-over-HTTP host (JSON-RPC 2.0, bearer-gated) and the member (end-user) tool server. The admin server lands on the same host in P4.
