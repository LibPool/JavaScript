# @blaze-cache/fetch

> 标签: cache, cache-control, caching, fetch, http, request, stale-while-revalidate, ttl, wasm, webassembly

## 简介

Drop-in fetch() replacement backed by a WebAssembly cache — TTLs, Cache-Control, stale-while-revalidate and an x-blaze-cache HIT/MISS marker
