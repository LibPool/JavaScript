# @lettrove/node

> 标签: email-editor, embeddable, html-email, server-sdk, webhooks

## 简介

Lettrove for your server: mint editor tokens, export and render designs, verify webhooks, erase users. Node 20+ and edge runtimes; refuses to run in a browser.
