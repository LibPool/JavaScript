# @mediaclip/http-pipeline

> 标签: fetch, http, pipeline

## 简介

HTTP Pipeline is a library designed to assist in creating HTTP Clients using a clean, structured approach inspired by Azure's HttpPipeline. It provides an alternative to manual fetch() calls by employing a builder pattern for request creation.
