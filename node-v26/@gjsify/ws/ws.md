# @gjsify/ws

> 标签: gjs, node, websocket, ws

## 简介

Drop-in replacement for the `ws` npm package on Gjs — wraps globalThis.WebSocket (Soup.WebsocketConnection) and Soup.Server for the WebSocketServer side
