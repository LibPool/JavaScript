# @gjsify/oxlint-plugin-gjsify

> 标签: blueprint, gjs, gobject, gtk, lint, oxc, oxlint, plugin

## 简介

oxlint JS plugin with gjsify's own lint rules for GJS/GTK code — Blueprint templates, translatable widget labels, GObject.registerClass field order, GJS-correct process exit, anchored deferral markers, and the CSS side-effect import that tree-shakes away.
