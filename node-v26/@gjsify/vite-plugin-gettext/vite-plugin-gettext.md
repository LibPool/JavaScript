# @gjsify/vite-plugin-gettext

> 标签: gettext, gnome, i18n, rolldown, rollup, vite

## 简介

Gettext PO/MO/JSON pipeline for Vite / Rollup / Rolldown — extract via xgettext, compile via msgfmt, JSON for browser targets.
