# @gjsify/adwaita-core

> 标签: adwaita, browser, design-system, gjs, gnome, headless, nativescript, node

## 简介

Headless Adwaita widget behavior (breakpoint condition grammar + apply/unapply state machine, color-scheme observable, avatar derivation) shared by the web and NativeScript Adwaita renderers — pure TS, no platform imports
