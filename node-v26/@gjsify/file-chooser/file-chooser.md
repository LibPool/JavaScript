# @gjsify/file-chooser

> 标签: file-dialog, file-system-access, gio, gjs, gtk, nativescript, opfs, storage-access-framework

## 简介

Gtk.FileDialog, Gtk.FileFilter and Gio.File as one import on GJS, the browser and NativeScript: the native classes on GJS, File System Access or a self-drawn OPFS dialog on the web, the Storage Access Framework on Android
