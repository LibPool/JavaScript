# @gjsify/webkit-native

> 标签: darwin, gjs, macos, webkit, wkwebview

## 简介

Apple WebKit (WKWebView) behind a GObject API shaped like WebKitGTK 6.0 — the darwin backend for @gjsify/iframe (ADR 0022). Contains no JavaScript; the prebuilt library and typelib arrive through per-target optionalDependencies.
