# @aoxborrow/registrar-client

> 标签: cloudflare, dns, domain-management, domain-registration, domains, dynadot, epp, gandi, godaddy, namebright, namecheap, namesilo, porkbun, rdap, registrar, registrar-api, spaceship, typescript, whois

## 简介

One consistent, fully-typed TypeScript interface to many domain registrar APIs (GoDaddy, Cloudflare, Namecheap, Spaceship, Dynadot, Porkbun, and more) behind a single pluggable multi-provider client
