# @rate-api/mcp

> 标签: ai, claude, currency, exchange-rates, finance, forex, fx, mcp, mcp-server, model-context-protocol, rate-api

## 简介

Model Context Protocol (MCP) server for the Rate-API.com exchange-rate API: gives Claude and other AI assistants currency rates, conversion, historical data, time series and crypto prices.
