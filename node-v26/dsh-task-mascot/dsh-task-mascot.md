> 标签: agent, animation, claude娘, deepseek-harness, desktop-pet, dsh, dsh-plugin, mascot, tool-calls, whale-girl, 大肥鱼

## 简介

metsh · Task Mascot — 真跟着 Agent 每一步工具调用在动。A DeepSeek Harness Web plugin whose mascot acts out every live tool call (read / write / edit / search / run / plan / sub-agent / wait / error) with step cards in chat. Swappable character packs (大肥鱼, Claude娘).
