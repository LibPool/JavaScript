# @pushengage/mcp

> 标签: ai-assistant, claude, claude-desktop, cursor, marketing-automation, mcp, model-context-protocol, push-notifications, pushengage, web-push

## 简介

PushEngage Model Context Protocol (MCP) server. Lets AI assistants like Claude Desktop and Cursor authenticate against PushEngage and send push notifications on your behalf.
