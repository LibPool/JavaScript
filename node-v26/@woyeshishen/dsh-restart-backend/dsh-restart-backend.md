# @woyeshishen/dsh-restart-backend

> 标签: backend, cordis, deepseek-harness, dsh, plugin, restart

## 简介

为 DeepSeek Harness Web 页面左下角添加“重启后端”按钮，一键重启 dsh 后端进程。
