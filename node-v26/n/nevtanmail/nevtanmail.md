# nevtanmail

> 标签: cli, custom-domain, email, email-sdk, mail-client, mailer, nevtan, nevtan-mail, nevtanmail, newsletter, transactional-email

## 简介

A high-performance zero-dependency Node.js email sending SDK for Nevtan Mail. Pure HTTP REST API delivery with automatic authentication, HTML and text emails, templates, and mailbox management. No browser or Chrome required.
