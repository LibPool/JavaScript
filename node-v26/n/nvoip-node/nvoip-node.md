# nvoip-node

> 标签: api, nvoip, otp, sms, telefonia, voip, whatsapp

## 简介

SDK Node.js oficial para integrar OAuth, chamadas, OTP, WhatsApp, SMS e saldo com a API v2 da Nvoip.

## 官网

- 官网：https://www.nvoip.com.br/
- 源码仓库：git+https://github.com/Nvoip/nvoip-node.git
- npm 页面：https://www.npmjs.com/package/nvoip-node

## 历史版本号

- 当前版本：0.2.0

- 0.2.0

## 获取地址

- npm 安装：`npm install nvoip-node`
- npm registry：https://registry.npmjs.org/nvoip-node
- Node 要求：>=18
