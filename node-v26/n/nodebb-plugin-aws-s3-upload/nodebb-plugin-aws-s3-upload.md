# nodebb-plugin-aws-s3-upload

> 标签: aws, nodebb, plugin, s3, storage, uploads

## 简介

A NodeBB plugin that handles file uploads and stores them in Amazon S3 using aws-sdk v3 and config.json or NodeBB database.
