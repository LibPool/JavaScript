# n8n-nodes-hetzner-auction-monitor

> 标签: ai-tool, apify, hetzner, hosting, monitoring, n8n, n8n-community-node-package, n8n-nodes, server-auction

## 简介

Poll the Hetzner Server Auction (Serverboerse) and return listings matching your price/spec criteria. Apify-backed n8n community node, pay-per-event, usable as an AI agent tool.
