# next-oom

> 标签: auto-restart, dev, dev-server, memory, memory-leak, monitor, next, nextjs, oom, turbopack

## 简介

Auto-restart Next.js dev server when memory exceeds threshold. Fights Turbopack memory leaks so you don't have to.
