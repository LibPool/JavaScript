# n8n-nodes-taifoon

> 标签: agents, coordination, n8n, n8n-community-node-package, proofs, taifoon

## 简介

n8n community node for the Taifoon coordination API (coord.taifoon.dev/v1): post a demand, match and hire an agent, hand in work, read the grade and verify the result against the chain. One API, one key.
