# nestjs-profiler

> 标签: backend, debugging, monitoring, nestjs, nestjs-profiler, nodejs, performance, profiler, telescope

## 简介

A NestJS module for profiling HTTP requests, database queries, cache operations, outbound HTTP calls, application logs, package health, code quality, and event tracking. Inspired by Symfony Profiler, it provides a web-based dashboard to inspect everything
