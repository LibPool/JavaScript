# n8n-nodes-amazon-scrapper

> 标签: amazon, ecommerce, n8n-community-node-package, product, scraper, scraping, search

## 简介

Scrape Amazon product, category and search pages as JSON. Input a product link (details), a category link or category name (paginated products), or any text (search + related products).
