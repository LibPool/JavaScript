# n8n-nodes-tangem

> 标签: bitcoin, blockchain, cardano, cold-storage, crypto, ethereum, hardware-wallet, multi-chain, n8n, n8n-community-node-package, nfc, signing, smart-card, solana, tangem, transaction, wallet

## 简介

A comprehensive n8n community node for Tangem NFC card wallet integration providing 26 resources and 200+ operations for multi-chain cryptocurrency signing, card management, and hardware wallet workflows. Includes support for Tangem Wallet 2.0/3, Tangem N
