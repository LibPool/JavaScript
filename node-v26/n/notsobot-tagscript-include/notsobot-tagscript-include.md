# notsobot-tagscript-include

> 标签: notsobot-tagscript, notsobot-tagscript-extensions, notsobot-tagscript-include, tagscript, tagscript-extensions

## 简介

Add the {include} command in NotSoBot TagScript as a cheap-import feature, like #include in C
