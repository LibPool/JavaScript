# node-red-contrib-edgelink-pg

> 标签: batch-insert, data-logger, edge-computing, industrial, iot, mitsubishi, modbus, node-red, plc, postgresql, scada, timescaledb

## 简介

EdgeLink PostgreSQL/TimescaleDB 批量写入节点 — 三菱PLC/Modbus 采集数据直写入库，支持断线缓存重试，v1.6.0 修复串表混插、确定性错误无限重试、关闭丢数据等问题
