# next-mdx-remote-client

> 标签: @mdx-js/mdx, @next/mdx, MDX, markdown, next-mdx-remote, nextjs

## 简介

A wrapper of the `@mdx-js/mdx` for the `nextjs` applications in order to load MDX content. It is a fork of `next-mdx-remote`.
