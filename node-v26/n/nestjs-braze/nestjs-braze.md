# nestjs-braze

> 标签: braze, braze-api, crm, customer-engagement, marketing, nestjs, push-notifications

## 简介

NestJS module for the Braze REST API — inject a typed BrazeService anywhere to track users, log events, trigger campaigns, and manage subscriptions.
