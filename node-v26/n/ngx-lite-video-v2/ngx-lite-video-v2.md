# ngx-lite-video-v2

> 标签: Angular, Vimeo, YouTube, embedded video, iframe, lazy load, ngx-lite-video, optimization, performance

## 简介

ngx-lite-video-v2 is an updated version of ngx-lite-video. ngx-lite-video is an Angular package for lazy loading embedded YouTube and Vimeo videos, improving page speed and user experience.
