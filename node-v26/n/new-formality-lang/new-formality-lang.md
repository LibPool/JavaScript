# new-formality-lang

> 标签: JavaScript

## 简介

Formality-Lang is a set of syntax sugars that transpile to [Formality-Core](https://github.com/moonad/formality-core). It extends that minimal core with user-friendly notations such as string literals and datatype declarations.
