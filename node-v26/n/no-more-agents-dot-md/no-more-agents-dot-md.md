# no-more-agents-dot-md

> 标签: context, extension, hooks, pi, pi-package, skill

## 简介

No More Agents Dot MD: turn .pi/context/*.md files into declarative behavior rules (conditional context injection, tool guards, confirmations, input transforms, notifications) managed with the /nma command.
