# noun-cli

> 标签: cli, fe

## 简介

diy自己的脚手架雏形 ·整个脚手架思想是运行脚手架init会拉去一个基础的node服务文件模版目录，为前端本地开发不依赖后端做基础 ·整个脚手架制作成开放模式，根据自己不同项目定义自己模版开发方便 ·加入一些vue、react等比较流行的框架模版 整个脚手架只为技术锻炼，和前后端分离开发提升前端开发效率为中心
