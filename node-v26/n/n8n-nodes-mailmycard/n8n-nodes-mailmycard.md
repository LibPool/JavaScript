# n8n-nodes-mailmycard

> 标签: cards, direct mail, handwritten, mailmycard, n8n, n8n-community-node-package

## 简介

Send real handwritten cards by post from n8n: a MailMyCard node (send a card, get an order, list templates) and a trigger for card events.
