# n8n-nodes-npm-registry-scraper

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Scrape npm package metadata, versions, download stats, and search results via the official npm Registry JSON API. No proxy, no auth. Batch lookup by package name or keyword search. Pay per result.

- 官网：https://apify.com/bovi/npm-registry-scraper
- npm 页面：https://www.npmjs.com/package/n8n-nodes-npm-registry-scraper
