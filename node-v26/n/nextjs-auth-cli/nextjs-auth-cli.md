# nextjs-auth-cli

> 标签: auth, authentication, cli, cli-tool, command-line, command-line-application, command-line-interface, command-line-tool, command-line-utility, javascript, next.js, nextjs, node, nodejs, npm, typescript

## 简介

A CLI tool to scaffold authentication backend routes into any Next.js project with support for MySQL, PostgreSQL, and libSQL (Turso) with ORM support.
