# n8n-nodes-drawing

> 标签: n8n-community-node-package

## 简介

`n8n-nodes-XhsPost` 是一款专为 [n8n](https://n8n.io) 工作流自动化平台打造的小红书发布插件，支持一键发布图文笔记与视频内容，实现从内容创作到账号运营的全流程自动化。
