# n8n-nodes-axelar

> 标签: axelar, blockchain, bridge, cosmos, cross-chain, defi, gmp, interchain, its, n8n, n8n-community-node-package, squid

## 简介

A comprehensive n8n community node for Axelar Network providing 16 resources and 60+ operations for cross-chain communication, GMP messaging, ITS token transfers, and Squid Router integration.
