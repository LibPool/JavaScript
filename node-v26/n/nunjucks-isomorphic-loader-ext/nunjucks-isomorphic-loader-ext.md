# nunjucks-isomorphic-loader-ext

> 标签: loader, nunj, nunjucks, template, webpack

## 简介

Fork of nunjucks-isomorphic-loader. A nunjucks loader for webpack, supporting both javascript template usage and static compilation through HtmlWebpackPlugin.
