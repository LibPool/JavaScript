# nukadoko

> 标签: acceptance-testing, agent-skills, ai-agents, allure, bdd, cucumber, cucumber-js, e2e-testing, gherkin, playwright, static-analysis, test-automation, typescript

## 简介

Typed step contracts for Gherkin, so a scenario can be told wrong before it runs. The vocabulary is machine-readable for agents, and every execution leaves a step record the tool measured rather than the agent reported.
