# n8n-nodes-npm-registry-scraper-ai-ml

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Scrape npm metadata, versions and download stats for AI/LLM SDK packages — openai, langchain, @anthropic-ai/sdk, ollama — via the official npm Registry JSON API. No proxy, no auth. Returns version, license, dependency count, downloads-last-month, parse_co
