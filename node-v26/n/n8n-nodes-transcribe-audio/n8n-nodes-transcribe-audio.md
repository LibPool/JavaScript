# n8n-nodes-transcribe-audio

> 标签: audio, captions, interview transcription, meeting transcription, mp3, n8n-community-node-package, podcast transcription, speech-to-text, subtitles, transcribe, transcribe audio, transcription, voice notes, wav, whisper

## 简介

Perform local speech-to-text. Transcribe audio files locally in self-hosted n8n with Whisper. No transcription API key required.
