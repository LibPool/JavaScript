# n8n-nodes-serpresult

> 标签: n8n, n8n-community-node-package, search results, serp api, serpresult

## 简介

SerpResult returns live organic search results from Google, Bing, DuckDuckGo, Yahoo, Brave and Yandex as structured JSON. This n8n community node runs a search, a bulk search and reads your account, using your own SerpResult API key.
