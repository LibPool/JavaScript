# nxvet-mcp

> 标签: mcp, modelcontextprotocol, nxvet, veterinary

## 简介

MCP server for the NxVET API (labels, transcripts, NxHub conversations, webhooks, API keys) — hosted at https://mcp.nx.vet/mcp or run locally via npx

## 官网

- 官网：https://api.nx.vet/mcp.html
- 源码仓库：git+https://github.com/nervextech/nxvet-mcp.git
- npm 页面：https://www.npmjs.com/package/nxvet-mcp
