# n8n-nodes-zcash

> 标签: automation, blockchain, cryptocurrency, n8n, n8n-community-node-package, privacy, rpc, shielded, zcash, zec

## 简介

A comprehensive n8n community node for Zcash blockchain providing wallet management, transactions, shielded operations, and blockchain queries via zcashd RPC.
