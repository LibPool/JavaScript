# node-rabbitmq-wrapper

> 标签: AMQP, AMQP 0-9-1, RabbitMQ, amqplib

## 简介

Wrapper around npm package [`amqp-connection-manager`](https://github.com/benbria/node-amqp-connection-manager).\ Exposes 4 methods: `start`, `listen`, `send` and `closeConnection`.
