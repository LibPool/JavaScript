# next-grecaptcha

> 标签: app-router, captcha, google-recaptcha, grecaptcha, invisible-recaptcha, next, nextjs, react, recaptcha, recaptcha-v2, recaptcha-v3, server-actions, siteverify, typescript

## 简介

Google reCAPTCHA v2 (checkbox + invisible) and v3 for Next.js. Own script loader, explicit rendering, typed siteverify client. Zero runtime dependencies.
