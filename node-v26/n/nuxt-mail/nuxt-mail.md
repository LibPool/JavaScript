# nuxt-mail

> 标签: email, express, frontend, inject, javascript, mail, nodemailer, npm, npm-package, nuxt, nuxt-module, nuxtjs, nuxtjs-module, server, webdevelopment

## 简介

Adds email sending capability to a Nuxt.js app. Adds a server route, an injected variable, and uses nodemailer to send emails.
