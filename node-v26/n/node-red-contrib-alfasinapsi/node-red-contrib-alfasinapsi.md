# node-red-contrib-alfasinapsi

> 标签: node-red, node-red-contrib

## 简介

NON INSTALLARE - DO NOT INSTALL. USE THE node-red-contrib-alfasinapsi-ultimate package instead! Nodi Node-RED per collegare Sinapsi Alfa e creare un controller carichi. In alternativa, e' possibile usare l'integrazione nativa con il load controller di KNX
