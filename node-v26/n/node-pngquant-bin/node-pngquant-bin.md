# node-pngquant-bin

> 标签: JavaScript

## 简介

pngquant Node.js wrapper that makes it seamlessly available on Windows and Mac OSX. Much like node-optipng-bin.

## 官网

- 官网：https://github.com/zauni/node-pngquant-bin
- 源码仓库：git://github.com/zauni/node-pngquant-bin.git
- npm 页面：https://www.npmjs.com/package/node-pngquant-bin

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- npm 安装：`npm install node-pngquant-bin`
- npm registry：https://registry.npmjs.org/node-pngquant-bin
- Node 要求：>= 0.8.0
