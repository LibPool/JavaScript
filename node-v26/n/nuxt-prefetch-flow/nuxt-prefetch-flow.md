# nuxt-prefetch-flow

> 标签: lighthouse, nuxt, nuxt-module, performance, ssr, useAsyncData, useFetch, waterfall

## 简介

Eliminate SSR request waterfalls in Nuxt by declaring route data as a dependency-aware parallel manifest. Build-time detector warns when native await useAsyncData/useFetch would serialize.
