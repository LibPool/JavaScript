# next-nuke

> 标签: .next, build-cache, cache, clean, cleanup, clear-cache, cli, disk-space, monorepo, next, nextjs, node_modules, npkill, pnpm, reset, turbo, turborepo

## 简介

Delete bloated .next build and cache folders in a Next.js app or monorepo, then reinstall clean. Warns when .turbo would restore a stale build.
