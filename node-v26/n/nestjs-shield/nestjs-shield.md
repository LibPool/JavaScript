# nestjs-shield

> 标签: api-protection, auto-ban, ddos, ip-blacklist, ip-whitelist, leaky-bucket, nestjs, rate-limit, rate-limiting, redis, security, shield, sliding-window, slow-down, throttle, throttler, token-bucket

## 简介

Layered API protection for NestJS: rate limiting, IP allow/block lists, auto-ban, slow-down, UA filtering, burst caps, payload limits. Pluggable storage (memory/Redis).
