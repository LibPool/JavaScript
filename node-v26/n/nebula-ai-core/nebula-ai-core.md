# nebula-ai-core

> 标签: agent, ai, casper, cspr, nebula, policy, treasury

## 简介

The SDK for nebula, a Casper-native policy-aware AI treasury agent: brain, local memory + storage, the policy/approval engine, Casper account identity, and the on-chain registry client
