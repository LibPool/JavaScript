# netjsonconfig-editor.js

> 标签: UI, django-netjsonconfig, editor, editor.js, javascript, json, netjson, netjsonconfig, netjsonconfig-editor.js, openWisp, openWisp 2, validation

## 简介

Javascript based UI for editing netjson. contains and advanced mode raw json editor and a GUI based netjson editor. Has inbuilt validation following json-schema standards
