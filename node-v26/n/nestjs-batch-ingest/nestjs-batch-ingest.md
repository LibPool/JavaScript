# nestjs-batch-ingest

> 标签: batch, buffer, bulk insert, bullmq, count threshold, ingestion, nestjs, queue, redis, time window

## 简介

Time & count based batching for NestJS. Buffer in Redis, flush in bulk via BullMQ (time window or count threshold).
