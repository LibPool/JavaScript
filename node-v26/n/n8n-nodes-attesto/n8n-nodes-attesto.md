# n8n-nodes-attesto

> 标签: attesto, audit, eu-ai-act, evidence, n8n-community-node-package

## 简介

Attesto nodes for n8n: log verifiable evidence events, fetch receipts, verify them offline, and trigger on signature-verified Attesto webhooks.
