# n8n-nodes-rexai

> 标签: ai, chat-model, langchain, llm, n8n, n8n-community-node-package, rexai

## 简介

RexAi nodes for n8n: a Chat Model sub-node that plugs into the AI Agent, and a standalone node for chat, image analysis, image generation and audio transcription.
