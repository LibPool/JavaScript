# n8n-nodes-poland-company-registry

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Look up Polish companies by KRS number via the official Ministry of Justice KRS API — free, no key. Returns legal name, form, status, address, PKD activity codes, board/representation. Optional REGON (GUS) enrichment resolves NIP/REGON with your own free
