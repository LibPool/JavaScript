# nuxt-sanctum-auth

> 标签: auth, laravel, nuxt, nuxt3, sanctum, typescript

## 简介

This is a simple package for interating Laravel Sanctum auth with Nuxt3. This package is in developement and for now works only in SPA mode (no ssr yet).
