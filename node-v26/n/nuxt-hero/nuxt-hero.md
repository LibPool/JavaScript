# nuxt-hero

> 标签: carousel, hero, nuxt, nuxt-module, parallax, slider, swiper, video, vue, vue-plugin

## 简介

A full-featured hero slider for Nuxt AND plain Vue 3 — parallax, video backgrounds, overlay patterns, customizable animations. Zero-Tailwind plain-CSS styling, touch-friendly, RTL + a11y ready.
