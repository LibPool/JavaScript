# node-red-contrib-sectoralarm-ng

> 标签: alarm, home-automation, node-red, sector alarm, sectoralarm

## 简介

Node-RED nodes for Sector Alarm — works with the current Sector Alarm API (My Pages / omatsivut). Complete rewrite, no dependency on the legacy sectoralarm library.
