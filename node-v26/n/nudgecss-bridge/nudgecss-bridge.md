# nudgecss-bridge

> 标签: claude-code, mcp, model-context-protocol, nudgecss

## 简介

Local relay: receives changes sent from the NudgeCSS panel's "Send to Claude" button and hands them to Claude Code as an MCP tool. No browser-automation dependency — separate from nudgecss-driver-b on purpose, see README.
