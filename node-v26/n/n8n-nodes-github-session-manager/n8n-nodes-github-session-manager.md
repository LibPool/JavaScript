# n8n-nodes-github-session-manager

> 标签: credentials, github, jwt, n8n, n8n-community-node-package, n8n-nodes, session

## 简介

Manage GitHub App session tokens in n8n and optionally rewire workflows to a freshly issued githubApi credential.
