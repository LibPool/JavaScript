# nextjs-redis-cache

> 标签: next-redis-cache, nextjs, nextjs-cache, nodejs-redis-cache, redis-cache, typescript

## 简介

A Redis Cache for Next.js Framework that supports expiration after a given time and also compress the data in memory.
