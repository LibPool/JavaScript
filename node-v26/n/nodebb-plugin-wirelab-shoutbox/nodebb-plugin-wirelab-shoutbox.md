# nodebb-plugin-wirelab-shoutbox

> 标签: chat, live-chat, moderation, nodebb, nodebb-plugin, plugin, shoutbox, websocket, widget

## 简介

Live shoutbox for NodeBB 4: a dock on every page (bottom sheet on phones) and a widget over the NodeBB websocket. Global read/write/moderate privileges, writing rules, mutes with a moderation log, mentions with notifications, emoji, optional rank-badges i
