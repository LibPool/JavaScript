# now-static-build-node

> 标签: JavaScript

## 简介

This package provides a [builder](https://zeit.co/docs/v2/deployments/builders/overview#when-to-use-builders) for Zeit's [Now 2.0](https://zeit.co/blog/now-2) that compiles static files with a custom npm script name (not `now-build`)
