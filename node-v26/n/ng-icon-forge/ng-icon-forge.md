# ng-icon-forge

> 标签: angular, angular-cli, favicon, icons, manifest, maskable, ng-add, pwa, schematics, svg

## 简介

ng add ng-icon-forge — generates Angular PWA icon assets from a source SVG and merges them into manifest.webmanifest, ngsw-config.json, and index.html.
