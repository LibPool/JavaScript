# namesniper-mcp

> 标签: ai-name-generator, brand-name, domain-availability, mcp, model-context-protocol, modelcontextprotocol, namesniper, social-handles, trademark, username-availability

## 简介

MCP server for NameSniper: monitor taken usernames and get alerted the moment they free up or drop, check handle and domain availability across the major social platforms and TLDs, and screen names for trademark conflicts.
