# namefinder-cli

> 标签: availability, brand, cli, domain, domain-name, domain-search, domains, namefinder, naming, rdap, whois

## 简介

Command-line client for NameFinder — generate available, brandable domain names, check availability + pricing, scan TLDs, and check social handles.
