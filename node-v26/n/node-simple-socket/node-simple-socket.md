# node-simple-socket

> 标签: aes256, asymetric, compression, decryption, easy, encryption, gzip, ip, keys, passwords, rsa, secure, simple, socket, tcp, typescript, wrapper

## 简介

Wrapper for sockets that makes it easy to send data compressed and crypted (RSA / AES) automatic.
