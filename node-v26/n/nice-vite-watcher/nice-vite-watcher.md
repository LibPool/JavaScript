# nice-vite-watcher

> 标签: development, hmr, hot-reload, linked-packages, local-dependencies, monorepo, symlink, toolkit, vite, vite-plugin, watch

## 简介

Vite plugin for hot-reloading symlinked npm packages. Watches dist folders and triggers browser reload when linked packages rebuild.
