> 标签: automation, cip, ethernet-ip, ethernet/ip, nj101, node-red, nx102, nx1p2, nx502, omron, plc, sysmac

## 简介

Node-RED nodes for reading and writing Omron NX/NJ Sysmac controller tags over EtherNet/IP, built on the omron-eip library.
