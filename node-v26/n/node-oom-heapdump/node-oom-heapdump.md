# node-oom-heapdump

> 标签: OnFatalError, OnOOMError, heapdump, memory, memory-leak, nodejs, out-of-memory

## 简介

Create a V8 heap snapshot when an "Out of Memory" error occurs, or create a heap snapshot or CPU profile on request.
