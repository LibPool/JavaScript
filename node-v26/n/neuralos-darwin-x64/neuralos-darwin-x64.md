# neuralos-darwin-x64

> 标签: darwin-x64, embeddings, needle, neuralos, offline, on-device, tool-calling

## 简介

neuralOS engine (libneedle3) and base weights (needle3.cact) for darwin-x64 — the platform payload for the neuralos package. Install neuralos instead of this package directly.
