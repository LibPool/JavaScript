> 标签: UI library, angular, angular component, angular library, autoplay, flyweight, gallery, grid layout, image gallery, lightbox, lightweight gallery, loop, media gallery, media viewer, ng-flyweight-gallery, responsive gallery, thumbnail support, video gallery

## 简介

`ng-flyweight-gallery` is a lightweight and customizable Angular component library for creating responsive media galleries. It supports images and videos, with features like autoplay, loop for videos and a responsive layout.
