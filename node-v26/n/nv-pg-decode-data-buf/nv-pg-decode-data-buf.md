# nv-pg-decode-data-buf

> 标签: JavaScript

## 简介

本库提供了解析PostgreSQL二进制格式的各种数据类型的功能，包括基本类型、一维数组和多维数组。 目的是避免在后端传输过程中不必要的 JSON 序列化/反序列化
