# nodebb-plugin-aliyun-green-text

> 标签: aliyun, nodebb, nodebb-plugin

## 简介

在config.json中添加 ```json {   "aliGreenConfig": {     "ACCESS_KEY_ID": "ACCESS_KEY_ID",     "SECRET_ACCESS_KEY": "SECRET_ACCESS_KEY",     "REGION": "hangzhou"   } } ``` Then enjoy it.
