# n8n-nodes-ibm-quantum

> 标签: ai-agent, automation, ibm-cloud, ibm-quantum, n8n, n8n-community-node-package, openqasm, qiskit, qiskit-runtime, qpu, quantum, quantum-computing, trigger

## 简介

Verified n8n community node for IBM Quantum. Build OpenQASM 3 circuits, submit to Qiskit Runtime, and trigger on job completion or failure. Usable as an AI Agent tool.
