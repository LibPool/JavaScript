# neverland-build

> 标签: JavaScript

## 简介

| 参数 | 说明 | 类型 | 默认值 | |------|------|------|--------| | entry | 需要打包的路径 | array | [] | | output | 输出路径 | string | './dist' | | context | 运行目录 | string | `process.cwd()` | | sourceMap | 是否需要开启 sourceMap | bool | false | | clean | 打包前是否需要清空输出目录内的文件 | bool
