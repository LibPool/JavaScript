# n8n-nodes-frisbii-billing-pay

> 标签: billing, frisbii, n8n-community-node-package, payments

## 简介

n8n community nodes for Frisbii Billing & Pay (https://docs.frisbii.com). Docker: run n8n and set N8N_CUSTOM_EXTENSIONS to this repo root after npm run build.
