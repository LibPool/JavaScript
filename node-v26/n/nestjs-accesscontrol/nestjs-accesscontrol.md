# nestjs-accesscontrol

> 标签: abac, access-control, accesscontrol, authorization, guard, nest, nestjs, permissions, rbac, roles

## 简介

Role & attribute-based access control for NestJS, built natively on accesscontrol v3 — fluent CRUD decorators, fail-closed guard, and attribute filtering.
