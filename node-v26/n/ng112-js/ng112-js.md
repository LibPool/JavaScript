# ng112-js

> 标签: 112, 911, dec112, emergency, ng112, ng911

## 简介

This javascript library should help integrating browser and node environments with existing NG112 or DEC112 infrastructure and covers standards [ETSI TS 103 479](https://www.etsi.org/deliver/etsi_ts/103400_103499/103479/01.01.01_60/ts_103479v010101p.pdf)
