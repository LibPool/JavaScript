# netexpert-mcp

> 标签: diagnostics, dns, homelab, lan, mcp, mcp-server, model-context-protocol, network, security-posture, wifi

## 简介

Cross-platform local-network diagnostics & security-posture MCP server — the local host + LAN half; complements ugnas-mcp (the NAS half). 31 tools, bounded probes, no shells, no raw sockets.
