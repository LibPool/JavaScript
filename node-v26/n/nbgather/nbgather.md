# nbgather

> 标签: jupyter, jupyterlab

## 简介

Tools for cleaning code, recovering lost code, and comparing versions of code in Jupyter Lab.

## 官网

- 官网：https://microsoft.github.io/gather/
- 源码仓库：git+https://github.com/Microsoft/gather.git
- npm 页面：https://www.npmjs.com/package/nbgather
