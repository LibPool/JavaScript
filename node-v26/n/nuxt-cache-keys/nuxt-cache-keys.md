# nuxt-cache-keys

> 标签: JavaScript

## 简介

Nuxt module, that provides a system to set cache-keys for later use in e.g. a full-page cache like Varnish or Fastly.

- npm 页面：https://www.npmjs.com/package/nuxt-cache-keys
