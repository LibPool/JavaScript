# namefinder-mcp

> 标签: agent, availability, domain, domain-name, domains, mcp, model-context-protocol, namefinder, naming, rdap

## 简介

MCP server for NameFinder — let AI agents generate available, brandable domain names and check availability, pricing, and social handles in-loop.
