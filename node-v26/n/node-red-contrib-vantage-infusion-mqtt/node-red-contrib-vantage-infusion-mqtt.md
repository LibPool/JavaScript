# node-red-contrib-vantage-infusion-mqtt

> 标签: automation, homeassistant, infusion, legrand, lighting, mqtt, node-red, vantage

## 简介

Professional Vantage InFusion Host Commands to MQTT bridge for Node-RED with native TCP/Telnet connection, dual output (MQTT and raw Vantage) and optional Home Assistant Auto-Discovery
