# nestjs-mvc

> 标签: inertia, inertiajs, monolith, mvc, nestjs, react, vue

## 简介

NestJS in MVC mode: controllers return views, the Inertia protocol delivers them to React or Vue. Server adapter, Vite plugin and client in one package.
