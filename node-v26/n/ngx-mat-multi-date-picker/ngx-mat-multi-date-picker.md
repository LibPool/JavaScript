# ngx-mat-multi-date-picker

> 标签: angular, calendar, datepicker, hijri, holiday, islamic, jalali, material, persian

## 简介

A standalone Angular component that provides Gregorian, Jalali (Persian) and Hijri (Islamic) calendars with built‑in holiday highlighting and custom holiday support.
