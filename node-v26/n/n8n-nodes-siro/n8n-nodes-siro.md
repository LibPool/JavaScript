# n8n-nodes-siro

> 标签: call-recording, conversation-intelligence, crm, n8n, n8n-community-node-package, sales, siro

## 简介

n8n community node for Siro (siro.ai) — AI sales-conversation recording: CRM sync (accounts, opportunities, engagements, users), recording insights (extractions, scorecards, followups, summaries, utterances), and recording-processed/linked webhook trigger
