# ngx-cust-table

> 标签: angular custom table, custom table, datatable, editable table, filter, search table, grid

## 简介

This repository is an Angular component library which holds custom table component with different customization like add/remove column filter, global search, column wise search, sort and row accordian needed for angular application development
