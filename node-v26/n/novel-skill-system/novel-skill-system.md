# novel-skill-system

> 标签: novel, opencode, skill, video, writing, 创作, 小说, 短剧

## 简介

小说创作与视频生成助手：智能体分工协作系统。包含7个专业智能体和1个总经理，支持流水线模式。从想法到成品（小说+封面+短剧）全自动完成。
