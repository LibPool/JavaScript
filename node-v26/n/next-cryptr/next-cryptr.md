> 标签: AES-GCM, AES-GCM-256, authorization, browser, cipher, crypto, cryptography, decrypt, decryption, edge, edge-runtime, encrypt, encryption, iv-generator, nextjs, security, symmetric

## 简介

Cryptographic utility for encrypting and decrypting data using AES-GCM 256 algorithm. Fully optimized for Next.js. Based on built-in API crypto.subtle.* methods.
