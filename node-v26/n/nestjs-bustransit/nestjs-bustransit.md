# nestjs-bustransit

> 标签: choreography, compensation, distributed-transactions, event-driven, message-bus, microservices, mongodb, nestjs, orchestration, postgresql, rabbitmq, resilience, retry-strategies, routing-slips, saga, saga-pattern, service-bus, state-machine

## 简介

Production-ready NestJS message bus with RabbitMQ, featuring Saga Pattern with persistence (MongoDB/PostgreSQL), Routing Slips orchestration, and comprehensive retry strategies for reliable distributed systems
