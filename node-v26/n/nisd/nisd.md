# nisd

> 标签: directories, directory, folder, folders, i, install, npm, sub, subdirectory, subfolder

## 简介

Npm Install in SubDirectories. Yes, it's that simple. Use it like: `nisd [subdirs...]` (Example: `nisd client server scripts`)
