# npm-l18-file-compare

> 标签: JavaScript

## 简介

用于项目中对文件的操作： 1. 项目中国际化语言文件比对，合并比对文件的差异，生成合并后的文件 2. 项目中国际化语言文件比对，输出比对文件的差异，生成文件将文件间的差异分别输出 3. 整合项目中所有图片资源文件（.jpg、.png、.svg）文件，生成html文件进行资源搜索和查看 4. 根据要求翻译项目中国际化语言文件（百度翻译支持的部分28种语种）
