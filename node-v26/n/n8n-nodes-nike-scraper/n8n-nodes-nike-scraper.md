# n8n-nodes-nike-scraper

> 标签: ai-tool, apify, ecommerce, n8n, n8n-community-node-package, n8n-nodes, nike, product-data, sneakers

## 简介

Scrape Nike.com product listings and full product detail via the api.nike.com consumer API. Apify-backed n8n community node, pay-per-event, usable as an AI agent tool.
