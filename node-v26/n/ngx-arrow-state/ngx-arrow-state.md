# ngx-arrow-state

> 标签: angular, arrow-key-navigation, chat-input, command-history, conversational-input, ctrl-enter, custom-state-manager, dependency-injection, elf, input-history, ioc, ngrx, ngrx-signals, pluggable-state, reactive-forms, state-management, textarea-submit

## 简介

An Angular library that provides conversational AI style input history navigation using arrow keys and Ctrl+Enter form submission. Pluggable state management via IoC — use the built-in in-memory store or bring your own (e.g. @ngrx/signals, @ngneat/elf).
