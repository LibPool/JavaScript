> 标签: auto-dialer, fax, freeswitch, ictcore, ictdialer, ictfax, ictpbx, n8n, n8n-community-node-package, pbx, telephony, voip

## 简介

n8n community node for ICTCore. Send faxes, place calls, manage contacts and run campaigns on ICTFax, ICTPBX and open source ICTDialer from a workflow.
