# node-red-contrib-cortex-hub

> 标签: cortex, crm, invoicing, kanban, node-red, timesheet, webhook

## 简介

Use Cortex from Node-RED: a webhook node that verifies Cortex's signed deliveries and an API node whose operations come from Cortex's own OpenAPI document.
