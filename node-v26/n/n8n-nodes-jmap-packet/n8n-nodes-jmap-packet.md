# n8n-nodes-jmap-packet

> 标签: apache-james, email, fastmail, jmap, mail, n8n-community-node-package, rfc8620, rfc8621, stalwart, twake-mail

## 简介

JMAP nodes for n8n — mail, mailboxes and threads over JMAP (RFC 8620/8621). Works with Stalwart, Apache James, Twake Mail and Fastmail.
