# number-scrubber

> 标签: JSON-RPC, LSP, mouse, neovim, number, scrubber, server, vscode

## 简介

An LSP server that lets you use the mouse drag action to update numbers in your text editor. Plugins available for neovim and vscode. Works great alongside websocket-text-relay.
