# node-onvif-nvr

> 标签: Baby Camera, Camera, Network Camera, ONVIF, PTZ, Security Camera

## 简介

The node-onvif-nvr is a node-onvif fork module which allows you to communicate with the network camera which supports the ONVIF specifications (and now NVR).
