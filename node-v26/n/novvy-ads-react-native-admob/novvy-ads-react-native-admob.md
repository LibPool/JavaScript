# novvy-ads-react-native-admob

> 标签: admob, ads, android, custom-event, interstitial, ios, mediation, novvy, react-native, rewarded, short-drama

## 简介

AdMob mediation adapter for the Novvy Ads React Native SDK — lets an existing AdMob waterfall call Novvy as a custom event. No JavaScript API: installing the package is the whole integration.
