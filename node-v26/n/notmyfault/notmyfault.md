# notmyfault

> 标签: ci, flaky-tests, github-actions, gitlab-ci, junit, testing

## 简介

Tells you whether a failing test is your fault or a known flaky test, in GitHub Actions, GitLab CI/CD, Forgejo, Gitea and any CI system. No server, no runtime dependencies.
