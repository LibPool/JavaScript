# nex

> 标签: build, dependencies, development, environment, globalDependencies, ide, link, linkDependencies, management, nex, nexus, node, npm, peerDependencies, private, proprietary, symlink, symlinks, systemDependencies, tool, workspace

## 简介

Simplify management of local npm and node.js development resources and processes, such as symlinks, global dependencies, etc. It's like grunt or gulp, but with 100x less code and a flatter learning curve.
