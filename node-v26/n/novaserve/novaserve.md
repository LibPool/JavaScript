# novaserve

> 标签: aws, azure, cli, cloud-infrastructure, cloudflare, compiler, deployment, devops, docker, gcp, iac, infrastructure-as-code, kubernetes, lambda, multi-cloud, novaserve, serverless, serverless-framework-alternative, terraform-alternative, typescript

## 简介

TypeScript-to-cloud compiler. Define serverless apps in TypeScript, compile to AWS, Azure, GCP, Cloudflare, Docker, or Kubernetes. Built-in local dev server and deployment planner.
