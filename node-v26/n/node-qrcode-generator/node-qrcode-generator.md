> 标签: buffer, customization, data uri, error correction, javascript, node js, node package, npm package, qr code, qr code generator, qr creation, qr image generation, qr library, url to qr

## 简介

A lightweight and versatile Node.js package for generating QR codes from URLs. It offers customizable options and a clean API for effortless integration into your projects.
