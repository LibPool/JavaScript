# nuqs-zod-adapter

> 标签: adapter, debounce, hook, nextjs, nuqs, query, state, typescript, url, zod

## 简介

A Nuqs adapter to safely bind Zod schemas with query parameters using type safety, debouncing and auto-reset support.
