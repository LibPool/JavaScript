> 标签: framework, fullstack, niral, ssr, zero-dependencies, zyoralabs

## 简介

Niral — the zero-dependency full-stack framework by ZyoraLabs. This package is a tiny launcher; the framework itself lives at github.com/Zyora-Dev/niral and has zero dependencies.
