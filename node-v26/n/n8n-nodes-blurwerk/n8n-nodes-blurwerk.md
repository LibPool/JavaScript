# n8n-nodes-blurwerk

> 标签: anonymization, face blur, gdpr, n8n-community-node-package, privacy, video

## 简介

n8n node for blurwerk: anonymize video — every face mosaiced, voices disguised or muted, metadata removed. Processed in Germany.
