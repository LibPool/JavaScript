# node-caching-proxy

> 标签: cache, cli, http, proxy, reverse-proxy

## 简介

A CLI caching reverse proxy that forwards requests to an origin server and caches responses, using only Node.js core modules.

- npm 页面：https://www.npmjs.com/package/node-caching-proxy
