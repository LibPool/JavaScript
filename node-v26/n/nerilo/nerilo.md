# nerilo

> 标签: datachannel, decentralized, e2ee, gossip, mesh, offline-first, p2p, sdk, signaling, webrtc

## 简介

Embeddable P2P E2EE messaging layer for the browser (WebRTC mesh + gossip, pluggable signaling/directory/storage).
