# n8n-nodes-verica

> 标签: ai-agent, llm, monitoring, n8n-community-node-package, observability, tracing, verica

## 简介

LLM observability for your AI Agent and LLM steps: send each execution to Verica as a trace with tool calls, tokens and cost.
