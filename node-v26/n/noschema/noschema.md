# noschema

> 标签: JavaScript

## 简介

如果你习惯于 MySQL 的生态，习惯于 SQL 查询，但是又向往 Mongodb 的无模式，动态创建表，不需要维护字段，使用 noschema 就可以满足你的幻想。
