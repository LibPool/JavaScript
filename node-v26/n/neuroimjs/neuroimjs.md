# neuroimjs

> 标签: brain, fmri, medical-imaging, mri, neuroimaging, nifti, volume, voxel, webgl

## 简介

A neuroimaging library for JavaScript — volumetric data, NIfTI I/O, spatial transforms, and WebGL orthogonal viewers
