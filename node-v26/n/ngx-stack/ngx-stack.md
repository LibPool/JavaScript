# ngx-stack

> 标签: angular, capacitor, cordova, ios, mobile, navigation, page-transition, router-outlet, swipe-back, tabs

## 简介

Native-feeling page stacks for Angular: push/pop transitions and an interactive iOS swipe-to-go-back. Built for Capacitor and Cordova, works on the web.
