# ng-form-foundry

> 标签: angular, angular-material, dynamic-forms, form-builder, forms, json-schema, reactive-forms, schema-driven-forms, typescript

## 简介

Build fully-typed Angular Reactive Forms and Angular Material UI from a declarative, recursive form-description schema.
