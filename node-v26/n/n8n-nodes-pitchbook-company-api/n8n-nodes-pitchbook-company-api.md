> 标签: ai-tool, apify, company-data, deal-data, funding, investors, lead-generation, n8n, n8n-community-node-package, n8n-nodes, pitchbook, private-companies, venture-capital

## 简介

Collect PitchBook private company data from a profile URL: firmographics, funding, deals, investors, and competitors. Apify-backed n8n community node, pay-per-company, and usable as an AI agent tool.
