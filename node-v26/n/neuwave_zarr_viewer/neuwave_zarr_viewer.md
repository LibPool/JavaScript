# neuwave_zarr_viewer

> 标签: JavaScript

## 简介

Repository to be used in tandom with [zarr.js](https://github.com/neuwavetechnologies/zarr.js) to access zarr datasets in S3 via value-based access instead of index-based. Data is then exposed as typed arrays (e.g. Float64Array) of n-dimensions.
