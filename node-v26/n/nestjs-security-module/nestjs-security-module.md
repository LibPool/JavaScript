> 标签: audit-log, cors, csp, helmet, middleware, nestjs, permissions-policy, rate-limit, referrer-policy, security, security-module, xss

## 简介

A plug-and-play NestJS security module with CORS, Helmet, rate limiting, audit logging, CSP, XSS sanitization, and more.
