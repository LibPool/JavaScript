# nuxt-log-utils

> 标签: consola, log, logger, logging, masking, nuxt, nuxt-module, nuxt3, nuxt4, transport

## 简介

A flexible, extensible logger module for Nuxt 3/4 with masking, file rotation, per-level config, and transport extensions.
