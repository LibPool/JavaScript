# ngx-zoneless-scrollbar

> 标签: angular, angular-scrollbar, css-scrollbar, custom-scrollbar, native-scrollbar, ngx-scrollbar, resize-observer, scrollbar, signals, standalone, zoneless

## 简介

A lightweight, zoneless-compatible scrollbar component for Angular. Uses native browser scrolling with CSS-styled scrollbars, designed for Angular's zoneless change detection mode.
