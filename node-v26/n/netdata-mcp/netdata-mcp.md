# netdata-mcp

> 标签: mcp, metrics, monitoring, netdata, self-hosted

## 简介

Query your Netdata agent (self-hosted; set NETDATA_URL; optional NETDATA_TOKEN): node info, chart list, chart data. Endpoints per official docs.
