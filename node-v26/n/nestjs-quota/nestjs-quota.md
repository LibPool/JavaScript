# nestjs-quota

> 标签: api-quota, billing, nestjs, quota, rate-limit, redis, throttling, usage-metering

## 简介

Production-grade API quota enforcement and usage metering for NestJS: multi-scope policies, atomic distributed consumption, idempotency, reservations, and pluggable storage backends.
