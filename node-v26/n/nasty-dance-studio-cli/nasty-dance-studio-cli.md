# nasty-dance-studio-cli

> 标签: ai-agent, cli, mcp-alternative, nasty, nasty-dance-studio

## 简介

Command-line tool for AI agents (and admins) to read and manage Nasty Dance Studio's platform data — clients, vouchers, schedule, check-in — via its /api/v1 API. Requires an API key generated by an owner-tier admin from the app's /api-keys screen.
