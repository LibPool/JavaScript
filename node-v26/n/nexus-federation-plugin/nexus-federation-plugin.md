# nexus-federation-plugin

> 标签: JavaScript

## 简介

A [Nexus](https://nexusjs.org/) plugin to integrate [Apollo Federation](https://www.apollographql.com/docs/federation/) with [Nexus Schema](https://nexusjs.org/docs/guides/schema).
