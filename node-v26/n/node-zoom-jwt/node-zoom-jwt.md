# node-zoom-jwt

> 标签: zoom

## 简介

This package makes it simple to use **Zoom's JSON Web Token** functions with **Node JS**. To use node-zoom-jwt you will need your [APIKey & APISecret](https://marketplace.zoom.us/docs/guides/build/jwt-app)
