# n8n-nodes-gostore

> 标签: gostore, minio, n8n-community-node-package, object-storage, s3

## 简介

n8n community node for gostore — S3-compatible object storage. Objects, buckets, presigned URLs, on-the-fly image transforms, ingest keys and admin (snapshots, backup, folder usage).
