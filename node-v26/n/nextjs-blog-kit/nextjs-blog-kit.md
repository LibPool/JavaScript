# nextjs-blog-kit

> 标签: app-router, blog, claude-code, mdx, nextjs, seo, tailwind

## 简介

Copy-in MDX blog for Next.js App Router: topic hubs, pagination, JSON-LD, RSS, sitemap, CTAs — plus a Claude Code skill for writing articles with optional AI hero images.
