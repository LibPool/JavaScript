# n8n-nodes-pdf-tesseract-ocr

> 标签: n8n-community-node-package

## 简介

Renders scanned PDF pages to real bitmaps via pdf.js and OCRs them with tesseract.js - works regardless of the PDF's internal image compression (CCITT, JBIG2, JPEG2000, etc.), unlike nodes that try to extract embedded image objects directly.
