# nubodb

> 标签: database, document-store, encryption, file-database, javascript, json-database, modular, nodejs, nosql, query-builder, schema-validation, typescript

## 简介

A modern, fast, and feature-rich NoSQL database for Node.js with TypeScript support, encryption, schema validation, and modular architecture.
