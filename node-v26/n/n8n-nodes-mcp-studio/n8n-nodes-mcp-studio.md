> 标签: ai-agent, ai-context, context-engineering, documentation, mcp, mcp-studio, model-context-protocol, n8n, n8n-community-node-package, rag

## 简介

Give AI agents persistent context in n8n. Turn docs, code repositories, PDFs, specs, and other MCP servers into a live Model Context Protocol endpoint your workflows and agents read before they act, without writing code.
