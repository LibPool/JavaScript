# n8n-nodes-ejentum

> 标签: agentic-ai, ai, anti-deception, cognitive-scaffold, ejentum, llm, n8n-community-node-package, reasoning-harness

## 简介

n8n community node for the Ejentum Reasoning Harness. Eight operation modes: four dynamic (reasoning, code, anti-deception, memory) and four adaptive (adaptive-reasoning, adaptive-code, adaptive-anti-deception, adaptive-memory) that pre-fit the operation
