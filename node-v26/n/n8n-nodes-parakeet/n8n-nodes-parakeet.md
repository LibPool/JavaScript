# n8n-nodes-parakeet

> 标签: asr, ggml, n8n, n8n-community-node-package, parakeet, speech-to-text, transcription, whisper.cpp

## 简介

n8n community node for Parakeet (parakeet.cpp / whisper.cpp) — offline speech-to-text using the parakeet-tdt-0.6b-v3 model. Downloads a prebuilt parakeet-cli and the ggml-parakeet-tdt-0.6b-v3-q8_0.bin model at runtime.
