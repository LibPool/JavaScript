# n8n-nodes-auphonic

> 标签: audio, audio-post-production, audio-processing, auphonic, loudness, mastering, n8n, n8n-community-node-package, noise-reduction, podcast, speech, transcription

## 简介

n8n community node for Auphonic: automatic audio post production with loudness normalization, noise reduction and transcription. Create productions, fetch their details, download output files, and trigger workflows when processing finishes.
