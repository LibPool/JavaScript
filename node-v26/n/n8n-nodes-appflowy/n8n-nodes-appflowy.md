# n8n-nodes-appflowy

> 标签: n8n-community-node-package

## 简介

n8n Community Node for AppFlowy - a privacy-first, open source workspace for your notes, wikis, projects, and more. Comes with both Regular and Trigger Node and is also available as Tool in AI Agents.
