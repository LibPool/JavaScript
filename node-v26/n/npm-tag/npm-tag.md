# npm-tag

> 标签: JavaScript

## 简介

> A [micro JavaScript library](http://microjs.com/#) for creating elements, inspired by [Laconic](https://github.com/joestelmach/laconic) and [React](facebook.github.io/react/). Tag removes the overhead of existing templates (in regards to speed and size)
