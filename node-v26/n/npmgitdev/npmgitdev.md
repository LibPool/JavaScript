# npmgitdev

> 标签: JavaScript

## 简介

A wrapper around npm that allows real live git repos to be cloned into node_modules.

## 官网

- 官网：https://github.com/TerriaJS/npmgitdev#readme
- 源码仓库：git+https://github.com/TerriaJS/npmgitdev.git
- npm 页面：https://www.npmjs.com/package/npmgitdev
