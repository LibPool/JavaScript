# neural-phrasex

> 标签: ai, chatbot, embeddings, information extraction, intent, knn, language model, machine learning, matching, misspellings, one shot learning, phrase, regex, search, semantic, sentence embeddings, slot filling, tensorflow

## 简介

Matches a given phrase to the best match in a database and determines the wildcards using a slot filler.  This is like a regex, but much more flexible for phrase matching and alignment.
