# ng-postcode-js

> 标签: address, address-validation, geocoding, ndaps, nigeria, nigerian, nipost, postal, postal-code, postcode, validation, validator, zip-code

## 简介

Validate, parse and format Nigerian postcodes (postal codes) offline: Nigeria's 11-character NIPOST digital postcode (NDAPS). Includes a client for the postcode.gov.ng API.
