# n8n-nodes-analytics

> 标签: ai, analytics, anthropic, cost, execution, langchain, n8n, n8n-community-node-package, openai, tokens, workflow

## 简介

Powerful n8n community node for execution analytics, AI token tracking, cost estimation, and workflow analysis. Replaces complex 10-20 node analytics workflows with a single reusable node.
