# neveroversell

> 标签: booking, concurrency, hold, idempotent, inventory, oversell, payment, postgres, reservation, seat, webhook

## 简介

Holds that cannot oversell: Postgres reservations with TTL, a payment phase, idempotent two-path confirmation, a concurrent-safe sweeper and a drift check. One migration, one thin client, the guarantee enforced by the database.
