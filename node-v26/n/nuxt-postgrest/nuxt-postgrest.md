# nuxt-postgrest

> 标签: database, nuxt, nuxt-module, postgres, postgresql, postgrest, rest

## 简介

First-class PostgREST for Nuxt: typed clients, SSR-aware composables and auth-aware JWT forwarding. No Supabase required.
