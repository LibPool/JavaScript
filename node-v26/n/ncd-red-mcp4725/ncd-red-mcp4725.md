# ncd-red-mcp4725

> 标签: DAC, MCP4725, i2c, ncd

## 简介

This library provides a class for the MCP4725, it relies on the ncd-red-comm library for communication, and includes a node-red node for the MCP4725. The MCP4725 is a low-power, high accuracy, single channel, 12-bit buffered voltage output Digital-to-Anal
