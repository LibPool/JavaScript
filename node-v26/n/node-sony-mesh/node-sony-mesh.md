# node-sony-mesh

> 标签: BLE, Bluetooth, Bluetooth Low Energy, Bluetooth smart, Internet of Things, IoT, MESH, SONY

## 简介

node-sony-mesh は、SONY の IoT ブロック「MESH」をコントロールするための node モジュールです。7 種類すべてのブロックに対応し、ブロックの制御やブロックからのメッセージ受信を行います。
