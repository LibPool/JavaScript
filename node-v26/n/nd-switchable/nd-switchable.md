# nd-switchable

> 标签: JavaScript

## 简介

Switchable 提供了切换的基本操作，并通过参数配置实现了自动播放，循环，切换等操作，并提供不同的特点封装成了 Tabs，Slide，Carousel，Accordion 模块。用户可以根据自己的需求引用不同的模块。
