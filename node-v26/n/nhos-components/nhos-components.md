# nhos-components

> 标签: JavaScript

## 简介

``` |--miniprogram_dev // 开发环境构建目录 |--dist // 生产环境构建目录 |--src // 源码 |--test // 测试用例 |--tools // 构建相关代码 |   |--demo // demo 小程序目录，开发环境下会被拷贝生成到 miniprogram_dev 目录中 |   |--config.js // 构建相关配置文件 | |--gulpfile.js ```
