# nous-verify

> 标签: cli, compliance, merkle-tree, rfc3161, sealkit, timestamp, verification

## 简介

Fully offline verifier for Sealkit sealed receipts — Merkle inclusion/consistency proofs + RFC 3161 timestamp, checked against a pinned CA, zero network calls.
