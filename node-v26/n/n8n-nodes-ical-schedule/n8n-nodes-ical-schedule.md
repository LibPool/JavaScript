# n8n-nodes-ical-schedule

> 标签: appointments, calendar, ical, ics, n8n, n8n-community-node-package, schedule

## 简介

n8n community node: today's (or the next few days') appointments from an iCal feed. Dependency-free port of the trmnl-calendar PHP iCal parser.
