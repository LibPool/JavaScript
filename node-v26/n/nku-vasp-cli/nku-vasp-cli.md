# nku-vasp-cli

> 标签: 2d-materials, agent, ai-cli, cli, crystal-structure, graphene, hbn, heterostructure, llm, materials, mos2, motif, pymatgen, supercell, vasp

## 简介

Agent-first materials CLI — build, edit, and inspect 2D materials and catalytic interfaces with 1-4 token commands. Auto-renders PNG + Markdown summary for multimodal-agent self-verification.
