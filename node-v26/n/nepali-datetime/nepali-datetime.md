# nepali-datetime

> 标签: AD to BS, BS to AD, ad-bs, ad-to-bs, bs-ad, bs-to-ad, calendar, date-converter, javascript, nepal, nepali, nepali-date, nepali-date-converter, nepali-time, nepali-timezone, node, typescript

## 简介

A Node project designed to support native JavaScript-like features for Nepali dates. It includes features such as 'NepaliDate' for Nepali date support and 'dateConverter' for date conversions.
