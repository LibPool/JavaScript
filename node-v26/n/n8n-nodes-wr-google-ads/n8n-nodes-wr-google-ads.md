# n8n-nodes-wr-google-ads

> 标签: adwords, conversion-upload, google-ads, googleads, n8n, n8n-community-node-package, offline-conversions

## 简介

Webrunner custom n8n node for Google Ads — drop-in replacement for the built-in Google Ads node, with a selectable (non-hardcoded) API version, a one-call campaign/ad group/ad ID-to-name lookup, and offline conversion upload (click + call) with a per-item
