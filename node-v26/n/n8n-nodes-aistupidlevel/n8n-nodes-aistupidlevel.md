# n8n-nodes-aistupidlevel

> 标签: ai-agent, aistupidlevel, benchmarks, llm, n8n, n8n-community-node-package, router

## 简介

n8n nodes for AI Stupid Level: the Smart Router (each request goes to the model measuring best for it, with your own provider keys), a chat model for the AI Agent, and continuously re-run LLM benchmark, drift and incident data.
