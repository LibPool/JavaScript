# n8n-nodes-ecb-exchange-rates-scraper-ru

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Курсы валют ЕЦБ через открытый API Frankfurter — без ключа, без прокси, без лимитов, история с 1999 г. Под расчёты и параллельный импорт СНГ-бизнеса: USD, EUR, TRY, CNY. ЕЦБ не публикует прямой курс RUB — только эти ~30 валют. Режимы: latest / historical
