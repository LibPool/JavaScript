# node-playsound

> 标签: audio, audio-playback, audio-player, cross-platform, esm, flac, mp3, nodejs, play-sound, sound, typescript, wav, zero-dependencies

## 简介

Play WAV, MP3, and FLAC files from Node.js on Windows, macOS, and Linux. Concurrent playback, seeking, and volume control with zero runtime dependencies.
