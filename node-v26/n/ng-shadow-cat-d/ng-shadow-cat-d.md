# ng-shadow-cat-d

> 标签: angular

## 简介

Ng-Shadow-Cat是一套前端组件库的Angular实现，封装了常用的一些UI组件,珊格系统和模式 假设你已了解关于 HTML、CSS 和 JavaScript 的中级知识，并且已经完全掌握了Angular的基本开发方式，便可使用
