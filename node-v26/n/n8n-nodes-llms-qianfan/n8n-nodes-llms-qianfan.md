> 标签: AI, Baidu, Qianfan, llm, n8n, n8n-community-node-package

## 简介

A custom n8n node to integrate and leverage the Baidu Qianfan model, enabling users to access powerful AI capabilities directly within their n8n workflows. The node facilitates seamless interactions with Baidu's big model for natural language processing,
