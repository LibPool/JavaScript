# nuxt4-ssr-devtools

> 标签: JavaScript

## 简介

用于 Nuxt 4 开发环境的 SSR 请求调试模块。它可以捕获 Nuxt 服务端渲染和浏览器端发起的 `fetch` 请求，并通过页面内浮动面板查看请求详情，同时兼容 `cms-chrome-extension`。
