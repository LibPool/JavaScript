# nfc-tap

> 标签: android-chrome, contactless, ndef, ndefreader, nfc, nfc-reader, nfc-tag, nfc-tap, nfc-writer, ntag, react-hooks, typescript

## 简介

A friendly wrapper around the browser's Web NFC API: one object per tap, a real stop(), auto-resume on backgrounding and typed errors.
