# nav-kit

> 标签: authentication, components, nextjs, react, supabase, ui, user

## 简介

This is the boilerplate for a react application with a prewritten, headless NavBar, coupled tightly with user authentication. It also comes with a login and signup form. All these components are headless and highly customisable.
