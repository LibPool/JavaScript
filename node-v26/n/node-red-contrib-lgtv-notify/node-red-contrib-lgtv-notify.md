# node-red-contrib-lgtv-notify

> 标签: home-automation, lg, lgtv, node-red, notification, smart-home, toast, tv, webos

## 简介

Send toast notifications to LG webOS TVs from Node-RED. Works with webOS 10+ (2025 TVs).
