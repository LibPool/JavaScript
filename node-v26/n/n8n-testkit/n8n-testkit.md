# n8n-testkit

> 标签: assertions, automation, ci, code-node, fixtures, n8n, n8n-test, n8n-testing, n8n-workflow, no-dependencies, regression, regression-testing, test, testing, workflow-testing

## 简介

Test n8n workflows in CI: runs the JavaScript in your Code nodes against fixtures and exits non-zero when the output regresses. No n8n instance, no credentials, zero dependencies.
