# n8n-nodes-wb-crm

> 标签: contacts, crm, leads, n8n, n8n-community-node-package, wb-crm

## 简介

WB-CRM nodes for n8n — interact with the WB-CRM REST API (Leads, Contacts, Tasks, Projects, Campaigns) and receive real-time webhook events.
