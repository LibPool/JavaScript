# node-build-stream

> 标签: build, gulp, gulp-alternative, no-dependency, node, stream, task-runner, vinyl

## 简介

A no-dependency, Node 24+ streaming build runner that replaces gulp while staying compatible with existing gulp plugins and Vinyl file objects.
