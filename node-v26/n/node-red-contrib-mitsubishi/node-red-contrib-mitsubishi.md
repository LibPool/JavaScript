## 简介

三菱 MC Protocol 3E/4E 读写节点 — TCP/UDP 双传输, 批量字写+原生位写+RMW, 写入表格默认值列, 960字聚类万点采集, 104项测试, 零依赖, 支持Q/L/iQ-R/iQ-F/FX5U
