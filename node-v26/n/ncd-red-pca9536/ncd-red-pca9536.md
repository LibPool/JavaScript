# ncd-red-pca9536

> 标签: PCA9536, i2c, ncd, relay-control

## 简介

This library provides a class for the PCA9536, it relies on the ncd-red-comm library for communication, and includes a node-red node for the PCA9536. The PCA9536 is an 8-pin CMOS device that provides 4 bits of General Purpose parallel Input/Output (GPIO)
