# node-auth-core

> 标签: JavaScript

## 简介

A production-ready, self-hosted authentication library for Node.js featuring JWT, refresh tokens, sessions, OAuth 2.0, MFA, and passwordless login — fully framework-agnostic with zero external auth dependencies.
