# @dnd-mapp/design-tokens

> 标签: css, css-custom-properties, design-system, design-tokens, dnd-mapp, dtcg, figma, fonts, sass, scss

## 简介

The D&D Mapp design tokens from the Figma library, as CSS custom properties, typed constants, Sass, and DTCG JSON, with the Inter and JetBrains Mono fonts.
