# @dnd-mapp/package-builder

> 标签: build-tools, cli, dnd-mapp, nodejs, npm, npm-package, pnpm, publishing, typescript

## 简介

Prepares the dist directory for npm publishing across D&D Mapp projects: writes a trimmed package.json, copies consumer files, and validates exports and bin paths.
