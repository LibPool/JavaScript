# @qmilab/lodestar-adapter-sql

> 标签: action-kernel, adapter, ai-agents, database, lodestar, postgres, sql, tool, trust

## 简介

Governed SQL/database tool adapter (parameterized-only query + mutation) for the Lodestar Action Kernel. Part of Lodestar, the trust layer for AI agents.
