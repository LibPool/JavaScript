# @3-/gitapi

> 标签: api, atomgit, git, github, sync

## 简介

Git API wrapper for repo synchronization; works with gitsync to sync AtomGit repos to GitHub. / Git API 封装，用于仓库同步；配合 gitsync 将 AtomGit 仓库同步到 GitHub。
