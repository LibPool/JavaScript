# caishi-mcp

> 标签: bilibili, browser, china, chinese, chrome, douyin, mcp, model-context-protocol, scraper, xiaohongshu

## 简介

Self-contained MCP server. Read Chinese platforms from any MCP client: Bilibili, Douyin, Xiaohongshu and any web page, through your own logged-in browser session.
