# @urbankitstudio/cli

> 标签: agents, api, arcgis, assessor, cli, county, gis, parcel, property, real-estate

## 简介

uks: the UrbanKit Studio command line. Plans, quota and usage for your API key, address-to-parcel lookups, county requests, and offline county discovery from the County Parcel REST API Atlas. JSON output and stable exit codes for agents.
