# @urbankitstudio/atlas

> 标签: api, arcgis, assessor, county, featureserver, geojson, gis, mapserver, parcel, property, real-estate, rest

## 简介

JS SDK for the UrbanKit County Parcel REST API Atlas: 227 counties across all 50 US states, 241 verified public ArcGIS REST endpoints for county parcel data, with searchable field metadata, sample queries and license info.
