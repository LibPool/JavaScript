# laravel-workers

> 标签: blade, build-time, cloudflare, d1, edge, laravel, toolchain, transpiler, workers, workers-native

## 简介

Build-time toolchain: compile a Laravel app's Blade views, routes and D1 read paths to a Cloudflare Workers artifact (static + snapshot + compiled handlers); unsupported constructs fail the build
