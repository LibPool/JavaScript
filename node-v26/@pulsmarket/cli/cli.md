# @pulsmarket/cli

> 标签: ai-agent, arc, candlestick, circle, cli, prediction-market, puls, trading, tui, usdc, x402

## 简介

Puls CLI — a full terminal trading desk for the Puls prediction market on Arc: buy / sell / claim predictions, live markets + candlestick charts, the AI agent swarm, AI oracle, x402 signal unlocks, bring-your-own-agent, and a full-screen TUI.
