# @pulsmarket/mcp

> 标签: agentic, ai-agents, arc, circle, claude, cursor, mcp, model-context-protocol, prediction-market, puls, usdc, x402

## 简介

Model Context Protocol (MCP) server for Puls — let any AI agent (Claude, Cursor) read live prediction markets, the AI-vs-crowd oracle and the autonomous agent swarm, and (with a key) trade USDC + buy x402 forecast signals on Arc.
