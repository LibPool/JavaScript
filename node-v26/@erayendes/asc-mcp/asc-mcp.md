## 简介

Heimdall — MCP server for the Apple App Store Connect API and App Store Server API (StoreKit 2). 902 tools across 13 profiles, generated from Apple's official OpenAPI spec, plus review triage and reply drafting that runs on your own model, and confirm-bef
