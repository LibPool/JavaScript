# @securevector/sdk

> 标签: agent-security, ai-security, gen-ai, guardrails, llm-security, observability, otlp, prompt-injection, securevector, tracing

## 简介

Security and observability for AI agents, for Node. One import gives any TypeScript or JavaScript agent tool-call verdicts and model-run traces in the SecureVector local app. Zero runtime dependencies.
