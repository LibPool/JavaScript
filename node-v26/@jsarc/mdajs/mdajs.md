# @jsarc/mdajs

> 标签: arcjs, components, design-system, mda, responsive, scss, typescript, ui, vanilla

## 简介

MDAJS est le portage vanilla (TypeScript/JavaScript, sans framework) du système de composants MDA : ~83 composants utilisables en HTML/JS pur, avec styles SCSS, support responsive/scroll par propriété et API déclarative data-*.
