# @sebastienrousseau/crypto-mcp

> 标签: ai-agents, claude, cryptography, encryption, llm, mcp, mcp-server, ml-dsa, ml-kem, model-context-protocol, post-quantum, pqc

## 简介

Model Context Protocol (MCP) server that gives AI assistants and agents cryptography tools: key generation, encryption, ML-KEM, ML-DSA signing, hashing, streaming encryption, KMS and CBOM.
