# @philipibovo/ngx-flexbox

> 标签: angular, flexbox, flexlayout, ngx-flexbox, philipi bovo

## 简介

ngx-flexbox provides an easy layout API using Flexbox CSS, this lib was created as an alternative to @angular/flexlayout
