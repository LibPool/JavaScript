# @sahan-sac/auth-kit-client

> 标签: auth, better-auth, expo, rbac, react, react-native

## 简介

React web and React Native (Expo) client for @sahan-sac/auth-kit's Better Auth engine: a typed auth client with auth-kit's user fields and sign-in, permission hooks, and a fetch helper that calls your API with the session.
