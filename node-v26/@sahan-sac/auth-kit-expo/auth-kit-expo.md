# @sahan-sac/auth-kit-expo

> 标签: auth, better-auth, expo, rbac, react-native

## 简介

React Native (Expo) client for @sahan-sac/auth-kit's Better Auth engine: a typed auth client with auth-kit's user fields, permission hooks, and a fetch helper that calls your API with the stored session.
