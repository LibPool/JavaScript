# @sahan-sac/propertyfinder-kit

> 标签: dubai, listings, propertyfinder, real-estate

## 简介

Property Finder (Atlas API) for server apps: typed client with token auth and retries, listing and lead transforms, webhook payload parsing, and an optional Redis cache layer that turns itself off when Redis is not configured. Framework-agnostic; persiste
