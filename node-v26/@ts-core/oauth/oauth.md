# @ts-core/oauth

> 标签: authentication, authorization, cordova, google, keycloak, login, mailru, oauth, oauth2, sso, telegram, typescript, vk, yandex

## 简介

TypeScript library for OAuth authentication through Google, VK, Yandex, Mail.ru, Keycloak and Telegram, supporting browser, Cordova and Telegram Web App platforms
