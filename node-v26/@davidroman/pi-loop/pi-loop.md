# @davidroman/pi-loop

> 标签: pi-package

## 简介

Reliable scheduled loops for the Pi coding agent — prompt/notify/shell/message on interval, once, or cron. Session-scoped by default (fires only where created), global opt-in. Always-visible status, working input, bulletproof recurrence.
