# @clikta/mcp-server

> 标签: browser-automation, claude, demo, documentation, mcp, model-context-protocol, playwright

## 简介

MCP server that lets Claude drive a real browser and turn what it does into a Clikta interactive demo, step guide, and narrated video — automatically.
