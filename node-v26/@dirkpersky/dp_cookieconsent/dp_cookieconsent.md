# @dirkpersky/dp_cookieconsent

> 标签: C-673/17, DSGVO, TTDSG, consent, cookie, cookieconsent, ePrivacy

## 简介

This Plugin includes the most popular solution to the EU Cookie law JavaScript Plugin Cookie Consent. Extended with an Script and iFrame helper, so it works with the ePrivacy law.
