# @internetdata/internetdata

> 标签: asn, bogon, dataset, download, hosting, ip-data, ip-database, ip-intelligence, maxmind-db, mmdb, proxy, vpn

## 简介

Official Node.js client library for the InternetData API. Download, verify and inspect licensed IP database files.
