# @softwareseva/auth

> 标签: JavaScript

## 简介

Drop-in authentication for Hono on Cloudflare Workers + D1 and React: JWT access tokens with rotating refresh-token families, cookie or bearer transport, password, WhatsApp/SMS/email one-time codes, Google, Sign in with Apple, and passkeys (WebAuthn). Shi
