# @softwareseva/core

> 标签: JavaScript

## 简介

Shared foundation for kashi apps: Hono app factory with request ids and error envelope, ApiError, WebCrypto helpers, PBKDF2 passwords, sortable ids, phone normalisation, LIKE escaping, D1 rate limiting, and a fetch client with shared session refresh.
