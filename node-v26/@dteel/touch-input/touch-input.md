# @dteel/touch-input

> 标签: JavaScript

## 简介

touch-input makes number typed inputs display a fullscreen number pad for easy editing on mobile devices. When clicked with a mouse, nothing special happens, but if touch event of pen event, it displays a fullscreen numberpad. Component signature looks li
