# @metantel/forge

> 标签: agents, claude, har, legacy, mcp, model-context-protocol, openapi

## 简介

Metantel Forge — one command from a web application to a deployable MCP server. Fuses browser HAR captures, Gateway tool catalogs, data-atlas drafts, and OpenAPI specs into a finished, compiling TypeScript MCP project.
