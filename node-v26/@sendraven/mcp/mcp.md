# @sendraven/mcp

> 标签: ai-agents, claude, cursor, email, email-api, mcp, model-context-protocol, sendraven

## 简介

MCP server for SendRaven, email infrastructure for AI agents: send email, read replies as threads, run campaigns and automations, with per-key limits and approvals.
