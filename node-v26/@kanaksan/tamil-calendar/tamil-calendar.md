# @kanaksan/tamil-calendar

> 标签: kanaksan, panchangam, react, tamil-calendar

## 简介

React component for rendering the kanaksan.com Tamil daily panchangam calendar sheet, backed by a REST API, with dark/light mode and a pluggable theme system.
