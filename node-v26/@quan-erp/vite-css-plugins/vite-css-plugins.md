# @quan-erp/vite-css-plugins

> 标签: JavaScript

## 简介

A PostCSS plugin designed to implement strict visual isolation for Quan ERP frontend modules. It automatically encapsulates CSS selectors within a unique plugin-specific attribute to prevent style leakage in the shared ERP shell.
