# @ansio/nuxt-schema

> 标签: JavaScript

## 简介

Nuxt module — injects a page's Ansio JSON-LD schema server-side into every render, so non-JS crawlers see it without a build step. Add to nuxt.config.ts modules and set { clientKey }.
