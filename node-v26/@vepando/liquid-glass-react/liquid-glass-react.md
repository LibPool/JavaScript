# @vepando/liquid-glass-react

> 标签: apple, backdrop-filter, feDisplacementMap, glassmorphism, ios26, liquid-glass, nextjs, react, refraction, svg-filter, ui

## 简介

Apple-style Liquid Glass for React: physically-based refraction (Snell's law), specular rim and touch-reactive glass via SVG backdrop-filter. No WebGL.
