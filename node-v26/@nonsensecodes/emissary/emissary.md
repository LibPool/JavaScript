# @nonsensecodes/emissary

> 标签: auth, authentication, oauth2

## 简介

Simple OAuth2 interaction library, utilizing ES6 modules and JavaScript object delegation.  Emissary negotiates the exchange of an authentication code for an access token. Provides simplified client access and allows for construction of more complex apis
