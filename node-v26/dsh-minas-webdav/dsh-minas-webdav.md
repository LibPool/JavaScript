# dsh-minas-webdav

> 标签: deepseek, deepseek-harness, dsh, dsh-plugin, mcp, minas, nas, webdav, xiaomi

## 简介

Xiaomi Smart Storage (MINAS) NAS file tools for DeepSeek Harness: registers the minas-webdav MCP server (14 nas_* tools) as a bundle. 小米 NAS 的 WebDAV 文件工具，注册 minas-webdav MCP。
