# markdown-transform-html

> 标签: JavaScript

## 简介

markdown-transform-html 2.x: a CommonMark-compliant Markdown to HTML engine (markdown-it based) with resume layout extensions — multi-column/head/main containers, icon & svg inline syntax, image size syntax. (基于 markdown-it 的标准 Markdown 转 HTML 引擎，扩展简历多列布局
