# @apachedubbo/dubbo-fastify

> 标签: JavaScript

## 简介

Dubbo is a family of libraries for building and consuming APIs on different languages and platforms, and [@apachedubbo/dubbo](https://www.npmjs.com/package/@apachedubbo/dubbo) brings type-safe APIs with Protobuf to TypeScript.
