# @upship/agents

> 标签: agents, ai-sdk, dag, llm, openrouter, orchestration, postgres, sqlite

## 简介

An agent platform where agents are data: versioned rows with a prompt, a model tier, tools, and an optional pipeline. API, CLI, and web UI in one install.
