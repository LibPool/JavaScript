# @irtio/ecs

> 标签: JavaScript

## 简介

Optional irtio library: an ECS-style query and system layer over the room schema, plus a correction-aware speculative-effect manager (claim/judge round trip, outcome transport, retention). For games built on it from the start; see the package README.
