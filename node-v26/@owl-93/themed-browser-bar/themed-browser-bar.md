# @owl-93/themed-browser-bar

> 标签: bar, browser, color, theme

## 简介

A lightweight backage providing a hook to manage theme meta tag in your document head. It is meant to allow you to dynamically update the theme color of your website so that you can control the color of the browser url bar on certain mobile browsers.
