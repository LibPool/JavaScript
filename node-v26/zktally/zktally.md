# zktally

> 标签: e-voting, homomorphic-encryption, lsag, paillier, ring-signature, secp256k1, voting, zero-knowledge

## 简介

Privacy-preserving, anonymously verifiable e-voting from linkable ring signatures, Paillier homomorphic encryption, and NIZK vote-correctness proofs. Unaudited academic software; must not be used for any binding election.
