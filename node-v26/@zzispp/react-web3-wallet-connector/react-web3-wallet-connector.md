# @zzispp/react-web3-wallet-connector

> 标签: blockchain, cryptocurrency, ethereum, react, solana, tron, wallet, web3

## 简介

一个用于 React 应用程序的 Web3 钱包连接组件库，支持多种钱包连接方式，包括 Ethereum、Solana 和 Tron。
