# chatgpt-webmcp-bridge

> 标签: ai-agents, chatgpt, cugel, glottis, iframe, mcp, mcp-apps, plugin, webmcp

## 简介

A ChatGPT plugin that lets ChatGPT use a web page's tools, served with glottis or registered with WebMCP, in a small browser panel inside the chat.
