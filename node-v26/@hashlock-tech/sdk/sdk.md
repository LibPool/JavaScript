# @hashlock-tech/sdk

> 标签: atomic-swap, bitcoin, cross-chain, defi, hashlock, htlc, otc

## 简介

TypeScript SDK for the Hashlock Markets developer API — non-custodial cross-chain atomic swaps (BTC ↔ EVM/TRON/Solana) over sealed RFQ + HTLC.
