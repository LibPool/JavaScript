# @b20labs/sdk

> 标签: b20, base, erc20, precompile, token-standard, viem

## 简介

TypeScript SDK for B20 — Base's native token standard. Byte-exact encoders (golden-vector tested against base-std), zero-RPC address derivation, typed precompile error decoding.
