# @jumentix/designer-core

> 标签: asyncapi, designer, domain-model, exporters, framework-free, importers, jumentix, openapi, validation

## 简介

Framework-free Service Management designer core — domain model, validation engine, exporters, importers and domain-package versioning as browser-safe ESM, with no DOM and no storage implementation.
