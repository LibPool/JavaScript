# @weapp-tailwindcss/react-native

> 标签: JavaScript

## 简介

Tailwind CSS compiler and Expo Metro integration for cross-platform React Native apps. 面向跨端 React Native 应用的 Tailwind CSS 编译器与 Expo Metro 集成。

## 官网

- 官网：https://tw.weapp.dev/docs/quick-start/react-native-expo
- 源码仓库：git+https://github.com/sonofmagic/weapp-tailwindcss.git
- npm 页面：https://www.npmjs.com/package/@weapp-tailwindcss/react-native
