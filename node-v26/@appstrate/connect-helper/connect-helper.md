# @appstrate/connect-helper

> 标签: appstrate, oauth, pairing

## 简介

One-shot OAuth helper for Appstrate model-provider subscriptions. Run the command the dashboard prints: `npx @appstrate/connect-helper@0.3.x <token>`.
