# @appstrate/afps-shared

> 标签: afps, appstrate, integrity, public-suffix-list, semver, sri

## 简介

Zero-internal-dependency AFPS helpers shared by @appstrate/core and @appstrate/afps-runtime (companion-file checks, semver resolution, SRI integrity, credential templates, authorized_uris rules and host bounds, delivery.http projection)
