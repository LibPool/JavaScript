# @ailura/alpinejs-theme

> 标签: alpine, alpinejs, dark-mode, headless, plugin, theme

## 简介

Light, dark, and system theme controller for Alpine.js — MachineController-backed, SSR-safe, with pluggable persistence and cross-tab sync.
