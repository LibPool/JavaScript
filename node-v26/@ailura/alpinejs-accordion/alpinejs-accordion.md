# @ailura/alpinejs-accordion

> 标签: accessibility, accordion, alpine, alpinejs, headless, plugin

## 简介

Alpine.js headless accessible accordion store — single/multiple modes, defaultOpen, roving tabindex, arrow-key navigation and ARIA helpers on @ailura/alpinejs-core. Moves state, not focus.
