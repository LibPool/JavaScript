> 标签: ai-agents, claude, libxml2, llm, mcp, mcp-server, model-context-protocol, read-only, sandbox, sezzlee, xml, xml-query, xpath

## 简介

Read-only MCP server that lets AI agents query local XML documents with XPath, paged and sandboxed to one folder.
