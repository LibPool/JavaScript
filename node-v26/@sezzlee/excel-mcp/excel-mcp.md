# @sezzlee/excel-mcp

> 标签: ai-agents, claude, csv, excel, llm, mcp, mcp-server, model-context-protocol, read-only, sandbox, sezzlee, spreadsheet, workbook, xlsm, xlsx

## 简介

Read-only MCP server that lets AI agents read local Excel workbooks (.xlsx, .xlsm, .csv): cells, formulas, tables and defined names, sandboxed to one folder.
