# @sezzlee/pdf-mcp

> 标签: ai-agents, claude, llm, mcp, mcp-server, model-context-protocol, ocr, offline, pdf, pdf-extraction, pdf-to-text, read-only, sandbox, sezzlee, text-extraction

## 简介

Read-only MCP server that lets AI agents extract text from local PDF documents, with optional pluggable OCR. Never reaches the network.
