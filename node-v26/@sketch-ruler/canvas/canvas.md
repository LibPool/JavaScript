# @sketch-ruler/canvas

> 标签: canvas, framework-agnostic, input, renderer, ruler, sketch-ruler

## 简介

Canvas rendering and DOM input management for sketch-ruler. Framework-agnostic, depends on Canvas 2D API and DOM Events.
