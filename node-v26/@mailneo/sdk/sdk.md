# @mailneo/sdk

> 标签: api-client, email, email-marketing, mailneo, newsletter, sdk, typescript

## 简介

TypeScript SDK for the Mailneo public API (v2). Fetch-based, zero runtime dependencies, Node 18+ and browsers.
