# @ladamczyk/react-compiler-profiler

> 标签: cli, memoization, performance, playwright, profiler, react, react-compiler, vite

## 简介

Empirically measure whether React Compiler is helping your app — build it with and without the compiler, replay the same Playwright scenarios against both, and report the difference in render counts and paint/load timings.
