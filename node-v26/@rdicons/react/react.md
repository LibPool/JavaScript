# @rdicons/react

> 标签: heroicons, icons, lucide, material-icons, phosphor, rdicons, react, react-icons, svg, tabler

## 简介

78,000+ open-source icons as tree-shakable React components. Import only what you use, e.g. import { House } from '@rdicons/react/lucide'.
