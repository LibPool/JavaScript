# @irisrun/host

> 标签: JavaScript

## 简介

Iris host adapter surface — HostAdapter {name, capabilities, store, scheduler}, runTurnOn (run a turn ON a host's store+scheduler), and checkHostCapabilities (the tool/host-level refusal). Makes 'same image, different host' explicit for the portability pr
