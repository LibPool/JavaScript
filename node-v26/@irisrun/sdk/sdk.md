# @irisrun/sdk

> 标签: JavaScript

## 简介

Iris adapter SDK — one dependency to build a store, channel, or provider adapter. Curated re-exports of the three port type-sets, the three importable conformance suites, and the forkless-loader contracts (openStore / openModelProvider / openChannel). Pai
