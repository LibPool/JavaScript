# @irisrun/store-mongo

> 标签: JavaScript

## 简介

Iris host store on MongoDB — a StateStore + Scheduler certified against @irisrun/store-conformance, plugged into the CLI via `--store @irisrun/store-mongo --db mongodb://…`. `mongodb` is a peer dependency (you install it), so Iris's own tree stays zero-de
