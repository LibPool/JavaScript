# @irisrun/journal-export

> 标签: JavaScript

## 简介

Iris verifiable portable journal — a self-contained, content-addressed (SHA-256 + tamper-evident hash chain) export of a session's snapshot + journal tail, with two-tier verification (Tier 1 file-only structure + content-address; Tier 2 replay-determinism
