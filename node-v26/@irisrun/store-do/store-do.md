# @irisrun/store-do

> 标签: JavaScript

## 简介

Edge host adapter that proves portability — the Cloudflare Durable Objects StateStore + Scheduler enforcing the SAME CAS/fencing/hwm/snapshot invariants as the sqlite/fs stores, so the same image resumes the same session on the edge byte-identically. Cold
