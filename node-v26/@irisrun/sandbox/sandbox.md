# @irisrun/sandbox

> 标签: JavaScript

## 简介

Iris sandbox boundary — SandboxBackend/SandboxSession with a deny-all network floor + credential brokering (secret never enters the sandbox). inmemory backend (unit) + docker backend (manual smoke). Host-side, zero external deps.
