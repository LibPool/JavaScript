# @claude-worker/ui

> 标签: agent, anthropic, claude, claude-code, components, react, tailwind, ui

## 简介

Styled agent-control component library for claude-worker: session panel, transcript with streaming, tool-call cards, permission prompts, session list, composer. Tailwind v4 + Base UI + cva. Pairs with the headless @claude-worker/react layer.
