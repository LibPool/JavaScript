# @claude-worker/web

> 标签: agent, anthropic, claude, claude-code, dashboard, spa

## 简介

The claude-worker dashboard as prebuilt static files: session list, create/resume flow, live panel, jobs, profiles, settings. Ships dist/ plus the path to it — serve it from the same origin as the gateway. Zero runtime dependencies.
