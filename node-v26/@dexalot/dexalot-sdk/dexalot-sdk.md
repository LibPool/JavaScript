# @dexalot/dexalot-sdk

> 标签: JavaScript

## 简介

Here is our first public release of Dexalot SDK for TypeScript.  It is in alpha testing right now.  Fork it, contribute to it and use it to integrate with Dexalot and let us know how we can improve it.
