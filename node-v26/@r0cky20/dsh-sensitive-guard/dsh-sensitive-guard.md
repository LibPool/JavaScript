# @r0cky20/dsh-sensitive-guard

> 标签: deepseek-harness, dsh, dsh-plugin, guard, pii, privacy, redaction, secrets, security

## 简介

Sensitive-data guard for DeepSeek Harness: blocks credential reads/outbound secrets and redacts secrets, tokens, and PII before they reach the model, session log, or spill files.
