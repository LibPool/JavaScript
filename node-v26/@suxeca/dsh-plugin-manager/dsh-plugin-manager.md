# @suxeca/dsh-plugin-manager

> 标签: JavaScript

## 简介

DSH 插件管理器：/plugin 人类命令 + 设置页「插件管理」，列出/安装/卸载 web profile 的 bundle 插件（改 ~/.dsh/profiles/web/package.json，重启生效）
