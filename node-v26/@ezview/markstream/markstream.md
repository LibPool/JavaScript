# @ezview/markstream

> 标签: echarts, katex, markdown, markstream, mermaid, streaming-markdown, vue, vue3

## 简介

Vue 3 开箱即用的流式 Markdown 渲染组件，基于 markstream-vue，内置 GitHub 浅色观感、Mermaid、ECharts、KaTeX、代码块高亮。
