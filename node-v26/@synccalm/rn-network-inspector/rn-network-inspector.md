# @synccalm/rn-network-inspector

> 标签: api-debugging, axios, claude, dashboard, debugging, devtools, diff, expo, fetch, http, inspector, json, logger, mcp, metro, model-context-protocol, network, network-inspector, react-native, xhr

## 简介

React Native network inspector — see every fetch and XHR your app makes in a live browser dashboard, diff repeated API calls like git, and let Claude query the traffic over MCP.
