# @meetstream/mcp

> 标签: claude, google-meet, mcp, meeting-bot, meetstream, microsoft-teams, model-context-protocol, transcription, zoom

## 简介

Official MeetStream MCP server — give Claude and any MCP client direct access to the MeetStream meeting-bot API (create bots, fetch transcripts, interact with live meetings).
