> 标签: icons, lucid-to-sprite, lucide, nextjs, react, sprite, svg, svg-to-sprite, tabler, tree-shaking, vite, zero-runtime

## 简介

Generate a single SVG sprite containing only the icons you used (Lucide + Tabler + custom). Lucid to SVG sprite solution for React.
