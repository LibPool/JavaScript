# @hitl-kit/langgraph

> 标签: agents, ai, hitl, human-in-the-loop, langchain, langgraph

## 简介

LangGraph adapter for HITL Kit. Emit schema-conformant HITL events from LangGraph interrupt() nodes and resume with typed Command payloads.
