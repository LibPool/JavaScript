# @mostajs/web-search

> 标签: mostajs, provenance, search-api, serper, tavily, web-search

## 简介

Interroger le web par plusieurs outils (API de recherche, IA à recherche intégrée, collecte autorisée, abonnements) et rendre des résultats normalisés, datés et tracés, avec les conditions d'usage de chaque outil.
