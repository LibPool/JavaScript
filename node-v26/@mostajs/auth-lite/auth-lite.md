# @mostajs/auth-lite

> 标签: auth, authentication, lightweight, mostajs, nextjs, orm, password, sessions, webcontainer

## 简介

Password login ENGINE (framework-neutral) + node:http / Express / Next adapters + view-models. PBKDF2-SHA256 600k by default, no native addon — boots everywhere; Argon2id injectable on a server. Reads 0.x hashes and rehashes on login.
