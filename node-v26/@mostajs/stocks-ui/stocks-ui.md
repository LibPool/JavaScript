# @mostajs/stocks-ui

> 标签: facture, html, mostajs, rapprochement, stocks, ui

## 简介

Vues PURES (view-model → HTML) des stocks : file de relecture des correspondances facture ↔ matière, et tableau des références fournisseurs. Compose @mostajs/app-shell-ui. Aucune logique métier, aucun accès données — le moteur est @mostajs/stocks.
