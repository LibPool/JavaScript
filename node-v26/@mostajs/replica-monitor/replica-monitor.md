# @mostajs/replica-monitor

> 标签: cdc, cqrs, dashboard, master-slave, monitoring, mostajs, replicator

## 简介

Live web dashboard for @mostajs/replicator — reads the replicator-tree.json directly (no DB connections required). Ships with a scaffolder that emits services/monitor.mjs into any project.
