# @mostajs/notifications

> 标签: JavaScript

## 简介

Generic notification engine for @mostajs/* — domain-agnostic templating + i18n + MULTI-CHANNEL dispatch (email + SMS + …) + idempotence + throttling + preview. Consume any event kind from any source. Plug-and-play with @mostajs/mailer (email) and @mostajs
