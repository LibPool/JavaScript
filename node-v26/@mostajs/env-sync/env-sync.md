# @mostajs/env-sync

> 标签: deploy, dotenv, env, idempotent, mostajs, ssh

## 简介

Upsert idempotent de clés gérées dans un .env (local ou distant SSH) en préservant le reste — pour les déploiements. Piloté par un manifeste. Zéro-dépendance. Membre de mosta-deploy-stack.
