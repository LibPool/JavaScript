# @mostajs/workflow-admin

> 标签: admin, crud, mostajs, no-code, statemachine, transitions, workflow

## 简介

Administration de workflows (CRUD états / transitions / permissions) PERSISTÉS en ORM, chargés dynamiquement dans @mostajs/workflow (remplace les presets codés). Autosuffisant (sans @mostajs/socle). Dialecte ORM injecté (DI).
