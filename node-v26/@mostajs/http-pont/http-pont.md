# @mostajs/http-pont

> 标签: adapter, fetch, mostajs, node-http, request, response

## 简介

Le pont node:http ⇄ Fetch. Convertit un IncomingMessage en Request et rend une Response dans un ServerResponse. Zéro dépendance, zéro configuration, zéro authentification.
