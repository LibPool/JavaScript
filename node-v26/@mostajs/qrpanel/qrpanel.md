# @mostajs/qrpanel

> 标签: branded-qr, config-driven, invite, magic-link, qr, qrcode, react, themes

## 简介

QR code panel — server-side PNG/SVG generator with 12 built-in themes (image-as-frame composite, ECC=H), config-driven (.qrconfig.json), cross-OS no chromium, + React <QrPanel> client with copy/share/mailto.
