# @mostajs/enrollment-ui-react

> 标签: enrollment, mostajs, provisioning, react, ui, zero-build

## 简介

Jumeau React de @mostajs/enrollment-ui-html : onglet d'enrôlement pour une console SPA. Mêmes garde-fous (alerte de ré-enrôlement bloquante, code affiché une seule fois, aucun jeton rendu). ZÉRO-BUILD (createElement, pas de JSX).
