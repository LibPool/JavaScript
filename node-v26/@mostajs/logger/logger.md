# @mostajs/logger

> 标签: json-lines, logger, logging, mostajs, n0, primitive, structured-logs

## 简介

Primitive N0 de journalisation structurée : format canonique LogEntry (JSON-lines) + émetteur multi-driver (console/mémoire/flux). Consommé par @mostajs/audit (conformité) et @mostajs/qa-engine (QA). Statut : proposition (cas C).
