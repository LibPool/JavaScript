# @mostajs/rbac-ui-html

> 标签: JavaScript

## 简介

Vues HTML server-rendered de RBAC (utilisateurs, rôles, permissions, catégories, matrice) pour apps SANS build/React (node:http). Compose @mostajs/rbac (données) et @mostajs/palette (thème accessible).
