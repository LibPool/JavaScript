# @jupyter-kit/core

> 标签: ipynb, jupyter, jupyter-kit, lezer, markdown, notebook, renderer, sanitizer, syntax-highlighting

## 简介

Framework-agnostic Jupyter notebook renderer with built-in syntax highlighting (Lezer) and a plugin runtime.
