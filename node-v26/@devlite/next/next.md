# @devlite/next

> 标签: ai, apm, devlite, error-monitoring, error-tracking, logging, monitoring, nextjs, observability

## 简介

DevLite Next.js SDK — AI-powered observability for Next.js. Automatic request tracking, error capture, user attribution, and client-side crash reporting via a thin wrapper over @devlite/nodejs.
