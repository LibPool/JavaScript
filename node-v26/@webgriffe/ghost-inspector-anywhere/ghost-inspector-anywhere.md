# @webgriffe/ghost-inspector-anywhere

> 标签: ghostinspector, ngrok, testing

## 简介

Allows to run [Ghost Inspector](https://ghostinspector.com/) tests anywhere through an [ngrok](https://ngrok.com/) tunnel.
