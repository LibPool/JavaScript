# @onirenaud/swiftshader-vulkan

> 标签: dawn, headless, icd, software-rendering, swiftshader, vulkan, webgpu

## 简介

SwiftShader's Vulkan driver, the CPU implementation Chrome bundles, as a Vulkan ICD for Linux (x64 and arm64): point VK_DRIVER_FILES at it to run Dawn, WebGPU or any Vulkan program without a GPU and get Chrome's output. Installs everywhere; icdPath() is n
