# lovemarkdown-mcp

> 标签: converter, docx, latex, lovemarkdown, markdown, mcp, model-context-protocol, omml, word

## 简介

MCP server for LoveMarkdown — Markdown ⇄ Word (.docx) and Markdown → LaTeX. Native Word equations (OMML) are restored as LaTeX math. Companion to https://lovemarkdown.com

## 官网

- 官网：https://lovemarkdown.com
- 源码仓库：git+https://github.com/coolnico/markdown.git
- npm 页面：https://www.npmjs.com/package/lovemarkdown-mcp
