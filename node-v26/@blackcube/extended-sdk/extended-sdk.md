# @blackcube/extended-sdk

> 标签: dex, exchange, extended, perp, perpetuals, sdk, stark, starkex, starknet, trading, websocket, x10

## 简介

TypeScript SDK for the Extended exchange (ex-X10, perpetuals DEX on Starknet/StarkEx): REST v1, WebSocket, SNIP-12 Stark order signing
