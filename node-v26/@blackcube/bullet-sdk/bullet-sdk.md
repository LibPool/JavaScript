# @blackcube/bullet-sdk

> 标签: bullet, bulletxyz, dex, ed25519, exchange, perp, perpetuals, rollup, sdk, solana, sovereign, trading, websocket

## 简介

TypeScript SDK for the Bullet exchange (perpetuals DEX on a Sovereign SDK rollup, Solana/Ed25519): REST (Binance-style fapi), WebSocket, Ed25519 rollup-tx signing via the official WASM signer
