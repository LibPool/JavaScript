# @blackcube/drift-sdk

> 标签: dex, drift, exchange, perp, perpetuals, sdk, solana, trading, websocket

## 简介

TypeScript SDK for the Drift exchange (perpetuals DEX on Solana): Velocity Data API (REST + WebSocket), unified Blackcube facade, on-chain trading via @drift-labs/sdk
