# @podpriatov/ai-chat-kit

> 标签: ai, chat, headless, hooks, llm, openai, react, sse, streaming

## 简介

Headless React hooks and components for streaming LLM chat UIs. Transport-agnostic core, streaming state outside React, abort and retry built in.
