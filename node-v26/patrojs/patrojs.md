# patrojs

> 标签: ad, ad2bs, bikram-sambat, bs, bs2ad, calendar, date-converter, date-picker, date-range-picker, datepicker, nepali-calendar, nepali-date, react

## 简介

React calendar and datepicker for Gregorian (AD) and Nepali Bikram Sambat (BS) dates, with AD ↔ BS conversion
