# @moonsjs/vite

> 标签: JavaScript

## 简介

Plugin Vite + runtime server untuk framework [**Moons**](https://github.com/moonsjs/docs): transform zero-trust `*.server.ts` (§12), virtual module, dev SSR, build client+server, graceful shutdown, dan health endpoint.
