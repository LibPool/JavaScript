# @moonsjs/core

> 标签: JavaScript

## 简介

Router file-based, typegen, config, error §15, serialisasi devalue, dan runner loader/middleware untuk framework [**Moons**](https://github.com/moonsjs/docs) — full-stack TypeScript yang membuat kebocoran kode server ke client mustahil.
