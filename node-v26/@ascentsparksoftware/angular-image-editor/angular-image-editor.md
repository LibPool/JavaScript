# @ascentsparksoftware/angular-image-editor

> 标签: angular, annotation, canvas, crop, fabric, fabricjs, filters, image-editor, photo-editor, standalone

## 简介

Standalone, themeable Angular 22 image editor built on Fabric.js v7 (MIT). A free, open-source alternative to commercial image editors — crop, rotate, filters, draw, text, redact, export.
