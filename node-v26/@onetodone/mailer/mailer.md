# @onetodone/mailer

> 标签: authjs, better-auth, email, email-template, email-templates, email-verification, html-email, i18n, magic-link, mailer, nestjs, nextjs, nodemailer, otp, password-reset, resend, smtp, transactional-email, typescript

## 简介

Type-safe transactional emails for Node.js: built-in templates, branding, i18n and pluggable transports, fully customizable.
