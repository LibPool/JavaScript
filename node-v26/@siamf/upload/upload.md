# @siamf/upload

> 标签: drag, drag and drop, image, image drag and drop, images, javascript, react image upload, react images uploading, react-component, reactjs, render props, typescript, upload, uploader, uploading

## 简介

A fully headless React package for handling image and file uploads with complete UI control. It provides four flexible components—ImageUpload, MultiImageUpload, FileUpload, and MultiFileUpload.
