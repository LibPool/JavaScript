# @siamf/tooltip

> 标签: @siamf/tooltip, next-component, react-component, react-tooltip, tooltip

## 简介

A highly customizable advanced React tooltip component, offering extensive styling options to fit any design needs. It supports dynamic positioning, and custom triggers for enhanced interactivity.
