# @siamf/rating

> 标签: e-commerce rating, next rating, nextjs rating component, rating product, react rating, react rating star, react-next rating, react-rating component, simple rating component

## 简介

A React rating component that supports Next.js SSR and allows fractional step ratings for precise user input. The component is customizable, lightweight, and optimized for performance.
