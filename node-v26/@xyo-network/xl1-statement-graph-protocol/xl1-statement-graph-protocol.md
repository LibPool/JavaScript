# @xyo-network/xl1-statement-graph-protocol

> 标签: JavaScript

## 简介

Canonical protocol logic for the XYO Statement Graph — identities, atomic Claim admission, per-hash deployment filters, the normative append-only claim fold, and vocabulary-neutral view helpers. Pure and environment-neutral: no chain I/O.
