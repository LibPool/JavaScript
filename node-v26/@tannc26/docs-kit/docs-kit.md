# @tannc26/docs-kit

> 标签: ai, charts, diagrams, documentation, html, llm, markdown, mermaid, report

## 简介

One script tag turns short Markdown or plain HTML into a finished documentation page: diagrams, charts, tables, maps, maths, terminal replays and API references. Made for people and AI assistants.
