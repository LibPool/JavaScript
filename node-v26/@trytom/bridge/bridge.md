# @trytom/bridge

> 标签: JavaScript

## 简介

Tom's bridge: runs on your computer, opens an outbound connection to your Tom at trytom.ai, and answers its questions with Claude Code in print mode, restricted and read-only, confined to the folders you name. Install with: TOM_BRIDGE_TOKEN=<token> npx @t

## 官网

- 官网：https://trytom.ai
- npm 页面：https://www.npmjs.com/package/@trytom/bridge
