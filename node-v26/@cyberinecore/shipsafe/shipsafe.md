# @cyberinecore/shipsafe

> 标签: ci, crates, helm, npm, publish, pypi, release, secrets, sourcemap, supply-chain, tarball

## 简介

Zero-dependency release gate: fails an npm tarball, wheel, crate, .vsix, Helm chart or image archive that ships source maps, embedded sources, source or test paths, credential files or secret tokens.
