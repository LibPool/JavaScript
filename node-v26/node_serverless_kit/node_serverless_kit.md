# node_serverless_kit

> 标签: aws, azure, cloudflare-workers, faas, gcp, lambda, multi-cloud, on-premises, serverless, step-functions, terraform, typescript

## 简介

Write a Node.js (TypeScript or JavaScript) serverless function once and deploy it to AWS, Azure, GCP, on-premises and 7 more clouds with one YAML file, powered by Terraform.
