# @burdenoff/mcp-libs

> 标签: burdenoff, graphql, mcp, mcp-sdk, model-context-protocol, modular

## 简介

Modular MCP SDK shared across all Burdenoff product MCPs (vibecontrols, botlit, fluidgrids, bigconsole, healthybowl, workspaces). Each module exports an McpModule contract; product MCPs become thin shells that pick which modules to mount.
