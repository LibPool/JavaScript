# @mcptoolshop/comfy-preflight

> 标签: comfyui, gate, mcp, model-context-protocol, preflight, validation, workflow

## 简介

A gate that runs on a ComfyUI workflow graph in the seconds before submission and halts a submission that would spend credits producing a known-wrong result. Zero-prerequisite npx launcher — no Python needed.
