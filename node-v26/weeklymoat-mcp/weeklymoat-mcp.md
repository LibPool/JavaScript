# weeklymoat-mcp

> 标签: ai-agent, buffett, claude, finance, graham, mcp, mcp-server, model-context-protocol, stock-screener, stocks, value-investing

## 简介

MCP server for the WeeklyMoat API: weekly value-investing buy signals, watchlist and full screener (966 stocks, 6 markets, Graham & Buffett scores) for Claude and other AI agents.
