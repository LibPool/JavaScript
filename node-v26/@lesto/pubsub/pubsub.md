# @lesto/pubsub

> 标签: JavaScript

## 简介

Lesto's pub/sub + transport-neutral WebSocket fan-out core: in-process hub, fanout() send policy with backpressure, bounded replay-ring arithmetic, and signed per-channel capability tokens.
