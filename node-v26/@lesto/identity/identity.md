# @lesto/identity

> 标签: JavaScript

## 简介

Lesto's batteries-included auth: users on the SQL DB, register/verify/login/reset flows composed from @lesto/auth + @lesto/db + @lesto/migrate + @lesto/mail + @lesto/csrf.
