# @jaralabs/codex-bridge

> 标签: bridge, chatgpt, codex, coding-agent, openai-compatible, opencode, subscription

## 简介

OpenAI-compatible HTTP bridge that reuses a local ChatGPT Business / Team / Plus session via codex, so OpenCode can list and call those models without paying for the OpenAI API.
