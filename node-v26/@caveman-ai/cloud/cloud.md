# @caveman-ai/cloud

> 标签: JavaScript

## 简介

cvm, the Caveman Cloud CLI: every Cloud operation from the terminal, plus the Cloud MCP server. Sign in with `cvm login`; `cvm setup` signs in, picks the project and installs the Caveman Cloud skill.
