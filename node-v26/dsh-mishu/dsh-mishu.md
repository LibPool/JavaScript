# dsh-mishu

> 标签: deepseek-harness, dsh, dsh-plugin, email, feishu, github, inbox, lark, notifications, reminder, secretary, telegram, todo, triage

## 简介

DSH secretary (小秘书) for DeepSeek Harness (dsh): watches GitHub notifications and the dated things you tell it (bills, renewals, documents, birthdays), closes what is already resolved, and keeps a short list of what actually needs you. Bilingual (中文 / Engl
