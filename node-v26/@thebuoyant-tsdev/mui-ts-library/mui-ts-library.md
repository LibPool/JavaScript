## 简介

Type-safe React component library for MUI v9. Kanban board with drag & drop, subtask checklists, WIP limits, built-in search & column management; Gantt chart; WYSIWYG rich text editor (TipTap); SQL & JSON code editors (CodeMirror 6); D3 data visualization
