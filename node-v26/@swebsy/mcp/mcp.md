# @swebsy/mcp

> 标签: claude-code, coding-agent, mcp, modelcontextprotocol, swebsy, website-builder

## 简介

MCP server that lets a coding agent (Claude Code, Codex, Cursor, Windsurf, …) drive an open Swebsy Studio tab over a local 127.0.0.1 WebSocket relay.

## 官网

- 官网：https://docs.swebsy.com/settings/ai-coding-agent/
- 源码仓库：git+https://github.com/swebsy/MCP.git
- npm 页面：https://www.npmjs.com/package/@swebsy/mcp
