# @rapui/react

> 标签: animation, component-library, components, design-system, radix, react, shadcn, tailwind, tailwindcss, ui

## 简介

A playful React UI kit on Radix + Tailwind v4: the breadth of shadcn/ui, plus hold buttons, liquid forms, charts you scrub and galleries you throw.
