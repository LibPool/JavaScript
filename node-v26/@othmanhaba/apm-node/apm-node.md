# @othmanhaba/apm-node

> 标签: JavaScript

## 简介

Falak APM for Node.js, Bun and Deno: an OpenTelemetry preset that exports Nightwatch-style request, outgoing request, query, cache and exception telemetry to the local falak-agent.

- 源码仓库：git+https://github.com/OthmanHaba/falak.git
- npm 页面：https://www.npmjs.com/package/@othmanhaba/apm-node
