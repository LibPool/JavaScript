# @highnessatharva/groundtruth

> 标签: aeo, answer-engine, ci, citations, claude, content-gate, docs, documentation, fact-check, fact-checking, linter, markdown, prose, provenance, readability, sarif, seo, sources, technical-writing, verification

## 简介

Bind every factual claim in a document to a verbatim quote in a real source, then fail the build when the binding breaks. Provenance, readability and SEO checks for markdown.
