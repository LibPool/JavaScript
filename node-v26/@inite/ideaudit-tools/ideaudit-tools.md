# @inite/ideaudit-tools

> 标签: due-diligence, inite, mcp, model-context-protocol, modelcontextprotocol, scoring, startup

## 简介

The deterministic scoring tools behind ideaudit, as a local MCP server. No account, no network, no model calls — just the arithmetic, so you can read it and disagree with it.
