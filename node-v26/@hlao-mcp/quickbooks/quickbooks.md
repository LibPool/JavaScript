# @hlao-mcp/quickbooks

> 标签: JavaScript

## 简介

HLAO MCP server wrapping the QuickBooks Online Accounting REST API (accounts, P&L, balance sheet, vendors, customers, invoices, expenses). Write tools gated through the HLAO passport gate.
