# @hlao-mcp/shared

> 标签: JavaScript

## 简介

Shared kit for the HLAO MCP server fleet: authority header schema, AsyncLocalStorage authority context, typed ToolError ladder, safeFetch, Streamable HTTP + stdio transports, Zod-validated tool wrapper.
