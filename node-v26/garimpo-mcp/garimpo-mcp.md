# garimpo-mcp

> 标签: brasil, claude, direito, jurisprudencia, mcp, model-context-protocol

## 简介

Servidor MCP local (stdio) de pesquisa de jurisprudência brasileira via busca direta do JurisprudênciaIA, com download de inteiro teor oficial dos tribunais. Cliente não oficial.
