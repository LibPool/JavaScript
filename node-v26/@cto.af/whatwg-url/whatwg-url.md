# @cto.af/whatwg-url

> 标签: JavaScript

## 简介

This is a quick hack to replace just the external-facing parts of the [whatwg-url](https://github.com/jsdom/whatwg-url#readme) package with the modern, built-in version of URL and URLSearchParams.
