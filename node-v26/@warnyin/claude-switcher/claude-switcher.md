# @warnyin/claude-switcher

> 标签: aws, bedrock, claude, claude-code, cli, gateway, powershell, profile, switcher

## 简介

Switch Claude Code between config profiles - a personal subscription and an enterprise setup, whether Amazon Bedrock or a company API gateway - per shell, using CLAUDE_CONFIG_DIR.
