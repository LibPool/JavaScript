# @kanso-labs/kanso-ui

> 标签: component-library, design-system, design-tokens, react, react-aria, storybook, style-dictionary, stylex

## 简介

A React component library built on React Aria Components primitives and styled with StyleX, with design tokens sourced from a single W3C DTCG file and compiled via Style Dictionary
