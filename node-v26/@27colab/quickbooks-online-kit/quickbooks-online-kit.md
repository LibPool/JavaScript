# @27colab/quickbooks-online-kit

> 标签: intuit, nextjs, oauth2, qbo, quickbooks, quickbooks-online, typescript

## 简介

Dependency-free QuickBooks Online toolkit: OAuth2 with refresh-token rotation, pluggable token stores, typed REST client, audit log, and optional Next.js route handlers and React status view.
