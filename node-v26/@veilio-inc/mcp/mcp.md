# @veilio-inc/mcp

> 标签: anonymizer, llm, mcp, model-context-protocol, privacy, secret-scanning, veilio

## 简介

MCP server exposing the anonymizer to coding agents, so a model can work on masked code without the real identifiers ever entering its context.
