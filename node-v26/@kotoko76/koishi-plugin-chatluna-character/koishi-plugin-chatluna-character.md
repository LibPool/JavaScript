# @kotoko76/koishi-plugin-chatluna-character

> 标签: chatbot, chatgpt, chatluna, koishi, market, plugin, preset, service

## 简介

Enable multiple bots to use their own presets and large language models for role-playing, disguising themselves as group members. A special version designed to work with the multi-bot-controller-chatluna-charon plugin
