# @authoritydmc/trust-cert

> 标签: ca, certificate, certutil, https, local-dev, security, self-signed, ssl, tls, trust-store, update-ca-certificates

## 简介

Zero-dependency CLI to inspect, extract, and auto-install TLS/SSL certificates and root CAs into Windows, macOS, and Linux trust stores.
