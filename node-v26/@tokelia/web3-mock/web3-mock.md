# @tokelia/web3-mock

> 标签: blockchain, crypto, mock, testing, wallets, web3

## 简介

JavaScript library to mock web3 responses either by emulating web3 wallets or web3 RPC requests.

- 官网：https://github.com/tokelia/web3-mock
- 源码仓库：git+ssh://git@github.com/tokelia/web3-mock.git
