# @hummer/vue-plugin-canvas

> 标签: JavaScript

## 简介

### 简介 &lt;ex-canvast&gt;是 Tenon 中画布组件，可用于绘制一些自定义图形，如：线段、矩形、圆形、椭圆、图片、文本等，从而实现复杂图形的展示。
