# zerodep-js-svelte

> 标签: JavaScript

## 简介

Svelte 5 页面 attachment。通过公开 fromAction 接口分开实例创建、参数更新和清理，不依赖 Svelte 内部 API。Svelte 与 zerodep-js 均作为 peer。
