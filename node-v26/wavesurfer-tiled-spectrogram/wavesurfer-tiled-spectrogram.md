# wavesurfer-tiled-spectrogram

> 标签: audio, bioacoustics, sonogram, spectrogram, tiles, wavesurfer, wavesurfer-plugin, wavesurfer.js

## 简介

A wavesurfer.js plugin that shows a precomputed spectrogram from image tiles, loading only the tiles in view
