# @violetjs/kodama

> 标签: deterministic, electronic-pet, indexeddb, offline, pet, terminal, virtual-pet, wasm, webassembly

## 简介

Electronic pet SDK for the web and Node: deterministic WebAssembly rules core, typed commands, terminal and canvas rendering, and an offline local mode.
