# @assebc/ng-signal-http

> 标签: angular, fetch, http, rxjs-free, signals, zoneless

## 简介

Signal-native HTTP client for Angular. Wraps the native Fetch API and returns Angular signals directly — no toSignal(), no RxJS required.
