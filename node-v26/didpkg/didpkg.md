# didpkg

> 标签: codec, decentralized-identifier, did, didpkg, install-name, npm, package-manager

## 简介

Install-name codec for didpkg: converts a DID and a package name to an npm-valid @didpkg/ install name, and parses it back. CLI and library.

- 官网：https://didpkg.dev
- 源码仓库：git+https://github.com/bnonni/drpm.tools.git
- npm 页面：https://www.npmjs.com/package/didpkg
