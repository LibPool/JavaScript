# @uued/dsh-rella

> 标签: JavaScript

## 简介

Corellapse 会话记忆总结插件（部署级静态版）：一键把当前会话结构化总结为带 frontmatter 的 Markdown 记忆条目，写入用户配置的资料库（CLPID 全局唯一、配置持久化、增量追加、脚本词频）。
