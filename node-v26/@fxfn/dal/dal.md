# @fxfn/dal

> 标签: JavaScript

## 简介

A data access layer for [Drizzle ORM](https://orm.drizzle.team). Provides typed repositories with CRUD operations, a dialect-agnostic schema DSL, pluggable database providers, and a query-string filter engine that parses expressions into Drizzle `SQL` WHE
