# @commentkit/comment-kit

> 标签: ai agent, annotations, bug reporting, comments, feedback, mcp, review, screenshot, website feedback

## 简介

Figma-style comments for any website. Clients pin feedback with an automatic screenshot; developers see it on localhost and hand it to their AI agent.
