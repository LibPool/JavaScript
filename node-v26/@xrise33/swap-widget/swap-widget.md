# @xrise33/swap-widget

> 标签: crypto, crypto-exchange, crypto-widget, dapp, defi, dex, erc20, ethereum, iframe, metamask, referral, ripple, swap, token-swap, wallet, web3, xrise, xrp, xrpl

## 简介

Embed the XRiSE swap widget into any website or dApp to enable Web3 token swaps. A customizable DeFi DEX widget for XRPL EVM, with wallet support (MetaMask, WalletConnect) and referral rewards.
