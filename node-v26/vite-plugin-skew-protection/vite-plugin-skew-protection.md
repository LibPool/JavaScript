# vite-plugin-skew-protection

> 标签: chunk-load-error, deploy, dynamic-import, failed-to-fetch-dynamically-imported-module, skew-protection, spa, version-skew, vite, vite-plugin

## 简介

Fix "Failed to fetch dynamically imported module" after deploys. Keeps old chunks alive on any static host and recovers gracefully when they're gone.
