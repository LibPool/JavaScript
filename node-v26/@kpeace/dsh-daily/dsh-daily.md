# @kpeace/dsh-daily

> 标签: bilibili, daily, deepseek, digest, dsh, dsh-better-sidebar, dsh-plugin, harness, news, rss, youtube

## 简介

DSH 日报插件：每日主动推荐多类型新闻，可用自然语言调教推荐偏好，提供含网页 / YouTube / 哔哩哔哩视频的高价值索引，并在右侧栏以常驻网页呈现、点击即达。
