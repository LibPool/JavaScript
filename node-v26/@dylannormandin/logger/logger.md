# @dylannormandin/logger

> 标签: JavaScript

## 简介

Shared logger for frontend (browser) and backend (Node). Built on Pino, with: - Module-scoped helpers: error, warn, info, debug - Transport-agnostic sinks API to forward logs anywhere (console, HTTP, GCP, etc.)
