# @knownkind/frizzle

> 标签: ast, compiler, drizzle, filter, lexer, parser, pratt-parser, query

## 简介

A fun, type-safe query compiler with a Pratt parser, pluggable code generators, and built-in validation. Filter, sort, and query your data.
