# @llm-ports/adapter-ollama

> 标签: ai, ai-sdk, embeddings, gemma, generative-ai, llama, llama3, llm, llm-adapter, llm-ports, llm-routing, local-llm, local-to-cloud, mistral, model-management, multi-provider, offline-llm, ollama, phi, privacy, qwen, self-hosted, tool-use, typescript, vision

## 简介

Ollama native adapter for llm-ports. Local LLMs via the Ollama daemon. Implements LLMPort, EmbeddingsPort, and ModelManagement (list/pull/delete/health).
