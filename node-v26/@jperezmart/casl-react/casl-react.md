# @jperezmart/casl-react

> 标签: abilities, authorization, casl, permissions, react, tanstack-query

## 简介

The browser side of the jperezmart CASL Adapters: a React provider that builds the Client ability from a Rules endpoint, a typed Can and hooks, and a TanStack Query integration.
