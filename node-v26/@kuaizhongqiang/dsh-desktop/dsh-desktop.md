# @kuaizhongqiang/dsh-desktop

> 标签: deepseek, deepseek-harness, desktop, dsh, electron, shell, windows

## 简介

Desktop shell for DeepSeek Harness (dsh): a pure Electron shell over the shared dsh Web UI. Never spawns dsh — it connects to the server started by dsh-launcher / dsh-vscode / `dsh web` (whoever started first owns it). Windows-only.
