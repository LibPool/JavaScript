# @thg-agentic/hyper-personalisation-spec

> 标签: JavaScript

## 简介

The THG Hyper-Personalisation event specification: versioned JSON Schemas, the event registry, a validator, generated TypeScript, Kotlin, Swift and Java event models, and the OpenAPI contracts for collection settings and the public API.
