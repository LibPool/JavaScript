# @react-agendfy/fullcalendar-compat

> 标签: agendfy, calendar, fullcalendar, migration, react, scheduler

## 简介

Drop-in replacement for @fullcalendar/react on top of react-agendfy: same props, callbacks (info objects, EventApi, revert) and getApi().
