# @tellandshow/game-engine

> 标签: canvas, education, game-engine, kids, tellandshow

## 简介

Canvas game engine for Tell and Show's Game Studio. Lifecycle hooks, audio synth, particles, screen shake, mobile shell, manga visual library, optional Upstash leaderboard.
