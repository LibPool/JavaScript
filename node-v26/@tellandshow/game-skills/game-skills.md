# @tellandshow/game-skills

> 标签: claude-code, game-builder, skills, tellandshow

## 简介

Claude Code skill recipes for Tell and Show's Game Studio. Game-specific layers: bootstrap (renderer), genre, compose (cross-cutting), manga (visual library), ops (deploy + debug). Shared kid/* skills live in @tellandshow/skills-core.
