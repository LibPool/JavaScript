# @tellandshow/story-skills

> 标签: claude-code, skills, story-builder, tellandshow

## 简介

Claude Code skill recipes for Tell and Show's Story Studio. Story-specific layers: genre, scene, character, drawing, animation, video, voiceover, ops. Shared kid/* skills live in @tellandshow/skills-core (future).
