# @tellandshow/movie-builder

> 标签: JavaScript

## 简介

The visual builder UI for Tell and Show's Movie Studio. React + Vite app the kid opens via `tns builder`. Cards organized by intent (start a movie, add a scene, voice-over, music, transitions); imports the wizard engine + AI Partner panel from @tellandsho
