# @tellandshow/movie-engine

> 标签: canvas, kids, movie, renderer, tellandshow

## 简介

Canvas-composited movie engine for Tell and Show's Movie Studio. Loads a movie.json timeline and renders scenes (backgrounds + characters + dialogue + audio + VFX) frame-by-frame via requestAnimationFrame. Plain ESM, no build step, browser-ready.
