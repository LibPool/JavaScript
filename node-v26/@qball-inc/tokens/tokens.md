# @qball-inc/tokens

> 标签: css, css-custom-properties, css-variables, design-system, design-tokens, dtcg, monospace, style-dictionary, theme, tokens

## 简介

QBall Design System tokens — framework-agnostic CSS custom properties, component classes, and a DTCG/Style-Dictionary JSON mirror. Zero build step; public default display face is Fira Code (Berkeley Mono restored per README in private builds).
