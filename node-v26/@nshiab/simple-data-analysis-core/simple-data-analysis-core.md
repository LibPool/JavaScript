# @nshiab/simple-data-analysis-core

> 标签: bun, csv, data-analysis, dataframe, deno, duckdb, geospatial, nodejs, parquet, spatial-analysis, sql, tabular, typescript

## 简介

Lightweight DuckDB-powered TypeScript library for tabular, SQL, CSV, Parquet, and geospatial data analysis on Deno, Node.js, and Bun.
