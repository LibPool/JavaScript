# @visorcraft/mongreldb-kit

> 标签: database, migrations, mongreldb, orm, query-builder, schema

## 简介

Application persistence layer for MongrelDB: schema DSL, typed query builder, migrations, and relational constraints (unique, foreign keys, cascade/set-null/restrict).
