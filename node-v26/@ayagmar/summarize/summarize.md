# @ayagmar/summarize

> 标签: agent-skills, claude-code, codex, markdown, pi-package, summarization

## 简介

Fetch a URL or convert a local file (PDF, DOCX, HTML, and more) into Markdown with markitdown, optionally summarizing it.
