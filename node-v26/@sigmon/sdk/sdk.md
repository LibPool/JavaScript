# @sigmon/sdk

> 标签: analytics, errors, nextjs, observability, posthog, sentry, sigmon, signalmonitor, telemetry

## 简介

SignalMonitor JavaScript and TypeScript SDK for events, errors, breadcrumbs, traces, LLM calls, identify, Web Vitals, session replay, click maps, feedback widgets, Node CPU/memory profiling, and Next.js instrumentation.
