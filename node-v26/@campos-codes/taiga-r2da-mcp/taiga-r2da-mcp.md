# @campos-codes/taiga-r2da-mcp

> 标签: ai-agents, claude, codex, kanban, mcp, mcp-server, model-context-protocol, project-management, scrum, taiga

## 简介

MCP server for a Taiga 6 installation: lets AI models read projects, user stories, tasks, issues, sprints, wiki pages and attachments, and optionally create, edit, move and delete user stories, tasks, issues, sprints and wiki pages and attach files to ite
