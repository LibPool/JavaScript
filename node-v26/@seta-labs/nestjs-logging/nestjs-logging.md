# @seta-labs/nestjs-logging

> 标签: JavaScript

## 简介

Structured logging for NestJS APIs: pino behind the Nest Logger, one JSON line per request with request id, credential redaction, error serialization and an opt-in catch-all exception filter with a stable error body
