# @blissy-auth/oauth2

> 标签: authentication, authorization, effect, introspection, oauth, oauth2, pkce, revocation, scope, token

## 简介

TypeScript implementation of the OAuth 2.0 protocol primitives with support for authorization requests, token requests, PKCE, scopes, client authentication, token revocation, and token introspection.
