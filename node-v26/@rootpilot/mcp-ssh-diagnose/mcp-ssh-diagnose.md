# @rootpilot/mcp-ssh-diagnose

> 标签: devops, diagnostics, docker, mcp, model-context-protocol, sre, ssh, troubleshooting

## 简介

MCP server that safely collects read-only diagnostics from your servers over SSH. Bring your own LLM; the model does the reasoning.
