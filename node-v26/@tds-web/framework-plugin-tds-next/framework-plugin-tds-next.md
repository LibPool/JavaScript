# @tds-web/framework-plugin-tds-next

> 标签: JavaScript

## 简介

云开发 Tencent CloudBase Framework Next SSR Plugin 插件，将项目下的 Next 应用一键部署云开发环境，提供自动弹性伸缩的高性能 Next 服务。
