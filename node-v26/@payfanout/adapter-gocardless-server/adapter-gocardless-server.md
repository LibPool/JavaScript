# @payfanout/adapter-gocardless-server

> 标签: JavaScript

## 简介

Server-side GoCardless adapter for PayFanout (Billing Requests REST API: hosted bank authorisation flows, payments, refunds, events, webhooks). Holds secrets — never bundle client-side.
