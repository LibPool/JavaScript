# @payfanout/adapter-worldline-server

> 标签: JavaScript

## 简介

Server-side Worldline Direct adapter for PayFanout (Online Payments REST v2: Hosted Tokenization, Payments, Captures, Refunds, Webhooks). Holds secrets — never bundle client-side.
