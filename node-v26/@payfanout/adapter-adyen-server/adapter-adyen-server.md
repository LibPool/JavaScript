# @payfanout/adapter-adyen-server

> 标签: JavaScript

## 简介

Server-side Adyen adapter for PayFanout (Checkout API v72: payments, captures, cancels, refunds, standard webhooks). Push-only: outcomes arrive by webhook. Holds secrets — never bundle client-side.
