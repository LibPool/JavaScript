# @paperboycms/client

> 标签: client, cms, delivery-api, headless-cms, paperboy, sdk, typescript

## 简介

Typed client for the Paperboy headless CMS Delivery API — lists, search, media variants, render helpers, optional ETag cache. Zero dependencies, no codegen.
