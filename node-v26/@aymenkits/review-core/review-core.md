# @aymenkits/review-core

> 标签: bayesian, core, marketplace, moderation, ratings, reviews

## 简介

Subject-generic review engine: transaction-anchored eligibility (verified reviews for free), per-subject-type policy (oncePer, edit window, reply/moderation permissions), aggregate snapshots with Bayesian small-sample smoothing, replies, reports. Seams: R
