# @aymenkits/chat-socketio

> 标签: chat, messaging, realtime, socket.io, socketio, threads

## 简介

Socket.IO glue for @aymenkits/chat-core: handshake auth through an identity seam (@aymenkits/auth-core TokenService fits as-is), per-user rooms, presence tracker, RealtimeLike transport and inbound chat:send / chat:read handlers with configurable event na
