# @default-js/defaultjs-common-utils

> 标签: common, defaultjs, object helper, string escaper, utils

## 简介

Common utils for javascript. Access to the global scope (browser, web worker and node). A customizable string escaper. Utilities for objects. Extensions to the base javascript api, such as String.hashcode().
