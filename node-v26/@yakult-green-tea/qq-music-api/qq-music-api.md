# @yakult-green-tea/qq-music-api

> 标签: QQ音乐, QQ音乐koa2, 音乐

## 简介

非官方、社区维护的 QQ 音乐 API 服务，基于 Rain120/qq-music-api，支持原生扫码登录并可内嵌进 Docker 或 Electron 主进程。
