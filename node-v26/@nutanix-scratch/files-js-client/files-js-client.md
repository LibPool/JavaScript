# @nutanix-scratch/files-js-client

> 标签: Nutanix Files APIs, nutanix

## 简介

The Javascript client for Nutanix Files APIs is designed for Javascript client application developers offering them simple and flexible access to APIs that manage virtual file servers, create and configure shares for client access, protect them using DR a
