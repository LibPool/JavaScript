# @nutanix-scratch/clustermgmt-js-client

> 标签: Nutanix Cluster Management APIs, nutanix

## 简介

The Javascript client for Nutanix Cluster Management APIs is designed for Javascript client application developers offering them simple and flexible access to APIs that manage Hosts, Clusters and other Infrastructure.
