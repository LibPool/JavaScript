# @co-it/ngrx-ducks

> 标签: angular, ngrx, redux, rxjs, typescript

## 简介

This library acts as a thin layer on top of ngrx. It automatically creates action creators and reducer functions for you. Furthermore, you get a service that you can use in your components. This Service provides a strictly typed API allowing both dispatch
