# @josefransaenz/hypergate-mqtt

> 标签: JavaScript

## 简介

hypergate-mqtt is built on top of [MQTT.js](https://github.com/mqttjs/MQTT.js) and can be used to connect a hypergate instance to a MQTT broker.
