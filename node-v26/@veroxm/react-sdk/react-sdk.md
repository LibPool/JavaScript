# @veroxm/react-sdk

> 标签: a-b-testing, cms, graphql, headless-cms, nextjs, personalization, react, veroxm

## 简介

React and Next.js SDK for VeroXM: content hooks, visual slots with A/B tests, the on-page editor, llms.txt and structured data.
