# @corum/corum-rpc-client

> 标签: JavaScript

## 简介

corum 自有 RPC 的浏览器调用助手：把已退役的 corumDesktop.unary IPC 桥手搓信封收敛为官方 connection.rpc.call('/api', '<ns>/<method>', { args })。供 corum 各 client UI 包（dev 面板 / IDE 面板）共享。
