# @adjudicate/adjutant

> 标签: JavaScript

## 简介

Adjutant — subordinate operations surface that executes adjudicated remediations under supervision with zero independent authority. Turns off-path signals (audit bus, drift, LLM diagnosis) into UNTRUSTED draft envelopes that re-enter the normal adjudicate
