# @thexjs/mcp

> 标签: ai-agent, claude, cursor, mcp, model-context-protocol, thexjs, x

## 简介

MCP server that gives AI coding agents (Claude Code, Cursor, Claude Desktop, Windsurf...) grounded, accurate knowledge of the x framework's conventions, so they stop guessing Next.js/TanStack Start syntax.
