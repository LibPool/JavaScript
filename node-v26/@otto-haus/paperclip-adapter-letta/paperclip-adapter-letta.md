# @otto-haus/paperclip-adapter-letta

> 标签: ai-agents, letta, otto, paperclip, paperclip-adapter

## 简介

Run a persistent, memory-backed Letta agent (otto) from inside Paperclip. External adapter plugin for paperclipai/paperclip.
