# @rhombuskit/core

> 标签: accessibility, angular, angular-material, components, design-system, rhombuskit, signals, standalone, ui, wcag

## 简介

Themeable, accessible Angular 21 component library — standalone, signal-based components over Angular Material, styled through the RhombusKit token contract.
