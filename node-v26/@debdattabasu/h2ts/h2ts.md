# @debdattabasu/h2ts

> 标签: browser, client, grpc, hpack, http/2, http2, rfc7540, rfc7541, streaming, tunnel, websocket

## 简介

A tiny HTTP/2 client for the browser, tunneled over a WebSocket (or any byte duplex). Idiomatic TypeScript, no Node core deps.
