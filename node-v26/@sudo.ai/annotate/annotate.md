# @sudo.ai/annotate

> 标签: ai-agent, annotate, babel-plugin, code-location, developer-experience, devtools, jsx-source, vite-plugin

## 简介

开发模式下的前端批注 lib：在跑着的页面上圈选元素写修改意见，一键复制成带源码行列位置的 markdown 交给 AI agent。Annotate a running page, export file:line-anchored markdown for coding agents.
