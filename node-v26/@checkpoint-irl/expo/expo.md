# @checkpoint-irl/expo

> 标签: background-location, checkpoint, expo, expo-config-plugin, geofence, location, react-native

## 简介

Checkpoint location / geofence / ingest SDK for Expo (SDK 51+). A config plugin wiring the iOS/Android background-location config plus a thin re-export of @checkpoint-irl/react-native. The SDK is a sensor; all detection logic runs server-side.
