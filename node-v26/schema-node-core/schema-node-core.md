# schema-node-core

> 标签: declarative, function, metadata, property, property-composition, relation, schema, typescript

## 简介

TypeScript schema execution framework — mirrors C# SchemaNode.Core. Language-agnostic core for declarative schema definition via @Meta decorators, property composition, and extensible schema families.
