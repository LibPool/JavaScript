# dsh-desktop-tools-plugin

> 标签: computer-use, cursor, deepseek-harness, desktop, dsh, dsh-plugin, gui-agent, input, keyboard, mouse, screenshot, scroll, shortcut, windows

## 简介

DeepSeek Harness 桌面工具插件：注册 desktop_step / get_screen_metrics 两个工具，用 user32.dll 直接操作跑着 dsh 的那台机器的屏幕、鼠标与键盘（Windows）。desktop_step 把「截图→操作→等监视区变化→再截图」做成同一次调用，画面以图像块直接返回。
