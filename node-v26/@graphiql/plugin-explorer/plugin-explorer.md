# @graphiql/plugin-explorer

> 标签: explorer, graphiql, graphql, plugin, react

## 简介

This package provides a plugin that integrates the [`GraphiQL Explorer`](https://github.com/OneGraph/graphiql-explorer) into the GraphiQL UI.
