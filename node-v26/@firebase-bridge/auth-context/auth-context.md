# @firebase-bridge/auth-context

> 标签: AppCheckData, AuthData, CallableRequest, app check, appcheck, auth, auth context, authentication, authorization, callable, cloud functions, custom claims, emulator alternative, firebase, firebase auth, firebase-functions, functions v1, functions v2, https, id token, identity, identity platform, in-memory, jest, mock auth, mocking, onCall, onRequest, testing, unit testing, vitest

## 简介

High-fidelity test utilities for Firebase Cloud Functions auth contexts. Register mock identities (Auth + App Check) and inject them into v1/v2 https.onCall and https.onRequest handlers for deterministic unit tests—no emulator required.
