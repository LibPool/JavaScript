# @an-epiphany/websocket-json-stream

> 标签: duplex, json, realtime, socket, socket.io, socketio, sockjs, stream, typescript, websocket, ws

## 简介

A TypeScript Duplex stream wrapper for WebSocket with automatic JSON serialization. Supports ws, SockJS, and Socket.IO.
