# @redspacem/rpc

> 标签: cyberpunk-2077, multiplayer, redspacem, rpc, typesafe

## 简介

Dependency-free, type-safe RPC layer for RedSpaceM resources: RpcServer, RpcClient, TypedRpc and a JSON transport contract.
