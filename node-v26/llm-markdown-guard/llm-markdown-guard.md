# llm-markdown-guard

> 标签: ai-security, anthropic, chatbot, echoleak, exfiltration, llm, markdown, openai, prompt-injection, sanitize, streaming

## 简介

Stop LLM chat UIs leaking data through markdown images and links (the EchoLeak attack). Sanitizes model output, including token streams, before it renders. Zero dependencies.
