# @cstart/coldstart

> 标签: agent, agent-memory, ai, ai-memory, claude-code, cli, code-navigation, codebase, codebase-memory, codex, context, cursor, dependency, indexer, mcp, memory, navigation, tree-sitter

## 简介

Self-maintaining codebase memory for AI coding agents: an AST index that answers which files matter, plus agent-written notes that flag themselves stale when the code changes. No embeddings, no API key. CLI + MCP.
