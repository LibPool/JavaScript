# @shotstack/shotstack-mcp-server

> 标签: ai, claude, mcp, model-context-protocol, shotstack, video

## 简介

MCP server for Shotstack video editing API - supports both remote HTTP (Claude.ai) and local stdio (Claude Desktop, Cursor, VS Code)
