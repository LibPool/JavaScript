# @real-a11y-dev/snapshot

> 标签: a11y, accessibility, baseline, ci, diff, fingerprint, snapshot

## 简介

The Real A11y snapshot engine — deterministic finding fingerprints, the diffable a11y-snapshot.json artifact, the findings/views/unified diff, and baselines. Node-only; the single home for what the CLI and MCP both capture and compare.
