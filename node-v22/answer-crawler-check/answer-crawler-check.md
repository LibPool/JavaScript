# answer-crawler-check

> 标签: aeo, ai-crawlers, answer-engine-optimization, ci, github-action, robots.txt, seo, sitemap

## 简介

Fail CI when robots.txt blocks an AI answer crawler (OAI-SearchBot, Claude-SearchBot, PerplexityBot and more) from any page in your sitemap.
