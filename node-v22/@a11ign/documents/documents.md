# @a11ign/documents

> 标签: a11y, accessibility, pdf, wcag

## 简介

The PDF layer (ADR 0036's second layer, #68): reads a PDF's own accessibility tag tree -- tagged/untagged, the document language, alt text on figures -- with no browser, no NVDA and no fleet.
