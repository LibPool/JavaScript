# @a11ign/scorer

> 标签: a11y, accessibility, nvda, scorer, screen-reader, wcag

## 简介

The trained screen-reader accessibility scorer as an artefact: 27 KB of heads over a frozen MiniLM encoder, plus the Python program that runs them. The weights are the API.
