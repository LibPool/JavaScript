# @icekuma/bktproxy

> 标签: JavaScript

## 简介

- bucket: 数据桶, 逻辑上代表一类数据的集合, 粒度由业务层定义, 可能随业务发展变化, 业务和运维最小操作单元 - vtable: 虚拟表, 一类bucket 的集合, 数据量过大一般会根据Hash分成多个bucket
