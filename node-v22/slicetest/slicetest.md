# slicetest

> 标签: api-testing, chaos-testing, contract-testing, graphql, integration-testing, jwt, language-agnostic, mock-server, mysql, n-plus-one, oidc, openapi, postgres, slice-test, sqlite, stub, test-data-factory, testcontainers, testing, vitest, vitest-plugin, webhooks, yaml

## 简介

Framework-agnostic slice tests: drive a real app process over HTTP with a real Postgres, MySQL or SQLite and stubbed outbound APIs, checked against OpenAPI contracts.
