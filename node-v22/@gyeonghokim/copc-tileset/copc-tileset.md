# @gyeonghokim/copc-tileset

> 标签: 3d-tiles, cesium, cesiumjs, copc, las, laz, lidar, octree, point-cloud, webgl

## 简介

Stream COPC (Cloud Optimized Point Cloud) files directly into CesiumJS — no pre-tiling, no backend.
