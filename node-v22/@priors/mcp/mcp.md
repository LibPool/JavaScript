# @priors/mcp

> 标签: agents, credit, mcp, priors, robinhood-chain, usdg, x402

## 简介

MCP server for Priors on Robinhood Chain: pay x402 URLs in USDG, read balances, credit lines and scores, borrow and repay, and buy, sell and redeem PT-USDG. Key from PRIORS_KEY_FILE (a file only you can read) or PRIORS_KEY, never the command line.

- 源码仓库：git+https://github.com/priors-agents/priors.git
