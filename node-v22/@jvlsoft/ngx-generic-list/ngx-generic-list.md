# @jvlsoft/ngx-generic-list

> 标签: JavaScript

## 简介

`ngx-generic-list` This library works with Angular 16 and Bootstrap 5 to generate paginated lists of items, with support for sorting and filtering. Always verify compatibility with Node version 16.2.16.
