# @idesify/client-core

> 标签: biometrics, blazeface, identity, idesify, kyc, liveness, wasm

## 简介

On-device biometric framing and end-to-end encryption engine for the Idesify SDKs. WebAssembly, self-contained, no bundler configuration required.
