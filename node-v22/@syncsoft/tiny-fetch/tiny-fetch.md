# @syncsoft/tiny-fetch

> 标签: ajax, axios, axios-alternative, browser, fetch, http, http-client, interceptors, nodejs, rest, tiny, typescript, xhr, zero-dependency

## 简介

Tiny, zero-dependency, axios-compatible HTTP client built on fetch. ~6KB, full TypeScript, interceptors, timeouts, progress uploads.
