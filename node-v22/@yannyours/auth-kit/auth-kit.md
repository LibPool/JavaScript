# @yannyours/auth-kit

> 标签: auth, authentication, authorization, express, jwt, login, oauth, oauth2, pkce

## 简介

Module d'authentification Node.js autonome — email/mot de passe + OAuth2 (Google, GitHub, générique) avec PKCE, JWT access/refresh avec rotation, adaptateur de stockage enfichable.
