> 标签: accessibility, ai-agent, ai-testing, automation, browser-testing, cdp, chrome-devtools-protocol, claude, cli, developer-tools, llm, testing, typescript, web-testing

## 简介

Lightning-fast web testing CLI for AI agents. Connect to Chrome via CDP, see the screen with one command, interact with simple tap/type/assert commands.
