# @retensy/mcp

> 标签: articles, automation, blog, bot, claude-code, funnel, instagram, markdown, max, mcp, model-context-protocol, retensy, telegram

## 简介

MCP server to build and publish Telegram, MAX and Instagram bot funnels/automations — and publish Markdown blog articles — in the Retensy Bots service. Zero dependencies.
