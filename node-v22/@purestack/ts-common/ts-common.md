# @purestack/ts-common

> 标签: JavaScript

## 简介

Shared TypeScript contracts for PureStack's site generator, components, and page scripts. This package defines site configuration, page frontmatter, navigation, logos, templates, and the rendering context so those packages agree on the same shapes.
