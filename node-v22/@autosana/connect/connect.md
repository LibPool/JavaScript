# @autosana/connect

> 标签: autosana, cli, mcp, model-context-protocol, wizard

## 简介

One-command setup for the Autosana MCP server — opens a browser for sign-in, then installs the server into Claude Code, Claude Desktop, Cursor, Gemini CLI, Codex, or OpenClaw.
