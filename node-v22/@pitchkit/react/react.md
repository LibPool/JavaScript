# @pitchkit/react

> 标签: analytics, charting, charts, data-visualization, dataviz, football, football-pitch, heatmap, mplsoccer, nextjs, pass-network, pitch, react, shot-map, soccer, soccer-analytics, statsbomb, typescript, visualisation, visualization

## 简介

React football (soccer) visualisation library — declarative <Pitch> + layer components for shot maps, pass networks and heatmaps. TypeScript, responsive by default, Next.js ready.
