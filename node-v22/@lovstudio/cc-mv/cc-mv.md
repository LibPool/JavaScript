# @lovstudio/cc-mv

> 标签: claude-code, cli, lovstudio, migration, move, mv, rename, session

## 简介

Move a project folder AND migrate its Claude Code session history in one shot. Rewrites ~/.claude/projects/<slug>/*.jsonl, history.jsonl, and running-session records so `claude --resume` still works after the move.
