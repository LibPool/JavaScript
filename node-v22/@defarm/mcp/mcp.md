# @defarm/mcp

> 标签: defarm, hpke, mcp, model-context-protocol, sealed-field, traceability

## 简介

DeFarm MCP server — seal, open, verify and ingest verifiable agri-traceability data from an AI agent. The DeFarm server stays cryptographically blind to sealed fields; private keys never leave the local keystore; credentials never flow through the model.
