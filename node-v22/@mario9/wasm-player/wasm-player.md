# @mario9/wasm-player

> 标签: canvas, h264, h265, hevc, media-player, mediabunny, video-player, vue-component, vue3, webcodecs

## 简介

基于 Vue 3 + mediabunny 的媒体播放器，支持 H.264、H.265/HEVC 视频和 MP3 音频
