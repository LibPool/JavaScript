# @tastic/hud

> 标签: color-picker, couch-multiplayer, dialog, dropdown, expo, hud, local-multiplayer, popover, press-away, react-native

## 简介

Visual component kit for local-multiplayer React Native games: inline (non-modal) popovers, dropdowns, color pickers, gauges, ready buttons, and dialogs, built to stay scoped to one player's own zone on a shared screen
