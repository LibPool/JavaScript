# @twinsunllc/minifac

> 标签: agent, ai, claude, cli, factory, graph, openspec, spec-driven-development, workflow

## 简介

A miniature factory: directed (possibly cyclic) YAML graphs of agent + tool nodes, executed by a small TypeScript runner.
