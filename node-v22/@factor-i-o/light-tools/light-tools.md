> 标签: ai-agents, coding-agents, context-engineering, developer-tools, file-tools, mcp, mcp-server, model-context-protocol, shell-tools, token-efficiency, tree-sitter

## 简介

MCP file and shell tools for coding agents: bounded multi-file reads, span edits, deduplication, searchable command output, SSH/SCP, and service-log inspection.
