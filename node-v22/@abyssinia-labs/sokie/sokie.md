# @abyssinia-labs/sokie

> 标签: ai-agents, api, cli, mcp, mcp-server, model-context-protocol, openapi, sokie, swagger

## 简介

Turn an OpenAPI or Swagger spec into an MCP server, run it on your machine, and deploy it to Sokie. The sokie command (alias sok).
