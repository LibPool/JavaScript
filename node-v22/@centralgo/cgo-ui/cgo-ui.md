# @centralgo/cgo-ui

> 标签: dark-mode, design-system, frontend, lit, react, responsive-design, theming, ui-components, web-components

## 简介

Lightweight Lit-based Web Components design system with light/dark themes, responsive UI, custom theming, and an optional React adapter.
