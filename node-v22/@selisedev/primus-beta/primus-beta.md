# @selisedev/primus-beta

> 标签: angular, angular-components, component-library, design-system, primeng, primeng-fork, primus, shadcn, tailwind, ui

## 简介

Angular UI component library (beta). shadcn-style, source-first fork of PrimeNG 21.1.9 (MIT) on Angular 22, with the PrimeUIX theming engine vendored in-tree. Beta channel for @selisedev/primus.
