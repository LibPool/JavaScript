# @nativescript-community/sqlite-default-engine

> 标签: Android, NativeScript, SQLite, iOS

## 简介

The default SQLite for @nativescript-community/sqlite-core: androidx sqlite-bundled on Android (WAL by default), the SQLite of the process on iOS.
