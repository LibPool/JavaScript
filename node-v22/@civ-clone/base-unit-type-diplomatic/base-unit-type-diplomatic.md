# @civ-clone/base-unit-type-diplomatic

> 标签: civilization, typescript

## 简介

A `Unit` type for non-military units such as Diplomats and Caravans. It extends `Fortifiable`, so they can still fortify, and rules can exclude them from unit support, military unhappiness, zones of control, attacks and city capture.
