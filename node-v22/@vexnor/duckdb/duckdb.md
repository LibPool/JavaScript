# @vexnor/duckdb

> 标签: @vexnor/duckdb, ai, analytics, duckdb, mcp, olap, plugin, sql, vexnor, vexnor-plugin

## 简介

DuckDB plugin for Vexnor — the typesafe, AI-native SQL framework. Schema introspection, typed execution, and the MCP agent surface for DuckDB via the official Node.js client.
