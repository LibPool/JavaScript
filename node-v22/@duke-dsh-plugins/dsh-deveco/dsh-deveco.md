# @duke-dsh-plugins/dsh-deveco

> 标签: arkts, arkui, deepseek-harness, deveco, dsh, harmonyos, hilog, plugin

## 简介

DSH 正式 bundle 插件：在官方右侧边栏（sidebarRightTabs）注册「HiLog 检查器」与「ArkUI Inspector」两个独立页面 Tab（HiLog 实时流 + 过滤；ArkUI UI 树 dump / 截图 / tap / swipe / text），并提供 .ets 文件查看器（ArkTS 语法高亮，内容经官方 remote.workspaceFiles 分页读取）；路径配置为设置根区的「HarmonyOS Suite」页面（settings.section；DevEco
