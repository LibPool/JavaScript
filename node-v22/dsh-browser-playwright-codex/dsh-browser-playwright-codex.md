# dsh-browser-playwright-codex

> 标签: agent, ai-agent, automation, browser, browser-automation, deepseek, deepseek-harness, dsh, dsh-plugin, form-filling, playwright, rpa, settings, web-automation, web-scraping

## 简介

Browser automation for DeepSeek Harness, one plugin: fill in forms, scrape lists and work across tabs in real pages, using the logins you already have. Runs in a visible window that stays quiet when minimised; native dialogs are parked instead of confirme
