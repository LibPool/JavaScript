# @joetjen/cooper-nestjs

> 标签: casc, config, configuration, cooper, nest, nestjs

## 简介

Under heavy development: not for production use before 1.0.0. A NestJS module that loads an application's CASC configuration once, at startup, with cooper-config, and feeds it to @nestjs/config's ConfigService -- each top-level block injectable on its own
