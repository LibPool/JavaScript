# @cocharts/util-library

> 标签: JavaScript

## 简介

Pure, framework-agnostic utilities: dates, formatting, collections, validation helpers, async helpers. Zero runtime dependencies; React-specific hooks live in a separate entry so non-React consumers never pull React.
