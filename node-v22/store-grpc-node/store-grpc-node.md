# store-grpc-node

> 标签: crud, gql, grpc, nodejs-store, protobuf

## 简介

gRPC adapter that auto-generates a .proto service per schema for nodejs-store (schema-driven CRUD over GQL, proto-first with runtime serialization, zero protoc)
