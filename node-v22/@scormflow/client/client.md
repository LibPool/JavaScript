# @scormflow/client

> 标签: cmi5, elearning, lms, react, scorm, scorm-1-2, scorm-2004, scorm-player, xapi

## 简介

Umbrella package for ScormFlow: SDK, player, React bindings, and types in a single install. Drop-in SCORM, xAPI, and cmi5 for any app.
