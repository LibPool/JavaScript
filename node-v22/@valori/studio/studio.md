# @valori/studio

> 标签: shared-ui, valori, vector-database

## 简介

Shared Valori product UI — the normal customer-facing feature set (projects, collections, search, metrics, cluster, graph, operations, proof, snapshots, tools, playground), usable by Desktop Local, Desktop Cloud, and Cloud Web. Contains no Tauri, Supabase
