# @rollfuse/evaluation-core

> 标签: JavaScript

## 简介

Dependency-free, browser-and-Node-safe deterministic flag evaluation and bucketing, shared by @rollfuse/sdk-js and @rollfuse/sdk-browser so they can never silently drift.
