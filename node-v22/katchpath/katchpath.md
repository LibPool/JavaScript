# katchpath

> 标签: api-keys, cli, devsecops, dotenv, env, git, git-hooks, gitignore, pre-commit, secret-scanning, secrets, security

## 简介

Tiny git guard: blocks .env files, private keys, key-shaped strings and node_modules before git add / git commit. One POSIX shell file, no dependencies.
