# @browsonic/build-tools

> 标签: browser-error-tracking, browsonic, browsonic-build-tools, esbuild-plugin, javascript-error-monitoring, rollup-plugin, sourcemap, sourcemap-upload, vite-plugin, webpack-plugin

## 简介

Bundler plugins (Vite / Webpack / Rollup / esbuild) for uploading source maps to Browsonic. Apache-2.0.
