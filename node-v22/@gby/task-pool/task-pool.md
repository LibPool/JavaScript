# @gby/task-pool

> 标签: task concurrency, task manager, task pool, task queue, 任务并发, 任务池, 任务管理, 任务队列

## 简介

task-pool 提供了任务池的功能，可控制任务的并发；即便于独立使用，又便于管理已有的任务业务
