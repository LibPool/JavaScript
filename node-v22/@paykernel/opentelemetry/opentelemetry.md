# @paykernel/opentelemetry

> 标签: metrics, observability, opentelemetry, paykernel, payments, telemetry, tracing, typescript

## 简介

Portable payment metrics, span instrumentation, and optional OpenTelemetry bridge for @paykernel/core (no hard OTEL dep in core).
