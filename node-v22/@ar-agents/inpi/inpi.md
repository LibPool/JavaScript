# @ar-agents/inpi

> 标签: agent, ai-sdk, ar-agents, argentina, inpi, marca, propiedad-industrial, trademark, vercel-ai

## 简介

INPI (Instituto Nacional de la Propiedad Industrial) agent toolkit for the Vercel AI SDK 6. Search trademarks by denomination, check registration status, look up the Nice classification class. Adapter pattern against INPI's public search portal.
