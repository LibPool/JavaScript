# @ar-agents/whatsapp

> 标签: agent, agentic, ai-sdk, argentina, messaging, meta, vercel-ai, waba, whatsapp, whatsapp-business

## 简介

WhatsApp Business Cloud API as drop-in tools for the Vercel AI SDK. Send text/template/media messages, parse incoming webhooks, mark as read. AR-friendly defaults but works for any WABA.
