# @ar-agents/shipping

> 标签: agent, agentic, ai-sdk, andreani, argentina, correo-argentino, envios, oca, shipping, vercel-ai

## 简介

Argentine shipping carriers (Andreani, OCA, Correo Argentino) as drop-in tools for the Vercel AI SDK. Cotizar, crear, trackear, cancelar envíos. Pluggable adapters: ships an UnconfiguredAdapter and a MockAdapter for dev; AndreaniAdapter wired to the real
