# @ecubelabs/elasticsearch-mcp

> 标签: JavaScript

## 简介

Elasticsearch **직접 조회** MCP. ECK 클러스터의 ES HTTP 서비스로 `kubectl port-forward`를 **MCP가 스스로 열어** 붙는다. Kibana를 거치지 않고 ES REST를 직접 호출하므로 `_search` 외에 `_mapping`·`_resolve/index`·`_settings`·`_alias` 같은 비검색 API까지 쓸 수 있는 게 존재 이유다.
