# @pay-skill/mcp

> 标签: JavaScript

## 简介

MCP server for Pay. x402 payment stack for AI agents -- direct payments, metered tabs, HTTP 402 paywalls. USDC on Base. Works with Claude Desktop, Cursor, VS Code.
