# @fragmentslab/mcp

> 标签: 3d, agent, ai, fragments, mcp, model-context-protocol, three.js

## 简介

Connect AI agents (Claude Code, Codex, Cursor and other MCP clients) to Fragments Studio, so they can build, animate and render in your open Fragments tab.
