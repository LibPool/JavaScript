# @h2loop/oscilloscope

> 标签: JavaScript

## 简介

Hydron plugin: drive any SCPI oscilloscope over LAN (Tektronix/Keysight/Rigol/generic) — discover, configure, measure, capture waveforms and screenshots.

## 官网

- 官网：https://www.hydron.sh/
- 源码仓库：git+https://github.com/h2loop/hydron-plugin-oscilloscope.git
- npm 页面：https://www.npmjs.com/package/@h2loop/oscilloscope
