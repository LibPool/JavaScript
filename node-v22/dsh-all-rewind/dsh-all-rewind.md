# dsh-all-rewind

> 标签: ai-ide, checkpoint, deepseek-harness, dsh, dsh-plugin, rewind, rollback, snapshot

## 简介

Conversation-turn rewind for DeepSeek Harness: per-session hidden snapshot repository (before-chat-turn / toolcall anchors), content-addressed directory trees, rewind buttons under each user prompt, configurable snapshot storage and automatic maintenance.
