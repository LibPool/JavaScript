# @bossforce.ai/mcp-mongodb

> 标签: JavaScript

## 简介

MCP server for **MongoDB**, built on the official [`mongodb`](https://www.mongodb.com/docs/drivers/node/current/) Node.js driver. **Read-only by design** — a good fit for reporting and data lookups.
