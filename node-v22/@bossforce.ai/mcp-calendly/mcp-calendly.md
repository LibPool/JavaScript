# @bossforce.ai/mcp-calendly

> 标签: JavaScript

## 简介

MCP server for the **Calendly v2** API (`https://api.calendly.com`), authenticated with a personal access token (`Authorization: Bearer <token>`). Read-only: identify the current user, list event types and their scheduling links, and list or fetch schedul
