# cartesia-mcp

> 标签: ai, cartesia, mcp, tts, voices

## 简介

Query the Cartesia API (free tier key; set CARTESIA_API_KEY, Bearer): voice list, localized voices, and speech synthesis (paid usage — synthesizing spends credits).
