# @geoalgeria/telecom

> 标签: 5g, 5g-coverage, algeria, couverture-5g, coverage, djezzy, dz, geoalgeria, geojson, mobile-network, mobilis, ooredoo, telecom

## 简介

Algeria mobile-network coverage as data: 3,598 5G coverage records from operator maps (Djezzy, Mobilis, Ooredoo), with 3,580 publishable coordinates. JSON, CSV, GeoJSON, TypeScript.
