# insigne-slider

> 标签: carousel, gallery, hero, image slider, responsive slider, revolution slider, slider, slider revolution alternative, swiper, swiper alternative, typescript, web component, web components, webgl

## 简介

Lightweight, zero-config responsive slider with layer animations, WebGL transitions and crop-free images. Use it as a web component, with data-* attributes or from JS/JSON.
