# @domphy/core

> 标签: core, domphy, framework, no-jsx, no-vdom, reactivity, ssr, ui, vanilla

## 简介

Domphy core runtime — patch-based, framework-agnostic UI with plain-object element trees, listener-based reactivity, and SSR + hydration (no JSX, no virtual DOM)
