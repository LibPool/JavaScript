# @shynome/stdf

> 标签: JavaScript

## 简介

该项目只是单纯的将 [stdf](https://github.com/any-tdf/stdf/tree/main/packages/stdf) 转换为 `SvelteKit Library` 项目, 以便使用 `Yes, using TypeScript syntax` 创建的项目可以使用
