# @btravstack/keys

> 标签: crypto-shredding, dependency-injection, envelope-encryption, hkdf, kms, typescript, unthrown

## 简介

An EnvelopeKeys port for @btravstack/core: per-owner root keys wrapped by an AWS KMS key of that owner, unwrapped in memory and cached for a TTL, erased with one key deletion, and an HKDF helper giving each purpose its own key
