# @zopay/js

> 标签: checkout, crypto, payments, usdt, widget, zopay

## 简介

Browser SDK for ZoPay. Renders the payment widget (QR + currency/network selector + polling) for a payment intent created by the merchant's backend. Keyless by design.

- 官网：https://docs.zopay.cash
