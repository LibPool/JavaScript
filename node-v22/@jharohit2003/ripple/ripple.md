# @jharohit2003/ripple

> 标签: proxy, react, reactive, redo, state, state-management, store, time-travel, undo, zustand-alternative

## 简介

Tiny mutation-based state manager with fine-grained path subscriptions and built-in time travel. Framework-agnostic core, React adapter included.
