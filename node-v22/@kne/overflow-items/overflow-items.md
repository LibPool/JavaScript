# @kne/overflow-items

> 标签: component, debounce, headless, hooks, i18n, layout, more, overflow, overflow-items, react, resize, responsive, toolbar, visible-count

## 简介

测量剩余宽度并自动决定露出若干 item 的 React 溢出收起库，提供组件、Hook 与纯函数，支持更多插槽与防抖。
