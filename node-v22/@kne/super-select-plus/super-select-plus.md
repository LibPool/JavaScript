> 标签: address-select, antd, cascade, cascader, city-select, enum, function-select, i18n, industry-select, multiselect, picker, pinyin, react, select, super-select

## 简介

基于 super-select 的 React 业务选择器组件库，提供职能、行业、城市选择器与枚举显示组件，支持国际化与拼音搜索
