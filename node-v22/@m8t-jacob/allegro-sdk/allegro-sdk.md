# @m8t-jacob/allegro-sdk

> 标签: allegro, allegro-api, ecommerce, marketplace, oauth2, offers, orders, poland

## 简介

Typed TypeScript/Node client for the Allegro REST API: OAuth2 (client credentials, authorization code, auto-refresh), categories, offers, orders, and account basics.
