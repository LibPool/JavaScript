# @m8t-jacob/mcp-guard

> 标签: claude, devsecops, linter, mcp, model-context-protocol, prompt-injection, sarif, sast, security, tool-poisoning

## 简介

Static security scanner/linter for MCP (Model Context Protocol) servers: detects tool poisoning, prompt-injection surfaces, hardcoded secrets, command injection, and excessive permissions in server source code and tool manifests. CLI + GitHub Action, SARI
