> 标签: abuse, api-client, disposable-email, duplicate-accounts, email-validation, fraud, fraud-detection, fraud-scoring, kaidn, multi-accounting, risk, sdk

## 简介

Official Node/TypeScript server-side client for the Kaidn fraud-scoring API — score, checks, batch, lists, labels, analytics and config.
