# @pg-prime/context

> 标签: async-local-storage, context, pg-prime, postgres, postgresql, rls, transactions

## 简介

Ambient transactions for pg-prime on AsyncLocalStorage: a TransactionHost with propagation and scoped settings. Pre-alpha — the API will change.
