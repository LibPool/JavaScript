# @tidy-ui/stack

> 标签: components, css-in-js, react, react-ui, stack, styled-components, ui, ui-components

## 简介

Stack, as the name says, can be used to stack any react component, plain html element or even just text nodes in an orderly fashion. Provide a divider component that separate each node with in the stack. It is provided with various styling options like al
