# @deniscodp/claude-profile-manager

> 标签: account-switcher, anthropic, claude, claude-cli, cli, dotfiles, nvm, profile, profile-manager, symlink

## 简介

Switch instantly between multiple Claude CLI accounts/profiles (personal, work, ...) by isolating CLAUDE_CONFIG_DIR per profile - like nvm, but for your Claude configuration.
