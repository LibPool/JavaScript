# @formtrieb/tokens-cli

> 标签: css-variables, design-system, design-tokens, tokens-studio

## 简介

Tokens-Studio JSON → CSS variables, utility classes, SCSS mixins and a Figma↔CSS lookup map, driven by a project-local config. The command line around @formtrieb/tokens-render.
