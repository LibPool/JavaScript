# @reventlessdev/reventless-graph

> 标签: JavaScript

## 简介

Graph view mode (GraphView, GraphMode, GraphData) for Reventless AutoUI, built on @reventlessdev/rescript-cytoscape. Optional add-on: apps without relationship graphs never load it.
