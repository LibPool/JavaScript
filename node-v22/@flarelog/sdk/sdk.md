# @flarelog/sdk

> 标签: ai, anthropic, cloudflare-workers, edge, genai, llm, llm-observability, logging, logs, observability, openai, opentelemetry, serverless, token-usage, vercel

## 简介

Zero-dependency observability SDK with AI inference observability. Ships logs, errors, W3C traces, and AI/LLM cost & token tracking from Cloudflare Workers, Vercel, Node.js, or the browser to FlareLog or any OTLP backend.
