# @hexvero/mcp

> 标签: asar, diff, electron, hexvero, ipc, mcp, mcp-server, reverse-engineering, static-analysis

## 简介

MCP server for hexvero: lets a coding agent diff two Electron releases and inspect app.asar, IPC, contextBridge and binaries, with file and line, without running them.
