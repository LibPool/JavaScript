# @natzar/client

> 标签: api-client, health, natzar, telehealth, webhooks

## 简介

Official TypeScript client for the Natzar Partner API — AI health-assistant chat, async physician consults, live video consults, a browser-side patient surface and physician workspace, and webhook signature verification.
