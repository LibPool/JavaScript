# @mtpc/core

> 标签: JavaScript

## 简介

**MTPC (Multi-Tenant Permission Core)** 是一个业务无关、可嵌入、可组合的多租户权限内核。它不是一个可直接部署的系统，而是作为依赖被真实业务系统（SaaS、内部后台、B端系统等）引入。
