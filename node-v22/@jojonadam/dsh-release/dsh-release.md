# @jojonadam/dsh-release

> 标签: automation, deepseek-harness, dsh-plugin, npm, publish, release

## 简介

One-command release pipeline for DSH plugins: preflight checks, version bump, test, commit, SSH push, npm publish, registry verification, desktop install and hub submission. 发布流水线 · 凭据走钥匙串 · 默认只读。
