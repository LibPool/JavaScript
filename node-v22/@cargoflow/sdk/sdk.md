# @cargoflow/sdk

> 标签: cargoflow, cold-chain, sdk, trade-finance, viem

## 简介

TypeScript SDK for CargoFlow: typed API client, contract ABIs and unsigned transaction builders, gateway signing, logger CSV parsing, evidence aggregates and Merkle verification.
