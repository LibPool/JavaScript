> 标签: ai-agent, ai-translation, claude, claude-code, claude-desktop, codex, cursor, document-translation, docx, epub, equalang, i18n, image-translation, localization, mcp, mcp-server, model-context-protocol, pdf-translation, pdf-translator, pptx, speech-to-text, srt, subtitle-translation, transcription, translate, translation, video-translation, windsurf, xlsx

## 简介

MCP server for Equalang: translate documents, slides, spreadsheets, e-books, subtitles, pictures, audio and video with their layout kept, transcribe recordings, and translate text.
