# @open-kingdom/shared-backend-feature-youtube

> 标签: JavaScript

## 简介

This library contains the backend feature module for YouTube Twin mock operations, exposing search functionality and managing error simulations. It integrates the `@open-kingdom/shared-backend-integration-test-doubles` YouTube twin.
