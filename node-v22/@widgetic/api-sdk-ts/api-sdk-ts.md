# @widgetic/api-sdk-ts

> 标签: api, fetch, partner, sdk, typescript, widgetic

## 简介

TypeScript and JavaScript client for the public Widgetic API: the calls a Widgetic customer or partner can make with an API key (ESM and CommonJS).

## 官网

- 官网：https://docs.widgetic.com
- npm 页面：https://www.npmjs.com/package/@widgetic/api-sdk-ts
