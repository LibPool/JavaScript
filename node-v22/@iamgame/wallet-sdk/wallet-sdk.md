# @iamgame/wallet-sdk

> 标签: embedded-wallet, iamgame, react, siws, solana, telegram, wallet, web3

## 简介

IAMGame Wallet browser SDK — Telegram & Solana wallet auth, balances, server-side signing, and key export. Drop-in React provider for game frontends.
