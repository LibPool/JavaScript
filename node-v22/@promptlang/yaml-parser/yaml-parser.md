# @promptlang/yaml-parser

> 标签: parser, promptlang, typescript, yaml, zero-dependencies

## 简介

Zero-dependency minimal YAML parser — the subset used by PromptLang and Praxis. Rejects anchors, block scalars, tags, and flow-style with line-aware errors.
