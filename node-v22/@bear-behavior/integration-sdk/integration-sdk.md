# @bear-behavior/integration-sdk

> 标签: JavaScript

## 简介

The SDK for building a Bear integration. It provides the wiring so an integration developer never has to implement HMAC verification, event dispatch, or key rotation by hand — the surface you touch is config and handlers only.
