# @arxo/law-client

> 标签: computational-law, law, legal-tech, mcp, model-context-protocol, registry, rules-as-code

## 简介

Typed client for the Arxo Law services: the MCP server (its full tool table over Streamable HTTP) and the public package registry / atlas. Transport and shape validation only — no legal semantics, no engine.
