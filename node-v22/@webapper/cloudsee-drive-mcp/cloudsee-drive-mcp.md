# @webapper/cloudsee-drive-mcp

> 标签: ai, claude, cloudsee, cloudsee-drive, file-management, mcp, model-context-protocol, s3

## 简介

Open-source MCP server for CloudSee Drive — connect your CloudSee account (Amazon S3) to Claude Desktop and any MCP client with an API key.
