> 标签: api, api-client, auth, axios-alternative, bonhomie, browser, fetch, fetch-wrapper, http, interceptors, jwt, node, react, rest, retry, timeout, token-refresh

## 简介

Smart fetch wrapper for React and Node: auth token injection, token refresh on 401, retry with backoff, timeout, interceptors, and consistent errors.
