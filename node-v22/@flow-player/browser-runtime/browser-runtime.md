# @flow-player/browser-runtime

> 标签: esm, flow-player, flv, h264, h265, hevc, wasm, webcodecs, webgl2

## 简介

Rust/WASM-powered browser video player runtime with FLV/HLS/MP4 demux, WebCodecs decode, WebGL2 render, and HEVC software decode fallback.
