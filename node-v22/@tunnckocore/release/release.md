# @tunnckocore/release

> 标签: JavaScript

## 简介

Release and publish a new project to NPM and GitHub, automatically. Following Conventional Commits specification and Semver. It provides GitHub App, similar to [semantic-release][], too.

## 官网

- 官网：https://github.com/tunnckoCore/release
- 源码仓库：git+https://github.com/tunnckoCore/release.git
- npm 页面：https://www.npmjs.com/package/@tunnckocore/release
