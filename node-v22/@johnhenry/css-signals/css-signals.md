# @johnhenry/css-signals

> 标签: @property, css, css-variables, custom-properties, houdini, scroll-driven-animations, signals

## 简介

Publish live browser state (pointer, scroll, viewport, ...) as typed CSS custom properties under a runtime-configurable prefix. Native CSS where the browser can do it, batched JS where it can't.
