# @johnhenry/html-modules

> 标签: compiler, custom-elements, declarative, esm, html-import, html-modules, shadow-dom, templates, web-components

## 简介

Declarative HTML modules: export components from ordinary HTML, import them with <html-import src as>, and optionally compile them to ES modules.
