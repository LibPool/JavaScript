# @johnhenry/domkit

> 标签: accessibility, custom-elements, dom, forms, html, no-build, web-components

## 简介

Small, independent custom elements and DOM utilities -- drop-in UI widgets, media-query-driven containers, persisted UI state, declarative loaders -- shipped as source, no build step.
