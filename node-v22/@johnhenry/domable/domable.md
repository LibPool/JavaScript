# @johnhenry/domable

> 标签: createElement, custom-elements, dom, html, hyperscript, jsx, react, shadow-dom, web-components

## 简介

Convert between HTML text, real DOM nodes, and React-element-shaped objects; build DOM directly with a createElement()-style hyperscript API; turn HTML strings (or DOM nodes) into Custom Element classes.
