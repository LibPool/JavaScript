# @johnhenry/mport

> 标签: cdn, dynamic-import, esm, esm.sh, fallback, import, import-map, importmap, jsdelivr, jspm, jsr, npm, race, router, unpkg

## 简介

Route JavaScript imports across any number of CDNs: deterministic resolution, adaptive transport (fallback, race, weighted, health-aware), compiled to standard import maps.
