# @geoql/mdr

> 标签: agent, autonomous, claude-code, journal, local, memory, opencode, plugin, semantic-search

## 简介

Persistent layered memory for coding agents (OpenCode, Claude Code) — journal, entities, state files, semantic search, daemon, scheduled reminders. A hard fork of ascorbic/macrodata by Matt Kane.
