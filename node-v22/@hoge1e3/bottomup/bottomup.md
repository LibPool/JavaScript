# @hoge1e3/bottomup

> 标签: bottom-up, directory, filesystem, iterator, nodejs, recursive, sfile, traversal, utility

## 简介

A bottom-up directory traversal utility that iterates files in order of recent updates. Compatible with @hoge1e3/sfile.
