# @nigelnguyen/2fcompresspdf

> 标签: cli, compress, dpi, pdf, pdf-lib, pdfjs

## 简介

Pure JS PDF compressor CLI using PDF.js, @napi-rs/canvas, and pdf-lib. No Ghostscript required.
