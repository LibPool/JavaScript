# @puppedo/core

> 标签: automatization, chrome, e2e, electron, end-to-end, playwright, puppedo, puppeteer, testing, tests, yaml programming

## 简介

PuppeDo is a runner for tests E2E in YAML style. With power of Playwright or Puppeteer.
