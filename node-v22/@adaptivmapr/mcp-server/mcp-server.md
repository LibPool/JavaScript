# @adaptivmapr/mcp-server

> 标签: adaptivmapr, csv-import, data-mapping, fhir, healthcare, mcp, model-context-protocol, schema-mapping

## 简介

Schema-mapping MCP server for AdaptivMapr: map any CSV/Excel/JSON to your schema — schema-only without a key, full-data with one (FHIR-ready for healthcare).
