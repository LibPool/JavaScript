# @formandcraft/kumihan

> 标签: Jisage, Kumihah, Tategaki, Yakumono, kerning, letterSpacing, typeSetting

## 简介

kumihanjsは、役物、禁則、ぶら下げ、ベタ組、カーニング等を一括で調整し、DTPのような繊細な文字組みをWebで簡単に実現するライブラリです。
