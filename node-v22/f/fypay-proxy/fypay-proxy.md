# fypay-proxy

> 标签: agent, agentpay, ai, fypay, monetization, payment, proxy, reverse-proxy, sidecar

## 简介

Zero-code payment proxy sidecar for AgentPay protocol. Merchants run one command to monetize any HTTP API.
