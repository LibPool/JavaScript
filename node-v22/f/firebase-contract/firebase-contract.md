# firebase-contract

> 标签: codegen, contract, data-connect, firebase, firestore, schema, typescript, yaml, zod

## 简介

Treat a **YAML contract as the single source of truth** for a Firebase app and generate every downstream representation from it — so shared types, enums, and validation stop being hand-maintained in parallel (and stop drifting).
