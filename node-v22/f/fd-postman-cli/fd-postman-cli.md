# fd-postman-cli

> 标签: api, api-automation, api-client, cli, curl-alternative, developer-tools, graphql, http, http-client, postman, request-chaining, rest, terminal, testing, workflow

## 简介

A powerful and efficient command-line interface (CLI) tool for API testing and interaction, inspired by Postman. Features workflows, request chaining, import/export, and history replay.
