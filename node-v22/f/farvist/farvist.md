# farvist

> 标签: bootstrap-alternative, css, dark-mode, design-tokens, framework, glass, glassmorphism, sass, scss, tailwind-alternative, ui-kit, utility-classes

## 简介

A lightweight (~21 KB) glassmorphism CSS framework — frosted surfaces, neon glow, gradients, 42 components and dark/light themes. A drop-in alternative to Bootstrap and Tailwind.
