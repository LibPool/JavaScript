# font-lab

> 标签: agent, astro, claude, claude-code, fonts, mcp, next-font, nextjs, skill, tailwindcss, typography, vite

## 简介

Font Lab — a decision surface for typography. Curate tasteful font directions on your real running site, let a human pick, and ship the exact code for your stack: next/font + Tailwind on Next.js, self-hosted @font-face on Vite/Astro/Remix/SvelteKit/TanSta
