# findcyrillicletters

> 标签: JavaScript

## 简介

- dir ( string ) - название директории, где искать файлы, - verticalResult ( boolean ) - по умолчанию true, выводит имя каждого файла вертикально в консоли, в противном случае, каждый новый файл с новой строки, т.е если несколько опечаток в одном файле,
