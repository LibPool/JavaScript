# flowlet

> 标签: async, chain, composition, control-flow, data-flow, flow, fluent, functional, lightweight, minimal, pipeline, step, sync, typescript, utility

## 简介

A lightweight utility for building fluent, composable data flows. It supports both synchronous and asynchronous steps, with clear semantics and a minimal API
