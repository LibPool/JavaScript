# flue-guard

> 标签: agent-tools, ai-agents, audit-log, authorization, flue, governance, idempotency, prompt-injection, tamper-evident, tool-authorization

## 简介

In-process authorization and tamper-evident audit for Flue agent tools — stop an agent acting on the wrong resource, twice, or unrecorded.
