# file-paste

> 标签: JavaScript

## 简介

file-paste 是一个开箱即用的工具，用于捕获粘贴事件并对粘贴的文件或图片进行处理。它支持将文件转换为多种格式（如 `FormData` 或 `Buffer`），并提供详细的文件信息，包括文件名、文件类型以及可预览的 `Blob` URL。该工具还支持同时处理多个粘贴的文件。
