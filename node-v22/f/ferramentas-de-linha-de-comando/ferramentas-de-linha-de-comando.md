# ferramentas-de-linha-de-comando

> 标签: JavaScript

## 简介

- Ferramenta que disponibiliza interface de linhas de comandos para executar tarefas no terminal. - Normalmente criado através de **Shell Script** - Automatiza uma tarefa através de um arquivo executável - Pode ser distribuída em várias plataformas
