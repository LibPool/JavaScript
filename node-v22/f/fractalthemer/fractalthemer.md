# fractalthemer

> 标签: css, dark-mode, design-system, linter, sass, svelte, svelte5, sveltekit, themes, tokens

## 简介

A class-based styling system: layered indented SASS with a generated class registry, semantic tokens, themes and auras, a Svelte 5 mode store with animated view transitions, and a shipped contract linter
