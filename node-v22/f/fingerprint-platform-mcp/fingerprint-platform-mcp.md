# fingerprint-platform-mcp

> 标签: ai-assistant, claude, cursor, device-id, fingerprint, install, mcp, model-context-protocol, sdk

## 简介

Model Context Protocol server that lets Claude / Cursor / Copilot Chat install and configure the Fingerprint Platform SDK in a user's project — analyze the codebase, propose a diff, generate the Cloudflare Worker proxy, verify the install.
