# flowcn

> 标签: cli, components, flowcn, react, template

## 简介

FlowCN is an AI-powered React component library that helps developers build sleek, animated, and responsive UIs faster. It combines Tailwind CSS, Framer Motion, and intelligent defaults to deliver ready-to-use, customizable components with smooth workflow
