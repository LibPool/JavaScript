# finch-anydoc

> 标签: document, docx, finch, finch-minitool, markdown, pdf, pptx, xlsx

## 简介

Read Word, Excel, PowerPoint, OpenDocument, RTF, EPUB, CSV and PDF files as clean Markdown, right inside Finch.
