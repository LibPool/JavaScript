# freegdpr

> 标签: ccpa, consent, consent-mode, cookie, cookie-banner, cookie-consent, eprivacy, gdpr, privacy, vanilla-js, zero-dependencies

## 简介

Standalone, zero-dependency GDPR cookie consent banner: script-blocking, Google Consent Mode v2, accessible Shadow DOM UI. Usable via CDN or npm.

## 官网

- npm 页面：https://www.npmjs.com/package/freegdpr

- npm registry：https://registry.npmjs.org/freegdpr
- Node 要求：>=18
