# friendlyfy-js

> 标签: array, browser, date, esm, format, human-readable, internationalization, nodejs, number, object, pure-javascript, string, time, utility, validation, zero-dependencies

## 简介

A zero-dependency utility library with 70+ functions for formatting dates, numbers, strings, arrays, objects, and validation. Works in both Node.js and browser environments.
