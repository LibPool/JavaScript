# frameworkqa-mcp

> 标签: automacao, cursor, fluxos-de-teste, frameworkqa, mcp, playwright, qa

## 简介

MCP server v6 — ferramentas consolidadas por domínio (fluxos_query, fluxo_relacionamentos, arquivar_fluxo, passos_query, passos_base_batch) + auth sliding window (access 7d + refresh 30d com rotacao) via /api/mcp/auth/*
