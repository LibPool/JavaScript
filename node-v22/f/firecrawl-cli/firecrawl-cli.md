# firecrawl-cli

> 标签: arxiv, biomedical, biorxiv, cli, crawler, data-extraction, firecrawl, life sciences, literature search, llm, markdown, medrxiv, paper search, pubmed, research, scraper, search, skill, web search, web-scraping

## 简介

Command-line interface for Firecrawl. Scrape, crawl, and extract data from any website, and search a ~43M-abstract research paper index (PubMed, bioRxiv, medRxiv, arXiv), directly from your terminal.
