# figma-code-composer

> 标签: ai-agents, claude-code, code-generation, cursor, design-system, figma, knowledge-graph, mcp, rag, scaffold, tokens

## 简介

Drop-in, framework-agnostic Figma-to-code multi-agent pipeline scaffold for Claude Code and Cursor. Includes a knowledge-graph CLI for cross-run component reuse, complexity-driven routing, and handover-based session optimization.
