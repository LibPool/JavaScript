# fasthar

> 标签: JavaScript

## 简介

A front-end UI that shows aggregated data (i.e., response sizes, response times, and number of requests), using [HTTP Archive (HAR)](https://dvcs.w3.org/hg/webperf/raw-file/tip/specs/HAR/Overview.html) data from captured network traffic. See [fastHAR-api](https://github.com/cvan/fastHAR-api) (the API) and the [phantomHAR](https://github.com/cvan/phantomHAR) (the [phantom.js](http://phantomjs.org/) script).
