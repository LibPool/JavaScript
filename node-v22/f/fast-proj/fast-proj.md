# fast-proj

> 标签: coordinates, gcj02, geodesy, mars coordinates, proj4, projection, transverse mercator, utm, wasm, web mercator, wgs84

## 简介

Fast batch coordinate conversions (UTM, transverse Mercator, Web Mercator, GCJ-02) with typed-array APIs and an optional WebAssembly backend
