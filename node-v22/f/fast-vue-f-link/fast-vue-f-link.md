# fast-vue-f-link

> 标签: fast-vue-f-link, vue

## 简介

Vue 组件获取其它组件实例插件 （无视组件层级、子孙关系），但不支持响应式，若要支持响应式获取和通知请看 `fats-vue-f-ref` 插件
