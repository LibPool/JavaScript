# fis3-jinja2

> 标签: JavaScript

## 简介

如题所示，使用 fis3，与 python 的 jinja2 框架，模拟站点运行。 因为不怎么了解 fis3 的服务器开发，所以把 express 内置在代码包中，充当服务器。
