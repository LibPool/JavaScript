# fsd-gen

> 标签: CLI, FSD, Feature-Sliced Design, codegen, generator, slices

## 简介

CLI tool for generating FSD (Feature-Sliced Design) components and slices in your project. Easily create UI components and slices for features, entities, widgets and pages.
