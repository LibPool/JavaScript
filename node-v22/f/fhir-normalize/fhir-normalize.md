# fhir-normalize

> 标签: fhir, healthcare, hl7, interoperability, normalize, r4, typescript

## 简介

Ingest healthcare data in multiple formats (FHIR JSON, FHIR XML) and get back one standard shape: a FHIR R4 Bundle, plus a simplified view with FHIR choice types resolved.
