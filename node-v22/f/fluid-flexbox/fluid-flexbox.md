# fluid-flexbox

> 标签: collapsed, css, detect, fit, flex, flexbox, fluid, layout, overflow, react, react-component, responsive, tailwind, utility, vanilla-js, wrap

## 简介

A "flex-wrap on steroids" component and custom element that detects when it's flex children no longer fit in a single row.
