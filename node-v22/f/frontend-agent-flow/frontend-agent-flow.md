# frontend-agent-flow

> 标签: agents, claude, claude-code, frontend, mcp, orchestrator, pipeline, react, skills, tdd

## 简介

Drop a 5-phase Claude Code agent pipeline (planner → executor → Door 1 → Door 2 → human approval) into any React/Node project with one command. Includes 30+ specialist agents, 40+ skills, prompt enhancer, wide-research MCP integration, and the no-auto-com
