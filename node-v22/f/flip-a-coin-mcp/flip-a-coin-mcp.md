# flip-a-coin-mcp

> 标签: anthropic, claude, coin-flip, decision, flip-a-coin, mcp, model-context-protocol, random

## 简介

MCP server for Claude Desktop and Claude Code that provides a verifiable, cryptographically fair coin flip via flip-a-coin.com's public API.
