# fbg

> 标签: JavaScript

## 简介

**使用**： 1. 下载node.js 2. npm install -g fbg 3. 新建项目文件夹 4. 在项目文件夹路径下使用指令：     - fbg dev：开启本地预览/初始化项目     - fbg new 文章名：新建一个文章     - fbg del 文章名：删除一篇文章     - fbg build：构建
