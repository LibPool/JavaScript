# forge-orm

> 标签: database, duckdb, embeddings, geo, geospatial, json-path, mongodb, mssql, multi-database, mysql, no-codegen, orm, pgvector, postgres, postgresql, prisma, query-builder, rag, similarity-search, sql-server, sqlite, typescript, vector, vector-search

## 简介

Prisma-shape multi-database ORM/wrapper for MongoDB, PostgreSQL, MySQL, SQLite, DuckDB & SQL Server from one codebase — typed geo / vector / JSON path / full-text search, no codegen, no query engine. Bring your own schema.
