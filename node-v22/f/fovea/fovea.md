# fovea

> 标签: accessibility, ansi, bionic-reading, cli, fixation-point, pty, reading, speed-reading, terminal

## 简介

Fixation-point reading for any terminal AI agent. Wraps a command in a pty and emphasizes the leading stem of each word, or filters piped output.
