# fastify-inertiajs

> 标签: fastify, fastify-inertia, fastify-inertiajs-plugin, fastify-plugin, inertiajs

## 简介

A lightweight Fastify plugin for Inertia.js that lets you build modern single-page applications with server-side rendering.
