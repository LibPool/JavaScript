# fielizator

> 标签: base64, express, file, form-data, json, middleware, multer, multipart, no-dependencies, upload

## 简介

Zero-dependency file upload middleware for Express. Supports multipart/form-data and JSON (data URL, base64, byte arrays, Buffer).
