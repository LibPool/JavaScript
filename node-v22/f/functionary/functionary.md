# functionary

> 标签: after, before, collapse, collapsing, completed, enhance, enhancement, failed, function, function modifier, functional, functional modifier, functionality, functionary, modifiers, modify, prototype, wrap

## 简介

functionary is a small library that extends the function core prototype for expanded functionality for Browser or NodeJS development.  It is similar to Prototype.js or sugar.js but only for functions.
