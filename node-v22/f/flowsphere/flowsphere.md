# flowsphere

> 标签: api, api-testing, automation, http, newman, postman, rest-api, sequence, testing, workflow

## 简介

Automate sequential HTTP workflows through JSON configuration. Create, edit and execute via visual Studio or CLI. Supports conditional execution, response chaining, user input prompts, and validations.
