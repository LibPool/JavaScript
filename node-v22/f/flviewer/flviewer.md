# flviewer

> 标签: audio, csv, docx, file-preview, image, markdown, pdf, pptx, text, video, viewer, web-component, xlsx

## 简介

Pure client-side file preview for the browser: images, PDF, video/audio, text family and office documents (DOCX/XLSX/PPTX) with built-in minimal UI.
