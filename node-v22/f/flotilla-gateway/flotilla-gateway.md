# flotilla-gateway

> 标签: devops, fleet, gateway, mcp, model-context-protocol, ssh

## 简介

Flotilla HTTP Gateway: the same fleet engine as flotilla-mcp, exposed over stateless Streamable HTTP MCP with bearer-token auth.
