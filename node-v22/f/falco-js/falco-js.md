# falco-js

> 标签: JavaScript

## 简介

A lightweight, JSON-only wrapper for falco, a Fastly VCL linter.

- 官网：https://github.com/fastly/vscode-vcl#readme
- 源码仓库：git+https://github.com/fastly/vscode-vcl.git
