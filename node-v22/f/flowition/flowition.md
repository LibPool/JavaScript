# flowition

> 标签: agents, amp, claude, cli, codex, cursor, deterministic, droid, grok, mcp, opencode, orchestration, resume, workflow

## 简介

Deterministic multi-CLI agent workflow engine: programmatic orchestration of claude/codex/amp/droid/opencode/pi/cursor/grok agents with journaled resume, live steering, inspection, and an MCP surface
