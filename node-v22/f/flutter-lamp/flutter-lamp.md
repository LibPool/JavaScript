# flutter-lamp

> 标签: ai, claude, dart, debugging, devtools, flutter, mcp, model-context-protocol, observability, vm-service

## 简介

Flutter Lamp — an MCP server giving AI live eyes on a running Flutter app over the Dart VM Service: exceptions, logs, network, frames, memory + root-cause diagnosis.
