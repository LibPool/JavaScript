# folder-structures

> 标签: cli-tool, directory-visualizer, file-tree, filesystem, folder-structure, folder-watcher, project-structure, structure-generator, tree-view

## 简介

Automatically generate and monitor your project folder structure. The output is a .txt file that shows the folder and file hierarchy in a tree view.
