# fhir-runtime

> 标签: clinical, ehr, emr, fhir, fhir-definition, fhir-r4, fhir-runtime, fhir-server, fhirpath, healthcare, hl7, implementation-guide, interoperability, medical, parser, profile, snapshot, structuredefinition, typescript, us-core, validation, validator

## 简介

Production-ready FHIR R4 runtime engine for TypeScript/Node.js. Includes parser, validator, snapshot generator, FHIRPath engine, and fhir-definition integration.
