# file-extract-loader

> 标签: JavaScript

## 简介

代替（扩展）file-loader,结合extract-text-webpack-plugin运用，处理extract-text-webpack-plugin抽出css文件后，css文件内路径不对的问题。

## 官网

- npm 页面：https://www.npmjs.com/package/file-extract-loader

## 历史版本号

- 1.0.0

- npm registry：https://registry.npmjs.org/file-extract-loader
