# falak-app-duo

> 标签: ably, arabic, boilerplate, brevo, laravel, realtime, rtl, scaffolder, vue3

## 简介

Vue 3 boilerplate scaffolder — Ably (realtime), Brevo, AES-256, Arabic/RTL, and a Laravel API client (API key + user token auth). No Firebase, no Groq/Paymob on the frontend (Groq is backend-only; Paymob dropped).
