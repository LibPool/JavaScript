# figma-local-mcp

> 标签: agent, ai, claude, copilot, cursor, design, design-to-code, figma, figma-plugin, framelink, local, mcp, multimodal, offline, typescript, vision

## 简介

MCP server for AI coding agents that consumes Figma designs offline — no API key, no rate limits. Ships with a companion Figma plugin that bundles design JSON + PNG screenshots + SVG icons + image-fill bytes into a single ZIP; the server surfaces per-node
