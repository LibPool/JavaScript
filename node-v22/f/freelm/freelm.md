# freelm

> 标签: ai, ai-gateway, cerebras, failover, fallback, free, free llm api, free-llm, free-tier, gemini, groq, llm, llm-gateway, llm-router, mistral, model-discovery, nodejs, nvidia-nim, openai, openai-compatible, openrouter, rate-limit, streaming, typescript

## 简介

Free, always-up LLM client over free-tier providers (OpenRouter, Google Gemini, NVIDIA NIM, Groq, Cerebras, Mistral) with automatic failover, key rotation, streaming, and live model discovery. OpenAI-compatible.
