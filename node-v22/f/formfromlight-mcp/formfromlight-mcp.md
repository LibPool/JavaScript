# formfromlight-mcp

> 标签: 3d, animation, claude, cursor, game-assets, glb, gltf, image-to-3d, mcp, model-context-protocol, rigging, text-to-3d

## 简介

MCP server for FormFromLight - generate, rig, animate, build walkable worlds from kits and export 3D assets from Claude, Cursor and other MCP clients.
