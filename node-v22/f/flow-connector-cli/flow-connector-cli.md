# flow-connector-cli

> 标签: ai-agent, automation, chrome-extension, cli, google-flow, image-generation, mcp, nano-banana, veo, video-generation

## 简介

CLI and local bridge for the Flow Connector Chrome extension — batch image and video generation on Google Flow, driven from a terminal or an AI coding agent.
