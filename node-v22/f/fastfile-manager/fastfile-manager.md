# fastfile-manager

> 标签: Appfile, CLI, Fastfile, Fastlane, fastfile-manager, iOS, manager

## 简介

Fastfile is config file for CI system Fastlane. fastfile-manager is simple tool for managing and updating fastfile on your projects.
