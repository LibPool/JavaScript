> 标签: ai-agent, bash, claude-code, codex, gbk, kimi-code, linux, mcp, mcp-server, opencode, powershell, shell, translate, translator, utf8, windows

## 简介

Fauxnix — run Linux-style commands on Windows via deterministic PowerShell translation. No VM, no WSL. MCP server + CLI for AI agents.
