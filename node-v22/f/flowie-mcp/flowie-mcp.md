# flowie-mcp

> 标签: agent-task-board, ai-agents, ai-coding-agents, claude, claude-code, codex, cursor, flowie, kanban, mcp, model-context-protocol, task-board

## 简介

Official MCP server for Flowie — the AI-native task board for managing AI coding agents (Claude Code, Cursor, Codex). Connect an agent to read tickets, project context and shared memory, and write results back.
