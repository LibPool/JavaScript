# fleetview-bridge

> 标签: claude-code, codex, fleetview, local-agent

## 简介

Local companion process for FleetView — relays between the FleetView web UI and an already-authenticated local claude/codex CLI. See docs/local-bridge-design.md in the main FleetView repo.
