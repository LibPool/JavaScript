# fushiguro-mcp

> 标签: agents, ai-adoption, claude, embeddings, hybrid-search, knowledge-base, mcp, memory, model-context-protocol, rag, runbooks, semantic-search, subagents

## 简介

MCP server that decides how much delegation a task deserves, routes it to specialist agents (single or planner-executor-tester-reviewer pipeline), and remembers how your business wants work done.
