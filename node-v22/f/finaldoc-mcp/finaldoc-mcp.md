> 标签: ai, claude, docs, finaldoc, knowledge-base, mcp, model-context-protocol

## 简介

Model Context Protocol server for FinalDoc — lets Claude, Cursor, and other MCP-aware AI clients operate inside your FinalDoc project via API token.
