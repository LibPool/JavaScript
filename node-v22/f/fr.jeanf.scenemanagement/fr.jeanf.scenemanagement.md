# fr.jeanf.scenemanagement

> 标签: jeanf, scenemanagement

## 简介

This package contains two scene loading system, one is additive using the addressable system, the other is to load subscenes. 
Both system are living side-by-side.
The dynamic systems handles the loading of all static content (environment) using subscenes
