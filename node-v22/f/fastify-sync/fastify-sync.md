# fastify-sync

> 标签: automatic, cli, fastify, file-based, file-based routing, routing, synchronization, url, watch, watcher

## 简介

Automatic URL synchronization for Fastify file-based routing. Watches your API route files and keeps the url field in sync with the file path.
