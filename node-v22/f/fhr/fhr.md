# fhr

> 标签: JavaScript

## 简介

PC视频录制，拍照照片。支持[h5 getUserMedia](https://developer.mozilla.org/zh-CN/docs/Web/API/MediaDevices/getUserMedia)和flash。优先使用h5 getUserMedia的方式。
