# ffantasy

> 标签: bun, cli, commit, fantasy, ffantasy, git, node

## 简介

CLI to generate concise, fantasy-styled Git commit messages with structured templates, localization (EN/FR), provider-agnostic LLM integration, optional auto-commit, and customizable lore/style prompts.
