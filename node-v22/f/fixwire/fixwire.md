# fixwire

> 标签: financial, fintech, fix, fix-engine, fix-library, fix-protocol, fix42, fix44, fix50, fixt, order-management, quickfix, trading, typescript

## 简介

A modern, fully-typed FIX protocol library for TypeScript. A QuickFIX-style engine with a correct session layer, zero dependencies, initiator and acceptor, FIX 4.2 to 5.0.
