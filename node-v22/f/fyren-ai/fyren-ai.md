# fyren-ai

> 标签: agents, ai-agents, ai-sdk, anthropic, claude, cli, cost-optimization, cost-tracking, gemini, llm, llm-cost, llm-observability, observability, ollama, openai, profiler, prompt-caching, token-counter, token-usage, tokens, vercel-ai-sdk

## 简介

Find where your LLM tokens and cost actually go — and which of them were avoidable. Token cost profiler for Claude, OpenAI, Gemini, Ollama and Vercel AI SDK agents. Detects missing prompt caching, wasted tool output and retries. Local CLI + web UI, zero d
