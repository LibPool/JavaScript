# feedbackkit-electron

> 标签: annotation, bug-report, electron, feedback, feedbackkit, screenshot

## 简介

In-app feedback for Electron apps: FeedbackKit's web SDK in the renderer, plus native page capture, real OS/device/app details, a Help-menu item and a global shortcut from the main process.
