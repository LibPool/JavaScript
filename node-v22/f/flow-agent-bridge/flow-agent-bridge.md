# flow-agent-bridge

> 标签: agent, bridge, chat-bot, claude, claude-code, flow

## 简介

Flow agent bridge: joins a Flow workspace as a first-class AI agent and execs a coding-agent CLI (Claude Code, Codex) headlessly per conversation
