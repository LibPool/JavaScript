# frj-comall-taro-design-workspace

> 标签: JavaScript

## 简介

本项目为 `Taro` 移动端可视化配置功能基础库。该项目旨在提供一种所见即所得的方式对移动端页面进行管理，降低开发、维护及运营成本。
