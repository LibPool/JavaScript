# fabrica-e-commerce

> 标签: cli, ecommerce, fabrica, nextjs, storefront, supabase, vercel

## 简介

CLI launcher for deploying Fabrica e-commerce stores — Supabase + Vercel, works on Windows, macOS, Linux & Termux.
