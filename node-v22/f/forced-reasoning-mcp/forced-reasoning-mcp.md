# forced-reasoning-mcp

> 标签: chain-of-thought, mcp, model-context-protocol, reasoning, scratchpad

## 简介

MCP server exposing the Forced-Reasoning scratchpad tool from arXiv 2609.26637v1 Appendix B, for extracting model reasoning through a tool channel.
