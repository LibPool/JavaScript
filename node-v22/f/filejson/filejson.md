# filejson

> 标签: async-await, atomic-writes, auto-save, automatic, autosave, cache, config, crash-safe, data-store, database, debounce, document-store, embedded-database, file, filesystem, json, local-storage, node, nodejs, nosql, persistence, promises, proxy, reactive, settings, state, storage, sync, typescript, zero-config

## 简介

Zero-config automatic JSON file persistence with atomic writes, debouncing, and crash safety. Just modify objects, changes save automatically.
