# feedback4ai

> 标签: ai-agent, annotation, claude-code, codex, css, cursor, design-review, dev-tools, feedback, html, mcp, toolbar, vanilla-js

## 简介

Click-to-annotate feedback toolbar for HTML/CSS/JS websites. Point at an element, write a note, and hand Claude Code, Codex, Cursor or any AI coding agent a structured prompt — or sync notes live over MCP with feedback4ai-mcp. One <script> tag, zero depen
