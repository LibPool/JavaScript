# freebuff2api

> 标签: codebuff, free-mode, freebuff, llm-router, openai, openai-compatible, proxy

## 简介

Freebuff LLM router - a local OpenAI-compatible /v1 server that proxies free-mode Freebuff models (DeepSeek V4 Flash, MiMo, etc.) for any agent client.
