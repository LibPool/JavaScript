# framer-to-nextjs

> 标签: cli, convert, export, framer, framer-to-html, framer-to-nextjs, nextjs, static-site

## 简介

Convert any published Framer site into a real Next.js project or an optimized static bundle — from the command line. No Framer login, no plugin, just a URL.

- 官网：https://framertonextjs.com
