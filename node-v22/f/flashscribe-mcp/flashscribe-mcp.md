# flashscribe-mcp

> 标签: claude, flashscribe, mcp, mcp-server, model-context-protocol, modelcontextprotocol, speech-to-text, srt, subtitles, transcription, vtt, whisper

## 简介

MCP server for the Flashscribe API - transcribe audio/video and fetch transcripts, timestamps, and subtitles from AI agents.
