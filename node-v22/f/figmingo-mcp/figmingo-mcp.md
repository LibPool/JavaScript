# figmingo-mcp

> 标签: design-to-code, figma, figma-api, html-replica, mcp, model-context-protocol

## 简介

Local-first Figma MCP server. Full read-side parity with the official Figma MCP on free plans, HTML 1:1 replica tooling with three-gate parity verification, and write-to-canvas via a companion plugin bridge.
