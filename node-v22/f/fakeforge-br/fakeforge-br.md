# fakeforge-br

> 标签: brazil, brazilian, cep, cnpj, cpf, fake-data, faker, fixture, gerador, mock, pix, seed, test-data, testing, typescript

## 简介

SDK oficial do FakeForge para gerar dados brasileiros válidos (CPF, CNPJ, CEP, PIX, cartão de crédito) em testes de software. Presets verticais fintech + ecom. Zero dependências, TypeScript nativo.
