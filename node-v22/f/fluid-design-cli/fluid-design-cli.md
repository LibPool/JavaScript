# fluid-design-cli

> 标签: agent-skill, css, design-system, fluid, responsive, scss, stylex, tailwindcss, typography, viewport

## 简介

Viewport-fluid design scale for any site: one small JSON for structure, every tuning number a CSS variable. Generates for Tailwind v4, CSS, SCSS and StyleX. The `fluid` CLI of the fluid-design agent skill.
