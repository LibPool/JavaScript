# fetch-request-demo

> 标签: JavaScript

## 简介

```bash 对请求环境的统一处理，对传递的参数做了容错性处理。 在请求拦截器中统一添加请求头header，content-type字段，accept等默认字段。 在响应拦截器中对后端返回的参数进行统一的错误校验。 后端返回错误时给用户友好性的提示，对后端返回正确的数据做统一的封装。 ```
