# fork-sortablejs

> 标签: angular, drag, meteor, mixin, ng-sortable, react, reorder, sortable, vue

## 简介

JavaScript library for reorderable drag-and-drop lists on modern browsers and touch devices. No jQuery required. Supports Meteor, AngularJS, React, Polymer, Vue, Knockout and any CSS library, e.g. Bootstrap. Fork from https://github.com/SortableJS/Sortabl
