# filename-cc

> 标签: Chinese, Simplified Chinese, Traditonal Chinese, filename conversion, filename-cc

## 简介

將檔名由簡體中文轉換成繁體中文，或是由繁體中文轉換成簡體中文，預設中文編碼均為UTF8。
