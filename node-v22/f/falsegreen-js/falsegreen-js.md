# falsegreen-js

> 标签: ai-generated-tests, code-quality, false-positive, javascript, jest, jsx, mocha, static-analysis, test-smells, testing, tsx, typescript, vitest

## 简介

Find JavaScript/TypeScript unit tests that give false positives: green tests that protect nothing, and tests that pass while asserting the wrong thing. Deterministic AST scanner, sibling of falsegreen (Python).
