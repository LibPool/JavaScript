# faster-whisper-ts

> 标签: ctranslate2, nodejs, speech-to-text, transcription, typescript, whisper

## 简介

TypeScript port of SYSTRAN/faster-whisper for Node.js, built on CTranslate2, Koffi, FFmpeg, and ONNX Runtime.
