# fingerprint-web

> 标签: anti-fraud, bot detection, browser fingerprint, browser fingerprinting, browser identifier, client fingerprint, device detection, device fingerprint, entropy based tracking, fingerprint js, javascript fingerprint, privacy respecting tracking, session tracking, unique browser id, user identification

## 简介

A blazing-fast, dependency-free browser fingerprinting library to uniquely identify devices using entropy data. Designed for high performance, privacy-respecting analytics, bot detection, and session tracking in modern web apps.
