# freedisk

> 标签: JavaScript

## 简介

Get total diskspace , free space and used space. It's using 'df -h' and can only work at *nix OS.

## 官网

- 源码仓库：https://github.com/saturngod/freedisk
- npm 页面：https://www.npmjs.com/package/freedisk
