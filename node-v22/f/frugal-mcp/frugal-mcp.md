# frugal-mcp

> 标签: agent-tools, claude, cost-optimization, cursor, failover, llm, llm-routing, mcp, mcp-server, model-context-protocol, routing

## 简介

The open routing layer for AI tools: an MCP server that routes agent tool calls (search, extract, browse) across providers per policy — cost, latency, pinning, deny lists — with failover and the routing decision on every result. BYOK.
