# franknet

> 标签: JavaScript

## 简介

一个基于 Axios 的增强型 HTTP 请求库，使用 TypeScript 编写，支持请求防重、智能重试、并行与串行请求、以及缓存功能。该库设计为高度可定制，模块化，易于集成，同时通过核心逻辑与底层 HTTP 请求实现的分离来保证灵活性。
