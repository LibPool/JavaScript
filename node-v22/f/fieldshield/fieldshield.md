# fieldshield

> 标签: clipboard, data-protection, dom-security, fintech, healthcare, hipaa, input, pci-dss, phi, pii, react, security, sensitive-data, web-worker

## 简介

Sensitive input protection for React — prevents DOM scraping, clipboard exfiltration, and accidental PHI exposure in healthcare and fintech applications.
