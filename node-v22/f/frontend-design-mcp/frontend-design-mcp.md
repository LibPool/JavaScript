# frontend-design-mcp

> 标签: design-md, design-system, design-tokens, designmd, frontend, getdesign, mcp, model-context-protocol

## 简介

MCP server that gives coding agents a real design system (DESIGN.md) for frontend work - searches getdesign.md, designmd.app and designmd.ai, and returns only the slice you asked for.
