# findingsteel-steel-sections-mcp

> 标签: gb-standard, mcp, section-properties, steel-fabrication, steel-sections, steel-weight-calculator, structural-steel

## 简介

MCP server for Chinese (GB) standard steel sections: look up section properties (A, Ix, Iy, Wx, Wy, ix, iy) and calculate theoretical weight for H-beams, I-beams, channels, angles, C/Z purlins, square/rectangular hollow sections and welded sections.
