# fakerbankbr

> 标签: 4devs, API wrapper, banco brasileiro, bancário, cheerio, conta bancária, conta bancária falsa, dados de teste, dados falsos, gerador de conta bancária, nodejs

## 简介

O fakerBankBR é um wrapper em Node.js para o serviço 4devs que permite gerar dados bancários falsos brasileiros. Este pacote é uma simples de obter informações de contas bancárias fictícias, incluindo número da conta, dígito verificador, agência e banco.
