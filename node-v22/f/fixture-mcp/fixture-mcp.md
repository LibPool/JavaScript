# fixture-mcp

> 标签: ai-agents, api-testing, drizzle, mcp, modelcontextprotocol, sqlite, testing

## 简介

MCP server for stateful API testing by AI agents. Persists sessions, context, events, and workflows in SQLite via Drizzle ORM.
