# fsl-async

> 标签: async, fs, fs.mkdir, fs.writeFile, fsl-async

## 简介

Designed to be a drop and replace for fs.writeFile and fs.mkdir. It supports recursive directory creation. It contains zero dependencies and uses Promises.
