# fhir-organization-get

> 标签: JavaScript

## 简介

<fhir-organisation-get> creates a form/page to display existing organization with all reusable components.  * Uses fhir-components and iron-ajax.  * In typical use, just use <fhir-organisation-get url=""></fhir-organisation-get>
