# flag-pipe

> 标签: angular 16, angular 17, angular country flags, angular flags, country, country code, country flags, flags, javascript, pipe, typescript

## 简介

Flag Pipe : is an Angular library that provides a pipe to [src] attribute on <img> to dynamically import flag image path.
