# flash-font-hanzi-semantic

> 标签: COLR, chinese, color-font, font, hanzi, mandarin, mnemonic, radicals, webfont

## 简介

Flash Hanzi Semantic: a color hanzi webfont where each character's semantic component is colored by meaning theme (water blue, fire red, ...). ~9,600 characters as unicode-range slices.
