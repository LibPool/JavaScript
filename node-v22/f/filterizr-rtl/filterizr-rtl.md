# filterizr-rtl

> 标签: Yiotis, css, css3, customizable, ecosystem:jquery, filter, filterizr, gallery, jquery-plugin, lightweight, responsive, search, shuffle, sort

## 简介

Filterizr-rtl is an iteration over the famous jQuery plugin that sorts, shuffles, searches and applies stunning filters over responsive galleries using CSS3 transitions and custom CSS effects
