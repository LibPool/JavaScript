# fant-axios-adapter

> 标签: axios, fant-axios-adapter, uni-app

## 简介

#### 介绍 `fant-axios-adapter`用于帮助开发者在`uni-app`项目使用`axios`请求库，提供了使用`uni.request`发起网络请求的`axios`适配器。
