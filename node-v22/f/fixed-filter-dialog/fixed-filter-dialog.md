# fixed-filter-dialog

> 标签: JavaScript

## 简介

The `lms-fixed-filter-dialog` can be used to filter based on multiple items on multiple categories. It can come handy as user themself can view specific items on their needs. It can be used by any  developer who needs to have filter feature in their appli
