# fhir-allergy-note

> 标签: JavaScript

## 简介

&lt;fhir-allergy-note&gt;` adds description of allergy to the page. Uses mwc-textfield and iron-ajax  * In typical use, just use &lt; fhir-allergy-note url="" /fhir-allergy-note&gt;
