# fruitmachine-form

> 标签: JavaScript

## 简介

A form [FruitMachine](http://github.com/ftlabs/fruitmachine) helper.  Hijacks the form's submit event and turns it into an ajax request.  Dependent on [superagent](https://github.com/visionmedia/superagent).
