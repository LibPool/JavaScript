# flexid

> 标签: auth0-id, benchmark, compact, fast, flexible, flexid, ksuid, nanoid, onetable, short-uuid, sortable, stripe-id, tiny, ulid, uuid, uuid-random

## 简介

A tiny, fast, sortable, compact, flexible id generator. Think Stripe IDs but customizable, ULIDs but faster.
