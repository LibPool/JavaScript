# fakegreen

> 标签: agents, ai, aider, ci, claude-code, codex, cursor, gemini-cli, git-diff, hooks, linter, reward-hacking, tests

## 简介

One command scans your agent's diff and flags every way it faked a green build. Deterministic, zero-LLM, no API key.
