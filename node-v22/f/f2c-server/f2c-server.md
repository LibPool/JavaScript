# f2c-server

> 标签: JavaScript

## 简介

f2c-server 是一个命令行工具，用于启动并接收来自`YYF2C`Figma 插件生成的代码，其中封装并集成了 `AI服务`，`代码格式化`等功能。

## 官网

- npm 页面：https://www.npmjs.com/package/f2c-server

- npm registry：https://registry.npmjs.org/f2c-server
- Node 要求：>=16
