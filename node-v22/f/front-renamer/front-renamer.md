# front-renamer

> 标签: cli, codemod, migration, react, refactor, rename, typescript

## 简介

Declarative bulk refactor tool for React/TypeScript repos. Moves files and folders, rewrites imports, and renames identifiers via the TypeScript language service. Pure TS, no ts-morph.
