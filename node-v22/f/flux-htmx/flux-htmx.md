# flux-htmx

> 标签: flux, frontend, fx, htmx, htmx4, hx, hypermedia, prefetch, server-driven, toast

## 简介

Thin server-driven frontend layer on HTMX 4. Shorthand fx-* verbs, presets, lifecycle, prefetch, and toast — without reimplementing htmx.
