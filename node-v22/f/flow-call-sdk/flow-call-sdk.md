# flow-call-sdk

> 标签: JavaScript

## 简介

- Execute tasks and jobs that user configured. - Uploading files to IPFS or downloading files from IPFS. - Keep your private keys in your client, **safe** and sound. - Fully **TypeScript** ready, with definition files and full TypeScript source.
