# fhir-organization-type

> 标签: JavaScript

## 简介

<fhir-organisation-type> adds type of organisation and system url to the page. Uses mwc-textfield, select and iron-ajax  In typical use, just use <fhir-organisation-type url=""></fhir-organisation-type>
