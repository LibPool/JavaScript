# faster-js-for-node

> 标签: babel, es next, es6, node

## 简介

This is a tool that is used to optimize which babel plugins should be used to transform es6/7/next features according to the runtime node enviroment and the babel config

## 官网

- npm 页面：https://www.npmjs.com/package/faster-js-for-node

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install faster-js-for-node`
- npm registry：https://registry.npmjs.org/faster-js-for-node
- Node 要求：>=6.5.x <7
