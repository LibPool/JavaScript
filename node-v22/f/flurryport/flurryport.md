# flurryport

> 标签: agent-tools, ai-agent, capture, claude, cli, codex, cursor, developer-tools, flurryport, github, localhost, mcp, mcp-server, model-context-protocol, multi-agent, ngrok-alternative, replay, shopify, slack, stripe, webhook, webhook-debugging, webhook-replay, webhook-testing, webhooks

## 简介

Capture webhooks byte for byte, replay them to localhost with signatures intact, let an agent act through pipes it never holds keys for, and give several agents one signed room to write to.
