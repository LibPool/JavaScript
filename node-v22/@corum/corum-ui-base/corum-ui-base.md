# @corum/corum-ui-base

> 标签: JavaScript

## 简介

corum 通用壳基座：自由二维网格（grid 树模型 + 拖放/sash/持久化）+ 区域卡片基座（RegionCard）+ 集成中心磁贴墙（mosaic：错落排布算法 + 排布样式）+ 槽位注册机制 + 主题投影（ThemePresenter）+ 极简默认主题。不含任何 IDE 业务槽位与液态玻璃主题，子壳（如 ide-shell）在其上注册自己的槽位与布局。
