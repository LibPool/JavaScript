# @junejuly-lockstep/reconciler

> 标签: ci, graphql, journey, lockstep, msw, playwright, reconciler, visual-regression, xstate

## 简介

Lockstep CI reconciler: extract the navigation graph, snapshot the GraphQL contract, walk journeys in Playwright against seeded mocks, diff screenshots, and post the run to the platform.
