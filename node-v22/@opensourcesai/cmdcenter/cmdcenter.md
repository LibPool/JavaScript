# @opensourcesai/cmdcenter

> 标签: diagnostics, hardware-detection, local-llm, ollama

## 简介

Local command center for a machine running Ollama — real hardware detection, model fit, live system pressure, honest measurement, and bench-result inspection. Talks only to AI runtimes on this machine, never to the internet.
