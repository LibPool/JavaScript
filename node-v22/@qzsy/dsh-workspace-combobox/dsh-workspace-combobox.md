# @qzsy/dsh-workspace-combobox

> 标签: branch, deepseek-harness, dsh, git, pinyin, plugin, workspace

## 简介

Pinyin-aware workspace combobox for the New Session picker, plus a Git branch picker with local/remote branch switching and a Ctrl+. frame-wide workspace switcher.
