# @tassyir/ui

> 标签: custom-elements, dark-mode, design-system, rtl, tassyir, tassyir-app, web-components

## 简介

Web components for Tassyir app pages: the dashboard's look (ink-on-paper tokens, right-to-left, dark mode) as custom elements that work in any framework or none.
