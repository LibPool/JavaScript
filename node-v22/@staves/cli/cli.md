# @staves/cli

> 标签: agents, bpmn, claude-code, jobs-to-be-done, mcp, process, service-design, workflow

## 简介

Describe work shared by people, agents and systems — from your code, from an interview, or by hand — in the open Staves format, and keep it true. An MCP server for Claude Code, Cursor and Codex, a web app, and one HTML file.
