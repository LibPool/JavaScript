# @techprofessor/mcp

> 标签: JavaScript

## 简介

MCP server to create, read, and update TechProfessor artifacts (quizzes, tours, flashcards, playgrounds, exams, syllabi), courses, and code challenges from any MCP client — you author the content, this persists it.
