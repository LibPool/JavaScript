# @printory/sdk

> 标签: api, personalization, pod, print-on-demand, printory, render, sdk, template, webhook

## 简介

TypeScript client for the Printory API: render print-ready files from templates, run batches, upload customer photos and verify webhooks.

## 官网

- 官网：https://docs.printory.io/en/api/sdk
- npm 页面：https://www.npmjs.com/package/@printory/sdk
