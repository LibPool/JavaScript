# @orchestral/runtime

> 标签: agent-runtime, agents, ai, capability-routing, human-in-the-loop, idempotency, job-orchestration, model-fallback, orchestration, typescript

## 简介

In-process Runtime implementation for @orchestral/core. Submits jobs, dispatches Patterns through a CapabilityRouter, walks the model fallback chain when a call fails, and dedupes by idempotency key. Same-model transient retry and cross-Pattern Alternativ
