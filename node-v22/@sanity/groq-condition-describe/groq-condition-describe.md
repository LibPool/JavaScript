# @sanity/groq-condition-describe

> 标签: ast, describe, explain, groq, sanity

## 简介

Describe GROQ boolean expressions: static analysis (reads, clause tree), three-valued explanation against a dataset, counterfactual what-ifs, and deterministic human phrasing with i18n-ready message ids.
