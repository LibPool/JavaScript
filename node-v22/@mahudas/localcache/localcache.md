# @mahudas/localcache

> 标签: JavaScript

## 简介

Mahudas的plugin，針對本機進行資料的cache。 + 可以依照任務的區分建立多個cache pool + 每個cache pool可以設定自己的maxSize、TTL、以及strategy(資料滿的時候的取捨策略)
