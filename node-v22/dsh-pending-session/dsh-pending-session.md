# dsh-pending-session

> 标签: cordis, deepseek-harness, draft, dsh, dsh-plugin, pending, 待执行

## 简介

待执行（Pending Session）：把带草稿的新会话留在侧边栏，点进继续编辑，发送即转正为普通对话。草稿文本与附件本地持久化，重启不丢。
