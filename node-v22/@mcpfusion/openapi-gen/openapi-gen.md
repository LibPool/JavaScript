# @mcpfusion/openapi-gen

> 标签: ai, code-generator, llm, mcp, mcpfusion, mva, openapi, presenter, swagger, zod

## 简介

OpenAPI-to-MCP mcpfusion Server Generator. Parses OpenAPI 3.x and Swagger 2.0 specs and generates a complete, ready-to-run MCP Server with full MVA tool stacks (Presenters, Tools, Registry, Server) — all features configurable via YAML.
