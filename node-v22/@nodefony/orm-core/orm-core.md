# @nodefony/orm-core

> 标签: abstraction, database, esm, nodefony, orm, repository, typescript

## 简介

Un contrat de dépôt de données pour Nodefony, plusieurs moteurs : interfaces, registre et classes de base pour le support multi-ORM
