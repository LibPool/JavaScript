# dalil

> 标签: bug-report, curl, feedback, qa, react, screenshot

## 简介

Drop-in 'Report a bug' for any web app (React, Angular, Vue, plain HTML): steps, screenshots, FE/BE verdict and a safe curl, sent to your own collector.
