# @laranex/myanmar-payments

> 标签: aya-pay, cybersource, kbzpay, laranex, mmqr, myanmar, node-myanmar-payments, payment-gateway, payments, wave-pay, wave-pay-mini-app, yoma

## 简介

Node.js SDK for Myanmar payment gateways: KBZ Pay, Wave Pay, Wave Pay Mini App, AYA Pay, Yoma MMQR and CyberSource. Typed requests and results, exact amounts, no runtime dependencies.
