# @vortxai/emem

> 标签: agent-memory, ai-agents, content-addressed, earth-observation, ed25519, geospatial, mcp, model-context-protocol, provenance, satellite, shared-memory, verifiable

## 简介

TypeScript client for emem: shared, verifiable memory for AI agents. One address per fact, one signature you can check. No key to read.
