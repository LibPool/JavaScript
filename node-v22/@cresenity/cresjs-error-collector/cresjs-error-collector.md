# @cresenity/cresjs-error-collector

> 标签: JavaScript

## 简介

Browser/React error collector for CF (Cresenity Framework) apps - reports to devcloud's Exception Collector via POST /cresenity/jsError. Used by cres.js itself and by every app's React SPA.
