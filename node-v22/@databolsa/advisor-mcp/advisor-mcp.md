# @databolsa/advisor-mcp

> 标签: advisor, databolsa, mcp, model-context-protocol, wealth

## 简介

Servidor MCP do DataBolsa Advisor (camada organizacional B2B) — tools geradas a partir do contrato OpenAPI do Advisor. Autentica com a chave pessoal (db_live_...).
