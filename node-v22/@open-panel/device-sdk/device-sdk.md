# @open-panel/device-sdk

> 标签: device-driver, hid, macropad, openpanel, stream-deck

## 简介

Hardware-agnostic device abstraction for OpenPanel: the DeckDevice/DeviceDriver interfaces, the connection state machine, a driver registry, and a mock device for hardware-free development.
