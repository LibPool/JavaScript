# @open-panel/ipc

> 标签: ipc, macropad, openpanel, stream-deck, websocket

## 简介

Typed WebSocket IPC contract for OpenPanel, with a ws-based server (daemon-only, ./server) and a client built on the standard WebSocket global that works in Node and in the browser/webview (./client).
