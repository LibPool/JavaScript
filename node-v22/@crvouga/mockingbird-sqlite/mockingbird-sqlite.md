# @crvouga/mockingbird-sqlite

> 标签: mockingbird, sqlite

## 简介

Owned sync SqliteClient port for Mockingbird services. Defaults to @crvouga/mockingbird-service-sqlite; accepts any duck-typed SQLite client.
