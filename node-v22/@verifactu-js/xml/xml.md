# @verifactu-js/xml

> 标签: aeat, factura, soap, spain, verifactu, xml, xsd

## 简介

Serialización al esquema oficial VERI*FACTU (AEAT), envoltorio SOAP y lectura de la respuesta. Sin dependencias de terceros. / Official VERI*FACTU schema serialisation, SOAP envelope and response parsing. No third-party dependencies.
