# @echostash/cli

> 标签: audit, ci, cli, echostash, eval, lint, llm, mcp, model-context-protocol, prompt, tool-surface

## 简介

Audit an MCP server's tool surface, scan your code for LLM prompts, and gate regressions in CI. No API key, no server, no model calls.
