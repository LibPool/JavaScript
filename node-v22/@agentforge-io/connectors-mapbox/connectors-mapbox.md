# @agentforge-io/connectors-mapbox

> 标签: JavaScript

## 简介

Mapbox connector for AgentForge — geocoding, routing, and field-service route lifecycle tools wired to per-tenant Mapbox secret tokens. Source-agnostic: tools exchange a canonical DailyRoute JSON that any data source (Sheets, ClickUp, HubSpot, custom ERP)
