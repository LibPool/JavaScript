# @sergiogdev/markdown-viewer

> 标签: css-variables, gfm, markdown, nextjs, react, themeable, viewer

## 简介

Visor de Markdown para React/Next, tematizable con custom properties CSS. Soporta GFM, tablas, columnas :::columns y resaltado de sintaxis opcional.
