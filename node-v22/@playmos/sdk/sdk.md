# @playmos/sdk

> 标签: base, games, iap, payments, playmos, prize-pool, stablecoin, usdc, web3

## 简介

Playmos SDK — stablecoin payments for games on Base. IAP and skill contests are flat 1%. USD in, USDC on-chain, no crypto UX for players.
