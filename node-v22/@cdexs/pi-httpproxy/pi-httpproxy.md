# @cdexs/pi-httpproxy

> 标签: domain-whitelist, fetch, network, pi, pi-coding-agent, pi-package, proxy, undici

## 简介

Pi coding agent extension that auto-installs a domain-whitelist global HTTP proxy: whitelisted domains go through your proxy, everything else stays direct. Zero-config safe (inert without a proxy address).
