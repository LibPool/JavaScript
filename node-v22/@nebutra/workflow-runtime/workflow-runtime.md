# @nebutra/workflow-runtime

> 标签: JavaScript

## 简介

Tenant-authored workflow orchestration. A workflow is tenant-written JavaScript (`agent()`, `parallel()`, `phase()`, `args`) — the same orchestration grammar as Claude Code's Workflow tool — executed **only** inside a fail-closed sandbox.
