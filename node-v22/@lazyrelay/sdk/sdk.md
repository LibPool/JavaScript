# @lazyrelay/sdk

> 标签: cli, lazyrelay, scheduler, sdk, social-media

## 简介

Official Node SDK and command-line tool for LazyRelay: schedule and publish social posts, upload media, read analytics and manage client approvals through the LazyRelay REST API. Typed, zero dependencies.
