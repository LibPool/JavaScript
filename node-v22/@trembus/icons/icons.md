## 简介

The Trembus glyph set — hand-authored, normalized 24×24 inline-SVG icons (node/file-type marks, the workflow-output vocabulary for human+AI command centers, and UI affordances) shared by @trembus/ui and @trembus/viz. Pure React components, no stylesheet:
