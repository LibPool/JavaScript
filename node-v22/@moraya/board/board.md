# @moraya/board

> 标签: JavaScript

## 简介

Teaching whiteboard core for the Moraya ecosystem. Scene-graph model, KaTeX+mhchem formula elements, freehand strokes, and self-contained *.mboard.svg serialization (scene JSON embedded in SVG metadata). Pure ESM, host-agnostic, framework-free.
