# @gardenfi/wallet-connectors

> 标签: JavaScript

## 简介

The `@gardenfi/wallet-connectors` package handles bitcoin wallet connections across different providers (OKX, Unisat, Xverse, Phantom, Keplr, Leap) with a unified interface. It supports mainnet and testnet networks, provides balance checking capabilities,
