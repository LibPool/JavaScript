# @nightjarhq/sdk

> 标签: api, nightjar, sdk, typescript

## 简介

Nightjar SDK — typed client for the /v1 REST + WS API (this build ships the typed surface + an in-memory mock; the phase-3 generated client replaces the mock). See ADR-016.
