# @solarisdk/e2b-compat

> 标签: code-interpreter, compat, e2b, sandbox, solari

## 简介

E2B-compatible API (sandboxes and code interpreter) on top of Solari Sandbox: change the import, keep your E2B code. Not affiliated with E2B.
