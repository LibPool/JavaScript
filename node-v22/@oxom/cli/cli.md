# @oxom/cli

> 标签: cli, creator, mcp, model-context-protocol, oxom, short-links

## 简介

Official oxom CLI — sign in to an oxom workspace, bridge the oxom MCP server into any stdio MCP client, and drive links, docs, and Drive from the terminal.
