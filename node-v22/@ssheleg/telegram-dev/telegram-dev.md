> 标签: agent-skills, aiogram, bot-api, claude-code, cursor, grammy, initdata, mini-app, mtproto, telegram, telegram-bot, telegram-mini-apps, telegram-stars, telethon, userbot

## 简介

Three skills for building on Telegram, separated by which API each one speaks: the official HTTP Bot API for bots, MTProto (Telethon) for user accounts, and Mini Apps for the web layer whose whole security model is one signed blob.
