# @tayomi/skiller

> 标签: agent-skills, claude-code, compiler, markdown, mdast, partials, skills, templating

## 简介

A compiler for agent skills: build the file that ships from sources you maintain, instead of hand-writing every copy. v1 strips author-only comments; composable blocks with slots are next.
