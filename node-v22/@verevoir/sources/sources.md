# @verevoir/sources

> 标签: JavaScript

## 简介

Source-adapter primitive: a contract over remote + local file sources (read/list/tree/write/branch/fork/PR) with implementations as subpath imports. GitHub + local FS + Notion today; GitLab, Bitbucket, S3 follow.
