# @upstash/agentkit-tanstack-ai

> 标签: agent, ai, lock, memory, persistence, rag, resumable-stream, tanstack, tanstack-ai, upstash

## 简介

Upstash AgentKit backends for TanStack AI: chat persistence, resumable streams, distributed locks, long-term memory, tool caching, rate limiting, and Redis-Search tools — all on one Upstash Redis.
