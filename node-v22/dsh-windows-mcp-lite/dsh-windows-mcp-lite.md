# dsh-windows-mcp-lite

> 标签: deepseek-harness, desktop-automation, dsh, dsh-plugin, mcp, stdio, ui-automation, windows, windows-mcp

## 简介

Config-only DeepSeek Harness bundle that mounts the in-box MCP client bridge against CursorTouch/Windows-MCP; no plugin code, least-privilege tool set by default.
