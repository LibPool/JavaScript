# @marktiderman/genesis-map

> 标签: cli, codebase, gitdata, map, resources, surfaces

## 简介

Map a codebase into gitdata rows: every screen the router reaches, the resources it reads and writes, and authored flows verified against both. Node built-ins only, no runtime dependencies.
