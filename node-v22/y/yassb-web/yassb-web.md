# yassb-web

> 标签: html, serverless, static, static website, website, website builder, website generator

## 简介

YASSB (Yet Another Static Site Builder) processes HTML, (S)CSS, JavaScript/TypeScript, JSX/TSX, JSON, MarkDown and many other files and combines them into beautiful static websites
