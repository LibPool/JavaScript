# yatt-ts

> 标签: browser-automation, e2e, headless, mcp, mcp-server, model-context-protocol, playwright, test-runner, testing, ui-testing, yatt

## 简介

Highly configurable YATT MCP server library: spin up your own UI-testing MCP server (35 tools, Playwright engine, headless-first) with strict, typed configuration for paths, HTTP transport, auth, permissions, sessions and retention.
