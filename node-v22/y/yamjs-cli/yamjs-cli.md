# yamjs-cli

> 标签: components, custom, html-components, react, vue, web, webcomponents, yam, yamjs, yamjs-cli, yamjscli

## 简介

Yamjs-cli 是针对yamjs 的自动化构建工具，帮你开发者更快的建立yamjs组件/项目 YamJS 一个webComponent的渲染函数组件;兼容非webComponent渲染,是一个针对html的开发的一个组件基类，让你开发一个组件，可以运行在原生HTML/vue/react等环境。
