# yalps

> 标签: ILP, Integer Programming, LP, Linear Optimization, Linear Programming, MILP, Mixed Integer Linear Programming, Solver

## 简介

Yet another linear programming solver. (A rewrite of javascript-lp-solver.) Aims to be decently fast.
