# youdata

> 标签: cli, database, database-cli, database-engine, embedded-database, fast-database, file-database, gateway, javascript, lightweight-database, local-database, nodejs, schemas, single-file-database, transactions, wal, write-ahead-log, youdata

## 简介

YouData is a fast, lightweight, compact single-file embedded database for Node.js with WAL recovery, schemas, transactions, gateways, and CLI tools.
