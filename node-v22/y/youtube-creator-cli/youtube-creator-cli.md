# youtube-creator-cli

> 标签: api, cli, nodejs, oauth2, typescript, upload, video, youtube, youtube-api

## 简介

CLI for YouTube Data API v3 with Node.js. Upload videos, manage metadata, set thumbnails, and interact with channels.
