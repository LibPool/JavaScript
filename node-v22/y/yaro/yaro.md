# yaro

> 标签: 100lines, arg, arg parser, arg-parse, argparse, argparser, argument, argument parser, arguments, argv, cli, cli flags, cli options, cli parser, command options, command-line, commandline, cross-platform, flags, flags parser, minimal, opt parser, optparse, parser, parsing, parsing cli, parsing flags, parsing options, process argv

## 简介

Fast, minimalist, pluggable and functional command line parsing. Create CLIs easily. A wrapper package exporting everything from several Yaro packages.
