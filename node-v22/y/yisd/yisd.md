# yisd

> 标签: directories, directory, folder, folders, i, install, sub, subdirectory, subfolder, yarn

## 简介

Yarn Install in SubDirectories. Yes, it's that simple. Use it like: `yisd [subdirs...]` (Example: `yisd client server scripts`)
