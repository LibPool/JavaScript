# ymltocsv

> 标签: convert, csv, i18n, json

## 简介

A cli tool to convert i18n yml files to csv files so you can import them into google sheets, excel, numbers, ...

- 官网：https://github.com/mobinni/i18ntocsv
- 源码仓库：https://github.com/mobinni/i18ntocsv
