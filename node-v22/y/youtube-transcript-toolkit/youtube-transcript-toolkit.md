# youtube-transcript-toolkit

> 标签: captions, llm, rag, srt, subtitles, transcript, vtt, youtube, youtube-transcript

## 简介

Get YouTube transcripts and subtitles (text, SRT, VTT, JSON, timestamps) from Node.js or the command line. No API key.

## 官网

- npm 页面：https://www.npmjs.com/package/youtube-transcript-toolkit

- 1.0.0

## 获取地址

- npm 安装：`npm install youtube-transcript-toolkit`
- npm registry：https://registry.npmjs.org/youtube-transcript-toolkit
- Node 要求：>=18
