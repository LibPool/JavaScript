# yapi-qx-mcp

> 标签: claude, cursor, mcp, model-context-protocol, yapi

## 简介

Auditable YApi MCP server (stdio only). Compatible tools with yapi-auto-mcp; outbound HTTP restricted to YAPI_BASE_URL.
