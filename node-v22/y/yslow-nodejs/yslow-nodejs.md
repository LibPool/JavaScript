# yslow-nodejs

> 标签: automation, command, har, line, performance, wpo, yahoo, yslow

## 简介

yslow-nodejs is forked from yslow's (https://github.com/marcelduran/yslow) nodejs component and fixed its jsdom version to 3.1.2 and upgraded yslow to version 3.1.8

## 官网

- 官网：http://getyslow.com
- 源码仓库：git+https://github.com/senthilprabhut/yslow-nodejs.git
- npm 页面：https://www.npmjs.com/package/yslow-nodejs

## 历史版本号

- 当前版本：3.1.9

- 3.1.8
- 3.1.9

## 获取地址

- npm 安装：`npm install yslow-nodejs`
- npm registry：https://registry.npmjs.org/yslow-nodejs
- Node 要求：>= 0.4.1
