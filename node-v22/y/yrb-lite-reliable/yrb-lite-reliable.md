# yrb-lite-reliable

> 标签: actioncable, crdt, reliable-delivery, typescript, y-websocket, yjs, yrb-lite

## 简介

Client core for the yrb-lite y-websocket protocol: sync steps, message encode/decode, awareness, and reliable delivery (ack-tracked queue, sync-since-last-ack, retransmit + reconnect replay). Written in TypeScript with bundled types; usable from plain JS.
