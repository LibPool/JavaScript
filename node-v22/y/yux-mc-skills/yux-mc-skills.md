# yux-mc-skills

> 标签: agent, bot, mcp, minecraft, mineflayer, model-context-protocol

## 简介

技能级 Minecraft MCP server —— 31 个中度行为封装（移动/挖矿/建造/生存/耕种/畜牧/照明/感知），fail-fast 走位，坐标批量层，双轨返回（人话 + 结构化信封），可被外部编排或二次封装
