# yuyuan-ui-one

> 标签: JavaScript

## 简介

1. 运行 `yarn` 2. 运行 `yarn build:website` 3. 得到的 dist 目录就是官网源代码 4. 编辑并运行 `sh deploy.sh` 就可以上传到 Github 或码云等支持 Pages 功能的平台
