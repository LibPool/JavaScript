# ym-hermes-desktop

> 标签: agent, api-server, cli, hermes, mcp, model-context-protocol, openai-compatible

## 简介

Hermes Agent 接入点客户端与 MCP server：把 Hermes（含其 MCP 工具）通过 OpenAI 兼容 API / MCP stdio 协议暴露给任意 AI 工具。
