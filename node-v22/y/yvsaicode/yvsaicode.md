# yvsaicode

> 标签: agent, ai, anthropic, cli, coding-agent, gguf, llama.cpp, llm, mcp, ollama, openai, skills, terminal

## 简介

Agentic terminal client for local and hosted models: tools, a kernel sandbox, bundled skills, memory, sub-agents, background jobs, scheduling and a phone bridge. Drives llama.cpp locally or any OpenAI-compatible API.
