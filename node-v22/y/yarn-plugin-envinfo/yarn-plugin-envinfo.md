# yarn-plugin-envinfo

> 标签: plugin, yarn, yarn-plugin

## 简介

Yarn plugin so that you can run `envinfo` in your project based on a local `.envinfo` project config file.

- 官网：https://github.com/TheKnarf/yarn-plugin-envinfo
