# yeim-uni-sdk

> 标签: JavaScript

## 简介

可私有化部署的全开源即时通讯uni-app js-sdk，仅需植入 sdk 即可轻松集成聊天能力，支持Web、uni-app项目接入使用，满足通信需要。
