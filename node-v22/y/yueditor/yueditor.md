# yueditor

> 标签: yuEditor, 富文本编辑器

## 简介

基于wangeditor改编的富文本编辑器，添加功能：上传音频、下标加点，内容区域自适应高度、拷贝文本

## 官网

- 官网：http://wangeditor.github.io/
- npm 页面：https://www.npmjs.com/package/yueditor
