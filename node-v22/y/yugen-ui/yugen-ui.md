# yugen-ui

> 标签: a11y, accessibility, component-library, components, dark-mode, design-system, design-tokens, fluent, fluent-2, high-contrast, radix-ui, react, rtl, sakura, shadcn, tailwindcss, tailwindcss-v4, typescript, ui

## 简介

Fluent 2-inspired React component library for Tailwind CSS v4: design tokens, accessible Radix-based components, Sakura brand, light/dark/high-contrast themes and RTL.
