# ym-openclaw-task

> 标签: dispatch, mcp, model-context-protocol, openclaw, report, task, webhook

## 简介

OpenClaw（龙虾）任务工具 MCP server：下发任务给 OpenClaw 执行（openclaw_chat，后台异步 + 完成自动上报），并支持任务完成上报（report_task，精确到年月日时分秒）。
