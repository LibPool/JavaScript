# yaml-admin-front

> 标签: JavaScript

## 简介

A frontend library that auto-builds a `react-admin` UI from a single `admin.yml`. With only entity definitions in YAML, it renders list/show/create/edit screens, menus, icons, and upload fields out of the box.
