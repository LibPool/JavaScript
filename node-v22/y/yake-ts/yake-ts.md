# yake-ts

> 标签: keyword-extraction, keyword-extractor, nlp, session-naming, text-analysis, text-mining, typescript, unsupervised, yake, zero-dependency

## 简介

Tiny, dependency-free YAKE keyword extractor — no classes, no caching, one pure function. English bundled, 33 more languages as opt-in imports.
