# @basaltkit/audit-sqlite

> 标签: audit, basalt, sqlite, store, typescript

## 简介

Durable, SQLite-backed implementation of the @basaltkit/audit AuditStore (append-only trail), on Node's built-in node:sqlite. Zero external dependencies.
