# @basaltkit/queue

> 标签: background-jobs, basalt, jobs, queue, typescript

## 简介

Driver-agnostic Basalt queues: declarative jobs with Zod payloads, context propagation (tenant/requestId) to workers, and a sync driver for tests. Backends ship as their own plugins (@basaltkit/queue-bullmq, -rabbitmq, -sqs, -kafka).
