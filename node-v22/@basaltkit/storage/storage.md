# @basaltkit/storage

> 标签: basalt, minio, s3, storage, typescript

## 简介

Driver-agnostic Basalt storage: disks, scoping, image pipeline and a local-filesystem driver. Cloud backends ship as their own packages (@basaltkit/storage-s3, -azure, -gcs).
