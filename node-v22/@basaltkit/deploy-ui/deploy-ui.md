# @basaltkit/deploy-ui

> 标签: basalt, deploy, ssh, ui

## 简介

A local web UI for @basaltkit/deploy: runs on the operator's machine, listens on 127.0.0.1 only, and drives the server over the system ssh with the operator's own keys. Never an app dependency.
