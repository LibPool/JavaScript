# @basaltkit/subscriptions-sqlite

> 标签: basalt, billing, sqlite, store, subscriptions, typescript

## 简介

Durable, SQLite-backed implementations of the @basaltkit/subscriptions stores (subscriptions, atomic usage metering, webhook idempotency) built on Node's built-in node:sqlite. Zero external dependencies.
