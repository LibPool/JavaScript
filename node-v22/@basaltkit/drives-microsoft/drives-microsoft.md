# @basaltkit/drives-microsoft

> 标签: basalt, drives, file-import, microsoft-graph, oauth, onedrive, sharepoint, typescript

## 简介

Microsoft OneDrive / SharePoint provider adapter for @basaltkit/drives: Entra ID OAuth with PKCE and rotating refresh tokens, /delta change feed, opaque @odata.nextLink pagination, pre-signed streaming downloads, quickXorHash checksums and clientState-aut
