# @basaltkit/billing-ui

> 标签: basalt, billing, saas, typescript, ui

## 简介

A self-contained HTML page for @basaltkit/subscriptions: show the current plan and available plans, subscribe/switch via hosted Checkout, and manage billing via the Customer Portal. Zero dependencies.
