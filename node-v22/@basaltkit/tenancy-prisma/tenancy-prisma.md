# @basaltkit/tenancy-prisma

> 标签: basalt, multi-tenant, postgresql, prisma, store, tenancy, typescript

## 简介

Prisma-backed implementation of the @basaltkit/tenancy TenantSource — the production reference backend (PostgreSQL/MySQL). Bring your own PrismaClient; ships a reference schema.
