# @basaltkit/audit-viewer

> 标签: audit, basalt, compliance, saas, typescript

## 简介

Read-only viewer for the @basaltkit/audit trail: tenant-scoped, filterable, paginated queries with aggregate stats, plus a self-contained HTML browser.
