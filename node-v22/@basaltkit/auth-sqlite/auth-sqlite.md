# @basaltkit/auth-sqlite

> 标签: auth, basalt, sessions, sqlite, store, typescript

## 简介

Durable, SQLite-backed implementations of every @basaltkit/auth store (users, sessions, refresh tokens, one-time tokens, API keys, MFA) built on Node's built-in node:sqlite. Zero external dependencies.
