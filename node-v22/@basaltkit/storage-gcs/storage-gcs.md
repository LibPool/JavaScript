# @basaltkit/storage-gcs

> 标签: basalt, gcs, google-cloud, storage, typescript

## 简介

Google Cloud Storage driver for @basaltkit/storage — put/get/list/delete/signed URLs over @google-cloud/storage, with an injectable client for testing.
