# @basaltkit/mcp

> 标签: agent, ai, basalt, mcp, model-context-protocol, tools

## 简介

Model Context Protocol for Basalt: expose opt-in routes as MCP tools over HTTP (any adapter) or stdio, and consume external MCP servers as a client — all through the neutral route pipeline.
