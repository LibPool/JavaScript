# @basaltkit/drives-dropbox

> 标签: basalt, drives, dropbox, file-import, oauth, typescript

## 简介

Dropbox provider adapter for @basaltkit/drives: OAuth with offline refresh, list_folder cursors, streaming download and upload, content_hash checksums, rate-limit and error mapping, and signed webhook verification.
