# @basaltkit/webhooks-prisma

> 标签: basalt, postgresql, prisma, store, typescript, webhooks

## 简介

Prisma-backed implementation of the @basaltkit/webhooks WebhookStore (endpoint subscriptions) — the production reference backend (PostgreSQL/MySQL). Bring your own PrismaClient; ships a reference schema.
