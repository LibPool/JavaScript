# @basaltkit/auth-prisma

> 标签: auth, basalt, postgresql, prisma, store, typescript

## 简介

Prisma-backed implementations of every @basaltkit/auth store (users, sessions, refresh tokens, one-time tokens, API keys, MFA) — the production reference backend (PostgreSQL/MySQL). Bring your own PrismaClient; ships a reference schema.
