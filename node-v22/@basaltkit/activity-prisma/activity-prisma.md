# @basaltkit/activity-prisma

> 标签: activity, basalt, postgresql, prisma, store, typescript

## 简介

Prisma-backed implementation of the @basaltkit/activity ActivityStore (activity feed) — the production reference backend (PostgreSQL/MySQL). Bring your own PrismaClient; ships a reference schema.
