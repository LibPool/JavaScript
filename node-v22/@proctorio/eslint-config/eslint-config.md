# @proctorio/eslint-config

> 标签: closure, code-quality, config, eslint, eslint-config, eslint10, eslintconfig, flat-config, javascript, jsdoc, linting, proctorio, styleguide, typescript

## 简介

Proctorio's opinionated ESLint configuration with strict JSDoc, Allman brace style, and tab indentation. Built for ESLint v10 flat config. Includes TypeScript support.
