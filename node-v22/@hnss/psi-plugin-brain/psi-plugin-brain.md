# @hnss/psi-plugin-brain

> 标签: JavaScript

## 简介

名字为 `brain` 的 Catalog。类型从 `@hnss/psi-compose` 导入，运行时不依赖 `@hnss/psi-core`。`config.dir` 缺省为 `~/.psi/brain`。本包不提供会话存储，也不提供模型。
