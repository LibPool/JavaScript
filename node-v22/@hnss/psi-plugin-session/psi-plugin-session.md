# @hnss/psi-plugin-session

> 标签: JavaScript

## 简介

`SessionStore` 的两种实现。类型从 `@hnss/psi-compose` 导入，运行时不依赖 `@hnss/psi-core`。本包不提供工具，也不提供模型。会话放在哪由调用方决定。
