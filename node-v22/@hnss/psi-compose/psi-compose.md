# @hnss/psi-compose

> 标签: JavaScript

## 简介

按 `config.json` 里的插件清单装一张 `Registry`。运行时只依赖 `@hnss/psi-core`。源码不导入 Ink，也不点名 `base`、`llm`、`session`。
