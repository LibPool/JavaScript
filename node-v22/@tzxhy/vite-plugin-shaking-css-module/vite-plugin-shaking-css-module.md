# @tzxhy/vite-plugin-shaking-css-module

> 标签: css module, tree shaking, vite plugin

## 简介

@tzxhy/vite-plugin-shaking-css-module --- `vite 插件`。用于去除 vue3 css module 中未引用的样式 （**css module tree shaking**）。
