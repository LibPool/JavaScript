## 简介

MCP server for the x402 Trust Layer — 13 agent-payment trust tools (preflight guard, KYM merchant score, mandate diff, semantic escrow, receipt audit, Agent Trust Protocol v4: passport, fraud scan, credit score). Pay-per-call in USDC over x402; no API key
