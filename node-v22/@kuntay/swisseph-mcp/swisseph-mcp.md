# @kuntay/swisseph-mcp

> 标签: astrology, astronomy, claude, llm, mcp, model-context-protocol, natal-chart, swiss-ephemeris

## 简介

Model Context Protocol server for Swiss Ephemeris. Gives an LLM exact astronomical and astrological calculations instead of plausible-looking guesses.
