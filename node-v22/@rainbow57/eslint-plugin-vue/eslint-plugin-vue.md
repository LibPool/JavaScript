# @rainbow57/eslint-plugin-vue

> 标签: eslint, eslint-config, eslint-plugin, rules, vue, vuejs

## 简介

Official ESLint plugin for Vue.js & Treat .nvue, .uvue type files as vue language files, and use the same processor as .vue
