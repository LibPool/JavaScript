# @aletheia-works/paludarium-wasm

> 标签: JavaScript

## 简介

A user-mode x86-64 Linux emulator in Rust. It runs statically linked x86-64 Linux programs unchanged on Linux, macOS and Windows, and in WebAssembly (Node.js and browsers), with a JIT for WebAssembly.
