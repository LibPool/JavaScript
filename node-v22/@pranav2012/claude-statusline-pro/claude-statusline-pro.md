# @pranav2012/claude-statusline-pro

> 标签: anthropic, claude, claude-code, cli, statusline, terminal

## 简介

A compact, information-dense statusline for Claude Code: model, token usage, cost, context window, and 5h/7d/extra-usage budgets from the OAuth usage API.
