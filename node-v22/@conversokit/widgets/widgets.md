# @conversokit/widgets

> 标签: chatgpt-apps, components, conversokit, mcp, react, ui

## 简介

19 themed React widgets for ConversoKit (commerce, booking, lead-gen, travel, dashboard, consent) — every widget styled via `--ck-*` CSS variables.
