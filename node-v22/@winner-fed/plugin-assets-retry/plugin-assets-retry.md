> 标签: assets-retry, cdn, css, error-handling, failover, frontend, javascript, plugin, resource-loading, retry, static-assets, typescript, winjs, winner-fed

## 简介

一个用于静态资源加载失败自动重试的 Winjs 插件，基于 [assets-retry](https://github.com/BetaSu/assets-retry) 库实现。
