# @snnh/dsh-llm-service-lite

> 标签: anthropic, cordis, cordis-plugin, deepseek-harness, dsh, llm, openai-compatible, openai-responses

## 简介

Community plugin for DeepSeek Harness: a lighter LLM service with self-contained provider profiles, a declared model catalog, and the chat-completions, Anthropic Messages, and OpenAI Responses wires on the harness LLM seam.
