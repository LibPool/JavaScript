# dsh-notify-tray

> 标签: deepseek, deepseek-harness, dsh-bundle, dsh-plugin, menubar, notification, tray, usage

## 简介

DeepSeek Harness 通知 + 状态栏插件：任务完成、需要输入、需要选择时弹系统通知（macOS / Windows / Linux）；macOS 与 Linux（含 UOS、Deepin、麒麟）状态栏常驻小图标，显示任务进度与花费。Windows 没有状态栏，只弹通知。
