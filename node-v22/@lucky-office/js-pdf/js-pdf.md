# @lucky-office/js-pdf

> 标签: lucky-office, pdf, pdf-preview, pdfjs, vue-office

## 简介

基于 vue-office 二次开发的框架无关 PDF 预览库（vanilla JS / UMD），底层基于 pdf.js。
