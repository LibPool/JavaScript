# lecodes-web-shared

> 标签: JavaScript

## 简介

What every web renderer and host of LeCodes shares: the fetch-buffer and media-player registries, the presentation model (router, presentPlayer, native views, touch), svg/video leaves, fonts, source-map errors, the canvas host
