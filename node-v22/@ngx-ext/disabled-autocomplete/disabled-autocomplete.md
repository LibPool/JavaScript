# @ngx-ext/disabled-autocomplete

> 标签: JavaScript

## 简介

> **Directive** for inputs disabling browser's auto-complete/auto-fill functionalities. Aims to handle the newest versions of Chrome, Edge, Opera, Safari and Firefox.
