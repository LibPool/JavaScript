# @svnrnns/typed-expo-store

> 标签: JavaScript

## 简介

A lightweight, type-safe wrapper for [expo-secure-store](https://docs.expo.dev/versions/latest/sdk/securestore/) with optional **Zod** validation for React Native and Expo apps.
