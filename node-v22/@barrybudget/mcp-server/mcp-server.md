# @barrybudget/mcp-server

> 标签: barrybudget, budgeting, finance, mcp, model-context-protocol

## 简介

Read-only MCP server exposing your own BarryBudget data (accounts, budgets, transactions, spending insights, net worth) to your own AI agent.
