# @byteindev/topup

> 标签: bank-transfer, emvco, ocr, promptpay, qr, slip, slip-ok, thailand, topup, truemoney, verification

## 简介

TrueMoney gift-code redemption and Thai bank-slip verification: QR decode (PromptPay EMVCo + slip-check Mini-QR with CRC validation), local OCR amount extraction, and Slip-OK/TrueMoney API clients.
