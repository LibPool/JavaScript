# smcreader

> 标签: agents, claude-code, claude-code-plugin, context, context-window, hooks, llm, mcp, model-context-protocol

## 简介

SMC Reader (Save My Context Reader): pull-model reading of large tool outputs for Claude Code. A PostToolUse hook spills big outputs to disk and leaves a short pointer; an MCP server returns only the lines or answers the model asks for.
