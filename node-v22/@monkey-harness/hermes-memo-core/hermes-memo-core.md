# @monkey-harness/hermes-memo-core

> 标签: JavaScript

## 简介

Shared Hermes-style memory core: storage, format codec, cross-process locking, SQLite search, migration. Agent-agnostic; pi and DeepSeek Harness facades both operate through it.
