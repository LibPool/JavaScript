# @speechineer/react

> 标签: ai-forms, dictation, hooks, react, speech-to-form, speech-to-text, speechineer, structured-data, voice-documentation, voice-input

## 简介

Build voice-based documentation into your React app — a provider and one hook per capability turn speech or text into structured, typed values.
