# @xpaysh/storefront-audit-mcp

> 标签: agentic-commerce, ai-tool, audit, claude, conformance, mcp, model-context-protocol, storefront-audit

## 简介

Model Context Protocol (MCP) server exposing @xpaysh/storefront-audit's audit() function as the audit_storefront tool. Stdio transport; runs anywhere via npx. Lets Claude Desktop / Cursor / any MCP-capable agent verify any storefront URL is agentic-commer
