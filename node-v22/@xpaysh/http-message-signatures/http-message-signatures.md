# @xpaysh/http-message-signatures

> 标签: agentic-commerce, content-digest, ed25519, http-message-signatures, rfc-9421, signature, ucp

## 简介

RFC 9421 HTTP Message Signatures — sign and verify Signature, Signature-Input, and Content-Digest headers. Targets the component set UCP and agentic-commerce REST contracts use (@method, @target-uri, content-digest, idempotency-key). Ed25519 primary; HMAC
