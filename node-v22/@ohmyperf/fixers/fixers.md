# @ohmyperf/fixers

> 标签: core-web-vitals, fcp, fixers, inp, lcp, ohmyperf, patches, performance

## 简介

Structured patch archetypes for OhMyPerf opportunities. Given a measured report + an opportunity ID, emits { search, replace, rationale, expectedImpactMs } patches the propose_patch MCP tool returns.
