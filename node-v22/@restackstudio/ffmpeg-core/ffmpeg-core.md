# @restackstudio/ffmpeg-core

> 标签: ffmpeg, ffmpeg.wasm, hls, lgpl, mp4, remux, wasm

## 简介

LGPL build of the ffmpeg.wasm core (FFmpeg n5.1.4) for remuxing HLS/MPEG-TS, MP4 and AAC streams to MP4 without re-encoding. Drop-in for @ffmpeg/core 0.12 with @ffmpeg/ffmpeg.
