# retone

> 标签: chrome-extension, claude, codex, local-first, rewriting, threads, twitter

## 简介

Retone local helper — rewrite your X/Threads drafts with your own AI subscription (Claude/Codex/Antigravity CLI) or API keys. Zero-dependency companion server for the Retone Chrome extension.
