# rulemux-dsh

> 标签: agents-md, deepseek, dsh, dsh-plugin, harness, rulemux, rules

## 简介

rulemux rules inside DeepSeek Harness (dsh): asks the rulemux CLI for the rules it renders for this workspace and injects them into the session once, on the first turn (nothing written to disk for rules). Also syncs skills into the native skills dirs (.ds
