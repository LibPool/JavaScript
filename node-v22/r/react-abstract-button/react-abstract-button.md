# react-abstract-button

> 标签: JavaScript

## 简介

An abstract (unstyled) button element that dynamicly switches between a `<button>`, an `<a>` and a `<Link>` from [react-router](https://reacttraining.com/react-router/web/guides/philosophy). The idea is to make it easier for you to have a consistent style
