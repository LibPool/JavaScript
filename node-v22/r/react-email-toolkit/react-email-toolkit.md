# react-email-toolkit

> 标签: crm, django, email, email-automation, react, widget

## 简介

Drop-in React components (Composer, Templates, Logs) for django-email-toolkit. No Tailwind or CSS setup required — pair with the django-email-toolkit backend and this renders a full email-automation UI in any React/Next.js app.
