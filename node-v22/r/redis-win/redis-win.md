# redis-win

> 标签: bullmq, cache, developer-tools, in-memory, klority, lightweight, linux, lua, macos, npx, redis, redis-local, redis-server, redis-win, resp, streams, windows

## 简介

Ultra-lightweight Redis replacement for local development (Windows, macOS, Linux) with BullMQ, Lua scripting, Streams, and auto-persistence via npm/npx. Zero Docker required.
