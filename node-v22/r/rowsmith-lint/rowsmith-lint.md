# rowsmith-lint

> 标签: ci, fixtures, lint, test-data

## 简介

Local fixture linter: flags values in test fixtures and seed files that look like real emails, card numbers, phone numbers and US Social Security numbers, and suggests Rowsmith column types. Sends nothing anywhere.
