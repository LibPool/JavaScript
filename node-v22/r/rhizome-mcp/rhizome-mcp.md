# rhizome-mcp

> 标签: agent-coordination, ai-agents, claude-code, coding-agents, issue-tracker, lease, local-first, mcp, mcp-server, model-context-protocol, multi-agent, rhizome-mcp, sqlite, task-tracker

## 简介

Local-first MCP server for task tracking and coordination of autonomous AI coding agents. This package is a thin npm launcher around the platform-specific rhizome-mcp binary.
