# react-use-element-position

> 标签: React, bounding client rect, getBoundingClientRect

## 简介

A react package that returns a custom React hook that simplifies tracking the position of a DOM element within the viewport. It provides developers with an easy way to access the element's dimensions and position in real-time, utilizing the Intersection O
