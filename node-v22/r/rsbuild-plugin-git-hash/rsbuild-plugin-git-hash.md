# rsbuild-plugin-git-hash

> 标签: commit, git, hash, rsbuild, rsbuild-plugin, version

## 简介

rsbuild-plugin-git-hash 是一个Rsbuild插件，旨在为打包后的应用注入当前的Git Commit Hash
