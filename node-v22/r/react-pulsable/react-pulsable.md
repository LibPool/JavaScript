# react-pulsable

> 标签: pulsable, react, skeleton, skeleton-component, skeleton-content-loader, skeleton-effect, skeleton-loader, skeleton-loading

## 简介

This is a simple and customizable react component library to add a pulsing/skeleton loading effect to your existing component.
