# rushy-sdk

> 标签: JavaScript

## 简介

Один пакет для подключения чата Rushy к продукту: серверный вход `rushy-sdk/host` и React-хук `rushy-sdk/react`. Требуется Node.js 22 или новее. React нужен только клиентскому входу.

## 官网
