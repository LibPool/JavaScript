# reorg-safe-indexer

> 标签: blockchain, ethereum, ethers, events, evm, indexer, logs, reorg, reorganization, web3

## 简介

Lightweight, configurable blockchain event indexer with built-in chain reorganization handling. Idempotent processing, automatic rollback on reorgs, pluggable storage backends.
