# react-rubiks-cube

> 标签: 3d, animation, component, cube, hero, react, react-three-fiber, rubik, rubiks-cube, three, three-js

## 简介

A beautiful, self-solving 3D Rubik's Cube React component — auto scramble/solve loop, drag-to-turn interaction, and a fully themeable palette. Built on react-three-fiber.
