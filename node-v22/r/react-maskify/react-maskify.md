# react-maskify

> 标签: business-registration-number, codemod, credit-card, date, findDOMNode, format, hook, input, input-mask, korean, korean-phone, mask, masked-input, phone, react, react-18, react-19, react-hook-form, react-input-mask, react-input-mask-alternative, react-text-mask, react19, resident-registration-number, ssr, typescript, useMask

## 简介

Input mask component and hook for React 17-19. Maintained replacement for react-input-mask with a compat entry, Korean presets and a migration codemod. Zero dependencies, TypeScript.
