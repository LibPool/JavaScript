# react-native-save-to-calendar

> 标签: add-to-calendar, android, calendar, calendar-contract, eventkit, ios, new-architecture, react-native, turbomodule

## 简介

React Native module that opens the system add-event sheet on iOS and Android. Supports both the New and Legacy architectures. No calendar permission required — the OS handles its own permission prompt as part of the save flow.
