# react-native-latex-text

> 标签: expo, formula, latex, math, mathematics, mathjax, react-native, renderer, svg

## 简介

React Native/Expo LaTeX Formula Rendering Component, supports mixed typesetting of text and formulas, custom formula delimiters, automatic calculation of formula line height, based on MathJax SVG, built-in caching, no native dependencies. | React Native/E
