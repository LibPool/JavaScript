# recoengine

> 标签: deterministic, explainable, explainable-ai, personalization, plugin-architecture, ranking, recommendation, recommendation-engine, recommender, recsys, scoring, typescript

## 简介

Explainable recommendation engine for TypeScript, batteries included. Every recommendation carries the numbers that produced it. No AI, no model to train, no black box.
