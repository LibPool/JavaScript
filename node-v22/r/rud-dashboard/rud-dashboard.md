# rud-dashboard

> 标签: dashboard, drag-and-drop, grid, headless, layout, layout-engine, preact, react, resize, shadcn

## 简介

Headless dashboard layout engine: grid geometry, deterministic collision resolution, and layout serialization. Zero dependencies, no framework, no CSS.
