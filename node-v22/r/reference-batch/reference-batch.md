# reference-batch

> 标签: agent-skill, ai-skill, reference-batch

## 简介

输入论文标题 / DOI / 作者信息，一键批量生成 GB/T 7714、APA、MLA 等多格式参考文献条目，自动识别文献类型（期刊 / 学位论文 / 会议 / 图书 / 网络资源），输出可直接复制的参考文献列表。批量粘贴多篇文献标题、作者或 DOI 链接，自动识别类型并输出多种引用格式的完整清单，无格式错乱，可直接粘贴论文末尾。Use when the user asks for 参考文献批量生成、文献格式转换、GB/T7714、APA、MLA、DOI转引用、论文标题转引用、批量整理参考文献、文献类型
