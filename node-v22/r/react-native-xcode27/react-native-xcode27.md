# react-native-xcode27

> 标签: IPHONEOS_DEPLOYMENT_TARGET, cocoapods, deployment-target, expo, ios, ios-27, react-native, react-native-svg, scene-delegate, uiscene, xcode, xcode-27

## 简介

Build and launch React Native and Expo apps with Xcode 27. Fixes "deployment target is set to 12.4, but the range of supported deployment target versions is 15.0 to 27.0.x" in pods such as react-native-svg, the launch crash on iOS 16 and 17 from Swift C++
