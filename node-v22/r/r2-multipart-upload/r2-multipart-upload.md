# r2-multipart-upload

> 标签: aws4fetch, browser-upload, chunked-upload, cloudflare, cloudflare-r2, cloudflare-workers, direct-upload, edge, file-upload, framework-agnostic, hono, large-file-upload, multipart-upload, pause-resume, presign, presigned-url, r2, resumable-upload, s3, s3-compatible, serverless, signed-url, typescript, upload, upload-progress, webcrypto, workers

## 简介

Resumable multipart and presigned-URL direct uploads from the browser to Cloudflare R2, for Cloudflare Workers. Framework-agnostic server helpers (presign, multipart management) and a chunked upload engine with pause/resume and progress.
