# react-leaflet-v2-sidebar

> 标签: leaflet, leaflet-sidebar-v2, react, react-leaflet, react-leaflet-sidebar, react-leaflet-sidebar-v2, typescript

## 简介

This is a react hook for the [leaflet-sidebar-v2](https://www.npmjs.com/package/leaflet-sidebar-v2) package.\ It works with react-leaflet library.\ You can easily use this hook to add a sidebar to your react-leaflet map.
