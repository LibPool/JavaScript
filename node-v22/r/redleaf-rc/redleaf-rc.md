# redleaf-rc

> 标签: JavaScript

## 简介

- redleaf-rc 是一个轻量的，方便查看实现的组件库，没有层层封装，专注于满足最常用的功能 - redleaf-rc 提供了很多 CSS 变量，方便对组件进行样式定制，不需要进行复杂的 hack 就可以符合常用的定制需求
