# revise-sdk

> 标签: DNFT, NFT, dynamic, metadata, nft

## 简介

Revise is a protocol that enables building dynamic NFTs. It helps connect NFTs to real-world events and make them interactive. Revise sdk is like a Backend as a service for NFTs.
