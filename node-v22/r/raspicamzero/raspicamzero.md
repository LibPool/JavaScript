# raspicamzero

> 标签: camera, johnny-five, node, raspberry pi, raspicam, troyth

## 简介

Extension of Raspicam to support newever RPI versions similar to troyth, Original description: A Node.js-based controller module for the Raspberry Pi camera based on a command structure similar to Johnny-Five
