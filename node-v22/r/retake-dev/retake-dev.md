# retake-dev

> 标签: astro, devtools, mcp, nextjs, nuxt, prototype, react-router, remix, replay, sveltekit, time-machine, time-travel, vite, vite-plugin

## 简介

Retake: a time machine for your dev server (Vite, Next.js, React Router, Remix, Astro, SvelteKit, Nuxt). Drag back on a timeline and your app is at that moment; branch a new take from there.
