# reorg-cli

> 标签: agent, ai, cleanup, collaboration, directory, files, planner, reorganize, tree

## 简介

Plan directory reorganizations yourself or with an AI agent, collaborate through a live browser plan, and safely apply changes with generated undo scripts.
