# react-api-weaver

> 标签: api, cache, fetch, hooks, openapi, polling, react, react-19, suspense, swagger, typescript

## 简介

Convert OpenAPI YAML specs into typed React hooks with caching, polling, and cancellation support. Now with React 19 support!
