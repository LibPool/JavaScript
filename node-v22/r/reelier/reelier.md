# reelier

> 标签: agent, ai-agents, automation, ci, claude, deterministic, llm, mcp, mcp-server, record-replay, replay, skill.md, skills, snapshot-testing, testing, workflow

## 简介

Agents make claims, Reelier writes receipts - record an agent workflow once, replay it deterministically at 0 tokens, and get an asserted receipt on every run.
