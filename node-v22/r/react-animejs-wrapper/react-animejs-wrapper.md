# react-animejs-wrapper

> 标签: animation, animations, anime, anime.js, animejs, next, next.js, nextjs, react, react.js, reactjs, typescript, wrapper, wrapper-api

## 简介

A React wrapper for the Anime.js animation library. Allows for the quick and easy creation of powerful animations using React's JSX tags.
