# rhythmguard

> 标签: audit, cli, css, design-system, design-tokens, scss, spacing, spacing-scale, stylelint, tailwindcss

## 简介

The rhythmguard command: zero-config spacing-scale audit for CSS, SCSS and Tailwind. `npx rhythmguard` runs the CLI of stylelint-plugin-rhythmguard.
