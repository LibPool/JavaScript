# react-mediadrop

> 标签: drag-and-drop, dropzone, file-intake, file-upload, headless, react

## 简介

Headless React hook (useMediaDrop) for file intake, validation, drag/drop, and upload — @mediadrop/core is bundled in, no separate install needed. The xhr-upload transport is a separate, tree-shakeable "react-mediadrop/xhr-upload" subpath.
