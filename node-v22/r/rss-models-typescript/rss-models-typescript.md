# rss-models-typescript

> 标签: JavaScript

## 简介

This npm module provides rss-2.0 xsd models in typescript, generated by cxsd from https://raw.githubusercontent.com/ultraq/rss-xml-generator/master/Schema/RSS-2.0.xsd.
