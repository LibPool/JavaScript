# roozaneh

> 标签: calendar, drag-and-drop, event, event-calendar, jalali, persian, react, reactjs

## 简介

React wrapper for roozaneh: a fast, lightweight full-featured event calendar with drag & drop, supporting the Persian (Jalali) calendar and many more.
