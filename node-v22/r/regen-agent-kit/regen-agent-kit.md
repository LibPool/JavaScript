# regen-agent-kit

> 标签: agent, axelar, bridge, carbon, cosmos, ecological, governance, osmosis, refi, regen, regen-network, secp256k1, skip, x/data

## 简介

Drop-in kit that lets any AI agent drive the Regen Network chain (regen-1) with its OWN plain EVM secp256k1 key: govern (submit/vote), supply verified ecological work data (anchor/attest on x/data), and move REGEN between regen-1, Osmosis, Base and Arbitr
