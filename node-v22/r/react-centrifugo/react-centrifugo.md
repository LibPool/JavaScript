# react-centrifugo

> 标签: centrifugal, centrifuge, centrifugo, pubsub, react, react-hooks, react-native, real-time, realtime, ssr, subscriptions, typed-events, typescript, websocket

## 简介

React hooks for Centrifugo realtime messaging: shared WebSocket subscriptions, typed publications and events, connection state, and SSR-safe cleanup.
