# react-native-fieldflow

> 标签: android, autofocus, automatic-focus, avoidance, expo-compatible, fieldflow, focus-management, focusing next field, form, form-flow, form-management, input-chaining, input-focus, ios, keyboard, keyboard-accessory, keyboard-avoidance, keyboard-avoiding-view, keyboard-manager, react-native, react-native-form, reanimated, ref to next, scrollview, smooth-scrolling, textinput-focus

## 简介

High-performance React Native keyboard avoidance and zero-config focus chaining. Now featuring Chat Mode for WhatsApp-style chat inputs and 120fps synchronized accessory views on both iOS and Android.
