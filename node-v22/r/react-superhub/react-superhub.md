# react-superhub

> 标签: app-shell, brand-agnostic, css-variables, footer, header, layout, multi-zone, navbar, react, react-component, theme, typescript

## 简介

Brand-agnostic, configurable React app-shell primitives — Header, Footer, and a CSS-variable ThemeProvider. Framework-neutral links (bring your own <Link>), theming without Tailwind or any CSS framework.
