# react-smart-datetime

> 标签: a11y, accessible, calendar, dark-mode, date-picker, date-range, datepicker, datetime, datetime-picker, range-picker, react, react-component, time-picker, timepicker, typescript, zero-dependency

## 简介

A modern, accessible, zero-dependency React date & time picker with range selection, presets, time zones, dark mode, keyboard navigation, and full theming via CSS variables. No Tailwind or CSS framework required.
