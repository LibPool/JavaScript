# react-native-touchable-view

> 标签: animation, coordinate, direction, gesture, gesture animation, long press, react native touchable view, react native 手势响应控制, slide, x axis coordinates, x轴坐标, y axis coordinates, y轴坐标, 手势动画, 方向, 滑动, 滑动坐标

## 简介

你可以依赖这个TouchableView的长按,滑动,X轴滑动,Y轴滑动,长按后滑动等手势响应得到回调和一系列参数(如相对父组件x、y坐标,相对页面x、y坐标,x轴位移、y轴位移)处理你的业务(如手势动画)。
