# react-native-pointer-location

> 标签: android, crosshair, debugging, developer-tools, expo, fabric, gesture, ios, native-overlay, new-architecture, overlay, pointer, pointer-location, react-native, show-taps, tap, taps, touch, touch-indicator, touch-overlay, touch-visualizer, turbo-module, turbomodule

## 简介

Replicates Android's "Show Taps" and "Pointer Location" developer options on Android and iOS. Native global touch overlay with pass-through touches, crosshairs, gesture paths and real-time touch metrics.
