# react-native-signatures

> 标签: ReactNativeSignatures, expo, react-native, react-native-signatures

## 简介

Signature pad for React Native using platform-native 2D graphics (Core Graphics / Android Canvas / HTML Canvas) with signature_pad's velocity-based variable-width ink algorithm
