# react-native-lossless-trim

> 标签: android, avassetexportsession, expo, expo-module, ffmpeg-free, ios, lossless, mediamuxer, no-ffmpeg, passthrough, react-native, trim, video, video-editing, video-trim

## 简介

Lossless, ffmpeg-free video trimming for React Native and Expo. Stream-copy passthrough on the platform-native APIs (AVAssetExportSession / MediaMuxer): no re-encode, near-instant, ~zero binary weight.
