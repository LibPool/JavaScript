# reliastra

> 标签: cli, evidence, monitoring, reliastra, uptime, verification

## 简介

RELIASTRA command-line client: probes, verdicts, evidence records, public verification. Thin installer — downloads the platform binary from GitHub Releases on first run and verifies its SHA-256 before executing it.
