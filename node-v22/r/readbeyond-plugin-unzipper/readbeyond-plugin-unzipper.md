# readbeyond-plugin-unzipper

> 标签: cordova, cordova-android, cordova-ios, ecosystem:cordova, unzipper

## 简介

This plugin lists the entries in a ZIP file, decompresses a ZIP file, or one or more selected entries from a ZIP file.
