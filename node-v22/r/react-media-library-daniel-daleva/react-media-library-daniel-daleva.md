# react-media-library-daniel-daleva

> 标签: drag-and-drop, file-manager, file-manager-ui, filemanager, react, react-bootstrap, react-dom, reactjs

## 简介

Variation over React Media Library. This is a UI package similar to the WordPress media library, but for React. It features file drag-and-drop as well as a library to select previously uploaded files.
