# runnerize

> 标签: actions-runner, cd, ci, container, devops, ephemeral, github-actions, jit, podman, runner, self-hosted-runner

## 简介

Stateless, on-demand self-hosted GitHub Actions runners for your private repos: a dispatcher mints an ephemeral just-in-time runner per queued job and runs it in a throwaway rootless container.
