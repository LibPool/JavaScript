# repocrumb

> 标签: agent, ai, claude, claude-code, codex, context, crumb, cursor, developer-tools, handoff, llm, protocol

## 简介

The Crumb handoff protocol for coding agents. LOAD -> VERIFY -> WORK -> SAVE: a short last_crumb.md in your repo, anchored to a commit so you always know how much of it still applies, letting any AI coding agent pick up where the last one stopped across s
