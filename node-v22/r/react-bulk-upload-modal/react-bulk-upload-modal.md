# react-bulk-upload-modal

> 标签: batch-import, bulk-import, bulk-upload, csv-import, csv-parser, csv-to-json, csv-upload, data-import, data-validation, excel-import, excel-parser, excel-upload, file-upload, import-modal, inline-validation, react, react-component, react-csv, react-excel, react-file-upload, react-modal, reactjs, spreadsheet-import, xlsx-import, xlsx-upload

## 简介

Dependency-free React bulk upload modal for CSV & Excel (XLSX) import: parse, validate, fix errors inline, batch-import to your API, and show a results summary. No UI library required.
