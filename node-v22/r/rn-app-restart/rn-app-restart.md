# rn-app-restart

> 标签: i18n, new-architecture, react-native, reload, restart, rtl, turbomodule

## 简介

Restart your React Native app natively. True cold restart on Android, dev-menu-grade reload on iOS with a launch-screen overlay. Supports both the New Architecture (TurboModule) and the old architecture.
