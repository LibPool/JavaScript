# rn-project

> 标签: cnlc, cnlc-cli, cnlc-rn-cli, rn-cli

## 简介

#### 项目介绍 类似一个脚手架的工具 此项目致力于构建一套基础，简单，可维护的 适配我司的react-native项目。可在此基础上搭建项目，封装了基础架构，基础组件，以及各种交互等；可快速进行项目搭建，开发。 # 涉及主要技术 - 1. 项目主要架构     *  react native     * react-navigation     * redux
