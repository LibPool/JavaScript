# recaptcha-angular

> 标签: angular, checkbox, control-value-accessor, google-recaptcha, recaptcha, recaptcha-v2, recaptcha-v3, standalone, typescript

## 简介

Lightweight Angular reCAPTCHA v2 (checkbox) and v3 (score-based) component with TypeScript, standalone APIs, and ControlValueAccessor (ngModel / reactive forms) support
