# responseinterceptor

> 标签: async, buffer, configuration, content-type, custom logger, environment, error handling, express, intercept, middleware, monitoring, override, override response, propertiesmanager, res.end, res.render, res.send, res.write, response, status code

## 简介

This package allows intercept an express response ( res.send , res.end , res.write ) and update or upgrade response with your other logic
