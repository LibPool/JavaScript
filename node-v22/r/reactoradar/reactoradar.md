# reactoradar

> 标签: debugger, devtools, electron, flipper-alternative, hermes, macos, network-inspector, react-native, reactoradar, redux

## 简介

macOS debugger for React Native — Console, Sources, Network, Performance, Memory, Redux, AsyncStorage, React tree. Supports RN 0.74+ with Hermes and New Architecture.
