# react-slow-render-radar

> 标签: React.memo, debug, devtools, overlay, performance, profiler, re-render, react, slow-render, useMemo

## 简介

Dev-only overlay that detects React components re-rendering too often and shows a pulsing red dot with an actionable fix suggestion.
