# rvlib-mdwiki

> 标签: JavaScript

## 简介

Markdown-wiki tooling for Bun repos: a CLI (serve a live force-directed graph of your wiki's links, lint for orphan pages + dangling refs) and the same as a library. Self-contained page — no deps, no CDN.
