# rtl-for-claude

> 标签: arabic, asar, claude, claude code, codex, electron, farsi, hebrew, patcher, persian, right-to-left, rtl, urdu, vazirmatn

## 简介

Right-to-left text (Persian, Arabic, Urdu, Hebrew …) and the Vazirmatn font in the Claude Desktop app and the Claude Code / Codex chats. One command, 100% local, fully reversible.
