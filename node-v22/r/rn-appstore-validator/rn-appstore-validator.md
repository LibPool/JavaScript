# rn-appstore-validator

> 标签: app-store, apple, automation, ci-cd, compliance, guidelines, ios, linting, mobile, privacy, react-native, submission, validation

## 简介

A comprehensive validation tool that checks React Native builds against Apple App Store submission requirements to catch potential rejection issues before submission.
