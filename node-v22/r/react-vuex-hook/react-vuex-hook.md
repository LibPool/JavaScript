# react-vuex-hook

> 标签: hook, react, react-vuex, reducer, state, store, typescript, useReducer, vuex

## 简介

react-vuex-hook是利用React Hook配合Context和useReducer封装的一个用于小型模块的状态管理库，提供类似vuex的语法。
