# react-native-root-jail-detect

> 标签: android, android-root, anti-debug, anti-tampering, debugger-detection, device-integrity, emulator-detection, frida-detection, hook-detection, instrumentation-detection, integrity, ios, ios-jailbreak, jailbreak, jailbreak-detection, mobile-app-security, mobile-security, react-native, root, root-detection, runtime-security, security, security-sdk, simulator-detection, tamper-detection

## 简介

A lightweight and reliable React Native library to detect rooted Android devices and jailbroken iOS devices using modern Kotlin, Swift, and TypeScript. Built for security-focused mobile applications.
