# rag-demo

> 标签: JavaScript

## 简介

Acme Corp support agent with vector RAG retrieval. Demonstrates the full vector path: `Document -> Chunker -> Embedder -> VectorStore -> VectorRetriever -> createVectorRetrievalTool -> Agent -> Runtime -> Hono`.
