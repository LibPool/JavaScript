# restquick

> 标签: API generator, Django REST, Express.js, NestJS, Node.js, REST API, cli tool, project scaffolding, starter templates, template generator, typescript

## 简介

A powerful CLI tool to quickly generate REST API starter templates for Node.js and Django projects, including Express.js, NestJS, and more.
