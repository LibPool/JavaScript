# react-sheet-uploader

> 标签: csv, data-import, dromo, excel, flatfile, importer, react, spreadsheet, uploader, xlsx

## 简介

Open-source, embeddable spreadsheet importer for React. Drop-in compatible with the Dromo uploader API: same fields schema, settings, row/bulk/column/step hooks, and results shape.
