# reqexd

> 标签: include, module, require

## 简介

equivalent of require, but in another dir than node_modules to be able to version custom modules

## 官网

- 官网：https://github.com/idcware/node-require-externaldir
- 源码仓库：https://github.com/idcware/node-require-externaldir.git
- npm 页面：https://www.npmjs.com/package/reqexd
