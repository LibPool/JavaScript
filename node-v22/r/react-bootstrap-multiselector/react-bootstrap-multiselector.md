# react-bootstrap-multiselector

> 标签: Bootstrap Multiple Select, Multiple Checkbox, Multiple Select, Multiple Select DropDown, React Bootstrap Multiple Select, React Multiple Select

## 简介

- Provide  multiple select dropdown for any array of data - Sorting on demand ascending/descending - Filter by key press and you are able to active and inactive filter - Customize the placeholder name  - return the multiple checked object of array
