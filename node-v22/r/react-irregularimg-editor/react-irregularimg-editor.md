# react-irregularimg-editor

> 标签: canvas, clip, components, crop, editor, freeform, image, irregular, mask, polygon, react, typescript, ui

## 简介

A React + TypeScript component for cropping and masking images into irregular shapes — freeform/polygon crop, preset shape masks, rotate/zoom/reposition adjustments, and PNG/SVG export.
