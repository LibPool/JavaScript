# retry-wire

> 标签: 429, ai, anthropic, backoff, fetch, llm, openai, rate-limit, resilience, retry, throttle, typescript

## 简介

Provider-aware retry and throttle for LLM API calls — a tiny, zero-dependency wrapper around fetch or any async call that understands OpenAI and Anthropic rate-limit semantics (429, 529 overloaded, Retry-After, x-ratelimit-*).
