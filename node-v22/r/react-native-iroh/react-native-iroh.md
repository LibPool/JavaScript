> 标签: blobs, file-transfer, hole-punching, iroh, iroh-blobs, networking, nitro, nitro-module, p2p, peer-to-peer, quic, react-native, react-native-iroh, rust

## 简介

iroh for React Native: direct Rust bindings to the iroh peer-to-peer networking stack (QUIC, hole punching, relays) and iroh-blobs, via Nitro Modules
