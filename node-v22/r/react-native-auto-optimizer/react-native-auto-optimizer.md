# react-native-auto-optimizer

> 标签: android, flatlist, images, ios, jank, network, new-architecture, optimizer, performance, react-native

## 简介

Find React Native jank at runtime (long JS tasks, heavy lists, oversized images, duplicate fetches) and apply conservative fixes that roll back if they make the app worse
