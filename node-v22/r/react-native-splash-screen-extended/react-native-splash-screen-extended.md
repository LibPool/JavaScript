# react-native-splash-screen-extended

> 标签: android, ios, launch-screen, launchscreen, react-native, react-native-component, react-native-splash-screen, splash, splash-screen, splashscreen

## 简介

A splash screen for react-native, hide when application loaded, it works on iOS and Android. Forked from react-native-splash-screen of crazycodeboy. Modify to check & show app version on Android.
