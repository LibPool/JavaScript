# react-router-v6-class-props

> 标签: react router v6 for class component, react router v6 for class param, react router v6 navigation props, react-router-v6, react-router-v6 for class component, react-router-v6-class, react-router-v6-class-component, react-router-v6-class-props, react-router-v6-class-support

## 简介

A package that provides class component support for React Router v6 and enables navigation with additional props. Now You can navigate to other screens with `data` using the `navigate` method.
