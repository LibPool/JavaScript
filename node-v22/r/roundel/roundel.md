# roundel

> 标签: ansi, chalk, cli, color, colour, extensible, json, non-tty, picocolors, plugin, plugins, style, styleText, terminal, theme, zero-dependency

## 简介

The colours a CLI carries. One output policy, semantic tokens, a theme, and a chalk migration path lighter than chalk. Zero dependencies.
