# ready-table

> 标签: color, table

## 简介

node版本 14.15.4 ## 说明 完备表组件，封装一些常见的逻辑，开箱即用。具有如下功能： * 树结构;  * 自定义样式;  * 双击单元格直接编辑;  * 大数据量导出，[见常见问题解决方案](https://github.com/jingyuLin1999/ready-table#%E5%B8%B8%E8%A7%81%E9%97%AE%E9%A2%98%E8%A7%A3%E5%86%B3%E6%96%B9%E6%A1%88);  * 增、删、改、查、导入、导出、全屏放大、字段显
