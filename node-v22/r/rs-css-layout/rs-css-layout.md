# rs-css-layout

> 标签: JavaScript

## 简介

Bootstrap 提供了一套响应式、移动设备优先的流式栅格系统，随着屏幕或视口（viewport）尺寸的增加，系统会自动分为最多12列。它包含了易于使用的预定义类。根据实际的使用体验，我们扩展了原本的12栅格系统，进化为`24栅格`系统。
