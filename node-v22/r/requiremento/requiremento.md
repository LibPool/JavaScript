# requiremento

> 标签: acceptance-criteria, bdd, domain-driven-design, gherkin, json, requirements, specification-by-example, ubiquitous-language

## 简介

Living requirements as JSON: shared terms, one requirements file per ticket, viewers/editors and checkers. No dependencies.
