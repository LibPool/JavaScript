> 标签: agent-memory, ai-agents, claude, claude-code, fts5, full-text-search, mcp, model-context-protocol, search, session-history, sqlite, transcripts

## 简介

Grep for everything your AI coding agents ever did. Local SQLite/FTS5 search over Claude Code session transcripts: CLI, MCP server, and web UI.
