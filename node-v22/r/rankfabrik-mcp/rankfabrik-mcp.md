# rankfabrik-mcp

> 标签: captions, email-verification, jobs, local-business, mcp, model-context-protocol, places, rankfabrik, subtitles, transcript, transcription, youtube

## 简介

Canal MCP de RankFabrik : les 4 APIs de données publiques (Captions/transcription YouTube, Places/établissements, Jobs/emplois, Verify/vérification d'e-mails) exposées comme outils MCP. Serveur mince qui appelle les façades REST facturées.
