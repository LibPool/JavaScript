# rmmd

> 标签: abbr, cli, dfn, html, mark, markdown, micromark, remark, semantic-html, unified

## 简介

Convert Markdown to HTML, with syntax for the semantic inline elements Markdown leaves out: mark, dfn, s, sup, sub, cite, q, abbr. Built on unified.
