# rn-inputforge

> 标签: bare-react-native-cli, bottom-sheet, chat-input, dropdown, form, form-builder, input, keyboard-aware, multi-select, react-native, select, textinput, typescript, validation

## 简介

A production-ready, highly customizable input field system for React Native (bare CLI) — text/email/number/phone/password/search fields, description fields, chat input, and a single/multi-select dropdown (bottom sheet, popup, or inline), with built-in val
