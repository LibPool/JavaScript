# rs-data-grid-vanilla

> 标签: data-grid, grid, table, vanilla-js

## 简介

A configurable data grid component for plain JavaScript -- filtering, sorting, pagination, inline/popup/batch editing, drag-and-drop, and Excel/PDF export. No framework required.
