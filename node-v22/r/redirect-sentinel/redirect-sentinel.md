# redirect-sentinel

> 标签: appsec, cli, crawler, github-action, https, mixed-content, netlify, open-redirect, redirect, sarif, security, static-site, vercel, web-security

## 简介

Find open redirects and mixed content in a built site or a live crawl: http:// scripts, styles, frames and images on HTTPS pages, insecure forms, client-side redirects fed by URL parameters, open redirect rules in _redirects/vercel.json, HTTPS downgrades,
