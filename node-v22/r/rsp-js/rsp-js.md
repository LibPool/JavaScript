# rsp-js

> 标签: RDF, RDF Stream Processing, RSP, Semantic Web

## 简介

An RDF Stream Processing Library for Javascript built on top of [N3.js](https://github.com/rdfjs/N3.js/) and [Comunica](https://comunica.dev/)
