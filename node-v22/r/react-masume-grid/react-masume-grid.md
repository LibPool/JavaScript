# react-masume-grid

> 标签: clipboard, data-grid, datagrid, editable, excel, grid, ime, japanese, japanese-input, react, react-component, spreadsheet, table, virtualized

## 简介

A lightweight React spreadsheet grid with Japanese IME-friendly cell editing, Excel-compatible clipboard, sorting, filtering, and row virtualization. React is the only dependency (~12.5KB gzipped).
