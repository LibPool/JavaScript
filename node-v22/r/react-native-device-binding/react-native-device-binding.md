# react-native-device-binding

> 标签: android-keystore, attestation, biometric, cryptography, device-binding, ecdsa, hardware-security, p256, react-native, secure-enclave

## 简介

Hardware-backed ECDSA P-256 device binding for React Native. Keys stored in Secure Enclave (iOS) and Android Keystore.
