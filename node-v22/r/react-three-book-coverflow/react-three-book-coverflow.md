# react-three-book-coverflow

> 标签: 3d, book, carousel, coverflow, drei, gallery, r3f, react-three-fiber, three, threejs

## 简介

A looped 3D coverflow carousel for react-three-fiber — drag, scroll, idle auto-drift, and click-to-center — with a built-in procedural hardcover book. Render any 3D item.
