# repoctx

> 标签: agent, ai, claude, cli, codebase, context, developer-tools, llm, tokens

## 简介

Structured context layer for AI coding assistants. Reduces token cost and exploration overhead by storing file summaries, symbol cards and git diffs in .repoctx/
