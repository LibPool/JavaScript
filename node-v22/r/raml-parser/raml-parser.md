# raml-parser

> 标签: JavaScript

## 简介

A RAML parser based on PyYAML written in CoffeScript and available for use as NodeJs module or in-browser.

- 官网：https://github.com/raml-org/raml-js-parser#readme
- 源码仓库：git+ssh://git@github.com/raml-org/raml-js-parser.git
