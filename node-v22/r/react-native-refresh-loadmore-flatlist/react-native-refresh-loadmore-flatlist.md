# react-native-refresh-loadmore-flatlist

> 标签: FlatListRefresh, React Native, loadmore, react-native-refresh-loadmore-flatlist, refresh

## 简介

基于React Native官方组件FlatList，增加可定制化“下拉刷新”、“下拉加载更多”组件API的新列表组件，具体实现功能如下： * 自定义下拉刷新组件API * 自定义上拉LoadMore组件API
