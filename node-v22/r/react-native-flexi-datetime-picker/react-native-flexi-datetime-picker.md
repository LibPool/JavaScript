# react-native-flexi-datetime-picker

> 标签: android, calendar, date-picker, datetime-picker, ios, modal, react-native, time-picker

## 简介

All-in-one Date and Time picker for React Native. Combines react-native-flexi-date-selector and react-native-flexi-time-selector.
