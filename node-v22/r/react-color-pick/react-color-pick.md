# react-color-pick

> 标签: chrome, color picker, colorpicker, material design, photoshop, picker, popup, react, react-component, sketch

## 简介

A Collection of Color Pickers from Sketch, Photoshop, Chrome & more. Modified original Twitter picker to accept extra prop i.e isEditable so that Editable component can be rendered based on boolean value of this prop.
