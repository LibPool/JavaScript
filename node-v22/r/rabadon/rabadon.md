# rabadon

> 标签: agent-recovery, ai-agents, claude-code, coding-agent, compound-error, hooks, reliability, self-healing

## 简介

rabadon catches your coding agent's error before it compounds, and fixes it. It runs inside the live session, sees the error in the move that makes it, and hands the agent what the agent cannot see: what actually broke, and where this attempt diverges fro
