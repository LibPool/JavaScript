# recodey-shield

> 标签: ai, ci, cli, code-scanner, devops, recodey, sarif, sast, secret-detection, security, security-scanner, shield, vulnerability

## 简介

CLI-first launch-readiness scanner for JavaScript and TypeScript projects. Detects secrets, misconfigurations, risky dependencies, and code vulnerabilities, then tells you if you can ship.
