# retypeset-odyssey

> 标签: agent-skill, ai-friendly, astro, astro-theme, blog, i18n, llms-txt, retypeset, theme, typography

## 简介

Trilingual (zh/en/ja) Astro blog theme, usable as a standalone template or an installable npm package for content-only repos. Forked from astro-theme-retypeset; adds npm packaging, folder-based collections, Hexo migration, and agent-facing docs (AI_USAGE.
