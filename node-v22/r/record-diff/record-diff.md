# record-diff

> 标签: JavaScript

## 简介

> 一个对比两个记录集的差异的工具包，根据指定 keyName 来对比两条记录，并可分析出差异路径。 > - 可设置忽略某个键值 > - 支持是否全等对比 > - 输出差异节点路径 > - 细分变更类型，按新增，修改，删除
