# rvlib-i18n

> 标签: JavaScript

## 简介

Type-safe i18n the simple way: the EN dict is the source of truth, every locale typechecks against it (missing keys and wrong interpolation args are compile errors), one mobx-observable singleton holds the persisted locale. No framework, no ICU, no catalo
