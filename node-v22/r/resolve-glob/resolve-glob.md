# resolve-glob

> 标签: absolute, dir, directory, expand, expansion, file, filepath, glob, is, is-absolute, is-glob, pattern, resolve, tilde

## 简介

Ensures that absolute file paths are always returned from a glob pattern or array of glob patterns.
