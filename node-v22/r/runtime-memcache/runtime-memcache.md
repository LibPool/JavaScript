# runtime-memcache

> 标签: cache, javascript cache, js cache, js hash, key store, lru, memory cache, mru, node cache, runtime cache, timeout

## 简介

A no dependency javascript runtime key-value cache store for small chunks of arbitrary data (strings, objects, numbers)
