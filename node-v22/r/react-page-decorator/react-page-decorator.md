# react-page-decorator

> 标签: decorations, design-tool, drag-and-drop, editor, nextjs, overlay, react

## 简介

Drag-and-drop visual placement of images/illustrations anywhere on a React page. Dev editor + ships-in-code renderer, responsive per-breakpoint placements, pluggable persistence (localStorage / REST file).
