# remote-cp-node

> 标签: agent, binding, child_process, drop-in, exec, http, remote, spawn, ssh

## 简介

Node.js child_process-compatible module backed by HTTP. Drop-in replacement for require('child_process') that routes exec/spawn to a remote server — non-interactive SSH exec replacement.
