# react-lzy-img

> 标签: accessibility, blurhash, bundle-size, fade-animation, image-performance, intersection-observer, lazy-image, lazy-loading, lazyload, lightweight, lqip, modern-images, performance, picture-element, placeholder, progressive-image, react, react-component, react-hook, responsive-images, srcset, tree-shakeable, typescript, webp

## 简介

Lightweight (~1.4KB gzipped) React lazy loading library with responsive images, blurhash placeholders, and TypeScript support. Simple, fast, and feature-complete.
