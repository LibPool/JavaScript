# rain-sdk-v2

> 标签: account-abstraction, alchemy, rain, smart-account, viem, web3

## 简介

Rain SDK V2 — TypeScript SDK for Rain prediction markets on Arbitrum. Market creation, trading, liquidity, order book, split/merge, dispute, and smart account support.
