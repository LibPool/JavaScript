# react-skeletonix

> 标签: auto-generated, content-loader, content-placeholder, dynamic, ghost-elements, loading, loading-states, placeholder, pulse, react, react-loading-skeleton, react-skeleton-loader, shimmer, skeleton, skeleton-loader, skeleton-screen, skeleton-ui, skeletonix, typescript, ui, ux, ux-design, zero-config

## 简介

The smartest and most performant React skeleton loader. Automatically generates high-fidelity skeleton screens and loading placeholders from existing components with zero configuration. Supports shimmer, pulse, wave, and blink animations for superior UX.
