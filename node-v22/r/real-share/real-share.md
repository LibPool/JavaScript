# real-share

> 标签: agnostic, application, bind, call, eventsourcing, framework, independent, microservice, procedure, remote, remote procedure call, rest, rpc, rpclib, rpclibrary, tunnel, unified application framework

## 简介

Call a remote function or method of a remote object from a Node.js App thru websocket that can be shared to any web frontend frameworks or mobile apps
