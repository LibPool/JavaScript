# react-mui-tooltip-ifz

> 标签: material-ui, mui, mui-tooltip, react, react-component, react-mui-tooltip, react-tooltip, text-overflow, tooltip, truncate, typescript

## 简介

A lightweight React tooltip component for Material-UI (MUI v5) that only appears when text is truncated. Ideal for showing overflowed text automatically.
