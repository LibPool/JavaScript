# robinhood-chain-mcp

> 标签: ai-agent, arbitrum-orbit, blockchain, claude, dexscreener, erc20, ethereum, layer2, mcp, mcp-server, model-context-protocol, modelcontextprotocol, read-only, robinhood, robinhood-chain, viem

## 简介

Read-only MCP server for Robinhood Chain. Lets any AI agent query chain state, ERC-20 tokens, DEX pairs, and verify token addresses against ticker-collision scams. Never signs or sends transactions.
