# runtyp

> 标签: javascript, joi, joi-like, myzod, runtime, type, typescript, validation, zod

## 简介

Lightning-fast, zero-dependency runtime validation for TS/JS. ~14x faster and 15x smaller than zod (4kb vs 60kb gzipped).
