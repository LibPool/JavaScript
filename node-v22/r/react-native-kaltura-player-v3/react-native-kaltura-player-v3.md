# react-native-kaltura-player-v3

> 标签: kaltura, player, playkit, react, react-native, video

## 简介

KalturaPlayer is React Native component for both iOS and Android. Uses sdk v2 for iOS and newest Playkit for Android. Player on android has offline playback build in.
