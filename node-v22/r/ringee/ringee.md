# ringee

> 标签: agent, calls, cli, contacts, mcp, ringee, telephony, voip

## 简介

The `ringee` CLI — operate Ringee (contacts, leads, campaigns, call sessions, callbacks, meetings, DNC and call analytics) from the terminal, on top of the Ringee backend/MCP. Usable from any agent harness (Claude Code, OpenClaw, Hermes, …).
