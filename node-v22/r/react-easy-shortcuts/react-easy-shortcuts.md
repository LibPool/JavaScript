# react-easy-shortcuts

> 标签: JavaScript

## 简介

An very easy to use, PubSub like, React library to listen to keyboard shortcuts in your components

- 源码仓库：https://github.com/IvoFritsch/react-easy-shortcuts.git
- npm 页面：https://www.npmjs.com/package/react-easy-shortcuts
