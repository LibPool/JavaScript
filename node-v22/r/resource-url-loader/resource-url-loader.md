# resource-url-loader

> 标签: JavaScript

## 简介

Webpack 环境下的静态资源文件加载器。 得益于 [file-loader]()的构建思路，允许被引用文件base64进引用文件内，保留 webpack publicPath 生成逻辑，同时解决 url-loader 显式指定[path]和[context]无法正确解析引用文件和被引用文件相对位置关系问题。
