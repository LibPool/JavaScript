# react-test-renderer-helper

> 标签: JavaScript

## 简介

enzyme 是一个非常好的 React 测试库，不过随着 React 近期的快速迭代，enzyme 的更新已经落后于官方的 react-test-renderer，所以我们只需要为 react-test-renderer 添加扩展，满足绝大部分 React 测试所需，就可以享受最新的 React 功能。
