# react-kerala-map

> 标签: constituency, election-results, elections, geojson, kerala, leaflet, local-body, map, react, wards

## 简介

Interactive React map of Kerala for exploring districts, local bodies, wards and constituencies (Lok Sabha / State Assembly) with search. Party/alliance colouring is intentionally excluded; electoral results and constituency data are opt-in via showElecti
