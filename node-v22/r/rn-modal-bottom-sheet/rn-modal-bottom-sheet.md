# rn-modal-bottom-sheet

> 标签: action-sheet, actionsheet, android, animated, bottom-sheet, bottomsheet, drag-to-close, drawer, expo, gesture, ios, modal, modal-sheet, pull-to-collapse, react-native, react-native-bottom-sheet, react-native-modal, rn-modal-bottom-sheet, scroll-to-expand, sheet, slide-up, snap-points, typescript

## 简介

rn-modal-bottom-sheet - A performant, gesture-enabled bottom sheet component for React Native with snap points, scroll-to-expand, and pull-to-collapse. Zero native dependencies, works with Expo.
