# rules-linter

> 标签: MUSE.md, ai-agents, cli, code-quality, cursorrules, lint

## 简介

Lint AI coding-agent rules files (MUSE.md, .cursorrules, AGENTS.md) against repo reality: contradictions, vague rules, stale paths. Read-only, zero dependencies, no telemetry.
