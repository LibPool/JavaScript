# react-glb-viewer

> 标签: 3d, glb, gltf, model-viewer, react, sketchfab, three, threejs, viewer

## 简介

React component for viewing GLB/glTF models with three.js: URL fallbacks and proxying, byte progress, retry, auto-framing, and support for old Sketchfab spec-gloss materials.
