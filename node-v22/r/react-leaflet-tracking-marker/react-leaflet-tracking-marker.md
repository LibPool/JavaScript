# react-leaflet-tracking-marker

> 标签: drift marker, drift-marker, leaflet, leaflet bearing marker, leaflet drift marker, leaflet marker, leaflet moving marker, leaflet rotating marker, leaflet sliding marker, leaflet-drift-marker, leaflet-moving-marker, marker, moving, react, react leaflet marker, react-leaflet-v3, rotated, sliding marker

## 简介

React Leaflet marker that drifts to a certain point, computes its bearing angle using coordinates and rotates accordingly.
