# react-offsets

> 标签: JavaScript

## 简介

This package contains `useNodeOffsets` hook that accepts a React ref as parameter. It returns the `{ offsetWidth, offsetHeight }` of the ref even it exists within an invisible tree of elements (default browser behavior : `{ offsetWidth: 0, offsetHeight: 0
