# rivulet-redis

> 标签: consumer-groups, monitoring, realtime, redis, redis-streams, streams, visualizer, websocket

## 简介

Realtime, animated, read-only visualizer for Redis Streams: streams, consumer groups, lag and pending entries in motion.
