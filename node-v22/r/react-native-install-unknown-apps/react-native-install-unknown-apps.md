# react-native-install-unknown-apps

> 标签: android, android apk install, android permissions, apk installer, apk manager, app install permission, external apk install, install external apps, install unknown apps, mobile app permissions, permissions, react-native, react-native android permissions, react-native apk installer, unknown sources

## 简介

A lightweight React Native library to manage and enable the 'Install Unknown Apps' permission on Android devices. Ideal for apps that need to install APK files from external sources.
