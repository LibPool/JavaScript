# rrule-by-pattern

> 标签: calendar, dates, icalendar, pattern, plan, recurrences, rfc, rrule, schedule, shifts, template

## 简介

Build rrules by patterns / templates like '111100' (i.e. 4 on, 2 off). rrule.js extension.
