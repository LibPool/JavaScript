# react-wizard-engine

> 标签: a11y, accessibility, branching, checkout, flow, form, form-wizard, headless, headless-ui, multi-step, nextjs, onboarding, radix-ui, react, react-stepper, react-wizard, react18, react19, shadcn, signup-flow, stepper, tailwind, typescript, wizard

## 简介

Headless multi-step wizard engine for React with categories, branches, pluggable strategies, async navigation, and a shadcn-compatible styled adapter.
