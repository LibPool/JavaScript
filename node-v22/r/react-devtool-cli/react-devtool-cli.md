# react-devtool-cli

> 标签: agent-tooling, browser-automation, cli, component-tree, debugging, inspection, playwright, react, react-devtools, react-profiler

## 简介

Agent-first CLI for React component tree inspection, snapshot-aware node debugging, and profiler analysis through a Playwright-managed browser session.
