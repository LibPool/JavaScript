# ram-react-modal

> 标签: animation, component, context, hooks, modal, on closing confirmation, originating, react, scale-up, triggering, typescript

## 简介

A lightweight and customizable React modal with TypeScript support. Includes a dynamic scale-up animation that starts from the trigger element, support for stacking modals, and an optional confirmation step before closing.
