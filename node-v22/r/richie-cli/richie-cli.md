# richie-cli

> 标签: JavaScript

## 简介

richie-cli是一个快速生成Ant Design Pro 实例项目的生成器，类似于vue-cli。将richie-cli安装在全局环境下，提供了终端里的 `richie`命令。

- 官网：https://github.com/RichieChoo/richie-cli#readme
- 源码仓库：git+https://github.com/RichieChoo/richie-cli.git
- npm 页面：https://www.npmjs.com/package/richie-cli
