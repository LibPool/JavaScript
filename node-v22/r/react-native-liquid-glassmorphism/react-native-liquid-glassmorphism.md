## 简介

Liquid Glass for React Native on Android AND iOS — not an iOS-only wrapper. Apple's native UIGlassEffect on iOS 26, real-time AGSL refraction shader on Android 13+, from one <LiquidGlassView>. Glassmorphism, frosted glass, glass blur, custom shapes. Expo
