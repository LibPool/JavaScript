# react-paginated-multiselect

> 标签: async-search, autocomplete, customizable, debounce, dropdown, infinite-scroll, large-dataset, lightweight, multiselect, pagination, react, virtual-scroll

## 简介

A lightweight React multi-select dropdown with infinite scroll, server-side pagination, and async search. Zero UI framework dependencies - fully customizable styles.
