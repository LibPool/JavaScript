# react-locale-formatted-input

> 标签: controlled-input, currency-input, decimal-input, format, formatted-input, i18n, input, locale, localized-input, number-format, numeric-input, percent-input, price-input, react, thousand-separator

## 简介

A locale-aware formatted input component for React. Supports price, percent and custom numeric formats with thousand separators and configurable fraction digits.
