# react-a11y-doctor

> 标签: a11y, accessibility, alt-text, aria-label, astro, automatic-fix, eslint, nextjs, prettier, react, reactjs, remix, typescript, vite, wcag, wcag-compliance

## 简介

Automated accessibility fixes for React projects. Scans JSX/TSX and build output HTML to auto-fix missing alt, aria-label, role, tabIndex, SVG title and more.
