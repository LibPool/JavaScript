# react-jalali-gregorian-date-picker

> 标签: JavaScript

## 简介

The JalaliGregorianDatePicker component is a date picker designed for use in React applications. It allows users to select dates from both the Jalali and Gregorian calendars, offering flexibility and ease of use. ## Installation
