# react-modern-audio-player

> 标签: a11y, accessible, audio, audio-player, customizable, dark-mode, html5-audio, modern-ui, music-player, nextjs, playlist, react, react-audio-player, react-component, react-music-player, react-waveform, typescript, waveform, wavesurfer, wavesurfer-react, web-audio

## 简介

Modern, customizable React audio player with waveform visualization, drag-and-drop playlist, WAI-ARIA accessibility, TypeScript-first API, and Next.js App Router (Server Components) support.
