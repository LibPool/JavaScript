# rte

> 标签: basename, blog, directory, dirname, ext, extname, filepath, fs, link, path, permalinks, post, rename, rewrite, rewriting, route, routes, routing, uri, url, url-routing

## 简介

Simple filepath re-writing for node.js projects. Useful for re-writing paths in grunt/gulp/assemble tasks or plugins.
