# react-mathtex

> 标签: LaTex, TailwindCSS, blog, math, react, react-katex

## 简介

A React component  build using React-Katex and styled with TailwindCSS, to show LaTex content from text written in a simple format. It can be integrated from an form containing an input-text or using for a blog interface.
