# react-withquerytoggler

> 标签: JavaScript

## 简介

This is a React Higher Order Component (HOC), which lets you toggle values in the url. For example: when you have something like a filterbar in your app, which fetches new data React's `componentDidUpdate` lifecycle based on the url and its query string p
