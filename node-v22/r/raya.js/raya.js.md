# raya.js

> 标签: audio, discord, discord-bot, discord.js, eris, lavalink, lavalink-client, lavalink-v4, music, music-bot, nodelink, oceanic, raya

## 简介

A fast, resilient Lavalink v4 client for Node.js: session resuming, restart-proof players, automatic failover, queue, filters, autoplay, voice channel status and a live now-playing feed.
