# reduxboilergen

> 标签: react-redux

## 简介

Generated Boiler Plate Code for React-Redux. This can be used when you have API calls that needs to have an Request, Response, Error states during different lifecyle of the API call. This is a Command Line tool which will generate the Boiler Plate pattern
