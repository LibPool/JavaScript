# raccount-sso

> 标签: edge, nextjs, oauth2, pkce, raccount, sso, webhooks

## 简介

Node.js/TypeScript SDK for RAccount SSO — OAuth 2.0 authorization code + PKCE client, webhook verifier, and Next.js App Router route handlers.
