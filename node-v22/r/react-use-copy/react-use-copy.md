# react-use-copy

> 标签: clipboard, clipboard-api, copy, copy-to-clipboard, hook, javascript, react, react-hook, typescript, use-copy, useCopy

## 简介

A lightweight, zero-dependency React hook for copying text to the clipboard with full TypeScript support, configurable timeout, copied state, and error handling.
