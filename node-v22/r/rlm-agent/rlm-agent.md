# rlm-agent

> 标签: context, hermes, hermes-agent, kernel, opencode, pi, pi-mono, python, recursive-language-model, rlm, subagents

## 简介

RLM (Recursive Language Model) for any editor: persistent Python kernel, context lake, and background subagents that keep large data out of the LLM prompt. One repo, one installer, per-editor adapters.
