# reborn-cli-anything

> 标签: agent-native, agent-skills, claude, claude-code, cli-anything, cli-hub, korean, mcp, skill

## 简介

영상에서 소개한 CLI-Anything(HKUDS) 을 원저자 저장소에서 받아 깔고, 한국어 안내 스킬을 같이 심습니다. 깔기 전에 막히는 조건 둘(파이썬 · 감싸는 프로그램)을 먼저 알려 주고, 소개 영상들이 화면에 띄운 「토큰 N배」가 원문에 실제로 있는지 --audit 으로 직접 세어 보여 줍니다.
