# react-native-thermal-label-printer

> 标签: android, ios, react-native

## 简介

Bluetooth and WiFi thermal label printer for React Native. Supports CPCL, ZPL, TSPL and ESC/POS across SEWOO, B10, Rongta, Zebra, TSC, Honeywell and Bixolon printers.
