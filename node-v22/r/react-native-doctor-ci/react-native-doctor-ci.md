# react-native-doctor-ci

> 标签: ci, dependencies, github-actions, lint, new-architecture, policy, react-native, sarif

## 简介

Policy-as-code CI gate for React Native dependency health: fail PRs that add abandoned, non-New-Architecture, or npm-deprecated dependencies.
