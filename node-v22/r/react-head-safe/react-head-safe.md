# react-head-safe

> 标签: client-side-rendering, create-react-app, csr, document-head, document-title, duplicate-prevention, head, head-manager, meta, meta-description, meta-tags, og-tags, open-graph, page-metadata, react, react-component, react-head, react-helmet, react-helmet-async, react-seo, seo, seo-optimization, social-media, spa, typescript, vite

## 简介

A lightweight React head manager for CSR apps. Safely manage document title, meta tags, Open Graph, and SEO metadata without duplicates. TypeScript support included.
