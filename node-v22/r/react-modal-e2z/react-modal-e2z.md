> 标签: composable, controlled, dialog, headless, hook, hooks, modal, overlay, portal, react, react-component, react-library, react-modal, react18, ui

## 简介

A lightweight, headless, fully controlled React modal built on portals. Hook-first, composable, SSR-safe and React 18 ready.
