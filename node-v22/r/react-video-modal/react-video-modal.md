# react-video-modal

> 标签: a11y, accessible, dialog, lightbox, modal, popup, react, video, vimeo, youtube

## 简介

Accessible, zero-dependency React modal for YouTube, Vimeo and native video, with focus trap, scroll lock and smooth animations.
