# resilient-ws-client

> 标签: acknowledgement, backoff, jitter, queue, reconnect, resilience, websocket

## 简介

A reconnecting WebSocket client: state machine, exponential backoff with jitter, and a send queue with acknowledgement-based redelivery. No dependencies.
