# reviewfy

> 标签: annotation, comments, design-review, embeddable, feedback, review

## 简介

Figma-style review for any web page: click-to-comment severity pins, in-place text rewrites, data-source inspection, section reordering, an automated page audit, and an AI-ready markdown export.
