# react-native-web-nfc-api

> 标签: android, ios, ndef, ndefreader, nfc, react-native, turbomodule, web nfc api, web-nfc

## 简介

W3C Web NFC API (NDEFReader/NDEFMessage/NDEFRecord) for React Native on Android and iOS, with passthrough to the browser's native NDEFReader on web.
