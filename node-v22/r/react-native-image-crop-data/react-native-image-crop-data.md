# react-native-image-crop-data

> 标签: crop, cropper, gesture-handler, image, non-destructive, react-native, reanimated

## 简介

Non-destructive image cropping for React Native: store crop transforms as data, replay them on any renderer, and rasterize the source image only on explicit export.
