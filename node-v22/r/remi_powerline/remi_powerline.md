# remi_powerline

> 标签: JavaScript

## 简介

PowerLine lib!! ex: ```javascript const {PowerLine} = require("remi_powerline") const pl = new PowerLine() pl.add("hello", "bgBlue", "white")   .add("world", "bgRed", "white", "round"); console.log(pl.string) ```
