# @dzhechkov/loop-designer-plugin

> 标签: agent-skills, claude-code, codex, loop-plan, multi-agent, plugin, workflow

## 简介

The plugin authors, gates and reads plans; execution uses a separate runtime. Author loop-plan/1 plans with five plugin wrappers. Execute rendered scripts with the Claude Code Workflow host, or interpret plans separately with a current dz workflow run CLI
