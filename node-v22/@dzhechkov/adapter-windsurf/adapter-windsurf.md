# @dzhechkov/adapter-windsurf

> 标签: adapter, agent-skills, harness, windsurf, windsurf-rules

## 简介

Windsurf platform adapter - transforms canonical skills into per-skill .windsurf/rules/<id>.md workspace rules (Windsurf's trigger/description frontmatter + body; intentionally transforming, not byte-identical).
