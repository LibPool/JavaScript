# @lite-embeds/vimeo

> 标签: custom-element, embed, facade, lazy-load, lite, performance, privacy, video, vimeo, web-component

## 简介

Privacy-first facade web component for Vimeo embeds. Renders a static placeholder; only loads the real iframe when the user clicks.
