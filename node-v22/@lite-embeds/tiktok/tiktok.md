# @lite-embeds/tiktok

> 标签: custom-element, embed, facade, lazy-load, lite, performance, privacy, tiktok, video, web-component

## 简介

Privacy-first facade web component for TikTok embeds. Renders a static placeholder; only loads the embed script when the user clicks.
