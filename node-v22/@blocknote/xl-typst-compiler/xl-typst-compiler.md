# @blocknote/xl-typst-compiler

> 标签: compiler, javascript, pdf, typescript, typst, wasm

## 简介

The Typst compiler (official typst crates) compiled to WebAssembly, with a minimal TypeScript API - the engine behind BlockNote's PDF export.
