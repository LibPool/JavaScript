# @hyext/ext-sdk-basic-inner

> 标签: JavaScript

## 简介

- 多端适配：`src/platfroms/[rn]` 下是各个端的适配代码，最终将注册到SDK核心`extsdk.core`； - 统一入口：`src/modules` 下是所有要暴露的API接口，通过SDK核心回溯某个模块某个API`extsdk.core.callEvent`； - 根据任务配置构建出不同平台的SDK；
