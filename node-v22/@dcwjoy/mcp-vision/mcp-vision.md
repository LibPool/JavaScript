# @dcwjoy/mcp-vision

> 标签: image-recognition, mcp, model-context-protocol, ocr, qwen-vl, vision, vlm

## 简介

通用图片识别 MCP：为不支持图片输入的模型扩充视觉能力（默认阿里百炼 Qwen-VL，可切换任意 OpenAI 兼容视觉模型）。
