# @robosystems/mcp

> 标签: api, financial, graph, mcp, model-context-protocol, robosystems

## 简介

MCP stdio bridge connecting stdio-only AI clients to the RoboSystems financial intelligence platform; proxies to the hosted remote MCP endpoint by default
