# react-native-nitro-svg

> 标签: android, androidsvg, coresvg, icons, image-cache, ios, nitro, nitro-modules, react-native, remote-svg, svg, svg-image, web

## 简介

Fast remote SVG rendering for React Native: rasterized off the main thread with CoreSVG (iOS) and AndroidSVG (Android), with memory + disk caching, request deduplication and tinting. Built on Nitro Modules.
