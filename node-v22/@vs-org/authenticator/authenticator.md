# @vs-org/authenticator

> 标签: HOTP, Recovery codes generator, TOTP, VS, authenticator, generator, node, recovery code generator, vs recovery code generator, vs-org, vs-recovery-code-generator

## 简介

VS authenticator package can generate TOTP (RFC6238) for 2FA, and also provide secret and recovery codes for 2FA setup
