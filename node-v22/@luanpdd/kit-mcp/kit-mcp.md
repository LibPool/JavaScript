# @luanpdd/kit-mcp

> 标签: agents, antigravity, claude, codex, cursor, dynamic-workflows, mcp, model-context-protocol, skills, workflows

## 简介

Generic infrastructure to ship YOUR personal kit of agents/commands/skills as an MCP server, with cross-IDE sync (Claude Code, Cursor, Codex, Windsurf, Antigravity, Copilot, Trae).
