# @bernierllc/nevarmail

> 标签: api-client, bernierllc, email, esp, nevarmail, sdk, transactional-email

## 简介

Official client for the NevarMail v1 API. Typed, retries 429/5xx, throws NevarMailError on every non-2xx.
