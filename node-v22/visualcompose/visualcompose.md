# visualcompose

> 标签: data-binding, esm, framework, html-first, micro-framework, mpa, no-build, router, spa, templates

## 简介

Zero-dependency micro-framework for HTML-first apps: URL router, template stamping, fluent API client and declarative data binding. No build step required.
