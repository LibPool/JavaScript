# @openape/proof-cli

> 标签: cli, ddisa, openape, proof-link

## 简介

Shared CLI core for OpenApe proof-link apps (tasks, testrun, pr, plans, timetrack). Wires login/logout/whoami/open/docs + SP client from a single app descriptor; each app supplies only its domain commands.
