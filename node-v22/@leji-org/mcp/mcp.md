# @leji-org/mcp

> 标签: agent-context, ai-native, conformance, context-layer, leji, mcp, model-context-protocol, shared-context, validation

## 简介

Local stdio MCP server for Leji: retrieve the spec and schemas, and run validation and conformance against a context layer, natively from an AI agent.
