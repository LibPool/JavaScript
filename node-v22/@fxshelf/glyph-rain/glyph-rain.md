# @fxshelf/glyph-rain

> 标签: animation, canvas, effect, fxshelf, glyph, matrix, rain, react, vue, webgl

## 简介

Matrix-style glyph rain with cursor stir and drop-head lighting for React and Vue. WebGL2, zero animation-lib deps. Copy-as-source friendly.
