# @raffaelenatale/pi-docs-sync

> 标签: cache, docs, documentation, llms-txt, mirror, pi-extension, pi-package

## 简介

Pi extension: local structured mirror of official docs published as llms.txt / llms-full.txt, with differential (ETag/hash) syncing, async TTL refresh, and zero-latency local search/read tools for the agent.
