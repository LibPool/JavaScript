# @glorification/eslint-config

> 标签: eslint, eslint-config, eslintconfig, glorification, style

## 简介

Glorification ESLint config: a modern coding style — 4 spaces, single quotes, no semicolons, 120 columns — with optional sorting, aliases and JSDoc extras.
