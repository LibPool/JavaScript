# msglens-cli

> 标签: cli, email, eml, mcp, mcp-server, model-context-protocol, msg, msg-to-eml, outlook, parser, rtf, tnef, winmail.dat

## 简介

Read Outlook .msg, .eml and winmail.dat files in Node: headers, body (including bodies stored only as compressed RTF) and attachments. CLI, Node library and MCP server for AI assistants.
