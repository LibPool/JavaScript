# 4layers

> 标签: architecture, boundaries, clean-architecture, ddd, dependency-rules, hexagonal, layers, lint, static-analysis, vite, vite-plugin, vue

## 简介

Architecture layer checker for Vue.js / TypeScript apps. Enforces Presentation -> Application -> Domain <- Infrastructure boundaries at dev time, build time and in CI.
