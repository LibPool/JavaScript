# @zubari/sdk

> 标签: bip39, bip44, bitcoin, blockchain, creator-economy, crypto, ethereum, lightning, multi-chain, nft, sdk, self-custodial, solana, spark, tether-wdk, ton, tron, typescript, wallet, web3

## 简介

Multi-chain self-custodial wallet SDK for Web3 creator economy. Supports Ethereum, Bitcoin, TON, TRON, Solana, and Lightning (Spark) from a single BIP-39 seed phrase.
