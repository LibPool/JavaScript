# @see-what-i-see/mcp-server

> 标签: chrome-extension, mcp, model-context-protocol, screenshot, see-what-i-see, seewhatisee

## 简介

MCP server that exposes screenshots, HTML snapshots, and selections from the SeeWhatISee Chrome extension to any MCP client.
