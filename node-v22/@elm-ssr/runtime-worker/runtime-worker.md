# @elm-ssr/runtime-worker

> 标签: JavaScript

## 简介

Cloudflare Workers / Bun runtime for elm-ssr: request handling, backend-neutral effect adapters (KV/D1/Redis/Postgres), background tasks/queues, and the client island bootstrap.
