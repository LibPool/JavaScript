# @chrismessina/raycast-kit

> 标签: error-handling, house-style, pluralize, raycast, raycast-extension, toast

## 简介

House-style primitives for Raycast extensions: failure toasts that always carry a Copy Error action, safe error unwrapping, and count-aware copy
