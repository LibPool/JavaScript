# @medicine-wheel/client

> 标签: ceremony, client, http, medicine-wheel, relational-accountability, talking-circle

## 简介

Typed HTTP client for a Medicine Wheel — nodes, edges, ceremonies, beats and the ceremonial diary — with the wheel's paging honesty carried through (count, total, truncated) and fail-fast errors that name the status.
