# @sesamehut/design-tokens-md

> 标签: codegen, css-custom-properties, css-variables, design-md, design-system, design-tokens, design.md, dtcg, tailwind, tailwind-v4, tailwindcss, theme, tokens, w3c-design-tokens

## 简介

Drop-in replacement for @google/design.md's dtcg & css-tailwind exporters: compile a DESIGN.md into lossless W3C DTCG tokens and Tailwind v4 @theme CSS — pure, deterministic, byte-identical.
