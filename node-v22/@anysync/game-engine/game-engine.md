# @anysync/game-engine

> 标签: anysync, game-sdk, games, kids-games, phone-remote, tinyplay, tv, webrtc

## 简介

Shared TinyPlay game engine: canvas, loop, UI, procedural audio, local channel, and control widgets (buttons/roller/wheel/slider/tilt).
