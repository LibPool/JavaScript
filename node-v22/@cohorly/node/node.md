# @cohorly/node

> 标签: analytics, cohorly, mixpanel, node, product-analytics, server-side, tracking

## 简介

Server-side Node.js SDK for Cohorly, hosted product analytics (Mixpanel-style). Stateless mixpanel-node-like API: track with explicit distinct_id, batching queue with retry/backoff, people profile ops, alias.
