# opennode-chart

> 标签: candlestick, canvas, chart, finance, ohlc, react, shadcn, trading

## 简介

CN Chart — a shadcn/ui-compatible trading chart built on an original Canvas 2D engine, with drawings, indicators, replay, alerts and an agent-friendly control API.
