# @dreamdesk/os

> 标签: desktop, dos, dreamdesk, os, react, recycle-bin, shell, virtual-filesystem

## 简介

The OS layer for DreamDesk: a virtual filesystem with a recycle bin, processes with windows, file types, remembered app state, and a DOS shell.
