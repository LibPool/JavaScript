# @tsgwarp/webrtc

> 标签: browser-calling, sip, softphone, tsg, voice, warp, webrtc

## 简介

WARP Voice browser calling SDK — add a phone to your web app in minutes. Wraps SIP-over-WSS + WebRTC behind a clean Device/Call API.
