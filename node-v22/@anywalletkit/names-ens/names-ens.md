# @anywalletkit/names-ens

> 标签: anywalletkit, basenames, ccip-read, ens, ensip-11, ensip-9, ethereum, names

## 简介

ENS names for Any Wallet Kit wallets: vitalik.eth / name.base.eth / alice.cb.id → the address for one chain (ENSIP-9/11 multichain, wildcard + CCIP-Read), verified primary names, avatars, lookalike warnings. Implements the core NameResolver.
