# @anywalletkit/runtime-hermes

> 标签: abortsignal, hermes, polyfill, react-native, webcrypto

## 简介

The one documented place for React Native / Hermes polyfills Any Wallet Kit relies on: AbortSignal.timeout/any, crypto.subtle.digest, TextEncoder checks, Buffer.
