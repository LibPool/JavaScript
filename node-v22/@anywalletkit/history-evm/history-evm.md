# @anywalletkit/history-evm

> 标签: activity, alchemy, blockscout, etherscan, evm, history

## 简介

Activity history (HistorySource) for every EVM chain the SDK supports: Etherscan v2, Blockscout PRO and Alchemy Transfers API (API keys) with Blockscout and Routescan keyless fallbacks, merged into one ChainTx per hash with a documented spam heuristic.
