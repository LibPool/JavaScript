# @anywalletkit/extension-kit

> 标签: browser-extension, chrome-extension, eip-1193, mv3, sdk, vault, wallet

## 简介

Chromium (MV3) wallet-extension core for Any Wallet Kit: scrypt + AES-256-GCM vault with passkey (WebAuthn PRF) unlock, auto-locking session, dApp request router with per-origin permissions and an approval queue, signing-request checks, swap / Earn plan r
