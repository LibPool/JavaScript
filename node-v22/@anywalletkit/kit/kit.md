# @anywalletkit/kit

> 标签: multichain, orchestrator, policies, sdk, wallet

## 简介

The Any Wallet Kit orchestrator: one seed or signer, registered chain wallets and protocol modules, accounts by CAIP-2 chain, policies that run before anything is broadcast.
