# @anywalletkit/wallet-btc

> 标签: bip84, bip86, bitcoin, blockbook, esplora, psbt, taproot, wallet

## 简介

Bitcoin wallet for Any Wallet Kit on @scure/btc-signer: BIP-84 p2wpkh and BIP-86 taproot accounts, own coin selection, RBF, Blockbook/Esplora transports.
