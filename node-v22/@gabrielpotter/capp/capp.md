# @gabrielpotter/capp

> 标签: business-days, calendar, date, holiday, rest-api, rules-engine, scheduler, workday

## 简介

Calendar rules engine: define calendars as JSON + JS snippets, validate them with hashes, and serve them over a REST API or use them as a library.
