# @yoshine2007/agent-scan

> 标签: agent-skills, ai-agents, code-scanning, linter, mcp, model-context-protocol, prompt-injection, sarif, scanner, security, supply-chain

## 简介

Security scanner for the AI agent ecosystem: MCP servers, Agent Skills, AGENTS.md / rule files, and agent tool code. Detects prompt injection, tool poisoning, data exfiltration and supply-chain risks. Zero dependencies.
