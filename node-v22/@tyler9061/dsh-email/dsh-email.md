# @tyler9061/dsh-email

> 标签: dsh, email, imap, mail, plugin, smtp

## 简介

dsh web 邮件插件：分栏邮箱客户端（IMAP 接收 + SMTP 回复/快速回复）、设置界面（账号/权限/自动化）、agent 工具与自动处理、HTML 安全渲染
