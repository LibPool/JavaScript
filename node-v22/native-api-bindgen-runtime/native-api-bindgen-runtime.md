# native-api-bindgen-runtime

> 标签: bindings, jni, jsi, objective-c, react-native, turbomodule

## 简介

Runtime of native-api-bindgen for React Native (New Architecture): JSI host objects over JNI (Android) and Objective-C++ (iOS). Generated bindings embed a copy; this package is for apps that prefer a dependency.
