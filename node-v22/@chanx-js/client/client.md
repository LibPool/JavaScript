# @chanx-js/client

> 标签: @chanx-js/client, asyncapi, react, solid, svelte, typescript, vue, websocket

## 简介

Type-safe WebSocket client for chanx AsyncAPI schemas, with topic multiplexing. React, Vue, Svelte and Solid bindings.
