# @gigibiffi84/jsonforms-standard-schema

> 标签: arktype, csp, form, forms, json, jsonforms, jsonschema, standard-schema, valibot, validation, zod

## 简介

Unofficial fork of @jsonforms/standard-schema with the pluggable Form Validator (eclipsesource/jsonforms#1498). Use any Standard Schema library (Valibot, Zod, ArkType, ...) as the validator of JSON Forms
