# @saasifier/core

> 标签: JavaScript

## 简介

The SaaSify runtime — wires a `DatabaseAdapter` and a validated `saasify.config.ts` into a single `saas` object exposing tenancy, organizations, RBAC, entitlements, usage metering, billing, audit logs, webhooks, and API keys.
