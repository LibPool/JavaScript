# @weeebdev/ebay-mcp

> 标签: ai, ai-tools, api, backend, documentation, ebay, ebay-api, llm, mcp, model-context-protocol, server

## 简介

Model Context Protocol (MCP) server that exposes eBay's Sell APIs (302 tools across 270 endpoints) plus buy-side search, item lookup, and seller messaging to AI assistants like Claude, Cursor, and Cline, with OAuth authentication and refresh-token support
