# @negareh/widget

> 标签: embed, farsi, iframe, instagram-stories, link-in-bio, negareh, persian, rtl, sdk, story, story-ring, widget

## 简介

Official embeddable widget SDK for Negareh (نگاره) — drop interactive Persian/RTL story-rings, link-in-bio and more onto any website. Framework-agnostic, style-isolated, auto-resizing.
