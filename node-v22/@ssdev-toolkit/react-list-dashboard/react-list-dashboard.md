# @ssdev-toolkit/react-list-dashboard

> 标签: JavaScript

## 简介

React host for the same `ListDashboardConfig` used by `@ssdev-toolkit/angular-list-dashboard`. The shared core is bundled into this adapter; apps install this package (and `@ssdev-toolkit/react-forms` for filter and create sheets).
