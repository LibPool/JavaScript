# @mikro-orm/oracledb

> 标签: data-mapper, ddd, entity, identity-map, javascript, js, mikro-orm, oracle, oracledb, orm, ts, typescript, unit-of-work

## 简介

TypeScript ORM for Node.js based on Data Mapper, Unit of Work and Identity Map patterns. Supports MongoDB, MySQL, MariaDB, PostgreSQL, SQLite, MSSQL and Oracle databases.
