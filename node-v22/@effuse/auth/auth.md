# @effuse/auth

> 标签: auth, authentication, authorization, credentials, csrf, effect-ts, effuse, oauth, oidc, security, session, typescript

## 简介

Production-ready authentication for Effuse: one typed session, swappable ports with conformance suites, and named mitigations for session fixation, enumeration, brute force, and rotation races.
