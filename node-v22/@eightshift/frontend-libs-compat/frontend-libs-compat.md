# @eightshift/frontend-libs-compat

> 标签: WordPress, compat, compatibility, frontend, js, lite, mixin, module, scss, utility

## 简介

A small set of functions to preserve compatibility in projects using older Frontend Libs versions, while allowing new versions of Frontend Libs to be used alongside.
