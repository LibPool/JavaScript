# @any-nav/scan

> 标签: agent, markdown, navigation, scan

## 简介

Any-Nav scan core: the zero-dependency engine that walks a Markdown folder into a nav tree under the routes traversal semantics (exclusions, gitignore inheritance, a loud maxFiles budget, folder descriptions). Embedders consume this directly; @any-nav/cor
