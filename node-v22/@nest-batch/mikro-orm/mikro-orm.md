# @nest-batch/mikro-orm

> 标签: batch, job-repository, mikro-orm, nestjs, persistence

## 简介

MikroORM adapter SLOT for @nest-batch/core — JobRepository and TransactionManager interface shape, paired with @nest-batch/postgresql (Postgres driver) or @nest-batch/mysql (MySQL driver).
