# @wroud/vite-plugin-tsc

> 标签: bundler, development, esmodules, transpiler, tsc, tsgo, typescript, vite, vite-plugin

## 简介

A Vite plugin that uses TypeScript's tsc (or the native tsgo compiler) to transpile and type check TypeScript sources for seamless bundling.
