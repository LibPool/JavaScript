# @starreview/cli

> 标签: ai-agent, claude, cli, google-business-profile, mcp, reputation, review-management, reviews

## 简介

Social review management for AI agents: list reviews, draft and submit replies through StarReview's owner-controlled publishing policy. The CLI can never post.
