# fermata-mcp

> 标签: agent-payments, ai-agents, claude, escrow, mcp, model-context-protocol, mpp, stablecoin, tempo, tlsnotary, x402

## 简介

Pay-on-proof tools for Claude and other MCP agents: a local MCP server that pays a Fermata gateway's tools from a Tempo testnet wallet, released only on a TLSNotary proof, refunded on failure.
