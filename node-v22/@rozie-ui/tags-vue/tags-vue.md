# @rozie-ui/tags-vue

> 标签: accessibility, aria, chips, component, headless, multiselect, rozie, rozie-ui, tag-input, tags, token-input, vue

## 简介

Idiomatic Vue headless WAI-ARIA tags / token input (chips with removable controls, type-to-add with configurable delimiters, paste-to-bulk-add, dedup, validation, max cap) — one accessible Rozie source compiled to Vue.
