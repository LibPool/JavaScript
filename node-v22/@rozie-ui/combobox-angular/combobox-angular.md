# @rozie-ui/combobox-angular

> 标签: JavaScript

## 简介

Idiomatic Angular headless WAI-ARIA combobox / autocomplete (text input + popup listbox, client/async filtering, full keyboard navigation, aria-activedescendant, ControlValueAccessor) — one accessible Rozie source compiled to Angular.
