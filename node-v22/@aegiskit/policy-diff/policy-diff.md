# @aegiskit/policy-diff

> 标签: access-control, appsec, ci, policy-diff, rls, row-level-security, security, supabase

## 简介

Semantic access diff for Supabase RLS migrations: turns two migration states into a plain-English access delta (who can newly read/write what), fail-safe by design — for PR review, CI gating, and change-management evidence.
