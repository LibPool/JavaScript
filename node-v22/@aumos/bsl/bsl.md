# @aumos/bsl

> 标签: agent-policy, ast, aumos, behavioral-specification-language, bsl, typescript, validation

## 简介

TypeScript client for the AumOS BSL (Behavioral Specification Language) — token types, AST node types, validation diagnostics, and HTTP client for the BSL validation/formatting API
