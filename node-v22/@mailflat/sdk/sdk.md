# @mailflat/sdk

> 标签: ai-agents, automation, disposable-email, email, otp, temporary-email, testing

## 简介

Official TypeScript/JavaScript SDK for MailFlat — disposable, automation-friendly email inboxes with one-line OTP retrieval.
