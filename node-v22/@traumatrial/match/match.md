# @traumatrial/match

> 标签: EMS, NEMSIS, clinical-trials, ePCR, eligibility, healthcare, matching, trauma

## 简介

Real-time trauma trial eligibility matching engine. TypeScript port of the Python engine — same operators, same trace format, same confidence rubric. Includes a NEMSIS v3.5 ePCR adapter.
