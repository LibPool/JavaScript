# @vouchrun/referral-sdk

> 标签: defi, liquid-staking, pulsechain, referral, sdk, viem, vouch, vpls

## 简介

TypeScript SDK for Vouch's ReferralDeposit contract on PulseChain — quote, deposit, referrer management, and event tracking for vPLS referral deposits, plus the full vPLS unstaking lifecycle (quote, instant/queued unstake, withdrawal claims).
