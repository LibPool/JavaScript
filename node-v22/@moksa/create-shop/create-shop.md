# @moksa/create-shop

> 标签: create, ecommerce, emdash, moksa, taiwan

## 简介

npm create @moksa/shop：在 EmDash 網站勾選要安裝的 Moksa 商店功能（自架版），一次安裝並補上必要的環境變數。

- npm 页面：https://www.npmjs.com/package/@moksa/create-shop
