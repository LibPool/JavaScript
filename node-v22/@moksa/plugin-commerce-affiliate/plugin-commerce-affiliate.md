# @moksa/plugin-commerce-affiliate

> 标签: JavaScript

## 简介

推廣分潤：推薦連結與歸屬、佣金與鑑賞期、團隊長分潤、防弊、撥款（匯款或會員點數）與推廣素材，需搭配 @moksa/emdash-shop 網站整合套件。
