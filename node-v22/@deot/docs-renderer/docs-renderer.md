# @deot/docs-renderer

> 标签: JavaScript

## 简介

`@deot/docs-renderer` 同时提供只读 `Renderer` 与可视化装修 `Combo`。两者共享 扁平页面文档协议、模块定义和校验流程，但每个实例都有自己的 Module Catalog， 不会通过全局注册表互相污染。
