# @deot/vc-locale

> 标签: JavaScript

## 简介

`@deot/vc-locale` 提供 `@deot/vc` 使用的语言类型和语言数据。子包本身不依赖 Vue，也不包含响应式状态、Translator、Hook 或 Provider。
