# @access-lens/core

> 标签: abac, access-control, authorization, entitlements, feature-flags, headless, observability, permissions, rbac, saas, typescript

## 简介

Framework-agnostic access observability core. Record every gated UI decision (permission, feature flag, plan, entitlement, tenant config) with the exact reason it produced.
