# @tribe-nest/seating-core

> 标签: JavaScript

## 简介

Isomorphic core for reserved seating: the seat map document schema, generators (grid, curve, table), numbering schemes, geometry, flattening and the CSV codec. Imported by the backend (validation + event materialisation) and the admin editor so the editor
