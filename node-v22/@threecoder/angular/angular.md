# @threecoder/angular

> 标签: angular, seo, seo-autopilot

## 简介

Drop-in Angular integration for SEO Autopilot. Register provideSeoAutopilot() once in app.config.ts to automatically register, track route changes, and apply portal-approved SEO fixes to the DOM. Works with any `ng build` production output deployed to any
