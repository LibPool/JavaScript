# @xtramaps/web-map-openlayers

> 标签: JavaScript

## 简介

Framework-agnostic core logic for the OpenLayers web map component: projection setup, initial-view computation, and dynamic view/source switching when the active TileMatrixSet changes. Migrated from `ogcapi-html`'s `OpenLayers` component onto current `ol`
