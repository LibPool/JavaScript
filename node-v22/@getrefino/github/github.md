# @getrefino/github

> 标签: content, copy, git, github, refino

## 简介

GitHub persistence adapter for Refino: reads and commits the canonical copy file through the GitHub Contents API, so the repository stays the source of truth.

## 官网

- 官网：https://refino.dev
- 源码仓库：git+https://github.com/forant/inline-copy.git
- npm 页面：https://www.npmjs.com/package/@getrefino/github
