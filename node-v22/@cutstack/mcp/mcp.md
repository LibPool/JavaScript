# @cutstack/mcp

> 标签: background-removal, claude, cursor, cutstack, mcp, model-context-protocol, product-photos

## 简介

Cutstack as MCP tools: background removal for product photos, batches of up to 200, the review queue and the ZIP, driven by Claude, Cursor or any MCP client.
