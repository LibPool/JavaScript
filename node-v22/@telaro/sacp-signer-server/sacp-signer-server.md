# @telaro/sacp-signer-server

> 标签: JavaScript

## 简介

Reference HTTP signing server for the sACP RemoteSigner. Wraps a local keypair, a Turnkey vault, or an AWS KMS asymmetric key behind a uniform POST /sign endpoint with HMAC auth.
