# @telaro/defi

> 标签: defi, drift, jupiter, kamino, marginfi, solana, telaro, voltr

## 简介

Telaro DeFi-venue adapters bundle. Wrap Drift, Jupiter, Kamino, MarginFi, or Voltr SDKs so every venue interaction auto-records on Telaro. One install, one import per venue.
