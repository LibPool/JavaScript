# @c2n/marker

> 标签: lit, marker, web component

## 简介

Inline text marker that draws attention to a run of text the way a pen would: a highlighter stroke behind it, a line under or through it, or a box or loose circle around it. Set `animated` to draw the mark the first time it scrolls into view.
