# @c2n/hover-card

> 标签: hover card, hover-card, lit, popover, web component

## 简介

Preview card shown when a trigger is hovered or focused — a profile behind a mention, the summary behind a link. The pointer can move into the card and it stays open, so it may hold links and buttons.
