# @c2n/list-item

> 标签: list-item, lit, web component

## 简介

`c2-list-item` is a selectable row: on its own a click, Enter or Space toggles `selected`; inside a `c2-list` (or a `c2-select`) the list drives the selected state and the keyboard.
