# @eleung/react-grid-layout

> 标签: cross-grid-drag, cross-layout-drag, drag, draggable, flex-layout, flexbox, fluid, grid, react, resizable, resize, responsive

## 简介

A draggable and resizable grid layout with responsive breakpoints, for React. Includes Flexbox layout support and cross-layout drag and drop.
