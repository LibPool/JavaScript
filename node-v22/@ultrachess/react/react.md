# @ultrachess/react

> 标签: accessibility, chess, chess-engine, chess-ui, chessboard, react, react-chessboard, ssr, typescript, ultrachess, wai-aria, wasm

## 简介

Opinionated React chessboard with owned state, byte-scoped subscriptions, refs-only drag, polished default theme and pieces, sounds, arrows, premoves, and SSR static rendering.
