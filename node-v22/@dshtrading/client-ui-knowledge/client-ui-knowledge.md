# @dshtrading/client-ui-knowledge

> 标签: JavaScript

## 简介

Knowledge-base stage view plugin for dsh-trading (issue #34 / P5): registers the 中栏「知识库」tab via the tradingStageViews service — Obsidian-style force-directed knowledge graph with search/tag/author/credibility filters and a card detail drawer. Graph logic
