# @dshtrading/connector-akshare

> 标签: JavaScript

## 简介

AkShare 名义的 A 股宏观/另类数据连接器：实现面为东方财富公开 REST 直连（push2/push2his），提供 tradingCnMarketData 行情服务与 cn_get_ticker / cn_get_klines / cn_get_sector_fund_flow 三个工具，无交易通道。
