# @invoance/audit-viewer

> 标签: audit-log, audit-trail, ed25519, embeddable, invoance, react, verification

## 简介

Embeddable React audit-log viewer for Invoance: signed event table, filters, export, and in-browser Ed25519 tamper verification.
