# @mcp-verify/studio-runner

> 标签: assertions, jsonpath, mcp, model-context-protocol, testing

## 简介

Assert Studio building blocks — YAML schema + parser, JSONPath helpers, transport factory, dynamic-HTTP fixture executor. Lightweight OSS surface. Scoring + execution live in the closed mcpverify.dev cloud (T-184).
