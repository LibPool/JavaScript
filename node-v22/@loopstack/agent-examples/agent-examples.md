# @loopstack/agent-examples

> 标签: agent, claude, example, llm, loopstack, mcp, workflow

## 简介

Workflow examples for LLM agents in Loopstack — basic AgentWorkflow, code-exploration agent, MCP-connected agent, and a from-scratch custom agent loop with a deterministic turn budget.
