# @letisim/connect-sdk

> 标签: api, connect, esim, letisim, reseller, sdk, travel, webhooks

## 简介

Official server-side TypeScript SDK for the Letisim Connect API — typed errors, safe retries, idempotency, cursor iterators and webhook verification
