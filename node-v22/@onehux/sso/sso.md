# @onehux/sso

> 标签: JavaScript

## 简介

Node.js/TypeScript SDK for OneHux Accounts SSO. Two patterns: the OAuth client/BFF (Authorization Code + PKCE, real hosted login page, RP-initiated logout — root entrypoint plus ./express and ./sveltekit) and a pure resource server verifying Bearer tokens
