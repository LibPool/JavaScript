# @xmwengxing/dsh-client-ui-sidebar-perfmon

> 标签: cpu, cross-platform, deepseek, deepseek-harness, dsh, dsh-plugin, gpu, linux, macos, memory, monitor, perfmon, performance, process, sensor, sidebar, temperature, windows

## 简介

Real-time host performance monitor for the DeepSeek Harness right Sidebar: CPU / memory / swap gauges, a GPU clock and VRAM line, CPU / GPU / motherboard / drive temperatures, a sortable process table, and a keep-awake toggle for remote sessions — on Linu
