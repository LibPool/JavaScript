# @grinstead/webgpu

> 标签: JavaScript

## 简介

This is a TypeScript library that is designed to make it easy to use WebGPU. It is built on top of [SolidJS](https://www.solidjs.com/), so it is lightweight while maintaining powerful reactivity.
