# @chartdown/cli

> 标签: battlemap, chartdown, cli, hexcrawl, map, svg, ttrpg

## 简介

Chartdown CLI — render plain-text .cd map documents to SVG, and check them fail-loud. Self-contained bundle, zero runtime dependencies.
