# @chartdown/measure

> 标签: chartdown, coastline, georeference, map, measurement, ttrpg

## 简介

Derive Chartdown feature declarations from georeferenced imagery — size=, reach=, taper= and via measured rather than remembered. Zero runtime dependencies.
