# @trelmir-os/input-quality-compiler

> 标签: agent-input, deterministic, input-normalization, intent-compiler, llm-pre-processor, prompt-engineering, task-spec, trelmir

## 简介

Drop in front of any OpenAI / Claude / Gemini call as a token cost-guard. Blocks vague prompts before you pay for them. Deterministic, zero-dependency, sub-millisecond compile.
