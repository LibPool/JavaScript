# @editrajs/vue

> 标签: JavaScript

## 简介

Vue 3 adapter for Editra. `useEditra()` owns the editor lifecycle and returns a shallow `editor` ref plus a DOM `contentRef`. `EditraContent`, `EditraToolbar` and the `EditraEditor` convenience composition use the same public core and UI contracts.
