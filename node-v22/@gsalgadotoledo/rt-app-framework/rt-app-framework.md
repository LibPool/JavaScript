# @gsalgadotoledo/rt-app-framework

> 标签: JavaScript

## 简介

- `src/`: backend composition (`@gsalgadotoledo/rt-app-framework`). - `core-ts/`, `core-go/`, `core-python/`: language-specific component registries. - `packages/`: adapters, domain modules, observer, service manager and project generator. - `admin/`: sha
