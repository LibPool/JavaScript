# @hyperse/hps-srv-rspack

> 标签: JavaScript

## 简介

Rspack-based build and dev-serve toolkit for modern web apps. It wraps common build features (HTML generation, CSS/LESS, PostCSS, assets, SVG icons, image optimization), integrates TypeScript checking, React Fast Refresh, multi-page support, Module Federa
