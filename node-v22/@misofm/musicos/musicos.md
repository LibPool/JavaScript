# @misofm/musicos

> 标签: blockchain, composition, miso, move, music, object-model, recording, release, sdk, sui

## 简介

A sui-effect extension for the Miso object model (Composition, Recording, Release, Track): the Musicos service, PTB fragments, event decoders, and BCS codecs.
