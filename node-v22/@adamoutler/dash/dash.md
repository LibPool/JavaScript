# @adamoutler/dash

> 标签: agentic, automation, ci-cd, dash, guardrail

## 简介

A secure, authenticated CI/CD monitoring dashboard for autonomous AI agents and humans, supporting GitHub, Forgejo, and Jenkins with native MCP integration.
