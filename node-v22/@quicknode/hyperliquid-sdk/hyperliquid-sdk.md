# @quicknode/hyperliquid-sdk

> 标签: crypto, defi, evm, grpc, hyperliquid, orderbook, perpetuals, quicknode, spot, trading, websocket

## 简介

Community SDK for Hyperliquid. One line to place orders, zero ceremony. HyperCore, HyperEVM, WebSocket and gRPC streams. Not affiliated with Hyperliquid Foundation.

## 官网

- 官网：https://hyperliquidapi.com
- 源码仓库：git+https://github.com/quiknode-labs/hyperliquid-sdk.git
