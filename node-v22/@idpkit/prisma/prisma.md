# @idpkit/prisma

> 标签: JavaScript

## 简介

Prisma persistence for the structural `IdentityStorage` contract. The package does not import `@idpkit/server`; pass a generated `PrismaClient` (or a test double with the same delegates) to `new PrismaIdentityStorage(client)`.
