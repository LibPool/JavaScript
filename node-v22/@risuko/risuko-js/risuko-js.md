# @risuko/risuko-js

> 标签: bittorrent, download, download-manager, ed2k, ftp, m3u8, torrent

## 简介

Risuko download engine — Node.js native bindings for multi-protocol downloads (HTTP, BitTorrent, ED2K, M3U8, FTP/SFTP)
