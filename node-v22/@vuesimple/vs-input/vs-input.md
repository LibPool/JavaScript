# @vuesimple/vs-input

> 标签: form, front-end, input, text-input, vs-input, vue, vue-input, vue-js, vuejs, web

## 简介

A simple vue input component. Supports text, email, password, number, search and more with label, hint, validation states and prefix/suffix slots.
