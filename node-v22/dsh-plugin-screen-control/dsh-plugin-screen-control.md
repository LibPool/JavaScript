# dsh-plugin-screen-control

> 标签: computer-use, deepseek-harness, dsh, dsh-plugin, rust, screen-control, ui-automation, windows

## 简介

DSH 屏幕操控插件：TypeScript 薄壳 + Rust 常驻引擎。观察与操作后台窗口，不激活前台窗口。
