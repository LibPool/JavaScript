# @codesham/repolens-mcp

> 标签: ai-agent, claude, code-search, codebase, github, mcp, model-context-protocol, rag

## 简介

MCP server for RepoLens: lets AI agents index a GitHub repo and ask questions answered from its real code, with line-level citations, via the live RepoLens API.
