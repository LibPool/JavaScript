# @formael/action-risk-vocabulary

> 标签: action-risk, actlint, mcp, owasp, standards-crosswalk, vocabulary

## 简介

PURE DATA. The action-risk vocabulary, MCP-hint mapping, and standards crosswalk that back actlint. JSON-Schema'd and independently versioned so any tool can consume it as data, never code.
