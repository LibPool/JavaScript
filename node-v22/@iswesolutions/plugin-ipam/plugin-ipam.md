# @iswesolutions/plugin-ipam

> 标签: JavaScript

## 简介

A Backstage front end for [phpIPAM](https://phpipam.net): subnets, IP addresses, VLANs, a subnet map, usage history, DNS checks and a "needs attention" view, plus a card that shows an entity's addresses on its catalog page.
