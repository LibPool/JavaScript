# pi-context-guard-jev

> 标签: coding-agent, context, context-window, jev, openrouter, pi-extension, pi-package, token-savings, typesafe

## 简介

Pi extension that removes tool output the agent no longer needs from its context. The Jev classifier keeps the needed lines verbatim; stale small outputs, unrelated old exchanges and old screenshots become one-line notes. Everything can be recalled.
