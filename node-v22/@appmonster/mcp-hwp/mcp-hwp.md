# @appmonster/mcp-hwp

> 标签: hangul, hwp, hwpx, korea, markdown, mcp, model-context-protocol, 문서변환, 한글

## 简介

MCP server that converts HWP/HWPX (한글 문서) to Markdown and extracts tables, so AI agents can read Korean government and office documents.
