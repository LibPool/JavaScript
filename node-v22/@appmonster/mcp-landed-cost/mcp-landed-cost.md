# @appmonster/mcp-landed-cost

> 标签: cross-border, customs, de-minimis, duty, ecommerce, gst, import, landed-cost, mcp, model-context-protocol, vat

## 简介

MCP server for cross-border landed cost: customs duty + import VAT/GST for parcels into the US, UK, EU, Japan, Korea, China, Australia, Canada, Singapore with current de minimis rules. No keys.
