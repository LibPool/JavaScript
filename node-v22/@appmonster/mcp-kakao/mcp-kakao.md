# @appmonster/mcp-kakao

> 标签: kakao, kakaotalk, korea, mcp, message, model-context-protocol, notification, 카카오톡

## 简介

MCP server for KakaoTalk messages: send to self or friends via Kakao Developers message API, friends list, OAuth with auto-refresh. 카카오톡 메시지 MCP 서버.
