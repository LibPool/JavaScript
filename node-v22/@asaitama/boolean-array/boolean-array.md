# @asaitama/boolean-array

> 标签: Array, BitArray, Boolean, Boolean Array, Set, SetFixed, TypedArray, TypedBitArray, Uint1Array, binary, compression, drawing, fast, indexing, light, performance, selection

## 简介

Boolean (Typed Array) & Set of numbers. Very Fast! Greater 'selection' in compression and 2D drawing. Only around 16 kB.
