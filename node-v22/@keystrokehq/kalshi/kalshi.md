# @keystrokehq/kalshi

> 标签: integration, kalshi, keystroke, prediction-markets

## 简介

Kalshi integration for Keystroke workflows, built on the official TypeScript SDK. The package exposes canonical credential sets, SDK-backed operations, shared schemas, polling triggers, and helper utilities for prediction-market automation.
