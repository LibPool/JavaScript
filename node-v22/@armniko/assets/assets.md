# @armniko/assets

> 标签: asset-fetching, asset-loader, asset-manager, audio, batching, canvas, concurrency, font-face, font-loading, images, lazy-loading, preload, resource-loader, runtime-cache, typescript

## 简介

A tiny, zero-dependency JavaScript/TypeScript library for fetching and managing assets with in-memory caching and automatic font registration for canvas and dynamic text rendering.
