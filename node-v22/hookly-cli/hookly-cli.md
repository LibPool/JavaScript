# hookly-cli

> 标签: cli, content, developer-tools, hashtags, hook, linkedin, post, readme

## 简介

Turn your project README into LinkedIn post drafts: length, paragraph and tone controls, endless post structures, hook scores. Runs locally, no AI key, nothing uploaded.
