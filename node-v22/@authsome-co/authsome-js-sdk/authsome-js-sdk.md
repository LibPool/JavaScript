# @authsome-co/authsome-js-sdk

> 标签: JavaScript

## 简介

轻量级 OAuth2/OIDC 客户端 SDK，支持授权流程、Token 交换、用户信息获取和登出。基于 lottie-web 实现加载动画，无 React 依赖。
