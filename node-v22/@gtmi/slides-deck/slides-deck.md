# @gtmi/slides-deck

> 标签: JavaScript

## 简介

Framework-agnostic builder for Google Slides batchUpdate requests: units, palette, reusable slide layouts (title, section, feature+screenshot, detail cards, architecture, workflow). Emits chunked request batches you feed to any Slides client (e.g. gws CLI
