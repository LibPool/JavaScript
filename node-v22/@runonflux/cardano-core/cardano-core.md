# @runonflux/cardano-core

> 标签: ada, bip32-ed25519, cardano, cbor, cip-30, cip-8, wallet

## 简介

Pure-TypeScript Cardano transaction library: Icarus/BIP32-Ed25519 keys, Shelley and Byron addresses, span-preserving CBOR, Conway transactions, fees and min-ADA, coin selection, CIP-8 message signing and CIP-30 helpers. No WASM, two dependencies.
