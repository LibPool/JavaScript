# @netsphere/sdk

> 标签: apm, express, fastify, metrics, middleware, monitoring, netsphere, observability, telemetry

## 简介

Tiny, dependency-free client for shipping HTTP telemetry to NetSphere, with drop-in Express and Fastify middleware.
