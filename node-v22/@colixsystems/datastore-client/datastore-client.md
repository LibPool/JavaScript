# @colixsystems/datastore-client

> 标签: appstudio, client, datastore

## 简介

Typed, scoped data-plane client for the AppStudio datastore API (tables, records, aggregates, record-level permissions, BankID e-signing, realtime subscribe and typing signals). snake_case wire contract, no transform.
