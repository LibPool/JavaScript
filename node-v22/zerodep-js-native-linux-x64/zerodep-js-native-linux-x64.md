# zerodep-js-native-linux-x64

> 标签: JavaScript

## 简介

zerodep-js 原生 Go 编译器的 linux-x64 平台包，由对应架构的 GitHub Actions runner 构建、测试并打包。包含固定 TypeScript 7.1、框架转换、标准库与构建摘要。由 `zerodep-js-native` 的可选依赖选择安装，用户无需 Go。
