# @sfinges/sf-parametros

> 标签: JavaScript

## 简介

Editor reutilizable (agnostico del backend) para un grupo del catalogo `TBLParametros` (Grupo, Nivel, Descripcion, SubGrupo, SubNivel). `SubNivel` es un texto JSON de configuracion.
