# @acetrumtech/svg-to-fabric

> 标签: canvas, converter, design, editor, fabric, fabricjs, layers, svg

## 简介

Turn SVG files into editable, named Fabric.js layers — SVG to Fabric.js JSON with the group hierarchy preserved.
