# @encoradb/drizzle

> 标签: database, drizzle, drizzle-orm, encryption, field-level-encryption, security, typescript

## 简介

Drizzle ORM Adapter for **EncoraDB**. Provides custom column type builders (`encryptedText`, `encryptedJson`) and query result row decryption helpers.
