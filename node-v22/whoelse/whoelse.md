# whoelse

> 标签: antigravity, claude-code, codex, coding-agents, git-worktree, merge-conflicts, parallel-agents, tree-sitter

## 简介

Parallel coding agents merge cleanly and still break each other. whoelse warns an agent the moment another one renames, deletes or changes a function it is using.
