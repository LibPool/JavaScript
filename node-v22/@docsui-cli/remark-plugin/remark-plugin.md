# @docsui-cli/remark-plugin

> 标签: ai, callout, datatable, diagram, docsui, highlight, markdown, mdx, mermaid, plugin, remark, steps

## 简介

Remark plugin + string pre-processor — converts AI-generated markdown (blockquotes, tables, mermaid diagrams, numbered lists) to docsui components automatically
