# @expanso/bacalhau-node-sdk

> 标签: JavaScript

## 简介

This SDK provides a simple, high-level interface for interacting with a [Bacalhau](https://bacalhau.org) orchestrator from a Node.js application. It allows you to list nodes, submit jobs, query job results, inspect job history, and retrieve agent metadata
