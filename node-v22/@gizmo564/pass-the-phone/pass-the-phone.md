# @gizmo564/pass-the-phone

> 标签: JavaScript

## 简介

One-device handover: key-based cover gate (PassGate + pass-gate-state), re-cover on hidden tab or idle, and a PassCover screen. Logic adopted from the former game-kit/pass-the-phone (removed).
