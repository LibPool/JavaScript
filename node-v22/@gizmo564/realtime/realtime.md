# @gizmo564/realtime

> 标签: JavaScript

## 简介

For real-time (not turn-based) games: a bots plugin where every bot and every away player has its own timer, so other players' moves never reset or starve them. The game supplies a plan (action + delay); the plugin supplies timing, lobby bots, away flags
