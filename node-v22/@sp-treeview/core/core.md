# @sp-treeview/core

> 标签: cascade, checkbox, headless, lazy-loading, state, tree, tree-view, treeview, typescript

## 简介

Zero-dependency headless state engine for tree views: data projection, cascade/indeterminate selection, lazy loading, filtering. Renders nothing — bring any UI.
