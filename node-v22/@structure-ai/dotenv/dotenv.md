# @structure-ai/dotenv

> 标签: JavaScript

## 简介

First-class .env support on Effect: dotenv-compatible parsing, variable expansion, environment cascade (.env, .env.local, .env.<env>, .env.<env>.local), lossless file edits, required-key checks, and a CLI command group.
