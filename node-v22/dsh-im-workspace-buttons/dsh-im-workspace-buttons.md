# dsh-im-workspace-buttons

> 标签: channel-filter, deepseek-harness, dsh, dsh-im, dsh-plugin, workspace

## 简介

工作区旁按钮 — one 28x28 channel entry per @xmanrui/dsh-im channel that holds an account, in the official 工作区 header row; pressing one filters the session list to that channel. Extracted from eva-inspired-theme so the control installs without the skin.
