# @logos-kit/client

> 标签: basecamp, client, dapp, lez, logos, logos-execution-zone, wallet

## 简介

Typed client for the Logos Execution Zone: node reads, LWS-0 wallet actions, lossless u128 JSON. QML-safe root; raw-key signing in ./local.
