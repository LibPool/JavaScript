# @limeyfy/react-client-cms

> 标签: JavaScript

## 简介

This package is perfect for you who is going to build a admin panel or a cms solution. `ClientCms` Generates a form based on a `js` object you pass and will handle validation and errors and give you a stunning form. Also gives you a lot of customization
