# @jagpav/pipeline

> 标签: compensable-pipeline, compensation, orchestration, pipeline, rollback, saga, typescript

## 简介

A compensable pipeline for TypeScript: thread a model through ordered steps, auto-compensating completed steps in reverse order on failure.
