# vue-greenborn-image-viewer

> 标签: canvas, greenborn, image-viewer, overlay, pan, rotate, viewport, vue, vue3, zoom

## 简介

Visor de imagen para Vue 3: núcleo de viewport reutilizable con zoom (rueda y botones, centrado en el cursor), pan (Ctrl+arrastre) y rotación libre con preview recortado. Expone un slot para overlays (ej. canvas de anotaciones/detecciones) sincronizados c
