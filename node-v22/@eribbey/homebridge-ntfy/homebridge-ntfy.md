# @eribbey/homebridge-ntfy

> 标签: homebridge, homebridge-plugin, notifications, ntfy, ntfy-sh, self-hosted

## 简介

Homebridge plugin to send notifications through ntfy from HomeKit, with support for custom self-hosted servers and authentication
