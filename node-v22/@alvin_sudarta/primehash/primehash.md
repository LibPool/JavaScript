# @alvin_sudarta/primehash

> 标签: bcrypt, cryptography, hashing, hmac, keccak, password, pbkdf, prime, salt, security, sha, sponge

## 简介

An original password hashing scheme integrating a Keccak-based sponge construction with an adaptive prime-number-based salting mechanism.
