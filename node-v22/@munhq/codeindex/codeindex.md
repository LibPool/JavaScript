# @munhq/codeindex

> 标签: ai-agents, claude, code-intelligence, context-window, mcp, mcp-server, model-context-protocol, tree-sitter

## 简介

Structural code intelligence for AI coding agents over MCP: find a definition, read one function, see what calls a symbol, trace imports and judge a change's blast radius across 40+ languages — in tens of tokens instead of the ~1,563 a file read costs.
