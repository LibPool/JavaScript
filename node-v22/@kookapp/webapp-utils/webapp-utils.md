# @kookapp/webapp-utils

> 标签: kook, shared, utils, webapp

## 简介

KOOK webapp（host + 所有 PC Remote）专用的纯函数 utils 仓库。承接 webapp 端 _shared/utils/ 的内容（date / color / math / debounce / throttle / deepCopy / semver / 等），与 @k/utils（h5 + 跨端 KRequest / KResult 体系）刻意分裂，避免相互维护牵动。
