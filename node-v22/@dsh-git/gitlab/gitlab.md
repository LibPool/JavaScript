# @dsh-git/gitlab

> 标签: deepseek, dsh, dsh-plugin, git, gitlab, harness, merge-requests

## 简介

GitLab adapter for gitPlatform: REST v4 endpoints over Node fetch, normalized into the gitPlatform vocabulary (merge requests, issues, releases, pipelines, vulnerability findings).
