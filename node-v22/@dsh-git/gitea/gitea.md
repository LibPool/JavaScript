# @dsh-git/gitea

> 标签: deepseek, dsh, dsh-plugin, git, gitea, harness, self-hosted

## 简介

Gitea adapter for gitPlatform: OpenAPI/Swagger REST (GitHub-shaped responses) over Node fetch, also the template for generic self-hosted git hosts.
