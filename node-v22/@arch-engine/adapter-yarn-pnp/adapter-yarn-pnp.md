# @arch-engine/adapter-yarn-pnp

> 标签: adapter, arch-engine, extraction, monorepo, plug-n-play, pnp, topology, workspace, yarn, yarn-berry, yarn-pnp

## 简介

Safe, package.json-shape-based workspace topology extraction adapter for Yarn Berry / Plug'n'Play repositories. Does not execute .pnp.cjs.
