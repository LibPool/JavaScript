# @kwirthmagnify/kwirth-plugin-nettools

> 标签: dns, kubernetes, kwirth, network, plugin

## 简介

Net tools channel for Kwirth - resolves DNS names and checks TCP ports from where Kwirth runs, and charts the round trips, through the nettools DCE
