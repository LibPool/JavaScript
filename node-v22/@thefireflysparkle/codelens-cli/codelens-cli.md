# @thefireflysparkle/codelens-cli

> 标签: cli, code-review, gemini, llm, mistral, multi-agent, ollama, rag

## 简介

Multi-agent LLM code review tool. A context agent builds RAG embeddings over your codebase and feeds a review agent that reasons over git diffs, streaming its review token-by-token.
