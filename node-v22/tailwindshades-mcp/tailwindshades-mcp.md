# tailwindshades-mcp

> 标签: ai, color, mcp, mcp-server, model-context-protocol, oklch, palette, tailwind, tailwindcss

## 简介

MCP server that gives AI agents correct Tailwind CSS palettes (50–950) from any color, for Tailwind v4, v3, v2 and v1
