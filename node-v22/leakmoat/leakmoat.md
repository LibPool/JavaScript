# leakmoat

> 标签: anthropic, api-keys, git-history, leak, openai, scanner, secrets, security

## 简介

Find leaked API keys (OpenAI, Anthropic, Gemini, Stripe, AWS and more) in your code and git history. Runs locally, zero dependencies.
