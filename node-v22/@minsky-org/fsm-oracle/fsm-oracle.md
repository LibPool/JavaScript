# @minsky-org/fsm-oracle

> 标签: JavaScript

## 简介

Ask an xstate machine "is this edge legal, and where does it land" without spawning an actor. The machine is the single source of truth for a lifecycle; every guard, every permission check, every UI affordance asks it the same way.
