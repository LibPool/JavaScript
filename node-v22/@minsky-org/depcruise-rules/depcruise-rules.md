# @minsky-org/depcruise-rules

> 标签: JavaScript

## 简介

The eleven portable dependency-cruiser rules of a domain-oriented modular monolith with hexagonal segments: `domain/` pure, `query/` reads, `repo/` writes, `commands/` orchestrate, handlers are the sink, `shared/` never imports a module, no cycles, no orp
