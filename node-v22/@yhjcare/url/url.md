# @yhjcare/url

> 标签: JavaScript

## 简介

一款 URL 网址传参操作插件，可以单个或批量的对网址 hash 或 search 参数进行增删改查操作。亮点是容错能力强，可批量操作，可以开启错误或无效参数自动过滤。
