# @cliftonc/pptx-to-json

> 标签: json, ooxml, parser, powerpoint, pptx, slides

## 简介

Parse PowerPoint files (PPTX) and PowerPoint clipboard data into structured JSON — slides in presentation order, titles, speaker notes, geometry, connectors, tables and images.
