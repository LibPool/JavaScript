# @chainberry/expo-wallet-sdk

> 标签: bitcoin, blockchain, ethereum, expo, litecoin, react-native, self-custody, solana, ton, tron, wallet, xrp

## 简介

React Native / Expo wallet SDK — multi-chain wallet lifecycle, signing, sending, balances and validation, backed by @chainberry/trust-wallet-core's native self-custody module and the berry-stream broadcast/read API
