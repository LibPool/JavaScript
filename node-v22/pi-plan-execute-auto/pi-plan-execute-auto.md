# pi-plan-execute-auto

> 标签: acceptance, coding-agents, commit, extension, git, isolation, pi, pi-coding-agent, pi-extension, pi-package, plan, plan-execute, planning, review, sandbox, subagents, workflow

## 简介

Plan-and-execute workflow for Pi coding agent: human-approved phased plans, isolated per-phase execution, independent Executor and Reviewer agent CLI sessions, deterministic acceptance, rework loops, one validated git commit per phase, and resumable pause
