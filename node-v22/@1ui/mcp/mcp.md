# @1ui/mcp

> 标签: JavaScript

## 简介

Model Context Protocol server for [1UI](https://1ui.dev). It lets MCP clients such as Claude Code, Cursor, and Windsurf inspect and edit designs through the running app, reusing the same tool definitions as the built-in AI chat.
