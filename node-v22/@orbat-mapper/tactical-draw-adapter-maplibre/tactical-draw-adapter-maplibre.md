> 标签: app-6, control-measures, draw, edit, gis, maplibre, maplibre-gl, mapping, mil-std-2525, tactical-graphics

## 简介

MapLibre GL JS engine adapter for @orbat-mapper/tactical-draw. Draw and edit tactical control measures (MIL-STD-2525 / APP-6) on a MapLibre map.
