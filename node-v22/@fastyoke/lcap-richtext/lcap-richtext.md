# @fastyoke/lcap-richtext

> 标签: editor, fastyoke, lcap, richtext

## 简介

Richtext editor peer package for the FastYoke SDK's <SmartField /> resolver. Lazy-loaded by SmartField when an annotation row's @ui/component = 'richtext'.
