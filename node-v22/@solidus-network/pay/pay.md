# @solidus-network/pay

> 标签: checkout, crypto, eip-3009, non-custodial, payments, solana-pay, stablecoin, usdc, x402

## 简介

Solidus Pay SDK: invoices, payments, webhook verification and an embeddable checkout for a non-custodial crypto and stablecoin checkout.
