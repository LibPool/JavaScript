# @dreamtree-org/erp-sdk

> 标签: api-client, dreamtree, erp, korm, sdk

## 简介

Typed client SDK for the Dreamtree-Org ERP — Bearer-token access to all KORM models and services, governed server-side by the token's scope and permissions.
