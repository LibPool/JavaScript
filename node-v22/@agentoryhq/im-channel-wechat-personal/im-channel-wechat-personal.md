# @agentoryhq/im-channel-wechat-personal

> 标签: JavaScript

## 简介

Personal WeChat (iLink bot) channel adapter for Agentory — outbound long-poll against ilinkai.weixin.qq.com, no public webhook endpoint, single chats only
