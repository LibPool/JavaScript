# @pingroom/openclaw-plugin

> 标签: JavaScript

## 简介

OpenClaw channel plugin for PingRoom: phone pings, tappable Questions, approvals, and handoffs from any OpenClaw agent.

## 官网

- 官网：https://pingroom.io/connect-openclaw.md
- 源码仓库：git+https://github.com/pingroom/skills.git
