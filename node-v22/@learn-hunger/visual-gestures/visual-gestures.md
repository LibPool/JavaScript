> 标签: Hand Gestures, J.A.R.V.I.S, Touchless Interface, User Experience Innovation, VisualGestures.js, data, debugging tools, kit, landmarks, skelton, tensorflow, tensorflowjs, visual gestures, visualisation, visualization

## 简介

VisualGestures.js is a package that empowers users to effortlessly control the cursor, including actions such as hover, click, drag, and drop, through precise finger movements in the air.
