# @npaw/forge-react-native-video

> 标签: JavaScript

## 简介

react-native-video adapter glue for NPAW Forge: attaches the native Media3/AVPlayer Forge adapters to react-native-video's internal players via its native plugin API (react-native-video 6 and 7 generations, one major each).
