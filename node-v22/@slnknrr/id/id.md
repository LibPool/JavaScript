# @slnknrr/id

> 标签: decode, feistel, generator, id, permutation, typescript, ulid, uuid, uuidv4, uuidv7, uuidv8

## 简介

ULID and UUID (v4, v7, v8) generators as callable instances: CSPRNG, or a CSPRNG-free reversible permutation of (time, counter); stringify/parse for the 16-byte form, encode/decode for the payload.
