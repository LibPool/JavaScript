# evergist

> 标签: ai-agents, burn-after-reading, cli, e2ee, encryption, mcp, mcp-server, pastebin, secret-sharing, self-destructing

## 简介

Share end-to-end encrypted, self-destructing text from the terminal or any MCP client. Encryption happens locally; evergist.com only stores ciphertext.
