# @dendrite-lang/link

> 标签: dataflow, dendrite, messageport, remote, replica, websocket

## 简介

Drive a Dendrite ProgramInstance across a channel: a host serves one, an editor connects a replica. The message shapes are Dendrite's; the pipe is the host's.
