# @nestjs-dash/db-seeder

> 标签: JavaScript

## 简介

Standalone, ORM-agnostic database seeding tool (JSON/CSV/entity/mapping input, transactional inserts, CLI) with optional adapters for TypeORM/Prisma/Drizzle/MongoDB
