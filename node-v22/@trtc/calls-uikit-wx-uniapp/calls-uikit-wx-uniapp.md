# @trtc/calls-uikit-wx-uniapp

> 标签: call, miniprogram, trtc, tuicallengine, tuicallkit, uikit, uniapp, vue2, vue3, wechat

## 简介

TUICallKit WeChat mini-program UIKit for UniApp (Vue 2 & Vue 3 + @trtc/call-engine-lite-wx). Provides composable hooks, call service logic, Vue components, and static assets.
