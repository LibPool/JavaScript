# @vite-plugin-stickynote/vue

> 标签: annotation, comments, feedback, overlay, qa, review, vite, vite-plugin, vue, vue3

## 简介

In-app comment overlay for Vue dev environments — pin coordinates, threads, and replies, persisted via a Cloudflare Worker + D1.
