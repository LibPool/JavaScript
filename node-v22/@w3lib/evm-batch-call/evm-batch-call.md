# @w3lib/evm-batch-call

> 标签: batch, batch-transfer, disperse, eip-7702, ethcall, ethereum, ethers, evm, multicall, multicall3

## 简介

Batched EVM/Tron contract reads via Multicall3 with deployless fallback, native balances, RPC failover, auto-batching and staticCall simulation; batch transfer, collect and contract calls (Disperse / EIP-7702). ethcall compatible.
