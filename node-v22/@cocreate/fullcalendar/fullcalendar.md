# @cocreate/fullcalendar

> 标签: collaboration, fullcalendar, html5-framework, javascript-framework, low-code, realtime, realtime-framework, shared-editing

## 简介

A simple fullcalendar component in vanilla javascript. Easily configured using HTML5 attributes and/or JavaScript API.
