# @waveeditor/core

> 标签: ckeditor, ckeditor-alternative, contenteditable, editor, html-editor, prosemirror, quill, rich-text, rich-text-editor, self-hosted, tinymce, tinymce-alternative, tiptap, wave, waveeditor, white-label, wysiwyg, wysiwyg-editor

## 简介

Self-hosted, white-labeled rich-text editor for the web. Accepts legacy editor config strings for easy migration — no external CDN, no GPL contagion.
