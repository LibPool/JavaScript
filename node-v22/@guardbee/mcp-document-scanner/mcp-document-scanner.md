# @guardbee/mcp-document-scanner

> 标签: ai-security, dlp, gdpr, guardbee, kvkk, mcp, ocr, pdf, pii, security

## 简介

MCP server and CLI that finds PII and credentials inside PDFs, screenshots and scanned documents — PDF text extraction plus optional OCR (Turkish and English) — before they reach an LLM
