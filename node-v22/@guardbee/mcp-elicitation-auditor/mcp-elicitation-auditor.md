# @guardbee/mcp-elicitation-auditor

> 标签: ai-security, devtools, elicitation, guardbee, mcp, mcp-security, oauth, security

## 简介

MCP server that scans MCP server code for elicitation anti-patterns in the 2026-07-28 spec: form mode asking for secrets, URL mode pointed straight at a third-party authorize endpoint, and credentials or PII embedded in the elicitation URL
