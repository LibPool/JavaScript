# @guardbee/mcp-slopsquat-scanner

> 标签: ai-security, dependency-confusion, devtools, guardbee, mcp, security, slopsquatting, supply-chain, typosquatting

## 简介

MCP server that checks every dependency declared in package.json/requirements.txt/pyproject.toml against the real npm/PyPI registry -- flags names that don't exist at all (likely LLM-hallucinated dependencies an attacker may have pre-registered, i.e. slop
