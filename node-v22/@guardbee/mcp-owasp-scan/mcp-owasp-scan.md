> 标签: ai-security, ci, devtools, guardbee, mcp, mcp-scanner, mcp-security, owasp, owasp-mcp-top-10, sarif, security, security-scanner

## 简介

OWASP MCP Top 10 scanner: one CLI and MCP server that runs GuardBee's auditors over a codebase or a live MCP server, maps findings to MCP01–MCP10 and grades A–F
