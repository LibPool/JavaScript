# @guardbee/mcp-llm-redteam

> 标签: ai-security, devtools, guardbee, jailbreak, llm-security, mcp, red-team, security

## 简介

MCP server that red-teams a live LLM endpoint or chatbot with canary-based jailbreak/extraction/obfuscation probes to test whether known bypass techniques defeat its guardrails
