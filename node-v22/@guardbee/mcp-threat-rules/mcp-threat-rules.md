> 标签: agent-threat-rules, ai-security, atr, devtools, guardbee, kvkk, mcp, mcp-security, owasp, prompt-injection, security, tool-poisoning

## 简介

GuardBee MCP bridge to Agent Threat Rules (ATR) — evaluate agent/MCP events against the open Sigma-like detection standard for prompt injection, tool poisoning, context exfiltration, and MCP attacks
