# dsh-move-to-workspace

> 标签: conversation, deepseek-harness, dsh, dsh-plugin, move, session, workspace

## 简介

Move a DeepSeek Harness conversation into another workspace: copies the transcript into a new session bound to the target folder, archives the original, and can register a new workspace folder from the picker.
