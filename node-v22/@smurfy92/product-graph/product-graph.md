# @smurfy92/product-graph

> 标签: ai, claude-code, datalog, monorepo, product-specs, ratchet, static-analysis, user-stories

## 简介

Product graph analyzer CLI — extract product facts (user stories, domains, pages, API endpoints, migrations, i18n keys, tests) and enforce Datalog rules on them. Inspired by codegraph-toolkit but for the product layer.
