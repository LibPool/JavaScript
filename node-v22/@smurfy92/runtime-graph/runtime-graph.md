# @smurfy92/runtime-graph

> 标签: codegraph, datalog, dead-code, observability, opentelemetry, runtime-analysis, static-runtime-analysis, typescript

## 简介

Runtime observability framework — captures actual execution graph, joins with codegraph static facts via datalog. The OSS alternative to Datadog Live Code Coverage / JFrog X-Ray.
