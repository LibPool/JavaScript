# @sooperdoopersoftware/music-box

> 标签: JavaScript

## 简介

A rolling barrel of pins plucks a comb as it spins — an editable, swappable music-box visualizer with a built-in Web Audio synth (delay/reverb included). Ships as TypeScript source; consuming Next.js apps should add this package to transpilePackages.
