> 标签: boot, cordis, dsh, dsh-plugin, profile

## 简介

Our own app-boot: assemble a profile (bundle layers + patches) and boot its Cordis tree — replaces the private @deepseek-ai/dsh/profile-boot composition layer while still building on @deepseek-ai/dsh-app-boot.
