# @morlay/sandbox-profile

> 标签: bundle-entry, dsh, dsh-bundle, dsh-plugin

## 简介

可配置沙箱与审批的运行时策略面：禁用官方 sandbox / fs-sandbox 两行、插入替换行、给出访问规则的值，由替换行接管运行时快照（sandbox:policy / approval:policy）。
