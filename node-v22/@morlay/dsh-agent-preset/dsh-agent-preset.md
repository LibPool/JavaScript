# @morlay/dsh-agent-preset

> 标签: agent-preset, dsh, dsh-bundle, preset

## 简介

Personal dsh profile bundle: registers the coding / chat agent presets — each with its own isolated injection channel (context assembler) and injection rows, so no other preset is touched.
