# @morlay/dsh-tool-guidance

> 标签: dsh, dsh-plugin, guidance, tool-guidance

## 简介

Tool guidance for dsh: localized short tool descriptions, trimmed schema and usage groups as one host-plane row. The agent row list lives in the agent presets themselves (shipped or deployment-owned).
