# @morlay/dsh-desktopify

> 标签: desktop, dsh, electron, electron-builder, packaging

## 简介

Desktop packaging tool for dsh workspaces: hosts the upstream dsh-desktop-host child over framed byte pipes, with dev (workspace-linked) and bundle (static, unsigned) modes.

## 官网

- 源码仓库：https://github.com/morlay/better-session.git
- npm 页面：https://www.npmjs.com/package/@morlay/dsh-desktopify
