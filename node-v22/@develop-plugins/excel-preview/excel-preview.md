# @develop-plugins/excel-preview

> 标签: edit, excel-edit, excel-preview, excel-table, vue3

## 简介

一个基于 Vue3 的 Excel 预览和编辑组件，支持导入导出 Excel 文件，以及在线编辑表格数据。
