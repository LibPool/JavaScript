# @openqueue/core

> 标签: background-jobs, bun, jobs, openqueue, queue, typescript, worker

## 简介

Core engine for OpenQueue — typed tasks, queues, schedules, flows, and Drizzle persistence over a pluggable world (delivery transport + durable store).
