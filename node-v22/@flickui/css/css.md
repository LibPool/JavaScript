# @flickui/css

> 标签: components, css, design-system, framework, html, themes, ui, vanilla-js

## 简介

FlickUI — a simple HTML & CSS component framework with a single lightweight JS file for interactivity. Include the CSS + JS and build templates in plain HTML, Bootstrap-style. 47 components, 14 themes.
