# @osdlc/wayfinder

> 标签: cli, just, monorepo, moon, npm-scripts, task-runner, tui

## 简介

Browse and run every task in a repository from one list: a terminal UI where Enter runs the selected task, a live web view, and JSON for scripts. Tasks, installs, tool trust and git hooks come from @osdlc/system-model.
