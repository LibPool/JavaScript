# @osdlc/markdown-contract

> 标签: cli, contract, frontmatter, lint, markdown, markdown-as-data, mdast, remark, schema, sections, tables, typed-model, typescript, validation, yaml, zod

## 简介

Contracts for markdown documents: state what a document type must hold (frontmatter checked by a Zod schema, a grammar over its heading sections, typed tables, lists and code blocks), check it with one parse, and read a passing document back as a typed mo
