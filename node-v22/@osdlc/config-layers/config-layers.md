# @osdlc/config-layers

> 标签: cli, config, paths, xdg, yaml, zod

## 简介

A CLI tool's project and machine config files: the sections the project file is built from, the loader that reads them, the per-OS config directories, the `paths:` map, and the check a command runs before it starts.
