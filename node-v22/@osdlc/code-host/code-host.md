# @osdlc/code-host

> 标签: code-host, forgejo, github, port-and-adapter, pull-request

## 简介

The CodeHost port: what a code host (GitHub, Forgejo) answers about pull requests, with GitHub and Forgejo adapters, a host selector keyed on the git remote, doctor auth probes, and PR-reference parsing. Every shell-out goes through an injected command ru
