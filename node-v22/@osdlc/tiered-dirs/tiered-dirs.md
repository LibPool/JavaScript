# @osdlc/tiered-dirs

> 标签: app-dirs, cache, config, cross-platform, paths, typescript, xdg

## 简介

Machine-local directories for a vendor's products, on two axes: tier (vendor, suite, standalone tool) and home (durable, config, cache, state, logs, runtime), resolved over the per-OS directory table with native or XDG paths, plus an untiered scratch root
