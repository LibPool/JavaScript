# @verifnow/sdk

> 标签: api-client, email-validation, email-verification, iban, phone-validation, typescript, validation, vat, verifnow, vies

## 简介

Official Node.js SDK for the VerifNow validation API — email, phone, IBAN, VAT, SSN, SIN and NIF validation in one call.
