# @ioloco/credentials

> 标签: auth library, authentication, credentials, custom auth, email login, jwt, nextjs, react, refresh-token, zod

## 简介

Next.js authentication toolkit for integrating custom email/password login with your backend API using a JWT-based strategy with refresh token support.
