# @usekibble/cli

> 标签: claude-code, codex, copilot, cost, cursor, github-copilot, observability, tokens

## 简介

The Kibble collector: reports Claude Code, Codex and Copilot usage, per engineer, team, model and repo. Counts only, never prompts, code or paths.
