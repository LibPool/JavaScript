# @xq-labs/data-ui-v3

> 标签: JavaScript

## 简介

一套面向 Vue 3 项目的业务图表组件库，当前公开 `BaseChart`、`BarLineChart`、`PieChart`、`RadarChart` 四个组件，配套 `playground` 示例站点、离线文档、Rollup 发布构建和本地发布脚本。

- 0.1.0
