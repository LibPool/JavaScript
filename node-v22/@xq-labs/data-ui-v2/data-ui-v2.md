# @xq-labs/data-ui-v2

> 标签: JavaScript

## 简介

一套面向 Vue 2 项目的业务图表组件库，当前聚焦 `BaseChart`、`BarLineChart`、`PieChart`、`RadarChart` 四个公开组件，配套 `playground` 示例库、Rollup 发布构建和本地发版脚本。
