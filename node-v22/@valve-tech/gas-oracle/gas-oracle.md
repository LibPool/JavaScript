# @valve-tech/gas-oracle

> 标签: eip-1559, ethereum, evm, fee-market, gas, gas-oracle, gas-price, mempool, viem

## 简介

Multi-tier gas-fee oracle for EVM chains. Computes slow/standard/fast/instant tier recommendations from block-included tips, mempool pending tips, and base-fee trend, with a configurable downside-decay cap and a chain-aware EIP-1559 priority cutoff. viem-
