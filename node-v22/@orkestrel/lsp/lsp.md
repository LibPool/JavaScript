# @orkestrel/lsp

> 标签: diagnostics, json-rpc, jsonrpc, language-server, language-server-protocol, lsp, typescript

## 简介

A typed Language Server Protocol client over an injected byte transport — base-protocol framing, JSON-RPC and protocol guards, and a stdio child-process transport. Part of the @orkestrel line.
