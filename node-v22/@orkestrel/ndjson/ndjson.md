# @orkestrel/ndjson

> 标签: json, ndjson, newline-delimited-json, parser, streaming, typescript

## 简介

A minimal streaming NDJSON parser — chunk-fed parsing of newline-delimited JSON text into records, with partial-line buffering across chunk boundaries and tolerance for malformed lines. Part of the @orkestrel line.
