# @orkestrel/pool

> 标签: connection-pool, fifo, pool, resource-pool, typescript

## 简介

A typed resource pool with optional bounded capacity, FIFO abort-cancellable waiting, validated idle reuse, and an observable lifecycle. Part of the @orkestrel line.
