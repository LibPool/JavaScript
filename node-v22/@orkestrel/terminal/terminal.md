# @orkestrel/terminal

> 标签: cli, prompt, readline, terminal, tty, typescript

## 简介

An interactive terminal-prompt toolkit — a headless prompt state-machine broker, an SSE client bridge, and a raw-mode terminal driver. Part of the @orkestrel line.
