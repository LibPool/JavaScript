# @bronzw/create-discord-js-bot

> 标签: discord.js, init, template

## 简介

Simple CLI tool that helps you create boilerplate/template code for discord.js with vanilla discord.js + discord-akairo! Creates template commands and sets everything up with enviorment variables.
