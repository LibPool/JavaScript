# supabase-grant-lint

> 标签: grant, lint, migrations, postgres, postgresql, postgrest, rls, row-level-security, security, supabase

## 简介

Catch missing RLS, GRANT and REVOKE in Supabase migrations before they ship — tables without row level security, SECURITY DEFINER functions callable by anon, REVOKEs that hit the wrong overload, and tables your client reads but never granted.
