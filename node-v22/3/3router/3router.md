# 3router

> 标签: anthropic, api-proxy, claude-code, llm, proxy, router, typescript

## 简介

本地 Claude Code API 智能路由代理 —— 按消息内容将请求路由到不同上游/模型，支持规则引擎、多上游、系统守护进程与 Web 管理面板。
