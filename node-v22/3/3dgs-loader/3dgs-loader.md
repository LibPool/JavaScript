# 3dgs-loader

> 标签: 3dgs, 3dgs-loader, Gaussian loader, Gaussian splatting, gs, k-spalt, ply, sog, splat, spz

## 简介

A unified, extensible loader framework for efficient loading and processing of 3D Gaussian Splatting (3DGS) data.
