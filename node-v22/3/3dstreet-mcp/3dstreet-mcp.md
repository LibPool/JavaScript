# 3dstreet-mcp

> 标签: 3dstreet, aframe, anthropic, claude, mcp, model-context-protocol, urban-planning

## 简介

Fallback MCP relay for 3DStreet: drive an open 3DStreet tab from clients without WebMCP (Claude Desktop, Claude Code). Browser-embedded agents should use WebMCP directly at https://3dstreet.app — nothing to install.
