# @opensms/sdk

> 标签: africa, api, kenya, messaging, opensms, otp, sdk, sms

## 简介

Official TypeScript/JavaScript SDK for the OpenSMS prepaid SMS API: messages, OTP, batches, lookups, contacts, webhooks and more.
