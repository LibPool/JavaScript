# @onirenaud/node-webgl

> 标签: angle, gpu, headless, node, offscreen, opengl, rendering, three.js, webgl, webgl2

## 简介

Headless WebGL 1 and WebGL 2 for Node.js, powered by ANGLE. Render any WebGL or three.js scene without a browser.
