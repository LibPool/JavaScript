# @bridge-ds/stylelint-plugin

> 标签: bridge, design-system, design-tokens, stylelint, stylelint-plugin

## 简介

Stylelint rule bridge/use-tokens: no raw colors, lengths, radii, shadows, durations or z-index in product CSS where a design token exists. Autofixes exact matches. Reads the tokens through @bridge-ds/core and bridge.config.json.
