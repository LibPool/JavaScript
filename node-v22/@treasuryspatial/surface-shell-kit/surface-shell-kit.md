# @treasuryspatial/surface-shell-kit

> 标签: JavaScript

## 简介

Treasury's surface shell (React, styled-components 6): canvas frame with a top-bar slot, left and right rails, panel dock and shell panel; a missing shell manifest renders a visible contract failure.
