# @bradheitmann/odin-sentinel

> 标签: agent-orchestration, mcp, model-context-protocol, multi-agent, sentinel

## 简介

Portable MCP governance protocol for multi-agent terminal teams: 48 tools, 27 resources, readiness gates, ODIN watchers, receipts, delegation, and closeout over stdio.
