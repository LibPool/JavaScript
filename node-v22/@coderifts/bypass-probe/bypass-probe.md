# @coderifts/bypass-probe

> 标签: agent-governance, bypass, coderifts, evidence, langgraph, openai-agents, probe

## 简介

Probe your own agent installation for paths that reach a governed target without passing the gate. Reports dated, version-pinned evidence — a clean run is evidence, not proof.
