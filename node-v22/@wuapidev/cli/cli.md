# @wuapidev/cli

> 标签: ai-agents, cli, mcp, whatsapp, whatsapp-api, wuapi

## 简介

The wuapi command line: log in from the browser, link a WhatsApp number through a link the person opens (QR or pairing code), run your app with the key, send messages, set up the MCP server and call every endpoint of the wuapi API from your terminal or yo
