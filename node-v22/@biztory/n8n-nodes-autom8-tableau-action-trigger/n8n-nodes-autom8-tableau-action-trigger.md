# @biztory/n8n-nodes-autom8-tableau-action-trigger

> 标签: autom8, data action, n8n-community-node-package, tableau, trigger, webhook

## 简介

Autom8 Tableau Action Trigger node for n8n. Receives data from the Autom8 Tableau dashboard extension via webhook and surfaces it as workflow input.
