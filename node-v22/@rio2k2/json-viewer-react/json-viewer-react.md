# @rio2k2/json-viewer-react

> 标签: component, expand-collapse, highlight, interactive, json, json-editor, json-tree, react, search, tree, typescript, viewer

## 简介

A small, dependency-light React library that renders JSON data as an interactive tree with expand/collapse, search/highlight, copy, and optional inline editing
