# @better-compute/observability

> 标签: better-compute, gpu, metrics, monitoring, observability, prometheus, telemetry

## 简介

Metrics for better-compute: a bounded Prometheus registry, the standard better_compute_* series, a metered IamPort and backlog gauges.
