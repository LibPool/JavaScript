# @better-compute/iam

> 标签: authorization, authz, better-compute, better-iam, iam, multi-tenant, policy, usage-metering

## 简介

The better-iam bridge for better-compute: IAM plugin and catalog, event inbox, authz projection and resolver, the embedded IamPort, usage sink and flag cache.
