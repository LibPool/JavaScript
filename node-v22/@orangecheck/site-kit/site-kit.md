# @orangecheck/site-kit

> 标签: csp, internal, nextjs, orangecheck, seo

## 简介

OrangeCheck family-internal site scaffolding for the .ochk.io Next.js sites: SEO and JSON-LD, security headers and CSP, the local /api/auth/me and session gate, the OG card route, the build-time sitemap, and analytics that never report a page's query or f
