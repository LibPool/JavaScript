# @hypit/gpt-image-kits

> 标签: JavaScript

## 简介

`phone-ugc-v1` is a data-only Text Template for assembling image prompts. Its [source](kits/phone-ugc-v1.svs) emits a fixed iPhone-video capture paragraph, followed by the supplied Text slots in `person` → `shot` → `setting` order, with paragraph separato
