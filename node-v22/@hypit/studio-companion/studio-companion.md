# @hypit/studio-companion

> 标签: JavaScript

## 简介

The stable companion-package ABI understood by Hypit Studio. It carries only presentation, lineage, inspector and interaction DTOs plus helpers that do not encode the official video UI policy. Domain computation and manifests do not depend on it; package
