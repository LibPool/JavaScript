# @hypit/html-program

> 标签: JavaScript

## 简介

`@hypit/html-program` owns Hypit's portable, frame-addressed HTML visual program. It compiles a `Composition` and its absolute `Timeline` into one `HtmlProgram`. It does not launch a browser, encode video, mix audio, or select a local Provider.
