# @hypit/script

> 标签: JavaScript

## 简介

Official raw Script Surface for the Markup Frontend. It parses prose-first named Segment blocks, newline-independent Role Cues, Dual Text, Selection and Moment syntax, and lowers them to a canonical authored Narrative value with exactly `2M + 2N` semantic
