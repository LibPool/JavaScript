# @rxova/react-date-input

> 标签: a11y, accessible, calendar-free, date, date-entry, date-field, date-input, datepicker, headless, intl, iso-date, locale-order, no-calendar, no-date-library, react, segmented, zero-dependency

## 简介

A segmented, keyboard-first date field with no calendar and no date library. Headless, zero-dependency, locale-aware through Intl.
