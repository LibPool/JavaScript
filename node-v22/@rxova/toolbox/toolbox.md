# @rxova/toolbox

> 标签: commitlint-config, eslint-config, monorepo, prettier-config, rxova, tooling, tsconfig, tsdown, vitest

## 简介

The tooling every rxova repository shares: lint, format, commit, build and test presets, and the repo scripts behind the pre-push gate.
