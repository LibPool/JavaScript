# aveecare

> 标签: EVV, HIPAA, api, aveecare, caregiver scheduling, healthcare API, home care, home care software, home health, sdk

## 简介

Official Node.js and TypeScript library for the AveeCare API: patients, visits, caregivers and billing for home care agencies.
