# @byliner/mcp-agent

> 标签: agent, approval, byliner, human-in-the-loop, mcp, modelcontextprotocol

## 简介

MCP server letting an AI agent submit actions for multi-party human approval via Byliner. Cannot approve, reject, or delegate — by design.
