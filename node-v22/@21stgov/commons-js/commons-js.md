# @21stgov/commons-js

> 标签: JavaScript

## 简介

Framework-agnostic progressive-enhancement runtime for Commons — makes the .cui-* / data-slot markup interactive (accordion, dialog, menus…) with no framework.

## 官网

- 官网：https://commonsui.com
- 源码仓库：git+https://github.com/21stGov/commons.git
