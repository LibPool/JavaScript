## 简介

A reasoning ladder with no declared default leaves every unnamed call on that route with no reasoning parameter, and llm-pi-ai reads a missing parameter as explicit off — so a toggle model (Xiaomi MiMo, Moonshot/Kimi) does not think while its effort menu
