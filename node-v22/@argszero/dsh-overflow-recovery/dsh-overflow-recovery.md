# @argszero/dsh-overflow-recovery

> 标签: agent-request-error, compaction, context-overflow, context-window, cordis, deepseek-harness, dsh, fallback, overflow-recovery, plugin

## 简介

A session whose request exceeds the model's context window and whose summarizer cannot fit that same window has no way out: every later message replays the same oversized history into the same 400, so the session is unusable until someone edits the persis
