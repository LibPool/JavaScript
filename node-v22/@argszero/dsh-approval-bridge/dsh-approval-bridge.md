# @argszero/dsh-approval-bridge

> 标签: answerer, approval, approval-request, bridge, cordis, deepseek-harness, dsh, plugin, scope, waterfall

## 简介

Lets a plugin answer approval requests. The harness dispatches `approval/request` as a scope-filtered waterfall whose first listener is its own browser forwarder, so a plugin registered after it is never reached and a plugin mounted below an agent scope i
