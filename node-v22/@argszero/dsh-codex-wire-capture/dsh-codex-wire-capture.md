# @argszero/dsh-codex-wire-capture

> 标签: app-server, capture, codex, cordis, deepseek-harness, diagnostics, dsh, json-rpc, plugin, subagent

## 简介

A diagnostic plugin that records the Codex-side failure detail the subagent provider drops. When subagent_codex fails, the parent is told `Product subagent failure (product: Codex; stage: turn; category: product-error)` and nothing else: the wire's failur
