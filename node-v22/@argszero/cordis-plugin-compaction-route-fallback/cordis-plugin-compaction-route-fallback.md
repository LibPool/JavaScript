# @argszero/cordis-plugin-compaction-route-fallback

> 标签: compaction, context-window, cordis, deepseek-harness, dsh, fallback, llm, plugin, purpose

## 简介

Route fallback for a dsh compaction summary call the session's own window cannot fit: dsh-compaction-basic replays the shadowed region unbounded, so on a small-window route the call that must shrink the surface is rejected by it and the session self-locks
