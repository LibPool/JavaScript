# @midwayjs/serverless-scf-starter

> 标签: JavaScript

## 简介

本模块用于包裹无法定制运行时的 FaaS 平台，比如腾讯云 SCF。

## 官网

- 官网：https://github.com/midwayjs/midway#readme
- 源码仓库：git+ssh://git@github.com/midwayjs/midway.git
- npm 页面：https://www.npmjs.com/package/@midwayjs/serverless-scf-starter
