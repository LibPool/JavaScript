# @threahq/harness-client

> 标签: agent, harness, threa, tmux

## 简介

Helpers shared by the Threa harness daemon and the tmux-driven runtimes it supervises: harness link records, harnessd kick/reconnect, allowlisted tmux keys, and the supervisor socket. The public bot protocol lives in @threahq/bot-runtime-client.
