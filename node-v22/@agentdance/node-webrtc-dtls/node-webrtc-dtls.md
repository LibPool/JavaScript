# @agentdance/node-webrtc-dtls

> 标签: dtls, ecdhe, node, rfc6347, tls, typescript, webrtc

## 简介

RFC 6347 DTLS 1.2 transport — full handshake, ECDHE P-256, AES-128-GCM, self-signed cert via pure ASN.1/DER. Part of the @agentdance/node-webrtc stack.
