# @cbortech/cbor-cli

> 标签: binary, cbor, cbor-edn, cddl, cddl-validation, cdn, cli, diagnostic-notation, serialization

## 简介

Command-line tool to convert between CBOR binary data, CDN (Concise Diagnostic Notation) text, and annotated hex dumps
