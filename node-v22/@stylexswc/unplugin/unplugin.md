# @stylexswc/unplugin

> 标签: astro, atomic-css, css-extraction, css-in-js, esbuild, farm, napi-rs, nuxt, rollup, rsbuild, rspack, rust, stylex, swc, unplugin, vite, webpack

## 简介

Universal StyleX plugin for Vite, webpack, Rspack, Rollup, esbuild, Farm, Rsbuild, Nuxt, and Astro, powered by a Rust NAPI-RS/SWC compiler.
