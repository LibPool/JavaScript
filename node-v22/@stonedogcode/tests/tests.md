# @stonedogcode/tests

> 标签: dashboard, inventory, metrics, test-coverage, test-pyramid, testing

## 简介

A test-inventory surface for a fleet of repositories: how many tests each project has, at which tier, in which language, collected from projects that declare their tiers rather than having them guessed.
