# @pallasoft/ps-jev

> 标签: JavaScript

## 简介

Shared Pallasoft client for Jev AI (TypeSafe, model `jev-latest`). Jev decides first; keywords are the fallback when Jev is unreachable or unsure; then a default value. Plain `fetch`, no SDK, so it runs in Node and Cloudflare Workers.
