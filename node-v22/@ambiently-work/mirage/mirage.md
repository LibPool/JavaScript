# @ambiently-work/mirage

> 标签: agent, browser, filesystem, in-memory, mirage, overlay, sandbox, snapshot, virtual-filesystem

## 简介

Mirage — a pluggable in-process virtual filesystem. Pure-JS, browser and server, with snapshot/restore, layered overlays, and disk/repo loaders.
