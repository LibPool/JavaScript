# @sorokit/wallet-adapter

> 标签: JavaScript

## 简介

Adapter-agnostic wallet connection and signing layer for Sorokit. Bring your own connector via a WalletAdapter, or use the stellar-wallets-kit or blux adapters Sorokit ships.
