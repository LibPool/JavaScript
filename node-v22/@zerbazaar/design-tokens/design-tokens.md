# @zerbazaar/design-tokens

> 标签: JavaScript

## 简介

Zer Bazaar design tokens — Style Dictionary v4 source of truth for color, typography, spacing, radius, elevation. Outputs CSS, Tailwind preset, Dart, and flat JSON.
