# @mandateai/cli

> 标签: agent-orchestration, agents, claude-code, cli, imperial-court, mandate, multi-agent, openclaw, scaffold

## 简介

Mandate CLI — scaffold and operate self-governing multi-agent imperial courts. Provides create / validate (live) and genesis / evolve / run / court / audit / ratify / veto / status / explain (v0.4).
