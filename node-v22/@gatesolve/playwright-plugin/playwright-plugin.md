# @gatesolve/playwright-plugin

> 标签: ai-agent, anti-captcha, automation, bot-detection, browser-automation, captcha, captcha-bypass, captcha-solver, cloudflare, cloudflare-turnstile, gatesolve, hcaptcha, hcaptcha-solver, mcp, model-context-protocol, playwright, playwright-extra, recaptcha, recaptcha-solver, turnstile, web-testing

## 简介

Automatic CAPTCHA solving for Playwright and playwright-extra. Detects and solves Cloudflare Turnstile, reCAPTCHA v2/v3, and hCaptcha via GateSolve API. Free tier included.
