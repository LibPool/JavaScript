# tagsets-vue

> 标签: bcp47, glyphs, icons, keyboard, lucide, math, spdx, universal-dependencies, vue

## 简介

Tagsets glyphs as Vue 3 components: licenses, locales, part-of-speech tags, tech abbreviations, keys and math symbols on Lucide's 24px stroke grid.
