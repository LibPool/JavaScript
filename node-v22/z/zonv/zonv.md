# zonv

> 标签: config, config-management, configuration, dotenv, env, env-vars, environment, environment-variables, json-config, runtime-validation, schema, settings, type-safe, typescript, validation, zod

## 简介

Type-safe configuration management with Zod schema validation. Load config from JSON files and environment variables with full TypeScript support.
