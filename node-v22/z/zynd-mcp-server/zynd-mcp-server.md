# zynd-mcp-server

> 标签: agent-discovery, agentdns, ai-agents, ed25519, mcp, micropayments, model-context-protocol, x402, zyndai

## 简介

MCP server that turns Claude into a Zynd network agent: auto-bootstraps developer + persona, runs a parallel inbox for incoming A2A traffic, lets Claude call other agents over sync/push channels, and recognizes push-callback replies from tasks Claude init
