# zedsheet

> 标签: canvas, excel, spreadsheet, wasm, webassembly

## 简介

Web spreadsheet in Rust/WebAssembly — canvas grid, formula engine, styling, merges, charts, CSV/XLSX import-export; embeds in any app via a small JS API
