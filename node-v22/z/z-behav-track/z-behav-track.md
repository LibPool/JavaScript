# z-behav-track

> 标签: JavaScript

## 简介

Behav-Track 是一个专为 Vue 项目设计的行为跟踪工具，旨在帮助你高效地收集和分析用户在应用中的行为数据。本手册将详细指导你如何在 Vue 项目中安装、配置、使用 Behav-Track，并介绍数据埋点和相关注意事项。
