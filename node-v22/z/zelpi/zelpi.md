# zelpi

> 标签: ai, cli, edge-ai, fleet, mcp, pi-os, robotics, simulation, vla, zelpi, zos

## 简介

ZelPi — Physical Intelligence Operating System. A self-contained CLI OS for autonomous robot fleets: kernel QoS router, model registry (VLM/VLA/LLM), MCP server, and an embedded simulation backend. Command: `npx zelpi`.
