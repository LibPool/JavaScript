# zunivo-mcp

> 标签: ai-agents, arc, mcp, payments, usdc, x402, zunivo

## 简介

MCP server that gives AI agents a USDC wallet on Arc — discover .agent services, pay per call over x402, create payment links. Non-custodial, spend-capped.
