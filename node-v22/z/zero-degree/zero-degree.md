> 标签: angle, compass, coordinate, degree, destination, device, direction, earth, expo, geometry, gps, heading, kaba, latitude, location, longitude, magnetometer, phone, place, qibla, react-native, target

## 简介

A module that constantly monitors and returns the direction angle of the target location as the phone rotates or moves. This is a React Native/Expo package.
