# zod-to-mongoose

> 标签: mongodb, mongodb schema, mongodb validation, mongodb zod, mongodb zod schema, mongodb zod validation, mongoose, mongoose zod, mongoose zod schema, mongoose zod validation, schema, ts, types, typescript, validation, zod

## 简介

A library that allows you to create mongoose schemas derived from zod schemas, in an intiutive yet powerful way. Works without the need to add non-standard types to your zod schemas.
