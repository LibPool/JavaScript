# zcode-codegraph-kit

> 标签: ai-coding-agent, code-navigation, codegraph, hooks, mcp, zcode

## 简介

Make ZCode agents reliably explore code with codegraph (MCP) instead of grep — three hook layers + automatic index sync. Pure Node.js, no other runtime needed.
