# zahori

> 标签: archiving, dash, download, hls, live, m3u8, mcp, playwright, stream, video, yt-dlp

## 简介

Find the media stream behind any web page. A real browser drives the player and sniffs out the HLS/DASH/MP4; an optional LLM learns tricky sites and repairs them when they change.
