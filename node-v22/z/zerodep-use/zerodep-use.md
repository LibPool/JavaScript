# zerodep-use

> 标签: JavaScript

## 简介

zerodep-js 的可选应用工具，提供路由、浏览器持久化和编辑历史。通过同版本 `zerodep-js` peer 共享响应式与组件所有权；不依赖 Vue、React 或 Svelte。
