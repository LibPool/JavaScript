# zoho-sprints-mcp

> 标签: agile, ai, llm, mcp, model-context-protocol, project-management, scrum, sprints, zoho, zoho-sprints

## 简介

MCP (Model Context Protocol) server for Zoho Sprints – Manage workspaces, projects, sprints, items, epics, releases, timesheets, meetings, users, and more through natural language.
