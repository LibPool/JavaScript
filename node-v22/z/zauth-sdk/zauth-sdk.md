# zauth-sdk

> 标签: captcha, hashkey, sdk, typescript, verification, zkproof

## 简介

Zero-knowledge CAPTCHA SDK for HashKey Chain — mines PoW, generates a Groth16 proof in the browser, and submits it to an on-chain verifier
