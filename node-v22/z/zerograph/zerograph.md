# zerograph

> 标签: bm25, claude-code, embeddings, knowledge-graph, requirements, search, traceability, typescript

## 简介

Knowledge graph of a repository's requirement docs and code in 24 languages, built and refreshed at zero model tokens, asked by id, keyword or paraphrase
