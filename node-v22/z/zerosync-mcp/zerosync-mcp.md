# zerosync-mcp

> 标签: agenda, assistant, finance, habits, mcp, model-context-protocol, zerosync

## 简介

MCP server (stdio) que expõe as ações do ZeroSync via API REST v1. Autentica com um Personal Access Token (PAT).
