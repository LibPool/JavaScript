# zhihu-advert-preview

> 标签: JavaScript

## 简介

zhihu-advert-preview 是 `zhihu-advert` 的预览组件与 `react-zhihu-adviewer`是同级组件，`zhihu-advert` 是 webpack 打包所以不需要安装多余的依赖。
