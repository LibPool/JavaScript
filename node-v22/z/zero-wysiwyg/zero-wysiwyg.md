# zero-wysiwyg

> 标签: contenteditable, dark-theme, editor, html, i18n, image-resize, lightweight, no-dependencies, vanilla, wysiwyg, youtube

## 简介

A lightweight, zero-dependency WYSIWYG HTML editor with built-in YouTube embeds, image resize, dark/light themes, and i18n
