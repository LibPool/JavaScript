# zigfitsio

> 标签: astronomy, astrophysics, bun, fits, wasm, webassembly, zig

## 简介

TypeScript/JavaScript bindings for zigfitsio — a pure-Zig FITS 4.0 I/O library, shipped as a single WebAssembly module (Bun + Node + browser)
