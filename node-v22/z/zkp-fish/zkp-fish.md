# zkp-fish

> 标签: ZKP, fiat-shamir, javascript, node, non-interactive random oracle access

## 简介

Proof of concept library and helper methods enabling user to authenticate without compromising the password and without shared or public keys. Implements non-interactive random oracle access method for Zero Knowladge Proof - Fiat-Shamir heruistic
