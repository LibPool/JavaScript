# @crewhaus/ui

> 标签: agent, agents, ai, bun, crewhaus, harness, llm, ui

## 简介

Drop-in web UIs for every CrewHaus harness shape, plus a one-command scaffolder. Compile a spec, point @crewhaus/ui at it, get a polished shape-aware UI in the browser.
