# @crewhaus/egress-matcher-semantic

> 标签: JavaScript

## 简介

Optional embedding-backed EgressMatcher — scores outbound payloads against tagged data-lineage by cosine similarity, so semantic (paraphrased / re-encoded) leakage is caught where the substring default would miss it. The default egress path never imports
