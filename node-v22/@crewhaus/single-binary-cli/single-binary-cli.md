# @crewhaus/single-binary-cli

> 标签: JavaScript

## 简介

bun build --compile wrapper producing self-contained crewhaus binaries for linux/macos/windows × x64/arm64; auto-generated Homebrew/apt/Scoop/Winget manifests (Section 32)
