# @crewhaus/target-cf-worker-graph

> 标签: JavaScript

## 简介

Codegen backend for the graph target emitted as a self-contained Cloudflare Worker. Sibling of target-cf-worker-cli; reads the same IrGraphV0 variant, emits a linear single-path graph executor as a Worker bundle.
