# @demouth/mb_strwidth

> 标签: ansi, character, chinese, cjk, full, full-width, fullwidth, japanese, korean, string, unicode

## 简介

Calculates the width of a string, where halfwidth characters count as 1, and fullwidth characters count as 2.
