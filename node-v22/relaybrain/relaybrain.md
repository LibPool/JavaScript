# relaybrain

> 标签: agent-memory, ai-agents, claude-code, codex, coordination, copilot, cursor, falkordb, file-locking, graph, mcp, multi-agent

## 简介

Coordination layer for parallel AI coding agents — file locks, patch sync, Mission Control, and a FalkorDB memory graph that tells every agent who is doing what, and why.
