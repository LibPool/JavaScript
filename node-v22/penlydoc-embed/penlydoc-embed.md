# penlydoc-embed

> 标签: e-signature, electronic-signature, embedded-signing, esign, pdf, penlydoc

## 简介

Show the PenlyDoc e-signature page inside your web app: loads embed.js from PenlyDoc and mounts the signing frame, with TypeScript types.
