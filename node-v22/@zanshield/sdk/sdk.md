# @zanshield/sdk

> 标签: 2fa, authentication, egaz, mfa, zanshield, zanzibar

## 简介

Client library for integrating a system with ZanShield, eGAZ's multi-factor authentication service: builds signed, encrypted tickets and verifies ZanShield's acknowledgements.
