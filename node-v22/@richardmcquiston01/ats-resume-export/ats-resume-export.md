# @richardmcquiston01/ats-resume-export

> 标签: applicant-tracking-system, ats, cv, docx, pdf, resume, typescript

## 简介

Framework agnostic TypeScript package for exporting a resume to an ATS (Applicant Tracking System) compatible format: DOCX, PDF, HTML, plain text, and JSON, plus ATS checks and pluggable validation.
