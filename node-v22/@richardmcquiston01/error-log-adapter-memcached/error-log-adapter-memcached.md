# @richardmcquiston01/error-log-adapter-memcached

> 标签: adapter-pattern, error-logging, logger, memcached, memjs, typescript

## 简介

Memcached adapter for @richardmcquiston01/error-log-adapter: keeps recent errors in memory as expiring entries and a fixed-size ring, so retries never duplicate.
