# @richardmcquiston01/error-log-adapter-cassandra

> 标签: adapter-pattern, cassandra, cql, error-logging, logger, scylladb, typescript

## 简介

Apache Cassandra adapter for @richardmcquiston01/error-log-adapter: writes each error as a row in a time-bucketed error_log table through the DataStax driver.
