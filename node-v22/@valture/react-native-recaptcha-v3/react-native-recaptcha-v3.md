# @valture/react-native-recaptcha-v3

> 标签: abort-signal, android, antibot, bot-protection, captcha, enterprise, google, google-recaptcha, invisible, ios, react-native, recaptcha, recaptcha-v3, score-based, security, spam, typescript, v3, verification

## 简介

React Native component for Google reCAPTCHA v3 (score-based, invisible). TypeScript-first, ref-based API, AbortSignal support, reCAPTCHA Enterprise.
