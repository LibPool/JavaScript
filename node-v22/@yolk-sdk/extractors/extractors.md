# @yolk-sdk/extractors

> 标签: docx, effect, extraction, knowledge, pdf, pptx, xlsx

## 简介

Bounded text extraction for PDF, DOCX, XLSX, PPTX, and text files: an Effect FileExtractor service with Office archive validation, hyperlink-safe XLSX text, and a knowledge extractor adapter.
