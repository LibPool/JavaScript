# @withautonomi/ant-sdk-win32-x64-msvc

> 标签: ant, autonomi, napi-rs, native, storage, web3

## 简介

Direct-network (daemon-less) Autonomi client for Node.js and Electron — native addon over the Rust ant-ffi core.
