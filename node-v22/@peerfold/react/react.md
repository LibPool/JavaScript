# @peerfold/react

> 标签: hooks, lms, peerfold, react, sdk

## 简介

React provider + hooks for the Peerfold API, built on @peerfold/api-client and @peerfold/react-blocks. Plain React, no data-fetching runtime dependency; SSR-safe.
