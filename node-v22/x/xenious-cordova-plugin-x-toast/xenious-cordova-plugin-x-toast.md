# xenious-cordova-plugin-x-toast

> 标签: Alert, Message, Notification, Toast, cordova-android, cordova-blackberry10, cordova-ios, cordova-windows, cordova-wp8, ecosystem:cordova

## 简介

This plugin allows you to show a Toast. A Toast is a little non intrusive buttonless popup which automatically disappears.
