# x402-url-to-markdown

> 标签: ai-agents, html-to-markdown, llm, markdown, mcp, mcp-server, model-context-protocol, rag, reader, robots-txt, scraper, url-to-markdown, web-scraper, web-scraping, x402

## 简介

URL to Markdown for AI agents and LLMs: turn any public web page into clean Markdown (HTML to Markdown, SSRF-safe, robots.txt-aware). MCP server (stdio + remote), zero-dependency library and x402 pay-per-call API ($0.002 USDC on Base).
