# xargs

> 标签: args, arguments, command, command-args, command-arguments, exec, gulp, gulp-shell, run, shell, spawn, stream, streaming-spawn, unix, xargs

## 简介

Build and execute command lines from a input stream. This is the streaming version of the "xargs" unix command.
