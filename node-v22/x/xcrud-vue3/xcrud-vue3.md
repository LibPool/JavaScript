# xcrud-vue3

> 标签: JavaScript

## 简介

这个库是xcrud库的vue3版本。原项目地址：https://www.npmjs.com/package/xcrud ## 使用  用法跟xcrud类似。传参略有不同： - 此版本： ``` <x-form ref="xForm" v-model:propData="formData" :config="formConfig" /> ``` - 原版本： ``` <x-form ref="xForm" v-model="formData" :config="formConfig" /> ```
