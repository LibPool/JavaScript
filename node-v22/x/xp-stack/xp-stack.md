# xp-stack

> 标签: agent, ai, anthropic, claude-code, methodology, multi-agent, pair-programming, scaffolding, tdd, xp

## 简介

Portable XP/Akita methodology for AI coding agents (Claude Code, Codex, Cursor, Antigravity, Gemini CLI): absolute TDD, pair programming, formal research with triangulation, evidence-based task decomposition, policy-aware review, and optional native/headl
