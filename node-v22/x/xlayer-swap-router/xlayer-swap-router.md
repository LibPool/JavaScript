# xlayer-swap-router

> 标签: agent, dex, onchainos, skill, swap, uniswap, xlayer

## 简介

Type what you want and it swaps on X Layer. Parses natural language (dozens of phrasings), quotes OKX OnchainOS and Uniswap in parallel, derives live prices from real quotes, picks slippage from volatility and pool depth, checks the wallet before executio
