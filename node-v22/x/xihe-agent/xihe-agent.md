# xihe-agent

> 标签: agent, bun, coding-agent, deepseek, harness, llm, mcp, model-agnostic, multi-agent, orchestration

## 简介

Xihe — a model-agnostic multi-agent runtime. Wright is its first agent: a terminal coding agent with plan mode, code mode, multi-perspective fan-out, a self-consolidating memory, an MCP router, and a curated skill bundle.
