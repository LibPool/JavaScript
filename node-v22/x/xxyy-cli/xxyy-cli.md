# xxyy-cli

> 标签: JavaScript

## 简介

脚手架前景   为什么需要脚手架？     提供创建项目、项目运行、项目框架、项目打包、项目发布等一系列能力，提升研发效率，简化复杂流程     提供交互式项目创建工具、项目脚手架自带启动和打包命令、自动生成框架模板代码   VueCli与CRA(create-react-app)有什么局限     只能解决本技术域问题，不同技术域需要生产不同的脚手架   如何解决大前端团队底层工程链路的统一问题     需要生产统一的工程化脚手架，解决项目创建、运行、打包、项目模板代码问题
