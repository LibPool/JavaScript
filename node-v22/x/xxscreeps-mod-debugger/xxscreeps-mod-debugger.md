# xxscreeps-mod-debugger

> 标签: debugger, devtools, screeps, screepsmod, xxscreeps

## 简介

Chrome DevTools debugging for xxscreeps player code: connects a DevTools frontend to the per-user isolated-vm inspector session, enabling breakpoints, stepping, and live inspection of running user scripts.
