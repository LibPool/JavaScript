# x-json-transform

> 标签: data-manipulation, declarative, json, json-mapper, lodash-alternative, schema, transform, transformation, typescript

## 简介

A lightweight and powerful JSON transformation library that allows you to reshape JSON objects using a declarative schema. Supports path extraction, custom logic application, and chained operations.
