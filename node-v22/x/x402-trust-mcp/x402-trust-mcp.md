# x402-trust-mcp

> 标签: agent, ai-agent, base, crypto, mcp, model-context-protocol, onchain, reputation, trust, usdc, x402

## 简介

MCP server for x402 endpoint trust & reliability data. Free ecosystem stats, leaderboard, trust preview, and watch polling; paid per-endpoint trust scores, bulk scoring, endpoint history, and 30-day watches over x402, with optional auto-pay. Backed by x40
