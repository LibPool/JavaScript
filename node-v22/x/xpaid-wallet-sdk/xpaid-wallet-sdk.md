# xpaid-wallet-sdk

> 标签: JavaScript

## 简介

A robust, event-driven SDK for seamless iframe-based wallet interactions. Designed for embedding within partner applications, `XpaidWalletSdk` simplifies secure communication with the Xpaid Wallet.
