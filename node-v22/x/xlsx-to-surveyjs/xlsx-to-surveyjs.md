# xlsx-to-surveyjs

> 标签: converter, excel, surveyjs, xlsx

## 简介

Convert XLSX sheets (each sheet = form/page) into SurveyJS JSON. CLI + Node API.

## 官网

- npm 页面：https://www.npmjs.com/package/xlsx-to-surveyjs

- npm registry：https://registry.npmjs.org/xlsx-to-surveyjs
- Node 要求：>=16
