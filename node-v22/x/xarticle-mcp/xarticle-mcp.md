# xarticle-mcp

> 标签: claude, codex, markdown, mcp, model-context-protocol, obsidian, twitter, x

## 简介

MCP server that saves X (Twitter) Articles as Obsidian-faithful Markdown with locally-downloaded images and video. One tool: xarticle <url>.
