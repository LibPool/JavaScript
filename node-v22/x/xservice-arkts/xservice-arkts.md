# xservice-arkts

> 标签: arkts, flutter, harmonyos, ohos, plugin, xservice, xservice_kit

## 简介

A tool to generate xservice_kit based flutter plugin with support for ArkTS/OHOS. Forked from https://www.npmjs.com/package/xservice.
