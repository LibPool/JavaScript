# xinjianxue-raw-report-mcp

> 标签: mcp, raw-report, stdio, xinjianxue, 心鉴学

## 简介

心鉴学原始报告 MCP：获取特征编码+内容，鉴权计费。v1.4.0 计费调整：基础信息(静态) 3积分/人，完整信息(动态) 只扣10元余额/人（不扣积分）；v1.3.0 价格调整：基础信息(静态) 3积分/人，完整信息(动态) 10积分/人；v1.2.0 新增本地身份验证器 owner_bind/owner_verify/get_current_time/owner_status（标准 TOTP）；v1.1.2 新增 country 国家参数透传；v1.1.1 起解读方法(prompts)本地缓存+版本
