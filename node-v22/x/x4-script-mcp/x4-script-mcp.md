# x4-script-mcp

> 标签: aiscript, egosoft, mcp, mission-director, modding, model-context-protocol, x4, x4-foundations, xml

## 简介

MCP server for X4: Foundations scripts: checks, the elements and attributes of the game's schemas, expression types, scripts, cues and texts, for AI agents that write AI scripts and Mission Director scripts.
