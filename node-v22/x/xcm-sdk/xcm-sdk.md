# xcm-sdk

> 标签: asset, blockchain, kusama, multi-asset, polkadot, polkadot-js, substrate, token, vmp, xcm, xcm-format, xcmp

## 简介

XCM SDK is a tool that provides an interface to send XCM messages for Substrate based blockchains.
