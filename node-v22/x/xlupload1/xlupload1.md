# xlupload1

> 标签: liumou, xlupload1

## 简介

* 核心目标   - 可复用在不同应用系统项目中的界面通用功能和布局框架。 * 核心功能需求   - 标题区功能     - 可通过系统参数，设置应用系统的系统名称。       - 图和文字方式，或者全图方式，或者全文字方式。     - 集成"我的信息"模块     - 集成"我的消息"模块   - 菜单区功能     - 缺省将一级菜单展示为应用系统首页中的功能模块入口。     - 缺省将二级菜单展示为某个功能模块的一级菜单项。   - 内容区功能     - 缺省传入菜单
