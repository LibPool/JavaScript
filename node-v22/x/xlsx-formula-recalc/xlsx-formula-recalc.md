# xlsx-formula-recalc

> 标签: excel, excel-formulas, exceljs, formula-engine, formula-recalculation, formula-result-not-updating, libreoffice-alternative, node, recalculate-xlsx, sheetjs, sheetjs-recalc, spreadsheet, spreadsheet-formulas, stale-xlsx-cache, workbook, workbook-compatibility-report, workbook-risk-report, workpaper, xlsx, xlsx-cache-doctor, xlsx-calc, xlsx-formula, xlsx-formula-recalculation, xlsx-populate, xlsx-recalc, xlsx-recalculation

## 简介

Diagnose stale cached XLSX formula values and recalculate XLSX formulas in Node.js without Excel, LibreOffice, or browser automation.
