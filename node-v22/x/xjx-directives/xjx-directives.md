# xjx-directives

> 标签: JavaScript

## 简介

调试的时候,每次需要知道传入组件的值是否发生了变化,都是需要在需要的地方打印,写了个自定义logs指令,同步写入组件其他参数,即可在value值发生变化的时候,看到value的最新值.
