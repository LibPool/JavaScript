# x402-webcash

> 标签: agent-payments, bearer-token, e-cash, http-402, micropayments, webcash, x402

## 简介

x402 payment scheme for webcash bearer e-cash — facilitator, middleware, and a transport-agnostic client that auto-settles HTTP 402 challenges from a local wallet.
