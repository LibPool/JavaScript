# x402-seller-mcp

> 标签: ai-agents, claude, crypto, mcp, model-context-protocol, payments, usdc, x402

## 简介

MCP server exposing x402-seller's paid API endpoints (crypto prices, DeFi data, web reading, AI tasks) as tools for AI agents — pay-per-call in USDC over x402, no API key.
