# xlsx-style-fixedver

> 标签: excel, ods, office, spreadsheet, xls, xlsb, xlsm, xlsx

## 简介

xlsx-style-fixedver 修复 xlsx-style 存在的引入 bug 和支持 contentWs['!rows'] = [{ hch: number},{ hch: number}...] 形式写入每行(即 rows)的高度
