# x-account-cleaner

> 标签: cleaner, delete-posts, delete-tweets, playwright, purge, remove-followers, twitter, unfollow, unretweet, vanishx, x

## 简介

Autonomous browser automation CLI tool to delete X (Twitter) posts, replies, reposts, unfollow accounts, and remove followers safely.
