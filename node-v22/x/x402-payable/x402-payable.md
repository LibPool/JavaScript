# x402-payable

> 标签: 402, agentic-payments, ai-agents, base, ci, lint, payments, stablecoin, usdc, x402

## 简介

Is this x402 endpoint actually payable? Checks a URL against the traps that let an endpoint return a valid 402 while still not being something you can buy. Zero dependencies, no account, no third-party calls.
