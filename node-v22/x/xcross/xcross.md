# xcross

> 标签: aes, browser, cross, crypto, cryptography, decryption, digest, ecdh, edrsa, encryption, generate, hash, hasher, hashing, hmac, isomorphic, key, keys, node, pairs, pbkdf2, rsa, rsassa-pkcs1-v1.5, sha1, sha256, sha384, sha512, sign, verify

## 简介

Provides the standard [Web Crypto API](https://www.w3.org/TR/WebCryptoAPI/) for NodeJS and Browser since both support it natively.
