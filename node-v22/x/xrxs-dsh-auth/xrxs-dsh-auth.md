# xrxs-dsh-auth

> 标签: auth, deepseek-harness, device-code, dsh, dsh-bundle, dsh-plugin, session, xinrenxinshi, xrxs, 薪人薪事

## 简介

薪人薪事（Xinrenxinshi）授权插件（DeepSeek Harness 外部 bundle）：机器认证授权（设备码流程）拿 token、access_token 生命周期管理，并向其他插件提供校验有效的 sessionId / ua / csrf。
