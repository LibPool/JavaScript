# x7-lang-loader

> 标签: JavaScript

## 简介

项目中简繁体编译的 Loader，在项目中使用 Loader 后，可以直接将特定文本字符转化，在页面运行时根据设定环境返回简/繁体，无需关心繁体的转化和字库的维护
