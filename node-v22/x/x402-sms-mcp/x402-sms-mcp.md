# x402-sms-mcp

> 标签: agent, ai-agent, claude, mcp, model-context-protocol, paid-api, sms, twilio, usdc, x402

## 简介

MCP server for paid SMS. Agents pay $0.03 USDC per call to send a transactional SMS to a US phone number via x402.
