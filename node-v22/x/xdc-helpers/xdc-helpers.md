> 标签: JavaScript

## 简介

XDC-Helpers is a robust Node.js SDK designed to facilitate interactions with the validator、liteCSC and fullCSC contracts on the chain. With a streamlined setup process and easy-to-use functionalities, it simplifies the process of requesting the validator
