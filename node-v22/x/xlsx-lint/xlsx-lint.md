# xlsx-lint

> 标签: audit, ci, diff, excel, excel-diff, formula, github-action, lint, review, spreadsheet, xlsx, xlsx-diff

## 简介

Find Excel formulas that break their own pattern — in CI. Zero dependencies, runs locally, nothing is uploaded.
