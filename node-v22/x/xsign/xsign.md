# xsign

> 标签: brazil, digital-signature, integra-contador, pkcs12, procuracao, serpro, x509, xml-signature, xmldsig

## 简介

Sign and validate XML documents against the SERPRO Integra Contador XMLDSig profile, extensible to other documents via typed templates.
