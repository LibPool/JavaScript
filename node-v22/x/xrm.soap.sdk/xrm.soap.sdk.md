# xrm.soap.sdk

> 标签: crm, crm365, sdk, soap, xrm, xrm.soap.sdk

## 简介

Package to interact with Microsoft Dynamics CRM 365 from entity form and ribbon like CRM SDK manner (C# or any other .NET lang e.g. VB or F#).
