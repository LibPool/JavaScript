# xmodelnew

> 标签: JavaScript

## 简介

可控参数： 	title-标题； 	content-内容 	cancelTxt-取消按钮文字, 	sureTxt-确定按钮 	isOneBtn-是否只显示一个确定按钮 	cancelFun-取消按扭回调, 	sureFun-确定按钮回调
