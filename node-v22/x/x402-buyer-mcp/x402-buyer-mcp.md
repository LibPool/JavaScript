> 标签: agent, agent-economy, agentcash, ai-agent, api, base, buyer, claude, cursor, decixa, discovery, intelligence, mcp, micropayments, payments, usdc, x402

## 简介

Universal x402 buyer agent — discover, pay for, and call any x402 endpoint from Claude Desktop, Cursor, or Claude Code. Discovery powered by Decixa (5,500+ verified endpoints) with local registry fallback. Payment via AgentCash USDC on Base.
