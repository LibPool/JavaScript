# xsh-rm

> 标签: cli, cross-platform, delete, rm, safe-delete

## 简介

跨平台安全删除目录工具：先改名、再隐藏、最后逐文件慢删，避免误删与系统卡顿。

## 官网

- npm 页面：https://www.npmjs.com/package/xsh-rm
