# xenia-driver

> 标签: JavaScript

## 简介

[Xenia-driver-js](https://github.com/coralproject/xenia-driver-js) is a Javascript library that performs queries to [Xenia](https://github.com/coralproject/xenia) from the browser and Node.js.
