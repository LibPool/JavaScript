# xlsx-audit-mcp

> 标签: audit, claude, dependency-tracing, excel, financial-model, formula, mcp, mcp-server, model-context-protocol, spreadsheet, xlsx

## 简介

MCP server that audits Excel workbooks — formula dependency tracing, circular-reference detection, and risk smells (INDIRECT, hardcoded constants, external links). Reviews the model, not the data.
