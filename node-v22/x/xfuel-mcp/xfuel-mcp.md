# xfuel-mcp

> 标签: agent-tools, ai, chit402, depin, inference, mcp, model-context-protocol, sp1, xfuel, zk

## 简介

Official MCP server for Chit402 — chat completions (unmetered /v1), paid task submit, quotes, and settlement proofs. Runs over stdio or streamable HTTP.
