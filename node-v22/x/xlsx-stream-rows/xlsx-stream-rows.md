# xlsx-stream-rows

> 标签: async-iterator, browser, chunked, csv, ecma-376, excel, incremental, lazy, low-memory, memory-bounded, on-demand, ooxml, opc, partial, rfc-4180, row-by-row, spreadsheet, stream, streaming, web-worker, xls, xlsm, xlsx, zero-dependency

## 简介

Zero-dependency streaming XLSX/CSV reader for the browser. XLS via optional xlsx peer dep. Bounded memory regardless of file size.
