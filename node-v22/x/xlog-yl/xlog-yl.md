# xlog-yl

> 标签: JavaScript

## 简介

前端统一日志SDK是按照体验技术中心前端日志规范开发的日志采集工具，提供日志采集和上报能力，支持记录访问日志、接口请求日志、操作日志、错误日志、性能日志、自定义日志，为前端监控、问题排查和解决提供了数据基础。
