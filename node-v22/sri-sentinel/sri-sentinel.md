# sri-sentinel

> 标签: astro-integration, cdn, cli, devsecops, esbuild-plugin, github-action, hash, html, importmap, integrity, rollup-plugin, sarif, security, sha384, sri, subresource-integrity, supply-chain-security, vite-plugin, webpack-plugin

## 简介

Subresource Integrity (SRI) generator and checker: hashes <script> and <link> resources in built HTML (sha256/384/512, local and CDN), import maps, lazy webpack chunks, writes integrity + crossorigin, fails CI on missing, wrong or stale hashes. JSON manif
