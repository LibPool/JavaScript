# @opafex/retrieval-core

> 标签: bm25, chunking, embeddings, hybrid-search, idf, lexical-search, llm, rag, retrieval, vector-search

## 简介

Storage-agnostic retrieval for RAG: chunking, IDF-weighted rare-term matching and a vector + lexical merge, over three small ports. Zero dependencies.
