# @opafex/mcp-approval-queue

> 标签: agents, ai-safety, approval, elicitation, guardrails, human-in-the-loop, mcp, model-context-protocol

## 简介

Human-in-the-loop approval gate for AI agents: risk scoring, decisions in the client's own UI via MCP elicitation, and a CLI. The agent can ask; only a human can approve.
