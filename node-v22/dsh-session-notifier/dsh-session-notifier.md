# dsh-session-notifier

> 标签: deepseek-harness, desktop-notification, dsh, dsh-plugin, notifications, session, windows-toast, wsl

## 简介

Desktop notifications for DSH Web sessions: browser notifications plus Windows toasts from WSL when a session finishes, fails, needs an approval, or asks a question. Clicking one opens its session; browser notifications focus an open tab, Windows toasts o
