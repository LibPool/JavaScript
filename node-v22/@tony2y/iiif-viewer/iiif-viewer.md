# @tony2y/iiif-viewer

> 标签: cultural-heritage, deep-zoom, digital-library, iiif, image-viewer, manifest, openseadragon, viewer, vue, vue3

## 简介

A modern IIIF image viewer plugin for Vue 3, built on OpenSeadragon. Supports IIIF Image API 2.x/3.x and Presentation API multi-canvas reading, with built-in i18n, theming and responsive UI.
