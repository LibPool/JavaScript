# @houser/edus-plugin

> 标签: JavaScript

## 简介

用于 DeepSeek Harness Web 的课成品牌与 HTML 发布插件。除保留侧边栏和空会话页的品牌 Slot 外，它为聊天中打开的 HTML 文件提供右侧发布预览。
