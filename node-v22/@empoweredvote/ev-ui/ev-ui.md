# @empoweredvote/ev-ui

> 标签: JavaScript

## 简介

Shared React component library for the [Empowered Vote](https://empowered.vote) civic engagement platform. Used across CompassV2, essentials, read-rank, civic-spaces, and other Empowered Vote apps.
