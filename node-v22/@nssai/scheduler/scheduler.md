# @nssai/scheduler

> 标签: JavaScript

## 简介

MemFlow FSRS scheduling engine shared by all clients. Pure TypeScript, wraps ts-fsrs, aligned 1:1 with the legacy rs-fsrs 6.6.1 schedule() semantics.
