# @agent-sessions/dsh-lane

> 标签: JavaScript

## 简介

`@agent-sessions/dsh-lane` adds Agent Sessions native lane operations to a DSH profile that also loads `@agent-sessions/dsh-comms`. Its hard Cordis service dependency keeps the lane adapter pending until the communications plugin is live.
