# @dragon708/docmind-browser

> 标签: browser, docmind

## 简介

Official DocMind browser facade: analyzeFile and intent APIs (DOCX, image OCR, text, CSV/XLSX spreadsheets). PDF and fs paths use @dragon708/docmind-node.
