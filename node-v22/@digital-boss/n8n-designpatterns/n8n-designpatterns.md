# @digital-boss/n8n-designpatterns

> 标签: JavaScript

## 简介

n8n-designpatterns is a collection of interfaces and classes helping to follow [Segregation of Concerns](https://en.wikipedia.org/wiki/Separation_of_concerns) principle.
