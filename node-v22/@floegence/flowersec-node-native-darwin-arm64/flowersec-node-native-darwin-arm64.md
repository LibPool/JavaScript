# @floegence/flowersec-node-native-darwin-arm64

> 标签: JavaScript

## 简介

This package contains the macOS arm64 prebuilt used by `@floegence/flowersec-node-native`. Applications should use `@floegence/flowersec-core/node` rather than importing this package directly.
