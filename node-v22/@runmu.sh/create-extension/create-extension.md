# @runmu.sh/create-extension

> 标签: create, extension, muclient, mud, runmu

## 简介

Scaffold a μClient extension: npm create @runmu.sh/extension my-ext. TypeScript, esbuild, the SDK types, a Vue or plain-DOM panel, the hot-reload dev server, and optionally a Rust WASM helper.
