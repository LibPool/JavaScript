# @runmu.sh/ext-kit

> 标签: extension, gmcp, muclient, runmu

## 简介

The world-module runtime shared by the first-party μClient extensions (Tickets, Assist, Puppets): per-world enabled/source settings, staff role, Core.Supports, configurable actions, read marks, a payload validator, DOM helpers and the module panel styles.
