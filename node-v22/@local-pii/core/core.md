# @local-pii/core

> 标签: anonymization, expo, gdpr, llm, on-device, onnx, pii, privacy, react-native, redaction

## 简介

Adapter-first PII protection for Expo, React Native, browsers, and Node. Protect personal information before a model boundary, then restore it inside the caller's trust boundary.
