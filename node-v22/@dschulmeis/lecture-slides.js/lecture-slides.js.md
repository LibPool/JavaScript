# @dschulmeis/lecture-slides.js

> 标签: e-learning, slideshow, slideshow-maker

## 简介

A simple JavaScript library for the browser to create slides for online learning. In contrast to other (more powerful) HTML presentation framework each slide may have additional explanations and side notes.
