# pawbrowse

> 标签: browser-automation, cdp, chrome-extension, claude, claude-code, mcp

## 简介

Let Claude Code drive your real, logged-in Chrome. A zero-dependency MCP server + a Chrome MV3 extension that uses element-table perception over CDP. The calling agent is the policy: no second model, no API keys, page snapshots never leave for a third par
