# @svrooij/lumi-aqara

> 标签: aqara, gateway, home, iot, lumi, smart, xiaomi

## 简介

Control your Xiaomi Smart Home devices with this Lumi Aqara library, this is a user scoped release! It is released as a dependency of https://github.com/svrooij/node-xiaomi2mqtt/
