# @r3e/neo-js-sdk

> 标签: blockchain, javascript, n3, neo, neo-js, neo-n3, sdk, typescript

## 简介

Neo N3 JavaScript/TypeScript SDK — successor to neo-js (no longer maintained). Typed models, object-based RPC inputs, full N3 RPC coverage.
