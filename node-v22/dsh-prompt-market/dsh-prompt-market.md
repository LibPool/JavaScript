# dsh-prompt-market

> 标签: dsh, dsh-plugin, prompt-library, prompt-manager, prompt-market, prompts

## 简介

提示词市场（Prompt Market）— DeepSeek Harness 桌面端插件：输入框旁「提示词导入」按钮 + 浮层市场面板；零后端、纯 JavaScript、无编译步骤。
