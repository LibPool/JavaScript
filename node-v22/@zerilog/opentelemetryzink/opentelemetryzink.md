# @zerilog/opentelemetryzink

> 标签: opentelemetry, opentelemetryzink, otel, otlp, zerilog

## 简介

A zink for shipping logs over [OTLP](https://opentelemetry.io/docs/specs/otlp/) (the OpenTelemetry Protocol) using `zerilog`.
