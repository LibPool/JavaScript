# dialpress

> 标签: express, grpc, ivr, pbx, router, sip, telephony, voice-bot, voip

## 简介

Express 5-style SIP & call routing: apps connect to a SIP server over gRPC and handle every SIP method (router.invite, router.register, router.message...)
