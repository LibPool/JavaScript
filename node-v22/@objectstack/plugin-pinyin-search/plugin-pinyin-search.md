# @objectstack/plugin-pinyin-search

> 标签: i18n, objectstack, pinyin, plugin, search

## 简介

Pinyin search recall for ObjectStack — populates the hidden `__search` companion column (full pinyin + initials of the display/name field) so `$search` hits CJK names typed as pinyin. Locale-gated via OS_SEARCH_PINYIN_ENABLED (#2486).
