# @blumintinc/seaport-js

> 标签: JavaScript

## 简介

This package is a fork of [Seaport](https://github.com/ProjectOpenSea/seaport) - a marketplace protocol for safely and efficiently buying and selling NFTs. This is a JavaScript library intended to make interfacing with the contract reasonable and easy.
