# @earthpilot/groundcrew

> 标签: agents, civic, earthpilot, mcp, open-data, protocol

## 简介

Ground Crew: an open protocol and reference MCP server for pointing many people's AI agents at one public problem. Part of EarthPilot, mission support for Spaceship Earth.
