# @sheetpane/mcp

> 标签: JavaScript

## 简介

A Model Context Protocol server for sheetpane: describe the API, inspect a workbook, draft and check a rules file, diff two versions of a workbook, explain an SP code, find a skill — deterministic, read-only, over stdio.
