# @sheetpane/visibility

> 标签: JavaScript

## 简介

Hide and unhide rows, columns and sheets for sheetpane — menus, Google Sheets' shortcuts, a click on the grid's hidden-span markers — written into the download. Core already honours and marks what a file hides.
