# @sheetpane/tables

> 标签: JavaScript

## 简介

Excel tables for sheetpane — each table's header row, banded rows and columns and totals row drawn from its built-in table style, as a plugin on the `decorate` hook. The tables themselves are read by @sheetpane/import.
