# @create-cmp/inspector

> 标签: cmp, compose-multiplatform, design-tokens, inspector, kmp, mcp, model-context-protocol

## 简介

MCP server that reads a running Compose Multiplatform UI as structured JSON (hierarchy + geometry + resolved design tokens) and exposes query/assert/token-drift tools — never screenshots. Phase 0 of the create-cmp inspector.
