# @becos-ai/oc-codecollab

> 标签: JavaScript

## 简介

Opencode plugin: capture sessions to + recall memory from the becos brain, with optional redacted command, output, and code evidence. Bundles a vendored Python deliverer for privacy/auth/dedup — requires python3.
