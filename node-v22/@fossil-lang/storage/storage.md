# @fossil-lang/storage

> 标签: JavaScript

## 简介

Storage access for every @fossil-lang/* package, from credentials the host vends: a scoped DuckDB secret renewed before it expires, an Azure SAS lend, or an object_store request — fossil-storage in WASM.
