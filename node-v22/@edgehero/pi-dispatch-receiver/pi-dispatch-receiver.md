# @edgehero/pi-dispatch-receiver

> 标签: ai-agent, azure-devops, bullmq, coding-agent, docker, forgejo, gitea, github, gitlab, job-queue, pi, pi-coding-agent, podman, polling, self-hosted, webhook

## 简介

The pi-dispatch trigger edge: verifies GitHub, GitLab, Forgejo and Azure DevOps webhooks, or polls GitHub with no public URL, and queues one pi coding agent job per event (per replica, if set) for the worker.
