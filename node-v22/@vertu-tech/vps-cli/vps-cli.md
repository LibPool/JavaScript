# @vertu-tech/vps-cli

> 标签: agent, ai-cli, ai-skills, claude-code, cli, cursor, odoo, trae, vertu

## 简介

Vertu CLI - bridge Odoo ai_cli + ai_skills to a local Node.js command and one-click install skills into Cursor / Claude Code / Trae.
