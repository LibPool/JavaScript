# @shenyeaiwork/dsh-web-search-searxng

> 标签: JavaScript

## 简介

SearXNG-backed web search provider for the DeepSeek Harness web capability seam (ctx.web). Local, keyless metasearch for fully-local model profiles. (Independent build; an alternative implementation exists as unscoped dsh-web-search-searxng.)
