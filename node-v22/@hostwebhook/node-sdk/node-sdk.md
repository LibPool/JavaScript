# @hostwebhook/node-sdk

> 标签: hostwebhook, nodes, sdk

## 简介

El SDK de un nodo de HostWebhook: ciclo de vida, ejecución con iteración, reintentos, filtros y validación de esquema — lo que comparten la api y el futuro servicio de nodos
