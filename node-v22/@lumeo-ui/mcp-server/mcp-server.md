# @lumeo-ui/mcp-server

> 标签: blazor, llm, lumeo, mcp, model-context-protocol

## 简介

Model Context Protocol server for the Lumeo Blazor component library. Lets LLMs (Claude, Copilot, Cursor) author correct Lumeo markup.
