# @inferdi/inferdi

> 标签: container, dependency-injection, di, disposable, fluent-api, inversion-of-control, ioc, no-decorators, scoped, typescript, zero-dependency

## 简介

Zero-dependency, decorator-free, strictly typed DI container for TypeScript. Features scopes, lazy injection, lifetime guards, and explicit async teardown.
