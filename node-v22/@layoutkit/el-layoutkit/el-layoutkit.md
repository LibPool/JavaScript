# @layoutkit/el-layoutkit

> 标签: JavaScript

## 简介

`@layoutkit/el-layoutkit` 是一个基于elementplus ui的工厂函数，用于生成页面基础配置对象，提供表格、表单、对话框、工具栏、消息提示等功能，常用于后台管理系统页面。
