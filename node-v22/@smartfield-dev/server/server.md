# @smartfield-dev/server

> 标签: aes-256, decrypt, encrypt, encryption, form, hipaa, input, password, pci, rsa-2048, security, shadow-dom, smartfield, web-component

## 简介

Server-side SDK for SmartField — decrypt encrypted form data from <smart-field> components. AES-256-GCM + RSA-2048.
