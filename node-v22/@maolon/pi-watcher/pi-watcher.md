# @maolon/pi-watcher

> 标签: agents, long-running-tasks, monitoring, pi, pi-coding-agent, pi-extension, pi-package, watcher

## 简介

Watch long-running Pi tasks without babysitting: deterministic task monitoring, optional semantic review, and relay-delivered wakes only when something needs the host.
