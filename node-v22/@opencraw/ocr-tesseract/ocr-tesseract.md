# @opencraw/ocr-tesseract

> 标签: crawler, ocr, opencraw, pdf, scan, tesseract

## 简介

OCR for scanned PDFs, for OpenCraw: Tesseract (WebAssembly, bundled English model, other languages from @tesseract.js-data packages) behind the engine contract @opencraw/core reads a scan with. Each page is cleaned before it is read (background flattened,
