# @antihero/filidate

> 标签: browser, file, file-upload, image, magic-number, mime, node, pdf, schema, signature, typescript, upload, validation

## 简介

Lightweight, extensible, type-safe file validation for browsers and Node.js. Validates File, Blob, Buffer, ArrayBuffer, Uint8Array and file paths against declarative schemas.
