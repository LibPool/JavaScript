# @react-node-transform/i18n

> 标签: JavaScript

## 简介

@react-node-transform/i18n 提供了一种新的非侵入式的 i18n 解决方案，传统的 i18n 解决方案，例如 i18next，对源代码的侵入性太强，而且要求我们在开发时对每一个新的翻译指定一个不重复的 key，一定程度上增加了代码量和思考成本。
