# @harpd/x402-logging-middleware

> 标签: agent-commerce, agent-payments, express-middleware, harpd, payment-logging, x402

## 简介

Drop-in x402 payment logging middleware for Node HTTP / Express. Structured, audit-friendly logs for every x402 interaction. Zero runtime deps.
