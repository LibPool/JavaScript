# @steffolino/diagram-kit-cli

> 标签: cli, diagram, graph, png, svg, visualization

## 简介

Command-line rendering for diagram-kit: turn YAML/JSON/Mermaid/tree/directory input into an SVG or PNG diagram without writing any code.
