# @apimaster/cli

> 标签: api-key, apimaster, benchmark, claude-code, cli, codex, latency, llm, openai, openai-compatible

## 简介

Test any OpenAI-compatible LLM endpoint from the terminal: validate keys, list models, measure latency, probe model identity, generate images and video. Works with APIMaster.ai and any other OpenAI-compatible gateway.
