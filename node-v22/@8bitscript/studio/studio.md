# @8bitscript/studio

> 标签: JavaScript

## 简介

8BitScript Studio: the asset editor that ships with the toolchain and runs on the machines themselves — characters, sprites, and music, with the full editor on the Commander X16, a smaller one on an expanded VIC-20, and a read-only viewer on the PET and t
