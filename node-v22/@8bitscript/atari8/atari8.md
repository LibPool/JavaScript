# @8bitscript/atari8

> 标签: JavaScript

## 简介

Atari 8-bit target support for 8BitScript: the hardware underneath the portable APIs, for the 400/800/XL/XE/XEGS family. Parked in 0.2.0: not a build target until its native backend lands.
