# @loneship/zup

> 标签: atomic-deploy, cli, deploy, frontend, sftp, ssh

## 简介

一个用于发布本地的前后端目录或可执行文件的命令行工具，负责优雅地替换和部署（仅支持pm2部署的产品），并能自动备份旧版本。
