# @ophis/agent-swap

> 标签: agent, ai-agent, cow-protocol, defi, eip-712, ophis, rebate, swap

## 简介

Framework-agnostic core: execute an Ophis (CoW Protocol) ERC-20 swap from an AI agent's EOA wallet, carrying the Ophis partner fee + referrer code in appData so the integrator earns the rebate. Used by @ophis/plugin-goat and @ophis/agentkit-ophis.
