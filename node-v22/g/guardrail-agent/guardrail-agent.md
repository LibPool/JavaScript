# guardrail-agent

> 标签: ai-agents, ai-safety, claude-code, coding-agents, eu-ai-act, governance, guardrails, pre-execution, security

## 简介

Pre-execution security for AI coding agents. 13 free guards that block dangerous commands and file writes before they run, plus 48 Pro guards. Free 14-day Pro trial included.
