# grapesjs-cloud-assets

> 标签: asset-manager, dropbox, google-drive, grapesjs, grapesjs-plugin, onedrive, s3

## 简介

GrapesJS Asset Manager plugin: browse and insert media from Dropbox, Google Drive, OneDrive, Box and S3-compatible storage through one unified UI.
