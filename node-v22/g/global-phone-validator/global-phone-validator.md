# global-phone-validator

> 标签: E.164, E164, country-code, international, mobile, mobile-phone, phone, typescript, validation, validator, worldwide

## 简介

Comprehensive phone number validator for all countries. Validates mobile, landline, VoIP, toll-free, and premium numbers. Supports 50+ countries with type detection. Returns E.164 format.
