# gbit-db-dados

> 标签: cli, database, embedded, file-based, json, local, nosql, zero-dependency

## 简介

Banco de dados NoSQL local, orientado a arquivos, 100% Node.js puro. Sem dependências externas, sem PostgreSQL, sem MongoDB — só o filesystem.
