# grafana-faro-wrapper

> 标签: faro, frontend-monitoring, grafana, grafana-faro, metrics, observability, opentelemetry, otlp, react, real-user-monitoring, rum, slo, typescript

## 简介

Grafana Faro wrapper for web pages and React apps: one-call setup with OTLP transport, URL and label sanitization, custom metrics and step-based SLO metrics
