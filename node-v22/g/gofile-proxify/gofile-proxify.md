# gofile-proxify

> 标签: downloader, file-download, gofile, gofile.io, proxy, proxy-rotator, scraper

## 简介

Sebuah pustaka Node.js untuk mengunduh file dari Gofile.io dengan dukungan proxy, rotasi kumpulan proxy otomatis, dan pelacakan kemajuan..
