# glimpse-review

> 标签: agent, annotations, claude-code, claude-code-plugin, cli, glimpse, html, markdown, preact, review

## 简介

A small CLI for opening lightweight HTML/Markdown review windows via Glimpse, collecting form input, annotations, and selection comments — designed for agent/user interaction.
