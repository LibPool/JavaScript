# gcode-seer

> 标签: 3d-printer, 3d-printing, analyzer, bambu, extrusion, g-code, gcode, gcode-parser, javascript, prusa, streaming, typescript

## 简介

Dependency-free TypeScript and JavaScript library for streaming 3D printer G-code analysis: motion, extrusion, temperatures and printer constraints.
