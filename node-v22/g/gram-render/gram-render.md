# gram-render

> 标签: bot, generative-ui, jev, system-one, telegram, ui-spec

## 简介

JEV-powered generative UI spec generator for Telegram bot interfaces. Prompt + context in, validated Telegram UI JSON spec out. No transport, no bot framework — the consumer owns rendering and actions.
