# generator-pm

> 标签: documentation, project management, yeoman-generator

## 简介

Yeoman generator for Project Management and Documentation Repository. Project Management and Documentation Repository is just a folder where you can keep all project specs, notes and tasks in a form of regular files. "pm" stays for "Project Management".
