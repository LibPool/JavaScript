# grapesjs-context-menu

> 标签: breadcrumbs, context-menu, grapesjs, grapesjs-plugin, layer-manager, layers, right-click

## 简介

GrapesJS plugin: right-click context menu for the canvas and the Layer Manager (add block inside, select parent/child, reorder, move, clone, delete) plus a clickable hierarchy badge on the selected element.
