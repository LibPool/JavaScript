# gazan-init

> 标签: backend, boilerplate, cli, code-generator, express, generator, hmvc, mongodb, mongoose, mvc, postgresql, prisma, project-generator, scaffolding, typescript

## 简介

Interactive CLI that generates production-ready Node.js backend projects — architecture, database, auth, Redis, BullMQ, Socket.IO, and module aliases, all conditional on what you actually select.
