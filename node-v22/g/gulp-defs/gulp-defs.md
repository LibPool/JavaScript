# gulp-defs

> 标签: ES6, defs, gulpplugin

## 简介

Gulp plugin for static scope analysis and transpilation of ES6 block scoped const and let variables to ES3 vars

## 官网

- 官网：https://github.com/danielhusar/gulp-defs
- 源码仓库：git://github.com/danielhusar/gulp-defs
- npm 页面：https://www.npmjs.com/package/gulp-defs
