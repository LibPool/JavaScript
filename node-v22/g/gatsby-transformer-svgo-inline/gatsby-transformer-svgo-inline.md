# gatsby-transformer-svgo-inline

> 标签: gatsby, gatsby-plugin, gatsby-transformer-plugin, svg, svgo

## 简介

Basic transformer plugin enabling users to retrieve inline SVG processed by [SVGO](https://github.com/svg/svgo/) via Gatsby's GraphQL API.
