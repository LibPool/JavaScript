# geofaces

> 标签: avatar, avatars, deterministic, generative, geometric, identicon, placeholder, profile-picture, react, svg

## 简介

Deterministic, zero-dependency flat-geometric avatar faces. Same name, same face, generated as SVG with nothing to host.
