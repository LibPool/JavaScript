# graphslayer

> 标签: code-mode, entra, intune, mcp, microsoft-365, microsoft-graph, model-context-protocol

## 简介

An MCP server that lets an AI agent read and change a Microsoft 365 tenant through Microsoft Graph, by writing short scripts that run in a sandbox. Tools: docs, search, execute.
