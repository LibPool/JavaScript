# genshin-text

> 标签: genshin, genshin-impact, i18n, localization, textmap, translation, typescript

## 简介

Genshin Impact's own text in its fifteen languages: the language registry, a matcher from a browser's locale, and the game's strings looked up by the game's own text id, one lazily loaded chunk per language.
