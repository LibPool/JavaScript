# gulp-amphtml-validator-local

> 标签: AMP, AMP HTML, Accelerated Mobile Pages, gulpplugin, validate, validator

## 简介

Gulp plugin for the official AMP HTML validator (www.ampproject.org). Modified to use local validator js file.
