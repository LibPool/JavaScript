# ghostties-install

> 标签: ghostties, ghostty, installer, terminal

## 简介

Installer shim for Ghostties (macOS, Apple silicon). Downloads and verifies the newest release build of Ghostties.app.

## 官网

- 官网：https://ghostties.org
- 源码仓库：git+https://github.com/SeanSmithWorks/ghostties.git
- npm 页面：https://www.npmjs.com/package/ghostties-install

- npm registry：https://registry.npmjs.org/ghostties-install
- Node 要求：>=18
