# gitflic-cli-mcp

> 标签: ai-agent, claude, cursor, gitflic, mcp, model-context-protocol, rest-api

## 简介

MCP server wrapping the gitflic CLI — exposes the GitFlic REST API as typed tools for AI agents (Claude Code, Cursor, etc.)
