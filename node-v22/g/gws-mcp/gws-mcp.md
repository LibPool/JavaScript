# gws-mcp

> 标签: anthropic, claude, claude-cowork, claude-desktop, gmail, google-calendar, google-drive, google-sheets, google-workspace, gws, mcp, modelcontextprotocol

## 简介

MCP server wrapping the local `gws` (Google Workspace) CLI, so sandboxed agents (Claude Cowork, etc.) can use Google Workspace through your host-side OAuth credentials.
