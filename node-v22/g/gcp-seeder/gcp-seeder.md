# gcp-seeder

> 标签: boilerplate, bootstrap, gcp, google-cloud, googleapis, oauth, scaffold, service-account

## 简介

Spin up a fully wired Google Cloud project — APIs enabled, service account keyed, OAuth credentials downloaded — in one command. A TypeScript reimplementation inspired by GAM-team/got-your-back.
