# gavel-review

> 标签: adversarial-review, agent, code-review, dsh, dsh-plugin, llm

## 简介

对抗式多视角代码审查插件：多透镜并行攻击式审查、确定性静态哨兵、跨视角合并去重、严重度定级、抑制规则与审查历史。支持 dsh（DeepSeek Harness）工具接入与独立 CLI 两种入口。
