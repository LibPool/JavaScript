# gora8-agent-mcp

> 标签: JavaScript

## 简介

MCP server exposing gora8's agent-facing economic primitives (search, hire, dispute, plan, commit, execute, verify) as tools — a thin transport wrapper over gora8-agent, for any MCP-native agent host
