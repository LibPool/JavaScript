# gotify-mcp

> 标签: gotify, mcp, notifications, push, self-hosted

## 简介

Query any Gotify server (self-hosted; set GOTIFY_BASE_URL + GOTIFY_TOKEN, sent as X-Gotify-Key): send messages, list messages, list applications.
