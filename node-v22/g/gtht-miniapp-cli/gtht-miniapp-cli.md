# gtht-miniapp-cli

> 标签: JavaScript

## 简介

GTHT Miniapp Cli 是一个基于 vite 实现的 uniapp 组件库构建工具，通过 GTHT Miniapp Cli 可以快速搭建一套功能完备的 Vue 组件库。
