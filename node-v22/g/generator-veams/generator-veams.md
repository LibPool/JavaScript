# generator-veams

> 标签: app, assemble, backbone, boilerplate, browserify, component, es harmony, front-end, grunt, homepage, javascript, jquery, mangony, prototype, prototypes, react, scaffold, templating, veams, veams-components, veams-generator, veams-query, web apps, webpack, websites, yeoman-generator

## 简介

Scaffold modern frontend web apps or web pages with a static site generator, Grunt and/or Gulp, Sass and Bower. Use modern frameworks like Bourbon, Bootstrap or Foundation and structure your JavaScript with ES Harmony support.
