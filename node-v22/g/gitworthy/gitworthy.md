# gitworthy

> 标签: cli, contribution, duplicate-detection, github, issues, mcp, model-context-protocol, open-source, oss, triage

## 简介

is it worth your commit? A pre-flight tool for OSS contribution targets: checks whether an issue is already done, in flight, fixed but unreleased, duplicated, or genuinely open.
