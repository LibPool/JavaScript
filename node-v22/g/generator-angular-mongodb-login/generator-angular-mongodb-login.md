# generator-angular-mongodb-login

> 标签: angular, app, component, form, framework, front-end, login, scaffold, user, yeoman-generator

## 简介

Extends Yeoman generator for AngularJS and includes a sub-generator to scaffold user login page backed by MongoDB. NOTE: this is just an idea for now; if you like/need it star the project and I'll be happy to put more hours into it.
