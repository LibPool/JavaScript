# govcontractscout-mcp

> 标签: api, govcontractscout, government-contracts, mcp, naics, procurement, rfp

## 简介

MCP server exposing GovContractScout's US state & local government contracts API (search contracts, get details, NAICS lookup, AI match scoring) to AI agents.
