# give-me-this

> 标签: cli, copy, save-time

## 简介

這是一個因為懶惰而誕生的 CLI 工具，<br> 你可以將想要複製的「檔案/資料夾」存取在一個 key 上，<br> 之後就可以透過 CLI 快速的把資源給取出來。
