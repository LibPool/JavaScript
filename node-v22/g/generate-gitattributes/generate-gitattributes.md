# generate-gitattributes

> 标签: boilerplate, build, cli, cli-app, command-line, create, dev, development, framework, front, frontend, generate, generate-generator, generate-plugin, generategenerator, generateplugin, generator, gitattributes, init, initialize, new, plugin, project, projects, scaffold, scaffolder, scaffolding, template, templates, webapp, yeoman, yo

## 简介

Generate a .gitattributes file from the command line when Generate's CLI is installed globally, or use as a plugin or sub-generator in your own generator to make it a continuous part of the build workflow when scaffolding out a new project.
