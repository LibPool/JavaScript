# ga-measurement-protocol

> 标签: Measurement Protocol, google analytics

## 简介

Google Analytics Measurement Protocol with typescript. It can run in nodejs, browser, react-native, etc. Current it only supports protocol v4.   If you want to use protocol v1, please install previous version: ` yarn add ga-measurement-protocol@1.1.2`
