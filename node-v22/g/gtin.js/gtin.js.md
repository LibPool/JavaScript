# gtin.js

> 标签: JavaScript

## 简介

A JavaScript library for validating and parsing GTIN-8, GTIN-12, GTIN-13 and GTIN-14 codes.

## 官网

- 官网：https://github.com/powa/gtin
- 源码仓库：git+https://github.com/powa/gtin.git
- npm 页面：https://www.npmjs.com/package/gtin.js
