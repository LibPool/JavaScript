# gpusmarket-host

> 标签: ai, earn, gguf, gpu, gpu-rental, hosting, inference, llama-cpp, llama.cpp, llm, marketplace, ollama, passive-income, self-hosted

## 简介

List your GPU on GPUsMarket in one command. Auto-installs Ollama or llama.cpp, pulls models, connects tunnel. Or --target an existing server.
