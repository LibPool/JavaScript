# gulp-ccr-parallel

> 标签: configurable, configurable-gulp-recipe, configurable-gulp-recipes, configuration, configurations, gulp, gulp 4.0, gulp recipe, gulp recipes, gulp task, gulp tasks, gulp-ccr, gulp-chef, gulp-cookery, parallel, plugin, plugins, recipe, recipes, task, tasks

## 简介

Run sub tasks in parallel, without waiting until the previous task has completed. A cascading configurable gulp recipe for gulp-chef.
