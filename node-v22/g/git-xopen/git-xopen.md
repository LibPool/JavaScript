# git-xopen

> 标签: bitbucket, browser, cli, git, github, gitlab, open, remote

## 简介

Open a git remote's web page. Resolves SSH aliases (ssh.github.com, altssh.bitbucket.org, ...) and lets you pick between multiple remotes/URLs.
