# grunt-readme-generator

> 标签: automatic, doc, doc-gen, documentation, documentation-generator, gen, generator, gfm, git-hub, github, github-flavored-markdown, grunt, gruntplugin, helper, markdown, markdown-generator, md, mdown, plug-in, plugin, project, project-helper, readme, task, tool, utility, weaponxi

## 简介

A grunt task to generate a dynamic readme.md from partial markdown files in readme folder. Specifically designed for GitHub projects!
