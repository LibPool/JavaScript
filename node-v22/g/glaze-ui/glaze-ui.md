# glaze-ui

> 标签: glaze, glaze-ui, mfe, mfe framework, micro front end, micro frontend, micro-frontend

## 简介

Glaze UI is an open-source lightweight (~60kb) framework that lets you have multiple Micro Front-End (MFE) applications on the same Single Page Application (SPA). That means you can have different frameworks like React, Angular and Vue running side-by-sid
