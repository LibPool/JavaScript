# gitlab-duo-mcp-bridge

> 标签: ai-agents, code-review, gitlab, gitlab-duo, mcp, model-context-protocol

## 简介

MCP server that wraps the GitLab Duo CLI as a clean, fault-tolerant duo_review tool for AI coding agents.
