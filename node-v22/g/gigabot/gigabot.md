# gigabot

> 标签: agent, ai, autonomous, bot, edge-ai, gigabot, gignaati, india, nextjs, telegram

## 简介

Giga Bot — Gignaati's autonomous AI agent platform. Build, deploy, and run AI agents 24/7 with a two-layer architecture: Next.js Event Handler + Docker Agent. India-first, edge-native AI.
