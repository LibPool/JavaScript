# gestor-components

> 标签: JavaScript

## 简介

Passo a passo: 1 - npm adduser (fazer login no npm) 2 - Adicionar ao package.json:    scripts: "deploy": "npm version patch && npm publish"   name: COLOCAR_NOME_LIB_NPM - @nome-lib/nome-componente 3 - Entrar na pasta 'components' 4 - npm run deploy
