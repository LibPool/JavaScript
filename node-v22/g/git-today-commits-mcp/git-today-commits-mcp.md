# git-today-commits-mcp

> 标签: basic-auth, commits, daily-report, diff, git, mcp, model-context-protocol

## 简介

用账号密码(HTTP Basic Auth)获取指定 Git 服务器指定仓库的今日提交代码变更记录 (Asia/Shanghai)。同时提供 CLI 与 MCP server 双入口。

## 官网

- npm 页面：https://www.npmjs.com/package/git-today-commits-mcp

- 1.0.0

## 获取地址

- npm 安装：`npm install git-today-commits-mcp`
- npm registry：https://registry.npmjs.org/git-today-commits-mcp
- Node 要求：>=18
