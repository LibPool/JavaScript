# glassframe-protocol

> 标签: ai-moderation, anti-nuke, anti-raid, discord, discord.js, groq, moderation, security

## 简介

A layered, self-contained Discord security engine - AntiRaid, AntiNuke, Basic Security, and optional Groq-powered AI Moderation sharing one threat-scoring and punishment pipeline. Prefix commands only, Components V2 output, no slash commands.
