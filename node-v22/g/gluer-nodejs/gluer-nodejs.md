# gluer-nodejs

> 标签: gluer, integration, message-bus, messagepack, realtime, rpc, sdk, websocket, worker

## 简介

Node.js worker SDK for Gluer: expose JavaScript functions as remotely callable actions over the Gluer real-time mesh.
