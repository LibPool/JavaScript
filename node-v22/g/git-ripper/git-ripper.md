# git-ripper

> 标签: clone, directory-download, download, folder-download, git, git-utilities, github, github-api, monorepo-tools, partial-clone, repository, sparse-checkout, subfolder

## 简介

CLI tool that lets you download specific folders from GitHub repositories without cloning the entire repo.
