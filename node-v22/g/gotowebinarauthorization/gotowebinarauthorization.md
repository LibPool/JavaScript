# gotowebinarauthorization

> 标签: G2W, Go To Webinar, Go to webinar, Go to webinar authorization, GoToWebinar, go to webinar, gotowebinar

## 简介

The node module that simplify authorization in go to webinar service. Returns access_token, refresh_token and other data
