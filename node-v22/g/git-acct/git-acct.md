# git-acct

> 标签: account, cli, gam, git, manager, multi-account, personal, switch, work

## 简介

Git账号管理工具，支持多账号切换，区分工作和个人账号，不同仓库使用不同账号

- 源码仓库：git+ssh://git@github.com/ccOfHome/git-account-manager.git
