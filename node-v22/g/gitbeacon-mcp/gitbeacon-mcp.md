# gitbeacon-mcp

> 标签: agents, base, digest, gitbeacon, github, mcp, open-source, repos, trends, usdc, x402

## 简介

MCP server for GitBeacon — pay-per-call GitHub trend intelligence for AI agents: daily LLM-analyzed digests of open-source trends, top trending repos, and historical digests. Pay per call with USDC on Base via x402.
