# grok-termux

> 标签: aarch64, android, cli, coding-agent, termux

## 简介

Unofficial Termux/Android build of Grok Build, xAI's terminal coding agent. Installs on stock Termux; run under termux-chroot for network access.

- npm 页面：https://www.npmjs.com/package/grok-termux
