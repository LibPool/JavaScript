# gatsby-plugin-pinterest-twitter-facebook

> 标签: gatsby, gatsby-facebook, gatsby-facebook-like-button, gatsby-facebook-page, gatsby-facebook-plugin, gatsby-facebook-profile, gatsby-facebook-timeline, gatsby-facebook-widget, gatsby-pinterest, gatsby-pinterest-save, gatsby-pinterest-widget, gatsby-plugin, gatsby-social-widgets, gatsby-twitter, gatsby-twitter-follow-button, gatsby-twitter-plugin, gatsby-twitter-profile, gatsby-twitter-timeline, gatsby-twitter-widget

## 简介

Load the Pinterest, Twitter and Facebook JavaScript to let users save images to their Pinterest boards on image hover, load Twitter timeline and follow button, and load Facebook timeline and like button
