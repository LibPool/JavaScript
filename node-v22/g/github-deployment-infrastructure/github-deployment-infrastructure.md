# github-deployment-infrastructure

> 标签: ci-cd, claude-skill, cli, ephemeral, github-pages, preview-deployment, static-site

## 简介

Reusable ephemeral preview deployment platform, primarily backed by GitHub Pages. Turn branches into short-lived, disposable preview URLs with automatic TTL-based cleanup.
