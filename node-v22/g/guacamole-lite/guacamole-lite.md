# guacamole-lite

> 标签: guacamole, guacamole-client, guacamole-common-js, rdp, remote desktop, ssh, telnet, vnc

## 简介

Library to create servers compatible with the Guacamole protocol. Guacamole is a web client for RDP/VNC/SSH/Telnet
