> 标签: app, boilerplate, build, cli, cli-app, command-line, contributing, create, dev, development, framework, front, frontend, generate, generate-generator, generate-plugin, generategenerator, generateplugin, generator, init, initialize, new, plugin, project, projects, scaffold, scaffolder, scaffolding, template, templates, tool, web, webapp, yeoman, yo

## 简介

Generate a contributing.md, issue_template.md, or pull_request_template.md file for a project. Can be generated from the command line when Generate is installed globally, or as a plugin inside another generator.
