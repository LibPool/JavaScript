# gh-worktree-gc

> 标签: agents, branches, cleanup, gc, gh, git, github, multi-agent, prune, worktree

## 简介

Prune merged/stale git worktrees safely — clean-only, never loses work. Catches squash/rebase merges via gh. Keeps multi-agent fleets from drowning in worktrees.
