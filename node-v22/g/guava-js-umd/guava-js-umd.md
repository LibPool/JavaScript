# guava-js-umd

> 标签: JavaScript

## 简介

GuavaJS-UMD is a fork of [GuavaJS](https://github.com/nerdynick/guava-js) that was created for [postcss-rename](https://github.com/google/postcss-rename) to use in place of GuavaJS.

## 官网

- 官网：https://github.com/google/guava-js-umd#readme
- 源码仓库：git+https://github.com/google/guava-js-umd.git
- npm 页面：https://www.npmjs.com/package/guava-js-umd
