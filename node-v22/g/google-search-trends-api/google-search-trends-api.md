# google-search-trends-api

> 标签: analytics, google-search, google-trends, growth-rate, keyword-research, market-research, search-volume, seo, trends-api, trendsmcp

## 简介

Google Search interest time series and growth via REST API. Weekly data, period-over-period growth, zero dependencies. The typed JS/TS client for the Trends MCP API. Powered by trendsmcp.ai
