# gpt-handle

> 标签: chatgpt, gpt, gpt-handler, openai

## 简介

GPT-Handle is an npm module that allows you to access the text generation capabilities of OpenAI's GPT-3.5 Turbo model. This module allows you to send a text request to the GPT-3.5 Turbo API and receive the resulting response.
