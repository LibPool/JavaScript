# grok-agents-hub

> 标签: agents, ai, automation, grok, productivity, templates, x-ai

## 简介

Open-source repository with 50+ ready-made AI agents, templates, commands, and integrations for Grok (Grok 3/4). Simplify daily work with one-command installation.
