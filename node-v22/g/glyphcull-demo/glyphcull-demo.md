# glyphcull-demo

> 标签: compiled, demo, document, gpu, validation

## 简介

GlyphCull demo and validation harness: compiled .cull fixtures, browser pages for the JS and Rust runtimes, and the contract/perf/memory/E2E test suites that prove the compiler and both runtimes work together against the .cull contract.
