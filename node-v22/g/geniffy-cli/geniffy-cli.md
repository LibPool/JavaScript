# geniffy-cli

> 标签: claude-code, codex, cursor, geniffy, mcp, memory, opencode, setup

## 简介

Geniffy from the terminal: add your Geniffy memory to Claude Code, Cursor, VS Code, Codex, OpenCode, Windsurf and Gemini CLI in one step.
