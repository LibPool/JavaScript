# gulp-tinypng-plugin

> 标签: compress, gulpplugin, image, img, minifier, minify, photo, picture, png, tinypng

## 简介

tinypng图片压缩工具，支持多个Key，支持已压缩图片缓存。gulp plugin to compress png images using tinypng api
