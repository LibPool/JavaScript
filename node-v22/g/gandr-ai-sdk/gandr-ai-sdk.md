# gandr-ai-sdk

> 标签: gandr, text-to-speech, tts, vercel-ai-sdk, voice-agents

## 简介

Gandr speech provider for the Vercel AI SDK. First audio byte in 146 ms over the open internet, 116 ms p50 first audio, server side warm. 23 languages, every render watermarked.
