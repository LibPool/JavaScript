> 标签: args, arguments, arrow, arrow-function, arrows, dependency, deps, fn, func, function, function-arguments, generator, generators, get, inject, injectors, parameters, params, regular, useful

## 简介

Get function arguments, useful for and used in dependency injectors. Works for regular functions, generator functions and arrow functions.
