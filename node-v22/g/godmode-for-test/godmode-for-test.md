# godmode-for-test

> 标签: ethereum, solidity, test

## 简介

This library provides a truffle framework friendly api that allows developers to use the "Godmode Ganache" within the javascript testing environment provided in the truffle framework. The library also precompiles Godmode contracts for popular defi project
