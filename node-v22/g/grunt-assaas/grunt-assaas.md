# grunt-assaas

> 标签: gruntplugin

## 简介

Grunt plugin to take advantage of the ASSAAS Direct Conversion API to remove the need to have SASS installed on the local machine

- 官网：http://hazan.me
- 源码仓库：git://github.com/hazanjon/assaas-grunt.git
