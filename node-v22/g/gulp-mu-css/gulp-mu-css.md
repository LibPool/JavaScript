# gulp-mu-css

> 标签: css, gulp-mu-css, microcss, microgulp, sprite, ucss, ugulp

## 简介

µCSS™ 2 (package gulp-mu-css) - Node module to compile µCSS™-enhanced stylesheets (sprites, cursors, image generation via µPS / gulp-mu-ps). Successor of the 2013 Photoshop-script based µCSS™ 1.
