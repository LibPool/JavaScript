# glassfx

> 标签: backdrop-filter, blur, chromatic-aberration, css, frosted, glass, glassmorphism, liquid-glass, react, refraction, ui

## 简介

Real-refraction glassmorphism for any element — backdrop lensing, chromatic dispersion, depth and a cursor-tracking bloom. Pure CSS + ~1KB JS, with graceful fallback. Framework-agnostic, plus optional React bindings.
