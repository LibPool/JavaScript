> 标签: array, by, collection, group, group-array, group-by, groupby, gulp, gulp-plugin, gulpplugin, page, pager, paginate, pagination, paginationator, paging, plugin, vinyl

## 简介

Gulp plugin to group vinyl files into a collection and create new vinyl files using pagination and permalinks.
