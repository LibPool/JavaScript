# git-for-dsh

> 标签: cordis, deepseek-harness, dsh, git, plugin, sandbox

## 简介

Allowlisted git execution for DeepSeek Harness: a model-facing git tool that runs outside the file sandbox, with a settings page where the user ticks which git subcommands are permitted and, per path, which reads and writes are allowed, prompted or refuse
