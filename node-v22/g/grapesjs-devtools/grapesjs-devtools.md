# grapesjs-devtools

> 标签: debug, devtools, editor, grapesjs, grapesjs-plugin, inspector

## 简介

In-editor developer panel for GrapesJS — component/style inspection, event log, REPL, AI assistant and more. Built by gjs.market for the GrapesJS community.
