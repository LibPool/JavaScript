# gulp-jsart

> 标签: art, gulp, jsart

## 简介

gulp-jsart是一个gulp插件，用于jsart web编译工具中的art文件的转html

- 源码仓库：git+https://github.com/jsart/gulp-jsart.git
- npm 页面：https://www.npmjs.com/package/gulp-jsart
