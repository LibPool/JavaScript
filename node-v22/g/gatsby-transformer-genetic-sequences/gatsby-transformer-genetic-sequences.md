# gatsby-transformer-genetic-sequences

> 标签: gatsby, gatsby-plugin

## 简介

Gatsby plugin that uses [seqparse](https://github.com/Lattice-Automation/seqparse) to parse genetic sequences and creates GraphQL nodes for them.
