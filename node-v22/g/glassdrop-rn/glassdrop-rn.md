# glassdrop-rn

> 标签: dropdown, expo, glass, liquid-glass, material3, multi-select, picker, react-native, searchable, select, theme

## 简介

Token-driven, fully-customisable dropdown / select component for React Native (Expo). Single, multi, searchable, and grouped modes. Seven built-in themes.
