# gls-city-plugin

> 标签: JavaScript

## 简介

Este é um plugin para o [framework de e-commerce Vendure](https://www.vendure.io/) projetado para  adicionar a consulta de cidades ao contexto da API da loja ao projeto [Gseller](https://gseller.com.br/).
