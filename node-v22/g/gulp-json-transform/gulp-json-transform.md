# gulp-json-transform

> 标签: gulp, json, plugin, transform

## 简介

A gulp plugin to transform json files, pipe json files through it and transform them to other json files or other formats.

- 官网：https://github.com/thaggie/gulp-json-transform
- 源码仓库：git+ssh://git@github.com/thaggie/gulp-json-transform.git
