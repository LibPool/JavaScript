# gtfs

> 标签: geojson, gtfs, gtfs-realtime, kysely, mysql, postgres, postgresql, public-transit, sqlite, transit, transportation

## 简介

Import GTFS transit data into SQLite, PostgreSQL, or MySQL and query routes, stops, times and fares
