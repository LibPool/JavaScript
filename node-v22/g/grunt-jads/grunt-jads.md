# grunt-jads

> 标签: gruntplugin

## 简介

Spin up a simple node.js http server (wrapper for JADS - https://github.com/bocallaghan/JADS)

## 官网

- 官网：https://github.com/js1972/JADS
- 源码仓库：https://github.com/js1972/JADS.git
- npm 页面：https://www.npmjs.com/package/grunt-jads

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- npm 安装：`npm install grunt-jads`
- npm registry：https://registry.npmjs.org/grunt-jads
- Node 要求：>= 0.8.0
