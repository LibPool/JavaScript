# gition-ui

> 标签: cli, documentation, hot-reload, kanban, local-development, markdown, mdx, nextjs, task-management, workspace

## 简介

Zero-config, local web interface for managing Markdown/MDX documentation and tasks. Think Notion + Jira, but for your local files with real-time hot-reload and beautiful UI.
