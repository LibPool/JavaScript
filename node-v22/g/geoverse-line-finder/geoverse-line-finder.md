# geoverse-line-finder

> 标签: astar, dijkstra, geojson, gis, linestring, network, pathfinding, routing, shortest-path

## 简介

Weight-aware shortest paths on GeoJSON LineString networks: pluggable A*/Dijkstra/ALT engines, constrained and cost-optimal snapping, multi-waypoint routes with failure policies, linear referencing and topology diagnostics.
