# gcyphrq-ext-maven-dependency-tree

> 标签: dependency-tree, gcyphrq, gcyphrq-extension, graph, maven

## 简介

Maven dependency tree extension for gcyphrq — runs mvn dependency:tree and converts the output to a queryable graph
