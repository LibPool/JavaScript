# gdex.pro-sdk

> 标签: api, blockchain, copy-trading, crypto, defi, futures, gdex, hyperliquid, portfolio, sdk, trading, trading-bot, typescript

## 简介

A comprehensive TypeScript SDK for interacting with GDEX API endpoints, providing REST API access, WebSocket real-time data, and crypto utilities.
