# ghostimport

> 标签: agent, ai, ai-safety, claude, claude-code, copilot, cursor, ghost, hallucination, hallucination-detection, import-validation, imports, lint, mcp, mcp-server, npm, pre-commit, security, slopsquatting, supply-chain, supply-chain-security, typosquatting, vibe-coding

## 简介

Stops AI coding agents from installing npm packages that don't exist. MCP server + hooks that block slopsquatting and typosquat supply-chain attacks.
