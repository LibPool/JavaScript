# gatsby-plugin-ga-gdpr-fingerprint

> 标签: cookie consent, cookies, dsgvo, gatsby, gatsby-plugin, gdpr cookies, google analytics

## 简介

Gatsby plugin to add google analytics in gdpr conform way with a fallback to basic fingerprinting based on gatsby-plugin-gdpr-cookies
