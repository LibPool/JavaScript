# gulp-sharp-compress

> 标签: avif, compress, gulp, gulp-plugin, gulpplugin, image, image-compress, imagemin, mozjpeg, optimize, png, pngquant, sharp, tinypng, webp

## 简介

High-quality image compression for Gulp using sharp (mozjpeg/libwebp/oxipng/AVIF). Drop-in replacement for gulp-imagemin with better performance.
