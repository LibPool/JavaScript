# gitatlas

> 标签: architecture, c4-model, code-graph, developer-tools, github, knowledge-graph, mcp, multi-repo, static-analysis, visualization

## 简介

Turn a folder of repos or any GitHub repo into one interactive HTML architecture map, from system down to function. 21 languages, fully offline, with an MCP server for coding agents.
