# graphql-parse-relation-fields

> 标签: apollo, ast-parser, database-optimization, fragments, graphql, graphql-parse-relation-fields, graphql-relation, graphql-yoga, graphqlresolveinfo, overfetching, prisma

## 简介

This is a package that helps you sort out your graphql client query fields so they can be used for relational or non-relational(scalar) sql database queries
