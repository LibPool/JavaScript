# grabslabs-puppeteer-page-proxy

> 标签: chromium, headless, page, proxy, puppeteer

## 简介

Additional Node.js module to use with 'puppeteer' for setting proxies per page basis. Fixed fork of Cuadrix/puppeteer-page-proxy.
