# glass-lens

> 标签: displacement-map, effect, feDisplacementMap, frosted-glass, glass, lens, liquid-glass, refraction, svg-filter, ui

## 简介

Cross-browser glass refraction for live DOM — one SVG filter bends the page's own rendered pixels. Zero dependencies, no build step.
