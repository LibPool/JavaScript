# gatsby-source-google-docs-team

> 标签: docs, drive, gatsby, gatsby-plugin, gatsby-source, gatsby-source-plugin, google, google-docs

## 简介

Gatsby plugin to use Google Docs as a data source. Supports team drives and supports downloading images from docs.
