# gulp-biscotto

> 标签: biscotto, coffeescript, documentation, gulpfriendly, tomdoc

## 简介

A Gulp-friendly module to generate [Biscotto](https://github.com/atom/biscotto) documentation from CoffeeScripts and return the output files.
