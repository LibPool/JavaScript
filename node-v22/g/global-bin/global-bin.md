# global-bin

> 标签: JavaScript

## 简介

管理全局路径的可执行命令文件，支持增添、覆盖、删除 # Usage 安装后将添加快捷命令bin ```sh bin binName binContent bin binName binContent --alias #添加命令别名，参数将透传(传递)给命令 ```
