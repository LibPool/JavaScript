# glyphdown

> 标签: ai-agents, cli, collaboration, crdt, documents, glyphdown, markdown, realtime, sync, yjs

## 简介

Glyphdown CLI — Google Docs for markdown, built for AI agents: pull docs to plain files, edit, push back through CRDT merging; clone/sync mirrors your whole account
