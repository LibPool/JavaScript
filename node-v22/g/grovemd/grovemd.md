# grovemd

> 标签: angular, cli, documentation, editor, express, file-browser, grove, markdown, notes, obsidian-alternative, viewer, wiki

## 简介

Grove — a local markdown wiki for any folder. Browse, read, and (soon) edit. Renders GFM, math, mermaid, syntax highlighting, and media previews.
