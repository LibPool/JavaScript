# gitswitch-wizard

> 标签: account-switcher, cli, git, github, gitswitch, multi-account, ssh, wizard

## 简介

GitSwitch Wizard — multi-GitHub account manager installer & updater. Installs, updates and manages GitSwitch without touching SSH configs it doesn't own.
