# gatsby-source-tsubame

> 标签: gatsby, gatsby-plugin, gatsby-source, gatsby-source-plugin, tsubame

## 简介

Gatsby source plugin for the Tsubame delivery API. Markdown fields become text/markdown nodes, so gatsby-transformer-remark turns them into HTML.
