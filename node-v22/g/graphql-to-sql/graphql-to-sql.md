# graphql-to-sql

> 标签: code-generation, database, directive, generator, graphql, graphql-schema, graphql-schema-language, mysql, schema, sdl, sql, sql-schema

## 简介

Use GraphQL as the source of truth for schema. The SQL schema script is derived from the GraphQL type definitions.
