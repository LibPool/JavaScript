# guardskill

> 标签: ai-agent, claude-code, cli, codex, coding-agent, copilot, cursor, git, gitspawn, security, static-analysis, supply-chain

## 简介

Read-only scanner for the git settings that let a repository run code in a coding agent (Claude Code, Codex, Cursor, Copilot, Goose): fsmonitor, filters, hooks, aliases, includes, bare repositories in the tree. No dependencies, no network.
