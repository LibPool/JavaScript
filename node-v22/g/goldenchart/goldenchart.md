# goldenchart

> 标签: charts, d3, dataviz, flowchart, hand-drawn, react, roughjs, sketch, svg

## 简介

Hand-drawn, sketchy React charts and flowcharts. D3 does the math, Rough.js does the drawing, and a Vibe engine dials in the aesthetic.
