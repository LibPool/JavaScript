# google-ads-manager-mcp

> 标签: advertising, adwords, claude, google-ads, mcp, model-context-protocol

## 简介

Unofficial MCP server for reading and managing a Google Ads account (campaigns, budgets, keywords, ads) with a draft/confirm safety layer on every write.
