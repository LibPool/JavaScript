# gemini-watermark

> 标签: alpha-blending, browser, gemini, image-processing, typescript, watermark, watermark-removal

## 简介

Detect, remove, and add Gemini visible image watermarks via deterministic reverse alpha blending. Faithful TypeScript port of GeminiWatermarkTool. Zero dependencies, runs in browsers and Node.
