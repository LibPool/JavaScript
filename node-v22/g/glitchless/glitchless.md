# glitchless

> 标签: crash-reporting, error-tracking, fps, frame-time, game-analytics, game-development, game-observability, gamedev, mcp, observability, performance, phaser, phaser3, phaser4, stutter, telemetry, three.js, threejs, web-games, webgl, webmcp

## 简介

Game observability SDK for web games (Three.js, Phaser 3 and 4, or plain WebGL): frame time, stutter, errors and where players quit, with an in-game overlay and WebMCP tools for coding agents.
