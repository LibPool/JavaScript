# gigai-chronicle

> 标签: ai, claude-code, cli, codex, developer-tools, git, history, local-first, openai, prompts, provenance, version-control

## 简介

chronicle — your AI development history, recorded in-repo, linked to git, replayable. git blame says who; `chronicle why` says what was asked.
