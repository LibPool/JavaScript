# geo2zip

> 标签: geolocation, k-d, k-nn, kd, knn, lat, latitude, location, lon, long, longitude, nearest, neighbors, tree, zip, zipcode

## 简介

Translates latitude / longitude geolocations to the nearest corresponding U.S. zip code
