# get-research-done

> 标签: ai, claude, claude-code, data-science, experiment-tracking, hypothesis-driven, machine-learning, ml, reproducibility, research

## 简介

A recursive, agentic framework for ML research with hypothesis-driven experimentation. Features Critic agent for automated skeptical review, Explorer for data reconnaissance, and Architect for hypothesis synthesis.
