# git-kloc-analyzer

> 标签: analysis, cli, git, kloc, lines-of-code, statistics, typescript

## 简介

A powerful TypeScript tool for analyzing KLOC (Kilo Lines of Code) statistics from Git repositories with email-based contributor grouping
