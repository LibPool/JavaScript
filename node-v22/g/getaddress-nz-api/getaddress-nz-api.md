# getaddress-nz-api

> 标签: address, address-lookup, autocomplete, getaddress, linz, new zealand, nz, postcode

## 简介

Node.js client for the getaddress NZ address API: autocomplete and full look-up of every New Zealand address from LINZ, with unofficial postcodes, nearest addresses, suburb and town locations, typeahead, validate, distance, postcode corrections and usage.
