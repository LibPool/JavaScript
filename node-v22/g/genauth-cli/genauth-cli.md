# genauth-cli

> 标签: JavaScript

## 简介

GenAuth CLI 是一个命令行工具，用于快速创建和管理基于 GenAuth Guard 的项目。它支持 React 和 Vue3 框架，可以帮助开发者快速搭建带有认证功能的应用。
