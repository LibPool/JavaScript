# gtfs-bolivia-cochabamba

> 标签: JavaScript

## 简介

Configuration to transform OSM public transport data into GTFS format for Cochabamba, Bolivia. Uses [osm-public-transport-export](https://github.com/trufi-app/osm-public-transport-export) and [geojson-to-gtfs](https://github.com/trufi-app/geojson-to-gtfs)
