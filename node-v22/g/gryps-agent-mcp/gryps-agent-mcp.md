# gryps-agent-mcp

> 标签: agent, execution-cost, friction, gryps, market-data, mcp, model-context-protocol, perpetuals, read-only, trading

## 简介

MCP server that checks whether a trading signal can survive execution reality. Live Gryps v2 venue data, measured friction floor, and cost gating. Read-only.
