# gaonjs

> 标签: framework, fullstack, gaon, gaonjs, typescript, vue

## 简介

Gaon (가온) — AI가 개발을 가장 잘하는 Node.js 풀스택 웹 프레임웍. 개발자는 이 패키지 하나만 설치합니다 (설치명 gaonjs · CLI 명령 gaon).
