# goap-minimal

> 标签: ai, fsm, game-ai, goal-oriented-action-planning, goap, planning, state-machine, strips

## 简介

Minimal Goal-Oriented Action Planner (GOAP) in JSY: forward-search planning plus the three-state Goto/Animate runtime from Jeff Orkin's F.E.A.R. AI, in the STRIPS lineage. Built on astar-minimal.
