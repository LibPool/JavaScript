# garmin-mcp-auth

> 标签: ai-assistant, claude, claude-desktop, garmin, garmin-ai, garmin-connect, garmin-connect-mcp, garmin-mcp, garmin-mcp-server, mcp, mcp-server, mfa, model-context-protocol, oauth2, sso

## 简介

Garmin Connect sign-in for Garmin MCP, the unofficial MCP server for Garmin Connect: SSO, MFA, DI OAuth2 tokens and refresh. Not affiliated with Garmin.
