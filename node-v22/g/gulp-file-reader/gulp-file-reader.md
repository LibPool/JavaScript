# gulp-file-reader

> 标签: content, file, getter, gulp, loader, reader, stream

## 简介

Gulp plugin to read file and save its content in Vinyl#contents property for further processing by remaining pipelined gulp plugins. See https://github.com/gulpjs/vinyl for more details
