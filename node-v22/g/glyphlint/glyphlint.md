# glyphlint

> 标签: a11y, accessibility, arabic, axe-core, bidi, cli, devanagari, hebrew, i18n, internationalization, playwright, rtl, thai, unicode

## 简介

Accessibility scanner for defects caused by writing systems. Runs axe-core, then adds a script-aware rule layer on top.
