# greenborn-memory-cache

> 标签: cache, caching, lru, memory, memory-cache, nodejs, server, ttl

## 简介

Caché en memoria del lado del servidor para Node.js: TTL por entrada, eventos y limpieza periódica automática. Sin dependencias de runtime (usa node:events).
