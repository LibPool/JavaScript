# gruntbuild

> 标签: angular, grunt, gruntplugin, html, rev, usemin, yeoman

## 简介

Grunt task that revs versions of HTML, CSS & Angular template files in JS, as well as includes Grunt 0.4 versions of the clean, mkdir, copy and clean tasks.
