# generator-javascript

> 标签: babel, boilerplate, component, es2015, es6, es7, esnext, front-end, javascript, library, react, scaffold, yeoman-generator

## 简介

Generates a JavaScript library boilerplate for Node.js and the browser with ES6 / ES2015, ESLint, Babel, Mocha, Chai, Sinon, Istanbul, Coveralls...
