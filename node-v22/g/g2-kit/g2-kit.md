# g2-kit

> 标签: charts, even-hub, even-realities, framebuffer, g2, greyscale, smart-glasses

## 简介

Drawn UI for Even Realities G2 Hub plugins: charts, controls and HUD chrome rendered to 4-bit image tiles, driven by a blank input skeleton. Unofficial.
