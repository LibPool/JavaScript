# grab-api.js

> 标签: api, api-client, axios, browser, caching, devtools, fetch, fetch-wrapper, grab, grab-url, http, http-client, infinite-scroll, mock-api, mock-testing, pagination, rate-limiting, request, request-deduplication, rest-client, retry, typescript, zero-dependencies

## 简介

The grab() request function on its own — one function, zero dependencies, minimalist syntax, with auto-JSON, dedupe, caching, retries, rate-limiting, mock testing, pagination and a DevTools overlay. The core of grab-url, without the loading icons.
