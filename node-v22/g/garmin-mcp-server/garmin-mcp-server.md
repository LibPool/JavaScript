# garmin-mcp-server

> 标签: acwr, ai-assistant, claude, claude-desktop, ctl-atl-tsb, cycling, fitness-fatigue-form, garmin, garmin-ai, garmin-connect, garmin-connect-mcp, garmin-mcp, garmin-mcp-server, garmin-workout, hrv, mcp, mcp-server, model-context-protocol, running, structured-workouts, training-load, training-readiness, triathlon

## 简介

Unofficial, open-source MCP server for Garmin Connect. Ask Claude or any MCP client about your training: load, form and morning readiness computed locally with cited sports-science methods, and workouts sent to your watch. Not affiliated with Garmin.
