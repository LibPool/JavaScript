# gocreative-github-enrich

> 标签: ai-agents, developer-enrichment, github, github-api, github-user, gocreative, lookup

## 简介

Tiny single-purpose Node helper that looks up GitHub user profiles (name, bio, followers, public repos, location, company) via the GoCreative AI pay-per-call API. Bring your own gck_ API key or use the free demo tier (5/day per IP). For full multi-endpoin
