# glb-mp4

> 标签: JavaScript

## 简介

Based from @shopify/screenshot-glb and puppeteer-screen-recorder, a command line utility for screen recording a glTF 2.0 binary file rotating using Google's <model-viewer> component and convert the output to GIF.
