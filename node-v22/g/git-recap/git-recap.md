# git-recap

> 标签: cli, developer-tools, git, git-stats, gitinsights, open-source, spotify-wrapped, terminal, wrapped, year-in-review

## 简介

Spotify Wrapped for your git history — a local, zero-dependency, animated story of your code. Terminal card + shareable SVG, no upload, no API key.
