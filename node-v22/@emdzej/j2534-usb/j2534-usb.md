# @emdzej/j2534-usb

> 标签: diagnostics, j2534, libusb, node, openport, passthru, tactrix, transport, typescript, usb

## 简介

Node.js libusb bulk-endpoint transport for @emdzej/j2534-driver. Talks directly to the Tactrix OpenPort 2.0 (VID 0x0403 / PID 0xCC4D) bypassing the kernel CDC ACM driver. Requires elevated privileges on macOS/Linux.
