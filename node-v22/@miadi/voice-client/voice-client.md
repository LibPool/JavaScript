# @miadi/voice-client

> 标签: api-client, assembly-voice, miadi, tts, voice

## 简介

HTTP access to the Miadi voice layer — the /api/voice envelope, the two-name token tier, and a dependency-free fetch client. Publishes voice from any process that is not the server.
