# @miadi/companion-ui

> 标签: chronicle, companion, dialogue, episode, miadi, react, seat

## 简介

A companion seat in an episode, as React: the conversation a person held with the seat (their takes, its replies, each with its playback), and the opener that plans and opens the seat for an episode. Data and a transport in, intent out. No component holds
