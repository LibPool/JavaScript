# @miadi/stateloom-web

> 标签: canvas, designer, nextjs, realtime, smdf, state-machine, stateloom, visual-editor

## 简介

The stateloom visual state machine designer — a prebuilt Next.js canvas you run with `stateloom-web`, joined live to the bridge hub so an agent and a person edit the same board
