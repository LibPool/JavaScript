# @korbitbr/sdk

> 标签: brazil, cartão, korbit, pagamentos, payments, pix, sdk

## 简介

SDK oficial da Korbit para Node.js: pagamentos PIX e cartão, catálogo, assinaturas, saldo, saques e webhooks — com idempotência automática, retries e erros tipados.
