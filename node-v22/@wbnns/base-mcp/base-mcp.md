# @wbnns/base-mcp

> 标签: agents, base, base-chain, documentation, ethereum, llm, mcp, model-context-protocol

## 简介

MCP server exposing BaseHub — reference for agents on Base. Search and fetch raw-Markdown pages from basehub.org via Claude Desktop, Cursor, or any stdio MCP client.

- 官网：https://basehub.org
- 源码仓库：git+https://github.com/wbnns/basehub.git
- npm 页面：https://www.npmjs.com/package/@wbnns/base-mcp
