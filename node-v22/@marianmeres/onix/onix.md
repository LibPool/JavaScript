# @marianmeres/onix

> 标签: JavaScript

## 简介

A thin, typed HTTP client over the [Kros Onix](https://www.kros.sk/onix/) REST API (Swagger `V1`). Ships ready-made DTOs/models, ergonomic resource methods, cursor pagination, business-result helpers, and request/error logging — so you can just _consume_
