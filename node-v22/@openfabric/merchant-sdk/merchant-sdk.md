# @openfabric/merchant-sdk

> 标签: JavaScript

## 简介

OpenFabric simplifies acceptance of closed-loop consumer side payment methods (Wallets, BNPLs, Loyalty Platforms, etc) that are integrated into OpenFabric's Platform.
