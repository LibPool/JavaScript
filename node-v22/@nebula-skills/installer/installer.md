# @nebula-skills/installer

> 标签: claude-code, codex, cursor, installer, nebula, skills

## 简介

Shared installer for @nebula-skills/* packages: copy/symlink the skill folder into ~/.claude/skills, ~/.cursor/skills, ~/.codex/skills.
