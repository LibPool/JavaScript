# dsh-ollama-statistical

> 标签: client-plugin, deepseek, deepseek-harness, dsh, dsh-plugin, en, ollama, ollama-cloud, quota, statistics, token, usage, web-ui, zh

## 简介

DeepSeek Harness 插件：显示 Ollama Cloud 的 5 小时会话限额、周限额与官方请求量，并按供应商（provider）分类统计整个 DSH 的 token 用量（今天 / 本周周一开始 / 自定义日期，数据来自本机 DSH 会话日志），提供侧栏独立统计页与侧栏底部常驻双横条。Ollama Cloud session (5h) / weekly limits and official request counts, plus whole-DSH token usage broken
