# @actovision/facebook-conversion-api-nodejs

> 标签: analytics, capi, conversion, conversions, facebook, meta, pixel, tracking

## 简介

Node.js / TypeScript client for Meta's Conversions API (CAPI). FacebookCapiClient with full parameter coverage (user_data, app_data, referrer_url, LDU/CCPA, offline events), automatic SHA-256 hashing + normalization, batching up to 1000 events per request
