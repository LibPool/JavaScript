# @ptlm-azulejo/number-badge

> 标签: JavaScript

## 简介

The `NumberBadge` component displays a numeric value in a compact, highly visible badge. It is commonly used to indicate notifications, unread messages, pending tasks, or item counts associated with icons, buttons, navigation items, or tabs.
