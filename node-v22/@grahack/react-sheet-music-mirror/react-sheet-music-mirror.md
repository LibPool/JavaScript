# @grahack/react-sheet-music-mirror

> 标签: JavaScript

## 简介

React component to render interactive sheet music using [ABC notation](http://abcnotation.com/learn). Powered by [ABC JS](https://paulrosen.github.io/abcjs/) under the hood.
