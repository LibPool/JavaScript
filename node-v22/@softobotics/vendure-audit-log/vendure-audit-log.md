# @softobotics/vendure-audit-log

> 标签: JavaScript

## 简介

Records an immutable trail of Admin API activity — entity create/update/delete, channel and variant-channel assignment, and administrator login/logout — with before/after diffs where Vendure's event payload exposes them.
