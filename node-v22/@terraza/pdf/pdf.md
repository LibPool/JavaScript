# @terraza/pdf

> 标签: JavaScript

## 简介

Markdown-to-PDF rendering for Terraza apps. Headless Chromium via Playwright, PDF metadata injection via pdf-lib.

- npm 页面：https://www.npmjs.com/package/@terraza/pdf
