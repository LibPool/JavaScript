# @percena/weft

> 标签: agent, ai, chat, react, sdk, streaming, weft

## 简介

Weft — embeddable agent chat runtime SDK (browser, production-ready). Streaming chat panel + timeline + action-bridge: an agent drives your REST API through named tools, respects your state machine, and visually replays each call.
