# @definity/stake-ledger

> 标签: definSOL, definity, hardware-wallet, ledger, solana, staking

## 简介

Ledger hardware-wallet support for @definity/stake — carries the pinned @ledgerhq stack so the base CLI stays minimal. Install alongside @definity/stake to enable --ledger.
