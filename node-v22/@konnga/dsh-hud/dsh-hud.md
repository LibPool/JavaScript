> 标签: attribution, cordis, deepseek, deepseek-harness, diff, dock, dsh, floating-panel, git, hud, image-diff, plugin, prompt-history, review, review-progress, session, session-timer, sidebar, tool-activity, web-gui

## 简介

DeepSeek Harness 的只读工作区 Git 面板：分支、ahead/behind、改动清单与差异，外加「这个会话改过哪些文件、审到哪了、跑了什么工具」。A read-only workspace Git panel for DeepSeek Harness — branch, changed files, diffs, plus per-session change attribution, review progress, and tool activity.
