# @procedures/npm

> 标签: automation, deprecate, dist-tag, npm, procedures, registry

## 简介

The npm registry as typed procedures: view, dist-tags, whoami, pack (a dry run by default) and deprecate, run with argv, and a confirmation for each write to the registry.
