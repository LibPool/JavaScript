# @procedures/better-auth

> 标签: authentication, better-auth, oauth, passkey, principal, procedures, session

## 简介

Better Auth for a procedures server: the sign-in with GitHub, Google and passkeys over MongoDB, and a request hook that gives the principal of a session or of an agent token.
