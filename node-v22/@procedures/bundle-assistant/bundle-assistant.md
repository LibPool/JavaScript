# @procedures/bundle-assistant

> 标签: assistant, bundle, claude, mcp, procedures, tools

## 简介

The opt-in tools of the personal assistant for an MCP host: calendar files, mail parsing, places, routes, weather and photo metadata, without the procedures that can carry data out.
