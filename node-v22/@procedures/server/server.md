# @procedures/server

> 标签: http, procedures, rpc, server, websocket

## 简介

A standalone procedure server: load procedure packages and serve them over HTTP and WebSocket with a token and an expose list. Its procedures server.start, server.stop and server.status manage the background server of the mark CLI.
