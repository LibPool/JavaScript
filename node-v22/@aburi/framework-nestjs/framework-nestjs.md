# @aburi/framework-nestjs

> 标签: JavaScript

## 简介

Aburi NestJS framework plugin: recognizes @Module / @Controller / @Injectable class-level decorators, HTTP method decorators (@Get / @Post / @Put / @Delete / @Patch / @Options / @Head / @All), and Guards / Interceptors / Pipes / Filters. Emits framework:n
