> 标签: altinn, bronnoysund, brreg, company-data, compliance, kyc, mcp, mcp-server, model-context-protocol, norway, norwegian, regtech

## 简介

Apier MCP Server — Norwegian company data and compliance for AI agents. Hardened thin proxy connecting local MCP clients (Claude Desktop, Cursor, VS Code, Zed) to Apier's hosted MCP server at https://www.apier.no/api/mcp: Brønnøysund company data, Altinn
