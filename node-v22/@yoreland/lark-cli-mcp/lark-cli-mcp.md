# @yoreland/lark-cli-mcp

> 标签: feishu, lark, lark-cli, larksuite, mcp, model-context-protocol

## 简介

MCP server that wraps lark-cli to operate Feishu/Lark as your own user identity (send/read/reply/search messages). Designed for one-line npx launch.
