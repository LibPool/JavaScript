# @couchbase-ecosystem/cblite-mcp

> 标签: adb, agents, ai, android, claude, couchbase, couchbase-lite, mcp, model-context-protocol

## 简介

MCP server that lets AI agents query and edit the live Couchbase Lite database inside a running Android app (debug builds, via adb and the cbl-bridge library).
