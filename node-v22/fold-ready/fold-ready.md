# fold-ready

> 标签: adaptive, foldable, hover, iphone-duo, list-detail, react, responsive, safari, split-view, tailwind, touch, viewport

## 简介

Make web apps feel native on foldables and wide touch screens (iPhone Duo, iPad, Android foldables): decide by input, not width — docking panes, unfold-safe scroll, visible-viewport units, Safari toolbar tint, and a hover-only audit. Ships Safari measurem
