# @ziyarago/ui

> 标签: arabic, components, design-system, glassmorphism, hajj, nuxt, oklch, react, rtl, ui, umrah, vue, ziyarago

## 简介

ZiyaraGo UI — glass design system for Umrah and Hajj products. OKLCH tokens, two palettes, dark and light, RTL, Thmanyah. One framework-neutral core with Vue 3, Nuxt and React adapters, 102 free components and 6 page templates (more in @ziyarago/ui-pro).
