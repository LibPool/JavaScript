# @michi-vz/core

> 标签: a11y, accessibility, ai, canvas, charting, charting-library, charts, d3, data-visualization, dataviz, engine, framework-agnostic, graph, headless, llm, llm-ready, mcp, michi-vz, responsive, svg, typescript, vanilla-js, visualization, webgpu

## 简介

Framework-agnostic chart engine - SVG, canvas & WebGPU renderers, accessible by default, emitting an LLM-ready ChartContext. No framework dependencies.
