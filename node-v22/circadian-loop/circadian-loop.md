# circadian-loop

> 标签: agent, agent-harness, agentic, ai-agent, autonomous, autonomous-agent, circadian, coding-agent, context-window, extension, llm, long-running, long-running-agent, loop, pi, pi-coding-agent, pi-package, skill, sleep-wake

## 简介

Run a pi coding agent on one goal for days. It checkpoints to disk, sleeps on a countdown, then wakes with an empty context and resumes from loop.md. A long-running autonomous agent loop: one extension, one skill, no build step.
