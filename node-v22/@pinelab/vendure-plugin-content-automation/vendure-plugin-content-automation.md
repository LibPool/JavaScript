# @pinelab/vendure-plugin-content-automation

> 标签: ai, automation, bulk generation, content, seo, vendure

## 简介

Vendure plugin that orchestrates bulk generation and enrichment of entity content (e.g. SEO meta tags) per channel and language, via consumer-provided strategies.
