# @webbuf/pbkdf2-sha256

> 标签: hmac, key-derivation, password, pbkdf2, rust, sha256, wasm

## 简介

Rust/wasm optimized PBKDF2-HMAC-SHA256 password-based key derivation for the web, node.js, deno, and bun.
