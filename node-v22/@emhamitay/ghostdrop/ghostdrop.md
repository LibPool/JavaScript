# @emhamitay/ghostdrop

> 标签: dnd, drag-and-drop, draggable, droppable, ghostdrop, react, sortable

## 简介

A lightweight, flexible drag-and-drop framework for React — supports free drag, droppable zones, and sortable lists out of the box.
