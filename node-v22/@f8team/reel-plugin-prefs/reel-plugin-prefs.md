# @f8team/reel-plugin-prefs

> 标签: f8, localStorage, player, plugin, preferences, prefs, video

## 简介

Reel plugin: persist user prefs (volume, muted, playbackRate, qualityHeight, captionsLang) to localStorage with autoplay-muted bootstrap support
