# @relve/agent-ready

> 标签: aeo, ai-agents, ai-search, content-negotiation, geo, llms.txt, markdown, middleware, nextjs

## 简介

Make any site agent-ready: serve a clean Markdown version of every page to AI agents (Accept: text/markdown, .md URLs, llms.txt), write better Markdown ahead of time with AI, and prove it with a checker and a visits dashboard. Framework-agnostic core plus
