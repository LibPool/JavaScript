# @pithagoras/godot

> 标签: game-engine, godot, mcp, pi-package, pithagoras

## 简介

Godot for Pithagoras: the real Godot 4.7 editor on the GPU, run in a container through Docker, streamed into a panel beside the chat, with its tools in every chat
