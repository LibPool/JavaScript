# @lacspace/api

> 标签: JavaScript

## 简介

Lightweight, zero-dependency, isomorphic TypeScript HTTP client for Lacspace APIs — retries, interceptors, pagination, plus query/URL/header/form/error helpers.

- 官网：https://developer.lacspace.com/packages/api
- 源码仓库：git+https://github.com/lacspace/npm-packages.git
- npm 页面：https://www.npmjs.com/package/@lacspace/api
