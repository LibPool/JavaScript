# @lacspace/inventory

> 标签: batch, ecommerce, expiry, fefo, fifo, fulfilment, headless, immutable, inventory, isomorphic, lot-tracking, low-stock, multi-location, oversell, reorder-point, reservation, safety-stock, stock, stock-ledger, stock-management, stock-transfer, typescript, warehouse

## 简介

Stock-tracking engine that prevents overselling — reserve, release, commit & restock over a plain { onHand, reserved } state. Immutable, bring-your-own-store, throws before it oversells. Isomorphic (Node, edge, browser).
