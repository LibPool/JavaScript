## 简介

Passkeys / biometric (FaceID, fingerprint, security keys) — browser ceremony helpers + server challenge, options and assertion verification (ES256/RS256/Ed25519) over Web Crypto, with passkey-sync (backup) flags, AAGUID, UV/resident-key policy and transpo
