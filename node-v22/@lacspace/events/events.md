# @lacspace/events

> 标签: browser, emitter, event-emitter, eventemitter, events, isomorphic, mitt-alternative, nanoevents-alternative, observer, pub-sub, pubsub, type-safe, typed-events, typescript, zero-dependency

## 简介

A fully type-safe event emitter / tiny pub-sub for Node and the browser — declare an events map and get compile-time-checked on/emit, error-isolated dispatch, once, waitFor and wildcard listeners. Zero-dependency, isomorphic, tree-shakeable.
