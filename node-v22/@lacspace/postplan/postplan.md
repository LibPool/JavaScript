# @lacspace/postplan

> 标签: content-planning, facebook, format-selection, instagram, isomorphic, newsroom, scheduling, social-media, typescript, zero-dependency

## 简介

Choose a post format (video / single image / carousel / text) per story and platform, so a feed like Facebook gets a natural mix instead of all videos. Rule-based and deterministic — platform fit, what the story can actually produce, a breaking-news nudge
