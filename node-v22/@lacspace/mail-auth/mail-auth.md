# @lacspace/mail-auth

> 标签: arc, authentication-results, bec, dkim, dmarc, email, homoglyph, impersonation, lookalike-domain, phishing, punycode, rfc8601, security, spf, typescript, webmail

## 简介

Email authentication-result parsing and phishing/impersonation heuristics for webmail warning banners. RFC 8601 Authentication-Results parser (SPF, DKIM, DMARC, ARC, Received-SPF fallback, trusted authserv-id selection so forged lower headers are ignored)
