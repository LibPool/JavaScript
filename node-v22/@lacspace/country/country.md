# @lacspace/country

> 标签: alpha-2, alpha-3, calling-codes, countries, country-codes, country-data, dial-codes, flags, iso-3166, isomorphic, region, typescript, zero-dependency

## 简介

ISO 3166-1 countries with alpha-2/alpha-3/numeric codes, names, calling codes, currencies, top-level domains, regions and flag emoji — lookup by any code or name, search, and typed data. Zero-dependency, isomorphic.
