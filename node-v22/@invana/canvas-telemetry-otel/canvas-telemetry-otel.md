# @invana/canvas-telemetry-otel

> 标签: canvas, fps, hyperdx, metrics, observability, opentelemetry, otlp, telemetry, traces

## 简介

OpenTelemetry (OTLP/HTTP) adapter for @invana/canvas telemetry — traces, metrics (FPS), and logs to HyperDX or any OTel collector.
