# @invana/renderer-pixijs

> 标签: backend, canvas, pixijs, renderer, webgl, webgpu

## 简介

PixiJS drawing backend for @invana/canvas — implements IRenderer + IPrimitivesRenderer, owns the Application, viewport, primitives, textures and fonts.
