# dsh-plugin-mesh

> 标签: deepseek-harness, discovery, dsh, dsh-desktop, dsh-plugin, lan, mesh, multicast, remote, tailnet, tailscale, tsnet, wireguard

## 简介

DSH Mesh：局域网自动发现同网段的 DSH 实例、显示每台机器上报的能力，并双向派发任务；可用内置的用户态 Tailscale 节点跨互联网组网。Discovers other DSH instances on the LAN, shows the capabilities each one reports, and dispatches tasks between machines in both directions, with an optional userspace Tailscale n
