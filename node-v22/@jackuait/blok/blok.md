# @jackuait/blok

> 标签: block-based editor, blok, extensible editor, headless editor, notion-like editor, rich text editor, text editor

## 简介

Blok — headless, highly extensible rich text editor built for developers who need to implement a block-based editing experience (similar to Notion) without building it from scratch
