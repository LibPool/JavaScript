# @elvora/angular

> 标签: accessibility, angular, angular17, angular18, components, design-system, elvora, headless, signals, standalone, ui

## 简介

Elvora UI components for Angular 17+ — standalone components, signals-based, same headless API as the React adapter, WCAG 2.1 AA.
