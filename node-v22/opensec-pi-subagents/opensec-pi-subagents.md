# opensec-pi-subagents

> 标签: agent, autonomous, bun, opensec, pi, pi-bolt, pi-extension, pi-package, subagent

## 简介

OpenSec Subagents for Pi: specialized agents in separate sessions that inherit the parent's model and thinking level. Bun build, for Pi-Bolt.
