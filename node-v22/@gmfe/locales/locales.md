# @gmfe/locales

> 标签: JavaScript

## 简介

`@gmfe/locales` 是 gmfe 组件库的国际化工具包，用于管理多语言翻译。内置支持简体中文（zh）、繁体中文（zh-HK）、英文（en）和泰语（th）四种语言，语言偏好会自动持久化到 `localStorage`。
