# @leaguetoolkit/meta-cli

> 标签: JavaScript

## 简介

Command-line client for the LoL Meta Wiki API (meta-api.leaguetoolkit.dev): property types at a build, hash resolution, class lookups, and type diffs across patches.

- 官网：https://meta-wiki.leaguetoolkit.dev/api/cli/
- 源码仓库：git+https://github.com/LeagueToolkit/lol-meta-wiki.git
