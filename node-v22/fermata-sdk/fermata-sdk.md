# fermata-sdk

> 标签: agent-payments, ai-agents, escrow, mcp, mpp, stablecoin, tempo, tlsnotary, x402

## 简介

Pay on proof for AI agents: the `fermata` MPP payment method (agent and server side), escrow bindings on Tempo, reconciliation by memo and vendor scores.
