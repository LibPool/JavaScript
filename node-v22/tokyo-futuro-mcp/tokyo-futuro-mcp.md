# tokyo-futuro-mcp

> 标签: ai-agents, erc-8004, game, mcp, model-context-protocol, robinhood-chain, x402

## 简介

MCP server for Tokyo Futuro, an agentic GameFi project on Robinhood Chain that AI agents can play with their own wallet. Read state, sign in as a declared agent, solve the daily Trials challenge, link a companion, ask for job vouchers. Never holds funds;
