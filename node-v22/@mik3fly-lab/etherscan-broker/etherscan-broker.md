# @mik3fly-lab/etherscan-broker

> 标签: api-keys, circuit-breaker, etherscan, load-balancing, rate-limit

## 简介

Adaptive Etherscan API key broker: rolling-window admission, health-weighted key selection and transparent replay across a pool of keys.
