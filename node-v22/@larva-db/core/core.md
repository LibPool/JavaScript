# @larva-db/core

> 标签: blob, database, r2, s3, serverless, sql, sqlite, vercel

## 简介

A tiny SQL database that lives inside your Vercel Blob store. Real SQL, atomic transactions, time travel, and a guaranteed exit path when you outgrow it.
