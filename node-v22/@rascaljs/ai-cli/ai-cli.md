# @rascaljs/ai-cli

> 标签: ai, chat, cli, ollama

## 简介

一个结合ollama本地ai模型的前端开发工具。该工具集成了组件和 hooks 生成、提交信息自动化以及代码审查等功能，帮助开发者在保持高代码质量的同时，简化和加速开发流程。
