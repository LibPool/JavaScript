# @scryve-tools/ckb-xudt

> 标签: beaf, ckb, nervos, payment, rgb++, token, udt, utxoswap, xudt

## 简介

xUDT/RGB++ token payments on CKB — send tokens, split payments between multiple recipients, fetch live prices from UTXOSwap, and encode/decode LE-16 cell data.
