# @scryve-tools/ckb-witness-data

> 标签: ckb, encoding, nervos, receipt, seal, transaction, witness

## 简介

Generic witness data encoding for CKB transactions — embed arbitrary structured data in transaction witnesses using a magic-byte-prefixed binary format. Zero capacity cost.
