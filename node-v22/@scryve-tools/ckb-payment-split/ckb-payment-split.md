# @scryve-tools/ckb-payment-split

> 标签: capacity, ckb, fee, nervos, omnilock, payment, split

## 简介

CKB payment splitting with cell capacity awareness — dynamically calculates minimum cell capacity for any CKB address and splits payments between recipients with dust-limit auto-rebalancing.
