# @jillson1/dsh-file-jump

> 标签: JavaScript

## 简介

DSH web GUI plugin: 让 read/edit/write 工具卡片的文件路径带上绝对路径与修改片段，点击后由 dsh-vscode 扩展在 VS Code 编辑区打开并精确跳行
