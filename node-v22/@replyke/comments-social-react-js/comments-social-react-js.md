# @replyke/comments-social-react-js

> 标签: comments, downvotes, moderation, react, reactions, replyke, reporting, social, typescript, upvotes

## 简介

Replyke: Add a modern comment section to your React apps: replies, likes, mentions, highlighted comments, GIFs, built-in authorization, reports & moderation.
