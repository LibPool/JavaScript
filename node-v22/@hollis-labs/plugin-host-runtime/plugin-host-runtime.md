# @hollis-labs/plugin-host-runtime

> 标签: import-map, micro-frontend, plugin, react, vite

## 简介

One shared React for runtime-loaded plugin UIs: a Vite plugin that emits the host import map, the plugin-side externals config, and a browser preflight.
