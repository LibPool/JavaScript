# @coworkkit/server

> 标签: agent, ai, backend, coworkkit, nextjs, sdk, token, voice

## 简介

Coworkkit server SDK — the one token route your backend needs: hold the secret key, mint a session (mintSession / coworkkitSessionRoute for Next.js). The key never reaches the browser.
