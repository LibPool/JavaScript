# @blockchain0x/x402

> 标签: agent-payments, ai-agent, base, blockchain0x, express, fastify, http-402, payment-required, usdc, x402

## 简介

x402 protocol client + server adapters for Blockchain0x. Drop-in fetch wrapper for pay-side, Fastify/Express plugins for receive-side. See https://blockchain0x.com/docs/x402.
