# @tmorin/ceb-core

> 标签: custom-element, custom-element-builder, custom-elements, custom-elements-v1, javascript-library, typescript, typescript-library

## 简介

The package is part of the `<ceb/>` library. It provides the main builder used to define and register Custom Elements (v1).
