> 标签: bus, cqrs, custom-element, custom-element-builder, custom-elements, custom-elements-v1, event-bus, javascript-library, message-bus, messaging, typescript, typescript-library

## 简介

The package is part of the `<ceb/>` library. It provides a builder to interact with the Bus in Custom Elements.
