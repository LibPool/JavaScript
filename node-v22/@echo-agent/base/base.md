# @echo-agent/base

> 标签: agent, ai-agent, bun, cli, llm, llm-agent

## 简介

Echo's assembly layer: the launcher parts, the product contract, the shell port, host capabilities and the pipe form. No terminal dependency — a web or desktop product depends on this and brings its own shell. Requires Bun.
