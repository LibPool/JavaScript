# tabby-s3-sync-settings

> 标签: s3, settings, sync, tabby, tabby-plugin

## 简介

Sync your Tabby config across devices using Amazon S3 or any S3-compatible storage (Wasabi, DigitalOcean Spaces, Backblaze B2, MinIO, Cloudflare R2...).
