# @bridgeline-digital/hawksearch-app-cli

> 标签: cli, hawk-apps, hawksearch

## 简介

For Bridgeline developers: create, deploy and register Hawk Apps (Services-built tools embedded in HawkSearch). Requires a Hawk Apps publisher key.
