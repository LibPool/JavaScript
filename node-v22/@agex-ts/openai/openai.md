# @agex-ts/openai

> 标签: agent, agex, agex-ts, gpt, llm, ollama, openai, openrouter, provider, vllm

## 简介

OpenAI Chat Completions provider for agex-ts. Lowers NeutralTurn[] to OpenAI messages; streams via SSE; baseUrl-friendly for OpenAI-compatible local servers (ollama, vLLM, LM Studio, OpenRouter, Together, etc.).
