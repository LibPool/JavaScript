# cm-live-markdown

> 标签: codemirror, codemirror6, editor, live-preview, markdown, obsidian, react, wysiwyg

## 简介

Живой Markdown в духе Obsidian Live Preview для CodeMirror 6: разметка прячется вне курсора, списки, чекбоксы, таблицы, сочетания клавиш. Ядро без React и тонкая обёртка для React.
