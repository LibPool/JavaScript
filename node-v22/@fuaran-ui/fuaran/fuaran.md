# @fuaran-ui/fuaran

> 标签: JavaScript

## 简介

Reserved convenience entry point for the Fuaran UI TypeScript implementation. The substantive packages ship as @fuaran-ui/ui, @fuaran-ui/ops, @fuaran-ui/renderer and friends — install @fuaran-ui/ui instead.
