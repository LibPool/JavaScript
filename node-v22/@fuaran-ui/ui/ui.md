# @fuaran-ui/ui

> 标签: ai, fuaran, smart-constructors, typed-ui, ui

## 简介

Smart constructors + bounded-type kit + pre-emit validation for the Fuaran UI language contract — the ergonomic TypeScript author surface (fuaran.dashboard / fuaran.metric / …) over @fuaran-ui/schema. Mirrors the F# Fuaran.X module.
