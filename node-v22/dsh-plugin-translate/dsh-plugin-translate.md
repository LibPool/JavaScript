# dsh-plugin-translate

> 标签: deepseek-harness, dsh, plugin, translation

## 简介

Immersive translation for the DeepSeek Harness web GUI: inline sub-text translations of assistant output and reasoning, plus a selection popover and a pluggable provider registry.
