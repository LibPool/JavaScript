# @lotux/cli

> 标签: ai-agent, cli, ctrader, lotux, mt5, trading

## 简介

Thin command-line wrapper over @lotux/client for the LOTUX AI-native API — read accounts/positions/history and (opt-in) place/modify/close trades.
