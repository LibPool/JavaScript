# nanocalcs-mcp

> 标签: calculator, llm, mcp, model-context-protocol, nanocalcs, tokens

## 简介

MCP server for nanocalcs.com: exact calculators (dates, business days, Schengen, time zones, loans, compound interest, units, molar mass, SAT/AP scores, LLM tokens, API cost, GPU VRAM) plus prefilled links to 430+ free online tools in 63 languages.
