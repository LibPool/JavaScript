# @bermont-digital/iframetools

> 标签: JavaScript

## 简介

Bermont Digital Public Package for resizing iFrame using PostMessage API, as well as checking for StorageAccess API Access and if not, redirecting to specific url with PHP file to set First-Party Cookies for safari web browser agents.
