# @eloquentjs/validator

> 标签: eloquent, express, fastify, orm, validation, validator, yup, zod

## 简介

Full-featured standalone validation for EloquentJS and any Node.js app — sync/async rules, nested fields, fluent schema API, ORM-integrated unique/exists, Express and Fastify adapters
