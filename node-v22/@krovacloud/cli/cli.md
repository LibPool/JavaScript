# @krovacloud/cli

> 标签: cli, cloud, cubes, firecracker, krova, krova-cloud, microvm

## 简介

Krova Cloud CLI (krova) — manage Cubes (Firecracker microVMs), browse the catalog, and log in, from your terminal.
