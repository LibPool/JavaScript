# @wazobiatech/wazui

> 标签: JavaScript

## 简介

`@wazobiatech/wazui` is a React component library that provides a set of reusable UI components, hooks, and providers for building modern web applications. It is built with TypeScript, Tailwind CSS, and integrates Shadcn UI components.
