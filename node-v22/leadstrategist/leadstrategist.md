# leadstrategist

> 标签: cli, company data, cvr, danish companies, denmark, financials, mcp

## 简介

Read-only CLI for Danish company data (CVR) and annual-report financials from Lead Strategist: look up companies, search by industry/size/revenue, fetch financials.

## 官网

- 官网：https://leadstrategist.dk/docs
- npm 页面：https://www.npmjs.com/package/leadstrategist
