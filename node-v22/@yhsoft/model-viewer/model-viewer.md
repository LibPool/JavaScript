# @yhsoft/model-viewer

> 标签: 3d model, ThreeJS, component, front-end, model-viewer, vue-component, vue3, yhsoft, 颖华软件

## 简介

基于 ThreeJS 开发的三维模型查看器，支持多种 3D 格式的模型浏览，支持对模型的旋转、平移、缩放等操作
