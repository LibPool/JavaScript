# @reinconsole/signer

> 标签: agent-payments, ai-agents, custody, eip-3009, rein, session-keys, signer, x402

## 简介

Rein's session-key signer — the custody tier. Holds agent wallet keys and releases EIP-3009 signatures only against engine-signed allow decisions, under session caps.
