# @bernhardb/ngx-virtual-scroller

> 标签: angular, angular 14, angular 15, angular 16, angular 17, angular 18, ngx, scroll, virtual scroll

## 简介

Virtual Scroll displays a virtual, "infinite" list. Supports horizontal/vertical, variable heights, & multi-column.
