# @gatilab/emdash-emailit

> 标签: email, email-provider, emailit, emdash, emdash-plugin, transactional-email

## 简介

Emailit email provider for EmDash: delivers EmDash's own mail (invites, magic-link sign-in, account recovery) and plugin email through the Emailit API, with the API key, sender and Reply-To editable in the admin.
