# @dogsbay/format-myst

> 标签: JavaScript

## 简介

MyST Markdown format plugin for Dogsbay — imports MyST (Sphinx myst-parser / Jupyter Book / mystmd) corpora into TreeNode[] by translating MyST directives, roles, and targets to Dogsbay-MD.
