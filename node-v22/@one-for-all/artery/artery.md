# @one-for-all/artery

> 标签: JavaScript

## 简介

低代码工具链中有两个非常重要的环节，一是为开发者提供一套功能完备的用于构建动态页面的页面引擎；二是将前者构建的页面渲染给最终用户使用的渲染引擎。初看上去，页面引擎似乎包含了渲染引擎的能力，但其实不然。
