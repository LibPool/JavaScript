# @oklch-picker/angular

> 标签: angular, angular-color-picker, angular-colour-picker, angular-component, color, color-picker, color-space, colour, colour-picker, colour-space, display-p3, gamut, oklch, oklch-color-picker, oklch-colour-picker, oklch-picker, p3, picker, rec2020, signals, srgb, standalone, wide-gamut

## 简介

An OKLCH color picker for Angular 17+. Standalone, signal-based, with gamut-aware sliders and wide-gamut P3 and Rec. 2020.
