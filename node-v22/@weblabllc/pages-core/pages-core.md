# @weblabllc/pages-core

> 标签: articles, blog, cms, mongodb, multilang, mysql, pages, postgres, puck, redirects, sitemap, typescript

## 简介

Transport- and ORM-agnostic core for Puck-backed content: configurable kinds (page/article/blog), publish lifecycle, MLT, authors, folders with computed slugs and redirects, portable export/import, sitemaps, optional Postgres/MySQL/MongoDB stores
