# @gizmodata/warp-sql

> 标签: apache-arrow, arrow, duckdb, fetch, gizmodata, hardcharger, http, sql, warp-sql

## 简介

JavaScript/TypeScript client for the Warp SQL protocol: SQL over plain HTTP with Apache Arrow results, for Node, browsers, Deno, Bun and edge runtimes.
