> 标签: android, auth, authentication, credential-manager, google-login, google-sign-in, google-signin, oauth, oauth2, openid-connect, react-native, sign-in-with-google

## 简介

A premium, Google-compliant Sign-In library for React Native. Dual-flow support — modern Credential Manager + classic GoogleSignInClient. Built directly on Google's official SDKs with no hacks.
