# dsh-design-studio

> 标签: deepseek-harness, design, dsh, dsh-plugin, frontend, preview

## 简介

Design workbench in the DeepSeek Harness right sidebar: watch web / app / poster screens generate on a canvas with device frames, click an element to send it to the chat, tweak design tokens, compare versions, export share-ready images and scan to view on
