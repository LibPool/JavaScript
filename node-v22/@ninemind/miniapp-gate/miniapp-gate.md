# @ninemind/miniapp-gate

> 标签: JavaScript

## 简介

Admission gate and bake-time redaction for generated single-file miniapp bundles. Host-neutral: the smoke-load runs in a worker thread, so a hostile or merely broken bundle cannot take the host process down.
