# @mulmobridge/webhook

> 标签: ai-agent, bridge, chatbot, http, mulmobridge, mulmoclaude, webhook

## 简介

Generic webhook bridge for MulmoBridge — POST JSON, get the AI reply in the response. Any HTTP-speaking tool can use it.
