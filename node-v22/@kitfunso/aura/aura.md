# @kitfunso/aura

> 标签: claude-code, colors, cross-platform, hooks, iterm2, macos, terminal, windows-terminal

## 简介

Color identity for terminal windows: repo = hue, branch = shade, tab name when no repo names it. Any shell, any agent.
