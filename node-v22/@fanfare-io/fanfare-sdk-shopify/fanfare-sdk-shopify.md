# @fanfare-io/fanfare-sdk-shopify

> 标签: ecommerce, fanfare, headless, sdk, shopify, storefront

## 简介

Shopify storefront adapter for Fanfare SDK: product→experience resolver, checkout verifier, and experienceIds metafield primitives
