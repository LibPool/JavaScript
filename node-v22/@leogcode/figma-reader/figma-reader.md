# @leogcode/figma-reader

> 标签: ai-agents, cli, design-tokens, figma, mcp, model-context-protocol

## 简介

Read-only Figma access for AI agents without plugin or API token, as an MCP server or a CLI: local .fig decoding, or logged-in figma.com over CDP
