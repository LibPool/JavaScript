# @runmarks/grok-plugin

> 标签: agent-tracker, grok, grok-build, hooks, runmark, telemetry

## 简介

将 [Grok Build](https://x.ai/cli)（`grok`）编码会话遥测上报到 [Runmark](../../README.md) 服务中心，与 OpenCode / Codex / Claude 等客户端共用同一 Dashboard。
