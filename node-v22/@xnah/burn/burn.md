# @xnah/burn

> 标签: anthropic, cli, cost, dashboard, llm, observability, openai, openrouter, proxy, spend, tokens

## 简介

Track LLM token usage and spend across providers. A local proxy that prices every request and a dashboard that shows where the money went.
