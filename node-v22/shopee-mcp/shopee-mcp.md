# shopee-mcp

> 标签: ai-agent, browser-extension, claude, mcp, model-context-protocol, shopee

## 简介

MCP server yang menjembatani AI assistant ke Shopee lewat browser extension pendamping (cek login, cari produk, bandingkan harga, verifikasi varian). Butuh extension pendamping (lihat README) agar bisa berfungsi.
