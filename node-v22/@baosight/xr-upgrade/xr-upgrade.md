# @baosight/xr-upgrade

> 标签: baosight, ef, migration, upgrade, xr

## 简介

XR/EF Vue3 老项目原地升级：npx @baosight/xr-upgrade 免装运行，或全局安装后用 xr-upgrade 命令（自动识别应用名/平台/类型，在线拉取模板包对比升级，dry-run 报告 → --apply）
