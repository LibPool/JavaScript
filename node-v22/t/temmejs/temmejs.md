# temmejs

> 标签: dom, emmet, javascript, javascript-library, typescript

## 简介

Temme (or Emmet in reverse) is to javascript what Emmet is to HTML and CSS, with no doubts, Emmet saved us from the headache of working with HTML and CSS, and now, Temme is doing Javascript the same favour too.
