# text-to-diagram

> 标签: ai-agent, architecture-diagram, chinese, dagre, diagram, diagram-as-code, drawio, elk, excalidraw, flowchart, json-ir, knowledge-graph, mcp, mermaid, plantuml, svg, text-to-diagram

## 简介

Archify 式图示流水线：Agent 只产出结构化 JSON（禁止坐标/DSL），本地做 Schema 校验 + 自动修复 + 证据反幻觉 + dagre/ELK 双引擎布局 + SVG/HTML/PNG/Mermaid/PlantUML/draw.io/Excalidraw 多格式导出。中文友好、零锁定、无 Chromium。
