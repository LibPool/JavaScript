# twosystems

> 标签: agent-hooks, ai-agents, calibration, claude-code, codex, coding-agents, decision-models, github-copilot, guardrails, llm-cost, system-1, token-optimization

## 简介

A cheap, honest watchman for AI coding agents (Claude Code, GitHub Copilot, Codex): notices when the agent is stuck or a fresh start would save tokens, using a small decision model, and measures what it saved. Created by Shashikant.
