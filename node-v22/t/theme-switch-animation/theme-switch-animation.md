# theme-switch-animation

> 标签: animation, dark-mode, nextjs, nuxt, react, theme, view-transitions, vue

## 简介

Theme switch animation library built on the View Transitions API. Works with React 18+, Vue 3+, Next.js and Nuxt 3+.
