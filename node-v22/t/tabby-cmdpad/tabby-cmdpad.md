# tabby-cmdpad

> 标签: beta, broadcast, cmdpad, command, commands, editor, execute, multi-line, ssh, tabby-plugin, terminal, version, 测试

## 简介

Multi-line command editor for Tabby SSH terminals. One-click execute to the current terminal, or broadcast to all SSH terminals. Button injected next to Reconnect via TerminalDecorator.
