# typespec-postman

> 标签: api-testing, codegen, postman, postman-collection, typespec, typespec-emitter

## 简介

TypeSpec emitter: generate a Postman Collection v2.1 from an HTTP service definition, with requests, auth, chained ids and assertions derived from the spec.
