# titan-email-mcp

> 标签: ai-agent, claude, claude-code, claude-desktop, email, godaddy, imap, mcp, model-context-protocol, smtp, titan, titan-email

## 简介

MCP server that connects Claude (or any MCP client) to a Titan Email mailbox over IMAP/SMTP, tested and confirmed with GoDaddy mailboxes.
