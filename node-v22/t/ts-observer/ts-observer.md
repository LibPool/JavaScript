# ts-observer

> 标签: JavaScript

## 简介

基于rxjs + proxy代理的方式实现响应式观察，监听对象属性的变化(可以监听嵌套对象属性变化，新增、删除属性行为，及数组的变化)，自动实例化BehaivorSubject，并自动next更新。外部只需订阅响应式对象即可获取变更通知
