> 标签: angular, browser-extension, bug-reporting, bug-reproduction, bug-tracking, bugsnag-alternative, chrome-extension, console-errors, debug, debugging, developer-tools, devtools, error-reporting, frontend-debugging, fullstory-alternative, github, github-issues, javascript, jira, logrocket-alternative, network-errors, nextjs, qa-testing, qa-tool, react, reproduction-steps, root-cause-analysis, sentry-alternative, session-recording, session-replay, typescript, vue

## 简介

Capture a browser bug into one offline .html file your AI coding agent reads over MCP and fixes — session replay, console, network, repro timeline, and a generated failing test. Local-first, zero backend. Free.
