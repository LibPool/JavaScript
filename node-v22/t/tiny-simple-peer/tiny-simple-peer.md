# tiny-simple-peer

> 标签: data, data channel, data channel stream, data channels, p2p, peer, peer-to-peer, stream, video, voice, webrtc, webrtc stream

## 简介

Simple one-to-one WebRTC video/voice and data channels, which drops stream support from simple-peer to improve performance and reduce bundle size
