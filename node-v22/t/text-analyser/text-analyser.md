# text-analyser

> 标签: empty lines counter, letters, signs, signs counter, spaces counter, text, text analyse, txt file, txtFile, word counter, words

## 简介

Text Analyser is lightweight library to analyse basic informations about text files like number of words, signs, spaces and empty lines.
