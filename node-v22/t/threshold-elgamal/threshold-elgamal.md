# threshold-elgamal

> 标签: cryptographic-algorithm, cryptography, data-protection, distributed-cryptography, elgamal, encryption, key-management, privacy, public-key-encryption, secret-sharing, secure-communication, security, threshold-encryption, typescript-cryptography

## 简介

A browser-native TypeScript ElGamal library for Ristretto255-based research prototypes, shipping additive ElGamal, threshold decryption, protocol helpers, board auditing, transport primitives, and log-driven DKG state machines.
