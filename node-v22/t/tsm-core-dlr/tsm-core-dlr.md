# tsm-core-dlr

> 标签: dlr, lancedb, mcp, neo4j, nl2sql, semantic-layer, tsm

## 简介

TSM Core Service (DLR): the semantic-layer backend for the Three-Level Semantic Modeling framework — LanceDB vectors + in-process memory graph (Neo4j optional) + MCP server with 7 tools. CLI: tsm serve|status|build|verify|scenario|fetch-model|grade|stats|
