# trpc-docs-generator

> 标签: api, docs, documentation, generator, trpc, typescript, zod

## 简介

Generate beautiful, fully interactive tRPC API documentation with a built-in testing playground. Test endpoints directly in the browser, manage headers, auto-fill requests, and see live responses - all with zero configuration.
