# terv-ipc

> 标签: electron, eçectron.js, react, template, terv, terv.js, tervjs, vite

## 简介

Terv-ipc é uma ferramenta especialmente criada para o projeto Terv.js. Este pacote facilita a comunicação via IPC diretamente de sua aplicação ReactJS ou qualquer outra interface de usuário. O IPC é um conceito amplamente difundido em projetos com Electro
