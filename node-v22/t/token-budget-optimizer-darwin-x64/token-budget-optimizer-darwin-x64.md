# token-budget-optimizer-darwin-x64

> 标签: ai-agents, bm25, context, llm, napi-rs, rag, rust, tiktoken, token-budget, tokens

## 简介

Send less context. Keep what matters. Deterministic, local-first selection of LLM context under a hard token budget, powered by Rust.
