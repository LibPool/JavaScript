# tutti-api

> 标签: api, auth0, classifieds, client, graphql, messaging, reverse-engineered, search, switzerland, tutti, tutti.ch

## 简介

Unofficial TypeScript client for the (reverse-engineered) tutti.ch API — search, listings, seller profiles, categories, suggestions, messaging, and Auth0 login.
