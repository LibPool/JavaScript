# tradingview-chart-mcp

> 标签: ai-agent, chart, mcp, model-context-protocol, playwright, screenshot, trading, tradingview

## 简介

MCP server that drives the TradingView web chart: screenshots, drawings, indicators, timeframes, alert webhook. Works over stdio and Streamable HTTP.
