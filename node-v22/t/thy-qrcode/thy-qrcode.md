# thy-qrcode

> 标签: javascript, lit, qr code generator, qrcode, text qr, typescript, vite, webcomponent, wifi qr

## 简介

This is a web component to generate QR-Codes. It supports two types ("text" and "wifi") that can be  set via the type-attribute. It then renders the inputs accordingly. Supports unicode emojis 😀.
