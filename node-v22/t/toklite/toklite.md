# toklite

> 标签: anthropic, claude, claude-code, cli, cost-optimization, llm, openai, prompt-caching, proxy, tokens

## 简介

Local CLI proxy that cuts LLM token usage for Claude Code, Kiro, Cursor and any OpenAI/Anthropic-compatible tool, with provider-verified savings.
