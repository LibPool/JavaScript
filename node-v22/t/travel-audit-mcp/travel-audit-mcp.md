# travel-audit-mcp

> 标签: audit, expense-report, mcp, mcp-apps, mcp-server, model-context-protocol, stateful-ui, travel-expense

## 简介

差旅费审核 MCP App —— 状态驱动 UI（服务端单一事实源 + dispatch_ui_action + app-only 工具组），基于 @modelcontextprotocol/ext-apps 2.x SDK。缺省 MOCK 演示模式，可配 TAAPP_ 环境变量切换真实后端。
