# transpareo-time-machine

> 标签: digital-product-passport, dpp, epcis, esprr, renderer, spa

## 简介

Open-source Digital Product Passport renderer: a self-contained SPA that consumes signed DPP snapshots + EPCIS events and renders the public passport page for a publisher.
