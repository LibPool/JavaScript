# temporal-fmt

> 标签: date, format, tc39, temporal, time

## 简介

Format and parse Temporal (PlainDate, PlainTime, PlainDateTime, ZonedDateTime) using date-fns-style tokens. Validates strictly — bad input throws, not garbage. Locale-aware, no deps.
