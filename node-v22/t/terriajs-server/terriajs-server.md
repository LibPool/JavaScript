# terriajs-server

> 标签: National Map, terriajs

## 简介

NodeJS server for TerriaJS, consisting of a CORS proxy, proj4 CRS lookup service, and express static server.

## 官网

- 官网：https://github.com/TerriaJS/TerriaJS-Server
- 源码仓库：git+https://github.com/TerriaJS/TerriaJS-Server.git
