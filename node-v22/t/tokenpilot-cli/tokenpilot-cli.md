# tokenpilot-cli

> 标签: claude, claude-code, cli, context, cost, tokens, usage

## 简介

See where your Claude Code tokens go and keep sessions on track: context rent, sub-agent cost, cross-session edit conflicts, failure loops, output trimming and hand-overs. Local, zero runtime dependencies.
