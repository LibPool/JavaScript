# tinyzip

> 标签: JavaScript

## 简介

Comparing to other modules this module provides zip file stream which  is more cpu and memory savy. Also it doesn't depend on any non standard native liberaries, pure Node.Js > 0.6.X.

- 源码仓库：git://github.com/sergeyksv/tinyzip.git
