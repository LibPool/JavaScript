# test-arbiter

> 标签: ai, cli, flaky-tests, junit, qa, testing, triage

## 简介

Your AI QA engineer — finds coverage gaps, generates tests, runs suites, triages failures as real bugs vs. noise, and heals broken tests. Works as a CLI or MCP server.
