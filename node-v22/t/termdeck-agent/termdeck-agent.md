# termdeck-agent

> 标签: agent, ai-agent, claude, claude-code, cli, codex, coding-agent, developer-tools, grok, remote, termdeck, web-ui

## 简介

Connect a machine to Termdeck, the web UI for Claude Code, Codex and Grok CLI sessions. Installs, repairs and checks the Termdeck agent on macOS, Linux and Windows.
