# terminus-shell

> 标签: agent, ai-agent, claude, cli, mcp, remote-shell, skill, ssh, tmux

## 简介

Agent-friendly persistent remote shell: SSH exec, durable tmux sessions, cursor-based output reading, and per-server memory for AI agents.
