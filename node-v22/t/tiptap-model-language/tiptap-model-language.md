# tiptap-model-language

> 标签: autocomplete, editor, model-language, prompt, prompt-editor, prosemirror, syntax-highlighting, template, template-editor, tiptap, validation

## 简介

A Tiptap extension for the model-language template syntax: raw-text {{…}} highlighting, staged type-aware autocomplete (variables, filters, control blocks), hover diagnostics and local validation via the model-language engine.
