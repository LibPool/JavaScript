# tbr-ui

> 标签: JavaScript

## 简介

Using npm ```sh     npm i tbr-ui ``` ## 使用方式 在main.ts 里面添加如下代码 ```js import 'tbr-ui' import 'tbr-ui/dist/tbr-ui.css' ``` ## 如何添加通用（组件，管道，指令） 通用（组件，管道，指令）添加方式和平时开发一致，开发完成之后记得到对应目录下的index.ts注册
