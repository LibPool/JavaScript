# tokmax

> 标签: ccusage, claude-code, codex, leaderboard, litellm, tokenmax, tokens, usage, vibecoding

## 简介

Scan your local Codex + Claude Code logs, aggregate per-model token usage, and publish the API-equivalent $ to the tokmax leaderboard (tokmax.dev). Prices: LiteLLM, counting: ccusage. Aggregates only — never your prompts, files, or keys.
