# taint-tracked-tool-broker

> 标签: agent, agentic, ai-safety, llm, mcp, prompt-injection, sandboxing, security, taint-tracking, tool-calling

## 简介

Provenance labeling for agent inputs, enforced at the tool-call boundary. Blocks untrusted data from reaching shell, filesystem, and network sinks. Ships with an injection corpus and a published list of known gaps.
