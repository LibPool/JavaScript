# threejs-scene

> 标签: app-shell, deterministic, frame-loop, scene, three, threejs, webgl

## 简介

Deterministic imperative three.js scenes: a scoped, unidirectional module contract, an LLM-first procedural asset toolkit, fixed-step physics, explicit disposal — and the instructions, agents and enforced rules shipped inside the package.
