# tr-json-chain

> 标签: append-only, audit, audit-log, event-log, hash-chain, immutable, postgres, postgresql, tamper-evident

## 简介

Immutable SHA-256 hash-chained JSON event log on PostgreSQL. Append-only audit chain with self-maintaining, never-migrated schema.
