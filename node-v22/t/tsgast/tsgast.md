# tsgast

> 标签: gas, tap, test, test-anything-protocol, testing, unit-testing

## 简介

TSGasT is a TAP-compliant testing framework for Google Apps Script(GAS) in TypeScript. It provides a simple way to verify that the GAS programs you write behave as expected.
