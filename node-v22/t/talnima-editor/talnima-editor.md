# talnima-editor

> 标签: arabic, article, dari, editor, medium, persian, prosemirror, react, rich-text, rtl, sanitize, tiptap, wysiwyg

## 简介

A fast, Medium-style article editor for React, built on Tiptap/ProseMirror, with right-to-left (Dari/Persian/Arabic) support and a server-safe HTML renderer.
