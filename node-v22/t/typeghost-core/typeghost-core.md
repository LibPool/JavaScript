# typeghost-core

> 标签: auto-type, demo, live-coding, presentation, screencast, teleprompter, typewriter, typing, typing-simulator

## 简介

Human-like code typing engine — the heart of TypeGhost. Replay pre-written code with realistic rhythm, corrected typos and checkpoints, in any editor you can adapt it to.
