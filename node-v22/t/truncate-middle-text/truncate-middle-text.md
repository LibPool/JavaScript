# truncate-middle-text

> 标签: truncate, truncate middle, 中间省略号

## 简介

针对单行文本中间省略号，特点： 1. 根据元素宽度自动触发单行文本中间省略号 2. 文字动态变更亦可以触发 3. 当隐藏元素（从超长文档中滚动到视图内）时，可以正确识别是否渲染中间省略号
