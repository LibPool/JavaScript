# tritanopia

> 标签: a11y, accessibility, color-blindness, color-vision, colorblind, cvd, simulate, tritan, tritanopia

## 简介

Simulate tritanopia (blue-yellow) color vision — a typed shortcut over cvdsim / the OpticQuiz engine (Machado, Oliveira & Fernandes 2009).

## 官网

- 官网：https://opticquiz.com/
- 源码仓库：git+https://github.com/vince-gonzalez/opticquiz.com.git
- npm 页面：https://www.npmjs.com/package/tritanopia
