# tailwind-dark-theme

> 标签: css, dark-theme, light-theme, tailwind, tailwindcss, theme

## 简介

Zero-config Tailwind CSS plugin for seamless dark/light theme switching with automatic color inversion (white↔black, gray-50↔gray-950) and custom CSS variables support.
