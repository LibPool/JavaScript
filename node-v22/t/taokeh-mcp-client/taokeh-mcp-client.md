# taokeh-mcp-client

> 标签: accounting, malaysia, mcp, taokeh

## 简介

Minimal reference client for the Taokeh MCP connector (taokeh.my) — connect with a bearer token, list tools, call one.

## 官网

- 官网：https://taokeh.my/mcp-server
- 源码仓库：git+https://github.com/taokeh/taokeh-mcp.git
