# taro_licenseplate

> 标签: JavaScript

## 简介

- 请确保安装node vue3.2+  - 本项目用taro编写 实际语法跟vue3差不多 - 使用到了taro 一个popup相关组件 如需用到自己的非taro框架项目中 请替换popup组件 （components/licensePlate/index 59行）
