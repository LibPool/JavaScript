# trendsapi-tiktok

> 标签: hashtag-trends, tiktok, tiktok-api, tiktok-trends, trendsapi, typescript

## 简介

TikTok hashtag and search interest trends via the Trends API. History, growth, and live trending hashtags. No TikTok API approval needed.
