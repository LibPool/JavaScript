# trackline

> 标签: agent-alignment, ai-agents, ci, claude-code, codex, developer-tools, evaluation, guardrails, hooks, llm

## 简介

Watches whether an AI coding agent is still doing what you asked. Runs beside Claude Code or Codex and says when the work stops matching the request.
