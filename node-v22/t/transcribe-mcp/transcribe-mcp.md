# transcribe-mcp

> 标签: mcp, modelcontextprotocol, pay-per-call, subtitles, transcription, usdc, video-editing, whisper, x402

## 简介

MCP server that transcribes audio/video and finds dead air, paying per call in USDC over x402. No account, no API key, no signup.
