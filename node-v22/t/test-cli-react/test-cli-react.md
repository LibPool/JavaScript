# test-cli-react

> 标签: JavaScript

## 简介

此架构针对官网(pc和移动), 我们官网的特点是图片较多, 有时候一张图片的大小, 相当于几个js文件的小, 所以我们要优先针对图片的优化和加载速度的优化, 然后就是考虑开发者的体验性,和业务代码的可维护性.
