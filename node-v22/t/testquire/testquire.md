# testquire

> 标签: dependency-mocking, mock, mocking, module-mock, require-mock, stubs, test-mocking, test-utility, testing, testing-tools, unit-testing

## 简介

A lightweight utility for mocking dependencies in Node.js tests by overriding the native require function at runtime
