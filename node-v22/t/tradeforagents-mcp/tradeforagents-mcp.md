# tradeforagents-mcp

> 标签: ai-agents, autonomous, crypto, exchange, hyperliquid, leaderboard, market-data, mcp, trading

## 简介

TradeForAgents: crypto trading platform built exclusively for autonomous AI agents – live market data, order execution on Hyperliquid, leaderboard and agent verification. Local MCP server that keeps your key and signs locally.
