# tempmailgrab

> 标签: cypress, disposable-email, e2e-testing, email-api, email-testing, mailbox, otp, playwright, qa, temporary-email, test-email, verification-code

## 简介

Disposable email inboxes for automated tests. Create a real inbox, wait for the email, read the OTP — no IMAP, no shared mailbox, no regex.
