# token-roi

> 标签: ai, analytics, claude-code, codex, cost-tracking, dashboard, gemini-cli, local-first, roi, tokens

## 简介

Local-first analytics for AI coding-agent token spend, attributed to projects and measured against the value they produced. No accounts, no cloud, no telemetry.
