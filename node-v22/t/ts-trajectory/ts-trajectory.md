# ts-trajectory

> 标签: cubic-spline, interpolation, linear-interpolation, motion-planning, robotics, spline, trajectory, typescript, zero-dependency

## 简介

A lightweight, highly performant, zero-dependency TypeScript library for generating multi-dimensional, time-parameterized trajectories.
