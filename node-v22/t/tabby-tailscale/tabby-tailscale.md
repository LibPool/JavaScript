# tabby-tailscale

> 标签: ssh, tabby-plugin, tailscale

## 简介

Tabby Tailscale - lists Tailscale peers as SSH connection profiles in Tabby, grouped and filtered by regex rules on hostname/tags/online status, with configurable name labels
