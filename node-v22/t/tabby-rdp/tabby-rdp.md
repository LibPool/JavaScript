# tabby-rdp

> 标签: gnome, gnome-remote-desktop, ironrdp, rdp, remote-desktop, ssh, tabby, tabby-plugin, windows

## 简介

Remote desktops in Tabby's SSH tabs: Linux (GNOME) and Windows, through the SSH connection, with clipboard, files and sound. Built on IronRDP.
