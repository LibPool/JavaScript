# thinkingroot

> 标签: agents, ai, cli, database, memory, rag, thinkingroot

## 简介

ThinkingRoot CLI — `npx thinkingroot connect` wires ThinkingRoot MCP, hooks and the memory rules into every AI tool (Claude Code, Cursor, Antigravity, OpenClaw, Hermes, Codex, Windsurf) plus SDK/terminal. JSON-first for humans and agents.
