# telegram-agent-kit

> 标签: agent, agents, bot-api, deepagents, esm, html, langgraph, llm, markdown, streaming, telegram, telegram-bot

## 简介

Render markdown to Telegram, stream agent replies into live drafts, and drive a snapshot/rollback turn-loop — runtime-agnostic.
