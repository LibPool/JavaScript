# traclytics-js-sdk

> 标签: analytics, angular, employee-analytics, engagement-tracking, feature-tracking, framework-agnostic, hr-analytics, internal-tools, javascript, lightweight, privacy-focused, react, sdk, session-tracking, time-tracking, tracking, traclytics, traclytics-js-sdk, user-behavior, vanilla-js, vue

## 简介

Simple, privacy-focused analytics SDK for internal tools and applications. Track feature usage, measure engagement, and understand how your internal tools are being used—without the complexity of enterprise analytics platforms.
