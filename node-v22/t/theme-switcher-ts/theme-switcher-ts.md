# theme-switcher-ts

> 标签: angular, astro, dark-mode, dark-mode-toggle, framework-agnostic, light-mode, react, tailwindcss, theme-switcher, theme-toggle, typescript, vue

## 简介

A tiny, framework-agnostic dark/light theme switcher with 30 built-in animated toggle designs. Works with plain HTML/CSS, React, Vue, and Tailwind CSS.
