# tailwind-subshades

> 标签: colors, intermediate, plugin, subcolors, subshade, subshades, tailwind, tailwind-plugin, tailwindcss, tailwindv3, tailwindv4, tokens

## 简介

A plugin for Tailwind v3 and v4 for generating intermediate color steps for vanilla and custom Tailwind color tokens.
