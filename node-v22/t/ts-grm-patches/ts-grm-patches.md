# ts-grm-patches

> 标签: auto-increment, default-value, orm, patch, schema-migration, ts-grm

## 简介

Extension patches for ts-grm: adds column-level autoIncrement and default support so ts-grm binaries and ts-grm-migrate can emit the matching DDL
