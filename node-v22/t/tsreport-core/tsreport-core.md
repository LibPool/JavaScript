# tsreport-core

> 标签: barcode, font, invoice, layout, opentype, pdf, report, reporting, typescript, zero-dependency

## 简介

Pure TypeScript report engine: OpenType font parsing and shaping, band-based report layout, barcodes, SVG, and PDF rendering with embedded fonts - zero runtime dependencies
