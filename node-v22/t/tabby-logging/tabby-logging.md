# tabby-logging

> 标签: log, logging, recorder, session, ssh, tabby, tabby-plugin, terminal, timestamp

## 简介

Tabby SSH session log recorder: a Logging button next to Reconnect, timestamps every line into clean text files, customizable filename and directory
