# trpc-nuxt-module

> 标签: nitro, nuxt, nuxt-module, ssr, subscriptions, trpc, typescript, websocket

## 简介

tRPC for Nuxt — a Nuxt module that registers your router's HTTP and WebSocket handlers, fetches through the request event during SSR, and decorates the typed client with useQuery, useMutation and useSubscription over useAsyncData.
