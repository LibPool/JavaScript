# testid-scan

> 标签: accessibility, angular, cypress, data-testid, e2e, jsx, locators, playwright, react, testing, vue

## 简介

Static scanner for Angular templates, React components and Vue single-file components: shows which elements a UI test can find by role and accessible name, and which ones need a test ID.
