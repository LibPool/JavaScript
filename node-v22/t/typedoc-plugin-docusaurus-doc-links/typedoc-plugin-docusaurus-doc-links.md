# typedoc-plugin-docusaurus-doc-links

> 标签: documentation, docusaurus, markdown, typedoc, typedoc-plugin

## 简介

TypeDoc plugin that prefixes bare generated Markdown doc links so Docusaurus resolves them as local doc files.
