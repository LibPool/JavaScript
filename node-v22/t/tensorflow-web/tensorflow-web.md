# tensorflow-web

> 标签: browser, edge-ml, flatbuffers, int8, quantization, tensorflow, tensorflow-lite, tflite, tinyml

## 简介

Train a TensorFlow model in the browser tab and emit a verified .tflite. Headless, framework free, int8 quantization included.
