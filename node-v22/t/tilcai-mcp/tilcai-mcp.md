# tilcai-mcp

> 标签: avalanche, cctp, mcp, model-context-protocol, payments, stellar, usdc, x402

## 简介

MCP server: lets an EVM agent pay USDC to a Stellar address through tilcai-infrastructure (CCTP V2, Avalanche Fuji -> Stellar Testnet, or Avalanche C-Chain -> Stellar Public Network with TILCAI_NETWORK=mainnet)
