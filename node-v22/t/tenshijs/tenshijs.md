# tenshijs

> 标签: backend, express, framework, nodejs, typescript

## 简介

Tenshi is a NodeJS backend framework, this works with TypeScript  and ExpressJS.  Tenshi give us the possibillity to added easly the jwt security code, api key, role validation, regex, validation, required fields validation, logical deletions and others.
