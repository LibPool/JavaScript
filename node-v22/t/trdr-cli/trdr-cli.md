# trdr-cli

> 标签: cli, codemod, design-system, drift, shadcn, trdr

## 简介

CLI de manutencao do design system TRDR: doctor (drift de componentes ejetados), diff (contra o registry) e migrate (codemod de classes trdr-* legadas).
