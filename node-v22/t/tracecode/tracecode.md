# tracecode

> 标签: cli, code-graph, codebase-intelligence, developer-tools, git, git-blame, impact-analysis, local-first, why

## 简介

Understand your codebase before you change it. Local-first CLI that indexes git history and code structure to explain why code exists and what a change will break.
