# type-ai-sdk

> 标签: ai, assistant, blockchain, crypto, ethereum, sdk, solana, typeai

## 简介

A powerful TypeScript SDK for blockchain interactions and AI-powered conversational prompts. Supports Ethereum and Solana, enabling token management, transaction operations, and natural language queries with full TypeScript typings.
