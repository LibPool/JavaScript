# terminalis-mcp

> 标签: claude, cursor, mcp, model-context-protocol, terminal, terminalis

## 简介

MCP server exposing Terminalis terminals (profile name, directory, env, tags, and recent output) to Cursor, Claude, and other MCP clients.
