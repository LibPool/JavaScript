# typespun-codegen

> 标签: bun, cli, code-generation, codegen, config, configuration, dotenv, env, environment-variables, nodejs, type-safe, typed-config, typescript

## 简介

Generate a type-safe config loader from one TypeScript interface. Schema analyzer and CLI for environment variables, dotenv, and YAML defaults.
