# tiny-event-intercept

> 标签: browser, conditional-events, dom-events, edge-cases, event-handling, event-intercept, event-listener, frontend, javascript, lightweight, memory-safe, react, robust, ssr-compatible, typescript, vue, zero-dependencies

## 简介

Lightweight (~1.2KB gzip) TypeScript library for conditional event interception with browser-standard API. Zero dependencies, browser-first, SSR-safe.
