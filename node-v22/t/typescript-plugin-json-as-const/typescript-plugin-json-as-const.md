# typescript-plugin-json-as-const

> 标签: as-const, json, json-schema, json-schema-to-ts, language-service, typescript, typescript-plugin

## 简介

TypeScript language service plugin that types imported .json files as if they were `as const` literals (great with json-schema-to-ts)
