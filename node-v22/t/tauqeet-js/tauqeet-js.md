# tauqeet-js

> 标签: astronomical, ephemeris, high-precision, islam, islamic-prayer-times, javascript, nodejs, npm, prayer, prayer-times, qibla, typescript, vsop87

## 简介

High-precision TypeScript library for Islamic prayer times and Qibla direction in JavaScript and Node.js, powered by VSOP87 solar ephemeris and zero-dependency astronomy logic.
