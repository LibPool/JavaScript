# time-rest

> 标签: news, smile

## 简介

Данный проект создан для просмотра новостей или чтения развлекательного контента в терминале. Настройка и команды очень просты, что позволит отвлечься на минутное чтение прямо во время работы.\ This project created for rest duaring programming.
