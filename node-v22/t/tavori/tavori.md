# tavori

> 标签: agent, ai, ai-agent, autonomous, goal-driven, llm, motivation, multi-agent, orchestrator, satisficing, task-discovery, typescript

## 简介

AI agent orchestrator that gives existing agents the drive to persist — set a goal, and Tavori observes, delegates, verifies, and loops until done.
