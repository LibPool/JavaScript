# TrixCSS

> 标签: css, oocss, trix

## 简介

Trix 0.8 é um framework css para desenvolvedores front-end. Comecei a construção do Trix para agilizar meus trabalhos, no final decidi disponibilizar para comunidade. Fácil de ser usado, rápido e bem leve.
