# techdiagrams-mcp

> 标签: agent, ai, architecture, claude, claude-code, context, mcp, model-context-protocol, software-design, techdiagrams, tickets

## 简介

Gives a coding agent the architecture, contracts, schema and acceptance criteria behind a ticket — instead of letting it infer them from the code.
