# tokkit

> 标签: base62, binary-encoding, bit-packing, codec, compact, encoding, query-string, schema, serialization, state-sharing, token, url-safe, url-token, zero-dependency

## 简介

Encode JavaScript objects into compact, URL-safe tokens using schema-based bit packing and Base62 encoding
