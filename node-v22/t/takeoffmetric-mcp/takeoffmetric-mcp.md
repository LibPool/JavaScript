# takeoffmetric-mcp

> 标签: asphalt, calculator, claude, concrete, construction, duct, estimating, fence, gravel, mcp, model-context-protocol, rebar, roofing, takeoff

## 简介

MCP server for construction takeoff calculators: concrete, rebar, gravel, fill, sand, topsoil, asphalt, board feet, roofing, roof pitch, fence, duct and paver base, plus a searchable table of sourced estimating constants.
