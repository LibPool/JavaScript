# typescript-zestty-plugin

> 标签: JavaScript

## 简介

TypeScript Language Service plugin for ZesTTY (zts): remaps go-to-definition results that land in committed `zts-check --twins` output back to the sibling .zts source, via the twin's sourcemap (symbol search fallback). Same pattern as typescript-svelte-pl
