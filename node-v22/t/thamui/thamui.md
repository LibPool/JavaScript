# thamui

> 标签: JavaScript

## 简介

A terminal UI library for Node.js with web-style ergonomics. JSX components, CSS in real `.scss` files, flexbox layout via Yoga, focus / hover / active states with the corresponding pseudo-class selectors, mouse and keyboard input, and progressive cell-le
