# termux-codex-login

> 标签: android, codex, codex-cli, login, oauth, openai, proot, resolv.conf, termux, termux-open-url

## 简介

Make OpenAI Codex CLI's ChatGPT OAuth login work on Android/Termux: opens the auth URL via termux-open-url and fixes the token-exchange DNS failure with a proot resolv.conf shim.
