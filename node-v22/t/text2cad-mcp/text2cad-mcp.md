# text2cad-mcp

> 标签: ai, autocad, cad, catia, dxf, llm, mcp, step, stl, text2cad

## 简介

Natural-language driven CAD MCP server (2D/3D): generate part/assembly drawings and bridge to AutoCAD & CATIA. Auto-installs its Python backend into a managed virtualenv.
