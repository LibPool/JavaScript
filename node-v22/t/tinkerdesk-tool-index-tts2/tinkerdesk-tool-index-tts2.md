# tinkerdesk-tool-index-tts2

> 标签: index-tts2, tinkerdesk-tool, tts, voice, voice-clone

## 简介

TinkerDesk 外置工具：index_tts——调用本机 IndexTTS2（IndexTTS-2.5）生成克隆语音（Agent 自主调用、全参数：语速/情感/五语/文本归一化）。
