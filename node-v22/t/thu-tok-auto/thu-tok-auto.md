# thu-tok-auto

> 标签: auto-refresh, cordis-plugin, deepseek-harness, dsh, madmodel, thu, token, tsinghua

## 简介

Get / auto-refresh THU MadModel (madmodel.cs.tsinghua.edu.cn) API tokens and write them straight into the DSH model provider config (credential MADMODEL_API_KEY). Installs as a DSH profile bundle (Cordis plugin).
