# toolerance

> 标签: anthropic, bedrock, cli, convert, function-calling, gemini, json-schema, llm, openai, schema, tool, tools, vertex

## 简介

Convert one canonical tool/function schema to every provider dialect (OpenAI Chat + Responses, Anthropic, Gemini Developer + Vertex, AWS Bedrock) and get a report of exactly what each target cannot represent.
