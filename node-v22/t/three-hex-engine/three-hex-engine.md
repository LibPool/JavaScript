# three-hex-engine

> 标签: agents, ai-first, browser-game, game-dev, game-engine, gamepad, hexagonal, llm, multiplayer, plugins, ports-and-adapters, socket.io, threejs, web-audio

## 简介

AI-first game engine for the browser: hexagonal core (ports and adapters) + plugins. Fixed-step loop, three.js, keyboard/gamepad, Web Audio, grid physics, multiplayer rooms. Ships an AGENTS.md that teaches coding agents to build games with it.
