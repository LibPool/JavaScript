# tr-key-vault-client

> 标签: client, jose, jwe, jwk, jwt, key management, key-vault, vault

## 简介

Client library and command line client for the tr-key-vault key vault server. Server-side JWT/JWE operations with vault-held keys over a minimal JSON-over-POST API.
