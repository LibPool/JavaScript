# testrix-cli

> 标签: automation, ci, cli, junit, pest, playwright, report, test, vitest

## 简介

Parse test reports (JUnit, Playwright, TestNG, NUnit3, .trx, Mochawesome, CTRF, TAP, k6, JMeter, HTML, Excel) and publish the results to a Testrix dashboard API.
