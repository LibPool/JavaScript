# tokens-gone

> 标签: anthropic, claude, claude-code, cli, codex, dashboard, oh-my-pi, opencode, pi, tokens, usage

## 简介

Local dashboard for AI coding agent token usage and costs. Reads Claude Code, Codex, OpenCode, Pi, and Oh My Pi logs, aggregates spend, slices interactively.
