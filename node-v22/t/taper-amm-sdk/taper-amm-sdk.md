# taper-amm-sdk

> 标签: amm, dlmm, liquidity, solana, taper

## 简介

Client-side view of the taper-amm ABI: PDAs, instruction builders, account parsers, a swap quote, and an independent f64 ladder. Transport free — no RPC layer.
