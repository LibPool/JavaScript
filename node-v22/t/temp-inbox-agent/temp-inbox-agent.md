# temp-inbox-agent

> 标签: agent identity, agent tools, ai agent email, ai inbox, autonomous email, durable email identity, email verification, magic link, otp extraction, persistent inbox

## 简介

Durable email inboxes for AI agents. Persistent agent email identities for OTP codes, magic links, and verification emails. No signup. Zero dependencies.
