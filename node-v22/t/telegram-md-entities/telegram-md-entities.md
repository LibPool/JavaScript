# telegram-md-entities

> 标签: bot-api, entities, grammy, llm, markdown, message-entity, telegraf, telegram, telegram-bot

## 简介

Lenient markdown → Telegram Bot API { text, entities } renderer built for LLM output: no parse_mode, no escaping, no parse errors; entity-aware message splitting, streaming-friendly partial rendering, offline preview.
