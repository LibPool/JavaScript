# tiss-hash

> 标签: ans, brasil, epilogo, hash, healthcare, md5, padrao-tiss, saude-suplementar, tiss, xml

## 简介

Hash MD5 do epílogo XML TISS/ANS (Padrão TISS). Reverse-engineered, validado contra goldens reais privados + vetores sintéticos.
