# termcade

> 标签: 3d, ascii, half-block, renderer, software-rasterizer, terminal, truecolor, tui

## 简介

Software 3D renderer that draws to the terminal with truecolor half-blocks and shape-matched glyphs. Pure TypeScript, no GPU, no native deps.
