# tr-create

> 标签: AngularJS, HTML, JSON, angularjs-translate, dummy, translate

## 简介

Finds __text to be translated__ in a specified HTML file and creates en.json plus new HTML file with {{ 'nameSpace.textToBeTranslated' | translate }}.
