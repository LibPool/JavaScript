# teddy-orchestrator

## 简介

Teddy — your friendly AI engineering companion. Plans, develops, tests, validates and versions real code in sandbox/Docker, with anti-AI-scrap scanners, deterministic state machine, multi-agent collaboration, code graph, and Mermaid visualizations.
