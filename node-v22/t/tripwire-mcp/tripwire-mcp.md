# tripwire-mcp

> 标签: agent-security, ai-agents, ai-safety, guardrails, llm-security, mcp, mcp-gateway, mcp-proxy, mcp-security, mcp-server, model-context-protocol, prompt-injection, tool-use

## 简介

Security gateway for MCP agents: blocks prompt-injection-driven tool calls (poisoned payments, fabricated results) with cryptographic receipts, value-provenance enforcement, and multi-model consensus. The verification layer no syntactic MCP firewall has.
