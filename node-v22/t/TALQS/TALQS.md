# TALQS

> 标签: JavaScript

## 简介

TALQS 是一个专为爱贝壳题库试题渲染的插件。它可以快速地帮开发人员将爱贝壳题库的试题按照试题数据结构渲染出对应的 HTML 代码字符串。开发人员还可以通过自定义的配置轻松地实现试题结构呈现，而无需关心试题的题型。
