## 简介

Toolverse — 254 React components + 1,052 icons x 7 variants (line, solid, duotone, aurora, neon, glass, crystal3d). Real theme system, zero-dependency CLI (add - icons - theme - stats - doctor), tree-shakeable, TypeScript strict, MIT.
