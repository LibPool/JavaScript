# tiddlywiki-cpl

> 标签: cli, cpl, multiwikiserver, mws, plugin, plugin-library, tiddlywiki, tiddlywiki5

## 简介

CLI to search, install and batch-update plugins from the TiddlyWiki Community Plugin Library (CPL) for Node.js wikis, MultiWikiServer (MWS) and the MWS container image layout.
