# toolweave

> 标签: agents, code-mode, langgraph, llm, quickjs, sandbox, tools, tsgo, type-checking, typescript

## 简介

Typed code-mode tool orchestration for LLM agents: tools become TypeScript declarations, generated programs are type-checked (routeable checker backends), repaired via diagnostics, and executed in a QuickJS sandbox.
