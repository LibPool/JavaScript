# timetable-api-node

> 标签: api, gtfs, lviv, mcp, model-context-protocol, public-transport, timetable, transit, ukraine

## 简介

Lviv (Ukraine) public transport REST API and read-only Model Context Protocol (MCP) server: stops, timetables, routes, live vehicle positions, GTFS/GTFS-RT. No API key required.
