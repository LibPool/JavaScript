# tonofcov

> 标签: blockchain, coverage, func, lcov, smart-contracts, tolk, ton

## 简介

Source-line code coverage for TON smart contracts (FunC, Tolk planned). HTML report, conditional-throw branch coverage, agent-friendly gaps listing, and LCOV output for IDEs and CI.
