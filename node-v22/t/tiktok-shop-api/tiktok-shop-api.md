# tiktok-shop-api

> 标签: ecommerce, tiktok shop, tiktok shop api, tiktok shop oauth, tiktok shop openapi, tiktok shop partner api, tiktok shop sdk, tiktok shop webhooks, typescript, unofficial

## 简介

TypeScript client for the TikTok Shop API (TikTok Shop Partner API): request signing, OAuth, multi-shop support, typed webhooks and exact 64-bit IDs. Unofficial. Not affiliated with or endorsed by TikTok or ByteDance.
