# terminull

> 标签: claude-code, cli, codex, coding-agent, harness, panel, terminull, tui

## 简介

Terminull — a local, consent-shaped control panel for your CLI coding agents (Claude Code, Codex). `npx terminull setup` injects a fully reversible hook harness; `terminull eject` removes it byte-for-byte.
