# tree-sitter-flatbuffers

> 标签: fbs, flatbuffers, parser, syntax, tree-sitter, tree-sitter-grammar

## 简介

Tree-sitter grammar for FlatBuffers (.fbs) schema files. Syntax highlighting + incremental parsing for Neovim, Helix, Zed, and any editor with a tree-sitter consumer.
