# think-prompt

> 标签: anthropic, anti-pattern, claude, claude-code, cli, coaching, developer-tool, hooks, local-first, privacy, prompt, prompt-engineering

## 简介

Local-first prompt coach for Claude Code — collects your prompts via hooks, scores them with rules, and shows patterns in a private dashboard. No data leaves your machine.
