> 标签: ci, css, design-tokens, eslint, eslint-plugin, eslintplugin, ghost-classes, lint, static-analysis, tailwind, tailwindcss, theme, unused-classes

## 简介

Find Tailwind CSS classes that silently generate no CSS in your config (replaced theme scales, prefixes, dropped keys)
