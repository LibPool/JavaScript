# temporal-fmt-lite

> 标签: date, format, tc39, temporal, time

## 简介

Format Temporal.PlainDate/PlainDateTime/PlainTime/ZonedDateTime objects using date-fns-style token strings. Minimal, frozen API, no dependencies.
