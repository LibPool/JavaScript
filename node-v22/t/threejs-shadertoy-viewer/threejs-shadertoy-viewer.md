# threejs-shadertoy-viewer

> 标签: JavaScript

## 简介

A simple THREE.js template code that make use of [three-shadertoy-material](https://www.npmjs.com/package/three-shadertoy-material) to render on a mesh. You can edit the sourcecode or load shaders dynamically using shadertoy.com Api. Type the url of shade
