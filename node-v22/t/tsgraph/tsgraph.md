# tsgraph

> 标签: JavaScript

## 简介

tsGraph is a fork of mxGraph which aims to be compatible with TypeScript, mxGraph is a fully client side JavaScript diagramming library. It is the underlying technology that powers the drawing functionality that you see in https://www.draw.io.
