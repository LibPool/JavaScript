# turnspeedcl

> 标签: cf-bypass, cf_clearance, challenge, cloudflare, cookies, puppeteer-real-browser, scraping, turnstile

## 简介

Headful browser lib that solves Cloudflare Turnstile challenges via puppeteer-real-browser and hands back the CF clearance cookies (cf_clearance, __cf_bm, cf_chl_rc_*).
