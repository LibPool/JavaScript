# teamcore-tc4-lib-componentes-monorepo

> 标签: JavaScript

## 简介

Este es un monorepo para una librería de componentes de UI que soporta tanto React como Vue, compartiendo los mismos estilos base a través de Tailwind CSS. El proyecto utiliza Storybook para visualizar y desarrollar los componentes de forma aislada y Dock
