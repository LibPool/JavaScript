# theialang

> 标签: education, interactive, katex, latex, lecture, markdown, math, mathematics, presentation, slides, teaching, theia

## 简介

Compile a math-teaching markup language (.theia) into self-contained, interactive HTML slide decks — live sliders, reactive KaTeX, 2D/3D scenes.
