# tooltip-tour

> 标签: flying-tooltip, guide, interactive-guide, onboarding, step-by-step, tooltip, tour, user-guide, walkthrough, web-tour, website-tour

## 简介

A JavaScript library that guides users through a web page with a flying tooltip. The tooltip provides step-by-step information about each section of the page, moving smoothly to the next section for a seamless and informative user experience.
