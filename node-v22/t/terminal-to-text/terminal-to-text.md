# terminal-to-text

> 标签: agent, ansi, carriage-return, log, output, progress, pty, strip-ansi, terminal, truncate

## 简介

Render captured terminal output to the plain text a person would have seen: progress bars, spinners and redrawn screens collapse to their final state instead of thousands of intermediate frames.
