# timelens

> 标签: clappr, mediaelement, navigation, plugin, thumbnails, video, visual timeline

## 简介

Enhances web-based video players with a visual timeline and hover thumbnails, which make navigation more efficient, precise, and active. Comes with a general-purpose JavaScript library, and with plugins for various players.
