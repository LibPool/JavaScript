# thefactory-db

> 标签: database, docker, documents, embeddings, esm, fts, full-text-search, hybrid-search, pg, pgvector, postgres, postgresql, search, similarity-search, testcontainers, thefactory, tsvector, typescript, vector, vector-search

## 简介

Local-first PostgreSQL toolkit with hybrid text (tsvector) + vector (pgvector) search, Docker-managed ephemeral/persistent databases, and a TypeScript API for documents and entities.
