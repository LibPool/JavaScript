# @gsnowdrift/dsh-archive-manager

> 标签: archive, cleanup, deepseek-harness, dsh, dsh-plugin, plugin, session, settings

## 简介

归档会话管理插件：在 DSH 设置里按日期/工作区筛选已归档会话、批量取消归档，并提供可逆的自动清理策略（自动归档闲置会话 / 保留期还原 / 上限还原）。
