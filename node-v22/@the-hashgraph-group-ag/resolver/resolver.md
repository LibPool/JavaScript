# @the-hashgraph-group-ag/resolver

> 标签: JavaScript

## 简介

This package provides the `resolveDID` function, a core component of the Hashgraph DID SDK. It resolves Decentralized Identifiers (DIDs) registered on the Hedera network to their corresponding DID Documents.
