# @ling2/ling-cordis

> 标签: context, cordis, dependency-injection, event-bus, fiber, hmr, ioc, plugin, schema, schemastery, vite

## 简介

Standalone cordis runtime: contexts, plugin fibers, event bus, services, timer, schema validation (schemastery), and console logging — plus a /dev toolkit (module registry, vite HMR bridge, build orchestration).
