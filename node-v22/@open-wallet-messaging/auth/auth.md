# @open-wallet-messaging/auth

> 标签: 2fa, authentication, capability, ethereum, grant, oidc, open-wallet-messaging, owm, siwe, wallet

## 简介

Open Wallet Messaging auth: wallet-held second factor, sign-in, scoped capability grants and an OIDC bridge — a drop-in seam for TOTP-style verification
