# @juspay/kriya

> 标签: action-executor, ai-actions, ai-automation, automation, browser-automation, cjs, dom-manipulation, esm, form-automation, form-filling, juspay, kriya, typescript, web-automation, zero-dependency

## 简介

Pure automation execution engine for web actions — no AI, no UI. Execute action commands (click, fill, submit, navigate, capture) from any AI provider. TypeScript-first, browser + Node, dual CJS/ESM.
