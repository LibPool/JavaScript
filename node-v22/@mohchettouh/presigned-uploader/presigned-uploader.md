# @mohchettouh/presigned-uploader

> 标签: cloudinary, direct-upload, file-upload, multipart, presigned, react, s3, upload, vue

## 简介

Framework-agnostic orchestrator for presigned (direct-to-storage) multi-file uploads, with React and Vue bindings. Queue, sequential upload, progress, retry, cancel.
