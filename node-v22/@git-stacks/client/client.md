# @git-stacks/client

> 标签: JavaScript

## 简介

Carrier-neutral client state for git-stacks: encrypted-carrier contracts, framed authenticated sessions, RPC/event dispatch, browser WebTransport pinning, signal reduction, priority ordering, and shared presentation semantics. It is safe to use in browser
