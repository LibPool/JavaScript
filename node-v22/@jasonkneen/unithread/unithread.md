# @jasonkneen/unithread

> 标签: atomics, isomorphic, multithreading, pool, sharedarraybuffer, threads, web-worker, worker, worker_threads

## 简介

Isomorphic true-multithreading for JavaScript: one API over node:worker_threads and Web Workers. Function shipping, worker pools, RPC proxies, shared memory + Atomics.
