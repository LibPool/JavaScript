# @circuitwall/icloud-langchain

> 标签: agent, apple, caldav, calendar, icloud, imap, langchain, langgraph, mail, reminders, tool, tools, vtodo

## 简介

LangChain tools for iCloud Mail (IMAP) and iCloud Calendar / Reminders (CalDAV) — direct protocol calls, no MCP. Auth via Apple ID + app-specific password. Extracted from Jarela.
