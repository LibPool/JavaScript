# @quadcore-lib/settings-server

> 标签: JavaScript

## 简介

Configuración del panel/sitio como **key-value** (teléfono, correo, redes, envíos, etc.). Lectura **pública** de los valores marcados `isPublic`; lectura completa y escritura **admin**.
