# @quadcore-lib/admin-categories

> 标签: JavaScript

## 简介

Módulo de gestión de categorías para el panel administrativo, consume exclusivamente la API de `categories-server`. Mismo patrón que `admin-products`/`admin-orders`/`admin-users`/`admin-tickets`.
