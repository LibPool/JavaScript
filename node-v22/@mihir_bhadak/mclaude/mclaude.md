# @mihir_bhadak/mclaude

> 标签: ai, claude, claude-code, cli, mcp, remote, tool-proxy

## 简介

Install Claude Code once, use it everywhere. Thin client for mclaude-server: mirrors a remote Claude Code TUI while executing every tool locally.
