# @oge-ui/react-overlay

> 标签: accessibility, context-menu, design-system, dialog, dropdown, menu, modal, notification, popover, popup, positioning, react, toast, tooltip, typescript

## 简介

React overlay surfaces from the OGE UI suite: viewport-aware anchored popups (flip + clamp, RTL-aware, Escape stack), a full WAI-ARIA menu with submenus and type-ahead, accessible tooltips, a right-click context menu, a modal dialog with async close guard
