# @oge-ui/gantt

> 标签: angular, dependencies, excel-export, gantt, gantt-chart, pdf-export, project-management, signals, standalone-components, tasks, timeline

## 简介

Signal-based Angular Gantt chart: task tree pane + timeline chart with summary/milestone bars, FS/SS/FF/SF dependency arrows, drag/resize/progress editing with Escape-cancel and full keyboard access — the only Angular-native Gantt. Source-available commer
