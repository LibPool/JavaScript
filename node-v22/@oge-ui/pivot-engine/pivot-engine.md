# @oge-ui/pivot-engine

> 标签: analytics, headless, olap, pivot, pivot-grid, pivot-table, typescript

## 简介

Framework-free pivot grid engine behind @oge-ui/pivot (Angular) and @oge-ui/react-pivot (React): field layout model, axis and header layout math, two-axis virtualization windows, the remote-store adapter, header and measure menus, value filters, the field
