# @oge-ui/react-forms

> 标签: accessibility, form-layout, forms, react, typescript, validation

## 简介

React form layout from the OGE UI suite: responsive column layout, groups, tabbed/accordion/wizard sections, declarative validation rules and a validation summary — running the same item model and the same rule evaluator as the Angular forms package.
