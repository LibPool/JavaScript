# @oge-ui/react-scheduler

> 标签: accessibility, agenda, appointments, calendar, event-calendar, react, recurrence, scheduler, timeline, typescript

## 简介

React scheduler / event calendar from the OGE UI suite: day, work-week, week, month, agenda, timeline and year views, all-day strip, pure-kernel overlap layout, drag & resize with Escape-cancel, drag-to-create, recurrence with occurrence-vs-series editing
