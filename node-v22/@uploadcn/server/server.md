# @uploadcn/server

> 标签: clamav, multipart, nextjs, ocr, presigned, r2, s3, tanstack-start, upload, virus-scan

## 简介

Framework-agnostic upload route for UploadCN: presigned S3/R2 uploads, multipart signing, local-disk storage, Cloudinary signing, virus scanning and OCR, using Web standard Request/Response.
