# pi-keepwarm

> 标签: anthropic, claude, openai, pi, pi-extension, pi-package, prompt-caching

## 简介

Pi extension: manually keep a long session's prompt cache warm while you're idle, so the next message after a long break doesn't pay a full cache rewrite.
