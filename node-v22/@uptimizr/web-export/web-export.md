# @uptimizr/web-export

> 标签: 3d, analytics, godot, heatmap, privacy, unity, unreal, uptimizr, webassembly, webgl

## 简介

Shared foundation for Uptimizr web-export engine connectors (Unity, Godot, Unreal): the versioned JS bridge contract, a zero-engine-code JS-only capture tier, and native-frame normalization.
