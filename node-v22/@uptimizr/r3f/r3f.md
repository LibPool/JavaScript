# @uptimizr/r3f

> 标签: 3d, analytics, heatmap, privacy, r3f, react, react-three-fiber, three, threejs, uptimizr

## 简介

react-three-fiber connector for Uptimizr — a thin React layer over @uptimizr/three that wires capture into the R3F render store.
