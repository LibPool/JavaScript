# @utdk/vcs

> 标签: code-review, git, pull-request, utdk, vcs

## 简介

Shared Git-hosting contract for UTDK VCS providers: one repos/pullRequests/branches/files surface over any hosting vendor, normalized PR and review shapes, and unified-diff reads sized for a code-review workflow
