# dsh-plugin-headless-sessions-panel

> 标签: deepseek-harness, dsh, dsh-bundle, dsh-plugin, forensics, headless, panel, sessions

## 简介

Sidebar headless-sessions panel for DSH: lists running/recent headless sessions and exports each as readable Markdown, with open-into-workspace actions.
