# pi-multi-accounts

> 标签: anthropic, chatgpt, claude, codex, multi-account, oauth, openai, pi, pi-package

## 简介

Pi extension: switch between several Claude Pro/Max OAuth logins with /account, and use extra ChatGPT (Codex) logins as parallel openai-codex-<name> providers
