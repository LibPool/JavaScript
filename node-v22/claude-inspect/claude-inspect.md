# claude-inspect

> 标签: agent-observability, ai-agents, ai-tools, anthropic, claude, claude-code, claude-code-tools, cli, dashboard, developer-tools, llm, local-first, monitoring, observability, subagents, svelte, token-usage, transcripts, typescript, usage

## 简介

Claude Code dashboard & monitor: live sessions, subagents, spawned claude workers, tool calls, timelines, CPU and token usage and transcript history – read passively from ~/.claude, no hooks.
