# @ultrasa/browser-utilities

> 标签: browser, cache, clipboard, download, localStorage, utilities

## 简介

Small TypeScript utilities for browser apps: clipboard, JSON downloads, duration formatting, localStorage preferences, a temporary cache, and stage configuration lookup.
