# @ishizakahiroshi/vite-plugin-git-version

> 标签: app-version, git, git-describe, release, version, vite, vite-plugin

## 简介

Resolve app version from git tags (git describe --tags --match v*) and inject it into Vite builds as __APP_VERSION__.
