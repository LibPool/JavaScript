# @proteles/react

> 标签: authentication, nextjs, oauth2, oidc, proteles, react

## 简介

Drop-in React components and hooks (SignInButton, UserButton, SignedIn/SignedOut, useUser, Protect) for the Proteles identity platform. Talks to the @proteles/next BFF, never to the authorization server directly.
