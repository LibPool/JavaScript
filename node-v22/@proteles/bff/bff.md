# @proteles/bff

> 标签: authentication, bff, oauth2, oidc, proteles

## 简介

Framework-agnostic Backend-for-Frontend core for Proteles: encrypted httpOnly session cookies and the login/callback/logout/me flow over Web Request/Response. Used by @proteles/next and @proteles/svelte.
