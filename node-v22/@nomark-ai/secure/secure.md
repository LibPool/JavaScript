# @nomark-ai/secure

> 标签: JavaScript

## 简介

NOMARK Secure — the NOMARK security plane. Injection classification, secrets egress redaction, tool-call policy, and hook adapters for the Claude Code harness, plus a standalone zero-harness CLI (init|scan|redact|policy|doctor).
