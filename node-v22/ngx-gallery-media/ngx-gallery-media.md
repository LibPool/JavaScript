# ngx-gallery-media

> 标签: angular, carousel, gallery, image-gallery, lightbox, signals, standalone, thumbnails, video-gallery, zoom

## 简介

Angular picture and video gallery with thumbnails and a full-window preview: the options of ngx-gallery plus videos, signed URLs, translations and theming through CSS variables.
