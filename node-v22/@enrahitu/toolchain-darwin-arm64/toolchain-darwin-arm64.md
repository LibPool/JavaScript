# @enrahitu/toolchain-darwin-arm64

> 标签: JavaScript

## 简介

EnRaHiTu toolchain native binaries for macOS arm64: encore-runtime.node + tsparser-encore (encoredev/encore v1.57.9, MPL-2.0). Installed as an optional dependency of @enrahitu/toolchain on matching hosts.
