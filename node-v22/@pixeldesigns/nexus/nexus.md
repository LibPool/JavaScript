# @pixeldesigns/nexus

> 标签: agent, ai, anthropic, claude, claude-code, csv, cursor, data, local-first, mcp, model-context-protocol, spreadsheet, sqlite, xlsx

## 简介

Local-first agent layer for tabular data. Drop any CSV, XLSX, or SQLite file — get a local MCP server your AI agent can query without your data ever leaving your machine.
