# @npm-liqingfeng/dsh-theme-center

> 标签: JavaScript

## 简介

DSH web UI 主题插件（一体化）：设置 > 插件配置「主题」卡片双 Tab——「主题」23 款皮肤试穿 / 应用、亮暗预览与背景遮罩；「外观」聊天宽度预设、聊天区精简、会话区字号、全站字体、隐藏开关。配置保存在服务器设置中，一处配置、所有终端生效（localStorage 为首屏缓存）。
