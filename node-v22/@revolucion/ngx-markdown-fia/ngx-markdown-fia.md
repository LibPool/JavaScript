# @revolucion/ngx-markdown-fia

> 标签: angular, emoji, katex, markdown, marked, marked.js, ngx, parser, prism, prism.js

## 简介

Angular library that uses marked to parse markdown to html combined with Prism.js for synthax highlights. Forked from ngx-markdown.
