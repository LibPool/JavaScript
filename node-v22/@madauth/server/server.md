# @madauth/server

> 标签: auth, authentication, aws-lambda, azure-functions, dynamodb, google-sign-in, hono, jwt, login, session, sign-in

## 简介

madAuth server: Google, e-mail & password and authenticator-app sign-in with madAuth sessions, for Docker, AWS Lambda and Azure Functions.
