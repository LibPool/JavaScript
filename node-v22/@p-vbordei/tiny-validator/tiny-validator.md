# @p-vbordei/tiny-validator

> 标签: schema, typescript, validation, validator, zod

## 简介

A tiny Zod-like schema validator with TypeScript inference. Chainable builders, refine/transform, helpful error paths. Zero dependencies, ~250 LoC.
