# @p-vbordei/token-bucket

> 标签: leaky-bucket, rate-limit, throttle, token-bucket

## 简介

Token-bucket rate limiter with continuous refill, async waiting, and a keyed registry (per-IP, per-user, ...). Zero dependencies.
