# @mirrormedia/lilith-draft-renderer

> 标签: draft.js, react, readr

## 简介

本套件是由 `@mirrormedia/lilith-draft-editor` 將其 maintain 的 buttons 對應的 block renderers 和 entity decorators 的邏輯 decouple， 以應用在 Next.js 專案以及 CMS 上。
