# @traceroot-ai/pi-extension

> 标签: llm, observability, opentelemetry, pi, pi-package, traceroot, tracing

## 简介

Traceroot extension for pi. Automatic OpenTelemetry tracing of pi sessions, turns, LLM calls, and tool executions to Traceroot.
