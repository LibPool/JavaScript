# @homeant/asvc

> 标签: agent, claude-code, cli, daemon, dev-server, process-manager

## 简介

统一管理本地开发服务的守护进程 + CLI，让人和 agent 通过同一套 asvc 命令启动/重启/关闭服务，避免端口冲突与重复启动。

- 源码仓库：git+https://github.com/homeant/agent-server-manager.git
