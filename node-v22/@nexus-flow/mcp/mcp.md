# @nexus-flow/mcp

> 标签: mcp, model-context-protocol, nexus-flow, nxs

## 简介

Runner shim: fetch, verify (sha256 + minisign), cache, and exec the signed nxs binary as an MCP server for hosts where nxs is not installed.
