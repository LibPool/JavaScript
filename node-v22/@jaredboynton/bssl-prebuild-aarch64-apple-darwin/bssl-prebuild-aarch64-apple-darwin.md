# @jaredboynton/bssl-prebuild-aarch64-apple-darwin

> 标签: JavaScript

## 简介

Prebuilt BoringSSL static libs + headers for aarch64-apple-darwin. Set BORING_BSSL_PATH and BORING_BSSL_INCLUDE_PATH at the package's lib/ and include/ to skip CMake on every boring-sys build.
