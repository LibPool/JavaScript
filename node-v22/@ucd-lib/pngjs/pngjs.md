# @ucd-lib/pngjs

> 标签: PNG, decoder, encoder, js-png, node-png, parser, png, png-js, png-parse, pngjs

## 简介

PNG encoder/decoder in pure JS, supporting any bit size & interlace, async & sync with full test suite.
