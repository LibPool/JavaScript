# @miasaki/dsh-sidebar

> 标签: JavaScript

## 简介

官方右栏的「审查」与「辅助对话」两个 tab；外加底部内嵌多标签终端（Ctrl+`）与系统终端启动器。不安装任何重型侧边栏基座，全部自研。
