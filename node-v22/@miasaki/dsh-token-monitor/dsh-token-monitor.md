# @miasaki/dsh-token-monitor

> 标签: JavaScript

## 简介

Token 用量监控：会话「用量」Tab（纯当前会话视角：上下文剩余 + 官方聚合 + 按会话过滤的实时明细 + 活跃时长）+ 侧栏脚部「用量统计」入口 → 全局浮窗（跨会话总览 / 年热力图 / 趋势 / 模型用量 + 会话活跃分布（标题与工作目录折叠自会话日志，含近 30 日逐日分布条）/ 今日限额）。账本按 profile 分区：官方桌面端只记载官方消耗，不与自制壳 / 浏览器 GUI 混账。
