# @thanh-libs/theme

> 标签: JavaScript

## 简介

A design-system theme library built on [Emotion](https://emotion.sh), providing a complete theming solution with **light/dark presets**, **global CSS reset**, **color palette**, **typography**, **spacing**, and **shadows**.
