# @atlasauth/pca-verified-core

> 标签: agent authorization, attenuation, capability, dafny, formal verification, pca, proof-carrying authority, replay protection, threshold

## 简介

The decision logic of the PCA verifier (capability-chain walk and attenuation, threshold distinct-role count, replay guard, check/verdict combinator, suite and PQ-pin binding rules), written and machine-proved in Dafny and compiled to JavaScript.
