# @atlasauth/pca-acp

> 标签: agent authorization, agentic commerce, ai agents, http 402, payments, pca, proof-carrying authority, x402

## 简介

Agentic Commerce (ACP) + x402 adapter for PCA: mint an ACP delegated one-time payment token (bound to session+merchant+amount+expiry) AS a PCA proof, and an x402/HTTP-402 facilitator hook that gates settlement on a verified PCActn.
