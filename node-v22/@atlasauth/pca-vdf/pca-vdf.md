# @atlasauth/pca-vdf

> 标签: agent authorization, ai agents, cooling-off, pca, proof-carrying authority, timelock, verifiable delay function

## 简介

Verifiable Delay Function timelock for PCA: a mandatory, offline-verifiable cooling-off on irreversible actions — a VDF proof that T sequential steps elapsed gates execution, with no trusted clock. Wesolowski-style proof (cheap verify).
