# @atlasauth/pca-gateway

> 标签: agent authorization, ai agents, api gateway, envoy, ext_authz, pca, proof-carrying authority, service mesh

## 简介

Drop-in PCA enforcement for API gateways/service meshes: a framework-agnostic ext_authz handler that verifies a proof-carrying action per request (Envoy HTTP ext_authz, Cloudflare Worker, Lambda authorizer) so unmodified services get code-free proof enfor
