# @atlasauth/pca-oprf

> 标签: agent authorization, ai agents, oprf, pca, private revocation, proof-carrying authority, psi, rate limiting, rfc 9497

## 简介

OPRF (RFC 9497) + PSI for PCA: private rate-limiting and private revocation checks without revealing which capability or identifier.
