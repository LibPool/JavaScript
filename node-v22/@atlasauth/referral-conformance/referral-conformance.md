# @atlasauth/referral-conformance

> 标签: atlas, atlasauth, conformance, referalli, referral, webhook

## 简介

Conformance suite for the Atlas referral protocol (the Referalli connection API): recorded signed calls with the answers a server must give, a runner, and recorded inbound events. Run it against your own referral platform in CI.
