# @atlasauth/pca-payments

> 标签: agent authorization, ai agents, mandates, payments, pca, proof-carrying authority, prototype, spending limits

## 简介

Payment-mandate reference for Proof-Carrying Authority: merchant/category allowlists, per-transaction and cumulative caps, auto-approve threshold, hard ceiling and bonded refunds expressed as PCA capabilities. Experimental prototype.
