# @atlasauth/pca-mpc-wasm

> 标签: agent authorization, ai agents, constant-time, curve25519, oblivious transfer, pca, proof-carrying authority, wasm, webassembly

## 简介

Constant-time Ed25519 base-OT curve core (curve25519-dalek, compiled to WebAssembly): a drop-in, genuinely constant-time replacement for @atlasauth/pca-mpc's pure-BigInt ec.ts curve ops.
