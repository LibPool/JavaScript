# @atlasauth/pca-ciba

> 标签: agent authorization, ai agents, backchannel, ciba, human approval, pca, proof-carrying authority, step-up

## 简介

CIBA (Client-Initiated Backchannel Authentication) bridge for PCA FROST step-up: turn a step-up request into a backchannel human-approval flow with risk-adaptive gating.
