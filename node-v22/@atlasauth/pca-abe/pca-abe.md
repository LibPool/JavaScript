# @atlasauth/pca-abe

> 标签: agent authorization, ai agents, attribute-based encryption, bls12-381, pca, policy encryption, proof-carrying authority

## 简介

Proof-carrying encryption for PCA: attribute/policy-based encryption on BLS12-381 so a tool payload decrypts only for a holder whose capability satisfies the policy — binding confidentiality to proven authority.
