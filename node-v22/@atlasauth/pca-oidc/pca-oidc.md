# @atlasauth/pca-oidc

> 标签: agent authorization, ai agents, id token, jwks, oidc, openid connect, pca, proof-carrying authority

## 简介

Root a PCA grant in a real OIDC-authenticated human: verify an ID token (discovery + JWKS) and map its subject/claims to the PCA principal.
