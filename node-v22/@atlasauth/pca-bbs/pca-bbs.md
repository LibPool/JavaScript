# @atlasauth/pca-bbs

> 标签: agent authorization, ai agents, bbs signatures, credentials, pca, proof-carrying authority, selective disclosure, zero-knowledge

## 简介

BBS signatures (CFRG draft) for PCA: issue a capability as a multi-message BBS credential, then present it with selective disclosure + unlinkable zero-knowledge proof-of-possession, so an agent reveals only the attributes a tool needs and uses can't be co
