# @atlasauth/pca-fndsa-wasm

> 标签: agent authorization, ai agents, falcon, fips 206, fn-dsa, pca, post-quantum signatures, proof-carrying authority, wasm, webassembly

## 简介

FN-DSA (Falcon, FIPS 206) signature backend for @atlasauth/pca: FN-DSA-512 / FN-DSA-1024 keygen, signing and verification from the vetted pure-Rust fn-dsa crate family (Thomas Pornin) compiled to WebAssembly. Verification is the PCA verifier's public-key
