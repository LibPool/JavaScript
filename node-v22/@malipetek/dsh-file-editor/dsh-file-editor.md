# @malipetek/dsh-file-editor

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, editor, files, workspace

## 简介

Workspace files, editable: a right-Sidebar tree with new file, new folder, rename and delete, and a text editor that opens, edits and saves through the session's own filesystem and sandbox policy.
