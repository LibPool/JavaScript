# @malipetek/dsh-action-cards

> 标签: approvals, cordis, deepseek-harness, dsh, dsh-plugin, tooling

## 简介

Action cards: the agent proposes a concrete action (create a file, edit a value, run a command), you edit it and apply it in one click, and the Host executes it and reports back.
