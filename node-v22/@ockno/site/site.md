# @ockno/site

> 标签: ci, github-action, landing-page, lead-form, ockno

## 简介

Ockno's site contract: the CI check for repo-backed sites (forms, page identity, the script tag, renderer rules) and typed React helpers for forms, booking and hosted embeds.
