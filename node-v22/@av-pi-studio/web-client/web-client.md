# @av-pi-studio/web-client

> 标签: JavaScript

## 简介

The production React/Vite browser UI for Pi-Studio — connects to a daemon over WebSocket (`@av-pi-studio/client`) and renders chat sessions, agent-stream timelines, tool calls, terminals, a file/diff viewer, and git status. Ships as a prebuilt static SPA
