# @av-pi-studio/relay

> 标签: JavaScript

## 简介

End-to-end encrypted relay for Pi-Studio. Lets a client reach a daemon that's behind a firewall/NAT — the daemon dials **outbound** to a relay server, the client connects to the same relay, and all application traffic between them is E2EE (Curve25519 ECDH
