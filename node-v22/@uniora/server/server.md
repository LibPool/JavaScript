# @uniora/server

> 标签: api, authorization, multi-tenant, server, uniora

## 简介

UNIORA as its own self-hosted HTTP service: an authenticated, bounded, documented API over @uniora/core. Your backend calls it with an API key; your auth provider stays where it is.
