# @isdk/match-ex-schema

> 标签: ajv, isdk, json-schema, match-ex, plugin, validate

## 简介

Ajv-backed JSON Schema plugin for @isdk/match-ex. Importing it registers AjvSchemaType as the engine's schema implementation, so JSON Schema expectations validate out of the box.
