# @isdk/proxy

> 标签: cacache, cache, framework-agnostic, hybrid-cache, lru, middleware, proxy, request-collapsing, stale-while-revalidate, swr

## 简介

A framework-agnostic, high-performance hybrid caching middleware with SWR, request collapsing, and stale-if-error support.
