# @isdk/match-ex

> 标签: assert, diff, expect, isdk, json-schema, match, match-ex, operators, scoring, validate, validation

## 简介

A declarative, weight-aware matching/validation engine: match actual values against an expectation tree using operators ($and, $or, $contains, $each, ...), JSON Schema, diffs and templates. Framework-agnostic -- usable in plain fixture-driven integration
