# @iswangh/eslint-config

> 标签: @antfu/eslint-config, eslint, eslint-config

## 简介

基于 @antfu/eslint-config 的 ESLint 扁平配置，添加了自定义规则（TypeScript 命名约定、Vue TypeScript 强制、未使用导入检测等），支持 JavaScript 和 TypeScript 配置文件
