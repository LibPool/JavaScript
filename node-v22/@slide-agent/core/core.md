# @slide-agent/core

> 标签: agent-skill, ai-agent, charts, design, mcp, ooxml, powerpoint, pptx, presentations, slides, typography

## 简介

Model-directed PowerPoint: you decide the design, the engine solves geometry, fits text, verifies contrast, and writes native .pptx. Agent skill, MCP server, CLI, and TypeScript toolkit.
