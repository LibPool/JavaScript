# @almadar/auth

> 标签: almadar, auth, firebase, identity, oidc

## 简介

App-user identity for Almadar apps: token verification (Firebase / Identity Platform, generic OIDC), verified user to @user resolution, dev personas as emulated users, and the one OIDC client.
