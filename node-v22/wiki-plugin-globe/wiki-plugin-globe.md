# wiki-plugin-globe

> 标签: federated-wiki, fedwiki, geojson, globe, map, wiki-plugin

## 简介

Federated Wiki plugin — draws a globe.gl globe from the pins in Map items, GeoJSON files and pins typed into the item, and offers them back as markerData so a Map item can freeze them
