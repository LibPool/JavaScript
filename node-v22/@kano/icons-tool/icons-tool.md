# @kano/icons-tool

> 标签: JavaScript

## 简介

Generates svg icon sheet from a collection of svg files. Icons are optinized using https://github.com/svg/svgo. The default formatter exports a SVG icon sheet ready to be used with `@kano/icons-rendering`
