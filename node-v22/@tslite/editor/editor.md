# @tslite/editor

> 标签: diagnostics, editor, lsp, monaco, quickfix, typescript, vscode

## 简介

TSLite editor integration — turns parse/type diagnostics into Monaco markers or LSP/VSCode diagnostics, with rich hovers and quick-fixes from @tslite/explain. No editor dependency.
