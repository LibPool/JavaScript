# @youneed/server-plugin-grpc

> 标签: JavaScript

## 简介

@youneed/server plugin: run a gRPC (HTTP/2) server alongside your @youneed/server app on its lifecycle, with introspection + a unary call-tester over HTTP and a devtools tab.
