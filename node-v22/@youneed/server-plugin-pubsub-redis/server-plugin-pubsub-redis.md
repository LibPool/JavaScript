# @youneed/server-plugin-pubsub-redis

> 标签: JavaScript

## 简介

Redis/Valkey adapter — RedisKV (@youneed/server-plugin-store) + RedisPubSub (@youneed/server-plugin-pubsub) over a hand-rolled minimal RESP2 client (zero external deps).
