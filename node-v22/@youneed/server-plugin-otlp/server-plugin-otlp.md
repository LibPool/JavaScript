# @youneed/server-plugin-otlp

> 标签: JavaScript

## 简介

@youneed/server plugin: export per-request traces over OTLP/HTTP (JSON) to an OpenTelemetry collector / Jaeger / Tempo — no OTel SDK — with a devtools tab.
