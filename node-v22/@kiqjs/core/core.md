# @kiqjs/core

> 标签: container, decorator, dependency-injection, di, ioc, spring, typescript

## 简介

Core dependency injection container for Node.js/TypeScript, inspired by Spring. Provides @Service, @Configuration, @Bean, @Value, @PostConstruct, autowiring by type, qualifiers, and lifecycle scopes.
