# timecode-tools

> 标签: audio, companion, decoder, linear-timecode, ltc, midi, midi-timecode, mtc, show-control, smpte, timecode

## 简介

SMPTE LTC and MIDI Time Code (MTC) readers for Node.js: stream in PCM or MIDI bytes, get timecode, lock, loss and jump events. Rust core, prebuilt binaries.
