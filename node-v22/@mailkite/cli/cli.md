# @mailkite/cli

> 标签: cli, dns, email, mailkite, transactional, webhook

## 简介

MailKite command-line client — sign in, add domains, set DNS + webhooks, send mail, and tail inbound messages from your terminal. Built on the MailKite Node SDK.
