# @totalaudiopromo/tap-cli

> 标签: campaigns, cli, contacts, music, pr, radio, total-audio

## 简介

Terminal interface for Total Audio Platform — manage campaigns, contacts, pitches, and workspace skills from the terminal. Uses REST v1 with workspace-scoped tap_ak_* keys.
