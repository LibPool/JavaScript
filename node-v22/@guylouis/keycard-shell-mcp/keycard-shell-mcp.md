# @guylouis/keycard-shell-mcp

> 标签: agent, eip712, ethereum, hardware-wallet, keycard, keycard-shell, mcp, signing, usb-hid

## 简介

MCP server that makes a Keycard Shell the signer for your AI agent. The agent proposes transactions; only the device, and the person holding it, can sign them.
