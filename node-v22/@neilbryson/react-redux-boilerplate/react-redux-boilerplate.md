# @neilbryson/react-redux-boilerplate

> 标签: boilerplate, react, react boilerplate, redux, routing, styled components

## 简介

Boilerplate for React applications with CSS-in-JS, routing, linting, and testing.  Extends [Create React App](https://github.com/facebook/create-react-app).
