# @iivgll4/lema

> 标签: agent, cli, coding-agent, llm, lm-studio, local, ollama, self-improving, skills

## 简介

Agentic CLI for local LLMs (LM Studio, Ollama, llama.cpp). Real agent loop, web search, skill memory, auto-compaction, MCP server. Optimized for small models (4-14B).
