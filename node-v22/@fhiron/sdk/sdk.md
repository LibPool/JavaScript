## 简介

Fhiron SDK — embebe validación FHIR® contra CL Core v1.9.3 en tu app. Mismo motor que @fhiron/mcp-connector y @fhiron/cli. Cliente tipado, errores en español, zero dependencies. Node 18+, ESM y CommonJS.
