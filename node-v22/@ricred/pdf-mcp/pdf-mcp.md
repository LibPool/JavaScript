# @ricred/pdf-mcp

> 标签: ai, llm, mcp, model-context-protocol, pdf, pdf-to-text, pdfjs, text-extraction

## 简介

Fast, token-lean MCP server exposing pdf_to_text: extract clean plain text from PDFs with page targeting, byte caps, and caching. Built for LLMs.
