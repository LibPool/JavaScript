# @oribos/background-tasks

> 标签: agent-framework, ai-agents, background-tasks, leases, llm, task-execution, typescript

## 简介

Oribos background-tasks capability package — application-owned background work as task rows: submit → lease → in-process execution → heartbeat → settle, with adopt() re-running orphans and untilIdle() as a package-level wait. In-memory store and lease def
