# @oribos/supervisor

> 标签: ai-agents, delegation, llm, multi-agent, supervisor, typescript

## 简介

Oribos supervisor capability package — createSupervisor composes sub-agents as delegation tools on one parent agent (the standardized as-tool composition), no dependencies beyond the @oribos/core peer.
