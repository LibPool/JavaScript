# @navetacandra/ddg-ai

> 标签: ai, api, browser, chat, completion, ddg, duckduckgo, javascript, llm, node, streaming, typescript, unofficial

## 简介

A powerful and unofficial Node.js and browser library for interacting with DuckDuckGo's AI chat features, enabling text generation, model retrieval, and real-time streaming of AI responses.
