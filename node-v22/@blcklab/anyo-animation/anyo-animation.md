# @blcklab/anyo-animation

> 标签: 3d, animation, anyo, glb, gltf, sekai64, spatial-web, state-machine

## 简介

Optional renderer-neutral animation runtime for Anyo with parameters, state machines, events, root motion, authoring contracts, and an explicit Sekai64 adapter.
