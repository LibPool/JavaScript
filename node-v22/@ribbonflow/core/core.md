# @ribbonflow/core

> 标签: JavaScript

## 简介

Pure, headless heart of ribbonflow — simulation engine, curve/width/glyph geometry, the scene model (buildFlowScene/agentsView), and the flow format layer (serialize/deserialize/migrate/model/flow-set). No DOM, no framework.
