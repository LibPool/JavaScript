# n8n-nodes-feishu-suite

> 标签: feishu, lark, larksuite, n8n, n8n-community-node-package, n8n-node, 飞书

## 简介

Full-featured Feishu/Lark community nodes for n8n, including messages, bitable, docs, approval, tasks, mail, minutes, VC, search and attendance.
