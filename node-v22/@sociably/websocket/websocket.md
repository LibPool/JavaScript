# @sociably/websocket

> 标签: JavaScript

## 简介

This package is an underlying module of webview platform for serving WebSocket. You might want to use [`@sociably/webview`](https://github.com/machinat/sociably/tree/master/packages/webview) unless you want to serve your own web service.
