# simplified-mojang-jsons

> 标签: addon, api, bedrock, events, minecraft, mojang, scripting, wrapper

## 简介

An API in TypeScript for creating and managing the JSON configuration of vanilla and custom Minecraft Bedrock entities using type system support, OOP, and a more organized and reusable structure.
