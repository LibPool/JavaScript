# @geophrase/core

> 标签: address, address-autocomplete, address-picker, address-verification, checkout, delivery-address, ecommerce, geocoding, india, javascript, logistics, pincode, rto, sdk, vanilla-js, widget

## 简介

Drop-in address picker widget for Indian e-commerce checkouts. Captures structured addresses with coordinates to reduce RTO.
