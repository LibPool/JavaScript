# @geophrase/react

> 标签: address, address-autocomplete, address-picker, address-verification, checkout, delivery-address, ecommerce, hooks, india, nextjs, pincode, react, react-hook, rto, sdk, widget

## 简介

React & Next.js hook for the Geophrase address picker. Drop-in widget that captures structured Indian addresses with coordinates to reduce RTO.
