# @timonwa/firebase-hooks

> 标签: authentication, cloud-functions, firebase, firebase-auth, firebase-storage, firestore, hooks, oauth, react, react-hooks, typescript

## 简介

Typed React hooks for Firebase — one hook per flow, with its state, errors, and callbacks handled. Every action returns a result you can branch on, and each service is its own import, so an app only carries what it uses.
