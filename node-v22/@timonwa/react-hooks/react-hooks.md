# @timonwa/react-hooks

> 标签: dark-mode, hooks, media-query, react, theme, typescript

## 简介

Typed React hooks for the DOM problems every app hits — theme, media queries, countdowns, object URLs, click-outside, visibility, page titles. Client-side by design, no framework assumptions.
