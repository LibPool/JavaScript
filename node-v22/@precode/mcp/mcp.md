# @precode/mcp

> 标签: ai-agents, mcp, model-context-protocol, precode, spec-driven-development, verification

## 简介

PreCode MCP on npm — agent-agnostic build loop for any spec format, optimized for PreCode docs. Phased build → recheck → fix with hard definition-of-done gates and an implemented-vs-todo ledger.
