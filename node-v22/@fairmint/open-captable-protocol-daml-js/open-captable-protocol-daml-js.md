# @fairmint/open-captable-protocol-daml-js

> 标签: blockchain, daml, fairmint, opencaptable, smart-contracts

## 简介

Open CapTable Protocol (OpenCapTable-v35, with OpenCapTableApi-v01) DAML contracts with generated JavaScript bindings. Other Fairmint DAML packages live in @fairmint/daml-js.
