# @yashau/prick-mcp

> 标签: ai, cloudflare, mcp, modelcontextprotocol, secrets, secrets-manager

## 简介

Model Context Protocol server for a self-hosted secrets manager on Cloudflare Workers and D1. Lets an AI coding assistant list and write secrets without a value ever entering the conversation.
