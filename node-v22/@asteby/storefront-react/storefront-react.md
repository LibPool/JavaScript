# @asteby/storefront-react

> 标签: JavaScript

## 简介

React bindings for @asteby/storefront — SSR-safe provider, optimistic cart, Money, responsive Image, prices, variant selection, SEO meta and JSON-LD, section registry and server-rendered theme CSS.

- 源码仓库：https://github.com/asteby/metacore-sdk
