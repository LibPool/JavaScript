# @asteby/metacore-maps

> 标签: JavaScript

## 简介

Lazy maps for metacore hosts and addons — MapView, markers, clusters, routes, geofences, LocationPicker, TrackingTimeline and the declarative `map`/`timeline` renderers. MapLibre GL loads on demand; no API keys.
