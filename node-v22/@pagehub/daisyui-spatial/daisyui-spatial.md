# @pagehub/daisyui-spatial

> 标签: daisyui, density, fluid, spacing, spatial, tailwind, tokens

## 简介

Density-scaled spatial tokens for DaisyUI 5 — plug into any DaisyUI project to get fluid, adjustable spacing via a single --spacing-density multiplier.
