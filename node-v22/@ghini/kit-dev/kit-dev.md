# @ghini/kit-dev

> 标签: db, http2, io, kit-dev, pg, redis

## 简介

js的实用工具函数库,开发完整版,有较详细的demo和注释.
这是个汇总大模块,使用方便,代价是初始化开销略微大,但对现代性能来说微乎其微.
要优化起来也很简单,直接把使用部分单独拎出去就行,仅在最求极致的速度(✅)和蚊子腿内存(❌)时才有可能这么做
