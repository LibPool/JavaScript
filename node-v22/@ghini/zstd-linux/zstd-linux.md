# @ghini/zstd-linux

> 标签: zstd

## 简介

高效好用的zstd压解windows版,level 0-20,默认8. 提供了直接加解压,对100m内文件处理没问题,保持了简洁性.大于此一般也不用zstd,实在要用需找zstd编解码器做流式处理
