# @josharsh/webmcp-agent

> 标签: agent, ai, anthropic, browser, chat, claude, mcp, model-context, tools, webmcp

## 简介

In-page AI agent for WebMCP — discovers and operates the tools your site registers via webmcp-tools (document.modelContext). Headless core, drop-in React widget, and a fetch-style server proxy handler.
