# @tkawen/os-mcp

> 标签: claude, lms, mcp, model-context-protocol, tkawen, tkawen-os

## 简介

Read-only MCP server (stdio) exposing a TKAWEN OS academy's live catalogue, instructors, certificate verification and, with a token, the learner's own dashboard.
