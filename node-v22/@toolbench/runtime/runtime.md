# @toolbench/runtime

> 标签: custom-elements, interactive, no-framework, shadow-dom, toolbench, typescript, web-components, web-worker, widget, zero-dependencies

## 简介

Renders and runs a Toolbench tool in any web page: a <tool-host> custom element with three display modes, no framework required.
