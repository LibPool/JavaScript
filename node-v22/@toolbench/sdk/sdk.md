# @toolbench/sdk

> 标签: fixtures, interactive, manifest, tool, toolbench, typescript, validation, widget, zero-dependencies

## 简介

The contract a Toolbench tool implements: types, manifest validation, version migration, and a fixture runner. No runtime dependencies, no DOM.
