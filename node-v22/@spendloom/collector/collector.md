# @spendloom/collector

> 标签: ai, claude-code, cli, codex, copilot, cost, gemini, opencode, spendloom, telemetry, usage

## 简介

SpendLoom collector: ships metadata-only AI coding usage (tokens, model, timestamps, salted-hashed paths - never prompt or code content) from local CLI logs to your SpendLoom dashboard.
