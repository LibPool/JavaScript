# @vastdisk/sdk-ts

> 标签: aes-256-gcm, blake3, browser, crypto, e2ee, ed25519, encryption, vastdisk

## 简介

VASTDISK client-side crypto SDK - AES-256-GCM encryption, BLAKE3 hashing, Ed25519 proof verification. Browser-native Web Crypto + @noble/hashes.
