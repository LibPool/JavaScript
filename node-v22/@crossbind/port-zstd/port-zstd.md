# @crossbind/port-zstd

> 标签: android, compression, crossbind, crossbind-package, ios, libzstd, react-native, wasm, webassembly, zstandard, zstd

## 简介

This package provides a libzstd library compiled with crossbind, enabling seamless usage of Zstandard (de)compression functionalities in JavaScript, WebAssembly and React Native projects.
