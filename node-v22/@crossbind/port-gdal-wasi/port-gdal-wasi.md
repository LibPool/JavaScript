# @crossbind/port-gdal-wasi

> 标签: crossbind, crossbind-package, gdal, geospatial, gis, libgdal, raster, vector, wasi, webassembly

## 简介

WASI build of the precompiled GDAL geospatial library, built with crossbind. Use it together with the main package @crossbind/port-gdal.
