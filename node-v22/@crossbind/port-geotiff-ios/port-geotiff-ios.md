# @crossbind/port-geotiff-ios

> 标签: crossbind, crossbind-package, geospatial, geotiff, gis, ios, libgeotiff, react-native

## 简介

iOS build of the precompiled libgeotiff (GeoTIFF) library, built with crossbind. Use it together with the main package @crossbind/port-geotiff.
