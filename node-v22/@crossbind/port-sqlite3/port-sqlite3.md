# @crossbind/port-sqlite3

> 标签: android, crossbind, crossbind-package, database, ios, libsqlite3, react-native, sql, sqlite, sqlite3, wasm, webassembly

## 简介

This package provides the precompiled sqlite3 library, built using crossbind, for easy integration into JavaScript, WebAssembly and React Native projects. It offers database functionalities through the sqlite3 API, ensuring high performance and cross-plat
