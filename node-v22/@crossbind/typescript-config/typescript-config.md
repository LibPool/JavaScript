# @crossbind/typescript-config

> 标签: crossbind, rust, tsconfig, typescript

## 简介

Shared TypeScript configuration wiring the editor types crossbind generates under .crossbind/ (C++ .h and Rust .rs imports, cargo: crates) - extend it once and never manage the wiring by hand.
