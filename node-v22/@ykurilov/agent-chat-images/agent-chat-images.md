# @ykurilov/agent-chat-images

> 标签: JavaScript

## 简介

Картинки от агента: инструмент `generate_images` через Runware или KIE.ai, файлы в хранилище вложений. Отдельное расширение: приложению без картинок пакет не нужен. Требует `@ykurilov/agent-chat-attachments`.
