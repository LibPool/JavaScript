# @ykurilov/agent-chat-attachments

> 标签: JavaScript

## 简介

Вложения к сообщению: картинки, PDF и текстовые файлы. Отдельное расширение: приложению, которому вложения не нужны, они не нужны и в сборке. Без пакета чат остаётся текстовым, договор остальных пакетов не меняется.
