# @accessmeru/react

> 标签: JavaScript

## 简介

Access Meru for browser and React apps: <AccessMeruProvider> runs sign-in and account state (callback, restore, silent sign-in, refresh, revocation, sign-out), with hooks, the Continue with Access Meru button, and a framework-free core.
