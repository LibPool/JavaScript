# @banzhe/dsh-web-icons

> 标签: JavaScript

## 简介

Serve the Web launcher icon set (favicon, PWA manifest icons, apple-touch-icon) from a Bundle-owned snapshot, so the browser surface stops depending on whichever dsh-web-frontend the running harness ships
