# @tiptap/ai-toolkit

> 标签: ai toolkit, server, server ai toolkit, tiptap, tiptap ai

## 简介

Integrate AI capabilities into the Tiptap editor. This package contains the SDK for connecting to the Server AI Toolkit service.
