> 标签: bun, cargo, cli, command-runner, developer-tools, fuzzy-search, go, go-mod, monorepo, npm, npm-scripts, package-manager, package-manager-detector, pnpm, pnpm-workspace, project-cli, python, rust, script-runner, workspace, yarn

## 简介

Project-aware CLI that detects npm, pnpm, yarn, bun, Go, Rust and Python projects, then routes installs, scripts, builds and workspace commands automatically.
