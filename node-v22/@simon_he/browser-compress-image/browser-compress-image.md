# @simon_he/browser-compress-image

> 标签: arraybuffer, base64, blob, browser, compress, file-processing, file-size-reduction, frontend, gif, image-compression, image-optimization, jpeg, lightweight, modern, optimization, png, typescript, web-performance, webp, zero-dependencies

## 简介

🚀 A powerful, lightweight browser image compression library with TypeScript support. Compress JPEG, PNG, GIF images with multiple output formats (Blob, File, Base64, ArrayBuffer) and zero dependencies.
