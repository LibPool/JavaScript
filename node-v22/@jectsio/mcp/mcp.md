# @jectsio/mcp

> 标签: hierarchical-data, jects, knowledge-management, mcp, model-context-protocol, process-management

## 简介

MCP server for _jects — manage hierarchical topics, concepts, and ideas via Model Context Protocol. Supports both local (stdio) and remote (HTTP) transports.
