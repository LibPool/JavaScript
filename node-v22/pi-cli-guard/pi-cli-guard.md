# pi-cli-guard

> 标签: agentic-coding, ai-agent, ai-agents, ai-coding, bash, canonicalize, cli, developer-tools, egrep, fd, fgrep, find, grep, llm, modern-cli, pi, pi-coding-agent, pi-extension, pi-package, rg, ripgrep, shell, tool-call-repair, tool-calling, tool-guard, typescript

## 简介

Pi extension that rewrites the agent's bash to the modern toolchain: grep/egrep/fgrep → rg (ripgrep), find → fd (conservative whitelist) — applied at the tool_call event, so it composes with other bash extensions
