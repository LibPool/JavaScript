# @systemix/hash

> 标签: crypto, hash, hashing, node, password, password-hashing, pbkdf2, scrypt, systemix, typescript, utility

## 简介

Password hashing and verification with PBKDF2 and scrypt, built on Web Crypto and Node.js built-ins. Zero dependencies. Part of the Systemix toolkit.
