# @igloo-ui/vertical-bar-chart

> 标签: JavaScript

## 简介

A vertical bar chart is a graphical representation that uses vertical bars to display data values, with each bar representing a category or group. The height of each bar corresponds to the magnitude of the data it represents, allowing for easy comparison
