# @niumoteam/node-plugin

> 标签: JavaScript

## 简介

TaskSync node plugin for deepseek-harness: keeps this harness connected to the TaskSync cloud as a worker node and runs dispatched tasks in-process through the harness's own agent engine (no ACP subprocess)
