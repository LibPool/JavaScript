# @etheslay/dsh-token-dashboard

> 标签: cordis, dashboard, deepseek, deepseek-harness, dsh, dsh-plugin, react, statistics, token, usage

## 简介

Token-usage profile for DeepSeek Harness — a Codex-style usage panel inside Settings: lifetime tokens, a year of activity, cache hit rate and top models. · DSH 用量统计面板：在设置里查看累计 token、一年活动热力图、缓存命中率与最常用模型。
