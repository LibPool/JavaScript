# dsh-zenmux

> 标签: cordis, dsh, dsh-plugin, llm, provider, quota, zenmux

## 简介

ZenMux 供应商的 DSH 插件：对话内额度显示、推理等级配置、模型目录刷新与额度显式实施。

- 源码仓库：git+https://github.com/LC-86/dsh-plugins.git
- npm 页面：https://www.npmjs.com/package/dsh-zenmux
