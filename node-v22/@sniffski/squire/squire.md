# @sniffski/squire

> 标签: ai-agent, appium, browser-automation, cdp, mcp, playwright, squire, web-automation

## 简介

Squire — AI-native desktop & browser automation over MCP: drive a real browser like a human (multi-tab, navigation-tolerant scripts, vision grounding). Built on the appium-mcp foundation; retains Appium mobile tools. Not affiliated with Appium.
