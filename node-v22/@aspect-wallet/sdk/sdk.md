# @aspect-wallet/sdk

> 标签: account-abstraction, arbitrum, bundler, erc-4337, ethereum, gasless, passkeys, paymaster, session-keys, smart-wallet, social-login, turnkey, useroperation, web3, webauthn

## 简介

TypeScript SDK for ERC-4337 Account Abstraction smart wallets. Gasless transactions, social logins, passkeys, session keys, multi-factor auth, and account recovery.
