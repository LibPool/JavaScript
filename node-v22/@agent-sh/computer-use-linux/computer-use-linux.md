# @agent-sh/computer-use-linux

> 标签: accessibility, claude-code, codex, computer-use, hermes-agent, linux, mcp, pi-package, wayland

## 简介

Native Linux desktop control for AI agents (MCP server, Pi tools, and CLI): semantic AT-SPI accessibility trees, screenshots, compositor window targeting, Wayland/X11 input, and an on-screen activity indicator.
