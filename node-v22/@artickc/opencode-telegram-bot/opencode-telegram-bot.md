# @artickc/opencode-telegram-bot

> 标签: ai-agent, ai-coding-assistant, chatops, cross-platform, daemon, devtools, grammy, mobile-coding, opencode, opencode-ai, telegram, telegram-bot

## 简介

Control OpenCode from Telegram over ACP (JSON-RPC/stdio). Switch projects, resume and attach to live coding sessions, stream responses with diffs, queue follow-ups, and run 24/7 as a cross-platform background service.
