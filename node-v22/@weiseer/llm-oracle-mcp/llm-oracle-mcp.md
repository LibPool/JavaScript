# @weiseer/llm-oracle-mcp

> 标签: ai-agent, llm, mcp, model-context-protocol, oracle, pricing, weiseer

## 简介

MCP server for LLM provider availability and pricing — catalog of 10+ models across Anthropic, OpenAI, Google, DeepSeek, Mistral with cited sources. Self-contained (bundled catalog) with optional fresh-data fetch.
