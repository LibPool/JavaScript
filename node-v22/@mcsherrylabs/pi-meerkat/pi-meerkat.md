# @mcsherrylabs/pi-meerkat

> 标签: agent-tools, evolver, meerkat, pi-package

## 简介

Pi agent extension: announce a channel you control onto the meerkat announcements registry, and search what others have announced. Owns the announcement wire contract; wraps @mcsherrylabs/pi-evolver for the chain and the content cache.
