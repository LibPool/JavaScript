# @alderinc/sdk

> 标签: JavaScript

## 简介

`@alderinc/sdk` provides server-side TypeScript clients for Alder. `AccountClient` uses a person grant, user key, or account key. `MerchantClient` uses an application secret. Agents use the protocol directly and need no package.
