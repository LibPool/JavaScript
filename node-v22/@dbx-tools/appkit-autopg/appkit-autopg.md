# @dbx-tools/appkit-autopg

> 标签: JavaScript

## 简介

`autopg()` is a one-line helper that fills in every Lakebase Postgres env var the AppKit `lakebase` plugin needs from whatever fragments your deployment actually carries. Run it once before `createApp(...)` and stop hand-rolling connection strings:
