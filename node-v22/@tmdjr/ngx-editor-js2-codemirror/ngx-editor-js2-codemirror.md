# @tmdjr/ngx-editor-js2-codemirror

> 标签: JavaScript

## 简介

This block embeds a [CodeMirror](https://codemirror.net/) editor inside [Ngx-Editor-Js2](https://www.npmjs.com/package/@tmdjr/ngx-editor-js2). Use it to display and edit code snippets with syntax highlighting.
