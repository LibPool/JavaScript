# @tmdjr/ngx-editor-js2-panel

> 标签: JavaScript

## 简介

This block offers Confluence‑style panels for [Ngx-Editor-Js2](https://www.npmjs.com/package/@tmdjr/ngx-editor-js2). Use it to highlight content such as notes, tips or warnings.
