# @tmdjr/ngx-editor-js2-pop-quiz

> 标签: JavaScript

## 简介

Create interactive quiz questions in [Ngx-Editor-Js2](https://www.npmjs.com/package/@tmdjr/ngx-editor-js2). A configuration overlay lets you define questions, answers and feedback messages.
