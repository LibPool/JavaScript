# @tmdjr/ngx-editor-js2-blockquotes

> 标签: JavaScript

## 简介

This package provides a blockquote component for [Ngx-Editor-Js2](https://www.npmjs.com/package/@tmdjr/ngx-editor-js2). It displays quoted text with configurable sizes so your content can stand out.
