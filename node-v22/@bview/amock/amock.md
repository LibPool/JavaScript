# @bview/amock

> 标签: JavaScript

## 简介

### 功能列表 - API书写友好,基于REST原则 - 支持文件上传接口，文件下载，文件上传支持进度条 - 支持图片mock - 支持`mock.js`工作流 - 支持代理转发,基于`http-proxy-middleware` - 支持自定义响应消息 - 支持现有nei mock项目
