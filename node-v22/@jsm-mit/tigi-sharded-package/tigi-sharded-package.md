# @jsm-mit/tigi-sharded-package

> 标签: JavaScript

## 简介

The one package of the Tigi network group: takes the coordinator's id and hides the coordinator, the core and the workers — for a consumer the group is one canister; plus the rider's few driver-canister endpoints (U-14).
