# @cyberclarence/openpgp

> 标签: crypto, gpg, openpgp, pgp

## 简介

OpenPGP.js is a Javascript implementation of the OpenPGP protocol. This is defined in RFC 4880.

## 官网

- 官网：https://openpgpjs.org/
- 源码仓库：git+https://github.com/cyberclarence/openpgpjs.git
- npm 页面：https://www.npmjs.com/package/@cyberclarence/openpgp
