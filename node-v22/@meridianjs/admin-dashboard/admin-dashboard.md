# @meridianjs/admin-dashboard

> 标签: JavaScript

## 简介

The MeridianJS admin dashboard. A Linear.app-inspired React SPA built with Vite, TanStack Query, Tailwind CSS, and shadcn/ui. Served as a static site alongside your API.
