# @camera.ui/camera-ui-reolink

> 标签: baichuan, camera-ui-plugin, reolink

## 简介

Integrates Reolink cameras and doorbells into camera.ui via the native Baichuan protocol, with device discovery, live streaming, two-way audio, and motion, AI object, battery and doorbell events.
