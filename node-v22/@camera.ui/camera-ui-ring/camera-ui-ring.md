# @camera.ui/camera-ui-ring

> 标签: camera-ui-plugin, cameras, doorbell, ring

## 简介

Integrates Ring cameras and doorbells into camera.ui, with device discovery, live streaming, and motion, battery, light, siren and doorbell events.
