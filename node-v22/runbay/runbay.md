# runbay

> 标签: bun, cli, desktop-app, developer-tools, electron, launcher, npm, package-manager, pnpm, scoop, self-update, tray, windows, yarn

## 简介

Not an installer. A launcher. Detect, launch, update and uninstall apps installed from the command line (npm, pnpm, yarn, bun, scoop) — in one modern window.
