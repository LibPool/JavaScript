# safebyok-graphql

> 标签: e2ee, graphql, safebyok, urql, vault

## 简介

GraphQL storage for safebyok: the schema and resolvers that carry a server-side VaultDB's verbs, and the VaultDB over an urql Client that calls them from the browser.
