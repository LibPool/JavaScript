# @hydranium/glsp-client-vscode

> 标签: diagram, glsp, hydranium, langium, language-server, lsp, vscode, vscode-extension, webview

## 简介

VS Code client primitives for GLSP heads built on @hydranium/glsp-server: the extension host's GLSP server over a discovered socket port and a custom editor whose webview hosts the diagram, and a webview starter that binds @hydranium/glsp-client's host-ne
