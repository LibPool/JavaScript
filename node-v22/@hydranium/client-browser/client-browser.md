# @hydranium/client-browser

> 标签: browser, hydranium, langium, language-server, lsp, monaco, web-worker

## 简介

The page side of a hydranium host that runs its heads in a web worker: the worker bootstrap that hands each head its own MessagePort, the page's LSP handshake, a Monaco LSP client, the data head's port, and the rejection of what is pending when the worker
