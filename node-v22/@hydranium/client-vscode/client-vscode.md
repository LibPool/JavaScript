# @hydranium/client-vscode

> 标签: hydranium, langium, language-server, lsp, vscode, vscode-extension

## 简介

Cross-head VS Code client primitives for a hydranium host: the extension host asks the language server for each socket head's port, bounded, and registers the host commands through which a Theia app that sideloads the extension reaches those ports.
