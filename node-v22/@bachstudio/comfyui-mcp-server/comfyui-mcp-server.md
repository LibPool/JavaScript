# @bachstudio/comfyui-mcp-server

> 标签: ai, comfyui, image-generation, llm, mcp, model-context-protocol, stable-diffusion

## 简介

Simple Model Context Protocol (MCP) server for ComfyUI: text-to-image, image edit, 换装 (Flux 2 Klein 9B), Wan2.2 image-to-video, and Wan2.2 RemixV2 首尾帧 11s / 32fps 走秀视频 (快速版). Works with a local or remote ComfyUI instance.
