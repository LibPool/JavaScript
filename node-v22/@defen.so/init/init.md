# @defen.so/init

> 标签: ai-security, bootstrap, defen.so, defenso, django, express, fastapi, fastify, flask, init, install, laravel, middleware, next.js, sdk, security, symfony, vibe-coding, waf

## 简介

One command to install a production Web Application Firewall. Detects Node (Next.js / Express / Fastify), PHP (Laravel / Symfony), and Python (Django / FastAPI / Flask), installs the right Defenso SDK, wires the middleware, writes DEFENSO_TOKEN to .env. $
