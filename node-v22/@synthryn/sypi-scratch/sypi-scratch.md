# @synthryn/sypi-scratch

> 标签: extension, scratch, sypi

## 简介

Give each session a throwaway workspace outside the repository and expose it through the scratch tool. Use it when temporary files should not become project state. Primary capability: the scratch tool and session-local cleanup.
