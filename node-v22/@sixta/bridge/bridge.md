# @sixta/bridge

> 标签: agent, context, database, mysql, postgresql, sixta

## 简介

SIXTA Connect's self-hosted context agent: pushes derived database statistics (no rows, no query text) from inside your network to connect.sixta.ai.

## 官网

- 官网：https://connect.sixta.ai
- 源码仓库：git+https://github.com/sixta-systems/sixta-bridge.git
- npm 页面：https://www.npmjs.com/package/@sixta/bridge
