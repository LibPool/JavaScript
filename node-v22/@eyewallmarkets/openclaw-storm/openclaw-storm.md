# @eyewallmarkets/openclaw-storm

> 标签: arbitrage, eyewall, openclaw, openclaw-plugin, prediction-markets, storm

## 简介

Storm prediction-market arbitrage feed + watchlist push alerts for OpenClaw agents. Free tier exposes the public spread tape; Pro adds personal watchlists with push alerts; Edge bundles the full read API via @eyewallmarkets/storm-mcp.
