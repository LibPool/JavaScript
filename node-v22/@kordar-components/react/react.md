# @kordar-components/react

> 标签: JavaScript

## 简介

`@kordar-components/react` 是面向 React 生态的通用 Hook 与表格运行时封装，主要服务于 monorepo 内的后台模板、`@kordar/easyui` 以及资源页场景。它的目标不是提供单一 UI 组件，而是提供一套可组合的状态管理与业务交互基座。
