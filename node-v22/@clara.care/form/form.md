# @clara.care/form

> 标签: clara, fhir, form, medical, questionnaire, react, web-component

## 简介

Clara medical form: React component, <clara-form> web component and CDN script, with live filling from a Clara consultation, validation and FHIR R4 QuestionnaireResponse export.
