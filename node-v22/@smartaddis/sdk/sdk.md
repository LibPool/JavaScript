# @smartaddis/sdk

> 标签: addis-ababa, address, ethiopia, geocoding, gis, openapi, smart-city

## 简介

Official TypeScript client for the Smart City Platform API: permanent entity identity, official addresses, geocoding and routing for Addis Ababa.
