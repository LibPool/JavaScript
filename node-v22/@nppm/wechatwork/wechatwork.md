# @nppm/wechatwork

> 标签: npm

## 简介

企业微信是腾讯微信团队打造的企业通讯与办公工具，具有与微信一致的沟通体验，丰富的OA应用，和连接微信生态的能力，可帮助企业连接内部、连接生态伙伴、连接消费者。专业协作、安全管理、人即服务。企业微信已覆盖零售、教育、金融、制造业、互联网、医疗等50多个行业，正持续向各行各业输出智慧解决方案。
