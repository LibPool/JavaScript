# @mesh-intelligence/capacitor-firebase-auth-plugin

> 标签: capacitor, native, plugin

## 简介

This is a plugin to allow native SDK usage for authentication with firebase on iOS, Android, and Web/PWA. It is a Ionic Capacitor Plugin.
