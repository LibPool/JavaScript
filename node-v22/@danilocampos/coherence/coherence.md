# @danilocampos/coherence

> 标签: agents, claude-code, codex, coherence, harness, spec, verification

## 简介

A spec + coherence harness for agent-developed projects: derive a multi-resolution graph from *.spec.md + code, render an explorable outline and an agent map, and verify claims/narrative/coverage. Language and platform specifics live behind adapters.
