# @rick427/react-native-lottie-splash

> 标签: android, animated-splash, animation, bootsplash, ios, lottie, new-architecture, react-native, splash, splash-screen, turbomodule

## 简介

Animated Lottie splash screen for React Native — plays on launch, dismisses when your app is ready. Pairs with react-native-bootsplash for a flash-free launch experience.
