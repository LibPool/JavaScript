# node-red-contrib-raspi5-neopixel

> 标签: addressable, led, led-strip, neopixel, node-red, node-red-contrib, raspberry-pi, raspberry-pi-5, spi, spi0, spi1, ws2812, ws2812b

## 简介

Raspberry Pi 5 WS2812 / NeoPixel pure JavaScript Node-RED node with SPI0/SPI1, selectable color order (RGB/GRB/...), brightness, per-pixel control and effects
