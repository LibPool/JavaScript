# @rossz/pi-fast-jev-compaction

> 标签: compact, compaction, context, fast-jev-compaction, jev, pi, pi-package, typesafe, verbatim

## 简介

Fast, verbatim, jev-guided compaction for pi: keeps old user and assistant text as is and lets TypeSafe's jev model decide which tool calls and outputs to drop. A pi version inspired by the fast-jev-compaction Claude Code plugin.
