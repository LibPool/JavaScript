# @asksql/widget

> 标签: ai, ask-database, database, database-chat, embed, llm, natural-language, nl2sql, shadow-dom, sql, sql-generation, text-to-sql, text2sql, vanilla-js, widget

## 简介

Vanilla-JS AskSQL embed for non-React pages. Mounts the bubble/chat into a shadow root so host CSS never bleeds in or out.
