# @livecore/design-tokens

> 标签: JavaScript

## 简介

Generic, product-neutral design tokens and theme contracts for LiveCore vertical apps: the token contract (color, spacing, typography, radius, shadow, breakpoint, motion), the stable scale keys, a neutral base theme and a type-safe theme authoring helper.
