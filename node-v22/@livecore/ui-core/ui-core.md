# @livecore/ui-core

> 标签: JavaScript

## 简介

Generic, product-neutral UI primitive contracts for LiveCore vertical apps: the variant vocabularies (tone, size, emphasis, surface level, layout), the typed prop shape of each generic primitive and the pure variant-resolution defaults. Framework-agnostic
