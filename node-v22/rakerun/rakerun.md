# rakerun

> 标签: agents, cli, cloudraker, rakerun, run

## 简介

rakerun: the command line of cloudraker.run. Sign up, create projects from templates, deploy agents, run them, and manage secrets, connectors, tokens and Structured Knowledge from the terminal.
