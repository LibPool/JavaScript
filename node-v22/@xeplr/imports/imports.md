# @xeplr/imports

> 标签: csv, excel, express, import, upload

## 简介

Data imports as a drop-in module: upload a CSV/Excel/JSON file, check it against the table, load it as a New table, Append or Replace, see and download the rows the database refused, and roll back — routes, access catalog and env in one package
