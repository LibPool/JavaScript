# @hanzo/sentinel

> 标签: error-tracking, hanzo, issues, observability, sentinel, traces

## 简介

Hanzo Sentinel — the client for the error plane's read face. Lists and resolves grouped issues, reads captured errors, lists projects, and queries logs, stats, traces and aggregates over /v1/sentinel. The write side is @hanzo/event.
