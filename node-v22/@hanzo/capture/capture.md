# @hanzo/capture

> 标签: analytics, attribution, capture, funnel, hanzo, product-analytics, telemetry

## 简介

Hanzo Analytics — tiny, batched product-analytics capture client. Emits pageview/event/identify/group to Hanzo Cloud (/v1/analytics + /v1/tracker) with first-touch UTM/referrer/refCode attribution, beacon-on-unload, and a shared event + goal vocabulary.
