# @pro-laico/mux-video

> 标签: JavaScript

## 简介

Atomic Payload mux-video plugin. Thin wrapper around @oversightstudio/mux-video that adds a local MuxVideo extension collection with Atomic Payload defaults.

- 源码仓库：git+https://github.com/pro-laico/atomic-payload.git
