# @zavora-ai/computer-use-mcp

> 标签: JavaScript

## 简介

MCP server + client for cross-platform desktop control (macOS + Windows + Linux) — screenshot, mouse, keyboard, clipboard, app management. Backed by Rust NAPI native module.
