# @oxvoinsights/agent-guard

> 标签: agent-security, ai-agent, llm-security, oxvo, oxvo-insights, prompt-injection, secret-detection, security-scanner, yara, yara-x

## 简介

Security scanner for AI coding agents from OXVO Insights. Checks what an agent reads, writes and runs for prompt injection, secret exfiltration, destructive commands, supply-chain attacks and hardcoded secrets.
