# @woyeshishen/dsh-lan-access

> 标签: cordis, deepseek-harness, dsh, lan, network, plugin

## 简介

为 DeepSeek Harness 提供局域网访问能力：绑定 0.0.0.0 并注入 crypto.randomUUID polyfill，使纯 HTTP 局域网源下 GUI 与 /api 正常工作，不改动任何原始代码。
