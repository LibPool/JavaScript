> 标签: claude, copilot-studio, endpoint-management, intune, mcp, microsoft-365, microsoft-graph, model-context-protocol, msp

## 简介

Microsoft Intune MCP server. Microsoft Graph access for managed devices, compliance, configuration, apps, autopilot, scripts and audit — including write operations (sync, rename, retire, wipe, delete, bulk-delete). Multi-tenant MSP support, Copilot Studio
