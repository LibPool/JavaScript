# @visiq/claude-code-harness

> 标签: action-governance, agent-governance, ai-governance, anthropic, audit-trail, claude, claude-code, hooks, retrieval-governance, visiq

## 简介

VisIQ agent-governance harness for the Claude Code CLI — action governance on every tool call, retrieval governance on its built-in read tools and read-shaped MCP tools, and audit-trail reporting, installed as Claude Code hooks.
