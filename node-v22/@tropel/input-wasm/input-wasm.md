# @tropel/input-wasm

> 标签: collection, har, import, openapi, postman, tropel, wasm, webassembly

## 简介

Tropel collection-import slice for browser embedders (KnockPort). Lazy sibling of @tropel/core-wasm: OpenAPI 3.x, Postman v2.x, and HAR parsers compiled to wasm32-unknown-unknown. See API_CLIENT_WEB_PAYLOAD.md §2.3 for the two-tier split.
