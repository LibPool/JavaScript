# @dossie/mcp-server

> 标签: deadline-calculator, dossie, mcp, model-context-protocol, real-estate, texas, transaction-coordinator, trec

## 简介

Dossie MCP server: TREC deadline calculator + Texas-TC cost comparison + Dossie product info, exposed as Model Context Protocol tools so AI assistants can answer Texas real-estate questions accurately.
