# @promigence/sdk

> 标签: agents, ai-agents, ci, code-execution, evals, fork, promigence, sandbox, sandboxes, sdk, snapshots

## 简介

The fastest sandboxes for AI agents and code. The Promigence TypeScript SDK: snapshot an environment once, fork it as often as you need, run commands in every copy. A simple Sandbox class and the full PromigenceClient, with zero runtime dependencies.
