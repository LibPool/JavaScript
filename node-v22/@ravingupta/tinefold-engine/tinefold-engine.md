# @ravingupta/tinefold-engine

> 标签: and-or-graph, anthropic, brainstorming, design-doc, event-sourcing, llm, openai, prd

## 简介

Pure TypeScript engine for tinefold, an AI brainstorming tool built on an AND-OR graph: event log, rules, staleness, prompts, providers, documents.
