# @hoodprivate/sdk

> 标签: agent-economy, ai-agents, confidential-transfers, hoodprivate, neobank, payments, privacy, robinhood-chain, sdk, stablecoin, typescript, usdg, web3, x402, zero-knowledge

## 简介

The official TypeScript SDK for HoodPrivate, the private financial layer of the agent economy. Confidential transfers, agent accounts with on-chain spend policies, and native x402 payments on Robinhood Chain, fully typed and ready in minutes.
