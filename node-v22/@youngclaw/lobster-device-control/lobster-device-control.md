# @youngclaw/lobster-device-control

> 标签: android, device-control, openclaw, openclaw-plugin, websocket

## 简介

Remote Android device control plugin for OpenClaw. Manages WebSocket connections with LobsterAgent Android app and exposes device control as OpenClaw tools.
