# canonical-beacon

> 标签: canonical, duplicate-content, github-action, hreflang, html, international-seo, rel-canonical, sarif, seo, static-site

## 简介

Check canonical tags and hreflang clusters in your built static site: missing, multiple, relative or in-body canonicals, targets that are missing, noindex or chained, and hreflang codes, self-references, return links and x-default. Text/JSON/SARIF/Markdow
