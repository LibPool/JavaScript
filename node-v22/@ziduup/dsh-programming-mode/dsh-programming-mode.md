## 简介

DeepSeek Harness 编程模式组合包：标准模式之上强制执行 Superpowers 工程纪律（TDD、系统化调试、先计划后编码、完成前验证、代码审查），常驻 Ponytail 代码量纪律，内置全套 superpowers 与 ponytail 技能，dsh plugin add 一键安装。
