# @jeffreyjyz/opencode-context

> 标签: context, opencode, opencode-plugin, tokens

## 简介

Context-window breakdown for opencode: a /context dialog plus a context_breakdown tool showing where the window went (system prompt, tool definitions, thinking, tool I/O, messages), delta.app style.
