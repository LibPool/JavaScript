# @super_camel/dsh-skill-panel

> 标签: JavaScript

## 简介

DSHP session-scoped skill control and plugin management: session_skill_* tools, /skill-* commands, and a browser panel for skills, session MCP, and host-composition plugins (enable/disable, bundle→patch promote)
