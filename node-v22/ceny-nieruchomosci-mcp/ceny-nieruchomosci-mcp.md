# ceny-nieruchomosci-mcp

> 标签: ai-agent, ceny-mieszkan, claude, dzialka, gugik, housing-prices, mcp, model-context-protocol, mpzp, nieruchomosci, open-data, parcel, plan-miejscowy, poland, rcn, real-estate, rejestr-cen-nieruchomosci, uzbrojenie, zoning

## 简介

MCP server for Polish real estate: real transaction prices from notarial deeds (Rejestr Cen Nieruchomości) and parcel checks – zoning plan (MPZP), utilities, flood risk, nature protection. No API key.
