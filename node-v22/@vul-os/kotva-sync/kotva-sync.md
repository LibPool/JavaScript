# @vul-os/kotva-sync

> 标签: bindings, crdt, kotva, sync, wasm

## 简介

The browser/JS binding for the KOTVA Sync substrate (substrate/SYNC.md, substrate/BINDINGS.md §3): a wasm-bindgen wrapper exposing kotva-sync's signed CRDT operation algebra, HLC, observable-state snapshots, version vectors and range-Merkle reconciliation
