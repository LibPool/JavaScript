# @windowkit/appkit

> 标签: appkit, calayer, core-animation, coretext, iosurface, macos, native-controls, nsmenu, react-x11, windowkit

## 简介

Retained-mode AppKit backend for Node.js: Core Animation (CALayer) layer trees, CoreText layout and drawing, IOSurface presentation, NSMenu, and native control bezels — the macOS half of react-x11.
