# @windowkit/win32

> 标签: direct2d, directcomposition, directwrite, react-x11, win32, windows

## 简介

Mechanism-only Win32 bridge for Node.js: HWNDs on a UI thread of their own, DirectComposition surfaces, a Direct2D verb table and DirectWrite text — the Windows half of react-x11.
