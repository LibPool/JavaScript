> 标签: accessibility, components, css-modules, design-system, forms, grid-system, navigation, primitives-first, react, responsive, spexop, spexop-design-system, spexop-ui, theme, typescript, ui-library

## 简介

React component library with TypeScript and accessibility. 60+ components following the Primitives-First philosophy. Grid primitives, navigation, forms, buttons, cards, data, feedback, and more.
