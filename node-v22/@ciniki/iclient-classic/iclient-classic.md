# @ciniki/iclient-classic

> 标签: SuperMap

## 简介

@supermapgis/iclient-classic 是一套基于 SuperMap iClient 8C(2017) for JavaScript 的 GIS 客户端应用程序开发工具，通过它用户可以在 SuperMap iClient 8C(2017) for JavaScript 的基础上使用最新的 SuperMap 服务功能。

## 官网

- 官网：https://iclient.supermap.io
- 源码仓库：git+https://github.com/SuperMap/iClient-JavaScript.git
- npm 页面：https://www.npmjs.com/package/@ciniki/iclient-classic
