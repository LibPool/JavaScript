# dsh-cline-quota

> 标签: cline, clinepass, credits, deepseek-harness, dsh, dsh-plugin, quota, usage

## 简介

在 DeepSeek Harness 会话页头显示 Cline / ClinePass 订阅额度、Credits 余额与 ClinePass token 消耗，支持多账号切换。Show Cline / ClinePass subscription quota, credits, and ClinePass token usage in the DSH session header, with multi-account switching.
