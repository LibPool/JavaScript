# @smjr3/mermaid-editor

> 标签: diagram, editor, mermaid, static-site, svelte

## 简介

Customizable distribution of Mermaid Live Editor, delivered as an npm package and buildable into a static site. Unofficial derivative of mermaid-js/mermaid-live-editor.
