# pakistan-address

> 标签: address, district, division, dropdown, geo, pakistan, province, tehsil

## 简介

Pakistan's administrative hierarchy (province, division, district, tehsil) as typed JSON and tiny helpers for cascading address dropdowns. Zero dependencies.
