# @graphty/visual-review

> 标签: chromatic-alternative, git-lfs, github-actions, playwright, review, screenshot, snapshot, storybook, visual-regression, visual-testing

## 简介

Self-hosted visual review of Storybook stories: capture in GitHub Actions, keep the baselines in git (Git LFS), accept or reject each change in a local page, and gate pull requests
