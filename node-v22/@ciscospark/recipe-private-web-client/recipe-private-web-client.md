# @ciscospark/recipe-private-web-client

> 标签: JavaScript

## 简介

This is a plugin recipe for the Cisco Webex JS SDK. This recipe uses internal APIs to provide the features needed by the Cisco Webex Teams Client. There is no guarantee of non-breaking changes. Non-Cisco engineers should stick to the `ciscospark` package.
