# @aylith/inspekt

> 标签: JavaScript

## 简介

Everything-in-one package for Inspekt — the element inspector runtime, Vite/bundler plugins, CLI, daemon, and MCP server. Installs every @aylith/inspekt-* package and exposes the inspekt, inspekt-daemon, and inspekt-mcp commands.
