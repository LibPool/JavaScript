# remote-browser-use

> 标签: browser, chatgpt, chromium, claude, mcp, model-context-protocol, oauth, playwright

## 简介

Let an MCP-capable AI chat use selected tabs of a separate, persistent Chromium browser on your computer, behind OAuth and local approvals.
