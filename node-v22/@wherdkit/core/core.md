# @wherdkit/core

> 标签: changelog, feature-requests, feedback, headless, react, sdk

## 简介

Headless core for Wherd — the in-app feedback, feature-voting, and changelog SDK. Client, offline queue, store, and React hooks. Platform-agnostic.
