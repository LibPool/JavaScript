# @motrix/cli

> 标签: agent, aria2, cli, download, download-manager, json-rpc, mdxp, motrix

## 简介

Command-line client for the Motrix download manager — speaks MDXP (JSON-RPC 2.0) to a running Motrix, for humans and AI agents.
