# @serfab/cadre-rn

> 标签: cadre, crypto, hermes, libp2p, metro, noise, polyfills, react-native, sereus

## 简介

React Native kit for Sereus apps - phone-node bring-up and lifecycle, secure key storage and node-local record slots, native crypto for libp2p-noise, the runtime polyfills a cadre node needs under Hermes, and the Metro configuration that bundles it
