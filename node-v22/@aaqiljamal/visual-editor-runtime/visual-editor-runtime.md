# @aaqiljamal/visual-editor-runtime

> 标签: css-modules, next, styled-components, tailwind, visual-editor

## 简介

Visual-edit dev overlay (Preact in a closed Shadow DOM). Mount automatically via @aaqiljamal/visual-editor-next or the Vite plugin, or render <VisualEditOverlay /> yourself.
