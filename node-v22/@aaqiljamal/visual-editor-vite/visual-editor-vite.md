# @aaqiljamal/visual-editor-vite

> 标签: react, tailwind, visual-editor, vite, vite-plugin

## 简介

Vite plugin for visual-editor: stamps JSX with source ids before @vitejs/plugin-react, serves the AST-writer API as dev-server middleware, and auto-mounts the overlay. Works with Vite + React, React Router v7 (framework mode), TanStack Start and Astro+Rea
