# @exocognosis/pqc-sidecar-verify

> 标签: caip-2, certificate, cometbft, fips-204, ml-dsa, post-quantum

## 简介

Verifier for pqc-sidecar ML-DSA-65 (FIPS 204) checkpoint certificates (.pqcc format v2, chain-agnostic, and v1). Node and browsers.
