# @haybarn/ext-events-h1-5-3-wasm-eh

> 标签: duckdb, duckdb-wasm, events, extension, haybarn, wasm

## 简介

WebAssembly (eh) build of the Haybarn extension 'events' for duckdb-wasm. Built against haybarn 1.5.3. Pick the variant (mvp/eh/threads) matching your duckdb-wasm bundle.
