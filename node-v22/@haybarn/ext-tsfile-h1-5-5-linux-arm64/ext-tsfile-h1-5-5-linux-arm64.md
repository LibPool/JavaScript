# @haybarn/ext-tsfile-h1-5-5-linux-arm64

> 标签: JavaScript

## 简介

Haybarn extension 'tsfile' for linux/arm64 (glibc). Built against haybarn 1.5.5. Installed automatically by the @haybarn/ext-tsfile-h1-5-5 meta-package; use that, not this leaf, in your dependencies.
