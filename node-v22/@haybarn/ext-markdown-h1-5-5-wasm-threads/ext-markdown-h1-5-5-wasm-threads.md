# @haybarn/ext-markdown-h1-5-5-wasm-threads

> 标签: duckdb, duckdb-wasm, extension, haybarn, markdown, wasm

## 简介

WebAssembly (threads) build of the Haybarn extension 'markdown' for duckdb-wasm. Built against haybarn 1.5.5. Pick the variant (mvp/eh/threads) matching your duckdb-wasm bundle.
