# @haybarn/ext-duckhog-h1-5-3

> 标签: duckdb, duckhog, extension, haybarn

## 简介

Query Arrow Flight SQL servers that expose DuckLake-based catalogs and tables directly from DuckDB using standard SQL — including PostHog's managed data warehouse via [Duckgres](https://github.com/PostHog/duckgres).
