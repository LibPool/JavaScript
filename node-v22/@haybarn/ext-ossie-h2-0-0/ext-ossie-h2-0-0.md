# @haybarn/ext-ossie-h2-0-0

> 标签: duckdb, extension, haybarn, ossie

## 简介

The Apache Ossie (incubating) extension for DuckDB. Reads Ossie semantic model files in YAML or JSON and answers semantic queries against the tables in DuckDB, from a single binary, with no infrastructure. Also exposes the semantic layer via MCP.
