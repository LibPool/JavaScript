# @zhang_jifan/fanui

> 标签: components, css, dark-mode, design-system, design-tokens, framework, glassmorphism, grid, react, scss, theme, ui, vanilla-js, vue

## 简介

fanUI —— 一套 UI 设计系统，内置 12 套可在运行时切换的主题配色，支持液态玻璃质感、明暗双模式；适配官网、博客与 B 端控制台场景。下载即可使用：可直接用 script/link 引入编译产物，也可通过 npm + ESM / SCSS 接入项目。
