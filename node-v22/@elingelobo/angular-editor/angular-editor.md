# @elingelobo/angular-editor

> 标签: angular, angular-editor, angular-wysiwyg-editor, editor, native, rich, rich text editor, wysiwyg, wysiwyg-editor

## 简介

Simple editor nativo WYSIWYG para Angular 8+, 12+. Componente Angular de texto enriquecido. Basado en editor Kolkov en inglés
