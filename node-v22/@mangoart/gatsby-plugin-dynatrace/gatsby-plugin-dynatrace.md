# @mangoart/gatsby-plugin-dynatrace

> 标签: dynatrace, gatsby, gatsby-plugin, real user monitoring

## 简介

Gatsby Plugin to inject the Dynatrace JavaScript Agent into the generated pages and uses the JS ADK to track page changes
