# @bloc-ui/kit

> 标签: accessible, angular, angular-components, bloc-ui, component-library, lightweight, standalone-components, tailwind, themeable, typescript, ui-library

## 简介

All-in-one umbrella package — re-exports every stable and experimental Bloc UI component (except @bloc-ui/video-player, which must be installed directly).
