# vivi-figma-mcp

> 标签: design, design-generation, figma, figma-plugin, mcp, model-context-protocol

## 简介

MCP-сервер: ИИ-агенты (Claude Code, Cursor, Devin…) смотрят дизайн в открытом файле Figma, выгружают из него картинки и создают/правят дизайн настоящими нодами.
