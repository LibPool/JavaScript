# @arguslog/mcp-server

> 标签: agent, ai, arguslog, claude, error-tracking, mcp, model-context-protocol, observability

## 简介

Arguslog MCP server — exposes the full Arguslog API (issues, projects, orgs, alerts, releases, tier admin, …) as Model Context Protocol tools. Authenticate with a Personal Access Token from the dashboard.
