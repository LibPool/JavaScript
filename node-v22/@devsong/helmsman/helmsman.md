# @devsong/helmsman

> 标签: claude, devflow, helmsman, installer, npx, opencode

## 简介

DevFlow 自动化开发流程工具安装器：npx 一键安装，按 --agent 参数分发到 opencode / claude / 默认目录 (~/.agents)

- npm 页面：https://www.npmjs.com/package/@devsong/helmsman
