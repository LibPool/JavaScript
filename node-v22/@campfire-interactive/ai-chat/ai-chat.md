# @campfire-interactive/ai-chat

> 标签: JavaScript

## 简介

The platform AI chat panel for Campfire Suite apps: a docked, page-aware assistant opened from the header, answering from every app the user is granted, with typed answer blocks and confirm-to-write cards.
