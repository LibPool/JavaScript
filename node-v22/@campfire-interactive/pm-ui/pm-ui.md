# @campfire-interactive/pm-ui

> 标签: JavaScript

## 简介

Program Management's launch screens for the Campfire Suite: a program's launch checklist and the tenant's launch checklist settings. Rendered by pm's own webapp and embedded by other apps (omsf) through a transport the host supplies, so both show the same
