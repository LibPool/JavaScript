# ax-drag-ui

> 标签: JavaScript

## 简介

本项目支持通过**组件面板（ComponentPanel.vue）中的 commonData 配置**，结合 `widgetsConfig.js` 的属性-编辑器映射，实现拖拽组件到画布后，右侧属性面板自动渲染你配置的所有属性，极大提升属性配置的灵活性和可维护性。
