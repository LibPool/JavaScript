# aleph-cli

> 标签: agent, ai-agent, cli, ethereum, evm, mcp, robinhood-chain, security, terminal, wallet, web3

## 简介

AI agent for Robinhood Chain in your terminal. Watches contracts, checks wallets, prepares transactions you sign, surfaces watchlist alpha. Never asks for a private key. Never says "safe".
