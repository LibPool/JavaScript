# agent-context-manager

> 标签: agctx, agent-config, agent-guidance, ai-agents, antigravity, claude-code, codex, gemini, github, tdd

## 简介

A profile-based context manager for AI coding agents: keep rules in profiles, apply one per repository, and keep Codex, Claude Code, and Antigravity in sync
