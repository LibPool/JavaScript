# arch-contract

> 标签: architecture, ast, ci, dependency-rules, deptrac, layers, pest-arch, typescript

## 简介

ArchContract — architecture contract validator for TypeScript projects. Enforces layers, dependency boundaries, AST expectations and agent instructions in CI/CD — without acting as a linter.
