# audio-to-haptics

> 标签: amplitude, android, audio, audio-analysis, audio-reactive, beat-detection, frequency, haptic-feedback, haptic-pattern, haptics, media, mobile, music, navigator-vibrate, pulse-width-modulation, pwm, react, react-hook, realtime, requestanimationframe, sound, sync, typescript, vibration, vibration-api, video, waveform, web-audio, web-audio-api

## 简介

Converts audio into haptic (vibration) feedback patterns using the Web Audio API and Vibration API. Analyzes an audio file, detects amplitude spikes and decay tails, and drives `navigator.vibrate()` in sync with a media element.
