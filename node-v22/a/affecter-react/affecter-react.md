# affecter-react

> 标签: affecter, affecter-react, react-affecter, 影响者

## 简介

Affecter 中文名字是影响者，它用于根据子元素与其与特定1个或者多位置的距离对子元素设置样式，affecter-react 是 Affecter 的 React 版本；

- npm 页面：https://www.npmjs.com/package/affecter-react
