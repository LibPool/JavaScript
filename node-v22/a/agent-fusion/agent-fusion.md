# agent-fusion

> 标签: claude-code, codex, coding-agents, multi-model, orchestration

## 简介

One command: Claude writes, your tests check, Codex reviews, one repair. You get a verified patch in an isolated git worktree and a ledger of which agent delivers in your repo.
