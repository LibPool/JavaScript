# aws-dynasync

> 标签: AWS, api, appsync, appsync-graphql-api, database, dynamodb, graphql, schema

## 简介

Create an AWS AppSync GraphQL Api and a DynamoDB datasource with a single command. Automate the building and provisioning of a GraphQL API using a single config file with AWS AppSync and Amazon DynamoDb to store the data. The entire process is controlled
