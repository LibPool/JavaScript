# astro-lqip

> 标签: astro, astro-component, astro-integration, background, css, image, lqip, picture

## 简介

🖼️ Native extended Astro components for generating low-quality image placeholders (LQIP), compatible with `<Image>`, `<Picture>` and CSS background images.
