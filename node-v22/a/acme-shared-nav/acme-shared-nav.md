# acme-shared-nav

> 标签: JavaScript

## 简介

Spike: env-aware product link config for a shared nav / product switcher. Fixture data only (no real company names or URLs) — safe to publish publicly. Home: emitwise-v2/front-end/libs; consumed via workspace by customer-app and via npm by foreign apps.
