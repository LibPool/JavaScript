# acr-verify

> 标签: audit, ed25519, jcs, offline, receipt, revocation, rfc8785, verification

## 简介

An independent, dependency-free checker for Command Control Receipts, the signed records ALEETH Command issues. Checks the signature and, offline, revocation against a signed revocation list. Single-file browser build and a command line tool.
