# astro-xelement-next

> 标签: XElement, XElement-next, astro, astro-component, astro-ui, astro-xelement, astro-xelement-next

## 简介

XElement is a powerful Astro Web Component generator. Create your own  Astro compliant Web Components using HTML Elements with additional Client-Side JS interactivity sprinkled into the Element.
