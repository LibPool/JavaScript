# airdeploy-v3

> 标签: JavaScript

## 简介

This Node.js repository contains the configuration and deployment scripts for the Air V3 protocol core and periphery contracts. The repository makes use of `hardhat` and `hardhat-deploy` tools to facilitate the deployment of Air V3 protocol.
