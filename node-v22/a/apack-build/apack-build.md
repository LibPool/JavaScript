# apack-build

> 标签: JavaScript

## 简介

基于 [apack](http://gitlab.alipay.net/geyuhang.pt/apack) 的更快的打包构建工具, 支持 `.js, .jsx, .less, .css, .json` 文件的处理.

## 官网

- npm 页面：https://www.npmjs.com/package/apack-build
