# autoryn-cli

> 标签: agent, autoryn, bugs, cli, interactive, issue-tracker, json, project-management, tasks, tickets, tui

## 简介

Interactive + scriptable CLI to list and manage Autoryn tickets (tasks & bugs) — arrow-key pager, JSON mode, and an agent manifest for headless control.
