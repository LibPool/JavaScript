# agentblueprint

> 标签: agent-blueprint, ai, blueprint, cli, mcp, model-context-protocol

## 简介

8 MCP tools for exploring and downloading AI agent blueprints. List blueprints, get summaries, download full Agent Skills directories for implementation by coding agents. Vendor-agnostic output works with ServiceNow, Salesforce, OpenClaw, or any platform.
