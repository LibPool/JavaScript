# avelajs

> 标签: JavaScript

## 简介

Framework web server-driven para Node.js: la aplicación, su estado y sus componentes viven en el servidor; el navegador solo presenta y comunica. Incluye Express, rutas por archivo y base de datos opcional con easyormjs.
