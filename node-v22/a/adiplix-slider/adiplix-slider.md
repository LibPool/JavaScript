# adiplix-slider

> 标签: JavaScript

## 简介

Wrapper para o `VSlider` do Vuetify que aplica os padrões visuais usados pelo tema Vuexy e expõe uma API enxuta para uso isolado em qualquer projeto Vue 3 + Vuetify.
