# ada-agent-wallet

> 标签: agent-payments, ai-agents, cardano, mcp, model-context-protocol, spend-policy, wallet, x402, x402-cardano

## 简介

Out-of-process spend control for AI agents paying with x402: per-tx and rolling caps, payee allowlist, human approval, and a hash-chained audit log — enforced in a separate daemon that holds the key, not in the agent. Settles on Cardano.
