# adaptive-tests

> 标签: adaptive, ai, ai-ready, ast, automatic, broken-tests, developer-experience, developer-tools, devtools, discovery, dx, import, imports, jest, mocha, refactor, refactoring, resilient, smart, test, test-framework, test-maintenance, test-runner, testing, vitest

## 简介

Tests that don't break when you move files. Smart test discovery finds your code by understanding its structure, not hardcoded paths. Works with Jest, Mocha, Vitest.
