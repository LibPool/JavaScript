# airlock-ratelimit

> 标签: abuse, edge, middleware, nextjs, rate-limit, ratelimit, security, supabase, token-bucket

## 简介

Drop-in rate limiting for Next.js + Supabase that doesn't punish families. Keys authenticated requests by user (not shared IP), with a token bucket, zero dependencies, and an injectable clock.
