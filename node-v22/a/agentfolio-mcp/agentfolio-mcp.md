# agentfolio-mcp

> 标签: agent, agentfolio, ai-agent, claude, cursor, identity, mcp, model-context-protocol, reputation, satp, solana, trust

## 简介

MCP server for SATP (Solana Agent Trust Protocol) — query 200+ AI agent trust scores, verifications, and reputation from AgentFolio. Works with Claude Code, Cursor, and Claude Desktop.
