# agent-guard-plugin

> 标签: agent-guard, agent-safety, claude-code, guardrails, hooks, outbound-control, security

## 简介

One-command setup for the agent-guard outbound gate in Claude Code: installs the guard-hook binary, the outbound policy, and a PreToolUse hook that gates git push, npm publish, docker push, gh release, non-local HTTP mutations, and rm -rf.
