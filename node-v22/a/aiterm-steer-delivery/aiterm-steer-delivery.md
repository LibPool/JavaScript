# aiterm-steer-delivery

> 标签: ai-agents, aiterm, claude-code, codex, cursor, hooks, mcp, steer

## 简介

Aiterm's steer delivery as a library: deliver text to the parent AI session that called your MCP tool — steered into the running turn when it is busy, delivered normally when it is idle. Codex (official queue + sync hooks), Claude Code (asyncRewake hooks)
