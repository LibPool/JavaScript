# array-queryable

> 标签: array, extend, linq, plugins, query

## 简介

一个链式调用，用于处理集合的工具。并且支持插件（新的命令和功能）的注入。对于处理复杂的集合操作非常有用，大家一起来丰富它的功能吧！ 本工具对于使用orm框架查询返回的实体集合，再进行特定场景下的业务处理，将非常有用。
