# adinkra-icons

> 标签: adinkra, africa, font, ghana, icon, icon library, icon pack, symbols

## 简介

Adinkra Icons is a set of visual symbols for designers and developers. These symbols represent an historical and philosophical significance originally printed on cloth which royals wore to important ceremonies. Originating from the Gyaman people of Ghana
