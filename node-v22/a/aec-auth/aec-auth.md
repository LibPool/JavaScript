# aec-auth

> 标签: aec, aps, auth, autodesk, bim, construction, forge, nextjs, oauth, tokens, vercel-connect

## 简介

The token layer for Autodesk Platform Services (APS / ACC). One TokenSource contract, pluggable backends (Vercel Connect, Better Auth, self-hosted vault), a typed client, and a single-flight refresh that survives APS's single-use rotating refresh tokens.
