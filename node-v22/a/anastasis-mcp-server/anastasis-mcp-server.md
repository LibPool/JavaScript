# anastasis-mcp-server

> 标签: anastasis, api-discovery, attack-surface, bug-bounty, endpoint-discovery, javascript, mcp, modelcontextprotocol, pentesting, recon, security, sourcemap

## 简介

MCP server for JavaScript endpoint discovery and attack surface mapping. Discovers JS files from 23+ passive sources, extracts API endpoints via AST parsing, reconstructs sourcemaps, probes API documentation. Powered by the Anastasis engine.
