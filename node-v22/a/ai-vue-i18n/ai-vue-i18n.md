# ai-vue-i18n

> 标签: ai, internationalization, translate, vue-i18n, vue2, vue3

## 简介

基于AI的Vue项目自动化国际化工具，能够智能提取代码中的中文内容并生成多语言配置文件，简化Vue项目的i18n开发流程
