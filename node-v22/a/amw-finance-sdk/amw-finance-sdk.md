# amw-finance-sdk

> 标签: agent, eip-712, erc-20, guardrail, hedera, mandate, supervision, viem

## 简介

Sign a mandate, classify a venue, put an action to the guard, and read what it said. Composition invariants enforced before execution, on chain.
