# authevo

> 标签: 2fa, auth, authevo, one-time-password, otp, telegram, verification, whatsapp

## 简介

Official Node.js / TypeScript SDK for the Authevo verification API — WhatsApp OTP (with Telegram fallback) and TOTP two-factor.
