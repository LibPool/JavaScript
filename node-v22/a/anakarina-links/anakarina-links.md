# anakarina-links

> 标签: Markdown, links, md-Links

## 简介

Herramienta de línea de comando que permite validar las URLs dentro de archivos markdown, a partir de la ruta que recibe como argumento, analizará el archivo e imprimirá los links que encuentre.
