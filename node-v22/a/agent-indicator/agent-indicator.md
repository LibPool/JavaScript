# agent-indicator

> 标签: agent, agent-state, agent-ui, agentic, ai, ai-sdk, approval, components, hitl, human-in-the-loop, llm, react, react-components, status-indicator, tool-approval, typescript, ui, vercel-ai-sdk

## 简介

When an agent needs a person, this is the interface. React approval UI for when an agent spends money, sends messages or reaches private data. Works with Vercel's AI SDK out of the box.
