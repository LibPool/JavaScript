# army-meal

> 标签: boilerplate, cjs, demo, esm, example, npm, package, sample, starter, typescript, umd

## 简介

이 모듈은 https://openapi.mnd.go.kr 의 급식 api를 더욱 편하게 사용할 수 있도록 하는 모듈입니다. api key와 부대 번호, 메뉴를 알고 싶은 날짜만 입력하면 급식 메뉴를 간편하게 구할 수 있습니다.
