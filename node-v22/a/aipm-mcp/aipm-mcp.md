# aipm-mcp

> 标签: ai, aipm, cursor, development-tools, feature-building, http-server, ide-integration, mcp, project-management, stdio-server, task-management, time-tracking

## 简介

Complete AIPM integration for Cursor IDE - Get tasks, manage features, track time, and build features with AI. Supports both MCP stdio mode and HTTP server mode.
