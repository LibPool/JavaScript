# agent-tools-runtime-pi-extension

> 标签: agent-tools-runtime, mcp, pi-package, pi.dev

## 简介

Pi (pi.dev) extension for agent-tools-runtime: registers each real facade tool natively at load time, no pi-mcp-adapter or /mcp setup onboarding required.
