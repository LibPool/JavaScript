# ai-text-popover

> 标签: AI, AI assistant, AI tooltip, GPT, LLM, browser extension, chatbot, contextual help, developer tool, educational tool, frontend widget, glossary, groq, hover popup, inline explain, interactive UI, machine learning, natural language processing, on-page help, openai, popover, semantic popup, text explainer, text selection, web enhancement

## 简介

A lightweight, plug-and-play JavaScript utility that allows users to **select text** on a webpage and get a simple explanation for it using Groq's LLMs. Perfect for **glossary-style popovers**, educational tools, or AI-assisted documentation.
