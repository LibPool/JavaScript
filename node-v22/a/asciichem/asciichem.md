# asciichem

> 标签: JavaScript

## 简介

TypeScript implementation of AsciiChem — parse ASCII chemistry into a semantic model and render Text, SVG, and canonical JSON wire form. Conformant with asciichem-model v1 and the asciichem-tests corpus.
