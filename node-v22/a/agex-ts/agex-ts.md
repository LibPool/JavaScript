# agex-ts

> 标签: agent, ai-agent, browser, code-execution, llm, sandbox, tool-use, typescript

## 简介

Embeddable LLM-work primitive: typed-function task contract, code as the action space, kvgit-backed state. TypeScript port of agex-py.
