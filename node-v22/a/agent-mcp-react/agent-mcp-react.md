# agent-mcp-react

> 标签: agent, ai-agent, browser, llm, mcp, model-context-protocol, react, tool-calling, tools, webmcp, websocket

## 简介

Expose a running React application as an MCP server over an authenticated WebSocket transport — a second control interface onto one application, not browser automation.
