# axon-runtime

> 标签: ai-agents, coding-agent, distributed, llm, multi-agent, worker

## 简介

Distributed worker runtime that dispatches goal-shaped coding jobs to AI agent workers in disposable git worktrees over authenticated SSH tunnels.
