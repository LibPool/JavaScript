# arale-dialog

> 标签: alert, confirmbox, modal, overlay, widget

## 简介

Dialog 是通用对话框容器，提供显隐关闭、遮罩层、内嵌iframe、内容区域自定义以及模态对话框等功能。

## 官网

- 源码仓库：git+ssh://git@github.com/aralejs/dialog.git
- npm 页面：https://www.npmjs.com/package/arale-dialog
