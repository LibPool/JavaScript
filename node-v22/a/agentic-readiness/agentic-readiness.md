# agentic-readiness

> 标签: a2a, agentic, ai-agents, ci, llms, mcp, openapi, robots.txt, seo

## 简介

Check what a website exposes to AI agents, and whether each published technology is implemented correctly. Runs in CI; fails the build only on defects, never on absence.
