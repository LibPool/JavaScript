# amonitor

> 标签: apm, error-reporting, error-tracking, exceptions, monitoring, nodejs, observability, tracing

## 简介

Error tracking and performance tracing client for Node.js — reports uncaught exceptions, breadcrumbs and request traces to a node-monitor instance
