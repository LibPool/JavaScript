# auth-record-kit

> 标签: auth, component, getPhoneNumber, login, miniprogram, record, wechat, wx.cloud

## 简介

微信小程序可复用登录 + 记录组件包：手机号/微信一键授权登录、登录态维护与刷新、通用数据记录 SDK 与 UI 组件。基于微信云开发，零自建服务器即可复用。
