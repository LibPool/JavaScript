# agent-witness-protocol

> 标签: audit, dsse, in-toto, provenance, schema, tamper-evident, verifiable, witness

## 简介

Open schema and verifier for the Agent Witness Protocol (AWP) — tamper-evident, customer-keyed, offline-verifiable witness records. Verify a receipt without trusting, or asking, the producer.
