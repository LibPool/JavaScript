# awesome-auth-input

> 标签: 2fa, accessible, auth-code, headless, one-time-password, otp, pin-input, react, two-factor-authentication, typescript, verification-code

## 简介

A headless, accessible, and fully-typed React component for OTP/auth code inputs with support for numeric, alphabetic, and custom validation patterns.
