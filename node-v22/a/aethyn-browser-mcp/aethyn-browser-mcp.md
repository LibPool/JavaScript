# aethyn-browser-mcp

> 标签: aethyn, ai-agent, browser-automation, geo-targeting, mcp, model-context-protocol, playwright, proxy, residential-proxy, sticky-session, web-scraping

## 简介

MCP server that drives a local Playwright browser through residential proxies — the AI agent picks the country/city and holds one sticky identity per task. Defaults to Aethyn; works with any HTTP proxy.
