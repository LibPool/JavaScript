# autofill

> 标签: autofill, clone, copy, fill, jquery, jquery-plugin, overwrite, plugin, textarea, textbox

## 简介

Autofill is a light weight jQuery plugin for autofilling textboxes or textareas from another textboxes or textareas.

## 官网

- 官网：https://github.com/harshen/jquery-autofill
- npm 页面：https://www.npmjs.com/package/autofill
