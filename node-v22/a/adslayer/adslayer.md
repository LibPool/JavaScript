# adslayer

> 标签: active-directory, code-mode, group-policy, ldap, mcp, model-context-protocol

## 简介

An MCP server that lets an AI agent read and change on-premises Active Directory, by writing short scripts that run in a sandbox. Runs on Windows as the logged-on user. Tools: docs, search, execute.
