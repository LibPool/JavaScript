# alliotools-mcp

> 标签: calculator, converter, local, mcp, model-context-protocol, no-telemetry, offline, pdf, pdf-tools, privacy, tools, utilities

## 简介

Privacy-first MCP server for allio Tools — 106 utilities that run entirely on your machine. Calculators, converters, developer tools, text, date/time, health, fun, and PDF tools.
