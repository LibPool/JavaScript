# ai-cli-chat-export

> 标签: ai, backup, chat, claude-code, cli, codex, conversation, export, opencode

## 简介

One-command exporter for local CLI AI conversation history — Claude Code, Codex CLI, opencode, Gemini/Qwen CLI. Zero runtime dependencies, read-only. (Web chats: see the companion userscript project.)
