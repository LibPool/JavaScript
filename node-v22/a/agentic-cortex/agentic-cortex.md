# agentic-cortex

> 标签: agent-context, ai-agent, codebase-graph, knowledge-graph, memory, rag, semantic-memory

## 简介

Persistent self-improving agent memory with tree-of-thoughts reasoning: MCTS/beam search, PRM step verification, self-consistency voting, s1 budget forcing, REPL program-aided reasoning, reflexion self-correction, failure classification, experience replay
