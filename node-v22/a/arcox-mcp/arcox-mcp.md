# arcox-mcp

> 标签: agent, arc, arcox, cctp, circle, dex, mcp

## 简介

ARCOX DEX MCP server and terminal agent with Hermes/Claude remote OAuth MSCA support, local EOA/SCA execution, and quote-before-execute safety for swap, bridge, send, ARCOX Pay invoices, balances, history, retry bridge, and agentic jobs.
