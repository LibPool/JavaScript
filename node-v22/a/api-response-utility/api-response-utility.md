# api-response-utility

> 标签: api, async-handler, error-handling, express, http, json, middleware, node, nodejs, pagination, response, rest, status-codes, typescript, utility

## 简介

Production-ready standardized API response utility for Node.js/Express: success & error formatters, HTTP status code constants, pagination helper, async error handling, custom error classes, and full TypeScript support.
