# apex-psi-verifier

> 标签: ai-governance, apex, apex-psi, ed25519, eu-ai-act, merkle-tree, post-quantum, provenance, psi, rfc8785, sha256, verification, verifier

## 简介

MIT-licensed verifier for the PSI-SEAL/1 canonical seal schema. Verification is free forever; a seal whose Ed25519 signature was not checked is never reported as a pass.
