# aegis-chain-sol

> 标签: agent, ai-agent, cross-chain, ed25519, post-quantum, self-custody, solana

## 简介

Aegis Vault Solana adapter — deterministically derive a Solana keypair (ed25519) from an agent's PQC root identity, with base58 address and message signing. Private keys never leave the agent/browser.
