# aqi-calculator

> 标签: AQI, Air Pollution, cjs, es6, javascript, js, umd

## 简介

aqi-calculator is an NPM package that allows you to calculate Air Quality Index (AQI) with the help of pollutant concentrations ranging from PM 2.5, PM 10, SO2, NOX, O3 and CO.
