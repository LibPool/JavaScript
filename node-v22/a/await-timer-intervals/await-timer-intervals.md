# await-timer-intervals

> 标签: async, delay, interval, promise, timer, utils

## 简介

Lightweight and promise-based **timer utilities** built with `setTimeout` and `setInterval`.   Useful for async/await delays and repeatable intervals in modern JavaScript/TypeScript projects.
