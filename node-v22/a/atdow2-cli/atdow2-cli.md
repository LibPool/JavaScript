# atdow2-cli

> 标签: JavaScript

## 简介

itcast -h|--help查看使用帮助 itcast-V|--version 查看工具的版本号 itcast list 列出所有可用模板 itcast init <template-name> <project-name>基于指定的模板进行项目初始化
