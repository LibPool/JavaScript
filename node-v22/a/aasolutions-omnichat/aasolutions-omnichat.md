# aasolutions-omnichat

> 标签: bot, chat, gchat, messaging, multichannel, omnichannel, sdk, slack, teams, telegram, whatsapp

## 简介

Direct omnichannel chat SDK for Node/TypeScript — Telegram, Slack, Google Chat, Teams, WhatsApp. No server needed — install, connect your channels, handle messages.
