# agent-quality-loop

> 标签: agent, ai, claude, code-quality, cursor, eslint, mcp, prettier, typescript

## 简介

MCP server that guides AI agents to produce clean, policy-compliant code — runs ESLint, TypeScript, Prettier, AI security analysis (free via Groq), unused-code detection, dependency checks and more.
