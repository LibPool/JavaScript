# agent-debug-mcp

> 标签: chrome-extension, devtools, mcp, model-context-protocol, playwright, react, tanstack, vite-plugin

## 简介

Agent Debug MCP: local MCP server (stdio + streamable HTTP) bridging the Agent Debug MCP Chrome extension to coding agents, with built-in browser automation (embedded Playwright MCP re-exported as page_* tools), a CDP endpoint for external Playwright clie
