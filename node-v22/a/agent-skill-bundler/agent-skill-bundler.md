# agent-skill-bundler

> 标签: agent-skills, claude-code, cli, codex, converter, skills

## 简介

Port Claude Code skill plugins to other agent platforms — Codex is the implemented target, with a target-agnostic pipeline ready for more adapters. Produces namespace-prefixed flat skills, inlined shared includes, cross-plugin reference rewriting, and sel
