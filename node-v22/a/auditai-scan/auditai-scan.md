# auditai-scan

> 标签: audit, authorization, idor, multi-tenant, nextjs, rls, sast, security, supabase, vibe-coding

## 简介

Deterministic security scanner for Next.js + Supabase apps: cross-tenant reads, RLS gaps, service-role misuse, mass assignment. No account, no model, seconds.
