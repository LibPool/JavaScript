# apigeetoopenapi

> 标签: api-documentation, api-spec, apigee, apigee2openapi, apigeetoopenapi, apigeex2openapi, array-parameters, cli-tool, extractvariables, json-schema, nested-objects, openapi, proxy-bundle, swagger

## 简介

A powerful CLI tool that converts Apigee Proxy Bundles into OpenAPI 3.0.0 specifications with support for nested JSON, array parameters, multiple auth types, and modular architecture.
