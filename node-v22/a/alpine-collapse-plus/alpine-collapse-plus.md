# alpine-collapse-plus

> 标签: Alpine, Alpine Collapse, Alpine Collapse Plus, Alpine JS, Alpine JS Plugin, Alpine JS Plugins

## 简介

An Alpine JS plugin that replaces the collapse directive. It seperates transform and opacity animations for a more seamless transition.
