# anime365wrapper

> 标签: anime, anime365, api, client, esm, nodejs, openapi, smotret-anime, tus, typescript, wrapper

## 简介

Full ESM TypeScript client for the anime365 API (smotret-anime.app / anime365.ru): catalog, translations, video/subtitle links, auth and tus video upload — matches the official OpenAPI spec
