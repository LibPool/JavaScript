# affix-prompt

> 标签: affix, pi, pi-extension, pi-package, prompt, sticky, tui

## 简介

pi 扩展：transcript 中「用户输入消息」的 Affix 吸顶（类似 antd Affix），统一 maxRows 缩略模型，fullscreen TUI 模式
