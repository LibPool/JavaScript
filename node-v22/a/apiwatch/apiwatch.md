# apiwatch

> 标签: audit, cli, http, retry, static-analysis, timeout, typescript

## 简介

A CI guard for outbound HTTP calls in Node and TypeScript: fails the build on new calls with no timeout, and reports missing retry and response validation. Static, never runs your code.
