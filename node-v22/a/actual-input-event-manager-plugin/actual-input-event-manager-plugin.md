# actual-input-event-manager-plugin

> 标签: angular, dirty, form, ie, input

## 简介

Internet Explorer 10+ implements 'input' event but it erroneously fires under various situations, e.g. when placeholder changes, or a control is focused. This plugin prevents an otherwise pristine field from being dirtied in this cases.
