# agy-indicator

> 标签: agy, cordis, deepseek-harness, dsh, indicator, status-light

## 简介

agy 状态灯（家级）：收集各会话 agy-first-bridge 推送的 agy 运行状态，经 webServer HTTP 路由暴露给浏览器，在会话标题栏按项目（工作目录）分别显示状态灯。随软件启动、所有会话自动可见。标准 npm 分发形态：host 半用裸包名（main → lib/index.mjs），client 半靠 dsh.client 声明自动纳入浏览器。
