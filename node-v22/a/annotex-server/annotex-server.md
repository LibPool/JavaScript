# annotex-server

> 标签: annotation, annotex, collaboration, comments, inline-comments, obsidian, publishing, self-hosted

## 简介

Self-hosted inline-commenting server for published notes — the backend for the Annotex Obsidian plugin. Invited colleagues highlight text and leave anchored comments (with LaTeX); the data stays on your own server.
