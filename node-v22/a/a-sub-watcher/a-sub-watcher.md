# a-sub-watcher

> 标签: claude, claude-code, dashboard, observability, sub-agent, watcher

## 简介

Live dashboard for Claude Code sub-agents. Parent-child hierarchy, suspended/running status, token counts, and turn-by-turn breakdown (thinking/tool-call/output)—real-time, read-only.
