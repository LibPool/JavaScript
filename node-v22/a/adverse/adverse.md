# adverse

> 标签: adversarial, ai, claude, claude-code, code-review, codex, llm, multi-agent, review, skill

## 简介

Multi-agent adversarial code review for any coding agent. Single model, three lenses, two rounds. Ships as both a CLI and a Claude Code Skill.
