# aws-sigv4-mcp-proxy

> 标签: aws, bedrock-agentcore, iam, mcp, model-context-protocol, proxy, sigv4

## 简介

Bridge plain-HTTP or stdio MCP clients to AWS SigV4-gated MCP endpoints (Bedrock AgentCore, API Gateway, Lambda Function URLs).
