# agent-tictactoe

> 标签: agent, ai-agent, claude, claude-code, cli, game, minimax, noughts-and-crosses, skill, terminal, tic-tac-toe, tictactoe

## 简介

Tic-tac-toe in the terminal for humans and AI agents: interactive play for people, a JSON command interface for agents, plus CLAUDE.md and SKILL.md so coding agents know how to play.
