# axios-wrapper-pro

> 标签: Axios, 响应拦截, 自动取消, 请求去重, 请求拦截, 请求重试

## 简介

基于 Axios 的增强型 HTTP 客户端，支持请求去重、自动取消、重试机制和可配置拦截器
