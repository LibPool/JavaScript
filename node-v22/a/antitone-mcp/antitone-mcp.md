# antitone-mcp

> 标签: a-share, antitone, finance, mcp, modelcontextprotocol, news

## 简介

Antitone 情报 API 的本地 MCP Server（stdio 传输）：让 Claude Desktop / Cursor / Cline 等 agent 直接查询新闻、行情、板块题材、龙虎榜、早晚报、回测与用量。全部工具只读，单次返回硬截断 32 KB。
