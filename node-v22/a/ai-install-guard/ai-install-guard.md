# ai-install-guard

> 标签: claude, claude-code, mcp, plugins, security, skills, static-analysis, supply-chain

## 简介

A pre-install security gate for Claude Code: scans plugins, mods, skills and MCP servers without running them, and installs nothing until you approve.
