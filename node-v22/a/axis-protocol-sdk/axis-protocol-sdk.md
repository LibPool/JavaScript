# axis-protocol-sdk

> 标签: agent-identity, axis, axis-protocol, did, ed25519, sdk

## 简介

Reference SDK for the AXIS protocol. Agent identity, signing, and registry operations. Zero runtime dependencies; runs in Node 20+, Cloudflare Workers, and modern browsers.
