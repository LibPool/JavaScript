# auto-clear-cache

> 标签: angular, auto reload, browser storage, cache, cache buster, clear cache, javascript, pwa, react, svelte, update detector, versioning, vite, vite plugin, vue

## 简介

Automatically detects new app versions, clears browser caches & storages, and reloads to ensure users always get the latest deployment.
