# appatlas

> 标签: architecture, cli, code-intelligence, dashboard, nestjs, observability, prisma

## 简介

Architecture observability for JS/TS backends — scan your NestJS + Prisma app into an interactive local dashboard. No AI, no API keys, 100% local.
