# aitestuirunner

> 标签: JavaScript

## 简介

Runner 通过最小权限 Token 访问 `/api/v1/runner/*`。本地 Runner 使用项目共享 Token；云 Runner 使用管理员创建、仅显示一次的云 Runner Token。

## 官网

- npm 页面：https://www.npmjs.com/package/aitestuirunner
