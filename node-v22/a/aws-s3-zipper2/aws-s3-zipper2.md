# aws-s3-zipper2

> 标签: amazon, aws, s3, zip

## 简介

Zip files from and to an Amazon AWS S3 Bucket directory as a stream, file or fragments. Allows filtering files. Modified for Lambda from https://github.com/DanielHindi/aws-s3-zipper
