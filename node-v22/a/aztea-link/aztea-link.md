# aztea-link

> 标签: agent-to-agent, agents, claude, codex, mcp, model-context-protocol, relay

## 简介

Cross-machine event relay for AI agents (Claude Code, Codex, Gemini CLI, …) — typed rooms, games, and a live spectator web UI.
