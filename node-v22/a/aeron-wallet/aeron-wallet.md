# aeron-wallet

> 标签: agent, mcp, micropayments, robinhood-chain, stablecoin, usdg, wallet, x402

## 简介

Non-custodial agent wallet for Robinhood Chain. Pays x402 requests in USDG. Ships as a CLI and an MCP server.

## 官网

- 官网：https://aeron.sh/wallet/
- 源码仓库：git+https://github.com/aeronlabs/aeron-wallet.git
