# apr-constant

> 标签: async, async-await, await, awaitful, constant, control, control-flow, es2015, es2016, es2017, es6, es7, es8, flow, promise, promises

## 简介

Returns a promise that when called, then's with the values provided. Useful as the first function in a waterfall.
