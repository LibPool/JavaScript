# agent-lore

> 标签: agent, claude, claude-code, cli, codex, knowledge-base, memory, wiki

## 简介

A persistent, private, self-growing knowledge lore for Codex and Claude Code — install once, and every session reads and writes back to your own private GitHub repo.
