# arca-epg-payment-gateway-armenia

> 标签: acba, arca, armenia, armenian, ashib, binding, card, epg, gateway, ineco, payment

## 简介

ARCA EPG (Electronic Payment Gateway) client for Armenian banks — ACBA, ASHIB, INECO and all arca.am partners. Supports card binding.
