# aria-snapshot

> 标签: a11y, accessibility, aria, aria-snapshot, playwright, yaml

## 简介

Playwright's ariaSnapshot (accessibility-tree walk + YAML renderer) as a standalone, pure-DOM package. Runs in any page context — no CDP, no Playwright runtime.
