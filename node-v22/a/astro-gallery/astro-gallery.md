# astro-gallery

> 标签: astro, astro-component, astro-integration, exif, gallery, gdpr, image-optimization, images, leaflet, lightbox, map, photos, timeline, withastro

## 简介

Folder-driven image galleries for Astro: a responsive grid with lightbox, an EXIF-date timeline, and a GDPR-friendly photo map — all powered by astro:assets.
