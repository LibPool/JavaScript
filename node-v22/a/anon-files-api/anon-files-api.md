# anon-files-api

> 标签: anonfiles, api

## 简介

This unofficial Nodejs API was created to make uploading and downloading files from <anonfiles.com> simple and effective for programming in Nodejs. The goal of the project is to create an intuitive library for anonymous file sharing.
