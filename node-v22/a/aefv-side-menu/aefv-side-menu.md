# aefv-side-menu

> 标签: do-not-use

## 简介

AEFV Side Menu es un componente de Angular que proporciona un menú lateral personalizable para tus aplicaciones. Facilita la navegación y mejora la experiencia del usuario con un diseño moderno y responsivo.
