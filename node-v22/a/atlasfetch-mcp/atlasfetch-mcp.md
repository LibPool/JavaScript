# atlasfetch-mcp

> 标签: administrative-boundaries, geocoding, geofencing, geojson, gis, iso-3166, mcp, modelcontextprotocol, point-in-polygon, reverse-geocoding

## 简介

MCP server for AtlasFetch — reverse geocode a coordinate to its country, region and municipality (ISO 3166 codes), and match it against your own geofences.
