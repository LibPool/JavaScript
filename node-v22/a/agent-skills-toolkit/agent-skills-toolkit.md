# agent-skills-toolkit

> 标签: agent-skills, claude-code, cli, codex, conformance, linter, plugin, skills

## 简介

A deterministic, portable gate that grades an agent skill library (Claude Code and Codex plugins) against the Advanced Skill Library Standard and reports the Bronze/Silver/Gold tier it earns.
