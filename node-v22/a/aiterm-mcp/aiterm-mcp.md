# aiterm-mcp

> 标签: agent, ai-agent, claude, claude-code, codex, codex-cli, cursor, devtools, grok, interactive-cli, mcp, mcp-server, model-context-protocol, persistent-terminal, pty, ssh, terminal, terminal-mcp, tmux

## 简介

Persistent terminal MCP with one harness-based launcher for Claude Code, Codex CLI, Grok CLI, and Cursor Agent CLI, plus durable PTYs for SSH, containers, and REPLs.
