# ai-coding-stack

> 标签: agents-md, ai, antigravity, claude-code, codex, coding-agents, context7, cross-platform, cursor, developer-tools, kimi, mcp, opencode, project-scaffolding, windsurf, zai-code, zcode

## 简介

Portable toolkit for AI coding tools (Claude Code, Codex, Antigravity, opencode, Cursor, Windsurf, ZAI Code, Kimi): a first-run wizard installs them + configures Context7 MCP + the in-tool project-init command, and scaffolds any project with cross-tool AG
