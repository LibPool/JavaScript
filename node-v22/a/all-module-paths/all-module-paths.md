# all-module-paths

> 标签: bin, bin-paths, binaries, developer-experience, development, dx, global, global-modules, hela, javascript, local, local-modules, module, module-paths, npm, package-paths, packages, paths, pnpm, tunnckocore-oss, tunnckocorehq, utils, yarn

## 简介

Get all possible javascript (npm/yarn/pnpm) global or local, binaries or packages paths, e.g. node_modules and node_modules/.bin. Also works for those using NVM or such
