# axios-cookie-auth

> 标签: api, auth, authentication, axios, cookie, cookies, http-client, httpOnly, javascript, refresh, retry, token, typescript

## 简介

A lightweight Axios helper for managing httpOnly cookies and automatic token refresh with retries in TypeScript.
