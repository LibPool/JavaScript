# aurelia-auth-ld

> 标签: aurelia, auth, authentication, oauth

## 简介

Plugin for security token service, social media authentication and local authentication together with other authentication utilities, forked from https://github.com/paulvanbladel/aurelia-auth, with addition support for no-popup.
