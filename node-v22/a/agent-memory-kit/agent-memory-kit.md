# agent-memory-kit

> 标签: agent, codex, codex-cli, hooks, knowledge-base, llm, memory

## 简介

A file-based long-term memory layer for Codex CLI: human-readable markdown cards, per-session index injection, on-demand recall, and human-reviewed consolidation. 给 Codex 装一层看得见、改得动、管得住的长期记忆。
