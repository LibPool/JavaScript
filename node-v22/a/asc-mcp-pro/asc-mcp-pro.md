# asc-mcp-pro

> 标签: anthropic, app-store-connect, appstore, claude, ios, mcp, model-context-protocol, testflight

## 简介

MCP server exposing 191 tools across the App Store Connect API — apps, versions, builds, TestFlight, IAP/subscriptions, pricing, screenshots, certs, reports, plus high-level workflow macros and a declarative workflow runner.
