# appmixer

> 标签: JavaScript

## 简介

The command-line interface to the [Appmixer](https://www.appmixer.com) engine. It covers the full Appmixer API surface — flows, components, accounts, users, data stores, logs, system administration — and the complete *connector development lifecycle*: sca
