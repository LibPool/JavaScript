# arbo-ocr-js

> 标签: bun, document-ai, ocr, onnx, onnxruntime, paddleocr, pp-ocrv6, text-detection, text-recognition, typescript

## 简介

Node.js and Bun wrapper for arboOCR — runs the prebuilt arboocr_demo binary as a subprocess, no C++ build required.
