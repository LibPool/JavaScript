# anteroom

> 标签: anteroom, claude-code, cli, game, terminal, tui

## 简介

Anteroom CLI — play quick turn-based games (RPS, Four in a Row, Reversi, Blackjack, Craps, Roulette, Slots) for play-money chips while a long task runs.
