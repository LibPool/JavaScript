# avu-kit

> 标签: JavaScript

## 简介

`avu-kit` 是一个基于 Vue 3 和 TypeScript 的后台管理插件，基于 Element Plus 进行二次封装，提供了内置的后台布局、404 页面、常用通用组件（如表格组件、弹窗组件）以及路由鉴权功能，旨在帮助开发者快速搭建后台管理系统。
