# analytics-bridge

> 标签: analytics, clarity, consent, event-tracking, ga4, gdpr, google-analytics, gtag, microsoft-clarity, nextjs, react, segment, telemetry, tracking, twilio-segment, typescript

## 简介

Provider-independent analytics for React and Next.js. One typed API for Google Analytics 4, Twilio Segment, Microsoft Clarity and custom providers, with consent management, batching and plugins.
