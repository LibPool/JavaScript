# angular-capacitor-workspace

> 标签: angular, capacitor, generator, npm-audit, playwright, schematics, storybook

## 简介

Schematics, dependency policy and audit gate for an Angular workspace that ships as a web app, a Capacitor mobile app, a prerendered marketing site and shared libraries.
