# aurebesh

> 标签: angular, code-highlighting, contenteditable, custom-element, editor, html-sanitizer, image-upload, react, rich-text, rich-text-editor, table, vue, web-component, wysiwyg

## 简介

A lightweight, dependency-free WYSIWYG editor for the web. Rich text, tables, code blocks, images and video, with pluggable uploads. Works in React, Vue, Angular or plain HTML.
