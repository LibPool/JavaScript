# astpack

> 标签: ast, claude, cli, codebase, context, gpt, llm, mcp, prompt, repomix, skeleton, tokens, tree-sitter

## 简介

Compress a codebase into an LLM-ready prompt by stripping function bodies with Tree-sitter (Skeleton Mode).
