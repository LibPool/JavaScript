# argus-xdrs-governance

> 标签: adr, ai-agents, argus, decision-records, governance, seeds, xdrs

## 简介

ARGUS collective governance system (30 seeds) integrated with XDRS decision records. Provides deliberation protocol, seed definitions, and structured policy archiving for any project.
