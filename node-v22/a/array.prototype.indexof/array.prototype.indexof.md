# array.prototype.indexof

> 标签: Array.prototype.indexOf, ES5, array, es-shim API, indexOf, polyfill, shim

## 简介

An ES2015 spec-compliant `Array.prototype.indexOf` shim/polyfill/replacement that works as far down as ES3.
