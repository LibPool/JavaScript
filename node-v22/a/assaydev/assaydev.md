# assaydev

> 标签: agent-skills, ai-agents, ci, claude, linter, llm, mcp, model-context-protocol, quality

## 简介

The open-source quality gate for everything you feed an AI agent: skills, MCP servers, and context files. Lighthouse-style grades, actionable fixes, CI gating, and README badges. Fully local, zero accounts.
