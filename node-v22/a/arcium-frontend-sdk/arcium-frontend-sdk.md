# arcium-frontend-sdk

> 标签: arcium, frontend, sdk, solana, typescript

## 简介

TypeScript SDK for encrypted Solana apps with Arcium: derive PDAs, encrypt user inputs, build encrypted instructions, manage compute/priority fees, and verify SignedComputationOutputs.
