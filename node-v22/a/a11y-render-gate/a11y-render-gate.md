# a11y-render-gate

> 标签: a11y, accessibility, agent, claude-code, contrast, mcp, playwright, wcag

## 简介

An accessibility gate inside the agent loop. Renders the UI an agent just wrote and reports contrast, focus visibility, hit targets and label wiring as computed facts with fix-shaped payloads.
