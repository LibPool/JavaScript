# ask-later

> 标签: async, claude-code, coding-agent, hooks, human-in-the-loop, inbox, pending, queue, unattended, 無人, 非同期

## 简介

Async question queue for Claude Code hooks: the agent shelves questions in PENDING.md, your one-line answers in INBOX.md are injected on the next tool call, and the stop is blocked (twice by default) while lines are unread. — 聞いて、待たずに進む。Claude Code 用の非同期の
