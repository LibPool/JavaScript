# apostrophe-tiptap-rich-text-widgets

> 标签: apostrophe, apostrophecms, tiptap

## 简介

Wrapper allowing the use of the tiptap vue-based rich-text editor for Apostrophe 2.x. In 3.x it will be standard equipment.
