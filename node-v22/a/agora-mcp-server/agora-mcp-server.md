# agora-mcp-server

> 标签: agora, ai-agents, e-commerce, mcp, model-context-protocol, product-search

## 简介

MCP server for Agora's open agent-commerce protocol. Search 22.5k+ products across 52 stores, build carts, and run consumer-approved checkouts. Stdio transport. Compatible with Claude Desktop, Cursor, ChatGPT.
