# ai-sdk-provider-forge

> 标签: ai-sdk, conductor, forge, llm-router, openai-compatible, opencode

## 简介

AI SDK v6 provider for the forge Conductor auto-router: renders Conductor's routing decision, live orchestration tree, and running cost inline as an OpenCode reasoning (thinking) block, with a graceful text fallback for plain OpenCode.
