# authkey.io

> 标签: authkey, calling, cpaas, sip, voice, webrtc

## 简介

Unified voice calling SDK for the Authkey platform — one authkey, one call() API, browser (WebRTC) and Node.js (SIP/WebRTC via werift) auto-detected.
