# ajv-validation-mcp

> 标签: JavaScript

## 简介

This project provides a minimal [Model Context Protocol (MCP)](https://modelcontextprotocol.io/quickstart/server#node) server for validating JSON data against JSON Schema using [AJV](https://ajv.js.org/).
