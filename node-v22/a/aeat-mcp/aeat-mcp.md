# aeat-mcp

> 标签: aeat, autonomos, fiscal, hacienda, irpf, iva, mcp, model-context-protocol, spain, tax, vat

## 简介

MCP server for Spanish AEAT tax reference data — IRPF brackets, VAT rates, fiscal calendar, tax form catalog, and more. 100% official sources (BOE, AEAT).
