# accessible-color-palette

> 标签: a11y, accessibility, color, contrast, mcp, monochrome, palette, wcag

## 简介

Generate WCAG 2.2 AA monochromatic palettes from a single hex color. Ships as a TypeScript library and as an MCP server for AI assistants.
