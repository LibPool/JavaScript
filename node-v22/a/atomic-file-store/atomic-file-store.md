# atomic-file-store

> 标签: atomic, atomic-write, compare-and-swap, concurrent, config, cross-process, effect, file, json, json-file, multi-process, optimistic-concurrency, race-condition, read-modify-write, session, store, typescript

## 简介

Atomic read-modify-write for local JSON files. Compare-and-swap optimistic concurrency across processes — no lockfiles, no merges.
