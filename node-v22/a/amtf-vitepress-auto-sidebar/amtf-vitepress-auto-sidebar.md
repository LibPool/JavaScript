# amtf-vitepress-auto-sidebar

> 标签: auto-sidebar, sidebar, vite, vitepress, 指定可以忽略的文件类型

## 简介

给vitepress项目自动生成侧边栏目录，在原的基础上增加了可以指定 忽略后缀名 的选项 用法： ```ts   vite: {     plugins: [AutoSidebar({ prefix: '.', collapsed: false ,忽略后缀名:[".vue",".js"]})],   }, ``` 原项目：https://github.com/QC2168/vite-plugin-vitepress-auto-sidebar
