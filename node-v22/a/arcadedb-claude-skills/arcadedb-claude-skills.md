# arcadedb-claude-skills

> 标签: JavaScript

## 简介

Claude Code plugin for ArcadeDB: zero-config graph context per project, agent memory (decisions/insights/sessions), code indexer, Obsidian vault sync, slash commands. One package, pre-bundled hooks.
