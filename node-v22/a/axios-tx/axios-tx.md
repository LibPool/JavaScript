# axios-tx

> 标签: abort axios, axios transaction, axios tx, axios-tx, cancel axios, cancel multiple axios requests

## 简介

Use this to cancel multiple/nested axios rest operations at once, by using the returned axios instance's REST API (get, post, etc) and instance.cancel function
