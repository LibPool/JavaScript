# ayz-ui

> 标签: ayzenberg, design-system, react, storybook, tailwindcss, typescript, ui-components

## 简介

ayz-ui is Ayzenberg's shared UI library, combining foundational style variables, typography, and reusable components built with Tailwind and ShadCN for a consistent and efficient frontend experience.
