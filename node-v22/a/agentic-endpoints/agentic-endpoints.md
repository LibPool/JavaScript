# agentic-endpoints

> 标签: agent-payments, ai-agents, base, exactly-once, idempotency, mcp, usdc, x402

## 简介

Client for agentic-endpoints: run an action exactly once across a fleet of AI agents, paid per call in USDC on Base via x402.
