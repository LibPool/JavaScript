# anipub

> 标签: anime, anime-api, anipub, api, characters, genre, japanese-animation, jikan, mal, manga, myanimelist, search, streaming, voice-actors

## 简介

A full-featured JavaScript/TypeScript client for the AniPub Anime API — search, browse by genre, get streaming links, MAL data, characters & voice actors.
