# attest-verifier

> 标签: digital-goods, digital-ownership, drm-free, ed25519, offline-verification, receipts, verifier

## 简介

Offline verifier for attest: durable, portable proof the buyer holds; the seller signs a receipt, the buyer keeps the file, anyone verifies offline after the store is gone.
