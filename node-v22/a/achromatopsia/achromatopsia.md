# achromatopsia

> 标签: accessibility, achromatopsia, color-blindness, colorblind, cvd, grayscale, luminance, monochromacy

## 简介

Simulate total color blindness (achromatopsia / complete monochromacy) — collapse a color or an image to its WCAG luminance. Built on the OpticQuiz engine.

## 官网

- 官网：https://opticquiz.com/
- 源码仓库：git+https://github.com/vince-gonzalez/opticquiz.com.git
- npm 页面：https://www.npmjs.com/package/achromatopsia
