# android-dialog-lib

> 标签: alert, android, confirm, dialog, javascript, material-design, popup, prompt, toast, ui

## 简介

Todo lo necesario para crear interfaces con estilo Material Design 3. Incluye: diálogos, promesas, campos de entrada, notificaciones, selectores (radio y casillas), estados de carga y temas dinámicos.
