# astro-strict-csp

> 标签: astro, astro-integration, content-security-policy, csp, security, shiki, sri, strict-csp, subresource-integrity, withastro

## 简介

Zero-dependency Astro integration for strict Content Security Policy (zero 'unsafe-inline'), inline style and script extraction, bundling, Subresource Integrity (SRI) hashing, and CSP enforcement.
