# apk-revise

> 标签: APK, Android, meta-data, 渠道包

## 简介

用于反编译APK文件，修改资源文件后重新打包、签名。目前主要用途用于修改AndroidManifest.xml的meta-data数据（添加渠道等信息），也可用于其他修改。
