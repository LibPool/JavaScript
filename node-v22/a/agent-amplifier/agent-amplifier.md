# agent-amplifier

> 标签: agents, ai, ai-reliability-engineering, amplifier, claude-code, qualixar, runtime

## 简介

Runtime amplification for AI coding agents. Same product as the PyPI package — npm install bootstraps the Python package via pipx so `npm install -g` and `pip install` both yield a working `agent-amp` CLI.
