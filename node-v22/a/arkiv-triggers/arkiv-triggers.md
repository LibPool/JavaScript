# arkiv-triggers

> 标签: arkiv, expiry, telegram, triggers, webhook, worker

## 简介

Database triggers for Arkiv: when an entity expires or a time arrives, open-source workers send a Telegram message, call a webhook or record a receipt, and sign a receipt anyone can check.
