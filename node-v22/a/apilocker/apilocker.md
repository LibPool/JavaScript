# apilocker

> 标签: anthropic, api-keys, cli, credentials, encryption, env, environment-variables, mcp, oauth, openai, proxy, rotation, secrets, stripe, vault

## 简介

Replace your .env file with one token. Encrypted vault, auto-rotating tokens, and a smart proxy for every API your app talks to.
