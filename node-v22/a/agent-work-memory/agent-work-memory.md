# agent-work-memory

> 标签: changelog, claude-cli, cli, decision-tracking, developer-tools, feature-tracking, issue-tracking, project-management, session-tracking, sqlite, work-memory

## 简介

SQLite-based CLI tool for tracking work sessions, changelog entries, features, decisions, and issues across multiple projects. Integrates with Claude CLI for automated session capture.
