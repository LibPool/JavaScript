# air-datepicker-amd

> 标签: customizable, datepicker, plugin, powerful, timepicker

## 简介

Lightweight customizable cross-browser jQuery datepicker, built with es5 and css-flexbox. Forked from http://t1m0n.name/air-datepicker/ and refined it to support AMD and fixed some bugs.
