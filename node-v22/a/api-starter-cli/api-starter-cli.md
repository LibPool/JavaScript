# api-starter-cli

> 标签: cli, express, layered-architecture, mongodb, mongoose, mysql, node, postgresql, project-initializer, scaffolding, sequelize, sqlite, templates

## 简介

Una CLI interactiva para inicializar proyectos Node.js con Express, plantillas con capas, y opciones de base de datos (MongoDB/Sequelize).
