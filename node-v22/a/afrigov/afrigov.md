> 标签: a11y, accessibility, africa, civic-tech, css, design-system, design-tokens, ghana, government, govtech, kenya, nigeria, senegal, wcag

## 简介

Open-source components for building accessible African public-service websites. Country-neutral core, per-country token packs, plain CSS, no build step required.
