# agentic-bookkeeper

> 标签: accounting, agentic, ai, anthropic, bookkeeping, categorisation, claude, llm, structured-outputs, tool-use

## 简介

Agentic chart-of-accounts categorisation for bank transactions, powered by Claude. Production patterns: Zod-validated structured outputs, prompt caching, multi-provider abstraction, evaluation harness.
