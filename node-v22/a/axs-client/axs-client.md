# axs-client

> 标签: agent-web, ai-agents, ax-protocol, axs, compact-protocol, llm, llms-txt, wordpress

## 简介

Minimal client for AXS — the compact agent language of the AX Protocol. One GET: offers, prices, availability and next actions. ~80% fewer tokens than the JSON crawl.
