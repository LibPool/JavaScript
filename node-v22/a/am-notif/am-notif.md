# am-notif

> 标签: css, frontend, javascript, notification, react

## 简介

am-notif est un système de notification léger et personnalisable conçu pour les applications web. Avec une intégration fluide à l'aide de JavaScript, cette bibliothèque offre une solution élégante pour informer les utilisateurs de manière visuelle.
