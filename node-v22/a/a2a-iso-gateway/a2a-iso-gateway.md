# a2a-iso-gateway

> 标签: a2a, fdx, fintech, iso20022, obie, open-banking, pacs008, pain001, payment

## 简介

Translate Open Banking A2A payment events into ISO 20022 MX messages (pain.001, pacs.008, pain.002, camt.054)
