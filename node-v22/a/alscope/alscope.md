# alscope

> 标签: async-hooks, asynclocalstorage, cls, cls-hooked, context, continuation-local-storage, request-context, typescript

## 简介

Typed, framework-neutral request context over Node's AsyncLocalStorage. Reads outside a scope throw instead of silently returning undefined.
