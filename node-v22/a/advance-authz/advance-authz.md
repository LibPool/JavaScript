# advance-authz

> 标签: abac, access-control, authorization, authz, nodejs, permissions, policy, rbac, role-based, security, toon, typescript

## 简介

Lightweight, secure authorization engine for Node.js using TOON policy files. Zero eval(), TypeScript-first, deny-by-default.
