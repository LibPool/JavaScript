# apprende-plan-pdf-parser

> 标签: chile, curriculum, education, lirmi, parser, pdf, planning, scraper

## 简介

Parser for LIRMI educational planning PDFs from Chile. Extracts structured data (teacher, school, subject, learning objectives with checkmark associations) from LIRMI planning PDFs.
