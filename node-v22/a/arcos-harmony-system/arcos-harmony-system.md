# arcos-harmony-system

> 标签: JavaScript

## 简介

A production-ready design token and theme package for Arcos Harmony. It bundles flattened token JSON, MUI-compatible theme options, compiled CSS variables, and optional Tailwind integration so product teams can adopt the system with a single dependency.
