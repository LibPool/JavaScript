# agent-connector

> 标签: claude-code, codex, copilot, cursor, gemini-cli, hooks, mcp, model-context-protocol, multi-platform, opencode, telemetry, tokens

## 简介

Write your MCP server + hooks once; agent-connector installs and adapts them across every AI-agent platform (Claude Code, Codex, Cursor, OpenCode, Copilot, Gemini, Warp, …) and gives you default, platform-independent per-tool token telemetry.
