# aide-memoire

> 标签: agent-memory, ai-agent, event-sourcing, llm, memory, prompt-injection, provenance

## 简介

A typed, provenance-carrying memory log for AI agents: entries, a writer model, proposals, redaction and an escaped, budgeted prompt rendering. Pure functions, no dependencies.
