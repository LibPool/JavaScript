# a2a-mcp-skillmap

> 标签: a2a, agent, agent-to-agent, bridge, mcp, model-context-protocol

## 简介

Turn any A2A agent into an MCP tool server. Dynamic skill discovery, multimodal output, stdio + HTTP transports. Zero glue code.
