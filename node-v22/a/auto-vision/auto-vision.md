# auto-vision

> 标签: deepseek-harness, dsh, image, llm, plugin, sanitize, see-image, vision

## 简介

DSH（DeepSeek Harness）图片一体化插件：粘贴图片只进对话不进模型请求（llm/stream 清洗），并注册 see_image 工具让文本模型通过任意 OpenAI 兼容视觉 API 按需看图
