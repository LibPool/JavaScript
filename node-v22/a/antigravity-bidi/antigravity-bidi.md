# antigravity-bidi

> 标签: antigravity, arabic, asar, bidi, electron, hebrew, persian, rtl

## 简介

Arabic / RTL support for Google Antigravity: right-to-left chat messages and correct bidirectional text in the composer. Zero dependencies.
