# attestation-ledger

> 标签: ai-governance, attestation, audit-trail, expert-knowledge, human-in-the-loop, provenance, sop

## 简介

Provenance for expert assertions. A model can propose a value; only a named human can attest it. Status derives from verification dates, so attestations decay unless re-checked.
