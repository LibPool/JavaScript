# aeonproof-cli

> 标签: aeonproof, anteriority, authorship, ed25519, ip, merkle, moss, plagiarism, proof, timestamp, winnowing

## 简介

AeonProof Code — proof of anteriority and integrity for source code. Hashes locally (Merkle + Ed25519), detects derived/plagiarized code by winnowing; your code never leaves your machine.
