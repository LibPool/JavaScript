# accessibility-scanner-cli

> 标签: a11y, accessibility, audit, axe-core, ci, testing, wcag

## 简介

Run axe-core WCAG accessibility checks on any URL from the command line or CI. Fail the build on new violations. By accessibilityscanner.app
