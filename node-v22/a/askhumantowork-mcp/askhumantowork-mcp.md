# askhumantowork-mcp

> 标签: ai-agents, claude, mcp, model-context-protocol, reminders, todo

## 简介

MCP server for AskHumanToWork — lets AI agents (Claude Desktop, Claude Code, any MCP client) add todos with due dates and provenance to your AskHumanToWork account, fetch your agenda, and manage tasks. Requires an AskHumanToWork API token.
