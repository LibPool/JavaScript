# asterisk-audiosocket

> 标签: ai-voice-agent, asterisk, audiosocket, ivr, pcm, rtp, sip, slin16, speech, telephony, voice, voicebot, voip

## 简介

Dependency-free Asterisk AudioSocket protocol implementation for Node.js. TypeScript types, framed slin16 codec, paced playback, barge-in.
