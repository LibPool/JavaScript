# ai-browser-test

> 标签: accessibility, ai-testing, browser-testing, e2e-testing, multi-modal-validation, persona-testing, playwright, screenshot-validation, vision-language-model, visual-testing, vllm

## 简介

Browser testing utilities using Vision Language Models (VLLM) for multi-modal validation with Playwright. Supports persona-based experience testing, human-interpreted time scales, and built-in prompt templates.
