# ask-trivium

> 标签: agent, arbitration, cli, dispute-resolution, mcp, model-context-protocol, x402

## 简介

A payment-aware MCP bridge to the Ask Trivium dispute-analysis panel. Runs as a local stdio MCP server, or as a plain CLI.
