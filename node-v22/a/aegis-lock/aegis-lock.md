# aegis-lock

> 标签: aegis, aes-gcm, client-side-encryption, crypto, database-agnostic, encryption, field-level-encryption, mern, mongodb, security, supabase

## 简介

Database-agnostic client-side AES-256-GCM field-level encryption. Works with Supabase, MongoDB, or any database via pluggable adapters.
