# athena-query-execution-waiter

> 标签: athena, aws, aws-sdk, execution, query, waiter

## 简介

A small library that waits for an AWS Athena query execution to complete. It repeatedly checks the Athena API until the execution reaches a terminal state: SUCCEEDED, FAILED, or CANCELLED.
