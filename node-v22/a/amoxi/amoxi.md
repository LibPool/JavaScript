# amoxi

> 标签: a2a, ai-agents, dependency-injection, framework, fullstack, generative-ui, islands, jsx, llm, mcp, micronaut, rag, ssr, typescript

## 简介

Full-stack TypeScript framework for Node.js and AI agents: compile-time dependency injection, server-rendered JSX pages with islands, durable streaming agents with generative UI, MCP and A2A.
