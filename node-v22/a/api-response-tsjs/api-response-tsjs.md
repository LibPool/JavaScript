# api-response-tsjs

> 标签: api, crud, cursor-pagination, error-handling, express, fastify, hono, http-errors, offset-pagination, pagination, response, rest, typescript

## 简介

Type-safe, framework-agnostic success/error response envelopes, error classes, and offset + cursor pagination helpers for Node.js APIs. Ships optional Express, Fastify, and Hono adapters.
