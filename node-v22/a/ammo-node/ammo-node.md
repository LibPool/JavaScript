# ammo-node

> 标签: ammo.js, physics, simulator

## 简介

NodeJS version of Ammo.js, the javascript emscripten port of the bullet physics engine.  This is based on Bullet 2.82.

## 官网

- 源码仓库：https://github.com/kripken/ammo.js/
- npm 页面：https://www.npmjs.com/package/ammo-node

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm registry：https://registry.npmjs.org/ammo-node
