# agenthandle

> 标签: adb, agent, ai, android, arduino, arduino-cli, cargo, debug, embedded, esp32, esp8266, firmware, frontend, gradle, headless-chrome, ios, platformio, probe-rs, puppeteer, rust, serial, simulator, stm32, swift, upload, watch, web, xcode

## 简介

Watch, compile, upload/run and log embedded (ESP/Arduino/STM32), Rust (cargo/probe-rs), Android (gradle/adb), iOS (xcodebuild/simctl) and Swift (SPM) projects — plus a background headless-Chrome web renderer for debugging frontends — so an AI agent can it
