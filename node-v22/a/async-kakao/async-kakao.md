# async-kakao

> 标签: kakaotalk, 카카오

## 简介

카카오 JavaScript SDK 를 비동기적으로 내려받습니다. 그리고 SDK 초기화를 진행시켜줍니다. 그러므로 DOMContentLoaded 이벤트 병목현상을 해소할 수 있습니다.
