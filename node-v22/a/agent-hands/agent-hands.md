# agent-hands

> 标签: agent-browser, ai-agent, automation, cdp, chrome, human-input

## 简介

Human-rate mouse and keyboard for a real Chromium browser: one you launched, the one you are logged into, or an agent-browser session. Drives it over raw CDP at 60-100Hz with Fitts-law motion, Bezier paths and lognormal keystroke timing, without touching
