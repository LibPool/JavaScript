# ai-bookmarks-mcp

> 标签: bookmarks, chrome-bookmarks, claude, mcp, model-context-protocol

## 简介

Model Context Protocol server exposing your Chrome bookmarks (keyword search over tags and AI summaries) to AI agents like Claude Desktop, Antigravity, Cursor, and Cline.
