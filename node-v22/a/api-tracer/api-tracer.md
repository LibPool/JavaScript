# api-tracer

> 标签: axios, debug, devtools, devtrace, frontend

## 简介

DevTrace 配套 npm 包：在 axios 请求与路由切换中注入语义化信息，配合 DevTrace 浏览器插件使用。仅 DEV 环境激活。
