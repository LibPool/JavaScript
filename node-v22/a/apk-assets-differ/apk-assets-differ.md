# apk-assets-differ

> 标签: apk-assets-differ, differ, node

## 简介

比较两个上传的 APK 或者 IPA，将其中 更新的版本中的 `assets` 的内容 和 更旧的版本中的 `assets` 内容比对，列出其中的不同
