# agent-sdk-kit

> 标签: acp, agent, ai, claude, copilot, llm, opencode, sdk, toolkit

## 简介

Wrap multiple coding-agent CLIs (claude, copilot, opencode, pi) behind a uniform API with native session resume and fork.
