# autodesk-mcp-server

> 标签: autocad, autodesk, bridge, civil3d, mcp, model-context-protocol

## 简介

MCP server exposing Civil3D.Bridge tools to MCP clients (Claude Desktop, Cursor, VS Code, Cline, ...) over the Autodesk MCP named-pipe protocol.
