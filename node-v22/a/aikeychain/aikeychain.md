# aikeychain

> 标签: ai-agents, api-keys, claude, claude-code, codex, dotenv, dotenv-alternative, keychain, macos, mcp, model-context-protocol, secret-management, secrets

## 简介

AI KeyChain CLI & MCP server — resolve keychain:// secret references from macOS Keychain and let AI agents (Claude, Codex) use them safely. Run `akc init` to set up discovery.
