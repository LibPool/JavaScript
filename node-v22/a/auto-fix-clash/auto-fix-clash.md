> 标签: auto-switch, chatgpt, clash, clash-meta, clash-party, clash-verge, clashx, cli, codex, cross-platform, health-check, latency-test, launchd, linux, macos, mihomo, node-selection, nodejs, openai, proxy, proxy-group, proxy-selector, schtasks, self-healing, switch-node, systemd, task-scheduler, windows, 代理, 机场订阅, 自动切换, 节点切换

## 简介

Clash / mihomo（Clash Meta）代理组自动测速与自愈：直连 ChatGPT、Codex 等目标站点判定节点的真实可用性，节点挂了自动换可用节点，并装好定时任务自动巡检；支持 macOS / Linux / Windows。Auto-fix and self-heal Clash / mihomo proxy groups by probing real endpoint reachability.
