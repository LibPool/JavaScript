# agentic-code-metrics

> 标签: ai, analytics, claude, claude-code, cli, dashboard, llm, metrics

## 简介

Dashboard de métriques pour mesurer l'efficacité des sessions LLM (Claude Code). Génère un HTML statique avec des graphes d'évolution.
