# architecture-diagram-generator

> 标签: ast, cli, codebase-visualization, dependency-graph, static-analysis, ts-morph, typescript

## 简介

Automated architecture analysis for TypeScript and Next.js projects. Scan codebases, classify layers, score architecture health, and generate interactive dashboards and Mermaid diagrams.
