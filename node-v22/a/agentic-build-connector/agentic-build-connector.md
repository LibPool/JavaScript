# agentic-build-connector

> 标签: ai-agent, mcp, model-context-protocol, plugin, roblox, roblox-studio

## 简介

MCP server that connects AI agents (Claude Code, Codex, Cursor, and any MCP client) to a live Roblox Studio session via the Agentic Build Connector plugin.
