# aai-vite-plugin-css-injected-by-js

> 标签: css, css-injected-by-js, js, plugin, single-js-file, typescript, vite, vite-plugin

## 简介

A Vite plugin that takes the CSS and adds it to the page through the JS. For those who want a single JS file.
