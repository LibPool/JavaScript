> 标签: JavaScript

## 简介

Я работаю с Vue3.js проектом, использующим для запросов к API Axios.     Работа с несистематизированным вызовом API через Axios имела следующие проблемы:    - Повторное использование кода (пусть это и всего лишь вызов API)    - Изменение заголовков, ад
