# agentreplay-cli

> 标签: agent, ai, claude, claude-code, cli, codex, developer-tools, local-first, openai-codex, replay, session, transcript, visualization

## 简介

Turn a Claude Code or Codex CLI session into a self-contained HTML replay of how the agent worked — locally, with no telemetry.
