# agent-whiteboard

> 标签: ai-agent, claude, claude-code, mcp, mermaid, model-context-protocol, teaching, visualization, whiteboard

## 简介

A domain-agnostic interactive whiteboard for AI teacher agents — render diagrams, math, charts, and HTML to a local browser tab via MCP tools.
