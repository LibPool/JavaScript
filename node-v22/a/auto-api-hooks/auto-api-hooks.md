# auto-api-hooks

> 标签: api-client, axios, code-generation, codegen, fetch, graphql, hooks-generator, mock-server, msw, openapi, react-hooks, react-query, swagger, swr, tanstack-query, typescript, zod

## 简介

Generate React Query hooks, SWR hooks, and TypeScript types from OpenAPI 3.x, Swagger 2.0, and GraphQL specs. API client code generator with Zod schema validation and MSW v2 mock server generation.
