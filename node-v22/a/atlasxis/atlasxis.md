# atlasxis

> 标签: access-control, authorization, bola, idor, nextjs, proof, rls, security, static-analysis, supabase

## 简介

Authorization proof engine for Next.js + Supabase APIs. Proves, per data sink, whether there is structural evidence of authorization — and says so when it can't. Never claims your app is secure.
