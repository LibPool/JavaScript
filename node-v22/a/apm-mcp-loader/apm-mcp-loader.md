# apm-mcp-loader

> 标签: agent, apm, apm.yml, claude, config-loader, copilot, mcp, model-context-protocol

## 简介

Agnostic loader/bridge for Microsoft APM manifests (apm.yml) and MCP client configs (mcp.json), transforming them into target runtime configs (Copilot SDK, MCP client SDK, or raw JSON).
