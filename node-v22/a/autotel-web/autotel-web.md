# autotel-web

> 标签: browser, distributed-tracing, nextjs, observability, opentelemetry, otel, react, spa, traceparent, tracing, vue, w3c-trace-context, web

## 简介

Ultra-lightweight browser SDK for distributed tracing - propagates W3C traceparent headers to backends using Autotel (~2-5KB gzipped)
