# ai-portal-blocknote-editor

> 标签: JavaScript

## 简介

一个基于 BlockNote（React）在 Vue 3 中封装的富文本/知识块编辑器组件，内置中文词典、AI 助手按钮、Markdown 粘贴与按块插入、标题扩展（支持 `agentId`）等能力。
