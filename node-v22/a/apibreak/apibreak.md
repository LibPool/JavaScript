# apibreak

> 标签: api, api-diff, breaking-changes, ci, github, integration, openapi, stripe, swagger

## 简介

Early access. A CI check that compares the vendor OpenAPI specifications you depend on against a baseline you pin, and reports only the changes that touch the endpoints you declared. No vendor credentials required, no repository access, nothing uploaded.
