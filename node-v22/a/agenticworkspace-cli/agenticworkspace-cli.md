# agenticworkspace-cli

> 标签: agent-workspace, ai-agents, claude-code, cli, context-management, developer-tools, devex, session-handoff

## 简介

CLI that converts any repository into an agent-ready workspace: detects your stack, scaffolds a .workspace/ directory with progressive context loading and session handoffs, and installs a working Claude Code adapter out of the box.
