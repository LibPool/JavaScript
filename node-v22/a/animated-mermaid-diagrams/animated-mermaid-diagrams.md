# animated-mermaid-diagrams

> 标签: animation, diagram, flowchart, mermaid, sequence-diagram, state-diagram, svg

## 简介

Drop-in animated rendering for Mermaid diagrams. One dependency: @dagrejs/dagre (the same layout engine Mermaid uses).
