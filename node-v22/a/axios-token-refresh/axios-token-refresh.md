# axios-token-refresh

> 标签: 401-error, authentication, authorization, axios, axios-interceptor, axios-middleware, axios-refresh, http-client, http-interceptor, interceptor, refresh-token, refresh-token-logic, retry-requests, token-expiry, token-refresh

## 简介

A lightweight utility for Axios to handle token refresh logic seamlessly. Automatically retries requests after token expiration with customizable retry logic and status code handling.
