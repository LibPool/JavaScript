# agent-broker

> 标签: agents, circuit-breaker, concurrency, coordination, distributed-systems, llm, rate-limiting, redis

## 简介

An in-process TypeScript library coordinating budget reservation, concurrency limiting, and circuit breaking across independent Node.js processes via Redis.
