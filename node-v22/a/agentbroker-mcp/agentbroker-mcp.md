# agentbroker-mcp

> 标签: agentbroker, ai-agents, business, hatchloop, mcp, mcp-server, model-context-protocol

## 简介

stdio->HTTP MCP shim for AgentBroker - 20 tools for sanctions screening, company verification, SMB discovery, booking and messaging. Use from Claude Desktop, Cursor, or any MCP client.
