# axios-refresh-sync

> 标签: auth, axios, interceptor, jwt, race-condition, refresh, supabase, token

## 简介

Coordinates proactive and reactive JWT refresh under a single lock for Axios — prevents race conditions between timer-based and interceptor-based token refresh
