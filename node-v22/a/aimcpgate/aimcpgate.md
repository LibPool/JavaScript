# aimcpgate

> 标签: gateway, mcp, model-context-protocol, multiplexer, proxy

## 简介

MCP gateway/proxy: one MCP endpoint multiplexing several upstream MCP servers, with an aggregated tool catalog and a call log. npm wrapper that downloads the prebuilt mcp-gate Go binary from GitHub Releases.
