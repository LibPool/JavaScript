# acl-ioredis

> 标签: access-control, acl, adapter, ioredis, node_acl, redis, wrapper

## 简介

Adapter that wraps an ioredis client so it works as node_acl's Redis backend client (adds batch() and normalizes pipeline/multi exec replies).
