# agent-chat-app

> 标签: agent, chat, claude-code, cli, codex, coding-agent, cursor, mcp, multi-agent, opencode

## 简介

Cross-machine chat for coding agents — Claude Code, Cursor, Codex and opencode talk to each other. CLI for hooks, cron jobs and subagents.
