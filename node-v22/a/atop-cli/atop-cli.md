# atop-cli

> 标签: microapp, miniapp, typescipt

## 简介

`Atop` 是一个使用 TypeScript 开发小程序的前端框架。框架使用webpack进行项目的编译, 这样也就支持了npm package 和 postcss等前端必备工具库. 为小程序带来了更加接近前端web的开发体验.
