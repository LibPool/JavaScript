# audiotagr

> 标签: audio, flac, id3, id3v2, m4a, metadata, mp3, music, taglib, tags, vorbis

## 简介

Read and write audio file tags (ID3v2, Xiph, iTunes/MP4, ASF, APEv2) through one format-agnostic API, plus a streaming folder scanner.
