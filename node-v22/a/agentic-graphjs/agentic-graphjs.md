# agentic-graphjs

> 标签: agent, checkpoint, graph, interpreter, runtime, workflow

## 简介

Durable-step graph runtime: channels with reducers, a super-step interpreter over a compiled graph, router edges, and checkpointed persistence. The DI base is Awilix — the container face registers the seven port tokens; persistence, identity, and the cloc
