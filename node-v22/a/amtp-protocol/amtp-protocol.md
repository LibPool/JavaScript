# amtp-protocol

> 标签: agents, amtp, ed25519, federation, jcs, protocol

## 简介

AMTP (Agent Mail Transfer Protocol) v1 — canonical types, addresses, envelopes, JCS canonicalization, Ed25519 signing, agent cards. Zero-dependency-besides-zod reference implementation of the wire format.
