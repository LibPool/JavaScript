# agent-tool-guard

> 标签: agent, ai-agent, anthropic, asynclocalstorage, audit-log, authorization, claude, function-calling, llm, mcp, multi-tenancy, multi-tenant, prompt-injection, tenant-isolation, tool-use, typescript

## 简介

Tenant and permission isolation for LLM agent tool calls: a principal context on AsyncLocalStorage, a guard that scopes every call and audits it, and a test kit that proves no tool escaped.
