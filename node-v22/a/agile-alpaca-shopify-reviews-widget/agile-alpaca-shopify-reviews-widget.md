# agile-alpaca-shopify-reviews-widget

> 标签: JavaScript

## 简介

React + Vite + TypeScript widgets for the public reviews API from `panel`. Widget interface text is available in English, Ukrainian, and Russian. English remains the default unless a language option is explicitly configured.
