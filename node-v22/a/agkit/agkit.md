# agkit

> 标签: agentic, claude, claude-code, cli, copilot, generator, github-copilot, marketplace, plugin, scaffold

## 简介

Scaffold and manage plugin marketplaces for Claude Code and GitHub Copilot, distributed via any Git host (GitHub, GitLab, Bitbucket, Gitea, self-hosted). Init, add plugins from built-in or remote templates, sync, validate, bump.
