# @vitrina/widget

> 标签: automotive, chat, chat-widget, dealer, embed, livechat, shadow-dom, sse, vitrina, widget

## 简介

Vitrina embeddable chat widget for dealer websites — shadow-DOM UI, real-time SSE, publishable origin-locked key.
