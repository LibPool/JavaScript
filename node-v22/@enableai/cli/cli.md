# @enableai/cli

> 标签: JavaScript

## 简介

`enableai-cli` 是一个面向多包（monorepo）前端/SDK工程的命令行工具，用于统一初始化工程模板、构建流程、类型产物、发布流程与发布策略。   它解决的核心问题是：把“每个仓库都要手工搭一遍”的工程化步骤标准化，减少重复劳动与人为错误。
