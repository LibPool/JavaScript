# @lefrui/ctx-tree

> 标签: chatgpt, claude, cli, clipboard, context, directory-tree, gitignore, llm, prompt, tree

## 简介

Print a clean project file tree for pasting into LLM chats. Respects .gitignore, skips build noise, copies to clipboard.
