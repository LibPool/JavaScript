# @sveltebuilder/logistic

> 标签: drizzle, fulfillment, inventory, logistics, shipping, supply-chain, svelte, svelte5, sveltebuilder, sveltekit, warehouse, wms

## 简介

Warehouse and logistics domain module for SvelteBuilder — suppliers, storage locations, stock, receiving, pick tasks, shipments, returns, and cycle counts, with a Drizzle schema and i18n built in.
