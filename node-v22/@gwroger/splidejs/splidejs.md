# @gwroger/splidejs

> 标签: carousel, gallery, lightweight, responsive, slider, slideshow, splide, touch, typescript

## 简介

Based on Splidejs. I added an horizontal scroll option. Splide is a lightweight, flexible and accessible slider/carousel. No dependencies, no Lighthouse errors.
