# @ai-path/tb-mcp

> 标签: JavaScript

## 简介

Expose a Taible grid to AI agents: a transport-agnostic tool registry (get_cell/set_cell/get_range/evaluate/define_name) with handler-validated inputs and a result-enveloped dispatcher.
