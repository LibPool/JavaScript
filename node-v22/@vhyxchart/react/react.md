# @vhyxchart/react

> 标签: animation, diagram, react, vhyxara, vhyxchart

## 简介

React components for VhyxChart — animated diagrams from text. <VhyxChart>, a headless hook for custom controls, and a server-renderable <VhyxChartStatic>.
