# @sigx/lynx-markdown

> 标签: ai, lynx, markdown, native, signalx, sigx, streaming

## 简介

SignalX-native streaming markdown renderer and WYSIWYG editor for Lynx. Renders and edits @sigx/richtext (mdast) trees natively as <view>/<text> primitives, through @sigx/richtext-markdown, with incremental streaming for AI output.
