# @sigx/lynx-icons-fa-free

> 标签: font-awesome, fontawesome, icon, lynx, signalx, sigx

## 简介

Font Awesome Free adapter for @sigx/lynx-icons. Provides solid/regular/brands styles via the official @fortawesome/* packages.
