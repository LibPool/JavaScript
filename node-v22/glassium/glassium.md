# glassium

> 标签: custom-elements, glass, glassmorphism, liquid-glass, refraction, ui, web-components, webgl2, webgpu

## 简介

Liquid Glass（液态玻璃）UI 的 Web 实现：GPU 渲染的折射、色散与融合的玻璃，以 Web Components 交付（WebGPU → WebGL2 → CSS 兜底）
