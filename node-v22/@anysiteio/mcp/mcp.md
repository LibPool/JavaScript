# @anysiteio/mcp

> 标签: ai-agent, anysite, claude, crm, crunchbase, duckduckgo, instagram, linkedin, mcp, model-context-protocol, reddit, sec, twitter, web-scraping, y-combinator, yc, youtube

## 简介

Local stdio bridge to the AnySite remote MCP server (mcp.anysite.io) — structured data from LinkedIn, Instagram, Twitter/X, Reddit, YouTube, SEC, Crunchbase and hundreds of other sources via discover / execute / get_page / query_cache / export_data plus C
