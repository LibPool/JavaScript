# @smai-kit/dsh-smkit

> 标签: cordis, deepseek, deepseek-harness, dsh, mcp, model-context-protocol, oauth, plugin, stdio

## 简介

MCP server manager for DeepSeek Harness: Settings → MCP page, OAuth (PKCE + dynamic client registration) or static-token auth, local stdio servers, workspace isolation, and an opt-in on-demand tool broker.
