# @emito/core

> 标签: consent, emito, multi-channel, multi-tenant, notification-engine, notification-infrastructure, notifications, preferences, self-hosted

## 简介

The Emito notification engine — one send() that resolves the subscriber, applies preference and consent gates, renders localized templates, and routes to provider plugins.
