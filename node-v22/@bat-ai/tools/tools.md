# @bat-ai/tools

> 标签: agents, ai, automation, bat-ai, framework, multi-agent, tools, typescript

## 简介

A framework for creating and sharing tools for the BatAI multi-agent system. Enables developers to build and contribute custom tools that can be used by AI agents.
