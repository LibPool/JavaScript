# dsh-balance-inquiry

> 标签: balance, coding-plan, deepseek-harness, dsh, new-api, plugin, quota

## 简介

多套餐余额看板：侧边栏显示剩余额度，左键打开看板看每个套餐的余额，支持原生余额接口、New API 与编程套餐（Token Plan / Coding Plan）
