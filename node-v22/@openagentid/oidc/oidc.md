# @openagentid/oidc

> 标签: agent, did, identity, oauth2, oidc, openagent, rfc8693, token-exchange

## 简介

OIDC/OAuth2 bridge for OpenAgent SDK — maps between human OIDC tokens and OAS agent DIDs + Arsenal capability tokens.
