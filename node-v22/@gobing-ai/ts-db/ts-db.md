# @gobing-ai/ts-db

> 标签: cloudflare-d1, dao, database, drizzle-orm, migrations, orm, sqlite, typescript

## 简介

@gobing-ai/ts-db — a drizzle-free database facade: typed DAOs over Bun SQLite / Cloudflare D1, a small predicate query spec, single-source-of-truth tables, and migrations. Drizzle stays an internal detail.
