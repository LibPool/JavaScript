# @chirag127/atoms

> 标签: atoms, design-system, framework-agnostic, ui, vanilla-js, web-components

## 简介

Framework-agnostic atomic web components (buttons, chips, cards, badges, fields, nav links, prose). Vanilla custom elements, zero dependencies — they restyle automatically under any @chirag127/theme archetype.
