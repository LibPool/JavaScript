# @planmonster/olkcli

> 标签: calendar, cli, email, mcp, microsoft-graph, onedrive, outlook

## 简介

CLI for Microsoft Outlook and OneDrive via the Microsoft Graph API (mail, calendar, contacts, tasks, files) — and an MCP server for AI agents (olk mcp).
