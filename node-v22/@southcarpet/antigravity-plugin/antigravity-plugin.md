# @southcarpet/antigravity-plugin

> 标签: agy, ai-delegation, antigravity, antigravity-cli, claude-code, claude-code-plugin, code-review, codex, codex-cli, gemini, image-analysis, mcp, mcp-server, vision

## 简介

Multi-host plugin for delegating tasks and code reviews to Google Antigravity CLI (agy). Works inside Claude Code, Codex CLI, agy itself, and as a standalone CLI.
