# @krassx/turbokv

> 标签: cache, cluster, ipc, lru, napi, native, shared-memory

## 简介

Layered in-memory KV cache for Node.js clusters: per-process L1 with a byte budget over a shared-memory L2 the primary owns and workers map read-only.
