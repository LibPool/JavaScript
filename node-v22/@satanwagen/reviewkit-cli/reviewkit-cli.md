# @satanwagen/reviewkit-cli

> 标签: claude-code, cursor, emblema, mcp, review, reviewkit

## 简介

ReviewKit terminal tools: `reviewkit` (list/triage review comments from the terminal, MCP bridge for Claude Code & Cursor) and `reviewkit-emblema` (local sync agent pairing a project with the Emblema desktop app).
