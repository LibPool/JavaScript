# @frapx/fx-particles

> 标签: background, confetti, gpu, particles, snow, transform-feedback, webgl2

## 简介

WebGL2 GPU particle runtime for website backgrounds: declarative presets, transform-feedback simulation, and deterministic fixed-step playback for frame export.
