# qa-wrap-bridge

> 标签: browser-extension, bug-report, mcp, mcp-server, model-context-protocol, native-messaging, qa, read-only, testing

## 简介

Read-only agent bridge for QA Wrap: an MCP server (stdio) that reads sessions through Chrome native messaging. Local only, no network.
