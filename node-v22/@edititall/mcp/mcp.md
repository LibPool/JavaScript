# @edititall/mcp

> 标签: ai-agents, edititall, image-compression, mcp, mcp-server, model-context-protocol, pdf, spreadsheet

## 简介

MCP server that drives EditItAll's in-browser editors locally (photo, vector, PDF, sheet, Word, slides, image convert). Files never leave the machine.
