# @better-iam/svelte

> 标签: abac, access-control, authentication, authorization, iam, multi-tenant, rbac, svelte, sveltekit, typescript

## 简介

SvelteKit and Svelte bindings for Better IAM: a handle hook that serves the IAM API, guarded loads and form actions, and session stores.
