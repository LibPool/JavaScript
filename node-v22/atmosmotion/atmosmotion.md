# atmosmotion

> 标签: animation, framer-motion-alternative, gestures, motion, physics, react, spring

## 简介

Physics-based animation for React on the web: analytical springs, velocity-preserving interruptions, drag with momentum and rubber-banding, and presence/layout animations.
