# @pliscelle/agent-mailbox-mcp

> 标签: JavaScript

## 简介

AIScelle MCP connector: reads and sends end-to-end encrypted agent mailbox messages from an MCP-capable agentic client. Decryption happens on this machine only, never on Pli Scelle's servers.
