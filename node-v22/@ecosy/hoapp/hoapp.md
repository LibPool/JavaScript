# @ecosy/hoapp

> 标签: dependency-injection, ecosy, hono, openapi, router, standard-schema

## 简介

Routers on Hono with injected dependencies, one response envelope, typed exceptions, Standard Schema validation and OpenAPI — the same way of writing a route as @ecosy/next, for services.
