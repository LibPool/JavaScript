# @boring-stack-pkg/eslint-plugin-three

> 标签: 3d, eslint, eslintplugin, three, threejs, typescript, webgl

## 简介

ESLint plugin for Three.js as a render substrate: canonical imports, GPU dispose contracts, scene-graph APIs, loader error paths, and instanced-buffer updates. Ported from the tsforge `three` rule pack.
