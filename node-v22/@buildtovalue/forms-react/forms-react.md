# @buildtovalue/forms-react

> 标签: bpmn, forms, react, renderer

## 简介

Pure React renderer for @buildtovalue/forms schemas: controlled, headless-friendly, a11y-first. The SAME schema drives client rendering and server-side submission validation. Storybook stories ship with every component.
