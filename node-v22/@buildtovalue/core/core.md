# @buildtovalue/core

> 标签: audit, bpmn, diagram, governance, versioning, workflow

## 简介

Zero-dependency BPMN domain engine: model, lifecycle governance, validation, structured diff, hash-chained audit ledger, geometry and BPMN 2.0 XML (with DI).
