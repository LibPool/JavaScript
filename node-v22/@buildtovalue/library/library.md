# @buildtovalue/library

> 标签: artifact, catalog, governance, headless, lifecycle

## 简介

Generic, ecosystem-independent artifact catalog for BuildToValue Studio (Handoff 6 S-1): the ArtifactAdapter contract plus headless search/filter/sort/count logic. Knows nothing about BPMN, DMN or any concrete artifact type — adapters plug in. Zero depend
