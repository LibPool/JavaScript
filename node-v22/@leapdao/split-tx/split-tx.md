# @leapdao/split-tx

> 标签: JavaScript

## 简介

Lightweight (1.2Kb zipped) CLI to encode/decode `splitERC20` call of [PaymentSplitter contract](https://github.com/leapdao/leap-contracts/blob/master/contracts/misc/PaymentSplitter.sol).
