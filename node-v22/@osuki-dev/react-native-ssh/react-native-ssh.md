# @osuki-dev/react-native-ssh

> 标签: android, expo, ios, nitro, nitro-modules, react-native, russh, rust, ssh, ssh-client

## 简介

Native SSH client for React Native and Expo — russh (Rust) wrapped in Nitro Modules. Connections, shells, exec and keys; bring your own terminal.
