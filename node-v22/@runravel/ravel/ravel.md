# @runravel/ravel

> 标签: agentic, agents, ai, claude, human-in-the-loop, mcp, orchestration, runtime

## 简介

Ravel — an agentic runtime: define an agentic team as a folder of agents, tools, and processes, and run it with orchestration, budgets, scheduling, and human-in-the-loop approval.
