# @dixydo/roomkit

> 标签: real-time, roomkit, self-hosted, sfu, video, video-call, video-conference, webrtc

## 简介

Vanilla-JS SDK for embedding self-hosted roomkit video calls into any web page (SFU-based, framework-agnostic).
