# @mohammedayman/aecsami-component-library

> 标签: JavaScript

## 简介

The SAMI Advanced Electronics React UI kit — a plug-and-run component library built on Radix primitives and Tailwind, shipped with a precompiled stylesheet so you can use it **without installing or configuring Tailwind yourself**.
