# @saulshanabrook/egraph-visualizer

> 标签: JavaScript

## 简介

Interactive visualizer for e-graphs in [the serialized JSON format](https://github.com/egraphs-good/egraph-serialize/) using Cytoscape JS and Eclipse Layout Kernel.
