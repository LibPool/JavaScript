# @tools-for-agents/keep

> 标签: agent-tools, ai-agents, claude, keep, llm, mcp, mcp-server, redaction, secrets, zero-dependency

## 简介

Use a secret without holding it: an encrypted vault whose values are injected into the commands an agent runs and redacted from everything that comes back.
