# @besaitech/ng-design-system

> 标签: JavaScript

## 简介

Reusable **Angular 20** component library (`sds-` prefix) styled with **Tailwind CSS v4**, based on the Saitech visual language. Buttons, inputs, selects, tables, tabs, accordions, a date picker, phone input, plus the app shell (top bar + sidebar).
