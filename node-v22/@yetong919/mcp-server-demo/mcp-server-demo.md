# @yetong919/mcp-server-demo

> 标签: JavaScript

## 简介

一个给 `ai-chat` 面试 demo 准备的独立 MCP Server。它不改动 `ai-chat` client 侧代码，只提供一个 stdio MCP server，方便用 MCP Inspector、Cline、Cursor、Claude Desktop 或之后的 AI SDK Host 连接。
