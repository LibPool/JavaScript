# @graphrefly/native-darwin-arm64

> 标签: dispatcher, graphrefly, napi-rs, reactive

## 简介

GraphReFly Rust substrate (napi-rs bindings) — preview. Async-surface Rust implementation of the GraphReFly dispatcher (Core runs on a tokio blocking pool; every Core-touching call is async). NOTE: this is NOT (yet) a drop-in substitute for @graphrefly/pu
