# @xsolla-zk/tokens

> 标签: JavaScript

## 简介

A powerful CLI package for generating design tokens from Figma Tokens Studio into various formats. This package transforms design tokens into TypeScript objects, Tamagui configurations, and other formats for seamless integration with the Xsolla ZK design
