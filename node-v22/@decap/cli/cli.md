# @decap/cli

> 标签: cli, decap-cms, decap-turbo, experimental, local-backend, mcp, proxy

## 简介

The Decap command line: run the local proxy server for the CMS, manage Decap Turbo from your terminal, and connect AI agents to it over MCP
