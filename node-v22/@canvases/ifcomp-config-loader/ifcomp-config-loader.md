# @canvases/ifcomp-config-loader

> 标签: config-loader, ifcomp, multi-project, project management

## 简介

本项目提供了一个 Webpack Loader，用于在 Vue2 项目中进行条件编译功能。它允许你在 Web 和不同平台（如 `APP-PLUS`、`H5`、`MP-WEIXIN` 等）之间运用不同的业务组件。
