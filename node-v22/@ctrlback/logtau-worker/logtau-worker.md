# @ctrlback/logtau-worker

> 标签: log, logger, logging, logtau, off-thread, sharedarraybuffer, transport, typescript, worker, worker-threads

## 简介

Off-thread transport for @ctrlback/logtau: runs a logtau-egress byte sink on a dedicated worker thread over a SharedArrayBuffer ring.
