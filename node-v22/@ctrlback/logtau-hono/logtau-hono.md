# @ctrlback/logtau-hono

> 标签: hono, http, log, logger, logging, logtau, middleware, request-logging, structured-logging, typescript

## 简介

Hono request-logging middleware for @ctrlback/logtau. Structured NDJSON access logs with per-request child loggers.
