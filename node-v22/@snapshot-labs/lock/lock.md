# @snapshot-labs/lock

> 标签: JavaScript

## 简介

Web3 connector library for Snapshot's Vue app. It bundles concrete implementations for common wallets (injected, WalletConnect, Coinbase, Safe, Sequence, Argent X, Unicorn) plus a `Guest` connector and an EIP-6963 provider discovery helper used internally
