# @fefeding/ppt-parser

> 标签: pptx, pptx parser, pptx serializer, ppt导出, ppt解析, typescript

## 简介

PPTX文件解析与序列化核心库，纯TS编写，支持解析PPTX为JSON结构、JSON序列化为标准PPTX文件，无框架依赖
