# @xgsail-e1/capacitor

> 标签: ble, bluetooth, capacitor, e1, esp32, sailing

## 简介

TypeScript BLE client for the E1 sailing tracker — GATT protocol UUIDs, config/status, calibration, and session-relay primitives (Capacitor).
