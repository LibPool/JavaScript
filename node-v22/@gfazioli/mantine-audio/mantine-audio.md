> 标签: audio, audio-player, component, compound-component, extension, headless, library, mantine, mantine-extension, mantine-ui, mantine-v9, nextjs, podcast, react, react-audio, react-component, reactjs, spectrum-analyzer, typescript, ui, waveform, web-audio-api

## 简介

A Mantine-native audio player for React with waveform visualization and live spectrum analyzer, built on Web Audio API. Compound component API + headless useAudio hook.
