# @uverifyng/node

> 标签: aml, bvn, face-match, identity-verification, kyc, liveness, nigeria, nin, uverify

## 简介

Official Node.js library for the Bytid API (formerly UVerify): BVN, NIN and ID checks, liveness, face match, ID documents and AML screening for Nigeria.

## 官网

- 官网：https://www.bytid.com/docs
- 源码仓库：git+https://github.com/elastodev/uverify-sdks.git
