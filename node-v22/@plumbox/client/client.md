# @plumbox/client

> 标签: client, drive, oauth, pkce, plum, plum-box, plumbox, sdk, self-hosted

## 简介

Client SDK for Plum Box: log in once, auto-connect to the user's box via Plum Relay, and use the Drive API — no IP, port, or tunneling knowledge required.
