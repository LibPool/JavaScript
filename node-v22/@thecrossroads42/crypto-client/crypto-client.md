# @thecrossroads42/crypto-client

> 标签: client-side-encryption, encryption, thecrossroads

## 简介

The Crossroads — client-side-encryption integration layer (value / visit / longitudinal crypto + keyring wiring) over @thecrossroads42/crypto. Inject server access via configure(); used by the app and the terminal client.
