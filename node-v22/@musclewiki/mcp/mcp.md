# @musclewiki/mcp

> 标签: ai, claude, cursor, exercise, fitness, llm, mcp, model-context-protocol, musclewiki, workout

## 简介

First-party Model Context Protocol (MCP) server for the MuscleWiki API - expose 1,900+ exercises to any MCP client (Claude, Cursor, VS Code, Windsurf, Zed, ...) as native tools
