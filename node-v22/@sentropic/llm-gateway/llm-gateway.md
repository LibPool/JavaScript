# @sentropic/llm-gateway

> 标签: JavaScript

## 简介

Authenticated, pooled, metered LLM egress gateway for Sentropic (WP16 Layer B). Provider-compatible Anthropic/OpenAI wire over the @sentropic/llm-mesh account pool.
