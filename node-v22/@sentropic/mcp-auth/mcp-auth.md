# @sentropic/mcp-auth

> 标签: JavaScript

## 简介

Framework-agnostic MCP resource-server kit for Sentropic: RFC 9728 Protected Resource Metadata, MCP-profile audience-bound access-token validation (DPoP, tenant hook), and RFC 6750 WWW-Authenticate challenge semantics. Fetch-style core + optional Hono ada
