# aegisone

> 标签: aegis, aegiscloud, aegiscode, aegisone, cli, desktop, llm

## 简介

AEGISONE — one product, two faces. `aegis` opens the window when there is nothing else to do and runs the terminal otherwise; `aegiscode` keeps behaving exactly as it always has.
