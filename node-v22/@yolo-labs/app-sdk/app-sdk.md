# @yolo-labs/app-sdk

> 标签: bridge, iframe, react, sdk, tile-app, yolo

## 简介

Client SDK for YOLO Apps — the typed, origin-safe bridge an app's iframe code uses to talk to the YOLO host (replaces hand-rolled postMessage). The ONLY package a third-party app installs.
