# @curviate/mcp

> 标签: JavaScript

## 简介

Thin stdio bridge to the hosted Curviate MCP endpoint, for stdio-only clients (Claude Desktop, Claude Code, Cursor). Ships no tool implementations; the hosted server is the single source of truth.

## 官网

- 官网：https://docs.curviate.com
- 源码仓库：git+https://github.com/Curviate/curviate-mcp.git
- npm 页面：https://www.npmjs.com/package/@curviate/mcp
