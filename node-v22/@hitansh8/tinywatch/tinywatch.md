# @hitansh8/tinywatch

> 标签: analytics, cloudflare-d1, cookieless, events, pageviews, postgres, privacy, sdk, self-hosted, sqlite, tracking, tree-shakeable, turso, web-analytics, zero-dependencies

## 简介

Tiny, embeddable web analytics: a ~900B client SDK plus a server handler that writes to your own database. A dependency, not a deployment.
