# @tbox.cn/app-sdk-client

> 标签: JavaScript

## 简介

tbox 应用平台 SDK client 轴：runtime/http/logger/error-boundary、桥接（支付宝 web-view）、client-context、卡片渲染基元。agent 前端运行时在 @tbox.cn/app-agent-sdk-client。
