# @tbox.cn/app-agent-sdk-server

> 标签: JavaScript

## 简介

tbox agent 应用框架 server 轴：chat 引擎、技能/前置工具/记忆、LLM provider、会话与 WS 通道、TTS、工具工厂、agent 配置。模块系统（注册表/装配/动作域/auth/inspector）在 @tbox.cn/app-sdk-server。
