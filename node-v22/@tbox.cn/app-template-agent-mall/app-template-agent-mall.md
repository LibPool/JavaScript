# @tbox.cn/app-template-agent-mall

> 标签: JavaScript

## 简介

tbox 商圈 AI Agent 全栈模板（多包 pnpm workspace）：apps/client + apps/server。客户端同时跑在浏览器与支付宝小程序 web-view 壳里；开箱即用商圈形态（mallName 回显 + 商圈主屏），能力经 tbox-app module add 模块扩展（shopping-guide/member 等）。
