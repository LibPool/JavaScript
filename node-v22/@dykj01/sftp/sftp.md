# @dykj01/sftp

> 标签: cli, deploy, sftp, ssh, tar.gz, zip

## 简介

一个简单好用的 SFTP 打包上传 CLI：在本地将指定目录压缩为 `.tar.gz`，上传到服务器后解压并删除压缩包。支持交互/非交互模式、忽略规则、上传进度、上传前清空目录、后置命令以及超时/保活等配置。
