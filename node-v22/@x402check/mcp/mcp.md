# @x402check/mcp

> 标签: ai-agents, attestation, drainer, mcp, model-context-protocol, payments, phishing, risk-check, sanctions, wallet, x402, x402check

## 简介

MCP server for x402check: pre-payment risk checks with verifiable attestations for AI agents, and x402 payments made only after the payee is cleared (right before signing).
