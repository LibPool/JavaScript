# @agentwares/mcp-kit

> 标签: ai-agents, llms-txt, mcp, mcp-server, model-context-protocol, stdio, streamable-http, tools, x402, zod

## 简介

Expose any package as an MCP server: one defineTool definition served over stdio and Streamable HTTP, errors that always carry code/cause/fix/retryable, 402 payment gating, and generators for server.json, llms.txt and pricing.json.
