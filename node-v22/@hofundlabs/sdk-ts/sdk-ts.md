# @hofundlabs/sdk-ts

> 标签: behavioral, consent, digital-therapeutic, hofund, hofund-mirror, intelligence, sdk, telemetry

## 简介

Hofund Mirror — TypeScript SDK. Used by client apps (web, server, React Native) to record consent decisions and ingest behavioral / operational events into the Hofund Mirror platform.
