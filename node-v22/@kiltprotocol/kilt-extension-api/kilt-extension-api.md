# @kiltprotocol/kilt-extension-api

> 标签: JavaScript

## 简介

KILT Extension API is a JavaScript/TypeScript library that provides helper functions for interacting with KILT enabled extensions. It facilitates seamless communication between your application and KILT extensions.
