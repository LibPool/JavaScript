# dsh-deepseek-offpeak-indicator

> 标签: deepseek, deepseek-harness, dsh, dsh-plugin, off-peak, plugin, pricing

## 简介

DeepSeek Harness plugin: a small dot left of the model name in the composer tool row — yellow for DeepSeek peak hours, green for off-peak (half price). Rendered only when the session's model provider is DeepSeek.
