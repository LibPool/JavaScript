# @toolsuitev2/suite-mcp

> 标签: JavaScript

## 简介

MCP server for the ToolSuite Suite API — drive every ToolSuite tool (media cleanup, upscaling, voiceovers, and more as they land) from Claude Desktop, Cursor, or any MCP client with one ts_suite_ key.
