# figma-clipboard-design-mcp

> 标签: clipboard, design-to-code, figma, kiwi, mcp, model-context-protocol

## 简介

Turns Figma clipboard data (layers, layout, fills, text, vector paths) into a local MCP server for AI: view-seat friendly, zero API quota, zero deps.
