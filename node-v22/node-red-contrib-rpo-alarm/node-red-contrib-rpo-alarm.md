# node-red-contrib-rpo-alarm

> 标签: acknowledge, alarm, building-automation, hvac, interlock, latch, node-red, quittierung

## 简介

Node-RED alarm with acknowledgement: stays active until the fault is gone and the alarm is acknowledged; on/off delay, inhibit, alarm object for notifications
