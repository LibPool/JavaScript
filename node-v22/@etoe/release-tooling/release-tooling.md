# @etoe/release-tooling

> 标签: JavaScript

## 简介

Etoe supply-chain release tooling — CycloneDX SBOM generation + a release-pipeline auditor that proves npm provenance (sigstore) and cosign Docker signing are wired (Gates B5/B6/B7). Zero runtime dependencies.
