# @etoe/crypto-core-libsignal

> 标签: JavaScript

## 简介

Crypto core for the @etoe/sdk-* packages: vendors @signalapp/libsignal-client and exposes the CryptoCore boundary consumed by the platform SDK packages. Owns the per-target build artifacts (Node N-API + WASM + UniFFI/JSI).
