# @visutry/tryon-web

> 标签: ar, augmented-reality, computer-vision, face, face-analysis, face-shape, glasses, h5, landmark, mediapipe, on-device, privacy, sdk, threejs, try-on, typescript, virtual-tryon, visutry, webgl

## 简介

Web (H5) adapter for VisuTry SDK: getUserMedia camera, MediaPipe FaceLandmarker, Three.js renderer and SDK facade.
