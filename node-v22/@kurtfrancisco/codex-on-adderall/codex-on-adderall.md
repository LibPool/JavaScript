> 标签: agents, budget, claude-code, codex, cursor, mcp, multi-model, orchestration, spec

## 简介

Plan -> build -> review across models, as a zero-dependency MCP server for Claude Code, Cursor and Codex: spec gate before handoff, tool vetting, per-run and per-day cost/token hard stops, safe defaults, clear logs. Based on Codex on Crack by Ethan Rogers
