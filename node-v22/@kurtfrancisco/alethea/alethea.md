> 标签: agent-decision-memory, ai-agents, alethea, claude, claude-code, cursor, mcp, mcp-server, model-context-protocol

## 简介

Alethea of Agents (formerly agent-decision-memory): Persistent decision and constraint memory for coding agents: a local stdio MCP server and CLI that store ADR-style decisions as git-friendly markdown, linked to SpecGate requirement ids, tests and commit
