# docker-ci

> 标签: continuous integration, docker, docker-ci

## 简介

Docker-ci - an ultimate solution to managing docker containers.
Say you want to launch multiple containers and link them together. Sounds easy, right? But what if you need to clean stopped containers? Ensure container is running? Kill or remove container
