# dsh-zotero-local

> 标签: deepseek-harness, dsh, dsh-plugin, reference-manager, research, zotero

## 简介

Zotero tools for DeepSeek Harness via the Zotero local API (no API key): search your library, read item metadata and abstracts, list collections and attachments, read PDF full text (on-the-fly parsing), download PDFs and manage notes.
