# dsh-mobile-enter

> 标签: JavaScript

## 简介

dsh web GUI 客户端插件：手机端输入框回车改为换行（Shift+Enter 发送），避免误触发送；桌面端不受影响。

## 官网

- npm 页面：https://www.npmjs.com/package/dsh-mobile-enter
