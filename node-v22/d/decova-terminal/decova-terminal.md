# decova-terminal

> 标签: cli, cmd, command, command-line-tool, console, exec, execute, programatically

## 简介

It's a library for creating a cli tools. It wraps the great inquirer package in a more convenient way to use for .net and java developers. It also facilitates running commands as a part of your cli tool.
