# dsh-a-stock-select

> 标签: A股, a-stock, cordis, dsh, skill, 投资, 股票, 选股

## 简介

A股选股与持仓诊断 DSH 插件：四大策略（超短线/短线/中线/长线）+ 持仓诊断，基于 a-stock-data 开发，内置 47 个数据端点，输出强制风险提示
