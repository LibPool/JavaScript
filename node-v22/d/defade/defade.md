# defade

> 标签: base, bundle detection, crypto security api, defade, ethereum, insider detection, mcp, memecoin, rug checker, rug pull, rug score, solana, token security, wallet forensics

## 简介

Official SDK for the DeFade API — rug pull risk scores and on-chain forensics (bundles, funding traces, deployer history) for tokens on Solana, Ethereum, Base and Robinhood Chain.
