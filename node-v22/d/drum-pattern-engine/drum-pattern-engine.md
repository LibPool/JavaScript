# drum-pattern-engine

> 标签: arrangement, drum, generator, groove, music, pattern, sequencer

## 简介

Universal drum-pattern + song-arrangement generator. Emits a device-agnostic song structure (roles, velocity, micro-timing, meter). No runtime dependencies.
