# dsh-engram

> 标签: deepseek-harness, dsh, dsh-plugin, long-term-memory, memory, pi-esr, symbolic-index

## 简介

Minimalist long-term memory for DeepSeek Harness, distilling symbolic-index + pi-esr ideas: zero-LLM auto-capture, a symbolic [ENGRAM] index with progressive disclosure, and an ESR-lite evidence-closure protocol (esr_task / esr_node / esr_close / esr_link
