# dsh-vnc-client

> 标签: cordis, deepseek-harness, dsh, plugin, remote-desktop, rfb, screen-sharing, vnc, vnc-client

## 简介

VNC client tab for the DeepSeek Harness right sidebar: an RFB client that connects to any VNC/RFB server over a WebSocket-to-TCP bridge running in the Host
