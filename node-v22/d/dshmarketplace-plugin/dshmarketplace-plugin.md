# dshmarketplace-plugin

> 标签: deepseek-harness, dsh, dsh-plugin, marketplace, plugin-store

## 简介

Browse and install DeepSeek Harness plugins from inside DSH, in English or Chinese.

- 官网：https://dshmarketplace.dev
- 源码仓库：git+https://github.com/DshMarketPlace/dsh-plugins-store.git
