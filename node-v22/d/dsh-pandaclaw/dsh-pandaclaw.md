# dsh-pandaclaw

> 标签: JavaScript

## 简介

PandaClaw 民主协商多智能体会议系统：dsh-team 之上的伴生插件，提供六类会议阶段状态机、M1 机械计票、表决前置门、准入审查、监督窗口双门（关窗预告＋缺席替身）、归档后复审回告闭环（有备必审/审查替身/异议方陈述/出口三选）等代码级强制，以及浏览器侧会议舞台视图
