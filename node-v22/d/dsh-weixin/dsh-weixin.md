# dsh-weixin

> 标签: bundle, clawbot, deepseek-harness, ilink, plugin, wechat, weixin

## 简介

微信 ClawBot (iLink) 通道插件：把微信消息接入 DeepSeek Harness 会话，按用户隔离、原生注入与回发。
