# dsh-inline-figures

> 标签: agent-output-readability, asd-ste100, cordis, deepseek-harness, diagrams, draw_figure, dsh, dsh-plugin, inline-figures, svg

## 简介

DeepSeek Harness (DSH) host plugin: the model draws clean vector figures inline between the paragraphs of its reply, so answers arrive as text-figure-text instead of a wall of text.
