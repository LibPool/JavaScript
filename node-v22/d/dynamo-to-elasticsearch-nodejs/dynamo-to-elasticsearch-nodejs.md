# dynamo-to-elasticsearch-nodejs

> 标签: AWS, AWS Blueprint, AWS Dynamo, AWS ES, AWS Elasticsearch, AWS Handler, AWS dynamodb streams, AWS serverless, AWS streams, Dynamo to Elasticsearch trigger, DynamoDB, Elastic Search, Lambda, javascript, node js

## 简介

Performance oriented node.js lambda handler for DynamoDB to Elastic search using DynamoDB streams. This module uses Bulk processing. Compatible with node 12.x and above.
