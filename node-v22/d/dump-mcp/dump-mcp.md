# dump-mcp

> 标签: ai, anthropic, api-testing, claude, dump, llm, mcp, model-context-protocol, webhook, webhook-capture

## 简介

MCP server for dump.xoozoo.com webhook capture service - allows AI assistants to create endpoints, view requests, and replay webhooks
