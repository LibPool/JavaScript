# dsh-gotofile

> 标签: changed-files, deepseek-harness, dsh, goto-file, plugin, productivity, reveal-in-file-manager, web-ui

## 简介

Turn-tail text report of the files this turn produced or modified, each with its full path; double-click a path to reveal it in the OS file manager
