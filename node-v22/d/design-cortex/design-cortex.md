# design-cortex

> 标签: ai-agents, claude, claude-code, cursor, design-system, design-tokens, figma, knowledge-base, mcp, skills

## 简介

Point an AI agent at your Figma design system and generate a portable, two-tier markdown knowledge base — every component, variant, token, and composition rule — that any agent can read at session start instead of querying Figma live.
