# dsh-graph-client

> 标签: deepseek-harness, dsh, dsh-plugin, goals, graph, kanban, plugin, ui

## 简介

dsh-graph 的 client 半边：在 DSH Web 界面内渲染二维泳道目标看板（看板/详情/写操作工作台），host 半边注册 /api/dsh-graph REST 端点。
