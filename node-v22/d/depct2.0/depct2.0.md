# depct2.0

> 标签: ai-agents, causal-chains, claude-code, cli, copilot, cursor, debugging, depct, error-detection, instrumentation, nodejs, observability, runtime-intelligence, shape-diff, test-generation

## 简介

Runtime state for AI coding agents. Instruments Node.js apps with zero code changes, captures error patterns with causal chains and arg shape diffs, outputs structured JSON that AI agents consume to fix bugs.
