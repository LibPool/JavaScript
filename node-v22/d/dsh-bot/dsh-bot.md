# dsh-bot

> 标签: automation, bot, cron, deepseek-harness, dsh-plugin, headless, scheduler, webhook

## 简介

Bot framework for the DeepSeek Harness (dsh) - run headless dsh agents on cron schedules, webhooks, and queues, with run logs, retries, and CI-friendly exit codes.
