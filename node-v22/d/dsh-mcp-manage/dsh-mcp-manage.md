# dsh-mcp-manage

> 标签: cordis, deepseek-harness, dsh, dsh plugin, dsh-plugin, harness, mcp, mcp-client, model-context-protocol, plugin

## 简介

A DeepSeek Harness (DSH) static market plugin that adds an 'MCP 服务' management page in Settings: list / add / edit / delete the MCP servers registered in cordis.patch.yml, and run a real MCP initialize connection handshake per server to verify each servic
