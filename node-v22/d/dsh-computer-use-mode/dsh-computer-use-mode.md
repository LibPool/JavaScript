# dsh-computer-use-mode

> 标签: computer-use, deepseek-harness, dsh, dsh-plugin, gui-automation, screen-capture

## 简介

Computer-use mode for DeepSeek Harness: native-resolution screen capture plus mouse, keyboard and window control, for operating software that has no agent-facing integration.
