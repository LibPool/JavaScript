# dsh-github-mcp-hint

> 标签: JavaScript

## 简介

DSH 插件：GitHub MCP 示例提示面板（设置→插件，随机 4/30 条可复制 + 公开仓库星/fork 可视化）+ gh_repo_stats / gh_current_user 模型工具（星数/近14天克隆量/当前账号）。前端直连公开 API 但带本地缓存降频与容错，避免触发 403。
