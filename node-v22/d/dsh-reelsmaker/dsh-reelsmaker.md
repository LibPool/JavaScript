# dsh-reelsmaker

> 标签: deepseek-harness, dsh, dsh-plugin, reels, remotion, tts, video

## 简介

DeepSeek Harness plugin: turn lines of narration into a finished vertical reel. Free neural voice-over, burned-in captions, no API keys.
