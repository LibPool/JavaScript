# dsh-ui-projects

> 标签: JavaScript

## 简介

Extensible UI project system for the dsh Web GUI: a UI project registry, a dynamically rendered Settings > UI section, and one built-in skin (Glass) that ships OFF and is switched on like any other project. External UI project packages stay a first-class
