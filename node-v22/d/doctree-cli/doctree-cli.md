# doctree-cli

> 标签: cli, code-documentation, dev-tools, developer-utilities, directory-tree, doc-generator, documentation, folder-structure, fs-tree, markdown, npx, project-structure, readme, tree, vscode-extension

## 简介

Generate clean project structure trees for README.md from the command line. Works anywhere — no editor needed. Auto-creates README, supports custom ignores, and saves full structure to fs-full.md.
