# dsh-session-memo

> 标签: cordis, deepseek-harness, dsh, git, memo, npm, plugin, session

## 简介

DSH Web UI 对话侧边备忘录：GitHub 同步状态（自动探测 git）/ npm 发布状态（自动对比 registry）/ 项目版本 / 手动备忘标签，与 dsh-session-status 状态标签联动
