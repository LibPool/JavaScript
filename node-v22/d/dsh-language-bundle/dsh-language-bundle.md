# dsh-language-bundle

> 标签: JavaScript

## 简介

dsh-external in-box dsh bundle: the 'force Chinese responses' agent language directive, contributed as a global system-prompt section (toggle is a disabled flip in the DSH_HOME cordis.patch.yml, hot-reloaded).
