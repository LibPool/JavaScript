# decision-gate

> 标签: 429, backoff, budget, cache, decision-model, jev, rate-limit, rate-limiter, retry, spend-limit, typesafe

## 简介

Rate and spend limits for calling TypeSafe Jev from Node: an account-wide 429 pause with backoff, a shared rate limiter, a per-key daily spend ceiling, an answer cache that stores no text, and never-send checks
