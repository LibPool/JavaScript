# dsh-opencode-zen-plugin

> 标签: cordis, cordis-plugin, deepseek-harness, dsh, dsh-plugin, llm, llm-adapter, llm-provider, opencode, opencode-console, opencode-zen

## 简介

OpenCode Console (Zen) models for DeepSeek Harness (DSH): fill in your Console API key under Settings → Plugins and the Console's chat models become selectable.
