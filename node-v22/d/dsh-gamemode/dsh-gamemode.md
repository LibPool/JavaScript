# dsh-gamemode

> 标签: agent-preset, deepseek-harness, dsh, gamemode, plugin, slash-command

## 简介

DSH 插件：/gamemode 1 = 一键切换到内置创造模式（cordis）预设。DSH plugin: /gamemode 1 = switch to the built-in Creative Mode (cordis) agent preset.
