# doodleworks-mcp

> 标签: gemini, illustration, image-generation, mcp, mcp-apps, model-context-protocol, openai

## 简介

Turn any idea, blog post, article, or X post into hand-drawn "Tinku" illustrations that explain the key concepts — an MCP App with an interactive viewer for your AI host; bring-your-own image API key (OpenAI/Gemini).
