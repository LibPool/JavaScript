# dsh-skill-admin

> 标签: deepseek-harness, dsh, plugin, skill-admin, skill-manager, skills

## 简介

在设置页「技能管理」或独立管理页中列出/新建/编辑/改名/删除 DSH 技能文件, 支持 kebab-case 校验、自定义根目录、模型/用户调用开关; 纯文件管理不接管官方技能提供方, 修改经 DSH watcher 即时生效。Manage DSH skills from the Settings panel or a host-served page: list/create/edit/rename/delete skill files with validation, custom roots, a
