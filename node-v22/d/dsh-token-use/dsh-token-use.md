# dsh-token-use

> 标签: cost, cost-estimation, deepseek-harness, dsh, dsh-plugin, echarts, heatmap, token, token-usage, usage-dashboard

## 简介

Real-time token usage and estimated spend for DeepSeek Harness, in a four-tab settings panel: an overview with cost/totals cards, a trend chart with a daily-average line and a 12-month usage heatmap; by-model and by-project tables with day/month/year/date
