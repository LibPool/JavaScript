# dsh-web-search-unified

> 标签: agent, deepseek-harness, dsh, exa, firecrawl, llm, plugin, search, tavily

## 简介

Unified multi-engine search provider for DeepSeek Harness: one plugin, three engines (Exa / Tavily / Firecrawl), three model-facing tools (web_search_exa / web_search_tavily / web_search_firecrawl) plus standard web_search fallback.
