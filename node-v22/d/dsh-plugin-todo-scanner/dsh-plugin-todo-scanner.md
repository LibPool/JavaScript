# dsh-plugin-todo-scanner

> 标签: code-scan, cordis, deepseek-harness, fixme, plugin, scanner, tech-debt, todo

## 简介

DeepSeek Harness TODO 代码扫描插件：扫描本地项目目录中的 TODO/FIXME/HACK/NOTE 等标记，生成结构化清单，支持状态管理、Markdown 导出与侧边面板。
