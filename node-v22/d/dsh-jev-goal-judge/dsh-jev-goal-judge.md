# dsh-jev-goal-judge

> 标签: agent-harness, decision-model, deepseek-harness, dsh, goal-loop, jev, system-one, typesafe

## 简介

Jev progress judgment between DeepSeek Harness goal rounds: one bounded typed-decision call at each round boundary steers verify-complete or report-blocked nudges back into the same turn, saving wasted rounds — shadow mode by default, fail-open everywhere
