# dsh-plugin-telegram

> 标签: ai-agent, bot, deepseek-harness, dsh, dsh-plugin, self-hosted, telegram

## 简介

Self-hosted Telegram front for DeepSeek Harness (dsh): pick a project, join dsh sessions as chats, run headless agents from Telegram. No external services — just your bot token.
