# dsh-skill-station

> 标签: agent-skills, claude, codex, cursor, deepseek-harness, dsh, dsh-plugin, gemini, skill-manager, skills

## 简介

Skill station for DeepSeek Harness: a sidebar hub that scans Claude/Codex/Cursor/Gemini skill libraries, imports skills with one click, manages global and project skills, and installs skill folders by drag-and-drop. · DSH 技能站：侧边栏技能中枢，扫描各家 agent 技能库一键导入，管理
