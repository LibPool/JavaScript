# dsh-roster-consumer

> 标签: JavaScript

## 简介

Roster consumer for DeepSeek Harness: register roster_* tools so digital-twin workers can read/write their roster entry over the roster-server HTTP API, off by default and enabled per twin via settings; ships a DSH settings-page tab (shared roster config)
