# dsh-llm-xai-oauth

> 标签: deepseek-harness, dsh, dsh-plugin, grok, llm-provider, oauth, subscription, supergrok, xai

## 简介

Native SuperGrok / X Premium OAuth provider for DeepSeek Harness. Reuses local grok-bridge tokens; no xAI API key.
