# dbml-diff

> 标签: d2, database, dbdiagram, dbml, diff, migration, schema, svg

## 简介

Structural diff for DBML schema files - emits text, JSON, an annotated DBML document that renders as a visual diff in dbdiagram.io, D2 diagram source, or a locally-rendered SVG
