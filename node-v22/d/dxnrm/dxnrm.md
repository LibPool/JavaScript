# dxnrm

> 标签: NPM, registry

## 简介

`dxnrm` can help you easy and fast switch between different npm registries, now include: `npm`, `cnpm`, `taobao`, `tencent`.

- 官网：https://github.com/duiyuan/dxnrm
- 源码仓库：git://github.com:duiyuan/dxnrm.git
- npm 页面：https://www.npmjs.com/package/dxnrm
