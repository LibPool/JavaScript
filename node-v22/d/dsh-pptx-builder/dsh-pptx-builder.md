# dsh-pptx-builder

> 标签: charts, code, deepseek-harness, dsh, dsh-plugin, formulas, latex, math, powerpoint, pptx, presentation, slides

## 简介

PowerPoint decks for DeepSeek Harness: pastel palettes, ten slide templates, styled text, web images, Python-rendered charts, highlighted code cards and LaTeX formulas (matrices, integrals, sums), plus a ready-made Presentations agent mode.
