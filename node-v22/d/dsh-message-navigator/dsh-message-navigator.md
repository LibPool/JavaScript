# dsh-message-navigator

> 标签: chat, deepseek-harness, dsh, dsh-plugin, message-navigation, web-gui

## 简介

DSH Web GUI 插件：会话右侧悬浮消息导航条 —— 收起态 10 条短横杠，悬停展开为用户消息摘要，点击平滑滚动定位历史消息；固定 10 条窗口 + 跟随/锁定模式 + 增量更新。
