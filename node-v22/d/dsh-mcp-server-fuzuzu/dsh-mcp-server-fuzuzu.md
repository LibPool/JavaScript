# dsh-mcp-server-fuzuzu

> 标签: deepseek-harness, dsh, fuzuzu, mcp, plugin

## 简介

DeepSeek Harness plugin: connects the Fuzuzu (福租租) MCP server over its custom SSE transport and registers its tools as native mcp__fuzuzu__* tools
