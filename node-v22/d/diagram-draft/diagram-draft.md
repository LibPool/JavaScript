# diagram-draft

> 标签: architecture, cli, codebase, dataflow, dependencies, diagrams, mermaid, visualization

## 简介

A CLI workflow tool that scans your codebase and auto-generates Mermaid diagrams for architecture, data flow, and module dependencies. Built with AI by Craftpipe
