# dsh-resume-screening

> 标签: ats, candidate, deepseek-harness, dsh, dsh-plugin, hr, markdown, plugin, recruiting, resume, resume-screening, sqlite

## 简介

Resume screening plugin for DeepSeek Harness (HR): ingest up to 100k Word/PDF/Excel resumes into one searchable library with skills / coarse categories / ingest time, auto-ingest & de-dupe new resumes, then screen by plain-language criteria — rule pre-fil
