# dsh-jev-decide

> 标签: decision, deepseek-harness, dsh-plugin, jev, system-one, typesafe

## 简介

DSH 插件：把 TypeSafe Jev（System One 决策模型）注册为 agent 工具 jev_decide。调用 https://api.typesafe.ai/v1/systemone，让 agent 在路由/分级/guardrail 等场景拿到带校准概率的结构化判定（noul/choice/score），而不是让大模型瞎猜。
