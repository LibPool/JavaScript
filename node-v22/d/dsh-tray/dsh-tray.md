# dsh-tray

> 标签: deepseek-harness, dsh, system-tray, tray, voice-input-helper, windows

## 简介

System tray manager for DeepSeek Harness (dsh) web: start/stop/autostart/open browser from a tray icon. Windows / PowerShell based.
