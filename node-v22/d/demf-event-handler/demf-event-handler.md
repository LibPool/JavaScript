# demf-event-handler

> 标签: JavaScript

## 简介

The Event Handler microfrontend handles common errors returned by server calls (400, 401, 403, 404, 409, 500-599 errors). It works in the background listening for error events and displays alert notifications to users, managing centralized error handling
