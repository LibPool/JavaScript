# dsh-desktop-entry

> 标签: cordis, deepseek-harness, desktop, dsh, plugin

## 简介

DeepSeek Harness plugin: creates a Windows desktop entry (shortcut + launcher) that opens the web UI in a Chrome app-mode window. No installer, no bundled runtime.
