# ds-notify-plugin

> 标签: bundle, deepseek-harness, dsh, notification, plugin, toast, windows

## 简介

Windows 对话完成通知插件：主对话每轮完成后弹出 Windows 系统 toast 通知，并标明所属对话的标题。
