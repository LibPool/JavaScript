# dsh-prompt-predict

> 标签: composer, deepseek-harness, dsh-plugin, ghost-text, prompt-prediction

## 简介

输入框提示词联想插件：助手回复结束后预测你的下一句话，以灰色 ghost text 浮在输入框里，Tab 采纳、Esc 忽略 ｜ Codex-style composer prompt predictions for DeepSeek Harness: your next message ghosted into the composer, accepted with Tab.
