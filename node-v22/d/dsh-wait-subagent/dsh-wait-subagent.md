# dsh-wait-subagent

> 标签: agent, background, continuable, cordis-plugin, deepseek-harness, dsh, dsh-plugin, parallel, settlement, subagent, wait, 后台任务, 子代理, 并行, 收尾消息, 智能体, 等待

## 简介

Active wait for background continuable subagents in DeepSeek Harness: registers a wait_subagent tool that blocks until the named subagent settles, then returns its stop reason and closing message — closing the gap between run_in_background fire-and-return
