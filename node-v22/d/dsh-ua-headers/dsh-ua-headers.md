# dsh-ua-headers

> 标签: deepseek-harness, dsh, dsh-ecosystem-spec, dsh-plugin, headers, user-agent

## 简介

自定义所选模型调用时的 User-Agent 与额外请求头；遵循 dsh-ecosystem-spec，配置存储于 LocalStorage 并以声明式设置项呈现。
