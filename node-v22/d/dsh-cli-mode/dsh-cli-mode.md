# dsh-cli-mode

> 标签: cli, cordis, deepseek-harness, dsh, plugin, terminal

## 简介

把 DeepSeek Harness 会话变成终端可交互的 CLI:终端直接与 agent 对话、切换会话/模型/模式/权限模式、审批桥接、codex 式工作区。
