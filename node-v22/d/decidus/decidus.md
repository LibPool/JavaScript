# decidus

> 标签: anthropic, canary, decision models, function calling, gateway, gemini, human in the loop, jev, litellm, llm, openai, prompt management, shadow, structured outputs

## 简介

The policy loop for decision models: people decide what the model couldn't, decidus rewrites the decision's text, replays it for accuracy and tries it in shadow or canary before it goes live. Structured outputs, tool calls, OpenAI Decisions and Jev, direc
