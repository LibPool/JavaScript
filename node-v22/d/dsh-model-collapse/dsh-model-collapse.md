# dsh-model-collapse

> 标签: deepseek-harness, dsh, dsh-plugin, model-picker, ui

## 简介

DSH web plugin: collapse the model picker by provider, with a pinned quick bar for expand-all / collapse-all / focus-current / filter / reset.
