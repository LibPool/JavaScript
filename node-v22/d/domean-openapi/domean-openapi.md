# domean-openapi

> 标签: JavaScript

## 简介

根据 [OpenApi3](https://swagger.io/blog/news/whats-new-in-openapi-3-0/) 文档生成 request 请求代码。 根据 [@umijs/openapi](https://github.com/chenshuai2144/openapi2typescript) 修改增加支持axios请求库。
