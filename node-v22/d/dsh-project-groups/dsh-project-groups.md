# dsh-project-groups

> 标签: deepseek-harness, dsh, dsh-plugin, project-document, project-groups, session-groups, sidebar, workspace

## 简介

DSH plugin: group sidebar sessions by project (a label, not a directory), give each project a work document whose format follows a spec, register its related links, and show the exact runtime-context injection on the settings card.
