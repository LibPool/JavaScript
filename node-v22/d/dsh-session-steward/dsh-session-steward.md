# dsh-session-steward

> 标签: archive, deepseek-harness, doctor, dsh, dsh-plugin, health, session

## 简介

DSH Web 插件：会话管家 —— 会话历史文件（归档浏览与清理）与会话健康检查（体检 → 处方 → 出院），不碰会话日志、只做可逆处置
