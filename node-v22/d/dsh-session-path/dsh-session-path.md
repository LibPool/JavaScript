# dsh-session-path

> 标签: deepseek-harness, dsh, dsh-plugin, handoff, path, session, session-log, 会话, 接续

## 简介

DeepSeek Harness plugin: copy a session's log path (and an agent-readable handoff) so another session can read it and continue the work.
