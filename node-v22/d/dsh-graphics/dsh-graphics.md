# dsh-graphics

> 标签: agent-tools, canvas, cordis, deepseek-harness, diagram, dsh, dsh-plugin, excalidraw, prototype, wireframe

## 简介

Excalidraw canvases inside the workspace for DeepSeek Harness: five agent tools to draw, read and update .excalidraw files, SVG export, and rendered PNGs handed straight back to the model so it can see its own drawing.
