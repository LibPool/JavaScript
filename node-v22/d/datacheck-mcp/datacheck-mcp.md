# datacheck-mcp

> 标签: ai-agent, csv, data-checking, data-quality, data-validation, llm, mcp, model-context-protocol

## 简介

Give AI agents the ability to check whether data is actually correct — duplicate keys, impossible dates, silent nulls, rows that would be lost.
