# dsh-trend-radar

> 标签: analytics, cordis, dashboard, deepseek-harness, dsh, dsh-plugin, plugin, radar, trend, web

## 简介

Ecosystem trend dashboard ('行情面板') for dsh plugins: snapshot the dsh-plugin topic and awesome list into local history, then report weekly trends — new plugins, star gainers, category heat, awesome coverage — plus keyword radar for new plugins and star sur
