# dsh-mmx-bridge

> 标签: ai-agent, deepseek-harness, dsh, image-cache, imgjson, minimax, mmx-cli, multimodal, plugin

## 简介

MiniMax multimodal bridge for DeepSeek Harness (DSH). One mmx_bridge tool covers describe/image/video/speech/music/cover/search/quota; optional web_search/read_image takeover; built-in client enhancement renders inline players/previews plus a settings-pag
