# durablestack

> 标签: background-jobs, cron, durable-jobs, job-scheduler, mysql, postgres, sqlite, sqlserver

## 简介

Durable background jobs for Node.js with PostgreSQL, MySQL, SQL Server, SQLite, and in-memory providers.
