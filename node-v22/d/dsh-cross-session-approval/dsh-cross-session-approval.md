# dsh-cross-session-approval

> 标签: agent, approval, cross-session, deepseek-harness, dsh, orchestration, plugin, session

## 简介

Cross-session task delegation for DeepSeek Harness 0.2.x, with 10 tools, an approval bridge, child-session permission clamping, and base62 session aliases.
