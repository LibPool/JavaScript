# d-spreadsheet

> 标签: Excel

## 简介

D-spreadsheet là một module hỗ trợ bảng tính nhúng cho các ứng dụng web sử dụng thư viện mặt trước ReactJS . Bạn có thể clone D-spreadsheet từ git đểsử dụng cho ứng dụng của bạn nếu thấy phù hợp hoặc có thể cài đặt nó thông qua npm bằng cách . npm install
