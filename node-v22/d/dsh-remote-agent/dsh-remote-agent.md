# dsh-remote-agent

> 标签: agent, ai-agent, artifact, deepseek-harness, dsh, dsh-plugin, handoff, multi-agent, remote-agent, remote-execution, self-hosted, subagent-provider, task-automation, zero-dependency

## 简介

把另一台电脑变成你 DSH 的远程 Agent 同事：副机本地持久跑任务、独立 Agent 循环，只回传 handoff 摘要与产物清单，成品按需拉取。
