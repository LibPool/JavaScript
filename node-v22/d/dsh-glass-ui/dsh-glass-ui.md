# dsh-glass-ui

> 标签: deepseek, dsh, dsh-plugin, glassmorphism, harness, theme, ui

## 简介

Glassmorphism UI theme for DeepSeek Harness web: frosted-glass surfaces, adjustable opacity/blur, custom fonts, background images & live video wallpapers with carousel, NetEase Cloud Music player with dock lyrics, custom CSS and soft animations. DSH Web 毛
