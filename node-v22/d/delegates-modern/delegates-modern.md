# delegates-modern

> 标签: commonjs, delegates, delegates-compatible, delegation, esm, fluent-api, javascript, metaprogramming, nodejs, object-delegation, property-delegation, typescript

## 简介

Modern, dependency-free TypeScript-first implementation of the delegates@1.0.0 core API, with ESM/CJS, first-party types, symbol support, and additive auto() delegation.
