# dxs-bsv-token-sdk

> 标签: bitcoin-script, bitcoin-sv, bsv, dstas, sdk, stas, typescript

## 简介

TypeScript SDK for Bitcoin SV with first-class DSTAS flows, older STAS helpers, and low-level BSV primitives for transaction and script work.
