# dsh-diagram-orchestrator

> 标签: deepseek-harness, dsh, dsh-plugin

## 简介

Orchestrate diagram generation across Mermaid, draw.io, and Excalidraw DSH plugins by routing user intent to the appropriate engine and reporting engine availability.
