# devkit-for-strapi-mcp

> 标签: ai, ai-agents, cms, mcp, mcp-server, model-context-protocol, schema, strapi, strapi-v4, strapi-v5

## 简介

MCP server exposing accurate Strapi project facts (UIDs, schemas, references) to AI coding agents — reads your real schema.json, so an agent looks values up instead of grepping for them.
