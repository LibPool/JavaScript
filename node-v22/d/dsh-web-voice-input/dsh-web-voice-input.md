# dsh-web-voice-input

> 标签: deepseek-harness, dsh, groq, microphone, plugin, speech-to-text, voice-input, web-ui, whisper

## 简介

Voice input for the DeepSeek Harness (DSH) Web GUI: a microphone button in the chat composer that records audio, transcribes it through an OpenAI-compatible Whisper API (Groq / OpenAI / SiliconFlow), and inserts the recognized text into the input box.
