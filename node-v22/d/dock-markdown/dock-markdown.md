# dock-markdown

> 标签: deepseek-harness, dock, dsh, dsh-plugin, markdown, plugin, viewer, web-ui

## 简介

Markdown viewer for the dock file explorer: renders .md/.markdown/.mdx files with a one-click switch to the text editor.
