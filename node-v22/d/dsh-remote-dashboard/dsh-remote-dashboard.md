# dsh-remote-dashboard

> 标签: dashboard, deepseek, dsh, dsh-plugin, harness, monitor, multi-machine, tablet

## 简介

Read-only wall dashboard for DeepSeek Harness sessions across several machines: pull or push, aggregated by one hub, with a tablet page that fits the screen.
