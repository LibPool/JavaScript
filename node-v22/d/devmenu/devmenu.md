# devmenu

> 标签: cli, command-browser, command-menu, command-picker, developer-tools, devmenu, ink, json, project, react, shell, terminal, tui, yaml

## 简介

A terminal UI to browse and run categorized shell commands, search the whole list, and keep everything in one place instead of hunting through package.json, readmes, and random docs.
