# dsh-croco-generation

> 标签: JavaScript

## 简介

Croco 生成插件套件（DSH bundle）：Croco TV Studio（内嵌 HyperFrames）+ 角色同步 + 视频(H3) + 图片 + 音频(TTS) + 音乐(MiniMax Music 3) + 设置页。
