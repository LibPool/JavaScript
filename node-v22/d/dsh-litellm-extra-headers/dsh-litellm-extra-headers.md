# dsh-litellm-extra-headers

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, extra_headers, litellm, llm, proxy, session-affinity, x-opencode-session

## 简介

DeepSeek Harness plugin: inject an `extra_headers` entry into the OpenAI-compatible request BODY for model calls routed to listed providers and sent to listed upstream hosts — the only injection point that survives a LiteLLM relay, which drops client HTTP
