# ddys-lark-bot

> 标签: api, bot, ddys, event-callback, feishu, lark, lark-bot, message-card

## 简介

Official Feishu/Lark bot integration for the DDYS API with event callbacks, signature verification, encrypted callbacks, message cards, access control, diagnostics, and cache support.
