# dsh-spark-insights

> 标签: deepseek-harness, dsh, minecraft, nukkit, performance, profiler, spark

## 简介

Read spark profiler and heap exports from Minecraft servers and report TPS, MSPT, CPU, memory, GC, hotspots, and plugin attribution.
