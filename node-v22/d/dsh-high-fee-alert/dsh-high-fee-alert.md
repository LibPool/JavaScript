# dsh-high-fee-alert

> 标签: deepseek, dsh, dsh-plugin, fee-alert, harness, ntp, peak, pricing

## 简介

DeepSeek Harness 高峰资费提醒插件：每次启动时从 DeepSeek API 文档抓取最新定价，从 ntp.ntsc.ac.cn 获取北京时间，在峰时段弹出居中提醒窗口（710×430）。
