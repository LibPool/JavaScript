# drobek-module-counter

> 标签: counter, drobek, drobek-module, page-views

## 简介

A drobek platform module: named counters per app (page views, likes, downloads) — POST /__drobek/v1/counter/:key/hit, drobek.counter.hit(key) / get(key) / list().
