# dsh-whale-commands

> 标签: compat, deepseek, deepseek-harness, dsh, harness-0.2, migration, multi-persona, persona, plugin, slash-commands, wechat, weixin, whale

## 简介

Slash commands for the DeepSeek Harness Weixin channel: persona toggle & multi-persona library, session history (soft load or real session switch), model selection, token usage and balance, scheduled daily greetings. Host-side execution, zero model tokens
