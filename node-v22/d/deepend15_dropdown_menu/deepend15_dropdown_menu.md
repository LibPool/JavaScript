# deepend15_dropdown_menu

> 标签: JavaScript

## 简介

A function to show hidden dropdown menus upon click events to the dropdown menu button, and re-hide them upon click events outside of the menu. Also includes class toggling for hovering/clicking on dropdown menu buttons.
