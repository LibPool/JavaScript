# dsh-zcode-browser-use

> 标签: browser, browser-automation, deepseek-harness, dsh, playwright, plugin, sidebar

## 简介

DSH port of the ZCode browser-use plugin: Playwright-backed browser tools plus the upstream control-browser and web-gui-tester skills, and the plugin's own real browser mounted in DSH Desktop's right sidebar for anything behind a login or an anti-bot chec
