# dsh-plugin-cds

> 标签: claude, css-tokens, deepseek, deepseek-harness, design-system, dsh, dsh-plugin, theme

## 简介

Claude Design System theme for DeepSeek Harness: overrides 11 host design tokens (light + dark), ships the CDS scale and motion physics. No fonts, no network requests.
