# dsh-memsearch

> 标签: cordis, deepseek-harness, dsh, memory, memsearch, plugin

## 简介

Automatic semantic memory for DeepSeek Harness (DSH) via memsearch — writes per-turn summaries to the memory journal and injects recall hints, mirroring the Codex/Claude Code memsearch plugins.
