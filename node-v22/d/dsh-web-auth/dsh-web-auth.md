# dsh-web-auth

> 标签: auth, cordis, deepseek-harness, dsh, password, plugin, web

## 简介

Password gate for the DeepSeek Harness Web shell: a webserver fork with the request-gate extension plus a login-page auth plugin. Drop-in replacement for @deepseek-ai/dsh-host-webserver when you need authentication in front of the GUI.
