# daraja-mcp

> 标签: daraja, kenya, m-pesa, mcp, mobile-money, model-context-protocol, mpesa, payments, ratiba, safaricom, standing-order, stk-push

## 简介

MCP server for the Safaricom M-Pesa Daraja 3.0 API. Full product surface including M-Pesa Ratiba, a hardened callback receiver, and an offline simulator so you can test without a Safaricom account.
