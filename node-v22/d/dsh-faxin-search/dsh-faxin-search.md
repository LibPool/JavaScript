# dsh-faxin-search

> 标签: deepseek-harness, dsh, dsh-plugin, faxin, law, legal-search, mcp

## 简介

DSH 客户端插件：登录你的法信(faxin.cn)账号，向 AI 提供结构化的法律条文 / 司法解释 / 裁判规则(审判意见) / 指导性案例检索工具
