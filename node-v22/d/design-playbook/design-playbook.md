# design-playbook

> 标签: cjk, console, craft, design, design-io, design-playbook, dsh-bundle, dsh-plugin, evaluator, pi-package, spec, ui, ux

## 简介

Design I/O for coding agents: evidence-forced UI acceptance — every criterion bound to a captured artifact, findings pointing back to declarations, verdicts owned by the evaluator, not the implementer. Design-baseline covers existing-product UI work. Use
