# diagramweave-mcp

> 标签: ai, claude, diagram, diagramweave, dl, dlv, flowchart, mcp, model-context-protocol, svg

## 简介

MCP server for DiagramWeave: parse DL, resolve DL/DLV to Scenes, render SVG diagrams, and make round-trip text edits from AI assistants (Claude, ChatGPT, Cursor, ...).
