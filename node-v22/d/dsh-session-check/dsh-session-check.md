# dsh-session-check

> 标签: deepseek-harness, diagnostics, dsh, dsh-plugin, maintenance, migration, projection-cache, session, storage

## 简介

Read-only diagnosis of stored DeepSeek Harness sessions (migration gates, including two that call the official v0 validator), offline projection-cache maintenance, and a read-only cache-footprint diagnostic plugin.
