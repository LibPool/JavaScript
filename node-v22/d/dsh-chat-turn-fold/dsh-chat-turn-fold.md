# dsh-chat-turn-fold

> 标签: codex, conversation, deepseek-harness, dsh, fold, plugin, tool-calls

## 简介

DSH web plugin: Codex-style conversation folding — group consecutive tool calls into one collapsible box and collapse each finished turn into a summary card with the elapsed time / total token line on top (expandable to the full process).
