# dotenv-sentinel

> 标签: cli, config-validation, dotenv, env, env-file, environment-variables, github-action, gitignore, sarif, schema, secret-scanning, secrets, security

## 简介

Validate .env files against .env.example or a JSON schema (missing, empty, extra and mistyped variables), flag weak and default secrets, real secrets in example files, and .env files that are committed, in git history or not gitignored. Never prints secre
