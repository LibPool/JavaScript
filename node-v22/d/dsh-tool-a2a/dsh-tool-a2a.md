# dsh-tool-a2a

> 标签: a2a, agent, agent2agent, cordis, dsh, plugin

## 简介

A2A (Agent2Agent) client tools for DeepSeek Harness (DSH) agents: discover agent cards and send/get/cancel tasks over HTTP JSON-RPC.
