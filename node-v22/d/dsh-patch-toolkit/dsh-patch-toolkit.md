# dsh-patch-toolkit

> 标签: conflict, diff, diff3, dsh, lcs, merge, patch, plugin, unified-diff

## 简介

Text-level patch toolkit for DeepSeek Harness: LCS line diff to unified format, hunk application with fuzzy offset tolerance (backward application, no drift), and diff3 three-way merge with git-style conflict markers. Pure in-memory text ops, zero depende
