# dsclaw

> 标签: ai-agent, automation, dropclaw, dropshipping, dsers, feishu, mcp, openclaw, telegram, whatsapp

## 简介

AI-powered dropshipping agent system built on OpenClaw. Two agents (Navigator + Claw-Ops) automate DSers workflows via Telegram, WhatsApp, and Feishu.
