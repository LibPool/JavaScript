# dsh-kaban-board

> 标签: board, cordis, deepseek-harness, dsh, dsh-plugin, kanban, tasks, канбан

## 简介

Personal kanban board for DeepSeek Harness — a global «Канбан доска» panel button that opens a dedicated board screen in the center column with columns and cards (create / rename / delete / drag-drop) persisted to a local JSON file.
