# deps-report

> 标签: abstract-syntax-tree, ast, dependencies, dependency, dependent, dependents, exports, flow, module, packages, report, reporter, require, tracking, typescript, usage

## 简介

Generate reports about dependencies and dependents of your JavaScript/TypeScript files through an AST. It supports import and require statements.
