# dsh-session-port

> 标签: archive, backup, deepseek, deepseek-harness, dsh, dsh-plugin, export, import, session, zip

## 简介

DeepSeek Harness 会话导入导出插件：把会话导出为压缩包，或把导出的会话作为新会话导入当前工作区，附件随会话一起搬运。
