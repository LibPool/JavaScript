# dsh-shell-themes

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, theme, themes

## 简介

dsh-desktop 内建主题宿主：一个插件承载多个数据主题（themes/<id>/），经 webserver/index-inject 注入活动主题的前端 CSS；主题清单同时供壳复用（窗口底色 / 启动屏）
