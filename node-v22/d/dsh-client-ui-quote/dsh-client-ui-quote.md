# dsh-client-ui-quote

> 标签: annotation, comment, deepseek-harness, dsh, dsh-plugin, kimi-code, quote, review, selection

## 简介

Turn any DSH selection into a reviewable quote — comment / add to chat / side chat, source highlights and jump-back, a searchable review list, side threads, revisions, and per-quote reply badges.
