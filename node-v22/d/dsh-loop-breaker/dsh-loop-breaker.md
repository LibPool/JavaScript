# dsh-loop-breaker

> 标签: agent-safety, circuit-breaker, deepseek-harness, dsh, dsh-plugin, guard, llm, loop-breaker

## 简介

Same-args circuit breaker for DeepSeek Harness: blocks identical tool calls repeated in a sliding window via ctx.tools.guard (agent loop prevention)
