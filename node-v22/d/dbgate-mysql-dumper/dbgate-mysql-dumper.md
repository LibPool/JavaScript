# dbgate-mysql-dumper

> 标签: backup, database, dump, mariadb, mysql, mysql2, mysqldump, restore, sql

## 简介

Standalone, client-agnostic MySQL SQL dump and restore library for Node.js, compatible with native mysqldump/mysql
