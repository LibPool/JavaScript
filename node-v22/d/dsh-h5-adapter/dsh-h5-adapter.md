# dsh-h5-adapter

> 标签: JavaScript

## 简介

H5 shell adapter: narrow-viewport (<=1023px) layout overrides for the DSH web shell plus touch-first interaction fixes — header corner pinned right, account/row menus above the drawer, always-visible session row actions, and a history-backed back gesture
