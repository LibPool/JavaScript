# dsh-vaultwarden

> 标签: bitwarden, cordis, credentials, deepseek-harness, dsh, dsh-plugin, plugin, realtime, secrets, sync, totp, vault, vaultwarden, websocket

## 简介

Vaultwarden/Bitwarden real-time sync for DeepSeek Harness: WebSocket push notifications, on-disk vault cache with revision probing, read/write tools and an entry browser panel. Independent implementation; see THIRD-PARTY-NOTICES.md.
