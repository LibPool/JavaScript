# dsh-token-heatmap-wyz

> 标签: deepseek-harness, dsh, dsh-plugin, heatmap, token-usage, 用量, 统计

## 简介

dsh web 的 Token 用量热力图：固定近 26 周（周日起始对齐）按天着色、GitHub 风格、深色/浅色自适应；今日/本周/本月/累计四个总量 chip 点击即把明细表锁定到对应时段，可再点选单日；明细按 provider/model 拆分（输入/输出/缓存读/缓存写/占比）。数据全部来自本机会话日志，增量聚合 + 磁盘缓存。
