# deepworker

> 标签: cli, codex, deepseek, deepworker, dsh, mcp, orchestration

## 简介

DeepWorker: Codex orchestrates DeepSeek Harness (DSH) over its local HTTP/WebSocket protocol. Exposes 12 MCP tools over stdio and a doctor CLI.
