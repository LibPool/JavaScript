# deny-sh-openai-agents

> 标签: ai-agents, credential-isolation, deniable, deny.sh, openai-agents, openai-agents-sdk, tool-calling, vault

## 简介

Wrap a deny.sh vault entry as an OpenAI Agents SDK tool. The credential resolves inside execute(); only a narrowed DTO reaches the model. Fail-closed leak sweep.
