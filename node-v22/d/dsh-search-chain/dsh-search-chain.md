# dsh-search-chain

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, web-search

## 简介

链本体（三级模型：源 → key → 额度，按 key 记账/闸门/自动停用）：注册 web_search 的 provider 并供应配置卡片。由 dsh-websearch-tavily-keys-select 依赖，通常无需单独安装。
