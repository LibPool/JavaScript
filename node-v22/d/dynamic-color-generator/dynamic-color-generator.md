> 标签: color, color-generator, color-palette, color-scheme, css-variables, random-colors, styling, theme, web-design

## 简介

A simple utility that generates dynamic color schemes, either randomly or based on a base RGB color. It automatically sets CSS variables, allowing your web application to have a fresh, unique look each time it loads, with either custom or default color sc
