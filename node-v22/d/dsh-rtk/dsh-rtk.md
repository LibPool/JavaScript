# dsh-rtk

> 标签: compression, cordis, deepseek-harness, dsh, plugin, pwsh, rtk, token-killer

## 简介

Per-session rtk output-compression switch for the pwsh tool + composer dock badge + /rtk command. Writes NO session events: per-session state lives in a $DSH_HOME/plugin-state sidecar keyed by session id, and the badge reads GET /rtk/state (fetch mode). T
