# dreama-link

> 标签: audio, bot, dave, discord, discord.js, dreama-link, e2ee, lavalink, lavalink-v4, lavalyrics, lavasrc, music, music-streaming, player, queue, sponsorblock

## 简介

A powerful but simple, Lavalink v4 client for Discord.js bots! supports ESM & CJS, full REST API, filters, queues, session resuming, DAVE E2EE, and plugin support.
