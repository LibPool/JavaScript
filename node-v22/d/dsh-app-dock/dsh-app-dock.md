# dsh-app-dock

> 标签: JavaScript

## 简介

Bandung Circuits 应用坞：dsh 应用集群宿主。成员应用（Auctor/Pictor/POMASA Studio…）以依赖本插件入伙，经 window.__dshAppDock__ 注册自己的开关；坞在 dsh 左下角 footer 直接排成员应用图标网格（每行两个、多了加行），点图标直达应用，无中间面板。
