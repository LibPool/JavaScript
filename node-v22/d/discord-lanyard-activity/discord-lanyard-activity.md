# discord-lanyard-activity

> 标签: activity, discord, framework-agnostic, headless, lanyard, presence, react, svelte, vue, websocket

## 简介

A headless, framework-agnostic Discord activity tracker using Lanyard API. Works with React, Vue, Svelte, and vanilla JavaScript.
