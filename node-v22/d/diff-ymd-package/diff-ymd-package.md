# diff-ymd-package

> 标签: aY-bM-cD, aYears-bMonths-cDays, age, age-calculator, age-finder, customized-format, date-calculator, date-difference, date-time, date-utility, dates, dates-difference, desired-formats, diff-library, diff-ymd, diff-ymd-package, formatted-dates-difference, formatted-difference, time-intervals, ymd

## 简介

A javascript library for calculating the difference between two dates in formatted ways like (aY bM cD)(aYears bMonths cDays) or customized desired formats like aY-bM-cD or aYears-bMonths-cDays or kDays or mWeeks or nMonths etc.
