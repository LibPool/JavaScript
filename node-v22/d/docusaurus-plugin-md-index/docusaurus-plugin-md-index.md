# docusaurus-plugin-md-index

> 标签: docusaurus, index, markdown, mdx, plugin, remark, search, unified

## 简介

Plugin para Docusaurus que indexa Markdown/MDX em texto puro com rotas e headings, disponível via usePluginData.

## 官网

- npm 页面：https://www.npmjs.com/package/docusaurus-plugin-md-index

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install docusaurus-plugin-md-index`
- npm registry：https://registry.npmjs.org/docusaurus-plugin-md-index
- Node 要求：>=18
