# dsh-hunk-review

> 标签: deepseek, deepseek-harness, diff, dsh, dsh-plugin, harness, hunk, review

## 简介

Review the agent's file edits per hunk in the DeepSeek Harness Web UI: keep or revert each hunk, a whole file, or every change of a turn, with conflict detection and a note to the agent about what you reverted.
