# dsh-opencode-bridge

> 标签: deepseek-harness, dsh, dsh-plugin, free-models, llm-adapter, opencode, opencode-bridge

## 简介

Use OpenCode free models in DSH, with automatic model refresh, optional context trimming of completed-turn reasoning and egress-proxy rotation. Includes a tool bridge that rejects unsafe conversions by default, plus offline, agent-scoped compatibility aud
