# dsh-mnemos-continuity

> 标签: cognitive-architecture, deepseek-harness, dsh-plugin, memory, mnemos

## 简介

Cross-model continuity for DeepSeek Harness: memory, skills and rules live in local files, so judgement survives session and model changes. Not about storing more memory — about using it well after the model changes.
