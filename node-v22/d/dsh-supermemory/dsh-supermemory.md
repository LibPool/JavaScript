# dsh-supermemory

> 标签: ai, claude-code, context, deepseek-harness, dsh, dsh-plugin, memory, supermemory

## 简介

Persistent memory across DeepSeek Harness (DSH) sessions using Supermemory. A native port of the Claude Code supermemory plugin.
