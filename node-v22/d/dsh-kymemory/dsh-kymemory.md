# dsh-kymemory

> 标签: deepseek-harness, dsh, dsh-plugin, markdown, memory, persistent-memory, progressive-disclosure

## 简介

Layered local memory for DeepSeek Harness: a Markdown index auto-injected into the system prompt, a route layer read on demand, and evidence files for detail. Pure files, zero runtime dependencies.
