> 标签: cordis, deepseek, deepseek-harness, deepseek-harness-plugin, deepseek-harness-web, dsh, dsh-plugin, plugin-guard, plugin-manager, plugin-safety

## 简介

Plugin Guard for the official DSH web client: isolate broken user plugins so the web UI stays up, plus one-click self-update from npm.
