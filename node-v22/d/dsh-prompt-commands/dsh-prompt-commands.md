# dsh-prompt-commands

> 标签: deepseek-harness, dsh, plugin, prompts, slash-commands, templates

## 简介

pi-style prompt templates for dsh: .agents/prompts markdown templates dynamically registered as slash commands, compatible with pi's prompt template format.
