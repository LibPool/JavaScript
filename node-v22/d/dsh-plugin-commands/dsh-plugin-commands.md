# dsh-plugin-commands

> 标签: deepseek-harness, dsh, opencode, openspec, plugin, slash-command

## 简介

DSH 通用斜杠命令加载器插件：扫描项目 .agents/commands/*.md 与 .dsh/commands/*.md，注册为 opencode 风格的 / 斜杠命令
