# dsh-lan-link

> 标签: deepseek-harness, dsh, dsh-plugin, lan, launch-token, mobile, remote, reverse-proxy, websocket, 反向代理, 局域网, 手机访问, 远程访问

## 简介

Give this harness process LAN access: publish its authenticated launch links to <harness home>/lan-link.txt (and DSH_LAN_LINK), and optionally serve devices directly on a fixed LAN port — the session is held locally, so a device needs no token.
