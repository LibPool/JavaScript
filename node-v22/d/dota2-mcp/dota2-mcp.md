# dota2-mcp

> 标签: console-bridge, custom-game, dota-2, dota2, mcp, model-context-protocol, vconsole2

## 简介

MCP server for Dota 2 custom game development — real-time console bridge, live API docs, game control and asset tooling via the Model Context Protocol.
