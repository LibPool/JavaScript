# dsh-plugin-agent-monitor

> 标签: agent-monitor, deepseek-harness, dsh, dsh-plugin, web-ui

## 简介

Floating monitor card for dsh web: running sessions and their active subagents with name, task brief, model, reasoning effort and status. Auto-refresh every 2s.
