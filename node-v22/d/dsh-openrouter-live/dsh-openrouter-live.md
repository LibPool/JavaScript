# dsh-openrouter-live

> 标签: deepseek-harness, dsh, dsh-plugin, llm, openrouter

## 简介

OpenRouter provider for DeepSeek Harness with a live model list: every model OpenRouter serves, with context sizes, reasoning levels and image input read from its /models endpoint.
