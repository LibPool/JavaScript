# dsh-rea-agents

> 标签: apktool, deepseek, dsh, dsh-plugin, ghidra, harness, jadx, mcp, rea, reverse-engineering

## 简介

Pinned-version REA for DeepSeek Harness: installs rea-agents locally, starts its MCP server from that pinned copy, and upgrades only when you press Update.
