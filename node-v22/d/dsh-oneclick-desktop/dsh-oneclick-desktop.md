# dsh-oneclick-desktop

> 标签: chat, deepseek, deepseek-harness, dsh, dsh-plugin, launcher, split, taskbar, tray, windows

## 简介

Windows: turns DSH into a desktop app. A one-click launcher and tray controller, plus a sidebar button that splits DSH and chat.deepseek.com side by side with its own taskbar button.
