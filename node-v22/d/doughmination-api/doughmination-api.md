# doughmination-api

> 标签: discord, doughmination, hooks, pluralkit, presence, react, tanstack-query, websocket

## 简介

React hooks and typed client for the Doughmination API — Discord presence, Minecraft/Hypixel stats, plural system fronters, devices and guestbook, with a single live WebSocket.
