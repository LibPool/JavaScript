# dsh-claude-migrator

> 标签: claude, deepseek-harness, dsh, mcp, migrator, rules, skill

## 简介

Claude → DeepSeek Harness (DSH) 配置迁移插件：把 .claude/skills、.claude/rules、.mcp.json、CLAUDE.md 拖入插件目录即自动加载为 DSH 能力，内置完整看板（skills / rules / MCP / 连接状态）。
