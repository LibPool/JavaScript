# dsh-im

> 标签: approval, chatbot, deepseek-harness, dsh, dsh-plugin, im-bridge, notifications

## 简介

统一 IM 桥核心：让 DeepSeek Harness 通过 IM 可指挥、可通知、可审批（会话映射 / 命令 / 通知总线 / 审批流 / MockChannel）。
