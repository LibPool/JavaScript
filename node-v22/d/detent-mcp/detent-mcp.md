# detent-mcp

> 标签: agent-payments, ai-agents, detent, mcp, model-context-protocol, policy, receipts

## 简介

MCP server for DETENT: a deterministic verdict on every agent payment, a signed receipt for every verdict, and a guard that pins tool definitions by hash.
