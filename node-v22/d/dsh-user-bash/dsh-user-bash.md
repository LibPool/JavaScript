# dsh-user-bash

> 标签: JavaScript

## 简介

方法一:   直接通过DSH插件系统一键安装   ```bash dsh plugin --profile web add user-bash ``` 方法二:   从源码安装 ```bash git clone https://github.com/qiuqiu-dot/user-bash cd user-bash pnpm install dsh plugin --profile web add . ```
