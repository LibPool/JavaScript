# decorator-dependency-injection

> 标签: container, decorators, dependency-injection, di, factory, inject, injectable, inversion-of-control, ioc, jest, mock, mocking, service-locator, singleton, stage-3-decorators, tc39-decorators, testing, typescript, vitest

## 简介

Lightweight dependency injection (DI) library using native TC39 Stage 3 decorators. Zero dependencies, built-in mocking, TypeScript support.
