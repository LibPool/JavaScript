# dsh-serial

> 标签: JavaScript

## 简介

DSH plugin: embedded serial debugging tools (scan ports, send data, monitor output, capture logs) for COM/UART work, driven by pyserial Python scripts.

## 官网

- npm 页面：https://www.npmjs.com/package/dsh-serial
