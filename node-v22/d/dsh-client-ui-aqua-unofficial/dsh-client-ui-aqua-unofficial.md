# dsh-client-ui-aqua-unofficial

> 标签: JavaScript

## 简介

Aqua: a highly customizable glassmorphism theme for the DeepSeek Harness Web UI — blur, frost, fluid or video wallpaper, unified corners, and motion. Unofficial community fork, not affiliated with DeepSeek.
