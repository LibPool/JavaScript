# dsh-harden

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, guard, resilience

## 简介

DSH 运行时看护层：在 agent 生命周期的关键点做防护，保证任何停止都有明确原因，不让异常静默变成正常结束。
