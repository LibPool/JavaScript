# dxf-vuer

> 标签: autocad, blueprint, cad, cad-viewer, drawing, dxf, dxf-parser, dxf-renderer, dxf-three, dxf-viewer, dxf-vuer, engineering, parser, render-dxf, technical-drawing, three.js, threejs, typescript, viewer, vue, vue-component, vue-dxf, vue-dxf-viewer, vue3, vuejs, webgl

## 简介

Vue 3 DXF file viewer — render AutoCAD DXF drawings in the browser with Three.js. Built-in parser, vector text rendering, TypeScript support.
