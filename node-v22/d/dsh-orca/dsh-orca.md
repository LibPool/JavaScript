# dsh-orca

> 标签: agent, cli, coding-agent, cordis, deepseek, deepseek-harness, dsh, terminal, tui

## 简介

Orca — a self-owned in-process TUI front door for DeepSeek Harness, mounted as a Cordis plugin. Zero kernel changes.
