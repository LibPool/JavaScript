# drizzle-docs-mcp

> 标签: ai, docs, documentation, drizzle, drizzle-orm, llm, llms-txt, mcp, model-context-protocol, orm, tmcp

## 简介

MCP server for the Drizzle ORM documentation: 450+ pages across 6 SQL dialects with fuzzy and full-text search, over stdio (npx) or Streamable HTTP (self-hosted).
