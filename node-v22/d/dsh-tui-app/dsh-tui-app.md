# dsh-tui-app

> 标签: coding-agent, cordis, deepseek, deepseek-harness, dsh, terminal, tui

## 简介

Terminal UI (TUI) for DeepSeek Harness: an interactive coding-agent surface composed as Cordis plugins and installed into a dsh profile as a bundle. Work in progress.
