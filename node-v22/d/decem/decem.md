# decem

> 标签: arbitrary-precision, bigdecimal, bigint, bignumber, correctly-rounded, currency, decimal, esm, exact, financial, math, money, precision, rounding, typescript

## 简介

A modern decimal library for TypeScript, built on BigInt. Addition and multiplication are exact; rounding takes a precision argument.
