# dsh-live-token-stats

> 标签: bpe, deepseek-harness, dsh, dsh-plugin, stats, token, tps

## 简介

DSH Web 插件：基于 DeepSeek 官方 BPE 分词表，在 composer 下方实时渲染 token 状态带，显示流式 TPS、输出 token 与首字延迟，并对比上次 step 的估算与实际偏差；纯插件自包含，不改 DSH 源码
