# dsh-bloub-mood

> 标签: animated, bloub, deepseek-harness, dsh, dsh-plugin, favicon, logo, mood, web

## 简介

DeepSeek Harness 心情图标插件：把 web 端 logo/状态点换成 bloub 心情形象（8 形状 × 12 色 × 16 表情，随会话状态自动切换），内置桌面启动子功能（macOS/Windows 桌面入口共用 dsh web 后端），设置页中英双语。
