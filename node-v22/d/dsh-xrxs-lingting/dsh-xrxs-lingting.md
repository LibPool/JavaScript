# dsh-xrxs-lingting

> 标签: JavaScript

## 简介

灵听 DSH 插件：数据列表在主页面（业务插槽），实时转写在右侧面板，在聊天旁边使用。已对接真实后端（aim 表单接口 + cinlyn JSON/SSE + 转写 WebSocket），麦克风与系统声音混合采集 16kHz PCM，记录保存在服务端。
