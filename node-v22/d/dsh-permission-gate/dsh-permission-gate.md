# dsh-permission-gate

> 标签: cordis, cordis-plugin, deepseek-harness, dsh, dsh-bundle, dsh-plugin, idle-timeout, lock-screen, permission-gate, tool-guard

## 简介

UI-level access gate + process-wide agent tool brake for DeepSeek Harness: shared session, strict 60-minute idle lock, native settings module. NOT server-side authentication.
