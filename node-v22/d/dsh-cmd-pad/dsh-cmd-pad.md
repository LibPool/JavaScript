# dsh-cmd-pad

> 标签: JavaScript

## 简介

DSH Web UI 插件：测试命令行速查面板——命令按自定义分组+项目归档、一键复制；「上次使用」动态最近使用视图（范围切换）。软依赖 better-sidebar（peer optional）：装了走侧边栏 Tab 主形态（order 45，支持一键运行——新开专用终端直送执行、危险命令双人工确认），没装走浮动图标+非模态抽屉降级形态（无运行只复制）
