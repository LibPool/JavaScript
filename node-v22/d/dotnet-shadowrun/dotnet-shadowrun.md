# dotnet-shadowrun

> 标签: agent, build, cli, developer-tools, dotnet, hot-reload, robocopy, run

## 简介

Build a .NET project, copy its output to a temp dir, and run it from there — leaving bin/ unlocked so coding agents/tools can rebuild.
