# dsh-permission-panel

> 标签: deepseek, deepseek-harness, dsh, dsh-permission-panel, dsh-plugin, hotkey, keybinding, permission, plugin, shortcut, shortcuts

## 简介

DSH 工作区权限面板（Web / Desktop 双载体）：按工作区分组列出每个会话的权限预设，支持搜索、按四个权限等级筛选、定位并高亮当前会话所在行、两级全选与批量修改，自动跳过已归档会话，可设置新会话默认权限，并显示当前会话实际生效的策略；另提供「重启 DSH」命令（仅 Desktop）。
