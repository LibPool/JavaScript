# debate-api-client

> 标签: api-client, debate-ai, grab-url, hey-api, openapi, sdk

## 简介

Typed SDK for the Debate AI API, generated from debate-openapi.yml with Hey API and powered by grab-url (caching, retries, rate limiting, and dedupe on every call).
