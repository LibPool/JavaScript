# dsh-kit-input-history

> 标签: JavaScript

## 简介

DSH 输入历史（dsh-kit 全家桶功能包，由 dsh-kit 聚合包挂载）——记录当前会话发送的消息，输入框无命令菜单时按 ↑/↓ 切换回填
