# dynamic-config-sdk

> 标签: JavaScript

## 简介

从服务器获取解析后的配置      @param path 配置的路径 例如: spring.datasource.username  , 默认获取整个配置文件    @return object 解析后的配置   ```typescript getConfig = (path: string = '') : object ```
