# dsh-wm-toolkit

> 标签: assistant-edit, deepseek-harness, delete-message, dsh, message-delete, message-edit, message-recall, plugin, regenerate, session-manager, surface-replace, workspace-migration, 会话管理, 删除回复, 删除消息, 工作区迁移, 撤回, 重新生成, 重编辑

## 简介

撤回、编辑指令与回复（连思考过程一起改）、用原提问重新生成、删除任意一条指令或回复（模型上下文级，不改写日志）、会话归档/删除/跨工作区移动与工作区迁移。 Recall, edit prompts and replies (reasoning included), regenerate with the original prompt, delete any single prompt or reply (context-level, log untouched), session archive/del
