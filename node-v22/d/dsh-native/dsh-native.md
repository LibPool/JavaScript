# dsh-native

> 标签: code-index, dsh, dsh-native, dsh-plugin, powershell, rust, session-projection, sidecar

## 简介

dsh-native: resident Rust worker (lane pool, session affinity, soft RSS/CPU limits) for command execution, sha256-guarded file IO, code indexing and search, session-log projection and resource sampling; host-side JSON-RPC middleware with 7 HTTP routes, pl
