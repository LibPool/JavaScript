# dsh-crabtodo

> 标签: deepseek-harness, dsh, dsh-plugin, dsh-web, task, tasklist, todo, todo-list, todos, 任务管理, 待办, 清单

## 简介

CrabTodo — a persistent todo manager for DeepSeek Harness: model-facing todo tools backed by a JSON store under $DSH_HOME, plus a full sidebar page in the Web UI. 持久化待办插件：模型可增删改查的 todo 工具 + Web 侧边栏任务页面。
