# desktopcgi-bridge-express

> 标签: Bridge, Desktop Application, Desktop-CGI, Electron, ExpressJS, Server

## 简介

Express based bridge for Desktop-CGI application serving. Serves files, proxy, manages processes, and manages concurrency
