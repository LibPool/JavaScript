# dead-props

> 标签: dead-code, design-system, monorepo, props, react, ts-morph, typescript, unused-props

## 简介

Find component props declared in a *Props interface/type that no JSX call site in the project ever passes — cross-file, TypeScript-aware, monorepo-friendly.
