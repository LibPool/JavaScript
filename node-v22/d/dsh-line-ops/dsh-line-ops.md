# dsh-line-ops

> 标签: dsh, lines, plugin, text-processing

## 简介

Line-level text operations plugin for DeepSeek Harness: extract lines by selector or regex, and apply ordered transform chains (dedupe, sort, number, prefix, trim, head/tail).
