# dsh-memory-system-prompt

> 标签: deepseek-harness, dsh, dsh-plugin, memory

## 简介

全局记忆：AI 主动写入与读取的记忆文件，每轮对话前自动注入索引，不占上下文，仅按需展开；支持本对话禁用。
