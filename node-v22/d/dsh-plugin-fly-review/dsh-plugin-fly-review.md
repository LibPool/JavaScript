# dsh-plugin-fly-review

> 标签: JavaScript

## 简介

Fly 评审姿态（agent 平面插件）：/review 开关一个只读评审姿态，引导模型先讲阻塞问题、给 path:line 证据，判词由用户裁决。照 @deepseek-ai/dsh-plan-mode 的形状实现。
