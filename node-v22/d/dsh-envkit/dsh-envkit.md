# dsh-envkit

> 标签: bom, deepseek-harness, diagnostics, dsh, dsh-plugin, environment, git-repair, json, troubleshooting

## 简介

DeepSeek Harness 环境工具插件：env_probe 一次性探明网络/代理/可写性/子进程管道，safe_json_edit 无 BOM 安全改写 JSON（修 profile 的头号杀手），git_repair 检测并重建丢失的 .git 元数据。
