# darkroom-settings

> 标签: claude-code, codex, darkroom, installer

## 简介

Installer for Darkroom Engineering's Claude Code + Codex configuration. Downloads and runs the official cc-settings bootstrap; the configuration itself always comes from the origin-pinned GitHub repository, never from this package.

## 官网

- 官网：https://github.com/darkroomengineering/cc-settings#readme
- 源码仓库：git+https://github.com/darkroomengineering/cc-settings.git
- npm 页面：https://www.npmjs.com/package/darkroom-settings

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install darkroom-settings`
- npm registry：https://registry.npmjs.org/darkroom-settings
- Node 要求：>=18
