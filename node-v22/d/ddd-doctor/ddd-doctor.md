# ddd-doctor

> 标签: architecture, ddd, domain-driven-design, express, hono, lint, prisma, static-analysis, typescript

## 简介

Zero-config static analyzer that detects Domain-Driven Design violations in TypeScript backends by framework and ORM API signatures - no folder-name conventions or manual annotations required
