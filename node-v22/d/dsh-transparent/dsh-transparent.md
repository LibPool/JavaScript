# dsh-transparent

> 标签: cordis-plugin, deepseek-harness, dsh, liquid-glass, transparency, windows

## 简介

Unofficial DSH desktop plugin: makes the window translucent so the desktop wallpaper shows through. Windows only. Also ships a genuinely refracting liquid-glass composer, though the app's layout keeps it barely visible.
