# dsh-desktop-statusbar

> 标签: cost, deepseek-harness, dsh, dsh-plugin, statusbar, token-usage

## 简介

把 DSH 桌面端对话区底部的统计行换成可配置状态栏：10 个字段可选可排序，按官方峰谷口径估算费用，支持自定义模型单价与账户余额。
