# dsh-plugin-recommender

> 标签: audit, deepseek-harness, dsh, dsh-plugin, plugin-market, recommend, recommender, role, security

## 简介

DSH 插件推荐助手：首次使用自动弹出对话框询问你的职业/角色（程序员、设计师、写作、研究、运维、学生…），按角色推荐合适的 DSH 插件，并对每个插件做安全审计（静态扫描）与口碑检查（下载量/星数）。A role-based plugin recommender with security & trust audit for DeepSeek Harness.
