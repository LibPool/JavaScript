# dsh-time-auditor

> 标签: anti-addiction, deepseek-harness, dsh, dsh-plugin, focus, web, wellness

## 简介

时间稽查官：住在 DeepSeek Harness 里的防沉迷角色。观察你的使用时长，超时后现身、翻日志戳穿你、逼你写下承诺赎回时间，还会调动 AI 毒舌提醒。
