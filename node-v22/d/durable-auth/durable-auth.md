# durable-auth

> 标签: auth, authentication, cloudflare, durable-objects, passkeys, passwordless, sessions, webauthn, workers

## 简介

Passkey sign-in for Cloudflare Workers, kept in one Durable Object: accounts, sessions and email recovery, no auth service and no user database.
