# datatables-lite

> 标签: bootstrap, datatables, jquery, responsive, table

## 简介

DataTables enhances HTML tables with the ability to sort, filter and page the data in the table very easily. Package includes the core software with Bootstrap 3 integration plugin and Responsive extension.
