# dsh-paste-code-block

> 标签: cherry-studio, code-block, deepseek-harness, dsh, i18n, paste, plugin, ui

## 简介

Cherry Studio-style paste for DSH Web: pasted text/code becomes a bordered, collapsible, language-tagged card with localized names (中文/English) and a one-click remove button; restored as a fenced code block on send — and folded back into collapsed, expand
