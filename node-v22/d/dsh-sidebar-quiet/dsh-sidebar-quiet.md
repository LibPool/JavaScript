# dsh-sidebar-quiet

> 标签: css, deepseek-harness, dsh, dsh-plugin, sidebar, userstyle

## 简介

Quiet, collapsible DSH left-sidebar footer: fold the balance / import / memory / logout rows into a single line so the workspace and session list get the vertical space.
