# dbc-stream

> 标签: bonding-curve, dbc, events, indexer, launchpad, meteora, solana

## 简介

Plug-and-play event stream for Meteora Dynamic Bonding Curve (DBC): decoded events, derived price and graduation progress, per-launchpad filtering, restart-safe.
