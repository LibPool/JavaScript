# dsh-quota-pill

> 标签: balance, deepseek, deepseek-harness, dsh, plugin, quota, web

## 简介

DeepSeek API quota widget for the dsh web GUI: collapsible pill with drag support — shows remaining DeepSeek API balance, today's consumption and current conversation cost. Fork of dsh-deepseek-quota with fold + drag UX.
