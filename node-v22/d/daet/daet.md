# daet

> 标签: add, ago, browser, calendar, date, dates, datetime, es2016, es2022, es5, export-default, format, formatting, from, from now, immutable, javascript, minimal, minus, module, moment, node, now, parse, plus, relative, small, substract, time, timeago, tiny, typed, types, typescript

## 简介

Minimal immutable date class that supports relative time, calendar time, and plus/minus of different units.
