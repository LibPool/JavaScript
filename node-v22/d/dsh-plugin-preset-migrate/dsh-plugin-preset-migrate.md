# dsh-plugin-preset-migrate

> 标签: agent-preset, deepseek-harness, dsh, dsh-plugin, migrate, migration, persona, preset

## 简介

Migrates DeepSeek Harness user agent presets that a release renamed a plugin config field under, starting with persona text -> prefix.
