# dsh-preset-qq-editor

> 标签: agent-preset, dsh, dsh-bundle, dsh-plugin, persona, qqbot

## 简介

DSH 的「可编辑人设」agent preset 插件：把群聊人设（啾啾·群聊）从 YAML 里搬到一个文本文件，在「设置 → 群聊人设」页面直接编辑，保存即生效、无需重启。register 出来的 preset 可与 dsh-qqbot-lite 搭配使用。
