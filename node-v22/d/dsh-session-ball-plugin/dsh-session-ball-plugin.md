# dsh-session-ball-plugin

> 标签: computer-use, deepseek-harness, desktop, dsh, dsh-plugin, floating-ball, hud, overlay, session, status, windows, wpf

## 简介

⚠ 这是一个仍在持续更新的插件：版本号会不断往前走，能力与行为都可能变，请按最新版取用。它只为一件事而做——让「在后台运行的任务」拥有前端反馈：任务在后台跑（尤其是模型开始操作桌面、网页端失去前台位置时）你依然看得见它在做什么、是不是在等你、以及**跑完了没有**。具体是一个原生 Windows 置顶悬浮球，报告**所有会话**的整体状态（几个在跑、谁在等你、有没有出错），并且**只要有会话还在输出就把球染成蓝色、让球呼吸**——那一眼不用读任何字：颜色回到空闲灰、球安静下来，就是这一轮跑完了。它不跟着某
