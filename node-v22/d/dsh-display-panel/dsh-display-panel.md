# dsh-display-panel

> 标签: deepseek-harness, display, dsh, panel, plugin, vnc, xvfb

## 简介

A display tab for the DeepSeek Harness Web UI: watch — and drive — the AI's own headless test display (per-session, isolated, with mouse/keyboard injected back).
