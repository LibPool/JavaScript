# dsh-context-pruner

> 标签: compaction, context, deepseek, dsh, dsh-plugin, harness, prune

## 简介

DSH 插件：纠错式上下文裁剪。用 /prune 把已经走错方向的旧对话压成一条「结论修正」摘要，让模型忘掉错误答案 X、只记住正确结论 Y，而不是把 10 轮试错原样留在上下文里继续误导。
