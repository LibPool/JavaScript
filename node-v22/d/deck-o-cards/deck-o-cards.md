# deck-o-cards

> 标签: 21, blackjack, card games, cards, casino, deck, deck of cards, fun, games

## 简介

A simple single function that returns a randomized single deck of 52 cards as an array of arrays: [[ '♠️Jack', 10 ], [ '♦️9', 9 ], [ '♣️King', 10 ] ...]
