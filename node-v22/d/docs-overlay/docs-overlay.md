# docs-overlay

> 标签: docs, docs-as-code, documentation, documentation-versioning, framework-agnostic, inheritance, markdown, monorepo, overlay, versioned-documentation, versioning, zero-dependencies

## 简介

Version your documentation without duplicating it: author only the diff between versions and let the engine resolve inheritance. Framework-agnostic, zero dependencies.
