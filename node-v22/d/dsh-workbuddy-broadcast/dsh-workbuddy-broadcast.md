# dsh-workbuddy-broadcast

> 标签: deepseek, deepseek-harness, dsh-plugin, model-provider, openai-compatible, workbuddy, wsl

## 简介

把本机 WorkBuddy 账号发布为 OpenAI 兼容的 HTTP 服务，供同一台机器上的其他 Agent 工具复用其模型 — expose WorkBuddy desktop models as an OpenAI-compatible endpoint for other agent tools on the same machine.
