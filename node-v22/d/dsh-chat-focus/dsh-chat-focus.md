# dsh-chat-focus

> 标签: JavaScript

## 简介

dsh web 对话界面插件：折叠运行时信息 + 聊天气泡 + 可配置设置（聊天层插件，骑在宿主 @deepseek-ai/dsh-client-ui-conversation 引擎上，替换宿主 ui-chat 气泡行）
