# discord-container-ui

> 标签: JavaScript

## 简介

Leichte Container-UI als TypeScript‑Bibliothek – kompatibel mit JS & TS. Enthält Container, TextDisplay, Section, Separator, MediaGallery & FileItem inkl. JSON-Serialisierung.
