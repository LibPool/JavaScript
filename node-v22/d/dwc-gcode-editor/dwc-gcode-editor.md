# dwc-gcode-editor

> 标签: JavaScript

## 简介

Custom G-code editor core for the DuetWebControl plugin family: a CodeMirror-6-based, virtualised, huge-file-capable editor driven by dwc-gcode-core's tokeniser, dictionary and diagnostics. Framework-free — no Vue, Vuetify or DWC imports; a thin Vue wrapp
