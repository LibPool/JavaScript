# drizzle-orm-expo-sqlite-async

> 标签: async, drizzle, drizzle-orm, expo, expo-sqlite, react-native, sqlite

## 简介

An async Drizzle ORM driver for expo-sqlite (runAsync/prepareAsync/getAllAsync), usable on web where the official sync expo-sqlite driver deadlocks.
