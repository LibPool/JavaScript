# dsh-font-probe-lite

> 标签: cjk, cordis, deepseek-harness, dsh, dsh-plugin, font, letter-spacing, line-height, theme, typography

## 简介

Minimal companion plugin for DSH: only font weights (interface + headings) and typography (letter-spacing, line-height, paragraph spacing, first-line indent) — the parts the official Appearance settings do not provide.
