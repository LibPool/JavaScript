# dxchatbot-widget

> 标签: chat, chatbot, cross-origin, customer-support, iframe, messaging, responsive, widget

## 简介

A lightweight, customizable chatbot widget that can be easily integrated into any website. Features responsive design, secure cross-origin communication, and customizable positioning.
