# diffcore

> 标签: apply-patch, audit-log, change-tracking, cli, compare-json, crdt-alternative, deep-diff, delta, diff, fast, history, json, json-diff, json-patch, json-pointer, merge, merge-conflict, nodejs, object-diff, optimistic-update, patch, react, rfc6902, rust, simd, state-management, state-sync, streaming, three-way-merge, typescript, undo-redo, wasm, webassembly

## 简介

Fast WebAssembly JSON diff engine. Returns real JSON Pointer paths and decoded values. Includes applyPatch, revertPatch, RFC 6902 JSON Patch output, a React hook, and a CLI.
