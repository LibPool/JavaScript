# diagnostic-tool

> 标签: JavaScript

## 简介

1. 若依赖装在根目录 则所有package会共享     - pnpm install lodash -w    - pnpm install lodash -wD 2. 如果想要只给单独的某一个package装依赖    - pnpm --filter <package_selector> <command>    例如我们需要在@packages/components安装lodash: pnpm -F @packages/components add lodash    -F 等价于 -
