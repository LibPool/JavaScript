# dsh-composer-prediction

> 标签: composer, deepseek-harness, dsh, dsh-plugin, ghost-text, prediction, tab-to-accept

## 简介

ChatGPT-style composer predictions for DeepSeek Harness: after each assistant turn, suggest the user's next message as ghost text in the composer. Tab accepts, Escape dismisses.
