# dsh-cloud-handoff

> 标签: cloud, deepseek-harness, dsh, dsh-plugin, handoff, remote, sync

## 简介

「云接力」：把本地 DSH 会话一键迁到云端 DSH 继续执行，笔记本合盖/关机不中断；回本地重开自动同步云端结果（DeepSeek Harness 插件）
