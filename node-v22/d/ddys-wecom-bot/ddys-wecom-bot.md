# ddys-wecom-bot

> 标签: api, bot, ddys, enterprise-wechat, event-callback, message-card, wechat-work, wecom

## 简介

Official WeCom bot integration for the DDYS API with self-built app callbacks, smart bot callbacks, encrypted messages, cards, access control, diagnostics, and cache support.
