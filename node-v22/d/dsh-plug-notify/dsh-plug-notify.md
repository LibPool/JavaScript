# dsh-plug-notify

> 标签: bot, deepseek-harness, dingtalk, dsh, dsh-plugin, feishu, notification, qq, template, wecom

## 简介

DeepSeek Harness 通知插件：配置企业微信/QQ/飞书/钉钉机器人推送消息。宿主侧确定性自动通知（goal 达成/受阻、workflow 结束、会话长任务完成）；支持多消息模板（{参数名} 占位 + 系统参数自动注入）；设置 → 通知机器人 提供配置、模板与测试界面。
