# ddys-discord-bot

> 标签: api, ddys, discord, discord-bot, ed25519, embeds, interactions, slash-commands

## 简介

Official Discord Interactions integration for the DDYS API with slash commands, Ed25519 verification, autocomplete, embeds, access control, diagnostics, and cache support.
