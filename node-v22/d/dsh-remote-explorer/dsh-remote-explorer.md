# dsh-remote-explorer

> 标签: deepseek-harness, dsh, dsh-plugin, remote, remote-development, ssh, tunnel

## 简介

远程开发启动器：把 dsh 装到远程主机并在本机浏览器中使用，凭据不离开本机
