# devutils-mcp-server

> 标签: base64, cidr, developer-tools, devutils, encoding, hash, json, jwt, mcp, model-context-protocol, network, text, timestamp, utilities, uuid, yaml

## 简介

MCP server with 36 zero-auth developer utilities: hashing (MD5/SHA/bcrypt), encoding (Base64/hex/URL), UUID/password generation, JWT decoding, JSON/YAML/XML formatting, timestamp conversion, network tools (CIDR, IP, DNS), and text utilities.
