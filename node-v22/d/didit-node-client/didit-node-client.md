# didit-node-client

> 标签: aml, biometric, didit, face-match, identity-verification, kyb, kyc, liveness, nfc, proof-of-address, sdk, typescript, verification, webhook

## 简介

Official-grade Node.js / TypeScript client for the Didit Identity Verification API (v3): sessions, KYC/KYB, standalone ID verification, and secure webhook handling.
