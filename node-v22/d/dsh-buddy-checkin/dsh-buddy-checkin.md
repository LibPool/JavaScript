# dsh-buddy-checkin

> 标签: check-in, deepseek, deepseek-harness, dsh-plugin, workbuddy

## 简介

DSH 启动时自动完成 WorkBuddy 国内版账号的每日签到 — runs the WorkBuddy (CN) daily check-in on DSH startup, claiming the daily credits.
