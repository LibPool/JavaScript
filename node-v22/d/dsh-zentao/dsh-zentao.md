# dsh-zentao

> 标签: deepseek-harness, dsh, dsh-plugin, project-management, zentao, 禅道

## 简介

DSH 插件：1 个 zentao 薄代理工具（查询/操作禅道数据）+ 对话内表格卡片 + 右侧栏禅道概览 Tab（按工作区 .dsh-zentao.json 绑定展示任务与 Bug）。凭证由 zentao CLI 内部管理，插件不接触凭证。
