# dsh-git-push-gate

> 标签: cordis, deepseek-harness, dsh, git, guard, plugin, push

## 简介

Tool-layer gate: refuses agent-initiated git push at tools/pre-execute, before any shell runs. Local commits stay untouched. Matching core lives in the cross-agent shared gate repo, located through GIT_PUSH_GATE_HOME (portable default <homedir>/shared/hoo
