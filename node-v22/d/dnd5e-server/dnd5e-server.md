# dnd5e-server

> 标签: JavaScript

## 简介

This repo offers typings and function endpoints to the [DnD 5e API](http://www.dnd5eapi.co/).  It is based on the [dnd5e](https://github.com/SandyGifford/dnd5e) package and can be used with the [dnd5e-client](https://github.com/SandyGifford/dnd5e-client)
