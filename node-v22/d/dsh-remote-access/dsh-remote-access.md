# dsh-remote-access

> 标签: dsh, lan, plugin, remote-access, webserver

## 简介

dsh Web GUI remote access: bind the webserver to 0.0.0.0 for LAN/remote access and inject the crypto.randomUUID polyfill for non-secure HTTP origins.
