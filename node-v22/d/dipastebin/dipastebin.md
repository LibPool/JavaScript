# dipastebin

> 标签: cli, developer, dipastebin, pastebin, sdk, share-code, snippet, terminal, uploader

## 简介

Official NPM SDK and CLI client for dipastebin.web.id - Instantly upload, share, and delete code snippets from your programmatic scripts or terminal.
