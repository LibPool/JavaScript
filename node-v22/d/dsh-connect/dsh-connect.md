# dsh-connect

> 标签: ai-agent, all-in-one, chatbot, cordis, deepseek-harness, dingtalk, dsh, feishu, lark, messaging, telegram

## 简介

All-in-one DeepSeek Harness (DSH) chat bridge: one plugin, one config block — Feishu/Lark, Telegram, DingTalk, and Web mirror adapters plus the web-settings pane, all behind a channels[] selector
