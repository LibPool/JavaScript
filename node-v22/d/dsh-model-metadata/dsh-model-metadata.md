# dsh-model-metadata

> 标签: context-window, custom-provider, deepseek-harness, dsh, dsh-plugin, llm, model-metadata, models.dev, reasoning-effort, vision

## 简介

Capability metadata for hand-declared gateway models, resolved at runtime by bare model name (context window, output cap, reasoning levels, vision) — matched against the official DeepSeek route's catalog, the installed pi-ai catalog, opencode and models.d
