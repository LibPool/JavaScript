# dsh-session-tabbar

> 标签: cordis, cordis-plugin, deepseek, deepseek-harness, dsh, dsh-plugin, plugin, session, session-tabs, tabbar, tabs, ui

## 简介

DSH web plugin: a browser-style session tab bar pinned in the top overlay of DeepSeek Harness — switch, close and create sessions as tabs. · DSH 顶部会话标签栏插件。
