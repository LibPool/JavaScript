# dsh-plugin-resume-warehouse

> 标签: dsh-plugin, local-first, resume, tools

## 简介

Local-first resume warehouse for DeepSeek Harness: one tool to start/stop the local app and read its health. Everything stays on this machine; the only outbound path is a configurable LLM API.
