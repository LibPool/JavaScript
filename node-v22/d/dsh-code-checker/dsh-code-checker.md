# dsh-code-checker

> 标签: bug-check, code-check, deepseek-harness, mcp, plugin, qa, simulation

## 简介

DeepSeek Harness 代码全面检查插件：三步流水线（编译运行检查 → 功能完整性核对 → 真实用户模拟测试），自动把问题反馈给 AI 修复，可选用 GUI，并附带适用于 Trae/Qoder 等平台的独立 CLI 与 MCP 服务
