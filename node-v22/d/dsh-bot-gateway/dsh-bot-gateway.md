# dsh-bot-gateway

> 标签: bot, cordis, deepseek-harness, dingtalk, dsh, feishu, gateway, lark, napcat, onebot, qq, telegram

## 简介

DSH Bot Gateway：把 QQ(NapCat OneBot v11 / 官方机器人)/Telegram/飞书/钉钉 接成 DSH 的远程任务网关 —— 聊天里发消息即可建任务/续聊/查进度/收交付物（Cordis 宿主插件，零运行时依赖）
