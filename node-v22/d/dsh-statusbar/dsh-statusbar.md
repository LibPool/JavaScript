# dsh-statusbar

> 标签: appearance, balance, deepseek-harness, dsh, plugin, statusbar, weather

## 简介

tmux 风格状态栏：替换 DSH 输入框下方统计行，左为统计信息 + DeepSeek 余额三色提醒，右为地点/温度/天气预报/日出日落
