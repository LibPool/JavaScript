# dsh-extension-hub

> 标签: cordis, deepseek-harness, dsh, extension, mcp, plugin, skill

## 简介

Extension Hub for DeepSeek Harness (DSH): manage skills, MCP servers and plugins from the DSH Web settings page — list / create / edit / delete / enable-disable, import from Claude and Codex, manage official & third-party plugins, a Plugin Market with a c
