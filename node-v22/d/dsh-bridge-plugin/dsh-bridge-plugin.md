# dsh-bridge-plugin

> 标签: deepseek, deepseek-harness, dsh, dsh-bridge, dsh-plugin, mcp, playwright

## 简介

DeepSeek Harness plugin: expose the local dsh-bridge browser bridge (Python/Playwright, 4 web AIs) as native DSH tools. PoC registers ask_deepseek; the bridge itself is reused over MCP stdio, not reimplemented.
