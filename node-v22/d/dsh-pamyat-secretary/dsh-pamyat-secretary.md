# dsh-pamyat-secretary

> 标签: agent, compaction, deepseek-harness, dsh, memory, plugin

## 简介

Секретарь компакции для DSH: снимает сводку затираемой истории и кладёт её в память с verbatim-ссылкой на затенённый диапазон.
