# darwin-langgraph

> 标签: ab-testing, agent-orchestration, ai-agents, darwin-agents, gepa, langchain, langgraph, multi-agent, self-evolving-agents, stategraph, trajectory-capture

## 简介

LangGraph.js adapter for darwin-agents — wrap self-evolving Darwin agents as StateGraph nodes with zero hard deps. V0.5.4 opens the darwin-agents peer range to any 0.x (ends the per-minor install breakage; verified against 0.11). V0.5.2 wires the runAgent
