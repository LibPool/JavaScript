# dsh-web-search-tavily-pool

> 标签: deepseek-harness, dsh, plugin, tavily, web-search

## 简介

DSH web plugin: tavily search provider for ctx.web with a managed multi-key pool (per-key add/remove/enable/test from Settings), rotation, cooldown, and quota-aware failover
