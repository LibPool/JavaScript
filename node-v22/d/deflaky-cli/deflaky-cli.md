# deflaky-cli

> 标签: ci-cd, cli, cypress, deflaky, flakescore, flaky, flaky-tests, jest, junit, playwright, pytest, selenium, test-automation, test-reliability, test-runner, testing, tests

## 简介

Detect flaky tests by running your test suite multiple times. Works with Playwright, Selenium, Cypress, Jest, Pytest and any JUnit/JSON reporter.
