# dsh-stream-upload

> 标签: attachment, cordis, deepseek-harness, dsh, plugin, streaming, upload

## 简介

DeepSeek Harness hybrid attachment plugin: native image attachments plus bounded-memory non-image streaming into a verified session workspace, with quotas, trust fencing and TTL cleanup.
