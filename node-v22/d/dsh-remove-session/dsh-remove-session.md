# dsh-remove-session

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, session, sidebar

## 简介

Adds a red “Delete session” action to every Session's “...” menu, with a confirmation dialog and a real on-disk delete. | 在会话「...」菜单末尾增加红色“删除会话”，二次确认后真正删除会话记录。
