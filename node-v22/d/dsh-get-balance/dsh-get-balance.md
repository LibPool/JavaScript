# dsh-get-balance

> 标签: dsh-get-balance, dsh-plugin, jsoncode

## 简介

DeepSeek balance & token-cost plugin for DeepSeek Harness (dual-face): query official balances of every DeepSeek provider (multi API key), compute costs (last question / session / today-project / today-all) from token usage with a user-editable price tabl
