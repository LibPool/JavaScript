# dsh-extra-context

> 标签: context, cordis, deepseek-harness, dsh, dsh-plugin, system-prompt

## 简介

给当前 DSH 的全部会话与子代理统一附加一段额外说明和上下文：设置页分段维护、实时预览、热生效。
