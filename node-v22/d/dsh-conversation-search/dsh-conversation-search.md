# dsh-conversation-search

> 标签: conversation, deepseek-harness, dsh, dsh-plugin, full-text, search, session

## 简介

DeepSeek Harness 对话内容搜索插件：在 Web UI 内搜索当前与全部历史会话的消息文本，点击结果自动切换/滚动定位到命中消息并高亮，面板内展示命中消息的前后上下文。Conversation full-text search for DeepSeek Harness: search the current and all historical sessions, click a hit to auto-navigate, scroll to and highlight the matchi
