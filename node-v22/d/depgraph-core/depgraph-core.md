# depgraph-core

> 标签: cli, dependency-graph, impact-analysis, static-analysis, typescript

## 简介

Dependency mapping, impact simulation, and structural AST inspection for multi-language codebases (JS/TS, Python, Go, Java, C#, Ruby, Rust, PHP, Kotlin)
