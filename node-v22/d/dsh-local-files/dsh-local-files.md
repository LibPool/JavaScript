# dsh-local-files

> 标签: deepseek-harness, docx, download, dsh, file-browser, file-manager, plugin, upload, xlsx

## 简介

Local file manager for DeepSeek Harness Web: browse, preview, download, upload, edit, rename and delete host files from the browser, over the same authenticated DSH web server
