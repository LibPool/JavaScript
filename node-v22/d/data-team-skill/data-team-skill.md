# data-team-skill

> 标签: analytics, claude, claude-code, data, etl, installer, medallion, metrics, plugin, semantic-layer, skill

## 简介

One-command installer for the `data-team` Claude Code plugin — a whole data team as /data-team:run. Eight composable data roles (medallion, governed semantic layer, BI, ML, SRE) over your own data. stdlib-only, sovereign.
