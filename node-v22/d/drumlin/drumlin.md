# drumlin

> 标签: agent, ai, cli, cursor, mcp, next, nextjs, static-analysis, ux

## 简介

Local-first UX intelligence for AI-assisted development. Reads a Next.js app as a graph of screens, states and actions, and reports the UX problems a type checker cannot see.
