# dsh-context-window

> 标签: compaction, context-window, cordis, deepseek-harness, dsh, dsh-plugin, model-selection

## 简介

Manual context window selector & adaptive compaction guard plugin for DeepSeek Harness (上下文窗口手动配置与自适应压缩防失败守卫插件：在模型选择弹窗扩展第三行【上下文窗口】与 64K~2M/自定义输入面板，支持高切低先压缩保护并实时刷新 Context Pressure 进度条)
