# dshvm

> 标签: cli, deepseek, dsh, harness, nvm, unofficial, version-manager

## 简介

Unofficial, zero-dependency multi-version manager for the DeepSeek Harness CLI (dsh): install from npm, GitHub or local, switch in a second, with optional per-version data isolation.
