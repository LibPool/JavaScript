# date-picker-module-kihak12

> 标签: JavaScript

## 简介

A lightweight, dependency‑free React date picker used in HRnet. It supports: - Date selection - Optional time selection (hours and minutes) - Minimum and maximum selectable dates - Keyboard- and mouse-friendly interactions
