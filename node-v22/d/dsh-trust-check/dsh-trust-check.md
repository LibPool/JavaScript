# dsh-trust-check

> 标签: audit, capability-disclosure, deepseek-harness, dsh, dsh-plugin, supply-chain, trust

## 简介

Static capability disclosure for DeepSeek Harness plugins: capabilities, injected prompts, install scripts, and provenance, each with file:line evidence. Facts, not a safety verdict.
