# dsh-better-plan-reviewer

> 标签: JavaScript

## 简介

DSH web plugin: takes over the plan review card and adds an execution-model selector at its bottom — pick which model will carry out the plan; on approve the plugin switches the session model first, then answers the review so execution runs on the chosen
