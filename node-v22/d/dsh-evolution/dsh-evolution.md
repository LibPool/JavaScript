# dsh-evolution

> 标签: cordis-plugin, deepseek-harness, dsh, dsh-plugin, evolution, evolve, local-first, memory

## 简介

DSH 自动进化（本地优先）：记录开发会话账本，用你自己已配好的模型做跨会话复盘，把踩过的坑和有效做法沉淀成本地知识；默认不联网、不上传、可一键导出。
