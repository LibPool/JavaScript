# dsh-shift-scheduling

> 标签: JavaScript

## 简介

DeepSeek Harness 排班插件：根据营业时间、员工、班次和休假规则生成、调整并检查排班，说明冲突与改动影响，并协助整理和导出 Excel 排班表
