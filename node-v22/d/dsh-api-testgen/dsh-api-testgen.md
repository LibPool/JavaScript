# dsh-api-testgen

> 标签: deepseek-harness, dsh, dsh-plugin, openapi, test-generation, testing, 接口, 测试

## 简介

接口测试生成：解析 OpenAPI 3.x，为每个接口生成覆盖成功/缺参/非法枚举的测试用例，输出 Python(pytest) 或 TypeScript(vitest) 测试骨架
