# douyin-bridge

> 标签: archive, bridge, douyin, downloader

## 简介

Local bridge for the Douyin profile downloader — runs a real browser on your machine so profile crawls use your own session and IP.

## 官网

- npm 页面：https://www.npmjs.com/package/douyin-bridge

## 历史版本号

- 1.0.0

## 获取地址

- npm 安装：`npm install douyin-bridge`
- npm registry：https://registry.npmjs.org/douyin-bridge
- Node 要求：>=18
