# druk

> 标签: bun, cli, code-editor, editor, opentui, search, syntax-highlighting, terminal, tree-sitter, tui

## 简介

A terminal code editor — file tree, tabs, tree-sitter syntax highlighting and search; keyboard and mouse driven.
