> 标签: angular, apollo, arrow function, async, async function, asynchronous, await, browser, concurrency, concurrent, decorator, fifo, javascript, job, limit, limited, lock, microtask, mutex, nestjs, node, promise, queue, rate, rate-limit, ratelimit, sequential, sync, synchronization, synchronized, synchronous, task, task queue, task-queue, task-runner, tasks, throat, throttle, typescript, worker

## 简介

A task queue executes tasks sequentially or concurrently. Wrap an async/promise-returning/sync function as a queue-ready async function for easy reusing. Support passing arguments/getting return value, @synchronized/@concurrent decorator, Node.js/Browser.
