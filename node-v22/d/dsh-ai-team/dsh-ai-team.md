# dsh-ai-team

> 标签: agentic, ai-team, autopilot, ci, deepseek-harness, deploy, dsh, dsh-plugin, multi-agent, quality-gates, remote-git, rollback, unattended

## 简介

DSH plugin: an unattended AI software team. Feed it a bare Linux server, a set of secrets (env-var references only) and a git remote, and the plugin-driven AI team drives the whole project lifecycle — environment bootstrap, scaffolding, task decomposition
