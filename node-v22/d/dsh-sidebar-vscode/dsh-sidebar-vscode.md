# dsh-sidebar-vscode

> 标签: cordis, deepseek-harness, dsh, dsh-client-ui-sidebar-right, dsh-plugin, serve-web, sidebar-tab, vscode

## 简介

DSH web plugin: an official right-Sidebar tab type ('vscode') that embeds the VS Code web workbench opened at the current session workspace — same-origin by default through the plugin's built-in reverse proxy (/sidebar/vscode), or via a gateway subpath /
