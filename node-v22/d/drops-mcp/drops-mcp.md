# drops-mcp

> 标签: ai-agents, anthropic, artifact-sharing, artifacts, claude, claude-code, cli, cursor, file-sharing, mcp, mcp-server, password-protection, publish-html, self-hosted, send-co-alternative, stacktree-alternative, staticrypt, vercel-blob, zero-knowledge

## 简介

Open-source artifact sharing — publish HTML/Markdown/files as branded, password-protected, zero-knowledge links on your own domain, from any AI agent. CLI + MCP server. The open-source, self-hosted Stacktree alternative.
