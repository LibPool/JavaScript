# dsh-long-memory

> 标签: JavaScript

## 简介

DSH 超长记忆包：跨会话长期记忆、长文分块检索、聊天记录提取与精炼。纯 JS 混合检索（BM25 + CJK 二元分词），零第三方依赖。
