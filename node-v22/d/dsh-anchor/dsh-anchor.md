# dsh-anchor

> 标签: adoption, anchor, deepseek-harness, dsh, dsh-plugin, long-running, reliability, session-truth

## 简介

Session Anchor Protocol plugin for DeepSeek Harness: pre-committed intents + immediate reconciliation on every tool action. Crash, rescan the anchor tree, adopt, continue - the filesystem is the session's truth. Tested on Windows 11.
