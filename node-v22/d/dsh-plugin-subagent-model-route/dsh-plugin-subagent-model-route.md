# dsh-plugin-subagent-model-route

> 标签: catalog, client-plugin, deepseek-harness, dsh, dsh-plugin, model, subagent

## 简介

Annotate every subagent with the model route it actually ran on: a badge line in each parent-catalog row and a readout in a child session's own header.
