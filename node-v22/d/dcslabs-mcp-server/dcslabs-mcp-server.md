# dcslabs-mcp-server

> 标签: ai-agents, cryptographic-receipts, dcs-labs, ed25519, mcp, model-context-protocol, open-standard, provenance, r2

## 简介

MCP server that emits an R+2 receipt for every tool call — verifiable provenance for agent actions, wired to the @dcslabs stack.
