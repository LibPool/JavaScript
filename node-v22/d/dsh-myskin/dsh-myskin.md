# dsh-myskin

> 标签: deepseek-harness, desktop, dsh, plugin, skin, theme

## 简介

DSH 全兼容皮肤可视化编辑框架：可视化自定义 + 「皮肤管理」，可以随心设计你的专属皮肤，并通过分发 .dshframework 皮肤包和你的小伙伴们分享。非侵入式、可逆覆盖层，适配 DSH 0.1.7-rc.2 / 0.2.0-rc.1 / 0.2.0-rc.2（Web 与 Desktop 共用同一条客户端插件管线），已声明兼容适配 dsh-wallpaper-engine。
