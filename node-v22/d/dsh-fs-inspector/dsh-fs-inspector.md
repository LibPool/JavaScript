# dsh-fs-inspector

> 标签: disk-usage, dsh, filesystem, plugin

## 简介

Filesystem inspector plugin for DeepSeek Harness: directory size aggregation with Top-N subdirectories/files, recently modified files with relative-time filters. Read-only, no symlink traversal. Zero runtime dependencies.
