# dsh-tide-ui

> 标签: animated, aurora, dsh, floating-window, i18n, liquid-glass, skin, theme, tide, translucent, whale-girl

## 简介

Hot-pluggable tide liquid-glass skin for the dsh web GUI: dynamic aurora/tide backdrop, floating workspace window, deep-tinted liquid-glass panels, deep-sea caustics, animated SVG waves, a draggable DeepSeek whale-girl companion, and full light/dark suppo
