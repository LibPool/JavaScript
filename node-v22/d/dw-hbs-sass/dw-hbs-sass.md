# dw-hbs-sass

> 标签: hbs, sass

## 简介

Un potente traspilador de plantillas Handlebars y estilos SASS que convierte tu código fuente en páginas HTML dinámicas y atractivas. Simplifica el proceso de desarrollo web con facilidad y elegancia.
