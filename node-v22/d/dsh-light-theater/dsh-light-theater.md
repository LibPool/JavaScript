# dsh-light-theater

> 标签: animation, composer, deepseek-harness, dsh, input-skin, plugin, web-ui

## 简介

DSH 输入框皮肤插件：跟随皮肤主题美化输入框——内部青/紫双光束向两侧扩散巡视（24s 大周期切换红蓝）、顶部两段线段光沿边框圆角弧线反向巡游（16s 一圈）、青→蓝→紫颜色循环（4s）。
