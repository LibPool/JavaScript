# dedupe-infusion

> 标签: dedupe, framework, infusion, npm

## 简介

Micromodule script to deduplicate instances of Fluid's "Infusion" throughout an npm module tree

- 官网：http://fluidproject.org/infusion.html
- 源码仓库：git+ssh://git@github.com/fluid-project/dedupe-infusion.git
- npm 页面：https://www.npmjs.com/package/dedupe-infusion
