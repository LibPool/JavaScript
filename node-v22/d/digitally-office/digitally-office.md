# digitally-office

> 标签: claude-code, dev-tools, live-coding, office, pixel-art, retro, visualization, vj

## 简介

A retro pixel-art office that visualizes your dev activity live — every module is a room, agents (you + your Claude Code sessions) walk around and work, commits launch rockets. Music-reactive; built for live-coding/DJ sets.
