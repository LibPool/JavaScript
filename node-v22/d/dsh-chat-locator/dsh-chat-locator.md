# dsh-chat-locator

> 标签: conversation-navigation, cordis, cordis-plugin, deepseek-harness, dsh, dsh-plugin, hover-preview, turn-navigator, web-ui

## 简介

Turn-rail settings for the DSH Web conversation locator: tick thickness, rail side, a curved length gradient anchored on the hovered tick, and a plain-text hover preview with adjustable line count, font size, and width.
