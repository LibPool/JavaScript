> 标签: docs, docs-as-code, docs-overlay, documentation, documentation-versioning, docusaurus, docusaurus-versioning, markdown, mdx, versioned-docs, versioned-documentation, versioning

## 简介

Versioned documentation for Docusaurus without copying versioned_docs: author only the diff between versions, and let the build materialise the snapshots Docusaurus reads.
