# dsh-agent-switcher

> 标签: agent, deepseek-harness, dsh, dsh-plugin, history, opencode, preset, settings, subagent

## 简介

Create, manage, and switch your own DeepSeek Harness agents: per-agent settings, history, search and pinning, a try-it playground, and a custom_agent tool for model-authored subagents.
