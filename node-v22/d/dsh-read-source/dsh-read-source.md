# dsh-read-source

> 标签: cordis, deepseek-harness, docx, dsh, pdf, plugin, read

## 简介

One read-anything tool for DeepSeek Harness agents: reads text and images from web pages, Word .docx, PDF, images, and plain text files through a single entry point.
