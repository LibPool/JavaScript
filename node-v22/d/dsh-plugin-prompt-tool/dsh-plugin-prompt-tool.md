# dsh-plugin-prompt-tool

> 标签: JavaScript

## 简介

DSH 插件：提示词工具，规范模型的思维链与回答内容，提供 Web UI 编辑 preset.md 与 AGENTS.md，并按 skills 目录注册可开关技能。
