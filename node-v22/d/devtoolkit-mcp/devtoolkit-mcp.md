## 简介

29 developer utilities as an MCP server — JSON repair, SQL format, hash, encode/decode, UUID, regex, CSV, subnet calc, diagram generation, git diff parsing, DB schema parsing, JSON schema validation, and more. No API keys. Runs locally.
