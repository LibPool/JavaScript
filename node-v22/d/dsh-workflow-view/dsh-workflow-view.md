# dsh-workflow-view

> 标签: deepseek-harness, dsh-plugin, web-ui

## 简介

DSH Web UI plugin: a 工作流 (Workflow) conversation tab that turns one Session's recorded events into per-turn execution chains — model requests (system / messages[] / tools), model responses (reasoning, content, tool calls), tool executions, and token/cache
