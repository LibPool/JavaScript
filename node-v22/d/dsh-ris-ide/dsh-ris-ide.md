> 标签: code-editor, cordis, debugger, deepseek-harness, devtools, dsh, dsh-plugin, file-tree, ide, jdwp, log-viewer, spring-boot

## 简介

RIS-IDE local dev panel for the DSH web GUI: live log tail, one-click start/stop of workspace programs, JDWP debugging, file tree + editor, and a standalone IDE window that carries no session history. · DSH 右侧栏本地开发面板：日志实时跟随、一键启停本地程序、Java 断点调试、文件树与编辑器、独立 I
