# dsh-manga-translation-plugin

> 标签: comic, deepseek-harness, dsh, dsh-plugin, manga, mcp, translation

## 简介

DeepSeek Harness 漫画翻译插件：OCR 气泡框提取 + 逐页 LLM 翻译 + 文本匹配 + 自动嵌字，依赖 Manga-Translation-MCP。
