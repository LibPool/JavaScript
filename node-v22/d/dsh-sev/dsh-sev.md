# dsh-sev

> 标签: agent, deepseek, dsh, harness, plugin, remote, server, ssh, tunnel

## 简介

Remote DSH host management for DeepSeek Harness: manage a headless dsh instance on your own server from the local GUI — SSH tunnels, live remote session list, one-click remote GUI. 远程 DSH 分身管理：本地 GUI 控制服务器上的 dsh 实例。
