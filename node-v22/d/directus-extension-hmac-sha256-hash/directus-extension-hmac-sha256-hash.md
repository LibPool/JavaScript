# directus-extension-hmac-sha256-hash

> 标签: directus, directus-extension, directus-extension-operation

## 简介

This extension provides a simple and secure operation for Directus Flows to generate an HMAC-SHA256 hash from an input string and a secret key. It's perfect for creating signatures for API requests, verifying webhooks, or any other task requiring a keyed
