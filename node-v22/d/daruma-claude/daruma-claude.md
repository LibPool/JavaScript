# daruma-claude

> 标签: agent, claude-code, claude-code-plugin, daruma, multi-agent, oh-my-claudecode, orchestration, plugin

## 简介

Glue between tupical/daruma and oh-my-claudecode. Drives the daruma pipeline (parse / decompose / plan / execute) with omc /team as the per-task executor.
