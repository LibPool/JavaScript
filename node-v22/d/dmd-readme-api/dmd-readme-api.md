# dmd-readme-api

> 标签: api, dmd, documentaiton, jsdoc, jsdoc2md, markdown, md, readme

## 简介

A jsdoc2md template plugin generating elegant, compact one-page APIs in markdown, suitable for embedding in a README.md.
