# dsh-harness-desktop

> 标签: deepseek, deepseek-harness, desktop, dsh, electron

## 简介

DeepSeek Harness 桌面版：双击启动 DSH Web，后台运行无终端窗口，关闭窗口即停止后台服务。内置运行时，无需安装 Node.js。
