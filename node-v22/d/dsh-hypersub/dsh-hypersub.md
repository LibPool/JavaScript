# dsh-hypersub

> 标签: deepseek-harness, dsh, model-routing, multimodal, plugin, vision

## 简介

Route DSH subagent requests to user-approved multimodal/economy models; paste/drop-to-path image cache with thumbnail rail; silent at boot, no cordis runtime needed.
