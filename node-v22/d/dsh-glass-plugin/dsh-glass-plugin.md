# dsh-glass-plugin

> 标签: deepseek-harness, desktop, dsh, dsh-plugin, electron, glass, status-bar, windows

## 简介

Floating glass status bar for DeepSeek Harness: a frameless always-on-top window that shows session progress, pending approvals and questions.
