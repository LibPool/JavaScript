# dsh-plugin-vault-memory

> 标签: deepseek-harness, dsh, knowledge-base, obsidian, second-brain, vault

## 简介

让本地 Obsidian 知识库成为 DeepSeek Harness agent 的长期记忆与工作台（索引 + 检索工具 + 会话记忆注入 + 捕获 + GUI 浮卡）
