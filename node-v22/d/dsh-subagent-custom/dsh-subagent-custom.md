# dsh-subagent-custom

> 标签: deepseek-harness, dsh, dsh-plugin, jev, routing, subagent

## 简介

Subagent model control for DeepSeek Harness: pick a subagent model by hand per session, or let Jev assign one per task — both enforced on the subagent's own request.
