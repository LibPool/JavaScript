# dsh-launch-buttons

> 标签: composer, cordis, deepseek-harness, dsh, dsh-plugin, launcher

## 简介

Multiple named launch targets in the DSH composer: left-click starts the default target, right-click opens the list. 对话输入框的多启动项按钮：左键启动默认项，右键弹出列表，每项可绑定一个程序或目录。
