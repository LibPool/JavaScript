# dsh-linghun-assembler

> 标签: agent-team, assembler, bm25, cognitive-agent, cognitive-loop, deepseek-harness, dsh, dsh-plugin, memory, retrieval

## 简介

灵魂的记忆提取侧·认知循环团队版：判断→捞取→组装→被判定→校准五步闭环，判官/史官/辩手/编辑/书记角色化子智能体承载，BM25 检索 + 时序素材 + LLM 组装「有用素材包」注入 linghun。与 dsh-linghun 组合使用。
