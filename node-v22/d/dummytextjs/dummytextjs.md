> 标签: HTML, JavaScript, Lorem Ipsum, data attributes, dummy text, library, npm, open source, paragraphs, plugin, productivity, sentences, software projects, testing, web development

## 简介

A plug-and-play dummy content generator for words, sentences, and paragraphs — with built-in auto-injection for Vue, React, and Angular apps using HTML data attributes.
