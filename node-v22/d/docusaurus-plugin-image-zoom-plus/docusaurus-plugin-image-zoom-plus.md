# docusaurus-plugin-image-zoom-plus

> 标签: docusaurus, image, plugin, react, zoom

## 简介

这是一个适用docusaurus V3版本的图片放大插件， 原有docusaurus-plugin-image-zoom插件不支持docusaurus V3版本
