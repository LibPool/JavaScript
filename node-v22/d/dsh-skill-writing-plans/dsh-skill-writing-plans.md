# dsh-skill-writing-plans

> 标签: cordis, deepseek-harness, dsh, plan-first, plugin, skill, trae, writing-plans

## 简介

DeepSeek Harness skill plugin that adds the 'plan-first' skill: writes a structured implementation plan before coding, executes simple tasks inline, and offers an execution choice for complex work. The skill is named plan-first rather than writing-plans s
