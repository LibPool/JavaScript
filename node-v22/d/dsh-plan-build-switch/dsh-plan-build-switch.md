# dsh-plan-build-switch

> 标签: bundle, client, deepseek-harness, dsh, plan-mode, plugin, web

## 简介

Composer Plan/Build mode switch for DeepSeek Harness web: neutral segmented control, customizable global shortcut, fully custom plan indicator; installs as a profile bundle (no manual patch row) and auto-reloads open pages when the module roster changes
