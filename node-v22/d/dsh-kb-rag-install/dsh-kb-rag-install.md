# dsh-kb-rag-install

> 标签: dsh, installer, kb-rag, knowledge-base, literature, rag

## 简介

One-command installer for dsh-kb-rag (local literature knowledge-base RAG for DSH): `npx dsh-kb-rag-install` does everything — Python deps, engine smoke test, pnpm, DSH plugin install+activate, model pre-download (auto HF mirror retry).
