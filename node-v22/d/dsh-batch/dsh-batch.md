# dsh-batch

> 标签: batch, cordis, deepseek-harness, dsh, dsh-plugin, jobs, queue

## 简介

Batch jobs for DeepSeek Harness: Queue many small jobs and run them in controlled batches inside DeepSeek Harness, with per-batch limits and failure isolation. Name reserved; first release in development.
