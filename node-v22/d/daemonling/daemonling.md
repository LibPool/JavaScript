# daemonling

> 标签: animation, custom-element, mascot, operating-systems, presentation, slides, sprite, teaching, web-component

## 简介

A tiny animated process character (web component) that lives on top of your slides — spawns, walks, holds up code words, goes zombie, and terminates with a bang.
