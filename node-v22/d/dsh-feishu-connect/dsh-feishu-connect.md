# dsh-feishu-connect

> 标签: bot, cordis, deepseek-harness, dsh, feishu, lark

## 简介

Bridge Feishu (Lark) chats with a DeepSeek Harness agent conversation: official-SDK long connection (no public URL), cc-connect-style commands (/new /switch /list /help), per-chat sessions, typing reactions, markdown cards, and a settings-page UI.
