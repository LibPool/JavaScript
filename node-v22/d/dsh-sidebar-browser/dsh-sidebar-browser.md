# dsh-sidebar-browser

> 标签: agent-tool, browser, browser-automation, cordis, deepseek-harness, dsh, dsh-plugin, sidebar

## 简介

Agent tool that drives DeepSeek Harness's built-in right-Sidebar Browser: open, navigate, snapshot, click, type, press, select, scroll, wait, evaluate JavaScript, and capture screenshots.
