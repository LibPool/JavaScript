# dmk-async-race

> 标签: async, framework-agnostic, mutex, race, semaphore, vue3, 竞态

## 简介

框架无关的异步竞态防护。RaceGuard / SubmitLock / Semaphore / runCancellable 一套组合拳，Vue 已适配（dmk-async-race/vue）。
