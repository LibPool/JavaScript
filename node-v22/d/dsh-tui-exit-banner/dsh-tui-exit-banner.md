# dsh-tui-exit-banner

> 标签: cordis, deepseek, deepseek-harness, dsh, dsh-tui, exit-banner, plugin, tui

## 简介

退出 dsh-TUI 时打印大号 DeepSeek 横幅：会话标题 + dst --resume <id>，空会话静默退出。
