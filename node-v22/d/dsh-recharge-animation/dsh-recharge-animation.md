# dsh-recharge-animation

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, recharge, startup-animation

## 简介

DSH 充值启动动画：侧边栏充值按钮 → 毛玻璃开场动画 → 动画结束用内置平台视图打开官方充值页；右键按钮可打开设置面板换图标、音效与文案。
