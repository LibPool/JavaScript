# dsh-gui-auth-url

> 标签: agent-tool, authenticated-url, browser-automation, cordis, deepseek, deepseek-harness, dsh, dsh-plugin, gui, web-gui

## 简介

Expose the running DeepSeek Harness Web GUI's authenticated URL as an agent tool, so browser automation can open the GUI instead of failing with 401.
