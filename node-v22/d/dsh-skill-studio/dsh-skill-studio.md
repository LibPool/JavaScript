# dsh-skill-studio

> 标签: deepseek-harness, dsh, dsh-plugin, editor, extract, extractor, manager, session, skill, skills, studio

## 简介

Skill studio for DeepSeek Harness: visualize all agent skills, view/edit their SKILL.md bodies, toggle model/user invocation, and mine session logs to extract reusable personal skills (auto-loadable by the agent) — from the web settings panel (Skill 工作台)
