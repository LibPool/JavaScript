# dashcommerce-mercadopago

> 标签: astro, checkout, dashcommerce, ecommerce, emdash, latam, mercadolibre, mercadopago, payment-provider, payments, typescript

## 简介

Mercado Pago (Checkout Pro) payment provider for DashCommerce - the open-source commerce plugin for EmDash CMS. Covers all of Latin America plus USD/EUR.
