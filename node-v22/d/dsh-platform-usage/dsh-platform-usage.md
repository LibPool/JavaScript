# dsh-platform-usage

> 标签: balance, deepseek, deepseek-harness, dsh, plugin, usage, web

## 简介

DeepSeek Harness web plugin: adds a 用量 (usage) entry beside Settings showing DeepSeek platform balance plus last-30-days and today usage (cost + tokens).
