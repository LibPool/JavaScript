# dragon-doll-kit

> 标签: JavaScript

## 简介

黑龙骨架成品包:13 根骨骼 / 13 块部件 + 9 帧振翅贴图,翅膀逐帧换图的振翅,Cocos Creator 3.8。npm 装包后跑 dragon-doll-sync 把资源同步进工程 assets/resources/。
