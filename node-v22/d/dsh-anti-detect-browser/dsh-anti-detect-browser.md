# dsh-anti-detect-browser

> 标签: agent-tools, anti-detect, antidetect, automation, browser, camofox, camoufox, chromium, deepseek, dsh, playwright, stealth

## 简介

Interactive browser tools for dsh (navigate/snapshot/click/fill/eval/screenshot/close). Dual backend: Camoufox anti-detect Firefox or local full Chromium via Playwright. Ref-based element snapshots; architecture mirrors the Hermes Agent browser tool.
