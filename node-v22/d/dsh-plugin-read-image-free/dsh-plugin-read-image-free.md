# dsh-plugin-read-image-free

> 标签: dsh, glm, image, ocr, plugin, read-image-free, vision

## 简介

dsh web 插件：不因模型不支持图片而拒绝附件（图片保存到本地后把带扩展名的绝对路径以文本传给模型）；并内化 image-read-free 技能逻辑，注册 read_image_free 工具（调用智谱 GLM-4.1V-Thinking-Flash 做 OCR/图像理解），模型无需该技能即可直接处理图片
