# digest-auth-header

> 标签: authorization-header, digest-auth, digest-authentication, http-auth, rfc2617, rfc7616, www-authenticate

## 简介

Parse a WWW-Authenticate: Digest challenge and build the matching Authorization header, per RFC 7616 (and RFC 2617/2069)
