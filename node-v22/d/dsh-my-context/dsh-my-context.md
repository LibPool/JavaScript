# dsh-my-context

> 标签: JavaScript

## 简介

DSH 上下文透镜 + 成本治理插件：token 用量可视化（每次请求的上下文构成、KV 缓存命中率）+ 每轮/每会话预算控制（超限提醒/拦截）。DSH web plugin: context lens (token usage visualization, KV cache hit rate) + cost governance (per-turn / per-session budget with warn/deny).
