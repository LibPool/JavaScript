# dgb-digidollar-mcp

> 标签: ai-agents, digibyte, digidollar, mcp, x402

## 简介

TESTNET-ONLY proof of concept: an MCP server that lets an AI agent pay for a service in DigiByte/DigiDollar via the x402 pay-and-retry pattern. Allowance, not custody.
