# dsh-wtq-pool

> 标签: deepseek-harness, dsh-plugin, failover, model-provider, multi-account, qoder, trae, workbuddy

## 简介

把本机 WorkBuddy、Trae、Qoder 的桌面登录接入 DeepSeek Harness。限流或额度用尽时自动换号，三家各自开关，国内与国际账号分别成组。
