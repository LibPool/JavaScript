# dufresne

> 标签: algorithms, cli, copy-paste, data-structures, helpers, lodash, registry, shadcn, type-fest, types, typescript, underscore, utilities, utils

## 简介

Copy small, dependency-free TypeScript utilities, algorithms, data structures and types straight into your project instead of installing a package for them — shadcn/ui, applied to code.
