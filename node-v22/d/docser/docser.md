# docser

> 标签: describe, development, docs, docs-server, explain, markdown, readme, server

## 简介

主要用于管理开发文档，例如前端的组件库，前端的模块等，都可以提供一个良好的文档，本文档也不仅限于前端项目，可以用于任何的项目的介绍，不过前端项目可以直接在前端预览。
