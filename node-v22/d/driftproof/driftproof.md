# driftproof

> 标签: agent-skills, claude-code, drift, llm-evaluation, receipts, skill-eval, skill-md

## 简介

A dated proof that this skill, this hash, this model, still helps: run a skill's eval suite with and without the skill across model versions, emit hash-verified dated receipts, and diff receipts into drift reports.
