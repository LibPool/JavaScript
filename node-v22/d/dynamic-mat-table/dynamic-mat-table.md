# dynamic-mat-table

> 标签: advance table, angular, angular2, arabic, auto height, configurable setting, high performance, material, multi language, multi setting configuration, persian, rtl support, table, virtual scroll

## 简介

dynamic-mat-table is an Angular component for presenting large and complex data with a lightning fast performance (at least 10x faster) and excellent level of control over the presentation.
