# dsh-write-create-only

> 标签: create-only, deepseek-harness, dsh, dsh-plugin, edit, no-overwrite, write

## 简介

禁止 write 覆盖已存在的文件：write 只允许创建新文件，目标已存在时在工具执行前直接拒绝并提示改用 edit，全局所有会话生效，防止模型用 write 整体覆写已有内容。纯 host 端 dsh 插件。
