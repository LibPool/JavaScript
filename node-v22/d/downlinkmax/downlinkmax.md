# downlinkmax

> 标签: amd, api, bandwidth, coffeescript, connection, detect, downlink, downlinkmax, download, framework, information, javascript, library, micro, navigator, network, polyfill, speed, window

## 简介

downlinkMax is a 0.26KB Network Information API polyfill for navigator.connection.downlinkMax written in both CoffeeScript and JavaScript with AMD support.
