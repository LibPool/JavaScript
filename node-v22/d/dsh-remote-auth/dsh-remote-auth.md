# dsh-remote-auth

> 标签: authorization, browser-auth, deepseek, deepseek-harness, dsh, dsh-plugin, lan, mobile, qr, remote-access, tailscale

## 简介

DSH remote-access authorization page: one click or QR scan mints the current process's browser-session URL (no more digging tokens out of server logs). Optional authority/subnet fence and 8-char PIN gate. · DSH 远程授权页：点击链接或扫码即可铸造当前进程的浏览器会话，带 Host/网段围栏与 PIN
