# dsh-similarity

> 标签: dedupe, dice, dsh, edit-distance, fuzzy-match, hamming, jaccard, levenshtein, plugin, similarity

## 简介

Similarity toolkit for DeepSeek Harness: edit distance (Levenshtein / Dice / Jaccard / Hamming), near-duplicate pair discovery across a list, and fuzzy best-match lookup. Zero runtime dependencies, read-only.
