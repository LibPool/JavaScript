# dialeto

> 标签: agent, beliefs, claude-code, codex, local-first, mcp, mcp-server, truth-maintenance

## 简介

An MCP server that gives an agent a dialect with its owner: beliefs with standing, a feedback loop, and a gate on action. No model calls, no API key.
