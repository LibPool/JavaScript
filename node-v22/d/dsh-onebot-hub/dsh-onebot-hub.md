# dsh-onebot-hub

> 标签: agent, cordis, deepseek-harness, dsh-plugin, llm, nonebot, onebot, onebot-v11, qq

## 简介

OneBot v11 hub for DeepSeek Harness: connects to an upstream OneBot v11 implementation (forward WebSocket client) and serves/dials downstream bot implementations with the same protocol, relaying events and actions verbatim so DSH can observe every message
