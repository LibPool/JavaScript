# dsh-pocket-ui

> 标签: deepseek-harness, dsh, dsh-plugin, mobile, plugin, pocket, responsive, web

## 简介

DSH Web UI 移动端适配（轻量核心版）：窄屏下侧栏变抽屉、对话框变底部 sheet、刘海安全区避让、输入区不重叠；鼠标操作的桌面端任何宽度都完全 no-op。
