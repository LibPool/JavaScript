# dsh-quote-annotate

> 标签: annotate, dsh, plugin, quote, reference, selection

## 简介

选区引用与锚点批注：在 DSH 会话中选中文字 → 批注 → 引用锚点 chip（点击跳回原文、悬停显示原文）→ 提交序列化为结构化引用块。
