# drawio-mcp

> 标签: architecture-diagrams, diagrams, drawio, mcp, model-context-protocol, mxgraph, svg, visualization, vscode

## 简介

MCP server for generating draw.io diagrams using mxgraph. Create and manage diagrams programmatically with VSCode compatibility.
