# duneforge

> 标签: access-control, admin-console, api, auth, backend, crud, introspection, jwt, kysely, mysql, openapi, permissions, postgres, postgresql, rbac, rest-api, row-level-security, typescript

## 简介

Universal backend: introspects your MySQL/Postgres schema and serves an access-controlled REST API, auth, file upload, generated docs and a master console.
