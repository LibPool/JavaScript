# dicom-worklist

> 标签: c-find, dicom, dimse, healthcare, hl7, mwl, orthanc, pacs, radiology, worklist

## 简介

DICOM Modality Worklist (MWL) C-FIND client for Node.js. Query scheduled procedures from any PACS supporting MWL SOP Class.
