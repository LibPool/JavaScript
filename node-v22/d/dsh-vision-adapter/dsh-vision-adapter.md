# dsh-vision-adapter

> 标签: deepseek-harness, dsh, kimi, llm-adapter, multimodal, vision

## 简介

给 DeepSeek Harness 加视觉能力：可视化设置页选视觉厂商（Kimi/智谱/通义/OpenAI/Gemini/豆包/MiniMax/阶跃星辰）并粘贴 API Key，聊天里即可拖图识别——图片走视觉模型、文字走 DeepSeek 推理。
