# dxf-lit

> 标签: autocad, blueprint, cad, cad-viewer, custom-element, drawing, dxf, dxf-lit, dxf-parser, dxf-renderer, dxf-three, dxf-viewer, engineering, lit, parser, technical-drawing, three.js, threejs, typescript, viewer, web-component, webgl

## 简介

Web Component DXF viewer — render AutoCAD DXF drawings in any stack (or none) via a <dxf-viewer> custom element. Built on a Three.js/WebGL engine with a built-in parser and vector text rendering.
