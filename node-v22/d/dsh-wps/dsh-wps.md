# dsh-wps

> 标签: cloud-docs, deepseek-harness, dsh, dsh-plugin, mcp, wps, 金山文档

## 简介

WPS / 金山文档 cloud-docs integration for DeepSeek Harness: official SkillHub MCP (https://mcp-center.wps.cn/skill_hub/mcp), custom browser authorization (auth-guide + exchange-poll token), WPS cloud-doc tools under mcp__wps__*, wps_status/wps_oauth_start/wps
