# dsh-web-direct

> 标签: bundle, deepseek-harness, dsh, fake-ip, plugin, web, web-fetch, web-search

## 简介

DeepSeek Harness (DSH) host plugin: make web_search / web_fetch bypass a machine fake-ip DNS and resolve/connect to the real public address (绕过 fake-ip DNS，让 web 工具解析到真实地址)
