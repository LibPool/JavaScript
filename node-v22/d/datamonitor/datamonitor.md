# datamonitor

> 标签: JavaScript

## 简介

DataMonitor ===================   datamonitor是一个监控服务，启动之后监听一个端口。   客户端通过socket连接将实际用户的请求信息发送到这个服务器， {type, date, name, id, ext, action}\x01{......}   datamonitor通过统计这些流量的频率来判断用户是否为爬数据行为
