# dsh-personal-assistant

> 标签: agent, deepseek-harness, dsh, dsh-plugin, personal-assistant, personal-knowledge, preferences, proactive-assistant

## 简介

A proactive, human-like personal-assistant kernel for DeepSeek Harness: personal knowledge, stable and situational guidance, follow-through tasks, adaptive check-ins, resource discovery, and reusable experience.
