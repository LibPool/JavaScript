# dockerfile-sentinel

> 标签: cli, container-security, containerfile, devsecops, docker, docker-compose, dockerfile, github-action, hadolint, linter, sarif, secrets, security

## 简介

Dockerfile and Docker Compose security linter: root users, unpinned or EOL base images, hardcoded secrets, curl | sh, disabled TLS/GPG checks, sensitive COPY, missing .dockerignore, privileged containers, docker.sock mounts, host namespaces and dangerous
