# dsh-git-vcs

> 标签: deepseek-harness, dsh, git, plugin, vcs, web-ui

## 简介

DSH Web GUI 的 Git 版本管理插件：右侧栏新增「版本管理」页，功能与界面参照 IntelliJ IDEA 的 Version Control 工具窗（本地变更 / 提交 / 历史 / 分支 / 命令 / 贮藏）。
