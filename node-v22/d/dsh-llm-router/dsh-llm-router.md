# dsh-llm-router

> 标签: auto-route, cordis, deepseek-harness, dsh, dsh-plugin, fallback, llm-router, model-routing, plugin

## 简介

Task-aware automatic model router (auto route) for the DeepSeek Harness: picks a backend model per request (vision / long-context / default) and falls back across configured models on clean pre-content failures.
