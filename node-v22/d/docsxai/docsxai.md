# docsxai

> 标签: agent, claude-code, docsxai, documentation, playwright

## 简介

Deterministic screenshot docs for web apps — the batteries-included CLI. Meta-package over @docsxai/engine (the docsxai CLI + library) and @docsxai/viewer (the renderer `docsxai render` spawns).
