# docujoint

> 标签: cli, documentation, documentation-as-code, graph, knowledge-base, linter, markdown, okf, sqlite, static-analysis

## 简介

Deterministic documentation-format engine: you declare the format (an OKF profile), it parses your markdown into a joinable IR — findings, dashboards, and a graph projection
