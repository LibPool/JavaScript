# dsh-ast-edit-tool

> 标签: ast-grep, codemod, cordis, dsh, dsh-plugin, structural-edit

## 简介

DSH structural code-edit tool: preview and apply ast-grep rewrites ($NAME / $$$ARGS metavariables) over files, directories, and globs, ported from oh-my-pi's ast_edit.
