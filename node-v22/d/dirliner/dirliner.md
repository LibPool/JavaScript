# dirliner

> 标签: ai-tools, cli, code-preparation, code-review, directory, directory-mapper, dirliner, dirliner-cli, file-transformer, files, flat-directory, flat-files, flatten, javascript, node, path, path-converter, structure, typescript

## 简介

Transform directory structures into flat files while preserving path relationships in filenames. Convert paths like src/app/page.ts to src-app-page.ts automatically.
