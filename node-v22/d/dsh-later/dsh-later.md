# dsh-later

> 标签: deepseek-ai, dsh, dsh-plugin, later, reminder, session, timer

## 简介

会话内定时消息插件：在 dsh-schedule 引擎之上提供用户可直接操作的 GUI + 用户工具，实现「关网页也能准时触发的会话内定时提醒」。
