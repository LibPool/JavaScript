# discuz-cli

> 标签: JavaScript

## 简介

**dz-cli** 是一个用于创建 Discuz 插件的脚手架工具。通过该工具，你可以快速生成 Discuz 插件的基础结构，从而专注于插件的具体功能开发。

## 官网
