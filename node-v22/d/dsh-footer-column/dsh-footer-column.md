# dsh-footer-column

> 标签: JavaScript

## 简介

DSH web 补丁插件：把侧边栏底部插件入口区（sidebar.footer.action）从横向 flex 行改为纵向堆叠，并阻止插件按钮浮动定位，解决多插件入口溢出错位/与设置按钮重叠的问题。纯 CSS 注入，选择器基于 CSS-module 稳定后缀（footerActions），DSH 或其他插件升级后依然有效。
