# dsh-session-watch

> 标签: archive, deepseek, deepseek-harness, dsh, dsh-plugin, session, sidebar, status, watch

## 简介

DSH Web 插件：侧边栏底部显示运行中/未读/待处理/闲置/未归档/已归档的会话计数，可在设置页逐项开关。
