# deno-srt-to-vtt

> 标签: JavaScript

## 简介

A deno library that converts SRT files to VTT equivalents so they can be broadcast on the Internet.

## 官网

- 源码仓库：https://git.froth.zone/sam/srt-to-vtt
- npm 页面：https://www.npmjs.com/package/deno-srt-to-vtt
