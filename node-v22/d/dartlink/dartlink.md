# dartlink

> 标签: JavaScript

## 简介

dartlink is a lightweight Node.js utility that bridges the gap between Flutter and your Node.js workflow. Easily manage, sync, or trigger Dart and Flutter files directly from your Node environment. Ideal for automation, build processes, and hybrid app pip
