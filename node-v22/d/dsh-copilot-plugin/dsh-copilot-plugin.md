# dsh-copilot-plugin

> 标签: copilot, cordis, cordis-plugin, deepseek-harness, dsh, instructions, plugin, prompt, system-prompt, web-ui

## 简介

A co-pilot for your DSH agent's instructions: read the system prompt as sections, write your own house rules into it, catch the rules that contradict each other, keep a logbook of every change - and roll it all back.
