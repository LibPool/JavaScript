# derrick-mcp

> 标签: ai, b2b, claude, derrick, email, enrichment, linkedin, mcp, prospecting, sales

## 简介

Derrick B2B enrichment MCP server — find emails, enrich LinkedIn profiles, search companies, and more. Works with Claude Desktop, Claude Code, Cursor, and any MCP-compatible client.
