# dsh-restart-planner

> 标签: agent-automation, deepseek-harness, dsh, dsh-plugin, hot-reload, plugin-reload, process-control, relaunch, reload, restart, self-restart, watchdog, windows, 鑷姩閲嶅惎, 閲嶅惎

## 简介

让 agent 自己能安排宿主重启：排程、到点动手，重启完自动接着刚才没做完的事继续。 Let the agent restart its own DSH host: schedule it, run it, and resume the same session afterwards.
