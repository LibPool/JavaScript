# dsh-easy-upgrade

> 标签: cordis, deepseek-harness, dsh, plugin, upgrade

## 简介

DSH web plugin: check the local harness repo against origin/<branch> and one-click upgrade (stop dsh, reset --hard, install, build, restart). · DSH 一键升级：检查本地仓库与远程主分支差异，侧栏设置上方显示版本/更新按钮，点击一键升级并重启服务。
