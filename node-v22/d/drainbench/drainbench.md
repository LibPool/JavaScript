# drainbench

> 标签: agent-security, agents, ai-safety, benchmark, llm, payments, prompt-injection, red-teaming, security, tool-use, usdc, x402

## 简介

Benchmark: how often LLM agents with a pay() tool get prompt-injected into paying an attacker, and which defense layer stops the money.
