# devfree

> 标签: cache, cleanup, cli, development, nextjs, npx, storage

## 简介

Interactive CLI to scan and clean temporary development folders. Currently supports .next folders from Next.js projects.

## 官网

- npm 页面：https://www.npmjs.com/package/devfree

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install devfree`
- npm registry：https://registry.npmjs.org/devfree
- Node 要求：>=18
