# dsh-claude-import

> 标签: claude-code, dsh, dsh-plugin, import

## 简介

Import Claude Code config (skills / rules / CLAUDE.md / AGENTS.md) into DeepSeek Harness, with destination preview, conflict strategies, and idempotent re-imports.
