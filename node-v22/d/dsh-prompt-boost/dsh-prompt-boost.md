# dsh-prompt-boost

> 标签: deepseek-harness, dsh, dsh-plugin, prompt, prompt-engineering, 提示词

## 简介

提示词强化插件：输入框旁一键按钮，把用户写好的简短话优化成完整提示词（手动触发，非输入框自动实时增强）。
