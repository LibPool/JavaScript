# datapipe-js

> 标签: LINQ, data, data-analysis, data-cleaning, data-clensing, data-management, data-manipulation, data-mungling, data-science, data-wrangling, json, pandas

## 简介

dataPipe is a data processing and data analytics library for JavaScript. Inspired by LINQ (C#) and Pandas (Python)
