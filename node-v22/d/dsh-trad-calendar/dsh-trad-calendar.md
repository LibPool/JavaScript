# dsh-trad-calendar

> 标签: JavaScript

## 简介

传统历法坐标(数据之镜):干支(年月日)、二十四节气、月相、五行季节与旺相休囚死。依据《交易维度-二十四节气与地支藏干五行阴阳关系》。
