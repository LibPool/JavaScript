# drachtio-astmrf

> 标签: JavaScript

## 简介

A companion module to [drachtio-srf](https://www.npmjs.com/package/drachtio-srf) that lets you build [drachtio](https://drachtio.org) applications and utilize [Asterisk](https://www.asterisk.org) as a media server.
