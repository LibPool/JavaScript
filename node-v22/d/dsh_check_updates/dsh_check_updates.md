# dsh_check_updates

> 标签: deepseek, deepseek-harness, npm, update-check, version-check

## 简介

DeepSeek Harness 更新检查插件：DSH 本体与 profile 插件版本可见性（模型工具 + Settings 页面 + 周期复查），只报告不执行升级。
