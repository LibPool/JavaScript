# dsh-config-backup

> 标签: backup, config, deepseek-harness, dsh, plugin, restore

## 简介

DSH configuration backup and restore: inventory, export, and import the portable config surface (agent presets, skills, instructions, settings, credentials, profiles) as a JSON manifest.
