# dsh-windows-monitor

> 标签: cordis, cpu, deepseek, deepseek-harness, disk, dsh-plugin, memory, monitor, overlay, performance, plugin, resource-monitor, system-monitor, web-ui, windows, windows-monitor

## 简介

System monitor overlay for DeepSeek Harness: a compact corner pill showing CPU and memory, expandable into a detail card with disk activity and throughput, per-volume capacity, network, uptime and battery. Windows only.
