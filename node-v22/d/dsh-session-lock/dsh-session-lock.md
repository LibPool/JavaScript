# dsh-session-lock

> 标签: deepseek-harness, dsh-bundle, dsh-plugin, lock, passcode, privacy, session, session-lock, web-ui

## 简介

Passcode lock for DeepSeek Harness Sessions: a locked Session cannot be opened for viewing in the Web UI. / 用口令锁定 DSH 会话：锁定后必须输入口令才能在界面中打开查看。
