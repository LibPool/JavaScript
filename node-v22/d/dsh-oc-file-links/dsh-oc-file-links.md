# dsh-oc-file-links

> 标签: deepseek, deepseek-harness, dsh, dsh-plugin, file, open

## 简介

DeepSeek Harness 逐轮产出物卡片插件:每一轮(assistant 回答下方)显示该轮真正产出的文件与网址,精确按轮归属、只认非只读工具写/改/展示内容,撤回(截断)该轮后卡片随轮消失;卡片可一键用默认程序打开、在侧边栏预览或打开所在位置
