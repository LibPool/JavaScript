# directus-extension-single-session

> 标签: concurrent-login, directus, directus-extension, directus-extension-bundle, session, single-session

## 简介

Sitefinity-style single active session for Directus: when the same user logs in from a second device, the new device is asked to either kick the other session or go back to the login screen.
