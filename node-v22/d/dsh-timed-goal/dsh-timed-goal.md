# dsh-timed-goal

> 标签: automation, deepseek-harness, dsh, goal, plugin, scheduler, timed-goal, webui

## 简介

DSH web plugin: schedule an automatic /goal execution from inside a conversation, with both a /timed-goal command and a Web UI (per-conversation input control + settings section). Configure an absolute datetime (year/month/day/hour/minute/second) plus a p
