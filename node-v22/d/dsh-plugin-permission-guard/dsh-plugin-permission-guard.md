# dsh-plugin-permission-guard

> 标签: cordis, deepseek-harness, dsh, permissions, plugin, sandbox, security

## 简介

Four-mode file-permission fence for DeepSeek Harness (workspace read/write x outside read/write), enforced at the tool layer, with a read-only composer mode indicator and a locale-aware UI.
