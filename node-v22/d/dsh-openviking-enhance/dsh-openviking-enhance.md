# dsh-openviking-enhance

> 标签: deepseek-harness, dsh, dsh-plugin, memory, observability, openviking

## 简介

OpenViking in the DSH web GUI: a Studio panel, a per-session memory-commit status pill with its commit timeline, and a right-sidebar tab showing what the current session retrieves.
