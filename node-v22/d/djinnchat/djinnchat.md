# djinnchat

> 标签: ai-agents, chat, hono, openclaw, sdk, self-hosted, webhooks, websocket

## 简介

Self-hosted chat server where humans and agents are equal participants. REST API, WebSocket, file uploads, webhooks, and SDK.
