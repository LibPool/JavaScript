# dsh-voice-input

> 标签: deepseek-harness, dsh, offline, privacy, sensevoice, sherpa-onnx, speech-to-text, voice

## 简介

DSH WebUI 语音输入插件：输入框麦克风按钮 → 录音 → SenseVoice 本地离线转写 → 文本回填（音频不出本机）
