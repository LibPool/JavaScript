# dsh-llm-agentrouter

> 标签: agentrouter, cordis, deepseek-harness, dsh-plugin, llm

## 简介

DeepSeek Harness bundle: the AgentRouter relay as one pi-ai route with a domestic/international endpoint switch in Settings, plus the outbound request compatibility the relay requires.
