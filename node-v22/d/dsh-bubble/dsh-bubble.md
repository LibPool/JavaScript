# dsh-bubble

> 标签: bubble, deepseek-harness, desktop-assistant, dsh-plugin, lookover, macos

## 简介

macOS 悬浮对话气泡：在当前工作页面旁提问，与 DSH 主窗口继续同一会话。搭配 dsh-look 读取上下文、dsh-expmem 复用解决经验。
