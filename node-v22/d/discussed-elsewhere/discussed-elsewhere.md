# discussed-elsewhere

> 标签: bluesky, comments, discussions, hacker-news, hugo, lemmy, reddit, static-site

## 简介

Find where an article is being discussed (Hacker News, Reddit, Bluesky, Lemmy) and list the threads: a dependency-free, keyless browser module for static sites
