# dsh-lan-tool

> 标签: bundle, deepseek-harness, dsh, lan, plugin, remote, web-gui

## 简介

LAN access for the DeepSeek Harness Web GUI: a password-gated LAN channel whose on/off switch lives in Settings (no install scripts, no password prompt at install time). Serves the LAN from the plugin's own reverse proxy, so DSH's listener stays on loopba
