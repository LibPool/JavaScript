# db-knih-api

> 标签: JavaScript

## 简介

DB Knih API je npm balíček poskytující jednoduché rozhraní pro čtení informací z databáze knih. Balíček obsahuje funkce pro vyhledávání knih a získávání podrobností o konkrétní knize.
