# dsh-persona-memory

> 标签: deepseek-harness, dsh, dsh-plugin, long-term-memory, memory, persistent-memory, persona, plugin

## 简介

Persistent long-term persona memory for DeepSeek Harness: MEMORY.md/USER.md storage, memory + memory_search tools, per-request context injection, secret scanning, and a WebUI memory-management settings page. Ported in spirit from pi-hermes-memory. TypeScr
