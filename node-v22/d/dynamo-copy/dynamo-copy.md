# dynamo-copy

> 标签: AWS, AWS dynamodb sync, copy dynamodb, dynamo-copy, dynamodb, dynamodb copy

## 简介

- Copy data from one AWS account to another AWS account in DynamoDB.  - Copy data in same AWS account in DynamoDB.  - Upsert data in DynamoDB.  - Copy data, modify, and insert.
