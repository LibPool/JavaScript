# dsh-conversation-outline

> 标签: conversation-navigation, conversation-outline, deepseek-harness, dsh, plugin, session-index

## 简介

DeepSeek Harness Web 会话大纲插件：固定在页面最右侧的一列横条标记当前 Session 的用户提问，鼠标 hover 展开单行摘要大纲，点击跳转到对应对话位置；数据量大时列表可滚动并动态加载，hover 到列表边缘可自动滚动。
