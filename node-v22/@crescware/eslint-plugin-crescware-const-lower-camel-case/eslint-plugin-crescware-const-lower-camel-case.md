# @crescware/eslint-plugin-crescware-const-lower-camel-case

> 标签: JavaScript

## 简介

ESLint plugin that requires every `const` declaration binding to be named in lowerCamelCase. It ships as a standard ESLint plugin and is dogfooded on its own source through [oxlint](https://oxc.rs/docs/guide/usage/linter)'s JS plugin support.
