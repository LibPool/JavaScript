# @nxt-demo/lib-i18n

> 标签: JavaScript

## 简介

A biblioteca da i18n da [Nexti](https://www.nexti.com/) é uma extensão do [react-i18next](https://react.i18next.com/), um poderoso framework de **internacionalizaçcão** para **React**, que é baseado no [i18next](http://i18next.com).
