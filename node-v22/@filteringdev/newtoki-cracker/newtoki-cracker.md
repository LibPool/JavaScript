# @filteringdev/newtoki-cracker

> 标签: JavaScript

## 简介

newtoki-cracker 유저스크립트는 Newtoki 웹사이트(도메인 패턴: `sbxh[0-9]+.com`)에서 안티-애드블록 스크립트나 기타 스크립트를 차단하거나 무력화하는 유저스크립트입니다.
