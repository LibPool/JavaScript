# @cache-utils/core

> 标签: cache, cache-adapter, cache-manager, caching, ttl, typescript

## 简介

Adapter-based cache manager for TypeScript — wrap, get/set/del, distributed locks, and namespacing on top of a 4-method CacheAdapter interface.
