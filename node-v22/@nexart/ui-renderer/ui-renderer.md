# @nexart/ui-renderer

> 标签: ai-agent, bounded, browser, canvas, creative-coding, deterministic, generative, miniapp, preview, renderer, runtime, sandbox

## 简介

Browser-first bounded generative renderer for safe, fast, interactive visuals. Resolution scaling, frame budgets, observable state.
