# @table-craft/table-craft

> 标签: ai, board-game, bots, card-game, game-engine, mcp, model-context-protocol, multiplayer, prototyping, socket.io, tabletop, three.js

## 简介

Server-authoritative 3D tabletop engine: write the rules of any board or card game as one JavaScript module and get a physics-based, multiplayer, bot-ready table.
