# @tita-agent/dsh-session-taskpath

> 标签: JavaScript

## 简介

将冗长的 DSH 会话轨迹按任务和子目标聚合为执行路径；每轮结束增量提取详细节点与精简主阶段，支持证据回查和 Token 用量查看。
