# dsh-behavior-guard

> 标签: behavior-layer, deepseek-harness, dsh, dsh-plugin, safety, tool-guard

## 简介

把行为层里最容易忘的三条变成硬拦截：改文件前必须在本次会话读过它、会丢工作的破坏性命令先拿可逆写法、任务清单别变成摆设。
