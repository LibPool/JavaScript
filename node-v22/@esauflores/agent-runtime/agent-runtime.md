# @esauflores/agent-runtime

> 标签: JavaScript

## 简介

A small TypeScript CLI that runs one local command, optionally enforces a timeout, and records its result. Run source on **Node.js 24+ or Bun 1.4+**; published packages include compiled JavaScript so Node can execute the installed CLI without stripping Ty
