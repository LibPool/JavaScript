# @zhushanwen/z-words-reminder

> 标签: hooks, plain-language, readability, reminder, user-prompt-submit, zcode

## 简介

Periodic readability reminder for zcode: UserPromptSubmit hook injects a concept-grounding + lexicon reminder every 3rd user message.
