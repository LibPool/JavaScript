# @zhushanwen/subagent-engine-sdk

> 标签: JavaScript

## 简介

Engine-side SDK for the subagent engine protocol: NDJSON stdio contract types, engine primitives (schema emulation, nesting guard, kill chain, journal replay projection, data-dir/paths resolution) — the shared contract root between subagent-core and engin
