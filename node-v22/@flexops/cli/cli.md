# @flexops/cli

> 标签: cli, dhl, fedex, flexops, labels, sandbox, shipping, tracking, ups, usps

## 简介

Command-line companion for the FlexOps Gateway API. Issue sandbox keys, create labels, and track shipments without leaving the terminal.
