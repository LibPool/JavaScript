# nest-flowmap

> 标签: api-docs, bruno, documentation, flowchart, mermaid, nest, nestjs, openapi, postman, static-analysis, swagger

## 简介

Static documentation for NestJS APIs: per-endpoint flowcharts, an offline viewer, OpenAPI 3.0.0, Postman and Bruno exports (no LLM, runs locally)
