# @enterstellar/web-ui

> 标签: JavaScript

## 简介

Enterstellar shared UI component library — reusable, Enterstellar-branded primitives built on shadcn/ui (Radix) + Tailwind v4. Published to npm, consumed by all Enterstellar web apps and product repo internal/ui packages.
