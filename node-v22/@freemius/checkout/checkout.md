# @freemius/checkout

> 标签: checkout, freemius, wordpress

## 简介

Zero-dependency TypeScript SDK to embed Freemius Checkout in SaaS apps: secure buy button, user_token prefill, trials, coupons, multi-currency, i18n, callbacks. ESM/CJS.
