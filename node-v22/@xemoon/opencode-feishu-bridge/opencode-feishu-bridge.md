# @xemoon/opencode-feishu-bridge

> 标签: bridge, chatbot, feishu, lark, mcp, opencode

## 简介

飞书 ⇄ OpenCode 桥接服务：本地命令与 /m 菜单卡片、任务内提问/授权交互卡片、跨工作目录事件转发、文件直发（feishu_send_file MCP）。基于 opencode serve 的统一事件流，无需 opencode run 子进程。
