# @intlayer/vue-compiler

> 标签: JavaScript

## 简介

Vite-compatible compiler plugin for Vue with Intlayer, providing HMR support, file transformation, and optimized dictionary loading for Vue applications.

## 官网

- 官网：https://intlayer.org
- 源码仓库：git+https://github.com/aymericzip/intlayer.git
- npm 页面：https://www.npmjs.com/package/@intlayer/vue-compiler
