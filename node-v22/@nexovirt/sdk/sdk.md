# @nexovirt/sdk

> 标签: kvm, lxc, nexovirt, proxmox, proxmox-ve, rest-api, sdk, virtualization, vps

## 简介

Official TypeScript/JavaScript SDK for the NexoVirt REST API over Proxmox VE (hosts, guests, plans, IPAM, firewall, snapshots).
