# @rob.j.qva/babel-plugin-debug

> 标签: babel, babel plugin, babel-plugin, babelplugin, debug, plugin

## 简介

Plugin that transforms __DEBUG(<MESSAGE>) to console.log("[DEBUG line:", <LINE>, "file:", "<FILE>]", <MESSAGE>)
