# @dmstoykov/trayce

> 标签: android, bottom-sheet, expo, gesture-handler, headless, ios, modal, react-native, reanimated, sheet, tray

## 简介

A floating bottom tray for React Native: spring physics, height-morphing multi-step flows, stacked trays, and promise-based results.
