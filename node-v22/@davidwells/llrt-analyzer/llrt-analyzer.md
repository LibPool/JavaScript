# @davidwells/llrt-analyzer

> 标签: aws-lambda, cold-start, compatibility, llrt, quickjs, runtime, serverless

## 简介

Per-function analyzer that decides (statically + by actually running under LLRT) whether a Lambda function can switch to AWS LLRT for ~10x faster cold starts, and helps flip it.
