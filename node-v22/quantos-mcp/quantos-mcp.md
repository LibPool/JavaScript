# quantos-mcp

> 标签: ai-agent, erc-4337, grok, mcp, ml-dsa, post-quantum, trading, wallet

## 简介

Quantos MCP server: a quantum-safe trading wallet for AI agents (Grok Bot, Claude, any MCP app). The agent key is generated and kept locally.
