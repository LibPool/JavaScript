# @raolin2025/cc-node-bridge

> 标签: agent, bridge, cc-node, json-rpc, llm, stdio, websocket

## 简介

cc-node 引擎多客户端桥接层：Web / VS Code 统一接入（子进程池 + JSON-RPC 2.0 + 流式），支持引擎参数透传与运行时切换 LLM 源
