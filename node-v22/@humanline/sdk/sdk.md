# @humanline/sdk

> 标签: attestcoin, credit, creditcoin, proof-of-personhood, sybil-resistance, viem, world-id

## 简介

Sybil resistance on Creditcoin: check whether a wallet belongs to a verified World ID human, read their credit line, and gate contracts one-human-one-action.
