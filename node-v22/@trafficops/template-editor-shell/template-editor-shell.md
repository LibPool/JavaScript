# @trafficops/template-editor-shell

> 标签: JavaScript

## 简介

The shared React editor for Landing Studio, HTTP embedding and custom hosts. Storage, analysis, lifecycle and AI transport are supplied through the `EditorHost` ports from `@trafficops/template-editor-core`. The shell does not import a compiler, read API
