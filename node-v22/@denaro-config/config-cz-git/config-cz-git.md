# @denaro-config/config-cz-git

> 标签: commit, commitizen, config, cz, cz-git, denaro, git-cz

## 简介

前端工程化中的 cz-git 通用配置, 与 Commitlint 配合, 获取 Commitlint 相关配置, 给予命令行提示信息。
