> 标签: blockchain, carbonx3, cx3, cx3js, cx3script, cx3wasm, green-chain, oauth2, sdk, secp256k1, smart-contracts, tokens, web3

## 简介

Official Node.js SDK (CX3js) for CarbonX3 Green Chain: OAuth2 app access, local secp256k1 signing, ABI-bound contracts and token deploys over REST + JSON
