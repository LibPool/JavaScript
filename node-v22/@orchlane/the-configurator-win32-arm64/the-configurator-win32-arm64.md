# @orchlane/the-configurator-win32-arm64

> 标签: JavaScript

## 简介

the-configurator prebuilt binary for win32/arm64 (Windows on ARM). Installed automatically as an optionalDependency of @orchlane/the-configurator — do not depend on this package directly.
