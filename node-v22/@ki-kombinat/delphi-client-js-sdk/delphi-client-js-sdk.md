# @ki-kombinat/delphi-client-js-sdk

> 标签: delphi, headless, ki-kombinat, react, sip, softphone, telapi, telphi, tts, voice-agent, voice-ai, webrtc, websocket

## 简介

Session-first SDK for the Delphi voice-AI platform. Read-aloud, browser actions, text chat, and full WebRTC voice calls through one unified API. Zero runtime dependencies in the core; optional React bindings.
