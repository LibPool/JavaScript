# @qvelop444/humal

> 标签: commonjs, compiler, esm, humal, human, indentation, javascript, js, programming-language, transpiler, ts, typescript

## 简介

Humal is a programming language with human-readable syntax that uses indentation like Python and compiles directly to JavaScript, supporting both ESM and CommonJS.
