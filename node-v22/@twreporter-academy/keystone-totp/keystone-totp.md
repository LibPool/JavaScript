# @twreporter-academy/keystone-totp

> 标签: JavaScript

## 简介

TOTP (authenticator-app) two-factor authentication for [Keystone 6](https://keystonejs.com/), shaped like `@keystone-6/auth`: `createTotp()` returns `{ withTotp, fields }` and you wrap your config.
