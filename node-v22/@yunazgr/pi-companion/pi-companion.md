# @yunazgr/pi-companion

> 标签: companion, developer-tools, mobile, pi, pi-coding-agent, pi-extension, pi-package, remote-agent, remote-control, session-dashboard

## 简介

Local-first remote control for Pi sessions: live activity feed, steering, git diff, file drop and phone pairing from a single Rust daemon.
