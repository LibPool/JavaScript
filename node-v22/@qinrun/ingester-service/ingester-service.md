# @qinrun/ingester-service

> 标签: JavaScript

## 简介

data ingestion service - model是表结构, main 方法创建表 - data_basic 获取基础数据，股票基础数据和指数基础数据 - data_quotations 行情数据(日线，周线，年线) - data_index 指数数据(日线，周线，年线) - run 获取历史数据，每日增量数据
