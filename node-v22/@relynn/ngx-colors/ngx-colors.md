# @relynn/ngx-colors

> 标签: Angular, Color, Color Picker, ColorPicker, Colors, Material, Palette, ngx

## 简介

A beautiful color picker for angular that let you choose from a color palette, using sliders (Hue, Lightness, Alpha sliders) or through text input(hex, rgba, hsla). Fork of ngx-colors updated for Angular 22.
