# @donotlb/pi-vite

> 标签: docker, envsubst, mkcert, nginx, runtime-env, spa, vite, vite-plugin

## 简介

Vite plugins and a container entrypoint for static SPAs: runtime env injected at container start instead of baked in at build time, a shared dev server block (same-origin API proxy, mkcert HTTPS, tunnel hosts) and mode-gated HTML scripts.
