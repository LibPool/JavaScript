# @getparafe/a2a-extension

> 标签: a2a, a2a-extension, a2a-protocol, agent, agent-to-agent, ai, consent, google-a2a, identity, parafe, trust

## 简介

Parafé trust extension for the A2A protocol (A2A 1.0 and 0.3) — cryptographic agent identity, mutual authentication, and scoped consent carried in A2A message metadata
