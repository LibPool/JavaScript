# @linchkit/cap-adapter-ui

> 标签: JavaScript

## 简介

Frontend UI adapter for LinchKit — React 19 + Shadcn + TanStack Router/Query/Table. Provides entity-driven UI components (AutoForm, AutoList), shell layout, i18n, and theme support.
