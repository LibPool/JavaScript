# @utilityjs/retry-with-backoff

> 标签: backoff, exponential backoff, javascript, resilience, retry, retry logic, typescript

## 简介

Executes an asynchronous function with exponential backoff retry logic, automatically retrying on failure with increasing delays between attempts.
