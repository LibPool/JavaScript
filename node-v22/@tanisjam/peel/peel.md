# @tanisjam/peel

> 标签: branch, cli, dev-server, git, qa, worktree

## 简介

Ephemeral git worktrees with auto-managed dev servers. Spin up any branch with its own node_modules, env, and free port — and tear it all down on Ctrl+C.
