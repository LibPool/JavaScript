# @allansantos-dev/token-guard

> 标签: ai-agents, claude-code, context, copilot, cost, cursor, guardrails, mcp, tokens

## 简介

Economia de contexto para agentes de IA, agnóstico de IDE: mede o custo real do repositório em tokens, barra as chamadas que estouram a janela devolvendo sempre a alternativa barata, mede o preâmbulo dos servidores MCP e governa o contrato de saída. Adapt
