# @allem-sdk/analytics

> 标签: allem-sdk, amplitude, analytics, event-tracking, mixpanel, nextjs, page-view, posthog, react, react-hooks, segment, tracking, typescript

## 简介

Provider-agnostic analytics hooks for React. Works with Mixpanel, Segment, PostHog, Amplitude, and any custom adapter. useTrack, usePageView, useIdentify.
