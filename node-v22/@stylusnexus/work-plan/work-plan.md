# @stylusnexus/work-plan

> 标签: cli, github issues, project planning, tracks, work-plan

## 简介

Track-aware daily work planning over GitHub issues. Shared tracks (git-synced .work-plan/ in each repo), AI clustering (group/auto-triage), VS Code viewer, Claude Code + Codex plugins. Pure Python stdlib.
