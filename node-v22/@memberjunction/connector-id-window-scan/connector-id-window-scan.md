# @memberjunction/connector-id-window-scan

> 标签: JavaScript

## 简介

Pure helper that reads an object the vendor will not bulk-list, by walking its numeric key in bounded windows. Budget-aware, resumable, and it isolates records the vendor refuses instead of losing the object to them. One function, no class, no base — conn
