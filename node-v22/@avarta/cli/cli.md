# @avarta/cli

> 标签: JavaScript

## 简介

A small CLI that also runs as an MCP server — one binary, two entry points, both hitting the same Avarta API a browser session would. Built to answer: "how does a developer's coding CLI/extension feed Avarta's knowledge base?"
