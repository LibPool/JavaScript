# ds-web-ui

> 标签: JavaScript

## 简介

Web chat interface for DeepSeek Harness (DSH) — UI faithfully ported from pi-web-ui, agent backend swapped to the DSH stdio JSON-RPC runtime. All JavaScript, no Python.
