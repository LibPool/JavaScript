# @cognibox/babel-plugin-es5-proxy

> 标签: JavaScript

## 简介

Babel plugin to use ES6 Proxy in ES5. Inspired by the work of https://github.com/krzkaczor/babel-plugin-proxy, fixed for babel7 (and a lot more).
