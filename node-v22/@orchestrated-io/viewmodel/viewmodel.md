> 标签: command, couchdb, cqrs, database, ddd, dddd, domain, event, eventdenormalizer, eventsourcing, host, memory, model, mongodb, orm, redis, repo, repository, tingodb, view, viewmodel

## 简介

Node-viewmodel is a node.js module for multiple databases. It can be very useful if you work with (d)ddd, cqrs, eventdenormalizer, host, etc.
