# @rhedbull/pi-permissions

> 标签: guardrails, permissions, pi, pi-extension, pi-package, security

## 简介

Claude Code-style permission modes for pi. Controls approval for file writes, edits, and bash commands with four modes: default, acceptEdits, fullAuto, and bypassPermissions.
