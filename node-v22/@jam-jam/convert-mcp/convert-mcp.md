# @jam-jam/convert-mcp

> 标签: chord-chart, chord-detection, chord-sheet, chordpro, chords, claude, claude-code, claude-desktop, cursor, guitar, jam-jam, lyrics, mcp, mcp-server, midi, model-context-protocol, music, musicxml, piano, sheet-music, songbook, ukulele, vscode, windsurf

## 简介

Official MCP server for Jam Jam: turn audio, PDF, photos, links and text into chord sheets (ChordPro, PDF, MIDI, MusicXML) and manage your songbook from Claude, Cursor or VS Code.
