# @apiverve/passwordstrength

> 标签: check password strength, password strength api, password strength checker, password strength checker api, signup password check api

## 简介

Password Strength is a password strength checker API that scores how strong a password is. It returns a strength label and score, a breakdown of the character types used, weak-pattern detection, theoretical entropy in bits, and recommendations to improve
