# @apiverve/pdftotext

> 标签: convert pdf to text, extract text from pdf api, pdf parser api, pdf text extraction, pdf to text api

## 简介

PDF to Text extracts the text layer of a PDF, uploaded or fetched from a URL, and returns it as plain text with the page, word and character counts. Paid plans add the text of each page separately and the document metadata, such as title, author and creat
