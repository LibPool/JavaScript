# @apiverve/streetaddressparser

> 标签: address normalization api, address parser, address parsing api, parse street address, street address parser api

## 简介

Street Address Parser is an address parsing API that breaks raw US street addresses into structured location components. Pass any single-line address string to extract the building number, street name, street type, city, state abbreviation, and postal cod
