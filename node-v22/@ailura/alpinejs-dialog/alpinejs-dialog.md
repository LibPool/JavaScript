# @ailura/alpinejs-dialog

> 标签: accessibility, alpine, alpinejs, dialog, headless, plugin

## 简介

Alpine.js headless accessible dialog store — registry-keyed open/close, per-instance close rules, x-dialog binding and ARIA helpers on @ailura/alpinejs-core. No focus management, no scroll lock.
