# @crestable/schema

> 标签: JavaScript

## 简介

The contracts crestable is built on: the `User<Meta>` shape and runtime validation derived from a consumer-authored contract. Validation is built on rule lists over the guards in [`objectively`](https://www.npmjs.com/package/objectively) — everything else
