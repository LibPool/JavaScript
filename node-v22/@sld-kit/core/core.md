# @sld-kit/core

> 标签: diagram, electrical, headless, single-line-diagram, sld, svg

## 简介

Headless, framework-agnostic engine for single-line (electrical) diagrams: document model, grid layout, undo/redo commands, JSON serialization and PowerPoint-safe SVG export.
