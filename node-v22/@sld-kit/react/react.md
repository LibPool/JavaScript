# @sld-kit/react

> 标签: diagram, electrical, react, single-line-diagram, sld, svg

## 简介

React components for single-line (electrical) diagrams: a headless pan/zoom canvas, element views, and event-dispatching editor chrome built on @sld-kit/core.
