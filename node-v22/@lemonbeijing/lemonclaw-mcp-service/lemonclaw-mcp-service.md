# @lemonbeijing/lemonclaw-mcp-service

> 标签: JavaScript

## 简介

用于查询和操作柠檬云 Lemon Cloud 业务数据的 MCP 服务，覆盖云代账机构与客户、账套、进销存 SCM、业财 ERP、财务 ACC 和独立开票；支持代账客户业务进度及通用业务查询、报表、导出、开票和问题反馈。
