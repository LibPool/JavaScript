# atl-axi

> 标签: agent, atlassian, axi, cli, issue-tracker, jira, toon

## 简介

AXI-compliant Atlassian Jira Cloud CLI for agents - issues, JQL search, field edits (story points, sprint, parent), transitions, comments, links - with token-efficient TOON output
