# @ngote-technologies/shopeetory-contracts

> 标签: JavaScript

## 简介

Public, versioned wire contracts shared by ShopeeTory Core and POS Desktop. Only browser- and runtime-neutral schemas, DTOs, enums, and error shapes belong here. Publish tagged releases to the npm registry after Core and POS compatibility tests pass.
