# @sensejs/multipart-s3-adaptor

> 标签: JavaScript

## 简介

This package, `@sensejs/multipart-s3-adaptor`, provides an experimental S3 storage adaptor for `@sensejs/multipart`, based on the official AWS SDK v3 for Javascript.
