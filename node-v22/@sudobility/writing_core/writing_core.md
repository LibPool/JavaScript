# @sudobility/writing_core

> 标签: collaborative, fadewright, screenplay, screenwriting, yjs

## 简介

Headless, platform-free writing engine for screenplays, stage plays and manuscripts: collaborative document model (Yjs), templates, editing commands, SmartType and per-session undo
