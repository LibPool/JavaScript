# @just-ai/dsh-auto-update

> 标签: auto-update, deepseek-harness, dsh, plugin

## 简介

自动检测并更新 DeepSeek Harness（dsh）的插件：侧边栏显示当前版本，一键 npm install -g 更新并跨平台重启。
