# @getopentoken/sdk

> 标签: ai-gateway, bedrock, finops, llm, observability, opentelemetry

## 简介

Open Token SDK: fail-open routing to the Open Token gateway with direct Amazon Bedrock fallback, cost spans, shadow dry-runs and one-line OpenTelemetry auto-instrumentation.
