# dsh-wsl-projects

> 标签: deepseek-harness, dsh, dsh-plugin, windows, wsl, wsl2

## 简介

Run one DeepSeek Harness web server per project inside WSL2, managed from the Windows dsh app: each project gets its own service, port and dsh home.
