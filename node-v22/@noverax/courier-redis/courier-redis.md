# @noverax/courier-redis

> 标签: courier, presence, pubsub, realtime, redis, redis-streams, replicas, scaling, sse, type-safe, typescript, websocket

## 简介

Redis for Courier realtime: Pub/Sub that carries WebSocket channels across replicas, presence shared between them, and Streams that keep the events a reconnecting client resumes from
