# @noverax/courier-sveltekit

> 标签: api-client, bff, courier, form-actions, load, proxy, session, ssr, svelte, sveltekit, type-safe, typescript

## 简介

SvelteKit adapter for Courier: an endpoint that proxies typed calls to any backend, with the user's session in load functions and form actions
