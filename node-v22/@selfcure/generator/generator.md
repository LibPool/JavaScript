# @selfcure/generator

> 标签: JavaScript

## 简介

Legacy BYOK test generator for selfcure — sends component analysis to an LLM (Anthropic/OpenAI/Google/Groq/DeepSeek/Ollama) and returns Playwright test code. Optional fallback for teams without Playwright Test Agents; the headline flow is `selfcure lint`
