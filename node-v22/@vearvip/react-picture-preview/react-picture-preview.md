# @vearvip/react-picture-preview

> 标签: component, image preview, photo preview, picture preview, react, react component, 图片预览, 照片预览

## 简介

一个基于 React 和 rc-image 的图片预览组件，具备图片旋转、翻转、缩放和下载等功能。
