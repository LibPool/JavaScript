# knex

> 标签: SQL, 查询构建

## 简介

A batteries-included SQL query & schema builder for PostgresSQL, MySQL, CockroachDB, MSSQL and SQLite3

- 官网：https://knexjs.org/
- 源码仓库：git://github.com/knex/knex.git
