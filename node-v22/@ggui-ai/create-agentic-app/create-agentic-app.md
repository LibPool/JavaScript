# @ggui-ai/create-agentic-app

> 标签: agentic-app, create, ggui, scaffold

## 简介

Scaffold a ggui agentic app from one of the official templates (claude-agent-sdk, openai-agents-sdk, google-adk). One-time-use; meant to be invoked via `npx @ggui-ai/create-agentic-app`.
