# @wyfe/h5-bridge-sdk

> 标签: android, bridge, flutter, h5, ios, javascript-bridge, webview

## 简介

H5与App桥接SDK，支持iOS/Android原生和Flutter环境，基于WebViewJavascriptBridge、FlutterBridge和Flutter_inappwebview。
