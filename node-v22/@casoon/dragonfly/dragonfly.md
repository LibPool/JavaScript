> 标签: accessibility, astro, components, container-queries, css, css-layers, dark-mode, design-system, framework, icons, lightningcss, logical-properties, modern, modular-css, responsive, ssr, theming, ui, utility-classes

## 简介

Modular, lightweight CSS framework and design system for modern web projects. Optimized for Astro JS, LightningCSS and Container Queries with @layer-based architecture and comprehensive accessibility.
