# @staticflux/rspack-plugin

> 标签: client-side, framework, staticflux, typescript

## 简介

Rspack plugin: logical chunk naming, sf-manifest emission, per-profile preloads, SW precache list, Module Federation 2.0 remote mapping, budget report.
