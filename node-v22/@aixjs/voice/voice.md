# @aixjs/voice

> 标签: agents, ai, aix, framework, fullstack, llm, react, realtime, speech, typescript, voice

## 简介

AIX voice sessions: realtime speech-to-speech (OpenAI Realtime, Gemini Live) and a speech-to-text → agent → text-to-speech pipeline, with interruptions and captions.
