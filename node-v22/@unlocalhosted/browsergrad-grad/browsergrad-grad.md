# @unlocalhosted/browsergrad-grad

> 标签: autograd, browser, education, machine-learning, numpy, pyodide, tensor

## 简介

A small, readable tensor + autograd library that runs inside Pyodide. PyTorch-flavored API, NumPy-backed, designed to be educational source code. Not PyTorch — `import browsergrad_grad as grad`.
