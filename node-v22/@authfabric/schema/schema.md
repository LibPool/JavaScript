# @authfabric/schema

> 标签: auth, identity, mfa, multi-tenant, oauth, rbac, schema, user, validation

## 简介

Framework-agnostic user identity schema and validation. Covers the 80% of auth identity patterns: OAuth provider linking, multi-tenancy, RBAC, MFA, service accounts, and audit actors.
