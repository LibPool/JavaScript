# @routegraph/watcher

> 标签: JavaScript

## 简介

Chokidar-based file watcher that hot-reloads route files into a running RouteGraph.

## 官网

- 官网：https://routegraph.vercel.app
- 源码仓库：git+https://github.com/udaybhangare/routegraph.git
- npm 页面：https://www.npmjs.com/package/@routegraph/watcher
