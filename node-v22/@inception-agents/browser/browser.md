# @inception-agents/browser

> 标签: JavaScript

## 简介

Lightweight client-side beacon (&lt;5 KB) for tracking AI agent referral attribution. Detects when users arrive from AI platforms (ChatGPT, Perplexity, Claude, Gemini, Copilot, and more) and fires attribution events to the Inception Agents analytics API.
