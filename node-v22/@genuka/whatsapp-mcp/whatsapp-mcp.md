# @genuka/whatsapp-mcp

> 标签: ai-agents, claude, cursor, genuka, mcp, model-context-protocol, whatsapp, whatsapp-api, whatsapp-business-api, whatsapp-cloud-api

## 简介

MCP server for Genuka WA: lets Claude, Cursor, VS Code and other AI agents send WhatsApp messages, templates and campaigns through the official WhatsApp Business Platform (Cloud API).
