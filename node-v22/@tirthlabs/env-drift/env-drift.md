# @tirthlabs/env-drift

> 标签: ci, config, devops, django, docker-compose, dotenv, env, env-example, environment-variables, github-actions, kubernetes, linter, nextjs, secrets, vite

## 简介

Find environment variables that are missing, undocumented, unused or leaking to the browser, across code, .env files, Docker, docker compose, GitHub Actions and Kubernetes. Works in CI.
