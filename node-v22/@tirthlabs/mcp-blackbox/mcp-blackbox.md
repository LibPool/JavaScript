# @tirthlabs/mcp-blackbox

> 标签: ai-agents, claude, cursor, debugging, inspector, logging, mcp, mcp-server, model-context-protocol, observability, proxy, regression-testing, replay

## 简介

Flight recorder for MCP servers. Wrap any stdio server to log every call with secrets hidden, watch it live in a web viewer, and replay real sessions as regression tests in CI.
