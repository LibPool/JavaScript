# @ever-co/connect-sdk

> 标签: JavaScript

## 简介

Ever Platform connection SDK: the client over the generated operation table, the key manifest and entitlement verifier, the client assertion, lookup hashing, usage readings, the anonymous statistics signer and the managed-operation runner.
