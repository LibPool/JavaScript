# @nn12138/dsh-voice

> 标签: asr, deepseek-harness, dsh, mic, speech, voice

## 简介

Voice input plugin for DeepSeek Harness: microphone → local/browser speech recognition → text submitted as a normal chat message (input-only, preset-agnostic)
