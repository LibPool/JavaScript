# sourcepeek

> 标签: ai, angular, click-to-source, dev-tools, git, inspector, nextjs, react, svelte, vite, vue

## 简介

Click any UI element in dev mode to see its source file, line, component chain, props and git history. Alt+click opens your editor. Describe a change and the AI previews it or writes it into your code. React, Next.js, Vue, Svelte and Angular.
