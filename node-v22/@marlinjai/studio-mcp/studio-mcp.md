# @marlinjai/studio-mcp

> 标签: ai-agents, brand, character-consistency, image-generation, lumitra, mcp, model-context-protocol, video-generation

## 简介

Model Context Protocol (MCP) server over the Lumitra Studio HTTP API: generate images, mint characters, run workflows, swap characters into video.
