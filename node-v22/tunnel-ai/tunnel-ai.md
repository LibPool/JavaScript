# tunnel-ai

> 标签: agents, ai, claude-code, cli, codex, cursor, e2e, gemini-cli, opencode, tunnel

## 简介

Open an end-to-end encrypted tunnel between AI coding agents (Claude Code, Codex, Cursor, Gemini CLI, OpenCode) on different machines.
