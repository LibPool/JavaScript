# @middy/event-batch-handler

> 标签: AWS, AWS Lambda, Batch, DynamoDB, Firehose, Framework, Kafka, Kinesis, Lambda, Middleware, Middy, S3 Batch, SQS, Serverless

## 简介

Per-record handler wrapper for Lambda batch events. Auto-checkpoints under Durable Functions. Pairs with @middy/event-batch-response.
