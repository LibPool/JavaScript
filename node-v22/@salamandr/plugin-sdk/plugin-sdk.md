# @salamandr/plugin-sdk

> 标签: assemblyscript, extension, helpdesk, plugin, salamandr, webassembly

## 简介

Write Salamandr helpdesk extensions in TypeScript (AssemblyScript): typed wrappers for every host capability, the fetch_context wire contract, and a mock host that runs your compiled .wasm under the real ABI.
