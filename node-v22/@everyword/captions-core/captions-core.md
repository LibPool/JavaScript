# @everyword/captions-core

> 标签: amazon-transcribe, captions, karaoke, literacy, same-language-subtitling, subtitles, webvtt, word-timing

## 简介

The EveryWord caption format and engine: word-timed caption documents, a normalizer for Amazon Transcribe output (segmentation, clause-aware line breaks, gap tiling), and the pure word-index math that drives karaoke highlighting.
