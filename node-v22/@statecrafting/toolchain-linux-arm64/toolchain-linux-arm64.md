# @statecrafting/toolchain-linux-arm64

> 标签: JavaScript

## 简介

Encore toolchain native binaries for linux arm64: encore-runtime.node + tsparser-encore (encoredev/encore v1.57.9, MPL-2.0). Installed as an optional dependency of @statecrafting/toolchain on matching hosts.
