# @farohqbr/node

> 标签: ai, error-tracking, express, farohq, monitoring, nextjs, observability

## 简介

Envia os erros de aplicações Node.js (Express, Next.js, Fastify...) para o FaroHQ: análise de causa raiz lendo o seu código.
