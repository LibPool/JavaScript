# @xcelsior/demo-pipeline

> 标签: JavaScript

## 简介

Scaffold an automated demo-video pipeline (beat-locked capture of real UI -> Kokoro voice-over anchored to on-screen events -> Screen-Studio-style Remotion edit) into any repo. Driven by Claude via /demo-video.
