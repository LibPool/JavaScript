# @statorjs/stator

> 标签: framework, islands, server-canonical, sse, ssr, state-machine

## 简介

Server-canonical web framework: business logic in composable state machines, UI as a thin renderer binding machine outputs to DOM positions. Ships TypeScript source, loaded natively by its own toolchain — no build step.
