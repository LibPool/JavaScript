# @cap2ui5/cds-plugin

> 标签: abap2ui5, cap, cds, cds-plugin, fiori, sap, sapui5, server-driven-ui, ui5

## 简介

abap2UI5 for CAP: a cds-plugin that hosts the transpiled abap2UI5 runtime, keeps its drafts in a CDS entity and lets apps be written as plain JavaScript classes
