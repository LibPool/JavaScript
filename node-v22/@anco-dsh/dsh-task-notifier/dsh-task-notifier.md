# @anco-dsh/dsh-task-notifier

> 标签: JavaScript

## 简介

DSH 任务完成通知器：Agent 每轮完成、子代理结束、Workflow 跑完、目标完成、Agent 提问时发送系统通知（macOS osascript）。
