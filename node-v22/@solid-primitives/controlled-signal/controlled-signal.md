# @solid-primitives/controlled-signal

> 标签: controllable, controlled, headless, primitives, signal, solid, ui, uncontrolled

## 简介

Reactive signals that support both controlled (externally managed) and uncontrolled (internally managed) state — a pattern commonly used in headless UI components.
