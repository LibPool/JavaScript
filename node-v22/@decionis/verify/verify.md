# @decionis/verify

> 标签: agent-safe-intent, conformance, decionis, decision-dossier, ed25519, jwks, non-repudiation, signed-audit, verification

## 简介

Independently verify a Decionis Decision Dossier's Ed25519 proof bundle, and Agent-Safe Intent v1 conformance, offline, using only Node's built-in crypto. No Decionis account, SDK, or network dependency required.
