# @integratex/whatsappman

> 标签: baileys, claude, daemon, mcp, model-context-protocol, whatsapp

## 简介

MCP server + CLI to send WhatsApp messages (text, image, document, location, contact) from any Claude CLI session, via a Baileys-backed always-on local daemon — multi-number, draft/confirm, no third-party API, no server, no database. macOS, Linux, Windows
