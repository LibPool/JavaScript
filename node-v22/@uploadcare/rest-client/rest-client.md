# @uploadcare/rest-client

> 标签: api, browser, file, file-management, media-conversion, nodejs, pagination, rest, sdk, typescript, uploadcare, webhooks

## 简介

@uploadcare/rest-client is a JavaScript and TypeScript SDK for the Uploadcare REST API. Covers file management, groups, webhooks, media conversion (video and document), and add-ons (virus scanning, image recognition, background removal). Works in Node.js
