# @saltcorn/tui

> 标签: fieldview, markdown, plugin, saltcorn, toastui, wysiwyg

## 简介

WYSIWYG Markdown editor for Saltcorn string fields using TOAST UI Editor. Saves Markdown reliably (incl. soft-break -> hard-break fix).
