# @camposweb-ignite-ui/react

> 标签: JavaScript

## 简介

Este design system foi desenvolvido a partir do módulo de Design System da trilha de ReactJS da Rocketseat para ser utilizado posteriormente para a aplicação Ignite Call do módulo final do treinamento, isso possibilita que os componentes sejam utilizados
