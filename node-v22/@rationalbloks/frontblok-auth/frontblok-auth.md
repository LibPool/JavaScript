# @rationalbloks/frontblok-auth

> 标签: auth, frontend, jwt, rationalbloks, react, tokens

## 简介

Authentication for RationalBloks frontends - API client with JWT session and refresh, Google Sign-In, password reset, email verification, cross-tab sync, route protection
