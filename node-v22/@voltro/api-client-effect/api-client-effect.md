# @voltro/api-client-effect

> 标签: framework, typescript, voltro

## 简介

The Effect flavor of a generated TypeScript client for a Voltro public API (`voltro build api --target typescript`): `ApiClient` as a service over the same transport `@voltro/api-client` speaks — a call is an `Effect` whose error channel is the app's own
