# @voltro/sql-mssql

> 标签: framework, typescript, voltro

## 简介

SQL Server (mssql) dialect adapter for Voltro's cross-dialect DataStore (OUTPUT-clause returning, OFFSET/FETCH paging, inline reactivity).
