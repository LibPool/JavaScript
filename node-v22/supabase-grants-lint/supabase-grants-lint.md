# supabase-grants-lint

> 标签: cli, github-action, grants, linter, migrations, postgres, postgresql, rls, security, supabase

## 简介

Replays Supabase SQL migrations and flags tables the Data API cannot reach once auto-grants are gone (PostgREST 42501).
