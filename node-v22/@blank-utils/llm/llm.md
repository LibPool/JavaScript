# @blank-utils/llm

> 标签: ai, browser, chat, gpt, hooks, huggingface, inference, llm, local, react, streaming, transformers, webgpu, webllm

## 简介

Run LLMs directly in your browser with WebGPU acceleration. Supports React hooks and eager background loading.
