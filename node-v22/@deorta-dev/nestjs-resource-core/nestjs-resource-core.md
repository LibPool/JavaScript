# @deorta-dev/nestjs-resource-core

> 标签: JavaScript

## 简介

Library for NestJS that standardizes resource management in an API: full CRUD, configurable prefix permissions, authentication-based scope/workspace, filtering, dynamic reports, gateways, and more.
