# @bdbchgg/wingetjs

> 标签: cli-wrapper, package-manager, typescript, windows, winget

## 简介

A JavaScript/TypeScript wrapper library for the Windows Package Manager (winget) CLI. Search, install, list, upgrade, and manage packages programmatically.

- npm 页面：https://www.npmjs.com/package/@bdbchgg/wingetjs
