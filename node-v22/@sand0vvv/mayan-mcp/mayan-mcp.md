# @sand0vvv/mayan-mcp

> 标签: bridge, cross-chain, defi, mayan, mayan-finance, mcp, model-context-protocol, non-custodial, solana, swap, unsigned-transactions

## 简介

MCP server for Mayan Finance cross-chain swaps. Read-only and unsigned transaction building: never holds keys, never signs, never broadcasts.
