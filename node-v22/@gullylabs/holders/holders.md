# @gullylabs/holders

> 标签: bubblemaps, defi, embed, holder map, launchpad, react, token holders, wallet clusters

## 简介

Typed client for the Gully Labs Holder Map API, and a React component that frames the map: who holds a token and how the biggest wallets are connected.
