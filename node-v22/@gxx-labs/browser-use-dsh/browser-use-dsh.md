# @gxx-labs/browser-use-dsh

> 标签: browser, browser-use, deepseek-harness, dsh, dsh-plugin, webview

## 简介

DSH Desktop 可见协作/批注层：在内建右侧 Browser 中把 Agent 的观察、操作、批注与审批可视化；不是官方 Browser Use Provider 的替代。
