# @gxx-labs/agent-team-dsh

> 标签: agent-preset, agent-team, cordis, deepseek-harness, dsh, dsh-plugin, multi-agent, team

## 简介

DSH 插件：团队 —— 可保存复用的团队模板，成员可各自使用不同 Agent 预设（能力不同），在会话输入框选中后由队长调度协作并统一汇总。
