# @gxx-labs/edit-agents-md-dsh

> 标签: agents, agents-md, cordis, deepseek-harness, dsh, dsh-plugin, instructions, settings, system-prompt

## 简介

DSH 插件：设置 → 系统指令 —— 在线编辑 DSH 真正加载的用户全局指令 $DSH_HOME/AGENTS.md（注意：单数 AGENT.md 不会被加载）。保存固定使用插件自身的最高权限写入，不需要切换当前会话的权限模式；带 Markdown 预览、版本冲突保护（409 不覆盖），并提供「立即刷新」发起真实的第一方 read 调用，让改动即时生效。
