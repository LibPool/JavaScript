# @stephenspage/webcrypto-envelope

> 标签: aes-gcm, browser, e2ee, encryption, end-to-end-encryption, offline-first, pbkdf2, web-crypto-api, webcrypto, zero-knowledge

## 简介

Tiny typed wrapper over the Web Crypto API: PBKDF2 password keys and AES-256-GCM encrypt/decrypt in a compact iv:tag:ciphertext envelope — plus seal/open for zero-knowledge shareable payloads.
