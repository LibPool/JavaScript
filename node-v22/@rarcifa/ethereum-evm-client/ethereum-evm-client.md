# @rarcifa/ethereum-evm-client

> 标签: blockchain, erc20, erc721, ethereum, evm, javascript, typescript

## 简介

A typescript client library for interacting with the Ethereum EVM, facilitating operations on both ERC20 and ERC721 tokens.
