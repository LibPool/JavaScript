> 标签: ai-agents, claude-code, llm, observability, opentelemetry, otlp, tracing, visualization

## 简介

See what your AI agent actually did: an interactive timeline and call tree for Claude Code sessions and OpenTelemetry traces, in one self-contained HTML file.
