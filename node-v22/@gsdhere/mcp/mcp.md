# @gsdhere/mcp

> 标签: claude, documents, e-sign, esignature, gsd, mcp, model-context-protocol

## 简介

GSD e-signing MCP server (local/stdio): send envelopes from your templates, check status, download signed PDFs — with your own GSD API key.
