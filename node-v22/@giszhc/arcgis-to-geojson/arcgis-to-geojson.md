# @giszhc/arcgis-to-geojson

> 标签: ArcGIS, arcgisJSON, geoJSON

## 简介

一个轻量级的 ArcGIS JSON 与 GeoJSON 双向转换工具库，支持点、线、面等多种几何类型，开箱即用，并针对现代前端开发进行了 Tree Shaking 优化。
