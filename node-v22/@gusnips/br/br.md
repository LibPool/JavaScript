# @gusnips/br

> 标签: brazil, cep, cnpj, cpf, phone, typescript, validation

## 简介

Brazilian documents and phone numbers: CPF and CNPJ (the alphanumeric CNPJ too), phones, CEP. Check digits, display, input masks, CEP address lookup. Zero dependencies, no framework.
