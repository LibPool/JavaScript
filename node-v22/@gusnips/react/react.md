# @gusnips/react

> 标签: base-ui, headless, i18next, react, react-query, spa, vite, zustand

## 简介

The headless runtime under a Vite + React SPA: typed fetch client with single-flight refresh, auth store, query defaults, route guards, error boundary, stale-tab recovery, i18n bootstrap.
