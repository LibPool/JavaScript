# @gusnips/locale

> 标签: accept-language, date, hreflang, i18n, locale, prerender, timezone, typescript, url

## 简介

Where a language lives in a URL, how it crosses to another origin, which one a request asks for, what day it is in a time zone, and what currency a language pays in. Zero dependencies, no framework.
