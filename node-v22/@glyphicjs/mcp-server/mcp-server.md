# @glyphicjs/mcp-server

> 标签: ai-agents, claude, diagram-generator, diagrams, llm, mcp, mcp-server, mermaid-alternative, model-context-protocol, text-to-diagram

## 简介

MCP server for Glyphic — the model emits typed JSON, Glyphic renders it deterministically as SVG/PNG. No DSL, no headless browser, 18 diagram types for LLMs and agents.
