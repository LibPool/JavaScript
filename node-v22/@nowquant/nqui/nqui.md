# @nowquant/nqui

> 标签: charts, components, composer, dashboard, data-grid, finance, markdown, react, react-aria, sql-editor, tailwindcss, ui

## 简介

NQUI: an original Tailwind CSS v4 + React Aria component library for consoles, data warehouses, monitoring, and finance UI, with charts, a SQL editor, Markdown rendering, and a Tiptap composer as sub-entries.
