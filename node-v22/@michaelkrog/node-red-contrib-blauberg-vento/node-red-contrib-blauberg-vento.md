# @michaelkrog/node-red-contrib-blauberg-vento

> 标签: blauberg, duka

## 简介

This is a Javascript module with Typescript support for communicating with a Blauberg Vento (as OEMS like Duka One S6w). The Blauberg Vento is a one room ventilationsystem with a heat exchanger.
