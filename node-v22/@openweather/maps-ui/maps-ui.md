# @openweather/maps-ui

> 标签: maps, openweather, ui, weather

## 简介

Framework-free DOM renderer for the OpenWeather Maps SDK's designed UI controls — legend, layer rail, timeline, point-query popup, detail panel — built on @openweather/maps-ui-core's view-models
