# @hiogawa/vite-rsc

## 简介

This package provides [React Server Components](https://react.dev/reference/rsc/server-components) (RSC) support for Vite. Any feedback is welcome, please feel free to share an idea in [the discussion](https://github.com/hi-ogawa/vite-plugins/discussions/
