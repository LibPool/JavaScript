# @kerusiweb/core

> 标签: airline, booking, cinema, kerusi, seat-map, seat-picker, seat-selection, seatmap, ticketing, venue

## 简介

Framework-agnostic core for the Kerusi Seat Map & Availability Format: document types, a conformance validator, and the render model and geometry a seat-map renderer consumes.
