# @solvorx/sx-tool-web

> 标签: authentication, oauth, oidc, pkce, solvorx

## 简介

Integración de identidad de SolvorX para apps web: login, sesión persistente y logout contra sx-management-service. Cliente público (navegador) y cliente confidencial con backend propio (subpath ./server).
