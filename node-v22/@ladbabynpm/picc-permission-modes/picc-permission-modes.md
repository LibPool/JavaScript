# @ladbabynpm/picc-permission-modes

> 标签: claude-code, permission-modes, pi, pi-extension, pi-package, plan-mode

## 简介

Claude Code style permission modes (default, acceptEdits, plan, bypassPermissions, auto) and user-defined permission rules for the pi coding agent. A more faithful port of Claude Code's harness than pi-permission-modes.
