> 标签: claude-code, claude-code-shim, drop-in-replacement, hapi, ndjson, pi, pi-extension, pi-package, stream-json

## 简介

Drop-in replacement for Claude Code CLI. Speaks Claude Code's NDJSON protocol (--output-format stream-json / --input-format stream-json / --permission-prompt-tool stdio) so that third-party tools like hapi can drive pi instead of Claude Code. Internally c
