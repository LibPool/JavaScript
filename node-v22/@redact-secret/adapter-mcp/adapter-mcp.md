# @redact-secret/adapter-mcp

> 标签: JavaScript

## 简介

The supported MCP redaction boundary over the Redact Secret core: sanitize tool results, opt-in tool arguments, and streamed tool output before logging, persistence, or model context. A thin specialization of @redact-secret/adapter-ai-context.
