# @redact-secret/key-provider-aws-kms

> 标签: aws-kms, envelope-encryption, redaction, secrets, vault

## 简介

Optional AWS KMS key provider for the persistent Redact Secret vault: envelope data keys generated, unwrapped, and re-wrapped by a consumer-supplied KMS client.
