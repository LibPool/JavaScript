# @redact-secret/vault-conformance

> 标签: conformance, redaction, secrets, testing, vault

## 简介

Runner-agnostic conformance harnesses for persistent Redact Secret vault Store and KeyProvider implementations, with a transaction oracle, fault injection, and an insecure deterministic test key provider.
