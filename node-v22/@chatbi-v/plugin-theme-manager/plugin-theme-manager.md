# @chatbi-v/plugin-theme-manager

> 标签: JavaScript

## 简介

Theme Plugin 是 ChatBI 系统的核心插件之一，负责管理应用程序的全局主题、配色方案以及布局设置。它允许用户在不同的视觉风格之间无缝切换，并支持亮色/暗色模式的自动适配。
