# @niche-works/react-defer-rendering

> 标签: layout, react, style

## 简介

`@niche-works/react-defer-rendering` is a niche library specialized in deferring the rendering of components until a specified condition is met.\ It provides a set of hooks covering a wide range of conditions, including timers, Promises, and browser APIs
