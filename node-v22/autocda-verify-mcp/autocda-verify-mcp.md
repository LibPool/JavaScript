# autocda-verify-mcp

> 标签: ai-agent, analog, circuit, claude, eda, mcp, model-context-protocol, ngspice, spice, verification

## 简介

The SPICE-verified truth layer for analog circuit design — an MCP server (and HTTP API) that turns a plain-English intent into a real-ngspice-verified, buyable circuit. Lets an AI agent verify component values instead of hallucinating them.
