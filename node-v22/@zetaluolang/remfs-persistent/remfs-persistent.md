# @zetaluolang/remfs-persistent

> 标签: cordis, deepseek-harness, dsh, file-manager, phone, remote, tailscale, workspace

## 简介

Persistent phone remote workbench for DeepSeek Harness: start sessions / manage workspaces and browse, preview, edit, download, upload PC files from your phone over a trusted RPC channel. One-click Tailscale deploy + install guide in the GitHub repo.
