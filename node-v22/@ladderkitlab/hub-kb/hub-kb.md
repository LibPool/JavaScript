# @ladderkitlab/hub-kb

> 标签: JavaScript

## 简介

npm 包，给支持本地（stdio）MCP 服务器的 AI 助手接入 hub 知识库用——**只作后备**：能用远程 MCP 时优先用远程，本地方式是发布时打进包里的一份内容快照，见下面「局限」。
