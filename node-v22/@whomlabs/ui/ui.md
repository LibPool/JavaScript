# @whomlabs/ui

> 标签: JavaScript

## 简介

Este é o projeto inicial da biblioteca de componentes do **Whom**, desenvolvido para fornecer um conjunto padronizado de elementos de interface e acelerar o desenvolvimento de aplicações.
