# @tuxxin/webfetch

> 标签: bing, crawler, extraction, headless, scraper, scraping, scrapingbee, search-api, serp, webfetch, yahoo

## 简介

Official JavaScript client for the webfetch.io scraping API. Fetch any URL as HTML, text, markdown or structured JSON, and get ranked search results as JSON.
