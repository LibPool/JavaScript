# @satyadip28/asciitosvg

> 标签: ascii, ascii-art, box-drawing, diagram, llm, mcp, pyodide, svg, unicode, wasm

## 简介

Render ASCII and Unicode box diagrams as clean SVG, every character in its exact cell, with a 1:1 self-check. The ascii2svg Python library running in WebAssembly.
