# @workonward/reach-js

> 标签: email, reach, sdk, transactional-email, workonward, workonwardsend

## 简介

Official JavaScript/TypeScript SDK for WorkOnward Reach (https://send.gitdate.ink) — send emails, manage contacts, contact books, campaigns, and domains, and verify webhooks. Defaults to the send.gitdate.ink instance.
