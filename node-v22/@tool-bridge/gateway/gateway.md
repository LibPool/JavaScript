# @tool-bridge/gateway

> 标签: agent-tools, cloudflare-workers, htbp, mcp, tool-bridge

## 简介

Cloudflare Workers host adapter for tool-bridge: binds D1 / R2 / Durable Objects / Static Assets to the host-neutral @tool-bridge/app, and default-exports the Worker plus the DeviceSession Durable Object
