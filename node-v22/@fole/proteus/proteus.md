# @fole/proteus

> 标签: agent, agents, ai, anthropic, claude, framework, llm, openai, orchestration, router, streaming, tool-use

## 简介

Provider-agnostic LLM agent framework. One LLMProvider interface, two adapters (Anthropic + OpenAI-compatible), tool loop, router/specialist orchestration, streaming, confirmation gate, typed errors, retry, channels. Zero runtime dependencies.
