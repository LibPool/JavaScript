# @mounaji_npm/blog-discussion

> 标签: blog, comments, moderation, mounaji, nextjs, postgres, reactions

## 简介

Comentarios moderados y reacciones (👍/👎) para los blogs del workspace, sin login: migraciones SQL para Postgres, núcleo de servidor sin framework, adaptador para route handlers de Next y componentes React que heredan los tokens del sitio.
