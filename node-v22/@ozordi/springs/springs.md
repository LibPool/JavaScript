# @ozordi/springs

> 标签: animation, plugin, springs

## 简介

Springs is a physically based animation system for the web. It uses custom attributes to instantiate animations and apply them to the elements. It offers control over animation parameters like duration, bounce, stiffness, damping, and mass.
