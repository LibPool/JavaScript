# @flexito360/knowledge-sdk

> 标签: ai, api-client, flexipedia, flexito, kb, knowledge-base, roadmap, sdk, search, streaming, tickets, typescript

## 简介

Official TypeScript SDK for the FlexiPedia knowledge base API. Covers every public /api/v1/* endpoint with type-safe resource namespaces, retries, pagination iterators, SSE streaming, and observability hooks.
