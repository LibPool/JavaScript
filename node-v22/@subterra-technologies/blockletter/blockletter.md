# @subterra-technologies/blockletter

> 标签: blocks, email, email-builder, html-email, json-schema, newsletter

## 简介

Blockletter core: a typed newsletter document model and an email-safe HTML + plain-text renderer. Zero dependencies; runs in the browser, Node, edge runtimes and Convex.
