# opencode-task-complete

> 标签: completion, opencode, opencode-plugin, stall, task-complete, task_complete, watcher

## 简介

OpenCode V2 plugin: the task_complete tool - the model's explicit 'I am finished' signal, with the v1 todo gate and ack self-loop guard, observable by any plugin.
