# @forjio/agent-ui

> 标签: agent, catentio, chat, crud-sheet, forjio

## 简介

The embedded catentio agent surfaces for the Forjio family: the agentic CRUD sheet (Agentic + Manual tabs), the docked chat composer, and the adapter seams that let each product route transport through its own BFF.
