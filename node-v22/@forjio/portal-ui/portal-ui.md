# @forjio/portal-ui

> 标签: dashboard, forjio, portal, sidebar, ui, workspace

## 简介

Shared portal chrome (sidebar, workspace switcher, profile dropdown, portal shell) for the Forjio family of SaaS products. Mirrors @forjio/website-ui but for the authenticated dashboard side.
