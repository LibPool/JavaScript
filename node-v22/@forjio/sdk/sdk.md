# @forjio/sdk

> 标签: arn, forjio, iam, jwt, oidc, outbox, sdk

## 简介

Shared SDK for the Forjio commerce suite. JWT middleware, ARN parser, event envelope, outbox helpers, HTTP envelope types, OIDC device-flow auth, multi-profile session store, typed API client.
