# browserlessapi

> 标签: ai agents, captcha, cli, cloudflare, headless browser, markdown, mcp, scraper, web scraping

## 简介

BrowserlessAPI command-line tool: scrape any page to Markdown, take screenshots, run browser steps, solve captchas, and connect BrowserlessAPI to Claude, ChatGPT, Cursor and other AI apps over MCP.

- 官网：https://browserlessapi.com/
