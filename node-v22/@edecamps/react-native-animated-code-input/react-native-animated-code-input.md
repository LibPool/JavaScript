# @edecamps/react-native-animated-code-input

> 标签: android, animated, code-input, ios, one-time code, pin-code, pin-code-input, react, react-component, react-native, react-native-component, react-native-web

## 简介

Animated code input component for React Native, with support for iOS, Android, and React Native Web. It works with one-time code autofill on iOS and Android.
