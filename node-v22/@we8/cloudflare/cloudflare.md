# @we8/cloudflare

> 标签: cloudflare, cloudflare-workers, cms, d1, r2, we8, wrangler

## 简介

The Cloudflare pack for we8: the wrangler config generator, the first-boot doctor, the migrations runner, and the Cloudflare Email Service sender.
