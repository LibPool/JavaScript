# @lingui/vite-plugin

> 标签: i18n, icu-messageformat, internationalization, lingui, linguijs, localization, message-catalog, translation, vite, vite-plugin

## 简介

Vite plugin that compiles Lingui message catalogs on the fly, so .po files can be imported directly

- 源码仓库：git+https://github.com/lingui/js-lingui.git
