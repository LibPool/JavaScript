# dsh-weekly-report

> 标签: cordis, daily-report, deepseek-harness, dsh, dsh-plugin, git, markdown, plugin, report, weekly-report

## 简介

按时间段挑选 DSH 会话与项目 git 提交，参考你自己以前写的报告样例，生成日报/周报/月报（Markdown）。Pick DSH sessions and git commits for a window, then write a daily/weekly/monthly report in your own house style.
