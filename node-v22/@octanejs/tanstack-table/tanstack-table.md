# @octanejs/tanstack-table

> 标签: JavaScript

## 简介

TanStack Table v9 bindings for the octane renderer — reuses the framework-agnostic @tanstack/table-core (atom-based reactivity, tree-shakeable features) and ports the adapter (useTable, Subscribe, FlexRender, createTableHook) onto octane.
