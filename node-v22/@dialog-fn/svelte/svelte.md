# @dialog-fn/svelte

> 标签: async, await, confirm, confirmation, dialog, drawer, headless, imperative, modal, popup, promise, prompt, svelte, sveltekit, toast, unstyled

## 简介

Promise-based dialogs for Svelte — open a dialog and await the result. Headless, unstyled, zero dependencies, no providers.
