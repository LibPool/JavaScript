# @hikae/opencode-auto-continue

> 标签: auto-continue, error-recovery, opencode, plugin

## 简介

OpenCode V2 plugin that auto-sends "continue" when transient errors occur. Port of developing-today/opencode-auto-continue to the V2 plugin API.
