# @tarhnama/docx

> 标签: docx, editor, markdown, outline, persian, prosemirror, rtl

## 简介

Microsoft Word interop: direct OOXML import with effective-outline-level resolution, and export honouring Word's complex-script formatting slots. Runs in Node with no DOM.
