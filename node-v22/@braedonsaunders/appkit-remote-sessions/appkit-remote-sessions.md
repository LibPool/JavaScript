# @braedonsaunders/appkit-remote-sessions

> 标签: agents, appkit, rdp, remote-desktop, ssh, terminal, vnc, winrm

## 简介

Provider-neutral remote computer and terminal sessions with fenced leases, one-time viewer grants, append-only events, observable control, and executable provider conformance.
