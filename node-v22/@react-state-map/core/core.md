# @react-state-map/core

> 标签: ast, component-analysis, context, graph, prop-drilling, react, redux, state, state-management, static-analysis, typescript, zustand

## 简介

Static analysis engine for React state flow visualization — parses components, detects prop drilling, context boundaries, and state patterns (useState, Redux, Zustand)
