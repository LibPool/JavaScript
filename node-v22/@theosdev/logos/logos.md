# @theosdev/logos

> 标签: ios, iphone, jailbreak, language, mac, objc

## 简介

Logos is a Perl regex-based preprocessor that simplifies the boilerplate code needed to create hooks for Objective-C methods and C functions with an elegant Objective-C-like syntax.
