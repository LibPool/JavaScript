# @dignetwork/dig-sdk

> 标签: chia, chip-0002, chip-0035, content, datalayer, decentralized, dig, dig-network, sage, wallet, walletconnect

## 简介

The typed front door for building dapps on the DIG Network: a Chia wallet abstraction (ChiaProvider) plus DigClient read-crypto (verify + decrypt content by URN) and the canonical CHIP-0035 spend builder. ESM + CJS + .d.ts, browser + Node 18+.
