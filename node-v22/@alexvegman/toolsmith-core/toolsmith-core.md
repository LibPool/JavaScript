# @alexvegman/toolsmith-core

> 标签: JavaScript

## 简介

Canonical IR types (ToolSpec, ToolSurface, Finding) for Toolsmith, a tool-surface linter for LLM agent tool definitions — see @alexvegman/toolsmith-engine.
