# @intermezzo-chess/chessground-react

> 标签: chess, chess-board, chess.js, chessground, lichess, react, react-component, typescript

## 简介

A strongly-typed, idiomatic React wrapper for lichess.org's chessground chess board, with an optional chess.js integration.
