# @aionui/officecli-sdk

> 标签: docx, excel, office, officecli, ooxml, powerpoint, pptx, sdk, word, xlsx

## 简介

Node.js SDK for officecli — a thin async client over the officecli resident pipe (read/write .docx/.xlsx/.pptx).
