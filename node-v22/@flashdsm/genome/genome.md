# @flashdsm/genome

> 标签: claude, cursor, design-system, design-tokens, flash-ds, genome, mcp, model-context-protocol

## 简介

Flash Genome - the local MCP server for a Flash design system: give Cursor, Claude and any MCP client your real tokens, component specs and token linting over stdio, and keep the repo in sync with Flash Web
