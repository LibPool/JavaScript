# @rozenite/lynx

> 标签: bundler, devtools, lynx, plugin, rozenite, rspeedy

## 简介

Rozenite for Lynx: the device-side runtime, plus an rspeedy/Rsbuild plugin (`@rozenite/lynx/rspeedy`) that wires it in automatically.
