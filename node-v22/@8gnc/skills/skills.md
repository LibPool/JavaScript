# @8gnc/skills

> 标签: 8gnc, brand-strategy, branded-mayhem, claude, claude-code, codex, cursor, marketing, plugins, seo, skills

## 简介

8gnc — install the free, MIT-licensed Branded Mayhem skill plugins (brand strategy, product strategy, content, SEO, conversion, sales) into Claude Code, Codex or Cursor. `npx 8gnc` lists the catalog; `npx 8gnc add <plugin>` installs it.
