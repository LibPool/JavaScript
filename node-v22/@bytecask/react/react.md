# @bytecask/react

> 标签: blob-storage, blob-store, browser-storage, bytecask, content-addressed-storage, file-upload, indexeddb, offline-first, opfs, react, react-hooks, typescript

## 简介

React bindings for bytecask — BytecaskProvider plus usePutBlob/useBlob/useStorageEstimate hooks over the content-addressed blob store.
