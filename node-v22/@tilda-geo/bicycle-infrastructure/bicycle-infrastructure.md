# @tilda-geo/bicycle-infrastructure

> 标签: bicycle, bicycle-infrastructure, cycling, openstreetmap, osm, tilda

## 简介

TypeScript port of TILDA's LUA bicycle-infrastructure processing (category + surface/protection/oneway derivations). Runs on plain OSM tag objects (e.g. live Overpass data).
