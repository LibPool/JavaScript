# @jobo-ai/connector-core

> 标签: ats, connector, job-search, jobo, jobs

## 简介

Shared client for Jobo marketplace connectors. Zero runtime dependencies, required injectable transport and sleep (no bundled timers) — designed to be bundled at build time, never depended on at runtime.
