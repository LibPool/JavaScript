# @nfinitmonkeys/clan-engine

> 标签: clan, claude-code, jungle, mcp, nfinitmonkeys

## 简介

Deterministic setup engine for Nfinit Monkeys clans — the single template + reconciliation authority behind the published CLIs and the internal fleet tooling. Idempotent, dry-run-by-default, non-destructive.
