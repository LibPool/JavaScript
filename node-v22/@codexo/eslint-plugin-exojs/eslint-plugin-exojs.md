# @codexo/eslint-plugin-exojs

> 标签: eslint, eslint-plugin, eslintplugin, exojs, gamedev, lint, typescript

## 简介

ESLint rules for ExoJS projects: lifecycle hooks the frame loop calls synchronously, render pass and filter contracts, teardown chaining, never-registered systems, and deprecated engine imports.
