# @aparte/plugin-approval

> 标签: agent, aparte, approval, human-in-the-loop, plugin, tool, web-components

## 简介

Approval modes for aparté tool calls — plan, ask, auto-edit, auto — from a classification of your tool names, with a switch for the composer's toolbar.
