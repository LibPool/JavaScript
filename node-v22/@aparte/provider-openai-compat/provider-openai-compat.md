# @aparte/provider-openai-compat

> 标签: ai, chat-completions, llm, lmstudio, ollama, openai, openai-compatible, provider

## 简介

One OpenAI-compatible chat-completions adapter for any /v1 endpoint — OpenAI, Mistral, OpenRouter, Z.ai, Groq, LM Studio, Ollama and friends, via presets or plain config.
