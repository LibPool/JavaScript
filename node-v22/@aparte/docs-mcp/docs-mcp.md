# @aparte/docs-mcp

> 标签: ai, aparte, chat, documentation, llms-txt, mcp, model-context-protocol

## 简介

The aparté documentation as an MCP server — a coding agent searches the guides, reads a page or a whole topic (tools & approval, bring your own loop, theming & the UI kit…), always the version that ships, straight from apartejs.dev.
