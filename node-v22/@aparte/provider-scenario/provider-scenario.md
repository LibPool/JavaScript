# @aparte/provider-scenario

> 标签: ai, aparte, chat, demo, llm, mock, provider, scenario, testing

## 简介

A scripted model for aparté — replays turns you wrote (text at a typing pace, thinking, tool calls, errors) so demos, docs and your own tests stream real-looking conversations with no key and no network.
