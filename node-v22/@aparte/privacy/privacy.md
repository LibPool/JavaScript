# @aparte/privacy

> 标签: anonymization, aparte, gdpr, names, on-device, personal-data, pii, privacy, redaction

## 简介

Finds personal data in text (names, addresses, emails, phone numbers, URLs, dates, account numbers) with a 196 KB model, in the browser or Node, no API call
