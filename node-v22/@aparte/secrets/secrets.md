# @aparte/secrets

> 标签: aparte, api-key, browser, credentials, llm, masking, offline, password, privacy, redaction, secret-detection, secrets, security, tiny-model, token

## 简介

Finds passwords, API keys, tokens and private keys in text: a 196 KB model bundled, in the browser or Node, no API call, no dependency
