# tsc-after

> 标签: build, clean, dist, orphan, outDir, stale, tsc, typescript, watch

## 简介

Remove stale build output that tsc leaves behind when you delete or rename source files. Tsconfig-aware: just run tsc && tsc-after. 🧹
