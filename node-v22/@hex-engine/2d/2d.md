# @hex-engine/2d

> 标签: JavaScript

## 简介

This package expands on [`@hex-engine/core`](http://npm.im/@hex-engine/core) to provide primitives for making a 2D game in [Hex Engine](https://github.com/suchipi/hex-engine).
