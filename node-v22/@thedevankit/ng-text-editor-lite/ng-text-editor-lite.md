# @thedevankit/ng-text-editor-lite

> 标签: angular, angular18, contenteditable, dompurify, editor, markdown, reactive-forms, rich-text, sanitization, standalone, text-editor, wysiwyg

## 简介

Lightweight Angular 18+ WYSIWYG rich text editor with markdown-aware paste, CSS isolation, DOMPurify sanitization, and full Reactive Forms support. No ProseMirror, no Quill, no TipTap.
