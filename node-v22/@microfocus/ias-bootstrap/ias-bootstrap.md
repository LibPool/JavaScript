# @microfocus/ias-bootstrap

> 标签: JavaScript

## 简介

Provides a stylesheet for use with [UX Aspects](https://uxaspects.github.io/UXAspects/), the official CSS/JS framework for Micro Focus Identity, Access, and Security (IAS) products. UX Aspects is based on [Bootstrap](https://getbootstrap.com/docs/3.3/
