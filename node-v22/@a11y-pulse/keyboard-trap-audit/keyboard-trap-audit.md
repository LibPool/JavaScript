# @a11y-pulse/keyboard-trap-audit

> 标签: a11y, accessibility, audit, keyboard-trap, no-keyboard-trap, playwright, puppeteer, wcag

## 简介

WCAG 2.1.2 No Keyboard Trap audit that tabs through a page, detects focus cycling within part of it, and tries the standard keyboard exits before reporting a trap.
