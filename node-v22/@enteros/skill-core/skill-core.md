# @enteros/skill-core

> 标签: agent, enteros, mcp, molecule, skill, skill-framework

## 简介

Core runtime for authoring EnterOS skills: define a skill module, its config slice, and conformance rules, then compose and load skill families with reserved-name and write-discipline guards enforced from the contract SSOT.
