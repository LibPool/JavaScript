# @geekybones/canvas-kit

> 标签: canvas, canvas-kit, design-tool, graphics, pixi, pixijs, text-effects, typescript, vector, webgl, webgpu

## 简介

CanvasKit — a modular canvas runtime built on PixiJS v8. Compose only the features you need — elements, history, camera, snap, alignment, serialization, and more.
