# ruang-kerja-bridge

> 标签: bridge, mysql, postgresql, ruang-kerja

## 简介

Bridge lokal agar aplikasi web Ruang Kerja bisa membuka MySQL / PostgreSQL dari browser tanpa mengirim password ke server.
