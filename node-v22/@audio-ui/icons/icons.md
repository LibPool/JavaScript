# @audio-ui/icons

> 标签: audio, audio-ui, daw, framework-agnostic, icons, music, react, svg

## 简介

Icons for audio interfaces: a knob, a fader, a rack unit, the shape of a filter. One thin stroke on a 24 grid, in four weights, as data and SVG for any framework, and as React components.
