# @big_blue_dragon/nest-prisma-crud-kit

> 标签: nestjs

## 简介

Efficiently build robust NestJS applications with pre-built Prisma integration and ready-to-use CRUD services. This package provides a base module and service layer that simplifies processing development through common database interaction.
