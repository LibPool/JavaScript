# @goalapi/sdk

> 标签: api-client, fixtures, football, goal-api, live-scores, sdk, soccer, sports-data, standings

## 简介

JavaScript and TypeScript SDK for the GOAL API: football fixtures, live scores, standings, stats and live WebSocket updates.
