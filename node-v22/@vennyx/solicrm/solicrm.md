# @vennyx/solicrm

> 标签: api, crm, sdk, solicrm, typescript

## 简介

Official TypeScript SDK for the SoliCRM API — typed access to contacts, companies, deals, pipelines, activities, tasks, notes, saved views and cross-resource search.
