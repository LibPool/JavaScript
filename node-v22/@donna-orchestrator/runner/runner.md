# @donna-orchestrator/runner

> 标签: agent, ci, claude, donna, donna-orchestrator, runner

## 简介

Native macOS/Linux/Windows runner for the Donna orchestrator. Connects a developer machine to a Donna server and executes spec/plan/implement/verify/review stages locally.
