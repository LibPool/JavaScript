# reborn-tinyfish

> 标签: claude, claude-code, korean, mcp, skill, tinyfish, web-agent

## 简介

AI 에이전트용 웹 인프라 TinyFish(tinyfish.ai)를 클로드 코드에 연결하는 법을 한국어 안내 스킬로 넣어 줍니다. 옵션으로 공식 MCP 연결 명령도 대신 돌립니다. 본체는 제작사의 것이며 대신 만들지 않습니다.
