# @meshrouter/sdk

> 标签: ai, anthropic, bedrock, claude, llm, mesh, meshrouter, openai, router, usdc

## 简介

Official TypeScript SDK for MESH Router (api.meshrouter.app) — one OpenAI-compatible endpoint across 45 models from 14 providers, with USDC payments and signed receipts.
