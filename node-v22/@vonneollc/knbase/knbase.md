# @vonneollc/knbase

> 标签: agent, ai, cursor, governance, mcp, memory, model-context-protocol

## 简介

Agent-agnostic AI project governance and memory system. Forces AI agents to read governance docs before acting, bootstraps them if missing, forces updates after each task, and maintains a combined mind map and activity log.
