# dsh-runner-watcher

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, github-actions, observability, performance, runner, self-hosted-runner

## 简介

DSH plugin: observe self-hosted GitHub Actions runners — import them yourself or let auto-discovery link them, then score reliability/speed/efficiency/stability (RPS) and chart the trend.
