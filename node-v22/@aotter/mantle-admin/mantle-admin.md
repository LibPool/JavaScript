> 标签: admin, admin-dashboard, admin-panel, agent-native, mantle, mcp, mcp-apps, model-context-protocol, react, typescript, vite

## 简介

Native Admin console for Mantle apps: React admin app and build, same-origin preview and Admin MCP App. Uses @aotter/mantle as a peer.
