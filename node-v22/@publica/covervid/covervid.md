# @publica/covervid

> 标签: JavaScript

## 简介

CoverVid ======== At the core of CoverVid, is the idea of this little CSS snippet being possible... ```css .selector {     background-video: url('../foo/bar.mp4 || ../foo/bar.webm');     background-size: cover;     background-position: center center; } ``
