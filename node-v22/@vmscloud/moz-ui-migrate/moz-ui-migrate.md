# @vmscloud/moz-ui-migrate

> 标签: JavaScript

## 简介

custom-ui 레포를 레거시 moz-ui 패키지(GitHub Packages, Wijmo)에서 신규 public npm 패키지(moz-ui-components-vue·moz-ui-grid-vue·moz-ui-chart-vue)로 전환하는 CLI와 AI 에이전트 스킬
