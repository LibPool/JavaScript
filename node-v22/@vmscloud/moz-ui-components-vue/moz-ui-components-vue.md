# @vmscloud/moz-ui-components-vue

> 标签: JavaScript

## 简介

Vue 3 wrapper over @vmscloud/moz-ui-components-core (headless lit-html). One shared bridge (defineMozComponent) + one-line-per-component. During migration this is the -vue package; at cutover it may publish as @vmscloud/moz-ui-components for zero consumer
