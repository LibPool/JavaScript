# @evlog/telemetry

> 标签: citty, cli, consent, do-not-track, evlog, github-actions, privacy, structured-logging, telemetry, wide-events

## 简介

Wide-event telemetry for CLIs and automation — evlog's one-event-per-run model for tools on user machines, with privacy-safe flags, consent, outbox, and auto disclosure
