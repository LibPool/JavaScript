# @qkix/better-blocks-core

> 标签: better-blocks, blocks, cms, headless-cms, strapi, strapi-v5, types

## 简介

Framework-independent core for Strapi v5 Better Blocks content - the document types every renderer shares, plus the attribute mapping they all apply
