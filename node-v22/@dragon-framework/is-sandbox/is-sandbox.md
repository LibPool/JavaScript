# @dragon-framework/is-sandbox

> 标签: JavaScript

## 简介

L5 Container Runtime ABB 的执行侧（M14 计划 S2 轨）：一个 `SandboxExecutionBackend` SPI、 三层实现（进程内策略 / 子进程 rlimit / 容器短命实例）、装配期可用性降级链（③→②→①， fail-closed），以及 T8 资源封顶（CPU/内存）到各后端的接线与结构化超限事实。
