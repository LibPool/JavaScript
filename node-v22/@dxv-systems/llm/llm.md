# @dxv-systems/llm

> 标签: anthropic, claude, dxv, llm, openrouter

## 简介

Provider-agnostic one-shot LLM calls for DXV apps — Anthropic and OpenRouter adapters behind a single port, with documents, JSON-schema output, reasoning effort and transport retry.
