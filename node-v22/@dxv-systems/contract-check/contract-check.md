# @dxv-systems/contract-check

> 标签: cli, conventions, dxv, lint

## 简介

Asserts that a DXV app repo meets the DXV contract (CLAUDE.md block, dev/check/test/lint scripts, self-reloading dev, db:migrate/db:seed, seed guard, .dxv/preview.json). Zero runtime dependencies.
