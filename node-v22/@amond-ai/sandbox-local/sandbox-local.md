# @amond-ai/sandbox-local

> 标签: agent, claude-code, desktop, local, provider, sandbox

## 简介

A local-process backend for @amond-ai/sandbox — runs the command on this machine and journals it to disk, so a desktop app that was killed and relaunched can still find the turn it started
