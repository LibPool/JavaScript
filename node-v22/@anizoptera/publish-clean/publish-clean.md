# @anizoptera/publish-clean

> 标签: bun, cleanup, exports, monorepo, npm, pack, package, package.json, pnpm, provenance, publish, supply-chain, workspace

## 简介

Cleans and helps to publish npm packages properly with a clean package.json (no unnecessary entries), verified exports, checks for unwanted files, unresolved workspace dependencies and missing entry points.
