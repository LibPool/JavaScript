# @webstorio/cli

> 标签: automation, cli, command-line, deploy, preview, react, site builder, ssg, static sites, web development, website hosting, webstorio

## 简介

Webstorio CLI — author sites as multi-file local projects, preview with `webstorio dev`, and `webstorio push` to a Webstorio project.
