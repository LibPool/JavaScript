# @freshost/ui

> 标签: JavaScript

## 简介

Freshost design system — wraps PatternFly v6 (owns it as a dependency), re-exports its components/icons, and ships the Freshost brand theming as one stylesheet. Consuming apps depend only on @freshost/ui.
