# @essrt/physics

> 标签: astronomy, deep-time, eclipse, essrt, geocentric-model, precession, solar-system

## 简介

ESSRT (Expanding Solar System Resonance Theory) physics core — pure, injectable-constants, no I/O, no globals, no DOM. The complete model incl. fitted coefficients; every published version immutably ships one recorded model identity.
