# @adatechnology/game-interactables

> 标签: containers, furniture, game, interaction, loot, plumbing, power, three

## 简介

Renderer-agnostic runtime for interactive world objects: movable parts, containers with pickable items, power grid, fuel, logical plumbing, seats, soft volumes, effects, mirrors and damage.
