# @adatechnology/game-shapes

> 标签: 3d, game, geometry, json, low-poly, procedural, worker

## 简介

Renderer-agnostic 3D shape generator: a JSON shape schema (primitives, extrusions, lathes, cheap booleans, transforms, groups, named parts, materials by id, LOD rules, instancing hints) in, typed-array buffers per material out. Pure, deterministic by seed
