# @adatechnology/game-test-room

> 标签: destruction, devtools, game, playtest, test-room, three, threejs, weapons

## 简介

Reusable test room for three.js: any module loads its objects, then the player grabs, carries and throws them, shoots them with the weapons of @adatechnology/game-weapons, hits, burns, melts and takes them apart, with a behaviour log that can be exported
