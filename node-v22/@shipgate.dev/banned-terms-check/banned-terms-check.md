# @shipgate.dev/banned-terms-check

> 标签: JavaScript

## 简介

Scan ShipGate user-facing surfaces for banned IntentOps terms (VibeCheck, TruthPack, Prompt Builder, etc.). Fails CI when a banned term sneaks back into primary UX.
