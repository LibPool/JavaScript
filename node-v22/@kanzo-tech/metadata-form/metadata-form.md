# @kanzo-tech/metadata-form

> 标签: dcat, form, health-dcat-ap, json-ld, metadata, rdf, react, rudof, shacl, shacl-ui, turtle, wasm

## 简介

Auto-generate editable React forms from SHACL shapes, powered by the rudof engine (WebAssembly). Edit an RDF graph and serialize to Turtle and JSON-LD.
