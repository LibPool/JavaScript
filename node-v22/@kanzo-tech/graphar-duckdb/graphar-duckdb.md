# @kanzo-tech/graphar-duckdb

> 标签: duckdb, graph, graphar, parquet, property-graph

## 简介

An Apache GraphAr graph attached to a DuckDB engine: its YAML read through the engine, a view per vertex and edge type over the Parquet chunks, and the graph's metadata as four relations. TypeScript only: no WASM, no engine of its own.
