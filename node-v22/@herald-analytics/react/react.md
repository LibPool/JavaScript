# @herald-analytics/react

> 标签: analytics, expo-router, hooks, react, react-native, react-navigation

## 简介

Track Herald events from React Native screens and lists, with React Navigation or Expo Router: screen views each time a screen gets focus, impressions when a list item is really on screen, and taps.
