# uix-button

> 标签: a11y, accessible, angular, angular-button, button, button-component, cjs, color-palette, component-library, css-variables, design-system, esm, framework-agnostic, loading-button, material-design, material-ripple, nextjs, react, react-button, ripple, ripple-effect, spinner, ssr, theming, tree-shakeable, typescript, ui, ui-components, ui-library, vue, vue-button, vue3, zero-dependencies

## 简介

Lightweight, accessible button component for React, Vue 3, Angular and vanilla JavaScript with optional ripple effect, loading spinner, six variants and CSS-variable theming. Zero dependencies, TypeScript, tree-shakeable.
