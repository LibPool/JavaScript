# @holoscript/domain-plugin-template

> 标签: domain, holoscript, plugin, template, vertical

## 简介

Multi-domain plugin template. Fork this, add your domain context, ship a vertical. Composes: agriculture, retail, manufacturing, compliance, science, genetics modules.
