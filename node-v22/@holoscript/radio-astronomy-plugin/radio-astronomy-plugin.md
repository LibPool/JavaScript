# @holoscript/radio-astronomy-plugin

> 标签: astrophysics, holoscript, plugin, radio-astronomy, science

## 简介

Radio Astrophysics plugin for HoloScript spatial environments. Adds primitives for interferometers, pulsar analysis, and synchrotron emissions.
