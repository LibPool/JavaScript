# @holoscript/holoembed

> 标签: code-intelligence, embedding, holoscript, snn, webgpu

## 简介

HoloEmbed: 768-dim NL→code embeddings via structural features + char-trigram subwords. Optional SNN-WebGPU population coding for GPU-accelerated batch encoding.
