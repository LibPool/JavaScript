# @open-tuya/cloud-developer

> 标签: home-automation, iot, nodejs, open-tuya, smart-home, tuya, tuya-api, tuya-cloud, tuya-developer-platform, tuya-iot, tuya-openapi, typescript

## 简介

Unofficial client for the Tuya developer platform API, signed in with a cloud project's access ID and secret: list devices with their local keys, and read and write their data points.
