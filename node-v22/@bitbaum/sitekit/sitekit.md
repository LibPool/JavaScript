# @bitbaum/sitekit

> 标签: content-model, headless-cms, react, sections, site-generator, zod

## 简介

A website as data: a closed union of section shapes validated at runtime, one set of React renderers, and per-field provenance so a generated site can prove it fabricated nothing.
