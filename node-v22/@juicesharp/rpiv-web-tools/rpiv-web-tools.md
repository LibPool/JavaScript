# @juicesharp/rpiv-web-tools

> 标签: JavaScript

## 简介

Pi extension. Web search and fetch for the model with pluggable providers (Brave, Tavily, Serper, Exa, You.com, Jina, Firecrawl, Perplexity, SearXNG, Ollama).
