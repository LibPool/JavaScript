# @dijji/cli

> 标签: android, cli, dijji, e2e, ios, maestro, mobile

## 简介

Runs a Dijji pipeline's mobile (Android/iOS) end-to-end test jobs on a developer machine: run it in the app's repository, it takes the job for that repo and platform, checks out the published commit, builds the app with the agent-written recipe you approv
