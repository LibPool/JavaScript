# @facturion/pointer-patterns

> 标签: json, json-pointer, patterns, relative-json-pointer, rfc6901, validation

## 简介

JSON Pointer patterns: a strict superset of JSON Pointer (RFC 6901) with wildcards, an anchor-bound index and entry filters, matched against a document to concrete pointers, including places that don't exist yet.
