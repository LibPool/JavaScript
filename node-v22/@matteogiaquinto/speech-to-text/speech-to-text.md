# @matteogiaquinto/speech-to-text

> 标签: browser, dictation, french, local-ai, privacy, speech-to-text, typescript, voice, webgpu, whisper

## 简介

Local speech-to-text for web apps. Add private Whisper-powered dictation to any input with no backend or API key.
