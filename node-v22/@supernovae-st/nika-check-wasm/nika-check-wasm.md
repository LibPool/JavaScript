# @supernovae-st/nika-check-wasm

> 标签: checker, nika, static-analysis, wasm, workflow, yaml

## 简介

The static half of `nika check`, compiled to the browser — parse + conformance judgment over a workflow source, emitting findings in the report's own row shape
