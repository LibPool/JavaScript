# @smspool/sdk

> 标签: api, otp, phone-verification, sdk, sms, sms-verification, smspool, typescript

## 简介

Official JavaScript and TypeScript client for the SMSPool API: SMS verification numbers, rentals, pre-orders and eSIMs.
