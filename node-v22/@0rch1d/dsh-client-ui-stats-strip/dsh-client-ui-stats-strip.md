# @0rch1d/dsh-client-ui-stats-strip

> 标签: JavaScript

## 简介

Stats-strip redesign for DeepSeek Harness: replaces the composer's text stats line with five labeled mini-gauges (turns, time, cache, speed, tokens) and per-metric hover cards.
