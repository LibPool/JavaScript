# @eigeninteractive/server

> 标签: cloudflare-workers, durable-objects, eigen, game-engine, multiplayer, turn-based

## 简介

The deployable half of the EigenInteractive engine: the createEngine Worker factory, the BaseGameDO Durable Object base class, the D1 schema and appliers, auth, bots and push.
