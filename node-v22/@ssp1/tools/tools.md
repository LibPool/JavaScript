# @ssp1/tools

> 标签: agent, ai-sdk, signals, solana, ssp1, tools

## 简介

The SSP-1 agent tools, framework-neutral: one catalog of commit / preflight / record / verify / profile tools over @ssp1/agent, with adapters for the Vercel AI SDK and plain JSON Schema. The MCP server and the framework plugins are built on it
