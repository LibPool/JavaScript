# @pseolint/core

> 标签: audit, lint, programmatic-seo, pseo, seo, spambrain

## 简介

Programmatic SEO audit engine: 66 rules across 4 categories (integrity, discoverability, citation, data) for SpamBrain risk + AI Overview citability. Verdict ladder + site classifier.
