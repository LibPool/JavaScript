# @barter.game/web-client

> 标签: barter, federated, ledger, mutual-credit, pwa, spa

## 简介

Browser SPA (installable PWA) served by a barter.game bank at /:bank/ui. Plain static assets, no build step — a bank host serves them through the AssetReader seam of @barter.game/bank-core.
