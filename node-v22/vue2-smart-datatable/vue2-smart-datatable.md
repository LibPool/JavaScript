# vue2-smart-datatable

> 标签: csv-export, data-grid, data-table, datatable, filtering, pagination, rtl, server-side, sorting, table, typescript, vue, vue-2, vue-component, vue2

## 简介

A TypeScript-ready, UI-framework-independent data table for Vue 2.6+ with server-side pagination, filtering, mobile layouts, RTL, and CSV export.
