# @kaooffline/quickhost

> 标签: astro, deploy, hosting, kaooffline, quickhost, static, vite

## 简介

quickHOST CLI - one-command static hosting (Vite/Astro/HTML) to username.kaooffline.top/app. Free, 30-day rolling expiry.
