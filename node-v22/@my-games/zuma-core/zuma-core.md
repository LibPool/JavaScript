# @my-games/zuma-core

> 标签: arcade, browser, canvas, cjs, cross-framework, esm, game, game-engine, h5, iife, level, marble-chain, mobile-web, renderer, touch, typescript, umd, zero-dependencies, zuma

## 简介

Framework-agnostic Zuma (marble-chain) game engine with a canvas renderer that takes only a 2D context; ships ESM, CJS, UMD and IIFE builds. 无框架依赖的祖玛引擎，四格式产出。
