# @adrienlcp/styles

> 标签: contrast, css, font-face, font-fallback, fontaine, postcss, reset, sass, wcag

## 简介

A reset, a reduced-motion switch, default tokens, Sass mixins for self-hosted fonts, container queries, a breakpoint, visually hidden text, a skip link that clears the notch, a fluid size in rem, a spin animation, a PostCSS plugin that lists Arial's metri
