# @finntang/bazi-core

> 标签: bazi, calendar, chinese-astrology, four-pillars, ganzhi, lunar, metaphysics, 八字

## 简介

Deterministic, LLM-free BaZi (八字) computation library. Computes charts; does not interpret or predict.
