# @finntang/bazi-mcp

> 标签: ai-tools, bazi, claude-desktop, mcp, model-context-protocol, 八字

## 简介

MCP server (stdio + HTTP) wrapping @finntang/bazi-core. Deterministic BaZi chart computation for Claude Desktop, Cursor, and other MCP clients.
