# dsh-memory-github

> 标签: cordis, cross-session, deepseek, deepseek-harness, dsh, dsh-plugin, git, github, memory, sync

## 简介

Cross-session memory for DeepSeek Harness. Local memory store by default, optional GitHub-backed sync (git), with primary/child roles for multi-device setups.
