> 标签: ad-management, ad-server, adbutler, adtech, advertising, advertising-api, ai-agent, ai-tools, anthropic, chatgpt, claude, cursor, mcp, model-context-protocol, openai, openrtb, programmatic, rtb, vast, windsurf

## 简介

MCP server for the AdButler ad management API. Manage advertisers, campaigns, zones, creatives, placements, VAST video, programmatic, targeting, drafts, contracts, and reports from Claude, ChatGPT, Cursor, Windsurf, and any other MCP client.
