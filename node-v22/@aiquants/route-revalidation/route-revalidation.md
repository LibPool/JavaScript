# @aiquants/route-revalidation

> 标签: loader, react-router, revalidation, route, shouldRevalidate, typescript

## 简介

One declarative rule for React Router's shouldRevalidate: which destinations, submissions, paths and query changes run a route's loader again, built by a single function every app and package shares.
