# @aiquants/authz-core

> 标签: access-control, authorization, authz, column-level-security, rbac, row-level-security, typescript, zod

## 简介

Transport- and DB-agnostic RBAC authorization core: action/scope types (zod), scope merge/eval, and a DI guard factory.
