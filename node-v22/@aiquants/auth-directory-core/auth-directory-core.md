# @aiquants/auth-directory-core

> 标签: auth, directory, group, rbac, synchronization, typescript

## 简介

Provider-agnostic core for external directory group synchronization: the read-only DirectoryProvider port, a pure reconciler with a removal circuit breaker, and a pure tenant-membership rule. No network, no database, no vendor SDK.
