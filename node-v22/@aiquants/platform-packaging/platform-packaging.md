# @aiquants/platform-packaging

> 标签: binary, cross-compile, go, npm, optionaldependencies, packaging, platform, publish

## 简介

Build tooling that turns a Go command into per-platform npm packages (esbuild/Biome-style os+cpu split with optionalDependencies, bin-field executable bits, and publish-order guards)
