# @aiquants/auth-react-router

> 标签: auth, authentication, google-oauth, react-router, remix-auth, session, typescript

## 简介

React Router v7 / v8 auth adapter for @aiquants/auth-core: Google OAuth strategy factory (remix-auth), cookie session storage with DI test backdoor, a loader guard that authenticates at most once per request (token refresh + photo cache), auth route handl
