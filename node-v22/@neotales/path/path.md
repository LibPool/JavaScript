# @neotales/path

> 标签: file, glob, path, url

## 简介

Path utilities with glob and URL support that are based on Deno's std/path module.

## 官网

- 官网：https://github.com/neotales/js-std
- 源码仓库：git+https://github.com/neotales/js-std.git
- npm 页面：https://www.npmjs.com/package/@neotales/path

- Node 要求：>=22
