# @lattice-php/vite-svg-sprite

> 标签: icons, sprite, svg, vite, vite-plugin

## 简介

Vite plugin to vendor SVGs from icon packages, build an SVG sprite from folders, and generate a typed module and/or PHP enum of the icon names.
