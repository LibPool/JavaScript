# @libeilong/react-admin-next

> 标签: JavaScript

## 简介

轻量的 React 后台管理组件集合，集成了 Ant Design Pro 组件、表单抽屉、表格查询、位置选择等常用功能，便于在内部管理系统中快速搭建页面。
