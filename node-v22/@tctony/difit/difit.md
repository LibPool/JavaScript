# @tctony/difit

> 标签: cli, code-review, diff, diff-viewer, git, github, react, review, tailwind

## 简介

Fork of difit (yoshiko-pg/difit): a lightweight CLI that spins up a local web server to display Git commit diffs in a GitHub-like Files changed view
