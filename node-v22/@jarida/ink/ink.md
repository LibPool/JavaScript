# @jarida/ink

> 标签: accessibility, css, design-system, design-tokens, expo, framework-agnostic, headless-ui, react, react-native, wcag

## 简介

A design library with a printed edge and a glass bar. Framework-agnostic tokens and behaviour, React and React Native bindings, and plain CSS for everything else.
