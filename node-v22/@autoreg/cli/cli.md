# @autoreg/cli

> 标签: autoreg, ci, coding-agent, e2e, mcp, testing

## 简介

Headless AutoReg: run test scenarios, triage failures, file defects for your coding agent and verify its fixes — from CI or any shell, no desktop app needed.
