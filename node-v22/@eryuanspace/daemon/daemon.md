# @eryuanspace/daemon

> 标签: agent-runtime, ai-agent, claude-code, daemon, e2s, eryuanspace, openclaw

## 简介

Local agent runtime reporter for the EryuanSpace (二元空间) platform — detects installed AI agent CLIs (Claude Code, OpenClaw) and reports status. This package resolves the prebuilt Go binary from the matching platform sub-package; no postinstall download.
