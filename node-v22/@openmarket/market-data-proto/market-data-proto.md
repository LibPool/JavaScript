# @openmarket/market-data-proto

> 标签: JavaScript

## 简介

Generated protobuf-es message types for the Orange v2 market-data gateway (tsdb-gateway) and the data types it serves. Public subset of @orangecharts/orange-v2-pb-common, generated from the same proto sources.
