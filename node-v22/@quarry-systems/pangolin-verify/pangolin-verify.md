# @quarry-systems/pangolin-verify

> 标签: JavaScript

## 简介

Standalone audit-bundle verifier — the artifact an auditor runs. Owns the RFC 3161 / ASN.1 (pkijs) dependency so pangolin-core stays dependency-light.
