# @adapt-toolkit/sdk-native

> 标签: JavaScript

## 简介

Native (NAPI) backend for the ADAPT TypeScript SDK. Pulled in automatically as an optional dependency of @adapt-toolkit/sdk on platforms with a prebuilt; if absent, the SDK falls back to the bundled WASM backend.
