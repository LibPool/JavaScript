# @jojoman2024/dsh-prompt-inject

> 标签: deepseek-harness, dsh-plugin, prompt-inject, system-prompt

## 简介

在会话工具条挂按钮，点击后开新标签页管理提示词；点【注入】可在当前会话下一次模型 step 前注入 prompt 到 system prompt。
