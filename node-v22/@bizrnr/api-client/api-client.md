# @bizrnr/api-client

> 标签: api, bizrnr, crm, leads, sdk, typescript, voice

## 简介

Official TypeScript SDK for the BizRnR Public API. Typed wrappers for every /v1 endpoint with cursor pagination and rich error classes.
