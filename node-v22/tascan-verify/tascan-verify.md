# tascan-verify

> 标签: e-signature, ed25519, jws, passkey, receipt, tascan, verify, webauthn

## 简介

Reference verifier for TaScan Action Receipts (Ed25519 JWS) and signed documents (passkey signature bundles). Zero dependencies, Node 18+, one file you can read end to end. Checks without trusting TaScan's server.
