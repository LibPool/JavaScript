# @phestus/in-memory

> 标签: backend, data-storage, development, in-memory, phestus, query-management, schema, service-adapter, testing, typescript

## 简介

An in-memory service adapter for Phestus, providing in-memory schema definition, data storage, and query management for development, testing, and lightweight applications.
