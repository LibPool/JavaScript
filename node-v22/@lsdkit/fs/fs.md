# @lsdkit/fs

> 标签: JavaScript

## 简介

这是一个基于 TypeScript 封装的 Node.js 文件操作和监控库，旨在简化文件系统管理相关的业务集成。通过这个库，您可以更方便地进行文件操作、文件系统监控等任务。
