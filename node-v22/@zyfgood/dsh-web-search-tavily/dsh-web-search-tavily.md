# @zyfgood/dsh-web-search-tavily

> 标签: cordis, deepseek-harness, dsh, plugin, tavily, web-search

## 简介

DeepSeek Harness 插件：把 web_search 的搜索后端从 DeepSeek 云（每次搜索 = 一次完整模型调用）换成 Tavily API（免费 1000 次/月），支持多 key 轮换
