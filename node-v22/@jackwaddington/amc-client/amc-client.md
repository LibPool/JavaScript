# @jackwaddington/amc-client

> 标签: amc, client, llm, ollama, sdk

## 简介

TypeScript client for AMC's HTTP API — submit jobs, poll or subscribe to live results, check runner status, and read/write Projects, Agents, Batches, and Notes.
