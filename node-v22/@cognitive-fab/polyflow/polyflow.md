# @cognitive-fab/polyflow

> 标签: ai-agents, durable-execution, mcp, model-checking, openworker, polyrun, procedural-memory, state-machine, workflow-engine

## 简介

A workflow engine for AI agents: the agent reasons a workflow, polyflow admits it only if it model-checks, then runs it durably and hands the agent one work order at a time.
