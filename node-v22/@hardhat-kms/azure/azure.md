# @hardhat-kms/azure

> 标签: azure, azure-key-vault, azure-monitor, ethereum, ethers, hardhat, hardhat-kms, hardhat-plugin, hardhat3, hsm, key-vault, kms, managed-hsm, signer, smart-contracts, viem

## 简介

Azure Key Vault and Managed HSM signer for Hardhat 3 (hardhat-kms provider): keys stay in the vault; signing history from Azure Monitor for Key Vault keys.
