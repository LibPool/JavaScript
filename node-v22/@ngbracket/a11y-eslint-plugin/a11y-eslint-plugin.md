# @ngbracket/a11y-eslint-plugin

> 标签: a11y, accessibility, angular, angular-eslint, eslint, eslint-plugin, eslintplugin, ngbracket

## 简介

ESLint rules that check Angular templates for missing accessible names, including on custom components you map to native elements.
