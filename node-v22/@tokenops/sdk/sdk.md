# @tokenops/sdk

> 标签: airdrop, confidential, disperse, erc7984, ethereum, evm, fhevm, tokenops, vesting, viem, zama

## 简介

Typed viem-first SDK for TokenOps FHEVM contracts (confidential vesting, confidential airdrops, confidential disperse, plus a testnet faucet for the ERC-7984 test-token pair TTT + CTTT) — consumed by tokenops-app (Next.js) and tokenops-api (Express).
