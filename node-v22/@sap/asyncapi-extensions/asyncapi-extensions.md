# @sap/asyncapi-extensions

> 标签: asyncapi, discovery, event-driven-architecture, events, specification, standard

## 简介

This library extends the AsyncAPI Specification 2.0 format to describe events according to the CloudEvents specification for SAP ecosystem and adds SAP-specific extensions.
