# @frostbase-dev/db

> 标签: agents, cloudflare, database, durable-objects, frostbase, live-queries, realtime, workers

## 简介

Documents with live queries and schema-first SQL tables on Cloudflare Durable Objects, one isolated instance per collection or table - the database primitive behind Frostbase.
