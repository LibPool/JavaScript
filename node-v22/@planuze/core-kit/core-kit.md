# @planuze/core-kit

> 标签: JavaScript

## 简介

Primitivos públicos do Planuze: Result<T,E>, AppError, Logger contract, IDisposable, validators de pack (packId/packVersion/labelKey), path-safety. Base do SDK de packs e re-exportado por @planuze/kernel.
