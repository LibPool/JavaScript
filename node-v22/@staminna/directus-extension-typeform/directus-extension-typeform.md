# @staminna/directus-extension-typeform

> 标签: directus, directus-custom-bundle, directus-extension, forms, surveys, typeform, webhooks

## 简介

Bidirectional Typeform integration for Directus — one-shot form import (ID or URL), Flow operations for the full Typeform API, webhook sync with upsert, and auto-mapped collections
