# @formstr/local-relay

> 标签: formstr, local-relay, nip-01, nip-65, nostr, offline-first, outbox, relay, web-worker

## 简介

NIP-01 Web Worker local relay + an intent-only data layer for Nostr apps. The app declares interests and publishes; the worker owns every connection decision.
