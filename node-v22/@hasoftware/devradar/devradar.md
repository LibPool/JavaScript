# @hasoftware/devradar

> 标签: cli, code-analysis, devradar, framework-detection, hasoftware, language-detection, line-counter, loc, monorepo

## 简介

A CLI tool to analyze code projects: count lines of code, detect programming languages, and identify frameworks in use.
