# @marg-adk/widget

> 标签: agent-framework, agents, chat-ui, llm, mcp, typescript, widget

## 简介

The Marg chat widget — one <script> tag, Shadow DOM, zero dependencies: streaming replies, chips, forms, cards, tables, media, resume, nudges, voice. Served by @marg-adk/gateway at /widget.js.
