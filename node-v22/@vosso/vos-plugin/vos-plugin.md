# @vosso/vos-plugin

> 标签: cli, vos, vosso

## 简介

Forwarding shim. The take pipeline and the vos.so verbs this package used to carry now ship inside @vosjs/cli (one package, every verb): npm i -D @vosjs/cli@latest. Installing this package does nothing else.
