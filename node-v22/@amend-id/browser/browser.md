# @amend-id/browser

> 标签: amend, amend-id, oauth, oidc, pkce, sign-in

## 简介

Sign in with Amend iD, in the browser — the hard parts done once: PKCE, the redirect back, tokens kept right across tabs, refresh under a lock, honest states, sign-out that reaches every tab.
