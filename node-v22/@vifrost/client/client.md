# @vifrost/client

> 标签: api-client, laravel, rest, vifrost

## 简介

Framework-agnostic runtime client for Laravel Vifrost APIs: a typed Model base class, a spatie/laravel-query-builder-compatible query builder, and an identity map ready for real-time sync.
