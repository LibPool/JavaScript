# roomy-cli

> 标签: ai-agents, cleanup, cli, disk, macos, mcp, mcp-server, storage

## 简介

Keeps your Mac roomy: finds what is safe to delete, warns before storage or memory runs out. CLI, TUI and MCP server for people and AI agents.
