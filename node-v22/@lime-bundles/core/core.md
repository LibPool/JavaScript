# @lime-bundles/core

> 标签: bundles, headless, hydrogen, nextjs, shopify, storefront

## 简介

Headless storefront primitives for the Lime Bundles Shopify app. Storefront API client, bundle parser, pricing math, analytics, and A/B helpers.
