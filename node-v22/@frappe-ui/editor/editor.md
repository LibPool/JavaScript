# @frappe-ui/editor

> 标签: components, design-system, frappe, frappe-ui, headless, tailwind, ui

## 简介

Unofficial community port — Framework-free rich text editor for frappe-ui-universal: a Tiptap/ProseMirror controller plus a toolbar model that every binding renders.
