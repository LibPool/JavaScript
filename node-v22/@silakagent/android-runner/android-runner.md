# @silakagent/android-runner

> 标签: adb, android, appium, e2e, qa, runner, scrcpy, silak, testing

## 简介

Daemon self-hosted Fase 4 — Appium server + UIAutomator2 + better-sqlite3, pairing token lokal ke extension. Wajib untuk semua device Android, emulator maupun USB fisik, deteksi dinamis via adb devices -l (PRD §5.8)
