# @blissy-auth/oidc

> 标签: authentication, discovery, effect, identity, nonce, oidc, openid, openid-connect

## 简介

TypeScript implementation of OpenID Connect protocol primitives with support for provider metadata parsing, discovery documents, nonce generation, and nonce validation.
