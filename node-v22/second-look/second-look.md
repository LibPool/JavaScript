# second-look

> 标签: accessibility, claude-code, layout, mobile, playwright, responsive, testing, vibe-coding

## 简介

Checks a web page the way real visitors see it: phone widths, larger text turned on, cut-off buttons and words, broken links and JavaScript errors. Plain-English report.
