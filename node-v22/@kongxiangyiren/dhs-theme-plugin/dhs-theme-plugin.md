# @kongxiangyiren/dhs-theme-plugin

> 标签: deepseek-harness, dsh-plugin, theme

## 简介

主题管理插件：设置-主题大分类，内置森林绿/海洋蓝，支持上传 __ModuleLoader__.load 格式的 JS 主题（overrideTokens + CSS + slots UI），点击切换，磁盘持久化。
