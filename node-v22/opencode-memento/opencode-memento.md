# opencode-memento

> 标签: amnesia, compaction, context, markdown, memory, opencode, opencode-plugin

## 简介

Amnesia insurance for OpenCode: injects your project's Markdown memory index into session compaction, so auto-summarization never forgets that memory exists. Zero dependencies.
