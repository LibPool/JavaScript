# @eimerreis/az-npm

> 标签: artifacts, auth, azure-devops, bun, cli, npm, pnpm

## 简介

Zero-config CLI that authenticates npm, pnpm, and bun registries against Azure DevOps Artifacts feeds using the Azure CLI.
