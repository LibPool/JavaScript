# @webjsdev/server

> 标签: dev-server, router, server, ssr, webjs

## 简介

The server for WebJs, a full-stack JavaScript framework built on web components with server-side rendering and no build step. Provides the file-based router, SSR, server actions, route handlers, middleware, and live reload on Node 24+ or Bun.
