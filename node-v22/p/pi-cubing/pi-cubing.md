# pi-cubing

> 标签: cstimer, cubing, pi, pi-extension, pi-package, rubiks-cube, speedcubing, timer

## 简介

A cstimer-style Rubik's Cube timer overlay for Pi, with scrambles, averages, ratings, and local solve persistence.
