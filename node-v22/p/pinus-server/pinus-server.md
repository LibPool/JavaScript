# pinus-server

> 标签: application, cluster, framework, game server, netease, pinus, runtime, server, service

## 简介

1. pinus是pomelo的TS版本，框架内部把回调改为了Promise。 1. 框架与pomelo一样，所以可以看pomelo的相关教程。 1. 协议与pomelo一样，所以pomelo的客户端代码可以直接对接上pinus服务端。
