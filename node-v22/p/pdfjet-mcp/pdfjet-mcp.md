# pdfjet-mcp

> 标签: convert, encrypt, extract, markdown, mcp, merge, model-context-protocol, pdf, pdfjet, rag, split

## 简介

MCP server for PdfJet — let your AI assistant extract PDFs (Markdown/CSV/Word/searchable), convert files to PDF, and merge/split/encrypt PDFs.
