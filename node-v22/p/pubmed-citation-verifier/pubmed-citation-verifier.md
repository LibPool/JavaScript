# pubmed-citation-verifier

> 标签: citation, e-utilities, fact-checking, hallucination, llm, ncbi, pmid, pubmed, reference

## 简介

Checks that each cited PMID belongs to the cited article, using the PubMed API. Finds the right PMID when it does not. No dependencies.
