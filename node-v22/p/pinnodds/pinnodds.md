# pinnodds

> 标签: arbitrage, betting, closing-line-value, dropping-odds, odds, odds-api, odds-drop, pinnacle, pinnacle-api, pinnacle-odds, real-time, sports-betting, sports-odds, sse, steam-moves, websocket

## 简介

Official Node.js client for the pinnodds Pinnacle odds API — live and prematch REST snapshots, real-time odds-drop SSE streams, quarter-line depth and player props. Zero dependencies, TypeScript types included.
