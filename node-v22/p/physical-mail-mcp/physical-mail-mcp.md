# physical-mail-mcp

> 标签: agentic-commerce, ai-agents, anthropic, certified-mail, claude, click2mail, cursor, direct-mail, letters, lob, machine-payments-protocol, mailsnail, mcp, model-context-protocol, physical-mail, postcards, snail-mail, stripe, usps

## 简介

Send physical mail (USPS letters, postcards, certified mail) from AI agents. MCP server with three modes: managed (no signup, pay-per-piece via Stripe Link), Click2Mail BYOK, or Lob BYOK. Powers Mailsnail.
