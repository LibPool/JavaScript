# pip-window

> 标签: always-on-top, chrome, document-picture-in-picture, dom, floating-window, mini-player, picture-in-picture, pip, popout, react-hooks, typescript, video-call-controls

## 简介

Put real DOM in an always-on-top floating window with the Document Picture-in-Picture API: styles copied, content moved and restored, typed errors.
