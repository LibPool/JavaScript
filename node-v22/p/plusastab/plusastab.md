# plusastab

> 标签: focus, form, forms, input, keyboard, numpad, shortcuts, tab, tabbable, tabbing, tabindex, tenkey, usability

## 简介

A jQuery plugin to use the numpad plus key (configurable) as a tab key equivalent.
