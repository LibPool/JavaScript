# pi-harness-delegate

> 标签: amp, claude, code-review, codex, coding-agent, delegate, harness, opencode, pi, pi-package, subagent

## 简介

Delegate work to any harness (Claude Code, Muse, OpenCode, Amp) from the pi coding agent — code reviews, plans, implementation, security audits, docs, or your own custom templates.
