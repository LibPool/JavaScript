# pi-shift-router

> 标签: agent-failover, agent-routing, ai-router, auto-router, calibrated-probability, cost-optimization, decision-model, exponential-backoff, jev, judge-model, llm-judge, llm-router, model-routing, model-selection, model-switching, model-tier-routing, multi-model-fallback, orchestrator, pi-agent, pi-coding-agent, pi-extension, pi-package, rate-limit-handling, shift-router, subagent, system-one, task-classifier, task-orchestration, two-tier-routing, typesafe

## 简介

Per-turn model routing for Pi: a small judge picks the cheap or the strong tier for each message, with multi-model failover, task-level orchestration, and an optional decision-model judge (Jev) that answers with a calibrated probability instead of prose.
