# paper-parser

> 标签: academic, arxiv, markdown, paper, parser, pdf, pdf-to-html, pdf-to-text, poppler

## 简介

Parse scientific PDF papers into structured, selectable HTML and Markdown — columns, headings, tables, sub/superscripts, figures and display equations rendered as images — powered by poppler.
