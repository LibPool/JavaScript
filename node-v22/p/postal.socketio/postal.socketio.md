# postal.socketio

> 标签: JavaScript

## 简介

postal.js/postal.federation plugin for federating instances of postal.js across socket.io (http://socket.io/).

- 官网：http://github.com/ifandelse/postal.socketio
- 源码仓库：git://github.com/ifandelse/postal.socketio.git
- npm 页面：https://www.npmjs.com/package/postal.socketio
