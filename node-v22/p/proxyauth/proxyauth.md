# proxyauth

> 标签: JavaScript

## 简介

模拟登陆过程，用于前后端分离开发时，作为中间服务将前端接口代理到测试或线上环境，并添加cookies，以及方便的进行代理方案切换，避免重启编译的耗时。 使用puppeteer进行模拟登陆，会根据set-cookie保存cookie, 在代理中携带。
