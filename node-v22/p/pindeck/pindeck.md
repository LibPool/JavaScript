# pindeck

> 标签: ai, claude, claude-code, editor, presentation, reveal.js, slides

## 简介

PinDeck: an editor for HTML slide decks on macOS, and on Linux (beta) through an SSH tunnel. Pin elements, describe the change, and Claude Code edits the slides.
