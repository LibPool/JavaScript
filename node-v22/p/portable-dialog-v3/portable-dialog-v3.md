# portable-dialog-v3

> 标签: create-dialog, custom-dialog, dialog, open-dialog, show-dialog, vue-dialog

## 简介

portable-dialog-v3是为了解决页面在使用弹窗时，维护弹窗数据及状态的代码可以单独抽离出来封装，防止页面弹窗过多时，代码维护困难。
