# personal-device-scanner-mcp

> 标签: android, clamav, mcp, model-context-protocol, osquery, security, wazuh

## 简介

MCP server that lets AI agents inspect your own PC and Android device read-only with osquery, ClamAV, Wazuh and adb (runs the Python server; needs Python 3.11+)
