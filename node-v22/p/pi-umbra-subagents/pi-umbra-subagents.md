# pi-umbra-subagents

> 标签: loop, parallel, pi, pi-extension, pi-package, pi-skill, subagents

## 简介

Parallel pi branches with a live agent tree under the input box, read-only or in their own git worktree, the delegate skill that starts them, and /umb-loop, which resubmits a prompt on a count or a timer.
