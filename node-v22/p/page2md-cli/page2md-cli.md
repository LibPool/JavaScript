# page2md-cli

> 标签: cli, ego-lite, llm, markdown, page2md, pdf, rag, scraping

## 简介

npm launcher for page2md — turn any web page into LLM-ready Markdown, typed blocks and citable chunks with zero LLM tokens. Bootstraps the Python CLI (uv/pipx/pip) on first run, then forwards everything to it.
