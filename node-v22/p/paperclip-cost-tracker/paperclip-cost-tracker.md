# paperclip-cost-tracker

> 标签: agent-costs, budget, cost-tracking, dashboard-widget, paperclip, plugin

## 简介

Real-time agent cost tracking dashboard for Paperclip. Track costs per agent, per run, per day with visual charts and budget alerts.
