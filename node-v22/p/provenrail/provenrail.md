# provenrail

> 标签: agent-security, agents, ai, ai-agents, anthropic, audit-log, audit-trail, claude-code, compliance, ed25519, eu-ai-act, guardrails, hash-chain, llm, mcp, observability, openai, provenance, tamper-evident, verifiable

## 简介

Verifiable audit trail for AI agents, for TypeScript and Node. Capture every model and tool call your agent makes, hash-chain and sign it off-box, and verify it with the same open-source verifiers as the Python SDK.
