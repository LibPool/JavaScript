# plataforma-mcp

> 标签: claude, cursos, ead, mcp, model-context-protocol, plataforma-de-cursos, white-label

## 简介

Servidor MCP para operar sua plataforma de cursos conversando com o Claude: criar cursos e aulas, liberar alunos, trocar capas, ver métricas e responder comentários.
