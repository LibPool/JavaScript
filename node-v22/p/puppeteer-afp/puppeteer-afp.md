# puppeteer-afp

> 标签: anti-detection, anti-fingerprint, bot-detection, canvas, chrome, crawler, fingerprint, fingerprint-vault, headless, privacy, proxy, puppeteer, scraping, stealth, typescript, webgl, webrtc

## 简介

Coherent, persistable anti-fingerprinting for Puppeteer. One seed → one consistent browser identity, with proxy/timezone/geo coherence and a fingerprint vault.
