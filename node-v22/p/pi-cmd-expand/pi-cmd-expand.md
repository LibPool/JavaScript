# pi-cmd-expand

> 标签: claude-code, command-expansion, pi-extension, pi-package

## 简介

Expand !`cmd` and !```sh\ncmd\n``` inline command syntax in prompts and project context files (AGENTS.md / CLAUDE.md). Commands run in the agent's cwd.
