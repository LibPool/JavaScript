# paris-compass-mcp

> 标签: apur, bodacc, commercial-property, mcp, modelcontextprotocol, open-data, paris, retail

## 简介

MCP server for Compass: address-level context on Paris commercial premises, from open data — what traded on a shopfront before, how the street turns over, what sources say and how sure they are. Anonymous read-only access, the same trust boundary as a vis
