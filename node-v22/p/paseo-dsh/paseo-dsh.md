# paseo-dsh

> 标签: deepseek, deepseek-harness, dsh, paseo, paseo-plugin, provider

## 简介

DeepSeek Harness (dsh) as a native Paseo provider: question cards, plan mode, thinking levels, steering, images and a real slash menu. 把 DeepSeek Harness 接成 Paseo 原生 provider。
