# phluff-mcp

> 标签: chatgpt, chrome, claude, gemini, mcp, phluff

## 简介

MCP server for Phluff — drives your logged-in ChatGPT / Claude / Gemini tabs (image generation, send-message, full-page screenshots) via the Phluff macOS app's Chrome bridge.
