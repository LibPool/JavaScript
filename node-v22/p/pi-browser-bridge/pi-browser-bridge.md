# pi-browser-bridge

> 标签: automation, browser, browser-agent, cdp, chrome, pi, pi-extension, pi-package

## 简介

pi extension that lets a local pi agent see and operate Chrome through the Browser Agent extension (HTTP/SSE bridge, 20 browser tools)
