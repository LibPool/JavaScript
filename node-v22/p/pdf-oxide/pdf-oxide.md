# pdf-oxide

> 标签: native-binding, pdf, pdf-parsing, prebuilt, rust-ffi, text-extraction

## 简介

The fastest Node.js PDF library — 0.8ms mean, 5× faster than the industry leaders, 100% pass rate on 3,830 real-world PDFs. Prebuilt native bindings, no build toolchain: text extraction, Markdown/HTML conversion, PDF creation and editing.
