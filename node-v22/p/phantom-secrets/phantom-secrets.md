# phantom-secrets

> 标签: ai-safety, api-keys, claude, codex, copilot, cursor, dotenv, env, keychain, mcp, model-context-protocol, phantom, proxy, secrets, security, vault, windsurf

## 简介

Prevent AI coding agents from leaking your API keys. Replaces real secrets with phantom tokens; a local proxy swaps them back at the network layer.
