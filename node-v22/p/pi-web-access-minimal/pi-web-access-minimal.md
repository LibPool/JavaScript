# pi-web-access-minimal

> 标签: extension, fetch, pi, pi-coding-agent, pi-package, scraping, web-search

## 简介

Minimal web search and URL fetching for Pi coding agent. Search via OpenAI or Brave; fetch readable/raw content from URLs, GitHub repos, and PDFs.
