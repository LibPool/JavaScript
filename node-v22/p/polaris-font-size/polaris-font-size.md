# polaris-font-size

> 标签: CSS, Framework, HTML, JavaScript, Sass, TypeScript, Web, front-end, responsive-design, webpack

## 简介

Polaris font-size Plugin for Polaris Framework. A set of responsive classes for controlling the 'font-size' of HTML elements.
