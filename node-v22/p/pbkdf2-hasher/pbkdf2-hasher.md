# pbkdf2-hasher

> 标签: hash, hasher, password, pbkdf2

## 简介

Password hashing and verification for Node using the built-in crypto.pbkdf2 (HMAC-SHA1).

- 源码仓库：http://github.com/mpeak/pbkdf2-hasher.git
- npm 页面：https://www.npmjs.com/package/pbkdf2-hasher

- npm registry：https://registry.npmjs.org/pbkdf2-hasher
