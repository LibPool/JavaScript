# pi-sigrok

> 标签: dslogic, i2c, logic-analyzer, pi-package, protocol-decoder, sigrok, spi, uart

## 简介

Logic analyzer control and protocol decoding via sigrok-cli. Supports DreamSourceLab DSLogic and other sigrok-compatible devices.
