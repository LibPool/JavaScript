# pi-prompt-restore

> 标签: coding-agent, editor, history, input, pi, pi-extension, pi-package, prompt, recovery, tui, undo

## 简介

Pi extension that saves discarded prompts when Ctrl+C clears the editor - recover with the Up arrow
