# pi-todone

> 标签: anti-laziness, completion, evidence, pi, pi-coding-agent, pi-extension, pi-package, todo

## 简介

Todo 完成义务闸 + 证明点协议：todo 标 completed 必须附 evidence（格式闸），空闲时有 pending 注入证明义务（证明/继续/卡点），语义验证交给 subagent 系
