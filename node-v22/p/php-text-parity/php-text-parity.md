# php-text-parity

> 标签: compatibility, grapheme, migration, natural-sort, parity, php, slugify, string, strnatcasecmp, text, utf-8, word-count

## 简介

PHP-compatible text processing for JavaScript. Grapheme counts, UTF-8 byte length, PHP trim() and strnatcasecmp(), plus 48 text transforms — verified byte for byte against PHP 8.3.
