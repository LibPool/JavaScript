# persian-date-kit

> 标签: calendar, date-picker, datepicker, datetime, dayjs, jalali, persian, react, rtl, shamsi, time-picker, typescript

## 简介

Production-ready Persian (Jalali) date pickers for React with Gregorian-only values, optional time picker (wheel/dropdown), and RTL-first UI.
