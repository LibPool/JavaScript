# pdf-codec

> 标签: codec, mathml, pdf, pdf-generation, pdf-parser, pdf-writer, round-trip, zod

## 简介

Hand-written, dependency-minimal PDF codec: parses arbitrary real-world PDFs and generates new ones, built on its own codec-owned LayoutDocument item model and Zod 4 codecs.
