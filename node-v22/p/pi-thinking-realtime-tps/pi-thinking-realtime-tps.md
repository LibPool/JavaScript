# pi-thinking-realtime-tps

> 标签: pi-extension, pi-package, thinking, token-speed, tokens, tps, working-message

## 简介

Pi extension that adds elapsed time, directional tokens, and real-time tokens-per-second (TPS) to Pi's original working/thinking loader.
