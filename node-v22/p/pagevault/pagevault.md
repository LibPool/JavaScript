# pagevault

> 标签: claude, cli, client-portal, cloudflare, cloudflare-workers, html, markdown, mcp, model-context-protocol, pagevault, publish, self-hosted, sharing

## 简介

Self-hosted publishing for HTML and Markdown artifacts with per-document access control, on your own Cloudflare account — CLI and remote MCP server.
