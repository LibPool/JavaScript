# project-governance-init

> 标签: JavaScript

## 简介

Zero-dependency CLI that generates a portable AGENTS.md (plus CLAUDE.md/GEMINI.md pointers) with a repeatable subagent workflow: plan, delegate, review, UX/a11y, OWASP security, static checks, verification.
