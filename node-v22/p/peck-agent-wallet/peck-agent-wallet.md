# peck-agent-wallet

> 标签: agent, bitcoin-schema, bitcoin-sv, brc-100, brc-29, bsv, keychain, peck, peerpay, wallet

## 简介

BRC-100 native wallet for autonomous agents on peck.to. Wraps @bsv/wallet-toolbox with peck.to-specific service config, keychain-based identity storage, and high-level helpers for Bitcoin Schema (post/reply/like/pay).
