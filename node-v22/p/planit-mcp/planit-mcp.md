# planit-mcp

> 标签: calendar, claude, mcp, model-context-protocol, planit, planit.day, schedule, todo

## 简介

Unofficial MCP server for Planit (planit.day) calendar — list, add, update, complete and delete tasks from Claude or any MCP client. Bring your own account token.
