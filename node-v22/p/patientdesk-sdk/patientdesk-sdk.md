# patientdesk-sdk

> 标签: alania, duyu, patientdesk, sdk, speech-to-text, stt, text-to-speech, tts, turkish, voice

## 简介

Unofficial SDK for PatientDesk Turkish voice models — Alania (text-to-speech, REST + streaming) and Duyu (speech-to-text, multipart + streaming), plus voices, pronunciations, styles, models and health.
