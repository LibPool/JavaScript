# pervigil

> 标签: caffeinate, cross-platform, display-sleep, inhibit, keep-awake, linux, macos, nosleep, power-management, powersaveblocker, presentation, prevent-sleep, stay-awake, systemd-inhibit, wake-lock, windows

## 简介

Cross-platform keep-awake / prevent-sleep utility for Node — inhibits host & display sleep (caffeinate / systemd-inhibit / SetThreadExecutionState). Zero dependencies, no native addons.
