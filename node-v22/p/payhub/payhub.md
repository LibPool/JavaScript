# payhub

> 标签: checkout, expo, express, lemonsqueezy, nextjs, nodejs, payments, razorpay, react, react-native, stripe, subscriptions, typescript, webhooks

## 简介

Plug-and-play payment integrations for Node.js, React, Next.js and React Native. One consistent API for Stripe, Lemon Squeezy and Razorpay — checkouts, products, plans, subscriptions, customers and verified webhooks.
