# pi-git-auth

> 标签: extension, git, git-auth, github, gitlab, keyring, pi, pi-coding-agent, pi-package

## 简介

pi coding-agent extension: git auth for GitHub and GitLab: keyring-stored login tokens, account switching, transparent git/gh/glab auth, token placeholder for any CLI tool, repo list/create with details overlay
