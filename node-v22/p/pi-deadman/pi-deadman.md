# pi-deadman

> 标签: crash, deadman, freeze, kill, macos, memory, memory-pressure, oom, pi-package, process-manager, ram, swap, system-health, watchdog

## 简介

Prevents macOS freezes during pi sessions. Auto-kills runaway processes when memory runs out.
