# pbi-lineage-lenz

> 标签: ci, data-lineage, dax, documentation, fabric, lineage, pbip, pbir, power-bi, tmdl

## 简介

Find the lineage, understand the model, document both. Trace Power BI columns from physical source to report visual, generate documentation that cannot go stale, build a self-contained handoff file, and gate CI on broken references.
