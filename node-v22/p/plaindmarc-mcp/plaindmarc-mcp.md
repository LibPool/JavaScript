# plaindmarc-mcp

> 标签: bimi, deliverability, dkim, dmarc, email-authentication, mcp, model-context-protocol, mta-sts, spf

## 简介

Read-only MCP server for DMARC, SPF, DKIM, BIMI and MTA-STS checks, DMARC record generation, and aggregate-report analysis — powered by plaindmarc.com's public tools. No API key, no account.
