# pkg-use-react-app

> 标签: JavaScript

## 简介

A **highly customizable and reusable** login form component built with **React Hook Form**, **Yup**, and **Material UI**, supporting image uploads, file inputs, CAPTCHA validation, and flexible UI overrides.
