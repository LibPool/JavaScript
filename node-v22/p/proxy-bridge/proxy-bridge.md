# proxy-bridge

> 标签: access-token, app-router, auth, authentication, bff, cookies, http-only, httponly, next, next.js, nextjs, proxy, refresh-token, route-handler

## 简介

Next.js App Router proxy bridge for token-based backend authentication with httpOnly cookies, refresh retry, and response sanitization.
