# prompt-cache-fit

> 标签: anthropic, cache-hit-rate, context-window, llm, openai, prefix-cache, prompt-caching, prompt-engineering

## 简介

Reorder LLM prompt blocks from least- to most-volatile so provider prefix caches stay hot, and measure the resulting hit rate.
