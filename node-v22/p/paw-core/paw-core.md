# paw-core

> 标签: ai-agent, automation, bezier, browser, cdp, chrome-devtools-protocol, cli, cursor, human-in-the-loop, visualization

## 简介

PAW — Physical Agent Worker. AI's body on the web. `paw click 1` walks a visible cursor across the page on a bezier curve, then fires real CDP mouse events. Human can grab the wheel mid-task with Alt+drag. Zero runtime dependencies.
