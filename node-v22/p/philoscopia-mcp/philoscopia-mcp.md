# philoscopia-mcp

> 标签: ai, claude, critical-thinking, knowledge-base, llm, mcp, model-context-protocol, philosophical, philosophy, philosophy-education, philosophy-framework, socratic

## 简介

MCP server for the Philoscopia framework: explore 80 axes of philosophical positions, compare figures, and build your own philosophical profile in a local, private workspace.
