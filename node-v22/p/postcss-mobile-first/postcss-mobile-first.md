# postcss-mobile-first

> 标签: Build tools., CSS customization, CSS desktop first, CSS mobile 1st, CSS mobile first, CSS optimization, CSS preprocessing, Code customization, Code formatting, Desktop-first approach, Media queries, Mobile-first approach, Mobile-first development, PostCSS, PostCSS plugin, Responsive web design, css breakpoints, esponsive design, make css fast, production CSS files

## 简介

This PostCSS plugin converts your desktop-first CSS code to mobile-first CSS code. This plugin helps you automatically converting your old css desktop first code into modern mobile-first code. This Plugin can save time and effort.
