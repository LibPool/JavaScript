# pi-jev-lens

> 标签: compression, context, jev, pi-extension, pi-package, prompt-cache, tool-output, typesafe

## 简介

pi extension that compresses large tool results before they reach the model: jev picks the view (outline, relevant blocks, sections, signals, testlog), full text stays recallable
