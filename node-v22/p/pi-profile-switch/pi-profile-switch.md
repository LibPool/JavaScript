# pi-profile-switch

> 标签: pi, pi agent, pi-package, pi-profile-switch, profile

## 简介

Named profiles for Pi: reference skills, extensions, MCP servers, and tools per workflow, switched without restarting. Install: npm install -g pi-profile-switch (not pi install).
