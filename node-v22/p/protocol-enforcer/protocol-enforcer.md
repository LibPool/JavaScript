# protocol-enforcer

> 标签: ai-agents, audit, governance, mcp, mcp-server, merkle, state-machine

## 简介

Passive, deterministic MCP server that serves a nested, force-ordered state machine to AI agents — with an RFC 6962 auditable transcript per session. Native binary; this package is the launcher.
