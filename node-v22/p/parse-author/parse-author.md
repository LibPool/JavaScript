# parse-author

> 标签: author, authors, contributor, exec, expression, extract, maintainer, maintainers, match, package, parse, person, pkg, re, regex, regexp, regular, somebody

## 简介

Parse an author, contributor, maintainer or other 'person' string into an object with name, email and url properties following npm conventions.
