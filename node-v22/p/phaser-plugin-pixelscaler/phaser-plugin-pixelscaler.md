# phaser-plugin-pixelscaler

> 标签: phaser, phaser3, pipeline, pixel-art, pixelscaler, plugin, postfx, retro, shader, webgl

## 简介

WebGL post-FX pipeline for Phaser 3 that snaps any scene to a virtual pixel grid, with optional palette quantisation, to render games as pixel art without authoring at a tiny canvas resolution.
