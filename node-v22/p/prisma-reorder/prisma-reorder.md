# prisma-reorder

> 标签: cli, column-order, database, mariadb, migration, mysql, orm, prisma, schema, typescript

## 简介

A TypeScript NPM package that enhances Prisma ORM by enabling automatic column reordering in MySQL/MariaDB databases to match the column order defined in the Prisma schema.
