# permaweb-mcp

> 标签: ai, ai-memory, arweave, blockchain, claude, fastmcp, mcp, mcp-server, memory, permaweb, permaweb-mcp

## 简介

MCP server for AO process management, Arweave deployment, ArNS domain operations, and wallet management. Provides 16 tools across process operations (spawn, message, query), Permaweb deployment, ArNS name services, and Arweave wallet generation.
