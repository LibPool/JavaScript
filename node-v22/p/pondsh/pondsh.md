# pondsh

> 标签: agent-native, agents, app-runtime, capsule, cli, deploy, full-stack, hono, multi-tenant, pond, preact, runtime, serverless, sqlite, typescript

## 简介

Agent-native CLI and runtime for building small full-stack TypeScript apps. Hosted Lakebed-style anonymous deploys included.
