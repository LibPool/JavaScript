# pixelletter-mcp

> 标签: fax, letter, mcp, model-context-protocol, pixelletter, post

## 简介

Local stdio MCP server for the PixelLetter HTTPS interface: send PDF files or plain text as physical letters and faxes, with registered mail options, test mode and account balance.
