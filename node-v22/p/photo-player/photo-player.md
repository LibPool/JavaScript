# photo-player

> 标签: JavaScript

## 简介

一个影集工具，可以很好地在移动端以及PC端播放图片，支持PC端方向键切换图片，支持移动端左右滑动切换图片。可以自动顺序或者随机地播放图片。支持全屏播放，使用了 [animate.css](https://github.com/daneden/animate.css) 中的部分动画效果。
