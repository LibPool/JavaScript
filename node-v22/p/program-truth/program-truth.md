# program-truth

> 标签: claude, codex, confluence, jira, notion, program-management, skill, status-artifact, tpm

## 简介

Program Truth gathers and synthesizes execution-level evidence into a canonical, machine-readable status artifact; Truth Tools deterministically reviews the supplied artifact.
