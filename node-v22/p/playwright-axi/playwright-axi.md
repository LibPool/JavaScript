# playwright-axi

> 标签: agent-experience-interface, agents, axi, browser-automation, cli, playwright

## 简介

Agent-ergonomic browser automation over the Playwright engine — TOON output, combined operations, inline filtered snapshots. Wraps the `playwright` npm package's agent CLI.
