# promise-temp

> 标签: promises, temp, temporary, tmp

## 简介

Tool for making temporary files asynchronously that return Promises. Wraps node-temp module with Promises.

- 官网：https://github.com/mikaturunen/promised-temp
- 源码仓库：git://github.com/mikaturunen/promised-temp.git
- npm 页面：https://www.npmjs.com/package/promise-temp

- npm registry：https://registry.npmjs.org/promise-temp
