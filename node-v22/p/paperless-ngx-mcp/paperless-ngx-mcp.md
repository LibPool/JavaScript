# paperless-ngx-mcp

> 标签: ai, claude, document-management, mcp, model-context-protocol, paperless, paperless-ngx

## 简介

Model Context Protocol (MCP) server for Paperless-NGX. Lets AI assistants manage documents and their versions, tags, correspondents, document types, custom fields, saved views, storage paths, workflows, mail accounts and rules, share links and bundles, no
