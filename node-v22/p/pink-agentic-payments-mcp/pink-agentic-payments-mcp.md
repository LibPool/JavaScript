# pink-agentic-payments-mcp

> 标签: agent-payments, ai-agents, mcp, mcp-server, model-context-protocol, payments, pink, pinkwallet

## 简介

Local stdio MCP server that bridges any MCP client (Claude Desktop, Cursor, VS Code, Windsurf, n8n) to the Pink Agentic AI Payments remote MCP server.
