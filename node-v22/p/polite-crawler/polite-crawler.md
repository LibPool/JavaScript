# polite-crawler

> 标签: ai-agent, aipref, cache, claude, content-signals, crawler, fetch, fts5, full-text-search, headless, json-ld, llm, mcp, model-context-protocol, opening-hours, playwright, polite-crawler, research, rfc9309, robots.txt, schema.org, scraper, sqlite, web-crawler, web-scraping

## 简介

A polite web crawler for research and AI agents. It fetches a source once, keeps it, and reads it many times: robots.txt obeyed, one request per site, full-text search. The MCP server is the package polite-crawler-mcp.
