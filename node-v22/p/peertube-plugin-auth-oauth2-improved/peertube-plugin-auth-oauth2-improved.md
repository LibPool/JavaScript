# peertube-plugin-auth-oauth2-improved

> 标签: auth, oauth2, peertube, plugin

## 简介

A PeerTube server plugin that adds support for external authentication via an OAuth 2.0 provider. The callback URL path is /plugins/auth-oauth2/router/callback
