# pushenv

> 标签: cli, config, dotenv, env, environment, library, sync, typescript, validation, zod

## 简介

Pushenv is a simple, end-to-end encrypted CLI for sharing .env files safely across your team. Use as a library (dotenv alternative with validation) or CLI for team sync.
