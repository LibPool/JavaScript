# partweave

> 标签: boilerplate, cli, django, expo, full-stack, generator, monorepo, nextjs, scaffold, scaffolder

## 简介

A modular full-stack scaffolder — pick the parts you need (Django server, Next.js web, Expo mobile) and generate only that code, wired together.
