# puppetty

> 标签: ai-agent, automation, conpty, expect, pty, rust, terminal

## 简介

The terminal as an API: run interactive programs in controllable PTY sessions that AI agents can drive — prompts auto-answered by policy or LLM, secrets from the OS keyring, no more hangs.
