# phonegap-plugin-barcodescanner-asb

> 标签: cordova-android, cordova-browser, cordova-ios, cordova-windows, cordova:plugin, ecosystem:cordova, ecosystem:phonegap

## 简介

ASB-Fork, Don't Use! You can use the BarcodeScanner plugin to scan different types of barcodes (using the device's camera) and get the metadata encoded in them for processing within your application.
