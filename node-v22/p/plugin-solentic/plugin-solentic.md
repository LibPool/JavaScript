# plugin-solentic

> 标签: ai-agent, defi, elizaos, mcp, plugin, solana, staking

## 简介

Native Solana staking plugin for ElizaOS — stake, unstake, withdraw SOL with Blueprint validator. ~6% APY, zero custody.
