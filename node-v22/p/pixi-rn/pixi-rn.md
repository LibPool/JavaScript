# pixi-rn

> 标签: expo, expo-gl, game, pixi, pixijs, react-native, ui, webgl

## 简介

pixi.js v8 inside React Native on expo-gl: renderer bring-up, retained flex layout, federated native input, texture upload, bitmap text, a frame loop, expo-audio pooling, and a dtMs-driven tween.
