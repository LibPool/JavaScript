# portbridge

> 标签: backend, cli, cors, dev, dev-server, developer-tools, frontend, fullstack, log-aggregator, mern, pern, proxy

## 简介

One command to run your frontend + backend dev servers behind a single unified proxy port — no CORS setup, merged logs, and a live request dashboard.
