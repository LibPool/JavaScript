# pi-pii-mask

> 标签: mask, pi-extension, pi-package, pii, privacy, redaction, security, unmask

## 简介

Lightweight regex-based PII mask/unmask extension for Pi coding agent. Redacts emails, phones, SSNs, credit cards, API keys, and more before they reach the LLM. Restores originals in responses.
