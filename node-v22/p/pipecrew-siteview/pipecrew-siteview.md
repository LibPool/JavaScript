# pipecrew-siteview

> 标签: agents, claude, claude-code, dashboard, observability, pipecrew, sessions

## 简介

A live, machine-wide dashboard for native Claude Code sessions — see every running session, its token usage, and the sub-agents it has spawned, in real time.
