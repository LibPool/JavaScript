# playwright-soak

> 标签: cdp, chrome-devtools-protocol, e2e, gc, heap, leak, memory, memory-leak, memory-leak-detection, performance, playwright, soak-test, soak-testing, spa, stress-test, tanstack-intent, testing

## 简介

Catch memory leaks in Playwright tests. Repeat a user flow a few hundred times, force GC, and fail the test if DOM nodes, listeners or heap keep piling up.
