# pdf-render-pool

> 标签: chromium, concurrency, html-to-pdf, pdf, puppeteer, render-pool

## 简介

A persistent, concurrency-capped headless-Chromium HTML-to-PDF renderer built on Puppeteer — one warm browser instead of launching/tearing down Chromium per PDF.
