# purstags

> 标签: JavaScript

## 简介

A command line tool for generating Emacs tags for PureScript code independent from the \`docs\` component of the PureScript compiler. Instead, this project makes use of the [language-cst-parser](https://github.com/natefaubion/purecript-language-cst-parser
