# pi-live-models

> 标签: anthropic, model-discovery, models, openai-compatible, openrouter, pi, pi-extension, pi-package

## 简介

Live /v1/models discovery for pi — any OpenAI-compatible or Anthropic gateway, plus built-in provider catalog overrides. Config-driven filters, metadata merge ladder, credential reuse, offline cache.
