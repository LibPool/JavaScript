# portawhip

> 标签: agent-tools, ai-agents, claude-code, codex, developer-tools, gemini-cli, mcp, model-context-protocol, tool-router

## 简介

Tools collector + context-cheap router for AI agent hosts: dispatches capability install to add-mcp/mise/asm, then routes the right one at the right moment instead of loading everything into context.
