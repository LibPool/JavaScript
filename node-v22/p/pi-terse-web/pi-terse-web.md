# pi-terse-web

> 标签: extension, fetch, pi, pi-coding-agent, pi-package, search, web

## 简介

Lean web fetch + web search for the Pi coding agent: URL to clean markdown, query to results. One fetch, one timeout, no SSRF DNS gymnastics.
