# pi-tool-compact-display

> 标签: coding-agent, collapse, compact, diff, diff-visualization, hide, output-mode, output-truncation, pi, pi-coding-agent, pi-extension, pi-package, pi-tui, tool-output, tool-rendering, truncate, tui

## 简介

Fork of pi-tool-display (by MasuRii) with left-padding alignment tweaks. Compact tool call rendering, diff visualization, and output truncation extension for Pi coding agent. Hides, collapses, and truncates verbose tool output for cleaner TUI display.
