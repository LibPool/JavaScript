# pi-team-orchestration

> 标签: agent-skill, multi-agent, orchestration, pi, pi-package, pi-web

## 简介

A Pi skill for orchestrating multiple Pi Web sessions with isolated scopes, file-based handoffs, review gates, and low-frequency callbacks.
