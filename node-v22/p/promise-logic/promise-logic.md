# promise-logic

> 标签: async, async-programming, combinational, concurrency, logic, logic-gates, majority, nand, nor, promise, xnor, xor

## 简介

Compose promises with logic gate semantics (AND, OR, XOR, NAND, NOR, XNOR, Majority). Forget APIs, remember logic.
