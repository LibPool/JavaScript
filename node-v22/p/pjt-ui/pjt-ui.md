# pjt-ui

> 标签: framework, jquery, ui

## 简介

pjt-ui 是一款由公司项目独立出来的，基于jQyery开发的插件库。2016年上线，目前稳定使用已有4年多，丰富的接口，简单明了的调用方式，多个回调函数，让您轻轻松松打造出富有灵活交互的Web前端界面解决方案。
