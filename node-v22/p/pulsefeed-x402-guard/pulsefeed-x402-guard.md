# pulsefeed-x402-guard

> 标签: agents, ai-agents, base, crypto, guard, payments, safety, trust, usdc, x402

## 简介

Safety guard for x402 agent payments — verify an endpoint with PulseFeed before paying, and block dead / scam / risky x402 services automatically. ESM and CommonJS.
