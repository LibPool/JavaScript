# porteur-sdk

> 标签: ai-agents, file-request, human-in-the-loop, mcp, porteur

## 简介

TypeScript SDK for Porteur.ai, the human-input layer for AI agents. Request a file from a person, resume when they answer.

## 官网

- 官网：https://porteur.ai
- npm 页面：https://www.npmjs.com/package/porteur-sdk
