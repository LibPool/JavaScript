# pi-beer-promptbook

> 标签: injection, multilingual, pi-extension, pi-package, prompt, rules, system-prompt, task-routing

## 简介

Task-routed prompt profiles for Pi — a dumb registry: profiles are markdown files declaring a task; consumers ask resolveTask("task") and get the prompt. No roles, no decisions. — appends markdown rule profiles to the system prompt via the official before
