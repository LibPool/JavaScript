# pepiros-mcp

> 标签: ai-agent, citation, citation-verification, claude, claude-code, grounding, llm-tools, mcp, model-context-protocol, pdf, research-papers

## 简介

MCP server for Pepiros: search, verify, and cite claims against a paper's actual text over stdio -- quote-located grounding, not vector similarity.
