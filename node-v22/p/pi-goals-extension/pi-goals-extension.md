# pi-goals-extension

> 标签: goals, pi, pi-extension, pi-package, todo

## 简介

Standalone Pi extension for parent-owned goal/TODO work graphs with delegated claims, CAS receipts, and oracle-gated completion. Zero runtime dependencies.
