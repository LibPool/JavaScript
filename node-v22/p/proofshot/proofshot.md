# proofshot

> 标签: agent, ai, automation, browser, claude-code, codex, coding, copilot, cursor, proofshot, recording, screenshot, testing, verification, video, visual

## 简介

Open-source, agent-agnostic CLI for visual verification. Your AI coding agent builds a feature — ProofShot records video proof it works.
