# peasy-design-embed

> 标签: color, design, embed, gradient, palette, peasy, peasydesign.com, shadow, shadow-dom, typography, widget, zero-dependencies

## 简介

Embed PeasyDesign widgets on any website. Lightweight (<8KB gzipped), zero dependencies, Shadow DOM isolation, 3 themes.
