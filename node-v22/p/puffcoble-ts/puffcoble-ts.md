# puffcoble-ts

> 标签: ble, bluetooth, lorax, peak-pro, proxy, puffco, web-bluetooth

## 简介

TypeScript Web Bluetooth library for Puffco Peak Pro / Proxy over the Lorax protocol. Ported from github.com/Fr0st3h/PuffcoBLE with enhancements for Web Bluetooth.
