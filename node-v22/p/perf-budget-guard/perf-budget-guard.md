# perf-budget-guard

> 标签: bundle-size, core-web-vitals, github-action, lighthouse, performance, performance-budget, pull-request

## 简介

Compare a pull request's bundle size and Lighthouse metrics against main, check them against a budget, and post one readable PR comment.
