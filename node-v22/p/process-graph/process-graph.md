# process-graph

> 标签: dependency-graph, flowchart, process-model, sequence-diagram, state-machine, swimlane

## 简介

A process and dependency graph model with projections into flowcharts, swimlanes, state machines and sequence diagrams, reasoning over a run, layout, the GitHub issues source, the SQLite store for Node and the browser, and the process-graph command line,
