# priam-cassandra-cql

> 标签: priam

## 简介

Node.js driver for Apache Cassandra - fork from node-cassandra-cql that includes Kit Cambridge's normalize-typed-value-v1 branch for the binary v1 protocol. Specifically used for the Go Daddy Priam driver.
