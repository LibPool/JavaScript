# pdfzus-cli

> 标签: cli, jpg-zu-pdf, pdf, pdf-komprimieren, pdf-trennen, pdf-zusammenfuegen, pdfzus

## 简介

Deutsche CLI fur pdfzus-Core: PDF zusammenfugen, komprimieren, trennen, Seiten organisieren und JPG zu PDF umwandeln.
