# poi-plugin-sortie-lock

> 标签: kancolle, poi, poi-plugin, sortie, taiha

## 简介

Block the in-game advance and sortie buttons when the fleet has heavily damaged ships, and the sortie button when Akashi / Nozaki leads the fleet
