# pi-402

> 标签: JavaScript

## 简介

Pi Agent 402 extension: pay-per-request access to OpenAI-compatible inference providers that support 402 payment protocols (L402, x402, MPP), settled over a Nostr Wallet Connect (NWC) Lightning wallet.
