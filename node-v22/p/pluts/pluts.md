# pluts

> 标签: accounting, bookkeeping, cloudflare, double-entry, durable-objects, ledger, sqlite, typescript

## 简介

A double-entry accounting ledger for TypeScript, targeting Cloudflare Durable Objects (SQLite-backed storage).
