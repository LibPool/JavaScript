# pi-codemode-guard

> 标签: agentic-coding, ai-agent, ai-sdk, await, cloudflare, codemode, codex, compiler, deepseek, dialect, llm, openai, opencode, pi-extension, pi-package, ptc, quickjs, tanstack, tool-calling, tool-guard, transpiler, typescript, vercel

## 简介

Pi extension that compiles LLM codemode scripts into pi's QuickJS-sandbox JavaScript: adds missing await, strips markdown fences, converts JSON tool-call programs, and translates OpenCode, Codex, Cloudflare, TanStack, Vercel, DeepSeek PTC dialects
