# pi-tinymemory

> 标签: coding-agent, memory, pi, pi-package, tinymemory

## 简介

Tiny, fast, local long-term memory for the Pi coding agent. Memories saved by past sessions auto-load at session start. One Rust binary + plain Markdown files — no daemon, no DB, no MCP, no API keys.
