# pi-vlm-proxy

> 标签: describe-image, image-analysis, multimodal, openai-compatible, pi-extension, pi-package, vision, vlm

## 简介

Generic vision proxy extension for pi: lets non-multimodal models (e.g. DeepSeek) delegate image analysis to ANY OpenAI-compatible multimodal model. Zero vendor hardcoding - a model is just baseUrl + apiKey + model id. Auto-hides itself when the main mode
