# process-builder

> 标签: ai, llm, prompt, typescript

## 简介

ProcessBuilder 是一个由 AI 驱动的流程构建器，为应用提供自然语言接口，自动构建并调用应用中的功能。为开发人员提供无缝的流程构建接口，只需定义好基本的节点，剩下的交给 ProcessBuilder 。
