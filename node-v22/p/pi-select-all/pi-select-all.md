# pi-select-all

> 标签: clipboard, editor, input, pi, pi-package, select-all, tui

## 简介

Real select-all for pi's prompt editor: Ctrl+Alt+A highlights the whole prompt as a selection; typing replaces it, Ctrl+C copies, Ctrl+X cuts.
