# prerender-crawler

> 标签: build-time, crawler, prerender, prerendering, ssg, static site generation, vite, vite-plugin

## 简介

Framework-agnostic build-time prerendering. Point it at anything fetch-shaped (Request in, Response out) and it crawls the site into static HTML: seeds, link discovery, header hints, redirects, retries, throttling, and an integration seam for build-time d
