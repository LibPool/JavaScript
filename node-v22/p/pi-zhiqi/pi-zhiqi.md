# pi-zhiqi

> 标签: catalog, chinese, i18n, installer, pi, pi-extension, pi-package, pi.dev, search, tui

## 简介

把 pi.dev 包目录搬进 pi TUI：搜 → 选 → 装到当前项目。结果描述自动翻成简体中文，中文关键词也能搜。Zero-dependency, zero-startup-cost pi.dev catalog browser for pi — search, pick, install into the current project, with Simplified-Chinese descriptions.
