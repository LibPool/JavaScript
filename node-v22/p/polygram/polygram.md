# polygram

> 标签: bot, claude, claude-code, daemon, history, multi-bot, openclaw, openclaw-migration, per-chat-session, sqlite, telegram, telegram-agent, transcript

## 简介

Telegram daemon for Claude Code that preserves the OpenClaw per-chat session model. Migration path for OpenClaw users moving to Claude Code.
