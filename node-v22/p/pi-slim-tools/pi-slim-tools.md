# pi-slim-tools

> 标签: cli, compact-output, pi, pi-coding-agent, pi-extension, pi-package, pi-slim, productivity, slim-tools, terminal, tool-collapse, tui

## 简介

Pi 扩展：将 bash/read/edit/write/grep/find/ls 的输出压缩为单行摘要，终端更清爽。按 Ctrl+O 展开。
