# pict-provider-keybindings

> 标签: JavaScript

## 简介

Pict provider for centralized browser keyboard shortcuts — a registry of keystroke -> function-or-route bindings, each with a name, description, and optional help link. Views register/deregister bindings in their lifecycle; a built-in cheatsheet overlay s
