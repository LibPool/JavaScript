> 标签: chat-history, coding-agent, context-window, conversation-history, hide-messages, messages, pi, pi-coding-agent, pi-extension, pi-package, pi-tui, restore-messages, session-context, transcript, tui

## 简介

Pi extension: keep only the latest N TUI messages visible (old entries stay in the session file). Fork of pi-hide-messages adapted for pi 0.84+.
