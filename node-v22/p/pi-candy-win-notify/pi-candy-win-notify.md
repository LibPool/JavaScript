# pi-candy-win-notify

> 标签: notification, pi-extension, pi-package, windows, wpf

## 简介

pi 的 Windows 桌面通知与终端标签页状态显示工具 — 快速聚焦、回复预览、耗时显示、勿扰、多语言、任务四态实时可见
