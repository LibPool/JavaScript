# puppet-master

> 标签: JavaScript

## 简介

- Execute Node.js code in Chrome using [`puppeteer`](https://github.com/GoogleChrome/puppeteer). - Bundles Node.js module into Chrome using [`parcel`](https://github.com/parcel-bundler/parcel).
