# pictures.js

> 标签: 3d, animation, canvas, creative-coding, education, games, graphics, sprites, three.js

## 简介

Write a short JavaScript file and it draws: 2D canvas and three.js scenes with setup(), update(dt) and draw(), nothing to import. The JavaScript sibling of Pyctures.
