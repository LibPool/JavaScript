# permid-tagger

> 标签: opencalais, permid, tagger

## 简介

A simple tagger for the permid.org API. Using intervals, it allows you to make up to 500 requests with one function call. Simply pass in a file of your choosing, pick a field which you would like to see tagged and the tagger will return a list of tags. Wh
