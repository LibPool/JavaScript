# paperclip-adapter-live-agent

> 标签: agents, claude-code, hermes, mailbox, ollama, paperclip, paperclip-adapter

## 简介

Hire agents that are already awake in their own harness (Claude Code, Hermes, grok, opencode, Ollama, anything that can make an HTTP request) into Paperclip through a mailbox. Paperclip holds no provider logins.
