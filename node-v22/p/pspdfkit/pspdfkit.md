# pspdfkit

> 标签: angular, backbone, ember, jquery, pdf, pdf sdk, pdf wasm, pdf webassembly, pdf.js, react, sdk, vue, web-sdk, webassembly

## 简介

View and annotate PDF files in your web app. Full support for mobile and desktop. Runs in the browser using WASM.
