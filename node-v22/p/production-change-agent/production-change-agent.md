# production-change-agent

> 标签: cli, film-production, human-in-the-loop, mcp, scheduling

## 简介

AI Production Change Agent: a local console, REST API, and MCP server that analyse a film production change and apply it only after human approval. Runs on a clean machine with npx and no paid service.
