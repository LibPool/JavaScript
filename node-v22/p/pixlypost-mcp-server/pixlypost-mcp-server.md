# pixlypost-mcp-server

> 标签: ai-agents, claude, mcp, modelcontextprotocol, pixlypost, social-media

## 简介

MCP server for PixlyPost — lets Claude, Cursor, and other MCP-capable AI assistants call the PixlyPost HTTP API on the user's behalf. The API key lives in the OS keychain (via `pixlypost-mcp-server login`); the AI never sees it.
