# protractor-fix-starting-from-115-chrome

> 标签: angular, selenium, test, testing, webdriver, webdriverjs

## 简介

Webdriver E2E test wrapper for Angular with a fix to solve the issue starting from 115 chrome. Here is more information about the changes from 115 chrome: https://developer.chrome.com/docs/chromedriver/downloads/version-selection.
