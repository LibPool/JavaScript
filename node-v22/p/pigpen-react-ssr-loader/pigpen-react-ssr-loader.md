# pigpen-react-ssr-loader

> 标签: loader, webpack

## 简介

pigpen-koa使用的react服务端渲染webpack loader，源于easy-team/react-entry-template-loader，按个人喜好做了细微调整，解除对easy-webpack的依赖。

## 官网

- 官网：https://github.com/xiek881028/pigpen-react-ssr-loader
- npm 页面：https://www.npmjs.com/package/pigpen-react-ssr-loader

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install pigpen-react-ssr-loader`
- npm registry：https://registry.npmjs.org/pigpen-react-ssr-loader
- Node 要求：>=6.0.0
