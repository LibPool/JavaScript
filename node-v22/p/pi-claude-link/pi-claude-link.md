# pi-claude-link

> 标签: agent-mesh, claude-code, inter-agent-messaging, pi-coding-agent, pi-extension, pi-package

## 简介

Mesh pi coding-agent sessions with Claude Code: appear in each other's session lists and exchange messages over Claude's cross-session socket protocol.
