# payload-icon-picker

> 标签: icon-picker, icons, payload, payload-plugin, payloadcms, react-icons, svg

## 简介

A dynamic icon picker field plugin for Payload CMS 3.0 supporting custom icon packs, searching, and custom SVG rendering.
