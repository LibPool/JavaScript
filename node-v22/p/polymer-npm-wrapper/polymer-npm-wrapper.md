# polymer-npm-wrapper

> 标签: component, components, module, modules, npm, polymer, unofficial, web, webcomponent, webcomponents, wrapper

## 简介

Unofficial wrapper for getting latest version of Polymer from Git as NPM dependency and exporting it as ES2015 module.
