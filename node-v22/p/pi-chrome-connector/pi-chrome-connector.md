# pi-chrome-connector

> 标签: browser, browser-automation, cdp, chrome, chrome-extension, devtools, pi, pi-coding-agent, pi-extension, pi-package, screenshot

## 简介

Agent-first Chrome connector for pi: drive your real Chrome (tabs, keyboard and mouse, screenshots, console, network, request mocking) through a companion extension.
