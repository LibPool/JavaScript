# pi-editor-plus

> 标签: caret, mouse, pi-coding-agent, pi-extension, selection, tui

## 简介

Editing upgrades for the pi coding agent prompt editor: mouse click-to-caret, drag-to-select with copy, and undo/redo (regular + fullscreen TUI)
