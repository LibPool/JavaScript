# posekit

> 标签: animation, exercise, fitness, inverse-kinematics, procedural, range-of-motion, rehabilitation, svg

## 简介

Procedural 2D figure animation for exercise demonstration. Generates poses from joint angles at runtime, so range of motion, tempo and load are parameters rather than pre-rendered frames.
