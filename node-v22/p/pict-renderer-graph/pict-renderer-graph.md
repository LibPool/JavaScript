# pict-renderer-graph

> 标签: JavaScript

## 简介

Headless Excalidraw rendering as a fable service. JSON graph in, hand-drawn SVG (or PNG) out. Drives a pre-warmed Chromium for ~30ms-per-diagram throughput. Usable as a library, CLI, or HTTP service.
