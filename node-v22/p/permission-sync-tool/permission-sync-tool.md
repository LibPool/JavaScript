# permission-sync-tool

> 标签: authorization, casl, cli, nestjs, permissions, prisma, rbac, react, roles, typescript

## 简介

A powerful CLI tool and utility library for syncing roles and permissions to your Prisma database and generating CASL abilities for NestJS and React applications.
