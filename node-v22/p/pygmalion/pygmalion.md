# pygmalion

> 标签: JavaScript

## 简介

Pygmalion：将 DeepSeek Harness（dsh）改造为「拟真 AI 好友」服务的 dsh 插件——QQ 官方机器人接入、文件系统双索引长期记忆、heartbeat+脚本+hook 主动交互，一次安装即用（含管理网页）
