# pi-model-staging

> 标签: model-ladder, model-staging, pi-extension, pi-package, plan-mode

## 简介

A pi extension that adds plan-then-implement mode with a single model ladder. Steps the model and thinking level down as the LLM grinds autonomously, snaps back to the snappy tier when control returns to the user.
