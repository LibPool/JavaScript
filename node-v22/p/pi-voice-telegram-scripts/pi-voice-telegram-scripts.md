# pi-voice-telegram-scripts

> 标签: JavaScript

## 简介

Runtime shell scripts for the pi-voice-telegram stack. The Pi agent + @llblab/pi-telegram bridge call these from telegram.json#outboundHandlers[0].template to synthesize voice replies. Pure Node.js / bash, no build step. The two .mjs files are the canonic
