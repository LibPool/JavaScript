# pi-a2a-adaptor

> 标签: a2a, agent-protocol, agent2agent, pi-extension, pi-package

## 简介

A2A extension for Pi — `pi install npm:pi-a2a-adaptor`, then `/a2a-send` by name, URL, or agent number
