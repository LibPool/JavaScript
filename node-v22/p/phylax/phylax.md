# phylax

> 标签: csv, placeholder, privacy, sanitizer, security

## 简介

Name-reservation placeholder for Phylax, a privacy-first, browser-only CSV sanitizer by Phylaxis Labs. The actual product is distributed as a single self-contained HTML file, not via npm. See https://phylaxislabs.com once the site is live.
