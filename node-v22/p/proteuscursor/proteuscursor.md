# proteuscursor

> 标签: JavaScript, UI, UX, animation, css, cursor, cursor effects, custom cursor, dynamic, frontend, hover, html, interaction, interactivity, mouse, shape, user interface, visual effects, web design, web development

## 简介

Zero-dependency shapeshifting cursor library. Two modes — circle and fluid — state machine, built-in presets, blend mode, click animations, and first-class adapters for React, Vue 3 and Svelte.
