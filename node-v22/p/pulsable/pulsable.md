# pulsable

> 标签: pulsable, skeleton, skeleton-component, skeleton-content, skeleton-content-loader, skeleton-effect, skeleton-loader, skeleton-loading

## 简介

A simple and customizable JavaScript library to add a pulsing/skeleton loading effect to your specific html section.
