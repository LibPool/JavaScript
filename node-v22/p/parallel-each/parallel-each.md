> 标签: array, async, asynchronous, concurrent, each, flow, forEach, iterate, iteration, loop, map, max-degrees-of-parallelism, parallel

## 简介

A parallel, asynchronous implementation of forEach in ES6 with a configurable maximum degree of parallelism.
