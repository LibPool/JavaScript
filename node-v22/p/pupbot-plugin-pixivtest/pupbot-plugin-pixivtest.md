# pupbot-plugin-pixivtest

> 标签: JavaScript

## 简介

复制粘贴自[kivibot-plugin-qnets-pixiv](https://www.npmjs.com/package/kivibot-plugin-qnets-pixiv)，个人权限是插件权限体系的基础，即**必须配置**个人权限来使插件功能正常运作，群组权限决定**在群组内个人权限是否生效**，建议运行一次后编辑 `框架目录/data/plugins/pixivtest/config.json` 文件，快速设置。
