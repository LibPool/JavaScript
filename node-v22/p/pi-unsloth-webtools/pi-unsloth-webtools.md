# pi-unsloth-webtools

> 标签: coding-agent, duckduckgo, extension, pi, pi-package, ssrf, unsloth, web-fetch, web-search

## 简介

Pi extension: web_search and web_fetch tools that began as a port of the Unsloth Studio codebase and now diverge from it (multi-engine search, opt-in SSRF guard, HTML-to-Markdown extraction)
