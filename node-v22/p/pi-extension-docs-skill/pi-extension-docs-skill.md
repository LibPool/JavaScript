# pi-extension-docs-skill

> 标签: ai, coding-agent, docs, llm, pi, pi-extension, pi-package, skill

## 简介

pi 插件：把系统提示里的 pi 文档注入块转成 pi-docs 技能文件，一次注入、每次会话复用，省下每次请求重复携带的文档 token。
