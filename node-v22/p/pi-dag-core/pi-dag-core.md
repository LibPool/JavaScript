# pi-dag-core

> 标签: dag, orchestration, pi, pi-extension, pi-package, state-machine, subagents, workflow

## 简介

Production-ready DAG workflow state machine for pi: AI orchestrates, human approves, agents follow the protocol. Execution via the subagent tool, correctness via CI-style evidence gates (state machine + payload attribution + artifact verification).
