# pgrls-test

> 标签: drizzle, postgres, postgresql, rls, row-level-security, supabase, testing, vitest

## 简介

Code-first RLS testing for Postgres — TypeScript port of pgrls.testing. Implements the cross-language Layer 1 protocol (PROTOCOL_VERSION 1).
