# pauschbetrag-api

> 标签: API, Pauschalen, Reisekostenabrechnung

## 简介

Pauschbeträge für Verpflegungsmehraufwendungen und Übernachtungskosten für beruflich und betrieblich veranlasste Auslandsdienstreisen.
