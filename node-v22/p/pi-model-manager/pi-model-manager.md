# pi-model-manager

> 标签: anthropic, client-headers, model-manager, models-json, openai, pi, pi-extension, pi-package, provider-manager

## 简介

A TUI model and provider manager for Pi with native models.json persistence, request-header profiles, proxy routing, and protocol compatibility.
