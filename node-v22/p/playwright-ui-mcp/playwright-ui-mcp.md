# playwright-ui-mcp

> 标签: anthropic, browser-automation, claude, headed-browser, mcp, model-context-protocol, playwright, screenshot, ui-testing, web-automation

## 简介

Lightweight MCP server for headed browser UI capture and analysis using Playwright. Supports screenshots, video recording, and browser automation for Claude.
