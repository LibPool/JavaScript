# peckish-mcp

> 标签: agent, ai, anthropic, claude, doordash, food-delivery, mcp, mcp-server, modelcontextprotocol, ordering

## 简介

MCP server that lets Claude order food on DoorDash — search, compare real fee-included totals, build carts, and place orders behind a human approval dialog.
