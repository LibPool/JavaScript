# pi-secret-guard

> 标签: api-key, devops, git, github, pi, pi-extension, pi-package, pre-commit, secret-detection, secret-scanning, security, security-tools

## 简介

A pi extension that guards against committing secrets, API keys, and credentials to git repositories using hybrid regex + LLM review.
