# popular-web-fonts-woff2

> 标签: cli, conversion, fonts, google-fonts, popular-fonts, ttf, web-fonts, webfont, woff2

## 简介

CLI pipeline for downloading popular web fonts and converting them from TTF/OTF to WOFF2 assets.
