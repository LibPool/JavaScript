# pinta-companion

> 标签: ai, annotation, chrome-extension, claude-code, mcp, pinta, ui-edit

## 简介

Companion server for the Pinta browser-annotation workflow. Bridges the Pinta Chrome extension and your coding agent (Claude Code, Cursor, Aider) so visual annotations turn into source-file edits.
