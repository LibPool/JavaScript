# pi-cursor-reins

> 标签: agent, cursor, mcp, pi, pi-extension, pi-package, provider

## 简介

Cursor provider for pi: fully Pi-owned tool execution (no Cursor-side exec, audited) using your Cursor subscription quota. AgentService channel by default, optional RunInference.
