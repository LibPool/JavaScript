# pagefire-mcp

> 标签: mcp, model-context-protocol, pagefire, publishing, stdio

## 简介

stdio MCP connector for PageFire — bridges your MCP client to the hosted PageFire endpoint over Node's TLS stack, sidestepping client-runtime TLS quirks (e.g. Bun) and network fingerprint filtering.
