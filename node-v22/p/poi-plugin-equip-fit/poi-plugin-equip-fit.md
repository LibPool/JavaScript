# poi-plugin-equip-fit

> 标签: equipment, kancolle, poi, poi-plugin, 装备适配

## 简介

查「谁能装这件装备」：按对陆 / 反潜 / 司令部 等特殊装备类别筛选，区分已拥有/未拥有的舰，并考虑补强增设槽（打孔）。数据全部来自游戏主数据，不联网。
