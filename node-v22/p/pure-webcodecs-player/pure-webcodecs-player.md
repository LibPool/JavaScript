# pure-webcodecs-player

> 标签: audio, demuxer, esm, flv, hls, mkv, mp4, mse, player, ts, video, webcodecs

## 简介

纯前端媒体播放器：Container 解析 → Demux → WebCodecs 解码 → Canvas/AudioWorklet 渲染。零构建、纯 ESM、零第三方运行时依赖（下一代 ffplay.js 方向）
