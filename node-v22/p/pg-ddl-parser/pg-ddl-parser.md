# pg-ddl-parser

> 标签: database, ddl, erd, migration, parser, pg, postgres, postgresql, schema, sql

## 简介

Zero-dependency PostgreSQL DDL parser for PG12-PG19. Converts CREATE/ALTER/DROP SQL into a structured schema model.
