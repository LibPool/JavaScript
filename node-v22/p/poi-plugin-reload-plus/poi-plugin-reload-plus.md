# poi-plugin-reload-plus

> 标签: hotkey, kancolle, mouse, poi, poi-plugin, reload

## 简介

Reload+ for poi: fast game-frame reload with instant-persist settings, keyboard/Mouse4/Mouse5 shortcuts, optional guarded Mouse2 binding, floating panel, and configurable reload-button color.
