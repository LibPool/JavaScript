# pi-c2c

> 标签: agents, c2c, messaging, pi, pi-extension, pi-package, swarm

## 简介

Native c2c for Pi — anywhere-to-anywhere messaging between AI coding agents. Adds c2c send/list/rooms tools, slash commands, and background auto-delivery of inbound messages straight into pi's transcript.
