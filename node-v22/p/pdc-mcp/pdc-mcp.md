# pdc-mcp

> 标签: claude, coolify, cursor, deploy, mcp, model-context-protocol, pdc

## 简介

Servidor MCP do PDC Deploy — opere o PDC (criar projetos, deployar, acompanhar builds) pelo seu agente de IA, com login por device code e segredos fora do chat.
