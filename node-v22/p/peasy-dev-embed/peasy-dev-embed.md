# peasy-dev-embed

> 标签: dev, developer, diff, embed, formatter, json, peasy, peasydev.com, regex, shadow-dom, widget, yaml, zero-dependencies

## 简介

Embed PeasyDev widgets on any website. Lightweight (<8KB gzipped), zero dependencies, Shadow DOM isolation, 3 themes.
