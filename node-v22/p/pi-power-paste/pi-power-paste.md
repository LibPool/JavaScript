# pi-power-paste

> 标签: clipboard, image-attachments, opencode, paste, pi-extension, pi-package, windows

## 简介

OpenCode-grade clipboard paste for pi on Windows: instant Ctrl+V image attachments, Explorer file drops as collapsible blocks, large-text collapsing, persistent clipboard helper
