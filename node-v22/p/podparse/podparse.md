# podparse

> 标签: atom, feed, googleplay, itunes, javascript, node, nodejs, parse, parser, podcast, podcast-aggregator, podcast-client, rss, xml

## 简介

A simple package for parsing podcast RSS feeds into manageable JavaScript objects. For use with Node and in the browser.
