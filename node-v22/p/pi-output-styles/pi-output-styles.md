# pi-output-styles

> 标签: extension, oh-my-pi, omp, output-styles, persona, pi, pi-package, system-prompt

## 简介

Named, swappable system-prompt styles for Oh My Pi (OMP) and Pi — live /style switcher that replaces the personality slot.
