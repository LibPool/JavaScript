# pi-bidi

> 标签: arabic, bidi, hebrew, persian, pi-coding-agent, pi-extension, pi-package, rtl, terminal, unicode

## 简介

Renders right-to-left text (Hebrew, Arabic, Persian) correctly in Pi on terminals without bidi support.
