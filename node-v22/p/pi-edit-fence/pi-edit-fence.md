# pi-edit-fence

> 标签: concurrency, file-lock, pi, pi-extension, pi-package, worktree-free

## 简介

Stop concurrent pi sessions from clobbering each other's edits. Per-file locks, auto-claim on edit, retry-later, lease expiry, crash recovery. No git worktrees.
