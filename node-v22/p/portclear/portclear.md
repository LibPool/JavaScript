# portclear

> 标签: cross-platform, go, java, kill, kill-port, killport, linux, mac, node, pkill-port, port, port-eject, port-kill, port-nuke, port-range, portclear, portstop, process, python, tcp, typescript, udp, universal, unix, windows, zero-dependency

## 简介

Kill process running on any given port. Works with Node.js, Python, Go, Java, and any language. Zero dependencies, cross-platform support for Windows, macOS, Linux & Unix.
