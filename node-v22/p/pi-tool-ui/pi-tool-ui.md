# pi-tool-ui

> 标签: coding-agent, compact, fff, pi, pi-coding-agent, pi-extension, pi-package, rendering, theme, tui

## 简介

Claude Code-style tool rows for the Pi coding agent, covering built-in and third-party tools alike. Rendering only: no configuration, no hidden tools, no changes to agent behaviour.
