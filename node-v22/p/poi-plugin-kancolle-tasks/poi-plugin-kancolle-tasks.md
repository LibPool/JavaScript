# poi-plugin-kancolle-tasks

> 标签: kancolle, poi, poi-plugin, quest

## 简介

在 POI 内一键打开《舰队Collection 定期任务总览》（出击含周常 / 演习 / 远征 / 工厂 / 改装；疲劳·破损一目了然的精简舰队面板 + 大破禁止出击警告 + 可拖动、可自动关闭的接取提示弹窗；夜间主题 + 自定义背景）
