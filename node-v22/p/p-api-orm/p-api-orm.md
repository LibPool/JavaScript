# p-api-orm

> 标签: JavaScript

## 简介

`p-api-orm` 是一个基于 Knex 和 Zod 的轻量 TypeScript ORM 封装。它不负责创建数据库连接，也不负责迁移表结构；调用方需要自己初始化 Knex，并把 Knex 实例传给 `Model` 或 `ViewModel` 的方法。
