# page-lifecycle-tracker

> 标签: back-forward-cache, bfcache, browser, freeze, opentelemetry, page lifecycle api, page-lifecycle, pagehide, pageshow, real-user-monitoring, resume, rum, telemetry, visibilitychange, web-vitals

## 简介

The Page Lifecycle state of a web page (active, passive, hidden, frozen, terminated) for monitoring and telemetry libraries: one shared tracker for the page, observers before exporters, back/forward cache restores, and marks.
