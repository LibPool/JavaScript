# pi-feishu-link

> 标签: bot, bridge, feishu, lark, pi, pi-extension, pi-package

## 简介

High-reliability Feishu/Lark bridge for Pi — zero-config onboarding, persistent outbox (at-least-once), streaming output, native pi command adapter, permission bridge, one-click diagnostics
