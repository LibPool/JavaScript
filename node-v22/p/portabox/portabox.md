# portabox

> 标签: blink, browser, linux, microvm, sandbox, wasm, x86_64

## 简介

Self-contained sandbox SDK: run a real x86_64 Linux userspace in the browser or Node, with no server and no network — backed by the webix Blink WASM emulator.
