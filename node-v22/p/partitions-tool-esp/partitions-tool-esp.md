# partitions-tool-esp

> 标签: esp-idf, esp32, fatfs, firmware, flash, littlefs, nvs, partition-table, spiffs

## 简介

Pure TypeScript library to generate and parse ESP-IDF partition tables, NVS, SPIFFS and FatFS partition images (Node + Browser).
