# proxy-ip-pricing-cn

> 标签: china, dataset, ip-proxy, l2tp, open-data, pricing, proxy, proxy-ip, residential-proxy, socks5

## 简介

Open dataset as a package: monthly price ranges, protocol support, coverage and official registration links for 18 proxy IP providers serving the Chinese market. Ships JSON + CSV, zero dependencies.
