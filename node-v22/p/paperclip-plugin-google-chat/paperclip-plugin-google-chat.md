# paperclip-plugin-google-chat

> 标签: agents, chatops, google-chat, google-workspace, paperclip, paperclip-plugin

## 简介

Bidirectional Google Chat integration for Paperclip — post agent/issue notifications to spaces and drive Paperclip from Chat slash commands.
