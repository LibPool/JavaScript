# portmind-cli

> 标签: cli, dev-server, devtools, docker, eaddrinuse, lsof, port, port-conflict, port-scanner

## 简介

Local-first CLI that scans listening ports, enriches them with process/Docker/IANA detail, and remembers what normally runs where.
