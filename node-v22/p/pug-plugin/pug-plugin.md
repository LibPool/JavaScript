# pug-plugin

> 标签: bundle, bundler, css, entry, entrypoint, html, integrity, javascript, js, loader, markdown, plugin, pug, script, scss, style, template, webpack

## 简介

Pug plugin for webpack handles a template as an entry point, extracts CSS and JS from their sources referenced in Pug.
