# pi-gortex

> 标签: code-graph, gortex, mcp, pi-extension, pi-package

## 简介

Gortex for Pi: high-performance code-intelligence engine for AI agents, based on graph. Exposes only the information the agent needs, cutting token usage up to 50x. 100% local.
