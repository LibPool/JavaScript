# @ajentify/sdk

> 标签: agents, ai, ajentify, llm, sdk, structured-output, tools

## 简介

Official TypeScript SDK for the Ajentify API. A clean, uniform wrapper over agents, contexts, tools, structured responses, data windows, API keys, JSON documents and models with Zod-first schemas.
