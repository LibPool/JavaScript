# @mt3o/middleware-pipe

> 标签: clean-architecture, compose, composition, middleware, middleware-stack, onion, pipeline, registry, schema-validation, type-safe, typescript, zod

## 简介

Type-safe middleware composition for TypeScript: onion-model stacks with optional Zod schema validation between layers and a lazy-loading registry.
