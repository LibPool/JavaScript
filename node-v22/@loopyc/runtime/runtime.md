# @loopyc/runtime

> 标签: agent, agent-loop, automation, bounded, crash-resumable, durable-execution, llm, loopspec

## 简介

The durable execution engine for Monkey D Loopy standalone loop artifacts: event-sourced journal, deterministic replay, idempotent effects, hard caps, durable sleep + breakpoints.
