# @potswap_io/sdk

> 标签: ai-agent, defi, jupiter, potswap, sdk, solana, swap

## 简介

Potswap SDK: best-route Solana swaps with hard spending limits, transfers, wallet, strategies (DCA / rebalance / TP-SL / limit) and POT rewards. The engine behind @potswap_io/mcp and the potswap CLI. Non-custodial.
