# @potswap_io/cli

> 标签: ai-agent, cli, jupiter, potswap, solana, swap

## 简介

potswap: command-line Solana swaps, transfers, wallet, strategies and POT rewards on the Potswap engine. Same limits and fee as the MCP server.
