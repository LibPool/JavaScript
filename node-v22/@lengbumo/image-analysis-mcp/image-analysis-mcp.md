# @lengbumo/image-analysis-mcp

> 标签: ai, doubao, image-analysis, llm, mcp, model-context-protocol, openai, vision, volcengine

## 简介

通用视觉模型 MCP Server —— 为无视觉能力的 LLM 提供图片识别能力。默认使用火山引擎豆包，支持任意 OpenAI 兼容视觉 API（自定义 base_url / model / api_key）
