# @haruhimemoe/brand

> 标签: brand, haruhime, icon, opengraph, osu, osu!, svg, wordmark

## 简介

Brand kit generator for the haruhime.moe osu! tools: palettes from one hue, Nunito wordmarks, monogram icons and README banners as outlined SVG, and the PNG icons and link previews Next.js serves as static files.
