# @haruhimemoe/messages

> 标签: haruhime, i18n, icu, messages, next-intl, osu, translations

## 简介

The translation catalogs for the haruhime.moe tools and the harumin bot: one ICU message catalog per app and locale, English as the source, missing keys falling back to English. Loaders shaped for next-intl through @haruhimemoe/next-kit. No dependencies.
