# @crowi/plugin-renderer-crowi-legacy

> 标签: JavaScript

## 简介

Crowi v1 compatibility quirks aggregator for Crowi 2.x. Fixes actual v1 idiosyncrasies (e.g. `##hoge` heading-without-space) that are NOT standard markdown. The single-newline → <br> behaviour shipped here in earlier dev iterations is now a Crowi-wide def
