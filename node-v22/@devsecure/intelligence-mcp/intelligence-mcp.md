# @devsecure/intelligence-mcp

> 标签: cisa-kev, cve, epss, mcp, model-context-protocol, prioritisation, security, vulnerability

## 简介

MCP server for DevSecure Intelligence: rank CVEs by real-world risk (RPS from CVSS, EPSS and CISA KEV) from Claude Desktop, Cursor, Continue, Cline and other MCP clients.
