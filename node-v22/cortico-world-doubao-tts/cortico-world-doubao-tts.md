# cortico-world-doubao-tts

> 标签: coopanion, cortico, cortico-world, doubao, tts, voice, volcengine, 方言, 语音合成, 豆包语音

## 简介

让桌宠用豆包（火山引擎）TTS 2.0 读出气泡内容：360 个 2.0 音色可按场景、语种、标签筛选，支持语音指令（方言/情绪）与语速、音量、音调、句尾静音调节，本机播放。
