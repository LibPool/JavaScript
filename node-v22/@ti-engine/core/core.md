# @ti-engine/core

> 标签: distributed-systems, framework, ioredis, message-queue, messaging, microservice-framework, microservices, node, redis

## 简介

Microservice framework for Node.js: a Redis-backed message exchange with end-to-end call tracing, retries and tamper-evident message envelopes.
