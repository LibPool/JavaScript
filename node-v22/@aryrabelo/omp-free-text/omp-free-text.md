# @aryrabelo/omp-free-text

> 标签: extension, free-text, notes, oh-my-pi, omp, pi, plugin, scratchpad

## 简介

OMP harness extension: a free-text session-notes panel below the status line with a prompt queue and cross-session note browsing, persisted per repo/branch/session.
