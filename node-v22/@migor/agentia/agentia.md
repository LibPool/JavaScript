# @migor/agentia

> 标签: agent, anthropic, claude, decorators, di, framework, llm

## 简介

面向应用开发的声明式 agent 服务开发框架：装饰器 + DI 声明四类能力，主 agent 编排执行；每次 run 产出结构化结果与可观测调用树（trace、成本、指标），交付可直接上线的服务。
