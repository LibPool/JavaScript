> 标签: audio, audio input, linear16, mickit, microphone, pcm, pcm16, wav, web audio, web audio api

## 简介

## 📚 **Overview** `@mickit/input` is a simple and lightweight library for capturing audio input from the microphone. It provides a simple API to listen to audio chunks, detect silence, and adjust the gain automatically.
