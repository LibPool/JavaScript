# store-rbac-bootstrap-node

> 标签: bootstrap, contextProvider, jwt, nodejs-store, rbac, skin

## 简介

Optional skin-layer bootstrap for common-store RBAC: policy bootstrap (setRbac + role-rule configs) and credential-to-context factories (JWT / API-Key / Session) for the contextProvider seams of store-api / store-grpc / store-graphql
