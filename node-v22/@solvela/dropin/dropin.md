# @solvela/dropin

> 标签: claude-code, payment-channel, sidecar, solana, usdc, x402

## 简介

Claude Code drop-in signing sidecar — point ANTHROPIC_BASE_URL at localhost; it signs a spend-down-channel voucher per request and relays the gateway's native response
