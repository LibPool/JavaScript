# @ariadocs/components

> 标签: ariadocs, components, docs, documentation, openapi, react, shadcn

## 简介

shadcn-style compound components for Ariadocs. Renders @ariadocs/mdx pages and @ariadocs/openapi references with composable Docs.* and OpenAPI.* trees. Works in Server and Client Components.
