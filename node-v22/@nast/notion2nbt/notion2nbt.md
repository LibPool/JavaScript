# @nast/notion2nbt

> 标签: block-tree, converter, latex, markdown, nbt, notion, notion-api, notion-block-tree, notion-blocks, notion-to-nbt, parser, typescript

## 简介

Transform Notion pages into Notion Block Trees (NBT) for any rendering target using the official Notion API. A rendering-agnostic TypeScript library with full type safety.
