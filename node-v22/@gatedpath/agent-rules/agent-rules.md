# @gatedpath/agent-rules

> 标签: JavaScript

## 简介

One source of truth for Redbelly Network agent rules, rendered to CLAUDE.md, AGENTS.md, Cursor MDC, Copilot instructions, GEMINI.md, llms.txt and llms-full.txt, plus the one table of failure messages the MCP server, the frontend kit and the site share.
