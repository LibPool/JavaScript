# @coda-console/magpie

> 标签: JavaScript

## 简介

Magpie：把这台机器上的 Magpie 网关（127.0.0.1:3425）作为模型服务提供给 Pi 等插件选用，不用填地址和 Key；安装时没有 Magpie 就装上，并让网关常驻。
