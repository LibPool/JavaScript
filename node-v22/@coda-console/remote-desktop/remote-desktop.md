# @coda-console/remote-desktop

> 标签: JavaScript

## 简介

让同一空间的成员经 Coda 连到这台电脑的桌面：握手经插件在 Coda 插件宿主里的模块，画面、键鼠与剪贴板用 WebRTC，只走空间网络的中继，受控端不监听端口。一台电脑同一时间只有一个连接。
