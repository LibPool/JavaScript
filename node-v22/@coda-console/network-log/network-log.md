# @coda-console/network-log

> 标签: JavaScript

## 简介

只记录、不拦截：每秒看一次这台机器的连接表，把建连卡住的连接连同进程、对端、走的网卡和 mihomo 有没有收到记下来；每分钟分段探测几个常用服务。保留 30 天，一页看全空间，Agent 用 network-log 命令查。
