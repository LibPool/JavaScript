# @jperezmart/tanstack-start-casl

> 标签: abac, abilities, authorization, casl, permissions, rbac, tanstack, tanstack-start

## 简介

The TanStack Start Adapter of @jperezmart/casl-core: middleware that adds the request's CASL Ability to server functions and server routes, an assertCan that answers by the Denial rule, and a ready-made Rules endpoint handler.
