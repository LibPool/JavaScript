# @personaai/nextjs

> 标签: adapter, ag-ui, agents, app-router, next, nextjs, persona, persona.hasanraiyan.me, route-handler, runtime

## 简介

Next.js integration for Persona (persona.hasanraiyan.me) — one App Router catch-all route mounts the whole agent runtime; the root entry re-exports @personaai/react for the client.
