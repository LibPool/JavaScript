# @bacnh85/pi-references

> 标签: context, docs, external, monorepo, pi, pi-package, references, sdk

## 简介

External context roots for Pi — alias sibling dirs or git repos as @docs, @sdk and reference them in chat. Auto-clones git repos into a local cache; injects descriptions into agent context. Inspired by OpenCode's references feature.
