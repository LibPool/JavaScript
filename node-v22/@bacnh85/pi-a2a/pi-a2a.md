# @bacnh85/pi-a2a

> 标签: a2a, agent-interop, agent-to-agent, multi-agent, pi-extension, pi-package, task-distribution

## 简介

A2A Protocol v1.0 bidirectional extension for the Pi coding agent — distribute tasks to remote agents, be called by them, and self-declare for local session discovery.
