# @bacnh85/pi-cron

> 标签: automation, cron, pi-extension, pi-package, scheduler

## 简介

Scheduled jobs for Pi — cron-style jobs that fire a prompt into the live session while pi is running, with past-due catch-up and crontab export for 24/7 needs.
