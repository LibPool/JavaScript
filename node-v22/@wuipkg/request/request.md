# @wuipkg/request

> 标签: JavaScript

## 简介

基于 `axios` 环境扩展的网络请求类基元应用。具有面向对象深层解耦特性，实现了多后端与前置配置结合的分阶段控制，支持局部代理及无感知Loading状态托管。
