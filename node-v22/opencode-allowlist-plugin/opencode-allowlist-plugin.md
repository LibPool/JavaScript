# opencode-allowlist-plugin

> 标签: ai-agents, allowlist, denylist, opencode, opencode-plugin, permissions, security

## 简介

OpenCode v2 plugin that gates file edits, shell commands, web and MCP calls behind an allowlist/denylist. Anything unlisted asks via the native permission dialog, enforced by the app and never by the model.
