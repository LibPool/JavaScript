# @deconbear/get-skill

> 标签: claude, claude-code, design, installer, npx, ocr, skill, ui, vision

## 简介

Download and install a Claude Code skill from DeconBear/skills (premium-ui-gallery, vision, ocr-parser) into ~/.claude/skills/.

## 官网

- 官网：https://github.com/DeconBear/skills#readme
- 源码仓库：git+https://github.com/DeconBear/skills.git
- npm 页面：https://www.npmjs.com/package/@deconbear/get-skill

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- npm 安装：`npm install @deconbear/get-skill`
- npm registry：https://registry.npmjs.org/@deconbear/get-skill
- Node 要求：>=18
