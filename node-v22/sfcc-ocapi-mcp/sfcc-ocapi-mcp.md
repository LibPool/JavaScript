# sfcc-ocapi-mcp

> 标签: demandware, mcp, model-context-protocol, ocapi, salesforce-commerce-cloud, sfcc

## 简介

MCP server for SFCC: read-only OCAPI Data API, WebDAV logs and locally prepared Impex archives. No cartridge required.
