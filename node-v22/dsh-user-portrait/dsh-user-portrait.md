# dsh-user-portrait

> 标签: dsh, dsh-plugin, memory, persona, profile, user-portrait

## 简介

Learns your habits, skills and working style from everyday conversations and work summaries, keeps an evidence-backed portrait you can use as resume material, and offers a prompt hint plus tools that let the model consult it on demand.
