# @lang-tag/presets

> 标签: i18n, internationalization, lang-tag, lang-tag-presets, localization, presets, translation, type-safe-translations, typescript

## 简介

Optional helpers for [`lang-tag`](https://www.npmjs.com/package/lang-tag). Core stays a thin bridge to your i18n setup; this package covers common add-ons you would otherwise copy into every app.
