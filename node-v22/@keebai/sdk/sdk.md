# @keebai/sdk

> 标签: keebai, messaging, meta, sdk, whatsapp, whatsapp-cloud-api

## 简介

Official Keebai SDK — send WhatsApp messages from TypeScript with a single typed client. Two modes: directly to Meta Cloud API or through the Keebai platform.
