# better-files

> 标签: access-control, better-iam, data-room, document-sharing, secure-file-sharing, typescript, virtual-data-room

## 简介

Embeddable data rooms for TypeScript apps on Better IAM: rooms, folders, permission matrices, guests, secure viewing and audit, mounted into Next.js, NestJS, Express and more.
