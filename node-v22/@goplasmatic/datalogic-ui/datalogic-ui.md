# @goplasmatic/datalogic-ui

> 标签: business-rules, debugger, flow-diagram, json-logic, jsonlogic, logic-editor, react, react-component, rule-builder, rule-editor, rules-engine, visual-debugger

## 简介

React rule builder, visual debugger, and editor for JSONLogic (json-logic) — flow-diagram view and live execution tracing, powered by the datalogic-rs WASM engine.
