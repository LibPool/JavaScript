# @elicitly/tools

> 标签: elicitation, human-in-the-loop, mcp, mcp-server, model-context-protocol

## 简介

Embeddable MCP elicitation toolkit — register elicit_confirm, elicit_form, elicit_doctor, and elicit_display on any McpServer, plus the elicitation-schema types and capability report/probe layer.
