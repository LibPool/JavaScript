# @zoblocks/signature-core

> 标签: accessibility, consent, esignature, fhir, healthcare, signature, signature-pad, wcag

## 简介

The capture engine behind ZoBlocks's signature component. Stroke model, smoothing, export, and the outcome union — no React, no DOM required, no dependencies.
