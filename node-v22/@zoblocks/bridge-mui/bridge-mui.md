# @zoblocks/bridge-mui

> 标签: css-variables, design-tokens, healthcare, material-ui, mui, react, theming

## 简介

Theme bridge for Material UI: reads a host's resolved MUI theme and writes ZoBlocks's component token surface, so ZoBlocks components take the host's design language without importing MUI.
