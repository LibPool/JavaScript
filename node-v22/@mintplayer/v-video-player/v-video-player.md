# @mintplayer/v-video-player

> 标签: JavaScript

## 简介

A Vue 3 wrapper for the framework agnostic `@mintplayer/video-player`. It wires up all supported provider plugins and exposes a declarative component that mirrors the APIs used by the Angular and React packages.
