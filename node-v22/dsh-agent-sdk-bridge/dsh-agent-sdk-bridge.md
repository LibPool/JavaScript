# dsh-agent-sdk-bridge

> 标签: acp, agent-client-protocol, agent-sdk, agent-sdk-bridge, codebuddy, codebuddy-code, deepseek, deepseek-harness, dsh-agent-sdk-bridge, dsh-plugin, minimax, minimax-code, model-provider, qoder, qoder-cn, qoder-international, quota

## 简介

DeepSeek Harness LLM adapter bridge for Qoder CN, Qoder International, Tencent CodeBuddy and MiniMax Code subscriptions. It reuses each provider's own SDK or official ACP server and CLI login, shows available quota, and exposes per-provider settings pages
