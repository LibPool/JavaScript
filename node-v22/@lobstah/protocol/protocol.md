# @lobstah/protocol

> 标签: canonical-json, decentralized, ed25519, lobstah, mac-mini, p2p, schnorr, signed-receipts

## 简介

Ed25519 + Schnorr identities, signed receipts and announcements (canonical JSON), Zod request schemas, replay-protection helpers, URL safety checks for the Lobstah distributed-inference grid.
