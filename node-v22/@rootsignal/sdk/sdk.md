# @rootsignal/sdk

> 标签: JavaScript

## 简介

RootSignal JS SDK — thin typed GraphQL client over the api organ's /graphql (modules/api/src/schema.rs). Hand-written index.d.ts + index.mjs, no build step, no codegen.
