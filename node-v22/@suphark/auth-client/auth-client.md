# @suphark/auth-client

> 标签: auth, nextjs, oauth2, oidc, pi-auth, pkce

## 简介

Pi Auth SDK: OIDC code+PKCE flow, encrypted session cookie, JWT verify via JWKS, Next.js handlers/middleware, React hook, service client, webhook verify
