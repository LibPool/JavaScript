# @shapeso/mcp

> 标签: claude, codex, cursor, icons, mcp, model-context-protocol, react, svg

## 简介

Shape's icon library as an MCP server: search 11,160 catalog icons from Shape, Lucide, Simple Icons, Solar and SVG Logos; export SVG, React, Vue or Svelte in seventeen shared styles or SVG Logos’ original colours.
