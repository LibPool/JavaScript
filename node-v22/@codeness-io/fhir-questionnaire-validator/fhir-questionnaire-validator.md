# @codeness-io/fhir-questionnaire-validator

> 标签: fhir, fhirpath, hl7, questionnaire, questionnaireresponse, sdc, validation

## 简介

Validate FHIR R4 QuestionnaireResponses against their Questionnaire (enableWhen, SDC constraints, dynamic limits) and lint Questionnaires. Isomorphic, synchronous, no network.
