# @tzam-org/sessions

> 标签: JavaScript

## 简介

Sessões agnósticas: token opaco (só o hash é guardado), expiração total e por inatividade, revogação; consentimento de cookies assinado (subcaminho /consent). Persistência por interface implementada em cada app.
