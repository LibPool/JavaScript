# @mikefreno/omp-pygienium

> 标签: code-hygiene, lint, omp, omp-extension, pygienium, subagents

## 简介

Code hygiene extension for omp (port of the pi extension) — isolated sub-agent checks that scan a target, apply fixes, and emit a findings+changes report.
