# @sarcio/mcp

> 标签: ai, claude, live-patching, mcp, model-context-protocol, sarcio

## 简介

MCP server for Sarcio: triage bug reports, read and preview AI-drafted patches, and check what is live from Claude or any MCP client, signed in to your own Sarcio workspace.
