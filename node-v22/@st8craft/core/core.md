# @st8craft/core

> 标签: anvil, ethereum, jest, statecraft, testing, viem, vitest, web3

## 简介

Composable Ethereum integration-test scenarios for TypeScript and viem: runtime, clients, and fixtures in one package. Works with Vitest and other test runners.
