# @metatrongg/sdk

> 标签: metatron, oauth2, openapi, payments, pkce, sdk, typescript, zod

## 简介

Typed TypeScript client for the Metatron API -- generated from the published OpenAPI spec. OAuth 2.1, payments, realtime sockets, webhook verification, and the full user/developer/admin surface.
