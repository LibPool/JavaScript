# @devorajs/core

> 标签: devora, framework, multi-app, react, ssr, typescript, vite

## 简介

Devora.js framework internals — SSR/streaming request handling, sessions/CSRF, security headers, islands, backend modules, generic API routes, middleware, config loading. Not a standalone library; used by @devorajs/cli-scaffolded apps.
