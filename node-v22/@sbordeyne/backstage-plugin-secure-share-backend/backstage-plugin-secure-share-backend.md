# @sbordeyne/backstage-plugin-secure-share-backend

> 标签: backend-plugin, backstage, backstage-plugin, encryption, secrets, sharing

## 简介

Backstage backend plugin storing ciphertext and wrapped keys for Secure Share; never sees a data key or plaintext.
