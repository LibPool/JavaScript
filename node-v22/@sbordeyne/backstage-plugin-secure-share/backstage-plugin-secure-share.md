# @sbordeyne/backstage-plugin-secure-share

> 标签: backstage, backstage-plugin, encryption, frontend-plugin, secrets, sharing

## 简介

Backstage frontend plugin for short-lived, end-to-end encrypted sharing of credentials, text and files between users and groups.
