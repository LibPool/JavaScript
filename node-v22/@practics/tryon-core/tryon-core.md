# @practics/tryon-core

> 标签: computer-vision, litert, on-device-ml, pose-estimation, segmentation, thin-plate-spline, virtual-try-on, webgpu

## 简介

Framework-free virtual try-on pipeline: person segmentation, pose estimation, TPS garment warp, and mask/depth-aware compositing — embeddable in any app, on-device, no server.
