# @dong-victor/dsh-better-sidebar-jupyter

> 标签: deepseek-harness, dsh, dsh-better-sidebar, ipynb, jupyter, notebook, plugin

## 简介

Jupyter notebook support for the dsh-better-sidebar editor: .ipynb opens inline as a runnable notebook viewer with IDEA/PyCharm-style run mode (Ctrl+Enter / Shift+Enter / run-all shortcuts, IDEA toolbar, gutter run icons, In/Out labels, execution duration
