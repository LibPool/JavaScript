# @vantreeseba/graphql-casl

> 标签: abac, access-control, apollo-server, authorization, casl, envelop, graphql, graphql-middleware, graphql-yoga, middleware, permissions, rbac, resolvers, typescript

## 简介

GraphQL middleware plugin for defining CASL permission rules on resolvers, with optional argument scoping and an envelop/Yoga integration.
