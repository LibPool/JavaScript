# @openengio/sdk

> 标签: JavaScript

## 简介

The OpenEngineering SDK for Node.js 22 or later, published on npm. JavaScript and type declarations are bundled with no runtime dependencies. TypeScript consumers also need `@types/node` version 22 or later; it is an optional peer dependency.
