# @mapzone/speed-alert

> 标签: expo, expo-module, mapzone, react-native, speed-alert, speed-camera, speed-limit, vietmap

## 简介

Speed-limit, camera, toll and restriction alerts from the road network around the vehicle (zone-based, no route needed) for React Native apps.
