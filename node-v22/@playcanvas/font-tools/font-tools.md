# @playcanvas/font-tools

> 标签: atlas, bmfont, font, font-generation, msdf, playcanvas, sdf, text

## 简介

Generate PlayCanvas MSDF font assets (JSON + atlas PNG) from TTF/OTF fonts, in Node or the browser.
