# @mapled/support

> 标签: chat, inbox, mapled, script-tag, support, widget

## 简介

The support window of Mapled, the hosted headless CMS for sites built with AI — a chat button on any site: visitors write to the project's team, answers come back in the window and by email. One script tag, or a React component.
