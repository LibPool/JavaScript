# @nclabs/bpm-senior-body-parser

> 标签: JavaScript

## 简介

Converte MULIT-LEVEL JSON para JSON SIMPLES e vice-versa, pois o BPM Senior permite apenas atributos simples (string, inteiro, data..) no corpo das requisições.
