# dsh-heartbeat

> 标签: cordis, cron, deepseek-harness, dsh, dsh-plugin, heartbeat, reminder, scheduler, timer

## 简介

DSH 心跳：按时间规则向指定会话的主 Agent 主动投递一条你自己写的提示；模型输出期间不计时
