# @liveflux/devtools

> 标签: debugging, devtools, liveflux, observability, realtime, typescript

## 简介

Dev-only observability tooling for Liveflux — an event bus, redaction, and client discovery a DevTools panel builds on. Install as a devDependency; stripped from production.
