# @livevariant/core

> 标签: ab-testing, contextual-bandit, experimentation, multi-armed-bandit, thompson-sampling

## 简介

Shared foundation of LiveVariant: URL-encoded test configs with hash identity, stats secrets, seeded RNG, Thompson-sampling bandits (plain, bucketed, linear) with LLM warm-start priors, and event-sourced state derivation
