# @baseportal/grid-table

> 标签: airtable, baseportal, canvas, data-grid, datagrid, glide-data-grid, infinite-scroll, pagination, react, spreadsheet, table, virtualized, windowed

## 简介

Fast canvas-rendered data grid for React. Built on glide-data-grid with first-class support for millions of rows, paginated/infinite scrolling, draft rows, app-supplied overlay editors, and a Material-UI theme bridge.
