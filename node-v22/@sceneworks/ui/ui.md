# @sceneworks/ui

> 标签: design-system, react, sceneworks, ui

## 简介

Shared SceneWorks design system — OKLCH tokens + theme (dark mode, accents), the app-shell layout, and core React primitives. Consumed by SceneWorks, ChatWorks, and SoundWorks.
