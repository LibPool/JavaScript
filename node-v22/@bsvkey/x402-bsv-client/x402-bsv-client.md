# @bsvkey/x402-bsv-client

> 标签: 402, ai-agents, bsv, http-402, micropayments, payments, usage-receipt, verifiable, x402

## 简介

Pay an x402 HTTP 402 in BSV — the missing bsv-p2pkh payment builder for x402 agents. Also verifies BSVKey inference usage receipts and per-call x402 delivered receipts.
