# @nexartis/homeport-sdk

> 标签: a2a, agent-discovery, apache-2.0, cloudflare-workers, homeport, nanda, nexartis, orchestration, oss, routing

## 简介

Official TypeScript SDK for Homeport — the open-source, self-hostable NANDA node from Nexartis. Register agents, run A2A discovery and trust scoring, orchestrate DAG workflows, and resolve the NANDA Index (Project NANDA, MIT Media Lab).
