# @tradallo/reputation

> 标签: agent, claude, llm-tool, mcp, model-context-protocol, reputation, tradallo, trading, verified

## 简介

MCP server + TypeScript client for the Tradallo Verified Record Protocol — query cryptographically-verified human + agent trading reputations. Speaks MCP over stdio for Claude Desktop / Cursor / any LLM, exposes a CLI for terminal use, and exports Tradall
