# @agentevo-cli/agentevo

> 标签: agent-memory, ai-agents, guardrails, skills

## 简介

Agentevo CLI launcher: local-first agent memory (skills, guards, regression tests). Installs the pinned agentevo-sdk from PyPI into an isolated cache on first run.
