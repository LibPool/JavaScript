# wav2flac

> 标签: audio, encoder, flac, resample, stream, wasm, wav, wave, webassembly, worker

## 简介

Fast, streaming WAV to FLAC encoder (Rust → WebAssembly) with resampling and bit-depth conversion. Browser, Node, workers.
