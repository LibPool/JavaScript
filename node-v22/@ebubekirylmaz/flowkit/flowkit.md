# @ebubekirylmaz/flowkit

> 标签: automation, canvas, execution-engine, flow, node-editor, react, workflow

## 简介

A node-based workflow editor library with a real execution engine on top — pan/zoom, drag, connect, cut/paste, and a topological runner with branch-aware failure isolation.
