# @pactline/react

> 标签: ai-agents, enterprise-ui, escrow, react, settlement, sla

## 简介

React components for agent handshakes: authority card, escrow meter, SLA circuit-breaker gate and bilateral settlement inspector, plus a command palette and a precompiled stylesheet.
