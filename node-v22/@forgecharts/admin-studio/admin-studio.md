# @forgecharts/admin-studio

> 标签: JavaScript

## 简介

Self-hosted Admin Studio for Unmanaged ForgeCharts SDK deployments — license activation, data-feed provider configuration, and the same apps/api backend that powers it, bundled as a single CLI-runnable server.
