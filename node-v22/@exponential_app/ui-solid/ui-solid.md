# @exponential_app/ui-solid

> 标签: a2ui, exponential-ui, generative-ui

## 简介

Exponential UI for SolidJS: the core A2UI catalog painted on plain elements (floating-ui, aria-hidden) with the same DOM, the same compiled stylesheet and the same runtime themes as the React renderer, run through the conformance suite and the web-parity
