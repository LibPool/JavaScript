# @serverless-devs/tablestore-event-parser

> 标签: JavaScript

## 简介

Fc 函数计算的 事件函数 参数格式为`(event, context, callback)`。第一个参数 event 的参数类型为 buffer 对象, tablestore-event-parser 会将其转换为 json 格式
