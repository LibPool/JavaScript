# @pulsebus/core

> 标签: azure, bus, event-driven, kafka, messaging, microservices, pulsebus, queue, rabbitmq, sqs, typescript

## 简介

PulseBus is a minimalistic, extensible, provider-agnostic messaging abstraction for Node.js and TypeScript. Designed for RabbitMQ, Azure Queue, AWS SQS, Kafka and more.
