# @hanshu-ai/dsh-plugin-db-explorer

> 标签: database, dsh, dsh-plugin, mysql, oracle, postgres, sqlite, sqlserver

## 简介

DeepSeek Harness plugin for read-only database exploration: schema, table sizes, row counts, column distributions, and inferred table relationships (SQLite, PostgreSQL, MySQL, SQL Server, Oracle). Includes a local SQLite e-commerce demo and a Web GUI page
