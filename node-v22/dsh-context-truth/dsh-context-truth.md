# dsh-context-truth

> 标签: agent, compaction, context, context-window, deepseek-harness, dsh, dsh-plugin, runtime-context, token-meter

## 简介

DeepSeek Harness plugin: tells the model its real, host-measured context occupancy every turn — and keeps compaction summaries from carrying false "context is nearly exhausted" claims.
