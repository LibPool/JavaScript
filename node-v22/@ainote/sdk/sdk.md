# @ainote/sdk

> 标签: ainote, api-client, mcp, productivity, sdk, tasks, todo, typescript

## 简介

TypeScript SDK for the ainote API — typed REST client for tasks, categories & papers, plus an MCP tool-mirror escape hatch for vault/sync.
