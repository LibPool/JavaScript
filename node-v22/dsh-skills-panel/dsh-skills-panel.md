# dsh-skills-panel

> 标签: client-plugin, dsh, dsh-plugin, sidebar, skills

## 简介

Left-sidebar Skills panel for the DSH web client: lists the skills of the current DSH instance, pins favourites, and inserts /skill-name into the composer.
