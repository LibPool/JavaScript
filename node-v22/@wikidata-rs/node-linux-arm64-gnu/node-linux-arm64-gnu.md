# @wikidata-rs/node-linux-arm64-gnu

> 标签: bzip2, dump, json, napi, rust, streaming, wikibase, wikidata

## 简介

Stream Wikidata JSON dumps in Node.js: parallel bzip2, filters before parsing, typed and normalised entities, compact subsets, with bounded memory (Rust, N-API).
