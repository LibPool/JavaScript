# @ultimaps/mcp

> 标签: choropleth, choropleth-map, data-visualization, geography, map-image, maps, mcp, mcp-server, model-context-protocol, thematic-map, ultimaps, us-counties, zip-codes

## 简介

MCP server that turns data into map images: choropleth, category and pin maps of the world, countries, states, counties and ZIP codes.
