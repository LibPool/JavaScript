# @finilog/crypto

> 标签: aes-gcm, ecdh, encryption, pbkdf2, webcrypto, zero-knowledge

## 简介

Client-side crypto core of finilog.de: PBKDF2 key derivation, AES-256-GCM envelope encryption, ECDH key wrapping for beneficiaries, and the recovery-kit code format.
