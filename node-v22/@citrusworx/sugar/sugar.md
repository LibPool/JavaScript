# @citrusworx/sugar

> 标签: JavaScript

## 简介

Sugar is a visual and node based editor for creating and managing Blueprints in the CitrusWorx ecosystem. It provides an intuitive interface for developers to design, configure, and deploy their applications using Blueprints.
