# @tir.jp/canvas-auto-resolution

> 标签: canvas, device-pixel-ratio, dpr, hidpi, resize-observer, resolution

## 简介

Keep a canvas backing-store size in sync with its CSS display size, device pixel ratio and max resolution limits. Abbreviated as car.
