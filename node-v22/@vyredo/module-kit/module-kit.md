# @vyredo/module-kit

> 标签: boundaries, codegen, manifest, modular-monolith, modules, rpc, typescript

## 简介

Turn a folder into isolated modules: manifests, dependency checks, per-module tsconfigs, import boundaries, optional realms, and @vyredo/rpc-bus clients
