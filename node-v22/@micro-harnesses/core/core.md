# @micro-harnesses/core

> 标签: agent, ai, harness, llm, plugins, tools

## 简介

Composable, plugin-first library for building LLM agent harnesses. Provides the agent loop, tool registry, session/context management, policy engine with command-safety rules, provider/credentials registries, and an in-process subagent primitive.
