> 标签: anthropic, claude, claude-code, cli, ghostty, pty, tui, zig, zmux

## 简介

claude-p fork: `claude -p` drop-in plus an interactive TUI shell around Claude Code (fullscreen), with prefix completion, overlays and JS plugins.
