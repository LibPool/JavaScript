# dsh-stream-focus

> 标签: deepseek-harness, dsh, dsh-plugin, reasoning, streaming, tools, transcript, work-details

## 简介

DSH plugin: smooths running-turn thinking and tool output across all Work details modes, with a capped following window in Compact/Standard and row-level pacing in Detailed/Verbose.
