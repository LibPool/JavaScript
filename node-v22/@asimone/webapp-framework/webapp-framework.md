# @asimone/webapp-framework

> 标签: JavaScript

## 简介

This is the sass framework that models pattern abstractions leveraged in webapp. We are using [Sassdoc](http://sassdoc.com/) as a static documentation generator to give a general overview of of the sass framework. Sassdoc creates a documentation site base
