# @millicast/influxdb-v1-mcp

> 标签: devin, influxdb, influxdb-v1, influxql, mcp, model-context-protocol, read-only

## 简介

Read-only Model Context Protocol (MCP) server for InfluxDB v1 over stdio. Runnable via npx or Docker.
