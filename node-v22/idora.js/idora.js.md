# idora.js

> 标签: decorator, id, identifier, idora, prefix, prefixed-id, sortable, time-ordered, ulid, uuid, uuidv7

## 简介

Idora.JS: prefixed, time-ordered entity identifiers such as usr_01k2f9v8ta7m3x0qbrn4dzeh5c. A per-entity prefix tells you what an ID identifies; a lowercase ULID (default) or UUIDv7 makes IDs sort by creation time. Zero dependencies.
