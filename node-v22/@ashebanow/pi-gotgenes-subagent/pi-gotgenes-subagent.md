# @ashebanow/pi-gotgenes-subagent

> 标签: agent, autonomous, pi, pi-extension, pi-package, subagent

## 简介

Soft fork of @gotgenes/pi-subagents — a focused, in-process sub-agent core for pi with Reviewer agent added. Autonomous agents plus a typed API and lifecycle events other extensions build on.
