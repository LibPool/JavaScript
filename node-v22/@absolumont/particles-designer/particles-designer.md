# @absolumont/particles-designer

> 标签: animation, audio-reactive, background, generative, midi, particles, roto-control, shader, visualizer, web-component, webgl2

## 简介

Luminous GPU particle fields for any web page: <particle-field> element and ParticleField API, with the Particles Designer (WebGL2, audio-reactive, AI-authored looks).
