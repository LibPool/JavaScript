# @densds/link-encoder

> 标签: aes-gcm, browser, deeplink, encryption, incy, isomorphic, vpn, web-crypto

## 简介

Unofficial browser-compatible fork of @incy/link-encoder — encodes subscription URLs into incy://crypt1/<payload> deep links using AES-256-GCM (Web Crypto API). Runs in the browser and in Node.js. Based on the open-source INCY-DEV/incy-link-encoder projec
