# @marleyfetch/sdk

> 标签: api, bun, cloudflare-workers, deno, edge-functions, email, marleyfetch, netlify, sdk, serverless, smtp, transactional-email, vercel

## 简介

Universal SDK for MarleyFetch. Send email through your own SMTP connections with a chainable API. Works in Node.js, Cloudflare Workers, Vercel, Netlify, Deno, and Bun.
