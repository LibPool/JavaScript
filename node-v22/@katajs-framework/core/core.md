# @katajs-framework/core

> 标签: api, backend, dependency-injection, esm, framework, hono, http, rpc, type-safe, typescript, web-framework, zod

## 简介

An opinionated, type-safe web framework on Hono — static DI, mandatory Zod input/output schemas, no-codegen RPC, and a verifiable folder layout.
