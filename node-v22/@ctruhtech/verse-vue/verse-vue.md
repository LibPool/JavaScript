# @ctruhtech/verse-vue

> 标签: 3d, ctruh, gltf, nuxt, verse, viewer, vue, web-component

## 简介

Vue 3 wrapper for <verse-viewer>, the Verse Engine web component: typed props, events for the viewer's lifecycle, a ref to the embed SDK API, a plugin. SSR-safe (Nuxt).
