> 标签: claude, creatorcrawl, cursor, instagram, linkedin, mcp, model-context-protocol, reddit, scraper, social-media-api, tiktok, twitter, youtube

## 简介

Official MCP server for CreatorCrawl. 60+ tools for TikTok, Instagram, YouTube, LinkedIn, Twitter/X, and Reddit. Stdio MCP server that proxies to the CreatorCrawl hosted API.
