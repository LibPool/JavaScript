# @kreijstal/ecw2tiff-wasm

> 标签: wasm, webassembly

## 简介

ecw2tiff's from-scratch ECW (Enhanced Compression Wavelet, v2 and v3) decoder for the browser: no ECW SDK code, a module with no imports
