# @tradecanvas/mcp

> 标签: ai, charts, coding-agent, mcp, model-context-protocol, tradecanvas, trading

## 简介

An MCP server for TradeCanvas: coding agents look up its indicators, drawing tools, options, feature switches and style keys, and check an options object before they use it.
