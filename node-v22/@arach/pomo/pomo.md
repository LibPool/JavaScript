# @arach/pomo

> 标签: agent, ansi, cli, focus, macos, pomo, pomodoro, terminal, timer, tui

## 简介

Control and install the Pomo macOS HUD timer from the shell or an agent — live ANSI UI, agent-ready JSON state, and YouTube or SoundCloud playback. Zero dependencies. https://pomo.arach.dev
