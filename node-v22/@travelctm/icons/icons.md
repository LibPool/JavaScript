# @travelctm/icons

> 标签: JavaScript

## 简介

This package contains icons from the Compass design system (in the form of Svelte 5 [Snippets](https://svelte.dev/docs/svelte/snippet)) as well as a [Vite](https://vite.dev/) plugin that can be used to import `.svg` files as Svelte Snippets.
