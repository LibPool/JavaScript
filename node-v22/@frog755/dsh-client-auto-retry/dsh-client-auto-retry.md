# @frog755/dsh-client-auto-retry

> 标签: auto-retry, client, deepseek-harness, dsh, plugin, retry

## 简介

DSH client plugin: 检测回合被中断/出错/超长时, 自动发送「继续」重试, 不做模型/provider 切换。带设置卡片。
