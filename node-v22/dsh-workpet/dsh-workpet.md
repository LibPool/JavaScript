# dsh-workpet

> 标签: cordis, deepseek-harness, desktop-pet, dsh, dsh-plugin, workpet

## 简介

Work pet capability for DeepSeek Harness: a floating pet whose actions mirror what the current Session is doing, with swappable appearances contributed by other plugins.
