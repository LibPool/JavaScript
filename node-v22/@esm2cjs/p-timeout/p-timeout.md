# @esm2cjs/p-timeout

> 标签: async, await, bluebird, cancel, error, invalidate, out, promise, promises, time, timeout

## 简介

Timeout a promise after a specified amount of time. This is a fork of sindresorhus/p-timeout, but with CommonJS support.
