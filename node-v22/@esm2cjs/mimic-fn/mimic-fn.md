# @esm2cjs/mimic-fn

> 标签: change, copy, fn, func, function, imitate, infer, inherit, mimic, name, properties, rename, set

## 简介

Make a function mimic another one. This is a fork of sindresorhus/mimic-fn, but with CommonJS support.
