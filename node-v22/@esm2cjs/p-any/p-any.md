# @esm2cjs/p-any

> 标签: any, async, await, bluebird, collection, fastest, fulfilled, iterable, iterator, one, promise, promises, race, resolved, single, wait

## 简介

Wait for any promise to be fulfilled. This is a fork of sindresorhus/p-any, but with CommonJS support.
