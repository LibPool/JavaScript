# @vorionsys/aurais-mcp-market-scout

> 标签: aurais, crypto, indicators, markets, mcp, stocks, vorion

## 简介

Aurais Market Scout as an MCP server — tickers in, per-ticker briefings out (RSI, MACD, SMA, volume, relative strength vs SPY) with a signed Vorion proof chain (via @vorionsys/aurais-core).
