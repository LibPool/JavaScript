# @youj/miniatures

> 标签: alpha, illustration, interactive, isometric, loader, progress, react, svg, youj

## 简介

(alpha) Miniatures: interactive isometric objects for React. A turntable that plays, a server cabinet that fails over, an hourglass that is a progress indicator. Each is one import, drawn in SVG, with keys, light and dark, reduced motion and optional soun
