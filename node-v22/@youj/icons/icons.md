# @youj/icons

> 标签: alpha, animated-icons, icons, lucide, morph, react, svg, youj

## 简介

(alpha) Animated icons for React: the Youj icon set, the icon engine (createIcon, useIconState, IconSwap) and YoujIcon for lucide.
