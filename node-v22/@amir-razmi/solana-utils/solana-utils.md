# @amir-razmi/solana-utils

> 标签: blockchain, solana, utils, web3

## 简介

A lightweight, **TypeScript-first** utility library for interacting with the **Solana blockchain**.   It bundles multiple services — **transactions**, **transfers**, **token accounts**, **NFTs**, and **fees** — into a single, easy-to-use class.
