# @qing3a/dsh-tray

> 标签: deepseek-harness, dsh, dsh-plugin, plugin, system-tray, tray, trayicon, windows

## 简介

Windows 系统托盘插件：托盘图标 + 菜单（打开界面/状态/退出）+ 气泡通知，基于 trayicon（exe 宿主，无 native 编译）
