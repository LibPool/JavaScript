# @cm4all-wp-impex/generator

> 标签: blocks, cm4all-wp-impex, generator, gutenberg, html, import, transform, wordpress

## 简介

Transforming any data to Gutenberg block annotated WordPress content by generating WordPress ImpEx plugin (https://github.com/IONOS-WordPress/cm4all-wp-impex) files
