# @limeade-labs/sparkui-icons

> 标签: accessibility, emoji, icon-replacement, icons, lucide, sparkui, svg

## 简介

Emoji → Lucide SVG icon replacement for SparkUI. 208 mapped emojis, single-pass regex, <2ms for typical pages.
