# dsh-desktop-auto-restart

> 标签: deepseek-harness, dsh, dsh-plugin, reload, restart

## 简介

DSH 桌面端（Windows）重启插件：从侧边栏按钮或默认关闭的模型工具重启宿主，重启后按会话原有预设自动唤醒；宿主繁忙时拒绝重启。
