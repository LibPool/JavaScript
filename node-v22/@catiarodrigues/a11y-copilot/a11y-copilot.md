# @catiarodrigues/a11y-copilot

> 标签: a11y, accessibility, axe-core, claude, cli, mcp, playwright, wcag

## 简介

An accessibility auditor built on a 3-agent pipeline (Planning, Execution, Validation) that scans a page, grounds fixes in WCAG/ARIA guidance via local RAG, and validates fixes by simulating them in a cloned DOM before reporting them as confirmed.
