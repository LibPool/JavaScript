# @crediolabs/policy-synth

> 标签: authorization, openzeppelin, policy, smart-account, soroban, stellar

## 简介

Off-chain TypeScript core for the OZ Accounts Policy Builder: record a Soroban transaction or state a mandate, get the rule that permits exactly that, verify it through the interpreter's own `check`, and return an unsigned install transaction.
