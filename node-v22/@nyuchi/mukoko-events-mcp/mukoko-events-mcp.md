# @nyuchi/mukoko-events-mcp

> 标签: events, mcp, model-context-protocol, mukoko, nhimbe, nyuchi

## 简介

MCP server for Mukoko Events (events.mukoko.com) — discover and manage community events across Africa. Stdio bridge to the hosted Streamable HTTP endpoint at events.mukoko.com/mcp.
