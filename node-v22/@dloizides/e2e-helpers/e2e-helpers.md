# @dloizides/e2e-helpers

> 标签: api, dloizides, e2e, helpers, playwright, testing

## 简介

Shared Playwright E2E building blocks for the estate's two-tier (@api/@ui) suites — reachability, ROPC realm tokens, auth headers, health polling, multipart CSV, username/email derivation.
