# @dloizides/music-runtime

> 标签: eisaipollis, game-music, music, procedural, synth, web-audio

## 简介

Procedural music engine extracted from Beyond the Void. Web Audio synth + scheduler + 40 named compositions, framework-agnostic, zero deps. Consumed by every EisaiPollis game.
