# @dloizides/ui-media

> 标签: dloizides, image, photo, react, react-native, react-native-web, ui, upload

## 简介

Themable React Native (RN-web) media controls: ImagePickerButton (idle/uploading/error/done around a consumer-supplied upload function) and PhotoFramingEditor (live frame preview, size stepper, position d-pad). The framing bounds and clamp are also export
