# @dloizides/game-skins

> 标签: eisaipollis, game, palette, skin, theme, three

## 简介

Engine-free game skin contract (roles, materials, environment, UI tokens, audio cues) plus the shared skin palettes Night circuit, Dusk highway, Ember line and Deep current. Zero deps. Extracted from Surge.
