# @vivliostyle/remark-sectionize

> 标签: JavaScript

## 简介

remark plugin to wrap headings in `<section class="levelN">` elements, with VFM-specific extensions for non-section markers and section-end marks. Derived from `remark-sectionize` (Jake Low, 2019).
