# @mailwoman/neural-weights-en-au

> 标签: JavaScript

## 简介

Mailwoman neural-classifier weights for locale 'en-au'. Data-only overlay — shares the base model.onnx + tokenizer.model from @mailwoman/neural-weights-en-us (they are byte-identical); ships only the au-specific data siblings. Loaded by @mailwoman/neural
