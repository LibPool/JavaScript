# @trustlist/mcp

> 标签: mcp, model-context-protocol, rankings, reviews, software, trustlist

## 简介

MCP server for TrustList: lets AI assistants search TrustList's rankings of software, IT services and B2B firms, and cite them. Read-only, no key.
