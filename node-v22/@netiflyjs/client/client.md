# @netiflyjs/client

> 标签: JavaScript

## 简介

Zero-dependency browser/Node WebSocket client for Netifly — reconnects with full-jitter backoff and typed event handlers.

- 官网：https://github.com/NetiflyJS/netifly#readme
- 源码仓库：git+https://github.com/NetiflyJS/netifly.git
