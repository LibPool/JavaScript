# @n-tco/ysh-web-setup

> 标签: JavaScript

## 简介

Local web UI to read/write a YSH client config folder (data-structure, page-structure, role-structure, track-and-trace JSON plus logic/role/page/task/report assets), with schema and cross-reference validation.
