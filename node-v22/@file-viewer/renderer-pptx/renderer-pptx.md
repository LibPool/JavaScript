# @file-viewer/renderer-pptx

> 标签: document-preview, file-viewer, powerpoint, pptx, presentation, renderer, self-hosted

## 简介

Standalone OpenXML PowerPoint renderer for PPTX, PPTM, POTX, POTM, PPSX, and PPSM files.
