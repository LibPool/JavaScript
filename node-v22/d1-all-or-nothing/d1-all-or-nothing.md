# d1-all-or-nothing

> 标签: cloudflare, cloudflare-d1, cloudflare-workers, d1, drizzle, optimistic-locking, race-condition, sqlite, transaction, workers

## 简介

Writes on Cloudflare D1 that all happen or none do, even when another request changed the rows you read. D1 has no transactions you can read inside.
