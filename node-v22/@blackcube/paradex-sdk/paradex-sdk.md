# @blackcube/paradex-sdk

> 标签: dex, exchange, paradex, perp, perpetuals, sdk, snip12, stark, starknet, trading, websocket

## 简介

TypeScript SDK for the Paradex exchange (perpetuals DEX on a Starknet appchain): REST v1, WebSocket JSON-RPC, SNIP-12 Stark signing + JWT auth
