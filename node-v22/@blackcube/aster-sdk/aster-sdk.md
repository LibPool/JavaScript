# @blackcube/aster-sdk

> 标签: aster, asterdex, bnb, bsc, dex, eip712, evm, exchange, perp, perpetuals, sdk, spot, trading, websocket

## 简介

TypeScript SDK for the Aster exchange (perpetuals & spot DEX on Aster L1 / BNB Chain): REST futures & spot V3, WebSocket, EIP-712 agent signing
