# @djarin/next-inspect

> 标签: debugging, inspector, logger, logs, middleware, next, nextjs, nextjs logger, terminal

## 简介

Zero-code, pluggable request/console log inspector for Next.js. Captures API calls, server-side fetches and console output with file:line initiators — no per-call code needed.
