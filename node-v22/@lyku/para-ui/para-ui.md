# @lyku/para-ui

> 标签: fork, para, parabun, signals, svelte

## 简介

Para's UI runtime — Svelte forked with @lyku/para-signals at the reactive core. Powers .pui component files. Pre-release: API parity with upstream Svelte verified (7301 tests pass) but devtools/HMR (F2) still pending — see PARA-FORK.md.
