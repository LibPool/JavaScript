# @funny_diodio/dsh-session-delete

> 标签: deepseek-harness, delete, dsh, dsh-plugin, session

## 简介

Adds a Delete Session row to the sidebar session '...' menu: a confirm dialog with a one-click Force delete that releases the session from memory, stops its work, and removes the log, projection cache and registry bookkeeping with no ghost rows left. Work
