# @propxchain/mcp-server

> 标签: ai-agent, claude, conveyancing, icp, internet-computer, mcp, model-context-protocol, propxchain

## 简介

Model Context Protocol server for PropXchain — gives LLM agents (Claude, ChatGPT, etc.) access to property conveyancing transactions on the Internet Computer.
