# @wolfigs/webnak

> 标签: cms, in-place-editing, nextjs, react, visual-editor, vue, webnak, wolfigs

## 简介

Install the Webnak visual editor connector in any JS app — SSR-safe injector plus React and Vue bindings. Loads the connector from Webnak's CDN; adds ~0 KB of editor weight to your bundle.
