# @casalia/agent

> 标签: agent, ai, llm, ollama, real-estate, whatsapp

## 简介

Reusable AI agent core with LLM provider abstraction (Ollama, OpenAI, xAI, DeepSeek, OpenRouter), language/persona/scope guards, and storage adapter interfaces. Used by re-ai-agent (free self-hosted) and casalia-saas.
