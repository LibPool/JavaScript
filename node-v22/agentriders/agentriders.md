# agentriders

> 标签: agentriders, ai-agents, claude-code, evals, flight-log, verifiable

## 简介

Verifiable, metadata-only flight records for people who run AI agents. Signs a Claude Code session with a device key and earns a Verified flight badge on agentriders.com.
