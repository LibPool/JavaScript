# @s-age/kernelee-mcp-tools

> 标签: control-flow, dispatch, introspection, kernelee, mcp

## 简介

Causal-graph MCP tools for kernelee — a ts-morph static scan + runtime projection assembled into an IndexDocument, exposed over an MCP server (arch_overview/arch_endpoint/arch_state/arch_walk/arch_refresh). TS port of swift-kernelee's KernelIntrospect / K
