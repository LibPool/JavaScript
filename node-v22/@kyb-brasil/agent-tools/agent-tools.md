# @kyb-brasil/agent-tools

> 标签: ai-agents, brazil, cnpj, compliance, kyb, langchain, mcp, openai, sanctions, vercel-ai, x402

## 简介

KYB Brasil tools for AI agents: Brazilian company search, sanctions, risk score and dossiers, paid per call with x402 (USDC on Base). Adapters for Vercel AI SDK, LangChain and OpenAI function calling.
