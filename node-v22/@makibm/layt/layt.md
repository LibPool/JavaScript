# @makibm/layt

> 标签: cli, crop, image, layout, screenshot, segmentation, slice, xy-cut

## 简介

Deterministic image layout slicer: recursive XY-cut on whitespace. Reads png/jpg/webp/gif/avif/svg, emits region boxes + crops.
