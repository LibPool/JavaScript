# @unfenced-ai/mcp

> 标签: agent, claude, cursor, markdown, mcp, model-context-protocol, scraping, web

## 简介

MCP server for Unfenced - full-web access for AI agents: fetch any page as a real user sees it and get clean, LLM-ready markdown back, with a real-browser fallback for JS-heavy and protected sites.
