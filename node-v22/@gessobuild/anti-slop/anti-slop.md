# @gessobuild/anti-slop

> 标签: ai-slop, claude, css, design-lint, generated-ui, gesso, html

## 简介

Deterministic design critique for HTML/CSS: 73 slop guards (gradient text, indigo default accent, puffy shadows, emoji icons, fake dataviz, floating hero badges, layout-collapse bugs, em-dash copy, placeholder imagery...) with prevention prompts, detector
