# cubby-mcp

> 标签: 3d-printing, ai-agent, cad, claude-code, codex, cubby-slicer, cubbycad, mcp, mcp-server, slicer

## 简介

Local MCP server that lets an AI agent (any MCP client) drive CubbyCAD and Cubby Slicer browser tabs over a paired 127.0.0.1 WebSocket.

## 官网

- 官网：https://cubbycad.com
- npm 页面：https://www.npmjs.com/package/cubby-mcp
