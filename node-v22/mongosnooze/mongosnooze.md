# mongosnooze

> 标签: agenda, background-jobs, bullmq, change-streams, delayed-jobs, mongodb, scheduler, ttl, typescript

## 简介

Lightweight, MongoDB-native delayed-job trigger using Change Streams and TTL wakeups. No Redis required.
