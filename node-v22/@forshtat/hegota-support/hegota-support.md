# @forshtat/hegota-support

> 标签: eip-8141, ethereum, frame-transactions, hegota, solidity

## 简介

Helpers for the Hegota frame-transaction EIPs (8141, 8250, 7906, ...): HegotaSupport.sol, which gives Solidity the frame opcodes, and a profile-driven TypeScript codec for the transactions
