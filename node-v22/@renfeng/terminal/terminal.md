# @renfeng/terminal

> 标签: cli, devtools, git, gradle, kiro, maven, mcp, model-context-protocol, terminal

## 简介

MCP server providing terminal/CLI tool execution for Kiro IDE — wraps mvn, git, gradle, and other CLI tools as MCP tools over stdio
