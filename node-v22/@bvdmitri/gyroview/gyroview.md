# @bvdmitri/gyroview

> 标签: 360, insta360, insv, player, stabilization, video, web-component, webcodecs

## 简介

Play raw Insta360 .insv recordings (X3, X4, X5, X6) in the browser: a <gyro-view> web component that stitches and gyro-stabilizes the camera's dual-fisheye video on the GPU. Fork build for Cutaway (rendition API, app-trim fix, ONE R IMU frame, rolling-shu
