> 标签: ai-agents, cli, context-engineering, developer-tools, embeddings, local-first, mcp, memory, rag, sdk, semantic-search, talocode, vector-search

## 简介

Open-source local vector memory engine for AI agents — ingest documents, chunk content, generate embeddings, search locally, return metadata/citations.
