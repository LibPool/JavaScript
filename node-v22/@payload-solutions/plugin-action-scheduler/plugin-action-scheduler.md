# @payload-solutions/plugin-action-scheduler

> 标签: action-scheduler, cron, jobs, payload, payload-plugin, payloadcms, queue, scheduler

## 简介

WooCommerce Action Scheduler for Payload CMS: typed, scheduled and recurring actions with retries, a bounded ledger and a first-class admin view, executed by the Payload job queue.
