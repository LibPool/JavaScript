# @vibetestq/tamash-agent

> 标签: JavaScript

## 简介

TAMASH GenEx agent (Generator Executer agent): runs plain-English test cases in parallel browser contexts with rules first and a model for what rules cannot decide, and generates maintainable Playwright page objects and tests from the cases that pass.
