# @jwot/capacitor-appcenter

> 标签: android, apk, appcenter, capacitor, plugin, upgrade

## 简介

AppCenter 升级（Capacitor / Android）：壳 APK 升级（检查→下载→SHA256 校验→拉起安装→结果判定）+ Web 资源热更新（切后台生效、失败自动回滚）。自带原生实现，零第三方依赖。
