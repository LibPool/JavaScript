# n8n-nodes-fragments

> 标签: bim, fragments, ifc, n8n, n8n-community-node-package, openbim, thatopen, web-ifc

## 简介

n8n node that converts IFC files to That Open Fragments (.frag) inside the n8n instance, in an isolated child process
