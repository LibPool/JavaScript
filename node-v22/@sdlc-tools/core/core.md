# @sdlc-tools/core

> 标签: ai-agents, cli, keychain, oauth, pkce

## 简介

Shared foundation for sdlc-tools CLIs: credentials in the OS keychain, OAuth2 PKCE login, error and exit-code model, and the human/agent output contract.
