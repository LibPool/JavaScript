# @dileep-ct/grove

> 标签: apache, branch, cli, development, docker, git, git-worktree, laravel, laravel-sail, macos, mariadb, mkcert, mysql, nginx, php, php-fpm, sail, sqlite, tenancy, worktree

## 简介

Run every branch of a Laravel app side by side: one git worktree per branch with its own URLs, databases, dependencies and logs (php-fpm with nginx or Apache, or Laravel Sail; MySQL/MariaDB or SQLite; Linux and macOS; optional HTTPS)
