# @voskan/context-aware-logger

> 标签: ELK Stack, color logger, console logger, context aware, debugging, development logger, elastic, elasticsearch, elasticsearch logger, elasticsearch logging, express logger, fastify logger, file logger, http logger, koa logger, logger, logging, middleware logger, nestjs logger, nodejs logger, performance logging, production logger, structured logging

## 简介

A flexible and context-aware logging module for Node.js applications. It supports multiple transports (console, file, HTTP, Elasticsearch), and enriches log messages with contextual information like timestamps, request IDs, and custom data. Ideal for both
