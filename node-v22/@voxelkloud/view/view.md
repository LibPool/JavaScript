# @voxelkloud/view

> 标签: lidar, lod, point-cloud, potree, renderer, three, threejs, viewer, webgpu

## 简介

WebGPU point cloud renderer built on three.js (WebGPURenderer/TSL), consuming @voxelkloud/loader streams.
