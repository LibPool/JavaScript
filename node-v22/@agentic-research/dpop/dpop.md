# @agentic-research/dpop

> 标签: dpop, jwt, oauth2, proof-of-possession, rfc9449, webcrypto

## 简介

DPoP (RFC 9449) utilities and resource-server verifier SDK for notme-issued access tokens. Zero dependencies, pure Web Crypto — runs on Cloudflare Workers, Node, Deno, and browsers.
