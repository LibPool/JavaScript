# @jimvella/s3-event-store

> 标签: cloudflare-workers, conditional-writes, crypto-shredding, event-sourcing, event-store, gdpr, optimistic-concurrency, r2, s3

## 简介

Event sourcing directly on S3-compatible object storage — no database, no server. Optimistic concurrency via conditional writes; compaction; crypto-shredding erasure.
