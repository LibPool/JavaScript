# @introspection-sdk/aauth-protocol

> 标签: JavaScript

## 简介

AAuth (draft-hardt-oauth-aauth-protocol -11) plumbing shared by the Person Server, Access Server and resource packages: problem errors, the signing key, request-signature verification, discovery and R3 proposals
