> 标签: agent-tools, cordis, cordis-plugin, deepseek-harness, dsh, dsh-plugin, market, npm, preflight, publish

## 简介

Pre-publish gate for DSH plugins: every silent failure in the publish path turned into a deterministic check — package.json completeness, BOM, YAML/JSON parseability, junction and patch insert correctness, npm scope permissions, GitHub repo and token stat
