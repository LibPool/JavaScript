> 标签: android, cli, go, java, linux, node, php, python, ruby, rust, safe-shell, termux

## 简介

Professional visual CLI for Termux & Linux. Rich agent mode for AI/automation, safe execution, intelligent project context, cross-environment bridge (Termux ↔ proot-distro), and beautiful TUI navigation.
