# @ifiske/cordova-plugin-migrate-localstorage

> 标签: cordova, cordova-ios, ecosystem:cordova, localstorage, uiwebview, wkwebview

## 简介

Migrate LocalStorage data from UIWebView to WKWebView, or from file url to http url in android
