# @maxsbond/figma-bridge

> 标签: claude, codex, copilot, figma, figma-plugin, mcp, model-context-protocol

## 简介

Local MCP server bridging AI agents (Claude, Codex, Copilot) to Figma through a development plugin (no REST/MCP rate limits)
