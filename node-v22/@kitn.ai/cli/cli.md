# @kitn.ai/cli

> 标签: chat, cli, kai, kitn, scaffold, ui

## 简介

The kai command line for @kitn.ai/ui: scaffold a project or add a block to one, diagnose its wiring, and run the construct dev/eject/compile tooling.
