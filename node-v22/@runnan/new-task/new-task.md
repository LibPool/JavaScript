# @runnan/new-task

> 标签: JavaScript

## 简介

多个迭代并行时，经常需要切迭代分支开发，切完分支往往还要重新安装依赖。在需要频繁切换分支时这样的操作很麻烦。因此可以一个迭代直接clone一个仓库进行开发。
