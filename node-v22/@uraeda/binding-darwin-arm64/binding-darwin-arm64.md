# @uraeda/binding-darwin-arm64

> 标签: JavaScript

## 简介

The native binding of [Uraeda](https://github.com/mrtolkien/uraeda) for darwin-arm64, installed by [`@uraeda/ui`](https://www.npmjs.com/package/@uraeda/ui). Do not install it directly: see the [repository](https://github.com/mrtolkien/uraeda) to use Uraed
