# vega-calm-ui

> 标签: 10-foot-ui, a11y, accessibility, eslint-plugin, fire-tv, kepler, older-adults, react-native, react-native-tvos, tv, vega, vega-os, wcag

## 简介

Accessible, low-arousal 10-foot components for Vega OS and Fire TV: 32pt type, 7:1 contrast, three actions at most, no red, no timers. Enforced at render time and by ESLint.
