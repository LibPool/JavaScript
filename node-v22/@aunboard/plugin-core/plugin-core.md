# @aunboard/plugin-core

> 标签: aunboard, babel, build-plugin, codegen, data-attribute, jsx, product-tour

## 简介

Bundler-agnostic core for aunboard build-time stamping: JSX element discovery, stable id generation, the aunboard.ids.json map, and durable re-matching across refactors.
