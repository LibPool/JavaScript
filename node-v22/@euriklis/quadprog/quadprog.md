# @euriklis/quadprog

> 标签: Goldfarb-Idnani, Mathematical programming, SVM, SharedArrayBuffer, active set method, dpofa, dpori, dposl, dual algorithm for quadratic programming, optimization, parallel, qp-solver, qpgen2, quadprog, quadprog-typescript, quadratic programming, solveQP, solveQPFast, typescript, typescript-quadprog

## 简介

A TypeScript implementation of the quadprog (Goldfarb-Idnani) quadratic programming solver, with an optional parallel factorisation.
