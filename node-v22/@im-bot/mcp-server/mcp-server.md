# @im-bot/mcp-server

> 标签: ai-agent, bridge, claude-code, cline, cursor, im-bot, mcp, model-context-protocol, stdio, trae

## 简介

Model Context Protocol (MCP) stdio client for im-bot. Wraps the HTTP /mcp endpoint and exposes im-bot tools to TRAE, Cursor, Claude Code, Cline, Zed, and any other MCP-compatible AI IDE.
