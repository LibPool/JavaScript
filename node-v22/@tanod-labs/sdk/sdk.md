# @tanod-labs/sdk

> 标签: ai-agents, base, mcp, security, smart-contracts, solidity, usdc, web3, x402

## 简介

TypeScript client for Tanod: pay-per-call security tools for AI agents (address risk, contract scan, MCP/skill package scan, chain reads), paid with x402 USDC on Base. Free daily tier, no signup.
