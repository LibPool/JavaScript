# dsh-session-attention

> 标签: attention, deepseek-harness, dsh, notification, plugin, session, 提醒, 通知

## 简介

DSH 会话提醒插件：agent 完成一轮 / 提问 / 需要审批时提醒（系统通知 + 提示音），外加显示活跃会话的活动悬浮球，点会话行可直接跳转。
