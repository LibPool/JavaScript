# @korateams/x402-sdk

> 标签: agent-commerce, base, express-middleware, machine-payable, usdc, x402

## 简介

Open-source x402 payment-required middleware for merchants joining the Global Commerce Index. Add machine-payable pricing to any Express route in a few lines.
