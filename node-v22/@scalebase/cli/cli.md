# @scalebase/cli

> 标签: billing, cli, mcp, scalebase

## 简介

Scalebase CLI — Scalebase 契約者向けの CLI / MCP サーバー。利用には Scalebase ダッシュボードで発行する API キーが必要です。

## 官网
