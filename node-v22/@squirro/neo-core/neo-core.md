# @squirro/neo-core

> 标签: JavaScript

## 简介

Runtime, component library and dev server for Squirro Neo UI bundles. Most projects should not depend on this package directly: scaffold a bundle with the CLI and it is installed for you.

## 官网

- 官网：https://docs.squirro.com/en/latest/technical/neo/
- 源码仓库：git+https://github.com/squirro/web-client.git
