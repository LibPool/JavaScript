# @kernel4632/agent-core

> 标签: agent, ai, ai-sdk, anthropic, bun, gemini, llm, openai, tool-calling

## 简介

轻量的 AI Agent 核心：给它模型地址和工具（文件目录或内存对象），自动循环「问模型 → 执行工具 → 再问模型」。支持 OpenAI Chat / Responses、Anthropic、Gemini 四种协议，上下文压缩保留、提示词缓存，纯对话模型也能用工具。
