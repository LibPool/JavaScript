# @zagcool/components

> 标签: JavaScript

## 简介

本组件库在构建阶段使用 `postcss-px-to-viewport-8-plugin` 将样式中的 `px` 单位按 750 设计稿转换为 `vw`，仅作用于 `packages/components` 下的组件样式。
