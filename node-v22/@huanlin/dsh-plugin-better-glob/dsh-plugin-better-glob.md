# @huanlin/dsh-plugin-better-glob

> 标签: dsh-plugin

## 简介

Shadow-replaces the built-in glob tool: auto-excludes bottomless directories (node_modules, dist, build, .venv, ...) and requires an explicit include whitelist to search inside them.
