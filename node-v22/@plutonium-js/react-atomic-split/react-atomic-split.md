> 标签: animate, animation, atomic, css animation, plutonium, react, split characters, split chars, split components, split divs, split elements, split letters, split text, split words, stagger, stagger animate, stagger animation

## 简介

An advanced React component that adds staggered animation capabilities to child elements and components.  Optionally split child text into animatable component characters and words!
