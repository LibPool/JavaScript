# @nmime/nestjs-asyncapi

> 标签: amqp, asyncapi, asyncapi-2.0, asyncapi-3.0, documentation, event-driven, kafka, microservices, nest, nestjs, openapi, pubsub, rabbitmq, socket.io, swagger, websockets

## 简介

NestJS AsyncAPI module - generate documentation of your event-based services using decorators. Supports AsyncAPI 3.0, 2.x, and 1.x specifications.
