# @af199/anima-core

> 标签: ai-safety, deterministic, llm-agents, model-organism, psychodynamic, reproducible, simulation

## 简介

Deterministic psychodynamic engine for LLM agents — seven-dimensional state vector, seeded RNG, byte-reproducible. The engine at the heart of ANIMA, as a library.
