# @7obygit/space

> 标签: cli, context-switching, environment-variables, productivity, scratch-space, vscode, workspace

## 简介

A powerful CLI tool for managing dynamic VS Code workspaces. Switch contexts, manage environment variables, and attach files on the fly.
