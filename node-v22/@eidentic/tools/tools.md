# @eidentic/tools

> 标签: agents, ai, bash, eidentic, file-tools, tools, typescript, web-search

## 简介

Built-in agent tools for Eidentic — file I/O, bash execution, web fetch, web search (Tavily / Exa / Serper / SearXNG), and sandbox confinement.
