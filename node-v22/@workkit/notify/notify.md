# @workkit/notify

> 标签: cloudflare, cloudflare-email, email, gupshup, in-app, meta, notifications, notify, resend, sse, twilio, whatsapp, workers, workkit

## 简介

Unified notification dispatch for Cloudflare Workers — preferences, opt-out, quiet hours, idempotency, fallback chains, pluggable adapters (email, in-app).
