# @pharen-ai/cli

> 标签: build-distribution, cli, crash-reporting, dsym, fastlane, ios, mobile, ota, symbolication

## 简介

The Pharen command-line tool: set up an iOS app, manage ingest and query keys (mint, rotate, revoke), upload builds and dSYMs, and check an integration end to end. JSON on stdout for CI and lanes; zero runtime dependencies.
