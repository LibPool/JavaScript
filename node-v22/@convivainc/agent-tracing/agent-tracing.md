# @convivainc/agent-tracing

> 标签: agent, conviva, llm, observability, openllmetry, opentelemetry, otel, traceloop, tracing

## 简介

Conviva tracing SDK for AI agents — a thin wrapper over OpenLLMetry that exports OTLP http/protobuf traces to the Conviva agent gateway, with Conviva's span processors and baggage connector built in.
