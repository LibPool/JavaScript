# @glacierjs/core

> 标签: JavaScript

## 简介

作为 GlacierJS 的核心模块，它提供： 1. MiddlewareQueue：支撑函数的插件化。 2. Logger：统一管理 GlacierJS 的日志。 3. Const：统一管理静态变量
