# @uoa/dynamo-utils

> 标签: dynamoDB, lambda, uoa

## 简介

This library contains a helper class which assists with transformations commonly used in projects typescript projects using DynamoDB in University of Auckland projects. This library currently only supports transformation syntax for the dynamoDB document c
