# @fastn-ai/embed

> 标签: api-client, embed, fastn, headless, iframe, integrations, react, sdk

## 简介

Embed the fastn Integration Hub in your product, or build your own UI against the same API. Framework-agnostic core, optional React entry points, and a headless client — in one install.
