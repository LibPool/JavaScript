# mej-mcp

> 标签: claude, claude-code, colombia, cursor, estadistica-judicial, mcp, mej, model-context-protocol, rama-judicial, sierju

## 简介

Servidor MCP del MEJ (Motor de Estadística Judicial, Rama Judicial de Colombia): entradas civiles, salidas y acciones constitucionales para asistentes de IA, procesadas 100 % en el equipo del despacho.
