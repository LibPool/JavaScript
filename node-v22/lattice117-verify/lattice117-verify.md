# lattice117-verify

> 标签: delivery-windows, deterministic, feasibility, fixed-point, logistics, offline-first, rest-period, rota, route-sheet, routing, scheduling, shift-compliance, staff-rota, time-windows, verification, vrptw, wasm, webassembly, working-time-regulations, wtr

## 简介

Deterministic schedule feasibility verification. Checks whether a planned route holds against its own time windows and names the exact violation when it does not. Runs entirely locally — no network, no server, no telemetry.
