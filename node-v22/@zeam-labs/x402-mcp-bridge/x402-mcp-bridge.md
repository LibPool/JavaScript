# @zeam-labs/x402-mcp-bridge

> 标签: JavaScript

## 简介

Put a wallet in front of any x402-paid MCP server, and hold a metered line on the ones that sell time. Stock MCP clients cannot construct x402 payments; this one does, and proxies your existing client through it.
