# @trylath/react-native

> 标签: auth, authentication, components, expo, lath, mfa, react-native, sign-in

## 简介

Drop-in React Native components for Lath authentication: sign-in, sign-up, MFA, profile and organization switcher, themed from the project's own tokens.
