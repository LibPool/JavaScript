# @openredaction/elysia

> 标签: JavaScript

## 简介

Elysia plugins for PII detection and redaction. Inspects request bodies, optionally auto-redacts fields, and attaches results to the Elysia context via `{ pii }` destructuring. Elysia is a peer dependency (`>=1.0.0`).
