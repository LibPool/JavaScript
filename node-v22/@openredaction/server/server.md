# @openredaction/server

> 标签: JavaScript

## 简介

Zero-dependency Node.js HTTP servers for OpenRedaction: a REST API for PII detection/redaction and a Prometheus scrape endpoint. Uses Node's built-in `http` module — no Express, no framework.
