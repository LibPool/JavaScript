# @neoworks-dev/otter-sdk

> 标签: JavaScript

## 简介

Shared TypeScript library for building Otter plugins. Provides all media types, the stdin/stdout JSON protocol handler (`runPlugin`), and HTTP utilities with browser-compatible headers.
