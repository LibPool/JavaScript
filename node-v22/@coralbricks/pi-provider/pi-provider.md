# @coralbricks/pi-provider

> 标签: coralbricks, glm, gpt-oss, inference, kimi, llm, openai-compatible, pi, pi-package

## 简介

CoralBricks provider for the pi coding agent — GLM 5.3, GLM 5.3 Flash, Kimi K3 and GPT-OSS 120B with up to 1M context and free cached input.
