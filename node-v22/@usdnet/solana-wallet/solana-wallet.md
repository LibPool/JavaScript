# @usdnet/solana-wallet

> 标签: solana, typescript, wallet

## 简介

Self-custodial Solana wallet library: create or import wallets from BIP39 seed phrases, sign transactions and messages, send SOL and SPL tokens, estimate fees, activity, balance monitoring, and encrypted storage helpers
