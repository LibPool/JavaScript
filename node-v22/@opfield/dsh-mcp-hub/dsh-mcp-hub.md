# @opfield/dsh-mcp-hub

> 标签: deepseek-harness, dsh, dsh-plugin, mcp, model-context-protocol, oauth

## 简介

MCP Hub for DeepSeek Harness: every MCP server in one place, per-server eager / lazy / auto tool exposure, OAuth for HTTP servers, direct node launch of npx packages, and the mcpHub service for plugins that contribute servers
