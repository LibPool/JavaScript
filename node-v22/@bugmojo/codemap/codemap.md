# @bugmojo/codemap

> 标签: ai-agents, app-router, bugmojo, codemap, expo-router, nextjs, qa, static-analysis, test-generation, trpc

## 简介

Deterministic, framework-aware codebase mapper for BugMojo — turns a repo's routes, components, APIs and forms into Feature rows and a stable code summary. No LLM, no network.
