# @gabriele.muscogiuri/notion-api

> 标签: api, automation, cli, database, notion, type-generation, types, typescript, wrapper

## 简介

Modern Notion API wrapper with CLI type generation, automatic type safety, and zero maintenance. Generate custom TypeScript types from your Notion databases with official type compatibility.
