# @bsuite/charge-calc

> 标签: JavaScript

## 简介

Charge-rate calculation and BOOT assessment engine for Australian GTO and labour-hire operators. Includes FWC award comparator, failure-pattern detector, F17 export, and GTO multi-placement variant (ss.193/193A Fair Work Act 2009).
