# @bsuite/dates

> 标签: JavaScript

## 简介

Universal date and time localisation for BSuite. Defaults to en-AU (Australian DD/MM/YYYY), with a per-user toggle to en-US. Exposes pure formatters and a React LocaleProvider/useLocale.
