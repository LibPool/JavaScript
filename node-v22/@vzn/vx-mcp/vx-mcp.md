# @vzn/vx-mcp

> 标签: agents, ai, mcp, model-context-protocol, monorepo, vx, vx-plugin

## 简介

Model Context Protocol server for vx — a plugin that adds `vx mcp`, exposing cache stats, run history and cache-key explanations to AI coding agents over stdio.
