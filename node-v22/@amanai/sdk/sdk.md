# @amanai/sdk

> 标签: agent, ai, guardrails, llm, policy-as-code, security, tool-call

## 简介

Action Policy Engine for AI agents — policy-as-code for tool-calls. Zero-dependency TypeScript core engine that loads the same policy JSON and returns the same decisions as the Python SDK.
