# dsh-doc-assistant

> 标签: deepseek-harness, document, dsh-plugin, reader, revision, tracked-changes

## 简介

企业文档助手 (Enterprise Document Assistant) — a DSH plugin that turns the harness into a document workbench: project-scoped document library, an e-reader style three-column page (tree | document | AI chat), selection-to-ask, and AI rewrite shown as tracked-cha
