# @zhiaiwan/requestkit

> 标签: axios, cache, http, request, retry, typescript, umd

## 简介

基于 axios 二次封装的现代化、类型安全的 HTTP 客户端，开箱即用地提供请求队列追踪、分组取消、自动重试、Token 刷新、错误分类、并发限制、响应缓存和 Debug 日志
