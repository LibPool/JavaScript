# @bzbc/cli

> 标签: JavaScript

## 简介

`yf-cli`是快速搭建`vue`项目的脚手架，可以实现vue项目的初始化、页面（组件）新建、打包等功能。`yf-cli`脚手架是基于`vue-cli`实现的，集成了包括`vuex`、`vue-router`、`axios`在内的`vue`常用插件，以及`mockjs`、`monent`等前端常用插件。
