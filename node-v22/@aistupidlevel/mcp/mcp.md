# @aistupidlevel/mcp

> 标签: ai, benchmarks, drift, leaderboard, llm, mcp, mcp-server, model-context-protocol, router

## 简介

MCP server for AI Stupid Level: LLM leaderboard, model history, drift status, incidents and provider status from the ASL Data API, plus route previews and prompts through the ASL Smart Router.
