# @uued/dsh-see-image

> 标签: JavaScript

## 简介

Vision model settings page (Web Settings → Models → 视觉模型) plus a see_image tool: lets text-only DeepSeek models "see" images via a configurable OpenAI-compatible vision API (default Zhipu GLM-4.6V-Flash, free).
