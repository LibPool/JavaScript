# @stripe_widget/stripe-backend-sdk

> 标签: backend, level3, payments, sdk, stripe

## 简介

Lightweight backend SDK to process tokenized Stripe payments (create/attach PaymentMethod, confirm PaymentIntent) with optional Level 3 data.
