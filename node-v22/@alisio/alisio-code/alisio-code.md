# @alisio/alisio-code

> 标签: agent-harness, ai, cli, coding-agent, llm, openai-compatible, plugins, terminal, tui

## 简介

Alisio: an extensible, provider-agnostic coding-agent harness for your terminal. TUI, OpenAI-compatible providers, permissioned local tools, context compaction, persistent memory and a typed plugin SDK.
