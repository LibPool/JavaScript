# @alisio/core

> 标签: agent, agent-harness, ai, coding-agent, llm, mcp, openai-compatible, plugins

## 简介

Embeddable provider-agnostic Alisio agent core: tool loop, context compaction, local tools, MCP, plugin host and SQLite session store. Runs on Node >=22.16 and Bun.
