# @alisio/plugin-material-icons

> 标签: alisio-plugin, icon-theme, icons, material-icon-theme, ui

## 简介

Material Icon Theme for the Alisio web UI: a self-contained icon-theme provider with the vendored Material Icon Theme SVGs and VSCode-style manifest.
