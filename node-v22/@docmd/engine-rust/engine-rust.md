# @docmd/engine-rust

> 标签: docmd, docs, documentation, engine, markdown, minimalist, native, performance, rust, site-generator, zero-config

## 简介

Rust-accelerated engine for docmd. The postinstall script downloads a pre-built platform binary from npm CDN (unpkg/jsdelivr). No code is executed beyond copying the .node file. Source: https://github.com/docmd-io/docmd
