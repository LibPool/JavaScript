# @dimarborda/xlsx-editor

> 标签: canvas, editor, excel, formulas, openxml, rust, spreadsheet, template, viewer, wasm, web-component, webassembly, xlsx

## 简介

Excel (.xlsx) editor for the browser and engine for Node.js: Rust + WebAssembly that edits workbooks without losing what it does not touch, with a canvas grid as a framework-agnostic web component
