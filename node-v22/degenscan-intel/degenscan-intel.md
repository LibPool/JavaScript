# degenscan-intel

> 标签: ai-agents, carry, degenscan, funding-rate, hip-3, hyperliquid, market-data, mcp, polymarket, usdc, x402

## 简介

Official client for the Degenscan Intel API: Hyperliquid funding/carry data across all dexes (HIP-3 included), event feed, derivatives, Polymarket context and a calibrated forecast oracle. Pays per call in USDC via x402, or uses an API key.
