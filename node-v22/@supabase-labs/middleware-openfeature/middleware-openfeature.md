# @supabase-labs/middleware-openfeature

> 标签: edge, feature-flags, fetch, middleware, openfeature, supabase

## 简介

Typed OpenFeature flag resolution as a @supabase/middleware middleware. Resolves every declared flag per request and contributes the values at ctx.flags.
