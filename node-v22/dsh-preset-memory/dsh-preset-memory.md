# dsh-preset-memory

> 标签: deepseek-harness, dsh, dsh-plugin, memory, preset, shadow, shim

## 简介

Universal memory shadow plugin for DSH: shadows other memory plugins' context and tools within a preset, giving that channel a clean context.
