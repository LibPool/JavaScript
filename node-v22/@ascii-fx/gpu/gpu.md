# @ascii-fx/gpu

> 标签: ascii, ascii-art, ascii-fx, canvas, compute-shader, gpgpu, renderer, webgpu

## 简介

WebGPU renderer for ASCII FX: exact structural-v1 compute matching and one-draw atlas compositing, with a CPU fallback.
