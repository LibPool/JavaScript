# zerodep-js-native

> 标签: JavaScript

## 简介

固定 TypeScript 7.1 的 zerodep-js 原生 Go 编译器。框架分析与输出编入 TypeScript，保留原始源码类型检查、声明、源码映射和语言服务。运行时协议为 ABI 2，项目只维护这一编译路线。
