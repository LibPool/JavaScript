# @qingwawangzi/pi-speedline

> 标签: pi-extension, pi-package, pi-speedline, speedline, speedometer, status-bar, throughput, tokens-per-second, ttft

## 简介

Unified pi speedometer: real-time calibrated tokens/s while streaming + exact per-turn TTFT and throughput in ONE theme-adaptive footer slot. Merges pi-tokens-per-second and pi-throughput-meter, timer-free.
