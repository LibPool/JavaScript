# @ryancardin/noaa-tides-currents-mcp-server

> 标签: api, co-ops, currents, mcp, model-context-protocol, noaa, tide-predictions, tides, water-levels

## 简介

MCP server for NOAA CO-OPS Tides and Currents: water levels, tide predictions, currents, meteorology, station metadata, datums, high tide flooding, sea level trends, plus sun and moon calculations
