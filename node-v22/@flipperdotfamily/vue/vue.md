# @flipperdotfamily/vue

> 标签: coin flip, flipper, nuxt, robinhood chain, viem, vue, vue3, web3, widget

## 简介

Vue 3 component, plugin and composable for flipper.family: the drop-in <FlipperWidget> (bring your own wallet) and a headless useFlipperClient.
