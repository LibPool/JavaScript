# @yairl/payload-db-backup-restore

> 标签: backup, export, import, mongodb, payload, payloadcms, plugin, restore

## 简介

Admin UI for exporting and restoring selected Payload CMS collections as portable JSON. Includes a /admin/backup view and a sidebar shortcut.
