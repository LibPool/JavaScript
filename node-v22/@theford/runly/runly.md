# @theford/runly

> 标签: broker, coding-agents, dev-environment, e2e, environment, harness, preview, sandbox, warm-pool

## 简介

Worktree-owned app environments for coding agents and humans: seeded data, activity-based idle and wake, stable proxy ports, and expiring public previews.
