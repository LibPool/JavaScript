# @things-scene/things-board-integration

> 标签: JavaScript

## 简介

1. npm install 로 모듈 및 폰트 설치 ``` $ npm install ``` 2. npm run serve ``` npm run serve ``` 3. 브라우저에서 서비스 포트에 연결해서 샘플 실행 ``` http://localhost:8080/demo/board-hatiolab-com.html ```
