# @motebit/state-export-client

> 标签: content-provenance, motebit, operator-transparency, self-attesting, verification

## 简介

Browser-safe client for verified motebit state-export reads. Wraps fetch with X-Motebit-Content-Manifest verification + Trust-On-First-Use bootstrap from /.well-known/motebit-transparency.json. Apache-2.0; consumes @motebit/crypto + @motebit/protocol only
