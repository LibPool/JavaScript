# dsh-preclaim

> 标签: cordis-plugin, deepseek-harness, deterministic, dsh, dsh-plugin, evidence, fail-closed, no-network, phocinae, preclaim, verification

## 简介

DeepSeek Harness plugin: a deterministic gate that checks a git commit, push or README write asserting something was verified against what the session actually ran. No model, no network.
