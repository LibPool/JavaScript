# @praveen-palanisamy/agent-browser-runtime

> 标签: agents, ai-agents, authenticated-sessions, browser-agent, browser-automation, cdp, github-action, headless-chrome, kernel, kernel-browsers, playwright, rpa, self-hosted, session, steel, steel-browser, storage-state, web-automation

## 简介

Stateful, secure browser-session execution for agents: pluggable browser providers (local Chromium, CDP, Steel, Kernel), post/probe/capture orchestration, an HTTP runner service and a Playwright-free client
