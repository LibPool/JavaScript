# @mj-biz-apps/issues-core-entities-server

> 标签: JavaScript

## 简介

Server-side entity subclasses for BizApps Issues — lifecycle hooks for Issue, IssueComment, etc. (stamp ResolvedAt/ClosedAt, fire IssueType action hooks).
