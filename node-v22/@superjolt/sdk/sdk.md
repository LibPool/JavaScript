# @superjolt/sdk

> 标签: agents, billing, mcp, sdk, superjolt, webhooks

## 简介

Official SDK for Superjolt — agent-first cloud compute. Subscribe to the event feed, headless magic-link auth, fetch session context, generate billing & portal URLs from any deployed app.
