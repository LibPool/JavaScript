# @xdbml/from-mongodb

> 标签: data-modeling, dbml, mcp, mongodb, reverse-engineering, schema, schema-inference, xdbml

## 简介

Map MongoDB inferred collection schemas (MongoDB MCP server collection-schema / mongodb-schema SimplifiedSchema) to xDBML, with reviewable reference detection.

## 官网

- 官网：https://xdbml.org/recipes/mongodb
- 源码仓库：git+https://github.com/xdbml/xdbml-spec.git
- npm 页面：https://www.npmjs.com/package/@xdbml/from-mongodb
