# @yuban32/wardogs-rcon-api

> 标签: api, client, dedicated-server, game-server, rcon, typescript, wardogs

## 简介

Typed client and utilities for the Wardogs dedicated server RCON HTTP API (/v1). ESM + CJS + UMD, zero runtime dependencies, works in Node, Bun, Deno and the browser.
