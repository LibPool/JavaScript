# @essentim/node-red-contrib-lcc

> 标签: node-red

## 简介

Dies ist ein node-RED Plug-in, welches eine Verbindung zu WALDNERs Lab Control Center herstellt und somit die Verarbeitung von LCC Daten via node-RED ermöglicht.

## 官网

- npm 页面：https://www.npmjs.com/package/@essentim/node-red-contrib-lcc

- npm registry：https://registry.npmjs.org/@essentim/node-red-contrib-lcc
- Node 要求：>=22.0.0
