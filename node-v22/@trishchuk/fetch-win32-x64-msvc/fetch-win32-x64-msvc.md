# @trishchuk/fetch-win32-x64-msvc

> 标签: JavaScript

## 简介

Fetch API-shaped HTTP client for Node.js (buffered bodies, no streaming yet), backed by a Rust (wreq/hyper/BoringSSL) native addon with TLS/HTTP2 fingerprint emulation
