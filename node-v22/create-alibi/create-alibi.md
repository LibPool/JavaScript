# create-alibi

> 标签: e2e, playwright, scaffold, testing, ui-testing

## 简介

Adds an alibi/ test folder to a web app repo, ready for Playwright tests run by an Alibi server.

## 官网

- npm 页面：https://www.npmjs.com/package/create-alibi

- 0.1.0

- npm registry：https://registry.npmjs.org/create-alibi
- Node 要求：>=18
