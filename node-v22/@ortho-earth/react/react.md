# @ortho-earth/react

> 标签: globe, maplibre, ortho-earth, react

## 简介

React bindings for @ortho-earth/globe: <Globe> creates the map, useGlobe() hands it to children, <Source>/<Layer> mirror addSource/addLayer, <Data> wraps map.addData, <Marker> is the DOM marker, useGlobeEvent() subscribes to map events. No JSX runtime req
