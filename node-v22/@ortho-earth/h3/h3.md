# @ortho-earth/h3

> 标签: binning, globe, h3, hexagon, ortho-earth

## 简介

H3 cells for @ortho-earth/globe: cell ids → GeoJSON polygons, point binning into H3 cells (count/sum/mean/min/max with MapLibre expressions), zoom → resolution, and map.addH3() which draws the cells as a fill or fill-extrusion layer.
