# @costa-app/openclaw-costa-user-attribution

> 标签: attribution, gateway, llm, openclaw, openclaw-plugin

## 简介

OpenClaw provider plugin for the Costa LLM gateway. Stamps a per-agent X-COSTA-USER-ATTRIBUTION header onto outbound model requests so one shared gateway key can be attributed per user.
