# @powerduck/a2a-kit

> 标签: a2a, agent-card, agent-protocol, agent2agent, canonicalization, grpc, json-rpc, jwks, jws, powerduck, server-generator, sse

## 简介

Isomorphic Agent2Agent (A2A) toolkit: protocol request builders and validators for A2A 1.0/0.3, Agent Card parsing, RFC 8785 canonicalization and JWKS signature verification, plus a runnable A2A server project generator (JSON-RPC, REST and gRPC).
