# @omni2fa/core

> 标签: 2fa, email-otp, framework-agnostic, headless, mfa, passkey, totp, two-factor-authentication, webauthn

## 简介

Omni2FA — framework-agnostic TypeScript core. State machines, WebAuthn ceremony, HTTP client, timers, validation. No React/Vue/Angular dependencies. Consumed by @omni2fa/react and future Vue/Angular/Svelte adapters.
