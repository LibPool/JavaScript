# @kormsen-engineering/cms-astro

> 标签: JavaScript

## 简介

Kormsen CMS for Astro: Zod schema extraction (.cms/schema.json), the edit build (drafts per request, the bridge loader, field markers, the site adapter for Astro's swap) and region re-render through the Astro Container API.
