# open-anatomy-3d-react

> 标签: 3d, anatomy, human-body, medical, react, react-three-fiber, three.js, viewer

## 简介

Interactive 3D human anatomy viewer for React (react-three-fiber): orbit, zoom, toggle body systems, hover and click any structure, pin callouts.
