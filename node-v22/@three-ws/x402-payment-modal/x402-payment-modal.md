# @three-ws/x402-payment-modal

> 标签: 402, agentic, base, checkout, eip-3009, evm, metamask, micropayments, modal, pay-per-call, payments, paywall, phantom, siwx, solana, stablecoin, three-ws, usdc, wallet, web3, x402

## 简介

Drop-in x402 payment modal for any paid HTTP endpoint. One ES module, zero runtime dependencies — handles wallet connect (Phantom/Solana + EVM via EIP-3009), the 402 → sign → settle flow, SIWX re-entry, client-side spending caps, and a receipt. Vanilla JS
