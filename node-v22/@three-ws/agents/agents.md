# @three-ws/agents

> 标签: agents, ai-agents, automation, llm, sdk, solana, three.ws, typescript

## 简介

TypeScript SDK for the three.ws v1 Agents API: create, start and chat with AI agents, run goals, automate, and trade from Solana agent wallets.
