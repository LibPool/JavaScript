# @three-ws/cli

> 标签: agents, claude, cli, codex, cursor, gemini, grok-bot, mcp, model-context-protocol, oauth, solana, three.ws, vscode

## 简介

One command to connect any MCP client to three.ws: sign in with OAuth or an API key, write the three.ws MCP servers into Claude Code, Claude Desktop, Cursor, Windsurf, VS Code, IBM Bob, Codex, Gemini CLI or Hermes, print the connector fields for Grok Bot,
