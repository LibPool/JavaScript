# @three-ws/spatial-mcp

> 标签: 3d, glb, gltf, mcp, model-context-protocol, spatial, structured-content, three.ws, tool-result, validator

## 简介

Validator, builder, and conformance fixtures for Spatial MCP — the open (CC0) shape for returning a live, interactive 3D scene as a first-class MCP tool result.
