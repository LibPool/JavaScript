# @three-ws/agent-glance

> 标签: adaptive-card, agent, badge, home-screen, pwa, svg, three.ws, web-component, widget

## 简介

Put a three.ws agent on any surface that has a slot: home screen widgets, README badges, Slack unfurls, and a live <agent-glance> web component.
