# @fses/workbench-card

> 标签: JavaScript

## 简介

工作台卡片组件库，提供卡片注册表、渲染器、图表协议和图生组合卡片模式。组件库只承载 UI、类型和契约；PersonalWorkbench 的 API、store、问数和保存逻辑仍由宿主通过 bridge 注入。
