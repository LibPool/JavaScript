# @hetuh/saakshi

> 标签: analytics, dpdp, drizzle, first-party, gdpr, kysely, nextjs, no-cookies, page-views, postgres, privacy-first, self-hosted, trpc

## 简介

Lightweight, privacy-first, ORM-agnostic first-party analytics for Next.js + Postgres. Beacon endpoint, page-view tracker, dashboard components, and tRPC router factory — works with Drizzle, Kysely, raw pg, or Prisma.
