# @ycforge/auth

> 标签: auth, iam, nestjs, typescript, yandex-cloud, ydb

## 简介

Shared authentication strategies for Yandex Cloud (IAM tokens, metadata service, service account keys) and YDB, with adapters for @ydbjs/auth and NestJS
