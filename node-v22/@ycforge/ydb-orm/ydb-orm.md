# @ycforge/ydb-orm

> 标签: nestjs, orm, typeorm, typescript, yandex-cloud, yandex-database, ydb

## 简介

TypeORM-like ORM для YDB (Yandex Database): Active Record, relations, шифрование полей, schema sync, транзакции и миграции. Опциональная интеграция с NestJS — подпакет @ycforge/ydb-orm/nest
