> 标签: android, android-tv, annotation, breadcrumbs, bug-report, bug-reporting, crash-reporting, error-reporting, feedback, ios, react-native, screenshot, session-replay, traceitx, turbomodule, tvos

## 简介

React Native SDK for TraceItX — AI-ready in-app bug reporting, bridging the native iOS and Android reporter to your RN app. Supports phone, Apple TV, and Android TV.
