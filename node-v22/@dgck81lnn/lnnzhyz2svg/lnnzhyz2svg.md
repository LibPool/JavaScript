# @dgck81lnn/lnnzhyz2svg

> 标签: JavaScript

## 简介

此工具可以将 [LNN 中华语字][lnnzhyz]绘制成 SVG。支持普通话和[希顶语][xdi8] [LNN 中华语字方案][方案]。
