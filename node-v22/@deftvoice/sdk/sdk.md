# @deftvoice/sdk

> 标签: agent, conversational-ai, deftvoice, sdk, voice, voice-agent, websocket

## 简介

Production-ready SDK for Deftvoice. Simple integration for voice agents with auto-reconnection, audio buffering,  interruption handling.
