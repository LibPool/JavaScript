# @stdlib/stats-nanmeanpn

> 标签: arithmetic mean, average, avg, central tendency, math, mathematics, mean, ndarray, statistics, stats, stdlib, stdmath

## 简介

Compute the arithmetic mean along one or more ndarray dimensions, ignoring `NaN` values and using a two-pass error correction algorithm.
