# @stdlib/math-strided-special-smskabs

> 标签: abs, absolute, array, element-wise, float, float32, float32array, flt, magnitude, mask, masked, math, mathematics, missing, missing values, na, ndarray, single-precision, stdlib, stdmath, strided, value, vector

## 简介

Compute the absolute value for each element in a single-precision floating-point strided array according to a strided mask array.
