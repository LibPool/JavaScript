# @stdlib/napi-argv-dataview

> 标签: addon, array, arraybuffer, bytes, dataview, macros, napi, native, stdlib, utilities, utils

## 简介

Convert a Node-API value corresponding to a DataView to an array of bytes (i.e., an unsigned 8-bit integer array).
