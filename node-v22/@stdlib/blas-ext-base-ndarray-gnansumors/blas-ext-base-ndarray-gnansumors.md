# @stdlib/blas-ext-base-ndarray-gnansumors

> 标签: blas, extended, math, mathematics, ndarray, recursive, statistics, stats, stdlib, stdmath, sum, summation, total

## 简介

Compute the sum of a one-dimensional ndarray, ignoring `NaN` values and using ordinary recursive summation.
