# @stdlib/ndarray-reverse-dimension

> 标签: data, dimension, flip, matrix, ndarray, reverse, stdlib, stdtypes, structure, types, vector, view

## 简介

Return a read-only view of an input ndarray in which the order of elements along a specified dimension is reversed.
