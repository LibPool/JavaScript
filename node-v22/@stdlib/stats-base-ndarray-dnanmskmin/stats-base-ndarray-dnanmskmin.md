# @stdlib/stats-base-ndarray-dnanmskmin

> 标签: domain, extent, extremes, mask, masked, masked array, math, mathematics, min, minimum, ndarray, range, statistics, stats, stdlib, stdmath

## 简介

Compute the minimum value of a double-precision floating-point ndarray according to a mask, ignoring `NaN` values.
