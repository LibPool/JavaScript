# @stdlib/stats-base-smeanlipw

> 标签: arithmetic mean, array, average, avg, central tendency, float, float32, float32array, math, mathematics, mean, one-pass, pairwise, pw, single, statistics, stats, stdlib, stdmath, strided, strided array, typed, welford

## 简介

Calculate the arithmetic mean of a single-precision floating-point strided array using a one-pass trial mean algorithm with pairwise summation.
