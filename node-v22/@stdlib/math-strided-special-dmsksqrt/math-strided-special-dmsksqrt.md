# @stdlib/math-strided-special-dmsksqrt

> 标签: array, dbl, double, double-precision, element-wise, float64, float64array, mask, masked, math.sqrt, missing, missing values, na, ndarray, number, power, principal, root, sqrt, square, stdlib, strided, trig, vector

## 简介

Compute the principal square root for each element in a double-precision floating-point strided array according to a strided mask array.
