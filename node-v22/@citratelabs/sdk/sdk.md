# @citratelabs/sdk

> 标签: ai, citrate, distributed-ai, ethereum, javascript, ml, typescript, web3

## 简介

Canonical TypeScript/JavaScript SDK for the Citrate distributed AI network. This is the canonical SDK — all other language SDKs are non-canonical until a real pilot integrator requires parity.
