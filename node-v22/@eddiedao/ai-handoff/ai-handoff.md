# @eddiedao/ai-handoff

> 标签: ai-tunnel, automation, claude, claude-code, gh, github, handoff, issue, skill

## 简介

Deterministically hand a GitHub issue to the AI-tunnel bot: verify plan pushed to the default branch, set the plan marker in the issue body, then apply the trigger label last. A Claude Code skill + CLI.
