# @eddiedao/ai-tunnel

> 标签: agent, automation, ci, github, omp, orca, webhook, worktree

## 简介

Turn a labeled GitHub issue into an autonomous PR via a pluggable worktree environment (Orca) and coding harness (omp). Ships an interactive installer.
