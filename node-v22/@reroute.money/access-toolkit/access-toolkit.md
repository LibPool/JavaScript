# @reroute.money/access-toolkit

> 标签: JavaScript

## 简介

Reroute Money 接入点 REST `/v2/*` 的 TypeScript 客户端 | 签名鉴权、下单/查单/账户、信封解包与业务错误都在这一层。能力口径与仓库根的 [`golang/`](../golang) 版对齐，语义细节见[根 README](../README.md)。
