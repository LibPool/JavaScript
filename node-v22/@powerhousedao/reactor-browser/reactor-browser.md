# @powerhousedao/reactor-browser

> 标签: browser, document-model, drive-app, editor, event-sourcing, hooks, local-first, powerhouse, react, reactor, vetra

## 简介

Browser-side Powerhouse reactor — React hooks and IReactorClient for building editors and drive-apps inside Connect, Switchboard, or Vetra Studio.
