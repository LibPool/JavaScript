# @anvil-di/anvil-codegen-wasm

> 标签: JavaScript

## 简介

WASM build of the anvil codegen pipeline. Same parser + graph + emitter as the native CLI, in-process for any host that runs WebAssembly (Node, browsers, Workers, Bun).
