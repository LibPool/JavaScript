# @brightkyefoo/codevault

> 标签: backup, cli, disaster-recovery, export, sauvegarde, snapshot, source-code, vault

## 简介

Exporte le code de tes projets vers https://code-export.brightkyefoo.cm — sauvegarde hors-serveur, consultable en ligne, téléchargeable en zip, visible de toi seul.
