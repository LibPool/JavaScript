# @x-otto/plugin-skill-inductor

> 标签: JavaScript

## 简介

Skill inductor plugin — distills repeated task trajectories into episodes (RFC-318 M2). External plugin since 2026-08-13: install via `otto extension install plugin-skill-inductor` (registry) or `npm i -g @x-otto/plugin-skill-inductor`.
