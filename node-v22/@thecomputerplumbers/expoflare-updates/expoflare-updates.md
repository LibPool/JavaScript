# @thecomputerplumbers/expoflare-updates

> 标签: cloudflare, cloudflare-workers, expo, expo-updates, ota, r2

## 简介

Self-hosted Expo over-the-air updates on your own Cloudflare Worker: a mountable Expo Updates protocol handler, pluggable storage (R2, KV), and a publish CLI.
