# @codeimplants/version-control

> 标签: android, angular, app-version, capacitor, feature-control, force-update, ionic, ios, maintenance-mode, mobile-sdk, mobile-versioning, react, react-native, remote-config, sdk, soft-update, update-management, version-control

## 简介

A lightweight cross-platform SDK to remotely control app version behavior such as soft update, force update, and maintenance mode using backend-driven rules, without enforcing UI.
