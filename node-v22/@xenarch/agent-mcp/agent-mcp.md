# @xenarch/agent-mcp

> 标签: ai-agent-payments, base, base-l2, claude, cloudflare-alternative, crewai, cursor, http-402, langchain, machine-to-machine-payments, mcp, mcp-server, model-context-protocol, non-custodial, pay-json, pay-per-crawl, tollbit-alternative, usdc, x402, xenarch

## 简介

Non-custodial x402 MCP server for AI agents. Lets Claude, Cursor, LangChain and CrewAI pay for HTTP 402–gated APIs with USDC micropayments on Base L2. Unlike Cloudflare Pay-Per-Crawl, works on any host and settles agent-to-publisher direct.
