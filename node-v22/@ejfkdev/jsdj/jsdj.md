# @ejfkdev/jsdj

> 标签: cli, javascript, nextjs, recon, scanner, sourcemap, tls-fingerprint, utls, vite, webpack

## 简介

Extract JS URLs and source maps from websites: discover dynamically loaded JS, restore original sources from source maps. Library and CLI.
