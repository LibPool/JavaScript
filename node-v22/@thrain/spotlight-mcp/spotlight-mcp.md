# @thrain/spotlight-mcp

> 标签: accessibility, ada, eaa, mcp, modelcontextprotocol, pdf, pdf-ua, section-508, wcag

## 简介

MCP server that audits PDFs for accessibility (PDF/UA basics: tags, structure, language, title, alt text, reading order) entirely on the local machine. The free checker behind spotlight.thrain.ai.
