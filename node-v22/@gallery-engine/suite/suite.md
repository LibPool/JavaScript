# @gallery-engine/suite

> 标签: JavaScript

## 简介

Suite 是 Gallery Engine 的一站式入口包。它聚合 `core`、`layouts`、`animations`、`preview`、`plugins` 和 `shared` 的稳定命名 API，适合应用项目快速接入。🌟
