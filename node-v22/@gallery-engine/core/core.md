# @gallery-engine/core

> 标签: JavaScript

## 简介

Core 是 Gallery Engine 的运行时核心。它负责配置合并、生命周期、事件通信、渲染辅助、图片加载、懒加载、无限滚动、虚拟滚动和插件调度。🚀
