# @xiaopangshushu/npnpm

> 标签: cli, linux, macos, manager, npnpm, nvm, pnpm, pnpm-manager, unix, version, version-manager, 多版本管理, 版本控制

## 简介

npnpm - 跨 Node 版本的 pnpm 多版本管理器（类 nvm 设计，仅限 macOS/Linux）：安装一次自部署到 ~/.npnpm，nvm 任意切换 node 版本均可正常使用，支持 pnpm 多版本安装/切换/卸载
