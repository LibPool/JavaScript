# @sveltier/ui

> 标签: accessibility, agents, ai, components, design-system, fintech, llms, svelte, svelte5, ui

## 简介

The UI framework for AI coding agents, on Svelte 5: one typed vocabulary, docs generated from the types, and errors that say how to fix them.
