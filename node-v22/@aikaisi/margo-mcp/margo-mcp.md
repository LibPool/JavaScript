# @aikaisi/margo-mcp

> 标签: ai, annotations, claude, claude-code, code-notes, continue, copilot, cursor, margo, mcp, model-context-protocol

## 简介

MCP server for the Margo VS Code extension — exposes list/add/update/resolve tools so any MCP-compatible AI tool (Claude Code, Cursor, Continue, etc.) can read and write Margo code notes.
