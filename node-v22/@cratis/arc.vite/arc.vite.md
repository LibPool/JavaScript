> 标签: arc, aspnetcore, cqrs, cratis, proxy, typescript, vite, vite-plugin

## 简介

Vite helpers for Cratis Arc applications — metadata and query plugins for the generated TypeScript proxies of the CQRS framework for ASP.NET Core.
