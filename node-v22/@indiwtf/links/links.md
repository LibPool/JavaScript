# @indiwtf/links

> 标签: hooks, indiwtf, indonesia, links, react, sdk, shortlinks, url-shortener

## 简介

Typed, read-only client for the Indiwtf Links API — resolve a short link's currently active destination in Indonesia. Includes React hooks.

- 源码仓库：https://github.com/fransallen/indiwtf-sdk.git
