# @attestwire/stripe-einvoice

> 标签: cii, compliance, e-invoice, e-invoicing, einvoice, en16931, factur-x, facturx, invoice, peppol, stripe, stripe-invoice, ubl, vat, webhook, xrechnung, zugferd

## 简介

Turn a finalized Stripe invoice into a compliant EN 16931 e-invoice — XRechnung UBL or Factur-X/ZUGFeRD CII XML — mapped, generated and validated locally, with an optional call to the hosted Attestwire API for the Factur-X PDF.
