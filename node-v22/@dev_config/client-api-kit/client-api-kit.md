# @dev_config/client-api-kit

> 标签: api-client, axios, crud, nextjs, pagination, react-query, server-actions, server-components, tanstack-query, typescript

## 简介

Generic, type-safe API client built on axios and api-response-kit's response envelope. Framework-agnostic 'resources' for server components/server actions, plus a TanStack Query hooks layer for client components. Generic CRUD, offset + cursor pagination,
