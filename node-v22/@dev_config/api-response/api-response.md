# @dev_config/api-response

> 标签: api, crud, cursor-pagination, error-handling, express, fastify, http-errors, offset-pagination, pagination, response, rest, typescript

## 简介

Type-safe, framework-agnostic success/error response envelopes, error classes, and offset + cursor pagination helpers for Node.js APIs. Ships optional Express and Fastify adapters.
