# @vps-deckhand/vps-deckhand

> 标签: cli, typescript

## 简介

vps-deckhand is a simple CLI tool designed to streamline Linux VPS deployments by orchestrating code repositories, secrets, variables, DNS, and CI/CD pipelines from multiple providers, all from a single configuration file.
