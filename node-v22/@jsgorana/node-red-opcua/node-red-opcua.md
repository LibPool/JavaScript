# @jsgorana/node-red-opcua

> 标签: automation, iiot, industrial, node-red, opc-ua, opcua, scada

## 简介

Lean, modern OPC-UA client and server nodes for Node-RED 5.0 — read, write, browse, subscribe, and expose Node-RED data as an OPC UA server.
