# @tokenosdeai/receipt-verifier

> 标签: a2e, ai, audit, deai, ed25519, inference, receipt, tokenos, trust, verification

## 简介

Verify TokenOS DeAI inference receipts offline. Ed25519 over canonical-JSON serialization, no network calls, no platform trust required. Supports receipt-format spec v1.0 / v1.1 / v1.3 (version-gated canonicalization keeps every version verifiable).
