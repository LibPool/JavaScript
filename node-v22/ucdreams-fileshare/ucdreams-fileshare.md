# ucdreams-fileshare

> 标签: browser-transfer, datachannel, file-sharing, file-transfer, large-files, p2p, ucdreams, webrtc, zero-cloud-storage

## 简介

Client-side WebRTC RTCDataChannel peer-to-peer file transfer engine. Official open-source client for FileShareOnline by UCDREAMS (https://ucdreams.com).
