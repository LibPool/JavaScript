# @jsx-contracts/authoring

> 标签: composition, contracts, design-system, eslint, jsx, react, slots

## 简介

Type-safe authoring API for JSX composition contracts — defineContracts and the schema-shaped contract() surface that compiles to the rule table the @jsx-contracts/eslint-plugin rules consume.
