# @knowvah/dot-core

> 标签: @knowvah/dot-engine, dot, graphviz, render, svg

## 简介

Framework-agnostic Graphviz DOT → SVG render engine for static-site plugins, powered by the pure-TypeScript @knowvah/dot-engine.
