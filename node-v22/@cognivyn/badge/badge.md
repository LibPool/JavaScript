# @cognivyn/badge

> 标签: astro, attribution, badge, cognivyn, custom-element, footer-widget, react, svelte, typescript, utm-tracking, vue, web-component, zero-dependency

## 简介

Universal, zero-dependency footer badge web component for Cognivyn Infrasys client websites. Works with React, Vue, Svelte, Astro, and vanilla HTML.
