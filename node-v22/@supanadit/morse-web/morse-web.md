# @supanadit/morse-web

> 标签: agent, ai, angular, chat, mcp, morse, nest, pi, pi-coding-agent

## 简介

Comfortable Pi Interface in your browser: the Morse host (Angular + NestJS) as one installable package. `npm i -g @supanadit/morse-web` then `morse start`.
