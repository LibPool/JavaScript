# @darcas/rollup-sub-resource-integrity

> 标签: javascript, open-source, rollup, security, sri, subresource-integrity, typescript, vite-plugin, web-security

## 简介

A zero-dependency Rollup plugin that adds Subresource Integrity (SRI) attributes to HTML files to ensure the integrity of scripts and stylesheets using hashing algorithms like SHA-256, SHA-384, and SHA-512.
