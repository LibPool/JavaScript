# @libs-ui/services-grid-layout

> 标签: JavaScript

## 简介

Mặt phẳng kéo–thả. Thư viện lo **toàn bộ** việc vẽ lưới, kéo thả, đổi kích thước, lồng container, tay cầm kéo, bộ nút trên khối, viền chế độ sửa, và dọn dẹp khi component chết.
