# @useavalon/mcp

> 标签: ai-agents, astro-migration, avalon, hydration, islands, llm-tools, mcp, model-context-protocol

## 简介

Model Context Protocol (MCP) server for the Avalon Framework — teaches AI agents Avalon's island/hydration directives so they don't confuse them with Astro's client:* attributes
