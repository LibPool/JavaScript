# @franck35/nuxt-version-page

> 标签: JavaScript

## 简介

Ce layer Nuxt permet d'extraire, de centraliser et d'afficher de manière élégante les informations de versioning de votre application (version du package, versions des frameworks, versions de Node.js au build et au runtime, ainsi que la date de build).
