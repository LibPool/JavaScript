# @oshal/chat

> 标签: JavaScript

## 简介

Local desktop node that joins the OSHAL swarm as an A2A remote client: a Jarvis-style orb you talk to, that also runs swarm-dispatched tasks locally with your own signed-in CLIs (codex/claude/gcloud/aws).
