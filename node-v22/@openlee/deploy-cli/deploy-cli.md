# @openlee/deploy-cli

> 标签: ci-cd, claude-code, cli, deploy, devops, docker, nginx, ssh

## 简介

Universal CLI for deploying frontend/full-stack projects via SSH. Supports static builds, Docker, and Nginx Proxy Manager.
