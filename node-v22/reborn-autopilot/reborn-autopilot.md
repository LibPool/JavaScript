# reborn-autopilot

> 标签: claude, claude-code, content-calendar, instagram, korean, skill

## 简介

클로드 코드에 「내 분야 + 공개 인스타 아이디」를 말하면 30일치 릴스·캐러셀·스토리·훅 콘텐츠 캘린더를 한 장으로 짜 주는 스킬(content-autopilot)을 스킬 폴더에 놓고, 파일이 실제로 늘었는지 다시 셉니다. 인스타 계정에 로그인하거나 연결하지 않습니다 — 공개 웹 조사와 직접 붙여 준 숫자만 씁니다. 캘린더는 초안이며 효과를 약속하지 않습니다.
