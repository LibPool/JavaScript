# @zyntek/storage

> 标签: bucket, object-storage, s3, storage, zyncloud, zyntek

## 简介

SDK oficial de ZynCloud Object Storage (S3 de Zyntek). Buckets y objetos con firma ZYN1, como @aws-sdk/client-s3 para S3.
