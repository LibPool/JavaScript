# @flow-as-code/tf

> 标签: amazon-connect, aws, contact-center, contact-flow, infrastructure-as-code, ivr, opentofu, terraform, typescript

## 简介

Terraform/OpenTofu emitter: FlowDoc to aws_connect_* resources, .tftpl content, and an awscc version/alias scaffold. One-way in v1.
