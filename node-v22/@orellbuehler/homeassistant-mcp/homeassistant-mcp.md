# @orellbuehler/homeassistant-mcp

> 标签: ai, ai-agents, automation, claude, hass, home-assistant, home-automation, homeassistant, llm, mcp, mcp-server, model-context-protocol, smart-home

## 简介

Model Context Protocol server for Home Assistant: introspect entities, services, events, registries, render templates and validate configuration to help AI agents author HA configs and automations.
