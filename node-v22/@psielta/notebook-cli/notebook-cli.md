# @psielta/notebook-cli

> 标签: cli, golang, nb, note-taking, notebook, notes, productivity, sqlite, terminal

## 简介

nb — a fast, local-first notes CLI. Organize notes into notebooks straight from your terminal. Cross-platform, single SQLite store, no daemon, no config.
