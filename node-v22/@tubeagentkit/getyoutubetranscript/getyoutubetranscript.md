# @tubeagentkit/getyoutubetranscript

> 标签: ai, api-client, captions, llm, rag, sdk, subtitles, timestamps, transcript, transcripts, typescript, youtube, youtube-api, youtube-captions, youtube-search, youtube-subtitles, youtube-transcript, youtube-transcript-api, youtube-transcripts

## 简介

YouTube transcript API for Node.js and TypeScript: get YouTube video transcripts, captions and subtitles with timestamps, search YouTube, and list channel and playlist videos. No proxies or headless browser.
