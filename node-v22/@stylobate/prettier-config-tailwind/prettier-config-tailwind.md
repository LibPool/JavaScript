# @stylobate/prettier-config-tailwind

> 标签: JavaScript

## 简介

在 [`@stylobate/prettier-config`](../prettier-config) 之上叠加 [`prettier-plugin-tailwindcss`](https://github.com/tailwindlabs/prettier-plugin-tailwindcss)，自动按 Tailwind 推荐顺序整理 `class` 属性。
