# @jahidorjahid/react-bdmap

> 标签: bangladesh, bd, choropleth, component, data-visualization, divisions, interactive-map, map, react, svg

## 简介

An interactive, accessible SVG map of Bangladesh for React — choropleth data binding, selection, tooltips, labels and lat/lng markers. Zero dependencies.
