# @domainkits/mcp

> 标签: dns, domain-api, domain-data, domain-search, domainkits, expired-domain-search, expired-domains, expired-domains-data, mcp, model-context-protocol, newly-registered-domains, newly-registered-domains-api, newly-registered-domains-list, search-expired-domains, search-newly-registered-domains, whois

## 简介

MCP server for the DomainKits domain data API. Exposes expiring domains, newly registered domains, DNS, WHOIS and more to any MCP client.
