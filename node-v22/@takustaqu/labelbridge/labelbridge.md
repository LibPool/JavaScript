# @takustaqu/labelbridge

> 标签: dot-by-dot, electron, label-printer, raster, web-serial, webusb

## 简介

Dot-by-dot printing for some KING JIM label printers without vendor drivers. Browser (WebUSB / Web Serial) and Node (LAN).
