# @vibeinfra/mcp-server

> 标签: devops, incident-response, infrastructure, kubernetes, mcp, mcp-server, modelcontextprotocol, sre, vibeinfra

## 简介

Model Context Protocol server for VibeInfra — enables AI agents to browse the SRE incident catalog, start live disposable sandboxes, coach learners with hints, and grade remediations.
