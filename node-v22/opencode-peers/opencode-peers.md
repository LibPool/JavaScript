# opencode-peers

> 标签: ai-coding-agent, claude-code, cross-session, messaging, multi-agent, opencode, opencode-plugin

## 简介

Cross-session messaging for opencode (one package for v1 and v2 hosts) — let independent sessions discover and text each other, modeled after Claude Code's cross-session messaging
