# @freshjuice/astro-search-plugin

> 标签: astro, astro-component, astro-integration, cmd-k, command-palette, custom-element, framework-agnostic, freshjuice, fulltext, fulltext-search, orama, react, search, search-plugin, static-search, svelte, vue, web-component

## 简介

Framework-agnostic, type-safe search for Astro 5+ powered by Orama. Build the index at build time, query it client-side, drop in a Cmd+K palette as a web component (vanilla, Vue, Svelte, Solid…) or React component. Apache-2.0, no runtime CDN, no telemetry
