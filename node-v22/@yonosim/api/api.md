# @yonosim/api

> 标签: connectivity, esim, esim-api, placeholder, sdk, travel, yonosim

## 简介

Placeholder for the official TypeScript SDK for the YonoSIM API (api.yonosim.com). The full generated SDK ships alongside the first paying partner integration — until then, the API is REST-only and pastable curl commands are all you need. See https://yono
