# @lewis-rotchell/wp-gutenberg-create-block

> 标签: JavaScript

## 简介

Gutenberg Create Block is a command line tool that allows you to quickly create new blocks for your Gutenberg WordPress themes. With this tool, you can easily create new blocks in either PHP or JavaScript, or both.
