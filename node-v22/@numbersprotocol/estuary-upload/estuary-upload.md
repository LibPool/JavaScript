# @numbersprotocol/estuary-upload

> 标签: JavaScript

## 简介

Upload your file to Estuary and generate Numbers ID (Nid, the same as [default IPFS CIDv1](https://github.com/ipfs/kubo)).

## 官网

- npm 页面：https://www.npmjs.com/package/@numbersprotocol/estuary-upload

- npm registry：https://registry.npmjs.org/@numbersprotocol/estuary-upload
- Node 要求：>=14.16
