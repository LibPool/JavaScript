# kiotvietsdk

> 标签: api, ecommerce, express, hono, kiotviet, nestjs, nextjs, pos, retail, sdk, tanstack-start, typescript

## 简介

TypeScript SDK for the KiotViet Retail Public API — full endpoint coverage, better-auth-style setup with a mountable handler, adapters for Express, Hono, NestJS, Next.js and TanStack Start, and a type-safe browser client
