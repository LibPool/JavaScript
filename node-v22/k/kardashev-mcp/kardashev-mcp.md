# kardashev-mcp

> 标签: ERCOT, ISO, LMP, RTO, carbon intensity, curtailment, electricity, energy, forecast, grid, interconnection queue, mcp, model-context-protocol

## 简介

MCP server for Kardashev Labs US grid data — LMP, carbon, load, curtailment, interconnection queues, ERCOT large loads, and live RT−DA spread forecasts. No API key required.
