# kilo-opencode-command-code

> 标签: ai, command-code, commandcode, kilo, llm, opencode, plugin, provider

## 简介

Command Code Provider API plugin for Kilo and OpenCode — auto-syncs models and capabilities (vision/reasoning), handles auth, routes Claude via the Anthropic Messages endpoint
