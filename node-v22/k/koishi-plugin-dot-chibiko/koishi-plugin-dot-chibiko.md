# koishi-plugin-dot-chibiko

> 标签: chatbot, chibi, gif, koishi, minecraft, plugin, skin

## 简介

将Minecraft的皮肤PNG转换为双身小角色GIF和PNG。支持39种动态GIF和18种静态图片
