# kinbot-plugin-teamspeak

> 标签: channel, kinbot, kinbot-plugin, teamspeak, tts, voice

## 简介

Bridge KinBot with a TeamSpeak server via the local ts-bot WebSocket API. Channel adapter (chat + TTS) + tools (move, speak, send chat, status, per-speaker WAV recording).
