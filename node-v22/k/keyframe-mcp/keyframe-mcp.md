# keyframe-mcp

> 标签: 2d-animation, animation, claude, game-development, gamedev, keyframe, mcp, mcp-server, model-context-protocol, modelcontextprotocol, pixi-spine, skeletal-animation, slot-symbols, spine, sprite

## 简介

MCP server for Keyframe.it — let Claude (or any MCP client) rig, animate and export 2D skeletal animations by driving the free Keyframe.it editor in your browser.
