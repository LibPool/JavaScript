# kaitai-struct-loader

> 标签: binary, kaitai, loader, parsing, struct, webpack

## 简介

This [webpack loader](https://webpack.js.org/concepts/loaders/) adds support for [Kaitai Struct](https://kaitai.io) .ksy definitions.
