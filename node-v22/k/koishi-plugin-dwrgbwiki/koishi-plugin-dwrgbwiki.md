# koishi-plugin-dwrgbwiki

> 标签: bwiki, koishi, plugin, winrate, 第五人格

## 简介

第五人格BWIKI编辑组开发，所有代码由DeepSeek V4 Flash 0731编写。支持胜率/地图/模仿者/勋章/基础数据查询、图鉴查询、wiki页面截图、藏头诗、抽卡模拟、加页手记探索、赛事数据（选手/对决）、公告变动推送、BWIKI页面更新推送、反馈系统等功能。
