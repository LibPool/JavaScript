# keelrun-cli-linux-arm64-musl

> 标签: JavaScript

## 简介

Prebuilt `keel` CLI binary for Linux aarch64, statically linked (musl) — runs on glibc hosts too, so no libc restriction is declared here. Optional dependency of keelrun-cli — installed automatically on a matching platform, ignored otherwise. See scripts/
