# koishi-plugin-membership-accept

> 标签: chatbot, koishi, plugin, wikidot

## 简介

全自动审批 Wikidot 成员申请书插件：读取待审批申请书、转发到群聊并支持通过/拒绝（Auto-approve Wikidot membership applications）
