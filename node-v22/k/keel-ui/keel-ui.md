# keel-ui

> 标签: component-library, components, dark-mode, design-system, react, shadcn, tailwind, typescript, ui

## 简介

A shadcn-inspired React component library with accessible primitives, product patterns, CSS-variable theming, dark mode, and zero runtime dependencies.
