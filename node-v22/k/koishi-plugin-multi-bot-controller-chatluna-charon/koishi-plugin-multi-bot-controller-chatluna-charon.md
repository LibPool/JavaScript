# koishi-plugin-multi-bot-controller-chatluna-charon

> 标签: chatbot, chatluna, koishi, multi-bot, persona, plugin

## 简介

Charon, the ancient Greek god of the River Styx, is configured to assign each Bot an independent ChatLuna persona (with unique presets and models), achieving persona isolation across multiple Bots.
