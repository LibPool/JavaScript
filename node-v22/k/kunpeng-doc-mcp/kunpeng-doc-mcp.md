# kunpeng-doc-mcp

> 标签: BoostKit, DevKit, HPCKit, kunpeng, 原生开发, 应用迁移, 系统迁移, 编译, 调优, 鲲鹏, 鲲鹏文档, 鲲鹏社区, 鲲鹏高性能计算

## 简介

将鲲鹏开发技术文档（含鲲鹏社区和鲲鹏相关开源仓）包装成MCP标准只读数据源，让任何兼容 MCP 的 Agent 都能便捷地引用权威资料，减少大模型知识幻觉；它只做资料读取，不执行操作。
