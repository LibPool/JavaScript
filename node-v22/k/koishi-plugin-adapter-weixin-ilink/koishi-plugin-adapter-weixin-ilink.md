# koishi-plugin-adapter-weixin-ilink

> 标签: adapter, chatbot, clawbot, ilink, koishi, plugin, weixin, 微信

## 简介

微信 ClawBot 适配器，支持扫码登录及文本、图片、文件和视频收发，仅用于 ClawBot 会话。
