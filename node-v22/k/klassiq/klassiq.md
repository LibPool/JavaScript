# klassiq

> 标签: agent, ai, cli, coding, developer-tools, llm, terminal, tui

## 简介

Klassiq — a terminal coding agent with build/plan/chat modes, autonomous file tools, and your own AI provider keys. Install it, then use it: a keyboard-first TUI like opencode.
