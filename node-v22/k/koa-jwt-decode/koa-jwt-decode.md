# koa-jwt-decode

> 标签: jwt, koa

## 简介

Koa middleware to only decode JWT tokens to context.state.user property (IMPORTANT: it does NOT verify the token)

- 源码仓库：git@github.com/victorperin/koa-jwt-decode.git
