> 标签: claude, claude-code, cli, flashcards, fsrs, hiragana, japanese, kana, katakana, spaced-repetition, terminal, tmux

## 简介

Learn hiragana & katakana in the dead time while Claude Code is thinking — a kana flashcard pane that pops up beside Claude while it works.
