# kiro-langfuse-export

> 标签: agent, export, hook, kiro, kiro-agent, langfuse, llm, observability, tracing

## 简介

Export Kiro IDE (kiro-agent) sessions to Langfuse, one trace per turn. Installs as a Kiro Stop hook.
