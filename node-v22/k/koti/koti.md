## 简介

CLI tool to scaffold Bun API projects with a choice of Express or Elysia framework and MongoDB or PostgreSQL database. Pick both at create time (--framework express|elysia --database mongodb|postgres) with full feature parity: JWT auth, RBAC, audit, docum
