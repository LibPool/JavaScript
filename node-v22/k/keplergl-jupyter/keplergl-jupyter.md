# keplergl-jupyter

> 标签: ipython, ipywidgets, jupyter, jupyterlab, jupyterlab-extension, widgets

## 简介

This is a simple jupyter widget for kepler.gl, an advanced geo-spatial visualization tool, to render large-scale interactive maps.

- 官网：https://github.com/keplergl/kepler.gl#readme
