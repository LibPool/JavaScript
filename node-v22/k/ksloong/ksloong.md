# ksloong

> 标签: JavaScript

## 简介

本组件库是一个使用 Dumi 精心构建的 React 项目，它巧妙地融合了 Ant Design（Antd）、axios 等业界领先的组件库，其核心组件——FormPanel，旨在提供一种高效、灵活的表单构建解决方案。
