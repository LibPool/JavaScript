# kalendly

> 标签: angular, calendar, custom-elements, datepicker, events, react, scheduler, typescript, vue, web-components

## 简介

A universal calendar web component — works in React, Vue, Angular, Svelte, Solid.js, and plain HTML with no framework dependency
