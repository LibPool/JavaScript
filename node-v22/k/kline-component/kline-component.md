# kline-component

> 标签: BOLL, EMA, KDJ, MA, MACD, RSI, candlestick, canvas, chart, crypto, kline, react, stock, technical-analysis, trading

## 简介

A high-performance React K-line (candlestick) chart component with Canvas rendering, 7 technical indicators, dark/light themes, zoom, pan, and crosshair.
