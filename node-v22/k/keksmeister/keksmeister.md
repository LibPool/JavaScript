# keksmeister

> 标签: consent-management, cookie-banner, cookie-consent, custom-element, dsgvo, eprivacy, gdpr, privacy, shadow-dom, web-component

## 简介

A modern, framework-agnostic cookie consent Web Component with Shadow DOM encapsulation. Built for GDPR/DSGVO compliance.
