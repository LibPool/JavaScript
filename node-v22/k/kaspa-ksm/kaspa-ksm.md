# kaspa-ksm

> 标签: covenant, kaspa, kip-20, ksm, p2sh, silverscript, verification

## 简介

Kaspa Spend Map (.ksm): a portable file for verifying and spending Kaspa P2SH covenants without the service that created them, and for verifying KIP-20 covenants by ID
