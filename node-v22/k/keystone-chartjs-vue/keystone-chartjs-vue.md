# keystone-chartjs-vue

> 标签: annotation, bar-chart, boxplot, bubble-chart, candlestick, chart, chart.js, chartjs, charts, composition-api, data-visualization, datalabels, doughnut-chart, horizontal-bar, line-chart, matrix-chart, mixed-chart, ohlc, pie-chart, polar-area, radar-chart, reactive, resize, sankey, scatter-chart, treemap, typescript, violin, visualization, vue, vue3, zoom

## 简介

A single, generic <Chart> component for Vue 3 wrapping Chart.js — every built-in chart type plus the financial, boxplot, matrix, sankey, and treemap extensions, selected via a `type` prop.
