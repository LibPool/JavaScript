# koishi-plugin-idv-rank-stats

> 标签: chatbot, koishi, plugin

## 简介

第五人格排位数据查询插件，支持查询本赛季各角色的平率、胜率和使用率，帮助玩家了解当前环境和角色表现，辅助制定对局策略。
