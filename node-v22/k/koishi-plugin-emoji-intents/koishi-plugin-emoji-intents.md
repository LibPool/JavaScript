# koishi-plugin-emoji-intents

> 标签: chatluna, emoji, emojiluna, koishi, plugin

## 简介

意图式表情注入:把 emojiluna 的标签/分类词表(而非逐张 URL 清单)注入 chatluna,模型挑意图、服务器随机选图;token 随标签数封顶,不随图片数增长
