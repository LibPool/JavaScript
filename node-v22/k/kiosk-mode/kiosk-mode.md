# kiosk-mode

> 标签: digital-signage, fullscreen, kiosk, kiosk-mode, no-sleep, pwa, react, screen-orientation, self-service, tablet, touchscreen, wake-lock

## 简介

One call to put a web page into real kiosk mode: fullscreen, wake lock, orientation lock, gesture and key blocking, idle reset, hidden exit gesture.
