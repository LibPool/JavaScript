# koishi-plugin-kardsman

> 标签: kards, koishi, plugin

## 简介

KARDS 卡牌游戏助手：解析 %% 卡组代码并生成卡组预览图，支持自动同步卡牌数据库、定时检测版本更新、按需补卡
