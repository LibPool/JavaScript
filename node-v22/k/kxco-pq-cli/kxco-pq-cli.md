# kxco-pq-cli

> 标签: cli, command-line, deterministic-keygen, fingerprint, fips-204, jcs, json-canonicalization, key-management, key-rotation, keygen, kxco, ml-dsa, nist, post-quantum, pqc, rotation-manifest, well-known

## 简介

Command-line post-quantum key management for institutions: generate ML-DSA-65 keypairs, rotate keys with an on-chain anchor, sign files and verify signatures, all without writing code.
