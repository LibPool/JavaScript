# kilde

> 标签: async state, backpressure, channels, computed, csp, reactive, select, signals, store, streams

## 简介

Signals, streams, and channels for JavaScript — synchronous reactivity, backpressured push streams, CSP-style coordination, and async state, with pluggable ownership. No dependencies.
