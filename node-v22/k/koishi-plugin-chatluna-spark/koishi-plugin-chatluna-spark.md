# koishi-plugin-chatluna-spark

> 标签: ai, chatbot, chatluna, koishi, koishi-plugin, proactive, reminder, scheduled

## 简介

为 ChatLuna 添加主动对话能力的 Koishi 插件，基于 ChatLuna Agent Trigger 支持定时提醒、跟进、节日问候、主动聊天等功能
