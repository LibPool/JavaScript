## 简介

A lightweight, agent-agnostic Kanban skill set (Claude Code, Codex, OpenCode, Gemini, AGENTS.md) — a tiny Jira for 1–2 people where AI agents pick up and ship cards. Zero infra: one HTML board + one JSON file + four skills.
