# koishi-plugin-ojita

> 标签: chatbot, koishi, plugin

## 简介

这是一个koishi插件，用于访问https://janice.e-351.com/获取物品估价并返回给用户。
 包含两个参数 apiUrl:https://janice.e-351.com/api/rest/v2/appraisal?market=2&persist=true&compactize=true&pricePercentage=1 
 apiKey:请通过DISCORD联系原网站作者获取。
