# kitty-media-player

> 标签: audio, cli, ffmpeg, ghostty, ink, kitty, kitty-graphics, media, player, terminal, tui, video

## 简介

Terminal media player for video and audio files. Ink UI with a kitty-motion video panel over Kitty graphics Unicode placeholders.
