# kakizaki-otayori-web

> 标签: feedback, framework-agnostic, self-hosted, slack, web-sdk, widget

## 简介

アプリ内フィードバックを Slack へ届ける おたより の Web SDK。フローティングマスコット + チャット UI をフレームワーク非依存で提供する (iOS の OtayoriKit と同一の UI/UX)
