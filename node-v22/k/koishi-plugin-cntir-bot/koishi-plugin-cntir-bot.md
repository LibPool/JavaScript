# koishi-plugin-cntir-bot

> 标签: american-truck-simulator, ats, chatbot, cntir, ets2, euro-truck-simulator, koishi, plugin, truckersmp

## 简介

CNTIR 平台功能插件：服务器状态+在线趋势 / 统计 / 玩家资料(多账号选择) / 新闻公告 / 活动+倒计时 / 车队+排行 / 定位 / 足迹 / 绑定(好号庆祝) / 签到活跃榜 / 谁在线 / @多人对比（指令以 C 结尾，发「菜单/帮助」出菜单卡）
