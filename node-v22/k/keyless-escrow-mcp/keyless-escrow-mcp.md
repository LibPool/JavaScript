# keyless-escrow-mcp

> 标签: agent, escrow, mcp, model-context-protocol, non-custodial, solana

## 简介

MCP server for keyless-escrow — open, inspect, and resolve non-custodial Solana escrows as agent tools. A moderator can release funds but never steal them.
