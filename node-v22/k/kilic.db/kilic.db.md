# kilic.db

> 标签: database, db, kilic, mongodb, mongoose, nosql, orm, singleton, wrapper, zero-boilerplate

## 简介

Tiny MongoDB helper for Node.js. Configure once, create/get/update/delete everywhere, and drop to raw Mongoose when needed.
