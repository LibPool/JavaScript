# kenya-regions

> 标签: administrative-divisions, census, constituencies, counties, districts, divisions, dropdown, east-africa, geodata, geojson, iebc, iso-3166-2, kenya, knbs, locations, map, outlines, pcodes, point-in-polygon, provinces, provincial-administration, regions, sub-counties, sub-locations, wards

## 简介

Offline dataset and typed API for every way Kenya is divided: 47 counties, 290 constituencies, 1450 wards, the 8 former provinces, ISO 3166-2 codes, OCHA p-codes, regional economic blocs and the ASAL classification. No network, no dependencies.
