# keyless-escrow

> 标签: arbiter, durable-nonce, escrow, jito, keyless, non-custodial, p2p, solana

## 简介

Non-custodial, arbiter-mediated escrow for Solana. The vault has no private key, so a moderator can RELEASE funds but can never STEAL them. Atomic settlement via Jito bundles.
