# koishi-plugin-group-verification

> 标签: chatbot, group-verification, guild-management, join-request, koishi, moderation, plugin

## 简介

Koishi 群组加群验证插件，支持多关键词匹配审核、多种审核方式、黑名单和详细统计功能
