# koishi-plugin-ai-manager

> 标签: chatbot, koishi, plugin

## 简介

基于大模型的全自动群组消息审查。汇总消息并进行分析，并根据预设规则，自动对违规消息执行撤回、转发操作，或对违规用户进行禁言或踢出。
