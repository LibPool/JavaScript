# koishi-plugin-blind-watermark

> 标签: blind-watermark, dwt, image, koishi-plugin, steganography, watermark

## 简介

盲水印：往图片里嵌入看不见的水印（文字 / 图片），需要时再从图片里原样提取出来 —— 基于 guofei9987/blind_watermark（DWT-DCT-SVD，抗缩放 / 裁剪 / 旋转 / 截屏等攻击）
