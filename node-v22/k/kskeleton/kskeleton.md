# kskeleton

> 标签: loading, placeholder, shimmer, skeleton, skeleton-screen, svelte, svelte5

## 简介

Automatic skeleton loading overlays for Svelte 5. Mark an element and KSkeleton draws a shimmering placeholder that matches its real size, position and border radius.
