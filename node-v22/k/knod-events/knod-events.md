# knod-events

> 标签: cli, eventbrite, events, ical, luma, mcp, scraper

## 简介

Import structured event data (name, date, location, cover image) from Luma, Eventbrite, Partiful, Meetup, Ticketmaster — CLI + MCP server. No API key.
