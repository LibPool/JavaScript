# kijito-inbox-monitor

> 标签: agent, cli, inbox, kijito, monitor, pipx, python, watcher

## 简介

Pointer to the Python package kijito-inbox-monitor. A zero-dependency watcher that wakes a running agent when new Kijito inbox mail arrives. Install the real tool with pipx/uv/pip.
