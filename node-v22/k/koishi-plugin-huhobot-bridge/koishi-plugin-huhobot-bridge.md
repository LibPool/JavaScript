# koishi-plugin-huhobot-bridge

> 标签: bds, chat-bridge, koishi, minecraft, napcat, online-query, plugin, qq, websocket

## 简介

为 HuHoBot BDS 插件提供 WebSocket 桥接服务，实现 Minecraft 游戏内聊天与 QQ 群消息互通，以及在线玩家查询功能。
