# koishi-plugin-bilibili-notify-bridge

> 标签: bilibili, chatbot, koishi, plugin

## 简介

把这台 koishi 里已经配好的 bot 借给 bilibili-notify 用 —— 它监听 B 站 UP 主的动态 / 直播，渲染成卡片图片推送出去：https://github.com/Akokk0/bilibili-notify
