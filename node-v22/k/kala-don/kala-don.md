# kala-don

> 标签: Framework, Kala Don, Kala-Don, KalaDon

## 简介

Kala-Don is a powerful Node.js framework that simplifies backend development with built-in support for REST APIs, PostgreSQL, Prisma, WebSocket, email, security, and more.
