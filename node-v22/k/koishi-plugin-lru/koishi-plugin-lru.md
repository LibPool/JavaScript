# koishi-plugin-lru

> 标签: chatbot, koishi, plugin

## 简介

踢出最长时间没发言的群友，仅支持OneBot协议，提供不踢有头衔群友以及更高群等级的选项。如更新了0.2.1~0.2.4的朋友，必须卸载重装
