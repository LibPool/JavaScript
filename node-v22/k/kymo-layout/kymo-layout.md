# kymo-layout

> 标签: dagre, diagram, flowchart, graph, kymo, layout, wasm

## 简介

Pure-Rust graph/diagram layout algorithms for kymo's mermaid renderers (dagre, layered/Sugiyama, grid, force-directed) — no merman dependency.
