# koa-server-static

> 标签: file, koa, middleware, sendfile, static

## 简介

koa-static的增强版,支持动态选择pc端还是移动端的静态文件,coderlibs官方提供的Koa静态文件服务中间件

- 源码仓库：git+https://github.com/coderlibs/koa-server-static.git
- npm 页面：https://www.npmjs.com/package/koa-server-static
