# keelrun-cli

> 标签: JavaScript

## 简介

The `keel` CLI binary (run/doctor/init/status/mcp/explain/...) via npm. Downloads nothing at install time — the matching platform package is an optionalDependency, resolved the same way keel-core-native's napi addon is. Source-only in a dev checkout; bina
