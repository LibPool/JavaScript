# koishi-plugin-cloudery-ai-image

> 标签: ai, gemini, gpt, image-generation, image2image, koishi, koishi-plugin

## 简介

AI 生图插件：接入 OpenAI 通用模型（Gemini 等），支持积分系统，可生成动漫化/手办化图片（fork 自 koishi-plugin-ll-ziyong，使用 koishi-plugin-monetary 积分系统）
