# kaamelott-ipsum-cli

> 标签: cli, ipsum, kaamelott, lipsum, lorem

## 简介

Kaamelott Ipsum CLI is a Command Line Interface that generates Lorem Ipsum text from the famous quotes of the French TV series "Kaamelott" created by Alexandre Astier.
