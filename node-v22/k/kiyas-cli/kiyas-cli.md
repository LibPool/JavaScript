# kiyas-cli

> 标签: ai, claude, cli, codex, cursor, design, design-system, figma, mcp, model-context-protocol, qa, vision

## 简介

MCP server and CLI for AI-powered design fidelity — compare Figma designs (or screenshots) against rendered UI. Measured on a golden eval set: 90% mutation recall, zero false positives on clean pairs. Uses your Claude Code or Codex subscription — no API k
