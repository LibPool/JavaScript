# koishi-plugin-elysia-api-orchestrator

> 标签: ai, chatbot, elysia-api, koishi, llm, plugin

## 简介

Inspired by New-API, the Elysia-API model orchestrator plugin manages API gateways and allows users to define custom model groups. This plugin depends on the model aggregator plugin.
