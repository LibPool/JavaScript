# kalp-fabric-js-sdk

> 标签: Fabric Shim, Hyperledger Fabric, fabric-shim

## 简介

A node.js implementation of Hyperledger Fabric chaincode shim, to allow endorsing peers and user-provided chaincodes to communicate with each other

- 官网：https://github.com/hyperledger/fabric-chaincode-node#readme
- 源码仓库：git+https://github.com/hyperledger/fabric-chaincode-node.git
- npm 页面：https://www.npmjs.com/package/kalp-fabric-js-sdk
