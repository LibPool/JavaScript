# k2js

> 标签: JavaScript

## 简介

## do - 设置0值，不会报错、不会越界 - 设置100值，不会报错、不会越界 - 选择时，产生动画和浮动窗 - resize时，界面刷新，不会产生动画 - 文字随分辨率改变
