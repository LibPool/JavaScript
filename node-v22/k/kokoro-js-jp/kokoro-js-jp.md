# kokoro-js-jp

> 标签: browser, japanese, kokoro, open-jtalk, text-to-speech, tts, wasm

## 简介

Browser-based English + Japanese TTS: kokoro-js (Kokoro-82M via transformers.js/ONNX) + openjtalkjs (Open JTalk G2P, WASM). No server or container required.
