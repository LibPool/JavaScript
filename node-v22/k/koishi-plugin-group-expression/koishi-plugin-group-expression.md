# koishi-plugin-group-expression

> 标签: chatbot, koishi, plugin

## 简介

用于群聊使用表情包，使用习惯参考Miao-yunzai的表情。本插件是完美兼容云崽的喵喵插件的表情管理。可以直接把原来的数据迁移过来即可使用。
