# knowbase

> 标签: ai, claude-code, daemon, feishu, git, knowledge-base, lark, markdown, mirror, sync

## 简介

以飞书知识库为唯一真相源的团队知识镜像：exporter 把飞书导出为 Git 仓库，成员本机维护一份只读 Markdown 镜像，agent 读走本地 grep、写走飞书。安装即忘，后台自动同步。
