# kanbo-board

> 标签: cli, git, issue-tracker, kanban, local-first, mcp, model-context-protocol, project-management, roadmap, sprints

## 简介

Local-first project management. Kanban, sprints and roadmap from your terminal, with a git repo as the only backend. Ships an MCP server too.
