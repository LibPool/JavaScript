# kix

> 标签: dev-kit, dom, interface, javascript, js, js-dom, js-kix, jsx, kid-js, kix, kix-dom, kix-js, ts, tsx, typescript, ui, website

## 简介

Kix is a platform for building web applications. Kix makes it painless to create interactive UIs. Declarative views make your code more predictable and easier to debug.
