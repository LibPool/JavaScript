# kcv-sdk

> 标签: cambodia, face-compare, face-liveness, identity, kcv, kyc, ocr, sdk, typescript

## 简介

TypeScript/JavaScript SDK for the KCV (Khmer Computer Vision) REST API — OCR extraction, passive face liveness, and face comparison.
