# keycloak-connect-adapter

> 标签: authentication, keycloak, oauth, oauth2.0, sso

## 简介

A Fork of Keycloack-nodejs-connect with improved token validation. Official Keycloak-connect adapter invalidates token from different hostname even though Keycloak frontend URL is provided. This repo is a quick fix for the aforementioned issue.
