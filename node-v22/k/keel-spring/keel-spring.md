# keel-spring

> 标签: agents, codegen, dsl, keel, spring-boot

## 简介

Generador Spring Boot para diseños Keel: valida el diseño agnóstico y genera services/<servicio>-spring/ con el scaffolding transversal al stack más el conocimiento del agente; los adaptadores de infraestructura y la lógica de negocio los completa el agen
