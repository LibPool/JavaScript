# kr-history-bm25

> 标签: baekje, bm25, classical-chinese, corea, drizzle, fts5, full-text-search, goguryeo, gojoseon, goryeo, goryeosa, hanja, historical-geography, korea, korean-history, literary-chinese, mcp, place-name-identification, samguk-sagi, samguk-yusa, silla, simplified-chinese, sqlite, toponym, traditional-chinese, 고려사, 삼국사기, 역사지리

## 简介

Convert Korean historical source XML (국사편찬위원회 한국사DB) into a searchable SQLite BM25 corpus — hanja-primary full-text search, structured place/person index, co-occurrence clustering, and an optional LLM literal-translation secondary index.
