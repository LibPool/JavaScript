# keyboard-shortcutx

> 标签: event listener, hotkey, hotkeys, javascript hotkeys, keybinding, keyboard, keyboard events, keyboard manager, keyboard-shortcut, react hook, react shortcuts, shortcut, shortcut-manager

## 简介

Lightweight, dependency-free keyboard shortcut & hotkey manager for JavaScript and React. ESM-first, easy API, supports global and component-level shortcuts.
