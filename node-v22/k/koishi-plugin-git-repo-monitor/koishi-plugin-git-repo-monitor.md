# koishi-plugin-git-repo-monitor

> 标签: chatbot, git, koishi, monitor, plugin, typst

## 简介

监控 Git 仓库变化并推送通知到指定频道，🎨 支持 Typst 和 puppeteer 渲染图片卡片， 📦目前支持Github 和 Gitee
