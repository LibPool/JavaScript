# kiro-memory

> 标签: ai-tools, claude-code, cline, context, cursor, embeddings, kiro, mcp, memory, persistence, sqlite, typescript, vector-search, windsurf

## 简介

Persistent cross-session memory for AI coding assistants. Works with Claude Code, Cursor, Windsurf, Cline, and any MCP-compatible editor.
