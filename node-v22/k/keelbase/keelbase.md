# keelbase

> 标签: ai, cli, crud, flutter, keelbase, nestjs, scaffold

## 简介

KeelBase CLI — 按基座约定生成业务模块（EASY-2 开发期 AI）。`npx keelbase init` 对话式/自然语言生成全栈 CRUD 模块（NestJS + Flutter）。
