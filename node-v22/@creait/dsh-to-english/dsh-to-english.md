# @creait/dsh-to-english

> 标签: cordis, deepseek-harness, dsh, english, localization, market, plugin, translate

## 简介

Automatically rewrite market-downloaded plugins' Chinese copy/prompts into natural English, using a model you already have configured — once at install, then live-reloaded.
