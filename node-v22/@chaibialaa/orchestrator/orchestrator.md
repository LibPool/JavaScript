# @chaibialaa/orchestrator

> 标签: agents, automation, claude-code, codex, mcp, orchestration, unity

## 简介

A driving loop for coding agents: a judge decides, an agent executes, a proof settles it. Cost, deliverables and progress are derived from the traces — never declared.
