# afrigov-images

> 标签: africa, afrigov, cli, compression, government, images, performance, responsive-images, srcset, webp

## 简介

Make images light enough for African government websites. Resizes for each screen, converts to WebP, removes location data, checks the afrigov weight limits and prints the HTML.
