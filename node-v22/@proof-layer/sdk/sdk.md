# @proof-layer/sdk

> 标签: agent-governance, ai-governance, ai-safety, audit, ed25519, hash-chain, merkle, proof-layer, prooflayer, receipts, world999labs

## 简介

Official Proof Layer Node.js SDK — submit AI agent action proposals for governance, retrieve Ed25519-signed receipts, and verify hash-chained audit trails. Drop-in for any Node service that needs cryptographic proof of agent decisions.
