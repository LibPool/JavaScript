# @alphinex/files

> 标签: JavaScript

## 简介

File manager UI, upload queue with progress, gallery lightbox and image cropper. Upload transport is injected by the app — no @alphinex/api dependency. See documentation/PRODUCT-RESEARCH-MASTER-PLAN.md §10.3 (Sprint 38).
