# @alphinex/dashboard-kit

> 标签: JavaScript

## 简介

Draggable/resizable widget grid for building saved dashboard layouts. Reuses @dnd-kit (ADR-0011) for pointer/touch drag; resize and keyboard repositioning are hand-rolled. See documentation/PRODUCT-RESEARCH-MASTER-PLAN.md §10 (Sprint 19).
