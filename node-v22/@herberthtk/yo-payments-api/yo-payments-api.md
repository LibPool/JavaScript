# @herberthtk/yo-payments-api

> 标签: airtel, ipn, mobile-money, mtn, payments, typescript, uganda, yo-payments

## 简介

TypeScript client for the Yo! Payments mobile-money gateway (deposits, withdrawals, airtime, statements, IPN verification). Works in Node.js 18+, Bun, and Next.js (server-side).
