# @arnilo/prism-obscura

> 标签: agent, browser, cdp, mcp, obscura, playwright, prism, tools

## 简介

Optional Prism tools for a host-installed Obscura headless browser: fail-closed process lifecycle, full MCP tool bridge, CDP/Playwright composition, and bounded CLI web tools.
