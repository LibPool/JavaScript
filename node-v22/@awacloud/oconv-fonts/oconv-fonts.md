# @awacloud/oconv-fonts

> 标签: browser, font-embedding, fonts, liberation, oconv, office, ofl, pdf, worker-safe

## 简介

The SIL OFL companion of @awacloud/oconv — vendored Liberation 2.1.5 Sans/Serif/Mono font faces (12 TrueType programs, Regular/Bold/Italic/BoldItalic) registered as an @awacloud/fw descriptor by name, so oconv's md → pdf route embeds real faces by default
