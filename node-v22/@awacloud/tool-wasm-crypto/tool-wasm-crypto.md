# @awacloud/tool-wasm-crypto

> 标签: JavaScript

## 简介

Build tool that compiles and verifies the WebAssembly crypto modules used by @awacloud/fw, from each package's own C sources, validated against pinned test vectors and checked into the repo as committed bytes.
