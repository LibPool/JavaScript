# @apexstream/client

> 标签: apexstream, browser, nodejs, pubsub, realtime, typescript, websocket, ws, wss

## 简介

Official ApexStream JS/TS SDK — WebSocket client for the realtime gateway (subscribe, publish, channel messages). Uses api_key on the WS URL; browsers & Node 18+.
