# @camped-ui/date-picker

> 标签: camped, camped-ui, components, date-time-picker, next.js

## 简介

A date picker component allows users to select a specific date from a visual calendar interface. It streamlines date input by eliminating the need for manual entry, ensuring accurate and user-friendly date selection.
