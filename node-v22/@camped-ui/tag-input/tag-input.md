# @camped-ui/tag-input

> 标签: camped, camped-ui, components, next.js, tag-input

## 简介

Tag Input is a versatile package designed to simplify the process of managing and displaying tags within input fields. With intuitive components like TagAutocomplete, TagPopover, TagList, and TagInput, users can effortlessly add, remove, and organize tags
