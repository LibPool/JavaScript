# @noviuz/kyc-js

> 标签: JavaScript

## 简介

The Noviuz Hosted KYC partner SDK. Framework-agnostic, tiny, ships via NPM (ESM/CJS) and CDN (IIFE). Sensitive data never touches the partner side.
