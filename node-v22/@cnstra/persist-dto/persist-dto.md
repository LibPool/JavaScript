# @cnstra/persist-dto

> 标签: cnstra, dto, persist, resumable, run, stimulation

## 简介

Canonical, name-based data model for CNStra resumable execution: run/stimulation/task DTOs (emit) and persisted entities, plus the frontier progress DTO. Zero-runtime types shared by @cnstra/persist and the devtools.
