# @agenticprimitives/key-custody

> 标签: agent-authority, agentic, agentic-primitives, agentic-trust, agenticprimitives, ai-agents, aws-kms, envelope-encryption, gcp-kms, hmac, kms, secp256k1

## 简介

Pluggable envelope encryption + signers + HMAC providers (local-AES / AWS KMS / GCP KMS / AKCS agentic-kms). Pure crypto primitives; no session lifecycle (that's in delegation).
