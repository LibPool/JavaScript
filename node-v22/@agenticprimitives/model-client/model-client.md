# @agenticprimitives/model-client

> 标签: agentic, inference, llm-client, model-gateway, orchestration

## 简介

The typed client of the AP Model Gateway (spec 434): models.generate / stream / listProfiles under an app key or a session wire, and the orchestration bridges that let a harness swap planner, composer, structured-call and text-stream factories onto the ga
