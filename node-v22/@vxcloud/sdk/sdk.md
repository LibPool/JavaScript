# @vxcloud/sdk

> 标签: ai-agents, deploy, docker, iac, infrastructure, kubernetes, sdk, ssh, vxcli, vxcloud

## 简介

TypeScript SDK for the vxcloud / VxCloud platform — provision infrastructure, deploy applications, run AI agents, and drive the SalesShift GTM stack (prospect pool, CRM, campaigns, opportunity signals) from your app, terminal or CI pipeline.
