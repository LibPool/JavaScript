# @bc-coders/iam

> 标签: auth, authentication, authorization, express, framework-agnostic, iam, jwt, nestjs, rbac, session

## 简介

IAM (Identity & Access Management) framework-agnóstico para Node.js, Nest.js y cualquier backend JS. Autenticación + RBAC, con adaptadores de persistencia (BYO ORM). Cero dependencias de runtime.
