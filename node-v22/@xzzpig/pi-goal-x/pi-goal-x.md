# @xzzpig/pi-goal-x

> 标签: agent-loop, autoresearch, goal, long-running, pi, pi-extension, pi-package, sisyphus

## 简介

Goal mode extension for pi: durable long-running objectives, a constant six-tool surface, structured tasks, independent completion audit, Sisyphus mode, auto-continue, and a status overlay.
