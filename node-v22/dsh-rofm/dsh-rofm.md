# dsh-rofm

> 标签: context, deepseek-harness, dsh, dsh-plugin, memory, recall

## 简介

DSH 长期记忆插件：上下文超过阈值时把最早的一段对话归档进 memory/ 回忆文件夹，之后按关键词与重要性概率自动回忆。 · DSH long-term memory: archives the earliest context into memory/ folders and recalls it by keyword probability.
