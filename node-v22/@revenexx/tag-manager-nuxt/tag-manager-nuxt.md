# @revenexx/tag-manager-nuxt

> 标签: analytics, b2b, consent, ecommerce-tracking, etracker, ga4, google-tag-manager, hubspot, matomo, meta-pixel, nuxt, nuxt-module, nuxt-scripts, nuxt4, privacy, revenexx, tag-manager, theme-events

## 简介

Consent-gated tag manager for Nuxt, built on @nuxt/scripts: loads the tags published in the revenexx Tag Manager only with the visitor's consent and maps one vendor-neutral theme event stream (GA4-style, plus B2B events, no personal data) onto GA4, GTM, M
