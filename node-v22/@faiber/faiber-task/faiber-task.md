# @faiber/faiber-task

> 标签: JavaScript

## 简介

Typed client for every authenticated Faiber Tasks route. Tasks is the sandbox-local authority for projects, work items, sprints, scoped access grants, reporting, comments, agent proposals, and realtime invalidation events.
