# @kokojs/plugin-npm-duplicate

> 标签: JavaScript

## 简介

`@kokojs/plugin-npm-duplicate` 用于检测 npm 依赖包是否重复安装了多个版本。

## 官网

- 源码仓库：http://gitlab.qima-inc.com/fe/koko
- npm 页面：https://www.npmjs.com/package/@kokojs/plugin-npm-duplicate
