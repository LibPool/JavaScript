# @ripast/vue

> 标签: ast, nuxt, refactor, ripast, volar, vue

## 简介

Vue (and Nuxt) framework adapter for ripast. Provides Volar/Vue Language Service-backed rename, move, and template rewriting for .vue SFCs.
