# @sweberdev/cosine

> 标签: client-side, cosine-similarity, docs-search, documentation, embeddings, search, semantic-search, static-site, transformers.js, web-component

## 简介

Semantic search for documentation sites that runs entirely in the browser. Build the index once, search with keywords instantly and by meaning once the model has loaded. No server, no API key.
