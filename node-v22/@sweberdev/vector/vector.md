# @sweberdev/vector

> 标签: hmac, mysql, postgres, retries, self-hosted, signature, sqlite, ssrf, standard-webhooks, svix, svix-alternative, webhook, webhooks

## 简介

Self-hosted webhooks for Node.js and TypeScript: Standard Webhooks signatures (HMAC and Ed25519), retries with backoff, delivery log, SSRF protection and Postgres, MySQL and SQLite stores. A Svix alternative you run yourself.
