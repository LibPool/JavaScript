# @sweberdev/gradient

> 标签: accessibility, color, color-scale, contrast, dark-mode, design-tokens, oklch, palette, tailwind, wcag

## 简介

Accessible OKLCH color scales from one brand color. Contrast built into the step numbers, dark mode included, export for CSS, Tailwind v3/v4 and design tokens. Zero dependencies.
