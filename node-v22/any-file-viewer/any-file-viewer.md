# any-file-viewer

> 标签: csv, document-viewer, docx, file-viewer, pdf, pptx, preview, xlsx

## 简介

Universal in-browser file viewer: PDF, Word, Excel, PowerPoint, CSV, images, video, audio, text, code, HTML and ZIP. Framework-agnostic core with a React wrapper.
