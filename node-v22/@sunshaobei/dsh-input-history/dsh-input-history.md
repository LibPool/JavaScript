# @sunshaobei/dsh-input-history

> 标签: composer, deepseek-harness, dsh, dsh-plugin, input-history

## 简介

Input history switcher for the DSH composer: locally persists every submitted prompt (text plus attachment bytes, max 50, newest-first) and re-fills the empty composer via ArrowUp/ArrowDown with file references and image previews re-attached through the c
