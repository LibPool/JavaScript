# @axolot-ai/mcp-server

> 标签: ai-agent, astro-cms, axolot, claude-mcp, cursor-mcp, developer-tools, mcp, mcp-server, model-context-protocol, visual-editor

## 简介

Model Context Protocol (MCP) server for Axolot CMS. Expose live visual slots, schema design tokens, media libraries, and blog modules directly to AI assistants like Cursor, Claude Desktop, and VS Code.
