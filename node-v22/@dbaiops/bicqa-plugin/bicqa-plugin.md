# @dbaiops/bicqa-plugin

> 标签: awr, bic-qa, cordis, database, dsh, llm, qa

## 简介

BIC-QA OpenAPI 工具集（DSH/Cordis 插件）：数据库知识问答 / AWR 与日志分析 / 附件上传 / 报告下载 / 会话管理；默认异步发起、流式取回；注册 bicqa 设置命名空间（可在 DSH 设置界面配置 API Key）。
