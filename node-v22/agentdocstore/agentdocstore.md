# agentdocstore

> 标签: agentdocstore, ai-agents, documents, markdown, mcp, model-context-protocol, offline-first, self-hosted

## 简介

Offline-first, self-hosted store for the documents AI agents write: a web UI, a REST API and an MCP server over one versioned store.
