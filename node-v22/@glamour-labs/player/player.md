# @glamour-labs/player

> 标签: animation, canvas, glam, glamour, interactive, web-component, webgl, webgl2

## 简介

Browser runtime for glamour documents — renderGlamour, the <glam-canvas> web component, self-contained HTML export, and a headless drive-and-assert harness.
