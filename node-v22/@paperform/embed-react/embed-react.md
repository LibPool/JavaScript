# @paperform/embed-react

> 标签: JavaScript

## 简介

React wrappers over @paperform/embed: <InlineEmbed>, <PopupButton>, <DrawerButton> and <Popover>, with callback props and an imperative open/close handle. The protocol, chrome and sizing all live in the core package.
