# @verifact/cli

> 标签: ai-safety, audit-ledger, cli, evidence, fact-checking, hallucination-detection, provenance, verification

## 简介

Verifact command line: verify claims against primary-source byte spans, block hallucinations, seal evidence certificates, and run a hash-chained provenance ledger and a self-hosted Studio.
