# @verifact/core

> 标签: ai-safety, assentra, citations, claims, ecdsa, evidence, fact-checking, hallucination-detection, pactline, provenance, web-crypto

## 简介

Framework-free provenance engine: binds claims to SHA-256 byte spans of primary sources, detects hallucinated or drifted values, signs ECDSA P-256 evidence certificates and hands verified facts to Assentra and Pactline. Node 20+, edge runtimes and browser
