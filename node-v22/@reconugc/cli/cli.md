# @reconugc/cli

> 标签: ai, cli, mcp, modelcontextprotocol, reconugc, tiktok, ugc

## 简介

RECON UGC from your terminal — search viral TikToks, read breakdowns, compare videos, and run RECON as a local MCP server. Sign in with your browser, no API key.
