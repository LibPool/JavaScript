# dsh-browser-computer

> 标签: browser-automation, computer-use, cordis, deepseek-harness, dsh, dsh-plugin, mcp, peekaboo, playwright

## 简介

让 DeepSeek Harness 直接操作浏览器与电脑：以插件形式装配 playwright-mcp 与 peekaboo-mcp，并提供一键依赖安装、系统权限引导与连接自检
