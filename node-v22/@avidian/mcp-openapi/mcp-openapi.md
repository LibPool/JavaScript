# @avidian/mcp-openapi

> 标签: agent, ai, api, mcp, model-context-protocol, openapi, rest, swagger

## 简介

MCP server for OpenAPI/Swagger — gives AI agents the ability to discover, search, and call any REST API described by an OpenAPI document.
