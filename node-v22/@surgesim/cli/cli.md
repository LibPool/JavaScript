# @surgesim/cli

> 标签: aws, capacity-planning, cdk, ci, cli, simulation

## 简介

The surgesim command-line tool: run Surgesim models, enforce capacity thresholds in CI, write HTML reports, compare runs, import CloudFormation/CDK.
