# @zusor/ovenplayer

> 标签: HLS, HTML5, Low Latency HTTP, MPEG-DASH, OvenMediaEngine, Player, Sub-Second Latency Streaming, Video, WebRTC

## 简介

OvenPlayer is Open-Source HTML5 Player. OvenPlayer supports WebRTC Signaling from OvenMediaEngine for Sub-Second Latency Streaming.

## 官网

- 官网：https://www.ovenmediaengine.com/ovenplayer
- 源码仓库：git+https://github.com/zusorio/OvenPlayer.git
- npm 页面：https://www.npmjs.com/package/@zusor/ovenplayer
