# @mcleanstewart/ledger

> 标签: components, css-variables, dark-mode, dashboard, design-system, design-tokens, react

## 简介

Ledger — a dashboard design system: dark-first, almost-monochrome, hairlines instead of shadows, tabular figures. Typed React components and vanilla CSS, no bundler and no runtime dependency beyond icons.
