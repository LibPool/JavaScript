# @geeboo/viewer

> 标签: JavaScript

## 简介

vue的多资源预览器，会根据资源的后缀发起预览，这里的图片预览时整合了@geeboo/img-view组件，由于pdf依赖pdfjs导致包非常大，如果没有pdf要求，建议使用@geeboo/img-view
