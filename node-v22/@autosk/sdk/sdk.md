# @autosk/sdk

> 标签: agent, autosk, autosk-sdk, types, workflow

## 简介

Public extension-facing types for autoskd v2: Task / Session / Workflow / Agent / Isolation / AutoskAPI, pi-format transcript entries, and proto-v2 wire types.
