# @platforma-open/milaboratories.tcr-clustering.gliph-runner

> 标签: JavaScript

## 简介

GLIPH2 runner: a docker image (R + turboGliph, baked run_gliph2.R) that builds the GLIPH2 clone_network for the GLIPH2 + Leiden clustering engine.
