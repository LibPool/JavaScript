# @saifulapm/layoutlint

> 标签: ai-agents, css-grid, flexbox, layout, lint, mcp, overflow, tailwind, yoga

## 简介

Deterministic UI layout checks and screenshots for JSX/HTML + Tailwind — overflow, overlap, viewport fit, text truncation, SVG/PNG render — in milliseconds, no browser. Validated against headless-Chromium golden files.
