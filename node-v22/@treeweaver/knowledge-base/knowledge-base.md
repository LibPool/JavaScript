# @treeweaver/knowledge-base

> 标签: JavaScript

## 简介

The knowledge-base plugin for a LoomWeaver distribution: listing, document, trash, tags, categories, add dialog and ask, behind a gateway the host supplies or the HTTP gateway the package ships.
