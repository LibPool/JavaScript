# @whisperr/expo

> 标签: churn, config-plugin, expo, expo-notifications, push-notifications, react-native, whisperr

## 简介

Push notifications for Expo apps on Whisperr: config plugin, permission + push token registration, notification opens with deep links, and foreground receipts, and expo-router screen tracking.
