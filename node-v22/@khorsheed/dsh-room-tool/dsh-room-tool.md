# @khorsheed/dsh-room-tool

> 标签: agent-preset, cordis, dsh, dsh-plugin, multi-agent, room, tool

## 简介

The session-granted room model tools (room_invite / room_task / room_message), companion to @khorsheed/dsh-room: a tool-only row (provides no service) that agent presets compose to grant the room's agent-facing member/task/message paths per session. Delib
