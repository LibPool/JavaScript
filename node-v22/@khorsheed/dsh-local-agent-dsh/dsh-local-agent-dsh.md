# @khorsheed/dsh-local-agent-dsh

> 标签: cordis, dsh, dsh-plugin, local-agent, subagent

## 简介

dsh harness for dsh-local-agent: delegate to dsh itself as a local CLI — scoped DSH_HOME under the shared homes root, one-shot sub-dsh runs visible in the 子代理 surface, caller-supplied session ids, resume across rounds, DeepSeek toggle in settings
