# @byteink/aish

> 标签: ai, anthropic, assistant, cli, command-line, llm, lmstudio, natural-language, ollama, openai, shell, typescript

## 简介

AI shell assistant that turns natural language into shell commands. Local-first (Ollama, LM Studio), with OpenAI and Anthropic support.
