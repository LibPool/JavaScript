# @byteink/mppjs

> 标签: cli, converter, graalvm, microsoft-project, mpp, mpxj, mspdi, native-image, typescript

## 简介

Convert Microsoft Project (.mpp) files to XML from Node, Bun, or Deno. Native binary, no JVM required.
