# @ticatec/redis-client

> 标签: cache-framework, cache-stampede, caching, data-caching, ioredis, json-serialization, logger-api, logging, mock-redis, multi-instance, nodejs, pub-sub, redis, redis-client, redis-wrapper, singleton, ttl, typescript

## 简介

A lightweight TypeScript wrapper around ioredis with singleton/multi-instance pattern support, logging through the @ticatec/logger-api contract, mock Redis for testing, and an abstract caching framework.
