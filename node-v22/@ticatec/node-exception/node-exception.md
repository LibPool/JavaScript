# @ticatec/node-exception

> 标签: 400, 401, 403, 404, 500, api, authentication, authorization, commonjs, content-negotiation, dual-module, enterprise, error-handler, error-handling, error-middleware, error-response, esm, exception, exception-handler, express, express-middleware, http-error, http-errors, http-status, logging, middleware, nodejs, production-ready, rest-api, status-codes, ticatec, type-safe, typescript, validation

## 简介

Production-ready Express error handling middleware with standardized HTTP error types, centralized exception management, and automatic content negotiation for REST APIs. Type-safe, with logging injected through the @ticatec/logger-api contract.
