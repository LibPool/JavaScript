# @ticatec/excel-wizard

> 标签: batch, component, data-processing, dropdown, excel, exceljs, i18n, import-export, schema, svelte, template, upload, validation, wizard, xlsx

## 简介

A schema-driven Svelte component library for Excel batch data processing with wizard-style interfaces, supporting validation, encoding, and template generation.
