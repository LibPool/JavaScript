# @ticatec/i18n

> 标签: deep-merge, frontend, i18n, internationalization, languages, localization, multilingual, proxy, react, resource-management, svelte, translation, typescript

## 简介

A lightweight frontend internationalization (i18n) solution with Proxy-based resource access, deep merge capabilities, and flexible override controls for React, Svelte and other modern frameworks.
