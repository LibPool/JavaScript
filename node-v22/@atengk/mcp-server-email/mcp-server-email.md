# @atengk/mcp-server-email

> 标签: ai-agent, email, imap, imapflow, llm, mcp, model-context-protocol, nodemailer, smtp

## 简介

生产级 Email Model Context Protocol (MCP) 服务端，支持 SMTP 邮件外发、IMAP 邮箱检索与附件处理，提供 Stdio 与 SSE 双模传输
