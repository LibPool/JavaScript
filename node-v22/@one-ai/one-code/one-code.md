# @one-ai/one-code

> 标签: agent, claude-code, cli, coding-agent, mcp, pi

## 简介

One Code — the Claude Code experience on any model, batteries included: ships its own pinned pi harness, keeps all state isolated in ~/.onecode, and coexists with any existing pi install
