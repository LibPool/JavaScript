# @mafesoftware/clientes

> 标签: clientes, cuit, dni, duplicados, multi-tenant, prospectos

## 简介

Validacion de documento (DNI/CUIT) y normalizacion para detectar duplicados (email/telefono/documento) de clientes o prospectos. Nucleo puro: sin DB ni framework, compone @mafesoftware/documentos-ar para el digito verificador.
