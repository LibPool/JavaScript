# @getsens/mcp-server

> 标签: electricity, energy, mcp, model-context-protocol, sens

## 简介

npx-installable wrapper for sens-mcp (the real MCP server, distributed as a Python package via uv/pip). Requires uv to be installed.

## 官网

- 官网：https://docs.getsens.energy
- 源码仓库：git+https://github.com/SofiaFlux/sens-toolkit.git
- npm 页面：https://www.npmjs.com/package/@getsens/mcp-server
