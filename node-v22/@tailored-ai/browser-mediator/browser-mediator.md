# @tailored-ai/browser-mediator

> 标签: agent, ai, anthropic, browser, claude, egress-allow-list, hitl, llm, openai, playwright, tools, vault

## 简介

Framework-agnostic browser-control surface for LLM agents. Bounded tool API over Playwright, with egress allow-list, vault $ref expansion, output sanitiser, and always-HITL gates. No dependency on any specific agent framework.
