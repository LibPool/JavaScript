# @tailored-ai/deploy-aws

> 标签: agent, ai, aws, deploy, ec2, self-hosting, tailored-ai

## 简介

AWS deploy target for Tailored AI — runs TAI on a single EC2 instance with a persistent EBS volume. Install with `tai plugin install @tailored-ai/deploy-aws`, then `tai deploy up aws-ec2`.
