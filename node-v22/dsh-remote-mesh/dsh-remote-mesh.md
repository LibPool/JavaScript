# dsh-remote-mesh

> 标签: deepseek-harness, dsh, e2ee, mesh, plugin, port-forward, remote, workspaces

## 简介

remote-workspaces: an end-to-end encrypted mesh that gives the DSH Web GUI a remote-workspaces section — other machines' workspaces and conversations, their full GUI proxied onto a local loopback port, and loopback port forwards for debugging remote pages
