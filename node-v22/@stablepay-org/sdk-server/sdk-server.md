# @stablepay-org/sdk-server

> 标签: africa, payments, sdk, server, stablepay, wallet

## 简介

Server-side helper for @stablepay-org/sdk. Implements the wallet issuer's quote / scan / pay routes against the StablePay money API, so an issuer's backend is a few lines instead of a few hundred.
