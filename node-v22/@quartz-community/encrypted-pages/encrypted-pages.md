# @quartz-community/encrypted-pages

> 标签: aes-gcm, encrypted-pages, encryption, hast, password-protected, quartz, quartz-plugin, rehype

## 简介

Password-protected encrypted pages for Quartz. Encrypts page content at build time with AES-256-GCM and decrypts client-side using the Web Crypto API.
