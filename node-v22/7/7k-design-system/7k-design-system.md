# 7k-design-system

> 标签: 1-bit, components, css, dark-theme, design-system, geist, manga, neon, react, tokens, typography

## 简介

Dark, neon-accented, manga-inflected design system for multi-project tech company 7K. Three-font system (Geist sans + Geist Mono + Geist Pixel 5 geometric variants), #FF0FF brand pulse, Tokyo neon atmosphere with 1-bit manga punctuation.
