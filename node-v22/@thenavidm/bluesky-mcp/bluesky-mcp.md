# @thenavidm/bluesky-mcp

> 标签: ai-agents, at-protocol, atproto, bluesky, claude, claude-code, llm-tools, mcp, mcp-server, model-context-protocol

## 简介

MCP server for Bluesky and the AT Protocol. 41 tools for posting, threads, feeds, search, lists, notifications and the social graph, with LLM-optimised output. Works with Claude Code, Claude Desktop, Cursor, Windsurf, and any MCP-compatible client.
