# @phoenix-plugin-registry/brackets-elixir-tools

> 标签: .ex, .exs, REPL, auto completion, code, completion, elixir, highlight, highlighter, highlighting, syntax

## 简介

Tooling and syntax highlighting for Elixir in Brackets. Includes integration of an Elixir REPL, Elixir autocompletion and inline documentation for Elixir modules and documents.
