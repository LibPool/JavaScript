# @phoenix-plugin-registry/hdy.brackets-shell

> 标签: command, linux, os-x, prompt, shell, windows

## 简介

Shell access within Brackets. Want to run some shell command, install a node package, install from bower the list goes on and on. Well then, this extension is for you.
