# @phoenix-plugin-registry/jonwolfe.file-tree-exclude

> 标签: brackets, exclude, folders, hide

## 简介

Excludes folders from the Brackets file system to avoid the 30,000 file limit. This is an updated version of Glenn Ruehle's now defunkt plugin.
