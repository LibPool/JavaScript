# @phoenix-plugin-registry/pflynn.sloc-counter

> 标签: JavaScript

## 简介

Counts the number of JavaScript files, lines, and lines of code ("SLOC" - excluding whitespace/comments) in your project. Supports exclusions. To get started, choose "View > Count Lines of Code".
