# @phoenix-plugin-registry/malas34.brackets-console-plus

> 标签: console, debug, error, log

## 简介

Shows console.logs &.errors without leaving Brackets. + Toolbar Icon & Notifier, Filters by logs/errors, Errors stacks details and.... a very nice look + Update: log window object error
