# @phoenix-plugin-registry/deddy.dbmanager

> 标签: Database, sql server

## 简介

A brackets extension to querying a database server, now only support SQL server, other database will follow. Now it's only offer basic functionality, like browse databases, tables, show table fields, show table data in a paging table, run query. Changelog
