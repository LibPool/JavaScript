# @phoenix-plugin-registry/smooth-neutrals-theme

> 标签: neutral, neutrals, smooth, themes

## 简介

Modified Son of Hammsidian Theme. Support for wangling in the colors of Jeff Booher's Bookmarks Extension to better fit the Smooth Neutrals theme.
