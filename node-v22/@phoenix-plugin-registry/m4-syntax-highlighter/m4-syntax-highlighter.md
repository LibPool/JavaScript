# @phoenix-plugin-registry/m4-syntax-highlighter

> 标签: autoconf, highlighting, m4, syntax

## 简介

Simple Syntax highlighting for M4 Macro files (e.g. Autoconf). To improve editting of configure.ac files primarily.
