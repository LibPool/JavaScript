# @phoenix-plugin-registry/brackets-drop-includer

> 标签: browse, drag, drop, file, include

## 简介

You can select file(s) from [Browse...] or modal window, from right-clicking. And suitable tag will be inserted automatically (link tag, img tag, script tag, css @import, and php(or ejs) include statement).
