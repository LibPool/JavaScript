# @dvoid-io/payload-zitadel

> 标签: auth, oidc, payload, payloadcms, pkce, pomerium, sso, zitadel

## 简介

Zitadel admin sign-in for a Payload panel: a confidential PKCE client over payload-oauth2, gated fail-closed on a Zitadel project role — and a strategy that accepts a Pomerium edge's signed assertion as the panel session.
