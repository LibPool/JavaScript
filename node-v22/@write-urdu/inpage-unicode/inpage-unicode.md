# @write-urdu/inpage-unicode

> 标签: encoding, inpage, transliteration, unicode, urdu

## 简介

Convert Urdu text between legacy InPage-style encoding and Unicode. Same engine that powers the InPage ↔ Unicode Converter tool on write-urdu.com.
