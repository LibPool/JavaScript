# @electron-stagewright/plugin-ipc

> 标签: ai-agent, electron, ipc, mcp, stagewright, testing

## 简介

IPC plugin for Electron Stagewright: capture Electron IPC traffic by channel, invoke channels, and stub responses for agent-driven testing.
