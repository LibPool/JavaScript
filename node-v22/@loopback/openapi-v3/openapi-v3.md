# @loopback/openapi-v3

> 标签: OpenAPI Spec, Swagger, TypeScript

## 简介

Decorators that annotate LoopBack artifacts with OpenAPI v3 metadata and utilities that transform LoopBack metadata to OpenAPI v3 specifications
