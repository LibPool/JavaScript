# @react-gnome/react-native

> 标签: JavaScript

## 简介

React Native compatibility layer for React Gnome — View / Text / Image / ScrollView / TextInput / Pressable rendered via GTK 4 + libadwaita. Apps that import from 'react-native' resolve here when the vite-plugin-gir alias is enabled.
