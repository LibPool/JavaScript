# @lopatnov/javascripttostring

> 标签: JavaScript, TypeScript, array-to-string, circular-references, code-generation, cross-references, function-to-string, javascript-to-string, object-to-string, runtime-converter, serialization, source-code, stringify, value-to-string

## 简介

A TypeScript library that converts any JavaScript runtime value into its string source code representation, including objects, arrays, functions, circular references, and cross-references
