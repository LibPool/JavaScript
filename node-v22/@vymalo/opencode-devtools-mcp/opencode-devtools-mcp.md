# @vymalo/opencode-devtools-mcp

> 标签: cron, crypto, datetime, jwt, math, mcp, model-context-protocol, utilities

## 简介

MCP server for @vymalo/opencode-devtools — exposes the same local developer utilities (math, codec, crypto, datetime, convert, http) over the Model Context Protocol so any MCP client (Claude Code, Cursor, Cline, …) can call them. No bridge, no auth — pure
