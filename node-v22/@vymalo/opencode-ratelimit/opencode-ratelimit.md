# @vymalo/opencode-ratelimit

> 标签: 429, ai-sdk, envoy, opencode, opencode-plugin, rate-limit, throttle

## 简介

OpenCode plugin that makes OpenAI-compatible providers rate-limit aware: it reads Envoy Gateway / IETF draft-03 rate-limit response headers (x-ratelimit-limit/remaining/reset), proactively throttles requests when the quota is exhausted, and backs off and
