# @vymalo/opencode-repo-auth

> 标签: ai-sdk, gateway, oauth2, opencode, opencode-plugin, project, token-exchange

## 简介

OpenCode plugin that gives local-dev requests repo-as-project attribution: a developer logs in once as themselves and every gateway request from an enrolled repo carries a project-scoped bearer.
