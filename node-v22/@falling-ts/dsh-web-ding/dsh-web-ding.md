> 标签: agent, client, cordis, ding, dsh, idle, notification, sound, turn-end, web-audio

## 简介

DSH Cordis plugin: announces the moment an agent finishes (turns idle) by pushing a 'done' signal from the Host half into the falling-ts-web-ding settings namespace, which the browser client half mirrors live and answers with a synthesized 'ding' tone via
