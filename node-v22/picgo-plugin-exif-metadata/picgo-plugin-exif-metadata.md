# picgo-plugin-exif-metadata

> 标签: exif, exiftool, gps, metadata, picgo, picgo-gui-plugin, picgo-plugin

## 简介

Automatically add author, copyright, source URL and license metadata to images before uploading with PicGo, with placeholder expansion ({year}, {filename}) and checkbox-based control over GPS and other metadata.
