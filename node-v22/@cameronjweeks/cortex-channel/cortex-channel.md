# @cameronjweeks/cortex-channel

> 标签: ai, bot, chat, cortex, openclaw, openclaw-channel, openclaw-plugin

## 简介

OpenClaw channel plugin that bridges OpenClaw agents to Cortex chat — rich AI status events, automatic channel task lifecycle, attachment handling, and crash-safe task persistence.
