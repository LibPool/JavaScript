# @codeages/live-stack

> 标签: JavaScript

## 简介

面向浏览器端直播能力的 TypeScript 工具库，封装了 WHIP/WebRTC 推流、本地媒体轨道采集、信令适配和 PeerConnection 网络状态监控等能力。
