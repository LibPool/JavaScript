# @virajp.dev/claude-status

> 标签: anthropic, claude, claude-code, cli, macos, powerline, status-line, statusbar, statusline, terminal

## 简介

Installer for claude-status, the Claude Code powerline status line. Downloads the release binary against a pinned digest; carries no binary itself.
