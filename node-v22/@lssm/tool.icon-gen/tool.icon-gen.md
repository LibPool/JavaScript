# @lssm/tool.icon-gen

> 标签: cli, contractspec, favicon, generator, icon, pwa

## 简介

Cross-platform CLI to generate PWA / web icon sets from a source logo (favicon.ico, PNG variants, apple-touch-icon, maskable). Uses sharp + a pure-JS ICO writer — no macOS-only sips dependency.
