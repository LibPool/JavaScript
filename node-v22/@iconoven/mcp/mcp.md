# @iconoven/mcp

> 标签: JavaScript

## 简介

MCP server for IconOven UI icons: search, get SVGs and code snippets from Claude Code, Cursor, VS Code and Windsurf. Stroke is free; Pro styles need an IconOven key.

## 官网

- 官网：https://iconoven.com
- npm 页面：https://www.npmjs.com/package/@iconoven/mcp
