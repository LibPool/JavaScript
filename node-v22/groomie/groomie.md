# groomie

> 标签: agile, backlog, claude-code, confluence, epics, grooming, jira, opencode, user-stories

## 简介

Groom a messy single-feature idea — a Jira issue, Confluence page, URL, or file — into a clean epic / user-story / technical-task breakdown, with tasks blocking stories. Outputs markdown.
