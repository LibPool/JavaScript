# @chromatrix/cli

> 标签: chromatrix, chrome-devtools-protocol, cli, mcp

## 简介

chromatrix CLI - a thin remote client over the gateway's MCP surface (@silkweave/mcp cliProxy). Every @Mcp tool the gateway exposes becomes a command automatically; there is no per-command code here by design.
