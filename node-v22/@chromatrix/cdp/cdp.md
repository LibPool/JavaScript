# @chromatrix/cdp

> 标签: browser-automation, cdp, chrome, chrome-devtools-protocol, multiplexer

## 简介

CDP client + flat-session multiplexer for chromatrix: one upstream connection to Chrome, N downstream clients, per-client command-id remapping, event routing by sessionId, per-tab ACLs, and a pluggable message-interception layer (the mitigating-mux core).
