# @chromatrix/gateway

> 标签: browser-automation, cdp, chromatrix, chrome-devtools-protocol, gateway, mcp

## 简介

chromatrix gateway (NestJS + @silkweave/nestjs): raw-WS CDP mux mounted at the underlying http.Server (outside Nest's pipeline) + silkweave mgmt/MCP Actions (provision/allocate/health/takeover) + the bundled dashboard. Run it with `npx @chromatrix/gateway
