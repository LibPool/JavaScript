# @spawnite/testing

> 标签: JavaScript

## 简介

What a Spawnite game's tests share: the jsdom setup file every project's vitest config names, fakes of React Three Fiber and drei for jsdom, a fetch stub, temp folders a test cannot forget to remove, a way to run a child process from a test and read back
