# tabhelm-mcp

> 标签: ai-agent, browser-automation, chrome-extension, cursor, mcp, native-messaging

## 简介

Unofficial browser bridge for Cursor's agent: a Chrome extension plus a local MCP server that let an agent see and control your real, logged-in Chrome.
