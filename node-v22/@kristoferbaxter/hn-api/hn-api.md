# @kristoferbaxter/hn-api

> 标签: JavaScript

## 简介

Reusable HN-API for Node.js implementations of HNPWA. Background caches each feed, their feeditems, and foreground fetches details from publicly available APIs. Responses are delivered in a flat entity cache model for use with React-HN, Preact-HN, and Gli
