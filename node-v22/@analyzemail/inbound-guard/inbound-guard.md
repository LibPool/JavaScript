# @analyzemail/inbound-guard

> 标签: ai-agents, cold-email, email, inbox, mcp, mcp-server, sales-outreach, spam

## 简介

Score an incoming email as cold outreach, with the reasons: sequencer fingerprints, look-alike sending domains, new domains, follow-up patterns. CLI, MCP server and library. Zero dependencies.
