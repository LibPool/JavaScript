# @ramanacr/ngx-smart-image-cropper-workspace

> 标签: JavaScript

## 简介

`@ramanacr/ngx-smart-image-cropper` is an Angular 21 standalone image cropper with signal-backed state, mouse and touch interactions, keyboard nudging, undo/redo history, and canvas-based export.
