# @nullplatform/ingest

> 标签: agent-skill, catalog, collector, ingest, llms.txt, nullplatform, sdk

## 简介

Client SDK for the nullplatform ingest API: push snapshots and delta events from a collector into the catalog and other targets, follow runs, replay and drift checks
