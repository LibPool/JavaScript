# @coroboros/uri

> 标签: coroboros, decode, domain, encode, idn, ip, nodejs, parse, punycode, rfc-1034, rfc-1123, rfc-3986, rfc-3987, rfc-6874, sitemap, sitemap-protocol, typescript, uri, url, zero-dependency

## 简介

RFC-3986 URI toolkit for Node.js. IDN (RFC-3987), IPv6 zone identifiers (RFC 6874), Sitemap protocol. Zero dependencies.
