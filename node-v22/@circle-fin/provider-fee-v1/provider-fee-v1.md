# @circle-fin/provider-fee-v1

> 标签: cctp, circle, circle-fin, fee, provider, quote, typescript, usdc

## 简介

Client for Circle's Quote API that fetches signed fee quotes for the prepaid FORWARD fast-deposit path of a CCTP v2 USDC burn.
