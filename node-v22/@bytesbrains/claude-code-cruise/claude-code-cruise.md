# @bytesbrains/claude-code-cruise

> 标签: budgets, bytesbrains, claude-code, claude-code-plugin, cruise, llm-gateway, mcp

## 简介

BytesBrains Cruise for Claude Code: your key's models, budget and spend over MCP, a skill for lanes and refusals, a spend status line, and guided setup. The package root is the plugin root, for a marketplace's npm source.
