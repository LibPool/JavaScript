# @kmacute/vin-eloquent

> 标签: drizzle, eloquent, laravel, mariadb, model, mysql, orm, typescript

## 简介

Eloquent-style model helper on top of Drizzle ORM (MySQL / MariaDB). A thin, strongly-typed convenience layer exposing a Laravel/Eloquent-style CRUD and query API.
