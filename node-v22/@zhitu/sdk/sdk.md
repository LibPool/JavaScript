# @zhitu/sdk

> 标签: blob, iframe, postmessage, sdk, spaced-repetition, typescript, zhitu

## 简介

zhituSDK —— 平台沙箱工具官方前端 SDK：iframe 内经 postMessage 存取私有 KV、设备本地文件、受控导出，并可把条目提交到用户复习计划（零依赖、零凭据）
