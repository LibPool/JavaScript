# @xcwds/sveltekit

> 标签: offline-first, pwa, sveltekit, vite-plugin, xcwds

## 简介

Binds the @xcwds kernel to SvelteKit: a Vite plugin that sets up SvelteKit, server hooks, the <App> component, Svelte 5 persist() and reactive settings, and a route registry.
