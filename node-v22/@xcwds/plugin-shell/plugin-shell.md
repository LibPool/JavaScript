# @xcwds/plugin-shell

> 标签: app-shell, navigation, offline-first, pwa, xcwds, xcwds-plugin

## 简介

The app shell for @xcwds apps: header with the page title and back arrow, a tab bar on phones, header links or a sidebar on wider screens, toasts and a Home page plugins add to.
