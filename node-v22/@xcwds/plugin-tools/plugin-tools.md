# @xcwds/plugin-tools

> 标签: offline-first, pwa, shortcuts, tools, xcwds, xcwds-plugin

## 简介

A tool registry for @xcwds apps: an index page of small tools, pinned and recently used tools on Home, and manifest shortcuts, with private tools kept out of recents and sharing.

- 源码仓库：git+https://github.com/xcwds/xcwds.git
