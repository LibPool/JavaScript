# @hlao-adapter/jwt

> 标签: JavaScript

## 简介

Provider-agnostic JWT verification for HLAO verifyActor: takes any JWKS URI or static public key, verifies signature, issuer, audience, and expiry, and extracts a configurable claim as the actor id.
