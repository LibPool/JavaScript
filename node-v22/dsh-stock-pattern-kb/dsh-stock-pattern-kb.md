# dsh-stock-pattern-kb

> 标签: a-share, cordis, dsh, dsh-plugin, knowledge-base, pattern, stock, trading

## 简介

DSH plugin: a structured A-share short-term trading pattern library (137 cards) covering 连板/龙头/情绪周期/退潮/可转债/仓位/复盘 — search trigger conditions, entry, exit, position sizing and invalidation signals, each with source citations.
