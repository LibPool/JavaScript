# @particle-academy/fancy-3d-babylon

> 标签: 3d, babylonjs, fancy-3d, react, webgl

## 简介

Babylon.js adapter for @particle-academy/fancy-3d — WebGL renderer, primitives, React components (Stage, Monitor, Card3D, Screen) that mount onto a Babylon Scene.
