# @particle-academy/fancy-3d-three

> 标签: 3d, fancy-3d, react, three, threejs, webgl

## 简介

three.js adapter for @particle-academy/fancy-3d — WebGL renderer, primitives, React components (Stage, Monitor, Card3D, Screen) that mount onto a three.js Scene.
