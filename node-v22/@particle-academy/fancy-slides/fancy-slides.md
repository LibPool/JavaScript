# @particle-academy/fancy-slides

> 标签: agent, deck, fancy, human-plus, presentation, react, slides, slideshow

## 简介

Presentation editor + web viewer for the fancy UI set — Google-Slides-style deck authoring with a JSON-friendly schema, full keyboard-driven viewer, and an agent bridge so LLMs can compose decks directly.
