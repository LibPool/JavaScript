# @particle-academy/fancy-grid

> 标签: agent, data-grid, human-plus, react, table, tanstack-table, tanstack-virtual, virtualization

## 简介

Data grid for Human+ UX — TanStack Table (and optionally TanStack Virtual) under a controlled, JSON-serializable, agent-bridgeable Fancy surface. The engines stay peers; the grid never bundles them.
