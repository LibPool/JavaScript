# @particle-academy/agent-integrations

> 标签: agents, collaboration, fancy, mcp, model-context-protocol, react, whiteboard

## 简介

MCP-driven agent presence in collab sessions: per-session micro-MCP server, pluggable bridges to fancy-* packages, and agent UX components (panel + on-canvas cursor).
