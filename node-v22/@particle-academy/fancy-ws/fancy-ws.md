# @particle-academy/fancy-ws

> 标签: fancy, node, realtime, rfc6455, websocket, websocket-server, ws, zero-dependency

## 简介

A WebSocket server for Node with zero runtime dependencies. Node ships a WebSocket client and no server; this is the server half — RFC 6455 framing over node:http's upgrade event, with authorisation before the 101.
