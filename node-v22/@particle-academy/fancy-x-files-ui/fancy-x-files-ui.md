# @particle-academy/fancy-x-files-ui

> 标签: JavaScript

## 简介

Headless react-fancy editor suite for the well-known files modeled by fancy-x-files — robots.txt, security.txt, llms.txt, humans.txt, sitemap.xml, AGENTS — controlled, JSON-friendly, Human+ UX
