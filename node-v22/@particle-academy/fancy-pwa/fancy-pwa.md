# @particle-academy/fancy-pwa

> 标签: fancy, install-prompt, offline, pwa, react, service-worker, ssr, vite-plugin

## 简介

Lean, framework-agnostic, SSR-safe PWA layer for the Fancy UI suite — install prompt, online/offline, a Workbox-free service-worker toolkit, a Vite plugin, and update detection composed on fancy-app-update.
