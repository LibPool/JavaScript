# @particle-academy/fancy-pixel

> 标签: agent, analytics, badge, beacon, fancy-ui, human-plus, pixel, shadow-dom, verification

## 简介

All-in-one embeddable Fancy UI pixel: one <script> renders the verification badge AND streams the site's full interaction analytics (clicks / scroll / pointer heatmap / dwell + agent activity) to the host, Google-Analytics-style, keyed by site_key. Shadow
