# dsh-doctor-plugin

> 标签: deepseek, deepseek-harness, diagnostics, dsh, plugin, repair, windows

## 简介

DSH 私人医生：检查并一键修复桌面端在 Windows 上踩过的坑（桌面图标变白/闪烁、工作区注册在桌面、profile 宿主包重复、启动崩溃）
