# @xia-sc/dsh-git

> 标签: commit, cordis, deepseek-harness, diff, dsh, git, plugin, web-gui

## 简介

Complete Git management for the DeepSeek Harness Web GUI: branch switch, new-branch-from-base, fetch, pull, stage-all, commit (with AI-drafted message), push, status, and a click-to-open diff viewer (staged/unstaged, resizable) — as a collapsible floating
