# @pinnadash/account-sdk

> 标签: account, entitlements, pinnadash, pkce, subscription

## 简介

Pinnadash account system client SDK: PKCE login, deep-link callback, token refresh, offline grace, entitlements, paywall. Zero dependencies, Web Crypto + fetch, browser / Workers / Tauri webview.
