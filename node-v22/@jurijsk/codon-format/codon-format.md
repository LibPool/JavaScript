# @jurijsk/codon-format

> 标签: codon, formatter, gfm, markdown, tables

## 简介

Codon's canonical markdown formatter (tables, paragraph reflow) as a standalone, vscode-free CLI and library — used by the jurijsk.codon VS Code extension and runnable anywhere Node runs.
