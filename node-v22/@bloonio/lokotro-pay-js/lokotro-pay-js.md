# @bloonio/lokotro-pay-js

> 标签: bank-transfer, card-payment, checkout, e-wallet, fintech, lokotro, mobile-money, nextjs, payment, react, vanilla-js

## 简介

Framework-agnostic JavaScript SDK for Lokotro Pay - drop-in payment checkout widget and headless payment engine for React, Next.js, Vue, Svelte or plain JS. Cards, mobile money, e-wallets, bank transfer.
