# @linusdevx/cpi-mcp-server

> 标签: claude, cpi, integration-suite, mcp, model-context-protocol, sap

## 简介

MCP server for SAP Cloud Platform Integration (CPI) — query packages, iFlows, message processing logs, partner directory, security material, and more via the CPI OData API.
