# @cheetahbyte/pi-subagents

> 标签: agent, autonomous, pi, pi-extension, pi-package, subagent

## 简介

A pi extension that brings Claude Code-like sub-agents and workflow orchestration to pi — parallel execution, live widget, custom agent types, mid-run steering, dynamic workflows, Claude Code compatibility, look and feel.
