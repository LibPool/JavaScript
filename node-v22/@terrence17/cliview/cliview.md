# @terrence17/cliview

> 标签: ai-agent, claude-code, cli, codex, cursor, developer-tools, publish, web

## 简介

Publish your CLI as a polished web page using your local AI agent (Claude Code, Codex, Cursor, …). cliview is the pipeline; your agent is the model.
