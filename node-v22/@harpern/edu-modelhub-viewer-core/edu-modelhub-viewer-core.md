# @harpern/edu-modelhub-viewer-core

> 标签: 3d, accessibility, edu_modelhub, glb, gltf, threejs, viewer

## 简介

Framework-agnostic viewer core for EDU_modelhub models: metadata loading, normalization, region binding, annotation markers, and camera behavior shared by every conforming viewer
