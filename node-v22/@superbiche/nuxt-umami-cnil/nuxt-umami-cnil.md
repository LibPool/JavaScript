# @superbiche/nuxt-umami-cnil

> 标签: analytics, cnil, nuxt, nuxt-module, privacy, umami

## 简介

Nuxt module for self-hosted Umami under the CNIL audience-measurement exemption: no query strings, origin-only referrers, no ids, visitor opt-out, correct page titles.
