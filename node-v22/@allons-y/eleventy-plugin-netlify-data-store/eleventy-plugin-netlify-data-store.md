# @allons-y/eleventy-plugin-netlify-data-store

> 标签: cache, data-store, eleventy, eleventy-plugin, netlify, netlify-blobs

## 简介

Read & write build-time content for Eleventy from Netlify Blobs, with a TTL-based local cache for fast, offline-tolerant builds.
