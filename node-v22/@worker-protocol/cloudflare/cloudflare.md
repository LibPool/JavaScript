# @worker-protocol/cloudflare

> 标签: cloudevents, cloudflare, durable-objects, queues, rowing-tech, worker, worker-protocol

## 简介

The protocol's stores in Durable Objects, and the Queues between an outbox and a sink: mixins for ENDP-16, SUB-7, LOG-2 and an outbox, for Workers on Cloudflare
