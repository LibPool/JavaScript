# @nightwatch/vue

> 标签: JavaScript

## 简介

Nightwatch plugin which adds support for Vue component testing using the Vite dev server. Requires Nightwatch 2.0+

## 官网

- 官网：https://nightwatchjs.org
- 源码仓库：git+ssh://git@github.com/nightwatchjs/nightwatch-plugin-vue.git
- npm 页面：https://www.npmjs.com/package/@nightwatch/vue
