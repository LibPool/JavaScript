# dsh-on-phone

> 标签: deepseek-harness, dsh, dsh-plugin, mobile, mobile-web, phone, plugin, remote-access, second-screen, tailscale

## 简介

让手机成为 DeepSeek Harness 的第二块屏：手机浏览器打开你自己 tailnet 里的地址，就能直接用电脑上的 DSH。默认走 Tailscale Serve，无需配对、不经第三方中继。
