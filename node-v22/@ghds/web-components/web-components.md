# @ghds/web-components

> 标签: custom-elements, design-system, ghds, hand-drawn, lit, sketchy, web-components

## 简介

Framework-agnostic hand-drawn (sketchy) web components for GHDS, authored with Lit. Outlines from @ghds/sketch-core, design values from @ghds/tokens.
