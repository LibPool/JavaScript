# pi-provider-gd

> 标签: girard-davila, litellm, pi-extension, pi-package

## 简介

Native `gd` pi provider for api.girard-davila.net: /login gd accepts a pasted API key or browser SSO, key auto-stored, models appear as gd/<model-id> with no restart. Self-contained (no pi-provider-litellm).
