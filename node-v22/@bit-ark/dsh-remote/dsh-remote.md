# @bit-ark/dsh-remote

> 标签: JavaScript

## 简介

远程工作区：把 SSH 主机上的项目目录接入 dsh 侧栏工作区，AI 的读写 / bash / 搜索自动路由到远端执行（本地大脑 + 远程手脚）。管理界面由 dsh-work 工作台的「远程工作区」标签提供。
