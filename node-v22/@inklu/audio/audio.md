# @inklu/audio

> 标签: audio, data-attributes, declarative, feedback, notification-sound, sfx, sound, ui, web-audio

## 简介

A synthesized sound library for interfaces. No audio files, no dependencies — every sound is generated on the fly with the Web Audio API.
