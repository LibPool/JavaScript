# @inklu/keys

> 标签: accessibility, command-palette, commands, hotkeys, keybindings, keyboard, react, scopes, sequences, shortcuts

## 简介

A command system for the web — typed commands, portable keybindings, scopes, sequences, conflict detection, rebinding, and platform-aware display.
