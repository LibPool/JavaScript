# @vibecontrols/vibe-plugin-security-rescan

> 标签: bun, epss, grype, rescan, scheduled, security, vibe, vibe-plugin, vibecontrols

## 简介

Scheduled nightly rescan for the scheduled.rescan lifecycle stage. Reloads the latest SBOM evidence from the agent's local cache, runs Grype offline, and optionally enriches findings with EPSS scores via FIRST.org.
