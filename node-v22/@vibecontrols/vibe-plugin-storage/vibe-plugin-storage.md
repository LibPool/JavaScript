# @vibecontrols/vibe-plugin-storage

> 标签: bun, meta, storage, vibe, vibe-plugin, vibecontrols

## 简介

Storage meta plugin — owns the AgentDatabase contract and StorageProvider interface, and provides the adapter registry for concrete storage providers.
