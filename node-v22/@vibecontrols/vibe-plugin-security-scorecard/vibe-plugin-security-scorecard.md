# @vibecontrols/vibe-plugin-security-scorecard

> 标签: bun, main-merge, openssf, scorecard, security, vibe, vibe-plugin, vibecontrols

## 简介

OpenSSF Scorecard checks at the main.merge lifecycle stage. Runs `scorecard --repo file://<path>` for offline checks and `--repo <url>` when GH_TOKEN is present for full set.
