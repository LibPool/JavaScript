> 标签: bun, cve, gitleaks, grype, incident, secret, security, vibe, vibe-plugin, vibecontrols

## 简介

Targeted incident-response scanner for the incident.response lifecycle stage. Accepts input.config.cves[] and input.config.secretRules[] and runs only the targeted subset for sub-60s incident triage.
