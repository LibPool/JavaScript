# @gajae-gateway/cli

> 标签: cli, gajaeway, gateway

## 简介

Owner CLI for the gajaeway gateway: status, sessions, chat, monitors, and worker lanes over the gateway socket. Requires the Bun runtime (uses Bun.file/Bun.spawn).
