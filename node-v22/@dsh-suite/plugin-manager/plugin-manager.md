# @dsh-suite/plugin-manager

> 标签: deepseek-harness, dsh, dsh-plugin, plugin-manager, plugin-store

## 简介

DSH Web UI 插件应用商店：目录浏览/搜索/一键安装/兼容徽章/已装列表。A plugin store for DSH Web UI — catalog browse, search, one-click install, compat badges, installed list.
