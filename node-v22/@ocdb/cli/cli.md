# @ocdb/cli

> 标签: JavaScript

## 简介

openclaw-debug-toolkit 命令行工具。通过 REST 调用 `@ocdb/plugin` 暴露的 Debug Service（默认 `:7887`），提供 Agent 调试的全套命令。
