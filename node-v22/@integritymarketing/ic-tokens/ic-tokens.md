# @integritymarketing/ic-tokens

> 标签: JavaScript

## 简介

Palette primitives and CSS custom-property tokens. palette.ts is the only file in the monorepo where a hex literal may appear. Zero runtime dependencies by design, so non-React consumers (email, the Make kit, Figma variables) can install it without pullin
