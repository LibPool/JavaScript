# @polyskill/conorluddy.ios-simulator-skill

> 标签: JavaScript

## 简介

iOS Simulator Skill is a production-ready Agent Skill providing 21 scripts for iOS app building, testing, and automation. It wraps Apple's xcrun simctl and Facebook's idb tools with semantic interface
