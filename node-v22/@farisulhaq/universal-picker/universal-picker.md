# @farisulhaq/universal-picker

> 标签: accounting, calendar, date-picker, date-range-picker, datepicker, daterangepicker, doubledate, lightweight, no-dependency, periode, picker, typescript, vanilla-js

## 简介

A lightweight, zero-dependency date range picker. Supports calendar, accounting period, double-date, and periode (month-range) modes.
