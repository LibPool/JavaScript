# @emilia-protocol/gate

> 标签: agent, ai-safety, authorization, emilia, firewall, gate, mcp, policy-enforcement-point, receipt, trusted-action-firewall

## 简介

Executor-side consequence control that verifies relying-party-pinned evidence for one exact action, reserves authority before effect, and fails closed.
