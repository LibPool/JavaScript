# @emilia-protocol/fire-drill

> 标签: agent, ai-agent-security, ai-safety, authorization, eg-1, emilia, fire-drill, firewall, mcp, mcp-security, openapi, receipt, scanner

## 简介

Static declaration scanner for high-risk MCP/OpenAPI actions. Detects required receipt inputs without claiming runtime verification, consumption, or EG-1 enforcement.
