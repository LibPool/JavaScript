# slidelistener-miniprogram

> 标签: JavaScript

## 简介

- `verDeg`  垂直容差角度值   - `horiDeg` 水平容差角度值   - `vertDif` 垂直判断阈值   - `horiDif` 水平判断阈值   - `timeLim` 手指停留时间阈值（ms） ## 方法   - `slideUp` 向上滑动   - `slideDown` 向下滑动   - `slideLeft` 向左滑动   - `slideRight` 向右滑动
