# safe-qmath

> 标签: math, qmath, safemath, solidity

## 简介

Solidity library that provides basic mathematical operations on UQ128.64 fixed point numbers. UQ128.64 numbers are unsigned positive numbers with 128 bits of whole number precision and 64 bits of fractional precision.
