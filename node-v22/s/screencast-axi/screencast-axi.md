# screencast-axi

> 标签: agent, axi, cli, demo, gif, playwright, screencast, toon, video

## 简介

AXI-compliant screencast recorder - script a web workflow, record it with a synthetic cursor and captions, encode to mp4/webm/poster. Requires ffmpeg.
