# slack-stdio-mcp

> 标签: mcp, model-context-protocol, oauth, pkce, slack, stdio

## 简介

Agent-agnostic MCP stdio bridge to https://mcp.slack.com/mcp (user OAuth, PKCE, token refresh, tool proxy, local file download overlay)
