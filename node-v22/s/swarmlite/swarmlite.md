# swarmlite

> 标签: content-addressed, decentralized, ethswarm, serverless, sqlite, swarm, vfs, wasm, web3

## 简介

Verifiable serverless SQLite on Ethereum Swarm: lazy SELECT over gateway range reads (browser and Node), client-side verification, and a pure-JS publisher
