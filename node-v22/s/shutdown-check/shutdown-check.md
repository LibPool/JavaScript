# shutdown-check

> 标签: cli, graceful shutdown, http server, in-flight requests, integration testing, junit, node.js shutdown, node:test, process lifecycle, readiness probe, request draining, shutdown testing, sigterm, vitest, zero-dependency

## 简介

Verify Node.js graceful shutdown under SIGTERM: drain in-flight HTTP requests, withdraw readiness, reject new work, and report CI failures.
