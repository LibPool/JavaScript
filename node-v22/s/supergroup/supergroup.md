# supergroup

> 标签: compare, d3, dag, groupby, hierarchy, polyhierarchy, records, sequence, tree

## 简介

Grouping for flat records that returns navigable structure: trees, DAGs, sequences, and comparisons whose nodes carry records, parents, paths, and aggregates.
