# sf-inspector

> 标签: apex, audit, cli, devops, lwc, metadata, package.xml, salesforce, sf, sfdx

## 简介

A lightweight, zero-config CLI tool for Salesforce developers to inspect, audit, and compare metadata between local branches, package.xml, and Salesforce orgs.
