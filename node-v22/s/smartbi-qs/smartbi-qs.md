# smartbi-qs

> 标签: JavaScript

## 简介

#### Description 基于vue开发的问卷调查组件，主要题型包括：单选题，单选填空题，多选题，段落题，比重题，矩阵多选，矩阵单选，矩阵填空，判断矩阵，排序题，选择排序题
