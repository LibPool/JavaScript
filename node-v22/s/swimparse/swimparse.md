# swimparse

> 标签: ev3, hy-tek, hy3, hyv, meet-events, meet-results, parser, sd3, sdif, swim-meet, swimming, time-standards

## 简介

Parses SDIF v3 (.sd3) and Hy-Tek (.hy3) swim-meet result files into one NormalizedMeet JSON contract, and Hy-Tek meet-setup files (.ev3/.hyv) — events, sessions and qualifying cuts — into a NormalizedMeetSetup. Zero dependencies; runs in the browser, Node
