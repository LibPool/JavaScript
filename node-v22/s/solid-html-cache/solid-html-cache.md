# solid-html-cache

> 标签: cache, html, indexeddb, localstorage, lru, persistent-cache, solid, solidjs, tagged-template

## 简介

A structural cache wrapper for Solid 2 tagged HTML, with optional normalized built-template persistence through solid-html-cachable.
