# shap-svg

> 标签: beeswarm, explainable-ai, heatmap, interpretability, microbiome, react, shap, svg, waterfall, xai

## 简介

Interactive SVG charts for SHAP explanations — eight plots drawn in the browser from SHAP values, with a framework-free core and React components.
