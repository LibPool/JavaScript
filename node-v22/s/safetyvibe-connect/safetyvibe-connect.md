# safetyvibe-connect

> 标签: audit, dependencies, osv, safetyvibe, security, vulnerabilities

## 简介

Checks your app's dependencies for known vulnerabilities and its public configuration for common mistakes. Sends the package list and public settings only; preview with --dry-run.
