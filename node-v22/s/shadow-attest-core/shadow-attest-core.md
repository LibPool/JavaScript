# shadow-attest-core

> 标签: agent-recording, article-12, attestation, audit, ed25519, eu-ai-act, evidence, flight-recorder, hash-chain, tamper-evident

## 简介

Zero-LLM-dep cryptographic evidence primitives for AI decision attestation and agent session recording. Ed25519 signing, hash chain, batch attestation, and streaming session bundle API. Independently verifiable offline.
