# science-ai-mcp-server

> 标签: academic, citation, claude, claude-desktop, cline, cursor, journal-recommender, mcp, model-context-protocol, peer-review, pubmed, research, research-gaps, scholarly-publishing, science-ai-journal, writer

## 简介

MCP (Model Context Protocol) server for Science AI Journal tools — Pre-Check, AI Review, Research Gaps, Journal Recommender, Duplicate Publication Checker, Article Writer. Use them inside Claude Desktop, Cursor, Cline, or any MCP-enabled client.
