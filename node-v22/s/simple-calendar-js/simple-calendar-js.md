# simple-calendar-js

> 标签: angular, booking, calendar, calendar-component, dark-mode, date-picker, datepicker, day-view, event-calendar, events, framework-agnostic, fullcalendar-alternative, javascript, list-view, month-view, no-jquery, range-picker, react, responsive, scheduler, scheduling, ui-component, vanilla-js, vue, week-view, zero-dependencies

## 简介

Lightweight JavaScript calendar component (~16KB gzipped). Zero dependencies, framework-agnostic (React, Vue, Angular, vanilla JS). Month, week, day, and list views. Built-in date & range picker. Free for personal use — commercial license at simplecalenda
