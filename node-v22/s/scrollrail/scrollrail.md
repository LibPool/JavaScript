# scrollrail

> 标签: action, attachment, custom-scrollbar, directive, react, scrollbar, scrollrail, svelte, vanilla, vue

## 简介

Framework-agnostic custom scrollbars — Vue directive, Svelte action and attachment, and a helper for vanilla JS and React. Zero framework peer dependencies.
