# solidity-argus

> 标签: audit, defi, ethereum, foundry, opencode, plugin, security, slither, smart-contract, solidity

## 简介

Solidity smart contract security auditing plugin for OpenCode — 6 specialized agents, 16 tools (15 core + optional Solodit), and a curated vulnerability knowledge base
