# solhint-plugin-gsn

> 标签: linters, solhint, solidity, testing

## 简介

A solhint plugin intended for use with contracts which make use of Gas Station Network and therefore cannot use msg.sender or msg.data, and must rather use the GSN-specific implementations of these functions.
