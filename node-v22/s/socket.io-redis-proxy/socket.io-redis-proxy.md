# socket.io-redis-proxy

> 标签: JavaScript

## 简介

Provides a way for redis adapter to define a proxy url to enable redis message delivery to particular VMs where client is connected in cloud deployments. This is based on top of socket.io-redis 5.4.0 version. ## License
