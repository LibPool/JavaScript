# stockbit-mcp

> 标签: bandarmology, broker-summary, claude, cursor, idx, indonesia, mcp, mcp-server, model-context-protocol, saham, stock-market, stockbit, trading

## 简介

MCP server for Stockbit (IDX, Indonesia): bandarmology/broker flow, quotes, orderbook, fundamentals, screener, watchlists, alerts, chart drawing and confirm-gated order entry through your own Stockbit account. Unofficial.
