# ssrf-guarded-fetch

> 标签: dns, fetch, rate-limit, redirect, robots.txt, security, ssrf

## 简介

A fetch wrapper that resolves DNS before connecting, blocks private/loopback/link-local/CGNAT addresses, re-checks every redirect hop, honours robots.txt, and rate-limits per host. No dependencies.
