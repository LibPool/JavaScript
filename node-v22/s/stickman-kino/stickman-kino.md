# stickman-kino

> 标签: agent-skills, animation, claude-code, codex, explainer-video, gsap, hyperframes, motion-graphics, stick-figure, stickman, text-to-video

## 简介

Stickman explainer films, directed by your AI agent and rendered as code. No video-generation APIs: agent skills + animation engine + CLI for Claude Code, Codex, Cursor, Gemini CLI and friends.
