# swagger-to-tanstack-query

> 标签: api-client, axios, code-generator, codegen, hooks, openapi, openapi-codegen, openapi-typescript, openapi3, queryKey, queryOptions, react, react-query, swagger, swagger-codegen, swagger2, tanstack, tanstack-query, type-safe, typescript

## 简介

Generate fully type-safe TanStack Query (React Query) code — queryOptions hooks, axios API functions and TypeScript types — from a Swagger/OpenAPI spec, split one folder per controller.
