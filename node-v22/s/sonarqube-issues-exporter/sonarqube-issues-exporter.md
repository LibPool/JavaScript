# sonarqube-issues-exporter

> 标签: cli, code-quality, coverage, dashboard, local, pdf-report, quality-gate, security-hotspots, sonarcloud, sonarqube, static-analysis, typescript

## 简介

Run a local SonarQube dashboard on your machine — live issues, quality gate, hotspots, coverage across projects/branches, with PDF export. No more logging into the dashboard or SSHing to the VM.
