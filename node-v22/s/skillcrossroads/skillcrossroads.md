# skillcrossroads

> 标签: audit, claude, claude-code, linter, quality, scorecard, skills

## 简介

Skill Crossroads CLI — the signpost for Claude Code artifacts. Audit a Skill and get an evidence-based quality scorecard with a letter grade: ship, fix, or rethink.
