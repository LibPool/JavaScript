# sigilkit

> 标签: adventure, game-engine, ink, isometric, partykit, pixijs, point-and-click, react, scumm

## 简介

Composable 2D adventure engine for React in the spirit of SCUMM: painted rooms, point-and-click verbs, Ink story, orthogonal and isometric rooms, optional PartyServer multiplayer. Import only the parts you use.
