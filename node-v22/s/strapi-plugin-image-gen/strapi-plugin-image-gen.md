# strapi-plugin-image-gen

> 标签: ai, gemini, image-generation, media-library, nano-banana, plugin, strapi, strapi-plugin

## 简介

Generate and retouch Media Library images from inside Strapi, with Google's Nano Banana models. Generated files become ordinary assets — thumbnails, responsive formats, provider storage.
