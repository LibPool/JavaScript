# scoutpost-cli

> 标签: cli, journalism, news-monitoring, osint, scout, scoutpost

## 简介

Scout — the CLI for Scoutpost (scoutpost.ai), AI-powered local news monitoring. Ships the native deno-compiled `scout` binary via npm.
