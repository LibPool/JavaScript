# syntony

> 标签: crdt, decentralized, distributed, eventual-consistency, feature-flags, gossip, hlc, swim

## 简介

An embedded, decentralized, in-process shared-state primitive. A shared object any instance of your app can read and write instantly, which syncs itself across the fleet with no server to run.
