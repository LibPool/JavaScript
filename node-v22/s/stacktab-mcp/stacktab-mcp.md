# stacktab-mcp

> 标签: free-tier, mcp, modelcontextprotocol, pricing, saas, stack-cost, stacktab

## 简介

StackTab MCP server from Compound Labs. Reports published pricing and free-tier limits for SaaS services and estimates a stack's monthly bill. No key and no signup.
