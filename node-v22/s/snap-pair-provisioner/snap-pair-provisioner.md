# snap-pair-provisioner

> 标签: firebase, mcp, model-context-protocol, snap-pair

## 简介

Local MCP server that provisions the Firebase backend (Anonymous Auth + default Realtime Database, plus .env injection) for snap-pair-core, alongside the official Firebase MCP server.
