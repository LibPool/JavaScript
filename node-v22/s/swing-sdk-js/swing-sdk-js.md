# swing-sdk-js

> 标签: analytics, business-intelligence, event-tracking, humanbehavior, nextjs, performance-monitoring, privacy, react, rrweb, session-recording, session-replay, typescript, user-behavior, user-tracking, web-analytics

## 简介

Complete session replay SDK for Next.js with automatic business intelligence tracking. Drop-in replacement for HumanBehavior SDK with rrweb-powered recording, user management, and privacy controls.
