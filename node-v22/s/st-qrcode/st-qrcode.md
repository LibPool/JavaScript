# st-qrcode

> 标签: JavaScript

## 简介

QRCode.js is javascript library for making QRCode. QRCode.js supports Cross-browser with HTML5 Canvas and table tag in DOM. QRCode.js has no dependencies.

## 官网

- npm 页面：https://www.npmjs.com/package/st-qrcode
