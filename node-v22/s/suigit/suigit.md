# suigit

> 标签: blockchain, cli, decentralized, git, github, repository, storage, sui, version-control, walrus, web3

## 简介

Decentralized GitHub on Sui blockchain with Walrus storage integration. Create and manage repositories, branches, and pull requests on-chain with fine-grained privacy control.
