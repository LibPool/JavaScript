# sad-popup

> 标签: ljy, popup, sad-popup

## 简介

Popup 组件是一个可定制的弹出层组件，可用于在网页上展示特定内容，并提供一些可选的动画效果。该组件适用于需要在用户交互或特定事件发生时显示临时信息或内容的场景。
