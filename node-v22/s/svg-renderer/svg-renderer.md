# svg-renderer

> 标签: dom, expo, floor-plan, gesture-handler, hit-testing, map, pan, react, react-dom, react-native, react-native-svg, reanimated, renderer, svg, typescript, viewer, web, zoom

## 简介

Fast, correct SVG rendering for React Native on top of react-native-svg and for React DOM (import from /web), plus a pan/zoom viewer (import from /viewer or /web) with taps resolved in SVG space, selection highlights, badges and built-in controls.
