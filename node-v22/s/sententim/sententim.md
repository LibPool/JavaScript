# sententim

> 标签: claude, deterministic, fts5, legaltech, local-first, mcp, model-context-protocol, no-llm-runtime, orzecznictwo, polish-law, sad-najwyzszy, sad-okregowy, sad-rejonowy, sankcja-kredytu-darmowego, saos, sqlite, sygnatura, typescript

## 简介

Deterministyczny weryfikator sygnatur wyroków polskich sądów — MCP, lokalnie, offline, zero LLM w runtime. Jeśli wyrok nie istnieje w bazie → NOT_FOUND, nigdy halucynacji.
