# sdc-angular-dragdrop

> 标签: JavaScript

## 简介

This directive with chges required by sdc allows you to use jQuery UI's draggable and droppable plugins with AngularJS. SDC project: https://gerrit.onap.org/r/gitweb?p=sdc.git;a=summary
