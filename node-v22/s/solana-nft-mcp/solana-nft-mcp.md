# solana-nft-mcp

> 标签: ai-agent, candy-digital, claude, digital-collectibles, magic-eden, mcp, metaplex-core, model-context-protocol, nft, nft-data, solana, solana-nft, web3

## 简介

Read-only MCP server for Solana NFTs and digital collectibles: Metaplex Core ownership history, who can freeze or burn an item, marketplace sales and floors that keep their currency and source. No sign-up.
