# spdt

> 标签: chrome, declarative, e2e, fixture, generator, headless, jest, puppeteer, react, storybook, test, testing

## 简介

spdt stands for Storybook Puppeteer Declarative Testing. Declarative testing of isolated React components using storybook as a renderer and puppeteer+jest as a test runner
