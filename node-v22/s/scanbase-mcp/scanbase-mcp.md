# scanbase-mcp

> 标签: 152-fz, compliance, mcp, modelcontextprotocol, personal-data, privacy, russia, scanbase

## 简介

MCP-сервер ScanBase — сканер сайтов на соответствие 152-ФЗ (персональные данные) и смежным законам РФ. Даёт AI-агентам инструмент проверки сайтов на юридическое соответствие.
