# silverbullet-mcp

> 标签: knowledge-base, markdown, mcp, model-context-protocol, notes, pkms, silverbullet

## 简介

MCP bridge that exposes a SilverBullet space's /.fs HTTP API as MCP tools — list, read, write, append, delete and search markdown pages.
