# siyuan-kernel-primitives

> 标签: JavaScript

## 简介

Deterministic, version-pinned building blocks for the SiYuan kernel API — block-tree walks, title guard, doc reads, and verified writes that prove they landed and refuse on kernel drift or stale content.
