# stackdeck

> 标签: ai-agent, dashboard, dev-server, git, git-worktree, hotel, local-development, mcp, mcp-server, process-manager, procfile, worktree

## 简介

Your agent made four worktrees. Stackdeck runs them: starts, supervises, streams logs, shows every port on the machine, and drives it all over MCP. A browser and terminal board for local dev services — zero dependencies, never leaves 127.0.0.1.
