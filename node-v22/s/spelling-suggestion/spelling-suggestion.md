# spelling-suggestion

> 标签: algorithm, compare, comparison, diff, difference, leven, levenshtein, match, matching, search, similar, similarity, spelling, spelling-suggestion, suggestion

## 简介

Given a name and a list of names that are not equal to the name, return a spelling suggestion if there is one that is close enough.
