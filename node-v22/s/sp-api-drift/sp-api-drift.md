# sp-api-drift

> 标签: amazon, drift, lockfile, reports-api, schema, selling-partner-api, sp-api

## 简介

Lockfile-based drift detection for Amazon SP-API report columns and undocumented rate limits that have no OpenAPI schema to diff.
