# stylesheet-ui

> 标签: cli, components, design-system, expo, react-native, stylesheet, ui

## 简介

Copy-paste React Native components for Expo. Plain StyleSheet, no DSL — you own the source. Run `npx stylesheet-ui init`, then `add <name>` to drop a component into your project.
