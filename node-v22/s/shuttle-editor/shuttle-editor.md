# shuttle-editor

> 标签: editor, katex, markdown, notes, prosemirror, react, tiptap, wiki-links

## 简介

A React rich-text editor for note-taking apps, built on Tiptap 3: wiki links, addressable blocks, transclusion, math, tables and markdown paste.
