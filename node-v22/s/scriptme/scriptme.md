# scriptme

> 标签: templates

## 简介

Scriptme is a smart-template engine inspired by script-host platform like php+html but using nodejs code, you cant make text/plain, source code or anything you want from templates

- 源码仓库：https://github.com/delmosaurio/scriptme.git
