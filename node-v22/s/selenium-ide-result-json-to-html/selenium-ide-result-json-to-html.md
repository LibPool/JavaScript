# selenium-ide-result-json-to-html

> 标签: JavaScript

## 简介

Using jest-stare to parse selenium side runner's test result json   Usage:   ``` npm i -g selenium-ide-result-json-to-html --registry=https://registry.npm.taobao.org j2h -f "json file"   ```
