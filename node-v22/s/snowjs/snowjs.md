# snowjs

> 标签: snow, snow-flake, snowflake, snowjs, 下雪, 雪花

## 简介

snowjs 是一个雪花效果的插件；通过使用 Canvas 来显现雪花效果，支持与雪花交互；

- npm 页面：https://www.npmjs.com/package/snowjs
