# skillfold

> 标签: agent-skills, agentskills, claude, claude-code, devtool, lockfile, package-manager, skill-manager, skill-md, skillfold-skill, skills, yaml

## 简介

Declarative skill manager for Claude config. Declare skills in YAML, pin them in a lockfile, install them into .claude/skills.
