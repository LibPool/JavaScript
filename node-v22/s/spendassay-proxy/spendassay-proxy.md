# spendassay-proxy

> 标签: ai, anthropic, cost, finops, gateway, llm, observability, openai, proxy, spendassay

## 简介

Drop-in observe-only LLM gateway for SpendAssay — swap one base URL to get per-request cost attribution (customer, feature, agent) with zero code changes. OpenAI- and Anthropic-compatible. Transparent streaming passthrough, fail-open, zero runtime deps.
