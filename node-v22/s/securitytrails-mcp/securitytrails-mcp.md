# securitytrails-mcp

> 标签: dns, mcp, modelcontextprotocol, osint, recon, security, securitytrails, subdomain-enumeration, whois

## 简介

Unofficial MCP server for the SecurityTrails API — DNS history, subdomain enumeration, WHOIS, SSL certificates and IP intelligence as tools for LLM agents. Not affiliated with SecurityTrails or Recorded Future.
