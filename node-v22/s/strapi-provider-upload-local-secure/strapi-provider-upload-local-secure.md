# strapi-provider-upload-local-secure

> 标签: file, local, path, private, provider, security, strapi, upload

## 简介

Strapi v5 local upload with path/pathDir organization, private folder (JWT/HMAC URLs), multi-upload, robust delete, and optional empty-dir cleanup.
