# santriverse-skills

> 标签: agent-skills, antigravity, google-apps-script, mcp, monorepo, santriverse

## 简介

One-command installer that connects Santriverse skill repositories (Apps Script + Monorepo guidelines) to Google Antigravity as Agent Skills or an MCP server.
