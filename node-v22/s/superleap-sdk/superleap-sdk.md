# superleap-sdk

> 标签: api, client, crm, django-like, javascript, orm, query-builder, sdk, superleap, typescript

## 简介

A comprehensive JavaScript SDK for interacting with the Superleap CRM API, with a Django-like query builder, opt-in caching and a throwing ORM layer
