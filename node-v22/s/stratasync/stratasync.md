# stratasync

> 标签: cli, create, linear, linear sync engine, local-first, offline-first, scaffold, sync, sync-engine, typescript

## 简介

stratasync: the CLI for Strata Sync, an open-source implementation of Linear's sync engine. `npx stratasync init my-app` scaffolds a runnable local-first app with a Fastify + Postgres sync server and a React client.
