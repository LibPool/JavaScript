# semantic-inspector

> 标签: ai, babel, babel-plugin, clipboard, data-loc, devtools, inspector, jsx, react, screenshot, source-location, vibe-coding, vite, vite-plugin

## 简介

Dev-only React inspector: a hotkey highlights elements and click-copies their `Component — file:line` (or a PNG screenshot) for fast context handoff to AI coding assistants.
