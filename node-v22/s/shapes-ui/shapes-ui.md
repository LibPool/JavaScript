# shapes-ui

> 标签: JavaScript

## 简介

- Create a new app: `npx shapes-ui create my-app` - Create and install deps: `npx shapes-ui create my-app --install` - Full setup in one step: `npx shapes-ui create my-app --full` - Full setup with style: `npx shapes-ui create my-app --full --style brutal
