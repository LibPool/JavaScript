# sonics

> 标签: click, haptics, microinteraction, react, sound, sound-effects, synthesis, ui, web-audio, zero-dependency

## 简介

Tiny, dependency-free UI sounds you can feel. Synthesised in the browser with the Web Audio API — no audio files.
