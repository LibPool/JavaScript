# schema-form-lint

> 标签: forms, json-forms, json-schema, jsonforms, lint, react-jsonschema-form, rjsf, static-analysis, uischema

## 简介

Static checks for JSON Forms and react-jsonschema-form configs. Catches required-but-hidden fields, impossible rule conditions, and dead uiSchema keys before your users do.
