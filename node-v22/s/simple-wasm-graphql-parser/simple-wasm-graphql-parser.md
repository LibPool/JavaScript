# simple-wasm-graphql-parser

> 标签: graphql, parser, rust, schema, typescript, wasm, webassembly

## 简介

A very basic GraphQL parser that uses Apollo's parser as a start and some custom logic to extract all data from a schema. The package in npm was built and published using wasm-pack.
