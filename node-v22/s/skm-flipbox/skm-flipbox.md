# skm-flipbox

> 标签: JavaScript

## 简介

**EditorJS Carousel Plugin** is a custom tool for the [EditorJS](https://editorjs.io/) framework that enables users to add, edit, and delete text carousels within the editor. This plugin provides a seamless way for users to incorporate carousel components
