# stylize-css

> 标签: converter, css, css-to-json, design-system, design-tokens, generator, json, parser, sass, sass-to-json, scss, scss-to-json, style-analysis, stylesheet, theme

## 简介

Bidirectional CSS/SCSS/SASS to JSON converter. Parse stylesheets to structured JSON and generate back while preserving variables, nesting, sections, and comments.
