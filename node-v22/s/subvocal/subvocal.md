# subvocal

> 标签: claude-code, codex, copilot, cursor, gemini-cli, hooks, plugin, reasoning, shorthand, thinking-tokens

## 简介

Fewer thinking tokens, same answers. One measured instruction keeps a model's internal reasoning concise; the reply is unchanged. `/subvocal ultra` asks for a minimum draft per thinking step.
