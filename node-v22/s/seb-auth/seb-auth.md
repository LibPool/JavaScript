## 简介

Official JavaScript/Node.js SDK for SebAuth — one API key, five services: authentication (SebAuth), document database (SebBase), transactional email (SebMail), static site hosting (SebHost) and hosted checkout (SebCheckout) on https://seb-auth.lovable.app
