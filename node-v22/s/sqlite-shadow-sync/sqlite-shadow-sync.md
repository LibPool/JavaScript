# sqlite-shadow-sync

> 标签: background-backup, backup, database-rotation, integrity-check, shadow-copy, sqlite, sqlite3, wal-mode, zero-dependency

## 简介

Safe, zero-lock, automatic background shadow backups for SQLite in Node.js with WAL-safety, compression, and integrity-checks.
