# superfastmongooserest

> 标签: ReST, express, model, mongodb, mongoose, node, restify

## 简介

Create a REST interface for mongoose models and allow simple manipulation of your models from your client side code; Abstract all the boilerplate needed to set up an express-mongo server into a single line of code
