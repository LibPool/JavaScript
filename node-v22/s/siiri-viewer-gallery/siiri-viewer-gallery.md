# siiri-viewer-gallery

> 标签: bim, demo, siiri, viewer

## 简介

BIM轻量化平台是一个互联网三维可视化解决方案。包括BIM轻量化引擎和业务组件。本项目是轻量化引擎的一些简单示例。
