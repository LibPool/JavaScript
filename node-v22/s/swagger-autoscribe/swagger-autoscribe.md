# swagger-autoscribe

> 标签: api-documentation, autodoc, documentation-generator, nestjs, nodejs, openapi, postman, swagger, swagger-ui, typescript

## 简介

Zero-config Swagger/OpenAPI docs for NestJS: reads your TypeScript to document schemas, errors, auth and pagination, and adds Postman-style variables in Swagger UI.
