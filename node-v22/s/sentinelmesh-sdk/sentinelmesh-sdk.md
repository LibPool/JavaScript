# sentinelmesh-sdk

> 标签: cdr, edr, encrypted, sentinelmesh, story-protocol, telemetry, threat-intelligence, web3

## 简介

Registered-org, Langfuse-style telemetry SDK for the SentinelMesh encrypted cross-org threat pool on Story CDR. Register an org, capture bad EDR events (encrypted client-side, contributed to a CDR vault), and read/subscribe to correlated cross-org campaig
