# svelte-a2ui

> 标签: a2ui, ag-ui, agent, generative-ui, genui, llm, svelte, sveltekit

## 简介

A2UI (Agent-to-UI) protocol renderer for Svelte 5. Runes-native. Renders agent-authored declarative UI from a locked component catalog.
