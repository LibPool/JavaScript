# svelteesp32

> 标签: angular, esp32, esp8266, espasyncwebserver, psychichttpserver, react, svelte, svelte5, vue, webserver

## 简介

Convert Svelte (or any frontend) JS application to serve it from ESP32 webserver (PsychicHttp)
