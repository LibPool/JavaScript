# sileojs

> 标签: css-animation, gooey, metaballs, notificaciones, notification, react, spring, svelte, toast, vanilla-js, vue, vue3, zero-dependencies

## 简介

Toast notificaciones con morphing gooey y spring physics. Core vanilla JS (cero dependencias) + adaptador Vue 3. Toda la animacion en CSS.
