# simpletslinq

> 标签: HelpLibrary, Linq, Simple, Typescript

## 简介

A simple library with utility method with Linq-like functionality on Arrays in Js, written in Typescript. Adds utility methods to Array prototype for easy way of calling utility methods directly on arrays. Contains additional functionality also with helpe
