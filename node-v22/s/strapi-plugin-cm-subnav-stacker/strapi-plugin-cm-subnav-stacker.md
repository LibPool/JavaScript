# strapi-plugin-cm-subnav-stacker

> 标签: content-manager, content-manager menu, content-manager navigation, navigation, strapi, strapi admin, strapi admin menu, strapi admin navigation, strapi admin subnavigation, strapi custom navigation, strapi menu, strapi navigation, strapi plugin, subnavigation

## 简介

Automatically groups related content types in the Strapi Content Manager sidebar into collapsible subnavigation sections based on name patterns.
