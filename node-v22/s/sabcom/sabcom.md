# sabcom

> 标签: SharedArrayBuffer, atomic, buffer, communication, concurrency, inter-process, ipc, memory, multithreading, parallel, shared, synchronization, thread, worker

## 简介

A TypeScript/Node.js library for inter-thread communication using SharedArrayBuffer with atomic operations for raw buffer data transfer
