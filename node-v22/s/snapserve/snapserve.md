# snapserve

> 标签: admin, cli, express, file-server, gallery, npx, photo, photo-management, react, server, tailwind, typescript, upload, vite

## 简介

A lightweight CLI photo server with admin authentication and React frontend. Start with 'npx snapserve --admin yourpassword'
