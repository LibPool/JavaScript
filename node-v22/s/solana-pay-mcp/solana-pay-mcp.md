# solana-pay-mcp

> 标签: agent, claude, invoice, mcp, model-context-protocol, payments, solana, solana-pay, usdc

## 简介

MCP server that lets Claude invoice, get paid, and pay in USDC on Solana. Stripe agent toolkit, but USDC on Solana.
