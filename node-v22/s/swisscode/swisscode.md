# swisscode

> 标签: account-switcher, anthropic, anthropic-api, api-key-manager, claude, claude-code, claude-max, claude-pro, cli, coding-agent, developer-tools, llm, openrouter, profiles, proxy, rate-limit, usage-limits

## 简介

swisscode CLI: launch Claude Code with a named profile — switch between multiple Claude Pro/Max accounts, run the subscription proxy with rate-limit failover, use OpenRouter or custom providers.
