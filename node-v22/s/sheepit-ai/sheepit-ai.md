# sheepit-ai

> 标签: cli, codegen, devtools, feature-flags, flags, sheepit

## 简介

Installs the Sheepit CLI. Re-exports the `sheepit` binary from @sheepit-ai/cli so `npm install -g sheepit-ai` works.
