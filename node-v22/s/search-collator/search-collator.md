# search-collator

> 标签: case-insensitive, collator, endswith, find, includes, indexof, intl, lastindexof, locale, punctuation, reverse, search, startswith

## 简介

Extensions for Intl.Collator for locale-aware searching in strings (findMatches, findMatch, indexOf, lastIndexOf, includes, startsWith, endsWith).
