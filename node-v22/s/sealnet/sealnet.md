# sealnet

> 标签: e2ee, end-to-end-encryption, file-sharing, sdk, seal, secure

## 简介

Official SEAL SDK: send and open end-to-end encrypted files and secrets, and ask a person for one, from any website or server. The key never reaches SEAL.

## 官网

- 官网：https://seal.net
- npm 页面：https://www.npmjs.com/package/sealnet
