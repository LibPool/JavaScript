# subscription-gateway

> 标签: agent-sdk, deepseek-harness, gateway, mcp, subscription

## 简介

Subscription gateway for DeepSeek Harness — runs the model loop through the vendor's official agent SDK, so the platform works on a subscription seat instead of a metered API key, with the token kept in one place on the machine.
