# sellbonds-mcp

> 标签: ai-agent, base, bonds, defi, mcp, model-context-protocol, sellbonds

## 简介

MCP server for sellbonds.now — lets any MCP client (Claude, Cursor, custom agents) issue, fund, and manage uncollateralized on-chain bonds in USDC on Base.
