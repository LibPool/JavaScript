## 简介

Batch ERC-20 payouts for AI agents — pay up to 200 recipients in one atomic transaction on Base with any token. Gasless via CDP Paymaster (agents holding only tokens, zero ETH, can pay), non-custodial auto-wallet, and per-agent budget caps. An OpenClaw pl
