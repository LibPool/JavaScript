# serpdive-cli

> 标签: agent, ai, claude, codex, cursor, mcp, serpdive, skill, web-search, windsurf

## 简介

One command to wire SERPdive into every AI coding agent on this machine — MCP server plus an agent skill. Real-time web search that returns answer-ready page content instead of links.
