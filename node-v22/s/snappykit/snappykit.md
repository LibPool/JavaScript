# snappykit

> 标签: browser, classes, css, dom, events, formatting, helpers, html, lightweight, manipulation, parser, store, string, toolkit, typescript, utilities, zero-dependency

## 简介

A lightweight, zero-dependency TypeScript utility kit for DOM manipulation, event handling, string formatting, HTML parsing, and state management.
