# sf-org-migrator

> 标签: contentversion, data-migration, files, migration, org-to-org, salesforce, sfdc, sfdx

## 简介

Migrate Salesforce records and files between orgs — files up to 2GB, resumable, with version history. OAuth login, auto field mapping, and a local web UI.
