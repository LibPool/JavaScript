# signalk-x729

> 标签: battery, geekworm, raspberry-pi, signalk-category-utility, signalk-node-server-plugin, ups, x729

## 简介

Signal K plugin for the Geekworm X729 UPS (Raspberry Pi): publishes battery voltage/capacity and an AC power-loss notification
