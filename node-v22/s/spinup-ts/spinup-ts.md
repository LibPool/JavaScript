# spinup-ts

> 标签: biome, boilerplate, cli, docusaurus, eslint, scaffold, starter, template, typescript, vitest

## 简介

Scaffold a production-ready TypeScript project with opinionated tooling (Biome, ESLint strict, Vitest, Husky, GitHub Actions, Docusaurus, Docker, devcontainer). The TypeScript sibling of spinup-py.
