# sframework

> 标签: JavaScript

## 简介

本项目中包含了以下一些类库： * laya.core.js * laya.webgl.js * laya.ui.js * laya.ani.js * lodash.js:lodash方法库，其中含有以下一些方法   * groupBy   * uniq   * chunk   * isArray   * isObject   * fill   * random   * clamp   * intersection   * flatten   * countBy   * d
