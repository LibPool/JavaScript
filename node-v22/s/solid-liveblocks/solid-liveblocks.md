# solid-liveblocks

> 标签: collaboration, collaborative, conflict resolution, crdts, documents, liveblocks, multiplayer, presence, reactivity, real-time, rooms, solid, synchronize, toolkit, websockets

## 简介

A set of Solid hooks and providers to use Liveblocks declaratively. Liveblocks is the all-in-one toolkit to build collaborative products like Figma, Notion, and more.
