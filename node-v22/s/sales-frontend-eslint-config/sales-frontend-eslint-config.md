# sales-frontend-eslint-config

> 标签: JavaScript

## 简介

ESLint 9 **flat config** 공유 설정. 구 `eslint-config-v8`(eslintrc)의 룰셋을 1:1로 이식했다. (구 `eslint-config-v9` 패키지를 이 패키지로 통합)
