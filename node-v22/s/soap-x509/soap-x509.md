# soap-x509

> 标签: soap

## 简介

A minimal node SOAP client with x509 signature security based off node-soap from Vinay Pulim <v@pulim.com>

- npm 页面：https://www.npmjs.com/package/soap-x509

- npm registry：https://registry.npmjs.org/soap-x509
- Node 要求：>=0.8.0
