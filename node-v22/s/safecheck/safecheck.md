# safecheck

> 标签: audit, cli, cve, maven, npm, osv, pypi, security, supply-chain, vulnerability

## 简介

Supply-chain risk scanner for npm, PyPI, and Maven packages - typosquats, maintainer takeovers, install-script surprises, known CVEs, and repo-wide dependency scanning. CLI for PackageSafe.

## 官网

- 官网：https://packagesafe.dev/cli
- 源码仓库：git+https://github.com/adewale-codes/IsThisPackageSafe.git
