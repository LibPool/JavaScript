# sqljs-documentstore

> 标签: Document, DocumentStore, ES7, Generic, Micro, ORM, SQLite, Store, Typescript

## 简介

Minimal, encrypted, sql friendly typed document store, with support for indexed columns. Protects against transactional conflicts
