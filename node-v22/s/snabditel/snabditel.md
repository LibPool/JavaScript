# snabditel

> 标签: als, async, async-hooks, container, dependency-injection, di, ioc, react-query, scoped, singleton, typescript, zero-dependencies

## 简介

Tiny async DI container — no ceremonies. Zero deps. ESM + CJS, scoped/singleton/transient, cycle detection, Symbol.asyncDispose support, optional ALS propagation.
