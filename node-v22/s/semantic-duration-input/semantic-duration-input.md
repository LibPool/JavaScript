# semantic-duration-input

> 标签: duration, input, iso8601, nuxt, nuxt-ui, parser, primevue, shadcn-vue, standard-schema, tailwindcss, time, vue, vue3, vuetify

## 简介

Vue 3 input component that parses human-friendly durations ("2h", "3 days", "1h30", "1:30", "PT1H") into minutes, seconds, ms or ISO 8601.
