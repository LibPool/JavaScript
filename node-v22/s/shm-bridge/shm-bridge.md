# shm-bridge

> 标签: SharedArrayBuffer, atomics, cross-process, ipc, mmap, mutex, native, ringbuffer, shared-memory, shm

## 简介

Cross-process shared memory for Node.js — SharedArrayBuffer over OS shared memory, plus a crash-safe Mutex, zero-copy RingBuffer, and ops utilities
