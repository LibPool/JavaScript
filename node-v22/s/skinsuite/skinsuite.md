# skinsuite

> 标签: css-variables, dark-mode, design-token, multi-layout, multi-theme, react, theme, theme-switch, typescript, vue, zero-dependency

## 简介

多主题 / 多版式机制的纯内核（零运行时依赖）：目录名与默认值的白名单常量、主题包契约类型、明暗 mode 与色系 tone、CSS 变量 token 的安全校验、设备维度 URL 参数读取。不碰 DOM / 构建器 / 路由，可在任意前端（Vue / React / Node / SSR）复用。
