# strapi-admin-2fa-pro

> 标签: 2fa, account-security, admin-security, authenticator, google-authenticator, login-security, mfa, multi-factor, one-time-password, otp, recovery-codes, rfc6238, security, strapi, strapi-plugin, strapi-v5, totp, two-factor, two-factor-authentication, users-permissions

## 简介

Two-factor authentication for Strapi v5 — TOTP with QR enrolment and recovery codes, enforced on the admin panel login and, optionally, on users-permissions sign-in.
