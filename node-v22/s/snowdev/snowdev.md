# snowdev

> 标签: boilerplate, browser-sync, dev, dev-server, development, es-modules, eslint, esm, format, formatter, js-doc, lint, linter, prettier, prototyping, scaffold, server, template, types, typescript, unbundled, zero-configuration

## 简介

Zero configuration, unbundled, opinionated, development and prototyping server for simple ES modules development: types generation, format and linting, dev server and TypeScript support.
