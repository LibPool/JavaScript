# sple-plugin

> 标签: JavaScript

## 简介

Sketch Plugin Library Export (SPLE) Sketch Plugin to export Sketch pages into pdfs and upload to CDN for 3rd party use

## 官网

- npm 页面：https://www.npmjs.com/package/sple-plugin

## 历史版本号

## 获取地址

- npm 安装：`npm install sple-plugin`
- npm registry：https://registry.npmjs.org/sple-plugin
- Node 要求：>=10.12.0
