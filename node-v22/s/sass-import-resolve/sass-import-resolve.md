# sass-import-resolve

> 标签: sass, sass-import, sass-import-resolve, sass-import-resolver, sass-imports, sass-parser, scss, scss-import, scss-import-resolve, scss-import-resolver, scss-imports, scss-parser

## 简介

Parses scss string and returns an array of filenames that the `@import` directives resolve.
