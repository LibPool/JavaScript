# super-beautiful-toast

> 标签: animation, microinteraction, morph, notification, shared-element, snackbar, spring, toast, vue, vue3, zero-dependencies

## 简介

Toast notifications for Vue 3 where the button that triggers the action becomes the toast. Physical springs, a card-deck stack, swipe and scroll to dismiss. No dependencies.
