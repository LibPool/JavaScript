# spektral

> 标签: gpu, graphics, postprocessing, react, react19, shader, svelte, svelte5, webgpu, wgsl

## 简介

Framework-agnostic WebGPU runtime for fullscreen WGSL shaders with explicit Svelte, React, and Vue adapter entrypoints.
