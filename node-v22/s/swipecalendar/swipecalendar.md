# swipecalendar

> 标签: Calendar, FullCalendar, HTML5, JavaScript, Slide, Swipe, SwipeCalendar

## 简介

SwipeCalendar is a third-party JavaScript plugin that provides swiping/sliding capabilities to FullCalendar.
