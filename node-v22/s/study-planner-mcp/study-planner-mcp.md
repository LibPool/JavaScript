# study-planner-mcp

> 标签: assignment milestones, exam schedule, exam study plan, mcp, mcp server, model context protocol, offline, pomodoro, revision planner, spaced repetition, student, student planner, study planner, study planner mcp, study schedule, study timetable, study-planner-mcp

## 简介

Study planner MCP server. Give it your exam dates and daily study hours and it builds an exam schedule, a study timetable with spaced repetition review dates, pomodoro blocks and assignment milestones. Runs offline, no account.
