> 标签: data, data channel, data channel stream, data channels, p2p, peer, peer connection, peer-to-peer, signaling server, simple-peer, socket server, stream, video, voice, webrtc, webrtc stream

## 简介

A wrapper for simple-peer that includes a socket.io signaling server client. To be used in the browser with simple-peer-server.
