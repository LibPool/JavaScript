# signoz-ts-bun-sdk

> 标签: bun, hoyasumii, observability, openapi, opentelemetry, sdk, signoz, typescript

## 简介

SDK TypeScript da API REST do SigNoz v0.142.1 (241 operações tipadas), autenticado com os tokens da sessão do navegador (AUTH_TOKEN/REFRESH_AUTH_TOKEN), com rotação automática da sessão. Não oficial.
