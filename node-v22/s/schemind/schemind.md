# schemind

> 标签: array, index, indexed keys, messagepack, msgpack, packed, schema, serialization

## 简介

Read and write to messages serialized as arrays (indexed keys) by defining a schema, 
enabling smaller message size when using protocols such as msgpack or JSON.
