# social-preview-cli

> 标签: cli, developer-tools, github-banner, og-image, png, social-card, social-preview, svg, twitter-card

## 简介

High-performance CLI and Node.js library to generate developer-first social preview cards (OG Images) for GitHub, X, LinkedIn, and blogs. Pure SVG & Rust-backed PNG render.
