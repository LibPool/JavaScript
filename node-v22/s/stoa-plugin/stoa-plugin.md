# stoa-plugin

> 标签: architecture, claude-code, cli, cloudflare, diagram, supabase, visualizer

## 简介

Open a localhost GUI to visualize your app's architecture from architecture.md — built for working alongside Claude Code. Optional verification against live Cloudflare and Supabase resources.
