# slnmap-ts

> 标签: code-graph, slnmap, static-analysis, typescript

## 简介

Frontend HTTP call-site extractor for slnmap. Walks a TypeScript/React project with the TS Compiler API and emits a JSON artifact of resolved and unresolved call sites for slnmap's `analyze-ts` verb to ingest.
