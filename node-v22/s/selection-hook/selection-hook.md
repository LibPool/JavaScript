> 标签: accessibility, clipboard, cross-platform, electron, global-keyboard, global-mouse, input-events, input-hook, keyboard, keyboard-hook, linux, macos, mouse, mouse-hook, napi, native, node, node-addon, selected-text, selection, text-selection, ui-automation, wayland, windows, x11

## 简介

The first open-source library for cross-application text selection monitoring and global input event hooks. Works with Node.js and Electron.
