# stylelint-theme-variable-plugins

> 标签: JavaScript

## 简介

stylelint检测项目中样式文件变量使用情况插件,项目中如果设置了通用变量，可以通过它来实现项目中样式的文件对变量的实施情况，检测到变量中的值会提醒开发者应该调用变量，而非直接使用值
