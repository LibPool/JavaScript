# select-csv

> 标签: chunk, comma, csv, data, delimited, fast-csv, file, filereader, large-file, line, parse, parser, parsing, pipe, stream, tab, text

## 简介

A high-performance, memory-efficient CSV parser for Node.js. Supports streaming large files via chunks and row offsets with zero dependencies.
