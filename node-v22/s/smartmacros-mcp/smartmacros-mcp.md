# smartmacros-mcp

> 标签: browser-automation, chrome-extension, claude, cursor, macro, mcp, model-context-protocol

## 简介

MCP bridge for the SmartMacros Chrome extension: lets Claude, Cursor and other MCP clients create, run and repair browser macros on your own machine.
