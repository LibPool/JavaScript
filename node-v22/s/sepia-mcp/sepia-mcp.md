# sepia-mcp

> 标签: knowledge-graph, mcp, memory, sepia

## 简介

Self-contained MCP server for Sepia — a personal knowledge-graph memory server. Talks to the Sepia REST API (SEPIA_URL + SEPIA_API_KEY); stdio or HTTP transport.
