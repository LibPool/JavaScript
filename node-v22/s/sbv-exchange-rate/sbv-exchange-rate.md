# sbv-exchange-rate

> 标签: api, bank, central-bank, currency, exchange-rate, exchange-rates, forex, fx, of, official-rates, sbv, state, typescript, vietnam, vnd

## 简介

Official State Bank of Vietnam (Vietnam) daily exchange rates — 28 currencies vs VND, history since 2009. Zero-dependency Node.js/TypeScript client.
