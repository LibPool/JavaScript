# safe-stream-archiver

> 标签: archive, backpressure, cloud, content-length, data-transfer, s3, stream, streaming, tar, zip

## 简介

Archive Readable streams whose byte length is unknown or unreliable (e.g. remote cloud assets) into TAR or ZIP, without crashing — bounded memory, disk-spooling for TAR, streaming for ZIP.
