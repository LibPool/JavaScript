# saive-client

> 标签: anthropic, carbon, gemini, llm, observability, openai, sustainability, tokens

## 简介

Zero-friction LLM footprint reporting for saive (saive.tech) — patches the OpenAI, Anthropic and Google GenAI clients to report usage asynchronously. Never sends prompt or completion content.
