# specship

> 标签: agent, agents, claude, cline, codex, copilot, cursor, gemini, roo, scaffold, skills, windsurf, workflow

## 简介

Install a staged spec→plan→coding→review agent workflow (skills + per-agent config) into any project. Works with Claude Code, Codex, Gemini CLI, Cursor, Antigravity, Copilot, Windsurf, Cline, Roo Code, and AGENTS.md-compatible agents.
