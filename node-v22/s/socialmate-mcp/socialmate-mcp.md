# socialmate-mcp

> 标签: ai, baileys, claude, mcp, modelcontextprotocol, socialmate, whatsapp

## 简介

Model Context Protocol server for SocialMate — let Claude Desktop, Cursor and any MCP client control WhatsApp through your self-hosted SocialMate server.
