# socket.io-2-nats

> 标签: JavaScript

## 简介

fixed socket.io-nats adapter to work with socket.io > v2.0 by providing Adapter.addAll-Function. This module is based on work by Edgar Ribeiro, https://github.com/efmr/socket.io-nats
