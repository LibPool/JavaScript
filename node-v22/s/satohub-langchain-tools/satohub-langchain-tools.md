# satohub-langchain-tools

> 标签: crypto, langchain, langchainjs, onchain-agents, satohub, tools, web3

## 简介

LangChain.js tools for Sato Hub: search the scored onchain-agent index, run a Preflight check before installing or trading, get a swap-venue recommendation with the fee disclosed, and turn a goal into a build plan of real listings. Read-only and non-custo
