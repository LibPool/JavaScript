# stellar-transfer-server-validator

> 标签: JavaScript

## 简介

This project is intended to run an automated test suite on a Stellar anchor's SEP24 transfer server. It can be used as a javascript library or command line utility. It will interact with your anchor server and validate that everything is working properly,
