# sbercoinjs-lib

> 标签: bitcoin, sber, sbercoin, sbercoin.com, sbercoinjs, smart contract

## 简介

An extend lib for bitcoinjs-lib, it supports a new network of sbercoin-mainnet, and it can generate contract creating and sending transactions
