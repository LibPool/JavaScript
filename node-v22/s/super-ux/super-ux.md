# super-ux

> 标签: audit, claude-code, cursor, scenario-driven, scenarios, ui, user-flows, ux

## 简介

Scenario-driven UI development for AI agents (Claude Code, Cursor, 70+ agents): a versioned design chain in docs/ux/, a scenario-first hard rule, a deterministic drift linter, and evidence-backed UX audits. This package is the installer CLI.
