# sunmoontimes

> 标签: moon, moonrise, moonset, sun, sunrise, sunset, times, twilight

## 简介

A JavaScript library to calculate sunrise, sunset, moonrise, moonset and twilight times based on latitude, longitude, date, and timezone.
