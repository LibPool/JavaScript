# spm-hydrogen-integration

> 标签: JavaScript

## 简介

`spm-hydrogen-integration` est un package permettant d'intégrer le script **ShopiMind** dans un thème **Hydrogen** d'une boutique Shopify. Cette intégration est essentielle pour activer les fonctionnalités avancées de marketing proposées par ShopiMind.
