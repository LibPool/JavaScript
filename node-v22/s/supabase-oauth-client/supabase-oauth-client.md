# supabase-oauth-client

> 标签: auth, authorization-code, oauth, oauth2, oauth2.1, pkce, supabase

## 简介

Zero-dependency OAuth 2.1 client (authorization code + PKCE) for Supabase Auth's OAuth server, for same-device redirects or codes delivered out of band
