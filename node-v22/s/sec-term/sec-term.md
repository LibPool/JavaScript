# sec-term

> 标签: aws, cli, developer-tools, devops, dotenv, env-diff, parameter-store, secrets, secrets-manager, ssm

## 简介

High-fidelity terminal secrets manager for AWS SSM Parameter Store & local zero-cloud encrypted vaults supporting instant .env export, multi-target drift diffing, and zero-disk in-memory secret injection.
