# sliceui-skill

> 标签: agent, ai, angular, claude, frontend, image-to-code, screenshot-to-code, skill

## 简介

Agent skill + CLI: convert UI designs (Figma XML or screenshots) into idiomatic component code that matches your project's framework and UI libraries (Angular 13, React, Vue, Svelte, Next.js, Tailwind, Bootstrap, HTML).
