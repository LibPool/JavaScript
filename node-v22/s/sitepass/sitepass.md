# sitepass

> 标签: astro, auth, bun, cloudflare-pages, deployment-protection, edge, express, gate, hono, middleware, netlify, next, password, password-protection, staging, sveltekit

## 简介

Put one shared password in front of any web app. No database, no accounts, no auth provider.
