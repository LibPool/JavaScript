# sri-and-commoncdn-webpack-plugin

> 标签: JavaScript

## 简介

webpack 插件，用于替换部分或者所有文件的publicPath，note: 如果替换所有publicPath，建议使用webpack本身的配置 可以为所有生成的静态文件  添加 attributes 内部为兼容 ***webpack-subresource-integrity*** 直接提供了sri选项
