# shimguard-cli

> 标签: agent-native, cli, devsecops, github, issue-tracker, pull-request, security, supply-chain, verification, vulnerability-scanner

## 简介

Verify that a GitHub issue closed as "fixed" actually has a merged fix. Catches security issues and bugs marked fixed whose PR was never merged, with structured JSON output for CI and AI agents.
