# streamdown-angular

> 标签: ai, angular, chat, katex, llm, markdown, mermaid, rehype, remark, shiki, streamdown, streaming

## 简介

Angular port of Vercel's Streamdown — stream-safe Markdown rendering for AI chat UIs (signals, standalone, OnPush). Code highlighting (Shiki), tables, Mermaid and KaTeX as optional plugins.
