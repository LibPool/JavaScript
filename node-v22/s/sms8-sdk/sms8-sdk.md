## 简介

SMS8 SDK — send SMS, MMS, and OTPs from any Node/browser/Deno/Bun runtime through your own Android phone. Twilio alternative for developers. Includes CLI (sms8), React hooks + <OtpInput> component (sms8/react), and an MCP stdio bridge (sms8 mcp). No per-m
