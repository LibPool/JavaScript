# signalk-1wire-temperature

> 标签: 1-wire, ds18b20, onewire, signalk, signalk-category-hardware, signalk-node-server-plugin, temperature

## 简介

Signal K plugin that reads 1-Wire temperature sensors, with a configurable Signal K path and calibration offset per sensor
