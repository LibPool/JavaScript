# subscription-engine

> 标签: billing, dunning, invoice, proration, recurring, recurring-billing, saas, state-machine, stripe-alternative, subscription, subscriptions, typescript

## 简介

The subscription layer a payment provider does not give you: a pure state machine over trials, renewals, dunning, proration and invoices, with no database and no provider.
