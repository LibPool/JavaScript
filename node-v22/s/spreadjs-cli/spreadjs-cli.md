## 简介

这是一个基于 SpreadJS 纯前端表格控件进行快速开发的原型脚手架工具，提供： - 快速建立基于 SpreadJS 的在线类 Excel 应用初始 Demo - 通过模板选择 Vue2/Vue3/React 多种原型版本 - 可选择是否在原型中创建带有表格编辑器插件（Designer) 的 Demo
