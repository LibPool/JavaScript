# safeship

> 标签: cve, express, nextjs, sast, scanner, secrets, security, semgrep, vibecoding

## 简介

Security scanner for vibe-coded projects. Finds leaked credentials, known-vulnerable dependencies, insecure configuration, and injection bugs in AI-generated Python and JavaScript.
