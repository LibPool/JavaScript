# styletyper

> 标签: css-modules, declaration-map, dts, lightningcss, sass, sass-embedded, scss, typescript

## 简介

TypeScript declaration generator for SCSS/CSS modules on a native-speed toolchain (Dart Sass via sass-embedded + Lightning CSS in Rust). Programmatic API and CLI; ESM output with declaration source maps. The Vite plugin ships separately as vite-plugin-sty
