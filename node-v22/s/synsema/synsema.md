# synsema

> 标签: agents, cli, language, llm, synsema

## 简介

Synsema — the programming language for AI agents. This package installs the native `synsema` binary (Linux, macOS, Windows) from npm: `npm i -g synsema` or `npx synsema run app.syn`.
