# symbl-opus-encdec

> 标签: audio, decoder, encoder, ogg, opus, resampler, streamer, wasm, webassembly

## 简介

This is a fork of https://github.com/mmig/opus-encdec with additional enhancements to stream live Opus data. This library is meant for encoding and decoding OPUS audio.
