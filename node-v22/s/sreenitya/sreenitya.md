# sreenitya

> 标签: agent, api-client, cli, portfolio, sreenitya, sreenitya-thatikunta

## 简介

Command line client for the Sreenitya Thatikunta portfolio API (sreenitya.in) — profile, skills, experience and projects as text or JSON.
