# safe-handlebars

> 标签: JavaScript

## 简介

A fork of the `@kbn/handlebars` custom version of the handlebars package which, to improve security, does not use `eval` or `new Function`. This means that templates can't be compiled into JavaScript functions in advance and hence, rendering the templates
