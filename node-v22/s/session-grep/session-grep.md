# session-grep

> 标签: agent-tools, claude-code, codex, grep, promptfoo, sessions, skill, transcripts

## 简介

Grep AI coding-session transcripts (Claude Code, Codex) with bounded message context — built for agents. Includes rarity-ranked multi-word search, session overviews, sampled spines, and a built-in self-test.
