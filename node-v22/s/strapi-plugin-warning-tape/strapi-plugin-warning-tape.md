# strapi-plugin-warning-tape

> 标签: admin, banner, environment, marquee, plugin, strapi, strapi-plugin, warning

## 简介

A police-tape banner across the top of the Strapi 5 admin with a scrolling message, so nobody mistakes preprod for production. Colour, text, speed and position are configurable; the environment name is detected server-side.
