# steam-app-id-finder

> 标签: app-id, appid, epic-games, game-library, game-names, gog, steam, steam-api, steam-app-id

## 简介

CLI to find Steam App IDs from game names or a Steam account, and export owned-game lists from GOG and Epic Games accounts.
