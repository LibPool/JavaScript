# sidemux

> 标签: ai-agents, claude, claude-code, codex, mcp, mcp-server, opencode, terminal, tmux

## 简介

MCP server that lets AI coding agents delegate commands to tmux sidecar panes — run, wait, and read output token-efficiently.
