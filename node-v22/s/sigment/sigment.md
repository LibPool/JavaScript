# sigment

> 标签: batch-rendering, dom-performance, fast-dom, javascript, lightweight-framework, no-vdom, reactive, sigment, signals, state-management, ui-engine, vanilla

## 简介

A lightweight reactive JavaScript framework built with signals and vanilla JS — no virtual DOM, no JSX, no transpilation.
