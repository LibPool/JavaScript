# spatial-harness

> 标签: geojson, geopackage, gis, gistudio, mapping, openlayers, qgis, shapefile, spatial-analysis, webgis

## 简介

SpatialHarness —— 纯本地 WebGIS 工作台：引擎抽象层 + OpenLayers v1，File System Access API 直读本地磁盘，QGIS 风格现代化组件化 UI
