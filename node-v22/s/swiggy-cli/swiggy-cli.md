# swiggy-cli

> 标签: agent, agent-plugins, ai, anthropic, claude, cli, dineout, food, instamart, mcp, model-context-protocol, payments, skills, skills.sh, swiggy, upi

## 简介

Human- and agent-friendly CLI for the official Swiggy MCP servers (Food, Instamart, Dineout): 51 tools, UPI/Swiggy Money payments, stable JSON envelope, bundled agent skills and plugin manifests.
