# stable-webrtc

> 标签: browser, data-channels, datachannel, mediastream, nodejs, p2p, peer, peer-connection, peer-to-peer, sctp, signaling, simple-peer, stream, video, voice, webrtc, webrtc stream, wrtc

## 简介

A production-grade WebRTC library for Node.js & Browsers. Handles glare, renegotiation conflicts, out-of-order signaling, NAT quirks, and bloated SDPs so you can build reliable real-time apps faster.
