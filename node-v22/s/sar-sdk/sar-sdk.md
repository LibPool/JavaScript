# sar-sdk

> 标签: agent-commerce, attestation, ed25519, receipt, sar, settlement-attestation-receipt, verification

## 简介

TypeScript SDK for SAR (Settlement Attestation Receipt) — sign, verify, and resolve portable execution proofs for agent commerce. Supports v0.1 and v0.2 (counterparty).
