# survey-vue3-ui

> 标签: Bootstrap, JavaScript, Library, Survey, knockout

## 简介

survey.js is a JavaScript Survey Library. It is a modern way to add a survey to your website. It uses JSON for survey metadata and results.

## 官网

- 官网：https://surveyjs.io/
- 源码仓库：git+https://github.com/surveyjs/surveyjs.git
- npm 页面：https://www.npmjs.com/package/survey-vue3-ui
