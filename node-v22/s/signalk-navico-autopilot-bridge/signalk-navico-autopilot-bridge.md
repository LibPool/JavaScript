# signalk-navico-autopilot-bridge

> 标签: ac12, ac42, autopilot, bng, navico, nmea2000, signalk-category-hardware, signalk-category-nmea-2000, signalk-node-server-plugin, signalk-webapp, simrad

## 简介

Emulate a Simrad AC12/AC42 so a Navico MFD (B&G/Simrad/Lowrance) drives any SignalK Autopilot V2 pilot (e.g. a Raymarine EV-200) from its own autopilot control view. Beta — see README for verified behaviour and known limitations.
