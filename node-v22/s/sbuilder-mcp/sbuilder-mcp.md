# sbuilder-mcp

> 标签: ai-agent, mcp, model-context-protocol, page-builder, sbuilder, store-builder, website-builder

## 简介

MCP server that designs and operates a Store Builder site — pages, data, theme and publish — through the platform's own API and live-edit protocol.
