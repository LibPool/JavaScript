# scraping-comments

> 标签: JavaScript

## 简介

O [scraping](https://pt.wikipedia.org/wiki/Scraping) é uma tecnica de extrair dados de uma página web. Neste projeto iremos fazer uma busca no instagram e extrair os comentaários da página e verificar se o usurio realizou a tarefa de comentar.
