# spatium-engine

> 标签: floor-plan, geojson, indoor-map, indoor-navigation, pathfinding, wayfinding

## 简介

TypeScript toolkit for building, viewing, and embedding indoor maps — buildings, floors, rooms, walls, doors, POIs, and navigation/routing graphs.
