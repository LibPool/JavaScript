# s3-quill-image-upload

> 标签: S3, image, quill, quilljs, upload

## 简介

A module for Quill rich text editor to upload images to be selected from toolbar editor. Forked from https://github.com/fxmontigny/quill-image-upload. This version of the module directly integrates with S3. Still Experimental.
