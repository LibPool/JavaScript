# semantic-relevance

> 标签: aggregator, content-curation, embeddings, feed, filter, github, hackernews, lobsters, news, novelty-detection, reddit, rss, semantic-search, signal, transformers

## 简介

Semantic signal detection for content feeds. Filter high-volume feeds to surface what matters using local embeddings, decay-based novelty tracking, and explainable signal classification.
