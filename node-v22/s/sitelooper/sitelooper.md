# sitelooper

> 标签: browser-automation, cli, deterministic-replay, e2e-testing, llm-agent, playwright, record-replay

## 简介

Sitelooper: an agent-in-the-loop Playwright CLI that learns a flow once, then replays it with no model in the loop — zero-LLM, deterministic, verified.
