# socket-client-proxy

> 标签: JavaScript

## 简介

- socket 继承自 nodejs 的 net 模块，拥有和 new net.Socket() 完全一致的 API。 - 支持 socks5 代理，支持用户名密码 - 支持 http 代理，支持用户名密码（要求 http 代理支持 CONNECT 方法）
