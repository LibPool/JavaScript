# squirrelswap-mcp

> 标签: agent, aggregator, defi, dex, mcp, model-context-protocol, pulsechain, squirrelswap

## 简介

MCP server for SquirrelSwap — best-route DEX aggregation, fee-on-transfer tax detection, and prepared (signable) transactions on PulseChain. Holds no keys: pair with any wallet MCP for signing.
