# sharedbrain

> 标签: anthropic, claude, claude-code, claude-desktop, mcp, memory, skill

## 简介

A shared memory brain for Claude across Claude Code, Claude Desktop, and any MCP-capable surface. One SQLite store, four tools, zero config.
