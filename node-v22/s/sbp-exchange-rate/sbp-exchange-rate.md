# sbp-exchange-rate

> 标签: api, bank, central-bank, currency, exchange-rate, exchange-rates, forex, fx, of, official-rates, pakistan, pkr, sbp, state, typescript

## 简介

Official State Bank of Pakistan (Pakistan) daily exchange rates — 35 currencies vs PKR, history since 2017. Zero-dependency Node.js/TypeScript client.
