# skills-agents

> 标签: agent-skills, agents, claude-code, codex, cursor, skills, subagents

## 简介

Install agent skills (SKILL.md) and subagents (AGENT.md) from any well-known source with one command — skills for Claude Code, Codex, and Cursor via the skills CLI; subagents downloaded natively.
