# safeseed

> 标签: ci, data-minimization, fixtures, gdpr, non-production, pii, privacy, synthetic-data, test-data

## 简介

Generate, record, verify, and scan low-fidelity test data from a versioned catalog of reserved, test-designated, and deliberately fake values. No production dataset required, zero runtime dependencies, MIT.
