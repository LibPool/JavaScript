# skiptingar

> 标签: hyphenation, icelandic, orðskipting, typesetting, typography, íslenska

## 简介

Icelandic text, set well: hyphenation from the 2020 letter patterns, better breaks and Icelandic locale details, all made on the server as soft hyphens and no-break spaces.
