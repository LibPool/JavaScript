# standup-mcp

> 标签: ai, claude, daily-standup, developer-tools, github, jira, linear, mcp, model-context-protocol, scrum, slack, standup

## 简介

Generate your daily standup from real activity across GitHub, Jira, Linear, and Slack. An MCP server that answers "what should I say at standup today?" from yesterday's commits, PRs, ticket moves, and threads. Local, read-only, model-agnostic.
