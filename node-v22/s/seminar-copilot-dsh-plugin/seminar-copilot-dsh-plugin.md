# seminar-copilot-dsh-plugin

> 标签: asr, dashscope, deepseek-harness, dsh-plugin, meeting-recorder, seminar-copilot, whisper

## 简介

DeepSeek Harness Web GUI plugin for Seminar Copilot: one-click local seminar recording, ASR backend settings (local MLX Whisper / Aliyun Bailian), auto-start of the dev stack.
