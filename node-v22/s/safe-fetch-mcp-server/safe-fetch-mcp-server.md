# safe-fetch-mcp-server

> 标签: agent, fetch, mcp, model-context-protocol, security, ssrf

## 简介

A secure-by-default MCP server for fetching web content: SSRF, DNS-rebinding, and redirect-to-internal protection with post-resolution IP validation.
