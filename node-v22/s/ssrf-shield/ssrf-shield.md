# ssrf-shield

> 标签: aws-metadata, cloud-security, dns-rebinding, express, fastify, firewall, hono, ip-validation, koa, middleware, node, owasp, pentest, protection, security, server-side-request-forgery, ssrf, ssrf-protection, typescript, web-security

## 简介

Block SSRF attacks in one line. Production-ready middleware for Express/Fastify/Hono/Koa. Covers IPv4, IPv6, DNS rebinding, cloud metadata, octal/hex IPs, gopher, and 200+ bypass techniques.
