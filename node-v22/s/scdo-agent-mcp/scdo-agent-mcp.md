# scdo-agent-mcp

> 标签: agent, base, mcp, scdo, streamable-http, usdc, wallet, x402

## 简介

MCP server for SCDO: public Agent Ledger and x402 tools over stdio or Streamable HTTP, plus a local per-agent Base USDC wallet.

- 官网：https://scdo.com.au/linux-agent/
