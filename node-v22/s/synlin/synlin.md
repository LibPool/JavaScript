# synlin

> 标签: JavaScript

## 简介

CLI for managing a personal library of AI coding-agent config items (skills, agents, commands, rules, templates) and installing them into projects for Claude Code, Codex, Cursor, and OpenCode

## 官网

- npm 页面：https://www.npmjs.com/package/synlin

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- npm 安装：`npm install synlin`
- npm registry：https://registry.npmjs.org/synlin
- Node 要求：>=20
