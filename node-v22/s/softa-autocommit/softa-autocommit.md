# softa-autocommit

> 标签: JavaScript

## 简介

The purpose of this CLI is to facilitate the commits we make in softaliza projects as we use the `BIR-123` or `GEN-123` pattern to create branches and automated commits with jira tasks for each project. And just install the CLI and run it with the command
