# strapi-plugin-component-usage

> 标签: admin-ui, audit, cleanup, component, component-dependencies, component-management, component-tracker, component-usage, content-management, content-type, dependency-graph, dependency-tracking, developer-tools, refactoring, strapi, strapi-admin, strapi-plugin, strapi-v4, unused-components

## 简介

Strapi v4 plugin to track component usage, visualize dependencies, find unused components, and safely clean up content types. Includes dependency graph, usage analytics, and validation.
