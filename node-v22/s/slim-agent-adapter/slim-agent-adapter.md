# slim-agent-adapter

> 标签: agent, llm, lmstudio, local, mcp, ollama, openai, proxy, qa, test-automation, tool-filtering

## 简介

Zero-dependency OpenAI-compatible proxy for local LLMs: prompt-driven tool filtering, tool-schema slimming, Qwen3 /no_think, and a live dashboard — so small local models stay fast in agent mode on modest hardware.
