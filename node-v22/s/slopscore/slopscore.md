# slopscore

> 标签: ai-generated-code, ai-slop, claude-code, code-quality, code-review, cursor, linter, security, slop, static-analysis, vibe-coding

## 简介

Scan your codebase for AI slop, get a Slop Score, ship clean. Zero runtime dependencies. 190 detectors (security, robustness, performance, code quality, design tells) + a 286-pattern Anti-Slop Protocol for AI coding agents. Optional --ast mode for real co
