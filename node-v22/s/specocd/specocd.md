# specocd

> 标签: ai-agents, claude-code, cli, codex, copilot, cursor, jira, multi-agent, sdd, spec-driven-development

## 简介

Spec-driven development with multi-agent coordination: task claims, conflict detection and a shared decision log, so multiple AI coding agents can work the same change safely.
