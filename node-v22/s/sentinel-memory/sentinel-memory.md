# sentinel-memory

> 标签: agent, ai, cache, chatbot, context-window, embedded, eviction, llm, memory, token-budget, ttl, zero-dependency

## 简介

Embedded, zero-infra, importance-aware memory for chatbots and agents: bounded store, TTL, compaction that forgets the least important first, and token-budgeted context windows
