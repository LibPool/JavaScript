# surprise-crud

> 标签: Crud, Express, Javascript, MongoDB, Mongoose, Nodejs

## 简介

Simple Express Mongoose Crud - This npm allow You to use basic crud for Express with Mongoose like: GET, GETBYID, POST, PUT, DELETE
