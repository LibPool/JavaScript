# sautocomplete-suggestion

> 标签: angular, autocomplete, dependency-free, grouped-suggestions, lightweight, react, search-input, suggestion, vanilla-js, vue

## 简介

A lightweight, dependency-free grouped autocomplete suggestion input (Vanilla TS). Sync + async dataSource, virtualized, sanitized, form-ready. Framework-agnostic with React, Vue and Angular wrappers.
