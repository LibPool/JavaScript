# svg-to-react-native

> 标签: JavaScript

## 简介

Just a small wrapper around https://react-svgr.com/ for converting SVGs to their React Native SVG version through your clipboard.

## 官网

- npm 页面：https://www.npmjs.com/package/svg-to-react-native
