# string-easy-assistant

> 标签: JavaScript

## 简介

This is a lightweight Node.js utility package designed for common string manipulations, such as converting to uppercase, lowercase, reversing, trimming, and capitalizing. Ideal for quick and straightforward text processing tasks.
