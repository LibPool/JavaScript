# shared-table-filters

> 标签: JavaScript

## 简介

A ready-to-use **Angular table library** with support for **filtering, pagination, and multiple column types** (text, boolean, select, date, radio).   Supports both **Gregorian and Jalali (Persian) calendars** ✨
