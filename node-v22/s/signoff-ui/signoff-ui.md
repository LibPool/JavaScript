# signoff-ui

> 标签: accessibility, acp, ag-ui, agent-client-protocol, agent-ui, ai-agents, ai-elements, ai-sdk, approval, approval-rules, assistant-ui, claude-code, code-review, codex, coding-agent, diff, diff-review, human-in-the-loop, hunk, langgraph, nextjs, patch, permissions, react, shadcn, tailwindcss, tool-approval, tool-calling

## 简介

Review what your agent changed and approve what it may do: React components for multi-file diff review and tool approvals that return a result your agent acts on, for AI SDK 6 & 7, AG-UI and ACP agents, inside assistant-ui, AI Elements or your own chat.
