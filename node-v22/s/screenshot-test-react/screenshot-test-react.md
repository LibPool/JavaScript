> 标签: react-snapshot-test, react-snapshot-testing, react-test, screenshot-test, screenshot-test-react, screenshot-testing, screenshot-testing-react, snapshot-test, snapshot-testing

## 简介

The most straightforward UI testing library for react. Just wrap your UI component/widget inside `useScreenshotTest` and render it on your browser.
