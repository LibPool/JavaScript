# serverless-llrt-analyzer

> 标签: aws-lambda, cold-start, llrt, provided.al2023, serverless, serverless-plugin

## 简介

Serverless Framework plugin to flip Lambda functions to AWS LLRT (llrt: true) for ~10x faster cold starts, with a deploy-time compatibility guard powered by llrt-analyzer.
