# safebrowse-agent

> 标签: action-classifier, ai-agents, approval-gate, browser-agents, browser-use, consent, guardrails, human-in-the-loop, prompt-injection, safebrowse, safety

## 简介

A hard floor for browser agents: classify every click/type by consequence — payments, deletions and account-security actions can never be auto-approved, no matter the mode.
