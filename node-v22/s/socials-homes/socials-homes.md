# socials-homes

> 标签: ai-agents, apartments, api, cli, housing, listings, openapi, rent, rental, sdk, socials-homes

## 简介

Official JavaScript SDK and CLI for the Socials Homes API: covered cities, plans and prices, and live rental listing counts per city and budget. Read-only, no API key.
