# snap-carousel.js

> 标签: carousel, custom-elements, javascript, lightweight, modular, no-dependencies, responsive, scroll-snap, slider, typescript, vanilla, web-components

## 简介

A lightweight vanilla JavaScript carousel library built with modern web technologies. Based on custom elements, scroll-snap, and scroll-padding.
