# shopify-admin-client-ts

> 标签: admin-api, graphql, oauth, shopify, shopify-api, typescript

## 简介

A small, framework-agnostic TypeScript client for Shopify GraphQL Admin API with OAuth, rotating offline tokens, HMAC verification, throttling and retries.
