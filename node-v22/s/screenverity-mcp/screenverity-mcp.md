# screenverity-mcp

> 标签: agent-tools, compliance, credentialing, debarment, exclusion-screening, healthcare, mcp, modelcontextprotocol, ofac, oig-leie, sam-exclusions, sanctions

## 简介

MCP server for ScreenVerity — free U.S. exclusion, debarment and licence screening with Ed25519 receipts. One call replaces a portal scrape.
