# shipyard-inference

> 标签: agent, anthropic, inference, llm, openai, payments, proxy, router, shipyard, solana, usepod, x402

## 简介

The always-available inference layer for the Shipyard stack: streaming, cost-aware routing, x402-on-Solana payments, and a drop-in OpenAI-compatible gateway over Anthropic, OpenAI, UsePod, Nous/Hermes, and Venice video.
