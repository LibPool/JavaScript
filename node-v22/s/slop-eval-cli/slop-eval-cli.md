# slop-eval-cli

> 标签: agent-native, ai, anthropic, ci, design, design-review, eval, github-action, llm-judge, quality-gate, slop, ui

## 简介

Scores AI-generated UI for genericness ("slop") using an LLM-judge rubric. Composable RuleSource plugin architecture, --json mode for CI/agent gates, and a documented library API alongside the CLI.
