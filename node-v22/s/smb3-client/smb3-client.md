# smb3-client

> 标签: cifs, fileshare, ms-smb2, ntlm, ntlmv2, samba, smb, smb2, smb3, spnego, windows

## 简介

TypeScript SMB3 client for Node.js. Pure ESM, no native dependencies. fs-like promise API with streaming I/O, directory change notifications, and share enumeration. Speaks MS-SMB2 over TCP/445.
