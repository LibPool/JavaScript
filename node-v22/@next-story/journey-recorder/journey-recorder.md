# @next-story/journey-recorder

> 标签: analytics, dead-click, nextjs, rage-click, user-journey, vercel

## 简介

Lite user-journey recorder for Next.js: navigation path, rage-clicks, dead-clicks and session outcome. No session replay, no DOM recording.
