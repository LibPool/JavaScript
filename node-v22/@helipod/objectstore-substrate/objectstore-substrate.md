# @helipod/objectstore-substrate

> 标签: JavaScript

## 简介

Object-storage substrate for Helipod: the durable commit log and manifests live in an object store (S3-compatible or filesystem), while each node keeps a local SQLite database as a queryable cache — storage/compute separation with no standalone database s
