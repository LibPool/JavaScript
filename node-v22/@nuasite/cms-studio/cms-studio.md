# @nuasite/cms-studio

> 标签: cms, headless, nuasite, standalone, studio

## 简介

Standalone, batteries-included Nua CMS: a single `bunx` process that serves the cms-sidecar /cms/v1 API plus a prebuilt collections admin UI for the project it is launched in.
