## 简介

TeamHub — a self-hosted, project-aware MCP server + CLI for running a multi-agent Claude Code team (Team Lead plans/assigns, Developers code, Testers verify), with skills, a headless agent runner, one-command install/autostart, and a live monitoring dashb
