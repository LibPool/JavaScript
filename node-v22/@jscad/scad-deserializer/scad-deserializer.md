# @jscad/scad-deserializer

> 标签: deserializer, jscad, openjscad, openscad, scad, translator

## 简介

Translates OpenSCAD syntax (http://www.openscad.org/) into OpenJsCAD syntax (http://joostn.github.com/OpenJsCad/).
