# universal-autoloader

> 标签: autoload, cross-platform, directory, fast, filesystem, http, http-server, lightweight, microws, middleware, plugin, proxy-protocol, router

## 简介

Universal plugin, that use the _file system_ scan, to load in a server all routes in a directory.
