# urldn-link-check

> 标签: broken-links, cli, documentation, github-action, https, link-checker, markdown, redirect, url, urldn

## 简介

Scan Markdown and documentation for broken links, redirect chains, insecure HTTP links, and excessively long URLs. Usable as a CLI or a GitHub Action.
