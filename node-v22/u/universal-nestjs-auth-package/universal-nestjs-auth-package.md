# universal-nestjs-auth-package

> 标签: authentication, hybrid-auth, jwt, multi-device, nestjs, oauth, redis, session, typescript, universal

## 简介

A comprehensive authentication package for NestJS applications providing JWT and session-based authentication with hybrid mode support, multi-device sessions, Redis integration, and Google OAuth.
