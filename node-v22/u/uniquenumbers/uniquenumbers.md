# uniquenumbers

> 标签: JavaScript

## 简介

Функция generateUniqueNumbers() создает уникальные числа достаточно вписать значения в таком порядке:  количество уникальных цифр, минимальное значение после максимальное значение. пример:  > let uniqueNums = generateUniqueNumbers(5, 10, 20); console
