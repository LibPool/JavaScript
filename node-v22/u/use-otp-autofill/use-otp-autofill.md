# use-otp-autofill

> 标签: 2fa, autofill, code-verification, hook, otp, otp-input, otp-verification, react, react-hook, sms-otp, two-factor-auth, use-otp, use-otp-autofill, verification, web-otp

## 简介

A lightweight React hook that automatically reads OTP (One-Time Password) codes from SMS using the [Web OTP API](https://web.dev/web-otp/).
