# ux-review-skills

> 标签: agent-skills, claude-code, design-review, interaction-design, product-design, skills, spec, ux

## 简介

Agent skills that bring a designer's eye to software work: review how people move through a product (interaction-flow), shape a feature before it is built (design-reflection), and interview the owner to pin down meaning and intent (clarify-intent).
