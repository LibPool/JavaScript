# uishot-core

> 标签: JavaScript

## 简介

Manifest schema, recipe engine, capture planning, and pixel diff for [uishot](https://github.com/TimCrooker/uishot) — instant, addressable UI screenshots for AI agents. You probably want the `uishot` CLI package.
