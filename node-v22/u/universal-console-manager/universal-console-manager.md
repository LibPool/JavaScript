# universal-console-manager

> 标签: angular, browser, console, debug, development, framework-agnostic, javascript, logging, nextjs, nodejs, performance, production, react, typescript, universal, utilities, vue, zero-dependencies

## 简介

A lightweight, framework-agnostic utility for managing console output with fine-grained control. Easily disable or restore any console method conditionally.
