# uivisor

> 标签: ai, devtools, next, react, tailwind, turbopack, visual-editing, vite-plugin

## 简介

Dev-only visual UI tweaker that turns mouse edits into a precise, breakpoint-aware prompt for your AI coding agent — without touching your source.
