# upload-smith

> 标签: cloudinary upload, express file upload, express s3 upload, file validation middleware, ftp upload, image compression node, multer alternative, multer middleware, node file upload, nodejs file uploader, sftp upload, typescript upload middleware, upload to azure blob, upload to google cloud storage, upload to s3, upload-smith

## 简介

Upload Smith is an Express.js file upload middleware built on top of Multer that supports AWS S3, Azure Blob Storage, Google Cloud Storage (GCS), Cloudinary, FTP, and SFTP.
