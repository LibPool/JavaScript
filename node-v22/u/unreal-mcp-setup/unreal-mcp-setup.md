# unreal-mcp-setup

> 标签: ai, claude, cursor, mcp, model-context-protocol, unreal, unreal-engine

## 简介

One-command setup for Unreal Engine MCP (Model Context Protocol) in any UE 5.8+ project. Enables the required engine plugins in your .uproject and writes MCP client configs (Claude Code, Cursor, VS Code, Gemini, Codex).
