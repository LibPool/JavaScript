# uinix-theme

> 标签: css, design system, spec, theme, ui system, uinix

## 简介

Fully configurable framework-agnostic theme system (spec, theme, renderer, themed styles/keyframes/CSS variables) for building UIs.  Your theme your rules 🤘.
