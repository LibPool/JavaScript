# ui-components-vue

> 标签: JavaScript

## 简介

使用vue create project-name方式创建的项目<br> 项目内容： 主要用于开发vue3私有组件库 <br> 技术栈： vue3 + webpack <br> 自动化：eslint + prettier + commitlint 实现代码检查、代码格式化及commit msg
