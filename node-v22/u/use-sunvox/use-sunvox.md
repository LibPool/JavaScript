# use-sunvox

> 标签: JavaScript

## 简介

This is a custom React hook (`useSunVox`) that makes it possible for React components to interact with the [JavaScript SunVox library](https://warmplace.ru/soft/sunvox/jsplay/).

- 源码仓库：https://github.com/metrasynth/use-sunvox/
