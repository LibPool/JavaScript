# uws-cors

> 标签: JavaScript

## 简介

Plugin for [uWebSockets.js](https://github.com/uNetworking/uWebSockets.js) for Cross Origin Requests (CORS) Inspired by [@elysiajs/cors](https://github.com/elysiajs/elysia-cors).
