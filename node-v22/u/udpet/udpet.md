# udpet

> 标签: JavaScript

## 简介

### Send a packet ```py npx udpet [ip] [port] [data...] ``` Example: ```py npx udpet localhost 80 "Hello, UDP!" #send binary npx udpet localhost 80 "\FF\2E\10" ```
