> 标签: ai, anthropic, bedrock, cost, flux, gemini, grok, llm, models.dev, openai, runway, sora, tokens, typescript, validation, veo, vertex, zod

## 简介

Validation layer for LLM API calls: catalog-aware, zod-powered request validation and response sanity checks for every provider — bring your own SDK or fetch.
