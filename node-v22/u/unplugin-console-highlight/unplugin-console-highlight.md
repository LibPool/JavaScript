# unplugin-console-highlight

> 标签: console, debug, highlight, logger, plugin, rolldown, turbo-console, unplugin, vite, webpack

## 简介

An unplugin console transformer with turbo-style prefix/suffix labels and runtime value syntax highlighting that adapts to browser, terminal and plain environments
