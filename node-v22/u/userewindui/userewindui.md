# userewindui

> 标签: ai-agent, before-after, changelog, claude-code, copilot, cursor, devtools, dom-observer, mutation, overlays, react, rewind, snapshots, timeline, undo, visual-diff

## 简介

Visual changelog for AI agent edits. Tracks every DOM mutation. Visual overlays on changed elements, DOM snapshots, smart commit labels, timeline scrubber, before/after diffs, accept/reject with undo, annotations, session persistence, impact scoring. Git
