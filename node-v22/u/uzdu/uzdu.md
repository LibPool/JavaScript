# uzdu

> 标签: aws, azure, blob, download, nexus, raw, s3, unzip, upload, zip

## 简介

UZDU - universal zipper, downloader and uploader. Move files to/from zip, clouds (AWS, Azure), to HTTP PUT (e.g. Nexus) and to SSH
