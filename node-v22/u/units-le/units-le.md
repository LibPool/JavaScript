# units-le

> 标签: audit, bytes, cli, config, duration, letools, nolindnaidoo, quantities, units, units-le

## 简介

Find every quantity in a codebase, a number welded to a unit: durations, byte sizes, percentages and frequencies, each with its value in one base unit. Refuses what it cannot read unambiguously.
