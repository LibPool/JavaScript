# unflake

> 标签: async, concurrency, deadlock, deterministic, fault-injection, flaky, property-testing, race-condition, simulation, testing

## 简介

Deterministic simulation testing for TypeScript. Find async races, deadlocks and lost retries, reproduce them from a seed, and exhaustively prove small tests correct.
