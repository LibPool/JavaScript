# umpl_compiler

> 标签: JavaScript

## 简介

This project enable powerful code preprocessing for any languages simply by adding a set a tags. UMPL is here to **strongly optimize program**, **avoid repeating code**, and even **create self-programming software**. The syntax is similar to PHP and ASP.N
