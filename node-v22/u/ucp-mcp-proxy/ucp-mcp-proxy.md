# ucp-mcp-proxy

> 标签: ai-agent, claude, cline, connector, mcp, model-context-protocol, proxy, ucp, universal-commerce-protocol, woocommerce, wordpress

## 简介

EXPERIMENTAL: Connect AI Agents (Claude Desktop, Cline) to your WooCommerce store via Universal Commerce Protocol (UCP) and Model Context Protocol (MCP). This proxy bridges local stdio MCP clients to remote HTTP UCP endpoints.
