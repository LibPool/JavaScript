# upn-qr-mcp

> 标签: ai, claude, iban, mcp, model-context-protocol, payment-order, qr-code, slovenia, upn, upn-qr

## 简介

Model Context Protocol (MCP) server for Slovenian UPN payment orders — let Claude and other AI assistants read, validate and generate UPN QR codes.
