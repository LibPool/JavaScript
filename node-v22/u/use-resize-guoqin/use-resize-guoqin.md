# use-resize-guoqin

> 标签: JavaScript

## 简介

实现一个基于vue的依赖包，并发布到npm上 需实现支持一个函数同时支持hook 和 自定义指令 去监听dom宽高的变化 pnpm init tsc --init 新建vite.config.ts 新建src/index.ts 新建index.d.ts pnpm i vue -D // 项目必定是基于vue的，该依赖安装依赖时vue放到devDependencies时就可以了，所以要加-D pnpm i vite -D  实现src/index.ts中代码 配置vite.config.
