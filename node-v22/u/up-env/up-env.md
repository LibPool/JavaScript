# up-env

> 标签: apex, aws, env, environmental variables, parameter store, secrets, ssm, up

## 简介

A super simple cli utility for Apex [up](https://up.docs.apex.sh/) that loads environmental variables from AWS SSM (parameter store) into up.json.
