# uriobject

> 标签: domain, host, parts, port, protocol, url

## 简介

gets you the scheme (http/ftp...) userinfo (user:pass) @ host (domain.com) : port (8080) path (/some/folder/or/file) ? query (asdf=asdf&b=b) # fragment (#anchor_tag)
