# unescape-entity

> 标签: char, character, characters, entities, entity, escape, html, string, un-escape, unescape, xml

## 简介

Convert HTML entities to HTML characters, e.g. `&gt;` converts to `>`. Renamed original library to unescapeEntity because we had some conflicts with other libraries in our code.
