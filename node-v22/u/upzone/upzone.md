# upzone

> 标签: dropzone, file upload, javascript, multiples files, typescript, upload, upload files, upzone, vuedropzone, vuejs

## 简介

A file upload component with drag-and-drop functionality. Provides easy integration for file selection, validation, and progress tracking.
