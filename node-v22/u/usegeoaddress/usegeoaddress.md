# usegeoaddress

> 标签: address, city, coordinates, current, details, district, experience, geo-location, geolocation, handling, latitude, location, longitude, npm, package, permission, precise, region, useGeoLocation, usegeoAddress, user

## 简介

usegeoaddress is a lightweight npm package that retrieves users' current location, including city, district, and region details. It also handles location permission errors seamlessly for a smooth user experience.
