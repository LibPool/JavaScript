# uis-mcp-server

> 标签: culture-statistics, education, education-statistics, enrolment, literacy, mcp, mcp-server, model-context-protocol, official-statistics, open-data, provenance, remote-mcp-server, research-and-development, science-statistics, sdg4, uis, unesco

## 简介

Remote MCP server for the UNESCO Institute for Statistics (UIS): ~5,000 indicators on education, science/R&D, culture and communication by country, region and year — hosted, nothing to install, no API key, with source URL, data release, retrieval timestam
