# uni-conf-orm

> 标签: apikey, mybatis, orm, rest, sql

## 简介

一款基于配置驱动的多数据库 ORM,以 “配置驱动” 为核心，通过巧妙的设计将数据操作逻辑从代码转移到配置文件中，实现了跨数据库自适应、与 Web 框架解耦、零冗余路由等颠覆性功能。本文将从设计理念、核心功能、技术创新等方面，详细阐述这款框架如何彻底改变传统数据访问层的开发模式，让开发者从繁琐的重复劳动中解放出来，专注于真正有价值的业务逻辑。
