# unicode-emojis-unique-id-json

> 标签: emojis, json, unicode

## 简介

JSON-version of fully qualified emojis in https://unicode.org/Public/emoji/14.1/emoji-test.txt with unique digit only IDs. The IDs should be unique over time, also when new versions of unicode emojis are released.
