# unified-scrollbar

> 标签: css, css-scrollbar, custom-scrollbar, firefox-scrollbar, scrollbar, scrollbar-style, scrollbar-theme, style, ui, unified-scrollbar, webkit-scrollbar

## 简介

A zero-dependency library for unifying cross-browser (WebKit/Firefox) scrollbar styles with a single API call or CSS import.
