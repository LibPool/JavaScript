# ultronpx

> 标签: anthropic, claude-code, cli, context-compression, llm, proxy, token-optimization, vision-tokens

## 简介

Local context-compression proxy for Claude Code — renders dense context blocks as PNG to cut token cost, with verbatim safety guards
