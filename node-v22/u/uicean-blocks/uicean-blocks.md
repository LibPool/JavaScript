# uicean-blocks

> 标签: auth, blocks, design-system, footer, hero, landing-page, login, react, registry, shadcn, shader, tailwind-v4, tailwindcss, uicean, webgl

## 简介

Section-sized page blocks for UICean — heroes, feature grids, logo clouds, footers, app shells, sign-in screens, maps and WebGL effects. Built from the core primitives, so they inherit your tokens instead of bringing their own.
