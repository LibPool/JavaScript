# uniapp-echarts

> 标签: echarts, echarts-uniapp, 可视化, 图表

## 简介

uni-app 版本 echarts, 支持 Vue2/3, 开发者可以通过熟悉的 ECharts 配置方式，快速开发图表，满足各种可视化需求.
