# ui-ux-components-pxml

> 标签: ai, codegen, components, design-system, nextjs, pxml, tailwind, ui, ux

## 简介

Comprehensive pxml UI/UX component library (~150 base components across 15 genres) for AI-compiled web projects. Use a tag via extends + attach an llm-judge prompt to restyle.
