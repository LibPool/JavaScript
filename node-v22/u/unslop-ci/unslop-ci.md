# unslop-ci

> 标签: ai, ci, code-review, diff, github-actions, lint, llm, quality-gate, slop, unslop

## 简介

A diff-aware CI gate for AI slop. Scans only the lines a PR adds for the tells that make code, prose, and UI read as AI-generated, and fails the build when a strong tell lands.
