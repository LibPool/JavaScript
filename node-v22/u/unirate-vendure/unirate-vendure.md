# unirate-vendure

> 标签: currency, ecommerce, exchange-rates, unirate, vendure, vendure-plugin

## 简介

Vendure plugin for the UniRate currency-exchange API — injectable UniRateService (rates, convert, currencies, VAT) plus unirateConvert/unirateRate GraphQL queries, with zero runtime dependencies.
