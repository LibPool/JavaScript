# ui-craft-detect

> 标签: accessibility, ai-slop, anti-pattern, cli, code-quality, css, design, design-system, detector, jsx, linter, tailwind, tsx, ui

## 简介

Static anti-slop detector for UI code. Flags AI-generated design patterns (purple gradients, bounce easing, glassmorphism, generic CTAs, ALL CAPS headings, transition: all). Zero dependencies, works out of the box.
