# until-mcp

> 标签: assignments, canvas, education, etl, lms, mcp, moodle

## 简介

MCP server for university eTL (Canvas/Moodle) — read-only assignment inbox, spec/requirements, materials, routing, readiness checks, submission-series, semester overview, and weekly briefs. No generation tools, no LLM calls. Requires a local Python 3.10+
