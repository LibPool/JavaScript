# undetermini

> 标签: eval, llm, non-deterministic, prompt-engineering, testing

## 简介

Eval harness for non-deterministic (LLM) code — subjects, variants (provider × model × reasoning), weighted-assertion scoring, trial cache, SQLite runs, CLI + TUI.
