# unofficial-trackjs-mcp

> 标签: claude, error-monitoring, javascript-errors, mcp, model-context-protocol, trackjs

## 简介

Unofficial MCP server for the TrackJS Data API. Read-only tools for querying JavaScript errors, error trends, and page views. Not affiliated with TrackJS.
