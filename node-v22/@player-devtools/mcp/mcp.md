# @player-devtools/mcp

> 标签: JavaScript

## 简介

An [MCP](https://modelcontextprotocol.io) server that exposes the Player UI Devtools to AI agents. It lets a model — e.g. Claude — inspect and drive a live Player instance: list running Players, read their flow / data / logs / config, inspect plugin state
