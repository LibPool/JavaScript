# @sharpee/bootstrap

> 标签: bootstrap, if, interactive-fiction, sharpee, story-loader

## 简介

Load and assemble a Sharpee story (entry-aware) into a runnable game — the single loader used by transcript-tester, the CLI bundle, and devkit (ADR-180)
