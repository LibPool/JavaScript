# @adsq/solid-signal-store

> 标签: jsnq, proxy, reactive, solidjs, store

## 简介

Fine-grained SolidJS store with a callable nested proxy API: reads like store.user.name(), writes like ordinary assignment, and wakes only the paths a component actually consumes.
