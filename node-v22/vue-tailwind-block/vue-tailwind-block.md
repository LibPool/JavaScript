# vue-tailwind-block

> 标签: nuxt, nuxt-module, tailwind, tailwindcss, unplugin, vite, vue, vue3, yaml

## 简介

Keep long Tailwind utility classes out of your Vue templates with a typed <tailwind> YAML block for Vite and Nuxt.
