# @jetprint/editor-sdk

> 标签: JavaScript

## 简介

基于 **Vue 3 + Fabric.js 7** 的可视化 POD 设计编辑器 SDK：产品选型、刀版 / 变形模板、图层编辑（图片 / 文字 / 平铺 / 画笔 / 油漆桶 / 裁切 / 抠图）、实时预览与效果图渲染、设计保存与还原、多尺码 × 多颜色批量出图，以及刺绣、异形抱枕两种特殊设计模式。
