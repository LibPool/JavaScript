# @kinnet/crypto

> 标签: ed25519, http-message-signatures, jcs, kinnet, rfc9421

## 简介

Identity, signing, and verification for Kinnet: Ed25519, JCS canonicalization, participant-ID derivation, key-event logs with pre-rotation, and RFC 9421 HTTP Message Signatures.
