# @woustachemaxd/agent-compiler

> 标签: AI, agentic, claude-code, codex, context, harness, pi

## 简介

Compile the recurring, deterministic workflows an AI coding agent re-derives every session into shell scripts and replayable recipes — so future agents run one command instead of re-reasoning.
