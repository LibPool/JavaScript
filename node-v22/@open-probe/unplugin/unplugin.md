# @open-probe/unplugin

> 标签: esbuild-plugin, open-probe, rspack-plugin, unplugin, vite-plugin, webpack-plugin

## 简介

Build-tool plugin (Vite/Webpack/Rspack/esbuild) that injects the open-probe runtime in development mode.
