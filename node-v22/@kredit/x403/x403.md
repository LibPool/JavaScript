# @kredit/x403

> 标签: agentic payments, ap2, kredit, mpp, risk, x401, x402, x403

## 简介

x403: a signed risk decision before money moves. Objects, canonical JSON, ES256 signing and verifying, the HTTP binding, a client and middleware.
