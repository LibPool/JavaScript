> 标签: API, automation, n8n, n8n-community-node, n8n-community-node-package, n8n-node, nytimes-archive, openapi, swagger, workflow

## 简介

Archive API provides lists of NYT articles by month going back to 1851. You can use it to build your own local database of NYT article metadata
