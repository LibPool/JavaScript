# @ch1/sql-tables

> 标签: dal, database, postgres, reactive, schema, sql, stream, typescript

## 简介

Thin data access layer and schema generator for Postgres (and potentially other SQLs) that leverages RxJS streams and can generate TypeScript type defintions
