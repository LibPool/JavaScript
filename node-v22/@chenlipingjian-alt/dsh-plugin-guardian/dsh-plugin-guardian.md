# @chenlipingjian-alt/dsh-plugin-guardian

> 标签: deepseek-harness, dsh, dsh-plugin, plugin-discovery, security-audit, supply-chain

## 简介

Searches community DSH plugins, audits each pinned commit against a fixed security checklist, installs only approved candidates, and verifies the result with evidence, for DeepSeek Harness.
