# @shahid.la/cds-db-nlquery-mcp

> 标签: ai-agent, anthropic, cap, cds, claude, db-layer, hana, llm, mcp, mcp-server, model-context-protocol, natural-language, nl2sql, nlquery, openai, sap, sap-cap, text-to-sql

## 简介

MCP server for natural language queries against CDS db-layer entities. Targets raw db/schema.cds entities via cds.run() with real SQL JOINs — bring your own LLM (Anthropic, OpenAI, or any OpenAI-compatible endpoint).
