# vue-note-backend-config

> 标签: backend, component, config, git, gitee, note, pouchdb, vue, vue3, webdav

## 简介

A Vue 3 <BackendConfig> modal component to configure PouchDB-local / Git / Gitee / WebDAV backends for a notes app. No network calls, no storage, no DB instances.
