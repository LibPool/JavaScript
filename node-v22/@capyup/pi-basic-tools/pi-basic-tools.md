# @capyup/pi-basic-tools

> 标签: editing, pi, pi-extension, pi-package, search

## 简介

Standalone core productivity tools for pi: repo_map, read_block, symbol_outline, apply_patch, exec_command, write_stdin, grouped basic-tool UI, work_checkpoint, ask_user, ask_question, ask_questionnaire, fetch, Sourcegraph, and built-in search activation.
