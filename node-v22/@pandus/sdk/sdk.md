# @pandus/sdk

> 标签: a11y, accessibility, analytics, consent, gdpr, heatmaps, nextjs, nuxt, privacy, react, session-recording, vue, wcag, web-vitals

## 简介

Pandus SDK for npm: live accessibility barriers from real visitors and privacy-first analytics, loaded only after consent. Typed API, React/Next.js and Vue/Nuxt helpers.
