# @aws-icons/alpine

> 标签: alpine, alpinejs, aws, aws-icon, icon, icons, svg

## 简介

AWS Architecture Icons as an Alpine.js plugin — x-aws-icon directive and $awsIcon magic with tree-shakeable icon data (flat, high-contrast, modern).
