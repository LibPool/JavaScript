# @agledger/verify-core

> 标签: JavaScript

## 简介

Shared offline verification core for AGLedger audit chains: COSE_Sign1 (RFC 9052) decode/verify, Ed25519 + ES256, hash-chain walk, vault key-statement trust walk, RFC 9162 Merkle proofs, and the canonical failure taxonomy. One dependency (cborg); no netwo
