# @keelcodes/migrate

> 标签: account-abstraction, agent, erc-4337, erc-7579, module-migration, session-key

## 简介

Lazy, dual-module migration tooling for ERC-7579 session validators: version routing, a migration state machine and the silent-AA24 probe.
