# @mulmuri/claude-agent-sdk

> 标签: agent, agent-sdk, claude, claude-code, codex, llm, mcp

## 简介

Claude Agent SDK-compatible client that reaches Claude Code through Codex CLI (interactive `claude "..."`) or the Claude Code MCP server — never through `claude -p`.
