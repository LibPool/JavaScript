# @matschik/vite-sainte-stack

> 标签: JavaScript

## 简介

Runtime primitives for the Sainte Stack (SvelteKit + SQLite): env validation, error-log, rate-limit, health, and analytics wiring. Explicit primitives — you wire them in your `hooks`/`routes`. ESM-only.
