# @pqqqqqdev/agent-context-lint

> 标签: agent, ai, claude, cli, context, copilot, cursor, instructions, lint, linter, windsurf

## 简介

A command-line linter that audits AI coding-agent context/instruction files for repositories. Helps reduce token bloat, duplicated instructions, vague agent instructions, missing project commands, and dangerous shell commands.
