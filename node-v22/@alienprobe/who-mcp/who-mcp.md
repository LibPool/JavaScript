# @alienprobe/who-mcp

> 标签: agent-payments, gleif, kyb, legal-entity, lei, mcp, modelcontextprotocol, x402

## 简介

MCP server for the Alien Probe `who` lookup: one legal-entity fact (LEI, legal name, jurisdiction, status), paid per call with x402 on Base. Free refusals, hard spend caps.
