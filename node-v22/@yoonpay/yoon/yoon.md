# @yoonpay/yoon

> 标签: dexpay, naboopay, orange-money, paydunya, payments, senegal, wave, xof, yoon

## 简介

JavaScript/TypeScript client for Yoon, a self-hosted payment gateway for African payment providers. Runs on Node, Bun, Deno and edge runtimes.
