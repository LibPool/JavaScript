# @aidex/document

> 标签: ai, contract, document, document-intelligence, feature-pack, invoice, ocr, resume

## 简介

Aidex Document — the first Aidex Feature Pack: engine identifiers and typed request/response contracts for document intelligence (extraction, OCR, translation, summarization, resume analysis, invoice extraction, contract review).
