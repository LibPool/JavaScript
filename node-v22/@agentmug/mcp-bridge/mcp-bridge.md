# @agentmug/mcp-bridge

> 标签: agent, agentmug, ai, ai-worker, claude, cline, continue, cursor, mcp, model-context-protocol

## 简介

Expose a hosted AgentMug worker as an MCP server for Claude Code, Cursor, Cline, Continue, and compatible hosts.
