# @arivie/react

> 标签: JavaScript

## 简介

Arivie React surface — headless hooks (useAgent, useSchema, useMemory) AND a drop-in chat UI (<ArivieChat>, <ArtifactPane>) wired to the shared @arivie/ui-catalog via @json-render/react.
