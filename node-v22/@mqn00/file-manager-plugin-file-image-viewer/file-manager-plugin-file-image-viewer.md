# @mqn00/file-manager-plugin-file-image-viewer

> 标签: file-manager, file-manager-plugin, image, picture, viewer

## 简介

File Manager 文件查看子插件：图片查看（缩放/旋转/适应窗口，文件夹内上一张/下一张切换，缩略图图库分页跳转，常见图片格式）
