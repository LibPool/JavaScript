# @sailbound/sdk

> 标签: eip-3009, ethers, lending, robinhood-chain, sailbound, stock-tokens, usdg, x402

## 简介

JavaScript SDK for Sailbound: borrow USDG against stock tokens on Robinhood Chain, fund the pool, and pay or settle x402 requests in USDG.
