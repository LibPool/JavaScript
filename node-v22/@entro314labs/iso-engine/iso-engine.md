# @entro314labs/iso-engine

> 标签: animation, diagram, explorable, figure, illustration, isometric, svg

## 简介

Interactive isometric figures and autoplaying isometric animations in plain SVG: a projection kernel, interaction patterns, a glow kit and the Iso animation engine. No framework, no canvas, zero dependencies.
