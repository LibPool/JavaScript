# @elvoroz/authnest-client

> 标签: authentication, authnest, expo, oauth, passkeys, react-native

## 简介

Framework-agnostic AuthNest client for browsers, Node 18+, React Native and Expo: sign-in, sessions with automatic refresh, MFA, passkeys, social and passwordless flows.
