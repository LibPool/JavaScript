# dsh-addtochat

> 标签: composer, deepseek, deepseek-harness, dsh, dsh-plugin, quote, selection, web-plugin

## 简介

DSH web plugin: select text in a conversation reply and add it to the composer input as a fenced code block — one button replaces select-copy-paste. Zero-hack: browser Selection API + the official inputActions.setDraft face; no persistence, no overlays, n
