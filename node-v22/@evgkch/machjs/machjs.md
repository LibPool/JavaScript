# @evgkch/machjs

> 标签: discriminated-union, finite-state-machine, fsm, mealy, state-machine, transducer, typescript, typestate

## 简介

A small, typed Mealy state machine: one table of rules, a context that belongs to the state rather than the machine, and a graph that is a projection of the same object — serialize it, draw it, analyse it
