# @upupjs/preact

> 标签: camera, drag-and-drop, dropbox, dropzone, file-upload, file-uploader, google-drive, one-drive, preact, presigned-url, s3, typescript, upload, uploader

## 简介

Preact file uploader with cloud-drive sources, resumable uploads, an image editor (real Filerobot as a lazy real-React island), theming, and ICU i18n.
