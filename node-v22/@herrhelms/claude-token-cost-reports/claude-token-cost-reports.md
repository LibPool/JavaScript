# @herrhelms/claude-token-cost-reports

> 标签: anthropic, billing, claude, paperclip, paperclip-plugin, tokens, usage

## 简介

Track Claude token usage per Paperclip company, store daily rollups, render a dashboard, and export a monthly CSV for token-based billing. Pricing table covers Opus 4.8 / 4.7 and Sonnet 4.6 / 4.5 with 1M-context variants.
