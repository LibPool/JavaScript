# @story-kit/svelte-layout

> 标签: daisyui, demo, layout, rtl, storybook, svelte, svelte5, theme, viewport

## 简介

Storybook-inspired demo layout for Svelte 5: viewport, direction and theme controls (persistable), hash-synced tabs, offsets and a back link.
