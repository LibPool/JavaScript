# @knighted/jsx

> 标签: dom rendering, jsx runtime, no-build jsx, react rendering, rspack loader, ssr, tagged template, typescript plugin, wasm parser, webpack loader

## 简介

Runtime JSX tagged template that renders DOM or React trees anywhere with or without a build step.
