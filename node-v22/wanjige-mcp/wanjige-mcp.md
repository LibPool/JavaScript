# wanjige-mcp

> 标签: chinese, mcp, mcp-server, modelcontextprotocol, stdio, tools, wanjige, wanjige-mcp, 万机阁

## 简介

万机阁 MCP 桥接器 —— 一个 MCP 接入 15,552 个中文工具（stdio 客户端接入万机阁远程 MCP 服务：天气路线 POI、股票汇率、学术检索、文档解析、TTS/生图生视频、税费计算等）
