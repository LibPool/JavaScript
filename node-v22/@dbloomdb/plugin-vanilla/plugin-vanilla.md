# @dbloomdb/plugin-vanilla

> 标签: dbloom, ddl, multibanco, plugin, sql, vanilla

## 简介

Plugin vanilla para dbloom — primitive SQL types como domains, IF NOT EXISTS, log flat opcional. Roda em 5 dialetos via createVanilla(dialect).
