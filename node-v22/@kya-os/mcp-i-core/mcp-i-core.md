# @kya-os/mcp-i-core

> 标签: JavaScript

## 简介

Compatibility shim — re-exports @kya-os/mcp-i-runtime (product layer) plus the pinned W3C-VC delegation modules. Prefer @kya-os/mcp-i-runtime directly.
