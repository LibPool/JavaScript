# @axion-ct/parser-js

> 标签: JavaScript

## 简介

JavaScript/TypeScript front-end for Code Translator: parses JS/TS/JSX/TSX into the shared parser contract defined in `@axion-ct/core` (`ParseResult`, spans, comments, module info — see `docs/architecture.md` §4).
