# @ngx-docs-markdown-kit/parser-md-seo

> 标签: docs, frontmatter, json-ld, markdown, seo, sitemap

## 简介

Extension de @ngx-docs-markdown-kit/parser-md que extrae metadatos de SEO del frontmatter, y expone los servicios de Angular (meta tags, JSON-LD) + funciones (sitemap.xml/robots.txt) para aplicarlos.
