# @drzl/generator-elysia

> 标签: bun, codegen, drizzle, drizzle-orm, elysia, rest, standard-schema

## 简介

Generate Elysia routes from a Drizzle schema, one mounted module per table, validated by DRZL's own schemas through Elysia's own validator slot.
