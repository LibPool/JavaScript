# @drzl/generator-effect-http

> 标签: codegen, drizzle, drizzle-orm, effect, effect-platform, httpapi

## 简介

Generate Effect Platform HttpApi endpoints from a Drizzle schema, one group per table, declared against the Effect Schema modules DRZL already emits.
