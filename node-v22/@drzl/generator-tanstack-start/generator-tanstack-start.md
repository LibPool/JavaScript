# @drzl/generator-tanstack-start

> 标签: codegen, drizzle, drizzle-orm, server-functions, standard-schema, tanstack, tanstack-start

## 简介

Generate TanStack Start server functions from a Drizzle schema, one module per table, with the reads on GET and the writes on POST and every payload validated by the schemas DRZL already emits.
