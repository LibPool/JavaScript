# @useupup/core

> 标签: camera, cloud-storage, drag-and-drop, dropbox, dropzone, file-picker, file-upload, file-uploader, google-drive, headless, image-upload, one-drive, presigned-url, s3, typescript, uploader

## 简介

Headless, framework-agnostic file-upload engine powering the upup uploader — file state, upload pipeline (compression, HEIC, web-worker offload), cloud-drive sources, i18n, and theming.
