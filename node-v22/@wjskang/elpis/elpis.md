# @wjskang/elpis

> 标签: JavaScript

## 简介

> 一句话概括：**你写的是配置，系统生成的是项目。** > Elpis 是一套「中后台低代码 / DSL 驱动」全栈框架：后端基于 Koa2 + loader 体系（类似 egg 的约定式加载），前端是 Vue3 动态渲染器（Dashboard）。开发者通过声明式 JSON 配置（DSL）描述系统长什么样，Elpis 解析、合并、渲染，自动生成完整的中后台项目。
