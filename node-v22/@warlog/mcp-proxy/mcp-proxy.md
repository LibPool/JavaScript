# @warlog/mcp-proxy

> 标签: ai-agents, audit, compliance, eu-ai-act, gdpr, mcp, model-context-protocol, nis2, warlog

## 简介

Warlog audit proxy for Model Context Protocol — sits between MCP clients (Claude Desktop, Cursor, Cline) and MCP servers, signs every tools/call with the Warlog trust-layer contract.
