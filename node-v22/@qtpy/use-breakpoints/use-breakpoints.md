# @qtpy/use-breakpoints

> 标签: hooks, media query, react, ui

## 简介

`useBreakpoints` — кастомный React-хук для адаптивного управления значениями в зависимости от размеров окна браузера. Поддерживает числовые, текстовые значения, JSX и динамические правила (DynamicRule) для гибкой настройки. Хук принимает необязательный па
