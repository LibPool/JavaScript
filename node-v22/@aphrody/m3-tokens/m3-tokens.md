# @aphrody/m3-tokens

> 标签: JavaScript

## 简介

Material 3 design tokens (--md-sys-*) for the @aphrody/material-web fork: MUI-theme → M3 token CSS generation and runtime Material You dynamic colour via material-color-utilities.
