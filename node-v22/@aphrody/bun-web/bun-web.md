# @aphrody/bun-web

> 标签: JavaScript

## 简介

Bun browser SDK: CDP pages over Bun.WebView, the bun_browser engine lifecycle and web service (fetch, scrape, crawl), agent-browser client, Tauri bridge and the Playwright-compatible test runner.
