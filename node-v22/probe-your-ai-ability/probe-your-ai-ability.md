# probe-your-ai-ability

> 标签: ai, claude-code, cli, codex, copilot, cursor, developer-productivity, report

## 简介

Measures how you work with AI coding agents (Claude Code, Codex, Cursor, Copilot CLI, Antigravity) from your local logs and git — facts only leave the machine, DaVaL scores them and returns a PDF report, a sealed .daval and a type guide
