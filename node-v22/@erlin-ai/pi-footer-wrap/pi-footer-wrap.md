# @erlin-ai/pi-footer-wrap

> 标签: extension, footer, pi, pi-coding-agent, pi-package, wrap

## 简介

Adaptive-wrapping footer for the pi coding agent: takes over the default footer and wraps extension statuses across lines instead of truncating them. No data is dropped.
