# @erlin-ai/pi-token-summary

> 标签: cost, extension, pi, pi-coding-agent, pi-package, token-summary, token-usage

## 简介

Token/cost inline stats for the pi coding agent: dim transcript line with this turn's output, cumulative tokens, context %, and cost. Modes via /token-summary verbose|brief|off.
