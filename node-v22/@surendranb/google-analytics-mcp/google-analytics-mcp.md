# @surendranb/google-analytics-mcp

> 标签: ai-agent, analytics, anthropic, claude, claude-code, cursor, ga4, google-analytics, mcp, mcp-server

## 简介

Model Context Protocol (MCP) server for Google Analytics 4 (GA4) data and schema discovery via NPX. Spawns the Python package through uvx with full stdio passthrough.
