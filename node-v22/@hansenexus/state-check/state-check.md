# @hansenexus/state-check

> 标签: app-router, convex, error-boundary, lint, loading, nextjs, pending, ratchet, react-router, suspense, vite, wouter

## 简介

The hansenexus frontend state contract as a deterministic check: dynamic Next.js App Router segments need loading.tsx or <Suspense>; opt-in rules for client router routes (wouter, React Router: error boundary, lazy pages in Suspense), Convex useQuery load
