# @hansenexus/shell

> 标签: app-shell, command-palette, design-system, react, tailwindcss

## 简介

hansenexus app shell: floating panels with nav, header, main and an optional context pane, a ⌘K container that takes external command sets or a whole palette, and capability-based nav visibility. Semantic tokens only.
