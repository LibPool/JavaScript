# @adaskothebeast/angular-date-http-interceptor

> 标签: angular, date, http-interceptor, httpclient, iso8601, json, typescript

## 简介

Angular HttpClient interceptor that deeply converts ISO 8601 date strings in JSON responses with a pluggable hierarchical converter.
