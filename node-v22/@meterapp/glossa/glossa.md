# @meterapp/glossa

> 标签: ai, cli, crowdin, i18n, l10n, localization, mcp, translation

## 简介

Glossa CLI: push and pull translation files, run the AI review queue, and every other Glossa op from your terminal or CI. Includes a stdio MCP bridge.
