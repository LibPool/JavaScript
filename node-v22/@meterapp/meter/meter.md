# @meterapp/meter

> 标签: agents, chatgpt, claude, cli, codex, fleet, mcp, mcp-server, meter, taxi

## 简介

Command-line client and MCP bridge for Meter, the taxi meter and fleet platform. Sign in with OAuth, query fleets, members, vehicles, trips, bookings, earnings and accounting from a terminal or a CI job, run a stdio MCP server, and generate agent configur
