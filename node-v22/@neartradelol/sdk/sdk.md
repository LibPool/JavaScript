# @neartradelol/sdk

> 标签: dex, launchpad, near, neartrade, rhea, sdk, swap, trading

## 简介

TypeScript SDK for the neartrade developer API: onboard users from any chain onto NEAR (NEAR Intents), then quote and swap on every NEAR launchpad and Rhea pool, paid in NEAR or USDC.
