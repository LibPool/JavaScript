# @apsulis/emdash-light-smtp

> 标签: email, emdash, emdash-plugin, nodemailer, smtp

## 简介

Light, hardened SMTP email provider for self-hosted EmDash (Node.js): one-line configuration, mandatory TLS, safe off switch.
