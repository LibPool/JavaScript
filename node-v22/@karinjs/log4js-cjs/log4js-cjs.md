# @karinjs/log4js-cjs

> 标签: karinjs, log4js

## 简介

Use vite+tsup to recompile log4js into cjs, which is smaller in size.

## 官网

- 官网：https://github.com/KarinJS/log4js
- 源码仓库：git+https://github.com/KarinJS/log4js.git
- npm 页面：https://www.npmjs.com/package/@karinjs/log4js-cjs

## 历史版本号

- 当前版本：1.1.1

- 1.1.1

## 获取地址

- npm 安装：`npm install @karinjs/log4js-cjs`
- npm registry：https://registry.npmjs.org/@karinjs/log4js-cjs
- Node 要求：>=18
