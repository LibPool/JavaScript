# dsh-get-session-status

> 标签: cascreenguard, cordis, deepseek-harness, dsh, lockscreen, privacy

## 简介

把 DeepSeek Harness 的会话状态写成 CAScreenGuard 锁屏可读的 JSON（working / waiting）。只写状态，不写对话内容、项目名或提示词。
