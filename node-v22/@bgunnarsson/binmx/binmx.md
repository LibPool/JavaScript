# @bgunnarsson/binmx

> 标签: ajax, csp, html, htmx, hypermedia, security

## 简介

Hypermedia-driven HTML attributes without the eval. A security-first htmx-compatible core: bin-get/post/put/patch/delete, swapping, out-of-band swaps, history — no JavaScript in your markup.
