# @metanoialabs/widget

> 标签: JavaScript

## 简介

A drop-in chat widget for [Metanoia Mosaic](https://github.com/Xephyr-Labs/metanoia-mosaic). It needs no framework, renders inside Shadow DOM so your page styles don't leak in, and talks to a [`@metanoialabs/chatbot`](https://www.npmjs.com/package/@metano
