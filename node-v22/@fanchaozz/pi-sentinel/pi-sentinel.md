# @fanchaozz/pi-sentinel

> 标签: ai, coding-agent, pi-extension, pi-package, pii, privacy, redaction, secrets, security, tokenization

## 简介

A pi extension that protects sensitive information (PII & credentials) in coding-agent sessions: inbound tokenization, outbound plaintext restoration for tool calls, derived masked display, and zero-plaintext session persistence.
