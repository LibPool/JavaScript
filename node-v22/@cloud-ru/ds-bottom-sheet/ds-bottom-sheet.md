# @cloud-ru/ds-bottom-sheet

> 标签: JavaScript

## 简介

Mobile-first overlay-контейнер с drag-handle и swipe-down для диалогов, выпадающих списков и фильтров. Поддерживает snap-points (раскрытие на половину → full).
