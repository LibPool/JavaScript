# @cloud-ru/ds-uikit-product-page-layout

> 标签: JavaScript

## 简介

Набор страничных раскладок продуктового кабинета — каталог, детальная страница сервиса, форма, дерево-навигация, сайдбар и общие слоты — с адаптацией desktop/mobile через AdaptiveProvider.
