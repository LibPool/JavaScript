# @cloud-ru/ds-uikit-product-charts

> 标签: JavaScript

## 简介

Продуктовые графики: кольцо заполненности BagelChart, круговая диаграмма PieChart с легендами, тепловая карта HeatMapChart и интерактивный график InteractiveChart на uPlot.
