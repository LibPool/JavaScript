# dts-js-extensions

> 标签: d.ts, declarations, esm, node16, nodenext, tsc, typescript, vite-plugin-dts

## 简介

Rewrites relative imports in emitted .d.ts files to explicit .js paths for moduleResolution node16/nodenext. A vite-plugin-dts afterBuild hook and a CLI for tsc output.
