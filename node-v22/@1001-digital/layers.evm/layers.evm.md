# @1001-digital/layers.evm

> 标签: JavaScript

## 简介

Nuxt layer for EVM applications. It extends `@1001-digital/layers.base` and adds wallet connection, SIWE, ENS, multi-chain config, EVM components, composables, and transaction flows.
