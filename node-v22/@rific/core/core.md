# @rific/core

> 标签: context, provider, react, react-native, redux, settings, state

## 简介

Required foundation for @rific/* packages: createSettingsContext + createSettingsSlice for a live, patchable settings object (Context and Redux, respectively), and createModuleConfig for one-time optional-peer-module injection
