# @rmartz/repo-hygiene

> 标签: ci, conflict-markers, github-actions, lint, repo-hygiene

## 简介

Low-cost repo-hygiene CI checks (conflict markers, GitHub Actions SHA pins, docs link integrity, file-size caps, and more), distributed via the rmartz/repo-hygiene-action GitHub Action and kept current by Dependabot.
