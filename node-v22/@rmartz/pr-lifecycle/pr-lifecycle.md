# @rmartz/pr-lifecycle

> 标签: auto-merge, ci, github-actions, labels, lifecycle, pull-request

## 简介

Event-driven PR lifecycle reconciler: recomputes a pull request's lifecycle labels from its current facts on every GitHub event and arms native auto-merge on approval.
