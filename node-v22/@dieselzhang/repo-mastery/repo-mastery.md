# @dieselzhang/repo-mastery

> 标签: claude-code, codex, education, gemini-cli, learning, mastery, open-source, skill, spaced-repetition

## 简介

Turn any open-source repository into a developer-focused mastery course — usage, architecture, key implementations, with deterministic mastery gates and spaced review. Installable as a skill for Claude Code, OpenAI Codex, and Gemini CLI.
