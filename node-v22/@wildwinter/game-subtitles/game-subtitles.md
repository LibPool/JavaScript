# @wildwinter/game-subtitles

> 标签: captions, games, hyphenation, localization, subtitles, text-layout

## 简介

Subtitle player for games: wraps, hyphenates, paginates, and times subtitles, using the soft hyphens the Game Subtitles preprocessor adds.
