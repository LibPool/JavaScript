# @tracklution/cli

> 标签: ai-agent, claude-code, conversion-tracking, cursor, mcp, nextjs, server-side-tracking, tracklution, windsurf

## 简介

Install Tracklution server-side conversion tracking. Scope-reserved alias of the `tracklution` package: forwards to its CLI. Real install goes via the Tracklution MCP at https://mcp.tracklution.com/mcp. Protocol: https://www.tracklution.com/agent-install.
