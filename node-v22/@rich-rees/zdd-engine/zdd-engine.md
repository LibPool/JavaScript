# @rich-rees/zdd-engine

> 标签: adr, agent-index, claude-code, documentation, glossary, zero-drift

## 简介

Zero-Drift Docs engine: derive codebase metadata, render the agent + human indexes, and run the drift checks — deterministic, stdlib-only, no LLM. Consumed by both CI (npx, no Claude Code) and the zdd Claude Code plugin.
