# dsh-inject-kit

> 标签: JavaScript

## 简介

Inject Kit for DeepSeek Harness: selectable AGENTS.md presets (per-session composer selector, default keeps DSH's original AGENTS.md behavior) plus a reusable prompt library referenced as #Name in the composer; references are replaced with a send-time sna
