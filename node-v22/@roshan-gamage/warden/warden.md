# @roshan-gamage/warden

> 标签: cluster, daemon, nodejs, pm2, process-manager, prometheus, supervisor, warden

## 简介

Self-hosted PM2 alternative: supervise any process (Node, Python, binaries) with cluster mode, auto-restart, logs, metrics, Prometheus, and a CLI dashboard.
