# @gjsify/gtksource-nativescript

> 标签: android, editor, gjs, gtksourceview, highlighting, nativescript, source-view, syntax

## 简介

GtkSource.View for NativeScript — an Android EditText with incremental syntax highlighting, a line-number gutter and GtkSourceView language/scheme managers, driven by @gjsify/gtksource-core
