# @gjsify/devtools-browser

> 标签: adwaita, browser, devtools, gjs, mcp, webkit

## 简介

Minimalist Adwaita web browser for GJS — shared BrowserCore + native Adw shell + a devtools extension so an agent can drive and inspect web apps over MCP
