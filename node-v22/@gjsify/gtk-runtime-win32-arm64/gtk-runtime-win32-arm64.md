# @gjsify/gtk-runtime-win32-arm64

> 标签: JavaScript

## 简介

Batteries-included GTK/GObject-Introspection runtime bundle for Windows arm64 — lets @gjsify/node-gi load gi:// namespaces (GLib/GObject/Gio/cairo/Pango/Graphene/Gdk) with NO gvsbuild/system GTK. Platform-gated (win32/arm64 only). GTK is built from source
