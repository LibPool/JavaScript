# @gjsify/devtools

> 标签: adwaita, dbus, debug, devtools, gjs, gtk, mcp

## 简介

In-app DBus devtools control plane for GJS/GTK apps — inspect, screenshot, and drive a running app over org.gjsify.Devtools (gdbus or the MCP bridge)
