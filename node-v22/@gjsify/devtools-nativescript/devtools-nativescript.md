# @gjsify/devtools-nativescript

> 标签: android, cdp, debug, devtools, gjs, ios, mcp, nativescript

## 简介

In-app NativeScript devtools agent — exposes a running NS app's view tree + screenshots to the @gjsify/devtools-mcp bridge over the V8 CDP inspector (org.gjsify.Devtools method registry)
