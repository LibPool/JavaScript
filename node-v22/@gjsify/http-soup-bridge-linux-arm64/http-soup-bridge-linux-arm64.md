# @gjsify/http-soup-bridge-linux-arm64

> 标签: JavaScript

## 简介

linux-arm64 prebuilt native library + GObject-Introspection typelib for @gjsify/http-soup-bridge. Installed automatically on linux/arm64 as an optionalDependency of that package (ADR 0017) and skipped everywhere else. Contains no JavaScript.
