# @gjsify/site

> 标签: appstream, flathub, gnome, landing-page, metainfo, static-site

## 简介

Static landing page generator for a GNOME-style app, rendered from its AppStream metainfo — downloads, screenshots, release notes, support links, no JavaScript required.
