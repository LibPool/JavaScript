# @endstate-sdk/web

> 标签: authentication, browser, chip, endstate, nfc, tap, verification, wallet, web-nfc

## 简介

Endstate in the browser - tap capture from redirects and Web NFC, tap sessions, and wallet provisioning over the Endstate wallet frame, with zero runtime dependencies.
