# @cvfile/server

> 标签: JavaScript

## 简介

Server middleware that serves .cv files with HTTP Link header content negotiation. Express, Fastify, Hono adapters.

## 官网

- 官网：https://cvfile.org
- 源码仓库：git+https://github.com/cvfile/cv.git
- npm 页面：https://www.npmjs.com/package/@cvfile/server
