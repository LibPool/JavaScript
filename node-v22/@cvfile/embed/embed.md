# @cvfile/embed

> 标签: JavaScript

## 简介

Open-source embedding generation for the .cv format. BGE-M3 by default; pluggable.

## 官网

- 官网：https://cvfile.org
- 源码仓库：git+https://github.com/cvfile/cv.git
- npm 页面：https://www.npmjs.com/package/@cvfile/embed
