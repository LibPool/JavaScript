# @syncfusion/react-svg-tooltip

> 标签: react, react-svg-tooltip, syncfusion, syncfusion-react, web-components

## 简介

Syncfusion React SVG tooltip component is a lightweight and customizable React SVG tooltip component for enhancing data visualizations with interactive overlays.
