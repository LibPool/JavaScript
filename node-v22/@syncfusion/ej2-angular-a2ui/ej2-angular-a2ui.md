# @syncfusion/ej2-angular-a2ui

> 标签: a2ui, agent, ai, angular, ej2, syncfusion

## 简介

Syncfusion EJ2 Angular adapter for the A2UI agent-to-UI protocol (v0.9). Mirrors @syncfusion/ej2-react-a2ui one-for-one across 55+ components. Built on the official @a2ui/angular v0.10 runtime using the CatalogComponent + signal-input + props() bag patter
