# @tabcommerceio/cross-sell-sdk

> 标签: cross-sell, recommendations, shopify, storefront, tab-commerce, upsell

## 简介

Storefront JavaScript SDK for Tab Cross Sell: recommendation resolve, valid-impression observation, click / add-to-cart tracking, and batched event delivery.
