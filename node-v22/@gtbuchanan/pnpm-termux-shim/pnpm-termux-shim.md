# @gtbuchanan/pnpm-termux-shim

> 标签: JavaScript

## 简介

pnpm wrapper with an absolute-path shebang for Termux/Android, where /usr/bin/env doesn't exist and glibc-built binaries (e.g. turbo) bypass Termux's Bionic LD_PRELOAD shebang shim
