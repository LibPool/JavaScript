# @rikaido/react

> 标签: allergens, cooking, food-graph, headless, react, recipe, rikaido

## 简介

Headless, composable React components for cooking apps, on Rikaido's foundations: the harness verdict, the food graph, the ingredient cast, scaling, units, timers and cook-mode steps. Powered by Rikaido.
