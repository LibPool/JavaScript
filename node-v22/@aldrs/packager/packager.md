# @aldrs/packager

> 标签: CLI, aldrs, audio, cross-platform, directory, json, utf8, video, zip

## 简介

A CLI tool to create a structured JSON and zip a directory with UTF-8 support, audio/video filtering, and cross-platform compatibility.
