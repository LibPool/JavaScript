# @morten.hogseth/bundler

> 标签: babel, bundling, mvc, webpack

## 简介

A package that bundle asp.net MVC application's using webpack. Enables the project to use modern javascript with module loading. This will emulate a full ES2015 (ES6) environment. The goal of this package is to abstract the setup process as much as possib
