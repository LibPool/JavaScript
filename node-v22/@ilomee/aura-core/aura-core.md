# @ilomee/aura-core

> 标签: aura, css-variables, design-system, design-tokens, theming

## 简介

Aura Design System core — design tokens (CSS variables, JS tokens), base component styles, class builders, component contracts, and headless DOM behaviour (focus trap, positioning, dismiss, scroll lock)
