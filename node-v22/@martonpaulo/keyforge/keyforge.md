# @martonpaulo/keyforge

> 标签: encryption, key, password, password-generator, security, utility

## 简介

KeyForge is a secure and flexible password generation and evaluation library for Node.js. It allows you to generate strong, cryptographically secure passwords with customizable options, and also provides a function to check the strength and security level
