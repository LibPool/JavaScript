# @sol-fab/svc

> 标签: graceful-shutdown, sigterm, sol

## 简介

Sol's service-lifecycle contract for TypeScript HTTP services -- idempotent SIGTERM/SIGINT, a bounded drain (matching sol-svc's drain_timeout_s), and ordered shutdown hooks. Not a routing framework; wraps Fastify/Express, doesn't replace them.
