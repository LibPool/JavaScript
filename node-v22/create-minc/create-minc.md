# create-minc

> 标签: argocd, cloudnativepg, dev-cluster, kubectl, kubernetes, microshift, minc, okd, openshift, pomerium, postgres, scaffold

## 简介

Scaffold a local MicroShift-in-Container (minc) OpenShift/Kubernetes dev cluster, with optional Console, CloudNativePG Postgres, and Argo CD.
