# @nxkit/playwright

> 标签: CLI, E2E, Monorepo, Nx, Nx Plugin, Playwright, Testing

## 简介

Nx Plugin containing executors and generators allowing your workspace to use the powerful Playwright end-to-end testing capabilities.
