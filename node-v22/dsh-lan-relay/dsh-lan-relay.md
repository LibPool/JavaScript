# dsh-lan-relay

> 标签: agent-to-agent, deepseek-harness, dsh, dsh-bundle, dsh-plugin, lan, message-bus, multi-agent, relay, wake-on-message

## 简介

DeepSeek Harness 局域网中继插件：一台机器在 DSH 进程内做 hub，其余机器粘贴加入码即可加入；跨机器 Agent 消息互通、离线补投、自动唤醒会话，标准 DSH bundle，装完即用。
