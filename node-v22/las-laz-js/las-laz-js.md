# las-laz-js

> 标签: asprs, gis, las, laz, lidar, opfs, point-cloud, pointcloud, survey, threejs

## 简介

Zero-dependency JavaScript reader and writer for ASPRS LAS point clouds, and reader and writer for LAZ (LASzip), for the browser and Node, built for files larger than memory.
