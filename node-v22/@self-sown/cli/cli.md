# @self-sown/cli

> 标签: agent, agentic-commerce, cli, marketplace, mcp, nostr, self-sown, ucp

## 简介

Terminal client for the Self-Sown marketplace — lets AI agents and humans search the catalog, get a free shopping API key, and complete checkouts from the command line.
