# @hasdata/google-images-mcp

> 标签: google-images, hasdata, image-search, mcp, model-context-protocol, reverse-image, scraper, seo, serp

## 简介

MCP server for Google Images through HasData's hosted API: image search with size, colour and type filters, returning 100 results a call with the source page and the full-resolution URL. 1,000 free credits every month.
