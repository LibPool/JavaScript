# @hasdata/indeed-mcp

> 标签: hasdata, indeed, indeed-mcp, job-search, jobs, mcp, model-context-protocol, scraper

## 简介

MCP server for Indeed through HasData's hosted API: search job listings by keyword and location, and read a single posting in full. No Indeed developer account. 1,000 free credits every month.
