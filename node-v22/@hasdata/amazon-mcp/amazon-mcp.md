# @hasdata/amazon-mcp

> 标签: amazon, amazon-mcp, asin, ecommerce, hasdata, mcp, model-context-protocol, product-data, scraper

## 简介

MCP server for Amazon through HasData's hosted API: keyword search, product details, seller storefronts and their catalogues. No Amazon developer account. 1,000 free credits every month.
