# @hasdata/tiktok-mcp

> 标签: hasdata, mcp, model-context-protocol, scraper, social-media, tiktok, tiktok-mcp, tiktok-scraper

## 简介

MCP server for public TikTok data through HasData's hosted API: profile lookup, an account's videos, video comments and reply threads, and keyword search over videos or creators. No TikTok developer account. 1,000 free credits every month.
