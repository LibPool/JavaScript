# @hasdata/instagram-mcp

> 标签: hasdata, instagram, instagram-mcp, mcp, model-context-protocol, posts, profile, scraper

## 简介

MCP server for public Instagram data through HasData's hosted API: profile lookup by handle and public post feed, as structured JSON. Reads public data only. 1,000 free credits every month.
