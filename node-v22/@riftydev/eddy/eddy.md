# @riftydev/eddy

> 标签: install, npm, resolver, rifty, service

## 简介

Opt-in fast npm-install resolver service for rifty: runs rifty's own resolution server-side and returns one EddyBundleV1 (lockfile + compressed tarballs). ADR-0182.
