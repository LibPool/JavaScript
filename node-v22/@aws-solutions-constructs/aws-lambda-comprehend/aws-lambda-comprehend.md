# @aws-solutions-constructs/aws-lambda-comprehend

> 标签: AWS Lambda, AWS Solutions Constructs, Amazon Comprehend, Amazon S3, aws, awscdk, cdk

## 简介

CDK constructs for defining an interaction between an AWS Lambda function and Amazon Comprehend natural language processing service with optional S3 buckets for asynchronous analysis jobs.
