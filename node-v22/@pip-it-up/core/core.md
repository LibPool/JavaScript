# @pip-it-up/core

> 标签: browser-api, document-picture-in-picture, document-pip, floating-window, framework-agnostic, picture-in-picture, pip, pip-api, pip-window, safari-pip, vanilla-js, video-pip, web-api

## 简介

Vanilla JS engine for the Document Picture-in-Picture API with automatic video PiP fallback — move, clone, or portal any DOM element into a floating PiP window (public beta)
