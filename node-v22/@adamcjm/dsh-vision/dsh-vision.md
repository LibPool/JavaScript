# @adamcjm/dsh-vision

> 标签: bundle, deepseek-harness, dsh, multimodal, plugin, subagent, vision

## 简介

Vision subagent delegation for DeepSeek Harness: when the main session model cannot read images, delegate image understanding to a one-shot vision subagent; when the main model is natively multimodal, read directly and skip the subagent.
