# @vladkrutenyuk/event-cache

> 标签: JavaScript

## 简介

Utility for THREE.EventDispatcher to cache event data easy and neat, reducing object creation overhead. One-line get and update cached data. TypeScript support and automatic EventMap inference to keep single source of trust.
