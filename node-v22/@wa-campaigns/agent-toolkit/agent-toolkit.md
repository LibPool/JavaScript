# @wa-campaigns/agent-toolkit

> 标签: agent, cli, mcp, messaging, templates, twilio, whatsapp

## 简介

WhatsApp-branded agent skins for the WhatsApp Campaigns gateway: an MCP server (wa-mcp) and a CLI (wa). A thin alias over @rcs-campaigns/agent-toolkit — same gateway, same tool catalog, WhatsApp as the default channel.
