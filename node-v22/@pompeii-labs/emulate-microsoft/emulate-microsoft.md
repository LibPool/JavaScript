# @pompeii-labs/emulate-microsoft

> 标签: JavaScript

## 简介

Microsoft Entra ID (Azure AD) v2.0 OAuth 2.0 and OpenID Connect emulation with authorization code flow, PKCE, client credentials, RS256 ID tokens, and OIDC discovery.
