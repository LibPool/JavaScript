# @decennium/booapp

> 标签: booapp, bridge, decennium, peqaboo, pet, sdk, types, typescript, webview

## 简介

TypeScript types for the BooApp SDK. The peqaboo runtime is auto-injected into BooApp WebViews; this package provides ambient types for autocomplete and type-checking.
