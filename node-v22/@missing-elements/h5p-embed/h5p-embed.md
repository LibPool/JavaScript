# @missing-elements/h5p-embed

> 标签: cli, elearning, embed, h5p, h5p-embed, h5p-player, h5p-self-hosted, iframe, static-site

## 简介

Self-hosted H5P embeds: writes the H5P embed page as a static site for a player domain of your own, then any site frames it with an iframe and one script line. No H5P server, no third-party service; optional allowlists for package hosts and embedding site
