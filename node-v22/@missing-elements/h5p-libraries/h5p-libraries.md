# @missing-elements/h5p-libraries

> 标签: h5p, h5p-hub, h5p-libraries, h5p-offline-player

## 简介

The H5P hub's runtime libraries for every content type it serves, for <h5p-player>'s `libraries` attribute: one archive per library, which the player fetches as a package needs them, and the whole pack as one .h5p.
