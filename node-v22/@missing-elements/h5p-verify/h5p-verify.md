# @missing-elements/h5p-verify

> 标签: agent-skill, cli, elearning, h5p, headless, playwright, test, verify

## 简介

Plays an .h5p package in a headless browser through h5p-offline-player and reports whether it works: start-up, errors, missing libraries, a screenshot. The last check before a generated package is handed to anyone.
