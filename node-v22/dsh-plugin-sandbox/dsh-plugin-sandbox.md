# dsh-plugin-sandbox

> 标签: capability, cordis, deepseek-harness, dsh, dsh-plugin, isolation, sandbox, security

## 简介

Plugin sandbox for DeepSeek Harness: Run third-party dsh plugins in an isolated capability profile: filesystem, shell, network and env access are gated per plugin before it loads. Name reserved; first release in development.
