# @jsfit/agent-bridge

> 标签: agent, bridge, cli, device, selfbuilder

## 简介

Convenience npm shim for the agent-bridge SelfBuilder device connector — `npx @jsfit/agent-bridge --server … --token …` resolves/installs the Python CLI (pipx / private venv) and execs it.
