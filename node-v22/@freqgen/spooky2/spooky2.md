# @freqgen/spooky2

> 标签: function-generator, generatorx, rife, serial, signal-generator, spooky2, typescript, web-serial

## 简介

TypeScript drivers for Spooky2 signal generators — XM, Gen X and Gen X Pro — over USB serial, in Node.js and the browser.
