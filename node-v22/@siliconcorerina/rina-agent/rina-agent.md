# @siliconcorerina/rina-agent

> 标签: agent, ai, autonomous, code, rina, rina-ai, shell, swe-agent, tool-use

## 简介

Autonomous shell agent powered by RINA AI — reads files, writes patches, searches code, runs commands, fetches URLs, inspects git. MIT, multi-backend (DeepSeek, OpenAI, Anthropic, Mistral) with native function-calling. Resumable sessions, gitignore-aware,
