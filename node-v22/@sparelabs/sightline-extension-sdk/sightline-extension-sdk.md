# @sparelabs/sightline-extension-sdk

> 标签: JavaScript

## 简介

The server SDK for hosted Sightline extensions: defineExtension and serve(), extension-token verification against core's JWKS, ctx.db / secrets / core / log, and ToolResult helpers.
