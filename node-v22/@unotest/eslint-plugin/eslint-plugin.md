# @unotest/eslint-plugin

> 标签: JavaScript

## 简介

ESLint plugin for unotest web DSL scenarios: one `dsl` rule that runs the exact same validator as `unotest-web lint` (parser, vocabulary, linter rules, config severities) and reports its diagnostics through ESLint, plus a flat `recommended` config wired f
