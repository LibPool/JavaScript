# @nimbus-sh/runtime-ruby

> 标签: nimbus, ruby, runtime, wasi, wasm

## 简介

Ruby 3.3.4 (ruby.wasm) for wasm32-wasi, with its stdlib packed in, as a Nimbus runtime package.
