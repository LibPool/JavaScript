# @ozgurguler/trnorm

> 标签: asr, number-to-words, okunuş, sayı, speech, text-normalization, tts, turkish, türkçe

## 简介

Turkish text normalization for speech, in JavaScript: written -> spoken form for TTS, evaluation normalization for ASR (WER/CER), and spoken -> digits. The same output as the Python trnorm.
