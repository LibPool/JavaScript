# @pkcprotocol/active-page-sort

> 标签: active, bitsocial, bump, imageboard, page-sort, pkc, sage

## 简介

Bump-order (active) page sort for pkc-js communities where replies carrying a configured keyword, such as sage, do not bump the thread
