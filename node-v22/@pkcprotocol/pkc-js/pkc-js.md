# @pkcprotocol/pkc-js

> 标签: bitsocial, community, content-addressed, content-sharing, decentralized, decentralized-web, discussion, distributed, forums, ipfs, javascript, nodejs, p2p, peer-to-peer, pkc, pkc-js, social, social-media, social-network, typescript

## 简介

TypeScript SDK for PKC (Public Key Communities), a serverless, decentralized social protocol built on IPFS, IPNS, and libp2p pubsub. Powers all PKC clients: CLI, Electron desktop, and web.
