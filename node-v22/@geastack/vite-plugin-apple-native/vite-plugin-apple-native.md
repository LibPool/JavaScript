# @geastack/vite-plugin-apple-native

> 标签: JavaScript

## 简介

Vite plugin that lowers Apple-native (UIKit/AppKit/MapKit/Metal) JSX into native view construction for Gea Apple targets, plus an empty-IR emitter for native-rendered apps.
