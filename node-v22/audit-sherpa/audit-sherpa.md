# audit-sherpa

> 标签: audit, cli, fix, llm, mcp, model-context-protocol, npm, npm-audit, security, vulnerabilities

## 简介

Guided npm audit: list vulnerabilities in a filterable table and fix them selectively (prod-only, direct-only, or hand-picked). Includes an MCP server for LLM agents.
