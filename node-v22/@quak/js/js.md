# @quak/js

> 标签: announcements, api, client, openapi, quak, smart-home, sonos, speakers, text-to-speech, tts

## 简介

JavaScript/TypeScript client for the Quak API (quak.party): text-to-speech announcements, sounds and clips on Sonos speakers

- 源码仓库：git+https://github.com/quakparty/quak-js.git
- npm 页面：https://www.npmjs.com/package/@quak/js
