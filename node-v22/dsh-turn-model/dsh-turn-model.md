# dsh-turn-model

> 标签: client-plugin, conversation, deepseek-harness, dsh, dsh-plugin, model, turn, ui

## 简介

在 DeepSeek Harness 每个已完成回合的操作行前显示该回合实际使用的模型名（纯文本，无图标）。Show which model answered each completed turn.
