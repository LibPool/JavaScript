# @continuousarchitecture/archi-open-exchange

> 标签: archi, archimate, enterprise-architecture, model-exchange, open-exchange, typescript, xml

## 简介

Convert a parsed Archi ArchiModel into the ArchiMate Model Exchange File Format XML (The Open Group standard, XSD 3.1).
