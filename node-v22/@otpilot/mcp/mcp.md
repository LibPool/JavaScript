# @otpilot/mcp

> 标签: 2fa, ai-agents, claude-code, codex, mcp, model-context-protocol, password-manager, totp

## 简介

OTPilot for AI agents: let Claude Code, Codex, Cursor or any MCP agent sign in and run commands with the accounts you allow — without ever seeing the passwords or 2FA codes.
