# @ostico/bruno-mcp

> 标签: ai-agent, api-client, api-security-testing, api-testing, authorization-testing, bru, bru-files, bru-format, bruno, bruno-mcp, claude, claude-code, cursor, http-client, integration-testing, llm-tools, mcp, mcp-server, model-context-protocol, opencollection, postman-alternative, rest-client, test-automation

## 简介

An MCP server that turns an agent's API testing into files you keep: it authors and edits Bruno collections in place, then runs them — HTTP, WebSocket and gRPC, one identity or many — and reports per-request pass/fail you can re-run in CI.
