# leonui

> 标签: agent, ai, declarative, html, lightweight, no-build, reactive, signals, ui, web-components

## 简介

Typed reactive UI runtime: author plain HTML + ui:* attributes — signals, keyed lists, closed effect-verb catalog, no build step, no vdom. Agent-first: ships with its own skill.
