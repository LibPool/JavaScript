# @jslop/runtime

> 标签: cell, framework, jslop, reactive, runtime, signals

## 简介

Core reactive primitives (cell / derived / effect / batch / untrack / scopes) for the JSlop framework. Tiny, dependency-free, browser- and Node-friendly.
