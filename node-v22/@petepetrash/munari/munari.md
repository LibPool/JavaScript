# @petepetrash/munari

> 标签: dom, html-in-canvas, react-three-fiber, three, ui, webgl

## 简介

Live DOM as physical matter in WebGL — a three.js / react-three-fiber binding that lets a WebGL scene carry the real DOM's pixels as matter.
