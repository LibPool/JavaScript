# @nx-devkit/typescript

> 标签: biome, eslint, monorepo, nx, nx-plugin, nx-preset, oxlint, tsdown, tsgo, typecheck, typescript, vitest, zero-config

## 简介

Preset Nx plugin that infers typecheck, test, lint, format, and build targets from config files you already keep — no project.json required. One-command bootstrap: npx @nx-devkit/typescript init
