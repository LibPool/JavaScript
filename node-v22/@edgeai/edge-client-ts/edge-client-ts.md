# @edgeai/edge-client-ts

> 标签: agent, ai, daemon, edge, fleet, iot, relay, telemetry, typescript, websocket

## 简介

TypeScript edge-client for the Edge AI Agent fleet — pure-npm reimplementation of the Rust `ec` binary with byte-compatible wire protocol.
