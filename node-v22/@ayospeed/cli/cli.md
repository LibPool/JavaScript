# @ayospeed/cli

> 标签: ai, app-builder, ayospeed, cli, mcp, publish, sync

## 简介

The AyoSpeed command line: create projects, ask the AI builder for changes, sync a project's files with a local folder, publish, read logs, and connect AI assistants over MCP.
