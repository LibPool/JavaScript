# @wingsky-1/dsh-plugins-all

> 标签: JavaScript

## 简介

DSH 插件全家桶聚合包：一键安装全部功能插件（notifier / provider-usage / mcp-manager / lan-proxy / verify-isolated / worktree-sidebar）。装它 = 子包 dependencies 拉齐 + 聚合 cordis patch 激活。dsh-gzip / dsh-web-file-preview 等已退役包不再随全家桶分发。
