# @cella-lang/c

> 标签: array, c, cella, formal-verification, integer, malloc, pointer, printf, proof, scanf, string, struct

## 简介

A formally verified C11 subset for the Cella proof checker: integer types with C promotions and conversions, control flow (if, loops, switch, goto), arrays (including multi-dimensional, variable length and const), pointers, malloc, realloc and free, strin
