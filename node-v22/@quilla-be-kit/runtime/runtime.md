# @quilla-be-kit/runtime

> 标签: component-registry, graceful-shutdown, lifecycle, runtime, shutdown, signals, typescript

## 简介

Process runtime: phased ShutdownManager, OS-signal / uncaught-error bridge that owns process.exit, and a transport-agnostic ComponentRegistry.
