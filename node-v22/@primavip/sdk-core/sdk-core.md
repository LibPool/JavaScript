# @primavip/sdk-core

> 标签: JavaScript

## 简介

PRIMA Partner SDK — the reference core: wire types, cohort and token model, availability decoding, listing composition, the booking gate and state machine, error taxonomy, transport policy. No UI, no platform APIs, no private dependencies.
