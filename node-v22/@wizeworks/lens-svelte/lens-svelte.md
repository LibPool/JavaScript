# @wizeworks/lens-svelte

> 标签: profiler, svelte, sveltekit, tracing, web-vitals, wizelens

## 简介

WizeLens for Svelte and SvelteKit apps: links browser calls to server traces, and sends page views and errors from hooks.client.ts and afterNavigate.
