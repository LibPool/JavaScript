# @creatorqsf/yield

> 标签: riot, riot v3, riot v4, riot.js, riotjs, slot, yield

## 简介

`yield` is a complement patch for `Riot.js v4` which lacks some of the features implemented with `<yield />` in `Riot.js v3`.
