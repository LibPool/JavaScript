# @cloudauthn/vfs-sync

> 标签: crdt, file-system-access, google-drive, merge, offline-first, opfs, sync, three-way-merge, vfs

## 简介

Multi-peer folder sync for OPFS, the File System Access API and Node fs — a git-style content-addressed engine with renames, tombstones and mtime conflict resolution.
