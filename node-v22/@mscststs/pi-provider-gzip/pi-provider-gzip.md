# @mscststs/pi-provider-gzip

> 标签: brotli, compression, fetch, gzip, interceptor, latency, performance, pi, pi-extension, pi-package, provider, ttft, zstd

## 简介

Pi extension that compresses model request bodies (gzip, Brotli, Zstandard) to cut time-to-first-token on slow LLM gateways.
