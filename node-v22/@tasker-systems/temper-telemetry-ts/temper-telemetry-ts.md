# @tasker-systems/temper-telemetry-ts

> 标签: JavaScript

## 简介

Shared OpenTelemetry span-export bootstrap + W3C trace-context helpers for Temper's Node hops (temper-ui, eve agents). The TS analog of the Rust temper-telemetry crate.
