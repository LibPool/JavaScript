# @andromanpro/lava-orb

> 标签: animation, canvas, canvas2d, effect, fire, form, frost, ice, input, interactive, liquid, no-deps, orb, particles, range, reactive, slider, survey, temperature, visual

## 简介

Temperature-reactive liquid orb attached to HTML range inputs. Canvas2D, zero dependencies. Ice at min, fire at max, smooth gradient in between.
