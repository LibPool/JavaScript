# @napi-rs/lzma-win32-ia32-msvc

> 标签: Node-API, compress, decompress, lzma, napi, napi-rs, xz

## 简介

lzma / lzma2 / xz compression for Node.js and the browser, backed by pure-Rust lzma-rust2 via https://napi.rs
