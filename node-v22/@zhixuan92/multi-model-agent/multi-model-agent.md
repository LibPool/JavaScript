# @zhixuan92/multi-model-agent

> 标签: agent, claude, codex, delegation, http-server, llm, multi-model, openai

## 简介

Standalone HTTP server for multi-model-agent. Routes tool-invocation work to Claude or Codex sub-agents with async-polling REST dispatch and installable skills for Claude Code, Gemini CLI, Codex CLI, and Cursor.
