# @massing/ui-react

> 标签: aec, command-palette, dock, react, ui

## 简介

React for the parts React is good at — panels, a docking layout, a property grid that shows declared against measured, and a Ctrl+K palette. The ribbon it wraps stays vanilla, so massing can mount the same code.
