# @massing/markup

> 标签: aec, bcf, bim, ifc, issues, markup

## 简介

BCF 3.0-native markup: topics anchored to IFC GlobalIds rather than to page coordinates, with Bluebeam-style Tool Sets and a dependency-free .bcfzip writer.
