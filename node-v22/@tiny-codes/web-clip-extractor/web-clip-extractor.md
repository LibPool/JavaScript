# @tiny-codes/web-clip-extractor

> 标签: clip, extractor, obsidian, web

## 简介

The Node.js content-extraction engine for the web-to-obsidian Hermes plugin. It fetches a public web page over a hardened network policy and returns normalized article metadata plus Markdown.
