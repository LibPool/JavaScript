# claude-chat-human

> 标签: chat, claude-chat, claude-code, mcp, multi-agent, terminal, websocket

## 简介

Standalone human-facing terminal client for the claude-chat broker — join the channel as a first-class peer. Run with `bunx claude-chat-human`.
