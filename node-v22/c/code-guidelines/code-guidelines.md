# code-guidelines

> 标签: agent-skill, ai-coding, claude-code, codex, coding-guidelines, cursorrules, gemini-cli, guardrails, lint, opencode

## 简介

A zero-dependency installer that delivers one explicitly-invoked /code-guidelines skill to Claude Code, Codex, opencode, and Gemini CLI — syncing curated guardrail rules and lint baselines into a target repository.
