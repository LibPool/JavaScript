# capsulemcp

> 标签: agent, ai-tools, anthropic, capsule, capsule-crm, claude, claude-desktop, crm, mcp, model-context-protocol

## 简介

Model Context Protocol server for Capsule CRM. Lets Claude (Desktop, Code, or web Projects via Custom Connector) read and write your CRM in plain English. Covers contacts, opportunities, projects, tasks, timeline activity, structured filters, saved filter
