# codemote-cli

> 标签: cli, coding agents, dev tunnel, ios, ipad, iphone, mobile, remote, remote control, terminal

## 简介

Control your coding setup from your iPhone & iPad — a real terminal, files, and Git, over a secure dev tunnel. Runs anywhere Node runs (VPS, server, any machine), no IDE required.
