# collect-test-cases

> 标签: cases, cli, docs, documentation, e2e, generator, i18n, jest, markdown, monorepo, playwright, readme, screenshots, test, test-cases, test-discovery, test-documentation, testing, vitest

## 简介

Scan Playwright/Vitest/Jest spec files and generate a single Markdown README per app, with optional screenshot galleries and an i18n plugin.
