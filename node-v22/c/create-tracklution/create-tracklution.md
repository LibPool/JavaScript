# create-tracklution

> 标签: ai-agent, claude-code, conversion-tracking, create-tracklution, cursor, mcp, nextjs, server-side-tracking, tracklution, windsurf

## 简介

Install Tracklution server-side conversion tracking. Alias of the `tracklution` package: forwards to its CLI so `npm create tracklution@latest` works. Real install goes via the Tracklution MCP at https://mcp.tracklution.com/mcp. Protocol: https://www.trac
