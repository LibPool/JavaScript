# cloudforge

> 标签: amazon, aws, cloud, cloudfront, engine, hosting, html, minifier, s3, sass, static, template, templates, templating, web, website

## 简介

CloudForge is a super simple, lightweight HTML templating engine built on doT.js with reusable component support, build output minification and lightning fast Sass compilation. It also provides tools to quickly deploy your website to AWS' S3 and CloudFron
