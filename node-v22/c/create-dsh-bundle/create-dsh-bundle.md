# create-dsh-bundle

> 标签: bundle, cli, cordis, create, deepseek-harness, dsh, dsh-plugin, generator, plugin, scaffold

## 简介

Scaffold and verify a DeepSeek Harness (DSH) plugin bundle: zero-dependency, non-interactive, with a built-in --verify check.
