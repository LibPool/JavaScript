# console-components-doc-data-dont-use-me

> 标签: JavaScript

## 简介

这个包用来发布 console-components 的基础组件文档的数据。目前只发布到内网的 npm，方便内部文档站点能够加载、渲染基础组件文档。

- npm 页面：https://www.npmjs.com/package/console-components-doc-data-dont-use-me
