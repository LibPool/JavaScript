# corvid-js

> 标签: browser, database, embedded, hybrid, search, vector, wasm

## 简介

Browser/Worker binding for the corvid embedded database — the engine compiled to wasm32: idiomatic synchronous OOP (in-memory) plus async OPFS persistence via a dedicated Worker
