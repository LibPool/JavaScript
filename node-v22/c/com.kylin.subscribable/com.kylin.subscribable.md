# com.kylin.subscribable

> 标签: collection, observable, property, reactive, subscribable

## 简介

Reactive property system for Unity 6. SubscribableProperty<T>, SubscribableCollection<T>, SubscribableDictionary<TKey,TValue> with LINQ extensions and debug tools.
