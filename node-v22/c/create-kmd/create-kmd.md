# create-kmd

> 标签: claude-code, codex, kmd, knowledge-base, obsidian, qmd

## 简介

Interactive installer for a kmd knowledge base: scaffolds the KB, installs the Claude Code / Codex plugin, and wires up qmd search — with sensible defaults.
