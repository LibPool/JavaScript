# code-extend

> 标签: addon, callback, code-evolve, codeextend, extend, extension, hook, plugin, tap, tapable, twelvetone, typescript

## 简介

Code-Extend is a framework for enabling a codebase to integrate plugins, addons, and extensions.  By using a variety of customizable hook topologies, your architecture will become highly extensible and loosely coupled
