# codeatlas-cli

> 标签: agent, ai, cli, code-index, code-search, codeatlas, context, local-first, mcp

## 简介

CodeAtlas CLI — a local-first AI context engine that scans, parses, and indexes a source tree into a queryable context database for developer tools and AI agents.
