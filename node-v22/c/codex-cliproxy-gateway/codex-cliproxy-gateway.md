# codex-cliproxy-gateway

> 标签: bun, claude, cliproxy, codex, gateway, gemini, openai

## 简介

A cross-platform Bun-powered local gateway that keeps Codex ChatGPT OAuth for native models and routes cliproxy/* models to CLIProxyAPI.
