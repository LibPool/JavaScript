# change-hex-to-rgb

> 标签: Hex, Hex To RGB, RGB, To, color code to RGB

## 简介

This Package is easy to change Hex To RGB.For example: hexToRGB('#ffffff'),result is 255,255,255. Next hexToRGB('#ffffff', .2) is 255,255,255,0.2
