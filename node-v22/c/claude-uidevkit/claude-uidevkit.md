# claude-uidevkit

> 标签: claude, claude-code, devtool, dx, nextjs, overlay, react, screenshot, ui

## 简介

Dev-only in-app overlay: click an element (or drag a box) in your running Next.js app to bundle full context for Claude Code, then fix it with the /uidevkit slash command.
