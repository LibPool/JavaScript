# claudebrew

> 标签: brainstorming, claude-code, cli, harness, installer, sdlc, workflow, worktree

## 简介

ClaudeBrew — a full software-development lifecycle as a suite of Claude Code skills (brainstorm → worktree → requirement → design → code → test → ship), installed into your Claude Code environment by the `claudebrew` CLI.
