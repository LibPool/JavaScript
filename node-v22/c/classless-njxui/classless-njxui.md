# classless-njxui

> 标签: classless, classless-css, css, css-variables, dark-theme, drop-in, no-build, no-class, pico-alternative, semantic-html, stylesheet, themes, water-css-alternative, zero-dependencies

## 简介

Classless CSS for plain semantic HTML — zero class names, zero dependencies, zero build step. 9 themes via one data-theme attribute, ~7 KB gzip.
