# cituna-mcp

> 标签: aeo, ai-visibility, cituna, geo, google-search-console, mcp, modelcontextprotocol, seo

## 简介

MCP server for Cituna: daily AI-visibility tracking (per-engine citations, positions, and the answer receipts), audits, gaps, and live Google Search Console data, for Claude and other MCP clients.
