# chrome-extension-oauth2

> 标签: JavaScript

## 简介

This package aims to be, as much as possible, a "batteries-included" solution to [OAuth 2.0](https://oauth.net/2/) authentication in extensions for Chromium-compatible browsers such as Chrome and Edge.
