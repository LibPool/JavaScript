# candidate-pool

> 标签: a-share, quant, stock-screener, 尾盘选股, 选股, 量化

## 简介

A股短线选股工具包：次日候选池初筛（R01 量能验证突破 + R07 板块内补涨）与尾盘选股（14:50 口径），数据取自腾讯公开行情接口，输出单文件双语 HTML 报告
