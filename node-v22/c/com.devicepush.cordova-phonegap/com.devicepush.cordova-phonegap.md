# com.devicepush.cordova-phonegap

> 标签: APN, Android, Cordova, FCM, PhoneGap, iOS, notification, push

## 简介

This plugin is for use with Cordova and PhoneGap, and allows your application to receive push notifications on Android and iOS devices.
