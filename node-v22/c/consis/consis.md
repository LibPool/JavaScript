# consis

> 标签: JavaScript, Node.js, clone, cloning, consis, consistency, deep cloning, http request, library, performance, requester, type casting, utility

## 简介

A small Node.js library for type casting, http/s requests, object cloning, and other math, object, string, image, time and uuid helpers
