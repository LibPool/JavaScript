# claude-log-compressor

> 标签: anthropic, claude, claude-code, gradle, jest, log-compression, mcp, npm, pytest, token-optimization

## 简介

MCP server that intercepts build/test/install commands, runs them, and returns a compressed summary to Claude — dramatically reducing context consumption during iterative build/test loops.
