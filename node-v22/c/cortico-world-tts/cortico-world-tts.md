# cortico-world-tts

> 标签: coopanion, cortico, cortico-world, openai-compatible, qwen, speech-synthesis, text-to-speech, tts

## 简介

文本转语音（Text to Speech）—— 给 Coopanion 桌宠的 cortico World 扩展：把文字合成为语音，音频落盘并作为附件交回对话。 / A cortico World extension that turns text into speech through a configurable TTS API and returns the audio as a conversation attachment.
