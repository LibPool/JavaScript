# changesafe

> 标签: ai-safety, ci, cli, guardrails, infrastructure, kubernetes, policy, terraform

## 简介

Gate AI-proposed infrastructure changes from the terminal or CI: deterministic policies, honest exit codes, hashed receipts. The gate itself never calls a model.
