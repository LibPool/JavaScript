# consilium

> 标签: a11y, accessibility, ai-review, audit, axe-core, cli, playwright, qa, screenshots, seo, visual-testing

## 简介

Multi-angle visual & technical QA for websites, local dev servers, and built output — real screenshots, axe-core accessibility, mobile/console/network checks, optional AI review lenses. Honest, evidence-cited reports.
