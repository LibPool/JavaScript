# cpnjs

> 标签: colored-petri-net, comms-java, cpn, cpnjs, cpntools, petri-net, simulation, socket, tcp

## 简介

A Node.js library to interact with CPN Tools models via TCP, enabling real-time Petri Net simulation, data exchange, and control.
