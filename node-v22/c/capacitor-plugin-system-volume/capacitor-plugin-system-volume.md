# capacitor-plugin-system-volume

> 标签: audio, capacitor, capacitor-plugin, cordova, hardware-volume, ionic, ios, mpvolumeview, native, plugin, system-volume, volume

## 简介

Capacitor plugin for system volume + media routing: a native MPVolumeView slider and AirPlay button on iOS, and AudioManager volume + a Cast device picker on Android, so an on-screen slider stays in sync with the hardware buttons.
