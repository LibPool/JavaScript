# cardano-tessera-respond-react

> 标签: cardano, cip-179, custom-element, governance, poll, react, survey

## 简介

React bindings for the <tessera-respond> CIP-179 survey widget: one typed component that registers the element, syncs props as DOM properties, and delivers the tessera:* events as onResponse / onChange / onInvalid callbacks. Works identically on React 18
