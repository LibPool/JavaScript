# cross-model-orchestrate

> 标签: agents, ai, claude, claude-code, codex, llm, multi-agent, orchestration, rate-limits, subagents

## 简介

Run agent fan-outs across two AI subscriptions at once: pick each subagent's model by complexity, length and token efficiency against live usage limits, spend Codex before Claude, and always grade work on the vendor that did not produce it.
