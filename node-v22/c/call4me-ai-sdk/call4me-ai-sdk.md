# call4me-ai-sdk

> 标签: agents, ai, ai-sdk, call4me, mcp, phone, phone-calls, tools, vercel-ai-sdk, voice

## 简介

Phone call tools for the Vercel AI SDK: your agent calls businesses to book, cancel, ask and wait on hold. Backed by the call4me MCP server.
