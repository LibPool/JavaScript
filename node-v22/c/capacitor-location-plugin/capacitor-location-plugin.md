# capacitor-location-plugin

> 标签: capacitor, native, plugin

## 简介

Capacitor plugin for location-services status (with live change events) and fake / mock GPS (spoofing) detection on Android & iOS, including a deep last-known check that stays positive through a lingering fake fix.
