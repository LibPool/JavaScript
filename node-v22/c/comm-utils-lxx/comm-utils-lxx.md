# comm-utils-lxx

> 标签: utils

## 简介

1. 编辑代码 2. `npm login` (随后输入账户和密码及邮箱) 3. 修改 package 中的 `version` 版本号 4. `npm publish` 发布 (如果安装了 cnpm 记得切换到 npm 源，OTP密码会发送到邮箱)
