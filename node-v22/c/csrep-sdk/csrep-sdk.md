> 标签: anticheat, api, counter-strike, cs2, csrep, csrep.gg, demo, reputation, sdk, trust-factor

## 简介

Cliente TypeScript/JavaScript no oficial para la API de CSRep.gg. Sube demos de CS2 para su análisis anticheat y consulta la reputación de los jugadores.
