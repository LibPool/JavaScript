# create-yt-dialogue-kit

> 标签: ai, antigravity, dialogue, remotion, video-production, voicevox, youtube

## 简介

YouTube非属人対談動画の制作環境を一発セットアップ。Antigravity + VOICEVOX + Remotionで全自動動画制作パイプラインを構築します。
