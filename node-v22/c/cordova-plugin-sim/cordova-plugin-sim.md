> 标签: carrier, cordova, cordova-android, cordova-ios, cordova-windows, ecosystem:cordova, imei, mcc, mnc, sim, telephonenumber, uicc

## 简介

A plugin to get the device's SIM data (carrier name, mcc mnc, country code, telephonenumber, imei, etc)
