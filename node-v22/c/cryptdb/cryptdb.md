# cryptdb

> 标签: Backend, Database, Encryption, JavaScript, Single-Key Encryption

## 简介

My own attempt to create a simple, in-app encrypted database soloution using JavaScript. With this database, one can orginize documents into collections, all stored in one database. Every Document and Collection is represented as a single encrypted utf-8
