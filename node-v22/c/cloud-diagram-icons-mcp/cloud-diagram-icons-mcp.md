# cloud-diagram-icons-mcp

> 标签: architecture-diagrams, azure, diagrams, drawio, dynamics-365, entra, icons, mcp, microsoft, microsoft-fabric, model-context-protocol, power-platform

## 简介

MCP server that gives LLMs exact draw.io style strings for cloud service icons (Microsoft first). Compose with the official draw.io MCP tooling to generate diagrams with real portal icons.
