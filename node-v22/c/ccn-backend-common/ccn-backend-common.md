# ccn-backend-common

> 标签: ccn, cube, logging, microservice, mongodb, mongoose, shared

## 简介

Shared backend functions for CCN microservices: multi-database connections, CCN central-logging wrapper, cube identity resolution, HTTP client and Express building blocks.
