# codecmedia

> 标签: audio, codec, conversion, ffmpeg, image, media, metadata, probe, validation, video

## 简介

Synchronous Node.js media probing, validation, metadata, extraction and conversion with a zero-dependency core and optional FFmpeg/ffprobe integration.
