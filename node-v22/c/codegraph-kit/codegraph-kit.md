# codegraph-kit

> 标签: ai-agent, code-navigation, codegraph, knowledge-graph, llm, mcp, model-context-protocol, sqlite, typescript

## 简介

Standalone code knowledge-graph MCP server for TypeScript/JavaScript repos: a built-in indexer, a symbol-aware edit loop as first-class agent tools, and KG-only coding agents for Claude Code, OpenCode, Cursor, Codex CLI and Code Puppy.
