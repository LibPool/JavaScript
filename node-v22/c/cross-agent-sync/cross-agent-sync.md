# cross-agent-sync

> 标签: agent, claude-code, cli, codex, context, cursor, handoff, kiro, mcp, opencode, session, trae

## 简介

跨 agent 会话同步：换 agent 或新开会话时，一条命令把上次的上下文、原始提问（含图片）搬过来。支持 Claude Code / Codex / Cursor / OpenCode / Kiro / Trae 与自定义 agent。
