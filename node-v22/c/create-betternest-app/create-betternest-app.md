# create-betternest-app

> 标签: authentication, better-auth, cli, docker, drizzle, fly, monorepo, mysql, nestjs, nextjs, postgresql, prisma, railway, render, sqlite, starter, tailwindcss, turborepo, vercel

## 简介

Scaffold a production-ready Next.js + NestJS + Better Auth monorepo. Zero CORS, 6 DB combos (Prisma/Drizzle, PostgreSQL/MySQL/SQLite), deploy anywhere (Vercel + Railway/Fly.io/Render/VPS) with Docker.
