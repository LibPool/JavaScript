> 标签: class-variance-authority, component-library, composition, css, css-in-js, cva, design-system, frontend, polymorphic, react, react-components, react-library, styled-components, styling, tailwind, type-safe, typesafe, typescript, ui, utility-first, variants

## 简介

A powerful, type-safe component styling library for React that combines the best of CSS-in-JS, utility-first CSS, and component composition. Features include variant support, polymorphic components, and seamless TypeScript integration.
