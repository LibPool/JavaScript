# code-coverage

> 标签: CSS and JS Code Coverage, Code Coverage, Ease Manual Testing, Manual Testing

## 简介

Find unused CSS and JS code. When you load or run a page, the app tells you how much code was used, versus how much was loaded. You can reduce the size of your pages by only shipping the code that you need
