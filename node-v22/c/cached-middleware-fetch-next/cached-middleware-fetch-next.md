# cached-middleware-fetch-next

> 标签: cache, edge, fetch, middleware, nextjs, proxy, runtime-cache, vercel

## 简介

A Next.js fetch wrapper for proxy.ts (middleware) that uses Vercel Runtime Cache as its caching backend
