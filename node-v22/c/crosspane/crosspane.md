# crosspane

> 标签: console, debugging, devtools, in-app-browser, qa, remote-debugging, session-replay, webview

## 简介

Debug web screens where devtools can't reach — a hub dashboard for live @crosspane/agent sessions (webviews, in-app browsers, kiosks) and offline capture replay.
