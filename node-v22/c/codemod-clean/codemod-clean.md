# codemod-clean

> 标签: architecture-analysis, ast, babel, code-cleanup, codemod, console-cleanup, coupling-detection, dependency-graph, import-optimization, javascript, monorepo, orphan-detection, refactoring, shared-packages, static-analysis, typescript, unused-code, unused-imports, unused-packages, unused-variables, vue

## 简介

Monorepo-aware static analysis and codemod engine for JavaScript/TypeScript/Vue. Detect unused code, optimize imports, analyze dependency graphs, and identify architectural hotspots across packages.
