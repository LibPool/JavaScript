# cdp-events-tracker

> 标签: analytics, cdp, customer-data-platform, events, nmg-digital, tracking

## 简介

A lightweight TypeScript library that collects and sends user interaction data to your Customer Data Platform (CDP). Supports event queuing, batching, and Beacon API for optimal delivery.
