# create-pipeline

> 标签: Ahmad Awais, ahmadawais, create-pipeline

## 简介

Create AI agents pipeline. A command-line interface (CLI) tool that helps you quickly set up new AI agent projects using the ⌘ Langbase SDK. It streamlines the process of creating a new project, installing dependencies, and setting up a basic example.
