# convoy-ai

> 标签: agents, ai, anthropic, llm, multi-agent, openai, orchestration, router, streaming, tool-calling

## 简介

A lightweight, production-grade framework for building multi-agent LLM systems: intelligent LLM routing, a uniform agent loop, provider abstraction, streaming, memory and cost tracking.
