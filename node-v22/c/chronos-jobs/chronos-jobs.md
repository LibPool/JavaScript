# chronos-jobs

> 标签: background, background-jobs, background-tasks, cron, cronjob, delayed, job, job-queue, jobs, mongodb, nodejs, persistent, queue, recurring, runner, schedule, scheduler, scheduling, task, typescript

## 简介

A lightweight, persistent job scheduler for Node.js using a MongoDB backend. Supports cron syntax, delayed jobs, and human-readable intervals.
