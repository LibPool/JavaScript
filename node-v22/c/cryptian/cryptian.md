# cryptian

> 标签: 3des, aes, blowfish, cast, cbc, cfb, cipher, crypto, ctr, des, encryption, gost, legacy, libmcrypt, mcrypt, migration, ofb, padding, php, pkcs7, rijndael, serpent, tripledes, twofish

## 简介

MCrypt-compatible cipher suite for Node.js: reads and writes data from PHP mcrypt, including Rijndael 192/256-bit blocks and legacy ciphers OpenSSL dropped
