# cordova-plugin-uniquedeviceid

> 标签: Windows, android, cordova, cordova-android, cordova-ios, cordova-wp8, device, ecosystem:cordova, id, ios, phone, phonegap, unique, uuid, wp

## 简介

PhoneGap / Cordova unique device id (UUID) plugin for Android, iOS and Windows Phone 8. Remains the same after app uninstall.
