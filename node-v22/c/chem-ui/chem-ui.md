# chem-ui

> 标签: ChemUI

## 简介

本项目是基于化学展示的组件库 ## 目录架构 - components：存放组件 - docs：存放文档 - src：存放开发时源码 ## 使用方式 ```bash npm i chem-ui yarn add chem-ui ``` ## Example ```bash cd docs yarn install yarn dev ```
