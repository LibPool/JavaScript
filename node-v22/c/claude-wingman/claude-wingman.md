# claude-wingman

> 标签: agents, ai-agents, claude, claude-cli, claude-code, cross-platform, cross-platform-testing, developer-experience, dispatch, linux, macos, multi-machine, paseo, productivity, remote, remote-development, ssh-alternative, tailscale, windows, wsl

## 简介

Use all your computers from one Claude Code session: hand work to Claude agents on your other Mac, Windows or Linux machines, over Tailscale. No SSH, one command to set up.
