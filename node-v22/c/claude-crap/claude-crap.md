# claude-crap

> 标签: claude-code, claude-code-plugin, crap-index, deterministic, mcp, mcp-server, mutation-testing, quality-assurance, quality-gate, sarif, sast, shift-left, technical-debt, tree-sitter

## 简介

Deterministic QA plugin for Claude Code — CRAP index, Technical Debt Ratio, tree-sitter AST, SARIF 2.1.0, hooks, and a local Vue dashboard.
