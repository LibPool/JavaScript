# copilot-llm-proxy

> 标签: anthropic, claude-code, cli, codex, copilot, github-copilot, llm, openai, proxy

## 简介

Local proxy that exposes GitHub Copilot's LLM backend via OpenAI- (chat-completions + responses) and Anthropic-compatible (messages) HTTP APIs. Use Claude Code CLI, Codex CLI, and Codex Desktop with your Copilot subscription.
