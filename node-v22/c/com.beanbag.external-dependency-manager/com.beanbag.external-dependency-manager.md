# com.beanbag.external-dependency-manager

> 标签: Android, Cocoapods, Dependency, Google, Gradle, Unity, Unity Package Manager, vh-name:External Dependency Manager for Unity, vh-name:external-dependency-manager, vh-name:play-services-resolver, vh-name:unity-jar-resolver

## 简介

External Dependency Manager for Unity (EDM4U) can be used by any Unity plugin that requires Android specific libraries (e.g. AARs), iOS CocoaPods, version management of transitive dependencies, and/or management of Unity Package Manager registries.
