# cortico-world-qq-voice

> 标签: asr, qq, tts, voice

## 简介

QQ 语音收发功能包（依赖 cortico-world-qq-lite）。TTS/ASR 供应商注册表（native/custom/local），保留语音收发，剔除 voxcpm 侧车与语音电话。
