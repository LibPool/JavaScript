# camelcase-es5

> 标签: camel, camel-case, camel-case-es5, camelcase, case, convert, dash, dot, hyphen, pascal-case, pascalcase, separator, string, text, underscore

## 简介

Convert a dash/dot/underscore/space separated string to camelCase or PascalCase: `foo-bar` → `fooBar`
