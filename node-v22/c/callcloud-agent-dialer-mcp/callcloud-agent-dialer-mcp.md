# callcloud-agent-dialer-mcp

> 标签: callcloud, claude, contacts, dialer, lead-lists, mcp, model-context-protocol, outbound, sales, telephony, voip

## 简介

MCP server for CallCloud: give an AI agent a phone line. Dials real numbers, screens out answering machines, and connects live humans to your browser over WebRTC. Also manages the CallCloud web dialer's data: lead lists, contacts, draft campaigns, perform
