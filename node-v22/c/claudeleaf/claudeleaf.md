# claudeleaf

> 标签: automation, claude, collaboration, latex, mcp, overleaf, sharejs

## 简介

Bring Claude (and any agent) into Overleaf: a reliable bridge that drives the Overleaf web editor in real time via an SDK, CLI, and MCP server.
