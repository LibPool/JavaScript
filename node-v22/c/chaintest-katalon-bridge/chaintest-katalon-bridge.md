# chaintest-katalon-bridge

> 标签: chaintest, ci, katalon, katalon-studio, test-automation, test-report, testing

## 简介

Zero-touch ChainTest reporting for Katalon Studio, plus an optional real-time dashboard (ChainLP) with build history and trends - install with one command, no plugin, no manual Test Listener authoring.
