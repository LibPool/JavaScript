# coc-token-refresher

> 标签: api-key, brawl-stars, clash-of-clans, clash-royale, ip, refresh, supercell, token, token-refresh

## 简介

This is a module to generate a fresh API key for Supercell games for your current IP. It supports Clash Royale, Clash of Clans and Brawl Stars.

## 官网

- npm 页面：https://www.npmjs.com/package/coc-token-refresher

- 2.0.0

- npm registry：https://registry.npmjs.org/coc-token-refresher
