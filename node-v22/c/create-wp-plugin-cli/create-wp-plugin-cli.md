# create-wp-plugin-cli

> 标签: cli, generator, gutenberg, interactivity-api, phpunit, plugin, psr-4, scaffold, woocommerce, wordpress, wordpress-plugin, wp-cli, wpcs

## 简介

Interactive scaffold generator for modern WordPress plugins — static bootloader with a Services locator, PSR-4, selectable WPCS/VIP standards, PHPUnit + Brain Monkey, Jest, Playwright, WP-CLI, WooCommerce, Interactivity API, and CI out of the box
