# create-site-starter

> 标签: app-router, cli, cms, cookie-consent, create-app, gdpr, generator, nextjs, sanity, sanity-io, scaffold, tailwindcss, template

## 简介

Interactive CLI that scaffolds a production-grade Next.js App Router site with an embedded Sanity Studio, modular sections, mock-data fallback, and a pre-built legal compliance suite.
