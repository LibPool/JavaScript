# cuttledb

> 标签: agents, database, embeddings, knn, local-first, rag, real-time, redis, sqlite, vector-search, wasm

## 简介

CuttleDB JS/TS client — embedded realtime database with vector search, WAL durability, and event streaming. Works in Node (TCP) and the browser (in-process WASM).
