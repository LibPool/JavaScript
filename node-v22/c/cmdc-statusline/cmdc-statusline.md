# cmdc-statusline

> 标签: cli, cmdc, command-code, commandcode, mod, status-line, statusline

## 简介

A status line mod for Command Code (cmdc): model, gradient context bar, cache hit rate, session cost, output speed, sub-agent usage, session name and git state.
