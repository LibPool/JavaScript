# cesium-wind-layer-3d

> 标签: 3d, cesium, cesiumjs, gpgpu, particles, webgl2, wind, wind-field

## 简介

A WebGL2 GPU-accelerated 3D wind field layer for CesiumJS, using 3D textures and particle advection.
