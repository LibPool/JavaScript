# chatgpt-local-mcp

> 标签: ai, chatgpt, claude, filesystem, llm, local, mcp, model-context-protocol

## 简介

Give ChatGPT (or any MCP client) agentic access to your local project folder — filesystem, terminal, git, processes, clipboard, archives and more — over a secure cloudflared tunnel. Folder-scoped by default for security.
