# crawlgraph-mcp

> 标签: ahrefs-alternative, backlinks, claude, common-crawl, crawlgraph, cursor, gap-analysis, mcp, model-context-protocol, seo

## 简介

MCP server for the CrawlGraph backlink-intelligence API (Common Crawl webgraph). Backlink lookups, competitor gap analysis, and a ready-made outreach-target finder for any MCP client.
