# clines

> 标签: ai, cli, cloc, cloc-alternative, code-churn, code-comments, code-complexity, code-duplication, code-hotspots, code-metrics, code-quality, codebase-metrics, comment-drift, complexity, context-window, copy-paste-detector, count, developer-tools, duplicate-code, duplication, git-blame, hotspots, lines, lines-of-code, loc, nodejs, refactoring, stale-comments, static-analysis, technical-debt, token, token-count, token-estimate, tokens, typescript

## 简介

Count lines of code per language, find duplicate code, rank files by code complexity, estimate the token count of a repository for AI agents, find stale comments, and decide which files are worth refactoring. A modern cloc alternative.
