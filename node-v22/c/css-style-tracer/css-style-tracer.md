# css-style-tracer

> 标签: ai, cascade, cdp, chrome-devtools-protocol, css, debugging, devtools, layout, mcp, specificity, style

## 简介

Trace the CSS cascade chain of any element via Chrome DevTools Protocol: find the winning rule, its file:line source, what it overrides, and inherited styles. CLI + MCP server + AI skill. Fixes 'AI edits CSS but it does not take effect' by giving agents r
