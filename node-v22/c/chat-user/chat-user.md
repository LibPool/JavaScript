# chat-user

> 标签: JavaScript

## 简介

一个用户即时聊天框,用户端.接口props: {sname: String//客服姓名,name: String//用户姓名,list: Array //后台获取的聊天记录必须含有: 发送人uname 发送时间newTime 消息内容newText},按钮点击事件接口onSendOut
