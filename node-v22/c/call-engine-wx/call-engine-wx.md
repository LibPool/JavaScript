# call-engine-wx

> 标签: call, miniprogram, rtc, signaling, trtc, tuicallengine, voip, wechat

## 简介

Pure-JS TUICallEngine implementation for WeChat Mini Program (no WASM). API-compatible with @trtc/call-engine-lite-wx.
