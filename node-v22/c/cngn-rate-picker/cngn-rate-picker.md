# cngn-rate-picker

> 标签: crypto, exchange-rate, failover, forex, naira, ngn, quidax, stablecoin, typescript, usdc, usdt

## 简介

Resilient cNGN <-> USD-stablecoin (USDT, USDC, and any future USD-backed coin) exchange rate library with multiple providers and automatic failover.
