# changelg

> 标签: changelog, changelog-generator, cli, conventional-commits, devtools, git, keep-a-changelog, release, release-notes, semver, zero-dependency

## 简介

Generate a CHANGELOG from your git history (Conventional Commits). Zero dependencies — no Rust, no config file, no GitHub token.
