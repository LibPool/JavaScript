# color-zone

> 标签: color-input, color-picker, color-selector, color-zone, eyedropper, gradient-picker, hex, hsl, hsv, react, react-color-picker, rgb, typescript, ui-component

## 简介

A zero-dependency React color picker with HSV, RGB, HSL, HEX, gradient support, EyeDropper API, and a headless useColorPicker hook for custom UIs.
