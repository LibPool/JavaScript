# claude-trace-v2

> 标签: anthropic, api, claude, claude-code, debugging, logging, observability, proxy, trace

## 简介

Record Claude Code v2 traffic (request bodies, system prompts, tools, streamed responses) into a JSONL log and a self-contained HTML viewer, by proxying ANTHROPIC_BASE_URL through a local HTTP server.
