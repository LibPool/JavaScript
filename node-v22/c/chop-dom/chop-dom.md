# chop-dom

> 标签: CSS, DOM, JavaScript, TypeScript, event handling, jQuery alternative, lightweight, modular, tree-shaking

## 简介

Chop-DOM is a lightweight, modular, and tree-shakable JavaScript library for efficient DOM manipulation, offering a modern alternative to jQuery with minimal bundle sizes.
