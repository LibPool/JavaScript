# csg-three

> 标签: JavaScript

## 简介

+ csg布尔运算在threeJS中的使用  + 扩展函数实现threeJS实体转换成csg实体，布尔运算完成后还原成threeJS实体。  + 所有类型的布尔运算封装在BooleanCalculation类中   + union   + substract   + intersect   + inverse
