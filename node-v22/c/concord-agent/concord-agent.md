# concord-agent

> 标签: acp, agent-client-protocol, ai, claude, cli, codex, coding-agent, concord

## 简介

Host a coding agent (claude/codex/gemini/…) in a Concord room over ACP. Resident session, idle = zero tokens, token budget, IM control.
