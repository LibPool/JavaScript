# cipetpet

> 标签: browser, cipetpet, onnx, speech, stt, tts, turkish, wasm

## 简介

Turkish speech in the browser: Antalia-2 Mini and EMA Lightning (text to speech) and Duyu-small (speech recognition) running on ONNX Runtime Web (WASM), with the model files wrapped in .cpet packs.
