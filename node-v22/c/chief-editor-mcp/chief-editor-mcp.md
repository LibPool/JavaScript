# chief-editor-mcp

> 标签: ai-detection, claude, llm-detection, mcp, model-context-protocol, slop-detector, text-analysis, writing-analysis

## 简介

MCP server for the Chief Editor AI slop detector — analyses text for AI-generated writing patterns and returns sloppiness, originality, and hype scores with per-pattern annotations.
