# clickpesa-nodejs-sdk

> 标签: api, clickpesa, express, fintech, nestjs, nextjs, payments, sdk, tanzania

## 简介

Production-grade Node.js SDK for the ClickPesa API — collections, payouts, BillPay, hosted links, webhooks and more. Works with Express, NestJS, Next.js and every Node app.
