# cortico-world-onebot

> 标签: coopanion, cortico, cortico-world, lagrange, llonebot, napcat, onebot, onebot-v11, qq, snowluma

## 简介

让TA使用QQ。连接到你的napcat或者snowluma，然后在QQ上和TA聊天吧。就像直接用QQ一样，使用几乎所有功能。
