# codebase-search-mcp

> 标签: ai, code-search, mcp, model-context-protocol, ripgrep

## 简介

Read-only MCP server exposing ripgrep content search, file glob and file read over a checked-out code base (root-locked). Grounds agent answers in the actual source.
