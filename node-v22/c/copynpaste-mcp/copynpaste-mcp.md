# copynpaste-mcp

> 标签: converter, copynpaste, discord, markdown, mcp, model-context-protocol, slack, text-formatting, whatsapp

## 简介

MCP server for copynpaste: convert text formatting between apps via the copynpaste API (Slack, Discord, WhatsApp, Telegram, Reddit, Teams, Markdown, Google Docs, Notion).
