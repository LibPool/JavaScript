# cabal-ui-cloning-kit

> 标签: claude-skill, cloning, design, design-system, frontend, html, ui

## 简介

A distilled, typed playbook for cloning UI designs at top-1% fidelity — brand-energy motion profiles, typography matching, illustration zones, the Functionality Contract, the weakness catalog, and pre/post-build checklists. Doubles as a Claude skill.
