# claude-lanes

> 标签: agent-teams, anthropic, claude, claude-code, cli, deepseek, glm, kimi, model-switcher, openai, provider, proxy, router, vllm

## 简介

Per-window provider router for Claude Code — pin a model to each terminal lane. Team mode (leader/teammates on different providers), OpenAI protocol translation, zero daemon.
