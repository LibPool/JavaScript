# chess960

> 标签: chess, chess-960, chess960, fen, fischer random chess, fischer-random, freestyle chess, generator

## 简介

Chess960 (Fischer Random Chess) start position generator: all 960 positions by number, random positions, X-FEN and Shredder-FEN output, and a CLI.
