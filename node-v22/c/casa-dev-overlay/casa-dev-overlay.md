# casa-dev-overlay

> 标签: JavaScript

## 简介

A local-dev overlay for GOV.UK CASA apps. Visualises the journey graph, inspects the JourneyContext, jumps to any waypoint, and auto-fills with reusable presets (compatible with spiderplan personas).
