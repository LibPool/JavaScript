# charles-create

> 标签: JavaScript

## 简介

## 简介  一个创建node mvc模板和web模板的cli ## 全局安装 ```  npm install -g charles-create ``` ## 项目安装 ```  npm install --save-dev charles-create ``` ## 快速开始  ### 本地安装    package.json scripts 添加命令    ```     "create": "t-create"    ```  ### 全局安装      终端运行         t-creat
