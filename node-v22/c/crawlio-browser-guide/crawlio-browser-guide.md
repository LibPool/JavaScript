# crawlio-browser-guide

> 标签: accessibility-snapshot, ai, browser-guide, chrome-extension, crawlio, mcp, model-context-protocol, native-messaging, read-only

## 简介

Companion CLI and read-only MCP server for Crawlio Browser Guide: install the native helper with one command, and let Claude Code or Codex see the browser page the user chose to share, with no way to act on it.
