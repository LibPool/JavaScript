# cordova-plugin-sms-retriever-api

> 标签: Google SMS Retriver, Retriever API, cordova-android, ecosystem:cordova, read SMS

## 简介

An cordova plugin that allows your app to read SMS by using Google's SMS Retriever API for Android devices.
