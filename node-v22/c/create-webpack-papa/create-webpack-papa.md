# create-webpack-papa

> 标签: JavaScript

## 简介

生成基于[webpack-papa-script](https://github.com/nonjene/webpack-papa-script)的项目结构的cli工具。 [webpack-papa-script](https://github.com/nonjene/webpack-papa-script) 是一个帮助前端开发更轻易的开发到部署的工程化工具。
