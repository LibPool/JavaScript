# create-openclawd

> 标签: agentic-os, aios, claude-code, create, openclawd, scaffold

## 简介

Scaffolder for OpenClawd OS. Run `npm create openclawd@latest <dir>` to drop the whole agentic OS into a new folder.

## 官网

- npm 页面：https://www.npmjs.com/package/create-openclawd

- npm registry：https://registry.npmjs.org/create-openclawd
- Node 要求：>=20
