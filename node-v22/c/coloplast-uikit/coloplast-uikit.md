# coloplast-uikit

> 标签: JavaScript

## 简介

Accessible, headless-ish Vue 3 UI components built with TypeScript and Tailwind-friendly markup.   This README documents the **Accordion** component pair: `<Accordion>` and `<AccordionItem>`.
