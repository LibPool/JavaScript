# capabilityos-mcp

> 标签: agent-governance, ai-agents, capabilityos, llm-tools, mcp, model-context-protocol

## 简介

MCP bridge for CapabilityOS — connect any MCP-compatible AI agent (Claude, Cursor, …) to the CapabilityOS governance layer: discover, register, and invoke governed API capabilities.
