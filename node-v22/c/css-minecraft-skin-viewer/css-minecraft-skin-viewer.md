# css-minecraft-skin-viewer

> 标签: 3d, animation, cape, component, css, effects, face, minecraft, minecraft-skin, nextjs, npm, outline, pixelated, player, pose, react, skin, skin-viewer, skull, spin, ssr, typescript, viewer, walking, wind

## 简介

A pure CSS 3D Minecraft skin viewer for React. Supports poses, animations, effects, outline, skull, cape, face views. SSR-compatible. Zero runtime dependencies.
