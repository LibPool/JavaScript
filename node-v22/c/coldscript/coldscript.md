# coldscript

> 标签: coldscript, hotscript, numbers, objects, runtime, strings, tuples, type-level, typed, typescript, utilities

## 简介

Runtime companions to HotScript - typed JavaScript utilities for strings, numbers, tuples, and objects whose return types are computed by HotScript.
