# cvdplate

> 标签: color-vision, colorblind, cvd, deuteranopia, ishihara, plate, protanopia, pseudoisochromatic, test, tritanopia

## 简介

Generate Ishihara-style pseudoisochromatic color-vision test plates — a digit hidden in a dot field that collapses under protanopia, deuteranopia, or tritanopia. Reproducible from a seed. Built on the OpticQuiz engine (Machado 2009 + CIEDE2000).
