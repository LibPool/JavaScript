# chord-lyric

> 标签: chord, chord-sheet, guitar, headless, lead-sheet, lyrics, music, piano, react, tabs, transposition, vue

## 简介

A lightweight, framework-agnostic formatting engine and component library for rendering synchronized chord sheets and lead sheets across Vue 3, React, and Vanilla TypeScript/JavaScript.
