# create-dda-stack

> 标签: cli, create-react-native-app, expo, module-federation, react-native, scaffold, superapp

## 简介

Scaffold a React Native project (RN CLI, Expo, or Superapp/Module Federation host+remote) with navigation, React Query, an Axios client, env config, and your choice of package manager.
