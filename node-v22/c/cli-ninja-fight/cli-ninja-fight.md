# cli-ninja-fight

> 标签: ascii, cli, curses, fighting-game, game, ninja, terminal, tui

## 简介

A terminal 1v1 ninja fighting game (punch / kick / grab / parry) rendered in pure ASCII, inspired by Shadow Fight.
