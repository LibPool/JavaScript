# cohorte

> 标签: agents, claude, claude-code, codex, cursor, gemini-cli, multi-agent, opencode, pipeline

## 简介

Portable, stack-agnostic multi-agent development pipeline for Claude Code, Codex CLI, Cursor, Gemini CLI and OpenCode — install the core, run /cohorte-init-pipeline, and it adapts to your project's stack.
