# cortico-world-qq-better

> 标签: cortico-world, napcat, onebot, qq

## 简介

Cortico World 扩展：QQ（OneBot v11 / NapCat）适配器，移植自 fat-fish qq_bot 运行时，支持反向与正向 WebSocket 双模式，并增量集成了 Cortico 内置能力（发送确认门、控制台、环境提示词、通知、可选视觉识别）。
