# cicd_gigena

> 标签: angular, aws, cicd, cloudfront, github-actions, ionic, s3, scaffold

## 简介

Genera automáticamente los GitHub Actions de deploy a DEV/QA/PROD (S3 + CloudFront) para proyectos frontend Angular/Ionic.
