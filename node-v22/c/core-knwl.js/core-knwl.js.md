# core-knwl.js

> 标签: data, language, natural language processing, nlp, parsing, tagging

## 简介

It's a fork from knwl.js. It comes without knwl.js default and experimental plugins. Parse through text for specific information. It's just a core, it does nothing until you plug your plugins on the knwl instance.
