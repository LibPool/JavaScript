# companion-for-agy

> 标签: agy, agy-cli, antigravity, ci-cd, claude-code, cli, codex, conpty, gemini, gemini-cli, gemini-cli-wrapper, llm, multi-agent, node-pty, pty, stdout-capture, subprocess, terminal-buffer, wrapper

## 简介

Unofficial node-pty/ConPTY wrapper for agy (Antigravity CLI / Gemini CLI) that captures terminal-buffer responses as stdout for automation
