# card-bin-info

> 标签: bin, bin-list, binfo, binlist, bins, card-bin, card-bin-info, card-bin-list, cardinfo, check, checker

## 简介

**card-bin-info** — это библиотека для поиска информации по BIN-коду банковской карты.   Она позволяет определить банк, который выпустил карту, используя локальные JSON-данные.
