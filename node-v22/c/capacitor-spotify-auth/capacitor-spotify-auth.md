# capacitor-spotify-auth

> 标签: android, auth, capacitor, ios, native, oauth, plugin, spotify

## 简介

Capacitor plugin for Spotify OAuth authentication. Uses native Spotify SDK on iOS/Android (app-to-app if Spotify installed), falls back to web OAuth.
