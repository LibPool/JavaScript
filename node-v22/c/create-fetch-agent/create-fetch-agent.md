# create-fetch-agent

> 标签: agents, ai-agents, asi, asi-one, chat-protocol, cli, create, fet, fetch.ai, fetchai, generator, payment, scaffold, uagents

## 简介

Scaffold runnable Fetch.ai uAgent projects — single, multi-agent (ASI:One-routed), or pay-to-use (on-chain FET) — with the chat protocol wired in and AI-coding-tool context, in one command.
