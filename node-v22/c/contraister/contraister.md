# contraister

> 标签: ai, claude, cross-check, fact-checking, gemini, llm, mcp, model-context-protocol, openai, openrouter

## 简介

MCP server to cross-check an AI's answers against other AI models (Gemini, Claude, OpenAI, Grok, Mistral, DeepSeek, Groq, Together, Perplexity, OpenRouter, Ollama).
