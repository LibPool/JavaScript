# create-sacbe

> 标签: authelia, caddy, create, dev-server, docker-compose, reverse-proxy, sacbe, self-hosted

## 简介

One cross-platform installer for Sacbé — a self-hosted gateway that puts every dev server on your VM behind one authenticated HTTPS door.
