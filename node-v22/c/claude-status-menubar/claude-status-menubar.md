# claude-status-menubar

> 标签: anthropic, claude, cowork, macos, menubar, notifications, status

## 简介

macOS menu bar app showing live status of Claude Desktop (Cowork) sessions — ✳ Running / Done / Idle — with a notification when a session finishes. Compiles locally, no Gatekeeper friction.
