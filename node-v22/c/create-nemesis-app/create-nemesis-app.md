# create-nemesis-app

> 标签: api-security, application-security, create, express, fastapi, nemesis, nemesis-shield, nextjs, positive-security, scaffold, security, starter, supabase, waf

## 简介

Scaffold a web app or API with a positive-security WAF (Nemesis Shield) already wired in. One command, safe by default (observe mode).
