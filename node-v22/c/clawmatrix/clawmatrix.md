# clawmatrix

> 标签: cluster, decentralized, gateway, handoff, mesh, model-proxy, openclaw, openclaw-plugin

## 简介

Decentralized mesh cluster plugin for OpenClaw — inter-gateway communication, model proxy, task handoff, and tool proxy.
