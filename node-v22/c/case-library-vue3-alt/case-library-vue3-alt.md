# case-library-vue3-alt

> 标签: JavaScript

## 简介

使用 npm i CaseCibraryVue3 下载组件 在 main.js 中 import CaseCibraryVue3 from 'case-library-vue3' createApp(App).use(CaseCibraryVue3).mount('#app') // 挂在到全局 页面中 <CaseCibraryVue3   :sign="sign"   :app_id="appId"   :case_id="caseId"   :phone="phone"   :ui
