# compress-utils

> 标签: brotli, bzip2, compression, decompression, gzip, lz4, lzma, snappy, wasm, webassembly, xz, zlib, zstd

## 简介

WASM compression bindings for zstd, brotli, zlib, bz2, lz4, xz, snappy, gzip - all tree-shakeable.
