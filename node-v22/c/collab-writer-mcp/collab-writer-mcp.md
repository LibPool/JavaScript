# collab-writer-mcp

> 标签: claude, collab-writer, latex, mcp, model-context-protocol

## 简介

MCP server exposing collab-writer documents to an MCP client (e.g. Claude Code / Claude Desktop): read the LaTeX source, context files, and skills; propose edits as tracked-change suggestions or appendix notes.
