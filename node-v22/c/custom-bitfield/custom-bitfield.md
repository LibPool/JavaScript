# custom-bitfield

> 标签: bigint, bit, bitfield, bitfields, buffer, custom, customisable, customizable, discord, field, permission, permissions, size, unlimited

## 简介

A customisable bitfield that can be used for building e.g. your own permissions system (or similar). Works with any amount of bits.
