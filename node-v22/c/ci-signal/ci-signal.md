# ci-signal

> 标签: agent, ci, ci-events, coding-agent, events, github, github-actions, router, self-hosted, sqlite, webhook

## 简介

Lightweight, self-hostable CI-to-agent event router. Routes CI failure signals from GitHub to your coding agent (webhook/command/file) with no AI analysis and minimum API requests.
