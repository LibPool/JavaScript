# claude-usage-limits

> 标签: budget, claude, claude-code, cli, cost, limits, rate-limit, statusline, tokens, usage

## 简介

Puts your remaining Claude Code usage limit into Claude's context before every prompt, so it opens with what fits in the budget instead of starting work that gets cut off. Reports headroom as turns rather than percentages, prices a job before you start it
