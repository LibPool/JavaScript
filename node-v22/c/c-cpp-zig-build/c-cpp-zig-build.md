# c-cpp-zig-build

> 标签: addon, build, c, c++, cross-compile, n-api, napi, native, node-api, node-gyp-alternative, zig

## 简介

Build native C/C++ Node.js addons and libraries with Zig, downloads the Zig toolchain for you, and ships a build.zig template that configures a whole project from a handful of parameters.
