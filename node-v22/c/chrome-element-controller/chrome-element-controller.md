# chrome-element-controller

> 标签: ai-agent, automation, browser-control, chrome-extension, dom-scanner, mcp, model-context-protocol

## 简介

Reads HTML elements, numbers them on-page, and provides human-like activity controllers with real-time DOM updates & MCP Server integration.
