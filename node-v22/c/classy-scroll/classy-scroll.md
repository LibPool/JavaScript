# classy-scroll

> 标签: animation, css-classes, framework-agnostic, intersection-observer, mutation-observer, performance, scroll, typescript, viewport

## 简介

A lightweight, performance-first library for scroll-based class toggling. Built with the IntersectionObserver API and TypeScript.
