# create-keel-module

> 标签: create-keel-module, keel, native-module, react-native, scaffold

## 简介

Scaffolding tool for new Keel native modules — invoked via `npm create keel-module keel-module-foo` or `npx create-keel-module keel-module-foo`.  Follows the npm `create-<thing>` convention; mirrors create-expo-module.
