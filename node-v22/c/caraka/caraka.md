# caraka

> 标签: acp, agent-client-protocol, ai-agent, claude-code, coding-agent, developer-tools, mcp, pwa, telegram, telegram-bot, web

## 简介

Send the task. Caraka runs it. — a local bridge from chat or Web/PWA to the coding agent on your machine.
