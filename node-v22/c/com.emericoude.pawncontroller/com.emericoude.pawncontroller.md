# com.emericoude.pawncontroller

> 标签: JavaScript

## 简介

Inspired by Unreal Engine's Gameplay Framework, this packages aims to deliver an efficient backing structure to creating character controllers (i.e. pawns) that can be controlled by either players or AI.
