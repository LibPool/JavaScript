# codeclassify

> 标签: aba, barcode, bic, check-digit, checksum, container, cusip, ean, gtin, iban, isin, iso-6346, lei, luhn, offline, routing-number, sedol, upc, validation, validator, vin

## 简介

Offline, zero-dependency checksum & format validators: IBAN, GTIN/EAN/UPC, Luhn, ISIN, CUSIP, SEDOL, LEI, VIN, ISO 6346 container, ABA routing number, BIC. No network calls.
