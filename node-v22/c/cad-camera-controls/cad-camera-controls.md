# cad-camera-controls

> 标签: 3d, cad, camera-controls, react-three-fiber, threejs

## 简介

CAD-style camera controls for Three.js with fixed-pivot rotate, modifier pan, and cursor-anchored zoom. Optional React Three Fiber wrapper included.
