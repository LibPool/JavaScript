# cordova-plugin-x-socialsharing-vmatskiv-fork

> 标签: Email, Facebook, LinkedIn, Pocket, SMS, Share, Social, Tumblr, Twitter, WebShare, WhatsApp, cordova, cordova-android, cordova-ios, cordova-windows, ecosystem:cordova

## 简介

Share text, images (and other files), or a link via the native sharing widget of your device. Android is fully supported, as well as iOS 6 and up. WP8 has somewhat limited support.
