# cbr-exchange-rate

> 标签: api, bank, cbr, central-bank, currency, exchange-rate, exchange-rates, forex, fx, of, official-rates, rub, russia, typescript

## 简介

Official Bank of Russia (Russia) daily exchange rates — 54 currencies vs RUB, history since 2016. Zero-dependency Node.js/TypeScript client.
