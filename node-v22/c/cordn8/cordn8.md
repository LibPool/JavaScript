# cordn8

> 标签: adapter, agents, ai, ai-agents, anthropic, automation, claude, cli, coordination, dashboard, developer-tools, gui, hub, llm, local-first, multi-agent, nextjs, nvidia, openai, orchestration, web-ui

## 简介

Agent-neutral coordination for AI agents, coding CLIs, LLM APIs, IDE assistants, and custom tools through a local auditable channel — with a built-in local web dashboard (Cordn8 Mantle).
