# ccpool-server

> 标签: ccpool, claude, claude-code, hono, libsql, quota, self-hosted, server, turso, usage

## 简介

Multi-tenant HTTP server for ccpool (Hono + libSQL) — the one path to the shared ledger. Self-host it to run your own group.
