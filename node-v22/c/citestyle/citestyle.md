# citestyle

> 标签: academic, apa, bibliography, bibtex, chicago, citation, citation-style-language, citeproc, csl, doi, formatting, harvard, ieee, latex, mla, reference, ris, scholar, vancouver

## 简介

Citation formatting for the web — compile CSL styles into lightweight JavaScript. Structured output (HTML, text, parts, links) from any of 10,000+ citation styles in ~9-13KB.
