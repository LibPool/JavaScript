# create-mc-bedrock

> 标签: add-on, addon, bedrock, bedrock-build, cli, create, deploy, javascript, mcaddon, minecraft, scaffolder, typescript

## 简介

Interactive scaffolder for Minecraft Bedrock addons. Lays down one opinionated starter (powered by @keyyard/bedrock-build) with create:* generators wired in, so you can build content in seconds.

## 官网

- 官网：https://bedrockcli.keyyard.xyz
- 源码仓库：git+https://github.com/Keyyard/create-mc-bedrock-cli.git
