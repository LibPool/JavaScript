# class2style-webpack-plugin

> 标签: JavaScript

## 简介

这是一个允许你使用类函数的方式生成css的webpack插件，支持webpack4.0，webpack5.0。只需要简单的配置，就可以将.html，.vue，.jsx，.tsx文件中的类名转化成css样式。
