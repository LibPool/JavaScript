# cordova-plugin-streaming-media-xtreme

> 标签: cordova-android, cordova-fireos, cordova-ios, ecosystem:cordova, media, streaming

## 简介

This plugin allows you to stream audio and video in a fullscreen, native player on Android and iOS.
