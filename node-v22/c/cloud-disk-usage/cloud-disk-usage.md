# cloud-disk-usage

> 标签: Dropbox, FTP, Github, NextCloud, Owncloud, SFTP, cli, cloud, disk, disk space, du, fs, hdd, linux, optimize, space, webdav

## 简介

Command line utility which displays the size of folders (recursively) and files in your cloud storage (e.g. Dropbox and more).
