# calendrical-javascript

> 标签: Date, Intl, Intl.DateTimeFormat, calendar, calendrical computations, custom calendars, date-format, gregorian calendar, icu4j

## 简介

Routines for computations on calendars. Extend Date and Intl.DateTimeFormat. Allow custom calendars. Add historical gregorian calendars with custom switching date. Specify date in custom calendar. Handle week figures. Enhance Intl.DateTimeFormat. Extend U
