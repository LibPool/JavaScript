# create-tekivex-app

> 标签: create-app, react, scaffolder, security, tekivex-ui, typescript, vite

## 简介

Scaffold a secure React + Vite app with tekivex-ui pre-wired — CSP headers, SecurityCore, dark/light theme, TypeScript, ESLint.
