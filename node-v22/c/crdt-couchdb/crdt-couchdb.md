# crdt-couchdb

> 标签: JavaScript

## 简介

A subclass of [`crdt`](https://github.com/dominictarr/crdt) which sources data from CouchDB and updates them in real-time. It supports pre-fetching of views and filtering of changes with CouchDB filters (using [`changes`](https://github.com/indexzero/changes)).
