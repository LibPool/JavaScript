# crap-check

> 标签: code-quality, cognitive-complexity, complexity, coverage, crap, cyclomatic, github-action, typescript

## 简介

Cyclomatic, cognitive and CRAP complexity for TypeScript and JavaScript repositories, with weekly git history, SVG charts, pull-request deltas and a generated GitHub Action.
