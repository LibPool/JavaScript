# copilotkit

> 标签: JavaScript

## 简介

The CopilotKit CLI scaffolds starter apps, connects project creation to a CopilotKit workspace through the Ops/Clerk platform, and manages local CLI authentication for CopilotKit Intelligence onboarding.
