# create-recensus-agent

> 标签: ai-agents, create, erc-8004, know-your-agent, kya, recensus, robinhood-chain, starter, usdg, x402

## 简介

Know Your Agent on Robinhood Chain: one command makes a small agent project with its own wallet that registers in ERC-8004, sends a labelled USDG transfer, pays for a KYA check over x402 and sells behind a KYA gate. Testnet by default.
