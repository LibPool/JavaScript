# capacitor-apple-maps-native-sdk

> 标签: apple maps, capacitor, ios, mapkit, native, plugin

## 简介

The capacitor-apple-maps-native-sdk is a Capacitor plugin that provides access to the native iOS Apple Maps SDK for developers to integrate Apple Maps into their mobile applications.
