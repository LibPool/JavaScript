# calcfi-real-return

> 标签: calcfi, cpi, finance, fisher-equation, inflation, nominal, real-return

## 简介

Compute the real (inflation-adjusted) return from a nominal return and inflation rate. Uses Fisher equation. CPI/PCE inflation data sourced
