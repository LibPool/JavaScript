# claude-code-scroll

> 标签: anthropic, claude, claude code, cli, scroll, scrollback, terminal

## 简介

Run Claude Code with working terminal scrollback and mouse-wheel scroll — a thin wrapper around the CLAUDE_CODE_DISABLE_ALTERNATE_SCREEN / CLAUDE_CODE_DISABLE_MOUSE env vars.
