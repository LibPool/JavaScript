> 标签: claude, codeigniter, framework, llm, mcp, model-context-protocol, mvc, php, scaffolding

## 简介

MCP (Model Context Protocol) server that accelerates development of a custom PHP framework inspired by CodeIgniter: MVC + optional Services/Repository layer. Scaffolds controllers, services, repositories, entities, migrations and tests; validates routes a
