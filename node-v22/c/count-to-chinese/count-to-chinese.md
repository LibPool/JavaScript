# count-to-chinese

> 标签: JavaScript

## 简介

count-to-chinese is a dependency-free, lightweight vue component that can be overwrited  easingFn by yourself. You can set startVal and endVal ,it will automatic judge count up or count down. It is support vue-ssr. It is learn from countUp.js;
