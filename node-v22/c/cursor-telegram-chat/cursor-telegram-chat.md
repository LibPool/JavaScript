# cursor-telegram-chat

> 标签: agent, chatops, cursor, discord, github, images, mcp, remote-control, speech-to-text, telegram, voice, whisper

## 简介

Control the Cursor AI agent from a chat app (Telegram, Discord, GitHub) — with image attachments and voice notes transcribed to text. Pluggable transport adapters + a local daemon + MCP tools + hooks.
