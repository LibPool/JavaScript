# codice-fiscale-it

> 标签: belfiore, codice-fiscale, comuni, fiscal-code, italia, italian, omocodia, tax-code, typescript

## 简介

Calcolo, decodifica e verifica del codice fiscale italiano. Algoritmo ufficiale DM 23/12/1976, archivio completo dei comuni e degli stati esteri, zero dipendenze.
