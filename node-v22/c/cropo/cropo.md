# cropo

> 标签: canvas, crop, crop-image, cropper, cropping, image-crop, image-cropper, image-processing, image-zoom, pinch-to-zoom, profile-image, zoom, zoom-images

## 简介

Cropo is a fast, lightweight image cropping tools for JavaScript. Resize and crop your uploaded image using a intuitive user interface.
