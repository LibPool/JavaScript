# cwthree.js

> 标签: cloudwise, cwthree, three

## 简介

一款基于Three.js进行了能力抽象的方法库、使用CWThree您可更关注于业务逻辑功能，不必将精力投入复杂的3D渲染效果和功能等非业务核心的技术细节
