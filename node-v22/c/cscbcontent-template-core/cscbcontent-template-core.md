# cscbcontent-template-core

> 标签: template

## 简介

This is a common node module which contains the model and section details which are defined in Cscbcontentnodeweb node web application. This module is consumed by both Cscbcontentnodeweb (producer) and Cscbcontentnodeserv (consumer) components
