# create-atlas-addon

> 标签: JavaScript

## 简介

A CLI tool for generating a fully working [AtlasFramework](https://github.com/8char/AtlasFramework/) addons with a preconfigured lauxconfig.json and example code for integrating your addon with [AtlasFramework](https://github.com/8char/AtlasFramework/). [
