# com.careboo.serially

> 标签: SerializableType, SerializeReference, inspector, reference, serializable, serialization, serialize, type

## 简介

Provides extension classes to extend Unity's serialization capabilities.

- Serialize Type references
- Inject instances into [SerializeReference] fields
