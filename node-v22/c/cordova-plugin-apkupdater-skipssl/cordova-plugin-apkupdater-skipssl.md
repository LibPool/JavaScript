# cordova-plugin-apkupdater-skipssl

> 标签: apk, capacitor, cordova, cordova-android, downloader, ecosystem:cordova, installer, ionic, play-store, updater

## 简介

This plugin allows your Android app to download and install compressed updates without the Google Play Store.
