# claude-in-chrome-cli

> 标签: automation, browser, chrome, claude-in-chrome, cli, mcp

## 简介

Call Claude in Chrome MCP tools from the shell. Drives your real, logged-in Chrome from scripts, cron jobs, and agents that cannot hold an MCP connection.
