# cbrew

> 标签: feedback, feedback-board, feedback-widget, react, user-feedback, widget

## 简介

Context Brew — a drop-in feedback widget (React FAB + framework-agnostic script-tag embed) for the hosted cbrew.co feedback product. Point it at the hosted API with a publishable app key; you provision nothing.
