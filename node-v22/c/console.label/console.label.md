# console.label

> 标签: add label, console, console label, console log, console.label, console.log, consoleLabel, debug, debugging, label, log, name, stack, stack trace, stack tracing, stacktrace, trace, variable, variable name

## 简介

Adds a console.label() function that acts like console.log, except it automatically adds a label to each log with the name of the variable being logged
