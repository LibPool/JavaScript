# capacitor-rich-share

> 标签: android, capacitor, instagram, ios, mediastore, native, photos, plugin, share, tiktok

## 简介

Capacitor plugin for native-quality sharing — system share sheet with image+text, Save to Photos / Gallery, unified shareTo() router for IG Story / IG Feed / FB Story / Snap / TikTok / WhatsApp / Telegram / X / LinkedIn / SMS / Email / clipboard, app-inst
