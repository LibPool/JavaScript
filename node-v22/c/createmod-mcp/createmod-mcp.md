# createmod-mcp

> 标签: create-mod, createmod, mcp, minecraft, modelcontextprotocol, schematics

## 简介

MCP server for CreateMod.com — search and reference Minecraft Create Mod schematics. Stdio bridge to the remote server at https://createmod.com/api/mcp.

## 官网

- 官网：https://createmod.com
- 源码仓库：git+https://github.com/uberswe/createmod-claude.git
- npm 页面：https://www.npmjs.com/package/createmod-mcp

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install createmod-mcp`
- npm registry：https://registry.npmjs.org/createmod-mcp
- Node 要求：>=18
