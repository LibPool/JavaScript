# coordigent

> 标签: claude-code, codex, coding-agents, coordination, cursor, developer-tools, mcp, mcp-server, multi-agent

## 简介

Coordigent's coord and coord-mcp commands: downloads the binaries for this machine on first run, checks their SHA-256, and runs them. `npx coordigent` and `npx coordigent mcp` work too. mcprush.com-8242fc9f4ab552f2820f7907
