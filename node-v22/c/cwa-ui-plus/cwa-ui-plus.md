# cwa-ui-plus

> 标签: element-ui, vue, vue-i18n

## 简介

cwa-ui-plus 是一个基于 Vue3 + Element-plus + Ts 二次开发的公共前端组件库；<br> 可帮组前端开发人员减少重复封装相同组件的工作，减少工作量，提高开发效率；
