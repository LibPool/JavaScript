# calcuris-mcp

> 标签: calcuris, income-tax, mcp, model-context-protocol, property-tax, stamp-duty, take-home-pay, tax-calculator

## 简介

MCP server exposing the Calcuris tax engines — US income tax & paycheck, US property tax, Canadian provincial income tax, Australian stamp duty & income tax, UK dividend tax. Real 2026 rates, no API key.
