# create-ult

> 标签: create, init, native, rust, template, tsx, ult

## 简介

Create an ult app: `npm create ult my-app` runs `ult init my-app`. 3.0.0-alpha.0 claims the name; the command arrives with 3.0.0-alpha.1.
