# crypt-uniid

> 标签: cryptuniid, cuid, distributed-system, hash-id, id-generator, secure-id, sha256, timestamp-id, unique-id, uuid

## 简介

A secure, efficient, and machine-aware unique ID generator using timestamp, counter, and SHA-256 hashing.
