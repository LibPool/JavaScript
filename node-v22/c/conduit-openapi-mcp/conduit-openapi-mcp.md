# conduit-openapi-mcp

> 标签: ai-tools, api, conduit, mcp, model-context-protocol, openapi, rest, swagger

## 简介

Turn any OpenAPI/Swagger spec into an MCP server: one tool per endpoint. A showcase for Conduit (conduitmcp.app).
