# chainsentry

> 标签: audit, chainsentry, cli, mern-packages, merndev, nodejs, npm, npm-pm, observability, postinstall, scanner, security, supply-chain, typescript, typosquat

## 简介

Supply-chain scanner that audits npm dependencies for typosquats, malicious install scripts, license risk, and known CVEs.
