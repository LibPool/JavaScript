# components-globals

> 标签: Node

## 简介

FileMaster es una librería de Node.js diseñada para facilitar la gestión eficiente de archivos y recursos en aplicaciones web y backend. Proporciona un conjunto de herramientas todo en uno para optimizar el manejo de archivos grandes, realizar compresión
