# cordova-plugin-photoviewer-no-android-permissions

> 标签: cordova, cordova-android, cordova-ios, ecosystem:cordova, photoviewer

## 简介

Forked from [com-sarriaroman-photoviewer](https://github.com/sarriaroman/photoviewer)! This plugin is intended to show a picture from an URL into a Photo Viewer with zoom features.
