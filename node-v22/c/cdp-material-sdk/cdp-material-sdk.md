# cdp-material-sdk

> 标签: JavaScript

## 简介

`cdp-material-sdk` 是面向独立仓库外部作者的公开 SDK，用于编写真实 React 组件包并向宿主注册 `ComponentManifest`、`EngineComponentPackage` 与 `EngineComponentPlugin`。
