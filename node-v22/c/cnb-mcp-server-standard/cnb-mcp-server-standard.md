# cnb-mcp-server-standard

> 标签: api, cnb, commits, git, issues, mcp, model-context-protocol, server, tencent, typescript

## 简介

CNB MCP Server for accessing commits, issues and creating issues via MCP protocol. Supports multi-user concurrent queries and time-range filtering.
