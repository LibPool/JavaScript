# create-lyra

> 标签: 3d-avatar, avatar, companion, create, installer, lip-sync, lyra, openclaw, voice, vrm

## 简介

One command to install Lyra — a self-hosted, local-first 3D avatar companion you talk to. Downloads the app, fetches the bodies, and runs a guided setup.
