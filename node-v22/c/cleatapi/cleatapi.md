# cleatapi

> 标签: 2fa, cleat, otp, sms, verification-code, webhook

## 简介

TypeScript client for the Cleat API: read the texts and transcribed calls that arrive on your own US mobile lines.

## 官网

- 官网：https://cleat.so/for/developers
- 源码仓库：git+https://github.com/davidcleat/cleat-js.git
- npm 页面：https://www.npmjs.com/package/cleatapi
