# create-egonitida

> 标签: 3d, agentic, create, effect, egonitida, engine, foldkit, game-engine, real-time, scaffold, three, webgpu

## 简介

EgoNitida is a real-time 3D engine built on Effect, Three.js, and Foldkit. The create-egonitida package powers npm create egonitida, the starting point for new EgoNitida projects.
