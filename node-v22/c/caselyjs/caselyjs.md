# caselyjs

> 标签: came case to kebab case, case changer, codebase renamer, file / folder renamer, kebab case to pascal case, naming convention tool, pascal case to camel case

## 简介

Powerful CLI to bulk rename files and directories across your codebase with kebab, camel, or Pascal case. Fast, simple, and easy to use.
