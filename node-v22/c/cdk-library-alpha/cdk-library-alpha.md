# cdk-library-alpha

> 标签: cdk

## 简介

This repository contains alpha versions of AWS CDK constructs that are not yet ready for the main `@myhelix/cdk-library`. It also holds packages that are pinned to a specific version of the AWS CDK (`2.176.0`) due to breaking changes in AWS CDK alpha pack
