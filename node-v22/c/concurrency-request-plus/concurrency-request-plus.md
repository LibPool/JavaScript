# concurrency-request-plus

> 标签: JavaScript

## 简介

1. concurrency-request-plus 是一个用于解决并发请求的一个库，是使用promise解决的 ## 参数说明 1. requestArr:[] ,是一个请求数组，里面包含了所有的请求 2. maxRequest:number ,并发请求的个数 ## 返回值说明 1. 返回值是按照请求顺序所返回的请求结果，为一个数组，请求结果是promise
