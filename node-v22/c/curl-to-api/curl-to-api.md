# curl-to-api

> 标签: apipost, cli, codegen, curl, postman, vue

## 简介

从 curl / Apipost 接口文档一键生成 Vue API 代码或 TS 类型文件

- npm registry：https://registry.npmjs.org/curl-to-api
- Node 要求：>=18
