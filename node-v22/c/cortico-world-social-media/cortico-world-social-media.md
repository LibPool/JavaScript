# cortico-world-social-media

> 标签: bilibili, comments, companion, cortico, cortico-world, social-media, video

## 简介

让 Bot 带着兴趣逛 B站：读字幕、看画面、接评论，闲时探索话题，也能优先参与主人的新作品。发言与频率可控，交流按视频归档；沿用现有模型，无需 Browser World。
