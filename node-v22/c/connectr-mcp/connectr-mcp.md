# connectr-mcp

> 标签: ai-agents, antigravity, claude-code, codex, cursor, gemini-cli, kiro, mcp, multi-agent, orchestration

## 简介

Shared brain for AI coding agents - one MCP server giving Claude Code, Codex, Cursor, Kiro, Gemini CLI and Antigravity a common task board, shared memory and advisory file claims.
