# color-palettekz

> 标签: JavaScript

## 简介

Mon premier package npm ! 🎉   Un petit module Node.js qui fournit de jolies palettes de couleurs : **sakura**, **autumn**, **night**, **garden**, **galaxy**.   Permet de lister les palettes, d’en récupérer une par nom ou d’en sélectionner une au hasard p
