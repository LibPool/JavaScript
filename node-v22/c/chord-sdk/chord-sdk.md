# chord-sdk

> 标签: api, bot, chat, chord, chord.tr, client, components, embed, moderation, slash-commands

## 简介

Chord Bot API için resmî Node.js istemci kütüphanesi — slash komutları, komut framework'ü, embed/buton builder'ları, etkileşimler, REST ve canlı gateway olayları.
