# codekeel

> 标签: agentic-coding, ai-agent, claude-code, cli, code-governance, decision-ledger, developer-tools, drift-detection, hooks

## 简介

Record a decision once and Claude Code stops re-deciding (and contradicting) it later. A local decision ledger for Claude Code sessions — free, open source, runs entirely on your machine.
