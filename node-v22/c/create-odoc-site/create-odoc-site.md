# create-odoc-site

> 标签: JavaScript

## 简介

ODoc 提供一个 Starter Kit，你可以一键安装已完善好环境配置的站点包，快速开始进行内容装载。只需在终端执行以下命令 (可通过 npm 或 yarn 安装)，当然，在此之前请确保你的本地环境支持 Node.js / TypeScript。 ```bash npm create odoc-site / yarn create odoc-site ```
