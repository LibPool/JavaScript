# create-keboola-app

> 标签: cli, create, generator, keboola, react, scaffold, tanstack, vite

## 简介

Scaffold a Keboola-shaped frontend app — Vite + React 19 + TanStack Router/Query/Form + Zustand + @keboola/design — from a minimal shell plus the blocks you pick
