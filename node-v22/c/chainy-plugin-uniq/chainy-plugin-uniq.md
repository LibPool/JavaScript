# chainy-plugin-uniq

> 标签: chainy, chainy-action, chainy-addon, chainy-extension, chainy-modifier, chainy-plugin, chainy-standalone

## 简介

Chainy action that rejects duplicates inside the chain's data array, based on the item itself, or a particular field
