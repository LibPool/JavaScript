# clarity-tax-report-ui

> 标签: clarity-tax, design-tokens, html-reports, jinja2, nunjucks, reports

## 简介

Shared components, tokens and runtime for Clarity Tax HTML reports. Renders identically under the platform's Nunjucks engine and a report repo's local Jinja2 harness.
