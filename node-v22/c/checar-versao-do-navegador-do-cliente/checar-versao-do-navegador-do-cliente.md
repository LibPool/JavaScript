# checar-versao-do-navegador-do-cliente

> 标签: browser, client-hints, compatibilidade, deteccao, detection, ie11, legacy, navegador, pt-br, suporte, user-agent, versao, version

## 简介

Biblioteca JavaScript leve (~13 KB min) para detectar o navegador do cliente, classificar o nível de suporte e avisar o usuário quando for necessário atualizar. Parametrizável, UMD (script/require/import), IE11-safe.
