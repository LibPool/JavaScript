# casl-net

> 标签: abac, authorization, casl, csharp, dotnet, permissions, rbac

## 简介

Use CASL .NET rules in the browser: @casl/ability with the MongoDB logical operators ($and, $or, $nor, $not) switched on, so it reaches the same decisions as the .NET library.
