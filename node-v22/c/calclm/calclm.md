# calclm

> 标签: JavaScript

## 简介

使用npm init初始化一个package.json文件 注意：必须要有这个文件才能上传，npm可以上传任何一个包含package.json的包，package.json的main(入口)设置为index.js（名字自取）然后在本目录下建一个index.js文件，name表示你这个包的名字只能小写,version代表版本，每次更新都要修改这里的版本再npm publish
