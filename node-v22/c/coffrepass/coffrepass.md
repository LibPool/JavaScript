# coffrepass

> 标签: argon2, argon2id, bcrypt, cli, crypto, diceware, hash, password, php, python, scrypt, security

## 简介

Professional cryptographic password hashing, verification, inspection, strength analysis and CSPRNG generation CLI & library for Node.js, compatible with PHP >= 8.2 & Python.
