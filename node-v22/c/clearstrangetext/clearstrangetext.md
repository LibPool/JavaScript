# clearstrangetext

> 标签: clean, clear, string, text

## 简介

清理字符串：去掉空格和各种“奇怪符号”，保留：- 数字 0-9- 英文字母 a-zA-Z- 中文（常用汉字范围）- 其他文字（任意语言的字母：如日文假名、韩文等） 说明：- 会删除：空白符、标点符号、表情、各种符号（如 @#$%^&* 等）- 会保留：各语言“字母/文字”和数字  - 适用于：需要清理输入文本、提取纯文本内容的场景
