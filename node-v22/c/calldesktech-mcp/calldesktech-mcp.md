# calldesktech-mcp

> 标签: calldesktech, mcp, model-context-protocol, telephony, voice-agents

## 简介

MCP server for the CallDeskTech API — build, publish and operate voice agents (flows, subflows, knowledge bases, numbers, calls, batch calls, webhooks) from any MCP client.
