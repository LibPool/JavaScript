# claude-stat

> 标签: ansi, anthropic, cache-hit, claude, claude-code, claude-code-statusline, claude-status, cli, context-window, developer-tools, prompt-cache, rate-limit, status-bar, status-line, statusline, terminal, zero-dependencies

## 简介

A compact, information-dense status line for Claude Code. Shows context window usage, rate limits, prompt cache hit percentage, model, effort level, git branch, and session token totals. Zero dependencies.
