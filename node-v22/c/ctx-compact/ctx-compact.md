# ctx-compact

> 标签: agents, chat, compaction, context-window, conversation, llm, openai, tokens

## 简介

Framework-neutral conversation compaction for plain OpenAI-shaped message arrays, with tool-call/tool-result pairing so trimming never orphans a tool result.
