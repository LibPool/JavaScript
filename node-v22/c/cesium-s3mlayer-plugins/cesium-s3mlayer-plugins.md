# cesium-s3mlayer-plugins

> 标签: JavaScript

## 简介

cesium-s3mlayer-plugins（SuperMap_Plugin_for_Cesium）是iClient3D for WebGL产品面向Cesium推出的插件集合，用户基于该插件，在Cesium中高效快捷的实现iClient3D for WebGL产品的部分功能。
