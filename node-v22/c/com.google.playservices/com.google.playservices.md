# com.google.playservices

> 标签: JavaScript

## 简介

This is a simple Cordova plugin that adds the [Google Play Services](http://developer.android.com/google/play-services/setup.html) client library to your app.

## 官网

- npm 页面：https://www.npmjs.com/package/com.google.playservices

- npm registry：https://registry.npmjs.org/com.google.playservices
- Node 要求：{'name': 'cordova', 'version': '>=3.0.0'}
