# copy-to-figma

> 标签: clipboard, color-palette, copy-paste, design-tokens, design-tools, figma, icons, styleguide, svg, typography

## 简介

Copy color palettes, type scales, icon grids and full styleguides into Figma as editable frames — plain clipboard SVG, no plugin required.
