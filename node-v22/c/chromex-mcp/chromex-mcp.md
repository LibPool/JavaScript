# chromex-mcp

> 标签: ai-agent, automation, browser, browser-automation, cdp, chrome, claude-code, devtools, mcp, mcp-server, scraping, testing

## 简介

Agent-first Chrome DevTools toolkit with a token-efficient CLI, 85 typed MCP tools, modal-free pipe transport, diagnostics, memory analysis, extensions, and WebMCP.
