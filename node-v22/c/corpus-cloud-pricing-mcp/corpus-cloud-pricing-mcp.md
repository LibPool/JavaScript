# corpus-cloud-pricing-mcp

> 标签: aws, azure, cloud-pricing, corpusai, gcp, gpu, mcp, model-context-protocol, spot, usdc, x402

## 简介

MCP server for the corpusAI Cloud Pricing API: cloud spot, on-demand, reserved and GPU rental prices with index fixings, paid per call in USDC over x402 (Circle Gateway). No accounts, no API keys.
