# chm-strtime

> 标签: JavaScript

## 简介

``` npm i chm-strtime ``` ## 使用说明 1.导入 ```js const {dateFormat} = require('strtime') ``` 2.使用 ```js dateFormat(时间戳)||dateFormat()  //返回值是'yyyy-MM-dd hh:mm:ss'格式的时间 ``` ## 开源协议 ``` ISC ```
