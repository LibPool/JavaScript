# custom-directives-qingyun

> 标签: JavaScript

## 简介

1. 目前只有两种指令    - v-move：移动端拖拽移动自定义指令，并且是加上自定义的元素 必须 要是  fixed 或者 绝对定位，才可以，然后  body 也必须 有宽高，代码中是依据来进行偏移    - v-date：日期格式换组件，默认是 YYYY-MM-DD，结合 dayjs 插件做的，适用于 移动端、PC 端    - v-resize：拖拽控制元素宽高，可以指定方式 v-resize="'both'" v-resize="'height'" v-resize="'width'"  这三
