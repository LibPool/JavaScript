# churchtools-mcp

> 标签: churchtools, mcp, model-context-protocol, stdio

## 简介

MCP server for the ChurchTools API — runs locally over stdio (npx) or as a Streamable HTTP service. Fork of samuelspagl/ct-mcp with a stdio entrypoint.
