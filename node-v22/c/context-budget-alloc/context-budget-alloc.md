# context-budget-alloc

> 标签: ai-tooling, context-window, llm, prompt-engineering, token-budget, typescript

## 简介

TypeScript library and CLI for allocating and rebalancing an LLM context-window token budget across named zones (system, tools, retrieval, history, buffer).
