# css-token-extract

> 标签: cli, css, css-variables, custom-properties, design-tokens, extract, scss, tailwind, tokens

## 简介

Extract CSS custom properties (variables) from CSS/SCSS files and output as JSON, SCSS map, or Tailwind config
