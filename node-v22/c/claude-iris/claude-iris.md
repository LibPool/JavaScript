# claude-iris

> 标签: claude, claude-code, katex, markdown, mermaid, mirror, notebooklm, render

## 简介

Render Claude Code's terminal replies in a browser tab — markdown, KaTeX, Mermaid, syntax highlighting. Optional NotebookLM tutor wizard with role templates.
