# csv2mysqlra

> 标签: csv, excel, javascript, mysql, nodejs, sequelize

## 简介

本工具是通过 sequlize 来将数据导入 mysql。当 csv 文件大小大于 100M 时，程序会使用，逐行读取方式来获取数据，以减少内存消耗。
