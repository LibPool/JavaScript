> 标签: agent-skills, ai-tools, annotations, automation, claude, claude-code, claude-insights, cli, code-quality, developer-tools, friction, insights, productivity, skills

## 简介

CLI that parses Claude Code /insight reports and generates tailored skills, CLAUDE.md rules, hooks, and todos — with false-positive annotation filtering, team aggregation, trend tracking, and auto-apply mode
