# ccpatch

> 标签: JavaScript

## 简介

ccpatch 是一个用于修改 Claude Code CLI 的 AST 补丁工具。它使用 Babel 解析器修改 JavaScript 代码以绕过某些验证和显示限制，支持多种补丁的配置化管理。
