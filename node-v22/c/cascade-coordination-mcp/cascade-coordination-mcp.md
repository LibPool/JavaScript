# cascade-coordination-mcp

> 标签: agents, cascade, claude, coordination, cursor, lease, locking, mcp, mcp-server, model-context-protocol, multi-agent

## 简介

MCP server for Cascade: lets any MCP client claim and release shared resources so several agents never act on the same thing at once, with every decision signed and verifiable.
