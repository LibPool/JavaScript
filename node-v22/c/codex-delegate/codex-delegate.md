# codex-delegate

> 标签: codex, delegation, hooks, macos, openai, process-groups, subagent

## 简介

Run one Codex CLI task. Prompts and files are sent to OpenAI. Uses your ChatGPT Codex allowance or API-billed usage. Cleanup is bounded; surviving process groups report CLEANUP_FAILED. Requires macOS and a signed-in Codex CLI.
