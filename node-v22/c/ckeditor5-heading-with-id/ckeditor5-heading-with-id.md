# ckeditor5-heading-with-id

> 标签: ckeditor, ckeditor 5, ckeditor5, ckeditor5-dll, ckeditor5-feature, ckeditor5-plugin

## 简介

Headings feature for CKEditor 5 with support for ID as an allowed attribute. Generates a random hash when a new heading is inserted.
