# combinations-ts

> 标签: TypeScript, combinations, javascript, library, object properties, typescript

## 简介

A TypeScript library for generating all possible combinations of object properties. It takes multiple arrays of objects and creates a pair for each property. It is flexible, easy to use and well-documented
