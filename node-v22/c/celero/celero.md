# celero

> 标签: api-client, axios, cache, circuit-breaker, dedupe, edge, fetch, hooks, http, http-client, interceptors, isomorphic, ndjson, query, react, rest, retry, server-sent-events, sse, stale-while-revalidate, standard-schema, streaming, tanstack, timeout, typescript, usequery, validation, zod

## 简介

Swift, production-grade HTTP for JavaScript. TypeScript-first fetch client with retries, circuit breaker, caching, deduplication, SSE/NDJSON streaming, schema validation and typed errors. Zero dependencies.
