# cyclecalcs-widget

> 标签: astronomy, custom-element, eclipse, ephemeris, moon-phase, sunrise-sunset, web-component, widget

## 简介

Live moon phase, sunrise and sunset, tonight's sky, planet parade, eclipse countdown and cosmic clock as one custom element. Free, no account, no API key.
