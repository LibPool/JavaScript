# closeout

> 标签: agent, ai-agent, cleanup, cli, exit, exit-hook, extensible, json, non-tty, plugin, plugins, restore-cursor, shutdown, signal, signal-exit, teardown, terminal, zero-dependency

## 简介

Close everything out. Exit handlers that run exactly once on every path, terminal restore, and a bounded deadline so shutdown cannot hang. Drop-in paths for signal-exit, exit-hook and restore-cursor. Zero dependencies.
