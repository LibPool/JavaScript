# canpoint-ui-mcp

> 标签: design-system, design-tokens, mcp, model-context-protocol, ui

## 简介

UI spec query MCP for the StudyTour product line: fetch official design tokens, component specs and generation rules for the mini-program and admin console, and verify generated-page screenshots against the spec.
