# cursor-usage-optimizer

> 标签: cursor, mcp, model-context-protocol, optimizer, quota, requests, usage

## 简介

Local MCP server that reads your live Cursor usage/spend and helps the agent optimize/save requests (conserve mode, verbose footer, follow-up, daily update check).
