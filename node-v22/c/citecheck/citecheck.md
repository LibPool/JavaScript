# citecheck

> 标签: academic, bibliography, bibtex, citation, crossref, csl-json, doaj, open-access, openalex, references, retraction, ris, thesis, zotero

## 简介

Check whether the references in your .bib / .ris / CSL-JSON bibliography actually exist and haven't been retracted, and see which sources are in DOAJ-listed open-access journals — using Crossref, OpenAlex and DOAJ. No API key, no signup.
