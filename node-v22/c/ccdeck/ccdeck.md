# ccdeck

> 标签: agents, ai-agents, anthropic, claude, claude-code, claude-code-dashboard, cli, codex, codex-cli, cost, dag, dashboard, deck, hooks, monitor, monitoring, observability, openai, quota, subagents, tokens, usage, visualization

## 简介

Live dashboard for Claude Code and Codex — which agent is waiting on you, tool calls, token spend and every Claude Code subagent on one calm canvas. Run it with npx ccdeck.
