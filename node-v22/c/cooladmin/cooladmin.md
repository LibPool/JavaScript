# cooladmin

> 标签: admin, admin-dashboard, admin-template, bootstrap, bootstrap5, chartjs, colorlib, dashboard, fullcalendar, html5, responsive, template, vanilla-js

## 简介

CoolAdmin — Bootstrap 5.3 admin dashboard template. 35 pages, vanilla JavaScript, no jQuery. Chart.js, FullCalendar 7, Leaflet, dark-mode tokens, command palette, and an optional Pug + SCSS + Vite source pipeline.
