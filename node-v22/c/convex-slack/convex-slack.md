# convex-slack

> 标签: block-kit, component, convex, oauth, realtime, slack, webhooks

## 简介

Install your app into any number of Slack workspaces, sync channels/messages/reactions/users into Convex reactively, and drive the full Slack platform -- messaging, threads, Block Kit modals, slash commands, shortcuts, and files -- directly from Convex fu
