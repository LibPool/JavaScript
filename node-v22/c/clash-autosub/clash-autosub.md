# clash-autosub

> 标签: automation, clash, cli, node.js, puppeteer, subscription, typescript, vpn

## 简介

基于 Node.js + Puppeteer 的 VPN 订阅全自动化工具。智能检测订阅API模式，首次登录后自动保存认证配置，后续更新使用纯HTTP请求实现静默后台执行（< 1秒），彻底解决动态订阅地址的手动维护负担。
