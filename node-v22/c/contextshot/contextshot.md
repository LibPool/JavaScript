# contextshot

> 标签: ai, apple-pencil, claude, contextshot, cursor, ipad, mcp, mcp-server, recording, screen-recording, screenshot, visual-input

## 简介

MCP server for ContextShot. Exposes iPad drawings, screenshots, and screen recordings to AI tools like Claude Code and Cursor.
