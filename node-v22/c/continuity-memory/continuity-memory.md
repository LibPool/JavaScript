# continuity-memory

> 标签: ai, claude, cursor, mcp, memory, model-context-protocol, sqlite, windsurf

## 简介

Persistent memory backbone for AI tools. MCP server that gives Claude Code, Cursor, and Windsurf shared, versioned memory across sessions.
