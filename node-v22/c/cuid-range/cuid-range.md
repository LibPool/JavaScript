# cuid-range

> 标签: cuid, cuid-between, cuid-range, cuid2, javascript, nodejs, pagination, typescript

## 简介

Generate and validate CUID between two bounds. Useful for order-preserving pagination keys, gap insertion, or sequence IDs.
