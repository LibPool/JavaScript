# changeset-recover

> 标签: JavaScript

## 简介

recover utility to generate changeset (https://github.com/changesets/changesets)  entries when they'd previously been forgetten. 
Gives library maintainers a chance to double check merged work without fear of  missing attribution in the CHANGELOG.
