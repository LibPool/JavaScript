# cubicdb-module

> 标签: cubicdb, image, puzzle, rubik, scramble

## 简介

A TypeScript library for generating **puzzle scrambles** with optional **images** and **seed-based reproducibility**. Designed for both **Node.js** and the **browser (UMD)**.
