> 标签: agentic, ai-agents, claude-code, code-quality, contract-testing, create, express, fastapi, harness, monorepo-standards, nextjs, openapi, rigel, scaffold, starter, template

## 简介

Scaffold a Next.js, Express, or FastAPI project where an AI coding agent's work is constrained by rules and checked by a gate that fails the build. Wired for Claude Code.
