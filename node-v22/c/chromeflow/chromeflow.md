# chromeflow

> 标签: agent-tooling, ai-agent, browser-automation, browser-use-alternative, canvas, chrome-extension, claude-code, codex-cli, mcp, model-context-protocol, playwright-alternative, puppeteer-alternative, real-chrome-session, stripe, web-automation

## 简介

MCP server for chromeflow — lets Claude Code or Codex CLI drive your real Chrome browser with sessions intact. Plugin install recommended; npx chromeflow for manual MCP wiring.
