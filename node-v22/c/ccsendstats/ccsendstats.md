# ccsendstats

> 标签: audit, claude, claude-code, cli, context-window, proxy, tokens, transparency

## 简介

See what your Claude Code session actually sends to the API: real token totals per request, a category breakdown, and the invisible overhead you never see. Includes an optional live proxy for the bytes a transcript cannot show.
