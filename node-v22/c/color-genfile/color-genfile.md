# color-genfile

> 标签: angular, bootstrap, color, css, file, generate, generator, html, name, react, scss, stylesheet, ui, vue

## 简介

Color-Genfile cli is a Vscode extension that helps you to generate different colors of your choice and generate it into a css or scss file for Html, Angular React etc.
