# codex-token-tracker

> 标签: codex, convex, electron, menubar, openai, tokens, tracker, tray, usage

## 简介

Menu bar / system tray app and headless agent that tracks OpenAI Codex token usage, cache hits, model mix and API-equivalent cost — and syncs it to your team dashboard.
