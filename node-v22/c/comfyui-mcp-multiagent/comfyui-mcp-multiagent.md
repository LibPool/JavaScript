# comfyui-mcp-multiagent

> 标签: agent-skills, ai-agent, antigravity, claude-code, claude-plugin, claude-skills, comfyui, comfyui-extension, flux, image-generation, ltx-video, mcp, mcp-server, model-context-protocol, stable-diffusion, text-to-image, video-generation, wan, workflow-automation

## 简介

Antigravity + Claude Code plugin + MCP server for ComfyUI - 96 tools, 16 AI skills (Flux, WAN, LTX video, Qwen, Civitai), live graph editing from your Claude session. Generate images, video & audio, manage models and custom nodes.
