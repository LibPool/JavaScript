# custom-responsive-image

> 标签: aspect-ratio, contain, cover, custom, headless, icon, illustration, image, object-fit, responsive

## 简介

Framework-agnostic responsive image component with strict aspect ratio, object-fit (contain/cover/adaptive), and automatic small-image (icon/illustration) handling.
