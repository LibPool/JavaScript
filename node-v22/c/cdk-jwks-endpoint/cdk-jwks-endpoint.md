# cdk-jwks-endpoint

> 标签: api-gateway, aws-cdk, cdk, cloudfront, construct, jwk, jwks, jwks-uri, lambda-function-url, oidc, openid-connect

## 简介

CDK construct that serves JWKS stored in Secrets Manager or SSM parameters from a jwks_uri behind a Function URL, CloudFront, an HTTP API or REST API
