# cortico-provider-gemini-web

> 标签: cdp, cortico, cortico-provider, gemini, gemini-web

## 简介

Cortico 的 Gemini Web Provider（Windows）：通过内嵌 Electron 使用已登录的 Gemini 网页。必须与 cortico-world-gemini-web 同时安装，二者互为刚需。

## 官网

- npm 页面：https://www.npmjs.com/package/cortico-provider-gemini-web
