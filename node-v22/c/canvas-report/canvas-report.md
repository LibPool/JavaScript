# canvas-report

> 标签: canvas, editor, image, picture, 编辑器

## 简介

canvas的图片编辑器，可以任意旋转画图，方形、圆形、文字、对勾、箭头、放大、缩小，橡皮、重置、不会出现旋转或放大或移动后，鼠标路径与绘制路径不符情况
