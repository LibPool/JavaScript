# cxselect

> 标签: jquery plugin, select

## 简介

cxSelect 是基于 jQuery 的多级联动菜单插件，适用于省市、商品分类等联动菜单。

## 官网

- 官网：http://code.ciaoca.com/jquery/cxSelect/
- 源码仓库：git+https://github.com/ciaoca/cxSelect.git
- npm 页面：https://www.npmjs.com/package/cxselect

- 1.4.0
