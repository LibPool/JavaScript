# cloudgo-figma-frontend-kit

> 标签: agent-skill, bem, bootstrap, claude, cloudgo, css, design-system, figma, figma-console-mcp, html, mcp, omp, tailwindcss

## 简介

CloudGO Figma Frontend Kit — an installable Agent Skill that turns a Figma design link into a machine-readable design-system + faithful Bootstrap 5 / TailwindCSS HTML/CSS. Ships the skill payload and a CLI that installs it into your agent's skills folder
