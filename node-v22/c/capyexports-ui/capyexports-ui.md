# capyexports-ui

> 标签: UI components, component library, customizable, gradient, react

## 简介

`capyexports-ui` 是一个自定义的 React 组件库，提供多样化的 UI 组件，如带渐变背景的容器组件、按钮等。该库支持 TypeScript、CSS Modules、动态样式配置，适用于快速构建响应式和可定制的界面。
