# codemode-workers

> 标签: agent, cloudflare, code-execution, code-mode, llm, mcp, model-context-protocol, openapi, sandbox, tools, worker-loader, workers

## 简介

Expose any API to an LLM agent as two sandboxed MCP tools (search + execute) on Cloudflare Workers.
