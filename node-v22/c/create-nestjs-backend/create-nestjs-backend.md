> 标签: better-auth, boilerplate, cli, drizzle, liquibase, nestjs, postgresql, prisma, scalar, typeorm

## 简介

An opinionated NestJS backend stack generator with ORM choices, Better Auth, Liquibase, Scalar, Oxc tooling, and strict TypeScript.
