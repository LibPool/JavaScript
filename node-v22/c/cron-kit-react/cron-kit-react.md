# cron-kit-react

> 标签: cron, cron-expression, crontab, form, quartz, react, react-component, scheduler

## 简介

React 版 Cron 表达式可视化组件：可在表单与弹窗中配置，实时给出中文描述与最近运行时间，零运行时依赖。
