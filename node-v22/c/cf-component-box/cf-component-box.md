# cf-component-box

> 标签: JavaScript

## 简介

Cloudflare Box Component

This is styling component similar to cf-component-flex which allows for arbitrary styling.

 This component should only be used when the built in style doesn't quite fit the bill and when it can't be done with fela. Ideally, cfui
