# cct-cli

> 标签: JavaScript

## 简介

npm install cct-cli -g # 成功后执行，可查看都有哪些命令 cct-cli # 执行create命令，根据提示选择自己需要装的模板和分支，自动会下载并且安装依赖，全部安装好后可以直接run cct-cli create <template-name>
