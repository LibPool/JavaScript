# create-es-plus

> 标签: ai, ant-design-vue, create, crud, element-plus, element-ui, es-plus, mcp, scaffold, starter, vue2, vue3

## 简介

Scaffold a runnable ES-Plus project in one command: npm create es-plus@latest. Pick a renderer (Vue 3 + Element Plus / Vue 2 + Element UI / Vue 3 + Ant Design Vue) and optionally wire the AI (MCP) toolchain.
