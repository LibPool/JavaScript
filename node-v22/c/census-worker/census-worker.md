# census-worker

> 标签: boundaries, cartography, census, geojson, government, statistics, usa

## 简介

Convenience functions for working with Census APIs: Statistics, Cartographic GeoJSON, lat/lng -> FIPS, and other niceties. Stuffed into a web worker
