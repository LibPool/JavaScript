# c3d-gcode-viewer-core

> 标签: 3d-printing, g-code, gcode, three.js, threejs, viewer, webgl

## 简介

Framework-agnostic 3D G-code viewer built on three.js: parser, extruded-bead geometry, and a plain THREE.Group/canvas wrapper.
