# chanjs-cli

> 标签: chanjs, chanjs-hono, cli, mvc, scaffold

## 简介

ChanJS / ChanJS-Hono 官方脚手架 CLI。可选框架（chanjs / chanjs-hono）× 类型（简单 / 完整），一条命令生成标准项目模板。

## 官网

- npm 页面：https://www.npmjs.com/package/chanjs-cli

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install chanjs-cli`
- npm registry：https://registry.npmjs.org/chanjs-cli
- Node 要求：>=22.0.0
