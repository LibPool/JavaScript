# context-bridge-mcp

> 标签: ai, claude, codex, context, gemini, mcp, memory, model-context-protocol

## 简介

Project-scoped shared memory as an MCP stdio server for Claude, Codex, and Gemini. Pluggable JSON/SQLite storage, auto-save hooks, and team attribution.
