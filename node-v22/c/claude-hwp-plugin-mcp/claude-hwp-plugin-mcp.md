# claude-hwp-plugin-mcp

> 标签: claude, claude-code, document, form-fill, hwp, hwpx, kordoc, korean, mcp, model-context-protocol, 한글

## 简介

MCP Server for HWP/HWPX Korean document control via Claude Code. Supports reading, form auto-fill, batch generation, document creation, and comparison.
