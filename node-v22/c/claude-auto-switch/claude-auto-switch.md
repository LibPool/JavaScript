# claude-auto-switch

> 标签: account-switcher, anthropic, claude, claude-code, cli, rate-limit, rotation, usage-limit

## 简介

Keep working across Claude usage limits: run Claude Code through ccx and it transparently switches to another of your accounts when one hits its cap.
