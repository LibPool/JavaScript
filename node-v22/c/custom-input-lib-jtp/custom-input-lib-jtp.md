# custom-input-lib-jtp

> 标签: JavaScript

## 简介

Input field that masks the last characters entered by the user. Masks on blur and retains the original value on focus of the input field This library was generated with [Angular CLI](https://github.com/angular/angular-cli) version 15.0.0.
