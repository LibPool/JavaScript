# com.kylin.di.layered

> 标签: architecture, dependency-injection, di, kdi, layered, mvvm

## 简介

Five-layer one-way dependency enforcement on top of Kylin DI. Marker interfaces (View / ViewModel / ApplicationService / DomainService / Data) and a build-time validator that rejects same-layer or upward injections.
