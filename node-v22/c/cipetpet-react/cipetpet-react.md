# cipetpet-react

> 标签: cipetpet, onnx, react, speech, stt, tts, turkish

## 简介

React hooks and components for cipetpet: Turkish text to speech (Antalia-2 Mini, EMA Lightning) and speech recognition (Duyu-small) in the browser.
