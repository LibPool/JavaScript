# code-session-memory

> 标签: ai, claude-code, codex, cursor, gemini-cli, mcp, memory, opencode, sessions, sqlite-vec, vector, vscode

## 简介

Automatically index OpenCode, Claude Code, Cursor, VS Code, Codex, and Gemini CLI sessions into a shared sqlite-vec vector database for semantic search across your AI coding history
