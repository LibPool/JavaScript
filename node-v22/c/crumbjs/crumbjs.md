# crumbjs

> 标签: JavaScript

## 简介

A Crumb egy magyar morfológiai generátor. Képes dinamikusan előállítani különböző magyar szavakat toldalékolással, de számos egyéb alapeszközt biztosít természetes mondatok generálásához.
