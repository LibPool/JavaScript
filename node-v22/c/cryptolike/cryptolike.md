# cryptolike

> 标签: api-client, bitcoin, crypto, crypto-payments, cryptocurrency, cryptolike, hmac, invoices, payment-gateway, payments, sdk, typescript, usdt, webhooks

## 简介

Official server-side SDK for the CryptoLike merchant API: signed requests (HMAC-SHA256), automatic Idempotency-Key, retries with backoff, typed resources generated from the OpenAPI spec, and webhook signature verification.
