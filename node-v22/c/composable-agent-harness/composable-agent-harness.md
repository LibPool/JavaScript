# composable-agent-harness

> 标签: agent, agent-harness, ai-agents, cli, llm, local-first, policy-engine, typescript

## 简介

Vessel — a composable agent harness: a thin core loop, behaviour IR compiled into every agent, hard policy enforcement instead of prompt-only rules; local-first and model-agnostic. Ships a single self-contained CLI (no runtime dependencies).
