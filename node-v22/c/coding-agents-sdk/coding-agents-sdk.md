# coding-agents-sdk

> 标签: agent-sdk, ai-agent, claude-code, codex, coding-agent, container, cursor, gemini, opencode, sandbox

## 简介

Run coding agents (Claude Code, Codex, Cursor, Gemini, OpenCode, Pi — CLI and SDK) behind one uniform TypeScript interface, with optional container and sandbox execution.
