# cli-pomodoro

> 标签: JavaScript

## 简介

A simple,  cross-platform [Pomodoro](https://en.wikipedia.org/wiki/Pomodoro_Technique)-like application that runs in your terminal! Requires [Node.js version 14 and up](https://nodejs.org/en/) to work.
