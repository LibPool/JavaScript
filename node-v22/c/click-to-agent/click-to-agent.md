# click-to-agent

> 标签: ai-agent, claude-code, click-to-agent, click-to-component, click-to-source, cursor, developer-tools, devtools, locator, nextjs, react, react-19, rsbuild, rspack, source-locator, source-map, tanstack, turbopack, vite, vscode

## 简介

Alt+Click any React component to jump to source (Cursor, VS Code) or send props, state & DOM to AI agents. Works with Next.js, Vite, TanStack Start & Rsbuild — no browser extension.
