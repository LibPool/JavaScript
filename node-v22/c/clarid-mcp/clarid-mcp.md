# clarid-mcp

> 标签: ai-agent, clarid, claude, cursor, documentation, mcp

## 简介

MCP server for Clarid — populate your project's source-of-truth docs from code, keep them in sync, and read them from Claude Code, Cursor and other MCP clients.
