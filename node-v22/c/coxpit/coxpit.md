# coxpit

> 标签: ai-agents, claude-code, cockpit, coding-agents, fleet, git-worktree, self-hosted, tmux

## 简介

Self-hosted cockpit for running a fleet of AI coding agents across your own machines — parallel worktree runs, live board, compare & merge, web terminal, design capture.
