# cross-domain-localstorage

> 标签: browser storage sharing, cross domain localstorage, cross origin storage, cross subdomain storage, iframe localstorage hack, javascript storage sdk, localstorage iframe, postmessage storage, share localstorage across domains, static website storage

## 简介

Share localStorage across subdomains and different domains using iframe and postMessage. Works on static websites without backend.
