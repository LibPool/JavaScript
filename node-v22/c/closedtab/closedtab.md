# closedtab

> 标签: aar, adr, after-action-report, agent, audit, closedtab, documentation, handoff, human-agent, mcp, reconciliation, scaffold, trace

## 简介

Review the work your AI agents do. Scaffold an Agent Action Record (Intent, Action, Judgment, Deviation, Consequence, Change), score it, and reconcile it against a trace of what the agent actually did. CLI + MCP.
