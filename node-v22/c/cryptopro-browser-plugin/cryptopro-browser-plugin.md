# cryptopro-browser-plugin

> 标签: cryptopro, plug-in

## 简介

КриптоПро ЭЦП Browser plug-in предназначен для создания и проверки электронной подписи (ЭП) на веб-страницах с использованием СКЗИ "КриптоПро CSP"
