# create-llms-txt

> 标签: aeo, agents, ai-search, ai-seo, answer-engine-optimization, generative-engine-optimization, generator, geo, llm, llms.txt, llmstxt, machine-readable, scaffold, seo

## 简介

Write an llms.txt for your site in one command. Reads your routes, so the file lists what is actually on the site. Optionally adds a Human/Machine pill so visitors can read it too.
