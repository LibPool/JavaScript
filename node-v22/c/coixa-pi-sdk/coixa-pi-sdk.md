# coixa-pi-sdk

> 标签: JavaScript

## 简介

A lightweight TypeScript/JavaScript SDK for interacting with the Pi Network blockchain, designed for wallet management and transaction operations. Part of the [Coixa Wallet](https://coixa.xyz) project.
