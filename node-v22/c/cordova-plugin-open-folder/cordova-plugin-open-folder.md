# cordova-plugin-open-folder

> 标签: android, cordova, cordova-android, ecosystem:cordova, file explorer, file manager, sap neptune, zebra

## 简介

Cordova/Android plugin to open a given folder path directly in the device's native file manager app (no picker dialog).
