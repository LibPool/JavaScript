# cross-frame-messenger

> 标签: communication, cross-frame, messaging, postmessage, typescript

## 简介

A flexible and easy-to-use library for enabling cross-frame communication in web applications. Supports TypeScript and offers customizable options for robust messaging across different window contexts.
