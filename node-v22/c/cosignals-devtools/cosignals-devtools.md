# cosignals-devtools

> 标签: chrome-extension, cosignals, debugger, debugging, dependency-graph, devtools, react, signals, state-management, tracing

## 简介

Devtools for cosignals: a live dependency-graph explorer and a causal event log inline in your app or as a Chrome DevTools panel.
