# create-quickadui

> 标签: cli, quickadui, react, scaffold, vite

## 简介

create-quickadui — scaffolds a Vite + React + Tailwind v4 project (`quickadui init`) and installs QuickadUI packages into it (`quickadui add`). Editing an existing project's CSS is left to the person (see README) — narrower than the original framework-det
