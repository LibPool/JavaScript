# chromeship

> 标签: browser-extension, chrome-extension, cli, dev-tools, mcp, monetization, scaffolding, stripe, supabase

## 简介

Build, run, and monetize Chrome extensions from one local studio with managed runtimes, backend integrations, a CLI, dashboard, and MCP server.
