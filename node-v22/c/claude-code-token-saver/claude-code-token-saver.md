# claude-code-token-saver

> 标签: ai, anthropic, claude, claude-code, developer-tools, hooks, scaffold, subagents, token-saver

## 简介

One-shot installer that adds token-saving Claude Code rails (CLAUDE.md, hooks, subagents, slash commands, dev-docs) to any git repo.
