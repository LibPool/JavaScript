# compute-nanqmean

> 标签: computation, compute, compute.io, math, mathematics, mean, nan, quadratic mean, rms, root mean square, statistics, stats

## 简介

Computes the quadratic mean (root mean square) of an array of values ignoring any values which are not numeric.
