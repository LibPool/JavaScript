# contrast-color

> 标签: accessibility, background, black, bright, brighten, brightness, chroma, color, colors, contrast, convert, css, dark, darken, font, foreground, hex, hsl, hsv, light, lightness, luma, luminosity, rgb, text, wcag, white, yiq

## 简介

Determines the best contrast color to use. Give it a background color and it returns a foreground color (black or white by default but customizable).
