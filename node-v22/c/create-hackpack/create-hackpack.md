# create-hackpack

> 标签: authentication, better-auth, boilerplate, cli, cloudflare-workers, composable, create, crud-generator, d1, deterministic, drizzle, fastapi, full-stack, generator, hackathon, hono, nextjs, npx, nuxt, project-generator, python, react, scaffold, scaffolding, shadcn, starter-kit, starter-template, svelte, sveltekit, typescript, vite, vue

## 简介

CLI to scaffold full-stack hackathon projects in seconds. Pick a framework, add features (UI, auth, DB, AI), generate CRUD pages, deploy to Cloudflare Workers. Run with npx create-hackpack.
