# cv-ember-core

> 标签: JavaScript

## 简介

Ember Core Services, Utilities and Framework for building Fleetbase Extensions in the Console. To start building with Fleetbase, you need to install `ember-core`, which is built using Ember, a JavaScript framework for building web applications
