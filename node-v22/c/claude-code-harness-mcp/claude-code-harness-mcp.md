# claude-code-harness-mcp

> 标签: ai-agent, antigravity, claude-code, cli, cursor, mcp, model-context-protocol

## 简介

MCP server that routes functionality/backend/logic tasks from any AI coding agent to a local Claude Code session, while the host agent keeps doing design/UI work itself.
