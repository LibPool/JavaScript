# cm-image-cropper

> 标签: angular, angular-image-cropper, angular-library, cm image cropper, cm image editor, cropper, customizable, image cropper, image cropper for angular, image editor for angular, image-cropper, image-formatting, open-source, rich image cropper, rich image editor, toolbar, typescript, wysiwyg

## 简介

An Angular library for cropping images with extensive customization options. It allows free or aspect-ratio-constrained cropping, color adjustments, rotation, flipping, and more. The cropped image is returned as a file via an output event.
