# crispy-mcp

> 标签: ai-agents, crispy, linkedin, mcp, modelcontextprotocol, stdio

## 简介

Local stdio MCP bridge for Crispy, the LinkedIn MCP server. Proxies every request to https://crispy.sh/api/mcp for clients that cannot send custom headers.

## 官网

- 官网：https://crispy.sh
- 源码仓库：git+https://github.com/shyftai/crispy-mcp.git
- npm 页面：https://www.npmjs.com/package/crispy-mcp
