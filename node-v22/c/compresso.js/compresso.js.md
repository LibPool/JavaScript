# compresso.js

> 标签: accessibility, avif, batch-processing, browser, canvas, client-side, compress-image, compression, exif, file-upload, heic, heif, image, image-compressor, image-optimizer, image-processing, image-resize, jpeg, lightweight, offscreencanvas, optimize, parallel, png, resize, typescript, web-worker, webp, webworker, zero-dependency

## 简介

Tiny image optimizer that runs entirely in the browser — a 3.6 KB core with zero required dependencies. Compress, resize, and convert images (HEIC/HEIF input supported), with parallel Web Worker batching, on the client side — no server needed.
