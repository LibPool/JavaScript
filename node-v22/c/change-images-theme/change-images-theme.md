# change-images-theme

> 标签: cli, color, image, jpg, png, rebrand, recolor, sharp, theme, theming

## 简介

A Node.js CLI that applies a visual theme to PNG/JPG assets: match brand hues in HSL, recolor with CSS hue-rotate, and preserve alpha (rebrand / white-label friendly).
