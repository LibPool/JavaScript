# colourlovers

> 标签: color, colourlovers, designer, palettes, pattern

## 简介

COLOURlovers for Node.js is a connection library for COLOURlovers API, giving you access to an infinite database of colors, palettes, patterns and a lot more provided by COLOURlovers.
