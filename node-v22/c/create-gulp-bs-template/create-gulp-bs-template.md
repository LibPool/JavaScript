# create-gulp-bs-template

> 标签: bootstrap, browser-sync, gulp, html

## 简介

Get a head start on your next web project with this HTML and Bootstrap starter template. Includes SCSS for easy styling and Browser-Sync for live reloading. Everything you need to build a modern, responsive website.
