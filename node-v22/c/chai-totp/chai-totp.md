# chai-totp

> 标签: Google authenticator, Two-factor authentication, hotp, otp, totp

## 简介

TOTP (Time-Based One-Time Password Algorithm), 两步验证中使用的密码是一次性密码（One-Time Password 简称OTP），动态口令
