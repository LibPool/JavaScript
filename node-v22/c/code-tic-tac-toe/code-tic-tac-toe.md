# code-tic-tac-toe

> 标签: angular, game, react, react js, tictactoe, typescript, vue, vue js

## 简介

Tic Tac Toe Engine provides the behind the scenes logic for tic tac toe game play. The library is supported by all the major platforms like Angular, React JS and Vue JS.
