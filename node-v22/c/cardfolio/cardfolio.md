# cardfolio

> 标签: JavaScript

## 简介

## Overview Cardfolio is a sleek and professional digital business card and portfolio template built with **Next.js, Tailwind CSS, and Framer Motion**. This template provides a modern and interactive way to showcase personal or professional work online.
