# @swerver/nether-sdk

> 标签: control-protocol, microvm, nether, sandbox, sdk

## 简介

TypeScript SDK for the nether sandbox control protocol: a high-level Sandbox facade plus the low-level wire codec and role clients. Zero runtime dependencies.
