# @gramstax/worker-thread

> 标签: bun, gramstax, ipc, nodejs, rpc, thread, typescript, unix-socket, worker, worker-thread

## 简介

Worker thread lifecycle with type-safe RPC, inter-worker socket gateway, and worker pools. Multi-runtime (Bun, Node.js).
