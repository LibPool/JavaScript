# @super-line/collections-crdt-pglite

> 标签: collaboration, collections, crdt, electric, pglite, postgres, self, super-line, sync, yjs

## 简介

Self-clustering CRDT (Yjs, via super-store) document collection backend for super-line — an append-only op-log in central Postgres that ElectricSQL ships to a per-node PGlite replica; validate-before-commit at ingress; no adapter.
