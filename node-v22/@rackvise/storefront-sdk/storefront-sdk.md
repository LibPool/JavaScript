# @rackvise/storefront-sdk

> 标签: ecommerce, multi-tenant, rackvise, sdk, storefront, tanstack-query

## 简介

Immutable storefront SDK for Rackvise multi-tenant e-commerce platform. Wraps public APIs with TanStack Query for type-safe caching.
