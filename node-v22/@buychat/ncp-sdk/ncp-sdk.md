# @buychat/ncp-sdk

> 标签: agent, ai-agent, buychat, ed25519, marketplace, ncp

## 简介

TypeScript SDK for the BuyChat Neural Commerce Protocol (NCP v1). Ed25519-signed agent client for rank, search, negotiate, threads, and conformance endpoints.
