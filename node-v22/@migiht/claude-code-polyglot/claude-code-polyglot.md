# @migiht/claude-code-polyglot

> 标签: anthropic, bergamot, claude-code, i18n, machine-translation, offline-translation, proxy, translation

## 简介

Work with Claude Code in your native language: a local proxy translates your prompts for the model and its replies for you, fully offline. Code, paths, and tool calls are never touched.
