# @advui/core

> 标签: JavaScript

## 简介

Cross-platform React / React Native components built on Tamagui: buttons, forms, overlays, navigation, feedback, layout and media. Data, chart and editor components ship in @advui/data, @advui/charts and @advui/editor.
