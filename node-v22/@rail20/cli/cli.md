# @rail20/cli

> 标签: agents, base, cli, groth16, onchain, privacy, rail20, web3, zero-knowledge, zk

## 简介

Private payments for onchain agents. CLI for RAIL20 - shield, send, swap, bridge with zero-knowledge privacy on Base, Robinhood Chain, Arbitrum, and BNB Smart Chain.
