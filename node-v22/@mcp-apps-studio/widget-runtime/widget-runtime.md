# @mcp-apps-studio/widget-runtime

> 标签: ext-apps, mcp, mcp-apps, react, widget

## 简介

Studio conveniences on top of the official MCP Apps SDK App: connectWidget (tool lifecycle recorded before the handshake, host theme applied) and React hooks.
