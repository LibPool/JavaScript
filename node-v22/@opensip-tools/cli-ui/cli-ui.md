# @opensip-tools/cli-ui

> 标签: cli, code-quality, ink, opensip-tools, react, static-analysis, terminal

## 简介

Shared Ink/React presentational primitives for OpenSIP Tools CLI tools — banner, spinner, run header, theme. Used by every tool that ships an Ink live view.
