# @depup/ts-jest

> 标签: depup, jest, latest, patched, react, security, sourcemap, testing, ts-jest, typescript, updated-dependencies

## 简介

A Jest transformer with source map support that lets you use Jest to test projects written in TypeScript (with updated dependencies)
