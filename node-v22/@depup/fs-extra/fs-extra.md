# @depup/fs-extra

> 标签: copy, create, delete, depup, directory, extra, file, file system, fs, fs-extra, json, latest, mkdir, mkdirp, mkdirs, move, output, patched, promise, read, recursive, remove, security, text, touch, updated-dependencies, write

## 简介

fs-extra contains methods that aren't included in the vanilla Node.js fs package. Such as recursive mkdir, copy, and remove. (with updated dependencies)
