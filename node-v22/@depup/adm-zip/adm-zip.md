# @depup/adm-zip

> 标签: adm-zip, archive, depup, latest, methods, patched, security, unzip, updated-dependencies, zip

## 简介

Javascript implementation of zip for nodejs with support for electron original-fs. Allows user to create or extract zip files both in memory or to/from disk (with updated dependencies)
