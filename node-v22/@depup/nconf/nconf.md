# @depup/nconf

> 标签: configuration, depup, key value store, latest, nconf, patched, plugabble, security, updated-dependencies

## 简介

Hierarchical node.js configuration with files, environment variables, command-line arguments, and atomic object merging. (with updated dependencies)
