# @depup/typeorm

> 标签: depup, latest, patched, security, typeorm, updated-dependencies

## 简介

Data-Mapper ORM for TypeScript and ES2023+. Supports MySQL/MariaDB, PostgreSQL, MS SQL Server, Oracle, SAP HANA, SQLite, MongoDB databases. (with updated dependencies)
