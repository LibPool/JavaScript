# @depup/css-tree

> 标签: JavaScript

## 简介

A tool set for CSS: fast detailed parser (CSS → AST), walker (AST traversal), generator (AST → CSS) and lexer (validation and matching) based on specs and browser implementations (with updated dependencies)
