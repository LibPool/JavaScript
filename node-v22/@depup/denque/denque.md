# @depup/denque

> 标签: data-structure, data-structures, denque, dependency-bumped, depup, deque, double, double-ended-queue, end, ended, queue, updated-deps

## 简介

[DepUp] The fastest javascript implementation of a double-ended queue. Used by the official Redis, MongoDB, MariaDB & MySQL libraries for Node.js and many other libraries. Maintains compatability with deque.
