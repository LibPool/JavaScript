# @depup/memcached

> 标签: InnoDB memcached API, cache, client, cluster, dependency-bumped, depup, failover, hashing, membase, memcache, memcached, nMemcached, nosql, updated-deps

## 简介

[DepUp] A fully featured Memcached API client, supporting both single and clustered Memcached servers through consistent hashing and failover/failure. Memcached is rewrite of nMemcached, which will be deprecated in the near future.
