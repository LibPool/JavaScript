# @onebooks/app-bridge

> 标签: accounting, app-bridge, embedded-app, iframe, onebooks, postmessage, sdk

## 简介

Browser SDK for OneBooks embedded apps: App Bridge protocol v1 (postMessage) — session tokens, host navigation, toasts, dialogs and auto-resize.
