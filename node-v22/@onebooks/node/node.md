# @onebooks/node

> 标签: accounting, api-client, oauth, onebooks, sdk, session-token, webhooks

## 简介

Server-side SDK for the OneBooks API: authenticated requests with retries, OAuth helpers (PKCE, code exchange, refresh, session-token exchange), ES256 session-token verification and webhook signature verification.
