# @kinginsun/mcp-drugsea

> 标签: cde, cli, drugsea, mcp, model-context-protocol, nmpa, pharmaceutical, yaohai

## 简介

MCP server for DrugSea / Yaohai pharmaceutical databases: cross-db search, China marketed products (product_cn), and CDE registration review (reg_cn).
