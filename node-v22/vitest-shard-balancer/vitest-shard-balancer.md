# vitest-shard-balancer

> 标签: ci, duration, github-actions, knapsack, load-balancing, parallel, shard, sharding, split-tests, test-sharding, test-splitting, timings, vitest, vitest-reporter, vitest-sequencer

## 简介

Balance Vitest --shard runs by measured test file durations: timing-based test splitting for parallel CI, instead of Vitest's split by path hash.
