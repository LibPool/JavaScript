# @yaosu/pi-path-guard

> 标签: path-guard, permission, pi-extension, pi-package, safety

## 简介

Path Guard for pi — blocks destructive commands & path overwrites, protects .env/keys, with strict/normal/loose/trusted/naked guard modes (/guard). pi 防误删/防误覆盖扩展，支持 5 种防护模式。
