# @pond-ts/charts

> 标签: analytics, candlestick, canvas, charts, dashboard, line-chart, ohlc, pond-ts, react, react-timeseries-charts, realtime, streaming, time-series, timeseries, typescript, visualization

## 简介

Canvas-rendered, streaming-first React time-series charts for pond-ts: line, area, band, bar, scatter, box, candlestick, with cursors, selection and annotations
