# @ulu/vite-plugin-virtual-modules

> 标签: JSON, SSG, build-time, codegen, data, dynamic-modules, fetch, hmr, loader, plugin, virtual, virtual-modules, vite, vite-plugin

## 简介

A Vite plugin to create virtual modules from loader files at build time, with support for HMR, file watching, and query parameters.
