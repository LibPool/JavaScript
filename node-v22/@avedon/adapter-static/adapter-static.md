# @avedon/adapter-static

> 标签: JavaScript

## 简介

Fail-closed static export for Avedon. Writes only `build/client` (hashed assets + SSG HTML). Deploy that folder to Cloudflare Pages, Netlify, GitHub Pages, S3/CDN, etc.
