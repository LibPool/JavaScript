> 标签: ai-image, claude, glassypic, image-compression, image-optimization, image-resize, image-upscale, mcp, mcp-server, model-context-protocol, seo, webp

## 简介

GlassyPic MCP server transforms raw images into production-ready assets in one workflow: upscale, resize, crop, compress, convert file formats, and generate SEO-friendly filenames and alt text
