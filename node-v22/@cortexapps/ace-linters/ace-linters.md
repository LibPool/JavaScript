# @cortexapps/ace-linters

> 标签: ace-editor, code-completion, code-formatting, error-checking, intellisense, language client, language server protocol, linting, lsp

## 简介

Ace linters is lsp client for Ace editor. It comes with large number of preconfigured easy to use in browser servers.
