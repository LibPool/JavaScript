# @paybilldev/rra-ebm-sdk

> 标签: ebm, osdc, rra, sdk, vsdc

## 简介

A production-ready Node SDK for integrating with the Rwanda Revenue Authority (RRA) EBM OSDC (Online Sales Data Controller) and VSDC (Virtual Sales Data Controller) API
