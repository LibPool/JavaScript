# @markii/lua

> 标签: lua, mark, markdown, mk.md, sandbox, scripting, wasmoon

## 简介

Sandboxed Lua 5.4 (wasmoon) execution runtime for Mark's document scripting: an empty-env global whitelist, two-tier capability-gated net/cache/bundle access, instruction-count/wall-clock/memory limits, and depth/size-capped Lua<->JS marshaling.
