# @moneva/mcp

> 标签: kyc, mcp, model-context-protocol, moneva, payments, payouts, stablecoin

## 简介

Model Context Protocol server for the Moneva Platform API: onboard customers, price and send payouts, and drive the sandbox from any MCP host.
