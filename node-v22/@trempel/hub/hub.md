# @trempel/hub

> 标签: cli, hub, launcher, projects, trempel

## 简介

Trempel hub: one control panel per machine for Trempel projects — finds projects, runs their actions (a layer of the hub, of the user, of the project's kit version and of the project) from a local web page or the `trempel` CLI, keeps track of long-running
