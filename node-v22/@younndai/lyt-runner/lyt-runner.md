# @younndai/lyt-runner

> 标签: automator, lyt, runner, yon, younndai

## 简介

Lyt automation runner — a thin layer on @younndai/yon-runner that expands declarative @AUTOMATOR + @DIRECTIVE records into core YON before execution and registers the vault-aware std:vault.* + std:mesh.* + std:lease.* ops.
