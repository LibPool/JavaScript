# @share-the-mark/embed

> 标签: annotation, feedback, markdown, playwright, screenshot, widget

## 简介

Embeddable, browser-free annotation widget for share-the-mark — annotate a live page and export a Markdown changelog plus an annotated screenshot, no extension required.
