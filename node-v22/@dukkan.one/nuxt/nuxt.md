# @dukkan.one/nuxt

> 标签: dukkan, nuxt, nuxt-module, oauth, webhooks

## 简介

Nuxt module for Dukkan apps: mounts the OAuth install and callback routes and the signed webhook receiver on top of @dukkan.one/app-sdk.

## 官网

- 官网：https://developer.dukkan.one/docs/sdk/nuxt
- 源码仓库：git+https://github.com/dukkan-one/app-sdk.git
- npm 页面：https://www.npmjs.com/package/@dukkan.one/nuxt
