# @danypops/pi-rpc-protocol

> 标签: jsonl, pi, pi-extension, protocol, rpc

## 简介

A small, dependency-free parser/encoder for the subset of Pi's documented RPC protocol needed by clients speaking to a pi --mode rpc process.
