# @danypops/pi-eval-harness

> 标签: agent-evaluation, eval, pi, pi-extension, testing, tool-call

## 简介

Scores a real agent run's own tool-call behavior -- AND/OR tool-call matching, graduated checker composition, and turn/tool-call/token-usage rollups -- over Pi's own real AgentSessionEvent stream (e.g. from @danypops/pi-process-harness).
