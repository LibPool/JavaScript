## 简介

ゲーム発売くん — ゲームクリエイター・ゲーム企業のための販売支援 MCP サーバー。Claude / Codex / Gemini CLI から Steam のレビュー・ストア情報を取得・集計し、日本市場向けのマーケ分析・改善提案に使う。
