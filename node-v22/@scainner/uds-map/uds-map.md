# @scainner/uds-map

> 标签: automotive, can-bus, car-diagnostics, iso14229, obd2, uds, vin

## 简介

A queryable knowledge map of manufacturer-specific UDS (ISO 14229) diagnostic addresses and DID ranges for 21 car brands, keyed by VIN — the data behind Scainner's auto-discovery engine.
