# @linbin-mk/dsh-client-ui-settings-sync

> 标签: cordis, deepseek, deepseek-harness, dsh, dsh-plugin, react, session-sync, settings, typescript, web-client

## 简介

Session sync settings plugin for the dsh web GUI: the Sync section page with git remote, cadence, project mappings, and manual sync, talking to the host through the plugin's own same-origin HTTP API
