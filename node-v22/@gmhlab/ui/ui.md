# @gmhlab/ui

> 标签: base-ui, components, design-system, react, shadcn, tailwindcss

## 简介

React 19 component library for the GMH Lab design system — shadcn/Tailwind primitives plus MFY layout primitives, built on Base UI and React Aria.
