# @snvshal/sndo

> 标签: JavaScript

## 简介

`sndo` is a **Model Context Protocol (MCP) server** that securely exposes a user’s personal context (areas, tasks, notes, achievements) via **API key–based access**, designed for AI agents and MCP-compatible clients.
