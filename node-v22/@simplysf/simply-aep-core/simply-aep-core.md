# @simplysf/simply-aep-core

> 标签: at4dx, fflib, force, salesforce, salesforcedx, sf, sf-plugin, sfdx, sfdx-plugin

## 简介

Apex Enterprise Patterns (fflib, force-di, AT4DX) scan and resolution logic — the library layer behind @simplysf/simply-aep, published separately for direct consumption (e.g. editor tooling) without the CLI framework
