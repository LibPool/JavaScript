# @n0n3br/ngx-dynamic-forms-core

> 标签: JavaScript

## 简介

Shared foundation for the ngx-dynamic-forms suite: schema models, versioning + publish workflow, permissions, field-type registry, persistence ports (with a default IndexedDB implementation), draft merging and the field runtime used by both the responder
