# @fuguejs/xlsx

> 标签: JavaScript

## 简介

Pure workbook parsing for Fugue DAGs. `parseWorkbook` turns `.xlsx` bytes into Zod-validated typed rows. It is a pure function (deterministic, no I/O) — fetching the bytes is a [`documents`](../document-source) capability concern ([`@fuguejs/fs`](../adapt
