# @lagroon/inkwell-design-system

> 标签: JavaScript

## 简介

Inkwell is a React design system: typed components, a three-tier token pipeline, and one stylesheet. It is published as `@lagroon/inkwell-design-system` and is designed to sit inside an application without taking over its styling.
