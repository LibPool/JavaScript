# @fulate/yoga

> 标签: JavaScript

## 简介

`@fulate/yoga` 用 `yoga-layout` 为 Canvas 元素提供 Flex 布局。`Div` 是带 Yoga 样式的矩形容器， `Span` 是带文本测量的 Yoga 文本元素；两者都仍是普通 Fulate Node/Element，不创建独立场景树。
