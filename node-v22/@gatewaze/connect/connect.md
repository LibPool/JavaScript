# @gatewaze/connect

> 标签: JavaScript

## 简介

One-command setup that connects your AI clients (Claude Desktop, Claude Code, Goose, ChatGPT) to a Gatewaze MCP server.

- 源码仓库：git+https://github.com/gatewaze/gatewaze.git
