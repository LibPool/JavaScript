# @gatewaze/host-session

> 标签: JavaScript

## 简介

Framework-free session-holder core for Gatewaze host-session mode: GoTrue sign-in and refresh, an encrypted Redis session store, CSRF and token-rewriting rules, an HTTP proxy and a Realtime bridge.
