# @owli/agent-sdk

> 标签: ai-agent, decentralized-identity, double-ratchet, e2ee, forward-secrecy, nostr

## 简介

Headless Node.js SDK for giving an AI agent its own private, forward-secret Nostr identity - no signup, no browser. Phase 1 of the ai.owli.chat initiative.
