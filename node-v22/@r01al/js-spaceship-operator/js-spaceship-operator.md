# @r01al/js-spaceship-operator

> 标签: comparison, loader, operator, spaceship, webpack

## 简介

A Webpack loader that adds a JavaScript spaceship (<=>) comparison operator. This project was inspired by the spaceship operator introduced in PHP 7.
