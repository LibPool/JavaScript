# @vsfedorenko/next-logger

> 标签: consola, console, instrumentation, json, json-logging, logger, logging, logs, next.js, nextjs, observability, patch, pino, sentry, structured-logging, turbopack, winston

## 简介

Universal logging kit for Next.js — wraps console.* (Next's own logs included) and routes output through one sink: consola by default, Sentry/JSON/Winston and more as reporters.
