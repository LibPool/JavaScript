# dsh-expr-engine

> 标签: calculator, computed-column, dsh, eval, excel, expression, formula, parser, plugin

## 简介

Expression engine plugin for DeepSeek Harness: recursive-descent parser, Excel-style operator precedence, 40+ function library (IF/SUM/ROUND/MID...), single-expression eval, syntax validation with position, and per-row computed columns for JSON data. Pure
