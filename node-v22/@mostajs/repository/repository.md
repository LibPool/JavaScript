# @mostajs/repository

> 标签: JavaScript

## 简介

Generic Repository<T> abstraction over @mostajs/data-plug. CRUD + query DSL + composable middlewares (tenant scoping, soft-delete, audit). Backend-agnostic: Mongo / Postgres / REST decided by MOSTA_DATA env.
