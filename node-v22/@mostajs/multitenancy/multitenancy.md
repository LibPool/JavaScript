# @mostajs/multitenancy

> 标签: JavaScript

## 简介

Tenant context + AsyncLocalStorage scoping for multi-tenant @mostajs/* apps. Express/Next/Fastify middleware pour extraire le tenantId par requête. Composable avec @mostajs/repository (withTenantScope).
