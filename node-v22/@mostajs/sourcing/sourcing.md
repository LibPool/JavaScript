# @mostajs/sourcing

> 标签: marketplace, mostajs, procurement, rfq, sourcing, supplier, trading

## 简介

Agent de sourcing / procurement réutilisable : découverte d'offres sur le marché (web + places de marché + fournisseurs connus), normalisation, scoring multi-critères, RFQ hybride. Connecteurs pluggables ; LLM/web injectés (DI). Composé par @mostajs/chatb
