# @mostajs/markdown-html

> 标签: docs, html, markdown, mostajs, no-build, readme, zero-dependency

## 简介

Rendu Markdown → HTML zéro dépendance, sans build : titres, listes, tableaux, code, citations, liens, cases à cocher + table des matières. Tout est échappé (le HTML d'un .md n'est PAS interprété). Pour servir un README comme page d'aide.
