# @mostajs/orm-copy-data

> 标签: backup, copy, cron, cross-dialect, csv, dump, json, migration, mosta, orm, sql

## 简介

Cross-dialect data copy — 1 source (DB/CSV/JSON/SQL) → N destinations (DB/SQL dump/JSON/CSV). Backup, migration, seeding. CLI + API + .env-piloted `mostajs-load`. Cron-ready.
