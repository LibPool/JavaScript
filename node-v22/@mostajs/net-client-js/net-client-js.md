# @mostajs/net-client-js

> 标签: client, dialect-proxy, fetch, javascript, mostajs, net, polyglot, rest, typescript

## 简介

Lightweight HTTP client + dialect proxy for @mostajs/net server. JS/TS — companion of the 14 polyglot clients (Java, Rust, Python, Go, Lua, …). Zero deps, uses native fetch.
