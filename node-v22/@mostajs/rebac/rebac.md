# @mostajs/rebac

> 标签: access-control, authorization, graph, mostajs, prolog, rebac, relationship, zanzibar

## 简介

ReBAC (Relationship-Based Access Control) pour @mostajs — tuples de relations + réaccessibilité par graphe via le moteur Prolog de @mostajs/rules. Composable en attribut/PIP dans abac/pbac.
