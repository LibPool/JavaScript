# @mostajs/auth-kit

> 标签: auth, mostajs, node-http, saas, session

## 简介

L'assemblage prêt à monter : @mostajs/auth-lite + sessions révocables en base + courriel, configuré par l'environnement. Pour un serveur node:http, sans framework.
