# @mostajs/markdown-editor

> 标签: editor, html, markdown, no-build, preview, toolbar, zero-dependency

## 简介

Éditeur Markdown live (barre d'outils + aperçu temps réel + import .md), zéro build. Compose @mostajs/markdown-html pour le rendu. Aperçu rendu côté serveur (même moteur que le site).
