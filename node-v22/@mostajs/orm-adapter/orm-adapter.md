# @mostajs/orm-adapter

> 标签: adapter, entity-schema, interoperability, json-schema, mostajs, openapi, orm, prisma, schema, swagger

## 简介

Bidirectional schema adapters for @mostajs/orm — Prisma / JSON Schema / OpenAPI / Native, both directions (to/fromEntitySchema)
