# @mostajs/appconfig

> 标签: admin, config, dotenv, env, mostajs, no-socle, settings

## 简介

Interface d'administration de la configuration .env des modules @mostajs/* : spec déclarative contribuée par module (chatbot, sourcing, chat, db…), résolution des valeurs courantes (secrets = présent/absent), édition validée et réécriture .env (I/O inject
