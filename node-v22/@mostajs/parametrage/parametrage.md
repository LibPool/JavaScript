# @mostajs/parametrage

> 标签: configuration, mostajs, multi-tenant, parametrage, saas, secrets, settings, white-label

## 简介

Moteur headless du paramétrage d'une instance (application ou SaaS) : sections déclarées par les modules (champs typés, départ, contrôle motivé), sources en cascade départ → données → base → .env, réglages par locataire, secrets chiffrés saisis à l'écran,
