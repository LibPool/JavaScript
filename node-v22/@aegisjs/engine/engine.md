# @aegisjs/engine

> 标签: cache, custom-elements, django, forms, framework, frontend, html-templates, htmx-alternative, hydration, islands, laravel, no-build, no-dependencies, offline-first, rails, reactive, router, server-rendered, signals, swr, ui, vanilla-js, web-components, zero-build

## 简介

Zero-build reactive UI engine for server-rendered pages: your server renders the HTML, Aegis makes parts of it alive. Signals, islands, html templates, an HTTP-aware cache, forms and a router in one ES module with no dependencies.
