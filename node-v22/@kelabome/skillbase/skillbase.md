# @kelabome/skillbase

> 标签: agent-skills, ai-agents, claude-code, claude-skills, codex, coding-agent, context-engineering, context-window, embeddings, local-first, mcp, mcp-server, model-context-protocol, opencode, prompt-engineering, semantic-search, skill-md, skills, skills-registry, vector-search

## 简介

Find agent skills by meaning, not keywords: local semantic search over shared git skill repos for Claude Code, Codex and OpenCode. An MCP server that keeps any number of skills out of your agent's context until you pick one.
