# @kdrdev/echo-markdown-editor

> 标签: component, editor, markdown, prosemirror, tiptap, vue, vue3, wysiwyg

## 简介

A WYSIWYG markdown editor component for Vue 3, built on Tiptap. You type on a rendered surface; v-model gives you markdown.
