# @candlelight-ds/eslint-plugin

> 标签: candlelight, design-system, eslint, eslint-plugin, eslintplugin

## 简介

Candlelight's governance as code — the spec's Appendix-D lint guards as a shareable ESLint flat-config plugin: token discipline, the gradient ban, wrapped primitives, one overlay engine, no bare keydown listeners.
