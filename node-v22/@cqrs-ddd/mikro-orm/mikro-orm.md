# @cqrs-ddd/mikro-orm

> 标签: cache, cqrs, ddd, mikro-orm, optimistic-concurrency, repository

## 简介

MikroORM persistence adapters for @cqrs-ddd/core: authoritative aggregate loading, version-conditioned writes, a revision-fenced cache and root-entity schema mapping.
