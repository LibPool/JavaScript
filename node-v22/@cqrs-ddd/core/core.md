# @cqrs-ddd/core

> 标签: aggregate, cache, cqrs, ddd, domain-driven-design, domain-events, repository

## 简介

Framework- and ORM-neutral DDD building blocks for TypeScript: aggregates and domain events, CQRS base classes and repository ports, and a revision-fenced repository cache, as separate entry points.
