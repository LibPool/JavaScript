# @rkarimabadi/model-probe

> 标签: cli, coding-agent, diagnostics, function-calling, gateway, llm, models, openai-compatible, probe, tool-calling

## 简介

Probe any OpenAI-compatible endpoint and report which models are actually usable in a coding agent (tool calling, tool round-trip, streaming).
