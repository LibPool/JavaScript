# n8n-nodes-formy

> 标签: e-signature, forms, formy, hebrew, israel, n8n, n8n-community-node-package

## 简介

n8n nodes for Formy, the Hebrew-first form builder: start a workflow when a form receives a new submission, read workspaces, forms and fields, and send documents for signature.
