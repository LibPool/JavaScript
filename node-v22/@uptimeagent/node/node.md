# @uptimeagent/node

> 标签: cloudflare-workers, edge, errors, incident, logging, logs, monitoring, observability, pino, serverless, uptime, uptimeagent, winston

## 简介

Ship the errors your Node app already logs to UptimeAgent, so incidents arrive with your own error lines attached. Evidence only — never votes on uptime. Zero dependencies.
