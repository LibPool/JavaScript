# @webority/mobile-core

> 标签: auth, axios, formatters, network, ota, permissions, react-native, storage, validators, webority

## 简介

Platform layer for Webority React Native apps: HTTP clients, auth/token storage, config, logging, formatters, validators, network status, permissions, storage, version checks and over-the-air updates. No UI.
