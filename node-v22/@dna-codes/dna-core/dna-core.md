# @dna-codes/dna-core

> 标签: business-modeling, cell-based-architecture, dna, dsl, json-schema

## 简介

DNA — a JSON description language for business systems. Ships typed schema bindings, a JSON-schema manifest, and the cross-layer validator. Schemas themselves live in @dna-codes/dna-schemas.
