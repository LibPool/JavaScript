# @igor.dvlpr/registry-apppaths

> 标签: applications, apppaths, igor.dvlpr, igorskyflyer, packages, registry, user, windows

## 简介

🪀 A Node.js module for reading the AppPaths registry key on Windows. Useful for retrieving applications that can be launched from the command prompt. 🗃

- 官网：https://github.com/igorskyflyer/npm-registry-apppaths
- 源码仓库：git+https://github.com/igorskyflyer/npm-registry-apppaths.git
- npm 页面：https://www.npmjs.com/package/@igor.dvlpr/registry-apppaths

- 1.0.0

## 获取地址

- npm 安装：`npm install @igor.dvlpr/registry-apppaths`
- npm registry：https://registry.npmjs.org/@igor.dvlpr/registry-apppaths
- Node 要求：>=20.0
