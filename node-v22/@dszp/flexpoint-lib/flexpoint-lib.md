# @dszp/flexpoint-lib

> 标签: cloudflare-workers, flexpoint, integration, invoicing, merchant, msp, payments

## 简介

Portable, Node-free, read-only client for the FlexPoint merchant API: automatic token login and refresh, lossless int64 ids, and complete-list walkers checked against record-count. Runs unchanged in a Cloudflare Worker, Node, or the browser.
