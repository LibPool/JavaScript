# @classytic/arc-sync

> 标签: arc, classytic, offline-first, outbox, sync

## 简介

Offline-first command sync for arc apps — durable client command log, a server engine recording one verdict per seq in the transaction of the command's effects, consistent pull batches over the change feed, per-domain command packs
