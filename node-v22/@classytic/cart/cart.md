# @classytic/cart

> 标签: auction, booking, cart, checkout, commerce, ecommerce, group-buy, idempotency, mongodb, mongoose, reservation, saga, subscription

## 简介

Framework-agnostic universal cart engine for commerce — drafts, checkouts, reservations, the LineKind strategy, and a disciplined finalization saga. Powered by MongoDB via @classytic/mongokit. Zero framework deps — usable from Arc, Express, Nest, Next.js,
