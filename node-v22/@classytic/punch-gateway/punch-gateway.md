# @classytic/punch-gateway

> 标签: adms, attendance, biometric, classytic, device-gateway, fingerprint, hrms, iclock, mongokit, muster, punch, rfid, time-clock, zkteco

## 简介

Attendance device gateway — vendor protocol adapters (ZKTeco ADMS/iClock push first) behind one normalized DevicePunch pipeline: device registry (SN → org/scope/timezone), enrollment mapping (device PIN → polymorphic subject), replay-safe idempotency key
