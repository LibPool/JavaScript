# @jhsdc/builder-input-types

> 标签: builder-plugin, builder.io, cms-link, input-type

## 简介

A library of custom Builder.io input editors for React integrations — featuring CMSLink, a link input that lets content editors choose between an external URL and a live reference to another piece of Builder.io content.
