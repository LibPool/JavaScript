# srezai-cli

> 标签: ai-agents, cli, mcp, russian-web, scraping, srezai, web-search

## 简介

Web access for AI agents: search, read, map, crawl, extract, verify, answers and deep research via the srezai API. Zero dependencies, keeps tool schemas out of the model context.
