# @newthird/og-preview

> 标签: claude-code, link-preview, mcp, og-image, open-graph, twitter-card, unfurl

## 简介

Local link-preview tester: how a URL's Open Graph tags look on X, LinkedIn, Facebook, Slack, Discord, iMessage, WhatsApp, Telegram, Bluesky and Mastodon, with a JSON report for scripts and an MCP tool for AI agents.
