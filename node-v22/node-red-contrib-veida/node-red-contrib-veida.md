# node-red-contrib-veida

> 标签: ai, image-editing, image-generation, node-red, text-to-image, veida

## 简介

Node-RED node for Veida AI: turn a prompt into an AI image, or edit an image, and get back a CDN link. Works on the free tier with no API key.
