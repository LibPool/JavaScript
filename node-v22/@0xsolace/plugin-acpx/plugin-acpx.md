# @0xsolace/plugin-acpx

> 标签: acpx, agent-client-protocol, coding-agent, elizaos, milady, plugin, subagent, task

## 简介

acpx-backed task and subagent plugin for ElizaOS. Wraps the acpx CLI to spawn coding agents (codex/claude/gemini) as subprocesses and exposes them through ElizaOS actions.
