# @pixelmatters/markup

> 标签: annotation, bug-report, embed, feedback, pixelmatters, preact, screenshot, tanstack-intent, widget

## 简介

Embeddable feedback widget for collecting visual bug reports, screenshots, and comments on live web apps.
