# @docsxai/backend

> 标签: agent, claude-code, docsxai, documentation, playwright

## 简介

Authenticated service that persists doc packs (projects, revisions, flow-files, screenshots, annotations, style artifacts, run history). REST + per-resource endpoints; OAuth 2.1 auth.
