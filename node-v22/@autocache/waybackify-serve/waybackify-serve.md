# @autocache/waybackify-serve

> 标签: JavaScript

## 简介

The wayback mirror serving core — one Hono app (/web/<ts><flag?>/<url> router + chrome strip + standalone CSP), the Store abstraction (FsStore/S3Store/R2Store/MemoryStore), and the Node listener (serveCacheRoot/serveBucket). Production and the crawl probe
