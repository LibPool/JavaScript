# @vechain/dev-stack

> 标签: block-explorer, blockchain, cli, dev-environment, docker-compose, indexer, thor, thor-solo, vechain

## 简介

Shared local dev environment for VeChain projects: thor-solo + indexer + block-explorer, with per-project address registration.
