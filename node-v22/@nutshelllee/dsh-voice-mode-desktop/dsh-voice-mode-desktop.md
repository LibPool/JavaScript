# @nutshelllee/dsh-voice-mode-desktop

> 标签: asr, barge-in, captions, chinese, deepseek-harness, dsh, dsh-plugin, tts, voice, voice-mode

## 简介

Full-duplex voice mode for DeepSeek Harness 0.2 desktop: streaming ASR to draft, sentence read-aloud, barge-in, live captions, plus an in-app settings page. An unofficial compatibility fork of dsh-voice-mode 0.7.15.
