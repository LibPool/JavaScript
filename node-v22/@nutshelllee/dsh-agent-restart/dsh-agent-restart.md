# @nutshelllee/dsh-agent-restart

> 标签: dsh, dsh-plugin, restart

## 简介

Agent-initiated restart for DeepSeek Harness: one tool that writes a restart journal, relaunches the app through a detached WMI helper, and injects the pending work back after restart.
