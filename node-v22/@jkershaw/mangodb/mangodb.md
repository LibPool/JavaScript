# @jkershaw/mangodb

> 标签: database, drop-in, embedded, file-based, local, mongodb, nosql, testing

## 简介

File-based MongoDB drop-in replacement for TypeScript/Node.js. SQLite is to SQL as MangoDB is to MongoDB.
