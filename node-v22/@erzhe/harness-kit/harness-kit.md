# @erzhe/harness-kit

> 标签: agent, agents.md, ai, claude, cli, cursor, harness, manifest, scaffold

## 简介

AI-friendly repo harness: a manifest.yaml single source of truth that generates AGENTS.md / CLAUDE.md / Cursor rules and enforces invariants, contracts and drift via `harness-kit verify`.
