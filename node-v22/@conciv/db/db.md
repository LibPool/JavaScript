# @conciv/db

> 标签: conciv, drizzle, sqlite

## 简介

Internal to @conciv/it (installed automatically, do not install directly). conciv persistence: typed drizzle schema, sqlite open + migrations, and sealed run-lifecycle queries on node:sqlite.
