# @conciv/client

> 标签: client, conciv, orpc, tanstack-intent

## 简介

Internal to @conciv/it (installed automatically, do not install directly). conciv client data layer: typed oRPC access, TanStack Query option factories, and the useChat connection bridge. Zero UI.
