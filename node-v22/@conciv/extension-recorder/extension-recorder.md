# @conciv/extension-recorder

> 标签: conciv, extension, recorder, replay, rrweb

## 简介

Internal to @conciv/it (installed automatically, do not install directly). The recorder built-in extension: rrweb session recording of the host page with a server-side sliding window, agent tools returning a distilled action log plus keyframes, and a repl
