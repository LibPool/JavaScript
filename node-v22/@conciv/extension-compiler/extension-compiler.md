# @conciv/extension-compiler

> 标签: conciv, extension, vite

## 简介

Internal to @conciv/it (installed automatically, do not install directly). The vite build plumbing for conciv extension code: client/server splitting, Solid TSX compilation, JSX source stamping, and the extensions virtual module.
