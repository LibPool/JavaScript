# dsh-session-navigator

> 标签: deepseek-harness, dsh, dsh-plugin, explorer, navigator, session

## 简介

会话资源管理器 (Session Navigator) for DeepSeek Harness: virtual folders, tags, notes, trash and multi-workspace session browsing on top of the native DSH session store.
