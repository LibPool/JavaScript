# @makaio/provider-z-ai

> 标签: JavaScript

## 简介

Type-only provider package for Z.AI (GLM) — the reference implementation for dual-protocol providers. This package declares the provider identity, endpoint URLs for both the Anthropic-compatible and OpenAI-compatible inference APIs, credential environment
