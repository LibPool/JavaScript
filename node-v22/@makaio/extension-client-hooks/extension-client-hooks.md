# @makaio/extension-client-hooks

> 标签: JavaScript

## 简介

A generic CLI bridge that forwards raw hook events from any AI client tool (Claude Code, Codex, etc.) to the Makaio bus. Client tools invoke it from their native hook configuration; the bridge reads the event payload from stdin and emits it verbatim witho
