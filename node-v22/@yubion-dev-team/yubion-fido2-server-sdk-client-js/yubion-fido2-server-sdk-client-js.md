# @yubion-dev-team/yubion-fido2-server-sdk-client-js

> 标签: FIDO2, Passkey, WebAuthn, YubiOn

## 简介

This project is a client-side SDK to support WebAuthn API calls for YubiOn FIDO2 Server Service.
