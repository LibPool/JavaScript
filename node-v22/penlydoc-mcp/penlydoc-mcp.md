# penlydoc-mcp

> 标签: e-signature, electronic-signature, mcp, model-context-protocol, pdf, penlydoc

## 简介

Model Context Protocol server for PenlyDoc e-signatures: send documents and templates for signature, see who signed, download sealed PDFs.
