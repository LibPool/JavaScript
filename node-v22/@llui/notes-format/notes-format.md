# @llui/notes-format

> 标签: devtools, llui, notebook, notes, serialization

## 简介

LLui devmode notebook on-disk format — zero-dependency note types, filename/slug/session helpers, and YAML (de)serialization shared by the vite-plugin server store, the HUD, and the MCP server
