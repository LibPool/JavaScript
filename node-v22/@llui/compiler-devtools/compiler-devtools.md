# @llui/compiler-devtools

> 标签: compiler, devtools, llui, mcp

## 简介

LLui compiler — dev-MCP / LLM tooling support (opt-in, dev-mode only). Emits `__componentMeta` (file/line for source navigation) and future trace instrumentation (`_eachDiffLog`, `_disposerLog`, `_effectTimeline`, `_coverage`). Depends on @llui/compiler-i
