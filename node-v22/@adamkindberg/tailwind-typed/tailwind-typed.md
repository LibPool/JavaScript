# @adamkindberg/tailwind-typed

> 标签: codegen, css-variables, design-tokens, tailwind, tailwind-v4, tailwindcss, typescript, vite-plugin

## 简介

Generate fully-typed, importable access to your Tailwind v4 theme tokens (CSS variables + resolved values) for use anywhere, including non-Tailwind contexts.
