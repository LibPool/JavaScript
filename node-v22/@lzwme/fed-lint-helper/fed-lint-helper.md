# @lzwme/fed-lint-helper

> 标签: commitlint, eslint, fed, jest, lint, lint-helper, prettier, tsc, typescript

## 简介

前端项目编码质量 lint 检测辅助工具。用于辅助大型长期研发的前端项目渐进式的迁移与改进编码规范约束。
