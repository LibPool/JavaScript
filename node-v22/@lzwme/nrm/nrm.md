# @lzwme/nrm

> 标签: NPM, registry

## 简介

NPM registry manager can help you easy and fast switch between different npm registries, now include: cnpm, taobao, nj(nodejitsu), edunpm

- 官网：https://github.com/renxia/nrm
- 源码仓库：git://github.com/renxia/nrm.git
- npm 页面：https://www.npmjs.com/package/@lzwme/nrm
