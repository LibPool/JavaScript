# @cryptoswapdex/v3-lm-pool

> 标签: JavaScript

## 简介

Liquidity Mining Pool (LM Pool) is a separate contract for liquidity mining reward accounting. It is not meant to be deployed manually. It will be deployed automatically by MasterChefV3 with LmPoolDeployer whenever there is a new liquidity mining camp
