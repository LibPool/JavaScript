# @quincus/chat-core

> 标签: chat, headless, quincus, rag, sdk, sse, streaming

## 简介

Headless, framework-agnostic chat SDK wrapping the Quincus RAG API (sessions, SSE streaming, disambiguation, suggestions, feedback).
