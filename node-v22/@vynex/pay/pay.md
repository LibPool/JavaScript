# @vynex/pay

> 标签: pay, payments, pix, sdk, vynex

## 简介

SDK JavaScript (ESM, zero dependências) da API Vynex Pay: recursos por família, Idempotency-Key automática, retry com backoff, paginação por async iterator e verificação de webhook.

- 官网：https://pay.vynexsystems.com/docs/sdks
- 源码仓库：git+https://github.com/vynex-systems/pay-js-sdk.git
- npm 页面：https://www.npmjs.com/package/@vynex/pay
