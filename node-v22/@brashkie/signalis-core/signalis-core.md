# @brashkie/signalis-core

> 标签: aead, aes-cbc, aes-gcm, commonjs, cryptography, curve25519, diffie-hellman, digital-signature, dual-package, e2e-encryption, ecdh, ed25519, esm, hepein, hkdf, hmac, napi, native, rust, sha256, signal-protocol, x25519, xed25519

## 简介

Cryptographic primitives for Signal Protocol — Rust-powered Node.js library with Ed25519, XEd25519, Curve25519, HKDF, AES-GCM (with AAD), AES-CBC, ChaCha20-Poly1305, HMAC, SHA-256 (ESM + CJS + TypeScript). Android arm64/armv7 support.
