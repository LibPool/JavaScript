# finch-image-gen

> 标签: finch, finch-minitool, image-generation, image-to-image, openai, text-to-image

## 简介

Generate and edit images with OpenAI GPT Image 2.5 (or an OpenAI-compatible relay): text-to-image, image-to-image, masked edits, transparent backgrounds and custom sizes, right inside Finch.
