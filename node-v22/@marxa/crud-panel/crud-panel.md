# @marxa/crud-panel

> 标签: JavaScript

## 简介

Componente para crear una dinámica CRUD con componentes de **@angular/material**. Permite agregar un template para **Create**, Enlistar un array para **Read**, un template para **Update** y un botón para **Delete**
