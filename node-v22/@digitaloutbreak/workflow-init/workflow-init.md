# @digitaloutbreak/workflow-init

> 标签: agents, ai-agents, anthropic, claude, claude-code, scaffold, starter, workflow

## 简介

Drop-in workflow scaffold for AI-assisted coding — works with Claude Code, Codex, Cursor, Gemini, Copilot, Cline, Windsurf, and any agent loading the open agent skills standard. Includes /workflow-init slash command, /feature lifecycle, /cleanup, code-sca
