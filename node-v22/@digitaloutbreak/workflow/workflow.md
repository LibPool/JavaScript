# @digitaloutbreak/workflow

> 标签: agents, ai-agents, anthropic, ci-cd, claude, claude-code, github-actions, scaffold, starter, workflow

## 简介

Drop-in workflow scaffold for AI-assisted coding with guided project discovery, PR-first feature delivery, and framework-aware CI/CD. Works with Claude Code, Codex, Gemini, Antigravity, and Open Skills agents.
