# @coffeekraken/s-sugar-feature

> 标签: JavaScript

## 简介

Global feature that you can apply on your body and that will handle convinient things like automatically expand your "pleasant css" classes, add/remove a "scrolled" class on the body, remove animations when user resize the page, and more...
