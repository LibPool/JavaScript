# @steerable/agent-harness

> 标签: agent, budget, harness, policy, steerable, tracing, typescript

## 简介

Steerable framework Tier 2 — TypeScript facade over the Python harness (policy, budget, retry, completion, tracing) used for cross-language conformance tests. Production code should depend on the Python harness.
