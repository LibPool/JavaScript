# @mingxy/cerebro-mcp-zcode

> 标签: cerebro, mcp, memory, model-context-protocol, zcode

## 简介

Cerebro MCP server for ZCode — 17 memory tools. Auto-reads ~/.config/cerebro/config.json. Use via: npx -y @mingxy/cerebro-mcp-zcode
