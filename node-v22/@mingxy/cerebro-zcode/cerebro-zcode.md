# @mingxy/cerebro-zcode

> 标签: agent-memory, cerebro, mcp, memory, persistent, zcode, zero-dependency

## 简介

Cerebro persistent memory plugin for ZCode — session-start memory injection (profile + project + semantic), reasoned-recall instruction + keyword nudge on every prompt, recall auto-approval, incremental session archival at stop, and a bundled zero-depende
