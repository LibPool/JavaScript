# @idlebox/source-map-support

> 标签: JavaScript

## 简介

如果没有设置options，那么以下情况跳过加载: * `inspector.url()` 返回非空 * execArgv（或者 NODE_OPTIONS）包含“--inspect”、“--inspect-brk”、“--enable-source-maps” * DISABLE_SOURCE_MAP 非空
