# @orrisai/orbit-cli

> 标签: agent, ai, cli, kanban, orbit

## 简介

Command-line client for the Orbit kanban board (https://orbit.zeabur.app). Designed so AI agents can manage tasks: create cards, post comments, move columns, edit metadata.
