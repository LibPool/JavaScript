# common-context-mcp

> 标签: agent-memory, ai-agents, common-context, mcp, model-context-protocol, shared-context

## 简介

Shared, append-only context store for AI agents over MCP: checkpoints, failures, claims, handoffs, crash recovery. Multi-process safe.
