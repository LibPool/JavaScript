# @nexys/user-management-jwt-wasm

> 标签: JavaScript

## 简介

Pure-TS wrapper around the um-jwt-wasm bundle. Verifies access + refresh tokens against /api/auth/jwks using the same Ed25519 code path the server uses to sign them.
