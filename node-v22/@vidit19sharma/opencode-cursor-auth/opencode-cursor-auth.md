# @vidit19sharma/opencode-cursor-auth

> 标签: ai, auth, cursor, cursor-sdk, llm, opencode, opencode-plugin

## 简介

OpenCode plugin that uses your Cursor subscription via the official @cursor/sdk — no proxy server, one-time browser login, in-process bridge.
