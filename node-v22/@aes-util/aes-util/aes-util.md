# @aes-util/aes-util

> 标签: AES, decryption, encryption

## 简介

A module to decrypt/encrypt data using AES algorithm. The module perform symmetric encryption/decryption, using 128 bits PBKDF2 key, generated with randomized IV and SALT. The procedure is password based
