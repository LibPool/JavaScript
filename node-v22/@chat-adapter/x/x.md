# @chat-adapter/x

> 标签: adapter, ai-agent, ai-sdk, bot, chat, chat-sdk, chatbot, messaging, twitter, vercel, x, x-api, xchat

## 简介

X (Twitter) adapter for Chat SDK: reply to mentions, send direct messages, and post from your bot account with the X API v2, plus encrypted XChat conversations from the @chat-adapter/x/chat subpath
