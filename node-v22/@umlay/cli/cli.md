# @umlay/cli

> 标签: cli, dsl, er-diagram, linter, renderer, uml, umlay

## 简介

Umlay DSL command-line interface — parse / lint / render `.umlay` files. Tracks Umlay spec 1.10.0 with `@flowchart_diagram` view kind (RFC 0055) and lint L059–L061.
