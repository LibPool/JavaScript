# @deepfirstsearch/agent-pay-cloudflare

> 标签: agents, ai-agents, base, cloudflare, cloudflare-agents, mcp, payments, usdc, x402

## 简介

Agent Safe for the Cloudflare Agents SDK: an owner-signed policy for withX402Client so a Cloudflare agent can only pay the pinned payee, within a budget, even if prompt-injected
