# cortico-world-gemini-web

> 标签: cortico, cortico-world, gemini, gemini-web

## 简介

Cortico 的 Gemini Web 内嵌 World（Windows）：提供 Gemini 原生网页、状态与窗口同步。必须与 cortico-provider-gemini-web 同时安装，二者互为刚需。

## 官网

- npm 页面：https://www.npmjs.com/package/cortico-world-gemini-web

- 0.1.13
