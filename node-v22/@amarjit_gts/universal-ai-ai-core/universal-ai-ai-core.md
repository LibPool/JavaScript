# @amarjit_gts/universal-ai-ai-core

> 标签: JavaScript

## 简介

Provider-independent AI Gateway: chat, embeddings, structured output, and basic tool-calling routed across OpenAI/Anthropic/Google/local models via a Model Registry and Router. Business code never imports a provider SDK directly.
