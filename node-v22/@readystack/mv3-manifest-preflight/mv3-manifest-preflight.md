# @readystack/mv3-manifest-preflight

> 标签: browser extension lint, chrome extension, chrome web store, edge add-ons, manifest v3, manifest.json, mv3

## 简介

25 rules over manifest.json: every line Manifest V3 or the Chrome Web Store upload refuses, with the fix beside it. The shipped MV2 fixture returns 19 findings, 16 of them errors that block the upload
