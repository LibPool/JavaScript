# @readystack/erb-rails-view-snippets-audit

> 标签: erb, html.erb, rails, ruby, views

## 简介

Paste or open one .html.erb view and see every raw, html_safe, params and CSRF finding a Rails security review sends back — 26 rules, 36 snippets, offline in the editor, no account.
