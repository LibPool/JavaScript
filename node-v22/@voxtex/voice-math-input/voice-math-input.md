# @voxtex/voice-math-input

> 标签: accessibility, asr, latex, math, speech-to-math, transformers.js, voice-input, webgpu, whisper

## 简介

Voice-to-LaTeX input SDK: on-device Whisper ASR + spoken-math grammar. Headless core, optional Web Component.
