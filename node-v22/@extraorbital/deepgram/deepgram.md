# @extraorbital/deepgram

> 标签: JavaScript

## 简介

A credential for Deepgram: a broker's refresh token (DEEPGRAM_REFRESH_TOKEN, DEEPGRAM_TOKEN_URL, DEEPGRAM_BASE_URL) exchanged for a short-lived one.
