# @extraorbital/gladia

> 标签: JavaScript

## 简介

A key for Gladia and the URL to spend it at, read from EXTRAORBITAL_GLADIA_KEY and GLADIA_BASE_URL: a broker's virtual key with the broker's own front, or an account's own key.
