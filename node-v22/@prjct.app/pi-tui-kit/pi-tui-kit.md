# @prjct.app/pi-tui-kit

> 标签: design-system, pi, pi-agent, pi-coding-agent, pi-extension, terminal, tui

## 简介

One minimal, actionable TUI for every prjct Pi extension: a docked list/detail panel with one-key actions, and one line for active modes.
