# @beeos-ai/device-mcp-server

> 标签: JavaScript

## 简介

Singleton multi-device MCP tool server for BeeOS device-agent (Android / desktop / mobile sandboxes). Implements the Model Context Protocol over Streamable HTTP and stdio.
