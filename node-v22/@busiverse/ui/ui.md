# @busiverse/ui

> 标签: Business, Busiverse, Ecosystem, Intelligence, Technology

## 简介

BUSIVERSE shared React UI, design tokens, pricing, i18n, auth helpers, and product shell. Network-neutral core; Gateway transport is app-injected.
