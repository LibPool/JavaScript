# @xberg-io/llamaindex-xberg

> 标签: document-extraction, llama-index, llamaindex, node-parser, ocr, pdf, rag, reader, text-extraction, xberg

## 简介

LlamaIndex.TS reader and node parser for Xberg — extract text, tables, metadata, and structure-aware nodes from 107 document formats with optional OCR.
