# @kryxjs/wav

> 标签: audio, container, kryx, multimedia, pcm, riff, wav, wave

## 简介

A small, dependency-free reader for the WAV (RIFF/WAVE) container — pure Rust core with a TypeScript SDK. Part of the Kryx multimedia ecosystem.
