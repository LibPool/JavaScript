# @yovchev-projects/components-library

> 标签: JavaScript

## 简介

A modern, accessible React component library built on [shadcn/ui](https://ui.shadcn.com/), powered by [Radix UI](https://www.radix-ui.com/) and [Tailwind CSS](https://tailwindcss.com/).
