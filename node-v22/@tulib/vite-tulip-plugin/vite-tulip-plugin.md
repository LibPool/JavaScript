# @tulib/vite-tulip-plugin

> 标签: JavaScript

## 简介

### JSR 1. Add a file `.npmrc` with `@jsr:registry=https://npm.jsr.io` 2. And add to the `package.json` -> `"@tu/vite-tulip-plugin": "npm:@jsr/tu__vite-tulip-plugin@latest"` 3. Run `yarn` on the project
