# @ctrlpi/mcp-bridge

> 标签: ai, claude, ctrlpi, esp32, gpio, llm, mcp, model context protocol, pi pico, pico, raspberry pi, raspberry pi pico, raspberry pico

## 简介

An MCP (Model Context Protocol) server that lets an AI agent (e.g. Claude Desktop) control one or more GPIO agents - `pi-gpio-api` Pis, `pico-gpio-api` Pico Ws or `esp32-gpio-api` ESP32s - by calling their REST API over HTTP.
