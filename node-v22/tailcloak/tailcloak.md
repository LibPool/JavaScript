# tailcloak

> 标签: class names, css, mangle, minify, obfuscate, obfuscator, tailwind, tailwindcss

## 简介

Tailwind CSS v4 class name obfuscator. The framework-agnostic core behind @tailcloak/next, @tailcloak/vite and @tailcloak/postcss.
