# @jindin/mapbox-gl-echarts-layer

> 标签: JavaScript

## 简介

基于mapbox-gl-js的扩展的EChartsLayer图层插件,可直接在 Mapbox GL JS 中使用 Apache ECharts 的 scatter、effectScatter 和 lines
