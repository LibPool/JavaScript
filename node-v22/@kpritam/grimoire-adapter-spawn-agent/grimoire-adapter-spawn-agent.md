> 标签: acp, agent-client-protocol, claude, claude-code, codex, copilot, cursor, droid, gemini, grimoire, opencode, pi, spawn-agent

## 简介

Grimoire AgentRunner adapter backed by `spawn-agent`. Drives any locally-installed coding-agent CLI (Claude Code, Codex, Cursor, GitHub Copilot, Gemini, OpenCode, Factory Droid, Pi) over the Agent Client Protocol.
