# @kky42/pievo

> 标签: JavaScript

## 简介

Pievo daemon — runs on your machine, connects to a Pievo server, and executes scheduled loops via your local coding agent (Claude Code, Codex, or Pi). One binary, two roles (daemon / loop callback).
