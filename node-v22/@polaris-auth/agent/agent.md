# @polaris-auth/agent

> 标签: agent-auth, agent-sdk, agentic, ai-agents, capabilities, client-credentials, edge, jwt, mcp, model-context-protocol, oauth2, polaris, private-key-jwt, receipts, token-exchange, typescript, webcrypto

## 简介

The agent SDK for Polaris for PHP: discover a Polaris server, register or enrol an agent, request grants and wait for approvals, sign request JWTs, execute capabilities and verify receipts. Node and edge, no runtime dependency.
