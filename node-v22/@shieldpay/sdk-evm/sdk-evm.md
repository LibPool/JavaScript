# @shieldpay/sdk-evm

> 标签: evm, privacy, shieldpay, viem, zk

## 简介

EVM adapter for the ShieldPay SDK: viem-backed chain, vault, burner, stealth, protocol-aware stealth integrations, deposit, transfer, withdraw, recovery, discovery, proving, and event-source implementations.
