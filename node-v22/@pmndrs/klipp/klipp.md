# @pmndrs/klipp

> 标签: camera, cinemachine, ecs, r3f, react-three-fiber, three.js, virtual-camera, webgl

## 简介

A camera toolkit for the web: a complete virtual camera system for any renderer, with React Three Fiber and three.js built on top. Inspired by Unity Cinemachine.
