# dsh-aoci-bind

> 标签: aoci, cordis, deepseek-harness, dsh, mcp, plugin, workspace

## 简介

DSH Host 侧 AOCI 接入插件：发现带 aoci.txt 的工作区、诊断/修复 MCP 绑定、初始化未接入的仓库，并提供状态与体检工具。
