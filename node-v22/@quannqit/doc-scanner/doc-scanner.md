# @quannqit/doc-scanner

> 标签: camera, crop, deskew, document-scanner, pdf, perspective, react, scanner

## 简介

Document scanning for the web: detect a sheet of paper in a camera frame or photo, flatten its perspective, and clean it up like a scanner. Zero dependencies, no OpenCV. Optional React camera UI.
