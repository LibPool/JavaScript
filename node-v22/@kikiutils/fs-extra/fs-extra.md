# @kikiutils/fs-extra

> 标签: copy, create, delete, directory, extra, file, file system, fs, fs-extra, json, mkdir, mkdirp, mkdirs, move, output, promise, read, remove, text, touch, write

## 简介

Wraps node:fs, node:fs/promises, and fs-extra functions with try-catch, returning success/failure indicators. Includes additional file and path utilities.
