# @treewyrm/fetch-byte-ranges

> 标签: 206, byte-range, fetch, http-range, isomorphic, partial-content, stream

## 简介

Isomorphic HTTP byte-range fetcher. Concurrent partial GETs with preflight, stream output per range.
