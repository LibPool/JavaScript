# @noobdigital/react-native-dynamic-island

> 标签: activitykit, android, deep-linking, dynamic-island, ios, live-activities, lock-screen, notifications, order-tracking, react-native, widget

## 简介

Live-updating activity cards for React Native — Live Activities / Dynamic Island on iOS 16.2+, an ongoing lock-screen notification on Android. One JS API, branded UI, deep linking, and Old/New Architecture support via classic NativeModules.
