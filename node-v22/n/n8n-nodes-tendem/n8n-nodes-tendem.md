# n8n-nodes-tendem

> 标签: human-experts, human-in-the-loop, mcp, n8n, n8n-community-node-package, outsourcing, tendem

## 简介

Delegate tasks to vetted human experts with Tendem — create a task, read the priced contract, approve the spend, poll, and fetch the result.
