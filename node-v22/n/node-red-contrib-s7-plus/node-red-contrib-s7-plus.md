# node-red-contrib-s7-plus

> 标签: industrial-automation, iso-on-tcp, node-red, optimized-blocks, plc, s7, s7-1200, s7-1500, s7comm-plus, s7commplus, siemens, simatic, subscription, symbolic-access, tia-portal, tls

## 简介

Node-RED nodes for symbolic read/write/subscribe to Siemens S7-1200/1500 over native S7CommPlus (Optimized DBs, no PUT/GET).
