# node-red-contrib-flight-recorder

> 标签: black-box, blackbox, debug, debugging, diagnostics, flight-recorder, incident, logging, node-red, recorder, ring-buffer

## 简介

A flight recorder for Node-RED flows: rolling message recordings, dumped as structured incidents on demand, on error, or on watermark match. Inline and tap capture, cockpit-style control node, crash-surviving persistence.
