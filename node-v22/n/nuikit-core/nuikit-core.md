# nuikit-core

> 标签: cfx, esx, fivem, gta, nui, qbcore, qbox, react, redm, roleplay, shadcn

## 简介

The runtime behind nuikit, one design system for your whole FiveM server: typed fetchNui and events, surfaces (focus, layers, Escape across resources), the theme compiler (tokens v1, DTCG) and browser devtools.
