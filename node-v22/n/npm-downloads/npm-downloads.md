# npm-downloads

> 标签: downloads, npm

## 简介

Prints the number of downloads for a given npm package and the packages that directly depend on it

## 官网

- 源码仓库：git://github.com/aheckmann/npm-downloads.git
- npm 页面：https://www.npmjs.com/package/npm-downloads
