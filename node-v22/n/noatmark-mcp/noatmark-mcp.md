# noatmark-mcp

> 标签: clean text, invisible characters, llm, mcp, prompt injection, sanitize, text hygiene

## 简介

MCP server for text hygiene: sanitize text before feeding it to an LLM (strip invisible characters, flag prompt injection), scan for hidden text, and clean LLM formatting. Companion to noatmark.com.
