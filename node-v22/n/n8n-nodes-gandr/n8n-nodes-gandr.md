# n8n-nodes-gandr

> 标签: gandr, n8n, n8n-community-node-package, text-to-speech, tts, voice-agents

## 简介

n8n community node for the Gandr TTS API. First audio byte in 146 ms over the open internet, 116 ms p50 first audio, server side warm. 23 languages, every render watermarked.
