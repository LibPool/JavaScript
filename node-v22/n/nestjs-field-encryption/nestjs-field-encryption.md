# nestjs-field-encryption

> 标签: aes, encryption, kms, multi-tenant, nestjs, prisma

## 简介

Per-tenant field-level encryption for NestJS: AES-256-CBC + KMS envelope encryption, a @Encrypt() decorator, an HTTP pipe/interceptor pair, and a schema-agnostic Prisma write-encryption extension.
