# next-build-filter

> 标签: app-router, build, bundle, filter, glob, next.js, nextjs, optimization, pages, pages-router, pattern-matching, plugin, webpack, wildcard

## 简介

A Next.js plugin to exclude pages/routes during build without removing files. Supports both Pages Router and App Router (Next.js 13+).
