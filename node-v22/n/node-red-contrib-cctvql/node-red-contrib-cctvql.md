# node-red-contrib-cctvql

> 标签: camera, cctv, frigate, hikvision, home-automation, nlp, node-red, nvr, surveillance

## 简介

Node-RED nodes for querying and controlling CCTV systems via cctvQL — natural language queries, live events, and PTZ control across Frigate, Hikvision, Synology, and more.
