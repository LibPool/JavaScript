# nginject-decorator

> 标签: $inject, AngularJS, ES6, ES7, decorator, dependency-injection, nginject

## 简介

Simply sets a static $inject property onto a component, controller, service or filter class which specifies what dependencies AngularJS built-in $injector will need to inject at runtime and avoids mucking up module declarations with unnecessary verbosity.
