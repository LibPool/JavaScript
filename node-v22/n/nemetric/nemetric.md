# nemetric

> 标签: devtools, downlink, downlinkMax, effectiveType, first-contentful-paint, first-input-delay, first-paint, hardwareConcurrency, largest-contentful-paint, metrics, navigation-timing, navigatorInformation, performance-metrics, react, rtt, user-timing, web-performance, webperf, 性能, 监控, 采集

## 简介

前端性能监控,采集以及上报。用于测量第一个dom生成的时间(FP/FCP/LCP)、用户最早可操作时间（fid|tti）和组件的生命周期性能,，网络状况以及资源大小等等。向监控后台报告实际用户测量值。
