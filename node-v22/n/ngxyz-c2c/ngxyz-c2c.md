# ngxyz-c2c

> 标签: angular, angular-library, angular-module, clipboard, copy-to-clipboard, javascript, typescript

## 简介

- Includes a Directive which can be applied directly to the Element whose content (innerText) needs to be copied.  - Also includes a Service which can be used to directly interact with the underlying API for more advanced or customised use cases.
