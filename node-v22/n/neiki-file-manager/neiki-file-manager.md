# neiki-file-manager

> 标签: custom-elements, drag-and-drop, file-explorer, file-manager, i18n, upload, vanilla-js, web-components

## 简介

Lightweight, dependency-free CDN-ready File Manager Web Component with grid/list views, drag & drop upload, previews, rename, folders, context menu, and i18n support
