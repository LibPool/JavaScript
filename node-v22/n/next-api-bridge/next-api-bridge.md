# next-api-bridge

> 标签: api, api-client, app-router, auth, authentication, backend, bridge, cookies, fetch, http, middleware, next.js, nextjs, route-handlers, server-actions, server-components, session, typescript

## 简介

Cookie-aware API bridge for Next.js App Router with Server Actions. Handles auth, cookies, and session flow entirely on the server for external backends.
