# native-shell

> 标签: android, ios, javascript, native, quickjs

## 简介

Run small JavaScript programs inside iOS, Android, macOS and Linux apps, rendered with native views (UIKit, Android View, AppKit, GTK 4), with the programming model of gpui-shell.
