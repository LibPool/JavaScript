# nuxt-content-git

> 标签: frontend, javascript, node, nodejs, npm, npm-package, nuxt, nuxt-content, nuxt-module, nuxtjs, nuxtjs-module, webdevelopment

## 简介

Additional module for @nuxt/content that replaces or adds createdAt and updatedAt dates based on the git history.
