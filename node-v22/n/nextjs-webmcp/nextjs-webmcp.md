# nextjs-webmcp

> 标签: agents, ai, mcp, model-context, next, nextjs, server-actions, webmcp

## 简介

Route-scoped WebMCP tools for the Next.js App Router: expose server actions as tools agents can call, with route scoping, server-side validation and DevTools.
