# n8n-nodes-universal-media-downloader

> 标签: download, instagram, media, messenger, n8n, n8n-community-node-package, telegram, whatsapp

## 简介

Universal media downloader node for n8n. Detects and downloads non-text media from WhatsApp, Telegram, Messenger, Instagram, and direct URLs.
