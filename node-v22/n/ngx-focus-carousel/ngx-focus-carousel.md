# ngx-focus-carousel

> 标签: angular, angular-carousel, carousel, focus, ngx, ngx-focus-carousel, scroll, zoom

## 简介

An Angular carousel component with a focus/zoom effect — the center card enlarges as you scroll. Supports custom templates.
