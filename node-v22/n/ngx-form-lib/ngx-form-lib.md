# ngx-form-lib

> 标签: angular, angular forms, angular-18, angular-material, control-flow, dynamic forms, form-library, json-forms, material-3, reactive-forms, type-forms, typescript

## 简介

Dynamic form library for Angular 18 with Material 3 support. Create complex reactive forms easily using JSON configuration with modern Angular 18 control flow syntax.
