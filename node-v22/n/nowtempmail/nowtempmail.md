# nowtempmail

> 标签: 2fa, cypress, disposable-email, e2e, e2e-testing, email-testing, mcp, mfa, nowtempmail, otp, playwright, tempmail, temporary-email, verification-code

## 简介

Disposable mailboxes and OTP codes for your tests. Verification codes are extracted server-side, so there is no regex to write.
