# nodeversioncheck

> 标签: JavaScript

## 简介

Will exit the process with code 1 if the node version running is not compatible with the one specified in package.json of working directory

## 官网

- 源码仓库：https://github.com/e-conomic/nodeversioncheck
- npm 页面：https://www.npmjs.com/package/nodeversioncheck

- npm registry：https://registry.npmjs.org/nodeversioncheck
- Node 要求：>=0.6
