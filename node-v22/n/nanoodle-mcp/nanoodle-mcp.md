# nanoodle-mcp

> 标签: accountless, agent, ai, byok, image-generation, llm, mcp, micropayments, model-context-protocol, nano, nanogpt, nanoodle, tools, video-generation, workflow, x402

## 简介

MCP stdio server that turns saved nanoodle workflow graphs into callable tools — BYOK or accountless x402 (pay per call in Nano), runs on the NanoGPT API
