# n8n-nodes-sitemap-validator

> 标签: 404, excel, n8n-community-node-package, seo, sitemap, validator

## 简介

n8n node to load a sitemap and validate every URL inside it: 404 links, 5xx errors, redirect chains, timeouts, and missing lastmod. Can output an Excel report
