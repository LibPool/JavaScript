# n8n-nodes-mysql-variables

> 标签: credentials, globals, mysql, n8n, n8n-community-node-package, secrets, variables

## 简介

n8n community node to store variables (cookies, API keys, client id/secret) in MySQL or embedded SQLite — flat key→value store with per-credential isolation and AES-256-GCM encryption at rest.
