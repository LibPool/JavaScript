# nested-contexts

> 标签: context, hook, nested-contexts, react, typescript

## 简介

A minimal, lightweight React utility for precise subscriptions via nested Contexts, avoiding re-renders of components subscribed to unrelated fields. 极简轻量 React 工具库：通过嵌套 Context 实现精确订阅，避免订阅无关字段的组件重渲染。
