# node-log-viewer

> 标签: discord, express, log viewer ui, log-viewer, logger, logging, nestjs, slack

## 简介

Date-wise file logging for Node.js and NestJS with an embedded web UI log viewer and a plugin system (Discord and Slack notifications built in).
