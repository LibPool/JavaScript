# n8n-nodes-certyneo

> 标签: certyneo, contracts, eidas, electronic-signature, esignature, n8n, n8n-community-node-package

## 简介

n8n community node for Certyneo — eIDAS-compliant electronic signatures. Send documents to sign, follow envelopes, and trigger workflows on signature events.
