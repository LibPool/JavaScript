# n8n-nodes-crm

> 标签: n8n-community-node-package

## 简介

Esse é um pacote de nós personalizado para n8n, focado em integrações com sistemas de CRM. Ele inclui nós para conectar, gerenciar e automatizar fluxos de trabalho relacionados a dados de clientes, facilitando a sincronização e manipulação dessas informaç
