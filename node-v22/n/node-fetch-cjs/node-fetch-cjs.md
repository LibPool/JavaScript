# node-fetch-cjs

> 标签: JavaScript

## 简介

A wrapper for node-fetch (a light-weight module that brings Fetch API to node.js) to be used in commonjs environment.

## 官网

- 官网：https://github.com/node-fetch/node-fetch
- 源码仓库：git+https://github.com/touchifyapp/node-fetch-cjs.git
- npm 页面：https://www.npmjs.com/package/node-fetch-cjs
