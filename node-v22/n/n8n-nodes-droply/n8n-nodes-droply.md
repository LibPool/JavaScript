# n8n-nodes-droply

> 标签: deploy, droply, hosting, html, n8n, n8n-community-node-package, publish, static site

## 简介

Publish HTML, files and static sites on Droply from n8n: create and update sites, save drafts, publish, roll back, and manage passwords and expiry.
