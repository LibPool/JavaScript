# ngx-perf

> 标签: analysis, angular, lightweight, performance, performance analysis, web vitals

## 简介

Optimize Angular Application performance & web-vitals using one library. Provides features to optimize initial bundle size, initial navigation load time, web vitals score, running performance, performance analysis, and other features.
