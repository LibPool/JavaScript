# n8n-nodes-sftp-tp

> 标签: legacy, n8n, n8n-community-node-package, sftp, ssh

## 简介

Nodos n8n para subir, descargar y listar archivos por SFTP en servidores SSH legacy, con control de algoritmos de negociación (KEX, host key, cipher, HMAC).
