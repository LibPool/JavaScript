# n8n-nodes-verifly

> 标签: email, email-validation, email-verification, n8n, n8n-community-node-package, verifly, verify

## 简介

n8n community node for Verifly — agent-native email verification. Verify single addresses, run async bulk jobs, and read account/usage from your workflows.
