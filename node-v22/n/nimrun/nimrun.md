# nimrun

> 标签: agent, ai, anthropic, claude, claude-code, cli, llm, nim, nvidia, openai, proxy

## 简介

Run Claude Code against any NVIDIA NIM model. Pick a model, get a throwaway Anthropic-compatible proxy, launch claude — nothing is left behind when it exits.
