# node-loggerizer

> 标签: formatting, logger, loggerizer, logs, output

## 简介

Really small logger that allows to set layers of logging output such as: ERROR, WARNING, INFO, NOTICE, DEBUG and format it as [formatted-time]: LEVEL: text format
