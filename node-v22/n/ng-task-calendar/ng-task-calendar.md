# ng-task-calendar

> 标签: angular, calendar, full-calendar, ng, task, task-calendar

## 简介

A complete calendar to manage tasks, meetings, appointments and more. Inspired by modern calendars like Microsoft's, this Angular library provides an intuitive and flexible interface to organize your time efficiently.
