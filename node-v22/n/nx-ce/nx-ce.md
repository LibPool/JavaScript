# nx-ce

> 标签: anthropic, chrome-extension, claude, claude-code, native-messaging, sdk, websocket

## 简介

Claude Engine — WebSocket adapter for @anthropic-ai/claude-agent-sdk. Single serve mode serves all consumers (CLI / Chrome extension / native_host) over a unified JSON-over-WebSocket protocol.
