# nodejs-nano-service

> 标签: amqp, async, cloud-native, distributed-systems, enterprise-integration, event-bus, event-driven, event-driven-architecture, event-processing, high-performance, message-broker, message-queue, messaging, microservices, nodejs, pubsub, queueing, rabbitmq, real-time-processing, scalable-architecture, serverless

## 简介

A lightweight event-driven microservices package for RabbitMQ in Node.js. Enables scalable message publishing and consuming for distributed systems.
