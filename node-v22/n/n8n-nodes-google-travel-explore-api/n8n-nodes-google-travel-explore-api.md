> 标签: ai-tool, apify, destinations, flight-deals, google-travel-explore, n8n, n8n-community-node-package, n8n-nodes, travel, travel-deals, trip-ideas

## 简介

Discover destinations from a departure airport with flight prices, hotel prices, and trip dates. Apify-backed n8n community node, pay-per-result, and usable as an AI agent tool.
