# nice-modal-vue

> 标签: JavaScript

## 简介

这是个方便管理、调用弹窗、抽屉的 Vue 工具包，适用于 Ant Design Vue、Element Plus 等常用的 Vue 组件库。 代码逻辑~~抄袭~~借鉴自[@ebay/nice-modal-react](https://github.com/eBay/nice-modal-react)。
