# n8n-nodes-layerone

> 标签: docx, eidas, electronic-signature, facturx, layerone, n8n, n8n-community-node-package, pdf, sign

## 简介

Noeuds n8n pour les API LayerOne : DocX (generation de documents Word/PDF, factures Factur-X) et Sign (signature electronique eIDAS / PAdES).
