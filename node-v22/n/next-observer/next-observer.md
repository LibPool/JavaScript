# next-observer

> 标签: adk, ai-agents, apm, collector, nextjs, observability, opentelemetry, tracing

## 简介

The observer for Next.js: a server with a UI and AI agents that receives your app's OpenTelemetry traces, shows them and investigates them. Run with npx next-observer dev. The APM agent that goes into the app is next-observe.
