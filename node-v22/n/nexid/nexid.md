# nexid

> 标签: bson, globally, guid, id, identifier, k-ordered, nexid, sortable, typescript, unique, uuid

## 简介

Fast, time-sortable unique identifiers for the JavaScript ecosystem. Port of the original Go library github/rs/xid.
