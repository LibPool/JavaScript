# nd-str

> 标签: JavaScript

## 简介

nd-str ======================= - simple wrap of v8::String - same as Buffer.from  buf.toString()   - just for test  small-string  - expose v8::internal::String which can make a string mutable(just for test nvlang's StringRef feature)
