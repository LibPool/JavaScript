# n8n-nodes-onenote-system

> 标签: graph, microsoft, n8n, n8n-community-node-package, notes, onenote

## 简介

n8n community nodes for Microsoft OneNote (personal accounts): notebooks, sections, pages, images, audio, files and videos - read and write, plus a polling trigger.
