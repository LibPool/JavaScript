# n8n-nodes-linkedin-profile-scraper

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Scrape public LinkedIn profiles with no login, no cookies, no API key. Returns name, headline, current company, location, education, photo, followers + a parse_confidence score per record. Drop-in for Clay / Make / n8n enrichment and recruiter sourcing. P
