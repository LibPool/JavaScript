# n8n-nodes-crowdtrendz-wallet

> 标签: ada, blockchain, cardano, crowdtrendz, crypto, n8n-community-node-package, wallet

## 简介

The CrowdTrendz DEX n8n node provides comprehensive wallet management and DEX trading capabilities for the Cardano blockchain, integrating with Minswap’s aggregator for DEX trades and optimal swap routing
