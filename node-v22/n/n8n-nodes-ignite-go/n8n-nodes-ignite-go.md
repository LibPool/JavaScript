# n8n-nodes-ignite-go

> 标签: ignite-go, ignitecore, n8n, n8n-community-node-package, whatsapp

## 简介

n8n nodes for Ignite GO, the WhatsApp API by Ignite Core: send messages, manage chats, instances and groups, and trigger workflows from signed webhooks.
