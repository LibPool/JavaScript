# n8n-nodes-businessesforsale-listings

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Search BusinessesForSale.com by keyword and return business-for-sale marketplace listings: asking price, revenue, cash flow, full description, and broker/listing-agent contact. Official public marketplace data, no login wall.
