# nexthink-mcp-server

> 标签: agent, dex, digital-employee-experience, llm, mcp, model-context-protocol, nexthink, nql

## 简介

Enterprise-grade Model Context Protocol (MCP) server exposing Nexthink DEX telemetry (saved NQL API queries), Remote Actions, and engagement workflows to LLM agents. Targets MCP spec 2025-11-25 with pluggable auth for every Nexthink credential type.
