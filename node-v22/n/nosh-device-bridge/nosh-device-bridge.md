# nosh-device-bridge

> 标签: device-bridge, escpos, nosh, point-of-sale, pos, printing, qz-tray, receipt, thermal-printer, websocket

## 简介

Universal JavaScript client for the Nosh Device Bridge — securely print ESC/POS receipts to a local thermal printer from any browser app or Node service.
