# nockchain-mcp

> 标签: agent, blockchain, mcp, model-context-protocol, nock, nockchain

## 简介

Model Context Protocol server for Nockchain: address balances, payment verification, blocks, and endpoint health. Built by Prism. Not affiliated with the Nockchain project.
