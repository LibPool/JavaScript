# nuxt-unified-confetti

> 标签: JavaScript

## 简介

This library integrates the well made [canvas-confetti](https://github.com/catdad/canvas-confetti) library into your application as a layer, this enables seamless usage of Nuxt's auto import features as well as ease of further addition of things like mous
