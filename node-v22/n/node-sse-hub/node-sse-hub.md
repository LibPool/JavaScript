# node-sse-hub

> 标签: eventsource, express, fastify, nodejs, realtime, server-sent-events, sse, streaming

## 简介

Hub-centric Server-Sent Events (SSE) library for Node.js: connection registry, topics, replayable history, and optional Redis clustering
