# nanocached-keyv

> 标签: cache, cache-manager, distributed-cache, keyv, nanocached, nestjs, storage-adapter

## 简介

Keyv storage adapter for nanocached, a tiny distributed cache with client-side replication — for cache-manager v6+ and NestJS 11's CacheModule
