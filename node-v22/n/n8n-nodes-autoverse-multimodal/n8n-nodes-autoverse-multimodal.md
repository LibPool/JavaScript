# n8n-nodes-autoverse-multimodal

> 标签: ai, audio, autoverse, gemini, gpt, multimodal, n8n, n8n-community-node-package, pdf, transcription, video, vision, whisper

## 简介

AutoVerse Multimodal — n8n community node that unifies chat, image, audio, speech-to-text, document/PDF and video analysis with dynamic model capability discovery. Routes to OpenRouter under the hood but is independent of any official OpenRouter node.
