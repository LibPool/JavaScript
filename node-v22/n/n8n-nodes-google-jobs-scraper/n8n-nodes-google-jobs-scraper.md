# n8n-nodes-google-jobs-scraper

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Scrape Google for Jobs: one query returns aggregated postings across LinkedIn, Indeed, company sites and more, with multi-platform apply links, full descriptions, employer, location, salary and posted date. PPE per result, GOOGLE_SERP proxy.
