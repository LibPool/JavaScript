# nubraio-js

> 标签: algo-trading, api, nubra, rest, sdk, stock-market, trading, websocket

## 简介

Unofficial JavaScript/TypeScript SDK for the Nubra (nubra.io) REST API and WebSocket streams. Early development — API may change. Not officially affiliated with Nubra.
