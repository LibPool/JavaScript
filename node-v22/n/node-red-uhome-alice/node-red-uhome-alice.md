# node-red-uhome-alice

> 标签: alice, node-red, yandex, алиса, яндекс

## 简介

**NodeRed Home** (node-red-uhome-alice) - это сервис позволит, в несколько простых шагов, подключить любые ваши устройства заведенные в Node-RED к умному дому от Яндекса и управлять ими с помощью голосового помощника Алиса.
