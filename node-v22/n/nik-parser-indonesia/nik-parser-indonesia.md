# nik-parser-indonesia

> 标签: indonesia, kepmendagri, ktp, nik, parser, wilayah

## 简介

Library untuk melakukan parsing NIK (No Induk Kependudukan) Indonesia untuk mendapatkan info daerah, jenis kelamin, dan tanggal lahir.
