# node-red-contrib-ros2-suite

> 标签: node-red, robot, robotics, ros, ros2, rosbridge

## 简介

Node-RED nodes for ROS 2 over rosbridge — subscribe, publish, services and actions (client and server), parameters, TF and discovery. No local ROS install, no rclnodejs.
