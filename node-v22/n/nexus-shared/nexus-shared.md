# nexus-shared

> 标签: components, crud, datatable, design-system, forms, inputs, nepali-calendar, nextjs, nexus, react, typescript, ui

## 简介

The Nexus component library for React and Next.js: params-driven inputs and forms, a data table with a CRUD on top, popups and toasts, an API layer with permissions, Markdown and rich text editors, and 7 themes in light and dark.
