# niterateurdelais

> 标签: asynchrone, délais, itérateur, settimeout

## 简介

Cette portion de code gère le parcours d'un tableau et enclenche une fonction de rappel en fonction du délais depuis le dernier appel de chaque objet parcouru (pause globale ou particulière possible).
