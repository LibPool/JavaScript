# nextjs-agent-mcp

> 标签: agent, ai, automation, browser, introspection, mcp, model-context-protocol, next, nextjs, react, testing

## 简介

MCP server to drive and inspect a running Next.js app: headless route/error introspection + a real-event in-page browser bridge (click, fill, snapshot, React fiber tree, network, storage, eval) — no Playwright.
