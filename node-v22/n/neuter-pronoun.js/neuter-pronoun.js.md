# neuter-pronoun.js

> 标签: neuter, neutro, pronome, pronoun, replace, substituir

## 简介

O pronome neutro é aquele isento de indicação de gênero, geralmente usado para se referir a pessoas não binárias. O seu uso depende do direito de escolha da pessoa, podendo optar pelo uso de pronomes como “elu/delu” ou mantendo aqueles com indicação de gê
