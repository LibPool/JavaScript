# native-federation-vite

> 标签: angular, mfe, micro-frontend, microfrontend, module-federation, native-federation, react, remoteEntry, vite, vite-plugin, vue

## 简介

Vite plugin that generates a remoteEntry.json compatible with @angular-architects/native-federation, letting Vite remotes (Vue/React/Svelte/Solid) be federated by an Angular shell.
