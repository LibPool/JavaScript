# ninenine-mcp-unofficial

> 标签: 99, ai-agents, local-first, mcp, model-context-protocol, ninenine, ride-hailing

## 简介

Unofficial local-first 99 passenger MCP for fare estimates (99Pop + 99Moto), ride history and tracking. Never pays unless NINENINE_ALLOW_MUTATIONS and explicit_user_intent are both set.
