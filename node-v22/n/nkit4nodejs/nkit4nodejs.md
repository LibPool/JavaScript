# nkit4nodejs

> 标签: cdata, convert, cpp, data, data2xml, expat, filter, js, js2xml, json, json2xml, nkit, sax, xml, xml2data, xml2js, xml2json

## 简介

Fast XML to Javascript data (and vise versa) converter and filter. Written in C++ using Expat SAX parser.
