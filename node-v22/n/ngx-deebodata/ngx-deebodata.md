# ngx-deebodata

> 标签: accessibility, angular, angular-grid, angular-table, bar-graph, charts, customizable, data, data-grid, data-table, datagrid, datatable, feature-rich, graphs, grid, grouping, high-performance, line-graph, pagination, row-grouping, server-side, sorting, virtual-scroll

## 简介

Angular data grid and charts solution with virtual scroll or pagination options, row grouping, column resizing, re-ordering, column hiding, cell editing, tab accessibility, sorting with priority, and advanced filtering.
