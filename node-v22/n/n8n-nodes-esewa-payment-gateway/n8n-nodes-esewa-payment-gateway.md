# n8n-nodes-esewa-payment-gateway

> 标签: esewa, n8n-community-node-package, nepal, payment-gateway

## 简介

Integrate eSewa (Nepal's digital wallet) payment gateway with n8n: Epay v2 and Intent payment flows, HMAC-SHA256 signing, status checks, and callback verification
