# nexus-icons

> 标签: icons, next, nextjs, nexus, react, server-components, svg, tabler

## 简介

All 6,000+ Tabler icons for React: <Icon name="wifi" /> fetches one tiny file on first use, <InlineIcon> draws interface icons straight into the page. Server components, typed names, no runtime dependencies.
