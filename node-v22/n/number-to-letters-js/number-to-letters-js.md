# number-to-letters-js

> 标签: Node.js facturacion, SUNAT compliant, boletas electronicas SUNAT, conversion numerica optimizada, conversor numerico SUNAT, convertir numeros a letras, dolar a texto, euro a texto, facturacion electronica Peru, facturas electronicas formato, formato SUNAT, gestion administrativa Peru, herramienta facturacion Peru, number to letters, numero a texto, sol peruano a texto, soporte multiples monedas

## 简介

Convierte números a su representación textual en el formato requerido para boletas y facturas electrónicas según las normas de la SUNAT Perú. Este paquete es una herramienta esencial para desarrolladores que necesitan generar documentos fiscales con forma
