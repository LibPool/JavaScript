# netlify-plugin-tradly

> 标签: netlify, netlify-plugin

## 简介

Netlify Build plugin - Making deployment on Netlify is even faster now. A single auth will get all your configs from Tradly Headless API to launch commerce and marketplace apps blazing fast.
