# notifkit

> 标签: drizzle, email, multi-tenant, notification-system, notifications, postgres, push-notifications, queue, quiet-hours, redis-streams, self-hosted, sms, transactional-email, typescript, unsubscribe, user-preferences, webhooks

## 简介

Self-hosted notification infrastructure. One call delivers to email, SMS, push, and webhook — routed by preference, quiet hours, and consent.
