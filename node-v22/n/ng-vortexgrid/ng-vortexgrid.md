# ng-vortexgrid

> 标签: angular grid, angular table, customizable, datatable, drag-and-drop, export excel, grid, library, pagination, sortable, table, vue

## 简介

A modern, customizable, cross-framework data grid library for React, Angular, Vue, and more. Features sorting, pagination, drag-and-drop, and persistent order.
