# n8n-nodes-passport

> 标签: air-gapped, bbqr, bitcoin, casa, cold-storage, envoy, foundation, foundation-devices, hardware-wallet, multisig, n8n, n8n-community-node-package, passport, psbt, seedqr, unchained

## 简介

A comprehensive n8n community node for Foundation Passport hardware wallet providing 21 resources and 150+ operations for air-gapped Bitcoin signing, PSBT handling, multisig workflows, and watch-only wallet exports. Includes BBQr animated QR, Envoy/Casa/U
