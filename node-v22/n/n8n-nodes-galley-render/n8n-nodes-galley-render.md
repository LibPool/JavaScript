# n8n-nodes-galley-render

> 标签: certificate, document, html-to-pdf, invoice, n8n, n8n-community-node-package, og-image, pdf, pdf-generation

## 简介

Galley Render node for n8n — JSON in, PDF out. Render invoices, certificates, reports, labels and cards from a template and a payload.
