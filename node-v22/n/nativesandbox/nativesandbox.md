# nativesandbox

> 标签: agent, arm64, container, docker, isolation, no-kvm, podman, sandbox, untrusted-code

## 简介

Run untrusted code in isolated sandboxes on any Linux host — containers via Podman or Docker, no nested virtualisation and no KVM required.
