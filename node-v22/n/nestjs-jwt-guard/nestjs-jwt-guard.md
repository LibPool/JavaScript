# nestjs-jwt-guard

> 标签: auth, authentication, bearer, guard, jwt, nest, nestjs

## 简介

Bearer-JWT authentication for NestJS, built on @nestjs/jwt — a configurable guard, @Public(), and a token-issuance helper.
