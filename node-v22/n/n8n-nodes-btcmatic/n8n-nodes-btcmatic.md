# n8n-nodes-btcmatic

> 标签: automation, bitcoin, btc, btcmatic, n8n-community-node-package, trading, webhook

## 简介

n8n community node for BTCMatic — Bitcoin event engine: react to rule fires, manage rules, run backtests and send events into webhook-triggered rules
