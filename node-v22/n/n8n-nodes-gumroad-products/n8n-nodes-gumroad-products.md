# n8n-nodes-gumroad-products

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

This actor reads product pages and search results on Gumroad. Records contain product names, creator information, prices, currencies, descriptions, product URLs, and other fields exposed by each listing.
