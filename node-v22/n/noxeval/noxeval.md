# noxeval

> 标签: cohen-kappa, eval, evaluation, llm, llm-as-a-judge, prompt-injection, rag, testing

## 简介

Evaluate LLM apps you can trust: deterministic checks first, an optional judge second, and planted errors plus blind human review to check the judge.
