# npmwat

> 标签: runner, scripts

## 简介

A CLI that lists all scripts in package.json and allows filtering and selecting which to run. Also detects whether project should be run with yarn or npm

## 官网

- npm 页面：https://www.npmjs.com/package/npmwat
