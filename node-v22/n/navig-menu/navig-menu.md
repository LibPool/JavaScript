# navig-menu

> 标签: cli, developer-tools, menu, monorepo, navig, package-manager, plugins, terminal, tui

## 简介

AI-first menu builder — auto-detects any project's stack and builds a premium interactive terminal menu with layouts, a plugin system, and a live settings panel. Standalone or via `navig menu`.
