# node-ftp-honeypot

> 标签: JavaScript

## 简介

node-ftp-honeypot is a ftp honepot. When the application is launched, a ftp server is launched. Everything is forbidden except file upload. When a bot or a ftp scanner tries to upload a file this file is moved into pandora-box inside a folder named with t
