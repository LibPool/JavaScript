# nightshift-verify

> 标签: gate, nightshift, off-chain, starknet, subscription

## 简介

Check a NIGHTSHIFT tier presentation off-chain: no transaction, no gas, nothing written to the chain. Reads the vault's views over RPC and checks the owner-key signature.
