# next-boilerplate-cli

> 标签: boilerplate, jest, next, testing, typescript

## 简介

This is a CLI for the Next.js Boilerplate (https://github.com/vladimirvoth/next-boilerplate). With this CLI you can generate a new project and generate new pages automatically with a SCSS file and boilerplate for a test.
