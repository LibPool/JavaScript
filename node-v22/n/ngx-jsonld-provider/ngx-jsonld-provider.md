# ngx-jsonld-provider

> 标签: angular, json, json-ld, jsonld, ngx

## 简介

Angular shim for JSON-LD operations. Inject an Angular provider that performs compaction and expansion, framing, RDf translation, etc. Built on top of jsonld.js.
