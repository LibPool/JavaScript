# n8n-nodes-snaprender

> 标签: n8n, n8n-community-node-package, screenshot, snaprender, web-capture

## 简介

n8n node for SnapRender API: screenshots, content extraction, batch processing, signed URLs, webhooks. PNG, JPEG, WebP, PDF with device emulation, dark mode, ad blocking.
