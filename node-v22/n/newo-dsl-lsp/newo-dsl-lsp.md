# newo-dsl-lsp

> 标签: guidance, language-server, lsp, newo, nsl, vscode

## 简介

Language Server Protocol server for the Newo DSL (NSL/Guidance). Powers the VS Code extension and any LSP-aware editor (Neovim, Helix, Zed).
