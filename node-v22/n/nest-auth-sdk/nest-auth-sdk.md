# nest-auth-sdk

> 标签: auth, data-permission, jwt, nestjs, permission, rbac, sm3

## 简介

NestJS 权限框架基础二方包，对标 Java csoft-permission：JWT认证 + RBAC权限 + 数据权限 + 操作日志 + 用户上下文 + SM3加密
