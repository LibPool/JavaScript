# nosana-mcp

> 标签: ai-agents, claude, comfyui, deploy, gpu, mcp, minimax, model-context-protocol, nosana

## 简介

Nosana MCP: let AI agents rent GPUs on the Nosana network and deploy templates such as MiniMax H3 with account credits. Ships the nosana-deploy CLI too.
