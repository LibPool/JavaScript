# nano-payload

> 标签: ashiro, baileys, lycount, ptv, video-note, wa-bot, whatsapp

## 简介

Universal PTV (Video Note) payload builder untuk WhatsApp bot berbasis Baileys — auto-detect native support, fallback ke raw proto message.
