# nova-twi

> 标签: english to twi, nova-twi, translation, translator, twi sdk, twi translator

## 简介

A lightweight, hybrid English-to-Twi translation engine for Node.js. It combines lightning-fast dictionary/phrase mapping with LLM context-refinement via Groq (Llama-3) to produce fluid, natural Twi translations instead of direct mechanical word-for-word
