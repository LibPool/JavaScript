# nodejs-schema-rules

> 标签: dynamic-rules, dynamic-schema, dynamic-validation-rules, joi validation rules, mysql schema rules, node, nodejs-validation, postgres schema rules, schema, validatorjs, validatorjs  validation rules, vineJs  validation rules, vinejs@vine  validation rules

## 简介

The CLI tool automatically generates basic validation rules for popular libraries such as JOI, ValidatorJS and @vinejs/vine based on your database table schema!
