# next-dialect

> 标签: app-router, compiler, i18n, icu, internationalization, l10n, localization, messageformat, next, nextjs, react, react-server-components, zero-runtime

## 简介

Zero-overhead i18n for Next.js: messages compile to constants inside the chunks that use them. No client catalog, no runtime lookups, no fallback chains.
