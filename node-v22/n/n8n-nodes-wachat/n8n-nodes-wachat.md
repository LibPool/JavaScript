# n8n-nodes-wachat

> 标签: crm, n8n, n8n-community-node-package, wachat, whatsapp

## 简介

Nodo de n8n para WaChat: envía mensajes de WhatsApp y gestiona conversaciones (asignar agente, fila, estado, etapa de pipeline) desde tus automatizaciones.
