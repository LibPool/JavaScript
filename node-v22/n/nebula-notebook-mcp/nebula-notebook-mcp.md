# nebula-notebook-mcp

> 标签: ai, claude, jupyter, mcp, model-context-protocol, notebook

## 简介

MCP server for Nebula Notebook — lets agents (Claude Code, Codex, etc.) read, edit, and execute notebooks on a running Nebula server
