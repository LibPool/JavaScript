# n8n-nodes-nokfi

> 标签: accounting, e-invoice, finance, invoice-extraction, invoices, invoicing, n8n-community-node-package, nokfi, spain, tax, vat, verifactu, webhook

## 简介

n8n nodes for Nokfi: issue invoices (PDF, e-invoice, VERI*FACTU), extract and validate invoices, run financial analyses, Spanish tax tools (NIF, VAT, IRPF, Modelo 130, tax calendar) and a trigger for Nokfi events.
