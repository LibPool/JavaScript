# n8n-nodes-ghost-blocks-cloud

> 标签: blog, cms, content-blocks, ghost, lexical, n8n, n8n-community-node-package, publishing

## 简介

n8n community node for publishing to Ghost CMS using simple, flat content blocks. Verified-compatible (n8n Cloud installable). Builds Lexical documents and handles JWT auth internally.
