# n8n-nodes-sambungan

> 标签: automation, chat, instagram, messaging, n8n, n8n-community-node-package, sambungan, trigger, webhook, whatsapp

## 简介

n8n community node for Sambungan - Send WhatsApp and Instagram DM messages with interactive buttons, flexible customer lookup, typing indicators, and a trigger for Sambungan webhook events
