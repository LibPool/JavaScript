# number-flow-react-native

> 标签: android, animated-numbers, animation, counter, currency, dashboard, digit-animation, expo, fintech, i18n, internationalization, intl-numberformat, ios, number, number-flow, number-formatting, number-ticker, odometer, price-ticker, react-native, react-native-component, reanimated, rolling-numbers, skia, spinning-numbers, ticker, time-animation, transition

## 简介

Beautiful number animations for React Native: digit-by-digit rolling counter, currency ticker, time display, and odometer with View-based and Skia renderers. Full Intl.NumberFormat support.
