# n8n-nodes-speakai

> 标签: captions, n8n-community-node-package, sentiment, speak, speakai, transcription

## 简介

n8n community node for Speak AI: upload media and text for transcription and analysis, run AI Chat, look up media, and trigger workflows on new transcripts, captions, sentiment, AI Chat responses, and recordings.
