# node-red-contrib-dynamic-websocket-pool

> 标签: basic-auth, dynamic, node-red, reconnect, websocket, wss

## 简介

A Node-RED node to manage a pool of WebSocket connections with keepalive, auto-reconnect, Basic Auth, and per-id routing.
