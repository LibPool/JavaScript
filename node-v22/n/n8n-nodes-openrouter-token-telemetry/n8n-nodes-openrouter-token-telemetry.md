# n8n-nodes-openrouter-token-telemetry

> 标签: cost, deepseek, n8n, n8n-community-node-package, observability, openrouter, prompt-caching, token-usage, tokens

## 简介

OpenRouter chat model for n8n that reports the full token usage the default node discards: cached input, billable input, reasoning tokens and cache hit ratio.
