# node_todolist_1

> 标签: JavaScript

## 简介

这是一个对待办事项进行管理的小插件，可以对自己所添加的任务进行标注已完成操作，还能对自己所添加的待办事项进行增删改查操作

- npm 页面：https://www.npmjs.com/package/node_todolist_1
