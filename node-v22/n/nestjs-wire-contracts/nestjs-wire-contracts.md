# nestjs-wire-contracts

> 标签: contracts, message-pattern, microservices, nestjs, typescript, zod

## 简介

Typed, validated contracts for @nestjs/microservices message patterns (TCP, Redis, NATS, Kafka, RabbitMQ, MQTT). Early development placeholder.
