# nestweaver-linux-arm64

> 标签: JavaScript

## 简介

NestWeaver prebuilt binary for Linux aarch64 (glibc). Not meant to be installed directly -- installed automatically as an optional dependency of the `nestweaver` package.

## 官网

- 官网：https://github.com/Kehl-io/nestweaver
- 源码仓库：git+https://github.com/Kehl-io/nestweaver.git
- npm 页面：https://www.npmjs.com/package/nestweaver-linux-arm64
