# n8n-nodes-looktwice

> 标签: compliance, cpsc-recalls, ecommerce, email-validation, iban, looktwice, n8n-community-node-package, n8n-nodes-looktwice, product-safety, vat-validation, vies

## 简介

Official LookTwice node for n8n: validate EU VAT numbers with VIES outage fallback, screen CPSC product safety recalls, verify emails, and check IBANs.
