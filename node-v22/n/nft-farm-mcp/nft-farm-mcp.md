# nft-farm-mcp

> 标签: evm, free-mint, mcp, model-context-protocol, nft, onchain-analytics, pnl, robinhood-chain, seaport

## 简介

MCP server + CLI: find free-mint NFT collections and the wallets farming them, ranked by on-chain secondary PnL. Any EVM chain with a Seaport deployment; Robinhood Chain by default.
