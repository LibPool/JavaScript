# n8n-nodes-max-fedotovteam

> 标签: n8n-community-node-package

## 简介

n8n community node for Max messenger integration. Форк от fedotovteam — исправлена загрузка на свежих версиях n8n (pnpm). Send messages, handle webhooks, manage attachments, and create interactive bot experiences using the official Max Bot API.
