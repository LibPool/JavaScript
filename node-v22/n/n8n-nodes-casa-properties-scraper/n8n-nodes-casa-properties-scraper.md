# n8n-nodes-casa-properties-scraper

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Scrape Casa.it Italian real estate listings from search-result URLs. Returns price, rooms, surface, energy class, district/block geo rollup, publisher and media. No proxy needed. Pay per listing.
