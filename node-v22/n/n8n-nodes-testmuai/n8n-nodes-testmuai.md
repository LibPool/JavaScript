# n8n-nodes-testmuai

> 标签: ai-agent, browser-automation, lambdatest, n8n-community-node-package, selenium, testmuai, webdriver

## 简介

n8n verified community node for TestMu AI (Formerly LambdaTest). Gives an AI Agent native browser tools — navigate, click, type, extract — running on TestMu's real cross-browser cloud infrastructure via the W3C WebDriver protocol.
