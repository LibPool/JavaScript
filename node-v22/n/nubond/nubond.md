# nubond

> 标签: adopted-styles, aspects, attribute-binding, change-detection, content-projection, custom-elements, data-binding, declarative, decorators, dependency-injection, framework, lightweight, progressive, pwa, reactive, routing, shadow-dom, spa, transformers, typescript, ui-framework, web-components, zero-dependencies

## 简介

A declarative TypeScript progressive framework with Web Components, Shadow DOM, and an attribute-driven binding system — featuring dependency injection, routing, automatic change detection, aspects, transformers, and content projection.
