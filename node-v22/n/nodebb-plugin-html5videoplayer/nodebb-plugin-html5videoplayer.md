# nodebb-plugin-html5videoplayer

> 标签: mov, mp4, nodebb, ogv, player, plugin, video, webm

## 简介

this plugin embeds an HTML5 videoplayer. when upload a video this does not appear as a link but as players in the content. Accepted video formats MP4, WEBM, MOV, OGV. Forked from https://github.com/ogerly/nodebb-plugin-videoplayer.
