# neiki-table

> 标签: csv-export, custom-elements, data-table, datagrid, i18n, table, vanilla-js, web-components

## 简介

Lightweight, dependency-free CDN-ready data table Web Component with sorting, search, filters, pagination, inline editing, row selection, column resizing, density modes, custom cell formatting, CSV/JSON export/clipboard and i18n support
