# notipo

> 标签: ai-agents, claude, cli, gutenberg, markdown-to-wordpress, mcp, model-context-protocol, notion, notion-to-wordpress, notipo, publishing, self-hosted, seo, wordpress, wordpress-publishing

## 简介

Publish to self-hosted WordPress from AI agents, scripts, or Notion — markdown to Gutenberg, image hosting, featured images, and SEO. Pairs with the Notipo MCP server.
