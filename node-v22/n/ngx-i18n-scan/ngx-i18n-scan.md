# ngx-i18n-scan

> 标签: angular, cli, extract, extractor, i18n, internationalization, localization, merge, ngx-translate, scanner, translation, typescript, xliff

## 简介

A CLI tool to scan Angular projects for i18n keys, detect unused and duplicate keys, and auto-update translation files.
