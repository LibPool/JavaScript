# node-red-contrib-sqlitedb

> 标签: node-red, sqlitedb

## 简介

Sends SQL queries to an SQLite cloud database provided as a service at <a href="https://www.sqlitedb.com/" target="_blank">https://www.sqlitedb.com/</a>
