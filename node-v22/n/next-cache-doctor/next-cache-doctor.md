# next-cache-doctor

> 标签: app-router, cache, cacheLife, cacheTag, cli, devtools, lint, next.js, nextjs, static-analysis, use-cache

## 简介

Static analysis CLI for Next.js 'use cache' directive: catches missing cacheLife, potential private-data leaks in cached scopes, and missing cacheTag before they hit production.
