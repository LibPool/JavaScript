# nimble-http

> 标签: axios, cache, client, fetch, form-data, http, https, interceptor, request, retry, timeout, zero-dependency

## 简介

Zero-dependency Node.js HTTP client built on native fetch(), with interceptors, automatic retry, timeout, response caching, FormData uploads, redirect handling, and progress tracking. A leaner, more capable alternative to axios and node-fetch.
