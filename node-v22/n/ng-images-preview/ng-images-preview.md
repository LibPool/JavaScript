# ng-images-preview

> 标签: angular, gallery, image-preview, image-viewer, images-preview, lightbox, mobile-ready, pinch-to-zoom, preloading, pull-to-close, rotate, signals, standalone, swipe, thumbnails, touch-support, vanilla-css, zoom

## 简介

🚀 High-performance Angular 18+ Image Preview & Gallery. Features native-like mobile gestures (Pinch-to-Zoom, Pull-to-Close), auto-thumbnails & smart preloading. Built with Signals & Zero-Dep Vanilla CSS.
