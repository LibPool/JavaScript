# n8n-nodes-google-workspace-sa

> 标签: admin sdk, domain-wide delegation, gmail, google workspace, impersonation, n8n-community-node-package, service account

## 简介

Call Gmail and Admin SDK APIs as any user in your Google Workspace domain, using a service account with domain-wide delegation — impersonates a different mailbox on every call.
