# nv-time-str

> 标签: JavaScript

## 简介

nv-time-str ======================= - simple util to convert Date'isoStr  to compatible with nvlang' compile-time date-var-name - nvlang support a special Literal   begin with "DT":  DTYYYYMMDD\_hhmmss\_xxx
