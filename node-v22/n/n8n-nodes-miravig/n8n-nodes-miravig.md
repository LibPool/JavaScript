# n8n-nodes-miravig

> 标签: gdpr, llm, n8n-community-node-package, pii, privacy, prompt

## 简介

Detects sensitive data before sending text to an LLM, and reverses masking afterwards -- checksum-verified glossary sync, never a silent correction. Prompt-quality checks (variables, placeholders, JSON wrapping, verbatim preservation) are a separate tool
