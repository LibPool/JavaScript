# notjev

> 标签: abstention, calibration, classification, decision, jev, llama.cpp, llm, logprobs, ollama, openai, openjev, system-one, typed-decisions, typesafe, typesafe-ai, vllm

## 简介

Read a decision out of the next-token distribution instead of making a model write it: one chat/completions request, max_tokens 1, logprobs on, a verdict AND a calibrated-ish probability. Server-agnostic, zero runtime dependency. Speaks the Jev /v1/system
