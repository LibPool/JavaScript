# n8n-nodes-redfin-scraper

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Scrape Redfin real estate listings by city, ZIP code, county, or any Redfin search URL. Returns price, beds, baths, sqft, lot size, year built, days on market, coordinates, and more via Redfin's internal stingray JSON API. No proxy required for most regio
