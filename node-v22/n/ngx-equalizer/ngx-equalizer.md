# ngx-equalizer

> 标签: angular, equalizer, height, ng, ngx

## 简介

This library is inspired from [equalizer](https://github.com/skrajewski/Equalizer) jQuery library to keep HTML elements with equal height.   The library is compatible with Angular 4+ because of its low peer dependencies.
