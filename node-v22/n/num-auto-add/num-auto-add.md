# num-auto-add

> 标签: animate, guang-hui, numAutoAdd

## 简介

`num-auto-add` 是一个轻量级的库，用于在 Vue 3 应用中为数字添加自动递增的动画效果。本文档将指导你如何在基于 Vite 的 Vue 3 项目中集成和使用该库。
