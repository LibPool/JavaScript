# n8n-nodes-oddsrelay

> 标签: bookmakers, exchange, n8n, n8n-community-node-package, odds, odds-api, oddsmatcher, oddsrelay, sports-odds

## 简介

n8n node for the OddsRelay odds API: matched boards, raw bookmaker and exchange prices, events and sports, with a token cap on every call that spends tokens.
