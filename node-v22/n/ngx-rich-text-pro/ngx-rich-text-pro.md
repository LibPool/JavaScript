# ngx-rich-text-pro

> 标签: angular, angular-editor, contenteditable, editor, hashtag, hashtags, html-editor, ngx-editor, ngx-rich-text-pro, rich-text-editor, rich-text-pro, social-media-editor, standalone, text-editor, wysiwyg

## 简介

A modern, lightweight, zero-dependency Rich Text & Social Post Editor for Angular 17, 18, 19, 20, 21+. Includes standalone support, Reactive Forms, custom toolbars, callable API, real-time hashtags, and smart placeholders.
