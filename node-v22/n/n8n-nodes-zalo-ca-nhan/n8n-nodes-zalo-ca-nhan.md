## 简介

n8n-nodes-zalo-ca-nhan - Community nodes package cho n8n tự động hóa Zalo hoàn chỉnh. Xây dựng workflow n8n, tự động hóa gửi tin nhắn, quản lý nhóm, bạn bè Zalo. Hỗ trợ đăng nhập QR, webhook tin nhắn, trigger sự kiện kết bạn, tạo poll, quản lý tag. Sử dụn
