# next-calendrix

> 标签: booking, calendar, date-range, datepicker, hotel-calendar, range-selection, react, react-calendar, typescript

## 简介

A lightweight, headless React calendar component with range selection, hotel mode, blocked dates, min-nights, smart suggestions, and mobile/desktop variants.
