# n8n-nodes-krisha-listings

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Collect property listings from Krisha.kz (Kazakhstan): title, rooms, area, floor, price, currency, city, address, photo and listing link. No login, walk any search or category page.

## 官网

- 官网：https://apify.com/bovi/krisha-listings
- npm 页面：https://www.npmjs.com/package/n8n-nodes-krisha-listings
