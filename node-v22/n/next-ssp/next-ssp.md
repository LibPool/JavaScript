# next-ssp

> 标签: dehydration, error-handling, get-server-side-props, http-status, hydration, meta-tags, next, nextjs, pages-router, pipeline, react-query, seo, server-side-props, ssp, ssr, tanstack-query

## 简介

Server-side props pipeline for the Next.js pages router: a step engine with lifecycle hooks, deterministic error-to-status mapping, a React Query dehydration companion and a MetaHead component.
