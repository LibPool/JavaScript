# n8n-nodes-videocaptioner-asr

> 标签: asr, bcut, bilibili, capcut, jianying, n8n-community-node-package, speech-to-text, srt, subtitle, transcription, videocaptioner

## 简介

n8n community node that transcribes audio into subtitles with the free B interface (Bcut / Bilibili) and J interface (JianYing / CapCut) ASR services. Ported from VideoCaptioner.
