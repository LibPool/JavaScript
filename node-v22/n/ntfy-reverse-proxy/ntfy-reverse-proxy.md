# ntfy-reverse-proxy

> 标签: cloudflare-workers, notifications, ntfy, pfsense, reverse-proxy, seerr, statuspage, synology, unifi, webhooks

## 简介

Notification gateway on Cloudflare Workers that routes webhooks and emails to ntfy with automatic server failover
