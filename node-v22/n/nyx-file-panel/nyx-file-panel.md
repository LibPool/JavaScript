# nyx-file-panel

> 标签: deepseek-harness, diff, dsh, dsh-plugin, file-panel, viewer

## 简介

Antigravity-style in-app file panel for DeepSeek Harness: file links open a right-side preview / diff / editor column instead of the OS default app.
