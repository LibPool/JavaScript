# nestjs-query-simple

> 标签: GraphQL, MongoDB, NestJS, Nestjs-query, TypeScript

## 简介

A thin layer built on top of 'NestJS-Query', enables easy definition of MongoDB/GraphQL Entities and DTOs within NestJS apps.
