# node-scaffolder

> 标签: JavaScript

## 简介

Node-scaffolder is an interactive command line tool to create Node.js projects quickly. With just 3 questions (which takes 10 seconds) you can scaffold a project with your favorite language (JS or TS) bundler (Babel, Webpack 4, Rollup, TSC) and test setup
