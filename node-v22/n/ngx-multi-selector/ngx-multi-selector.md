# ngx-multi-selector

> 标签: angular-6-drop-down, angular6-dropdown, drop-down, multi selector, multi-drop-down, multi-selector, ngx-multi-selector

## 简介

A small plugin which generates multi-selector control, it supports web api loading. Only supported angular 5.
