# n8n-nodes-multi-stl-rental-monitor

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Monitor short-term-rental supply across Airbnb and Booking.com in one run, in one unified schema: name, price, rating, reviews, geo and URL per listing. Compare cross-platform supply and pricing for a market. Pay per listing.
