# nevernullable

> 标签: discriminated-union, esm, fp, fp-ts, functional, functional-programming, match, maybe, maybe-monad, monad, never-null, neverthrow, non-null, non-nullable, none, null, null-safe, nullable, nullsafe, option, option-type, optional, oxide, pattern-matching, result, rust, rust-option, some, ts, type-safe, typesafe, typescript, typescript-library

## 简介

Type-safe Option<T>, Some<T>, None for TypeScript and JavaScript. Replace null and undefined with a Rust-inspired Option type with map, andThen, filter, match, unwrap and Promise interop. Zero dependencies, dual ESM + CJS, ~2 KB.
