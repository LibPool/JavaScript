# node-red-contrib-spike-reporter

> 标签: monitoring, node-red, out-of-control, reporter, spike

## 简介

Node-RED node for monitoring system's state and reporting alarms based on consecutive out-of-control status indications obtained from node-red-contrib-simple-spc node.
