# node-idb

> 标签: admin-ui, database, database-gui, database-studio, document-database, document-store, embedded-database, idb, json-database, nodejs, nosql, query-builder, sqlite, sqlite-gui, sqlite3, transactions, typed-storage, upsert

## 简介

An embedded SQLite document store for Node.js with typed values, SQL-style queries, automatic indexes, and a local browser Studio.
