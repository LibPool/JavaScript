# n8n-nodes-minimax-unified

> 标签: ai, ai-agent, anthropic-compatible, chat, chatbot, language-model, llm, minimax, minimax-ai, minimaxi, n8n, n8n-community-node-package, n8n-nodes, n8n-nodes-minimax-unified, n8n.io, n8n.io-nodes, openai-compatible

## 简介

n8n community node for MiniMax AI. Supports both the international (api.minimax.io) and China (api.minimaxi.com) endpoints, Standard and Coding Plan keys, and the latest MiniMax-M3 model. Fixes the authorization failure seen in older community packages.
