# nodesvr

> 标签: boilerplate, cli, express, jwt, nodejs, postgresql, prisma, scaffold, typescript, zod

## 简介

Scaffold a new Node.js server project (Express + Prisma + PostgreSQL + Zod + JWT + RBAC) by answering a few prompts.
