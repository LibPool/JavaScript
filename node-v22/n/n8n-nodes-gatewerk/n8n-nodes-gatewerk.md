# n8n-nodes-gatewerk

> 标签: ai-agents, approval, gatewerk, hitl, human-in-the-loop, human-oversight, n8n, n8n-community-node-package, review

## 简介

Pause an n8n workflow until a person approves it in Gatewerk, with edit before approve, revision loops and a signed audit trail.
