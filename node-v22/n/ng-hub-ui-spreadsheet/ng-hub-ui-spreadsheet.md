# ng-hub-ui-spreadsheet

> 标签: accessibility, angular, cell-editing, clipboard, data-grid, editable-table, excel, ng-hub-ui, range-selection, signals, spreadsheet, standalone

## 简介

Excel-like editable spreadsheet for Angular: in-cell editing, full keyboard navigation, rectangular range selection and a clipboard that round-trips with Excel. Accessible, themable through CSS variables and free of paid tiers. Part of the ng-hub-ui famil
