# ngx-quill-v2

> 标签: angular, angular 2, angular2, component, directive, editor, ng, ngx, quill, quilljs, rich text, text editor, wysiwyg

## 简介

An angular (>= v2) component for the easy use of the QuillJS rich text editor for v2 release. The v2 release is a dev preview which has new experimental features like table support.
