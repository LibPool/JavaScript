# n8n-nodes-bringatrailer-auction-listings

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Scrape live car auction listings from bringatrailer.com: current bid, reserve status, VIN, lot number, seller, listing details, gallery images and comments. Pay per result.
