# n8n-nodes-eu-pii-redact

> 标签: anonymization, gdpr, llm, n8n-community-node-package, pii, privacy, redaction

## 简介

n8n node: redact European personal data (names, EU national IDs, IBANs, emails, phones) before it reaches an LLM, and restore it afterwards.
