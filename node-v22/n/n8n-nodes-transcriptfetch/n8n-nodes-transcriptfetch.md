# n8n-nodes-transcriptfetch

> 标签: captions, instagram, n8n-community-node-package, speech-to-text, tiktok, transcript, transcriptfetch, transcription, youtube, youtube-transcript

## 简介

n8n community node for TranscriptFetch: video transcripts from YouTube, TikTok and Instagram - captions in about a second, automatic AI speech-to-text when none exist - plus YouTube search, channel and playlist listing, and a new-video trigger.
