# n8n-nodes-confluence-designer

> 标签: atlassian, confluence, design, markdown, n8n-community-node-package, storage-format

## 简介

Confluence Designer node for n8n: turn Markdown, JSON data and building blocks into styled Confluence Storage Format (Data Center & Cloud) — panels, themed tables, status lozenges, TOC, layouts, HTML preview. No API access needed. Powered by Thomas Braun.
