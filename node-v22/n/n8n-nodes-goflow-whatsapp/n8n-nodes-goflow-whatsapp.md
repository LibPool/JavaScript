# n8n-nodes-goflow-whatsapp

> 标签: goflow, messaging, n8n, n8n-community-node-package, trigger, whatsapp

## 简介

n8n community node for GoFlow WhatsApp — receive incoming messages and send text, media, mentions, typing and read receipts via the GoFlow API.
