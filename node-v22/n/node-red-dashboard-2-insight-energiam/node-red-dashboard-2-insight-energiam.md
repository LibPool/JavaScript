# node-red-dashboard-2-insight-energiam

> 标签: chart, dashboard, echarts, energiam, node-red, node-red-dashboard-2, timeseries, visualization

## 简介

Widget ECharts offline para FlowFuse Dashboard 2.0. Visualizador de series temporales estilo Grafana, agnóstico a la fuente de datos. Parte del ecosistema EnergIAM.
