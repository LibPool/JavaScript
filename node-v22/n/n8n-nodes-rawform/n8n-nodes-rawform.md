# n8n-nodes-rawform

> 标签: form, html, n8n, n8n-community-node-package, wait, webhook, workflow

## 简介

n8n community nodes that render fully author-controlled, unsanitised HTML as multi-page web forms, driven by n8n's durable wait/resume.
