# nestlibs-winston-logger

> 标签: JavaScript

## 简介

This package is for self use. Feel free to use it if you find it useful.\ A simple wrapper around the [winston](https://www.npmjs.com/package/winston) logger with [daily log rotation](https://www.npmjs.com/package/winston-daily-rotate-file) To log message
