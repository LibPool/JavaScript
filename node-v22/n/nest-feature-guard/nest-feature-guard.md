> 标签: a-b-testing, access-control, beta-features, canary-deployment, decorators, experimental-features, feature-flags, feature-gates, feature-toggles, gradual-rollout, guards, nestjs, progressive-enhancement, redis, typescript, user-targeting

## 简介

A powerful, NestJS-first feature flag guard and decorator library with Redis caching support. Perfect for implementing feature toggles, A/B testing, gradual rollouts, and user-specific feature access control.
