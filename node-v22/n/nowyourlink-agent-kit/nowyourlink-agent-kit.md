# nowyourlink-agent-kit

> 标签: api-client, cli, javascript, mcp, nowyourlink, sdk, typescript

## 简介

Official nowyourlink JavaScript and TypeScript SDK, CLI and agent plugin for nowyourlink.com: public Spotlight reads and OAuth 2.1 delegated advertiser actions.
