# n8n-nodes-eleman-jobs

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Collect Turkish job listings from Eleman.net: job title, company, city/district, summary, phone-application flag, company logo and listing link. No login, keyword + page filters.

## 官网

- 官网：https://apify.com/bovi/eleman-jobs
- npm 页面：https://www.npmjs.com/package/n8n-nodes-eleman-jobs
