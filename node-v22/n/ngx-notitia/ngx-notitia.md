# ngx-notitia

> 标签: alert, angular, angular-toast, component, dark-mode, glassmorphism, light-mode, ng, ngx-notitia, notice, notification, notitia, overlay, popup, signals, snackbar, standalone, toast, toast-notification, toastr, typescript, ui

## 简介

Easy, flexible toast notifications for Angular 17+. Glassmorphism theme with blur and background opacity controls, dark/light mode, swipe-to-dismiss, and Angular signals.
