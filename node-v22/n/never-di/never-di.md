# never-di

> 标签: dependency-injection, di, esm-only, framework-agnostic, functional-di, injection, ioc, lightweight, never-di, typescript, typescript-di

## 简介

A lightweight, immutable, dependency-free, function-only dependency injection (DI) container for TypeScript.
