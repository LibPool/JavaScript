# n8n-nodes-wr-facebook-capi

> 标签: capi, conversions-api, facebook, meta, n8n, n8n-community-node-package, offline-conversions

## 简介

Webrunner custom n8n node for the Meta (Facebook) Conversions API — offline/CRM conversion upload against a per-item dataset ID, with Meta-spec identifier normalization and hashing, fbc assembly, and a client-side guard on Meta's 7-day event_time cliff
