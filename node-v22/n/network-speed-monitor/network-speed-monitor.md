# network-speed-monitor

> 标签: network-speed, network-speed-monitor, network-speed-nodejs

## 简介

A Node.js module for monitoring real-time network upload and download speeds. This module allows you to monitor the current network speed at a specified refresh interval, making it useful for applications that require up-to-date network performance inform
