# native-sim

> 标签: agent-device, expo, github-actions, ios-simulator, preview, react-native, serve-sim, simulator

## 简介

Stream a live iOS Simulator of your React Native or Expo app from a GitHub-hosted macOS runner to your browser — and let a coding agent drive it.
