# next-route-mapper

> 标签: api-endpoints, api-routes, cli, documentation, endpoints, next.js, nextjs, nextjs-api-routes, route-mapper

## 简介

Zero-dependency CLI that scans Next.js App Router projects and sub-routes to list all API endpoints and HTTP methods.
