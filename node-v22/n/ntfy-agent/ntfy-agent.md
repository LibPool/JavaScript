# ntfy-agent

> 标签: claude-code, cli, codex, copilot-cli, cursor, gemini-cli, hooks, notifications, ntfy, push-notifications

## 简介

Push a phone and desktop notification when your coding agent finishes a turn or needs input. Works with Claude Code, Codex, Cursor, Gemini CLI and Copilot CLI.
