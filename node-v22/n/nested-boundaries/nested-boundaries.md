# nested-boundaries

> 标签: architecture, biome, biome-plugin, boundaries, deep-modules, dependency-cruiser, encapsulation, eslint, eslint-plugin, gritql, module-boundaries, oxlint

## 简介

Enforce the Recursive Deep Modules convention from paths alone: nested module boundaries for ESLint, oxlint, and Biome, plus cycle detection and structural checks.
