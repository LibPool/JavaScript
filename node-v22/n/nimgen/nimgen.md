> 标签: ai-art, claude, cursor, flux, flux-1, image-editing, image-generation, mcp, model-context-protocol, nim, nvidia, opencode, text-to-image

## 简介

First MCP server for NVIDIA NIM FLUX — Generate and edit images using FLUX.1 models with your existing NVIDIA API key. No extra subscriptions needed.
