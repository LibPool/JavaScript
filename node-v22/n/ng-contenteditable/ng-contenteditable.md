# ng-contenteditable

> 标签: angular, contenteditable

## 简介

This is micro Angular v6+ contenteditable directive for compatibility with Angular forms. It just implements [ControlValueAccessor](https://angular.io/api/forms/ControlValueAccessor) for this purpose.
