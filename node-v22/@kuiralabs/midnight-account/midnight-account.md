# @kuiralabs/midnight-account

> 标签: JavaScript

## 简介

A client library for Midnight's account contract (MIP-0012 custody, MIP-0013 device authorisation, Passport's signature-schemes and scoped-grants drafts): the byte recipes, signers, InboxEntry, GrantViewSeal, the grant mailbox, and grant requests, written
