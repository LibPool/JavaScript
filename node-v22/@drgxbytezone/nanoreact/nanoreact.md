# @drgxbytezone/nanoreact

> 标签: fiber, framework, hooks, lightweight, react, router, typescript, virtual-dom

## 简介

An ultra-lightweight, feature-packed mini React framework with Fiber Reconciler, Full Hooks suite, Built-in NanoRouter, and JSX support built from scratch in TypeScript.
