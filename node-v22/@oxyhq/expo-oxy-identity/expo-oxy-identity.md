> 标签: content-provider, expo, expo-module, identity, oxyhq, react-native, sso

## 简介

Cross-app shared Oxy identity bridge for Oxy Expo apps. Commons (the identity vault) writes a single secp256k1 keypair; every same-device Oxy app signed with the shared release key reads it via a signature-protected ContentProvider, enabling silent "Sign
