# @secretgenerator/cli

> 标签: auditable, cli, cosign, csprng, password-generator, secret-generation, secretgenerator, sigstore, slsa

## 简介

Zero-config installer for the secretgenerator CLI. Downloads the right binary for your OS/arch from a verified GitHub release, checks the SHA-256, and (when cosign is available) verifies the keyless Sigstore signature.
