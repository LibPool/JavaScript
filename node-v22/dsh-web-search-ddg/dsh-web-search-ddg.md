# dsh-web-search-ddg

> 标签: JavaScript

## 简介

Zero-token web search for the DeepSeek Harness (DSH) web capability seam (ctx.web) — Bing fetch engine with local headless-browser DuckDuckGo fallback, no API key, no auxiliary model request
