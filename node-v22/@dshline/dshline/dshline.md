# @dshline/dshline

> 标签: capabilities, deepseek-harness, dsh-plugin, terminal, terminal-native, tui

## 简介

Terminal-native frontend for DeepSeek Harness with real scrollback; a direct, in-process consumer of Harness capabilities.
