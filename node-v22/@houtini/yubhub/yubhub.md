# @houtini/yubhub

> 标签: ai, ats, automation, careers, claude, job-feeds, mcp, model-context-protocol, recruitment, yubhub

## 简介

MCP server for YubHub — discover, enrich and publish jobs from career pages. Manage feeds, monitor pipelines and view stats through Claude, Cursor or any MCP client.
