# @kirigami/php-wasm

> 标签: curl, emscripten, jspi/*.js, jspi/*/*.wasm, kirigami, node, php, php-wasm, php8, sandbox, wasm, webassembly, wordpress-playground

## 简介

A custom PHP-WASM build for Node.js — JSPI only, no browser support. Built for the Kirigami project.
