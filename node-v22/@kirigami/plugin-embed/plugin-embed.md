# @kirigami/plugin-embed

> 标签: embed, kirigami, kirigami-plugin, oembed, plugin, video, vimeo, youtube

## 简介

<youtube>/<vimeo> video embed cards for Kirigami — oEmbed-backed, localStorage-cached, cover thumbnail + play button, powered by @kirigami/canva's observer.
