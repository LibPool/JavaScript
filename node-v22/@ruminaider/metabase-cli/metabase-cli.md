# @ruminaider/metabase-cli

> 标签: agent, cli, mcp, metabase, pi-package

## 简介

Metabase CLI with full read/write access: cards, dashboards, databases, tables, queries, collections, search, and revisions from the terminal. Token-efficient JSON output.
