# dsh-session-color

> 标签: color, contextmenu, deepseek-harness, dsh, dsh-plugin, session, sidebar

## 简介

DeepSeek Harness 侧栏会话右键标色:默认红色、十色色板、自定义取色,颜色本地持久化。 / Right-click any session row in DSH's sidebar to color-tag it (red by default, palette + custom picker), persisted locally.
