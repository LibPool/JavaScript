# @emulates/flex

> 标签: checkout, emulates, flex, fsa, hsa, payments, service, withflex

## 简介

Stateful emulator of the Flex HSA/FSA payments API: products (recorded catalog corpus), checkout sessions in payment, subscription, off-session and setup modes, subscriptions, customers, setup intents, refunds, the hosted checkout page, and Svix-signed we
