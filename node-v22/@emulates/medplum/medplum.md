# @emulates/medplum

> 标签: ehr, emulates, emulator, fhir, fhir-r4, medplum, service

## 简介

Stateful emulator of the self-hosted Medplum server (FHIR R4 REST, OAuth2 and admin API), proven at parity with a real self-hosted Medplum used as the oracle.
