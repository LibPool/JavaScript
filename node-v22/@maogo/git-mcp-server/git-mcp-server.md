# @maogo/git-mcp-server

> 标签: JavaScript

## 简介

一个基于 Model Context Protocol (MCP) 的 Git 助手服务器。通过标准输入/输出传输提供一组 Git 与项目文档相关的工具，便于智能体或自动化流程进行仓库操作、文档生成与代码分析。
