# @flowaitec/corex-js

> 标签: JavaScript

## 简介

A biblioteca Corex é um cliente Node.js para comunicação com servidores Corex através de conexões TCP, oferecendo funcionalidades de mensageria, canais, serviços e eventos em tempo real.
