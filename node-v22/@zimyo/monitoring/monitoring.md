# @zimyo/monitoring

> 标签: JavaScript

## 简介

Pure-logging monitoring package for Express apps. Drops into any existing app and captures requests, SQL (mysql2 / sequelize), outbound HTTP, errors, and time-series metrics — all persisted to MongoDB.
