# @shim-works/spackle

> 标签: chrome-38, core-js-alternative, embedded, es5, garbage-collection, kiosk, legacy-browser, memory, performance, polyfill, polyfills, retention, safari-7, set-top-box, smart-tv, tv

## 简介

Runtime polyfills for slow hardware (smart TV, set-top box, kiosks, etc) — Chrome >= 38 / Safari >= 7.1, built to avoid retaining memory rather than to match core-js
