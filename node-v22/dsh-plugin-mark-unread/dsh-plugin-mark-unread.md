# dsh-plugin-mark-unread

> 标签: deepseek-harness, dsh, plugin, session, unread

## 简介

DSH Web GUI 的「标记为未读」：给工作区会话行补一个手动未读标记（官方 completionUnread 只读且不落盘）。为官方支持前的过渡插件，自带自动退休机制。
