# @foresightjs/angular

> 标签: ForesightDirective, angular, angular-directive, foresight, foresightjs, interaction-prediction, js.foresight, mouse-trajectory, prefetch

## 简介

Angular bindings for ForesightJS - directives and services to register elements with the ForesightManager from Angular components.
