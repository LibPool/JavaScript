# @usemosaik/plugin-icons

> 标签: JavaScript

## 简介

The Icons Plugin implementation: adds lucide-react as a dependency. Dependency-only by design — no example usage is generated, to avoid coordinating file edits with other plugins that might also touch src/pages/Home.
