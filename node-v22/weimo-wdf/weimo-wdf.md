# weimo-wdf

> 标签: document, markdown, prosemirror, rich-text, tiptap, wdf

## 简介

WDF (Weimo Document Format): a strict canonical rich-text model with adapters for Tiptap/ProseMirror JSON, Apple document JSON, Markdown, and plain-text rendering
