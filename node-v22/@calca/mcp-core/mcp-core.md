# @calca/mcp-core

> 标签: JavaScript

## 简介

Pure, runtime-neutral half of Calca's Layer-2 agent playground: canvas tool implementations over [`@calca/canvas-base`](../canvas-base), protocol types, and the single-source tool contract that generates MCP tool JSON Schemas and docs.
