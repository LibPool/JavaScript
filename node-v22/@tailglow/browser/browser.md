# @tailglow/browser

> 标签: analytics, browser, observability, rum, tailglow, telemetry

## 简介

Browser SDK for Tailglow. Auto-collects page views, errors, vitals, and section engagement. Cookie-free by default.

## 官网

- 官网：https://docs.tailglow.io
