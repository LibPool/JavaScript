# @getbourdon/fs-lock

> 标签: JavaScript

## 简介

Bourdon OS file-lock primitive: an exclusive, nonblocking lock on a persistent sidecar file (flock on POSIX, LockFileEx on Windows) that interoperates with the Python engine's federation locks. A small Node-API addon shipped as sha256-verified prebuilt bi
