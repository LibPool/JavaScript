# @getbourdon/inference

> 标签: JavaScript

## 简介

Bourdon inference layer — the backend-neutral InferenceBackend protocol (llama.cpp / Ollama / vLLM), the llama SSE backend, L2 episodic retrieval, and the codex/cursor turn compilers. Python (pip install bourdon) is the oracle.
