# @jiihpeeh/is-animated

> 标签: animated, animation, apng, avif, detect, gif, image, is-animated, jxl, webp

## 简介

Detect whether an image (WebP, AVIF, APNG, GIF, JXL) is animated by inspecting its binary header.
