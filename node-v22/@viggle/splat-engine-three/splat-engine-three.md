# @viggle/splat-engine-three

> 标签: JavaScript

## 简介

Gaussian-splat character engine for three.js: load .vsplat character bundles, skin them to a rig, play skeletal animation. A three.js port of @viggle/splat-engine with no PlayCanvas dependency.
