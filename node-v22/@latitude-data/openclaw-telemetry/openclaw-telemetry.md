# @latitude-data/openclaw-telemetry

> 标签: latitude, observability, openclaw, opentelemetry, otlp, telemetry

## 简介

OpenClaw plugin that streams agent runs to Latitude as OTLP traces: model calls with usage and cost, tool calls and definitions, memory, subagents, cron runs, and user identity
