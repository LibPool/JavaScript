# @mongodb-js/atlas-local

> 标签: N-API, NAPI, Rust, napi-rs, node-addon, node-addon-api

## 简介

A Node.js library for managing MongoDB Atlas Local deployments using Docker. This library provides a high-level JavaScript/TypeScript interface to interact with MongoDB Atlas Local deployments, making it easy to develop and test applications against a loc
