# @uwmd/lake

> 标签: commercial-real-estate, data-lake, jsonb, postgresql, underwriting, uwmd

## 简介

Reference PostgreSQL/JSONB lake adapter for UW Markdown (RFC 0049) — plans idempotent, parameterized load statements for canonical envelopes, block-value facts, receipts and package manifests without taking a database driver as a dependency.
