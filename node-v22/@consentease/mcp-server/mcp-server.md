> 标签: ai-agents, ccpa, cmp, consent, consent-management, consentease, cookie-banner, cookie-consent, gdpr, mcp, model-context-protocol, privacy

## 简介

MCP server for the ConsentEase Connect API — a thin client over the /api/v1 REST surface that lets coding agents manage consent banners and cookie inventories.
