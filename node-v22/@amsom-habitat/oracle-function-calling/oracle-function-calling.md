# @amsom-habitat/oracle-function-calling

> 标签: amsom, blob, clob, nestjs, oracle, oracledb, plsql, stored-procedures

## 简介

Appel de fonctions stockées Oracle depuis Node : binds natifs (dont CLOB/BLOB), lecture du retour et traduction des erreurs ORA (portage Node du package PHP amsom-habitat/oracle-function-calling).
