# @amsom-habitat/mailer-sender

> 标签: amsom, api-mail, mail, mailer, nestjs

## 简介

Connecteur vers l'API Mail interne : envoi par template ou en corps libre, avec garde-fou anti-spam hors production (portage Node du package PHP amsom-habitat/mailer-sender).
