# env-worktree-sync

> 标签: 1password, ai-agent, bootstrap-env, claude-code, cli, coding-agent, cursor, dev-setup, doppler, dotenv, dotenv-cli, ensure-env, env, env-file, env-setup, env-worktree-sync, git-worktree, git-worktrees, infisical, monorepo, pnpm, postinstall, prepare, secret-management, secrets, symlink, vault, worktree

## 简介

Ensure a .env file exists: skip if present, symlink it from the main repo inside git worktrees, otherwise generate it with your secret manager command (Doppler, 1Password, Infisical, Vault).
