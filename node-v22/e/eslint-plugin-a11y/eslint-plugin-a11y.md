# eslint-plugin-a11y

> 标签: a11y, accessibility, accessibility-checker, accessibility-linter, accessibility-testing, aria, eslint, eslint v9, eslint-config, eslint-flat-config, eslint-plugin, flat config, jsx, jsx-a11y, nextjs, react, screen-reader, semantic-html, typescript, vue, wcag, wcag-compliance, web-accessibility

## 简介

ESLint accessibility (a11y) plugin for React, Vue, and JSX, supporting both classic .eslintrc (ESLint 8+) and flat config (ESLint v9+), with a matching runtime A11yChecker API. Alternative to eslint-plugin-jsx-a11y for modern design systems.
