# eclaude

> 标签: claude, claude-code, cli, conpty, napi, pty, repl, send-keys

## 简介

Drive a live, interactive Claude Code session from outside: host Claude in a pseudo-terminal and inject REPL/slash commands (e.g. /clear) with `eclaude send`.
