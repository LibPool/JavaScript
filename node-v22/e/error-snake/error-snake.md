# error-snake

> 标签: JavaScript

## 简介

Uma biblioteca TypeScript para padronização, enriquecimento e serialização de erros em aplicações Node.js/TypeScript. Permite criar erros customizados, registrar logs detalhados e converter objetos para snake_case de forma segura, facilitando integração c
