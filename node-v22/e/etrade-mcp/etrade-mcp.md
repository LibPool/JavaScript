# etrade-mcp

> 标签: broker, etrade, mcp, model-context-protocol, oauth, trading

## 简介

MCP server for the E*TRADE Account + Order APIs: account reads always-on, order placement opt-in via ETRADE_ALLOW_ORDERS=1.
