# echarts-worker

> 标签: JavaScript

## 简介

This package allows you to run your [Apache ECharts](https://echarts.apache.org/) instance inside a [web worker](https://developer.mozilla.org/en-US/docs/Web/API/Web_Workers_API/Using_web_workers).
