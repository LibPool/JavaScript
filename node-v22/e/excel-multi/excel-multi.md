# excel-multi

> 标签: excel, xls, xlsx

## 简介

Web and node.js spreadsheet library. Supports xlsx, csv, tsv (or any simple delimited file) for now.

- 官网：https://github.com/northwind/excel.js
- 源码仓库：https://github.com/northwind/excel.js
