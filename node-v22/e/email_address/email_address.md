# email_address

> 标签: address, compare, email, emailaddress, internationalization, match, parse, smtputf8, validate

## 简介

A Javascript language library for validating and working with Email Addresses. By default, it validates against a "conventional" subset of the RFC specification which consitute user email addresses.
