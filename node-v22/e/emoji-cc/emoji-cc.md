# emoji-cc

> 标签: Emoji One, emoji, emoji set, emojione, emojis, emoticons, smileys, smilies, unicode

## 简介

Complete set of emojis designed for the web. It includes JSON to help convert unicode characters to shortnames (:smile:) and shortnames to our custom emoji images. SVG formats provided for the emoji images.
