# email-imap-mcp

> 标签: connector, email, imap, mailbox, mcp, readonly-by-default, smtp, workbuddy

## 简介

IMAP + SMTP email connector for WorkBuddy. Read-only by default (list mailboxes, search by date window, read message text); sending, drafts, moving, marking read and deletion are opt-in per permission switch. Deletion always moves to Trash — permanent del
