# enterprise-agent-designer

> 标签: agent, enterprise-agent-designer, skill-md, skills, workbuddy

## 简介

企业 Agent 设计师 v0.35.0：面向业务负责人、领域专家和产品人员的 Agent 设计与评审专家。从一句工作需求或既有材料出发，形成岗位假设、比较候选、识别知识／Tool／权限／运行依赖，并把成立的设计编译成可供平台适配的独立源码。
