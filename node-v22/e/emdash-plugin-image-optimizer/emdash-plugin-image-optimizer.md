# emdash-plugin-image-optimizer

> 标签: avif, cms, emdash, emdash-plugin, image, media, optimization, webp

## 简介

EmDash plugin that converts uploaded JPEG/PNG images to WebP or AVIF, keeping the originals. Converts on upload and in bulk.
