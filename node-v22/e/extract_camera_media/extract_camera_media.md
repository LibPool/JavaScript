# extract_camera_media

> 标签: JavaScript

## 简介

一个通用的相机媒体提取脚本：遍历相机媒体目录，保持目录结构把媒体文件处理到目标目录中。照片原样拷贝，视频压缩转码（默认转码为 H.265）。
