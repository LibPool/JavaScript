# expo-assistant-functions

> 标签: ai, android, app-functions, app-intents, appfunctions, assistant, expo, gemini, ios, react-native, shortcuts, siri

## 简介

Expo module for Assistant Functions — exposes in-app functions to Android App Functions (Gemini, Google Assistant) and iOS App Intents (Siri, Shortcuts).
