# express-idempotency-keys

> 标签: api, exactly-once, express, idempotency, idempotency-key, middleware, mongodb, payments, redis, retry

## 简介

Stripe-style idempotency keys for Express. Safe retries for POST/PATCH/PUT/DELETE, with correct behaviour under concurrency. Zero dependencies.
