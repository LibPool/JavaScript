# eslint-plugin-design-tokens

> 标签: ant-design, antd, border-radius, borders, colors, css-in-js, css-variables, custom-properties, design-system, design-tokens, emotion, eslint, eslint-plugin, eslintplugin, hardcoded-borders, hardcoded-colors, hardcoded-radius, hardcoded-shadows, hardcoded-spacing, hardcoded-transitions, hardcoded-typography, hardcoded-z-index, jsx, lint, linter, material-ui, mui, shadows, spacing, styled-components, sx, theme, theming, transitions, typescript, typography, z-index

## 简介

ESLint rules that catch hardcoded colors, spacing, typography, shadows, radii, borders, transitions and z-index in sx/style/css props and styled-components, so design tokens stay the only source of truth.
