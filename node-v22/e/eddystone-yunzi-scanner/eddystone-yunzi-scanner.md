# eddystone-yunzi-scanner

> 标签: Beacon, Eddystone, Physical Web, Sensoro, Websocket, Yunzi

## 简介

Scan for Eddystone Yunzi beacon's using Node.js. It returns motion, light, temperature and other parameters and transmit them via websocket
