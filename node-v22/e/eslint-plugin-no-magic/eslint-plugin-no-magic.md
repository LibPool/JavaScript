# eslint-plugin-no-magic

> 标签: eslint, eslint-plugin, eslintplugin, magic-numbers, magic-strings, no-magic-strings

## 简介

ESLint rule that flags magic string literals only in suspicious contexts (comparisons, switch cases, action types, analytics/storage/feature-flag/route sinks) and on duplication, instead of reporting every literal.
