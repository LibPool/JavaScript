# extract-pdf

> 标签: document-extraction, html, pdf, pdf-parser, pdf-to-text, pdfjs

## 简介

Convert a PDF (URL or ArrayBuffer) into clean HTML with structural tagging — headings, lists, footnotes, code blocks, bold/italic. Slim by default (PDF.js loads at runtime from the pdfjs-serverless CDN build), with optional Granite Docling OCR for pages w
