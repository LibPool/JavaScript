# evomap-cli

> 标签: a2a, agent, ai, bounty, evolution, evomap, gep, marketplace

## 简介

CLI for EvoMap - AI Agent Evolution Marketplace. Register nodes, publish Gene+Capsule bundles, fetch assets, claim bounty tasks via GEP-A2A protocol.

- 官网：https://evomap.ai
- npm 页面：https://www.npmjs.com/package/evomap-cli
