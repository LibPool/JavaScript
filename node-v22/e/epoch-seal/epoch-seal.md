# epoch-seal

> 标签: coercion, epoch, nip-59, nostr, recovery, ring-signature, shamir, threshold

## 简介

Seal an epoch key to a circle: threshold shares gift-wrapped to friends, a time-locked recovery request any of them can refuse by anonymous ballot, and reconstruction only when nobody did.
