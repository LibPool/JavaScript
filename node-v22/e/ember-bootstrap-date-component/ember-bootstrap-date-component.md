# ember-bootstrap-date-component

> 标签: bootstrap, bootstrap-datepicker, datepicker, ember-addon, ember-cli, ember-datepicker

## 简介

Datepicker component for Ember CLI based on bootstrap-datepicker. It is forked from soulim. It doesn't have any external dependency except bootstrap-datepicker, supports popup and inline modes.
