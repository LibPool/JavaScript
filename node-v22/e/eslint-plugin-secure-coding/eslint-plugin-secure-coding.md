# eslint-plugin-secure-coding

> 标签: ai-assistant, appsec, authentication, authorization, auto-fix, code-quality, cwe, deserialization, eslint, eslint-plugin, eslintplugin, graphql-injection, hardcoded-credentials, injection, interlace-security, ldap-injection, linting, llm-optimized, nodesecurity, object-injection, owasp, owasp-top-10, pii, redos, sast, secure-coding, security, static-analysis, template-injection, typescript, vulnerability, xpath-injection, xxe

## 简介

ESLint plugin for secure coding — detects LDAP, XPath, XXE, GraphQL and template injection, unsafe deserialization, ReDoS, missing authentication, and PII in logs.
