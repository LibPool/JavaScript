# errisy-tsc

> 标签: compiler/transpiler, typescript

## 简介

a customized typescript compiler that transpile *.rpc.ts to *.client.ts for front end consumption and *.data.ts to *.sys.ts for typed MongoDB access. *.rpc.ts can be also transpiled to C# file for .net front ends.
