# ember-cli-deploy-fastboot-s3

> 标签: ember-addon, ember-cli-deploy-fastboot-s3, ember-cli-deploy-plugin, ember-cli-fastboot

## 简介

An ember-cli-deploy plugin that archives and uploads FastBoot build to AWS S3.
