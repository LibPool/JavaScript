# ember-timezone-js

> 标签: ember-addon, ember-timezone-js, timezone-js

## 简介

This is an ember-cli ES6 module shim for timezone-js within your Ember application.

## 官网

- npm 页面：https://www.npmjs.com/package/ember-timezone-js

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- npm 安装：`npm install ember-timezone-js`
- npm registry：https://registry.npmjs.org/ember-timezone-js
- Node 要求：6.* || 8.* || >= 10.*
