# ephemeral-cloud-mcp

> 标签: agents, base, mcp, model-context-protocol, polling, usdc, watch, webhooks, x402

## 简介

MCP server for Ephemeral Cloud: temporary webhooks, URL watches and delayed callbacks for AI agents, paid per use with x402 (USDC on Base). No accounts, no API keys.
