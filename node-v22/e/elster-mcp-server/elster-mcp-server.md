# elster-mcp-server

> 标签: claude, elster, est, euer, finanzamt, germany, mcp, model-context-protocol, puppeteer, steuer, tax, ustva

## 简介

Model Context Protocol (MCP) server for ELSTER (German tax portal) automation via Puppeteer. Submit UStVA, prepare EUER/ESt, sync inbox and history.
