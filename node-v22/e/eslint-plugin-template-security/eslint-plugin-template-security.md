## 简介

ESLint security rules for template bindings, written once for JSX, Astro, Vue, Svelte, HTML and server templates (Jinja, Django, Twig, Blade, ERB, EJS, PHP, JSP), with htmx and Alpine: unsafe HTML sinks, unescaped output, script breakout, javascript: URLs
