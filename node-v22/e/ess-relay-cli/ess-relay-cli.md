# ess-relay-cli

> 标签: JavaScript

## 简介

`apps/relay` 目录既是 Relay Web 服务，也是 npm 发布包 `ess-relay-cli` 的根目录。 安装后提供全局命令 `ess-relay`。

## 官网

- npm 页面：https://www.npmjs.com/package/ess-relay-cli

## 获取地址

- npm registry：https://registry.npmjs.org/ess-relay-cli
- Node 要求：>=22
