# each-promise

> 标签: aftereach, async, asyncawait, await, bail, beforeeach, concurrency, concurrently, each, eachlimit, eachof, eachofseries, eachseries, failfast, finish, fun, hook, hooks, hooksystem, iterate, iteration, iterator, limit, map, mapper, mapseries, parallel, prom, promise, promises, serial, serially, series, settle, start

## 简介

Iterate over promises, promise-returning or async/await functions in series or parallel. Support settle (fail-fast), concurrency (limiting) and hooks system (start, beforeEach, afterEach, finish)
