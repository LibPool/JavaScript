# expo-live-stream

> 标签: camera, expo, haishinkit, live-stream, player, publisher, react-native, rootencoder, rtmp, streaming, vlc

## 简介

RTMP live stream publisher & player for React Native (Expo). Uses HaishinKit + VLC (iOS) and RootEncoder + VLC (Android).
