# email-templates-v2

> 标签: css, ejs, email, email-templates, html template, inline, juice, node-email-templates, subject template, templates, text template, v2, windows

## 简介

Node.js module for rendering beautiful emails with ejs, jade, swig, hbs, or handlebars templates and email-friendly inline CSS using juice.
