# expo-google-credential-auth

> 标签: android, authentication, credential-manager, expo, expo-module, google, google-sign-in, google-signin, googlesignin, id-token, ios, oauth, react-native

## 简介

Sign in with Google for Expo / React Native on Android and iOS — Android's modern Credential Manager API and the iOS GoogleSignIn SDK. Returns an ID token via a one-tap / account-picker flow, with a separate authorization flow for OAuth access tokens.
