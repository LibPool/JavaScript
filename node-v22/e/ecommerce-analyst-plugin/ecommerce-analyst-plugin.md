# ecommerce-analyst-plugin

> 标签: JavaScript

## 简介

dsh 电商商单智能体插件：商品管理 / 订单处理 / 销售数据分析 / 库存预警（含桌面端「电商数据中台」与 Excel 月/周复盘导入）。v0.4.5：数据对比柱线合一图（每月分色+环比折线、KPI 锚定最近导入月、多月份全对比而其余面板只显示最近导入月）；统一空数据治理根治清除后销售概览图表/排行残留；对比按键交互修复；CSV 导出含复盘报表
