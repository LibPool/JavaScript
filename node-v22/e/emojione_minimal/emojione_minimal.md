# emojione_minimal

> 标签: Emoji One, emoji, emoji set, emojione, emojis, emoticons, smileys, smilies, unicode

## 简介

This is a minimal publishing fork of Emoji one. Emoji One is a complete set of emojis designed for the web. It includes libraries to easily convert unicode characters to shortnames (:smile:) and shortnames to our custom emoji images. PNG and SVG formats p
