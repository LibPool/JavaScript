# ex-generic-component-library

> 标签: JavaScript

## 简介

Generic component that can be useful to any react project. Creating component for Button, Search Input, Form Input Controllers, Modal Side Navigation Panel, Breadcrums, Menu Bar, Toast Messages, Toggle Switch, Progress Bar, Slider, Accordian, Date Picker,
