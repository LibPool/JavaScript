# eslint-plugin-i18n-leak

> 标签: eslint, eslint-plugin, eslintplugin, i18n, internationalization, jsx, l10n, localization, react

## 简介

Find the i18n bugs that have no string literal to scan: browser-rendered validation messages and raw backend error text.
