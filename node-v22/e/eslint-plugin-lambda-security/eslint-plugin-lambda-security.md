# eslint-plugin-lambda-security

> 标签: ai-assistant, api-gateway, appsec, aws, aws-lambda, aws-security, code-quality, cors, cwe, eslint, eslint-plugin, eslintplugin, iam, interlace-security, lambda, linting, llm-optimized, middy, node, nodejs, owasp, sast, secrets, security, security-headers, serverless, serverless-security, static-analysis, typescript, validation, vulnerability

## 简介

ESLint plugin for AWS Lambda security — detects overly permissive IAM policies and CORS, unvalidated event bodies, secrets in env vars, and leaked error details.
