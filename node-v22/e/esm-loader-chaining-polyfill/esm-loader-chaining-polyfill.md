# esm-loader-chaining-polyfill

> 标签: ecmascript, es, es-modules, esm, esm-loader

## 简介

A Node.js polyfill of @devsnek's "esm: loader chaining" proposal for chaining several cooperative experimental EcmaScript module loaders.

- 源码仓库：https://github.com/concision/esm-loader-chaining-polyfill.git
- npm 页面：https://www.npmjs.com/package/esm-loader-chaining-polyfill
