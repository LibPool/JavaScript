# ekmp-algolia

> 标签: JavaScript

## 简介

Static Content Generator. Pure HTML template engine base on markdown files, syntax from Jinja2. Built for official website, Blog and WIKI, and so on.  Please to visit [Everkm Publish](https://publish.everkm.com) for more details。
