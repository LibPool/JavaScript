# effect-once

> 标签: at-least-once, cron, deduplication, exactly-once, idempotency, idempotent, lock, retry, scheduler, side-effect

## 简介

Run a side effect at most once per key — crash-safe idempotency for at-least-once schedulers (cron supervisors, queue redelivery, lambda retries).
