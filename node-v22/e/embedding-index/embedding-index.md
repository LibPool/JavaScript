# embedding-index

> 标签: binary-quantization, cosine-similarity, embeddings, hamming, local-first, rag, semantic-search, similarity-search, top-k, vector-search, zero-dependency

## 简介

Fast top-k search over embeddings in pure JavaScript. One bit per dimension for the scan, full precision for the answer. Zero dependencies, no WASM, no native build.
