# entrega12

> 标签: JavaScript

## 简介

Esta entrega consiste na criação de uma pequena biblioteca em TypeScript que lidará com a busca e tratamento das informações de cotação e conversão das moedas utilizando a api [CoinMarketCap](https://coinmarketcap.com/api/).
