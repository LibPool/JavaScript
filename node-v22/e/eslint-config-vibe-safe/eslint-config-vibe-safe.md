# eslint-config-vibe-safe

> 标签: ai, copilot, cursor, eslint, eslint-config, eslintconfig, nextjs, security, supabase, vibe-coding

## 简介

ESLint rules for the mistakes AI coding assistants make in Next.js and Supabase apps: unverified sessions, unvalidated environment config, string execution. Zero dependencies.
