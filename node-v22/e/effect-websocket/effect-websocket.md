# effect-websocket

> 标签: browser, bun, client, cross-platform, effect, effect-ts, functional-programming, monorepo, node, real-time, reconnection, rpc, server, streaming, websocket

## 简介

Runtime-agnostic WebSocket library for Effect-TS with client/server support, automatic reconnection, and cross-platform compatibility (Node.js, Bun, Browser)
