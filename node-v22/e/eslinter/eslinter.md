# eslinter

> 标签: check, code, code validation, eslint, file glob, glob, javascript, jshint alternative, jsx eslint, jsx lint, lint, validate code

## 简介

Simple wrapper around eslint with support for globs and cache, so files that not changed can be skipped, if previous run passed
