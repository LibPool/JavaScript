# emailgrab

> 标签: email, next-js, react, signup, supabase

## 简介

Have you wanted to have an email sign-up sheet on your next-js website? Well, this package lets you do exactly that! You can style the component with tailwind css and you just need to add your supabase env keys and the rest will be done for you!
