# emdash-admin-theme-classic

> 标签: admin, admin-theme, emdash, emdash-admin-theme, emdash-cms, wordpress, wp-admin

## 简介

wp-admin look for the EmDash CMS admin panel. Two layers: design tokens on their own, or tokens plus geometry. CSS only, no core patching.
