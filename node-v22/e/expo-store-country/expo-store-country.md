# expo-store-country

> 标签: android, app-store, billing, country, expo, expo-modules, in-app-purchase, ios, iso-3166, play-store, react-native, storefront, storekit

## 简介

Expo module that returns the active App Store storefront or Play Store billing country as a lowercase ISO 3166-1 alpha-2 code.
