# expo-lux-sensor

> 标签: ExpoLuxSensor, ambient-light, android, camera, expo, expo-lux-sensor, illuminance-measurement, ios, light-sensor, lux, lux-meter, react-native, sensor

## 简介

A native Expo module for ambient light (lux) measurements. Uses hardware light sensor on Android (with camera fallback) and camera-based estimation on iOS.
