# element-api-docs

> 标签: api-docs, element-ui, swagger2, vue

## 简介

本项目是一个基于element-ui，swagger2的快速接口测试工具。其实swagger-ui已经可以满足接口测试的场景，但是我们项目要求接口参数加密，这就导致了swagger-ui无法使用，所以诞生了此项目。<br> 另外，直接使用本项目可能会存在跨域的问题，请在后台设置测试环境下允许跨域。（正式环境请禁用swagger2）
