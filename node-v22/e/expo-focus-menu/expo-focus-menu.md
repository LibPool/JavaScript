> 标签: ExpoFocusMenu, context-menu, emoji-reactions, expo, expo-focus-menu, haptic-feedback, ios, menu, native-menu, react-native, sf-symbols, uicontextmenu

## 简介

Native iOS context menus with haptic feedback, React component icons, and interactive emoji reactions for React Native. Provides an elegant focus menu UI component for Expo and React Native apps.
