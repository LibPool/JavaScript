# electron-theme-mode

> 标签: dark-mode, dark-reader, darkreader, electron, electron-plugin, theme

## 简介

开箱即用的 Electron 暗黑模式支持，整合 DarkReader 与 Electron 生态，提供亮色/暗色/跟随系统三模切换。
