# easy-peasy-mcp

> 标签: asyncapi, documentation, llms-txt, mcp, openapi

## 简介

Lightweight zero-config MCP server. Give it an llms-full.txt (path or URL) and optional OpenAPI/AsyncAPI dirs — it registers the right tools automatically.
