# express-model

> 标签: JavaScript

## 简介

为Express框架提供Model支持，可集成多种数据库(SQL & NoSQL)，灵活性高的轻量级工具。 由于Express官方并未显式地提供Model支持，express-model不仅能有效嵌入Express Mvc中，还支持多种需要Model的场景
