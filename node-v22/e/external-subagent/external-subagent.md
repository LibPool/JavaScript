# external-subagent

> 标签: agent-tasks, codex, dsh, mcp, subagent, zcode

## 简介

Manage bounded ZCode, DeepSeek Harness (DSH), and Codex subagent tasks through a local MCP service for any local host (Codex, ZCode, or a custom MCP client)
