# eslint-plugin-hootlens

> 标签: eslint, eslint-plugin, eslintplugin, hoot-lens, hootlens, session-replay

## 简介

ESLint rules that teach coding agents and developers the Hoot Lens conventions: stable ids, page versions, private regions, dynamic content and consent.
