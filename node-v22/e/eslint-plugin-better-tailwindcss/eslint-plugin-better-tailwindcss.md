# eslint-plugin-better-tailwindcss

> 标签: astro, break, eslint, eslint-plugin, formatting, horizontal, html, jsx, line, linebreak, literal, multi, multiline, newline, qwik, react, readability, readable, scrolling, solid, stylistic, svelte, tailwind, tailwind-classes, tailwind-css, tailwindcss, template, template-literal, template-literals, vue, wrap

## 简介

auto-wraps tailwind classes after a certain print width or class count into multiple lines to improve readability.
