# emic-bus

> 标签: JavaScript

## 简介

EMICBus V2 desde Node: COBS, CRC, tramas, Intel HEX PIC24, cliente del programador V2 y transporte serie hacia la pasarela V3. Port byte a byte del JS del editor (verificado en hardware).
