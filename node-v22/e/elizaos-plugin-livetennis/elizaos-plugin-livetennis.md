> 标签: atp, elizaos, elizaos-plugin, fixtures, live-scores, plugin, rankings, sports, sports-api, sports-data, tennis, tennis-api, wta

## 简介

Live tennis scores, upcoming fixtures, and player search for elizaOS agents via the Live Tennis API — ATP, WTA, Challenger, ITF and juniors. FREE-tier endpoints only, with honest per-action tier errors.
