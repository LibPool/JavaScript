# eslint-plugin-supabase

> 标签: eslint, eslint-plugin, eslintplugin, postgres, realtime, rls, supabase, supabase-js, typescript

## 简介

ESLint rules for Supabase projects: unsent query builders, missing realtime subscribe status handlers, unpublished realtime tables, and RLS or grant mismatches.
