# eth-monitoring

> 标签: JavaScript

## 简介

此项目旨在监控以太坊钱包的余额，并在余额增加时立即提供通知。这在某些情况下特别有用，例如钱包的私钥已经被泄露，但攻击者并未持续监控钱包的活动。
