# easy-storage-browser

> 标签: cookie, localStorage, sessionStorage

## 简介

简化浏览器 localStorage、sessionStorage、cookie 存储方式，自动做 JSON.parse、JSON.stringify 且保证存储前后数据类型一致，支持私有化存储，定时存储。
