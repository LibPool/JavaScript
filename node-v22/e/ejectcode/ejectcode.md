# ejectcode

> 标签: JavaScript

## 简介

Node commandline application to make review version of your Frontend project: obfuscate your code for browser view and errorify it for code quality review.

## 官网

- 源码仓库：https://bitbucket.org/tangofrontteam/ejectcodejs
