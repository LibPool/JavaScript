# express-error-toolkit

> 标签: async-handler, custom-errors, error-handling, express, middleware, typescript

## 简介

A lightweight and developer-friendly toolkit for robust error handling in Express.js applications.
Includes ready-to-use custom error classes, an async route error handler wrapper, a global error handler middleware, and a convenient 'not found' route hand
