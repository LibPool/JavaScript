# ember-cli-dimple

> 标签: ember-addon

## 简介

This addon provides an entrypoint for using [PMSI-AlignAlytics/dimple](https://github.com/pmsi-alignalytics/dimple/) with your [ember-cli](https://github.com/stefanpenner/ember-cli) project.
