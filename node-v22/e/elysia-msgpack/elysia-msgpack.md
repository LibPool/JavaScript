# elysia-msgpack

> 标签: binary, bun, decode, deserialize, elysia, encode, json, messagepack, msgpack, pack, perfomance, serialize, unpack

## 简介

The library for elysia which allows you to work with MessagePack. To pack/unpack it, we use really fast msgpackr
