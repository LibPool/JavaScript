# espressivo

> 标签: expressive-performance, mei, meico, midi, mpm, msm, music-encoding, music-performance

## 简介

MEI / MSM+MPM => expressive MIDI. An idiomatic TypeScript port of the Java meico library, proven equivalent to it.
