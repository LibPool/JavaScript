# export-ton-verifier

> 标签: circuit, func, groth16, knowledge, plonk, tact, tolk, ton, zero, zksnark

## 简介

Tool for generating Groth16 and PLONK verifier code for the TON blockchain from SnarkJS .zkey or verification key JSON files.
