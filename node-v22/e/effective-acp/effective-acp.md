# effective-acp

> 标签: acp, agent, agent-client-protocol, effect, json-rpc

## 简介

The Agent Client Protocol on Effect: schemas generated from the SDK's JSON Schemas, a two-way JSON-RPC peer, the agent and client ends, stdio and Streamable HTTP.
