# expo-and-native-starter-kit

> 标签: expo-and-native-kit, expo-kit, expo-starter-kit, react-native-starter-kit, starter-kit

## 简介

This is the ejected expo kit which lets you run expo and native code from the same codebase. You can utilize what expo has to offer without compromising the native module and bridge features of react-native.
