# expo-sugiyama

> 标签: dag, expo, graph, hierarchical, layout, react-native, sugiyama

## 简介

High-performance native hierarchical (Sugiyama) graph layout computation for React Native. Computes layering, ordering, and coordinate assignment entirely in native code, off the JS thread.
