# enumconsts

> 标签: codes, constants, consts, dlopen, enoent, enum, errno, error-codes, error-constants, errors, priority, signals, types

## 简介

Node.js constants (ERRNO, SIGNALS, DLOPEN, PRIORITY) as javascript enums (frozen objects). Typescript types included.
