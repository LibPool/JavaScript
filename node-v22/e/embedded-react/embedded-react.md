# embedded-react

> 标签: aot, embedded, esp32, gui, jsx, mcu, microcontroller, quickjs, react, react-native, stm32, ui

## 简介

React Native-style component package + reconciler that drives the embedded-react C engine through the QuickJS NativeUI bridge (Flow A).
