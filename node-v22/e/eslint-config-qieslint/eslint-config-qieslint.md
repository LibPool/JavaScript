# eslint-config-qieslint

> 标签: JavaScript

## 简介

用法 1、npm 下载 npm i eslint-config-qieslint 2、在 .eslintrc 文件中添加代码 { "extends": "qieslint", // 你的规则（覆盖） "rules": {} }
