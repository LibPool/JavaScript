# eslint-plugin-gameface-tailwind

> 标签: coherent-labs, coherent-ui, css-compatibility, css-validation, eslint, eslint-plugin, frontend-gaming, game-development, gameface, gameface-css, gaming, html5-gaming, linting, tailwind, tailwindcss, ui-framework, web-components

## 简介

An ESLint plugin that validates Tailwind CSS classes and inline CSS styles files against [Coherent Labs Gameface Framework](https://docs.coherent-labs.com/cpp-gameface/) compatibility.
