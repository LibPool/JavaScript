# edge-compat-check

> 标签: ci, cli, cloudflare-workers, compatibility-checker, dependency-scanner, edge-compatibility, edge-functions, edge-runtime, fastly-compute, middleware, netlify-edge, nextjs, node-api, node-compatibility, nodejs, serverless, static-analysis, vercel-edge, wintercg

## 简介

Static-analysis dependency scanner for edge runtime compatibility — scans your Node.js dependencies for Node.js APIs that break on Vercel Edge, Cloudflare Workers, Netlify Edge, and Fastly Compute, using per-target profiles you can run locally or as a CI
