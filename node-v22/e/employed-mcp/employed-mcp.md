# employed-mcp

> 标签: ats, cli, employed, guaq, job-search, jobs, mcp, model-context-protocol

## 简介

MCP server + CLI for Employed by Guaq AI (jobs.guaqai.me) - thin Node launcher around the stdlib-only Python client, so `npx employed-mcp` works with no manual download.

## 官网

- 官网：https://jobs.guaqai.me/docs
- 源码仓库：git+https://github.com/buddywhitman/resume-cv.git
