# eslint-plugin-use-client

> 标签: eslint, eslint-plugin, eslintplugin, next, react, react-server-components, rsc, use client

## 简介

ESLint rule that enforces the 'use client' directive in files using client-only React features (hooks, use(), createContext, browser APIs, event handlers).
