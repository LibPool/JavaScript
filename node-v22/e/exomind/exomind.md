# exomind

> 标签: cli, cross-platform, exomind, knowledge-base, mcp-alternative

## 简介

ExoMind 跨平台命令行客户端 — 通过 REST 与 ExoMind 知识飞轮交互(ingest/query/search/review),替代 Windows 不可用的 MCP 客户端。
