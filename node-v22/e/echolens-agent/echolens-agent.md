# echolens-agent

> 标签: JavaScript

## 简介

一个从零开始、模型中立的本地代码 Agent。v0.7 加固了持久队列、可恢复会话和 Worktree 子 Agent，并通过更严格的 TypeScript 门禁收敛运行时实现。
