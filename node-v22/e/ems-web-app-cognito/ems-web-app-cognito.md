# ems-web-app-cognito

> 标签: angular, angular.io, auth, authentication, aws, cognito, educational, educational media solutions, ems, media, module, password, solutions, username, web app, web application

## 简介

This angular.io module includes a component, service and supporting classes that wrap the Amazon Cognito Identity SDK to enable simple username/password authentication.
