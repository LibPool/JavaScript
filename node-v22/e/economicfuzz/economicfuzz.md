# economicfuzz

> 标签: anchor, attack-simulation, audit, defi, flash-loan, fuzzer, mev, oracle, security, solana

## 简介

Economic attack simulation framework for Solana DeFi — oracle manipulation, flash loans, MEV sandwiches, governance griefing. Runs YAML scenarios + genetic-fuzz parameter search, exits non-zero on invariant breach.
