# eslint-plugin-no-interpolation-spacing

> 标签: angular, angular interpolation eslint, angular template eslint, eslint, eslint plugin, html, interpolation, lint, spacing

## 简介

An ESLint plugin to enforce no spacing between Angular-style interpolations and HTML elements.
