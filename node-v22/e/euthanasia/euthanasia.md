# euthanasia

> 标签: cpu, graceful-exit, graceful-shutdown, high-cpu, memory, nodejs, oom, out-of-memory, process-exit, resource-limits, resource-monitoring, self-terminate, watchdog

## 简介

Gracefully exits a Node.js process when memory or CPU usage exceeds defined thresholds. Supports customizable exit logic via async hooks.
