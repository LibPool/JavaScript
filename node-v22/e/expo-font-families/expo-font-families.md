# expo-font-families

> 标签: custom-fonts, expo, expo-config-plugin, expo-font, font-families, font-family, font-weight, fontWeight, fonts, google-fonts, react-native, typography

## 简介

One font name, every weight, both platforms. Make your expo-font fonts behave like the system font, with a typed style for every face.
