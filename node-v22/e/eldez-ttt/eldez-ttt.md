# eldez-ttt

> 标签: Project, TEA, Tac, Testnet, Tic, Toe

## 简介

Welcome to Tic Tac Toe Sci-Fi Edition! This is a simple web-based game of Tic Tac Toe with a futuristic twist. The game is built using HTML, CSS, and JavaScript, and features a sci-fi inspired design.
