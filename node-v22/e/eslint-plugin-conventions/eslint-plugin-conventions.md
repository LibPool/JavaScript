# eslint-plugin-conventions

> 标签: ai-assistant, clean-code, code-quality, code-style, consistency, conventions, deprecation, eslint, eslint-plugin, eslintplugin, filename-case, interlace-quality, linting, llm-optimized, magic-numbers, naming-conventions, static-analysis, todo-comments, typescript

## 简介

ESLint plugin for team code conventions — enforces filename case, magic-number bans, commented-out code, expiring TODOs, and deprecated-API usage.
