# es6-module-clean-transpilation

> 标签: amd, commonjs, es6, module, transpile

## 简介

es6-module-clean-transpilation is an experimental compiler that allows you to write your JavaScript using a subset of the current ES6 module syntax, and compile it into clean AMD, CommonJS, UMD and globals styles.
