# eslint-plugin-css-property-order

> 标签: css, declaration-order, devtools, eslint, eslint-plugin, eslintplugin, properties-order, property-order, recess, stylelint-order

## 简介

ESLint plugin enforcing CSS declaration order for @eslint/css: Recess/Bootstrap logical order, Chrome DevTools panel order, or your own.
