# electron-frameless-window-plugin

> 标签: double-click-titlebar, electron, isMaximized, maximize, right-click-titlebar, transparent, transparent-maximize, transparent-window

## 简介

Fix the problems about electron frameless and transparent window, such as using maximize() can not emit 'maximize' event.
