# express-cdn-cloudfiles

> 标签: cdn, cloud, cloudfiles, express-cdn-cloudfiles, rackspace

## 简介

Add-on module for express-cdn to provide Rackspace CloudFiles integration with built-in Akamai CDN delivery.
