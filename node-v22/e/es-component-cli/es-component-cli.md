# es-component-cli

> 标签: JavaScript

## 简介

`easy-component-cli`是一个解决<b>重复写组件代码</b>问题的命令行工具。把日常常用的组件加入到配置文件里，通过简单的命令就可以自动插入代码到目标文件中。
