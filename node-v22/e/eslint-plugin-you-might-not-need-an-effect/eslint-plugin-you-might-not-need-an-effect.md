# eslint-plugin-you-might-not-need-an-effect

> 标签: eslint, eslintplugin, hooks, react, useeffect

## 简介

A small ESLint plugin that flags common useEffect patterns React recommends replacing with render logic, better state structure, keys, or event handlers.
