# easy-dev-cli

> 标签: JavaScript

## 简介

- 功能: 支持下载模板 `create` 命令 - 全局命令可使用 `cl` - 该脚手架包含Vue2普通模板、Vue2 qiankun主应用模板、Vue2 qiankun子应用模板、Vue3模板

## 官网
