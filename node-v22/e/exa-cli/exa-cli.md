# exa-cli

> 标签: JavaScript

## 简介

Simple agent-first CLI wrapper around the [Exa Search API](https://docs.exa.ai/reference/getting-started) (not to be confused with the [exa](https://github.com/ogham/exa) terminal replacement for `ls`).
