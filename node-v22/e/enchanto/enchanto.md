# enchanto

> 标签: HammerTail, React, Text Editor, Typescript, WYSIWYG

## 简介

This is the repository for the Enchanto text editor. It is a simple text editor written in Typescript specifically tailored for the HammerTail. It is a work in progress and is not yet ready for use.
