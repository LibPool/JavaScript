# eslint-plugin-type-narrower

> 标签: eslint, eslint-plugin, eslintplugin, static-analysis, typescript, union-types

## 简介

ESLint plugin surfacing type-narrower findings: function parameters whose declared union types are wider than anything the call sites actually pass.
