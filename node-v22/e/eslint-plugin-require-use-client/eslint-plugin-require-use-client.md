# eslint-plugin-require-use-client

> 标签: app-router, autofix, client-components, directive, eslint, eslint-plugin, eslint-rule, next, nextjs, nextjs-app-router, react, react-server-components, rsc, use client, use-client

## 简介

Enforce the "use client" directive (with a blank line) in Next.js/React client components; remove it in utility/type files. With autofix.
