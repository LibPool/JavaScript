# eslint-plugin-i18n-unused

> 标签: eslint, eslint-plugin, eslintplugin, i18n, internationalization, intlify, locale, translations, unused, unused-keys, vue-i18n

## 简介

Fast ESLint rule reporting unused i18n locale keys. Drop-in replacement for @intlify/vue-i18n/no-unused-keys, without the per-file AST parse.
