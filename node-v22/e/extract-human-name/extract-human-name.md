# extract-human-name

> 标签: apa, author, byline, citation, human-name, metadata, name-parsing, organization-detection

## 简介

Extracts, characterizes, and structures human author names from arbitrary text: tells a person ("Dr. John Doe") from an organization ("The New York Times"), parses name parts (title, first, middle, last, honorific), splits multi-author bylines, and format
