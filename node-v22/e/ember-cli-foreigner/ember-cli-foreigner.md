# ember-cli-foreigner

> 标签: ember-addon, foreigner, locale, localization, translation

## 简介

`ember-cli-foreigner` is a set of helpers and mixins to interface with the [foreigner.js](https://github.com/mirego/foreigner.js) library in Ember.
