# esbuild-plugin-solarite

> 标签: esbuild, esbuild-plugin, jsx, precompile, solarite, tsx

## 简介

esbuild plugin that compiles JSX/TSX to Solarite precompile output, giving JSX the same runtime speed as h tagged templates.
