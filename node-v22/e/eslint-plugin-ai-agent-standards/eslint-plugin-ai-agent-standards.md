# eslint-plugin-ai-agent-standards

> 标签: ai-agents, code-review, eslint, eslintplugin, react, react-native, typescript

## 简介

ESLint rules that mechanize the review comments human reviewers leave on AI-agent-written React / React Native / TypeScript code: named conditions, named hook deps, one component per file, no double assertions, no verbose comments, no inline noops, .ts-wi
