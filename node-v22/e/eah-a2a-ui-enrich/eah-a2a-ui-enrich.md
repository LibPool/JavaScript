# eah-a2a-ui-enrich

> 标签: JavaScript

## 简介

`eah-a2a-ui-enrich` provides the default UI renderer layer for enriched A2A responses. It renders rich answers, structured cards, and fallback JSON payloads from the response format produced by `eah-a2a-enrich`.
