# espeak-phonemizer

> 标签: espeak, espeak-ng, ipa, phonemes, phonemizer, piper, text-to-speech, tts, wasm, webassembly

## 简介

Lightweight WASM build of eSpeak-NG for g2p (grapheme to phoneme conversion), built to be used with web implementations of Piper TTS.
