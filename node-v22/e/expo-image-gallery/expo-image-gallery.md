# expo-image-gallery

> 标签: android, expo, gallery, gesture-handler, image-gallery, ios, lightbox, pinch-to-zoom, react-native, reanimated

## 简介

Performant, fully-customizable image gallery for Expo (SDK 50+). Powered by Reanimated v4 and Gesture Handler v3.
