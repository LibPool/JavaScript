# eslint-plugin-react-i18next-prettier

> 标签: eslin, eslint-plugin, i18n, i18next, react, react-i18next, reactjs

## 简介

Plugin resolves a conflict between a component <Tras><Trans> and prettier(max length) adding /*prettier-ignore*/ before the component.
