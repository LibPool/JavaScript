# dsh-pointer

> 标签: ai-agent, cordis-plugin, deepseek-harness, dsh, dsh-plugin, element-picker, html-preview

## 简介

In-preview element pointer (指代器) for DSH: pick elements inside previewable documents and feed the agent a selector, outerHTML and file:line
