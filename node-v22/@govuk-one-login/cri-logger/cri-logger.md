# @govuk-one-login/cri-logger

> 标签: JavaScript

## 简介

This package initialises and exports an instance of the AWS Lambda Powertools logger. For more information on the logger, see [their documentation](https://www.npmjs.com/package/@aws-lambda-powertools/logger).
