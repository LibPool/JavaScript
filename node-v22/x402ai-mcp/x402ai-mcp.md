# x402ai-mcp

> 标签: base, mcp, payments, usdc, x402

## 简介

Local stdio MCP server that lets an AI client buy embed, summarize and ask calls from api.x402ai.dev via x402 (USDC on Base), with per-payment and per-session spend caps.
