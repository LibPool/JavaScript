# @williamzujkowski/oklch-terminal-themes

> 标签: ansi, colors, culori, oklch, palette, tailwind, terminal, themes

## 简介

644 terminal color schemes converted to OKLCH, with WCAG contrast data per theme — npm package + JSON API for Astro, Svelte, Tailwind v4, and theme pickers.
