# @richkitjs/extension-bookmark

> 标签: bookmark, editor, link-card, link-preview, prosemirror, rich-text, rich-text-editor, richkit, richkit-extension, text-editor, unfurl, wysiwyg

## 简介

Link preview cards for RichKit: insertBookmark renders a URL as a card with title, description and image supplied by your own resolver. Never fetches on its own.
