# @richkitjs/extension-list-item

> 标签: editor, indent, list, list-item, prosemirror, rich-text, rich-text-editor, richkit, richkit-extension, text-editor, wysiwyg

## 简介

List item node for RichKit, shared by bullet and ordered lists: split, indent with Tab and outdent with Shift-Tab.
