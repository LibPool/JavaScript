# @qvac/tts-ggml

> 标签: JavaScript

## 简介

Text to Speech (TTS) addon for qvac (ggml backend, wrapping the chatterbox + supertonic + parler + cosyvoice3 + audio8 engines from tts-cpp)

## 官网

- 官网：https://qvac.tether.io
- 源码仓库：git+https://github.com/tetherto/qvac.git
- npm 页面：https://www.npmjs.com/package/@qvac/tts-ggml
