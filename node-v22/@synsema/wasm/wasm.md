# @synsema/wasm

> 标签: agents, edge, llm, synsema, wasm, webassembly

## 简介

Synsema — the programming language for AI agents — embedded as WebAssembly: run .syn programs inside browsers, Node/Bun/Deno and edge runtimes, lending them http/kv/llm from your app
