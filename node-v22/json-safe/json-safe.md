# json-safe

> 标签: bigint, circular, error, fast-safe-stringify, json, logging, map, safe, serialize, set, stringify

## 简介

JSON.stringify that never throws: handles circular references, BigInt, Map, Set, Error (with cause), typed arrays, throwing getters and more. Optional sorted keys and depth limit. Zero dependencies.
