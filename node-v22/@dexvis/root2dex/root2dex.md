# @dexvis/root2dex

> 标签: dex, edm4eic, edm4hep, firebird, jsroot, podio, root

## 简介

Converts EDM4eic / EDM4hep podio ROOT files to Firebird DEX using the JSROOT API. Plain worker-safe TypeScript; reads only the bytes of the requested event.
