# @takahashim/mruby-wasm-js

> 标签: browser, createvm, mruby, ruby, wasi, wasm, webassembly

## 简介

Minimal mruby ↔ JavaScript bridge for WebAssembly. Run mruby in browsers and Node with a JS::Object DOM/JS interop API.
