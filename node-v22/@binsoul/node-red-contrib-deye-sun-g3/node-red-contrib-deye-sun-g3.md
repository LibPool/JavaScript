# @binsoul/node-red-contrib-deye-sun-g3

> 标签: Deye SUN G3, Solarman v5, device, node-red

## 简介

Retrieves data from a Deye SUN300/500/600/800/1000/2000G3 micro inverter using the Solarman v5 protocol.
