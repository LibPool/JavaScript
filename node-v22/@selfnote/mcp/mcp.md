# @selfnote/mcp

> 标签: claude, mcp, modelcontextprotocol, notes, selfnote, tasks

## 简介

MCP server for Selfnote: let Claude (CLI, Desktop, or claude.ai) read, write and organize notes and tasks in your self-hosted Selfnote instance.
