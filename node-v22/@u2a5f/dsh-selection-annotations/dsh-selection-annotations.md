# @u2a5f/dsh-selection-annotations

> 标签: annotation, cordis, deepseek-harness, dsh, dsh-plugin, quote, selection, web

## 简介

DSH plugin: select text in the Web UI to annotate it, and send the whole set with your message as a separate JSON content block — never mixed into your message text.
