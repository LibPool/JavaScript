# @getoma/sdk

> 标签: agents, ai, llm, managed-agents, oma, sdk, sse, streaming

## 简介

Official TypeScript SDK for the oma managed agents platform. The API is also wire-compatible with @anthropic-ai/sdk via baseURL.
