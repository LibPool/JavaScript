# n8n-nodes-nemo-speech

> 标签: asr, diarization, gguf, n8n, n8n-community-node-package, nemo-speech, nemotron, parakeet, speech-to-text, transcription, translation

## 简介

n8n community node for NeMo-Speech.cpp — offline speech-to-text (ASR), speaker diarization, VAD, punctuation, inverse text normalization, and translation using NVIDIA models. Fully self-contained static binary.
