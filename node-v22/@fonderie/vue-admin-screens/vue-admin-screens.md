# @fonderie/vue-admin-screens

> 标签: admin, dashboard, fonderiejs, screens, shell, typescript, vue

## 简介

The admin shell for Vue: navigation by the operator's questions, seven pages over @fonderie/admin (attention, modules, doctor, configuration, routes, access, admin log), and the config/secrets and template screens composed as sub-pages under the one admin
