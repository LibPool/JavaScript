# @fonderie/media

> 标签: avatar, fonderiejs, media, saas, storage, typescript, upload

## 简介

Provider-abstracted asset storage — upload, store, and serve user-owned images (avatars, logos) with a DB-blob backend by default and object storage as a one-line swap.
