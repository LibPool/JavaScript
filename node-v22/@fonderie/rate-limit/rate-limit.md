# @fonderie/rate-limit

> 标签: brute-force, fonderiejs, rate-limit, throttle, token-bucket, typescript

## 简介

Distributed rate limiting for @fonderiejs — atomic token bucket over memory, PostgreSQL, or Redis, with standard RateLimit-* headers.
