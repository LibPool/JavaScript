# @fonderie/vue-courier-admin

> 标签: admin, composables, courier, fonderiejs, templates, typescript, vue

## 简介

Vue 3 composables for the Fonderie courier admin API (email/SMS/push template management) — thin bindings over @fonderie/client's CourierAdminClient.
