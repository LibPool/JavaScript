# @teselia/otp

> 标签: 2fa, a11y, accessibility, custom-element, one-time-code, otp, otp-input, verification-code, vue, wcag, web-component

## 简介

Accessible one-time code input (OTP), shipped as a framework-agnostic Web Component. One real input drawn as cells, so paste, SMS autofill and screen readers work. WCAG 2.2 AA by default.
