# @studioraming/warudo-agent-bridge

> 标签: ai-agent, claude, codex, mcp, model-context-protocol, unity, vtuber, warudo

## 简介

MCP server and CLI that let AI agents (Claude, Codex and other MCP clients) inspect and control a running WARUDO: scene, assets, camera, character pose and IK, expressions, blueprints and captures.
