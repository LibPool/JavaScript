# @dockndevai/mcp-ios

> 标签: ai, appium, device-control, ios, llm, mcp, mobile, model-context-protocol, webdriveragent, xcuitest

## 简介

Model Context Protocol server to drive a physical iPhone/iPad over Appium + WebDriverAgent (XCUITest) — screenshots, taps, typing, swipes, app launch, Shortcuts — safe-by-default with access modes and gated destructive ops.
