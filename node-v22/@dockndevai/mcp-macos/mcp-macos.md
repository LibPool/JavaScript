# @dockndevai/mcp-macos

> 标签: ai, applescript, automation, computer-use, llm, mac, macos, mcp, model-context-protocol

## 简介

Model Context Protocol server for macOS — observe and operate a Mac (files, processes, apps, screenshots, shell, AppleScript, GUI) with safe-by-default access controls.
