# @dockndevai/mcp-azure-devops

> 标签: ai, azure-devops, boards, devops, governance, llm, mcp, model-context-protocol, pipelines

## 简介

Model Context Protocol server for Azure DevOps — boards, repos, pipelines, and projects with governance controls (access modes, project scoping, protected projects, delete gating, confirmation, dry-run, audit).
