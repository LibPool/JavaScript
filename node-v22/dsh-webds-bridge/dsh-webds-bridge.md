# dsh-webds-bridge

> 标签: browser-automation, chatbot-bridge, cordis, deepseek, deepseek-harness, deepseek-web, dom-automation, dsh, dsh-plugin, webview

## 简介

DSH 插件：把网页版 DeepSeek 以纯 DOM 自动化接入 DSH，无需 API Key。支持多对话记忆隔离、自动续接、设置页面板与快捷操作栏（Host + Client 单包）。
