# @a1-x-tech/mcp-google-auth

> 标签: google, login, loopback, mcp, model-context-protocol, oauth, oauth2, pkce

## 简介

Reusable Google OAuth onboarding for the mcp-google-* MCP server line: in-chat login tools (loopback + PKCE) and a per-request TokenProvider.
