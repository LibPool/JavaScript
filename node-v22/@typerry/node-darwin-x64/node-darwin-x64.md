# @typerry/node-darwin-x64

> 标签: addon, assemblyscript, build-tool, bun, code-protection, codegen, compiler, cross-platform, cryptography, edge-computing, encryption, native, nodejs, performance, perry, plugin-system, portable, rust, serverless, standalone, swc, transpiler, ts-to-wasm, ts2wasm, typescript, wasm, wasm-compiler, wasm-generator, webassembly, zero-runtime

## 简介

TypeScript to WebAssembly compiler — standalone, zero dependencies, Rust-powered via perry. compile .ts directly to .wasm for performance, cryptography, edge computing, code protection, and portable cross-platform libraries.
