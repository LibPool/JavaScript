# @volter/twin-svix

> 标签: JavaScript

## 简介

Local Svix twin for the webhook-delivery-as-a-service surface: Application/Endpoint/Message CRUD, a deterministic per-endpoint Message Attempt fan-out + delivery-state-progression machine (pending->sending->success, or a configured-failure retry counter s
