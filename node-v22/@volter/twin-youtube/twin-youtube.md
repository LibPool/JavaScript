# @volter/twin-youtube

> 标签: JavaScript

## 简介

Local YouTube Data API v3 twin (resumable uploads, media served with Range) with a youtube.com mirror, built on @volter/world-core.

## 官网

- 官网：https://world.volter.ai/twins/youtube
- 源码仓库：git+https://github.com/volter-ai/twin.git
- npm 页面：https://www.npmjs.com/package/@volter/twin-youtube
