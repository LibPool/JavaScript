# @multiversal-ventures/brook

> 标签: bank-statements, brook, fintech, plaid, react, underwriting

## 简介

React wrapper for Brook — the Plaid-failover bank-statement collection API. Opens a collection session with your publishable key, renders the upload popup, and resolves with an exchangeRef your server swaps for Plaid-shaped data.
