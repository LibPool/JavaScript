# dsh-anchor-memory

> 标签: context, deepseek, deepseek-harness, dsh, dsh-plugin, long-term-memory, markdown, memory, token-efficiency

## 简介

基于 markdown 文件的长期记忆（DSH host 插件）：自动注入记忆索引，提供 memory_status/search/read/write 工具，写入时自动维护「目录 + 锚点」，检索只读命中那一节，并守住索引预算硬上限。零依赖。
