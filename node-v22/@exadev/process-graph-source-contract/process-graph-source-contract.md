# @exadev/process-graph-source-contract

> 标签: conformance, contract, orpc, port, process-model

## 简介

The GraphSource port as an oRPC contract: versioned, paginated and streamed sync of bound activities, participants, transitions and overlay status, with an in-memory fake and a conformance kit every adapter must pass.
