# @exadev/process-graph-store-sqlite

> 标签: drizzle, orpc, process-model, sqlite, store

## 简介

The GraphStore port on SQLite through Drizzle: one schema, committed drizzle-kit migrations applied the same way in every runtime, recursive SQL for the structural queries, written against Drizzle's async SQLite database so any driver plugs in.
