# @exadev/process-graph-source-github-issues

> 标签: dependencies, github, graphql, issues, orpc, process-model

## 简介

The GitHub issues GraphSource adapter: issues as bound activities, blockedBy and blocking as transitions, sub-issues, repositories, organisations and assignees, read through the GraphQL API with server-side filters, pagination, rate-limit handling and typ
