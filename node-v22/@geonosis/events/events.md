# @geonosis/events

> 标签: cloudflare-queues, events, medusa, outbox, registry, zod

## 简介

An event declares its type, its payload schema and what it is about, once. A registry that refuses a duplicate name, a totality type that makes every event answerable, and an outbox port — with the engines' own facts kept in their adapters.
