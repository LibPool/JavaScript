# @geonosis/integrations

> 标签: integrations, plugin, provider, registry, settings, zod

## 简介

One integration seam: a prefixed id, an optional settings schema, one registry that refuses a duplicate, a wrong prefix or a missing required id — and settings fields derived from the schema rather than hand-mapped.
