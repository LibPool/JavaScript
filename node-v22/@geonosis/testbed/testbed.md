# @geonosis/testbed

> 标签: fixtures, integration, medusa, postgres, testing, workerd

## 简介

The fixtures law as code, one adapter contract for an integration harness, and the conformance suite an adapter has to pass. Extracted from a Medusa storefront's Medusa runner and a Workers + D1 app's workerd cell.
