# @zyphr-dev/auth-core

> 标签: auth, authentication, session, token-refresh, zyphr

## 简介

Framework-agnostic auth session core for Zyphr — session state, proactive token refresh, and pluggable secure storage. The engine behind @zyphr-dev/auth-react and auth-react-native.
