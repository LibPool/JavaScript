# @dshcli/dsh-cli

> 标签: agent, ai-agent, cli, coding-agent, deepseek, deepseek-harness, dsh, harness, terminal, tui

## 简介

Pure-CLI terminal client for DeepSeek Harness (dsh): multi-turn agent sessions, an isolated harness home, a folder-dialog working-directory picker, model switching, one-command launch of the browser frontend, and vision-based frontend verification.
