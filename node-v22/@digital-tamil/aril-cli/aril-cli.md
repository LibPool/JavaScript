# @digital-tamil/aril-cli

> 标签: cli, command-line-utilities, font-converter, pdf-converter, tamil, text-processing, unicode

## 简介

High-throughput CLI tool for batch converting and archiving legacy Tamil fonts (Bamini, TSCII, ShreeLipi) and legacy-encoded PDF documents to standard Unicode.
