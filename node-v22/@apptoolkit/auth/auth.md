# @apptoolkit/auth

> 标签: JavaScript

## 简介

- `RSA_PRIVATE_KEY`(*Required*): String of the private key in pkcs8 type with pem format or the path to a .pem file - `RSA_KEY_PASSPHRASE`(*Required*): Passphrase of the private key - `APP_NAME`(*Required*): Display name for the application - `ON_SIGN_IN_
