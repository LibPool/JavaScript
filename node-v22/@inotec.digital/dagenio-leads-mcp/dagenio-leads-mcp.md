# @inotec.digital/dagenio-leads-mcp

> 标签: crm, dagenio, leads, mcp, model-context-protocol

## 简介

Model Context Protocol (MCP) server for the Dagenio Leads CRM. Exposes the Dagenio Leads V2 REST API (leads, contacts, companies, teams, follow-ups, qualifications, templates, salutations) as MCP tools.
