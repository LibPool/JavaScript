# @authorbot/git-github

> 标签: authorbot, git, github

## 简介

Worker-compatible GitHub integration for Authorbot (Phase 5 contract): GitHub App auth, Git Data API reader/writer, and a deterministic in-process fake GitHub with a real git object model
