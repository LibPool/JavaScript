# @authorbot/repo-coordinator

> 标签: authorbot, git, outbox

## 简介

Outbox processor and Git mirroring for Authorbot: byte-stable annotation/reply artifact rendering, BookRepoWriter with a LocalGitAdapter, and the queued-to-committed git_operations walker (Phase 2 contract section 5)
