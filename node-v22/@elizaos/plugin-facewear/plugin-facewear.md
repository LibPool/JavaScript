# @elizaos/plugin-facewear

> 标签: JavaScript

## 简介

Unified facewear plugin — Meta Quest 3, XReal, Even Realities G1/G2, Apple Vision Pro. Bidirectional voice+camera streaming, smartglasses display, view panels, device management.
