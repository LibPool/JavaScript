# @elizaos/scenario-runner

> 标签: JavaScript

## 简介

Lean scenario runner for the WS7 scenario-schema architecture. Loads .scenario.ts files, executes them against a real @elizaos/core AgentRuntime with a live LLM, and emits a JSON report.
