# @samyx/repl-openapi-oauth

> 标签: auth, device-flow, oauth, oauth2, openid, pkce, repl-openapi, www-authenticate

## 简介

OAuth 2.0 auth handler for @samyx/repl-openapi — authorization-code+PKCE, device, and refresh grants, with OS-keychain token storage and reactive WWW-Authenticate handling
