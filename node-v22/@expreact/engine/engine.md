# @expreact/engine

> 标签: baseui, engine, expreact, react, ui, ux

## 简介

Expreact is a complete solution for react project. Based on react mui, this framework provides one of the best developer experiences. Helps new developers to easily integrate themselves onto the project with minimal efforts.
