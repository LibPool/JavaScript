# pi-dsh-tools

> 标签: coding-agent, deepseek, deepseek-harness, dsh, pi, pi-coding-agent, pi-extension, pi-package, subagents, workflow

## 简介

DeepSeek Harness (DSH) agent controls reimplemented for Pi: goals, todos, jobs, terminals, subagents, workflows, PTC, guards, spill, and filesystem policy.
