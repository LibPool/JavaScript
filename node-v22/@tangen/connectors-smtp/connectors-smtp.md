# @tangen/connectors-smtp

> 标签: JavaScript

## 简介

The SMTP connector pack for Tangen: send email through any SMTP server as a connection an operator manages, with a typed email service, a Flow action and a form destination. Tangen ships no connectors of its own - install the providers you use
