# @tangen/realtime

> 标签: JavaScript

## 简介

The Tangen realtime client - lazy, one multiplexed connection per tab, WebSocket with automatic SSE fallback, reconnect with cursor resume. Framework-neutral; depends on @tangen/sdk for auth and base URL only.
