# @t2a/chat

> 标签: agent, chat, chat-ui, claude, embeddable, form-block, gemini, interactive-form, llm, openai, system-event, t2a, tool-calling, websocket

## 简介

Talk-to-Action Chat Runtime — the official UI/runtime layer for @t2a/core. Embeddable WebSocket chat with native interactive forms, slot system, tool rendering, and multi-modal attachments.
