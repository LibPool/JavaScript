# @textnode/cli

> 标签: cli, command-line, css-variables, design-tokens, font-analysis, font-metrics, fonts, scss, tailwind, type-scale, typography

## 简介

CLI tools for textnode typography system. Initialize projects, analyze fonts, export design tokens to CSS/SCSS/Tailwind/JSON.
