# @evident-ai/runner-synchroniser

> 标签: credentials, evident, litestream, opencode, runner, s3

## 简介

Restores and syncs the Evident runner's OpenCode credential stores (and litestream config) to an object store, so a runner survives task replacement with almost no state loss.
