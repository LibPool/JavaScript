# @rayspec/handler-sdk

> 标签: JavaScript

## 简介

The **only** package a trusted-author escape-hatch handler may import: the public, type-only contract for handlers (including the neutral `BlobStore` interface). Keeping this surface type-only is what keeps handler code reviewable and the runtime boundary
