# n8n-nodes-proofledger

> 标签: n8n-community-node-package, polygon, proof of existence, proofledger, sha256, timestamp, timestamping

## 简介

n8n community node for ProofLedger: anchor a file's SHA-256 hash on the Polygon blockchain, read proofs back, and start workflows when a proof is anchored. The file never leaves n8n.
