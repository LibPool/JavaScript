# @aardworx/wombat.dom

> 标签: aardvark, adaptive, dom, incremental, jsx, reactive, scene-graph, ui, webgpu, wombat

## 简介

Adaptive DOM + 3D scene-graph DSL for the Wombat TypeScript stack — direct-DOM JSX over @aardworx/wombat.adaptive, with optional WebGPU scene-graph extensions.
