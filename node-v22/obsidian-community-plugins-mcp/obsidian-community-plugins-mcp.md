# obsidian-community-plugins-mcp

> 标签: ai, claude, llm, mcp, model-context-protocol, obsidian, obsidian-plugins, obsidian-themes

## 简介

MCP server that lets coding agents check the official Obsidian plugin and theme directory (9,000+ plugins) before building, with downloads, versions and last-update dates.
