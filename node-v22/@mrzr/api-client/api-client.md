# @mrzr/api-client

> 标签: api-client, fetch, http-client, httponly, jwt, multi-tab, nextjs, nuxt, react, rest, ssr, token-refresh, typescript, vue, web-worker

## 简介

The HTTP layer under TanStack Query, SWR and Vue Query — it handles auth so they don't have to. Coalesced token refresh, Web Worker token isolation, cross-tab session sync. Zero dependencies.
