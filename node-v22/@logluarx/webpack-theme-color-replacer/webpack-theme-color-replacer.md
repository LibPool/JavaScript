# @logluarx/webpack-theme-color-replacer

> 标签: color, javascript, replacer, runtime, theme, webpack

## 简介

基于webpack-theme-color-replacer,处理antd样式和qiankun对接. A webpack plugin designed to dynamicly change the theme colors at runtime. 实现运行时快速动态替换主题色的webpack插件.
