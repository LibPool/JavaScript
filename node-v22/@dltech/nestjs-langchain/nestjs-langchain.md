# @dltech/nestjs-langchain

> 标签: fallback, function-calling, json-schema, langchain, llm, nestjs, output-parser, structured-output, tool-calling, zod

## 简介

NestJS-friendly LangChain utilities: decorator-based JSON Schema generation for tool/function calling, a streaming output parser for class-typed tool calls, LLM fallback chains, and an Observable adapter for LangChain streams.
