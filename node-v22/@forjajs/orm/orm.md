# @forjajs/orm

> 标签: database, migrations, mongodb, mysql, orm, postgres, postgresql, sqlite, typescript

## 简介

Multi-driver ORM (json-driver, SQLite, MySQL, PostgreSQL, MongoDB) — schema validation, migrations, transactions, query builder, relations. Usable standalone, no Forja required.
