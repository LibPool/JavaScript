# clacky

> 标签: clacky, contribution-graph, contributions, custom-element, github, heatmap, keyboard, keycap, mechanical-keyboard, motion, react, web-audio, web-component

## 简介

Your GitHub contribution graph as a grid of clickable mechanical keycaps, with tactile press animations and real switch sounds. React component + Web Component.
