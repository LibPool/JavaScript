# @suluk/openapi-compat

> 标签: JavaScript

## 简介

Lossless-where-possible conversion between the OpenAPI v4 'Suluk' candidate and OpenAPI 3.1 (the dialect Scalar/Swagger consume). CANDIDATE tooling.
