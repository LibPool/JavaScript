# @dfine-io-gmbh/dlint

> 标签: architecture, code-quality, compiler-api, dlint, linter, performance, security, static-analysis, typescript

## 简介

Semantic TypeScript linter built on the TS Compiler API — 86 rules covering quality, security, performance, and architecture, plus secret scanning and an HTML report dashboard.
