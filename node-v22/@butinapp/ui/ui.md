# @butinapp/ui

> 标签: JavaScript

## 简介

Butin's embeddable, theme-portable design system + the generic data-view renderer (DashboardRenderer, Overview, app shell). Pure, prop-driven, no Electron. Ships a self-contained, .butin-scoped butin.css for drop-in embeds (zero host build), plus theme.cs
