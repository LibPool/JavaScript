# @lerkel/ngx-ui-loader

> 标签: Angular loader, Angular loading, Angular multiple loaders, Angular progress bar, Angular spinner, loader, loader AoT compatible, loading, ngx-loader, ngx-loading, ngx-multiloader, ngx-multiple-loader, ngx-spinner, ngx-ui-loader, progress bar, progressbar, spinner

## 简介

An all-in-one and fully customizable loader/spinner for Angular applications. It supports foreground, background spinner/loader, indicative progress bar and multiple loaders.
