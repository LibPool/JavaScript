# @knapsack-pro/playwright

> 标签: CI, automation, integration, knapsack, knapsack pro, parallelisation, playwright, runner, test, test suite parallelisation, testing

## 简介

Knapsack Pro Playwright splits Playwright tests across CI nodes and makes sure that tests will run in optimal time on each CI node.
