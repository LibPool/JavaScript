# @withmateza/sdk

> 标签: ai, mateza, multimodal, sdk, speech, translation, typescript

## 简介

Official TypeScript SDK for the Mateza API: AI responses, translation, i18n, and multimodal text on the Mahoro backend. Speech-to-text and text-to-speech are coming soon.

## 官网

- 官网：https://mateza.rw/docs/sdks/sdk
- 源码仓库：git+https://github.com/matezahq/mateza.git
- npm 页面：https://www.npmjs.com/package/@withmateza/sdk
