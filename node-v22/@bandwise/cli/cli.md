# @bandwise/cli

> 标签: bandwise, classification, decisions, jev, llm, system-one, typesafe

## 简介

The bandwise command. `bandwise run --local` runs a question set spec on a state with no network and no key; `bandwise run --live` and `bandwise hook` run it against the real model with your own key.
