# @shallbay/dsh-bridge-browser

> 标签: browser, chrome-extension, deepseek-harness, dsh, plugin

## 简介

dsh browser bridge: token-authenticated WebSocket carrier plus text-only browser_* tools that drive the user's own Chrome through the bundled extension. Repack of @yuxianglin/dsh-bridge-browser that installs from npm and also runs on the DSH Desktop 2.x p
