# @merediv/sso-sdk-react

> 标签: auth, mmadwn, oidc, react, react-native, sso

## 简介

React hooks + provider for 'Sign in with mmadwn'. The client half of @merediv/sso-sdk — talks to the BFF /auth endpoints. Works in React and React Native. Zero runtime dependencies (react is a peer).
