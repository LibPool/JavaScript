# @kitiumai/encryption

> 标签: aead, aes-256-gcm, aes-gcm, argon2, audit, aws-kms, azure-key-vault, browser, compliance, crypto, cryptography, ed25519, encryption, envelope-encryption, gcp-kms, hashicorp-vault, hsm, key rotation, key-management, kitium, kitiumai, kms, node, policy, scrypt, sdk, security, typescript, webcrypto

## 简介

TypeScript encryption SDK for Node.js and browsers with AES-256-GCM + Ed25519, envelope encryption, pluggable providers (local/KMS/HSM), and built-in audit/policy hooks.
