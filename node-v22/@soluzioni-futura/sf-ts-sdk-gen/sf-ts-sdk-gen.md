# @soluzioni-futura/sf-ts-sdk-gen

> 标签: JavaScript

## 简介

`sf-ts-sdk-gen` is a Node module that generates a TypeScript SDK starting from an OpenAPI definition. It can be used as a CLI or as a Node module.
