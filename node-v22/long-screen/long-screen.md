# long-screen

> 标签: panorama, screen-recording, screenshot, stitching, webassembly, webcodecs, worker

## 简介

Turn a screen recording into one big screenshot, in the browser: Long Screen’s reconstruction engine (Rust/WebAssembly in a Worker) for your own page.
