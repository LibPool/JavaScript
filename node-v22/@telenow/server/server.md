# @telenow/server

> 标签: ai-agent, ai-phone-call, ai-voice-agent, api-client, bun, call-automation, call-center, cloudflare-workers, conversational-ai, custom-llm, deno, llm, nodejs, outbound-calls, server-sent-events, sse, telenow, telephony, voice-agent, voice-ai, voice-bot, webhooks

## 简介

Telenow voice AI SDK for Node, Bun, Deno & edge — place AI agent phone calls, mint browser/app call sessions, transfer & end live calls, verify webhooks, and build custom-LLM streaming (SSE) endpoints. Zero dependencies.
