# @ancplua/qyl-api-schema

> 标签: contracts, observability, openapi, qyl, typespec

## 简介

TypeSpec source of truth for qyl API contracts. Emits OpenAPI, JSON Schema, Qyl.Api.Contracts DTOs, and TypeScript contract types; not an OpenTelemetry package, storage schema, or server implementation.
