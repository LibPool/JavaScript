# @autonome-research/fleet-router

> 标签: inference, llm, load-balancing, local, openai-compatible, router, vllm

## 简介

Client-side request routing across heterogeneous local LLM inference endpoints: context-window eligibility, capacity-normalized least-loaded selection, health probing. Zero dependencies.
