# @getpipher/term

> 标签: automation, pi-extension, pi-package, programmatic-terminal, qa, testing, tmux, tui

## 简介

Programmatic tmux driver for the pi coding agent — spawn/drive a tmux session (send-keys, capture-pane, wait-for-pattern/quiet, resize, kill) for autonomous TUI QA. tmux-only; ships as an importable lib + a thin pi extension.
