# @sahidha/sdk

> 标签: api-client, finance, personal-finance, sahidha, sdk

## 简介

TypeScript SDK for the Sahidha REST API. Used by the Sahidha web, mobile, CLI, and MCP server. Anyone integrating against /api/v1 can import this for typed, ergonomic access.
