# @luchai/viewer

> 标签: JavaScript

## 简介

Turnkey Луч ИИ DICOM viewer (shell + viewport, self-contained inline WASM core) — rebrandable via config (theme/brand/features/locale). Nothing to host: npm i, pass a licenseKey, mount.
