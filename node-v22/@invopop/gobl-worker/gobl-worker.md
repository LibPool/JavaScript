# @invopop/gobl-worker

> 标签: JavaScript

## 简介

Node.js package to help use the GOBL CLI WASM binary distributed via CDN. This package at the moment won't try to embed the `.wasm` as an asset.

## 官网

- 官网：https://gobl.org
- 源码仓库：git+https://github.com/invopop/gobl.dev.git
- npm 页面：https://www.npmjs.com/package/@invopop/gobl-worker
