# @meednite/vue-datepicker

> 标签: calendar, chinese, component, customizable, date-picker, datepicker, datetime, gregorian, hijri, i18n, internationalization, jalaali, jalali, multi-calendar, persian, range-picker, rtl, shamsi, time-picker, vue, vue-calendar, vue-datepicker, vue3, vue3-datepicker, vuejs

## 简介

A comprehensive Vue 3 datepicker with Jalali, Gregorian, Hijri, and Chinese calendar support. Features range selection, time picker, and full customization.
