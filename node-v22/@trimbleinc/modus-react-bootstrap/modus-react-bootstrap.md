# @trimbleinc/modus-react-bootstrap

> 标签: modus, modus-bootstrap, modus-react-bootstrap, react, react-bootstrap

## 简介

The Modus React Bootstrap is a component library extended from Open Source library react-bootstrap developed as a common, open source platform for all of Trimble’s web applications built on React.
