# @oceanalt/crossmint

> 标签: agent-payments, agent-wallets, aml, crossmint, eip-3009, pre-signing, smart-wallets, x402

## 简介

Guard for Crossmint wallets: ask OceanAlt about the real payee (allow / review / decline) before a Crossmint EVM wallet sends, signs an x402 authorization or approves. Fails closed. No keys, no custody. Not affiliated with Crossmint.
