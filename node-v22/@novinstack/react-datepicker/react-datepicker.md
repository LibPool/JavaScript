# @novinstack/react-datepicker

> 标签: calendar, date-picker, date-range, datepicker, datetime-picker, gregorian, hijri, hijri-datepicker, islamic, jalali, jalali-datepicker, ltr, novinstack, persian, persian-datepicker, react, react-datepicker, rtl, shamsi, time-picker, typescript

## 简介

React Date Picker with Jalali (Persian/Shamsi), Hijri (Islamic) and Gregorian calendars, RTL/LTR, TypeScript, range, time, multiple selection and full customization.
