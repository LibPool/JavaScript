# @trebired/logger

> 标签: backend, browser, bun, frontend, logger, logging, sqlite, structured-logging

## 简介

Local-first structured logger for Bun with an indexed SQLite store, partitions, default retention, redaction, query and export helpers, and browser runtimes.
