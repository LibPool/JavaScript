# @trebired/store

> 标签: bun, cache, entity-store, jsonb, postgres, sqlite, store

## 简介

Reusable generic entity store for Bun with typed entity registries, SQLite, scoped JSONB storage, modes, request loaders, cache invalidation, and sub-entity reads.
