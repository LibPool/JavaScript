# @face-auth/face-id-video

> 标签: auth, biometric, browser, camera, face-auth, face-authentication, face-id, face-recognition, frontend, getUserMedia, html5-video, identity, image-capture, javascript, media-stream, photo-capture, typescript, video, webcam

## 简介

Utility library for capturing photos from webcam video streams in the browser. Handles camera selection, image formatting, and output for face authentication APIs.
