# @sanbus/galley

> 标签: ffi, galley, javascript, parser, typescript, wasm

## 简介

Universal Galley JavaScript bindings: one package for Node, Bun, Deno, and browsers over @sanbus/galley-core, with native-first backend selection and WebAssembly fallback
