# @any-menu/any-menu-core

> 标签: JavaScript

## 简介

- shared/         | 通用部分 (其他所有子模块均可以依赖这个。尽量简单，                     使子模块迁移到其他项目中基本重新实现这个简单的东西即可迁移)   - locals/       | 多语言   - setting.ts - modules/        | 子模块   - editor/       | 编辑器管理     - event       | 事件管理     - cursor      | 光标、游标、选区 管理   -
