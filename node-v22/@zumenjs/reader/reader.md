# @zumenjs/reader

> 标签: autocad, cad, drawing, dwg, dxf, jww, sxf, viewer, webassembly

## 简介

Read every zumen format (SXF, JWW, DXF, DWG) in browsers and Node.js with zumen's Rust readers built to WebAssembly, on the page or in a Web Worker
