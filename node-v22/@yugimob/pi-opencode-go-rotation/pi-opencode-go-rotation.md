# @yugimob/pi-opencode-go-rotation

> 标签: api-key-rotation, opencode, pi-extension, pi-package, rate-limit, usage

## 简介

Rotate between multiple OpenCode Go API keys with reactive 429, rate-limit, and watchdog stall detection, plus live footer usage for the active key
