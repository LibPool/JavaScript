# vue-docx-document

> 标签: document, docx, invoice, office, openxml, renderer, report, vue, vue3, word

## 简介

Create Word (.docx) files with Vue 3 components: a custom Vue renderer on top of docx, for the browser and Node, with a live HTML preview.
