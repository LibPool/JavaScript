# @thoughtindustries/gcal-mcp

> 标签: JavaScript

## 简介

MCP server that lets Claude Code, Claude Desktop and other MCP clients read and manage **your own** Google Calendar. You sign in once with Google in your browser (OAuth 2.0 loopback + PKCE); tokens are cached per user. Modeled on [`ga4-mcp`](../ga4-mcp/).
