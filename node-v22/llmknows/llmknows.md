# llmknows

> 标签: agents, ai, api, benchmark, claude, cli, developer-experience, hallucination, llm, llms-txt, openai, typescript

## 简介

Does AI know your library? Measures how often LLMs hallucinate your npm package's API by typechecking the code they write against your real types.
