# @agentworkforce/persona-registry

> 标签: JavaScript

## 简介

Programmatic resolution for AgentWorkforce personas. It owns the same source cascade used by the CLI: cwd personas, cwd agents, configured directories (including the personal directory), then the built-in catalog.
