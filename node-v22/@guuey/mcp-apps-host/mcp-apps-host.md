# @guuey/mcp-apps-host

> 标签: generative-ui, guuey, host, mcp, mcp-apps, sep-1865, view

## 简介

The MCP Apps (SEP-1865) Host role for guuey's chat surfaces — view-mount narrowing across UI channels, ui:// locator rehydration by resources/read, and the sandbox-trust channel contract. Vendor-neutral: any spec-following MCP App mounts through it.
