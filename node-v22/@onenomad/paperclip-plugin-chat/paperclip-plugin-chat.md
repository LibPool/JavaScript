# @onenomad/paperclip-plugin-chat

> 标签: agents, chat, paperclip, paperclip-plugin

## 简介

Chat with your CEO or any agent in Paperclip without opening a task. Conversations keep context, replies stream in, and the agent can act on what you ask.
