# @ndiinginc/ussd

> 标签: JavaScript

## 简介

Library Node.js untuk membangun menu **USSD** berbasis pohon (tree) dengan routing ala URL, parameter dinamis, tombol kembali, pagination otomatis untuk pesan panjang, dan timeout sesi.
