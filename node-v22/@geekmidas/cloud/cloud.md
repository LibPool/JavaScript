# @geekmidas/cloud

> 标签: JavaScript

## 简介

SST (ion / Pulumi) integration for `@geekmidas` apps — opinionated, linkable constructs that map 1:1 to deployable units and **validate their environment before deploy**, plus the runtime helpers that resolve linked resources into environment variables.
