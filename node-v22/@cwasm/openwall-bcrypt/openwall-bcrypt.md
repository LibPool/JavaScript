# @cwasm/openwall-bcrypt

> 标签: bcrypt, crypt, crypto, hash, openwall, password, wasm

## 简介

BCrypt hashing for Node.js, using [Openwall BCrypt](https://www.openwall.com/crypt/) compiled to [WebAssembly](https://webassembly.org/).
