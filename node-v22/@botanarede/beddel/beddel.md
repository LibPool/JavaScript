# @botanarede/beddel

> 标签: ai, automation, beddel, llm, openclaw, plugin, workflow, yaml

## 简介

Beddel workflow runner plugin for OpenClaw — execute declarative YAML AI workflows with branching, retry, multi-provider LLM support, guardrails, and OpenTelemetry tracing.
