# @neurealistic/gh-mcp

> 标签: github, issue, mcp, model-context-protocol, pull-request, token

## 简介

MCP server for the GitHub API (PRs, issues, reviews, repos) — server-side token, HTTP mode, run_steps batch. Companion to @neurealistic/git-mcp. Runs via npx, no docker.
