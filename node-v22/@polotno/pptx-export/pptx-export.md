# @polotno/pptx-export

> 标签: editable powerpoint, javascript, json to pptx, polotno, powerpoint, pptx, pptx export, presentation export

## 简介

Convert Polotno JSON into editable PowerPoint PPTX files with native text, shapes, tables, images, and animations
