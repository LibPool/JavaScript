# @batchgrid/mcp

> 标签: batch, batchgrid, inference, llm, mcp, model-context-protocol

## 简介

MCP server that gives Claude Desktop, Claude Code, and other agents a bulk LLM tool - plan a multi-step job in natural language and run it over every row.
