# @barcodesgg/scanner

> 标签: barcode, barcode-detector, barcode-lookup, barcode-scanner, barcodes.gg, camera, ean, gtin, react, scanner, sneakers, upc, upc-lookup, web-component, zxing

## 简介

Drop-in barcode scanner for websites by Barcodes.gg. Scan UPC/EAN barcodes with the camera, and look products up with a Barcodes.gg publishable key. Web component, React hook and headless core.
