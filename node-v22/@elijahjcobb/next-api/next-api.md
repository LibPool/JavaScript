# @elijahjcobb/next-api

> 标签: JavaScript

## 简介

The following environment variables are required: |Name|Description| |---|---| |`KV_URL`|A url to a redis instance.| |`TOTP_SECRET`|A secret for generating TOTP tokens.| |`TOKEN_SECRET`|A secret for encrypting a JWT.|
