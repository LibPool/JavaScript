# @ariada-org/surface-browser

> 标签: a11y, accessibility, bookmarklet, browser, compliance, devtools, eaa, eupl, scanner, wcag

## 简介

In-browser surface adapter for @ariada-org/core-engine — bookmarklet, DevTools panel entry point, and importable ES module for multi-domain compliance scanning in any browser context.
