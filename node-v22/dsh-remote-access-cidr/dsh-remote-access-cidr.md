# dsh-remote-access-cidr

> 标签: bundle, cidr, cordis, deepseek-harness, dsh, plugin, remote-access, tailscale

## 简介

Expose this machine's DSH web GUI to a chosen CIDR range (e.g. Tailscale), with an optional numeric access code.
