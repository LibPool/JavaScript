# @poolse/react

> 标签: chat, chat-hooks, chat-sdk, hooks, in-app-messaging, messaging, poolse, react, react-chat, react-hooks, realtime, realtime-chat, sendbird-alternative, stream-chat-alternative, typescript, use-messages, use-presence, use-typing, websocket

## 简介

React hooks for realtime chat — PoolseProvider plus useMessages, useTyping, usePresence, useReactions, useMembers, useAttachmentUpload. Works on web and React Native. No UI. MIT — alternative to sendbird-chat-react and stream-chat-react.
