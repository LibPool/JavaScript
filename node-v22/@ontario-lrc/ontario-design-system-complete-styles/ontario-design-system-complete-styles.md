# @ontario-lrc/ontario-design-system-complete-styles

> 标签: JavaScript

## 简介

Complete styles package for the Ontario Design System containing all SASS and CSS for use independently of the Component Library. This is a carbon-copy of @ongov/ontario-design-system-complete-styles@4.2.0, with bug fixes discovered.
