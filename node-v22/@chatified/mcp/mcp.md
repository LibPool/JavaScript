# @chatified/mcp

> 标签: chatified, claude, cursor, mcp, model-context-protocol, rag, support-chat

## 简介

MCP stdio bridge to the remote Chatified MCP server. Surfaces visitor intent, identity graph, conversions, segments, campaigns, and conversations inside Claude Desktop, Cursor, Zed, and any MCP-capable agent.
