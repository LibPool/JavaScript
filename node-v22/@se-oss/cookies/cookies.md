# @se-oss/cookies

> 标签: aes-gcm, browser, chunking, cookie, cookie-parser, cookie-serializer, cookies, encryption, hmac, node, rfc6265, secure-cookies, signing, typescript, web-crypto

## 简介

A lightweight, secure cookie manager for JavaScript and TypeScript with signing, AES-GCM encryption, transparent chunking, and RFC 6265bis prefix validation.
