# @se-oss/uuid

> 标签: guid, rfc4122, rfc9562, typescript, uuid, v1, v3, v4, v5, v6, v7

## 简介

A TypeScript library for generating and validating all modern UUID versions (1, 3, 4, 5, 6, and 7).
