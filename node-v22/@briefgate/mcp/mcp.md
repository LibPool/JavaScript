# @briefgate/mcp

> 标签: ai-agent, briefgate, claude-code, client-intake, client-portal, dashboard, file-collection, freelance, mcp, no-code, onboarding

## 简介

Client intake: collect logos, copy, logins and structured data from clients. Build the request in the browser dashboard — no agent needed — or let your AI coding agent build it over MCP.
