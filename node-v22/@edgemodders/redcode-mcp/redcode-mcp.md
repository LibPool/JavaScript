# @edgemodders/redcode-mcp

> 标签: cyberpunk, cyberpunk2077, mcp, mcp-server, modding, model-context-protocol, redcode, tweakdb, wolvenkit

## 简介

Cyberpunk 2077 modding tools for AI assistants over MCP: the game archives, CR2W files as JSON and node-by-node edits, textures, TweakDB, game sounds, export, import and pack, through REDbridge and WolvenKit's engine.
