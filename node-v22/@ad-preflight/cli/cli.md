# @ad-preflight/cli

> 标签: ad-compliance, ad-ops, ad-preflight, ad-rejection, ad-tech, adform, ai-ad-validation, ai-tool, banner-automation, banner-validation, cicd, cli-tool, clicktag-checker, cursor-rules, doubleclick, dv360, google-ads-validator, html5-ad-packaging, html5-ads, html5-banner, iab, marketing-tech, mcp, mcp-server, model-context-protocol, sizmek

## 简介

Validate, auto-fix, and package HTML5 ad creatives against IAB-standard sizes and Google display specs, with clickTag / Sizmek / Adform exit detection. CLI, CI/CD, and MCP server for Cursor.
