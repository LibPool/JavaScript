# @clawsjoy/dsh-egress-observer

> 标签: deepseek-harness, dsh, dsh-plugin, egress, observability, subprocess

## 简介

Record-only egress observation for tool subprocesses, attributed by DSH_TOOL_CALL_ID (Linux /proc; never blocks, never throws).
