# @mamba/sprite

> 标签: JavaScript

## 简介

O componente `Sprite` ajuda na criação de animações utilizando uma _SpriteSheet_. É recomendado que se utilize este componente no lugar de arquivos `.gif` por ter um desempenho melhor.
