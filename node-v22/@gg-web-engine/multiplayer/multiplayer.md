# @gg-web-engine/multiplayer

> 标签: browser-game, firebase, game-development, game-engine, gamedev, multiplayer, netcode, networking, p2p, peer-to-peer, physics, serverless, typescript, webrtc

## 简介

Peer-to-peer shared-world multiplayer for gg-web-engine: 2-8 players in one physics world over WebRTC, with Firebase or BroadcastChannel signaling
