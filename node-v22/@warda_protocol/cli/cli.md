# @warda_protocol/cli

> 标签: agent, agent-payments, cli, kaspa, spending-limits, warda, x402

## 简介

One short command for the whole life of a Warda grant: create it, see what it may spend, pay behind an HTTP 402, and read back every attempt. Adds no capability — the rules stay in @warda_protocol/core.
