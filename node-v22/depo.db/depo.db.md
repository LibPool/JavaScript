# depo.db

> 标签: database, discord, key-value, node:sqlite, quick.db, sqlite, wio.db, zero-dependency

## 简介

Zero-dependency key-value database for Node.js on the built-in node:sqlite. Drop-in replacement for wio.db and quick.db without native modules.
