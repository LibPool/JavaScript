# @vault77/summon

> 标签: cli, developer-tools, keychain, macos, memecoin, solana, solana-cli, solana-swap, trading

## 简介

A recovered VAULT77 relic for macOS operators. summonTheWarlord is a high-performance CLI for Solana swaps on macOS. Private keys rest in the macOS Keychain and are loaded into process memory only for local signing. Prefer executionMode=basic for RPC pref
