# @landifed/acamera

> 标签: JavaScript

## 简介

* Acamera建立在AgoraRTC的服务至上，依赖于agora-rtc-sdk与pixi.js  * 主要作用，创建音视频流信息对象，通过配置参数创建之后，可根据需要渲染到PIXI对象上  * 使用config配置基础参数信息  * getAgoraDevices 获取用户设备信息，也可以在ClientCamera中获取  * CreateClientCamera 创建当前客户
