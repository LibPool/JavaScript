# @simplijs/simplijs

> 标签: bridge, cdn, esm, html-first, javascript-framework, lightweight, no-build, reactive, ssg, ssr, time-travel, vanilla-js, zero-config

## 简介

SimpliJS — Ultra-lightweight JavaScript framework. Zero config, HTML-first reactivity, <20 KB, native ESM/CDN, built-in routing/SSG/SEO, React/Vue/Svelte Bridge, and Time Vault state time-travel. The anti-build movement framework.
