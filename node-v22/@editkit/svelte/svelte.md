# @editkit/svelte

> 标签: @editkit/svelte, contenteditable, editkit, editkit-svelte, editkit-text-editor, rich-text-editor, svelte, svelte-editor, svelte-rich-text-editor, svelte5, sveltekit, sveltekit-editor, sveltekit-rich-text-editor, table-editor, wysiwyg, wysiwyg-editor

## 简介

Svelte and SvelteKit rich text editor action with tables, color picker, and no third-party editor engine. Supports Svelte 3, 4, and 5.
