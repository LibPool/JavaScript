# @rockey2020/next-network

> 标签: @rockey2020/next-network, next-network

## 简介

A fetch-based, future-oriented construction of a new next-generation network request library, with an advanced request
queue task mechanism, as well as load-balanced request interface, to achieve a breakthrough in the number of concurrent
browser requests
