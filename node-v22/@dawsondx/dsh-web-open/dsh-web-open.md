# @dawsondx/dsh-web-open

> 标签: browser, bundle, deepseek-harness, dsh, open, plugin

## 简介

A DeepSeek Harness (dsh) bundle: when `dsh web` is ready, print the full GUI URL and open it in your default browser. Cross-platform, dependency-free, fail-safe.
