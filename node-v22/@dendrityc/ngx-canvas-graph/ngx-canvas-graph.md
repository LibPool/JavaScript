# @dendrityc/ngx-canvas-graph

> 标签: JavaScript

## 简介

This library provides the ngx-canvas-graph component (lib-ngx-canvas-graph) that renders graphs using the dagre graph layout algorithm (https://www.npmjs.com/package/dagre).
