# dsh-preview-blender

> 标签: 3d, blend, blender, deepseek-harness, dsh, dsh-plugin, glb, gltf, preview

## 简介

Preview Blender .blend files inside DeepSeek Harness: the Host half exports a cached GLB with Blender headless and the right-Sidebar document preview draws it in an interactive WebGL viewport with scene statistics.
