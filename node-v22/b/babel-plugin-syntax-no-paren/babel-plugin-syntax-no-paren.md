# babel-plugin-syntax-no-paren

> 标签: babel, babel-core, compiler, modules, no, parentheses, plugin, swift, syntax, transpile, transpiler

## 简介

Allows parentheses to be omitted in javascript 'if', 'while' and 'for'(each) statements
