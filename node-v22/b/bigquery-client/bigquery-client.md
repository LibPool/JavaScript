# bigquery-client

> 标签: analytics, batch-processing, bigquery, cache, client, cloud-sql, data-warehouse, database, gcp, google-cloud, materialized-views, metrics, orm, partitioned-tables, performance, query-builder, security, sql, streaming, typescript, validation

## 简介

A feature-rich Node.js client for Google BigQuery with support for CRUD operations, transactions, query building, and advanced features like aggregate functions, pagination, and logging.
