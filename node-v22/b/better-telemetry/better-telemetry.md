# better-telemetry

> 标签: bun, decorator, inspect, instrumentation, mcp, nextjs, observability

## 简介

Pluggable instrumentation for async data functions (`observe()` / `@observe()` + connectors). Ships with MCP stdio server for live inspection of results by AI agents (Claude, Cursor, etc.). Works in Bun, Next.js, and plain Node.js apps.
