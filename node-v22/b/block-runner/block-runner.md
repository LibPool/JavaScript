# block-runner

> 标签: agent, block-converter, block-editor, blocks, cli, content-pipeline, gutenberg, gutenberg-blocks, headless-gutenberg, html-to-blocks, wordpress, wordpress-blocks

## 简介

The layer between generated content and WordPress — convert what AI, agents, and design tools emit into clean, valid, native Gutenberg blocks, and validate every result. CLI + library.
