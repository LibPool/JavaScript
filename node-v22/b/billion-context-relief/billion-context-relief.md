# billion-context-relief

> 标签: acp, billion-context-dsh, compaction, context, dsh, dsh-plugin

## 简介

Agent-requested context relief for DSH — companion to billion-context-dsh (ACP). context_export moves a range to a temp file and leaves a path pointer (the model never reads it); context_delete drops a range with a DELETED REFERENCES marker; context_large
