# boxthis

> 标签: 14kb, critical-css, first-paint, progressive-rendering, slow-start, ssr, streaming, tcp, ttfb, zero-dependencies

## 简介

Reach the network floor: stream a budget-capped, JS-free critical shell that paints in the first network round-trip, then stream the rest — the build-by-construction companion to lightsout's network-floor analysis. Zero dependencies.
