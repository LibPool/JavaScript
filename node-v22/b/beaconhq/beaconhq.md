# beaconhq

> 标签: api-monitoring, apm, beacon, bullmq, cron, express, fastify, heartbeat, hono, koa, middleware, monitoring, nestjs, observability, telemetry

## 简介

Beacon Node.js client SDK — buffer per-request telemetry and ship it to the Beacon ingest API. Includes Express, Fastify, Koa, NestJS, and Hono middleware.
