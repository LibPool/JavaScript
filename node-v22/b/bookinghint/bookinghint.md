# bookinghint

> 标签: appointments, bookings, messaging, reminders, swagger

## 简介

A semi automated messaging framework by Joseph Cumines. Built on my propertyobject.js project, I have aimed to create a generic framework that can be easily adapted to as many applications as possible.
