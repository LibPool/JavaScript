# bun-unpacker

> 标签: bun, bun-build-compile, decompile, decompiler, elf, extract, mach-o, pe, reverse-engineering, single-file-executable, unpack, unpacker

## 简介

Decompile and unpack a Bun single-file executable: extract the JavaScript bundle, native addons, sourcemaps and embedded assets from bun build --compile output
