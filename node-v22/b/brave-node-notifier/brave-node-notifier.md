# brave-node-notifier

> 标签: growl, mac os x 10.8, notification, notification center, notify, notify-send, terminal-notifier, toaster, windows 8 notification

## 简介

A fork of a Node.js module for sending notifications on native Mac, Windows (post and pre 8) and Linux (or Growl as fallback)
