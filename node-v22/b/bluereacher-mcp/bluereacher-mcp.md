# bluereacher-mcp

> 标签: agent, api, bluereacher, imessage, mcp, model-context-protocol, sms

## 简介

Model Context Protocol server for Blue Reacher. Lets AI agents send iMessage, check delivery status, read conversations, and check iMessage capability over a dedicated line.
