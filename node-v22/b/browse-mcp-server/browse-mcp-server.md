> 标签: agentab, ai-agent, browsemcp, browser mcp, browser-automation, browser-control, browser-mcp, chrome, mcp, mcp-server, model-context-protocol

## 简介

Browser MCP server — alias package for AgenTab. Let AI agents drive a real Chrome browser with your logged-in sessions. Installs the agentab CLI.
