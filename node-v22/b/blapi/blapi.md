# blapi

> 标签: API, Node.js, auto, automated, bot, botblock, botlist, dbl, discorbotlists, discord, discord.js, discordbot, discordbotlist, discordbots, js, list, posting, stats, typed, typescript

## 简介

BLAPI is a package to handle posting your discord stats to botlists. It's intended to be used with discord.js, though you can also manually post your stats.
