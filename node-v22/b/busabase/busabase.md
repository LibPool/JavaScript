# busabase

> 标签: agent-workspace, agentic-ai, ai-agents, airtable-alternative, cli, database, human-in-the-loop, knowledge-base, local-first, mcp, notion-alternative, open-source, openapi, pglite, self-hosted

## 简介

Open-source database & workspace for AI agents: structured data, durable knowledge, reusable skills, runnable apps, and human review on the writes that matter. Local-first and self-hostable. Run it with `npx busabase server`.
