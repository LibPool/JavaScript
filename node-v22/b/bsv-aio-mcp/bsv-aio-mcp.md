# bsv-aio-mcp

> 标签: beef, bitcoin-sv, brc, bsv, knowledge-base, mcp, model-context-protocol, opcodes, runar

## 简介

Read-only BSV knowledge MCP server: pinned-snapshot answers for BRCs, Bitcoin Script opcodes, BEEF, Runar, the Tier 0 SDKs and the Craig Wright essay corpus. Never fetches live HTTP; never actuates.
