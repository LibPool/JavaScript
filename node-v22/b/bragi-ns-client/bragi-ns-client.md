# bragi-ns-client

> 标签: cache, dns, ipv4, ipv6, lookup, resolve4, resolve6

## 简介

An implementation to speed up the nodejs `dns.lookup` method by avoiding thread pool and using resolve4/resolve6 with DNS TTL values
