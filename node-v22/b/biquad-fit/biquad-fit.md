# biquad-fit

> 标签: audio, autoeq, biquad, dsp, eq, equalization, filter, frequency-response, headphone, iem, parametric-eq, peq, tuning

## 简介

Compute optimal parametric EQ filter parameters to match a measured frequency response to a target curve. Reverse-engineered from AutoEq into TypeScript. Zero dependencies.
