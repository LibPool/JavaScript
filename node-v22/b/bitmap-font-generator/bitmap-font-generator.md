# bitmap-font-generator

> 标签: bitmap-font, chinese-font, cjk, font-generator, lazy-loading, pixi, pixijs, sprite-sheet, unicode

## 简介

Generate bitmap font atlases with lazy-loaded Unicode subsets from TTF/OTF fonts for PixiJS.
