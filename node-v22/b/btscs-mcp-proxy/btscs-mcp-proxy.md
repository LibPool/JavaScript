# btscs-mcp-proxy

> 标签: btscs, claude-desktop, cline, cursor, mcp, model-context-protocol, stdio, workbuddy

## 简介

stdio ↔ HTTP 代理：让 Claude Desktop / Cursor / Cline / WorkBuddy 等 MCP 客户端连接 btscsapi PHP 端点（btscsapi/api/index.php?c=mcp），自动带上用户的 apikey 身份信息。
