# bunny-x402-cli

> 标签: 402, cli, evm, payment-required, payments, stablecoin, usdc, viem, web3, x402

## 简介

Command-line x402 client for testing payment gateways: create throwaway wallets, check balances, decode the protocol headers, verify a signature without spending, and run the full pay-and-settle flow. Chain, token, and facilitator agnostic.
