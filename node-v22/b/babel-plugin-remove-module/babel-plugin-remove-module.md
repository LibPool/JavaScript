# babel-plugin-remove-module

> 标签: JavaScript

## 简介

一个可以根据当前运行环境移除当前环境之外的babel插件.场景:例如有些代码只存在于开发环境,而不发布到测试环境.或者只存在于开发和测试环境,而不发布到生产环境
