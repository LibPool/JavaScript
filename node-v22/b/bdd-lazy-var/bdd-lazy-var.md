# bdd-lazy-var

> 标签: bdd, dsl, jasmine, jest, lazy, mocha.js, rspec, subject, syntax, variable

## 简介

Provides "ui" for testing frameworks such as mocha/jasmine which allows to define lazy variables and subjects
