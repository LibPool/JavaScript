# barkparty-commander

> 标签: JavaScript

## 简介

BarkParty Commander is a general command for all barkparty backend or task microservice use to cron command jobs such like Jobs, task throw SSH or throw route, this can be installed locally (npm i git-repo) or globaly (npm g i git-repo)
