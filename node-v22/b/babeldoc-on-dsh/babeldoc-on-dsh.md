# babeldoc-on-dsh

> 标签: babeldoc, deepseek-harness, dsh, pdf, plugin, translation

## 简介

BabelDoc-on-dsh: a DeepSeek Harness plugin bundle that translates PDFs through BabelDOC while keeping their original layout.
