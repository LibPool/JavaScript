> 标签: ai-tools, bunny, bunny-net, bunny.net, bunnycdn, cdn, cdn-purge, claude-code, cli, deploy, dns, edge-scripting, firebase-deploy, magic-containers, mcp, model-context-protocol, nodejs, static-deploy, static-site, storage, stream, typescript

## 简介

Bunny.net CLI + MCP server. Deploy static sites to Bunny Storage and purge CDN with one command. Manage Storage, Pull Zones, DNS, Stream, Edge Scripting from a single binary - plus AI-native MCP for Claude Code & Claude Desktop.
