# bitcoin-rpc-api

> 标签: api, bitcoin, bitcoind, client, jsonrpc, promise, rest, rpc

## 简介

A promise based modern full-featured Bitcoin Core REST and RPC Express middleware to execute administrative tasks, multiwallet operations and queries about network and the blockchain using URL structure exposed for easy interfacing with a bitcoind Bitcoin
