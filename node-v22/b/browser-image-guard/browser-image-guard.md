# browser-image-guard

> 标签: browser, compression, exif, file-type, heic, image, magic-bytes, security, upload, validation

## 简介

Harden browser image uploads in one call: magic-byte validation, HEIC to JPEG, EXIF-stripping compression, worker-with-main-thread-fallback, and safe filenames.
