# bootstrap-lombardia

> 标签: css, framework, front-end, mobile-first, responsive, sass, web

## 简介

Bootstrap Lombardia è una customizzazione di Boostrap Italia per la creazione di applicazioni web conformi alle Linee Guida per il design e l’identità visiva digitale di Regione Lombardia
