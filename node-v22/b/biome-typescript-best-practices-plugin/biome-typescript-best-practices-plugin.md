# biome-typescript-best-practices-plugin

> 标签: best-practices, biome, biome-plugin, gritql, lint, type-safety, typescript

## 简介

Biome plugin that enforces TypeScript best practices — no `as` assertions, no `in` operator, no empty-object reduce accumulators, no enums, no dynamic delete, and safe array sorting.
