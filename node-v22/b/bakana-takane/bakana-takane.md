# bakana-takane

> 标签: bioinformatics, scRNA-seq, single-cell

## 简介

Extensions to the bakana single-cell analysis pipeline to accept takane-formatted datasets and results. This facilitates interoperability with the rest of the ArtifactDB ecosystem.
