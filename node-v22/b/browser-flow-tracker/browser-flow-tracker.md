# browser-flow-tracker

> 标签: api, api-documentation, cdp, chrome-devtools-protocol, claude, cursor, har, mcp, model-context-protocol, network, network-flow

## 简介

Record and document the API flow of any Chromium browser page (Brave, Chrome, Arc, Edge) via the Chrome DevTools Protocol. Ships as a local MCP server for Claude/Cursor and a CLI. Emits structured JSON + HAR + a Markdown flow-doc.
