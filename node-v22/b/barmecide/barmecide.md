# barmecide

> 标签: controllers, hook, models, sails, sails.js

## 简介

A castle of fog; a mirage; "superpowers for your Sails.js hooks." This library provides a set of features from the (rightfully) discontinued marlinspike, while adding safety features and resolving issues with Sails v1.
