# blinescan

> 标签: JavaScript

## 简介

**BLineScan** is a CLI tool that scans your web project’s **HTML**, **CSS**, and (soon) **JavaScript** source code to analyze browser compatibility using the **Baseline** dataset.   It generates a detailed, visual **compatibility report** that can be view
