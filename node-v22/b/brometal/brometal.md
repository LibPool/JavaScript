# brometal

> 标签: 3d, compiler, glsl, gltf, gpu, graphics, instancing, renderer, rendering, shader, shaders, typescript, webgl, webgpu, wgsl

## 简介

Write shaders in TypeScript, compiled at build time to WGSL, with a tiny WebGPU runtime. Write TypeScript. Lift Shaders. Ship Shredded.
