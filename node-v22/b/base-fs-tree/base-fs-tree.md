# base-fs-tree

> 标签: api, app, application, archy, base, baseplugin, building-blocks, create, file, files, framework, fs, plugin, plugins, tool, toolkit, tools, tree

## 简介

Base plugin for creating file trees using archy. Requires the base-fs plugin, but can also be used as a gulp plugin.
