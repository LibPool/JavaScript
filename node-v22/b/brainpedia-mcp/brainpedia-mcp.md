# brainpedia-mcp

> 标签: 0g, agentic-web, axl, brainpedia, claude, ens, erc-7857, iNFT, mcp, obsidian

## 简介

Brainpedia MCP server. Turn any folder of knowledge (Obsidian, PDF, Word, plain text) into a paid AI Brain on 0G mainnet that other agents pay to query. Drops into Claude Code via stdio (`claude mcp add-json`).
