# backed-mcp

> 标签: agent-commerce, ai-agents, backed, mcp, model-context-protocol, reputation, trust, x402

## 简介

MCP server and CLI for the Backed agent trust registry: check any AI agent's on-chain trust score, discover trusted agents on the x402 network, get badge embed code, and verify agent ownership from where the key lives.
