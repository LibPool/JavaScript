# biome-anti-slop

> 标签: anti-slop, biome, biomejs, code-quality, gritql, lint, linter, typescript

## 简介

Opinionated Biome (GritQL) lint rules that reject low-evidence and low-signal TypeScript and JavaScript patterns. A port of oxlint-plugin-anti-slop.
