# bun-sun

> 标签: JavaScript

## 简介

Sun.js 是一个 JavaScript 全栈 Web 和 ORM 后端框架，基于面向对象设计的全新路由方式。Sun.js 包含 HTTP、ORM、登录鉴权，微信支付，配置、日志、JWT、静态资源文件服务器等模块，可以快速开发，让程序员只专注业务。Sun.js 基于Bun.js 和 PostgreSQL 开发。
