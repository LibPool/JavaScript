# botcms

> 标签: JavaScript

## 简介

Система управления для создания чат-ботов.   Позволяет поддерживать неограниченное количество ботов в рамках одного приложения на любых площадках. "Из коробки" поддерживаются Telegram и ВКонтакте, любые другие возможно подключить путем написания "драйверо
