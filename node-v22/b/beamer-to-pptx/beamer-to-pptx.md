# beamer-to-pptx

> 标签: JavaScript

## 简介

Command line tool to convert Beamer-generated PDFs to Powerpoint files, using SVGs for lossless conversion and including speaker notes.

## 官网

- npm 页面：https://www.npmjs.com/package/beamer-to-pptx
