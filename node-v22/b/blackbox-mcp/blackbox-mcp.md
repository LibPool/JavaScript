# blackbox-mcp

> 标签: ai-agent, blockchain, cross-chain, dkg, ecdsa, ethereum, mcp, model-context-protocol, privacy, solana, threshold-cryptography

## 简介

MCP server for AI agents to interact with the BlackBox privacy protocol — deposit, claim keys, withdraw across chains via 3-of-5 distributed threshold cryptography
