# babel-plugin-jsx-style-px-to-rem

> 标签: babel plugin, babel-plugin-jsx-style-px-to-rem, inline style px to rem, inline-style-px-to-rem, jsx style, jsx style px to rem, jsx-style-px-to-rem, px, px to rem, rem

## 简介

`babel-plugin-jsx-style-px-to-rem` 是一个 Babel 插件，用于将 JSX 和 `React.createElement` 中的 `px` 单位转换为 `rem` 单位。
