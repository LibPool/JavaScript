# baselinegrid.scss

> 标签: baseline, design-system, grid, responsive, sass, scss, typography, vertical-rhythm

## 简介

A modern SCSS toolkit for aligning text and layout to a baseline grid with configuration validation, responsive utilities, fluid spacing, and container queries.
