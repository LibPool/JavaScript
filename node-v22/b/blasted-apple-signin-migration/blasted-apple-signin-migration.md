# blasted-apple-signin-migration

> 标签: app-transfer, apple, firebase, firebase-auth, migration, sign-in-with-apple, transfer_sub

## 简介

Resumable CLI tool for migrating Sign in with Apple users in Firebase Authentication when an iOS app is transferred between Apple Developer teams.
