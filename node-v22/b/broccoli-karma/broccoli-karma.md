# broccoli-karma

> 标签: broccoli, karma

## 简介

CLI app that wraps Broccoli's watcher and Karma's runner, so that Karma will run on Broccoli builds.

## 官网

- 官网：https://github.com/thomasboyt/broccoli-karma
- 源码仓库：git://github.com/thomasboyt/broccoli-karma.git
- npm 页面：https://www.npmjs.com/package/broccoli-karma
