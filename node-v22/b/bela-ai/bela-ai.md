# bela-ai

> 标签: agent, ai, cpu, intent, mcp, nlu, offline-first, self-training, slot-filling

## 简介

Bela — small AI with big ambitions. A self-training, app-scoped agent engine: 1.5M parameters, trains in seconds on one CPU core, runs a real hotel. No GPU, no LLM API, MIT.
