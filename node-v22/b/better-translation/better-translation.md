# better-translation

> 标签: ai-translation, i18n, internationalization, localization, react, svelte, tanstack, translation, typescript, vite, vite-plugin

## 简介

Local-first Vite i18n plugin for React and Svelte that turns source copy into flat Locale value JSON, with optional AI translation.
