# basescope

> 标签: ai-agents, base, ethereum, evm, honeypot, mcp, model-context-protocol, onchain, rug-check, security, token-safety, viem, web3

## 简介

The read-only safety layer for onchain AI agents. A Model Context Protocol (MCP) server that gives AI assistants safe, read-only onchain tools on Base and EVM chains — token/contract safety checks, risky-approval detection, verified-source lookup, balance
