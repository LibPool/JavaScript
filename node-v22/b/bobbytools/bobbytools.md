> 标签: ai, aider, anthropic, api, claude-code, cli, cloudflare, failover, gemini, groq, llm, manager, openai, opencode, openrouter, provider, proxy, rate-limit, round-robin, router, translation

## 简介

AI Provider Manager, anti-429 Router & CLI Launcher. Pool multiple AI accounts with auto-rotation, cross-provider fallback, and on-the-fly format translation (Anthropic / OpenAI / Gemini / Responses), then point any CLI tool at one local endpoint
