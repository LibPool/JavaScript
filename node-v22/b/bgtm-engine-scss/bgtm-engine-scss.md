# bgtm-engine-scss

> 标签: JavaScript

## 简介

This is an engine which can be used in conjunction with [BGTM](https://www.npmjs.com/package/bgtm) for the purposes of compiling sass files in a consistent and repeatable manner across every project in an agency.
