# backlex

> 标签: baas, backend-as-a-service, backlex, client, realtime, rest, sdk, typescript

## 简介

Typed TypeScript client for the backlex API — auth, collection CRUD, query builder, realtime, storage, jobs, flows, flags, and offline sync. Zero required dependencies (`ably` is an optional peer, needed only by serverless deployments that use the signal
