# bathys-mcp

> 标签: ai-agents, deep-research, llm, local-first, mcp, model-context-protocol, search, web-search

## 简介

Unified local deep-research search service for AI agents — one pipeline (search → extraction → query distillation → cache), zero cloud quotas. MCP stdio server with native harness integration.
