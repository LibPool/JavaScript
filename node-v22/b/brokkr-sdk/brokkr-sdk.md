# brokkr-sdk

> 标签: JavaScript

## 简介

This SDK provides some functionality to make it easier to use brokkr strategies and portfolios in your application. With this SDK you can fetch the information about portfolios, user holdings, and detail on invest and withdraw in a portfolio.
