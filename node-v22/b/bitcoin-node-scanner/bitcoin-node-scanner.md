# bitcoin-node-scanner

> 标签: bitcoin, btc, crawler, dns-seed, getaddr, network, node, p2p, scanner

## 简介

Bitcoin node scanner that scans for BTC nodes via publicly known DNS, random IPs and user-specified IPs. Does scan peer's peers.
