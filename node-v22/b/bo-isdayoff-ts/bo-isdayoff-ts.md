# bo-isdayoff-ts

> 标签: JavaScript

## 简介

IsDayOff-TS is a TypeScript fork and improvement of [isdayoff](https://www.npmjs.com/package/isdayoff), an API wrapper for [isdayoff.ru](https://isdayoff.ru).
