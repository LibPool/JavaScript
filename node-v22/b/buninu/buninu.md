# buninu

> 标签: android, browser-terminal, bun, cross-platform, portable, pty, self-bootstrapping, shell, terminal, termux, userspace, web-terminal

## 简介

Buninu is a portable, self-bootstrapping Unix-like userspace built on Bun that runs across operating systems
