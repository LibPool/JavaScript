# browserheap

> 标签: agents, ai-agent, browser, chromium, claude-code, codex, headless, playwright, repl, tabs, web-automation

## 简介

A browser for AI agents where idle tabs sleep: real Chromium, a JavaScript REPL whose pages keep working through sleep and wake, and a CLI for Claude Code and Codex.
