# bottrunk-mcp

> 标签: ai-agents, algorand, bottrunk, mcp, model-context-protocol, usdc, x402

## 简介

MCP server that lets Claude, Cursor and any MCP agent buy BotTrunk services pay-per-call with USDC over x402 on Algorand — from the agent's own wallet.
