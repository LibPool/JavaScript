# b2n-pool-lastest

> 标签: JavaScript

## 简介

**##b2n-pool-lastest** <br> High performance Node.js (with native C addons) mining pool for CryptoNote based coins. Comes with lightweight example front-end script which uses the pool's AJAX API. Support for Cryptonight (Original, Monero v7, Stellite v7
