# blockly-workspace-notes

> 标签: annotation, blockly, blockly-plugin, comment, notes, serialization, sticky-notes, workspace-comment

## 简介

Sticky notes for a Blockly workspace: draggable, resizable, colour-coded comments with a title, that round-trip through JSON and XML.
