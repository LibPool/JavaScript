# bangumi-renamer

> 标签: anime, bangumi, cli, emby, infuse, jellyfin, kodi, media, movie, plex, rename, subtitle, tmdb, tv

## 简介

Rename anime/TV/movie files using TMDB metadata. Works with Infuse, Plex, Emby, Jellyfin, Kodi and more.
