# birdnode

> 标签: chrome, cli, cookie, cross-platform, graphql, scraper, search, tweet, twitter, x, x.com

## 简介

Cross-platform CLI for X (Twitter) — reads Chrome cookies and calls X's GraphQL APIs directly. No API key needed.
