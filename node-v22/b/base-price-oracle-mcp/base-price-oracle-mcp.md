# base-price-oracle-mcp

> 标签: aerodrome, ai-agent, ai-agents, autonomous-agent, base, base-chain, blockchain, claude, claude-code, defi, dex, erc20, ethereum, mcp, mcp-server, model-context-protocol, on-chain, price-oracle, token-price, uniswap, web3

## 简介

MCP server for AI agents to fetch real-time token prices on Base from on-chain DEX pools (Uniswap, Aerodrome). Pure on-chain price oracle with no external API dependencies.
