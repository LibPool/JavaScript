# brasil-data-mcp

> 标签: ai-tools, brasil, brasilapi, brazil, cambio, cdi, cep, claude, cnpj, cpf, cvm, ddd, ibge, ipca, isbn, mcp, model-context-protocol, registro-br, selic

## 简介

MCP server providing access to Brazilian public data (CNPJ, CEP, banks, holidays, DDD, ISBN, economic rates, exchange rates, CVM brokers, IBGE states/municipalities, .br domains) via BrasilAPI. Optional premium CPF and state tax ID lookups. Ships with MCP
