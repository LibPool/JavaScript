# brainiac-install

> 标签: bootstrap, brainiac, cli, installer, second-brain

## 简介

One-command bootstrap for the Brainiac 'brain' CLI engine — installs brainiac-cli from PyPI (uv/pipx/pip), verifies it, and initializes a vault.
