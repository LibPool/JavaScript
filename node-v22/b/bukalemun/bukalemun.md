# bukalemun

> 标签: accessibility, bauhaus, cdn, components, css, css-framework, dark-mode, design-system, glassmorphism, neobrutalism, neumorphism, no-dependencies, skins, themes, ui, vanilla-js, vaporwave

## 简介

One CSS + JS framework that wears 50 completely different visual languages — neo-brutalist, glassmorphic, terminal, Bauhaus, risograph, neon-sign and more. Zero dependencies, drop-in via CDN or npm.
