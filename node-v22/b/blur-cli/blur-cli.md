# blur-cli

> 标签: JavaScript

## 简介

"blur-cli 开发：" 一个node项目中的package.json中的devDependencies不会被下载 到项目中的node_modules中，反之dependencies会下载，因此一个 node项目中，重复依赖的问题的产生对象是dependencies，故通过 分析package.json中的dependencies字段，再去找每个字段在项目 node_modules对应的包，在去找该包下的package.json中的dependencies
