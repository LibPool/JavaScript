# bundlebd

> 标签: betterdiscord, betterdiscord-plugins

## 简介

A simple bundler for BetterDiscord plugins. Bundles plugins composed of multiple files/modules. Allows for the use of Typescript, JSX, CSS, CSS preprocessors, and more.
