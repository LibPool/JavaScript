# beckhoff-xts-viewer-3d

> 标签: 3d, beckhoff, gfx, hepco, linear-motor, react, react-three-fiber, three, threejs, viewer, xts

## 简介

Unofficial, independent React component for rendering Beckhoff XTS linear-motor systems in 3D using Three.js. Not a Beckhoff product and not affiliated with or endorsed by Beckhoff Automation GmbH & Co. KG.
