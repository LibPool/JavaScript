# browser-mock-api

> 标签: api, browser, development, fetch, frontend, http, interceptor, jest, middleware, mock, mocking, rest, routing, testing, typescript, vitest

## 简介

A comprehensive TypeScript library for intercepting and mocking fetch requests in browser environments. Features flexible routing, middleware support, stateful mocking, network delay simulation, and full TypeScript support for frontend development and tes
