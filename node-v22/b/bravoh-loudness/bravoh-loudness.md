# bravoh-loudness

> 标签: audio, bs1770, dbtp, dsp, ebu-r128, k-weighting, loudness, loudness-range, lufs, mastering, normalization, true-peak, typescript, zero-dependencies

## 简介

ITU-R BS.1770-4 / EBU R128 loudness meter in pure TypeScript. Integrated LUFS, loudness range, momentary & short-term, true peak. Zero dependencies, streaming or one-shot, browser + Node + CLI.
