# bazg-exchange-rate

> 标签: and, api, bazg, border, central-bank, chf, currency, customs, exchange-rate, exchange-rates, federal, for, forex, fx, office, official-rates, security, swiss, switzerland, typescript

## 简介

Official Swiss Federal Office for Customs and Border Security (Switzerland) daily exchange rates — 73 currencies vs CHF, history since 2000. Zero-dependency Node.js/TypeScript client.
