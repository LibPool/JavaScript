# backend-smith

> 标签: api-generator, backend-automation, backend-development, backend-scaffolding, backend-smith, boilerplate, cli-tool, code-generator, controller-generator, crud-generator, dto-creator, express-boilerplate, express-generator, module-generator, mongoose, node-backend, node-cli, nodejs-tools, openapi, orm, prisma, rest-api, route-generator, scaffolding-tool, schema-creator, service-creator, swagger, typeorm, typescript, validation-generator

## 简介

CLI that scaffolds a production-ready Express.js + TypeScript backend and generates full CRUD modules (schema, DTO, service, controller, route, validation) with Swagger/OpenAPI docs, from a simple field syntax. Supports Mongoose, TypeORM, or Prisma.
