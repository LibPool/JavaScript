# bsre-ui-kit

> 标签: JavaScript

## 简介

UI Kit resmi untuk pengembangan aplikasi di lingkungan BSrE. Dibangun menggunakan **Vue 3** dan **Tailwind CSS**, menyediakan komponen yang aksesibel, konsisten, dan siap pakai sesuai standar SPBE.
