# bijoy2unicode

> 标签: ansi-to-unicode, ascii-to-unicode, bangla, bangla-converter, bangladesh, bengali, bengali-converter, bijoy, bijoy-keyboard, bijoy-to-unicode, converter, doc, docx, odt, rtf, sutonny, sutonny-mj, unicode

## 简介

Convert legacy Bijoy / Sutonny MJ Bangla text and Word documents (.docx, .doc, .odt, .rtf, .html, .txt) to Unicode Bengali. Strict font-aware detection keeps English untouched.
