# better-auth-email-challenge

> 标签: auth, authentication, better-auth, better-auth-plugin, cross-device, email-otp, magic-link, otp, passwordless, sign-in

## 简介

Email-bound authentication challenge plugin for Better Auth. One challenge, multiple completion methods (approval link or OTP), with browser-bound session issuance for safe cross-device sign-in.
