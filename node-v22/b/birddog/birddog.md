# birddog

> 标签: JavaScript

## 简介

Birddog is a jquery plugin for initializing a pop-up that points to the targeted element, like a tooltip.  The trigger for the birddog can be remote or the targeted element.  Birddog elements can be grouped together in packs and shown as a slideshow for g
