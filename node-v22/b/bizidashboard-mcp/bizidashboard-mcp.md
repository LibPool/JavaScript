# bizidashboard-mcp

> 标签: bike-share, bizi, mcp, model-context-protocol, zaragoza

## 简介

Model Context Protocol server for BiziDashboard's Zaragoza bike-share analytics: stations, history, occupancy, alerts, mobility, and rebalancing.
