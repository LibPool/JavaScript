# best-frontend-monitor-sdk

> 标签: JavaScript

## 简介

这是用于浏览器端错误采集与上报的独立 SDK。它向前端监控服务的 `POST /report` 接口发送标准化事件，可作为 npm 包引入，也可构建为浏览器 `<script>` 文件。
