# bhokan-mcp

> 标签: bhokan, kanban, mcp, model-context-protocol, project-management

## 简介

Give Claude, Copilot, Cursor and other MCP clients hands on your Bhokan boards: read, create and move cards, run checklists, manage labels and members, all from a chat.
