# bootstrap-scss-only

> 标签: JavaScript

## 简介

[Bootstrap](http://getbootstrap.com/) CSS and SASS libraries only. No javascript, and more importantly NO depenedency on jQuery.

## 官网

- 官网：http://getbootstrap.com
- npm 页面：https://www.npmjs.com/package/bootstrap-scss-only
