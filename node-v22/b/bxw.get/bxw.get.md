# bxw.get

> 标签: bxw

## 简介

功能：1.随机颜色changeColor 2.数组去重newArr 3.数组冒泡排序 4.新闻数据网址newsUrl 5.淘宝网址tbUrl 6.获取文件方法getFile(文件路径，需求）需求：getFirstDirs获取第一层文件、getAllDirs获取路径下所有文件、getFilesUrl获取当前路径下文件的相对路径、getAllFiles获取当前路径所有文件、getAllRows获取当前路径下所有代码行数。需求要加“”使用/引号
