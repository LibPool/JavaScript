# budget-aware-mcp

> 标签: ai-agent, code-graph, code-intelligence, codebase-memory, graph-retrieval, mcp, model-context-protocol, sqlite, token-budget, tree-sitter

## 简介

Model-agnostic code memory MCP server. Budget-aware graph retrieval for AI agents — sub-millisecond queries, token budgeting, no embeddings, no API keys. Built on CodeGraphContext for 155-language tree-sitter indexing.
