# barshik-nepali-patro

> 标签: bikram-sambat, bs-calendar, nepal, nepali-calendar, nepali-date, nepali-patro, react-calendar, react-native-calendar

## 简介

A precise, zero-dependency Bikram Sambat (BS) calendar library for React & React Native with official Nepali month data, holiday support, and graceful fallback for future years.
