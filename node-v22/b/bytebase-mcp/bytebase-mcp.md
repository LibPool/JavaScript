# bytebase-mcp

> 标签: bytebase, database, database-migration, mcp, mcp-server, oauth2, schema-management, sql

## 简介

MCP server for Bytebase — SQL Editor, schema catalog and change plans over the Connect-RPC API, with OAuth 2.1 (PKCE) and a multi-process-safe rotating refresh token.
