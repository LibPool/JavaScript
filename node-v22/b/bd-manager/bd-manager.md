# bd-manager

> 标签: bd, brilliant-directories, cli, cms, git, post-types, widgets

## 简介

Multi-site Brilliant Directories content manager — Node.js CLI + local web dashboard for git-versioned pull/push of widgets, pages, post types, menus, forms and more across multiple BD sites. Bundles the official BD MCP server for Claude/AI integration.
