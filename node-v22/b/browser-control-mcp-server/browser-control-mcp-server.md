# browser-control-mcp-server

> 标签: ai-agent, automation, browser, browser-control, cdp, chrome, chrome-devtools-protocol, claude, dom-inspection, headless, mcp, model-context-protocol, puppeteer, screenshot, testing, web-automation

## 简介

MCP server that gives AI agents full browser control — navigate, click, type, scroll, screenshot, inspect DOM, and read console logs in both headless Puppeteer and real Chrome browser.
