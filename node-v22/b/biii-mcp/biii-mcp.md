# biii-mcp

> 标签: JavaScript

## 简介

Safe-to-pay & token-genuineness verdicts on Base as an MCP server. Fail-closed, non-custodial: is a token the genuine issuer's or a look-alike? is a wallet known-bad? Every verdict re-verifiable on-chain.
