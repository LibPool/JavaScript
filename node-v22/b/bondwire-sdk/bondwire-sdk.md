# bondwire-sdk

> 标签: agent, agentic, arc, bondwire, circle, escrow, ethers, reputation, stablecoin, streaming, usdc, verifier

## 简介

Tiny ethers v6 SDK for Bondwire on Arc testnet: AgentBond (reputation backed trust), StreamPay (continuous USDC settlement), CommitStakeV2 (bonded verifier escrow, pay only on verified PASS) and the Agent Passport reputation score.
