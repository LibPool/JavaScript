# bv2mp3

> 标签: JavaScript

## 简介

A tool to download all videos and convert to mp3 inside a video set of bilibili (also works for single video, of course).

## 官网

- 官网：https://github.com/wxsms/bilibili-video2mp3
- 源码仓库：git+https://github.com/wxsms/bilibili-video2mp3.git
- npm 页面：https://www.npmjs.com/package/bv2mp3
