# basicdeploy-mcp

> 标签: ai-agents, basicdeploy, containers, deploy, kafka, mcp, postgres, s3, streaming

## 简介

MCP server for BasicDeploy: lets AI coding agents deploy and manage containers, each with Postgres, S3-compatible storage, and a Kafka broker.
