# babel-jest-import-glob

> 标签: JavaScript

## 简介

Wrapper of [babel-jest](https://www.npmjs.com/package/babel-jest) that makes jest aware of wildcard glob imports using [babel-plugin-import-glob](https://github.com/novemberborn/babel-plugin-import-glob).
