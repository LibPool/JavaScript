# bunny-x402

> 标签: 402, bunny, bunny.net, bunnycdn, edge, edge-scripting, micropayments, payment-required, paywall, reverse-proxy, stablecoin, usdc, web3, x402

## 简介

Config-driven x402 (HTTP 402 Payment Required) paywall for Bunny.net Edge Scripting. Put any website behind a pay-per-request stablecoin paywall without touching the origin.
