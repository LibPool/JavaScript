# b64hash

> 标签: algorithm, base64, crypto, data, decoding, efficiency, encoding, fast, hash, hashing, integrity, optimization, performance, security, xxhash

## 简介

A fast and efficient (3.4kB) Base64 hashing library, optimized for performance and similar in operation to xxhash.
