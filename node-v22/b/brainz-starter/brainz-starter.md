# brainz-starter

> 标签: JavaScript

## 简介

This is a general template for ThreeJS applications. It uses [Parcel](https://github.com/parcel-bundler/parcel) to create the bundle and [Tweakpane](https://github.com/cocopon/tweakpane) for live updates.
