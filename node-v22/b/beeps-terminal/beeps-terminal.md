# beeps-terminal

> 标签: JavaScript

## 简介

A terminal dashboard for managing on-call incidents via the [beeps.dev](https://beeps.dev) API. Built with [OpenTUI](https://github.com/anomalyco/opentui) and the `@beepsdev/sdk`.
