# balukajs

> 标签: chalk, chokidar, cli, command line interface, command line tool, conversion, interfaces, jsdoc, json, ts, tsup, types, typescript, watch, watch mode

## 简介

Baluka (pronounce _balooka_) is a tiny library that takes your json file and gives you back a jsdoc types or typescript interfaces definition.
