# bitgpu

> 标签: 1-bit, binary, browser, inference, llm, low-bit, on-device, quantization, qwen3, webgpu

## 简介

Fast WebGPU runtime for 1-bit (binary-weight) LLMs in the browser. Bit-exact, zero runtime dependencies.
