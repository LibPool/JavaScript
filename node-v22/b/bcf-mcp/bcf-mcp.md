# bcf-mcp

> 标签: aec, bcf, bim, buildingsmart, ifc, mcp, model-context-protocol, openbim

## 简介

MCP server for BCF (BIM Collaboration Format): read, write and manage BCF topics, comments and viewpoints. Part of the Flinker OpenBIM toolchain.
