# bb-aws-amplify-react-native

> 标签: JavaScript

## 简介

aws-amplify-react-native is a JavaScript library for Frontend and mobile developers building cloud-enabled applications. Bambrew has forked v7.0.2 and is maintaining bb-aws-amplify-react-native library for its own consumption with its applications.
