# base64-2-img

> 标签: base64, base64-2-img, base64-to-image, convert, ecmascript5, image, image-to-base64, img-2-base64, javascript-library, nodejs, npm, string

## 简介

A library for converting an image url or file to base64 string and base64 string back to an image file.
