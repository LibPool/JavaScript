# bitunix-mcp

> 标签: bitunix, crypto, exchange, futures, mcp, model-context-protocol, spot, trading

## 简介

Secure MCP server for the Bitunix exchange (Spot + Futures). Read-only by default; trading tools are opt-in. No withdrawal or transfer capability by design.
