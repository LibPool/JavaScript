# boilermate

> 标签: authentication, boilerplate, boilerplate-generator, cli, drizzle, express, javascript, jwt, mongodb, mongoose, mysql, nodejs, orm, passport, postgresql, prisma, project-generator, rest-api, scaffold, starter-kit, template, typescript

## 简介

CLI to quickly scaffold production-ready Node.js apps with TypeScript/JavaScript, Prisma/Drizzle/Mongoose, JWT/Passport authentication, and multiple database support (MongoDB/MySQL/PostgreSQL)
