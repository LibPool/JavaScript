# bootstrapv5-wizard

> 标签: bootstrap, twitter, wizard

## 简介

This twitter bootstrap v5 plugin builds a wizard out of a formatter tabbable structure. It allows to build a wizard functionality using buttons to go through the different wizard steps and using events allows to hook into each step individually.
