# bothelp-mcp

> 标签: bot, bothelp, broadcast, claude-code, flow-builder, funnel, mailing, mcp, model-context-protocol, scenario, telegram

## 简介

MCP server to read and BUILD BotHelp bot scenarios and SCHEDULE broadcasts (Telegram/VK/MAX/WhatsApp) via the constructor's private WebSocket-RPC. Zero-dependency on Node >=22.
