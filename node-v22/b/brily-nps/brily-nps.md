# brily-nps

> 标签: brily, feedback, net-promoter-score, nps, survey, widget

## 简介

Framework-agnostic NPS widget loader for Brily. One mount() call drops the floating feedback bubble into any page (vanilla JS, Vue, Svelte, Solid, etc.).
