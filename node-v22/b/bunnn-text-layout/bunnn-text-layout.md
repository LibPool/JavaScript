# bunnn-text-layout

> 标签: JavaScript

## 简介

一个强大的字段编排工具，支持在同一个输入框中混合编辑常量文本和结构化变量（变量、枚举、字典）。支持光标插入、删除整体 Token、获取结构化数据等功能。
