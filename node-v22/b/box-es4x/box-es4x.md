# box-es4x

> 标签: box-es4x

## 简介

基于[vert.x](https://vertx.io)和[es4x](https://reactiverse.io/es4x/)的JavaScript轻量级高性能web开发工具箱, 结合了JS的灵活便捷性和Java平台丰富且成熟的资源。
