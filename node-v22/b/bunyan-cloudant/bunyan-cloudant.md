# bunyan-cloudant

> 标签: bunyan, cloudant, couchdb, log, logger, nodejs, stream

## 简介

This is a [bunyan](https://github.com/trentm/node-bunyan) plugin for [Cloudant](https://cloudant.com/). It allows you to 'stream' your bunyan logs to Cloudant.
