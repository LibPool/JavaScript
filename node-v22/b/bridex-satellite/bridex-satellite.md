# bridex-satellite

> 标签: JavaScript

## 简介

Join your own computer to a Bridex organization as an agent workstation: runs are claimed over an outbound connection and executed by your locally installed CLI (Claude Code, Codex, ...) with your local tools (Unity, Blender, MCP servers).
