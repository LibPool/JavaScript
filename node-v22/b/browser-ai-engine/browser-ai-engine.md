# browser-ai-engine

> 标签: browser-ai, llm, offline, rag, stt, tool-calling, tts, webgpu, webllm

## 简介

Offline-first LLM + STT/TTS engine for the browser. WebGPU inference via WebLLM, audio via Transformers.js, tool calling with Zod validation.
