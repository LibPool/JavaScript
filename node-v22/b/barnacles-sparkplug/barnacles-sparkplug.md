# barnacles-sparkplug

> 标签: Eclipse Sparkplug, IoT, MQTT, reelyActive

## 简介

Distribute ambient IoT sensor timeseries data via MQTT as Eclipse Sparkplug B payloads.  We believe in an open Internet of Things.
