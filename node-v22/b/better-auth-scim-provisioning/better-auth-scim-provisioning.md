# better-auth-scim-provisioning

> 标签: better-auth, entra-id, google-workspace, identity-provider, microsoft-365, provisioning, saml, scim, webhooks

## 简介

User provisioning for Better Auth: create, update and deactivate users in the apps they sign in to, over SCIM 2.0, Google Workspace, Microsoft Entra ID and signed webhooks.
