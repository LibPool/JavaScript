# brix-cms

> 标签: block-editor, blocks, cms, content-management, drag-and-drop, headless-cms, nextjs, open-source, page-builder, postgresql, prisma, self-hosted, sqlite, typescript, visual-editor

## 简介

Open-source self-hosted block-based CMS. Visual page builder, 38 blocks, drag-and-drop, headless REST API, Next.js 16, SQLite/PostgreSQL.
