# bharatlas-mcp

> 标签: bharatlas, boundaries, claude, collect, geo, geospatial, gis, india, llm, mcp, parquet, pmtiles

## 简介

MCP server for India's open geo data. Query layers, locate points, find nearby features, filter and group data. Also authors collect maps: register a share link, moderate contributions, and publish to the catalog.
