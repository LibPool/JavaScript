# belzium

> 标签: components, di, etl, framework, frontend, ioc, pipelines, reactivity, typescript, vdom

## 简介

Framework frontend minimalista en TypeScript con compiler propio (.bel), reactividad, componentes, DI/IoC y pipelines de datos — cero dependencias de runtime.
