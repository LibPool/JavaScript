# bogart-cors

> 标签: CORS, REST, bogart, framework, sinatra

## 简介

Bogart (written by Nathan Stott) now has CORS - however, the npm entry for Bogart has not been updated to reflect this.  Once Nathan publishes the latest version of Bogart to npm, this package will no longer be necessary.
