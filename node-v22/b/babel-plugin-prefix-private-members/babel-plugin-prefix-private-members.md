# babel-plugin-prefix-private-members

> 标签: babel, babel-plugin, mangle, minify, private, protected, terser, typescript

## 简介

Babel plugin that prefixes TypeScript private and protected class members, so a minifier can mangle them

- 源码仓库：git+https://github.com/mbraak/babel-plugin-prefix-private-members.git
