# buildsure

> 标签: automatic, build, buildsure, bun, clasen, ensure, incremental, install, monorepo, mtime, npm, pnpm, yarn

## 简介

Install + build your projects only when sources changed. Auto-detects pnpm/npm/yarn/bun.
