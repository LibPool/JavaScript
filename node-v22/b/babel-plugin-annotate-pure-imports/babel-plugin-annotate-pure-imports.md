# babel-plugin-annotate-pure-imports

> 标签: JavaScript

## 简介

A plugin that allows to annotate imported paths as pure to avoid side-effects for Terser.

## 官网

- npm 页面：https://www.npmjs.com/package/babel-plugin-annotate-pure-imports

## 历史版本号

- 当前版本：1.0.0-1

- 1.0.0-1

## 获取地址

- npm 安装：`npm install babel-plugin-annotate-pure-imports`
- npm registry：https://registry.npmjs.org/babel-plugin-annotate-pure-imports
- Node 要求：>=10
