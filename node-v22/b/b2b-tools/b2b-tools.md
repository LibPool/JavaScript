# b2b-tools

> 标签: JavaScript

## 简介

**b2b-tools** is an Angular 22 standalone component library for enterprise UIs. Zero runtime dependencies beyond Angular itself. Signals-based reactivity, strict TypeScript, and full CSS variable theming.
