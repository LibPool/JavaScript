# babel-plugin-decimal.js

> 标签: JavaScript

## 简介

> 处理代码中的运算，避免出现进度丢失 ```js 0.1 + 0.2 = 0.30000000000000004 0.3 - 0.1 = 0.19999999999999998 ```
