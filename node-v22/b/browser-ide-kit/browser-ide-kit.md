# browser-ide-kit

> 标签: code-editor, ide, monaco, react, seti-icons, webcontainer, xterm

## 简介

Reusable in-browser IDE building blocks: a resizable split-pane layout, Monaco editor, xterm terminal bound to a WebContainer, a Seti-iconed file tree, and Radix UI primitives. Framework for tools like tw-extension-maker.
