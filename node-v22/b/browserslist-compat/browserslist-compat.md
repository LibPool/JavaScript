# browserslist-compat

> 标签: browserslist, compat, engines, es-check, esbuild, oxc, rolldown, rolldown-plugin, target, tsdown, vite, vite-plugin

## 简介

Build targets from a package's browserslist and engines for tsdown, rolldown, Vite and esbuild, and a plugin that checks the output really runs on them
