# babystack

> 标签: ai-agents, cli, database, docker, ephemeral, fixtures, integration-testing, mysql, seed, testing, vitest

## 简介

Real MySQL, fresh every run — a local baby of your production stack. Seeded, disposable, real backing services for tests + AI agents. The flagship: re-exports the API and ships the `baby` CLI.
