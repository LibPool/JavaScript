# bear-notes-mcp

> 标签: ai-assistant, bear app, bear notes, markdown notes, mcp, mcp-server, notes management, productivity, typescript

## 简介

Opinionated MCP for Bear Notes. Relevance-ranked search across titles, bodies, hierarchical tags. Offline-first.
