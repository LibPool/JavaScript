# bing-wui

> 标签: JavaScript

## 简介

- 本项目仅仅作为vue组件封装练习使用 - 安装组件库 npm add bing-wui - 全局导入 import WUI form 'bing-wui'    import 'bing-wui/lib/w-icon.css'   Vue.use(WUI)
