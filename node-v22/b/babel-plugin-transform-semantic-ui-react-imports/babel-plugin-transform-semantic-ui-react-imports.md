# babel-plugin-transform-semantic-ui-react-imports

> 标签: babel, imports, plugin, semantic-ui-css, semantic-ui-less, semantic-ui-react

## 简介

Babel plugin that can convert semantic-ui-react module imports to default imports and add semantic-ui-css/-less imports.
