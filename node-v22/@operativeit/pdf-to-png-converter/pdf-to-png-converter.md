# @operativeit/pdf-to-png-converter

> 标签: pdf, pdf buffer to image, pdf file to image, pdf parse, pdf to image, pdf to png

## 简介

Node.js utility to convert PDF file/buffer pages to PNG files/buffers with no native dependencies.
