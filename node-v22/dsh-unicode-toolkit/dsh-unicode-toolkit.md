# dsh-unicode-toolkit

> 标签: codepoint, dsh, escape, fullwidth, normalize, plugin, unicode, utf8

## 简介

Unicode toolkit for DeepSeek Harness: inspect code points (U+, UTF-8 bytes, display width, category), escape/unescape text (js/json/html/url), and normalize or convert between full-width and half-width forms. Zero runtime dependencies, read-only.
