# @neutron-build/workflow

> 标签: durable-execution, event-sourcing, neutron, nucleus, replay, workflow

## 简介

Durable workflow engine for Neutron. Event-sourced replay on Nucleus: workflows that suspend, survive restarts, and resume days later.
