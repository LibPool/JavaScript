# @open-rlb/ng-bootstrap

> 标签: JavaScript

## 简介

Angular component library built on Bootstrap 5.3 (signals, OnPush), with timezone-aware date handling via [`@open-rlb/date-tz`](https://www.npmjs.com/package/@open-rlb/date-tz). Requires **Angular 22** (`>=22.0.0 <23.0.0`).
