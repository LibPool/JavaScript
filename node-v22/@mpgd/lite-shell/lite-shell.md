# @mpgd/lite-shell

> 标签: canvas, devvit, game-development, lightweight, mpgd

## 简介

Renderer-agnostic lightweight game shell (no Phaser): DPR-aware stage, scroll-safe tap input, idle-sleeping frame loop, and font subset loading. Ships a Canvas2D renderer.
