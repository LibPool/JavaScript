# @mpfe/mpa

> 标签: JavaScript

## 简介

map 是基于`redux`、`redux-saga` 做的非常浅的包装(浅的不能再浅)，将原来需要单独定义的 action、actionCreator、reducer、saga 定义到一个 model 对象上，然后 mpa 负责将定义的 reducer 和 saga 注册到 redux 中,并创建 action 函数仅此而已
