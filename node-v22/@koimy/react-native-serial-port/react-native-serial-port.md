# @koimy/react-native-serial-port

> 标签: react-native

## 简介

1. 在`package.json`里面的 `dependencies` 添加 `"react-native-serial-port": "github:Marcello168/react-native-SerialPort"` 2. 添加后 执行 `$ npm install ` 就会下载 3. 执行 如下命令 自动链接到原生库  `$ react-native link react-native-serial-port` 4. 在Android 目录下 的`build.gradle`文件里面的
