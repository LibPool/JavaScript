# @dsh-stack/dialects

> 标签: JavaScript

## 简介

The provider-wire-dialect abstraction: registers the `ctx.dialects` registry that concrete dialect extensions (`@dsh-stack/dialect-openai`, `-claude`, `-gemini`, `-code-assist`, `-antigravity`) plug into.
