# @dsh-stack/directory-picker-fix

> 标签: JavaScript

## 简介

Replaces harness's `directory-picker` row (`@deepseek-ai/dsh-host-directory-picker-auto`) with a statically-mounted equivalent, working around a loader-entry double-registration that only reproduces under a full Stack-scale boot (dsh-stack#188).
