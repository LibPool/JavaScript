# @freetts/mcp

> 标签: audio, claude, cursor, freetts, mcp, model-context-protocol, speech-to-text, text-to-speech, tts, voice

## 简介

FreeTTS MCP server: text to speech for Claude, ChatGPT, Cursor, VS Code, Codex and any MCP client. Free without an account, more with a FreeTTS key.
