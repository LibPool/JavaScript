# @niyankhadka/yantra

> 标签: architecture-diagram, cli, diagram, documentation, drawio, er-diagram, flowchart, html, interactive, mcp, mcp-server, mermaid, mind-map, offline, plantuml, sequence-diagram, state-machine, svg, visio, walkthrough

## 简介

Interactive, step-by-step diagrams and one-page answers from JSON: automatic layout, orthogonal edge routing and a validator. One offline HTML file; CLI, MCP server and browser playground.
