# @dotcms/ai

> 标签: AI, CMS, MCP, agent, agentic, dotCMS, model-context-protocol, runtime, sandbox

## 简介

The dotCMS agentic runtime — run model-written or human-written code safely against a dotCMS instance, with auth and policy owned in one place.
