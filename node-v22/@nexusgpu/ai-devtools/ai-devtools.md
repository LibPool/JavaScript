# @nexusgpu/ai-devtools

> 标签: JavaScript

## 简介

In-app AI devtools for React + Vue: click any element to file UX issues, browse API routes, visualize DB schemas, open data studio, track tasks across draft→plan→implement→verify, and drive Codex/Claude agents end-to-end without leaving your app.
