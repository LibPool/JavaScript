# @miden-sdk/vite-plugin

> 标签: blockchain, miden, plugin, rollup, vite, wasm, zk

## 简介

Vite plugin for Miden dApps: WASM dedup, COOP/COEP headers and a gRPC-web proxy. Run `npm create @miden-sdk@latest` to set up agent guidance.
