# @hashspan/viem

> 标签: ai-agents, evm, observability, opentelemetry, opentelemetry-instrumentation, otel, tracing, transactions, viem

## 简介

OpenTelemetry instrumentation for viem: records each transaction as a send span and each receipt wait as a linked confirm span.
