# @hashspan/cdp

> 标签: ai-agents, cdp, coinbase, evm, observability, opentelemetry, opentelemetry-instrumentation, otel, tracing, transactions

## 简介

OpenTelemetry instrumentation for the Coinbase CDP SDK: traces the transactions of CDP server accounts and the user operations of smart accounts.
