# @kiwa-test/qwikcity

> 标签: endpoints, kiwa, qwik, qwik-city, qwikcity, routeAction, routeLoader, testing, vitest

## 简介

Qwik City routeAction$ + routeLoader$ + Endpoints test adapter for kiwa — invoke action / loader / onGet|onPost handlers with simulated RequestEvent and capture JSON / redirect / status without a running Qwik dev server (part of the kiwa test framework fa
