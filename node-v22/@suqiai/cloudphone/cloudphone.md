# @suqiai/cloudphone

> 标签: cloudphone, openclaw, plugin

## 简介

OpenClaw CloudPhone plugin that gives AI agents cloud phone automation via natural language instructions. Submit tasks to the backend AI Agent and stream results via SSE.
