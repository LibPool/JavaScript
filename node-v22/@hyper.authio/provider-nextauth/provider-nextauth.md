# @hyper.authio/provider-nextauth

> 标签: authio, authjs, backchannel-logout, frontchannel-logout, next-auth, nextjs, oauth, oidc, provider, refresh-token, step-up

## 简介

Authio for NextAuth.js v4 and Auth.js v5, configured like the client in the console through NextAuth's own options (checks, client authentication incl. private_key_jwt, ID token algorithm incl. HS*): sign-in validated by @hyper.authio/client, token refres
