# @hyper.authio/bff

> 标签: authio, backend-for-frontend, bff, express, oauth, oidc, session, spa

## 简介

Backend-for-Frontend for Authio on Express: server-side sessions, login/logout/user endpoints, anti-forgery, token refresh, remote API proxy and back-channel logout. Tokens never reach the browser.
