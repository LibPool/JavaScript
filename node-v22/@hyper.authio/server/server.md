# @hyper.authio/server

> 标签: api, authio, authorization, jwt, oauth

## 简介

Protect a Node.js API with Authio: token validation (JWT or introspection), the caller with every form of permission (scopes, roles and permissions by source, groups, claims, organization, acr/amr), authorization rules, webhooks, forwarding and on-behalf-
