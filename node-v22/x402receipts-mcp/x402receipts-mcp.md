# x402receipts-mcp

> 标签: accounting, agents, base, mcp, model-context-protocol, receipts, reconciliation, solana, usdc, x402

## 简介

MCP server for x402receipts: record the x402 purchases an agent makes as reconciled, auditable receipts, and verify any receipt against the public ledger.
