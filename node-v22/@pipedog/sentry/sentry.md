# @pipedog/sentry

> 标签: conversational-ai, metrics, observability, pipecat, pipedog, realtime, sentry, voice-ai

## 简介

Sentry metrics for pipedog (pipecat.processors.metrics.sentry): SentryMetrics reports TTFB and processing time as Sentry transactions, with any Sentry JS SDK (Node, Bun, Deno, Cloudflare).
