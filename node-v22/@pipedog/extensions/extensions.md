# @pipedog/extensions

> 标签: conversational-ai, dtmf, ivr, pipecat, pipedog, realtime, telephony, voice-ai, voicemail

## 简介

Pipecat's extensions (pipecat.extensions) for pipedog: IVRNavigator for LLM-driven phone menu navigation with DTMF, and VoicemailDetector with TTSGate for outbound calls.
