# @pipedog/mcp

> 标签: coding-agent, docs, llms-txt, mcp, model-context-protocol, pipecat, pipedog

## 简介

A local stdio MCP server with the pipedog docs, for coding agents: list, search and read the pages, and look up the API of every @pipedog/* package. The docs ship with each release and work offline.
