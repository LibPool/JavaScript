# @pipedog/onnx

> 标签: conversational-ai, inference, onnx, onnxruntime, pipecat, pipedog, realtime, voice-ai, wasm

## 简介

A tiny ONNX inference backend for pipedog models (Silero VAD, Smart Turn): onnxruntime-node when installed, else onnxruntime-web (WASM), with a Cloudflare Workers variant.
