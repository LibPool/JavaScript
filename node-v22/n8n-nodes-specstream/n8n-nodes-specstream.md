# n8n-nodes-specstream

> 标签: b2b-leads, company-list, enrichment, google-maps-leads, google-sheets, grants, lead-generation, lead-list, lead-lists, live-web, local-business, mcp, monitoring, n8n-community-node-package, specstream, web-data

## 简介

Build lead lists from the live web in n8n: local businesses, companies, grants and jobs, each row with its source. Send them to Google Sheets, HubSpot or Slack. Priced per match.
