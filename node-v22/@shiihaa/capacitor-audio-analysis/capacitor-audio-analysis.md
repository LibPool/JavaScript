# @shiihaa/capacitor-audio-analysis

> 标签: analysis, audio, audio-analysis, avfoundation, biofeedback, breathwork, capacitor, ios, microphone, native, rms, wkwebview

## 简介

Native audio analysis for Capacitor iOS — bypasses broken WKWebView Web Audio API. Real-time RMS and frequency energy from the device microphone via AVAudioEngine.
