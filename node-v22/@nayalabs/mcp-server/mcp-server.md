# @nayalabs/mcp-server

> 标签: ai-tools, anthropic, claude, cursor, mcp, model-context-protocol, naya, price-intelligence, resale, secondhand

## 简介

Model Context Protocol server for the naya resale price intelligence API. Lets Claude, Cursor, and other AI agents check live secondhand market prices, p25/p75, deal scores, and cross-platform alternatives across Grailed, Poshmark, Depop, and Vinted.
