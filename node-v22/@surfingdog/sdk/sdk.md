# @surfingdog/sdk

> 标签: agents, bookings, ed25519, hmac, http-message-signatures, inbox, orders, signature, standard-webhooks, surfingdog, web-bot-auth, webhook, webhook-verification, webhooks

## 简介

Verify Surfing Dog Inbox webhooks and type their events; for a customer's agent, carry a person's pass, sign requests (sdi-agent/1, Web Bot Auth compatible), verify receipts and counter-sign them. WebCrypto only: no dependencies, runs unchanged on Node, W
