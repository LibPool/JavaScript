# @happy-technologies/design-system

> 标签: JavaScript

## 简介

Happy Technologies design system - warm/light Tailwind tokens, Inter/Jost fonts, Phosphor duotone icons, and presentational React primitives shared across HappyHive, HappyTechnologies, HappyKnowledge, ConfigBuddy, and PulsePlus.
