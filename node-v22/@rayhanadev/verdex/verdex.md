# @rayhanadev/verdex

> 标签: abac, authorization, authz, opa, policy, policy-engine, rbac, rules-engine, standard-schema, type-safe, typescript

## 简介

A small, type-safe, OPA-inspired policy engine for TypeScript. Rules are typed functions; queries and calls are fully inferred. Zero runtime dependencies.
