# @coinspace-social/agent-sdk

> 标签: agent, ai-agent, base, coinspace, onchain, sdk, viem

## 简介

TypeScript SDK for agents and scripts to interact with the CoinSpace on-chain social protocol directly -- no API, no server, bring your own wallet.
