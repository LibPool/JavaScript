# @pybara/pybara-js

> 标签: checkout, crypto, crypto-payments, donations, icp, internet-computer, payment, payments, pybara

## 简介

Accept crypto payments and donations with Pybara on any page — a callable checkout, in the stripe-js / paypal-js convention.
