# @flowlib/db

> 标签: drizzle, flowlib, schema

## 简介

Drizzle schemas + schema-merger + schema-generator for Flowlib core. Lightweight package consumable from any JS runtime (Node, Workers, edge) without pulling in the @flowlib/core executor.
