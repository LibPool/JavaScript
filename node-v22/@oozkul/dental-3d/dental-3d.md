# @oozkul/dental-3d

> 标签: 3d, clinic, dental, dental-3d, dental-chart, ehr, fdi, ngx-dental-viewer, odontogram, teeth, three.js, threejs, tooth

## 简介

Interactive 3D dental chart (odontogram) for the web: clickable teeth, FDI numbering, per-tooth status, framework-free, built on three.js.
