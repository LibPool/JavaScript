# @trackmedia/sdk

> 标签: api-client, scheduling, sdk, social-media, trackmedia

## 简介

Official TypeScript SDK for TrackMedia — connect social accounts, compose, schedule and publish posts, and read analytics. Isomorphic: Node 18+, browsers, workers.
