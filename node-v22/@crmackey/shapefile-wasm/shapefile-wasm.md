# @crmackey/shapefile-wasm

> 标签: arcgis, dbf, esri, geojson, gis, rust, shapefile, shp, wasm, webassembly

## 简介

Read and write ESRI Shapefiles from GeoJSON in the browser, Node and workers. Rust core compiled to WebAssembly.
