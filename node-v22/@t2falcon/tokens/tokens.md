# @t2falcon/tokens

> 标签: JavaScript

## 简介

Falcon design tokens — the compiled Falcon theme CSS (Tailwind v4 SSOT: all :root token variables, dark-mode overrides, keyframes, host-shell global font rules) plus the Falcon icon font and self-hosted webfonts. The base/preflight reset ships SEPARATELY
