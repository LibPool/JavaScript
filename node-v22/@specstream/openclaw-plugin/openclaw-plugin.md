# @specstream/openclaw-plugin

> 标签: agent-tools, lead-lists, live-web, mcp, openclaw, openclaw-plugin, specstream, web-data

## 简介

SpecStream plugin for OpenClaw: ask for any list in plain words and get every matching row from the live web, each with its source page, priced per match.
