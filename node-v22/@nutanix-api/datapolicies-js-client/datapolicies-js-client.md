# @nutanix-api/datapolicies-js-client

> 标签: Nutanix Data Policies APIs, nutanix

## 简介

The Javascript client for Nutanix Data Policies APIs is designed for Javascript client application developers offering them simple and flexible access to APIs that manage Policies for Disaster Recovery and Storage.
