# @frontmcp/storage-sqlite

> 标签: agentfront, better-sqlite3, frontmcp, mcp, model-context-protocol, session, sqlite, storage

## 简介

SQLite storage for FrontMCP: sessions, background tasks, elicitations and stream events in a local file, without Redis

- 源码仓库：git+https://github.com/agentfront/frontmcp.git
