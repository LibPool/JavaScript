# @frontmcp/plugin-webmcp

> 标签: agentfront, agents, browser, frontmcp, mcp, model-context-protocol, modelcontext, plugin, webmcp

## 简介

WebMCP plugin for FrontMCP - expose an in-browser FrontMCP server's tools to browser agents through document.modelContext

- 官网：https://frontmcp.dev/reference/plugins/webmcp
- 源码仓库：git+https://github.com/agentfront/frontmcp.git
