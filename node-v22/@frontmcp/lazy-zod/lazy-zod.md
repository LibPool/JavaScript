# @frontmcp/lazy-zod

> 标签: bundler, cold-start, edge, frontmcp, lazy, performance, schema, typescript, validation, zod

## 简介

Zod 4's z with compound schemas built on first use, for faster start-up. Exports z (lazy), eagerZ (Zod's own) and lazyZ

- 源码仓库：git+https://github.com/agentfront/frontmcp.git
