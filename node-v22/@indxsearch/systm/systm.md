# @indxsearch/systm

> 标签: buttons, component-library, components, css-modules, design-system, forms, indx, inputs, minimalist, react, react-components, typescript, ui, ui-kit

## 简介

Minimal design system and UI component library for React. Includes buttons, inputs, sliders, checkboxes, tables, and more. Built with CSS modules and customizable via CSS variables.
