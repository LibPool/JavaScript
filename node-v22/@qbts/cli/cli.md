# @qbts/cli

> 标签: cli, constellation, execution-engine, orchestration, pipeline, qbits, qbts

## 简介

qbts — a two-tier execution CLI: a classical/AI task-pipeline engine (shell/ai/http/write steps) plus a credential-free client for the qbits coordination fabric.
