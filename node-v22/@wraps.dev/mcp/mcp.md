# @wraps.dev/mcp

> 标签: ai-agent, amazon-ses, aws, aws-ses, bounce-handling, claude, deliverability, email, email-events, mcp, mcp-server, model-context-protocol, ses, suppression-list, transactional-email, wraps

## 简介

MCP server for Amazon SES. Send email from your own AWS account, check domains, suppressions and sandbox status. Wraps adds send history and delivery events.
