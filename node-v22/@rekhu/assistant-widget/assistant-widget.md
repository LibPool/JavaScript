# @rekhu/assistant-widget

> 标签: ai, assistant, chat, chatbot, copilot, customer support, next, nuxt, react, rekhu, vue, web component, widget

## 简介

The chat widget of Rekhu Assistant: a custom AI assistant inside your app, for your own customers. A framework-free web component for Vue, React, Nuxt, Next, Svelte or plain HTML, talking to a Rekhu server package in your back end, such as @rekhu/assistan
