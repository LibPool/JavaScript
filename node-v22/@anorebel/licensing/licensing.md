> 标签: activation, aes-gcm, bun, canonical-json, crypto, deno, ed25519, express, fastify, fingerprint, hmac, hono, jws, lic1, license, license-key, license-manager, licensing, node, offline-licensing, pbkdf2, pkcs8, postgres, rsa-pss, signed-tokens, software-licensing, sqlite, typescript

## 简介

Offline-capable licensing toolkit: canonical JSON, LIC1 signed tokens, key hierarchy, issuer lifecycle, HTTP handlers, client activation flow, and storage adapters — all in a single package mirroring the Go module layout.
