# @rjames86/homebridge-opensprinkler

> 标签: homebridge-plugin, irrigation, opensprinkler, sprinkler, supports-hap

## 简介

Homebridge plugin for OpenSprinkler irrigation controllers using HomeKit's native Irrigation System service, with MQTT-driven real-time updates.
