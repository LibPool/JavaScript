# @zadq/mcp

> 标签: accountability, agent-payments, agents, http-402, mcp, model-context-protocol, seller-verification, verifiable-accountability, x402, zadq

## 简介

Model Context Protocol server for the free seller-verification path of x402 endpoints: two tools an agent calls before paying, lookup_verdict and endpoint_status. JSON-RPC 2.0 over stdio; with no configuration every lookup answers "unknown" and nothing bl
