# @jsonjoy.com/collaborative-codemirror

> 标签: binding, codemirror, codemirror-editor, codemirror-editor-binding, collaborative, collaborative-editor, contenteditable, crdt, editor, input, json, json-crdt, multiplayer, textarea

## 简介

Binding for collaborative editing support in CodeMirror Editor. Connects JSON CRDT str node to CodeMirror Editor.
