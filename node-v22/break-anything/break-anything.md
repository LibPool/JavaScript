# break-anything

> 标签: agent, appsec, cve, mcp, osv, reachability, sast, sca, security, vulnerability

## 简介

One CLI and MCP server for coding agents to find vulnerabilities across code, dependencies, apps, and infrastructure — on targets you own or are authorized to test.
