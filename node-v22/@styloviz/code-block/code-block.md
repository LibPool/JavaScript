# @styloviz/code-block

> 标签: JavaScript

## 简介

Read-only source display with a zero-dependency highlighter for 7 languages. Four variants — block, multi-file tabs, diff (unified or split with per-hunk accept/reject) and terminal — plus streaming-safe rendering, line numbers, soft wrap, line highlighti
