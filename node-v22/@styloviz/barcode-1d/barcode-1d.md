> 标签: angular, barcode, code128, ean13, scanning, styloviz, svg, tailwind, ui-kit

## 简介

Code 128, EAN-13 and EAN-8 rendered as SVG from a real encoder: mod-103 and mod-10 check characters computed rather than trusted, EAN-13's leading digit carried in the left-half parity, subset-C packing so a long serial fits the label, spec quiet zones, a
