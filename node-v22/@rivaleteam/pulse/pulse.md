# @rivaleteam/pulse

> 标签: binary-protocol, double-ratchet, e2ee, end-to-end-encryption, isomorphic, noise-protocol, realtime, signal-protocol, websocket, x3dh

## 简介

End-to-end encrypted messaging fabric for the browser and Node: Noise transport, Double Ratchet payloads, a blind relay, and a tokenized binary wire format. Zero runtime dependencies.
