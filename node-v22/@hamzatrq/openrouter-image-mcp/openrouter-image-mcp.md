# @hamzatrq/openrouter-image-mcp

> 标签: ai, claude, gemini, gpt-image, image-generation, mcp, model-context-protocol, openrouter

## 简介

Model Context Protocol server exposing OpenRouter image-generation models (Gemini, GPT-5 Image, and any other image-capable OpenRouter model) with typed per-model parameters.
