# @wdl-dev/cli

> 标签: cli, cloudflare-workers, deployment, wdl, workers

## 简介

Companion CLI for the WDL platform (open-source, self-hostable): deploy Cloudflare Workers-style projects, manage WDL resources, and tail live worker logs.
