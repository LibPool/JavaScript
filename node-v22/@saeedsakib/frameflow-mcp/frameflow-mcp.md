> 标签: claude, codex, cursor, gemini, image-generation, mcp, modelcontextprotocol, nano-banana, omni, veo, vertex-ai, video-generation

## 简介

MCP server for Google image and video models (Nano Banana, Gemini Omni, Veo) on Gemini Enterprise Agent Platform, with a one-command service account setup for Claude Code, Cursor and Codex
