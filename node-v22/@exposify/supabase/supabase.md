# @exposify/supabase

> 标签: ai-agents, edge-functions, mcp, model-context-protocol, postgrest, supabase

## 简介

Expose a Supabase-backed app's database and edge functions to AI agents over MCP, generated from PostgREST + Row Level Security — RLS is the authorization layer, so agents can do exactly what the logged-in user can do.
