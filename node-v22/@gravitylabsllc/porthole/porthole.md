# @gravitylabsllc/porthole

> 标签: android, compose, debugging, jank, mcp, profiling

## 简介

MCP server and live timeline for Porthole: query a running Android app for recomposition counts, frame timing, main-thread stalls, navigation, state, in-flight work and logs, and capture and query Perfetto system traces.
