# @klaroshield/sdk

> 标签: ai, anthropic, budget, llm, middleware, observability, openai, pii, retries, runtime, secrets

## 简介

The AI Runtime every AI application installs on Day 1 -- retries, budget control, secret/PII redaction, structured output validation, and local logging for LLM calls. Zero required cloud account.
