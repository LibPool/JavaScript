# @motion-mcp/anatomy-engine

> 标签: JavaScript

## 简介

Species-aware SVG anatomy detection: classifies parts by name or geometry, matches them to species schemas (human biped, avian crow), and resolves semantic actions into per-anatomy animation queues.
