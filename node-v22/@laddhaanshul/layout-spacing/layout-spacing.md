> 标签: 8pt-grid, aspect-ratio, box, components, cross-platform, design-tokens, flex, layout, react, react-native, responsive, spacing, stack, ui

## 简介

A unified layout, spacing, responsive, and aspect-ratio system for React & React Native. Token-based 8pt grid spacing engine with Box, Flex, Stack primitives, responsive hooks, and AspectRatio component.
