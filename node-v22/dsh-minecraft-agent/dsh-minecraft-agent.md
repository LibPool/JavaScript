# dsh-minecraft-agent

> 标签: agent, bot, dsh, dsh-plugin, forge, minecraft, modded

## 简介

Minecraft agent for DSH: drive a real 1.20.1 Forge client over a localhost bridge — chat, gather modded blocks by registry name, build, and work the client GUI.

## 官网

- npm 页面：https://www.npmjs.com/package/dsh-minecraft-agent

- npm registry：https://registry.npmjs.org/dsh-minecraft-agent
