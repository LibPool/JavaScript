# @penpair/docker

> 标签: ai-agents, design-systems, developer-tools, docker, mcp, penpot

## 简介

Everything in @penpair/core, plus running Penpot in Docker on your computer: one instance per project, generated secrets, up and down, backup, verify and restore.
