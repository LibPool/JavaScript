# @penpair/web

> 标签: ai-agents, design-systems, design-tokens, developer-tools, mcp, penpot

## 简介

The penpair command for Penpot on the web (design.penpot.app or your team's own): guided setup, a safe write protocol, skills for AI agents. Includes everything in @penpair/core.
