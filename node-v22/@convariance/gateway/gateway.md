# @convariance/gateway

> 标签: ai-participant, claude-code, mcp, mcp-server, sse, transcript

## 简介

The convariance local gateway: one Node process bridging an MCP agent (Claude Code over stdio) and a live web session (HTTP + SSE), sharing one in-memory BridgeSession. Direct-drain mode out of the box — no API key required; plug a Classifier in for the r
