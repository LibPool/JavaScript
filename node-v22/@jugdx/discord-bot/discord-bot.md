# @jugdx/discord-bot

> 标签: JavaScript

## 简介

Discord Bot is a simple projects based on **[discord.js](https://github.com/discordjs/discord.js)** API. It helps you creating a Client (aka a Bot) and generating **events** or **commands** using **Typescript**.
