# @kblockai/client

> 标签: agents, approvals, gateway, k-block, langchain, mcp, model-context-protocol

## 简介

Connect an existing agent to the K-Block Gateway: an MCP client over Streamable HTTP with typed K-Block outcomes (completed, approval pending, denied with the policy's explanation…), approval waiting and resumption, typed errors, and an optional LangChain
