# @clawzam/adapter-serpapi-google-related-questions

> 标签: adapter, clawzam, serpapi, serpapi-google-related-questions

## 简介

Get expanded 'People Also Ask' results from Google. Requires a next_page_token from a prior Google Search API response's related_questions block.
