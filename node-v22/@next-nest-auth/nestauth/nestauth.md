# @next-nest-auth/nestauth

> 标签: access-control, auth, authentication, facebook-oauth, google-oauth, jwt, jwt-auth, jwt-strategy, nestjs, nestjs-auth, nestjs-jwt, nestjs-passport, nestjs-security, nodejs, oauth, oauth2, passport, refresh-token, rest-api, security, typescript

## 简介

Drop-in authentication module for NestJS: local (username/password) login, Google and Facebook OAuth2, and JWT access + refresh token issuance and validation, wired up via one NestAuthModule.forRoot() call. Stateless and API-first — pairs well with Next.j
