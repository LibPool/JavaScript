# @cryptocurpays/dsh-multi-directory

> 标签: cordis, cordis-plugin, deepseek-harness, dsh, multi-directory, plugin, sandbox, seatbelt, workspace

## 简介

Mount extra directories into one DeepSeek Harness session: read/write/edit/glob/grep work there, and the sandbox profile is widened so shell commands may write there too.
