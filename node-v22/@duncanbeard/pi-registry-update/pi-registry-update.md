# @duncanbeard/pi-registry-update

> 标签: minimum-release-age, npm-registry, pi, pi-extension, pi-package

## 简介

Registry-aware pi updates: when your npm registry holds back newly published packages, `pi update` installs the newest release it can serve and the update notice says when newer ones become installable.
