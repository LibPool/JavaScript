# duckhts

> 标签: bam, bioinformatics, duckdb, duckdb-extension, duckdb-wasm, genbank, genomics, gff, htslib, vcf

## 简介

DuckHTS DuckDB extension for duckdb-wasm: read HTS formats (BAM, CRAM, VCF, BCF, FASTA, FASTQ, GFF, GTF, BED, GenBank, bigWig, tabix) with SQL in the browser
