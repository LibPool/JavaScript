# @normbill/mcp

> 标签: e-invoice, e-rechnung, en16931, factur-x, kosit, mcp, mcp-server, model-context-protocol, xrechnung, zugferd

## 简介

MCP server for the normbill e-invoicing API: generate, validate, parse and explain XRechnung, ZUGFeRD/Factur-X and Peppol BIS 3.0 invoices from Claude, Cursor and other MCP clients.
