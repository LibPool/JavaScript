# @autter/runtime-cli

> 标签: cli, debug-id, error-tracking, nextjs, source-maps, sourcemaps, vite, webpack

## 简介

Readable stack traces for Autter Runtime: inject debug ids into JS bundles and upload their source maps (CLI, Vite/Rollup, webpack and Next.js plugins)
