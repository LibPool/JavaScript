# @82chart/map-kr

> 标签: cartogram, chart, choropleth, election, hexmap, korea, map, ssr, svg, tilemap, 시군구, 시도, 행정구역

## 简介

Korea maps for 82chart: a choropleth of the 16 provinces (with 전남광주통합특별시, or the 17 before July 2026), the 시군구 level, a tile map, and a hex map with one equal hexagon per 시군구; several series color each region by the one that leads there (election style).
