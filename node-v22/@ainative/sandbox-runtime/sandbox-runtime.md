> 标签: ainative, bubblewrap, cody, filesystem-restrictions, network-filtering, sandbox, sandbox-exec, seatbelt, security

## 简介

AINative Sandbox Runtime - A general-purpose tool for wrapping security boundaries around arbitrary processes. Based on Anthropic's sandbox-runtime (Apache-2.0).
