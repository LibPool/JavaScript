# @data-os/portal-mcp-init

> 标签: agent-skills, claude-code, codex, cursor, mcp, memory, model-context-protocol

## 简介

Point your coding agent's memory at the reporting portal's MCP server: installs a user-level skill, an agent-file rule, and (optionally) the MCP server entry for Claude Code, Codex and Cursor.
