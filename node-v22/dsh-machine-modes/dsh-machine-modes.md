# dsh-machine-modes

> 标签: deepseek-harness, docker, dsh-plugin, remote, ssh, wsl

## 简介

Session-level machine modes for DeepSeek Harness: run commands and file operations on the local host, a WSL distribution, a Docker container, or an SSH host, switchable mid-session, with tty and root escalation.
