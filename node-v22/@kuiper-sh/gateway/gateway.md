# @kuiper-sh/gateway

> 标签: gateway, kuiper

## 简介

Kuiper's gateway client: the key, the gateway's address, errors and retries. Shared by @kuiper-sh/models, @kuiper-sh/browsers and @kuiper-sh/sandboxes.
