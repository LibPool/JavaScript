# @kuiper-sh/sandboxes

> 标签: agents, code-execution, kuiper, sandbox, terminal

## 简介

Remote computers for your agents on Kuiper: create a sandbox, run commands, open a terminal, move files, serve a port at its own URL, hibernate it.

- 官网：https://kuiper.sh/docs/sdk/
