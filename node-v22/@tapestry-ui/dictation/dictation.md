# @tapestry-ui/dictation

> 标签: a11y, dictation, headless, preact, speech-recognition, speech-to-text, tapestry-ui, voice

## 简介

Speak instead of typing. A headless Preact hook over the browser's SpeechRecognition, with the iPhone quirks handled and a provider shape you can swap for a server transcriber.
