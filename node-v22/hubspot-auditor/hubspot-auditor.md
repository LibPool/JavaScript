# hubspot-auditor

> 标签: audit, claude, crm, gdpr, hubspot, hubspot-api, marketing-ops, mcp, mcp-server, model-context-protocol, revops, typescript

## 简介

Read-only MCP server that audits a HubSpot portal and reports what works, what is broken, what is missing, and what needs a person to confirm.
