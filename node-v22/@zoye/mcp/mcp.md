# @zoye/mcp

> 标签: contacts, crm, leads, mcp, model-context-protocol, zoye

## 简介

Zoye MCP server. Sync leads and contacts into Zoye from any MCP-compatible AI assistant (Claude Code, Cursor, Windsurf, Cline, Zed, and more) in about a minute.

- 官网：https://www.zoye.io/docs/website-api/mcp-server
- npm 页面：https://www.npmjs.com/package/@zoye/mcp
