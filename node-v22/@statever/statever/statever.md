# @statever/statever

> 标签: developer-tools, governance, pqdc, pqdx

## 简介

StateVer — Versioning standard for continuously-composed AI-native systems. Identifies the running state, not the shipped artifact. SemVer named what was released; StateVer names the state that is alive.
