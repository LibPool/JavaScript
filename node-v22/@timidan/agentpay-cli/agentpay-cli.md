# @timidan/agentpay-cli

> 标签: agents, casper, cli, mcp, payments, x402

## 简介

AgentPay CLI: check x402 charges before paying on Casper. Create operator sessions, issue scoped agent tokens, run payment checks, verify settlements, and fetch receipts.
