# @holeauth/adapter-drizzle

> 标签: auth, drizzle, holeauth, mysql, postgres, sqlite

## 简介

Drizzle factory-based adapters for holeauth core (users, sessions, accounts, verification, audit). Supports Postgres, MySQL, SQLite.
