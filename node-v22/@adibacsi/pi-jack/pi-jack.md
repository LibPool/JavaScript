# @adibacsi/pi-jack

> 标签: json-schema, pi, pi-extension, pi-package, subagents

## 简介

JACK (JSON Agent Contractor Kit): Pi extension for delegating to subagents under a JSON schema contract, for structured, reliable, and type-safe agent responses.
