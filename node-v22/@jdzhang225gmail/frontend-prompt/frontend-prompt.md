# @jdzhang225gmail/frontend-prompt

> 标签: JavaScript

## 简介

这是一个**前端开发辅助 CLI 工具**。通过零 Token 消耗的本地分析，将模糊的需求转化为**Intent-Alignment (意图对齐)** 模式的专业 Prompt，供 Agent 或开发者直接使用。
