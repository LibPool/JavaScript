# @antivamp_io/sdk

> 标签: anti-vamp, antivamp, identity, launchpad, solana, token

## 简介

Official AntiVamp SDK — cross-chain token identity protection for launchpads. Validate launches, verify signed decisions and webhooks, report lifecycle events.
