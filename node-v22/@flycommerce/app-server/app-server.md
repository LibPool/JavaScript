# @flycommerce/app-server

> 标签: ecommerce, embedded-apps, flycommerce, oauth, sdk

## 简介

Server-side building blocks for FlyCommerce apps: verify dashboard sessions, finish installs, call the store API as the user or the app, OAuth sign-in to third parties, and serve the app's pages.
