# @dr5hn/trello-cli

> 标签: atlassian, automation, cli, kanban, task-management, trello

## 简介

Generic Trello CLI in TypeScript with rate limiting, atomic card-claim protocol, structured JSON output, and an idempotent setup flow. Designed for autonomous-worker integrations and humans alike.
