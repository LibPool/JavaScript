# @tivility/dsh-tool-subagent-model

> 标签: deepseek-harness, delegation, dsh-plugin, model-routing, subagent

## 简介

Delegation tool with per-call model, provider, and reasoning-effort selection, for a main agent that dispatches subtasks across a fleet.
