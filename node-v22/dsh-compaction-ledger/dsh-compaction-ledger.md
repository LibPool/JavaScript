# dsh-compaction-ledger

> 标签: audit, compaction, context, deepseek-harness, dsh, dsh-plugin, memory

## 简介

Compaction ledger for the DeepSeek Harness: audit every context compaction (what was shadowed, when, at what token cost) and let the model recall pruned content on demand
