# @contensu/directus-extension-model-viewer-interface

> 标签: 3d, directus, directus-custom-interface, directus-extension, glb, gltf, model, obj, stl, three

## 简介

A Directus interface that renders 3D model files (glTF/GLB, STL, OBJ, PLY) from a file field in an interactive three.js viewer with orbit controls.
