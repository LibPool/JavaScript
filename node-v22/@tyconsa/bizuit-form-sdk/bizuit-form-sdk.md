# @tyconsa/bizuit-form-sdk

> 标签: bizuit, bpm, forms, nextjs, react, typescript, workflow

## 简介

Core SDK for Bizuit BPM form integration - handles authentication, process management, file uploads, instance locking, and DataService queries. Simplified single-URL configuration!
