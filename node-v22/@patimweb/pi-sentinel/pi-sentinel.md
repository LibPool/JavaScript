# @patimweb/pi-sentinel

> 标签: checkpoints, checks, extension, harness, pi, pi-coding-agent, pi-package, repair-loop, rewind, verification

## 简介

Verification harness for the pi coding agent: runs your checks when the agent edits and before it is done, sends it back when they fail, and checkpoints every run so it can be rewound.
