# @mukundakatta/pii-sentry-mcp

> 标签: agent-safety, claude, cline, cursor, llm, mcp, model-context-protocol, pii, privacy, redaction, security, windsurf, zed

## 简介

MCP server exposing pii-sentry: detect and redact PII (emails, phones, SSNs, credit cards, API keys) from text before AI processing. Built for Claude Desktop, Cursor, Cline, Windsurf, and Zed.
