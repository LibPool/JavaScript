# @vibeclipper/mcp

> 标签: ai, claude, cursor, mcp, model-context-protocol, reels, shorts, vibeclipper, video

## 简介

Connect any MCP client to VibeClipper — turn long videos into short vertical clips and publish them to YouTube Shorts and Instagram Reels.
