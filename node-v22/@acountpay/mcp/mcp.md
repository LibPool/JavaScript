# @acountpay/mcp

> 标签: acountpay, ai-agents, mcp, model-context-protocol, open-banking, payments

## 简介

Model Context Protocol server for AcountPay: let AI agents create pay-by-bank payments, check status, refund and manage webhooks with guardrails.
