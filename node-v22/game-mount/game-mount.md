# game-mount

> 标签: babylonjs, canvas, devicepixelratio, game-dev, mobile, pixi-react, pixijs, r3f, react, react-three-fiber, reactylon, strictmode, webgl

## 简介

Mount a game renderer into a parent-sized box: one DPR, quality and reduced-motion policy, with adapters for PixiJS, @pixi/react, react-three-fiber and Babylon.js (Reactylon). Each adapter needs only its own renderer installed.
