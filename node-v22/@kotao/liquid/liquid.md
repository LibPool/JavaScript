# @kotao/liquid

> 标签: JavaScript

## 简介

Kotao Liquid runtime (fidelity sub-project B, #701): a LiquidJS environment configured for Shopify-theme semantics — string templates only, no filesystem, edge-safe. Drops/filters/tags land in later slices.
