# @kotao/cli

> 标签: JavaScript

## 简介

Kotao CLI (ADR-0003) — storefront slice: the create-kotao-storefront scaffolder + `kotao storefront …` tooling. The Skeleton theme template lives in template/ (shipped as data, not a workspace member).
