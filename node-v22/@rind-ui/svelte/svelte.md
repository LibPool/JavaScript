# @rind-ui/svelte

> 标签: a11y, accessibility, components, design-system, headless, headless-ui, state-machine, svelte, svelte5, ui, wai-aria

## 简介

Accessible headless Svelte 5 components: behaviour, keyboard, ARIA and state, styled through data-* attributes. Every component ships a test driver.
