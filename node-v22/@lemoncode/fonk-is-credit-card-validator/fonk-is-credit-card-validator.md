# @lemoncode/fonk-is-credit-card-validator

> 标签: fonk, form validation, isCreditCard, sync validation, validate, validator

## 简介

This is a [fonk](https://github.com/Lemoncode/fonk) microlibrary that brings validation capabilities to validate if a field of a form is a valid credit card
