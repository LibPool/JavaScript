# @giaeulate/baas-sdk

> 标签: auth, baas, postgrest, realtime, rpc, sdk, storage, supabase

## 简介

Standalone TypeScript SDK for golang-baas (Supabase-style BaaS) — auth, data (PostgREST), storage, realtime, functions, RPC, admin APIs. Zero runtime dependencies.
