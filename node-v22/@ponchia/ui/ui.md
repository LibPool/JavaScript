# @ponchia/ui

> 标签: accessibility, cascade-layers, colorways, css, css-layers, dark-mode, data-visualization, design-system, design-tokens, framework-agnostic, icons, monochrome, nothing, oklch, ui, ui-framework, wcag, zero-dependencies

## 简介

CSS-first identity and UI layer for services, tools, sites, and reports — works in HTML, every framework, and PDF, no component runtime. Shared app shell, forms, tables, workflow chrome, plus opt-in analytical/report primitives. Monochrome with one ration
