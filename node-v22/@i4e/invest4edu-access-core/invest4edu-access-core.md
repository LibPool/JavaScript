# @i4e/invest4edu-access-core

> 标签: access-control, async-local-storage, mongoose, nfd, tenant-isolation

## 简介

Shared access-control primitives for NeoFindesk: tenant keystone, role capabilities, reportee tree, entity/role vocabulary, feature flags, and the unified access engine (registry schema, snapshot resolver, visibleWhen).
