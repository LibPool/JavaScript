# @html-schema/html-form-engine

> 标签: JavaScript

## 简介

`html-form-engine` 是框架无关的 HTML 表单模板核心库。它负责解析工程表单模板、构建字段 schema、管理字段值、校验字段值，并把运行时字段值序列化回 HTML 快照。
