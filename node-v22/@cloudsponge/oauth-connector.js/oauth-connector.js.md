# @cloudsponge/oauth-connector.js

> 标签: JavaScript

## 简介

This is the implementation of the CloudSponge Proxy URL as an npm package. It is meant to be hosted in the head of a page so that it can detect and redirect when the conditions are perfect (i.e. the user just completed the OAuth flow).
