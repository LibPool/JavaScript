# @movatec/rtc-sdk

> 标签: contact-center, haddacloud, infobip-rtc, movatec, sip, softphone, voip, webrtc

## 简介

Movatec RTC JavaScript SDK: llamadas de voz WebRTC (salientes a la red telefónica, entrantes al navegador y entre usuarios) desde tu CRM o aplicación web. Superficie compatible con infobip-rtc-js.
