# @bot403/node

> 标签: altcha, bot-protection, bot403, bun, captcha, cloudflare-workers, deno, forms, nodejs, proof-of-work, server, spam

## 简介

Bot403 for Node.js and other server runtimes: verify form tokens and read statistics. Typed, no dependencies. Works in Node.js 18+, Bun, Deno, Cloudflare Workers and Next.js.
