# @purea/dsh-mcp-manager

> 标签: cordis, deepseek-harness, dsh, mcp, model-context-protocol, plugin, settings

## 简介

Visual MCP server manager for DeepSeek Harness (DSH 0.1.5-rc.1, web profile): inspect live MCP servers, add/remove rows in the profile patch file, enable/disable, test connectivity, and read the live fiber/tool status.
