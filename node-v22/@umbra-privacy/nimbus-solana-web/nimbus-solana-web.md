# @umbra-privacy/nimbus-solana-web

> 标签: JavaScript

## 简介

The Solana SDK for browsers with every dependency filled: load it for a cluster from its bundled preset, open a session for the connected wallet, and run the flows, with crypto in WASM, IndexedDB storage, the prover's WASM, the service clients and @solana
