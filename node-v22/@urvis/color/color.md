# @urvis/color

> 标签: JavaScript

## 简介

A **CSS Color Module 4** toolkit: parse, convert, serialize, gamut-map, interpolate, and analyze colors. A pure, tree-shakeable functional core with an ergonomic, **Temporal-shaped** immutable `Color` class on top.
