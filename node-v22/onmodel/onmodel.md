# onmodel

> 标签: claude-code, gemini, icons, image-generation, onmodel, sprite-sheet, sprites

## 简介

The onmodel command under its plain name: `npx onmodel` runs @akins20/onmodel, images, sprites and sets kept on model with Gemini's image models.
