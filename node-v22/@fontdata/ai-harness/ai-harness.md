# @fontdata/ai-harness

> 标签: ai, claude-code, fontdata, harness, scaffold, slash-commands

## 简介

Harness de engenharia com IA da Fontdata para Claude Code: roda os slash commands direto na pasta do projeto via npx, sem instalar nada — ou instala-os em .claude/commands.
