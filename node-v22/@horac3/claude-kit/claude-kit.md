# @horac3/claude-kit

> 标签: agents, ai, claude, claude-code, developer-tools, golang, typescript

## 简介

A drop-in Claude Code setup for Go and TypeScript projects: token-lean context, model routing, file-based handoffs, and hook-enforced safety.
