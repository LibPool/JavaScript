# @hamolus/mcp

> 标签: agent, ai, cloudflare, hamolus, mcp, model-context-protocol

## 简介

Model Context Protocol server for Hamolus: exposes the core API (collections, records, media, files, panels, lands) as MCP tools over Streamable HTTP on Cloudflare Workers.
