# @kundlit/mcp

> 标签: astrology, jyotish, kundali, mcp, modelcontextprotocol, panchang, vedic-astrology

## 简介

Thin stdio bridge to the hosted Kundlit Vedic astrology MCP server (panchang, muhurta, kundali, matching, doshas, numerology). No API key.
