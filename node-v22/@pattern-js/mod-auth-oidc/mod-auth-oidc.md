# @pattern-js/mod-auth-oidc

> 标签: auth, login, mod, oidc, openid-connect, pattern, sso

## 简介

OIDC login for Pattern — sign users in with Google, Microsoft, Keycloak or any OpenID Connect issuer. Authorization-code flow with PKCE, ID tokens verified with jose, sessions minted by mod-identity. Code-configured (a small wrapper mod); several provider
