# @ouvarov/scroll-parallax

> 标签: animation, animation-timeline, css, parallax, react, scroll, scroll-driven, view-timeline

## 简介

Scroll parallax for React, under 1 KB per component. Translate, opacity, scale, rotate, stagger, plus FadeOnView, RevealOnView, ScrollProgress and StickyShrink. Zero JS at runtime. Pure CSS animation-timeline: view() / scroll().
