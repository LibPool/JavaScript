# @orpc-ws/cookie-bff

> 标签: JavaScript

## 简介

Framework-free cookie-BFF core for ORPC-over-WebSocket: server-side session store seam, at-rest token encryption, and hardened cookie/CSRF helpers. Tokens never reach the browser. NestJS wiring lives in @orpc-ws/cookie-bff-nestjs.
