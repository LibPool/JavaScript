# @jdesignlab/button

> 标签: JavaScript

## 简介

사용자의 클릭으로 특정 동작을 실행하는데 사용됩니다. 다양한 액션을 트리거하거나, 사용자에게 여러 선택지를 제공하는 등 다양한 용도로 사용될 수 있습니다.
