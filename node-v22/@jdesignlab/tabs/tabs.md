# @jdesignlab/tabs

> 标签: JavaScript

## 简介

사용자가 여러개의 탭 중 하나를 선택할 수 있는 UI 요소입니다. 각 탭은 관련된 컨텐츠를 표시하고, 사용자는 탭을 선택하여 해당 컨텐츠를 전환할 수 있습니다.
