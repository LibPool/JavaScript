# @open-music-sdk/lib-playlists

> 标签: apple-music, apple-music-api, import, isrc, musickit, playlists, sdk, sync, typescript

## 简介

Playlists for the Apple Music API, where a playlist can only be made and added to: resolve tracks to the catalog, read a playlist, plan what is missing and append it. Developer token and Music User Token.
