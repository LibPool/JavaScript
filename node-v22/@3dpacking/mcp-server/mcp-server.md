# @3dpacking/mcp-server

> 标签: 3d-bin-packing, bin-packing, cargo, chatgpt, claude, container-loading, freight, load-planning, logistics, mcp, model-context-protocol, shipping

## 简介

Container and truck load planning for AI assistants. Describe a shipment in plain English, get back the containers it fits in and a link to the 3D load plan.
