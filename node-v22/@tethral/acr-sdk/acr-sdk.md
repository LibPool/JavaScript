# @tethral/acr-sdk

> 标签: acr, agent, composition, friction, interaction-profile, mcp, observability, registry, sdk, tethral

## 简介

Zero-dependency TypeScript SDK for the ACR (Agent Composition Records) network. Register agents, log interactions, query friction reports, check skills, and monitor system health.
