> 标签: futures, indicators, mcp, mcp-server, model-context-protocol, prop-firm, technical-analysis, trading

## 简介

An MCP server for AI assistants: futures prop firm rules with every rule's verification status and source, technical indicators tested against TA-Lib and pandas-ta, and Setup Odds' conditional frequencies on intraday bars. Read-only, no account, no API ke
