# @malloy-publisher/server

> 标签: ai-agents, analytics, bigquery, business-intelligence, data-warehouse, duckdb, llm, malloy, mcp, mcp-server, model-context-protocol, semantic-layer, semantic-model, snowflake, text-to-sql

## 简介

An open source MCP and REST server for Malloy semantic models, so AI agents, applications, and BI tools query one governed model instead of raw SQL.
