# workbuddy-auth

> 标签: codebuddy, deepseek, deepseek-harness, dsh-plugin, model-provider, workbuddy

## 简介

WorkBuddy / CodeBuddy 桌面端接入（DeepSeek Harness 插件）：自动发现桌面 App、解密其登录态、把国内版与国际版模型接入 DSH 并路由到正确区域网关，附带 UA 修复所需的主机信息、令牌自检与卡片 UI。前身为 dsh-workbuddy-connect。
