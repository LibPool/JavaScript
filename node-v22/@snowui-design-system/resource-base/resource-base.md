# @snowui-design-system/resource-base

> 标签: assets, design-system, icons, snowui, svg, ui, ux

## 简介

SnowUI Design Resource Base - Processes design assets from raw-assets folder, converts black icons to currentColor, generates multi-size bitmaps with 3x retina support, and publishes standardized assets with metadata.
