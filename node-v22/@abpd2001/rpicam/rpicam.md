# @abpd2001/rpicam

> 标签: cam, camera, pi, raspberry, raspberry-pi, raspberry-pi-cam, rpi, rpi-cam, rpicam

## 简介

A lightweight library to control CSI-2 camera modules via any raspberry pi can read camera module but is dependent to shell.
