# @mininglamp-oss/octo-daemon

> 标签: agent-runtime, ai-agent, claude-code, daemon, octo, openclaw

## 简介

Local agent runtime reporter for the OCTO platform — detects installed AI agent CLIs (Claude Code, OpenClaw) and reports status. This package resolves the prebuilt Go binary from the matching platform sub-package; no postinstall download.
