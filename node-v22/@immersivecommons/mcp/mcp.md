# @immersivecommons/mcp

> 标签: agent, ai, immersive-commons, immersivecommons, mcp, model-context-protocol

## 简介

MCP server connector for Immersive Commons (immersivecommons.com) — bridges stdio MCP clients (Claude Desktop, Cursor, Windsurf) to the hosted Streamable HTTP server at https://www.immersivecommons.com/api/mcp (138 tools).
