# @render-policy/angular

> 标签: a2ui, agent, angular, llm, markdown, sanitize, sanitizer, security, streaming, trusted-types, xss

## 简介

Angular adapter for @render-policy/core: [rpRender] directive and <rp-markdown> component that render agent content without [innerHTML] or bypassSecurityTrustHtml; A2UI Text and Image components under @render-policy/angular/a2ui.
