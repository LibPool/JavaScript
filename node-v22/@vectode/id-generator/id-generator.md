# @vectode/id-generator

> 标签: cli, id, id-generator, identifier, nanoid, pattern, sequence, snowflake, ulid, uuid, uuidv7

## 简介

Identifiers for Node.js, browsers, Deno and Bun: your own patterns with persistent sequences, plus UUID v4/v7, ULID, NanoID and Snowflake. No runtime dependencies.
