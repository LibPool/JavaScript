# @vectode/self-updater

> 标签: auto-update, cli, continuous-deployment, deploy, docker, docker-compose, github, gitlab, gitops, pm2, rollback, self-updater, systemd, webhook

## 简介

Keeps a server checkout in sync with its Git repository: deploys new commits or release tags, restarts PM2, Docker, Compose or systemd services, checks health and rolls back on failure. Polling or webhooks, no runtime dependencies.
