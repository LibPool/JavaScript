# @sundream-studio/mcp

> 标签: ai-agent, mcp, model-context-protocol, sundream, video-generation

## 简介

Drive Sundream Studio from your own agent. Bridges the hosted MCP endpoint to stdio and mirrors generated media to a local folder.
