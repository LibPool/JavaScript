# @ray-js/wechat-ms-basic

> 标签: JavaScript

## 简介

> @ray-js/wechat-ms-basic 该 SDK 提供了门锁小程序的基础能力，包括远程开锁、获取实时视频拉流地址、获取视频首桢图、判断设备类型等
