# @ray-js/audit-rating-web-component

> 标签: JavaScript

## 简介

基于 React 的审计评分 Web 组件，用于展示应用程序的审计评分和性能指标。该组件可以通过 npm 或 CDN 轻松集成到任何 Web 应用程序中。
