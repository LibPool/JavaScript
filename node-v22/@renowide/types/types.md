# @renowide/types

> 标签: canvas-kit, renowide, sdui, typescript, zod

## 简介

Canonical Canvas Kit v2 schema, expression grammar, and signing helpers for Renowide external agents. Mirror of the Renowide backend pydantic schema — any drift breaks canvas rendering.
