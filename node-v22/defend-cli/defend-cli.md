# defend-cli

> 标签: ai, claude-code, cli, code-review, codex, engineering-governance, git, whiteboard-defense

## 简介

Never ship code you can't defend. Automated whiteboard defense for AI-assisted code: a fresh Claude Code or Codex session interviews the author about the change and verifies the answers against the repository.
