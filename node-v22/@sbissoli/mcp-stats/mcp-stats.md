# @sbissoli/mcp-stats

> 标签: aggregation, mcp, open-data, percentiles, statistics

## 简介

Motor de estatísticas para tools MCP tabulares: média/mediana/distribuição/percentis/topN/agruparPor computados no servidor, com camada de exibição por idioma. Zero dependências.
