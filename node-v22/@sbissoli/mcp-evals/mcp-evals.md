# @sbissoli/mcp-evals

> 标签: evals, evaluation, mcp, open-data, tool-selection

## 简介

Harness de evals de seleção de tool para servidores MCP: extrator de catálogo (fake McpServer), validação de fixtures, scorer offline (top-1/top-k/por-área), gate de acurácia e runner via Anthropic Messages API.
