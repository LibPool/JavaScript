# @icjia/pdf-search-index

> 标签: astro, document, docx, fuse, mcp, nuxt, office, pdf, pptx, search, static-site, xlsx

## 简介

Full-text PDF, DOCX, PPTX, XLSX search for static sites — Apache Solr for client-side apps, without Solr.
