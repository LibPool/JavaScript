# @bryceo/keyvia

> 标签: hid, keyboard, keymap, mechanical-keyboard, qmk, terminal, tui, via

## 简介

A terminal UI for configuring VIA-compatible mechanical keyboards — remap keys, browse layers, edit macros, and test switches without leaving your terminal.
