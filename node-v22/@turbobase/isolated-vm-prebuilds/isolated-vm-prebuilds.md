# @turbobase/isolated-vm-prebuilds

> 标签: isolated-vm, prebuild, turbobase

## 简介

Prebuilt isolated-vm binaries for the platform/ABI pairs upstream does not ship. Consumed by @turbobase/cli's `turbobase ext extras install`; not useful on its own.
