# dsh-progress-widget

> 标签: agent, deepseek-harness, dsh, eta, plugin, progress, progress-bar, subagent, task-progress, task-tracker, widget, 进度条, 鲸程

## 简介

鲸程（Whale Run）：给 DeepSeek Harness 的任务进度条——阶段、百分比、当前动作、已用时间与预计剩余一目了然；多会话独立跟踪，子智能体任务默认折叠不刷屏。独立悬浮窗，不侵入 dsh 界面。
