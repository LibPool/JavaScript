# @codewright/install

> 标签: JavaScript

## 简介

One-command installer for Codewright: detects your agent harness (Claude Code, Codex CLI, OpenCode) and registers the MCP server + skill. Run with `npx @codewright/install`.

## 官网

- 源码仓库：https://github.com/highnet/codewright
- npm 页面：https://www.npmjs.com/package/@codewright/install

## 历史版本号

- 当前版本：0.1.4

- 0.1.4

## 获取地址

- npm 安装：`npm install @codewright/install`
- npm registry：https://registry.npmjs.org/@codewright/install
- Node 要求：>=24.18.0 <25
