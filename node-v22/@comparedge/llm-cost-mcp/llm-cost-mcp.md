> 标签: ai-budget, anthropic, claude, comparedge, cost-estimation, cursor, gemini, llm, llm-pricing, mcp, model-context-protocol, openai, token-cost

## 简介

MCP server that estimates the dollar cost of LLM API calls and workflows from token counts, using ComparEdge's verified per-1M-token prices for 60+ models across 16+ providers.
