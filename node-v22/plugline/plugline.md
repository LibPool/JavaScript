# plugline

> 标签: api-key, connectors, enterprise, integrations, logistics, oauth2, plugline, rate-limit, retry, sdk, telematics, tms, trucking, webhooks

## 简介

Vendor-agnostic integration SDK: declarative connectors, pluggable auth strategies, OAuth 2.0 authorization-code flow, retries and rate-limit handling, and a host adapter interface. Zero runtime dependencies.
