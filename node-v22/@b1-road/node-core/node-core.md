# @b1-road/node-core

> 标签: b1, bff, eduzz, eduzz-plat, iam, oidc, plat, rbac, road

## 简介

Framework-agnostic core for the Eduzz Plat Node BFF — OIDC login, session + token store, streaming proxy, permission primitives. Install a driver (@b1-road/express, @b1-road/nestjs) instead of this.
