# @liyuzhong/simple-ui

> 标签: sass ui组件, 前端ui组件, 无框架依赖ui, 移动端适配方案

## 简介

基于[sass](https://www.sass.hk/)编写的移动场景css库，包括主题色号配置、基准字号配置、原子样式(布局、字号、边距)、常用ui组件。
