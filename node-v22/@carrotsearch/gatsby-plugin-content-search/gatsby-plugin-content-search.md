# @carrotsearch/gatsby-plugin-content-search

> 标签: fuzzysort, gatsby, gatsby-plugin, search

## 简介

A Gatsby plugin for building Sublime-like client-side content search. Based on the fuzzysort library, ideal for searching API elements.
