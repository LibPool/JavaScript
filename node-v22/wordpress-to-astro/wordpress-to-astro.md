# wordpress-to-astro

> 标签: astro, cli, converter, markdown, migration, static-site, wordpress, wordpress-to-astro

## 简介

Convert a public WordPress site into an Astro project: Markdown posts and pages, images, permalinks kept, redirects, RSS and sitemap.
