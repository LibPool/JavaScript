# @wildboar/idm

> 标签: JavaScript

## 简介

TypeScript implementation of a the Internet Directly-Mapped (IDM) Protocol as described in [ITU Recommendation X.519 (2019)](https://www.itu.int/rec/T-REC-X.519/en).
