# dsh-session-inherit

> 标签: context, continue, deepseek-harness, dsh, dsh-plugin, handoff, inherit, session

## 简介

Inherit a long DeepSeek Harness session into a clean one: adds an "Inherit" row to the session "..." menu, mechanically extracts concrete anchors (task, recent instructions, files edited, recent tool failures, commands, todos) from the source session log
