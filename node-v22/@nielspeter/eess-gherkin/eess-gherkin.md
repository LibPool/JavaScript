# @nielspeter/eess-gherkin

> 标签: architecture, bdd, cucumber, eess, gherkin, testing

## 简介

Architecture testing for Gherkin feature files — the Gherkin dialect of the eess family. Features and scenarios as first-class elements, ready for cross-validation against a markdown corpus.
