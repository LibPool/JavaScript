# @voostack/screenstack-sdk

> 标签: android, app-store, ci, detox, flutter, ios, marketing, play-store, playwright, react-native, screenshots, screenstack, xcuitest

## 简介

ScreenStack capture CLI and SDK. One screenstack.yml drives web (Playwright), Flutter, iOS, Android and React Native captures, then uploads them to ScreenStack.
