# @rsc-kit/core

> 标签: bun, cloudflare-workers, elysia, hono, react, react-server-components, router, rsc, ssr, streaming, vite, vite-plugin

## 简介

React Server Components as a Vite plugin. Routing, streaming, server actions, typed urls and build-time prerendering — deploy to Bun, Node, Workers, Vercel or Deno.
