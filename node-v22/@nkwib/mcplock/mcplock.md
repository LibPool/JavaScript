# @nkwib/mcplock

> 标签: integrity, lockfile, mcp, model-context-protocol, rug-pull, security, streamable-http, supply-chain, tool-poisoning

## 简介

Lockfile-gated integrity pinning for MCP tool definitions. Hash them once, approve them once, fail CI when a server swaps them.
