# @sequentialos/sequential-flow

> 标签: async, bun, cross-runtime, deno, edge-functions, execution, fetch, firestore, flow-control, javascript, mysql, node, pause, postgresql, redis, resume, serverless, sqlite, state-management, storage, zero-dependencies

## 简介

JavaScript execution library with automatic pause/resume on fetch calls and custom storage. Built for edge functions, serverless environments, and cross-runtime compatibility. Lightweight alternative to FlowState.
