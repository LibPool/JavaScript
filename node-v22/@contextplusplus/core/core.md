# @contextplusplus/core

> 标签: JavaScript

## 简介

Shared engine for contextplusplus — converts public URLs and provider responses into LLM-friendly Markdown (domain, application workflows, providers, and Handlebars templates). Consumed by the contextplusplus CLI, HTTP API, and MCP server.
