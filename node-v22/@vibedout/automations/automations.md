# @vibedout/automations

> 标签: automation, cloudflare, d1, reminders, scheduler, workers

## 简介

Time-based automation rules for Cloudflare Workers: a rule (trigger events, flat conditions, steps with offsets from the event or from a time it carries, quiet hours, a frequency cap), a planner that turns an event into runs with deterministic ids, latene
