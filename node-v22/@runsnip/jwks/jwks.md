# @runsnip/jwks

> 标签: access-token, introspection, jwk, jwks, jws, jwt, mcp, oauth, oauth2, openid, rfc7662, rfc9068, verify

## 简介

Verify JWTs and OAuth access tokens against JSON Web Key Sets, with node:crypto alone: remote and local key sets, authorization server discovery, RFC 9068 access tokens, RFC 7662 introspection.
