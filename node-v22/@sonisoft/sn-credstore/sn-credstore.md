# @sonisoft/sn-credstore

> 标签: agents, ci, credentials, headless, keyring, now-sdk, oauth, servicenow, systemd-creds

## 简介

Headless-safe credential storage for the ServiceNow SDK. Replaces the OS-keyring backend so non-interactive agents can authenticate.
