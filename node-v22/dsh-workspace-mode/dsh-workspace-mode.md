# dsh-workspace-mode

> 标签: agent-preset, cordis, dsh, mode, permission, plugin, settings, workspace

## 简介

Per-workspace default permission preset and mode (agent preset) for DSH: assign a permission preset and/or an agent preset to each workspace directory from Settings, and every new session opened there starts with them.
