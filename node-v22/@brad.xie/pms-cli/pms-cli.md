# @brad.xie/pms-cli

> 标签: JavaScript

## 简介

PMS CLI 是面向 Codex、Claude Code、WorkBuddy 等本地工作台的 PMS 命令行入口。安装后提供一个位于 PATH 中的 `pms` 命令，通过自然语言工作台调用 CLI，再由 PMS 后端负责权限、流程模板、动态字段、业务校验、幂等和审计。
