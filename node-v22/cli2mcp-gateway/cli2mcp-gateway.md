# cli2mcp-gateway

> 标签: bearer, cli, express, http, mcp, model-context-protocol, oauth, stdio, wrapper

## 简介

Wrap any CLI as a Streamable HTTP MCP server with bearer / OAuth 2.1 / Auth0 auth, CORS, and rate limiting.
