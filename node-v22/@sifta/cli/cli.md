# @sifta/cli

> 标签: JavaScript

## 简介

Sifta CLI 是 Sifta Agentic Talent 的可选 command/connector 层，用于从终端调用 Sifta HTTP API、 管理本机 API key、返回稳定 JSON/trace，并同步 Sifta skills suite。它不替代宿主 agent 的 native GitHub search、academic/web search、网页阅读和推理能力。
