# dsh-memex

> 标签: deepseek, diary, dsh, dsh-plugin, harness, journal, lifelog, memex, worklog

## 简介

Memex for DeepSeek Harness (dsh) — every day it records what dsh did (sessions, prompts, tools, files, commands) as a Markdown diary. · dsh 的起居注：每天自动整理 dsh 当天做了什么，存成日记。
