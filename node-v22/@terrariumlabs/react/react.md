# @terrariumlabs/react

> 标签: anvil, dapp, eip-1193, eip-6963, ethereum, evm, nextjs, react, revm, simulator, storybook, testing, wallet, wasm

## 简介

Mount the Terrarium (chain in a Worker, EIP-6963 wallet, dev bar) from a React tree, for projects that cannot use the Vite plugin.
