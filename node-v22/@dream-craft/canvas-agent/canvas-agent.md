# @dream-craft/canvas-agent

> 标签: JavaScript

## 简介

本地 Canvas Agent 用来连接画布网页和用户电脑上的 Codex / Claude Code。本地开发时优先连接 `http://localhost:3000`，不需要先使用线上站点。
