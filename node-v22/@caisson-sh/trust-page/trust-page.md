# @caisson-sh/trust-page

> 标签: JavaScript

## 简介

Trust-page generator: a self-contained static HTML + JSON page, built from an evidence pack + its crosswalk rollup through allowlist-based redaction, that you host anywhere to show your own customers your compliance posture.
