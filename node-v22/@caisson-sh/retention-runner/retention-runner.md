# @caisson-sh/retention-runner

> 标签: JavaScript

## 简介

CCPA/GDPR right-to-erasure runner: pluggable multi-store erasure (object-storage purge, cascade DB delete, orphan sweep) with per-target error isolation and a reason-tagged audit row, scheduled via @caisson-sh/jobs.
