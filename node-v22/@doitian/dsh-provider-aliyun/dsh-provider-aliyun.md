# @doitian/dsh-provider-aliyun

> 标签: aliyun, aliyuncs, bailian, dashscope, deepseek-harness, dsh, dsh-bundle, dsh-plugin, llm, model-discovery, provider, qwen

## 简介

Aliyun DashScope (Bailian) model provider for DeepSeek Harness: registers an `aliyun` route whose model list comes from the configured endpoint itself, with a shipped fallback catalog for capacities and offline use.
