# @mauromeutudo/skill-disponibilizar-skills

> 标签: claude-code, meutudo, no-code, scaffold, skill

## 简介

Skill mestre — guia funcionários não-técnicos da meutudo a criar, empacotar e publicar a própria skill Claude Code no npm, com auto-update e reporting de erros via Slack injetados automaticamente
