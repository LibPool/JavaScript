# @osqd/archiverjs

> 标签: archival, archive, brotli, gzip, log-rotation, logrotate, logs, retention, rotation, typescript, zstd

## 简介

Seamless automatic archival for TypeScript and Node.js — rotate, compress and prune log files (and anything else that grows) while the program keeps running.
