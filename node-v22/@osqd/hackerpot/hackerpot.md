# @osqd/hackerpot

> 标签: canary, deception, decoy, honeypot, intrusion-detection, middleware, scanner-detection, security, typescript

## 简介

A honeypot for TypeScript servers — decoys, detectors and responses that catch attacker probes, mounted beside your application or run as a standalone service, with a dashboard to watch it.
