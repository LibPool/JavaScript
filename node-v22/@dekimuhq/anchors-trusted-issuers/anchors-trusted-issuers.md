# @dekimuhq/anchors-trusted-issuers

> 标签: allowlist, anchored-receipts, did-web, ed25519, governance, trust

## 简介

Signed allowlist + hash-chain governance for the Anchored Receipts protocol family. Default TrustedIssuersSource implementation backed by ar.trusted_issuers.v1 standalone-attestation. Pure library, zero runtime npm dependencies.
