# create-cratebase

> 标签: cratebase, create-app, expo, nextjs, scaffold, tanstack-start, vite

## 简介

Scaffold a new app on Cratebase — Next.js, Vite + React, TanStack Start, or Expo — wired up to the Cratebase SDKs out of the box.
