# @xqitw/dsh-skills-manager

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, skill, skills-manager

## 简介

dshweb 设置页 Skills 管理器：浏览、搜索、创建、编辑、删除 skills，切换模型可见性，ZIP 上传安装。纯 Node 实现，无 python/unzip 依赖。
