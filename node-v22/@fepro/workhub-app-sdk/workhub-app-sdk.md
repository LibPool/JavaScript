# @fepro/workhub-app-sdk

> 标签: iframe, postmessage, saas, sdk, tenant, workhub

## 简介

Client SDK for apps embedded in WorkHub. Use it inside an iframe app to call back into the host (identity, storage, notifications, events, API proxy).
