# @mmutils/assert

> 标签: assert, TypeScript assert, typed assert, type safe assert, type guard

## 简介

Assert and type guard functions that utilize TypeScript's type predicates and asserts to narrow down types in Control Flow Analysis at compile time and add fail safe at runtime. Makes refactoring easy and keeps the code clean, no clutter conditions. Suppo
