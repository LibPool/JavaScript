# @garagem-ai/site-sdk

> 标签: garagem, headless, imoveis, nextjs, real-estate, sdk

## 简介

Typed, runtime-agnostic SDK for building custom real estate sites against the Garagem platform. Drop into any Next.js (or other JS) project to fetch listings, sites and CMS data.
