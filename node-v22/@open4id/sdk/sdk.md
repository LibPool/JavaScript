# @open4id/sdk

> 标签: authentication, oauth, oidc, open4id, pkce, web-sdk

## 简介

Framework-agnostic Web JavaScript SDK for Open4ID player authentication (OAuth Authorization Code + PKCE, headless client and Shadow-DOM auth element).
