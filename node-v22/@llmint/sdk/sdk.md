# @llmint/sdk

> 标签: JavaScript

## 简介

Client SDK for emitting thread/span/feedback events to llmint (see the root [README](../../README.md) for the platform overview). `createClient({ apiKey, baseUrl })` returns a `LlmintClient`; `client.thread()` starts a thread and returns message/trace/exp
