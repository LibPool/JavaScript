# @shi-institute/vite-plugin-custom-elements-manifest

> 标签: JavaScript

## 简介

Vite plugin that generates a Custom Elements Manifest during the build of `@shi-institute/custom-elements`. Used internally by the `custom-elements` package; not intended for external use.
