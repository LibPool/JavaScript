# @th-batman/3d-viewer-angular

> 标签: JavaScript

## 简介

Official Angular component wrapper for `@th-batman/3d-viewer-core`. Renders photorealistic 3D jewelry and customizer canvases in Angular 18+ applications (including standalone components and legacy `NgModule` architectures).
