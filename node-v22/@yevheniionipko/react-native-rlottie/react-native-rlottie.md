# @yevheniionipko/react-native-rlottie

> 标签: android, animation, fabric, ios, lottie, native-component, new-architecture, react-native, rlottie, turbomodule

## 简介

High-performance Lottie animations for React Native, rendered natively via the rlottie C++ engine. Supports both the New Architecture (Fabric + TurboModules) and the Legacy Architecture.
