# @eventfabric/postgres

> 标签: cqrs, ddd, dead-letter-queue, dlq, domain-driven-design, event, event-driven, event-sourcing, event-store, eventfabric, events, eventsourcing, eventstore, multi-tenancy, multi-tenant, outbox, outbox-pattern, partitioning, pg, postgres, postgresql, projection, snapshot, typescript

## 简介

PostgreSQL backend for EventFabric: event store, outbox + DLQ, snapshots, catch-up / async projection runners, partitioning, conjoined + per-database multi-tenancy, migrations.
