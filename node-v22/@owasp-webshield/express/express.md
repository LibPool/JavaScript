# @owasp-webshield/express

> 标签: authentication, authorization, csrf, express, express-middleware, input-validation, middleware, owasp, owasp-top10, rbac, secure-coding, security, security-headers, ssrf, webshield

## 简介

Express adapter for OWL (OWASP Webshield Library): middleware for authentication, access control, CSRF, validation, security headers, SSRF checks and security error handling
