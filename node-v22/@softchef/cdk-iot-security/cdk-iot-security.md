# @softchef/cdk-iot-security

> 标签: Fleet-Provisioning, JITP, JITR, aws, cdk, construct

## 简介

This is a AWS CDK construct package surrounding the topic of the AWS IoT Device registration, mainly implementing the functionalities of JITP, JITR, and Fleet-Provisioning.
