# receivify

> 标签: bitcoin, crypto, crypto-payments, ethereum, invoice, non-custodial, payment-gateway, payments, receivify, stablecoins, usdt, webhook

## 简介

Official Node.js SDK for the Receivify crypto payment gateway — invoices, forwarding addresses, payment links and signed webhooks. Zero dependencies.
