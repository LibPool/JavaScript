# @tal-naeh/freelens-gpu-extension

> 标签: dcgm, extension, freelens, freelensapp, gpu, kubernetes, lens, monitoring, nvidia, openlens

## 简介

Freelens extension for GPUs — per-pod and per-device GPU utilisation, VRAM and power from dcgm-exporter or a per-process exporter, zero cluster footprint
