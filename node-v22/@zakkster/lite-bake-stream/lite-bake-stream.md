# @zakkster/lite-bake-stream

> 标签: binary, ingestion, json, lite-bake, sax, streaming, zero-gc

## 简介

Streaming byte-level JSON to LBK1 binary containers. Zero-GC, tree-shakeable, gigabyte-scale.
