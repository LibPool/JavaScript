# @zakkster/lite-delaunay

> 标签: arena, canvas, computational-geometry, data-oriented, delaunator, delaunay, esm, gamedev, geometry, half-edge, halfedge, mesh, mesh-generation, performance, pre-allocated, real-time, simulation, sweepline, triangulation, typed-array, typescript, voronoi, webgl, zero-allocation, zero-gc

## 简介

Zero-GC 2D Delaunay triangulation for per-frame use. Pre-allocated Int32Array arena, sweepline algorithm (Mapbox-style), half-edge mesh output. ~500 LOC, no dependencies, no per-frame allocations.
