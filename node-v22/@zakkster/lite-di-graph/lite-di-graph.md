# @zakkster/lite-di-graph

> 标签: chrome trace, dependency injection, di, dot, exporter, graph, graphviz, introspection, perfetto, typescript, zero-gc

## 简介

Read-only formatters/exporters over a lite-di-container describe() snapshot: JSON, Graphviz DOT, and Chrome Trace Event Format. Pure over the snapshot, fail-closed on a malformed shape.
