# @zakkster/lite-signal-gsap

> 标签: animation, canvas, game, gsap, interpolation, lite-signal, object-pool, overlay, performance, reactive, reactivity, signal, signals, smooth-follow, tween, tweening, twitch, webgl, zero-allocation, zero-gc

## 简介

Zero-GC bridge between GSAP and @zakkster/lite-signal. Pool-backed proxy tweens, reactive-target smooth-follow, auto-cleanup inside effects. No per-frame allocations.
