# @zakkster/lite-headless

> 标签: aria, custom-elements, headless-ui, primitives, reactive, signals, web-components, zero-gc

## 简介

Zero-dependency headless UI primitives -- 63 ARIA-correct factories + custom-element wrappers, with explicit state-attribute CSS contract. Zero-GC hot paths; reactive accessors via lite-signal.
