# @zakkster/lite-media

> 标签: breakpoints, container-query, esm, matchmedia, media-query, prefers-color-scheme, prefers-reduced-motion, reactive, responsive, signal, signals, ssr, style-query, twitch-extension, zero-allocation, zero-gc

## 简介

Reactive media, container-query, and preference signals for @zakkster/lite-signal. Wraps window.matchMedia and the browser's native @container evaluator in Signal<boolean>. Zero-GC steady state, scoped instances via createMedia().
