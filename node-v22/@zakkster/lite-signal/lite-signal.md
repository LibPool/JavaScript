# @zakkster/lite-signal

> 标签: computed, devtools, effect, fine-grained, introspection, object-pool, owner-tree, performance, reactive, reactivity, signal, signals, twitch-extension, zero-allocation, zero-gc

## 简介

Zero-GC reactive graph. Monomorphic object pool, versioned push-pull propagation, 32-bit modular versioning. Built for hot paths and long-running processes.
