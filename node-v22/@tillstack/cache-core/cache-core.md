# @tillstack/cache-core

> 标签: cache, edge, kv, pubsub, queue, redis, tillcache, tilldev

## 简介

TillCache client core — one HTTPS endpoint, one token: KV, queues and pub/sub over a Redis-compatible command API. Runtime-agnostic core shared by @tillstack/cache-node, @tillstack/cache-edge and @tillstack/cache-cloudflare.
