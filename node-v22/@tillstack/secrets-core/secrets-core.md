# @tillstack/secrets-core

> 标签: config, env, secrets, tilldev, tillsecrets, vault

## 简介

TillSecrets client core — pull encrypted config at boot over one authenticated endpoint. Runtime-agnostic core shared by @tillstack/secrets-node and @tillstack/secrets-edge.
