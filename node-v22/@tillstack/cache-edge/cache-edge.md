# @tillstack/cache-edge

> 标签: bun, cache, deno, edge, kv, pubsub, queue, tillcache, tilldev, vercel

## 简介

TillCache client for any edge runtime (Vercel Edge, Deno, Bun, browsers) — fetch-based, zero dependencies, KV + queues + pub/sub over one HTTPS endpoint.
