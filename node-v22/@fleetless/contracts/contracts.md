# @fleetless/contracts

> 标签: fleetless, json-schema, openapi, robotics, ros2

## 简介

Fleetless wire contracts: the bridge-cloud protocol, the REST API schemas and the error codes, as zod schemas with generated JSON Schema and OpenAPI artifacts.
