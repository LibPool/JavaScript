# dev-launcher

> 标签: ai-agents, claude-code, cli, codex, gemini-cli, launcher

## 简介

Abre tus proyectos con tu agente de IA (Claude Code, Codex, Gemini, Copilot, Cursor, OpenCode...) desde un menu en la terminal.
