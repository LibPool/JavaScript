# @opentyped/vite-express-rsc-oapi

> 标签: JavaScript

## 简介

This package adapts the RSC plugin's `route.ts` and `routes.tsx` conventions to OAPI's parser pipeline. It reads TypeScript source; it never imports route modules or executes middleware and handlers.
