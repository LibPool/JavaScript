# @cyanheads/aviation-weather-mcp-server

> 标签: JavaScript

## 简介

Fetch METARs, TAFs, PIREPs, and domestic SIGMETs from the NWS Aviation Weather Center via MCP. STDIO or Streamable HTTP.
