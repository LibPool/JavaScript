# @catesworks/skill-chrome-diff-screenshot

> 标签: JavaScript

## 简介

Captures a targeted element or full-page screenshot via Chrome DevTools MCP and compares it against a saved baseline for visual regression testing, reporting a pixel mismatch percentage or pass/fail…
