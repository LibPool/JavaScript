# @catesworks/skill-pr-gh-code-review

> 标签: JavaScript

## 简介

Performs a systematic, file-by-file review of a GitHub pull request and posts inline comments plus a verdict directly to the PR via the GitHub CLI and API, prioritizing correctness, security,…
