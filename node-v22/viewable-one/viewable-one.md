# viewable-one

> 标签: agent, board, canvas, claude, claude-code, mcp, viewable

## 简介

Run coding agents from the Viewable board. Connects your machine to app.viewable.one, launches a session in its own worktree when you press Run, and streams what it does back to the canvas.
