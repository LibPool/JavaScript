# @hlf-core/common

> 标签: blockchain, chaincode, composite-key, distributed-ledger, fabric, hyperledger, hyperledger-fabric, state-key, typescript

## 简介

TypeScript library with core classes shared across hlf-core packages: Hyperledger Fabric state key building, user identifiers, crypto keys, transport commands and domain errors
