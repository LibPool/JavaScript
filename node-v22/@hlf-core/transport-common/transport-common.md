# @hlf-core/transport-common

> 标签: blockchain, chaincode, distributed-ledger, fabric, hyperledger, hyperledger-fabric, signature, transport, typescript

## 简介

TypeScript library with shared Hyperledger Fabric transport protocol: request and response payloads, signed command options, nonce and chaincode metadata commands
