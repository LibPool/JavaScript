# @todoforai/whatsapp-api

> 标签: api, cli, cloud-api, messaging, meta, whatsapp, whatsapp-business

## 简介

JSON-first CLI for the WhatsApp Business Platform Cloud API (messages, templates, media, phone numbers, WABA, flows) on the Meta Graph API, generated from the official OpenAPI spec
