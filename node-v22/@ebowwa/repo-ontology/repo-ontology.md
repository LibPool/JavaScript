# @ebowwa/repo-ontology

> 标签: JavaScript

## 简介

Builds deterministic cross-language ontologies of codebases — a repo-wide dictionary of every symbol (kind, location, signature, doc) plus import/export/reference/provenance edges. Tree-sitter powered with regex fallback; @ebowwa/codegen-kit powered write
