# @kuailian/mcp-server

> 标签: agent, ai, claude, claude-code, cursor, deploy, hosting, html, mcp, mcp-server, model-context-protocol, publish, static-site, 快链

## 简介

Publish AI-generated web pages to a live URL from Cursor or Claude Code. 在 Cursor / Claude Code 里一句话把 AI 生成的网页发布成网址。
