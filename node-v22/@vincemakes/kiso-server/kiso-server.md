# @vincemakes/kiso-server

> 标签: JavaScript

## 简介

kiso server — the hosted-session service: many durable sessions in one process, observers with exact replay from a sequence number, approve / abort / resume routed to the right run, drain and close. No transport; a product supplies the agent factory.
