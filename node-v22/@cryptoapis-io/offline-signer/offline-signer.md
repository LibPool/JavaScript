# @cryptoapis-io/offline-signer

> 标签: bitcoin, blockchain, cryptoapis, evm, kaspa, non-custodial, offline-signing, solana, transaction-signing, tron, utxo, xrp

## 简介

Offline, local transaction signing for EVM, UTXO, Tron, XRP, Kaspa and Solana — no API calls, no API key, the private key never leaves your process.
