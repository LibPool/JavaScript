# @cryptoapis-io/x402-buyer-sdk

> 标签: agent, cryptoapis, fetch, micropayments, non-custodial, payments, stablecoin, usdc, x402

## 简介

CryptoAPIs x402 buyer SDK — a fetch wrapper that auto-pays HTTP 402 responses (authorize → sign locally → retry). Non-custodial: you provide the signer; keys never enter the SDK.
