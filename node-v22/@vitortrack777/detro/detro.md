# @vitortrack777/detro

> 标签: ai, claude, claude-code, cli, code-generator, codegen, crud-generator, detro, detro-cli, gerador-de-codigo, gerador-de-crud, ia, llm, nestjs, ollama, postgresql, react, scaffolding, typescript

## 简介

detro CLI: CLI de desenvolvimento com IA que gera CRUDs completos (banco, API e tela) e corrige código com Ollama, revisado pelo Claude Code. NestJS, React, TypeScript e PostgreSQL.
