# @thetanuts-finance/agentkit

> 标签: agentkit, ai-agent, base, coinbase-agentkit, defi, ethereum, options, rfq, thetanuts

## 简介

Coinbase AgentKit ActionProvider for trading Thetanuts options on Base — for autonomous backend agents that own their own wallet (CDP, viem, Privy, server wallets).
