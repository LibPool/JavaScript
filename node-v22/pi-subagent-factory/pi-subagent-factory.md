> 标签: agent-factory, claude-code, codebase-analysis, codebase-scan, coding-agent, multi-agent, pi, pi-extension, pi-package, subagent-factory, subagent-spawn, subagents

## 简介

Auto-scan any codebase and generate a tailored pi subagent team (architect / implementer / reviewer / tester + stack specialists) with ready-to-use subagent_spawn args. 自动扫描项目技术栈，自动创建专属 subagent 团队，一键并行派活。
