# dsh-user-shell

> 标签: deepseek, deepseek-harness, dsh, dsh-plugin, harness, shell, sudo

## 简介

Claude-Code-style shell commands for the DeepSeek Harness Web composer: `!cmd` runs in the session workspace and adds its output to the model's context, `!!cmd` runs without it, with live output, cancel, and a browser password prompt for sudo.
