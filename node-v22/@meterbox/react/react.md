# @meterbox/react

> 标签: components, meterbox, pricing-table, react, subscription-preview

## 简介

Embeddable React components for Meterbox: pricing tables, subscription preview, credit balance and usage charts. Presentational by default, with data fetched by your backend via @meterbox/node.
