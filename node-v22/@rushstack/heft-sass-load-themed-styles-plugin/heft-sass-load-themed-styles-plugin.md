# @rushstack/heft-sass-load-themed-styles-plugin

> 标签: JavaScript

## 简介

Heft plugin that connects to heft-sass-plugin and replaces load-themed-styles theme expressions with standard CSS variables

## 官网

- 官网：https://rushstack.io/pages/heft/overview/
- 源码仓库：git+https://github.com/microsoft/rushstack.git
- npm 页面：https://www.npmjs.com/package/@rushstack/heft-sass-load-themed-styles-plugin
