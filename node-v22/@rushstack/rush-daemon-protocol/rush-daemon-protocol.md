# @rushstack/rush-daemon-protocol

> 标签: daemon, frames, protocol, rush, rushd, wire

## 简介

Wire protocol for the Rush daemon (rushd): frame taxonomy, length-prefixed binary codec, and version negotiation. (public beta)
