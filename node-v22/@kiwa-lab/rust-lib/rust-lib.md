# @kiwa-lab/rust-lib

> 标签: actix-web, axum, kiwa, mock, rocket, rust, testing, tower-http

## 简介

Rust web framework mock harness for kiwa — axum / actix-web / tower-http / rocket を統一 interface で invoke する in-process mock。 handler / middleware / extractor / router を real framework と同じ signature で叩ける test infra、 実 Rust binary 起動なしで request-response cyc
