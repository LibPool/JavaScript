# @kiwa-lab/webhook

> 标签: github, hmac, kiwa, mock, signature, slack, stripe, testing, twilio, webhook

## 简介

Webhook provider mock harness for kiwa — Stripe / GitHub / Slack / Twilio の hmac 署名検証 + payload parse + delivery retry loop を統一 interface で invoke する in-process mock。 verify / parse / dispatch retry / redelivery までを real provider と同じ signature で叩ける test i
