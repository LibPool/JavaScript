# @kiwa-lab/workflow

> 标签: aws-step-functions, durable, inngest, kiwa, mock, orchestration, temporal, testing, trigger.dev, workflow

## 简介

Durable workflow / step orchestration mock harness for kiwa — Temporal / Inngest / Trigger.dev / AWS Step Functions を統一 interface で invoke する in-process mock。 defineWorkflow (steps) / executeWorkflow / retryStep (exponential backoff) / eventDrivenTrigger
