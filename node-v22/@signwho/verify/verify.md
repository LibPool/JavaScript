# @signwho/verify

> 标签: e-signature, evidence, rfc3161, signwho, verification, webauthn

## 简介

Verify a SignWho signature package (signed PDF + evidence.json) independently: file integrity, WebAuthn assertion, RFC 3161 timestamp, triangle hash — the same checks as signwho.com/verify, as a library.
