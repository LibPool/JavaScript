# @askahuman/mcp

> 标签: agent, approval, claude, cursor, human-in-the-loop, mcp, model-context-protocol

## 简介

Copy-paste MCP server: let your AI agent ask a human for approval on their phone. End-to-end encrypted, no accounts, no database.
