# @paircode/tool-voice

> 标签: paircode

## 简介

人声创作域插件（★ 工具 + UI 同包，2026-09-17 合并）：工具面（纯 DSP，Node 桥 + lib/）voice_import / voice_analyze / voice_edit / voice_render / voice_verify —— 音高修正、时值伸缩、停顿删减、确定性渲染与溯源审计；UI 面（client 半 + assets/voice-panel.js bundle）「人声」面板：源素材 / 波形 / F0 曲线 / 音符段 / 切片 / 编辑链 / 渲染产物 /
