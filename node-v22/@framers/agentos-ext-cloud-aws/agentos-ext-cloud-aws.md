# @framers/agentos-ext-cloud-aws

> 标签: agentos, amplify, aws, cloud, cloudfront, extension, lambda, lightsail, route53, s3

## 简介

AWS cloud extension — deploy static sites to S3, manage Lightsail instances, configure Route53 DNS, deploy via Amplify, set up CloudFront distributions, and deploy Lambda functions using direct REST API calls with SigV4 signing.
