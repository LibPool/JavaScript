# @framers/openquarry

> 标签: frontmatter, json-schema, knowledge-base, markdown, notes, openquarry, quarry, typescript, validator, zettelkasten

## 简介

The OpenQuarry format for Markdown knowledge bases: JSON Schemas for note frontmatter and folder manifests, TypeScript types, and a validator.
