# @agentfirm402/x402-research-mcp

> 标签: base, crypto, mcp, model-context-protocol, usdc, x402

## 简介

MCP server for the x402-research pay-per-call API (crypto signals/briefs, Base address risk, x402 invoice/settlement/approval checks). Testnet by default; your own wallet pays, capped per call and per session.
