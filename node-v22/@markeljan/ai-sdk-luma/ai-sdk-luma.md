# @markeljan/ai-sdk-luma

> 标签: @markeljan/ai

## 简介

The **Luma provider** for the [AI SDK](https://sdk.vercel.ai/docs) contains support for Luma AI's state-of-the-art image generation models - Photon and Photon Flash.
