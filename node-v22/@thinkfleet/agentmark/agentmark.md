# @thinkfleet/agentmark

> 标签: agentmark, agents, ai, browser, llm, markdown, playwright, wire-format

## 简介

AI library for any AI-readable surface — web pages, PDFs (text/scanned/AcroForm), audio (transcribed), video (transcribed + frame-captioned), with signature detection. One compact wire format any AI client can read or drive via MCP.
