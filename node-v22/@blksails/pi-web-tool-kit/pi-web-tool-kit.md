# @blksails/pi-web-tool-kit

> 标签: JavaScript

## 简介

pi-web 通用工具套件:声明式工具引擎 + 首批 AIGC 生成工具集。主入口零运行时依赖(声明,前端安全);./runtime 子入口为 node-only 执行层(pi SDK + undici)。
