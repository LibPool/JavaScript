# @iloveagents/foundry-web-ui

> 标签: ag-ui, agent, agent-framework, assistant-ui, chat, foundry-ui, react

## 简介

React agent UI core for Foundry UI — chat, composer, AG-UI adapter for assistant-ui, tool cards, panels, sidebar, theme runtime, and UI stores.
