# @ruoguo/k-storage

> 标签: JavaScript

## 简介

一个简单易用的浏览器存储工具库，封装了 `localStorage`、`sessionStorage` 和 `document.cookie` 的常用操作，同时提供统一的数据校验方法 `check`。
