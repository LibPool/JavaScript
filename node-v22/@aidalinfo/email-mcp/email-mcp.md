# @aidalinfo/email-mcp

> 标签: email, mcp, mcp-server, scaleway, tem, transactional-email, typescript

## 简介

Outbound email MCP server over Scaleway Transactional Email (TEM) — fixed sender from config, recipient allowlist, two-step confirmed, rate-limited and audited sends
