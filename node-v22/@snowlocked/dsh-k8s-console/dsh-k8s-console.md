# @snowlocked/dsh-k8s-console

> 标签: ai, deepseek-harness, dsh-plugin, k8s, kubeconfig, kubectl, kubernetes

## 简介

DSH K8s 控制台插件：管理 kubeconfig，点击即开会话 Tab（同一集群可开多个），每个会话含「kubectl 命令控制台」与「AI 对话」两个子页；AI 复用 DSH 自身模型配置。
