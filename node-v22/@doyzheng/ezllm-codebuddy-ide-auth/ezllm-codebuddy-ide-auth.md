# @doyzheng/ezllm-codebuddy-ide-auth

> 标签: codebuddy, ezllm, ide, opencode, plugin

## 简介

CodeBuddy IDE 登录态插件：把 JetBrains / IntelliJ 里 CodeBuddy 插件的登录凭据直接当上游账号用（每请求实时读 secret-storage.xml，不落盘、不刷新）
