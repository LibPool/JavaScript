# @refrakt-md/planhub

> 标签: JavaScript

## 简介

DEPRECATED — use @refrakt-md/trace. Legacy alias shim that re-exports the Refrakt Trace CLI plugin under the `planhub` namespace so `refrakt planhub <verb>` keeps working during the v2.0.0 deprecation window.
