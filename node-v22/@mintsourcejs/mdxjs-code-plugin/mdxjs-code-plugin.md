# @mintsourcejs/mdxjs-code-plugin

> 标签: live, mdx, mdxjs, plugin, rehype

## 简介

A plugin for @mdx-js/mdx@2.x to add underlying data/functionality to MDX documents required to support a live code editing implementation.
