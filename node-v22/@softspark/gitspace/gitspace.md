# @softspark/gitspace

> 标签: developer-tools, gh-cli, git, git-identity, github, gitlab, multiple-accounts, oh-my-zsh, oh-my-zsh-plugin, ssh, workspace, zsh

## 简介

Oh My Zsh plugin binding git identity to workspace directories: per-directory commit e-mail, gh account and SSH key, optional SSH commit signing, and an audit that finds repositories already holding the wrong identity.
