# @bimetal/a11y-dom

> 标签: a11y, dom, focus-trap, framework-agnostic, keyboard

## 简介

Framework-free DOM a11y primitives for the BIMETAL render layers: createFocusTrap (the modal focus lifecycle — initial focus, Tab cycle, Escape, restore) and getFocusable. No framework — consumed by every -{fw}-components binding. Implements the v0.29 key
