# @bimetal/forms-data

> 标签: cqrs, event-sourcing, form-builder, forms, headless, schema, undo, validation

## 简介

Forms-domain event-sourcing: Form-as-Schema-Aggregate (a form DEFINITION — ordered fields, types, labels, per-kind validation rules — is ONE aggregate). Filling values is NOT a domain fact; the schema's validateField/validateForm are the single validation
