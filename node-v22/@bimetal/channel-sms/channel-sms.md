# @bimetal/channel-sms

> 标签: alerting, channel, notifications, sms, twilio

## 简介

SMS channel adapter for @bimetal/channel over the Twilio HTTP API (Basic auth). Built on fetch (injectable) — no Twilio SDK dependency. Zero external npm dependencies.
