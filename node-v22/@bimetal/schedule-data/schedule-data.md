# @bimetal/schedule-data

> 标签: event-sourcing, headless, idempotent, recurring, schedule

## 简介

Event-sourced recurring schedule: anchor + interval keyed by a stable key, a pure due-ness query and an exactly-once acknowledgement per occurrence, so replay/rehydrate never report an occurrence twice. No timer in core — the host polls. Built on @bimetal
