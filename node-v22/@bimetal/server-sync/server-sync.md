# @bimetal/server-sync

> 标签: event-sourcing, headless, node, server, sync, websocket

## 简介

Node sync-server skeleton for @bimetal/sync. WebSocket layer over a consumer-supplied http.Server, pluggable EventStore as authority. No HTTP framework; optional per-connection authentication and read/write authorization hooks.
