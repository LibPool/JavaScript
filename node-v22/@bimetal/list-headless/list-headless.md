# @bimetal/list-headless

> 标签: a11y, catalog, controller, framework-agnostic, headless, list, multi-select, undo

## 简介

Canonical, framework-agnostic list/catalog controller (createListController) on @bimetal/headless-core. Owns all list interaction — multi-select (click/ctrl/shift), keyboard + drag batch-reorder (one MoveItems = one undo), batch delete, in-place rename, l
