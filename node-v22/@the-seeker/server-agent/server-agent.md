# @the-seeker/server-agent

> 标签: JavaScript

## 简介

Node.js 20 이상에서 실행하는 읽기 전용 서버 모니터링 수집기입니다. 수집기, 게이트웨이 WebSocket 클라이언트(`run`), systemd/launchd 설치 명령 (`install`·`uninstall`·`status`)을 포함합니다.
