# @elghanam/bottom-sheet

> 标签: android, animated, bottom-sheet, component, drawer, expo, gesture, ios, modal, no-reanimated, overlay, react-native, sheet, typescript, ui

## 简介

A lightweight, animated bottom sheet component for React Native, built on top of `Animated` and `PanResponder` (no `react-native-reanimated` or `react-native-gesture-handler` dependency required).
