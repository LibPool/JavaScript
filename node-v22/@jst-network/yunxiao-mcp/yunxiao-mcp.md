# @jst-network/yunxiao-mcp

> 标签: inventory, mcp, model-context-protocol, sales-management, yunxiao, 库存管理, 进销存, 销售管理

## 简介

云销管家 MCP 连接器：在 WorkBuddy 中用自然语言查询商品、库存、客户欠款与单据，并开具销售单。数据全程在你自己的服务器与电脑之间流转。
