# @godcreator/word-report

> 标签: gwb

## 简介

报告：JSON 报告文档的格式、校验与分章组装，MDX 写法编译成它（.）；读报告目录、检查、导出 Word、JSON 报告转 MDX 的命令行 report-docx（./node）；报告页与报告列表（./site），两页与图片的 loader（./site/server）；engine/ 是驱动本机 Word 的 Python 导出引擎与 .dotx 模板；template/ 是建站器复制进站点 app/features/word-report/ 的接线文件（两条页面路由、图片路由、侧栏入口、样式）。
