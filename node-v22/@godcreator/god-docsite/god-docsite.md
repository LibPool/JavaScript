# @godcreator/god-docsite

> 标签: JavaScript

## 简介

文档站平台：fumadocs（React Router + Vite）站点的公共部分——三种页面来源、布局与侧栏、搜索、llms、推送、术语标注、vite 插件（开发服务没给端口就随机挑），发布版启动命令 docsite-serve，以及唯一的站点模板与建站器（建站、加功能、重写功能汇总文件）、站点身份文件 docsite.json 的读写（站点类别与布局代号）
