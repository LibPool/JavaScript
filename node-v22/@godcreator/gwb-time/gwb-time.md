# @godcreator/gwb-time

> 标签: gwb-plugin

## 简介

东八区时间：状态栏右侧显示东八区（UTC+8）的月日时分，命令 time.now 回起文件名常用的几种东八区时间写法，都不跟本机时区走；随包说明书 time 讲 agent 起时间文件名的规矩
