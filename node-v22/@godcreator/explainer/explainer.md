# @godcreator/explainer

> 标签: JavaScript

## 简介

讲解组件：分步、动画、选情况三种外壳配一句一句的说明，用固定的控制条播放和切换；接缝图把一个系统分成模块、按接缝逐条讲。`.` 是机读文字规则（各步说明、接缝图写成给 AI 读的文字，供站点的组件名册用，不 import react）与接缝图的定义；`./site` 是组件：分步、动画、选情况三种外壳，面板、终端、胶囊、代码行等画帧用的零件，画系统接缝图的 SeamDiagram，共用一套样式 `./styles.css`。template/ 是建站器复制进站点 app/features/explaine
