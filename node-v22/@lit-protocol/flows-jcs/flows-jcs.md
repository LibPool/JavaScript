# @lit-protocol/flows-jcs

> 标签: canonicalization, flows, jcs, lit-protocol, rfc-8785

## 简介

Minimal RFC 8785 (JCS) JSON canonicalization for the value subset Flows signs — pure, zero-dependency, identical bytes on every host (backend, CLI, and the CID-pinned Lit Action).
