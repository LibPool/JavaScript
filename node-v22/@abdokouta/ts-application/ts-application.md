# @abdokouta/ts-application

> 标签: application, bootstrap, dependency-injection, di, lifecycle, nestjs, typescript

## 简介

Application bootstrap layer for @abdokouta/ts-container. Provides ApplicationContext.create() to scan modules, instantiate providers, and run lifecycle hooks.
