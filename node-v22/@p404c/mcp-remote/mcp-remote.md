# @p404c/mcp-remote

> 标签: mcp, oauth, remote, sse, stdio

## 简介

Remote proxy for Model Context Protocol, allowing local-only clients to connect to remote servers using oAuth (fork: honours an empty scopes_supported so servers advertising no scopes authenticate)
