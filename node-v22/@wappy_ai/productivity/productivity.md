# @wappy_ai/productivity

> 标签: ai-agent, local-first, productivity, typescript, whatsapp

## 简介

A reactive Gmail/Calendar assistant for WhatsApp agents - answers any question in normal language via real, parameterized read-only search tools, no saved tasks, no cron, no WhatsApp Message Templates required.
