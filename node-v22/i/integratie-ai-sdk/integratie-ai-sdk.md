# integratie-ai-sdk

> 标签: JavaScript

## 简介

OpenAI-compatible AI SDK providers for Meta (muse-spark), Alibaba DashScope (glm-5.2, kimi-k2.7-code, qwen3.8-max) and Amazon Nova (nova-2-lite-v1) with tool calling support.
