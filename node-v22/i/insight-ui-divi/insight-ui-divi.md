# insight-ui-divi

> 标签: bitcore-divi, blockchain, blockexplorer, divi, front-end, insight

## 简介

An open-source frontend for the Insight API. The Insight API provides you with a convenient, powerful and simple way to query and broadcast data on the Divi network and build your own services with it.
