# ionic-daterange-picker

> 标签: angular, calendar, date-range, daterangepicker, ionic, signals

## 简介

Syncfusion-style date range picker for Ionic + Angular, built from native Ionic components and Ionic CSS tokens so third-party themes (@rdlabo/ionic-theme-md3, @rdlabo/ionic-theme-ios26) style it for free.
