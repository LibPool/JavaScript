# inibase

> 标签: better-sqlite, database, db, file, firebase, json, local, mongodb, mongoose, nosql, pocketbase, postgresql, rdms, relational, sql, sqlite, storage, supabase

## 简介

A file-based & memory-efficient, serverless relational database with crash-atomic ACID: single-table DML + multi-table transactions (per-table writer locks, write-ahead journal + crash recovery, fsync-backed durability, begin/commit/rollback)
