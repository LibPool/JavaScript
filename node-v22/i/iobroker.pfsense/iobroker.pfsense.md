# iobroker.pfsense

> 标签: dhcp, firewall, ioBroker, netgate, pfsense, presence, router, vpn

## 简介

Monitor and control pfSense firewalls through the pfSense REST API package: system health, interfaces, gateways, services, DHCP and presence, VPN, CARP, firewall rules and Wake-on-LAN
