# image-size-from-url

> 标签: bmp, dimensions, gif, height, ico, image, image-dimensions, image-size, jpeg, png, size, svg, url, webp, width

## 简介

Get image dimensions (width & height) from a URL. Supports JPEG, PNG, GIF, WebP, SVG, ICO, BMP, PSD, CUR, DDS.
