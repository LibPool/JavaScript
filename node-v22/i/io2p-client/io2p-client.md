# io2p-client

> 标签: api-client, client, cqrs, discovery, esm, event-sourcing, federated, hash-chain, identity, io2p, iom, isomorphic, openapi, protocol, rest-client, sdk, tamper-evident, typescript, typescript-sdk

## 简介

TypeScript client for the io2p protocol — typed access to an io2p-core storage node (/v1), with a pluggable getToken auth seam and an optional dependency-free issuer-auth helper.
