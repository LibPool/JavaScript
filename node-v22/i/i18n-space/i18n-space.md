# i18n-space

> 标签: cli, monorepo, scaffold, workspace, workspaces

## 简介

CLI that scaffolds a new npm workspace (default folder name "i18n-space") inside the current project.

## 官网

- npm 页面：https://www.npmjs.com/package/i18n-space

- npm 安装：`npm install i18n-space`
- npm registry：https://registry.npmjs.org/i18n-space
- Node 要求：>=18
