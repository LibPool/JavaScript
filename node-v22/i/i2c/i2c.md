# i2c

> 标签: JavaScript

## 简介

Native bindings for i2c-dev. Plays well with Raspberry Pi and BeagleBone.

## 官网

- 官网：https://github.com/korevec/node-i2c#readme
- 源码仓库：git+ssh://git@github.com/korevec/node-i2c.git
- npm 页面：https://www.npmjs.com/package/i2c
