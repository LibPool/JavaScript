# i18n-xlsx-to-json

> 标签: cli, converter, excel, i18n, internationalization, json, translation, xlsx

## 简介

命令行工具：将 Excel (xlsx) 文件转换为多个 JSON 文件，支持 i18n 国际化文件生成

## 官网

- npm 页面：https://www.npmjs.com/package/i18n-xlsx-to-json

- 1.0.0

## 获取地址

- npm 安装：`npm install i18n-xlsx-to-json`
- npm registry：https://registry.npmjs.org/i18n-xlsx-to-json
- Node 要求：>=12.0.0
