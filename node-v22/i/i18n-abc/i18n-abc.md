# i18n-abc

> 标签: JavaScript

## 简介

## 功能 1. 自动提取待翻译的 key/value，生成缩短过后的 key（用 CRC16） 2. 删除未翻译的多语言文本 3. 未翻译的多语言文本用默认语言代替 4. 自动进行简单的简繁转换
