# isomorphic-secp256k1-js

> 标签: ECDSA, bitcoin, blockchain, browser, crypto, csprng, currency, curve, digital, ecc, elliptic, entropy, key-generation, lightweight, node, private-key, public-key, public-key-recovery, randomness, recoverable-signature, rfc6979, secp256k1, signature, typescript, universal, verification, web-crypto, webcrypto, zero-dependency

## 简介

Zero-dependency secp256k1 ECDSA for Node.js and browsers, with native or caller-supplied CSPRNG key generation, RFC 6979 signing, verification, and recovery.
