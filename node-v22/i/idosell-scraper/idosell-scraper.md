# idosell-scraper

> 标签: api, e-commerce, idosell, scraper

## 简介

Pakiet **npm** nowoczesny napisany w **TypeScript**, który udostępnia wygodne API do panelu Idosell.com. Obsługuje autoryzację (w tym opcjonalną weryfikację dwuetapową TOTP), zarządzanie sesją oraz typowe operacje panelu, takie jak pobieranie stron, wysył
