# inferiq

> 标签: ai, build errors, cli, debugging, fix, inferiq

## 简介

Inferiq from your terminal: send a failing command's error to a fix agent, approve the quote, get a patch.

- 官网：https://inferiq.run
- npm 页面：https://www.npmjs.com/package/inferiq
