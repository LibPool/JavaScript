# infiniloom-node

> 标签: ai-tools, ast, blake3, claude, code-analysis, code-chunking, code-context, content-addressable, embeddings, gemini, gpt4o, gpt5, infiniloom, llama, llm, napi-rs, pagerank, pinecone, qdrant, rag, retrieval-augmented-generation, rust, tiktoken, tree-sitter, vector-database, weaviate

## 简介

Node.js bindings for Infiniloom - AST-aware code context engine for RAG and vector databases. Tree-sitter parsing, PageRank ranking, BLAKE3 content-addressable chunks, 27+ tokenizers.
