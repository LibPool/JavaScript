# insight-pac-ui

> 标签: PAC, bitcore-pac, blockchain, blockexplorer, front-end, insight

## 简介

An open-source frontend for the Insight-PAC API. The Insight-PAC API provides you with a convenient, powerful and simple way to query and broadcast data on the $PAC network and build your own services with it.
