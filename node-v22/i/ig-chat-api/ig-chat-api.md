> 标签: api, bot, chat, fca, graph-api, ig-chat-api, instagram, instagram-messaging, messenger

## 简介

Instagram Chat API - FCA-compatible wrapper for Instagram Messaging API (Graph API). Drop-in replacement for fb-chat-api.
