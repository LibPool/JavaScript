# iobroker.solintec

> 标签: battery, dyness, inverter, ioBroker, modbus, photovoltaik, pv, solar, solinteg, stack100

## 简介

ioBroker adapter for Solinteg MHT-25~50K-100 hybrid inverters with Dyness STACK100 battery, via local Modbus TCP.
