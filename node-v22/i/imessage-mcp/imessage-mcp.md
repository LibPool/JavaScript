# imessage-mcp

> 标签: apple-messages, claude, codex, cursor, imessage, local-first, macos, mcp, mcp-server, messages, model-context-protocol, rcs, read-only, sms

## 简介

Search and read your Apple Messages history from any MCP client. Read-only, runs on your Mac, no native dependencies.
