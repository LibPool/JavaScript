# interactive-cli-mcp

> 标签: ai-agent, claude-code, cli, cursor, interactive, mcp, model-context-protocol, pty, terminal, tui

## 简介

MCP server that gives AI coding agents (Claude Code, Cursor, etc.) the ability to interact with interactive CLI processes via PTY — answering prompts, navigating menus, and controlling TUI applications.
