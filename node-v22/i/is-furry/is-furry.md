# is-furry

> 标签: check-owo, furry, has-owo, has-uwu, is-furry, is-owo, is-uwu, owo, uwu

## 简介

Checks if a string has "owo" or "uwu" in it. Multiple strictness settings from "owo" to "0,w u"
