# imzo-agnost

> 标签: capiws, crypto, digital-signature, e-imzo, pfx, pkcs7, plugin, typescript, uzbekistan, websocket

## 简介

Modern TypeScript library for E-IMZO API with comprehensive plugin architecture supporting all E-IMZO operations including PFX/PKCS7/FTJC/CryptoAuth/X509/TSA/CRL/PKI and more
