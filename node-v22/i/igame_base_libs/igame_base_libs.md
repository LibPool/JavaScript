# igame_base_libs

> 标签: JavaScript

## 简介

- 消除重复业务逻辑开发，比如各种投递 - 消除大部分前端兼容开发，如兼容低版本的JS兼容 css兼容 - ui组件包含pc和H5，pc支持到ie8
