# inventor

> 标签: JavaScript

## 简介

基于 mvc 架构模式，借鉴众多优秀 php 框架(CI, Laravel等)的设计方式，使用 koa2 作为 http 处理核心进行封装，路由则借鉴了 Laravel 强大的路由系统，加入路由组的概念，提供更合理的路由规划方式。web 端则采用 react 的同构开发方式。
