# idkitx

> 标签: base62, compact-id, database-index, database-performance, deduplication, deterministic-id, id, id-generator, idempotent, lexicographical, postgres, primary-key, sequential-id, short-id, timestamp-id, ulid-alternative, unique-id, url-safe-id, uuid-alternative

## 简介

Generates compact, URL-safe IDs optimized for humans and database performance. Supports random, deterministic, and sequential modes for idempotency, deduplication, and index efficiency.
