# insight-ui-rapture

> 标签: bitcore-rapture, blockchain, blockexplorer, front-end, insight, rapture

## 简介

An open-source frontend for the Insight API. The Insight API provides you with a convenient, powerful and simple way to query and broadcast data on the rapture network and build your own services with it.
