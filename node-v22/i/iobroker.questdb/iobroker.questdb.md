# iobroker.questdb

> 标签: history, ioBroker, iot, questdb, storage, time-series, timeseries

## 简介

Stores ioBroker state history in a QuestDB time-series database. Each enabled datapoint gets its own QuestDB table, written via the InfluxDB Line Protocol (ILP) over HTTP, HTTPS, or TCP.
