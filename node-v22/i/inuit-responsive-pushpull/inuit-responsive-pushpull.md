# inuit-responsive-pushpull

> 标签: css, inuitcss, oocss, rwd

## 简介

The inuitcss `pushpull-responsive` polyfill module is an extension of the default [`pushpull` polyfill module](https://github.com/alexhillel/trumps.pushpull).
