# islam.js

> 标签: arabic-text, azkar, dua, faith, hadith, hadith-api, hijri-calendar, islam, islam.js, islamic-education, islamic-resources, islamic-tools, javascript, muslim-developers, nodejs, npm-package, open-source, prayer, prayer-times, quran, quran-api, spirituality, supplications, tafseer, typescript

## 简介

A comprehensive JavaScript package offering Quranic text with multiple dialects (Hafs and Warsh), translations in over 20 languages, 28 Tafseers, Hadith collections with multiple translations, Dua and Azkar in 134 categories, prayer timings, and Hijri cal
