# imredline

> 标签: annotation, bug-report, component-capture, design-inspiration, design-tokens, feedback, github-issues, nextjs, qa, review, screenshot, website, widget

## 简介

Point at anything on a live website, say what's wrong, and it lands as a GitHub issue — screenshot, pinned element, attachments and all — for humans and AI agents to fix.
