# ictexam-mcp

> 标签: ai-agent, assessment, claude, edtech, exam, grading, ictexam, lti, mcp, model-context-protocol, moodle

## 简介

Model Context Protocol server for ICTExam. Lets AI assistants read exams, gradebooks and item analysis, and (when writes are enabled) parse a question paper with AI and publish exams.
