# isotone

> 标签: annotations, coding-agent, design-review, dev-tool, feedback, iteration, review, variants, vite-plugin

## 简介

Design variants and feedback for your running web app. Switch between variants your coding agent builds, pin elements, and give the agent the context to make the change.
