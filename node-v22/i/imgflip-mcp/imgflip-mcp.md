# imgflip-mcp

> 标签: ai, claude, imgflip, mcp, meme, meme-generator, model-context-protocol

## 简介

Model Context Protocol (MCP) server for the Imgflip meme generator API — browse templates, caption memes, and generate AI memes from any MCP client.
