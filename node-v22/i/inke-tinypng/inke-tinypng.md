# inke-tinypng

> 标签: JavaScript

## 简介

`inke-tinypng` 使用了网页版 tinypng 的压缩图片接口 `https://tinypng.com/web/shrink` ，参考借鉴了知乎专栏文章《原来TinyPNG可以这样玩!》原文链接：https://zhuanlan.zhihu.com/p/152317953 ，在该作者的基础上，加入了一些常用配置，并且可以递归遍历文件夹等。
