# igm-cli

> 标签: cli, download, igcraftlit, igm, minecraft, mod

## 简介

iGM CLI - iGCraftLit × MuoCeon 联合构建的命令行下载工具，用于检索、下载、更新、卸载 iGCraftLit Community 资源。
