# input-joystick

> 标签: canvas, game-dev, input, joystick, mobile, pointer-events, react, touch, virtual-joystick

## 简介

Touch-anywhere floating virtual joystick for React canvas games, with a pure deadzone/normalize function and an opt-in keyboard co-map.
