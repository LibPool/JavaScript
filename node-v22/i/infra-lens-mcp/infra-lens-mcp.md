# infra-lens-mcp

> 标签: ai, anomaly-detection, baseline, claude, devops, infrastructure, linux, mcp, metrics, model-context-protocol, monitoring, observability, sre, ssh, z-score

## 简介

MCP server that connects to Linux servers over SSH, collects live metrics, builds statistical baselines, detects anomalies with z-score analysis, and explains infrastructure health in plain English
