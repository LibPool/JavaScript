# igroot-input-tag

> 标签: igroot

## 简介

组件直接使用 [React-input-tag](https://github.com/prakhar1989/react-tags) 来进行二次扩展，只扩展了标签是否重复(repeatable)、是否只能输入推送的（onlySuggestions）
