# ipalinked-mcp

> 标签: android, apk, app-distribution, claude, copilot, cursor, ios, ipa, ipalinked, mcp, model-context-protocol, ota

## 简介

IPALinked MCP server — share and analyze iOS (.ipa) and Android (.apk) builds from your AI assistant (Cursor, Claude, Copilot). Upload a build and get an install link + QR in natural language.
