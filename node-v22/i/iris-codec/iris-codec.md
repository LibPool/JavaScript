# iris-codec

> 标签: digital pathology, iris, iris-codec, pathology, whole slide image

## 简介

The Iris Codec Community module is a part of the Iris Digital Pathology project. This module allows for the remote reading of Iris whole slide image (WSI) digital slide files (.iris) using HTTP ranged reads
