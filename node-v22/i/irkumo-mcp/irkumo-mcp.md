# irkumo-mcp

> 标签: edinet, ir, irkumo, japan, mcp, model-context-protocol, stock, tse

## 简介

irkumo (IR Lookup API for Japanese listed companies) の MCP サーバ｡上場会社の IR ページ URL と決算短信一覧 URL を証券コード･社名･別名から引く

## 官网

- 官网：https://irkumo.com
- npm 页面：https://www.npmjs.com/package/irkumo-mcp

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- npm 安装：`npm install irkumo-mcp`
- npm registry：https://registry.npmjs.org/irkumo-mcp
- Node 要求：>=20.0.0
