# is-web-biometrics-supported

> 标签: biometrics, faceid, passkey, touchid, typescript, web-authentication, webauthn, windows-hello, zero-dependency

## 简介

SSR-safe helper for deciding whether to show a biometric login button in WebAuthn and passkey apps.
