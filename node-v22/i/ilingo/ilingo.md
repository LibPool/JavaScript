# ilingo

> 标签: bcp47, client-side, edge, i18n, i18next-alternative, internationalization, intl, l10n, lightweight, locale, locales, localization, pluralization, server-side, ssr, translate, translation, tree-shakeable, typescript

## 简介

A lightweight, framework-agnostic translation and internationalization (i18n) library for TypeScript — pluggable stores, BCP-47 fallback, ICU-lite plurals, Intl formatters.
