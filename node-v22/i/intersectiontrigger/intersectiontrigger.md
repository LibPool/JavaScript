# intersectiontrigger

> 标签: IntersectionObserver, animation, animejs, intersection, intersection-observer, lazy-load, lazy-loading, performance, scroll, scrollbar, toggle-class, trigger, viewport

## 简介

A lightweight TypeScript library that extends the IntersectionObserver API with intersection-based triggers, scroll-linked animations, and a plugin architecture. Zero dependencies.
