# invinoveritas-acp

> 标签: acp, agent-commerce-protocol, ai-agent, autonomous, onchain, review, second-opinion, trading, verification, virtuals, x402

## 简介

Virtuals ACP server for invinoveritas — exposes an independent, capital/risk-aware verdict before an irreversible action (with recomputable signed proofs) as ACP offerings, plus free proof verification. A thin wrapper over the live verification API.
