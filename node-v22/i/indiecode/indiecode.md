# indiecode

> 标签: ai, cli, coding-agent, indierouter, kanban, local-first, terminal

## 简介

Local-first terminal coding agent: SQLite sessions on your disk, 150+ model providers, kanban auto-dispatch to git worktrees. An indierouter.ai product.
