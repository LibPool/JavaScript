# imba-node-watch

> 标签: JavaScript

## 简介

This tiny CLI tool watches for changes in `*.imba` files and restarts the given imba file as node application. It is needed when you develop server-side application in Imba. Uses [chokidar](https://github.com/paulmillr/chokidar) under the hood.
