# illusionist-phrase-maker

> 标签: HUNTER×HUNTER, illusionist

## 简介

This is an application that converts “。” (Japanese period) in an input sentence into one of “♦/♣/♥/♠” to make the phrase sound like an illusionist from a Japanese manga. *This application is available only in Japanese.
