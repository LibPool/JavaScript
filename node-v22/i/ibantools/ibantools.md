# ibantools

> 标签: BBAN, BIC, IBAN, ISO 3136-1 alpha-2, SEPA, SWIFT

## 简介

Validation, extraction and creation of IBAN, BBAN, BIC/SWIFT numbers plus some other helpful stuff like ISO 3136-1 alpha 2 country list
