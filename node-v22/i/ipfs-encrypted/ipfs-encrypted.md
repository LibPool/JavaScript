# ipfs-encrypted

> 标签: aes-256-cbc, ifps, ifps-encryption, ipfs-js, ipfs-nodejs, web3storage

## 简介

ipfs-encrypted can encrypt, decrypt, upload, and download files securely using IPFS and AES-256-CBC encryption algorithm.
