# ifc-agent

> 标签: aec, agent, ai, bim, buildingsmart, ifc, llm, mcp, openbim

## 简介

Protocol-agnostic agent interface for IFC building models: let AI agents query and act on IFC data across transports. Part of the Flinker OpenBIM toolchain.
