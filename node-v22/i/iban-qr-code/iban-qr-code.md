# iban-qr-code

> 标签: bank, bezahlcode, bic, epc, giro, girocode, iban, qr, sepa, transfer

## 简介

Creates strings for a QR code to initiate a SEPA credit transfer (SCT). Similar to Girocode or BezahlCode in Germany
