# iflow-adapter-sdk

> 标签: adapter, agent, agent-runtime, event-journal, iflow, sdk

## 简介

Runtime-agnostic iFlow edge: origin journal, outbox, command idempotency ledger, local projection and the RuntimePorts contract every host implements.
