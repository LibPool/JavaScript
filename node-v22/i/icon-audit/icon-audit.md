# icon-audit

> 标签: agent, cursor, design-system, devtools, figma, fontawesome, iconoir, icons, lucide, svg

## 简介

Dev-only overlay that flags <img> icons vs inline <svg>, then helps replace them with Lucide, Font Awesome, or Iconoir via searchable catalogs and copy-paste agent prompts.
