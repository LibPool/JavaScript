# io.liftoff.vungleads.bundled

> 标签: JavaScript

## 简介

Liftoff/Vungle Ads Unity plugin for Android and iOS. iOS bundles the VungleAds 7.7.6 xcframework; Android declares VungleAds 7.7.7 as a Gradle/Maven dependency so versions of shared libraries (okhttp, okio, ...) are mediated with the rest of the app. Supp
