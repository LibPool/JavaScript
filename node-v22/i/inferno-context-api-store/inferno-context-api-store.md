# inferno-context-api-store

> 标签: global-states, inferno, inferno-create-context, state-management, stateful, store

## 简介

Seemless, lightweight, state management library that supports async actions and state persisting out of the box. Inspired by Redux and Vuex. Built on top of create-inferno-context.
