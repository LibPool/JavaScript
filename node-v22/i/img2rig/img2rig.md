# img2rig

> 标签: animation, canvas, character-rig, live2d-style, spring-physics, stable-diffusion

## 简介

Dependency-free Canvas player for img2rig character rigs - springs, breathing, blinks, hit/stagger/enrage motions from a single rig.txt layer pack.
