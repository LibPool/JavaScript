# insight-ui-posq1

> 标签: bitcore-posq, blockchain, blockexplorer, front-end, insight, posq

## 简介

An open-source frontend for the Insight API. The Insight API provides you with a convenient, powerful and simple way to query and broadcast data on the POSQ network and build your own services with it.
