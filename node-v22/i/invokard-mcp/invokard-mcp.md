# invokard-mcp

> 标签: firestore, invokard, mcp, model-context-protocol, prompts, skills

## 简介

Servidor MCP local (stdio) que sirve las cartas de Invokard a la cuenta que las tiene desbloqueadas. Quien decide el acceso es Firestore, no el cliente.

- 官网：https://invokard.web.app
- npm 页面：https://www.npmjs.com/package/invokard-mcp
