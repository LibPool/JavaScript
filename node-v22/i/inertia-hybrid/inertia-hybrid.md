# inertia-hybrid

> 标签: hooks, inertia, inertiajs, laravel, livewire, react, resolver, vite

## 简介

Livewire-style ergonomics for Inertia + React: drop a logic.ts next to any view.tsx and it binds itself to the view as the $hook prop.
