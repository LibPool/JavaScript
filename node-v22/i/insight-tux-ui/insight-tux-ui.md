# insight-tux-ui

> 标签: blockchain, blockexplorer, front-end, insight, tuxcoin, tuxcore

## 简介

An open-source frontend for the Insight API. The Insight API provides you with a convenient, powerful and simple way to query and broadcast data on the Tuxcoin network and build your own services with it.
