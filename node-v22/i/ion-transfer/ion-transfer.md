# ion-transfer

> 标签: angular, files, formdata, images, ion-transfer, ionic, ionic-file-upload, ionic-http, ionic-post-data, ionic-transfer, json, multiple, post

## 简介

Package to transfer single and multiple files to server. This is also and alternate of native ionic HTTPClient. You can use this package to send post data to server.
