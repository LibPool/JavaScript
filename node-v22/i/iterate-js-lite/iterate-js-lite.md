# iterate-js-lite

> 标签: C#, aurelia, each, filter, iterator, js, map, node

## 简介

Collection of data processing experiments designed for use with aurelia/node.js and brings in some dearly missed C# features like '{0} {1}'.format('foo', 'bar').
