# infozit-push-notification-sdk

> 标签: infozit, notifications, push, pwa, sdk, service-worker, web-push

## 简介

A robust JavaScript SDK for integrating push notifications powered by InfozIT. Simplifies service worker registration, permission handling, and subscription management.
