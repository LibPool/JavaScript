# interaction-analytics-web-sdk

> 标签: JavaScript

## 简介

行迹 Web 埋点 SDK。每个 Web 系统初始化一次，即可自动采集页面访问、SPA 路由切换、可交互元素点击和页面退出时长；关键业务结果通过显式事件上报。
