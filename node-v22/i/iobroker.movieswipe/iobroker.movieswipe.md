# iobroker.movieswipe

> 标签: ioBroker, kinopoisk, movies, movieswipe, multimedia, pwa

## 简介

ioBroker adapter for MovieSwipe PWA - Movie discovery application with Kinopoisk API integration. Optimized database (48 MB) with improved rate limit handling
