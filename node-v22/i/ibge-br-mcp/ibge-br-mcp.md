# ibge-br-mcp

> 标签: brasil, brazil, censo, cidades, dados-abertos, datasus, demografia, estados, estatistica, geografia, geojson, ibge, ipca, localidades, malhas, mcp, mcp-server, model-context-protocol, municipios, nomes, open-data, pesquisas, pib, pnad, populacao, sidra

## 简介

MCP server giving AI assistants live, sourced access to Brazilian public data — geography, census, economy and health — from the official IBGE APIs. Exact figures with provenance, not approximations.
