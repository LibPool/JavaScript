# internetdata-mcp

> 标签: agent, dataset, ip-data, ip-database, ip-intelligence, llm, maxmind-db, mcp, mmdb, model-context-protocol

## 简介

Official MCP server for the InternetData API. Lets an LLM agent browse the IP databases an organization is licensed for, inspect what is inside one, and verify a copy it already holds.

- 源码仓库：git+https://github.com/internetdata/mcp.git
