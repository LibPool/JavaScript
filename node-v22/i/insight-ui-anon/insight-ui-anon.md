# insight-ui-anon

> 标签: bitcore, blockchain, blockexplorer, btcp, front-end, insight

## 简介

An open-source frontend for the anon Insight API. The Insight API provides you with a convenient, powerful and simple way to query and broadcast data on the anon network and build your own services with it.
