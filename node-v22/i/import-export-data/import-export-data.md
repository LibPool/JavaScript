# import-export-data

> 标签: backup, csv, export, import, json, mysql, postgres, restore, sql, sqlite, strapi, strapi-plugin, xlsx

## 简介

Import/export data and scheduled database backups for Strapi 5. Wraps the official `strapi export` / `strapi import` CLI and adds per-collection CSV/JSON/XLSX export, encrypted tar archives, cron-scheduled auto-backups with retention, and one-click restor
