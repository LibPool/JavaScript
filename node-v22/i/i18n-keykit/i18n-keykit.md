# i18n-keykit

> 标签: ai-translation, claude-code, cli, hreflang, i18n, internationalization, l10n, locale, localization, next-intl, nextjs, parity, translations

## 简介

Keep i18n message keys in lock-step across locales: a CI parity guard + scaffolding CLI, optional next-intl runtime helpers and React components, and Claude Code slash-commands for AI-assisted translation. English (the default locale) is the source of tru
