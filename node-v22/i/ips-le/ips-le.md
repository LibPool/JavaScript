# ips-le

> 标签: audit, cidr, cli, ip, ips-le, ipv4, ipv6, letools, mac, network, nolindnaidoo

## 简介

Find every IP address, CIDR block and MAC address in a codebase, normalized per RFC 5952 and classified. Refuses what it cannot read unambiguously.
