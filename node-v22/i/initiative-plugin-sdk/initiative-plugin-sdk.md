# initiative-plugin-sdk

> 标签: initiative, jsonata, jwks, manifest, oauth2, plugin, private-key-jwt, sdk, widget

## 简介

Build a plug-in for Initiative: one typed definition of its endpoints, hooks, schedules, widgets and listing, the server Initiative calls, the client it calls Initiative with, the CLI that builds its manifest, and declarative integrations Initiative runs
