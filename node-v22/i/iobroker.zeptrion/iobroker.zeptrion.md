# iobroker.zeptrion

> 标签: feller, hagel, ioBroker, rolladen, shutter, smart home, storen, wlan, zapp, zeptrion

## 简介

ioBroker Adapter für Feller zeptrion / zApp WLAN-Aktoren (WLAN-Nebenstelle 4K, WLAN-Zwischenmodul 2K) über die zrap Webservice API - inkl. Sammelbefehlen für Hagelalarm und mDNS-Discovery
