# india-basemap

> 标签: basemap, geojson, india, map, maplibre, maplibre-gl, openmaptiles, react

## 简介

React component rendering an India-focused MapLibre basemap: India-only labels and boundaries, zoom-staged label hierarchy (country -> states -> cities), bundled OSM-derived boundary data.
