# isotope-zero

> 标签: agent, embeddings, ink, llm, memory, onnx, rag, sqlite, tui, vector-search

## 简介

Sub-millisecond, local-first cognitive memory layer for AI agents — NumPy/BLAS-accelerated hybrid retrieval, Ebbinghaus decay, and knowledge compaction. Ships a premium React/Ink terminal UI plus the `izero` Python CLI bridge.
