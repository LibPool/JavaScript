# income-stat-report

> 标签: excel, exceljs, income, offline, sheetjs, single-file, statistics, wwt, xlsx

## 简介

收入统计明细生成器 —— 纯前端单文件工具：上传维修/销售源表，生成《收入统计明细表》xlsx（SUMIFS 公式，无数据透视）。SheetJS 与 ExcelJS 已内联，离线可用。
