# ignore

> 标签: .gitignore, asterisks, filter, fnmatch, gitignore, glob, ignore, manager, npmignore, regex, regexp, regular-expression, rules

## 简介

Ignore is a manager and filter for .gitignore rules, the one used by eslint, gitbook and many others.
