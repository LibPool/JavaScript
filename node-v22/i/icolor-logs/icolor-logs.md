# icolor-logs

> 标签: color, colors, console, consolelog, custom, format, javascript, js, log, logs, node, nodejs, react, reactjs, recolor, terminal

## 简介

iColor-Logs is a log formatting library created by ShadowCoding (Chase Quinn). You can easily set different colors for your logs using the various functions available. It is made to be lightweight and efficient.
