# iframe-js

> 标签: ack, cross-origin, eventbus, iframe, micro-frontend, postMessage, promise, react, vue, 通信

## 简介

轻量、安全、优雅的跨域 iframe 通信库。支持 Promise ACK 双向确认、消息队列与多实例完全隔离。
