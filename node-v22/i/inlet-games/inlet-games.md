# inlet-games

> 标签: agent, catalog, cli, games, mcp

## 简介

Command-line client for the Inlet Games catalog: list games, prices and links. Read-only, no account, same data as the Inlet Games MCP server.

## 官网

- 官网：https://inlet.games/agents
- npm 页面：https://www.npmjs.com/package/inlet-games

- 1.0.0
