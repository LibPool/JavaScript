# indigo-express

> 标签: api, api-versioning, boilerplate, code-generator, express, knex, kysely, layered-architecture, postgresql, scaffolding, starter, template, typescript

## 简介

A robust TypeScript-based Express API template with PostgreSQL, Knex migrations, Kysely query builder, and interactive code generators for rapid API development
