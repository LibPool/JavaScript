# insight-ui-komodo

> 标签: bitcore, blockchain, blockexplorer, front-end, insight, monaize

## 简介

An open-source frontend for the Insight API. The Insight API provides you with a convenient, powerful and simple way to query and broadcast data on the monaize network and build your own services with it.
