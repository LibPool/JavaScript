# ion-input-scroll-into-view

> 标签: ion input scroll, ion input scroll into view, ion input scroll into view if needed, ion input scrollIntoView, ion input scrollIntoViewIfNeeded, ionic 3 input scroll into view, ionic input scroll, ionic input scroll into view, ionic2 input scroll, ionic3 input, ionic3 input scroll, ionic3 input scroll into view, ionic3 input scroll into view if needed, ionic3-input, ionic3-input-scroll-into-view

## 简介

A thin directive bundled with the scroll-into-view-if-needed ponyfill for scrolling the ion input into the view on focus event only if needed. Built for both Ionic 2 & 3 applications
