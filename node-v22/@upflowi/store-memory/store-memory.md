# @upflowi/store-memory

> 标签: cjs, esm, file-transfer, memory, store, typescript, upload

## 简介

In-memory UploadStore for upflowi — process-lifetime resume state, useful for tests, Node scripts, and any environment where persistence across reloads isn't needed.
