# @upflowi/provider-s3

> 标签: aws, cjs, esm, file-transfer, multipart, s3, typescript, upload

## 简介

upflowi storage provider for AWS S3 multipart uploads, driven entirely by presigned URLs your own backend generates. Never receives AWS credentials.
