# @yorauth/js-sdk

> 标签: authentication, authorization, mfa, oauth, oidc, rbac, sdk, yorauth

## 简介

Official server-side TypeScript SDK for the YorAuth Authentication & Authorization Platform. For Node.js, Deno, and Bun -- not for browser use.
