# @localfirst-ai/localfirst

> 标签: ai-agents, anthropic, audit, claude, claude-code, cline, cost, governance, local, policy, privacy, proxy, secrets

## 简介

LocalFirst — control what re-enters the model after every AI tool call. Per-tool decision (LOCAL/PASS/BLOCK/TRANSFORM) driven by one policy.yml, tamper-evident audit chain, same engine for Claude Code and MCP.
