# @tech-byte-frontier/jevgate

> 标签: claude-code, code-review, codex, hooks, jev, quality-gate, typesafe

## 简介

JevGate, the code-review gate for CI and coding agents: this package downloads the matching release binary, checks its SHA-256, caches it and runs it
