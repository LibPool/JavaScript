# @g-digital/n8n-nodes-ead-factory

> 标签: digital-trust, ead-factory, n8n, n8n-community-node-package

## 简介

EAD Factory connector for n8n — Digital Trust services from EAD Trust for your n8n automations. Generate certified evidence (SHA-256 hashing, S3 upload, qualified TSP/DLT timestamping), run full signature-request workflows, and send certified notification
