# dsh-mcp-studio

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, mcp, mcp-server, skills

## 简介

DeepSeek Harness 的 MCP 服务与 Skills 管理器：面板里增删改 MCP 行、扫描导入其他 Agent 配置、管理 Skills；装了 dshmarket 时内嵌插件市场。Web 与 Desktop profile 通用。
