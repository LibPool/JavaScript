# @abelcaptain/cctp-mcp

> 标签: bridge, cctp, circle, claude-code, cross-chain, mcp, usdc

## 简介

MCP server for cross-chain USDC bridging via Circle CCTP V2. Supports 18 chains (17 EVM + Solana).
