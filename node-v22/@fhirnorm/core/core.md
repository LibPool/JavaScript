# @fhirnorm/core

> 标签: core, fhir, fhir-r4, fhirnorm, healthcare, hl7, normalizer

## 简介

Convert FHIR R4 resources to plain normalized JSON and back. Supports Patient, Observation, Condition, Encounter and MedicationRequest.
