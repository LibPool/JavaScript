# @jielga/react-popup-window

> 标签: detached, hook, multi-window, panel, popup, portal, react, tanstack-intent, window, window.open

## 简介

React hook to open part of your UI in a separate browser popup window — live portal rendering, style syncing and cross-window messaging.
