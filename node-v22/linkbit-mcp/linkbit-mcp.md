# linkbit-mcp

> 标签: link-shortener, linkbit, mcp, mcp-server, url-shortener

## 简介

MCP server for LinkBit URL shortener: shorten links, bulk create, and get click analytics from Claude, ChatGPT, Cursor and n8n.

- 官网：https://linkbit.live/mcp
