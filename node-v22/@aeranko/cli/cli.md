# @aeranko/cli

> 标签: aeo, aeranko, cli, ship

## 简介

CLI for Aeranko Ship. Installs @aeranko/ship and connects your app to Aeranko in one command.

## 官网

- 官网：https://aeranko.com/ship
- 源码仓库：git+https://github.com/aeranko/aeranko.git
- npm 页面：https://www.npmjs.com/package/@aeranko/cli
