# @deverjak/tenantkit-reservation-core

> 标签: JavaScript

## 简介

Layer-2 reservation domain on @deverjak/tenantkit-kernel: pure courses/sessions/capacity logic, the enrollment rules, and the omluvenka (excuse -> makeup-credit -> redeem) engine. Vendor-free, no I/O.
