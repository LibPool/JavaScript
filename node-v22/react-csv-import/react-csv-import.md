# react-csv-import

> 标签: csv, csv-import, csv-importer, csv-upload, data-import, import, importer, mui, react, react-component, spreadsheet, validation

## 简介

React CSV import dialog: upload a CSV, validate every row against your schema, fix errors in a grid, then save the clean rows.
