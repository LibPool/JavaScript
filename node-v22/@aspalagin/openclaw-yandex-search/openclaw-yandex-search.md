# @aspalagin/openclaw-yandex-search

> 标签: brave, brave-search, multi-search, openclaw, openclaw-plugin, search, web-search, yandex, yandex-search

## 简介

Yandex + Brave web search for OpenClaw: both engines queried in parallel, results merged and deduplicated. Also ships a standalone Yandex Search API v2 provider.
