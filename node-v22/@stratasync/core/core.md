> 标签: decorators, delta-sync, linear, linear sync engine, linear-sync-engine, local-first, model-registry, offline-first, optimistic-updates, realtime, sync, sync-engine, transactions, typescript

## 简介

@stratasync/core: model runtime, schema decorators, transactions and the sync protocol of Strata Sync, an open-source implementation of Linear's sync engine.
