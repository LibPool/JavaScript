# @stratasync/next

> 标签: app-router, linear, linear sync engine, linear-sync-engine, local-first, next, nextjs, offline-first, react, realtime, server-components, ssr, sync, sync-engine, typescript

## 简介

@stratasync/next: Next.js App Router integration for Strata Sync, an open-source implementation of Linear's sync engine. Server-side bootstrap prefetch and a client provider.
