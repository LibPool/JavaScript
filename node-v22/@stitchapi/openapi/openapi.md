# @stitchapi/openapi

> 标签: client-generator, code-generation, codegen, openapi, scaffold, stitchapi, swagger, typescript

## 简介

Eject selected operations from an OpenAPI document into ready-to-own StitchAPI source — a build-time code generator, separate from the zero-dep runtime.
