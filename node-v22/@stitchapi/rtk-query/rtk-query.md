# @stitchapi/rtk-query

> 标签: cache, query, redux, redux-toolkit, rtk-query, stitchapi

## 简介

RTK Query bindings for StitchAPI — stitchQueryFn turns a stitch into an RTK Query endpoint queryFn (error-normalized), and stitchStreamUpdater folds a streaming stitch into the cache via onCacheEntryAdded.
