# @stitchapi/hono

> 标签: api-client, cloudflare-workers, edge, fetch, hono, middleware, seam, sse, stitchapi, typescript

## 简介

Hono middleware + helpers for StitchAPI — put a seam on the request context, stream a stitch's SSE output, and map Stitch errors to HTTP. Edge/multi-runtime (Fetch-only, no node:*).
