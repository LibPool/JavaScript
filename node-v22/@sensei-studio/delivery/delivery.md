# @sensei-studio/delivery

> 标签: JavaScript

## 简介

Sensei Studio Delivery API client (read-only published content). Generated types from the frozen Delivery API 1.6.0 contract plus a hand-written ergonomic layer, including a loosely-typed GraphQL read helper (ADR-0044). ESM-only.
