# @sensei-studio/preview

> 标签: JavaScript

## 简介

Sensei Studio Preview API client (SERVER-SIDE ONLY read access to draft/changed/working content). Generated types from the frozen Preview API 1.3.0 contract plus a hand-written ergonomic layer, including a loosely-typed GraphQL read helper (ADR-0044). ESM
