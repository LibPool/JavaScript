> 标签: end-of-turn, endpointing, log-mel, onnxruntime, smart-turn, turn-detection, vad, voice-agent, voice-ai, whisper

## 简介

Run the Smart Turn v3 end-of-turn detection model from JavaScript: dependency-free Whisper log-mel preprocessing and a thin wrapper for the ONNX Runtime you already use.
