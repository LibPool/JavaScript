# @plugsight/mcp

> 标签: JavaScript

## 简介

Plugsight MCP server: the agent-facing peer of the menu-bar app (docs/spec/03). A deliberately thin stdio-MCP adapter over the daemon's local JSON-RPC-over-UDS API (docs/spec/02).
