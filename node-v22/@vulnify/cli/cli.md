# @vulnify/cli

> 标签: ai-agents, audit, claude-code, codex, cursor, guardrails, hooks, mcp, pretooluse, security, vulnify

## 简介

Vulnify CLI: audit the AI agents on your machine (read-only, local) and install the fail-closed Vulnify hook into Claude Code.
