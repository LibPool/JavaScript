# @hapbeat/sdk

> 标签: creative-coding, hapbeat, haptics, osc, react-native, three.js, udp, vr, webxr

## 简介

JavaScript/TypeScript SDK for driving Hapbeat haptic devices (direct UDP in Node and React Native, hapbeat-helper WebSocket in the browser)

## 官网

- 官网：https://devtools.hapbeat.com/
- 源码仓库：git+https://github.com/hapbeat/hapbeat-js-sdk.git
- npm 页面：https://www.npmjs.com/package/@hapbeat/sdk
