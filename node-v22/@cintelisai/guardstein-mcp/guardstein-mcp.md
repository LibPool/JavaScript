# @cintelisai/guardstein-mcp

> 标签: claude, device-flow, diagrams, drawio, guardstein, mcp, modelcontextprotocol, notes

## 简介

MCP server for GuardStein (formerly Brainstorm Board): connect Claude to your workspace with SSO device-flow sign-in, no API keys. Read and write notes, upload files, and add editable draw.io diagrams.
