# @kenny_novacare/omega-ds

> 标签: component, react, storybook, tailwindcss, ui

## 简介

Omega Design System is a Storybook-powered design system built with Next.js and React, providing a modern and scalable component library. It leverages Tailwind CSS for styling and follows best practices for accessibility, usability, and design consistency
