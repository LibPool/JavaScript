# @telemetry-dev/sdk

> 标签: genai, llm, observability, opentelemetry, otel, sdk, telemetry, tracing

## 简介

Pure TypeScript SDK for telemetry.dev: LLM traces, logs, and GenAI metrics on OpenTelemetry, for Node and edge runtimes.
