# @spreadspace/embed

> 标签: documents, embed, iframe, lending, loader, sdk, spreadspace

## 简介

Plain JavaScript loader for embedding SpreadSpace surfaces via a secure, token-isolated iframe, with the host chrome drawn in your page.
