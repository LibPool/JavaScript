# @pylonts/dsl-dto

> 标签: JavaScript

## 简介

`@pylonts/dsl-dto` is a small DSL for defining **channel contracts** (DTO schemas) — the request/response structures exchanged at API boundaries. It is the DTO-layer counterpart of `@pylonts/mysql-schema` (storage contract).
