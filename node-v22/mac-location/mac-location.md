# mac-location

> 标签: JavaScript

## 简介

Get the current location of the Mac from Node.js. Bundled native helper, no API key or network service.

## 获取地址

- npm 安装：`npm install mac-location`
- npm registry：https://registry.npmjs.org/mac-location
- Node 要求：>=22.22.2
