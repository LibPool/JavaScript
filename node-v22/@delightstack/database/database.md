# @delightstack/database

> 标签: cloudflare, database, delightstack, durable-objects, reactive, search, sqlite, sync, workers

## 简介

Reactive SQLite for Cloudflare Durable Objects — typed schema, client/worker sync over Comlink, and a built-in full-text search engine.
