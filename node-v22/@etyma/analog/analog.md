# @etyma/analog

> 标签: analog, analogjs, angular, hydration, i18n, internationalization, seo, ssr

## 简介

AnalogJS integration for Etyma: URL-driven locale routing, SSR-translated HTML, hydration without a locale refetch, and localized SEO metadata.
