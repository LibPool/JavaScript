# @godxjp/markdown

> 标签: gfm, godxjp, markdown, mermaid, sanitize

## 简介

The one Markdown renderer for GoDX apps: GFM + heading anchors, one sanitiser schema, a shared fixture corpus, and Mermaid drawn only after its SVG passes a fail-closed gate.
