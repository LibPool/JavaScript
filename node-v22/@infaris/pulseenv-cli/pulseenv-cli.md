# @infaris/pulseenv-cli

> 标签: JavaScript

## 简介

CLI om lokale .env-bestanden te syncen met PulseEnv via iPulse OAuth (loopback PKCE). Config-driven, werkt in elke repo.

- 源码仓库：git+https://github.com/iPulseHQ/PulseEnv.git
