# grooph

> 标签: agents, claude-code, codex, loop-graph, mcp, mcp-server, multi-agent, prompt-package, workflow

## 简介

Author, check and compile multi-agent loop graphs for a coding harness: templates, a validator with stable rule codes, a compiler to a prompt package, and an MCP server. It never runs agents.
