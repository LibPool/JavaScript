# @hitheo/agent-link

> 标签: agent-link, claude-code, codex, mcp, opencharts, personas, theo

## 简介

Agent Link Bridge — run Codex or Claude Code as the brain behind your Theo Personas. Pairs with your OpenCharts account, listens for hand-offs, does the work locally, and speaks the answer back through the persona.
