# @imprint-pdf/print

> 标签: cmyk, icc, imprint, pdf-x, print

## 简介

Print-ready add-on for imprint-pdf — PDF/X-4, CMYK, ICC profile embedding, spot color, bleed/trim, and PDF/A output.
