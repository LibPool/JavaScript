# @shipstatic/drop

> 标签: deploy, dropzone, file-drop, file-validation, headless, hosting, react, react-hook, shipstatic, static-hosting, static-site, web-hosting, website, zip-extraction

## 简介

Headless React hook that prepares files for ShipStatic deployments: drag and drop with folder support, ZIP extraction, path normalization, and validation.
