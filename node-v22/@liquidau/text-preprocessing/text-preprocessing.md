# @liquidau/text-preprocessing

> 标签: chunking, edge, preprocessing, source-spans, tokenization

## 简介

Reproducible document preprocessing; exact UTF-16 source spans, versioned deterministic splitters, an injected exact-tokenizer contract, hard token-budget chunk packing and canonical pipeline digests. No dependencies.
