# @postio/node

> 标签: address, address-validation, email, node, ordnance-survey, paf, phone, postcode, postio, royal-mail, sdk, typescript, uk, validation

## 简介

Node-flavoured server SDK for the Postio API. Wraps @postio/core with retries, jitter, and a request-scoped logger hook.
