# @blackbelt-technology/pi-path-containment-guard

> 标签: path-containment, pi-extension, sandbox, security

## 简介

Opt-in, fail-closed pi extension that rejects tool calls whose path argument resolves outside configured allowed roots, and rejects configured denied tools. Loaded explicitly (-e / scope.extensions), never by discovery.
