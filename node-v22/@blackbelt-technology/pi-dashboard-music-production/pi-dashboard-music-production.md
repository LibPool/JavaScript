# @blackbelt-technology/pi-dashboard-music-production

> 标签: beat-grid, librosa, music, pi-package, pi-skill, showreel, video-editing

## 简介

Music-production pi skills: analyse a local audio file into a versioned music map (tempo, downbeat cut grid, key, sections, drops, stems), cut it to length on the beat grid with scored click-free joins, and pick irregular camera-punch hits for a beat-sync
