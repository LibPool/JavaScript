# @coderbuzz/kvs-client

> 标签: bun, client, deno, key-value, kv, node, rest, sdk, typescript, websocket

## 简介

TypeScript client SDK for @coderbuzz/kvs-server — REST and WebSocket RPC transport, watch, and push-based queue listeners.
