# @quantumart/qp8-widget-platform-bridge

> 标签: QP, QP8, QP8.WidgetPlatform, npm, package, react

## 简介

Данный пакет предназначен для организации взаимодействия по технологии Module Federation между оболочкой (проектом, построенным на основе qp8-widget-platform-shell) и модулем (проектом, построенным на основе qp8-widget-platform-modules)
