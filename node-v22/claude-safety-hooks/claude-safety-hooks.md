# claude-safety-hooks

> 标签: ai-coding, anthropic, claude, claude-code, developer-tools, hooks, safety

## 简介

One command to add three Claude Code safety hooks: block dangerous shell commands, protect .env and key files, and stop hand edits of lockfiles.
