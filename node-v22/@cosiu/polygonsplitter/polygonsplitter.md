# @cosiu/polygonsplitter

> 标签: JavaScript

## 简介

PolygonSplitter 是一个轻量级、多边形切割工具，支持通过折线（polyline）切割闭合多边形，返回两个子多边形。适合几何计算、地图应用或可视化工具中使用。
