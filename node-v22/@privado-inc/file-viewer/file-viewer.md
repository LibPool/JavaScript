# @privado-inc/file-viewer

> 标签: JavaScript

## 简介

Privado's document preview preset: PDF, Word, text/Markdown, PPTX, image and spreadsheet renderers with the React viewer component. Built from flyfish-dev/file-viewer v3.1.2, upstream source unmodified.
