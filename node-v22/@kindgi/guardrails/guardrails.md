# @kindgi/guardrails

> 标签: JavaScript

## 简介

Runtime + CI enforcement of agent-behavior guardrails for Kindgi. Same declaration is checked at runtime (the Kindgi runtime in 0.1 stops the turn only on halt and records every other action) and in CI (fails the build) — no drift between test and prod. Z
