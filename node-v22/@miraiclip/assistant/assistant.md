# @miraiclip/assistant

> 标签: agent, ai, assistant, function-calling, llm, openai, tool-calling, video, video-editor

## 简介

An AI editing assistant for Miraiclip: a vendor-neutral ChatModel contract (OpenAI first; any OpenAI-compatible server works), an agent loop that edits a forked project and lands each request as one undo step, high-level editing tools, and a server handle
