# @miraiclip/capture

> 标签: capture, miraiclip, screen-recording, screencast, tutorial, webcodecs

## 简介

Record screen, microphone and camera in the browser with an interaction log (clicks, keys, scrolls, cursor path, sensitive fields) on the same clock — the input for Miraiclip's screencast planners.
