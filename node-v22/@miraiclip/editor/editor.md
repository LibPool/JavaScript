# @miraiclip/editor

> 标签: headless, snapping, timeline, video, video-editor

## 简介

Headless editor logic for Miraiclip: timeline scale, clip drag and trim with snapping, selectors, typed commands, gestures, shortcuts, media import. No UI framework.
