# @hookraft/useauth

> 标签: auth, authentication, brute-force, hooks, jwt, lockout, rate-limit, react

## 简介

Strict, composable authentication hook for React. JWT decoding, brute force protection, bot detection, token refresh, and flexible storage built in.
