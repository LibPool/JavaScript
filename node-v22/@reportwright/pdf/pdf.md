# @reportwright/pdf

> 标签: accessibility, aes, digital-signature, encryption, factur-x, pades, pdf, pdf-a, pdf-ua, pdf-writer, reportwright, streaming, truetype, zugferd

## 简介

A streaming PDF writer for Node and browsers with no runtime dependencies: flat memory, PDF/A-1b to 3a, PDF/UA-1, Factur-X, embedded TrueType with Unicode text.
