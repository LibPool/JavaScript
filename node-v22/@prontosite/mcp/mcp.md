# @prontosite/mcp

> 标签: claude, deploy, mcp, model-context-protocol, prontosite, website

## 简介

MCP-Server für ProntoSite – Website-Status, Export, Deploy und Veröffentlichen direkt aus einem KI-Assistenten (Claude Desktop). Dünner Client um die ProntoSite Deploy-API.
