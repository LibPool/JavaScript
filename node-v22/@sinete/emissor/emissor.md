# @sinete/emissor

> 标签: brasil, emissor, idempotencia, mdfe, nfe, nfse, retomada, sefaz

## 简介

Camada de emissão dos DF-e com estado entre chamadas: bytes assinados gravados antes do envio com trava entre processos (TransmissaoStore), política dos bytes por cStat, retomada automática, cancelamento com recuperação, pool de emissores por certificado
