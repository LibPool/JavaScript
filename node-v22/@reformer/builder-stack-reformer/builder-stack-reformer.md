# @reformer/builder-stack-reformer

> 标签: builder, codegen, form-builder, reformer, typescript

## 简介

ReFormer stack for ReFormer Builder: form-schema model, component catalog, kit descriptors, mock data, fixtures and the codegen printer for @reformer/renderer-json forms
