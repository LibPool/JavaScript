# @cimom/vben-core-typings

> 标签: JavaScript

## 简介

该包提供了 Vue Vben Admin 项目的核心类型定义，包括通用类型、应用类型、路由类型、菜单类型等。它是整个项目类型系统的基础，确保了代码的类型安全和开发体验。
