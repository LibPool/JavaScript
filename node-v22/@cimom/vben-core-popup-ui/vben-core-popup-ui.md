# @cimom/vben-core-popup-ui

> 标签: JavaScript

## 简介

Popup UI 组件是一个基于 Vue 3 的弹出层组件库，包含模态框（Modal）、抽屉（Drawer）和警告框（Alert）等组件，提供了丰富的配置选项和 API 调用方式。
