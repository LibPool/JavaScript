# @cimom/vben-core-shared

> 标签: JavaScript

## 简介

该包提供了 Vue Vben Admin 项目的核心共享工具和功能，包括常量、工具函数、缓存管理、颜色处理、状态管理等基础功能。它是整个项目的基础设施，为其他模块提供了通用的功能支持。
