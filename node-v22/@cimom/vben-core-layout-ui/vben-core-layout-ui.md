# @cimom/vben-core-layout-ui

> 标签: JavaScript

## 简介

Layout UI 组件是一个基于 Vue 3 的高度可定制化布局组件，提供了多种布局模式，支持响应式设计、侧边栏折叠、头部固定等功能。
