# @cimom/vben-icons

> 标签: JavaScript

## 简介

用于多个 `app` 公用的图标文件，继承了 `@cimom/vben-core-icons` 的所有能力。业务上有通用图标可以放在这里。

- 源码仓库：git+https://github.com/vbenjs/vue-vben-admin.git
