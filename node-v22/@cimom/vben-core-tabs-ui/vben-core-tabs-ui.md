# @cimom/vben-core-tabs-ui

> 标签: JavaScript

## 简介

Tabs UI 组件是一个基于 Vue 3 的标签页组件，提供了丰富的配置选项，支持拖拽排序、滚轮滚动、右键菜单等功能，适用于各种标签页导航场景。
