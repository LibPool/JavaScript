# @cimom/vben-core-icons

> 标签: JavaScript

## 简介

该包提供了 Vue Vben Admin 项目的核心图标系统，集成了 Iconify 和 Lucide 图标库，并提供了便捷的图标创建和使用工具。它是整个项目图标系统的基础，确保了图标使用的一致性和可扩展性。
