# @charon1212/shogi-ui

> 标签: JavaScript

## 简介

- template-npm-tsをコピーし、package.jsonを修正。 - tsconfig.jsonにjsx設定を追加。`"jsx": "react-jsx"` - 以下を実行。   - `npm i react`   - `npm i -D @types/react`   - `npm install @mui/material @emotion/react @emotion/styled` - hello.tsxにテスト用コンポーネントを設定。
