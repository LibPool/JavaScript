# @kevinpeckham/barkdown

> 标签: codec, contenteditable, dom, footnotes, gfm, markdown, marked, round-trip, serializer, wysiwyg

## 简介

Markdown ⇄ DOM round-trip codec, guaranteed to invert marked. Canonical identity, fixed-point convergence, footnote fidelity, and no silent loss — the serializer half of an editable-markdown pipeline.
