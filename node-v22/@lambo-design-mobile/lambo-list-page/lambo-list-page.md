# @lambo-design-mobile/lambo-list-page

> 标签: JavaScript

## 简介

LamboListPage 是一个列表数据组件，基于vant实现，用于列表页面。查询区域可用插槽扩展查询表单。列表元素用插槽自定义显示内容。列表行支持批量选择和操作。
