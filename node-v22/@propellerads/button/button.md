# @propellerads/button

> 标签: JavaScript

## 简介

`Button` is the core component of the UI system. Version 10 is a rewrite: the look is built the shadcn way — one stylesheet, variants picked by [class-variance-authority](https://cva.style/), polymorphism from [Base UI](https://base-ui.com/react/component
