# @roamsocket/server

> 标签: ai, cli, coding-agent, github, ios, pairing, roamsocket, websocket

## 简介

RoamSocket desktop companion: headless WebSocket coding server that pairs with the iOS app, clones repos, runs the agent loop, and opens PRs.
