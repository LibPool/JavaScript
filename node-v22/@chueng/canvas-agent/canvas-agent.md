# @chueng/canvas-agent

> 标签: JavaScript

## 简介

本地 Canvas Agent 用来连接画布网页和用户电脑上的 Codex / Claude Code。本地开发时统一连接 `http://127.0.0.1:3000`，不需要先使用线上站点。

- npm 页面：https://www.npmjs.com/package/@chueng/canvas-agent
