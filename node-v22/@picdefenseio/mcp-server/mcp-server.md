# @picdefenseio/mcp-server

> 标签: ai-agent, content-detection, exif, image-analysis, mcp, model-context-protocol, picdefense, reverse-image-search

## 简介

MCP server for the PicDefense.io API — image risk scoring, EXIF, reverse-image backlinks, and image content detection (face, landmark, logo, label, SafeSearch)
