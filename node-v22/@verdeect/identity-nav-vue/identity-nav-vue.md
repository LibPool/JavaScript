# @verdeect/identity-nav-vue

> 标签: identity, inertia, landing, navigation, sso, user-menu, verdeect, vue, vue3

## 简介

Vue 3 integration with Verdeect Identity Service: global navigation rail, profile menu, rail state from backend props, and a public rail for landing pages without a backend
