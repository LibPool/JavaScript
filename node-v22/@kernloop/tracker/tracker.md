# @kernloop/tracker

> 标签: JavaScript

## 简介

Kernloop shared issue-tracker abstraction (spec §5.5): a provider-agnostic TrackerProvider interface + a secure, dry-run-first GitHub provider that builds gh invocations as args-arrays (no shell), guards flag injection, allowlists subcommands, and scopes
