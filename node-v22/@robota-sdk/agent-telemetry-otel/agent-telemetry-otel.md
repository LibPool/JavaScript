# @robota-sdk/agent-telemetry-otel

> 标签: JavaScript

## 简介

OpenTelemetry tracing and metrics for Robota agents: content-free span projection of live prompt traces, a run observer and GenAI metric samples, with agent.* or GenAI semantic-convention names
