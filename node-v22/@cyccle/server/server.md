# @cyccle/server

> 标签: JavaScript

## 简介

The server-only SDK for Cyccle's Merchant API. It requires Node.js 22 or newer and must never be bundled into browser code because it carries a secret API key.

## 官网

- npm 页面：https://www.npmjs.com/package/@cyccle/server
