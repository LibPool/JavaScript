# @ebenova/legal-docs-mcp

> 标签: africa, contracts, documents, ebenova, legal, mcp, nda, nigeria, smithery, tenancy

## 简介

MCP server for the Ebenova Legal Document API. Generate NDAs, contracts, tenancy agreements and 24 more document types across 18 jurisdictions — directly from Claude Desktop, Cursor, or any MCP-compatible AI client.
