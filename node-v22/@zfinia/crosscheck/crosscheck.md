# @zfinia/crosscheck

> 标签: ai-agents, bun, ci, github-action, lockfile, monorepo, npm, package-manager, pnpm, yarn

## 简介

Flags conflicting package-manager configuration (e.g. package-lock.json added to a pnpm repo) in the pull request that introduces it. Local, no account, no network.
