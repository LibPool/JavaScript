# @boy-offi9-inc/isomorphic-unzip

> 标签: apk, archive, browser, ipa, isomorphic, node, unzip, zip

## 简介

Maintained drop-in replacement for the abandoned isomorphic-unzip — same API (getBuffer, string/RegExp/function matching), powered internally by fflate instead of a yauzl+zip.js split that never actually reached parity between Node and browser.
