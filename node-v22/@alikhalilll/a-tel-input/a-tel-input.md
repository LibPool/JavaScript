# @alikhalilll/a-tel-input

> 标签: headless, libphonenumber, nuxt, phone-input, shadcn, tel-input, vue, vue3

## 简介

Headless, shadcn-vue style Vue 3 international telephone input with country detection, validation, and a responsive country picker. Part of the @alikhalilll/a-* toolkit.
