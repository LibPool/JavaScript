# @sx4im/chronos-vitest

> 标签: chronos, deterministic-simulation-testing, dst, failure-replay, race-conditions, testing-framework, vitest, vitest-plugin

## 简介

Vitest integration for Chronos: simTest, expectInvariant, replayTest, failure capsules, failure shrinking. Reproduce distributed-systems bugs from a single integer seed.
