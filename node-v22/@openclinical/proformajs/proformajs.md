# @openclinical/proformajs

> 标签: JavaScript

## 简介

PRO*forma* is a clinical decision support system (CDSS) language (see [Sutton and Fox 2003](http://www.ncbi.nlm.nih.gov/pmc/articles/PMC212780/)). This is a javascript PRO*forma* engine.
