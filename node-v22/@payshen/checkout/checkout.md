# @payshen/checkout

> 标签: 3ds, adyen, browser, card-payments, checkout, checkout-com, embedded-checkout, hosted-fields, payment-orchestration, payments, payshen, pci, stripe, typescript

## 简介

Embedded checkout for Payshen payment orchestration: mount the routed provider's secure card fields, run 3-D Secure and confirm, with no card data on your servers.
