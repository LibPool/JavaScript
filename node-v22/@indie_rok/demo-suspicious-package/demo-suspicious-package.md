# @indie_rok/demo-suspicious-package

> 标签: demo, educational, security-talk, supply-chain

## 简介

Demo package for a supply-chain security conference talk. The postinstall script reads the machine's hosts file (/etc/hosts) at install time to show what npm runs with no approval - locally only, sends no data, and has no dependencies.
