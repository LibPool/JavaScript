# @liangai/pulpo-companion

> 标签: acp, agent, delegation, mcp, model-context-protocol, orchestration, pulpo

## 简介

pulpo companion — stdio MCP server injected into agent sessions, exposing cross-channel delegation (delegate_to_agent / send_input / get_task / cancel_task) and list_agents.
