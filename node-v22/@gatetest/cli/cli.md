# @gatetest/cli

> 标签: accessibility, ci-cd, claude, gatecode, gatetest, performance, qa, quality-assurance, security, seo, testing, visual-regression

## 简介

GateTest — 121-module QA gate with MCP. Eyes (screenshot live pages), ears (production errors), hands (verify fixes worked). Security, supply chain, AI safety, mutation testing. Iterative Claude fix loop. Replaces SonarQube + Snyk + ESLint + 10 others.
