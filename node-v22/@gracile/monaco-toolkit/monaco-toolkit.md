# @gracile/monaco-toolkit

> 标签: JavaScript

## 简介

A collection of tools and settings to easily bootstrap a Monaco Editor setup, for live playgrounds, REPL, etc. with a focus on **JSX** and HTML/CSS/SVG/MD… **Tagged Template Literals**.
