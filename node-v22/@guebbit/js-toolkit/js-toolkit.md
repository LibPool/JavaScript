# @guebbit/js-toolkit

> 标签: array, browser, commonjs, cookies, dom, esm, helpers, query-string, string, toolkit, typescript, utilities

## 简介

Framework-free TypeScript helpers — arrays, strings, numbers, time, formatting, DOM, browser platform — shipped as a dual ESM/CommonJS build with no runtime dependencies.
