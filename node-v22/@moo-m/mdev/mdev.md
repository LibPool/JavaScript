# @moo-m/mdev

> 标签: console, developer-tools, devtools, dom-inspector, mobile-debugging, shadow-dom, typescript, web-inspector, webview

## 简介

In-browser developer tools: Console, Elements, Application and Sources in floating windows. Built with TypeScript and Shadow DOM, no framework.
