# launchpad-registry

> 标签: evm, launchpad, memecoin, meteora, pump.fun, radar, raydium, registry, sniper, solana, uniswap-v4

## 简介

Community-maintained registry of token launchpads (program IDs, factories, launch events) across Solana and EVM chains, plus a generic new-launchpad detector.
