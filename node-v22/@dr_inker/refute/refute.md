# @dr_inker/refute

> 标签: adversarial, agents, ai, anthropic, ci, claude, code-review, fact-checking, llm, multi-agent, openrouter, verification

## 简介

An adversarial verification panel: spawn independent skeptic agents that try to REFUTE a claim, a PR diff, or a finding — and only let it through if the panel can't.
