# @vaarto/whatsapp

> 标签: messaging, notifications, sdk, sms, typescript, vaarto, webhooks, whatsapp, whatsapp-api, whatsapp-business, whatsapp-cloud-api

## 简介

Official TypeScript and Node.js client for the Vaarto WhatsApp Business API — send templates, text, media and interactive messages, read the log, and verify webhooks.
