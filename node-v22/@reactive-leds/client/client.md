# @reactive-leds/client

> 标签: browser, canvas, esp32, led, led-strip, livecoding, neopixel, proxy, reactive-leds, realtime, udp, visuals, websocket, ws2812

## 简介

Browser JavaScript client for realtime LED control over WebSocket. Bridges the reactive-leds UDP protocol to browser applications via a local proxy.
