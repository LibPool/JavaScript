# @inite/brain

> 标签: agent-memory, ai-sdk, bitemporal, brain, inite, knowledge-graph, langgraph, memory, rag

## 简介

TypeScript SDK for INITE Brain — a typed client, framework-shaped tools for the Vercel AI SDK and friends, and a LangGraph-shaped store. Long-term memory for agents: bitemporal facts, hybrid retrieval, citations.
