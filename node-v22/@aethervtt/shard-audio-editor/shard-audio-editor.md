# @aethervtt/shard-audio-editor

> 标签: JavaScript

## 简介

Embeddable audio authoring for Shard events, parameters, collections, mixers, snapshots and music. The editor uses DOM controls and Canvas waveforms. It needs no renderer, GPU, UI framework, filesystem or desktop application. Every panel supports a 300 px
