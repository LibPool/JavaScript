# @simperate/graph

> 标签: JavaScript

## 简介

This is a NestJS application module which provides a GraphQL implementation for frontend applications on top of [aws-sdk-v3](https://docs.aws.amazon.com/AWSJavaScriptSDK/v3/latest/index.html).
