# @aiwerk/mcp-server-swiss-company

> 标签: commercial-register, handelsregister, mcp, model-context-protocol, shab, sogc, switzerland, uid, zefix

## 简介

MCP server for Swiss company data: commercial register (Zefix, LINDAS), Swiss Official Gazette of Commerce, UID register, .ch domain data and the tel.search.ch directory. Per-company lookups with hard request budgets, never bulk downloads.
