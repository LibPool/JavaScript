# @degreesign/server

> 标签: aes-256 encryption, api routing, cors, degreesign, framework-free http server, hcaptcha, hmac, json body parser, native http server, no express, node http createServer, nodejs api server, nodejs server setup, one-time password, request hardening, rest api server sdk, server-side cache, totp, typescript server sdk

## 简介

Framework-free TypeScript REST API server SDK built on Node's native node:http — routing, CORS, JSON parsing, AES-256 encryption, HMAC, hCaptcha, TOTP and cache/file helpers.
