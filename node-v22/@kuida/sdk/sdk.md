# @kuida/sdk

> 标签: api, kuida, pacientes, salud, sdk, webhooks, whatsapp

## 简介

SDK oficial de la API de Kuida para Node.js y TypeScript: pacientes, turnos, consultas, solicitudes de ingreso, tratamientos, eventos y webhooks.

- npm 页面：https://www.npmjs.com/package/@kuida/sdk
