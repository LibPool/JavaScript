# @vetojs/drizzle

> 标签: access-control, authorization, casl-alternative, drizzle, drizzle-orm, permissions, postgres, sql, typescript

## 简介

Drizzle ORM adapter for @vetojs — compiles rule conditions into SQL WHERE with engine-faithful fail-closed semantics.
