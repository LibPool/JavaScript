# @antzsoft/rfid-reader-sdk

> 标签: JavaScript

## 简介

Reader-agnostic SDK for animal microchip (RFID/PIT) scanners over Bluetooth Classic (SPP/MFi), BLE, and serial — React Native, Node, Electron.
