# @antzsoft/wso2-auth-web

> 标签: antz, auth, identity, oauth2, pkce, wso2

## 简介

Framework-agnostic WSO2 IS auth client — login, logout, token refresh, change password. Works with React, Vue, Next.js, or plain JS.
