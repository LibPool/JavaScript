# @potato-forge/dsh-sideboard-bundle

> 标签: JavaScript

## 简介

Install the dsh-sideboard canvas: a right-sidebar drawing surface the agent drives with the `canvas` tool — d3 charts, WCAG contrast, Mermaid diagrams, computed diffs, and sandboxed HTML.
