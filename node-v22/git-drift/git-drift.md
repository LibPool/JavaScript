# git-drift

> 标签: audit, deploy, devops, drift, file-integrity, git, git-status, github, rsync, server, ssh, uncommitted, unpushed, vps

## 简介

Find code that never made it to GitHub: on your servers and your laptop. Uncommitted edits, unpushed branches, stale or hand-edited deploys, checked file by file over plain SSH.
