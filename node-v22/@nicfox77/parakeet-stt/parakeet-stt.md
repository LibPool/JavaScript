# @nicfox77/parakeet-stt

> 标签: asr, nvidia, openclaw, parakeet, speech-to-text, stt, transcription

## 简介

Parakeet TDT INT8 speech-to-text plugin for OpenClaw. Supports V2 (English) and V3 (Multilingual) models.
