# @kg3d/core

> 标签: 3d, data-visualization, force-directed, graph, graph-visualization, knowledge-graph, louvain, network, pagerank, three, threejs, webgl

## 简介

Framework-agnostic 3D interactive knowledge graph engine. GPU-instanced rendering, Barnes-Hut force layout, insight analytics and cinematic camera work for graphs up to ~50k nodes.
