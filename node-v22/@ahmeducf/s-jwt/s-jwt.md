# @ahmeducf/s-jwt

> 标签: browser, jwt, node, typescript

## 简介

A TypeScript library that implements the JSON Web Token (JWT) standard defined in RFC 7519. It provides a simple and easy-to-use API for generating and verifying JWTs, with support for various algorithms and options. This library is fully written in TypeS
