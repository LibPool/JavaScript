# @jibaru/latex-api-cli

> 标签: agent, ai-agent, cli, compile, latex, lualatex, pdf, pdflatex, skill, tex, xelatex

## 简介

Agent-first command-line client for the LaTeX API: compile projects to PDF, sign in from the terminal, manage tokens and profiles, run async jobs, scaffold templates.
