# @camille-hdl/fat-marker

> 标签: JavaScript

## 简介

Draws a fat marker sketch of UI directions, as in [Shape Up, chapter 4](https://basecamp.com/shapeup/1.3-chapter-04), from JSON to SVG or PNG.
