# @amritk/runtime-validators

> 标签: ajv, coercion, fast, json-schema, mjst, parse, parser, runtime, typescript, validation, validator

## 简介

Extremely fast, eval-free runtime JSON Schema validation. Interprets a schema you do not know ahead of time — no new Function, no build step, runs anywhere.
