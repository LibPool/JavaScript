# @hesperia/elysia

> 标签: JavaScript

## 简介

Connect an Elysia HTTP API to component-owned Hesperia queries and mutation tasks. The project plugin checks your server's App type and supplies route metadata to the browser adapter. Eden sends the HTTP requests, and Aeolia owns their shared query state.
