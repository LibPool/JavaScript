# @codellyson/justui

> 标签: astro, design-system, just-ui, react, tailwind, tauri, theme

## 简介

Design system for the just* app family — theme tokens, twelve themes, a no-flash boot script, ~50 React components on Radix, Astro adapters, and a Tailwind v4 design config.
