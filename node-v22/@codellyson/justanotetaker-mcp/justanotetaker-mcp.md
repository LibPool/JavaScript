# @codellyson/justanotetaker-mcp

> 标签: canvas, justanotetaker, mcp, model-context-protocol, notes

## 简介

MCP server for Just a Notetaker — lets any MCP client (Claude, etc.) list, create, update, and delete boards and notes on your canvas, drive agent task cards, fill live tables and embeds, and search.
