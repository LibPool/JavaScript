# @chepchik/spa-router

> 标签: history-api, router, spa, view-transitions

## 简介

Lightweight client-side SPA router: link interception, History API, lazy-loaded pages, nested layouts, loaders, guards, caching, prefetch, scroll restoration and View Transitions.
