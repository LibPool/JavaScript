# tsgolint-rust

> 标签: linter, oxlint, tsgolint, type-aware, typescript

## 简介

A Rust port of tsgolint on ts-rust: the type-aware linter that oxlint runs for --type-aware and --type-check. Install it as oxlint-tsgolint.
