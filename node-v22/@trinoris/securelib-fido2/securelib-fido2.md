# @trinoris/securelib-fido2

> 标签: ctap2, fido2, hmac-secret, webauthn, yubikey

## 简介

Real CTAP2/HID Fido2Authenticator transport for @trinoris/securelib's yubikey-fido2 KeyProvider (specs/securegit/06-key-provider-port.md) -- any FIDO2 authenticator's hmac-secret extension.
