# @kwelder/agent

> 标签: carbon, claude-code, emissions, kwelder, metering

## 简介

Kwelder metering agent for AI-assisted development (Claude Code + Codex) — counts tokens locally, syncs only counts, model ids, timestamps, path hashes and project folder names (optional). Never prompts, code or file contents.
