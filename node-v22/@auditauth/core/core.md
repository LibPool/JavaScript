# @auditauth/core

> 标签: auditauth, auth, authentication, identity, jwt, oauth, security

## 简介

`@auditauth/core` is the shared foundation used by the AuditAuth SDK packages. It provides token and portal helpers, request metrics helpers, shared types, and runtime settings used across the SDK ecosystem.
