# @qemuguest/site-chat-server

> 标签: chat, cloudflare, d1, live-chat, nextjs, simplex, support, telegram, widget

## 简介

Backend for website live chat: Web-standard handlers, storage adapters (D1, SQLite, memory) and relays to SimpleX (one chat per customer), Telegram and email.
