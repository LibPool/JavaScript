# opencode-longrun-harness

> 标签: agent, evidence, harness, llm, long-running, opencode, plugin, verification

## 简介

Bounded, evidence-driven long-run workflow harness for OpenCode: contract-bound runs, fingerprint-bound receipts, operator-reviewed completion. Dependency-free.
