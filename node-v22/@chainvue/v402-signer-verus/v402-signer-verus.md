# @chainvue/v402-signer-verus

> 标签: JavaScript

## 简介

Signer implementations for v402 clients: NodeSigner (Verus daemon signmessage), EnvSigner and FileSigner (local WIF signing, byte-compatible with verusd, validated against the reference test vectors).
