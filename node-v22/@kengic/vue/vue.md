# @kengic/vue

> 标签: JavaScript

## 简介

1. ComputedRef 类型的变量使用 $$ 后缀, 如: `class$$` 2. Ref 类型的变量使用 $ 后缀, 如: `height$` 3. 当组件名称或者模块名称作为前缀时, 使用 $ 包裹组件名称, 如: `$Canvas$get`, `$Canvas$set` 4. 动词使用小写开头, 名词使用大写开头, 如: `$Canvas$get`, `$Canvas$Status`
