# @justai/cuts-next

> 标签: JavaScript

## 简介

The Next face of the persona shell — injects @justai/core's framework-free head behaviour (js-class, SSO capture, optional reveal) the way @justai/cuts does for Astro, so a Next persona (auth, console) inherits the SAME logic instead of re-writing it.
