# @justai/screen

> 标签: JavaScript

## 简介

A second screen that stays in step. The session that opens one — Cast, a paired browser — and the discipline that keeps it honest: a shared clock, a timeline the receiver DERIVES rather than is told, and a jitter buffer for anything continuous. Born at 3d
