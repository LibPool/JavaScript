# @fiqryq/one-auth

> 标签: auth, authentication, edge, effect, oauth, sessions

## 简介

A single-tenant auth library — an alternative to Clerk that you install into your own app, built entirely on Effect. Runs anywhere with Web Crypto and fetch: Node, Bun, Deno, Cloudflare Workers, Vercel Edge.
