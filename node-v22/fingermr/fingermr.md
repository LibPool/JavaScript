# fingermr

> 标签: attendance, biometrics, check-in, digitalpersona, fingerprint, fingerprint-reader, hid, kiosk, time-clock, u.are.u, uareu

## 简介

Turn a USB fingerprint reader into a time clock for your web app: a local bridge for the HID DigitalPersona U.are.U reader that identifies people offline and returns a signed proof your server verifies.
