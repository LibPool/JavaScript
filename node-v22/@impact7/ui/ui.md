# @impact7/ui

> 标签: JavaScript

## 简介

impact7 에코시스템 공유 React 컴포넌트 라이브러리 (design-tokens SSoT + a11y 기반). React 앱은 직접 import, 바닐라/Svelte 앱은 mount 어댑터로 부분 마운트.
