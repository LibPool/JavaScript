# @pinesandbox/computer

> 标签: ai-agent, browser-automation, computer-use, pine-computer, sdk

## 简介

Server SDK for Pine Computer: create and start Computers, run Pine's agent or your own, use the shell and files, and hand a browser-safe connection to your web app.
