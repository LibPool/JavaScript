# @yak/swc

> 标签: css-in-js, react, styled-components, swc-plugin, typescript

## 简介

Rust based SWC plugin of @yak/react and @yak/solid to compile styled components at build time

- 官网：https://yak.js.org/
- 源码仓库：https://github.com/galaxuslabs/yak.git
