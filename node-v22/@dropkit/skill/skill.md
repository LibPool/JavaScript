# @dropkit/skill

> 标签: agent, cdn, claude, claude-code, codex, cursor, dropkit, file-upload, gemini, skill, upload

## 简介

Agent skill for dropkit. Teaches coding agents (Claude Code today; Codex, Gemini, Cursor planned) to wire file uploads into any JS/TS project with one command.
