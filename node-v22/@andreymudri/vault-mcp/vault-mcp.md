# @andreymudri/vault-mcp

> 标签: bm25, knowledge-base, mcp, model-context-protocol, obsidian

## 简介

MCP server for searching, reading and writing an Obsidian knowledge vault: lexical BM25 retrieval plus one wiki-link hop, and learning capture that propagates to the domain MOC, the knowledge index and the daily note in a single commit.
