# @liarjs/checks

> 标签: anti-detect, antidetect, bot-detection, browser-fingerprinting, canvas, consistency, fingerprint, fraud-detection, headless-detection, ja3, ja4, tls, ua-client-hints, user-agent, webgl, webgpu

## 简介

52 browser-fingerprint consistency rules as pure functions: score a JS fingerprint against itself and against what the TLS/HTTP layer saw. Bot and anti-detect browser detection, no dependencies.
