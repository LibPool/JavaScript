# @ttrpg/grid

> 标签: axial, battlemap, distance, grid, hex, rpg, square, ttrpg

## 简介

Grid math for TTRPG digital tools. Square (Chebyshev/Manhattan/Euclidean/alternating) and hex (axial + offset coordinates). Distance, neighbors, lines, rings, discs. Zero dependencies.
