# @candidelabs/wdk-protocol-sda-candide

> 标签: candide, cross-chain, deposit-address, ethereum, forwarding-address, protocol, sda, stablecoin, tether, usdt, usdt0, wdk

## 简介

WDK Smart Deposit Address (SDA) protocol module for Candide's Forwarding Address: deterministic deposit addresses that forward funds from any supported EVM chain to a recipient on a destination chain.
