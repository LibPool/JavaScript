# @streetjs/slack

> 标签: chatops, connector, esm, integration, slack, street-framework, streetjs, typescript, webhook

## 简介

StreetJS Slack connector: a typed Slack Web API client (post/update/delete messages, reactions, conversations) built on @streetjs/integrations, plus Slack request-signature (v0) verification for inbound events.
