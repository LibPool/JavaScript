# @streetjs/linear

> 标签: connector, esm, graphql, integration, issue-tracker, linear, street-framework, streetjs, typescript

## 简介

StreetJS Linear connector: a typed Linear GraphQL API client (viewer, issues, comments, generic queries/mutations) built on @streetjs/integrations, plus Linear-Signature HMAC webhook verification.
