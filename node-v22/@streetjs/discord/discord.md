# @streetjs/discord

> 标签: chatops, connector, discord, esm, integration, interactions, street-framework, streetjs, typescript, webhook

## 简介

StreetJS Discord connector: a typed Discord REST API client (channel messages, reactions, webhook execution) built on @streetjs/integrations, plus Ed25519 interaction-request verification.
