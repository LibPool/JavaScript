# @streetjs/http-client

> 标签: backoff, esm, fetch, http-client, interceptors, rest, retry, street-framework, streetjs, timeout, typescript, zero-dependencies

## 简介

StreetJS HTTP client foundation: a typed outbound HTTP client over fetch with base URLs, query building, JSON helpers, timeouts, retries with backoff, request/response interceptors, and descriptive errors. Zero runtime dependencies.
