# @streetjs/telemetry

> 标签: esm, latency, metrics, observability, percentile, ring-buffer, street-framework, streetjs, telemetry, typescript, zero-dependencies

## 简介

StreetJS telemetry foundation: an in-process metrics tracker with bounded ring-buffer retention — heap/RSS sampling, request counters, and p50/p99 latency percentiles, plus a health snapshot. Zero runtime dependencies.
