# @streetjs/security

> 标签: aes-256-gcm, auth, encryption, esm, hmac, hs256, json-web-token, jwt, key-rotation, security, street-framework, streetjs, typescript, zero-dependencies

## 简介

StreetJS security foundation: a dependency-free HS256 JWT service (sign/verify/decode) with algorithm-confusion protection, timing-safe signature comparison, and exp/nbf/iat/iss/aud claim validation, plus AES-256-GCM field encryption (FieldCipher/KeyRing)
