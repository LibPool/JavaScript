# @sluicehub/visualizer-ng

> 标签: angular, dashboard, iot, mqtt, sluicehub, telemetry, visualization

## 简介

Embeddable Angular telemetry SDK for SluiceHub — live MQTT streaming, historical backfill, and seven standalone views (gauge, oscilloscope, chart, dartboard, drum, map, pager) with threshold alerting.
