# dsh-clean-search

> 标签: bing, deepseek-harness, dsh, dsh-plugin, search

## 简介

Bing 直连干净搜索 provider：直连 cn.bing.com，代码过滤导航、页脚、广告，只把标题、链接、摘要喂给模型的 web_search 后端
