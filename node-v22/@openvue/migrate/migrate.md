# @openvue/migrate

> 标签: codemod, migration, openvue, primevue, vue

## 简介

Codemod that migrates a PrimeVue project to OpenVue by rewriting package names and import specifiers

## 官网

- 官网：https://github.com/openvi-foundation/openvue
- 源码仓库：git+https://github.com/openvi-foundation/openvue.git
