# @kensai/quiz-player

> 标签: cdn, education, embeddable, player, quiz, widget

## 简介

Embeddable, framework-free web player for the Kensai Quiz format. Use via npm (import) or a single CDN <script> — then KensaiQuiz.init('#el', { quiz }).
