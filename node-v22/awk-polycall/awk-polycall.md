# awk-polycall

> 标签: awk, busybox, ffi, gawk, gawk-extension, libpolycall, mawk, peer-to-peer, polycall

## 简介

AWK binding for Polycall: a gawk extension that runs the real core in-process (@load "awk_polycall"), and a POSIX AWK library that drives the polycall CLI (gawk, mawk, busybox awk).
