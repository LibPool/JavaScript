# @techelusive/nest-auth

> 标签: 2fa, auth, authentication, jwt, magic-link, nestjs, oauth, otp, passkeys, postgresql, totp, typeorm, webauthn

## 简介

Reusable, production-grade authentication for NestJS apps: passwords, codes, magic links, social, passkeys, 2FA, organizations and API keys, stored in each app's own database
