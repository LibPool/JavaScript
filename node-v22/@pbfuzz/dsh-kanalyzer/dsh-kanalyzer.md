# @pbfuzz/dsh-kanalyzer

> 标签: deepseek-harness, dsh-plugin, llvm, reachability, static-analysis

## 简介

General-purpose LLVM static-analysis plugin for DeepSeek Harness: builds analysable bitcode and runs kernel-analyzer (KAMain) reachability analysis behind ctx.kanalyzer
