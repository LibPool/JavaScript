# @xandreed/evals

> 标签: ai-agent, effect, effect-ts, evals, llm, llm-as-judge

## 简介

efferent SDK — a minimal, Effect-native eval library: the data → task → scorers shape as Effects, so a task can be the real agent loop and a scorer can call an LLM. Trace-first reporting.
