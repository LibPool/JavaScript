# dsh-extra-prompt

> 标签: cordis, dsh, plugin

## 简介

Prompt injection, subagent routing, Skill install, rtk output compaction, MCP servers and a session dashboard for DSH — one switchable plugin row each, configured from a settings page in the Web UI
