# @h_domi/pdf-canvas-kit

> 标签: canvas, drag-and-drop, framework-agnostic, headless, overlay, pdf, pdf-annotation, pdf-editor, pdf-viewer, pdfjs, react, vue

## 简介

Framework-agnostic PDF editor and viewer — render a PDF as page backgrounds and place your own components on top. Zero framework runtime, thin React and Vue wrappers.
