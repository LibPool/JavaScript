## 简介

React components and hooks for TryOnIt, the free open-source virtual try-on SDK. Drop-in <TryOnButton> for e-commerce product pages: virtual makeup, glasses, hats, jewelry, watches and clothing. Works with Next.js, Remix and Vite. Fully themeable and head
