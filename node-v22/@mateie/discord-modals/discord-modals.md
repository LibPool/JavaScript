# @mateie/discord-modals

> 标签: discord, discord-forms, discord-modals, discord.js, discord.js-forms, discord.js-modals, forms, interaction modals, modal form, modal interactions, modals

## 简介

Discord-Modals is a package that allows your discord.js v13 and v14 bot to create, and interact with Modals, a new Discord feature.
