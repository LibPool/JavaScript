# @dizyx/nockerl-tokens

> 标签: JavaScript

## 简介

The canonical web build of the Nockerl design tokens. CSS custom properties plus a typed token map (tokens.json and TS), generated from the DTCG source. Source of truth: dizyx/nockerl-design.
