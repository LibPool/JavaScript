# @meowshed/meow-godot

> 标签: meowpaw, pi-package

## 简介

Detects Godot projects from what git tracks, reads the engine version from each project file before it binds anything, prints a stages table bound from the gdtoolkit, GUT and export preset files the repository committed with an import before every export
