# @meowshed/meow-csharp

> 标签: meowpaw, pi-package

## 简介

Detects a .NET solution or project from what git tracks, compares the SDK global.json pins with the ones installed, prints a stages table that restores explicitly and keeps every build's output outside the working tree, reports Nullable, TreatWarningsAsEr
