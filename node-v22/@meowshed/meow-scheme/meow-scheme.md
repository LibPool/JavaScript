# @meowshed/meow-scheme

> 标签: meowpaw, pi-package

## 简介

Detects Scheme projects from the manifests git tracks, names the implementation before it binds anything, prints a stages table that binds Racket's tests as raco test without writing bytecode and binds nothing for an implementation whose commands the repo
