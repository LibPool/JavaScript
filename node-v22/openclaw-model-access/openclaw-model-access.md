# openclaw-model-access

> 标签: ai-models, base, claude, gemini, gpt, llm, model-provider, openclaw, openclaw-plugin, usdc, x402

## 简介

OpenClaw model provider: 130+ AI models (Claude, GPT, Gemini, Grok, Kimi, GLM, DeepSeek) with tool calling, paid per request in USDC on Base via x402 from a local wallet, with spending limits. No account, no API key.
