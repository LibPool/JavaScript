# leaflet-tual

> 标签: annotation, arrows, canvas, framework-agnostic, gis, leaflet, leaflet-tual, map-tools, notes, overlay, react, react-leaflet, tual, tuval, vanilla-js

## 简介

Framework-agnostic interactive canvas and annotation toolkit for Leaflet maps — draw arrows, shapes, freehand sketches, rulers, notes, and text pinned to geo-coordinates. Optional React bindings.
