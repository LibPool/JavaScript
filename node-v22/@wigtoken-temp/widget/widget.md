# @wigtoken-temp/widget

> 标签: claude-code, counter, embed, react, sse, token-usage, widget, wigtoken

## 简介

React components that embed live token-usage counters from a wigtoken server on any page. <TokenCounter />, <CostCounter />, <WeightedTokenCounter /> with auto SSE updates.
