# openjobs

> 标签: agent, ashby, ats, form-filler, greenhouse, job-application, lever, resume, workable, workday

## 简介

OpenJobs is a job application agent. It reads public job feeds, queues postings, fills employer ATS forms, reviews every form, and sends only the applications you approve.
