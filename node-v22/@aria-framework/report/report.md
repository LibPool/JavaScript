# @aria-framework/report

> 标签: JavaScript

## 简介

Aria App Framework — report rendering. CSV serialisation (RFC-4180, BOM, formula-injection guard with the plain-number exemption), the pdfmake report document as a mechanism with injected cell/total rendering and theme, normaliseSvg, and a CSP-safe inline
