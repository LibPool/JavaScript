# @chativa/rn-webview

> 标签: chat, chativa, expo, mobile, react-native, webview

## 简介

Chativa RN WebView — embeds the Chativa web chat widget in a react-native-webview, bridged to native props/callbacks, so any existing @chativa/connector-* works unmodified. See README.md for architecture and the native-fallback tracking issues.
