# @openreceive/node

> 标签: bitcoin, bolt11, cli, lightning, nwc, openreceive, payments

## 简介

Accept Bitcoin Lightning payments in Node.js with your own wallet and optional USDT, USDC, SOL and ETH swaps.

- 源码仓库：git+https://github.com/openreceive/openreceive.git
