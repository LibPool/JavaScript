# @hyzyn/dsh-docker

> 标签: agent, ai, compose, container, cordis, deepseek, deepseek-harness, docker, dsh, plugin, ssh, web

## 简介

DSH Web GUI 的 Docker 容器面板插件：本机或 SSH 主机上的容器列表 / 启停删 / 日志 / 统计 / 镜像 / 一次性 exec，默认只读，配套只读优先的 agent 工具。
