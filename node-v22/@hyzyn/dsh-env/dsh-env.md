# @hyzyn/dsh-env

> 标签: JavaScript

## 简介

DSH Web GUI 的环境变量 / 密钥管理插件：官方设置 → 插件 里的「环境变量 / 密钥管理」卡片，托管 ~/.dsh/env.yml 的密钥区块，支持普通值与 js: 前缀表达式，保存后可选写入当前进程环境变量。
