# mal-githell

> 标签: cli, console, game, git, kubectl, learn, tui, tutorial

## 简介

GIT HELL: Doomslaying BOFH — a console game that teaches git (and kubectl) by doing. TypeScript, zero dependencies, runs on Node. npx mal-githell
