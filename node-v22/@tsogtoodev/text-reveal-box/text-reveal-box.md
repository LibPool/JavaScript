# @tsogtoodev/text-reveal-box

> 标签: animation, component, scroll, scroll-animation, text-reveal, vue, vue3

## 简介

Scroll-driven word-by-word text reveal effect for Vue 3 — each word is stamped in by a box that flashes over it as you scroll.
