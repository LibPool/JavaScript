# @iggy-lakic/pi-muninndb

> 标签: mcp, memory, muninndb, omp-plugin, pi-extension, pi-package

## 简介

MuninnDB MCP plugin for Pi and OMP — one package, works equally on both hosts; registers the MCP server and notifies when MuninnDB is down. Never installs anything.
