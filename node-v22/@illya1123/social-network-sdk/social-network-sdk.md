# @illya1123/social-network-sdk

> 标签: facebook, graph-api, instagram, meta, sdk, social, threads, tiktok, typescript

## 简介

Framework-independent TypeScript SDK for the Meta social-network family (Facebook Pages, Facebook Login, Instagram Business, Threads) and TikTok.
