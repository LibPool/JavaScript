# @kethyrpay/sdk

> 标签: aleo, kethyrpay, payment, sdk, wasm, zero-knowledge

## 简介

KethyrPay 最小 SDK：Aleo 支付封装（WASM 初始化、钱包适配器、KethyrPay 主类），基于 @provablehq/sdk 与 @provablehq/aleo-wallet-adaptor-*
