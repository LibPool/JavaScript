# @1gr14/route0

> 标签: path, query-string, route, router, routing, search-params, standard-schema, type-safe, typescript, url

## 简介

Type-safe URL paths for TypeScript — define a pattern once, then build paths and parse URLs with full type inference, search params, and Standard Schema validation. Not a router; the typed path toolkit you build one on.
