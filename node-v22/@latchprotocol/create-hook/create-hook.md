# @latchprotocol/create-hook

> 标签: amm, create, defi, foundry, hook, hooks, latch, latchprotocol, scaffold, solidity

## 简介

Scaffold a Latch (a hook contract for LatchProtocol pools) in one command: npm create @latchprotocol/hook. Runs the create-latch-hook scaffolder from @latchprotocol/cli.
