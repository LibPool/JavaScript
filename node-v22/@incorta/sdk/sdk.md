# @incorta/sdk

> 标签: analytics, incorta, metadata, oauth, oidc, schema

## 简介

Read Incorta schemas, tables, views, and columns on behalf of the signed-in user — OAuth 2.0 sessions from @incorta/auth, no personal access tokens.
