# drupal-sdc-thumbnail

> 标签: canvas, drupal, playwright, screenshot, sdc, single-directory-components, storybook, thumbnail, varbase, vartheme

## 简介

Generate static thumbnail images for Drupal Single Directory Components (SDC) by screenshotting their Storybook stories, for use as Drupal Canvas component previews.
