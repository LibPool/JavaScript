# rasso-plugin-pdf-toolbox

> 标签: JavaScript

## 简介

本地化轻量 PDF 工具箱：多页缩略图可视化勾选拆分提取、多文件拖拽排序合并、逐页渲染转高清长图，pdf-lib + pdf.js 引擎 100% 离线运算，敏感文件绝不上云
