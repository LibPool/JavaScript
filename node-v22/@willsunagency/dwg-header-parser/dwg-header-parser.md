# @willsunagency/dwg-header-parser

> 标签: autocad, bim, cad, dwg, dwg-parser, dwg-version, dxf, engineering

## 简介

Lightweight, zero-dependency parser for detecting AutoCAD DWG binary file versions and release year metadata from magic byte headers.
