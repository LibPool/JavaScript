# @moncircle/sdk

> 标签: ecommerce, loyalty, mon, monad, rewards, web3

## 简介

Self-hosted MON loyalty reward infrastructure for e-commerce platforms. Supports SINGLE, MULTI, and HYBRID reward modes with Monad on-chain settlement.
