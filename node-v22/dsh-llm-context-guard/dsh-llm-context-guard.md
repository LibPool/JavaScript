# dsh-llm-context-guard

> 标签: JavaScript

## 简介

阻止 pi-ai 的上下文估算把 max_tokens 压成 1（模型只吐一个字就 finish_reason: length）。幂等自愈补丁，可跨 DSH 安装复用。
