# @razohq/razo-analyzer

> 标签: ai, claude, failure-analysis, playwright, razo, test-reporting, testing

## 简介

AI failure analysis for razo test artifacts: feeds ai-steps.json to Claude and returns which business action failed, a root-cause hypothesis, and a suggested fix.
