# @whisper-security/whisper-mcp

> 标签: agent-identity, ai-agents, claude, cursor, dane, dnssec, egress, ipv6, mcp, model-context-protocol, rdap, threat-intelligence

## 简介

Give an AI agent a real, routable IPv6 identity, verifiable egress and DNS policy. Keyless: verify any agent's identity and query the infrastructure graph. With a key: register, govern and route agents.
