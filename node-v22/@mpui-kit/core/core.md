# @mpui-kit/core

> 标签: africa, cameroon, checkout, fcfa, framework-agnostic, headless, mobile-money, phone-number, xaf, xof

## 简介

Framework-free core of MPUI-KIT: a Mobile Money checkout controller, phone number and FCFA helpers, and FR/EN strings for African markets. Works with React, Vue, Svelte or plain JavaScript.
