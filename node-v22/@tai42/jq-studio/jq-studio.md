# @tai42/jq-studio

> 标签: editor, jq, json, node-graph, react, transform, visual

## 简介

Standalone, embeddable visual jq editor: a node canvas that reads a jq expression into an editable graph and writes it back, round-trip AST converters, a faithfulness guard, and a drop-in JqField — design-system-agnostic, with an injectable primitives sea
