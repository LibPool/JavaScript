# mcp-overleaf

> 标签: claude, latex, mcp, model-context-protocol, overleaf

## 简介

Unofficial MCP server for Overleaf: read, edit and write LaTeX projects (in Markdown too) from Claude, Cursor and other MCP clients. Not affiliated with Overleaf.
