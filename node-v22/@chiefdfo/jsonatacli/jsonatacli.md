# @chiefdfo/jsonatacli

> 标签: cli, csv, jq, json, jsonata, pipeline, transform, xml, yaml

## 简介

Run JSONata transforms over JSON, CSV, XML, and YAML from the command line. Runs transform/pipeline files exported from JSONata Studio.
