# @i-scope/vlst-parser

> 标签: ajs, binary-parser, debug, i-scope, iscope, iscope-debugger, jscript, oscilloscope, vlst

## 简介

Parser for the VLST (Variable List String Table) binary blob returned by ScopeAppDbgCtrl::GetStackContent. Shared building block for any iScope IDE frontend (Cursor/VS Code, future WebStorm) that needs to surface JScript locals / watch trees.
