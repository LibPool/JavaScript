# @i-scope/mcp-server

> 标签: ai-agent, ajs, autoscope, claude, cursor, dap, debug, i-scope, iscope, iscope-debugger, jscript, mcp, model-context-protocol, oscilloscope

## 简介

Model Context Protocol server for iScope / Oscilloscope.exe debug & control. Lets AI agents drive a .ajs debug session — breakpoints, step, variables, evaluate — through standard MCP tools layered on top of the iScope DAP adapter.
