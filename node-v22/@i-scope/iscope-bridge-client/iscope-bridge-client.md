# @i-scope/iscope-bridge-client

> 标签: ajs, autoscope, com-automation, i-scope, iscope, iscope-debugger, jscript, json-rpc, oscilloscope, vlst

## 简介

Node.js JSON-RPC client for iScopeBridge.exe — speaks the helper's wire protocol (Content-Length framed JSON-RPC 2.0 over stdio) and exposes a typed promise + event API for driving Oscilloscope.exe via COM/OLE Automation. Plain Node, no vscode dependency.
