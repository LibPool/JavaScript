# @i-scope/debugger

> 标签: ajs, autoscope, dap, debugger, i-scope, iscope, iscope-debugger, jscript, mcp, meta-package, oscilloscope, sdk

## 简介

iScope Debugger — meta-package. Single-install entry point for the full debugger SDK: DAP adapter for IDE integrations, MCP server for AI agents, Win32 native helper bridge, source-map / VLST / COM-protocol building blocks. Pure dependency umbrella; no ru
