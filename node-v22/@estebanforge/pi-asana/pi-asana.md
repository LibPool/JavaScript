# @estebanforge/pi-asana

> 标签: asana, coding-agent, pi-extension, pi-package, project-management, rest-api, task-management

## 简介

Asana Work Graph tool for Pi. Adds 12 LLM-callable tools (asana_*) that query the Asana REST API over plain HTTP. Mirrors a curated subset of the official Asana MCP tool set &mdash; no MCP server install required. Personal access token auth via ASANA_ACCE
