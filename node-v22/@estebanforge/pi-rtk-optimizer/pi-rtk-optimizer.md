# @estebanforge/pi-rtk-optimizer

> 标签: command-rewrite, output-compaction, pi-extension, pi-package, rtk, token-optimization, tool-compaction

## 简介

RTK command rewriting and tool output compaction extension for the Pi coding agent. Rewrites bash commands to their rtk equivalents and compacts noisy tool output to reduce context window usage. (fork of MasuRii extension)
