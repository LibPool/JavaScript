# @estebanforge/pi-ask-shared

> 标签: background, delegation, pi

## 简介

Shared runtime for the @estebanforge ask extensions: background-run registry, wake sender, stop handler, one-shot spawn lifecycle, layered config primitives, per-CLI peer adapters (claude/codex/agy), and the cross-peer consult core. Plain library, no Pi e
