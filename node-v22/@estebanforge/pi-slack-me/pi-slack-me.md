# @estebanforge/pi-slack-me

> 标签: chat, coding-agent, pi-extension, pi-package, slack, slack-api, user-token

## 简介

Slack tools for Pi that act as YOU, not as a bot. Adds 8 LLM-callable tools (slack_*) that read channels, threads, DMs, and search results, plus post, update, and delete messages using a Slack USER token (xoxp-). No bot to invite, no footprint in the work
