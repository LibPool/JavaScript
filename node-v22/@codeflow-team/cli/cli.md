# @codeflow-team/cli

> 标签: agent, cli, codeflow, codegen, mcp, scaffold, typescript, workflow

## 简介

The `codeflow` command — scaffold a flow workspace, generate typed tool/library declarations from codeflow.config.ts, and check flows against the contract.
