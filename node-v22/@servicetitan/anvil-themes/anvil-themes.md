# @servicetitan/anvil-themes

> 标签: JavaScript

## 简介

Anvil-theme provides global design tokens that are based on core design tokens based on `@servicetitan/tokens`. It utilizes style-dictionary to generate tokens for different platform but the source(JSON) is generated by js files in `./theme`.
