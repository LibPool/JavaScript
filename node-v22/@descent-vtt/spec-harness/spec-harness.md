# @descent-vtt/spec-harness

> 标签: agents, brief, claude-code, guardrails, harness, hooks, mcp, spec

## 简介

The agent-facing member of the spec-* tools: context for a round, a guard on every write, an audit when it ends, probes that prove a defect before it is filed, and rulings a person signs.
