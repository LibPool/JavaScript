# @codizelabs/agent-rewake

> 标签: acp, agent-client-protocol, ai-agents, antigravity, auto-resume, claude, claude-code, claude-code-auto-resume, codex, coding-agent, copilot-cli, cron, gemini-cli, github-copilot, grok, rate-limit, resume, schedule, scheduler, session-limit, usage-limit, weekly-limit, zed, zed-editor

## 简介

Auto-resume Claude Code, Codex, Gemini CLI, GitHub Copilot, Grok or any Zed agent when its usage limit resets, in the same session, and schedule messages into your agent threads.
