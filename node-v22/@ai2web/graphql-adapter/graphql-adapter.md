# @ai2web/graphql-adapter

> 标签: adapter, agentic, ai-agents, ai2web, graphql, mcp, schema

## 简介

Expose an AI2Web site's declared capabilities as a GraphQL schema, with RFC-0006 §3 approval/credential/SSRF enforcement.
