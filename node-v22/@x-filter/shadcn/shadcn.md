# @x-filter/shadcn

> 标签: dsl, filter, filter-builder, headless, query, query-builder, react, shadcn, tailwind, typescript

## 简介

shadcn/Tailwind UI adapter for the X-Filter query builder — composable atomic components with DnD, DSL editor, and ARIA tree keyboard navigation.
