# dsh-ohna

> 标签: agent-runtime, bug-tracker, cordis, development-pipeline, dsh, dsh-plugin, subagent

## 简介

Multi-tool development toolkit for the agent runtime: ohna_devline_run (parallel, context-isolated dev pipeline) + ohna_bug_record / ohna_bug_fixed (workspace bug log) + a Web GUI bug table. The orchestrating tool named by the one-click fix prompt is conf
