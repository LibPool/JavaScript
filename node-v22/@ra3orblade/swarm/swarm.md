# @ra3orblade/swarm

> 标签: ai-agents, claude-code, codex, developer-tools, mcp, observability, orchestration, worktrees

## 简介

Local-first control plane for AI-agent development: watch every Claude Code / Codex / Grok session on your machine, ledger tasks and worktrees, enforce rules as hook denials.
