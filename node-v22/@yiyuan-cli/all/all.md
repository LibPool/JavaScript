# @yiyuan-cli/all

> 标签: meta-package, umbrella, yiyuan, yy-cli

## 简介

yy-cli 伞式元包 (umbrella): 聚合所有 @yiyuan-cli/* 子包,供 WorkBuddy 等 Agent 平台一次安装到位;本身不提供代码与命令。
