# @yiyuan-cli/api

> 标签: JavaScript

## 简介

yy-cli 通用 API plugin 包(扫到后注册 `yy api ...` 子命令),用于在 cli 未提供对应命令时,直接构造 YiYuan 后端 API 请求并自动注入 cookie

## 官网

- npm 页面：https://www.npmjs.com/package/@yiyuan-cli/api
