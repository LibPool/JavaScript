# @miaskiewicz/turbo-test

> 标签: drop-in, fast, jest, native, rust, test, test-runner, testing, v8, vitest

## 简介

A blazing-fast native test runner — a drop-in replacement for vitest, ~5-12x faster vs jsdom. Rust + V8, oxc transform, all-Rust DOM (rtdom), native V8 coverage.
