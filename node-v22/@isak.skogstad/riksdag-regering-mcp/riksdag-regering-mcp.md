# @isak.skogstad/riksdag-regering-mcp

> 标签: mcp, model-context-protocol, parliament, regeringen, riksdagen, swedish-government

## 简介

Professionell MCP server för att hämta, söka, analysera och jämföra data från Riksdagen och Regeringskansliet. Innehåller 27 verktyg och 5 resources med förbättrad säkerhet och response validation.
