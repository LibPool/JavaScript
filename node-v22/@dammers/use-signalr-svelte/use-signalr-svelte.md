# @dammers/use-signalr-svelte

> 标签: realtime, signalr, stores, svelte, sveltekit, typescript, websocket

## 简介

Fully-typed multi-hub SignalR provider + stores for Svelte: auto-reconnect, invoke retry, lazy hubs, live status.
