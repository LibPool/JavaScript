# @dammers/use-signalr-solid

> 标签: realtime, signalr, solid, solidjs, typescript, websocket

## 简介

Fully-typed multi-hub SignalR provider + hooks for SolidJS: auto-reconnect, invoke retry, lazy hubs, live status.
