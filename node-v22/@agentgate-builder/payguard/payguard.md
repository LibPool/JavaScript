# @agentgate-builder/payguard

> 标签: ai-agents, aml, compliance, crypto, crypto-address-screening, kyt, mcp, mcp-server, ofac, ofac-screening, sanctions, sanctions-screening, usdc, wallet-screening, x402

## 简介

OFAC sanctions screening for crypto addresses: check whether a wallet address is on the US Treasury SDN list (EVM, BTC, TRX, SOL and more). Free offline MCP server (sanctioned yes/no); full entity and program details via x402 pay-per-call API.
