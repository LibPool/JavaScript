# clothsy-mcp

> 标签: ai-agent, clothsy, ecommerce, mcp, model-context-protocol, virtual-try-on

## 简介

MCP server that helps AI coding agents add Clothsy AI virtual try-on to a store: stack detection, integration plans, docs, error help and a live key check.
