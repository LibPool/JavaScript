# @ascentsparksoftware/react-image-editor

> 标签: annotation, canvas, crop, fabric, fabricjs, filters, image-editor, nextjs, photo-editor, react

## 简介

Standalone, themeable React 19 image editor built on Fabric.js v7 (MIT). A free, open-source alternative to commercial image editors — crop, rotate, filters, draw, text, redact, export.
