# @quxkit/quxkit-mcp

> 标签: agents, billing, email, identity, mcp, mcp-server, model-context-protocol, multi-tenancy, quxkit

## 简介

One MCP server for the QuxKit family — it mounts the tools of whichever kits are installed, rather than one server per kit.
