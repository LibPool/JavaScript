# pr-receipts

> 标签: ai-agents, claude-code, cli, git-notes, github-action, llm-cost, pull-request, token-usage

## 简介

Per-PR cost receipts for agent-written code: tokens, list-price dollars and agent time from local Claude Code transcripts, stored in git notes and posted as a sticky PR comment.
