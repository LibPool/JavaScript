> 标签: atomic-design, css-tokens, css-variables, design-system, design-tokens, scss, semantic-css, style-tokens, tailwind-style, ui-kit

## 简介

A minimal, semantic SCSS tokens library for atomic design systems—providing a standardized, override‑friendly set of color, spacing, typography, border, shadow, breakpoint, size and z‑index tokens to kickstart any project.
