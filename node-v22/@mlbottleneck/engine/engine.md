# @mlbottleneck/engine

> 标签: benchmark, gpu, inference, llama.cpp, llm, planner, quantization, speculative-decoding, tokens-per-second, vllm, vram

## 简介

Physics-based LLM inference planner: decode/prefill tokens per second, memory fit, multi-GPU strategy, and speculative-decoding gains for any model on any hardware, calibrated on community benchmarks.
