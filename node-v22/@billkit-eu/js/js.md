# @billkit-eu/js

> 标签: billkit, browser, checkout, embedded, mollie, payment-element, stripe

## 简介

Browser SDK for BillKit: the embedded checkout element (<CheckoutElement/>) served from js.billkit.eu. The Stripe-Elements-shaped payment UI for BillKit on Mollie.
