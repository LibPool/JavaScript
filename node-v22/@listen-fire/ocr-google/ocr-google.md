# @listen-fire/ocr-google

> 标签: JavaScript

## 简介

Reading text out of scanned PDFs with Google Document AI (online for short files, batched through a Cloud Storage bucket for long ones). The OCR half of the file-text reading slot, as its own package so a deployment without OCR carries no Google Cloud SDK
