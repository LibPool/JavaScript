# @listen-fire/models

> 标签: JavaScript

## 简介

The models slot's module for any vendor the platform speaks (`@lf/models`): Gemini (on Google Cloud or with a Gemini API key), OpenAI, Claude on Anthropic's API or on Vertex. Movement model names map to the vendor's models through the platform's model map
