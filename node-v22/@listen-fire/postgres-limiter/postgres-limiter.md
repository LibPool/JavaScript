# @listen-fire/postgres-limiter

> 标签: JavaScript

## 简介

The limiter slot kept in Postgres, so many lf workers share one count of calls and held places instead of each allowing the full limit. A process module lf starts (kind: core, slot: limiter); see lf-external.yaml. The contract suite runs in apps/cli
