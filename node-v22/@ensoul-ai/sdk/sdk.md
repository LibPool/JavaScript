# @ensoul-ai/sdk

> 标签: agent-simulation, ai, ai-agents, ai-characters, ai-npc, conversational-ai, game-ai, llm, memory, npc, npc-simulation, persona, personality, simulation

## 简介

Official TypeScript SDK for the Ensoul API. Build AI NPCs and personas with memory and personality that evolve through real conversation, scale to thousands, and run simulations where they change over time.
