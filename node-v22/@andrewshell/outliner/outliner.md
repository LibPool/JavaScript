# @andrewshell/outliner

> 标签: concord, editor, opml, outliner, typescript

## 简介

TypeScript port of Concord, Dave Winer / Small Picture's JavaScript outliner. Rewritten with no jQuery, no Bootstrap, and inline SVG icons instead of Font Awesome. GPL-3.0; derived from https://github.com/scripting/concord.
