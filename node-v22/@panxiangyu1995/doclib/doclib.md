# @panxiangyu1995/doclib

> 标签: agent, claude, cli, documentation, knowledge-base, spec-driven

## 简介

把任意项目蒸馏成可复原的文档图书馆：有索引、有层次、覆盖全，任何 agent 或人只凭这套文档即可从零重建该项目（≥90% 功能复原）。非克隆，是文档驱动的重新开发。
