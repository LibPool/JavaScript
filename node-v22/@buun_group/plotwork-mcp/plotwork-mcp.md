# @buun_group/plotwork-mcp

> 标签: ai-agents, database-schema, diagrams, flowchart, mcp, model-context-protocol, plotwork, sequence-diagram, stdio, svg

## 简介

No API key and no account. Plotwork MCP server for local use over stdio: read-only tools that draw, validate, outline, convert, and render twenty kinds of diagram, from flow, sequence, and database to Gantt, state, mind map, and treemap. It sends nothing
