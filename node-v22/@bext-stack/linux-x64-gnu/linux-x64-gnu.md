# @bext-stack/linux-x64-gnu

> 标签: JavaScript

## 简介

Prebuilt Linux x64 (glibc) native addon for @bext-stack/runtime. Not installed directly — pulled in as an optional dependency.

## 官网

- 官网：https://bext-stack.github.io
- 源码仓库：git+https://github.com/bext-stack/bext.git
- npm 页面：https://www.npmjs.com/package/@bext-stack/linux-x64-gnu

- npm registry：https://registry.npmjs.org/@bext-stack/linux-x64-gnu
- Node 要求：>=18
