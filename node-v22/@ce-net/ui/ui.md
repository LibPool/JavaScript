# @ce-net/ui

> 标签: ce, ce-net, components, custom-elements, dashboard, ui, vanilla

## 简介

Framework-free TypeScript UI components, CSS tokens, and live-data helpers shared by CE Host, ce-infer-ui, ce-drive-web, and the wallet panel.
