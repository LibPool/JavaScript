# groovy-polycall

> 标签: ffi, ffm, groovy, libpolycall, polycall

## 简介

Groovy binding for the Polycall binding ABI v1 (Foreign Function & Memory API, JDK 22+). Source distribution of a Gradle project; not a JavaScript library.
