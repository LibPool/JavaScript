# quiet-toolbar

> 标签: bug-report, debugbar, dev, devtools, feature-flags, staging, toolbar

## 简介

Floating dev/staging toolbar for any web app: build info, feature flags, caught errors, one-click bug report, clear storage, custom actions. Zero dependencies, never ships to production.
