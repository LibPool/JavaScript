> 标签: core, error-handling, event-bus, framework-agnostic, lyntra, nodejs, sandbox, security, utilities, uuid, validation

## 简介

Production-ready core systems for Node.js applications - Framework agnostic utilities including sandboxing, event bus, error handling, validation, and webhook notifications. Zero dependencies on any specific framework.
