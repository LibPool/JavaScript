# @dvai-bridge/ios-shared-core

> 标签: JavaScript

## 简介

DVAI-Bridge iOS shared HTTP-server + handler-dispatch types used by all backend cores. Extracted from ios-llama-core so non-llama backends don't transitively inherit llama.xcframework.
