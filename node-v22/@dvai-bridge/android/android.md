# @dvai-bridge/android

> 标签: JavaScript

## 简介

DVAI-Bridge Android native SDK — embedded local OpenAI-compatible HTTP server with llama.cpp + MediaPipe (LiteRT-LM) + LiteRT backends. Capacitor-free, pure Kotlin singleton API.
