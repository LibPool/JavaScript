# @eternalnight/dsh-theme

> 标签: 360-follow, background, deepseek-harness, dsh, dsh-plugin, skin, theme, video-background, wallpaper

## 简介

DeepSeek Harness 主题皮肤插件：给 DSH Web GUI 换背景（内置主题 / 静态图片 / 动态视频环绕跟随帧），设置页与侧边栏底部一键切换。
