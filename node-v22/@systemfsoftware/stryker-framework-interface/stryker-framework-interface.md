# @systemfsoftware/stryker-framework-interface

> 标签: ast, estree, format, framework, mutation-testing, plugin, stryker, test-quality

## 简介

The framework interface for StrykerJS-style mutation tooling — the plain framework object a plugin exports, its format claim, the embedded document and script regions it produces, and the toolkit context its hooks receive. Types only, with no runtime expo
