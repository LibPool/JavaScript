# @systemfsoftware/effect-cell-types

> 标签: architecture, effect, effect-ts, either, type-contracts, typescript, workflow

## 简介

Type-level contracts for the repo's cell taxonomy, starting with the Workflow decision channel — branded Workflow<C, D, E> types plus a runtime make constructor shared across the repo's cells.
