# n8n-nodes-insightsocial

> 标签: insightsocial, linkedin api, n8n, n8n-community-node-package, social media api, tiktok api, web scraping, youtube api

## 简介

n8n community node for InsightSocial: public data from TikTok, LinkedIn, X, YouTube, Reddit and Pinterest through one API key, priced per call in credits.
