# @lakutata/template-web-nuxt

> 标签: docker, lakutata, lakutata-template, nuxt, template, vue

## 简介

The Nuxt web template of the lakutata projects: an HTTP API serving a Nuxt application (rendered on the server) from the same process, deployed as a Docker image.
