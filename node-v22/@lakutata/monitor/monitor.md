# @lakutata/monitor

> 标签: cpu, event-loop, lakutata, memory, metrics, monitor, monitoring, typescript

## 简介

The monitors of the lakutata framework: the CPU, the memory, the event loop and the HTTP requests of the process, on the histograms of Node.js.
