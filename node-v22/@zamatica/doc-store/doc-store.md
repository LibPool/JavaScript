# @zamatica/doc-store

> 标签: JavaScript

## 简介

Document persistence with format-by-extension dispatch (JSON5 / YAML). File-backed store at the root; git-backed (isomorphic-git, local-only) at /git with commit + history + diff + restore; NestJS adapter at /nestjs.
