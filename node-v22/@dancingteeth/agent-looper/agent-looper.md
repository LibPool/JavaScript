# @dancingteeth/agent-looper

> 标签: agent, agent-loop, agentic, ci, claude-code, cline, codex, coding-agent, cursor, deepseek, fix-until-green, llm-judge, opencode, pi, verify

## 简介

Fix-until-green harness for coding agents: frozen goal + verify.sh, a fresh worker each round, optional judge review. Works with Cursor, Claude Code, Codex, OpenCode, Cline, Pi, DSH, and Muse.
