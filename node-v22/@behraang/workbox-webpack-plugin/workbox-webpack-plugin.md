# @behraang/workbox-webpack-plugin

> 标签: caching, fetch requests, file manifest, offline, service worker, webpack, workbox, workboxjs

## 简介

A plugin for your Webpack build process, helping you generate a manifest of local files that workbox-sw should precache.
