# @d34dman/sutram

> 标签: agentic-ai, ai-agents, browser, command-line, command-palette, console, developer-tools, drupal, json-schema, llm-tools, mcp, model-context-protocol, repl, web-components, webmcp

## 简介

Let AI agents use your web app through commands, not clicks. Register commands once: agents call them through WebMCP, from JavaScript in a headless browser, or by typing into a console that people can use too.
