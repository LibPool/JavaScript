# @customyai/experience-native

> 标签: customy, experience, expo, hermes, i18n, ota, react-native, translations

## 简介

Customy Experience for React Native / Expo: signed-release updates with an always-on baseline, atomic apply, bounded store, runtime probe, RTL, telemetry, policy and composition rendering. Pure logic: platform capabilities are injected.
