# @customyai/experience-web

> 标签: brand, customy, design-tokens, experience, i18n, icu, react, ssr

## 简介

Customy Experience for React: provider, useT() with ICU, lazy namespaces, injected baseline, flicker-free SSR, brand loader (CSS variables from validated tokens), <ExperienceComponent> and a bridge to the design system message provider.
