# @customyai/client

> 标签: auth, brand-studio, browser, customy, react, react-native, sdk, session

## 简介

Customy browser client: session, sign-in, MFA, passkeys, active organization, capabilities and account linking over same-origin HttpOnly cookies, with React, native and native React bindings and the brand-studio screen renderer (studio, studio/react) as s
