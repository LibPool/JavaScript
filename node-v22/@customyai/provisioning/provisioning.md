# @customyai/provisioning

> 标签: customy, provisioning, sdk, test-users, testing

## 简介

Customy Provisioning: create, find and clean up TEST users (identity provisioning) with an Access API key, over @customyai/core. Includes withEphemeralUsers for CI.
