# @maelstrom-co/planner-jev

> 标签: ai, jev, maelstrom, planner, server, typesafe

## 简介

Experimental server-only Maelstrom planner that lets TypeSafe Jev decide selection, actions and tiling layout, with a small LLM call for the user message.
