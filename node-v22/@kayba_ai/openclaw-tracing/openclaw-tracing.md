# @kayba_ai/openclaw-tracing

> 标签: ace, agent, kayba, mlflow, observability, openclaw, tracing

## 简介

OpenClaw plugin that captures full agent turns (user message + LLM call + tool calls + reply) and emits them as Kayba traces. Pairs with @kayba_ai/tracing.
