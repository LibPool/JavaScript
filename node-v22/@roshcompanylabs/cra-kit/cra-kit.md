# @roshcompanylabs/cra-kit

> 标签: compliance, cra, cyber-resilience-act, cyclonedx, osv, sbom, security, supply-chain, vulnerability

## 简介

Turn an npm repo into the EU Cyber Resilience Act evidence the free SBOM tools don't produce: SBOM, OSV vulnerability match, depth justification, vulnerability-handling/CVD policy, draft EU Declaration of Conformity, and an Annex I readiness checklist.
