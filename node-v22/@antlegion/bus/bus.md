# @antlegion/bus

> 标签: agents, ai-agents, append-only, blackboard, cli, content-addressed, coordination, event-log, fact-bus, multi-agent, stigmergy, tuple-space

## 简介

Append-only fact bus for autonomous agents — facts, not commands. Stateless trusted core, single total order, coordination as reader-side folds; SDK + alctl CLI (the sanctioned agent interface) included.
