# @soamee/database-backup

> 标签: backup-verification, database-backup, digitalocean-spaces, gcs, nestjs, pg_dump, s3

## 简介

Configurable NestJS database backup service with convention-based storage paths, multi-provider adapters (DO Spaces, AWS S3, GCS), and backup verification
