# schzem-auth

> 标签: auth, authentication, authorization, browser-auth, cross-platform, customizable, express, jwt, password, rbac, schzem, security, typescript, webcrypto

## 简介

A customizable authentication toolkit for Node.js and modern Web Crypto runtimes, with JavaScript, TypeScript, browser helpers, JWT, password hashing, RBAC, and Express middleware.
