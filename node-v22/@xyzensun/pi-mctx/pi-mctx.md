# @xyzensun/pi-mctx

> 标签: compaction, context, pi-extension, pi-package, session

## 简介

Manual context management for pi — /mctx new distills the session into a kickoff prompt and starts a fresh session; /mctx sink moves used-up tool results out of context with lossless obs readback
