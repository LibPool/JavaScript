# @fullcalendar/interaction

> 标签: calendar, drag-n-drop, event, full-sized, fullcalendar, resizing, selecting

## 简介

FullCalendar v6 only (in v7, this plugin is built into each framework package, e.g. @fullcalendar/react/interaction). Calendar functionality for event drag-n-drop, event resizing, date clicking, and date selecting

## 官网

- 官网：https://fullcalendar.io/docs/editable
- 源码仓库：git+https://github.com/fullcalendar/fullcalendar.git
- npm 页面：https://www.npmjs.com/package/@fullcalendar/interaction
