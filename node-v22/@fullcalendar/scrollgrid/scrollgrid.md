# @fullcalendar/scrollgrid

> 标签: calendar, event, full-sized, fullcalendar, resource, scheduler

## 简介

FullCalendar v6 only (in v7, this plugin is built into each framework package, e.g. @fullcalendar/react-scheduler/scrollgrid). Tabular data chunked into scrollable panes

## 官网

- 源码仓库：git+https://github.com/fullcalendar/fullcalendar-workspace.git
