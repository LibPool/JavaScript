# @mcmcjs/plots

> 标签: bayesian, diagnostics, forest, mcmc, plots, trace, visualization

## 简介

Diagnostic plots (trace, density, forest, rank, ...) for MCMC.js, rendered to the terminal, SVG, or a self-contained HTML page.
