# @dijkspicy/lazy-dsh

> 标签: agent-preset, deepseek-harness, dsh

## 简介

Installer for the lazy-dsh (懒人模式) dsh agent preset: six named-role subagent tools with fixed model routes, a model-routing skill, and the always-on 躺主 orchestrator persona.
