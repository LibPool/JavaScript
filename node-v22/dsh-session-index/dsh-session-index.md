# dsh-session-index

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, fts5, search, session, sqlite

## 简介

A derived SQLite index over DSH session logs: search, list, read and an incremental rebuild -- as a service and as agent-facing tools. Imports no dsh code.
