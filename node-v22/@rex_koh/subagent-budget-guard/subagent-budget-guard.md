# @rex_koh/subagent-budget-guard

> 标签: budget, claude-code, claude-plugin, rate-limit, subagents, tokens

## 简介

Claude Code plugin that limits subagent launches by default, records verified subagent usage, and optionally enforces 5-hour session budgets.
