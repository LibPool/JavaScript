# @yulimfish/opencode-tool-search

> 标签: dynamic-tools, kimi-k3, llm-tools, mcp, opencode, opencode-plugin, tool-search

## 简介

Dynamic tool loading for opencode — Kimi K3 tool-search pattern, adapted to opencode's plugin runtime. Collapses noisy tool descriptions into a searchable catalog so the LLM only sees relevant tools per turn.
