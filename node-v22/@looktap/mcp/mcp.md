# @looktap/mcp

> 标签: ai-agents, android, android-emulator, claude, ios, ios-simulator, iphone, mcp, mcp-server, mobile-automation, model-context-protocol

## 简介

MCP server that lets your AI agent see, use and control the apps on your phone: read the screen as text, tap by label, type, swipe, screenshot, read logs and crashes, on iPhone and Android.
