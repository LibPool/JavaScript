# @fffangchenghao/dsh-latex-look

> 标签: agent, dsh, latex, layout, pdf, plugin, synctex, vision

## 简介

DSH plugin: let an AI agent see a LaTeX document — compile it, render the page, locate the source line, and diff what an edit changed.
