# @raptortwentyone/openapi

> 标签: codegen, dotnet, generics, openapi, refit, swagger, tanstack-query, typescript

## 简介

Runs the Raptor21.OpenApi generator (C# Refit / TypeScript fetch + TanStack Query clients that keep generic response envelopes intact) from npm scripts. Installs the matching .NET tool on first use.
