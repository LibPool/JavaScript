# @majikah/majik-cjson

> 标签: arraybuffer, base64, binary, blob, browser, cloudflare-workers, compressed-json, compression, esm, fflate, gzip, json, json-compression, majikah, serialization, typescript

## 简介

Lightweight gzip-compressed JSON container with magic-byte framing. Compress, export, and restore typed JSON payloads as Blob, ArrayBuffer, or base64 — built for Cloudflare Workers and browser environments.
