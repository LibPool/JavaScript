# @majikah/majik-notary

> 标签: @solana/kit, blockchain, blockchain-notarization, chain-anchoring, content-authenticity, cryptographic-proof, cryptographic-verification, digital-notary, document-authenticity, document-integrity, document-signing, file-signing, immutable-audit-trail, majik-notary, majik-signature, majikah, notarization, proof-of-existence, proof-of-integrity, solana, solana-memo, spl-memo, tamper-evident, timestamping, trusted-timestamp, web3

## 简介

Chain-agnostic blockchain notarization library for Majik Signature. Creates independently verifiable proof-of-existence by anchoring sealed file hashes on-chain, with an initial implementation using the Solana blockchain.
