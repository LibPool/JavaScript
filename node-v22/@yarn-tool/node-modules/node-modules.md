# @yarn-tool/node-modules

> 标签: JavaScript

## 简介

Node.js 模組路徑尋找工具，特別適用於 Yarn Workspaces 環境。提供快速尋找專案中 node_modules 路徑的功能，支援 scoped packages 和一般 packages 的識別。
