# @geml/geml

> 标签: addressable, agent, ai, cli, code-graph, docs, document, geml, general expressive markup language, llm, markdown, markup, mcp, mcp-server, parser, typed-block, versioning

## 简介

Read and edit long Markdown by block instead of by file — geml list/find/get address any .md, nothing is converted. Plus GEML, a plain-text format where blocks carry ids for validated writes, reference checks and per-block history. Ships an MCP server.
