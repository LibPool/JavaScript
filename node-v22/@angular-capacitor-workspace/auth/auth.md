# @angular-capacitor-workspace/auth

> 标签: angular, auth, authentication, capacitor, cognito

## 简介

Sign-in for an angular-capacitor-workspace: a session, guards and an HTTP interceptor that work the same with every identity provider, and Amazon Cognito as the first.
