# code-secret-handler

> 标签: cli, devops, dotenv, env, hardcoded, scanner, secrets, security

## 简介

A language-agnostic CLI tool that scans codebases for hardcoded secrets, moves them to .env files, and rewrites source files with proper env-var references.
