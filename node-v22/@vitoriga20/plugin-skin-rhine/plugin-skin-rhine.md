# @vitoriga20/plugin-skin-rhine

> 标签: JavaScript

## 简介

Rhine/终末地工业皮肤 for the vibepm shell — 暗色金属 + 柠檬黄。向 :root 覆盖 @VIBE-SKIN token，装上即整皮切换为终末地风，卸载即撤回科研黄黑。
