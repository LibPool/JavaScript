# @parischap/effect-lib

> 标签: conversion, date, effect, format, formatting, functional-programming, matching, number, parse, parsing, pattern, rounding, sprintf, sscanf, templating, text, tree, typescript

## 简介

Collection of utility modules extending the official effect library: simple yet efficient pattern matching, cycle-safe tree module, mutable caching with optional bounded capacity and optional time-to-live, number and BigDecimal rounding, number and DateTi
