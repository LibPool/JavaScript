# @ishibashi0112/spreadsheet-grid

> 标签: datagrid, grid, react, react19, spreadsheet, ssrm, table, typescript, virtual-scroll, virtualized

## 简介

React 19 製のカスタム仮想化データグリッド。100 万行対応の仮想化・3 ペイン固定列・ソート/フィルター・クライアント/サーバーサイド行モデル対応。コアは @ishibashi0112/spreadsheet-grid-core。
