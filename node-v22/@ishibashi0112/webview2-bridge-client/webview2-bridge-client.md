# @ishibashi0112/webview2-bridge-client

> 标签: bridge, json-rpc, postMessage, react, vite, webview2, winforms, zod

## 简介

Front-end runtime for webview2-bridge: typed JSON-RPC client over WebView2 postMessage (WebView2Transport), in-browser MemoryTransport for development, and zod validation on both ends
