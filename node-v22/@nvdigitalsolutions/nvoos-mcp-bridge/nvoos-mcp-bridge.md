# @nvdigitalsolutions/nvoos-mcp-bridge

> 标签: bridge, claude, codex, cursor, mcp, model-context-protocol, nvoos, stdio, wordpress, zed

## 简介

Zero-dependency MCP stdio↔HTTP relay for NV oOS (Open Operator System) WordPress sites. Connect Zed, Claude Desktop, Cursor, and Codex to any NV oOS site over HTTPS or SSH.
