# @crossly/mcp

> 标签: ai-agent, claude, crosslister, crossly, depop, ebay, mcp, mercari, model-context-protocol, poshmark, reseller

## 简介

Self-hostable Model Context Protocol server for Crossly. Exposes the Crossly public API (15 marketplaces, 57 endpoints) as MCP tools so an AI agent (Claude Desktop, Cursor, Cline) can run a reseller's multi-marketplace store end-to-end.
