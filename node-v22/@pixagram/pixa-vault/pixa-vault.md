# @pixagram/pixa-vault

> 标签: argon2, argon2id, blake3, blockchain, chacha20, chacha20-poly1305, crypto, encryption, hive, kdf, key-derivation, pbkdf2-replacement, pin, pixagram, post-quantum, secure-storage, vault, wasm, web3, webassembly

## 简介

Post-quantum hardened secure vault for Pixagram — Argon2id + ChaCha20-Poly1305 + BLAKE3 in Rust/WASM. Drop-in replacement for PBKDF2-based key encryption, designed for short PINs.
