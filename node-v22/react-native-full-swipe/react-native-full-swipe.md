# react-native-full-swipe

> 标签: android, expo, full-swipe, gesture-handler, ios, leading-trailing-actions, list, react-native, reanimated, row, snackbar, swipe, swipe-actions, swipe-list, swipe-to-archive, swipe-to-delete, swipeable, swipeable-row, typescript, undo

## 简介

Full-swipe actions for React Native rows: swipe past a threshold you can feel to delete, archive or mark as read, with a different action on each side and an undo bar. Reanimated + Gesture Handler, UI thread, TypeScript.
