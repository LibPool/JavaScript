# @ramcna/capacitor-ephemeris

> 标签: capacitor, native, plugin

## 简介

Capacitor plugin that integrates Swiss Ephemeris (JNI) to calculate accurate planetary positions using SEPLM, SEPL_18, and SE1 ephemeris data files.
