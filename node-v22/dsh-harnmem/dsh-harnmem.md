# dsh-harnmem

> 标签: agents, deepseek-harness, dsh, dsh-plugin, harnmem, memory

## 简介

HarnMem memory plugin for the DSH (DeepSeek Harness) agent: byte-stable hot-index injection, memory tools, session-end extraction, and a read-only memory browser panel.
