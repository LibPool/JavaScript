# dokuha-cli

> 标签: bookwalker, cmoa, comic, dmm, downloader, ebookjapan, k-manga, kindle, manga, mokuro, ocr

## 简介

読破 (dokuha) — browserless CLI that downloads volumes from BookWalker, CMOA, ebookjapan, Kindle, k-manga and DMMブックス, and can hand them to mokuro-bridge for OCR.
