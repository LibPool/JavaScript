# @numaris-microfront/widget-dev-harness

> 标签: dev-tools, micro-frontends, numaris, testing

## 简介

Harness de desarrollo que emula el host de la plataforma Numaris: sesion de mentira, tema de marca, y un panel para inspeccionar y disparar eventos del Event Bus a mano.
