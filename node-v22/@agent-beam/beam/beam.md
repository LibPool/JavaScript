# @agent-beam/beam

> 标签: agent observability, ai agent security, ai safety, claude code, claude code hooks, cli, codex cli, cursor, heuristic detection, llm security, mcp scanner, mcp security, model context protocol, prompt injection, risk scanning, secret redaction

## 简介

Local-first observation and heuristic risk scanning for AI coding agents (Claude Code, Codex, Cursor, Copilot CLI, Gemini). Redacts secrets, flags risky tool calls, scans skills and MCP configs offline.
