# @jiesou/dsh-webui-fix-mobile-stats-line

> 标签: JavaScript

## 简介

Make the DSH Web UI stats line tooltip reachable on touch/coarse-pointer UIs: keep the bubble visible under dsh-mobile and toggle it per tap (client-only plugin).
