# @jalali-js/vue

> 标签: calendar, date, date-picker, datepicker, farsi, jalali, jalali-calendar, nuxt, persian, shamsi, vue

## 简介

Vue bindings for jalali-js: useCalendar composable, headless Calendar grid, a default-styled DatePicker, SSR-safe timezone resolution.
