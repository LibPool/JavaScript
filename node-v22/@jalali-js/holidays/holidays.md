# @jalali-js/holidays

> 标签: calendar, date, farsi, holidays, iran, iran-holidays, jalali, persian, shamsi

## 简介

Official Iran (IR) public holiday data for jalali-js: fixed Jalali rules, lunar year tables, and picker helpers. Offline, zero runtime dependencies. AF and TJ reserved.
