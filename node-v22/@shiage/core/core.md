# @shiage/core

> 标签: ast, css, devtools, jsx, shiage, tailwind, tailwindcss, tsx

## 简介

Framework-agnostic core for Shiage: CSS→Tailwind mapper, JSX AST editor, WebSocket protocol, diff generation.
