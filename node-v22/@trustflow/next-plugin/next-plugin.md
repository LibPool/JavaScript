# @trustflow/next-plugin

> 标签: did, did:web, llms.txt, next, nextjs, trustflow

## 简介

Trustflow Next.js config wrapper. Warns in development when public/llms.txt or public/.well-known/did.json is missing or invalid. Scaffold with npx @trustflow/cli@latest init.
