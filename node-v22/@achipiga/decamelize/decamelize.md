# @achipiga/decamelize

> 标签: camelcase, case, convert, dash, decamelcase, decamelize, hyphen, lowercase, str, string, text

## 简介

Convert a camelized string into a lowercased one with a custom separator: unicornRainbow → unicorn_rainbow
