# @adaptiveworx/iac-azure

> 标签: adaptiveworx, azure, fabric, iac, infrastructure-as-code, onelake, pulumi, typescript

## 简介

Reusable Pulumi infrastructure components for Microsoft Azure (Fabric, Storage, Key Vault, Networking). Empty skeleton — components are extracted into this library after they have stabilized through inline use in real Azure deployments.
