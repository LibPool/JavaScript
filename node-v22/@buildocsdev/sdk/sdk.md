# @buildocsdev/sdk

> 标签: backend-driven-ui, dynamic-ui, enterprise-ui, react-components, schema-driven-ui, ui-runtime, workflow-engine

## 简介

Buildocs SDK is a backend-driven UI runtime for rendering dynamic interfaces, workflows, tables, and modals inside React applications.
