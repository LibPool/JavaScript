# @piwikpro/nuxt-piwik-pro

> 标签: analytics, nuxt, piwik-pro, plugin

## 简介

Dedicated Piwik PRO library that helps with implementing Piwik PRO Tag Manager and the Piwik PRO tracking client in Nuxt.js applications.
