# @valeness/hangar

> 标签: cockpit, components, css, css-framework, design-system, design-tokens, hud, oklch, ui

## 简介

A cockpit/HUD UI framework: global CSS classes for components, instruments and readouts in OKLCH, dark and light, plus optional dependency-free JS behaviour that works in React, Vue, Svelte or plain HTML.
