# @contextgit/store

> 标签: JavaScript

## 简介

Storage interface (`ContextStore`) plus the LocalStore (SQLite + sqlite-vec), RemoteStore (HTTP), and SupabaseStore (Postgres + pgvector) backends for [ContextGit](https://www.npmjs.com/package/contextgit).
