# @ngxrx/store

> 标签: JavaScript

## 简介

### 初衷 - rxjs配合依赖注入可以很方便并且灵活地实现状态服务，但是灵活的另一方面又会导致状态库代码不够规范，状态的处理逻辑和其他业务逻辑杂糅的情况 - redux风格的状态库可以让代码更规范健壮，然而过多的概念及代码量会增加开发者的心智负担
