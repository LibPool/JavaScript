# @pdsjs/oci

> 标签: JavaScript

## 简介

Host OCI container images natively in an atproto account. Tags, manifests and layers live in the account's PDS as a `dev.pdsjs.oci.repo` record plus blob storage, so an image rides along in CAR backups, migrates with the account, and needs no separate reg
