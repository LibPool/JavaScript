# @gansotech/astro-datasource-gitlab

> 标签: astro, astro-loader, documentation, gitlab, starlight, withastro

## 简介

Astro content loader that fetches Markdown docs and their assets from a GitLab repository over the REST API. Built for Starlight docs sites, works with any content collection.
