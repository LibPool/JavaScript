# @plinth-dev/sketch

> 标签: architecture, diagram, documentation, dsl, plinth, svg

## 简介

Render Plinth Sketch DSL files to typeset SVG architecture diagrams. Drop the DSL in your repo, render at build time, embed the SVG in your README.
