# @veltrosecurity/shell

> 标签: JavaScript

## 简介

Veltro suite shell — cross-app navigation chrome (AppSwitcher, SuiteTopBar, SuiteLanding, command palette) shared between VectorFlow, CHAD, and future suite apps. Framework-agnostic React built on @veltrosecurity/ui and @veltrosecurity/tokens.
