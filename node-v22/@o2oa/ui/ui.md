# @o2oa/ui

> 标签: JavaScript

## 简介

- oo-input：`输入框` - oo-button：`按钮` - oo-checkbox：`多选框` - oo-checkbox-group：`多选框组` - oo-code-editor：`脚本编辑器 （需要单独引入）` - oo-radio：`单选框` - oo-radio-group：`单选框组` - oo-select：`选择框` - oo-optionGroup：`选择框的选项组` - oo-option：`选择框的选项` - oo-selector：`人员选择框`
