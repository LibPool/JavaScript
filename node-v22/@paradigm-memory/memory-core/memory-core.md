# @paradigm-memory/memory-core

> 标签: agent, audit, cognitive-map, embeddings, fts5, llm, local-first, mcp, memory, rag, sqlite

## 简介

Local-first cognitive map retrieval engine. SQLite + FTS5 + pluggable embeddings, with audited mutations and an offline consolidator.
