# @oauthkit/agentauth

> 标签: agent-auth, ai-agent, cli, device-flow, github, mcp, notion, oauth, oauth2, slack

## 简介

OAuth in 3 lines for AI agents. Device flow + localhost callback, multi-provider, OS keychain storage, auto-refresh. Built for CLI / desktop / MCP-server contexts where browser-redirect OAuth doesn't fit.
