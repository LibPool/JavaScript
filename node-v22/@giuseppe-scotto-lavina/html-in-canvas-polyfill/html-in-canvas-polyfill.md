> 标签: canvas, drawElementImage, drawable, foreignObject, html-in-canvas, paint-event, polyfill, webgl, webgpu, whatwg, wicg

## 简介

Polyfill for the proposed HTML-in-Canvas API (content="drawable", drawElementImage, the paint event) over a live DOM, for desktop Chrome, Firefox 155+ and Safari 27+, Chrome for Android 130+ and Safari on iOS 26+. Native-first: steps aside where the brows
