# @flayerlabs/nftx-v4-sdk

> 标签: amm, base, ethereum, nft, nftx, sdk, uniswap-v4, viem

## 简介

Strict TypeScript SDK for NFTX v4 on Ethereum and Base: canonical deployments, quotes, transaction plans, guarded calldata, and viem-backed execution.
