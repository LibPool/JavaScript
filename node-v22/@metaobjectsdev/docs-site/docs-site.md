# @metaobjectsdev/docs-site

> 标签: JavaScript

## 简介

HTML documentation-site generator for metaobjects models — a browsable multi-page site (nav, search, per-object/package pages, kind-aware ER diagrams). Powers the `meta docs --site` surface.
