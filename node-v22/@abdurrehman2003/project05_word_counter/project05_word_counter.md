# @abdurrehman2003/project05_word_counter

> 标签: JavaScript

## 简介

This TypeScript and Inquirer-based word counter app prompts for a paragraph, then calculates and shows the word count and character count (excluding whitespaces), offering a quick and user-friendly text analysis.
