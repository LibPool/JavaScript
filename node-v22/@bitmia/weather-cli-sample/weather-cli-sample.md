# @bitmia/weather-cli-sample

> 标签: ascii, cli, forecast, terminal, weather

## 简介

CLI weather tool with ASCII art — current local weather, 4-day forecast, and best city within driving range. Boxed terminal output, ANSI colors, wind/sun/moon/UV, JSON mode.
