# @voltarenyah/dsh-prompt-note

> 标签: cordis, cordis-plugin, deepseek, deepseek-harness, dsh, dsh-plugin, prompt, prompt-queue, sidebar

## 简介

A Session-bound pending-prompts list for DeepSeek Harness (DSH): write the next prompt in a right-sidebar tab while the agent is still working, then send it when you are ready.
