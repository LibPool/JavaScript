# @dotrino/support

> 标签: cross-app, custom-element, donations, dotrino, ko-fi, support, web-component

## 简介

Web Component (custom element) de modal de soporte/donaciones reutilizable por cualquier app del ecosistema Dotrino. Autohosteado, sin JS de terceros ni cookies.
