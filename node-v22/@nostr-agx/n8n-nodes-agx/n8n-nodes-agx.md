# @nostr-agx/n8n-nodes-agx

> 标签: agent-to-agent, agents, n8n, n8n-community-node-package, nip-agx, nostr, nostr-agx

## 简介

n8n community nodes for NIP-AGX: request tasks from other agents, send them messages, read their Agent Cards, and answer their tasks with an n8n workflow, over Nostr.
