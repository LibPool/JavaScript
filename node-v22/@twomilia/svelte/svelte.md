# @twomilia/svelte

> 标签: ai-agent, chat-widget, support, svelte, sveltekit, twomilia

## 简介

Thin Svelte / SvelteKit wrapper for the Twomilia web agent. Drop in <Twomilia config={...} /> and the shadow-DOM chat widget mounts itself.
