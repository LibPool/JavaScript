> 标签: advertising, ai, brain, fmri, mcp, model-context-protocol, neuro, sapient

## 简介

Model Context Protocol (MCP) server for the Sapient brain-response API — run scans, read your scan history, query cross-scan intelligence, and read the Sapient knowledge base from any MCP client.
