# @prisma/composer-prisma-cloud

> 标签: JavaScript

## 简介

The Prisma Cloud target for Prisma Composer: compute(), postgres() (ORM-managed, via /orm), rawPostgres(), the target extension, and first-party modules realized on Prisma Cloud (cron).
