> 标签: clock-drift, cristian-algorithm, magmacomputing, network-time, ntp, plugin, server-timing, sntp, tempo, tempo-plugin, temporal, time-sync, typescript

## 简介

Tempo plugin providing client-server network time synchronization and monotonic clock drift compensation using Cristian's algorithm and HTTP Server-Timing headers.
