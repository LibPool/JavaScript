# @pgmi-builds/omp-web-sdk

> 标签: JavaScript

## 简介

OMP Web SDK line: same dsh bridging contract as omp-web, but the OMP core is embedded via the @oh-my-pi/pi-coding-agent SDK (Bun sidecar) instead of `omp --mode rpc`.
