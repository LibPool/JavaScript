# @pgmi-builds/better-dsh

> 标签: agent, deepseek-harness, dsh, eval, ipython, kernel, plugin, repl

## 简介

Better Dsh (Dashr): a persistent Python-kernel REPL for DeepSeek Harness (dsh) — eval cells with tool.* bindings, scheme:// resource addressing, and a wired-in IDE (LSP, AST, hashline edit)
