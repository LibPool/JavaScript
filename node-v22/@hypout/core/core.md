# @hypout/core

> 标签: broker, crdt, presence, pubsub, realtime, replay, rfc6455, socket.io-alternative, websocket, zero-dependency

## 简介

Zero-dependency real-time engine: RFC 6455 WebSocket codec and handshake, CRDT presence, ring-buffer replay, pub/sub broker and HP-101..106 gates. No ws, no socket.io.
