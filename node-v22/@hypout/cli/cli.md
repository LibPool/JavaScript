# @hypout/cli

> 标签: cli, crdt, presence, pubsub, realtime, rfc6455, self-hosted, websocket

## 简介

Run a self-hosted Hypout real-time server: WebSocket upgrade, pub/sub channels, CRDT presence, replay, a hash-chained audit ledger and the Studio. One command, no ws, no socket.io.
