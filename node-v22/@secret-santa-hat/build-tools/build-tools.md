# @secret-santa-hat/build-tools

> 标签: build, changelog, git, github, release, secret-santa-hat, versioning

## 简介

Release build tools for Secret Santa Hat JavaScript repositories. Provides the `ssh-release` command, a JS-tailored port of the gcrq (git_create_release_quiet) release flow.
