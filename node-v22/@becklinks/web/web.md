# @becklinks/web

> 标签: becklinks, deep links, deferred deep linking, smart banner

## 简介

Beck Links for websites: create deep links from the browser and show an open-in-app banner. No dependencies, no cookies.

- 官网：https://docs.becklinks.com/sdks/web
- npm 页面：https://www.npmjs.com/package/@becklinks/web
