# @evinvest/error-monitoring

> 标签: JavaScript

## 简介

Vendor-neutral error-monitoring toolkit: a tiny injectable ErrorSink core plus Sentry adapters for React, Node/Edge, and Next.js. Mirrors the error_monitoring Cargo feature.
