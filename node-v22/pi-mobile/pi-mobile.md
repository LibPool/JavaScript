# pi-mobile

> 标签: e2e, mobile, phone, pi, pi-extension, pi-package, remote-control, web-push

## 简介

Continue every pi session from your phone: end-to-end encrypted, no server needed, answer any extension's dialogs, lock-screen notifications. Works in the browser, or with the native iPhone and Android apps.
