# flowrail

> 标签: agent-safety, ai-agents, claude, claude-code, cli, coding-agents, developer-tools, flowrail, git, guardrails, hooks, llm-safety, local-first, mcp, pretooluse, security

## 简介

Guardrails for Claude Code that hold. A PreToolUse hook parses every command before it runs, the agent cannot switch it off, and `flowrail audit` replays your past sessions to show what it would have caught. Zero deps, no cloud, MIT.
