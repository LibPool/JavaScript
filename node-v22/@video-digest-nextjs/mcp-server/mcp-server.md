# @video-digest-nextjs/mcp-server

> 标签: JavaScript

## 简介

Video Digest 的标准 MCP stdio 服务。它通过网站侧 `/api/mcp` HTTP gateway 转发请求，让 MCP 客户端可以使用网站生成的 MCP Token 创建视频摘要任务、读取视频摘要记录、字幕、摘要和邮件投递状态。
