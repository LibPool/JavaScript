# pi-codemode-snippets

> 标签: agentic-coding, ai-agent, ai-coding, cli-snippets, codemode, composition, developer-tools, idempotent, json-schema, llm, mcp, pi, pi-coding-agent, pi-extension, pi-package, pi-skill, quickjs, sandbox, script-to-tool, snippets, tool-calling, tool-registry, tools, typescript

## 简介

Pi extension that turns user-authored `.js` codemode snippets (a `// @snippet:` pragma plus a sandbox script) into first-class pi tools the model, other tools, and codemode scripts can call.
