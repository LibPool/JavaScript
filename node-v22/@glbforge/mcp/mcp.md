> 标签: 3d, ai, draco, glb, gltf, ktx2, mcp, mesh-optimization, meshopt, meshy, model-context-protocol, react-three-fiber, threejs, webgl

## 简介

GLBForge MCP server — agent-oriented 3D asset tooling: validate / inspect / render GLB and USDZ with stable error codes and prim paths, plus optimize, export, and generation.
