# @egose/keycloak-fluent

> 标签: automation, declarative, dsl, fluent, iam, identity-management, keycloak, keycloak-admin, keycloak-admin-client, provisioning, typescript

## 简介

Fluent TypeScript wrapper for the Keycloak Admin API with idempotent provisioning for realms, users, clients, flows, organizations, and admin operations.
