# @infra-tools/agentic-ui-copilot-skill

> 标签: JavaScript

## 简介

GitHub Copilot Extensions adapter for the @infra-tools/agentic-ui platform. Wraps the Copilot skill webhook protocol: verifies the GitHub signed request, parses incoming messages, exposes a typed handler seam, and streams OpenAI-shaped SSE chunks back. Se
