# @nredd/pi-dev-tools

> 标签: pi-extension, pi-package

## 简介

Typed pi tools for git, ssh, Python (uv/ruff/ty/pytest) and Rust (cargo): compact structured results, explicit exit-code states, no-shell spawn, bounded output.
