> 标签: agents, confirmation, consent, llm, mcp, model-context-protocol, otp, payments, step-up, tool-use

## 简介

Single-use, caller-bound confirmation tokens with an optional out-of-band step-up code, for MCP tools that move money or do anything consequential.
