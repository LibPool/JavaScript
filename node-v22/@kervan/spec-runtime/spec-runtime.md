# @kervan/spec-runtime

> 标签: ai-agents, http, mcp, mcp-server, model-context-protocol, no-code, yaml

## 简介

Turn a kervan.yaml spec into MCP tools that call HTTP APIs: templates, JMESPath output selection, SSRF protection and secret redaction.
