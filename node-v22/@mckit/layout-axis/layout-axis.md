# @mckit/layout-axis

> 标签: JavaScript

## 简介

Axis layout for MC Kit: a dark navigation sidebar, a white topbar with **left / center / right** slots and a light content area. Built for Angular 21, PrimeNG 21 and Tailwind CSS v4.
