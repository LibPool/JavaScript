# @cxbox-ui/schema

> 标签: JavaScript

## 简介

This package includes schemas shared by [Cxbox](https://github.com/CX-Box/cxbox) and [Cxbox-UI](https://github.com/CX-Box/cxbox-ui) in form of Typescript types, their corresponding JSON schemas and utilities to extend built-in types and rebuild the schema
