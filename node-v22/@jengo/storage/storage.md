# @jengo/storage

> 标签: chunking, codeigniter4, flysystem, jengo, r2, resumable, s3, storage, upload

## 简介

Universal client library for Jengo Storage featuring chunked uploads, resumability, direct-to-cloud S3/R2 transfers, and framework adapters.
