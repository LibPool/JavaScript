# @thg-agentic/hyper-personalisation-web

> 标签: JavaScript

## 简介

Browser SDK for the THG Hyper-Personalisation event specification: event tracking from a write key and remote settings, strict CMP-agnostic consent, a GA4 dataLayer bridge and in-session audience evaluation. Dependency-free ESM on the Segment wire protoco
