# system-design-and-plan-skill

> 标签: adr, agent-skill, architecture, backlog, claude-code-plugin, engineering, estimation, planning, roadmap, system-design

## 简介

An agent skill that produces a rigorous, evidence-backed engineering plan before any code is written: architecture, data model, flows, ADRs, a derived effort model, and a granular backlog.
