# @apowerb/apowerb-sdk

> 标签: agents, api, apowerb, rag, sdk, thaink2

## 简介

JavaScript SDK for the apowerb backend: agents, tools, RAG, BI, webhooks and billing. Dependency-free, runs in the browser and in Node.
