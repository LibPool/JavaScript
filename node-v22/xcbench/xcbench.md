# xcbench

> 标签: board, dashboard, deepseek-harness, dsh, dsh-plugin, schedule, workbench, xcbench

## 简介

XCbench — workbench layout for DeepSeek Harness: task-state strip, schedule board with per-status tints, weather/clock bar and a right-hand quick-chat column.
