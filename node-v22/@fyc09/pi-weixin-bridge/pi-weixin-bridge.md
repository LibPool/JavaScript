# @fyc09/pi-weixin-bridge

> 标签: ai-agent, clawbot, coding-agent, extension, ilink, pi, pi-package, wechat, wechat-bot, wechat-bridge, weixin, 微信

## 简介

微信机器人 extension for pi — 通过微信官方 iLink/ClawBot 接口，扫码登录后微信私聊消息自动转发给 pi，pi 回复自动发回微信。
