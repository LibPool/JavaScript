# @frink-okn/actor-query-source-identify-hypermedia-sparql-bounded

> 标签: JavaScript

## 简介

Comunica's SPARQL endpoint source with bounded COUNT queries, timed by the server, source selection that accepts a bounded count without an ASK, and source grouping that nests only what a source takes
