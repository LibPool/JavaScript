# @tablecharts/mcp-server

> 标签: charts, claude, csv, cursor, dashboard, data-visualization, google-sheets, mcp, model-context-protocol, notion, salesforce, tablecharts

## 简介

MCP server for TableCharts — turn tables (CSV, JSON, Notion, Google Sheets, Salesforce) into shareable interactive dashboards from Claude, Cursor, and any MCP client.
