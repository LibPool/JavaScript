# @vibeorm/scoped-conformance

> 标签: conformance, multi-tenancy, orm, prisma, row-level-security, tenant-scoping, test-vectors, typescript, vibeorm

## 简介

Binding-agnostic conformance artifact for the tenant-scoped database handle ($scoped): the canonical fixture schema, seed, tenancy map, rewrite vectors and behavior checklist that every binding (VibeORM first-class, Prisma extension) must satisfy
