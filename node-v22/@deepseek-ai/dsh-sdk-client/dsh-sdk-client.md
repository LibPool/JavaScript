# @deepseek-ai/dsh-sdk-client

> 标签: JavaScript

## 简介

TypeScript client SDK for driving a DeepSeek Harness runtime subprocess over stdio JSON-RPC: the DeepSeekHarness high-level turns API and the lower-level HarnessClient
