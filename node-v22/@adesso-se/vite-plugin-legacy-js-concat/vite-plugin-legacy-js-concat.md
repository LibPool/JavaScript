# @adesso-se/vite-plugin-legacy-js-concat

> 标签: concat, gulp, javascript, legacy, vite, vite-plugin

## 简介

Concatenate legacy JavaScript files in a specific order into a single bundle for Vite, replacement for gulp-concat.
