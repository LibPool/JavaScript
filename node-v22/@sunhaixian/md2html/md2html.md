# @sunhaixian/md2html

> 标签: html, inline-style, markdown, wechat, weixin, 公众号排版, 微信公众号, 排版

## 简介

将 Markdown 文件转换为微信公众号编辑器兼容的 HTML 文件。自动注入内联样式，直接复制到公众号后台即可使用。
