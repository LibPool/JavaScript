# @jbrowse/shader-tools

> 标签: codegen, glsl, jbrowse, jbrowse2, shader, slang, wgsl

## 简介

Slang → WGSL/GLSL + typed-TS shader codegen for JBrowse GPU displays (the `pnpm gen:shaders` pipeline)
