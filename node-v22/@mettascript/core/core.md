# @mettascript/core

> 标签: atomspace, hyperon, interpreter, metta, opencog, symbolic-ai, typescript

## 简介

MeTTa (OpenCog Hyperon) interpreter in pure TypeScript: atoms, spaces, type system, pattern matching, evaluation, and the standard library.
