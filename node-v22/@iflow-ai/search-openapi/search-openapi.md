# @iflow-ai/search-openapi

> 标签: coze, http, iflow, iflow-search, image-search, open-webui, openapi, tool-server, web-fetch, web-search

## 简介

HTTP / OpenAPI tool server for the iFlow Search API. Exposes web search, image search, and web fetch over JSON-over-HTTP for Open WebUI, Coze, and other OpenAPI 3.x tool hosts. Built on @iflow-ai/search-core.
