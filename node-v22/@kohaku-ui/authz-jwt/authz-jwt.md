# @kohaku-ui/authz-jwt

> 标签: JavaScript

## 简介

JWT / OIDC identity resolution for kohaku hosts (principal, roles, tenant from claims) with capability tokens delegated to @kohaku-ui/authz-hmac — a reference adapter; the contract stays @kohaku-ui/spec-core's ports.ts.
