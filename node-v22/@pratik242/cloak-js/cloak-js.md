# @pratik242/cloak-js

> 标签: domain-lock, frontend-protection, javascript, next-plugin, obfuscator, parcel-plugin, secure-js, tamper-protection, vite-plugin, wasm

## 简介

A powerful frontend code protector: obfuscates JavaScript, injects anti-tamper runtime, locks domains, and supports Vite/Next.js/Parcel plugins.
