# @tanbo/ui-ie9

> 标签: angular components, angular ui, component, theme, ui

## 简介

@tanbo/ui是一个基于 Angular 的组件库，并基于最小改动，最小学习成本的前提下，拓展了部分表单控件，提供了很多网页上的视觉交互组件、指令、服务、过滤器等等。并提供了一套侵入性很小的底层css样式表。
