# @tahul/uri-js

> 标签: HTTP, HTTPS, IDN, IRI, MAILTO, RFC2141, RFC2616, RFC2818, RFC3986, RFC3987, RFC4122, RFC4291, RFC5891, RFC5952, RFC6068, RFC6455, RFC6874, URI, URN, UUID, WS, WSS

## 简介

An RFC 3986/3987 compliant, scheme extendable URI/IRI parsing/normalizing/resolving/serializing library for JavaScript.
