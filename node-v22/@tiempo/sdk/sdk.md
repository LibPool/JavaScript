# @tiempo/sdk

> 标签: api, appointments, availability, booking, booking-api, booking-engine, calendar, classes, double-booking, reservations, scheduling, scheduling-api, sdk, tiempo, webhooks

## 简介

TypeScript client for Tiempo, the scheduling API for booking platforms: availability search, holds and bookings that never double-book, classes, recurring series and signed webhooks.

- 官网：https://tiempo.one/docs
