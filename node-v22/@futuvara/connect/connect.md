# @futuvara/connect

> 标签: JavaScript

## 简介

Connect a coding agent to a Futuvara project: adds the Futuvara MCP server, installs every Futuvara skill and applies the project config.

- 官网：https://www.futuvara.com
- 源码仓库：git+https://github.com/Futuvara-Agentic/Futuvara.git
