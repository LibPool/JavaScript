# @layerhop/goat

> 标签: ai-agents, bridge, cross-chain, defi, evm, goat, goat-sdk, layerhop, onchain-agents, solana, swap

## 简介

LayerHop plugin for the GOAT SDK: best-price cross-chain and same-chain swap quotes, unsigned transactions, deposit addresses and checkout for on-chain agents. LayerHop never sees keys.
