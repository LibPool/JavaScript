# @layerhop/plugin-elizaos

> 标签: ai-agents, bridge, cross-chain, defi, eliza, elizaos, elizaos-plugin, evm, layerhop, solana, swap

## 简介

LayerHop plugin for ElizaOS: best-price cross-chain and same-chain swap quotes, unsigned transactions with an explicit confirmation step, deposit addresses and checkout. Holds no keys and never auto-signs.
