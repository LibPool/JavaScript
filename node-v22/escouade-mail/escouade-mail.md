# escouade-mail

> 标签: agent, ai-agent, e-mail, email, escouade, ia, inbox, mcp, subagent

## 简介

TypeScript SDK for Escouade Mail (formerly Subagent): real mailboxes for AI agents, with sending rules enforced by the server.
