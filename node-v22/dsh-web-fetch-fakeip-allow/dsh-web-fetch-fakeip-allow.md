# dsh-web-fetch-fakeip-allow

> 标签: clash, deepseek-harness, dns, dsh, dsh-plugin, fake-ip, mihomo, web-fetch

## 简介

DSH host plugin: let web_fetch reach domains the local Clash/mihomo TUN resolves into its fake-ip pools (IPv4 198.18.0.0/15, IPv6 2001:2::/48), while every other non-public address stays blocked.
