# @cjser/camelcase

> 标签: camel, camel-case, case, convert, dash, dot, hyphen, pascal-case, pascalcase, separator, string, text, underscore

## 简介

Convert a dash/dot/underscore/space separated string to camelCase or PascalCase: `foo-bar` → `fooBar`
