# redactly

> 标签: gdpr, logging, mask, pci, pii, pino, redact, redaction, sanitize, secrets, security, winston

## 简介

Redact secrets and personal data (tokens, cards, IBANs, emails, API keys) from logs by detecting the values themselves, not just known paths. Zero dependencies, any runtime.
