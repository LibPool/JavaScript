# @darkm3tter/codeprovenance

> 标签: agents, ai, claude-code, git, opencode, provenance, traceability

## 简介

AI-blame: trace which agent, session and prompt generated each file change. Reads opencode and Claude Code session logs, stores locally in SQLite, stamps commits.
