# @sleetdrop/dsh-plugin-topology

> 标签: cordis, deepseek-harness, dsh-plugin, graphviz, plugin-topology

## 简介

Plugin dependency graph inspector for DeepSeek Harness: a host service that snapshots the live Cordis plugin fiber tree, a graph.render tool for the model, and a browser panel that renders the plugin/service topology as a zoomable graph with metrics, lege
