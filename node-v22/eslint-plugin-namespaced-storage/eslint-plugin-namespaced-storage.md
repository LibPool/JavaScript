# eslint-plugin-namespaced-storage

> 标签: eslint, eslint-plugin, eslintplugin, localstorage, namespaced-storage, sessionstorage

## 简介

ESLint rules that keep browser storage behind a namespaced store: no raw localStorage, literal namespaces, reserved keys, co-located declarations.
