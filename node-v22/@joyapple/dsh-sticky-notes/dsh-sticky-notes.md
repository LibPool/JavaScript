# @joyapple/dsh-sticky-notes

> 标签: JavaScript

## 简介

StickyMind：DSH 便签插件。右下角浮动便签板，马卡龙配色、字数上限、自动保存，还能把便签贴到页面任意位置自由拖动（贴出/收回/置顶/固定位置）。StickyMind: a pretty sticky-notes board for DSH — pastel notes, char limit, autosave, and tear-off notes that float anywhere on the page with drag, pin and position-lock.
