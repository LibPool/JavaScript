# @diamonddigitaldev/electron-kit

> 标签: accessibility, auto-update, bootstrap, design-system, electron, ui-components

## 简介

The shared design system for Diamond Digital Development's Electron apps: main-process behaviour, a shared preload, page components and CSS, and test helpers.
