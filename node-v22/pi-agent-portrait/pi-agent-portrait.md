> 标签: ai-agents, avatar, coding-agent, emote, kitty-graphics, pi-coding-agent, pi-extension, pi-package, pixel-art, terminal, tui

## 简介

Animated pixel-art portrait for the pi coding agent that reacts to thinking, tools, failures and idle time, with a script that draws a custom character for each agent
