# @gavinc-cn/dsh-readonly-guard

> 标签: cordis, deepseek-harness, dsh, guard, plugin

## 简介

只读守卫: bash 命令分类为只读则放行, 可能修改系统的默认转 DSH 原生审批 (ask, 可配 deny 复刻 kimi); 沿用 kimi 的审批标记 ######USER_APPROVED###### 与 ~/.kimi-code/readonly_whitelist.json / readonly_pending.jsonl 数据格式。
