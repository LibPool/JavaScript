# @gavinc-cn/dsh-plugins-ui

> 标签: bundle, cordis, deepseek-harness, dsh, plugin, ui

## 简介

DSH 插件组合包（UI bundle）：5 个面向 Web GUI 的组件（其中 dsh-patch-ask-expand 由宿主侧启动时给官方 client bundle 打补丁实现），每个是一行独立开关；其余宿主侧组件见 @gavinc-cn/dsh-plugins-runtime。
