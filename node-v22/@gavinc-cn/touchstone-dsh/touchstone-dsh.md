# @gavinc-cn/touchstone-dsh

> 标签: agent, automation, deepseek-harness, dsh, dsh-plugin, testing, touchstone

## 简介

AI-agent-driven automated testing platform for DeepSeek Harness (dsh): Markdown case library, bug reports, per-project serial queue, development board and built-in load testing.
