# @nwire/logger

> 标签: log, logger, nwire, observability

## 简介

Nwire — Logger contract + Noop + Console defaults. Production adapters: @nwire/logger-pino, @nwire/logger-winston. Envelope ids auto-attached via loggerForEnvelope.
