# @henriquecosta/chaos-api

> 标签: JavaScript

## 简介

Middleware pra simular falhas de producao (delay, erros, timeout, indisponibilidade, respostas malformadas/obsoletas) em APIs Express/Fastify/NestJS/Koa durante desenvolvimento.
