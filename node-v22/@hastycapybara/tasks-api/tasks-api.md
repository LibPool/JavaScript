# @hastycapybara/tasks-api

> 标签: markdown, obsidian, tasks, types, vscode

## 简介

TypeScript types for the public API of the Tasks for Markdown VS Code/Cursor extension (getAPI(1)): queries, edits, notes, events. Types only — no runtime code.
