# @z-ai/terminal

> 标签: cli, editor, micro, terminal, text-editor

## 简介

终端文本编辑器（基于 micro 2.0.15），安装后在终端输入 terminal 即可启动

## 官网

- npm 页面：https://www.npmjs.com/package/@z-ai/terminal

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- npm 安装：`npm install @z-ai/terminal`
- npm registry：https://registry.npmjs.org/@z-ai/terminal
- Node 要求：>=18
