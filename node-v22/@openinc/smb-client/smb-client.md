# @openinc/smb-client

> 标签: cifs, fileshare, libsmbclient, samba, smb, smb2, smb3

## 简介

SMB1/2/3 client for Node.js, backed by native libsmbclient (Samba) via koffi FFI. Usable as a library or as a standalone HTTP container.
