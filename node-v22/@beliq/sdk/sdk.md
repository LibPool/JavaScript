# @beliq/sdk

> 标签: beliq, compliance, e-invoice, einvoice, en16931, factur-x, peppol, sdk, xrechnung, zugferd

## 简介

Official beliq SDK: generate, validate, parse, and convert EU-compliant e-invoices (XRechnung, ZUGFeRD, Factur-X, Peppol BIS) against authority-pinned, drift-checked rules.
