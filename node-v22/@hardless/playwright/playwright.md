# @hardless/playwright

> 标签: e2e, emulator, escpos, fixture, matchers, playwright, point-of-sale, pos, receipt-printer, testing, web-nfc, web-serial, webusb

## 简介

Playwright fixture and matchers (toHavePrinted, toHaveOpened, ...) for testing POS web apps against emulated receipt printers, cash drawers, scanners and NFC readers.
