# @hardless/shim-web

> 标签: barcode-scanner, cash-drawer, emulator, escpos, ndef, point-of-sale, polyfill, pos, receipt-printer, shim, testing, web-nfc, web-serial, webusb

## 简介

Drop-in navigator.serial, navigator.usb and NDEFReader backed by emulated POS devices (receipt printer, cash drawer, NFC reader, barcode scanner), for developing and testing web apps without hardware.
