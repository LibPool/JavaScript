# @osm-editor-kit/react-map-gl-draw

> 标签: draw, edit, geojson, maplibre, maplibre-gl, react, react-map-gl

## 简介

Draw and edit points, lines and polygons on a react-map-gl (MapLibre) map as a controlled React component: value in, onChange out, styles as layer styles.
