# @lenso/otel

> 标签: JavaScript

## 简介

The root export is the official OpenTelemetry API only. Core, Engine and Tasks record telemetry without initializing an SDK; without an entry bootstrap it is no-op. Logger is a separate structural interface from `@lenso/core`.
