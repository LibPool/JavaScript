# @voidbase-cloud/voidbase

> 标签: baas, backend, cloudflare-workers, d1, pocketbase, r2, void

## 简介

PocketBase-compatible backend on Cloudflare Workers (D1, R2, Queues, Durable Objects) via Void, or a single Bun process
