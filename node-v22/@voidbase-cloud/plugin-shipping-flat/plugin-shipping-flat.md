# @voidbase-cloud/plugin-shipping-flat

> 标签: cloudflare-workers, shipping, voidbase, voidbase-plugin

## 简介

The flat-rate shipping plugin of voidbase: provides shipping@1, one rate from two knobs, free over a threshold
