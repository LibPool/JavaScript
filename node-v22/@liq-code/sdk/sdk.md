# @liq-code/sdk

> 标签: agent, ai, cli, coding-agent, liq, liq-code, llm, sdk

## 简介

TypeScript SDK for the LIQ CODE coding agent — drive it from a script and stream every file edit, command and token as a typed async iterable.
