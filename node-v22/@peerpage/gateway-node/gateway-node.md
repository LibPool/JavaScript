# @peerpage/gateway-node

> 标签: allowlist, express, gateway, hono, identity-token, peerpage, rpc, websocket

## 简介

Peerpage resident gateway for Node/TypeScript backends — an outbound WebSocket to the platform, a local allow-list dispatcher, and the same-origin identity-token route. Framework-agnostic core + thin Express and Fetch (Hono/Bun/Deno/Workers/Next) adapters
