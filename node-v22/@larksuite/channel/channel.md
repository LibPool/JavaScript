# @larksuite/channel

> 标签: bot, channel, feishu, im, lark, larksuite, sdk, websocket

## 简介

Channel SDK — let agents and external services integrate with the Feishu/Lark messaging system: reliable inbound events, message normalization, streaming replies, media upload, card interactions.
