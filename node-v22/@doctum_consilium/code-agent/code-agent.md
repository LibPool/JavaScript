# @doctum_consilium/code-agent

> 标签: agent, ai, cli, coding-agent, litellm, llm, ollama, tui

## 简介

Agents de code spécialisés dans le terminal : un modèle LLM par agent, sur n'importe quel back-end (gateway LiteLLM, Ollama, LM Studio, vLLM, API directes).
