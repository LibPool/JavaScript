# @magic-spells/sticky-header

> 标签: custom-elements, header, hide-on-scroll, reveal, scroll, sticky, sticky-header, web-components

## 简介

Scroll-following sticky header web component — the header tracks the scroll 1:1 and settles to shown or hidden on idle, with sticky-content riders, breakpoint gating, and lock support, no dependencies
