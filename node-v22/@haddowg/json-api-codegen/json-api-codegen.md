# @haddowg/json-api-codegen

> 标签: api, cli, code-generation, codegen, json-api, jsonapi, openapi, typescript

## 简介

CLI that reads the json-api-symfony OpenAPI spec (+ JSON Schemas) and emits a typed client descriptor.
