# lumenql

> 标签: apq, browser, bun, cache, client, dedupe, defer, deno, edge, esm, fetch, file-upload, gql, graphql, graphql-client, graphql-ws, isomorphic, lightweight, live-queries, lru-cache, lumenql, middleware, node, pagination, persisted-queries, react, react-hooks, retry, solid, sse, stream, subscriptions, subscriptions-transport, suspense, svelte, typed, typescript, vue, websocket, zero-dependency

## 简介

Zero-dependency, typed GraphQL client with caching, request deduplication, retries, subscriptions, streaming and React hooks. Works with the Fetch API across runtimes.
