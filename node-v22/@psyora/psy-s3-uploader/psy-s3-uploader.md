# @psyora/psy-s3-uploader

> 标签: JavaScript

## 简介

**Psy-S3-Uploader** library is created to securely upload images and files to S3 bucket from and Angular application. This library was generated with [Angular CLI](https://github.com/angular/angular-cli) version 10.0.14.
