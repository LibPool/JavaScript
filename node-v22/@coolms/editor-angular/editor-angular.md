# @coolms/editor-angular

> 标签: angular, coolms, editor, rich-text, tiptap, wysiwyg

## 简介

The CoolMS rich-text editor for Angular: a Tiptap bridge with a pluggable action and extension registry, paged layout, and DTMPL-aware widget transforms.
