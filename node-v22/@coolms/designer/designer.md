# @coolms/designer

> 标签: bpm, bpmn, coolms, designer, dmn, lcap, modeler, state-machine, workflow

## 简介

Framework-agnostic vanilla TypeScript visual designer for BPMN-Lite, DMN decision tables, DMN DRDs, and Symfony Workflow state machines. MIT-licensed, zero runtime dependencies.
