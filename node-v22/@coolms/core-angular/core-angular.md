# @coolms/core-angular

> 标签: angular, client, cms, coolms, runtime

## 简介

The CoolMS client runtime for Angular: session and token refresh, boot manifest and app configuration, theme, user preferences, error handling, HTTP interceptors, and the wire types the CoolMS API emits.
