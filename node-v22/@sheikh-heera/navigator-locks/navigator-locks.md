# @sheikh-heera/navigator-locks

> 标签: browser, concurrency, cross-tab, lock, mutex, navigator.locks, web-locks, weblocks

## 简介

A small, fluent, immutable wrapper for the Web Locks API. Native only: no polyfill, no fallback, no invented locking.
