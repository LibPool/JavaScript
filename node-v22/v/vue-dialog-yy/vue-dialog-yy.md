# vue-dialog-yy

> 标签: dialog, element, window, 弹窗, 窗体

## 简介

vue2基于ElementUI实现可拖动、缩小、放大等多功能弹窗，可直接通过全局方法调用打开弹窗（请直接使用最新版本）
