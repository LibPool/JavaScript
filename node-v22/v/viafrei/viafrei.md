# viafrei

> 标签: bridge, germany, mcp, modelcontextprotocol, open-data, proxy, stdio, transport

## 简介

stdio<->Streamable-HTTP bridge for the ViaFrei MCP server - German road, rail, parking, charging and fuel data for stdio-only MCP clients

- 源码仓库：git+https://github.com/mavrovde/viafrei-bridge.git
