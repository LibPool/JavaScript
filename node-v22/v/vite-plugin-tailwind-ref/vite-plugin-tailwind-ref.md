# vite-plugin-tailwind-ref

> 标签: apply, css, reference, svelte, tailwind, tailwindcss, vite, vite-plugin, vue

## 简介

A Vite plugin that automatically adds @reference directives to CSS files and framework style blocks (Svelte, Vue, etc.) using Tailwind CSS @apply
