# vue-dynatable

> 标签: big data table, dynamic table, table on vue, vue table

## 简介

This package allows you to manage big data in table. You could set the settings what table would do: dragging cols, resize cols, pin cols, filter and sort data. All the cells could be replaced by named slot.
