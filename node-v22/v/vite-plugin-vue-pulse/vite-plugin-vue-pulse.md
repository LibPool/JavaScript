# vite-plugin-vue-pulse

> 标签: devtool, graph, reactivity, visualization, vite-plugin, vue

## 简介

Dev-only Vite plugin that visualizes Vue reactivity (ref/reactive/computed/watch/watchEffect) as a live, glowing dependency graph — declarations are nodes, components are boundaries/filter tags; static map + runtime traffic.
