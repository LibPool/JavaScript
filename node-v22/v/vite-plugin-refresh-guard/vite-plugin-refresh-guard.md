# vite-plugin-refresh-guard

> 标签: app-update, changelog, pwa, react, refresh, service-worker, version-check, vite, vite-plugin, vue

## 简介

Vite 应用的可配置版本更新检测+刷新方案：静默自动刷新 / 提示后自动刷新 / 弹窗阻断，按产品需要选档位，核心逻辑框架无关，附 Vue/React 适配层。Configurable new-version detection + refresh for Vite apps — silent / toast-auto / modal-blocking, framework-agnostic core with Vue and React adapters.
