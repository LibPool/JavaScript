# vite-plugin-region-ifdef

> 标签: ifdef, ifndef, plugin, region, vite

## 简介

一个用于 Vite 的插件，实现类似 C/C++ 条件编译的功能，支持多种条件编译、嵌套条件编译和条件表达式。
