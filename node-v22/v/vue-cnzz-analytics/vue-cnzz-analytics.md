# vue-cnzz-analytics

> 标签: cnzz, cnzz统计, spa analytics, umeng统计, vue 3.0 analytics, vue 3.0 cnzz, vue 3.0 umeng, vue analytics, vue cnzz, vue umeng, vuepress analytics, vuepress统计, 友盟统计

## 简介

A data collection tool that supports reporting of single-page application data built by Vue 3.0 & 2.0 & VuePress, based on cnzz statistics.
