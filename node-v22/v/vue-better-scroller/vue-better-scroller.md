# vue-better-scroller

> 标签: JavaScript

## 简介

> 一款基于 [**better-scroll.js**](https://github.com/ustbhuangyi/better-scroll) （已内置依赖无需导包）<br/> > 为 vue.js 提供 scroll 滚动，上拉加载， 下拉刷新<br/> > 使用 es6， vue-cli 3 构建
