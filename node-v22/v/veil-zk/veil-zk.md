# veil-zk

> 标签: JavaScript

## 简介

Zero-knowledge predicate proofs for [Veil](https://github.com/SiyahKale0/veil): prove `age >= 18` or `balance >= 100` over a numeric claim **without revealing the value**. The verifier learns only true or false.
