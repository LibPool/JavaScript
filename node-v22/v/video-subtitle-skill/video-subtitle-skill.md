# video-subtitle-skill

> 标签: agent-skills, ass, burn, chatgpt, claude-code, codex, ffmpeg, srt, subtitle, transcribe, translate, video, whisper

## 简介

One-line install for the video-subtitle Agent Skills plugin — extracts audio, transcribes with Whisper, translates via AI, and burns subtitles into videos. Compatible with Claude Code, Codex CLI, ChatGPT, Cursor, and 30+ other AI agents.
