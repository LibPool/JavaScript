# vibe-spec-overlay

> 标签: development-tool, documentation, mui, overlay, react, spec, ui-specification

## 简介

React/MUI 기반의 UI 스펙 오버레이 라이브러리입니다. 개발 단계에서 UI 컴포넌트 위에 요구사항, 입력/출력, 예외 케이스 등의 스펙 정보를 시각적으로 오버레이하여 개발자와 디자이너 간의 커뮤니케이션을 돕습니다.
