# vercel-armor

> 标签: abortcontroller, backoff, circuit-breaker, edge, nextjs, request-collapsing, resilience, serverless, stale-if-error, vercel

## 简介

Resilience toolkit for Vercel serverless APIs — three-state circuit breaker (closed/open/half-open), retry with backoff + Retry-After, one-line Next.js App Router wrapper, observability events. Zero runtime deps.
