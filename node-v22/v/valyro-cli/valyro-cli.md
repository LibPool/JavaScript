# valyro-cli

> 标签: agent-skills, cli, components, mcp, model-context-protocol, react, registry, shadcn, ui, valyro, valyro-ui

## 简介

Install ValyroUI React components into your project as source, with their dependencies; includes an MCP server and Agent Skills for AI assistants. ValyroUI Pro items install after `valyro login`.
