# vexy-vlip-js

> 标签: captions, explainer, interactive-video, stop-motion, subtitles, tutorial, vexy-vlip, video, web-component, webvtt

## 简介

Interactive explainer video player: a single video + WebVTT becomes styled, positioned on-screen cards with continuous and click-to-advance stop-motion modes. Ships as ESM, Web Component, and a classic-script global. Zero runtime dependencies.
