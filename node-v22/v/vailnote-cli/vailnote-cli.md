# vailnote-cli

> 标签: aes-256-gcm, cli, e2e-encrypted, encryption, notes, secrets, vailnote

## 简介

Official VailNote CLI - create, read, and delete end-to-end encrypted notes. Content is encrypted and decrypted locally; the server only ever stores ciphertext.
