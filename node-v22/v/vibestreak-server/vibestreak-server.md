# vibestreak-server

> 标签: ai, claude, claude-code, companion-server, cross-platform, ios, vibecoding, vibestreak

## 简介

Companion server bridging Vibestreak iOS app to Claude Code CLI. Run with: npx vibestreak-server --tunnel
