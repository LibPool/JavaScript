# vue-nsel

> 标签: event emitter, event listener, namespace, namespaced listener, vue event namespace

## 简介

A wrapper around Vue's event emitter which adds the possibility to give a namespace to listeners, to easily unbind them. Inspired by jQuery's namespaces.
