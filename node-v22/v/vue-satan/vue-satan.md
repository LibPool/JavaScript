# vue-satan

> 标签: JavaScript

## 简介

一个类似dva的vue框架；1. start中增加autoResetModel配置项（默认true）,实现model的引用管理，自动卸载和重置无引用的model;2. 清理不必要的model引用，从而优化内存使用; 3. 累积bug的修复;
