# vite-plugin-set-version

> 标签: JavaScript

## 简介

编译时在产物加上version.json，内容是 `{"version":"2023-03-28 18:39:49"}` 用于版本标记。   本地version和文件对比判断是否更新版本，提示用户刷新页面。
