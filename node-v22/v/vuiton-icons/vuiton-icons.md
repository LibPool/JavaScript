# vuiton-icons

> 标签: JavaScript

## 简介

🧩 Icon library for [vuiton](https://github.com/reflexjsi/vuiton) – fast, flexible, and tree-shakable. Supports multiple icon sets like [Heroicons](https://heroicons.com/), [Feather](https://feathericons.com/), and more.
