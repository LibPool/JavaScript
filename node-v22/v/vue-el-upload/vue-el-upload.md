# vue-el-upload

> 标签: component, sfc, vue

## 简介

基于 elementUI 上传组件 [vue-upload-component](https://github.com/lian-yue/vue-upload-component) 编写的一个弹窗上传组件 内置 express 上传接口可供调试，server 目录下`npm start`

- 源码仓库：https://github.com/FengZeming/vue-el-upload.git
- npm 页面：https://www.npmjs.com/package/vue-el-upload
