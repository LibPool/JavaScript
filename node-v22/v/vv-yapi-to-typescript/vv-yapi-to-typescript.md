# vv-yapi-to-typescript

> 标签: codegen, typescript, yapi

## 简介

根据 YApi 的接口定义生成 TypeScript/JavaScript 的接口类型及其请求函数代码。

## 官网

- npm 页面：https://www.npmjs.com/package/vv-yapi-to-typescript

- npm registry：https://registry.npmjs.org/vv-yapi-to-typescript
- Node 要求：>=10.19.0
