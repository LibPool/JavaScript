# vite-plugin-str

> 标签: library, vite, vite 模板, web库, 公共代码, 前端库

## 简介

vite-plugin-str 是 vite 的插件，支持通过  `import base64String from './path/file?str&base64' 将文件导入为 指定的编码的字符串，默认使用 base64 编码
