# vue-greenborn-sso-front

> 标签: auth, authentication, google, greenborn, oauth, sso, vue, vue3

## 简介

Cliente SSO para aplicaciones Vue 3 que se integra con el servidor de autenticación Greenborn (auth.greenborn.com.ar). Proporciona login con Google (OAuth), intercambio de token temporal por bearer token, verificación de sesión, logout y componente callba
