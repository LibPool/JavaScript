# vite-plugin-preload-assets

> 标签: critical css, critical js, critical resources, css preload, fonts preload, html preload, image preload, js preload, lazy loading, loading optimization, performance, preconnect, preload, vite, vite html plugin, vite multi page, vite performance plugin, vite-plugin, web performance

## 简介

Optimizes performance by automatically injecting preload and preconnect tags for critical resources with Vite (JS, CSS, fonts, images).
