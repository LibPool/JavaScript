# vitepress-i18n

> 标签: generator, i18n, internationalization, language, locale, plugin, translate, translation, util, utility, vitepress, vitepress-plugin

## 简介

VitePress i18n is a plugin for VitePress that makes it easy to translate text in the default theme and search tool.
