# vetguard

> 标签: cli, npm, sca, security, slopsquatting, supply-chain, typosquatting, vulnerability

## 简介

Local-first scanner for AI-era npm supply-chain threats: hallucinated (slopsquatted) dependencies, typosquats, malicious young packages, and prompt injection aimed at coding agents.
