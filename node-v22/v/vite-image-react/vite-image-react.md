# vite-image-react

> 标签: avif, blur-up, cls, compression, content-aware, core-web-vitals, device-adaptive, face-detection, image, image-compression, image-loader, image-optimization, jpeg, lazy-loading, lcp, next-plugin, nextjs, optimization, optimizer, perceptual, performance, picture, placeholder, png, react, react-component, responsive-images, saliency, sharp, srcset, ssim, svg, svgo, vite, vite-plugin, webp

## 简介

Content-aware, device-adaptive image optimizer for React. Works with Vite and Next.js. Auto-converts to AVIF/WebP/JPEG with SSIM auto-tune, face detection, SVGO, and device-tier delivery. Built by @ezitounioussama at gotodev.ma.
