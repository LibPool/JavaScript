# version-monitor-plugin

> 标签: JavaScript

## 简介

系统版本更新提醒：当系统是以按需加载构建时，发布新版本，单页面应用的系统在切换模块时，还请求的旧的js路径，因新版本的发布，旧的js文件名已不存在，这时需要提醒用户刷新浏览器。
