# vue-sanitize-escape

> 标签: escape, sanitize, security, sqli, vite, vitejs, vue, vuejs, xss

## 简介

Vue.js plugin for sanitizing and escaping user input to protect against XSS, SQL injection, and other security vulnerabilities.
