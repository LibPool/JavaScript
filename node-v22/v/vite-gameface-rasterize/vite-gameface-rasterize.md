# vite-gameface-rasterize

> 标签: 9-slice, coherent-labs, cohtml, gameface, performance, rasterize, vite-plugin

## 简介

A Vite plugin that bakes expensive static CSS decorations into pre-rendered textures using the Gameface Player, so cohtml draws a textured quad instead of re-evaluating shadows, gradients and filters every frame.
