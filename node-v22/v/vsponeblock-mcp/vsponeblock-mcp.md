# vsponeblock-mcp

> 标签: hitachi, mcp, mcp-server, model-context-protocol, storage, vsp, vsp-one-block

## 简介

Community MCP server for Hitachi VSP One Block: the VSP One Block REST API (microcode 10.5.4) for Claude and other MCP clients. Not an official Hitachi Vantara product.
