# verdaccio-maven-s3-proxy

> 标签: maven, plugin, proxy, s3, verdaccio, verdaccio-plugin

## 简介

Maven pull-through cache middleware for Verdaccio: parallel fan-out to configured repositories, dual-stream to client and S3.
