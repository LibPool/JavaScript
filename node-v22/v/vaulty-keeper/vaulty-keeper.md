# vaulty-keeper

> 标签: aes, agent, apollo, cli, database, keychain, mongodb, mysql, postgres, redis, secrets, snapshot, tunnel, vault

## 简介

Encrypted-at-rest Apollo snapshots and local DB tunnels (PostgreSQL, MySQL, Redis, MongoDB) for AI agents, plus AES helpers and a loopback web UI
