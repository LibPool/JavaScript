# vite-styleguidist

> 标签: component, components, docs, documentation, generator, jsx, react, react-styleguidist, style guide, styleguide, styleguidist, vite

## 简介

Isolated React component development environment with a living style guide, powered by Vite. A maintained fork of React Styleguidist.
