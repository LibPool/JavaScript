# vite-plugin-vue2-jsx-oxc

> 标签: jsx, oxc, rolldown, tsx, vite, vite8, vue2, vue2.7

## 简介

Vue 2.7 JSX/TSX transform for Vite 8 using Oxc Parser, with Babel-compatible Composition API, directives, explicit VNodeData spread merging, HMR and SSR
