# vue-split-drag-pane

> 标签: drag, mobile, pane, pc, resize, split, vue, vue2, vue3, 拖到大小的面板

## 简介

一个可拖动调整面板布局大小的vue组件，支持vue2与vue3，支持PC与移动端操作
