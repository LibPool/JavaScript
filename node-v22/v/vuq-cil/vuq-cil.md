# vuq-cil

> 标签: JavaScript

## 简介

每次开新项目时都需要从头搭建架构，或者就是把之前的项目直接复制粘贴过来修修改改。 当然有时稍微勤奋一点的就会弄个基础模板放在本地或者放在 github，需要的时候直接 clone 过来。 但是其便捷性和通用性极差，就开始想为什么不做一个类似 vue-cli 的命令行工具呢(刚好现在有时间～)
