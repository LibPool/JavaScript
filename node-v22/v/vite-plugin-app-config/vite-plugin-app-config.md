# vite-plugin-app-config

> 标签: app, config, global, react, svelte, vite

## 简介

一个vite项目配置文件管理的解决方案，可方便开发者在本地环境/测试环境/投产环境等多种配置里面快速切换

- npm 页面：https://www.npmjs.com/package/vite-plugin-app-config
