# vctrfx-cli

> 标签: bloom, cli, duotone, effects, filter, glitch, halftone, nodejs, postprocessing, scanlines, svg, terminal

## 简介

Apply post-processing effects to any SVG from the terminal. Scanlines, bloom, glitch, halftone and more.
