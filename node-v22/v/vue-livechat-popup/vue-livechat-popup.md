# vue-livechat-popup

> 标签: chat, livechat, marketing, popup, social, vue

## 简介

This simple and practical Vue.js plugin helps you effortlessly create a beautiful popup for your live chat section on your website using messaging services like WhatsApp, Telegram, Messenger, etc., without the need for any server or account.
