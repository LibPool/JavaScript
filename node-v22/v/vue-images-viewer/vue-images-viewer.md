# vue-images-viewer

> 标签: carousel, component, es6, images, pan, pinch, scale, slider, swipe, touch, vue, 缩放, 轮播

## 简介

vue-images-viewer is a component for vue that can display any images, supporting swiping as well as pinching every image.
