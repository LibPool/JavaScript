# veritiles

> 标签: cid, integrity, ipfs, leaflet, maplibre, maps, openlayers, pmtiles, tiles, vector-tiles, verification

## 简介

Verified map tiles: a pmtiles-compatible Source that fetches PMTiles byte ranges from any dumb HTTP host and cryptographically verifies every byte against a content-addressed trust anchor (CID) before your map renders it.
