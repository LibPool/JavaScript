# vue-uni-intent

> 标签: accessibility, composables, focus-management, game-menu, gamepad, keyboard-navigation, roving-tabindex, spatial-navigation, vue, vue3

## 简介

Game-menu-style focus control for Vue 3, navigable by keyboard, mouse, and gamepad featuring spatial navigation using from DOM positions.
