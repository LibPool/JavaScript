# vipwx-packupimg

> 标签: JavaScript

## 简介

> npm install vipwx-packupimg -g ### 功能介绍 - 批量压缩图片（jpg/png），默认压缩比为0.7 - 压缩后在图片名后添加md5后缀，防止图片覆盖和cdn缓存 - 打包到image.zip ### 使用 全局安装后，在图片所在的目录下执行packupimg 命令，即可在当前文件夹下输出images文件夹、images.zip文件、加了md5码后的文件名imageName.json
