# vue-canvas-element

> 标签: business card, canvas card, flipping card, info box, info card, vue, vue 2, vue.js

## 简介

vue-canvas-element is a Vue component to create a multipurpose canvas card. vue-canvas-element has many options and can be used in different situations like: - dashboard statistic information - business card - product card
