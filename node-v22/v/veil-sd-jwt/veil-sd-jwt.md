# veil-sd-jwt

> 标签: JavaScript

## 简介

SD-JWT-VC selective disclosure for [Veil](https://github.com/SiyahKale0/veil). Issue a credential, disclose only the claims a verifier asks for, and keep the rest hidden — with holder key binding and nonce/audience binding.
