# vue-configure

> 标签: configuration, vue

## 简介

- 可添加连接管道，管道具有流动效果并可随意添加、删除子路径段，每段路径能添加文字描述； - 可添加基于图片的设备，随意按比例缩放； - 可添加基于svg的设备，随意按比例缩放不失真； - 可添加流程组件； - 可添加数据点组件； - 设备可添加文字描述； - 管道的节点可随意连接设备； - 可框选多个组件，一起拖动，提高描绘效率； - 可整体放大缩小； - 可保存成JSON数据，并读取； - 各组件对应属性面板和条件面板； - 条件联动：组件状态根据数据点的数值变化而变化；并能自定
