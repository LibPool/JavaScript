# vite-plugin-kite

> 标签: kite, vite-plugin, wasm, webassembly

## 简介

Import .kite files from a Vite project. The compiler is WebAssembly, so nothing is installed.

- 官网：https://kite-lang.dev
- 源码仓库：git+https://github.com/channyeintun/kite-lang.git
