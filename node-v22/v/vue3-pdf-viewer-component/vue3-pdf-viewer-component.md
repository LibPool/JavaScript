# vue3-pdf-viewer-component

> 标签: pdf, pdf.js, viewer, vue, vue3

## 简介

A Vue 3 (Composition API + TypeScript) wrapper around PDF.js viewer, ported from ng2-pdfjs-viewer and fully self-contained.
