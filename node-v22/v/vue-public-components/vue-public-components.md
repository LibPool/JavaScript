# vue-public-components

> 标签: border-beam, collapse, color-picker, component, layout, masonry, splitter, vue, vue3

## 简介

Vue 3 折叠容器（CollapseBox）、分屏面板（Splitter）、色彩选择器（ColorPicker）、瀑布流（Masonry）、边框流光（BorderBeam）与禁用容器（DisabledBox）组件，零外部 UI 库依赖
