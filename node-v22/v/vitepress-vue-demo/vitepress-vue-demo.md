# vitepress-vue-demo

> 标签: demo, markdown, vitepress, vue

## 简介

vitepress-vue-demo 是一个基于 Vitepress 开发的插件，它可以帮助你在编写文档的时候，通过`路径引用`，直接展示 `Vue 组件示例 + 代码`。
