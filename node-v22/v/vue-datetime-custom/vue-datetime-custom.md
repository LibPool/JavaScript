# vue-datetime-custom

> 标签: date, datetime, datetime-picker, picker, vue

## 简介

FORK of https://github.com/mariomka/vue-datetime - Mobile friendly datetime picker for Vue. Supports date, datetime and time modes, i18n and disabling dates.
