# vexify

> 标签: ai, database, document processing, embeddinggemma, embeddings, google drive, machine learning, ollama, pdf search, portable, rag, semantic search, sqlite, vector, vector search, web crawler

## 简介

Portable vector database with in-process ONNX embeddings. Zero-config semantic search via SQLite. No external servers required.
