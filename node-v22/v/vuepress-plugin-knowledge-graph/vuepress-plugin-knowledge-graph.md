# vuepress-plugin-knowledge-graph

> 标签: knowledge-graph, markdown, obsidian, vuepress, vuepress-plugin

## 简介

A VuePress 2 plugin that generates an Obsidian-like knowledge graph from Markdown links, tags, attachments, and unresolved links.
