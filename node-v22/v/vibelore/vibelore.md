# vibelore

> 标签: continuity, fiction, mcp, multilingual, novel-writing, web-novel, webtoon

## 简介

Local MCP server for writing consistent serial fiction with continuity checks and approval workflows, then adapting chapters into webtoon scenes: one image per scene with dialogue in the work language, pre-generation checks and visual review.
