# vector-migrate

> 标签: azure-devops, cli, contribution-graph, git, git-filter-repo, github, mailmap, migration, ssh

## 简介

Interactive, zero-token CLI that migrates Azure DevOps repositories to GitHub, preserving full commit history and rewriting author identities so the contribution graph stays intact.
