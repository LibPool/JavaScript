# vies-mcp

> 标签: audit, consultation-number, eu, mcp, modelcontextprotocol, tax, validation, vat, vies

## 简介

MCP server for EU VAT validation via VIES — returns official consultation numbers (audit evidence) through the Vatnode API, inside Claude, Cursor, or any MCP client.

## 官网

- 官网：https://vatnode.com
- 源码仓库：git+https://github.com/acirema792/vies-mcp.git
- npm 页面：https://www.npmjs.com/package/vies-mcp
