# vcs-patch-deploy

> 标签: bastion, cli, deploy, git, incremental, patch, php, svn, thinkphp, vcs, zip, 堡垒机, 增量部署

## 简介

PHP 后端（ThinkPHP）增量部署包生成工具 — 支持 SVN revision 与 Git commit 差异对比，打 zip 并附带 apply-update.php，供堡垒机/Web 终端上线
