# vxe-table-plugin-export-xlsx-syz

> 标签: vxe-table-plugin-export-xlsx-syz

## 简介

基于 vxe-table 表格的扩展插件，支持导出 xlsx 格式，适用于vxe-table@4.0.0~4.5.9
