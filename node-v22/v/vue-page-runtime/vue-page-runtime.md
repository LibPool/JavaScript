# vue-page-runtime

> 标签: async, loading, page-runtime, page-store, plugin, task, vue, vue2

## 简介

vue-page-store 的任务编排插件 —— 在 definePageStore 中声明 tasks，获得自动运行 / 依赖顺序 / loading / abort
