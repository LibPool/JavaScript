# vaultools

> 标签: cli, cli-tool, developer-tools, hash, json, jwt, regex, timestamp, uuid

## 简介

CLI for the Vaultools dev micro-tools (JSON formatter, JWT decoder, UUID/hash generator, regex tester, timestamp converter) — for CI and scripting use.
