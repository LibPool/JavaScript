# vibe-coding-bundle

> 标签: ai, anthropic, claude, cli, compression, linter, llm, optimizer, prompt, prompt-engineering, token

## 简介

Interactive CLI for prompt engineering, behind one command: lint prompts against 17 rules, rewrite weak ones with Claude, and squash verbose system prompts.
