# valta-leak

> 标签: agents, anthropic, cost, llm, openai, static-analysis

## 简介

Static analysis CLI that finds deterministic LLM-agent cost-exposure bugs (unbounded retry loops, unbounded while(true) agents, leaked system prompts) and computes a worst-case dollar exposure ceiling from real, dated model pricing.
