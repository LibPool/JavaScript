# vinyl-kit

> 标签: album, blend-mode, component, css, music, react, record, vinyl

## 简介

A tintable vinyl record built from one grayscale mask and a CSS blend mode — disc, sleeve with slide-out choreography, stacks, and cover-accent extraction. React, zero dependencies.
