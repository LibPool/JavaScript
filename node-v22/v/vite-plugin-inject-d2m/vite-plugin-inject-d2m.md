# vite-plugin-inject-d2m

> 标签: JavaScript

## 简介

+ 打包时自动生成一个和输出html一样的带用VConsole的页面，打开输出html时，检测到条件符合配置的condition时，自动跳到带有VConsole的页面（便于调试）
