# vite-plugin-page-annotator

> 标签: ai-coding, annotate, annotation, claude, claude-code, click-to-source, codex, devtools, jsx, mcp, mcp-server, openai-codex, page-annotator, preact, react, solid, visual-feedback, vite, vite-plugin

## 简介

Click elements on your live Vite dev page, write what should change, and send exact JSX source locations (file:line:column) and element screenshots straight to Claude Code or OpenAI Codex via MCP, plugin, or clipboard.
