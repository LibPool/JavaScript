# vibetalk

> 标签: accessibility, cli, dictation, local-ai, offline, speech-to-text, transcription, typing, vibe-coding, voice, voice-coding, voxtral

## 简介

Voice-to-text dictation CLI — speak and it types wherever your cursor is. Powered by Voxtral local AI. No API key needed.
