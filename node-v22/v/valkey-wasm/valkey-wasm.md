# valkey-wasm

> 标签: bullmq, embedded, in-memory, in-process, ioredis, pglite, redis, redis-compatible, valkey, wasm, webassembly

## 简介

Real Valkey (the BSD-licensed Redis fork) compiled to WebAssembly, networking bridged to node:net — an in-process, Redis-compatible server for Node. PGlite for Redis.
