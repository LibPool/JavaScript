# viberevert

> 标签: agent-safety, agentic, ai, ai-agent, ai-coding, checkpoint, claude-code, cli, codex, coding, cursor, git, mcp, mcp-server, project-integrity, rollback, safety, selective-rollback, snapshot, undo, vibe-coding

## 简介

Project integrity for AI coding: record the working state before an agent starts, flag risky changes deterministically, and selectively remove unwanted agent changes without discarding the rest.
