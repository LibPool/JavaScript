# videojs-react-thumbnail-player

> 标签: JavaScript

## 简介

Custom Video.js React player component featuring automatic MPEG-DASH & WebVTT timeline thumbnail preview support, quality selector, subtitles, PiP, and full keyboard shortcuts.
