# @crawlertoll/x402

> 标签: agentic-commerce, ai-crawler, base, cloudflare, coinbase, crawler-toll, http-402, pay-per-crawl, settlement, usdc, x402, x402-foundation

## 简介

x402 settlement-rail adapter for CrawlerToll. Build x402 v2 payment quotes for the 402 response body, parse incoming X-PAYMENT headers, and verify payments via a facilitator URL (Coinbase CDP, Cloudflare, or self-hosted).
