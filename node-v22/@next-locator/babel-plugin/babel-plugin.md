# @next-locator/babel-plugin

> 标签: babel-plugin, click-to-code, click-to-component, component-inspector, developer-tools, devtools, jsx, locatorjs, next.js, nextjs, react, vscode

## 简介

Babel plugin for Next Locator. Stamps JSX elements with source file paths so Alt+Click opens them in VS Code.
