# @basementai/gateway

> 标签: agents, ams, basement, gateway, itsm, mcp, sap, sdk

## 简介

The TypeScript SDK for the Basement Gateway. Your programs read and write the documents, files, skills and tasks of an SAP operation and work in its ITSM (Jira, GLPI and others), each with a key of its own.
