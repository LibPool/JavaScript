# @kubb/plugin-mcp

> 标签: ai, ai-tools, code-generation, codegen, kubb, llm, mcp, meta-framework, model-context-protocol, typescript

## 简介

Generate Model Context Protocol (MCP) tool definitions with Kubb. Expose your REST APIs as AI-callable tools for LLMs, Claude, ChatGPT, and other AI assistants.
