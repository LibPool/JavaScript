# @kubb/cli

> 标签: cli, code-generator, codegen, kubb, meta-framework, sdk-generator, typescript

## 简介

Official CLI for Kubb. Run kubb generate, kubb init, kubb validate, kubb studio, and kubb mcp to manage the full code generation lifecycle.
