# @leviosa-ai/detail-page-editor

> 标签: JavaScript

## 简介

Leviosa detail-page editor shell. Source-only: consumers compile it through Next transpilePackages. Every app coupling (sourcing server, brand store, cache keys, toast) arrives through the DetailPageHost interface, and every URL it fetches comes from conf
