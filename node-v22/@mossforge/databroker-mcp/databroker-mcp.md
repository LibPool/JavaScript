# @mossforge/databroker-mcp

> 标签: agent-tools, base, dvsa, mcp, micropayments, model-context-protocol, mot, open-data, uk, usdc, vehicle-data, x402

## 简介

MCP server for MossForge DataBroker - pay-per-call UK vehicle MOT history, MOT analytics, and identifier/reference-data utilities, paid via x402 USDC micropayments on Base. No API key, no account.
