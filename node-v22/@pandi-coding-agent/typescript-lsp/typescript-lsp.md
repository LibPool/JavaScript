# @pandi-coding-agent/typescript-lsp

> 标签: diagnostics, pi, pi-extension, pi-package, tsc, typescript

## 简介

Pi extension for TypeScript diagnostics feedback: runs tsc --noEmit on the coherent edge (agent_end) over touched files, plus a typescript_diagnostics tool and a /tsc command. Not a full LSP (no hover/go-to-def).
