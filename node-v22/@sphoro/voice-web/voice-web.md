# @sphoro/voice-web

> 标签: agents, ai, browser, dialer, realtime, softphone, speech, sphoro, telephony, voice, webaudio, webrtc

## 简介

Browser client for Sphoro Voice: a conversation with an agent, or a headless softphone for a dialler inside your own product
