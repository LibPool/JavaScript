# @huksley/nodebugger

> 标签: cli, debugger, devtools, eval, inspector, remote-debug, stack-trace, v8

## 简介

CLI tool to inspect running Node.js processes via V8 Inspector Protocol. Eval expressions, capture stack traces, debug remotely.
