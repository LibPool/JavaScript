# @agentsbloom/agent

> 标签: agentic-commerce, agentsbloom, ai-agents, ap2, http-message-signatures, rfc9421, ucp, webmcp

## 简介

Agent-side SDK for AgentsBloom stores: one client that discovers any agent-ready store (UCP-first), signs write requests (RFC 9421 or the cross-SDK legacy HMAC), mints AP2 budget mandates, and handles idempotency, retries, and cookies.
