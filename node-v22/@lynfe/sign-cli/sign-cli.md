# @lynfe/sign-cli

> 标签: JavaScript

## 简介

App Signer 命令行工具：通过一次性网页授权拉取签名凭据，并在本地完成 APK / HAP / IPA 签名

- npm 页面：https://www.npmjs.com/package/@lynfe/sign-cli
