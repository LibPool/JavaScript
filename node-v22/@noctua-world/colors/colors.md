# @noctua-world/colors

> 标签: accessibility, apca, color, colour, css-variables, custom-properties, dark-mode, design-system, design-tokens, dtcg, oklch, palette, tailwind, tailwindcss, theme

## 简介

A generated colour system: CSS custom properties, a Tailwind v4 theme, DTCG 2025.10 tokens and SCSS. Solved in OKLCH against APCA contrast targets, not hand-picked.
