# dsh-agconfig

> 标签: JavaScript

## 简介

多模态配置：在 设置 → 插件 → 多模态配置 中填写 Agnes AI API 密钥，持久化到 $DSH_HOME/ag-multimodal.json。dsh-agimage / dsh-agvideo 两个工具从同一配置文件读取密钥（未配置时回退内置默认值）。
