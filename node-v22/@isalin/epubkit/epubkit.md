# @isalin/epubkit

> 标签: cli, ebook, ebook-metadata, ebook-tools, ebooks, epub, epub-cli, epub-cover, epub-editor, epub-merge, epub-metadata, epub-parser, epub2, epub3, javascript, metadata, node, node-cli, nodejs, opf, opf-parser, typescript, typescript-library

## 简介

TypeScript EPUB library and Node.js CLI for editing metadata, merging EPUB files, managing covers, and inspecting archives.
