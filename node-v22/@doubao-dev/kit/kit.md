# @doubao-dev/kit

> 标签: JavaScript

## 简介

豆包应用插件的公开构建与调试工具，发布到公网 npm，版本跟随 SDK 发布组。 提供本地编译、开发服务器、Web 模拟器和 Node.js SDK，运行时不需要安装内部 Kit 包。

## 官网

- npm 页面：https://www.npmjs.com/package/@doubao-dev/kit

## 历史版本号

- 当前版本：0.8.0-rc.0

- 0.0.0-stage
- 0.8.0-rc.0

## 获取地址

- npm 安装：`npm install @doubao-dev/kit`
- npm registry：https://registry.npmjs.org/@doubao-dev/kit
- Node 要求：>=22.13.0
