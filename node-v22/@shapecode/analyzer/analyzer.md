# @shapecode/analyzer

> 标签: angular, binary-stream, code-analysis, documentation, nestjs, nextjs, react, static-analysis, typescript

## 简介

ShapeCode Analyzer - Static analysis for JavaScript, TypeScript, React, Angular, NestJS, and NextJS projects. Uses binary event streams for 3x smaller uploads. No Java required.
