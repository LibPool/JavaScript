# @divmode/eventkit

> 标签: ast, aws, build-tools, cli, discovery, event-system, eventbridge, events, infrastructure, messaging, pubsub, pulumi, schema-registry, sst, type-safety, typescript, validation, zod

## 简介

Type-safe AWS EventBridge toolkit. Generate patterns from Zod schemas, publish events, auto-register schemas, and build event-driven architectures with full TypeScript support.
