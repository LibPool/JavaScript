# @thedoc001/5d-claw-security

> 标签: agent-safety, audit, fivedrisk, governance, openclaw, openclaw-plugin, policy

## 简介

Deterministic per-action policy gate for OpenClaw agents. Registers before_tool_call at priority 70 and bridges to the fivedrisk Python core via persistent stdio.
