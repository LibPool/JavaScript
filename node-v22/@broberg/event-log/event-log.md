# @broberg/event-log

> 标签: activity-log, anonymize, audit-log, broberg, event-log, gdpr, headless, retention

## 简介

Headless append-only event-log core (audit / activity / server layers): typed LogEntry with a generic kind, a frozen LogStore interface, fire-and-forget writers that never throw, convenience wrappers (logLogin, logDocumentCreated, …), plus GDPR primitives
