# @broberg/lens

> 标签: auth, broberg, cardmem, lens, playwright, screenshot, session, storagestate, visual-regression

## 简介

Make any app Cardmem-Lens-compliant: a headless POST /api/lens-session mint endpoint (narrow Bearer → short-lived, read-only Playwright storageState) so Lens can log past the auth wall and screenshot the real authed surface, incl. prod. Framework-agnostic
