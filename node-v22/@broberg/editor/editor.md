# @broberg/editor

> 标签: broberg, editor, prosemirror, rich-text, tiptap, wysiwyg

## 简介

The fleet's shared WYSIWYG editor on TipTap: a headless core (createEditor, toolbarState, markdown in/out), server-side HTML rendering without a browser, image upload through your own callback, and thin React/Preact adapters. Epic F101.
