# @broberg/data-table

> 标签: broberg, data-table, datagrid, pagination, preact, sorting, stack-b, table

## 简介

The fleet's data table for Stack B (Preact, no shadcn): sorting, search, pagination, multi-select with an indeterminate select-all, remembered column visibility, a row ⋮-menu and typed cells (badge, status, number, select). Framework-free core + Preact co
