# @broberg/consent-cookie

> 标签: broberg, consent, consent-manager, cookie-banner, cookie-consent, eprivacy, gdpr, headless, privacy

## 简介

GDPR cookie consent for any site: <broberg-consent>, a drop-in custom element (banner, settings panel, reopen handle) that works the same in Next, Vite+Preact and plain HTML and takes the site's @broberg/theme tokens, on top of a framework-free consent co
