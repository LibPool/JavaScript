# @broberg/realtime

> 标签: broberg, chat, last-event-id, optimistic-ui, postgres-listen-notify, presence, realtime, server-sent-events, sse, typing-indicator

## 简介

Live channels for chat and realtime: an SSE stream per channel with Last-Event-ID resume, durable vs ephemeral events, presence with expiry, fan-out across machines via Postgres LISTEN/NOTIFY, and a browser client that reopens on foreground/online/silence
