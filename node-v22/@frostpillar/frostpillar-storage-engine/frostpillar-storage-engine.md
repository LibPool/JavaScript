# @frostpillar/frostpillar-storage-engine

> 标签: browser, database, embedded, indexeddb, key-value, lightweight, nodejs, opfs, storage-engine, typescript

## 简介

Chunk-based storage engine for browsers and Node.js that packs many small key-value entries into a single backing store.
