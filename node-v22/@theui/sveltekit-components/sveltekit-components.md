# @theui/sveltekit-components

> 标签: Entry pop-up, Exit pop-up, accordion, alert, badges, breadcrumbs, buttons, buttons-groups, collapses, components, container, darkmode, dropdown, forms, icons, mbparvez, modals, navbar, notifications, offcanvas, progress, svelte, sveltekit, sveltekit-components, tabs, tailwindcss, theui, tooltips, ui

## 简介

This is an official component library of The UI for Sveltekit. The components designed on the top of TailwindCSS with custom theming. The components are accessible out of the box.
