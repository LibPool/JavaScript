# @yanu30adi/vision-bridge-mcp

> 标签: gemini, image-analysis, mcp, model-context-protocol, ocr, opencode, vision

## 简介

MCP server that gives text-only coding agents (e.g. OpenCode + DeepSeek) the ability to see and analyze local images via the Gemini API.
