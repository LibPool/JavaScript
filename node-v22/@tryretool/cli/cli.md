# @tryretool/cli

> 标签: JavaScript

## 简介

Build, validate, and publish Retool apps from the command line. Write app code on your machine, in your editor or with your own coding agent, and let `retool` handle the Retool side: scaffolding, resource types, validation, preview builds, and publishing.
