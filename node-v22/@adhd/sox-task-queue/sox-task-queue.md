# @adhd/sox-task-queue

> 标签: queue, scheduler, sqlite, task, typescript, worker

## 简介

Durable SQLite-backed task queue — atomic priority-aware FIFO claim/lease, retry with exponential backoff, heartbeat lease management, a worker pool with graceful shutdown, and a croner-backed cron scheduler.
