# @adhd/sox-blob-store

> 标签: blob, content-addressable, sqlite, storage, typescript

## 简介

Content-addressable blob storage: SHA-256 CAS write, SQLite reference tracking, stream-based API, mark-and-sweep GC with grace periods, FD guard, integrity verification.
