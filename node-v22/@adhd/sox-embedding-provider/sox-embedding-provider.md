# @adhd/sox-embedding-provider

> 标签: embedding, onnx, typescript, vector

## 简介

Pluggable text→vector embedding provider — generic EmbeddingProvider interface, config-driven model resolution, async batch-first API (AsyncIterable). Default: fastembed (local ONNX, >=3 model dims proven). Loud-fail: createEmbeddingProvider() throws Reso
