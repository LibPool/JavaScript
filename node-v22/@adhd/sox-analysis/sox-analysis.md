# @adhd/sox-analysis

> 标签: analysis, batch, clustering, graph, typescript

## 简介

Batch derivation over a corpus — clustering (density-clustering, in-process JS), near-dup detection, importance + link scoring, and a suite of pure graph algorithms (topoSort, criticalPath, detectCycles, packBatches). No CorpusBackend wrapper: DB-integrat
