# @adhd/sox-extension-memory-server

> 标签: graph, mcp, memory, server, sqlite, typescript

## 简介

sox-memory MCP server (stdio/http/sse) — 20 memory_* tools over a Turso (default, multiprocess-write) or SQLite graph store, with hybrid recall and deterministic in-process enrichment
