# @adhd/sox-hybrid-search

> 标签: hybrid, ranking, retrieval, search, typescript, vector

## 简介

Generic hybrid retrieval ranker — fuses vector similarity + text relevance signals (mechanism-agnostic: textScore / vecScore) via normalized RRF/max-score fusion. SearchBackend interface decouples ranking logic from storage. StoreSearchBackend wires Vecto
