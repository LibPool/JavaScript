# @telperion/ng-pack

> 标签: angular, angular-signals, angular-utilities, cookie, event-manager, event-modifiers, eventsource, httpclient, interceptors, localstorage, promise, reactive, real-time, rxjs, secondary-entrypoint, server-sent-events, sessionstorage, signals, sse, storage, toSignal, typescript, utilities

## 简介

Collection of Angular utilities and libraries organized as secondary entry points. Includes signal-based storage (localStorage/sessionStorage/cookieStorage), SSE client with HttpClient-inspired interceptors, event modifier plugins, and more. Built with Ty
