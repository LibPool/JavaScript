# @usekorti/flowlocal

> 标签: dictation, gigaam, offline, russian, speech-to-text, voice, windows, диктовка

## 简介

Приватная диктовка для Windows: зажал клавишу, сказал, отпустил - текст в активном окне. Голос не покидает компьютер.
