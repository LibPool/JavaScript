# permlang

> 标签: ai-agents, ai-generated-code, ai-security, capabilities, code-review, devsecops, github-action, github-actions, least-privilege, lint, llm-security, mcp, model-context-protocol, permissions, prompt-injection, sast, security, security-scanner, static-analysis, supply-chain-security, typescript

## 简介

Build-time permission checker for TypeScript and AI agents. Fails the pull request when code starts reaching a new server, file, secret, database table, or CI permission, and flags risky MCP and other AI tools.
