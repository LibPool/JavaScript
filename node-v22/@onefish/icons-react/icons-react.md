# @onefish/icons-react

> 标签: design system, efishery, icons, onefish, react, svg

## 简介

Onefish Icons is one part of OneFish Design System. We are extending [phosphor icons](https://github.com/phosphor-icons/phosphor-react) and add our own icon set.
