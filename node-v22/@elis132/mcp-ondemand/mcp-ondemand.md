# @elis132/mcp-ondemand

> 标签: claude-code, lazy-loading, mcp, memory, model-context-protocol, proxy

## 简介

Run MCP servers only while they are used: one proxy lists every tool from cache, starts each server on its first call, shares it between sessions and stops it when idle.
