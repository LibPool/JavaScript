# @d1g1tal/tsbuild

> 标签: build, bundler, compiler, declarations, dts, esbuild, esm, library, type-checking, typescript

## 简介

A fast, ESM-only TypeScript build tool combining the TypeScript API for type checking and declaration generation with esbuild for bundling. Built for modern ESM-only projects on Node.js 24+.
