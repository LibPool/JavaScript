# @shapediver/sdk.stargate-sdk-core

> 标签: JavaScript

## 简介

Low-level Stargate transport utilities for TypeScript. This package provides the WebSocket client used by the higher-level `@shapediver/sdk.stargate-sdk-v1` package.
