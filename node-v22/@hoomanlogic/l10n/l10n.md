# @hoomanlogic/l10n

> 标签: babel, gettext, i18n, l10n, localization, po, pot, vite, webpack

## 简介

Localization by tagging strings in place - a Babel plugin that extracts [l10n:] literals into a gettext .pot, a tiny runtime lookup, and .po parsing/merging tools.
