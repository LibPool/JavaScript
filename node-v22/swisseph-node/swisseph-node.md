# swisseph-node

> 标签: astrology, astronomy, ephemeris, n-api, prebuildify, swiss

## 简介

Modern N-API binding for Swiss Ephemeris — self-contained (vendored C sources), ships prebuilt binaries, bundle-friendly (base64-embedded fallback for serverless/bundler-only runtimes)
