# dsh-import-graph

> 标签: circular, cycle, dependency, dsh, graph, import, orphan, plugin, require

## 简介

Dependency graph for DeepSeek Harness: build_graph (parse JS/TS import & require edges), find_cycles (circular dependency detection), orphan_files (files neither imported by nor importing others). Heuristic resolution, zero runtime dependencies, read-only
