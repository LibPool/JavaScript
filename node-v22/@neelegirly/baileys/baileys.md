# @neelegirly/baileys

> 标签: automation, baileys-fork, js-whatsapp, multi-device, neelegirly, whatsapp, whatsapp-api, whatsapp-chat, whatsapp-group, whatsapp-web

## 简介

Eigenstaendiger Baileys-Fork von Neele Girl (NICHT WhiskeySockets/Baileys) — multi-device WhatsApp Web API fuer Node.js, mit Multi-Button-Support, QR-/Pairing-Stabilitaet und self-healing WA-Web-Version.
