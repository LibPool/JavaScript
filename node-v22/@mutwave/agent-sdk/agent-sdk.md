# @mutwave/agent-sdk

> 标签: JavaScript

## 简介

Build your own Mutwave support dashboard — agent sign-in, team/break management, ticket handling, and realtime updates for your app's own support staff. Framework-agnostic core, with optional React (web + React Native) and React Native storage subpaths.
