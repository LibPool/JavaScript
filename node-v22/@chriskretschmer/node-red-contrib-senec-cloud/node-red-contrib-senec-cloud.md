# @chriskretschmer/node-red-contrib-senec-cloud

> 标签: node-red, senec

## 简介

Once installed and added to Node-RED all configuration is done from within the nodes configuration UI. You need to provide your username and password combination. If you provide no custom URL, an overview of the first system is queried.
