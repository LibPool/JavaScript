# @aetherya/mcp

> 标签: aetherya, ai-agents, behavioral-simulation, copy-testing, market-research, mcp, model-context-protocol, synthetic-audience, ux-audit

## 简介

Aetherya MCP server: test decisions on a synthetic audience from any MCP agent. Run research studies, site audits, copy tests, instant market reads and post or email simulations, then get a decision brief. Simulated, not real-user data.
