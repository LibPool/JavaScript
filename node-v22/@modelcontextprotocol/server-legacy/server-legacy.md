# @modelcontextprotocol/server-legacy

> 标签: legacy, mcp, modelcontextprotocol, oauth, server, sse

## 简介

Frozen v1 SSE transport and OAuth Authorization Server helpers for the Model Context Protocol TypeScript SDK. Deprecated; use StreamableHTTP and a dedicated OAuth server in production.
