# @decaf-ts/paperclip-pixels

> 标签: bridge, paperclip, pixel-agents, plugin, relay, worker

## 简介

Paperclip <-> Pixel Agents bridge: a Paperclip plugin (manifest, event subscriptions, snapshot bootstrap, worker->UI bridge, action policy) plus the paperclip-pixel-relay companion CLI for Pixel Agents.
