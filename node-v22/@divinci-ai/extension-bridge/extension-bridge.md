# @divinci-ai/extension-bridge

> 标签: a2a, browser-extension, divinci, local-llm, on-device, webgpu, webmcp

## 简介

Talk to the Divinci Local Inference browser extension from any website (on-device chat / WebMCP / A2A), with graceful fallback to the Divinci cloud API. Pure TypeScript, no Divinci-internal dependencies — works in any browser.
