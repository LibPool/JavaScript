# @vn.unifyid/integrity-verifier

> 标签: base, merkle, rfc6962, sign-protocol, transparency, unifyid, verifier

## 简介

Verify UnifyID records against signed, hash-chained checkpoints without trusting UnifyID: the record's Merkle proof, UnifyID's signature, and the checkpoint on UnifyID's anchor contract and Sign Protocol on Base (chain 8453; Base Sepolia 84532 for testing
