# @nu-agent/mcp-server

> 标签: JavaScript

## 简介

MCP (Model Context Protocol) server for [Nu Agent](https://nu-agent.com). Access your Nu Agent conversations from any MCP-compatible client like Claude Code, Claude Desktop, Cursor, and more.
