# @aun-abbas/expo-pin-shortcut

> 标签: android, expo, expo-module, home-screen, home-screen-shortcut, launcher, pin-shortcut, react-native, shortcut

## 简介

Pin a shortcut to the Android home screen from your Expo or React Native app. Wraps ShortcutManagerCompat.requestPinShortcut. Android-only by design (iOS does not expose a programmatic equivalent).
