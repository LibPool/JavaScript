# @netless/window-manager-wheel-extend

> 标签: JavaScript

## 简介

为 [@netless/window-manager](https://github.com/netless-io/window-manager) 提供的滚动条扩展插件，为白板主视图提供可自定义的滚动条，让用户能够通过直观的拖拽控制来导航大型内容区域。
