# @dateline/recurring

> 标签: dateline, events, ical, recurrence, rfc5545, rrule, timezone

## 简介

Helper library extending Dateline events with RFC 5545 recurrence: RRULE validation, lazy on-read materialization with a 2-year cap, KV range caching, and DST-aware IANA timezone handling.
