# @knorby/nih-dsld-client

> 标签: api, client, database, dietary, dsld, label, nih, ods, react-native, supplement, typescript, universal

## 简介

A fully-typed, zero-dependency TypeScript client for the NIH Dietary Supplement Label Database (DSLD) v9 REST API. Universal: Node, React Native, browsers, Bun, and Deno.
