# @striderlabs/mcp-instacart

> 标签: agent, agent-action-execution, agent-commerce, ai-agent-integration, automated-grocery, autonomous-agent, autonomous-shopping, delivery-agent, grocery-agent, grocery-delivery, grocery-shopping-automation, instacart, instacart-automation, mcp, mcp-ecommerce, model-context-protocol, personal-agent, shopping-agent, shopping-automation

## 简介

Autonomous grocery shopping via Instacart. Let your AI agent search products, manage shopping lists, apply discounts, and complete orders. Persistent session management for recurring grocery runs. Production-ready MCP server for personal agents.
