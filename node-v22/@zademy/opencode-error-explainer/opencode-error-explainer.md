# @zademy/opencode-error-explainer

> 标签: ai-coding, debugging, error-explainer, errors, opencode, opencode-plugin, terminal, zademy

## 简介

An OpenCode plugin that detects failed terminal commands, classifies common errors, and explains them to the AI so debugging is faster.
