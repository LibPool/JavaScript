# @adaptive-ds/sharepoint

> 标签: bun, cli, document-library, microsoft-graph, microsoft365, office365, onedrive, pnpjs, result, sharepoint, typescript, valibot

## 简介

SharePoint files from the terminal and TypeScript: list, search, download, upload, mkdir and delete across all sites via Microsoft Graph, with app-only auth and Result-based errors.
