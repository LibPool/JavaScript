# @adaptive-ds/jitsi-files

> 标签: adaptive-ds, bun, file-sharing, hono, jitsi, jitsi-meet, prosody, self-hosted, sqlite, typescript, webrtc

## 简介

Self-hostable file-sharing backend for Jitsi Meet config.fileSharing. Drop-in HTTP service with Prosody short-lived JWT auth, persistent index, TTL + room-purge lifecycle.
