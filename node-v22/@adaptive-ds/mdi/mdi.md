# @adaptive-ds/mdi

> 标签: adaptive-ds, esm, icons, material-design-icons, mdi, path, pictogrammers, svg, tree-shake, typescript

## 简介

Material Design Icons as one ESM file per path string. Import only the icons you use — no barrel, no CJS, no extra runtime deps.
