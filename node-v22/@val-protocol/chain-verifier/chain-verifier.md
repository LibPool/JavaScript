# @val-protocol/chain-verifier

> 标签: audit, hash-chain, ndjson, sha256, tamper-evident, val, verifiable-authorization-lineage, verifier

## 简介

Reference offline verifier for Verifiable Authorization Lineage (VAL). Zero runtime dependencies — pure SHA-256 against the canonical preimage specified in the VAL wire format. Verify chain integrity, lineage, scope, grounding, and delegator authority cli
