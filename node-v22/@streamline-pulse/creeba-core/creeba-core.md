# @streamline-pulse/creeba-core

> 标签: creeba, local-first, p2p, peer-to-peer, sync

## 简介

Portable Creeba P2P core: generic presence, peers and routing of opaque app payloads over a pluggable SyncTransport. No native dependency — usable from Bun, Node, browser or React Native. Message shape and persistence belong to the application.
