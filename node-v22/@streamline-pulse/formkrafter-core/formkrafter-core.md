# @streamline-pulse/formkrafter-core

> 标签: form-builder, formio, forms, json-schema, low-code

## 简介

Framework-agnostic core for FormKrafter: form specs, RFC 6902 ops with undo/redo, Ajv validation, sandboxed rules engine and injectable services
