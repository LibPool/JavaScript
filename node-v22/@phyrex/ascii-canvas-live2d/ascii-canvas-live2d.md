# @phyrex/ascii-canvas-live2d

> 标签: ascii, ascii-art, cubism, custom-element, live2d, pixi, web-component

## 简介

Web Component that renders Live2D models as live ASCII art. Built on @phyrex/ascii-canvas + pixi-live2d-display.
