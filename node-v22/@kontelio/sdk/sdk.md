# @kontelio/sdk

> 标签: accounting, api-client, bookkeeping, buchhaltung, e-invoicing, e-rechnung, en16931, germany, invoice, invoice-api, invoicing, kontelio, rechnung, rechnungssoftware, sdk, umsatzsteuer, vat, xrechnung, zugferd

## 简介

Official TypeScript/JavaScript SDK for the Kontelio API: create invoices, e-invoices (XRechnung, ZUGFeRD) and customers from any application. German invoicing and bookkeeping API for ERP, CRM, SaaS and e-commerce integrations.
