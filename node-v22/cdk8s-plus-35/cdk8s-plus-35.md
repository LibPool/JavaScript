# cdk8s-plus-35

> 标签: cdk, configuration, constructs, containers, k8s, kubernetes, microservices

## 简介

cdk8s+ is a software development framework that provides high level abstractions for authoring Kubernetes applications. cdk8s-plus-35 synthesizes Kubernetes manifests for Kubernetes 1.35.0
