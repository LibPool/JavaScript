# bursar-mcp

> 标签: ai-agents, arc, budget, claude, cursor, mcp, model-context-protocol, spending-limits, usdc, x402

## 简介

MCP server that gives any AI agent a Bursar spending key: job budgets, allow-listed payees and approvals, paid in USDC on Arc.
