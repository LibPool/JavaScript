# @nugehs/aiglare

> 标签: ai, audit, ci, governance, guardrails, lint, llm, mcp, mcp-server, repoctx, static-analysis

## 简介

aiglare: audit AI/LLM features in any JS/TS codebase for governance guardrails. Finds where model output reaches users or side-effects without confidence handling, fallbacks, validation, or human-in-the-loop.
