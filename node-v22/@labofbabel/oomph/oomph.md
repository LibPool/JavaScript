# @labofbabel/oomph

> 标签: bigint, component, float64, number-input, orders-of-magnitude, ruler, scale, ui

## 简介

Orders Of Magnitude — a drag-to-navigate control for numbers far too big for a slider. Exact BigInt, with an experimental Float64 mode.
