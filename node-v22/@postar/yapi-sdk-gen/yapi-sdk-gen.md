# @postar/yapi-sdk-gen

> 标签: @postar/yapi-sdk-gen, api, generator, mock, sdk, typescript, yapi

## 简介

从 YAPI 接口文档自动生成 TypeScript 类型定义、请求函数、Mock 文件的 SDK 工具，帮助前端团队实现接口类型安全与自动化对接。
