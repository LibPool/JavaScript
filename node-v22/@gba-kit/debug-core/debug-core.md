# @gba-kit/debug-core

> 标签: debugger, dwarf, emulator, gameboy-advance, gba, typescript

## 简介

IDE-agnostic GBA debugging session on top of gba-kit: breakpoints, stepping, frames and variables, rewind, tracing, and the emulator views
