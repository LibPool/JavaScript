# @concourse-sdk/http

> 标签: consumer, event-bus, http, message-broker, publisher, pubsub, queue, sdk, zero-dependency

## 简介

Zero-dependency, pure-HTTP Concourse client (event bus / message broker / queue) for old Node.js runtimes (>=14): HttpPublisher over POST /v1/publish and HttpConsumer short-polling POST /v1/consume/poll, using only Node built-ins — no ws, no ESM
