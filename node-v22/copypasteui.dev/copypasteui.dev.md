# copypasteui.dev

> 标签: ai, components, mcp, model-context-protocol, react, shadcn, tailwind, ui, vibe-coding

## 简介

Local MCP server and CLI for CopyPasteUI: search and add free small-business website templates, sections and themes from Claude Code, Cursor, VS Code and other editors. No account or API key.
