# @gct-paas/vxe-table

> 标签: vue grid, vue table, vxe-grid, vxe-table

## 简介

一个基于 vue 的 PC 端表格组件，支持增删改查、虚拟树、列拖拽，懒加载、快捷菜单、数据校验、树形结构、打印导出、自定义模板、渲染器、JSON 配置式...
