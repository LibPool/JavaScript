# @truplexy/server

> 标签: chat, express, nextjs, nuxt, support, sveltekit, truplexy, widget

## 简介

Typed Truplexy customer chat API client and widget server route. Keeps your chat key on the server, for Next.js, Nuxt, SvelteKit, Remix, Astro, Express, Cloudflare Workers and any Fetch-API runtime.
