# react-next-utility

> 标签: cookies, geocoding, nextjs, pwa, react, session, typescript, web-vitals

## 简介

Production Next.js and React TypeScript library for PWAs. Import one module at a time: route query read/write for Server and Client Components, JSON HTTP with timeout and retries, preference cookies, tab sessionStorage, namespaced localStorage, HTTP-only
