# @lpextend/node-sdk

> 标签: http-proxy, iframe, liveperson, lp-extend, sdk

## 简介

Node.js/Backend SDK for LP Extend apps - provides typed access to ALL LivePerson APIs (Account Config, AI Studio, Messaging) through the shell proxy
