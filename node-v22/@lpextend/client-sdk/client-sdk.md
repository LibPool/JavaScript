# @lpextend/client-sdk

> 标签: authentication, browser, frontend, iframe, liveperson, lp-extend, sdk, shell

## 简介

Browser/Frontend SDK for LP Extend child apps - provides unified authentication with shell and independent auth strategies, ExtendJWT support, and shell context detection
