# @lpextend/ais-flows

> 标签: JavaScript

## 简介

Shared types + helpers for LivePerson AI Studio flows. Used by the broker (server-side CRUD) and the app-ai-studio package (renderer-side editor). Transport-agnostic — no fetch logic, no Nest deps.
