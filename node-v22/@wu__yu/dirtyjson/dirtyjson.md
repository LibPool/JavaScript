# @wu__yu/dirtyjson

> 标签: ECMA-404, JSON, RFC-4627, RFC-7259, RFC-8259, dirty, fix, format, formatter, invalid, parse, validate, validation

## 简介

DirtyJSON is a Node.js library designed for fixing and parsing invalid JSON data. 超强纠错 JSON 解析器。
