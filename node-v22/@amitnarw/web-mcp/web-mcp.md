# @amitnarw/web-mcp

> 标签: agent, ai, automation, browser, browser-automation, chromium, mcp, mcp-server, model-context-protocol, puppeteer

## 简介

Dedicated browser automation MCP server using an isolated Chromium profile and Extension to provide AI browser control. Fully supports OpenCode, Cursor, Claude Code, Zed Editor, Sourcegraph Cody, Windsurf, Cline, and OpenAI Codex.
