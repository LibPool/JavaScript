> 标签: apm, kyrontha, lens, logs, mcp, model-context-protocol, observability, traces

## 简介

Model Context Protocol server for Kyrontha Lens — lets Claude Desktop, Claude Code, Cursor, and other MCP clients query your logs, traces, and APM data.
