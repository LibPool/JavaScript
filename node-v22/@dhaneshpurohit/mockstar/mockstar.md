# @dhaneshpurohit/mockstar

> 标签: api-mocking, bun, mock, mock-server, mockoon-alternative, testing, wiremock-alternative

## 简介

Bun-based mock server with static + dynamic mocking, JSON config, named JS handlers, pass-through, multi-tenancy, and test-data utilities.
