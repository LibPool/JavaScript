# @launchnotes/moments-semantic-release

> 标签: JavaScript

## 简介

A [semantic-release](https://github.com/semantic-release/semantic-release) plugin that allows you to publish Moments via the [Moments API client](https://github.com/launchnotes/moments-api-client).
