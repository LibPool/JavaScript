# @sea-lion/react-theme

> 标签: JavaScript

## 简介

Theme 组件是一个提供统一设计系统的主题提供者，用于向应用程序提供颜色、字体、尺寸等设计变量。将应用内容包裹在 `<Theme>` 中，即可统一应用设计令牌，并支持明暗模式切换和局部主题覆盖。
