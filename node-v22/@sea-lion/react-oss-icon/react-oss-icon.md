# @sea-lion/react-oss-icon

> 标签: JavaScript

## 简介

OssIcon (IconFont) 是基于 [iconfont 平台](https://www.iconfont.cn/) 的图标组件，支持通过 **Font-class**（.css）或 **Symbol**（.js）资源地址加载图标；不传资源地址时使用内置默认链接，可通过 `useSymbol` 在单色与多色模式间切换。
