# @sea-lion/react-badge

> 标签: JavaScript

## 简介

Badge 是徽章组件，用于展示标签、计数或状态等短文本。支持多种尺寸、变体、颜色和圆角选项，适用于通知计数、功能标签、版本信息、在线状态等场景。
