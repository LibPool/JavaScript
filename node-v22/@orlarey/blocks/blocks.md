# @orlarey/blocks

> 标签: JavaScript

## 简介

Framework-agnostic renderers for markpage's fenced markdown blocks (chart, bda, category, adt, diff, tree) — self-contained HTML/SVG, no app dependencies.

## 官网

- 官网：https://markpage.org
- 源码仓库：git+https://github.com/orlarey/markpage.git
- npm 页面：https://www.npmjs.com/package/@orlarey/blocks
