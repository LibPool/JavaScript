# @evantahler/myqq

> 标签: chamberlain, craftsman, garage-door, liftmaster, mcp, myq, smart-home, typescript

## 简介

TypeScript client for MyQ-enabled garage doors (Liftmaster / Chamberlain / Craftsman). Includes a stdio MCP server so AI agents can query and operate doors.
