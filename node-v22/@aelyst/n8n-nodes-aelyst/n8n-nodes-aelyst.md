# @aelyst/n8n-nodes-aelyst

> 标签: aelyst, crm, messaging, n8n-community-node-package, omnichannel, whatsapp

## 简介

n8n community node for Aelyst — AI-powered omnichannel CRM. Triggers (new messages, contact updates, conversation events) and actions (send messages, manage contacts, tags, assignments).
