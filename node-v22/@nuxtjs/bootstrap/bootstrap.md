# @nuxtjs/bootstrap

> 标签: JavaScript

## 简介

With [bootstrap-vue](https://github.com/bootstrap-vue/bootstrap-vue) you can easily use standard bootstrap 4 components with your app. (you need to add bootstrap package in your package.json too)

## 官网
