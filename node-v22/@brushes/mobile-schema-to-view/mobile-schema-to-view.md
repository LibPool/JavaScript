# @brushes/mobile-schema-to-view

> 标签: pi-package

## 简介

根据 移动端(Mobile)UI 截图/设计稿动态生成低代码平台 JSON schema。当用户提供 移动端(Mobile) UI图片要求生成页面、将设计稿转为低代码页面、根据截图创建页面 JSON、图片转 Schema 时使用此 skill。触发条件：移动端(Mobile) UI截图 + 低代码、设计稿转代码、图片生成页面、schema 生成
