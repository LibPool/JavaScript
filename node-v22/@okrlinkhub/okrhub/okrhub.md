# @okrlinkhub/okrhub

> 标签: component, convex, initiatives, key-results, kpi, linkhub, objectives, okr, risks

## 简介

Convex component for syncing OKR data (Objectives, Key Results, Risks, Initiatives) to LinkHub via secure HMAC-authenticated API.
