# @lynmoe/ssh-mcp

> 标签: controlmaster, cursor, mcp, model-context-protocol, openssh, remote, ssh, stdio

## 简介

MCP server: list SSH hosts from your config and run shell commands on remotes via OpenSSH (ControlMaster).
