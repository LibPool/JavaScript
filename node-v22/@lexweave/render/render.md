# @lexweave/render

> 标签: bilingual-reading, diglot-weave, epub, graded-reader, immersion, language-learning, renderer

## 简介

Deterministic renderer for Lexweave learning editions — inject progressive bilingual replacements into HTML or plain text with spatial density control (coverage + min-gap). Zero dependencies; runs in browsers, WebViews, and Node.
