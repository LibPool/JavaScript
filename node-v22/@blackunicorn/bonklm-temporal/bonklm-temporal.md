# @blackunicorn/bonklm-temporal

> 标签: ai-safety, durable-execution, guardrails, prompt-injection, security, temporal, workflow

## 简介

Temporal SDK middleware for BonkLM. Validators run as ACTIVITIES (non-determinism rule); cachedValidate keys decisions for idempotent retry.
