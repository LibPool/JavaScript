# @blackunicorn/bonklm-voice-webhooks

> 标签: ai-safety, guardrails, hmac, prompt-injection, realtime, retell, security, vapi, voice, webhook

## 简介

Vapi (HTTP) + Retell (WebSocket) webhook validators for BonkLM. HMAC-SHA256 auth, sync tool-calls / assistant-request, async transcript observe-only, Retell update_only + response_required.
