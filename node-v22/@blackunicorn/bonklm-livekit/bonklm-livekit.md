# @blackunicorn/bonklm-livekit

> 标签: ai-safety, audio, guardrails, livekit, livekit-agents, prompt-injection, realtime, security, voice

## 简介

LiveKit Agents (v1.x) wrapper for BonkLM — wires AudioStreamValidator into UserInputTranscribed + beforeLLMCallback + beforeTTSCallback + function_tools_executed hooks; interim-injection triggers session.interrupt() BEFORE the LLM call.
