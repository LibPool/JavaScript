# @proof-holdings/proof-check

> 标签: cli, delegation, mcp, npm, proof-of-delegation, pypi, supply-chain

## 简介

Check, from the terminal, whether a domain has published a Proof of Delegation for a package or endpoint — the places are looked up, and every token found is verified locally against the issuer's keys
