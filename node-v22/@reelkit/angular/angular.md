# @reelkit/angular

> 标签: angular, angular-component, carousel, gesture, mobile, reels, slider, swipe, tiktok, touch, typescript, vertical-slider, virtualized

## 简介

Angular adapter for ReelKit — virtualized one-item slider with gesture, keyboard, and wheel support.
