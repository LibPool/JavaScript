# @rongcloud/imlib-next

> 标签: Electron, IM, RongCloud, SDK

## 简介

赋能开发者在自己的 APP 上快速拥有专业的、丰富、高质量的互联网通信能力，SDK 支持单聊、群聊、聊天室、超级群、系统通知等通信能力，安全可靠、全球互通。
