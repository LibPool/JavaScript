# @hmlr/verify-unused-deps

> 标签: depcheck, dependencies, husky, knip, pre-commit, unused

## 简介

Prove a dependency is unused before removing it: remove it in a sandbox, clean-install, run the tests, and reinstate it if anything breaks.
