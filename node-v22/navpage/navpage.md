# navpage

> 标签: dashboard, homepage, hono, navigation, self-hosted, sqlite, startpage

## 简介

纯个人导航起始页:一页常用链接 + 分组 + 搜索 + 好看背景。自托管单进程,零配置 SQLite,手机优先,三套玻璃风格。
