# @altimist/altimist-id-consumer

> 标签: JavaScript

## 简介

Consumer-side library for AltimistID auth in Next.js apps — the ADR-031 Node-runtime middleware choke point (DB-backed sessions, default-deny route policy, VC-derived roles, hosted-handoff popup login) as an installable package. Counterpart to @altimist/d
