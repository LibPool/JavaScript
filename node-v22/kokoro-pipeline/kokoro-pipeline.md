# kokoro-pipeline

> 标签: claude-code, documentation, kokoro-os, pipeline, spec

## 简介

After your AI builds the app from a kokoro-baton spec, run the follow-up tools in one go: parameter table, a spec for people, one spec per system checked against the code, a hands-on check list (Aegis) and a code review (Polish).
