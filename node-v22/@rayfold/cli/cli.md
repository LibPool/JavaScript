# @rayfold/cli

> 标签: api, breaking-changes, cli, codegen, protocol, rayfold

## 简介

Rayfold command line: check, lock, hash, explain, gen, shapes, import from OpenAPI or GraphQL, a mock server, a language server, and a dev server with the explorer.
