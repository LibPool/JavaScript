# @rayfold/server

> 标签: api, graphql-alternative, http, live-queries, mcp, protocol, rayfold, rest, server

## 简介

Rayfold server for Node.js: batches with pipelining, schema policies, HTTP caching, live queries, WebSocket, MCP and REST bindings.
