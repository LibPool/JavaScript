# @restheart-cloud/cli

> 标签: cli, configuration, infrastructure-as-code, restheart, restheart-cloud

## 简介

The RESTHeart Cloud CLI. Configure a service from a plan committed to git — collections, indexes, permissions and plugins, applied idempotently from a terminal or a CI pipeline.
