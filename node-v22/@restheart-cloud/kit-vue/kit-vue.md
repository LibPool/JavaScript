# @restheart-cloud/kit-vue

> 标签: JavaScript

## 简介

Vue composables and navigation guards for RESTHeart Cloud authentication and payments — wraps @restheart-cloud/kit. Includes a /nuxt subpath for Nuxt server-side rendering.
