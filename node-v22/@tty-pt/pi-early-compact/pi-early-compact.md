# @tty-pt/pi-early-compact

> 标签: compaction, pi, pi-extension, pi-package

## 简介

Standalone Pi extension: deterministic, configurable early compaction (adaptive window tiers, percentage/token thresholds, warning margin). Composable with pi-vcc but never dependent on it.
