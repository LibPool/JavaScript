# @garygentry/system1-pi

> 标签: agents, classification, decision-model, decisions, jev, pi-package, triage

## 简介

Route closed judgements (pick one, rate this, yes/no) to a decision model instead of reading everything yourself. Typed, calibrated answers in ~300 ms for a fraction of a cent, via the `decide` CLI. Skills only, for Pi.
