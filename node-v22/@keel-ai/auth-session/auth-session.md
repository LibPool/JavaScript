# @keel-ai/auth-session

> 标签: JavaScript

## 简介

OAuth 2.0 PKCE helper for Keel React Native apps. Wraps the native ASWebAuthenticationSession (iOS) / Chrome Custom Tabs (Android) for sign-in flows against any RFC-6749 provider.
