# @develit-services/auth

> 标签: JavaScript

## 简介

Microsluzba pro autentizaci a autorizaci uzivatelu — registrace, prihlaseni, sprava sessions, JWT tokeny a MFA. Postavena na Cloudflare Workers s D1 databazi a Secrets Store.
