# dataverse-plugins-native

> 标签: agent-skills, copilot, dataverse, low-code, power-fx, power-platform

## 简介

Build and deploy Dataverse low-code plug-ins (instant Functions and automated plug-ins) from a CLI, an agent, or a local UI. Self-contained: no Power Platform CLI or app registration needed.
