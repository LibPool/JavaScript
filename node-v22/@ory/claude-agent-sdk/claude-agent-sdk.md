# @ory/claude-agent-sdk

> 标签: agent, agent-sdk, ai, anthropic, authorization, claude, ory

## 简介

Ory Agent Security for the Anthropic Claude Agent SDK — per-tool authorization, activity auditing, and identity propagation via PreToolUse hooks and canUseTool. Built on @ory/argus.
