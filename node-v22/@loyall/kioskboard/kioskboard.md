# @loyall/kioskboard

> 标签: keyboard, kiosk, kiosk keyboard, numpad, virtual keyboard, virtual numpad

## 简介

Customize Kioskboard keyboard position to fix it inside a wrapper instead of sliding from bottom of the screen.
