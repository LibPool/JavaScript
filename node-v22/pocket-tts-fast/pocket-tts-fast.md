# pocket-tts-fast

> 标签: german, kyutai, onnxruntime-web, pocket-tts, text-to-speech, tts, wasm, web-worker

## 简介

Optimized Pocket TTS for the browser: dynamic KV caches, streaming audio, stock voices and optional local cloning. Framework-free JavaScript with TypeScript types.
