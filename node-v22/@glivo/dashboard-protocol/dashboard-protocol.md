# @glivo/dashboard-protocol

> 标签: dashboard, entity, glivo, protocol, typespec

## 简介

Glivo dashboard protocol — entity refs, TypeSpec, entity-bus frames and the DashboardHostProtocol. Pure types + pure functions, zero dependencies, zero platform APIs (no Bun/Node/DOM): shared by the Bun backend, the desktop UI and the portable dashboard r
