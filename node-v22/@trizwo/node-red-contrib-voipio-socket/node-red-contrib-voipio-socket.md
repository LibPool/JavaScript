# @trizwo/node-red-contrib-voipio-socket

> 标签: innovaphone, node-red, pbx, trizwo, voipio, websocket

## 简介

A set of Node-RED nodes that integrates websocket connections of a innovaphone pbx with myApps into Node-RED
