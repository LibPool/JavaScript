# @oathline/sdk

> 标签: agent-wallet, agentkit, ai-agent, base, ethereum, intent, multisig, safe, transaction-security, viem

## 简介

Check every transaction an AI agent is about to sign against the owner's plain-language mandate: allow, ask or block, before it is signed. Shadow or enforce mode, fail closed. The SDK never holds keys.
