# @evmnow/sdk

> 标签: abi, contract-metadata, diamond, erc-2535, erc-7572, ethereum, evm, natspec, proxy, sourcify

## 简介

Resolve complete contract metadata for any EVM contract — curated repository, ERC-7572 contractURI, Sourcify + NatSpec, and proxy/diamond resolution — merged into a single document.
