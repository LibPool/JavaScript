# @ropean/inline-assets

> 标签: @ropean, @ropean/inline-assets, build-tool, bundler, css, esbuild, html, inline, inline-assets, inline-css, inline-js, inline-svg, javascript, rollup, single-file, svg, vite, vite-plugin, webpack, zero-dependency

## 简介

A zero-dependency utility to inline CSS, JavaScript, and SVG assets into HTML for single-file deployment. Works as a Vite plugin or standalone function with any build tool.
