# @compilecat/core-darwin-arm64

> 标签: JavaScript

## 简介

Rust/oxc core for compilecat, exposed as a napi addon. Build tool only — not published; its loader is folded into `compilecat` and its binaries ship as @compilecat/core-<triple> platform packages.
