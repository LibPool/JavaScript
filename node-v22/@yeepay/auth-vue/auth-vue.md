# @yeepay/auth-vue

> 标签: JavaScript

## 简介

Vue 3 对 `@yeepay/auth-core` 的薄适配层，提供插件注入、`usePermission`、`v-permission`、路由 meta 守卫和可选 Pinia Store 适配。
