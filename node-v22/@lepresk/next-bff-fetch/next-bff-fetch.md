# @lepresk/next-bff-fetch

> 标签: app-router, backend-for-frontend, bff, cookies, fetch, nextjs, proxy, server-actions, server-only, session

## 简介

Server-only Backend-for-Frontend fetch client for the Next.js App Router: forwards session cookies to an upstream API, re-emits Set-Cookie on the Next origin, negotiates JSON content-type, and degrades gracefully when the upstream is unreachable.
