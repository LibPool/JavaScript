# @codefusion-cc/ui

> 标签: components, contrast, css, design-tokens, dtcg, light-dark, oklch, react, tailwindcss, theming, vite, wcag

## 简介

The token contract every CodeFusion look fills, and the kit built on it: typed roles (colours, fonts, radii, shadows, control heights, motion), defineLook checked at compile time, lookProblems for WCAG 2.2 AA contrast and target sizes in light and dark, C
