## 简介

The core of a CodeFusion shop on Cloudflare Workers and D1: integrations as plugins (configuration checked, secrets sealed per row, shop events, webhooks, feeds, scheduled work, errors for the panel), the catalog's core (products, availability, GPSR, Omni
