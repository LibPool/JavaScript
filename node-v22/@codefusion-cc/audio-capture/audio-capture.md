# @codefusion-cc/audio-capture

> 标签: audio, audioworklet, dictation, microphone, pcm, resampler, speech

## 简介

Microphone to streaming 16 kHz PCM16 frames in the browser: an AudioWorklet capture that needs no file copied by the app, a resampler that keeps its state across chunks, a framer, a level meter, a React hook and a scripted fake for tests
