# @lmliheng/csu-mail

> 标签: JavaScript

## 简介

Manage a Coremail mailbox (CSU student mail, mail.csu.edu.cn) over IMAP/SMTP with a client app password instead of the unified auth portal — create the app password once, then list, search, read and send mail from the shell, with a copy kept in the Sent f
