# @pawells/react-shared

> 标签: components, hooks, inactivity-timeout, material-ui, mui, notifications, react, typescript, voronoi

## 简介

Shared React component and hook library providing MUI-based UI components, a global notification context, an inactivity-warning system, and an animated Voronoi background for @pawells React applications
