# @taco-ai/sidecar

> 标签: JavaScript

## 简介

Taco sidecar — Pi harness-driven JSON-RPC protocol layer. WeChat IM channel support requires the optional @wechatbot/wechatbot dependency (not bundled by default; see README IM Channels).
