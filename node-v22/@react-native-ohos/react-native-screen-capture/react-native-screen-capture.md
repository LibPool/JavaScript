# @react-native-ohos/react-native-screen-capture

> 标签: FLAG_KEEP_SCREEN_ON, FLAG_SECURE, android, component, ios, keep awake, library, module, react-native, screen capture, screenshot, setSecureTextEntry

## 简介

react-native-screen-capture allows you to protect screens in your app from being captured or recorded, as well as be notified if a screenshot is taken while your app is foregrounded.
