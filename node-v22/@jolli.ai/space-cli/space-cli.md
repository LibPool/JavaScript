# @jolli.ai/space-cli

> 标签: cli, jolli, plugin

## 简介

Jolli Space — closed-source plugin for @jolli.ai/cli (adds the `jolli space` command namespace). Discovered and loaded by the open-source `jolli` CLI when both are installed.
