# @alef-prime/audit-agent-system

> 标签: agent-safety, agentic, ai, alef, audit, linter, orphan-tool-use, owasp-asi06, patterns, prompt-cache

## 简介

Scan any repo against the ALEF Pattern Catalog — the periodic table of agentic AI failures. Flags instances of named patterns (orphan tool_use, verifier-source-mismatch, prompt-cache prefix drift, ...) in logs and source. CI-friendly via JSON / SARIF outp
