# @alef-prime/i18n-pick

> 标签: alef-prime, i18n, locale, next, pick, react, ternary

## 简介

Six lines of code that kill 50 lang === 'he' ? ... : ... ternaries. A tiny helper for picking a value from a per-locale map with a safe fallback.
