# @theholocron/holocron-plugin-checkly

> 标签: checkly, holocron, monitoring, plugin

## 简介

Holocron plugin for Checkly. Implements the monitoring capability against Checkly's REST API, plus exports verifyToken + AUTH_HINT for `holocron auth`.
