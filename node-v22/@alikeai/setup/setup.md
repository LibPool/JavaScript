# @alikeai/setup

> 标签: alike, claude-code, codex, coding-agents, cursor, hooks, installer, mcp

## 简介

Connect every coding agent on your machine to Alike with one command. Detects Claude Code, Codex, Cursor and ten more, wires hooks and MCP additively, pairs the machine in your browser, and verifies the connection.
