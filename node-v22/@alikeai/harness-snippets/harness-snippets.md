# @alikeai/harness-snippets

> 标签: alike, claude-code, codex, coding-agents, cursor, mcp

## 简介

Per-agent MCP configuration snippets for Alike. The single encoding shared by the @alikeai/setup installer and the Alike web app, so a debugged fact such as Codex's experimental_use_rmcp_client flag exists exactly once.
