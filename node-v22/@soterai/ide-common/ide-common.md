# @soterai/ide-common

> 标签: broker-client, ide-guard, local-first, soterai

## 简介

Shared TypeScript client and helpers for SoterAI IDE adapters: authenticated Local AI Broker client, token loading, feature flags, and test fixtures. No detector logic.
