# @metataro/zumen-mcp

> 标签: ai-agent, claude-code, diagram, diagram-as-code, mcp, mcp-server, svg, yaml

## 简介

MCP server for zumen — AI-editable diagrams as code. Lets Claude Code and other agents read the spec, browse 389 worked examples, propose edits as diffs a human applies, inspect and export (SVG, PNG, Mermaid, draw.io).
