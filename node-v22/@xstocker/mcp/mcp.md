# @xstocker/mcp

> 标签: ai-agent, mcp, mcp-server, model-context-protocol, solana, tokenized-stocks, xstocks

## 简介

MCP server for trading tokenized U.S. stocks (xStocks) on Solana via the xStocker Agent API. Non-custodial: builds orders, the user signs with their own wallet.
