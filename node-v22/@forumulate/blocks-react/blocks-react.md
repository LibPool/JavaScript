# @forumulate/blocks-react

> 标签: blocks, cms, forumulate, headless, react, rich-text

## 简介

Render Forumulate content (rich text, CMS blocks, media) in React with the same markup the hosted reader serves. SSR-safe, no network requests, no runtime dependencies.
