# @tramo/editor

> 标签: agent, ai, automation, n8n, node-editor, workflow, zapier

## 简介

Visual node-editor for tramo workflows — React components and LLM-agent glue. Pairs with @tramo/spec (the wire format) and @tramo/runtime (the executor).
