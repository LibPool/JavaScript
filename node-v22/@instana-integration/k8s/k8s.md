# @instana-integration/k8s

> 标签: custom dashboard, ibm, instana, k8s, kubernetes, monitoring, opentelemetry

## 简介

The integration package is used to support Kubernetes monitoring. Once you import this package into your Instana environment, you will be able to monitor Kubernetes Components.
