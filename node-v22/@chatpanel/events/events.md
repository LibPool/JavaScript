# @chatpanel/events

> 标签: audit, capability, chatpanel, determinism, event-sourcing, provenance

## 简介

The canonical ChatPanel event-log and capability contracts — typed durable facts, clock-free deterministic linearization, schema upcasting, and the invariants the replay harness asserts. Pure, dependency-free ESM shared by the ChatPanel extension, gateway
