# @chatpanel/sdk

> 标签: agents, chatpanel, client, gateway, llm, privacy, sdk

## 简介

Typed client for the local ChatPanel gateway — chat through the privacy proxy, search the user's history, read and write memory, follow team runs. Zero dependencies.
