# @paniniapi/bsa

> 标签: bank-statement-analysis, bsa, credit-underwriting, fintech, foir, income-detection, india, privacy-preserving

## 简介

BSA-in-a-box — turnkey bank statement analysis: statement files in, enriched transactions + deterministic credit-relevant report (JSON + Markdown) out. Fully client-side, zero telemetry, zero implicit network calls.
