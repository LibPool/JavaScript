# @gavinrigs/decap-media

> 标签: JavaScript

## 简介

Media widgets for Decap CMS: a drag-and-drop reorderable image/file control, a configurable image-plus-extras widget (caption/alt, focal point), and a multi-select/multi-upload gallery list widget.
