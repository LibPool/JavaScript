# @ty-ras/frontend-node-zod

> 标签: client, data, frontend, http, node, runtime, validation, zod

## 简介

Bundle of TyRAS libraries suitable to use in frontends/clients which use Axios library to send HTTP requests, and `zod` as data validation library.
