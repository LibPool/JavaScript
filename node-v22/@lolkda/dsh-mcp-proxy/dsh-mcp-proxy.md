# @lolkda/dsh-mcp-proxy

> 标签: cordis, cordis-plugin, deepseek-harness, dsh, mcp, mcp-proxy, tool-discovery

## 简介

DSH native-mode MCP proxy: hide mcp__ tools from the model tool list, expose list/search/describe/call discovery tools, and execute MCP tools through a guarded nested call.
