# @twobots/ui-theme

> 标签: JavaScript

## 简介

Shared visual material for the twobots.dev card-game lineup — design tokens, generic card rendering, table-shell chrome, a dialog/sheet overlay shell, the rail header strip + utility-button + control, a ranked stopping-point screen, and a bot thinking-dot
