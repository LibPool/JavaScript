# @chrissgon/light-site-auditor

> 标签: 3g, accessibility, acessibilidade, audit, auditoria, axe, cli, english, lighthouse, performance, portuguese, wcag, web-performance

## 简介

Checks a small business's home page for weight, load time on 3G and accessibility (WCAG 2.1 AA), and explains the fixes in plain Portuguese or English. Real sites only with the owner's consent.
