# @toobstudio/notas

> 标签: api-client, brasil, fiscal, nfse, nfse-nacional, nota-fiscal, nota-fiscal-de-servico, nota-paulistana, sdk, toob, toobstudio, typescript

## 简介

SDK oficial da TOOB Notas — emita NFS-e (nota fiscal de serviço) reais no Brasil com uma chamada. TypeScript, zero dependências, idempotente por padrão.
