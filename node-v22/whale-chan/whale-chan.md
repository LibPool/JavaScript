# whale-chan

> 标签: agent, deepseek, desktop-pet, harness, pycharm, terminal, tui, vscode, whale, 桌宠, 鲸鱼娘

## 简介

鲸鱼娘 (Whale-chan) — 生活在任意 IDE 终端里的 2D 桌宠 + DeepSeek Harness 智能体对话。可直接在 VS Code / PyCharm / Windows Terminal 的终端面板里运行。不需要 API Key：她调用的是你本机已经登录过的 dsh。
