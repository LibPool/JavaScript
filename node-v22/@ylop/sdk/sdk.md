# @ylop/sdk

> 标签: JavaScript

## 简介

Shared TypeScript SDK for the Ylop lending protocol. Wraps all contract interactions (supply, borrow, collateral, leverage, oracle, liquidation) into typed async methods. Transactions are executed via a Polymarket Account (Safe or Proxy) with optional Ten
