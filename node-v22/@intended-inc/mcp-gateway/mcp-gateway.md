# @intended-inc/mcp-gateway

> 标签: JavaScript

## 简介

Authority gateway for MCP — sits between an MCP client and an upstream MCP server on the official @modelcontextprotocol/sdk (stdio + streamable-HTTP). Every tools/call is authorized through Intended before it reaches the upstream.
