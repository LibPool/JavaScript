# @intended-inc/mcp-server

> 标签: JavaScript

## 简介

Intended as an MCP server — exposes Intended's authority layer (submit_intent, verify_token, get_receipt, list_policies, explain_decision) to any MCP client over stdio or streamable-HTTP.
