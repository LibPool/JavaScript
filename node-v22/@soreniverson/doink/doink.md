# @soreniverson/doink

> 标签: agent, ai, automation, browser, browser-automation, cdp, langchain, llm, playwright, web-scraping

## 简介

A deterministic, agent-shaped browser SDK over Playwright: plain selectors are free and never call an LLM, the LLM path is an explicit cached ai() call, and every failure is an obsessive, replayable error that tells you what to fix.
