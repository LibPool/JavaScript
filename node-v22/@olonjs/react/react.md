# @olonjs/react

> 标签: JavaScript

## 简介

React rendering bindings for the OlonJS engine (JsonPagesEngine, PageRenderer, ConfigContext). Depends on @olonjs/core; dynamically loads the optional @olonjs/studio editor for the /admin route.
