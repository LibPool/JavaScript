# @onrail-xyz/utils

> 标签: base64, bidirectional, bigint, const, encoding, hex, immutable, json, mapping, readonly, tuple, type-safe

## 简介

Zero-dependency foundation of the SDK: type-safe utilities for readonly and const data structures, lookup tables built from a const spec, general typing utilities, and the runtime primitives built on them - encoding, codec-extensible JSON, bytes, and rang
