# @morozeckiy/dd-lib

> 标签: JavaScript

## 简介

Для публикации библиотеки: 1. Выполнить одну из команды в scripts (будет запрошен коммент для коммита)   - lib:patch - для меких багов   - lib:minor - в случае добавления нового функционала   - lib:major - в случае изменения работы текущего функционал
