# @thearvindas/applemusic-cli

> 标签: airplay, apple-music, applescript, cli, macos, music, music-app, now-playing

## 简介

Local-only Apple Music CLI for macOS. Control Music.app via AppleScript — play, pause, now playing, volume, shuffle, repeat, AirPlay.
