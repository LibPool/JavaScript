# @momics/dns-sd-node

> 标签: JavaScript

## 简介

Node.js runtime adapter for @momics/dns-sd-shared: a UDP-multicast DatagramTransport (via node:dgram) driving the shared, standards-compliant mDNS / DNS-SD engine.
