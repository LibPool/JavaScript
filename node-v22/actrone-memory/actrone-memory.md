# actrone-memory

> 标签: actrone, agent-memory, ai-agents, embeddings, langchain, llm, long-term-memory, mastra, memory, pgvector, qdrant, rag, redis, semantic-search, typescript, vector, vercel-ai-sdk

## 简介

Persistent memory for AI agents in TypeScript: short-term session turns plus long-term semantic recall. In-memory by default, with Redis, Qdrant and pgvector adapters and pluggable embeddings. Works with the Vercel AI SDK, LangChain.js and Mastra.
