# @edithree/core

> 标签: additive, animation, animationmixer, blend-space, blendspace, edithree, poses, r3f, react-three-fiber, state-machine, three, threejs, unreal

## 简介

Headless animation runtime for edithree: blend spaces (1D/2D, Delaunay barycentric), an animation state machine, a controller, and the three.js AnimationMixer driver. Framework-agnostic.
