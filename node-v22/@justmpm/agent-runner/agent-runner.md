# @justmpm/agent-runner

> 标签: agent-runner, coding-agent, headless, mcp, model-context-protocol, opencode

## 简介

MCP Server para invocar o OpenCode CLI em modo headless (7 tools concisas, sem owner, controle por mode via sufixo de prompt).
