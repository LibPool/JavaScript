> 标签: ai-agent, api, api-client, claude-code, cline, codex, cursor, graphql, gud-api, mcp, model-context-protocol, rest, windsurf

## 简介

Model Context Protocol server for Gud API — let AI coding agents (Claude Code, Cursor, Windsurf, Codex, Cline…) create, run, and save API requests and collections your team can open in any VS Code-compatible editor.
