# @andy-toolforge/knowledge-base

> 标签: facade, knowledge, knowledge-base, memory, persistence, serena, supermemory

## 简介

Filesystem-first knowledge base facade for AI agents: JSON store with CRUD/search, optional best-effort Supermemory/Serena adapters, and a management skill installed into client projects.
