# @net-watch/core

> 标签: banner, connection-speed, connectivity, downlink, effective-type, fetch, firefox, internet-connection, is-online, latency, navigator-online, network-information-api, network-quality, network-status, offline, offline-detection, online, ping, rtt, safari, ssr, typescript, zero-dependency

## 简介

Detect if the user is really online (not just Wi-Fi on) and measure connection quality: latency, speed and an offline banner. Zero dependencies, works in Chrome, Firefox and Safari.
