# @simplex2/framework

> 标签: framework, simplex2

## 简介

`@simplex2/framework` 是一个基于 TypeScript 的轻量级模型运行时。它使用“属性配置 + 模型树”的方式描述组件或业务模型，并提供动态属性、计算属性、父子节点关系和模型工厂等基础能力。
