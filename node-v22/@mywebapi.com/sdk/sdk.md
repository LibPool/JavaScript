# @mywebapi.com/sdk

> 标签: api-client, broker, cplugin, forex, oauth2, openapi, real-time, rest-api, sdk, signalr, trading, trading-platform, typescript, webapi

## 简介

Typed TypeScript SDK for the CPlugin WebAPI v2 — manage trading-platform servers from Node.js and browsers. OAuth2, retries, pagination and SignalR real-time included; types regenerated from the OpenAPI spec so they never drift.
