# @keemakr/observability

> 标签: JavaScript

## 简介

Keemakr telemetry: the host registration for a process (Core, Operator, Task Operator, Pack Runtime) and the exporter-neutral runtime that Core libraries, the Agents SDK and Pack code trace with.
