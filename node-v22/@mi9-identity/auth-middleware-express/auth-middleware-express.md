# @mi9-identity/auth-middleware-express

> 标签: express, identity, jwks, jwt, m2m, mi9, oauth2, rs256

## 简介

Express adapter for the Mi9 JWT verifier — drop-in middleware that verifies Mi9-issued JWTs and attaches AuthContext to req.auth.
