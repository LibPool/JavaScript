# @vscode-restclient/cli

> 标签: api, ci, dothttp, http, jetbrains, mcp, rest, rest-client, sse, testing, websocket

## 简介

Run .http files (REST Client / JetBrains HTTP Client format) from the terminal: assertions, environments, secrets, SSE, WebSocket, JUnit output and an MCP server for agents. The command is `restclient`. Runner of the Rest Client VS Code extension.
