# @unionkeyhq/hd-ble-sdk

> 标签: JavaScript

## 简介

`@unionkeyhq/hd-ble-sdk` is a library provided for mobild client. Its dependency on `@unionkeyhq/hd-transport-react-native`. We recommend using this libarary in ReactNative applications.
