# @downdraft/engine

> 标签: JavaScript

## 简介

Downdraft engine — core runtime (ECS, WebGPU renderer, module/DI system, SAB sim channels), runtime-agnostic game bootstrap (startGame/bootstrapGame, HostAPI types), and all engine libraries + feature modules, exposed as subpath exports.
