# @descryy/adapter-treesitter

> 标签: JavaScript

## 简介

The tree-sitter WASM harness, shared by every grammar-based adapter. Holds nothing about any one language — a grammar is a .wasm and a query set, and that is the whole of what a breadth adapter adds.
