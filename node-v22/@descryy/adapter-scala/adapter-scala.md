# @descryy/adapter-scala

> 标签: JavaScript

## 简介

Scala adapter, breadth tier, with a Play routes extractor. Types are named by package and declaration, calls resolve through written receiver types and in-repo ancestors, and routes are read from the routes file Play itself compiles.
