# @node_yara_rs/node-yara-rs

> 标签: JavaScript

## 简介

Node-yara-rs is a node module binding for the [yara-rs](https://github.com/Hugal31/yara-rust/) library which in turn does bind to [libyara](https://github.com/VirusTotal/yara).
