# @nuxeo/nuxeo-web-ui-ftest

> 标签: JavaScript

## 简介

A framework to develop functional tests for [Nuxeo Web UI](https://github.com/nuxeo/nuxeo-web-ui), using [WebDriverIO](https://webdriver.io/) and [Cucumber](https://cucumber.io/).
