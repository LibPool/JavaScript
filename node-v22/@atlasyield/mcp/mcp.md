# @atlasyield/mcp

> 标签: atlasyield, defi, mcp, model-context-protocol, risk, vault, yield

## 简介

Read-only MCP server for the AtlasYield judgment layer: vault scores, coverage, route survival, open alerts. No custody, no execution.
