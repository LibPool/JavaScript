# @lj92458/celo-ethers-wrapper

> 标签: Celo, Ethers

## 简介

A minimal wrapper to make Ethers.JS compatible with the Celo network. I have added function fromEncryptedJson and fromEncryptedJsonSync to CeloWallet.ts
