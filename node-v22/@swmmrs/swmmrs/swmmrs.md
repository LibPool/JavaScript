# @swmmrs/swmmrs

> 标签: JavaScript

## 简介

`@swmmrs/swmmrs` runs SWMM in a dedicated worker from a browser or from Node.js 22 and later. A `Simulation` owns its worker, solver state, and in-memory project files. The package is private and is built from this repository.
