# dsh-plugin-continue-on-limit

> 标签: agent, auto-continue, cordis, deepseek-harness, dsh, dsh-plugin, max-tokens, truncation

## 简介

DeepSeek Harness plugin that auto-continues a turn the model ended by exhausting its output-token limit, with a per-session burst cap and a minimum interval between continuations.
