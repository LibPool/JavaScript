# @svartal/cli

> 标签: agent, cli, effect, knit, oidc, svartal

## 简介

The svartal terminal CLI: sign in as a Svartal identity and see the machines, workspaces and sessions you can reach. Built only on the published Svartal client packages, so it is also the test that the harness-side surface really is extractable.
