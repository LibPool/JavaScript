# @vario-software/vario-app-framework-backend

> 标签: JavaScript

## 简介

Node.js backend for VARIO Cloud Apps: verifies incoming app tokens, obtains access tokens per tenant, and provides ERP REST and VQL clients, webhook registration and installation migrations.
