# pi-codex-auto-review

> 标签: approval, auto-review, pi-extension, pi-package

## 简介

Automatic execution approval review for Pi, inspired by Codex's "Approve for me". Reviews tool execution with rules and Pi's current model, requesting user approval when needed.
