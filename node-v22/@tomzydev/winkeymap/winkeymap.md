# @tomzydev/winkeymap

> 标签: KeyboardEvent, key, key name, keyboard, keycode, keymap, virtual key, vk, vkcode, win32, winapi, windows

## 简介

A JSON file containing mappings from Win32 Virtual Key codes to JavaScript `KeyboardEvent.key` strings. Uses the list of keys from MDN: https://developer.mozilla.org/en-US/docs/Web/API/UI_Events/Keyboard_event_key_values
