# @metalend/sdk

> 标签: aave, defi, eip-3009, ethereum, euler, metalend, morpho, sdk, usdc, yield

## 简介

TypeScript SDK for the Metalend yield-rebalancing protocol. Supports gasless USDC/MUSD deposits via EIP-3009 and approval-based USDT/RLUSD flows across Ethereum, Base, Polygon, Arbitrum, Optimism, Avalanche, and Linea.
