# @webx-ui/module-admin

> 标签: admin, cms, laravel, vue, vue3, webx-ui

## 简介

The frame a WebX UI admin panel runs in: bootstrap, the shell, the HTTP client and the module registry that pairs with webx-ui/module-admin on the server.
