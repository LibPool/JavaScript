# @webx-ui/module-tariffs

> 标签: admin, cms, pricing, tariffs, vue, webx-ui

## 简介

Tariffs for the WebX UI admin panel: price cards with a currency, a period, what is included and a button, in groups, ordered by hand, shown on the site by a block.
