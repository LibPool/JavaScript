# @okeav/idp-core

> 标签: authentication, identity-provider, jwks, jwt, mfa, oauth2, oidc, sso

## 简介

Standalone, pluggable identity provider for Node.js/TypeScript backends — OAuth2/OIDC authorization server, password + MFA + social login, session management, and service-to-service JWKS trust. Bring your own MongoDB.
