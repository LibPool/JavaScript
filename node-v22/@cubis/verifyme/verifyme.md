# @cubis/verifyme

> 标签: 2fa, email, mfa, otp, react, sms, telegram, totp, verification, verifyme, vue

## 简介

Verifyme SDK for JavaScript and TypeScript: send and verify one-time codes over SMS, Email and Telegram, embed the verification widget (React, Vue or any framework), and verify webhooks.
