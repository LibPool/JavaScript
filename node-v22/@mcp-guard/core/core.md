# @mcp-guard/core

> 标签: ai-security, anthropic, claude, mcp, mcp-server, model-context-protocol, sarif, sast, secret-detection, security, security-scanner, vulnerability-scanner

## 简介

Security scanning engine for Model Context Protocol (MCP) servers. Detects hardcoded secrets, command injection, SSRF, auth misconfig, and compliance gaps.
