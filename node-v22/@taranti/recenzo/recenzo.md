# @taranti/recenzo

> 标签: ai, bitbucket, code, recenzo, review

## 简介

Recenzo is a JS/TS library for custom AI powered Bitbucket code reviews. Fetch PR diffs, analyze changes, and automate reviewer feedback to enforce standards.
