# @tracelit/sdk

> 标签: apm, logs, metrics, observability, opentelemetry, otel, tracelit, tracing

## 简介

Official Node.js SDK for Tracelit — drop-in OpenTelemetry instrumentation for Node.js apps. Sends traces, metrics, and logs to the Tracelit ingest API via OTLP/HTTP.
