# @maptoolkit/maplibre-elevation-control

> 标签: control, map, maplibre, maplibre-gl, plugin

## 简介

A MapLibre GL JS control plugin that shows an elevation profile for 3D GeoJSON lines, based on @maptoolkit/elevation-profile.
