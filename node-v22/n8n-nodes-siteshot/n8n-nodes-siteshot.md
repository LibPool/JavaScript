# n8n-nodes-siteshot

> 标签: n8n, n8n-community-node-package, screenshot, site-shot

## 简介

n8n community node that captures a screenshot of a public web page with the Site-Shot API and returns it as binary data.

## 官网

- 官网：https://www.site-shot.com/
- 源码仓库：git+https://github.com/site-shot/n8n-nodes-siteshot-public.git
- npm 页面：https://www.npmjs.com/package/n8n-nodes-siteshot
