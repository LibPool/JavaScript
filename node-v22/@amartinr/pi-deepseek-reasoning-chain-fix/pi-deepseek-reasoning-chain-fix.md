# @amartinr/pi-deepseek-reasoning-chain-fix

> 标签: deepseek, extension, pi, pi-coding-agent, reasoning, tool-calling

## 简介

Pi Coding Agent extension that fixes the DeepSeek reasoning-chaining contract on tool-calling turns: replays the real reasoning text on continuations, forces non-empty reasoning_content in tool scope, and strips the thinking:disabled kill-switch.
