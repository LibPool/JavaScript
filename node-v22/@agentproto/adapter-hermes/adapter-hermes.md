# @agentproto/adapter-hermes

> 标签: acp, adapter, agent-cli, agentproto, aip-45, hermes, nous

## 简介

@agentproto/adapter-hermes — AIP-45 AGENT-CLI adapter for Nous Research's Hermes Agent. Spawns `hermes acp` and drives it as an agentproto agent CLI via the ACP protocol arm of @agentproto/driver-agent-cli.
