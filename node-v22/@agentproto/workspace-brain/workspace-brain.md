# @agentproto/workspace-brain

> 标签: agentproto, bm25, brain, conversation, knowledge, rag, retrieval, workspace

## 简介

A per-workspace 'brain': indexes the conversations of a workspace's agent sessions into a queryable knowledge store (BM25 by default, or any federated combination of the knowledge adapters) so downstream agents can recall what a workspace's sessions did.
