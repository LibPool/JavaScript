# @agentproto/mcp-app-host

> 标签: agentproto, app-bridge, mcp, mcp-apps, open-standard

## 简介

@agentproto/mcp-app-host — framework-free MCP Apps host. Wraps the official AppBridge from @modelcontextprotocol/ext-apps: a transport-agnostic core (createMcpAppHost) plus a browser DOM adapter (mountMcpApp) that mounts a ui:// resource in a sandboxed sr
