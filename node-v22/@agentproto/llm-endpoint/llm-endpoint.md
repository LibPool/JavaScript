# @agentproto/llm-endpoint

> 标签: agentproto, anthropic, gateway, llm, open-standard, openai-compat, proxy

## 简介

@agentproto/llm-endpoint — a multi-surface LLM proxy gateway. Exposes Anthropic Messages, OpenAI Chat Completions, and OpenAI Responses API surfaces with transparent provider/model routing to Moonshot, OpenRouter, ZAI/Zhipu, Groq, xAI, and OpenAI. Handles
