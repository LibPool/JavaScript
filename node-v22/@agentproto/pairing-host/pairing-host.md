# @agentproto/pairing-host

> 标签: agentproto, aip-59, e2e, pairing, rendezvous, tunnel

## 简介

@agentproto/pairing-host — the host side of AIP-59 pairing as a library: offer store, pair/v2 handshake over an untrusted rendezvous, persisted pairings with reconnect and revocation, a default ws rendezvous dialer, a loopback HTTP forwarder for the paire
