# @agentproto/provider-presets

> 标签: agentproto, aip-45, catalog, presets, providers

## 简介

@agentproto/provider-presets — concrete provider/backend preset registry (baseUrl, keyEnv, scrubEnv, defaultModel) shared by Anthropic/OpenAI-compatible adapters and the user-facing presets catalog. Pure TS data; projection stays in the consumer.
