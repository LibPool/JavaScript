# @agentproto/inference-endpoint

> 标签: agentproto, anthropic, gateway, inference, llm, open-standard, openai-compat, proxy

## 简介

@agentproto/inference-endpoint — a multi-surface inference proxy gateway. Exposes Anthropic Messages, OpenAI Chat Completions, and OpenAI Responses API surfaces with transparent provider/model routing to Moonshot, OpenRouter, ZAI/Zhipu, Groq, xAI, and Ope
