# @agentproto/workflow-loader

> 标签: agentic, agentproto, aip-15, loader, manifest, open-standard, workflow

## 简介

Host-side loader for AIP-15 WORKFLOW.md: reads a manifest off disk, imports its optional TypeScript entry module, and reconciles the entry's step graph against the declared manifest. The I/O layer the pure @agentproto/workflow + @agentproto/workflow-runti
