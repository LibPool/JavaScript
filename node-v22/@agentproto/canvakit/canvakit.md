# @agentproto/canvakit

> 标签: agentic, agentproto, aip-5, canvakit, defineCanvakit, open-standard

## 简介

@agentproto/canvakit — AIP-5 TEMPLATE.md reference implementation. A markdown + frontmatter format for templates that declare named data sources, resolve them in parallel, and re-render when data changes.
