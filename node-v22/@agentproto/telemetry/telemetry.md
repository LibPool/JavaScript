# @agentproto/telemetry

> 标签: agentic, agentproto, observability, open-standard, opentelemetry, otel, spans, telemetry

## 简介

agentproto/telemetry — vendor-neutral Telemetry port + reference sinks (noop, stderr, array, compose) and an OpenTelemetry adapter that maps the kernel's TelemetryEvent stream to OTel spans grouped on cycleId. The adapter takes a host-supplied Tracer; no
