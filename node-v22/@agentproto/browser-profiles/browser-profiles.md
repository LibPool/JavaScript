# @agentproto/browser-profiles

> 标签: agentic, agentproto, browser, camofox, chrome, open-standard, profiles, sessions

## 简介

Browser session and profile model: saveable session descriptors (zod), Chrome profile discovery, camofox session reuse, and typed injection seams (AuthSignalRegistry, accountSwitcher, SessionSource registry).
