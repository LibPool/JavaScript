# @agentproto/a2a

> 标签: a2a, agent-card, agent2agent, agentic, agentproto, open-standard

## 简介

@agentproto/a2a — typed A2A (Agent2Agent) Agent Card and builders for agentproto apps. Hand-written from the A2A JSON spec; no SDK dependency.
