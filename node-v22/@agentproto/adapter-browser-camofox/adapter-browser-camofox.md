# @agentproto/adapter-browser-camofox

> 标签: agentproto, browser, camofox, camoufox, provider, stealth

## 简介

Camofox browser provider for agentproto: a defineBrowser provider over the camofox stealth-Firefox REST server, with an idempotent launch, a health mapping, and a BrowserDriver.
