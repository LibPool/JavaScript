# @fikaro/client

> 标签: api, authentication, baas, backend, backend-as-a-service, fikaro, iran, no-code, postgresql, typescript

## 简介

Official JavaScript/TypeScript client for Fikaro — an Iranian backend-as-a-service. Auto-generated REST API, PostgreSQL, and end-user auth without writing a backend.
