# @hy-sde-org/dsh-hashline

> 标签: agent, deepseek, edit, harness, hashline, patch

## 简介

Line-anchored edit-patch engine (hashline) ported from oh-my-pi — the pure, dependency-free core behind the rich `edit` tool for DeepSeek Harness.
