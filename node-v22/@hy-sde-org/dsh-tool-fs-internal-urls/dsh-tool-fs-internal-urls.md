# @hy-sde-org/dsh-tool-fs-internal-urls

> 标签: agent, conflict, deepseek, dsh-plugin, harness, internal-urls, read, write

## 简介

Agent-scope shadow of the DeepSeek Harness read/write/edit fs tools that also resolves conflict://, pr://, issue:// URLs through ctx.internalUrls — the routing surface that makes internal URLs work on stock harness releases.
