# @nuphus/nuphus-desktop-osx-arm64

> 标签: arm64, desktop, macos, nuphus

## 简介

Nuphus desktop binary for macOS arm64 (Apple Silicon). Installed automatically by the @nuphus/nuphus-desktop meta package.
