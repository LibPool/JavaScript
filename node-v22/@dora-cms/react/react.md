# @dora-cms/react

> 标签: admin-panel, client-editing, cms, content-editing, headless-cms, inline-editing, react, self-hosted

## 简介

Drop-in, self-hosted client-editable content for React sites — inline text, images, theme colors and a blog list, editable live on the page.
