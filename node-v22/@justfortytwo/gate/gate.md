# @justfortytwo/gate

> 标签: agent, allowlist, claude-code, claude-code-plugin, guardrail, hook, policy, pretooluse, safety

## 简介

Standalone, agent-agnostic PreToolUse safety gate for Claude Code: an autonomy-tier policy engine, a fail-closed bash allowlist, and a hook that turns dangerous tool calls into one-shot approvals.
