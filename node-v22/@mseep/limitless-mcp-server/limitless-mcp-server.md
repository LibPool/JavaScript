# @mseep/limitless-mcp-server

> 标签: mcp-server, mseep

## 简介

This repository provides a minimal MCP server/client implementation for interacting with the Limitless Developer API (GET endpoint only). It demonstrates how to expose API endpoints as MCP tools and how to call them via a client using a single merged code
