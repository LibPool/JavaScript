# @xromdev/drumroll

> 标签: canvas, chiptune, drum-kit, drum-roll, drums, falling-notes, nes, noise, react, visualizer

## 简介

Drums falling onto a kit: the NES noise channel's sixteen rates as a drum kit that moves when struck — canvas blocks, DOM pieces, no framework in the frame loop. React component included.
