# @rohanx96/react-navigation-fluid-transitions

> 标签: navigation, react, react-native, shared elements, transitions

## 简介

An extension to react-navigation providing transitions and shared element transitions. This is forked from fram-x/FluidTransitions and only makes it compatible for react-navigation v3.
