# @evarentha/linearpress-easy-captcha

> 标签: easy-captcha, evarentha, linearpress, plugin

## 简介

为登录、注册与评论提供人机验证：普通 PNG 文本验证码（复杂度/变形/字符数/字符集可调）或 Cloudflare Turnstile，验证码错误次数超限自动封禁账号。
