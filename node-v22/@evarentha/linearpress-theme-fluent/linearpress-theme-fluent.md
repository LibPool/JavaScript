# @evarentha/linearpress-theme-fluent

> 标签: evarentha, linearpress, plugin, theme-fluent

## 简介

基于 Fluent 2 设计语言的完整主题：前台与后台全 Fluent 化，内置深色模式；Fluent Web Components 全量打包进包内，完全离线可用。
