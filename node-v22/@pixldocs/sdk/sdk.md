# @pixldocs/sdk

> 标签: api, certificate, document-generation, image-generation, invoice, pdf, pixldocs, template

## 简介

Official TypeScript SDK for the PixlDocs document-generation API — render invoices, certificates, tickets and images from templates + JSON.
