# @boluabraham/fhir-human-address_

> 标签: JavaScript

## 简介

&lt;fhir-human-address&gt; adds address line1, line2, city,district and use fields to your page. Uses mwc-textfield and iron-ajax  In typical use, just use &lt;fhir-human-address url=""/fhir-human-address&gt;
