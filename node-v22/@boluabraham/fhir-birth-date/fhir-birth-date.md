# @boluabraham/fhir-birth-date

> 标签: JavaScript

## 简介

`<fhir-birth-date>` adds input date to the page. Uses input type date in mm/dd/yyyy format   In typical use, just use `<fhir-birth-date url=""></fhir-birth-date>`
