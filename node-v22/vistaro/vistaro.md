# vistaro

> 标签: cli, ffmpeg, llm, playwright, video-generation

## 简介

CLI that turns a UI mockup (index.html + vistaro.config.json) or a live web page into demo videos, step-by-step help guides and their translations, driven by an AI agent or by hand
