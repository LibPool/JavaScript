# @edgeos/checkout-react

> 标签: checkout, commerce, edgeos, headless, hooks, payments, react, sdk, tickets

## 简介

React adapter for the EdgeOS headless checkout SDK — a <CheckoutProvider> and hooks over @edgeos/checkout-core. Re-exports the core; the building-edgeos-checkout Claude Code skill ships in @edgeos/checkout-core.
