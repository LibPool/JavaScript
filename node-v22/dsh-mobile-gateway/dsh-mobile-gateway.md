# dsh-mobile-gateway

> 标签: deepseek-harness, dsh, dsh-plugin, mobile, qr, remote, tunnel

## 简介

手机访问网关：局域网扫码 + 公网隧道，把电脑上的 DSH 实时同步到手机（含设置页）。
