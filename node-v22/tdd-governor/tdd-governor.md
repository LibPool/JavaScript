# tdd-governor

> 标签: ai-coding-agents, claude-code, git-hooks, mutation-testing, tdd, test-driven-development, vitest

## 简介

Git-hook gate that blocks commits lacking real TDD evidence: red before green, no skipped tests, optional mutation coverage.
