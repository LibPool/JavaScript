# @sunkitjs/react-middle-truncate

> 标签: accessible, address, ellipsis, filename, grapheme, hash, headless, middle-ellipsis, middle-truncate, nextjs, react, text-overflow, truncate, zero-dependency

## 简介

Pixel-accurate middle ellipsis for React: keep the start and end of addresses, hashes and file names visible. Grapheme-safe, accessible, SSR-ready, zero dependencies.
