# @chitwitgit/eslint-plugin-shortest-import

> 标签: alias, eslint, eslint-plugin, eslintplugin, import, oxlint, paths, tsconfig, typescript

## 简介

ESLint plugin to prefer the shortest import path (relative vs alias). Windows-safe fork of @marqhq/eslint-plugin-shortest-import.
