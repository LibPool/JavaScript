# @jungherz-de/notionkit

> 标签: components, css, dark-mode, design-system, design-tokens, documents, light-mode, no-dependencies, notion, ui, workspace

## 简介

A calm, document-centric CSS component library in the Notion idiom – sidebar, page tree, database views, settings and AI surfaces. ~100 components, light & dark mode, no dependencies.
