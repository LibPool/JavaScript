# @parametric-memory/snapshot-verify

> 标签: audit, ed25519, merkle, mmpm, parametric-memory, rfc8785, snapshot, verify

## 简介

Verify Parametric Memory (MMPM) SnapshotV1 artifacts and Merkle proofs — same code in browser and Node. Zero dependencies, WebCrypto only.
