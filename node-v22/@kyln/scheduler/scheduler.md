# @kyln/scheduler

> 标签: JavaScript

## 简介

Scheduled task execution for Kyln. Cron expressions, intervals, one-off delays, and `@Timeout` decorators, with persist-before-dispatch durability (WAL + `synchronous=FULL`) so a scheduled trigger survives a process restart.
