# dsh-peak-light

> 标签: deepseek, deepseek-harness, dsh, dsh-plugin, off-peak, peak, pricing, sidebar, token

## 简介

Tiny peak/off-peak pricing indicator beside the DeepSeek Harness sidebar brand: red during peak pricing, green off-peak, hover for a countdown.
