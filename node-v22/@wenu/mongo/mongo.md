# @wenu/mongo

> 标签: database, immutable, mongodb, nosql, repository, schema, type-safe, typescript, validation, zod

## 简介

Declarative, immutable, type-safe MongoDB repository layer with Zod validation. Zero throws, dual ESM/CJS, pluggable ID strategies.
