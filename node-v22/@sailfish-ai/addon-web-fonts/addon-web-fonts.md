# @sailfish-ai/addon-web-fonts

> 标签: terminal, xterm, xterm.js

## 简介

Addon to use webfonts with [xterm.js](https://github.com/xtermjs/xterm.js). This addon requires xterm.js v5+.

## 官网

- 官网：https://github.com/xtermjs/xterm.js/tree/master#readme
- 源码仓库：git+https://github.com/xtermjs/xterm.js.git#master
- npm 页面：https://www.npmjs.com/package/@sailfish-ai/addon-web-fonts
