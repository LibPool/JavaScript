# @gcode-viewer/plugins

> 标签: annotation, bim, cad, cad-viewer, ifc, layer, measurement, three.js, typescript, viewer, webgl

## 简介

Viewer plugins for @gcode-viewer/core — GCode layer/steps bars, legend, text panel, plus toolbar, measure, screenshot and related chrome for 3D print preview.
