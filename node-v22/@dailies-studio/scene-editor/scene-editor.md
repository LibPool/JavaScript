# @dailies-studio/scene-editor

> 标签: JavaScript

## 简介

The scene editor chrome: prebuilt React app served static at / by `dailies scene`, so user tooling can never break it. Hierarchy, add-object palette, inspector, TSL drawer. The 3D viewport lives in src/viewport and is served ONLY through the project's Vit
