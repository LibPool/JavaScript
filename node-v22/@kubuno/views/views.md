# @kubuno/views

> 标签: JavaScript

## 简介

Kubuno .kbview views runtime (@kubuno/views) — the code-behind model (View, @bind, element handles, event args), the renderer of compiled views and the runtime elements (Repeater, Timer, Query, Mutation, MessageBox, Dialog). Provided by the host at runtim
