# @da3monhunt3r/bugripper

> 标签: bug-reporting, feedback, javascript, typescript, widget

## 简介

Bugripper is a bug reporting tool that allows users to capture/report bugs and issues directly from your application. It provides a widget for users to submit feedback, and a core library for managing bug reports.
