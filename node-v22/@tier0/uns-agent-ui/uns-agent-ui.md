# @tier0/uns-agent-ui

> 标签: JavaScript

## 简介

Tier0 UNS Agent 的前端组件包：聊天面板（SSE 流式对话）、卡片画布、技能管理、定时任务。 配合 Tier0 uns-agent-service 后端使用，宿主应用自行编排布局。
