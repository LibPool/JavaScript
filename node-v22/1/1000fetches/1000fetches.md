# 1000fetches

> 标签: api, arktype, axios, client, fetch, http, schema, typescript, valibot, validation, zod

## 简介

A modern, type-safe HTTP client for TypeScript with built-in schema validation, middleware, opt-in retry logic, and compile-time path parameter validation. Features full TypeScript support, request/response middleware, and schema validation using Standard
