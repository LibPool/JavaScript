# @lymtic/version-watcher

> 标签: vite 插件, vue3, 提示组件库

## 简介

当一些频繁使用的网站发布新版本时，已经打开网页的用户可能无法即时了解到更新。尤其是对于某些后台应用，用户一旦打开页面，通常在相当长的时间内不会刷新。由于新版本在短时间内难以覆盖到平台上 80%及以上的用户，我们建议引导用户主动进行页面刷新，以确保他们获得最新的用户体验
