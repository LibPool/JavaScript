# pi-cowboy

> 标签: agents, ai, herdr, pi, pi-agent, pi-coding-agent, pi-extension, pi-package, subagents

## 简介

Agent orchestrator for pi: can manage Codex, Claude Code, OpenCode, pi, pig and pi-bolt as subagents. Runs subagents in background Herdr panes, isolated in copy-on-write Git worktrees.
