# @naskot/node-dispatched-tasks

> 标签: delayed-tasks, ioredis, microservices, node, redis, scheduler, task-queue, typescript, weight

## 简介

Lightweight Redis-backed delayed-task scheduler for Node microservices: weight-aware execution, integer auto-increment IDs, framework-agnostic.
