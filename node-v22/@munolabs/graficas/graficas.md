# @munolabs/graficas

> 标签: chart, charting, charts, data-visualization, dataviz, headless, react, server-side, svg

## 简介

Config-first, headless chart library: one JSON config renders as interactive React or a static SVG string (no DOM). Column, bar, line, area, pie, donut, combo, scorecard, table.
