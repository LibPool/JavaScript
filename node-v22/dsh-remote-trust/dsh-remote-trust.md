# dsh-remote-trust

> 标签: deepseek-harness, dsh, dsh-plugin, loopback, nginx, remote-access, reverse-proxy, settings, web

## 简介

DeepSeek Harness plugin: makes a reverse-proxied (non-loopback) dsh web page count as a trusted host, so the Settings surface loads instead of reporting "settings are unavailable in this browser".
