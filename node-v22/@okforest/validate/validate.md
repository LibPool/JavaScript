# @okforest/validate

> 标签: d2, lint, mermaid, okf, okforest, open-knowledge-format, validator

## 简介

Validate Open Knowledge Format (OKF) v0.2 trees: spec conformance, link and metadata checks, and D2 and Mermaid diagram syntax, as structured findings with stable rule IDs and file and line locations.
