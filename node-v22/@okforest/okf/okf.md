# @okforest/okf

> 标签: frontmatter, knowledge-management, markdown, okf, okforest, open-knowledge-format

## 简介

Read an Open Knowledge Format (OKF) v0.2 tree into a model: concepts, frontmatter, links, backlinks, trust tiers, staleness, and a metadata inventory. No SDKs or frameworks; runs in Node, browsers, and Workers.
