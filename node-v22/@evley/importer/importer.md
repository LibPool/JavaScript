# @evley/importer

> 标签: angular, data importer, ivy, javascript, typescript

## 简介

Simple Angular importer to get data into an Evley.app. However, its a general all purpose data import to local storage styled with Angular Material. P.s. Built with Angular Ivy which is only compatible with Angular 9.0.0+.
