# @i2analyze/create-notebook-sdk-plugin

> 标签: JavaScript

## 简介

Create Notebook SDK Plugin is a simple way to bootstrap development of i2 Notebook web client plugins. It produces a build setup with development proxy support and production bundling for plugin deployment.
