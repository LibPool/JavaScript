# @bulkheadtools/cli

> 标签: ai-agents, audit-log, auto-mode, claude-code, claude-code-hooks, coding-agent, completion-verification, containment, cost-limit, dangerously-skip-permissions, guardrails, hooks, ledger, pretooluse, safety

## 简介

Claude Code hooks that keep receipts: deterministic guardrails (incident-pack command rules, protected paths, $ caps, loop freeze), completion verification, and a tamper-evident ledger. One command. Containment and evidence — not a firewall.
