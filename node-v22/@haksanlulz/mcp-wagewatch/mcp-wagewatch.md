# @haksanlulz/mcp-wagewatch

> 标签: back-wages, civic-data, dol, enforcement, labor, mcp, model-context-protocol, wage-and-hour, wage-theft, whisard

## 简介

MCP server over the U.S. DOL Wage and Hour Division enforcement dataset (employer wage-theft history and back wages owed) for nonprofits, legal aid, and worker-justice organizers.
