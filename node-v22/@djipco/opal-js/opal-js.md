# @djipco/opal-js

> 标签: cobs, led, led-controller, neopixel, opal, serialport, ws2811, ws2812, ws2812b

## 简介

JavaScript client library for OPAL (Open Protocol for Addressable LEDs), with browser Web Serial and Node.js serial transports.
