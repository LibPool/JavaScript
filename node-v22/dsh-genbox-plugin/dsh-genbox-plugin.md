# dsh-genbox-plugin

> 标签: cordis-plugin, deepseek, deepseek-harness, dsh-plugin, genbox, image-editing, image-generation, inpainting, text-to-image, video-generation

## 简介

DeepSeek Harness tools for GenBox: image generation/editing (including inpaint, upscale, cutout) and video generation through a local GenBox server.
