> 标签: airbnb, anthropic, booking, channel-manager, claude, hospitality, mcp, model-context-protocol, pms, repull, vacation-rental, vrbo

## 简介

Model Context Protocol (MCP) server for the Repull API — agent-friendly access to reservations, properties, listings, guests, and conversations across 50+ PMS platforms and the major OTAs (Airbnb, Booking.com, VRBO, Plumguide). Includes built-in discovery
