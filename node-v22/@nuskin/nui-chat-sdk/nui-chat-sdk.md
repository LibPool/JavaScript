# @nuskin/nui-chat-sdk

> 标签: chat, nui, nuskin, sdk, sse, transport

## 简介

Framework-agnostic transport and protocol layer for NUi chat clients: authenticated conversation endpoints, SSE stream parsing, embed-token exchange, and LiveKit token retrieval. No UI, no React — shared by the web and React Native chat SDKs.
