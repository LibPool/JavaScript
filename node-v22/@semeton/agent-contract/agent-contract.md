# @semeton/agent-contract

> 标签: agent, agentic, ai, claude, claude-code, codex, contract, copilot, determinism, llm, scaffolding

## 简介

Deterministic contract layer between humans and coding agents. Drop into any repo to make AI agents (Claude, Codex, Copilot, etc.) operate under explicit, enforceable rules.
