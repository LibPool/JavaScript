> 标签: ai, antigravity, cli, codex, engineering-excellence, gentle-ai, gga, installer, mcp, opencode, pi, setup

## 简介

Cross-OS installer for an AI coding toolchain (pi, codex, antigravity, opencode, herdr, gentle-ai/gga, Engineering Excellence) with an interactive module menu and per-agent MCP registration.
