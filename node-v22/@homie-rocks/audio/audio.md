# @homie-rocks/audio

> 标签: JavaScript

## 简介

Web Audio building blocks for games: an output chain that cannot clip, seeded noise and reverb, envelopes, voice management, a beat clock and an offline sampler planner. It ships no notes, tempos or patches.
