# cuckoo-ask

> 标签: ai, ask, cuckoo-code, cuckoo-plugin, plugin, questionnaire

## 简介

让 AI 通过问卷卡片向用户提问的 Cuckoo Code 插件。捕获 ask 代码块，弹出可拖动问卷，答完作为用户消息发回。
