# hinglish-profanity

> 标签: abuse, bad-words, content-moderation, devanagari, filter, gaali, hindi, hinglish, india, moderation, profanity

## 简介

Profanity detection for English, Hindi (Devanagari) and romanized Hinglish. Returns evidence, not a boolean. Zero dependencies.
