# @mvpscale/mm3

> 标签: agent-skills, agents, claude-code, codex, decision-support, gemini-cli, mcp

## 简介

MM3, make and model for coding agents: MAK³ uses what is proven, MDL³ learns what is missing, with compact yes/no checklists, a calibrated consensus, and a log that learns where agents go wrong.
