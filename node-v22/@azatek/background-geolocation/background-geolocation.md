# @azatek/background-geolocation

> 标签: accuracy, android, background, battery-optimization, capacitor, geolocation, gps, ios, location, plugin, tracking

## 简介

Capacitor plugin for background geolocation tracking with configurable GPS accuracy modes (HIGH/BALANCED/LOW/PASSIVE) for battery optimization. Fork of @capacitor-community/background-geolocation with enhanced accuracy control.
