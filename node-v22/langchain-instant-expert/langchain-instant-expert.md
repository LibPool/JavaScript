# langchain-instant-expert

> 标签: ai-agents, experts, human-in-the-loop, langchain, mcp, toolkit

## 简介

LangChain.js toolkit for Instant Expert: let an agent pay specific executives and experts for a short call or a written answer, charged only when they answer.
