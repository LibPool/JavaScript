# brooksfleet-402-gateway

> 标签: 402, ai-crawlers, base, claudebot, express, gptbot, nestjs, nextjs, nginx, pay-per-crawl, phantom, robots.txt, solana, usdc, x402

## 简介

Make AI training crawlers pay: answer them with HTTP 402 — a plain block or an x402 USDC payment — while search engines and AI search agents pass. Next.js, Express/NestJS and nginx.
