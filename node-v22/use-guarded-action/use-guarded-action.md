# use-guarded-action

> 标签: concurrency, nextjs, race-condition, react, server-actions, stale-while-revalidate, useOptimistic, useTransition

## 简介

Discard stale async results when a newer call has already superseded them - a drop-in-shaped guard for Next.js Server Actions used with useOptimistic/useTransition, so rapid-fire clicks or slow responses can't overwrite fresher state with stale data.
