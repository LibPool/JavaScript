# @zhangdali1996/lr-map-viewer

> 标签: JavaScript

## 简介

`@zhangdali1996/lr-map-viewer` 是面向 Vue 3 项目的三维地图组件库，提供龙软三维场景承载能力，以及基于组件实例的视角控制与模型信息查询能力。
