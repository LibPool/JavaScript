# @apislash/auth-web

> 标签: apislash, auth, authentication, mfa, oauth, passkey, typescript, webauthn

## 简介

Browser platform adapter (OAuth2 redirect/popup + WebAuthn) for the Apislash auth core. Usable in any web app; published by Apislash.
