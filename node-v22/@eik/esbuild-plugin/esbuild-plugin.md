# @eik/esbuild-plugin

> 标签: esbuild, esbuild-plugin, esbuild.js, esm, import, url

## 简介

esbuild plugin for loading import maps from a Eik server and applying the mapping to ECMAScript modules in preparation for upload to the same server.
