## 简介

MCP server exponiendo las tools core de ST (check / derive / countermodel / formalize) sobre 11 perfiles lógicos. Usable desde Claude Code, Cursor, ChatGPT con MCP y cualquier cliente compatible con el Model Context Protocol vía transport stdio.
