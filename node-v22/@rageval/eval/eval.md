# @rageval/eval

> 标签: ai, claude, evaluation, hallucination-detection, langchain, llm, nlp, openai, rag, ragas, retrieval-augmented-generation, typescript

## 简介

TypeScript RAG pipeline evaluation library — the RAGAS equivalent for Node.js. Evaluate answer faithfulness, context relevance, answer relevance, context recall, and context precision.
