# @dikacode/telegram-mcp

> 标签: claude-code, codex, gramjs, mcp, model-context-protocol, mtproto, opencode, telegram

## 简介

Local MCP server that connects CLI agents (OpenCode, Codex CLI, Claude Code, ...) to a personal Telegram account over MTProto.
