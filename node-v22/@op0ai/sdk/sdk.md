# @op0ai/sdk

> 标签: agent, agents, cloudflare, fleet, governance, op0, runspec, runtime, workers

## 简介

The op0 SDK — an agent with a computer: a governed function under a RunSpec (goal + stop rules + verifier), typed ports, a vendor-free core. Build agents that run on op0 (op0.ai), the governed runtime for agent work. Proprietary — free to use WITH the op0
