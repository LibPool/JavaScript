# @maroonedsoftware/permissions-dsl

> 标签: authorization, permissions, rebac, serverkit, typescript, zanzibar

## 简介

A surface-syntax DSL and compiler (pdsl CLI) for @maroonedsoftware/permissions — author Zanzibar-style namespaces in .perm files and generate TypeScript that drives the runtime authorization model.
