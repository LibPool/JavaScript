# @orqenix/local-memory-federation

> 标签: apache-2.0, cross-project, memory-federation, orqenix

## 简介

Apache-2.0 pull-on-demand cross-project memory federation for Orqenix Workbench. Strictly opt-in per CR v8.0 ADR-E-011.
