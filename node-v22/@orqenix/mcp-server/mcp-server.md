# @orqenix/mcp-server

> 标签: ai-agents, apache-2.0, mcp, model-context-protocol, orqenix

## 简介

Apache-2.0 Orqenix MCP Server. Exposes memory + skills + mesh as MCP tools/resources/prompts over stdio/HTTP/WebSocket.
