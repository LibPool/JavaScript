# @tierone/llm-harness-nest

> 标签: agents, ai-agent, claude, claude-code, harness, harness-engineering, llm, nestjs, ruler, skills

## 简介

LLM agent harness for NestJS projects — guides (skills, instructions) + sensors (review agents). Installs into .ruler/ via a 3-way-merge-aware CLI.
