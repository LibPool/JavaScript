# @sikuthenomad/create-react-js

> 标签: cli, react, template, vite

## 简介

Provides a clean version of the scaffolding generated by `npm create vite@latest -> React -> Javascript`. Prompts for a project name. The version number will always represent the Vite version this project is synced with.
