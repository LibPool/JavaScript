# @sfxcode/nuxt-mongocamp-server

> 标签: JavaScript

## 简介

Nuxt module wrapping a generated OpenAPI client for [MongoCamp](https://mongocamp.io), with composables for browser-session auth and server-side API-key/bearer auth.
