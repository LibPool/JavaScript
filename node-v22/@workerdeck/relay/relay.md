# @workerdeck/relay

> 标签: agent, gateway, peers, relay, workerdeck

## 简介

The WorkerDeck relay: one always-on process every gateway dials out to. Holds the cross-gateway session registry, authenticates enrolled gateways, enforces the visibility rules and routes peer requests between them.
