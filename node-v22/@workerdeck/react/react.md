# @workerdeck/react

> 标签: agent, anthropic, claude, claude-code, headless, hooks, react

## 简介

Headless React layer for WorkerDeck: session hook + pure transcript and sessions-list reducers. No styling opinion - @workerdeck/ui is the styled layer on top.
