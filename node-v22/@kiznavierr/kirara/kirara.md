# @kiznavierr/kirara

> 标签: api, cards, enka, genshin, typescript

## 简介

A TypeScript library for fetching character data from Enka API and generating card images using enka.cards. Supports Genshin Impact, Honkai: Star Rail, and Zenless Zone Zero.
