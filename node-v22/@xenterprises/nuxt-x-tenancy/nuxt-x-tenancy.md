# @xenterprises/nuxt-x-tenancy

> 标签: better-auth, multi-tenant, nuxt, nuxt-layer, saas, tenancy

## 简介

Multi-tenant resolution layer for Nuxt: bridges better-auth active organization to tenant scope, X-Tenant-ID header injection, and useXCrud cache scoping
