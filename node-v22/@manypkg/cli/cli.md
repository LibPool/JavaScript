# @manypkg/cli

> 标签: JavaScript

## 简介

Manypkg is a linter for `package.json` files in Yarn, npm, Lerna, pnpm, Bun or Rush monorepos.

## 官网

- 官网：https://github.com/Thinkmill/manypkg#readme
- 源码仓库：git+https://github.com/Thinkmill/manypkg.git
- npm 页面：https://www.npmjs.com/package/@manypkg/cli
