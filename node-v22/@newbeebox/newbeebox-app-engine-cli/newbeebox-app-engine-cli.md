# @newbeebox/newbeebox-app-engine-cli

> 标签: app-engine, cli, deploy, kubernetes, nae, newbee, paas

## 简介

NewBee App Engine 命令行客户端（nae）——参数直达、默认人类可读（加 -o json 出 JSON），便于在终端使用与脚本/管道里解析。
