# @assurly/mcp-server

> 标签: agent-security, agent-tools, ai-agents, allowscripts, claude-code, cursor, install-scripts, mcp, mcp-security, mcp-server, model-context-protocol, nextjs, npm12, pre-deploy, prompt-injection, security, ship-gate, slopsquat, static-analysis, supabase, supply-chain-security, vibe-coding, vscode, windsurf

## 简介

MCP server that gives Cursor, Claude Code, VS Code and Windsurf a pre-deploy ship gate. Five tools: scan a path or files, explain a rule, read a hosted verdict, and audit the agent stack itself (MCP config and instruction files).
