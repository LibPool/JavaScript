# @birkheadc/github-repo-parser

> 标签: JavaScript

## 简介

Parses a specified user's public repositories for a specific file structure and uses that data to create an array of objects. Essentially, this facilitates the creation of a more advanced, API-legible README that can be stored directly in a project's repo
