# @openlibing/huaweicloud-oidc-client

> 标签: apig, gitcode, github-actions, huaweicloud, oidc, openlibing, sts

## 简介

openlibing 平台与华为云交互 SDK：OIDC 认证获取临时凭证、callApig 一行调用 APIG（V11-HMAC-SHA256 签名）、HTTPS 请求工具（基于 Node 内置 fetch）
