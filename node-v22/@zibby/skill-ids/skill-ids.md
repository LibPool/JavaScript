# @zibby/skill-ids

> 标签: agent-workflow, constants, skills, zibby

## 简介

Single authoritative Zibby skill-id map (zero-dep leaf). The one source of truth for well-known skill ids — every consumer (agent-workflow, core, skills, backend, templates) imports it, so the ids can never drift.
