# @zibby/bin-semgrep

> 标签: binary, code-scan, sast, semgrep, semgrep-core, supply-chain, vendored, zibby

## 简介

Zibby-owned, self-vendored Semgrep OSS engine (semgrep-core) delivery. Materializes the host-matched, sha256-pinned semgrep-core (+ its bundled libs) ON DEMAND from Zibby's own CDN into a local cache — no image bake, no upstream-npm binary trust at run ti
