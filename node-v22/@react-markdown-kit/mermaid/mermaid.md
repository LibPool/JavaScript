# @react-markdown-kit/mermaid

> 标签: diagram, drawing, flowchart, flowchart-editor, markdown, mermaid, mermaid-editor, plugin, react, react-mermaid, svg, visual-editor

## 简介

Mermaid diagrams for React Markdown Kit: mermaid() turns ```mermaid fences into static SVG in the renderer and a drawing canvas in the editor, and the /canvas entry is the same canvas as a standalone component. Edits are written back as Mermaid syntax.
