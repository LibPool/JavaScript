# @lucidcreative/ventuz-osc

> 标签: OSC, Open Sound Control, TCP, UDP, Ventuz, Web Socket, serial

## 简介

A JavaScript connector to Ventuz Remoting 4 via Open Sound Control (OSC) library that works in Node.js and the browser.
