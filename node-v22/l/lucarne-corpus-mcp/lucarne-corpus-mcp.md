# lucarne-corpus-mcp

> 标签: corpus, mcp, provenance, read-only, records

## 简介

Optional thin stdio MCP bin: read-only queries over a lucarne-records store. Never fetches, replays, or opens a browser — a miss returns a structured not_captured result telling the agent to browse to it in-session.
