# ligo-template-frontend

> 标签: JavaScript

## 简介

Este repositório é um template para iniciar projetos front-end usando **Vite**, **React** e **TypeScript**. O objetivo é fornecer uma base inicial pronta para desenvolvimento com configuração mínima.
