# llmt-runner

> 标签: agentic, ai-judge, automation, cli, llm, test-runner, testing, yaml

## 简介

LLM-judged CLI test runner — define test cases in YAML, execute commands, let an LLM judge PASS/FAIL. Outputs JSONL trace.
