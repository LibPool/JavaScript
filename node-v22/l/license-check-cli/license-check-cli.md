# license-check-cli

> 标签: agpl, cli, copyleft, dependency-audit, gpl, legal, license, license-checker, license-compliance, npm-audit, open-source-compliance, oss-compliance, supply-chain

## 简介

Scan npm project dependencies and flag copyleft/restrictive licenses (GPL, AGPL, LGPL, SSPL). Zero dependencies — pure Node.js built-ins.
