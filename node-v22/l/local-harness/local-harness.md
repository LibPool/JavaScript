# local-harness

> 标签: agent, ai, claude-code, cli, codex, cursor, gemini-cli, harness, llm, opencode

## 简介

One JavaScript API for the AI agent CLIs installed on this machine (Claude Code, Cursor, Codex, Gemini CLI, OpenCode): discover them, read their models and capabilities, and send prompts.
