# lwu-request

> 标签: lwu-request, uniapp, 刷新token, 网络请求, 请求中断, 请求拦截

## 简介

基于uniapp网络请求API封装的轻量级网络请求库，支持自动刷新token，请求拦截，请求中断，自动重试等特性
