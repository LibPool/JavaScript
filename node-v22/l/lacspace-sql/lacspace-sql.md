# lacspace-sql

> 标签: aggregate, cli, csv, excel, group-by, in-memory, json, ndjson, no-database, query, select, sql, sql-engine, typescript, xlsx

## 简介

Run SQL over your CSV, JSON, NDJSON and Excel files — SELECT, WHERE, ORDER BY, GROUP BY, aggregates — no database, no API keys. Built on the lacspace-scraper file engine.
