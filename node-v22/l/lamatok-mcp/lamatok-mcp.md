# lamatok-mcp

> 标签: ai, claude, codex, cursor, data-api, lamatok, mcp, mcp-server, model-context-protocol, social-media, tiktok, tiktok-api

## 简介

MCP server for LamaTok — TikTok data API. Auto-generates tools from the LamaTok OpenAPI spec so every endpoint is instantly usable from Claude, Cursor, Codex, Zed, and Windsurf.
