# lexis-mcp

> 标签: claude, claude-code, code-search, llm, mcp, retrieval, ripgrep

## 简介

Lexical + structural code search MCP server. ~80% fewer tokens per code task. Validated on Claude Code; should work with any MCP-compatible client (Cursor, Windsurf, Continue, Cline, Zed, etc. — untested, contributions welcome).
