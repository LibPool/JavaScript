# litert-react

> 标签: litert, litertjs, on-device-ml, react, react-hooks, tensorflow, web-worker, webgpu

## 简介

React hooks for LiteRT.js and Worker-based ML inference: model loading, Web Worker RPC, WebGPU detection with CPU fallback, frame throttling.
