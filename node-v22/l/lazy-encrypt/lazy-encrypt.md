# lazy-encrypt

> 标签: aes-gcm, code-splitting, encryption, lazy, pbkdf2, react, vite, vite-plugin, webcrypto

## 简介

Password-encrypt a lazily-loaded React route at build time with Vite. The plaintext source never ships — only an AES-GCM blob, decrypted in the browser after the correct password.
