# lua-redis-wasm

> 标签: engine, eval, lua, lua5.1, redis, sandbox, script, testing, wasm, webassembly

## 简介

WebAssembly-based Redis Lua 5.1 script engine for Node.js - Execute Redis-compatible Lua scripts without a live Redis server
