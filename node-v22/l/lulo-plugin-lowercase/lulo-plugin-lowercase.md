# lulo-plugin-lowercase

> 标签: AWS, CloudFormation, Custom Resource, Lowercase, Lulo, Plugin

## 简介

lulo lowercase is a plugin for [lulo](https://github.com/carlnordenfelt/lulo). It responds with a lowercased version of the provided Value string.
