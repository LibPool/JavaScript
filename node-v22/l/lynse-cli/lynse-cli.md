# lynse-cli

> 标签: ai, api-wrapper, cli, lynse, openclaw, transcription

## 简介

Lynse CLI 技能包 - 调用 lynse.ai 后端服务的 API，支持用户管理、文件管理、设备管理、AI 模型管理等功能

## 官网

- 官网：https://www.lynse.ai
- 源码仓库：git+https://github.com/johneyzhao-lynse/lynse-cli.git
- npm 页面：https://www.npmjs.com/package/lynse-cli

- npm registry：https://registry.npmjs.org/lynse-cli
- Node 要求：>=14.0.0
