# laws-of-form-react

> 标签: GSB, Laws of Form, LoF, React, Spencer-Brown

## 简介

A Laws of Form (1969) React library. Easily generate dynamical LoF Graphics. Moreover, LoF syntax highlighting, parsing and input fields are available.
