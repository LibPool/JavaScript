# lkpgestao-mcp

> 标签: claude, cowork, lkpgestao, mcp, model-context-protocol

## 简介

MCP server for LKPGestão — exposes the management API (projects, opportunities, quotes, tasks, timesheets, clients, helpdesk, financials) to Claude Code, Claude Desktop and Claude Cowork as read/write tools and prompts.
