# litescrape-mcp-server

> 标签: bing search, claude, cursor, duckduckgo, google ai mode, google ai overview, google maps, google reviews, google search, google shopping, litescrape, mcp, mcp-server, model context protocol, serp api, web search

## 简介

MCP server for the Litescrape API: Google Search, Bing, DuckDuckGo and Google Maps free without an API key, plus Google AI Mode, AI Overview, Shopping and Reviews with one. Stdio or Streamable HTTP.
