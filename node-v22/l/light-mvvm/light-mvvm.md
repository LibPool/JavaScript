# light-mvvm

> 标签: 迷你版Vue，小型MVVM框架，双向数据绑定,轻量级MVVM插件(适合单页面应用)

## 简介

它是仅有9KB大小的轻量MVVM插件,你可以采用vue语法构建应用。
