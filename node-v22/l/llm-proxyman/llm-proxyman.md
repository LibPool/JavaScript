# llm-proxyman

> 标签: anthropic, anthropic-api, api-proxy, claude, claude-code, codex, debugger, docker, gpt, inspector, llm, llm proxy, llm-proxy, llm-proxyman, lm-studio, local-llm, mitm, ollama, openai, openai-api, postman, prompt, proxy, proxyman, request-inspector, response-inspector, sqlite, sse, streaming, token, token-count, token-tracking, vllm, web-ui

## 简介

Local HTTP proxy that intercepts and inspects LLM API calls from Claude Code, Codex CLI, and OpenAI/Anthropic clients. Real-time web UI to view requests, responses, tokens, and timing. Routes to local LLM servers (Ollama, LM Studio, vLLM) or cloud APIs. M
