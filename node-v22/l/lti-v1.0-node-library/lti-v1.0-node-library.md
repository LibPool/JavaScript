# lti-v1.0-node-library

> 标签: a-plus, basic-outcomes, grade-submission, lms, lti, lti-v1.0, lti-v1.1, plussa

## 简介

TypeScript library for LTI 1.0/1.1 integration with LMS platforms (including older versions of A-Plus), including Basic Outcomes grade submission. Focused on LTI 1.0/1.1 support for platforms like older versions of A-Plus that don't support LTI 1.3.
