# lyrebirdai

> 标签: agent, ai, australia, lyre, lyrebird, lyrebirdai, react-native, voice, voice-agent, webrtc

## 简介

Browser & React Native SDK for starting voice calls with LYRE AI agents. Authenticate with a lyre_pk_ public key and connect via WebRTC.

## 官网

- 官网：https://lyre.au
- 源码仓库：git+https://github.com/wdetcetera/fulcrum-voice-api.git
