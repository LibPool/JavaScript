# lacspace-mock

> 标签: api-mocking, api-simulator, chaos, chaos-engineering, cli, contract-testing, cors, crud, developer-tools, fake-api, faker, fault-injection, fixtures, graphql, http, json-schema, json-server, latency-simulation, local-server, mock, mock-api, mock-server, openapi, openapi-mock, prototyping, proxy, record-replay, request-validation, rest, stateful, stub, swagger, typescript, zero-dependency

## 简介

Stand up a keyless local mock REST + GraphQL API server from a JSON db, an OpenAPI spec, or a small config — stateful CRUD, request validation, latency + chaos injection, record-and-replay proxy, filtering, templated routes, CORS. Zero dependencies.
