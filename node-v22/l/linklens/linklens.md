# linklens

> 标签: chat-link-preview, hashtags, highlight-link, link, link-detection, link-preview, linklens, mentions, metadata, npm, npm-react-component, open-graph, react, react-component, react-link-preview, react-url-parser, rich-preview, social-preview, thumbnail, url

## 简介

LinkLens is a lightweight React package to detect, highlight, and preview URLs, links, mentions, and hashtags in text. Supports rich link previews with thumbnails, titles, descriptions, and metadata.
