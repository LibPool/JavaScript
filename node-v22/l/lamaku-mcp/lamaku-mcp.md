# lamaku-mcp

> 标签: brightspace, claude, d2l, hawaii, lamaku, lms, mcp, model-context-protocol, valence

## 简介

MCP server for Lamakū, the University of Hawaiʻi's D2L Brightspace LMS — read course data and author announcements, content, assignments, grade items and discussions, with a FERPA guard on student identities
