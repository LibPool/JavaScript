# loopwarden

> 标签: event-loop, event-loop-lag, monitoring, opentelemetry, performance, pino, prometheus, sentry, worker-threads

## 简介

Native Node.js event-loop lag monitoring with percentile histograms, debounced two-level alerts, worker_thread support, and pluggable exporters (Prometheus, Sentry, OpenTelemetry).
