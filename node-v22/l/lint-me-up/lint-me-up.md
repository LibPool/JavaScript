# lint-me-up

> 标签: JavaScript

## 简介

I'm a tiny tool for installing eslint (airbnb style), prettier and a husky pre commit hook (for checking your code before you send it up) into react based projects.

## 官网

- npm 页面：https://www.npmjs.com/package/lint-me-up
