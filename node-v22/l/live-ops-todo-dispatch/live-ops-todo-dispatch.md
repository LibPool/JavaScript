# live-ops-todo-dispatch

> 标签: chat-extraction, cli, dingtalk, dispatch, live-ops, scheduler, todo

## 简介

直播运营每日代办分发 CLI v2：读取钉钉群聊/私聊，AI 语义筛选每日代办，结合固定模板自动创建钉钉待办、发送汇总消息，并生成云端定时（早批次+轮询）任务
