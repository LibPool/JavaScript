# logisheets-mcp

> 标签: agent, claude, excel, formula, llm, logisheets, mcp, model-context-protocol, spreadsheet, xlsx

## 简介

An MCP server that gives an AI agent a real, Excel-compatible spreadsheet engine to compute in and remember in — deterministic formulas, structured block memory addressed by (block, key, field), and a real .xlsx out.
