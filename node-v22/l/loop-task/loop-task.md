> 标签: agent, agent-automation, ai-agent, automation, automations, background-tasks, claude-code, cli, codex, coding-agent, cron, devops, interval, loop, loop-engineering, opencode, repeat, schedule, scheduler, timer

## 简介

Loop engineering toolkit. Run any command on a cadence, in the background, managed from a terminal board. Schedule tests, builds, syncs, or agent prompts.
