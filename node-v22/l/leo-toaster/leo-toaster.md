# leo-toaster

> 标签: angular, angular-toast, farsi, leo-toaster, ngx-toast, notification, persian, rtl, standalone, toast, toaster

## 简介

Beautiful, lightweight toast notifications for Angular (standalone). Supports Persian (fa) and English (en) with automatic RTL/LTR. Glassmorphism UI, signals-based, zero dependencies beyond Angular.
