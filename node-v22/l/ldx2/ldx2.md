# ldx2

> 标签: JavaScript

## 简介

本项目名为农博会平台后台, 已现有后台wd-html-admin为基础所开发出来的转为农博会服务的新后台，本项目属于公司内部使用，其中主要包含商品管理、订单管理、财务管理、运营管理4大功能板块
