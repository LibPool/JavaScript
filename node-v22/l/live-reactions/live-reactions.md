# live-reactions

> 标签: broadcastchannel, collaboration, emoji-reactions, floating-reactions, flying-emoji, laravel-echo, live-reactions, presence, react, reactions, realtime, reverb, vue, websocket

## 简介

Google Meet-style flying emoji reactions for any web app: send a reaction over Laravel Echo, raw WebSocket, BroadcastChannel or your own channel. Rate limiting, aggregation and TTL included. Zero dependencies, no SaaS. Vanilla, Vue and React bindings.
