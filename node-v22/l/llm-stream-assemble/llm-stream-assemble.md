## 简介

Composable TypeScript stream assembly for OpenAI, Anthropic, Gemini (Google AI + Vertex AI), AWS Bedrock, Cohere, and OpenAI-compatible LLM APIs — unified StreamEvent model for text, tools, reasoning, JSON, usage, and non-streaming responses.
