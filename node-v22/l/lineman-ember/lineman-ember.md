# lineman-ember

> 标签: ember, lineman, linemanplugin

## 简介

This is a plugin to get started with Ember using [Lineman](http://linemanjs.com). We recommend you look at our [Ember template project](https://github.com/linemanjs/lineman-ember-template/) as a starting point.
