> 标签: africa, angular, backoff, electron, fetch, form, image-compression, indexeddb, low-bandwidth, multi-tenant, offline, offline-first, pwa, react-native, retry, solid, svelte, vue

## 简介

Resilience for the other half of the internet: automatic retries, an offline request queue, and bandwidth-aware media for web apps on poor connections.
