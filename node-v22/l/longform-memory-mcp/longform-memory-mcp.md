# longform-memory-mcp

> 标签: ai-writing, claude, context-window, continuity, cursor, llm, local-first, long-context, mcp, mcp-server, memory, modelcontextprotocol, novel, token-budget

## 简介

MCP server that gives your AI writing assistant a constant-size memory of a long document. Chapter 1000 costs the same tokens as chapter 10. Local-only: no account, no API key, no network.
