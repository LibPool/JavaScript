# local-git-deploy

> 标签: branch-deploy, ci-cd-alternative, cli, cpanel, deploy, deploy-cli, deployment, file-sync, ftp, ftp-deploy, ftps, git, git-diff, git-ftp, git-sftp, incremental-deploy, local, local-deploy, multi-branch, php-deploy, post-deploy, remote-script, sftp, shared-hosting, ssh, ssh-hooks, sync, upload

## 简介

Deploy only changed git files to FTP, FTPS, or SFTP servers. Fast, incremental, no CI/CD pipeline required.
