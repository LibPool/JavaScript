# lingo-guardian-cli

> 标签: accessibility, css, devtools, i18n, internationalization, lingo, lingo.dev, lint, localization, ltr, overflow, react, rtl, testing

## 简介

CLI tool to detect i18n layout issues - CSS overflows, RTL breaks, and text expansion problems. Powered by Lingo.dev
