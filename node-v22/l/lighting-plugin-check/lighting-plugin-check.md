# lighting-plugin-check

> 标签: JavaScript

## 简介

> lighting-plugin-check 会检查 light 工程的源代码目录下是否有非 ascii 字符的文件名以及是否有仅大小写不同的文件名并提示；开发者也可以在工程根目录下的次配置文件 check-rules.js 中增加自定义规则，插件会根据配置文件进行语法检查并生成代码检查报告，存储于根目录下的 report.csv 文件中。
