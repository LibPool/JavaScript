# lambder

> 标签: api, api-gateway, aws-lambda, dynamodb, framework, guards, i18n, idempotency, lambda, msw, rate-limit, rest, serverless, session, templating, type-safe, typescript, zod

## 简介

Opinionated serverless web framework for TypeScript on AWS Lambda: type-safe APIs from Zod schemas, DynamoDB sessions, and declarative rate limits, authorization guards and idempotency.
