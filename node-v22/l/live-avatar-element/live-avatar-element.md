# live-avatar-element

> 标签: angular, avatar, azure, custom-elements, react, voice-live, web-component, webrtc

## 简介

Framework-agnostic Web Component for Azure Voice Live interactive avatar assistant. Compatible with Angular, ASP.NET Core, .NET MAUI, React, Vue, and plain HTML.
