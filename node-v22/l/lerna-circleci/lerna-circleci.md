# lerna-circleci

> 标签: JavaScript

## 简介

Lets Lerna monorepos fully utilize CircleCI features like parallelism and splitting tasks by timings.

- npm 页面：https://www.npmjs.com/package/lerna-circleci

- npm registry：https://registry.npmjs.org/lerna-circleci
- Node 要求：>=12
