# live-leaderboard

> 标签: express, leaderboard, mongodb, mysql, postgres, real-time, redis, sdk, socket.io, typescript

## 简介

A plug-and-play real-time leaderboard SDK using Redis with Postgres/MySQL/MongoDB persistence and Socket.IO + Express integration.
