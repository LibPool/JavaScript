# liferay-commands

> 标签: JavaScript

## 简介

## Liferay Update Bundle 7.4 U(x) to 7.4 U(x+1) ### Liferay-cmd update --old [liferay bundle home] --new [liferay bundle home] Update liferay 7.4 bundle by moving the required modules and files from the old bundle to the new bundle.
