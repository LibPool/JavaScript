# lg.contextmenu

> 标签: JavaScript

## 简介

右键菜单，懒加载设计，需配合鼠标右键事件，当然其他事件也可以，之所以如此设计是考虑页面渲染性能问题，只有在需要显示菜单时才去做渲染处理
