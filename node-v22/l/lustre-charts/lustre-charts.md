# lustre-charts

> 标签: 3d, bar-chart, charts, dataviz, donut-chart, glassmorphism, metallic, neon, pie-chart, radial-chart, radial-progress, three, threejs, visualization, webgl

## 简介

Gorgeous, configurable 3D charts for the web — metallic, glass, neon and holographic looks built on Three.js. Few chart types, obsessive attention to how they look.
