> 标签: accessible, esm, gallery, image-gallery, image-lightbox, images, javascript-lightbox, js-lightbox, lightbox, lightweight, litelight, litelight-js, mobile-friendly, modal, no-jquery, photo-viewer, pinch-zoom, responsive, swipe, touch, typescript, vanilla-js, vanilla-js-lightbox, zero-dependencies

## 简介

Zero-dependency vanilla JS lightbox for image galleries — touch, swipe, pinch-zoom, keyboard nav, TypeScript. npm install litelight-js. Under 10KB.
