# libassimp-linux-x64-gnu

> 标签: 3d, 3mf, assimp, converter, fbx, glb, gltf, mesh, stl, usd, wasm, webassembly

## 简介

Assimp for TypeScript with native Node-API and WebAssembly backends: import 69 3D formats and export 15 formats.
