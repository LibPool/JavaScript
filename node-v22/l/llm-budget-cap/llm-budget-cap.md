# llm-budget-cap

> 标签: anthropic, atomic, budget, cost-control, gemini, ioredis, llm, lua, openai, rate-limit, rate-limiter, redis, spend-limit

## 简介

Atomic Redis spend/usage cap for LLM (OpenAI, Gemini, …) APIs — one Lua-atomic INCR+PEXPIRE so a bug or abuse can't blow up your bill.
