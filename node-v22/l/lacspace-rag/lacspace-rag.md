> 标签: ai, chat, cli, cosine-similarity, embeddings, keyless, llm, local-first, ollama, openai, rag, retrieval, semantic-search, typescript, vector-search, zero-dependency

## 简介

Keyless, local-first RAG in one CLI — index a folder of docs, then query and ask grounded questions. Ollama by default (100% free, no API key), OpenAI-compatible too. Zero dependencies.
