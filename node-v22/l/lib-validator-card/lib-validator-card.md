# lib-validator-card

> 标签: card, validator

## 简介

Biblioteca para implementar um validador de dados de cartões de crédito. A biblioteca deverá validar o número do cartão de crédito (usando algoritmo de Luhn) e retornar true ou false de acordo com o caso.
