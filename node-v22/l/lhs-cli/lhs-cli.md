# lhs-cli

> 标签: cli, frontend, tool, typescript, utility, vite, vue, webpack

## 简介

本项目为开发模板库，主要用于提供标准化的项目结构和开发脚手架，帮助开发者快速启动新项目。当前版本包含基于 Vite 和 Webpack 的 Vue 3 + TypeScript 项目模板。
