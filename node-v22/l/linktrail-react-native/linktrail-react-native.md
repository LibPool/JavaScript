# linktrail-react-native

> 标签: android, attribution, deep-linking, deferred-deep-linking, ios, linktrail, react-native, turbomodule

## 简介

React Native SDK for LinkTrail — mobile attribution and deferred deep linking. A New Architecture TurboModule wrapping the native LinkTrail iOS and Android SDKs.
