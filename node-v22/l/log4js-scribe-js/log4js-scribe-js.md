# log4js-scribe-js

> 标签: log4js, logging, scribe-js

## 简介

A custom appender for log4js capable of sending logs to a scribe js server

- npm registry：https://registry.npmjs.org/log4js-scribe-js
- Node 要求：>= 0.8
