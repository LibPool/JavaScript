# lukk-nuxt

> 标签: 2fa, auth, jwt, laravel, lukk, nuxt, nuxt-module, passkey

## 简介

Nuxt module for lukk (first-party Laravel JWT auth) + useLukkFetch, an auth-aware client for your own Laravel API — SSR / SPA / SSG, BFF or direct.
