# lanehash

> 标签: 64-bit, bloom-filter, cache-key, checksum, consistent-hashing, cyrb53, dedupe, fast-hash, fingerprint, fnv, hash, hash-function, hash-table, hashing, murmurhash, no-wasm, non-cryptographic, pure-javascript, sharding, streaming, string-hash, typescript, utf-16, xxhash, zero-dependencies

## 简介

A fast non-cryptographic 64-bit hash designed for JavaScript engines: pure 32-bit integer math (no BigInt, no WebAssembly), strings hashed straight from UTF-16 without encoding, byte-identical results for strings and their UTF-16LE bytes, streaming, seeds
