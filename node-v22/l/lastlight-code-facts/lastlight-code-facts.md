# lastlight-code-facts

> 标签: ast-grep, code-review, lastlight, static-analysis, typescript

## 简介

Deterministic program-analysis facts about a pull request — impact cone, contract delta, constants-minus-literals, dependency delta, scanner patterns and changed-line coverage. The substrate the Last Light reviewer reasons over.
