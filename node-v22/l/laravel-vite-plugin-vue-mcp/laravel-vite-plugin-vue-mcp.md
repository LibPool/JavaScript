# laravel-vite-plugin-vue-mcp

> 标签: inertia, laravel, mcp, modelcontextprotocol, vite, vite-plugin, vue

## 简介

MCP server for your Laravel + Vue app (component tree, state, routes and Pinia), auto-attached to your laravel-vite-plugin entry. Fork of vite-plugin-vue-mcp by Arlo (@webfansplz).
