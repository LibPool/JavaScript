# lyunet

> 标签: JavaScript

## 简介

代码中引入 lyu模块，提供基础内容，名字和端口即可   如：   ```TypeScript import lyu from "./framework/lyu"; lyu.start({     name: "test_a",     port: 8081, }) // 注册调用方法 lyu.on("testFunc", (param) => {     return param + " im test_a"; }) ```   启动另一进程   ```TypeScript
