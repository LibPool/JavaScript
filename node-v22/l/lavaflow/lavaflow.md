# lavaflow

> 标签: audio, caching, discord, lavalink, lavalink-v4, music, nodelink, playback-stats, queue-management, recommendations, rest-api, websocket

## 简介

Professional-grade Lavalink v4 & Nodelink client library for Node.js with TypeScript-first design. Multi-backend support, advanced queue management, playback stats, caching, and recommendations.
