# live-cursors

> 标签: broadcastchannel, collaboration, collaborative, cursor-presence, cursors, laravel-echo, live-cursors, multiplayer, presence, react, realtime, reverb, shared-cursors, vue, websocket

## 简介

Figma-style live multiplayer cursors for any web app: cursor presence over Laravel Echo, raw WebSocket, BroadcastChannel or your own channel. Zero dependencies, no SaaS. Vanilla, Vue and React bindings.
