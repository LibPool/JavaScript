# log-api-curl

> 标签: api, api-logger, curl, curl-command, curl-generator, debug, debugging, developer-tools, express, http, http-client, http-logger, log, logger, middleware, monitoring, network, nodejs, request, request-debugger, request-logger, request-tracker, utilities

## 简介

A lightweight utility for logging API requests with automatic cURL generation. Easily capture method, headers, body, params, and convert any HTTP request into a clean, ready-to-run cURL command for debugging or sharing
