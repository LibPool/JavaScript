# lovable-migrate

> 标签: cli, deploy, docker, dockerfile, github-actions, lovable, lovable.dev, migration, react, self-hosted, supabase, vite

## 简介

CLI migration engine for Lovable.dev projects — auto-detects stack, generates Dockerfile, GitHub Actions CI/CD, and remote deploy plan. Zero original-project modification.
