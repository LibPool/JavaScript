# linghub-local

> 标签: ai, coding-assistant, linghub, llm, local-agent, lsp, ollama

## 简介

LingHub Local Agent — connects your local environment (Ollama, sandbox) to LingHub via built-in WebSocket tunnel. No cloudflared required.

## 官网

- 官网：https://hub.linghub.dev/docs/local-agent
- 源码仓库：git+https://github.com/onsitechain/linghub-platform.git
- npm 页面：https://www.npmjs.com/package/linghub-local
