# localship

> 标签: agent-skills, ai, android, arb, claude-code, flutter, gettext, i18n, i18next, ios, l10n, localization, mcp, mcp-server, string-catalog, translation, xcstrings

## 简介

Translate your app with the AI you already use. An MCP server, agent skills and CLI that check every translation before it's written. Android, Apple String Catalogs, gettext, Flutter ARB and JSON.
