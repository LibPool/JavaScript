# langsys-js-react

> 标签: i18n, internationalization, l10n, langsys, language, localization, react, react-hooks, sdk, translation

## 简介

React binding for the Langsys translation SDK — realtime continuous translations with automatic token discovery, delivered as hooks and a <Translate> component.
