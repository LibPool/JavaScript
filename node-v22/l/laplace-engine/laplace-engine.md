# laplace-engine

> 标签: board-game, game-engine, laplace, laplacebench, llm-benchmark

## 简介

Frozen LAPLACE 8x8 rules engine (ruleset laplace-8x8-v1): the deterministic referee used by LaplaceBench. Package versions are immutable ruleset IDs.
