# llm-fingerprint

> 标签: ai-security, fingerprint, jsd, llm, model-audit, model-identification, openrouter

## 简介

Identify LLMs by behavioral fingerprint — send simple questions, match answer distributions against 176+ models using Jensen-Shannon Divergence (AUC 0.97)
