# lpc-spritesheet-mcp

> 标签: character-generator, game-assets, gamedev, liberated-pixel-cup, lpc, mcp, mcp-server, model-context-protocol, pixel-art, sprite, spritesheet

## 简介

MCP server that generates Universal LPC character spritesheets headlessly (no browser) from the LiberatedPixelCup asset pack: 657 items, 6 body types, palette recoloring, 15 standard animations plus oversize custom ones
