# llm-entropy-filter

> 标签: ai, content-moderation, entropy, guardrails, heuristics, input-validation, llm, openai, prompt-filter, spam-detection

## 简介

Fast entropy and intent gate for LLM inputs (ALLOW/WARN/BLOCK). Reduces hallucinations, cost and spam before calling an LLM.
