# log4-microservice

> 标签: bunyan, correlationid, logger, mdc, microservices, pino, preetylogs, winston

## 简介

A full packaged logger that supports structured logging with multiple adapters like pino, winston, bunyan. It has support for MDC (mapped domain context) and correlationIds.
