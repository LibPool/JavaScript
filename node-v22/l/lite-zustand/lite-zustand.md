# lite-zustand

> 标签: external store, global state, lightweight state, react, react state, react store, reactive, redux, selector, state management, subscribe, typescript, useSyncExternalStore, watch, zustand

## 简介

A tiny, type-safe React state manager built on useSyncExternalStore. Granular re-renders via selectors, reactive watchers with previous/next diffing, and direct get/set access outside components — no providers, no boilerplate, no overhead.
