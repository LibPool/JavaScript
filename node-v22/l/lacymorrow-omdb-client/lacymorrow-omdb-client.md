# lacymorrow-omdb-client

> 标签: api, client, omdbapi

## 简介

Temporary fork to fix downstream code. A node.js and browser client for the http://www.omdbapi.com API. The OMDb API is a free web service to obtain movie information, all content and images on the site are contributed and maintained by its users.
