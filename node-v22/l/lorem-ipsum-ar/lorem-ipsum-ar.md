# lorem-ipsum-ar

> 标签: JavaScript

## 简介

A small lorem-ipsum alike VSC extension that uses '@ahmedrowaihi/faker-ar' fork package under the hood, with few commands that generate and insert arabic lorem ipsum alike text.
