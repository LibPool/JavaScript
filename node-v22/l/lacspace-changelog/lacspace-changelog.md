# lacspace-changelog

> 标签: automation, breaking-changes, changelog, changelog-generator, changelogrc, ci, cli, commit-config, commit-parser, compare-links, contributors, conventional-commits, git, git-log, issue-links, keep-a-changelog, monorepo, prerelease, release, release-notes, release-please, semver, semver-bump, standard-version, typescript, version-bump, zero-dependency

## 简介

Turn Conventional Commits into a grouped CHANGELOG.md, compute the next semver bump and print release notes — keyless and local. Zero dependencies.
