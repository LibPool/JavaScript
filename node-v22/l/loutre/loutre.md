# loutre

> 标签: api, bruno, cli, fake-data, insomnia, mock, openapi, postman, swagger

## 简介

Loutre in your terminal: serve an OpenAPI, Swagger, TypeScript, Postman, Insomnia or Bruno description as a mock API with realistic data, or push it to loutre.run.
