## 简介

1. 注册npm账号 2. 将源切换至npm (用过nrm 切换到taobao源的 需要进行这个步骤) 3. 初始化项目 `$ npm init -y` 4. 创建入口文件 5. 开发 6. 登陆npm账号  `$ npm adduser` 7. 发布项目     `$ npm publish`
