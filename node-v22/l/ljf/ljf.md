# ljf

> 标签: JavaScript

## 简介

- 安装全局依赖 ``` pnpm i typescript -w ``` --- - 安装局部依赖 ``` pnpm add vite --filter @ljf/client ``` --- - 安装项目内依赖 ``` pnpm add @ljf/base@* --filter @ljf/client ``` --- - 执行某个子包的命令 ``` pnpm -F server dev ```
