# lily-design-system-angular-locale-picker

> 标签: angular, design, lily, locale, picker, system

## 简介

Lily Design System Angular 20 locale picker: an icon button opening an APG listbox that sets lang and dir on the document. Headless, SSR-safe, no CSS.
