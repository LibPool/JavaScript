# lancast

> 标签: cli-tool, file-sharing, lan, local-network, nodejs, p2p, peer-to-peer, shareit-alternative, socket.io, webrtc, wifi-file-transfer, xender-alternative

## 简介

LanCast is a LAN-based peer-to-peer file sharing CLI tool. Instantly share files between devices on the same WiFi network with zero configuration.
