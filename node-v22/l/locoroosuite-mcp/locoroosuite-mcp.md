# locoroosuite-mcp

> 标签: agent, ai, assistant, automation, caldav, calendar, carddav, contacts, email, imap, locoroosuite, mcp, model-context-protocol, personal-assistant, self-hosted, webmail

## 简介

MCP server for LocoRooSuite — lets any AI agent (coding assistants, personal assistants, local LLM UIs, automation tools) access your mail, contacts, calendar, and documents via the Model Context Protocol.
