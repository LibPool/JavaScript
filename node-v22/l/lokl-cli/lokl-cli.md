# lokl-cli

> 标签: cli, go, reverse-proxy, tunnel, websocket

## 简介

a lightweight tunnel service that lets you expose your local web server to the internet through a public-facing Go server. It works similarly to services like ngrok but is built with Go and WebSockets.
