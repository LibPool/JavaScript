# load-remote

> 标签: css, inject to html, js, load, remote, script

## 简介

在 web 项目中引用载入远程资源（css, js），基于<link>/<script>标签实现。Used to load remote resources(CSS/JS) in a web project , based on the html tag(<link>/<script>).
