# lambdalith

> 标签: aws, dynamodb, eventbridge, events, lambda, router, serverless, sns, sqs

## 简介

A tiny event router for AWS Lambda functions. Route SQS, SNS, EventBridge, and DynamoDB Streams events with a fluent API.
