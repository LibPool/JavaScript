# lema-mcp

> 标签: adr, agent, ai, architecture-decision-records, claude, claude-code, context, cursor, decisions, documentation, kubernetes, mcp, model-context-protocol, react, rfc, rust

## 简介

MCP server that gives your coding agent the recorded why behind decisions — and what was already ruled out — cited. Check React, Rust, and Kubernetes out of the box, or capture and enforce never-reopen on your own repo. Local, no account.
