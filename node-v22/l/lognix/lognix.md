# lognix

> 标签: crash-handler, dashboard, express, express-logger, file-logger, http-logging, json-logger, log-analytics, log-rotation, log-shipping, log-viewer, logger, logging, middleware, monitoring, node, nodejs, observability, remote-logging, request-logging, structured-logging, typescript

## 简介

Zero-dependency Node.js logger with a built-in real-time observability dashboard, Express HTTP request/response capture, batched remote shipping with on-disk fallback, archive viewer, and time-limited sharing tokens.
