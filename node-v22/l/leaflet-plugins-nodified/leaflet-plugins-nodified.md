# leaflet-plugins-nodified

> 标签: bing, google, gpx, kml, leaflet, map, plugins, yandex

## 简介

This is a fork of https://github.com/shramov/leaflet-plugins and corresponds to v1.4.2. Miscellaneous plugins for Leaflet library for services that need to display route information and need satellite imagery from different providers
