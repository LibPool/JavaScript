# look-at-deepseek

> 标签: mcp, model-context-protocol, multimodal, ocr, stdio, streamable-http, vision

## 简介

Lightweight multi-channel MCP server for vision understanding and OCR. Integrates multi-provider failover, transient retry, and clarity-first image compression. stdio + Streamable HTTP transports.
