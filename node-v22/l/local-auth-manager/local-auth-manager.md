# local-auth-manager

> 标签: JavaScript

## 简介

**LocalAuthManager** - это библиотека для управления аутентификацией в клиентской части приложения. Она предоставляет простой интерфейс для работы с локальной сессией пользователя, включая хранение токенов, их валидацию и базовые операции входа и выхода и
