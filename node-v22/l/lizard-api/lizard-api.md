# lizard-api

> 标签: api, mongo, mongodb, mysql, nodejs, rest, restful

## 简介

This API is a starting point Node JS API based on express. It uses [turtle-orm](https://github.com/jgbernalp/turtle-orm) to handle  Mongo and Mysql databases.
