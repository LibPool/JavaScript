# llm-switchboard

> 标签: agentic-workflows, ai-gateway, ai-router, classification, claude, cost-optimization, deepseek, gemini, latency-optimization, llama, llm, llm-router, model-orchestration, nlp, openai, prompt-engineering, prompt-routing, serverless-ai, switchboard, typescript

## 简介

Blazing-fast, zero-cost local LLM router. Classify and route prompts to specialized AI models (OpenAI, Claude, Gemini, Llama) with <1ms latency using heuristic rules.
