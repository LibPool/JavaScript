# linkknil-dsh-model-balance

> 标签: JavaScript

## 简介

DSH 模型账户余额悬浮窗：右下角常驻的可拖拽小徽章实时显示 DeepSeek 账户余额，点击展开详情（各币种总额 / 赠送 / 充值、账户可用状态、更新时间），自动刷新。Host 侧经 /api/dsh-model-balance 读取 ~/.dsh/.credentials.yaml 中的 DEEPSEEK_API_KEY 调用官方余额接口。
