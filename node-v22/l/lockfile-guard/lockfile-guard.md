# lockfile-guard

> 标签: ci, dependabot, dependency-review, github-action, install-script, lockfile, npm-audit, package-lock, pnpm-lock, postinstall, provenance, sarif, security, supply-chain

## 简介

Diff two lockfiles in a PR and report supply-chain risk: new install scripts, a changed publisher, versions published minutes ago, resolutions pointing at another registry, obscure new transitive dependencies.
