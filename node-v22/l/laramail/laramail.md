# laramail

> 标签: email, email-testing, fake-mailer, laramail, laravel, mail, mail-testing, mailable, mailer, mailgun, markdown, nodemailer-mock, notification, postmark, queue, resend, sendgrid, ses, smtp, template, test-email, typescript

## 简介

Laravel-style mailer for Node.js — Mail.fake() + Mail.assertSent() for zero-setup email testing, provider switching via env var, works with Express/Fastify/any framework.
