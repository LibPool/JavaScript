# libreyolo-web

> 标签: computer-vision, libreyolo, machine-learning, object-detection, onnxruntime, rfdetr, wasm, webgpu, yolo, yolov8, yolov9, yolox

## 简介

Object detection in the browser. 100% MIT Licensed. Supports YOLOX, YOLO9, RF-DETR, and YOLOv8/v11/v26 via ONNX Runtime (WebGPU + WASM).
