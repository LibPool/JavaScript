# leitweg-id

> 标签: e-rechnung, glaeubiger-id, leitweg, leitweg-id, peppol, sepa, ust-idnr, validation, wirtschafts-identifikationsnummer, xrechnung, zugferd

## 简介

Validate, parse and build Leitweg-IDs for XRechnung, plus the other German e-invoice party IDs: USt-IdNr, W-IdNr and SEPA Gläubiger-ID. Zero dependencies.
