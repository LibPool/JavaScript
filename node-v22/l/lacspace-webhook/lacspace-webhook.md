# lacspace-webhook

> 标签: cli, curl, github-webhook, hmac, http, localhost, shopify-webhook, signature-verification, slack-webhook, sse, stripe-webhook, svix, typescript, webhook, webhook-inspector, webhook-mock, webhook-receiver, webhook-replay, webhook-testing

## 简介

A local webhook receiver, inspector and replayer — capture incoming webhooks in a live web dashboard, verify GitHub/Stripe/Shopify/Slack/Svix/HMAC signatures (with auto-detect), mock responses with rules, fan-out forward to localhost, export/import as cur
