# luna-orbit

> 标签: ai-testing, appium, autonomous-testing, e2e, luna-orbit, playwright, regression-testing, self-healing

## 简介

Luna Orbit — AI-powered autonomous regression testing SDK. Drop into any web app (Playwright) or mobile app (Appium). Describe flows in plain English, the agent drives a real browser/device, self-heals, screenshots, and reports.
