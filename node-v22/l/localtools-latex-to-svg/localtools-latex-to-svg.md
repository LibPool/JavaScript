# localtools-latex-to-svg

> 标签: JavaScript

## 简介

Render LaTeX, MathML or AsciiMath to SVG, PNG and MathML with speech text, offline with MathJax (localtools)

- 官网：https://github.com/chayprabs/localtools#readme
- 源码仓库：git+https://github.com/chayprabs/localtools.git
