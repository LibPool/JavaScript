# limbic

> 标签: agent, diversity, embeddings, gist, llm, local-first, memory, ollama, retrieval

## 简介

Local-first, emotion-aware, LLM-agnostic memory engine for TypeScript — scoring, decay and GIST diversity retrieval with zero required dependencies.
