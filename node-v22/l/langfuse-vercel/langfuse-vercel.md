# langfuse-vercel

> 标签: ai-sdk, deprecated, langfuse, legacy, llm, observability, vercel

## 简介

LEGACY Langfuse v3 integration for Vercel AI SDK (maintenance mode). For new projects use @langfuse/otel with the AI SDK's experimental_telemetry: npm install @langfuse/otel @langfuse/tracing
