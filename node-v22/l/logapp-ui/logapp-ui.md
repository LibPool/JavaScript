# logapp-ui

> 标签: cli, developer-tools, grafana, live-tail, log-explorer, log-viewer, logs, observability, pino, sse, tail, zero-dependencies

## 简介

Live log viewer with a Grafana-style browser UI for any local server. Pipe a process into it and watch live logs at localhost:9999.
