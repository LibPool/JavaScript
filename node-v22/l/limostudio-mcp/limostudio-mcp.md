# limostudio-mcp

> 标签: ai-agent, claude, cursor, limostudio, mcp, mcp-server, model-context-protocol, video-editor

## 简介

LimoStudio for your AI app: an MCP server that lets Claude Code, Claude Desktop, Cursor, VS Code and other MCP apps edit video and audio projects in a LimoStudio window you can watch.
