# lv-tools

> 标签: 函数库

## 简介

lv_tool(工具中的LV)是一个前端的工具包，使前端开发如鱼得水，它具有以下的特点: - 装笔性：有利于向他人展示代码的美好🐶 - 不严谨性: 作者能力有限，水平还在提升中🆙 - 不负责任性：想用的话，自己看着办吧👀...
