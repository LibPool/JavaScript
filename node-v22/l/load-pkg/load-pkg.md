# load-pkg

> 标签: config, dir, directory, file, find, find-up, findup, findup-sync, folder, json, load, look, look-up, match, package, package-json, parent, parents, parse, path, pkg, read, resolve, search, up, walk, walking

## 简介

Loads package.json, by finding the first directory with a package.json, recursing up, starting with the given directory.
