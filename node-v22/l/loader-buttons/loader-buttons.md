# loader-buttons

> 标签: animation, button, canvas, loader, loading, react, spinner, svg, ui, webgl

## 简介

25 original loading button animations built with WebGL, Canvas, SVG and CSS — headless loaders, a styled button, and a React component. Zero runtime dependencies.
