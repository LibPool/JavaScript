# lipsync-sdk

> 标签: afan, arkit, avatar, blendshape, lipsync, oculus, talkinghead, tts, viseme, vrm

## 简介

Fast text-driven lipsync codec — Oculus viseme word→blendshape conversion (TalkingHead-derived) plus ARKit mapping and AFAN binary streaming for downstream tools
