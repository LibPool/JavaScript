# logisheets-engine

> 标签: canvas, data-grid, excel, formula, spreadsheet, spreadsheet-component, svelte, wasm, webworker, xlsx

## 简介

Embeddable spreadsheet UI component for LogiSheets — an Excel-like, canvas-rendered data grid with formulas and .xlsx (Excel) import/export, powered by a Rust + WebAssembly engine in a Web Worker.
