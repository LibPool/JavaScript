# local-dev-mcp

> 标签: ai-agent, code-safety, developer-tools, lm-studio, local-llm, mcp, model-context-protocol, omlx

## 简介

Local-first MCP server that offloads code safety, boilerplate generation, dependency evaluation, project indexing, and task delegation to local LLMs via oMLX or LM Studio.
