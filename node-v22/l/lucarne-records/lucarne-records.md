# lucarne-records

> 标签: provenance, records, schema, store

## 简介

The general capture-corpus record language: a domain-agnostic CorpusRecord schema (open source/kind, opaque top-level domain fields), cursor/Page<T> helpers, and a pure node:fs record store + query API. Dependency-free, no network. Social/X-specific schem
