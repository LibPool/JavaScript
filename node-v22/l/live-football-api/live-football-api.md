# live-football-api

> 标签: football, football-api, live-football-api, live-scores, soccer, soccer-api, sports-api

## 简介

Official Node.js client for the Live Football API (live-football-api.com) - real-time scores, lineups, standings, H2H, injuries and goal webhooks.

## 官网

- 官网：https://live-football-api.com
- 源码仓库：git+https://github.com/gaffarkorkmaz/live-football-api-js.git
- npm 页面：https://www.npmjs.com/package/live-football-api
