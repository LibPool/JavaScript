# lawang

> 标签: cli, developer-tools, lawang, local-first, mobile-shell, qr, remote, self-hosted, shell, ssh-alternative, terminal

## 简介

Local-first remote terminal with QR pairing. Run a single command, scan a QR, get a browser/mobile shell — host approval mandatory.
