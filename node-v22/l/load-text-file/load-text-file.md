# load-text-file

> 标签: file, fs, graceful, load, parse, read, text

## 简介

[Strips UTF-8 BOM](https://github.com/sindresorhus/strip-bom), uses [`graceful-fs`](https://github.com/isaacs/node-graceful-fs), and returns Promises.
