# local-agent-memory

> 标签: JavaScript

## 简介

**local-agent-memory** es una herramienta de indexación de memoria para agentes de IA que opera localmente en tus repositorios. Permite sincronizar documentos Markdown, llevar un registro de sesiones de codificación y exponer toda esta información a asist
