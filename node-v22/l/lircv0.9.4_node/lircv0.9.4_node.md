# lircv0.9.4_node

> 标签: lirc

## 简介

Control LIRCv0.9.4 and up from Node, forked from lirc_node. irsend list's output format changed, breaking the original lirc_node. This is a quick and dirty fix, breaking compatibility with previous versions of LIRC.
