# lodash-miniprogram-polyfill

> 标签: lodash, lodash-es, miniprogram, polyfill

## 简介

小程序的lodash polyfill,需在lodash或lodash-es前导入,也可用于支持npm构建的其他小程序框架(uniapp,taro)

## 官网

- npm 页面：https://www.npmjs.com/package/lodash-miniprogram-polyfill
