# loomis

> 标签: ai, bmad, design-to-code, mcp, offline, prototype, stitch, ui

## 简介

Loomis - the UI Weaver: turns BMAD docs (DESIGN.md + EXPERIENCE.md + stories) into a runnable, connected, fully-offline HTML prototype via an AI-UI provider (Stitch), with an interactive studio.
