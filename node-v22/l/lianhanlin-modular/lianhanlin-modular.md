# lianhanlin-modular

> 标签: architecture, dag, dependency-injection, di, fullstack, hono, ioc, mesh, modular, path-ioc, topological-sort, type-safe, typescript, vite, vite-plugin, webpack, webpack-plugin, zero-boilerplate

## 简介

文件路径即依赖网格 (Mesh)，零装配、零反射的轻量 TypeScript 全栈 Path-IoC 模块引擎。内置 Vite 与 Webpack 官方插件，支持 DAG 拓扑排序、80% CPU 提速静态图预编译与 100% 类型自动生成。
