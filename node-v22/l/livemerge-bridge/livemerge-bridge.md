# livemerge-bridge

> 标签: agent, ai, claude, cli, codex, daemon, ed25519, intent-driven, livemerge

## 简介

Local daemon that pairs your machine with the LiveMerge web app to receive Ed25519-signed task dispatches and run them via your local Claude Code or Codex CLI.

- 官网：https://livemerge.dev
