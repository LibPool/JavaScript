# linkedin-relay-mcp

> 标签: agent, claude, claude-code, cli, linkedin, mcp, model-context-protocol, research, scraper, voyager

## 简介

Deep research over LinkedIn from your own account — CLI (lnrelay) + read-only MCP server + Claude Code skill. No paid API. Reads LinkedIn's private Voyager surface with your own session cookies.
