# llm-stream-guard

> 标签: agent, llm, pii, proxy, redact, secrets, security, sse, stream, tool-calling, transformstream, typescript

## 简介

Zero-dependency TypeScript security filter for LLM streams — redact secrets, enforce tool policy, byte and event modes.
