# rodiumai-mcp

> 标签: ai, api-gateway, claude, cursor, image-generation, mcp, model-context-protocol, rodiumai, text-to-speech, transcription

## 简介

MCP server for the RodiumAI API: images, speech, transcription, embeddings, chat, model catalogue and docs, from any MCP client with your rd_sk_ key.
