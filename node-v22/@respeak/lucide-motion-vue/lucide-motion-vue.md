# @respeak/lucide-motion-vue

> 标签: JavaScript

## 简介

546 Lucide icons / 838 named animations for Vue 3 — ergonomic animateOnHover/Tap/View triggers, a composable <AnimateIcon> wrapper, and a Nuxt module. Tree-shakable, SSR-safe.
