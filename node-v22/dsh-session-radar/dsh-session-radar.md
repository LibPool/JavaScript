# dsh-session-radar

> 标签: badge, counts, deepseek, deepseek-harness, dsh, dsh-plugin, jump, ledger, overview, pending, recovery, restart, retry, session-radar, session-status, shortcuts, sidebar, status, unread

## 简介

DSH Web 侧边栏助手：⌘⇧K 弹出未读与待决策总览，⌘⇧J / ⌘⇧I 顺序定位未读与等待处理，⌘⇧, / ⌘⇧. 在访问过的对话之间前后切换；底部六项会话状态读数（运行中 / 未读 / 待处理 / 闲置 / 未归档 / 已归档）每个图标可点，点了跳到下一个同类会话；host 半边的跨重启会话账本——上次中途退出的会话重启后依然未读，账本未读也画在会话行上，启动时还会弹一次续跑清单。
