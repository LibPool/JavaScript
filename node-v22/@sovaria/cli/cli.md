# @sovaria/cli

> 标签: baas, backend, cli, database, functions, mcp, postgres, sov, sovaria

## 简介

The Sovaria command-line interface (sov): log in, link a project, run SQL and migrations, deploy functions, manage auth, storage, realtime and more. Needs Python 3.11+.
