# @boole/boole

> 标签: ai, edge-ai, gguf, inference, llama.cpp, llm, local-first, local-llm, machine-learning, nodejs, offline-ai, on-device, sandbox, sdk, self-hosted, serverless-alternative, text-generation, typescript

## 简介

Local-first LLM inference SDK for JavaScript & TypeScript. Run GGUF models on your own hardware via llama.cpp, with an App/Function/Sandbox API and a 10x cost cut over always-remote inference.
