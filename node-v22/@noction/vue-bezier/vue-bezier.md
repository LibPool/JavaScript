# @noction/vue-bezier

> 标签: animations, bezier, blur, clip-path, composition-api, css-transitions, dissolve, fade, list-transitions, push, rotate, scale, sfc, slide, transition-group, transitions, vue, vue-components, vue-transitions, vue3, wipe, zoom

## 简介

A Vue 3 component library with customizable CSS-based transition components featuring Bezier timing functions. Includes fade, dissolve, blur, scale, slide, push, wipe, rotate, zoom, and clip-path transitions.
