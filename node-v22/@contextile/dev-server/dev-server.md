# @contextile/dev-server

> 标签: JavaScript

## 简介

Local all-in-one Contextile runtime: page config store, content-addressed asset pipeline, per-component function runtime, simulator, and HTTP facade.

- 官网：https://contextile.dev
- 源码仓库：git+https://github.com/contextile/contextile.git
