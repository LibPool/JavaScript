# @openpets/ticketmaster

> 标签: concerts, events, opencode, plugin, sports, ticketmaster, tickets

## 简介

Search for events, attractions, venues, and classifications using the Ticketmaster Discovery API. Find concerts, sports, arts, and more with powerful filtering by location, date, genre, and more.
