# @securegroupchat/web-sdk

> 标签: chat, e2ee, encrypted-chat, end-to-end-encryption, libsignal, messaging, realtime, signal-protocol

## 简介

TypeScript SDK for Ease. End-to-end-encrypted DMs, group messages, presence, contacts. Browser + Node 20+, TypeScript declarations included, libsignal-wasm bundled inside the package.
