# @kb-skills/adapter-openapi

> 标签: adapter, api-contract, kb-skills, node, openapi, swagger

## 简介

OpenAPI / Swagger spec adapter for kb-skills. Parses openapi.json / swagger.yaml and injects full API contract (request body, response schema, parameters) into the KB.

- npm 页面：https://www.npmjs.com/package/@kb-skills/adapter-openapi
