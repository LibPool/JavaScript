# @t09tanaka/test-gates

> 标签: cli, coverage, jest, lcov, mutation-testing, quality-gate, stryker, test, vitest

## 简介

Test gates for the code that must not be wrong: per-file 100% coverage as the floor, mutation testing with a per-mutant allow list as the real check.
