# @zerodds/node

> 标签: dds, deterministic, ffi, iot, omg-dds, pub-sub, publish-subscribe, realtime, robotics, rtps, xcdr2, zero-copy

## 简介

ZeroDDS TypeScript binding for Node.js (via koffi FFI over zerodds.h). Native RTPS 2.5, XCDR2, DDS 1.4 QoS.
