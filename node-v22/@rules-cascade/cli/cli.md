# @rules-cascade/cli

> 标签: ai-agents, business-rules, cli, decision-engine, mcp, rcas, rule-cascade, rules-cascade, rules-engine, validation

## 简介

The rcas command: check, test and evaluate Rule Cascade rulesets, and serve them to AI agents over MCP. Installs the prebuilt binary for this platform. Run it with npx -y @rules-cascade/cli <command>.
