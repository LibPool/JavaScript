# @looping-gg/mcp

> 标签: claude-code, codex, game-hosting, looping, mcp, model-context-protocol, threejs, unity-webgl

## 简介

Looping MCP: the stdio server that lets Claude Code, Codex and other MCP clients deploy web games (Three.js, Unity Web, any web build) to Looping, plus a CLI that checks a build and uploads one with a ticket.
