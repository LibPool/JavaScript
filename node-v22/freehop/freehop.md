# freehop

> 标签: games, nat-pmp, nat-traversal, p2p, pcp, peer-to-peer, sdk, signalling, stun, turn, upnp, video-chat, voice-chat, webrtc

## 简介

Open-source peer-to-peer voice, video and data SDK for browser and desktop apps, with signalling gates and session-member media gateways.
