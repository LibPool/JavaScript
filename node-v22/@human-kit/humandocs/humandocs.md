# @human-kit/humandocs

> 标签: docs, documentation, fumadocs, shiki, svelte, sveltekit

## 简介

A documentation kit for Svelte and SvelteKit — docs shell components, live demos with source, generated API reference tables, and a shiki dual-theme preset.
