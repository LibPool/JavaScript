# @nor-data/udir-mcp

> 标签: barnehage, education, kindergarten, mcp, model-context-protocol, nbr, norge, norway, nsr, school, skole, udir

## 简介

MCP server exposing Norway's national school (NSR) and kindergarten (NBR) registries from UDIR — search by municipality and fetch full detail with coordinates, pupil counts and ownership.
