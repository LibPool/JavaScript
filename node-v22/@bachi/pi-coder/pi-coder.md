# @bachi/pi-coder

> 标签: agent, coding-agent, extensions, pi, pi-coding-agent, pi-extension, pi-package, statusline, terminal, theme, themes, tui

## 简介

A complete Pi coding-agent environment: 37 TUI extensions, 5 themes, a theme-authoring skill and the global config files that make them work together.
