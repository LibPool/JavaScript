# dsh-code-workbench

> 标签: code-completion, deepseek-harness, dsh, dsh-plugin, editor, fim, monaco, typescript, workspace

## 简介

Code Workbench for the DSH Web GUI: Monaco (the VS Code editor core) over workspace files in the right sidebar, with a version-guarded save path. TypeScript source.
