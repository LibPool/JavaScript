# @canonical/terrazzo-plugin-css

> 标签: JavaScript

## 简介

Terrazzo CSS plugin for Canonical design tokens. Transforms DTCG tokens into CSS custom properties with light-dark(), modifier families, @layer ordering, and @media scoping.
