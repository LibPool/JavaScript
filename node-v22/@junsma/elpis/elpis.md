# @junsma/elpis

> 标签: JavaScript

## 简介

> 一个基于 **Vue 3 + Koa.js** 的企业级全栈应用框架（包名 `@junsma/elpis`）。核心思路是：**用一份 JSON Schema 描述业务，前端自动渲染出表格 / 搜索栏 / 表单 / 详情面板，后端按目录约定自动挂载接口**——即 DSL 驱动的低代码开发范式。
