# dsh-subagent-toggle

> 标签: agent-teams, deepseek-harness, dsh, dsh-plugin, settings, subagent, toggle

## 简介

DSH plugin: a Settings switch that disables the subagent tool family (subagent/subagent_fork/workflow/ralph/list_subagent_models/send_message) and tells the model to use Agent Teams instead.
