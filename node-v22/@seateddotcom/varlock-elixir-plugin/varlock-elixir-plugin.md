# @seateddotcom/varlock-elixir-plugin

> 标签: .env, codegen, elixir, env, environment variables, varlock, varlock-plugin

## 简介

Varlock plugin that adds @generateElixirEnv: a typed, coerced Elixir env module generated from your .env.schema
