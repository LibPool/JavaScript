# @uzmaps/engine

> 标签: 3d, gl, map, maplibre, routing, uzbekistan, uzmaps, vector-tiles

## 简介

UzMap JavaScript map engine — an interactive MapLibre GL map of Uzbekistan with 3D, terrain, routing and place search.
