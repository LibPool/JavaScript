# @spinal/underscore

> 标签: browser, client, functional, server, util

## 简介

Spinal uses [Backbone](https://backbonejs.org/) which uses [Underscore](https://underscorejs.org/). For our purposes we want/need our own release that does not rely on anything external and has things as we need.
