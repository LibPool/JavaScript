# sanity-plugin-maplibre

> 标签: geocoding, geopoint, maplibre, maplibre-gl, maps, nominatim, openfreemap, openstreetmap, photon, sanity, sanity-plugin, sanity-studio

## 简介

Keyless, open-source map inputs for Sanity Studio, built on MapLibre, OpenFreeMap and OpenStreetMap geocoding. A drop-in replacement for @sanity/google-maps-input.
