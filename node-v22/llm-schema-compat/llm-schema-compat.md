# llm-schema-compat

> 标签: anthropic, claude, function-calling, gemini, json-schema, llm, mcp, openai, strict-mode, structured-outputs, tool-calling, zod

## 简介

Make any JSON Schema (Zod, Pydantic, MCP tools, OpenAPI) work with OpenAI strict mode, Anthropic structured outputs and Gemini, and decode the model's output back to your original shape. Zero dependencies.
