# @steveapo/pier

> 标签: cli, dashboard, dev-server, developer-tools, ink, localhost, macos, nextjs, process-manager, tui, vite

## 简介

TUI dashboard for local dev servers — auto-discovers, stops, restarts, tails logs, captures errors, auto-stops idle servers.
