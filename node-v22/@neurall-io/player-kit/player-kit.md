# @neurall-io/player-kit

> 标签: JavaScript

## 简介

The runtime @neurall-io/player loads to draw a Neurall video: the reel kit, Remotion's Player and React built into one script. Served by jsDelivr, fetched by the loader at runtime. Not a library: nothing here is meant to be installed or imported.
