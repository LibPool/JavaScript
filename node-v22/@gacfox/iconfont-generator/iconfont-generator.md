# @gacfox/iconfont-generator

> 标签: eot, font, generator, icon, iconfont, svg, ttf, woff, woff2

## 简介

A tool that converts SVG icons into web font formats (TTF, WOFF, WOFF2, EOT) and generates CSS/HTML preview files.
