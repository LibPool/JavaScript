# workbuddy-bridge

> 标签: ai-coding, anthropic, bridge, claude-code, codebuddy, codex, llm, mcp, openai, openai-compatible, proxy, workbuddy, workbuddy-ai

## 简介

Use a WorkBuddy desktop account (international workbuddy.ai and/or China workbuddy.cn) as an OpenAI- and Anthropic-compatible API — a local model provider for Claude Code, Codex, and any coding agent.
