# dsh-session-bus

> 标签: cordis, deepseek-harness, dsh, messaging, plugin, session

## 简介

会话之间互相推送消息并自动唤醒对方：同一工作区或跨工作区都能直接派活，省掉手动暂停会话、复制、切过去粘贴的来回操作。
