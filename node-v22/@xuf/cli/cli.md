# @xuf/cli

> 标签: react18, swc, typescript5, vite, webpack5

## 简介

XUF CLI 是一个前端项目构建工具，内置 Webpack / Vite 构建能力，支持 React、TypeScript、Babel、SWC、开发服务、生产构建和 lib 打包。
