# @kkdev92/tisilia-runtime

> 标签: aspnetcore, client, codec, decimal, int64, json, lossless-json, tisilia, typescript

## 简介

The runtime of the TypeScript clients Tisilia generates from an ASP.NET Core API: a lossless JSON parser, exact codecs for the .NET values a JavaScript number cannot hold, and an HTTP pipeline that names every failure instead of throwing.
