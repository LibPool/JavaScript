# @lichen-ai/plugin-model-retry

> 标签: JavaScript

## 简介

`@lichen-ai/plugin-model-retry` adds retry logic around Xpert agent model calls. It keeps LangChain-style retry semantics while exposing only JSON-serializable configuration that can be edited in the Xpert middleware UI.
