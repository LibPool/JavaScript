# @guildex.net/adapter-claude-code

> 标签: JavaScript

## 简介

DAP -> Claude Code subagent compiler. Turns a DAP YAML doc into a non-invasive install bundle (a single guildex-<id>.md subagent file) for Anthropic Claude Code (~/.claude/agents/).
