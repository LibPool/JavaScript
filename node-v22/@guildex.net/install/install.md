# @guildex.net/install

> 标签: JavaScript

## 简介

Guildex install CLI. Compiles a DAP worker for a target runtime (OpenClaw, Claude Code) and installs it into the user's local target non-invasively. Run via `npx @guildex.net/install <id> --target <name>`.
