# @guildex.net/dap

> 标签: JavaScript

## 简介

Digital Agent Protocol (DAP) — shared schema, types, loader, validator. Used by every Guildex adapter (openclaw, claude-code, ...) so DAP spec changes patch in one place. Spec lives at /dap/spec.md.
