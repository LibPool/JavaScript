# @webartisanbros/directus-extension-o2m-tree-view

> 标签: directus, directus-extension, directus-extension-interface, o2m, one to many, treee-view

## 简介

A Directus extension that provides a tree view (Interface) for one-to-many relationships like the one used by Notion.
