# jodit-plugin-mailto

> 标签: editor, email, jodit, jodit-plugin, link, mailto, wysiwyg

## 简介

Jodit editor plugin that inserts email links (mailto:) with To, Cc, Bcc, Subject and Body fields, validation and editing of existing links
