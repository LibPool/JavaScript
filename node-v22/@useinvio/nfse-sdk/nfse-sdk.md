# @useinvio/nfse-sdk

> 标签: brazil, dps, erp, mtls, nfs-e, nfs-e-nacional, nfse, nota-fiscal, nota-fiscal-servico, sefin, sped, typescript, xml-dsig, xmldsig

## 简介

TypeScript SDK for Brazil's national NFS-e: JSON to DPS/XML, XMLDSIG, GZip/Base64, mTLS and SEFIN errors.
