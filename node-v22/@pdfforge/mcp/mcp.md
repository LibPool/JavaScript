# @pdfforge/mcp

> 标签: ai, claude, cursor, html-to-pdf, mcp, model-context-protocol, pdf, pdf-generation, pdfforge

## 简介

Model Context Protocol server for pdfforge — let AI agents (Claude, Cursor) generate pixel-perfect PDFs from HTML or stored templates.
