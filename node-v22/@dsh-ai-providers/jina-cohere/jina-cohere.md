# @dsh-ai-providers/jina-cohere

> 标签: cohere, deepseek-harness, dsh, jina, reranking

## 简介

DSH plugin that supplies reranking from any Jina- or Cohere-style /rerank API (Jina, Cohere, LocalAI, vLLM...), to dsh-ai-providers.
