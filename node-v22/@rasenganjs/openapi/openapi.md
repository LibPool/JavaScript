# @rasenganjs/openapi

> 标签: JavaScript

## 简介

OpenAPI 3.1 generation + Scalar/Swagger docs UI. Futon-native core (@rasenganjs/openapi/futon), no DI/Module required, with a thin Rasengan Server adapter (@rasenganjs/openapi/server) — OpenApiModule.forRoot() + DI-injected OpenApiRegistry — built on top
