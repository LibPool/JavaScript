# @paradoxcomputer/medusa-connect

> 标签: basecamp, connect, dapp, logos, medusa, privacy, sdk, wallet, wallet-connect

## 简介

Connect with Medusa - dApp SDK for the Medusa privacy wallet on Logos Basecamp. Request a wallet connection and submit transfers / shields / deshields through the user's wallet, with per-action approval in the wallet UI.
