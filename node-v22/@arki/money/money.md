# @arki/money

> 标签: allocate, arki, bigint, currency, decimal, exchange, finance, iso4217, monetary, money, parse, price, rounding, stripe, typescript

## 简介

Exact, fast money for every JavaScript runtime — amounts kept as whole units (plain numbers, bigint only when huge), a shipped ISO 4217 currency table, exact-or-throw rounding, fair allocation, and currencies checked by the type system.
