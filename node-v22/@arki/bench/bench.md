# @arki/bench

> 标签: arki, bench, benchmark, bundle-size, ci, mitata, performance, regression, statistics, typescript

## 简介

Benchmarks you can publish: compare a library against its competitors under executable contracts, with honest statistics, full provenance, bundle-size budgets and README tables generated from saved results. Built on mitata.
