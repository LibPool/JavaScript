# deep-roon-mcp

> 标签: claude, mcp, model-context-protocol, music, qobuz, roon, tidal

## 简介

An MCP server for Roon that reaches the parts the official API doesn't: reviews, biographies, Qobuz's and TIDAL's shelves, TIDAL's playlists, your history, search across your library and the streaming services
