# @seifer-webapp-factory/contact

> 标签: JavaScript

## 简介

contact — achtste capability-module: een publiek contactkanaal dat een bericht valideert, misbruik afvangt (honeypot + minimale invultijd + throttle), header-injectie onmogelijk maakt en het resultaat als mail aflevert via een geïnjecteerde Mailer. Bezit
