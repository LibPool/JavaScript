# @zukhruf/sqlite-data-version

> 标签: change-detection, data-version, node-sqlite, pragma, sqlite, wal

## 简介

The data version of a SQLite database that another process owns and writes. It polls PRAGMA data_version on its own read-only connection, which changes on each commit by another connection, also while the owner keeps the file open.
