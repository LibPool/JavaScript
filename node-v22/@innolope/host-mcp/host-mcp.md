# @innolope/host-mcp

> 标签: caddy, claude, claude-code, claude-desktop, devops, diagnostics, docker, mcp, model-context-protocol, nginx, observability, remote, ssh, systemd

## 简介

MCP server that lets MCP clients inspect a Linux host — locally or over SSH. Stdio for local use; HTTP+bearer for remote (Claude.ai connectors). Covers Docker, nginx, Caddy, systemd, ports, files.
