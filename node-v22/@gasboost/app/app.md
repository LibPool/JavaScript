# @gasboost/app

> 标签: backend, framework, gas, gasboost, google-apps-script, rpc, serverless, typescript, web-app

## 简介

A lightweight TypeScript runtime for building Google Apps Script applications with type-safe GET, POST, and RPC handlers.
