# @defterjs/core

> 标签: a1-notation, defter, diff, grid, headless, markdown, markdown-spreadsheet, parser, plain-text, projection, serialize, spreadsheet, text-canonical, typescript

## 简介

Headless, framework-agnostic core for Defter — a text-canonical collaborative spreadsheet. Parse/serialize, coordinates, minimal-splice edits, reference rewriting, projection.
