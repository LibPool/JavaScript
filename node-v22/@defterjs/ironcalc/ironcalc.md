# @defterjs/ironcalc

> 标签: calculator, defter, excel, formula, formula-engine, ironcalc, rust, spreadsheet, wasm

## 简介

IronCalc-wasm formula engine adapter for Defter — proves the pluggable-engine seam with a mature Rust/Wasm engine (300+ functions). Optional; the default is @defterjs/formula.
