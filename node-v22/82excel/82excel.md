# 82excel

> 标签: csv, excel, korean, parser, spreadsheet, validation, xls, xlsx

## 简介

82excel — read xlsx, xls and csv files in the browser or Node and validate them against a header schema. Korean-friendly (NFC headers, EUC-KR CSV).
