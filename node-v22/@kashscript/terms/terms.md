# @kashscript/terms

> 标签: JavaScript

## 简介

Agreements with a declared split — booking, pass, ticket, bounty, cohort. A deterministic state machine, a dust-free declared split, a sealed manifest and a signed completion receipt. It moves nothing and holds no balance. Apache-2.0.
