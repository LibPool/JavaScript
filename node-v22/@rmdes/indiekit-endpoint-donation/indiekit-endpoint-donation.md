# @rmdes/indiekit-endpoint-donation

> 标签: donations, fundraising, indiekit, indiekit-plugin, indieweb, stripe

## 简介

Stripe-backed donation endpoint for Indiekit. Treats Stripe Products as campaigns, PaymentIntents/Checkout Sessions as donations, exposes admin UI + public stats API + rebuild trigger.
