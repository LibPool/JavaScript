# dsh-lan-pair

> 标签: authentication, deepseek-harness, dsh, dsh-plugin, lan, pairing, polyfill, remote-access

## 简介

Secure LAN access for the DeepSeek Harness Web UI: per-interface listeners on a stable port, verbatim-Host reverse proxy to DSH's ephemeral loopback port, 4-digit pairing code, revocable device cookies, and an insecure-origin randomUUID polyfill.
