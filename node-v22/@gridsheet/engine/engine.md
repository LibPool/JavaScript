# @gridsheet/engine

> 标签: cell, engine, excel, formula, grid, gridsheet, headless, spread-sheet, spreadsheet

## 简介

Headless spreadsheet model + formula resolution engine for gridsheet (React/DOM-free; usable from CLI, extension hosts, and backends).
