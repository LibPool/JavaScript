# tapeo-cli

> 标签: asic, cli, eda, fpga, hardware, rtl, systemverilog, tapeo, verilog

## 简介

Terminal client for Tapeo: edit hardware projects locally, run the server's EDA workflow, read results, and work with the AI Architect and Engineer.
