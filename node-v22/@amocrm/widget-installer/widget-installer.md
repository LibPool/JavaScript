# @amocrm/widget-installer

> 标签: amocrm, widget

## 简介

Сервис, который упаковывает директорию в zip-архив и загружает в аккаунт amoCRM.  Если в amoCRM виджет не существует, он будет создан, иначе будет обновлен.
