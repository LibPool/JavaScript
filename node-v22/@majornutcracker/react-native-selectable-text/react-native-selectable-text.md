# @majornutcracker/react-native-selectable-text

> 标签: android, annotation, annotations, bookmark, ebook, expo, expo-module, highlight, highlighter, highlights, html, ios, notes, rangy, react-native, react-native-webview, reader, selectable-text, selection, text-highlight, text-selection, webview

## 简介

Text selection and persistent, animated highlights for HTML in React Native and Expo (iOS & Android). Serialize, restore and sync highlights. Built on react-native-webview and Rangy.
