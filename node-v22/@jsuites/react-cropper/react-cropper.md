# @jsuites/react-cropper

> 标签: React plugins, javascript, image cropper, react image cropper, react image editor, rotate, zoom, crop, brightness, contract.

## 简介

React image editor and cropper plugin, with crop, zoom, rotate, brightness, contract and methods to export the results.
