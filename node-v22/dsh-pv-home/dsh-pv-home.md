# dsh-pv-home

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, electron, home-screen, screensaver

## 简介

把一支 PV 当作 DeepSeek Harness 的主页：启动与刷新都落在默认窗口、影片全屏循环、Esc 返回、PV 风格的音量按钮、播放期间标题栏跟随影片配色，外加一个能连 Windows 屏保一起关掉的开关。不改 DSH 本体源码。
