# @rxap/nest-rabbitmq-vault

> 标签: nest, nest-rabbitmq-vault, packages, rxap

## 简介

This package provides a NestJS module that integrates with HashiCorp Vault to retrieve RabbitMQ credentials. It allows applications to dynamically fetch usernames and passwords for RabbitMQ from Vault, enhancing security and simplifying credential managem
