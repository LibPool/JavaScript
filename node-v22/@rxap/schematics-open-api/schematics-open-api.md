# @rxap/schematics-open-api

> 标签: open-api, packages, rxap, schematic, schematic-open-api

## 简介

This package provides schematics for generating code from OpenAPI specifications. It includes utilities for loading OpenAPI configurations, generating components, parameters, request bodies, and responses, as well as generating Angular directives and Nest
