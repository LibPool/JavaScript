# @hou-tea/mcp-server

> 标签: agent-commerce, agentic-payments, ai-agent, chinese-tea, claude, cursor, mcp, model-context-protocol, stablecoin, usdc, x402

## 简介

MCP server for hou-tea.com — browse, recommend, and buy authentic Chinese tea via x402 USDC payments. Designed for Claude Desktop, Cursor, Cline, and any MCP-compatible AI agent.
