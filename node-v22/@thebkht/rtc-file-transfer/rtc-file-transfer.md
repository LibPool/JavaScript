# @thebkht/rtc-file-transfer

> 标签: backpressure, bufferedAmount, chunking, datachannel, file-sharing, file-transfer, opfs, p2p, peer-to-peer, resume, rtcdatachannel, sha256, streaming, webrtc

## 简介

Peer-to-peer file transfer over WebRTC data channels, with chunking, backpressure, integrity checks, resume, streaming to disk, and offer/revoke. Bring your own signaling.
