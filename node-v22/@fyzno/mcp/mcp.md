# @fyzno/mcp

> 标签: ai-tools, caa, certificate, content-security-policy, csp, deliverability, dkim, dmarc, dns, dnssec, domain-check, email, email-security, hsts, https, llm-tools, mcp, model-context-protocol, modelcontextprotocol, mta-sts, nameserver, security, security-headers, security-scanner, smtp, spf, ssl, starttls, tls, website-security

## 简介

Read-only MCP server for fyzno.com. Three free reports on any domain: mail security (SPF, DKIM, DMARC, MTA-STS, live STARTTLS), website security (headers, CSP, TLS, cookies) and DNS hygiene (name servers, CAA, SOA). Zero dependencies.
