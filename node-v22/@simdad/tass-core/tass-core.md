# @simdad/tass-core

> 标签: JavaScript

## 简介

TASS's engine: LIWC-style category counting over OPEN lexicons (wildcard `stem*` terms, weighted categories, per-document + per-group rollups), a LIWC-format .dic importer (file-format reader - users bring their own licensed dictionaries), and KWIC concor
