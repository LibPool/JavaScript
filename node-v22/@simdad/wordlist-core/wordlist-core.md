## 简介

Excisor's engine: a pure, deterministic, dependency-free de-identification engine. Wordlist + structured HIPAA/FERPA/GDPR shape detection, mask/placeholder/generalize/safe-harbor/pseudonym transforms, checksum validators, and batch mode with a redaction c
