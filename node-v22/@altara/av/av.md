# @altara/av

> 标签: altara, autonomous-vehicles, av, camera-feed, lidar, lidar-react, object-detection, occupancy-grid, perception, point-cloud, pointcloud2, radar, radar-sweep, react, react-components, real-time, robotics, ros2, rosbridge, self-driving, sensor-fusion, slam, slam-map, telemetry, three, threejs

## 简介

Autonomous-vehicle React components for Altara — LiDAR point cloud (Three.js), occupancy grid, object-detection overlay, path planner, camera feed, control trace, radar sweep, perception state machine, sensor health matrix, SLAM map.
