# @sirux/md-press

> 标签: backlog, board, checklist, cli, html, kanban, live, markdown, offline, static-site, todo

## 简介

Press Markdown into clean pages. Build self-contained HTML, serve it live and save checkboxes back to the file, or open it as a Kanban board. No AI, no tokens.
