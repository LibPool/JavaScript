# @agentvisa/mcp

> 标签: agentvisa, ai-agent, human-verification, mcp, model-context-protocol

## 简介

AgentVisa MCP server — securely present your AgentVisa token to any site that requests it. Supports Web Bot Auth (RFC 9421) via AgentVisa-Assertion header.
