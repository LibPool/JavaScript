# @ours.network/fleet-claude-code

> 标签: acp, agents, claude, claude-code, fleet, ours, oversight, plugin, spawn

## 简介

Claude Code plugin for ours-fleet — spawn and oversee fleet agents from inside a session. Bundles the spawn-ours-agent and oversee-agents skills; the ours-fleet CLI (@ours.network/fleet) does the actual work.
