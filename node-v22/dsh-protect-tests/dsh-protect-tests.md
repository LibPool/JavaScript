# dsh-protect-tests

> 标签: agent, deepseek, deepseek-harness, dsh, dsh-plugin, guard, reward-hacking, skip, testing, tests

## 简介

DeepSeek Harness plugin that catches an agent weakening tests to make them pass: added skips, deleted assertions or test cases, trivial asserts, swallowed failures, and deleted test files.
