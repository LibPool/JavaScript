# @powertraces/node

> 标签: apm, logging, metrics, observability, opentelemetry, powertraces, tracing

## 简介

OpenTelemetry for Node.js, set up for PowerTraces in one line: traces, logs, metrics, header and user enrichment, and package lists for vulnerability checks.
