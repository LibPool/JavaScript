# @lumencast/canonical

> 标签: canonical, content-address, lsml, lumencast

## 简介

Canonical JSON form and content address for LSML bundles (LSML 1.0 §3). Leaf package, no internal dependency — the single canonicalizer shared by the compiler and the protocol conformance harness.
