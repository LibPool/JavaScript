# @genclass/runtime

> 标签: ai, anomaly-detection, browser-ai, duplicate-request, error-detection, frontend-reliability, genclass, local-first, observability, on-device-ai, onnx, race-condition, react, runtime, stale-response, wasm, webgpu

## 简介

A runtime for web apps: a small local model watches user actions, async work, network, state and errors, and flags, and optionally prevents, stale responses, races, duplicate requests, inconsistent state and failure storms.
