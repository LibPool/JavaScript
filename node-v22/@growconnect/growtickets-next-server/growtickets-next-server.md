# @growconnect/growtickets-next-server

> 标签: JavaScript

## 简介

El proxy de GrowTickets para Next.js: guarda la clave de API, firma quién reporta con la sesión del producto y reenvía a api/ingest por una lista blanca de 9 rutas.
