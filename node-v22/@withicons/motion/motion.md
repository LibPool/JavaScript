# @withicons/motion

> 标签: animated-icons, animated-svg, animation, css-animation, gif, hover, icon-animation, icon-library, icons, keyframes, micro-interactions, motion, react, reduced-motion, svelte, svg, svg-animation, vue, web-components, with-icons, withicons

## 简介

Optional animations for with icons: 47 CSS presets (15 in 3D, style-aware), per-icon defaults, icon-to-icon swaps and animated SVG/GIF export. Pure CSS core, tiny dependency-free JS.
