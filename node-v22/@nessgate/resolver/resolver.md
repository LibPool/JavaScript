# @nessgate/resolver

> 标签: a2a, acps, agentic-web, agents, ai, ard, discovery, gbz-185, llms-txt, mcp, nessgate, openapi, resolver, well-known

## 简介

Open, neutral universal resolver for the agentic web: give it a domain and get one normalized answer with the machine-readable resources it publishes across ARD (well-known, rel=ard, robots Agentmap), A2A, llms.txt, API catalogs, OpenAPI, ORD, host-meta,
