# @bilrs/cli

> 标签: api, bill-payment, bilrs, cli, payments, sandbox

## 简介

The bilrs CLI: onboard to the BILRS bill-payment API from your terminal. Paste your sandbox key, run the sandbox test cases, and scaffold a typed client.
