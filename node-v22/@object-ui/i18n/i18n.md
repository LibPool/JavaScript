# @object-ui/i18n

> 标签: i18n, internationalization, localization, objectstack, objectui, react, rtl, schema-driven-ui, sdui, shadcn, tailwind

## 简介

Internationalization (i18n) support for Object UI with 10+ language packs, RTL layout, and date/currency formatting.
