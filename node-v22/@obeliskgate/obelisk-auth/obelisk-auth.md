# @obeliskgate/obelisk-auth

> 标签: auth, authentication, obelisk, oidc, openid-connect, passkey, pkce, sso, vaultspark, webauthn

## 简介

Drop-in OIDC client SDK for Obelisk Gate. Point any project at Obelisk and get login, tokens, refresh, userinfo, and local JWKS verification — no per-project auth engine, no custom crypto.
