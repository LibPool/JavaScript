# @nestjs/throttler

> 标签: express, fastify, gql, nest, nestjs, rate-limit, throttle, ws

## 简介

A Rate-Limiting module for NestJS to work on Express, Fastify, Websockets, Socket.IO, and GraphQL, all rolled up into a simple package.
