# @inflowpayai/mpp-seller

> 标签: inflow, machine-payments-protocol, mpp, payments, seller

## 简介

InFlow MPP SDK: seller-side `inflow` method built as a native mppx server method — challenges are minted and HMAC-bound locally by mppx, validation is non-mutating, and broadcast delegates settlement to the InFlow PSP.
