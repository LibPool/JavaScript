# dsh-websift

> 标签: agent-tools, browser, browser-automation, cdp, chrome-devtools-protocol, clash, deepseek, deepseek-harness, dsh, dsh-plugin, headless-chrome, llm-context, proxy, screenshot, token-saving, web-scraping, web-search

## 简介

Token-efficient web reading for DeepSeek Harness, powered by a real Chrome over CDP. One call fetches several pages, gates them by relevance and returns a single digest (80-98% fewer context tokens). Real search URLs, login flow, screenshots, auto proxy.
