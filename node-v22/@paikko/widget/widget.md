# @paikko/widget

> 标签: JavaScript

## 简介

paikko consumer report widget (PaikkoProvider, ReportButton, PaikkoNav, capture) + provenance plugin. Backend-agnostic: configurable endpoint, projectKey, ticketsUrl.
