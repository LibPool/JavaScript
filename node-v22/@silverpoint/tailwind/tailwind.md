# @silverpoint/tailwind

> 标签: charts, silverpoint, tailwind-preset, tailwindcss

## 简介

Optional. A Tailwind preset naming silverpoint's public --sp- variables as theme tokens, for Tailwind 4 (theme.css) and 3.4 (JS preset). No dependencies.
