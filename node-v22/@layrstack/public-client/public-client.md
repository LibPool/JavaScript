# @layrstack/public-client

> 标签: angular, file-upload, layrstack, public-form, recaptcha

## 简介

Browser client for LayrStack public forms: uploads files (intent, direct storage PUT, complete) and submits the record in one call, with LayrStack reCAPTCHA support. Includes an optional Angular wrapper.
