# @ultrvlt/browser-rum

> 标签: observability, opentelemetry, otlp, real-user-monitoring, rrweb, rum, self-hosted, session-replay, web-vitals

## 简介

Ultraviolet Observability — browser RUM SDK (Web Vitals, JS errors, fetch timing, session tracking, and session replay) that emits OTLP spans to the Ultraviolet gateway and stitches to backend traces via W3C traceparent.
