# @hilariouhiss/dsh-colgrep

> 标签: code-search, colbert, colgrep, deepseek-harness, dsh, dsh-plugin, semantic-search

## 简介

colgrep — semantic code search (ColBERT multi-vector) for DeepSeek Harness. Adds a `colgrep` tool that finds code by meaning, not exact text.
