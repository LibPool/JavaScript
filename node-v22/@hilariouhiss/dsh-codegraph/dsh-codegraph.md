# @hilariouhiss/dsh-codegraph

> 标签: code-graph, code-intelligence, codegraph, deepseek-harness, dsh, dsh-plugin, mcp

## 简介

CodeGraph — semantic code intelligence (MCP) for DeepSeek Harness. Adds codegraph_explore so agents answer structural code questions from a pre-built code graph.
