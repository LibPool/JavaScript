# lean-html

> 标签: agent, ai, angular, claude, compression, handlebars, html, lean-html, lhtml, llm, parser, skill, templates, tokens, vue

## 简介

Lean HTML: a compact syntax for HTML that AI agents write with ~15% fewer tokens, converted losslessly to normal HTML. Includes a CLI and an agent skill.
