# @appforge-ci/admin-cli

> 标签: JavaScript

## 简介

`appforge-admin` — the platform-operator CLI for fleet management (enroll, list, drain, resume, reboot, run maintenance scripts on Mac minis). This is a **separate** tool from `appforge` (`packages/cli`), which is for AppForge's customers and has no fleet
