# @bynovl/optimize-schema

> 标签: json-ld, meta, microdata, novl, optimize, schema, schema.org, seo, static-site, structured-data, validation

## 简介

Schema.org validation submodule for the NOVL Optimize project. Checks HTML for Schema.org structured data, required properties, and best practices for SEO in static sites.
