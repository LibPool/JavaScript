# @flamel-ai/yext-api

> 标签: knowledge-graph, listings, openapi, sdk, typescript, yext, zod

## 简介

Clean, fully-typed TypeScript SDK for the Yext API, generated from the official OpenAPI specs with zod validation. Covers all 11 Yext APIs.
