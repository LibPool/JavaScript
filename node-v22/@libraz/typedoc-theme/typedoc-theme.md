# @libraz/typedoc-theme

> 标签: dark-mode, documentation, theme, typedoc, typedoc-plugin, typedoc-theme

## 简介

Refined, business-modern TypeDoc theme: a paper-and-ink palette with a viridian accent, editorial serif/sans/mono typography, and a multi-column layout.
