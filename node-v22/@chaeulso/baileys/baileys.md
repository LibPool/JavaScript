# @chaeulso/baileys

> 标签: automation, baileys, multi-device, typescript, whatsapp, whatsapp-web, ws

## 简介

Production-ready WhatsApp Web library. Dual ESM/CJS build with full TypeScript types, hardening, tests and docs. Fork of Baileys (WhiskeySockets).
