# dsh-codearts

> 标签: codearts, deepseek, deepseek-harness, dsh-plugin, huawei, model-provider

## 简介

把华为云 CodeArts 接入 DeepSeek Harness —— 内置 OAuth2 登录（PKCE + DPoP），登录后即可在 DSH 对话窗口使用 CodeArts 的模型。
