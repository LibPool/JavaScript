# @hummer/hummer-fetch

> 标签: JavaScript

## 简介

Fetch Api For Hummer Env。适用于 Hummer Env 环境的 Fetch API 实现。 ## API 整体是 [fetch api](https://developer.mozilla.org/en-US/docs/Web/API/WindowOrWorkerGlobalScope/fetch) 的子集。
