# @hummer/vue-plugin-error-handler

> 标签: JavaScript

## 简介

`Tenon Vue Plugin Error Handler` 用于全局捕获生产环境的 Error 信息，调用原生 API，统一上报给原生。 ### 简介 Error Handler 用于捕获生产环境中运行时 Error 信息，调用原生 API，统一上报给原生。 > 运行时错误，是指在 Vue 运行过程中发生的异常信息，主要包括生命周期处理、内部方法调用
