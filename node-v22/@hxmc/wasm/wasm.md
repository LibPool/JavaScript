# @hxmc/wasm

> 标签: JavaScript

## 简介

The compiler of @hxmc/cli as a WebAssembly module (wasm32-wasi) with its runner for node: where no native compiler runs (WebContainers, noexec sandboxes); @hxmc/cli uses it when installed, or downloads it
