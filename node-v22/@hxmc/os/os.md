# @hxmc/os

> 标签: JavaScript

## 简介

Windows, input, the app loop and audio output for hxmc, in pure Haxe: raw OS bindings (X11, the Objective-C runtime and AppKit, Win32, a canvas in the browser; ALSA, CoreAudio, WASAPI, WebAudio) and a portable layer
