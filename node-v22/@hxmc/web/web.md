# @hxmc/web

> 标签: JavaScript

## 简介

The web for @hxmc/view: a DOM renderer (JavaScript), a static renderer (HTML at build time, natively or on any target), hydration, islands in JavaScript or WebAssembly with a small loader, and typed calls from JavaScript into wasm32-wasi modules
