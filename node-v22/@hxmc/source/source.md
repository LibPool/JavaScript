# @hxmc/source

> 标签: JavaScript

## 简介

The sources of @hxmc/cli's compiler (the Haxe compiler ported to Haxe, hxmc) and hxmc-rebuild, which builds it again from them for @hxmc/cli

## 官网

- 官网：https://github.com/benmerckx/hxmc#readme
- 源码仓库：git+https://github.com/benmerckx/hxmc.git
- npm 页面：https://www.npmjs.com/package/@hxmc/source
