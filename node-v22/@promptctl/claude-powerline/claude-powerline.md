# @promptctl/claude-powerline

> 标签: claude, claude-code, powerline, statusline, typescript

## 简介

Powerline statusline for Claude Code — fork of @owloops/claude-powerline with CLI override flags (--layout, --set, --show, --display, --segment) so the entire config can live in settings.json without a separate config file.
