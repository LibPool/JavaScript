# dsh-markdown-bubble

> 标签: bubble, chat, deepseek-harness, dsh, dsh-plugin, markdown, render, user-message

## 简介

Markdown rendering for DeepSeek Harness sent user messages: every message bubble renders lists, code, tables, quotes and inline formatting through the host's own Markdown pipeline, while queues, previews and the composer keep their plain projection.
