# @onadiet/pdf

> 标签: compress-pdf, local, no-upload, onadiet, optimize-pdf, pdf, pdf-compression, pdf-lib, shrink-pdf

## 简介

onadiet PDF adapter: detect · weigh · slim PDFs by re-encoding embedded images (pdf-lib + sharp/mozjpeg). Permissive-only, standard formats out.
