# @onadiet/svg

> 标签: compress-svg, local, minify-svg, no-upload, onadiet, optimize-svg, svg, svgo, vector

## 简介

onadiet SVG adapter: detect · weigh · slim SVG vector files losslessly-to-aggressively via svgo (strip editor cruft, collapse, reduce precision). Permissive-only, no rasterization.
