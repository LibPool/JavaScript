# dsh-notify-say

> 标签: deepseek, deepseek-harness, desktop, dsh, dsh-plugin, notification, notify, plugin, speech, toast, tts, voice, voicevox, windows, zh

## 简介

Desktop notifications for DSH Desktop that actually speak: Windows TTS out of the box (zero download), VOICEVOX voice packs optional, a selectable system-sound fallback, and an idle gate that waits for running subagents before saying the turn is done. Inc
