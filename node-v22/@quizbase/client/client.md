# @quizbase/client

> 标签: api, multilingual, questions, quiz, quizbase, sdk, trivia, typescript

## 简介

TypeScript SDK for QuizBase API — typed client, retry, RFC 9457 errors, telemetry hook. Generated from openapi.json.
