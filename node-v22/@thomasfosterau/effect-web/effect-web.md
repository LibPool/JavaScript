# @thomasfosterau/effect-web

> 标签: cloudflare-workers, content-negotiation, effect, fetch, http, ssrf, sveltekit, typescript

## 简介

Framework-neutral web request/response utilities on effect/http: cache-control and security headers, Vary, the cross-origin guard, client IP, an SSRF-guarded fetch, structured logging and an allow-listed span tracer.
