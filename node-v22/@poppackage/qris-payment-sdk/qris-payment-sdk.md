# @poppackage/qris-payment-sdk

> 标签: JavaScript

## 简介

SDK JavaScript/TypeScript ringan untuk integrasi pembayaran QRIS melalui gateway Poppay. Mendukung tampilan **inline iframe** (di halaman utama) atau **popup**, dengan minimal konfigurasi dan data dinamis.
