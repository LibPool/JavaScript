# @zappimoney/zappi-sdk

> 标签: JavaScript

## 简介

Zappi deposit/withdraw contract, API client, webhook verification, wallet USDB signer, and React Query hooks. Single source of truth shared by zappi-nest, the Next.js BFF, and partners like BitKong.
