# @letts-ui/react

> 标签: commerce, components, design-system, letts-commerce, merchant, pos, radix, react, shadcn, tailwind, ui-library

## 简介

Emerald Merchant / Letts Commerce — commerce-first shadcn-style component library. React + Tailwind + Radix. Light + dark. Serves merchant back-office, customer mobile, POS, B2B, courier surfaces.
