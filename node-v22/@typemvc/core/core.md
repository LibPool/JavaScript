# @typemvc/core

> 标签: controllers, framework, frontend, mvc, reactivity, signals, spa, typescript, web

## 简介

A client-side MVC framework for TypeScript: controllers, typed views, signals reactivity, and DI. No JSX, no virtual DOM, no SSR.
