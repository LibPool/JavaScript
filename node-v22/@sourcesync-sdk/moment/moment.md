# @sourcesync-sdk/moment

> 标签: JavaScript

## 简介

The @sourcesync-sdk/moment package is a tool for managing and retrieving moments of a media within the SourceSync SDK ecosystem. It provides a robust set of features for selecting, contextualizing, and formatting moments in your applications.
