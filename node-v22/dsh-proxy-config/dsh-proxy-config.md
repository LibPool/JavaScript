# dsh-proxy-config

> 标签: cordis-plugin, deepseek-harness, dsh, dsh-plugin, http-proxy, no-proxy, proxy

## 简介

One configurable outbound HTTP proxy for DeepSeek Harness, with a live reachability check and an automatic no-proxy fallback while the proxy does not answer.
