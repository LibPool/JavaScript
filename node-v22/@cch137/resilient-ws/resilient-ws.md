# @cch137/resilient-ws

> 标签: auto-reconnect, backoff, buffer, deno, edge, exponential-backoff, heartbeat, keepalive, node, proxy-agent, realtime, reconnect, reconnecting, reconnecting-websocket, resilient, stream, typescript, watchdog, websocket, ws

## 简介

Auto-reconnecting WebSocket client for Node and Deno — exponential backoff, send buffering, seamless soft-restart, and an inactivity watchdog for zombie connections.
