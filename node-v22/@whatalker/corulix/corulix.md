# @whatalker/corulix

> 标签: ai-agent, cli, code-intelligence, corulix, lsp, mcp, model-context-protocol, tree-sitter

## 简介

WhaTalker Corulix — install and run corulix, an enterprise code-intelligence and controlled-mutation MCP server. This package is a thin launcher only; all parsing, indexing, and MCP logic lives in the native binary.
