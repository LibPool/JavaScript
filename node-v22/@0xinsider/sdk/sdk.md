# @0xinsider/sdk

> 标签: 0xinsider, api-client, esports, large-trades, polymarket, prediction-markets, sdk, sports-analytics, sse, webhooks

## 简介

Official TypeScript SDK for the 0xinsider API - analytics for Polymarket sports and esports markets (REST, cursor pagination, SSE stream, webhook verification)
