# @uaip/locator

> 标签: codegen, end-to-end-testing, page-object, playwright, qa, selector-generator, test-automation

## 简介

Crawl any public website and generate a Playwright TypeScript test suite. Self-healing and multi-framework codegen live in the hosted UAIP — this is the open-source core.
