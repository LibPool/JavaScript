# @oneidp/express

> 标签: authentication, bearer-token, cookie-session, express, jwks, jwt, oauth2, oidc, oneidp, openid-connect, pkce, sso, stateless

## 简介

Stateless ONEIDP sign-in for Express: sealed cookie sessions, PKCE, JWT verification, token refresh and role checks. No session store.
