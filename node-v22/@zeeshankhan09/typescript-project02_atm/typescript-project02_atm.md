# @zeeshankhan09/typescript-project02_atm

> 标签: JavaScript

## 简介

I created an atm machine using typescript with the features of withdraw, checkbalance, Deposit and Exit. The current balance of the user is set to $10000. You may either enter manually the amount you want to  withdraw or enter the preferred amount numbers
