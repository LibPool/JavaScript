# @largerio/secret-sdk

> 标签: e2ee, encryption, end-to-end-encryption, privacy, sdk, secret, secure-sharing, typescript, zero-knowledge

## 简介

JavaScript/TypeScript SDK for Secret — create, read, and delete zero-knowledge, end-to-end encrypted notes and files on any Secret instance.
