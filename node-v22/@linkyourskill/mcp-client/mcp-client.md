# @linkyourskill/mcp-client

> 标签: ai-agent, cli, command-line, linkyourskill, lys, marketplace, mcp, sdk, skillanbieter

## 简介

Official TypeScript/Node.js SDK and CLI (`lys`) for the LinkYourSkill agent API — search Skillanbieter, prepare orders (dry-run sandbox), and track status from AI agents or the command line.
