# @rumblewikis/wikipages-deno-bundler-middleware

> 标签: deno, fandom, mediawiki, middleware, wiki, wikipages

## 简介

Bundles .jsx, .tsx, .js, and .ts files into .js files using the Deno bundler for WikiPages.
