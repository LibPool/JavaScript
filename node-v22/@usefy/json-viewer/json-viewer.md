# @usefy/json-viewer

> 标签: headless, inspector, json, json-tree, json-viewer, large-json, react, tree-view, virtual-scroll, virtualized

## 简介

Virtualized JSON tree viewer for React — bounded DOM at any payload size via a lazy order-statistic index, chunked search, and a zero-dependency headless core
