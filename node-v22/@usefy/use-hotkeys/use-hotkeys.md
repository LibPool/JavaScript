# @usefy/use-hotkeys

> 标签: accessibility, hooks, hotkeys, keybinding, keyboard, mod, react, sequence, shortcut, useHotkeys

## 简介

A React hook for high-level keyboard shortcuts — combos, sequences, the cross-platform mod alias, scoping, and an input-field guard
