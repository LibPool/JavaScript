# @loops-adk/core

> 标签: agent, agent-loop, agent-memory, agent-orchestration, agent-workflow, agents, ai, claude, codex, convergence, convergence-loop, done-gate, git-as-memory, llm, loop, loops, multi-agent, orchestration, typescript

## 简介

Run an agent in a convergence loop with an honest done-gate. A small, nestable loop and DAG primitive: deterministic plus agent-judge conditions, git as memory, review-restart, budgets, and a live TUI.
