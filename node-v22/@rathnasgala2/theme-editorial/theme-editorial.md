# @rathnasgala2/theme-editorial

> 标签: JavaScript

## 简介

The Editorial presentation theme for Galascribe portable publications using `@rathnasgala2/template@^4.4.0`. It pairs warm paper and near-black ink with a restrained oxblood accent, an editorial serif reading face, and neutral sans interface typography.
