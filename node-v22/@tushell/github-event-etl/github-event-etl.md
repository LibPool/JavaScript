# @tushell/github-event-etl

> 标签: JavaScript

## 简介

GitHub webhook ETL: transforms verbose GitHub webhook payloads into simplified, agent-friendly events (push, pull_request, issues, workflow_run, ...) for conversational and workflow agents.
