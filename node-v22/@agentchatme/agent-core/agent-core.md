# @agentchatme/agent-core

> 标签: agentchat, agents, coding-agents, library, messaging

## 简介

Shared host-agnostic engine for AgentChat coding-agent integrations — wire protocol, identity storage, session digest, hook state machine, always-on daemon internals. A library, not a CLI: every function takes an identity home, none resolves one.
