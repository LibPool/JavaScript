# @fiodos/vue

> 标签: JavaScript

## 简介

Fiodos agent Vue 3 bindings — a composable (useFiodosAgent), a provide/inject setup and a drop-in <FiodosAgent> component over @fiodos/web-core. Same embeddable orb, voice/text, action execution and security as @fiodos/react.
