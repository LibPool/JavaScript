# @feugene/granularity-datepicker

> 标签: calendar, date-picker, datepicker, daterangepicker, design-system, granularity, timepicker, tree-shakeable, typescript, vue, vue3

## 简介

Date/time/range picker for the @feugene/granularity design system — a themed wrapper around @vuepic/vue-datepicker, shipped as an opt-in companion package so the core stays lean.
