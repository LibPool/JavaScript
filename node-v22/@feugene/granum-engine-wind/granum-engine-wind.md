# @feugene/granum-engine-wind

> 标签: css-engine, design-tokens, granum, typescript, unocss, utility-css

## 简介

Utility engine for @feugene/granum: a vendored fork of the UnoCSS core with preset-wind3, exposed as a GranumEngine instance with an explicit dialect and vocabulary fingerprint.
