# @feugene/granum

> 标签: css, design-system, design-tokens, granular, granum, themes, tree-shakeable, typescript, vite-plugin

## 简介

Build pipeline for granular UI packages: components, styles, design tokens and themes flow from provider manifests to the application bundle through one resolution. Framework-agnostic, zero dependencies.
