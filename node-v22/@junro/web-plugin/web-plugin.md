# @junro/web-plugin

> 标签: debugging, devtools, highlighter, inspector, react

## 简介

Embeddable bug-report and change-request widget for React apps: pick elements, grab screenshots, write it up, and send it to a Junro inbox or export an agent-ready prompt.
