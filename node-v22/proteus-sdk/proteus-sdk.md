# proteus-sdk

> 标签: animation, metamorphic, proteus, transitions, ui, ui-framework, wasm, webassembly, webgl, webgl2, webgpu

## 简介

TypeScript SDK for Proteus, a UI framework whose components transform into other components instead of loading new screens. Draws with WebGPU or WebGL2.
