# @magical-index/alidocs-web-mcp

> 标签: ai-agent, alidocs, dingtalk, document-editing, mcp, model-context-protocol, websocket-bridge

## 简介

Local MCP bridge that exposes the DingTalk Doc (alidocs) page already open in your browser to any MCP host over stdio.
