# @rfc0/effect-runner

> 标签: effects, functional-core, idempotency, imperative-shell, neverthrow, optimistic-concurrency, unit-of-work, zod

## 简介

A generic functional-core / imperative-shell effect runner: the domain returns writes as data, a driver-agnostic shell applies them with optimistic-concurrency version guards, idempotency, and retry. Bring your own database via a small adapter port.
