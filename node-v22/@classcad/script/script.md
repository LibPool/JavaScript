# @classcad/script

> 标签: agent, buerli, cad, classcad, llm, script

## 简介

Universal script executor for ClassCAD agents — model-written JavaScript against a session-abstracted API (api.v1.*, api.tree(), api.graphic()), identical in the browser (buerli), Node (MCP, harness) and CI.
