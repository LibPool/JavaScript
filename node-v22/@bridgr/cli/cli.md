# @bridgr/cli

> 标签: ai-agent, chrome-extension, cli, google-flow, mcp

## 简介

Bridgr Connect — CLI, local bridge daemon and MCP server for driving Google Flow from an AI agent. Ships the Chrome extension (run `bridgr extension path`).
