# @jantstack/adonis-audit

> 标签: activity-log, adonis, adonisjs, adonisjs-7, adonisjs-package, audit, audit-log, audit-trail, backend, compliance, esm, event-sourcing, lucid, lucid-orm, mysql, observability, postgresql, sqlite, typescript

## 简介

Audit trail engine for AdonisJS + Lucid: one transactional store plus fan-out sinks, a Lucid CRUD mixin, polymorphic actors and entities, and a safe-by-default snapshot where auditable ⊆ serializable — fields hidden from your API never reach the trail.
