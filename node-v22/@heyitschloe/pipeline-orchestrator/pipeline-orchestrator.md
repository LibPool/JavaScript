# @heyitschloe/pipeline-orchestrator

> 标签: JavaScript

## 简介

Self-hosted GitHub App pipeline engine — register any automation pipeline via config and write your own handlers, no shared hosted service. Ships with issue-to-PR automation (plan, approve, implement, quality gate) by default.
