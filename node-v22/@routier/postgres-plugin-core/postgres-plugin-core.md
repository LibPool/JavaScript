# @routier/postgres-plugin-core

> 标签: data access layer, database, entities, orm, postgres, postgresql, routier, typescript

## 简介

Engine-independent PostgreSQL building blocks for routier plugins: dialect, DDL, result translation, and a driver-shaped plugin base. Contains no database client.
