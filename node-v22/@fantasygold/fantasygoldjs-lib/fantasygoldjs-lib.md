# @fantasygold/fantasygoldjs-lib

> 标签: bitcoin, fantasygold, fantasygoldjs, smart contract

## 简介

An extend lib for bitcoinjs-lib, it supports two new network of fantasygold and fantasygold-testnet, and it can generate contract creating and sending transactions
