# @astragenie/memory-provider

> 标签: JavaScript

## 简介

Provider-swap memory layer (noop | file | astramem) shared across the Astragenie plugin ecosystem — Zod-validated MemoryEntry schema, recency x severity ranking with decay hygiene, a JSONL-backed fileProvider, and an astramemProvider that writes through t
