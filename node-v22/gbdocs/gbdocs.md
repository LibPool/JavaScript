# gbdocs

> 标签: contenteditable, document, docx, editor, ooxml, word

## 简介

挂逼文档：独立 .docx 编辑器（内核移植自 guabi office/docx 编解码 + 自研 contenteditable 编辑器内核，UI 用原生 HTML 重写），只依赖 gbooxml。

## 官网

- npm 页面：https://www.npmjs.com/package/gbdocs

- 0.1.0
- 0.1.1

- npm registry：https://registry.npmjs.org/gbdocs
- Node 要求：>=18
