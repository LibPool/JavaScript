# @kivcode/plugin-a11y

> 标签: a11y, accessibility, kiv, page-builder, plugin, visual-editor

## 简介

Accessibility auditing plugin for Kiv — flags missing alt text, heading-level skips, and other a11y issues on a KivDocument.
