# @kivcode/react

> 标签: kiv, nextjs, page-builder, react, react19, visual-editor

## 简介

React 19 renderer for the Kiv visual page-builder — a component per node type, plus KivRenderer/KivNodeRenderer to walk and render a KivDocument.
