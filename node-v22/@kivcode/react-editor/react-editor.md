# @kivcode/react-editor

> 标签: kiv, nextjs, page-builder, react, react19, visual-editor

## 简介

The Kiv visual page-builder editor UI for React — canvas, structure tree, inspector, drag & drop, undo/redo, node palette, and content-block library.
