# @tomhermans/range-knob

> 标签: custom-element, dial, form-associated, knob, midi, range, rotary, slider, ui, web-component

## 简介

A circular range/knob web component: form-associated, pointer and keyboard accessible, themeable via CSS custom properties and ::part(), with an optional built-in settings dialog and pluggable MIDI / CSS-binding add-ons.
