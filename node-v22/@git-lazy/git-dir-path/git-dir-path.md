# @git-lazy/git-dir-path

> 标签: cwd, find-up, git, git-dir, git-directory, git-env, path-finder, repository-root

## 简介

Search upward from a directory to find the Git repository root, supporting sync and async modes with GIT_DIR environment variable awareness
