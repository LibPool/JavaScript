# @zhengjunyao/dsh-mcp-manager

> 标签: MCP管理, deepseek-harness, dsh, dsh-plugin, mcp, mcp-manager, mcp-server, model-context-protocol, stdio, streamable-http

## 简介

MCP server manager for DeepSeek Harness: add, edit, enable and test stdio / Streamable HTTP MCP servers from the Web settings page and from agent tools, connected and disconnected at runtime without restarting DSH
