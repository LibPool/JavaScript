# @nxgt/drizzle-meilisearch

> 标签: drizzle, meilisearch, postgresql, search, sync, typescript

## 简介

Keeps a Meilisearch index in step with a PostgreSQL table: a typed transform, a full reindex, and one call per write — no change feed, and none pretended
