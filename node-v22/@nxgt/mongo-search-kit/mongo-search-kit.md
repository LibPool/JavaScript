# @nxgt/mongo-search-kit

> 标签: kit, meilisearch, mongodb, search, sync, typescript

## 简介

A search kit over @nxgt/mongo-kit: one config naming an index and a transform per collection, and one syncIndexes, reindexAll, start and close for all of them
