# @hayston/pi-token-meter

> 标签: cost, pi-extension, pi-package, token-meter, tokens, tui, usage

## 简介

Live token/cost meter for pi: a counter that grows next to the spinner and a per-round settlement line at the end of the transcript, with a settings panel.
