# @michaelthielemann/kestrel-publishing

> 标签: JavaScript

## 简介

Kestrel's publishing domain: the publish_deps/publish_status/publish_runs/published_snapshots tables, the publishing <Module>Db adapter, the runtime static publisher, the publish orchestrator, and the publish/publishRuns pipelines.
