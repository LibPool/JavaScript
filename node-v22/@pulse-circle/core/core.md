# @pulse-circle/core

> 标签: analytics, events, idempotent, offline-first, pulse, tracking

## 简介

Platform-agnostic core for Pulse analytics SDKs: persistent ordered event queue, idempotent delivery, identity. No DOM or React Native APIs.
