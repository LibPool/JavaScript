# @difizen/umi-plugin-mana

> 标签: decorator, difizen, mana, nodenext, plugin, route, umi

## 简介

- 支持 decorator 所需的 babel 配置，在 typescript 4 环境生效 - 支持动态路由路径 - 支持 nodenext，在 import path 中允许增加扩展名 - 支持 mana 运行时能力，基于 slot 的路由等
