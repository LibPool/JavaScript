# @kaishin/pi-usage

> 标签: footer, pi, pi-extension, pi-package, quota, usage

## 简介

Pi extension that surfaces per-provider token-usage and quota status in the footer, plus a /usage command and dashboard. Restored from pi-quotas with MiniMax support.
