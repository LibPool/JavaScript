# nanoeffects

> 标签: abort-signal, abortcontroller, debounce, effects, event-bus, event-emitter, queue, retry, side-effects, throttle, typescript

## 简介

Typed event bus where every handler is a task with an AbortSignal, plus policies (latest, debounce, throttle, queue), effects (retry, timeout, poll) and tracing. About 1.3 kB gzip.
