# @dsh-plug/dsh-sidebar-epub

> 标签: dsh-plugin

## 简介

DSH web plugin: EPUB ebook previewer for the better-sidebar editor. Registers the epub file viewer through ctx.betterSidebar.registerFileViewer, keeping the epub.js render library out of the better-sidebar bundle.
