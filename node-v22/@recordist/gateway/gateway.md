# @recordist/gateway

> 标签: a2a, mcp, meetings, model-context-protocol, recordist, transcripts

## 简介

MCP server + A2A agent for the Recordist app (https://recordist.app): lets AI assistants read, search and act on meetings recorded on your own computer.
