# @highflame/overwatch

> 标签: agent-security, ai-coding-assistant, ai-security, claude-code, codex, cursor, daemon, gemini-cli, github-copilot, guardrails, highflame, ide-security, kiro, mcp, mcp-security, overwatch, policy-enforcement, prompt-injection, security

## 简介

IDE-agnostic security daemon for AI coding assistants. Evaluates prompts, tool calls, file operations, shell commands, and MCP usage in real time for Cursor, Claude Code, GitHub Copilot, Gemini CLI, OpenAI Codex, and Kiro.
