# @geodechain/local-signer

> 标签: ai-agent, geode, mcp, model-context-protocol, polkadot, signer, substrate

## 简介

Signs Geode blockchain transactions on your own machine for AI agents using the Geode MCP server. Verifies every transaction independently; keys never leave your computer.
