# @spleenteo/datocms-dev-bar

> 标签: datocms, draft-mode, preview, visual-editing, web-component

## 简介

A local-only dev bar for DatoCMS sites: draft/published, visual editing and an X-Ray of the page's queries, loaded into any Node dev server without touching your code.
