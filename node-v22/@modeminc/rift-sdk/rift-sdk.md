# @modeminc/rift-sdk

> 标签: app, bot, chat, modeminc, rift, sdk

## 简介

The official Rift App SDK. Connect over WebSocket (socket mode - no inbound port), render a block UI, and handle taps, without hand-writing the wire protocol.
