# @xpert-ai/plugin-loop-guard

> 标签: JavaScript

## 简介

`@xpert-ai/plugin-loop-guard` implements a pure-plugin tool-call loop detector for Xpert agents. It does not rely on `xpert-pro` consuming `jumpTo: "model"`.
