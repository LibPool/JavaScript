# @decisive.rocks/sdk

> 标签: ai-tools, block-kit, decisive, extensions, plugins, sdk

## 简介

Build extensions for Decisive — a stable, versioned host API plus a declarative Block Kit UI. Lives on top of Decisive so platform updates don't break integrations.
