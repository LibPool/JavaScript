# @tecace/nest-opentelemetry

> 标签: JavaScript

## 简介

基于官方 npm 封装 nest-opentelemetry 工具，无侵入式劫持 controller/provider，提供装饰器手动劫持非 nestjs 代码、忽略采集，自动上报 traces 和 metrics
