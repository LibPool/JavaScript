# @bevyl-ai/rerender

> 标签: animation, filmstrip, frame-extraction, mp4, react, remotion, renderer, seek, thumbnails, video, webcodecs

## 简介

Random-access frame extraction from mp4 URLs — any frame in one Range request and one decode, with no dependencies. Plus a drop-in MIT Remotion alternative that renders real DOM to MP4 with WebCodecs and mediabunny. No ffmpeg.
