# @plexivo/client

> 标签: auth, database, gorm, graphql, migrations, orm, plexivo, postgres, postgresql, query-builder, react, react-native, realtime, supabase-alternative, vue

## 简介

Plexivo Postgres client for JavaScript and TypeScript: queries (Supabase-style and GORM-style), models and relations, transactions, migrations, auth, realtime, GraphQL, functions and storage
