# @cutils/postgres

> 标签: database, elf, native, pgwire, postgres, postgresql, scram-sha-256, scriptc, standard-schema, wire-protocol

## 简介

Hand-rolled async Postgres wire-protocol driver for chttp/scriptc apps — node:net + node:crypto, Standard-Schema row seam, no FFI. Compiles to a single static ELF.
