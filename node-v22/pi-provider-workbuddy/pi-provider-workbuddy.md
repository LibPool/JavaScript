# pi-provider-workbuddy

> 标签: ai, codebuddy, pi, pi-package, provider, workbuddy

## 简介

Pi extension for WorkBuddy (CodeBuddy) — dual-region providers (CN + Global) with OAuth login, dynamic model catalog with credit multipliers, DSML tool-call recovery, and read-only credit/status commands
