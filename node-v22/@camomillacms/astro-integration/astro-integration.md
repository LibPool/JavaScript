# @camomillacms/astro-integration

> 标签: astro, camomilla, whithastro

## 简介

This project is an Astro integration built to be used with Camomilla CMS. The aim of this project is to provide a simple and easy Frontend integration to easily use Camomilla CMS as a Headless CMS. 🚀
