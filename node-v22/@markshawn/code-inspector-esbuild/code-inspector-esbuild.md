# @markshawn/code-inspector-esbuild

> 标签: copy-path, enhanced, inspect, inspector, mode-switching, plugin, vite, vscode, vue, webpack

## 简介

Enhanced code-inspector esbuild plugin with mode switching: Click DOM to open IDE or copy path. Press Shift+Alt+C to toggle modes.
