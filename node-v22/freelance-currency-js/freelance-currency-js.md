# freelance-currency-js

> 标签: cli, currency, exchange-rate, freelance, invoice, npx, zero-dependencies

## 简介

Convert an invoice amount between currencies with a live exchange rate (or a manual one, offline). Zero dependencies, runs via npx straight from GitHub.
