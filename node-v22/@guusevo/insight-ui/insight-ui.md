# @guusevo/insight-ui

> 标签: bitcore-guus, blockchain, blockexplorer, front-end, guus, guuscore, insight

## 简介

An open-source frontend for the Insight API. The Insight API provides you with a convenient, powerful and simple way to query and broadcast data on the Guus network and build your own services with it.
