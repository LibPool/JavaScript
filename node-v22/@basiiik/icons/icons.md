# @basiiik/icons

> 标签: accessible, design-system, icon-set, icons, outline-icons, react, svg, zero-dependency

## 简介

Basiiik icons: a consistent 16px outline icon set as React components, with search words and when-to-use guidance for each icon. Zero runtime dependencies.
