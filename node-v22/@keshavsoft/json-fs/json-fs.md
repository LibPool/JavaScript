# @keshavsoft/json-fs

> 标签: declarative-fs, file-generator, json-driven, json-fs, json-scaffolding

## 简介

JSON-driven folder and file scaffolding engine. Takes a JSON source-of-truth tree and creates the real folder/file structure on disk.
