# @weissaufschwarz/mitthooks-drizzle

> 标签: JavaScript

## 简介

[Drizzle ORM](https://orm.drizzle.team/) integration for the mitthooks SDK. This package provides a PostgreSQL-based `ExtensionStorage` implementation using Drizzle ORM with built-in encryption support for sensitive data.
