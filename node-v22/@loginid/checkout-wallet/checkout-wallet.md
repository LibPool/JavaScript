# @loginid/checkout-wallet

> 标签: authentication, biometrics, checkout, fido2, passkey, passwordless, payments, wallet, webauthn

## 简介

The LoginID Checkout SDK for Wallets enables passkey-based passwordless authentication within embedded wallet experiences. It facilitates secure and efficient handling of authentication requests initiated from merchant sites.
