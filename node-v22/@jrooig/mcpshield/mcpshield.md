# @jrooig/mcpshield

> 标签: firewall, json-rpc, mcp, model-context-protocol, proxy, security

## 简介

A local firewall for AI agents: pauses dangerous MCP tool calls (shell, file deletes, secret exfiltration) for your approval before they run — live in the connection, 100% on your machine.
