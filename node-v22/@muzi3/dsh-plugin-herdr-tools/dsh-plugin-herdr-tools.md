# @muzi3/dsh-plugin-herdr-tools

> 标签: agent, cordis, deepseek-harness, dsh, dsh-plugin, herdr, layout, pane, terminal-multiplexer

## 简介

DSH plugin: herdr_layout / herdr_pane / herdr_agent tools — inspect and create Herdr terminal topology, drive ordinary commands in panes, and control coding agents. Port of @muzi3/herdr's pane-agent-tools.
