# @kingtech/react-rtekit

> 标签: accessibility, contenteditable, editor, email, html, quill, react, rich-text-editor, sanitize, wysiwyg

## 简介

Accessible, themeable rich-text editor for React with no dependencies: slots, handler middleware, theme tokens, built-in sanitization and HTML interop.
