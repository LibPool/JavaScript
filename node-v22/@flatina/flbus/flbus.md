# @flatina/flbus

> 标签: agent, claude-code, claude-code-plugin, cli, ipc, message-bus

## 简介

Agent-to-agent, human-gated message bus for Claude Code sessions — CLI for the flbus Claude Code plugin. After `npm i -g`, install the plugin (`claude plugin install flbus@flatina`) and wire the statusLine per the README; `flbus doctor` verifies.
