# @pdx-ts/pdxscript

> 标签: clausewitz, modding, paradox, parser, pdxscript, stellaris

## 简介

Parser and serializer for PDXScript, the Clausewitz engine script format (Stellaris-tested): order-preserving, duplicate-preserving, semantic round-trip
