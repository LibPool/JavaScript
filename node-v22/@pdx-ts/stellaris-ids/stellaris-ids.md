# @pdx-ts/stellaris-ids

> 标签: JavaScript

## 简介

Vanilla Stellaris identifiers (technologies, scripted triggers/effects, sprites, sounds, ...), install-derived and version-pinned to the game — declaration-merges into @pdx-ts/sdk to check vanilla references at compile time
