# @prex0/uikit

> 标签: JavaScript

## 简介

Prex UI Kit is a comprehensive collection of reusable React components designed to accelerate the development of web wallet applications. Built with TypeScript, Tailwind CSS, and Vite, this UI Kit ensures type safety, rapid styling, and efficient bundling
