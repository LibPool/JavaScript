# @sinco-lab/evm-mcp-server

> 标签: agent, ai, blockchain, ethereum, evm, gateway, mcp, model-context-protocol, service, viem

## 简介

An EVM interaction service gateway based on Model Context Protocol (MCP) and Viem, enabling AI agents or services to securely interact with EVM-compatible blockchains.
