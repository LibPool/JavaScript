# @rickardlind/livsmedel-mcp

> 标签: claude, food-composition, livsmedelsdatabasen, livsmedelsverket, mcp, mcp-server, model-context-protocol, nutrition, open-data, sweden

## 简介

Unofficial MCP server for the Swedish Food Agency's food composition database (Livsmedelsdatabasen): search 2,600 foods, read nutrient values, compare foods and calculate recipe nutrition.
