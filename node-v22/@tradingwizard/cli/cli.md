# @tradingwizard/cli

> 标签: ai, cli, mcp, trading, tradingwizard

## 简介

TradingWizard CLI — one command (`wiz setup`) installs the MCP connector into Claude Desktop, Cursor, Claude Code, VS Code, and more. Also wraps the MCP server for direct CLI queries. (`tw` still works as a legacy alias.)
