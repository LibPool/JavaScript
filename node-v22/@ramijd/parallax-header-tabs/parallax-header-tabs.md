# @ramijd/parallax-header-tabs

> 标签: android, collapsible, expo, header, ios, parallax, react-native, scroll, sticky-tabs, tabs

## 简介

Collapsing parallax header with sticky tabs and sub-tabs for React Native. Works in Expo and React Native CLI with zero native dependencies.
