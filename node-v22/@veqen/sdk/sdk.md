# @veqen/sdk

> 标签: ai sdk, anthropic, budget, finops, gemini, langchain, llm cost, openai, pricing, token cost

## 简介

The cost ledger for AI inference: exact cost for every model call (text, embeddings, images, video, speech and transcription, across labs, open-model hosts and clouds), per customer, feature and project, with budgets. Includes the `veqen` CLI.
