# @idevconn/llm-router

> 标签: ai, byok, chatgpt, claude, deepseek, gemini, grok, llm, router, strategy

## 简介

Library-agnostic LLM router: provider-neutral strategy interface + registry with env-driven platform selection and BYOK support. Opt-in adapters for Gemini, Claude, Grok, ChatGPT, and DeepSeek via subpath exports.
