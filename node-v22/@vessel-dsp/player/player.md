# @vessel-dsp/player

> 标签: cabinet, custom-element, dsp, electronics, guitar-pedal, nam, player, simulation, spectrum-analyzer, web-component

## 简介

Embeddable HTML Custom Element (<vessel-player>) and Web Audio player for VesselDSP circuits, guitar profiling, NAM, and cabinet IRs.
