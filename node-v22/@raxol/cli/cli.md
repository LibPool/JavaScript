# @raxol/cli

> 标签: agent, ai, elixir, raxol, terminal, tui

## 简介

Interactive AI agent and TUI toolkit in your terminal. A self-contained binary (via Burrito), so `npm i -g @raxol/cli` puts `raxol` on your PATH -- no Erlang or Elixir required.
