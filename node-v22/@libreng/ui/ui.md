# @libreng/ui

> 标签: angular, bootstrap, component library, fluent, libreng-ui, material, tailwind, ui library

## 简介

LibreNG UI is an open source UI library for Angular featuring a rich set of 80+ components, based on the MIT-licensed PrimeNG v21 by PrimeTek.
