> 标签: automation, ci, e2e-testing, failed-tests, flaky-tests, json-reporter, playwright, qa, test-automation, test-framework, test-report, test-summary, testing, typescript

## 简介

Parse a Playwright JSON test report for a trustworthy total/passed/failed/flaky/skipped summary and the tests still failing, with retries, multi-project runs and merged reruns handled correctly
