# mcp-janitor

> 标签: ai-agents, chatgpt, claude-code, claude-desktop, cli, codex, cursor, gemini-cli, mcp, memory, memory-leak, model-context-protocol, orphan-processes, playwright, process-manager, vscode

## 简介

Find and stop the idle or orphaned MCP server processes (node.exe, node_repl, Playwright) that Codex, the ChatGPT desktop app, Claude Code, Claude Desktop, Cursor and VS Code leave running, per conversation, by hand or automatically.
