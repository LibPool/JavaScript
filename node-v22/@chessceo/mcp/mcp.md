# @chessceo/mcp

> 标签: chess, chessceo, claude, fide, llm, mcp, modelcontextprotocol

## 简介

Model Context Protocol server for chess.ceo — 11.7M+ games, ~1.5M FIDE player profiles, opening preparation, live broadcasts.
