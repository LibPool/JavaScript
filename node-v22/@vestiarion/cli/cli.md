# @vestiarion/cli

> 标签: accounts-payable, arc, cli, stablecoin, treasury, usdc, vestiarion

## 简介

The Vestiarion API from a terminal: a workspace's status, bills, invoices, counterparties, milestones and the agent's decisions, plus offline checks of audit exports and webhook signatures.
