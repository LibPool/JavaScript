# @asouei/safe-fetch

> 标签: discriminated-union, error-handling, fetch, http, retry, safe, timeout, type-safe, typescript, zero-dependencies

## 简介

Tiny, typed wrapper around fetch with safe results, normalized errors, timeouts, retries and validation hooks.
