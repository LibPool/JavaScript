# @vdaluz/astro-inapp-escape

> 标签: affiliate-marketing, astro, astro-component, in-app-browser, webview

## 简介

In-app-browser (Instagram, TikTok, Facebook, etc) detection and escape for Astro sites - protects affiliate links that platforms prohibit from rendering in their own webviews.
