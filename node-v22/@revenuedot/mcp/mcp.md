# @revenuedot/mcp

> 标签: in-app purchases, mcp, model-context-protocol, revenuecat, revenuedot, subscriptions

## 简介

MCP server for RevenueDot, the open-source subscription backend that works with the RevenueCat SDK. Manage products, entitlements, offerings, customers and webhooks from Claude, ChatGPT, Cursor and other AI assistants.
