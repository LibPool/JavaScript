# @fortmesa/verdaccio-oidc-auth

> 标签: ci-cd-authentication, npm-registry, oidc, openid-connect, verdaccio, verdaccio-plugin

## 简介

Verdaccio middleware plugin: verifies CI/CD platform OIDC ID tokens against their public JWKS and maps trusted claims to per-repository Verdaccio identities/groups
