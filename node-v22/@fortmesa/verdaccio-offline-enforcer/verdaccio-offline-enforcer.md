# @fortmesa/verdaccio-offline-enforcer

> 标签: caching, npm-registry, offline, verdaccio, verdaccio-plugin

## 简介

Verdaccio middleware plugin: forces configured usernames/groups (and optionally unauthenticated requests) into offline mode, serving only already-cached packages instead of proxying to upstream
