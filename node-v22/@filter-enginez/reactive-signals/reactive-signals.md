# @filter-enginez/reactive-signals

> 标签: faceted-search, filter, filter-enginez, filtering, isomorphic, preact-signals, reactive, signals, typescript

## 简介

Signals for faceted search: reactive results, counts and filter state from the Filter EngineZ engine, built on Preact signals. Works in the browser, Node and Web Workers.
