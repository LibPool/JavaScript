# @filter-enginez/reactive-rxjs

> 标签: faceted-search, filter, filter-enginez, filtering, isomorphic, observable, reactive, rxjs, streams, typescript

## 简介

RxJS Observables for faceted search: results, counts and filter state from the Filter EngineZ engine as streams. Works in the browser, Node and Web Workers.
