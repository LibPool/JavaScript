# @cosmicdrift/kumiko-renderer-mail-html

> 标签: JavaScript

## 简介

Renderer-Foundation plugin for branded HTML emails: mail-kind templates (document HTML + subject meta) rendered with isolated Handlebars into an MJML layout, plus plain text via html-to-text. Templates resolved from template-resolver.
