# @bdxi/changenow-exchange-integration

> 标签: bdx, bdxtobtc, beldex, beldex-to-bitcoin, beldextobitcoin, cryptocurrency-conversion, cryptocurrency-exchange

## 简介

This module is used by the desktop, web and Android versions of the Beldex wallet to facilitate the exchange of XMR into other cryptocurrencies via ChangeNow.
