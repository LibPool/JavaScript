# @joeytisaly/dsh-client-ui-wallpaper

> 标签: JavaScript

## 简介

Wallpaper plugin for DeepSeek Harness web: a photo behind the web surface, set from General settings (Host /wallpaper route + browser apply over the --dsw-* token stylesheets)
