# @openmascot/core

> 标签: 2.5d, animation, character, mascot, openmascot, pseudo-3d, react-native, rigging, skeletal-animation, ssr, svg

## 简介

Framework-agnostic, dependency-free OpenMascot engine: annotated-SVG rig compiler, pseudo-3D solver, clip blending, effects and an SVG string renderer. Runs in browsers, Node, workers and React Native.
