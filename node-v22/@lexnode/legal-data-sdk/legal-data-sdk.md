# @lexnode/legal-data-sdk

> 标签: brazil, client, cnj, djen, legal, lexnode, openapi, sdk, typescript, webhooks

## 简介

Cliente TypeScript do LexNode, o motor de dados jurídicos do Brasil: transporte tipado, erros classificados, verificação de webhook e os tipos gerados do contrato OpenAPI.
