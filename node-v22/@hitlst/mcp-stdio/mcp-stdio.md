# @hitlst/mcp-stdio

> 标签: device-flow, hitlst, mcp, model-context-protocol, oauth, proxy, stdio

## 简介

Stdio MCP proxy for HITLst with device-flow authentication. Enables any MCP client (Claude Code, Claude Desktop, Cursor, etc.) to connect to a HITLst server using a short device-flow code for auth.
