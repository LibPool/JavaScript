# @swapdk/wdk-wallet-cosmos

> 标签: cacao, cosmos, mayachain, rune, swapdk, thorchain, wallet, wdk

## 简介

WDK wallet module for Cosmos-SDK chains, with first-class support for THORChain (RUNE) and MAYAChain (CACAO) swap-deposit messages. Fork of @base58-io/wdk-wallet-cosmos.
