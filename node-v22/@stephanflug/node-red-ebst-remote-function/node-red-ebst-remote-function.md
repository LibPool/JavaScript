# @stephanflug/node-red-ebst-remote-function

> 标签: automation, building-automation, energy, hvac, node-red, node-red-contrib, remote-function, weather

## 简介

Dynamischer Node-RED Node für zentral verwaltete EBST Remote-Funktionen mit automatischen Updates, dynamischen Einstellungen, Datenpunktbeschreibung und integriertem HTTP-Client.
