# @shrkcrft/context-planner

> 标签: ai-agent, context-planner, ranker, sharkcraft

## 简介

SharkCraft context planner: deterministic, token-budgeted context packs for AI coding agents. Combines code graph, rule-graph, and intent classification to pick the minimal relevant file set for a task.
