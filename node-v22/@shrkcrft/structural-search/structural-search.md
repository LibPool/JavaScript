# @shrkcrft/structural-search

> 标签: ast, codemod, sharkcraft, structural-search, typescript

## 简介

SharkCraft structural search: declarative AST patterns for TypeScript codebases. Find call sites, decorators, classes, imports — preview-only by default; rewrite mode lands in Wave 8.
