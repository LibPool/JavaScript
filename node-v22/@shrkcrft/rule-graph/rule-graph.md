# @shrkcrft/rule-graph

> 标签: bridge, code-intelligence, rule-graph, sharkcraft

## 简介

SharkCraft rule-graph: bridges code-graph file nodes to rules / paths / templates / boundaries so 'which assets apply to this file?' is a 1-hop query.
