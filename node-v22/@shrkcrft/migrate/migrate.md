# @shrkcrft/migrate

> 标签: codemod, migration, orchestration, sharkcraft

## 简介

SharkCraft migrations: orchestrate multi-step refactors (structural rewrites + shell + checkpoints) as one replayable migration. The safe path for big cross-cutting refactors.
