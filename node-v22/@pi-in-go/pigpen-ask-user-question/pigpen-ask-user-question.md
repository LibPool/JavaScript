# @pi-in-go/pigpen-ask-user-question

> 标签: ask-user, extension, pig-package, pigpen, questionnaire

## 简介

Go port of @juicesharp/rpiv-ask-user-question: a structured questionnaire the model can put to you, with typed options instead of free-form replies (partial: the dialog walker; the interactive questionnaire is not ported yet)
