# @pi-in-go/pigpen-pig-snake

> 标签: extension, game, pig, pig-package, pigpen, snake

## 简介

Pig Snake: a snake game whose head is the PiG pig and whose every eaten apple adds another pig to the line, so a herd forms behind the leader. Explicit /pig-snake command only.
