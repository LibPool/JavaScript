# @pi-in-go/pigpen-dirty-repo-guard

> 标签: extension, git, pig-package, pigpen, safety

## 简介

Go port of Pi's dirty-repo-guard example: blocks a session switch or fork while the git tree has uncommitted changes unless you allow it
