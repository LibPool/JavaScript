# @heuresis/mcp

> 标签: claude-code, claude-desktop, cursor, heuresis, ideation, knowledge-graph, mcp, model-context-protocol

## 简介

Cloud-authenticated Model Context Protocol server for a Heuresis workspace. Logs into the user's Heuresis account and lets any MCP client (Claude Desktop, Claude Code, Cursor, custom agents) read and write the same workspace the webapp uses. 31 data tools
