# @dpkrn/nodetunnel

> 标签: devtunnel, expose, gotunnel, http, localhost, multiplex, ngrok, tunnel, yamux

## 简介

Expose a local HTTP server through a devtunnel/gotunnel-compatible server (yamux + JSON). Node.js 18+.
