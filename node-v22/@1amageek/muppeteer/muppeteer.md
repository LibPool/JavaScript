# @1amageek/muppeteer

> 标签: JavaScript

## 简介

Recurrence Rules Processor (RRP) is a versatile JavaScript library for managing complex recurring date patterns. From 'every Tuesday' to intricate rules, RRP offers rule validation, occurrence calculation, and date checks, making it ideal for calendar app
