> 标签: agent-tool, agents-md, ai, anthropic, claude-code, cli, coding-agent, copilot, cursor, gemini-cli, llm, mcp, mcp-server, scaffold, windsurf

## 简介

Bootstrap AI coding-agent config (Claude Code, Cursor, Copilot, Gemini CLI, AGENTS.md, Windsurf) for a repo by auto-detecting its stack and the tools in use — interactively, or driven by an AI agent over JSON or MCP.
