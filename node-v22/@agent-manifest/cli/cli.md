# @agent-manifest/cli

> 标签: agent-boundaries, agent-declaration, agent-manifest, agent-manifest-spec, ai-agent, declarative-manifest, json-schema, schema-validation, structural-validation, validator

## 简介

Command-line validator for Agent Manifest v1.0 declarations. Checks a manifest's structure against the published Agent Manifest v1.0 JSON Schema; structural validation only. Not affiliated with the unrelated npm packages 'agent-manifest' or '@agentmanifes
