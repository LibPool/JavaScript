# @agent-manifest/schema

> 标签: agent-manifest, agent-manifest-spec, conformance-corpus, json-schema, schema

## 简介

The Agent Manifest v1.0 JSON Schema and its conformance corpus, distributed as data. No code, no runtime dependencies. The schema file is dedicated to the public domain under CC0 1.0 so it can be embedded without attribution obligations.
