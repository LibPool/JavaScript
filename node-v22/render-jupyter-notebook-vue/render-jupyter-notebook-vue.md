# render-jupyter-notebook-vue

> 标签: JavaScript

## 简介

The render-jupyter-notebook-vue is a vue component that renders the notebook file in vue. render-jupyter-notebook-vue是一个vue组件，实现了notebook文件在vue中的渲染。
