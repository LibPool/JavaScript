# iobroker.sungrow-local

> 标签: battery, inverter, ioBroker, modbus, pv, solar, sungrow, winet, winet-s2

## 简介

Sungrow hybrid inverter and battery via WiNet-S2 Modbus TCP - one connection, own poll interval per register group.
