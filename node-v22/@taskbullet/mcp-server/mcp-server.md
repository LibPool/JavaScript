# @taskbullet/mcp-server

> 标签: agent-tools, ai-agent, ai-agent-handoff, ai-tools, anthropic, autonomous-agent, claude, human-in-the-loop, llm-tools, mcp, mcp-server, model-context-protocol, task-delegation, taskbullet, va, virtual-assistant

## 简介

MCP server for delegating tasks from AI agents (Claude, GPT, Grok) to real human virtual assistants. Call get_balance, then delegate_task. Human-in-the-loop handoff via the TaskBullet API.
