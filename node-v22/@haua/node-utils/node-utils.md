# @haua/node-utils

> 标签: node, utils

## 简介

基本上只能在node中使用，如生成 stream.Writable 等。这个仓库的代码是无依赖的。以后如果有小工具是要依赖的，会单独一个项目，以免只需要少数工具时也安装那么多依赖。
