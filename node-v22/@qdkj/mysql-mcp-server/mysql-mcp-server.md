# @qdkj/mysql-mcp-server

> 标签: database, ddl, mcp, model-context-protocol, mysql, sql

## 简介

MySQL 数据库操作 MCP 服务端，提供表查询、表结构查询、预编译 SQL 执行、DDL 执行能力；通过 MCP 协议与 Cursor/Claude Desktop/CodeBuddy 等 AI 客户端通信。
