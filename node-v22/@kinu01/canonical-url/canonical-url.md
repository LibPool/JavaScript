# @kinu01/canonical-url

> 标签: canonical, canonicalize, commonjs, dedupe, esm, normalize, tracking-parameters, typescript, url, utm

## 简介

Turn a URL into a stable identity key: lowercase host, no fragment, tracking parameters removed, no trailing slash. Nothing else changes, so the result still opens. Zero dependencies, ESM and CommonJS, TypeScript types.
