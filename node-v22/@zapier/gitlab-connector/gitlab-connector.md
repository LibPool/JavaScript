# @zapier/gitlab-connector

> 标签: agent, ai, automation, connector, gitlab, mcp, skills, tools, zapier

## 简介

Agent-callable GitLab tools — manage issues and merge requests, review diffs, commit files, run pipelines, and search. Use when the user mentions GitLab or wants to review or merge an MR, commit code, run CI, or manage issues — even if they don't name Git
