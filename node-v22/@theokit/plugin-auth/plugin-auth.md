# @theokit/plugin-auth

> 标签: auth, saas, theokit, theokit-plugin

## 简介

Convenience meta-package for @theokit/sdk auth: bundles @theokit/auth-google + @theokit/auth-github + @theokit/auth-magic-link + createSaasAuth helper.
