# @kira905/dsh-nurse

> 标签: deepseek-harness, dsh, incident, isolated-instance, repair, rollback, safe-mode, whitelist, windows

## 简介

Safe-mode repair layer for DeepSeek Harness (DSH): launch an official-plugins-only instance in an isolated home/port, collect the scene, validate a repair proposal against a whitelist, execute with pre-write backups, verify, and roll back byte-exactly. Ze
