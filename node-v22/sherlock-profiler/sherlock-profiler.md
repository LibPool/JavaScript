# sherlock-profiler

> 标签: agent, android, claude, claude-code, cpu, electron, ios, mcp, memory, performance, profiler, rust, startup, tauri

## 简介

An agentic profiler. Sherlock launches or attaches to your app, measures startup, CPU, memory, memory bandwidth, GPU and network live, and tells you where the time and memory went.
