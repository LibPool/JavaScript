# @mocanvas/mocanvas

> 标签: canvas, diagram, drawing, editor, infinite-canvas, react, rust, sdk, tldraw, wasm, webassembly, webgl, whiteboard

## 简介

An infinite-canvas SDK for the web: React component, default shapes, tools and UI, on a Rust/WebAssembly engine.
