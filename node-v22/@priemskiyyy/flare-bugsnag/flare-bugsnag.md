# @priemskiyyy/flare-bugsnag

> 标签: adapter, bugsnag, error-reporting, error-tracking, flare, react-native, typescript

## 简介

Bugsnag destination for flare: event-local user, metadata, severity and breadcrumbs through notify's onError callback, for the browser and React Native, over an SDK you inject.
