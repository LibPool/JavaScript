# @rnrs/runtime

> 标签: JavaScript

## 简介

Experimental framework for React Native modules written as TypeScript specs plus Rust: JS runtime, Android and iOS (JSI) backends, the browser Wasm backend, the framework spec and Rust crates. The rnrs CLI is @rnrs/cli.
