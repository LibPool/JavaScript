# @conciso/design-system-mcp

> 标签: ai, angular, claude, conciso, copilot, cursor, design-system, mcp, mcp-server, model-context-protocol, storybook

## 简介

MCP-Server für Consumer des Conciso Design System, beantwortet docs-list, docs-show und docs-show-story über stdio aus einem mitgelieferten Storybook-Snapshot, ohne Netzzugriff.
