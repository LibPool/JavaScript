# @graphmemory/browser-mcp

> 标签: agent, ai, automation, browser, claude, headless, mcp, model-context-protocol, playwright, scraping

## 简介

MCP server that gives AI agents a full browser — open pages, read content, click, type, scroll, take screenshots, manage tabs, and emulate devices.
