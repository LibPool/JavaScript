# @dumbshow/core

> 标签: animation, canvas, diagram, engine, timeline

## 简介

The framework-free core of dumbshow: the language-pack contract, the timeline engine and headless player, the render core, the transcript projection, the editor's document model and drag mechanics, and the exporters.
