# @react-dotnetcore/runtime

> 标签: aspnetcore, hydration, mvc, react, react-dotnetcore, ssr, vite

## 简介

React-as-MVC-view runtime for ReactDotNetCore.AspNetCore: component registry, SSR renderer, client hydration, and a Node SSR sidecar (production + Vite HMR dev).
