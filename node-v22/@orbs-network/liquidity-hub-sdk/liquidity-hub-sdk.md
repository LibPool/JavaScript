# @orbs-network/liquidity-hub-sdk

> 标签: JavaScript

## 简介

`@orbs-network/liquidity-hub-sdk` lets a DEX request quotes from Orbs Liquidity Hub and execute a swap when Liquidity Hub offers a better result than the DEX's own router.
