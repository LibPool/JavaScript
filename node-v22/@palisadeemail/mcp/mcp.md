# @palisadeemail/mcp

> 标签: dkim, dmarc, dns, email-security, mcp, modelcontextprotocol, palisade, spf

## 简介

Local stdio bridge to the Palisade MCP server (email authentication: SPF, DKIM, DMARC, MTA-STS, BIMI).
