> 标签: agent, ai, ai-agent-security, atlasent, authorization, claude, cursor, execution-boundary, guardrails, mcp, mcp-server, model-context-protocol, permits, policy, windsurf

## 简介

AtlaSent MCP server: with an API key, an AI agent's consequential actions wait for organizational approval and get signed proof your auditor can check. Without a key it runs an offline, unsigned demo.
