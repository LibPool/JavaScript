# @ak3il/youtube-client

> 标签: ai-agent, captions, claude-mcp, cursor-mcp, golang, innertube, llm, mcp, model-context-protocol, nodejs, rag, subtitles, transcript, typescript, video-analysis, youtube, youtube-api, youtube-captions, youtube-chapters, youtube-client, youtube-mcp, youtube-subtitles, youtube-transcript, yt-dlp-alternative

## 简介

YouTube Client — free MCP server & Node library: transcripts with timestamps, RAG citation packs, chapters, captions, search. Native Go engine, no yt-dlp, no Python. For Cursor, Claude, and agents.
