# indeed-axi

> 标签: agent, axi, cli, hiring, indeed, playwright, toon

## 简介

AXI-compliant CLI for Indeed - a persistent authenticated browser session and agent-ergonomic primitives for driving the Indeed employer interface with Playwright.
