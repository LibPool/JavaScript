# @bmapgl-plugin/track

> 标签: 地图轨迹可视化, 实时路线轨迹展示, 百度地图轨迹展示, 路线轨迹回放

## 简介

基于百度地图GL API实现轨迹可视化能力，用于轨迹展示与回放。支持丰富的移动点类别、轨迹线样式和交互事件，以适应各类场景能力。
