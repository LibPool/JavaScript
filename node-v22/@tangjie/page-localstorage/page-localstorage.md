# @tangjie/page-localstorage

> 标签: localstoage, 数据持久化, 页面通信

## 简介

用于不适用keep-alive进行缓存时的一种解决方案。这是一个用于页面间通信的库，特别是在需要为这个页面存储很多项数据的时候，可以根据页面名称来操作存储在localStorage里面的数据
