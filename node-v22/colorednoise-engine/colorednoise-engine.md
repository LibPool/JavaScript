# colorednoise-engine

> 标签: audioworklet, brown-noise, generative, noise, pink-noise, synthesis, wav, web-audio, white-noise

## 简介

Programmable colored noise synthesis for the browser. White, pink, brown, blue and violet noise generated in an AudioWorklet, with multi-voice ADSR, JSON compositions and WAV export.
