# @gui-chat-plugin/jinglescript

> 标签: audio, gui-chat-protocol, jingle, jinglescript, mcp, player, vue

## 简介

GUI Chat Protocol plugin for JingleScript: the manageJingleScript tool, with a player view for rendered jingles (waveform, cues, beats, notes).
