# @tjfantell3113/leaflet.draw-ellipse-edited

> 标签: Leaflet, ellipse, plugin

## 简介

A plugin for leaflet that allows creating editable ellipses as well as other shapes. This package is almost entirely the work of Moebius Solutions and jjwtay.
