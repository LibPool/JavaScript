# @shinnjr/authfusion

> 标签: auth, helper, jwt, oauth, oidc, pkce, sso, token

## 简介

Zero-dependency OAuth/OIDC helper: PKCE, JWT decode, authorize-URL builder, callback parser. Provider-agnostic.
