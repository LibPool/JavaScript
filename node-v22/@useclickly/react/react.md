# @useclickly/react

> 标签: agent, ai, annotations, claude, cursor, devtools, feedback, inspector, mcp, react

## 简介

Click-to-annotate dev toolbar for React 18+ apps. Generates agent-ready prompts. Drop in one component — no config.
