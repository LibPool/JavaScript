# qinglin-ui-locale-ja-jp

> 标签: i18n, locale, qinglin-ui, 日本語

## 简介

Japanese (ja-JP) language pack for qinglin-ui. Install this alongside qinglin-ui to enable 日本語 UI text.

- npm 页面：https://www.npmjs.com/package/qinglin-ui-locale-ja-jp
