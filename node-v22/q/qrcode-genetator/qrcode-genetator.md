# qrcode-genetator

> 标签: qr, qrcode

## 简介

QR code generator, supports Numeric, Alphanumeric and Binary input mode up to lvl 40.

## 官网

- 官网：https://github.com/runn1ng/qrcode.js
- 源码仓库：git+https://github.com/runn1ng/qrcode.js.git
- npm 页面：https://www.npmjs.com/package/qrcode-genetator

- 1.0.2

## 获取地址

- npm 安装：`npm install qrcode-genetator`
- npm registry：https://registry.npmjs.org/qrcode-genetator
- Node 要求：>=0.10.x
