> 标签: market-data, nasdaq, options, questrade, questrade-api, stocks, streaming, trading, tsx, typescript, websocket

## 简介

Lightweight, zero-dependency TypeScript SDK for Questrade API with auto token refresh, rate-limit backoff, and dual WebSocket streaming & adaptive polling feeds.
