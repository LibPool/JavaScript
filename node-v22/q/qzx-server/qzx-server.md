# qzx-server

> 标签: based, koa, on, server

## 简介

> NEST.JS 整体感觉还是太重，而且集成太深，不是很灵活，koa 最原始，也最灵活，但是没有较好的注解支持。 此库就是对 koa 做了一层简易的安装，支持基本的注解，其余使用均与 koa 无差别。
