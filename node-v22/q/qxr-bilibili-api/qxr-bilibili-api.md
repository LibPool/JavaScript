# qxr-bilibili-api

> 标签: JavaScript

## 简介

基于 [哔哩哔哩-API收集整理](https://github.com/SocialSisterYi/bilibili-API-collect) 项目对接的 Bilibili 主站第三方接口，开箱即用。其中 wbi 校验算法借鉴自 [RSSHub](https://github.com/DIYgod/RSSHub)。
