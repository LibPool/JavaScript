# quick-chat-react

> 标签: chat, chat-component, chat-ui, emoji-reactions, file-upload, group-chat, lovable, messaging, react, read-receipts, real-time, realtime, supabase, typescript, unread-badge, voice-message

## 简介

The fastest way to add real-time chat to your React MVP. Drop-in component backed by Supabase — messaging, group chats, voice messages, file uploads, emoji reactions, read receipts, all via props.
