# quirkatar

> 标签: avatar, generator, identicon, lightweight, placeholder, procedural, profile, random, react, svg, vanilla-js, zero-dependency

## 简介

A free, lightweight, zero-dependency procedural avatar generator. Create unique, quirky profile pictures from any seed string.
