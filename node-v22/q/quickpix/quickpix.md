# quickpix

> 标签: bilinear, canvas, exif, image, lanczos, pica, resample, resize, thumbnail, wasm, webassembly

## 简介

High-performance image resize for browsers and Node.js. Rust/WASM accelerated, zero dependencies, pure JS fallback.
