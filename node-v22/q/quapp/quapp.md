# quapp

> 标签: ai-friendly, build, cli, development, mobile, qpp, qr-code, quapp, vite

## 简介

A lightweight CLI tool for Quapp development - start a Vite dev server with LAN QR code, build .qpp packages, and publish to Quapp Store
