# qjd-pages

> 标签: qjd-pages

## 简介

一个pagescli工具 ## 安装 ```bash npm i qjd-pages ``` ## 使用 ```json {   "scripts": {       "dev": "qjd-pages dev",       "build": "qjd-pages build",       "clean": "qjd-pages clean"   } } ``` + 开发环境：使用dev命令创建一个开发环境 + 生产环境：使用build命令打包 + 清除：使用clean 清除产出的文件
