# quicklook-thumbnail

> 标签: image, mp4, quicklook, thumbnail, video

## 简介

Use NodeJS to generate thumbnail images for all QuickLook-enabled filetypes (e.g. .mp4 videos, iMessage transcripts, text files) on Apple OSX.
