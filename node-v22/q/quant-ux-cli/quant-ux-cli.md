# quant-ux-cli

> 标签: JavaScript

## 简介

The Quant-UX-CLI tool allwos you to generate code out of your Quant-UX designs. Create a design at http://v2.quant-ux.com and run the cli to generate, CSS, HTML and Vue.js code

## 官网
