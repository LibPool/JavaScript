# qwikstart-next

> 标签: JavaScript

## 简介

A powerful CLI tool to scaffold **Next.js apps** in seconds with **TailwindCSS v4** and **Shadcn UI**, minus the clutter.   Perfect for developers who want to **start building immediately**, without wrestling with configs.
