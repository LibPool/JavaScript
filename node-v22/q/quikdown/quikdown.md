# quikdown

> 标签: airgapped, autolink, bidirectional, browser, commonmark, editor, fence, gfm, html, lightweight, llm, markdown, markdown-bidirectional, markdown-code, markdown-editor, markdown-mermaid, markdown-parser, markdown-to-html, mcp, md, model-context-protocol, node, nodejs, offline, parser, plugin, sanitization, standalone, streaming, task-lists, undo-redo, xss-protection, xss-safe, zero-dependencies

## 简介

Small, safe, bidirectional Markdown parser and editor with streaming, undo/redo, rich fences, MCP tools, and a standalone airgapped build. Zero runtime deps. Browser and Node.js.
