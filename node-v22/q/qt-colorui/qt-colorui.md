# qt-colorui

> 标签: Taro, colorui, raro-colorui

## 简介

Taro color-ui 是一款基于 Taro 框架并且联合 Color-UI CSS 库开发的多端 UI 组件库（支持小程序端和H5端, 代码来源mp-colorui 做了3.0封装
