> 标签: bug-reporting, claude-desktop, cursor, e2e-testing, mcp, mcp-server, model-context-protocol, playwright, quickcast, screen-recorder, screen-to-action, sop-generator

## 简介

High-performance Model Context Protocol (MCP) server for QuickCast Screen-to-Action Protocol: automated bug reporting, Playwright E2E test scaffolding, and SOP generation from QuickCast recordings.
