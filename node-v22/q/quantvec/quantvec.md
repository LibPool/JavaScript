# quantvec

> 标签: ann, approximate-nearest-neighbor, edge, embeddings, isomorphic, quantization, rabitq, rag, simd, similarity-search, turboquant, typescript, vector, vector-database, vector-search, wasm

## 简介

Data-oblivious, zero-training vector quantization and nearest-neighbor search for TypeScript — a clean-room implementation of Google Research's TurboQuant. Runs in Node, browsers, Bun, and edge/serverless runtimes.
