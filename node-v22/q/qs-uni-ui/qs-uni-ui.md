# qs-uni-ui

> 标签: JavaScript

## 简介

当前 `uni-ui` 版本可以在 `nvue` 页面中使用，因为 `nvue` 的特性，故 `uni-ui` 大部分组件样式有较大改动，您如果觉得最新的 `nvue` 版本有兼容问题，可以使用 [vue](https://github.com/dcloudio/uni-ui/tree/last-vue)  版本
