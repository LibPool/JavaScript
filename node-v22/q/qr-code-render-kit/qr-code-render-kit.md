# qr-code-render-kit

> 标签: code, generator, qr, qr code generator, qrcode, qrcode generator, qrcode-generator, react qr code, react qr code generator

## 简介

A type safe, typescript-first SVG QR code generator that supports multiple file download formats, styling options, customization options for refinded QR code generation.
