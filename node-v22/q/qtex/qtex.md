# qtex

> 标签: academic, cli, cloud-latex, compiler, document, fast, latex, latex-compiler, markdown-to-pdf, paper, pdf, pdflatex, rust, tectonic, tex, thesis, typesetting, xelatex

## 简介

Ultra-fast cloud LaTeX compiler. Compile .tex documents in milliseconds without installing TeXLive or MikTeX. Zero config, sub-second builds, live watch mode.
