# querystring-number

> 标签: JavaScript

## 简介

1. 极小 gzip 0.3k 2. 可以选择性的将 string 转为 number 3. 若 string 转为 number 之后，和原来的值有差异，则继续使用 string，如位数超过 double 的最大长度
