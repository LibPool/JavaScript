# quant-swarm-mcp

> 标签: backtest-audit, mcp, model-context-protocol, point-in-time, quant, trading

## 简介

Node launcher for the quant-swarm MCP servers (swarm-data-mcp, swarm-warden-mcp, swarm-gym-mcp): pre-trade checkers that gate live capital. Shells to uvx for stdio, or npx mcp-remote for the hosted endpoints.
