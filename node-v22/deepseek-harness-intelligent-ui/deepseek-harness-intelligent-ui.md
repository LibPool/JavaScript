# deepseek-harness-intelligent-ui

> 标签: deepseek-harness, dsh, dsh-plugin, generative-ui, intelligent-ui

## 简介

DeepSeek Harness Intelligent UI: generative, interactive UI in the chat (declarative component catalog + sandboxed streaming HTML widgets), inspired by CopilotKit OpenIntelligentUI.
