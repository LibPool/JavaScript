# @mimi-ng/cli

> 标签: angular, angular-components, component-library, design-system, mimi, ng-add, schematics, shadcn, tailwind, tailwindcss, tailwindcss-v4, ui, ui-components

## 简介

Angular + Tailwind CSS 4 UI components that a CLI copies into your project, so you own the code. Schematics for ng add and ng generate.
