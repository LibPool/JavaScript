# @hzblj/kara-sx

> 标签: expo, kara-ui, react-native

## 简介

The token-typed sx styling engine behind @hzblj/kara-ui: one surface resolved into SwiftUI modifiers, Compose modifiers or a React Native style, and the accessibility props translated the same way.
