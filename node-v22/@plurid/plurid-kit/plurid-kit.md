# @plurid/plurid-kit

> 标签: cli, framework, plurid, react, server-side rendering

## 简介

Batteries-included framework for building and serving plurid apps - the `plurid` CLI + plurid.config.ts + conventions on top of @plurid/plurid-react-server.
