# @npmenv/type

> 标签: @npmenv/type, npmenv, typescript环境

## 简介

tsconfig.json中对每个配置选项均作了汉化处理,方便初学者使用 ```sh npm init cnpm install typescript --save npx tsc --init cnpm install @types/node --dev-save npx tsc ```
