# @clawos-dev/extension-sdk

> 标签: clawos, extension, sdk

## 简介

Optional TypeScript helpers for ClawOS extensions (UI host bridge + server method wrapper). The ClawOS extension protocol is language-agnostic — see openclaw-plugin-extensions/PROTOCOL.md.
