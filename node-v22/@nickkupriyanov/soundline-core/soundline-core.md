# @nickkupriyanov/soundline-core

> 标签: audio, dom, headless, media, music, player, playlist, state-machine

## 简介

Framework-free core of Soundline: the player controller, the derived view model, the reducer, the playback engine and track source contracts, copy and stable class names.
