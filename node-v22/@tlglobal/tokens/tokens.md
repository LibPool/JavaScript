# @tlglobal/tokens

> 标签: JavaScript

## 简介

Design tokens for TuringLab products — CSS custom properties for color, type, spacing, radius and shadow, plus brand logo assets. Pure CSS: no build step, no React dependency. Usable from any surface (React, plain HTML, email templates, a marketing site).
