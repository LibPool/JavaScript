# @monarcpro/motion

> 标签: ai agents, animation, lower third, mcp, motion graphics, prores, render, svg, title, video

## 简介

MONARC Motion: brand-aware, voice-synced motion graphics as code. Packs of ready-made graphics, a CLI, a Node API and an MCP server that render them to ProRes 4444, WebM, MP4, GIF, PNG or SVG.
