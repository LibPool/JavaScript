# coursework-author

> 标签: coursework, curriculum, literature-survey, self-study, syllabus

## 简介

Author a structured, module-based self-study course on any technical topic — syllabus blueprint, one README per module, a fixed module anatomy, and two verification gates (memory-less logic review + literature survey).
