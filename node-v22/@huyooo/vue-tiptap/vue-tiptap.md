# @huyooo/vue-tiptap

> 标签: JavaScript

## 简介

面向 Vue 3 的 TipTap 富文本编辑器组件库，封装了常用正文编辑、目录、标题、表格、任务列表、图片上传、图片缩放、图片对齐、图片拖拽、图片工具栏等交互。
