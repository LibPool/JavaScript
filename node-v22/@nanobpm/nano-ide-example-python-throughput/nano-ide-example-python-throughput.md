# @nanobpm/nano-ide-example-python-throughput

> 标签: camunda, falcon, nano-ide-example, nano-ide-ext, nanobpm, python, throughput

## 简介

Distributable example app for the Nano RAD IDE: a Python throughput demo (async producer + JobWorker on the official camunda-orchestration-sdk) that runs one code path against Camunda 8 (REST) or Nano (Falcon).
