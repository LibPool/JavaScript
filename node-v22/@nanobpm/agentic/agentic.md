# @nanobpm/agentic

> 标签: agentic, blackboard, channel, cockpit, conformance, demand, nanobpm, presence, protocol, relay, session, transcript

## 简介

The Nano agentic protocol (ADR 0056): one app-tier channel carrying agent presence/registry, demand×supply, a shared blackboard and live terminal relay — with the wire contract, channel/hub, family modules and the operator cockpit, as subpath exports.
