# @elaanio/elements

> 标签: custom-elements, elaan, inbox, notifications, push, web-components

## 简介

Framework-agnostic Web Components for Elaan: <elaan-bell>, <elaan-feed>, <elaan-preferences>. Works in any page or framework.
