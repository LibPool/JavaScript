# @glowbox/extras

> 标签: 3d, animation, font, gif, glowbox, image, led, marquee, scroller, text, voxel

## 简介

Content helpers for @glowbox/led-grid — GIF/image animation player, bundled 5×7 bitmap LED font, text + marquee scroller, painted onto the LED grid.
