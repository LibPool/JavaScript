# @jpyc-skill/ec-purchase-mcp

> 标签: ai-agent, claude, cursor, ec, ecommerce, eip-3009, gasless, jpyc, mcp, model-context-protocol, stablecoin, x402

## 简介

MCP server that lets any LLM agent (Claude Desktop / Cursor / OpenAI Agents SDK) buy products on JPYC EC Platform via x402 — gasless EIP-3009 payments over HTTP.
