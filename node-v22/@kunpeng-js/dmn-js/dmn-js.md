# @kunpeng-js/dmn-js

> 标签: decision model, decision table, dmn, drd, modeler, toolkit, web modeler

## 简介

A DMN web modeler/toolkit — multi-view kernel (DRD + decision table + literal expression + boxed expression), built on diagram-js and table-js
