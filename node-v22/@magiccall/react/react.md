# @magiccall/react

> 标签: conferencing, hooks, react, rtc, video, webrtc

## 简介

React hooks over the MagicCall browser SDK (useRoom, useRoomEvents, useParticipants, useLocalParticipant, useConnectionState, useActiveSpeakers, useChat, useIsRecording, useTranscript, useCameraEffect, useMicrophoneEffect).
