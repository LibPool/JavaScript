# @sitharaj88/winctl

> 标签: automation, claude, connector, desktop, mcp, modelcontextprotocol, screenshot, ui-automation, win32, windows

## 简介

WinCtl — full Windows desktop control for Claude and other MCP clients: screen capture, UI Automation, synthetic input, window and process management, files and shell, behind tiered permissions with audit logging.
