# @fusionvault/pipeline

> 标签: etl, fusionvault, lineage, pipeline

## 简介

The pure core of FusionVault transformation pipelines: definition types, the publish gate, the step-kind registry, DAG ordering, column-level lineage and the expectation evaluator. No I/O.
