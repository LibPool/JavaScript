# @logan-robbins/smartypants

> 标签: architecture, claude, claude-code, codex, diagram, drift, intent, jev, mermaid, meta, pi-package, system-design

## 简介

Live Mermaid-style system diagram, compact IntentCode memory, and intent-drift flags for coding agents. Claude decides and writes through your Claude Code sign-in (Sonnet 5.5 decides by default; Typesafe Jev optional).
