# @loomail/browser

> 标签: analytics, browser, events, lifecycle-email, loomail, nextjs, nuxt, react, tracking, vue

## 简介

Browser client for Loomail: identify people and track events from any web app, with React and Vue helpers. Uses a publishable key.
