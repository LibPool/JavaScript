# @pith-hash/pith-text

> 标签: fingerprint, hashing, minhash, similarity, text

## 简介

Text fingerprints SDK: NFC canonicalisation, word 3-shingles and a 128-word MinHash signature via the pith-text Rust cdylib (koffi, prebuilt)
