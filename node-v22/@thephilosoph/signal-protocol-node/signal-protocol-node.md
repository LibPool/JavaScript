# @thephilosoph/signal-protocol-node

> 标签: double-ratchet, e2ee, encryption, end-to-end-encryption, messaging, nestjs, signal, signal-protocol, typescript, x3dh

## 简介

TypeScript implementation of the Signal Protocol (X3DH + Double Ratchet) for Node.js and NestJS: end-to-end encrypted messaging with pluggable storage.
