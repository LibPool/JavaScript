# @kud/gh-cockpit

> 标签: cli, cockpit, github, inbox, ink, pull-request, react, terminal, tui

## 简介

A configurable GitHub cockpit for the terminal — your PRs, reviews and issues in one Ink TUI, grouped by whose move it is.
