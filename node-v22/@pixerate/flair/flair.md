# @pixerate/flair

> 标签: ai-agents, animation, editor, effects, generative, motion-graphics, react, shaders, shadertoy, svelte, svg, webgl2

## 简介

Web visual effects and motion graphics: WebGL2 shader effects, animated vector effects, a catalog of ready-made effects, and a UI-agnostic, agent-ready effect editor.
