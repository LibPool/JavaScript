# @epic-web/totp

> 标签: 1password, 2fa, authentication, authy, google authenticator, one time password, otp, time-based one time password, totp, two-factor

## 简介

Create and verify cryptographically secure Time-based One-time Passwords (TOTP) using the HMAC-based One-time Password (HOTP) algorithm.
