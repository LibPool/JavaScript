# @grigoriychernish/widget-chat-opti

## 简介

Сучасний, адаптивний та високопродуктивний віджет чату для штучного інтелекту, створений на базі **Svelte 5 (Runes)**, **TypeScript** та **Vite**. Проект включає в себе інтерактивну панель керування для швидкого налаштування дизайну та миттєвої генерації
