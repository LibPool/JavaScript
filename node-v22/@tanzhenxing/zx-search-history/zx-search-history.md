# @tanzhenxing/zx-search-history

> 标签: Vue组件, 关键词高亮, 删除单条记录, 搜索历史, 搜索记录, 清空所有记录

## 简介

搜索历史组件，用于展示和管理用户的搜索历史记录，支持关键词高亮、删除单条记录、清空所有记录等功能。
