# @tanzhenxing/zx-fixed-nav

> 标签: 导航, 悬浮, 悬浮导航

## 简介

`zx-fixed-nav` 是一个悬浮导航组件，提供悬浮收起体验交互，用于快捷导航。支持 H5、小程序、App 多端。
