# @tanzhenxing/zx-pull-refresh

> 标签: pull, refresh

## 简介

`zx-pull-refresh` 是一个通用的下拉刷新组件，支持 H5、小程序和 App 端。它提供了下拉刷新的交互操作，允许用户通过向下滑动页面来加载最新内容。
