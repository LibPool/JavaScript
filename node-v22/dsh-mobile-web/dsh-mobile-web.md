# dsh-mobile-web

> 标签: deepseek, deepseek-harness, dsh, dsh-plugin, mobile, phone, pwa, remote-access, sse

## 简介

掌上 dsh —— DSH 的手机端完整聊天界面：6 位码配对、设备信任、工作区/会话/聊天、SSE 实时流，可经局域网或公网反代访问。
