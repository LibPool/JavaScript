# @jwbz/bili-downloader

> 标签: bilibili, download, ffmpeg, obsidian, whisper

## 简介

B站下载器——独立 NodeJS Web 工具：启动本地服务并打开网页，在网页内完成 B站视频解析、分批/分P 选择、下载（多 CDN 节点切换 + 下载原件 7 天本地缓存）、多段落剪辑（分开/合并交付）、压缩（ffmpeg，产物 ffprobe 校验兜底）、转文字（faster-whisper）、交付（移入交付目录 + 剪贴板 wikilink）与文献笔记快速流程（AI 直读 bz 配置，生成标题/标签/简介并润色正文落 vault 文献盒）
