# jg-postgres

> 标签: advisory-locks, node-postgres, pagination, pg, postgres, postgresql, transactions

## 简介

PostgreSQL helpers for node-postgres: safe transactions, advisory locks, SQLSTATE checks, cursor pages, and ordered lists.
