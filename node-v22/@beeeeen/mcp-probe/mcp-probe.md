> 标签: agent, anthropic, ci, claude, conformance, json-rpc, llm, mcp, mcp-lint, mcp-server, mcp-test, mcp-testing, mcp-validator, model-context-protocol, testing, tools

## 简介

Conformance and robustness test suite for Model Context Protocol (MCP) servers. Runs in CI, zero dependencies. Catches stdout pollution, broken tool schemas, and bad JSON-RPC error handling before your agent does.
