# @forthtilliath/forth-ui

> 标签: JavaScript

## 简介

Higher-level, opinionated React components built on top of [`@forthtilliath/shadcn-ui`](../shadcn-ui) primitives. Where shadcn-ui gives you the building blocks (`Button`, `Popover`, `Command`, ...), forth-ui assembles them into complete, batteries-include
