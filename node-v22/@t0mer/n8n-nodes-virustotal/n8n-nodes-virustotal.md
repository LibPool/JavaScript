# @t0mer/n8n-nodes-virustotal

> 标签: ioc, malware, n8n, n8n-community-node-package, security, threat-intelligence, virustotal

## 简介

n8n community node for the VirusTotal API v3: look up and scan files, URLs, domains and IPs, get a normalized verdict, and watch indicators for changes.
