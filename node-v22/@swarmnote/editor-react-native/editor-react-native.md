# @swarmnote/editor-react-native

> 标签: JavaScript

## 简介

React Native plumbing + WebView bundle for @swarmnote/editor-core. Provides Comlink bridge hooks (useEditorBridge / useEditorFormatting), I18nProvider, and the bundled editor WebView HTML. UI primitives via the shadcn-style registry.
