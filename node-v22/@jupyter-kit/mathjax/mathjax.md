# @jupyter-kit/mathjax

> 标签: ipynb, jupyter, jupyter-kit, latex, math, mathjax, notebook, renderer

## 简介

MathJax (bundled) plugin for @jupyter-kit/core. Renders TeX via rehype-mathjax during markdown processing.
