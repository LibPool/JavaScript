# @sym-bot/melotune-plugin

> 标签: cat7, claude-code, claude-plugin, melotune, mesh-cognition, mmp, music, sym, vibe-coding

## 简介

Claude Code plugin — turn the Claude Code console into a MeloTune music interface. View the upcoming queue, see current track, play, skip.
