# @perryts/mongodb

> 标签: aot, bson, bun, database, driver, llvm, mongo, mongodb, native, nodejs, op-msg, perry, perryts, scram, tls, typescript, wire-protocol

## 简介

Pure-TypeScript MongoDB wire-protocol driver. Runs on Node.js and Bun, and compiles to a native binary via Perry (LLVM). Zero native dependencies.
