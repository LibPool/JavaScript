# @samerecord/server

> 标签: drizzle, entity-resolution, hono, matcher, pgvector, samerecord

## 简介

The samerecord matcher — Hono-based HTTP service for entity resolution against PostgreSQL + pgvector. Runs match queries, persists active-learning feedback, calibrates per-scope thresholds, surfaces duplicate clusters. BYO embedding/parse functions — zero
