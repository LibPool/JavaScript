# @mstblockchain/mst-vibe-kit

> 标签: blockchain, cli, create-mst-app, hardhat, mst, scaffold

## 简介

Scaffold a full-stack MST blockchain project — Hardhat contracts, a Next.js frontend, and testnet/mainnet config baked in for MST Blockchain. This is a CLI tool to create a new MST project with the necessary boilerplate code and configurations.
