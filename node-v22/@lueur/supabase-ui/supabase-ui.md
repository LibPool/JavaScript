> 标签: composables, nuxt, nuxt-components, nuxt-module, nuxt-supabase, nuxt3, supabase, supabase-auth, supabase-nuxt, supabase-ui, vue3

## 简介

A Nuxt 3 module for seamless integration with Supabase, offering global components, composables, and .env-based configuration for effortless use of Supabase features in Nuxt apps.
