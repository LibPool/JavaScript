# @nicknisi/pi-workflows

> 标签: pi, pi-coding-agent, pi-package

## 简介

Model-facing front door to the first-party workflow engine — run JS workflow scripts over the subagent runtime, replacing the third-party @quintinshaw/pi-dynamic-workflows extension
