# @signalsumo/mcp

> 标签: claude, llm-tools, mcp, model-context-protocol, seo, signalsumo

## 简介

Model Context Protocol server for SignalSumo — lets Claude and other LLMs read SEO data, run audits, and check rankings via the SignalSumo API.
