# @claudewerk/bridge-substrate

> 标签: JavaScript

## 简介

The L2 substrate: named, durable coordination objects that live on both sides of a bun-reliable-ws connection. Composes bun-mq + bun-reliable-ws + envelope-codec + mutual-key-auth.
