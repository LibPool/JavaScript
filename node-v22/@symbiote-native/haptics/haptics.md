# @symbiote-native/haptics

> 标签: angular, expo-haptics, react, react-native, solid, svelte, symbiote-native, taptic-engine, vibration, vue

## 简介

expo-haptics wrapped for SymbioteNative — one framework-agnostic core, built once and reachable from the React, Vue, Svelte, Solid, and Angular adapters. Impact/notification/selection vibration feedback via iOS's Taptic Engine and Android's Vibrator API.
