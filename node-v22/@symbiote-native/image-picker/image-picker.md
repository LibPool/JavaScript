# @symbiote-native/image-picker

> 标签: angular, camera, expo-image-picker, image-picker, react, react-native, solid, svelte, symbiote-native, vue

## 简介

expo-image-picker wrapped for SymbioteNative — one framework-agnostic core, built once and reachable from the React, Vue, Svelte, Solid, and Angular adapters. Opens the system UI for picking an image/video or taking a photo with the camera.
