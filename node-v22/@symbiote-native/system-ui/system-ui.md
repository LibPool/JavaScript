# @symbiote-native/system-ui

> 标签: angular, background-color, react, react-native, solid, svelte, symbiote-native, system-ui, vue

## 简介

expo-system-ui wrapped for SymbioteNative — one framework-agnostic core, built once and reachable from the React, Vue, Svelte, Solid, and Angular adapters. Sets and reads the root view's background color.
