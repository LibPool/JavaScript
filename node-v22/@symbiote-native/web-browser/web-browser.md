# @symbiote-native/web-browser

> 标签: angular, in-app-browser, oauth, react, react-native, solid, svelte, symbiote-native, vue

## 简介

expo-web-browser wrapped for SymbioteNative — one framework-agnostic core, built once and reachable from the React, Vue, Svelte, Solid, and Angular adapters. In-app browser (SFSafariViewController / Android Custom Tabs) and the OAuth auth-session flow.
