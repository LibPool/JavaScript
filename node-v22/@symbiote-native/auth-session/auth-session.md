# @symbiote-native/auth-session

> 标签: angular, auth-session, expo-auth-session, oauth, oauth2, openid, react, react-native, solid, svelte, symbiote-native, vue

## 简介

expo-auth-session ported for SymbioteNative — one framework-agnostic core, built once and reachable from the React, Vue, Svelte, Solid, and Angular adapters. PKCE-based OAuth2/OpenID Connect flow over @symbiote-native/web-browser, @symbiote-native/crypto,
