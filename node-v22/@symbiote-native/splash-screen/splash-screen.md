# @symbiote-native/splash-screen

> 标签: angular, bootsplash, react, react-native, solid, splash-screen, svelte, symbiote-native, vue

## 简介

Third-party splash-screen native module wrapped for SymbioteNative — one framework-agnostic core, built once and reachable from the React, Vue, Svelte, Solid, and Angular adapters.
