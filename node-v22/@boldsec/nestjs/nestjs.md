# @boldsec/nestjs

> 标签: appsec, authorization, bola, idor, monitoring, nestjs, security

## 简介

BoLD live authorization monitoring for NestJS (9/10/11): one global interceptor watches your routes for cross-user access (BOLA/IDOR), function-level (BFLA), mass-assignment (BOPLA), and tenant-isolation risks. Metadata only, fail-safe, zero extraction lo
