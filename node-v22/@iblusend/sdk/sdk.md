# @iblusend/sdk

> 标签: api, facetime, iblusend, imessage, messaging, sdk, sms, webhooks

## 简介

Official TypeScript SDK for the iBluSend iMessage API: send texts, media, voice memos and tapbacks, read conversations and groups, manage contacts and opt-out, verify webhooks, prepare FaceTime calls. Zero dependencies.
