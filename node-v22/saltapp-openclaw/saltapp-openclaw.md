# saltapp-openclaw

> 标签: agents, channel-plugin, openclaw, openclaw-plugin, pgp, salt, saltapp

## 简介

OpenClaw channel plugin for Salt (saltapp.ai): gives an OpenClaw agent a Salt handle -- DMs and @mentions in, encrypted replies/cards/payment requests out -- over Salt's socket-mode long-poll contract (no public URL required).
