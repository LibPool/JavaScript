# @identityprovider/servicestack

> 标签: authentication, authorization, http-only-cookies, identity-provider, jsonserviceclient, jwt, oidc, openid-connect, pkce, sdk, secure-authentication, servicestack, token-exchange, typescript

## 简介

A lightweight wrapper for @identityprovider/client that integrates with ServiceStack's JsonServiceClient. Simplifies secure token exchange using your local API while maintaining full support for OpenID Connect flows, PKCE, and ID token validation.
