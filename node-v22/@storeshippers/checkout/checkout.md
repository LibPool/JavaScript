# @storeshippers/checkout

> 标签: checkout, delivery, ship, shipping, tracking

## 简介

StoreShippers has a shipping API that connects you with 100+ local and global carriers. This is a client library for accessing the Checkout SLA API from StoreShippers. It provides a standard interface for communicating with the StoreShippers platform.
