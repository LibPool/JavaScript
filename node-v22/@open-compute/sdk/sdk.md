# @open-compute/sdk

> 标签: JavaScript

## 简介

Capability-scoped Cloudflare-compatible management SDK for [open-compute](https://open-compute.dev) (`ocd`). The package exposes exactly the operations that `ocd` has qualified against the pinned official Cloudflare OpenAPI snapshot, plus open-compute-onl
