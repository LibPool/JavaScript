# @ronnakamoto/fnv-1a

> 标签: algorithm, fast, fnv, fnv1a, hash

## 简介

This is a TypeScript implementation of FNV-1a Hash. Fowler–Noll–Vo (or FNV) is a non-cryptographic hash function which is fast and simple in design.
