# @nl-framework/devtools

> 标签: bun, dashboard, devtools, nl-framework, observability

## 简介

Non-production devtools dashboard for NL Framework: live API performance, module/service dependency graph, and data-model explorer. Mounts as a plugin module and refuses to arm in production.
