# @nl-framework/testing

> 标签: bun, dependency-injection, test-harness, testing

## 简介

First-party testing utilities for nl-framework: testing module builder with provider/guard/interceptor/filter overrides, plus in-process HTTP, GraphQL, and microservice harnesses.
