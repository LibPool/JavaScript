# @fu1996/i18n-translate-tool

> 标签: JavaScript

## 简介

> 因为每次提取出的带有中文的原js 文件，都要手动去复制出中文，然后粘贴进谷歌浏览器，获取到复制结果以后，再把结果粘贴到 js 文件中，流程太长，且人工容易出错，所以有了此款工具。
