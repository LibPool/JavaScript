# @vurb/oauth

> 标签: ai, authentication, device-flow, llm, mcp, oauth, rfc-8628, token-manager, vurb

## 简介

OAuth 2.0 Device Authorization Grant (RFC 8628) for MCP servers built with vurb. Provides secure token storage, device flow authentication, and middleware integration.
