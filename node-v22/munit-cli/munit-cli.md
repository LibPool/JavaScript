# munit-cli

> 标签: ci, cycling74, junit, lint, linter, max, max-msp, maxmsp, maxpat, testing, unit-testing

## 简介

The mUnit command line for Max: lint patcher files anywhere (munit lint), run a test suite in Max (munit run) and set up a new one (munit init)
