# @stefangordon/fqdb

> 标签: browser, download-queue, file-queue, idb, indexeddb, persistent, queue, upload-queue, web-locks

## 简介

Persistent, indexed file queue for the browser. IndexedDB storage, Web Locks single-writer election, O(1) stats, scales to millions of items.
