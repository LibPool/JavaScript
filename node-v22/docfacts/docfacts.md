# docfacts

> 标签: cli, docs-as-code, documentation, fact-checking, hallucination, technical-writing, verification

## 简介

Check a technical document against the reference it was written from. Reports commands, flags, variables, exit codes and endpoints the reference does not support. Runs nothing, sends nothing.
