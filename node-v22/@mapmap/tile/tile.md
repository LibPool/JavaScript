# @mapmap/tile

> 标签: geojson, mapmap, mvt, pmtiles, tiler, vector-tiles, wasm

## 简介

Tile a GeoJSON file into a PMTiles archive of vector tiles, on your own machine or in the browser. The MapMap tiler, compiled to WebAssembly.

## 官网

- 官网：https://mapmap.ai/docs/self-host#tile-your-own-data
- npm 页面：https://www.npmjs.com/package/@mapmap/tile
