# @trudbot/qqbot-api

> 标签: JavaScript

## 简介

一个极简 TypeScript QQ Bot 私聊工具类：基于 QQ Bot WebSocket Gateway 接收 C2C 私聊消息，并提供私聊文本、流式 Markdown、图片发送 API。

## 官网

- npm 页面：https://www.npmjs.com/package/@trudbot/qqbot-api
