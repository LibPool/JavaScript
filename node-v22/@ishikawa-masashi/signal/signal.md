# @ishikawa-masashi/signal

> 标签: JavaScript

## 简介

イベントリスナー(イベント実行時に動く関数)の登録を行い、必要な時にその登録したイベントリスナーを実行できるライブラリです。Typescriptで書かれているので型安全です。
