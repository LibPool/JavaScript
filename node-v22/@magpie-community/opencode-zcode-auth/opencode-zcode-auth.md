# @magpie-community/opencode-zcode-auth

> 标签: bigmodel, coding-plan, glm, magpie, opencode, opencode-plugin, z.ai, zcode

## 简介

OpenCode provider plugin: signs in to Z.ai's or BigModel's (智谱) GLM Coding Plan as ZCode does, including team seats and ZCode's Start Plan
