# @kontsedal/olas-codemod

> 标签: codemod, migration, olas, ts-morph, upgrade

## 简介

Codemod for upgrading an Olas app from 0.8 to 1.0: the renames, the root handle, required ids, plugin meta and the new async contexts, with a TODO list for what needs a human.
