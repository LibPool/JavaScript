# @kontsedal/olas-eslint-plugin

> 标签: eslint, eslint-plugin, eslintplugin, lint, olas

## 简介

ESLint rules for Olas apps: no React hooks in controllers, definitions at module scope, synchronous factories, the optimistic-write recipe, test helpers kept in tests, and abort signals passed on.
