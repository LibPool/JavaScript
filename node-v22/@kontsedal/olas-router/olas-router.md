# @kontsedal/olas-router

> 标签: controller-tree, olas, react-router, reactive, router, signals, state-management, tanstack-router

## 简介

Olas router bridge — scopes + a generic Bridge component for wiring any client-side router (TanStack Router, React Router v6) into the controller tree.
