# @perflo/cli

> 标签: JavaScript

## 简介

Perflo — one CLI for your money (cash, bitcoin, ethereum) and your agent (pay-per-use services). Routes to the Perfolio backend and the Agent-mode backend behind a single, plain-language surface.
