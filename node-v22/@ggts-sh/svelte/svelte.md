# @ggts-sh/svelte

> 标签: charts, components, dataviz, ggplot2, grammar-of-graphics, interactive, plot, svelte, svelte5, visualization

## 简介

ggts: a layered grammar of graphics for Svelte 5 — ggplot2 semantics, JSON-serializable specs, agent-friendly validation, and hybrid SVG/canvas rendering. The ggts render CLI ships separately as @ggts-sh/cli.
