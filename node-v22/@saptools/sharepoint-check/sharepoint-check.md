# @saptools/sharepoint-check

> 标签: cli, diagnostics, microsoft-graph, msal, office365, sap, saptools, sharepoint

## 简介

Diagnose Microsoft SharePoint access via Microsoft Graph: verify app-only auth, list drives, walk folder trees, validate layout, and dry-run write permissions
