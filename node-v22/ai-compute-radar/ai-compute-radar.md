# ai-compute-radar

> 标签: cloud-pricing, gpu, gpu-rental, hugging-face, llm, local-ai, mcp, model-context-protocol, open-models, vram

## 简介

MCP server bridge for AI Compute Radar: which open models fit your GPU or Mac (measured GGUF sizes + computed context cache), GPU rental prices from eight sources, model momentum, weekly pick. Read-only, no auth, no telemetry.
