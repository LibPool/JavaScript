# @ai-matrx/sync

> 标签: ai-matrx, local-first, offline, powersync, supabase, sync, tanstack-db

## 简介

The ONE local-first data layer for Matrx clients: a local SQLite copy of the person's data kept in sync with the platform database by our self-hosted PowerSync, read through TanStack DB, written back through supabase-js under row security — version-condit
