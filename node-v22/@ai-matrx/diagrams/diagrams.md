# @ai-matrx/diagrams

> 标签: ai-matrx, archify, architecture, diagram, erd, layout, sequence, svg, workflow

## 简介

The AI Matrx diagram engine: Archify 3.2.0 as pure functions (validate, layout, render) for ten diagram types, plus the pure-DOM measurement script that turns a rendered diagram into numbers.
