# @ai-matrx/desktop-protocol

> 标签: ai-matrx, desktop, protocol, pty, react, relay, websocket, zod

## 简介

The one wire contract between Matrx 2 (the desktop app) and every client that drives it — phone, web app, extension, server: zod schemas for the envelope and every cap.op, the 16-byte binary frame codec, a reconnecting request/stream/credit/reattach clien
