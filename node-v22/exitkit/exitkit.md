# exitkit

> 标签: agent-skill, cli, dependency, maintenance, migration, open-weight

## 简介

Exit a risky dependency safely: scan, map usage, get an open-weight AI exit plan, cross-check its claims with code, apply in a git worktree, and emit a re-runnable Dependency Exit Capsule.
