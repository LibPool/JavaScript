# @chestnutlabs/gcode-dialects

> 标签: 3d-printing, bambu, chestnutlabs, cnc, cura, gcode, klipper, marlin, prusaslicer, reprap, slicer, toolpath

## 简介

Slicer/firmware dialect adapters for ToolpathIR annotation (DD-005). Adapters annotate metadata and optional channels — they can never alter geometry.
