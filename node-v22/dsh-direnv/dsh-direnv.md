# dsh-direnv

> 标签: deepseek-harness, devshell, direnv, dsh, dsh-plugin, envrc, nix

## 简介

Load each workspace's direnv environment into every command the DeepSeek Harness runs — automatically, per working directory. 让 DSH 每个工作区的子进程自动带上该工作区的 direnv 环境。
