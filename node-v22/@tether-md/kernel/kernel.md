# @tether-md/kernel

> 标签: agents, ai, anchoring, annotations, comments, markdown, review, suggest-mode, text-anchoring, web-annotation

## 简介

The Tether MD projection kernel: anchored comments in Markdown, W3C-selector re-anchoring that survives edits, and a byte-identical clean export — P(raw) → clean.
