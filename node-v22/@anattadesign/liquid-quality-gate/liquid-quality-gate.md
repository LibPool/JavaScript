# @anattadesign/liquid-quality-gate

> 标签: JavaScript

## 简介

Pre-push quality gate for Liquid theme repos — currently runs Lighthouse audits (performance, accessibility, best practices, SEO) against a live `shopify theme dev` server and blocks the push if any route falls below threshold.
