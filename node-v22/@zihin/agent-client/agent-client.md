# @zihin/agent-client

> 标签: agent, agent-client, ai, llm, sse, zihin

## 简介

Núcleo de invocação de agentes Zihin.ai — padrão único para n8n, Paperclip e integrações futuras. Stream direto (SSE bufferizado) + triggers assíncronos com callback.
