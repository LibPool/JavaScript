# @anilyesilkaya/marey

> 标签: ai-agents, chronophotography, claude-code, coding-agents, contact-sheet, mcp, model-context-protocol, screen-capture, screen-recording, visual-debugging

## 简介

Give AI agents eyes for motion. An MCP server that turns a short screen interaction into a timestamped, agent-readable contact sheet — so a coding agent can see what changed, not just what the screen looks like. Zero runtime dependencies.
