> 标签: adb, deepseek-harness, dsh, dsh-plugin, go, java, maven, node, platform-tools, ployenv, python, runtime-manager, rust, rustlang, version-manager

## 简介

DSH host plugin that drives the ployenv local runtime version manager from the chat (list/install/use runtimes, ship a ployenv binary, and inject its path list into session shells).
