# @mikehenken/agentable-canvas

> 标签: agent, ai, canvas, embeddable, gemini-live, lit, react, shadow-dom, voice, web-component, whiteboard

## 简介

Embeddable AI canvas web component — Lit shell + React internals + voice (Gemini Live) + a draggable-panel workspace. Drop into any page; brand via CSS tokens; isolate with Shadow DOM.
