# @yyc-jnu/dsh-skill-invocation-monitor

> 标签: deepseek-harness, dsh, dsh-plugin, monitor, observability, read-only, skill

## 简介

Skill Invocation Monitor — a read-only DSH plugin that shows, live in the Web GUI sidebar, which Agents are running and which Skill each one is invoking, with status and elapsed time. / 只读技能调用监控：在侧边栏实时展示活动 Agent 正在调用的 Skill、状态与耗时。
