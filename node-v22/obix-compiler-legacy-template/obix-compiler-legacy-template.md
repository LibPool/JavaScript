# obix-compiler-legacy-template

> 标签: obix

## 简介

LEGACY compatibility track (D-46): pure semantic template analysis for the Level-0 OBIX grammar: binding + event descriptor construction and dependency extraction. No JS parsing, no DOM. Depends only on obix-spec. The Vue template frontend of the new pipe
