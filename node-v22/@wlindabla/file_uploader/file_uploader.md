# @wlindabla/file_uploader

> 标签: browser, chunked-upload, event-driven, file-upload, file-uploader, large-file-upload, multipart-upload, nodejs, resumable-upload, typescript

## 简介

A powerful, event-driven chunked file uploader for browser and Node.js.A robust, framework-agnostic TypeScript library for uploading large files in chunks with resume capability, automatic retry, and comprehensive event handling.
