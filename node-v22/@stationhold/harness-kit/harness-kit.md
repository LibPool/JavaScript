# @stationhold/harness-kit

> 标签: JavaScript

## 简介

Turns one [Stationhold](https://stationhold.com) manifest into the files a given coding agent actually reads: its instructions file, its rules folder, or a text to paste into a plain chat. The manifest never names a tool; the adapter for each target does.
