# @esigner/sdk

> 标签: bankid, e-signature, eid, esignature, esigner, mitid, pdf, signing, webhooks

## 简介

Official TypeScript/JavaScript client for the esigner e-signing API: BankID, MitID and other eID signature requests, signed PDFs and verified webhooks.
