# @local-inspector/git

> 标签: JavaScript

## 简介

本项目是一个本地 Git 仓库可视化与实时洞察工具，通过本地运行的 HTTP + WebSocket 服务，实时监听 `.git` 目录变化，并在浏览器中提供仓库基础指标、提交历史、分支、贡献者、文件热度等信息的快速浏览。
