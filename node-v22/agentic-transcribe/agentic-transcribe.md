# agentic-transcribe

> 标签: assemblyai, audio-transcription, cli, deepgram, dry-run, mcp, nodejs, openai, speech-to-text, timestamps, transcript, typescript

## 简介

Audio transcription scaffold for OpenAI, Deepgram, and AssemblyAI with timestamp response mapping, a TypeScript API, CLI, and MCP server.
