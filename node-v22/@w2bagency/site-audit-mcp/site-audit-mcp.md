# @w2bagency/site-audit-mcp

> 标签: aeo, audit, geo, llms-txt, mcp, model-context-protocol, seo, wordpress

## 简介

MCP server for deterministic site SEO/GEO/AEO audits. Platform-agnostic Tier-1 read-only audits (incl. source-aware Astro) plus WordPress Tier-2 write/fix tools via the W2B wp-bridge companion plugin.
