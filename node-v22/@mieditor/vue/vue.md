# @mieditor/vue

> 标签: JavaScript

## 简介

`@mieditor/vue` 为 Vue 3 + Vite 项目提供 UI Editor 开发期集成。插件会处理 Vue SFC 模板，注入 `data-mi-editor-id`，并向编辑面板提供元素元数据和样式回写接口。
