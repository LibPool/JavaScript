# @mieditor/core

> 标签: JavaScript

## 简介

`@mieditor/core` 是 UI Editor 的基础包，提供开发期可视化样式编辑所需的公共能力，包括运行时桥接、编辑面板资源、Vite 插件基础逻辑、样式目标解析、CSS 回写、Tailwind 类名加载和 CSS 变量扫描。
