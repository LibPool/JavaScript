# @appilot-labs/appilot-mcp

> 标签: JavaScript

## 简介

Appilot MCP stdio server — 把 headless 服务 API（项目/快照/任务）暴露为标准 MCP 工具，供 Claude Desktop / Cursor 等客户端调用。
