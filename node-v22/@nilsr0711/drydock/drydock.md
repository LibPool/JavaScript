# @nilsr0711/drydock

> 标签: agent, ai, automation, claude, cli, github, issues, nextjs, pull-requests

## 简介

Local-first tool that autonomously turns GitHub issues into pull requests via the Claude CLI, startable from the terminal with `npx @nilsr0711/drydock`.
