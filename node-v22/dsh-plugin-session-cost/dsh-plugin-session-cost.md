# dsh-plugin-session-cost

> 标签: billing, cost, deepseek-harness, dsh, dsh-plugin, tokens, usage

## 简介

按会话统计 token 与金额：输入框下方显示当前会话花费，设置页列出每个会话的花费（含历史会话）。
