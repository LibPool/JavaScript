# @builder6/files

> 标签: JavaScript

## 简介

Builder6 Files 模块为 Builder6 平台提供完整的文件管理功能，包括文件上传、下载、存储管理以及邮件队列处理。该模块支持多种存储后端，提供灵活的文件访问控制和自动化邮件发送功能。
