# @voxel-tool/exporter

> 标签: exporter, fbx, glb, gltf, magicavoxel, obj, ply, stl, three, usdz, vox, voxel, voxel-tool

## 简介

Voxel model exporter — convert .vox / voxel data to GLTF, GLB, OBJ, STL, PLY, USDZ and FBX (built on Three.js exporters)
