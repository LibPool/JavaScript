# @voxel-tool/cli

> 标签: cli, exporter, fbx, glb, gltf, magicavoxel, obj, ply, stl, three, usdz, vox, voxel, voxel-tool

## 简介

Command-line voxel exporter — convert MagicaVoxel .vox files to GLTF/GLB/OBJ/STL/PLY/USDZ/FBX headlessly in Node (no browser required)
