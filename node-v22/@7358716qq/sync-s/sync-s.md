# @7358716qq/sync-s

> 标签: deepseek, deepseek-harness, dsh-plugin, encryption, github, sync

## 简介

DSH 多机自动同步：用 GitHub 私有仓库同步记忆/会话/插件配置，敏感信息 AES-256-GCM 加密，冲突按时间戳判定，打开自动拉取、回合结束自动推送，支持手动「立即同步」与国内网络多级容错。
