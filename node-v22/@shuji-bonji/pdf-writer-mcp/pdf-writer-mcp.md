# @shuji-bonji/pdf-writer-mcp

> 标签: markdown-to-pdf, mcp, model-context-protocol, normativepdf, pdf

## 简介

MCP server that generates and edits PDFs (text/Markdown/table creation, metadata & page operations) built on normativepdf, with Japanese font embedding (fontkit subset).
