# genever

> 标签: cli, codegen, json-ref, json-schema, json-schema-bundler, json-schema-to-typescript, juniper, openapi, type-generation, types, typescript

## 简介

Generate TypeScript types from JSON Schema files and OpenAPI documents, with strict schema checks and the same types Juniper infers.
