# @parkgraph/agent-sdk

> 标签: ai-agents, langchain, park-graph, parking, sdk, typescript

## 简介

Typed TypeScript client for the Park Graph parking API: search lots, book, check and end parking sessions from any agent framework.

- 官网：https://parkgraph.com/developers/sdk
