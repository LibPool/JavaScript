# @echo-lingua/inline-editor

> 标签: dev-tool, echo-lingua, gettext, i18n, in-context, translation, vite

## 简介

Dev-only in-browser translation editor for Echo Lingua: Alt-click a string, edit it, and write the change back to your repo.
