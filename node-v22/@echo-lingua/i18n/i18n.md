# @echo-lingua/i18n

> 标签: echo-lingua, gettext, i18n, localization, po, react, runtime, translation

## 简介

A tiny JS/TS runtime for Echo Lingua translations: the _() marker with placeholders, plurals, and rich text. Extraction and compilation live in @echo-lingua/i18n-cli.
