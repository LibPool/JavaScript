# @echo-lingua/i18n-cli

> 标签: echo-lingua, extract, gettext, i18n, laravel, localization, mo, php, po, translation

## 简介

Project-agnostic extractor and compiler for Echo Lingua translations: scan source (JS/TS + PHP/.phtml) for marked strings, hydrate gettext POs, and compile to JS, binary .mo, or Laravel JSON.
