# @latentedge/appstore-notifications

> 标签: app-store, app-store-server-notifications, cloudflare-workers, d1, in-app-purchase, jws, storekit, webcrypto, x5c

## 简介

Verify and record App Store Server Notifications V2 on Cloudflare Workers with Web Crypto only: x5c chain check to a pinned Apple Root CA - G3, typed payloads, sale event kinds, an idempotent D1 ledger, and notification history.
