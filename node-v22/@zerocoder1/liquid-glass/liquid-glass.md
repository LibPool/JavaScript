# @zerocoder1/liquid-glass

> 标签: backdrop-filter, glass, glassmorphism, liquid-glass, pwa, react, refraction, tizen, tv, ui, web-component, webgl, webgl2, webos

## 简介

Real-time liquid glass material for web, PWA and HTML5 TV. WebGL2 refraction with a CSS backdrop-filter fallback, plus glassify() to turn existing DOM into glass in place.
