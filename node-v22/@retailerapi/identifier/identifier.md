# @retailerapi/identifier

> 标签: asin, barcode, detector, ean, ecommerce, gtin, identifier, isbn, retailerapi, upc, validator, walmart

## 简介

Zero-dep detector for product identifiers — UPC-12, EAN-13, ISBN-10/13, GTIN-14, Amazon ASIN, Walmart item_id. ~50 LoC, no runtime dependencies.
