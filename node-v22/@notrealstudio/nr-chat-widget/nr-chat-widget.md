# @notrealstudio/nr-chat-widget

> 标签: JavaScript

## 简介

<nr-chat> — ванильный Web Component чата nrchat (Shadow DOM, без фреймворка): лента со стримом, карточки тулов, апрувов и вопросов, транспорты nr-ui-protocol (HTTP/SSE) и ACP (WebSocket), тулы страницы и снимок её состояния. Один бандл dist/nr-chat.js.
