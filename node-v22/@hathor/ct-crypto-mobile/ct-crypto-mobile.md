# @hathor/ct-crypto-mobile

> 标签: JavaScript

## 简介

React Native (iOS/Android) shielded crypto provider for Hathor confidential transactions. Rust core over UniFFI, bridged as a native module; implements the @hathor/ct-crypto-provider interface.
