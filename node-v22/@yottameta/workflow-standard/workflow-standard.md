# @yottameta/workflow-standard

> 标签: agent-skills, handoff, project-state, workflow, workflow-standard

## 简介

Universal cross-session, cross-project workflow standard for AI agents: 开工读状态、状态就近存、进行中记流水/任务/决策、收工留交接锚点。适合所有 AI 智能体的通用工作流。
