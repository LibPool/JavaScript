# dsh-ssh-plugin

> 标签: deepseek-harness, dsh, dsh-plugin, remote, sftp, ssh

## 简介

SSH for DSH agents: run commands and move files over SSH while private keys stay inside the Host process. ssh2 transport with an optional system-OpenSSH backend.
