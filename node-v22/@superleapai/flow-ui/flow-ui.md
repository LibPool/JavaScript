> 标签: components, currency, datepicker, design-system, flow, form-builder, forms, input, multi-step-form, notifications, phone-input, select, state-management, superleap, tailwind, timepicker, toast, ui, validation, vanilla-js

## 简介

A reusable design system for building multi-step forms with comprehensive UI components. Single file, clean globals, SDK included. Only FlowUI and SuperLeap exposed.
