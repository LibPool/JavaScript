# @rederive/request

> 标签: deprecated, http, rederive, request, supply-chain, verified

## 简介

Verified-recompose of request@2.88.2's PURE helper core (the deprecated HTTP client). The SIR firewall carves the pure leaves out of the HTTP effect spine; this package verifies the leaves, the spine is declared for trace-oracle follow-up.
