# @tom-ricci/cra-template

> 标签: create-octobox-app, framework, github pages, octobox, react, routing, sass, tailwind, typescript

## 简介

An opinionated, simple Typescript framework with Tailwind, Sass, dynamic filesystem routing, static filesystem routing, and page animations designed to be hosted on GitHub Pages.
