# @renderball/agent-toolkit

> 标签: ai agent, deck, langchain, mcp, openai agents, presentations, renderball, slides, tools, vercel ai sdk

## 简介

Give any AI agent the ability to build designed, editable presentations on Renderball: create a deck, send the file your agent wrote, get the link. Works with the Vercel AI SDK, the OpenAI Agents SDK, LangChain, or plain function calling. No account neede
