# @ausus/react-renderer

> 标签: api-runtime, ausus, react, renderer

## 简介

AUSUS L5 React Renderer — renders entities, projections and actions discovered from the api-runtime HTTP contract only. No knowledge of kernel/engine/compiler/repository.
