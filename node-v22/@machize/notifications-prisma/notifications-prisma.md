# @machize/notifications-prisma

> 标签: machize, notifications, postgresql, prisma, store, typescript

## 简介

Prisma-backed implementation of the @machize/notifications InAppStore (in-app notifications) — the production reference backend (PostgreSQL/MySQL). Bring your own PrismaClient; ships a reference schema.
