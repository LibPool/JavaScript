# @machize/realtime

> 标签: machize, realtime, saas, sse, typescript, websocket

## 简介

Realtime for Machize: server-to-client push over WebSocket/SSE with per-tenant channels, presence, an events bridge, and a pluggable backplane (in-memory or Redis pub/sub).
