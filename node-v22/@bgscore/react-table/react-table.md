# @bgscore/react-table

> 标签: JavaScript

## 简介

A React utility library that provides advanced API hooks (fetch, mutation, caching) and a customizable Table component with built-in pagination, sorting, and loading states. Built for scalable and flexible data handling in modern React applications.
