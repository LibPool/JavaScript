# @authvex/react

> 标签: authentication, components, dpop, passkey, rbac, react

## 简介

Embeddable React components for Authvex: a zero-trust login card with passkeys and TOTP, a threat radar workbench, a sessions and passkeys vault, and a tenant RBAC and impersonation studio.
