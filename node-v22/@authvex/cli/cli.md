# @authvex/cli

> 标签: authentication, cli, dpop, identity, passkey, self-hosted, zero-trust

## 简介

Run a self-hosted Authvex identity server: login with passkeys, TOTP and DPoP-bound sessions, refresh-family kill-switch, threat gate, RBAC, scoped API keys, sealed impersonation, a hash-chained audit ledger and the Studio.
