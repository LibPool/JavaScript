# pi-seamless-ssh

> 标签: pi-extension, pi-package, remote, remote-development, ssh, workspace

## 简介

Pi extension: point a chat at another machine over SSH. The model works there as if it lived there, your extensions keep working, and the project keeps its own .pi files.
