# @agentsigna/verify

> 标签: agentsigna, ai-agent, audit, authorization, ed25519, ledger, passport, verification

## 简介

Standalone offline verifier for AgentSigna Action Authorization Passports and Ledger Chains. No AgentSigna API dependency.
