# @noy-db/to-browser-fs

> 标签: adapter, browser, encryption, file-system-access, filesystem, lan, network-share, noy-db, offline-first, smb, zero-knowledge

## 简介

File System Access API adapter for noy-db — a browser sibling to to-file, so a page can read and write a mounted network share
