# @noy-db/to-rest

> 标签: JavaScript

## 简介

REST/HTTP adapter for noy-db — NoydbStore client for the @noy-db/in-rest ciphertext RPC proxy (POST /rpc). The HTTP mirror of by-peer's peerStore(); the server never sees a secret or plaintext.
