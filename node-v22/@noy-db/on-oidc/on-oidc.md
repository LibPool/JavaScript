# @noy-db/on-oidc

> 标签: apple, auth, encryption, federated-login, google, key-connector, keycloak, line, noy-db, oauth, oidc, okta, split-key, zero-knowledge

## 简介

OAuth/OIDC bridge for noy-db — federated login (LINE, Google, Apple, Okta) with split-key key connector — server never sees plaintext
