# @noy-db/to-cloudflare-r2

> 标签: cloudflare, noy-db, r2, s3, storage, to-cloudflare-r2

## 简介

Cloudflare R2 adapter for noy-db — S3-compatible object storage with zero egress fees. Thin wrapper around @noy-db/to-aws-s3 configured for the R2 endpoint. casAtomic: true, serverWriteTime: true.
