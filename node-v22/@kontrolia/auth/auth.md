# @kontrolia/auth

> 标签: auth, authentication, authorization, iam, kontrolia, rbac, sdk, supabase

## 简介

Official framework-agnostic KontrolIA Auth SDK. The only supported way to integrate an application — no app should ever import supabase-js, handle OAuth redirects, or parse a JWT directly.
