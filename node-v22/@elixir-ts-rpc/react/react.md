# @elixir-ts-rpc/react

> 标签: elixir, phoenix, react, react-query, rpc, tanstack-query, type-safe, typescript

## 简介

React + TanStack Query adapter for elixir-ts-rpc: typed useQuery/useMutation hooks over a generated RPC client.
