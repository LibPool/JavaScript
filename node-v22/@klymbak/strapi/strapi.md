# @klymbak/strapi

> 标签: agent, ai, assistant, klymbak, mcp, strapi, strapi-5, strapi-plugin

## 简介

An AI assistant for the Strapi 5 admin panel. It finds, writes and updates content as the signed-in admin, within their Strapi permissions, and asks before it changes anything.
