# @leo.gimp/opencode-auto-allow

> 标签: auto-approve, opencode, opencode-plugin, opencode-tui-plugin, permissions

## 简介

OpenCode TUI plugin: /allow toggles the built-in auto-approve permissions mode, with a persistent allow indicator in the home footer.
