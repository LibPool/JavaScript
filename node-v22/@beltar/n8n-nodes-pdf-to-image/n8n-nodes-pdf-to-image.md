# @beltar/n8n-nodes-pdf-to-image

> 标签: convert, image, jpeg, n8n, n8n-community-node-package, pdf, png, poppler

## 简介

n8n node to convert PDF files to images using poppler-utils. Supports Linux, macOS and Windows.
