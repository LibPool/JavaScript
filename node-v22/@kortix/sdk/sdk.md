# @kortix/sdk

> 标签: agent, kortix, opencode, sdk, sessions, streaming

## 简介

Official Kortix frontend TypeScript SDK — one typed client for the Kortix agent platform. Unifies project/session lifecycle and live agent streaming behind a single ergonomic Session handle, so web, mobile, and white-label apps never touch the raw HTTP AP
