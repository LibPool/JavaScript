# @arv/structs-compiler

> 标签: compiler, shared structs, structs, tc39, typescript

## 简介

The compiler of @arv/structs: the TC39 structs proposal's syntax (struct, shared struct) compiled to JavaScript, a command line, and a Node load hook; TypeScript projects type checked, with shared struct field access made direct
