# @aarvion/openclaw-guard

> 标签: JavaScript

## 简介

Aarvion guard PEP for OpenClaw: governs agent tool calls via a local policy decision point. Installs into a stock OpenClaw with `openclaw plugin install` - no OpenClaw source changes, no rebuild.
