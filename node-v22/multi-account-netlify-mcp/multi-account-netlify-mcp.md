# multi-account-netlify-mcp

> 标签: antigravity, claude-code, claude-code-plugin, codex, deploy, mcp, model-context-protocol, multi-account, netlify, opencode

## 简介

Multi-account Netlify MCP for Claude Code, Codex, opencode and Antigravity: one official @netlify/mcp server per account, with tool calls sent to one, several or all accounts.
