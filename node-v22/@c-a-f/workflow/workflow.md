# @c-a-f/workflow

> 标签: actions, caf, clean-architecture, clean-architecture-frontend, effects, fsm, guards, state-machine, state-management, workflow

## 简介

Framework-agnostic workflow and state machine management for CAF. Built on top of Ploc for reactive state management. Includes guards, actions, and effects utilities.
