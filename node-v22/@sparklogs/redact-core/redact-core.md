# @sparklogs/redact-core

> 标签: anonymization, cbs, gdpr, isomorphic, logs, pii, privacy, pseudonymization, redaction, windows

## 简介

Isomorphic core: detect and consistently pseudonymise PII in log text, with a residual-PII scanner. Pure string/regex — safe in Node or the browser. Driven by portable JSON detection specs.
