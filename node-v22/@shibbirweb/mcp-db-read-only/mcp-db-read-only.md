# @shibbirweb/mcp-db-read-only

> 标签: claude, clickhouse, database, elasticsearch, llm, mariadb, mcp, model-context-protocol, mongodb, mysql, opensearch, postgresql, read-only, redis, sql-server, sqlite

## 简介

A read-only MCP server for MySQL, MariaDB, PostgreSQL, SQLite, SQL Server, ClickHouse, MongoDB, Redis and Elasticsearch, with connections switchable at runtime.
