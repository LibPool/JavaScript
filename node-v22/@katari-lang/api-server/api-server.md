# @katari-lang/api-server

> 标签: JavaScript

## 简介

HTTP API server that hosts a Katari runtime instance (snapshot apply, agent run, escalation handling). Distributed both as an npm library and as a Docker image (ghcr.io/katari-lang/katari).
