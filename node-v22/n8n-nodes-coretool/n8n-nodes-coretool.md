# n8n-nodes-coretool

> 标签: coretool, e-invoice, e-rechnung, invoice, leitweg-id, n8n-community-node-package, xrechnung, zugferd

## 简介

n8n community node for the Coretool e-invoice API: create ZUGFeRD and XRechnung invoices, validate e-invoices, check Leitweg-IDs and read your usage.
