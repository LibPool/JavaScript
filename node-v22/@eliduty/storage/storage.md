# @eliduty/storage

> 标签: ESM, UMD, expire, lib, localStorage, sessionStorage, storage, tool, util

## 简介

该工具库是在本地存储的基础上进行的封装，优化使用体验，支持自定义localStorage和sessionStorage存储驱动。
