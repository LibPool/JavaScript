# @volcengine/web-rtmp

> 标签: JavaScript

## 简介

> Web版的RTMP推流SDK。 接收摄像头、麦克风、屏幕共享MediaStreamTrack, 视频编码为H264、音频编码为AAC, 并通过http协议以Flv打包格式进行推流
