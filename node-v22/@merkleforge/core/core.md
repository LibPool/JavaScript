# @merkleforge/core

> 标签: authenticated-data-structures, bincode, blockchain, cryptography, hash-function, inclusion-proof, interfaces, merkle, merkle-proof, merkle-proof-verification, merkle-root, merkle-tree, merkleforge, merkletree, proof, rust-compatible, serde, types, typescript, web3, zero-dependency

## 简介

Merkle tree and Merkle proof interfaces for TypeScript: MerkleTree and HashFunction types, proof types, errors, and Rust-compatible (bincode, serde) proof codecs. Part of MerkleForge.
