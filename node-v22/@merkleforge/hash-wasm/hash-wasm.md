# @merkleforge/hash-wasm

> 标签: authenticated-data-structures, blockchain, cryptography, ethereum, fast, hash, hash-wasm, keccak, keccak-256, keccak256, merkle, merkle-proof, merkle-root, merkle-tree, merkleforge, merkletree, performance, sha-256, sha256, typescript, wasm, web3, webassembly

## 简介

Fast WebAssembly Keccak-256 and SHA-256 for Merkle trees, about 6x faster Keccak, same output as @merkleforge/hash. Part of MerkleForge.
