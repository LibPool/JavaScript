# @zlayer/client

> 标签: container, openapi, orchestration, sdk, zlayer

## 简介

Ergonomic TypeScript SDK for ZLayer. Wraps the auto-generated OpenAPI client (@zlayer/api-client) with convenience methods and a Unix-socket-aware fetch.
