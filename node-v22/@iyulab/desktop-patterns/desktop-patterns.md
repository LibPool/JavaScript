# @iyulab/desktop-patterns

> 标签: JavaScript

## 简介

App-shell and structural layout patterns assembled on top of [`desktop-compact`](https://github.com/iyulab/desktop-compact)'s primitives. Framework-neutral custom elements ([Lit](https://lit.dev)), zero built-in strings, every content region a slot.
