# @iyulab/tauri-kit-dev

> 标签: cdp, desktop, e2e, installer, tauri, webview2

## 简介

Development and verification tools for Tauri desktop apps: drive the WebView2 window over CDP, check installers, and keep public text clean. Nothing here ships inside an app.
