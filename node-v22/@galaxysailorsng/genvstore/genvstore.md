# @galaxysailorsng/genvstore

> 标签: backup, cli, cloudflare, dotenv, env, env-file, environment-variables, r2, secrets, sync

## 简介

Serverless, plug-and-play CLI for backing up and restoring .env files through your private Cloudflare R2 bucket — no server, no database, no secrets-store.
