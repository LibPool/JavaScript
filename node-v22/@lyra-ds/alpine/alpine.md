# @lyra-ds/alpine

> 标签: accessibility, alpine, alpinejs, components, design-system, livewire, ui, white-label

## 简介

Lyra DS — Alpine.js plugin porting the exact state machines of the interactive @lyra-ds/react components. All appearance comes from @lyra-ds/styles .lyra-* classes; one Alpine.data() per component.
