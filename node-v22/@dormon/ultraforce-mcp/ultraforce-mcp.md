# @dormon/ultraforce-mcp

> 标签: apex, mcp, model-context-protocol, salesforce, soql

## 简介

Offline Salesforce org schema + Apex MCP server (ost_* tools). Ships the uf-ost binary; postinstall fetches the prebuilt release binary for your platform.
