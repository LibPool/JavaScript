# cordova-plugin-anyline-frame-replay

> 标签: anyline, cordova-android, cordova-ios, ecosystem:cordova, testing

## 简介

Feeds the Anyline scanner of io-anyline-cordova from images instead of the camera, through the SDK's own Frame Replay, so a scan can be tested without a camera or a real code
