# @ilovemusic/cli

> 标签: JavaScript

## 简介

Interactive command-line client for the ILoveMusic public API — download tracks from Spotify, SoundCloud, and Bandcamp without touching curl, HTTP, or job polling directly.

## 官网

- npm 页面：https://www.npmjs.com/package/@ilovemusic/cli
