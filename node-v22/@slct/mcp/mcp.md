# @slct/mcp

> 标签: agents, llm, mcp, model-context-protocol, routing, slct

## 简介

SLCT MCP server over stdio (15 tools: plan, verify, execute, compose, receipts). One bin, slct-mcp. The server code ships in @slct/cli; this package is the MCP registry entry point (sh.slct/slct).
