# @ignytehq/plunk-mcp

> 标签: anthropic, claude, email, mcp, model-context-protocol, plunk, self-hosted, transactional-email

## 简介

Unofficial MCP server for Plunk — gives Claude (and any MCP client) tools for transactional email, contacts, campaigns, segments, templates, workflows, events, and analytics. Targets the actively-developed useplunk/plunk codebase.
