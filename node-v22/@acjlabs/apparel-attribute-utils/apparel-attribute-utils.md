# @acjlabs/apparel-attribute-utils

> 标签: apparel, color, ecommerce, normalization, product-catalog, size, taxonomy

## 简介

Zero-dependency apparel size and color canonicalization — normalizes messy synonyms ("Medium", "2XL", "navy blue") to a fixed controlled vocabulary.
