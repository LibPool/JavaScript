# @yuants/utils

> 标签: JavaScript

## 简介

`@yuants/utils` 是 Yuan 体系内的通用工具库，聚焦于异步迭代、加密、时间/数值处理以及 RxJS 辅助算子等基础能力，供上层协议、行情与交易程序共享使用。
