# @yuants/data-account

> 标签: JavaScript

## 简介

`@yuants/data-account` 提供账户资金与持仓的统一建模、服务化推送和持久化辅助工具，帮助终端在 Yuan 体系内快速同步账户视图、写入数据库并输出监控指标。
