# @malva-ui/editor

> 标签: angular, editor, malva-ui, markdown, prosemirror, rich-text, tiptap, wysiwyg

## 简介

SSR-safe Angular rich-text editor for Malva UI — a Tiptap shell with HTML/Markdown/JSON values, image uploads and block reordering.
