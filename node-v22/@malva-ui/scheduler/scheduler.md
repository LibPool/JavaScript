# @malva-ui/scheduler

> 标签: angular, calendar, drag-and-drop, events, malva-ui, scheduler

## 简介

Calendar scheduler for Malva UI — month, week and day views with draggable, resizable timed and all-day events on top of a fully controlled event model.
