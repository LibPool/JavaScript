# @phuc1403/musketeer

> 标签: agents, claude, claude-code, cli, harness, hooks, scaffolder, skills

## 简介

Distributable custom Claude Code harness — one declarative command scaffolds a curated company of musketeers (skills/agents/hooks) into any project's .claude/.
