# @baiyibai-antora/jira-publisher

> 标签: adf, asciidoc, confluora, issues, jira, publish

## 简介

Create and update Jira Cloud issues from AsciiDoc: a seed manifest plus .adoc bodies become issues with native ADF descriptions via @baiyibai-antora/asciidoc-adf-converter
