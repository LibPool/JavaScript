# @baiyibai-antora/confluence-retriever

> 标签: adf, asciidoc, confluence, confluora, export, retriever

## 简介

Retrieve a Confluence Cloud space as AsciiDoc: pages via the v2 REST API in ADF, converted with @baiyibai-antora/asciidoc-adf-converter, attachments downloaded alongside
