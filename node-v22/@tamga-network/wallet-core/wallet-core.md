# @tamga-network/wallet-core

> 标签: JavaScript

## 简介

Cüzdan çekirdeği (SPEC-WALLET-0001, SPEC-PROTO-0001/0002): KeyProvider soyutlaması, OpenID4VCI alma, SD-JWT VC yerel doğrulama ve sunum (KB-JWT), cüzdan deposu. Node ve React Native (Hermes) uyumlu: node:crypto/Buffer/jose yok; @noble ile saf TS.
