# @tamga-network/issuer

> 标签: JavaScript

## 简介

Issuer kütüphanesi: credential fabrikası (şema doğrulama + türetilmiş claim + batch), OpenID4VCI sunucu yardımcıları (offer, tx_code, c_nonce, proof), Token Status List yayıncısı (bits=2, rastgele idx, sabit aralık) ve çapa isteği. Servis (tamga-platform)
