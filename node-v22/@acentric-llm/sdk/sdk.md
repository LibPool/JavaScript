# @acentric-llm/sdk

> 标签: cloudflare-workers, fireworks, gateway, llm, openai, responses-api, sdk

## 简介

Typed, dependency-free client for the acentric LLM gateway. Bring your own OpenAI or Fireworks key; runs in browsers, Node, Deno, Bun, and Workers.
