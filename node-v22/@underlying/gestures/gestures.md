# @underlying/gestures

> 标签: animation, drag, fling, flip, gestures, layout, physics, spring

## 简介

Drag, fling and interruptible FLIP for @underlying/core: pointer velocity straight into physics, layout transitions that retarget mid-flight. Physics-first.
