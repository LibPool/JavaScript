# @antelopejs/tooling-configs

> 标签: antelopejs, anti-slop, eslint, knip, oxc, oxfmt, oxlint

## 简介

Shared tooling presets for AntelopeJS repositories: oxlint (with the vendored anti-slop rules), oxfmt, ESLint for Nuxt layers, Knip, and an interface range check
