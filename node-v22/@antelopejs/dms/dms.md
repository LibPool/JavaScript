# @antelopejs/dms

> 标签: admin, antelopejs, backoffice, dashboard, dms, inertia, vue

## 简介

The AntelopeJS dashboard management system: admin dashboards declared in TypeScript, with auth and tenancy, data management, file uploads, notifications and realtime.
