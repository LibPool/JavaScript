# @mr.cuongnt/fcm-node-receiver

> 标签: electron, fcm, gcm, node, notifications, push, receiver, service

## 简介

A module to subscribe to GCM/FCM and receive notifications within a node process. Compatible with the latest FCM registration endpoints.
