# @rhythmjs/config

> 标签: config, config-module, config-service, env, environment, rhythm, standard-schema, validation

## 简介

NestJS-style configuration module for Rhythm: ConfigModule.forRoot with config factories, registerAs namespaces, and a schema-validated, dot-path-typed ConfigService.
