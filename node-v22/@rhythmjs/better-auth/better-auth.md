# @rhythmjs/better-auth

> 标签: auth, authentication, better-auth, bun, rhythm, session

## 简介

Better Auth for Rhythm on Bun: betterAuthModule.forRoot({ auth }) holds auth for include(); authHandler mounts auth.handler; withSession derives session and user onto the context; requireSession guards routes.
