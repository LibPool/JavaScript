# @rhythmjs/testing

> 标签: cli, inject, mock, rhythm, supertest, test-client, testing, websocket

## 简介

Testing utilities for Rhythm: kernel module mocking, a fetch-based router test client, a CLI command runner, and WebSocket hook harnesses.
