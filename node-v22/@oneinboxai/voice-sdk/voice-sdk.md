# @oneinboxai/voice-sdk

> 标签: cpaas, oneinbox, oneml, sip, softphone, telephony, voice, voip, webrtc

## 简介

Browser softphone for OneInbox — a Twilio.Device-shaped WebRTC voice client backed by SIP over WebSocket.
