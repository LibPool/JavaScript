# @lit-material/drawer

> 标签: drawer, lit, lit-material, material-design, material-design-3, notification-drawer, web-components

## 简介

Material Design 3-styled drawer web component (lit-material-drawer) — a non-modal, persistent overlay panel, e.g. for a notification drawer.
