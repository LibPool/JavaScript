# @lit-material/overflow-menu

> 标签: lit, lit-material, material-design, material-design-3, overflow-menu, responsive, toolbar, web-components

## 简介

Material Design 3-styled overflow menu web component (lit-material-overflow-menu) — a responsive action row that collapses overflowing items into a kebab menu.
