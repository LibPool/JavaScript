# @inlinedesk/widget

> 标签: helpdesk, inlinedesk, react, support, vue, widget

## 简介

InlineDesk support widget for your web app: loader, TypeScript types and React/Vue adapters. The widget itself is served from app.inlinedesk.com and stays current without republishing.
