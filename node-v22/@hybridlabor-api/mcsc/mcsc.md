# @hybridlabor-api/mcsc

> 标签: JavaScript

## 简介

Multi-CLI Subagent Configurator — detects installed coding-agent CLIs (agy, opencode, Codex, native Claude Code) and routes delegated subtasks via a capability-tier rulebook.
