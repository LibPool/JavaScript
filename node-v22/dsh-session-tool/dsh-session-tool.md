# dsh-session-tool

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, session

## 简介

DSH plugin: delete sessions from the sidebar (row menu + hover button) and via slash commands and agent tools. Trash-first, workspace-accounting aware.
