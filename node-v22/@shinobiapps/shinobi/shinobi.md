# @shinobiapps/shinobi

> 标签: ai-coding-agents, approvals, claude-code, cursor, dead-ends, mcp, model-context-protocol, remote-mcp, task-management

## 简介

Task spine + dead-end search + approvals for AI coding agents (Claude Code, Cursor, Cline, Continue.dev, Zed). Past dead ends are semantically searched before your agent writes code. Self-host or hosted — one brain across every device.
