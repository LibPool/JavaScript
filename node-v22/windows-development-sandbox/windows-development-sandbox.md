# windows-development-sandbox

> 标签: agent, claude, claude-code, codex, databases, development, dynamodb, gemini, opencode, sandbox, windows-sandbox

## 简介

A disposable Windows Sandbox for development, with or without an AI agent (Claude Code, Codex, Gemini, opencode, ...): the folder you run it from is the workspace, toolchains and databases for your project install themselves, and nothing else on your PC i
