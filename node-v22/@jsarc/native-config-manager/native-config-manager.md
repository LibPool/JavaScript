# @jsarc/native-config-manager

> 标签: JavaScript

## 简介

NATIVE CONFIG-MANAGER est un système de gestion de configuration modulaire pour les applications React Native et Expo avec TypeScript/JavaScript. Il fournit une gestion centralisée des configurations, un chargement dynamique des modules, et une intégratio
