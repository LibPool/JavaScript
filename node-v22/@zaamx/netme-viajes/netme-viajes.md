# @zaamx/netme-viajes

> 标签: medusa, medusa-plugin, medusa-plugin-loyalty, medusa-v2, plugin

## 简介

Módulo Viajes (incentivo por millas) para Netme/GoLife: campañas, catálogo de acciones, simulador y admin; el motor de cálculo vive en SQL netme_viaje_*.
