# @convrs/ai-bot-sdk

> 标签: ai crawler, bot detection, claudebot, convrs, express, gptbot, middleware, nextjs, perplexitybot, web analytics

## 简介

Detect and track AI crawlers, answer agents, and search bots (GPTBot, ClaudeBot, PerplexityBot, and more) hitting your site or API — server-side SDK for Convrs.
