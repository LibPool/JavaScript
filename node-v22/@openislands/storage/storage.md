# @openislands/storage

> 标签: adapter, backend, content-store, esm, filesystem, local-first, openislands, pluggable, port, storage

## 简介

OpenIslands storage ports — swappable ContentStore / AppStateStore / VersionStore so the runtime can be backed by local disk or another backend.
