# @aposudevsky/gatsby-source-drupal

> 标签: gatsby, gatsby-plugin, gatsby-source-plugin

## 简介

Gatsby source plugin for building websites using the Drupal CMS as a data source. Added possibility of request customization by adding headers and get params
