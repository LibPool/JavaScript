# @bir-tan/crisp-oquent

> 标签: api-client, eloquent, fetch, json-api, laravel, next, nuxt, query-builder, react, spatie, typescript, vue

## 简介

Fetch-only TypeScript API client that speaks Spatie laravel-query-builder's URL contract — fluent Eloquent-style builder with Filter Groups (JSON:API Fancy Filters).
