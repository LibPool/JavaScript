# @flarecart/admin-ui

> 标签: admin, combobox, context-menu, dark-mode, dialog, flyout, icons, modal, tailwind-v4, tailwindcss, toast, ui, ui-kit, vanilla-js

## 简介

The small vanilla-JS UI kit FlareCart's admin is built from: buttons, page headers, sortable table headers, switches, toasts, modals, flyouts, confirm and prompt dialogs, a searchable combobox, context and action menus, and an inline SVG icon set. Styled
