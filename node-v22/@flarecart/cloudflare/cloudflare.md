# @flarecart/cloudflare

> 标签: cloudflare, cloudflare-api, cloudflare-for-saas, cors, custom-hostnames, r2, rate-limiting, waf, workers

## 简介

One-click setup through Cloudflare's API — find the account and zone, rate-limit an API at the edge with WAF rules sized to the plan, open an R2 bucket to browser uploads with CORS, and serve customers' own domains (custom hostnames). Keeps every rule it
