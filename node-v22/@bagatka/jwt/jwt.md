# @bagatka/jwt

> 标签: apple, cloudflare-workers, effect, es256, github-app, jws, jwt, rs256, web-crypto

## 简介

Signs JSON Web Tokens with ES256 and RS256 keys, such as Apple's .p8 keys and a GitHub App's, through Web Crypto, with Effect.
