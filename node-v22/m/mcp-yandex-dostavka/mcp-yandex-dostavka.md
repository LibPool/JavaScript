# mcp-yandex-dostavka

> 标签: courier, delivery, express-delivery, logistics, mcp, model-context-protocol, pickup-points, yandex, yandex-delivery, yandex-dostavka

## 简介

MCP server for the Yandex Delivery B2B API (dostavka.yandex.ru) — express-courier price checks, claims and tracking plus NDD/pickup-point offers and orders for AI agents.
