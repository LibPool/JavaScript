# melta-contracts

> 标签: ai-ready, contracts, design-system, design-tokens, melta, react-native

## 简介

melta UI design contracts (design tokens / prohibited rules / component contracts) — single source of truth, JSON only, framework-agnostic. Consumed by melta-ui (web) and melta-app (React Native).
