# may-esinstall

> 标签: cjs, common.js, dependencies, esbuild, esinstall, esm, install, npm, rollup, svg, web

## 简介

Convert packages to ESM. Same as esinstall but without the cssplug in that was built in. I suggest using postcss plugin since it supports @import
