# mini-css-extract-hot-plugin

> 标签: JavaScript

## 简介

主要用来关闭掉`mini-css-extract-plugin`部分的`hmrc`,在5.5.0版本，热更时，总是全局刷css,体验太差，

## 官网

- npm 页面：https://www.npmjs.com/package/mini-css-extract-hot-plugin

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install mini-css-extract-hot-plugin`
- npm registry：https://registry.npmjs.org/mini-css-extract-hot-plugin
