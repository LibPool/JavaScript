# modernbrowser

> 标签: Browser, in App Browser, ionic, plugin

## 简介

An Android Cordova plugin that allows users to use a modern Web-browser (in App Browser) without leaving the app

- 官网：https://github.com/hitmacreed/Cordova-Plugin-Modern-Browser.git
