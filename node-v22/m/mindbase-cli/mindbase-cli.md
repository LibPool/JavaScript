# mindbase-cli

> 标签: agent, ai, anthropic, azure-openai, byok, cli, coding-agent, llm, openai

## 简介

Mindbase terminal coding agent — connect with a Mindbase access key (no model key needed), or BYOK to Azure OpenAI, OpenAI, Anthropic, or any OpenAI-compatible endpoint.
