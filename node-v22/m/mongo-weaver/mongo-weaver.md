# mongo-weaver

> 标签: browser, database, database-browser, database-gui, devtools, explorer, gui, mongo, mongodb, mongodb-client, mongodb-gui, nosql, objectid, populate, read-only, relations, viewer

## 简介

A local, read-only MongoDB GUI and database browser that turns ObjectIds into links — click a reference and jump to the document it points to
