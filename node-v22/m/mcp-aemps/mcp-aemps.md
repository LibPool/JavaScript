# mcp-aemps

> 标签: aemps, anthropic, cima, claude, healthcare, mcp, pharmaceutical, regulatory, spain

## 简介

MCP server for the Spanish AEMPS CIMA pharmaceutical registry — npm wrapper that delegates to `uvx mcp-aemps`.
