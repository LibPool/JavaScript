# meow-tile-kit

> 标签: amap, baidu, coordinate, gcj02, map, openstreetmap, tile, wgs84

## 简介

Multi-source map tile switching library with coordinate system support (WGS-84 / GCJ-02 / BD-09). Umbrella package: core + ui.
