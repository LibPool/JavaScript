# mcp-publisher

> 标签: browser-automation, mcp, model-context-protocol, playwright, publishing

## 简介

Универсальный обучаемый MCP: управление браузером для автопубликации контента на любых площадках. Запоминает редактор каждой площадки и публикует быстро по выученному.
