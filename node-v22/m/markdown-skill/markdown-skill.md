# markdown-skill

> 标签: agent-skills, claude-code, codex, cursor, documentation, readme, skill

## 简介

Agent Skill that writes accurate, screenshot-backed READMEs by reading your actual code. One-command install for Claude Code, Cursor, Codex CLI, Windsurf, Gemini CLI, and OpenCode.
