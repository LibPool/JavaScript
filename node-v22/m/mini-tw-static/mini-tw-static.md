# mini-tw-static

> 标签: atomic-css, css, css-framework, static-css, tailwind, utility, utility-first

## 简介

Static pre-built CSS utility library — drop-in Tailwind-like classes. One import, zero config, works everywhere (React, Vue, Svelte, plain HTML).
