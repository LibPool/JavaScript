# mean-rest-express

> 标签: Angular, Express, MEAN, Mongodb, Mongoose, Node.js, Rest

## 简介

Restful API exposure middleware for Express and Mongoose based framework. Provide Rest API automatically based on Mongoose schema. It can also work with mean-rest-angular to develop end to end MEAN stack web applications.
