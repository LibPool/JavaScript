# magic-reverse-proxy

> 标签: hsts, load-balancer, proxy, reverse-proxy, round-robin, typescript, vhost, websocket

## 简介

HTTP/HTTPS reverse proxy with a fluent TypeScript API, virtual hosts, WebSocket support, pluggable Round-Robin balancing, and HSTS policy helpers — zero Express/http-proxy dependencies.
