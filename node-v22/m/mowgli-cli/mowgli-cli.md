# mowgli-cli

> 标签: agent, claude-code, cli, codex, design, mowgli

## 简介

Mowgli CLI: lets coding agents such as Claude Code and Codex push and pull designs between a codebase and Mowgli (https://mowgli.ai).

## 官网

- 官网：https://mowgli.ai
- npm 页面：https://www.npmjs.com/package/mowgli-cli
