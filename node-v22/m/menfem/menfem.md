# menfem

> 标签: ai, cli, inference, llm, mcp, pricing, research, token-prices

## 简介

MenFem in your terminal — live AI inference prices with provenance, open/closed cost spreads, claim checking against primary filings, knowledge-base search, and the public market-call record. Zero config, no API key.
