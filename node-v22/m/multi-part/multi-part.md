# multi-part

> 标签: buffer, data, form, form-data, multi-part, multipart, stream, vinyl

## 简介

Simple multipart/form-data implementation with automatic data type detection. Supports: Strings, Numbers, Arrays, Streams, Buffers and Vinyl.
