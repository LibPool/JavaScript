# mellos-mapping

> 标签: bottom-up, claude-code, codex, dependency-graph, mcp, mcp-server, terminal, tui, visualization

## 简介

A live layered dependency map for bottom-up development — MCP server + terminal pane. Ghost the design first, then light nodes up from the bottom as they are built and verified.
