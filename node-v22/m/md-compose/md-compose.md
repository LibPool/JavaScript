# md-compose

> 标签: documentation generator, include, include markdown files, markdown, markdown builder, markdown fragments, markdown import, markdown include, markdown preprocessor, static site

## 简介

A lightweight Node.js utility to include Markdown files into other Markdown documents using [[[path/to/file.md]]] syntax.
