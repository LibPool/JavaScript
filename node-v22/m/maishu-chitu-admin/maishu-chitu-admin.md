# maishu-chitu-admin

> 标签: JavaScript

## 简介

提供一个基本的后台管理系统，除了前端，它还包括后端服务。它即可以单独使用，也可以配合 NODE-AUTH 使用，作为一个微服务，和 NODE-AUTH（网关）组成一个主从架构。
