# markmark-cli

> 标签: annotations, cli, comments, highlight, markdown, markdown-viewer, review, review-tool, viewer

## 简介

Read, highlight, and comment on Markdown files in your browser. Comments save to a sidecar JSON file you can commit, diff, share, or export. Zero dependencies.
