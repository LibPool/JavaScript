# mcp-archiveorg

> 标签: archive-org, books, full-text-search, internet-archive, mcp, model-context-protocol, open-library, wayback-machine

## 简介

MCP server for the Internet Archive. Search inside digitised books, browse the catalogue, and read Wayback Machine snapshots. No API key required.
