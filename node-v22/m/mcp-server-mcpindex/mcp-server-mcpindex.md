> 标签: agent, claude, cursor, discovery, gemini, governance, mcp, mcp-server-index, mcpindex, model-context-protocol, registry, tool-safety, trust

## 简介

The MCP server index that vets servers, not just lists them. Search by task, then get an advisory screen on a server before your agent calls its tools: whether each tool does what it claims, backed by conformance monitoring and a public drift ledger. Advi
