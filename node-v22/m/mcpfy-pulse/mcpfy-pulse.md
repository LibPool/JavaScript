# mcpfy-pulse

> 标签: mcp, mcpfy, model-context-protocol, observability, proxy, telemetry

## 简介

Telemetry for MCP servers: wrap any Transport, or proxy any command over stdio, to capture method/size/duration/outcome metrics for the MCPFY dashboard. Never sends argument values or resource content.
