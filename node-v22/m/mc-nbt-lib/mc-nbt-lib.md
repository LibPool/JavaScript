# mc-nbt-lib

> 标签: binary, chunk, dat, inventory, level, mca, minecraft, nbt, parser, playerdata, region, save, snbt, world

## 简介

A comprehensive Node.js library for reading, writing, and manipulating Minecraft NBT, DAT, and MCA files with SNBT and JSON conversion support
