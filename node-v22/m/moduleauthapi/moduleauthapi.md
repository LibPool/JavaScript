# moduleauthapi

> 标签: JavaScript

## 简介

Ce module npm fournit une solution pratique pour sécuriser les routes de votre API associée. Il permet de récupérer les informations de l'utilisateur à partir du jeton JWT présent dans l'en-tête de la requête, puis les compare aux exigences de la route sp
