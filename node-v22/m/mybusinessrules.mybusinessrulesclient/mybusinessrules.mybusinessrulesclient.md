# mybusinessrules.mybusinessrulesclient

> 标签: JavaScript

## 简介

The MyBusinessRulesClient simplifies executing business rules via https://www.mybizrules.com. It encapsulates the logic to send JSON data to My Business RUules and handles the response, making it easy to integrate with the system.
