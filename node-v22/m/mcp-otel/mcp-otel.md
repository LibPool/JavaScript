# mcp-otel

> 标签: distributed-tracing, genai, mcp, model-context-protocol, observability, opentelemetry, traceparent, tracing, w3c-trace-context

## 简介

W3C Trace Context bridge for the Model Context Protocol — propagate traces through MCP _meta and emit OpenTelemetry spans so Host -> MCP server -> tool -> downstream shows up as one trace.
