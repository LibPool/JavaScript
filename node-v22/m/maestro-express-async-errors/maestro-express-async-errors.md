# maestro-express-async-errors

> 标签: async, async errors, async/await, await, error, error middleware, error-handler, express, express-async-handler, expressjs, handling, typescript

## 简介

TypeScript-first async error wrapper for Express, with optional Express 4 global patch and domain error routing.
