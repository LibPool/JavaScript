# manual-markdown

> 标签: markdown, markdown-editor, markdown-parser, markdown-to-html, markdown-viewer

## 简介

Markdown 是一种轻量级的标记语言。它允许使用易读易写的纯文本格式编写文档，然后转换成 HTML 文档。
