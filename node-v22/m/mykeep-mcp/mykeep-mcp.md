# mykeep-mcp

> 标签: ai-agents, mcp, model-context-protocol, mykeep, secrets, vault

## 简介

Optional MCP server for mykeep: exposes the memory + vault REST endpoints as MCP tools. Holds no secrets — every tool is a 1:1 passthrough to the gateway with the user's token.
