# mcp-ja-text

> 标签: era, grapheme, i18n, japanese, mcp, nengo, normalization, wareki

## 简介

Deterministic Japanese text tools for MCP clients: wareki/seireki conversion, normalisation, and validation. No LLM calls, no network, no API keys.
