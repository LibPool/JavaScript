# minimojs

> 标签: 2d, canvas, emoji, engine, game, minimal, typescript

## 简介

MinimoJS v1 — ultra-minimal, flat, deterministic 2D web game engine. Emoji-only sprites, rAF loop, TypeScript-first, LLM-friendly.
