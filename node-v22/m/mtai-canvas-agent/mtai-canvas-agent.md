# mtai-canvas-agent

> 标签: JavaScript

## 简介

本地 Canvas Agent 用来连接 MTAI 画布网页和用户电脑上的 Codex / Claude Code。本地开发时优先连接 `http://localhost:3000`，不需要先使用线上站点。

## 官网

- npm 页面：https://www.npmjs.com/package/mtai-canvas-agent

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- npm 安装：`npm install mtai-canvas-agent`
- npm registry：https://registry.npmjs.org/mtai-canvas-agent
- Node 要求：>=18
