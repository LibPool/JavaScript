# mern-vault

> 标签: boilerplate, cli, express, fullstack, generator, mern, mongodb, react, scaffold, starter, tailwindcss, template, vite

## 简介

Production-ready, interactive CLI scaffolding utility for hardened MERN stack projects. Generates a complete frontend (Vite + React + Tailwind CSS) and backend (Express + MongoDB) workspace with enterprise security baked in.
