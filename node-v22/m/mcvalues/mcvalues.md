# mcvalues

> 标签: Boolean, Byte, Double, Float, Int, Long, Minecraft, Short, String, Varint, Varlong, mc, protocol, values

## 简介

This is a simple Node.js module for converting data to and from Minecraft's binary format. More information about this data can be found in this [Minecraft Wiki article](https://minecraft.wiki/w/Java_Edition_protocol/Packets).
