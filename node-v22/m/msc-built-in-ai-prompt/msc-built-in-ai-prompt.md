# msc-built-in-ai-prompt

> 标签: built-in ai, front-end, gemini, web, web component

## 简介

<msc-built-in-ai-prompt /> is a web component based on Chrome Built-in AI Prompt API. Web developers could use <msc-built-in-ai-prompt /> to connect with Gemini Nano and provide vivid features.
