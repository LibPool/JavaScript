# mic-lovely-ui

> 标签: JavaScript

## 简介

* 目录说明 packages/.. => 放置应用包，搭建与用户交互的应用页面   ui-packages/.. => 放置组件包，提供依赖给有需要的应用包   other-packages/.. => 从第三方开源项目中直接拉过来参考的项目，不会直接使用，要么改成vue的包，要么直接复制其中的js脚本等相关文件来用
