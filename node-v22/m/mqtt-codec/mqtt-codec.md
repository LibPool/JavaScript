# mqtt-codec

> 标签: JavaScript

## 简介

- Fast MQTT packet encoder/decoder for Node.js. - `mqtt-codec` is 4-10x faster than `mqtt-packet` and uses less memory, see benchmarks below. - Zero dependencies. - TypeScript types included.
