# makerflow-cli

> 标签: collaboration, deep work, distraction blocker, do not disturb, google calendar, macos, makerflow, notification aggregator, notification blocker, productivity, pull requests dashboard, slack

## 简介

Block distractions and get all your notifications/tasks in one place from other collaboration apps like messages from Slack and pull requests from GitHub or Bitbucket.
