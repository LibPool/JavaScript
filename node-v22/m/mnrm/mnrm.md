# mnrm

> 标签: NPM, registry

## 简介

NPM registry manager can help you easy and fast switch between different npm registries, now include: cnpm, taobao, nj(nodejitsu), rednpm, mnpm

## 官网

- 官网：https://github.com/Pana/nrm
- npm 页面：https://www.npmjs.com/package/mnrm
