# malinois-scan

> 标签: appsec, bolt, ci, firebase, lovable, replit, rls, scanner, secret-detection, security, supabase, vibe-coding

## 简介

Passive security check for a deployed web app — finds publicly readable databases, secrets left in client bundles, and exposed files. Built for apps shipped with AI builders (Lovable, Replit, Bolt, v0, Base44).
