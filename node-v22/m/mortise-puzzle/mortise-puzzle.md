# mortise-puzzle

> 标签: clip-path, jigsaw, mortise-and-tenon, pseudo-3d, puzzle, react, svg-path, tenon, vue, 拼图, 榫卯

## 简介

Cut any image into a 2x2 mortise-and-tenon jigsaw and render each piece as pseudo-3D with pure CSS. 榫卯拼图切割算法 + CSS 伪 3D 渲染。
