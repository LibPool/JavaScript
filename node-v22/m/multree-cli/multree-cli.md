# multree-cli

> 标签: apfs, cli, dev-tools, git, monorepo, polyrepo, reflink, worktree

## 简介

Multi-repo git worktree group orchestrator: spin up linked worktrees across N repos, run per-repo hooks, prime heavy artifacts via APFS reflinks, and wire consumer env files to values exposed by producer repos.
