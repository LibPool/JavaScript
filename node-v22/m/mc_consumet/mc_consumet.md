# mc_consumet

> 标签: anime, books, comics, consumet, light-novels, manga, meta, movies, news, scraper, streaming

## 简介

A custom for of Comsumet - Nodejs library that provides high-level APIs for obtaining information on various entertainment media such as books, movies, comic books, anime, manga, and so on.
