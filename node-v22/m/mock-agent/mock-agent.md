# mock-agent

> 标签: ajax, anyProxy, connect, middleware, mock, proxy

## 简介

线上ajax请求抓去工具，connect中间件。这两件事结合起来很有意义，工具从线上抓真实数据，生成mock文件，更加真实，快速。connect中间件用于对外提供mock数据服务。
