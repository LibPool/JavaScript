# mage-obsidian

> 标签: build-tools, esm, frontend, magento, magento2, mageobsidian, tailwindcss, theme, vite, vue

## 简介

The MageObsidian JS build engine for Magento 2 frontends: theme inheritance resolution, precompilation and JS interceptors for Vite builds.
