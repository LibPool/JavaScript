# markitdown-html

> 标签: browser, converter, html, html-to-markdown, markdown, markdownify, markitdown, typescript

## 简介

A faithful TypeScript port of Microsoft MarkItDown's HTML-to-Markdown converter. Works in Node.js and the browser.
