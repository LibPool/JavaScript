# magic-webp

> 标签: animated, browser, compression, convert, crop, gif, image, jpeg, optimization, png, resize, wasm, webassembly, webp

## 简介

Convert PNG/JPEG/GIF to WebP and process images (crop, resize) in the browser using WebAssembly. Supports animated GIFs.
