# medusa-email-confirmation-plugin

> 标签: ecommerce, email, email confirmation, email-confirmation, headless, medusa, medusa-plugin, medusa-plugin-admin, medusa-plugin-customer, medusa-plugin-email, medusa-plugin-email-confirmation, medusa-plugin-other, typescript

## 简介

medusa-email-confirmation-plugin is a Medusa plugin that adds obligatory requirement for customers to confirm their email used for sign up to Medusa ecommerce stores.
