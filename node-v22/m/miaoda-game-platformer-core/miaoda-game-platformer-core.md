# miaoda-game-platformer-core

> 标签: cocos, committed-jump, coyote-time, dash, jump, jump-buffer, movement, phaser, platformer, retro-platformer, wall-jump

## 简介

Engine-agnostic 2D platformer movement core with modern feel and committed-action models: variable jump, coyote/buffer, walls and dash via PlatformerBody; fixed arcs, locked air momentum, action constraints and knockback ownership via CommittedPlatformerB
