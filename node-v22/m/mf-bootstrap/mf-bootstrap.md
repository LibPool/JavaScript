# mf-bootstrap

> 标签: calions, micro frontends

## 简介

`mf-bootstrap` allows you to generate micro frontends to be used with [mf-maestro](https://github.com/calions-app/mf-maestro) and [mf-bundler](https://github.com/calions-app/mf-bundler)
