# mcp-authcheck

> 标签: authorization, cli, conformance, mcp, model-context-protocol, oauth, oauth2, rfc8707, rfc9728, security

## 简介

Grade any MCP server against the MCP authorization spec (OAuth 2.1, RFC 9728/8414/8707). Read-only, non-destructive conformance checks.
