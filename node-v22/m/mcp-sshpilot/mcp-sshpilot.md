# mcp-sshpilot

> 标签: claude, cursor, mcp, model-context-protocol, proxy, server-management, sftp, socks, ssh

## 简介

MCP server for managing remote machines over SSH — proxy support (SOCKS4/5, HTTP/HTTPS CONNECT), SFTP, dangerous-command guard, background jobs, server profiles.
