# mini-webpack-build

> 标签: JavaScript

## 简介

module.hot.accept()是webpack中的一个API，用于在开发模式下实现热更新。 热更新可以让代码更改后自动重新加载到浏览器中，而无需手动刷新页面。 module.hot.accept()允许开发者在代码发生变化时触发回调函数，通过回调函数来更新页面上的内容。
