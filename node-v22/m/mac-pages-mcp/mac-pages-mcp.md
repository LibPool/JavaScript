# mac-pages-mcp

> 标签: apple-pages, applescript, automation, claude, document-generation, docx, macos, mcp, model-context-protocol, pages

## 简介

MCP server giving AI agents full autonomous control of Apple Pages on macOS — author styled documents, insert images and tables, format text, and export to PDF/Word.
