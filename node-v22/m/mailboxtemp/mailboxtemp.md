# mailboxtemp

> 标签: disposable-email, email-testing, mailboxtemp, otp, qa, temp-mail, temporary-email, testing, verification

## 简介

Tiny, dependency-free Node.js client for the MailboxTemp disposable / temporary email API — create inboxes and read messages (incl. OTP codes) for automated signup and email-verification testing.
