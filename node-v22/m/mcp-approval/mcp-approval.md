# mcp-approval

> 标签: confirmation, elicitation, human-in-the-loop, mcp, model-context-protocol

## 简介

Ask a human before your MCP tool does something irreversible — elicitation on both protocol revisions, with a two-call confirmation token for clients that cannot be asked
