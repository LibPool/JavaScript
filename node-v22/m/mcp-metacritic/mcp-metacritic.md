> 标签: ai, claude, cursor, games, llm, mcp, mcp-server, metacritic, metascore, model-context-protocol, modelcontextprotocol, movies, no-api-key, ratings, reviews, tv

## 简介

MCP server for Metacritic. Search films, shows and games, read Metascores and critic reviews with attribution. No API key required.
