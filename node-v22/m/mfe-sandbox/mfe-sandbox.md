# mfe-sandbox

> 标签: JavaScript

## 简介

基于 `Proxy` 实现的微前端 JS 运行时沙箱，用于在同一个页面中隔离多个子应用的全局变量与 DOM 操作。配合 `vite-plugin-mfe-sandbox` 使用效果最佳。
