# mac-mini-mcp

> 标签: JavaScript

## 简介

A Model Context Protocol (MCP) stdio server that gives Claude Code (or any MCP client) access to your Mac and its iOS Simulators via the [Hatch mac-mini-client](https://hatch-web.pages.dev).
