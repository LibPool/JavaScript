# medusa-payment-provider

> 标签: medusa, medusa-plugin, medusa-plugin-other, medusa-v2, plugin

## 简介

Universal payment provider plugin for Medusa v2 — Razorpay, Stripe, PayPal, PayU, Juspay, PhonePe, Paytm, Cashfree, HDFC, PagLocal (PayGlocal), plus 1-click UPI identifiers.
