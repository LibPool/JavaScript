# mighty-reviewer

> 标签: adversarial-review, code-review, dry, opencode, opencode-plugin, solid

## 简介

opencode plugin that runs an automatic background adversarial code review (mechanical gates + risk critique + DRY/SOLID/design enforcement + OWASP security checklist) whenever a turn writes code, with a SHIP / NO-SHIP verdict.
