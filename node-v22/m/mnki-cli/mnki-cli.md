# mnki-cli

> 标签: a2a, agent-security, ai-agents, authorization, authzen, delegation, dpop, jws, mcp, mnki, spiffe, wimse

## 简介

mnki — init, identity, verify, inspect, delegate, attest, scan, protect (local MCP proxy, dry-run by default), conformance (agenttrust remains an alias). Run with `npm run agenttrust -- <command>` in the monorepo (tsx); packaged bins in the public repo.
