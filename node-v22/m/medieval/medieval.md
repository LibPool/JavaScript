# medieval

> 标签: JavaScript

## 简介

MediEval is a library that lets you evaluate code in several language runtimes. MediEval functionality is exposed in two convenient ways: 1. Command line executable, called 'medieval' 2. Node.js APIs, using `require('medieval')`.
