# md2ast

> 标签: ast, commonmark, llm, markdown, markdown-it, parser, renderer, typescript

## 简介

A lightweight, highly extensible, and strictly typed CommonMark-compliant Markdown parser and renderer written in TypeScript. Optimized for programmatic AST analysis and LLM-driven cleaning.
