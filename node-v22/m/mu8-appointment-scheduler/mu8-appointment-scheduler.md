# mu8-appointment-scheduler

> 标签: ant-design, appointment-scheduler, booking, calendar, dayjs, react, scheduler, typescript

## 简介

基于 React 18 + Ant Design 5 + Dayjs + TypeScript 打造的企业级预约时间管理看板组件。支持日 / 周 / 月 / 自定义日期范围四种视图，覆盖新建预约、拖拽改约、上下拉手调时长、客户优先模式、异步客户/服务搜索、冲突实时检测、弹回动画、营业参数本地持久化等完整场景
