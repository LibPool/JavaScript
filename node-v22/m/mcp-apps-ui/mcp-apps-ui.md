# mcp-apps-ui

> 标签: components, ext-apps, mcp, mcp-apps, mcp-ui, model-context-protocol, ui, ui-components, widgets

## 简介

Copy-paste UI components for MCP Apps. One self-contained HTML file per component, zero runtime dependencies, themeable with CSS variables.
