# mcp-ptitchef

> 标签: cooking, french-recipes, mcp, model-context-protocol, ptitchef, recipes

## 简介

MCP server for Ptitchef. Search recipes, browse the category tree, read one with its ingredients and method, rescale it, and cook from what is in the fridge. No API key required.
