# mcpgenx

> 标签: ai, cli, code-generation, graphql, mcp, model-context-protocol, openapi

## 简介

Generate a working, typed, deployable MCP server from an OpenAPI spec, GraphQL schema, or code repo. Installs the `mcpgen` command.
