# multirizcli

> 标签: agent, ai, cli, coding, multiriz, openrouter

## 简介

MultiRiz interactive AI coding CLI — Claude-Code-style agent that reads/writes/edits files and runs shell commands in your current folder, billed to your MultiRiz AI Credits. Zero npm dependencies — runs directly with node.
