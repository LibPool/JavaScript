# mcp-webapi-bridge

> 标签: agent, bridge, http, mcp, stdio, streamable-http, webapi

## 简介

MCP (Model Context Protocol) Streamable HTTP bridge. Connects stdio-based MCP clients to remote MCP servers via HTTP POST.
