# mobile-native-barcode-generator

> 标签: android, barcode, barcode-component, barcode-generator, c++, code-128, code128, cpp, cross-platform, expo, image-generation, ios, mobile, native-module, new-architecture, png, qr-code, qr-code-generator, qr-component, qrcode, react, react-native, react-native-web, save-to-gallery, turbo-module, wasm, web, webassembly, windows

## 简介

High-performance barcode & QR code generator for React Native and the web. Shared C++ core produces byte-identical PNGs on Android, iOS, Windows and WebAssembly — zero native dependencies, zero JS encoding libraries.
