# mikser-io-provider-directus

> 标签: JavaScript

## 简介

Directus as a content source for mikser-io. Lifecycle plugin syncs configured collections (and the directus_files store) into the catalog; `read(entity)` plugs into the engine's scheme-dispatched readEntityContent. Realtime via outbound WebSocket subscrip
