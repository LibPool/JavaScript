# minicpm-vision-mcp-bridge

> 标签: image-understanding, mcp, minicpm, ollama, vision

## 简介

MCP server for MiniCPM-V local vision via Ollama. Windows-native (no WSL needed for the MCP process); connects to Ollama over HTTP.
