# melta-app

> 标签: ai-ready, design-system, expo, melta, react-native, ui-kit

## 简介

melta for APP — melta デザインシステムの React Native UI kit。melta-contracts（デザイン契約）を single source of truth に RN 実装でその契約を満たす。アプリ本体ではなくライブラリ。
