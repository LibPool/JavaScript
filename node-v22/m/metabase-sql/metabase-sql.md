> 标签: ai-agent, claude, claude-code, cli, cursor, database, mcp, mcp-server, metabase, model-context-protocol, mysql, postgres, sql, sql-client, terminal

## 简介

Interactive SQL CLI and MCP server for Metabase. Query any Metabase database from the terminal or from AI agents (Claude, Cursor) without direct DB credentials.
