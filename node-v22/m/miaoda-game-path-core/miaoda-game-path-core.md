# miaoda-game-path-core

> 标签: arc-length, bezier, catmull-rom, cocos, path, path-following, phaser, spline, waypoint

## 简介

Engine-agnostic path-following core: waypoint polylines, Catmull-Rom splines and cubic beziers, an arc-length 'baking' engine for constant-speed travel, and a PathFollower with tangent-facing rotation and perpendicular sine sway. No rendering, no engine d
