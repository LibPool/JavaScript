# mcp-catastro

> 标签: cadastre, catastro, claude, gis, inspire, mcp, mcp-server, model-context-protocol, parcels, spain

## 简介

MCP server for the Spanish Catastro - local INSPIRE parcel cache, OVC lookups and sede electronica, with daily rate caps and block diagnosis
