# magicworker

> 标签: magic, manager, multithreading, performance, threading, worker

## 简介

A bundle of web worker management utilities for single script pipeline creation. Includes events, messagechannels, automatic typedarray transfer (especially for passing large datasets between workers), and canvas with input proxies, gpujs functions with g
