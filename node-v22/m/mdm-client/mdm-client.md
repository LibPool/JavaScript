# mdm-client

> 标签: JavaScript

## 简介

- **接口与 `meetingConfig` / `meetingFeatures` 的完整说明**（含默认 tab、`isDefault`、监控懒加载、Vue2 工具导出与破坏性变更）见仓库内 **`lib/MDM会议组件使用手册(vue3).md`**；其中 **「附录：本仓库 Vue2（mdm-client）与 meetingConfig 对齐」** 与当前 Vue2 源码一致。 - **Vue3 安装使用**：npm 包 **`mdm-client-plus`**，按该手册「快速开始」接入。
