# mini-cache-ttl

> 标签: JavaScript

## 简介

*Простой, легковесный in-memory кэш с TTL (Time-To-Live) для Node.js и браузера.* Поддерживает локальные хранилища, централизованный сервер и интеграцию с express-session.
