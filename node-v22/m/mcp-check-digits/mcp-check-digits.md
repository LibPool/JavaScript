# mcp-check-digits

> 标签: check-digit, iban, isbn, luhn, mcp, mcp-server, modelcontextprotocol, validation, vin

## 简介

MCP server that validates check digits for IBAN, LEI, ISBN, GTIN/UPC, VIN, NPI, ISIN, ABA routing numbers and payment cards.
