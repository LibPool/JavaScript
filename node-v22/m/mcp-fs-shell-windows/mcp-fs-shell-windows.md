# mcp-fs-shell-windows

> 标签: claude, deno, filesystem, lm-studio, mcp, model-context-protocol, puppeteer, shell, windows

## 简介

MCP server with 82 tools: batched filesystem access, standalone Windows shell, and a Beledarian-parity tool set (git, GitHub, system, document, database, web, RAG, browser, sub-agent). Extended fork of mcp-filesystem-extended.
