# makeit-search

> 标签: makeit, makeit search, makeit-search, makeit.vip, miitvip, vite, vue, vue3, 麦可易特网

## 简介

Makeit Search 搜索组件，基于 Vue3.x + Vite4.x 开发，默认根据本地数据进行数据筛选，支持远程搜索，同时也支持搜索结果分页配置，自定义结果列表中每一项的点击事件等
