# mng-js-marker-clusterer

> 标签: api, cluster, clusterer, google, javascript, js, marker, v3

## 简介

The library creates and manages per-zoom-level clusters for large amounts of markers. Google API v3. It's a fork based on https://github.com/googlemaps/js-marker-clusterer, adding some callbacks for click and dblclick event on marker clusterer
