# margin-padding.js

> 标签: CSS, CSS3, html, js, margin, padding

## 简介

MarginPadding is a lightweight JavaScript library that automatically applies margin and padding to HTML elements based on data-margin and data-padding attributes. It supports the x and y axes, as well as multiple values at once. Simplifies working with sp
