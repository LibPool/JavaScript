# macroify

> 标签: .macro, babel, babel-plugin-macros, boilerplate, create-react-app, createMacro, development, loader, macro, macros, module, plugin, production, utility, webpack, wrapper

## 简介

Macroify allows you to easily turn any JavaScript module, into a Babel macro that behaves (almost) like a regular object... but at build time.
