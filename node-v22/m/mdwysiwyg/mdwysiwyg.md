# mdwysiwyg

> 标签: editor, gfm, markdown, markdown-editor, react, react-component, rich-text-editor, syntax-highlighting, tiptap, wysiwyg

## 简介

Free, open-source, fully customizable Markdown WYSIWYG editor for React with dual synced views (rich-text + raw Markdown), GFM, syntax highlighting, and CSS theming.
