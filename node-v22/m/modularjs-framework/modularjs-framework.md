# modularjs-framework

> 标签: civet, compiler, custom-elements, framework, frontend, mjs, modularjs, reactive, shadow-dom, spa, web-components

## 简介

ModularJS (MJS) — framework front compile-time : réactivité résolue à la compilation (sans Proxy au runtime), Custom Elements + Shadow DOM, syntaxe .mjs (Civet par défaut). Compilateur + runtime + CLI dev/HMR.
