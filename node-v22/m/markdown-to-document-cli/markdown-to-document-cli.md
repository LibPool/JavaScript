# markdown-to-document-cli

> 标签: cli, converter, document, ebook, epub, markdown, npx, pandoc, pdf, publishing, typography

## 简介

Professional-grade EPUB/PDF conversion tool for Markdown files. 8 validation modules, auto-fix, typography presets, font subsetting (99% size reduction), ISBN validation, copyright page generation.
