# mona-attest-frontend

> 标签: attestation, authentication, cryptography, frontend, mona, passkey, payments, react, sdk, webauthn

## 简介

Mona AttestTool Frontend SDK - Secure client-side user attestation and biometric verification for React/Next.js applications. Provides seamless integration for payment flows, user discovery, and cryptographic signing with WebAuthn support.
