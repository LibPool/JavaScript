# md-tmpl-wasm-tests

> 标签: JavaScript

## 简介

WebAssembly bindings for the [md-tmpl](https://github.com/domenukk/md-tmpl) engine. Wraps the full Rust engine via `wasm-bindgen` for use in Node.js and browser environments.
