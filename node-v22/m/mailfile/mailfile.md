# mailfile

> 标签: browser, cfb, compound-file, converter, email, eml, lzfu, mapi, mime, msg, ole2, outlook, rfc5322, rtf

## 简介

Read and write Outlook .msg and RFC 5322 .eml files. Zero dependencies, runs in browsers, Node, Deno, Bun and workers.
