# model-shunt

> 标签: ai, claude, code-generation, cursor, llm, mcp, model-context-protocol, model-routing

## 简介

Model routing for AI coding agents - delegate bulk file reading and boilerplate generation to fast, economical worker models via MCP. Zero Python dependencies.
