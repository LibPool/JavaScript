# mcp-yandex-wordstat

> 标签: keyword-research, mcp, model-context-protocol, search-demand, seo, wordstat, yandex, yandex-wordstat

## 简介

MCP server for the Yandex Wordstat API via Yandex Cloud Search API v2 — search-demand statistics (top & related queries, time dynamics, regional distribution) for AI agents.
