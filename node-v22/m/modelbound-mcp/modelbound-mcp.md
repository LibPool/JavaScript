# modelbound-mcp

> 标签: agent-skills, ai-agents, claude, codex, context-engineering, cursor, generative-ai, kiro, llm, mcp, model-context-protocol, modelbound, prompt-engineering, skill-pipeline, token-optimization, vscode, windsurf

## 简介

Local-first MCP server for agent skills. Validate, lint, diff, convert, optimize tokens, and run the Skill Development Pipeline across Cursor, Claude, Codex, Kiro, Windsurf, VS Code, and Amazon Q. Optional cloud sync with ModelBound.
