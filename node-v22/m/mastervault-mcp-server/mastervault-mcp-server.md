# mastervault-mcp-server

> 标签: knowledge-base, mastervault, mcp, model-context-protocol, obsidian, second-brain, stdio, vault

## 简介

A headless, filesystem-backed MCP server that serves any MasterVault — its files and its operating protocol — to any MCP client. No Obsidian required.
