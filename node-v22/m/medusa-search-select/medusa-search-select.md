# medusa-search-select

> 标签: autocomplete, combobox, component, dropdown, medusa, medusa-js, medusajs, react, search-select, select

## 简介

A searchable, accessible select/combobox component for React, built for Medusa.js storefronts and admin dashboards (but usable in any React app).
