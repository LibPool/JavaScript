# mochi-zalo

> 标签: chat, messaging, multi-account, vietnam, webhook, zalo, zalo-api, zalo-bot

## 简介

Zalo personal API library for Node.js/TypeScript. Send messages, manage groups and friends, listen to events, multi-account support.
