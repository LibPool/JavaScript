# mini-tw-vite

> 标签: css, css-framework, tailwind, utility, utility-first, vite, vite-plugin

## 简介

Vite plugin for mini-tw — virtual CSS module with on-demand class generation. Scans source files, generates only used utility classes, supports HMR.
