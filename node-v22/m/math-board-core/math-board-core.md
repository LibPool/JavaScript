# math-board-core

> 标签: JavaScript

## 简介

数学画板核心 — GeoDocument 数据模型 + JSXGraph 引擎 + GeoGebra 风格命令 DSL + 流式 blockParser。aiws3-app / aiws3.1-web / aiws3.1-server 共用的单一源(全 ESM,Node v24 require(ESM) 可直接用)。
