# miniframe-tools-mcp

> 标签: agent-tools, brazil, cep, cnpj, markdown, mcp, modelcontextprotocol, pdf, pix, screenshot, x402

## 简介

MCP server for Brazilian data and document tools: Pix BR Codes, CEP and CNPJ lookup, web capture and PDF compression. Pay-per-call in USDC on Base via x402 — no signup, no API key.
