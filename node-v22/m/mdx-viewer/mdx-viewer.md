# mdx-viewer

> 标签: cli, documentation, katex, markdown, mdx, mermaid, offline, react, renderer, self-contained, shiki, viewer, vite

## 简介

Local MDX renderer: `mdxv <file|dir>` previews in the browser, `mdxx <file>` exports a self-contained offline HTML. Built on official @mdx-js + Vite + React — 100% MDX syntax compatible, components extensible.
