# miaoda-game-kinematic2d-core

> 标签: character-controller, cocos, collision, kinematic, phaser, platformer, top-down

## 简介

Deterministic engine-independent 2D kinematic body movement with swept AABB collision, slide response, one-way platforms, moving-platform carry, grounding, filtering, and snapshots.
