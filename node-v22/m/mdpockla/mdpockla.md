# mdpockla

> 标签: agent, cli, markdown, mcp, md-pockla, mdpockla, notes, pockla, share

## 简介

CLI for md.pockla.com - save and edit markdown notes from your shell or CI. Pairs with the md pockla MCP server for agent-native sharing.
