# mcp-mercado-publico

> 标签: chile, chilecompra, licitaciones, mcp, mercado-publico, model-context-protocol

## 简介

MCP server para la API pública de Mercado Público (ChileCompra). Consulta licitaciones, órdenes de compra y empresas del Estado chileno en tiempo real.
