# miragehttp

> 标签: JavaScript

## 简介

`miragehttp` 是一个基于 `Vue 3 + TypeScript + Vite` 构建的前端 SDK，用于统一封装 Mirage 系列系统的数据访问、登录、上传与多业务模块调用能力。
