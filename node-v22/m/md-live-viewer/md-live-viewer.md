# md-live-viewer

> 标签: ai-agent, cursor, file-watcher, hot-reload, live-reload, llm, markdown, preview, viewer

## 简介

Live-updating local markdown viewer. Run `npx md-live-viewer` in any folder to preview markdown files and see edits (e.g. from an AI agent) appear instantly -- no manual refresh.
