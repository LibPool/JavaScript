# mars-globe

> 标签: 3d, cesium, cesiumjs, gis, globe, mars, mola, nasa, planetary, space, trek, web-component

## 简介

Drop-in 3D Mars globe for CesiumJS — Mars ellipsoid, NASA Mars Trek basemaps, geographic tiling, no Ion token. NPM package, <mars-globe> Web Component, and CesiumJS plugin.
