# megallm

> 标签: ai, claude, cli, codex, configuration, megallm, oauth, opencode, setup

## 简介

Sign in once, configure Claude Code / Codex / OpenCode. Interactive Ink-based hub with OAuth device flow, named profiles, and per-org API keys.
