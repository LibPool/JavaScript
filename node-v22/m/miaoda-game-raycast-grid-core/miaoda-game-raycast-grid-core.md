# miaoda-game-raycast-grid-core

> 标签: cocos, dda, first-person, grid, phaser, pseudo-3d, raycasting, wolfenstein

## 简介

Engine-agnostic Wolfenstein-style grid raycasting with exact DDA traversal, camera columns, billboard projection and occlusion, plus flat floor/ceiling sampling spans. No rendering dependency.
