# mcp-jp-calendar

> 标签: business-days, calendar, fiscal-year, gotobi, holidays, japan, japanese, japanese-holidays, mcp, mcp-server, model-context-protocol

## 简介

MCP server for Japanese business-day, holiday, and fiscal-period calculations (business days, national holidays, gotobi settlement days, fiscal quarters) with no runtime network access.
