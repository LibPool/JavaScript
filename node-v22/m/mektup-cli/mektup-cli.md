# mektup-cli

> 标签: ai-agent, cli, domain-email, email, email-hosting, imap, smtp

## 简介

Command-line client for Mektup - register domains, create mailboxes, send email, and list messages against your Mektup account, from any shell or script. The fallback path for agents/environments without MCP support.
