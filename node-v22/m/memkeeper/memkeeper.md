# memkeeper

> 标签: agent-memory, ai-agents, deterministic, local-first, mcp, orchestration, permissions

## 简介

Local-first, deterministic control plane for AI agents: durable memory, project context, coordinated task handoffs, and deny-by-default permissions — all on your own machine, no LLM in the decision path. Reserved namespace for the memkeeper project; see h
