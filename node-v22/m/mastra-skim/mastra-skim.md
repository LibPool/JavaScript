# mastra-skim

> 标签: agent, ai, markdown, mastra, mastra-tool, reader, skim, web-scraping, x402

## 简介

Mastra tool for Skim (skim402.com) — clean web reader for AI agents. Fetch any URL as agent-ready Markdown. Card plan API key (free tier at skim402.com/pricing) or pay-per-call via x402 USDC wallet.
