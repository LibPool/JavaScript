# medusa-plugin-printful

> 标签: medusa, medusa-plugin, medusa-plugin-fulfillment, medusa-plugin-other, medusa-plugin-shipping

## 简介

A Medusa plugin that enables Printful as a fulfillment provider and provides product and order synchronization.
