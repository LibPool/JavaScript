# maiass

> 标签: ai, ai-commit, ai-commit-message, automation, changelog, changelog-generator, cli, commit, commit-message-generator, conventional-commits, developer-tools, git, git-automation, git-workflow, openai, semantic-versioning, semver, version-bump, version-management, workflow

## 简介

AI commit messages, version bumps, and changelogs from one command. Stages, commits, merges, tags. Anonymous on first run — no email, no card.
