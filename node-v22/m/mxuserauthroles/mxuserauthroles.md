# mxuserauthroles

> 标签: auth, authentication, jwt, manage, middlewares, protect, responsibilities, roles, routes, types, user, user acess, user roles

## 简介

A modular approach to managing different user types and responsibilities. The library provides endpoints and middlewares to protect routes based on user roles.
