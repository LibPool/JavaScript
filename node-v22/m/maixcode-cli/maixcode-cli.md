# maixcode-cli

> 标签: agent-skill, cli, iot, maixcam, maixcode, maixpy, sipeed

## 简介

CLI for MaixCAM / MaixPy devices (discover, run code, capture image, SSH). Companion to MaixCode VS Code extension; ships agent skill under skills/maixcode.
