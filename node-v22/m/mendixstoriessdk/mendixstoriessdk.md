# mendixstoriessdk

> 标签: Client, Mendix, Mendix SDK, Mendix Stories API, NodeJS, SDK

## 简介

The Mendix Stories API SDK allows you to retrieve, create and update the sprints, stories and tasks in your Mendix projects.
