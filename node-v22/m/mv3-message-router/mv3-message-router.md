# mv3-message-router

> 标签: browser-extension, chrome-extension, chrome-runtime-sendmessage, content-script, edge-extension, firefox-extension, manifest-v3, message-passing, message-router, mv3, service-worker, typed-messaging, typescript, web-extension, webextension

## 简介

Chrome extension message router — type-safe wrapper over chrome.runtime.sendMessage for Manifest V3 (MV3) service workers, popups, and content scripts. End-to-end typed payloads, zero dependencies.
