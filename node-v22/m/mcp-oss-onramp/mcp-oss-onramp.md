# mcp-oss-onramp

> 标签: automation, beginner-friendly, github, good-first-issue, mcp, oss

## 简介

MCP server for high-precision OSS issue scouting. Supports MCP_OSS_ONRAMP_GITHUB_TOKEN for PR cross-referencing and avoiding rate limits.
