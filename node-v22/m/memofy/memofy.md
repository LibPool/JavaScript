# memofy

> 标签: cache, cacheable functions, decorator, function, javascript, memofy, memoization, memoize, memoizer, optimization, performance, typescript, use-memo, useMemo, usememo, utility

## 简介

Prevents re-execution of large javascript functions that have been processed once with the same parameter.
