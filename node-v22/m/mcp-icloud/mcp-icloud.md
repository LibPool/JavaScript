# mcp-icloud

> 标签: apple, applescript, caldav, carddav, claude, icloud, imap, imessage, mcp, mcp-server, model-context-protocol, notes, reminders, safari

## 简介

MCP server for Apple services - Email, Calendar, Contacts, Reminders, Notes, Messages and Safari - with dual local (AppleScript) and cloud (IMAP/CalDAV/CardDAV) modes
