# minter-mcp

> 标签: blockchain, bsv, bsv-21, claude, dstas, mcp, mint, model-context-protocol, stas, tokens

## 简介

MCP server that mints STAS, DSTAS and BSV-21 tokens straight into a running BSV Desktop wallet — funded from your own wallet, visible in Assets within seconds. For testing token flows without hand-rolling a mint.
