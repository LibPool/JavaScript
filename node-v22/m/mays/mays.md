# mays

> 标签: JavaScript

## 简介

先介绍下MayReact            MayReact是我参照React,preact,nerv,Inferno,anujs等库写的一个miniReact框架；其初衷和anu很相似就是写一个更小更快，     不过可以拥有react的api完美兼容其生态的一个框架；         只有2000多行;         受控组件,合成事件统统具备;         可以跑通绝大部分的官方测试用例保证其兼容性和健壮性;
