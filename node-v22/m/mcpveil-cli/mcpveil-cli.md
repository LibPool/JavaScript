> 标签: agents, ai-agents, ci, code-scanning, dast, devsecops, llm, mcp, model-context-protocol, owasp, pentest, sarif, scanner, security, security-scanner

## 简介

Deterministic security test suite for MCP servers: sends real payloads through live MCP sessions and confirms exploitability from responses. CI-native with SARIF 2.1.0 output for GitHub Code Scanning.
