# mp-request-promise

> 标签: axios, miniprogram, miniprogram-request, mp-request, request, uni.request, wx.request

## 简介

Promise based HTTP client for miniprogram. 基于promise的小程序网络请求库,实现拦截器、取消请求等功能,用法类似axios.
