# mcraft-fun-mineflayer

> 标签: connector, mcraft, mcraft-fun, mcraft.fun, minecraft, mineflayer, packets, passthrough, prismarine, prismarine-viewer, protocol, relay, retransmit, server, viewer, web

## 简介

Mineflayer viewer (connector) for mcraft.fun project and vanilla Minecraft client! Both TCP and WebSockets servers are supported.
