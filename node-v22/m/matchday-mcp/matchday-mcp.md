# matchday-mcp

> 标签: ai-tools, claude, football, mcp, model-context-protocol, soccer, thesportsdb, zod

## 简介

MCP server for live football data (teams, fixtures, results, standings) powered by TheSportsDB. Built with TypeScript and Zod.
