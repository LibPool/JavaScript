# modlens-fast

> 标签: deepseek-harness, dsh, modlens, multimodal, patch, vision

## 简介

给 DeepSeek Harness 的 ModLens 视觉插件提速的第三方补丁：图片+问题直接由视觉模型作答，跳过完整证据契约与 DeepSeek 二次思考，识图从 ~10 秒降到 ~2.5 秒
