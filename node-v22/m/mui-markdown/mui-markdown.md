# mui-markdown

> 标签: markdown, markdown diagram, markdown mermaid, markdown syntax highlight, material-ui markdown, mui, mui markdown, react markdown

## 简介

mui-markdown uses markdown-to-jsx and MUI(formerly material-ui) to help you render MD/MDX files with MUI components.
