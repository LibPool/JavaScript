# mcp-image-uploader-server

> 标签: convert, image-uploader, imagemagick, jpeg, mcp, model-context-protocol, native-nodejs, webp

## 简介

MCP server to download an image from a URL using native Node.js modules, convert WebP to JPEG if needed, and upload it to a pre-configured image host. No external dependencies on wget or curl required.
