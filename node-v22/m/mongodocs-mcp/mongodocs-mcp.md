# mongodocs-mcp

> 标签: ai, claude-desktop, code-search, cursor-ide, documentation, embeddings, github, mcp, model-context-protocol, mongodb-atlas, rag, semantic-search, vector-search, voyage-ai

## 简介

Transform any GitHub repository into searchable vector embeddings. MCP server with smart indexing, voyage-context-3 embeddings, and semantic search for Claude/Cursor IDEs.
