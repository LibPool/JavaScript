# mighty-instincts

> 标签: continuous-learning, ecc, instincts, opencode, opencode-plugin

## 简介

OpenCode V2 plugin that observes session activity and distils it into ECC-compatible instincts, exposes the ECC instinct CLI as slash commands, and (OpenCode 2 TUI) shows a collapsible sidebar board summarising instincts, observations and skill evals.
