# mock-switch-webpack-plugin

> 标签: Mock一键切换, Mock热更新, env-switch, hot-mock, mock, mock-switch, proxy, webpack, webpack-mock, 前端Mock神器, 前端接口代理, 接口模拟, 环境切换

## 简介

前端Mock神器！浏览器一键切换Mock/开发/生产环境的Webpack插件，支持接口代理、Mock数据热更新、POST请求自动转发等特性，零配置接入React/Vue等所有Webpack项目，彻底告别需手动修改代码来切换环境的低效开发方式。
