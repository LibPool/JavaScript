# mass-build-runtime-setting

> 标签: JavaScript

## 简介

## 前言 · 此工具主要是在devops流程中根据需要构建不同的运行配置文件， devops默认先执行npm run build 构建， 再根据是否有构建变量进行带有构建变量的构建如npm run build:UAT (UAT即你在devops配置的构建参数)
