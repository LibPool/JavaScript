# mconsole-npm

> 标签: console, debugging, haxe, logging, profiling

## 简介

A cross platform Haxe implementation of the WebKit console API supporting logging, debugging and profiling.

- 官网：http://open.massiveinteractive.com
- 源码仓库：git://github.com/massiveinteractive/mconsole.git
