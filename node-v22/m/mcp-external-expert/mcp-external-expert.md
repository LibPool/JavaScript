# mcp-external-expert

> 标签: ai, delegation, expert-system, llm, mcp, model-context-protocol, ollama, openai

## 简介

MCP server that allows primary LLMs to delegate sub-tasks to external expert models via APIs (Ollama, OpenAI-compatible)
