# mcp-output-firewall

> 标签: agent, ai-security, egress, firewall, guardrails, indirect-prompt-injection, llm, mcp, model-context-protocol, prompt-injection, security, tool-poisoning

## 简介

Three-layer firewall for MCP servers — content inspection, egress policy and action policy. Runs as a proxy or as a standalone MCP server an agent can call before it acts. Catches prompt injection, tool poisoning, exfiltration and leaked secrets.
