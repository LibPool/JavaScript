# maxxsuite

> 标签: api, colombia, dian, erp, facturacion-electronica, maxxsuite, pos

## 简介

SDK oficial de Node/TypeScript para la API v2 de MaxxSuite ERP+POS — facturación electrónica DIAN (Colombia), pedidos POS, catálogo, clientes, nómina electrónica y webhooks.
