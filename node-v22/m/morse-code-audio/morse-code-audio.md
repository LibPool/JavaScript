# morse-code-audio

> 标签: audio, cw, decoder, farnsworth, goertzel, ham-radio, koch, morse, morse-code, wav

## 简介

Morse code in JavaScript: translate text, build ITU timing with Farnsworth spacing, render WAV audio, and decode Morse from recorded or live audio. No dependencies.
