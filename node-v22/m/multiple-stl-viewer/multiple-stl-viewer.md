# multiple-stl-viewer

> 标签: 3D, GCode, GCode viewer, JavaScript, Multiple GCode viewer, Multiple STL viewer, React, STL, STL viewer, Three, Three.js

## 简介

A component for viewing one or more STL or GCode objects (on the same scene) from given URLs by utilizing Three.js
