# mxverify

> 标签: bulk-email-verification, disposable-email, email, email-deliverability, email-validation, email-verification, email-verifier, lead-generation, mx-lookup, mx-record, no-api, role-based-email, validate-email, verify-email

## 简介

Fast email verifier with no API key — checks syntax, disposable domains, role addresses, and live MX records. Tags each email valid / risky / invalid. Zero dependencies.
