# my-tiny-events

> 标签: browser-events, dependency-free, emitter, event-driven, event-emitter, events, javascript, lightweight, my-tiny-events, node-events, observer, tiny

## 简介

A lightweight, dependency-free event emitter system for JavaScript and TypeScript, inspired by Node.js EventEmitter with support for multi-event handling and listener management.
