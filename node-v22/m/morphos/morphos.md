# morphos

> 标签: config-driven, data-mapper, data-transformation, declarative-mapper, json, json-mapper, json-to-json, json-transformation, json-transformer, mapper, mapping, nodejs, object-mapper, object-mapping, react, transformation, typescript

## 简介

JSON-to-JSON mapper with user-defined JSON mapping specs, plain JS transformation expressions, and isolated VM execution.
