# mongo-dpf

> 标签: JavaScript

## 简介

连接数据库 查找 find /finddata  类型 get  前台必须传的参数 page 根据传入的time进行排序 添加/编辑 /editdata  类型 post  必须要有的参数 card name 根据-id来进行更改 没有-id 进行添加学生信息  删除 /deldata  查找-id有则删无则返回 res.send({ code: 0, msg: 'error' }) 根据-id查找 /iddata
