# miaoda-game-command-core

> 标签: cocos, command, deterministic, event-log, phaser, replay, simulation, tactics, turn-based, undo

## 简介

Engine-agnostic deterministic game-command runtime with validation, previews, atomic commits, structured events, serializable RNG, checkpoints, forks, undo barriers for revealed information, explicit player-view projection, and replay verification.
