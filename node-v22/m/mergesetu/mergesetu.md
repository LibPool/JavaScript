# mergesetu

> 标签: collaboration, conflict-detection, crdt, llm-agents, merge, multi-agent, semantic-conflict, yjs

## 简介

Semantic conflict detection for multi-agent Yjs editors. Watches concurrent CRDT merges, flags overlaps, and classifies whether both agent intents still hold — without ever blocking the merge path.
