# mcp-lean

> 标签: agents, ai, claude, claude-code, context-window, cursor, lazy-loading, llm, mcp, model-context-protocol, proxy, tokens

## 简介

A lazy-loading MCP proxy that cuts your agent's startup context from tens of thousands of tokens to a few hundred — it exposes upstream tool schemas only when they're actually needed.
