# moban-ui

> 标签: Moban, moban, moban-ui, ui, vue

## 简介

Moban 的灵感来源于 "科圣" 墨子和 "匠师" 鲁班 ，期望 Moban 赋予开发者们更多自定义组件的能力，是一套基于 Vue 2.0 的桌面级 UI 组件库。
