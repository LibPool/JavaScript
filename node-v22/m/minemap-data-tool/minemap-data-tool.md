# minemap-data-tool

> 标签: JavaScript

## 简介

1. npm i minemap-data-tool ######插件使用 2. 在 main.js 中    import MinemapDataTool from 'minemap-data-tool';    Vue.use(MinemapDataTool);  3. 将minemap的全局变量复制给这个插件   this.$minemapDataTool(this.map);
