# miaoda-game-topdown-vehicle-core

> 标签: arcade, car, cocos, drift, kinematics, overhead, phaser, top-down, vehicle

## 简介

Engine-agnostic top-down arcade vehicle kinematics with heading acceleration, rolling steering, and configurable grip. The overhead counterpart to arcade-motion-core and road-core.
