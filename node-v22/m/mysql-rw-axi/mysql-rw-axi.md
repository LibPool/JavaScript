# mysql-rw-axi

> 标签: agent, axi, cli, mysql, sql, toon

## 简介

WRITE ACCESS - loopback hosts only. MySQL CLI for agents that CAN MODIFY AND DROP DATA on local databases - exec, import, create/drop databases, plus every read-only mysql-axi command. Use mysql-axi for anything that is not a local dev database.
