# markdown-lsp-mcp

> 标签: docs, lsp, markdown, mcp, model-context-protocol, stdio

## 简介

Local MCP server over stdio exposing markdown-lsp tools (outline, search, links) for any docs/ directory. Used by docs-sync skill.
