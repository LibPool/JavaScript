# mimo-usage-dashboard

> 标签: cache, cli, dashboard, heatmap, mimo, mimo-desktop, mimocode, opencode, python, tokens, usage, xiaomi

## 简介

MiMo Desktop local usage dashboard — a zero-AI Python CLI that renders HTML dashboards (token usage, cache hit rate, model share, session stats, context occupancy). Static snapshot by default; --open starts a loopback-only read-only refresh server.
