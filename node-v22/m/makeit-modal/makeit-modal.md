# makeit-modal

> 标签: makeit, makeit admin pro, makeit-admin-pro, makeit-modal, makeit.vip, miitvip, modal, vite, vue, vue3, 麦可易特网

## 简介

Makeit Modal 弹窗组件，是基于 Vue3.0 + Vite 开发。该组件可以在当前页面打开一个浮层来处理相关事务的某些节点，不影响整个事务的流程。内含多种弹出动效，同时包含快捷弹窗，便于快速处理浮窗提示。
