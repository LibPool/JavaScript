# mt-card-validator

> 标签: JavaScript

## 简介

Esta biblioteca destina-se à validação de cartão de crédito, utilizando o algoritmo de [Luhn](https://en.wikipedia.org/wiki/Luhn_algorithm) para uso em aplicações desenvolvidas em JavaScript.
