# mongo-table-admin

> 标签: handsontable, import data to mongo, inline edit, mongo, mongo admin, parse dashboard, pivot table

## 简介

Admin interface for mongo. Work with documents as table rows. Integrates Handsontables, Pivottable, Visual Query.
