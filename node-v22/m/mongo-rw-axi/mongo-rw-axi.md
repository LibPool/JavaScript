# mongo-rw-axi

> 标签: agent, axi, cli, mongo, mongodb, toon

## 简介

WRITE ACCESS - loopback hosts only. MongoDB CLI for agents that CAN MODIFY AND DROP DATA on local databases - insert, update, delete, indexes, collections, import, plus every read-only mongo-axi command. Use mongo-axi for anything that is not a local dev
