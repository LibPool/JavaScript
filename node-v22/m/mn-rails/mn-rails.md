# mn-rails

> 标签: JavaScript

## 简介

用于快速创建MarginNote4插件打包工程的脚手架。内置`AGENTS.md`作为AI辅助开发Prompt，建议配合Codex、Trae等开发工具使用。如果你使用AI进行开发，强烈建议先安装[MCP](https://github.com/Temsys-Shen/marginnote-addon-docs?tab=readme-ov-file#本地mcp搜索)。
