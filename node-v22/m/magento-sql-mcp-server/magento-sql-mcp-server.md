# magento-sql-mcp-server

> 标签: adobe-commerce, ai, ai-tools, claude, cline, cursor, database, ddev, ecommerce, librechat, llm, magento, magento-2, magento2, mcp, mcp-server, model-context-protocol, mysql, read-only, sql, ssh-tunnel, vscode, windsurf

## 简介

Professional MCP server for read-only Magento 2 / Adobe Commerce MySQL queries. Supports DDEV auto-detect, SSH tunnels, direct remote DB, schema exploration, config inspection, and canned debug prompts for Cursor, Claude, VS Code, and LibreChat.
