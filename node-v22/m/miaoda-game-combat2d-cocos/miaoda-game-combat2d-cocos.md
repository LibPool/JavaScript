# miaoda-game-combat2d-cocos

> 标签: cocos, cocos-creator, combat, component, hitbox, hurtbox, iframes, knockback, system

## 简介

Cocos Creator hosts for miaoda-game-combat2d-core: a shared CombatWorld with a scene-owned CombatFieldComponent by default and an optional cross-scene CombatWorldSystem.
