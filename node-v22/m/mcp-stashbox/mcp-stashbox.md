# mcp-stashbox

> 标签: catalogue, fingerprint, mcp, metadata, model-context-protocol, phash, stash-box, stashdb

## 简介

MCP server for the public stash-box metadata catalogues. Search scenes, performers, studios and tags across the public stash-box catalogues.
