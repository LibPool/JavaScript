# minecraft-protocol-pkce

> 标签: authentication, bot, encrypton, minecraft, packet, parse, protocol, serialize

## 简介

Parse and serialize minecraft packets, plus authentication and encryption. Features PKCE-based Microsoft auth with browser flow.
