# mediawiki-sdk

> 标签: fandom, markdown, mediawiki, mediawiki-ts, nodejs, parser, sdk, typescript, wiki, wikibase, wikidata, wikimedia, wikipedia, wikitext

## 简介

TypeScript SDK for generating and working with WikiText and MediaWiki API. Allows to get pages from wiki projects built on mediawiki.
