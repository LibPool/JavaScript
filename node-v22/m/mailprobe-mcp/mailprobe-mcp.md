# mailprobe-mcp

> 标签: deliverability, disposable email, email checker, email validation, email verification, mailprobe, mcp, mcp-server, model-context-protocol

## 简介

Official MCP server of the MailProbe API: an AI assistant verifies email addresses in real time, without sending anything (deliverability, disposable and role-based detection, typo fixes). Hosted in France.
