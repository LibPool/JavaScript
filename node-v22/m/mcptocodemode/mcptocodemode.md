# mcptocodemode

> 标签: code-mode, mcp, mcp-gateway, mcp-proxy, mcp-server, model-context-protocol, quickjs, sandbox

## 简介

Stop flooding your agent's prompt with MCP tools: MCPtoCodeMode puts every MCP server behind 3 tools and a sandbox, for Codex, Claude Code, Cursor, Grok, OpenCode, Pi, or any MCP client.
