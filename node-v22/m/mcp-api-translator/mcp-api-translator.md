# mcp-api-translator

> 标签: ai-tools, api, claude, cline, codegen, cursor, llm-tools, mcp, model-context-protocol, modelcontextprotocol, openapi, postman, swagger

## 简介

An MCP server that turns OpenAPI / Postman API definitions into runnable MCP servers, making any API discoverable to AI models.
