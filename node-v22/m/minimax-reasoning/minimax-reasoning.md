# minimax-reasoning

> 标签: ai, llm, mcp, minimax, minimax-m3, opencode, opencode-plugin, reasoning, thinking

## 简介

OpenCode plugin that fixes MiniMax M3 <think> tag leakage in the TUI by injecting reasoning_split into the chat params. Also works for any OpenAI-compatible provider that uses the same pattern.
