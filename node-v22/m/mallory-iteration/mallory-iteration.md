# mallory-iteration

> 标签: async, channel, generator, iterable, iterator, itertools, python, tee, transducer, typescript, zip

## 简介

Sync + async iterator algebra for TypeScript — transducers, Python-itertools parity, terminal consumers, bounded concurrency, cancellation, and backpressure-aware channels. Zero runtime dependencies.
