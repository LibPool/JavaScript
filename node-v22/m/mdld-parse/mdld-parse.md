> 标签: agent-memory, crdt, knowledge-graph, linked-data, llm, markdown, md-ld, mdld, ontology, prov-o, provenance, quad-store, rdf, rdfs, semantic-annotations, semantic-markdown, semantic-web, shacl, triple-store

## 简介

Write RDF knowledge graphs as plain Markdown. Parse to quads, generate back, merge documents. The human-friendly semantic web format.
