# mm-page-time

> 标签: JavaScript

## 简介

**页面停留时间（Time on Page)**  简称 TP 是分析用户粘性的重要指标之一 停留时长也可以侧面反映出网站的用户体验。平均访问时长越短，说明网站对用户的吸引力越差，可用内容信息越少。
