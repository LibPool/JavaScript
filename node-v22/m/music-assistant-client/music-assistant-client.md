# music-assistant-client

> 标签: airplay, chromecast, client, home assistant, home-assistant, music assistant, music-assistant, sonos, typescript, websocket

## 简介

Typed TypeScript client for the Music Assistant WebSocket API: token auth, live player and queue state, auto-reconnect, convenience commands, and every API command typed.
