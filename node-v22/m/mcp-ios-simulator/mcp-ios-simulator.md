# mcp-ios-simulator

> 标签: ai, automation, devtools, ios, iphone, mcp, model-context-protocol, simulator, xcode

## 简介

Model Context Protocol server that exposes DevTools-like automation for the Xcode iPhone Simulator so AI agents can preview and test iOS experiences.
