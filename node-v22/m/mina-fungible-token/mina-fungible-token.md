# mina-fungible-token

> 标签: JavaScript

## 简介

Standard implementation of fungible tokens in Mina, as per [RFC14: Fungible Token Standard on Mina](https://github.com/o1-labs/rfcs/blob/main/0014-fungible-token-standard.md).
