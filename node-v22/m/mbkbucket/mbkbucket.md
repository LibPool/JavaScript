# mbkbucket

> 标签: aws-sdk, bucket, bucket-manager, cli, cloudflare-r2, command-line, file-download, file-upload, idrivee2, mbkauthe, mbkbucket, mbktech.org, r2-bucket, s3, s3-bucket, storage

## 简介

Flexible S3/R2 bucket management — library, Express router, and CLI for mbktech.org applications. Provides upload, download, listing, multipart utilities, signed URLs, and a command-line interface with built-in configuration validation and health checks
