# maus-mcp

> 标签: claude, claude-code, clipboard, codex, cursor, macos, maus, mcp, model-context-protocol

## 简介

MCP server exposing the Maus clipboard manager (mausformac.com) to Claude Code, Cursor, Codex and other MCP clients. Local-only, tier-aware.
