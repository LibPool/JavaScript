# minimax-harness

> 标签: agent, cli, coding-agent, evaluation, llm, mcp, minimax

## 简介

A configurable coding harness for MiniMax M2.7 / M3 with plan-critique gating, execution guardrails, MCP tool servers, and a benchmark lab.
