# multi_page_webpack_react_app

> 标签: react, vue, 多页面, 开箱即用, 无需配置, 脚手架

## 简介

基于webpack4配置的多页面react项目、开箱即用的脚手架。默认配置为react+less，可根据需求自行修改（vue、jq，sass、stylus等），也可自行修改为单页面应用。
