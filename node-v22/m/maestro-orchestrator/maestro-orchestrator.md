# maestro-orchestrator

> 标签: agents, claude, cli, codex, langgraph, mcp, multi-agent, orchestrator, workflow

## 简介

A harness for precise, auditable agent workflows — compose a graph of roles, drive the CLI agents already on your machine, with typed, gated, replayable handoffs. Built on LangGraph.
