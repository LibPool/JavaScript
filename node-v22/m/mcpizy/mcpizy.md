# mcpizy

> 标签: ai, analytics, anthropic, claude, claude-code, cursor, developer-tools, mcp, mcp-client, mcp-server, model-context-protocol, monitoring, tools

## 简介

MCP management platform CLI — discover, install, and monitor MCP servers plus a local proxy that caches idempotent tool calls (real token savings) AND scans every tool response for prompt-injection / exfiltration / leaked secrets, blocking tool-poisoning
