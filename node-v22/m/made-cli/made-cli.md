# made-cli

> 标签: JavaScript

## 简介

- 1.支持个人或者组织的形式，并且支持项目的版本号拉取 - 2.可以默认获取我的github模板（只有测试模板没有任何内容，建议配置自己的项目模板） - 3.支持JS文件和JSON文件的预编译（模板支持ejs模板）
