# mcp-getweb

> 标签: AI, fetch, getweb, mcp, mcp-getweb

## 简介

Searching: Google (API keys), Felo AI, DuckDuckGo, Linkup; convert fetched pages to Markdown (LLM‑ready) and fetch ready docs from Jina API.
