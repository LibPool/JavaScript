# msdfgen-ts

> 标签: atlas, font, msdf, msdfgen, sdf, signed-distance-field, text, truetype, webgl, webgpu

## 简介

Runtime MSDF font atlases for WebGL/WebGPU: a TypeScript port of msdfgen with a built-in TrueType parser. No WASM.
