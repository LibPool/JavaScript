# maukirim

> 标签: api-client, maukirim, notification, otp, sdk, send-otp, typescript, whatsapp, whatsapp-api

## 简介

Official Node.js and TypeScript SDK for the MauKirim WhatsApp gateway (maukirim.com) — send OTP codes, send templated notifications, and operate rented WhatsApp numbers.

## 官网

- 官网：https://maukirim.com
- 源码仓库：git+https://github.com/MauKirim/sdk-nodejs.git
- npm 页面：https://www.npmjs.com/package/maukirim
