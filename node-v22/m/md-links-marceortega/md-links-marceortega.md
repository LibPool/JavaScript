# md-links-marceortega

> 标签: JavaScript

## 简介

Esta libreria permite analizar archivos con extensión MD.Analiza el contenido y extrae los links que contiene el archivo, además muestra el estado de los links, permitiendo al usuario saber si son unicos, o estan errados.
