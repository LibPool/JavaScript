# matchkeys

> 标签: filepath, filter, key, keys, keyword, keywords, match, module, node, npm, package, package.json, paths, pattern, pkg, require, resolve, resolved

## 简介

Utility for returning a list of arrays that contain matching keywords. Useful for filtering package.json files.
