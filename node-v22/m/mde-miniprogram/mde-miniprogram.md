# mde-miniprogram

> 标签: JavaScript

## 简介

这是一套基于样式库[weui-wxss](https://github.com/Tencent/weui-wxss/)开发的小程序UI组件库，同微信原生视觉体验一致的UI组件库，由微信官方设计团队和小程序团队为微信小程序量身设计，令用户的使用感知更加统一。
