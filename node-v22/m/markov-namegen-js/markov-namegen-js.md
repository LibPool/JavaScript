# markov-namegen-js

> 标签: damerau-levenshtein, game-dev, katz-backoff, markov, markov-chain, name-generator, procedural-content, procedural-generation, word-generator

## 简介

Procedural Markov chain name and word generator library in JavaScript with Katz backoff, Dirichlet priors, and Damerau-Levenshtein similarity sorting.
