# mex-call

> 标签: agent, claude, meeting, memory, mex, transcript

## 简介

Claude Code, now in your Google Meet — a bot that turns the conversation into structured, agent-readable memory in your repo, with the memory and context powers of mex. Works with Claude Code (plugin) and Codex (CLI).
