# mira_eagle_extension

> 标签: JavaScript

## 简介

在服务端复刻 Eagle 本地 HTTP 协议，让 Eagle 浏览器扩展无需改动即可把网页图片、截图、链接保存到 Mira 素材库。

## 官网

- npm 页面：https://www.npmjs.com/package/mira_eagle_extension

- 当前版本：1.0.0

- 1.0.0

- npm registry：https://registry.npmjs.org/mira_eagle_extension
