# mcp-smoke

> 标签: agents, ci, claude-code, mcp, model-context-protocol, readiness, smoke-test, testing

## 简介

Catch the silent first-turn tool loss before your users do. Smoke-tests your MCP server against a REAL client (Claude Code): were your tools actually visible on turn 1?
