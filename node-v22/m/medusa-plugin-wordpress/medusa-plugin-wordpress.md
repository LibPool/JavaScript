# medusa-plugin-wordpress

> 标签: ecommerce, headless, medusa, medusa-plugin, medusa-plugin-cms, medusa-wordpress, storefront, wordpress

## 简介

A Medusa plugin for WordPress integration. It enables you to use WordPress as a headless CMS or as a storefront for your Medusa shop.
