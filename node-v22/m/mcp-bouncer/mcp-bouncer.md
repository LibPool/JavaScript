# mcp-bouncer

> 标签: agent-security, ai-agents, audit-log, firewall, mcp, mcp-security, model-context-protocol, prompt-injection, proxy

## 简介

A bouncer for MCP servers. Wraps any stdio MCP server and enforces per-tool policy - tool allowlists, path/URL argument rules, rate limits, response caps - and logs every call to a local audit file.
