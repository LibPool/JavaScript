# markdown-archive-mcp

> 标签: archive, claude, claude-code, documentation, knowledge-base, markdown, mcp, model-context-protocol, second-brain

## 简介

MCP server for maintaining a markdown knowledge base: classify plans, archive completed docs to .archiveMD/, restore anything archived by mistake, and compact noisy files. Never deletes.
