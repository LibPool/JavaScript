# @baudevs/bau-log-hero

> 标签: baudevs, baudevs-monorepo, browser, colors, logging, node, timestamp

## 简介

A simple, no dependencies logging library for browser and node, with colors, timestamp, and easy to activate/deactivate by file and compatible with tree-shakeable
