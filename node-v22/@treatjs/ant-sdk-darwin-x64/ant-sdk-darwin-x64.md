# @treatjs/ant-sdk-darwin-x64

> 标签: JavaScript

## 简介

Prebuilt Treat Ant native SDK for darwin-x64 (x86_64-apple-darwin). Consumed by treat-ant-bridge's default build via TREAT_ANT_SDK_PATH / node_modules discovery.
