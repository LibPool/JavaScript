# @loomcycle/memory-view

> 标签: agent, ai, component, loomcycle, memory, react, vector

## 简介

Embeddable React memory browser for the loomcycle agentic runtime (RFC BV) — a themeable, standalone k/v Vector Memory console (with a fact viewer + unified semantic search).
