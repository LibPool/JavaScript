# @dimeskigj/pulumi-dokploy

> 标签: category/infrastructure, deployment, dokploy, kind/native, paas, self-hosted

## 简介

Pulumi provider for managing Dokploy projects, environments, applications, Compose stacks, Postgres, MySQL, MariaDB, MongoDB, and Redis databases, domains, SSH keys, registries, tags, project-tag associations, mounts, backup destinations, database backups
