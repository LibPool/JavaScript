# dsh-md-studio

> 标签: deepseek-harness, dsh, dsh-plugin, katex, markdown, mermaid, preview, syntax-highlighting

## 简介

Markdown Studio：在 DSH 原生右侧文件预览与对话消息中渲染 Mermaid 图表、KaTeX 公式、GFM 表格、任务列表、脚注及代码高亮。渲染引擎随包内置，完全离线可用。 / Native DSH right-sidebar Markdown preview with Mermaid diagrams, KaTeX math, GFM tables and syntax highlighting — fully offline.
