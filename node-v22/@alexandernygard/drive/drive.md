# @alexandernygard/drive

> 标签: collaboration, documents, drive, react, sharing

## 简介

Client for Nyggis Drive: open, create and share documents from word2, xl2 and ppt2, plus the shared React pieces (share dialog, avatars, file icons).

## 官网

- 官网：https://drive.nyggis.com
- 源码仓库：git+https://github.com/alexandernygard/drive-sdk.git
- npm 页面：https://www.npmjs.com/package/@alexandernygard/drive
