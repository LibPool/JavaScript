# ckeditor5-elements-menu

> 标签: ckeditor, ckeditor 5, ckeditor5, ckeditor5-feature, ckeditor5-plugin

## 简介

Element menus for CKEditor 5: the menu of an element, built from commands, and the element context menu, breadcrumbs and quick insert that open it.
