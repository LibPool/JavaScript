# dsh-quick-explain

> 标签: aside, deepseek, deepseek-harness, dsh, dsh-plugin, explain, quick-explain, selection, side-chat

## 简介

Select a fragment of a chat and open a temporary side conversation that explains it — without touching the main session. A DeepSeek Harness (dsh) plugin.
