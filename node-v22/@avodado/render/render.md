# @avodado/render

> 标签: api-documentation, architecture, avodado, c4-model, diagrams, diagrams-as-code, docs-as-code, documentation, documentation-as-code, html, markdown, mermaid-alternative, pdf, presentations, render, slides, static-site-generator, svg, system-design, technical-writing, yaml

## 简介

Render Avodado documentation-as-code (Markdown + typed YAML blocks) to standalone HTML, slide decks, and PDF — architecture & system-design diagrams, C4, ERDs, API references, tables, and charts as self-contained SVG. No runtime, no CDN, no client JS.
