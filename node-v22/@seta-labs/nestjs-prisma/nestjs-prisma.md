# @seta-labs/nestjs-prisma

> 标签: JavaScript

## 简介

Prisma for NestJS APIs on Postgres: a PrismaService built on the app's generated client (env check, pool with fail-fast, serialized interactive transactions, lifecycle logs), a database health indicator and the P2002/P2025 error predicates
