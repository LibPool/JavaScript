# @guilhermebkel/scenec

> 标签: agent-skill, ai-agents, compiler, illustration, scene, svg, yaml

## 简介

Scene compiler: turns a short YAML scene into an illustrated SVG, with warnings and a text description so AI agents that cannot see images can draw.
