# @solsonar/yellowstone-grpc-client

> 标签: geyser, grpc, low-latency, mev, real-time, rpc, solana, subscription, triton, yellowstone

## 简介

Production-ready Yellowstone gRPC (Geyser) client for Solana with TLS + x-token auth, ping/stale detection, exponential backoff reconnect, and live subscription updates.
