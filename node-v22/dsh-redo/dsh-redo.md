# dsh-redo

> 标签: chat-ui, cordis, deepseek, deepseek-harness, dsh, dsh-plugin, edit-message, regenerate, rewind

## 简介

Edit or retry an already-sent user message and regenerate in place: rewinds the model context to that message without leaving the session
