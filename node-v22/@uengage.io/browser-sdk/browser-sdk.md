# @uengage.io/browser-sdk

> 标签: appsync, browser, cdn, platform, realtime, uengage

## 简介

Browser bundles for the uEngage platform APIs. One IIFE per service for pages with no build step (served from cdn.platform.uengage.io), plus ESM/CJS entry points for bundled apps. Token minting, refresh-before-expiry and transport degradation are internal
