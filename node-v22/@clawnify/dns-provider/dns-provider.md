# @clawnify/dns-provider

> 标签: cname, custom-domain, dns, doh, domain-connect, nameserver

## 简介

Detect which DNS provider manages a domain (DNS-over-HTTPS NS lookup + nameserver registry), get per-provider guidance for adding records, and drive Domain Connect discovery + sync-flow URLs. Zero dependencies; runs in Cloudflare Workers, browsers, and No
