# @flexiui/svelte-tags-input

> 标签: JavaScript

## 简介

A lightweight and flexible tags input component for Svelte. Easily add, edit, and remove tags with support for custom styling, basic validation, and events. Perfect for managing tags, categories, or keywords in interactive applications.
