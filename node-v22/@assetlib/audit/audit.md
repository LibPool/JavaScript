# @assetlib/audit

> 标签: android, assets, audit, cli, duplicates, expo, images, ios, mobile, react-native

## 简介

Read-only local inventory of PNG, JPEG, and WebP assets in an existing app: measured bytes, exact duplicates, dimension candidates, literal-reference hints, and optional local git change history. No account, network, uploads, or source changes.
