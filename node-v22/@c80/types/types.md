# @c80/types

> 标签: JavaScript

## 简介

Contrato de tipos compartido del ecosistema barman (enums + interfaces de dominio + DTOs de WebSocket). Fuente unica de verdad para zerath-back, vulcan-arm y las apps del monorepo ngx-c80 (kyron, midas, chillbox, kiosk).
