# hugo-balancer

> 标签: benchmark, circuit-breaker, cluster, ewma, health-check, least-connections, load-balancer, p2c, proxy, reverse-proxy, rolling-restart, websocket

## 简介

Layer-7 load balancer for HTTP and WebSocket in plain Node: p2c-EWMA, least-conn and round-robin, health checks, outlier ejection, safe retries, a self-healing local cluster with rolling restarts, and a load tester. Zero dependencies
