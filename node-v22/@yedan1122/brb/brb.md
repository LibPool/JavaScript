# @yedan1122/brb

> 标签: agent-workflow, brb, browser-automation, cdp, chatgpt, handoff, pi-extension

## 简介

BRB connects Pi Agent workflows to a real ChatGPT Web conversation as a safe second reasoning workspace. Hand a task out, take the plan back, execute locally.
