# @vepando/switchyard-core

> 标签: ai, ai-router, cost-aware, cost-optimization, expected-cost, llm, llm-router, model-router, model-routing, pareto, router, token-cost, typescript

## 简介

Pure model-routing core: classify, filter, score, decide. Expected-cost routing with failure pricing, quota intelligence and Pareto banding. No I/O.
