# @wasm-gaming/mgba-wasm

> 标签: JavaScript

## 简介

mGBA (Game Boy Advance / Game Boy / Game Boy Color emulator) compiled to WebAssembly via Emscripten, with a JS SDK conforming to the wasm-gaming engine contract.
