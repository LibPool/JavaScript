# @wasm-gaming/rsdkv5-wasm

> 标签: JavaScript

## 简介

RSDKv5 (Retro Software Development Kit v5) compiled to WebAssembly, with a JS SDK conforming to the wasm-gaming engine contract. Runs Sonic Mania by loading Data.rsdk at runtime.
