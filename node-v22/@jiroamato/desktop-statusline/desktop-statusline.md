# @jiroamato/desktop-statusline

> 标签: claude, claude-code, claude-code-plugin, desktop, status-bar, status-line

## 简介

Installs desktop-statusline, a Claude Code plugin: a status bar above the prompt in the Claude desktop app with model, effort, folder, git branch, context meter, cost and elapsed time
