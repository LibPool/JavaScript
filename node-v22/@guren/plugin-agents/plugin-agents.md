# @guren/plugin-agents

> 标签: ai-agents, bun, cloudflare-agents, durable-objects, framework, fullstack, guren, typescript

## 简介

Durable agents for Guren applications: hosts Cloudflare Agents SDK Durable Objects that call the app's own agent tools through the RFC 0017 invocation pipeline.
