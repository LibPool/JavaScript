# dsh-progress-caption

> 标签: caption, deepseek-harness, dsh, dsh-client-plugin, dsh-plugin, progress, reasoning, thinking, web-ui

## 简介

DSH 客户端插件：在输入框上方显示当前思考到第几步、在干什么、成没成；纯本机规则推断，不调模型、不发网络请求。 A DSH client plugin that captions the thinking phase with step, action and outcome.
