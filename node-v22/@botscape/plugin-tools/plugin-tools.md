# @botscape/plugin-tools

> 标签: JavaScript

## 简介

BotScape MetaID tool plugin: registers the on-chain tool set (buzz post, pin read/write, MetaID/social search, wallet balance/transfer, file upload, MetaApp search, bot roster) into the DSH tools registry so every Bot preset can call them in conversation.
