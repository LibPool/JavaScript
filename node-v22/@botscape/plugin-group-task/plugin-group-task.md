# @botscape/plugin-group-task

> 标签: JavaScript

## 简介

BotScape group-task plugin: one-group-one-task on-chain collaboration (chair/worker members, status machine, [STATUS]/[DELIVERABLE]/[WORKING]/[CHECKPOINT] tag protocol over group chat), with DSH tools for the full task lifecycle.
