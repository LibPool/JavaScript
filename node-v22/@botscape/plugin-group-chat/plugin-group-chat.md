# @botscape/plugin-group-chat

> 标签: JavaScript

## 简介

BotScape group-chat plugin: create/join/leave MetaWeb groups and send AES-encrypted group messages on-chain (/protocols/simplegroupcreate|join|chat), record decrypted inbound group messages from im-listener, plus the browser client half (群聊 settings page)
