# @botscape/plugin-metabot

> 标签: JavaScript

## 简介

BotScape metabot plugin: create/manage Bots (wallet + on-chain Bot Info registration + agent preset generation), recover from mnemonic. Dual-face package: host plugin plus browser client half (Bot management settings page).
