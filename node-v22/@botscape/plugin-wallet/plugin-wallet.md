# @botscape/plugin-wallet

> 标签: JavaScript

## 简介

BotScape wallet plugin: mnemonic generation, BIP44 derivation (mvc/btc/doge), metaid/globalmetaid/chat-key computation, mnemonic stored in DSH credentials.
