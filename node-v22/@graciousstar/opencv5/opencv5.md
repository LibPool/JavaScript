# @graciousstar/opencv5

> 标签: alignment, ecc, image, n-api, opencv, orb, prebuilt, vision

## 简介

A few OpenCV 5 vision ops on raw image buffers - colorConvert, resize, filter, crop, rotate, ORB+ECC imageAlign - as a prebuilt N-API addon: async, bounds-checked, the same bytes on every CPU.
