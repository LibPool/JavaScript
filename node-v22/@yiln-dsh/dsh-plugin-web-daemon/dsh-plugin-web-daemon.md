# @yiln-dsh/dsh-plugin-web-daemon

> 标签: JavaScript

## 简介

DSH plugin that manages `dsh web` as a real systemd unit, exposes live server CPU, memory, network, and filesystem metrics in the Web GUI, and after a restart resumes the attached sessions together with the subagent children they had running.
