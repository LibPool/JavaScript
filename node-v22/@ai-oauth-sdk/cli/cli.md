# @ai-oauth-sdk/cli

> 标签: ai, chatgpt, claude, cli, copilot, gemini, grok, oauth, token

## 简介

Command-line tool to sign in to AI providers (ChatGPT, Claude, Gemini, Grok, Copilot) and print tokens for scripts.
