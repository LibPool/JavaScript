# @cstsortan/artifacts-cli

> 标签: agent, artifacts, claude, cli, html, markdown, mermaid, react, skill, svg

## 简介

Push single-file HTML, React, SVG, Markdown and Mermaid artifacts to an Artifacts host from the terminal or an agent, and install the bundled agent skill
