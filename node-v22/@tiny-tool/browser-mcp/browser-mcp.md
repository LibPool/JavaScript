# @tiny-tool/browser-mcp

> 标签: JavaScript

## 简介

tiny-tool-browser 是一个用于网页内容抓取和搜索引擎内容提取的工具集，支持通过 API、本地 MCP 协议和 Dify 插件三种方式集成。适用于 AI Agent、自动化数据采集等场景。
