# @node-actions/checker

> 标签: actions, ast, checker, node-actions, tslite, typecheck, typescript

## 简介

O typecheck do actions sobre o @node-actions/core — o eixo de DADOS (que valor flui). Baixa a action num corpo de função tslite e deixa o @tslite/checker tipar: scope-flow, inferência e narrowing entre statements de graça. Folha, opt-in, headless, sem thr
