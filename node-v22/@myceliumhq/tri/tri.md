# @myceliumhq/tri

> 标签: agent, cli, etapi, mcp, notes, trilium, triliumnext

## 简介

Agent-facing CLI for TriliumNext Notes, over its ETAPI REST API. Also ships a standalone MCP server for shell-less hosts.
