# @wzwolook/dsh-safe

> 标签: auto-recovery, boot-safe, deepseek, deepseek-harness, dsh, plugin, rollback, self-healing, startup

## 简介

Zero-config boot-safe wrapper for dsh: auto-disables failing plugins, restores broken configs via --patch overlay isolation. No dsh source changes needed.
