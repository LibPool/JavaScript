# @unirate/sveltekit

> 标签: currency, currency-converter, exchange-rates, fintech, forex, fx, hooks, load-function, money, svelte, svelte5, sveltekit, unirate

## 简介

SvelteKit integration for the UniRate currency-exchange API. Server-side getRate/convert helpers for load functions, createCurrencyHandle() geo-detection hook, API route proxy, and <Currency/> + <Rate/> Svelte 5 components. Zero runtime deps.
