# @unirate/solid

> 标签: createResource, currency, currency-converter, exchange-rates, fintech, forex, fx, money, solid, solid-js, solidjs, unirate

## 简介

SolidJS primitives and provider for the UniRate currency-exchange API. createRate, createRates, createConversion, createCurrencies, createVatRates, createHistoricalRate + UniRateProvider. Zero runtime deps.
