# @unirate/mcp

> 标签: ai-tools, anthropic, claude, currency, exchange-rates, forex, historical-rates, mcp, model-context-protocol, unirate

## 简介

Model Context Protocol server for the UniRate API — currency conversion, exchange rates, historical data (back to 1999), and supported-currency lookup for AI assistants. Stdio + Streamable HTTP/SSE transports.
