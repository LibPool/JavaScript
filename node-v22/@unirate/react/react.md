# @unirate/react

> 标签: currency, currency-converter, exchange-rates, fintech, forex, fx, money, react, react-hook, unirate, useExchangeRate

## 简介

React hooks and components for the UniRate currency-exchange API. useExchangeRate, useCurrencies, useConvert, useHistoricalRate + <Currency/> and <Convert/> components. Zero runtime deps.
