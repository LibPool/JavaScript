# @momentogg/format

> 标签: cbor, game-clips, game-memory, gaming, highlights, isobmff, metadata, momento, mp4, open-format

## 简介

Reader for the Momento Game Memory format — a structured gameplay event log embedded in standard MP4 files via an ISO BMFF uuid box. Browser + Node.js, zero ffmpeg, CBOR-encoded payload, SHA-256 media-binding integrity.
