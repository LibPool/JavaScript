# @shasvinth/tokengenius

> 标签: expiry, generator, password, random, secure, token, validation

## 简介

TokenGenius is a versatile and secure Node.js and browser-compatible package for generating random tokens. With customizable token lengths, various token types (numeric, alphabetic, hex, alphanumeric, special), and the ability to define your own character
