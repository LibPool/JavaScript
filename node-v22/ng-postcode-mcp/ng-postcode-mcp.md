# ng-postcode-mcp

> 标签: address-validation, ai-agents, geocoding, mcp, mcp-server, model-context-protocol, ndaps, nigeria, nigerian, nipost, postal-code, postcode

## 简介

MCP server for Nigerian postcodes (postal codes), Nigeria's NIPOST digital postcode (NDAPS): validate, look up, autocomplete and find postcodes by location.
