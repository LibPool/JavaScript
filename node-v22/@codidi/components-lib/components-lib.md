## 简介

- 创建tsconfig.build.json  - npx tsc -p tsconfig.build.json --module ESNext --outDir dist/esm  - npx tsc -p tsconfig.build.json --module commonjs --outDir dist/cjs  - 编译样式  - npx sass ./src/Calendar/index.scss ./dist/esm/Calendar/index.css  - npx sass ./src
