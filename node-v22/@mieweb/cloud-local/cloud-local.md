# @mieweb/cloud-local

> 标签: JavaScript

## 简介

Local/Node adapters implementing the Cloudflare-shaped @mieweb/cloud contracts: D1→SQLite (better-sqlite3), R2→filesystem, KV→in-memory/Redis, Queues→in-process, Durable Objects→in-process registry. Vectorize/Workers AI surface explicit UnsupportedBinding
