# @mieweb/pulsevault

> 标签: express, fastify, fastify-plugin, meteor, pulsevault, resumable, tus, tus-server, upload, video

## 简介

Resumable video uploads via TUS for Fastify (plugin) or any Node backend (framework-agnostic core), with a pluggable storage adapter and a filesystem-first local-storage default.
