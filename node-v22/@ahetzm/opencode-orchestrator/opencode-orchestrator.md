# @ahetzm/opencode-orchestrator

> 标签: agent, ai, opencode, opencode-plugin, orchestrator, subagent

## 简介

opencode plugin (v1 and v2) that adds an Orchestrator primary agent which delegates all work to configurable minion subagents.
