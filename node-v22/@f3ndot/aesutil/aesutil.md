# @f3ndot/aesutil

> 标签: aes-256-gcm, crypto, decryption, encryption, utility

## 简介

An opinionated NodeJS convenience library for AES-256-GCM Encryption/Decryption with optional Additional Data (AAD/AEAD) in a portable way
