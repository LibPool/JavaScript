# @r1ck404/fast-esbuild-wasm

> 标签: bundler, drop-in, esbuild, esbuild-wasm, jsx, transform, typescript, wasm

## 简介

Faster drop-in replacement for esbuild-wasm 0.28.2: esbuild ported to JavaScript (transform, build, context, the CLI and every other API), with byte-identical output and no WebAssembly binary
