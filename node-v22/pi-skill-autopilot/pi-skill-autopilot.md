# pi-skill-autopilot

> 标签: agent-skills, auto-install, autopilot, goal, pi, pi-coding-agent, pi-extension, pi-package, plan, skill-store, skillhub, skills

## 简介

Plan-aware skill provisioning for pi: after a plan or goal is produced, it predicts which skills each step needs, scores SkillHub store matches, asks you to confirm the batch, installs them, and continues the plan.
