# @maraventano/map

> 标签: agent, agent-literacy, agentic-commerce, decoder, mcp, merchant, model-context-protocol, shopping, x402

## 简介

MAP (Maraventano Agent Protocol): a subtractive MCP server for agent commerce — read (find any merchant: decode any product URL into one CleanRead), pay (use the wallet you already have), and publish (be found: serve your own catalog). Teacher, not butler
