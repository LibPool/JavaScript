# @mk-kit/ui

> 标签: accessible, admin, angular, angular22, components, css-variables, dark-mode, dashboard, design-system, signals, themable, ui, ui-library, wcag

## 简介

Themable, accessible Angular 22 component library for admin dashboards and UIs. Signals-based, WCAG 2.1 AA, controlled entirely through CSS variables with light/dark out of the box.
