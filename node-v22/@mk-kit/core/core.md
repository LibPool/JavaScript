> 标签: anchored, ansi, calendar, date-utils, diff, filter, framework-agnostic, markdown, markdown-parser, mk-kit, popover, positioning, predicate, query-builder, syntax-highlighting, zero-dependency

## 简介

The framework-free engines under @mk-kit/ui — anchored-overlay positioning maths, a line/word diff, a markdown parser + HTML renderer, JSON syntax highlighting, an ANSI escape-code parser, calendar date helpers and a filter-query engine (predicate compile
