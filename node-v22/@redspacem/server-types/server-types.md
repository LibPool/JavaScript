> 标签: cyberpunk-2077, gamemode, mp, multiplayer, redspacem, scripting

## 简介

Typed contract for the mp.* scripting host API injected by the RedSpaceM server core (Mp, MpPlayer, MpVector3, MpVehicle, events, commands).
