# @cjgammon/gamekit-server

> 标签: authoritative, game-server, gamekit, multiplayer, websocket, zero-dependency

## 简介

Authoritative multiplayer server for gamekit — headless fixed-rate loop, from-scratch WebSocket transport, snapshot broadcast. Zero runtime dependencies.
