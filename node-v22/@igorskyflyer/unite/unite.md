# @igorskyflyer/unite

> 标签: const, declaration, igor dimitrijević, igorskyflyer, runtime, safe-guard, source, types, union, validation, validator

## 简介

Zero-dependency TypeScript library for deriving a union type, a type guard, and an array validator from a single source array.
