# @remotehost/claims

> 标签: JavaScript

## 简介

Coordination CLI for multi-agent swarms on one repo: tasks, path claims with leases, conflict prediction, merge planning, and a git land gate. Also authors and manages agent skills (Claude Code, Codex) kept in sync with your repo.
