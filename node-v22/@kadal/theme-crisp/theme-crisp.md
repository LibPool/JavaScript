# @kadal/theme-crisp

> 标签: kadal-deck, kadal-theme, presentation, slides, slidev-port, theme

## 简介

Crisp: plain black on white for Kadal Deck, ported from a Slidev theme. Helvetica Neue, bold titles, pictures set in a margin; light and dark.
