# @dudousxd/nestjs-catalog-telescope

> 标签: catalog, diagnostics, lineage, nestjs, observability, telescope, watcher

## 简介

Telescope watcher and "Catalog" dashboard for @dudousxd/nestjs-catalog: loads, connector runs, schema changes and curation edits, grouped by the snapshot that correlates them.
