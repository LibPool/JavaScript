# @dudousxd/nestjs-authz-drizzle

> 标签: authorization, authz, drizzle, drizzle-orm, nestjs, permissions, rbac, roles

## 简介

Drizzle ORM RBAC persistence + query-scope compiler for @dudousxd/nestjs-authz — roles, permissions, a Gate seam, and gate.scope() → Drizzle WHERE (zero connection ownership).
