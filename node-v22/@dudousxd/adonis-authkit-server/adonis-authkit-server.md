# @dudousxd/adonis-authkit-server

> 标签: adonisjs, authentication, authkit, identity-provider, mfa, oauth2, oidc, openid-connect, rate-limiting, totp

## 简介

AdonisJS OIDC/OAuth2 provider (Identity Provider) toolkit: ejectable auth server with sessions, rate-limiting, MFA/TOTP, audit log, federated logout and OpenTelemetry metrics.
