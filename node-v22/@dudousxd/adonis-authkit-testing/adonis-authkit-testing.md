# @dudousxd/adonis-authkit-testing

> 标签: adonisjs, authentication, authkit, jwks, jwt, oidc, testing

## 简介

Test helpers for apps built on AuthKit: mint real signed ID tokens with a local JWKS, fake authenticators and account stores, and build valid identities — so host apps can test auth flows without booting an IdP.
