# @dudousxd/nestjs-agent-rag-media

> 标签: agent, media, nestjs, rag

## 简介

Auto-ingest @dudousxd/nestjs-media uploads into agent RAG — extract, chunk, embed, index, owner-scoped, with delete kept in sync. Couples via the diagnostics channel, no hard media dependency
