# @mongez/vite

> 标签: PUBLIC_URL, auto-open-browser, build-compress, dotenv, dotenv-in-html, env-in-html, htaccess, prerender, production-base-url, single-page-application, spa, tsconfig, tsconfig-path, tsconfig-path-resolver, vite, vite-plugin, vite-tsconfig-path-resolver, zip-build

## 简介

Drop-in Vite plugin for SPA workflows: typed env loading with NODE_ENV-aware resolution, in-HTML env interpolation, tsconfig path aliasing, auto-open dev server, post-build zip, .htaccess generation, and pre-render integration.
