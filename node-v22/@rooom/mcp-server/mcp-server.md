# @rooom/mcp-server

> 标签: JavaScript

## 简介

An [MCP](https://modelcontextprotocol.io) server that exposes the rooom API (spaces & products) as tools for any MCP-compatible AI client — Claude Code, Claude Desktop, Cursor, and others.
