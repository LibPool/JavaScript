# @smileid/njia-testing

> 标签: JavaScript

## 简介

Fakes for testing code built on @smileid/njia, Smile ID's flow navigation engine: a navigator that records a step's calls, a listener that records transitions, a scripted native module for component tests, and sendIdempotently.
