# @kieusonlam/wp-acf

> 标签: acf, advanced-custom-fields, flexible-content, headless, headless-wordpress, nodejs, repeater, typescript, wordpress

## 简介

Read Advanced Custom Fields data from a WordPress database in Node.js / TypeScript — full support for repeater, flexible content, group, clone, gallery, post object, taxonomy, user, date, link, and ACF Pro option pages.
