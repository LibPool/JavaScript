# @frontity/connect

> 标签: connect, frontity, state-manager

## 简介

The state manager of Frontity. Similar to MobX but much more lightweight because it's based on ES6 proxies.

## 官网

- 官网：https://frontity.org
- 源码仓库：git+https://github.com/frontity/frontity.git
- npm 页面：https://www.npmjs.com/package/@frontity/connect
