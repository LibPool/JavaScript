# @kesbyte/capacitor-exif-gallery

> 标签: android, capacitor, capacitor-plugin, exif, exif-gallery, filtering, gallery, geolocation, gps, image-filter, image-picker, images, ios, location, location-based, metadata, native, photo-gallery, photo-picker, photos, plugin, polyline, time-based

## 简介

Capacitor EXIF gallery plugin — filter and select photos by GPS location, route polylines, and time range. Native iOS & Android image picker with EXIF metadata extraction.
