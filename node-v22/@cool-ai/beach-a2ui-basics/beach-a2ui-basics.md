# @cool-ai/beach-a2ui-basics

> 标签: JavaScript

## 简介

Generic semantic primitives for A2UI v0.9 — extends `@a2ui/web_core`'s basic catalogue with Pill, Hero, Heading, Badge, Avatar, RatingStars, Price, Tag, EmptyState, Skeleton, CallToAction.
