# @cool-ai/beach-a2ui-renderer-static

> 标签: JavaScript

## 简介

Synchronous Lit-free static renderer for A2UI v0.9 SurfaceCommand streams. Emits email-client-safe HTML and structured plain text for batched non-browser channels (email, WhatsApp, archive). Zero heavy dependencies; companion to @cool-ai/beach-a2ui-render
