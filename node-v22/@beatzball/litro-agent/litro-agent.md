# @beatzball/litro-agent

> 标签: agents, declarative-shadow-dom, fast-element, lit, litro, llm, nitro, ssr, web-components

## 简介

Filesystem-first agent layer for Litro apps: tools that return server-rendered web components, durable NDJSON session streams, pluggable model providers. Deploys anywhere Nitro deploys.
