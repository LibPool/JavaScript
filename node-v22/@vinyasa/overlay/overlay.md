# @vinyasa/overlay

> 标签: JavaScript

## 简介

Overlay primitives: Dialog (+ `Modal` alias), Alert Dialog, Sheet (the `Drawer` role — see below), Tooltip, Popover, Hover Card, Context Menu, Dropdown Menu, Command Palette.
