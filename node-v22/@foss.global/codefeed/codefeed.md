# @foss.global/codefeed

> 标签: Gitea, activity feed, changelog, code analysis, codefeed, commits, development tools, module, npm, repository, version control

## 简介

The @foss.global/codefeed module generates commit/activity feeds from forge providers including Gitea and GitManager.
