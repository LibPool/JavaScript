# @openkakutou/web-ui-kit

> 标签: JavaScript

## 简介

Shared design system (Web Components + CSS custom-property tokens) for every OpenKakutou viewer/editor/mode web app.

- 官网：https://github.com/openkakutou/web-ui-kit#readme
