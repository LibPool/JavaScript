# @cues/sawdust

> 标签: browser, logger, logging, loglayer, nodejs, observability, structured-logging, typescript

## 简介

Runtime-agnostic logging toolkit built on LogLayer — Node and browser console/consola/pretty transports, request-scoped context, and structured error serialization. Datadog logs/RUM/APM live in @cues/sawdust-datadog.
