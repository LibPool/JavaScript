# @sweetvaluelab/sec

> 标签: 13d, 13f, 13g, 8-k, companyfacts, cusip, edgar, financial-statements, form-4, insider-trading, openfigi, sec, xbrl

## 简介

Read SEC EDGAR from TypeScript: XBRL financial statements, 13F holdings and changes, insider trades (Form 4), 8-K, 13D/13G, CUSIP → ticker. No API key, one dependency. Powers sweetvaluelab.com.
