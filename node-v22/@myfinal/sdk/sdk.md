# @myfinal/sdk

> 标签: JavaScript

## 简介

[Dian](https://github.com/FinalDevHQ/Dian) 框架的 OneBot 适配器，提供 WebSocket 和 HTTP 双向通信支持，以及插件开发者模式 CLI（`dian-dev`）。
