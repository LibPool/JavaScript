> 标签: deepseek, dsh, harness, manager, ratatui, terminal, tui, vim

## 简介

dsh-mt terminal chat bundle: an interactive protocol server over dsh-base for the dsh-mt Ratatui frontend (streaming events, approvals, questions, session list/resume)
