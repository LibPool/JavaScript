# @modracx/slider-js

> 标签: accessibility, autoplay, browser, carousel, gallery, jquery-plugin, loop, pagination, reduced-motion, rtl, slider, slides-per-view, slideshow, swipe, touch, zero-dependency

## 简介

Lightweight content carousel / slider for web pages — loop, autoplay, swipe, arrows, dots, multiple slides per view, RTL and reduced-motion aware. Zero dependencies.
