# @modracx/ruler-js

> 标签: box-model, browser, centimeters, crosshair, design-tool, devtools, distance, dpi, guides, inches, inspector, jquery-plugin, measure, measurement, overlay, ppi, ruler, snap-guides

## 简介

Lightweight on-screen ruler, draggable snap guides and element measurement overlay for web pages, with inch/cm/mm/px units and a crosshair.
