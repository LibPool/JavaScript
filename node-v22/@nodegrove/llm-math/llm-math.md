# @nodegrove/llm-math

> 标签: calculator, gpu, kv-cache, llm, local-llm, quantization, vram

## 简介

How much VRAM an open LLM needs and how fast it can run on a GPU: the memory, KV-cache and speed arithmetic behind nodegrove.io, with model data read from config.json and GPU specs from the makers.
