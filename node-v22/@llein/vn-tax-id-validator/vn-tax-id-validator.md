# @llein/vn-tax-id-validator

> 标签: accounting, checksum, e-invoice, fintech, ma-so-thue, modulo-11, mst, tax-id, typescript, utility, validator, vietnam, zero-dependency

## 简介

Validate and format Vietnam Tax Identification Numbers (Mã số thuế - MST 10 and 13 digits) using official Checksum Modulo-11 algorithm (Circular 105/2020/TT-BTC).
