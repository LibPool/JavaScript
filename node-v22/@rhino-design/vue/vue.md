# @rhino-design/vue

> 标签: ChatInput, design, design-system, typescript, vue, vue3, 自动合并表格, 语音输入

## 简介

全面开箱即用的高质量 Vue 3 组件库，覆盖绝大部分业务场景，并支持可选安装的独立 icons 包。
