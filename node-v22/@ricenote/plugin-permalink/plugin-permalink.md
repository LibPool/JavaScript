# @ricenote/plugin-permalink

> 标签: plugin, ricenote

## 简介

RiceNote 固定链接插件：用路径模板自定义文章、独立页面与分类的访问地址，并对外提供方案与参数的接入扩展点

- 源码仓库：git+https://github.com/ricenote/plugin-permalink.git
- npm 页面：https://www.npmjs.com/package/@ricenote/plugin-permalink
