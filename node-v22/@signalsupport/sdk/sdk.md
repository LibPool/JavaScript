# @signalsupport/sdk

> 标签: bug-report, feedback, help-center, signal, support, triage, widget

## 简介

Support inside your product, backed by Signal: report issues with evidence, follow them, hear back, and confirm the fix. A themeable panel for any framework, a headless core, and server helpers.
