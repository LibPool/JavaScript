# @corpobit/backstage-plugin-kikplate

> 标签: JavaScript

## 简介

This plugin integrates Kikplate into your Backstage developer portal. Kikplate is an open source marketplace for project templates and boilerplates. See https://kikplate.dev and https://github.com/kikplate/kikplate.
