# @manjeetkmr18/react-page-builder

> 标签: blocks, builder, cms, drag-and-drop, elementor, nextjs, page-builder, react, visual-editor

## 简介

Open-source, extensible drag-and-drop page builder for React and Next.js. Register your own blocks, edit visually, render anywhere from a JSON document.
