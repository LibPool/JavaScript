# @aimarket/esim-rails

> 标签: ai-agents, aimarket, esim, mcp, reseller, telecom, travel, usdc, x402

## 简介

SDK for eSIM operators on AIMarket rails: a seller node AI agents buy eSIMs from over x402, a supplier interface for your own provisioning system (or eSIM Access), signed webhooks for your CRM and billing, the esim.*@v1 JSON Schemas and a conformance chec
