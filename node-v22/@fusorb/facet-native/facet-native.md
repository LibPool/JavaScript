# @fusorb/facet-native

> 标签: animation, easing, facet, motion-tokens, native-driver, react-native

## 简介

React Native motion driver for @fusorb/facet-motion - subscribes facet motion values to a consumer-provided Animated module (react-native or reanimated v2) via bindAnimated().
