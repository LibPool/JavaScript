# @fusorb/facet-store

> 标签: SovGrant, auth, identity, react, react-native, session, state, tenant, zustand

## 简介

Framework-agnostic state stores for SovGrant auth: Zustand session + tenant state, token-refresh wiring, and hooks consumable across web and React Native. No React coupling in the store logic itself; consumers bring their own React for the auto-generated
