# @gotong/mcp-client

> 标签: JavaScript

## 简介

MCP (Model Context Protocol) client toolkit for Gotong agents — attach a fleet of MCP servers to an LlmAgent and let it use GitHub / filesystem / Slack / Postgres / etc. tools natively.
