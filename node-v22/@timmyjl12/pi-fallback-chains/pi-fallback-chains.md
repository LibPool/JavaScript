# @timmyjl12/pi-fallback-chains

> 标签: failover, fallback, fallback-chains, llm, model-fallback, pi, pi-extension, pi-package, provider-fallback

## 简介

Glob-keyed model fallback chains for pi. Per-model failover that walks a real ordered chain across providers, instead of one flat per-provider list.
