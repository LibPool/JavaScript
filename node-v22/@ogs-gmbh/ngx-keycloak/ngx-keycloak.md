# @ogs-gmbh/ngx-keycloak

> 标签: access-token, authentication, authorization, iam, identity-management, jwt, keycloak, keycloak-adapter, keycloak-angular, keycloak-auth, keycloak-client, keycloak-integration, keycloak-js, oauth2, oidc, openid-connect, security, sso

## 简介

A package that provides a seamless interface for integrating Keycloak authentication into Angular applications. It simplifies communication between Angular and Keycloak, handling token management, session control, and user authentication.
