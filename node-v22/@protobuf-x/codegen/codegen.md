# @protobuf-x/codegen

> 标签: cli, code-generator, codegen, compiler, javascript, proto, proto2, proto3, protobuf, protocol-buffers, typescript

## 简介

Code generator CLI + programmatic API for protobuf-x. Generates fast, type-safe TypeScript/JavaScript from .proto files.
