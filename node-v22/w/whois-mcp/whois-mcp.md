# whois-mcp

> 标签: cctld, dns, domain, domain-lookup, domain-registration, mcp, model-context-protocol, port-43, registrar, tld, whois, whois-lookup, whois-parser, whois-protocol

## 简介

WHOIS MCP Server - Domain registration lookup using proper WHOIS protocol (port 43). Supports 877+ TLDs with parsing for 169 ccTLDs.
