# wordpress-mcp-connector

> 标签: ai, blog, connector, mcp, modelcontextprotocol, publish, wordpress, wordpress-rest-api

## 简介

WordPress MCP server - manage your site from AI chat: create, read, update, delete posts; manage categories and tags. Works with WorkBuddy, CodeBuddy, Cursor, Claude Desktop and any MCP client.
