# wordpress-axi

> 标签: agent, axi, cli, cms, media, pages, posts, rest-api, toon, wordpress

## 简介

AXI-compliant CLI for WordPress - posts, pages, media, terms, comments, users, search, settings, plugins, and themes over the core REST API.
