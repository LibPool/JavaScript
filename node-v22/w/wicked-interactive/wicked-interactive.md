# wicked-interactive

> 标签: JavaScript

## 简介

The wicked family's document engine: document storage with write-once version lineage and fork, HTML/PDF/PPTX/video export, and demo recording behind one local API. wicked-crew spawns and proxies it; the builder UI lives in wicked-studio.
