# whale-girl-desktop

> 标签: companion, deepseek-harness, desktop-pet, dsh, tauri, whale-girl

## 简介

whale-girl 桌面伴侣：把 DSH Web GUI 内的鲸鱼娘宠物渲染到操作系统桌面（Tauri 渲染壳，零运行时依赖）
