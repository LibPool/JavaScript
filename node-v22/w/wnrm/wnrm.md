# wnrm

> 标签: NPM, registry

## 简介

NPM and YARN registry manager can help you easy and fast switch between different npm registries, now include: cnpm, taobao, nj(nodejitsu), edunpm

## 官网

- 官网：https://github.com/SunWuyuan/wnrm
- 源码仓库：git://github.com/Sunwuyuan/wnrm.git
- npm 页面：https://www.npmjs.com/package/wnrm

## 获取地址

- npm 安装：`npm install wnrm`
