# whatsapp-mcp-local

> 标签: agent, ai, macos, mcp, mcp-server, model-context-protocol, whatsapp, whatsapp-web

## 简介

MCP server: visão e escrita no WhatsApp (macOS app nativo + web cross-platform via Chrome). Lê o histórico local com segurança e envia com gate de confirmação.
