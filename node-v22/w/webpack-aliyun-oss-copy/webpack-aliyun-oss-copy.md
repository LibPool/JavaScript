# webpack-aliyun-oss-copy

> 标签: aliyun, aliyun-oss, assets, oss, plugin, webpack

## 简介

a webpack(version>=4) plugin to upload assets to aliyun oss, can be used with or without webpack. This is a copy of webpack-aliyun-oss, the original one was deleted by the author, so I release this one just for personal use.
