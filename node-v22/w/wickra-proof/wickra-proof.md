# wickra-proof

> 标签: backtest, determinism, proof, reproducibility, rust, trading

## 简介

Proof-of-Backtest: fold a (spec, data) pair into a deterministic report and a canonical hash, and verify a claimed proof by recomputation. Node bindings powered by Rust.
