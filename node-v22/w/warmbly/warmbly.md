# warmbly

> 标签: api, client, deliverability, email, oauth, oauth2, outreach, realtime, sdk, typescript, warmbly, websocket

## 简介

The official Warmbly SDK for JavaScript and TypeScript: REST API client, OAuth2 helper, and realtime gateway. Runs on Node, Bun, Deno, browsers, and the edge.
