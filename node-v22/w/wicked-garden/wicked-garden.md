# wicked-garden

> 标签: agentic, ai, claude-code, code-graph, code-intelligence, coding-agent, evidence-gate, memory, multi-model, refactoring, testing, wicked-bus, wicked-qe

## 简介

Curated toolkit for what AI coding agents can't do alone: evidence-gated work, codegraph relationships, deterministic multi-file refactor, multi-model second opinions, and cross-session memory. Installs as a Claude Code plugin.
