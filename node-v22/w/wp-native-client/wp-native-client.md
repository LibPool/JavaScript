# wp-native-client

> 标签: abilities-api, client, gutenberg, headless, react-native, wordpress

## 简介

Universal WordPress client built on the Abilities API. Discovery + execution. Works in WordPress blocks, React Native, and Node — one client, three transports, one ability surface.
