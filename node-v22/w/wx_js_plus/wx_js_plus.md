# wx_js_plus

> 标签: JavaScript

## 简介

- wxJsSdk 部分接口，promise 化 - 支持 vue 插件 - 支持快速设置微信分享 - this.\$wx.authJump({ app_id, redirect_url, scope, state }) => 生成微信授权链接
