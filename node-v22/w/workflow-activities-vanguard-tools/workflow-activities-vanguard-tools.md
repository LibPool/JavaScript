# workflow-activities-vanguard-tools

> 标签: ArcGIS, GIS, VertiGIS, Workflow

## 简介

The VertiGIS Workflow Vanguard Tools is a free extension project for the VertiGIS Studio Workflow system. It introduces custom activities that enhance the system's ability to handle data.
