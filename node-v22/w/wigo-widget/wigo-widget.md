# wigo-widget

> 标签: ai, assistant, chat, widget

## 简介

WigoChat is a versatile and customizable chat widget that can be easily integrated into your web applications. Whether you're using React, Vue, Angular, Svelte, or plain JavaScript, Wigo Chat provides a seamless way to add chat functionality to your site.
