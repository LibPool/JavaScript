# wb-logkit

> 标签: browser, directory, log, logger, logging, node, rotation, sanitize, typescript, universal, zero-dependency

## 简介

统一日志库：分级(trace/debug/info/warn/error/fatal)、模块级配置、必输/环境/文件矩阵控制、关键词调试、脱敏、requestId 注入、控制台与文件独立级别、全局 log 注册、按天/按模块分目录滚动文件（Node）/ 控制台自动降级（浏览器）
