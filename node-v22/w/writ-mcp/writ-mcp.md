# writ-mcp

> 标签: browser-automation, claude, mcp, model-context-protocol, workflows, writ

## 简介

Official Writ MCP server connector — bridges a stdio MCP client (Claude Code, Claude Desktop, Cursor) to Writ Cloud or a self-hosted Writ coordinator. Turns your saved browser workflows into callable tools.
