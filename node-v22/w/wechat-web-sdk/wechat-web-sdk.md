# wechat-web-sdk

> 标签: JavaScript

## 简介

在微信网页开发过程中，获取微信授权，页面上调用比如：微信分享、图片预览等js-sdk功能时，实现过程很繁琐。第一次实现一遍，第二次开始时还得安步骤再实现一次。这个模块对实现功能进行了封装。
