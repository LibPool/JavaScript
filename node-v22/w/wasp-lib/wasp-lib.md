> 标签: buffer, emscripten, ffi, interop, memory, memory-management, pointer, pointers, typesafe, typescript, wasm, wasm-helper, web-assembly-safe-pointers, webassembly, zero-dependency

## 简介

WASP (Web Assembly Safe Pointers) - a lightweight TypeScript library for type-safe interaction with Emscripten-generated WebAssembly memory.
