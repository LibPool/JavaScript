# webaiapi

> 标签: api-gateway, browser-automation, chatglm, cli, llm, openai, playwright, webaiapi

## 简介

Wrap AI chat web UIs (ChatGLM) into an OpenAI-compatible API — Playwright Firefox automation, no API key needed. 把 AI 聊天网页包装成 OpenAI 兼容 API（命令名：webaiapi）
