# woda-print-mcp

> 标签: JavaScript

## 简介

本地打印 MCP + CLI —— 接收 agent 转交的打印数据（take_waybill 返回契约），经平台打印组件（localhost WS，快手/小红书）出纸；支持 stdio MCP 与 woda-print 命令两种调用形态
