# wickra-shazam

> 标签: finance, fingerprint, pattern-matching, rust, similarity, trading

## 简介

The data-driven history-fingerprint match core: build a Shazam from a spec, index an asset's history, match the current fingerprint against it. Node bindings powered by Rust.
