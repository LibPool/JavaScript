# wish-importdoc

> 标签: JavaScript

## 简介

这个插件需要安装额外的依赖 yarn add  @types/file-saver@^2.0.5或者 npm install @types/file-saver@^2.0.5 安装依赖后在需要的模块中引入import {WishImportdocModule,IFile} from 'wish-util/publish' 随后界面上便可以使用 <wish-importdoc [files]='' [isCompress]="false" (upload)="upload($event)" （delete）
