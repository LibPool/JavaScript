# weird-erc20

> 标签: defi, ethereum, smart contracts, solidity

## 简介

This repository contains minimal example implementations in Solidity of ERC20 tokens with behaviour that may be surprising or unexpected. All the tokens in this repo are based on real tokens, many of which have been used to exploit smart contract systems
