# whatsapp-bot.js

> 标签: JavaScript

## 简介

A high-level, `discord.py`-inspired framework for building WhatsApp bots easily and quickly. Built on top of `whatsapp-web.js`.

- npm 页面：https://www.npmjs.com/package/whatsapp-bot.js
