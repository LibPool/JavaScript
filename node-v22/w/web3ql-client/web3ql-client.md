# web3ql-client

> 标签: celo, cli, e2e-encryption, encrypted-storage, nacl, sql, web3

## 简介

Web3QL client SDK — end-to-end encrypted SQL-like storage on Celo. NaCl encryption, UUPS proxy contracts, full TypeScript. Includes CLI.
