# wenmar-open-data

> 标签: automotive, nhtsa, sqlite, vehicle, vin, vpic

## 简介

The Wenmar Open data file: NHTSA vPIC VIN patterns and a year, make, model, trim and engine catalog, as one SQLite file. Read by wenmar-open/offline.
