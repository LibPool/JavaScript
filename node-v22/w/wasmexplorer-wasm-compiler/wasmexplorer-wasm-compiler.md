# wasmexplorer-wasm-compiler

> 标签: JavaScript

## 简介

Compile `.c/++` files to `.wasm` format using [WasmExplorer](https://mbebenita.github.io/WasmExplorer/) service by [@mbebenita](https://github.com/mbebenita).
