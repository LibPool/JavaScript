# webpack-plugin-markdown-jsdoc

> 标签: jsdoc, markdown, webpack, webpack-plugin

## 简介

> 基于 JSDoc 注释自动生成 Markdown 格式 API 文档的 Webpack 插件，支持函数/对象的多维度文档生成，完美适配现代前端工程化流程
