# willis-cli

> 标签: chalk, cli, commander, download-git-repo, inquirer, ora, simple-git-hooks, tsup, typescript, willis, willis-cli

## 简介

常用功能脚手架工具，支持克隆模板项目仓库、git 版本发布、版本预发布、查看分支信息、docker 镜像构建与重启等
