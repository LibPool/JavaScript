# wickchart-draw

> 标签: canvas, chart, charting, drawing, fibonacci, trading, trendline, web-component, wickchart

## 简介

Drawing tools for wickchart — trendlines, rays, levels, rectangles, fibonacci retracements and text as an opt-in plugin layer. Zero dependencies.
