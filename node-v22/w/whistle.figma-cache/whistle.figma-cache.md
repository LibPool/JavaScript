# whistle.figma-cache

> 标签: cache, cdn, figma, proxy, whistle, whistle-plugin

## 简介

Figma 客户端静态资源磁盘缓存：只缓存 content-hash 命名的不可变资源，命中即由本地磁盘回放，绝不触碰画布数据 / API / WebSocket
