# wiki-plugin-mechblocks

> 标签: blocks, federated wiki, mech, plugin, rcn, wiki

## 简介

Federated Wiki plugin: edit Ward Cunningham's Mech scripts as blocks, watch the shared notebook fill as a script runs, draw its graphs in the RCN Graph Tool, and answer PLUGIN rcn with Layer 1 and SODOTO badge blocks
