# wgrn-cli

> 标签: JavaScript

## 简介

1. 全局安装 npm install wgrn-cli -g 2. cmd切换到wegame_rn的路径下 3. 初始化一个项目：         命令： wgrn-init businessName(businessName建议输入纯业务即可)                     例如： wgrn-init lol        脚手架处理输入的businessName        a: businessName首字母大写 作为 src/layouts 中业务目录名
