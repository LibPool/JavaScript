# witnessd-mcp

> 标签: ai-agents, attestation, evidence, mcp, mcp-server, modelcontextprotocol, notary, web-archive, witness, x402

## 简介

MCP server for witnessd — have a neutral third party witness, timestamp and archive any URL or API response, with Merkle anchoring on Base. Pays per-call via x402 (your wallet) or an API key.
