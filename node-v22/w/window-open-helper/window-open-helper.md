# window-open-helper

> 标签: JavaScript

## 简介

`windowOpenHelper` 是一个用于解决异步操作后 `window.open` 被浏览器拦截问题的通用工具。它允许你在执行异步请求（如 API 调用）之前先同步打开一个带有加载状态的窗口，待异步操作完成后再重定向该窗口。
