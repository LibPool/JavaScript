# waypost

> 标签: adr, agent-roles, ai-agents, architecture-decision-records, claude-code, cli, codex, markdown, opencode, project-management

## 简介

One project vault — decisions, specs, epics, stories, a board — as markdown in git, and the same agent roles in every harness. Harness-agnostic fork of ProjectStore.
