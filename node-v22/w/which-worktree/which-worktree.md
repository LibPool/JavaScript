# which-worktree

> 标签: dev-server, git-worktree, nextjs, react, svelte, svelte5, vite, vite-plugin, worktree

## 简介

Dev-server helpers for worktree-based development: Vite plugin that fixes fs.allow for symlinked node_modules, plus a worktree/branch badge for Svelte, React, Next.js and other frameworks.
