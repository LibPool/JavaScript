# ws-changed

> 标签: affected, changed, ci, dependency-graph, incremental, lerna, monorepo, pgpm, pnpm, workspace

## 简介

Which workspace packages does a set of changed files affect? Pluggable workspace providers (pnpm, pgpm, glob), a dependency graph, and affected = changed ∪ dependents — for change-aware CI
