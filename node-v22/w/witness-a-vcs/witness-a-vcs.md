# witness-a-vcs

> 标签: JavaScript

## 简介

this is an attemp to make a simple version control system called Witness. Its based on popular vsc git.
This project doesn't use git porceilien and plumbing commands but rather approaches the problem at hand from scatch in NodeJs.
