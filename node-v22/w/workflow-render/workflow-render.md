# workflow-render

> 标签: cli, custom-element, export, n8n, n8n-workflow, png, svg, viewer, web-component, workflow-diagram

## 简介

Show n8n workflows on a portfolio, blog or docs page as interactive canvases: pan, zoom and open any node to inspect it, on a desktop or a phone. Needs only the workflow JSON. Also exports SVG and PNG.
