# web-search-panel

> 标签: cordis, deepseek-harness, dsh, plugin, search, search-engine, web-search

## 简介

DSH (DeepSeek Harness) 网页搜索增强插件：39 引擎/渠道 · 8 大类 · auto 智能路由（查询特性分析→自动选引擎/多引擎并行 RRF 融合）+ web_fetch_url 抓取 + 设置页配置卡片。一条命令安装：dsh plugin --profile web add web-search-panel
