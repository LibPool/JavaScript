# weixinpay-sdk

> 标签: Native, weixinpay, weixinpay-sdk, weixinpaysdk, 微信, 微信支付, 支付

## 简介

基于微信官方的原生 API 封装而成的 SDK，将官方要求的 xml 格式均通过 sdk 转换成 JSON 格式方便开发，当前已支持 Native
