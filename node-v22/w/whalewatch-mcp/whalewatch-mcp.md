# whalewatch-mcp

> 标签: claude, mcp, modelcontextprotocol, polymarket, prediction-markets, smart-money, whale-tracking

## 简介

MCP server for WhaleWatch — real-time Polymarket whale trades, smart-money consensus, data-continuity clock and the public track record, queryable by any Model Context Protocol client.
