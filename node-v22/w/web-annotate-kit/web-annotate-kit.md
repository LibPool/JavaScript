# web-annotate-kit

> 标签: annotation, comments, express, feedback, pin, proofing, react, review, screenshot, sqlite, turso, visual-review, website-review

## 简介

Pin-anchored visual review and comments for any live website. React client + Express server + pluggable storage (SQLite, Turso).
