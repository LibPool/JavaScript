# wkhtmltopdf-selfcontained

> 标签: JavaScript

## 简介

A wrapper for the wkhtmltopdf HTML to PDF converter using WebKit, with Linux binary included

## 官网

- 官网：https://github.com/meteor/node-wkhtmltopdf
- 源码仓库：https://github.com/meteor/node-wkhtmltopdf.git
- npm 页面：https://www.npmjs.com/package/wkhtmltopdf-selfcontained
