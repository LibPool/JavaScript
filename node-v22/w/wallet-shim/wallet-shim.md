# wallet-shim

> 标签: agent-skill, browser-automation, dapp, e2e, eip-1193, eip-6963, ethereum, metamask, mock, wallet

## 简介

Fake EIP-1193 (MetaMask-compatible) provider for dApp browser automation. Injects a connected wallet, dry-runs transactions.
