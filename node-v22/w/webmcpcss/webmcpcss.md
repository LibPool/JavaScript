# webmcpcss

> 标签: ai-agents, bootstrap, browser-automation, components, css, mcp, self-healing, shadcn, tailwind, webmcp

## 简介

Extiende el estándar WebMCP para hacer cualquier sitio web nativo para agentes de IA, con auto-reparación de selectores CSS.
