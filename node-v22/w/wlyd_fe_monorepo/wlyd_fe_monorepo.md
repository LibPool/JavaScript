# wlyd_fe_monorepo

> 标签: JavaScript

## 简介

> 为了便于管理前端工具类，采用了pnpm创建了monorepo的架构去进行管理npm包，并集成了以下技术辅助管理： > > + [tsup](https://github.com/egoist/tsup) : 一个简单高效的js、ts打包工具 > + [changesets](https://github.com/changesets/changesets) : 适用于monorepo架构的版本管理工具
