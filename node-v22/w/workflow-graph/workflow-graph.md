# workflow-graph

> 标签: async, directed-graph, error-handling, graph, mermaid, nodejs, retry, typescript, workflow, workflow-graph

## 简介

A lightweight TypeScript library for defining, validating, and executing workflow graphs with support for error handling, retries, and Mermaid diagram generation.
