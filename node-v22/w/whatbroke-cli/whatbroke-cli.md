# whatbroke-cli

> 标签: agent-testing, agents, ai-agents, anthropic, cli, diff, evals, langfuse, langsmith, llm, llm-evaluation, observability, ollama, openai, opentelemetry, regression-testing, tool-calls, tracing

## 简介

Diff your AI agent's behavior between two runs. Swap a model, change a prompt, run whatbroke, see exactly what changed.
