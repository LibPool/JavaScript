# web3-api

> 标签: JavaScript

## 简介

This package was created in the course of the diploma thesis at the HTBLA Perg. It is designed to work with a Smart Contract not publicly avialable. [Web3.js](https://github.com/ethereum/web3.js) is used for the communication to the Smart Contract.
