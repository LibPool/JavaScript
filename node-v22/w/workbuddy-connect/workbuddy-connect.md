# workbuddy-connect

> 标签: bridge, cli, deepseek-harness, dsh, openai, openai-compatible, workbuddy, zcode

## 简介

Local WorkBuddy bridge: turns your own WorkBuddy desktop account's models (free ones included) into an OpenAI-compatible endpoint any client can use
