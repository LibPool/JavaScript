# wp-migrate-core

> 标签: astro, cli, elementor, gutenberg, typescript, wordpress, wordpress-migration, wxr

## 简介

Turn a WordPress WXR export into an Astro handoff, with media, URL and link inventories, and a repair queue for the parts that still need a human.
