# webopenssl

> 标签: base64, crypto, hex, openssl, random, wasm, webcrypto

## 简介

Web-based OpenSSL-like random key generator (WASM or min.js). Provides rand -base64 and -hex outputs using WebCrypto or optional OpenSSL-wasm.
