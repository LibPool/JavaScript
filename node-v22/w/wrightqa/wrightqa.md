# wrightqa

> 标签: JavaScript

## 简介

CLI for scaffolding Playwright test infrastructure from a shared registry — shadcn-style copy-paste ownership for CI configs, fixtures, and helpers.

## 官网

- npm 页面：https://www.npmjs.com/package/wrightqa

- Node 要求：>=18
