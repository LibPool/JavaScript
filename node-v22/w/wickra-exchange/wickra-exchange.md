# wickra-exchange

> 标签: connectivity, crypto, exchange, rust, streaming, trading

## 简介

Streaming-native, unified connectivity for the ten largest crypto exchanges (market data + signed order execution), with paper and replay simulators. Node bindings powered by Rust.
