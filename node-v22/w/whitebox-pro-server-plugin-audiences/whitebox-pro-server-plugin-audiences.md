# whitebox-pro-server-plugin-audiences

> 标签: JavaScript

## 简介

WhiteBox server — AI audience plugin. Builds ad-network audiences by reasoning over per-passport awareness against declarative rules, and reports custom events (Mode A) to Meta, TikTok and Google (GA4).
