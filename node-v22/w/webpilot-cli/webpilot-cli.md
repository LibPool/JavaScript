# webpilot-cli

> 标签: accessibility-tree, cli-browser, headless-browser, llm-agent, mcp-server, playwright, terminal, terminal-browser, text-browser, web-browsing

## 简介

A semantic terminal browser for LLM agents and CLI-native developers. Browse any website from your terminal — no GUI, no mouse, just commands.
