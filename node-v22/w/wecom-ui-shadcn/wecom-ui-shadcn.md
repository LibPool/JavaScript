# wecom-ui-shadcn

> 标签: components, design-system, radix, react, shadcn, tailwindcss, ui, wecom

## 简介

WeCom UI component library — shadcn-style React components built on Radix Primitives + Tailwind, driven by Figma-sourced design tokens (Light/Dark). Covers desktop today, mobile soon.
