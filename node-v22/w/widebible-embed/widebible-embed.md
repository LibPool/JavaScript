# widebible-embed

> 标签: api, christianity, embed, scripture, shadow-dom, verse, widebible, widebible.com, widget, zero-dependencies

## 简介

Embed WideBible scripture widgets on any website. Lightweight (~5KB gzipped), zero dependencies, Shadow DOM isolation, 3 themes (light/dark/sepia).

## 官网

- 官网：https://widget.widebible.com
- 源码仓库：git+https://github.com/dobestan/widebible-embed.git
