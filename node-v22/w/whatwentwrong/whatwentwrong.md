# whatwentwrong

> 标签: alerting, aws, cloudwatch, ion, lambda, monitoring, pulumi, sns, sst

## 简介

Drop-in error alerting for SST v3 (ion) projects: SNS + CloudWatch alarms wired up with one .watch() call.
