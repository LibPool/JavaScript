# webtty-terminal

> 标签: bash, browser-terminal, node-pty, pty, remote, sandbox, shell, socket.io, ssh, terminal, web-terminal, webtty, xterm, xterm.js, z-ai

## 简介

Web-based terminal emulator with SSH support, connection manager, multi-session tabs. Powered by xterm.js, node-pty, ssh2, and Socket.IO.
