# ws-cognito-storage

> 标签: JavaScript

## 简介

Utility library which asynchronously exposes the localStorage primitive. While the logic is simple enough and it can be implemented inline the module is provided for convenience, especially useful if it needs to be replaced with bundlers such as browserif
