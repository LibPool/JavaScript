# webtoe

> 标签: creative-coding, dataflow, toe, toeexpand, touchdesigner, webgl

## 简介

Open TouchDesigner .toe files in the browser: `npx webtoe` serves the WebToe editor and runs your own toeexpand so a .toe is a plain drop target. Ships no Derivative code; loopback by default; zero dependencies.
