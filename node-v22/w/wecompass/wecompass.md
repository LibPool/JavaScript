# wecompass

> 标签: authentication, oauth2, qyapi, sso, wechat, wechat-work, wecom, 企业微信

## 简介

TypeScript SDK for WeCom (WeChat Work) OAuth2: build authorize URLs, exchange code for identity, access token cache with auto-refresh.
