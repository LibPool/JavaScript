# web-escpos-printer

> 标签: barcode, bluetooth, browser, escpos, pdf417, point-of-sale, pos, qrcode, qz-tray, receipt-printer, star-prnt, thermal-printer, typescript, web-bluetooth, web-serial, webusb

## 简介

Print to ESC/POS/StarPRNT thermal receipt printers straight from the browser — Web Bluetooth, Web Serial, WebUSB, or QZ Tray — no Node at runtime. Includes a preview renderer to test receipts without a physical printer.
