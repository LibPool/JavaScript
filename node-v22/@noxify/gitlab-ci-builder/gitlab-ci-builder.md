# @noxify/gitlab-ci-builder

> 标签: automation, builder, ci-cd, code-generation, configuration, configuration-management, continuous-deployment, continuous-integration, devops, extends-resolution, fluent-api, gitlab, gitlab-ci, gitops, infrastructure-as-code, mermaid, pipeline, typescript, visualization, yaml

## 简介

Build GitLab CI/CD pipelines programmatically with TypeScript. Fluent API for creating jobs, templates, and workflows. Import/export YAML, visualize with Mermaid diagrams, and resolve extends chains automatically.
