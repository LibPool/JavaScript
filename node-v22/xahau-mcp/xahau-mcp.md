# xahau-mcp

> 标签: blockchain, hooks, mcp, model-context-protocol, smart-contracts, static-analysis, wasm, xahau, xrpl

## 简介

Model Context Protocol (stdio) server for the Xahau network: offline Hook WASM inspection, a Hooks-specific static-analysis rule engine, and read-only ledger, codec, governance and unsigned-transaction tooling. Never signs or submits.
