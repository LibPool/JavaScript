# @prompt-anonymizer/element

> 标签: anonymization, custom-element, llm, pii, privacy, web-component

## 简介

A buddy check for PII before it reaches an LLM - consistent, reversible labels. Framework-agnostic <prompt-anonymizer> web component built on @prompt-anonymizer/core.
