# @ngzhengwei/dropdown-function

> 标签: JavaScript

## 简介

Adds dropdown functionality to your web app. Add class 'dropdown-button' to the buttons and 'dropdown' to the dropdown area. Tie them together using attribute 'data-dropdown-id' which is to be added to the img
