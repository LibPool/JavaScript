# @lewkca/understory

> 标签: accessibility, component-library, design-system, react, storybook, tailwindcss, typescript, ui

## 简介

Understory — a small, typed React component library built on the araxiemiller.com design language, with polymorphic primitives, composition APIs, and accessibility baked into the tokens.
