# @immediately-run/dev-fs

> 标签: dev, filesystem, fs, immediately.run, vite-plugin, zenfs

## 简介

Vite plugin that bridges immediately.run's async `fs` module (and Firestore-backed spaces) to your local disk during `vite dev`.
