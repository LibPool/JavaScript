# @baget/core

> 标签: api, bun, cloudflare-workers, decorators, dependency-injection, di, elysia, framework, rest, typebox, typescript, validation

## 简介

A decorator-driven framework on top of Elysia. Decorators, dependency injection, schema validation. Runs on Bun and Cloudflare Workers.
