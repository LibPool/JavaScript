# dsh-feishu-plugin

> 标签: ai-agent, approval, chatbot, coding-agent, cordis, deepseek, deepseek-harness, dsh, dsh-plugin, feishu, im-bot, lark, larksuite, 飞书, 飞书机器人

## 简介

Feishu/Lark bridge for DeepSeek Harness (dsh): one Feishu topic = one dsh session, in-card approvals and questions, long connection with no public endpoint. Minimal permissions: p2p read + send-as-bot; self-contained bundle, zero runtime deps.
