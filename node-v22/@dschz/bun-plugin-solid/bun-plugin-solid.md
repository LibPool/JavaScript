# @dschz/bun-plugin-solid

> 标签: babel, bun, jsx, plugin, solid, solidjs, ssr, tsx

## 简介

A Bun plugin for transforming SolidJS TSX/JSX files at runtime or build time using Babel. Supports SSR and DOM output.
