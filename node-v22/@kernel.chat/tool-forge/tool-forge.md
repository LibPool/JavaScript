# @kernel.chat/tool-forge

> 标签: ai-agent, dynamic-tools, forge, kbot, llm, runtime, tool-creation

## 简介

Runtime tool creation for AI agents. Define new tools from natural language descriptions at runtime — no restart needed. The agent builds its own tools.
