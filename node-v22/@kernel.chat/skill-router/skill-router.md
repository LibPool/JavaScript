# @kernel.chat/skill-router

> 标签: ai-agent, bayesian, kbot, llm, multi-agent, routing, skill-rating, trueskill

## 简介

Bayesian skill-rating router for AI agents. Routes tasks to the best specialist using TrueSkill-style ratings that improve with every interaction. Zero LLM calls.
