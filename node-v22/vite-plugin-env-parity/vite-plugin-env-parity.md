# vite-plugin-env-parity

> 标签: .env, .env.example, dotenv, env, environment-variables, validation, vite, vite-plugin

## 简介

Vite plugin that fails your build or dev server start when a variable from .env.example is missing or empty. Zero config. Built on @acus9345/env-parity.
