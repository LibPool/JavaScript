# @wovenui/core

> 标签: css, css-variables, dark-mode, design-system, design-tokens, framework, high-contrast, mixins, nuvoui, oklch, responsive, rtl, rtl-design, sass, sass-library, sass-mixins, scss, scss-framework, scss-library, tailwind-alternative, theming, utility-classes, utility-first, utility-first-css, utility-first-styling, wovenui

## 简介

Human-readable, utility-first SCSS framework and design-system foundation: design tokens, light, dark, inverse and high-contrast themes, readable utility classes and apply() mixins. No JavaScript.
