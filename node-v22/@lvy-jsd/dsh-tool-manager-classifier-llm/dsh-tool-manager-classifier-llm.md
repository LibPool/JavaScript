# @lvy-jsd/dsh-tool-manager-classifier-llm

> 标签: classifier, deepseek-harness, dsh, dsh-tool-manager, llm

## 简介

Small-model classifier for dsh-tool-manager: places tool groups into categories once, caches the answer, and never classifies on the hot path.
