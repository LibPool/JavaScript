# @lvy-jsd/dsh-tool-manager-panel

> 标签: deepseek-harness, dsh, dsh-tool-manager, panel, web

## 简介

Web panel for dsh-tool-manager: browse the tool directory, see what each live session has loaded and what it costs, and load or unload from the UI.
