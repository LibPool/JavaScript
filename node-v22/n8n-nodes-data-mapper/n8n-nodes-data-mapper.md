# n8n-nodes-data-mapper

> 标签: csv, drag-and-drop, etl, json, mapper, mapping, n8n, n8n-community-node-package, transform, visual-mapper, xml

## 简介

n8n community node: drag and drop incoming data onto a target profile and output XML, JSON or CSV, with auto-map, array handling and type conversion.
