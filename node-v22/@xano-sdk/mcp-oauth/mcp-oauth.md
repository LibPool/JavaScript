# @xano-sdk/mcp-oauth

> 标签: authentication, backend, codegen, consent, mcp, oauth, xano, xanoscript, xanosdk

## 简介

Hosted OAuth sign-in for Xano SDK MCP servers: a branded sign-in and consent page, the endpoints behind it, and the oauth block for mcpServer().
