# @netforge/engine-sim

> 标签: authoritative-server, client-side-prediction, ecs, entity-component-system, game-engine, game-server, gamedev, multiplayer, net-forge, netcode, physics, rapier, typescript

## 简介

Deterministic game simulation shared by browser client and server for Net Forge: ECS, Rapier physics, a fixed tick, input commands and delta snapshots.
