# @netforge/template-tower

> 标签: ai-agents, browser-game, game-engine, game-template, gamedev, html5-game, mcp, multiplayer, net-forge, threejs, tower-defense, typescript

## 简介

Co-op tower defense game template for Net Forge: up to 4 players, waves, building and upgrades, shared lives (COGSPIRE).
