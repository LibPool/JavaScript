# @netforge/kit-play

> 标签: ai-agents, browser-game, game-engine, game-server, game-template, gamedev, mcp, multiplayer, net-forge, threejs, typescript, vibe-coding, websocket

## 简介

Make, test and run Net Forge games on your own computer with play money: start a game from a template, run playtest bots, and play it in the browser with a local room host, with no wallet, chain or servers.
