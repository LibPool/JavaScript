# @solaryn/moon-cache

> 标签: bazel, cloudflare, moon, moonrepo, r2, remote-cache, workers

## 简介

Bazel HTTP remote cache protocol handler for Cloudflare Workers + R2, designed for use as moon's remote build cache.
