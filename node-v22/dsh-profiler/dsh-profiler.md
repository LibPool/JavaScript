# dsh-profiler

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, observability, performance, profiler

## 简介

DeepSeek Harness 运行时剖析器：启动耗时归因、工具延迟采样（P95）、会话 token 归因、CoreProtect 式文件变更回档。Runtime profiler + rewind for DeepSeek Harness.
