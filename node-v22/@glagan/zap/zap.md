# @glagan/zap

> 标签: notification, svelte, toast

## 简介

*zap* is a library to display simple yet customizable notifications in Svelte.   You can stylize text with a simple syntax, add buttons to make the notifications interactable and add callbacks for some events during the life of a notification.
