# @sebas-dv/shadcn-theme-editor-server

> 标签: dev-server, hono, postcss, shadcn, shadcn-ui, theme-editor, vite-middleware

## 简介

Companion dev server: scan/apply HTTP API that reads and rewrites the shadcn theme CSS. Usable standalone (CLI) or as Vite middleware.
