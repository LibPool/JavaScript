# @worm-vue3-print/common

> 标签: custom-elements, designer, framework-agnostic, print, template, web-components

## 简介

【预览版 · 实验性，不建议用于生产】打印模板设计器的通用宿主适配包：任意框架或无框架宿主均可直接接入（实现为零框架原生 Custom Elements + Shadow DOM），零 Vue/React 依赖，直接消费 @worm-vue3-print/core；Vue 3 项目请使用 @worm-vue3-print/canvas
