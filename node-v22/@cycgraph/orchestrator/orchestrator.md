# @cycgraph/orchestrator

> 标签: agent-memory, agents, compound-learning, durable-execution, event-sourcing, graph-runner, human-in-the-loop, llm, mcp, multi-agent, orchestrator, reflection, self-improving, workflow

## 简介

Self-improving agent workflows: every run distills lessons into memory, and future runs retrieve them automatically. Cyclic graph engine with durable execution, per-node budgets, taint tracking, and human-in-the-loop gates.
