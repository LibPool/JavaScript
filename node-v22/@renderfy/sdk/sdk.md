> 标签: chart-to-image, edge-runtime, headless-chrome, html-to-image, html-to-pdf, image-generation, invoice-pdf, markdown-to-pdf, og-image, open-graph, pdf, png, render-api, renderfy, satori, screenshot-api, tailwind-to-image

## 简介

The official Node.js / TypeScript SDK for Renderfy — convert HTML, Tailwind, Markdown, charts, diagrams, and math to PNG, JPEG, or PDF via a single API call.
