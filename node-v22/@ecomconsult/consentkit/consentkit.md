# @ecomconsult/consentkit

> 标签: consent, consent-mode, cookie, cookie-banner, gdpr, privacy

## 简介

GDPR cookie consent core with blocking engine, Shadow DOM UI and Google Consent Mode v2. Zero dependencies, no build step.
