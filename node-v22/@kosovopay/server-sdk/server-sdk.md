# @kosovopay/server-sdk

> 标签: bun, cloudflare-workers, kosovopay, payment-orchestrator, payments, stripe-like, typescript, webhooks

## 简介

Type-safe, runtime-agnostic server SDK for the KosovoPay payment orchestrator. Runs on Node, Bun, Deno, and Cloudflare Workers — zero dependencies.
