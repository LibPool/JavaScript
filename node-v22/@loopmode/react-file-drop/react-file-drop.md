> 标签: document, drag, drag and drop, drag n drop, drop, dropzone, facebook, file, gmail, react, react dropzone, react file drag drop, react file facebook, react file gmail, react file upload, react-file-drop, upload, window

## 简介

React component for Gmail or Facbook -like drag and drop file uploader. Drag files anywhere onto the window to highlight a 'drop area' of the page
