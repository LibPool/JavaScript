# @3sln/emon

> 标签: document-conversion, html, ocr, pdf, scraping, semantic-html, tables, wasm, webassembly

## 简介

emon's JavaScript SDK: PDFs and images to semantic HTML in the browser, over the WASM binding (DEVLOG P9.3). The library has no dependencies; the devDependencies are the browser test harness and the tesseract.js engine the OCR adapter drives.
