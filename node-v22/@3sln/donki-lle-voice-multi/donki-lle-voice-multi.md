# @3sln/donki-lle-voice-multi

> 标签: JavaScript

## 简介

Multilingual voice (Supertonic 3): Japanese, Korean and 29 more for @3sln/donki-lle's text to speech (part 1 of 3). Model files as ES modules, so a page can load them with import() alone.
