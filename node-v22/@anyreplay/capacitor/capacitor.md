# @anyreplay/capacitor

> 标签: anyreplay, capacitor, capacitor-plugin, ionic, session-recording, session-replay

## 简介

Session replay for Capacitor and Ionic apps: records the app's web view with @anyreplay/browser, plus the app id, version, lifecycle flushing, durable storage and the app's own styles, fonts and images.
