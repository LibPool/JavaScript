# @basenative/fonts

> 标签: basenative, css, fonts, self-hosted, webfont, woff2

## 简介

Self-hosted web fonts for BaseNative — the BaseNative Sans, Serif and Mono families plus Inter, JetBrains Mono, Source Serif 4 and DM Serif Display as woff2, with a ready-made @font-face stylesheet
