# @basenative/combobox

> 标签: a11y, aria, autocomplete, basenative, combobox, signals, typeahead, wcag

## 简介

Accessible combobox primitive — typeahead input that filters an existing list and lets the user create a new entry. WAI-ARIA combobox listbox pattern.
