# @basenative/station

> 标签: basenative, cloudflared, local-inference, openai-compatible, queue, station, vllm, workers-ai

## 简介

Queue-driven local-inference primitive — drives a cloudflared-tunneled vLLM tower (or any OpenAI-compatible endpoint) with an SQLite-backed job queue, iteration loop runtime, fallback to Workers AI, and reusable job templates.
