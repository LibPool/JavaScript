# react-native-alpha-video-gpu

> 标签: alpha, alpha-video, android, animation, astc, fabric, gpu, ios, ktx2, metal, opengl-es, react-native, react-native-component, react-native-web, texture-compression, transparency, transparent-animation, transparent-video, video-player, web, webgl

## 简介

Transparent (alpha) animations for React Native on Android, iOS and web, from ASTC texture arrays in KTX2 files. The GPU draws the frames as stored, with Metal, OpenGL ES or WebGL, so dozens play at once with little CPU.
