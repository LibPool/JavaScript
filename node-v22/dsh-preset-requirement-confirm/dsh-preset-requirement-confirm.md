# dsh-preset-requirement-confirm

> 标签: JavaScript

## 简介

Standard mode plus confirm-before-execute. Usage: start a session in this mode, describe the task, answer the questionnaire the agent sends (choices, multi-select, free text, a plain-language explanation per question), then submit; the agent executes only
