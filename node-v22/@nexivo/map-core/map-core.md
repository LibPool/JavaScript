# @nexivo/map-core

> 标签: adapter, amap, bmapgl, geocoder, google-maps, map, qqmap

## 简介

Vendor-neutral map SDK core: unified adapters for AMap, QQ Map, Google Maps and Baidu MapGL. Zero secrets, zero runtime dependencies — keys and endpoints are injected by consumers.
