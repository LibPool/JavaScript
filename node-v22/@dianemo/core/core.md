# @dianemo/core

> 标签: api-client, axios, distributed, http-client, oauth2, plugin, priority-queue, rate-limit, rate-limiter, token-bucket

## 简介

Distribute one API rate limit across every process that spends it — cost-weighted priority queues, freeze/thaw recovery and pluggable backends
