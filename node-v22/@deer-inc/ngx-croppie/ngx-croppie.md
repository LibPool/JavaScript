# @deer-inc/ngx-croppie

> 标签: JavaScript

## 简介

This is an Angular wrapper library for the [Croppie](https://github.com/foliotek/croppie). To use this library you should get familiar with the Swiper documentation as well since this documentation only explains details specific to this wrapper.
