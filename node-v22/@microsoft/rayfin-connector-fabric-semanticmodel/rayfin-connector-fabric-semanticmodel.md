# @microsoft/rayfin-connector-fabric-semanticmodel

> 标签: dax, fabric, powerbi, rayfin, semantic-model

## 简介

Typed connector marker for the Fabric semantic-model (Power BI dataset) connector category. Pair with @microsoft/rayfin-client to type `client.connectors.<name>.executeQuery(...)`.
