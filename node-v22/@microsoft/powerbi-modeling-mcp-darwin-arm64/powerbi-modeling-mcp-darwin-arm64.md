# @microsoft/powerbi-modeling-mcp-darwin-arm64

> 标签: analysis-services, mcp, model-context-protocol, modeling, powerbi, semantic-model, tabular

## 简介

Power BI Authoring MCP Server - Node.js client packaging to author Power BI semantic models in Power BI Desktop, Microsoft Fabric workspaces, and local PBIP and TMDL files., for darwin on arm64
