# @microsoft/power-apps-native-pdf-viewer

> 标签: native-extension, pdf, powerapps, react-native

## 简介

Native PDF viewer extension for Power Apps Mobile — renders PDFs via iOS PDFKit and Android PdfRenderer with Share and Print support.
