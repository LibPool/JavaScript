# @daxmadov/hmac-kit

> 标签: api, auth, authentication, express, fastify, hmac, nestjs, request-signing, security, signature

## 简介

Framework-agnostic HMAC-SHA256 request signing for server-to-server authentication. Includes client signer, server verifier, nonce stores (memory/Redis), and Express/NestJS/Fastify adapters.
