# welltested

> 标签: JavaScript

## 简介

Well Tested CLI: connect your coding agent (MCP + verify-before-done skill), test localhost through an origin-scoped tunnel, and run kept tests from the terminal (in the cloud, or in a browser on this machine with --local).
