# @opa.sh/analytics

> 标签: analytics, attribution, conversion-tracking, first-party, next, nextjs, opa, react, tracker

## 简介

Opa browser analytics SDK — first-party click attribution, identify/track, automatic pageview capture, outbound link decoration. Vanilla JS core with /react and /next subpaths.
