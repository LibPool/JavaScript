# @m59/yaml-to-json

> 标签: dir, directory, json, pipe, recursive, simple, stdin, stdout, yaml

## 简介

pipe yaml to stdin, get json from stdout, or pass a src directory of yaml files (recursive) and a dest directory for json files.
