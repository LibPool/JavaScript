# @snail-js/editor

> 标签: contract, editor, element-plus, pagination, print, rich-text, template, tiptap, vue, vue3

## 简介

Tiptap-based template document editor: a Word-like workspace with real pages, headers and footers, automatic pagination, variables, QR codes, a watermark and browser printing.
