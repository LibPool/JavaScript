# @snail-js/vue

> 标签: captcha, components, context-menu, icons, snail, vue, vue3, word-cloud

## 简介

Vue 3 component library: an icon set that complements Element Plus, Aliyun captcha, click-to-copy, a right-click context menu and a rotating 3D word cloud.
