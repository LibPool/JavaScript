# @insler/rpc-otel

> 标签: JavaScript

## 简介

OpenTelemetry tracing for @insler RPC, delivered as client and host middleware, with W3C traceparent format/parse helpers.

- 源码仓库：git+https://github.com/mattinsler/insler.git
- npm 页面：https://www.npmjs.com/package/@insler/rpc-otel
