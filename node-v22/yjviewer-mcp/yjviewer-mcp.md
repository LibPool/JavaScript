# yjviewer-mcp

> 标签: 3d, cad, cae, geometry, mcp, step, stl, viewer

## 简介

MCP server for YJViewer — load and render 3D geometry files (STEP/IGES/STL/OBJ/FBX/glTF/GLB/VTK/VTP and CAE results) in a browser, take screenshots and switch render modes.
