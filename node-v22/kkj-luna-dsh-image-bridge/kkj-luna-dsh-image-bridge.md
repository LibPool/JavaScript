# kkj-luna-dsh-image-bridge

> 标签: deepseek-harness, dsh, dsh-plugin, image-edit, image-generation, openai-compatible

## 简介

生图桥：给没有生图/修图能力的模型接入外部生图模型。在 Web 界面配置 API 与 Key，模型即可直接调用生图/改图能力。
