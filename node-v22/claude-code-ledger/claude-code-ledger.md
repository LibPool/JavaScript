> 标签: anthropic, audit, budget, claude, claude-code, cli, codex, context, cost, cursor, gemini-cli, hooks, report, token, tool-calls, usage, waste

## 简介

Local-first cost & tool-call audit for Claude Code (plus Codex / Gemini CLI / Cursor logs): per-tool context cost, waste detection, CLAUDE.md suggestions, budget statusline, before/after compare, HTML report. Never reads your message content.
