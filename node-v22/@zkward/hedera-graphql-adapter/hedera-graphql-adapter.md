# @zkward/hedera-graphql-adapter

> 标签: ai-vaults, erc4626, graphql, hedera, mirror-node, subgraph, the-graph

## 简介

Serve any Hedera contract as a standardized GraphQL / subgraph endpoint. Bridges Hedera Mirror Node into The Graph tooling ecosystem — one schema, works for any Hedera contract, no graph-node needed.
