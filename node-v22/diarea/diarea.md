# diarea

> 标签: ai, ai-agents, chrome-extension, claude-code, cli, frontend, github-action, leak-scanner, llm, mcp, reverse-engineering, secrets, security, source-maps

## 简介

Finds what your frontend leaks before anyone else does: exposed keys, source maps, API maps, AI system prompts and debug globals, scored from Sealed to Gushing. Local and read-only.
