# @liha-css/tokens

> 标签: JavaScript

## 简介

`@liha-css/tokens` は **CSS Variables（Design Tokens）** を配布します。 このパッケージは “スタイルを当てる” のではなく、**スタイルの材料（値）だけ**を提供します。

## 官网

- npm 页面：https://www.npmjs.com/package/@liha-css/tokens

## 历史版本号

- 当前版本：0.0.0

- 0.0.0

## 获取地址

- npm registry：https://registry.npmjs.org/@liha-css/tokens
