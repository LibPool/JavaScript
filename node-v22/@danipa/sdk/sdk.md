# @danipa/sdk

> 标签: africa, danipa, fintech, mtn-momo, payments, remittance, stripe

## 简介

Official Node.js SDK for the Danipa payments API — collections, disbursements, wallets, payment links, invoices, webhook verification.

## 官网

- 官网：https://developer.danipa.com/sdks
- 源码仓库：git+https://github.com/Danipa/node-sdk.git
- npm 页面：https://www.npmjs.com/package/@danipa/sdk
