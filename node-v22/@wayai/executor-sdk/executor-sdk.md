# @wayai/executor-sdk

> 标签: data, executor, hmac, idempotency, signature, verify, wayai, webhook

## 简介

Receive and verify WayAI Data's HMAC-signed, idempotency-keyed webhooks and proxied calls — the executor side of the WayAI Data executor contract.
