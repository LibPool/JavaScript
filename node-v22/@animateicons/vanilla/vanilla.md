> 标签: animated icons, animated svg, custom elements, free animated icons, huge animated, icons, lucide animated, motion icons, svelte icons, svg icons, vanilla js, web components

## 简介

Animated SVG icons for plain JavaScript, web components and every framework. The same motion as @animateicons/react, with no framework needed.
