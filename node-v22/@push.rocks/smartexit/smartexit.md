# @push.rocks/smartexit

> 标签: Node.js, SIGINT handling, TypeScript, async cleanup, child process termination, cleanup operations, graceful shutdown, library, module, npm package, process exit management, process management, signal handling, uncaught exception management

## 简介

A library for managing graceful shutdowns of Node.js processes by handling cleanup operations, including terminating child processes.
