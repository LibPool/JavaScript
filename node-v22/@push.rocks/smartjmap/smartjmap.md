# @push.rocks/smartjmap

> 标签: client, deno, email, event-driven, eventsource, fastmail, http, jmap, json, mail, message processing, push, rfc8620, rfc8621, server, stalwart, typescript

## 简介

A TypeScript JMAP toolkit (RFC 8620/8621): an event-driven mail client for reading, sending, and watching mail, plus an embeddable JMAP server core with pluggable storage.
