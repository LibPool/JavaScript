> 标签: API development, HTTP, TypeScript, client errors, custom status codes, error handling, error management, express.js, network services, response management, server errors, status codes, web applications

## 简介

A TypeScript library for managing HTTP status codes, providing detailed classes for each status to enhance HTTP error and response handling.
