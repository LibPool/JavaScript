# @push.rocks/smartstream

> 标签: async transformation, backpressure, buffer, data processing, duplex stream, esm, event handling, file streaming, node.js, pipeline, readable stream, stream, stream manipulation, stream utilities, transform stream, typescript, writable stream

## 简介

A library to simplify the creation and manipulation of Node.js streams, providing utilities for handling transform, duplex, and readable/writable streams effectively in TypeScript.
