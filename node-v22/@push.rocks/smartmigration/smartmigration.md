# @push.rocks/smartmigration

> 标签: data migration, idempotent, ledger, migration, mongodb, nosqldb, objectstorage, rolling deploy, s3, saas, schema migration, semver, startup migration

## 简介

Unified migration runner for MongoDB (@lossless.org/client nosqldb) and S3 (@lossless.org/client objectstorage) — designed to be invoked at SaaS app startup, with semver-based version tracking, sequential step execution, idempotent re-runs, and per-step r
