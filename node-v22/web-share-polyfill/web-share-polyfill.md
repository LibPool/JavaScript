# web-share-polyfill

> 标签: fallback, navigator.share, polyfill, qr code, share, share button, share dialog, share sheet, social, web share, web share api

## 简介

Web Share API polyfill: navigator.share() everywhere, with a tiny native-looking share sheet (copy link, QR code, email and 40+ apps) in 70 languages.
