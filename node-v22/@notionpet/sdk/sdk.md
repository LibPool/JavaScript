# @notionpet/sdk

> 标签: @notion, @notionpet, notion, notion sdk, notionpet

## 简介

@notionpet/sdk 是开发组件用的工具包, 结合 Notion.pet 平台，开发好后的组件可以发布到该平台然后通过 embed 嵌入notion软件中.

## 官网

- 官网：https://github.com/kuai-dian/notion-pet/tree/master#readme
- 源码仓库：git+https://github.com/kuai-dian/notion-pet.git#master
- npm 页面：https://www.npmjs.com/package/@notionpet/sdk
