# @pcpx/cli

> 标签: cli, encryption, one-time-link, pcpx, secrets, zero-knowledge

## 简介

CLI für pcpx.one: Zero-Knowledge Einmal-Secrets aus Scripts und Pipelines. Verschlüsselung läuft lokal (AES-256-GCM, PBKDF2 600k), die API sieht nur Ciphertext.

- npm 页面：https://www.npmjs.com/package/@pcpx/cli
