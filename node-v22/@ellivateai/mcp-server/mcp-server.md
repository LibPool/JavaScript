# @ellivateai/mcp-server

> 标签: ai, claude, claude-code, cursor, ellivate, mcp, model-context-protocol, windsurf

## 简介

MCP server for Claude Code, Cursor, and Windsurf — both teaches Ellivate-shaped patterns up-front and exposes action tools (doctor, publish, list-apps, etc.) the AI uses to actually translate and ship projects.
