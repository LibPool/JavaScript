# @dougen/dsh-cdp

> 标签: browser, cdp, chrome, chromium, devtools, dsh, dsh-plugin, edge

## 简介

让 DSH 通过 CDP 驱动本机已开启调试的 Chromium 内核浏览器：常驻连接只授权一次，零新增工具 schema，零运行时依赖。Drive any already-running Chromium browser over CDP from DSH — one approval per connection, no extra tool schemas, no dependencies.
