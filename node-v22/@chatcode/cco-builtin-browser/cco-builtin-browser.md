# @chatcode/cco-builtin-browser

> 标签: browser, cdp, deepseek-harness, dsh-plugin

## 简介

Shared real browser plugin for ChatCode CLI: install-and-use — a visible native browser the human can take over, driven by the agent over CDP. DOM-level interaction (React/Vue safe), per-task session isolation, cookie persistence (browser_auth), CAPTCHA d
