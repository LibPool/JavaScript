# @e-sig/worm

> 标签: archival, audit-log, compliance, esign, esignature, finra, immutable, object-lock, pdf, retention, s3, sec-17a-4, worm

## 简介

WORM (write-once-read-many) archival adapter for @e-sig/core — store signed PDFs and audit-chain exports in an S3 Object Lock bucket with COMPLIANCE-mode retention set atomically on every put. Technical controls in the style of SEC 17a-4(f) / FINRA 4511.
