# @e-sig/mcp

> 标签: agents, e-signature, esignature, iaaso, mcp, model-context-protocol, pades, pdf, post-quantum, uuaid

## 简介

MCP (Model Context Protocol) server for agent-driven e-signature workflows over @e-sig/core — agents prepare and track envelopes; cryptographic control of signing stays with humans by default (mode H, docs/architecture/esig-mcp.md).
