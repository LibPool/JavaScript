# @flowaws/node-sdk

> 标签: authentication, flowawsome, jwt, sdk, verification, webhook, workflow

## 简介

Node.js SDK for flowawsome — verify webhook signatures and access tokens issued by the flowawsome Identity/Workflow platform without calling back to the API.
