# @firedrill-run/runner-node

> 标签: JavaScript

## 简介

`@firedrill-run/runner-node` is a customer-owned optional execution adapter for the Firedrill SDK. It contains no simulation engine, database or Firedrill service. Ordinary native/command/HTTP clients do not require Docker or this package.
