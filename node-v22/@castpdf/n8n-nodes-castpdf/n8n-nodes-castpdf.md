# @castpdf/n8n-nodes-castpdf

> 标签: castpdf, html-to-pdf, n8n, n8n-community-node-package, pdf, pdf-generation, templates

## 简介

n8n nodes for CastPDF: create PDFs from your CastPDF templates or from HTML, and start workflows when a PDF is ready or fails.
