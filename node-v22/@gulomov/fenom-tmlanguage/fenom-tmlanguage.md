# @gulomov/fenom-tmlanguage

> 标签: fenom, grammar, syntax-highlighting, template, textmate, tmlanguage, tpl, vscode

## 简介

TextMate grammar for the Fenom template engine, injected over HTML so markup, CSS and JavaScript keep their own highlighting
