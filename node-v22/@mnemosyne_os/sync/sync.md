# @mnemosyne_os/sync

> 标签: ai, anonymous, libp2p, mnemosyne, multi-agent, offline, p2p, sovereign, sync

## 简介

MnemoSync — Anonymous P2P multi-agent synchronization for the Mnemosyne Neural OS ecosystem. Enables real-time coordination between AI agents and dev machines without cloud dependency.
