# @sahnavin123/scanner

> 标签: JavaScript

## 简介

A customizable, extensible, and engine-agnostic **QR code scanner** component for React. Built with TypeScript, supports multiple scanning engines like `html5-qrcode`, `zxing-js`, and more.
