# midflight-replay

> 标签: ai-agent, claude-code, cli, codex, developer-tools, forensics, jsonl, observability, postmortem, pr-review, replay, session-log

## 简介

Turn a finished AI coding-agent session into a scrubbable, single-file HTML replay you can attach to a PR. Zero deps, zero build, zero network.
