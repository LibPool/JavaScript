# @profullstack/notifications

> 标签: nextjs, notifications, push-notifications, pwa, rfc8291, rfc8292, service-worker, vapid, web-push, zero-dependencies

## 简介

Web Push that works everywhere, once: VAPID + RFC 8291 encryption from node:crypto (zero dependencies), a browser client that fetches the key at runtime and says exactly why push is unavailable, and service-worker handlers.
