# @profullstack/cli

> 标签: bun, cli, installer, npm, self-update, uninstall, update

## 简介

The commands every Profullstack CLI shares: `update` and `uninstall`, done the same way the tool was installed (curl installer, npm, bun, pnpm or yarn). No dependencies.
