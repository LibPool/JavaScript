# @profullstack/proxy

> 标签: cli, forward-proxy, hproxy, https-proxy, mcp, proxiware, proxy, proxyagent, residential-proxy, rotating-proxy, tui, undici, webshare

## 简介

Call the web through the residential proxies we pay for (Proxiware, Webshare, HProxy) with each provider's own auth and targeting. A library (proxyFetch, proxyUrl), a CLI (`proxy <url>`), a local forward proxy with a JSON API (`proxy serve`), an MCP serve
