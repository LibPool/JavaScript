# @astralux/dsh-token-dashboard

> 标签: balance, cost, dashboard, deepseek-harness, dsh, dsh-plugin, plugin, token, usage

## 简介

DeepSeek Harness 用量看板：账户余额、Token 使用量、按缓存命中/未命中输入与输出的成本拆分，附一年活跃度热力图与分工作区趋势曲线。Fork of @lyk308/dsh-token-dashboard with dsh 0.2.0-rc.2 compatibility fixes.
