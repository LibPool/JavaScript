# @typeflux/temporal-yaml

> 标签: JavaScript

## 简介

Opt-in declarative YAML runtime for the Typeflux TypeScript SDK — loads, env-interpolates, and validates a typeflux.yaml spec, and builds activities + a workflow from it. Keeps @typeflux/temporal dependency-light.
