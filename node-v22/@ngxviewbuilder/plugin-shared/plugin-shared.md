# @ngxviewbuilder/plugin-shared

> 标签: JavaScript

## 简介

Shared pieces of the NGX View Builder plugins (view logic analysis, license gate, icons). Installed with the plugins that need it; not meant to be added on its own.

- 官网：https://ngxviewbuilder.io
- 源码仓库：git+https://github.com/ngxviewbuilder/ngx-view-builder-community.git
