# @caboodle-tech/jamsedu

> 标签: basic, beginner, generator, jamstack, site, static, stem

## 简介

JamsEdu is a feature rich but simplistic to use Jamstack application designed for open source content. Originally designed to help rapidly develop and deploy university courses, JamsEdu is the perfect way to quickly create dynamic static websites for STEM
