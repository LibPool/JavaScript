# @arcagateway/mcp

> 标签: arca, evm, inference, llm, mcp, model-context-protocol, openai-compatible, robinhood-chain, x402

## 简介

MCP server for Arca — call Arca inference models (OpenAI-compatible, pay per call via x402 on Robinhood Chain) as tools from any MCP client.
