# @riskregister/sdk

> 标签: iso-31000, openapi, rest-api, risk-management, riskregister, sdk, typescript

## 简介

TypeScript SDK for the riskregister.com REST API. Generated types from openapi.yaml + a thin Bearer-auth client wrapper with typed errors.
