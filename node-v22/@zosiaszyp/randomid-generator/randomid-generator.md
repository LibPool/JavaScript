# @zosiaszyp/randomid-generator

> 标签: JavaScript

## 简介

Generator ID - paczka, która pozwala na wygenerowanie unikalnych identyfikatorów. W module tym główna funkcja, randomID, generuje losowy ciąg znaków, który na końcu jest zwracany.
