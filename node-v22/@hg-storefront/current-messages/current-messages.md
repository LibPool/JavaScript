# @hg-storefront/current-messages

> 标签: JavaScript

## 简介

Headless hooks for "Aktuella budskap", the rotating text row at the top of hemglass.se and the Hemglass app. Marknad schedules the messages in the Vendure Dashboard; this package fetches the ones that are active right now and rotates them. It ships no UI:
