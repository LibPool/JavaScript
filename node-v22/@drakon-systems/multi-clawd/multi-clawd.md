# @drakon-systems/multi-clawd

> 标签: anthropic, claude, claude-code, cli-backend, failover, multi-account, openclaw, plugin

## 简介

Multi-account Claude Code failover for OpenClaw — register additional Claude (Max/Pro) logins as first-class CLI backends and keep the full skills/MCP harness across every account. Also imports those accounts' setup tokens into Hermes Agent's Anthropic cr
