# @kidlab/dsh-kid-memory

> 标签: dsh, dsh-plugin, kid, memory

## 简介

给小朋友的内存启蒙插件：一个包 = 一张 🦉「记忆小管家·电脑的工作台」卡片 + 四个模型工具（mem_now / mem_pressure / mem_workbench / mem_top），零第三方依赖、无构建步骤。
