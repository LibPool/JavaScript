# @off-market/pmp-mcp

> 标签: JavaScript

## 简介

Local **stdio** MCP over `@starkware-libs/pmp-trading-core`: one identity, one file-backed store, guardrails from env. Tool semantics live in `src/doctrine.ts`. This file is the operator contract.
