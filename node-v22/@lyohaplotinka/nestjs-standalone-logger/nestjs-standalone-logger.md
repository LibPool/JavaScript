# @lyohaplotinka/nestjs-standalone-logger

> 标签: console, log-levels, logger, logging, nestjs, standalone

## 简介

NestJS logger extracted from the framework and decoupled from it. Works in any Node.js or Bun project with zero NestJS dependencies.
