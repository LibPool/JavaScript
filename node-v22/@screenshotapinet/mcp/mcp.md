# @screenshotapinet/mcp

> 标签: ai-tools, claude, html-to-pdf, mcp, model-context-protocol, screenshot, screenshotapi, url-to-pdf, web-scraping, website-screenshot

## 简介

Official MCP server for ScreenshotAPI — website screenshots, URL/HTML to PDF, scrolling videos, web scraping (text, Markdown, HTML), and bulk captures as MCP tools for Claude, Cursor, Windsurf, and any MCP client.
