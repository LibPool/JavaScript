# @node-cron/fastify

> 标签: cron, distributed, fastify, fastify-plugin, job, node-cron, schedule, scheduler, task

## 简介

Fastify plugin that schedules jobs with node-cron: a drop-in-friendly alternative to @fastify/schedule with cron expressions, distributed-ready scheduling via a pluggable coordinator, and background tasks.
