# @node-cron/nestjs

> 标签: background-task, cron, distributed, nest, nestjs, node-cron, schedule, scheduler, task

## 简介

NestJS integration for node-cron: a drop-in replacement for @nestjs/schedule with the same decorators, plus background tasks and distributed-ready scheduling.
