# @sleet-js/intear-api-tool-box

> 标签: JavaScript

## 简介

Typed TypeScript SDK for the Intear API (https://api.intea.rs) — token data, charts, trades, transfers, balances, holders over HTTP and a single WebSocket connection, with strict per-field types and AsyncIterable subscriptions.
