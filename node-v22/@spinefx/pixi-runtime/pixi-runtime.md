# @spinefx/pixi-runtime

> 标签: igaming, particles, pixi, pixijs, slot, spine, spinefx, vfx

## 简介

Live PixiJS runtime for SpineFX Particles effects. Loads .spfx.json emitter definitions exported from the SpineFX Particles editor and simulates particles each frame.

- 官网：https://spinefx.io/pixi
