# @chavajs/installer

> 标签: chavajs, cli, installer, laravel, scaffold, typescript

## 简介

chavaJs installer — the Laravel Installer equivalent. `chava new <name>` scaffolds a ready-to-run chavaJs app, downloading the framework from npm.
