# @elo/elo-base-lib

> 标签: @elo/elo-base-lib, @elo/elo-cli, @elo/ix-client-typescript

## 简介

ELO Base Lib is a foundational library for ELO Digital Office applications (ELO apps), providing essential utilities and functionalities to enable a single page application (SPA) to access an ELO repository.
