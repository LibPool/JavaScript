# @s3nd/core

> 标签: aws, bucket, indexeddb, local-first, minio, nextjs, r2, s3, storage, sync, typescript, upload

## 简介

Move a local-first app's data between devices through your own S3 bucket: snapshots, sync codes and a transfer handler. Works with AWS S3, Cloudflare R2, MinIO and any S3-compatible storage.
