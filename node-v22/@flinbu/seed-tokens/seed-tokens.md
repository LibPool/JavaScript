# @flinbu/seed-tokens

> 标签: design-system, design-tokens, seed, tailwindcss, theming

## 简介

Seed's design tokens as CSS variables, a Tailwind CSS v4 theme, DTCG JSON and typed data, plus createTheme() and the seed CLI for accessible brand themes.
