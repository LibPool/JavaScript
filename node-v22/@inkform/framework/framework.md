# @inkform/framework

> 标签: api-reference, blog, changelog, docs, documentation, mdx, nextjs, openapi, static-site

## 简介

Standalone Next.js + MDX framework for documentation, API reference (OpenAPI), blog, and changelog sites. The rendering engine behind the inkform docs themes — usable on its own.
