# @pantarey.io/ngx-planning-board

> 标签: angular, calendar, gantt, ngx, planning-board, resource-timeline, scheduler, shift-plan, timeline, vacation-planner

## 简介

Resource planning board for Angular: rows x time axis with layers of entries, per-row availability, grouping frames, style rules and result columns. Early development and test phase (0.x): the API changes until 1.0. Depends on Angular core, common and CDK
