# scopink

> 标签: acp, agent, ai-agents, ascii-art, discord, gemini-cli, meme, scope, scope-checker, scope-creep, zed

## 简介

Scopink - checks if an action is within the scope of what was asked. Detects scope creep in agent plans. In-scope, borderline, or out-of-scope with a reason.
