# @konce-pt/backdrop

> 标签: animation, backdrop, background, canvas, design-system, hero, koncept-ui, kpt

## 简介

Animated backdrop core for Koncept UI — canvas renderers plus the maths behind two effects: a density-ramped grid of squares and a flowing current of light with an OKLCH colour ramp. Framework-free TypeScript, zero runtime dependencies.
