# @konce-pt/theme

> 标签: contrast, dark-mode, design-system, design-tokens, koncept-ui, kpt, oklch, palette, theme, theming

## 简介

Theme core for Koncept UI — the kpt-theme document format, an OKLCH ramp derived from one seed colour, semantic role derivation, contrast audit and exporters to CSS/SCSS/TS/DTCG. Framework-free TypeScript.
