# dwt

> 标签: JavaScript

## 简介

Dynamic Web TWAIN (DWT) is an SDK covering the full web document scanning workflow: image acquisition via TWAIN/WIA/ICA/SANE/eSCL, viewing/editing, barcode reading, image export (PDF/TIFF/JPEG/PNG), and server upload — on Windows, macOS, and Linux.
