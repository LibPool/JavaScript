# @dylanmurzello/vendure-plugin-deep-pagination

> 标签: api, backend, cursor-pagination, deep-pagination, e-commerce, ecommerce, elasticsearch, elasticsearch-plugin, graphql, graphql-api, headless-commerce, infinite-scroll, nestjs, nestjs-plugin, pagination, performance-optimization, product-catalog, product-search, scalability, search-after, search-engine, typescript, vendure, vendure-ecommerce, vendure-plugin

## 简介

Infinite product pagination for Vendure e-commerce using Elasticsearch search_after cursors. Bypass the 10k offset limit. O(1) performance at any page depth.
