# @shelbyb/daywalker-sdk

> 标签: api-token, authentication, cron-monitoring, daywalker, devpulse, ed25519, feature-flags, logging, on-call, openfeature, product-analytics, request-signing, rest-api, rum, secrets, slo, standard-webhooks, web-vitals, webhooks

## 简介

Daywalker Auth service validation plus the DevPulse client SDKs (feature flags, OpenFeature, product analytics, Web Vitals, management API client) in one package with a single runtime dependency (re2js).
