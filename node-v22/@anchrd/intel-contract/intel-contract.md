# @anchrd/intel-contract

> 标签: JavaScript

## 简介

The shared wire contract for [`@anchrd/intel-api`](https://www.npmjs.com/package/@anchrd/intel-api): Zod schemas that describe every payload crossing Intel's HTTP, MCP and browser surfaces.
