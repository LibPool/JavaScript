# @gammarers/aws-frontend-web-app-deploy-stack

> 标签: aws, cdk, cdn, cloudfront, deploy, spa, web

## 简介

This is an AWS CDK Construct to make deploying a Frontend Web App (SPA) deploy to S3 behind CloudFront.
