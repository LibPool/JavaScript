# @nx/oxlint

> 标签: CLI, Lint, Monorepo, Oxlint, Web

## 简介

Experimental. The Oxlint plugin for Nx contains generators and utilities used for linting JavaScript/TypeScript projects within an Nx workspace.

- 官网：https://nx.dev
- 源码仓库：https://github.com/nrwl/nx.git
