# @hjam91/billing

> 标签: billing, cloudflare-workers, entitlements, feature-flags, hono, paywall, react, stripe, subscriptions, usage-based-billing

## 简介

Zero-dependency client for a billing-kit service: cached, fail-open entitlement and feature checks, usage tracking, Stripe Checkout / portal, signed webhook verification, a Hono gate and an optional React billing card.
