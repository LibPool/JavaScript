# @fomoxa/net

> 标签: binary, fomoxa, networking, protocol, tcp, udp

## 简介

The Fomoxa runtime for Node: framing, schema handshake, heartbeat and a non-blocking TCP/UDP tick loop. Codecs come from fomoxac.
