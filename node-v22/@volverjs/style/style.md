# @volverjs/style

> 标签: components library, css, css custom properties, css variables, design tokens, design-system, responsive, scss, utility classes, volver, volverjs

## 简介

@volverjs/style is a lightweight responsive CSS utility library to accompany @volverjs/ui-* and static webpages as well.

- 源码仓库：git+https://github.com/volverjs/style.git
