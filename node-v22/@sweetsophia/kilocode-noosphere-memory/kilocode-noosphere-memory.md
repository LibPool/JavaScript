# @sweetsophia/kilocode-noosphere-memory

> 标签: kilocode, kilocode-plugin, memory, noosphere, recall

## 简介

Kilo Code plugin for Noosphere memory: prompt-time auto-recall, optional idle auto-save, and explicit memory tools.
