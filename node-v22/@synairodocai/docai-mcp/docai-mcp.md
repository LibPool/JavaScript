# @synairodocai/docai-mcp

> 标签: document-ai, document-extraction, mcp, model-context-protocol, ocr

## 简介

DocAI MCP server and installer: lets MCP-compatible coding agents (Codex, Claude Code, Gemini CLI) discover DocAI capabilities, fetch integration guidance, and extract structured data from local documents through the DocAI API.
