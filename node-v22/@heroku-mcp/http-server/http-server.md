# @heroku-mcp/http-server

> 标签: heroku, mcp, mcp-server, model-context-protocol, oauth, self-hosted

## 简介

Self-hosted HTTP server exposing Heroku MCP tools to LLM clients via OAuth-protected MCP endpoint.
