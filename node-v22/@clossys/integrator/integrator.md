# @clossys/integrator

> 标签: admission, catalogue, entitlement, inventory, reachability, supersession, typescript, version-reconciliation

## 简介

Machinery a consuming plane runs against itself to answer whether it holds the catalogue it is entitled to, and whether that holding is current: entitlement and opt-out validation, an installed-inventory reader, a version reconciler, a reachability probe,
