# @clossys/observer

> 标签: audit, escape-rate, fleet-coverage, gate-efficacy, observability, redaction, telemetry, typescript

## 简介

Telemetry contracts, redaction as a tested contract, gate efficacy measured from caller-supplied run history, and a fleet package-coverage grader with a CLI. The measurer, never the measured: this package computes whether a gate is working and never judge
