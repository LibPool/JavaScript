## 简介

DEPRECATED — compatibility shim for @mailgent-dev/sdk (now defaults to api.mailgent.dev). Official Node.js SDK for the Loomal API — identity infrastructure for AI agents and Loomal Pay (x402 paywall). Migrate to @mailgent-dev/sdk.
