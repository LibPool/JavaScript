# @scalebrowser/mcp

> 标签: ai-agent, browser, browser-automation, mcp, mcp-server, model-context-protocol, scalebrowser

## 简介

Stdio MCP server for Scalebrowser: it connects your agent to the isolated browsers the Scalebrowser app runs on your own Windows machine.
