# @heyramzi/rich-editor

> 标签: editor, markdown, rich-text, svelte, svelte5, tiptap

## 简介

Svelte 5 rich text editor on Tiptap: slash menu, image toolbar, block ids, a Markdown bridge and an SSR renderer for the saved JSON.
