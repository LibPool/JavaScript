# @phygrid/analytics-publisher

> 标签: analytics, client, events, internal, phygrid, typescript

## 简介

Internal Phygrid library for publishing and validating analytics events, with support for batching, retry strategies, and observability. Designed for reliable event delivery and easy integration across services.
