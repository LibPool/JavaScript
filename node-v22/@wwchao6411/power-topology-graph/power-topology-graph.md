# @wwchao6411/power-topology-graph

> 标签: JavaScript

## 简介

`PowerTopologyGraph` 是主站网络拓扑通用组件，基于 AntV X6 3.x 渲染分区、业务分组、设备、逻辑总线、链路、拖拽同步、小地图和选中高亮。
