# @stephencollinstech/hotspots

> 标签: code-quality, complexity, cyclomatic-complexity, hotspots, lrs, static-analysis, typescript

## 简介

CLI that finds the riskiest code in your codebase by combining complexity with git change history (Local Risk Score) across TypeScript, JavaScript, Go, Python, Rust, and Java
