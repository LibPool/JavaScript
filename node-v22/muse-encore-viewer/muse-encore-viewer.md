# muse-encore-viewer

> 标签: engraving, mscx, mscz, musescore, music notation, score viewer, sheet music

## 简介

Show MuseScore files (.mscz/.mscx) in a web page like an inline PDF viewer: pages, continuous views, zoom, printing, full screen and playback. Based on MuseEncore, a TypeScript port of MuseScore Studio's engraving engine.
