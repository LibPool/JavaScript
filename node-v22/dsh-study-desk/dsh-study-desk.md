# dsh-study-desk

> 标签: deepseek-harness, dsh-plugin, heatmap, kanban, kaoyan, markdown, obsidian, pomodoro, spaced-repetition, study

## 简介

学习工作台 DSH 插件：Notion 式待办墙与标签过滤 + 间隔重复复习队列（简化 SM-2，带记忆曲线、未来 7 天到期预报与今日建议）+ 按实际复习时长点亮的热力图与周报 + 每日复盘 + Markdown 导出读回 + 跨面板存活的番茄钟 + 独立的不背单词打卡面板（只读本机 App 数据）。只消费主题 token，融入现有主题而不改主题。
