# @yiong/railguard

> 标签: agent-security, ai-safety, citation, guardrails, hallucination, llm, llm-guardrails, mcp, prompt-injection, rbac, vercel-ai-sdk

## 简介

Lifecycle-hook guardrail pipeline for LLM apps and agents: data-access guards and LLM I/O guards in one zero-dependency TypeScript library. In-process, Node + edge, per-rule enforce/observe/off.
