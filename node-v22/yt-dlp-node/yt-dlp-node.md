# yt-dlp-node

> 标签: innertube, metadata, streaming-data, typescript, video, youtube, yt-dlp

## 简介

Pure TypeScript YouTube video metadata and streaming-data extractor inspired by yt-dlp. Uses got for HTTP with built-in proxy support. No yt-dlp, Python or ffmpeg required.
