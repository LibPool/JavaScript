# @litfamily/litcodex

> 标签: ai-agents, codex, lit-loop, litcodex, orchestration

## 简介

Codex loop harness installer. Run `npm exec --package @litfamily/litcodex -- litcodex install` to set up the LitCodex Codex platform: the bare `lit` hook and the durable lit-loop runtime.
