# @michaelmagan/dnumb

> 标签: accessibility, agent, ai-agent, cli, contrast, dom, e2e, geometry, layout, playwright, testing

## 简介

Turns a rendered page into measurements an agent can read: element geometry, overflow, clipping, and a text diff of what changed between two states.
