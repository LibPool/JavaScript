# @dvd-toy-box/gateway

> 标签: broker, capabilities, gateway, mcp, oauth, toy-box

## 简介

One sign-in, one place, and every app also works from your AI assistant. An MCP gateway that mounts capability servers, holds the keys, enforces grants and tool policy, audits every call, and serves the app store page.
