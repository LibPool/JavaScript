# @link-foundation/link-cli-client

> 标签: client, clink, doublets, link-cli, links, links-notation, lino, wasm

## 简介

Minimal universal JS/TS client for link-cli stores: the clink --serve TCP protocol (Node.js, Bun, Deno), a subprocess adapter and the in-process WebAssembly backend, behind one contract with explicit capabilities
