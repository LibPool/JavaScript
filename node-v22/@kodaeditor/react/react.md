# @kodaeditor/react

> 标签: docx, editor, html-editor, prosemirror, react, react-component, react-editor, rich-text-editor, word-paste, wysiwyg

## 简介

React wrapper for KodaEditor: a WYSIWYG rich-text editor that keeps Word and Excel formatting on paste.
