# @nexural/forge-emit

> 标签: JavaScript

## 简介

Template render + filesystem emit engine for nx forge. Renders Handlebars-style {{vars}} + conditional blocks against validated recipe inputs and warehouse-supplied template files. Per ADR-0002, ADR-0011.
