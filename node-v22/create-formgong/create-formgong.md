# create-formgong

> 标签: astro, bolt, contact form, contact-form, create, email, form backend, form-backend, formgong, forms, formspree-alternative, gdpr, lovable, nextjs, react, starter, static-site, telegram, template, v0, web3forms-alternative

## 简介

Scaffold a contact form that works without a backend: Next.js, Astro, plain HTML or a React component for Lovable, Bolt and v0. Can create the Formgong form for you. Submissions go to email and Telegram.
