# @seydx/ciao

> 标签: bonjour, ciao, dns-sd, mdns, mdns-sd, multicast-dns, rfc-6762, rfc-6763, service-discovery, zero-configuration, zeroconf

## 简介

ciao is a RFC 6763 compliant dns-sd library, advertising on multicast dns (RFC 6762) implemented in plain Typescript/JavaScript
