# @atrib/mcp-wrap

> 标签: agent, attribution, ed25519, mcp, model-context-protocol, verifiable, wrapper

## 简介

Config-driven MCP wrapper for atrib's verifiable action layer. Gates, signs, logs, and mirrors tool calls from any upstream MCP server.
