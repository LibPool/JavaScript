# @atrib/summarize

> 标签: agent, atrib, attribution, cognitive-primitive, llm, mcp, memory, model-context-protocol, summarization, verifiable

## 简介

Legacy summarization MCP server retained during the D164 alias window. Summarizes signed records so agents read context, not raw bytes.
