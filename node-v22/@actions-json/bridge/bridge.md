# @actions-json/bridge

> 标签: actions.json, agent, bridge, browser, mcp

## 简介

Run the actions.json MCP bridge with npx — no Rust toolchain required. Downloads the prebuilt actions-json-mcp binary, bundles the primitive dictionary, and creates your storage workspace on first run.
