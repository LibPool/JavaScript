# @heventure/web-gpt

> 标签: ai-agent, browser-automation, chatgpt, cli, coding-agent, openai, playwright, second-opinion, web-gpt

## 简介

Unofficial browser bridge to a logged-in ChatGPT web session for coding agents. Temporary chats, JSON output, profile lock, debug bundles.
