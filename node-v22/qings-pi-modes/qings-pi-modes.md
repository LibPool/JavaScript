# qings-pi-modes

> 标签: bubblewrap, opencode, permission, permissions, pi, pi-coding-agent, pi-extension, pi-package, plan-mode, policy, sandbox, security, tree-sitter

## 简介

Declarative, user-definable permission modes for the pi coding agent: OS-level sandboxing (bubblewrap / sandbox-exec), an allow/ask/deny policy engine, real bash AST gating (tree-sitter), tool hiding, and skill/custom-tool gating.
