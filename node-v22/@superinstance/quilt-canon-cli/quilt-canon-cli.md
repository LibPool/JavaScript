# @superinstance/quilt-canon-cli

> 标签: ai-writings, cli, live-canon, quilt, rag

## 简介

A unified CLI for the Live Canon. `canon claim`, `canon drill`, `canon hash`, `canon graph`, `canon paper`. Wraps the @superinstance/canon-*, @superinstance/live-canon packages.
