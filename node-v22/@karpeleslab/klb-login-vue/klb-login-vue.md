# @karpeleslab/klb-login-vue

> 标签: authentication, klbfw, login, oauth2, passkey, vue, vue3

## 简介

Thin Vue 3 plugin around @karpeleslab/klb-login-core: dynamically loads the CDN core, injects klbfw transport + i18n, forwards events.
