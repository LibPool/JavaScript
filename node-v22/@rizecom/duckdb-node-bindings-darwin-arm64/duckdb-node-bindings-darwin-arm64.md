# @rizecom/duckdb-node-bindings-darwin-arm64

> 标签: JavaScript

## 简介

Binaries supporting [Node](https://nodejs.org/) bindings to the [DuckDB C API](https://duckdb.org/docs/api/c/overview) for Mac OS X (Darwin) arm64.
