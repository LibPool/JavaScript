# @vp-search/algolia

> 标签: algolia, docsearch, search, vitepress, vitepress-plugin

## 简介

Algolia DocSearch provider for @vp-search/core — a plain-fetch adapter for DocSearch indexes, without the algoliasearch client or the DocSearch UI bundle.
