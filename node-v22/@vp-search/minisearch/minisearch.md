# @vp-search/minisearch

> 标签: full-text-search, local-search, minisearch, search, vitepress, vitepress-plugin, web-worker

## 简介

Local search provider for @vp-search/core — per-locale MiniSearch indexes built from the rendered site, tiered artifacts queried in a Web Worker, CJK-aware.
