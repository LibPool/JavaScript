# @noem/virtual-keyboard

> 标签: browser, esm, keyboard, kiosk, lit, touch, typescript, virtual-keyboard, web-components

## 简介

Configurable virtual keyboard web component (<noem-virtual-keyboard>) for touch kiosks and desktops, built with Lit. Built-in layout templates, fully custom layouts, an events-first API that can drive an input/textarea directly, and theming via CSS custom
