# aurora-field

> 标签: animation, canvas, custom element, face tracking, generative, hero, landing page, mediapipe, offscreencanvas, particles, svg, text, web component, web worker, webgl, zero-dependency

## 简介

A zero-dependency WebGL particle field: lit, solid shapes that morph; people drawn by a pen of light then lit; storyboards as JSON on a stage; React. Text, SVG, images, rigged helmets, a web component, worker mode.
