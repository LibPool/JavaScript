# @cubig/design-system

> 标签: checkbox, description, design-system, input, label, react, styled-components, textfield, typescript, ui-components

## 简介

A comprehensive design system built with React, TypeScript, and styled-components. Includes Label, Description, Input, TextField, Checkbox components with dynamic trailing icons and responsive design tokens.
