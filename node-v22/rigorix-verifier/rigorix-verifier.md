# rigorix-verifier

> 标签: audit, hmac, jsonschema, rigorix, verifier

## 简介

Protocol-only verification of Rigorix audit envelopes: HMAC, JSON Schema, per-producer chains, and Ed25519 anchor artifacts. Consumes the canonical rigorix-schemas corpus.
