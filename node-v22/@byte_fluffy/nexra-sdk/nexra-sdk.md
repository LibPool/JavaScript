# @byte_fluffy/nexra-sdk

> 标签: JavaScript

## 简介

TypeScript SDK for the Nexra Task API. It includes task execution, model discovery, asset upload/download, webhook verification, authoritative catalog quotes, and the browser-safe public model catalog.
