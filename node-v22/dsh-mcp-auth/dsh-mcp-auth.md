# dsh-mcp-auth

> 标签: deepseek-harness, dsh, dsh-mcp-auth, dsh-v0.1.7-rc.2, mcp

## 简介

Persistent MCP login state for DeepSeek Harness: OAuth 2.1 / manual header credentials per MCP server, injected into mcp-client rows via !!js. Settings UI talks to the host over Typert Remote.
