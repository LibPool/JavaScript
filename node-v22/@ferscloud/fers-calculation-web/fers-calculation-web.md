# @ferscloud/fers-calculation-web

> 标签: beam, bending-moment, buckling, cad, civil-engineering, deflection, en1993, engineering, eurocode, fea, fem, finite-element, finite-element-analysis, frame, rust, shear-force, solver, steel-design, stiffness-matrix, structural-analysis, structural-engineering, truss, wasm, webassembly

## 简介

Structural analysis FEM solver for beams, frames and trusses, compiled from Rust to WebAssembly. Runs in the browser or in Node with no server round-trip. Includes Eurocode EN 1993-1-1 steel checks.
