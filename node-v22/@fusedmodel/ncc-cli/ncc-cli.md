# @fusedmodel/ncc-cli

> 标签: capability, cli, mcp, ncc, registry

## 简介

npm wrapper for the NCC CLI: locates (or downloads) the platform Rust binary and runs it.

- 官网：https://ncc.ai/cli
- 源码仓库：git+https://github.com/fusedmodel/ncc.git
