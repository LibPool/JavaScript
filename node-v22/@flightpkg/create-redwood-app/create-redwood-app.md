# @flightpkg/create-redwood-app

> 标签: JavaScript

## 简介

This package creates and installs a Redwood project, which is the entry point for anyone using Redwood. It has two parts: - The installation script `create-redwood-app.js` - Project template code in the `template/` directory

## 官网

- 源码仓库：https://github.com/redwoodjs/flight.git
- npm 页面：https://www.npmjs.com/package/@flightpkg/create-redwood-app
