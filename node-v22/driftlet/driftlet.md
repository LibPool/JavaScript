# driftlet

> 标签: band-diagram, battery, cyclic-voltammetry, device-simulation, drift-diffusion, electrochemistry, hodgkin-huxley, impedance-spectroscopy, ion-transport, membrane-potential, nernst-planck, physics, pn-junction, poisson-nernst-planck, semiconductor, simulation, solar-cell

## 简介

Dependency-free 1D drift–diffusion–reaction (Poisson–Nernst–Planck) solver for semiconductors, electrochemistry and nerves, fast enough for live web demos
