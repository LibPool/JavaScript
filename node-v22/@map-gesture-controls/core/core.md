# @map-gesture-controls/core

> 标签: a11y, accessibility, browser, computer-vision, gesture-control, gesture-detection, gesture-navigation, gesture-recognition, hand-gesture, hand-gestures, hand-tracking, hands-free, interaction, kiosk, map, map-controls, mediapipe, no-touch, touchless, touchless-navigation, wasm, webcam

## 简介

Map-agnostic hand gesture detection engine using MediaPipe. Pan, zoom, and rotate maps with webcam hand tracking in the browser.
