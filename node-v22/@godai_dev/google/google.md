# @godai_dev/google

> 标签: JavaScript

## 简介

GDI 共通 Google Drive 基盤（gdi-google-proxy）クライアント SDK。gdi-auth auth_token を Bearer で転送し、Drive 検索・取得・ダウンロード・アップロード・更新を数行で呼び出す
