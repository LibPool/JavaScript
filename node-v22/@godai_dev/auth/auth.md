# @godai_dev/auth

> 标签: JavaScript

## 简介

GDI 共通認証基盤（gdi-auth）JWT 検証 SDK。RS256 / JWKS ベースで auth_token を検証し、クロスドメイン SSO ハンドオフ（PKCE）を補助する
