# everbary-mcp

> 标签: certified-translation, immigration, legal, mcp, model-context-protocol, translation, uscis

## 简介

Order USCIS-ready certified translations from Claude, ChatGPT, Cursor or any MCP client. Local stdio bridge to the eVerbary MCP server.
