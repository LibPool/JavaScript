# @skavex/skavex

> 标签: katex, latex, markdown, rehype, remark, ssr, svelte, sveltekit, unified, vite-plugin

## 简介

Server-rendered Markdown + LaTeX for Svelte. A Vite plugin that compiles .md into real Svelte components.
