# @nutanix-scratch/aiops-js-client

> 标签: Nutanix AIOps APIs, nutanix

## 简介

The Javascript client for Nutanix AIOps APIs is designed for Javascript client application developers offering them simple and flexible access to APIs that manage infrastructure on-premises and in the cloud seamlessly through AIOps features such as Analys
