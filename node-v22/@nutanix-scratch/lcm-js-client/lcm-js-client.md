# @nutanix-scratch/lcm-js-client

> 标签: Nutanix Lcm Versioned APIs, nutanix

## 简介

The Javascript client for Nutanix Lcm Versioned APIs is designed for Javascript client application developers offering them simple and flexible access to APIs that manage Infrastructure, Software and Firmware Upgrades.
