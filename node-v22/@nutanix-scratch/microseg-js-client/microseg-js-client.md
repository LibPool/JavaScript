# @nutanix-scratch/microseg-js-client

> 标签: Nutanix Flow Management APIs, nutanix

## 简介

The Javascript client for Nutanix Flow Management APIs is designed for Javascript client application developers offering them simple and flexible access to APIs that manage Network Security Policy configuration of Nutanix clusters.
