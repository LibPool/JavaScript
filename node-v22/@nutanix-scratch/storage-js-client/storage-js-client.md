# @nutanix-scratch/storage-js-client

> 标签: Nutanix Storage Versioned APIs, nutanix

## 简介

The Javascript client for Nutanix Storage Versioned APIs is designed for Javascript client application developers offering them simple and flexible access to APIs that manages volume groups and storage containers in Nutanix cluster.
