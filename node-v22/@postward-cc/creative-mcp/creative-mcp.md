# @postward-cc/creative-mcp

> 标签: ffmpeg, image-processing, local-first, mcp, model-context-protocol, offline, video-editing

## 简介

Local-first MCP server for video and image editing — ffmpeg and ImageMagick driven by natural language. 100% offline: no keys, no network calls, no uploads, no account.
