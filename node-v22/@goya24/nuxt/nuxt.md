# @goya24/nuxt

> 标签: chat-widget, customer-support, goya24, messenger, nuxt, nuxt-module, persian, vue

## 简介

Nuxt module for the goya24 support messenger: the key from nuxt.config or the environment, the messenger in the browser, `useGoya24()` everywhere — server rendering included.
