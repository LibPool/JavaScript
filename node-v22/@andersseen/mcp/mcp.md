# @andersseen/mcp

> 标签: ai, andersseen, angular, claude, copilot, cursor, mcp, model-context-protocol, react, vue, web-components

## 简介

Model Context Protocol server for And Web Components — lets AI assistants (Claude, Cursor, Copilot, VS Code…) query the component catalog and generate correct, framework-specific usage snippets.
