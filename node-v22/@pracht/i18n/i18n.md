# @pracht/i18n

> 标签: accept-language, hreflang, i18n, internationalization, locale, pracht, preact, translations

## 简介

First-party i18n primitives for Pracht: locale-detection middleware, lazy locale dictionaries with typed keys, plural selection via Intl.PluralRules, and hreflang helpers.
