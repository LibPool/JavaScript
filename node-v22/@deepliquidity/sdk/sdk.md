# @deepliquidity/sdk

> 标签: amm, bonding-curve, cpmm, deep, deepswap, launchpad, sdk, solana

## 简介

TypeScript client for DEEP on Solana: deep-curve (launchpad bonding curve) and DeepSwap (deep-amm) PDAs, instruction builders, account and event decoders, and the programs IDLs.
