# @whatevertools/web-host

> 标签: JavaScript

## 简介

Install and run uTools-style plugin packages (.upx / .asar / .zip / folders) on any website at runtime: IndexedDB storage, a Service Worker that serves each plugin, one iframe per plugin, install policy
