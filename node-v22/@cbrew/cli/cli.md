# @cbrew/cli

> 标签: agent, ai-agent, claude-code, cli, feedback, work-orders

## 简介

Context Brew CLI — pull your human-approved 'ready' feedback queue into your repo as markdown work orders for an AI agent loop, and close items on ship. SSO-style device login; nothing secret is stored in your project.
