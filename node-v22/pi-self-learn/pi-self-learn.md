# pi-self-learn

> 标签: extension, lessons, local-first, long-term-memory, memory, pi, pi-coding-agent, pi-package, rag, recall, self-learning, session

## 简介

Self-learning memory for the pi coding agent — distills every session into scored, auto-injected lessons (short- and long-term memory, local RAG), 100% on-device
