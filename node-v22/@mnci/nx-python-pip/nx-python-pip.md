# @mnci/nx-python-pip

> 标签: azure-functions, nx, nx-plugin, pip, python

## 简介

An Nx plugin for pip-native Python projects (Ruff + pytest + the standard PyPA build/twine tools) — no uv, no Poetry, no lock file.
