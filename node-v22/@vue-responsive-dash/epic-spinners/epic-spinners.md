# @vue-responsive-dash/epic-spinners

> 标签: JavaScript

## 简介

Wrapper for [https://github.com/epicmaxco/epic-spinners](https://github.com/epicmaxco/epic-spinners). Places the choice of spinner automatically in the middle of the DashItem. Intended to be used when your DashItem components require data to be loaded.
