# @better-files/plugin-reviews

> 标签: access-review, better-iam, certification, compliance, data-room, typescript

## 简介

Access reviews for Better Files: periodic room access certifications with per-person keep or revoke decisions, recommendations from activity, self-review prevention, scheduled campaigns and revocation on completion
