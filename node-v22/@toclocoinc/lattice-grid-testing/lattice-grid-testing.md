# @toclocoinc/lattice-grid-testing

> 标签: accessibility, cypress, data-grid, e2e, end-to-end, lattice-grid, locators, playwright, test-helpers, testing

## 简介

End-to-end test helpers for apps built on Lattice Grid: locators and readers over the grid's public DOM contract (data attributes and ARIA roles), with thin bindings for Playwright and Cypress.
