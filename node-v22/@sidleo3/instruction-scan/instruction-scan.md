# @sidleo3/instruction-scan

> 标签: agent-instructions, agents-md, deepseek-harness, dsh, instruction, plugin

## 简介

Configurable AGENTS.md file discovery provider for DSH: scan cwd / project / ancestors / global, editable candidates and project-root markers, replacing hardcoded discovery in dsh-agent-instructions.
