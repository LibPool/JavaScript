# @sidleo3/dsh-kb

> 标签: deepseek-harness, dsh, knowledge-base, markdown, plugin, progressive-disclosure, tags

## 简介

通用知识库（渐进式披露）插件：目录即分类（多级，可启用/停用），每个知识点一个 markdown 文件（front-matter + 正文），多标签 + 关键词检索。适用于 DeepSeek Harness (DSH)，任意 preset 模式可用。Install via `dsh plugin --profile <name> add @sidleo3/dsh-kb`.
