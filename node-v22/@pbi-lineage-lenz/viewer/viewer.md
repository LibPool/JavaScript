# @pbi-lineage-lenz/viewer

> 标签: lineage, pbip, power-bi, semantic-model, source-map, viewer

## 简介

Read-only UI for a parsed Power BI model — lineage graph, measure catalog, and dual-name source map. No file I/O, so the same components render live in the browser and frozen inside a handoff file.
