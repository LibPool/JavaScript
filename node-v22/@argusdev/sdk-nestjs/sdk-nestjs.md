# @argusdev/sdk-nestjs

> 标签: argus, error-tracking, monitoring, nest, nestjs, sdk

## 简介

Argus SDK for NestJS — global exception filter (Express + Fastify) with source context: the crashing code lines, read at capture and shown in the dashboard.
