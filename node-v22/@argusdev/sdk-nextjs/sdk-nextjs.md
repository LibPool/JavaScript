# @argusdev/sdk-nextjs

> 标签: argus, error-tracking, monitoring, next, nextjs, sdk

## 简介

Argus SDK for Next.js — client components plus server-side capture via instrumentation.ts onRequestError, with source context (the crashing code lines) on the Node runtime.
