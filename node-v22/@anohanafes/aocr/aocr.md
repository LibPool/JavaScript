# @anohanafes/aocr

> 标签: chinese-ocr, frontend-ocr, image-recognition, ocr, offline-ocr, onnx, paddleocr, pdf, pp-ocr, rapidocr, react, text-recognition, vue

## 简介

轻量级离线 OCR 识别库，基于 PP-OCRv4/v5 ONNX 模型，支持 PDF 和图片识别，可无缝集成到 Vue、React 等前端框架
