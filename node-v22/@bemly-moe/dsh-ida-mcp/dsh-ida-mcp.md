# @bemly-moe/dsh-ida-mcp

> 标签: JavaScript

## 简介

DSH configuration-only bundle: connects the official Hex-Rays IDA MCP server over stdio (`uvx ida-mcp stdio --agent=dsh`, IDA 9.4+ with idalib).
