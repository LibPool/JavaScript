# @parsebounce/mcp-server

> 标签: ai, aws-ses, bounce-handling, claude, complaints, cursor, email, email-bounce, email-deliverability, llm, mailgun, mandrill, mcp, mcp-server, model-context-protocol, postmark, sendgrid, ses, sparkpost, suppression-list

## 简介

MCP server for ParseBounce — check email bounces, complaints, suppressions and deliverability stats for AWS SES, SendGrid, Mailgun, SparkPost, Postmark and Mandrill from Claude, Cursor, VS Code or any MCP client.
