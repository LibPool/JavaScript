# @nodatachat/folder-scan

> 标签: dlp, exposure, gitleaks, nodata, pii, privacy, scanner, secrets, security

## 简介

Deep local folder & document exposure scanner — hardcoded secrets (24 patterns), PII with checksum validation (Israeli ID / Luhn credit-card / IBAN), and vulnerable dependencies. Reads PDFs and Office files. Runs entirely on your machine and never uploads
