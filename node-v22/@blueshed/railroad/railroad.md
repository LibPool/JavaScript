# @blueshed/railroad

> 标签: bun, framework, jsx, router, signals, ui

## 简介

The smallest reactive layer for Bun realtime apps — signals, JSX, hash router. Built so an LLM can use it correctly without re-learning. Pair with @blueshed/delta for WebSocket document sync.
