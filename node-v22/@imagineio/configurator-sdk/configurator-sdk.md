# @imagineio/configurator-sdk

> 标签: JavaScript

## 简介

Configurator SDK — backend Configuration Engine client, state stores, shared 3D scene primitives, and pluggable placement (strategy + type). Drives every configurator (kitchen, sectional, …) from one self-contained surface.
