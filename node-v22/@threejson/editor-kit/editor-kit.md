# @threejson/editor-kit

> 标签: scene-editor, three.js, threejson

## 简介

Framework-agnostic, no-shell logic for building ThreeJSON scene editors: the editor command layer (registry + command specs), the AI scene-update flow (command/JSON round-trips), and the domain-edit session (drill-in, child-transform baselines, undo). No
