# @lukawi/toporealm-distribution

> 标签: JavaScript

## 简介

TopoRealm 1.0 distribution: module installer (npm pack --ignore-scripts + local path, ownership marker), host sync (claude-code plugin / pi extension+skills), 0.x migrate. Cold-path only: called by the cli, never touches a running daemon.
