# @kasidia/dsh-games

> 标签: JavaScript

## 简介

DSH 趣味编程插件：桌面宠物（DeepSeek 鲸鱼/自定义图案）+ 王冠成长（每 1M token 一顶青铜王冠，3 合 1 升级，魔法王冠带附魔特效）+ 多人房间（公开/邀请制 + 房间列表 + 自动回房）+ 可 Docker 部署的独立游戏服务器
