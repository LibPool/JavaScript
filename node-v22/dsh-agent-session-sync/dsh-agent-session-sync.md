# dsh-agent-session-sync

> 标签: claude-code, codex, cursor, deepseek-harness, dsh, dsh-plugin, kimi, session-import, session-transfer, two-way, workbuddy, zcode

## 简介

Two-way session import between DeepSeek Harness and local coding agents: read Codex, Claude Code, Cursor, ZCode, Kimi and WorkBuddy history into DSH, and import DSH sessions into those agents.
