# @kordar-lib/reducers

> 标签: JavaScript

## 简介

预置基于 Redux Toolkit 的通用状态管理包，默认挂载 user / app / layout 三个 slice，内置类型化的 React Hooks，以及常用的业务工具方法。支持与 redux-persist 组合和动态注入业务 reducer。
