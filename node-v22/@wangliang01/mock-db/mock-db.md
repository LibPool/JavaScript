# @wangliang01/mock-db

> 标签: database, db, mock, mock-db

## 简介

___ 由于前端同学很少直接操作数据库，在mock数据时，不是很方便，因此使用`fs.readFileSync`与`fs.writeFileSync`写了一个简易的mock-db，用于将数据存储在本地，作数据持久化，让数据更接近数据库操作。 > 这里只是作简单的mock，所以没有作性能上的考虑
