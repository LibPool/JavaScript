# @guitarserials/core

> 标签: charvel, dating, decoder, epiphone, esp, fender, gandl, gibson, gretsch, guitar, heritage, ibanez, jackson, ltd, martin, music-man, prs, rickenbacker, schecter, serial, serial-number, sire, squier, vintage

## 简介

Guitar serial-number decoder — pure TypeScript, zero runtime dependencies. Supports 18 brands across a century of production, month/day precision where encoded, and every PRS model line from 1985 through 2024.
