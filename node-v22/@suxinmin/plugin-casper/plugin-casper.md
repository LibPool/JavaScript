# @suxinmin/plugin-casper

> 标签: blockchain, casper, cryptocurrency, eliza, plugin, web3

## 简介

Casper blockchain plugin for Eliza AI agent framework — wallet, RPC reads (account/contract/token/NFT/staking/DeFi), network queries, and CEP-18/CEP-47/CEP-78/staking/DeFi write operations
