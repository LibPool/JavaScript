# @ldesign/dynamic-import

> 标签: dependency-management, dynamic-import, node, npm, package-manager, runtime-import, typescript

## 简介

一个功能强大的Node.js动态包管理工具，支持运行时动态导入npm包、自动依赖安装、批量导入、版本控制等功能
