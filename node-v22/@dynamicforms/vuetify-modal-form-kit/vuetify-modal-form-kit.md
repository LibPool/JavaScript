# @dynamicforms/vuetify-modal-form-kit

> 标签: dialog, dynamicforms, form-builder, form-layout, modal, velis, vue, vue3, vuetify

## 简介

Vue 3 + Vuetify 3 library providing a promise-based programmatic dialog API with a sequential dialog queue, a TypeScript fluent form layout builder (FormBuilder), and built-in keyboard shortcuts for dialog (Enter/Esc).
