# @metoncash/sdk-v1

> 标签: JavaScript

## 简介

SDK to build **Groth16 proofs** for the Meton `deposit` / `withdraw` / `transfer` circuits, plus the curve/commitment/encrypted-note helpers needed to construct inputs and manage wallet state off-chain.
