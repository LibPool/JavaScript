# @realitycollective/threejs-uiextensions

> 标签: docking, hand-menu, pointer, realitycollective, spatial-ui, threejs, typescript, ui, uikitml, vr, webxr, windowing, xr

## 简介

Plain three.js / WebXR adapter for the Reality Collective UI Extensions - hosts the engine-free @realitycollective/webxr-uiextensions windowing core (UIKitML panels, window chrome, follow mode, dock regions, hand menus) in any three.js WebXR scene, driven
