# @promus/gateway

> 标签: agent, ai, arbitrum, daemon, gateway, promus, sandbox, tee

## 简介

Promus gateway daemon: long-running brain runtime, listeners, tool registry, memory sync. Runs locally (laptop) or remotely (Arbitrum Sandbox TDX TEE).
