# @slates-integrations/smartsheet

> 标签: JavaScript

## 简介

Create, read, update, and delete sheets, rows, columns, and cells in a spreadsheet-like work management platform. Organize work into workspaces and folders with granular sharing permissions. Manage attachments, discussions, and comments on sheets and rows
