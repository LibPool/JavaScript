# @slates-integrations/evernote

> 标签: JavaScript

## 简介

Create, read, update, and trash notes in Evernote. Manage note content written in ENML markup, attach resources when creating notes, download resource file contents through Slate attachments, organize notes with notebooks and tags, search by Evernote sear
