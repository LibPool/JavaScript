# @slates-integrations/short-menu

> 标签: JavaScript

## 简介

Create, update, and delete branded short links with custom domains or the default shm.to domain. Assign tags to organize links and specify custom slugs or let the system generate random ones. Created and updated links include their identifiers and any cli
