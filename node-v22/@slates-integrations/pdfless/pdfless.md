# @slates-integrations/pdfless

> 标签: JavaScript

## 简介

Discover workspace templates, inspect the workspace connected to your API key, and generate downloadable PDF documents with dynamic JSON data. Templates support variable interpolation, conditionals, array iteration, barcodes, metadata, and bookmarks. PDF
