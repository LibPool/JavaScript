# @slates-integrations/updownio

> 标签: JavaScript

## 简介

Monitor website and service uptime by creating and managing HTTP, HTTPS, ICMP, TCP, and pulse checks. Configure check frequency, APDEX thresholds, custom HTTP headers, string matching, and monitoring locations. Retrieve downtime history with error details
