# @slates-integrations/metorial-admin

> 标签: JavaScript

## 简介

Metorial Admin exposes a controlled dynamic wrapper around Metorial dashboard instance API endpoints. It lists callable endpoints from Metorial introspection, lists instances available to the authenticated actor, and calls validated dashboard instance end
