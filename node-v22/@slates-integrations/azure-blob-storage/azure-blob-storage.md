# @slates-integrations/azure-blob-storage

> 标签: JavaScript

## 简介

Upload, download, copy, and delete blobs (block, append, page) in Azure cloud storage. Create and manage containers, set blob metadata and properties, and configure access tiers (Hot, Cool, Cold, Archive). Manage blob snapshots and versioning for point-in
