# @slates-integrations/digicert

> 标签: JavaScript

## 简介

Manage certificate orders in DigiCert CertCentral: discover products, order and reissue certificates, check issuance and validation status, download certificate files, cancel pending orders, and request revocation. List and manage domains and organization
