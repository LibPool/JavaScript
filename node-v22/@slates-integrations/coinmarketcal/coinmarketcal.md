# @slates-integrations/coinmarketcal

> 标签: JavaScript

## 简介

Search the CoinMarketCal V2 cryptocurrency event catalog by coin, date range, category, keyword, or impact. Retrieve event details, discover canonical coin and category identifiers, reconcile cancelled events, and inspect API usage.
