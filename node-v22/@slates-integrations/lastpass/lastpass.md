# @slates-integrations/lastpass

> 标签: JavaScript

## 简介

Manage administrative user metadata, group memberships, shared-folder permissions and audit reports through the LastPass Enterprise API. This integration uses a company ID and Enterprise provisioning hash. It does not read vault contents, passwords, share
