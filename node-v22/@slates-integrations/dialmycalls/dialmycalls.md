# @slates-integrations/dialmycalls

> 标签: JavaScript

## 简介

Send voice and text broadcasts, with optional email notifications. Manage contacts, groups, recordings, caller IDs, and access accounts. Inspect broadcast delivery statuses, incoming texts, keywords, shortcodes, vanity numbers, and do-not-contact entries.
