# @slates-integrations/leadfeeder

> 标签: JavaScript

## 简介

Access B2B website visitor leads and tracked website accounts using existing Leadfeeder legacy API credentials. Retrieve company details, visit routes, traffic sources, custom lead feed criteria, website tracking scripts, and downloadable JSON lead export
