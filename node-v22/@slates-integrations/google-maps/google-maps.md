# @slates-integrations/google-maps

> 标签: JavaScript

## 简介

Access Google Maps Platform geospatial services through tools for geocoding, address validation, Places search and details, Places Autocomplete (New), place-photo downloads, directions and route matrices, elevation, time zones, air quality, road snapping,
