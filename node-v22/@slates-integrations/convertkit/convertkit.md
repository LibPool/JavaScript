# @slates-integrations/convertkit

> 标签: JavaScript

## 简介

Manage Kit email marketing data for creator-focused newsletters, forms, sequences, broadcasts, purchases, posts, and reusable snippets. The integration uses Kit API V4 and supports OAuth 2.0 plus V4 API key authentication where the upstream API allows it.
