# @slates-integrations/screenshotone

> 标签: JavaScript

## 简介

Capture website screenshots, render HTML/Markdown to images or PDFs, and extract page metadata. Supports full-page and element-level screenshot capture in multiple formats (PNG, JPEG, WebP, GIF, PDF, and more). Emulate devices and viewports, block ads/coo
