# @qcoderx/sieve

> 标签: agent, claude, claude-code, extraction, mcp, web-scraping, webfetch

## 简介

Browser-grade page reading for AI agents. Reads pages a plain fetch returns empty, and says so when a read fails instead of letting an agent invent content.
