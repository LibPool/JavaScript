# @grupodiariodaregiao/bunstone

> 标签: JavaScript

## 简介

A decorator-based framework for [Bun](https://bun.sh) — the power of NestJS without the complexity. Bunstone is **Bun-native**: HTTP runs directly on `Bun.serve`, SQL on `Bun.SQL`, scheduling on `Bun.cron`. No Elysia, no Express.
