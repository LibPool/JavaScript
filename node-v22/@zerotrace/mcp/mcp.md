# @zerotrace/mcp

> 标签: agents, mcp, model-context-protocol, privacy, robinhood-chain, zero-knowledge, zerotrace

## 简介

MCP server for ZeroTrace: lets AI agents hold, send, sell and get paid in ZERO privately on Robinhood Chain, signing with their own key.
