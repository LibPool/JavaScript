# @daviduo/liquid-glass-web

> 标签: backdrop-filter, composable, directive, feDisplacementMap, frosted-glass, glassmorphism, liquid-glass, refraction, shader, telegram, ui, vue, vue3

## 简介

Liquid glass (real refraction, not blur) for the web — a Vue 3 composable/directive port of Telegram Android's blur3 shader, driven by an SVG feDisplacementMap on backdrop-filter.
