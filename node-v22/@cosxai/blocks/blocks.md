# @cosxai/blocks

> 标签: JavaScript

## 简介

Block-based content renderer with data-driven inline styles. BlockRenderer emits self-contained inline style — no external CSS bundle required. Cascade per sub-part: block.style (root only) > docStyle[type][subKey] > INTERNAL_DEFAULTS[type][subKey]. v0.7.
