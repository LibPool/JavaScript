# @mindees/router

> 标签: cross-platform, expo-router-alternative, react-native-alternative, router, search-params, signals, standard-schema, type-safe-routing, typed-router, typescript

## 简介

Quantum — the typed, signals-native router for MindeesNative: codegen-free typed path params, Standard Schema validated search params, and selector-isolated reactive route state.
