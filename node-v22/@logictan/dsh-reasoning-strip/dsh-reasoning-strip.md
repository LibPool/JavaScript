# @logictan/dsh-reasoning-strip

> 标签: chain-of-thought, context, deepseek-harness, dsh, plugin, reasoning, replay

## 简介

Drops replayed reasoning (chain-of-thought) blocks from assistant history at the adapter boundary, for every provider. Reasoning stays visible in the transcript; only what is sent back upstream changes.
