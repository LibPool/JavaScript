# @neokapi/kapi-format

> 标签: JavaScript

## 简介

Canonical TypeScript schema for the Kapi Bundle Format (KBF). Block/Run content model, reference Level-1 preview renderer, target validator, annotation overlay resolver. Mirrors core/kbf in Go byte-for-byte against shared golden fixtures.
