# linepay-v4

> 标签: line, line-pay, linepay, online-api-v4, payment, sdk, taiwan, thailand

## 简介

Zero-dependency TypeScript SDK for the LINE Pay Online API v4 — correct signing, lossless 19-digit transaction IDs, unknown-outcome aware errors.
