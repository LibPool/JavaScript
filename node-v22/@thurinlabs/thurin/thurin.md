# @thurinlabs/thurin

> 标签: JavaScript

## 简介

Thurin from a terminal: look up, attest, update, and revoke on-chain PGP identities. Never a wallet; never holds a PGP secret.

- 源码仓库：git+https://github.com/thurinlabs/thurin-cli.git
