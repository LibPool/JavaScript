# @viseed/theme-blog

> 标签: JavaScript

## 简介

Blog theme for [Viseed CMS](https://viseed.github.io/cms). Provides Eta templates, a settings schema, and static assets for a blog-style frontend. Register via the `blogTheme()` factory.
