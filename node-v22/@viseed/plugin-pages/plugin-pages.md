# @viseed/plugin-pages

> 标签: JavaScript

## 简介

Standalone pages plugin for [Viseed CMS](https://viseed.github.io/cms). Adds a pages table, CRUD REST routes, theme data injection via the `theme:beforeRender` hook, and an admin view (PagesView).
