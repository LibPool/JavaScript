# @discordkit/tauri

> 标签: discord, kkrpc, rich-presence, sidecar, social-sdk, tauri

## 简介

Tauri adapter for @discordkit/native — run the Discord Social SDK in a Node sidecar and reach it from the webview over a typed kkrpc bridge
