# @ir-kit/create-k6

> 标签: k6, load-testing, openapi, scaffold, wizard

## 简介

Wizard scaffolder for the @ir-kit/k6 stack. Run `npm create @ir-kit/k6` to generate a typed client from your OpenAPI spec and a starter loadtest.ts in one shot.
