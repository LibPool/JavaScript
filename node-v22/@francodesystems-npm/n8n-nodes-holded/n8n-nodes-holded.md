# @francodesystems-npm/n8n-nodes-holded

> 标签: accounting, erp, holded, invoicing, n8n, n8n-community-node-package, spain, verifactu

## 简介

n8n community node for Holded — the Spanish ERP / accounting platform. Full coverage of the Holded API v2 (43 resources, 327 operations) plus a webhook trigger.
