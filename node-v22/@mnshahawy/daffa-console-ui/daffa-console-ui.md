# @mnshahawy/daffa-console-ui

> 标签: JavaScript

## 简介

Vue 3 + Tailwind v4 component kit for Daffa-family operations consoles: status vocabulary, action grammar, tokens, and the primitives (buttons, selects, dialogs, toasts, confirm) extracted from Daffa's web console.
