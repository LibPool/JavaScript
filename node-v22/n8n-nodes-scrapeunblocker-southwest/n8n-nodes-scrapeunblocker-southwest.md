# n8n-nodes-scrapeunblocker-southwest

> 标签: airfare, apify, flights, n8n, n8n-community-node-package, scrapeunblocker, southwest, southwest-airlines

## 简介

n8n community node for the Southwest Airlines Flight Fares Scraper Apify Actor by ScrapeUnblocker: every Southwest flight on a route with times, stops and each fare product in dollars or Rapid Rewards points as JSON
