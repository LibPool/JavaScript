# @mpointer/url-guard

> 标签: allowlist, egress, fetch, metadata, private-ip, redirect, safe-fetch, security, ssrf, url

## 简介

SSRF guard for outbound URLs: canonical IP-literal parsing in every encoding, private/metadata/link-local classification, DNS-resolved validation, and a fetch that re-validates every redirect. Zero dependencies.
