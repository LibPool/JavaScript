# @teamix-evo/biz-ui

> 标签: JavaScript

## 简介

Business UI components — variant-aware (OpenTrek / Uni-manager / ...). Per ADR 0014: business components bind to variants (unlike @teamix-evo/ui which is variant-agnostic).
