# @anchalmehta/recipe-ui-components

> 标签: recipe, stencil, svelte, sveltekit, ui-components, web-components

## 简介

Reusable Web Component library (built with StencilJS) for the Recipe Finder & Meal Planner app: recipe cards, search bar, badges, meal-plan day slots and empty states.
