# @bitwild/rockets-adapter-firebase

> 标签: JavaScript

## 简介

Firebase Authentication adapter for Rockets — implements AuthAdapterInterface from @bitwild/rockets-core, validates Firebase ID tokens, maps to AuthorizedUser

- 源码仓库：git+https://github.com/btwld/rockets.git
