# @insumermodel/wdk-protocol-wallet-auth

> 标签: attestation, condition-based-access, insumerapi, protocol, trust, wallet-auth, wdk

## 简介

WDK protocol module for wallet auth — cryptographically signed, pre-transaction condition-based access. OAuth proves who you are; wallet auth proves what you hold. Powered by InsumerAPI.
