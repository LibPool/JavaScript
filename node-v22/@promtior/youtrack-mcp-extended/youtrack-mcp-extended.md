# @promtior/youtrack-mcp-extended

> 标签: ai-tools, anthropic, claude, issue-tracking, jetbrains, mcp, model-context-protocol, youtrack

## 简介

MCP server for YouTrack with 70 tools covering the full REST API — issues, comments, work items, attachments, agile boards, sprints, articles, projects, users, tags, links, and saved queries. ~3x the tool surface of the official JetBrains MCP server.
