# @appxiom/flutter-skills

> 标签: antigravity, appxiom, claude, coding-agent, copilot, cursor, dart, deobfuscate, flutter, skills, symbolication

## 简介

CLI to install Appxiom Flutter SDK integration skills (core, state & screens, network, goal tracking, activity trails, test issue, symbolication) into a project's coding agent skills directory.

## 官网

- 官网：https://www.appxiom.com
