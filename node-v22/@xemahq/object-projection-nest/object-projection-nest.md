# @xemahq/object-projection-nest

> 标签: JavaScript

## 简介

Shared NestJS building blocks for the XSI plane-1 object projection surface (`GET /describe-objects` + the `xema.object-registry.projection.published.v1` CloudEvent) that every XemaObject-owning service implements.
