# @xemahq/biome-test-harness

> 标签: JavaScript

## 简介

Static, infra-free conformance harness for biome authors: load a biome under test, then assert its manifest, agent parity, contribution manifests, skills, and workflows are valid — the same checks `xema biome validate` runs, exposed as reusable test asser
