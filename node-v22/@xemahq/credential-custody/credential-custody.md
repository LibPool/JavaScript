# @xemahq/credential-custody

> 标签: JavaScript

## 简介

Layer-1 custody abstraction for the Xema OS credential broker. One `CustodyBackend` interface (write/read/rotate/delete) with config-selectable adapters: `SecretsApiAdapter` (a zero-infra backend) and `OpenBaoAdapter` (KV-v2, the GA self-managed default).
