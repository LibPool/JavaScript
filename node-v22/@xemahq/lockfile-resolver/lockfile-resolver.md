# @xemahq/lockfile-resolver

> 标签: JavaScript

## 简介

Compositional Lockfile Resolver that turns an App's installed-biome list (plus optional agent/workflow/deliverable-spec/skill references) into a fully pinned `AppLockfile`. Pure leaf: no NestJS, no fetch, no semver npm dep — a pluggable `LockfileSource` i
