# @dagilleland/starlight-plugin-layouts

> 标签: astro, astro-component, astro-integration, layout, starlight, starlight-layouts, starlight-plugin

## 简介

Starlight plugin that bundles all four Starlight Layouts packages and registers their component overrides automatically — no override files to create.
