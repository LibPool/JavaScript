# sapling2d

> 标签: 2d, box2d, game-engine, godot, headless, minigame, physics, pixi, pixijs, planck, typescript, wechat, wechat-minigame

## 简介

Code-first, agent-friendly 2D game engine: PixiJS rendering, planck.js physics, Godot-style node tree. Runs in the browser and as a WeChat Mini Game, with deterministic headless testing.
