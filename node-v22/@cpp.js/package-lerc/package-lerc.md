# @cpp.js/package-lerc

> 标签: cpp.js-package, lerc, libLerc, raster-compression, react-native, webassembly

## 简介

This package provides the LERC (Limited Error Raster Compression) library compiled with Cpp.js, enabling seamless usage of LERC raster compression in JavaScript, WebAssembly and React Native projects.
