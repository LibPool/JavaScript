# @cpp.js/typescript-config

> 标签: cpp.js, rust, tsconfig, typescript

## 简介

Shared TypeScript configuration wiring the editor types cpp.js generates under .cppjs/ (C++ .h and Rust .rs imports, cargo: crates) - extend it once and never manage the wiring by hand.
