# @iddp/vefk-app-kit

> 标签: JavaScript

## 简介

Geteiltes Backend & geteilte Logik der VEFK-Tools-Suite: Storage-Adapter, Multi-Tenant-Middleware, Auth (Passwort+2FA / Magic-Code / Passwort ohne Mandant), Mail, Upload, Export.
