# @plune-ai/lex-bot

> 标签: ai-agent, anthropic, langfuse, langgraph, playwright, qa, test-generation, testing, ui-testing

## 简介

Autonomous QA agent that explores web pages and generates UI tests (@playwright/test) on LangGraph + Claude/OpenRouter, with self-improvement via Langfuse.
