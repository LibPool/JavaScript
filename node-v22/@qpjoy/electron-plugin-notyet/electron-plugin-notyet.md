# @qpjoy/electron-plugin-notyet

> 标签: ball, chat, electron, notyet, overlay, plugin, qpjoy

## 简介

NotYet floating consultation ball for QPJoy marketplace. Renders a 古风 + 科技 3D-style action ball on every host window with one-tap access to https://www.notyet.chat and a cover-not-replace navigation model (return preserves underlying app state).
