# @tiuxo/opencode-git-trailer

> 标签: attribution, commit, git, git-trailer, opencode, opencode-plugin, provenance

## 简介

Adds a configurable git commit trailer (e.g. Assisted-by: <model>) to commits opencode makes, without touching your own git usage.
