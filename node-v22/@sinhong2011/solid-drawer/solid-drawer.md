# @sinhong2011/solid-drawer

> 标签: bottom-sheet, corvu, drawer, sheet, snap-points, solid, solid-js, solidjs, vaul

## 简介

A drawer for Solid 2. Snap points, flings, scroll arbitration, nested drawers, a handle that cycles, the page scaling back behind it, and state you can read.
