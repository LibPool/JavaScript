# @sixtynine-digital/cms-tracking

> 标签: analytics, clickhouse, cms, events, first-party, nextjs, server-side, sixtynine, tracking

## 简介

Server-side, first-party event tracking client for SIXTYNINE CMS (Pulse analytics). Send page views and custom events from a Next.js (or any JS) backend — the delivery key never reaches the browser.
