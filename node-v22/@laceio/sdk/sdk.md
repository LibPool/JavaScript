# @laceio/sdk

> 标签: JavaScript

## 简介

A headless TypeScript SDK for self-custody wallets, reactive state observables, transaction building, signing and submission, and wallet modules on one engine. Build wallets with recovery phrases, user-controlled key material or passkeys. In a browser app
