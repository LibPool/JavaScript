# @pipe0/elements-react

> 标签: JavaScript

## 简介

Prebuilt React components for rendering [pipe0](https://pipe0.com) pipe and search configuration forms. Drop a `pipeId` or `searchId` in and get a fully-typed, validated form with the right inputs, autocomplete, and connection pickers.
