# @creaditor/cdtr-course-nav

> 标签: course, creaditor, curriculum, drop-in, hebrew, lms, navigation, progress, rtl, web-components

## 简介

Embeddable <cdtr-course-nav> and <cdtr-lesson-footer> web components. Draws the curriculum a course creator built, steps a learner through it, and reports which lesson was picked and which was finished. No networking, no storage, no routing: the host owns
