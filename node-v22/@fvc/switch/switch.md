# @fvc/switch

> 标签: antd, design-system, fe-vis-core, fvc, react, react-component, switch, ui

## 简介

`@fvc/switch` provides the FE-VIS styled toggle switch on top of Ant Design. It keeps the Ant Design `Switch` API familiar while restyling it to the AVIS UI kit design ([Figma](https://www.figma.com/design/mIoVgiLS8kZgKfqfUoL9Pa/AVIS-UI-kit-new?node-id=26
