# @amerilux/netsuite-api

> 标签: JavaScript

## 简介

The API layer for a NetSuite single-page app: endpoints served by a Restlet or a Suitelet, a typed browser client, SuiteScript module stubs for tests, and a generator that writes the client module from the controllers.
