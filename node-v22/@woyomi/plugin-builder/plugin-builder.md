# @woyomi/plugin-builder

> 标签: anime, bundle, cli, esbuild, extension, manga, plugin, woyomi

## 简介

CLI and library that bundles woyomi media plugins into self-contained IIFE bundles with manifests and sha256, plus a Mihon-style repo index generator
