# @gixcopilot/testing

> 标签: agent, ai, copilot, fixtures, llm, mocks, sdk, testing, typescript, vitest

## 简介

Deterministic testing SDK for AI Copilot applications - request-aware test models, tool mocks and assertions, security/RAG/memory/approval fixtures, agent and workflow simulation, a one-call copilot harness, and side-effect-free replay of recorded runs.
