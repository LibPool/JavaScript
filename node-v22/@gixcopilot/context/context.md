# @gixcopilot/context

> 标签: agent, ai, context, copilot, llm, prompt, sdk, token-budget, typescript

## 简介

Framework-independent application context and shared state engine for the AI Copilot SDK: registration, scopes, priority, serialization, token budgeting, and resolution.
