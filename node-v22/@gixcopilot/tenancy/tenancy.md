# @gixcopilot/tenancy

> 标签: agent, ai, copilot, isolation, llm, multi-tenant, sdk, tenancy, typescript

## 简介

Multi-tenancy primitives: authenticated runtime scope (tenant/project/environment), the project/environment model, tenant-scoped conversation storage ports and a server run recorder.
