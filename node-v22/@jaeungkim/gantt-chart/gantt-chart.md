# @jaeungkim/gantt-chart

> 标签: a11y, accessibility, chart, gantt, gantt-chart, headless, project-management, react, timeline, treegrid, virtualized

## 简介

An open-source React Gantt chart for interactive project planning. Drag tasks, connect dependencies, and organize nested timelines with working calendars, keyboard editing, virtualization, and light and dark themes.
