# @tiledev/react-native-performant-image

> 标签: coil, drop-in, fabric, image, image-cache, netinfo, new-architecture, nuke, offline, react-native, react-native-web, retry, turbo-image, web

## 简介

Drop-in replacement for React Native's Image on iOS, Android and web: Nuke/Coil loading via react-native-turbo-image, with automatic retries (backoff while online, staggered on reconnect) and zero cost for images that load.
