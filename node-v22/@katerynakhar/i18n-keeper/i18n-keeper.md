# @katerynakhar/i18n-keeper

> 标签: gettext, i18n, l10n, laravel, lint, locales, mcp, translation

## 简介

Deterministic i18n linter for JSON, Laravel PHP, gettext and YAML locale files, as a CLI and an MCP server.
