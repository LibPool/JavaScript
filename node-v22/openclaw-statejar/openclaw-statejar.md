# openclaw-statejar

> 标签: memory, openclaw, openclaw-plugin, statejar

## 简介

StateJar memory for OpenClaw: a memory-slot plugin with auto-recall, batched auto-capture with secrets removed, memory_search / memory_get, and `openclaw statejar init`.

- 官网：https://statejar.com/docs/openclaw
- 源码仓库：git+https://github.com/KING-OF-FLAME/statejar-integrations.git
