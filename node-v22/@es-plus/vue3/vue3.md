# @es-plus/vue3

> 标签: ai-friendly, component-library, config-driven, crud, dialog, element-plus, enterprise, es-plus, form, json-schema, table, typescript, vue, vue3

## 简介

es-plus for Vue 3 + Element Plus: configuration-driven enterprise components, sharing the same JSON config schema as @es-plus/vue2 (Vue 2 + Element UI). Renamed from es-plus-ui starting v1.4.0.
