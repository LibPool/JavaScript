# @godpowers/data-pack

> 标签: analytics, dashboard, data, etl, feature-store, godpowers, godpowers-extension, ml

## 简介

Data engineering specialists for ETL pipelines, ML feature stores, and dashboards. Refuses common data anti-patterns: stale features in prod, dashboards without SLOs, ETL without idempotency.
