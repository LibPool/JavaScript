# @eldrajs/theme-core

> 标签: cms, eldra, headless, page-builder, preview, theme

## 简介

Framework-free core of the Eldra theme SDK: the Studio preview bridge, stega encoding, the overlay runtime, layout CSS, rich-text positions, design tokens and image framing.
