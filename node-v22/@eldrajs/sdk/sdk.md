# @eldrajs/sdk

> 标签: cms, commerce, eldra, headless, sdk, storefront

## 简介

Framework-free client for the Eldra Web Studio public storefront API: CMS, catalog, cart, checkout handoff, orders, inventory. Types generated from your gateway's OpenAPI document and CMS schemas at build time.
