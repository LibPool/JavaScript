# @aivin-labs/sdk

> 标签: agentic, ai, aivin, automation, grpc, plugin, sdk, vector-search

## 简介

Aivin Plugin SDK - gRPC client/server for building plugins that run inside the Aivin platform (agentic engine, vector search, workspace, tasks, and more)
