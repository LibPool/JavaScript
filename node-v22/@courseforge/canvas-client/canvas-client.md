# @courseforge/canvas-client

> 标签: api-client, canvas-api, canvas-lms, education, instructure, lms

## 简介

Standalone Canvas LMS REST client — token or cookie-session auth, Link-header pagination, rate-limit retry, 3-step file uploads, and the content_migrations .imscc import dance
