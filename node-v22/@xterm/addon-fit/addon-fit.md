# @xterm/addon-fit

> 标签: terminal, xterm, xterm.js

## 简介

An addon for [xterm.js](https://github.com/xtermjs/xterm.js) that enables fitting the terminal's dimensions to a containing element. This addon requires xterm.js v4+.
