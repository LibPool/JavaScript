# @somnia-chain/accounts-sdk

> 标签: JavaScript

## 简介

Smart accounts on Somnia: derive an account's address offline, create it, manage its owners, sign through a chain of accounts, and read what controls it. The one gateway to the SomniaAccountFactory and the Safes it deploys.
