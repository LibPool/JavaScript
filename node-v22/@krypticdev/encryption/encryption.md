# @krypticdev/encryption

> 标签: aes-gcm, argon2, encryption, kryptic, sealed-box, secrets

## 简介

The open-source Kryptic encryption engine for the browser. AES-256-GCM envelopes, P-256 sealed boxes, Argon2id key derivation. Byte-compatible with the .NET and Go implementations.
