# @herrywang1998/elpis

> 标签: JavaScript

## 简介

服务端使用nodejs和koa,实现了api路由分发,其中包括api参数校验，错误捕获，日志生成等技术 前端页面使用vue和element-plus搭建了一套完整的动态项目系统, 通过一份jsonschema配置, 可完整输出一套成型的管理系统 主要技术栈: nodejs + koa + vue + webpack
