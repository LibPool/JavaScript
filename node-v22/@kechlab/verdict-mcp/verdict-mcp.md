# @kechlab/verdict-mcp

> 标签: agent-security, l402, lightning, mcp, prompt-injection

## 简介

MCP server: an AI agent asks Verdict whether an action is safe before it runs it (prompt injection, shell command, MCP tool install, action firewall). Free samples with no setup, then pay per call in sats over L402.
