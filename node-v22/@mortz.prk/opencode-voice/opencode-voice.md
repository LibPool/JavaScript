# @mortz.prk/opencode-voice

> 标签: opencode, piper, plugin, speech-to-text, stt, text-to-speech, tts, voice, whisper

## 简介

Speech-to-text and text-to-speech for OpenCode (V2). Record voice prompts with whisper-cpp or an STT API, hear responses via Piper TTS, with LLM normalization through any OpenAI-compatible endpoint.
