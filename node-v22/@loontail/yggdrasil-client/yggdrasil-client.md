# @loontail/yggdrasil-client

> 标签: JavaScript

## 简介

TypeScript launcher client for Loontail Minecraft Auth: Yggdrasil protocol calls (authenticate/refresh/validate/profile) plus skin/cape upload, delete, and lookup. Ships the authlib-injector jar and a -javaagent argument builder.
