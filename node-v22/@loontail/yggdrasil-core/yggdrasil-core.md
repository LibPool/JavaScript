# @loontail/yggdrasil-core

> 标签: JavaScript

## 简介

Shared types, Zod schemas, UUID helpers, PNG byte-level validation and texturesPayload codec used by Loontail Minecraft Auth on both server (Strapi plugin) and client (launcher).
