# dsh-rustvy

> 标签: api-key, api-keys, credentials, deepseek, deepseek-harness, dsh, dsh-plugin, dsh-rustvy, harness-plugin, key-ring, llm-pi-ai, model-icons, model-list, model-picker, model-sync, rustvy, ui, vendor-logo, web-gui

## 简介

Rustvy for DeepSeek Harness: vendor marks in the model picker, a model list kept in step with what the provider actually serves, and a ring of API keys that lets each chat send its requests with a key of its own — the host half mirrors the catalog and log
