# @funpm/paystack-rn-checkout-server

> 标签: africa, checkout, expo, nigeria, payment-gateway, payments, paystack, react-native, webview

## 简介

A robust Paystack payment SDK for React Native & Expo. Backend-initialized, WebView-powered checkout with proper lifecycle management — success handling, redirect control, polling, and deep link support.
