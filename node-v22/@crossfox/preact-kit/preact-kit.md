# @crossfox/preact-kit

> 标签: crossfox, cursor-pagination, hooks, infinite-scroll, preact, pwa, react-query, realtime, url-filters, wouter

## 简介

Preact + wouter + react-query frontend toolkit: URL-synced filters, infinite scroll, throttled refetch, cursor feed (realtime-ready), PL-flavoured formatters, PWA update watcher.
