# @stone-js/alibaba-fc-adapter

> 标签: Stone.js, adapter, alibaba, aliyun, china, faas, fc, function-compute, mns, oss, serverless, timer

## 简介

General-purpose Alibaba Cloud Function Compute adapter for Stone.js, run any app on event-driven FC triggers, beyond HTTP. Supports OSS, MNS, Timer and EventBridge.
