# @jentrix/plugin-claude

> 标签: agents, claude-code, jentrix, plugin, sessions

## 简介

The official Jentrix plugin for Claude Code: connected-session commands and trusted lifecycle hooks, materialized by the Jentrix CLI (jentrix plugin install claude).
