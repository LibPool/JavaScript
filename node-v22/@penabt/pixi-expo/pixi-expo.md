# @penabt/pixi-expo

> 标签: 2d, animation, canvas, expo, expo-gl, game, graphics, pena, pixi, pixi.js, pixijs, react-native, renderer, webgl

## 简介

PixiJS v8 adapter for React Native Expo. Enables hardware-accelerated 2D graphics using expo-gl WebGL context.
