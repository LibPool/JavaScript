# @bitbysoft/document-kit-export-pdf

> 标签: JavaScript

## 简介

PDF export plugin for BitBySoft DocumentKit — generates a PDF from a session's processed pages via a replaceable PdfExportProvider. Depends on the enhance plugin at registration time, not at compile time.
