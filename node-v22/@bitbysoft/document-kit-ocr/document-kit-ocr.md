# @bitbysoft/document-kit-ocr

> 标签: JavaScript

## 简介

OCR plugin for BitBySoft DocumentKit — extracts text from a session's processed pages via a replaceable OcrProvider. Depends on the enhance plugin at registration time, not at compile time.
