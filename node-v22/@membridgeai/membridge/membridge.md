# @membridgeai/membridge

> 标签: agents, ai, claude-code, codex, context, developer-tools, memory, sync

## 简介

Shared memory across your AI coding tools. A tiny background daemon that watches Claude Code, Codex and any other agent's session logs, distills a brief per-project memory, and syncs it into the context files every tool reads (CLAUDE.md, AGENTS.md, ...).
