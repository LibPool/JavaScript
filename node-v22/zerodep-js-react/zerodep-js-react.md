# zerodep-js-react

> 标签: JavaScript

## 简介

React 页面宿主。只在客户端 effect 中建立独立 zerodep-js 页面，支持输入更新、入口更换和 StrictMode 清理；服务器输出空容器。React 与 zerodep-js 均作为 peer，由消费项目提供。
