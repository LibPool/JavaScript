# @guided-context-ledger/connector

> 标签: JavaScript

## 简介

Local reference MCP connector for the Guided Context Ledger — runs the guided loop (orient, events, claims/leases, handoffs, commit, readback) over a plain-files workspace. Detection, not enforcement.
