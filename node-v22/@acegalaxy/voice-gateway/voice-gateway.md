# @acegalaxy/voice-gateway

> 标签: cost-cap, openai, rate-limit, stt, telegram, voice, whisper

## 简介

OpenAI Whisper wrapper with cost cap, rate limit, default-deny authz, queue, and audit log. Production-ready STT for Telegram bots.
