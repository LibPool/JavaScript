# @spzhongwin/skill-logger-plugin

> 标签: JavaScript

## 简介

Skill Logger 是 Aishuo 面向 OpenClaw Gateway 的运行期插件，用于记录 Skill 和工具调用、同步平台配置，并提供用户自建 Skill 的管理工具。
