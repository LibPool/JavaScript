# @cleepi/board

> 标签: agent, cleepi, cleevio, kanban, pi, sdd

## 简介

Autonomous SDD board for any repo. Triages tickets, drafts specs, runs work in isolated worktrees, opens PRs. Run `npx @cleepi/board` in your project.
