# @open-wysiwyg-editor/react

> 标签: a11y, accessibility, arabic, editor, nextjs, react, rich-text-editor, rtl, wysiwyg

## 简介

React and Next.js component for open-wysiwyg-editor: an accessible (WCAG 2.2 AA), RTL-first, CSP-safe rich text editor. <RichTextEditor value onChange /> and useEditor().
