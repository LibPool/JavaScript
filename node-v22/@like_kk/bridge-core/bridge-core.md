# @like_kk/bridge-core

> 标签: JavaScript

## 简介

bridge-core 项目是一个用于在不同窗口或 iframe 之间进行安全消息通信的 TypeScript 库。它提供了一个 BridgeCore 类，用于管理消息的发送、接收和处理，同时支持消息的安全验证和签名验证。
