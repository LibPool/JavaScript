# @french-castle/skill-scanner

> 标签: agent-skills, claude-code, codex, jev, npx-skills, opencode, pi, pi-package, prompt-injection, sarif, scanner, security, skills, supply-chain, typesafe

## 简介

Scan Agent Skills for prompt injection, hidden instructions, exfiltration, and remote code before Claude Code, Codex, OpenCode, Pi, or npx skills installs them. Standalone and offline by default; TypeSafe's jev is an optional second opinion.
