# @cornerstonejs/codec-little-endian

> 标签: JavaScript

## 简介

Pure JavaScript decoder for DICOM Little Endian transfer syntaxes (`1.2.840.10008.1.2`, `1.2.840.10008.1.2.1`, `1.2.840.10008.1.2.1.99`).
