# @rulecad/pcb

> 标签: autorouter, circuit-board, gerber, jlcpcb, keyboard, kicad, pcb, tscircuit

## 简介

Circuit boards from rules: parts from rule sets or any standard footprint, quarter-turn rotation, nets and autorouting; keyboards with every matrix track drawn by rule. Gerbers, KiCad files and a JLCPCB BOM. Circuit JSON written directly: no React.
