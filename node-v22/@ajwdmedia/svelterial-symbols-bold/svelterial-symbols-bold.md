# @ajwdmedia/svelterial-symbols-bold

> 标签: JavaScript

## 简介

Enables easy icon usage from the Material set within Svelte 5.   Uses [@material-symbols/svg-xxx](https://npmjs.com/package/@material-symbols/svg-400) as a base, extracts the svg paths, and exposes them over a Threlte-like API.
