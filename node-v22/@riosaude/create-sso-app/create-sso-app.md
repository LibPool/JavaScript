# @riosaude/create-sso-app

> 标签: nestjs, oidc, riosaude, scaffold, sso

## 简介

Gera uma aplicação NestJS integrada ao SSO RioSaúde: login OIDC+PKCE, sessão, logout único, webhooks e RBAC por rota prontos
