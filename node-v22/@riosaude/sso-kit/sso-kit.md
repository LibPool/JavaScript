# @riosaude/sso-kit

> 标签: codemod, migration, nestjs, oidc, riosaude, sso

## 简介

Migra aplicações existentes para o SSO RioSaúde: gera a integração da API NestJS e do front (Vite + React ou Next.js), inclusive webhook, verifica cada etapa de verdade e acompanha a evolução numa página
