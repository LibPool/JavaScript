# @glitchlab/vue-video-player

> 标签: adaptive, desktop, device-toggle, hls, hls.js, hover-play, m3u8, mobile, nuxt, nuxt3, overlay, player, responsive, streaming, typescript, video, video-player, vue, vue-player, vue3

## 简介

Vue 3 / Nuxt 3 video player with HLS support, device-mode toggle, hover-to-play, and zero global CSS side-effects.
