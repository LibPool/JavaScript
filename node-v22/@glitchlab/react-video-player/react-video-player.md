# @glitchlab/react-video-player

> 标签: adaptive, desktop, device-toggle, hls, hls-video-player, hls.js, hover-play, m3u8, mobile, next-app-router, next-video-player, nextjs, overlay, player, react, react-player, react-video-player, responsive, streaming, typescript, use-client, video, video-player

## 简介

React video player with HLS support (hls.js), device-mode toggle, hover-to-play, and zero global CSS side-effects. Works with Next.js App Router and TypeScript.
