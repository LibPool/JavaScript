# @yanlinglabs/video-extract-mcp

> 标签: ai-agent, asr, download, downloader, frame-extraction, keyframe, keyframes, llm-tools, local-first, mcp, mcp-server, model-context-protocol, scene-detection, sense-voice, speech-recognition, tiktok, transcript, transcription, video, video-download, video-downloader, video-understanding, wechat-channels, whisper, youtube, yt-dlp

## 简介

Local-first MCP server for video: download any video from almost any URL, or turn it into a transcript and the handful of keyframes that matter. YouTube, TikTok, Instagram, X, Facebook, WeChat Channels, direct MP4/HLS. No cloud, no API keys.
