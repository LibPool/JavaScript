# @stackline/multiselect

> 标签: accessibility, ada-compliant, admin-ui, aria, body-overlay, combobox, custom-renderer, dialog, dropdown, headless, javascript, keyboard-navigation, listbox, modal, multiselect, object-data, renderless, search, select, skins, slots, stackline, state, ui, vanilla

## 简介

Framework-agnostic vanilla JavaScript multiselect dropdown with headless state APIs, skins, object data, body overlays, and accessibility-focused keyboard/ARIA tested behavior.
