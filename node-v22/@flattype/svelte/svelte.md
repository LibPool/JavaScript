# @flattype/svelte

> 标签: fetch, flattype, json, models, solid, solidjs, stores, streaming, svelte, svelte5

## 简介

Svelte stores (and Solid resources) for FlatType.js: fetch Flat Notation or JSON into typed models, with streaming rows.
