# @stardust-cms/iframe-adapter

> 标签: cms, frame-link, iframe, overlay, postMessage, react, visual-editor

## 简介

Typed, framework-agnostic protocol plus iframe/host adapters for building in-iframe visual editors, transported over frame-link.
