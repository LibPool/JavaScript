# semantic-mermaid

> 标签: agents, diagram, elk, flowchart, layout, mermaid, swimlanes

## 简介

Mermaid flowcharts laid out by what they mean: directives an agent writes in comments, a layout engine that reads them, and a CLI to check and render.
