# @krizaka/config

> 标签: dependency-cruiser, design-system, eslint-config, krizaka, prettier-config, ratchet, tanstack, tsconfig

## 简介

The shared configuration of every Krizaka JavaScript repository: ESLint flat configs (base, Next.js, the four UI rules, the three stack rules, no locale ternary), the dependency-cruiser boundary, tsconfig bases, Prettier, EditorConfig, and the krizaka-rat
