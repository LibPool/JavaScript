# @krizaka/realtime

> 标签: krizaka, listen-notify, postgresql, presence, pubsub, realtime, redis, server-sent-events, sse, valkey

## 简介

Realtime for Node apps behind one interface: a bus (publish / subscribe by channel) and presence (who is connected, by heartbeat and TTL), with memory, PostgreSQL LISTEN/NOTIFY and Redis / Valkey adapters, plus Server-Sent Events framing.
