# @x12i/memorix-client

> 标签: client, mcp, memorix, sdk, x12i

## 简介

Canonical typed HTTP client for Memorix — Explore, pipelines, Source checkpoints, raw Memory, invoke callbacks, and MCP agent helpers (memorix-nexum + MGC snippets).
