# @x12i/backups-agent

> 标签: agent, backup, cli, cloudflare, hybrid, incremental, mcp, model-context-protocol, mongodb, r2, restore, x12i

## 简介

x12i Backup Agent: MongoDB full/incremental backups to Cloudflare R2 or local disk, with named servers, playbooks, cold-storage copies, retention, restores, transfers to the @x12i hybrid stack and cost forecasts. Every capability exposed as SDK, CLI, HTTP
