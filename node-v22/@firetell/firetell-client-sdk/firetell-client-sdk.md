# @firetell/firetell-client-sdk

> 标签: firetell, sdk, sip, telephony, voip, webrtc, webrtc-signaling, websocket

## 简介

TypeScript/JavaScript SDK for Firetell WebRTC — make and receive audio/video calls via native per-call WebSocket signaling
