# @hiero-did-sdk/publisher-internal

> 标签: JavaScript

## 简介

This package provides the `Publisher` class, a core component of the Hiero DID SDK. It offers a standardized way to submit and execute transactions on the Hedera network, simplifying the process of interacting with the Hedera Consensus Service (HCS).
