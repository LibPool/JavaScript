# @optomatica/pi-auto-session-name

> 标签: naming, pi, pi-extension, pi-package, session

## 简介

Auto-names pi sessions with concise, human-readable titles so `pi --resume` shows real descriptions instead of raw first messages. Never overwrites manual names, refreshes as topics evolve, and backfills old unnamed sessions.
