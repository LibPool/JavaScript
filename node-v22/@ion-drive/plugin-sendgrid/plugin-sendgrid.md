# @ion-drive/plugin-sendgrid

> 标签: email, ion-drive, plugin, sendgrid

## 简介

Ion Drive plugin: SendGrid email provider — swaps the platform's EmailProvider for real outbound delivery via the SendGrid v3 API. Zero runtime dependencies.
