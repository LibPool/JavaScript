# @dui-toolkit/plugin-notify

> 标签: ansi, bell, cli, iterm, kitty, libnotify, notification, os-notification, osc, terminal, toast

## 简介

Cross-platform desktop notifications and inline TUI toasts for @bdocs/dui — auto-routes between OS spawn, OSC escape sequences, and box-rendered toasts depending on the host environment.
