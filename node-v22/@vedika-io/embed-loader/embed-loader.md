# @vedika-io/embed-loader

> 标签: chat, embed, iframe, mountWidget, postMessage, vedika, web-component, widget

## 简介

Embed the Vedika chat in any website: mountWidget with signed config and a server-minted token, plus a web component, frame page and host adapter that enforce an origin check.
