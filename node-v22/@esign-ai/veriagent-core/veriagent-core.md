# @esign-ai/veriagent-core

> 标签: JavaScript

## 简介

VeriAgent Core 是面向 Node.js 集成方的核心运行时 SDK，提供智能体身份安装、本地证书状态查询、标准签名对象生成、标准验签和审计上报能力。
