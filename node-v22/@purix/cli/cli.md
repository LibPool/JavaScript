# @purix/cli

> 标签: ai, cli, code-verification, governance, mcp, model-context-protocol, sandbox, typescript

## 简介

Governance-first AI coding agent CLI: classifies and verifies AI-driven code changes in a sandbox, against your test suite, before they land. Also runs as an MCP server for other coding agents.
