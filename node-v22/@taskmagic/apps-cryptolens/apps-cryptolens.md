# @taskmagic/apps-cryptolens

> 标签: JavaScript

## 简介

Cryptolens is a Software Licensing as a Service (SLaaS) platform. This piece lets you manage software licenses: create and block license keys, extend licenses, add customers, and react to Web API events.
