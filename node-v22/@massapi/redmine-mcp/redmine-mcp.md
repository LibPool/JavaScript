# @massapi/redmine-mcp

> 标签: JavaScript

## 简介

一个基于 Node.js 的 Redmine MCP 服务，使用 `stdio` 作为传输层，适合被支持 MCP 的桌面客户端、CLI 或编辑器直接拉起。

## 官网

- npm 页面：https://www.npmjs.com/package/@massapi/redmine-mcp

## 历史版本号

- 当前版本：1.0.4

- 1.0.4

## 获取地址

- npm 安装：`npm install @massapi/redmine-mcp`
- npm registry：https://registry.npmjs.org/@massapi/redmine-mcp
- Node 要求：>=20
