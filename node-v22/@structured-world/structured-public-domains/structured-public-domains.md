# @structured-world/structured-public-domains

> 标签: domain, etld, psl, public-suffix, registrable-domain, tld, trie, validation

## 简介

Compact Public Suffix List (PSL) as a native TypeScript package: embedded ~108KB binary trie, synchronous zero-dependency lookups, ESM + CommonJS. Checked daily against publicsuffix.org.
