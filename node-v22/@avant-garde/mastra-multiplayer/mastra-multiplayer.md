# @avant-garde/mastra-multiplayer

> 标签: agents, collaboration, human-in-the-loop, mastra, multiplayer, presence, sse

## 简介

Multiplayer primitives for Mastra agents: presence, multi-approver gates, and a shared-session event bus for many humans in one agent session.
