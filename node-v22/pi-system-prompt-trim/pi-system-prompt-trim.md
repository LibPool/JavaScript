# pi-system-prompt-trim

> 标签: context, docs, documentation, pi-extension, pi-package, pi-skill, prompt-tokens, skill, system-prompt, system-prompt-trim

## 简介

Trim pi's own `docs` section out of every request: its doc paths, topic index and reading rules move into an on-demand `pi-docs` skill, and the always-on section is blank. Nothing else in the prompt is touched
