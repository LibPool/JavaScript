# @physis/react-server-dom-esm

> 标签: react

## 简介

React Server Components bindings for DOM using ESM. This is intended to be integrated into meta-frameworks. It is not intended to be imported directly.

## 官网

- 官网：https://react.dev/
- 源码仓库：git+https://github.com/facebook/react.git
- npm 页面：https://www.npmjs.com/package/@physis/react-server-dom-esm
