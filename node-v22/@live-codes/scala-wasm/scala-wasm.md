# @live-codes/scala-wasm

> 标签: compiler, livecodes, playground, scala, scala3, scalajs, wasm, webassembly

## 简介

Client-side Scala 3 toolchain for LiveCodes: compile and run Scala in the browser via the Wasm-compiled Scala 3 compiler + Scala.js linker.
