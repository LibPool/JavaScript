# @jianghh/canvas-graffiti

> 标签: @jianghh, @jianghh/canvas-graffiti, canvas, canvas-graffiti

## 简介

canvas涂鸦库，支持手写、笔写、鼠标，选中元素，并且移动、删除等功能。集成撤销重做操作。
