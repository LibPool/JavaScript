# @josueavalosjim/panelware

> 标签: accessibility, components, css, design-system, design-tokens, radix-ui, react, skeuomorphic, theme

## 简介

An accessible component kit with a chrome-and-LCD skin. Radix UI does the interaction; this does the surface. Stacked inset bevels, Web 2.0 gloss, and a sprite-sheet segment readout. Skins are data-attribute swaps, not separate installs. No runtime depend
