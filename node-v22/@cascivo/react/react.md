# @cascivo/react

> 标签: cascivo, components, css, design-system, react, react-components, signals, ui

## 简介

Prebuilt cascivo design system components — use without copying source. @cascivo/themes installs with it; pair with @cascivo/charts (data-viz) and @cascivo/icons. Docs offline: npx @cascivo/docs
