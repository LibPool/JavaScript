# @cistern/core

> 标签: cistern, gallery, geometry, lathe, three, threejs, tsl, webgpu

## 简介

Core geometry toolkit for galleries in the round — CisternGeometry (profile-revolution BufferGeometry with sectional attributes) and TSL/WebGPU CisternMaterial
