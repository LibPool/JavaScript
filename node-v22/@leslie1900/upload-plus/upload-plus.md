# @leslie1900/upload-plus

> 标签: element-plus, upload, uploader, vue, vue3

## 简介

基于 Vue 3 和 Element Plus 的增强版上传组件，支持 file/photo 上传、保护文件、预览缩放旋转、下载模式等功能。
