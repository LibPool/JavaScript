> 标签: cancel, checkpoint, durable, expressions, flow, flow-engine, json-config, orchestration, pipeline, resume, retry, state-machine, steps, suspend, type-safe, typescript, workflow, workflow-engine, zero-dependencies

## 简介

Typed flow engine with JSON-serializable flows, safe string expressions, pause/cancel/suspend, checkpoints and restore. Works in the browser and on the backend.
