# @simplex2-sdk-util/keyboard

> 标签: keyboard, simplex2-sdk-util

## 简介

Keyboard 是一个浏览器端键盘事件监听工具，支持单键和组合键（如 Ctrl+A、Shift+Z）监听，自动处理修饰键，适用于快捷键、表单增强、游戏等场景。支持多实例并行，事件解绑和销毁，API 简单易用。
