# @properui/html

> 标签: accessibility, components, css, design-system, html, tailwindcss, ui, vanilla-js

## 简介

Proper UI without React: CSS component classes on the same semantic tokens, small dependency-free vanilla-JS behaviours, and copy-paste HTML snippets.
