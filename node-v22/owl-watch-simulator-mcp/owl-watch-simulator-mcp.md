# owl-watch-simulator-mcp

> 标签: connect-iq, garmin, mcp, model-context-protocol, monkey-c, simulator

## 简介

MCP server that lets an AI agent build, run, see and drive Garmin Connect IQ apps in the Connect IQ simulator, in the background, even with the screen locked.
