# sigflint

> 标签: authorization, aws, bun, cloudflare-workers, deno, presigned-url, s3, signature, signing, sigv4, sigv4a

## 简介

Fast, dependency-free AWS Signature Version 4 signing for every AWS service: headers, presigned URLs, SigV4a, chunked uploads and event streams. Node.js, Bun, Deno, Cloudflare Workers and browsers.
