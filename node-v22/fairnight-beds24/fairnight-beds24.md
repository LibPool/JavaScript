# fairnight-beds24

> 标签: beds24, channel-manager, dynamic-pricing, short-term-rental, vacation-rental

## 简介

Beds24 connector for Fairnight: read rooms and bookings, write nightly prices and minimum stays through the official API v2 (refresh token, credit-aware).
