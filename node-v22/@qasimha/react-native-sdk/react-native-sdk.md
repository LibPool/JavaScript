# @qasimha/react-native-sdk

> 标签: bnpl, buy-now-pay-later, checkout, instalments, qasimha, react-native, saudi-arabia

## 简介

React Native checkout module for Qasimha: presents a hosted checkout session in the system browser sheet, reports the outcome, and offers an instalment promo component.
