# @supersuit/session-player

> 标签: agents, claude-code, replay, simulator, supersuit

## 简介

Plays recorded agent sessions (case studies) on a simulated phone or MacBook: a scenario format, a converter from Claude Code transcripts, and a React player anyone can step into.
