# @inflowra/verifiable-document

> 标签: inflowra, ocr, pdf, qr, sdk, vc-jwt, verifiable-credentials, verifiable-document, w3c

## 简介

Browser-first SDK for turning a document into a verifiable credential: place a QR, extract claims, issue, and stamp — all client-side.
