# @ozymandros/electron-message-bridge-adapter-named-pipe

> 标签: @ozymandros/electron-message-bridge, electron, ipc, named-pipe, transport, typescript, unix-socket

## 简介

Named Pipe / Unix socket transport adapter for @ozymandros/electron-message-bridge. Exposes typed IPC handlers over a local socket without Electron's built-in IPC.
