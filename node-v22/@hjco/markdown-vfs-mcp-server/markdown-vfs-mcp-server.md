# @hjco/markdown-vfs-mcp-server

> 标签: agent, llm, markdown, mcp, model-context-protocol, rag, vfs, wasm

## 简介

High-performance MCP server that exposes large Markdown files as a Virtual File System using a Rust B-Tree index compiled to WebAssembly
