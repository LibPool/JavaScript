# @polderlabs/bizar-plugin

> 标签: JavaScript

## 简介

Bizar Norse-pantheon multi-agent system — Claude Code-native plugin shim. Re-exports the SDK at packages/sdk so legacy `plugins/bizar/index.ts` consumers keep working while the actual logic lives in packages/sdk/.
