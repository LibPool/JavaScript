# @kanunilabs/datagrid-core

> 标签: columnar, data-grid, datagrid, engine, filtering, grid, grouping, headless, sorting, table, typed-arrays, typescript, virtual-scroll, web-worker

## 简介

Framework-agnostic DataGrid engine for KanuniLabs — headless controller, column model, row pipeline with an embedded Web Worker. Consumed by @kanunilabs/datagrid-react and @kanunilabs/datagrid.
