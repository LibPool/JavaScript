# @liiift-studio/font-fingerprint

> 标签: fingerprint, font, foundry, opentype, provenance, woff, woff2

## 简介

Embeds and reads a foundry fingerprint in font binaries — WOFF/WOFF2 private data block and TTF/OTF name table — with no re-conversion
