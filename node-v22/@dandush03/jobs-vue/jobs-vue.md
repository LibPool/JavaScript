# @dandush03/jobs-vue

> 标签: JavaScript

## 简介

Reusable Vue 3 panel for the forge-jobs queue — overview, timeline, per-queue charts, cron, scheduled jobs, dead-letter inspector. The Vue counterpart of the forge-jobs-ui Leptos crate.
