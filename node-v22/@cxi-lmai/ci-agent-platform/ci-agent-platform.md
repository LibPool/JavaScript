# @cxi-lmai/ci-agent-platform

> 标签: agents, automation, ci, claude, claude-code, code-review, github-actions, gitlab-ci

## 简介

Autonomous dev pipeline on plain GitLab CI or GitHub Actions, driven by Claude Code. A labeled issue goes in, an open merge request comes out.
