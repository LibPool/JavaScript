# @getscaled/cli

> 标签: api, cli, email, getscaled, marketing, mcp, rcs, sms, voice, whatsapp

## 简介

Official command-line interface for the GetScaled platform — AI-powered multi-channel (email, SMS, voice, WhatsApp, RCS) marketing & sales engagement. Wraps the GetScaled REST API and works with the same gsk_ key as the MCP server.
