# @animastor/editor

> 标签: animastor, book-editing, editor, entity-crud, http-api

## 简介

Animastor Editor — book-editing HTTP contour: core book GET/PUT/PATCH/DELETE, scene/metadata/location/character/voice/behavior patches, entity CRUD (characters/locations/voices/behaviors), structure CRUD (chapters/scenes/units) and blank-book scaffolding.
