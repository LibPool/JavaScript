# @animastor/web-ai-chat

> 标签: ai, animastor, chat, frontend, preact, pure-functions, sse, streaming, web-ui

## 简介

Pure AI chat streaming UX helpers for Animastor web frontend — SSE frame mapping, source badge logic, error code translation, and cancel detection. Zero host dependencies; pure functions and types only.
