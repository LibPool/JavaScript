# @incajs/cli

> 标签: bundler, cli, desktop-app, dev-server, gpui, gui, incajs, incarnative.js, json-rpc, quickjs, vite

## 简介

The inca CLI: watches an app's entry point through a bundler adapter, starts inca-host once the first bundle lands, and reloads it on every rebuild.
