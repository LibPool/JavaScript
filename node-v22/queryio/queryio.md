# queryio

> 标签: ai-agents, claude-code, codex, cursor, database-debugging, database-inspection, foreign-keys, mcp, mcp-server, model-context-protocol, postgres, postgres-mcp, postgresql, read-only

## 简介

PostgreSQL MCP server for AI coding agents. Inspect a row and its foreign-key relationships with inspect_row, then investigate with bounded, read-oriented SQL.
