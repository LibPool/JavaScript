# shotbox

> 标签: a11y, accessibility, gif, playwright, recording, reproducible, screenshots, testing, visual-regression, wcag

## 简介

Playwright helpers for reproducible browser screenshots and recordings: a static server, a sealed browser environment, frame-by-frame recordings, captions, GIFs, page errors and checks. The shotbox command itself is on PyPI.
