# @sneat/structured-data

> 标签: JavaScript

## 简介

Read-only JSON, YAML, and HCL parsing and presentation for Angular 22 and PrimeNG 22 applications. The package has a framework-free `@sneat/structured-data/core` entry point and a standalone `sneat-structured-data-viewer` component. It does not fetch file
