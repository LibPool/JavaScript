# @rdicons/core

> 标签: icon-customizer, icons, rdicons, svg, svg-to-jsx, svg-to-png

## 简介

Framework-free helpers behind rdicons: recolor icons, change stroke and size, convert SVG to JSX, export PNG.

- 官网：https://rdicons.vimalbhatt.com/docs/core
