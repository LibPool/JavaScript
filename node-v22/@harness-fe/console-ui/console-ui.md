# @harness-fe/console-ui

> 标签: JavaScript

## 简介

React SPA for the Harness-FE gateway console: data face (projects / sessions / replay) + governance face (tokens / servers / audit). Built with Vite + Tailwind, served by @harness-fe/gateway at /console.
