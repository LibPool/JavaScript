# @theyoungwolf/lexorank

> 标签: base62, drag-and-drop, jira, kanban, lexorank, ordering, ranking, sortable, typescript

## 简介

A feature-rich TypeScript implementation of the LexoRank ordered-ranking algorithm: bucket overflow, major/minor fractional precision, and batch insertion.
