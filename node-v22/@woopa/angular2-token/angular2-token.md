# @woopa/angular2-token

> 标签: JavaScript

## 简介

Token based authentication service for Angular2 with multiple user support. Angular2-Token works best with the devise token auth gem for Rails. Angular2-Token is currently in Alpha. Any contribution is much appreciated.
