# @abianbiya/llm-audit

> 标签: agent, audit, context, cost, llm, observability, pi-package, tokens

## 简介

See what pi actually sends and where it comes from: per-source attribution of the system prompt (AGENTS.md, skills, memory), per-tool schema cost, real token usage — one /llm-audit command with a settings panel and a clickable HTML report (pi extension).
