# @yeyo11/google-docs-mcp

> 标签: ai-tools, claude, comments, google-docs, google-drive, llm, mcp, mcp-server, model-context-protocol, oauth2, read-only

## 简介

Read-only MCP server for Google Docs that explains a document's comments in detail: authors, dates, status, quoted text and full reply threads. OAuth 2.0 sign-in.
