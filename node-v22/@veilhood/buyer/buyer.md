# @veilhood/buyer

> 标签: ai-agents, confidential-compute, differential-privacy, eip-3009, pay-per-query, robinhood-chain, veil, x402

## 简介

Programmatic buyer client for VEIL — run the full x402 pay-per-query flow (quote → sign EIP-3009 → settle → poll → verify the enclave attestation) to buy differentially-private aggregates. Built for AI agents and backends.
