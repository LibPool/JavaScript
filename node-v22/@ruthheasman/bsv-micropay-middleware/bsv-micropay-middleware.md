# @ruthheasman/bsv-micropay-middleware

> 标签: 402, ai-agent, bitcoin-sv, brc100, bsv, express, handcash, micropayments, middleware, pay-per-use, replit

## 简介

Express middleware for BSV micropayments. Gate any API endpoint with pay-per-use BSV in one line. Works with BRC-100 wallets, HandCash, Yours, and Metanet. Agent-friendly — no OAuth, no redirects.
