# @ab0t/acp

> 标签: JavaScript

## 简介

TypeScript/browser SDK for ACP (Agent Coordination Protocol): shared filesystem, ordered event log, mailbox, fencing leases, CRDT co-editing, presence — over the acp/1 wire.
