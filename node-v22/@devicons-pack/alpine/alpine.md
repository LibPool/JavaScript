# @devicons-pack/alpine

> 标签: alpine, alpinejs, dev-icon, devicons, icon, icons, svg

## 简介

Devicons as an Alpine.js plugin — x-dev-icon directive and $devIcon magic with tree-shakeable icon data (flat, high-contrast, modern).
