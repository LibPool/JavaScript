# @orvello/sdk

> 标签: accounting, bookkeeping, connection-manager, invoicing, nextjs, nodejs, oauth2, orvello, preflight, sdk, typescript

## 简介

Typed, zero-dependency SDK for integrating Node and Next.js applications with orvello - the accounting & invoicing platform. Sends the credential each route demands, and can prove a call would work without making it.
