# @theyashgupta/dispatch

> 标签: agent, claude-code, cli, kanban, linear, localhost, tmux, ttyd, worktree

## 简介

A local kanban board that turns Linear tickets into live Claude Code agent sessions - one git worktree per ticket, real terminals in the browser.
