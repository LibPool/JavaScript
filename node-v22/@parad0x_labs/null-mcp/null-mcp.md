# @parad0x_labs/null-mcp

> 标签: JavaScript

## 简介

MCP server for Web0 .null domains — agents resolve, buy (register), and bid on auctions. Returns unsigned Solana txs (BYO-signer, never holds keys). All tx layouts verified on mainnet.
