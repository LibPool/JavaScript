# @iappx/nest-js-extended-logger

> 标签: exception, interceptor, logger, logging, masking, nest, nest-winston, nestjs, request-logging, sql, transport, typescript, winston

## 简介

Structured request, exception and SQL logging for NestJS on top of winston: one labeled log block per HTTP request, per-category level thresholds and DTO-driven masking of logged request bodies.
