# @alexify/protoarray

> 标签: array, binary-alternative, browser, codec, columnar, compact, encoding, json, metaschema, msgpack, payload, positional, protoarray, protobuf, protocol-buffers, schema, schema-evolution, serialization, sparse, zero-dependency

## 简介

Fast, zero-dependency schema-based compact serialization for Node.js and browsers: objects travel as positional JSON arrays, a shared @alexify/metaschema schema maps every position back to its key. A lightweight alternative to Protocol Buffers
