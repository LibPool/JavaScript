# @gnldev/agui

> 标签: ag-ui, agent, ai, ai-sdk, copilotkit, durable, exactly-once, llm, typescript

## 简介

AG-UI (CopilotKit) protocol adapter: a standalone AG-UI route for @gnldev/durable agents, and the same format as a surface of @gnldev/server.
