# @rom-weaver/cli

> 标签: bps, chd, cli, disc-image, ips, patch, rom, rom-hack, rvz, z3ds

## 简介

A command-line ROM toolkit: patch, compress, extract, convert, identify, bake in cheat codes, and edit supported game saves. No telemetry.
