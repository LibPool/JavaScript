# @jasbros2568/react-viewer-360

> 标签: 360, 360-viewer, image-sequence, product-viewer, react, rotate, spin, turntable

## 简介

Drag-to-rotate 360° product viewer for React, built from an image sequence. Touch, mouse and keyboard support, preloading, autoplay and a scrub slider.
