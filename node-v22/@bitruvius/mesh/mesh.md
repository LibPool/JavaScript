# @bitruvius/mesh

> 标签: 3d-tiles, bitruvius, geospatial, mesh, renderer, webgl2

## 简介

Bitruvius mesh renderer: raw-WebGL2 unlit-textured triangle/point rendering of OGC 3D-Tiles / I3S meshes (PackedMeshTile), in the shared ENU frame
