# @ever-works/pipedrive-connector-plugin

> 标签: JavaScript

## 简介

Pipedrive CRM connector plugin for Ever Works platform (outbound notes + record creation via the official pipedrive Node SDK, and event-source pull of deal/person/organization changes into the event-ingest pipeline, with opt-in historical backfill)
