# @ever-works/google-workspace-connector-plugin

> 标签: JavaScript

## 简介

Google Workspace connector plugin for Ever Works platform (event-source pull of Drive file changes and Calendar events via the official Google API Node.js clients, including Google Meet recording transcripts, with opt-in historical backfill)
