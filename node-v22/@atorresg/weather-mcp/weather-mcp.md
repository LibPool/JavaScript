# @atorresg/weather-mcp

> 标签: AI, Forecast, LLM, MCP, ModelContextProtocol, Open-Meteo, Weather, Weather MCP Server

## 简介

Weather MCP Server, giving LLMs weather forecast capabilities (current conditions, daily forecast, hourly data) via Open-Meteo (free, no API key required).
