# @jyddwy/dsh-companion

> 标签: companion, deepseek-harness, dsh-plugin, screen, tts

## 简介

看屏幕陪玩/陪看剧/陪写代码的 DSH 插件：自动截图 → 多模态理解 → 人格化台词（带情绪）→ 本地 TTS + RVC 语音朗读。右侧栏可开停、调参数、看记录、开新对话、直接聊天。
