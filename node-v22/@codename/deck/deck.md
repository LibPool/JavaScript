# @codename/deck

> 标签: markdown, powerpoint, pptx, presentation, slides, slidev

## 简介

Slide decks as one web page: Markdown in Slidev's form inside a .deck.html file any browser presents, a renderer that runs anywhere, kits of layouts and looks, and an editable PowerPoint out
