# @seekdaseek/agentfeed-algo

> 标签: ai-agents, algorand, liquidations, market-data, mcp, micropayments, usdc, x402

## 简介

A paid x402 data API on Algorand mainnet, with an MCP server. Sells a cross-exchange liquidation tape per call in USDC, and says when it does not know.
