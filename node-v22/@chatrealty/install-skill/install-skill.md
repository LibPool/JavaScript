# @chatrealty/install-skill

> 标签: chatrealty, claude, claude-code, claude-desktop, real-estate, skill

## 简介

Install the ChatRealty Claude skill — lets you create landing pages on ChatRealty from Claude Code / Claude Desktop. For the full tool catalog, use @chatrealty/mcp-server instead.
