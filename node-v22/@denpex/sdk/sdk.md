# @denpex/sdk

> 标签: cuda, denpex, diagnosis, distributed-training, gpu, ml-training, nccl, observability, sdk

## 简介

TypeScript client for the Denpex API — diagnose GPU training failures from logs (POST /api/diagnose), report fix outcomes, check quota. Zero dependencies, Node >= 18.
