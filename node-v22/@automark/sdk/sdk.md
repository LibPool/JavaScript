# @automark/sdk

> 标签: automark, defi, predict, ptb, sui, vault

## 简介

TypeScript SDK for interacting with Automark vaults on Sui. Builds PTBs and reads on-chain state. Does not custody keys or submit transactions — wallets/apps do that.
