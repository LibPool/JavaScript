# @chaterafrikang/call-ui

> 标签: chaterafrika, react, telemedicine, video-call, voice-call, webrtc

## 简介

Drop-in, themeable, symmetric 1:1 voice/video call UI for @chaterafrikang/sdk. Both participants render the same component; role-neutral (doctor↔patient, agent↔customer).
