# @marginfront/mcp

> 标签: ai-agent, anthropic, billing, claude, cursor, llm-billing, marginfront, mcp, model-context-protocol, mrr, revenue-analytics, usage-tracking

## 简介

MCP server for MarginFront. Lets AI agents (Claude, Cursor, Copilot) record usage events, create and look up agents + signals, query revenue / cost / MRR analytics, manage customers + subscriptions + pricing plans, set per-customer cost and revenue watch
