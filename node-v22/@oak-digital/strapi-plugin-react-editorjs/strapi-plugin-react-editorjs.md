# @oak-digital/strapi-plugin-react-editorjs

> 标签: editor-js, plugin, strapi, wysiwyg

## 简介

Plugin for Strapi Headless CMS, hiding the standard WYSIWYG editor and replacing it with Editor.js

## 官网

- 官网：https://market.strapi.io/plugins/strapi-plugin-react-editorjs
- npm 页面：https://www.npmjs.com/package/@oak-digital/strapi-plugin-react-editorjs
