# @moxxy/plugin-stt-local

> 标签: agent, moxxy, offline, on-device, sherpa-onnx, speech-to-text, stt, transcriber, whisper

## 简介

Fully local, on-device speech-to-text Transcriber for moxxy. Runs multilingual Whisper (English + Polish) via sherpa-onnx in a forked sidecar process; models download once on first use from sherpa-onnx's pinned releases (sha256-verified). No API key, no n
