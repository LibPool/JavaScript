# @moxxy/plugin-stt-whisper

> 标签: agent, moxxy, stt, transcriber, whisper

## 简介

OpenAI Whisper Transcriber for moxxy. Audio bytes → text + segments. Plugs into the session's TranscriberRegistry; channels with audio input (Telegram voice, HTTP multipart) consume it transparently.
