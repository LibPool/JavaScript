# @moxxy/jev

> 标签: accessibility, agent, jev, moxxy, typesafe

## 简介

TypeSafe's Jev for moxxy's step runners: the System One client, a window's accessibility elements as Jev reads them, grounding a described target in them, and per-app memory of what worked. Shared by Computer Use and the desktop browser.
