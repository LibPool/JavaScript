# rea-agents-compat

> 标签: compatibility, json-schema, mcp, model-context-protocol, muse-spark, rea, rea-agents, reverse-engineering

## 简介

MCP compatibility proxy for rea-agents: keeps REA usable through models that reject deeply nested tool schemas (Muse Spark 1.3 and other strict function-calling providers).
