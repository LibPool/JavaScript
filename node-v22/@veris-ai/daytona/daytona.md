# @veris-ai/daytona

> 标签: agents, daytona, integration-testing, sandbox, veris

## 简介

Veris twin interception for Daytona: a drop-in @daytona/sdk whose sandboxes come up with a Veris twin already answering their vendor API calls. Unmodified code, real hostnames, receipts.
