# @intyga/verify

> 标签: audit, es256, offline, receipts, verification, webauthn, zero-dependency

## 简介

Independently verify INTYGA approval receipts — confirm a human cryptographically approved exactly the action about to run, with NO INTYGA secret. Zero npm runtime dependencies; optional OpenSSL 3 for timestamps.
