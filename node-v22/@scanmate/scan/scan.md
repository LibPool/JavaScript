# @scanmate/scan

> 标签: comparison, document, ocr, pdf, pipeline, scan

## 简介

The whole ScanMate pipeline: compare a returned document with the one that was issued - the pixel comparison, enhancement, content search and audit, with one class over them all and every other stage loaded only when it is used.
