# @nestjs-pipeline/deadletter

> 标签: behavior, bullmq, cqrs, dead-letter, dlq, nestjs, pipeline, postgres, rabbitmq, redrive, resilience, retry

## 简介

Dead-letter behavior for the NestJS pipeline — captures failed requests (events by default) through bundled BullMQ, RabbitMQ and Postgres transports, and redrives stored failures with an attempt count and a resolved state.
