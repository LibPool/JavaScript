# dsh-llm-kilo-gateway

> 标签: cordis, deepseek-harness, dsh-plugin, free-models, kilo, kilo-gateway, llm, openai-compatible

## 简介

Kilo Gateway free-model provider for DeepSeek Harness: auto-discovers the free model catalog, exposes tools/reasoning/image capabilities, records token usage, and gives you a settings page for your own API key and a catalog change log.
