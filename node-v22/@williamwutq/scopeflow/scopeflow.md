# @williamwutq/scopeflow

> 标签: event, lifecycle, reactive, scope, state, typescript

## 简介

A strongly typed, framework-independent scope-based event-reactive model for TypeScript: scopes own state and behavior for a meaningful lifetime, events are the communication boundary between them.
