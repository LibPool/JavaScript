# @yoseenir/web-sdk

> 标签: web-sdk, yoseenir, yoseenir-web-sdk

## 简介

@yoseenir/web-sdk, 旨在为前端开发者提供方便易用的sdk，用于在浏览器环境中无插件访问格物优信的热像仪产品

## 官网

- 源码仓库：https://gitee.com/polarbird/yoseenir-web-sdk.git
