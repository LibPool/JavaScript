# @rui.branco/revit-mcp

> 标签: autodesk, bim, claude, mcp, model-context-protocol, revit

## 简介

MCP server for Autodesk Revit: read and edit the open model from an MCP client, via a bundled C# bridge add-in that runs inside Revit
