# @boostengine/server

> 标签: boostengine, ecommerce-server, express-ecommerce, gst-invoicing, headless-api, otp-auth, payment-webhooks, shipping-api

## 简介

Plug-and-Play Headless eCommerce API Router for Express, Fastify, and Hono. 1-line auto-mount for Payments, Logistics, Returns, Coupons, Phone Auth, and GST Invoicing.
