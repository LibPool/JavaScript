# @milehimikey/em-tracker-bridge

> 标签: bridge, cli, em, event-modeling, issue-tracker, linear

## 简介

Deterministic em-slice -> issue-tracker bridge: mirrors em slice lifecycle transitions (draft/reviewed/ready-to-implement/implemented) into an issue tracker's own workflow states, one-way, never writing back to the model.
