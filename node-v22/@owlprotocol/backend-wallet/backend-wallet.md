# @owlprotocol/backend-wallet

> 标签: JavaScript

## 简介

[Wallet Client](https://viem.sh/docs/clients/wallet.html) designed to work with [viem](https://viem.sh/) or as a simple [EIP1193](https://eips.ethereum.org/EIPS/eip-1193) provider.
