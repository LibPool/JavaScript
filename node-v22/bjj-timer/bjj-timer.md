# bjj-timer

> 标签: bjj, brazilian-jiu-jitsu, custom-element, grappling, ibjjf, jiu-jitsu, round-timer, timer, web-component

## 简介

A free BJJ round timer web component with IBJJF match times, rest periods, a 10-second warning, audio cues, fullscreen, and screen wake lock. One script tag, no framework, no dependencies.
