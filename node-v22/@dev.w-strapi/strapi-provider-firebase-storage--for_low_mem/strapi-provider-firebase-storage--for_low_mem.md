# @dev.w-strapi/strapi-provider-firebase-storage--for_low_mem

> 标签: Firebase, Firebase Storage, Strapi

## 简介

This version is a custom version of Author SAM Redmond's Strapi-Provider-Firebase-Storage. A storage provider for the Strapi CMS that manages file uploads to Firebase Storage. This version is optimized for low memory environments by excluding the 'sharp'
