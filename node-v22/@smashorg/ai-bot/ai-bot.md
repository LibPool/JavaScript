# @smashorg/ai-bot

> 标签: JavaScript

## 简介

To Start project on local, follow these steps - 1. Ensure that node and npm are installed on your machine 2. Clone project directory 3. cd into the project directory 4. run `npm install` 5. run `npm run dev`
