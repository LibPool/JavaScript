# @enscribejs/layer1-vocabulary

> 标签: academic-publishing, custom-elements, enscribe, jats, layer1, semantic-html, vocabulary

## 简介

Layer 1 semantic HTML vocabulary specification for academic publishing. Defines the element set for articles, books, chapters, floats, citations, cross-references, notes, and apparatus.
