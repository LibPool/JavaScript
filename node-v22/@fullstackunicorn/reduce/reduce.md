# @fullstackunicorn/reduce

> 标签: ai, ai-context, code-reduction, codebase-to-md, fullstackunicorn, javascript, llm, markdown-export, node, project-flattener, project-tree, source-dump

## 简介

Reduce an entire JavaScript/Node.js project into a single Markdown file containing the full project tree and all source files. Designed to give AI systems like LLMs a complete, linear view of the codebase for analysis, refactoring, or documentation.
