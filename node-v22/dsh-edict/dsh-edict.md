# dsh-edict

> 标签: audit, deepseek-harness, dsh, dsh-plugin, edict, multi-agent, orchestration, state-machine, three-departments-six-ministries, workflow

## 简介

三省六部制多智能体审核流程，移植为 DeepSeek Harness 插件：12 状态状态机、门下省封驳、高风险操作确认、越权矩阵、委派防死锁、完整审计。规则与 edict（OpenClaw）逐条对齐。
