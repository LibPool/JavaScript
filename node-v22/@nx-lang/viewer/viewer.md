# @nx-lang/viewer

> 标签: JavaScript

## 简介

An <nx-viewer> custom element that shows an NX document's source as a reading view: elements read as groups and lines without tags or quotes, code reads as written in the editor's colors, and every piece is one click from its source. No framework.
