# @admillio-app/mcp-office-server

> 标签: accountant, accounting, admillio, boekhouding, boekhoudkantoor, claude, cursor, mcp, model-context-protocol, vscode

## 简介

Admillio MCP for accounting firms (boekhoudkantoren): connect Claude, Cursor, VS Code and other MCP clients to all clients of your firm with a kantoor token. Thin stdio bridge to https://admillio.com/api/mcp; every check runs on the server.
