# @admillio-app/mcp-server

> 标签: accounting, admillio, boekhouding, claude, mcp, model-context-protocol

## 简介

De officiële Admillio MCP-server. Koppel Claude, Cursor en andere MCP-clients aan een Admillio-administratie. Elke gebruiker koppelt met een eigen MCP-token en ziet uitsluitend zijn eigen data.
