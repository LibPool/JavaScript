# @ohos-ports/nx-node

> 标签: Backend, CLI, Cypress, Jest, Monorepo, Nest, Node

## 简介

The Node Plugin for Nx contains generators to manage Node applications within an Nx workspace. (HarmonyOS port via @ohos-ports; native binding via @nx/nx-openharmony-arm64 npm alias to @ohos-ports/nx-openharmony-arm64)
