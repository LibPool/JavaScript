# @ohos-ports/css-paint-polyfill

> 标签: css paint, custom paint, houdini, paint, paint worklet, polyfill, worklet

## 简介

A polyfill for the CSS Paint API, with special browser optimizations. (HarmonyOS Node.js port by ohos-ports, DOM shim prelude + CJS export added)
