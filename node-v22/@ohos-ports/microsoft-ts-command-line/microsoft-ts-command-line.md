# @ohos-ports/microsoft-ts-command-line

> 标签: command-line, harmonyos, ohos-ports, openharmony, parser

## 简介

An object-oriented command-line parser for TypeScript (HarmonyOS port of @microsoft/ts-command-line, based on @rushstack/ts-command-line@5.0.1)
