# @ohos-ports/netlify-esbuild-linux-ppc64le

> 标签: JavaScript

## 简介

The Linux PowerPC 64-bit Little Endian binary for esbuild, a JavaScript bundler. (Migrated: bin/esbuild recompiled for arm64 from esbuild v0.14.39 Go source, compatible with openharmony/arm64)
