# @ohos-ports/protoc-gen-grpc-web-openharmony-arm64

> 标签: JavaScript

## 简介

OpenHarmony aarch64 binary for @ohos-ports/protoc-gen-grpc-web (protoc plugin, built from grpc-web 1.5.0 source, statically linked protobuf 3.19.4 + OHOS libc++, signed).
