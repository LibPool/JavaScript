# @ohos-ports/swc-core-android-arm-eabi

> 标签: babel, openharmony, rust, swc, swcpack, tsc, typescript, webpack

## 简介

Super-fast alternative for babel (OpenHarmony arm64 native binding, compiled from swc.git v1.3.11 for aarch64-unknown-linux-ohos)
