# @ohos-ports/netlify-esbuild-android-arm64

> 标签: JavaScript

## 简介

The OpenHarmony ARM 64-bit binary for esbuild, a JavaScript bundler (compiled from esbuild v0.14.39 Go source, static pure-Go ELF, with HarmonyOS sandbox EPERM-tolerance patch).
