# @ohos-ports/github-copilot-language-server-openharmony-arm64

> 标签: JavaScript

## 简介

Copilot Language Server for openharmony-arm64. Pure JS distribution of @github/copilot-language-server 1.544.0 running on user-space Node.js, replacing the darwin-arm64 Mach-O prebuilt single-executable binary.
