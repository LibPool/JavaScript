# @onedayai/web-search

> 标签: JavaScript

## 简介

一个具备网页搜索能力的 MCP（模型上下文协议）插件，允许大语言模型执行网页搜索并获取相关信息。

## 官网

- npm 页面：https://www.npmjs.com/package/@onedayai/web-search

- 0.0.1

- npm registry：https://registry.npmjs.org/@onedayai/web-search
- Node 要求：>=18.0.0
