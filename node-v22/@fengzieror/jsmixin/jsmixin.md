# @fengzieror/jsmixin

> 标签: acorn, ast, game-modding, layaair, layanative, mixin, mod, node, redirect, wrap

## 简介

SpongePowered-Mixin-style JS source transform: AST-level inject/overwrite/wrap/redirect on any JavaScript before it is compiled. Runtime-agnostic core + LayaNative/Node adapters; mods are standalone folders loaded from disk, target code is never modified
