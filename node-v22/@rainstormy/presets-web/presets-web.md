# @rainstormy/presets-web

> 标签: configs, format, lint, oxc, oxfmt, oxlint, typescript

## 简介

Predefined, opinionated configurations for Oxfmt, Oxlint, and TypeScript, with add-ons for Next.js, React Router, Storybook, and Vitest.
