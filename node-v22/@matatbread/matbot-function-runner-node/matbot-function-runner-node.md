# @matatbread/matbot-function-runner-node

> 标签: agent, ai, llm, matbot, matbot-plugin, typescript

## 简介

Node-only FunctionRunner: runs a tool_function body with its synchronous stretches bounded, the globals that reach a capability withheld, and its import(...) routed through the caller's gate. Optional — without it a body runs unbounded, unshadowed and ung
