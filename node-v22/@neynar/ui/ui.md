# @neynar/ui

> 标签: base-ui, components, neynar, react, tailwind, ui

## 简介

AI-first React component library for coding agents. LLM-optimized docs, sensible defaults, zero config. Built on shadcn patterns, Base UI, and Tailwind CSS v4.
