# html2react-cli

> 标签: cli, converter, html, html2react, html2react-cli, htmltoreact, jsx, react, terminal

## 简介

Convert easily html code in react equivalent. In one command line transform svg attributes, class, styles...   Using: npx html2react myFileLocation
