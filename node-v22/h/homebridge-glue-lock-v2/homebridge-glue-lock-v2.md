# homebridge-glue-lock-v2

> 标签: glue, glue-lock, homebridge, homebridge-plugin, homekit, lock, smartlock

## 简介

Unofficial Homebridge plugin for Glue smart locks (fork of the GlueHome plugin). Supports Homebridge 1.8+ and 2.x.
