# hexo-swpp-es5

> 标签: ServiceWorker, auto, hexo, json, sw

## 简介

&emsp;&emsp;该插件用于在 hexo 中自动构建可用的 ServiceWorker，插件内自带了一个缺省的 sw.js，也支持使用自定义的 sw。
