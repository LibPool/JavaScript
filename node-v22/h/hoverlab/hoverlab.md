# hoverlab

> 标签: a11y, accessibility, agent-rules, animation, blocks, boilerplate, code-review, components, css, cursor, hover, mcp, model-context-protocol, nextjs, react, scaffold, svelte, tailwind, templates, ui, vue, windsurf

## 简介

Install UI from the Hoverlab catalog — CSS effects, React blocks, whole pages and scaffoldable templates — review your own components for design defects, and expose it all to your editor's AI agent over MCP.
