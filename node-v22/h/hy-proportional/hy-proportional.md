# hy-proportional

> 标签: proportional, 大屏等比工具

## 简介

一个轻量级的 **自适应缩放插件**，可以根据父元素大小按比例缩放子元素，同时保持居中。   支持 **Vue 3 指令** 和 **原生 JS / TypeScript 函数** 两种使用方式。
