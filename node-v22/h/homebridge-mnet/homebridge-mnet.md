# homebridge-mnet

> 标签: air-conditioner, g-50a, gb-50a, homebridge, homebridge-plugin, homekit, hvac, m-net, melans, mitsubishi

## 简介

Homebridge plugin that bridges Mitsubishi Electric M-NET centralized AC controllers (G-50A / GB-50A) to Apple HomeKit.
