# htmx-ui-engine

> 标签: bun, bun-plugin, cli, htmx, htmx-ui, nunjucks, static-site, tailwindcss, vite, vite-plugin

## 简介

Build htmx sites from Nunjucks pages: file-based routing, Tailwind, dev server with HMR and static builds, on Bun or Node.
