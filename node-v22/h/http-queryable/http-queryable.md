# http-queryable

> 标签: cache, caching, express, fastify, fetch, http, idempotent, query, query-method, rfc10008, safe-method

## 简介

QUERY endpoints + correct body-aware caching for Node. The new HTTP QUERY method (RFC 10008) made easy and safe — Express, Fastify, raw http, and an isomorphic client.
