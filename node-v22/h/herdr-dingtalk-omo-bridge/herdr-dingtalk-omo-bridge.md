# herdr-dingtalk-omo-bridge

> 标签: agent, bridge, dingtalk, herdr, omo, plugin

## 简介

Herdr plugin that bridges DingTalk messages to an OmO coding-agent session, posts the answer back, and tags each message as received/done.
