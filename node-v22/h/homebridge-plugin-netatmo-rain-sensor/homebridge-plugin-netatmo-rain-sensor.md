# homebridge-plugin-netatmo-rain-sensor

> 标签: homebridge-plugin, homekit, netatmo

## 简介

This Homebridge Plugin makes the Netatmo Rain Sensor accessible to HomeKit as a Switch or a Leak Sensor. This makes it possible to use the Netatmo Rain Sensor for all kinds of automations based on rain detection.
