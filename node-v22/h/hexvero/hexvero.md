# hexvero

> 标签: apk, asar, audit, binary-analysis, cli, contextbridge, diff, dotnet, electron, electron-security, elf, evm, go, ipc, mach-o, mcp, mcp-server, model-context-protocol, pe, release-diff, reverse-engineering, sarif, security-review, sqlite, static-analysis, wasm

## 简介

Electron release diff for security review and audit: compare two builds (app.asar, .app, install directory, release ZIP) and see what changed in IPC, contextBridge, window settings, network hosts and storage, with file and line. CI check with SARIF, MCP s
