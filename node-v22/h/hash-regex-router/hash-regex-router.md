# hash-regex-router

> 标签: frontend, hash, hashchange, regex, router

## 简介

Client-side hashchange regex router for [singe-page applications](http://en.wikipedia.org/wiki/Single-page_application). Works on Chrome 5, Firefox 3.6 and IE 10+.
