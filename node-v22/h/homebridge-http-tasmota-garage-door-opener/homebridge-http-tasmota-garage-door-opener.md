# homebridge-http-tasmota-garage-door-opener

> 标签: garage-door-opener, homebridge, homebridge-plugin, sonoff, sonoff-4ch, sonoff-sv, tasmota-door-opener

## 简介

Homebridge plugin for Sonoff (one or multiple chanels) running tasmota to open garage doors and gates with the Garage UI on the HomeKit App using HTTP request
