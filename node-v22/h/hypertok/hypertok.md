# hypertok

> 标签: bpe, gpt, huggingface, llm, o200k, openai, sentencepiece, tiktoken, token-counting, tokenization, tokenizer, wasm, webassembly

## 简介

The fastest tokenizer on the web. Exact token ids for any BPE or SentencePiece vocabulary, in browsers and Node.
