# honeytongue

> 标签: ai-npc, browser-game, charisma, charisma-check, dialogue, dialogue-system, game-ai, game-mechanics, gamedev, interactive-fiction, jev, npc, npc-dialogue, persuasion, phaser, rpg, sugarcube, text-adventure, text-game, twine

## 简介

Characters players can actually argue with: a persuasion mechanic for games where players type or speak to NPCs, judged by each character's own values. Powered by Jev.
