# hardsub

> 标签: JavaScript

## 简介

A command-line script for hardsubbing MKVs with ffmpeg. Includes a copy of ffmpeg; you don't need to install one.

## 官网

- npm 页面：https://www.npmjs.com/package/hardsub

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- npm 安装：`npm install hardsub`
- npm registry：https://registry.npmjs.org/hardsub
