# harless-dining-api

> 标签: allergens, dining-hall, harless, menu, nutrition, sodexo

## 简介

Unofficial menu client for Harless Dining Hall (Sodexo). Get Breakfast / Lunch / Dinner for any date, with stations, nutrition, and allergens.
