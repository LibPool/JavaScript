# homebridge-ogemray

> 标签: homebridge-plugin, homekit, local, ogemray, smart-switch, tata-power-ez-home

## 简介

HomeKit support for Ogemray-based Wi-Fi switches (Tata Power EZ Home and other rebrands) via local LAN control — zero-config discovery, no cloud.
