# harness-summit

> 标签: agent-communication, ai-agents, claude-code, codex, coding-agents, herdr, inter-agent-messaging, mcp, model-context-protocol, multi-agent, oh-my-pi, opencode, pi

## 简介

Let Claude Code, Codex, OpenCode, pi and OMP sessions on one machine message each other and wake idle agents. An MCP server plus small per-harness adapters, all through plain files.
