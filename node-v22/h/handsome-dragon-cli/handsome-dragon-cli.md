# handsome-dragon-cli

> 标签: JavaScript

## 简介

`dragon-cli` 是前端编码规范化工具，可以为项目一键接入规范，保障项目的编码规范和代码质量。

- 源码仓库：git+https://github.com/Digoler/Dragonboot.git
- npm 页面：https://www.npmjs.com/package/handsome-dragon-cli
