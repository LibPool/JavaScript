# hstui

> 标签: JavaScript

## 简介

``` cd hs-ui yarn install yarn run serve ``` ### 目录结构 #### packages > 主要包含 token2css 后的产物，及组件 - index.js 为入口文件 - token：token2css 转换后的 css 文件 - components：基于 token 变量的 vue 组件
