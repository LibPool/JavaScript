# homr-web

> 标签: JavaScript

## 简介

Browser port of homr, the optical music recognition engine: sheet music image in, MusicXML and the chord symbols above each staff out, no server.

## 官网

- 官网：https://github.com/jymen/homr-web
- 源码仓库：git+https://github.com/jymen/homr-web.git
