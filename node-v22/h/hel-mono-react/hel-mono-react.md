# hel-mono-react

> 标签: JavaScript

## 简介

hel-mono 是一个基于 hel-micro 和 pnpm 向上提炼的微模块大仓化开发架构，该架构下沉hel-micro sdk到编译阶段，可让用户无需用户感知到微模块存在，并通过不同的命令入口，编译出一体化产物（不含微模块），分布式产物（包含微模块），让用户针对不同场景（如私有部署场景、公有云架构等）做出更灵活的选择。
