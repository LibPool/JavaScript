# homebridge-petkit-bridge

> 标签: feeder, fountain, homebridge-plugin, homekit, litter-box, petkit, supports-hap

## 简介

Homebridge plugin for petkit-bridge: exposes PetKit feeders, litter boxes and fountains to Apple HomeKit via the local petkit-bridge HTTP API.
