# hexo-text-pipeline

> 标签: callout, hexo, hexo-plugin, hooks, mermaid, obsidian, obsidian-flavored-markdown, pipeline, text-transform, wikilink

## 简介

A general-purpose hooks bus for Hexo's render pipeline: hang your own scripts/commands on any text stage (text in, text out, edit-and-use), with a checker system as the safety net. Ships an Obsidian Flavored Markdown preset.
