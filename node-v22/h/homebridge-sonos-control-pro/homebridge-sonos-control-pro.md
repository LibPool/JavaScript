# homebridge-sonos-control-pro

> 标签: automation, homebridge-plugin, homekit, local, multiroom, scenes, siri, sonos, speaker, supports-hap, upnp

## 简介

Sonos scenes as HomeKit switches, built and edited in a visual editor inside Homebridge. Local UPnP control — no cloud, no hub, no account.
