# html-webpack-plugin-custom

> 标签: custom, html, html-webpack-plugin-custom, plugin, webpack

## 简介

一个基于html-webpack-plugin扩展的插件,实现按照html里面的占位符,和指定的配置,自定义静态资源文件的插入位置。
