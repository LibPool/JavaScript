# helloagents

> 标签: agent, ai, claude, cli, codex, cursor, grok, prompt, skills

## 简介

HelloAGENTS — AI 编码 CLI 的思维激活层：纠偏内核 + 按需思维技能，一条命令分发到 Claude Code、Codex、Grok、Cursor。A thinking-activation layer for AI coding CLIs.
