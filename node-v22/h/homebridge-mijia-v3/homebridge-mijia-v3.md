# homebridge-mijia-v3

> 标签: camera, homebridge-plugin, mijia, miot, xiaomi

## 简介

Homebridge plugin for Xiaomi Mijia v3 with local video and audio, snapshots, two-way talk, and experimental HomeKit Secure Video.
