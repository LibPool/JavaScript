# hungarian-language

> 标签: JavaScript

## 简介

> # 🇭🇺 hungarian-language Magyar nyelvű JavaScript wrapper könyvtár, amely lehetővé teszi, hogy a kódot magyarul írd és olvasd. Célja, hogy a programozás nyelve közelebb kerüljön az anyanyelvhez, miközben megőrzi a JavaScript erejét.
