# hurst-framework

> 标签: JavaScript

## 简介

**Hurst Trading Framework** — a TypeScript algorithmic trading engine for Interactive Brokers (IBKR) and beyond. Write a strategy once, run it unchanged in backtest, paper, and live modes.
