# hiflow-mcp

> 标签: ai, claude, hiflow, invoicing, llm, mcp, model-context-protocol, timesheet

## 简介

Model Context Protocol (MCP) server for the Hiflow API — lets AI assistants manage customers, estimates, invoices, jobs, tasks, timesheets and more.
