# homebridge-calendar-tempfix

> 标签: calendar, home-automation, homebridge, homebridge-plugin, homekit, ical

## 简介

This is a fork of the homebridge-calendar plugin. A calendar plugin for homebridge (https://github.com/nfarina/homebridge), which allows flexible scheduling of triggers using any iCal calendar.
