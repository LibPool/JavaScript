# headlo-server

> 标签: auth, authentication, express, headlo, hono, jwt, middleware, nextjs, oauth2, scope, verifier

## 简介

Server-side helpers for Headlo — verify tokens issued by auth.headlo.com and gate your own API endpoints with scopes. Node / Cloudflare Workers / Deno / Bun.
