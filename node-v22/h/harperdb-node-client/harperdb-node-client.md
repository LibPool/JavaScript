# harperdb-node-client

> 标签: bulk, caching, client, database, driver, harperdb, javascript, keep-alive, node, nodejs, nosql, optimized, parallel, sdk, sql, typescript, upsert

## 简介

High-performance HarperDB client for Node.js/TypeScript with connection pooling (keep-alive), query caching with auto-invalidation, bulk/parallel APIs, and GraphQL schema apply.
