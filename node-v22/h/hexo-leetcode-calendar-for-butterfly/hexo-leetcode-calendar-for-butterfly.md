# hexo-leetcode-calendar-for-butterfly

> 标签: butterfly, calendar, dark-mode, heatmap, hexo, leetcode, leetcode-cn

## 简介

A Hexo tag plugin that renders a leetcode.cn submission calendar with automatic light/dark mode, built for the Butterfly theme
