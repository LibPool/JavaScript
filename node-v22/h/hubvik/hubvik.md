# hubvik

> 标签: anomaly-detection, edge, gateway, iot, network, security

## 简介

Per-device network anomaly detection for IoT gateways, smart-home hubs, building-management servers and small appliances. Learns each device's normal behavior and reports deviations. Offline, zero dependencies.
