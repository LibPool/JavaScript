# hero-run-ai

> 标签: agents, ai, gateway, hero-run, llm, openai, router, vercel-ai-sdk

## 简介

Use Hero Run's multi-gateway AI router (375+ models across 10 gateways, paid in $HERO) from any app: an OpenAI-compatible client, a Vercel AI SDK provider, and a drop-in React chat widget.
