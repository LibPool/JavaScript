# homebridge-ambient-lights-aurora

> 标签: Andrew Mohawk, ambient-lights, aurora, homebridge-plugin, tv

## 简介

Interfaces with a Raspberry Pi to allow a user to turn on and off the Aurora system.  This is based on this github project: https://github.com/AndrewMohawk/Aurora NOT Aurora switches.
