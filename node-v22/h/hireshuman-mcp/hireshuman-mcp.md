# hireshuman-mcp

> 标签: ai-agents, hireshuman, hiring, mcp, model-context-protocol

## 简介

MCP stdio bridge for Hireshuman (https://hireshuman.com) — lets MCP clients that only spawn local stdio servers talk to the hosted Hireshuman MCP API.

## 官网

- 官网：https://hireshuman.com
- npm 页面：https://www.npmjs.com/package/hireshuman-mcp
