# hallmark-sdk

> 标签: depin, ed25519, hallmark, proof-of-serve, read, receipt, rpc, solana

## 简介

Receipt-aware TypeScript client for the Hallmark read layer on Solana. Every read returns a signed ed25519 receipt you can verify offline.
