# homebridge-honeywell-home-roomsensor

> 标签: homebridge-plugin, honeywell, honeywell home, honeywell home roomsensors, honeywellhome, honeywellhome roomsensors, honeywellhomeroomsensors, humidity, room sensors, temperature

## 简介

Add-on to the Honeywell Home https://honeywellhome.com plugin for Homebridge: https://github.com/homebridge/homebridge, that adds support for T9 Thermostat Room Sensors
