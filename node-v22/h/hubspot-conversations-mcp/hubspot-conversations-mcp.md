# hubspot-conversations-mcp

> 标签: conversations, helpdesk, hubspot, inbox, mcp, model-context-protocol

## 简介

MCP server for the HubSpot Conversations API — read threads and messages, send replies and comments, and manage conversation threads from any MCP client.
