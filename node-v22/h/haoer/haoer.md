# haoer

> 标签: app, framework, haoer, http, rest, restful, router, server, web

## 简介

Haoer es un marco de trabajo de Node.js para crear aplicaciones web. Está diseñado para ser simple, flexible y fácil de usar. Con Haoer, puedes crear aplicaciones web rápidamente sin la necesidad de aprender una gran cantidad de conceptos o sintaxis compl
