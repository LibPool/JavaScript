# homebridge-honeywell-home-roomsensor-thermostat

> 标签: Honeywell Home Roomsensor Thermostat, homebridge-plugin, honeywell, honeywell-home, honeywellhome, roomsensor, roomsensor-thermostat, thermostat

## 简介

Add-on to the Honeywell Home https://honeywellhome.com plugin for Homebridge: https://github.com/homebridge/homebridge, that adds support for T9 Thermostat Room Sensors and displays them as Thermostats to give that room priority.
