# hermes-tammi-plugin

> 标签: bridge, chatbot, gateway, hermes, hermes-agent, messaging, tammi, viettel, zego, zim

## 简介

Tammi (Viettel messenger) platform for Hermes Agent. A Node bridge runs the tammi.vn chat SDK; the Hermes adapter talks to it over HTTP + SSE.
