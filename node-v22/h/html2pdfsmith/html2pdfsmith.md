# html2pdfsmith

> 标签: browserless, bun, document, google-fonts, html-to-pdf, html2pdf, low-memory, no-chromium, no-puppeteer, node, nodejs, pdf, pdf-generator, pdf-render, pdfkit, report, streaming, table, typescript

## 简介

Browserless HTML-to-PDF rendering engine for TypeScript, Node.js, and Bun. No Chromium, low-memory streaming renderer, CSS font-family, Google Fonts caching, and local font installs.
