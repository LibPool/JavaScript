# hotedit

> 标签: agent, ai, chart.js, claude-code, contenteditable, editor, html, llm, mcp, mermaid, plotly, report, vega-lite, visual-editor, wysiwyg

## 简介

Edit any HTML file in your browser — text, styles, layout, charts — and save the changes back into the file as small, clean patches. Built for AI-generated reports.
