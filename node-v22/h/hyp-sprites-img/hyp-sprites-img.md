# hyp-sprites-img

> 标签: css-sprite, sprite, spritesheet, vite, vite-plugin, vue, vue3

## 简介

基于 Vue 3 + Vite 的雪碧图工具：构建期生成每帧坐标，支持远程图、网格与透明区检测，告别手写 background-position。
