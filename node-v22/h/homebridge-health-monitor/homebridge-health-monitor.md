# homebridge-health-monitor

> 标签: errors, health, homebridge, homebridge-plugin, homekit, logs, monitor, warnings

## 简介

Homebridge plugin that monitors the Homebridge log file and exposes health anomalies through a single HomeKit Leak Sensor.
