# homebridge-tivo-control

> 标签: homebridge, homebridge-plugin, tivo, tv

## 简介

Homebridge plugin for TiVo set top boxes, to provide momentary contact switches that simulate sending Tivo remote keypresses, and change channels. Multiple Tivo devices can be controlled with this plugin.
