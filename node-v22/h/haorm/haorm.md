# haorm

> 标签: orm, sql

## 简介

一个学习向工程，为了学习Node.js和ORM框架原理。Node.js下的ORM框架，帮助用户处理数据库。支持一二级缓存、读写分离。避免SQL注入、快速生成SQL语句，同时允许自定义SQL。
