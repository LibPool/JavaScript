# housestyle-mcp

> 标签: accessibility, apca, claude, color-contrast, css, design, design-system, design-tokens, font-pairing, google-fonts, linter, mcp, model-context-protocol, oklch, typography, wcag

## 简介

MCP server that stops AI-built interfaces from looking AI-built — audits CSS for generic-design tells, then fixes them with real Google Fonts data, WCAG/APCA contrast math, OKLCH palettes, and fluid type scales. No API key.
