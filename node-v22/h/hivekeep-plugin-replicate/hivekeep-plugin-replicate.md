# hivekeep-plugin-replicate

> 标签: embedding, hivekeep, hivekeep-plugin, image, llm, replicate

## 简介

Bring Replicate-hosted models to Hivekeep — LLM (Llama 3, Mistral, Mixtral), Image (Flux Schnell, Stable Diffusion 3.5), and Embedding — all behind one API token.
