# html-shutter

> 标签: canvas, capture, clipboard, data-url, dom, download, export, framework-agnostic, hook, html, png, react, report, screenshot, snapshot, vanilla-js

## 简介

Framework-agnostic PNG screenshots of any HTML element — clone the DOM, inline computed styles, rasterize via SVG, and export data URLs or file downloads. Optional React bindings.
