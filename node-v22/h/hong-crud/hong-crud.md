# hong-crud

> 标签: JavaScript

## 简介

首先安利一个特别厉害的前端框架[Avue](https://avuejs.com/)，此插件是基于avue进行的二次开发，一切为了业务和产品，当然Avue官方也提供了表格设计器avue-crud（功能已足够强大），但为了满足公司的一些特殊的业务场景，我就必须加加工啦，当然这篇文章只是为了本人开发沉淀。
