# honeyareyoucoming

> 标签: JavaScript

## 简介

`honeyareyoucoming` is a stateless Hono middleware package for defensive deception: it decorates every response with convincing IIS/ASP.NET/Umbraco banners and exposes a set of lure routes that waste attacker and scraper time.
