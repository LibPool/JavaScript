# homebridge-godox-tl

> 标签: ble, bluetooth, godox, godox-tl, homebridge, homebridge-plugin, homekit, mesh, sig-mesh, tl30

## 简介

Homebridge plugin for Godox TL30 BLE control. Exposes brightness, color temperature, HSI color, and optional FX/RGBW presets via BLE SIG Mesh.
