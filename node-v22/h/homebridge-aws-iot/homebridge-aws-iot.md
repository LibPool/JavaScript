# homebridge-aws-iot

> 标签: alexa, aws, homebridge alexa, homebridge aws iot, homebridge iot, homebridge-plugin, iot

## 简介

Synchronizes Homebridge Devices with AWS IOT device shadows, which enables Alexa and other platforms.
