# human-hindsight

> 标签: agents, claude, claude-code, cli, codex, kiro, kiro-cli, local-first, opencode, opencode-ai, prompt, prompt-engineering, prompt-library, transcripts

## 简介

Mine coding-agent history (Claude Code, Codex, Kiro, OpenCode) into a oneshot prompt library and CLAUDE.md/AGENTS.md preferences. The prompt you'd write if you knew then what you know now.
