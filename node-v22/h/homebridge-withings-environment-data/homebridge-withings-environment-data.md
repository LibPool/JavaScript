# homebridge-withings-environment-data

> 标签: air-quality, co2, environment-data, homebridge-plugin, homekit, temperature, withings, ws-50

## 简介

Homebridge plugin exposing ambient CO2/air-quality and room temperature readings from a Withings WS-50 scale as HomeKit sensors
