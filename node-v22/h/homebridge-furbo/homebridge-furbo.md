# homebridge-furbo

> 标签: camera, furbo, homebridge-plugin, homekit, rtsp

## 简介

Homebridge plugin for Furbo dog cameras - exposes the local RTSP stream as a HomeKit camera

- npm 页面：https://www.npmjs.com/package/homebridge-furbo

- npm registry：https://registry.npmjs.org/homebridge-furbo
- Node 要求：^20 || ^22
