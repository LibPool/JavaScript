# hyperfixer

> 标签: ai, ai-agents, bun, claude, claude-code, cli, code-quality, codex, deno, developer-tools, fail-fast, git-hooks, github-actions, llm, mutation-testing, nodejs, pre-commit, property-based-testing, quality-gates, testing, typescript, verification

## 简介

Layered verification pipeline for AI-agent-written code: cost-ordered gates, fail-fast, machine-readable verdicts for self-correction loops. Runs on Node, Bun and Deno.
