# hilbras-code

> 标签: agent, ai, cli, coding-agent, llm, openai-compatible, ripgrep, terminal

## 简介

Hilbras — a terminal coding agent. Streams from any OpenAI-compatible endpoint, runs shell commands behind an approval layer, and needs no vendor SDK.
