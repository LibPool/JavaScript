# history-library

> 标签: h5, history, js

## 简介

history-library可以维护出一条浏览器页面跳转记录栈，在H5项目中页面应对动态流程返回指定页面场景问题很有效。但是在有iframe嵌套的情况下，还有一定缺陷，待续优化。
