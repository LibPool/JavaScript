# homebridge-stream-sensors

> 标签: animal-detection, camera, homebridge, homebridge-plugin, homekit, motion-sensor, object-detection, onnx, package-detection, person-detection, rtsp, smart-home, vehicle-detection, yolo

## 简介

Homebridge plugin that turns camera/video streams into HomeKit motion sensors using on-device object detection (animals, people, vehicles, packages)
