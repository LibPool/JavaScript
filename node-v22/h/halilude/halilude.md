# halilude

> 标签: agent, ai, byok, claude, gemini, load-balancing, office, openai, qwen

## 简介

Multi-provider AI office: bring your own Claude/OpenAI/Gemini/Alibaba keys, load-balance across them, resume Claude Code sessions, run batch audits, and join a shared office where tasks run on members' own machines.
