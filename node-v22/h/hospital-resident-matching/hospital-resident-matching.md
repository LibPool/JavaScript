# hospital-resident-matching

> 标签: algorithm, assignment, deferred-acceptance, gale-shapley, hospital-resident, matching, stable-marriage, stable-matching

## 简介

Stable matching for the Hospital/Resident problem: a resident-oriented Gale-Shapley solver and a seeded instance generator that reproduces its Python original seed for seed.
