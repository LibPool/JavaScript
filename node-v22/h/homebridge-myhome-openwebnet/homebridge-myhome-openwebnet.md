# homebridge-myhome-openwebnet

> 标签: bticino, bticino myhome, bus, bus-scs, homebridge, homebridge-plugin, homebridge2, homekit, legrand, legrand myhome, my home, my-home, myhome, myhome openwebnet, open web net, openwebnet, scs, supports-hap

## 简介

Homebridge plugin for Bticino/Legrand MyHome OpenWebNet systems, with support for lights, dimmers, blinds, 3477 dry contacts and 4680 CEN+ controls.
