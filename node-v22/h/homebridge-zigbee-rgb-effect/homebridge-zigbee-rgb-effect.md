# homebridge-zigbee-rgb-effect

> 标签: colorloop, effect, homebridge, homebridge-plugin, led, mqtt, rgb, zigbee, zigbee2mqtt

## 简介

Homebridge plugin to control a Zigbee RGB LED via MQTT as a HomeKit switch with a configurable effect on turn-on.
