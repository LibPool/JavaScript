# hookwave-sdk

> 标签: client, events, hookwave, sdk, webhook, webhooks

## 简介

Official Node.js SDK for Hookwave — emit events into a Hookwave source. Batched, retried, fire-and-forget.

## 官网

- 官网：https://docs.hookwave.dev
- 源码仓库：git+https://github.com/hookwave/sdk-node.git
- npm 页面：https://www.npmjs.com/package/hookwave-sdk
