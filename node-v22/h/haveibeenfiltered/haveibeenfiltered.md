# haveibeenfiltered

> 标签: breach, data-breach, filter, haveibeenpwned, hibp, offline, password, password-check, pwned, ribbon-filter, security, sha1

## 简介

Offline password breach checking using ribbon filters. Check passwords against HIBP (2B+ passwords) and other breach datasets locally, with zero API calls.
