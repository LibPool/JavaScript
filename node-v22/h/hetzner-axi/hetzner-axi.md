# hetzner-axi

> 标签: agent, axi, cli, dns, hcloud, hetzner, hetzner-cloud, toon

## 简介

AXI-compliant Hetzner Cloud CLI for agents - servers, firewalls, volumes, IPs, networks, load balancers and DNS zones - with token-efficient TOON output, previews and idempotent mutations
