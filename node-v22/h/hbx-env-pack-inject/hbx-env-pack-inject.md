# hbx-env-pack-inject

> 标签: JavaScript

## 简介

hbx-env-pack 的构建侧：按 env-pack.json 的 mode 加载对应 .env，再 DefinePlugin 注入 process.env。HBuilderX 打 App 包和 vue-cli 构建都适用。
