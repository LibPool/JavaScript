# hexwright

> 标签: architecture, code-review, coding-agent, dependency-graph, hexagonal-architecture, human-in-the-loop, kotlin, mcp, mcp-server, ports-and-adapters, spring-boot, static-analysis, svg, visualization

## 简介

Design graph for hexagonal-architecture codebases. Renders what a branch changed as one picture a human can confirm at a glance, and gives a coding agent boundary verdicts it can run on itself before asking for review.
