# hd-assembly-table

> 标签: JavaScript

## 简介

最多3列，3个字段 两个属性 title为标题 例：title:{tit1:"编号",tit2:'标题',tit3:'内容'} content为内容 例：content:[       {id:1,title:'标题',content:'内容231231'},       {id:2,title:'标题2',content:'内容231231'},       {id:3,title:'标题3',content:'内容231231'}     ] *传入值必须为对象*
