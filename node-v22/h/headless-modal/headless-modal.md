# headless-modal

> 标签: a11y, accessible, aria, dialog, focus-trap, headless, modal, overlay, portal, react, react-hook, scroll-lock, ui, wai-aria

## 简介

Accessible, headless modal / dialog primitive for React — focus trap, scroll lock, portal rendering, Escape & overlay close, and full ARIA, with zero styling. You own the markup; it owns the behavior. Works with React 18 and 19.
