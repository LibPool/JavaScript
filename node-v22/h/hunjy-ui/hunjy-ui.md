# hunjy-ui

> 标签: cli, component-library, design-system, radix-ui, react, shadcn, tailwindcss, ui

## 简介

Eine moderne CLI, die React + Tailwind CSS Komponenten (mit Radix UI und Lucide Icons) direkt als Quellcode in dein Projekt bringt – im Stil von shadcn/ui.
