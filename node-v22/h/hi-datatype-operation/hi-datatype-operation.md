# hi-datatype-operation

> 标签: array-validation, data-types, object-validation, primitive-types, runtime-validation, tuple-validation, type-checking, typescript, union-types

## 简介

TypeScript 原生类型守卫生成器，自动同步类型定义与运行时验证逻辑。支持装饰器语法、类型谓词组合与泛型约束验证，提供 VS Code 智能提示插件。
