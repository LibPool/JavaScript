# htm-projection

> 标签: cdn, dom, htm, html, no-vdom, projection, reactivity, template, typescript

## 简介

Reactive HTML with 3 pillars: pattern parser, proxy, and programs. Browser-native API, lightweight reactive projection. Ready for widgets or SPA. A different approach from virtual DOM with fine-grained reactivity — slot-ready even with empty initial state
