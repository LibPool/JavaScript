# htmx-ui-upgrade

> 标签: codemod, htmx, htmx-ui, migrate, upgrade

## 简介

Upgrade an htmx-ui project's code to a newer htmx-ui: npx htmx-ui-upgrade@latest, bunx htmx-ui-upgrade@latest.
