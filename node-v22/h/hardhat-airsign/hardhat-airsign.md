# hardhat-airsign

> 标签: airsign, browser-wallet, dapp, deploy, env-security, ethereum, ethers-v5, evm, hardhat, hardhat-plugin, hardhat2, metamask, no-private-key, rainbowkit, remote-signer, runner, smart-contracts, solidity, transaction-signing, walletconnect, web3

## 简介

Hardhat 2 plugin for remote transaction signing via browser wallet (ethers v5). Deploy contracts, run tasks, and execute scripts from a browser UI — no private keys in .env files.
