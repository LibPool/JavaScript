# has-exif-cli

> 标签: automate, check, ci, cli, exif, image, iptc, metadata, xmp

## 简介

Checks if an image file has EXIF, XMP or IPTC metadata. Available as CLI. Can be used in CI automation. Supports both JPG and WEBP image format
