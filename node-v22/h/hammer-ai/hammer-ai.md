# hammer-ai

> 标签: agent, agentic-loop, ai, bash, compaction, llm, memory, tool-calling

## 简介

Infrastructure for building tool-calling bash-format chat agents: LLM client, agent loop, memory, tool registry, validation, and web runtime.
