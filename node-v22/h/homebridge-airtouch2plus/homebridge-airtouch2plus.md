# homebridge-airtouch2plus

> 标签: air conditioning, airtouch, airtouch2, airtouch2plus, daikin, ducted, homebridge-plugin, hvac, polyaire, supports-hap

## 简介

Homebridge plugin for the Polyaire AirTouch 2+ ducted AC controller (firmware API port 9200). Exposes AC, zones, fan speed, and fan-only/dry modes to HomeKit.
