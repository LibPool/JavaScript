# haru-cms-mcp

> 标签: astro, cms, haru-cms, harucms, headless-cms, mcp, modelcontextprotocol, nextjs, ヘッドレスCMS

## 简介

ハルCMS（HARU CMS）のMCPサーバー。日本語ヘッドレスCMSの記事作成・更新・予約公開・画像取り込みをClaudeやChatGPTから実行できます。

## 官网

- 官网：https://www.webharu.com/cms
- 源码仓库：git+https://github.com/Masato-haru/webharu-cms.git
- npm 页面：https://www.npmjs.com/package/haru-cms-mcp
