> 标签: agent-orchestration, ai-agents, ai-coding, ai-framework, anthropic, claude, claude-code, claude-subagents, code-review, coding-agent, copilot-cli, cost-optimization, developer-tools, github-copilot, haiku, hydra, multi-agent, opus, orchestration, sonnet, speculative-decoding, subagents, token-savings

## 简介

Multi-agent orchestration framework for AI coding CLIs (Claude Code, Gemini CLI, Codex CLI). Routes tasks to specialized cheap/fast subagents while the frontier model orchestrates — inspired by speculative decoding. ~50% API cost reduction.
