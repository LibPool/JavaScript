# homebridge-bambu-print-status

> 标签: 3d-printer, bambu-lab, homebridge-plugin

## 简介

Homebridge plugin exposing a Bambu Lab printer's print status as a HomeKit Occupancy Sensor, for driving automations (e.g. powering down via a smart plug) when the printer goes idle.
