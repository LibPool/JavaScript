# hosait-mcp-server

> 标签: JavaScript

## 简介

MCP server that connects Claude Code to a Hosait project (status, deploy logs, environment variables, redeploy, rollback, restart) via a project-scoped API token, and gives it the Hosait skill — the platform's conventions — without a separate install.
