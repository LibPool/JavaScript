# hanlint

> 标签: hangul, korean, korean-language, linter, markdown, proofreading, prose, prose-linter, readability, style-checker, text-linter, writing

## 简介

한국어 글 검사기. Korean prose linter for Markdown: translationese, noun piles, double passives, weak structure. Zero dependencies
