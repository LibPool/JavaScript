# husky-event-notify

> 标签: JavaScript

## 简介

--- > 这是一个基于发布订阅模式的消息队列框架,可用于`react`做组件间的事件通知.最好是没有任何关系并且不存在数据交互的事件通知,因为有数据的事件通知将会导致数据流的混乱.当然用于有数据传输的事件通知也没有什么不可,这个小框架也是具备这个功能的,哈哈!!
