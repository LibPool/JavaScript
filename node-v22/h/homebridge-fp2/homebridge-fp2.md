# homebridge-fp2

> 标签: aqara, fp2, hap, homebridge-plugin, mmwave, occupancy, presence

## 简介

Homebridge plugin for the Aqara Presence Sensor FP2 — exposes the main occupancy sensor, light level, and per-zone occupancy via HAP-over-WiFi.
