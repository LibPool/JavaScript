# homebridge-globalcache-gc100-kiro

> 标签: audio, gc100, global cache, globalcache, homebridge-plugin, ip2sl, ir, itach, multi-room, multiroom, rs232, s6.2, systemline, volume

## 简介

Homebridge plugin for controlling the Systemline S6.2 multi-room audio system via a Global Cache iTach IP2SL RS232 interface. Exposes zones as HomeKit switches and volume sliders. Built with Kiro AI.
