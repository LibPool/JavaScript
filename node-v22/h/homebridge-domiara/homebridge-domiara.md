# homebridge-domiara

> 标签: domiara, homebridge-plugin, homekit, smart-home, touchwand, wanderfull

## 简介

Homebridge plugin that brings TouchWand smart-home devices to Apple Home + Siri, using Domiara's field-tested LAN transport. Independent, third-party — not affiliated with TouchWand.
