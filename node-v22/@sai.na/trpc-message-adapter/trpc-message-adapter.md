# @sai.na/trpc-message-adapter

> 标签: JavaScript

## 简介

`@sai.na/trpc-message-adapter` 是一个用于通过消息传递实现 [tRPC](https://trpc.io/) 通信的适配器。它提供了灵活的接口，允许用户对接任意使用场景，只需实现数据收发的通道即可。
