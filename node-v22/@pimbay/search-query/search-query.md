# @pimbay/search-query

> 标签: adapter, cursor, pagination, search-terms, typescript

## 简介

Framework-agnostic, strict search/pagination contracts (page, slice, cursor) with no runtime magic — a foundation for datasource-specific extensions, starting with Drizzle.
