# @brillout/fetch

> 标签: JavaScript

## 简介

The `@brillout/fetch` package uses: - The browser built-in `window.fetch` if run in the browser. - The NPM package [`node-fetch`](https://github.com/bitinn/node-fetch) if run in Node.js.
