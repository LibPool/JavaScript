# n8n-nodes-labelixa

> 标签: barcode, cpcl, epl, label, n8n-community-node-package, thermal-printer, tspl, zebra, zpl

## 简介

n8n community node for Labelixa: render, validate and convert ZPL, EPL, TSPL and CPCL label code, and generate barcodes, without a printer.

## 官网

- 官网：https://labelixa.com
