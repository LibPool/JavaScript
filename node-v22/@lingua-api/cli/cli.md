# @lingua-api/cli

> 标签: JavaScript

## 简介

The `lingua` binary: keeps your app's translation catalogs in sync with the source-locale catalog by machine-translating through the Lingua API. Supports next-intl, react-intl, i18next and vue-i18n. Node 22+.
