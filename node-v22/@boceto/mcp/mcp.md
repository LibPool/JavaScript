# @boceto/mcp

> 标签: ai-tools, boceto, claude, cursor, mcp, model-context-protocol, wireframe

## 简介

MCP server for Boceto. Exposes parse, lint, fix, render-svg, and catalog tools — plus the full skill + spec as MCP resources — so any AI client (Claude Desktop, Cursor, Cline, etc.) gains a runtime feedback loop for authoring Boceto wireframes.
