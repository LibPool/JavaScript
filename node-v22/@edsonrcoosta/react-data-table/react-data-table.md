# @edsonrcoosta/react-data-table

> 标签: datatable, pagination, popover, react, table, tailwind

## 简介

Tabela reutilizável com colunas dinâmicas, ações por linha via Popover, paginação (controlada e não), estilizada com TailwindCSS.
