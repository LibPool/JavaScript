# @marcocavanna/mailbridge

> 标签: email, imap, macos, mbsync, mcp, model-context-protocol, notmuch, smtp

## 简介

MCP server for IMAP/SMTP mailboxes: read, search, organize, draft and send mail from an AI assistant. Passwords stay in the macOS Keychain and mail is never deleted.
