# @sal7one/dsh-design-studio

> 标签: deepseek-harness, design-gallery, design-studio, design-system, design-tokens, dsh, dsh-plugin, openrouter, style-atlas, ui-mockup

## 简介

Persistent Design Studio plugin for DeepSeek Harness: the design_studio agent tool, a /design-studio live-preview route + JSON API, identity presets, an attributed 88-style design atlas, content-addressed edit history with undo/restore, OpenRouter vision
