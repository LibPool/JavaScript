# @query.shop/node-sdk

> 标签: JavaScript

## 简介

Esta biblioteca oferece aos desenvolvedores uma coleção descomplicada de funcionalidades para facilitar a integração a API da Query Shop em seu site, permitindo a exibição e venda de produtos cadastrados no nosso Dashboard.

- 源码仓库：git+https://github.com/queryshop/node-sdk.git
