# @ray1270/dsh-task-stack

> 标签: agent, context-compaction, cordis, deepseek-harness, dsh, dsh-plugin, focus, task-stack

## 简介

A persistent multi-step task stack for DeepSeek Harness agents: focus_task / focus_complete / read_focus plus a /focus command, with zero automatic prompt injection
