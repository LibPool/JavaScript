# @zakadi/protocol

> 标签: biometrics, identity-verification, liveness, protocol, zakadi

## 简介

The Zakadi wire protocol (zakadi.v1) for the face-liveness SDKs: JSON Schemas, message types, standalone validators, conformance vectors and shared constants.
