# @remcp/runtime

> 标签: filesystem, mcp, model-context-protocol, remcp, remote, self-hosted, terminal

## 简介

First-party ReMCP local device runtime: filesystem, terminal, computer-use, browser, diagnostics and document tools over MCP.
