# @nayaverse/glyphcheck

> 标签: accessibility, arabic, cdp, ci, cjk, devanagari, font-fallback, fonts, i18n, indic, internationalization, l10n, playwright, rtl, testing, thai, typography

## 简介

Find the text faults nobody can see in a script they cannot read: silent font fallback, colliding lines, clipped glyphs, broken joins, missing direction.
