# @tetherto/wdk-protocol-bridge-usdt0-evm

> 标签: bridge, erc-4337, ethereum, protocol, usdt0, wdk

## 简介

A simple package that lets @tetherto/wdk-wallet-evm and wallet-evm-erc-4337 wallet accounts interact with the usdt0 protocol.
