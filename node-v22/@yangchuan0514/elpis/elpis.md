# @yangchuan0514/elpis

> 标签: JavaScript

## 简介

elpis的设计初衷是为了解决重复性的增删改查工作，将常规的增删改查沉淀到模型中，通过模型解析器解析模型配置，加上模型数据渲染组件将数据渲染到页面，并且支持常规交互。
