# @pepperui/tokens

> 标签: design-system, design-tokens, dtcg, mobupps, pepper-ui

## 简介

Pepper UI design tokens — the Mobupps design system. One source, seven outputs: CSS, SCSS, a Tailwind v3 preset, a Tailwind v4 theme, the shadcn variable map, Figma-import JSON and a Python module.
