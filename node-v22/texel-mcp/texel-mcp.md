# texel-mcp

> 标签: ai-agents, claude, mcp, minecraft, model-context-protocol, pixel-art, skin, texture

## 简介

MCP server and CLI that compile Minecraft skins and textures from JSON specs (palette + drawing ops) to PNG, with a review an AI agent can act on.
