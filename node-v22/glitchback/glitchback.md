# glitchback

> 标签: autofix, bug-report, bug-tracker, error-reporting, feedback, github, next, nextjs, react, triage, widget

## 简介

A "Report a problem" button that also reports failed requests and uncaught errors automatically, triages them, opens GitHub issues and suggests fixes as reviewable PRs. Setup: npx glitchback init
