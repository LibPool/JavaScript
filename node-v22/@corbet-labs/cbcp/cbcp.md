# @corbet-labs/cbcp

> 标签: bcp47, cbcp, i18n, locale, rust, typescript

## 简介

Deterministic BCP 47 locale-ID casting and vendor code mapping. No models, no I/O: same input always yields the same output. Mirrors the cbcp Rust crate release line.
