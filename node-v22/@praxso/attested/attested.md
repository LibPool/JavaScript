# @praxso/attested

> 标签: ai-agents, attestation, coding-agents, ctrf, github-actions, in-toto, playwright, provenance, sigstore, slsa, supply-chain, test-results

## 简介

Signed, verifiable test receipts for agent-authored pull requests: wraps Playwright or any CTRF test run into an in-toto receipt signed with Sigstore via GitHub artifact attestations.
