# @codehornets/ccpatch

> 标签: anthropic, bundle, claude, claude-code, cli, patch, unminify

## 简介

A patch framework for the official Anthropic Claude Code CLI — extract, unminify, and apply JavaScript-level patches to add features, fix bugs, and expose internals.
