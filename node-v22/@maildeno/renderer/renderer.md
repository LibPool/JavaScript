# @maildeno/renderer

> 标签: browser, cloudflare-workers, edge, email, html, maildeno, mjml, offline, react-email, render, template, vercel-edge, wasm, webassembly

## 简介

Render Maildeno email templates locally to HTML, MJML or React Email — in Node, browsers, and edge runtimes like Cloudflare Workers and Vercel Edge. No API calls, no network.
