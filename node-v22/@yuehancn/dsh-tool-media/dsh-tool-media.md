# @yuehancn/dsh-tool-media

> 标签: audio, compress, deepseek-harness, dsh-plugin, ffmpeg, media, thumbnail, transcode, video

## 简介

Run ffmpeg from DeepSeek Harness: probe a file, transcode it, extract frames or audio, and compress video to a target size.
