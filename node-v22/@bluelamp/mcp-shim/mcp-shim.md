# @bluelamp/mcp-shim

> 标签: bluelamp, cloud-proxy, mcp, shim

## 简介

BlueLamp 共通 MCP shim: manifest.json を読んで stdio MCP server を立て、tool 呼び出しを portal /api/cli/mcp-dispatch にフォワードする薄いランナー

## 官网

- npm 页面：https://www.npmjs.com/package/@bluelamp/mcp-shim

- 1.0.0

## 获取地址

- npm 安装：`npm install @bluelamp/mcp-shim`
- npm registry：https://registry.npmjs.org/@bluelamp/mcp-shim
- Node 要求：>=18
