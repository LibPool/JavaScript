# @corelibraries/nest-auth

> 标签: auth, authentication, guards, jwt, mongodb, mongoose, nestjs, rbac

## 简介

Simple, secure, drop-in JWT authentication for NestJS + MongoDB. It is a library, not a server: it runs in-process inside your app.
