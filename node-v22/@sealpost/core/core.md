# @sealpost/core

> 标签: deliverability, dkim, email, email-templates, mime, rfc6376, smtp, transactional-email, web-crypto

## 简介

Zero-dependency email engine: block-based template compiler, pre-flight deliverability gate, MIME, RFC 6376 DKIM signing and verification, suppression handling and signed delivery receipts. Node 20+, edge runtimes and browsers.
