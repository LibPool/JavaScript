# @dindocloud/assistant-widget

> 标签: agent, assistant, chat, ddysq, web-component, widget

## 简介

点枢启元（ddysq）AI 智能助手浮窗组件：可嵌入任意站点，支持个人 API Key 与企业密钥（租户+手机号）两种接入模式。功能与官网全局助手一致（流式对话 / 历史会话 / 附件 / 语音输入 / 回复朗读 / 猜你想问 / Markdown+图表）。
