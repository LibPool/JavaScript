# @mmmbuto/masix

> 标签: ai, android, cron, mcp, messaging, stt, telegram, termux

## 简介

Termux-first MIT automation runtime for Android/Termux; Linux/macOS supported via source builds and Homebrew; bundled plugin-base packages auto-install or auto-build as needed
