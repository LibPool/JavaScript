# @dsh-io/dsh-arm64-install

> 标签: JavaScript

## 简介

Thin installer for the official dsh-arm64 deployment package (DeepSeek Harness for Linux aarch64). Downloads, verifies sha256 and unpacks the GitHub Release artifact.

## 官网

- npm 页面：https://www.npmjs.com/package/@dsh-io/dsh-arm64-install

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- npm 安装：`npm install @dsh-io/dsh-arm64-install`
- npm registry：https://registry.npmjs.org/@dsh-io/dsh-arm64-install
- Node 要求：>=18
