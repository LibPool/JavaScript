# @axacraft-global/zeitcore-sdk

> 标签: JavaScript

## 简介

Zeitcore SDK is a lightweight JavaScript/TypeScript library designed to interact with Zeitcore's API. It provides an easy-to-use interface for managing rulesets and handling API requests.
