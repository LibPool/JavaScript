# @wasm-zoo/ghostscript

> 标签: browser, conversion, document, ghostscript, pdf, postscript, wasm, wasm-zoo, webassembly

## 简介

Ghostscript 10.08.0 compiled for browser WebAssembly by WASM Zoo, with Consumer API v1 and bundled runtime assets.
