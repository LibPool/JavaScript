# @spcsn/taro-mini-runner

> 标签: JavaScript

## 简介

`@spcsn/taro-mini-runner` 是 `@spcsn/taro-cli` 在小程序端调用的构建执行器。它接收 service 层传入的上下文，把页面、组件、模板、样式和静态资源组织成微信小程序可运行的产物。
