# @seekrit/openclaw-plugin

> 标签: api-keys, encryption, openclaw, openclaw-plugin, secretref, secrets, zero-knowledge

## 简介

seekrit for OpenClaw — resolve exec SecretRefs from end-to-end encrypted secrets, so the gateway config holds no plaintext and the seekrit API never sees one.
