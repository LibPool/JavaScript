# @kewab/dsh-file-drop

> 标签: composer, cordis, deepseek-harness, drag-and-drop, dsh, dsh-plugin, reference, workspace-files

## 简介

DeepSeek Harness plugin: drag a file or folder out of the Workspace Files tree onto the composer to insert the same @ reference the @ menu inserts.
