# @zenodev/voltron

> 标签: JavaScript

## 简介

Voltron is a lightweight React form library designed for flexibility and ease of use. With Voltron, you can build forms using pre-built components or use your custom inputs. Voltron also integrates seamlessly with Zod for schema validation and TailwindCSS
