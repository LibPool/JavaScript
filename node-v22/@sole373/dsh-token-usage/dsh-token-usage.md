# @sole373/dsh-token-usage

> 标签: analytics, cache, dsh, dsh-plugin, leaderboard, token, usage

## 简介

Token usage analytics for DeepSeek Harness: scans the host's own session logs and reports consumption by provider and model, cache hit rates, daily trends and a capability leaderboard for every model you can currently call.
