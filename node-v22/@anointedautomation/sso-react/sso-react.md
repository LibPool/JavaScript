# @anointedautomation/sso-react

> 标签: anointed-automation, nextjs, oidc, react, remix, sign-in, sso, vite

## 简介

Sign in with Anointed Automation for React: an accessible brand-styled sign-in button and a useAnointedSignIn hook that send the browser to your server's start route. No secrets client side.
