# @anointedautomation/sso

> 标签: anointed-automation, base44, deno, express, nextjs, oauth2, oidc, openid-connect, pkce, sign-in, sso

## 简介

Sign in with Anointed Automation: a dependency-free OpenID Connect client (authorization code + PKCE) for Node 18+, Deno and edge runtimes, with Express and Web (Next.js, Base44) adapters.
