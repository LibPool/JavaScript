# @motionscript/math

> 标签: animation, latex, math, motion script, motion-script

## 简介

Math for Motion Script: coordinate systems, function and vector-field plots, 3D graphs and surfaces, network graphs, and LaTeX formulas typeset to glyph paths that morph token by token.
