# @motionscript/headless

> 标签: JavaScript

## 简介

Render Motion Script projects to images and video from Node, through the browser engine in a headless Chromium page.

## 官网

- 官网：https://motionscript.dev
- 源码仓库：git+https://github.com/motionscript-dev/motionscript.git
- npm 页面：https://www.npmjs.com/package/@motionscript/headless
