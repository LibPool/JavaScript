# voxlingua107

> 标签: audio, browser, bun, ecapa-tdnn, language-detection, language-identification, onnx, speech, speechbrain, spoken-language, voxlingua107, webassembly

## 简介

Spoken language identification (107 languages) for Node.js, Bun and the browser. SpeechBrain's VoxLingua107 ECAPA-TDNN on ONNX Runtime, no Python.
