# @namics/remlog-browser-client

> 标签: @namics/remlog, debug, logging, node, remlog, remote, remotely, server, transport

## 简介

The browser clients helps you creating remote logs inside any browser (supports IE7+, Chrome, Firefox and Safari) by creating an image tag and appending it to the body of your website. It is recommended to add the package to your build or use a CDN like u
