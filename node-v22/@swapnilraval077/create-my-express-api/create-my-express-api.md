# @swapnilraval077/create-my-express-api

> 标签: boilerplate, cli, express, express-generator, generator, jwt, mongodb, mongoose, rest-api, scaffold

## 简介

Zero-dependency CLI that scaffolds a production-oriented Node.js + Express 5 + MongoDB REST API (JWT auth, Multer uploads, Nodemailer + EJS emails, Zod validation, Winston/Morgan logging, Jest tests).
