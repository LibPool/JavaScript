# @rynger/mcp

> 标签: ai-calls, mcp, model-context-protocol, outbound, rynger, voice-agent

## 简介

MCP server for Rynger — your personal AI outbound-call agent. A thin client over Rynger's HTTP API: place one-off calls, schedule them, manage phone numbers, and handle billing from any MCP host.
