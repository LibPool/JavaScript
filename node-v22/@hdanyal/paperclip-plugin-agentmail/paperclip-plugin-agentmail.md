# @hdanyal/paperclip-plugin-agentmail

> 标签: agentmail, email, paperclip, plugin, third-party

## 简介

AgentMail → Paperclip: webhooks create issues with attachments; inbox-scoped REST tools. Independent third-party plugin (not tied to any employer org).
