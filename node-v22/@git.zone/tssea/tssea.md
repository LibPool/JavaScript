# @git.zone/tssea

> 标签: binary, build-sea, cli, cross-compile, native addons, node.js, node:sea, sea, single executable application, typescript

## 简介

Builds Node.js single executable applications for linux, macOS and Windows from one host: pinned and verified Node.js binaries, per-target native addons, embedded asset trees, smoke runs, size guards and third-party notices.
