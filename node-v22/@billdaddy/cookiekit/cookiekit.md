# @billdaddy/cookiekit

> 标签: cookie, cookies, http, parse, partitioned, rfc6265, samesite, serialize, set-cookie, typescript, zero-dependency

## 简介

Tiny, type-safe HTTP cookie parse and serialize — RFC 6265 with SameSite, Partitioned, and Priority. Zero dependencies.
