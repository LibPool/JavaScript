# @billdaddy/queuekit

> 标签: abortsignal, async, backpressure, concurrency, p-queue-alternative, priority, promise, queue, task-queue, throttle, typescript, zero-dependency

## 简介

Tiny, type-safe async task queue — concurrency limit, priority, pause/resume, onIdle/onEmpty drain, and AbortSignal. Zero dependencies.
