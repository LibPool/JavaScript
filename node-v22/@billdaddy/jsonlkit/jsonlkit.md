# @billdaddy/jsonlkit

> 标签: batch, json-lines, jsonl, jsonlines, llm, logs, ndjson, parser, readablestream, serialize, stream, zero-dependency

## 简介

Stream-friendly NDJSON / JSON Lines parsing and serialization for strings, ReadableStreams, and async iterables. Zero dependencies.
