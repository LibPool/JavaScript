# @billdaddy/qskit

> 标签: array-format, parse, qs, query-string, querystring, querystring-parser, search-params, stringify, typescript, url, zero-dependency

## 简介

Tiny, type-safe query string parse and stringify — array formats (bracket/index/comma/repeat) and number/boolean coercion. Zero dependencies.
