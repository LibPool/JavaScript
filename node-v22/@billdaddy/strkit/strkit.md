# @billdaddy/strkit

> 标签: capitalize, center, dedent, ellipsis, escape-html, escape-regexp, string, template, truncate, typescript, zero-dependency

## 简介

Tiny, type-safe string utilities — truncate, template, escapeHtml/escapeRegExp, dedent, center, and prefix/suffix helpers. Zero dependencies.
