# @billdaddy/fsmkit

> 标签: finite-state-machine, fsm, state, state-machine, transitions, typescript, zero-dependency

## 简介

Lightweight zero-dependency finite state machine with full TypeScript support. Simple alternative to xstate/javascript-state-machine.
