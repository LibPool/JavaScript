# @fit2cloud-ui/vue-virtual-tree

> 标签: bigdata, dynamic, largedata, lazy loading, tree, virtual, vue

## 简介

基于Element-ui和vue-virtual-scroller实现的Vue2版本的虚拟树形组件，支持固定高度和动态高度两种模式
