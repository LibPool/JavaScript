# @cescofors/toonjs

> 标签: aggregation, analysis, correlation, data, dataframe, etl, manipulation, performance, pipeline, ranking, statistics, tabular, timeseries, toon, typescript

## 简介

High-performance TypeScript library for tabular data manipulation with 100+ optimized methods. Powered by Float64Array Columnar Architecture. Zero dependencies.
