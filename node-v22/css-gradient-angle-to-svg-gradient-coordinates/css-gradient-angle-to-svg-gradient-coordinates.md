# css-gradient-angle-to-svg-gradient-coordinates

> 标签: JavaScript

## 简介

Converts a CSS gradient's angle in degrees to a an SVG gradient's coordinates (x1/y1/x2/y2) to produce a linear gradient of the same angle.
