# @dasimems/react-native-svga

> 标签: android, animation, expo, gift-animation, ios, lottie-alternative, nitro-modules, react-native, react-native-svg, react-native-svga, sprite-animation, svga, svga-player, svgaplayer, vector-animation

## 简介

Fast, secure SVGA animation player for React Native and Expo. Nitro-powered, with streaming, disk + memory caching, and built-in/external audio. A lightweight Lottie alternative for vector & sprite animations.
