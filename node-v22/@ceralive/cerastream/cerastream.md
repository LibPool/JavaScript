# @ceralive/cerastream

> 标签: ceralive, cerastream, gstreamer, ipc, json-rpc, schema, srt, srtla

## 简介

Type-safe TypeScript schema + IPC client for the cerastream streaming engine (JSON-RPC 2.0 / NDJSON over a Unix domain socket).
