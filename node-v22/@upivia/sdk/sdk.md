# @upivia/sdk

> 标签: agent-governance, agentwallet, ai-agents, approvals, budgets, sdk, typescript, upivia, workflows

## 简介

TypeScript SDK for Upivia — the controlled-execution platform for autonomous AI agents: service requests, budgets, approvals, workflows, chat streaming, triggers, storage, and knowledge.
