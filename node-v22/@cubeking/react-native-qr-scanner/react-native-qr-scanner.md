# @cubeking/react-native-qr-scanner

> 标签: react-native-camera, react-native-qr-scanner, react-native-qrcode

## 简介

react native qrcode scanner. support 0.60.0, pod install, react-native的二维码扫描组件，支持扫描区域的限制以及扫描区域的偏移
