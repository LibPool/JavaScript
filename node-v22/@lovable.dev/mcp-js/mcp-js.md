# @lovable.dev/mcp-js

> 标签: lovable, mcp, model-context-protocol, tanstack, vite

## 简介

Author MCP servers for Lovable apps. Declare tools with defineTool, register them in defineMcp, and a framework adapter (TanStack or Supabase Edge Functions) emits the route(s) at build time.
