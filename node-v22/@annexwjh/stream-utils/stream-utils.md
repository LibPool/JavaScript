# @annexwjh/stream-utils

> 标签: JavaScript

## 简介

- `MultiReadStream` - `多级可读流`的作用是将多个可读流合并为一个可读流 - `MultiWriteStream` - `多级可写流`的作用是将多个可写流合并为一个可写流
