# @here.build/plexus-vfs

> 标签: JavaScript

## 简介

Plexus-backed virtual filesystem — a drop-in `fs` for isomorphic-git. File content is stored directly as a CRDT-synced `Uint8Array` field, so arbitrary binary round-trips faithfully.
