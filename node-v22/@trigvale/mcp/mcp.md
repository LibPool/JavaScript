# @trigvale/mcp

> 标签: agent, claude, claude-code, cursor, founder, idea-validation, mcp, model-context-protocol, startup, trigvale

## 简介

MCP server for Trigvale — validate startup ideas before your build agent scaffolds code. One tool: validate_idea, returns 10-dimension scorecard + kill/pivot/test/build verdict + live evidence.
