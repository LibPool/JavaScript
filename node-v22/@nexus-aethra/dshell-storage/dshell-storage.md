# @nexus-aethra/dshell-storage

> 标签: JavaScript

## 简介

dshell storage engines: the mediums behind the std storage contract. Currently a SQLite command-history store on Node's built-in node:sqlite, so there is no native dependency and no install script; host-only, never imported by a client bundle.
