# @xovris/node

> 标签: JavaScript

## 简介

Xovris for Node.js servers: errors from the wizard-written variables, process handlers that keep Node's own failure behaviour, and OTLP traces that join an existing OpenTelemetry setup instead of starting a second one (ADR 0011, D01.02.01).
