# @oselvar/var-language

> 标签: JavaScript

## 简介

Static analysis for Vár step definitions and specs: a TypeScript-based scanner that discovers step definitions and custom parameter types, and a workspace indexer that matches specs to step definitions. Used by `@oselvar/var-lsp` and the website.
