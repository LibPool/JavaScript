# @oselvar/var-lsp

> 标签: JavaScript

## 简介

The Language Server Protocol server for Vár — diagnostics, semantic tokens, and rename support for `.md` specs and their step definitions. Consumed by editor extensions such as `@oselvar/var-vscode`.
