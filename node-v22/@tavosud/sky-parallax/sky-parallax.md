# @tavosud/sky-parallax

> 标签: accessibility, animation, intersection-observer, parallax, performance, react, scroll, typescript

## 简介

Lightweight React parallax component with zero dependencies. Scroll-driven motion using CSS custom properties and IntersectionObserver for maximum performance.
