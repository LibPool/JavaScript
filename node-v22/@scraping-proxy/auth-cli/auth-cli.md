# @scraping-proxy/auth-cli

> 标签: JavaScript

## 简介

CLI tool that captures browser authentication state (cookies, localStorage) for use with `@scraping-proxy/client`.

## 官网

- npm 页面：https://www.npmjs.com/package/@scraping-proxy/auth-cli
