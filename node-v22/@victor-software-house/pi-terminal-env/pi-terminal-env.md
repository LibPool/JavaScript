# @victor-software-house/pi-terminal-env

> 标签: env, iterm2, pi, pi-package, terminal, tmux

## 简介

Tiny zero-dep helpers to detect the terminal emulator pi is running in (iTerm2, tmux, etc.). Pure env-var probes, no I/O.
