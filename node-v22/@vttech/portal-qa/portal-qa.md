# @vttech/portal-qa

> 标签: azure-devops, ci, dsh, playwright, portal-qa, qa, report, summary

## 简介

Lightweight, install-anywhere QA summary renderer, memory hooks, and HTTP server. Same renderer that powers ~/.dsh/, now publishable to npm, GitHub Packages, or any private registry.
