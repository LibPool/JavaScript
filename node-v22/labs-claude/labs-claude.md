# labs-claude

> 标签: anthropic, claude-code, cli, elevenlabs, proxy

## 简介

Run the real Claude Code CLI on ElevenLabs models (GPT-6 Astra, Opus 5.5, Gemini, GLM...) with your own ElevenLabs key — like Ollama, but for ElevenLabs.
