# @christianpasinrey/vue-code-parser

> 标签: barcode, composable, datamatrix, ean, gs1, qr, vue, vue3

## 简介

Composable para Vue 3 que permite detectar, validar y parsear códigos de barras EAN, DataMatrix y QR (GS1).
