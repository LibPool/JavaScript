# @starbeam/renderer

> 标签: JavaScript

## 简介

`@starbeam/renderer` is the adapter-author kit for implementing Starbeam in a framework renderer. App code should normally install a framework package such as `@starbeam/react`, `@starbeam/preact`, `@starbeam/vue`, or the framework-neutral `@starbeam/univ
