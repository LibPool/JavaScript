# @dahibe/tictactoe

> 标签: javascript, ta, tac, te, ti, tic, toe

## 简介

Es un modulo de un juego entre el usuario y el computador, mientras que el usuario marca "O" el computador marca una "X", cuando uno de los dos haya completado de "O" o de "X" de forma vertical, horizontal o diagonal gana la partida.
