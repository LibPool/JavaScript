# @npmsh-corp/codex-acct

> 标签: account, auth, chatgpt, cli, codex, openai, switcher

## 简介

Switch between multiple OpenAI Codex (ChatGPT) accounts by swapping ~/.codex/auth.json — like nvm, but for Codex logins.
