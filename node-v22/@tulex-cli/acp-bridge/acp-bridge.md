# @tulex-cli/acp-bridge

> 标签: JavaScript

## 简介

Shared ACP bridge primitives (EventBus, AcpChannel, in-memory channel, PermissionMediator interface) used by qwen serve, channels, IDE, TUI, and remote-control adapters.
