# @ddd-ts-kit/kernel

> 标签: aggregate, clean-architecture, cqrs, ddd, domain-driven-design, domain-events, hexagonal-architecture, ports-and-adapters, typescript, unit-of-work, value-object

## 简介

Framework-agnostic Domain-Driven Design (DDD) building blocks for TypeScript: aggregates, entities, value objects, domain events, CQRS command and query buses, unit of work and application ports, with an in-memory event bus.
