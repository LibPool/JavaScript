# @entyrix/mcp

> 标签: business-intelligence, business-registry, company-data, entyrix, eu, europe, kyb, llm-tools, mcp, model-context-protocol

## 简介

Model Context Protocol stdio bridge for Entyrix, the European business-registry (KYB) data platform. Forwards to the remote server https://entyrix.com/mcp/v1 (company search, briefs, financials, ownership, KYB/AML screening across 23 European registries)
