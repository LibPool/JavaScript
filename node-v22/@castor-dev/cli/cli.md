# @castor-dev/cli

> 标签: castor, chromecast, dlna, google-cast, hls, iptv, m3u8, roku, samsung, self-hosted, termux

## 简介

Cast video from any web page to Chromecast, DLNA, Roku and Samsung TVs, with live transcoding and subtitles
