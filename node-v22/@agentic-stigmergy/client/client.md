# @agentic-stigmergy/client

> 标签: JavaScript

## 简介

Loop-side client transport for Stigmergy: consult a warm daemon over a socket (ADR-12, ADR-20, FEAT-04-08), with a fallback to the local engine when the daemon is unreachable.
