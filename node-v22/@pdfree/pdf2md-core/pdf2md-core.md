# @pdfree/pdf2md-core

> 标签: ai, llm, markdown, pdf, pdf-to-markdown, pdfjs, rag

## 简介

Convert PDF to Markdown for AI/RAG — the same extraction engine behind pdfree.io's browser tool, runnable locally. Your files never leave your machine.
