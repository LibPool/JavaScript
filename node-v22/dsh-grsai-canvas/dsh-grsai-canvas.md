# dsh-grsai-canvas

> 标签: annotation, canvas, dsh, dsh-plugin, gpt-image, grsai, image-editing, nano-banana

## 简介

DSH 右侧栏「画布」插件:无限画布 + 直接在图上标注 + 接 GrsAI(gpt-image-2 / nano-banana)按标注改图,结果放在原图旁边对比,画布自动存到工作区
