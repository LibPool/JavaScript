# @kealthas-dev/opencode-llm-review-gate

> 标签: JavaScript

## 简介

llm-review-gate.ts opencode plugin (gates bash tool calls behind an LLM safety review before they run, via a real review_verdict function-call tool with a text-parsing fallback), published to npm so opencode's own npm-plugin loader can install it directly
