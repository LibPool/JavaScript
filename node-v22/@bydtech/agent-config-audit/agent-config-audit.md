> 标签: agent-security, agent-skills, agents-md, ai-agents, claude-code, cli, copilot, cursor, lockfile, mcp, owasp, sarif, static-analysis

## 简介

List everything in a repo that an AI coding agent will load or run (hooks, MCP servers, skills, plugins, rules files, env overrides), flag what is risky against the OWASP Agentic Skills Top 10, and lock it so later changes show up in review. Offline; neve
