# @bydtech/port-audit

> 标签: asvs, cli, cors, csp, dast, junit, localhost, owasp, owasp-top-10, sarif, scanner, security, security-headers

## 简介

Point it at your running app on a local port and get, in seconds, the security problems visible from outside: headers, cookies, CORS, TLS, exposed files, debug pages, open redirects and vulnerable front-end libraries, mapped to OWASP, with a fix snippet f
