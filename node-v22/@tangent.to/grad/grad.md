# @tangent.to/grad

> 标签: autograd, automatic-differentiation, backpropagation, browser, esm, gradient, reverse-mode

## 简介

Reverse-mode automatic differentiation for JavaScript (ESM): array-valued tape, linear-algebra adjoints (Cholesky, triangular solve, log-determinant). Finite-difference validated.
