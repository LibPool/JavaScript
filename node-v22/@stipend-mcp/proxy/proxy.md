# @stipend-mcp/proxy

> 标签: agentic-payments, authorization-proxy, mcp, mcp-proxy, stipend

## 简介

Transparent MCP proxy for Stipend — runs Stipend.authorize on every tools/call and forwards to an upstream MCP server.
