# dsh-term-glossary

> 标签: deepseek, deepseek-harness, dictionary, dsh, dsh-plugin, explain, glossary, harness-plugin, selection, term, tooltip, 划词, 术语

## 简介

Select a term in a DeepSeek Harness conversation and read its explanation in place — meaning, purpose, usage — with the token cost of that answer shown. · 选中对话里的术语就地解释（基本含义 / 用途 / 用法），并显示本次 token 用量。
