# @starci/vitest-preset

> 标签: JavaScript

## 简介

The StarCi vitest configs for Next front ends: one workspace lane per app or package (jsdom, HeroUI and React deduped) and one root config that writes a single coverage/lcov.info matching the Sonar denominators.
