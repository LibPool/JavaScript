# @odatano/dpp-sdk

> 标签: battery-passport, blake2b, digital-product-passport, dpp, espr, merkle, zero-knowledge

## 简介

Chain-agnostic Digital Product Passport domain SDK: product profiles, canonical hashing, payload projection, access levels, merkle proofs, lifecycles, ZK claim planning. Ships an EU Battery Regulation profile.
