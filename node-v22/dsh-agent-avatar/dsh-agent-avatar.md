# dsh-agent-avatar

> 标签: avatar, brand, deepseek-harness, dsh, dsh-bundle, dsh-plugin, favicon, sidebar

## 简介

Put your own image where the DSH Web GUI's sidebar brand mark goes (client half, sidebar.brand.mark) and override the page favicon (host half via webServer.tapIndex). Ships default icons in lib/; set config.iconPath to use your own PNG.
