# dsh-memory-guard

> 标签: compaction, deepseek, dsh, dsh-plugin, harness, memory, oom, session-log, vacuum

## 简介

Host memory and session-log guard for DeepSeek Harness: tracks heap and per-session log bytes, rejects oversized tool arguments, alerts on huge persisted payloads, and vacuum-shrinks bloated cold session logs.
