# docusaurus-plugin-myog

> 标签: docusaurus, docusaurus-plugin, og-image, open-graph, social-card, twitter-card

## 简介

Adds a MyOG.social og:image and twitter:image to every Docusaurus page, generated from each page's URL

## 官网

- 官网：https://myog.social/docs/docusaurus
- 源码仓库：git+https://github.com/MyOG-social/docusaurus-plugin-myog.git
