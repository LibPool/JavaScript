# @rqml/opencode

> 标签: drift, opencode, plugin, requirements, rqml, spec-first, traceability

## 简介

Make opencode code from requirements, not guesswork: anchor every session on the spec, hard-gate edits to unapproved-requirement code at the tool boundary, and surface the deterministic rqml check verdict (CI authoritative).
