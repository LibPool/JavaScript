# @zoah/dsh-trace

> 标签: agent, dashboard, deepseek-harness, dsh, observability, tracing

## 简介

Aggregate observability dashboard for DeepSeek Harness sessions: decode every session.jsonl.zstd and render tokens/tools/errors/latency as one HTML report.
