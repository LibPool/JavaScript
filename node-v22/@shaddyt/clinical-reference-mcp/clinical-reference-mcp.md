# @shaddyt/clinical-reference-mcp

> 标签: drug-reference, healthcare-ai, mcp, model-context-protocol, openfda, pharmacology, rxnav, rxnorm

## 简介

MCP server exposing drug, prescription, and pharmacology reference tools sourced from authoritative public APIs (openFDA, RxNorm/RxNav). Developer reference, not for clinical use.
