# @audio/synth-modal-fit

> 标签: audio, bell, cymbal, dsp, fit, matrix-pencil, modal, modes, percussion

## 简介

Modal snapshot from audio: one strike → synth-modal's { freq, amp, modes: [{ ratio, gain, t60 }] } (subband matrix pencil, least-squares amplitudes)
