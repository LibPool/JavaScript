# @audio/eq-fit

> 标签: audio, autoeq, dsp, eq, equalizer, fit, levenberg-marquardt, parametric

## 简介

Fit an N-band parametric EQ (RBJ peaking + shelves) to a target magnitude curve — greedy init + Levenberg–Marquardt refinement
