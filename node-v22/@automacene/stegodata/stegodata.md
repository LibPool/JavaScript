# @automacene/stegodata

> 标签: ai, embeddings, metadata, pdf, steganography

## 简介

Language-agnostic protocol for embedding structured steganographic memory into unstructured files—turning documents, images, and media into self-contained, context-aware containers for AI pipelines.
