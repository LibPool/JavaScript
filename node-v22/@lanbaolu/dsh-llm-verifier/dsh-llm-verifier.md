# @lanbaolu/dsh-llm-verifier

> 标签: agent, dsh, evaluation, llm-verifier, plugin, reward, verifier

## 简介

LLM-as-a-Verifier bridge for DSH: expose select/compare/track/ProgressTracker as agent tools via a Python stdio bridge (reuses the official llm-verifier package).
