# @kkoms/pxtorem

> 标签: JavaScript

## 简介

`@kkoms/pxtorem` is a typescript library for calculating px value to rem. rootPx is calculated based on `getComputedStyle(document.documentElement).fontSize`. Update its value when visibility changes.
