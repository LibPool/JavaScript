# @satlayer/cosmwasm-schema

> 标签: JavaScript

## 简介

A utility package with generated TypeScript type definitions (.d.ts files) from CosmWasm smart contract JSON schemas. This package automatically converts CosmWasm contract schemas into TypeScript type definitions, enabling type-safe interactions with SatL
