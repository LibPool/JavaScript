# dsh-plugin-rtl-text

> 标签: arabic, bidi, cordis, deepseek, deepseek-harness, dsh, persian, plugin, right-to-left, rtl, unicode-bidi

## 简介

DeepSeek Harness plugin that fixes RTL/LTR bidi rendering in chat: per-block direction for Persian and Arabic messages with embedded English, plus list markers and quote bars that follow their text
