# @invisra/rendezvous-server

> 标签: JavaScript

## 简介

Batteries-included server layer for Rendezvous: route-handler factories, a pluggable ThreadStore interface, request validation, security-header responses, admin auth, and rate limiting — built on @invisra/rendezvous-core and the Web-standard Request/Respo
