# @zf-uni-helper/navigate-to

> 标签: JavaScript

## 简介

`@zf-uni-helper/navigate-to` 是一个用于 UniApp 的导航工具包，旨在简化页面跳转和路径处理。它支持多种路径类型，并允许用户自定义路径规则，以满足特定需求。
