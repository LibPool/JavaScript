# @noxfly/noxus

> 标签: dependency-injection, electron, framework, ipc, lazy-loading, nodejs, nox, noxus, standalone, typescript

## 简介

Lightweight HTTP-like IPC framework for Electron with standalone controllers, explicit DI, and lazy route loading. No reflect-metadata required.
