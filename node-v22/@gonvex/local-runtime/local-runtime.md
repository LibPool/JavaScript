# @gonvex/local-runtime

> 标签: JavaScript

## 简介

The generated Gonvex client executes an interactive Reducer's existing TypeScript body in a browser worker. Applications define argument/result schemas and `run`; they do not maintain a separate optimistic handler or effects list.
