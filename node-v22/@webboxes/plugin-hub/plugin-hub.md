# @webboxes/plugin-hub

> 标签: JavaScript

## 简介

Saving, sharing and pulling Cordis plugins: dotted plugin names, the source argument, deterministic packing with sha512, the local plugin store, and the pull pipeline. Host-independent: no Cordis, DSH or surface dependencies.
