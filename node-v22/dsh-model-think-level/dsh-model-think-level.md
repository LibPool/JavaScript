# dsh-model-think-level

> 标签: deepseek-harness, dsh-model-think-level, dsh-plugin, input-modality, llm-settings, modalities, reasoning, reasoning-effort, request-headers, thinking, vision

## 简介

DSH 的第三方模型补齐思考等级：在官方 Models 页每个模型行注入 Thinking 开关和强度/模态编辑器，在输入框模型菜单加供应商→模型选择器、视觉徽章与等级行，并带搜索、拖拽排序、供应商启用开关；以及按路由接管请求头与 user-agent。
