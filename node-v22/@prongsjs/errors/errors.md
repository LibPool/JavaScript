# @prongsjs/errors

> 标签: ai-agents, errors, http, intents, nextjs

## 简介

The Prongs errors profile: what went wrong, told to the caller. Request, auth, permission, record, conflict, limit and failure intents, fail(), and checks for hand-written error responses and leaked error messages.
