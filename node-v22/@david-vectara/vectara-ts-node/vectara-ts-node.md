# @david-vectara/vectara-ts-node

> 标签: sdk, typescript, vectara

## 简介

This is the typescript (Node) implementation of the Vectara SDK for the OpenAPI V2 stubs. Please note, this has the
deprecated dependency on the "request" package due to the OpenAPI typescript-node generator.
