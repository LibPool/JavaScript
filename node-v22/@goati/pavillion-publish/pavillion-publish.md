# @goati/pavillion-publish

> 标签: ci, game, goati, pavillion, publish

## 简介

Publishes a build of your game to Pavillion (GOATi Entertainment) from a script or a CI machine: the publisher the Pavillion desktop app's Studio runs.

## 官网

- 官网：https://pavillionhub.com
- npm 页面：https://www.npmjs.com/package/@goati/pavillion-publish
