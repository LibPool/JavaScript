# @cosydev/react-pdf-exporter

> 标签: pdf, react

## 简介

React PDF Exporter is a module compatible with react that allows export of the DOM in PDF format. This module can keep page styling and includes a configuration system to customize the generated document. It can export any HTML element: text, images, tab
