# @ariankhademi/jwkit

> 标签: authentication, express, jose, jwks, jwt, middleware, oidc

## 简介

JWT / JWKS verification with key-rotation-aware caching and drop-in Express middleware. The TypeScript twin of the jwkit Go module: same checks, same typed errors.
