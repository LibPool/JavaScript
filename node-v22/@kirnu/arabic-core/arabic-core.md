# @kirnu/arabic-core

> 标签: arabic, arabic-normalization, arabic-numbers, currency-to-words, hijri, islamic-calendar, number-to-words, rtl, tafgeet, tashkeel, umm-al-qura

## 简介

Arabic number-to-words (tafgeet) with correct grammar, currency amounts in words, tashkeel removal, Arabic normalisation and Umm al-Qura Hijri dates. No dependencies, no DOM.
