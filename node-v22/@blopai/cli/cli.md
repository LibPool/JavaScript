# @blopai/cli

> 标签: blop, cli, logs, monitoring, observability, opentelemetry, otel, otlp, sqlite, tracing

## 简介

Local-first OpenTelemetry observability CLI for coding agents, with an OTLP collector, SQLite-backed investigation, deterministic audits, and Browser Harness flow verification for local, CI, staging, and deliberate production use.
