# @minhduydev/pi-subagents

> 标签: agent, background-tasks, delegation, herdr, orchestration, parallel-execution, pi, pi-extension, pi-package, session-management, subagent, task, tmux

## 简介

Herdr-native multi-repo delegation runtime for Pi with durable task state, foreground/background agents, worktree isolation, scoped claims, evidence and independent review gates, grouped completion, schedules, recovery, and SDK/tmux fallback. Runtime-only
