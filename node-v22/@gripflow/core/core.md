# @gripflow/core

> 标签: accessible, auto-scroll, collision-detection, dnd, drag and drop, drag-and-drop, gripflow, headless, keyboard, sensors, sortable, typescript, vanilla-js

## 简介

Gripflow core: framework-independent, headless drag and drop engine with pointer, touch and keyboard sensors, collision detection, modifiers, sortable model and auto-scroll.
