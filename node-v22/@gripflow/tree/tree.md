> 标签: accessible, dnd, drag and drop, drag-and-drop, file-tree, gripflow, headless, hierarchy, keyboard, nested, nextjs, react, sortable-tree, tree, tree-view, typescript

## 简介

Nested tree drag and drop for React (Gripflow): sortable tree view, file tree and folder hierarchy with move rules, depth limits and keyboard navigation.
