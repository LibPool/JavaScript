# @castari/castari-proxy

> 标签: agent-sdk, anthropic, castari, claude, openrouter

## 简介

Drop-in wrapper for @anthropic-ai/claude-agent-sdk that routes via the Castari Worker to Anthropic or OpenRouter models.
