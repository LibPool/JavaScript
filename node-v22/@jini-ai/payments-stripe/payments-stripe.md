# @jini-ai/payments-stripe

> 标签: JavaScript

## 简介

Stripe payment provider plugin for the @jini-ai/commerce payments kernel: PaymentIntents, partial refunds, manual capture, void, retrieve and signed webhooks over the host's HttpClientPort.
