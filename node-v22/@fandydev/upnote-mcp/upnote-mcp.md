# @fandydev/upnote-mcp

> 标签: ai-agent, macos, mcp, model-context-protocol, notes, upnote

## 简介

Unofficial MCP server for UpNote: create and revise notes (tables, images, checklists) through UpNote's URL scheme, and read them from the local database in read-only mode
