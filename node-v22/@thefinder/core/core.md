# @thefinder/core

> 标签: bun, chunked-upload, ckfinder, edge, elfinder, express, fastify, file-browser, file-manager, hono, koa, minio, nodejs, r2, s3, thumbnails, trash, upload, version-history, zip

## 简介

theFinder server engine: a framework-agnostic file manager backend with local disk and S3 storage, chunked uploads, zip, trash and version history. Zero dependencies.
