# @undercut/cli

> 标签: cli, console, filter, lodash, map, pipe, reduce, shell, stdin, stdlib, stdout, termial, underscore

## 简介

A CLI for lazy data processing in a shell using operations from Undercut and any valid JavaScript expression.
