# @faraday-academy/tutor

> 标签: JavaScript

## 简介

Faraday Academy tutor addon — the durable <Tutor> chat widget (client), docked beside the lesson with Markdown/math rendering. Pairs with the author-editable Nitro + Workflow server that `faraday new --tutor` drops into the lesson.
