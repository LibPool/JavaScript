# dsh-longtext-input

> 标签: client-plugin, deepseek, deepseek-harness, dsh, dsh-plugin, longtext

## 简介

DeepSeek Harness 长文本输入插件：在输入框工具栏加一个「长文本」按钮，弹出编辑器，保存后把正文写入工作区 .dsh-longtext/ 下的 md 文件，并把 @ 引用注入输入框。用于超长粘贴（报错日志、会议记录、文档）而不让聊天界面变乱。
