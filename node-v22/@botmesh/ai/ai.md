# @botmesh/ai

> 标签: ai, anthropic, baileys, bot, chatbot, claude, llm, ollama, openai, plugin, whatsapp

## 简介

Multi-provider AI autoresponder plugin (Anthropic / OpenAI / Ollama) for @botmesh/core, with per-chat conversation memory and a ctx.tools.ai client.
