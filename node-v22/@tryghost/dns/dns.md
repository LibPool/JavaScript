# @tryghost/dns

> 标签: JavaScript

## 简介

Lookup DNS info for a domain. The package powers Ghost(Pro) custom-domain checks by collecting DNS records, Cloudflare/Fastly-related metadata, and validity ratings for CNAME and SSL configuration.
