# @tryghost/domain-validator

> 标签: JavaScript

## 简介

Validate whether a custom domain is ready to be used with Ghost(Pro). The validator checks the expected Ghost(Pro) subdomain, DNS records, proxy setup, and optional CAA issuer requirements, then returns a structured validity report.
