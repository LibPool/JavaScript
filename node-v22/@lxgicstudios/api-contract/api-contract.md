# @lxgicstudios/api-contract

> 标签: api, breaking-changes, ci-cd, cli, contract, contract-testing, http, npx, response-validation, rest-api, schema, testing, type-checking, validation

## 简介

Validate live API responses against a contract schema. Auto-generate contracts from endpoints, then validate them on every deploy. Catch extra fields, missing fields, and type mismatches.
