# @lxgicstudios/ai-migrate

> 标签: alter-table, cli, database, database-migration, devops, migration-generator, mysql, postgres, rollback, schema-compare, schema-diff, sql, sql-migration, sqlite

## 简介

Generate database migration SQL from schema diffs. Compare SQL schema files and produce ALTER TABLE statements for column changes, type changes, and index updates.
