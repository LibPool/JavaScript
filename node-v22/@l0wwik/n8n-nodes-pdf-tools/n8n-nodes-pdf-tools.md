# @l0wwik/n8n-nodes-pdf-tools

> 标签: merge, n8n, n8n-community-node, n8n-node, pdf, rotate, split, text-extraction, watermark

## 简介

A custom n8n node to manipulate PDF files: split, merge, reorder, rotate, delete, watermark, add image, extract text, and read metadata.
