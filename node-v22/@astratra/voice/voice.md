# @astratra/voice

> 标签: astratra, cache, faster-whisper, ffmpeg, piper, sherpa-onnx, speech-to-text, text-to-speech, voice

## 简介

Server-side text-to-speech finishing and caching: deterministic voice-version keys, Piper (command line and HTTP) and ffmpeg builders, cancellation by AbortSignal, injected process and file adapters, and memory caches (bounded LRU included).
