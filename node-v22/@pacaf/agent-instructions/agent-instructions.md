# @pacaf/agent-instructions

> 标签: agent, claude, code-apps, cursor, github-copilot, instructions, pacaf, power-apps

## 简介

Power Apps Code App Foundations agent guidance for GitHub Copilot, Claude, and Cursor. Materializes .github/instructions/, .claude/rules/, .cursor/rules/ into a target repo and detects drift.
