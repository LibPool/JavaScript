# @muonroi/agent-harness-angular

> 标签: JavaScript

## 简介

Angular 16+ adapter for the muonroi agent harness. Exposes `[muonroiSemantic]` directive, `SemanticRegistryService`, and SSR-safe `SemanticSnapshotService`.
