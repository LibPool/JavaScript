# @muonroi/agent-harness-opentui

> 标签: JavaScript

## 简介

OpenTUI adapter for the muonroi agent harness. Provides `<Semantic>`, `<SemanticProvider>`, the OpenTUI reconciler hook, and the `installOpenTUIHarness` entry point.
