# @caspian-vega/nano-devtools

> 标签: custom-element, debugging, devtools, logger, nanostores, state-management, svelte, web-component

## 简介

Framework-agnostic in-memory logger for nanostores plus a Svelte web-component devtools UI that opens in an independent browser window. Capture store state changes/actions and inspect them (search, filter, timestamps) in a separate window.
