# agent-loop-breaker

> 标签: agent, agent-loop, agentic, ai-agent, ai-agents, ai-sdk, anthropic, circuit-breaker, claude-code, claude-code-hooks, doom-loop, function-calling, guardrails, hooks, infinite-loop, llm, llm-agent, loop-detection, loop-detector, mcp, openai, orchestration, repeated-tool-calls, safety, stuck-agent, token-cost, tool-calls, tool-use, vercel-ai

## 简介

Catch AI agents going in circles: repeated tool calls that return the same result, cycles that make no progress, and tools that keep failing. Hints the model, blocks the repeat, or stops the run. Works with any agent loop, the Vercel AI SDK, and Claude Co
