# @covenant-org/verified-er

> 标签: attestation, covenant, ephemeral-rollup, magicblock, provenance, solana, tdx

## 简介

Pick a Covenant-verified MagicBlock ephemeral rollup, and check an agent's on-chain provenance root. Read-only, one dependency.
