# @anmed/mui-time-scale

> 标签: JavaScript

## 简介

时间看板通过时间轴来显示一组事件的组件。下面是一个示意图。 ![](./time-kanban.png) 点击时间字段可以触发时间on:track，建议在显示纪录时间和修正时间（如果存在），如果该时间运行修改，那么用户可以修改修正时间。修改后时间将显示为斜体红色。
