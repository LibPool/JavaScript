# @metrobuzz/express-request-handler

> 标签: express, express-request, express-request-handler, handler, metro, metrobuzz, request, request-handler

## 简介

This module provides a higher-order function (HOF) that wraps Express route handlers to standardize error handling, logging, and response formatting.
