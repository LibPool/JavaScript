# @enclavia/client-wasm

> 标签: attestation, confidential-computing, enclave, enclavia, nitro, noise-protocol, wasm

## 简介

Enclavia client SDK compiled to WebAssembly: attested Noise tunnel to an enclave from browsers and JS runtimes (Node >= 22, Deno). Same Rust security core as the native SDK.
