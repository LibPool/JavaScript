# @awesome-cordova-plugins/stripe

> 标签: angular, cordova, ionic, mobile, native, plugin, stripe

## 简介

Stripe plugin for Cordova and Ionic. A plugin that allows you to use Stripe's Native SDKs for Android and iOS.
