# @awesome-cordova-plugins/ffmpeg

> 标签: angular, cordova, ffmpeg, ionic, mobile, native, plugin

## 简介

FFMpeg plugin for Cordova and Ionic. Simple plugin that binds mobile ffmpeg to execute ffmpeg commands
