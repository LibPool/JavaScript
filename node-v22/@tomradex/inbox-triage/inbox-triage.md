# @tomradex/inbox-triage

> 标签: tomrade, tomrade-plugin, types

## 简介

Pre-triage for the inbox: the worker model proposes a duplicate, kind, priority, title and draft reply for each new entry, for a person to confirm — declarations for full-mode plugins; Tomrade provides the code at run time
