# @tomradex/notes

> 标签: tomrade, tomrade-plugin, types

## 简介

ctx.notes — a project's files read as notes: wiki links and backlinks, tags, a ranked full-text index, link updates when a note moves, and a daily journal. Optional — Files works the same without it. — declarations for full-mode plugins; Tomrade provides
