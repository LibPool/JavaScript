# @tomradex/community

> 标签: tomrade, tomrade-plugin, types

## 简介

Community: browse, install, update and report store plugins — each checked against a signed attestation — and publish one from its GitHub repository — declarations for full-mode plugins; Tomrade provides the code at run time
