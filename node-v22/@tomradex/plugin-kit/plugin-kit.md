# @tomradex/plugin-kit

> 标签: tomrade, tomrade-plugin, types

## 简介

Plugin tooling without a context: the .tomrade-plugin package, content digests, signatures, the lock file and the static analyzer shared by the app, the CLI and the store's admin tool — declarations for full-mode plugins; Tomrade provides the code at run
