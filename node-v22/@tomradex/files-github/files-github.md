# @tomradex/files-github

> 标签: tomrade, tomrade-plugin, types

## 简介

GitHub as the place a project's files are shared: a repository per project, found or created with the account Tomrade already publishes with — declarations for full-mode plugins; Tomrade provides the code at run time
