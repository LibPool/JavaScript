# @moonraker46/xbtp

> 标签: btp, cf, cli, cloud-foundry, credentials, keychain, login, profile-manager, sap, sap-btp, secrets

## 简介

Secure CLI for managing multiple SAP CLI credentials (cf, btp). Encrypted profile store (AES-256-GCM + macOS Keychain), on-the-fly org/space discovery, PTY-based login.
