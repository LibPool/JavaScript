# @tathagatmaitray/walkback

> 标签: agents, ai, autonomous-agents, claude, mcp, model-context-protocol, reversible, rollback, time-machine, undo

## 简介

Undo anything your AI agent does. A universal time machine that records every side effect an autonomous agent produces — file writes, shell commands, git state, HTTP mutations — and reverses them with one command.
