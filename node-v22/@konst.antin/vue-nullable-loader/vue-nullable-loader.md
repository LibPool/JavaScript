# @konst.antin/vue-nullable-loader

> 标签: JavaScript

## 简介

This package allows you to use [optional chaining operator (**?.**)](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Operators/Optional_chaining) in Vue components.
