# @streamapp/desktop-darwin-x64

> 标签: JavaScript

## 简介

stream-desktop binary for macOS x64 — loaded by @streamapp/desktop (Stream Desktop)（配对 + 桌面控制均可用，桌面控制走 AX）。bin/ 里还带着读屏用的 PP-OCRv5 模型三件（ocr-det.onnx / ocr-rec.onnx / ocr-rec-dict.txt）与 ONNX Runtime 1.20.1 的动态库（libonnxruntime.dylib），可执行文件按同目录找它们
