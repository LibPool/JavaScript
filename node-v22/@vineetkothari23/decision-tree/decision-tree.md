# @vineetkothari23/decision-tree

> 标签: adr, agent, agent-skills, claude, decision-tree, devin, planning, skill

## 简介

Question-driven decision trees for planning software features: JSON in each app's .decisions/, an agent CLI, and a local HTML viewer for human-agent coordination. Ships as an agent skill.
