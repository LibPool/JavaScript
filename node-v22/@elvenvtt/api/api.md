# @elvenvtt/api

> 标签: api-client, creator-economy, elven, marketplace, publishing, rest

## 简介

Typed REST client for the Elven creator API. The shared core consumed by @elvenvtt/cli, @elvenvtt/mcp-account, and any third-party tooling.
