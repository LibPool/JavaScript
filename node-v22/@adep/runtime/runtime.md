# @adep/runtime

> 标签: JavaScript

## 简介

AgentDeploy 运行时内核：云函数执行器 + 本地模拟运行时 + cloud.db/cloud.storage 能力装配，零平台重栈依赖（无 elysia/drizzle/better-auth/nuxt/bun:sqlite/postgres/ioredis），供 server / CLI(adep dev) / 浏览器离线工作区三方复用。
