# @actaseal/verify

> 标签: actaseal, ed25519, receipt, tamper-evident, verify, webcrypto

## 简介

Minimal, zero-dependency JS/WebCrypto port of ActaSeal's offline dispute-packet verifier (chain integrity + Ed25519 receipt signature only -- see README for exact scope and what it does NOT check).
