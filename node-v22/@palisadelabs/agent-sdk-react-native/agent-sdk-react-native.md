# @palisadelabs/agent-sdk-react-native

> 标签: JavaScript

## 简介

Palisade in-app agent for React Native / Expo apps: assistant thread, nudges, home card, driver, outbox delivery. Headless core with theme + component injection; all copy, policy and capabilities are decided server-side.
