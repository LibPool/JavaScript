# @cargo-ai/api

> 标签: ai-agents, api, api-client, cargo, enrichment, go-to-market, gtm, orchestration, revenue, sdk, typescript

## 简介

Typed TypeScript client for the Cargo API — models and records, orchestration runs and batches, connectors and integrations, agents, segments, and billing. The programmatic surface behind the cargo-ai CLI.
