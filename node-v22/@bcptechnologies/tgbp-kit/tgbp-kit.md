# @bcptechnologies/tgbp-kit

> 标签: agent, erc20, gbp, mcp, solana, stablecoin, tgbp, viem, x402

## 简介

tGBP, the tokenised British pound, for developers: token registry, on-chain balances, transfers and watchers on EVM chains and Solana, a typed client for the mint, redeem and swap API, and an MCP server and agent skills with a client-side spend policy.
