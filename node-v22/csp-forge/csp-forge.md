# csp-forge

> 标签: ci, cli, content-security-policy, csp, hash, helmet, netlify, nginx, nonce, report-to, report-uri, sarif, security, security-headers, sha256, static-site, strict-dynamic, vercel, vite, webpack, xss

## 简介

Scan a built static site (dist/, build/, out/) or live URL and generate a tight Content-Security-Policy with sha256 hashes or nonce + strict-dynamic for SSR. Vite/webpack plugins, reporting headers, --check for CI.
