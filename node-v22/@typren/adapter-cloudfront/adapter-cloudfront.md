# @typren/adapter-cloudfront

> 标签: aws, cloudfront, cms, redirects, typren

## 简介

CloudFront host adapter for typren: the canonical viewer-request function (directory-index rewrite + bare→slash canonicalization + KVS-backed redirect lookup, fail-open) and a `typren-cloudfront sync-redirects` CLI that diff-syncs @typren/core's redirects
