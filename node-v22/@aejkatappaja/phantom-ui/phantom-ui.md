# @aejkatappaja/phantom-ui

> 标签: custom-element, framework-agnostic, lit, loading, placeholder, shimmer, skeleton, web-component

## 简介

Structure-aware shimmer skeleton loader as a universal Web Component built with Lit. Works with React, Vue, Svelte, Angular, Solid, or vanilla JS.
