# dsh-baseline

> 标签: audit, cordis, deepseek-harness, dsh, network-policy, security, subagent

## 简介

A fail-closed, transparent baseline gate for DeepSeek Harness: network egress policy, monotonic subagent permission ceiling, and one verifiable decision/result audit chain.
