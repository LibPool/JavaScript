# gbxlxs

> 标签: editor, excel, ooxml, spreadsheet, ui, workbook, xlsx

## 简介

Standalone spreadsheet (XLSX) engine with a self-contained HTML editor: read/write xlsx, workbook model ops, CSV/HTML import-export and a full spreadsheet UI.
