# @appcreate/cli

> 标签: appcreate, appcreatejs, cli

## 简介

AppCreate CLI é uma ferramenta de linha de comando poderosa para criação de projetos e gerenciamento de dependências dos pacotes AppCreate.

## 官网

- 官网：https://appcreatejs.github.io
- 源码仓库：git+https://github.com/appcreatejs/cli.git
- npm 页面：https://www.npmjs.com/package/@appcreate/cli
