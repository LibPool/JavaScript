# @redesigner/wave.js

> 标签: animation, background, canvas, gpu, react, shader, vanilla, waves, webgl

## 简介

GPU-accelerated animated sine wave backgrounds. Vanilla JS + React. WebGL2 → Canvas 2D → CSS fallback. 60 FPS.
