# @conduitcms/mcp

> 标签: JavaScript

## 简介

Conduit — an AI-first, code-first headless CMS. This is a name reservation for @conduitcms/mcp, the MCP server (raw MCP TS SDK over @conduitcms/core) exposing collections/fields/entries as agent tools with ability-scoped API keys and agent-readable schema
