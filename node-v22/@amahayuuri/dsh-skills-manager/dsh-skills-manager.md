# @amahayuuri/dsh-skills-manager

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, skill-manager, skills

## 简介

在 DSH 桌面端侧边栏管理 Skills：从仓库、压缩包或图形化选择的文件夹导入，按 DSH 规则校验并查重安装，查看来源并导出为 ZIP 分享。
