# @ironbridgefoundation/verify

> 标签: agent, audit, base, ironbridge, receipt, usdc, verifiable, x402

## 简介

Independently re-walk an IronBridge agent-call receipt — verify the on-chain payment, result binding, and hash-chain link with zero IronBridge secrets. No API key, no LLM, no trust required.
