# @miyuki333/jquery.popup

> 标签: ajax, ecosystem:jquery, jquery, jquery-plugin, modal, popup

## 简介

An intuitive modal popup library for jQuery. Create simple popups, ajax popups, customize your background, and more! Also with centering that actually works!
