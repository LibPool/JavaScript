# @hakari/web-player

> 标签: hakari, hls, llhls, low-latency, player, streaming, video

## 简介

Embed-friendly HLS / LL-HLS / WebRTC web player for Hakari live streams and VODs. Custom controls, sprite-thumbnail scrubbing, signed-playback aware.
