# @devfoundry-dev/toolbox-favicon-generator

> 标签: devfoundry, favicon, ico, icons, webmanifest

## 简介

Favicon generation engine — produces ICO, PNG, apple-touch-icon, android-chrome, webmanifest, and HTML snippet from a single source image.
