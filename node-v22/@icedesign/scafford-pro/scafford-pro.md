# @icedesign/scafford-pro

> 标签: JavaScript

## 简介

该模板内置了丰富的区块，主要用于展示现有区块的分类以及区块组合的效果，使用时需要根据需求进行删除和添加，效果图预览：https://alibaba.github.io/ice/ice-design-pro.html
