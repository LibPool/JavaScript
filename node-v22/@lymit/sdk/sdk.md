# @lymit/sdk

> 标签: ai, cloudflare-workers, edge, llm, rate-limit, rate-limiting, serverless, token-bucket

## 简介

Edge-first, application-level rate limiting for AI apps. Limit by user, workspace or tier and deduct real LLM token cost with one call.
