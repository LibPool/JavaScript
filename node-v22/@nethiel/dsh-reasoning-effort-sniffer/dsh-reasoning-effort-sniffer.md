# @nethiel/dsh-reasoning-effort-sniffer

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, pi-ai, reasoning-effort, sniffer, thinking

## 简介

Sniffs which thinking levels each third-party pi-ai route actually accepts and declares them, so the composer's model picker offers a strength switch; a sidebar panel switches sniffing and strength per provider.
