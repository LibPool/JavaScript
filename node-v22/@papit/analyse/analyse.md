# @papit/analyse

> 标签: analyse, cli, custom-elements, documentation, manifest, node, papit, typescript, web-component

## 简介

Reads a web component package's source and writes analyse.json, describing each custom element's tag, properties, methods, events, states, slots, parts and CSS variables, along with its full extends chain. Use it to generate docs, editor data or framework
