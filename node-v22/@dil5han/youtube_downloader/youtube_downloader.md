# @dil5han/youtube_downloader

> 标签: ytdownloader

## 简介

* url: a string representing the YouTube video URL * quality: a string indicating the quality of the video (avaiable options are: 144p, 240p, 360p, 480p, 720p, 1080p, 1440p, 2160p) * type: a string indicating the type of file (available options are: mp4
