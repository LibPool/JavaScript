# hangfolio

> 标签: academic, astro, astro-theme, bibtex, github-pages, portfolio, researcher, template

## 简介

A personal website for researchers and engineers on GitHub Pages: an Astro theme with results up front, publications from BibTeX, light and dark modes, and clear error messages.
