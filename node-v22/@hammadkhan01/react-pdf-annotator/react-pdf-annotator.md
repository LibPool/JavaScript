# @hammadkhan01/react-pdf-annotator

> 标签: annotation, drag-drop, field-tags, form-builder, pdf, pdf-viewer, react

## 简介

Drag-and-drop PDF field annotation component for React. Place field tags on a PDF, export a normalized annotation payload, and fill values from a backend.
