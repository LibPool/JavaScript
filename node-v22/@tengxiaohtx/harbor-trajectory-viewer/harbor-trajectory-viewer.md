# @tengxiaohtx/harbor-trajectory-viewer

> 标签: agent, atif, diff, harbor, llm, rollout, trajectory, viewer, visualizer

## 简介

Visualize Harbor ATIF agent trajectory (.json) files in the browser — timeline, tool calls, metrics, subagents, and code diffs. Open from the CLI or by uploading in the browser.
