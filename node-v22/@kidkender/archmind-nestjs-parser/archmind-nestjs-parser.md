# @kidkender/archmind-nestjs-parser

> 标签: api-contract, archmind, class-validator, dto, nestjs, parser, static-analysis

## 简介

Static analysis parser for NestJS projects — extracts routes, auth guards, DTOs, and class-validator field rules into ArchMind IR graphs.
