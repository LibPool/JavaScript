# @galaxyxieyu/pi-viking-memory

> 标签: ai-memory, memory, openviking, pi-extension, pi-package, viking-memory

## 简介

A unified Pi memory extension for Viking Memory and OpenViking with workspace isolation, global preferences, lifecycle controls, audit, and TUI memory cards.
