# @aymenkits/pay-express

> 标签: commission, connect, escrow, express, marketplace, payments, stripe

## 简介

Express 4/5 webhook route handler for @aymenkits/pay-stripe — raw-body + stripe-signature handling (the part that's easy to get wrong), envelope-agnostic.
