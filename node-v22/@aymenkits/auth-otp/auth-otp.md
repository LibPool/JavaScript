# @aymenkits/auth-otp

> 标签: auth, authentication, jwt, oauth, otp, passwordless

## 简介

One-time-code engine: generate → hash → deliver → verify, with TTL, attempt caps, resend cooldown and a dev master code. Storage and delivery are seams (OtpStore / OtpSender).
