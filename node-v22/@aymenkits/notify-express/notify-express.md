# @aymenkits/notify-express

> 标签: email, express, fcm, notifications, push, realtime, sms

## 简介

Express 4/5 handlers for the in-app notification endpoints every app exposes: list, unread count, mark read, mark all read. Envelope-agnostic, structural typing.
