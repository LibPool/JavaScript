# @aymenkits/pay-stripe

> 标签: commission, connect, escrow, marketplace, payments, stripe

## 简介

Stripe adapter for @aymenkits/pay-core — instant destination charges with per-component application fees, escrow (manual-capture → capture → release transfer), tips, refunds, setup intents, tiered Billing subscriptions and a typed webhook dispatcher. Stru
