# @beeuni/llm-catalog

> 标签: ai, beeuni, llm-catalog, models, sdk

## 简介

The Beeuni LLM model catalog — the models the Beeuni gateway supports and the managed-model set and defaults. Generated from models.dev; consumed across the Beeuni platform and by the @beeuni/sdk.
