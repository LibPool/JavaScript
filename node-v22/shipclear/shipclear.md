# shipclear

> 标签: ai, claude-code, codex, cursor, devtools, pre-commit, scanner, secrets, security, vibe-coding

## 简介

The last command before you launch. A free, local, cross-agent security gate for AI-built apps: prevents leaked secrets while you build, blocks them at commit time, and gives you a plain-English safe-to-ship verdict.
