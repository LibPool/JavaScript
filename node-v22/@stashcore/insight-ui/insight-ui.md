# @stashcore/insight-ui

> 标签: bitcore-stash, blockchain, blockexplorer, front-end, insight, stash, stashcore

## 简介

An open-source frontend for the Insight API. The Insight API provides you with a convenient, powerful and simple way to query and broadcast data on the Stash network and build your own services with it.
