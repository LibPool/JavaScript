# netforge

> 标签: agent-skills, agents-md, ai-agents, browser-game, cli, game-engine, gamedev, mcp, multiplayer, net-forge, vibe-coding

## 简介

Net Forge command line for coding agents: `npx netforge setup agent` writes AGENTS.md, CLAUDE.md, Cursor rules and MCP configs into a game project, and ships Agent Skills for building Net Forge games.
