# szkoly-mcp

> 标签: ai-agent, cke, claude, education, egzamin-osmoklasisty, matura, mcp, model-context-protocol, open-data, poland, przedszkola, rspo, schools, szkoly, wybor-szkoly

## 简介

MCP server: schools in Poland for AI agents – official register of schools and kindergartens (SIO) with per-school eighth-grade exam and matura results (CKE) vs county and national averages. No API key.
