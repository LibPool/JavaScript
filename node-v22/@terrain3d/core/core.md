# @terrain3d/core

> 标签: dem, dsm, dtm, geojson, gis, lod, measurement, orthomosaic, photogrammetry, pmtiles, quadtree, terrain, three, threejs, webgl

## 简介

Streaming DEM/DSM/DTM terrain viewer for three.js: quadtree LOD, orthomosaic drape, 3D measurement and draped GeoJSON overlays. No React, no DOM at module scope.
