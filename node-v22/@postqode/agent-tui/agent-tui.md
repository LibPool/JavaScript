# @postqode/agent-tui

> 标签: JavaScript

## 简介

Lean terminal UI for a PostQode coding agent — a readline + ANSI REPL on top of @postqode/agent's event stream. Streams text, renders tool calls, shows usage, and ships slash commands. Zero heavy UI deps.
