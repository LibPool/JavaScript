# @postqode/agent

> 标签: JavaScript

## 简介

Pluggable agent loop and tool execution for PostQode. Built on @postqode/ai. Ships Agent class, Tool/Host/Hooks contracts, NodeHost, assistant-message parsing, and persistent MEMORY.md-indexed memory.
