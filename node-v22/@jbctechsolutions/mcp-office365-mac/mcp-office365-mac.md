> 标签: anthropic, applescript, calendar, claude, contacts, email, macos, mcp, microsoft-365, microsoft-graph, model-context-protocol, office365, outlook, planner, tasks, teams

## 简介

MCP server for Microsoft 365 with dual backend support (AppleScript for classic Outlook, Graph API for new Outlook/M365). Read/write access to mail, calendar, contacts, tasks, teams, planner, and more.
