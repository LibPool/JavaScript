# @byteplus/veplayer-live

> 标签: JavaScript

## 简介

## 简介 视频云播放器（VePlayer Live）是一款 Web 端的直播拉流 SDK，结合火山引擎视频直播服务，为您提供流畅、稳定、高品质的直播解决方案，支持便捷接入、跨端兼容。帮助您一站式快速搭建自己的直播播放器。
