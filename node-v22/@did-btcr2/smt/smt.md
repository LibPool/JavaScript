# @did-btcr2/smt

> 标签: bitcoin, decentralized identifiers, decentralized identity, did, did method, did:btcr2, dids, smt, sparse merkle tree

## 简介

Sparse Merkle Tree for did:btcr2: full-depth zero-hash model with base64url inclusion/non-inclusion proofs and did:btcr2-specific leaf hash construction.
