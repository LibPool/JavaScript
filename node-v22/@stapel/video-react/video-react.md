# @stapel/video-react

> 标签: JavaScript

## 简介

Headless React pair for stapel-video's scope usage read: who in one partition talked how much, per calendar month. `useScopeUsage` runs the window read that feeds the month selector and the single-month read that feeds the rows, both over `GET /video/api/
