# @stapel/tasks-react

> 标签: JavaScript

## 简介

React pair for stapel-tasks: typed API client, TanStack Query hooks, the board assembly and move state machine, headless bags, i18n keys, and an opt-in AntD kanban skin (dnd-kit drag with keyboard and touch sensors) behind the /default subpath.
