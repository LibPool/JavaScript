# @stapel/calendar-react

> 标签: JavaScript

## 简介

Headless React pair for stapel-calendar plus its default antd skin: a typed client, TanStack Query hooks, headless primitives for every one of the module's ten operations, and a wired month/week/day calendar that degrades to an agenda on a phone. The mate
