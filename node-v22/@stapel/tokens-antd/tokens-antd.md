# @stapel/tokens-antd

> 标签: JavaScript

## 简介

Token bridge (§68 neutral colour-role dictionary; frontend-guidelines §2.4, §38 T3): projects @stapel/tokens' roles (surface, brand, text-muted, success-bg, ...) onto an Ant Design ConfigProvider theme. `toAntdTheme(mode)` -> theme.token; `toAntdThemeConf
