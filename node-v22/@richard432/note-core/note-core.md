# @richard432/note-core

> 标签: composable, git, notebook, pouchdb, sync, typescript, vue, webdav

## 简介

Vue 3 组合式函数的笔记核心库：内置 PouchDB / Git / WebDAV 多端 Provider 与 SyncEngine 同步引擎，纯 TypeScript，ESM 构建，可被网页直接调用。
