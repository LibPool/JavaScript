# @tnpay/flouci

> 标签: flouci, flouci.com, payment-gateway, payments, sdk, tnd, tunisia, webhook

## 简介

Typed Flouci (flouci.com) client for TypeScript, with a webhook handler that verifies every payment with Flouci before acting, and a fake Flouci server for tests.
