# @tnpay/konnect

> 标签: konnect, konnect.network, payment-gateway, payments, sdk, tnd, tunisia, webhook

## 简介

Typed Konnect (konnect.network) client for TypeScript, with a webhook handler that verifies every payment with Konnect before acting, and a fake Konnect server for tests.
