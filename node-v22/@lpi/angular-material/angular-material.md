# @lpi/angular-material

> 标签: angularjs, browser, client-side, component library, components, material, material design

## 简介

This repository is used for publishing the AngularJS Material v1.x library and localized installs using `npm`. The component source-code for this library is in the [AngularJS Material repository](https://github.com/angular/material).

## 官网

- 官网：https://material.angularjs.org
- 源码仓库：git://github.com/angular/material.git
- npm 页面：https://www.npmjs.com/package/@lpi/angular-material
