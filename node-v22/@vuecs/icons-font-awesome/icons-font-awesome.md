# @vuecs/icons-font-awesome

> 标签: font-awesome, iconify, icons, preset, vue, vuecs

## 简介

Font Awesome icon preset for vuecs — maps semantic-slot defaults (pagination prev/next/first/last, submit-button create/update, ...) to Font Awesome 6 Solid Iconify names. Successor to @vuecs/theme-font-awesome.
