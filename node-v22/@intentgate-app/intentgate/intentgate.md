# @intentgate-app/intentgate

> 标签: agent-security, ai-agents, authorization, capability-tokens, intentgate, macaroons, mcp, opa

## 简介

TypeScript SDK for the IntentGate authorization gateway. Three lines to wrap any agent's tool call with capability + intent + policy + budget checks. Zero runtime dependencies (uses native fetch and node:crypto).
