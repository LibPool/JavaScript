# @nysgpt/bucket-list

> 标签: audit, aws, bucket, cli, cost, dashboard, inventory, s3, storage

## 简介

Bucket List — lightweight search for S3. One command sweeps every bucket in an AWS account into a single offline HTML file: drill-down by bucket and folder, object counts, storage-class costs, largest files, and instant search.
