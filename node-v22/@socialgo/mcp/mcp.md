# @socialgo/mcp

> 标签: ai, claude, llm-tools, mcp, model-context-protocol, smm, social-media-marketing, socialgo

## 简介

Model Context Protocol server for SocialGO — lets AI assistants (Claude, etc.) search services and place SMM orders, including keyless guest checkout (buy without an account, no API key).
