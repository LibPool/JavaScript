# @radiobros/animatio

> 标签: animate.css, animation, css, glassmorphism, scroll-driven-animations, scss, tree-shaking, view-transitions

## 简介

CSS-only animation + effects library. animate.css parity, composable transform engine, scroll-driven reveals, glass/backdrop surfaces, and a tree-shaking engine.
