# @aevris/sdk

> 标签: agentic-ai, ai-security, llm-security, mcp-security, owasp-llm, prompt-injection

## 简介

Official JavaScript/TypeScript SDK for AEVRIS — deterministic AI security middleware that intercepts prompts before they reach AI models and verifies outputs before delivery.
