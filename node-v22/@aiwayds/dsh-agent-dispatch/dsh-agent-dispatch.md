# @aiwayds/dsh-agent-dispatch

> 标签: agent, deepseek-harness, dispatch, dsh, dsh-plugin, jev, subagent, typesafe

## 简介

dsh plugin: Jev-guided dispatch advice — before a turn starts, a TypeSafe Jev call decides whether the task belongs to a registered agent and which one, then injects a four-line, ignore-if-unsuited recommendation. Jev-optional: no key means silence.
