# @nathanchase/nuxt-dayjs-module

> 标签: dayjs, nuxt, nuxt3

## 简介

This is a Nuxt 3 compatible module built with the official Nuxt 3 (module-builder)(https://github.com/nuxt/module-builder) for (dayjs)(https://github.com/iamkun/dayjs/).
