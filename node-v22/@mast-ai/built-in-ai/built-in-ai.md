# @mast-ai/built-in-ai

> 标签: JavaScript

## 简介

On-device inference for [MAST](https://github.com/andreban/mast-ai) via Chrome's [built-in AI](https://developer.chrome.com/docs/ai/built-in) (Prompt API / Gemini Nano). No server, no API key, no network round trip.
