# @rqt/_registry

> 标签: JavaScript

## 简介

This package will call `npm config set @rqt:registry https://rqt.gitlab.io` to update the registry settings for RQT namespace.

## 官网

- 源码仓库：https://gitlab.com/rqt/_registry.git
- npm 页面：https://www.npmjs.com/package/@rqt/_registry
