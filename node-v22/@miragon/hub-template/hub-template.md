# @miragon/hub-template

> 标签: hub, login, miragon, netlify, training

## 简介

Sign-in gate for Miragon training hubs on Netlify: signed session cookie, login/logout functions, edge gate, rate limit and the login pages. Scaffolded by `npm create @miragon/slidev-deck -- --hub`; `hub-template sync` updates the managed files.
