# @miragon/bpmn-cli

> 标签: agent, ai, bpmn, bpmn-js, bpmn-moddle, cli, layout

## 简介

AI-friendly CLI for editing BPMN 2.0 models semantically: agents name elements and operations, never XML or BPMNDI. Keeps hand-made diagrams (incremental layout), redraws engine-owned ones, and offers diagram formatting operations.
