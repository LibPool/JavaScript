# @miragon/design-iq-validator

> 标签: bpm, bpmn, cli, dmn, modeling, validator

## 简介

Platform-owned validator for designIQ content repos — designiq.yml discovery, BPMN/DMN structure and diagram coverage, cross-model references, the schema check of Team Topologies, Context Maps and Value Chains, and a parse check for every other notation.
