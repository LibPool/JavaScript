# @miragon/design-iq-mcp

> 标签: architecture, bpm, bpmn, context-maps, dmn, event-storming, mcp, model-context-protocol, modeling, process-documentation, team-topologies, wardley-maps

## 简介

Read-only MCP server exposing a designIQ content repo's models — BPMN processes, DMN decisions, Wardley Maps, Team Topologies, Event Storming boards, Context Maps and more — to any MCP client. Discovered from designiq.yml, views derived from the models.
