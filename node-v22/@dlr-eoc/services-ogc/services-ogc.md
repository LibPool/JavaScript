# @dlr-eoc/services-ogc

> 标签: OGC, OWS Context JSON, WMS, WMTS, WPS, angular, mapping

## 简介

This module bundles our clients for OGC standards. E.g. parse OWS Context JSON, WMS, WMTS or WPS.
