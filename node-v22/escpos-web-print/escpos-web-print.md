# escpos-web-print

> 标签: dithering, esc-pos, escpos, goojprt, pt-210, raster, receipt-printer, thermal-printer, web-bluetooth, web-serial

## 简介

Zero-dependency ESC/POS raster printing from the browser over Web Bluetooth and Web Serial for 58mm/80mm thermal receipt printers.
