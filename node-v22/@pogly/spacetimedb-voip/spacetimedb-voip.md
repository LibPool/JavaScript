# @pogly/spacetimedb-voip

> 标签: opus, spacetimedb, submodule, voice-chat, voip

## 简介

Voice chat for SpacetimeDB, as a submodule: rooms, proximity voice, RLS-targeted delivery over an event table. Same schema and clients as voip.rs / Voip.cs.
