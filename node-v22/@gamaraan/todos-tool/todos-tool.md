# @gamaraan/todos-tool

> 标签: omp, pi-package, task-tracking, todo, todos

## 简介

pi coding-agent extension: an Oh My Pi (OMP)-style phased todo tool with reminders, /todo configuration, HUD, and optional desktop notification requests.
