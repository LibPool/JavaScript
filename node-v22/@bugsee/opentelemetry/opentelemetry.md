# @bugsee/opentelemetry

> 标签: JavaScript

## 简介

OpenTelemetry interop (Tier 3, pluggable extension): two-way bridge — produce Bugsee transactions as OTLP/JSON, consume OTel spans. Runtime-portable mapping core; OTel deps are peers in the per-runtime wiring. See docs/design/opentelemetry-integration.md
