# @stalefree/core

> 标签: cache, cache-invalidation, drizzle, listen-notify, no-redis, pg_notify, postgres, stale-while-revalidate, tags, typescript

## 简介

Framework-agnostic tag-based cache invalidation through the database you already have — in-memory L1, optional Drizzle L2, and an invalidation bus over Postgres LISTEN/NOTIFY (transactional: delivered on commit, dropped on rollback)
