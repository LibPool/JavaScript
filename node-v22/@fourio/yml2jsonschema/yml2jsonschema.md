# @fourio/yml2jsonschema

> 标签: JavaScript

## 简介

Yaml2JsonSchema is a CLI tool used internally at four.io to convert YAML representations of JSON schema files back to JSON and include PHPStorm syntax highlighting in attribute descriptions
