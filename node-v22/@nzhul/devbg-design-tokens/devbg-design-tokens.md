# @nzhul/devbg-design-tokens

> 标签: devbg-design-tokens, figma, material-ui, react, styling, ui

## 简介

A centralized collection of design tokens for consistent styling across projects. This repository includes color palettes, typography, spacing, and other design system assets generated using Figma's Token Studio Plugin. Ideal for use in React and Material
