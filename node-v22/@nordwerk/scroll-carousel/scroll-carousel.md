# @nordwerk/scroll-carousel

> 标签: accessibility, astro, carousel, preact, progressive-enhancement, react, scroll-snap, slider

## 简介

A dependency-free carousel on native scrolling: CSS scroll snap first, arrows, dots, paging and an API as progressive enhancement.
