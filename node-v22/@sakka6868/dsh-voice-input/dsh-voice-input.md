# @sakka6868/dsh-voice-input

> 标签: client-plugin, cordis, deepseek-harness, dictation, dsh, plugin, speech-to-text, stt, voice, web-speech-api

## 简介

DeepSeek Harness Web UI 语音输入插件：发送按钮左侧的麦克风按钮，调用浏览器 Web Speech API（Edge 中即微软语音服务）实时把语音转成文字写入输入框，停止后自动校对（错别字/同音偏差/繁体转简体/标点）。支持 Ctrl+Shift+M 快捷键，零依赖、无需 API Key。
