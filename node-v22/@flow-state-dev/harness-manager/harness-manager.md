# @flow-state-dev/harness-manager

> 标签: agents, ai, coding-agent, flow-state-dev, harness, llm, task-board, typescript, workflow

## 简介

A task-board worker that turns a row into a supervised coding run — its own checkout, a verdict read before the row settles, a question channel, and the coding harness as a slot you fill.
