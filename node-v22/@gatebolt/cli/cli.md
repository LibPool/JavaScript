# @gatebolt/cli

> 标签: ai-agents, audit, claude-code, cli, gatebolt, git, provenance, reconciliation

## 简介

Declare-then-observe agent client for GateBolt — records the files an AI agent intends to touch, then reconciles the actual git diff.
