# @magicpro97/vibeflow

> 标签: agy, ai, antigravity, claude-code, cli, codex, copilot, local-first, orchestrator, skills

## 简介

Local-first npm CLI that opens a web UI and orchestrates Claude Code, Codex CLI, GitHub Copilot CLI, OpenCode, and Antigravity CLI with shared context, skills, hooks, and verification.
