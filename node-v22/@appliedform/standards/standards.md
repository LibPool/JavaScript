# @appliedform/standards

> 标签: accessibility, design-system, design-tokens, dtcg, lint, mcp, playwright

## 简介

Standards by Applied Form: a design-system conformance gate measured in a real browser. DTCG tokens in, every rendered page checked at four fixed and two sampled widths, with drift surveys, an MCP server and an evaluation harness anyone can rerun.
