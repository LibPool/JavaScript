# @this-npm-test-org/gmail-connection-driver

> 标签: amodal, amodal-connection-driver, email, gmail

## 简介

First-party ConnectionDriver for Gmail — read inbound messages, send replies, and receive Pub/Sub push notifications. Templates declare a `protocol: "gmail"` connection and the runtime mounts /webhook/gmail-push under /api/connections/<connection_name>/.
