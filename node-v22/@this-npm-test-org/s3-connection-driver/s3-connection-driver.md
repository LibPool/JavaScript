# @this-npm-test-org/s3-connection-driver

> 标签: amodal, amodal-connection-driver, file-upload, r2, s3, storage

## 简介

First-party ConnectionDriver for S3-compatible blob storage (Cloudflare R2, AWS S3, MinIO, …). Registers /upload + /download/:blob_ref HTTP routes and read_blob/write_blob/delete_blob LLM tools. Templates that need file storage declare a `protocol: "s3"`
