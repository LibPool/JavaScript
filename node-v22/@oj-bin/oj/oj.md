# @oj-bin/oj

> 标签: backend, deno, low-code, oj, only-js, typescript, v8

## 简介

only-js (oj): low-code backend framework embedding a JS/TS runtime (V8) in Rust. Prebuilt binaries; install drops ./bin/oj + plugins + devkit into your project.
