# @decaspace/canapi

> 标签: api, auth, can, can-framework, canjs, crud, express, http, rest, typeorm

## 简介

API framework for Can apps: Express-powered REST server with TypeORM CRUD, JWT auth, and a reactive client resource layer for @decaspace/can-framework.
