# @vitronai/themis

> 标签: agentic, agents, ai, ai-agents, ai-coding, claude-code, cli, codex, cursor, deterministic, esm, html-report, intent-dsl, jest-alternative, jsdom, json-report, node-test-runner, nodejs, react-testing, rerun-failed, test-generator, test-runner, testing, tsx, typescript, unit-test, unit-test-framework, unit-testing, verdict-engine, vitest-alternative

## 简介

A Node.js and TypeScript unit test framework designed for AI coding agents. Drop-in alternative to Jest and Vitest with machine-readable failure output, structured repair hints, and one-command migration.
