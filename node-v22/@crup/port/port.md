# @crup/port

> 标签: browser, cross-origin, embed, iframe, iframe-runtime, messaging, postmessage, protocol, rpc, runtime, sdk, typescript, widget

## 简介

A lightweight protocol-first iframe runtime for building secure host/child embeds with explicit lifecycle and messaging.
