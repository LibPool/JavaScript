# @huaqiu/dsh-kicad-drc

> 标签: deepseek-harness, drc, dsh, dsh-plugin, kicad, pcb

## 简介

KiCad DRC tool for DeepSeek Harness — run kicad-cli pcb drc, return structured results, and render the report as a paginated card in the Web GUI.
