# @wit-secops/itglue-mcp

> 标签: ai, documentation, it-glue, itglue, llm, mcp, model-context-protocol, msp

## 简介

MCP server for the ITGlue API — documents, sections, organizations, configurations, contacts, locations, domains, expirations, and flexible assets, plus a local content-search index.
