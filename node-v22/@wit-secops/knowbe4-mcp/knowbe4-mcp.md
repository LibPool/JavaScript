# @wit-secops/knowbe4-mcp

> 标签: ai, knowbe4, llm, mcp, model-context-protocol, msp, phishing, security-awareness

## 简介

Read-only, multi-client MCP server for KnowBe4 security awareness training: partner-wide account and user risk figures, plus per-client phishing and training detail from the Reporting API.
