# @gaiajs/gaiajs

> 标签: JavaScript

## 简介

## gaia.js 是什么 gaia.js是基于[Egg.js][egg]的扩展框架，主要使用typescript开发。主要提供了：  * model（rpc、sequelize、mongoose）/object，cached model  * cache（couchbase/memcache/redis/context based runtime heap）  * blueprint路由  * request/response接口代码生成  * event  * kafka producer/cons
