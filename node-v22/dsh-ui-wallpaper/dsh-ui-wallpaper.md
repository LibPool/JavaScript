# dsh-ui-wallpaper

> 标签: background, deepseek-harness, dsh, dsh-plugin, theme, wallpaper

## 简介

DeepSeek Harness 自定义壁纸插件：在设置面板里选本机图片当背景，可调不透明度/模糊/界面通透度/压暗，即时预览。A DeepSeek Harness Web wallpaper plugin with a dedicated Settings section.
