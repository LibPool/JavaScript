# @sportsdataverse/sdvtables

> 标签: great-tables, gt, html-tables, sports, sports-analytics, sportsdataverse, tables, team-logos

## 简介

Publication tables for SportsDataverse data — TableSpec, 18+3 themes, team logos/headshots/colors, static HTML renderer. TypeScript port of sdvplotR gt_* / gtUtils

- 官网：https://plot.sportsdataverse.org
- 源码仓库：git+https://github.com/sportsdataverse/sdvplot-js.git
