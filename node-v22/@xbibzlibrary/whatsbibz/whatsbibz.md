# @xbibzlibrary/whatsbibz

> 标签: automation, baileys, bibzwhats, bot, multi-device, pairing-code, whatsapp, whatsapp-api, whatsapp-bot, whatsapp-web, whatsbibz, xbibz, xbibzlibrary

## 简介

WhatsBibz — WhatsApp Web multi-device library for Node.js (maintained Baileys fork): high-level client, custom pairing codes, self-healing sessions, configurable or automatic linked-device identity, complete TypeScript declarations.
