# @agentlair/x402-trust-gate

> 标签: agentlair, ai-agents, cloudflare-workers, middleware, payment, trust, x402

## 简介

Trust-gated x402 payment middleware. Agents with AgentLair behavioral trust scores pay less — trusted agents get the base price, unknown agents pay 10x, flagged agents are blocked.
