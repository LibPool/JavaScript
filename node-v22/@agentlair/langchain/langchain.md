# @agentlair/langchain

> 标签: aat, agent-authentication-token, agent-identity, agent-trust, agentlair, audit, behavioral-attestation, did-web, http-message-signatures, langchain, langchainjs, rfc9421, web-bot-auth

## 简介

AgentLair adapter for LangChain.js — issue per-agent AATs, attach Bearer tokens to tool calls, emit audit envelopes, and sign outbound HTTP requests with RFC 9421 / Web Bot Auth.
