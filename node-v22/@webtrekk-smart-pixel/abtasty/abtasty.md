# @webtrekk-smart-pixel/abtasty

> 标签: JavaScript

## 简介

The Webtrekk A/B Tasty extension makes it easier for you to analyse the displayed A/B test and variants. Using the extension, the information from A/B Tasty tests are sent directly to Webtrekk.
