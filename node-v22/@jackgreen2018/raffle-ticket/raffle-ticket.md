# @jackgreen2018/raffle-ticket

> 标签: JavaScript

## 简介

A lightweight, high-performance raffle ticket sheet generator that runs entirely in the browser or Node.js via Rust/WASM. No server required, no file uploads — 100% client-side with Rust-level speed.
