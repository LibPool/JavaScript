# @tower1229/videojs-plugin-source-switcher

> 标签: JavaScript

## 简介

videojs 视频源切换插件.基于[videojs-resolution-switcher]()项目二次开发, 支持 videojs^7.0.0; 更换构建工具为 Vite.
