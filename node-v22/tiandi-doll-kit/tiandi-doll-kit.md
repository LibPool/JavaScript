# tiandi-doll-kit

> 标签: JavaScript

## 简介

天帝(第十关 Boss)骨架成品包:站在半空、双手撑在胸前棋盘上的人形老帝王,18 根骨骼 / 18 块部件 + 手 / 笔 / 天目 / 电缆 / 蛆虫换图 + 红光明暗轨,Cocos Creator 3.8。npm 装包后跑 tiandi-doll-sync 把资源同步进工程 assets/resources/。
