# @checkpoint-irl/nativescript

> 标签: background-location, checkpoint, geofence, location, nativescript

## 简介

Checkpoint location / geofence / ingest SDK for NativeScript (iOS + Android). The TS layer drives the Capacitor-free native cores (CheckpointCore pod / dev.checkpoint:checkpoint-core AAR) via the NativeScript runtime; all detection logic runs server-side.
