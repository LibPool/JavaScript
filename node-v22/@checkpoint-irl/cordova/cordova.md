# @checkpoint-irl/cordova

> 标签: background-location, checkpoint, cordova, cordova-android, cordova-ios, ecosystem:cordova, geofence, location

## 简介

Checkpoint location / geofence / ingest SDK for Apache Cordova (iOS + Android). A thin bridge over the @checkpoint-irl/capacitor native cores; all detection logic runs server-side.
