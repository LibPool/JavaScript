# @cosyte/cli

> 标签: astm, c-cda, cli, command-line, dicom, fhir, healthcare, hl7, hl7v2, interoperability, mcp, mllp, ncpdp, typescript, x12

## 简介

The cosyte CLI: a PHI-safe developer front door over the @cosyte/* healthcare parsers. Parse HL7 v2 / FHIR from a file or stdin to typed JSON, with a documented exit-code contract.
