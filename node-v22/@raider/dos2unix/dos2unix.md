# @raider/dos2unix

> 标签: carriage return, crlf, dos2unix, lf, line endings, line feed, new line, newline, unix2dos

## 简介

A Node.js module to convert text files with DOS line breaks to Unix line breaks, i.e. like using `dos2unix`.

- 官网：https://github.com/JamesMGreene/node-dos2unix
- 源码仓库：git://github.com/JamesMGreene/node-dos2unix.git
