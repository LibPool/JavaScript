# @emisso/connect

> 标签: agentes, banco-central, bancos, chile, dte, emisso, factura-electronica, mcp, previred, sii, uf

## 简介

SDK TypeScript de Emisso Connect: un solo endpoint tipado hacia los sistemas chilenos (SII, bancos de empresa, Previred, emisión de DTE, indicadores del Banco Central).

- npm 页面：https://www.npmjs.com/package/@emisso/connect
