# @cerne1/tokens

> 标签: JavaScript

## 简介

Tokens de design do Cerne UI (cor, tipografia, espaçamento, elevação, radius, ícone) — plataforma-agnóstico. Fonte da verdade em src/*.json, transformado via Style Dictionary.
