# @layr8/mcp

> 标签: broker, claude-code, didcomm, layr8, mcp, model-context-protocol

## 简介

MCP adapter that makes non-agent runtimes (Claude Code, IDEs, CLIs, workflow engines) first-class DIDComm members of a layr8 cloud-node
