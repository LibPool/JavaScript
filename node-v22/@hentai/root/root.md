# @hentai/root

> 标签: JavaScript

## 简介

* Provide an alternative of react-formio (@tsed/react-formio) wrapper with some improvement. * Provide a @tsed/tailwind-formio package to support tailwind CSS framework with formio. * Provide a lightweight redux utils packages. * Provide a storybook
