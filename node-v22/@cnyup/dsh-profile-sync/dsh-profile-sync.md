# @cnyup/dsh-profile-sync

> 标签: backup, config, deepseek, deepseek-harness, dsh, dsh-plugin, git, multi-machine, profile, sync

## 简介

Sync a DSH profile's config across machines through a private git repo, one bucket per machine: plugin manifest, cordis patch, lockfile, pnpm policy, market plugin state, third-party theme state and the workspace table. Credentials are never included. · D
