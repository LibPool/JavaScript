# @yaebal/test

> 标签: actor, e2e, mock, telegram, telegram-bot, test, testing, yaebal

## 简介

yaebal test — an actor-driven test framework for yaebal bots: users/chats that send real updates, a virtual clock, apiError stubs, and satellite-plugin test packs.
