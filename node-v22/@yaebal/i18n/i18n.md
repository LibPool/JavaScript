# @yaebal/i18n

> 标签: i18n, localization, telegram, telegram-bot, yaebal

## 简介

yaebal i18n plugin — typed keys & params, nested dicts, Intl plurals, language_code detection, per-chat locale persistence, ctx.t / ctx.changeLanguage (powers useTranslation).
