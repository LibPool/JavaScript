# @floraspark/spark-chat

> 标签: chat, floraspark, sdk, spark-ai, web-component

## 简介

Het Spark AI-chatvenster van FloraSpark in je eigen applicatie: een web component, een React-wrapper en een server-handler die je API-sleutel op de server houdt.
