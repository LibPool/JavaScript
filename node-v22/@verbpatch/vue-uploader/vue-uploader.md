# @verbpatch/vue-uploader

> 标签: chunked-upload, headless, http, resumable-upload, tus, typescript, uploader, verbpatch, vue, websocket, webtransport

## 简介

A headless uploader library for Vue applications with full chunked upload and pause-and-resume support.
