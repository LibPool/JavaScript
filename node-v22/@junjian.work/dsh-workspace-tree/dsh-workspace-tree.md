# @junjian.work/dsh-workspace-tree

> 标签: JavaScript

## 简介

DSH 侧边栏工作区目录树：每个工作区行一键列出目录树（懒加载、目录在上文件在下），树条目右键复制相对/绝对路径、在资源管理器/终端中打开、添加到聊天；视图选项支持正常/归档会话切换，归档会话支持恢复与确认删除；会话行右键重命名；记录并恢复侧边栏宽度与收起状态
