# @prantlf/requirejs

> 标签: amd, optimizer, r-js, require, requirejs, requirejs-optimizer, umd

## 简介

Node adapter for RequireJS, for loading AMD modules. Includes RequireJS optimizer. Forked to fix the source map support.
