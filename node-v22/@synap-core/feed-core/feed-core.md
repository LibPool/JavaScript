# @synap-core/feed-core

> 标签: JavaScript

## 简介

The finishable work-feed model + store + hook factory, payload-agnostic with pluggable persistence. Framework-agnostic core + React hook. React-Native safe (no DOM/window/localStorage/AsyncStorage at module scope). Shared by Relay and the Telegram mini ap
