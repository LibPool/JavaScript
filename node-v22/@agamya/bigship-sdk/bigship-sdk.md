# @agamya/bigship-sdk

> 标签: b2b, b2c, bigship, courier, india, logistics, nextjs, shipping

## 简介

TypeScript SDK for the Bigship.direct Unified Outbound API — warehouses, orders, rates, couriers, tracking, manifests, and documents.
