# btcnotar

> 标签: bitcoin, blockchain, merkle-tree, notarization, op_return, proof-of-existence, timestamping

## 简介

Batch Bitcoin notarization: aggregate document hashes into a Merkle tree, anchor the root on-chain via OP_RETURN on a schedule, and generate per-hash proofs that can be verified independently against the live blockchain (transaction, block and date).
