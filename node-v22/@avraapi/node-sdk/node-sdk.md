> 标签: api-gateway, apix, avraapi, barcode, pdf, qr, sdk, sms

## 简介

Official TypeScript/JavaScript SDK for the APIX (AvraAPI) enterprise API gateway. Zero framework dependencies — works in any Node.js 18+ project.
