# @atomic-testing/angular-core

> 标签: JavaScript

## 简介

Shared Angular adapter core for Atomic Testing: AngularInteractor plus the bootstrapApplication-based createTestEngine. Install the per-major package (@atomic-testing/angular-20/-21/-22) instead of depending on this directly.
