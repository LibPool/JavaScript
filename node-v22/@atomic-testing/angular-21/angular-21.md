# @atomic-testing/angular-21

> 标签: JavaScript

## 简介

Angular 21 test adapter for Atomic Testing: bootstrap standalone components with Angular's real bootstrap API and test them through the component driver pattern. Thin re-export of @atomic-testing/angular-core pinned to the Angular 21 peer range.
