# @sphinxjs/cli

> 标签: JavaScript

## 简介

Command-line interface for Sphinx. Extracts translatable strings, initialises new locale `.po` files, and updates existing ones.

- npm 页面：https://www.npmjs.com/package/@sphinxjs/cli
