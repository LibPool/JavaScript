# @moltbankhq/mod-manifest-schema

> 标签: JavaScript

## 简介

Mod Protocol 1.1 manifest schema, validator, and constants. Single source of truth for the host CLI, the moltbank-app registry endpoints, and any third-party tooling that needs to validate moltbank.mod.json files.
