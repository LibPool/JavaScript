## 简介

Daily Tab Mod. Reads intel-mod's run artifacts (summary / strategy / dev-summary), appends a configurable pre-publish joke (with curated fallback rotation), and publishes the combined daily brief via cap.notify.send. Splits the daily-tab compose-and-publi
