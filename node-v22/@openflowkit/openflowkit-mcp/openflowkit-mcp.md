# @openflowkit/openflowkit-mcp

> 标签: claude, cursor, diagram, flowchart, local-first, mcp, mermaid, model-context-protocol, openflowkit, windsurf

## 简介

Local-first Model Context Protocol server for OpenFlowKit — pair the live editor or edit .openflow.json files: create/update/read diagrams from DSL, scene ops, icon search, export. No account, no cloud.
