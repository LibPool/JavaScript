# @sailei1996/enumx

> 标签: enum, typescript

## 简介

`EnumX` 是一个用于 TypeScript 的扩展类，帮助开发者更便捷地管理和操作枚举类型的数据。`EnumX` 提供了一系列访问和操作枚举项的方法，使得代码更具可读性和灵活性，尤其适用于需要字段映射、下拉列表等场景的数据管理。
