# @zeroroot-ai/zerocool-claude

> 标签: JavaScript

## 简介

Claude Code host adapter for Gibson (zerocool): the plugin bundle around the Gibson MCP server, plus SessionStart and SessionEnd hooks. The model stays on your Claude login.
