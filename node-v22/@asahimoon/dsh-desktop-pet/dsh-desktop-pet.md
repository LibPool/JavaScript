# @asahimoon/dsh-desktop-pet

> 标签: codex-pet, deepseek-harness, desktop-pet, dsh, electron, pet, petdex, tamagotchi, whale-girl

## 简介

DSH 桌面宠物（鲸鱼娘）— 透明置顶悬浮窗 + Agent 状态联动 + 热配置 + 多角色兼容（Codex/petdex）。安装：dsh plugin --profile web add @asahimoon/dsh-desktop-pet；独立运行：npx electron main.js；打包 exe：npm run dist
