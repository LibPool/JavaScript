# @osbo/policy-guard

> 标签: claude-code, cursor, license, mcp, model-context-protocol, osbo, policy, pre-commit, sbom, sca

## 简介

OSBO.AI policy at the point of generation: an MCP server for Claude Code, Cursor and OpenAI-compatible agents (validate changes, check a dependency, match a snippet against the corpus, explain licence obligations), plus a pre-commit hook and VS Code wirin
