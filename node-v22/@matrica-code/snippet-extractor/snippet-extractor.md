# @matrica-code/snippet-extractor

> 标签: code-snippets, codemod, documentation, extract-code, snippet-viewer, snippets, tree-sitter

## 简介

Multi-language (JS/TS/TSX/Java) extract-code snippet harvester. Produces the snippets.json consumed by snippet-viewer.
