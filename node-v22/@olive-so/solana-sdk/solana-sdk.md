# @olive-so/solana-sdk

> 标签: anchor, defi, market-maker, olive, options, rfq, solana

## 简介

Client and maker SDK for the Olive Solana options program: maker WebSocket transport, quote signing, canonical PDAs, and IDL-backed transaction construction.
