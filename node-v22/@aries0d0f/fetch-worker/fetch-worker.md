# @aries0d0f/fetch-worker

> 标签: comlink, fetch, http, http-client, web-worker, worker

## 简介

Native fetch, offloaded to a Web Worker — a tiny, dependency-light HTTP client with a comlink-powered worker transport and automatic main-thread fallback.
