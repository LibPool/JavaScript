# @dynamoprotocol/conformance-kit

> 标签: conformance, http-402, payments, test-vectors, verification, x402

## 简介

Dynamo Protocol public conformance kit: the rule-22 denial-class + crypto vector set, the reference credential verifier, and the endpoint-neutral x402 conformance checks/runner/CLI.
