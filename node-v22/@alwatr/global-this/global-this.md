# @alwatr/global-this

> 标签: ECMAScript, alwatr, browser, cross-platform, esm, global, global-polyfill, global-shim, globalThis, globalThis-polyfill, globalThis-shim, javascript, module, nanolib, node, nodejs, typescript, util, utility, utils

## 简介

Provides access to `globalThis`, ensuring cross-platform compatibility, including browsers (`window`), Node.js (`global`), and Web Workers (`self`).
