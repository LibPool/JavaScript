# @alwatr/lazy

> 标签: ECMAScript, alwatr, browser, cache, cross-platform, deferred, esm, gc, javascript, lazy, lazy-evaluation, lazy-initialization, lazy-loading, memoization, memoize, module, nanolib, node, nodejs, performance, typescript, util, utility, utils

## 简介

A generic, memory-efficient lazy evaluation wrapper. Defers execution of expensive initializers until the value is first accessed, then caches the result and frees the closure reference for GC.
