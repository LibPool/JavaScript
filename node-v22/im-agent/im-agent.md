# im-agent

> 标签: agent, bridge, claude-code, codex, feishu, lark, 飞书

## 简介

把飞书（以及以后的 Telegram 等）和 Web 页面桥接到本机 Claude Code / Codex：聊天驱动、卡片审批、会话与模型切换
