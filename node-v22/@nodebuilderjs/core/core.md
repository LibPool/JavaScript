# @nodebuilderjs/core

> 标签: bun, desktop, gui, jsx, linux, native, signals, tsx, wayland, x11

## 简介

Native Linux UI in TypeScript: TSX components with SolidJS-style reactivity, drawn by its own native core (Wayland/X11 + GLES2 + FreeType/HarfBuzz). No DOM, no Electron, no GTK/Qt.
