# @chest-gate/proxy

> 标签: agent, chest-gate, monetization, proxy, solana, usdc, x402

## 简介

x402 reverse proxy engine for Chest. Run your own paid API gate, sign deploy/app payloads, generate API keys, compute splits, resolve referrers.
