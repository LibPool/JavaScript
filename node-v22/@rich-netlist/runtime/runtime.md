# @rich-netlist/runtime

> 标签: netlist, rnl, schematic, spectre, spice, webassembly

## 简介

The RNL core as WebAssembly: SPICE and Spectre netlists with their RNL records read into the Documents a viewer draws, the editor interface's snapshots, and edits written back into the netlist.
