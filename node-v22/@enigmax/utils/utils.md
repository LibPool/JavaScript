# @enigmax/utils

> 标签: cache, enigma, headless, password, pwned, react, ssrf, ttl, upload

## 简介

Headless application utilities that render nothing: a short-TTL read cache with in-flight deduplication, a breached-password check that never sends the password anywhere, and server-side guards for fetching URLs from outside and handling uploads.
