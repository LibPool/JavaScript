# @gvasilei/react-lite-carousel

> 标签: JavaScript

## 简介

**ReactLiteCarousel** is a lightweight, swipeable, and responsive React carousel component.   It supports infinite looping, touch and mouse dragging, and easy customization with no dependencies.
