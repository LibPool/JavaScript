# @uni_toolkit/vite-plugin-component-config

> 标签: component, custom, miniprogram, plugin, uni-app, vite, vue3

## 简介

一个用于 UniApp 项目的 Vite 插件，用于处理 Vue 文件中的 `<component-config>` 标签，将配置提取并合并到对应的 `小程序 JSON 文件` 中。
