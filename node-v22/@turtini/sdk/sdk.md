# @turtini/sdk

> 标签: api, marketplace, modules, public-api, sdk, turtini

## 简介

Turtini SDK — Module SDK (hooks + design tokens for marketplace modules) plus the Public API client (Turtini class) for calling the Turtini API from external code.
