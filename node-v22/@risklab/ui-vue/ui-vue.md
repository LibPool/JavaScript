# @risklab/ui-vue

> 标签: components, composition-api, design-system, risklab, ui, vue, vue3

## 简介

@risklab/ui-vue — Vue 3 component library. Composition API + render functions. Same design token system as @risklab/charts and @risklab/ui-react.
