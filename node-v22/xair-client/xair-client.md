# xair-client

> 标签: behringer, mixer, mr18, osc, typescript, x-air, xair, xr12, xr16, xr18

## 简介

TypeScript client for Behringer X-Air digital mixers (XR12, XR16, XR18, Midas MR18) over OSC: discovery, values, meters. No runtime dependencies.
