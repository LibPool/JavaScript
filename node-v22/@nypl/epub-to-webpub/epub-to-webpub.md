# @nypl/epub-to-webpub

> 标签: JavaScript

## 简介

This repository is a converter between EPUBS and Webpubs. It can either be deployed as an endpoint service, consumed as a package within another Node service, or used as a CLI.

## 官网

- 官网：https://github.com/NYPL/ePub-to-webpub#readme
- 源码仓库：git+https://github.com/NYPL/ePub-to-webpub.git
- npm 页面：https://www.npmjs.com/package/@nypl/epub-to-webpub
