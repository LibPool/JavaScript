# @blanketbyte/wise-mcp

> 标签: banking, chatgpt, claude, codex, mcp, mcp-server, model-context-protocol, payments, transferwise, wise

## 简介

MCP server for Wise: read balances, card payments, transfers and recipients, and prepare transfers you approve twice. Runs locally (npx, for Claude, Codex, Cursor…) or as a remote connector for Claude and ChatGPT.
