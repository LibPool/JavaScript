# @keenable/mcp

> 标签: fetch, keenable, markdown, mcp, modelcontextprotocol, search, web, web-search

## 简介

MCP server for live web search and clean-markdown page fetch over the Keenable web index. Bridges to the hosted Keenable MCP server.
