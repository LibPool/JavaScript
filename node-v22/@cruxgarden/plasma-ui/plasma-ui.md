# @cruxgarden/plasma-ui

> 标签: animation, crux, cruxgarden, panels, react, ui, webgl

## 简介

Liquid panels for React, rendered in WebGL on canvas: every panel is one shared plasma - they fuse on contact, refract, and snap to a grid.
