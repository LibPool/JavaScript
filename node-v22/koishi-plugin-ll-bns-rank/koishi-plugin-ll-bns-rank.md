## 简介

Koishi plugin: 剑灵《仙幻·血色试炼》全服排行榜订阅推送 —— 后台设置推送群与时间点，到点从活动页抓取全榜数据，渲染成「血色天榜」描金风格卡片推送；兼容 QQ 官方机器人（Markdown 卡片 / 图片 / 纯文字三种发送格式）。
