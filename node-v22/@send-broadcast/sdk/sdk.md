# @send-broadcast/sdk

> 标签: broadcast, email, email-marketing, newsletter, sendbroadcast, transactional

## 简介

Node/TypeScript client for the Broadcast email platform. Subscribers, sequences, broadcasts, segments, templates, autopilot, webhooks, and transactional email. Works with any Broadcast instance.
