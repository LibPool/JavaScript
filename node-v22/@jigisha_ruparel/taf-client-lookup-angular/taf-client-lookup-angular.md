# @jigisha_ruparel/taf-client-lookup-angular

> 标签: JavaScript

## 简介

<taf-lookup> — a themeless combobox: a control surface (chips, a search input, a chevron) over a floating option panel with groups, per-option slots, keyboard navigation and honest loading/empty states.
