# @jigisha_ruparel/taf-client-inbox

> 标签: JavaScript

## 简介

TAF client SDK — inbox slice: one merged 'my work' feed fanned out across any entities that carry an assignee/owner field (tasks, approval steps, per-entity review queues). Generic — the caller declares the sources; no per-app entity coupling.
