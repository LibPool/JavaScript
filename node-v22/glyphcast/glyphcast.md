# glyphcast

> 标签: ascii, ascii-art, canvas, glyph, player, react, streaming, terminal, typescript, video, vue, webgl

## 简介

Video as colored glyphs: a complete WebGL2 player with controls and PiP, and a glyph stream a server can send instead of video
