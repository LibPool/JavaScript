# @incproctor/proctoring-sdk

> 标签: exam, incruiter, monitoring, proctoring, webrtc

## 简介

Browser SDK for InCruiter proctoring. Drop it into your exam page, point it at a session your backend created, and it reports browser activity, camera/microphone/screen state and evidence to the InCruiter proctoring API.
