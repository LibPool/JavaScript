# @voyant-travel/realtime-react

> 标签: JavaScript

## 简介

React hooks that make existing admin/portal screens live, consuming the channels published by [`@voyant-travel/realtime`](../realtime). Vendor-agnostic — the transport is injected as a `RealtimeConnector`.
