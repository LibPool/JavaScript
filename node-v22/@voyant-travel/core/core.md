# @voyant-travel/core

> 标签: JavaScript

## 简介

Module system and framework primitives for Voyant. Transport-agnostic — provides the contracts, registry, container, event bus, links, query, sagas, and optional plugin bundles that every Voyant module and transport adapter builds on.
