# @mambalabsdev/mcp-mobile-phone-waterfall-orchestrator

> 标签: apify, bring-your-own-key, clay, lead-generation, mcp, mobile-phone, model-context-protocol, phone-enrichment, phone-number-finder, waterfall-enrichment

## 简介

MCP server for Mobile Phone Waterfall. Find mobile phone numbers by chaining your own Prospeo, Lusha, ContactOut, and FullEnrich keys: one row per contact with the number, line type, country, Do Not Call flag, and the provider credits used. Runs on Apify.
