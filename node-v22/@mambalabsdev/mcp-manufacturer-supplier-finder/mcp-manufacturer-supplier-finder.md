# @mambalabsdev/mcp-manufacturer-supplier-finder

> 标签: apify, clay, distributors, lead-generation, manufacturers, mcp, model-context-protocol, sourcing, suppliers, wholesale

## 简介

MCP server for Manufacturer and Supplier Finder. Find manufacturers, wholesalers, and distributors for any product in 20 countries, each checked on its own website, with quoted evidence, domain, and a confidence score. Runs on Apify. Clay-ready output.
