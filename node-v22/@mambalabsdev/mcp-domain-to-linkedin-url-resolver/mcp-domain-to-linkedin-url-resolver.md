# @mambalabsdev/mcp-domain-to-linkedin-url-resolver

> 标签: apify, clay, company-url, firmographics, lead-generation, linkedin, mcp, model-context-protocol

## 简介

MCP server for Domain to LinkedIn URL Resolver. Resolves a company domain or name to its LinkedIn company URL with confidence scoring and firmographics via Apify. Clay-ready output.
