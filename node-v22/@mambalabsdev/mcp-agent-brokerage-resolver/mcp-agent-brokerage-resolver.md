# @mambalabsdev/mcp-agent-brokerage-resolver

> 标签: apify, brokerage, clay, lead-generation, license-lookup, mcp, model-context-protocol, real-estate, real-estate-agents, realtor

## 简介

MCP server for Agent to Brokerage Resolver. Look up a licensed US real estate agent on the official state register and get the brokerage of record, its active agent count and size band, and license status. 19 states; firm and zip rosters. No emails or pho
