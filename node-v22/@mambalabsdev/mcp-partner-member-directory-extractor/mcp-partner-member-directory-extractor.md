> 标签: apify, b2b, clay, lead-generation, list-building, mcp, member-directory, model-context-protocol, partner-directory

## 简介

MCP server for Partner and Member Directory Extractor. Turn a vendor partner directory (PartnerPage, Shopify Partner Directory) or a trade body member list into one company row per listing with website, domain, tier, tags, and location. Runs on Apify. Cla
