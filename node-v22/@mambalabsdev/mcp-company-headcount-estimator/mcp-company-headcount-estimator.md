# @mambalabsdev/mcp-company-headcount-estimator

> 标签: apify, clay, company-size, employee-count, firmographics, headcount, lead-generation, mcp, model-context-protocol

## 简介

MCP server for Company Headcount Estimator. Employee count band for any company domain from the LinkedIn company size in Google results, Wikidata, and the company site, with the source and a confidence score. Never opens linkedin.com. Runs on Apify. Clay-
