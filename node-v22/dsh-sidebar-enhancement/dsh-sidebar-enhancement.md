# dsh-sidebar-enhancement

> 标签: commands, cordis, deepseek, dsh, editor, file-tree, harness, plugin, sidebar, snippets, terminal

## 简介

Enhanced Sidebar files panel: rename, create, upload, download, delete and copy-full-path; an editable document renderer with save; a bottom terminal panel with a quick-command library.
