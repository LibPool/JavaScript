# @sauseschritt/eudi-rp-ts

> 标签: digital-identity, eidas, eudi, eudi-wallet, mdoc, oid4vp, openid4vp, relying-party, sd-jwt, sd-jwt-vc, verifiable-credentials

## 简介

Reference implementation of an EU Digital Identity relying party for Node — verifies SD-JWT VC and ISO mdoc credentials over OpenID4VP 1.0, with ETSI 119 612 trust lists and status-list revocation. Not affiliated with the European Commission.
