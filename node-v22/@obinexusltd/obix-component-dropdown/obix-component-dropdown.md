# @obinexusltd/obix-component-dropdown

> 标签: accessibility, component, dop, dropdown, menu, obix, overlay

## 简介

OBIX ObixDropdown overlay — accessible menu/picker with role=menu, aria-expanded trigger, and pure keyboard-navigation transitions. Data-Oriented, zero dependencies.
