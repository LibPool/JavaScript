# @soribashi/core

> 标签: cli, component-factory, design-system, design-tokens, react, soribashi, style-props, tailwindcss, theme

## 简介

Soribashi: a theme model, a component factory, and the `soribashi` CSS codegen CLI in one package. Framework only — it ships no components.
