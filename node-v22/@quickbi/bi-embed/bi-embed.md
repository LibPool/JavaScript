# @quickbi/bi-embed

> 标签: JavaScript

## 简介

Quick BI 嵌入 SDK：定义嵌入分析的四大契约——**嵌入源（src）**、**特性配置（feature）**、**行为（action）**、**事件（event）**（valibot schema + TypeScript 类型），并提供面向原生 JS / React / Vue 3 / Vue 2 的 iframe 嵌入客户端，用于将 Quick BI 页面嵌入三方系统并双向通信。
