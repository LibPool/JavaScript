# @proticom/paperboy-cli

> 标签: cli, command-line, converter, crawl, crawler, docx, epub, html, markdown, ocr, paperboy, pdf, sitemap

## 简介

Command-line edition of Paperboy: convert files and crawl entire sites to clean Markdown — offline, deterministic, scriptable (PDF, DOCX, EPUB, HTML, OCR, and more).
