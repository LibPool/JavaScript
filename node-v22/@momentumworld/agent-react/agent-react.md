# @momentumworld/agent-react

> 标签: JavaScript

## 简介

Embeddable AI agent chat widget for Country Club dashboards — floating button, popup panel, fullscreen Agent Mode, MCP tool approvals, and paginated result tables. Built exclusively on @momentumworld/ui-react.
