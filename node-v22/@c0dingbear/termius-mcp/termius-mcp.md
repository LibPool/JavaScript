# @c0dingbear/termius-mcp

> 标签: agent, mcp, opencode, sftp, ssh, termius, tunnel

## 简介

MCP server that connects agents to your Termius machines: token-authorized SSH tunnels with a native GUI approval dialog, persistent shell/exec, background tasks, and SFTP file transfer. Includes `termius-mcp setup` to auto-detect and configure agents.
