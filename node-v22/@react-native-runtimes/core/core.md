# @react-native-runtimes/core

> 标签: android, background-runtime, concurrent-rendering, fabric, headless-task, hermes, ios, multi-runtime, nitro-modules, react-native, react-native-new-architecture, runtime-function, secondary-runtime, threaded-runtime, turbomodules

## 简介

Run React Native components and functions in named secondary Hermes runtimes. Threaded surfaces, headless tasks, and cross-runtime function calls for React Native New Architecture.
