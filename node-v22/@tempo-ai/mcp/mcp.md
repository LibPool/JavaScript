# @tempo-ai/mcp

> 标签: ai-tools, claude-code, codex, mcp, model-context-protocol, tempo

## 简介

Tempo MCP server for Claude Code, Codex, Cursor, and any other MCP-compatible host. One server exposing Tempo's issues, docs, comments, agents, scripts, Slack, Linear, and canvas toolsets.
