# @kendordev/vite

> 标签: hmr, kendor, proxy, vite, vite-plugin

## 简介

Vite plugin that makes a dev server reachable + HMR-correct through the Kendor sandbox reverse proxy. No-op off-platform, so it is safe to commit to any repo.
