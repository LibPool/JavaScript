# @playground-sessions/yin-wasm

> 标签: audio, pitch, pitch-detection, wasm, web-audio, webassembly, yin

## 简介

YIN pitch detection compiled to WebAssembly with a minimal JS wrapper. Ships a playground page and typed APIs so you can swap thresholds and hop sizes and see the effect in real time. (Built during WebAudio Pitch Jam '25.)
