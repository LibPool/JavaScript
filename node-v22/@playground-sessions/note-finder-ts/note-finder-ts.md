# @playground-sessions/note-finder-ts

> 标签: audio, pitch, web-audio

## 简介

Utility that turns raw audio into musical note names with configurable tuning (A4, temperaments) and returns { note, octave, cents }. Ships as ESM with TypeScript types and zero runtime deps.
