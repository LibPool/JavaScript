# @metweave/grid

> 标签: grib2, grid, meteorology, scalar-field, visualization, weather

## 简介

Gridded scalar fields for weather maps: viz-ready container (grid header JSON + float32), GRIB2 decoding (complex packing 5.2/5.3) and crop-to-region — renderer-agnostic.
