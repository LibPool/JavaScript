# @loveebb/dsh-plugin-manager

> 标签: JavaScript

## 简介

面向用户的 dsh 插件全生命周期管理器——封装 pnpm 与 profile 配置树编辑，提供安装/卸载、启用/禁用/列表、更新/版本管理、市场浏览。
