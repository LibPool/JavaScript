# @generativereality/browser-automation

> 标签: ai-agents, browser-automation, cdp, chrome-devtools-protocol, claude-code, playwright-alternative

## 简介

Daemonless, per-tab-isolated browser automation CLI for Claude Code. Drives one shared headed Chrome (persistent profile + extensions) over per-target CDP — many parallel sessions, no focus stealing, nothing long-lived to crash.
