# @aprovan/native

> 标签: aprovan, native, sandbox, stt, utdk, vfs

## 简介

Aprovan-supplied native implementations: workspace contract backends (vfs, vcs, keyvalue, events, telemetry), on-device STT, and sandbox execution (bashkit, machine host, Node image)
