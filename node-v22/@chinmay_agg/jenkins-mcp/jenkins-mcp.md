# @chinmay_agg/jenkins-mcp

> 标签: cd, ci, claude, claude-code, deployment, jenkins, mcp, model-context-protocol

## 简介

Model Context Protocol (MCP) server for Jenkins — trigger builds/deployments, check status, read console logs, and list running builds from any MCP client (e.g. Claude Code).
