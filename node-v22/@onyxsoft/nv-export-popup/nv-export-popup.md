# @onyxsoft/nv-export-popup

> 标签: JavaScript

## 简介

Popup rápido para descargar Excel, con nombre de archivo editable. No genera ningún archivo: solo emite eventos (exportExcel, close) para que quien lo contiene resuelva la acción real. Standalone, OnPush, signals, sin lógica de negocio.
