# @nera-static/plugin-code-blocks

> 标签: code-blocks, copy-button, highlight.js, nera, nera-plugin, shiki, static-site-generator, syntax-highlighting

## 简介

A plugin for Nera static site generator to highlight fenced code blocks at build time, with a file name bar, a copy button and shell prompts.
