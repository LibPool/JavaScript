# @nera-static/plugin-feed

> 标签: atom, blog, feed, nera, nera-plugin, rss, static-site-generator, syndication

## 简介

A plugin for Nera static site generator to generate an Atom (or RSS 2.0) feed of a site's blog posts, one feed per language.
