# @nera-static/validate

> 标签: lint, nera, pug, static-site-generator, validation, yaml

## 简介

Validate a Nera site the way the build sees it — layouts and includes resolve (theme-aware), YAML parses, required frontmatter present — with structured results shared by the CLI and the Nera Pro platform
