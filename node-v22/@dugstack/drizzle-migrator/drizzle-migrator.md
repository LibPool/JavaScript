# @dugstack/drizzle-migrator

> 标签: JavaScript

## 简介

A standalone, config-driven database migration orchestrator for [Drizzle ORM](https://orm.drizzle.team) projects. The drizzle client is injected by the consumer; dialect-specific behavior lives behind subpath exports: [`/pg`](#dialects), `/mysql`, `/sqlit
