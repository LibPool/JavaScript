# @blokjs/helpers

> 标签: JavaScript

## 简介

Generic helper nodes used by the v0.5 workflow primitives — expr, ctx-publish, throw, log, audit-log, metrics-emit, in-memory-kv, json-schema. Designed to be small, predictable, AI-readable.
