# @blokjs/runtime-worker

> 标签: blok, bun, deno, grpc, nodejs, runtime, worker

## 简介

Persistent JavaScript/TypeScript execution worker for Blok — serves blok.runtime.v1 over gRPC under Node.js, Bun, or Deno.
