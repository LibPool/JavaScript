# @eight25-factory/seo-essentials

> 标签: ai-skills, canonical, contentful, contentstack, hreflang, metadata, nextjs, nuxt, open-graph, robots, seo, sitemap

## 简介

SEO essentials for Next.js and Nuxt with Contentful or Contentstack: per-entry metadata into <head>, environment-aware robots.txt, XML sitemap that skips untranslated locales, canonical URLs, og:type QA, and CMS field provisioning. Wires itself on install
