# dsh-desktop-sidecar

> 标签: automation, computer-use, deepseek, deepseek-harness, desktop, desktop-control, dsh, dsh-plugin, gui-automation, ocr, rpa, uia, windows

## 简介

DSH 桌面控制插件：让 AI 直接操作 Windows 桌面——窗口枚举、UIA 控件树、进程内 GDI 截图、离线 OCR 找字点击、UIA 调用、剪贴板输入中文、按键组合、网课自动播放。无需装驱动。Native Windows desktop control for DeepSeek Harness.
