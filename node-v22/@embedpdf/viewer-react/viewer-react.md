# @embedpdf/viewer-react

> 标签: JavaScript

## 简介

React wrapper for the full viewer: <PDFViewer> around the <embedpdf-viewer> custom element. Children are light-DOM slots — a child with slot="name" projects into the chrome's matching custom() unit while staying in YOUR React tree (your context, your CSS)
