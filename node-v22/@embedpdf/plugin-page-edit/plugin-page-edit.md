# @embedpdf/plugin-page-edit

> 标签: JavaScript

## 简介

Document-scoped page-edit capability: PON-addressed rotate/move/delete over the engine DocumentHandle. Owns relative→absolute rotation so framework adapters never re-derive it; the home for pending/undo/gating state.
