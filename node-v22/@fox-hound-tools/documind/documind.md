# @fox-hound-tools/documind

> 标签: JavaScript

## 简介

Markdownドキュメントをインテリジェントな知識ベースに変換するツールです。Documindは文書をインデックス化し、MCPサーバーを通じてAI搭載の検索機能を提供します。
