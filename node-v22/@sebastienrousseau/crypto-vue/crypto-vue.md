# @sebastienrousseau/crypto-vue

> 标签: composables, cryptography, encryption, hashing, nuxt, post-quantum, signing, vue, vue3

## 简介

Vue 3 composables for client-side cryptography: key generation, encryption, signing, hashing and post-quantum hybrid streaming encryption (ML-KEM-768), with reactive state.
