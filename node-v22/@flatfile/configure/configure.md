# @flatfile/configure

> 标签: JavaScript

## 简介

This package, `@flatfile/configure`, serves as a wrapper for the Flatfile [Blueprint](https://flatfile.com/docs/blueprint/overview) format, providing a convenient tool for schema authoring.
