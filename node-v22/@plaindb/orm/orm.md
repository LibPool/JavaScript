# @plaindb/orm

> 标签: CRUD, NoSQL, ORM, aggregator, batch-ops, database, encoder, fields, indexing, list-handlers, models, plaindb, query-engine, relations, storage

## 简介

A simple, yet extensible Object-Relational Mapping (ORM) library that allows you to interact with any key-value databse like LevelDB or Redis.
