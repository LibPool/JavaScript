# @dsh-cc/plugin-cc-codex-bridge

> 标签: JavaScript

## 简介

Official dsh-cc plugin: an approval-free Codex rescue lane — one canonical, locked-down bash invocation auto-allowed via a PreToolUse hook, with Codex's internal sandbox off while the dsh outer sandbox remains the single write boundary.
