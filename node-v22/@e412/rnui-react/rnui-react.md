# @e412/rnui-react

> 标签: JavaScript

## 简介

70+ React components built on [Base UI](https://base-ui.com/) primitives and Tailwind CSS v4. Headless accessibility from Base UI, shadcn/ui-style composability, distinctive themes from [`@e412/rnui-themes`](../themes).
