# paseo-plugin-devkit

> 标签: claude-code, cli, devtools, hermes, paseo, paseo-plugin, playwright, testing

## 简介

Unofficial dev kit for Paseo plugin authors: isolated dev daemon, host-contract checks, a scripted fake agent, web UI screenshots, registry and release helpers, plus a Claude Code skill.
