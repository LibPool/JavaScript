# @vendure/create

> 标签: JavaScript

## 简介

A CLI tool for rapidly scaffolding a new Vendure server application. Heavily inspired by [create-react-app](https://github.com/facebook/create-react-app).

## 官网

- 官网：https://www.vendure.io
- 源码仓库：git+https://github.com/vendurehq/vendure.git
- npm 页面：https://www.npmjs.com/package/@vendure/create
