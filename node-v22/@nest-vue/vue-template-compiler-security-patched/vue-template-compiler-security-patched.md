# @nest-vue/vue-template-compiler-security-patched

> 标签: compiler, vue

## 简介

Patched Vue 2.7.16 template compiler to fix XSS (CVE-2024-6783) and ReDoS (CVE-2024-9506) security vulnerabilities.
