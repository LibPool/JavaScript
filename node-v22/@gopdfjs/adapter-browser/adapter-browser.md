# @gopdfjs/adapter-browser

> 标签: JavaScript

## 简介

Browser GopdfAdapter — loads shared @gopdfjs/wasm (init fetches .wasm), pdf.js, canvas. Run pnpm --filter=@gopdfjs/wasm build:wasm first.
