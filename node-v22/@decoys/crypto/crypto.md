# @decoys/crypto

> 标签: JavaScript

## 简介

Decoy E2EE crypto — WebCrypto port of decoy-api/lib/sealed-blob.ts. Byte-compatible SealedBlob (VAULT + ENVELOPE) + RSA-OAEP/AES-GCM envelope. Runs in the browser, MV3 service worker, and Node.
