# @mt-tl/tl

> 标签: codec, codegen, mtproto, schema, telegram, tl, type-language

## 简介

TL (Type Language) tooling for MTProto: parser/IR, generic wire codec, value↔JSON, migrations, a TypeScript type generator, layer freezing, and the bundled MTProto protocol schema.
