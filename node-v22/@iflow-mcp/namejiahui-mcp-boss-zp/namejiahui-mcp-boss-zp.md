# @iflow-mcp/namejiahui-mcp-boss-zp

> 标签: boss-zp, boss直聘, mcp

## 简介

这是一个 [mcp](https://modelcontextprotocol.io/introduction) 服务器，提供大模型访问 boss 直聘部分接口的能力，让大模型替代用户人工筛选工作岗位并向 boss 打招呼
