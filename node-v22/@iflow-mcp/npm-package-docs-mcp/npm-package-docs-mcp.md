# @iflow-mcp/npm-package-docs-mcp

> 标签: docs, documentation, mcp, npm, package

## 简介

A Model Context Protocol (MCP) tool that provides up-to-date documentation for npm packages directly in your IDE. This tool fetches the latest README documentation from either the package's GitHub repository or the README bundled with the npm package itse
