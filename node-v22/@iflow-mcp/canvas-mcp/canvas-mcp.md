# @iflow-mcp/canvas-mcp

> 标签: canvas, education, gradescope, lms, mcp

## 简介

The MCP for everything EdTech. This is a collection of Canvas LMS tools for the model context protocol, which allows you to query your courses and get help for your assignments in the AI app of your choice. Try now!
