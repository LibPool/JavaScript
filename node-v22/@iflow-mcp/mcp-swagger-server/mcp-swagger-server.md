# @iflow-mcp/mcp-swagger-server

> 标签: ai, api, assistant, bridge, converter, mcp, model-context-protocol, openapi, rest, swagger

## 简介

A Model Context Protocol (MCP) server for Swagger/OpenAPI documentation that transforms OpenAPI specifications into MCP format, enabling AI assistants to interact with REST APIs through standardized protocol.
