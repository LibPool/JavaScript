# @iflow-mcp/wspringer-highs-mcp

> 标签: JavaScript

## 简介

A Model Context Protocol (MCP) server that provides linear programming (LP) and mixed-integer programming (MIP) optimization capabilities using the [HiGHS solver](https://highs.dev/).
