# @yumiku/mcp-forgejo

> 标签: ai, claude, cursor, forgejo, gitea, llm, mcp, model-context-protocol

## 简介

Model Context Protocol (MCP) server for self-hosted Forgejo. Exposes 32 tools for repos, branches, files, issues, PRs, releases, tags, and wikis via the Forgejo REST API.
