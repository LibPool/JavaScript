# @yangjingtao/hllm

> 标签: agent, anthropic-compatible, claude-code, cli, codex, human-in-the-loop, llm, openai-compatible, rlhf, training

## 简介

An OpenAI/Anthropic-compatible LLM server powered by a human — CLI trainer harness that drives a local agent (codex / Claude Code) to quiz a human answering as an LLM from the browser.
