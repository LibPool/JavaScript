# @abap2ui5/node-runtime

> 标签: abap, abap2ui5, abaplint, express, open-abap, openui5, sapui5, transpiler, ui5

## 简介

abap2UI5 for Node: the framework transpiled to JavaScript by @abaplint/transpiler over open-abap, with an HTTP handler, an express server and the ABAP sources to transpile your own apps with.
