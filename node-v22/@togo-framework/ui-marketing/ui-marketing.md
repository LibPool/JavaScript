# @togo-framework/ui-marketing

> 标签: JavaScript

## 简介

togo UI kit — landing/docs/marketing page components (Marketing, Glass, Marketplace, Docs, Terminal, ClaudeSession, BrowserFrame, MascotMark) plus the dynamic editable section board. Depends on @togo-framework/ui-core and @togo-framework/ui-markdown.
