# @itsthelore/proofkeeper

> 标签: lore, playwright, proofkeeper, qa, requirements-as-code, verification

## 简介

Lore Proofkeeper — an autonomous QA agent that drives a product, compiles the session into durable Playwright tests, gates them on fidelity, and reports which Lore capabilities are unverified.
