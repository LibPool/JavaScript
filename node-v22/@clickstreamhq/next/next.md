# @clickstreamhq/next

> 标签: analytics, clickstream, edge, middleware, next, nextjs, signals

## 简介

Next.js adapter for ClickStream. Edge middleware + Server Component / Route Handler helpers that read the first-party cookie and fetch VisitorContext server-side.
