# @bizbionic/x402-guard

> 标签: attestation, bizbionic, ed25519, guard, x402

## 简介

Fail-closed npm client for BizBionic x402 Guard. Decide → verify short-TTL ed25519 attestation → only then sign PAYMENT-SIGNATURE.

- 官网：https://guard.bizbionic.com/v1/agent.json
