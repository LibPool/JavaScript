# @dariyd/react-native-pdf-page-image

> 标签: android, codegen, fabric, image, ios, new architecture, new-architecture, pdf, pdf page, pdf renderer, pdf thumbnail, pdf to image, pdf-renderer, pdf-thumbnail, pdf-to-image, pdfkit, react native, react-native, react-native-library, react-native-module, render pdf, thumbnail, turbo module, turbomodules

## 简介

Render PDF pages to JPEG or PNG images in React Native. Built for New Architecture (TurboModules + Codegen). Uses PDFKit on iOS and PdfRenderer on Android.
