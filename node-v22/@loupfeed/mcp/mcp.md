# @loupfeed/mcp

> 标签: JavaScript

## 简介

loupfeed MCP server — lets MCP clients (Claude Code, Claude Desktop, …) pull feedback, crashes, and session replays from a loupfeed instance and close the loop: inspect → fix → reply → resolve.
