# @loupfeed/expo-inspector

> 标签: expo, expo-module, inspector, loupfeed, react-native

## 简介

Native point→element hit-test (by testID) for the loupfeed React Native inspector. An Expo module: resolves the exact tagged element under a tap via the OS view hierarchy, so element targeting works even when the app's components don't forward refs.
