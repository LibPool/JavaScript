# @valorbrain/connect

> 标签: agent-memory, claude-code, codex, cursor, grok, hermes, kiro, mcp, omp, opencode, valorbrain

## 简介

Wire any CLI agent harness (Claude Code, Kiro, OpenCode, Codex, Grok, Gemini CLI, Cursor, OMP, Hermes) to hosted ValorBrain memory.
