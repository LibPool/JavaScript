# @inxep/inputsystem

> 标签: xengine

## 简介

Unity Input System API subset on XEngine's InputManagement layer: InputActionAsset (multi-map + control schemes), Unity .inputactions JSON import, PlayerInput component, .triggered polling compat, interactive rebinding with JSON overrides. zonezero M4.
