# @inxep/platform.ios

> 标签: build, ios, toolchain, xcode, xengine

## 简介

Platform module for iOS builds: Xcode locator manifest (xcode-select / DEVELOPER_DIR / PATH) with version validation and actionable guidance. Apple licensing forbids redistributing Xcode, so this module downloads nothing — it locates, validates, and guide
