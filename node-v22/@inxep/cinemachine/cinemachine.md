# @inxep/cinemachine

> 标签: xengine

## 简介

Cinemachine 2.x API subset for XEngine: Brain (priority selection + eased blends), VirtualCamera with Transposer/Composer pipeline, FreeLook 3-rig orbit camera, Collider obstacle pull-in. zonezero M6.
