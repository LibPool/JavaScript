# @ntxmjs/react-custom-video-player

> 标签: captions, cinematic video player, custom video player, customizable player, hls.js, m3u8, modern ui, nitiksh, ntxm, ntxmjs, player, react, react component library, react hls player, react media player, react video player, responsive video player, subtitles, themeable, video, video streaming

## 简介

A modern, fully customizable React video player with HLS streaming + mp4 as well, custom subtitle support, and theme customization. Lightweight, responsive, and built for developers who need control over media playback in React JS.
