# @wmj-code/clone_npm

> 标签: AI合集, cli, cn, git, node, npm, 前端开发

## 简介

一个自定义命令行工具，打通git clone 和 npm install的流程，解决多/单项目开发中项目切换和项目依赖安装的问题
