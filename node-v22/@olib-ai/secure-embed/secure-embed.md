# @olib-ai/secure-embed

> 标签: analytics, chat-widget, credentials, embed, encryption, intercom, obfuscation, security, service-worker, third-party, wasm, webassembly

## 简介

Securely embed third-party scripts without hardcoding credentials. Uses Service Worker + WebAssembly encryption for runtime credential injection with maximum security.
