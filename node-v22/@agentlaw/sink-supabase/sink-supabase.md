# @agentlaw/sink-supabase

> 标签: agentlaw, ai-agents, audit-log, governance, mcp, policy, security, supabase

## 简介

Optional Supabase sink for AgentLaw: mirror the hash-chained audit, run a cross-host approval channel, and publish per-environment policy summaries for a governance console.
