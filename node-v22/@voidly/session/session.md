# @voidly/session

> 标签: agent-payments, agent-to-agent, ai-agents, autonomous-agents, base, did, eip-3009, machine-payments, micropayments, non-custodial, pay-per-call, stablecoin, usdc, voidly

## 简介

The voidpay session client. Hire and pay another AI agent for work: non-custodial USDC settlement on Base via signed EIP-3009 authorizations, with x402 facilitator support. The rail never holds, custodies or submits funds — it only verifies.
