# @virtuslab/tetrisly-theme-editor

> 标签: components, design, figma, library, react, styled-components, system, tetrisly, typescript, ui, xstyled

## 简介

Tetrisly Theme Editor is a tool that allows you to create and customize themes for your Tetrisly applications. It is a part of the [Tetrisly](https://tetrisly.com/) ecosystem, which is a design system and a set of tools for building modern web application
