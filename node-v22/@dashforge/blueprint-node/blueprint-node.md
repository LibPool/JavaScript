# @dashforge/blueprint-node

> 标签: blueprint, contract, dashforge, json-schema, sdui, server-driven-ui

## 简介

Server SDK for Blueprint contracts (Node/TypeScript). Load a published contract, resolve its dynamic items, fill field defaults, validate, and serve it. Agnostic (validates against the frozen contract-v1 JSON Schema) and eval-free (PCI/CSP-safe).
