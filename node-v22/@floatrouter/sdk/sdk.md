# @floatrouter/sdk

> 标签: agent, arc, circle, defi, stablecoin, usdc, usyc, wallet, yield

## 简介

Yield middleware for Circle Agent Wallets. Wrap any agent, route idle USDC into USYC, recall in seconds on Arc.
