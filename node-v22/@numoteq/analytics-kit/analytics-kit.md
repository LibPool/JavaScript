# @numoteq/analytics-kit

> 标签: analytics, astro, c15t, cloudflare-workers, consent, google-tag-manager, server-side-tagging, sgtm

## 简介

First-party analytics for Cloudflare Workers and Astro: a proxy to self-hosted server-side Google Tag Manager, server events through the Measurement Protocol, and a c15t preset
