# @caracode/fyi-cli

> 标签: cli, html, markdown, publishing, riar

## 简介

Publish Markdown, HTML and PDF docs to riar.fyi from any directory, pull in-app edits back, read docs and comments, work lists and draw sketches (agent-friendly --json).
