# @hjtdev/appkit

> 标签: JavaScript

## 简介

Shared Django + DRF + React foundation every app package and host in this ecosystem depends on — the HttpClient interface, the shared ApiClientProvider/useApiClient pair, the error envelope, and cross-half utilities. Not an installable feature; the thing
