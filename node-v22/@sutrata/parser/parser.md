# @sutrata/parser

> 标签: fountain, indic, iso-15919, parser, romanization, screenplay, sutra, unicode

## 简介

Reference parser for Sutra, a plain-text screenplay format for world languages: AST, byte-faithful round-trip, Fountain import/export, Indic romanization.
