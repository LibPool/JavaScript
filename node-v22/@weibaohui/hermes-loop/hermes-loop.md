# @weibaohui/hermes-loop

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, hermes, learning-loop, plugin, skills

## 简介

dsh 插件 · 自动复盘：对话收尾后自动复盘，把有价值的经验蒸馏成可复用的技能（skill）存入技能库，模型可直接调用；支持信号加速触发、手动立即复盘、审批模式与技能库治理（归档/恢复，永不直接删除）。
