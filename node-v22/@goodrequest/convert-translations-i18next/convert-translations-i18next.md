# @goodrequest/convert-translations-i18next

> 标签: JavaScript

## 简介

This scripts are converting JSON files which is generated by  [ i18next ](https://www.npmjs.com/package/i18next) to CSV file and also back from CSV to JSON files.

## 官网

- 官网：https://github.com/GoodRequest/i18nextJsonToCsv#readme
- 源码仓库：git+ssh://git@github.com/GoodRequest/i18nextJsonToCsv.git
- npm 页面：https://www.npmjs.com/package/@goodrequest/convert-translations-i18next
