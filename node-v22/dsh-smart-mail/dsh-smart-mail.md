# dsh-smart-mail

> 标签: automation, deepseek-harness, dsh, dsh-bundle, dsh-plugin, email, imap, mail, smtp

## 简介

Smart mail for DSH: multi-account IMAP/SMTP send & read tools plus whitelist-only headless wake on new mail (QQ/163/Gmail/Outlook presets, custom servers, authorization-code auth).
