# @k8ordo/color-scheme

> 标签: color-scheme, dark-mode, prefers-color-scheme, react, server-components, theme

## 简介

The colour-scheme axis of an application, owned: the visitor's light / dark / system preference, kept in localStorage, resolved against the system, put on <html> before the first paint and kept there.
