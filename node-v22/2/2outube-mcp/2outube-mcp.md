# 2outube-mcp

> 标签: mcp, model-context-protocol, transcript, youtube

## 简介

stdio shim for the 2outube MCP server — read YouTube video transcripts from any MCP client (bridges npx/claude-desktop to the remote streamable-HTTP endpoint)

## 官网

- 官网：https://2outube.com
- npm 页面：https://www.npmjs.com/package/2outube-mcp

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install 2outube-mcp`
- npm registry：https://registry.npmjs.org/2outube-mcp
- Node 要求：>=18
