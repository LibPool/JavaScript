# 2dai-cloud-sdk

> 标签: 2dai, agents, ai, api-client, claude, generative-ai, image-generation, image-to-video, mcp, sdk, text-to-image, typescript, video-generation

## 简介

Typed JavaScript/TypeScript client for the 2DAI generation API — generate images & video, upload references, and download results with an API key.
