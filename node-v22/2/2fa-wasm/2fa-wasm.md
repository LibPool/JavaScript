# 2fa-wasm

> 标签: 2fa, assemblyscript, authenticator, base32, constant-time, google-authenticator, hmac, hotp, otp, otpauth, rfc2104, rfc4226, rfc4648, rfc6238, sha1, sha256, sha512, totp, two-factor, typescript, wasm, webassembly, zero-alloc, zero-allocation

## 简介

Biblioteca 2FA zero-allocation (HOTP/TOTP/Base32, RFC 4226/6238/4648) en AssemblyScript/WebAssembly con wrapper TypeScript. Compatible con otpauth:// (Google Authenticator), validación constant-time, ~478K TOTP/s.
