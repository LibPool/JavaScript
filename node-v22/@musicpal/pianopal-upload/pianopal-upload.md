# @musicpal/pianopal-upload

> 标签: cloudflare-stream, mcp, pianopal, tus, upload

## 简介

Uploads media into the PianoPal library for partners authoring courses over the PianoPal MCP — as a command-line tool, or as a local MCP server that gives an AI assistant an upload tool.
