# @node-idempotency/core

> 标签: api-idempotency, at-least-once semantics, data consistency, deduplicate, distributed-systems, duplicate handling, http-idempotency, idempotency, idempotency-key, idempotent, idempotent request, node-idempotency, nodejs, request deduplication, request-deduplicate, request-deduplication, request-idempotency, retry with safety, safe operation

## 简介

A Race-Condition free Node.js library that ensures idempotency for requests, preventing unintended duplicate operations.
