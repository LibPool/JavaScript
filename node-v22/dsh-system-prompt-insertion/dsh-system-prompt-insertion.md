# dsh-system-prompt-insertion

> 标签: deepseek-harness, dsh, dsh-plugin, instructions, panel, prompt, prompt-insertion, sidebar, system-prompt

## 简介

User-owned system-prompt insertion for DeepSeek Harness: place your own text at the head, middle, or tail of the assembled prompt, and edit it from a left-column Web panel with a live preview.
