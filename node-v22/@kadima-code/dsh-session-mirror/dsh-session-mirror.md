# @kadima-code/dsh-session-mirror

> 标签: backup, conversation, deepseek-harness, dsh, dsh-plugin, restore, session

## 简介

按会话逐个镜像备份 DSH 对话日志到指定目录：每个对话一份最新，未变化则跳过；保留源已删除的会话（防误删），并区分主对话/子对话。
