# searchcast

> 标签: fingerprint, libcurl-impersonate, recipe, scraping, search, searchcast, self-hosted, serp

## 简介

Keyless search engines over HTTP with a real browser's fingerprint (libcurl-impersonate), driven by recipes, with an engine chain that falls back to a real browser (@searchcast/browser).
