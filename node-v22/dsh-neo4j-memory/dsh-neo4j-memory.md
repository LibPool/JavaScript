# dsh-neo4j-memory

> 标签: agent-memory, deepseek-harness, dsh, graph-memory, knowledge-graph, long-term-memory, neo4j

## 简介

Community Neo4j graph-memory plugin for DeepSeek Harness on Windows: events, people, concepts and places, with a local runtime, settings UI and read-only graph viewer
