# @bikramdas1/swift-iso20022-mcp

> 标签: banking, iso20022, mcp, mt103, pacs008, payments, swift

## 简介

MCP server exposing SWIFT MT and ISO 20022 MX (pacs.008/pacs.009) message validation, BIC/IBAN checks, and MT103->pacs.008 field mapping as tools for AI agents.
