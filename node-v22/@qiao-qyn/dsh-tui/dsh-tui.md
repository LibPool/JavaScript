# @qiao-qyn/dsh-tui

> 标签: agent, cli, deepseek, dsh, ink, react, tui

## 简介

The dsh Claude Code-style terminal UI bundle: an interactive Ink-based REPL over dsh-base with no Host, HTTP, or browser layer.
