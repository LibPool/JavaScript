# @ferrow/stable-stringify

> 标签: agent-tools, cache-key, deterministic-json, hash, json-stringify, sha256, sorted-keys, stable-stringify

## 简介

Deterministic JSON.stringify with recursively sorted keys, cycle detection, key filtering/replacer, stable number formatting, a streaming generator API, and a hashObject(obj) -> sha256 helper for cache keys and dedup.
