# @ferrow/pagination-helper

> 标签: cursor, keyset, offset, pagination, pagination-helper, typescript

## 简介

Cursor and offset pagination over in-memory arrays, with opaque base64url cursors, tamper detection, and a keyset (seek) helper for pagination that stays stable under concurrent inserts. Zero runtime dependencies.
