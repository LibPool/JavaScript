# @ferrow/cron-expression-parser

> 标签: agent-tools, cron, cron-expression, cron-parser, nextRun, schedule, task-scheduler

## 简介

Zero-dependency 5-field cron parser: ranges/steps/lists/names, precise validation errors, nextRun/nextN with a bounded UTC search, and describe() for human-readable schedule sentences.
