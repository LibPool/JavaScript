# @ferrow/deep-merge-patch

> 标签: agent-tools, deep-merge, immutable, json-merge-patch, patch, prototype-pollution, rfc7386

## 简介

RFC 7386 JSON Merge Patch (apply AND generate) plus a deep-merge with configurable array strategies (replace/concat/unionBy), a prototype-pollution guard, and fully immutable inputs.
