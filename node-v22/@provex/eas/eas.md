# @provex/eas

> 标签: JavaScript

## 简介

Ethereum Attestation Service primitives behind Provex identity, age, and release credentials — the schema definitions, the per-chain deployment addresses, the claim encoders, and the decoders and signature-recovery helpers a third party needs to **verify*
