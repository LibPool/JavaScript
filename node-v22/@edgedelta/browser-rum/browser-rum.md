# @edgedelta/browser-rum

> 标签: edgedelta, observability, opentelemetry, otlp, real-user-monitoring, rum, web-vitals

## 简介

Edge Delta Real User Monitoring for the browser. Ships view traces, fetch spans, Core Web Vitals, and JS errors to an Edge Delta ingestion pipeline over OTLP/HTTP.
