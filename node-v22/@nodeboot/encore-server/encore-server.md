# @nodeboot/encore-server

> 标签: encore, encore.dev, encore.ts, nodeboot

## 简介

Node-Boot Encore.ts server package. It lets you run a NodeBoot application as an Encore.ts service by exposing a raw endpoint handler, with support for routing, middleware, and request handling.
