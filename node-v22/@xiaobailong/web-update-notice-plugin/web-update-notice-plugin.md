# @xiaobailong/web-update-notice-plugin

> 标签: notice, plugin, update, vite, vite-plugin

## 简介

🔔 一款网页更新通知插件，在系统发布新版本时自动提醒用户刷新页面 🔄。全面支持 Vite、Nuxt 和 Webpack 生态 ⚡。
