# homebridge-yamaha-receiver-scenes

> 标签: homebridge-plugin, homebridge-yamaha, homebridge-yamaha-receiver, multi-zone, rx-v675, scenes, yamaha

## 简介

Homebridge plugin for Yamaha Audio Receivers with scene switches, zone-aware remote keys and better error handling (fork of homebridge-yamaha-receiver)
