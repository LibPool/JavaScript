# @sapt/analytics

> 标签: analytics, marketing, pageview, sapt, shopify, tracking

## 简介

Lightweight analytics SDK for Sapt. Drop-in script tag or programmatic client for pageviews, clicks, scroll depth, engagement, and custom events.
