# @herelsp/md-pdf-tool

> 标签: adoc, asciidoc, cli, documentation, markdown, pagedjs, pdf, plantuml, playwright

## 简介

Convert Markdown or AsciiDoc files to professional PDF with markdown-it / asciidoctor.js, Paged.js and Playwright (browser-rendered, no LaTeX).
