# ops-patent-search

> 标签: ai-tools, claude, epo, intellectual-property, mcp, model-context-protocol, open-patent-services, patent-search, patents

## 简介

Unofficial MCP server for exploring patents via the EPO Open Patent Services (OPS) API. Not affiliated with the EPO. An exploratory tool for Claude Desktop and other MCP clients — not a substitute for specialised patent search platforms.
