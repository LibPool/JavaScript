# ohh-ui

> 标签: components, oh-ui, ui, vue

## 简介

一个奇怪的ui库，本意是补充常规ui库所缺少的特色组件，比如clock组件，是常规ui库都没有的，因为非常规，所以强烈建议不要全局导入oh-ui组件库，否则可能导致你的项目体积增大。
