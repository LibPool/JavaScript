# opencode-team-mode

> 标签: ai-coding, collaboration, desktop, multi-agent, opencode, opencode-plugin, plugin, team-mode

## 简介

Team collaboration mode plugin for OpenCode Desktop — injects specialized agents (architect, reviewer, implementer, tester, researcher) and team workflow commands into your OpenCode workspace.
