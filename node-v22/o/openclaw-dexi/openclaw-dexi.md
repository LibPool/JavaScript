# openclaw-dexi

> 标签: dexi, mcp, memory, notes, openclaw, openclaw-plugin

## 简介

Dexi memory plugin for OpenClaw — your notes library as the agent's long-term memory (auto-recall, dexi_* tools, /remember, optional session digest)
