# orbit-transfer-wasm

> 标签: erasure, fountain, hdpc, ldpc, orbit-transfer, p2p, raptor, rateless, wasm, webrtc

## 简介

Rateless fountain codes (LDPC + HDPC precoding) with TypeScript bindings for Orbit-Transfer: encode/decode files in the browser with built-in loss tolerance
