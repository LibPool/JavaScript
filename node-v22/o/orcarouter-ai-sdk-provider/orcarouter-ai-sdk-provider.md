# orcarouter-ai-sdk-provider

> 标签: ai, ai-sdk, llm, openai-compatible, orcarouter, provider, vercel-ai-sdk

## 简介

The OrcaRouter provider for the Vercel AI SDK — access 150+ models from OpenAI, Anthropic, Google, xAI, DeepSeek, Qwen and others through a single OpenAI-compatible API with adaptive per-request routing.
