# orizn-visa-mcp

> 标签: ai-agent, claude, country, gpt, immigration, mcp, model-context-protocol, orizn, passport, travel, visa

## 简介

MCP server that gives an AI assistant visa and entry requirements for any passport/destination pair, in 15 languages: requirement type, visa-free days, documents, fees, processing times, photo specs, transit visas, embassies, overstay penalties, safety, v
