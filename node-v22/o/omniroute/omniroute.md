# omniroute

> 标签: ai, anthropic, auto-fallback, claude, cline, codex, cursor, fallback, gemini, llm, openai, proxy, router

## 简介

Unified AI router with 352 providers, RTK+Caveman compression, auto fallback, MCP/A2A, desktop, PWA, and OpenAI-compatible APIs.
