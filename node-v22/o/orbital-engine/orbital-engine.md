# orbital-engine

> 标签: 3d, astronomy, kepler, orbital-mechanics, react-three-fiber, solar-system, three.js, webgl

## 简介

A true-scale orbital mechanics rendering engine for react-three-fiber — real Keplerian orbits and single-snapshot fixed positions in one data contract, with a pixel-floor system so true-to-scale bodies stay visible.
