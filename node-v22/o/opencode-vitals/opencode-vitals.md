# opencode-vitals

> 标签: arabic, arabic-support, benchmark, bidi, composer, i18n, in-app, latency, observability, opencode, opencode-plugin, right-to-left, rtl, session-metrics, tokens-per-second, unicode-bidi, vitals

## 简介

OpenCode V2 plugin that shows session turns, steps, and average streaming tok/s inside OpenCode's own composer, and fixes Arabic (RTL) text direction in messages and the prompt box
