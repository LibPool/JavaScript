## 简介

❂  Objecture
⏣  Object Watcher, Property Manager
      ⊚  Capture property changes for object, array mutator methods.
      ⊚  Schematize and validate object, array properties.
      ⊚  Browser, NodeJS compatible.
⁘  Uses Core-Plex - Event Listener Manage
