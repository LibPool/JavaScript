# oyapicks-mcp

> 标签: algorand, alpha-arcade, base, mcp, modelcontextprotocol, polymarket, prediction-markets, usdc, x402

## 简介

Prediction-market data as MCP tools. Pay per call in USDC on Algorand or Base via x402. No API key, no account.
