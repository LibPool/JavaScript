# openfal-ts

> 标签: buses, fal, italy, trains, transportation

## 简介

openFAL-ts is a TypeScript implementation of FAL's (Ferrovie Appulo Lucane) private API's.   **It is meant as a educational project and is not affiliated with FAL in any way.**
