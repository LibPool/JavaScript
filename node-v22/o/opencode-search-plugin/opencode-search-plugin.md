# opencode-search-plugin

> 标签: agent, opencode, opencode-plugin, search, serp, websearch

## 简介

Twenty-one self-contained websearch provider plugins for OpenCode v2: AnySearch, Bocha, Brave, DeepSeek, Doubao, Jina, Kagi, Keenable, Linkup, Metaso, Moonshot, Moonshot CN, Ollama, Perplexity, Querit, SerpApi, Serper, StepFun, You.com, Z.ai and Zhipu.
