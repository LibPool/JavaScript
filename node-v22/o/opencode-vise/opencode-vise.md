# opencode-vise

> 标签: agent, behavioural-gate, guardrail, opencode, opencode-plugin, regression, vise

## 简介

An opencode plugin that gates an agent's changes against a frozen behavioural baseline, using the vise CLI as a tamper-proof judge.
