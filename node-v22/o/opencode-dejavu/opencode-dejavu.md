# opencode-dejavu

> 标签: ai-agents, bun, coding-agent, error-gates, memory, opencode, opencode-plugin, reliability

## 简介

Cross-session memory prosthesis for OpenCode: detects recurring tool-call failures and promotes them into enforced gates. Remind first, block on same-session repeat offense.
