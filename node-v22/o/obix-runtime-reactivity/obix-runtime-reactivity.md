# obix-runtime-reactivity

> 标签: computed, native, obix, reactivity, ref, runtime, watch

## 简介

The reactivity of OBIX's native runtime, its own: ref, computed, watch, effects with dependency tracking, batching, an ordered update queue and cleanup. No framework, no DOM. Phase 6 (docs/recovery/native-runtime.md).
