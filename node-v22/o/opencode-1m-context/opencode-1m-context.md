# opencode-1m-context

> 标签: 1m, anthropic, claude, context, copilot, github, gpt, opencode, plugin

## 简介

OpenCode plugin that enables 1M token context window for Claude and GPT-5 models on any provider (Anthropic direct, third-party gateways, Amazon Bedrock, GitHub Copilot, etc.)
