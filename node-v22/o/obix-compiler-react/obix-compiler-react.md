# obix-compiler-react

> 标签: compiler, dop, lowering, obix, react

## 简介

The React frontend of the OBIX compiler: React / TSX source lowered — read with the TypeScript compiler API, never by running React — into the canonical, frontend-neutral OBIX DOP IR of obix-compiler-ir, with the source provenance kept in a separate docum
