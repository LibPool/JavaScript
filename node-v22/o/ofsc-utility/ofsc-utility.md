# ofsc-utility

> 标签: field-service, ofsc, ofsc-plugin, oracle, oracle-cloud, oracle-field-service, oracle-field-service-cloud, oracle-ofsc

## 简介

TypeScript helpers for Oracle Field Service Cloud (OFSC): events, resources, inventories, metadata and CSV/Excel utilities.
