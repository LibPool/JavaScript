# offline-cloudinary

> 标签: cloudinary, emulator, express, file-system, file-upload, http, local-storage, mock, nodejs, offline, server, testing, upload

## 简介

An offline Cloudinary-like file manager with HTTP server emulator for local uploads, deletions, and testing without internet access.
