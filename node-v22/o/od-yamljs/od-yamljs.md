# od-yamljs

> 标签: json, json2yaml, yaml, yaml2json

## 简介

Standalone JavaScript YAML 1.2 Parser & Encoder. Works under node.js and all major browsers. Also brings command line YAML/JSON conversion tools. Supports block line number extraction.
