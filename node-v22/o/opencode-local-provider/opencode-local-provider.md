# opencode-local-provider

> 标签: exo, llama.cpp, llm, lmstudio, local, mlx-vlm, ollama, omlx, opencode, plugin, vllm

## 简介

OpenCode plugin that adds a 'local' provider with auto-detection for Ollama, LMStudio, llama.cpp, vLLM, Exo, llama-swap, oMLX, and MLX-VLM
