# overgrowth

> 标签: cleanup, cli, disk-space, node_modules, prune, trash, tui

## 简介

Reclaim disk space from heavy build artifacts. `overgrowth` scans a directory tree for `node_modules` folders (or any directory name you choose), shows them in a fast interactive terminal UI, and moves the ones you pick to the OS trash.
