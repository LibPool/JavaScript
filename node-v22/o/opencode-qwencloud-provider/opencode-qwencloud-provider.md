# opencode-qwencloud-provider

> 标签: ai, deepseek, glm, happyhorse, image-generation, llm, opencode, opencode-config, opencode-provider, provider, qwen, qwencloud, video-generation, wan

## 简介

QwenCloud provider for opencode — chat models (Qwen3.8, Qwen3.7, Qwen3.6, DeepSeek V4, GLM-5.2) via OpenAI-compatible API, plus Wan image generation and HappyHorse video generation as a plugin.
