# outlaw-cli

> 标签: JavaScript

## 简介

Formerly 'squad-cli'. A cli for running ADI's internal version of the Outlaw testing processor, with direct integration to Nightwatch.js. This module is completely useless outside of the ADI network. A public release may come in the future, but not now.
