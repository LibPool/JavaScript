# orkos

> 标签: application-framework, dependency-injection, dependency-order, graceful-shutdown, lifecycle, modular, module, module-loader, orchestrator, plugin-system, shutdown, startup, topological-sort, typescript

## 简介

A lightweight modular application orchestrator for TypeScript with dependency-ordered startup, shutdown, and topological module resolution.
