# opencode-secrets-env

> 标签: dotenv, env, environment-variables, mcp, opencode, opencode-plugin, secrets

## 简介

OpenCode plugin that injects secrets from ~/.config/opencode/secrets.env into process.env at startup, hot-reloads them on change, and reconnects MCP servers so they pick up new values
