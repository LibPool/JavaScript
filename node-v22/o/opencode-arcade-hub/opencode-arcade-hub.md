# opencode-arcade-hub

> 标签: agent, arcade, github, gmail, mcp, opencode, opencode-plugin, slack, tool-discovery, tools

## 简介

Let OpenCode use Arcade — external-service tools across every app you've connected over one MCP connection, with app sign-in handled in the browser.
