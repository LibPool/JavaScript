# o1x-launchpad-sdk

> 标签: api-client, base, launchpad, o1, o1.exchange, robinhood-chain, uniswap-v4, unofficial

## 简介

Unofficial typed TypeScript client for the o1 Launchpad Public API (Base + Robinhood Chain). Reads, swap quotes, and byte-for-byte passthrough of unsigned transaction plans. Never signs, never broadcasts. Not affiliated with o1.exchange.
