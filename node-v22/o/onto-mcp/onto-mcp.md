# onto-mcp

> 标签: agent-tools, ai-agents, code-review, domain-model, knowledge-graph, llm, mcp, mcp-server, model-context-protocol, ontology, ontology-extraction, spreadsheet-review, static-analysis, structured-output

## 简介

MCP server for LLM agents: check an artifact's ontological integrity (the logical consistency of its concepts, authority, and purpose) and derive a domain ontology from real sources, with every structured claim gated by runtime validation.
