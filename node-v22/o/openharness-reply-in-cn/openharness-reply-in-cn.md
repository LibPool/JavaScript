# openharness-reply-in-cn

> 标签: chinese, deepseek-harness, dsh, dsh-plugin, plugin, reply-in-cn, zh-cn

## 简介

DSH plugin that shows a '中文回复' label in the web sidebar and forces the model to reply in simplified Chinese.
