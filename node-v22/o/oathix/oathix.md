## 简介

Zero-dependency OAuth 2.0 client for Node.js — Google, GitHub, Facebook, Discord, Microsoft, Snapchat, TikTok, LinkedIn, Spotify & Twitter/X. Token refresh, user profiles, popup/redirect login, token storage, TypeScript support. 3 lines to add social logi
