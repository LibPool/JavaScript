# offlibrary

> 标签: background-fetch, cache-api, download, indexeddb, offline, podcast, progressive-web-app, pwa, range-requests, service-worker, storage

## 简介

Declarative offline asset management for the web: Background Fetch when available, a resumable streaming fallback when not, plus quota, eviction and range-request serving for offline media.
