# openmrs-sdk

> 标签: clinical-data, digital-health, ehr, emr, fhir, fhir-r4, global-health, health-informatics, healthcare, hl7-fhir, interoperability, medical-records, openmrs, patient-data, rest-api

## 简介

Lightweight, zero-dependency JavaScript/TypeScript client for the OpenMRS REST and FHIR R4 APIs. Works in Node.js, Deno, Bun, and modern browsers.
