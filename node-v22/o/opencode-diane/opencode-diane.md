# opencode-diane

> 标签: agents.md, bm25, experience-reuse, language-agnostic, memory, opencode, opencode-plugin, token-saving

## 简介

OpenCode plugin: hierarchical, token-efficient memory for any git repository. Convention-free — pre-fills from git diff-structure and project files, no LLM at the core, no commit-message parsing. Optional cross-lingual semantic search; skill mining.
