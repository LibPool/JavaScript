# omgobj

> 标签: 3d, loader, model, obj, plask

## 简介

OMG OBJ is an OBJ mesh reader in JavaScript.  It was written for use in Plask (www.plask.org), but is applicable elsewhere.

- 源码仓库：https://github.com/deanm/omgobj
- npm 页面：https://www.npmjs.com/package/omgobj
