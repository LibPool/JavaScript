# opencode-proxy-inject

> 标签: clash, env, opencode, plugin, proxy

## 简介

OpenCode plugin: inject proxy env vars (ALL_PROXY/HTTPS_PROXY/NO_PROXY) at startup so Bun fetch routes through Clash mixed-port
