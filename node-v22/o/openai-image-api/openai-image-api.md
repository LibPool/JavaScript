# openai-image-api

> 标签: admin-api, ai-image, cli, cost-assessment, gpt-image, gpt-image-1.5, gpt-image-2, gpt-image-2.5, gpt-image-2.5-flare, gpt-image-2.5-sunburst, image-edit, image-generation, openai, partial-images, streaming, text-to-image, typescript, usage-api

## 简介

Generate and edit images through the OpenAI Image API — GPT Image 2.5 (Sunburst, Flare), GPT Image 2 and 1.x — with streaming partial images, an organization image-cost assessment, a CLI, and TypeScript types
