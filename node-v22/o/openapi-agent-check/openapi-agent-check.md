# openapi-agent-check

> 标签: agent-readiness, ai-agents, api, lint, llm, mcp, openapi, tool-calling

## 简介

Score how well AI agents will use your API, 0-100, from its OpenAPI 3.0/3.1 spec: 13 rules for operationIds, descriptions, parameters, examples, schemas, errors, pagination, auth, idempotency and tool count.
