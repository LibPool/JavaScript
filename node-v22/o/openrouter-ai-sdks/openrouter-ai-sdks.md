# openrouter-ai-sdks

> 标签: ai, anthropic, chat, completion, llm, nodejs, openai, openrouter, sdk

## 简介

A small Node.js client for [OpenRouter](https://openrouter.ai), the API that gives you one HTTP interface to hundreds of chat models (OpenAI, Anthropic, Google, Meta, and more) instead of a different SDK and a different bill for each one.
