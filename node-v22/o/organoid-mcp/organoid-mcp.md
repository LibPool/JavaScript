# organoid-mcp

> 标签: dataset, embodied-ai, lerobot, mcp, model-context-protocol, mujoco, qa, robotics, validation

## 简介

MCP stdio shell for the organoid embodied-robot dataset QA kernel: 9-format lossless ingestion, 10 validators, six-state claim ledger. Perception-grade honesty: not_evaluated means insufficient evidence, never failure.
