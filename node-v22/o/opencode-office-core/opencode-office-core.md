# opencode-office-core

> 标签: docx, office, opencode, powerpoint, pptx, python-docx, python-pptx, word

## 简介

Read, edit, create, and render .docx/.pptx files (python-docx / python-pptx / LibreOffice under the hood). TypeScript source, executed directly by Bun/opencode — not a compiled Node package.
