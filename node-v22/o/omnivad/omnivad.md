# omnivad

> 标签: asr, audio, audio-classification, audio-event-detection, audio-segmentation, browser, fireredvad, music-detection, ncnn, nodejs, omnivad, real-time, singing-detection, speech, speech-detection, speech-segmentation, streaming-vad, vad, voice-activity-detection, wasm, webassembly, whisper, whisperx

## 简介

Cross-platform Voice Activity Detection and Audio Event Detection via WebAssembly. Runs in browsers, Web Workers, and Node.js. Built on FireRedVAD. Whisper-ready chunking included.
