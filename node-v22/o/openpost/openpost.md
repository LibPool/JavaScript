# openpost

> 标签: api-client, api-testing, graphql, headless, http, mcp, mock-server, postman-alternative, rest

## 简介

Headless REST & GraphQL API client — collections, environments, mock servers, MCP servers, vault, and license management. No UI, no VS Code dependency.
