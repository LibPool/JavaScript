# openstylus

> 标签: JavaScript

## 简介

Brand-neutral, code-on-disk canvas for iterating on rendered React/CSS assets. One local node (>=22.13) process hosts a Streamable-HTTP canvas-loop MCP + a first-party SSE channel + the web UI over one node:sqlite sidecar; the engine is config-parameteriz
