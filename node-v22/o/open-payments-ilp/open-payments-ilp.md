# open-payments-ilp

> 标签: better-auth, effect, gnap, hono, http-message-signatures, ilp, interledger, open-payments, stream

## 简介

Web Standards toolkit for Open Payments and Interledger: ILP/STREAM codecs, HTTP message signatures, GNAP, and a Better Auth GNAP plugin. Effect-native.
