# open-museum-mcp

> 标签: art, art-history, art-institute-chicago, cleveland-museum, europeana, mcp, metropolitan-museum, model-context-protocol, museum, open-access, wikimedia-commons

## 简介

MCP server for license-verified search across open-access museum collections (The Met, Rijksmuseum, Smithsonian, Cleveland, AIC, SMK, Walters, Wellcome, National Gallery of Art, Harvard, Getty, Wikimedia Commons, Europeana, and growing).
