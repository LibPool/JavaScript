# oh-my-ssh

> 标签: cli, devops, host-manager, ink, self-hosted, sftp, ssh, ssh-client, ssh-config, termius, termius-alternative, tui

## 简介

Self-hosted SSH host manager for the terminal. CLI + TUI, projects your hosts into ~/.ssh/config so ssh, scp, sftp and VSCode Remote work unchanged.
