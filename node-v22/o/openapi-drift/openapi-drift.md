# openapi-drift

> 标签: api-drift, api-testing, contract-testing, express, fastify, github-action, nestjs, openapi, spring-boot, swagger

## 简介

Keeps an OpenAPI document honest: compares it with the routes in your NestJS, Express, Fastify or Spring code and reports the drift, as a CLI and a GitHub Action.
