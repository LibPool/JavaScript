# onnx-fp16-guard

> 标签: batch-normalization, browser, edge, float16, fp16, inpainting, lama, model-compression, onnx, onnxruntime, onnxruntime-web, quantization, quantize, wasm, webgpu

## 简介

Safe fp16 (float16) conversion for ONNX models. Detects and fixes the BatchNorm range overflow that silently destroys quantized models.
