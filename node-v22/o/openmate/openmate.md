> 标签: antigravity, cli, code shortcuts, collections, cursor, dev workflow, developer tools, local repos, multi-repo, open multiple projects, open repositories, productivity, project manager, quick-open, repo, repository-manager, vscode, windsurf, workspace manager

## 简介

OpenMate: A fast CLI tool to open local repos or entire collections in VS Code, Windsurf, or Cursor using simple shortcuts for an efficient developer workflow.
