# opencode-jev-compaction

> 标签: compaction, context, cost, jev, opencode, opencode-plugin, tokens, typesafe

## 简介

opencode plugins that shrink context by deleting provably-stale tool calls and truncating the rest, deterministically first, with an optional local Laya backend.
