# ocean-mail-list

> 标签: JavaScript

## 简介

ocean-mail-list 是基于 vue-cli 4.x 而搭建的一个用于通讯录需求的项目; launch-group-chat 是通讯录项目中发起群聊的组件;group-chat-dialog是通讯录发起群聊中的弹框组件
