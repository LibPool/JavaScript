# offhook-agent

> 标签: ai-safety, evals, livekit, mcp, phone, receptionist, self-hosted, self-improving, sip, stt, telephony, tts, voice-agent, voice-ai

## 简介

The open, safety-first voice agent: it tests itself with adversarial callers and improves itself from real calls — gated so it can't break its own safety. Self-hostable, BYOK, any model.
