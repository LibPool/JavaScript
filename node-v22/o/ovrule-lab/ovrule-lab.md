# ovrule-lab

> 标签: agent-safety, ai-audit, ai-governance, ovrule, receipt-verification, typescript-sdk

## 简介

TypeScript SDK for Ovrule — accountability guardrails for AI agents: classify an action, guard a tool call (incl. the accounts-payable / payment-fraud pack), and verify signed receipts.
