# omgosc

> 标签: open sound control, osc

## 简介

OMG OSC is an OSC implementation in JavaScript, using the UDP protocol libraries from NodeJS, and the ArrayBuffer implementation for type conversions.  It was written for use in Plask (www.plask.org), but is applicable elsewhere.
