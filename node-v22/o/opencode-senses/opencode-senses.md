# opencode-senses

> 标签: moondream, multimodal, ocr, opencode, plugin, screenshot, vision

## 简介

Vision for text-only OpenCode models. Attach a screenshot, mockup, or web URL, and the model sees it — grounded OCR, layout, object detection, colors, image diffing, and 13 senses_* tools. Fully local, private, and free.
