# obix-binding-jsx

> 标签: accessibility, adapter, components, data-oriented, hyperscript, jsx, obinexus, obix, ui, wcag

## 简介

JSX factory (h / Fragment) and the JSX integration layer (functional, OOP, reactive bridges and mount) for OBIX components. No React, no virtual DOM.
