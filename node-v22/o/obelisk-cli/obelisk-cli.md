# obelisk-cli

> 标签: JavaScript

## 简介

manifest-to-App-Store 全自动上架工具。以 `obelisk/manifest.json` 为唯一数据源，覆盖从截图采集、官网同步到 App Store Connect 提审的完整上架流程。
