# oa2o

> 标签: array, convert, key, object, simple, to, value

## 简介

[oa2o](https://www.npmjs.com/package/oa2o) (object array to object) is a simple npm module to convert iterative object array ( [{k:"a"}, {k:"b"}] ) to object ( {a:{k:"a"}, b:{k:"b"}} ):
