# ol-ogc-api-crud

> 标签: JavaScript

## 简介

An [OpenLayers](https://openlayers.org) feature editor for OGC APIs that implement the CRUD draft ([OGC API - Features - Part 4: Create, Replace, Update and Delete](http://docs.ogc.org/DRAFTS/20-002.html)).
