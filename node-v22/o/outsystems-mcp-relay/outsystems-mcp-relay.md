# outsystems-mcp-relay

> 标签: keycloak, mcp, model-context-protocol, oauth, outsystems, proxy, relay, rfc9207

## 简介

Generic stdio-to-remote MCP relay with OAuth and an RFC 9207 issuer override — fixes remote MCP deployments (e.g. OutSystems' Keycloak-backed gateway) where the published metadata issuer doesn't match the authorization-response iss.
