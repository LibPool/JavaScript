# opencode-sticky-retry

> 标签: backoff, opencode, opencode-plugin, resilience, retry, sticky

## 简介

Configurable sticky retry plugin for opencode. Keeps retrying provider requests with backoff until success, a non-retriable rule matches, or the user aborts.
