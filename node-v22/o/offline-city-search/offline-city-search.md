# offline-city-search

> 标签: astrology, autocomplete, city, geocoding, geonames, kundali, lat, latitude, lng, longitude, offline, search, sqlite, timezone

## 简介

Offline, zero-latency city search with latitude, longitude, and IANA timezone. No API keys. No network. Just fast.
