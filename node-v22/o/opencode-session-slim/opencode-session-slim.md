# opencode-session-slim

> 标签: compact, context, opencode, opencode-plugin, revert, session, slim, trim, tui

## 简介

OpenCode TUI plugin to slim a session: check which Q&A turns to keep, then delete the rest (V1) or revert them from the model context (V2 — the platform reverts a contiguous tail and never touches files)
