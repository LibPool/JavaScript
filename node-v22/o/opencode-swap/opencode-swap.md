# opencode-swap

> 标签: 429, ai-agents, api-key-rotation, cli, failover, key-rotation, llm, load-balancer, multiple-accounts, opencode, opencode-go, proxy, rate-limit

## 简介

Automatic API key rotation for opencode-go — local proxy that round-robins multiple accounts and fails over on rate limits (HTTP 429)
