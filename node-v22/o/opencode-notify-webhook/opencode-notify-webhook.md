# opencode-notify-webhook

> 标签: discord, gotify, mattermost, notifications, ntfy, opencode, opencode-plugin, slack, teams, telegram, webhook

## 简介

V2-native OpenCode plugin that sends notifications to webhooks (Slack, Discord, ntfy, Gotify, Telegram, Teams, Mattermost, generic JSON/text).
