## 简介

📦 A developer-friendly CLI to install and manage reusable 🪝 React custom hooks directly from a centralized GitHub repository. Supports ⚙️ configuration, 📥 hook installation, 📃 listing with metadata, and works with both TypeScript and JavaScript.
