# opencode-usage-badge

> 标签: badge, deepseek-harness, dsh, opencode, usage

## 简介

DSH web plugin: an opencode go usage badge (rolling/weekly/monthly percent + reset countdown) next to the model selector. No API key is embedded: it is resolved at runtime from the model configuration.
