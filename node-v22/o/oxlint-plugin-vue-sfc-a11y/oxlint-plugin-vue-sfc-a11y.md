# oxlint-plugin-vue-sfc-a11y

> 标签: a11y, accessibility, aria, linter, nuxt, oxc, oxlint, sfc, vue

## 简介

Vue SFC accessibility rules for oxlint, as a JS plugin. Ports of eslint-plugin-vuejs-accessibility rules, with options upstream does not expose.
