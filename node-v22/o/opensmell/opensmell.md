# opensmell

> 标签: .osmell, digital-olfaction, e-nose, electronic-nose, feature-extraction, gas-sensors, mox

## 简介

OpenSmell JS SDK — digital olfaction for Node.js and the browser: .osmell I/O, Rs/R0 normalization, the full MOX feature framework, quality scoring, and ingest. Mirrors the Python and Rust SDKs.
