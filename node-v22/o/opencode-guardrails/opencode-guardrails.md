# opencode-guardrails

> 标签: guardrails, opencode, opencode-plugin, safety, shell-safety

## 简介

opencode 的执行前安全层：硬拦不可挽回的命令（rm -rf /、fork bomb、curl|sh、mkfs、dd）、展开 bash -c / python -c payload、对破坏性但合法的 git/sql/sudo 操作弹提示，并把模型轻推向 Read/Grep/Glob 而不是 cat/head/tail/find/sed/awk。
