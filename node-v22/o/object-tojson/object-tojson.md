# object-tojson

> 标签: flat, json.parse, json.stringify, object, primitive, serialise, serialize, tojson

## 简介

Turn a Javascript primitive into its "flat" representation. Aims to be equivalent to `JSON.parse(JSON.stringify(obj))`.
