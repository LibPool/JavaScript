# opencode-v2-handoff

> 标签: agent, context, handoff, opencode, opencode-v2, plugin, session

## 简介

Minimal deterministic end-of-session handoff for OpenCode v2 — writes a compact LATEST.md (goal/done/open/pointers/git/usage) so the next session resumes with just enough context.
