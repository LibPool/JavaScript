# openclaw-whatsapp-cloud

> 标签: ai-agent, chatbot, meta, openclaw, openclaw-plugin, whatsapp, whatsapp-cloud-api

## 简介

Meta WhatsApp Business Cloud API channel plugin for OpenClaw — inbound/outbound messaging, voice notes (STT/TTS), image generation, and tool-based reply delivery.
