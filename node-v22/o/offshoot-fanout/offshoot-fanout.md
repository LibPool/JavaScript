# offshoot-fanout

> 标签: conflict, descendant, fanout, merge, offshoot, propagate, sync, template

## 简介

Propagate a template change down to all its descendant repos and branches via `stem` git remotes, with dry-run and conflict reporting. The maintainer-side companion to offshoot.
