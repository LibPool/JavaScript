# opentelemetry-frontend

> 标签: opentelemetry

## 简介

A plug-and-play OpenTelemetry instrumentation setup for browser-based (frontend) applications. This module provides a single function to initialize tracing, metrics, and logging for your frontend app, with support for OTLP and console exporters, and a var
