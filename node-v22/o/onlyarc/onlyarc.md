# onlyarc

> 标签: cli, detect, onlyarc, stack, stackoo, tech-stack

## 简介

OnlyArc: detect a project's stack (framework, styling, components, data, auth, payments, testing, deploy) from package.json and config files. Short name for @onlyarc/cli.
