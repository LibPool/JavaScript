# onecodebase-js

> 标签: backend, onecode, onecodebase, postgres, postgrest, sdk, supabase

## 简介

Isomorphic JavaScript/TypeScript client for an Onecodebase backend (Postgres + PostgREST + auth + storage + realtime + edge functions).
