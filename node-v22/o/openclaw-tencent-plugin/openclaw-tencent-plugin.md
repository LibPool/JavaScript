# openclaw-tencent-plugin

> 标签: apm, llm, observability, openclaw, opentelemetry, tencent-cloud, tracing

## 简介

Tencent Cloud APM observability plugin for OpenClaw — full-chain distributed tracing with parent-child span tree. Requires diagnostics-otel to be enabled for OTel SDK.
