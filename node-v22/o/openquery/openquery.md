# openquery

> 标签: agent-skill, ai-agent, data-visualization, graph, mcp-alternative, postgres, read-only, sql

## 简介

Evidence explorer for databases — an agent-agnostic skill + local CLI that safely queries Postgres and renders answers as interactive entity graphs with SQL receipts. Your credentials never enter the AI's context.
