# opencode-v2-security

> 标签: bash, command-classifier, landlock, llm-reviewer, openai-compatible, opencode, opencode-plugin, opencode-v2, opencode-v2-security, permissions, sandbox, security, shell

## 简介

Autonomous execution-boundary security for OpenCode V2: scoped assessments, one-call authorization, bypass leases, and session read/write permission ceilings.
