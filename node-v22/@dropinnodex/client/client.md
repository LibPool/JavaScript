# @dropinnodex/client

> 标签: activity-feed, dropin, feed, follows, getstream, isomorphic, reactions, sdk

## 简介

Isomorphic, zero-dependency client SDK for dropin-activity — feeds, activities, reactions, and follows over fetch. Browser or Node.
