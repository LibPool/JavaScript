# @lexiprep/core

> 标签: ebook, epub, language-learning, nlp, pdf, tokenize, vocabulary, word-frequency

## 简介

Reusable pipeline: ebook (EPUB/PDF) -> clean text -> word tokens -> frequency list. Framework-agnostic, zero server/DB deps.
