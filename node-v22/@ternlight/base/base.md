# @ternlight/base

> 标签: bitnet, edge, embeddings, minilm, nearest-neighbor, on-device, semantic-search, sentence-embeddings, ternary, vector-search, wasm

## 简介

On-device semantic embeddings for JavaScript — the quality tier. 1.58-bit BitNet-style sentence embedder via WASM. ~7 MB on the wire, <5 ms per embedding, no API calls.
