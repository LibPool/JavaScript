# @kiwuuu/claude-handoff-mcp

> 标签: anthropic, claude, claude-code, claude-design, cline, cursor, handoff, mcp, model-context-protocol

## 简介

MCP server for Claude Design handoff bundles. Paste a handoff URL, get files + summary + deploy-ready artifacts in any MCP client (Claude Code, Cursor, Cline, Windsurf).
