# @coool/opencode-decision-mode

> 标签: JavaScript

## 简介

OpenCode v2 plugin: delegate judgments to Decision models (TypeSafe Jev via OpenRouter or direct, OpenAI gpt-6-luna) while your controller model stays the control plane.
