# jev-browser-sidekick-mcp

> 标签: agent, ai-agent, browser, browser-automation, cdp, jev, mcp, model-context-protocol, openrouter, playwright, typesafe, web-agent

## 简介

MCP server that runs plain-language browser steps. Jev, a typed decision model, picks the control on each page instead of an LLM reading the DOM.
