# @barefootjs/rust

> 标签: axum, barefoot, jinja, jinja2, minijinja, rust, ssr

## 简介

minijinja (Rust) adapter for BarefootJS — compiles IR to .j2 templates and ships a Rust rendering runtime (packages/adapter-rust/runtime/); runs under any Rust web framework (axum, etc.)
