# @acrossreport/acr-node

> 标签: acr, electron, invoice, pdf, png, print, receipt, report, template

## 简介

Render ACR (Across Report) templates to PDF/PNG directly from Node.js and Electron, powered by the Rust ACR engine (Skia-based, pixel-accurate).
