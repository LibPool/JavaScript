# @tiny-fish/hermes

> 标签: ai-agent, hermes, tinyfish, web-fetch, web-search

## 简介

TinyFish web provider plugin for Hermes Agent, delivered via npm for the TinyFish CLI. Installed by `tinyfish connect hermes`; not a JavaScript library.

## 官网

- 官网：https://docs.tinyfish.ai
- 源码仓库：git+https://github.com/tinyfish-io/tinyfish-web-agent-integrations.git
