# @devinosolutions/store-core

> 标签: android-publisher, app-store-connect, google-play, microsoft-store, partner-center, sdk

## 简介

Typed TypeScript clients for the App Store Connect, Google Play Developer and Microsoft Partner Center APIs, plus public storefront search: injected fetch/logger/clock, one typed error, bounded requests, no global state.
