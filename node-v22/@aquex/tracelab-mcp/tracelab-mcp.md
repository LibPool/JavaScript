# @aquex/tracelab-mcp

> 标签: ai-agent, aquex, claude, claude-code, claude-desktop, knowledge-base, mcp, model-context-protocol, rag, research, tracelab

## 简介

MCP server for TraceLab — gives AI agents research-to-output loops against a TraceLab knowledge base. Nine action-clustered tools (search, project, collection, report, document, mission, mission-execution, evidence, home) and an RFC 8628 device-code login
