# @haystackedai/a3react

> 标签: JavaScript

## 简介

A3UI React chart catalog component for @a2ui/react hosts. Install, merge A3_catalog into your A2UI catalog, and your agent's surfaces can place an A3_Chart (Recharts renderer + drill). Generated from the A3 chart contract.
