# @keepuni/ai-log

> 标签: ai, changelog, claude-code, coding-agent, context, cursor, hooks, mcp

## 简介

A reliable change log for AI coding agents. Records every edit an agent makes and feeds the relevant recent history back before the next edit, so the agent stops forgetting and stops breaking what it already fixed.
