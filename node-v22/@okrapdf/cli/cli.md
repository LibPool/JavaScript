# @okrapdf/cli

> 标签: agents, cli, document-ai, mcp, okra, okrapdf, pdf, pdf-extraction

## 简介

okraPDF CLI — upload PDFs, stream a local PDF-to-HTML twin, pull grounded context with bbox citations, run parse jobs, and query collections.
