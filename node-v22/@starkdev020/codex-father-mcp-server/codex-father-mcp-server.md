# @starkdev020/codex-father-mcp-server

> 标签: cli, codex, mcp, modelcontextprotocol

## 简介

MCP server for Codex Father, implemented with @modelcontextprotocol/sdk. Exposes codex.start/status/logs/stop/list tools by delegating to job.sh.
