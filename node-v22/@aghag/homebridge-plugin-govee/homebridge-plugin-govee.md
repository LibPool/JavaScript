# @aghag/homebridge-plugin-govee

> 标签: Govee, H5072, H5074, H5075, H5101, H5102, H5179, homebridge-plugin

## 简介

Homebridge plugin for Govee H5xxx Bluetooth Thermometer Hygrometer. This plugin is a fork of asednev with the only change that its using the latest version of node.
