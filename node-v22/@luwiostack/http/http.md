# @luwiostack/http

> 标签: client, fetch, headers, http, luwio, ofetch, react

## 简介

A small typed HTTP client over ofetch — createHttpClient + createRequest(client, params), whose chainable PendingRequest can delay or fail any call for testing loading/error UI. React <HttpClient> + useHttpClient() enrich the client with headers at runtim
