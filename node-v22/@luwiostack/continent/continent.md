# @luwiostack/continent

> 标签: continent, country, geography, hooks, i18n, intl, iso-3166, locale, luwio, react

## 简介

Typed ISO 3166 continent data for React — the seven continents, pairing with `@luwiostack/country` for country lookups, with a `<Continent>` provider and `useContinent` hook.
