# tiny-engineer

> 标签: antigravity, claude-code, cli, cursor, hooks, robot, tiny-engineer

## 简介

Tiny Engineer CLI: setup IDE hooks, anim/play over HTTP or USB serial (--transport serial / TINY_ENGINEER_TRANSPORT). Custom agents: REST API (docs/api.md).
