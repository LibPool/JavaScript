# @garzillion-labs/capture

> 标签: anthropic, audit, llm, openai, tiktoken, tokens

## 简介

Drop-in capture for LLM SDKs: recounts each response on a shared cl100k ruler and appends metrics-only records. No prompt or completion text ever touches disk.
