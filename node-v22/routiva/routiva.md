# routiva

> 标签: api, express, framework, http, middleware, node, rest, router, routing, server, zero-dependency

## 简介

A lightweight, zero-dependency Express.js alternative built on node:http — routing, middleware, body parsing, static files, CORS, compression and rate limiting.
