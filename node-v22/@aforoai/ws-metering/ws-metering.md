# @aforoai/ws-metering

> 标签: aforo, billing, metering, streaming, usage-based, websocket, ws

## 简介

Aforo WebSocket Metering SDK — wraps ws/Fastify-WebSocket/Socket.io connections to meter frames, bytes, and connection duration.
