# @aforoai/graphql-metering

> 标签: aforo, apollo, billing, complexity, graphql, metering, usage-based

## 简介

Aforo GraphQL Metering SDK — plugin + middleware that meters every GraphQL operation (query/mutation/subscription) with accurate complexity scoring and ships usage events to Aforo.
