# @relation-graph/vue

> 标签: JavaScript

## 简介

Vue relationship graph component for visualizing and editing knowledge graphs, org charts, and equity structures. Supports Vue 2 & Vue 3, force-directed layouts, tree layouts, and interactive graph editing.
