# @bendyline/squisq-calc

> 标签: calculation, excel, formula, ironcalc, spreadsheet, squisq, xlsx

## 简介

Spreadsheet calculation for squisq: the engine adapter contract (staleness, spill, budgets, cycle policy), an Excel formula parser, a pure-TypeScript in-house evaluator tier, and an IronCalc wasm backend behind the /ironcalc subpath (optional peer)
