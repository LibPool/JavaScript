# @bendyline/squisq-graph

> 标签: dependency-graph, diagram, graph, layered, layout, orthogonal, squisq, sugiyama

## 简介

Graph layout for squisq: a compound layered layout with orthogonal edge routing, nested containers with shared border ports, deterministic, dependency-free, and runnable in a Web Worker
