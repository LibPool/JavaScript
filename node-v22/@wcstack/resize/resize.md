# @wcstack/resize

> 标签: container-query, custom-elements, declarative, element-size, framework-agnostic, resize-observer, responsive, wc-bindable, web-components, zero-dependencies

## 简介

Declarative ResizeObserver component for Web Components. Framework-agnostic element-size primitive via wc-bindable-protocol.
