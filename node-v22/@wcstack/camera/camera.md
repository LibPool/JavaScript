# @wcstack/camera

> 标签: camera, command-token, custom-elements, declarative, event-token, framework-agnostic, getusermedia, mediarecorder, mediastream, recording, wc-bindable, web-components, webcam, zero-dependencies

## 简介

Declarative camera capture and media recording for Web Components. Binds live MediaStream handles directly to elements (never through serializable state) via getUserMedia + MediaRecorder.
