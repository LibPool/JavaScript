# @hiltjs/core

> 标签: architecture, command, event-bus, mvvm, reactive, rxjs, typescript, view-model

## 简介

A small MVVM core for TypeScript: view-model lifecycle, commands, reactive properties, conductors and an event bus, built on RxJS.
