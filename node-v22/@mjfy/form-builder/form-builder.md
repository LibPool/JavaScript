# @mjfy/form-builder

> 标签: Form-Builder, Formik, JSON, JoyUI, MUI, React, ffb-json-generator

## 简介

A React library to UI based on the Json using Formik-Form-Builder. It also generates react files, typescript files, and JSON schema from the Json.
