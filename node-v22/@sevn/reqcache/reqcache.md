# @sevn/reqcache

> 标签: cache, eleicoes, fetch, http, localstorage, sevn, ttl

## 简介

Cache de requisicoes HTTP em localStorage, com regra monotonica, deduplicacao e limite LRU. Pensado para cenarios de alto volume (ex.: apuracao de eleicoes).
