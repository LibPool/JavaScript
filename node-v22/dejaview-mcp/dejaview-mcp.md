# dejaview-mcp

> 标签: ai-agents, claude-code, diagrams, mcp, visualization

## 简介

MCP server that gives AI coding agents a small, fixed visual vocabulary. The agent sends compact JSON; DejaView renders a fixed template. Ships sequence diagrams.
