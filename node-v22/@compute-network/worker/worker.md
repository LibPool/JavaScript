# @compute-network/worker

> 标签: compute-network, distributed, gpu, inference, llm, ollama, worker

## 简介

Native CLI worker for Compute Network (compute.tech), the distributed inference network. Runs LLM inference via ollama and connects to the orchestrator via Socket.io.
