# @scrapeops/mcp

> 标签: ai-agent, anti-bot-bypass, javascript-rendering, llm-extraction, mcp, proxy, scrapeops, web-scraping

## 简介

MCP server for ScrapeOps Proxy API integration. Features web browsing, anti-bot bypass, JavaScript rendering, screenshots, and LLM-powered structured data extraction for AI agents.
