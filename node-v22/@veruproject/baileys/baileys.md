# @veruproject/baileys

> 标签: automation, baileys, bot, multi-device, multimedia, veruproject, whatsapp, whatsapp-api, whatsapp-bot

## 简介

veruproject/baileys — WhatsApp Multi-Device library rebased @whiskeysockets/baileys 7.0.0-rc14, using the original libsignal (GPL-3.0) Signal Protocol engine. Maintained by VeruProject. Focus: multimedia WhatsApp bots, low RAM footprint.
