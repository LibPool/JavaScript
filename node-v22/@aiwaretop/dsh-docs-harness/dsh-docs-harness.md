# @aiwaretop/dsh-docs-harness

> 标签: JavaScript

## 简介

Docs Harness for the dsh GUI: project governance rules injected per session, the plan lifecycle as tools, a live plan progress bubble, and user-driven install/upgrade/removal of the Python engine.
