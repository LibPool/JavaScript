# @codehourra/contextor

> 标签: claude, cli, context, cursor, developer, dotfiles, sqlite, sync

## 简介

Project-level developer context sync tool (SQLite-backed). Snapshot and restore .claude/.cursor/.codex/.env*/AGENTS.md/CLAUDE.md and similar dotfiles per project.
