# @adobedjangir/commerce-admin-get-config

> 标签: abdb, adobe-commerce, adobe-io, aio, app-builder, configuration, get-config

## 简介

Read scoped system configuration from Adobe App Builder Database (ABDB) with Magento-style inheritance, encryption, and Commerce REST scope resolution.
