# @omnigateway/pokemon

> 标签: omnigateway, omnigateway-plugin, pokemon

## 简介

A Pokémon companion for OmniGateway. Each gateway key raises one that hatches, evolves, and graduates into a Pokédex on the tokens that key spends.
