# @nichagiro/ui-primitives

> 标签: components, form, headless, react, react-hook-form, tailwindcss, ui

## 简介

Colección de componentes UI headless + form fields con React y Tailwind CSS v4. Funciona con cualquier librería de formularios o sin ninguna. React Hook Form es opcional.
