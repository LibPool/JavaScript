# @furo/vite-pico-mock

> 标签: fixtures, mock, mock-server, vite, vite-plugin

## 简介

A fixture server for vite projects: typed .ts fixtures mapped from the url, middleware, case sequences, a mock login gateway with users and api keys, push notifications and ndjson streams.
