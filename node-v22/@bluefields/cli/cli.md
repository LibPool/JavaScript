# @bluefields/cli

> 标签: attestation, bluefield, content-addressed, diff, ed25519, git-for-web-data, local-first, mcp, offline, provenance, snapshot, watch, web-scraping

## 简介

Bluefield — git for web data. A local-first CLI + library that snapshots web pages into a content-addressed store on your own disk and signs each capture with an offline-verifiable Ed25519 provenance manifest. No server, no account, no telemetry.
