# @sdd-method/maintain-cli

> 标签: JavaScript

## 简介

Bring an SDD repository current and rebuild its derived model — sync, briefing, catalogue build and aggregate, pack build, context pull — plus every read-only verify verb. Ships only the code those verbs reach; it cannot author specification content. Auth
