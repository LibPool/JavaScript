# @pristine-ts/gcp-identity-platform

> 标签: JavaScript

## 简介

Authenticator and guard for Firebase Auth / GCP Identity Platform. Mirror of `@pristine-ts/aws-cognito`: verifies Firebase ID tokens against Google's public X.509 certificate endpoint and gates routes on custom claims.
