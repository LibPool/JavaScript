# @reactwright/markdown

> 标签: commonmark, markdown, pandoc, pdf, reactwright

## 简介

Author Reactwright documents in Markdown. Parses CommonMark + YAML frontmatter into Reactwright content JSX so any template (essay, IEEE, report) can render `.md` files to HTML and PDF.
