# @radiate-so/nuxt

> 标签: analytics, cdp, nuxt, nuxt-module, personalization, radiate, tracking

## 简介

Official Nuxt module for Radiate. Provides $radiate, composables (useSegment, useTrack, useIdentify, …), and runtime-config wiring.
