# @nuthinking/site-edit

> 标签: agent, annotations, claude, editing, feedback, github, site-edit, vercel, website

## 简介

Edit a website from the website. Pins and notes on the page become a GitHub issue; an AI agent makes the change on a branch; a preview and an email with Ship follow.
