# @mionjs/bin-uws

> 标签: API, RPC, framework, server, typescript, uWebSockets, uws

## 简介

Loader for the uWebSockets.js prebuilt native binaries. Resolves the addon for the host platform; the binaries ride as per-platform optional dependencies (npm mirror of uNetworking/uWebSockets.js). Ships zero runtime dependencies.
