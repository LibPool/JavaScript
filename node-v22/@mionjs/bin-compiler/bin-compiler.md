# @mionjs/bin-compiler

> 标签: JavaScript

## 简介

Platform launcher for the mion resolver binary. Resolves and execs the prebuilt native binary for the host platform; the binary itself rides as a per-platform optional dependency. Ships zero runtime dependencies.
