# @peanutgraphic/bloxy-passkey

> 标签: JavaScript

## 简介

BLOXY passkey-authentication primitive — React hooks wrapping the browser WebAuthn ceremony with mandatory PRF activation. Pairs with peanutgraphic/bloxy-passkey on the server.
