# @peanutgraphic/bloxy-crypto

> 标签: JavaScript

## 简介

BLOXY zero-knowledge envelope encryption — client-held KEK, per-record DEKs, BIP39 24-word recovery, MOCK mode. Pairs with peanutgraphic/bloxy-crypto on the server.
