# @vantageos/corpus

> 标签: bm25, convex, convex-component, corpus, search, vantageos

## 简介

Reusable Convex component: common chunk schema + native BM25 full-text search + scope/orgId isolation. Zero embeddings, zero custom ranking -- machine shared, data per-domain.
