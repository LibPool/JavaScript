# dsh-approval-notify-macos

> 标签: approval, deepseek-harness, dsh, dsh-plugin, macos, notification

## 简介

DeepSeek Harness 插件（macOS）：每次需要审批时发系统通知，点击跳回 dsh；只提醒，不作答。
