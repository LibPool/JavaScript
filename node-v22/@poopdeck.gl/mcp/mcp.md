# @poopdeck.gl/mcp

> 标签: agents, deck.gl, llm-tools, mcp, model-context-protocol, spatiotemporal, tiles

## 简介

MCP (Model Context Protocol) server for spatiotemporal tiles: an open, self-hostable counterpart to CARTO's hosted MCP server — dataset discovery, @deck.gl/json view-map composition, and gated build/validate CLI tools over a directory of packed STT archiv
