# @trevorbyrum/keymask

> 标签: agent-secrets, ai-agents, api-keys, claude, claude-code, claude-desktop, codex, coding-agents, credential-broker, credentials, developer-tools, gemini, keychain, mcp, mcp-server, model-context-protocol, secrets, secrets-management, ssh, vault

## 简介

Local MCP credential broker for coding agents (Claude Code, Codex, Gemini, and any other MCP-stdio client). Values never enter the AI transcript — the agent requests secrets through a schema, a localhost form lets you type them, and they land in Vault, .e
