# create-appflare

> 标签: appflare, cloudflare, cloudflare-workers, create, installer, self-hosted, workers, wrangler

## 简介

Install Appflare, a self-hosted app manager for Cloudflare, into your own Cloudflare account.

## 官网

- 官网：https://appflare.dev
- 源码仓库：git+https://github.com/appflare/appflare.git
- npm 页面：https://www.npmjs.com/package/create-appflare

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- npm 安装：`npm install create-appflare`
- npm registry：https://registry.npmjs.org/create-appflare
- Node 要求：>=22
