# @colorless/stylelint-config

> 标签: JavaScript

## 简介

Stylelint是样式代码质量检测的工具，它通过静态扫描的方式结合相对应的代码编写规范，让你在开发过程中发现其代码中出现的问题，避免将问题遗留至运行时。想要了解更多信息请移步[官网](https://prettier.io/)
