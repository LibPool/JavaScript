# @spanexx/sdk-browser-cjs

> 标签: agentide, browser, capabilities, cjs, commonjs, frontend, platform, sdk

## 简介

CommonJS build of @spanexx/sdk-browser — for CJS consumers. Source is mirrored from @spanexx/sdk-browser; updated in lockstep. Note: the SDK targets browsers (native WebSocket, DOM APIs); the CJS variant is for SSR/Node-only consumers.
