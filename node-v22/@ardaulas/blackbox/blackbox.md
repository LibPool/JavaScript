# @ardaulas/blackbox

> 标签: agent-debugging, ai-agents, anthropic, cassette, ci, llm, openai, record-replay, testing, time-travel-debugger

## 简介

A flight recorder for AI agents: record your Anthropic or OpenAI agent to a hash-chained cassette, replay it offline, fork it with one tool result changed, and diff to the first divergence.
