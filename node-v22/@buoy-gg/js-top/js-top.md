# @buoy-gg/js-top

> 标签: debugging, devtools, expo, flipper-alternative, js-thread, performance, profiler, react-native, react-native-devtools, task-manager

## 简介

Inspect instrumented JavaScript timers, promises and callbacks to investigate work on the React Native JS thread.
