# zerodep-js-compiler

> 标签: JavaScript

## 简介

zerodep-js 的 Babel 8 编译器。处理显式变量宏、component 参数解构及默认值、JSX 和 For 实时参数；输出标准 ESM、源码映射和带源码位置的语义诊断。
