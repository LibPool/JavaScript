# dsh-plugin-workspace-archive

> 标签: archive, cordis, deepseek-harness, dsh, dsh-plugin, session, workspace

## 简介

DSH 插件：工作区目录被删/移走时自动归档其会话，目录回归时恢复（取消归档 + 把成员挂回分组）；支持手动归档整个工作区（工具与斜杠命令）；并把「无项目」里工作目录匹配的会话归位。只走官方 API、零运行时依赖。
