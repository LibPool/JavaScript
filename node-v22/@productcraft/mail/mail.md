# @productcraft/mail

> 标签: mail, productcraft, sdk

## 简介

Receive-and-store mail platform — template-rendered sends, mailboxes + domains + DKIM, message timeline, suppression lists, outbound webhooks via ProductCraft Mail. Generated from the production OpenAPI spec.
