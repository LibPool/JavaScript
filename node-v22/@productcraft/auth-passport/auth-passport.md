# @productcraft/auth-passport

> 标签: auth, jwt, passport, passport-jwt, productcraft, sdk

## 简介

Passport-JWT adapter for ProductCraft Auth. Plug an Auth ConsumerScope into a `passport-jwt` Strategy so existing Passport setups can authenticate Auth-issued tokens.
