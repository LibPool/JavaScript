# @owlai/agent-sdk

> 标签: agent, agent-sessions, eval, langsmith, observability, owl, tracing, withowl

## 简介

Owl AI (withowl.ai) records the production agent you already run. Agent sessions, evals, shadow clones. Owl never hosts the agent.
