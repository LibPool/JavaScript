# @vieratech/wadb

> 标签: JavaScript

## 简介

This project is a TypeScript implementation of the Android Debug Bridge(ADB) protocol over WebUSB. The implementation inspired on the [webadb.js][1], with the main difference being that implementation supports multiple concurrent streams.
