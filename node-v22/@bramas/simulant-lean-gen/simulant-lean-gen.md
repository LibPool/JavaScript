# @bramas/simulant-lean-gen

> 标签: JavaScript

## 简介

Translate compiled Simulant experiments to Lean 4. The generator emits the composed model, algorithm, initial configurations, parameter domains, task and statements to prove, using the semantic library in `@bramas/simulant-lean`.
