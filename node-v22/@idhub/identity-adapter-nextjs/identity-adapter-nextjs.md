# @idhub/identity-adapter-nextjs

> 标签: JavaScript

## 简介

Next.js App Router adapter for @idhub/identity-core: Edge-safe middleware that guarantees the canonical anonymous id cookie, plus an <IdentityProvider> client component and useIdentity() hook.
