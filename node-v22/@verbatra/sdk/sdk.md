# @verbatra/sdk

> 标签: ai, anthropic, arb, automation, deepl, flutter, gemini, i18n, i18next, internationalization, java-properties, l10n, local-llm, locale, localization, machine-translation, next-intl, ngx-translate, ollama, openai, openai-compatible, sdk, translation, vue-i18n, xliff, yaml

## 简介

Programmatic API to automate i18n translation and keep your locale files in sync across languages, using OpenAI, Anthropic, Gemini, DeepL, or an openai-compatible local or self-hosted model.
