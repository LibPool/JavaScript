# @nanhara/hara-design

> 标签: agent, ai, cli, design, design-systems, design-tokens, hara, html, plugin, preview

## 简介

Design from your terminal — in hara, Claude Code, or Codex. Generate self-contained, interactive HTML in 150 brand-grade design systems, preview live, and export to standalone HTML or a design-token / framework handoff (Tailwind, CSS, SwiftUI, Flutter).
