# @layerswap/widget-js

> 标签: cdn, embed, layerswap, module-federation, vanilla, widget

## 简介

Framework-agnostic loader that fetches the Layerswap widget from the CDN at runtime via Module Federation and mounts it into any DOM element. No framework required.
