# createwithoscar

> 标签: claude, dmx, mcp, midi, model-context-protocol, osc, oscar

## 简介

Connect an AI assistant (Claude and other MCP clients) to OSCAR, the editor and server for OSC, MIDI and DMX control interfaces.
