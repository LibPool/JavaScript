# @askalf/strongroom

> 标签: agent-security, ai-agents, credentials, least-privilege, own-your-stack, secrets, vault

## 简介

own your agent secrets — an encrypted vault that hands agents scoped, short-lived, single-use leases instead of raw keys, and audits every access. Part of Own Your Stack.
