# @pocketjs/framework

> 标签: embedded-ui, jsx, pocketjs, psp, solid, tailwind, vita, vue-vapor, wasm

## 简介

A portable application runtime that turns modern component code into native pixels across radically different hardware: Solid, Vue Vapor and Octane over a native Rust core, with build-time Tailwind styling and 60 FPS animation under an 8 MB memory budget.
