# @nw-cfg/core

> 标签: JavaScript

## 简介

定义 iframe Host 与 Guest 通信所需的协议类型、错误码以及基础工具函数。当前提供 `MsgEnvelope`、`ConfigMeta` 等接口与简单的 revision 辅助方法，后续将扩展到完整的事件语义、校验逻辑与类型守卫。
