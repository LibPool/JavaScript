# @c15t/browser

> 标签: banner, c15t, cmp, consent, consent-banner, consent-management, consent-management-platform, consent-manager, cookie, cookie-banner, cookie-consent, framer, gdpr, global-privacy-control, headless, iab-tcf, javascript, no-build, privacy, script-blocking, script-tag, squarespace, vanilla-js, webflow, wordpress

## 简介

Cookie consent banner and GDPR consent manager for Webflow, WordPress, Framer, Squarespace and plain HTML. One script tag, script blocking and an optional IAB TCF build.
