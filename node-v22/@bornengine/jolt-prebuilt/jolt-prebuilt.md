# @bornengine/jolt-prebuilt

> 标签: JavaScript

## 简介

Prebuilt JoltPhysics + bloom_jolt static libraries for every (os, arch) BornEngine targets. Consumed by @bornengine/engine to skip the multi-minute Jolt cmake build at install time.
