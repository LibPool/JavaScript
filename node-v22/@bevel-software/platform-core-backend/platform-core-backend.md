# @bevel-software/platform-core-backend

> 标签: JavaScript

## 简介

Open-source core backend of the Bevel platform: git-backed knowledge workspace, workflow (branches/change requests/locks/SSE), skills, tools, secrets vault, access control and the remote MCP surface.
