# @acronis-platform/tokens-pd

> 标签: JavaScript

## 简介

Acronis platform (PD) design tokens: per-brand CSS custom properties, per-component CSS, and a DTCG intermediate — generated from @acronis-platform/design-tokens via @acronis-platform/style-dictionary.
