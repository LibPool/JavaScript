# @illuma-ai/agents

> 标签: JavaScript

## 简介

The **Illuma agent runtime** — the TypeScript engine behind Illuma's agents: graph orchestration, streaming event handling, tool execution, provider adapters, subagent delegation, and message/context management for single-agent and multi-agent runs.
