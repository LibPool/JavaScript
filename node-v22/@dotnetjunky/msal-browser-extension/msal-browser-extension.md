# @dotnetjunky/msal-browser-extension

> 标签: AAD, PKCE, authorization code, implicit, js, msal, oauth

## 简介

This package is a fork of Microsoft Authentication Library for js, which allows storing cached tokens in the extension's local storage. This package is not affiliated with Microsoft.
