# @mosadd/voice-analyzer-core

> 标签: JavaScript

## 简介

Deterministic voice-deepfake feature-extractor + scorer. Pure TS, no DOM / no Web Audio. Used by Demo112 voice analyzer and the analyze-call-audio edge function — both run the same code on the same inputs.
