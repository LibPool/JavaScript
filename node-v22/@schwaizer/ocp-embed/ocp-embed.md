# @schwaizer/ocp-embed

> 标签: JavaScript

## 简介

OCP Embed widget — the loader core: zero-config context capture, origin-checked host↔iframe postMessage bridge, and the host API (setContext/open/close/identify/on). DOM is injected so the logic is testable in node; the browser entry is a thin wrapper.
