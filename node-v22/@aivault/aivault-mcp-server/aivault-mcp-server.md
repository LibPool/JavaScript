# @aivault/aivault-mcp-server

> 标签: agent, ai, aivault, conversation, knowledge-base, mcp, rag

## 简介

MCP Server for AIVault — search, sync, and manage your AI conversations from any agent. Connects to your AIVault instance via HTTP API.
