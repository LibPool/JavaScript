# @solinker/nodes-dingding-robot

> 标签: n8n-community-node-package, 协同办公, 钉钉机器人

## 简介

钉钉机器人是钉钉系统的内置功能，可以理解为是一个提醒通知工具，接收数据并自动发送信息到钉钉。
