# @solinker/nodes-deepl

> 标签: DeepL, n8n-community-node-package, 工具软件

## 简介

DeepL是德国的一家为语言开发人工智能的深度学习公司，成立于2009年，原名Linguee，并推出了用于翻译的互联网搜索引擎。 Linguee曾应答了超过10亿用户的100多亿次查询。 2017年，公司推出了基于机器翻译系统的DeepL翻译器。
