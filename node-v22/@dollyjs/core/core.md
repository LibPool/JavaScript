# @dollyjs/core

> 标签: animation-timeline, css only, no javascript, parallax, scroll animation, scroll reveal, scroll-driven animations, scrollytelling, sticky, view timeline

## 简介

Scroll-driven motion, in CSS. 34 camera moves on one attribute — no JavaScript, and content stays visible where scroll timelines aren't supported.
