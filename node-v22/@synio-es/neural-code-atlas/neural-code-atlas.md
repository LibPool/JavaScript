# @synio-es/neural-code-atlas

> 标签: claude, cli, code-analysis, code-intelligence, codebase, javascript, local, mcp, python, semantic-index, tree-sitter, typescript

## 简介

Local semantic index layer for codebases. Structural code intelligence via tree-sitter + SQLite, with MCP server for Claude Code.
