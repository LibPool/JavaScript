# llm-json-mend

> 标签: agent, ai, json, llm, partial-json, repair, standard-schema, streaming, structured-output, zod

## 简介

Repair broken, partial, or markdown-fenced JSON from LLM output and validate it against Zod or any Standard Schema. Zero dependencies.
