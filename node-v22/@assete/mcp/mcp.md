# @assete/mcp

> 标签: assete, claude, mcp, model-context-protocol, sql

## 简介

Read-only SQL access to your Assete browsing-activity database, for Claude Code. Bridges to the Assete browser extension over a token-authenticated loopback WebSocket — no data leaves your machine.
