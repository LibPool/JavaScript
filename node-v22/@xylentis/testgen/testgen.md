# @xylentis/testgen

> 标签: codegen, e2e, junit, mocha, playwright, playwright-go, recorder, selenium, test-generator, testng

## 简介

Record a UI test once with the Playwright recorder, then generate it for Playwright (TypeScript, Go) and Selenium (Java, JavaScript).
