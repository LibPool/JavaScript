# @mcd0luo/celes-center-session-bridge

> 标签: celestea, deepseek-harness, dsh, inter-agent, session-bridge

## 简介

dsh: cross-session messaging for the Celes dispatch center — address another session by id or name, deliver as its next user turn; queued bridge messages are merged in place (formatted append) instead of piling up turns
