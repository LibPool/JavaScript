# @cueplusplus/studio-mcp

> 标签: JavaScript

## 简介

The CUE++ studio's MCP bridge: a stdio server that joins a studio scene as a headless Yjs peer, so an agent can push a scene, wait for a person to tweak it, read what changed and export the result.
