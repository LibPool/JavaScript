# @youropinion/embed

> 标签: embed, feedback, form, iframe, popup, survey, widget, youropinion

## 简介

Embed YouOpinion surveys on any website. Surfaces: Widget, Dialog, Drawer, Popover. Triggers: Feedback Tab, Chat Bubble.
