# @tradingview/lwc-plugin-accessibility

> 标签: lightweight-charts, lightweight-charts-plugin, lwc-plugin

## 简介

Drop-in accessibility layer built on pane primitives: adds semantic markup, keyboard navigation, and screen-reader support to help meet WCAG 2.1 AA.
