# @opengovsg/auth

> 标签: JavaScript

## 简介

Framework-agnostic building blocks for a safe-by-default OTP login flow: PKCE-style session binding and one-time-password generation/verification with the ordering that closes known timing, brute-force, and replay attacks already built in.
