# @molecule/api-analytics-http

> 标签: analytics, http, molecule, telemetry

## 简介

Generic HTTP analytics provider — POSTs track/identify/page events to a configured first-party endpoint. Built for CLIs and services (mlcl, molecule-mcp) that emit into molecule.dev's own analytics.
