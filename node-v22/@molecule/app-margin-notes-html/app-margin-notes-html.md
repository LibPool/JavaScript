# @molecule/app-margin-notes-html

> 标签: annotations, html, margin notes, molecule, reading layout, sidenotes, static site

## 简介

Framework-free long-form reading layout with notes beside each paragraph: renders to an HTML string (build time or server), plus a small browser script for the switches, two-way hover and a phone panel that follows the reader
