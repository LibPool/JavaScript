# @molecule/api-bonds-default-express

> 标签: bonds, default, express, molecule

## 简介

Default API bond setup for Express-based apps. Provides setup functions for the 10 byte-identical bond wirings shared across the molecule fleet — config-env, database-postgresql, jwt-jsonwebtoken, middleware-{body-parser,cookie-parser,cors}-express, passw
