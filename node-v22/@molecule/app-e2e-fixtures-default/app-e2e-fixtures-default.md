# @molecule/app-e2e-fixtures-default

> 标签: console-errors, e2e, fixtures, molecule, playwright

## 简介

Shared Playwright `test` + `expect` with auto-attached browser console-error/pageerror guard. Every fleet app's e2e specs import from here so a runtime exception (React mount failure, ESM/CJS interop error, unhandled rejection) hard-fails the test instead
