# @molecule/api-instance-leadership

> 标签: distributed lock, leader election, leadership, molecule, multi-instance, singleton

## 简介

Instance-leadership core interface for molecule.dev: elect one API instance to run platform-wide singleton work, with demotion and takeover when the holder's connection is lost.
