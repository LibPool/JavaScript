# @molecule/api-ai-embeddings-embeddinggemma

> 标签: ai, embeddinggemma, embeddings, gemma, local, molecule, multimodal, offline, onnx, transformers

## 简介

EmbeddingGemma 2 ai-embeddings provider for molecule.dev — Google's open (Apache-2.0) multimodal embedding model run in-process via Transformers.js (ONNX): text, images and audio in one 768-d space, task prefixes applied for you, Matryoshka 512/256/128
