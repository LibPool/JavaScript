# @molecule/api-upstream-balancer

> 标签: edge, load balancing, molecule, replicas, round robin, upstream

## 简介

Upstream-balancer core interface for molecule.dev: choose which instance of a multi-instance deployment one request goes to — health-aware round-robin, failure cooldown, retry elsewhere, drain-aware.
