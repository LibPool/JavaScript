# @molecule/api-process-lifecycle

> 标签: drain, graceful shutdown, lifecycle, liveness, molecule, readiness

## 简介

Process lifecycle core interface for molecule.dev: named readiness and liveness checks with timeouts and criticality, a drain state, in-flight request tracking, and ordered shutdown hooks.
