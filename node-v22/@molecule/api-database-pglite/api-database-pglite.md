# @molecule/api-database-pglite

> 标签: browser, database, molecule, pglite, postgres, wasm

## 简介

PGlite database provider for molecule.dev — real Postgres compiled to WebAssembly, in-process, in memory, on disk, or in the browser's IndexedDB.
