# @molecule/app-i18n-default-react

> 标签: default, i18n, molecule, react

## 简介

Default i18n bond setup with 80-language definitions, lazy-loading wrapper, and locale persistence via storage bond. Used by every flagship app — 113 lines of byte-identical wiring across the fleet.
