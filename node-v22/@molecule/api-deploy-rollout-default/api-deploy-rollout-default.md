# @molecule/api-deploy-rollout-default

> 标签: deploy, molecule, rolling deploy, rollout, zero downtime

## 简介

Default deploy-rollout provider for molecule.dev: grow-then-shrink and in-place instance replacement with a capacity floor, continuous soak, reverse rollback and idempotent resume.
