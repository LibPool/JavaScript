# @workspec/topology-studio

> 标签: architecture, cli, cost-modelling, infrastructure, reconciliation, topology, yaml

## 简介

WorkSpec Topology Studio — standalone CLI + localhost host shell. workspec-topology authors/validates/imports/reconciles/costs an infrastructure topology as YAML artifacts in your working tree.
