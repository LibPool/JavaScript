# @workspec/c4-model

> 标签: architecture, c4, diagrams, loader, resolver

## 简介

Pure loader/resolver for a WorkSpec C4 working tree — discovers, parses, and resolves elements, diagrams, and layouts from any file-source port into one typed C4Model, with best-effort diagnostics. No IO assumptions, no DOM, no React.
