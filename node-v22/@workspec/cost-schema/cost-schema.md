# @workspec/cost-schema

> 标签: cost-attribution, finops, json-schema, schema, yaml, zod

## 简介

Zod source of truth for WorkSpec Cost Attribution artifacts (Inventory, Spend, Attribution, TagPlan) — TS types, runtime validation, generated JSON Schema, and byte-stable YAML serialization.
