# @mdy-docs/lamassu-js

> 标签: engine, interpreter, javascript, sandbox, template, untrusted, wasm, webassembly

## 简介

A strict, safe JavaScript-subset engine written in C, compiled to WebAssembly — sandboxed evaluation for untrusted templates.
