# @capturebeam/mcp

> 标签: agent, capturebeam, demo-video, mcp, model-context-protocol

## 简介

Model Context Protocol server for CaptureBeam — author and render agent-first demo videos from any MCP-capable client (Claude Code, Cursor, Codex, Windsurf).
