# @foldedspacelabs/metistry-mcp-eventkit

> 标签: JavaScript

## 简介

Metistry EventKit bridge: Calendar + Reminders over the §4.3 wire contract (HTTP + bearer auth + check() + preview-confirm). Ships a compiled, signed Swift helper; TCC-bound — runs as its own launchd service. Usable standalone.
