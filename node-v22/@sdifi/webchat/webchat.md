# @sdifi/webchat

> 标签: JavaScript

## 简介

This is the webchat widget for the SDiFI project. It requires a working instance of a [Masdif](https://github.com/sdifi/masdif/) server.

## 官网

- 官网：https://github.com/sdifi/webchat
- npm 页面：https://www.npmjs.com/package/@sdifi/webchat

- npm registry：https://registry.npmjs.org/@sdifi/webchat
- Node 要求：>=10
