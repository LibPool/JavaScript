# @alicloud/css-var-utils

> 标签: JavaScript

## 简介

css-var-utils 帮助你管理 css-var 的 fallback value，生成的代码类似于`background-color: var(--btn-bg-color, #ccc)`。因此组件使用者可以通过定义`--btn-bg-color`来覆盖这个颜色。
