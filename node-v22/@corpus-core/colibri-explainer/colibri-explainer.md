# @corpus-core/colibri-explainer

> 标签: colibri, ethereum, explainer, llm, simulation, transaction

## 简介

LLM-powered transaction simulation explainer for Colibri Stateless. Takes simulation results from colibri_simulateTransaction and produces human-readable explanations via configurable LLM providers.
