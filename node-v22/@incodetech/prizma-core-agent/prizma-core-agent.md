# @incodetech/prizma-core-agent

> 标签: JavaScript

## 简介

Prizma Core, queryable: a generated index of the library on web, Android and iOS, plus a CLI and an MCP server so an agent reads the system instead of inventing it. Answers for the Prizma Core version the project installed.
