# @mundoit-lib/plugin-vue-oidc

> 标签: auth, axios, histrix, http, internal, oidc, pkce, plugin, vue, vue-plugin, vue3

## 简介

OIDC authentication (authorization code + PKCE over oidc-client-ts) for Mundo IT Vue 3 apps: core auth, axios http client (Bearer + refresh retry on 401), Vue plugin with useOidcSession, callback component and router guard, compatible with the histrix-com
