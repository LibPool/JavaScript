# @form-create/tdesign

> 标签: @form-create, components, dynamic-form, form, form-builder, lowcode, tdesign, vue3, 低代码, 动态表单

## 简介

TDesign 版本低代码表单 | FormCreate 是一个可以通过 JSON 生成具有动态渲染、数据收集、验证和提交功能的低代码表单生成组件。
