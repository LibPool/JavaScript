# @agent360/browser-mcp

> 标签: ai-agent, browser, browser-automation, browser-mcp, captcha, captcha-solver, chrome, chrome-extension, claude, claude-code, human-in-the-loop, mcp, mcp-server, model-context-protocol, playwright-alternative, selenium-alternative, web-automation

## 简介

Browser MCP - the browser tool that can stop and ask you. A 2FA code, a CAPTCHA, a choice only you can make: it asks on your own screen, then carries on in the Chrome you're signed into. 40 tools, any MCP client, MIT.
