# @visioncortex/xsvg-viewer

> 标签: gradient-mesh, graphics, svg, text-layout, viewer, wasm, xsvg

## 简介

Render xsvg — an XML graphics format that compiles to plain SVG — in the browser. Bundles the WASM compiler and a drop-in preview/slide-deck surface.
