# @visioncortex/xsvg-compile

> 标签: compiler, gradient-mesh, graphics, node, svg, text-layout, wasm, xsvg

## 简介

Compile xsvg — an XML graphics format that compiles to plain SVG — in Node.js. Runs the WASM compiler with native (opentype.js) font metrics + glyph outlining. No browser, no cross-compilation.
