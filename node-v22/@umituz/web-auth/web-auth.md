> 标签: auth, auth-adapter, auth-layout, authentication, components, forgot-password, login, multi-tenant, org-switcher, password-strength, react, register, reset-password, session, session-provider, typescript

## 简介

Frontend auth module for the fleet — AuthLayout, Login/Register/Forgot/Reset forms, SessionProvider with an AuthAdapter seam, org switcher, demo login, ready-made better-auth client adapter + form actions; uauth-* stylesheet on design-system tokens
