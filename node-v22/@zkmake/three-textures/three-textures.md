# @zkmake/three-textures

> 标签: devtools, ktx2, r3f, react-three-fiber, texture, textures, three, threejs

## 简介

A dev panel for the textures in a three.js scene: see them, download them, paint them, swap them back in live — compressed (KTX2) textures included. Vanilla three and React Three Fiber.
