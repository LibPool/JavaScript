# @such-software/smirk-dapp-api

> 标签: bitcoin, dapp, grin, litecoin, monero, smirk, wallet, window.smirk, wownero

## 简介

Smirk wallet dapp integration. Provides window.smirk (connect / signMessage / requestPayment / claimPublicTip) for websites that want to support Smirk across the browser extension, desktop app, and mobile app. Transport-agnostic — auto-detects extension c
