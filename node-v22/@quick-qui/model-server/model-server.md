# @quick-qui/model-server

> 标签: JavaScript

## 简介

负责载入、解析、维护和发布模型。 关于模型的各种规则和计算在此执行 （但不在此定义，定义见 [@quick-qui/model-defines](http://github.com/quickqui/model-defines)。）
