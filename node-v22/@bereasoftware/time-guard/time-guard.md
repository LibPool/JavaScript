# @bereasoftware/time-guard

> 标签: date, date-formatter, date-time, datetime, formatter, i18n, immutable, internationalization, javascript, locale, solid-principles, temporal, temporal-api, time, time-guard, typescript

## 简介

A modern, fully-typed TypeScript date/time library built with the Temporal API, SOLID principles, and complete i18n support. Immutable and designed for type safety.
