# @ahpd/webhook

> 标签: agent, agent-host, agent-host-protocol, ahp, ai, automation, bot, plugin, webhook

## 简介

Webhooks for the ahpd daemon: a URL that talks to a bot by thread or fires an automation, with a secret per endpoint
