# @ahpd/tunnel-devtunnel

> 标签: agent, agent-host, agent-host-protocol, ahp, ai, dev-tunnels, devtunnel, plugin, tunnel, vscode

## 简介

A Dev Tunnel plugin for ahpd: forwards the bound port through a Microsoft Dev Tunnel so VS Code can find and reach the daemon from anywhere
