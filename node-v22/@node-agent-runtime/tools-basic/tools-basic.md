# @node-agent-runtime/tools-basic

> 标签: agent, calculator, demo, node-agent-runtime, tools

## 简介

Basic built-in tools package of the Agent runtime: calculator (safe Pratt parser, no eval), now/geocode/weather/exchange demos and the builtinTools collection. Demo-friendly defaults; kept out of the core to keep the engine lean (M6 P1 review, P0).
