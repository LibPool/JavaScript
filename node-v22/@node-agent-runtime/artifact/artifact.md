# @node-agent-runtime/artifact

> 标签: agent, artifact, blob, node-agent-runtime, storage

## 简介

Artifact package of the Agent runtime: ArtifactManager — metadata rows in the Storage doc domain plus payloads in the blob domain (text/file/chart/url), cascaded cleanup per session. Split out of the memory package (M6 P1 review, P1) so each package match
