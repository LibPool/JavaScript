# @blaueck/dsh-openui

> 标签: JavaScript

## 简介

DSH OpenUI plugin: the `openui` tool and its bundled skill let the model answer with OpenUI Lang — the Open Standard for Generative UI — rendered as a live, interactive, sandboxed card in the conversation, built from the official 84-component chat library
