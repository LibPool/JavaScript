# @adanami/kaleido

> 标签: cli, code-review, diff, git, markdown, mermaid, monaco, preview, typescript, viewer

## 简介

Monaco-based local web file viewer: browse any directory, diff git ranges, with real TypeScript hover, lint diagnostics, comments and review marks
