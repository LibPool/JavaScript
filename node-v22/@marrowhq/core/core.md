# @marrowhq/core

> 标签: claude, coding-agents, distillation, marrow, mcp, pgvector, postgres, product-context, provenance

## 简介

The Marrow engine: ingest the raw product room, distill it into decided vs open product truth with provenance, and serve task-scoped context to coding agents over MCP. One Postgres plus pgvector, provider interface, default Claude.
