# pi-date-tail

> 标签: ai-agents, coding-agent, date, llm, pi, pi-coding-agent, pi-extension, pi-package, prompt-cache, prompt-caching, timezone

## 简介

Tell the model what day it is without breaking pi's prompt cache: one short hidden message appended once per day, never the system prompt, and again after a compaction summarized it away.
