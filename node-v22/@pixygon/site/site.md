# @pixygon/site

> 标签: JavaScript

## 简介

The Pixygon website scaffold: one provider stack (theme, SEO, consent-gated analytics, auth, error boundary), design-token themes, a disciplined image component and the pinned stack manifest every Pixygon Vite site shares.
