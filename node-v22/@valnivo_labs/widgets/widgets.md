# @valnivo_labs/widgets

> 标签: angular, calculator, embed, loan, mortgage, offline, projection, react, self-contained, shadow-dom, standalone, valnivo, vue, web-component, widget

## 简介

Valnivo's financial calculators as components: standalone (no network, keeps working if valnivo.eu is gone) or framed from the site. React, Vue, Angular and plain HTML.
