# @binarynoir/vitepress-exclude

> 标签: docs, documentation, drafts, exclude, srcExclude, vite-plugin, vitepress, vitepress-plugin

## 简介

A VitePress plugin that keeps pages out of the build with a .exclude file in any folder, and restarts the dev server when one changes.
