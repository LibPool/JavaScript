# @binarynoir/vitepress-text-style

> 标签: color, docs, documentation, font-size, markdown-it, markdown-it-plugin, text-style, vitepress, vitepress-plugin, vuepress

## 简介

Color and size text inline in VitePress Markdown with [t:red:1.2em]text[/t]. Values are validated, code is left alone, and the syntax nests with the rest of your Markdown.
