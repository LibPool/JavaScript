# @binarynoir/vitepress-reading-time-tag

> 标签: docs, documentation, markdown-it, markdown-it-plugin, reading-time, vitepress, vitepress-plugin

## 简介

Write [[readingTime]] in VitePress 2 Markdown and get a "Reading time" tip block with the page's estimated reading time, calculated at build time.
