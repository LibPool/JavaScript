# react-native-magnetkit

> 标签: android, expo, gesture, ios, magnet, magnetic ui, magnetometer, react-native

## 简介

Magnetic UI for React Native: a real magnet beside the phone pulls your interface. MagnetKit (the on-device magnet model) as an Expo module for iOS and Android.
