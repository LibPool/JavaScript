# @mettlecast/domain-cdk-packer

> 标签: JavaScript

## 简介

AWS CDK L3 constructs that compile a `DomainRegistry` snapshot into CloudFormation. Takes the output of `mc-domain-module build` and generates type-safe infrastructure.
