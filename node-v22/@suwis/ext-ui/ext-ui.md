# @suwis/ext-ui

> 标签: ext-ui, suwis

## 简介

ext-ui 是suwis基于自身业务，抽取出来的扩展ui，主要弥补市面上ui框架未提供的业务ui组件

## 官网

- 源码仓库：https://gitee.com/suwis/ext-ui.git
- npm 页面：https://www.npmjs.com/package/@suwis/ext-ui
