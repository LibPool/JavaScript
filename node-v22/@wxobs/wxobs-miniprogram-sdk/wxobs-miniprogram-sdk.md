# @wxobs/wxobs-miniprogram-sdk

> 标签: JavaScript

## 简介

1. 安装：在小程序代码根目录下执行 `tnpm install @tencent/wxobs-miniprogram-sdk` 2. 构建：在微信开发者工具中，点击左上角菜单栏中“工具” -> “构建npm” 3. 使用：在 app.js 文件中引入 setup 函数，并在 onLaunch 中执行即可启动采集。
