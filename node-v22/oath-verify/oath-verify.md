# oath-verify

> 标签: admission-webhook, ci, docker, kubernetes, provenance, sigstore, solana, supply-chain

## 简介

Record a Docker image digest on Solana from CI and block deploys of images the pipeline did not build (CLI, Kubernetes admission webhook, GitHub Action)
