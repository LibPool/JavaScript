# @haven_ai/connect

> 标签: 402, agent-payments, ai-agent, budget, connect, haven, mcp, non-custodial, spending-limit, usdc, x402

## 简介

Haven connect — one command wires an AI agent to budgeted, non-custodial payments: installs the MCP runtime and generates the agent signing key locally, registering only the public address.
