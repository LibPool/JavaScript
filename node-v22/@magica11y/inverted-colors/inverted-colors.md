# @magica11y/inverted-colors

> 标签: a11y, accessibility, css, environment-blending, forced-colors, inverted-colors, level-5, light-level, matchmedia, media-query, prefers-color-scheme, prefers-contrast, prefers-reduced-motion, prefers-reduced-transparency

## 简介

Detects the user’s preferences for inverted colors using the 'inverted-colors' CSS3 level 5 media query.
