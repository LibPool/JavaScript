# @rhombus-std/fileproviders.core

> 标签: abstractions, fileproviders, filesystem, typescript

## 简介

Read-only file provider abstractions: IFileProvider/IFileInfo/IDirectoryContents plus the null-object helpers (NotFoundFileInfo, NotFoundDirectoryContents, NullFileProvider, NullChangeToken). Depends on @rhombus-std/primitives for the IChangeToken type.
