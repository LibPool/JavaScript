# @rhombus-std/config.extras

> 标签: compiler, config, configuration, ioc, transformer, typescript

## 简介

The @rhombus-std/config authoring surface: types .withType<T>() onto ConfigBuilder and rewrites it into a generated .withSchema(Type.object({...})) call at compile time. A Go/ttsc descriptor package — the transform runs in the shared owner binary.
