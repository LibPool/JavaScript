# @rhombus-std/di.transformer.options

> 标签: compiler, dependency-injection, di, ioc, options, transformer, ts-patch, typescript

## 简介

A @rhombus-std/di.transformer satellite: lowers the type-driven addOptions<T>() sugar to the explicit addOptions(token(Options<T>), token(T)) verb at compile time.
