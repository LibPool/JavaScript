# @linteldk/cli

> 标签: agentic, ai-agents, assisting, claude, claude-code, cli, coding, conventions, generator, personal-assistant, planning, project-template, sales, scaffolding, writing

## 简介

Applies a complete way of working to a project — agent roles, a gated process, document templates and conventions — then updates it later. Five packs: coding, writing, planning, sales, assisting.
