# @enwithai/outcome-check

> 标签: ai-engineering, ci, developer-tools, dora, engineering-metrics, pull-request

## 简介

Offline delivery-outcome metrics (PR acceptance, cycle time, review rework, CI first-pass, reverts) from exported GitHub data, with explicit definitions and unknown AI attribution by default.
