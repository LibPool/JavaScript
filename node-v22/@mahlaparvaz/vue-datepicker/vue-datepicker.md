# @mahlaparvaz/vue-datepicker

> 标签: calendar, chinese, customizable, datepicker, gregorian, hijri, i18n, jalali, persian, range-picker, rtl, time-picker, vue-component, vue-datepicker, vue3-datepicker

## 简介

Vue 3 datepicker supporting Jalali, Hijri, Gregorian, Chinese calendars with range, time picker, i18n, RTL, and full customization.
