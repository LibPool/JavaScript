# @ahmedrowaihi/k6-tools

> 标签: cli, k6, load-testing, openapi

## 简介

CLI for the @ahmedrowaihi/k6 framework. Scaffold load tests (init), regenerate the typed client (sync), bundle+run scripts against the real k6 binary, replay recorded traffic.
