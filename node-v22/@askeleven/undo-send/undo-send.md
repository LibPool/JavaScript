# @askeleven/undo-send

> 标签: agent-safety, ai-agents, delayed-send, email, human-in-the-loop, idempotency, outbox, sms, undo, undo-send

## 简介

Give your agent an undo button. Holds each email, text or other action for a delay before it runs, with an undo link a person can press, and never sends one that was undone. Library, runner, CLI and undo-link server. Zero dependencies.
