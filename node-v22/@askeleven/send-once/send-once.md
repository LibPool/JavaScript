# @askeleven/send-once

> 标签: ai-agents, approval, deduplication, duplicate-messages, email, exactly-once, human-in-the-loop, idempotency, idempotent, sms

## 简介

A send happens once, and only while the approval behind it is still true. An idempotency ledger and perishable approvals for code that sends email, SMS, or anything else on an agent's behalf. Zero dependencies.
