# jest-test-lineage-reporter

> 标签: analytics, coverage, dashboard, duplicate-tests, html-report, jest, jest-reporter, lineage, memory-analysis, mutation-analysis, mutation-testing, performance, reporter, test-analysis, test-coverage, test-effectiveness, test-quality, test-redundancy, testing, vitest, vitest-reporter

## 简介

Find the tests you can delete. Per-test line coverage for Jest, weighted by line rarity, plus mutation testing and test quality scoring.
