# jsgui-node-png

> 标签: image, jsgui, png

## 简介

jsgui - PNG module. Load, save, use scanline filters, supports 32bpp rgba, 24bpp rgb, and 1, 2, 4 and 8 bpp indexed color. Optimizes the selection of scanline filters when saving.
