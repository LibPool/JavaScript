# joplin-plugin-nlr

> 标签: joplin-plugin

## 简介

本插件可以将joplin变成一个网文小说阅读器，资源来自互联网。 ## 插件使用说明 ### 1. 插件安装后会在工具菜单添加一项：**NLR**
