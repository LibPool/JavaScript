# jiosaavn-api-client

> 标签: albums, api, artists, client, cloudflare-workers, download, jiosaavn, music, playlists, saavn, search, songs, streaming, type-safe, typescript, vercel-edge

## 简介

Complete, type-safe TypeScript client for JioSaavn API. Supports all endpoints including search, songs, albums, artists, and playlists. Works on Node, Bun, Cloudflare Workers, Vercel Edge, and Deno.
