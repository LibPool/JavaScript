# jayvictor-ui

> 标签: JavaScript

## 简介

组件的元素类名命名需要独特，避免使用时会造成类名冲突 组件为了方便修改样式，一般不加 scoped，如果加了 scoped，使用时可以使用深度选择器修改样式
