# jev-judge-mcp

> 标签: classification, claude-code, decision, jev, mcp, model-context-protocol, typesafe

## 简介

MCP server exposing TypeSafe's Jev as a `judge` tool for typed judgments with calibrated probabilities. Works in any MCP client; ships an optional Claude Code plugin wrapper.
