# jsdoc-plugin-hia

> 标签: hia, jsdoc, plugin

## 简介

jsdoc plugin, contain some annotations and features, such as @coderef(import a codeblock into doc)（一个jsdoc插件，包含一些标识符和特性，如@CodeRef（将代码块导入文档））
