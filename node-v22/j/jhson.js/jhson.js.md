# jhson.js

> 标签: binding, conversion, convert, converter, css, formatting, html, html5, javascript, jhson.js, json, render, template, text, typescript

## 简介

A JavaScript library for converting between HTML and JSON, with binding, templating, attributes, and CSS support.
