# jupyterlab_advanced_markdown_viewer_extension

> 标签: jupyter, jupyterlab, jupyterlab-extension

## 简介

Live Markdown preview for JupyterLab: an open rendered Markdown document follows the file on disk without a reload, with changes typed in on a green background, removed text shown red before it goes, and a tab cue
