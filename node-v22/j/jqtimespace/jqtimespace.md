# jqtimespace

> 标签: chart, data, date, ecosystem:jquery, events, jquery-plugin, schedule, timeline, timetable

## 简介

The jQuery Timespace plugin provides a way to handle the display of event data in a horizontal table that can be dragged in all directions.
