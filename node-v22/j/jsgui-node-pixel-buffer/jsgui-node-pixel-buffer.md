# jsgui-node-pixel-buffer

> 标签: buffer, image, jsgui, pixel

## 简介

jsgui - Simple pixel buffer for node.js. Supports rgb 24 bits per pixel and rgba 32 bits per pixel. Has get_pixel and set_pixel interface.
