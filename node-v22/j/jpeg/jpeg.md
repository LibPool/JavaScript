# jpeg

> 标签: image, jpg, picture, rgb, rgba

## 简介

A C++ module for node-js that converts RGB and RGBA buffers to a JPEG images (in memory).

## 官网

- 源码仓库：http://github.com/pkrumins/node-jpeg.git
- npm 页面：https://www.npmjs.com/package/jpeg
