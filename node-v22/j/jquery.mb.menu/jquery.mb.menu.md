# jquery.mb.menu

> 标签: ajax, jquery-plugin, menu, multilevel, tree, ui

## 简介

A powerful jQuery component that lets you easily build a multilevel menu or contextual menu (right click) in an intuitive way!<br>You can add as many sub menus as you want and if those are not defined in the page, the component will automatically get them
