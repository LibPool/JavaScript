# js-dynamic-components

> 标签: Node.js, Vue动态插入自定义组件, dynamic-components, js-dynamic-components, js动态插入vue自定义组件, vue, vue-dynamic-components, vue2, vue3, 实用函数

## 简介

Vue项目开发实现js动态插入自定义组件，基于vue的extend方法实现，实现对vue自定义组件动态管理操作，只需要一个方法，传入对应的参数即可实现自定义组件动态管理
