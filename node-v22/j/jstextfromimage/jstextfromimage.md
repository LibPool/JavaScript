# jstextfromimage

> 标签: ai, azure, azure-openai, batch-processing, claude, computer-vision, gpt-4, image-analysis, image-to-text, local-files, machine-learning, openai, typescript, vision-ai

## 简介

Get descriptions of images from OpenAI, Azure OpenAI and Anthropic Claude models. Supports both URLs and local files with batch processing capabilities.
