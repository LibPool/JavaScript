# js-dremio-sql-parser

> 标签: js, sql-parser

## 简介

Dremio SQL(select) parser written with jison. Parse SQL into abstract syntax tree(AST) and stringify back to SQL. SQL grammar follows https://docs.dremio.com/sql-reference/
