# jquery.depend

> 标签: browser, detection, ecosystem:jquery, html5, jquery-plugin, mobile, platform, support, tablet

## 简介

A jQuery plugin for browser detection. This plugin provides the browser detection, browser version detectioin, browser rendering engine detection, platform detection.
