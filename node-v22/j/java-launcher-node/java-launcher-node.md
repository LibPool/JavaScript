# java-launcher-node

> 标签: elyby, fabric, launcher, mc, minecraft, minecraft-launcher

## 简介

Library for creating Minecraft Java launchers. Supports offline and Ely.by authentication, version management, Fabric loader, asset downloading, and launching.
