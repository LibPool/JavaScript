# jsbot-cli

> 标签: boilerplate, cli, commands, react, react-redux, redux

## 简介

A npm package to generate a react boilerplate with : css, redux, routing. Also with the possibilty to generate react components from the command line with options to generate stylesheet, functional components and observer components
