# jq79

> 标签: components, mini, proxy, reactive, single-file-components, ui

## 简介

Mini reactive component library: single-file .html components, Svelte-style setup scripts, fine-grained proxy reactivity. No compiler, no bundler, no dependencies — works from any static host.
