# jarvis-react-ui

> 标签: dark-theme, hud, jarvis, orb, react, react-component, sci-fi, sound-effects, tailwind, three, ui, ui-library, window-manager

## 简介

Sharp, dark HUD-style React component library: primitives, compositions, a window/slot-grid system and a CSS/Three.js orb, with built-in UI sound effects.
