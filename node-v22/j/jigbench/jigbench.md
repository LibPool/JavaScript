# jigbench

> 标签: ai-agent, angular, claude, claude-code, codegen, devtools, dotnet, mcp, model-context-protocol, prototyping

## 简介

Jig — a local-first benchtop for shaping a feature before Claude builds it. Clamp an app repo, survey it, Point at the running app, write the requirement as a Prompt; Build runs Claude Code in the repo with it.
