# jev-eval-mcp

> 标签: calibration, classifier, evaluation, jev, mcp, model-context-protocol, system-one, typesafe

## 简介

Eval-first MCP server for TypeSafe's Jev: prototype typed questions, map them over many items, and measure them against labeled fixtures.
