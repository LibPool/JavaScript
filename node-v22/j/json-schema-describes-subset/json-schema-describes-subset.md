# json-schema-describes-subset

> 标签: disjunctive normal form, dnf, empty set, json, json schema, json schema canonicalization, json schema disjunctive normal form, json schema dnf, schema, static json schema analysis, static json schema processing, static json schema validation, subset, superset

## 简介

Tools for static JSON schema analysis, including functions to determine if one schema describes a subset of another or if a schema describes the empty set or to convert a schema to its disjunctive normal form (DNF).
