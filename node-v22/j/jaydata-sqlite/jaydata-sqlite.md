# jaydata-sqlite

> 标签: Android, Facebook, HTML5 data management, IndexedDB, JSLQ, JavaScript, JavaScript Language Query, OData, SQLite, WebSQL, YQL, cross-platform, iPhone

## 简介

Cross-platform HTML5 data-management, JavaScript Language Query (JSLQ) support for OData, SQLite, WebSQL, IndexedDB, YQL and Facebook (packaged for Node.JS)
