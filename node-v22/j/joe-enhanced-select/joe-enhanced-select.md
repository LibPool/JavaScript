# joe-enhanced-select

> 标签: autocomplete, component, dropdown, enhanced-select, joe-enhanced-select, joeEnhancedSelect, joeenhancedselect, multiselect, react, search, select, ui

## 简介

一个功能强大、易于使用的增强型选择组件，支持静态选项、异步加载、多选、搜索等功能（高亮匹配）。
