# jx-common-css

> 标签: JavaScript

## 简介

相对定位： .relative 绝对定位： .absolute 固定定位： .fixed 显示： .show 隐藏： .hide 文字水平居中： .text-center 文字居左：.text-left 文字居右：.text-right 文字中线/删除线：.line-through 文字下划线：.underline 元素垂直居中：.vertical-middle 元素垂直向上：.vertical-top 元素垂直向下：.vertical-bottom .tags：小标签样式 .
