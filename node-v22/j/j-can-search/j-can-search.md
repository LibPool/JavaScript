# j-can-search

> 标签: citation-verification, claude-code, codex, gemini, grok, grounding, mcp, model-context-protocol, openai, search, web-search

## 简介

MCP server that gives search-less AI agents a verified web search tool: drives a search-capable model (Gemini grounding / xAI web search / OpenAI Responses web_search / any OpenAI-compatible gateway) and verifies every cited URL before returning — fabrica
