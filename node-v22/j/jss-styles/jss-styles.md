# jss-styles

> 标签: JavaScript

## 简介

A Stylesguide parser (and example generator) for creating living styleguides, based on kss - http://github.com/kneath/kss.

## 官网

- 源码仓库：https://github.com/jesseditson/jss
- npm 页面：https://www.npmjs.com/package/jss-styles
