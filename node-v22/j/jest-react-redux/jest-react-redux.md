# jest-react-redux

> 标签: jest, mock, react, react-redux, redux, snapshot, test, testing, unit, unit-test

## 简介

Makes snapshot testing of react-redux (e.g. mapStateToProps or mapDispatchToProps) glue-code easy as pie.
