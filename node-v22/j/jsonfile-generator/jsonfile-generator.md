# jsonfile-generator

> 标签: JavaScript

## 简介

- 動態產生json檔案 # 安裝指令 - npm i  -g jsonfile-generator # 使用方式 - 新增一個名為Sample的資料夾 - 在Sample資料夾中建立兩個json檔     -  master.json (主要的json資料)     -  config.json (各個系統運作環境所需要的json資料) - master.json檔加入以下json文字範例 ``` {     "FileNmae":"Master" } ``` - config.json檔加入以下jso
