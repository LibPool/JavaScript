# jquery-svgpan

> 标签: pan, svg, zoom

## 简介

This plugin provides a jQuery hook to use Andrea Leofreddi's SVGPan library on an arbitrary number of SVGs.

- 官网：https://github.com/talos/jquery-svgpan
