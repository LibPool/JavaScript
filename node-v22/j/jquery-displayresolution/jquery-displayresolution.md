# jquery-displayresolution

> 标签: display, inspector, jquery, jquery-plugin, resolution, responsive, screen, viewport, widget

## 简介

jQuery plugin that displays viewport/screen resolution, scroll position and browser dimensions in a floating copy-to-clipboard widget
