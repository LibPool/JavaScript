# jev-swap

> 标签: ai-sdk, anthropic, classification, cli, cost, decision, jev, langchain, llm, openai, typesafe

## 简介

Find the LLM calls in your TS/JS or Python code that are really decisions, estimate their cost and speed on TypeSafe Jev, convert them, and prove the swap on your own traffic.
