# jsonresume-execute

> 标签: cli, cv, json resume, jsonresume, orchestrator, resume

## 简介

Unified CLI that orchestrates jsonresume-lint, jsonresume-parity, jsonresume-tailor, and resume-cli across languages and role variants — without bundling them.
