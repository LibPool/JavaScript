# json-kiln

> 标签: big-data, cli, data-generator, deterministic, docker, ejson, generator, json, large-files, load-testing, mongodb, nodejs, performance, seed, stream, streaming, typescript

## 简介

Streaming JSON array generator by target size (bytes). Exact-size files, per-item min size, deterministic, EJSON. No OOM.
