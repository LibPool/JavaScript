# joplin-plugin-inline-todo-gui

> 标签: joplin-plugin

## 简介

Convert the text at your cursor into an @TODO checkbox with a configurable default due date (calendar picker, or no date at all), tags, and a per-task keyword, in both the Markdown and Rich Text editors. Companion to the Inline TODO plugin (plugin.calebjo
