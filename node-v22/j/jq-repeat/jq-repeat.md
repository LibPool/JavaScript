# jq-repeat

> 标签: data-binding, dom, dynamic-lists, jquery, jquery-plugin, mustache, repeat, template, templating

## 简介

A simple, yet highly customizable jQuery plugin for dynamic DOM templating with Mustache. Supports automatic sorting, nested templates, and custom index keys.
