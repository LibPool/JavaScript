# jael

> 标签: ASTER, ASTGTM, ASTGTMV003, ASTGTM_v003, DEM, GeoTiff, Library, METI, NASA, altitude, elev, elevation, elevations, elevs, height

## 简介

Just Another Elevation Library --> reads multi-point elevation data from NASA/METI ASTGTM_v003 elevations dataset. GeoTiff files must be downloaded as described in the readme.
