# jev-firewall

> 标签: ai-agent, claude-code, codex, firewall, hooks, security

## 简介

A real-time firewall for AI coding agents: every tool call is checked (deterministic rules + the Jev decision model) before it reaches your machine. One command wires it into Claude Code and Codex.
