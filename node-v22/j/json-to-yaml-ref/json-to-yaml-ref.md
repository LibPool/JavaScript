# json-to-yaml-ref

> 标签: JavaScript

## 简介

Convert JSON/JS objects to YAML, aggressively deduplicating repeated nested objects and arrays into YAML **anchors** (`&name`) and **aliases** (`*name`). Identical structures are emitted once and referenced everywhere else — smaller, DRY, still 100% valid
