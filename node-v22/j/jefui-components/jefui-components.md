# jefui-components

> 标签: componentes, expo, jefui, librería, react-native, typescript, ui

## 简介

@jefui/components es una librería de componentes reutilizables para React Native (incluyendo soporte para Expo), diseñada para acelerar el desarrollo de interfaces móviles modernas y consistentes. Incluye botones personalizables, inputs estilizados, modal
