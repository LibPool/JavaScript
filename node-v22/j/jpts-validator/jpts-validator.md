# jpts-validator

> 标签: JavaScript, Node.js, TypeScript, validator

## 简介

TypeScript版本的验证器Validator，提供简单的正则、长度、大小、范围、数字、字符、日期等验证功能，同时支持验证规则的自定义扩展。
