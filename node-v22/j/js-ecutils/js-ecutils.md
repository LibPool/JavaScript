# js-ecutils

> 标签: cryptographic-algorithms, diffie-hellman-key-exchange, digital-signatures, ecc-based-protocols, ecdsa, elliptic-curve-cryptography, elliptic-curve-operation, javascript-cryptography, koblitz-encoding, massey-omura-protocol, message-encoding-and-decoding, public-key-cryptography, secure-communication

## 简介

JavaScript Library for Elliptic Curve Cryptography: key exchanges (Diffie-Hellman, Massey-Omura), ECDSA signatures, and Koblitz encoding. Suitable for crypto education and secure systems.
