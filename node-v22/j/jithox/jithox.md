# jithox

> 标签: agent, cli, connect, jithox, mcp

## 简介

Jithox Connect Kit — OAuth-first: connect the AI client you already use to Jithox; the client signs in itself, no credential in any file. Preview first, explicit consent, backup, atomic write, test, undo.
