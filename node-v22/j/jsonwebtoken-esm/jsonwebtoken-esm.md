# jsonwebtoken-esm

> 标签: jsonwebtoken, jwt

## 简介

A wrapper that rebundles [`jsonwebtoken`](https://www.npmjs.com/package/jsonwebtoken) into ESM, so you can use it in your `vite`, `skypack`, or wherever you need ESM.
