# joplin-plugin-aide

> 标签: ai, antigravity, assistant, chat, claude, codex, copilot, joplin, joplin-plugin

## 简介

AI assistant chat panel for Joplin - read, search and edit notes via Claude Code / GitHub Copilot / OpenAI Codex / Google Antigravity CLI or the Kimi (Moonshot) API, with per-write confirmation
