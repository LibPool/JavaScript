# js-gravatar

> 标签: angular-avatar, angular-gravatar, avatar, gravatar, javascript, react-avatar, react-gravatar, vue-avatar, vue-gravatar

## 简介

A vanilla JS library to get a user's gravatar and if it doesn't exist provides one different from gravatar default
