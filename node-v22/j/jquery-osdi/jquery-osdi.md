# jquery-osdi

> 标签: ajax, ecosystem:jquery, jquery-plugin, osdi

## 简介

The jQuery OSDI plugin implements non-authenticated POST via AJAX against OSDI-compliant API endpoints. It can be used to send in data to OSDI-compliant APIs.
