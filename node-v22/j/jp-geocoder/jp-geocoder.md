# jp-geocoder

> 标签: address, cloudflare-r2, geocoder, geocoding, japan, japanese-address, latitude, longitude, ジオコーディング, 住所, 緯度経度

## 简介

Japanese address geocoder powered by the Digital Agency Address Base Registry. No server, no database — static JSON over CDN. 日本の住所文字列を緯度経度に変換する
