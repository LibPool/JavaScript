# jw-gate

> 标签: async, concurrent, condition-monitoring, coordination, dynamic-conditions, event-driven, event-emitter, flow-control, gate, iot, locks, monitoring, multi-condition, orchestration, progress-tracking, promise-coordination, reactive, reactive-programming, resource-management, sensors, state-management, synchronization, ui-state, workflow

## 简介

Creates a "gate" with "locks." When all locks are open, the gate is open, useful for dealing with semi-random async events.
