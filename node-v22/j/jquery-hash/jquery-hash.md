# jquery-hash

> 标签: base64, hash, hex, jquery, jquery-plugin, sha1, sha256, sha384, sha512, webcrypto, webcrypto-api

## 简介

jQuery plugin to return a hash for a string using SHA 1/256/384/512 and the web crypto api
