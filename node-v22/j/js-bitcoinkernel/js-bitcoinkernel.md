# js-bitcoinkernel

> 标签: bitcoin, bitcoin-core, ffi, koffi, libbitcoinkernel, typescript

## 简介

A JavaScript/TypeScript Bitcoin kernel that wraps native C/C++ functions to provide safe and structured access to Bitcoin data structures like block headers and hashes.
