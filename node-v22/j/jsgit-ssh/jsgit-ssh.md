# jsgit-ssh

> 标签: clone, fetch, git, git over ssh, http shim, http-client, isomorphic-git, isomorphic-git-ssh, node, pull, pure js, push, receive-pack, remote, scp, ssh, ssh transport, ssh2, transport, upload-pack

## 简介

An SSH transport for isomorphic-git: an http-client shim that speaks git-upload-pack/git-receive-pack over an ssh2 exec channel, so git.clone/fetch/push/listServerRefs work over SSH in pure JS
