# jevtrace

> 标签: claude-code, code-context, codex, coding-agent, cursor, javascript, mcp, mcp-server, model-context-protocol, retrieval, typescript

## 简介

MCP server that hands coding agents the JS/TS code a task needs: Jev picks the relevant declarations, the TypeScript compiler follows their callers, callees, types and tests
