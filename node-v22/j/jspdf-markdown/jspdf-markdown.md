# jspdf-markdown

> 标签: autotable, columns, gfm, header-footer, jspdf, layout, markdown, pdf, table-styling, typescript

## 简介

Render Markdown into jsPDF with full inline formatting, styled tables (incl. merged cells), and a precise positional layout API (columns, headers/footers, measurement).
