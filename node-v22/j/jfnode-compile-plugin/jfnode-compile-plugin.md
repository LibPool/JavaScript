# jfnode-compile-plugin

> 标签: JavaScript

## 简介

**介绍** 允许你在 js 代码中新增自定义的标签，并且这个标签内的代码只有在开发环境的时候会编译进去， 在生产环境中不会编译，比如，你需要查看 state 中的变量，但是在生产环境中不需要，你需要一个 工具去帮助你只在开发的时候做些事，它是很好的选择。
