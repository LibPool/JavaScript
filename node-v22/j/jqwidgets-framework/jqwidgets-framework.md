# jqwidgets-framework

> 标签: JavaScript

## 简介

jQWidgets UI framework for JavaScript, jQuery, React, Vue and TypeScript with over 1,000 demos - 82 widgets including a data grid, scheduler, Gantt chart, pivot grid, tree grid and charts, with 40 themes.

- 源码仓库：git://github.com/jqwidgets/jQWidgets.git
