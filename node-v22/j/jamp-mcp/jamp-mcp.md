# jamp-mcp

> 标签: ai-agents, analytics, claude, error-tracking, jamp, mcp, modelcontextprotocol, monitoring, observability, uptime, web-vitals

## 简介

MCP server for JAMP. Your AI agent installs JAMP on a site, watches errors, uptime, vitals and traffic, and resolves what it fixes.
