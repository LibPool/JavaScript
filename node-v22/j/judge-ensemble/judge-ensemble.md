# judge-ensemble

> 标签: abort, ensemble, fallback, fanout, judge, jury, llm-as-judge, panel, retry, timeout, typescript

## 简介

Run N concurrent judges under a hard time budget — always get exactly N labeled results (real | substitute | fallback), streamed as they land, with abort cascades that never waste in-flight calls.
