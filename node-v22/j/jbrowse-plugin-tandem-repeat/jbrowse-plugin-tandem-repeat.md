# jbrowse-plugin-tandem-repeat

> 标签: VNTR, jbrowse, jbrowse2, tandem repeat

## 简介

JBrowse 2 view of a tandem repeat's alleles: one bar per haplotype, each copy coloured by its repeat unit, read from VCF 4.5 <CNV:TR> records
