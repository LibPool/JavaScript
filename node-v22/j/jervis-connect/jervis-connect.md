# jervis-connect

> 标签: ajax, auth, axios, browser, cache, circuit-breaker, client, fetch, graphql, http, interceptors, node, offline, plugins, priority-queue, request, sse, universal

## 简介

A lightweight, zero-dependency, plugin-based HTTP client for all JavaScript runtimes. Axios-like API with modern fetch.
