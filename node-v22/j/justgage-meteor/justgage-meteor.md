# justgage-meteor

> 标签: clean, dashboard, gauge, indicator, javascript, measure, meter, minimal, performance, plugin, simple, svg, vector

## 简介

This is a fork that allows to easily import JustGage into meteor. JustGage is a handy JavaScript plugin for generating and animating nice & clean gauges. It is based on Raphaël library for vector drawing, so it’s completely resolution independent and self
