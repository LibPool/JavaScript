# junhost

> 标签: agent, ai, codex, dashboard, mcp, self-hosted

## 简介

Jun — a self-hosted dashboard that runs and supervises Codex as a 24/7 local/VPS agent: chat runs, workspace files, skills, MCP, schedules.
