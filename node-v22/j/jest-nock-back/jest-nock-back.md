# jest-nock-back

> 标签: JavaScript

## 简介

Record HTTP fixtures (**N**etwork M**ocks**) for your tests. This is simply a light Jest-wrapper around [Nock](https://github.com/nock/nock)'s [nock-back](https://github.com/nock/nock#nock-back) feature.
