# jquery.photocols

> 标签: animation, columns, gallery, grid, horizontal-scroll, jquery, jquery-plugin, lazy-loading, masonry, parallax, photo, responsive, rows, vertical-scroll

## 简介

Photocols: An animated photo gallery with scrolling columns and rows for jQuery. Supports vertical/horizontal scrolling, variable speeds, lazy loading.
