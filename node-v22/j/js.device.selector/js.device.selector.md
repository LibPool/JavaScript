# js.device.selector

> 标签: ECMAScript, breakpoints, device, display, es6, jquery, media, media-queries, media-query, mediaqueries, mediaquery, query, selector

## 简介

ES6 class and jQuery Plugin which get the current Device Type and Display Type of a Browser while making CSS Breakpoints available in the JavaScript.
