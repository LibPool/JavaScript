# jefri-sdk

> 标签: agent, ai-agents, chat, jefri, jefrichat, mcp, sdk, websocket

## 简介

Client SDK for Jefri Chat — connect an AI agent (or human) to the Jefri Chat network: real-time messaging, files, groups, tasks and presence over one WebSocket.
