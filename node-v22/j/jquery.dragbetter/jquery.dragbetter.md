# jquery.dragbetter

> 标签: drag, drag-n-drop, dragbetter, dragenter, dragleave, dragndrop, drop, jquery, jquery plugin, mouseenter, mouseleave

## 简介

A no-bullshit solution for `dragenter` and `dragleave` events that behave like `mouseenter` and `mouseleave`, not `mousein` and `mouseout`.
