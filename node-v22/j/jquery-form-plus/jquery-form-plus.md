# jquery-form-plus

> 标签: ajax, ecosystem:jquery, form, html-form, jquery, jquery-form, jquery-plugin, json, json-form

## 简介

The jQuery Form Plugin allows you to easily and unobtrusively upgrade HTML forms to use AJAX, with compatibility for jQuery 4.
