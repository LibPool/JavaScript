# jclcheck

> 标签: cli, formatter, ibm, jcl, linter, mainframe, sarif, validator, z/os, zos

## 简介

Check z/OS JCL without a mainframe: a lexer, parser and rule engine based on the IBM JCL Reference, a formatter, and the jclcheck command (text, JSON and SARIF output). No dependencies.
