# jsorm-i18n

> 标签: JavaScript

## 简介

A JavaScript library for i18n: calendar conversions (Gregorian, Julian, Hebrew, Islamic, Sym010, Sym454, others), timezones, i18n resource bundles, currency rendering

## 官网

- 源码仓库：git://github.com/deitch/jsorm-i18n.git
