# jdex-mcp

> 标签: anthropic, claude, jdex, johnny-decimal, mcp, model-context-protocol, personal-knowledge-management, pkm

## 简介

Model Context Protocol server exposing a Johnny.Decimal index as queryable (and optionally writable) tools for Claude Desktop, Claude Code, Cursor, and any other MCP client.
