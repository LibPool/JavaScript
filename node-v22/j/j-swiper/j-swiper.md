# j-swiper

> 标签: j-swiper, swiper, uniapp, 切屏, 禁止回弹

## 简介

官方swiper无法设置禁止第一屏和最后一屏回弹，本插件旨在使用时搭配tabs切屏， 本插件仅代替swiper，示例使用了zTbas作为展示示例，实际导入时不包含zTbas。解决了左右滑动的回弹效果
