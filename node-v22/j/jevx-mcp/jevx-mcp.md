# jevx-mcp

> 标签: classification, decisions, jev-ai, jevx, mcp, model-context-protocol, typesafe, zero-shot

## 简介

MCP server for Jevx (jevx.org) — run Jev AI typed decisions (choice, score, noul with probabilities) from any MCP client, on your own Jevx API key.
