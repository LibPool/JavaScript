# js-data-typer

> 标签: api, body, coerce, coercion, express, javascript, node, payload, query, request, result, runtime, schema, typer, validation

## 简介

Payload typer for JavaScript APIs: plain-object schemas, coercion, and Result returns. Throws only on bad schemas.
