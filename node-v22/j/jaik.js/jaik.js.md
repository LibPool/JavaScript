# jaik.js

> 标签: ai, batteries-included, cors, css-in-js, dom, event-bus, framework, hyperscript, llm, micro-framework, middleware, minimal, node, router, static-server, token-efficient

## 简介

Batteries-included micro-framework for AI-generated code. Router, event bus, fetch, localStorage, CSS-in-JS, CORS, static server, middleware. 1-char API, zero verbosity.
