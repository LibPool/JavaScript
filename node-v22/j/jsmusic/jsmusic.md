# jsmusic

> 标签: API, JavaScript, audio, control, flac, library, mp3, music, npm, playback, player, wav

## 简介

JSmusic is a JavaScript library that makes it easy to play audio files in MP3, WAV, and FLAC formats. Its design makes it an ideal tool for creating simple music players or integrating audio features into various web projects.
