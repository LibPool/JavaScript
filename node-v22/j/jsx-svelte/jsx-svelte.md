# jsx-svelte

> 标签: jsx, svelte, svelte5, testing, tsx, vite-plugin, vitest

## 简介

Write Svelte 5 components in TSX for tests. A Vite plugin that extracts JSX components from .tsx files and compiles them with the real Svelte compiler.
