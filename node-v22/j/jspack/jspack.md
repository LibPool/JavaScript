# jspack

> 标签: JavaScript

## 简介

JavaScript library to pack primitives to octet arrays, including int64 support, packaged for NodeJS.

- 官网：https://github.com/birchroad/node-jspack
- 源码仓库：git://github.com/birchroad/node-jspack.git
