# @companydata/sirene-api

> 标签: b2b-data, business-register, company-data, company-search, entreprises, france, french, insee, sdk, siren, sirene, sirene-api, siret, typescript

## 简介

Sirene API wrapper: French company data from the Sirene register (INSEE) with full addresses, phone, email, website and firmographics, through one REST call. A thin layer over @companydata/companydata-sdk, pinned to FR.
