# @companydata/mcp-server

> 标签: business-registry, company-data, company-data-api, companydata, firmographics, kyb, mcp, mcp-server, model-context-protocol

## 简介

MCP server for the CompanyData API: company search, enrichment and city lookup from official business registers in 200+ countries. Local (stdio) or hosted at https://companydata.com/mcp/.
