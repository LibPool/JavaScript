# @crawlee/fs-storage-native-darwin-x64

> 标签: JavaScript

## 简介

Low-level Rust-powered napi-rs bindings for Crawlee's filesystem storage. Not intended for direct use in crawlers — depend on @crawlee/fs-storage instead.
