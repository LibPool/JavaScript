# @nightqueue/nq

> 标签: agent, automation, claude, claude-code, cli, mcp, memory, plugin, queue, studio

## 简介

Issues in, pull requests with proof out. A local queue of coding agents with a cockpit: queue a job in the Studio, watch it reproduce, root-cause, fix and prove the change phase by phase, and come back to a pull request with evidence. Runs on Claude Code,
