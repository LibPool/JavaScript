# sleepmetrics

> 标签: actigraphy, chronotype, circadian, mctq, msfsc, sleep, sleep-regularity, social-jetlag, sri

## 简介

Standard sleep metrics in pure JavaScript: sleep regularity index (SRI) and circadian phase (MSFsc / social jetlag). Zero dependencies, no build step, no network, no filesystem.
