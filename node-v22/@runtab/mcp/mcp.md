# @runtab/mcp

> 标签: ai-agent, mcp, model-context-protocol, payments, usdc, x402

## 简介

Tab MCP proxy: lets an AI agent pay x402 (HTTP 402) charges in USDC under a server-enforced spending cap — the agent never holds a key.
