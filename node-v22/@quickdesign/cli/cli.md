# @quickdesign/cli

> 标签: ai, claude-code, cli, image-generation, meta-ad-library, quickdesign, spy-brands, video-generation

## 简介

QuickDesign CLI — image + video generation (Sora 2, Kling, Seedance 2.0, UGC), Smart Ad Creator (incl. Advantage+), Spy Brands ad intelligence, Brand DNA extraction, and designs CRUD — from your terminal or a Claude Code agent.
