# @pablosr/mcp-email-notification

> 标签: JavaScript

## 简介

Small stdio MCP server with one tool, `send_email`. It sends plain-text email through Nodemailer. The tool accepts only `subject` and `text`; sender, recipient, and SMTP settings come from environment variables.
