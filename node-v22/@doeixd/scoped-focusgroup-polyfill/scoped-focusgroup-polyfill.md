> 标签: a11y, accessibility, focus management, focusgroup, grid, keyboard navigation, menu, open-ui, polyfill, pridepack, roving tabindex, shadow dom, tablist, toolbar, w3c, web components

## 简介

A complete and robust polyfill for the Scoped Focusgroup proposal, enabling declarative roving tabindex and accessible keyboard navigation.
