# @suzukihayate/graphemes

> 标签: emoji, grapheme, length, segmenter, slice, string, truncate, unicode, zero-dependency

## 简介

Emoji- and grapheme-aware string helpers (length, slice, truncate, reverse) using Intl.Segmenter. Zero dependencies.
