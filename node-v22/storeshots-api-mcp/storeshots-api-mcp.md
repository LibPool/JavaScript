# storeshots-api-mcp

> 标签: app-store, aso, google-play, marketing, mcp, model-context-protocol, screenshots, storeshots

## 简介

MCP server for StoreShots: turn raw app screenshots into App Store & Google Play marketing screenshots via the hosted StoreShots API (no Chrome needed).
