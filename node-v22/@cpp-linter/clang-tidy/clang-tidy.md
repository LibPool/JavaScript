# @cpp-linter/clang-tidy

> 标签: c, c++, clang, clang-tidy, cpp, lint, linter, llvm, static-analysis

## 简介

clang-tidy, the C/C++ linter from LLVM, as a static binary with its builtin headers (LLVM 23.1.3).
