# @mu-crew/mu

> 标签: agents, ai, herdr, orchestration, pi-coding-agent, pi-package, task-graph, terminal-multiplexer, tmux

## 简介

A persistent, observable crew of pi agents running in one tmux or herdr session per workstream, coordinated through a built-in task DAG.
