# @gradusmusic/notation-mcp

> 标签: agent, ai, ai-tools, anthropic, claude, claude-code, claude-desktop, composition, cursor, gradus, gradusmusic, lilypond-alternative, mcp, mcp-server, midi, model-context-protocol, music, music-engraving, music-notation, music-theory, musicxml, notation, sheet-music, svg, verovio

## 简介

Three Gradus music tools for AI agents in one MCP server: Gradus Notation (render scores to SVG/MusicXML/MIDI), the Gradus Harmonic Analyzer (Roman numerals, keys, cadences, texture), and the Gradus Engraver (checks against a citable engraving rulebook).
