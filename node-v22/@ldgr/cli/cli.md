# @ldgr/cli

> 标签: JavaScript

## 简介

LDGR's self-custody terminal wallet. Version 0.4.0 creates or imports local wallets, lets you select between them, shows addresses and balances, sends native Ledra or a token, and persistently switches the selected wallet between mainnet and testnet.
