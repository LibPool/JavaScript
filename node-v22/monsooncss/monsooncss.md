# monsooncss

> 标签: arbitrary-values, atomic-css, cdn, cdn-css, container-queries, css, css-cdn, css-framework, css-utilities, dark-mode, design-tokens, frontend, functional-css, no-build, no-build-css, oklch, production-css, purge, relative-color-syntax, responsive, seed-color, stylesheet, theming, utility-classes, utility-css, utility-first, zero-config, zero-config-css

## 简介

Utility-first CSS framework that needs no build step. One CSS file from a CDN, familiar utility class names, seed color theming in pure CSS and automatic dark mode.
