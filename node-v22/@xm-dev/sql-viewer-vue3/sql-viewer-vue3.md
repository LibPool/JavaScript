# @xm-dev/sql-viewer-vue3

> 标签: codemirror, database-terminal, sql-console, sql-editor, sql-viewer, vue

## 简介

Vue3 SQL editor component based on CodeMirror 6 & Element Plus, with syntax highlight, autocomplete, SQL formatter and database query console for admin projects.
