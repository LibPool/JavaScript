# @alfe.ai/openclaw-secrets

> 标签: agent, ai-agents, alfe, llm, openclaw, plugin

## 简介

OpenClaw plugin — per-scope (org/team/project/agent) encrypted secret store. Agents encrypt/decrypt locally with AES-256-GCM; KMS data keys are fetched via the Alfe secrets service.
