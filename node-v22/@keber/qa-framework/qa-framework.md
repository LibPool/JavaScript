# @keber/qa-framework

> 标签: agent, azure-devops, copilot, framework, playwright, qa, spec-driven, testing

## 简介

Reusable spec-driven QA framework for IDE-agent-assisted automated testing. Installable as an npm package. Provides structure, templates, agent instructions, and optional integrations for Playwright and Azure DevOps.
