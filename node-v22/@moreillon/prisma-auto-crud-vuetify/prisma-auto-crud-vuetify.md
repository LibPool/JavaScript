# @moreillon/prisma-auto-crud-vuetify

> 标签: JavaScript

## 简介

A Vue module built with Vuetify to automatically create views for each table managed by the [Prisma Auto CRU middleware](https://github.com/maximemoreillon/prisma-auto-crud). It is also provided as a standalone Docker container.
