# @humanexon/feedback-react

> 标签: JavaScript

## 简介

基于 `@humanexon/feedback-core` 框架无关前端逻辑的 headless React 绑定。**无样式、无传输** —— 传入一个 `FeedbackClient`（你基于 tRPC/REST 等的实现），用自己的 UI 渲染。
