# @pi-unipi/memory

> 标签: memory, mempalace, pi-coding-agent, pi-extension, pi-package, sqlite-vec, unipi, vector-search

## 简介

Persistent cross-session memory with MemPalace backend (auto-installed) and SQLite fallback for Pi coding agent
