# @typedecision/opencode-tdm

> 标签: ai-agent, jev, opencode, opencode-plugin, tdm, typed-decision-model

## 简介

TDM harness adapter for opencode: registers a tdm_judge tool for typed, auditable judgments and an automatic execute.before risk gate that escalates risky tool calls to user confirmation.
