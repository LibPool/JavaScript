# @huntabyte/svelte-get-component-info

> 标签: autogenerator, documentation, npm, svelte, sveltejs, sveltekit, ts, typescript

## 简介

Extract information about the props, actions, slots and css variables from a Svelte file. Designed to simplify the creation of documentation.
