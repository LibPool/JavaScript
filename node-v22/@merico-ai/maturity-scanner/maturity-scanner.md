# @merico-ai/maturity-scanner

> 标签: agents, ai, claude-code, cli, copilot, cursor, maturity, scanner, skills

## 简介

Scan a code repository and report its AI coding maturity (level L0-L4 + AMI score). Standalone CLI, no server, no database.
