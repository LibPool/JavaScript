# @zebridge/client

> 标签: cdc, jetstream, nats, offline-first, postgresql, replica, sqlite, sync

## 简介

ZeBridge client: an offline-first SQLite replica of PostgreSQL tables, kept in sync over NATS JetStream, for browsers and Node
