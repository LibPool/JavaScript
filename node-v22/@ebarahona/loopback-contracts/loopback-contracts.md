# @ebarahona/loopback-contracts

> 标签: asyncapi, avro, cloudevents, codegen, contract-first, contracts, extension, graphql, json-schema, loopback, loopback4, loopback4 extension, openapi, protobuf, zod

## 简介

JSON Schema-driven contract substrate for LoopBack 4 — emits LB4 model/repository/controller/datasource plus sidecars (Zod, TypeScript types, GraphQL, CloudEvents, AsyncAPI, Protocol Buffers, Avro, OpenAPI components, mock fixtures).
