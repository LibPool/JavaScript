# @razroo/iso-timeline

> 标签: agent, ai, cadence, claude-code, codex, coding-agent, cursor, follow-up, harness, opencode, timeline, workflow

## 简介

Deterministic time-based next-action planning for AI-agent workflows: compute due, overdue, suppressed, and blocked actions from dated events and local policy.
