# @anil-labs/file-picker-core

> 标签: file-picker, file-upload, framework-agnostic, image-picker, media-library, media-manager, typescript

## 简介

Framework-agnostic media-library file picker — folders, upload, search/type filters, metadata editing and single/multi selection. Renders its own UI; pluggable backend adapter. Zero dependencies.
