# openjev-mcp

> 标签: ai-agents, classification, claude, cursor, jev, llm-as-judge, mcp, mcp-server, model-context-protocol, openjev, routing, structured-output, typesafe

## 简介

MCP server for typed AI judgments: classify, route, score, and flag with calibrated probabilities instead of prose. Powered by Jev via the OpenJEV API.
