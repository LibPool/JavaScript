# @gentleduck/auth

> 标签: abac, auth, authentication, csrf, express, hono, iam, jwt, magic-link, mfa, next, oauth, passkey, passwordless, rbac, session, totp, webauthn

## 简介

Authentication for modern TypeScript apps. Faceted, framework-agnostic, transport-pluggable. Pairs with @gentleduck/iam.
