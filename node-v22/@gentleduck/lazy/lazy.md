# @gentleduck/lazy

> 标签: accessibility, components, gentleduck, image-lazy-loading, intersection-observer, lazy-load, lazy-loading, performance, react, react-lazy-load, virtualization

## 简介

A package for lazy loading components and images, providing virtualized rendering to improve client-side performance.
