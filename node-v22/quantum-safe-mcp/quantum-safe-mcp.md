# quantum-safe-mcp

> 标签: ai-agents, cbom, claude, cryptography, cursor, mcp, model-context-protocol, post-quantum, pqc

## 简介

Model Context Protocol server: lets coding agents audit a JavaScript/TypeScript project for quantum-vulnerable cryptography, choose a post-quantum algorithm suite, and look up quantum-safe-ts errors.
