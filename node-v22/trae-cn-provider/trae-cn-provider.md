# trae-cn-provider

> 标签: cordis, deepseek-harness, dsh, llm, plugin, provider, trae, trae-cn

## 简介

Trae CN as a native DeepSeek Harness LLM provider: browser OAuth login by default, optional local-install credential source, OpenAI-compatible surface on the host web server
