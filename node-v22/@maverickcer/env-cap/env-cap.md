# @maverickcer/env-cap

> 标签: config, configuration, documentation, dotenv, env, environment, schema, secrets, typescript, validation

## 简介

Secure, type-safe, framework-agnostic environment contracts. Contracts own the environment variables they consume; the package provides runtime validation and build-time contract discovery.
