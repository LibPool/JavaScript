# @cyca/simple-create-resource

> 标签: JavaScript

## 简介

Super basic create-resource for use with React Suspense with basic global cache. Note that this doesn't respect [HTTP Caching](https://gist.github.com/ryanflorence/e10cc9dbc0e259759ec942ba82e5b57c#gistcomment-3114667).
