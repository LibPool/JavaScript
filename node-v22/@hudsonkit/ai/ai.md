# @hudsonkit/ai

> 标签: agent, ai, ai-sdk, hudsonkit, llm, streaming, tools

## 简介

Provider-neutral Backend interface, multi-step tool execution loop, and portable toolset registry for Hudson AI surfaces. Ships pi-ai and vercel-ai adapters.
