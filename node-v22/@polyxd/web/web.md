# @polyxd/web

> 标签: JavaScript

## 简介

Web Components renderer for Polyxd UI documents: <polyxd-surface> and <polyxd-frame>, no framework, no shadow DOM, the same DOM and ARIA as @polyxd/react

- 源码仓库：git+https://github.com/visualfart/polyxd.git
