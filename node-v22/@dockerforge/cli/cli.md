# @dockerforge/cli

> 标签: cli, containerize, docker, dockerfile, generator, lint, sarif

## 简介

DockerForge CLI: generate production-grade Dockerfiles, .dockerignore, and Compose from a local project, and lint Dockerfiles (human/JSON/SARIF). Offline.
