# @whatsarab/sdk

> 标签: arabic, mena, messaging, meta-cloud-api, otp, whatsapp, whatsapp-business-api

## 简介

Official TypeScript client for the WhatsArab API — send WhatsApp messages, upload media, manage templates, send and verify OTPs, and verify signed webhooks.
