# @ixo/payouts-facilitator

> 标签: JavaScript

## 简介

One-command install of a company's own payouts-only IXO facilitator on Cloudflare (deploy, payout wallet, on-chain anchoring, trust check, admin), plus the browser-safe facilitator trust check (`@ixo/payouts-facilitator/trust`).
