# wenmar-open-data-shop

> 标签: automotive, nhtsa, recalls, sqlite, transport-canada, vehicle

## 简介

The Wenmar Open shop file: recall campaigns from NHTSA and Transport Canada matched to the Wenmar Open vehicle catalog, as one SQLite file. Read by wenmar-open/offline beside wenmar-open-data.
