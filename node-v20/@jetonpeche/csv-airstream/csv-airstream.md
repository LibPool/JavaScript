# @jetonpeche/csv-airstream

> 标签: bun, csv, csv-parser, csv-stream, csv-writer, decorators, deno, dto, edge, isomorphic, streaming, typescript, web-streams, zero-dependency

## 简介

Zero-dependency, memory-safe CSV streaming parser & writer using Web Streams. Features TypeScript DTO decorators and a resilient Result pattern.
