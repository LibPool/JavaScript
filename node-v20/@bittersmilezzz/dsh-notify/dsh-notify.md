# @bittersmilezzz/dsh-notify

> 标签: deepseek-harness, desktop, dsh, dsh-plugin, notification, notify

## 简介

DeepSeek Harness 的系统级桌面通知：审批/轮次完成/会话完成/出错提醒，点击通知跳转对应会话；macOS/Windows/Linux 三平台，通知文案跟随界面语言。
