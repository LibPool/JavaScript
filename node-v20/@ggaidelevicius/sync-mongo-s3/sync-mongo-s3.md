# @ggaidelevicius/sync-mongo-s3

> 标签: aws, backup, cli, mongodb, mongodump, mongorestore, restore, s3

## 简介

CLI for dumping a remote MongoDB, restoring it locally, and syncing an S3 bucket into ./s3-bucket.
