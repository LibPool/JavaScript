# operator-lite

> 标签: ai-agents, claude-code, cursor, guardrails, pre-tool-gate, security

## 简介

One command that installs the Operator Lite pre-tool gate for every coding agent on this machine (Claude Code, Cursor, Gemini CLI, Windsurf, Cline, Goose, opencode, Amazon Q).
