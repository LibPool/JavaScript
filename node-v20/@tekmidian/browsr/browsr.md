# @tekmidian/browsr

> 标签: accessibility, automation, browser, browser-extension, browsr-mcp, chrome, dom, mcp, mcp-server

## 简介

Browsr — browser control for agents: real Chrome tabs and DOM via an MV3 extension, a native messaging host and a stdio MCP server. Provider independent.
