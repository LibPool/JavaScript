> 标签: claude, database, graph-database, mcp, natural-language, neo4j

## 简介

Fork of da-okazaki's mcp-neo4j-server with automatic Cypher query syntax fixes. Neo4j MCP server for integrating Neo4j graph database with Claude Desktop through natural language interactions. Includes auto-fixing for common syntax errors (XML fragments,
