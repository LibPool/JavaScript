# @meister-of-manufacturing-it/node-red-contrib-nfcpy-id-with-touchend

> 标签: nfcreader, node-red

## 简介

Read the card ID (Mifare: UID, FeliCa: IDm) with nfcpy (a Python module).
This node can't catch touchend event.
