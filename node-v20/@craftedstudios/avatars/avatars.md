# @craftedstudios/avatars

> 标签: avatar, avatars, cursor, gradient, multiplayer, react, shader, web-component, webgl

## 简介

Live shader avatars from any name, email or user ID, plus presence cursors. One WebGL context for the whole page, a PNG export and a React entry.
