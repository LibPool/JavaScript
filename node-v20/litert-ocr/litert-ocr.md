# litert-ocr

> 标签: litert, markdown, mcp, ocr, offline, paddleocr, pdf, pdf-to-markdown, pp-ocr, tesseract, tesseract.js, text-recognition, webassembly, webgpu

## 简介

OCR in the browser and Node.js with the tesseract.js API: PP-OCRv6-Small on LiteRT.js (WebGPU or WebAssembly), images never leave the device. PDFs, scans and photos to Markdown with tables, JSON or text; a CLI and an MCP server.
