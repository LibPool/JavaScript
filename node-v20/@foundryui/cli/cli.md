# @foundryui/cli

> 标签: accessibility, cli, component-generator, design-system, react, scaffolding, storybook, typescript

## 简介

The ongoing, in-project Foundry CLI. Scaffolds artifacts (components today, more artifact types later) into an existing Foundry project. Not to be confused with create-react-foundry, which scaffolds the project itself.
