# @fat-zebra/sdk

> 标签: JavaScript

## 简介

A modern JavaScript SDK for integrating with [Fat Zebra](https://docs.fatzebra.com/docs/react-sdk-overview) payment services. This SDK enables fast and secure handling of payments.
