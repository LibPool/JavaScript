# @evlon/dsh-bridge

> 标签: JavaScript

## 简介

dsh 数字员工桥接层：把任意 IM 通道（Channel 接口）桥接到 dsh agent 会话。多账号（主 + 分身）、per-room agent、入站注入、出站投递、Owner 授权记忆、秘书编排红线（请示→读数据→私发→等交付→发群）。通道实现与原子工具由 @evlon/dsh-channel-* / @evlon/dsh-tools-channel 提供，本包只做编排。
