# @swarmclawai/markdowntools

> 标签: agents, api-client, claude, cli, cursor, documents, markdown, markdowntools, mcp, mcp-server, model-context-protocol, sync

## 简介

CLI and MCP server for the MarkdownTools.io document API: pull your Markdown documents to a folder, push edits back with conflict-safe writes, and let Claude, Cursor or any MCP client read and write them.
