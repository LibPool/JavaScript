# @matthiaskrijgsman/mat-builder

> 标签: block-builder, drag-and-drop, email-builder, headless, page-builder, pragmatic-drag-and-drop, react, react-email

## 简介

Headless-first React drag-and-drop block builder: document model, undo/redo, Pragmatic drag and drop, and composable editor UI. Ships an email builder preset.
