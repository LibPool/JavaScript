# @aurostack/stacks

> 标签: boilerplate, cli, generator, nestjs, react, scaffold, template, turborepo

## 简介

Scaffold new projects from house templates: a NestJS API, React app or Turborepo monorepo, and Node or Python workers. Subtractive templates plus a zero-dependency generator.
