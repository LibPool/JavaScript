# aimetadatacleaner-mcp

> 标签: exif, gps, mcp, metadata, pdf, privacy, raw, video

## 简介

Remove metadata (GPS, device, dates, AI labels) from video, PDF, RAW and photos from Claude, Cursor and other AI assistants. Uses the AI Metadata Cleaner API.
