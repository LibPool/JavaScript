# @fenecdb/web

> 标签: bm25, database, embedded, hnsw, local-first, sync, vector, wasm

## 简介

fenecdb in the browser: the engine as WebAssembly, and dependency-free ES modules with its query builder, HTTP client and sync layer -- or the client alone, with no engine (@fenecdb/web/client)
