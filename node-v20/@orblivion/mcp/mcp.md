# @orblivion/mcp

> 标签: agents, mcp, model-context-protocol, orbio, orblivion, robinhood-chain, trading

## 简介

An MCP server that lets AI agents trade on Robinhood Chain through Orblivion, safely: dry-run by default, owner caps the model can't widen, and every transaction verified by the Orblivion SDK before it is signed.
