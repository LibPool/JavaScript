# @5straps/runtime

> 标签: 5straps, asynclocalstorage, nitro, runtime, sqlite

## 简介

The runtime primitives Buckle is built on: service lifetimes, async scopes, lifecycle, CLI interaction, logging, SQLite ownership, and Nitro adapters.
