# @appkit/dek-lib

> 标签: JavaScript

## 简介

The DEK board runtime. Provides `BoardProvider`, the component hierarchy (`Board`, `Zone`, `Component`, `Router`), and a set of built-in plugins (base, calendar, clock, home-assistant, weather, desktop, sample).
