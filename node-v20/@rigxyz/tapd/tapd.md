# @rigxyz/tapd

> 标签: daemon, rig, sync, tap, tapd

## 简介

Local daemon for the hosted Tap relay — watches files, hashes content, uploads/downloads objects, applies remote changes. Pairs with @rigxyz/cli for shared-rig sync.
