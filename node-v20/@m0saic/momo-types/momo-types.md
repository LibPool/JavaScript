# @m0saic/momo-types

> 标签: agent, ai, m0saic, protocol, types

## 简介

The vocabulary contract for the m0saic AI-human work-session protocol. Types-mostly (a few pure-function helpers, no runtime baggage) so any package — including published file-format and tooling packages — can share the shape cheaply. The heavy AI runtime
