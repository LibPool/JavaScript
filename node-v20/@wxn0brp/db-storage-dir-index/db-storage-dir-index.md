# @wxn0brp/db-storage-dir-index

> 标签: JavaScript

## 简介

Adds BTree-based indexing to ValtheraDB's directory storage. Sorted index files (`.idx`) allow queries to locate matching `.db` files via binary search instead of scanning all files.
