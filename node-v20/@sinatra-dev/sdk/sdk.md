# @sinatra-dev/sdk

> 标签: ai-coding-agent, api-client, automation, background-agent, coding-agent, github, linear, pull-request, sdk, sinatra, sinatra.dev

## 简介

Official TypeScript client for sinatra.dev, the AI coding agent that turns Linear and GitHub issues into pull requests: start, follow and stop tasks, and delegate issues.

## 官网

- 官网：https://docs.sinatra.dev/docs/api-reference
- 源码仓库：git+https://github.com/sinatra-dev/sinatra-node.git
- npm 页面：https://www.npmjs.com/package/@sinatra-dev/sdk
