# @paymos/mcp

> 标签: agent, claude, crypto, cursor, mcp, model-context-protocol, payments, paymos, stablecoins, usdc, usdt

## 简介

Official Paymos MCP server: a local stdio server that lets coding agents (Claude Code, Cursor, custom LLM bots) build and verify a merchant integration against the Paymos sandbox without reading docs.
