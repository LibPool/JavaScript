# @cavulsqa/m3e

> 标签: material-3, material-design, material-expressive, material-you, shapes, springs, theming

## 简介

Framework-free Material 3 Expressive core: 2025-spec dynamic colour, the 35-shape library with morphing, spring motion tokens, wavy progress geometry, the loading indicator and every system token as CSS.
