# pi-letterbox

> 标签: automation, inbox, mailbox, multi-agent, pi-extension, pi-package, receipt, remote, ssh

## 简介

A letterbox for a running pi session: scripts, cron, CI or another machine over ssh drop a letter, the session reads it at a safe point, and receipts come back (delivered, read, done).
