# @clarkchan/dsh-ds4-service

> 标签: deepseek-harness, ds4, dsh, llm, plugin, server, service-control

## 简介

DeepSeek Harness DS4 服务控制插件：在 Web GUI 里开启/重启/关闭 ds4-server，并可视化配置 start.sh 的全部参数。插件自带 ds4-server 二进制与启动脚本。
