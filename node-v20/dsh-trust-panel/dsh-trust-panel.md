# dsh-trust-panel

> 标签: ai-agents, dashboard, deepseek-harness, dsh-plugin, security

## 简介

One plain-language dashboard for the dsh trust family: every interception, denial, drift and forgotten constraint across the nine channels, translated into sentences a non-security user can act on. Zero LLM calls
