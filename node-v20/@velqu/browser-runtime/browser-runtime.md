# @velqu/browser-runtime

> 标签: JavaScript

## 简介

Velqu Browser-WASM runtime: fetch(Request) -> Promise<Response> over the Rust/WASM kernel (ADR-0037). Browser-only: no Bun.*, node:*, native addons, q-http, or native runtime dependencies.
