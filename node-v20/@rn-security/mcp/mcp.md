# @rn-security/mcp

> 标签: masvs, mcp, model-context-protocol, owasp, react-native, sast, security, static-analysis

## 简介

Model Context Protocol server for the React Native Security Toolkit: exposes deterministic security findings, with severity and OWASP/CWE references, to whichever AI model you already use. No API key, no vendor, no source upload.
