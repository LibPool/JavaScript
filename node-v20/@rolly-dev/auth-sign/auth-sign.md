# @rolly-dev/auth-sign

> 标签: ecgfp5, eip712, goldilocks, plonky2, poseidon2, schnorr, signing, zk-rollup

## 简介

Pure-TypeScript Poseidon2 hashing, Schnorr (EcGFp5) & EIP-712 signing for Rolly ZK-Rollup — bit-exact with the Rust circuit, no WASM required
