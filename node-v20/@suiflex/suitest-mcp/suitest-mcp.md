# @suiflex/suitest-mcp

> 标签: ai-agents, blackbox-testing, claude, cursor, e2e, mcp, model-context-protocol, playwright, qa, suitest, test-automation, testing

## 简介

Suitest MCP server for IDE agents (Claude Code, Cursor, Codex) — generate, run, and publish QA tests from your editor. Includes blackbox DOM testing for any web app: no repo access required, just a URL and test credentials.
