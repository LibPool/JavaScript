# @kkobetskoy/chu

> 标签: ai-context, context, documentation, freshness, mcp

## 简介

Persistent, curated, auto-maintained project context for AI coding agents. Deterministic engine (chu CLI + MCP, no LLM) plus host-agent-driven doc updates on your own subscription.
