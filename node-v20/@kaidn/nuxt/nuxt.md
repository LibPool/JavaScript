# @kaidn/nuxt

> 标签: bot-detection, device-fingerprinting, fraud, fraud-detection, h3, kaidn, nitro, nuxt, nuxt3, nuxt4, vue

## 简介

Kaidn for Nuxt. A composable that collects a device id in the browser, and a server helper that scores it with the IP and device-token cookie read straight off the h3 event.
