# @quran.ws/qvp-react-native

> 标签: mushaf, quran, qvp, react-native, vector

## 简介

React Native wrapper for the QVP vector mushaf engine (Android; iOS TODO). Thin marshalling over the Kotlin library, which is JNI over qvp.h.
