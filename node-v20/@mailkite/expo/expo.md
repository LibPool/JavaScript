# @mailkite/expo

> 标签: email, expo, mailkite, oauth, pkce, react-native, secure-store

## 简介

Expo / React Native adapter for MailKite — wires expo-secure-store + expo-auth-session into @mailkite/client so RN apps get the OAuth (the token is the user) flow with zero re-implemented PKCE.
