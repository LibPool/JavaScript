# @kongjianguan/dsh-model-alias

> 标签: deepseek-harness, dsh, llm, model-alias, plugin

## 简介

Provider-scoped model name mapping for the pi-ai LLM adapter: the harness keeps using the DSH-facing model id (thinking levels, max tokens, context window all keyed by it) while the wire request carries the provider's real model name.
