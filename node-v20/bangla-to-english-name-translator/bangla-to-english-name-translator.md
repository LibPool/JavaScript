# bangla-to-english-name-translator

> 标签: bangla, bangla-to-english, bangladesh, bd, bengali, bengali-to-english, name, names, nid, romanization, romanize, translator, transliteration, typescript

## 简介

Convert Bangla (Bengali) person names to English, e.g. "শাহারিয়ার হৃদয়" -> "Shahariar Hridoy". Phonetic rules plus a dictionary of real-world spellings learned from 2.7 million name records. Zero dependencies.
