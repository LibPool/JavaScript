# @noyrax/documentation-system-plugin

> 标签: ai-agent, code-analysis, docs-as-code, documentation, drift-detection, mcp, noyrax, python, typescript, validation

## 简介

Documentation that never drifts. Automatic documentation generation with validation and drift detection. Generates 5-dimensional documentation structure (modules, symbols, dependencies, ADRs, changes) for codebases.
