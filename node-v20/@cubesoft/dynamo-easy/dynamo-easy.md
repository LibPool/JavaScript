# @cubesoft/dynamo-easy

> 标签: api, aws, dynamo, dynamo client, dynamodb, dynamodb client, expression, expression builder, filter expression, fluent-api, lambda, mapper, objectmapper, orm, serverless, typescript, typescript-decorators, update expression

## 简介

DynamoDB client for NodeJS and browser with a fluent api to build requests. We take care of the type mapping between JS and DynamoDB, customizable trough typescript decorators.
