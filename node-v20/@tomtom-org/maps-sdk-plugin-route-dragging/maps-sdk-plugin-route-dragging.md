# @tomtom-org/maps-sdk-plugin-route-dragging

> 标签: JavaScript

## 简介

Edit a route on a TomTomMap by dragging: move a waypoint's pin or pull a new stop off the route line, and the route re-plans as you drag, its answers shown in order
