# @volter/twin-ai-gateway

> 标签: ai-gateway, ai-sdk, llm, twin, vercel

## 简介

Vercel AI Gateway twin (Protocol 3): its recorded model catalogue, OpenAI's chat completions and the AI SDK's language-model protocol on the World's scenario or the kernel wire's labeled stub (the twin runs no model), with API keys. Built on @volter/world
