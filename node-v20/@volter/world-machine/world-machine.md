# @volter/world-machine

> 标签: firecracker, microvm, snapshot, twin, world

## 简介

The machine as a World service: a Firecracker microVM whose memory and disk snapshots are entries in the World's ledger, so `mark` and `branch --at` take the machine back exactly as they take a twin back.
