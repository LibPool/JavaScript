# @volter/twin-tinybird

> 标签: JavaScript

## 简介

Local Tinybird twin for the real-time analytics surface: Events API ingest (NDJSON/JSON, wait, schema-mismatch quarantine), typed Data Sources (create/list/get/truncate/delete-by-condition/drop), Pipes published from REAL SQL and executed by a determinist
