# @cursorx/cli

> 标签: anthropic, cursor, custom-model, openai, router, unofficial

## 简介

Local installer for CursorX — custom models in Cursor with your own API keys, via a 127.0.0.1 router. Unofficial; not affiliated with Cursor.
