# @fendlemark/ui

> 标签: argo-workflows, console, fendlemark, kubeflow, metaflow, mlflow, mlops, vue, vue3

## 简介

Vue 3 components, design tokens, and lattice client for the Fendlemark ML platform console. Embed Fendlemark views of MLflow, Metaflow, Argo Workflows, and Kubeflow in your own portal.
