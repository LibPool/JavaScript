# @duke-dsh-plugins/whaleharbor-promo

> 标签: JavaScript

## 简介

WhaleHarbor web onboarding: lite-client standalone window (--app), background installer download with mirror fallback + SHA-256 verify, browser task notifications, and a full-version install prompt.
