# @duke-dsh-plugins/dsh-archive-manager

> 标签: archive, deepseek-harness, dsh, plugin, session

## 简介

Archive manager for DeepSeek Harness: DSH < 0.1.7 gets the grouped search/restore/delete panel; DSH >= 0.1.7 adds the delete action missing from the built-in archive management.
