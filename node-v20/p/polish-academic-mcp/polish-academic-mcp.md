Lokalny serwer MCP dla polskich baz naukowych, publicznych i kulturowych (Biblioteka Nauki, GUS, ISAP, SAOS, Wolne Lektury i inne) z kreatorem konfiguracji dla Claude, Cursor, VS Code, LM Studio i innych aplikacji AI.
