# paseo-remote-power

> 标签: agent, homelab, mcp, paseo, paseo-plugin, power, wake-on-lan

## 简介

Wake and status control for remote machines — homelab boxes, GPU workstations — from the Paseo daemon: roster UI plus embedded MCP tools (power_status, power_wake, power_job_status) so agents can wake a host before running work on it.
