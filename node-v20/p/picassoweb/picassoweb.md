# picassoweb

> 标签: css, design-system, mcp, model-context-protocol, picassoweb, playwright, web-scraping, website-analysis, website-cloning

## 简介

PicassoWeb — MCP server that turns any website into a faithful replication kit: design tokens, real assets, animations, layout trees, section clones, screenshots, and pixel-diff verification.
