# pdf2markdown-cli

> 标签: cli, convert, document, markdown, pdf, pdf2markdown, pdf2md

## 简介

CLI for pdf2markdown.io — convert PDF and images to Markdown. Sync (30MB) and async (100MB). Skills for Cursor, Codex, OpenCode.
