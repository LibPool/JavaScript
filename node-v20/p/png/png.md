# png

> 标签: encode, image, picture, png, rgb, rgba

## 简介

A C++ module for node-js that converts an RGB and RGBA buffers to PNG images (in memory).

## 官网

- 源码仓库：http://github.com/pkrumins/node-png.git
- npm 页面：https://www.npmjs.com/package/png
