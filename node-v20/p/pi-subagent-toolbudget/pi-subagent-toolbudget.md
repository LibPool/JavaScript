# pi-subagent-toolbudget

> 标签: agents, ai, budget, cli, guardrail, pi, pi-coding-agent, pi-package, pi-subagents, subagents

## 简介

Companion extension for pi-subagents: caps a spawned sub-agent's tool calls (soft nudge + hard stop) so runaway agents finalize instead of overflowing context. No-op outside sub-agents.
