# postcss-plugin-pxtorem

> 标签: dpx, postcss, px

## 简介

基于postcss-plugin-px2rem 实现的一个postcss插件，用来将css中的dpx 换算成px以及将px转换成rem.保留了postcss-plugin-px2rem的所有配置。
