# pi-quiver

> 标签: cli, docx, fetch, markdown, pdf, pi, pi-coding-agent, pi-package, pptx, xls, xlsx

## 简介

Personal pack of Pi coding-agent extensions: context-safe fetch, doc_to_md PDF/DOCX/PPTX-to-Markdown conversion, session naming, a themed ASCII startup header, Opus 4.8 fast mode, and a provider-stall watchdog.
