# posfel-sync

> 标签: catalogo, checkout, ecommerce, el-salvador, facturacion, fel, guatemala, pos, posfel, sync

## 简介

CLI oficial de POSFEL para sincronizar el catálogo de tu web o ecommerce propio (productos, variantes, precios e imágenes) con POSFEL — checkout alojado, stock y factura FEL administrados en POSFEL.

## 官网

- 官网：https://posfel.com/integraciones/guia
- 源码仓库：git+https://github.com/YENERGT/POS-.git
- npm 页面：https://www.npmjs.com/package/posfel-sync
