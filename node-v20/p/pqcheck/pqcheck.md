# pqcheck

> 标签: ai-coder, ai-coder-mode, aider, blast-radius, ci, claude-code, copilot, cursor, deploy-check, deploy-gate, deploy-guard, harvest-now-decrypt-later, hndl, post-quantum, pqc, quantum, scanner, security, ship-decision, ssl, tls

## 简介

Deploy gate for AI-coded web apps. `pqcheck deploy-check --ai` returns ship_decision=pass|review|block for Claude Code / Cursor / Copilot / Aider to gate deploys before they ship. Anonymous, no signup, free for first use.
