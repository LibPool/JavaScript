# poe-stat-descriptions

> 标签: JavaScript

## 简介

var desc = require("poe-stat-descriptions"); desc.getDescription([stat(s)]);<br> +30% to elemental damage<br> desc.getDescription([stat(s)], noValue=true);<br> +(20-30)% to elemental damage<br> stats must be of the same description
