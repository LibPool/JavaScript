# prettymd2pdf

> 标签: cli, converter, markdown, pdf, puppeteer

## 简介

Convert Markdown into a beautifully designed PDF — cover page, table of contents, callout boxes, terminal-style code blocks, styled tables. CLI and local web UI, same renderer.
