# promptcanary

> 标签: ai, anthropic, assertions, gemini, google, jest, llm, llm-testing, openai, prompt-testing, semantic-similarity, testing, vitest

## 简介

Test your LLM prompts like you test your code. Assertions, semantic similarity, and multi-provider testing for Vitest, Jest, and any test runner.
