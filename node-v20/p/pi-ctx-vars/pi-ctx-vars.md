# pi-ctx-vars

> 标签: agent, compaction, context-management, llm, memory, pi, pi-extension, pi-package, sqlite

## 简介

Variable-based context management for pi: realtime variable population, agent-controlled compaction (pin/archive/drop), and a persistent SQLite store with SQL retrieval.
