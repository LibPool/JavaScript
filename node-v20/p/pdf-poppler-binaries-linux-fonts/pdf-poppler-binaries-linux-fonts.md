# pdf-poppler-binaries-linux-fonts

> 标签: aws, binaries, fontconfig, fonts, lambda, linux, pdf, pdf2image, poppler, serverless

## 简介

Linux binaries for pdf-poppler with bundled fonts. Includes Poppler utilities, fontconfig, and Liberation Sans fonts for environments without system fonts (Lambda, containers).
