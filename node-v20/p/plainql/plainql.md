# plainql

> 标签: ai, ai-agent, anthropic, claude, database, guardrails, llm, mysql, natural language, policy, postgres, security, sql, sqlite, text-to-sql

## 简介

Policy-enforced natural-language SQL for Node.js: an LLM writes the query, a 4-layer validator decides what may run.
