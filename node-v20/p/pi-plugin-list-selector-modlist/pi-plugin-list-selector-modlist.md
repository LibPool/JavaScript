# pi-plugin-list-selector-modlist

> 标签: extension, modlist, packages, pi, pi-extension, pi-package, profile, selector, settings, tools

## 简介

Named Pi profiles (modlists) for switching active tools and extension packages. Tool changes apply instantly; extension-package changes show a diff, require confirmation, update settings.json, and reload Pi resources.
