# pi-model-sync

> 标签: catalog, discovery, extension, models, pi, pi-coding-agent, pi-extension, pi-package, sync

## 简介

Keep Pi models fresh: /model-sync discovers live provider catalogs, enriches from models.dev, and writes missing models to models.json.
