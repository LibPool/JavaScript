# pi-tsgw

> 标签: gateway, models, pi, pi-package, tsgw

## 简介

Pi extension for the TOSSP AIH gateway: per-vendor model catalog and thinking operations for openai-completions, openai-responses, anthropic-messages, and google-generative-ai wire protocols.
