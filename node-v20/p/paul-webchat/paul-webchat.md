# paul-webchat

> 标签: JavaScript

## 简介

整合 [BotFramework-WebChat](https://github.com/microsoft/BotFramework-WebChat) 的 `webchat-es5.js` 並客製其它功能，讓大家可以輕鬆將 webchat 功能整合到現有的 Web Application 之中。
