# presign-guard-wallet-mcp

> 标签: agents, budget, claude, cursor, human-in-the-loop, mcp, model-context-protocol, presign, security, solana, spending-limits, telegram, usdc, wallet, x402

## 简介

An MCP server that gives AI agents (Claude, Cursor, …) a wallet with spending limits: pay x402 and MPP APIs (USDC on Base, USDC.e on Tempo incl. sessions, RLUSD on the XRP Ledger, USDC on Solana and Algorand) and send USDC, every payment checked by presig
