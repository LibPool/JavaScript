# parity-mcp

> 标签: anticheat, claude, fivem, mcp, model-context-protocol, moderation, parity

## 简介

Model Context Protocol server for the Parity Anti-Cheat REST API — lets an AI assistant manage bans, players, whitelist, team, analytics and Custom API Rules for your FiveM server.
