# paperclip-adapter-hermes-control

> 标签: hermes, hermes-agent, nous-research, paperclip, paperclip-adapter

## 简介

Hermes Control adapter for Paperclip: the agent name picks its Hermes instance/profile; Provider and Model menus list what Hermes knows; skills assigned in Paperclip are linked into that profile's skills folder. Drop-in override of the built-in hermes_loc
