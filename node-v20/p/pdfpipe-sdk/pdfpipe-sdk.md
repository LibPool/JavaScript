# pdfpipe-sdk

> 标签: document-extraction, headless-browser, pdf, pdf-api, pdf-attachment, pdf-converter, pdf-download, pdf-parser, pdf-scraper, pdf-to-base64, pdf-to-image, pdf-to-json, pdf-to-markdown, pdf-to-text, pdfpipe, structured-data

## 简介

Official Node.js SDK for PDFPipe — convert any PDF URL to JSON, text, markdown, and images. Handles inline PDFs, auto-download attachments, redirects, and token-gated files
