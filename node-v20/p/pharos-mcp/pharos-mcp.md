# pharos-mcp

> 标签: ai-tools, anthropic, beam, burrito, claude, claude-code, code-intelligence, cursor, developer-tools, erlang, gleam, gopls, haskell-language-server, language-server-protocol, lsp, lsp-bridge, mcp, mcp-server, metals, model-context-protocol, pyright, rust-analyzer, tsserver

## 简介

Headless LSP-MCP bridge for AI agents. Hands rust-analyzer, gopls, tsserver, pyright, jdtls and 19 more language servers to any MCP-aware agent (Claude Code, Cursor, ChatGPT Desktop). Single binary, 23 languages.
