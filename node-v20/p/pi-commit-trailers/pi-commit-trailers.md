# pi-commit-trailers

> 标签: co-authored-by, commit, git, pi, pi-extension, pi-package, pi-session, trailers

## 简介

A Pi extension that appends Co-Authored-By, Generated-By, and Pi-Session git trailers to every git commit — robustly, even under command chaining.
