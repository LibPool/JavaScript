# pointy-feedback-cli

> 标签: annotation, bug-tracking, cdn, feedback, installer, pointy, screenshot, visual-feedback, visual-qa, widget

## 简介

One-command Pointy installation for 20+ frameworks. Auto-detects React, Vue, Next.js, Django, Laravel, WordPress, and more. Auto-creates AND configures CSP at server level. Zero manual configuration. 100% test pass rate.
