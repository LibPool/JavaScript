# peeper-sv

> 标签: component, gallery, preview, storybook, svelte, svelte5, sveltekit

## 简介

Zero-config Svelte 5 component gallery. Run npx peeper-sv inside any SvelteKit project to browse every component with auto-generated prop controls.
