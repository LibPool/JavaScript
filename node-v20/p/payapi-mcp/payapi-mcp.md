# payapi-mcp

> 标签: agentic-commerce, ai-agents, mcp, model-context-protocol, property-api, uk-data, x402

## 简介

MCP server for PayAPI Market UK data APIs - property, finance, vehicle, company, weather - callable by AI agents via x402 micropayments on Base.

## 官网

- 官网：https://payapi.market
- 源码仓库：git+https://github.com/chetparker/payapi-mcp.git
- npm 页面：https://www.npmjs.com/package/payapi-mcp
