# pairharbor-mcp

> 标签: agents, claude, mcp, model-context-protocol, pairharbor

## 简介

MCP server for PairHarbor: your skill cloud, workspaces, projects and tasks as tools for Claude Code, Claude Desktop and other MCP clients. Ships the reference PM planner and a worker loop that runs your assigned tasks on your own machine.
