# ptm-cli

> 标签: cli, github, mamager, template, 模板初始化, 模板删除, 模板添加, 模板管理, 模板编辑, 码云（Gitee）

## 简介

一款对项目模板/项目进行管理的脚手架工具，具有添加模板/项目、编辑模板/项目、删除模板/项目、查看模板/项目以及下载项目和根据模板初始化项目等功能!
