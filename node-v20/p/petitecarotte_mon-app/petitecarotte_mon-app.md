# petitecarotte_mon-app

> 标签: JavaScript

## 简介

**MonModule** est un module Node.js léger permettant de simplifier la gestion des fichiers JSON. Il offre des fonctions pour lire, écrire et mettre à jour facilement des fichiers de données.
