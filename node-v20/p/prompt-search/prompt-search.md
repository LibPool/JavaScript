# prompt-search

> 标签: diamond-search, nlp, prompt-search, search-parser

## 简介

Free-text prompt -> diamond search filter parser (tokenizer, fuzzy match, resolver, engine). Ported unchanged from srk-one-web's Angular prompt-search feature.
