# ppcop-webpack-sourcemap-plugin

> 标签: JavaScript

## 简介

本插件为ppcop定制的SourceMapDevToolPlugin，负责生成指定的sourcemap，供上传。与 ppcop-webpack-sourcemap-upload-plugin 一起使用

## 官网

- npm 页面：https://www.npmjs.com/package/ppcop-webpack-sourcemap-plugin

- 1.0.0

## 获取地址

- npm registry：https://registry.npmjs.org/ppcop-webpack-sourcemap-plugin
