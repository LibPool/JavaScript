# perfai-cloud-mcp

> 标签: mcp, model-context-protocol, perfai, security, vulnerability-scanning

## 简介

Standalone MCP client for the hosted PerfAI cloud API — register an app by URL, run a security test, pull findings, and get fix prompts from Claude Code, Cursor, or any MCP client.
