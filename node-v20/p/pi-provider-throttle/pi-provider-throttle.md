# pi-provider-throttle

> 标签: 429, free-tier, llm, nim, nvidia, pacing, pi, pi-extension, pi-package, provider, rate-limit, rate-limiting, rpm, throttle, throttling, too-many-requests

## 简介

Per-provider LLM request throttling for the Pi coding agent — persistent seconds-between-calls pacing that prevents 429 Too Many Requests on rate-limited providers (e.g. NVIDIA NIM 40 RPM free tiers) while leaving unaffected providers untouched.
