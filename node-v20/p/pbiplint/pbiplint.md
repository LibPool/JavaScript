# pbiplint

> 标签: best-practices, cli, linter, pbip, power-bi, sarif, semantic-model, tmdl

## 简介

Lint Power BI semantic models (TMDL) for best-practice violations, with text, JSON, SARIF, and Markdown output. Nothing is uploaded.
