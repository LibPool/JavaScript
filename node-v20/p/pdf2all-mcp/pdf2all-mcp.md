# pdf2all-mcp

> 标签: converter, docx, excel, jpg, mcp, pdf, ppt

## 简介

pdf2all全能转换器 - 一个强大的 MCP 服务器，支持将 PDF 转换为 Word、Excel (带 OCR)、PPT 和图片，并支持云端存储和 URL 处理。
