# paperpony

> 标签: api, html-to-pdf, invoice, paperpony, pdf, pdf-generation, sdk, typescript

## 简介

Official JavaScript and TypeScript SDK for the PaperPony API: render PDFs from HTML or stored templates, and read the jobs they produce.
