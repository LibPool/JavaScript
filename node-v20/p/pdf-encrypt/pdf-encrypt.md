# pdf-encrypt

> 标签: JavaScript

## 简介

El paquete `pdf-encrypt` es una biblioteca para encriptar archivos PDF utilizando cifrado AES. Proporciona funciones sencillas y flexibles para proteger tus archivos PDF con contraseña.
