# payload-security

> 标签: access-control, ai-agents, auditor, cms, data-exposure, devsecops, graphql, headless-cms, payload, payloadcms, security, security-audit

## 简介

Audit any Payload CMS instance for collections readable without auth, GraphQL introspection, user/login enumeration and field-level leaks (apiKey, email, hash) — and PROVE each leak live with an anonymous probe. No admin token needed for the keyless scan.
