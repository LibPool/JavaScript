# pi-jev-task-router

> 标签: jev, llm-routing, model-routing, pi, pi-extension, pi-package

## 简介

Per-prompt model routing for the Pi coding agent: classify each prompt with Jev (TypeSafe System One), map it to a model tier, and switch models before the turn runs.
