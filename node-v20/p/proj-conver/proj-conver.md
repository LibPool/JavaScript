# proj-conver

> 标签: automatic build, project conver, project process, 自动构建, 项目处理, 项目转换

## 简介

proj-conver 可用于自动化构建项目，它可以从git自动拉取更新项目，对项目文件做任务转换，构建项目，然后将项目中的指定部分拷贝到指定位置
