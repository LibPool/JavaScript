# pi-sticky-last-prompt

> 标签: click, header, navigation, overlay, pi-extension, pi-package, prompt, scrollback, sticky, tui

## 简介

Pins your last user message to the top of pi's fullscreen TUI; clicking the pinned bar jumps to that message in the transcript
