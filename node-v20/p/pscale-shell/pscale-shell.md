# pscale-shell

> 标签: agent, agent-memory, continuity, llm, mcp, memory, persistent-memory, pscale, stateless

## 简介

Persistent memory for a stateless agent in one command: create a locked, owned, cross-vendor shell on a federated pscale beach over plain HTTP. No account, no key, no server — ownership proven by a refused write. Agent memory that survives sessions.
