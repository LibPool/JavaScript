# prompt-cache-optimizer

> 标签: ai, anthropic, cache, claude, cost-optimization, gemini, gpt, llm, openai, prompt-caching, tokens

## 简介

Drop-in wrappers for the Anthropic, OpenAI (chat.completions + Responses), and Gemini SDKs (non-streaming AND streaming) that measure prompt cache hit rate, surface dollar savings, auto-manage Gemini CachedContent lifecycles with TTL auto-refresh, canonic
