# plopino

> 标签: ai-agents, claude, claude-code, html, mcp, mcp-server, model-context-protocol, publish, share, static-hosting, url

## 简介

MCP server: publish a page, a document, a file, or a folder to Plopino and get a public URL — documents render as readable pages.
