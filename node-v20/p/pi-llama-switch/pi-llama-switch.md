# pi-llama-switch

> 标签: gpu, llama, llama-cpp, local-llm, model-switch, pi, pi-extension, pi-package, vllm, vram

## 简介

Restart llama-server with different model configurations. For single-model setups where models need different flags (context size, vision projector, sampling params).
