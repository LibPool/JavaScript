# pixelbolt

> 标签: agent-skills, ai-agents, apng, cli, dithering, game-assets, gamedev, gif, image-sequence, mcp, mcp-server, model-context-protocol, particle-effects, pixel-art, pixel-font, pixelart, png, sprite-animation, sprite-sheet, sprites, texture-atlas, video, zero-dependencies

## 简介

Agent-first pixel art and animation toolkit with a CLI, MCP server and local studio. Deterministic JSON recipes to PNG, APNG and sprite atlases; zero dependencies.
