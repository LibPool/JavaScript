# paypreflight

> 标签: compliance, iban, iso20022, mcp, pain.001, payments, sepa, validation, vat, vies

## 简介

Offline pre-flight checks for EU payment runs and VAT data: audit a CSV, JSON or pain.001 batch before you send it. CLI + MCP server + browser tool, zero dependencies.
