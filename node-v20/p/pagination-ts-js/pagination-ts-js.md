# pagination-ts-js

> 标签: Next JS, React JS, TypeScript

## 简介

pagination-ts-js is a lightweight pagination component designed for React and Next.js, with TypeScript support. Easily integrate and customize pagination for efficient navigation of large datasets. No additional dependencies required. Simplify pagination
