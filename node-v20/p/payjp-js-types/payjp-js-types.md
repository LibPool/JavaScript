# payjp-js-types

> 标签: JavaScript

## 简介

このライブラリは、TypeScriptでPAY.JPのJavaScriptライブラリを利用するための型定義を提供します。このリポジトリは [nemuvski/typedef-payjp-js](https://github.com/nemuvski/typedef-payjp-js) のフォークです。
