# payment-intelligence-mcp

> 标签: bic, camt, cbpr, fintech, iban, iso20022, mcp, model-context-protocol, pacs, payments, privacy, settlement-instructions, ssi, swift

## 简介

Offline ISO 20022 payment tools for AI assistants: explain pacs/camt messages in plain language, scrub customer data before sharing, check CBPR+ readiness, validate SSI files and check payments against your own SSIs, validate and build IBANs, check BIC sy
