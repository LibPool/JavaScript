# pi-dev-flow

> 标签: changelog, dev-flow, extension, git-worktree, guardrails, pi, pi-coding-agent, pi-package, plan, release, semver, spec, workflow

## 简介

Enforced feature workflow for Pi: plan → implement → pre-release → release, gated checkpoints, self-improvement reflections, one git worktree per feature, changelog + publish as part of the release
