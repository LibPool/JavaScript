# pi-feishu-router

> 标签: bot, chatbot, coding-agent, feishu, lark, pi, router

## 简介

用飞书机器人远控本机 pi coding agent（支持多项目管理）。可作为库嵌入 Electron / Node 应用，也可独立运行。
