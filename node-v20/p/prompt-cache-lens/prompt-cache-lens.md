# prompt-cache-lens

> 标签: ai-agent, anthropic, cli, cost-optimizer, deepseek, devtools, llm, openai, prompt-cache, prompt-caching

## 简介

LLM Prompt Cache Invalidation & Cost Leak Detector. Diffs consecutive LLM prompts, pinpoints exact cache break points, identifies root causes (timestamps, tool permutations, whitespace drift), and calculates wasted API dollars.
