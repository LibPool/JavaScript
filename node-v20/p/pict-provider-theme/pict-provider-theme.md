# pict-provider-theme

> 标签: JavaScript

## 简介

Pict provider for runtime theme management — registers theme bundles (token maps + CSS + SVG + image assets), applies them by injecting CSS custom properties into a single <style> element, supports dark/light/system modes via a class on <html>, and expose
