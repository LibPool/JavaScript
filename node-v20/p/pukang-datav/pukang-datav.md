# pukang-datav

> 标签: component-library, dashboard, datav, large-screen, pukang-datav, visualization, vue, vue3

## 简介

`pukang-datav` 是一套基于 Vue 3 的可视化大屏组件库，面向数据驾驶舱、指挥中心、运营监控、地图态势、设备看板等场景。
