# prompt-security-kit

> 标签: agent, chinese, guardrails, langchain, llm, mcp, pii, prompt-injection, redaction, sdk, security, typescript

## 简介

Lightweight, Chinese-first prompt-injection detection & PII redaction SDK. Inline in agent data flows (LangChain-JS, MCP, any TS runtime). Zero runtime deps, offline, fail-open.
