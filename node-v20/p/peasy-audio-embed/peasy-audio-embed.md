# peasy-audio-embed

> 标签: audio, compress, convert, embed, flac, mp3, peasy, peasyaudio.com, shadow-dom, wav, widget, zero-dependencies

## 简介

Embed PeasyAudio widgets on any website. Lightweight (<8KB gzipped), zero dependencies, Shadow DOM isolation, 3 themes.
