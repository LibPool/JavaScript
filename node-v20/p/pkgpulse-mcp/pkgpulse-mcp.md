# pkgpulse-mcp

> 标签: base, coding-agents, dependencies, mcp, mcp-server, micropayments, modelcontextprotocol, npm, package-health, security, supply-chain, typosquat, usdc, x402

## 简介

MCP server for pkgpulse: dependency intelligence for AI coding agents via x402 (USDC on Base). npm package health scores, typosquat/hallucination checks, and whole-package.json dependency audits — pay per call, no API key.
