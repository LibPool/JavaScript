# paperclip-pixels-common

> 标签: contract, dto, paperclip, pixel-agents, schema, zod

## 简介

Neutral paperclip-pixels wire contract package: DTOs, Zod validation, operation ids, error codes, schemaVersion compatibility rules, and fixture builders shared by the Paperclip plugin and the Pixel Agents plugin. Schemas only — imports no other package.
