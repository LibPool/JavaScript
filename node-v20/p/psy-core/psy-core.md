> 标签: ai-agent, anthropic, audit, audit-log, gbrain, governance, hermes, hermes-agent, langchain, langgraph, letta, llm, mastra, mem0, memory, observability, tamper-evident

## 简介

Tamper-evident audit log for AI agent memory operations. Adapters for Anthropic Memory, Letta, Mastra, Mem0, LangChain, LangGraph, GBrain, and Hermes Agent (via psy-core-hermes).
