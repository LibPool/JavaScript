# proactive-gate

> 标签: agent-guardrails, agents, ai, ai-sdk, budget, claude-code, conformance, consent, guardrails, langchain, llm, mastra, notification-budget, notifications, openai-agents, policy, presets, proactive, proactive-ai, python, quiet-hours, rate-limit

## 简介

Decide whether a proactive AI agent may reach a user right now, and log why not. Ordered checks as code or JSON, a conformance spec, presets for platform and legal limits, adapters for AI SDK, Mastra, LangChain and OpenAI Agents, and a Python sibling.
