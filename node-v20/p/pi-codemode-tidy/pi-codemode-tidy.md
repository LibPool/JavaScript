# pi-codemode-tidy

> 标签: codemode, extension, pi, pi-package, tool-rendering, transcript, tui

## 简介

Tidy transcript rendering for Pi's codemode tool: summarized nested calls, readable JSON output, and always-visible script errors — Ctrl+O expands the original view
