# pure-js-sftp

> 标签: cross-platform, docker, drop-in-replacement, file-transfer, lambda, modern-ssh-servers, no-native-dependencies, pure-javascript, revolutionary-fix, rsa-sha2, serverless, sftp, ssh, ssh-key-compatibility, ssh2-sftp-client, ssh2-streams, typescript, vscode-compatible

## 简介

A pure JavaScript SFTP client with revolutionary RSA-SHA2 compatibility fixes. Zero native dependencies, built on ssh2-streams with 100% SSH key support.
