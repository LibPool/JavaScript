# pi-kimi-keepalive

> 标签: cache, keepalive, kimi, moonshot, pi-extension, pi-package, prompt-cache

## 简介

Prompt-cache keepalive for Kimi (kimi-coding) sessions in the Pi coding agent. Replays the last real provider request while idle so the automatic prefix cache never expires.
