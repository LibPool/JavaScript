# playcover-skills

> 标签: agent, ai, claude, cli, ios, ipa, llm, macos, playcover, skill, trae

## 简介

Agent Skill package that documents PlayCover's headless CLI — install/uninstall/launch/sign iOS apps, manage keymaps, sources, settings, dylibs, and global config from the terminal.
