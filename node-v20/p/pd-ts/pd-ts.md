# pd-ts

> 标签: JavaScript

## 简介

- `yarn pd-ts-init` - `yarn pd-ts-start`     - **params**:        - `[0]` main file path eg. `pd-ts-start dist_dev/index.js`       - `-m, --mode`: enum nodemon       - `-s, --start`: npm start script **(note use -m or -s)**
