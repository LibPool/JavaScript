# pir-mcp

> 标签: agents, hyprland, mcp, mcp-server, model-context-protocol, motion-detection, privacy, screen, wayland

## 简介

A motion sensor for AI agents: MCP server that reports when a screen region changes or goes still. Scores only, never pixels.
