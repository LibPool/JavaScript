# plus-dialog

> 标签: dialog, plus-dialog, plus-dialog-main, showDialog

## 简介

一个弹出式对话框，可以传入消息显示，也可以在网页中写好固定的标签，可用于显示登录或注册页面或者查询某项数据显示详细内容。
