# phaser3-typescript-boilerplate

> 标签: JavaScript

## 简介

Contains 3 scenes: - **Boot** (for minimal file loading for files needed in Preload) - **Preload** contains a bespoke driven by the `manifest.json` - **Game** primary game scene
