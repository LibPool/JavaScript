# projectstore

> 标签: adr, agentic, ai-agents, claude-code, codex, engineering-process, epics, kanban, knowledge-base, markdown, obsidian, project-management, stories

## 简介

Your agent runs the project through a verified loop: task → artifact (ADR / spec / epic / story) → adversarial critic → backlog → planner → reviewer → done. Plain markdown in git — any model can pick the project up tomorrow.
