# procpipe

> 标签: cli, devops, monitor, notifications, process, pty, telegram, terminal, watcher

## 简介

Terminal process watcher with Telegram notifications. Spawn any long-running command and walk away — ProcPipe watches it and messages you when it completes or needs input.
