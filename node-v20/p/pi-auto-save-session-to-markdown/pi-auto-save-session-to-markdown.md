# pi-auto-save-session-to-markdown

> 标签: archive, auto-save, conversation, export, markdown, pi, pi-coding-agent, pi-extension, pi-package, session

## 简介

Pi extension that automatically saves each completed conversation turn as a markdown file with YAML frontmatter, one file per session-tree branch.
