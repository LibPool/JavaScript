# polymer-icons-extractor

> 标签: av-icons, converter, extractor, generator, icons, iron-icons, polymer, svg, tool

## 简介

A simple tool that extracts Polymer Icons (SVG) from any type(e.g 'av or hardware') and saves each icon in your local directory making it a standalone svg file.
