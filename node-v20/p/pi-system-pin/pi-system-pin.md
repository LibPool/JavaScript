# pi-system-pin

> 标签: ai-agents, coding-agent, kv-cache, llm, pi, pi-coding-agent, pi-extension, pi-package, prompt-cache, prompt-caching, system-prompt

## 简介

Stops pi re-reading your whole conversation when an extension's message starts a run: keeps the system block byte-identical so prefix caches hold. A stopgap for pi#5581; uninstall it once pi fixes that issue.
