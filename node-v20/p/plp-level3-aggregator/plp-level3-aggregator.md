# plp-level3-aggregator

> 标签: JavaScript

## 简介

Aggregates L3 Categories using a SEO L3 sort order to improve SLA business requirements. This module uses a cutting edge tech (Typescript, async) to meet the requirement for both Mobile App and Desktop platforms.
