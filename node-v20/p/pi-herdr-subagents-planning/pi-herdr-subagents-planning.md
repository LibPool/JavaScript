# pi-herdr-subagents-planning

> 标签: domain-modeling, grilling, herdr, pi, pi-package, plan, planner, reviewer, scout, subagents, worker

## 简介

Single pi package for the entire /plan grill-and-plan workflow — one interactive planner does grilling + domain-modeling → pointer plan + todos → sequential workers → reviewer, all on herdr subagents.
