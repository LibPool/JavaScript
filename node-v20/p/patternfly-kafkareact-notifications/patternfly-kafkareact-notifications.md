# patternfly-kafkareact-notifications

> 标签: JavaScript

## 简介

This library is custom react context for handling real time messaging over secured and unsecured `websocket` protocol between `ReactJS` and  any given ` Apache Kafka` instances. For it to function its advised to use <a href="https://www.patternfly.org/">
