# perfume-picks-mcp

> 标签: cologne, dupes, fragrance, mcp, model-context-protocol, perfume, perfume-picks, scent

## 简介

MCP server exposing the Perfume Picks fragrance database (13,000+ scents) as read-only tools for AI assistants. Search the catalog, find dupes, compare fragrances, and get wear suggestions — with citation-ready attribution.
