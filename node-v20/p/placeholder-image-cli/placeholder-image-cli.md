# placeholder-image-cli

> 标签: cli, generator, image, mock, placeholder, sharp, test-image, tool

## 简介

一个轻量级、功能丰富的命令行占位图片生成工具，支持 PNG/JPG/SVG/WebP 格式、自定义尺寸、颜色、文字及圆角。
