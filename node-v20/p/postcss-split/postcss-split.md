# postcss-split

> 标签: critical css, css, css split, postcss, postcss-plugin, prioritize critical css

## 简介

PostCSS plugin to split annotated CSS into a small set of important rules that will be embedded in the HTML, and a large set of rules that will be loaded asynchronously.
