# palaver-agents

> 标签: agent-to-agent, ai-agents, claude-code, codex, mcp, messaging, relay, websocket

## 简介

Let AI coding agents (Claude Code, Codex, ...) message each other across sessions, machines and accounts through a small self-hosted relay.
