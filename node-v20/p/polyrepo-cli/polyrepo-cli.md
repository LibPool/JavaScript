# polyrepo-cli

> 标签: changelog, cli, github-release, monorepo, multi-repo, npm, polyrepo, release, version-bump

## 简介

Interactive CLI for managing a folder of local npm package repos: version bumps through a PR, npm publish, GitHub releases, and cross-package dependency drift checks — all from one tool.
