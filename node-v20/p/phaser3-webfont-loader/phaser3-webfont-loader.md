# phaser3-webfont-loader

> 标签: JavaScript

## 简介

A webfont loader for Phaser 3 that uses CSS @font-face to download the font and FontFaceSet to detect the load.

## 官网

- npm 页面：https://www.npmjs.com/package/phaser3-webfont-loader

- 1.0.0
