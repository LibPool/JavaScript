# pi-multivision

> 标签: deepseek, extension, glm, image, multimodal, pi, pi-coding-agent, pi-package, qwen, step, vision

## 简介

Give text-only pi models vision — a native vision tool with a bundled vision script and a multi-backend model chain (auto-fallback, timeout, retry). Configure models via .env, JSON, or a custom script.
