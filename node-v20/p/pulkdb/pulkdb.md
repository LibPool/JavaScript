> 标签: croxydb, database, db, dot-notation, encryption, firebase, firestore, flat-file, json, json-database, jsondb, key-value, kv, local-database, local-storage, lowdb, migration, mongodb, mongoose, nosql, pulkadot, pulkdb, quick.db, quickdb, ttl, typescript, yaml, yamldb

## 简介

A fast, type-safe JSON/YAML database for Node.js with a multi-file path system, dot-notation, TTL, encryption, events, and one-line migration to/from MongoDB (Mongoose), Firebase, QuickDB, croxydb, lowdb and more.
