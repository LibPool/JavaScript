# pinnote-awareness

> 标签: awareness, deveco, opencode, pinnote, plugin, tui

## 简介

Pinnote AI awareness plugin for DevEcoCode - modular architecture (classify/gate/sniff/ccg/recommend/preInject), smart CCG (category counting + sub-agent whitelist + progressive block), edit-refs gate, check-not-build gate, conditional recommend, session
