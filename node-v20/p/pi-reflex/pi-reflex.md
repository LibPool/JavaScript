# pi-reflex

> 标签: calibration, classification, conformal, decision-engine, guardrails, jev, laya, llm-router, onnx, pi-package, reflex, system1, von

## 简介

TypeScript-native System 1 decision engine: non-autoregressive choice/score/noul decisions with calibrated probabilities, conformal guarantees, multilingual routing. A Jev-style, laya-compatible open alternative (not affiliated with TypeSafe). Zero Python
