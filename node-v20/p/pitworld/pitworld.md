# pitworld

> 标签: cli, dns, mcp, mcp server, model context protocol, moshpit, private search, search, tui, web search mcp

## 简介

pit.world MCP server: private web search and Moshpit name lookups for AI agents (stdio, no API key). Also a web app, API, CLI and TUI.
