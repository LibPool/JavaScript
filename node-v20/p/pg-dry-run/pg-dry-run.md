# pg-dry-run

> 标签: agent, approval, diff, dry-run, mcp, postgres, postgresql, preview, safety, sql

## 简介

See exactly which rows a Postgres INSERT, UPDATE or DELETE would write, before it runs. Then apply only those rows, and only if none of them have changed.
