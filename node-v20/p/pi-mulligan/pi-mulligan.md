# pi-mulligan

> 标签: agents, ai, cli, context, context-window, pi, pi-coding-agent, pi-extension, pi-package, retry

## 简介

Autonomous, token-cheap context self-rewind for a Pi coding agent — shed context produced by mistake and redo a turn with a self-authored note.
