# performant-array-to-tree

> 标签: algorithms, ancestors, array, array to tree, array-helper, array-manipulations, child, children, collection, data-structures, datastructures, descendants, list, list to tree, navigation, nested, parent, pointer, traverse, tree, tree-structure, unflatten, util

## 简介

Converts an array of items with ids and parent ids to a nested tree in a performant `O(n)` way. Runs in browsers and node.
