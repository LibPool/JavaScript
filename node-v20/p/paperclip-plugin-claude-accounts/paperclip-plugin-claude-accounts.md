# paperclip-plugin-claude-accounts

> 标签: claude, paperclip, paperclip-plugin

## 简介

Per-user Claude accounts for Paperclip: each member signs in to Claude from the browser, picks which agents use it, and it stays signed in. No shell, no re-auth.
