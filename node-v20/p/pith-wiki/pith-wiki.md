# pith-wiki

> 标签: claude-code, cli, deepseek, hydration, ink, knowledge-base, llm, markdown, pith, wiki

## 简介

Karpathy-style LLM knowledge base CLI: hydrate raw docs into dense Markdown entries; retrieve by keyword + link traversal. No embeddings, no vector DB, files all the way down.
