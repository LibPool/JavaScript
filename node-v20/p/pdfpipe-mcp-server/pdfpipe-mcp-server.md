# pdfpipe-mcp-server

> 标签: ai-agents, html-to-pdf, mcp, pdf, pdf-generation, pdfpipe

## 简介

MCP server for PDFPipe. Generate PDF documents (invoices, reports, certificates) from HTML or a URL in one tool call.
