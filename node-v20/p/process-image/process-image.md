# process-image

> 标签: JavaScript

## 简介

基于 [Squoosh](https://github.com/GoogleChromeLabs/squoosh) 封装, 内置 `pica` 通过 `resize` 传参， `url` 支持 `File` 对象 或者 图片链接,
