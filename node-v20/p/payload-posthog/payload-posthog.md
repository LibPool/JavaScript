# payload-posthog

> 标签: analytics, cms, feature-flags, payload, payload-plugin, payloadcms, posthog, session-replay

## 简介

Full-featured, fully customizable PostHog integration for Payload CMS — server-side capture, identify, feature flags, error tracking, session replay/surveys in the admin panel, reverse proxy, webhooks, and group analytics.
