# perly-pay-mcp

> 标签: bitcoin, claude, codex, crypto, cursor, mcp, model-context-protocol, non-custodial, payments, perly, perly-pay, usdc, usdt

## 简介

Perly Pay for AI coding assistants: a local MCP server (stdio) to sell for crypto from your editor — products, prices, payment links, invoices and test payments, straight to your own wallet.
