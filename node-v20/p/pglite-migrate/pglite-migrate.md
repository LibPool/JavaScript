# pglite-migrate

> 标签: database, embedded, migration, pg_upgrade, pglite, postgres, postgresql, upgrade, wasm

## 简介

Migrate PGlite data across PostgreSQL major versions (e.g. PG17 -> PG18) by transferring data between two PGlite instances, without native binaries or pg_upgrade.
