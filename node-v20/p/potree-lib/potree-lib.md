# potree-lib

> 标签: 3d, copc, ept, headless, las, laz, lidar, octree, point-cloud, pointcloud, potree, three, threejs, visualization, webgl

## 简介

Headless, modern npm port of the Potree point cloud viewer engine (viewer, loaders, materials, navigation, tools, modules, exporters) built on top of three.js.
