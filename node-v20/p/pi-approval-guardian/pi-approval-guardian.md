# pi-approval-guardian

> 标签: approval-gate, guardian, pi-extension, pi-package, risk-review

## 简介

A fail-closed-by-default Pi approval gate that reviews shell actions, private data access, and sensitive file mutations with an isolated risk model and explicit temporary bypass.
