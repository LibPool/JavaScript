# pubsub-auth

> 标签: auth, crypt, gcp, pubsub, pubsub-auth, pubsub-authenticate, pubsub-encrypt

## 简介

A simple library for encrypting and decrypting messages sent via GCP PubSub. Enables a higher level of authentication than natively supported by PubSub.
