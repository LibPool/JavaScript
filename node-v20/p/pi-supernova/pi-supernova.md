# pi-supernova

> 标签: codemode, extension, oh-my-pi, omp, pi, pi-coding-agent, pi-extension, pi-package, progressive-discovery, supernova

## 简介

CodeMode for Pi and OMP: read, edit, write and bash, with transactional files, source views and shared-input program batches.
