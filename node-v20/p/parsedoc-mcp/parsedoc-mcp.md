# parsedoc-mcp

> 标签: agent, base, invoice, mcp, ocr, parsing, receipt, usdc, x402

## 简介

MCP server for ParseDoc — parse receipts & invoices into structured JSON, paying per call with USDC (x402 on Base). No API key needed.
