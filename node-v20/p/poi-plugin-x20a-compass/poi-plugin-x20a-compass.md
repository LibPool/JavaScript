# poi-plugin-x20a-compass

> 标签: compass, deckbuilder, kancolle, poi, poi-plugin, routing

## 简介

POI plugin that embeds X-20A Compass, injects current fleet DeckBuilder data without reloading, and keeps Compass readable in POI dark mode.
