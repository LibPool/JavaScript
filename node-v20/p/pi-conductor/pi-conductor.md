# pi-conductor

> 标签: agent-workflow, claude, fsm, llm-workflow, multi-agent, orchestration, pi, pi-extension, pi-package, state-machine

## 简介

Multi-role LLM orchestration via a guarded, observable handoff state machine — installs as a pi extension exposing `/conduct`.
