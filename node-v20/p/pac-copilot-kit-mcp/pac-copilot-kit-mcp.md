# pac-copilot-kit-mcp

> 标签: alm, copilot-studio, dataverse, mcp, model-context-protocol, pac, power-platform

## 简介

Local MCP server (stdio) exposing the PacCopilotKit guarded Copilot Studio lifecycle as task-shaped verbs. The thin shim over the PowerShell module; every behavior lives in the module.
