# papercliped

> 标签: agents, chatgpt, claude, mcp, oauth, paperclip

## 简介

Papercliped — connect Claude, ChatGPT and any MCP app to your Paperclip: control agents, sync, report. MCP server + hosted multi-tenant OAuth bridge + public stats API.
