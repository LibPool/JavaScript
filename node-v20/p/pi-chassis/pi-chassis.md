# pi-chassis

> 标签: coding-agent, git, pi, pi-coding-agent, pi-package, tui

## 简介

A workbench for pi: an interface, git workflows and a widget platform for everyday engineering. Sidebar and home screen, Build/Plan modes, ctrl+x leader keys and a ctrl+p palette, a git diff view, git commands that draft commit messages and pull requests,
