# pi-zgrep

> 标签: ai-agent, ai-agents, bm25, code-search, coding-agent, embeddings, full-text-search, grep, hybrid-search, local-first, pi, pi-coding-agent, pi-extension, pi-package, rag, ripgrep, search, semantic-search, vector-search, zg, zvec-grep

## 简介

Semantic, BM25, hybrid, and grep search for the pi coding agent, powered by the zg (zvec-grep) engine. One tool, auto-indexed, local-first. A semantic upgrade over ripgrep for code questions.
