# pi-video-read

> 标签: bailian, dashscope, multimodal, omni, pi, pi-extension, pi-package, qwen, video, video-understanding

## 简介

pi 扩展：用 qwen3.8-omni-flash 读视频（画面 + 声音/口播转写）。本地文件自动分流 base64 内联或百炼官方临时上传，也支持 http(s) / oss:// 输入；quick/standard/fine 三档。
