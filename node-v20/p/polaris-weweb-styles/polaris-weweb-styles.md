# polaris-weweb-styles

> 标签: admin-ui, charts, component-library, components, css, design-system, design-tokens, echarts, mixins, polaris, sass, scss, shopify, shopify-polaris, ui, vue, vue3, weweb

## 简介

SCSS design system + Vue 3 component library for WeWeb custom components following Shopify Polaris design language. Includes mixins, design tokens, theming support, ready-to-use Vue components, and ECharts integration.
