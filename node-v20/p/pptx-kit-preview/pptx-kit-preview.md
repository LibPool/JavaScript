# pptx-kit-preview

> 标签: ooxml, png, powerpoint, pptx, preview, render, svg

## 简介

Experimental preview renderer for pptx-kit: render a slide to SVG (browser + Node) or rasterize it to a PNG/RGBA image in Node, with no browser binary.
