# pixel-mascot

> 标签: animation, assistant, canvas, clippy, mascot, pixel-art, sdf

## 简介

Procedural pixel-art mascots for the web: no sprites, every frame computed from signed distance functions. Eleven characters, 23 gestures, 28 accessories.
