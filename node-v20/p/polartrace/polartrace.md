# polartrace

> 标签: apm, distributed-tracing, express, fastify, instrumentation, koa, logging, metrics, mongodb, mongoose, monitoring, nestjs, observability, opentelemetry, otel, performance, polartrace, postgres, postgresql, profiling, redis, telemetry, tracing

## 简介

Zero-code observability agent for Node.js: distributed tracing, request logs and host metrics for Express, NestJS, Fastify and Koa apps, with automatic MongoDB, PostgreSQL and Redis instrumentation. Built on OpenTelemetry.
