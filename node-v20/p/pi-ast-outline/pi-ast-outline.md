# pi-ast-outline

> 标签: ast-outline, code-navigation, extension, grep, outline, pi-package, symbols, tree-sitter

## 简介

Native pi tools (code_outline, code_digest, code_symbol, code_grep) around the ast-outline CLI — stateless tree-sitter code navigation without indexes or language servers, plus a system prompt nudge
