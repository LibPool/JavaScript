# pi-undo-edits

> 标签: pi, pi-agent, pi-extension, pi-package, pi-undo, pi-undo-edits, restore, session, snapshots, undo

## 简介

Undo last N conversation turns and restore edit/write file changes (no git, no bash undo). Usage: /undo [N]
