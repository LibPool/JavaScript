# public-sdk

> 标签: anti-replay, deds, http, miniprogram, nodejs, redis, response, sdk, signature, token, tools, tree, utils, uuid, validator, wechat

## 简介

Node.js 服务端通用工具库 - 提供零依赖微信小程序 SDK、DEDS 签名防重放守卫、统一响应封装、Token 服务、通用 HTTP 客户端、常用工具方法等
