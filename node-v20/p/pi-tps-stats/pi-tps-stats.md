# pi-tps-stats

> 标签: extension, gentle-pi, gentle-shell, pi-package, tokens, tokens-per-second, tps, tps-stats

## 简介

Built with Gentle Shell, for Gentle Shell (works on plain Pi too). Live TPS, token and cache usage above the Pi prompt, plus a /tps stats panel.
