# pi-deepseek-search-tools

> 标签: deepseek, pi, pi-coding-agent, pi-extension, pi-package, web-search

## 简介

DeepSeek Search & Fetch for Pi: deepseek_search for live web results via the official POST /v1/tools/search API and deepseek_fetch for full-page Markdown via POST /v1/tools/fetch. Requires a DeepSeek API key (DEEPSEEK_API_KEY or /deepseek-setup).
