# pi-local-rag

> 标签: bm25, docx, embeddings, fts5, hybrid-search, index, local, ocr, offline, pdf, pi, pi-coding-agent, pi-extension, pi-package, rag, search, sqlite, sqlite-vec, transformers, vector

## 简介

Local hybrid RAG pipeline for the Pi coding agent. SQLite FTS5 + sqlite-vec, ONNX embeddings via Transformers.js, PDF/DOCX/HTML extraction (with OCR fallback), per-project storage, auto-injection. Zero cloud dependency.
