# pi-remote-feishu

> 标签: bot, chat-bridge, feishu, lark, pi, pi-extension, pi-package, websocket

## 简介

Remote control Pi Agent via Feishu (飞书) chat: WebSocket bridge, cards, attachments and file sending.
