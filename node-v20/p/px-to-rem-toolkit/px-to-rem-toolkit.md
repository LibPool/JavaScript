# px-to-rem-toolkit

> 标签: accessibility, cli, css, design-tokens, lint, px, rem, scss, tailwind, wcag

## 简介

Smart px → rem/em/vw conversion, accessibility and design-token checks for CSS, SCSS, Less, Stylus, Vue, Svelte, Astro, styled-components and Tailwind — the command line twin of the PX to REM Toolkit VS Code extension.
