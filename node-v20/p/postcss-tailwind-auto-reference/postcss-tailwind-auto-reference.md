# postcss-tailwind-auto-reference

> 标签: apply, css-modules, postcss, postcss-plugin, reference, scss, tailwind, tailwindcss

## 简介

PostCSS plugin that adds Tailwind CSS v4 `@reference` to CSS/SCSS modules automatically, so `@apply` just works.
