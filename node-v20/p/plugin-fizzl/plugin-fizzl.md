# plugin-fizzl

> 标签: approvals, base, diagnostics, eip-712, elizaos, elizaos-plugin, ichimoku, presign, safety, solana, trading, wallet-security, x402

## 简介

ElizaOS plugin for Fizzl's x402 agent services: Ichimoku Cloud trading signals, PlainText wallet-approval risk checks, x402 Doctor pre-payment checks and endpoint diagnosis, and presign-guard checks before signing. Pays per call in USDC on Solana or Base.
