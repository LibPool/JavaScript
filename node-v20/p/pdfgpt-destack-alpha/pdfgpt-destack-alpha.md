# pdfgpt-destack-alpha

> 标签: builder, grapesjs, landing page, nextjs, nocode, tailwind

## 简介

Page builder for pdfgpt based on destack which uses Next.js, Grapes.js & Tailwind CSS with zero-config deployment to Vercel
