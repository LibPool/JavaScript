# pi-xcode-mcp

> 标签: mcp, pi, pi-extension, pi-package, swift, swiftui, swiftui-preview, xcode, xcode-mcp

## 简介

Pi package that connects Pi to Xcode's built-in MCP server and exposes build, test, diagnostics, docs, and SwiftUI preview tools.
