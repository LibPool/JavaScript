# pgvouch

> 标签: cli, database-migrations, mcp, model-context-protocol, postgresql, schema-drift, zero-downtime

## 简介

MCP server + CLI for safe PostgreSQL migrations: drift detection, lock analysis, safe rewrites, checksum verification.
