# proj-lysis

> 标签: bilingual, cli, code-analysis, code-metrics, code-size, code-statistics, file-size, line-count, markdown-report, tool, typescript, zero-dependency

## 简介

零依赖的基于 Node.js 的代码统计分析工具 —— 按文件类型统计文件数、体积、代码行/注释行/空白行及占比，生成中英双语 Markdown 报告，支持 CLI 与编程调用
