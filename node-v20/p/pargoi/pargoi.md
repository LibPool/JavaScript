# pargoi

> 标签: content-posting, direct-post, oauth2, pargoi, tiktok, tiktok-api, video-upload

## 简介

A lightweight, production-ready, zero-dependency (except Axios) Node.js wrapper for the **TikTok v2 API**. Fully supports modern OAuth2 workflows, creator pre-flight queries, URL pull publishing, and high-performance chunked direct file streaming.
