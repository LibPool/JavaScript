# pnk-node-mongo

> 标签: aggregation, api, crud, database, mongo, mongodb, mongoose, node mongo library, nodejs, pagination, pnk, pnk-node-mongo, query builder

## 简介

A lightweight Node.js MongoDB utility library providing CRUD operations, pagination, filtering, sorting, and aggregation with Mongoose support.
