# provident-storeroom

> 标签: binding, esm, node-api, provident-storeroom, rust, store

## 简介

U-STOREROOM-PUBLISH: the published Node ESM binding for the native Rust store of Provident-Storeroom — the entry resolves the scoped per-target platform package first, the checkout's own module-relative addon second, and answers the store's single declare
