# pi-msb-sandbox

> 标签: isolation, libkrun, microsandbox, microvm, pi, pi-coding-agent, pi-extension, pi-package, sandbox

## 简介

Run agent bash commands inside a libkrun microVM (microsandbox) with two-way workspace sync — fail-closed isolation for pi
