# printer-mgmt

> 标签: Printer, add printer, delete printer, get default printer, linux, list printer, mac, management, printing, queue, set printer as default, windows

## 简介

Node module to Add, delete, get or set default Printer and list added Printers. Supports Windows, Mac and Linux operating systems.
