# pi-bedrouter

> 标签: aws, bedrock, claude, cost, gpt-oss, model-router, pi-extension, pi-package

## 简介

Pi extension for bedrouter: starts the cost-aware Bedrock model router, registers it as a provider, and shows which model served each request
