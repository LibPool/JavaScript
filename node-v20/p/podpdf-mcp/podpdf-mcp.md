# podpdf-mcp

> 标签: html-to-pdf, markdown-to-pdf, mcp, model-context-protocol, pdf, podpdf

## 简介

MCP server for PodPDF: turn HTML, Markdown, URLs and templates into PDFs from any MCP client.
