# pepys-mcp

> 标签: diarization, mcp, model-context-protocol, pepys, podcast, speech-to-text, subtitles, transcription

## 简介

Pepys transcription MCP server (stdio) – transcribe hours-long audio/video, diarization, timed SRT/VTT, paste-a-link (YouTube/podcast), batch, word-level export. Never trains on your audio.
