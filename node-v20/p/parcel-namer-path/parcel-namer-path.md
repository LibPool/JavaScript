> 标签: JavaScript

## 简介

需要在根目录的``.parcelrc``文件添加如下配置，如果有替换即可 ```json5 {   "extends": "@parcel/config-default",   "namers": ["parcel-namer-path"] } ``` 使用方法很简单，只需要在根目录的``package.json``文件添加``assets-rewrite``字段即可，例如项目结构为 ```tree     src                  ├─ js
