# papertrail-viewer

> 标签: acroform, annotations, browser, canvas, no-dependencies, pdf, pdf-renderer, pdf-viewer, viewer

## 简介

Dependency-free PDF viewer for the browser. Parses and renders PDFs itself - no pdf.js, no plugins, no runtime dependencies.
