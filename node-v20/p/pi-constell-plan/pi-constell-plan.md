# pi-constell-plan

> 标签: claude-code, constellagent, cursor, pi, pi-package, plan-mode

## 简介

Claude Code-style plan mode for pi: explicit --plan / /plan entry, askUserQuestion gating, and Constellagent-compatible plan exports.
