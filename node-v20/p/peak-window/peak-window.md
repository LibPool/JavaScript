# peak-window

> 标签: alpine, climbing, forecast, geosphere, hiking, mcp, meteofrance, meteoswiss, open-meteo, weather

## 简介

MCP server that ranks climbing/ascent weather windows using multiple high-resolution models (GeoSphere AROME 2.5km, MeteoSwiss ICON 2km, Météo-France AROME 2.5km, Open-Meteo global)
