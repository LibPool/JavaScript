# pi-lark-notify

> 标签: bridge, extension, feishu, lark, notify, pi, pi-package

## 简介

pi 主对话 ⇄ 飞书双向桥：主对话完成时发送飞书通知；在飞书里回复通知，内容自动注入对应 pi 会话继续执行。
