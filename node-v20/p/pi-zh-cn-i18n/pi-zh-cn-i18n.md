# pi-zh-cn-i18n

> 标签: chinese, i18n, localization, pi, pi-coding-agent, pi-package, tui, zh-cn

## 简介

Pi 编码代理的简体中文界面汉化扩展：命令补全、二级页面（设置 / 模型 / 会话 / 对话树 / 帮助 / 快捷键）、状态栏与提示全部中文化，并保证不同终端宽度不崩溃。
