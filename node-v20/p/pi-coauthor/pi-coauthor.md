# pi-coauthor

> 标签: co-author, extension, git, hook, pi, pi-coding-agent, pi-extension, pi-package, prepare-commit-msg

## 简介

Pi extension that installs a per-repository prepare-commit-msg git hook adding Co-authored-by and Generated-By trailers to commit messages.
