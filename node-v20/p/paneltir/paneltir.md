# paneltir

> 标签: admin-panel, dashboard, drag-and-drop, kanban, react, theming, ui-kit

## 简介

A React UI kit for admin panels: page frame, a board with touch-ready drag and drop, detail sheets, and a whole panel in one component. Structure and behaviour are fixed; colour and brand belong to each project.
