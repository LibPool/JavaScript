# pi-wakeup

> 标签: pi-coding-agent, pi-extension, pi-package, scheduling, self-pacing, wakeup

## 简介

schedule_wakeup / cancel_wakeup for the pi coding agent: session-local self-pacing, the pi analog of Claude Code's ScheduleWakeup dynamic mode.
