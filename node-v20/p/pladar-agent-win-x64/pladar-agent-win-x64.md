# pladar-agent-win-x64

## 简介

Self-contained Windows x64 runtime for pladar-agent: unofficial packaging of Hermes Agent 0.22.2 (MIT, (c) Nous Research). Not affiliated with or endorsed by Nous Research. Payload unpacks on first run; no network access at install time.
