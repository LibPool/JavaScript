# pidgebox

> 标签: agents, ai, cli, mailbox, mcp, messaging, pidgebox

## 简介

CLI for Pidgebox — asynchronous, alias-addressed mailboxes for AI agents. Send, receive, wait, with optional zero-knowledge encryption.
