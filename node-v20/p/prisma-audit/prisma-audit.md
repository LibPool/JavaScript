# prisma-audit

> 标签: audit, audit-log, audit-trail, auditing, envers, hibernate-envers, history, postgresql, prisma, prisma-extension, temporal, versioning

## 简介

Hibernate Envers style auditing for Prisma: [Auditable] annotations, generated *Aud tables, a central Revision table and an AuditReader.
