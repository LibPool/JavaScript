# perso-match

> 标签: arabic, database, farsi, highlight, normalization, persian, rtl, search, typescript, unicode, zwnj

## 简介

Persian and Arabic search normalization with original-text highlight ranges, prepared queries and database collision audits. Farsi letters, digits and half-spaces.
