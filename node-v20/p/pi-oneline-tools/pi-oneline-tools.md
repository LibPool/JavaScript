# pi-oneline-tools

> 标签: compact, extension, output, pi, pi-coding-agent, pi-extension, pi-package, renderer, tui

## 简介

Renders Pi's read/grep/find/ls/bash tool calls as a single dim line each instead of a bordered box, with the full output one keypress away.
