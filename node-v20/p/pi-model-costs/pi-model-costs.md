# pi-model-costs

> 标签: cost, extension, model, pi, pi-package, pricing

## 简介

Pricing-aware model picker for pi: select models with per-1M-token cost, context window, cache rates, tiers and reasoning support. Sort models by input/output/total cost with ctrl+s.
