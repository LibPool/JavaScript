# pi-devin-plus

> 标签: cognition, custom-provider, devin, pi-extension, pi-package, windsurf

## 简介

Run your Devin / Cognition account models (Opus 5.5, GPT-5.6 Sol, Fable 5, SWE-2...) inside the pi coding agent - CLI login, live model catalog, full tool calling. Enhanced fork of kashyab12/pi-devin.
