# paperclip-hermes-codex-auth

> 标签: auth, codex, hermes, hermes-agent, oauth, openai, paperclip, plugin

## 简介

Sign a Hermes agent in to OpenAI Codex from the Paperclip UI. Drives `hermes auth add openai-codex` on a pseudo-terminal, per Hermes profile, so each agent holds its own OAuth credential instead of sharing one.
