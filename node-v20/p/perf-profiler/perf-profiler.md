# perf-profiler

> 标签: benchmark, cli, latency, perf-hooks, performance, profiler, startup

## 简介

Checkpoint-based performance profiler for harness engineering. Emits human-readable and AI-friendly JSON reports with detected anomalies and fix suggestions.
