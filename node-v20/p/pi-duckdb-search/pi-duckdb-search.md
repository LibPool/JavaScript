# pi-duckdb-search

> 标签: bm25, duckdb, embeddings, full-text-search, onnx, pi-coding-agent, pi-extension, pi-package, search, semantic-search, session-search, vector-search

## 简介

DuckDB-powered BM25 keyword + semantic (ONNX embeddings) + hybrid (RRF) search over Pi session JSONL transcripts. Self-contained — no external APIs, no cloud accounts.
