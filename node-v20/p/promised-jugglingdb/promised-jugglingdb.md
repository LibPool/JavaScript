# promised-jugglingdb

> 标签: alternative, jugglingdb, promise, promise based, q, rewrite

## 简介

Dual API, promise based version of JugglingDB, the ORM for every database: redis, mysql, neo4j, mongodb, couchdb, postgres, sqlite
