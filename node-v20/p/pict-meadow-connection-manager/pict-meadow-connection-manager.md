# pict-meadow-connection-manager

> 标签: browser, configuration, connection, meadow, pict

## 简介

Browser-safe Pict provider + list/detail views for managing named meadow database connections. Delegates form rendering to pict-section-connection-form so the per-provider field schemas come from one canonical source (the meadow-connection-* modules).
