# peasy-social-embed

> 标签: embed, link-preview, meta, og-image, peasy, peasysocial.com, shadow-dom, social, twitter-card, widget, zero-dependencies

## 简介

Embed PeasySocial widgets on any website. Lightweight (<8KB gzipped), zero dependencies, Shadow DOM isolation, 3 themes.
