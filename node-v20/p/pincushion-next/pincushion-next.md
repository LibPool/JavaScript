# pincushion-next

> 标签: ai-agents, annotations, feedback, mcp, next-plugin, nextjs, pincushion, review, vercel-preview, visual-feedback

## 简介

One JSX line makes every Next.js dev build and Vercel preview pinnable — visual feedback anyone can leave, delivered to your AI coding agent as work packets via MCP.
