# poppyseed

> 标签: agents, conformance, dpop, mcp, nextjs, oauth, openapi, pap, personal-agent-protocol, poppy, testing

## 简介

Implements the Personal Agent Protocol (Poppy for short) in Next.js: discovery, sign-in, tools over MCP and OpenAPI, operations people approve, and conversations. Includes a test agent and the conformance suite.
