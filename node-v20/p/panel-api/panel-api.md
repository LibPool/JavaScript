# panel-api

> 标签: dialog, esm, floating-panel, panel, panel-api, popover, web-components, zui

## 简介

A durable application-chrome API for movable, resizable, in-page floating panels with optional ZUI (zooming user interface) integration. Plain ESM, no build step, no dependencies.
