# pagomovil-ocr

> 标签: bcv, comprobante, fintech, ocr, pago-movil, recibo, tasa-oficial, tesseract, typescript, usd, venezuela, ves

## 简介

Librería JavaScript para extraer, normalizar, parsear y validar comprobantes de Pago Móvil venezolanos mediante OCR, con utilidades de conversión USD/VES basadas en la tasa oficial del BCV.
