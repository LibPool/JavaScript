# pi-pinned-input

> 标签: alternate-screen, chat-input, coding-agent, floating-input, footer, pi, pi-coding-agent, pi-extension, pi-package, pi-tui, pinned-input, sticky-input, terminal

## 简介

Pi extension that pins a bounded, growing prompt editor to the bottom of the terminal while session history scrolls above it.
