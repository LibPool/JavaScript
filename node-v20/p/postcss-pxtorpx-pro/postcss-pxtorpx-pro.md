# postcss-pxtorpx-pro

> 标签: css, pixel, postcss, postcss-plugin, px, rpm, unit

## 简介

A CSS post-processor that converts px to rpx. 转换px单位为rpx，并允许指定任意单位及其转换函数，支持指定黑名单prop
