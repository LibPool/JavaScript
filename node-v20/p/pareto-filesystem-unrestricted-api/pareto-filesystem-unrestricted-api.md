# pareto-filesystem-unrestricted-api

> 标签: JavaScript

## 简介

A library providing an unrestricted API for filesystem operations, allowing manipulation of all files and directories in the file system without the constraints of a sandboxed environment. Use this API when a sandboxed directory is not sufficient.
