# yeboid-web

> 标签: africa, auth, oauth, oidc, pkce, yebo, yeboid

## 简介

YeboID OAuth/OIDC SDK for browser apps — PKCE flow, silent refresh, single-flight 401 retry, optional React adapter. Pairs with yeboid-node on the server.
