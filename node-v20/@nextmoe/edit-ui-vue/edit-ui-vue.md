# @nextmoe/edit-ui-vue

> 标签: JavaScript

## 简介

NextMoe edit-ui Vue 3 layer — the schema-driven edit form, the per-field controls, the diff/review/timeline views. Composes @kungal/ui-vue; ships zero CSS of its own.
