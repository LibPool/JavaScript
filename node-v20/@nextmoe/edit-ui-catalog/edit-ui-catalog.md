# @nextmoe/edit-ui-catalog

> 标签: catalog, edit-ui, nextmoe, preset, schema

## 简介

Field presets for the NextMoe catalog editing API — a tested EditFieldConfig table covering every field the editing engine registers, so a site does not have to rediscover each field's control, enum vocabulary and element shape.
