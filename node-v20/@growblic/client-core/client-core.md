# @growblic/client-core

> 标签: chat, messaging, phoenix, realtime, sdk, websocket

## 简介

Growblic chat SDK core — conversations, messages, media, calls, and presence over REST + Phoenix websockets. Framework-agnostic; pair with @growblic/client-react for hooks.
