# @frogbotai/portkey-gateway-embed

> 标签: AI gateway, LLM, OpenAI, Portkey, Portkey AI, embeddable, library

## 简介

Library-embeddable fork of Portkey AI Gateway. Adds a programmatic `app` export alongside the upstream CLI bin so the gateway can be embedded in-process as a Hono fetch handler.
