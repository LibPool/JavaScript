# @qingwu-ui/avatar

> 标签: avatar, crop, image-editor, profile, qingwu, rotate, zoom

## 简介

Framework-agnostic avatar editor for Qingwu UI - click avatar, crop with drag, zoom, rotate and radius controls, export Blob and dataURL locally
