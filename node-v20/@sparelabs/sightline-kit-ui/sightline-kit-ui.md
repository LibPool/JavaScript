# @sparelabs/sightline-kit-ui

> 标签: JavaScript

## 简介

Sightline's UI kit: the shadcn/ui primitives, cn, the hooks they need and a Tailwind preset, as ESM with types. React, Radix and the rest are peer dependencies.
