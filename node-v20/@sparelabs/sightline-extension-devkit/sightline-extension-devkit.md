# @sparelabs/sightline-extension-devkit

> 标签: JavaScript

## 简介

A local stand-in for Sightline core for hosted-extension development: token issuer and JWKS, the ext-api routes the SDK calls, a runner with the ext-runtime's Deno flags, the extension's Postgres in Docker, and an invoker.
