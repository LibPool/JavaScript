# @rafaelgomes/localprint-sdk

> 标签: escpos, inkjet, localprint, print, sdk, tauri, thermal

## 简介

TypeScript SDK to talk to the LocalPrint Desktop local HTTP API (pairing, system printers, ESC/POS raw and silent HTML printing).
