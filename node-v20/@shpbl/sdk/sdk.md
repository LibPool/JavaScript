# @shpbl/sdk

> 标签: api-client, capability, deterministic, gauntlet, mcp, sdk, shpbl

## 简介

Typed client for the SHPBL API — the same fourteen tools the MCP server runs, over ordinary HTTP. No model, no magic, no hidden state.
