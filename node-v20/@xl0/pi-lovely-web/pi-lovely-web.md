# @xl0/pi-lovely-web

> 标签: brave search, exa, firecrawl, pi-package, tavily, web fetch, web search

## 简介

Pi extension package for direct HTTP GET plus web_search, web_fetch, and web_image via Firecrawl, Exa, Tavily, and Brave.
