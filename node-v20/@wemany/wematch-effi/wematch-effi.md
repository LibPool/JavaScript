# @wemany/wematch-effi

> 标签: effi, plugin, wemany, wematch

## 简介

Plugin oficial de integración con la API de Effi Analytics para el motor de reglas de WeMatch.   Obtiene atributos clave como valor recaudado y cantidad de guías distribuidas, utilizando autenticación por API Key.
