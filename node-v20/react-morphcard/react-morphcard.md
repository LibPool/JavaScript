# react-morphcard

> 标签: animation, card, detail-view, hook, nextjs, pwa, react, react-hook, shared-element-transition, transition, web-animations-api, webview

## 简介

React hook for a card that grows into a full detail screen and shrinks back, with shared elements flying between the two. Works in any modern browser, installed PWAs and WebViews. Not for React Native. No dependencies besides React.
