> 标签: deep-object, http, http-params, model-binding, nested-objects, query-params, query-string, querystring, serializer, typescript, url-search-params, zero-dependencies

## 简介

Framework agnostic processor that turns deeply nested objects and arrays into HTTP query parameters your backend can model bind. Zero dependencies.
