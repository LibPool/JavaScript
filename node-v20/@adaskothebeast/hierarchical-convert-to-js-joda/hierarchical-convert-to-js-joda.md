# @adaskothebeast/hierarchical-convert-to-js-joda

> 标签: converter, date, iso8601, js-joda, json, typescript, zoneddatetime

## 简介

Deep, in-place conversion of ISO 8601 date-times in JSON payloads into js-joda values, plus a js-joda backend for the Typewriter runtime.
