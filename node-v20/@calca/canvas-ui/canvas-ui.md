# @calca/canvas-ui

> 标签: JavaScript

## 简介

Headless canvas UI components for Calca — presentational React pieces for canvas surfaces: `DesignFrame` (generated-frame chrome), `DesignCard`, `PipelineStatusOverlay`, `RubberBandOverlay` (marquee selection), `useMountEffect`. No React Flow or document-
