# @imagile-dev/toil

> 标签: agents, cli, enterprise, integrations, mcp

## 简介

The token-efficient alternative to MCP: one CLI for enterprise tools and databases, with compact JSON envelopes, --select for only the fields needed, and a skill read on demand instead of every tool schema. toil mcp stays available.
