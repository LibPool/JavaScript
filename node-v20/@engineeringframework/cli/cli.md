# @engineeringframework/cli

> 标签: cli, engineering-framework, knowledge-base, mcp, model-context-protocol

## 简介

Command-line client for Engineering Framework — log in via OAuth (PKCE) and ingest Markdown Documents into the Knowledge Base from your terminal.
