# @p-vbordei/relative-time

> 标签: ago, date, humanize, intl, relative, time

## 简介

Format dates as relative phrases ("2 hours ago", "in 3 days") with smart unit selection. Wraps Intl.RelativeTimeFormat. Zero dependencies.
