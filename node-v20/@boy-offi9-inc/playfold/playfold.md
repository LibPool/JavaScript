# @boy-offi9-inc/playfold

> 标签: audio, audio-player, discord, embed, iframe, link-preview, oembed, opengraph, player, player-ui, postmessage, sdk, telegram, unfurl, video, whatsapp

## 简介

Tiny, framework-agnostic SDK for embedding media players in an iframe and controlling them through a typed, promise-based API. Includes server-side link-preview helpers (Open Graph, Twitter, oEmbed) and a crawler checker.
