# @mitsuharu/vivliostyle-theme-noto-sans-jp

> 标签: vivliostyle, vivliostyle-theme

## 简介

This is a vivliostyle theme that sets fonts to Noto Sans JP and Noto Sans Mono. If use it, you MUST use with other themes.
