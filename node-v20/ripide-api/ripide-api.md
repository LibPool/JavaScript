# ripide-api

> 标签: ai-agent, ast, claude-code, codemod, cursor, refactor, rename, ripgrep, tailwind, typescript

## 简介

AST refactor engine for AI coding agents. Deterministic rename, move, find-usages, and tailwind/CSS class migration across TypeScript. Framework adapters loaded via ripide-<framework> packages.
