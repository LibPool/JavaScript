# @adhd/apigen-engine-naming

> 标签: JavaScript

## 简介

Naming and identifier helpers for apigen — case conversion, file-name normalization, namespace/project id derivation, export collision detection, and the §9.1 envelope-key conventions. Pure TypeScript (**platform: shared**).
