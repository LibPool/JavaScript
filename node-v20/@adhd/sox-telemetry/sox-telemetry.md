# @adhd/sox-telemetry

> 标签: metrics, otel, telemetry, tracing, typescript

## 简介

Shared tracing/metrics substrate (BL-351): OTel API facade, durable JSONL sink, wait/work primitive, stage self-check. The only package permitted to import @opentelemetry/*.
