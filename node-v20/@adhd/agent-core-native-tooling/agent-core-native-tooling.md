# @adhd/agent-core-native-tooling

> 标签: agent, dispatch, filesystem, mcp, native-tooling, permissions, shell, typescript

## 简介

Core resolver + thin tool-name permission matcher for the standardized, portable native toolset (fs/shell/dispatch) inherited by dispatched agents (ADR-0008). CommonJS-only (adhd ADR-0003).
