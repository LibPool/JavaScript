# @btheegg-kimth/img2webp

> 标签: animation, browser, img2webp, jpeg, libwebp, png, wasm, webp

## 简介

Frames (PNG/JPEG/WebP) -> animated WebP in the browser, via libwebp img2webp compiled to WASM.
