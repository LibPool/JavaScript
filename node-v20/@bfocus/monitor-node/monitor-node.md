# @bfocus/monitor-node

> 标签: bfocus, crash-reporting, error-tracking, express, fastify, monitoring, nextjs

## 简介

Monitoramento de erros do bFocus para Node.js — erros não tratados viram demanda, agrupados por causa e ligados ao cliente afetado.
