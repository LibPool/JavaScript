# @barakel/feedback-widget

> 标签: ai, assistant, chat, corpsec, embeddable, shadow-dom, sse, streaming, support, widget, yantra

## 简介

Embeddable, auth-gated AI chat widget for CorpSec products. Streams from the Yantra gateway, inherits the host page's theme, and handles image, document and pasted-text attachments.
