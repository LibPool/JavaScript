# @civify/mcp-server

> 标签: ai-agent, ats-score, civify, claude, cursor, cv-tailoring, mcp, model-context-protocol, resume

## 简介

Model Context Protocol (MCP) server for Civify AI Career Platform. Enables AI agents to parse resumes, tailor CVs against job descriptions, score ATS compatibility, redact PII, and track job applications.
