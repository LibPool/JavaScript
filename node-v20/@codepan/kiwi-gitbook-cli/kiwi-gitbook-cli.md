# @codepan/kiwi-gitbook-cli

> 标签: JavaScript

## 简介

一个使用gitbook来构建静态电子书，集成gulp对静态资源进行压缩混淆，并集成了ftp和scp两种方式自动化部署到服务器上的一个脚手架工具
