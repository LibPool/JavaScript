# @patrickdk77/xml-defuse

> 标签: cdr, cleaner, defang, defuse, detect, disarm, dtd, html, inspect, mht, mhtml, sanitise, sanitize, sanitizer, scanner, scrub, security, strip, svg, xhtml, xinclude, xml, xsl, xslt, xss, xxe

## 简介

Sanitize and clean HTML, XHTML, SVG, XML, XSLT and MHT files. Detects and removes scripts, event handlers, javascript: links, external entities and DTDs, XInclude, XSLT extension functions, frames, objects, forms, meta refresh and CSS that runs or loads,
