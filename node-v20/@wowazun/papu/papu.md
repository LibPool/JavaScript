# @wowazun/papu

> 标签: accelerometer, cli, devicemotion, exercise, for-fun, fun, git, git-hooks, joke, novelty, pre-push, push, push-up, workout

## 简介

push する前に腕立て伏せ (papu = push after a push-up)。スマホの加速度センサーで腕立てを検出し、CLI にカラフルな進捗バーを表示する。
