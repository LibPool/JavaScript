# expo-reanimated-side-menu

> 标签: drawer, expo, floating, menu, navigation-drawer, rail, react-native, reanimated, side-menu, sidebar, swipe

## 简介

A side menu for Expo and React Native with eight styles: 3D overlay, reveal, cards, flip, push, popup, floating card and docked rail. Reanimated, swipe to close, theming.
