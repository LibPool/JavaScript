# @seameet/mcp

> 标签: ai-agent, claude, claude-code, codex, cursor, desktop-app, mcp, mcp-server, meeting-notes, meeting-recorder, model-context-protocol, productivity, screen-recording, seameet, transcription, webhooks

## 简介

Dual-mode MCP server for SeaMeet — let AI agents (Claude Code, Codex, Cursor) drive the desktop recorder when it's running, else read your synced cloud library and manage webhooks. Cloud mode authorizes by logging into the web app — no key copy/paste.
