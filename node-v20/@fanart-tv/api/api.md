# @fanart-tv/api

> 标签: api, artwork, backgrounds, fanart, fanart.tv, images, movies, music, posters, tv

## 简介

Official fanart.tv API client for Node.js - supports v3, v3.1, and v3.2 with client_key authentication

## 官网

- 官网：https://api.fanart.tv
- 源码仓库：git+https://github.com/fanart-tv/fanart.tv-api.git
- npm 页面：https://www.npmjs.com/package/@fanart-tv/api
