# @mounaji_npm/tasks-board

> 标签: board, headless, kanban, mounaji, tasks, todo

## 简介

Headless tasks kanban core: task/event/summary types, board grouping with persistable manual order, due-date helpers, composable filters and a fetcher-injectable REST adapter — no UI, no fetch of its own
