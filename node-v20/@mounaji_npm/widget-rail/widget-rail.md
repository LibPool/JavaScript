# @mounaji_npm/widget-rail

> 标签: design-tokens, dock, fab, floating, mounaji, overlay, rail, widget

## 简介

Vertical widget rail: edge-anchored FAB rail with draggable position, collapse/auto-collapse, single resizable panel and an imperative registerWidget registry (extracted from mounaji-platform's WidgetSystem)
