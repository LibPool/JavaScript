# @mounaji_npm/geo-map

> 标签: geocoding, geojson, location-picker, map, maplibre, mounaji, nominatim, osm, pins

## 简介

Thin React map wrapper (MapLibre GL + OSM raster tiles by default): status-colored pins, GeoJSON zone layers with per-zone color and tap-to-select, pin click callbacks, tap-to-mark, draggable selection, camera fly-to, an address-search + reverse-geocode l
