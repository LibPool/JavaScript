# @geohar/unbien-cli

> 标签: agent-mesh, cli, coding-agent, pi, relay, remote, terminal, tui, un-bien, unbien

## 简介

unbien — a terminal client for remote Pi coding-agent sessions. Attach over an un-bien relay and render the transcript with pi's own TUI components: markdown, syntax highlighting, native tool cards, and your pi theme.
