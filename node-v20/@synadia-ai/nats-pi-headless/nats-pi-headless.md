# @synadia-ai/nats-pi-headless

> 标签: agent-protocol, agents, nats, pi, pi-agent, synadia-agents

## 简介

Headless NATS agent host that spawns, prompts, and stops PI coding-agent sessions as first-class Synadia Agent Protocol for NATS v0.3 instances. Each session registers as agents.prompt.pi-headless.<owner>.<session_id>; a small controller service adds verb
