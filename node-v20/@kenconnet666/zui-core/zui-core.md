# @kenconnet666/zui-core

> 标签: chain, css-in-js, design-tokens, dsl, emotion, framework-agnostic, theme, type-safe, typescript

## 简介

Framework-agnostic CSS-in-JS toolkit. Class-generic theme system on top of @emotion/css with strongly-typed four-state property carriers (fn / token / keyword / unit).
