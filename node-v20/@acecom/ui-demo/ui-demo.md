# @acecom/ui-demo

> 标签: acecom, react, storybook, tailwind, typescript, ui

## 简介

**AcecomUI** is a modern, reusable, and accessible React component library built with TypeScript and Tailwind CSS. Designed for **Acecom**'s internal projects, it helps developers build consistent and efficient user interfaces faster.
