# @better-software/rx-ws-effects

> 标签: declarative, effects, reactive, rxjs, server, simulator, websocket

## 简介

Declarative WebSocket message handling on RxJS: each effect is a pure function from a stream of incoming messages to a stream of outgoing ones.
