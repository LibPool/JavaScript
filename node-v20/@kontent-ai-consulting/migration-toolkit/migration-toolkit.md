# @kontent-ai-consulting/migration-toolkit

> 标签: Kontent.ai, Kontent.ai CSV export & import, Kontent.ai JSON export & import, Kontent.ai import, Kontent.ai import toolkit, Kontent.ai migration tool

## 简介

This program can be used to import content related data into Kontent.ai from various formats. Additionally, it can also be used to export Kontent.ai data using Delivery API.
