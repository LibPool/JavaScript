# @lyteboat/a2ui

> 标签: JavaScript

## 简介

lyteboat's A2UI template engine (a port of the reference template mode: manifest resolution, transforms DSL, walker, contract validation) and the render_a2ui tool that folds rendered cards into the lyteboatCards projection
