# @lyteboat/model-side-call

> 标签: JavaScript

## 简介

lyteboat's side model calls: one prompt a plugin sends for an agent (a routing decision, an intake classification) under its own deadline, recorded in the agent's session as an ignorable lyteboat/aux-llm-call record. Config: reasoningEffort, the effort ev
