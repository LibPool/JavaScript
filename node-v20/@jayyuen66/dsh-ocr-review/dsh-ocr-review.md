# @jayyuen66/dsh-ocr-review

> 标签: AI code review, DeepSeek Harness, code-review, deepseek-harness, dsh, dsh-plugin, ocr, open-code-review

## 简介

dsh 工作区代码审查插件：把 open-code-review（ocr CLI）封装为 5 个模型工具 + 设置卡片（从宿主设置服务的 provider 清单选 provider/model 应用到 OCR 配置）。
