> 标签: access control, ai agent, authorization, claude code, clickhouse, llm, mcp, model context protocol, multi-tenant, prisma, row-level security, tool use, typescript

## 简介

Library to turn your app's database into an MCP server for coding agents (Claude Code) — adapter-agnostic, row-level security, zero SQL
