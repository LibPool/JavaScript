# @treezjs/workspace_module

> 标签: jupyter, jupyterlab, jupyterlab-extension, treez, treezjs, workspace_module

## 简介

Looks for a JavaScript file 'workspace.js' in the workspace folder (=notebook-dir) and tries to load it as ES6 module. You can adapt the content of 'workspace.js' to your needs.
