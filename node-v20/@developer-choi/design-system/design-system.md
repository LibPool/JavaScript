# @developer-choi/design-system

> 标签: JavaScript

## 简介

여러 프로젝트가 함께 쓰는 화면 부품(버튼·입력창·모달 등)을 한곳에 모아 만든 디자인 시스템입니다. 색·여백·글자 크기 같은 시각 기준도 한곳에 모아, 그 기준만 바꾸면 전체 톤이 한 번에 바뀝니다.
