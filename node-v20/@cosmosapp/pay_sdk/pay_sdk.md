# @cosmosapp/pay_sdk

> 标签: albedo, api, browser, client, cosmos, cosmos-pay, freighter, lobstr, payment-intents, payments, rabet, sdk, sep-7, stellar, typescript, wallet, webhooks, xbull

## 简介

A powerful, object-oriented JavaScript/TypeScript SDK for the Cosmos Pay Payments API — server SDK (Stellar SEP-7 payment intents, webhooks, products, customers, analytics) plus a browser web client that auto-detects Freighter, xBull, Rabet, LOBSTR & Albe
