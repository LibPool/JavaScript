# @boluabraham/fhir-human-language

> 标签: JavaScript

## 简介

&lt;fhir-human-language&gt;adds language used to communicate to the page with a checkbox to show which one is preferred. Uses mwc-textfield, mwc-checkbox and iron-ajax  In typical use, just use &lt;fhir-human-language url=""/fhir-human-language&gt;
