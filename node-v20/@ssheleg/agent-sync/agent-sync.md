# @ssheleg/agent-sync

> 标签: agent-skills, claude-code, coordination, knowledge-base, lease, multi-agent, task-pipeline

## 简介

Let concurrent coding agents share one project without colliding — leases with TTL, race-free id reservation, a run journal and a generated board, over a pluggable knowledge cloud.
