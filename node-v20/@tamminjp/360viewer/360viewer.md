# @tamminjp/360viewer

> 标签: 360, equirectangular, hotspots, panorama, viewer, virtual tour, webgl

## 简介

Lightweight, dependency-free TypeScript library to display 360° photos with clickable hotspots for navigation, tooltips and custom actions.
