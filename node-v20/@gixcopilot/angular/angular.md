# @gixcopilot/angular

> 标签: agent, ai, angular, chat, copilot, llm, sdk, signals, typescript, ui

## 简介

Angular adapter for the AI Copilot SDK: provideCopilot, signal-based services, context/tool/state registration, trusted generative UI and an accessible chat component.
