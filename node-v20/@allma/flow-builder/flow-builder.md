# @allma/flow-builder

> 标签: ai, allma, builder, dsl, flow, flows-as-code, orchestration, serverless, typescript, zod

## 简介

TypeScript builder and CLI for authoring Allma flow definitions as code, with compile-time type safety and a deterministic JSON artifact.
