# @contentgrowth/content-auth

> 标签: astro, auth, better-auth, cloudflare, pages, react, vue, workers

## 简介

Better Auth wrapper with UI components for Cloudflare Workers & Pages. Includes custom schema mapping, Turnstile bot protection, and email normalization.
