# @ag-ui/mcp-middleware

> 标签: JavaScript

## 简介

AG-UI middleware that connects an agent run to one or more [MCP](https://modelcontextprotocol.io) servers. It lists each server's tools, injects them into the run, executes the resulting tool calls server-side, and loops the agent until no MCP tool calls
