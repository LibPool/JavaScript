# @j1n/lint-a-lot

> 标签: angular, best-practices, code-quality, eslint, eslint-plugin, lint-rules, linting, scss, stylelint, stylelint-config, typescript

## 简介

Lint-a-lot is an opinionated ESLint and Stylelint configuration for Angular projects using modern Flat Config. Also this project contains a `.editorconfig` that should be used.
