# @tangent.to/nn

> 标签: autograd, browser, concrete-dropout, deep-learning, dropout, esm, neural-network, tangent.to, uncertainty

## 简介

Neural networks on the tangent tape: a functional layer API (branches, dropout, concrete dropout) differentiated by @tangent.to/grad, trained with @tangent.to/opt, exportable as JSON.
