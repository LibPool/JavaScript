# @ribertec/directus-extension-api-autofill

> 标签: api, autofill, directus, directus-extension, directus-extension-bundle, lookup

## 简介

General-purpose API autofill interface for Directus: query an external HTTP API on input and fill sibling fields via a source-to-target mapping.
