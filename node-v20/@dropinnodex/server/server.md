# @dropinnodex/server

> 标签: activity-feed, dropin, feed, getstream, jwt, sdk, webhooks

## 简介

Server-side SDK for dropin-activity — mint HS256 user tokens offline, and manage users, feeds, and webhooks from your backend. Node only.
