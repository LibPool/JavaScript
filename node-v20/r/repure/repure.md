# repure

> 标签: JavaScript

## 简介

给 **pure function** 添加记忆功能， 替代[reselect](https://github.com/reactjs/reselect.git)并且提供更加简单的写法。 对于**pure function** 相同的入参，会得到相同的结果。 所以repure会根据入参来缓存结果， 一旦发现 入参相同，就直接返回缓存的结果
