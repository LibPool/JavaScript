# razi-tools-mcp

> 标签: ai-tools, claude, developer-tools, mcp, model-context-protocol, ocr, pdf

## 简介

MCP server for razi.pro — executable developer tools (PDF, image, video, OCR, text and AI helpers) for AI assistants. No API key required.
