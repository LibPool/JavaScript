# react-creatable-select

> 标签: autocomplete, combobox, creatable, headless, multiselect, radix, react, select, shadcn

## 简介

Headless, searchable, creatable + editable select/combobox for React. Single & multi select, inline rename, optional delete, async-first. Built on Radix Popover, designed to drop into shadcn/ui.
