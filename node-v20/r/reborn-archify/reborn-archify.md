# reborn-archify

> 标签: agent-skills, archify, architecture-diagram, claude, claude-code, diagram, korean, mermaid, skill, system-design

## 简介

코드베이스나 설명을 인터랙티브 구조도(HTML)로 만드는 Archify(tt-a1i · MIT) 스킬을 원저자 저장소에서 받아 클로드 코드 자리에 정확히 넣고, 한국어 안내 스킬을 얹습니다. --check 가 다섯 칸(노드 · 클로드 코드 · 클로드 코드 자리 · 엉뚱한 자리 · 렌더러)을 실제로 재 줍니다. 가장 많이 막히는 자리는 설치 위치입니다 — 다른 에이전트 폴더에만 들어가도 성공으로 뜨고, 클로드 코드는 조용히 못 봅니다. Archify 는
