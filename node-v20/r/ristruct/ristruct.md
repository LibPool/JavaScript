# ristruct

> 标签: bun, edge, framework, http, performance, router, typescript, web, web-standard

## 简介

A fast, type-safe web framework in pure TypeScript, built on Web Standard Request/Response. Single dependency-free package. Works on Bun, Cloudflare Workers, Cloudflare Pages Functions, Vercel Edge, Deno, and Node 18+.
