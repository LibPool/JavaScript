# rn-devtools-hub

> 标签: ai-agent, claude-code, debugger, devtools, e2e-testing, expo, inspector, mcp, mcp-server, model-context-protocol, network-inspector, react-native, screen-mirror, ui-automation

## 简介

The agent runtime for React Native and Expo: an MCP server that sees the app the way React sees it, knows which file produced each element, acts without coordinates, and proves it works. Local only, zero dependencies.
