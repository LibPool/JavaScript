# routewasm

> 标签: isochrone, maplibre, maps, matrix, offline, openstreetmap, osm, pmtiles, privacy, routing, turn-by-turn, valhalla, wasm, webassembly

## 简介

Offline-capable turn-by-turn routing that runs entirely in the browser. WebAssembly, OpenStreetMap, no server required.
