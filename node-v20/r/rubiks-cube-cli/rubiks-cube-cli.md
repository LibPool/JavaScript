# rubiks-cube-cli

> 标签: JavaScript

## 简介

交互式 3D 魔方网页应用，集成 Web3 钱包连接。使用 Three.js 进行 3D 可视化，ethers.js 处理区块链交互。

- npm 页面：https://www.npmjs.com/package/rubiks-cube-cli
