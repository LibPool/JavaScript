# react-native-latex-equation

> 标签: agent-skills, claude-code, equations, expo, inline-math, katex, latex, math, mathjax, react-native, webview

## 简介

Render inline LaTeX math ($...$ and $$...$$) inside React Native / Expo Text components, including mid-sentence equations mixed with regular text. Single-WebView KaTeX renderer with a fast path for plain-text strings.
