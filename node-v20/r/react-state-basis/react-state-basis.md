# react-state-basis

> 标签: architecture, debugging, development-tools, devtools, hooks, performance, profiler, react, react-devtools, redundancy-detection, state-management, state-profiler, useEffect, useState

## 简介

Runtime state profiler for React that detects redundant state, update chains, and infinite loops by tracking when state updates happen.
