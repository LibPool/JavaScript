> 标签: codegen, desugaring, ecmascript, es5, es6, harmony, javascript, refactoring, regex, regexp, regular expressions, rewriting, syntax, transformation, transpile, transpiler, unicode

## 简介

regexpu’s core functionality (i.e. `rewritePattern(pattern, flag)`), capable of translating ES6 Unicode regular expressions to ES5.
