> 标签: actions, bun, bun-native, file-based-routing, framework, hydration, loaders, markdown, rbssr, react, server-rendering, ssr, streaming

## 简介

Bun-native SSR React framework with file-based routing, loaders, actions, streaming SSR. No Node adapter layer.
