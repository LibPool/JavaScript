# react-native-liquid-fill

> 标签: accelerometer, animation, circular-progress, expo, fill, gauge, liquid, progress, progress-ring, react-native, reanimated, svg, tilt, typescript, water, wave

## 简介

Liquid progress for React Native: water that fills any shape, with travelling waves, rising bubbles and a surface that sloshes when the phone tilts. Plus a ProgressRing with a second lap past 100%. Reanimated + react-native-svg, UI thread.
