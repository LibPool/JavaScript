# react-native-number-bloom

> 标签: animated, animated-counter, animated-number, animated-numbers, animation, bloom, counter, currency, expo, flip, flip-number, intl, new-architecture, number, number-flow, number-flow-react-native, number-format, numberflow, numbers, odometer, price, react-native, react-native-number-flow, react-native-skia, reanimated, rolling-number, skia, ticker

## 简介

Smooth animated numbers for React Native. Digits roll, fade, and blur as the value changes. Skia-rendered with full Intl.NumberFormat support.
