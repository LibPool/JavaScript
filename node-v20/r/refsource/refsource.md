# refsource

> 标签: citations, compliance, datasets, fact-check, lookup, provenance, reference-data, regulations, source-quote, verification

## 简介

Look up reference data that carries its own source: every value comes with the URL it was read from and a verbatim quote from that page.

## 官网

- 官网：https://referencesource.org
- npm 页面：https://www.npmjs.com/package/refsource
