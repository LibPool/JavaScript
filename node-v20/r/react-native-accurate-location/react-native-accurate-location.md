# react-native-accurate-location

> 标签: accuracy, android, geolocation, gps, ios, location, mock-detection, new-architecture, react-native, turbomodule

## 简介

Fast, tunable high-accuracy one-shot geolocation for React Native (New Architecture): resolves on an accuracy threshold, returns the best fix on timeout, always-fresh, with mock-location detection.
