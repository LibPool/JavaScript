# remark-mdx-blockquote

> 标签: admonition, alert, blockquote, markdown, mdx, plugin, remark, remark-mdx-blockquote, remark-plugin, unified

## 简介

A remark plugin that converts GitHub-style alert blockquotes (e.g. > [!NOTE]) into <blockquote> elements with a data-callout attribute.
