# routeguard

> 标签: API route validation, JSON, backend utility, header validation, parameter validator, query validation, request validation, routeguard, routes, schema, strict validation

## 简介

a lightweight middleware package that dynamically validates API routes based on a JSON schema or rules defined at runtime.
