# react-native-call-reminder

> 标签: alarm, android, full-screen-intent, incoming-call, ios, medication, react-native, reminder, text-to-speech, time-sensitive, turbo-module

## 简介

Store-compliant, call-style reminders for React Native: a full-screen incoming-call screen on Android, Time Sensitive notifications on iOS, and spoken reminders via the device text-to-speech engine.
