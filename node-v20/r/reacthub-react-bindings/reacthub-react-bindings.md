# reacthub-react-bindings

> 标签: pixi-essentials, pixijs, react-pixi, reactjs

## 简介

React components for display-objects provided by pixi-essentials, for usage with @pixi/react. A forked version of the  @pixi-essentials/react-bindings with latest react and @pixi/react library updates.
