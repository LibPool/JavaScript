# renkei-next

> 标签: line, line-login, nextjs, oidc, openid-connect, renkei

## 简介

Next.js (App Router) helpers for renkei: route handlers for the OIDC login/callback/logout, an encrypted session cookie, getSession(), a proxy/middleware guard, and a LINE-guideline-compliant <LineLoginButton />.
