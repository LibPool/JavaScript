# resolve-pkg-conflicts

> 标签: cli, conflict, git, merge, npm, package.json

## 简介

Auto-resolve git merge conflicts in package.json dependency blocks, keeping the higher version of each duplicated package.

- npm 页面：https://www.npmjs.com/package/resolve-pkg-conflicts
