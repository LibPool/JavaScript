# react-native-edit-text

> 标签: EditText, TextInput, react-native

## 简介

React Native 默认的 `textInput` 组件默认是没有边框的，使用的时候需要自己在其外面套个`view`来使用。且安卓上面无法实现输入时，右侧出现删除按钮。
