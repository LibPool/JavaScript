# retro-core

> 标签: agent, continuous-improvement, dependency-injection, orchestrator, pipeline, retro, retrospective, zero-dependency

## 简介

Generic retrospective orchestrator: wires a loader, an analyzer, and a router into one run. Never commits anything itself.
