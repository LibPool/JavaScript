# readme-shield

> 标签: JavaScript

## 简介

A RESTful API service to track your GitHub README.md shield/badge vs npm's recent release version.  NodeJS, Redis, Shields.io as badge provider.

- npm 页面：https://www.npmjs.com/package/readme-shield
