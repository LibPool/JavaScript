# react-native-universal-datepicker-ios

> 标签: JavaScript

## 简介

React native datepicker that supports different calendars such as [Gregorian, hijri, IslamicUmmAlQura, Islamic, chinese, coptic, ISO8601, indian, islamicCivil, japanese, persian, republicOfChina, islamicTabular]
