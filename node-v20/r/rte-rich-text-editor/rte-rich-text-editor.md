# rte-rich-text-editor

> 标签: browser, contenteditable, editor, embeddable, html-editor, markdown, markdown-editor, no-dependencies, no-jquery, rich-text, rich-text-editor, richtext, rte, standalone, text-editor, umd, vanilla-js, wysiwyg, wysiwyg-editor, zero-dependencies

## 简介

WYSIWYG rich-text editor in one script tag. Zero dependencies, no framework, no jQuery. Tables, images, links, HTML and Markdown export.
