# react-pop-a-window

> 标签: draggable, floating-window, non-modal, pointer-events, portal, react, resizable, window

## 简介

Non-modal, draggable, resizable floating windows for React. The surface behind stays live. Self-contained styling via CSS custom properties, zero host dependencies, peer-dep on React only.
