# requirement-manager

> 标签: agent, agile, requirement, requirement-management, skill, teambition, 看板, 进度统计, 需求拆解, 需求管理

## 简介

需求管理 Agent Skill：需求下发 → 分析拆解 → 进度自动统计 → 图文看板汇报，可选 Teambition 双向同步。含标准 SKILL.md（跨 AI 工具可用）与 reqm CLI（终端命令）。
