# recalibrate-cryptocurrency-portfolio-allocation

> 标签: allocation, crypto, cryptocurrency, fintech, portfolio

## 简介

determines trades necessary to redistribute a cryptocurrency portfolio so that its FIAT value aligns with a desired percentage spread.
