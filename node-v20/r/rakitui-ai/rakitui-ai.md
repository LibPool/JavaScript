# rakitui-ai

> 标签: ai, claude, component, design, frontend, mcp, model-context-protocol, selection, tool, ui

## 简介

An intelligent UI component design selection tool built on the Model Context Protocol (MCP). Allows AI assistants to present multiple UI designs for user selection.
