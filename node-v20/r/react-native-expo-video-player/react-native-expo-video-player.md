# react-native-expo-video-player

> 标签: controls, expo, expo-video, fullscreen, gesture, player, react-native, video

## 简介

基于 expo-video 的功能丰富的 React Native 视频播放器组件，内置自定义控制栏、全屏手势、倍速切换等功能。
