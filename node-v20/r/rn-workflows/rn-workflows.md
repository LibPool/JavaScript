# rn-workflows

> 标签: cd, ci, codegen, expo, fastlane, github-actions, gitlab-ci, react-native, workflows

## 简介

Open-source CLI to generate Fastlane + GitHub Actions + GitLab CI from a single YAML config for React Native / Expo projects.
