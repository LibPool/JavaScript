# redstudio-mcp

> 标签: claude, cms, cursor, hosting, mcp, model-context-protocol, redstudio, website-builder

## 简介

MCP server that lets AI assistants build and edit websites hosted on RedStudio: pages, navigation, media, bookings, site settings and blog posts.
