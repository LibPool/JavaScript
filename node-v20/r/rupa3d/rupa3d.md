# rupa3d

> 标签: 3d, asset-validation, blender, cad, draco, glb, gltf, mcp, mcp-server, model-context-protocol, opencascade

## 简介

MCP server that builds and proves 3D assets: checks any GLB against a spec without Blender, OCCT b-rep CAD, and embeds the measured certificate inside the GLB.
