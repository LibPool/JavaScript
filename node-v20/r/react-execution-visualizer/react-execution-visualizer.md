# react-execution-visualizer

> 标签: debugging, devtools, execution-flow, hooks, profiler, prop-drilling, react, rerender, useEffect, visualizer, why-did-you-render

## 简介

Wrap any React subtree and see its full execution flow in real time: renders and why, hook values, state updates, commits, effects, callbacks, memos, events, fetches, timers, and prop drilling.
