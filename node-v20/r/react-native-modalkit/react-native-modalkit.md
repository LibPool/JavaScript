# react-native-modalkit

> 标签: animated, bottom-sheet, dialog, gesture-handler, modal, modalkit, react-native, react-native-modal, reanimated, swipe, typescript

## 简介

A modern, Reanimated-first, fully-customizable Modal for React Native — drop-in replacement for react-native-modal with imperative API, gesture v2 swipes, and built-in stacking.
