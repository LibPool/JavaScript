# react-toolkits

> 标签: JavaScript

## 简介

一套面向企业级应用的前端工具集，基于 React、Ant Design 与 TanStack Query。开箱即用的应用壳、权限/菜单、通用列表（分页/无限滚动）、抽屉/弹框表单与国际化支持，助你快速搭建一致、可维护的中后台应用。
