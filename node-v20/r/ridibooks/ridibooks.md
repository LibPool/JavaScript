# ridibooks

> 标签: JavaScript

## 简介

리디북스 책장 긁개. 리디북스 책장을 보니 어느덧 1000권이 넘었길래 대부분 만화책이겠지 하고 만들어봤는데 의외로 절반만 만화책이었습니다.
