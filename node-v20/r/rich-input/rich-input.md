# rich-input

> 标签: autocomplete, custom-element, custom-highlight-api, keyword-search, opaque-range, rich-input, search-input, web-components

## 简介

A rich input field with keyword-based autocomplete and in-input highlighting powered by <datalist>, OpaqueRange, and the Custom Highlight API
