# rfc7946-to-d3

> 标签: d3, geojson

## 简介

Converts rfc7946 geojson polygons to d3 compatible ones: d3 requires clockwise winding whereas rfc7946 specifies the opposite. See https://github.com/d3/d3-geo/pull/79
