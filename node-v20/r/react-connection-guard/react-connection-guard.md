# react-connection-guard

> 标签: connectivity, detection, hook, internet, network, offline, online, react, typescript

## 简介

Reliable real internet connectivity detection for React — goes beyond navigator.onLine with live HTTP probing, exponential backoff, connection quality reporting, and an offline action queue.
