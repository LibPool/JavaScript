# react-native-sms-consent-api

> 标签: android, one-time-password, otp, react-native, react-native-module, react-native-otp-read, react-native-sms, react-native-sms-consent-api, react-native-sms-user-consent, sms, sms-consent, sms-verification, user-consent

## 简介

A lightweight React Native module for Android's SMS User Consent API. Easily retrieve verification codes from SMS without full SMS permissions.
