# routes-to-nginx-conf

> 标签: configuration, nginx, routes

## 简介

Convert routing information in JSON to Nginx configuration statements. Currently uses environment variables to set PORT and SERVER_NAME appropriately.
	Example:

	...
	var routes = require("routes.json");
	var nginx_conf = require("routes-to-nginx-conf");
