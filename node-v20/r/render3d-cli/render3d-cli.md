# render3d-cli

> 标签: JavaScript

## 简介

Simple nodejs CLI to 3d render models using [webgi](https://webgi.dev/) in a chrome headless browser.

- 官网：https://github.com/repalash/render3d-cli
- 源码仓库：git://github.com/repalash/render3d-cli.git
