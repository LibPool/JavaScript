# react-native-paper-navigation-theme-context

> 标签: context, darkmode, lightmode, react, react-native, react-native-paper, react-navigation, theme, useColorScheme

## 简介

Theme Context for react-native (needs react, react-native and react-native-paper), to support Light, Dark and Default (your device) theme for your react-native-paper and react-navigation components.
