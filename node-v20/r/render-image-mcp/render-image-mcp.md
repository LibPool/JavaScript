# render-image-mcp

> 标签: JavaScript

## 简介

Render structured information into shareable PNG images, locally — an MCP server for turning query results into pictures. First tool: render_table_image (auto column widths, CJK + emoji, numeric right-align, zebra rows). Pure local drawing via @napi-rs/ca
