# react-ui-pixel

> 标签: JavaScript

## 简介

一个基于 React 19 + TypeScript 的像素风格（Pixel / 8-bit）组件库，提供 70+ 个组件，API 风格贴近 [Ant Design](https://ant.design)，视觉风格致敬经典 8-bit 游戏。
