# react-native-markdown-kit

> 标签: markdown, markdown-renderer, parser, react-native, react-native-markdown, rn-markdown, text

## 简介

A lightweight, zero-dependency Markdown renderer for React Native — headings, bold, italic, strikethrough, inline code, code blocks, lists, blockquotes, links and horizontal rules.
