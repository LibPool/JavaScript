# react-recheck

> 标签: debug, fps, performance, profiler, re-render, react, react-native, why-did-you-render

## 简介

Dev-time performance diagnostics for React & React Native: re-render tracking, per-render object/array/function recreation detection, method-call timing, FPS / jank monitoring and an in-app debug panel.
