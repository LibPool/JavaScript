# radio-color-system

> 标签: color, color-system, palette, svelte

## 简介

Radio Color System is a color system for Svelte that creates background color palettes with the given color and adds text with the right contrast ratio on that background. Its main purpose is to improve accessibility by ensuring that text is legible again
