# rt-convert-js

> 标签: conversion, dcmjs, dicom, dicom-seg, medical-imaging, radiotherapy, rtstruct, segmentation

## 简介

Convert between DICOM RT Structure Sets and DICOM Segmentation, with every lossy step recorded in provenance. Built on rt-geometry-js, rtstruct-js, and dicom-seg-js.
