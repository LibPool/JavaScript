# react-native-sip-voice

> 标签: calling, callkit, connectionservice, expo, react-native, sbc, sip, sip.js, voip, webrtc

## 简介

Carrier-agnostic VoIP calling for React Native: SIP.js over WebSocket + react-native-webrtc audio, native CallKit (iOS) and ConnectionService (Android), and an optional WhatsApp-style call UI.
