# react2npm

> 标签: npm, react, react2npm

## 简介

react2npm is an easy-to-use npx command that generates a complete React component project, ready to be published as an npm package.

## 官网

- 官网：https://docs-react2npm.vercel.app/
- 源码仓库：git+https://github.com/flexdiv/npx-react2npm.git
- npm 页面：https://www.npmjs.com/package/react2npm
