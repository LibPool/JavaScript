> 标签: bootstrap, breakpoint, matchmedia, media-query, responsive, ssr, tailwind, typescript, viewport

## 简介

Tiny, dependency-free, type-safe breakpoint state for the browser. Built on matchMedia, SSR-safe, framework-agnostic.
