# release-utils

> 标签: JavaScript

## 简介

Tools for incrementing versions and tagging projects in Git. Also contains a script for packaging npm modules and uploading them to S3 which is useful for deploying closed-source npm modules.

## 官网

- 源码仓库：git://github.com/ccare/s3-release.git
