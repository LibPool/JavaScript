# rtl-mcp

> 标签: ai-agent, arabic, bidi, hebrew, i18n, llm-tools, mcp, model-context-protocol, normalization, rtl

## 简介

MCP server that gives coding agents right-to-left awareness: lint layout for RTL breakage, normalise Arabic text, and detect script direction.
