# react-vfor

> 标签: babel, jsx, jsx-loops, react, react-plugin, react-vite-plugin, v-for, vite, vite-plugin, vue-syntax

## 简介

`ReactVFor` is a Vite/React plugin that allows you to use Vue-like `v-for` syntax in React components.
