# react-native-voice-glow

> 标签: agent, ai, audio, expo, glow, microphone, react-native, reanimated, siri, skia, visualizer, voice

## 简介

Sound-reactive glow for React Native and Expo: a colorful beam along the bottom edge of a chat input or phone screen that rises and blooms with a voice. Skia + Reanimated, runs on the UI thread.
