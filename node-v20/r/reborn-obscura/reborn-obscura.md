## 简介

Obscura(h4ckf0r0day/obscura · Apache-2.0) — 러스트로 만든 가벼운 AI 에이전트용 헤드리스 브라우저의 공식 릴리스 바이너리를 실행할 때 GitHub 에서 받아 내 사용자 폴더에 풀고, 실제로 실행되는지 확인하고, 클로드 코드에서 쓰는 법(퍼피티어·플레이라이트 연결, MCP)을 한국어 안내 스킬로 더합니다. 바이너리는 이 패키지에 들어 있지 않습니다.
