# rulemux

> 标签: agents, agents-md, ai-coding-agent, claude-code, codebuddy, codex, opencode, prompt-caching, rulemux, rules, trae, workbuddy

## 简介

One set of rules, delivered to every AI coding agent: copies the rule files you declare into each agent's native workspace rules directory, with the same effect and token cost as writing AGENTS.md by hand.
