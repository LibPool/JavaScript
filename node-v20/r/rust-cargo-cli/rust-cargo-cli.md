# rust-cargo-cli

> 标签: bin, cargo, cli, rust, rust-toolchain, rustc, rustup

## 简介

Rust toolchain as npm CLI package — automatically downloads rustup and installs cargo, rustc, rustup, rustfmt and rustdoc for the current platform
