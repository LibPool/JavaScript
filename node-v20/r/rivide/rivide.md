# rivide

> 标签: aes-gcm, cryptography, dilithium, fips-203, fips-204, kyber, ml-dsa, ml-kem, nist, post-quantum, pqc, quantum-safe, sha3

## 简介

Official Node.js native bindings for Rivide Post-Quantum Cryptography (NIST FIPS 203 ML-KEM & NIST FIPS 204 ML-DSA) C99 Library.
