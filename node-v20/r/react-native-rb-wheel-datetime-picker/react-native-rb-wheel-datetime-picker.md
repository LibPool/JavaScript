# react-native-rb-wheel-datetime-picker

> 标签: date, date-picker, date-time-picker, datepicker, datetime, datetime-picker, picker, react-native, scroll-picker, time, time-picker, timepicker, wheel, wheel-datepicker, wheel-timepicker

## 简介

A customizable, smooth, and haptic-enabled **wheel-style date picker** for React Native. It uses `FlatList` to simulate iOS-style scroll wheels, wrapped inside a bottom sheet for a modern UI.
