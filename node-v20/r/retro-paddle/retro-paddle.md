# retro-paddle

> 标签: arcade-game, browser-game, canvas-game, game, html5-game, javascript-game, multiplayer, no-dependencies, paddle, powerups, retro, retro-game, two-player, vertical

## 简介

A vertical paddle arcade game for the browser, with a retro feel, power-ups, power-downs, mines and obstacles. Drop it onto any web page with one constructor call.
