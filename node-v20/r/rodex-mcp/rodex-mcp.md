# rodex-mcp

> 标签: cloudflare, database, mcp, model-context-protocol, rodexdb, serverless

## 简介

RodexDB as a stdio MCP server — connect ANY MCP client (Claude Desktop, VS Code, local agents) to a RodexDB gateway. Point it at your own deploy or the live instance.
