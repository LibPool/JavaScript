# route-action-gen

> 标签: cli, codegen, form-actions, nextjs, react-hooks, route-handler, server-actions, type-safe, zod

## 简介

A code generation CLI and runtime library that produces type-safe route handlers, client classes, React hooks, server functions, form actions, and form components from declarative route config files for Next.js App Router.
