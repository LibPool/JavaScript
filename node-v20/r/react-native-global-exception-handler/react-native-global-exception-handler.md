# react-native-global-exception-handler

> 标签: android, crash-reporting, error-boundary, error-handling, exception-handler, fabric, global-error-handler, ios, library, mobile, native-modules, react-native, restart-app, turbomodules, typescript, uncaught-exception

## 简介

A modern, cross-platform React Native library to capture uncaught JS & native exceptions, show custom error UIs, and optionally restart the app. Supports TurboModules, Fabric, and both new/old architectures.
