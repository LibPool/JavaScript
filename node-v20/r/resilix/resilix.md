# resilix

> 标签: adaptive-concurrency, backpressure, bulkhead, circuit-breaker, cloudflare-workers, concurrency-limit, fault-tolerance, hedging, load-limiting, load-shedding, rate-limit, rate-limiter, resilience, retry, retry-budget, slow-call, throttle, timeout, typescript, zero-dependency

## 简介

Load limiting for JavaScript: adaptive concurrency limiting and slow-call circuit breaking. Sheds load when an upstream slows, not just when it errors.
