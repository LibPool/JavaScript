# radarscope

> 标签: air-traffic-control, atc, aviation, flight, ifr, radar, svelte, svg

## 简介

Aviation-themed SVG primitives: top-down radar scopes, aircraft blips, runways, waypoints. Framework-agnostic core + Svelte 5 adapter.
