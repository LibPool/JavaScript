# raglens

> 标签: evaluation, langchain, llm-evaluation, ollama, rag, ragas, typescript

## 简介

RAGAS-style RAG evaluation metrics for TypeScript — faithfulness, answer relevancy, context precision & recall. Provider-agnostic, zero required runtime dependencies.
