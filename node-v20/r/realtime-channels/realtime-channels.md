# realtime-channels

> 标签: appsync, appsync-events, aws, channels, expo, pubsub, react, react-native, realtime, websocket

## 简介

Tiny, dependency-free realtime channel client with pluggable transports. Ships an AWS AppSync Events adapter that runs unchanged in browsers, React Native (including Expo Go) and Node.
