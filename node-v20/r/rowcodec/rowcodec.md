# rowcodec

> 标签: aggregate, drizzle, join, kysely, mapper, nest, orm, prisma, row, sql, typescript

## 简介

Map flat ORM rows (left joins) into nested, aggregated domain objects. ORM-agnostic, functional, fully type-inferred.
