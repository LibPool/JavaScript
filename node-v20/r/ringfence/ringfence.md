# ringfence

> 标签: anti Shai-Hulud, bubblewrap, bun, bwrap, credentials, docker, install, isolation, lifecycle script, npm, pnpm, postinstall, protection, sandbox, secrets, security, supply chain attack, supply-chain, worm, yarn

## 简介

Sandbox npm/pnpm/yarn/bun install with bwrap (Linux) or Docker (macOS) to keep secrets in the working directory and host $HOME out of reach of postinstall scripts.
