# reasonix-termux

> 标签: aarch64, agent, ai, android, arm64, binary, cli, coding-agent, deepseek, deepseek-reasonix, prebuilt, reasonix, termux

## 简介

Prebuilt reasonix CLI binary for Termux (Android/aarch64). Auto-built from esengine/DeepSeek-Reasonix with GOOS=android GOARCH=arm64.
