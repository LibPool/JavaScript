# retry-circuit

> 标签: api, async, backoff, circuit-breaker, exponential-backoff, fetch, jitter, resilience, retry, typescript

## 简介

Universal retry utility with exponential backoff, jitter, timeout and circuit-breaker for any async function — works in Node and browsers.
