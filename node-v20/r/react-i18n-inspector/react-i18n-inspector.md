# react-i18n-inspector

> 标签: component, debug, developer-tools, devtools, i18n, i18next, inspector, locale, react, react-intl, translation

## 简介

Hover any element to see which React component renders it — plus the i18n translation key behind the text, so you can grep straight to the source.
