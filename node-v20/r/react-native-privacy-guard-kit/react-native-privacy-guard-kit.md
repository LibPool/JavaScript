# react-native-privacy-guard-kit

> 标签: android, ios, react-native

## 简介

A production-ready React Native library to protect sensitive app content — disable screenshots, detect screen recording, guard the app switcher, block copy/paste, and listen to capture events. Fully typed, hook & provider support, New Architecture ready,
