# react-threat-map

> 标签: attack-map, canvas, cyberattack, d3-geo, react, security, soc, threat-map, visualization, world-map

## 简介

A React component that renders animated cyberattack threats on a static world map, with intelligent per-region aggregation and first-class US state support.
