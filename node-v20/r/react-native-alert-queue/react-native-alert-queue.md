# react-native-alert-queue

> 标签: Alert.alert, alert, alert-queue, async, async-await, confirmation-dialog, dialog, modal, popup, promise, queue, react native alert, react native dialog, react native modal, react-native, ui

## 简介

React Native alert & dialog library. Queue multiple alerts, use async/await, and replace Alert.alert with a customizable, promise-based modal system.
