# react-native-image-with-progress-bar

> 标签: activity-indicator, activityindicator, image, image-loading, image-progress-bar, image-progressbar, image-spinner, loading, loading-image, progress-bar, progressbar, react-native, react-native-image-loading, react-native-loading-image, spinner

## 简介

A react-native image component that uses the content-length HTTP header to display a progress bar showing the progress of downloading an image from a http url
