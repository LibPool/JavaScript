# react-lazy-dropdown

> 标签: Api Calls, api call on scroll, async filtering, async lazy loading options, checkbox, combo-box, combobox, component, components, drop-down, dropdown, filter, filterable, lazy filtering, lazy loading, multi-select, multiselect, option pagination async, options, react, select, sort, sortable, tag-container, tags, tags-container, ui

## 简介

[react-lazy-dropdown] is a very useful react component for multi selection dropdown based on lazy loading option by API calls with async lazy Filtering, Sorting and Tags with custom functions can be provided from the outside
