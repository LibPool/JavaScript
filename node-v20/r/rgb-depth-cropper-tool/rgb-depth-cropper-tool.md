# rgb-depth-cropper-tool

> 标签: computer-vision, cropper, depth, depth-maps, desktop, download, electron, image-processing, interactive, numpy, reset, rgb, validation

## 简介

A modern Electron desktop app for interactively cropping RGB images and their corresponding depth maps with integrated smart validation, reset functionality, and organized download structure
