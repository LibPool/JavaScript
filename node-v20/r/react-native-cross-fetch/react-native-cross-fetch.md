# react-native-cross-fetch

> 标签: cross-fetch, cross-fetch-adapter, cross-fetch-adapter-fetch, cross-fetch-adapter-xhr, fetch, react-native, react-native-cross-fetch, react-native-fetch, xhr

## 简介

轻量请求库：三端可用（RN iOS/Android + Web），fetch 优先，必要时自动降级 XHR。
