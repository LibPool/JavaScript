# robotirremote.ino

> 标签: arduino, avr, gcc, ino, leo, make, uno, yun

## 简介

This library is based on the Ken Shirriff IR-Remote library and is used to send commands to the Arduino Robot Control Board. Packaged for the leo build system.

## 官网

- 官网：https://github.com/shirriff/Arduino-IRremote
- npm 页面：https://www.npmjs.com/package/robotirremote.ino
