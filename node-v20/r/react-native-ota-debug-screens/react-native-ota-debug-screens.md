# react-native-ota-debug-screens

> 标签: @expo/ui, debug, eas-update, expo, expo-updates, ota, update-channel

## 简介

Debug screens for Expo apps that use expo-updates: inspect the running bundle, check and load updates, and switch between the update channels you allow. Requires Expo SDK 56+; does not work without Expo.
