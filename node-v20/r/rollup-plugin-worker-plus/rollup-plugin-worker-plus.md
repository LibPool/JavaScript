# rollup-plugin-worker-plus

> 标签: Web Worker, Worker, rollup-plugin, vite-plugin

## 简介

基于 Web Worker 实现的多线程计算方法，提供了 Rollup， Vite 钩子，可让项目中的 JS 模块多线程运行
