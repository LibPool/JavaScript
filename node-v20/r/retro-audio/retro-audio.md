# retro-audio

> 标签: 8-bit, audio, chiptune, game-audio, gameboy, music, retro, sfx, sound, synthesizer, tracker, web-audio

## 简介

Lightweight, embeddable Web Audio synthesizer engine that emulates 8-bit sound hardware (Game Boy DMG style)
