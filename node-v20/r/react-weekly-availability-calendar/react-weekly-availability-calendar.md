# react-weekly-availability-calendar

> 标签: appointment, availability, availability-picker, booking, calendar, drag-and-drop, react, react-component, scheduler, scheduling, time-picker, time-slots, timetable, typescript, weekly-calendar, weekly-scheduler

## 简介

A customizable, draggable weekly availability calendar component for React. Create, resize, move time slots with zero external dependencies.
