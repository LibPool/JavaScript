# rsbuild-plugin-deploy

> 标签: JavaScript

## 简介

`rsbuild-plugin-deploy` 是一个功能强大的部署插件，旨在通过 SSH 连接将文件自动化地部署到远程服务器上。该插件与 `rsbuild` 构建系统高度集成，使得部署流程更加流畅和可控。
