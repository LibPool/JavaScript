> 标签: adonisjs, api, api-documentation, bun, cli, deno, elysia, express, fastify, hapi, hono, koa, nestjs, newman, nextjs, nuxt, openapi, postman, postman-collection, rest, sveltekit

## 简介

Generate a complete Postman collection from your Node.js, Bun or Deno API (Express, Fastify, NestJS, Koa, Hono, Elysia, Hapi, Next.js, Nuxt, SvelteKit, AdonisJS and more) with one command. No OpenAPI, decorators or running server needed.
