# react-native-get-media

> 标签: action, camera, gallery, image, media, permission, photo, picker, sheet

## 简介

Get media (photo/camera) easily without worrying about permission, without worrying if user block permission, without worrying either user pick camera or gallery. Just focus on your app, we handle media request thingy for you
