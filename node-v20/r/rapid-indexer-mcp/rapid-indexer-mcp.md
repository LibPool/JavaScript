# rapid-indexer-mcp

> 标签: claude, cursor, google-indexing, indexing, mcp, model-context-protocol, rapid-indexer, seo

## 简介

Model Context Protocol server for Rapid Indexer: submit URLs to Googlebot, check index status and manage traffic campaigns from Claude, Cursor, ChatGPT and other MCP hosts.
