# relaydance-skill

> 标签: agent-skill, ai-video, claude-code, claude-skill, image-to-video, relaydance, seedance, seedance-2-5, text-to-video, video-generation

## 简介

Agent skill for Seedance 2.5 and 2.0 AI video generation via RelayDance. Text-to-video, image-to-video, clips up to 30 seconds, up to 30 reference images, 4K upscaling. Works with Claude Code, Cursor, Codex.
