# react-leaflet-multi-options-polyline

> 标签: leaflet, multi-options-polyline, polyline, react, react-leaflet

## 简介

Provides a React component to enable multiple styles for a polyline in a react-leaflet map, based on Leaflet.MultiOptionsPolyline from hgoebl(https://github.com/hgoebl/Leaflet.MultiOptionsPolyline).
