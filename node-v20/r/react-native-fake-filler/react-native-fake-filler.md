# react-native-fake-filler

> 标签: detox, e2e, expo, fake-data, faker, form-filling, maestro, mock-data, qa, react-native, testing, typescript

## 简介

Intelligent, zero-config fake form filling for React Native. Auto-detects fields and populates them with realistic, unique, validation-aware fake data for development, QA, and automated testing.
