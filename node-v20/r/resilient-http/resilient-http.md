# resilient-http

> 标签: JavaScript

## 简介

Zero-dependency, fetch-first HTTP resilience toolkit: retries with backoff/jitter, per-attempt timeout + total deadline, idempotency-key, interceptor hooks, and standardized errors. Node.js, Bun, browsers.
