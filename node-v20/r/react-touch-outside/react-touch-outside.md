# react-touch-outside

> 标签: 2025, a11y, accessibility, bundle-size, cjs, click, cross-platform, detection, dropdown, esm, event-listener, hook, lightweight, mobile, modal, modern, outside, overlay, performance, popover, react, react-native, responsive, touch, tree-shakeable, typescript, universal, web, zero-dependencies

## 简介

A modern, performant React hook and component for detecting clicks/touches outside of elements. Works with React and React Native. Zero dependencies, TypeScript ready, tree-shakeable.
