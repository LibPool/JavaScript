# react-expo-in-app-updater

> 标签: android, app update, flexible update, immediate update, in-app updates, lightweight library, mobile updates, react-native, react-native-android, update flow

## 简介

Keep your app fresh—without users ever needing to visit the Play Store or App Store. This library enables native in-app updates for React Native on both Android and iOS, ensuring everyone is always on the latest version.
