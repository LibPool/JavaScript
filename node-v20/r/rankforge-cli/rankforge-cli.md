# rankforge-cli

> 标签: astro, audit, cli, core-web-vitals, crawler, lighthouse, mcp, nextjs, nuxt, robots, seo, sitemap, structured-data, sveltekit, technical-seo

## 简介

Deterministic technical-SEO audit from your terminal. Crawls a site, measures real issues (metadata, indexing, images, links, schema, performance), prints a scored report and ready-to-apply patches. No AI, no API keys, no telemetry.
