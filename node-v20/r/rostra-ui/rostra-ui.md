# rostra-ui

> 标签: a11y, accessibility, admin, components, css, dark-mode, dashboard, design-system, headless, internal-tools, react, tokens, ui, wcag, zero-dependencies

## 简介

A component system for admin panels and internal corporate tools: four themes, four densities, a dependency-free CSS core, an optional React layer, verified WCAG 2.1 AA contrast, and a separate build supporting IE10+
