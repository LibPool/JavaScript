# regexp.escape

> 标签: RegExp, ecmascript, es-shims API, escape, polyfill, regex, regular expression, shim

## 简介

A robust ES3-compatible polyfill for the `RegExp.escape` proposal - see https://github.com/tc39/proposal-regex-escaping
