# redai-automation-web-sdk

> 标签: JavaScript

## 简介

TypeScript SDK for RedAI Automation Web API - Zalo Personal automation, messaging, advanced sticker search. 100% compatible with automation-web backend. v1.9.4: Sync messaging APIs and DTOs with backend.
