# rt-geometry-js

> 标签: dicom, geometry, grid, histogram, mask, medical-imaging, radiotherapy, voxel

## 简介

Shared geometry core for DICOM imaging toolkits: GridGeometry, Mask3D, ScalarField3D, resampling-ready histograms, analytic phantoms, and comparison metrics. No DICOM, network, or filesystem dependency.
