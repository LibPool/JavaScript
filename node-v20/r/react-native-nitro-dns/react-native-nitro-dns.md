# react-native-nitro-dns

> 标签: android, dns, ios, network, nitro, nodejs, react-native

## 简介

Blazing-fast Node.js `dns` for React Native. Built with Nitro (JSI) & Rust, supporting DoH/DoT/DoQ and global native network interception.
