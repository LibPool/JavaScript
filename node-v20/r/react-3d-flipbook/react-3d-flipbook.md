# react-3d-flipbook

> 标签: 3d, animation, book, book-viewer, catalog, ebook, flipbook, magazine, page-curl, page-flip, page-turner, pdf, pdf-viewer, react, react-component, reader, three.js, threejs, typescript, webgl

## 简介

A modern React library for creating beautiful, interactive 3D flipbooks with realistic page-turning effects powered by WebGL and Three.js. Supports PDF loading, automatic page sizing, and customizable camera controls.
