# react-scaffold-ant

> 标签: JavaScript

## 简介

全局安装react-scaffold-ant; 使用命令react-scaffold init 项目名称 可创建一个可用项目模板; 模板中执行 npm install  npm start 可在浏览器看到效果。pro包为 npm run build;
