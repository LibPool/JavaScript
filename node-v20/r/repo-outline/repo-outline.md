# repo-outline

> 标签: ast, cli, codebase, diff, onboarding, outline, structure, tree, typescript, visualization

## 简介

Scan any repo or folder into an indexed structure tree - folders, files and TS/JS symbols - and see exactly what changed since the last scan. Outputs one self-contained HTML file. Fully offline, nothing is uploaded.
