# react-native-new-maps-directions

> 标签: android, ios, maps, react-native, react-native-maps, react-native-maps-directions, react-native-new-maps-directions

## 简介

TypeScript React Native component for rendering Google Maps directions and routes as polylines. Supports driving, walking, cycling, transit, and two-wheeler travel modes with full TypeScript support and automatic route fetching.
