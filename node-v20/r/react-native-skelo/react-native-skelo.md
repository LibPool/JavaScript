# react-native-skelo

> 标签: automatic, fabric, loading, loading-state, placeholder, react-native, reanimated, shimmer, skeleton, skeleton-loader, skeleton-screen, zero-config

## 简介

Automatic skeleton loading for React Native. Write your UI once, Skelo builds the loading state automatically.
