> 标签: android, animation, canvas, confetti, cpp, fireworks, high-performance, ios, jsi, native-rendering, new-architecture, nitro-modules, particle-animation, particle-effects, particle-system, particles, react-native, react-native-particle, react-native-skia, skia, snow, turbo-modules, visual-effects

## 简介

High-performance particle system for React Native — C++ engine via Nitro Modules with zero JS overhead. Runs entirely on the UI thread using Android Canvas & iOS Core Graphics. New Architecture ready.
