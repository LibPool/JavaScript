# reliz

> 标签: changelog, ci, cli, git-flow, gitflow, github-release, gitlab-release, nodejs, npm-publish, release, release-automation, semver, version, version-bump

## 简介

Release automation CLI for Node.js: semver version bump, auto CHANGELOG, Git Flow or linear workflow, optional npm publish & GitHub/GitLab releases. Zero dependencies, configurable, CI-ready.
