# react-graphviz

> 标签: JavaScript

## 简介

react-graphviz is a plugin for react, the flow control rules engine, which allows react to use graphviz to generate flow diagrams for the dependencies

- 源码仓库：http://github.com/jeffbski/react-graphviz.git
