# recursive-calc-element-coords

> 标签: JavaScript

## 简介

Get the position of an element relative to the document. The element can be nested inside absolute/relative/fixed elements, and it'll reliably get you the absolute coords. Returns an object {x: [number 0], y: [number 0]}
