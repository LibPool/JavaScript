# react-native-component-story

> 标签: react-native, storybook

## 简介

Uma biblioteca para facilitar a realização de QAs eficientes em componentes React Native. Permite manipular e alterar informações diretamente nos componentes, oferecendo uma alternativa prática ao Storybook, sem a necessidade de implementar cada component
