# retold-documentation-beacon

> 标签: beacon, chokidar, docs-lake, documentation, retold, sync, ultravisor

## 简介

Bidirectional sync between a documentation folder tree and a Retold Docs Lake. Watches a folder with chokidar and reconciles with the platform over /1.0/docs/* through a git 3-way merge. Runs standalone or supervised by Ultravisor.
