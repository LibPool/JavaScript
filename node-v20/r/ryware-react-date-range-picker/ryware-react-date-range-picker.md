# ryware-react-date-range-picker

> 标签: calendar, date-range, datepicker, i18n, portuguese, radix, react, ryware, shadcn, tailwind

## 简介

Enhanced DateRangePicker component for shadcn with Portuguese localization, DD/MM/YYYY support, configurable preset positioning, and improved styling. Built with Radix UI and Tailwind CSS.
