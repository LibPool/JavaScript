# rollup-plugin-disable-packages

> 标签: disable, fsevents, rollup-plugin

## 简介

Replace all `import {a, b, c} from 'myPackage'` statements with `const a = {}; const b = {}; const c = {};` and so on, effectively disabling those packages.
