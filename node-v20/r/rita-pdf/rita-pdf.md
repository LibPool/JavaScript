# rita-pdf

> 标签: documentation, handbook, markdown, mermaid, pdf, print, puppeteer

## 简介

Binds a directory of Markdown docs into a single typeset PDF handbook — cover, table of contents with real page numbers, mermaid diagrams, and syntax-highlighted code.
