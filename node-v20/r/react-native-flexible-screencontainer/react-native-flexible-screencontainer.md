# react-native-flexible-screencontainer

> 标签: bottomsheet, empty-state, error-handling, lightweight, loader, pull-to-refresh, react-native, safe-area, scrollView, shimmer, status-bar, typescript, view

## 简介

A lightweight and customizable UI library for React Native that includes dynamic status bar, loaders, shimmer effects, pull-to-refresh, error handling, safe area support, and bottom sheet implementation. Built with TypeScript for type safety.
