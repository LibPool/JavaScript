# regressionledger

> 标签: agent-memory, ai-coding-agent, claude-code, claude-code-hook, cursor, doom-loop, guardrail, regression, verification, vibe-coding

## 简介

Stop your coding agent from resurrecting fixes that already failed. A zero-dependency Claude Code hook + CLI that fingerprints every edit, links it to the test/build outcome, and HARD-BLOCKS the agent from re-applying a patch that previously failed — acro
