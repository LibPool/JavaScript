# ramexp

> 标签: JavaScript

## 简介

RAMEXP is the tool for mapping directories and counting its size Usage: ramexp [OPTIONS]    -v, --version       Display version    -h, --help          Display tools info    -d, --dist          Destination path of out files,    -p, --placer ..     Str
