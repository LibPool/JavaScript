# receiptrail-mcp

> 标签: agent-payments, escrow, mcp, proof-of-delivery, receipt, receiptrail, solana, usdc, x402

## 简介

ReceiptRail MCP (stdio bridge): issue and verify on-chain x402 delivery receipts on Solana. Hash-locked, verifiable proof of delivery for AI agent payments.
