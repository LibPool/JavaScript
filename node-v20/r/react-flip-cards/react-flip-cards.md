# react-flip-cards

> 标签: 3d, animation, clock, countdown, countdown-timer, counter, departure-board, digit, flip-card, flip-clock, flip-countdown, flip-numbers, lightweight, odometer, react, react-component, scoreboard, split-flap, ticker, timer, typescript, ui

## 简介

Tiny (~2kB), ref-driven 3D flip-card component for React. One flexible primitive for flip clocks, countdowns, counters, tickers and scoreboards.
