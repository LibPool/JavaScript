# react-native-nitro-rolling-number

> 标签: animated-number, counter, nitro, nitro-modules, odometer, react-native, rolling-number, ticker

## 简介

Native rolling number (odometer / ticker) view for React Native, built with Nitro. Digits roll natively when the value changes; supports currency prefix/suffix, shrink-to-fit and a loading shimmer.
