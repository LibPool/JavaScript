# raven-verify-js

> 标签: attestation, ed25519, raven, receipt, solana, verification

## 简介

Open, dependency-free local verifier for Raven receipt-v1: check a signed on-chain-evidence receipt offline against a published key.

- 官网：https://ravenattest.com
- npm 页面：https://www.npmjs.com/package/raven-verify-js
