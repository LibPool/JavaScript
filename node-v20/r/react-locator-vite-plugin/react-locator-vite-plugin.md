# react-locator-vite-plugin

> 标签: devtools, react, vite-plugin, vscode

## 简介

Tags JSX with source-location data at build time, for click-to-open-in-editor tooling that works on React 19 (where fiber._debugSource no longer exists). Companion to the React Locator Chrome extension.
