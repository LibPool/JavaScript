# redux-derive-middleware

> 标签: action, derive, middleware, reducer, redux

## 简介

* 用于从指定的action，在满足一定条件下，衍生出一个新的action，从而达到针对一定条件下的扎堆action在reducer中进行统一处理，而不用对每一个action都进行判断
