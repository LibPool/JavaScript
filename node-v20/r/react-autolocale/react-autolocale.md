# react-autolocale

> 标签: i18n, l10n, localization, react, translation, vite

## 简介

Wrap your React + Vite app in <AutoScale> and get fully translated static pages (/fr, /es, ...). Translations are generated by an explicit CLI step with a local model, OpenAI or Anthropic; builds never translate.
