# rtdose-js

> 标签: dcmjs, dicom, dose-volume-histogram, dvh, medical-imaging, radiotherapy, rt-dose, rtdose

## 简介

DICOM RTDOSE reading and dose-volume histograms (D95/V20/mean), built on rt-geometry-js. Research/QA tooling — not a treatment planning system.
