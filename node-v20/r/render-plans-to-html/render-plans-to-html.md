# render-plans-to-html

> 标签: claude-code, codex, html, markdown, mermaid, plan, renderer, review, skill, spec

## 简介

Tool-agnostic renderer that turns Markdown plans/specs/reviews into a single self-contained interactive HTML dashboard. Available as a skill for Claude Code and Codex.
