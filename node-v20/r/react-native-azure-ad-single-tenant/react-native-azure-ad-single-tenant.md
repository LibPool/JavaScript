# react-native-azure-ad-single-tenant

> 标签: AzureAD, Microsoft Account, Microsoft Authentication

## 简介

A React Native module for Azure AD enpoint version 2. This module implements Azure AD Single Tenant Authentication using pure React-Native with no other libs.
