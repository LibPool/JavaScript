# reveal.js-tagteam

> 标签: hidden, hide, plugin, portfolio, reveal, reveal-plugin, reveal.js

## 简介

A plugin for Reveal.js that is used to dynamically show only certain sections in presentations when you don't want to show everything. It uses URL parameters to set the needed sections.
