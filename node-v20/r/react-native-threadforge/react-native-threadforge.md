# react-native-threadforge

> 标签: background threads, c++ worker pool, multithreading, native, native modules, react, react-native, react-native optimization, react-native performance, threadforge

## 简介

React Native multithreading toolkit for executing JavaScript functions on background threads using a native C++ worker pool with Hermes and JSI compatibility.
