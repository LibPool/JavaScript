# reactwright

> 标签: browser-native, document, headless-chromium, jsx, paged-js, paged-media, pagination, pdf, react, typesetting, typography

## 简介

Author paginated documents in React. Two-reconciler engine that compiles JSX content + template trees to CSS Paged Media HTML and PDF via Paged.js + headless Chromium.
