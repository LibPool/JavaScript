# rtcmulticonnection-v3

> 标签: android, chrome, firefox, ie, internet-explorer, javascript, javascript-library, library, muaz, muaz-khan, multirtc, opera, peer, peer-to-peer, peer2peer, rtcmulticonnection, rtcmulticonnection.js, rtcweb, webrtc, webrtc-experiment, webrtc-library

## 简介

RTCMultiConnection is a WebRTC JavaScript wrapper library runs top over RTCPeerConnection API to support all possible peer-to-peer features.
