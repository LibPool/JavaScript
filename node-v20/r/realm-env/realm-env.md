# realm-env

> 标签: JavaScript

## 简介

[Realm Env](https://www.npmjs.com/package/realm-env) package builds [MongoDB Realm](https://docs.mongodb.com/realm/) functions/triggers on multiple environments. Main purpose of this function is to avoid writing same function twice for  development/stagin
