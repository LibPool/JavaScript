# refactron

> 标签: ai-agents, ast, autofix, blast-radius, ci, cli, code-quality, code-review, mcp, python, refactoring, safety, static-analysis, testing, typescript, verification

## 简介

A verification layer for code change: verify any diff for a SAFE / UNSAFE / UNPROVEN verdict, from the CLI or over MCP.
