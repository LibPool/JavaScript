# react-perfect-zoomer

> 标签: image, image enhancement, image enlarge, image zoom, perfect zoom, photo zoom, react, react perfect zoom, react zoom, zoom

## 简介

React component which allow you to see exact part of image thumbnail in real dimensions next to it. Works also on mobile devices.
