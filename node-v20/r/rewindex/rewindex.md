# rewindex

> 标签: checkpoint, codex, codex-cli, hooks, rewind, snapshot, undo

## 简介

git-free /undo for OpenAI Codex CLI — automatic shadow-git snapshots before every file-mutating tool call, restore with one command. Never touches your project's git history.
