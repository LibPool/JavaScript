# react-native-video-burn-overlay

> 标签: android, avfoundation, camera, geotag, gps, image-overlay, ios, mediacodec, new-architecture, no-ffmpeg, react-native, react-native-overlay, react-native-video-overlay, text-overlay, timestamp, timestamp-camera, turbo-module, video, video-editing, video-overlay, video-processing, video-watermark, watermark

## 简介

Burn text or custom image overlays permanently into recorded video pixels using native platform APIs only (AVFoundation on iOS, MediaCodec + OpenGL ES on Android).
