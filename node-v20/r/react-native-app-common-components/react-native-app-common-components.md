# react-native-app-common-components

> 标签: JavaScript

## 简介

一套基于 **React Native** 的通用组件库，包含按钮、弹窗、遮罩层、轻提示等常用 UI 组件，支持 Android 和 iOS 平台，提供简洁易用的 API 和良好的交互体验。
