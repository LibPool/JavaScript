# rtk-optimistic-patch

> 标签: axios, fetch, optimistic-update, redux, redux-toolkit, rtk-query, trpc, typescript

## 简介

Config-driven optimistic updates (patch-by-id, auto-revert on failure) for RTK Query mutations — with adapters for tRPC, fetch, and axios base queries.
