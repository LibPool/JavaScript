# red-contrib-telegram-lists

> 标签: bot, list, node, node-red, telegram

## 简介

Node to support creation of lists using telegram, this plugin can create a list of items, allow you to add items to the list by sending telegram message and also remove items from the list, it comes in very handy when you want to quickly note something do
