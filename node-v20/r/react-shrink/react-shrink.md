# react-shrink

> 标签: avif, batch-processing, browser, client-side, compression, frontend, heic, image-compression, image-optimization, jpeg, nextjs, optimize, performance, png, react, resize, typescript, upload, vite, web-worker, webp

## 简介

Blazing-fast client-side image compression library for React with Web Worker support. Compress images 70-99% with WebP, AVIF, JPEG. Zero dependencies, TypeScript-first.
