# react-native-sms-gateway

> 标签: android, background-sms, react-native, react-native-android-sms, react-native-sms, react-native-sms-forwarder, react-native-sms-gateway, react-native-sms-listener, sms, sms-api, sms-broadcast, sms-event, sms-filter, sms-forwarder, sms-forwarding, sms-gateway, sms-http, sms-inbox, sms-listener, sms-otp, sms-react-native, sms-receiver, sms-sender, sms-service, sms-telegram

## 简介

React Native Android SMS gateway: listen, receive, forward, and send SMS to server, Telegram, or your app. Background SMS listener, HTTP/Telegram forwarding, SMS filter, event emitter, OTP, Android-only.
