# retm-library

> 标签: drag-and-drop, editor, email, email-builder, react, retm, retm-library, tailwindcss, template, tiptap

## 简介

RETM Library — embeddable React components for visual email template management. Ships <EmailTemplatePanel> (authoring) and <EmailTemplateViewer> (read-only browsing). Tailwind CSS v4 native.
