# react-native-device-wake-state

> 标签: android, ios, keyguard, lock, react-native, screen-off, wake

## 简介

React Native lock / screen-off detection plus keep-awake. Reports PowerManager + Keyguard on Android and iOS protected-data / lock notifications. Also blocks idle sleep (FLAG_KEEP_SCREEN_ON / idleTimerDisabled).
