# ragadjust

> 标签: Adjustment, Rag, Typesetting, Typography

## 简介

A bit of JavaScript to automatically fix the rag of any body of text. Where you allow your lines to break in a block of text can be very important for readability, and quite tricky within a fluid layout. With this script you can set how and where you want
