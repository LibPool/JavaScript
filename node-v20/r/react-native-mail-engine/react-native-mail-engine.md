# react-native-mail-engine

> 标签: android, attachments, email, idle, imap, inbox, ios, jakarta-mail, mail, mailbox, mailcore2, mime, new-architecture, nitro, nitro-modules, oauth2, react-native, smtp, turbomodule, xoauth2

## 简介

A maintained, cross-platform native IMAP + SMTP engine for React Native (Nitro module + Expo config plugin): MIME parsing, IDLE push, attachments, and first-class OAuth2/XOAUTH2 — so you can finally build a real in-app inbox. iOS via MailCore2, Android vi
