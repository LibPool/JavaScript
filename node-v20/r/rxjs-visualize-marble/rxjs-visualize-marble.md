# rxjs-visualize-marble

> 标签: JavaScript

## 简介

This is a library that houses the component for the [RxJS Visualize](https://rxjs-visualizes.explosionpills.com) project. You can install and import this module to acquire access to the `<rxjs-visualize-marble>` component to create your own visualizations
