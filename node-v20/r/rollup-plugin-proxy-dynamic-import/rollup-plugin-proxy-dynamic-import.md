# rollup-plugin-proxy-dynamic-import

> 标签: proxy-dynamic-import, rollup-plugin, vite-plugin

## 简介

Bundle static imported bindings from modules which will be dynamically imported somewhere, and treeshake those static imported bindings from the dynamic imported modules
