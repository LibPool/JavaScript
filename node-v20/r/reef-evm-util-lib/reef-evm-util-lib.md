# reef-evm-util-lib

> 标签: JavaScript

## 简介

A TypeScript SDK providing unified utilities to interact with the **Reef Network** — combining **Substrate (Reef chain)** and **EVM-compatible** tooling for contracts, tokens, NFTs, accounts, and more.
