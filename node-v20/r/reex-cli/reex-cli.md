# reex-cli

> 标签: api, api-builder, api-integration, cli, code-generator, hooks, openapi, postman, react, react-framework, react-query, reex, reex-api, reex-api-builder, reex-cli, rest-api, swagger, tanstack-query, typescript

## 简介

CLI for Reex API, the React framework for API integration. Generate TypeScript API clients and TanStack Query hooks from OpenAPI and Postman collections.
