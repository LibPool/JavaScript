# reborn-spec

> 标签: claude, claude-code, korean, skills, spec-driven-development, spec-kit, specification

## 简介

클로드가 코드를 쓰기 전에 명세부터 적게 하는 스킬을 클로드 코드 스킬 폴더에 놓고, 파일이 실제로 늘었는지 다시 셉니다. 순서는 GitHub spec-kit(MIT)과 같은 명세 → 계획 → 조각 → 코드이고, 단계마다 사람이 확인하기 전에는 다음으로 가지 않습니다. spec-kit 본체가 같은 폴더에 깔려 있으면 그쪽 /speckit-* 스킬로 넘깁니다.
