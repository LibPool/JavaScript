> 标签: android, call, caller, callkit, default dialer, dialer, phone, react native, react-native, react-native-android, react-native-module, role manager, telecom, voip

## 简介

React Native module for Android that lets your app request default dialer role, initiate phone calls, and integrate with the native call system.
