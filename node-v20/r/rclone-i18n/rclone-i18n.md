# rclone-i18n

> 标签: i18n, internationalization, rclone, rclone-api, rclone-client, rclone-rcd, rclone-remote-control, rclone-rest, rclone-sdk, translation

## 简介

Translate rclone RC responses (config/providers, options/info) using language packs fetched on demand.
