# react-native-apng-avif

> 标签: alpha, android, animated-avif, animated-png, animation, apng, avif, fabric, image, ios, libavif, react-native, react-native-component, react-native-web, sdwebimage, transparency, transparent-animation, web

## 简介

Animated APNG and AVIF with full alpha transparency for React Native on Android, iOS and Web. One component plays both and reads the format from the file. New and old architecture.
