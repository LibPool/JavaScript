# react-native-wearlink

> 标签: ble, bluetooth, gloryfit, health, qring, react-native, smartwatch, veepoo, wearable

## 简介

React Native TurboModule (Android + iOS) kết nối điện thoại với thiết bị đeo: đồng hồ GloryFit/UTE (Y25), vòng tay Veepoo (GE54), nhẫn QRing, thiết bị Bluetooth chuẩn — đo, lịch sử, cài đặt, thông báo, cuộc gọi, nhạc, báo thức
