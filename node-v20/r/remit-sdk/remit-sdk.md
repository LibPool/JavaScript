# remit-sdk

> 标签: agent, agentic-commerce, ai-safety, audit, authorization, autonomous-agents, payments, policy, remit

## 简介

The authorization boundary between autonomous agents and financial action. Bring your own model; REMIT decides what it is allowed to do.
