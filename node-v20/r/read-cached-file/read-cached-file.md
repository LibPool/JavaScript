# read-cached-file

> 标签: cache, cached, file, local, local-caching, local-file, network-requests, read, resource-consumption, save, slow, speed-up, time-consuming

## 简介

Cache the result of a slow and/or resource/time consuming operation (e.g. response from a server request, heavy computation) into a local file.
