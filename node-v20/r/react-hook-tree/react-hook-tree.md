# react-hook-tree

> 标签: children, collapsablecollapse, customisable, data-driven, expandable-tree, expandexpandable, hooks, nested, nodes, parent, react, react-component, react-hook-tree, tree, treeview

## 简介

Lightweight simple react hook nested tree view, children nodes are placed inside their parent node in DOM. The parent node has an outlet to keep all the children nodes.
