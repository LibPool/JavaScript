# rollingkit

> 标签: ema, max, mean, median, min, moving-average, pandas, percentile, rolling, sliding-window, statistics, stddev, time-series, typescript, variance, zero-dependency, zoo

## 简介

Zero-dependency sliding window / rolling statistics for TypeScript: mean, variance, stddev, min, max, sum, count, median, percentile, EMA. Port of Python pandas rolling() / R zoo.
