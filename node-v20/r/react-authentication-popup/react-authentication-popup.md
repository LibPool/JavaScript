# react-authentication-popup

> 标签: auth, auth-popup, authentication, authentication-popup, oauth2, oauth2-login, oauth2-popup

## 简介

A React Component where you can receive a token from external authentication by popup, supports Authorization Code and Implicit Grant flows.
