> 标签: cls, core-web-vitals, fcp, fid, frontend-monitoring, inp, javascript-performance, lcp, lighthouse, pagespeed, performance-analytics, performance-metrics, performance-monitoring, performance-observer, privacy-first, real-user-monitoring, rum, tree-shaking, typescript, web-performance, web-vitals, web-vitals-library, zero-tracking

## 简介

Zero-tracking web performance monitoring - measure Core Web Vitals, errors, and resource timing without compromising user privacy. TypeScript-first with tree-shaking support.
