# rn-app-rating

> 标签: android, android store rating, app rating, custom in-app rating, ios, ios store rating, mobile, react native app rating, react native component, react native in-app rating, react-native

## 简介

A react native component that allows you to collect user feedback and promotes users with a positive experience to rate your application on the store, via in-app rating.
