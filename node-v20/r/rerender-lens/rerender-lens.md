# rerender-lens

> 标签: debug, devtools, memo, performance, re-render, react, rerender, why-did-you-render

## 简介

Find avoidable React re-renders and what caused them. Reads the fiber tree like React DevTools, so nothing is patched: works with Fast Refresh, memo, forwardRef and classes. Structured reports, test assertions, and a DevTools bridge.
