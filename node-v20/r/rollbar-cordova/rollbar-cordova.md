# rollbar-cordova

> 标签: cordova, cordova-android, cordova-ios, ecosystem:cordova, plugin, rollbar

## 简介

Rollbar offical supported plugin for Cordova. Provides full Rollbar functionality for Javascript, and native iOS and Android environments.
