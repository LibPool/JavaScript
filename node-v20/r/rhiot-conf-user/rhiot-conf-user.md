# rhiot-conf-user

> 标签: JavaScript

## 简介

This is a javascript library to parse configuration files (conf-user.h) from firmware [Rhomb.IoT](https://rhiot.rhomb.io). It also can do diffs from two `conf-users.h` to detect changes not present in one of them.
