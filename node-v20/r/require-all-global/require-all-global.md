# require-all-global

> 标签: JavaScript

## 简介

A global version of the require-all module. Just pass in the relative path to the folder you wish to require! You can also use an optional resolution function in the 2nd parameter and an optional RegExp to match filenames against in the 2nd or 3rd paramet
