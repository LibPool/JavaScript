# @bluemanta/portdash

> 标签: cli, dashboard, dev-server, localhost, memory, ports, process-manager, watchdog

## 简介

A visual control panel for local dev servers — see every listening port, control it, and freeze (not kill) runaway memory before it takes the machine down.
