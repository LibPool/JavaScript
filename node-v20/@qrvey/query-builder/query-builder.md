# @qrvey/query-builder

> 标签: clickhouse, elasticsearch, opensearch, postgresql, qrvey, query, query-builder, sql, typescript

## 简介

Product-agnostic query builder that compiles one normalized query/mutation definition into engine-specific queries (SQL for PostgreSQL/ClickHouse, search DSL for Elasticsearch/OpenSearch).
