# @epa-wg/cem-components

> 标签: JavaScript

## 简介

Declarative custom-element primitives that consume the CEM theme. No shadow DOM — every component renders in the light DOM via [`@epa-wg/custom-element`](https://www.npmjs.com/package/@epa-wg/custom-element).
