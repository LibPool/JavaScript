# @rhizomatics/signalk-einklabel-genai-plugin

> 标签: eink, esl, genai, llm, signalk-category-hardware, signalk-category-instruments, signalk-node-server-plugin

## 简介

GenAI prompt generated labels for the eInk Electronic Shelf Label plugin. Contributes prompts as an alternative to hand-authored SVG templates.
