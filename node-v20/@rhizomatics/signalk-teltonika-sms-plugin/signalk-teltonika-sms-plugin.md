# @rhizomatics/signalk-teltonika-sms-plugin

> 标签: RutOS, anchor-alarm, notifications, signalk, signalk-category-notifications, signalk-node-server-plugin, sms, teltonika

## 简介

Deliver SignalK notifications as SMS via a Teltonika router's RutOS API, e.g. an anchor watch alert.
