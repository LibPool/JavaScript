# @esthernandez/vibe-sec-cli

> 标签: 626labs, api-keys, ci, claude-code, claude-code-plugin, leak-detection, secret-scanner, security, vibe-coding

## 简介

Headless security scanner for vibe-coded apps — tier-aware secret detection with severity tiers and CI-safe exit codes. Self-contained bundle of the Vibe Sec audit engine; defers to gitleaks/trufflehog when present, in-house Layer A/B/C fallback otherwise
