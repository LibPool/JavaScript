# @codecompose/envi

> 标签: ai-development, backup, cli, config, configuration, cursor, developer-tools, devtools, dotenv, encryption, env, environment, environment-variables, git-worktree, github, maml, monorepo, parallel-agents, restore, secret-management, tool, version-control, worktrees

## 简介

Envi makes it easy to capture files that live outside of version control (like .env and .dev.vars) from a codebase in a central location that can be version controlled, and restored for new checkouts and spawning git worktree instances.
