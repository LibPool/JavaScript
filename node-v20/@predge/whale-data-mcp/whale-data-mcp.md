# @predge/whale-data-mcp

> 标签: agent, base, mcp, model-context-protocol, polymarket, predge, prediction-markets, smart-money, usdc, whale-tracking, x402

## 简介

MCP server exposing the Predge Whale Data x402 API (Polymarket whale trades + smart-money signals) as tools. Pays USDC per call under the hood via an x402 client; the operator supplies a funded buyer key.
