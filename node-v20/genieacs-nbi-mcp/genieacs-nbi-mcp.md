# genieacs-nbi-mcp

> 标签: acs, cwmp, genieacs, isp, mcp, model-context-protocol, ont, read-only, tr-069

## 简介

Read-only MCP server for GenieACS (TR-069 ACS) NBI: inspect CPE/ONT devices, faults, tasks and files without any write access.
