# @advdominion/browserslist-to-targets

> 标签: JavaScript

## 简介

Преобразует конфиг [browserslist](https://github.com/browserslist/browserslist) в массив target-строк, совместимый с [esbuild](https://esbuild.github.io) и [Oxc](https://oxc.rs).
