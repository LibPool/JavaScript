# @orboto/mcp

> 标签: agents, ai, claude, copilot, cursor, mcp, model-context-protocol, orboto, project-management, tickets

## 简介

Model Context Protocol server for orboto - exposes tickets, projects, milestones, time, docs, primer-facts, alerts and absences as MCP tools for Claude Desktop / Cursor / Copilot Chat / any MCP-aware AI client.
