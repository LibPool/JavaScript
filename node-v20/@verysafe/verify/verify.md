# @verysafe/verify

> 标签: digital-credentials-api, eudi, eudi-wallet, openid4vp, verifier, verysafe

## 简介

The browser library for VerySafe's EU wallet verifier: the browser prompt first, then a link on a phone, then a QR code. A browser half for the page and a server half for Node.
