# @2forweb/create-symfony-fe-app

> 标签: controllers, frontend, react, stimulus, symfony, typescript, vite

## 简介

A tool to create a fancy vite based symfony front-end application where you can maintain your stimulus and react controllers in TypeScript on its own folder
