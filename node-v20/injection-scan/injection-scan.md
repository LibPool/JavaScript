# injection-scan

> 标签: agent, ai, guardrails, jailbreak, llm, mcp, prompt-injection, sanitize, security, tool-calling

## 简介

Flag prompt-injection attempts in tool results, web pages and files before an AI agent reads them. Hidden-text detection, sanitizing and wrapping helpers. Zero dependencies.
