# @varynttools/work-mcp

> 标签: agency, claude, mcp, model-context-protocol, project-management, task-management, time-tracking, varynt, varynt-work

## 简介

MCP server for Varynt Work (https://work.varynt.in/), project and client management for agencies — lets an AI assistant read and create tasks, log time, pull reports and check approvals using your own API token.
