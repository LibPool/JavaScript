# @a1soyo0/dsh-autostart

> 标签: autostart, background, deepseek-harness, dsh, dsh-plugin, task-scheduler, user-service, windows-autostart

## 简介

User-level AutoStart plugin for DeepSeek Harness (DSH): start DSH automatically on Windows boot before user login using Windows Task Scheduler with user credentials, preserving full user environment and DSH ACL sandbox compatibility.
