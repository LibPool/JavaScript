# @jolli.ai/workflow-cli

> 标签: cli, jolli, plugin

## 简介

Jolli Workflows — closed-source plugin for @jolli.ai/cli (adds the `workflow` command: local-run, runs, run-status). Discovered and loaded by the open-source `jolli` CLI when both are installed.
