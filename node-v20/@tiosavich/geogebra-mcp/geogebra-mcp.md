# @tiosavich/geogebra-mcp

> 标签: ai-tools, claude, codex, education, geogebra, math, mcp, model-context-protocol

## 简介

Model Context Protocol server for GeoGebra: construct, evaluate, export, and round-trip .ggb files from any MCP client (Claude Desktop, Claude Code, Cowork, Codex CLI, etc.).
