# @gomisarita/persistent-chatbot

> 标签: ai, anthropic, chat, chatbot, claude, llm, markdown, openai, persistent, react, streaming

## 简介

Drop-in AI chat widget: survives page refresh, streams tokens, renders markdown, keeps API keys on the server. Zero dependencies.
