# karin-plugin-selfmsg

> 标签: bilibili, karin, karin-plugin, kkk, message_sent, onebot11

## 简介

让 Karin 接受 OneBot11 的 message_sent（上报自身消息）事件，使其进入插件层；用于同账号多框架场景下让 kkk 收到其它框架发出的链接
