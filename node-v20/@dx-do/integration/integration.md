# @dx-do/integration

> 标签: JavaScript

## 简介

Integration base for DX Operational Observability (DXO2): staged entities, tagged metrics with one method per metric family, cumulative totals turned into PER_INTERVAL deltas, a log shipper and a dry-run recording client — everything a monitoring loop nee
