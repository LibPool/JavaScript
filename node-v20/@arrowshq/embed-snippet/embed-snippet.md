# @arrowshq/embed-snippet

> 标签: JavaScript

## 简介

Vanilla JS embed snippet that is responsible to fetch @arrowshq/embed-core and thus show Arrows Plan as an embed on a page.

## 官网

- 官网：https://github.com/ArrowsHQ/Arrows-embed#readme
- 源码仓库：git+https://github.com/ArrowsHQ/Arrows-embed.git
- npm 页面：https://www.npmjs.com/package/@arrowshq/embed-snippet
