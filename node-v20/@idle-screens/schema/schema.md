# @idle-screens/schema

> 标签: ambient, canvas, declarative, idle, schema, screensaver

## 简介

Declarative, agent-authorable saver format for idle-screens: validate a data spec, then compile it into a runnable, seeded, flash-safe SaverPlugin.
