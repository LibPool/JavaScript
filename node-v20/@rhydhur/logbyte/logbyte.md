# @rhydhur/logbyte

> 标签: javascript, logbyte, logger, logging, observability, react, vue

## 简介

Tiny structured logging client for logbyte — send info/warning/error logs from any JavaScript app (Node.js backends or frontend frameworks like React and Vue) to your logbyte dashboard.
