# @xelluxofficial/auth

> 标签: 2fa, auth, authentication, oauth, oauth2, oidc, openid, sso, xellux

## 简介

Official JavaScript/TypeScript SDK for Xellux ID — drop-in OAuth 2.0 / OIDC authentication plus the read-only Account API.
