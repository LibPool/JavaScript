# @ungic/cli

> 标签: cli, cms, headless, ungic

## 简介

The ungic CLI for a Site as code: ungic dev (CMS + admin + app frontends built live from the theme, restarts on change), ungic build (typecheck, function contract, migrations check, production bundle, app frontends), ungic start, ungic migrate.
