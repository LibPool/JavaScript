# @akiflow/licenses-verifier

> 标签: IP, compliance, copyright, intellectual property, legal, licenses, sbom, verifier, zero-dependencies

## 简介

Verify that the dependencies of package.json are licensed in a way that allows their use in the current project. Zero dependencies.
