# @tian.zuo/pi-background-terminals

> 标签: background, pi, pi-coding-agent, pi-extension, pi-package, process, shell, terminal

## 简介

Replace Pi's built-in Bash with automatic background yielding, exactly-once completion notifications, and a /ps viewer.
