# @kordar-lib/common

> 标签: JavaScript

## 简介

通用样式与基础类型集合： - 样式：内置大量颜色类名（.color-xxx），打包输出 dist/index.min.css，便于在任意项目中即用即取 - 类型：提供通用 UI 类型定义（当前包含面包屑 Breadcrumb 相关类型）
