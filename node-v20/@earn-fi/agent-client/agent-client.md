# @earn-fi/agent-client

> 标签: agent, earnfi, human-in-the-loop, microjobs, solana, usdc, x402

## 简介

TypeScript client and CLI for the EarnFi Agent API — registration, x402 paid creates, polling, marketplace hire (create+fund), agent earnings withdraw to Solana wallet, disputes, deals, reviews, and creator actions.
