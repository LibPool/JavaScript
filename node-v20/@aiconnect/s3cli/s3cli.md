# @aiconnect/s3cli

> 标签: aws, bucket, cli, download, minio, s3, storage, supabase, upload

## 简介

Simple CLI for S3 operations using AWS SDK. Compatible with Supabase Storage, AWS S3, MinIO and other S3-compatible providers.
