# @natsunaaa/test

> 标签: JavaScript

## 简介

`@natsunaaa/test`는 Tailwind CSS를 번들에 포함하지 않는다. 컴포넌트는 정적인 Tailwind class를 제공하고, 이를 사용하는 웹 애플리케이션이 `tailwindcss@3.4.0`으로 최종 CSS를 생성한다.
