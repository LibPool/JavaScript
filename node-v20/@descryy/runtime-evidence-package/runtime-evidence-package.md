# @descryy/runtime-evidence-package

> 标签: JavaScript

## 简介

Assembles the scoped evidence package an AI investigation reads (plan §32). The rule it exists to enforce is 'do not dump the entire evidence store into the model' — it selects by stated priority tiers and names every slot it could not fill.
