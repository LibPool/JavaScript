> 标签: base, defi, eliza, elizaos, elizaos-plugin, etherscan, goplus, ofac, paladinfi, risk-gate, trust, x402

## 简介

Pre-trade trust verification for ElizaOS evm agents — composed OFAC SDN + GoPlus + Etherscan + anomaly-heuristics risk gate via x402-paid PaladinFi API on Base. Natural-language LLM extraction; preview (free) and paid ($0.001 USDC/call) modes.
