# @signdocs-brasil/api

> 标签: api, assinador, assinatura, assinatura-de-documentos, assinatura-digital, assinatura-eletronica, biometria, brasil, brazil, certificado-digital, digital-signature, document-signing, e-signature, electronic-signature, esignature, icp-brasil, sdk, signdocs, signdocs-brasil

## 简介

SDK oficial em TypeScript/Node.js para a API SignDocs Brasil: assinatura eletrônica e digital com ICP-Brasil, biometria, OTP e trilha de evidências (Brazilian e-signature API SDK)
