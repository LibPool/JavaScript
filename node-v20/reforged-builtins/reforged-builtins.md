# reforged-builtins

> 标签: rawcode, reforged, typescript-to-lua, warcraft, wc3

## 简介

The Built-in objects of each Warcraft III Reforged Patch, reduced to derived identifiers: Rawcode, Object kind, race, enUS name and Game data sets.
