# @nospt/backstage-plugin-catalog-gcp

> 标签: JavaScript

## 简介

A [Backstage](https://backstage.io) backend plugin that automatically discovers GCP resources via the **Cloud Asset Inventory API** and ingests them into the Backstage Software Catalog as `Resource` and `System` entities.
