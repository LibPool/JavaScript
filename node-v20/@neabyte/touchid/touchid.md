# @neabyte/touchid

> 标签: addon, authentication, biometric, biometry, device-identification, device-serial, hardware-uuid, localauthentication, macos, native, secure-enclave, security, touchid, ttl-caching, typescript

## 简介

Native macOS Touch ID authentication with device identification, TTL caching, and TypeScript support. Features hardware UUID, device serial, and biometric type detection.
