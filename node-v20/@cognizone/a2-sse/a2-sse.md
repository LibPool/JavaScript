# @cognizone/a2-sse

> 标签: JavaScript

## 简介

Angular wrapper around the browser's native `EventSource` API, exposing an observable-based interface for SSE connections. Requires: **Angular >= 20 for v1.1.x** **Angular >= 21 for v3.0.x**
