# @caisson-sh/frameworks-pack

> 标签: JavaScript

## 简介

Compliance framework catalogs as config-as-code: the typed canonical-control model plus own-authored SOC2-TSC, HIPAA-Security, and EU-AI-Act control packs with crosswalk references to each framework's requirement ids.
