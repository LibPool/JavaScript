# @caisson-sh/compliance

> 标签: JavaScript

## 简介

Compliance evidence kit: tenant-scoped field crypto, a WORM audit chain, own-authored SOC2-TSC and HIPAA control packs, and a deterministic, signed control-to-evidence-pack generator.
