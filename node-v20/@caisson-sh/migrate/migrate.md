# @caisson-sh/migrate

> 标签: JavaScript

## 简介

The base migration assembler + runner: reads each selected package's on-disk migrations/NNNN_*.sql, merges them via the kernel into ONE renumbered sequence + single schema_version ledger, emits the generated-app file set, and applies the sequence forward-
