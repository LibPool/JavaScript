# @neutron-build/core

> 标签: framework, fullstack, islands, neutron, preact, ssg, ssr, typescript, vite, web-framework

## 简介

The unified TypeScript web framework. Static sites with zero JS, app routes with Preact SSR, one router, deploy anywhere.
