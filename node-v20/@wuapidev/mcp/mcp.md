# @wuapidev/mcp

> 标签: ai-agents, claude, cursor, mcp, model-context-protocol, whatsapp, whatsapp-api

## 简介

Model Context Protocol server for wuapi, a WhatsApp API for developers. Lets Claude, Cursor, VS Code and other MCP clients send messages and manage linked numbers, chats, contacts, groups, communities, channels, profiles, webhooks, projects and invitation
