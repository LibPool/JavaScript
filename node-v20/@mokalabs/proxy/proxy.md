# @mokalabs/proxy

> 标签: claude, claude-code, cursor, debugging, gemini, github-copilot, inspector, json-rpc, mcp, mcp-proxy, model-context-protocol, proxy, vscode, windsurf

## 简介

See what your AI editor sends to your MCP server: a pass-through proxy that records every JSON-RPC message for the Moka inspector. Works with GitHub Copilot, Cursor, Claude Desktop and any client that starts MCP servers.
