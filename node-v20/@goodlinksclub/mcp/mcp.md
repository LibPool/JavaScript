# @goodlinksclub/mcp

> 标签: backlinks, good-links, mcp, modelcontextprotocol, seo

## 简介

MCP server for Good Links Club: find citations for a draft, work Existing Opportunities, content ideas and local links, place the link the way the verifier expects, and submit published URLs from your AI editor.
