# write-once

> 标签: content-synchronization, documentation-sync, fragment-reuse, single-source-of-truth, text-reuse, text-synchronization, write-once

## 简介

Keep documentation, AI instructions, skills, and code examples in sync from a single source of truth. Reuse text across files with simple markers and avoid duplicated edits.
