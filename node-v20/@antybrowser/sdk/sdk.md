# @antybrowser/sdk

> 标签: anti-detect, antybrowser, browser-automation, fingerprint, multi-accounting, proxy, puppeteer, selenium, undetected-browser

## 简介

Official Antybrowser SDK — TypeScript client for the Antybrowser Local API. Manage profiles, proxies, automations, groups, and extensions programmatically.
