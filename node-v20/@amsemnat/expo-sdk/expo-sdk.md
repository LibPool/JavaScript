# @amsemnat/expo-sdk

> 标签: amsemnat, eid, expo, nfc, pades, romania, signing

## 简介

Expo module that wraps the am-semnat iOS and Android SDKs — NFC read + PAdES sign for Romanian CEI eID cards.
