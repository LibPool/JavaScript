# @cloudpdf/viewer-svelte

> 标签: cloud, cloudpdf, pdf, svelte, viewer

## 简介

The full viewer as a Svelte component with the CloudPDF engine as its default: the same <PDFViewer> as @embedpdf/viewer-svelte, rendering on CloudPDF SaaS or your own @cloudpdf/server over HTTPS, the local engine loaded only when stamps need it.
