# n8n-nodes-zuuna

> 标签: kanban, n8n, n8n-community-node-package, project-management, zuuna

## 简介

n8n community node for Zuuna: create/update cards, add comments, list boards, columns and cards, and trigger workflows from Zuuna webhooks. Talks to the hosted, commercial Zuuna service (zuuna.de) or a self-hosted Zuuna instance.
