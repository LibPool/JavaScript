# @designless/dev-auth

> 标签: auth, designless, dev, express, fail-closed, next, nitro, nuxt, svelte, sveltekit

## 简介

Dev-only, fail-closed receiver: reads two headers the Designless desktop app injects during a capture and stands up a request-scoped { role }. No network, no telemetry, no auth-model logic.
