# @tbox.cn/app-theme-tbox

> 标签: JavaScript

## 简介

平台品牌主题包（公开发布）：五段 CSS 覆写 + 平台 IP 素材九语义位 + brand.js 品牌副作用入口（v1 仅标题）。接线 = import 本包 index.css + brand.js + applyTheme('tbox') 三行。素材独立化——IP 换代 = 本包补丁，模块零品牌资产。
