# @tbox.cn/app-sdk-server

> 标签: JavaScript

## 简介

tbox 应用平台 SDK server 轴：模块系统（ServerContext/注册表族/装配/动作域）、auth、inspector、Provider 集成运行时、平台客户端、upstream 内化客户端。agent 引擎在 @tbox.cn/app-agent-sdk-server。
