# @juggernautlabs/cloud

> 标签: ai, automation, cloud, juggernaut, juggernautlabs, process, sdk, typescript

## 简介

Official Node.js and browser SDK for the Juggernaut Cloud Platform. Execute AI processes, manage cloud database schemas, search resources, and run plugins locally.
