# @hyperez/regna-code

> 标签: ai, cli, coding-agent, regna, terminal

## 简介

Regna Code. A terminal coding agent on Regna. Install with `npm i -g @hyperez/regna-code` and run `regna`. Works with the Regna cloud API and on-premise deployments.
