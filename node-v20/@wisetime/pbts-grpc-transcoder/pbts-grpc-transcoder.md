# @wisetime/pbts-grpc-transcoder

> 标签: JavaScript

## 简介

pbts-grpc-transcoder is a TypeScript library that provides gRPC to HTTP/1 & JSON transcoding for the protobuf.js [library ](https://github.com/protobufjs/protobuf.js).
