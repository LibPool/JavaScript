# @pogly/spacetimedb-oauth

> 标签: oauth, pkce, spacetimedb, submodule, token-vault

## 简介

OAuth account linking and a token vault for SpacetimeDB, as a submodule: authorization code + PKCE, private tokens, scheduled refresh. Same schema and clients as oauth.rs / OAuth.cs.
