# @pogly/spacetimedb-voip-client

> 标签: audioworklet, opus, spacetimedb, voice-chat, voip, webcodecs

## 简介

Browser voice client for spacetimedb-voip: mic → noise gate / push-to-talk → Opus (WebCodecs) → reducer, and per-speaker decoders with adaptive jitter buffers and 3D panning.
