# @jbfullstack/score-parser

> 标签: abc-notation, gpx, guitar-pro, midi, music, music-notation, musicxml, parser, saxophone

## 简介

Parse MIDI and Guitar Pro files into a clean, format-neutral JSON structure. Handles transposing instruments (saxophone, clarinet, trumpet) correctly.
