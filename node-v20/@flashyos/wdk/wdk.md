# @flashyos/wdk

> 标签: agent, autonomous-organization, flashyos, tether, wallet, wdk

## 简介

The FlashyOS agent object: identity, authority, wallet, memory and partners behind one interface. Create an agent, give it an identity, provision financial capabilities on Tether WDK, set its permissions, let it transact, record what it did, coordinate it
