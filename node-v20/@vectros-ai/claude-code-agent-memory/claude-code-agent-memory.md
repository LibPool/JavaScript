# @vectros-ai/claude-code-agent-memory

> 标签: agent-memory, claude, claude-code, hooks, mcp, memory, recall, vectros

## 简介

Cross-session memory for Claude Code: recall relevant context automatically at the start of a turn, distill durable lessons out of a session involuntarily, and dispose them into your Vectros knowledge base under your own review. Pre-1.0 / beta.
