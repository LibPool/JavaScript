# @dora-cms/server

> 标签: backend, cms, content-api, express, mongodb, self-hosted

## 简介

Self-hosted API backend for dora-cms — content, blog and image-upload endpoints with admin auth. Deployable to Render as a Node service or to Vercel as serverless functions.
