# @alwatr/weaver

> 标签: alwatr, build, bun, bundler, dev-server, hot-reload, live-reload, loom, ssg, tailwindcss, weaver

## 简介

A bun-native build tool and dev server that composes @alwatr/loom (TSX→HTML), Bun's bundler (client JS), and Tailwind CSS — with in-memory serve and native live-reload.
