# @agentplugins/adapter-copilot

> 标签: agentplugins, ai-agent, copilot-cli, github-copilot, mcp, plugin-adapter

## 简介

GitHub Copilot CLI platform adapter for AgentPlugins — compiles AgentPlugins plugins into Copilot-compatible manifests, hooks, skills, and MCP configuration
