# floorcheck

> 标签: a11y, accessibility, audit, axe-core, cli, en-301-549, european-accessibility-act, playwright, wcag, wcag22

## 简介

WCAG 2.2 scanner built on axe-core that keeps conformance failures, needs-review items and advice apart, checks reflow at 320px, and refuses to call an error or bot-challenge page clean.
