# @route-forge/react

> 标签: api-client, hooks, laravel, named-routes, react, react18, react19, route-forge, typescript, url-generation

## 简介

Route Forge 的 React 集成：Provider + hooks（useForge/useForgeApi/useForgeRoute）+ 组件（ForgeRoute/ForgeLink）/ React integration for Laravel named routes: Provider + hooks (useForge / useForgeApi / useForgeRoute) + components (ForgeRoute / ForgeLink)
