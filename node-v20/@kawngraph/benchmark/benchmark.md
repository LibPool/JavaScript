# @kawngraph/benchmark

> 标签: JavaScript

## 简介

KawnGraph behavioral benchmark — subscription-authenticated, multi-agent (Claude, Codex), multi-project A/B measurement of agent retrieval and task outcomes with and without KawnGraph. No API keys; never logs credentials.
