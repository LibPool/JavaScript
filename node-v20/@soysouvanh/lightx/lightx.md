# @soysouvanh/lightx

> 标签: aot, bare-metal, framework, lightx, nodejs, performance, typescript

## 简介

LightX is a “Bare-Metal” Next-Gen Web Framework for Node.js and TypeScript, engineered for extreme O(1) runtime performances, strict AOT compilation, and native security.
