# @baaqar/artifact-to-pwa

> 标签: artifact, claude, cli, converter, desktop, exe, jsx, neutralino, pwa, react, standalone, webview2, windows

## 简介

Convert any Claude artifact (HTML/React/JSX) into a native .exe — ~5 MB output via Neutralino + WebView2
