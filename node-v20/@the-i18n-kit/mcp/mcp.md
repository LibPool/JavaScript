# @the-i18n-kit/mcp

> 标签: ai-agent, claude, cursor, developer-tools, i18n, internationalization, l10n, laravel, locale, localization, mcp, mcp-server, modelcontextprotocol, nextjs, nuxt, react, translation, vue

## 简介

Let your AI agent manage translations — find orphans, translate missing keys, add languages. Works with Cursor, Claude, VS Code. Supports Nuxt, Laravel, Vue, React/Next.js, and any framework.
