# @junsma/nivo

> 标签: admin, crud, dsl, element-plus, fullstack, json-schema, koa, low-code, schema-driven, vue3

## 简介

基于 Vue3 + Koa 的 DSL 驱动企业级全栈低代码框架：一份 JSON Schema 同时驱动表格/搜索栏/表单/详情面板，后端按目录约定自动挂载接口与参数校验。
