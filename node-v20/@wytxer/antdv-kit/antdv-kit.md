# @wytxer/antdv-kit

> 标签: ant design vue, antd, antdv, antdv kit, ui kit

## 简介

基于 ant-design-vue 1.x 封装的一套组件库，主要是增强了部分组件的功能，例如 Upload、DatePicker 等。
