# @luidev02/atlas-sdk

> 标签: apm, atlas, browser, crash-reporting, distributed-tracing, error-tracking, frontend, metrics, observability, opentelemetry, rum, sentry-alternative, service-identity, traceparent, tracing, w3c-trace-context, web-vitals

## 简介

Cliente de identidad y observabilidad para Atlas, para backend Y navegador. Un servicio Node resuelve su configuracion y reporta trazas, metricas y logs; el subpath /browser reporta errores, Web Vitals y trazas desde la pagina, cosidas con las del backend
