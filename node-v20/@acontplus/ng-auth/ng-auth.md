# @acontplus/ng-auth

> 标签: acontplus, angular, angular-material, auth-guard, auth-interceptor, auth-providers, auth-repository, auth-stores, authentication, clean-architecture, csrf-interceptor, csrf-protection, ddd, domain-models, enterprise, frontend, hexagonal-architecture, jwt, jwt-decode, login-component, route-guards, session-management, token-management, typescript, url-redirect, use-cases

## 简介

Comprehensive Angular authentication module with JWT token management, route guards, CSRF protection, URL redirection, session handling, and clean architecture patterns. Includes login components, auth interceptors, and DDD-based repositories.
