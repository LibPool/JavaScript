# @acontplus/ng-notifications

> 标签: acontplus, angular, angular-material, configurable-styling, dark-mode-detection, enterprise, frontend, material-design, material-integration, ngx-toastr, notification-providers, notification-system, notification-types, notifications, scss-theming, snackbar, sweetalert2, theme-detection, toast-notifications, typescript

## 简介

Comprehensive Angular notification system with toast notifications (ngx-toastr), alerts (SweetAlert2), snackbars, theme detection, notification providers, and configurable styling. Supports multiple notification types with Angular Material integration.
