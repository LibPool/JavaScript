# @beetleai_dev/lens-node

> 标签: apm, beetle, codelens, express, mongoose, monitoring, performance, profiler, tracing, vscode

## 简介

Production profiler for Node.js Express apps — tracks route latency, DB queries, and HTTP calls. Shows real metrics inline in VS Code via Beetle Lens.
