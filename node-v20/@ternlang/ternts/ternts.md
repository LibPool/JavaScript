# @ternlang/ternts

> 标签: compiler, decorators, emitDecoratorMetadata, esbuild, jsx, nestjs, swc, transpiler, tsc, typescript

## 简介

TypeScript to JavaScript as tsc emits it (legacy decorators with metadata, JSX), 6-45x faster. Written in Tern.
