# @yangtianlong/dsh-plugin-manager

> 标签: JavaScript

## 简介

DSH Web GUI 插件管理器：侧边栏「插件管理」入口，中栏面板列出本机安装的全部 DSH 插件（名称 / 版本 / 中英双语简介 / 运行状态 / 安装时间 / 使用次数）；使用次数为该插件注册的 agent 工具在本机会话中的累计调用数（会话日志统计，工具归属内置词典映射，未收录工具按「插件短名_动作」模式自动匹配）；简介语言可切换（中文为内置词典，未收录插件由内置翻译规则自动生成并标注「自动翻译」，不再回退英文），同一作者（npm scope 或 GitHub 仓库所有者）的插件折叠分组并带组级
