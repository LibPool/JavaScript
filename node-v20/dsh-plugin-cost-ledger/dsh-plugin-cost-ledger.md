# dsh-plugin-cost-ledger

> 标签: cordis, cost, deepseek-harness, dsh, dsh-plugin, export, ledger, plugin, tokens

## 简介

Persistent cost ledger for the DeepSeek Harness: every priced model call lands in a monthly JSONL file; /ledger renders monthly reports, /ledger-export writes CSV, and the agent can query its own spend via ledger_query.
