# @ai-composer/core

> 标签: JavaScript

## 简介

The framework-independent engine behind AI Composer. It manages the editor document, state, commands, triggers, plugins, undo/redo history, and serialization. Use it directly for a custom UI, or pair it with a framework adapter.
