# @noy-db/ui-nuxt

> 标签: data-table, noy-db, nuxt, nuxt-module, nuxt-ui, schema-driven, vue

## 简介

Nuxt UI fork of the noy-db UI family: schema-driven list + detail components built on @nuxt/ui primitives, standard app.config theming, deliberately plain. Domain-free; consumes collection.describe().
