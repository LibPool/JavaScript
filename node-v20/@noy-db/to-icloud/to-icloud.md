# @noy-db/to-icloud

> 标签: apple, bundle, icloud, macos, noy-db, storage, to-icloud

## 简介

iCloud Drive bundle store for noy-db — macOS-aware persistence that handles both eviction shapes (modern dataless-in-place and legacy .icloud stubs) and detects conflict files automatically. Treats each vault as a single .noydb bundle, safe for the Apple
