# @noy-db/by-tabs

> 标签: broadcast-channel, browser, by-tabs, encryption, multi-tab, noy-db, realtime, sync, tab-sync, zero-knowledge

## 简介

BroadcastChannel multi-tab transport for noy-db — sync between tabs of the same browser without round-tripping the storage backend
