# @noy-db/as-zip

> 标签: archive, as-zip, audit-trail, export, noy-db, plaintext, zero-knowledge, zip

## 简介

Composite record + blob archive export for noy-db — bundles a collection's records plus every attached blob into one zip. Zero dependencies (STORE-only zip encoder). Gated by the RFC #249 `assertCanExport('plaintext', …)` gate with format `'zip'`. Part of
