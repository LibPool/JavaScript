# @noy-db/as-json

> 标签: as-json, export, json, noy-db, plaintext, zero-knowledge

## 简介

Structured JSON plaintext export for noy-db — decrypts records and emits one JSON document per vault. Gated by `vault.assertCanExport('plaintext', …)` capability; writes an audit-ledger entry on every call. Part of the @noy-db/as-* portable-artefact famil
