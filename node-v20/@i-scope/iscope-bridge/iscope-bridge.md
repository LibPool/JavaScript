# @i-scope/iscope-bridge

> 标签: atl, autoscope, com-automation, i-scope, iscope, iscope-debugger, json-rpc, native, oscilloscope

## 简介

Win32 npm distribution of iScopeBridge.exe (JSON-RPC stdio → Oscilloscope COM). Not a Node.js library: no main entry — use @i-scope/iscope-bridge-client from TypeScript.
