# @i-scope/source-map-bridge

> 标签: ajs, dap, debug-adapter, i-scope, iscope, iscope-debugger, jscript, oscilloscope, source-map, sourcemap, typescript

## 简介

Bidirectional TypeScript ↔ AJS (Oscilloscope JScript) source-map manager. Loads v3 maps (inline data URI, sidecar, implicit-sidecar) and translates positions both directions (TS → AJS for breakpoints, AJS → TS for stack frames). Coordinate-system aware —
