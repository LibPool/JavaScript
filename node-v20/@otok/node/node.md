# @otok/node

> 标签: api-client, crm, e-commerce, marketing, orders, otok, sdk, transactional-email, webhooks

## 简介

Official Node.js SDK for the oToK marketing platform public API (/v1) — contacts, deals, orders, transactional email, webhooks, and a high-level e-commerce layer.
