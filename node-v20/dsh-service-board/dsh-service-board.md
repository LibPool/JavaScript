# dsh-service-board

> 标签: deepseek-harness, devtools, dsh, dsh-plugin, process-manager, service-dashboard, service-panel

## 简介

DSH 服务面板：查看由哪个对话（Agent 会话）启动了哪些服务，按会话分组、三态健康探测 + HTTP 码、启动时间/运行时长、礼貌停止、实时日志分栏与原地重启。含对上游 dsh-process-board 的若干修复（重启后 no-log、扫描器同名启动器误合并、面板抢占输入框焦点）。A docked DSH service panel: which conversation started which service, with uptime, tri-state health, live log
