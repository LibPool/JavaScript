# @plumbox/manifest

> 标签: app-platform, json-schema, manifest, plu, plum, plum-box, plumbox, validation

## 简介

JSON Schema for the Plum Box app manifest (manifest.json) — the single source of truth shared by the plum-dev CLI, the Plum Store upload checks and the box installer.
