# @vivariumjs/agent

> 标签: agent, ai-generated-ui, changeset, llm, vivarium

## 简介

Agent harness that turns natural-language intent and on-screen selection into verified changesets — pluggable model provider, knowledge, and strategy. Output is a changeset or nothing.
