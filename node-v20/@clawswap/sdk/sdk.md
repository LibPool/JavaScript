# @clawswap/sdk

> 标签: ai-agents, base, bridge, cross-chain, defi, eliza, elizaos, elizaos-plugins, moltbook, sdk, solana, swap, typescript, usdc, x402

## 简介

Gasless cross-chain token swaps for AI agents via x402 micropayments. Solana ↔ Base bidirectional. No API key, no gas management.
