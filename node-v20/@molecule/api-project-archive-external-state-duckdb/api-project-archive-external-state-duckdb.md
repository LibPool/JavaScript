# @molecule/api-project-archive-external-state-duckdb

> 标签: archive, backup, duckdb, molecule, project

## 简介

DuckDB external-state capture for project archives — copies a project's configured .duckdb database files (and their .wal siblings) into the archive and writes them back on restore.
