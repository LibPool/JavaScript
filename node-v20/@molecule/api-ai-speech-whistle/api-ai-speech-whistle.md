# @molecule/api-ai-speech-whistle

> 标签: ai, molecule, on-device, self-hosted, speech, speech-to-text, whistle

## 简介

Whistle speech provider for molecule.dev — Cactus Compute's 16.9 MB seven-language speech-to-text running in-process on CPU via the needle WASM engine (no server, no key)
