# @molecule/api-deploy-rollout

> 标签: deploy, molecule, replicas, rolling deploy, rollout, zero downtime

## 简介

Deploy-rollout core interface for molecule.dev: replace a deployment's running instances without downtime, grow-then-shrink or in place, with a capacity floor, soak, reverse rollback and idempotent resume.
