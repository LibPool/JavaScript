# @molecule/api-process-lifecycle-express

> 标签: express, graceful shutdown, health check, lifecycle, liveness, molecule, readiness

## 简介

Express/Node provider for @molecule/api-process-lifecycle: GET /health/live and /health/ready, request tracking with Connection: close while draining, and SIGTERM/SIGINT graceful shutdown with ordered hooks.
