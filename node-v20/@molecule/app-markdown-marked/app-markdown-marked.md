# @molecule/app-markdown-marked

> 标签: commonmark, gfm, markdown, marked, molecule, static-site

## 简介

Markdown rendering provider backed by marked: CommonMark + GFM to sanitized HTML with a table of contents, in Node or the browser (build-time static sites included)
