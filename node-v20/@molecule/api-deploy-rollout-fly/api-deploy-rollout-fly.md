# @molecule/api-deploy-rollout-fly

> 标签: deploy, fly, fly machines, molecule, rollout

## 简介

Fly Machines provider bond for @molecule/api-deploy-rollout: in-place restarts with a restore path and grow-then-shrink clones, over an injected flyctl runner.
