# @molecule/api-upstream-balancer-default

> 标签: edge, load balancing, molecule, round robin, upstream

## 简介

Default upstream-balancer provider for molecule.dev: per-host round-robin with a passive failure cooldown, retry elsewhere and drain-awareness.
