# @axiolex/mcp-gateway

> 标签: ai, axiolex, claude, mcp, model-context-protocol, proxy, stdio, tool-discovery

## 简介

Stdio-to-HTTP proxy for Axiolex MCP. Connects stdio-only MCP clients (Claude Desktop, Cursor, Codex) to a remote Axiolex server.
