# @loop-engine/loop-definition

> 标签: loop-definition, loop-engine, state-machine, yaml

## 简介

YAML parse/serialize, validation, and LoopBuilder for loop definitions (shared by @loop-engine/sdk and @loop-engine/registry-client).
