# @vibedout/media-core

> 标签: cloudflare, content-disposition, exif, file-type, gps, media, r2, uploads, workers

## 简介

File handling for Cloudflare Workers, as pure functions and small interfaces: a magic-byte sniff table for images (HEIC and AVIF included), video, audio, PDF, office documents, zip and text, a lossless metadata and GPS remover for JPEG, PNG, WebP and GIF,
