# @motifx/compiler

> 标签: JavaScript

## 简介

Compiler and Vite plugin for MotifJS JSX: lowers JSX to fine-grained reactive bindings. Includes the motif-lint and motif-explain CLIs.

## 官网

- 官网：https://motifjs.com/
- 源码仓库：git+https://github.com/motifjsdev/motifjs.git
- npm 页面：https://www.npmjs.com/package/@motifx/compiler
