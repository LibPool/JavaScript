# @yuanxueshi/koishi-plugin-yxs-pterodactyl

> 标签: QQ机器人, WebSocket, koishi, plugin, pterodactyl, 实时监控, 服务器管理, 翼龙面板

## 简介

对接翼龙面板 (Pterodactyl Panel) 的 Koishi 插件，支持 QQ 群内实时监控服务器状态、资源使用及启停管理（指令前缀 yxs）
