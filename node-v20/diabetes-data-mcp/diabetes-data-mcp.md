# diabetes-data-mcp

> 标签: cgm, diabetes, macos, mcp, model-context-protocol, nightscout, sqlite

## 简介

Mac Mini diabetes data plane: LAN-only Nightscout (LaunchAgents, loopback MongoDB), the Nightscout to SQLite sync, and a read-only bearer-token Streamable HTTP MCP over that archive
