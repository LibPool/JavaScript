# @lerg96/commait

> 标签: ai, ai-assistant, automation, commit, commit-message, emoji, git, git-hook, llm, openai

## 简介

🚀 AI-powered Git commit message generator with emojis. Analyzes your staged changes and generates concise, descriptive commit messages using OpenAI or your local LLM (LM Studio, Ollama, llama.cpp).
