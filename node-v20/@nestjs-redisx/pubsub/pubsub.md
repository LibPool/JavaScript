# @nestjs-redisx/pubsub

> 标签: broadcast, events, nestjs, publish-subscribe, pubsub, real-time, redis, websocket

## 简介

Redis Pub/Sub plugin for NestJS RedisX: typed publish/subscribe, pattern subscriptions, @Subscribe decorator with auto-discovery, and a dedicated subscriber connection
