# @unngh/youtube-api

> 标签: api, streaming, youtube, youtube-api, youtube-data-api

## 简介

JavaScript/TypeScript bindings for the yt Dart package. Universal (browser + Node.js) client for YouTube Data and Live Streaming APIs.
