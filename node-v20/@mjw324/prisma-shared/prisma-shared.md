# @mjw324/prisma-shared

> 标签: JavaScript

## 简介

A shared Prisma schema package used for eSentry, shared between the [Next.js frontend](https://github.com/mjw324/next-esentry) and [Node.js/Express.js backend](https://github.com/mjw324/next-esentry-nodejs). This package provides a common database schema
