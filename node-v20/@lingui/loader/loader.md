# @lingui/loader

> 标签: build-tooling, i18n, lingui, linguijs, localization, message-catalog, rsbuild, rspack, translation, webpack, webpack-loader

## 简介

Webpack-compatible loader that compiles Lingui message catalogs on the fly, so .po files can be imported directly

- 源码仓库：git+https://github.com/lingui/js-lingui.git
