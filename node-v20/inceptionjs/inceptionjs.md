# inceptionjs

> 标签: agent, ai-agent, browser, browser-automation, canvas, embed, iframe, webassembly, webgl, webkit

## 简介

A web browser engine (WebKit compiled to WebAssembly) that runs inside a web page and draws into a canvas. GPU-first, with a JSON-RPC protocol and an opt-in, policy-guarded API for AI agents.
