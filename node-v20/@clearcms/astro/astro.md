# @clearcms/astro

> 标签: JavaScript

## 简介

Astro Content Layer adapter for clear. Wraps @clearcms/sdk so consumers can use Astro's native getCollection() / getEntry() APIs to read from a clear bucket (fs / R2 / S3) or a running admin (REST).
