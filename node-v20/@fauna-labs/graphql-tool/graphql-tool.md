# @fauna-labs/graphql-tool

> 标签: JavaScript

## 简介

Fauna GraphQL tool is an automation library that is used to easily add features such as `authentication`, `custom resolver (UDF)`, `sorting of subgraphs`, `fuzzy full-text search`, etc.
