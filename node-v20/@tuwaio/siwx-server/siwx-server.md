# @tuwaio/siwx-server

> 标签: authentication, backend, caip-122, cookie, edge, jwt, node, server, session, tuwa, typescript, verification, web3

## 简介

Layer 2 (L2) of the TUWA Ecosystem. Backend utilities for @tuwaio/siwx. Parses, validates, and verifies CAIP-122 payloads on Node.js or Edge runtimes.
