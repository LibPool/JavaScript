# @clayseal/verify

> 标签: agent-identity, ai-agents, authorization, biscuit, capability-tokens, clayseal, jwt, mcp, openclaw

## 简介

Server-side verification of Clay Seal agent credentials for JavaScript/TypeScript MCP servers and tool gateways: offline JWT-SVID verification, Biscuit capability authorization, and sender-constrained proof-of-possession.
