# @vcincubator/validate

> 标签: license, license-validation, marketplace, monetization, redemption-code, saas, vci, vcinc

## 简介

Validate VCI Marketplace license codes from your app. Tiny, zero-dependency wrapper around the VCI validation API with retries, caching, and TypeScript types.
