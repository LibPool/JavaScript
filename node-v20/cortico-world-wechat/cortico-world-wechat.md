# cortico-world-wechat

> 标签: cortico, cortico-world, notifier, wechat, weixin

## 简介

把 Windows 微信新消息播报给桌宠：扩展自己解密并轮询微信本地库，把新消息推进桌宠的事件流，由桌宠决定怎么汇报。
