# @rennzsync/baileys

> 标签: automation, baileys, bot, multi-device, multimedia, renz, whatsapp, whatsapp-api, whatsapp-bot

## 简介

renz/baileys — WhatsApp Multi-Device library rebased @whiskeysockets/baileys 7.0.0-rc14, using the original libsignal (GPL-3.0) Signal Protocol engine. Maintained by RennZSync. Focus: multimedia WhatsApp bots, low RAM footprint.
