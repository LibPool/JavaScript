# @abap2ui5/embed-control

> 标签: abap, abap2ui5, custom-control, embed, openui5, sapui5, ui5, ui5-cc

## 简介

Embed abap2UI5 apps in any UI5 app: a UI5 control that runs an ABAP class implementing z2ui5_if_app
