# @styx-api/core

> 标签: boutiques, cli, code-generation, compiler, niwrap, styx

## 简介

Styx compiler core: parses CLI tool descriptors (e.g. Boutiques), optimizes an IR, solves typed parameter bindings, and generates type-safe wrappers (TypeScript, Python, JSON Schema). Part of the Styx/NiWrap ecosystem.
