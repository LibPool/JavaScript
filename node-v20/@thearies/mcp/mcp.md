# @thearies/mcp

> 标签: api-testing, aries, claude, cursor, mcp, model-context-protocol, openapi, postman

## 简介

Aries MCP server. Exposes Aries's spec-import, coverage, run, and rejection endpoints to any Model Context Protocol client so a developer working in Postman / Cursor / Claude Desktop can test their in-flight API without leaving the tool.
