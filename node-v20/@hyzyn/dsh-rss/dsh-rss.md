# @hyzyn/dsh-rss

> 标签: JavaScript

## 简介

DSH 的 RSS / 新闻聚合插件：订阅多个 RSS/Atom 源，每天自动汇总成一篇「今日值得读」Markdown，并注入 systemPrompt 供模型直接引用。
