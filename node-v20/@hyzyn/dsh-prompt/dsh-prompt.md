# @hyzyn/dsh-prompt

> 标签: JavaScript

## 简介

DSH Web GUI 的 Prompt 管理插件：可视化编辑 systemPrompt、版本管理、A/B 测试、导出/分享，配置保存在 ~/.dsh/prompts.yml 的托管区块。
