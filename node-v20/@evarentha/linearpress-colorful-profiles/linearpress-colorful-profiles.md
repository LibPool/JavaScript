# @evarentha/linearpress-colorful-profiles

> 标签: colorful-profiles, evarentha, linearpress, plugin

## 简介

增强的用户个人资料：GIF/APNG 头像与正方形裁剪、昵称显示、邮箱重验证、公开资料页与文章/评论头像展示。依赖 advanced-comments 与 advanced-user-management。
