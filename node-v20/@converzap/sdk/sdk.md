# @converzap/sdk

> 标签: ai-agents, converzap, crm, mcp, sdk, typescript, whatsapp, whatsapp-api, whatsapp-business, whatsapp-cloud-api

## 简介

Official TypeScript SDK for the ConverZAP API — WhatsApp on the official WhatsApp Business Platform (Meta Cloud API): contacts, conversations, messages, templates, campaigns, deals (CRM), automations, AI agents and webhooks.
