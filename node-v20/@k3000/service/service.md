# @k3000/service

> 标签: JavaScript

## 简介

这是一个为 Node.js 设计的轻量级、多协议 RPC（远程过程调用）库，支持 TCP、IPC 和 UDP，并采用自定义二进制协议。

## 官网

- npm 页面：https://www.npmjs.com/package/@k3000/service
