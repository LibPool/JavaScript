# @tawaship/pixim-box2d

> 标签: box2dweb, pixi, pixi.js

## 简介

"pixim-box2d" is a plugin for using "[box2dweb](https://github.com/hecht-software/box2dweb)" with "[Pixim.js](https://github.com/tawaship/Pixim.js)".

## 官网

- 官网：https://tawaship.github.io/Pixim-box2d/
- 源码仓库：git+https://github.com/tawaship/Pixim-box2d.git
- npm 页面：https://www.npmjs.com/package/@tawaship/pixim-box2d
