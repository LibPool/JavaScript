# @mcp-index/sdk

> 标签: agent, drift, mcp, mcpindex, model-context-protocol, security, tofu

## 简介

Pre-flight MCP tool-contract drift interceptor from mcpindex.ai, the drift-monitored MCP server index. One-line wrap() over an MCP client session that HOLDs a tool call before your agent runs it when the contract drifted from your pin. No credential handl
