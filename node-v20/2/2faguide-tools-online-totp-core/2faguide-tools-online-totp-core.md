# 2faguide-tools-online-totp-core

> 标签: 2fa, authenticator, base32, free2fa, hotp, otp, otpauth, rfc4226, rfc6238, totp, two-factor, webcrypto, zero-dependency

## 简介

Zero-dependency TOTP / HOTP core (RFC 4226 / RFC 6238) built on Web Crypto — the engine behind the Free2FA online 2FA tool. Runs in browsers, Node 18+, Workers, Deno and Bun.
