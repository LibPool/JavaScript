# 24htrack-mcp

> 标签: 24htrack, ai-agents, carrier, claude, delivery, dhl, fedex, mcp, mcp-server, model-context-protocol, multi-carrier-tracking, package-tracking, parcel-tracking, shipping, track-package, tracking, ups, usps

## 简介

MCP server for 24hTrack — track packages across 3,200+ carriers (USPS, UPS, FedEx, DHL, China Post, UniUni, SpeedX and more). Multi-carrier tracking with auto carrier detection for AI agents.
