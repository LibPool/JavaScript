# 2tikz

> 标签: JavaScript

## 简介

A minimal http server that accepts .png and .svg fils, vectorizes the .pngs and returns .tikz code for inclusion in .tex files.

## 官网

- npm 页面：https://www.npmjs.com/package/2tikz
