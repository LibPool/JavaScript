# 21millionpixels-mcp

> 标签: agent, base, mcp, model-context-protocol, pixel-canvas, usdc, x402

## 简介

MCP server for 21millionpixels.art: read the canvas free, pay per pixel in USDC over x402 to paint, with a spending cap and a dry-run mode

## 官网

- 官网：https://21millionpixels.art/docs
- 源码仓库：git+https://github.com/Kedawgs/21millionpixels-agents.git
- npm 页面：https://www.npmjs.com/package/21millionpixels-mcp
