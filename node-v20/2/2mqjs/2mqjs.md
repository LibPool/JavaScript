# 2mqjs

> 标签: event-bus, frontend-architecture, lazy-loading, state-management, typescript, vanilla-js, web-performance, web-workers

## 简介

A tiny performance-first architecture toolkit for framework-free web apps: lazy components, event ports, workers, tasks, and an off-main-thread store.
