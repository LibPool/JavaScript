# @mukundakatta/skillint

> 标签: anthropic, claude, claude-code, cli, github-action, linter, sarif, skill, validator

## 简介

Linter for Claude Code skill files (SKILL.md). Validates YAML frontmatter, required fields, descriptions, and secret leaks. CLI + GitHub Action.
