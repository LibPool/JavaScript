# @agent-invoice/mcp-server

> 标签: agent-invoice, claude, cursor, invoicing, mcp, model-context-protocol

## 简介

Model Context Protocol (MCP) server for Agent Invoice: create clients, issue invoices and estimates, record payments and send them from Claude, Cursor and any MCP client.
