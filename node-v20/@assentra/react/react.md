# @assentra/react

> 标签: approvals, enterprise-ui, policy-gate, rbac, react, web-crypto

## 简介

React components for approval workflows: dependency-aware forms, tradeoff comparison, escalation gates and a signed-seal inspector. Ships a precompiled, scoped stylesheet.
