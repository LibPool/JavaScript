> 标签: agent-auth, agent-identity, agent-security, agent-trust, agent-verification, ai-agent, attestation-registry, autonomous-agents, cli, creduent, creduent-cli, crewai, cryptographic-signing, dns-verification, ed25519, idevsec, langgraph, mcp, model-context-protocol

## 简介

The official command-line interface for Creduent: the open standard and security protocol for cryptographic AI agent identity, authentication, and trust verification using Ed25519 and DNS.
