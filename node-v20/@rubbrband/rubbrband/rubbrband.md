# @rubbrband/rubbrband

> 标签: JavaScript

## 简介

The Rubbrband JS library provides convenient access to the Rubbrband API from applications written in Javascript. It includes a class for API resources that clients can initialize with their API key, which they can retrieve from https://dashboard.rubbrban
