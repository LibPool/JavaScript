# @varnir/plan-limits

> 标签: JavaScript

## 简介

Zero-dependency plan-limits table and effective-plan resolver shared by the scanner, the wallets, the SDK and minigate. Compiled to CommonJS with declarations so minigate (node10/CommonJS) can require() the same source of truth the bundler and React-Nativ
