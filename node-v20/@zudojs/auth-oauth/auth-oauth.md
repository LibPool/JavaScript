# @zudojs/auth-oauth

> 标签: authorization-code, oauth, oauth2, pkce, social-login, zudojs

## 简介

OAuth2 authorization-code client for the Zudojs framework — PKCE S256, mandatory state, SSRF-guarded endpoints, and provider presets for Google, GitHub, Microsoft, Apple and Discord.
