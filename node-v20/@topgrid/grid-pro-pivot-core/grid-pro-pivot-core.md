# @topgrid/grid-pro-pivot-core

> 标签: data-table, datagrid, grid, headless, pivot, pivot-table, table, tanstack-table

## 简介

Framework-neutral pivot engine: declarative 2-D pivot transform + pure value reducers (no React/Vue). Consumed by @topgrid/grid-pro-pivot (React) and grid-pro-pivot-vue.
