# rolt-agent

> 标签: agent, ai, anthropic, deepseek, llm, mcp, nextjs, observability, openai, opentelemetry, sandbox, tools, tracing

## 简介

Rolt: a self-correcting AI agent for Node.js and Next.js. Plans, runs code in a sandbox, searches the web, uses your tools and MCP servers, and checks its own answers.
