# @4gency/capacitor-volume

> 标签: 4gency, android, audio, capacitor, ios, plugin, ratio, sound, volume, web

## 简介

A Capacitor plugin to control device volume with ratio-based API (0.0 to 1.0). Full support on Android (API 21+), read-only on iOS (11.0+), limited support on Web. Compatible with Capacitor 5+.
