# @kbach/cli

> 标签: cli, css, react, react-native, setup, styling, tailwind, utility-first

## 简介

Kbach's setup CLI — `npx @kbach/cli init` wires up @kbach/react or @kbach/react-native in an existing project (framework detection, config edits, install); `npx @kbach/cli doctor` diagnoses an already-broken setup. Installed globally (`npm i -g @kbach/cli
