# @sv-kit/a11y-keys

> 标签: a11y, accessibility, focus-trap, keyboard, roving-focus, screen-reader, shortcut, svelte

## 简介

Composable a11y helpers for Svelte: roving focus, focus trap, keyboard shortcuts, and screen-reader announcements.
