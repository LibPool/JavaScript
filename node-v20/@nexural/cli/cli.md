# @nexural/cli

> 标签: JavaScript

## 简介

The `nx` CLI — single human-facing command for the Nexural Federation. Commands: ask, audit, ecosystem (list/health/env), forge, health, new, open, play, project (add/list/check), serve, session save, status, sync, verify. Per ARCHITECTURE.md §4.1 + docs/
