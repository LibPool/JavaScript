# @thi.ng/base-n

> 标签: array, base10, base16, base26, base32, base36, base58, base62, base64, base8, base83, base85, bigint, binary, conversion, decode, encode, string, typescript

## 简介

Arbitrary base-n conversions w/ presets for base8/16/32/36/58/62/64/83/85, support for bigints and encoding/decoding of byte arrays
