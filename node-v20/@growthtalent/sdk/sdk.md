# @growthtalent/sdk

> 标签: JavaScript

## 简介

TypeScript SDK for the Growth.Talent API. Type-safe client auto-generated from the OpenAPI 3.1 spec — search, view, apply to, and post growth marketing jobs from any Node, browser, or edge runtime.
