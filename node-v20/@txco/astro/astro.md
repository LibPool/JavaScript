# @txco/astro

> 标签: astro, astro-integration, static, thanks-computer, txco, web-abi, withastro

## 简介

Astro integration for Thanks, Computer (txco): after `astro build`, writes a Web ABI build — your static site as public/, a 404 page and catch-all as ops/, and txco-web.json — for `txco apply` to install.
