# @wovyr/ui-react

> 标签: JavaScript

## 简介

React renderer for Wovyr's generative-UI frame protocol (PRD-005 RDR-4xx): consumes trust-layer-validated UiFrames and turns human decisions into typed, boundary-validated API calls.
