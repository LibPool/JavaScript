# @meterbox/mcp

> 标签: billing, claude, mcp, meterbox, model-context-protocol

## 简介

Meterbox MCP server: the hosted /mcp endpoint's tools and policy, plus a stdio bridge (npx @meterbox/mcp) for MCP clients that only speak stdio.
