# @klyftig/missions

> 标签: alarm, expo, klyftig, missions, react-native

## 简介

Klyftig alarm dismissal missions for Expo / React Native: registry, MissionRunner (chains), type picker + config editor, and the Math / Shake / Memory / Barcode / Typing / Squat / Steps / Photo / Maze screens. Built on @klyftig/alarm-core's mission model.
