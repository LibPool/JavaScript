# openflowkit

> 标签: architecture, cli, d2, diagram, mcp, mermaid, openflowkit, structurizr, svg

## 简介

The OpenFlowKit CLI: render Mermaid, D2, Structurizr or OpenFlow DSL to SVG, validate diagrams in CI, map a repo. Same as @openflowkit/openflowkit-mcp.
