# @cjboco/cj-image-flip-previewer

> 标签: 360, animation, flipbox, hover, image, interactive, mouseover, product-view, react, thumbnail, video-previewer

## 简介

React components for interactive image previews - flip through images by mouse position (FlipPreviewer) or animate frames on hover like a video previewer (VideoPreviewer).
