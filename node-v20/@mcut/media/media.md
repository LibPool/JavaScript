# @mcut/media

> 标签: export, mcut, media, timeline, typescript, video, video-editing, webcodecs

## 简介

Media I/O for mcut on Mediabunny: probing, thumbnails, audio extraction, frame sources, client-side export with a pluggable container-format registry (MP4/WebM/MKV built in)
