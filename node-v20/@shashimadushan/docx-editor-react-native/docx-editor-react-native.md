# @shashimadushan/docx-editor-react-native

> 标签: document, docx, editor, expo, react-native, webview, word

## 简介

React Native (Expo + bare) wrapper for the docx-editor-toolkit editor — a touch-friendly DOCX editor rendered inside a WebView, with a typed postMessage bridge for loading/saving .docx bytes.
