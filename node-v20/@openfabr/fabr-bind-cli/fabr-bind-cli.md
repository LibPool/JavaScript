# @openfabr/fabr-bind-cli

> 标签: devex, devops, openfabr, secrets, secretsmanager, ssm

## 简介

FABR Cloud Bind CLI - A CLI for generating code that binds code to infrastructure via a secret store. The CLI aims to be automation friendly, for example in CI/CD. The client libs aims to make access easy for app devs.
