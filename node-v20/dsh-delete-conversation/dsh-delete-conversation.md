# dsh-delete-conversation

> 标签: conversation, deepseek-harness, delete, dsh, dsh-bundle, dsh-plugin, menu, session, sidebar

## 简介

DSH 插件：在侧边栏会话的「…」菜单里加一项「删除会话」，彻底删除该会话的日志、工作区归属与投影缓存。Adds a "Delete session" action to the DeepSeek Harness sidebar session menu that permanently removes the stored session. 1.0.2 修复点击删除时恒报 403「deletion is limited to same-origin loopback requests」（旧实现强制要求
