# dsh-plugin-highlight-notes

> 标签: annotation, annotations, comment, deepseek-harness, dsh, dsh-plugin, highlight, note, notes, quote, 批注, 标注

## 简介

Annotations for DeepSeek Harness: select text in an answer, highlight or quote it with a note, and drop the excerpt back into the composer.
