# @revu-ai/server

> 标签: ai-crawler, analytics, bot, crawler, edge, middleware, revu, server

## 简介

REVU Server SDK - reports the crawler requests that reach your own web server to REVU. Zero dependencies. Runs on Node, Bun, Deno and edge runtimes.
