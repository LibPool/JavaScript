# @moku-labs/system

> 标签: JavaScript

## 简介

Isomorphic system API for Moku — store, notify, clipboard, tray, and deep-link capabilities via an env-style provider pattern (Tauri provider when the shell is detected, web fallback otherwise). Same island code runs on web and native.
