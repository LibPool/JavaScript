# @lynage/mcp

> 标签: JavaScript

## 简介

**Model Context Protocol server for [Lynage](https://github.com/qiao-coding/lynage-memory)** — exposes Lynage memory as 6 MCP tools (`lynage_memory_read` / `search` / `open_source` / `commit` / `read_user` / `stats`) for Claude Code and other MCP clients.
