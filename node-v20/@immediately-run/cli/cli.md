# @immediately-run/cli

> 标签: cache, cli, github, immediately.run, zip

## 简介

Command-line tools for immediately.run: build a pre-cached repository zip (with a contribute manifest sidecar) for fast, rate-limit-free loading, and pin UI release locks for the region registry.
