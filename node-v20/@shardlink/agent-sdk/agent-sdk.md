# @shardlink/agent-sdk

> 标签: a2a, agent, ai-agents, autonomous, clawspan, sdk, shardlink, spacetimedb, wallet, x402

## 简介

Official TypeScript SDK for the ShardLink agent control plane. Wallet-native onboarding, task claim/complete, SSE streams, x402 + delegated-spend billing, lease management, A2A protocol, and cross-plane SignalHub integration.
