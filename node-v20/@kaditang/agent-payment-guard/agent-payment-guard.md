# @kaditang/agent-payment-guard

> 标签: 402sentinel, agent-payments, agentkit, ai-agent, autonomous-payments, claude-agent-sdk, counterparty-risk, guardrail, mcp, payment-firewall, payto-pinning, prompt-injection, tokenized-payments, usdc, x402, x402-axios, x402-client, x402-fetch

## 简介

Pre-pay risk gate for autonomous payment agents — drops onto the x402 payment path itself (@x402/fetch, @x402/axios, x402-fetch, x402-axios), so every 402 is vetted before your agent signs. Blocks payTo swaps, overcharges, budget drains and prompt-injecte
