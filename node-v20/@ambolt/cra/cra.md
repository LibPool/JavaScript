# @ambolt/cra

> 标签: compliance, cra, cyber-resilience-act, cyclonedx, osv, sbom, security-txt, spdx, vulnerability-disclosure

## 简介

Command-line checks for the EU Cyber Resilience Act: SBOM minimum-element check with optional OSV lookup, security.txt and vulnerability disclosure policy generators. No dependencies.
