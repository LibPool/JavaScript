# @rnw-community/log-decorator

> 标签: decorator, framework-agnostic, log, logging, method decorator, universal

## 简介

Universal log method decorator with pluggable transport and pre/post/error hooks. Built on TypeScript's experimentalDecorators. Zero framework dependencies.
