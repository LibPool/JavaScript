# @lazily-hub/lazily-html

> 标签: JavaScript

## 简介

Isomorphic fine-grained HTML renderer on @lazily-hub/lazily-js. Preact/React-compatible API (Component class, hooks, createElement/h, createContext, forwardRef, memo, render, renderToString) with Solid-style run-once components: setState writes a lazily S
