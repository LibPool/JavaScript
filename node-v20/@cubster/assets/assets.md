# @cubster/assets

> 标签: assets, cubster, images, netlify, react, sdk, uploads

## 简介

Typed TypeScript SDK for the Cubster Assets API — keys, workspaces, uploads, grants, assets, and image/file URL builders, with an optional React subpath.
