# @vajajak/payload-plugin-typograf

> 标签: czech, nbsp, payload, payload-plugin, payloadcms, typograf, typography

## 简介

Payload CMS plugin that inserts non-breaking spaces after single-letter words (Czech prepositions and conjunctions) using typograf.
