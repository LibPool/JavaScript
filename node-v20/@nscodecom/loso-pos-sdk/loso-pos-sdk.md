# @nscodecom/loso-pos-sdk

> 标签: ecr, loso, loyalty, point-of-sale, pos, sdk

## 简介

Typed client for the Loso POS loyalty API (/api/pos/v1). Grant and spend loyalty on a sale while speaking only in money.
