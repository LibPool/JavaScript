# @ewanmellor/parcel-plugin-inline-svg

> 标签: JavaScript

## 简介

Ewan Mellor's version of SVGR Parcel plugin.  This is a fork of @svgr/parcel-plugin-svgr, with the only meaningful change being that we register for .inline-svg instead of .svg.
