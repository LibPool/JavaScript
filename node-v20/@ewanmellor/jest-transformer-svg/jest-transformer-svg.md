# @ewanmellor/jest-transformer-svg

> 标签: jest, react, svg, test, transformer

## 简介

Ewan Mellor's version of jest-transformer-svg. This is a fork of https://github.com/Em-Ant/jest-transformer-svg, which in turn is a fork of https://www.npmjs.com/package/jest-svg-transformer. The only meaningful change here is that we support .inline-svg
