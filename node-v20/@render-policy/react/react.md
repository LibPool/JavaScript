# @render-policy/react

> 标签: a2ui, agent, llm, markdown, react, sanitize, sanitizer, security, streaming, trusted-types, xss

## 简介

React adapter for @render-policy/core: render agent Markdown/HTML into a ref without dangerouslySetInnerHTML, with a streaming mode; A2UI Text and Image components under @render-policy/react/a2ui.
