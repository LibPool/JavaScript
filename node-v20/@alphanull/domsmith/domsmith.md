# @alphanull/domsmith

> 标签: declarative, dom, dom builder, event handling, frontend, html, svg, ui

## 简介

DomSmith is a lightweight and declarative DOM builder for JavaScript that enables you to create, update, and remove DOM trees with an intuitive API.
