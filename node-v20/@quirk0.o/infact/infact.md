# @quirk0.o/infact

> 标签: factory

## 简介

Infact is a JavaScript library for creating object factories that can be used for tests or mock servers. It's written in TypeScript and provides typings out of the box. Inspired heavily by [factory_bot](https://github.com/thoughtbot/factory_bot).
