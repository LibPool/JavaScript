# @cosmwasm/ts-codegen

> 标签: codegen, cosmwasm, interchain, smart contracts

## 简介

@cosmwasm/ts-codegen converts your CosmWasm smart contracts into dev-friendly TypeScript classes so you can focus on shipping code.
