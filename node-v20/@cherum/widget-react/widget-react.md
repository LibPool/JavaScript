# @cherum/widget-react

> 标签: batch-payments, bridge, cherum, cross-chain, defi, disperse, ethereum, evm, fan-out, multi-chain, multisend, payments, payouts, react, swap, web3, widget

## 简介

Embeddable cross-chain fan-out swap widget for React — send to many wallets across chains and tokens in one signature. Multisend, disperse and batch payouts without custody; partner fees built in.
