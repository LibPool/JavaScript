# @bugloper/activejs

> 标签: activesupport, callbacks, duration, inflector, pluralize, rails

## 简介

A port of Rails' ActiveSupport to JavaScript: inflector, durations, date calculations, callbacks, notifications, caching, message verification and core extensions.
