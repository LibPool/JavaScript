# @aymenkits/pay-core

> 标签: commission, connect, core, escrow, marketplace, payments, stripe

## 简介

Pure money math: Charge = typed components (base/delivery/tip/…), FeePolicy with per-component commission and per-merchant overrides, escrow release math (commission + accrued-fee recoup), subscription tier pricing. No Stripe, no I/O — fully unit-testable
