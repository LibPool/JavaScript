# @aymenkits/chat-core

> 标签: chat, core, messaging, realtime, socket.io, threads

## 简介

Chat engine: scope-typed threads (order/inquiry/salon-pair) with a policy deciding who chats with whom, send pipeline persist → realtime → presence-miss → notifier, unread counts, system messages, per-sender rate limiting. Seams: ThreadStore, MessageStore
