# @aymenkits/notify-core

> 标签: core, email, fcm, notifications, push, realtime, sms

## 简介

Notification dispatcher: in-app record first (source of truth), then per-channel fan-out (push/email/SMS/realtime) with error isolation. Seams: NotificationStore, PreferenceResolver, TemplateRenderer, channel senders. Includes structural FCM/SMTP/Twilio/S
