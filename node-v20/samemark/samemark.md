# samemark

> 标签: commonmark, fast, gfm, markdown, mdast, micromark, parser, remark, unified

## 简介

The same mdast as remark-parse, much faster: a markdown parser that matches mdast-util-from-markdown with GFM and falls back to it for anything else.
