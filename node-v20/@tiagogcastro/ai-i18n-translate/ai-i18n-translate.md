# @tiagogcastro/ai-i18n-translate

> 标签: ai, anthropic, cli, deepseek, gemini, i18n, internationalization, json, l10n, locale, localization, openai, translate, translation

## 简介

AI-powered i18n JSON translation CLI and library. Translates locale files automatically using OpenAI, Anthropic, Gemini, or DeepSeek. Supports parallel processing, translation caching, zero-fallback retry, dry-run, git-diff mode, markdown reports, and cus
