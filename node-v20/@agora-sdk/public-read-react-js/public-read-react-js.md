# @agora-sdk/public-read-react-js

> 标签: agora, anonymous, comments, embed, public, react, read-only, typescript, web

## 简介

Web components for the Agora anonymous public surface: a drop-in, read-only comment thread a blog can embed with no account and no Agora SDK installed. Re-exports @agora-sdk/public-read-core.
