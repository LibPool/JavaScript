# @agora-sdk/secure-chat-react-js

> 标签: agora, e2ee, mls, react, secure-chat, typescript, web

## 简介

Web (browser) bindings for Agora secure chat: real MLS crypto (ts-mls) + IndexedDB persistence. Re-exports @agora-sdk/secure-chat-core.
