# @fulate/components

> 标签: JavaScript

## 简介

`@fulate/components` 提供基于 Vue 和 Material Design 3 的 Canvas UI 组件：`FButton`、`FInput`、 `FSelect`、`FRadio`、`FCheckbox`、`FSwitch`、`FIcon`、`FTooltip`、`FPopover`、`FDialog` 与 `FMessage`。 导入包会加载 `@fulate/vue/yoga` 的标签注册，以便组件模板使用 Flex 容器。
