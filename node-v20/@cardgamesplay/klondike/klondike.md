# @cardgamesplay/klondike

> 标签: browser-game, canvas-game, card-game, drag-and-drop, free-online-game, html5-game, i18n, keyboard-accessible, klondike, patience, solitaire, typescript, vanilla-js, web-audio

## 简介

Browser-based Klondike Solitaire game built with TypeScript and vanilla DOM. Features drag-and-drop, keyboard navigation, card animations, sound effects, a music player, and i18n support for 16 languages. Play free at https://www.cardgamesplay.com/
