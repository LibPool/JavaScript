# @sapfever/dashboard-mcp-client

> 标签: claude, mcp, model-context-protocol, ms-copilot, sap, sapfever

## 简介

Stdio→HTTP bridge that connects Claude Desktop (and any stdio MCP client) to a SAPF Dashboard /api/mcp endpoint.
