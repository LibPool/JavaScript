# @siliph/pdf-engine

> 标签: browser-pdf, canvas2d, client-side, document-editor, esm, ilovepdf-alternative, javascript, no-server, offline-pdf, pdf, pdf-annotations, pdf-editor, pdf-encrypt, pdf-forms, pdf-manipulation, pdf-merge, pdf-parser, pdf-renderer, pdf-sdk, pdf-sign, pdf-split, pdf-toolkit, pdf-viewer, sejda-alternative, smallpdf-alternative, tree-shakeable, typescript, web-workers

## 简介

Complete browser-native PDF editing engine — parse, render, merge, split, edit text, fill forms, sign, encrypt, annotate, and export PDFs entirely client-side. No server required. TypeScript-first with tree-shaking support.
