# @abdurrahmanbd/bd-institution-list

> 标签: bangladesh-colleges, bangladesh-schools, bangladesh-universities, bd-college-list, bd-institutes, bd-institution-list, bd-madrasha-list, bd-school-list, bd-university-list, eiin

## 简介

Comprehensive, fast, TypeScript-native NPM package for all Bangladeshi educational institutions (Schools, Colleges, Universities, Madrashas). Support O(1) EIIN lookup, search, and category filters.
