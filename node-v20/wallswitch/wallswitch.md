# wallswitch

> 标签: background-changer, carousel, cli, desktop, desktop-background, electron, global-shortcuts, gnome, linux, macos, slideshow, system-tray, tray, ubuntu, wallpaper, wallpaper-changer, wallpaper-rotator, wallpaper-slideshow, wallpaper-switcher, windows

## 简介

Minimalist wallpaper changer for Linux, Windows and macOS: automatic wallpaper rotation (slideshow), tray icon, global keyboard shortcuts and CLI.
