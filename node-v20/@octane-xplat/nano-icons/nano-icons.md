# @octane-xplat/nano-icons

> 标签: cross-platform, icons, nativescript, octane, svg

## 简介

Build-time icon fonts and layered glyph rendering for Octane Xplat — SVG directories or Iconify collections compile to a TTF + typed glyph map (pipeline adapted from react-native-nano-icons)
