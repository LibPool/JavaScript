# @octane-xplat/shaders

> 标签: canvas, cross-platform, gpu, graphics, nativescript, octane, shader, webgpu, wgsl, xplat

## 简介

Thin adapter that runs the published `shaders` WebGPU library on Octane xplat Canvas surfaces — web (implemented) and NativeScript iOS/Android (experimental, device verification pending)
