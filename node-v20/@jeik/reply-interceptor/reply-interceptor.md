# @jeik/reply-interceptor

> 标签: JavaScript

## 简介

维护模式 / 宕机开关：在配置文件里打开开关后，网关**不再调用上游 LLM**，直接向渠道推送自定义文案（如「服务宕机，请稍后再试」）。
