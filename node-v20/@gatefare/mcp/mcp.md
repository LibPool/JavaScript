# @gatefare/mcp

> 标签: ai-agents, anthropic, api-marketplace, base, claude, coinbase, cursor, gatefare, llm-tools, mcp, mcp-server, micropayments, model-context-protocol, paid-apis, stablecoin-payments, usdc, web3, x402

## 简介

MCP server for the Gatefare paid-API marketplace. Works with Claude Desktop, Cursor, Continue, and any MCP client. Pay per API call in USDC on Base via the open x402 standard. Non-custodial.
