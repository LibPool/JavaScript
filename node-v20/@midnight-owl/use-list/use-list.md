# @midnight-owl/use-list

> 标签: composables, filtering, pagination, table, typescript, vue, vue-composables, vue3

## 简介

Free, MIT-licensed Vue 3 composable. useList is a reactive search + per-field filter + sort + paginate pipeline for a plain array ref, framework-agnostic and SSR-safe.
