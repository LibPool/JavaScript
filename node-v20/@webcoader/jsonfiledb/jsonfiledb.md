# @webcoader/jsonfiledb

> 标签: database, db, file, json, jsonfiledb, lite

## 简介

jsonFileDB is a lightweight and flexible database library that provides simple yet powerful functionality for managing and interacting with JSON-based storage files. It allows users to create and manage databases in a folder, define multiple storage files
