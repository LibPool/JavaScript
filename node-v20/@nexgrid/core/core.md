# @nexgrid/core

> 标签: csv, data-grid, datagrid, excel, export, pagination, server-side, sorting, table, tablex

## 简介

Framework-agnostic engine for TableX: server-driven query contract, grid state helpers, CSV/Excel export, and the shared theme.
