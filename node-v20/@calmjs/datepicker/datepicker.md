# @calmjs/datepicker

> 标签: accessible, calendar, css-modules, customizable, date, datepicker, form, formik, headless, react, react-hook-form, tailwind, tailwindcss, typescript

## 简介

A headless, production-ready React datepicker component that works with any form library. Fully customizable with Tailwind CSS, CSS Modules, or inline styles.
