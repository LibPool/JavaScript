# @customyai/experience-client

> 标签: customy, ed25519, experience, hermes, i18n, react-native, signed-manifest, translations

## 简介

Customy Experience client: verifies signed release manifests (Ed25519) and serves translations, brand tokens, compositions and decisions from the last good release. Runs in browsers, Node and React Native/Hermes (portable crypto).
