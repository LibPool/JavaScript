# @customyai/server

> 标签: auth, customy, jwks, jwt, sdk, server

## 简介

Customy identity verification for any server: JWKS with rotation, machine and user token verifiers, BFF actor assertions and request verification over the standard Request, with a Node IncomingMessage adapter. Server only.
