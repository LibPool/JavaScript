# @customyai/stories-render

> 标签: banners, customy, headless, react, stories, web

## 简介

Customy Stories renderer: headless core (state machine, ordering, seen state, preload, gestures, layout) plus light web and React components for story bars, story viewers and banners, and an optional module with the interactive components (quiz, reactions
