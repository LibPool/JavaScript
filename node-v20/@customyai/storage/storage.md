# @customyai/storage

> 标签: customy, files, sdk, storage, uploads

## 简介

Customy Storage for connected applications: upload bytes from memory (checksum and multipart handled), read metadata, signed download URLs and trash, over @customyai/core (typed errors, retries with Retry-After, idempotency, Access machine tokens). Server
