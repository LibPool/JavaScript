# @customyai/send

> 标签: customy, email, in-app, inbox, notifications, push, react, react-native, sdk

## 简介

Customy Send: email, templates, domains, webhooks, suppressions, notifications, push and in-app messages for servers, over @customyai/core (typed errors, retries with Retry-After, idempotency, Access machine tokens); ./inbox and ./inbox/react for end-user
