# @schorts/redis-cache

> 标签: cache, node, redis

## 简介

A lightweight implementation of the Cache<T> interface from @schorts/shared-kernel using Redis. This package provides persistent caching in Node with support for TTL (time-to-live) expiration and tag-based deletion.
