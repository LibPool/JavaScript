# @tevui/textarea

> 标签: JavaScript

## 简介

Componente React para texto multilinha, com label, dica, mensagem de erro e validação de campo obrigatório. Compatível com React 18 e 19.

- npm 页面：https://www.npmjs.com/package/@tevui/textarea
