# @pracht/session

> 标签: aes-gcm, auth, authentication, cookie, pracht, preact, session, webcrypto

## 简介

First-party sessions for Pracht: encrypted cookie sessions or store-backed session ids, secret rotation, flash messages, and session middleware. WebCrypto only, so it runs unchanged on Node, Cloudflare Workers, Netlify, and Vercel.
