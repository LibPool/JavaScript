# @emulon/github

> 标签: JavaScript

## 简介

Local GitHub App emulator with isolated `api` and `web` endpoints. The API supports `GET /app`, `GET /app/installations`, and `POST /app/installations/:installationId/access_tokens` under RS256 App JWTs. Both surfaces return 404 JSON for unsupported route
