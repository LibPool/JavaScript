# @undeffineddev/indexa

> 标签: browser, crud, database, db, indexeddb, localstorage, reactive, storage, subscription, typescript, wrapper

## 简介

A small TypeScript-friendly wrapper for the browser IndexedDB API, providing typed stores, simple CRUD operations, and reactive subscriptions.
