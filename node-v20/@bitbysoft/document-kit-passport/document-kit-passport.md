# @bitbysoft/document-kit-passport

> 标签: JavaScript

## 简介

Passport/identity document domain plugin for BitBySoft DocumentKit — maps generic AI extraction output into a validated, typed passport structure via a replaceable PassportProvider. Reuses ai-extraction and ocr; duplicates no OCR, MRZ scanning, or AI logi
