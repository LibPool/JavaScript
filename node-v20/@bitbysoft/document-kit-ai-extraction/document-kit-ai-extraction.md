# @bitbysoft/document-kit-ai-extraction

> 标签: JavaScript

## 简介

AI document extraction plugin for BitBySoft DocumentKit — extracts structured fields from a session's OCR output via a replaceable AIExtractionProvider. Depends on the ocr plugin at registration time, not at compile time.
