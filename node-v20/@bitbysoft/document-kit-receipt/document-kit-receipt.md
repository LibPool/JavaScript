# @bitbysoft/document-kit-receipt

> 标签: JavaScript

## 简介

Receipt domain plugin for BitBySoft DocumentKit — maps generic AI extraction output into a typed receipt structure via a replaceable ReceiptProvider. Reuses ai-extraction and ocr; duplicates no OCR or AI logic. Depends on the ai-extraction plugin at regis
