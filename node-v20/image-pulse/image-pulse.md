# image-pulse

> 标签: avif, core-web-vitals, github-action, images, lighthouse, performance, sarif, srcset, static-site, webp

## 简介

Find oversized and unoptimised images in a built static site: heavy files, images far wider than displayed, JPEG/PNG without AVIF/WebP, missing width/height, srcset and sizes, animated GIFs, opaque PNG photos, bloated SVGs. Reads image headers, no network
