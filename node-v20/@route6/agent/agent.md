# @route6/agent

> 标签: agent, ai-agent, ipv6, mcp, model-context-protocol, networking, route6, tunnel, wireguard

## 简介

Route6 client launcher — downloads, verifies and runs the r6me binary. Gives an AI agent its own public IPv6 identity, MCP endpoint and egress.
