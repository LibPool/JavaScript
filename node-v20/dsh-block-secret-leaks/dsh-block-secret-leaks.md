# dsh-block-secret-leaks

> 标签: agent, api-key, deepseek, deepseek-harness, dotenv, dsh, dsh-plugin, guard, redact, secrets, security

## 简介

DeepSeek Harness plugin that keeps secrets out of the conversation and out of git: blocks reading .env and key files, printing or uploading secrets, committing them, and redacts them from tool output.
