# @degreesign/analytics

> 标签: IP geolocation, analytics, browser, click tracking, cookie-free tracking, cookieless analytics, degreesign, inview tracking, nodejs, pageview tracking, privacy analytics, privacy-first, rate limiting, sdk, self-hosted, self-hosted analytics, traffic analysis, typescript, umd, web analytics

## 简介

Privacy-first, self-hosted web analytics SDK for Node.js and the browser - pageviews, clicks, in-view events, IP geolocation and traffic reports with TypeScript support.
