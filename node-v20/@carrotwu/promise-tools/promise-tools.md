# @carrotwu/promise-tools

> 标签: JavaScript

## 简介

### warmAll(task, [options]) + task: promiseLike函数即可 + options.race: 最大超时时间 伪取消请求 请求依然会发出正常处理，知识如果等待时间超过超时时间那么返回的res数组就是error类型 + options.limit: 最大并发数
