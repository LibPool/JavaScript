# @yroshcha/node-red-contrib-redis-full

> 标签: ioredis, node-red, pubsub, redis, redis-streams, xadd, xreadgroup

## 简介

Production-oriented Redis palette for Node-RED: generic commands, Pub/Sub, scans, transactions, and Redis Streams consumer groups.
