# @kaibutsujp/pitch-mcp

> 标签: JavaScript

## 简介

怪物ベースボールの投球軌道シミュレーター向けの MCP サーバ。「左下ぎりぎりに来る140キロのストレート」のような日本語の指示から、AI が投球軌道パラメータを生成できるようにする
