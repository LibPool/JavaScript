# @runonflux/flux-cloud-mcp

> 标签: ai-agent, decentralized-cloud, deploy, flux, fluxcloud, mcp, model-context-protocol, runonflux

## 简介

MCP server for Flux Cloud. Lets any AI agent quote, deploy, pay for, inspect and manage apps on the Flux decentralized cloud, priced in USD.
