# @runonflux/kaspa-core

> 标签: bip340, kaspa, multisig, p2sh, schnorr, wallet

## 简介

Pure-TypeScript Kaspa transaction library: addresses, scripts, M-of-N P2SH multisig, sighash, BIP340 signing, KIP-9 mass and fee, input selection. No WASM, two dependencies.
