# @patchstack/connect

> 标签: application-security, attack-surface, cve, dependency-scanning, nodejs-security, npm-audit, patchstack, rasp, runtime-security, sca, secret-redaction, security, ssrf, virtual-patching, vulnerability, waf

## 简介

Runtime application security for JavaScript and Node.js: dependency inventory, attack-surface mapping, and an in-process guard that virtually patches known vulnerabilities and hardens responses.
