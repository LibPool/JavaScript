# @mythwork/sdk

> 标签: JavaScript

## 简介

The Mythwork inner-app client: port handshake, typed request() against the method map, subscribe() against the event map, and thin namespaced helpers (sdk.fs.read, sdk.auth.getUser, ...). Dependency-free except @mythwork/protocol.
