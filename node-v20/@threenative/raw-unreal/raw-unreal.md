# @threenative/raw-unreal

> 标签: loader, static-mesh, three, threejs, threenative, uasset, unreal

## 简介

Loads raw Unreal editor .uasset static meshes directly into Three.js geometry — UE5 FMeshDescription and UE4.18 FRawMesh layouts, with no interchange conversion.
