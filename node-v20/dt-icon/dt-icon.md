# dt-icon

> 标签: angular, animated-icons, animation, custom-elements, icon-library, icons, morph, morphing, react, spring, stroke-icons, svelte, svg, tandd, vue, web-components

## 简介

1,440 stroke icons that morph into each other with spring physics. Components for React, Vue, Svelte, Angular and plain HTML. No dependencies.
