# @gothub/pulumi-gotiac-aws

> 标签: JavaScript

## 简介

This repo is a boilerplate showing how to create a Pulumi component provider written in Go. You can search-replace `gotiac` with the name of your desired provider as a starting point for creating a component provider for your component resources.
