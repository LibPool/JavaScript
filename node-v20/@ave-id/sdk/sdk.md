# @ave-id/sdk

> 标签: JavaScript

## 简介

TypeScript SDK for [Ave](https://aveid.net): passkey sign-in over OAuth 2.0 and OpenID Connect, with per-user end-to-end encryption keys delivered straight to your client code.
