# @faraday-academy/ui

> 标签: JavaScript

## 简介

Faraday shared design system — shadcn/Base UI primitives (.cn-* + CSS style layer). Lessons consume via @faraday-academy/kit re-exports; the platform app imports this package directly with platform.css.
