# pi-skills-anywhere

> 标签: autocomplete, coding-agent, pi-extension, pi-package, skills

## 简介

Invoke Pi skills from anywhere: /name commands for every skill, a mid-sentence slash popup, and in-place expansion of /name tokens and <skill> tags.
