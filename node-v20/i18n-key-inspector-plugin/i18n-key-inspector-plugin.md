# i18n-key-inspector-plugin

> 标签: devtools, i18n, inspector, vite-plugin, webpack-plugin

## 简介

Dev-only Vite/webpack plugin that stamps rendered DOM elements with their i18n message keys (data-i18n-path), so rendered text can be traced back to its message key in DevTools
