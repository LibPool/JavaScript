# @mosetta/i18n-kit

> 标签: JavaScript

## 简介

mosetta-i18n tile palette: the i18n block — a page's words in every language it serves. Other blocks' settings reference its values; it reads the request's language, ships visitors only theirs, and translates the missing ones through the host's translator
