# @irondsd/inline-svg

> 标签: graphics, inline, svg, typescript, web

## 简介

InlineSVG is a TypeScript library that allows you to easily inline SVG files into your HTML or JavaScript code. It provides a simple API to load SVG files and insert them directly into the DOM, making it easier to manage and manipulate SVG graphics in web
