# @vectotaxsoftwaregmbh/n8n-nodes-taxmetall

> 标签: erp, n8n-community-node-package, taxmetall, vectotax

## 简介

n8n community node for TaxMetall ERP — read customers, articles, orders, offers, invoices, delivery notes, purchase inquiries, purchase orders, purchase invoices, suppliers, dunning, and execute statistics queries via the TaxMetall REST API.
