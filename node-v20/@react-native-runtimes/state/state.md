# @react-native-runtimes/state

> 标签: android, cross-runtime-state, fabric, hermes, ios, multi-runtime, nitro-modules, react-native, react-native-new-architecture, shared-state, state-management, zustand

## 简介

Cross-runtime shared state for React Native multi-runtime apps. Zustand-style API backed by a process-wide C++ singleton — reads and writes from every Hermes runtime without a JS heap boundary.
