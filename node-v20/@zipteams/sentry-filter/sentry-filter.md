# @zipteams/sentry-filter

> 标签: error-tracking, exception-filter, fastify, graphql, nestjs, sentry

## 简介

NestJS exception filter that captures only 5xx errors in Sentry — eliminates 4xx noise, supports HTTP and GraphQL
