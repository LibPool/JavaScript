# @monosmith/eslint-config

> 标签: eslint, eslintconfig, flat-config, monosmith, vertical-slices

## 简介

The shared ESLint flat config every MonoSmith monorepo uses: one root config that lints and formats TS/JS, React, Svelte, Astro, JSON, YAML, TOML, Markdown, CSS and HTML, with vertical-slice rules.
