# @kumoproductions/mcp-aftereffects

> 标签: adobe, after-effects, aftereffects, claude, extendscript, llm, mcp, model-context-protocol, motion-graphics

## 简介

TypeScript MCP server for Adobe After Effects (Windows & macOS) — project/comp/layer introspection, atomic undo-grouped operations, JSON project export/import, and single-frame rendering via file IPC.
