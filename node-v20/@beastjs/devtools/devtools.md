# @beastjs/devtools

> 标签: beast, btsx, devtools, octane, refactor, rsbuild, rsbuild-plugin, rspack, rspack-plugin, tsrx, vite, vite-plugin

## 简介

In-page devtools for Beast (BTSX) and Octane apps on Vite, Rspack and Rsbuild: live component state, BTSX → TSRX inspection, and automatic component extraction for deeply nested templates.
