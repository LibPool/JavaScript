# morphe-cli

> 标签: agent, ai, byok, claude, cli, coding-agent, morphe, vibe-coding, web-builder

## 简介

Morphe in your terminal. Say what you want built and the agent makes it in your project folder, on whichever model you bring: Claude, GPT, Gemini, Groq, DeepSeek, xAI, OpenRouter, or a local Ollama / LM Studio model.
