# @dosaygo/browserbox

> 标签: automation, browser, browsergap, chrome, chrome controller, chromescreen, groundcontrol, headless, interactive-image, oni, remoteview, supreme-architect, viewfinder, viewfinderjs, zanj

## 简介

BrowserBox - embeddable remote browser isolation. A WebView for the open web, an unrestricted IFRAME element, a CORS-proxy, and reverse proxy. And secure document viewer. All produced by DOSAYGO.
