# @yoyo-bot/binder-manager

> 标签: JavaScript

## 简介

Shared binder package manager — manifest parsing, validation, semver resolution, source resolution, lockfiles, and install logic for YoYo binders.

- 源码仓库：git+https://github.com/CG-Labs/YoYo.git
