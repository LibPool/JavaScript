# @serpkite/ai-sdk

> 标签: agents, ai-sdk, google, llm, nextjs, serp, serpkite, tools, vercel, web-search

## 简介

SerpKite tools for the Vercel AI SDK: Google search, news, maps, place details, scholar, webpage-to-Markdown, extract, site map and crawl for generateText, streamText and agents in Next.js, Node and edge runtimes.
