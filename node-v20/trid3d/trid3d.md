# trid3d

> 标签: 3d, canvas, obj, renderer, shader, webgl, wireframe

## 简介

A small 3D library for the HTML canvas: wireframes, filled and smooth faces, textures and shader effects, drawn with Canvas 2D or WebGL. No dependencies.
