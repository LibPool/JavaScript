# @shrkcrft/impact-engine

> 标签: blast-radius, code-intelligence, graph, impact-engine, sharkcraft

## 简介

SharkCraft impact engine: graph-backed change analysis. Combines code graph + rule-graph + symbol-reference edges into a v3 impact payload (affected files, symbols, rules, templates, tests, risk).
