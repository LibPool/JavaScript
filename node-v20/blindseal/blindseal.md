# blindseal

> 标签: agents, attestation, audit, mcp, prompt-injection, solana, zero-knowledge

## 简介

Blindseal — a local MCP proxy that screens every tool call (four detection layers), redacts before the model-based layers, keeps a hash-chained audit log, and produces zero-knowledge attestations verifiable on Solana.
