# @digitalcredentials/tls-did-registry

> 标签: JavaScript

## 简介

This repository contains the TLSDIDContract; a ethereum smart contract thats stores a TLS-DID's data and the TLSDIDRegistry; a smart contract that stores mappings between a TLS-DID and a TLSDIDContract. # Development
