# @webmusic/audio

> 标签: audio, audio-decoding, flac, mir, mp3, music, music-analysis, ogg, playback, react, spectrogram, transcription, wav, waveform, web-audio, web-components, webmusic

## 简介

Digital audio for the web: immutable clip model, mp3/wav/ogg/flac decoding via optional WASM peers, playback, MIR analysis, transcription, views, Web Components and React bindings.
