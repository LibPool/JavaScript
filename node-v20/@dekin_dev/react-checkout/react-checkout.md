> 标签: africa, checkout, hubtel, iframe, modal, moolre, payment, payments, payswitch, react

## 简介

A lightweight, provider-agnostic React modal/iframe checkout for embedding hosted payment pages (Hubtel, Moolre, PaySwitch, and custom gateways).
