# @vigilly/node

> 标签: errors, exceptions, metrics, monitoring, node, observability, opentelemetry, otlp, sentry, tracing, vigilly

## 简介

Vigilly observability client for Node.js — exceptions (Sentry-compatible) plus OpenTelemetry traces, metrics and logs in one call.
