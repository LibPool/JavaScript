# @vigilly/observer

> 标签: cli, datadog, observability, opentelemetry, otlp, prometheus, sentry, telemetry, vigilly

## 简介

Local live telemetry viewer for vigilly-instrumented apps — see logs, traces, exceptions and metrics as they are emitted, in a simple web UI.
