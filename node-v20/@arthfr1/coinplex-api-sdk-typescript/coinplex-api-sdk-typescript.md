# @arthfr1/coinplex-api-sdk-typescript

> 标签: JavaScript

## 简介

TypeScript SDK for the Coinplex multichain wallet API: typed WalletClient/PriceClient wrappers over a generated OpenAPI client, plus a stateful MulticoinWallet helper.
