# @ng-linguo/extract

> 标签: angular, cli, extract, gettext, i18n, internationalization, ng-linguo, po, translation

## 简介

The ng-linguo extraction CLI — scans Angular source for translatable messages, manages gettext .po catalogs, and compiles them to runtime JSON. Pure Node, zero Angular deps.
