# @cernosh/server

> 标签: anti-bot, behavioral-biometrics, captcha, jwt, server, validation

## 简介

Server-side validation pipeline for Cerno CAPTCHA: maze-relative behavioral scoring, PoW verification, JWT tokens, CaptchaStore interface
