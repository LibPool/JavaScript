# @barter.game/protocol

> 标签: barter, canonical-json, ed25519, federated, jcs, ledger, mutual-credit

## 简介

Canonical JSON (JCS), ed25519 signing, doc types, and validators for the barter.game federated mutual-credit protocol. Consumed as TypeScript source; no build step. Runs identically under Bun, Node.js, and browser.
