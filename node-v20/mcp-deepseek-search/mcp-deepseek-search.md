# mcp-deepseek-search

> 标签: claude, cline, cursor, deepseek, fetch, mcp, model-context-protocol, search, web-search

## 简介

MCP server exposing DeepSeek's web Search & Fetch tools — web search with rerank/authority scoring and page-to-Markdown fetching, for Claude Desktop, Cursor, Cline, ZCode and any MCP client.
