# @shashwath_45/ssrf-shield

> 标签: aws-metadata, defense, dns-rebinding, firewall, ip-validation, ipv6, nodejs, security, server-side-request-forgery, ssrf

## 简介

A modular SSRF (Server-Side Request Forgery) defense engine. Provides a configurable 13-layer pipeline of validation steps to detect and block SSRF attacks including DNS rebinding, AWS metadata access, IPv6 bypasses, and private IP targeting.
