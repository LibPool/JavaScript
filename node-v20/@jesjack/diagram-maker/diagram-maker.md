# @jesjack/diagram-maker

> 标签: diagram, flowchart, layout, mermaid, png, svg

## 简介

Diagramas de flujo a partir de sintaxis Mermaid con un motor de layout propio: rejilla, líneas rectas y sin cruces. Visor web, recarga en vivo y exportación a SVG/PNG.
