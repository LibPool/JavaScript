# @huloglobal/vendure-plugin-checkout-guard

> 标签: bank-transfer, checkout, manual-capture, payments, reconciliation, stripe, vendure, vendure-plugin

## 简介

The missing safety layer around Vendure checkout and payments: Stripe manual-capture holds that actually place the order, bank transfer with auto-expiry, failed-payment and orphaned-charge visibility with Stripe reconciliation, session-bound order lookup,
