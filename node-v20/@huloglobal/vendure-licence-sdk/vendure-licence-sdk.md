# @huloglobal/vendure-licence-sdk

> 标签: licence, license, vendure, vendure-plugin

## 简介

Licence validation helpers for HULO Vendure plugins. JWT verification, revocation polling and an admin status check used by paid HULO plugins to confirm the host installation is licensed.
