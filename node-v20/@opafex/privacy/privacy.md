# @opafex/privacy

> 标签: anonymisation, data-protection, gdpr, llm, logging, pii, privacy, redaction, uk-gdpr

## 简介

PII redaction for logs and LLM payloads: same value, same token, so a redacted log is still debuggable. UK-aware, zero dependencies.
