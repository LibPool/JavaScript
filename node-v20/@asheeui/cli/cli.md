# @asheeui/cli

> 标签: asheeui, cli, codegen, nextjs, playground, playgrounds, react, scaffold, setup, tailwindcss, tanstack-start, vite

## 简介

Scaffold and maintain AsheeUI in an existing React app, with framework detection, provider wiring, a doctor command, and a playground command that copies an official playground application.
