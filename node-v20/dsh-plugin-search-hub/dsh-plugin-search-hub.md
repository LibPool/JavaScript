# dsh-plugin-search-hub

> 标签: brave-search, deepseek-harness, dsh, dsh-plugin, exa, search, searxng, serper, tavily, web-search

## 简介

Multi-engine web search for DeepSeek Harness: a keyless free mode rotating across free AI search endpoints with per-engine cooldown, plus Tavily, Brave, Serper, Exa, Perplexity, Jina, Bocha and SearXNG, configurable from the Plugins page.
