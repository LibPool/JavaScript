# @modern-office/sideload

> 标签: microsoft-365, modern-office, office-addins, office-js, sideload, unified-manifest, vite, xml-manifest

## 简介

Provides start, sideload, and unsideload for generated projects, including app packaging, registration, host launch, and the in-process Vite dev server.
