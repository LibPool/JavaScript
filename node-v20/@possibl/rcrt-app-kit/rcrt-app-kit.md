# @possibl/rcrt-app-kit

> 标签: advisor, app-control, app-kit, breadcrumbs, rcrt, react, section-registry

## 简介

React application framework for RCRT apps — section registry, app shell with automatic App Control (ui-manifest, advisor, anchors, page context), SWR caching, breadcrumb schema helpers and UI primitives
