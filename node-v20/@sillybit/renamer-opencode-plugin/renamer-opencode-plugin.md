# @sillybit/renamer-opencode-plugin

> 标签: OpenCode, OpenCode-plugin, renamer, text-transform

## 简介

OpenCode plugin that replaces case-insensitive 'OpenCode' text with a configurable value (default: 'Renamer') across chat messages, system prompts, tool outputs, and session titles
