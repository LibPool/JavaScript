# @csntgao/uni-base

> 标签: JavaScript

## 简介

用于把 Uniplat 登录、应用切换和数字员工聊天能力嵌入第三方网页的 TypeScript SDK。v0.1 包含与 UI 无关的浏览器客户端、一组标准 Web Component，以及原生 HTML 接入示例。
