# @hive-academy/ptah-cli

> 标签: a2a, agent-sdk, ai, claude, cli, coding-agent, headless, json-rpc, ptah

## 简介

Headless agent-to-agent (A2A) CLI bridge for the Ptah coding orchestra. Drives the same DI graph as the Ptah VS Code extension and Electron app over JSON-RPC 2.0 stdio.
