# @jindin/mapbox-gl-custom-layer

> 标签: mapbox-gl, mapbox-gl-amap-layer, mapbox-gl-baidu-layer, mapbox-gl-custom-layer

## 简介

基于mapboxgl的自定义图层插件，实现对互联网地图栅格瓦片进行纠偏。实现了mapboxgl api加载 百度地图（栅格）、高德地图等栅格地图纠偏到3857、4490、4326坐标系的功能
