# @qinmoon/create-vue-vite-app

> 标签: cli, eslint, generator, git-hooks, pinia, scaffold, typescript, unocss, vite, vue, vue-router

## 简介

A CLI tool to quickly scaffold new Vue 3 projects with Vite, offering options for TypeScript, Vue Router, Pinia, ESLint, UnoCSS, and Git commit hooks.
