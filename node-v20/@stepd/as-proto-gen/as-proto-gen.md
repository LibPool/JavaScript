# @stepd/as-proto-gen

> 标签: JavaScript

## 简介

* Encodes and decodes protobuf messages * Generates AssemblyScript files using `protoc` plugin * Produces relatively small `.wasm` files * Relatively fast, especially for messages that contains only primitive types
