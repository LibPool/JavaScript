# @motion-script/canvaskit

> 标签: canvaskit

## 简介

Custom CanvasKit WASM build for Motion Script with variable font support and WebCodecs-based image I/O.

- 官网：https://motionscript.dev/
- 源码仓库：git+https://github.com/motion-script/motion-script.git
