# @gramkick/langkick

> 标签: dictionary, i18n, language-switcher, nextjs, react, react-native, translation

## 简介

Universal language switcher + static dictionary translator for React, Next.js and React Native. AI is used once at build time; at runtime translation is a plain lookup.
