# @alydev/datepicker

> 标签: accessible, calendar, calix, date-picker, datepicker, gregorian, headless, jalali, persian, react, react-date-picker, rtl, typescript

## 简介

Accessible, headless React date picker with Gregorian and Jalali calendars, RTL, time, ranges, and TypeScript.
