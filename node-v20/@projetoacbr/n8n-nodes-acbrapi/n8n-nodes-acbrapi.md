# @projetoacbr/n8n-nodes-acbrapi

> 标签: acbr, acbr-api, brasil, fiscal, n8n, n8n-community-node-package, nfse, nota-fiscal, nota-fiscal-de-servico

## 简介

Official n8n node for the ACBr API, maintained by the ACBr team: Brazilian electronic fiscal documents and business data lookups. Service invoices (NFS-e), CNPJ and postal code in this version, more document types to follow.
