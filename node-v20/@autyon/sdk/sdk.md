# @autyon/sdk

> 标签: agentchain, ai-agent, autyon, blockchain, cli, credit-network, evm, sdk

## 简介

TypeScript/JavaScript SDK and CLI for Autyon AgentChain — on-chain identity, wallet, payments, reputation, staking, profiles, and escrowed agent-to-agent hiring.
