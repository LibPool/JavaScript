# @stagewright-ai/playwright

> 标签: playwright, playwright-test, reporter, stagewright, video, walkthrough

## 简介

Stagewright for Playwright Test: a walkthrough fixture that records narrated-walkthrough artifacts from existing tests, and a reporter that uploads them as local runs.
