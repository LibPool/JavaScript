# @~lyre/dashboard

> 标签: admin, cms, crud, dashboard, drizzle, lyre, shadcn-svelte, svelte5, sveltekit

## 简介

Schema-introspection-driven CRUD admin dashboard for SvelteKit + Drizzle. Pass your Drizzle schema, get table grids, edit forms, charts, and a sidebar — with pluggable hooks for domain invariants. Host app must ship shadcn-svelte + Tiptap.
