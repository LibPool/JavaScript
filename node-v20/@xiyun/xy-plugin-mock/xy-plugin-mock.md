# @xiyun/xy-plugin-mock

> 标签: JavaScript

## 简介

## 简介 mock 插件是为项目提供 mock 数据的工具，支持 [Mock.js](https://github.com/nuysoft/Mock/wiki) 语法。此插件可选，未集成到 Cli 中。
