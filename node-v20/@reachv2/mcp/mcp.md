# @reachv2/mcp

> 标签: ai-agent, claude-desktop, cursor, mcp, model-context-protocol, reach

## 简介

Reach MCP stdio bridge — 让只支持 stdio 的本地 MCP 客户端（Claude Desktop / Cursor / Cline / Cherry Studio 等）通过 API Key 或 OAuth 接入 https://reach.codes/mcp，并可按岗位预设/前缀裁剪工具面
