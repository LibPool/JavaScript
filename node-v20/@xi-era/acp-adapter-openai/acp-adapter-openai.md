# @xi-era/acp-adapter-openai

> 标签: acp, adapter, agent, openai, tool-call

## 简介

ACP (Agent-Component-Protocol) to OpenAI Tool-Call adapter — convert ACP component descriptors to OpenAI function tools and execute tool calls against ACP servers.
