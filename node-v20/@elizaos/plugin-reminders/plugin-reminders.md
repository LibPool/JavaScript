# @elizaos/plugin-reminders

> 标签: JavaScript

## 简介

Reminder delivery + escalation data layer for elizaOS agents: owns the app_reminders schema (reminder plans, per-channel delivery attempts, escalation states) carved out of @elizaos/plugin-personal-assistant, with a non-destructive migration from app_life
