# @elizaos/plugin-waifu-swap-app

> 标签: JavaScript

## 简介

Native **token-swap AppView** for waifu agents. Renders inside an agent's ElizaOS web UI canvas (the apps overlay / desktop tab) and drives the **PancakeSwap v3** swap capability on the waifu.fun API.
