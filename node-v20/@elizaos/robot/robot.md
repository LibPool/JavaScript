# @elizaos/robot

> 标签: ainex, brax, elizaos, hiwonder, mujoco, rl, robotics

## 简介

Python robotics stack (MuJoCo sim, Alberta continual-RL training, Brax/MJX baselines, websocket bridge, perception, trajectory DB) with a thin TS surface for re-exports and shared schemas. Drives simulated and real robots via profile-driven configuration;
