# @elizaos/capacitor-websiteblocker

> 标签: dns, focus, vpn, website-blocker

## 简介

Blocks websites through the Eliza runtime on desktop/web, uses native Android VPN DNS enforcement, and manages a native Safari content blocker on iPhone and iPad.
