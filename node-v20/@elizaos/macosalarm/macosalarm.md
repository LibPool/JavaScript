# @elizaos/macosalarm

> 标签: alarm, elizaos, macos, notifications, swift

## 简介

macOS native alarm helper plugin. Schedules UNUserNotificationCenter calendar-trigger alarms via a self-contained Swift CLI invoked from the Eliza runtime.
