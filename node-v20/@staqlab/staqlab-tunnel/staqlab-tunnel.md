# @staqlab/staqlab-tunnel

> 标签: localhost, localtunnel alternative, nexmo, ngrok alternative, serveo alternative, shopify, ssh, ssh tunnel, tunnel, twilio, webhook

## 简介

connect your localhost to the public internet through ssh tunnel and create public link which you can share anywhere to test webhooks such as shopify hooks, nexmo hooks, facebooks hooks etc
