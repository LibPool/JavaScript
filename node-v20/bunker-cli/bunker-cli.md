# bunker-cli

> 标签: ai-agent, bunker, cli, hermes, hermes-agent, installer

## 简介

Instalador do Bunker (`npx bunker-cli init`) — configura o perfil base do Agente 0/VP no Hermes (LLM/modelo, SOUL.md, persona) como primeiro passo da instalação do Bunker.
