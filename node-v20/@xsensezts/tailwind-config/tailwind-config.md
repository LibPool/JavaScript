# @xsensezts/tailwind-config

> 标签: JavaScript

## 简介

This package provides the Tailwind CSS configuration used by XSENSEZTS projects. It includes a set of default styles, themes, and utility classes to ensure consistent design and styling across all XSENSEZTS codebases.
