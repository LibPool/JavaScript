# @astralchemist/matchstick

> 标签: astro, backlinks, indexnow, lastmod, mentions, nextjs, seo, sitemap, static-site

## 简介

Sitemap lastmod that only changes when a page's content really changes, plus the list of changed URLs for IndexNow.
