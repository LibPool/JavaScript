# node-red-contrib-easye4-mqtt

> 标签: easy, easye4, eaton, mqtt, node-red, plc, sps, steuerung

## 简介

Node-RED nodes for the Eaton easyE4 via its MQTT interface: read/write operands, RUN/STOP, function blocks, program and firmware updates (English/Deutsch)
