# airdrop-llm

> 标签: apple-silicon, cuda, distributed, edge-computing, gpu, inference, llm, metal, offline, p2p, pipeline-parallel, rust

## 简介

Zero-dependency, offline, multi-node pipeline-parallel LLM inference broker. Pool heterogeneous consumer hardware over local networks for distributed model execution.
