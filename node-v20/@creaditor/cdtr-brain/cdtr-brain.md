# @creaditor/cdtr-brain

> 标签: brain, creaditor, drop-in, embed, web-components

## 简介

Embeddable <cdtr-brain> web component. Owns the cdtr-studio API surface and routes drop-in requests through <cdtr-auth> via the @cdtr/signal bus. Drop-ins call ops by name; the brain holds the paths.
