# @creaditor/cdtr-course-builder

> 标签: course, course-builder, creaditor, drop-in, hebrew, lms, rtl, web-components

## 简介

Embeddable <cdtr-course-builder> web component. Wraps CourseCore + CourseBuilder + <course-sidebar> + <lesson-settings> behind a host-owned-data event contract. No networking: the host answers reads and persists writes.
