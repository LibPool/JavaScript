# @danielfransix/ui-explorer

> 标签: component-gallery, crawler, design, playwright, screens, screenshots, storybook-alternative, ui, vite, vite-plugin

## 简介

Explore every screen and state of a front-end app: an automatic crawler, a source-driven explorer, a flow canvas and thumbnails. Development tool; a read-only snapshot can optionally be shipped with a build.
