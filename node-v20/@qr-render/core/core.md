# @qr-render/core

> 标签: core, engine, matrix, qrcode, reed-solomon, tree-shaking, typescript, zero-dependency

## 简介

The modern, zero-dependency successor to qrcodejs. Platform-agnostic QR code generation engine (matrix, masking and Reed-Solomon error correction) for @qr-render/web and @qr-render/cli
