# @tsogtoodev/babi-toast

> 标签: gooey, morph, notification, promote, sonner, toast, vue, vue3

## 简介

An opinionated, morphing gooey toast notification library for Vue — a Sonner-style replacement with FLIP morphs, streaming, and promote-to-widget.
