# @skfoldr/mcp

> 标签: JavaScript

## 简介

This MCP (Model Context Protocol) server provides tools to interact with the Skfoldr GraphQL API for managing code snippets. The server enables IDEs and LLMs to retrieve company snippets and their content for use in development workflows.
