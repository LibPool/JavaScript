# @decent-render/runner-core

> 标签: decent-render, remotion, render-farm, render-payload, runner

## 简介

Render-payload core for the Decent render network — the runner main loop and render job (bundle sha256 verify, Remotion render, presigned upload, workdir purge). The renderer is injected, so no Remotion version is pinned here.
