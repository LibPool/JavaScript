# @fyio/buildfyio

> 标签: buildfyio, deploy, docker, local, paas, self-hosted

## 简介

npx buildfyio — one command from nothing to a running dashboard. Starts Buildfyio Local (Docker-only, self-hosted) and opens the browser.
