# @lynnlo/obsidian-desmos-quartz

> 标签: desmos, graph, obsidian, quartz, quartz-plugin, transformer

## 简介

Desmos graph transformer plugin for Quartz v5. Renders Obsidian's `desmos-graph` code blocks as interactive graphs via the Desmos Graphing API.
