# @rashidrazak/opencode-status-line

> 标签: opencode, opencode-plugin, status-line, statusline, tui

## 简介

A live status line for OpenCode v2's terminal UI — context window, cache, streaming speed, cost, elapsed time and uncommitted changes in one configurable row.
