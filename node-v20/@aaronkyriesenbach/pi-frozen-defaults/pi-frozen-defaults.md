# @aaronkyriesenbach/pi-frozen-defaults

> 标签: pi-extension, pi-package

## 简介

Pi extension that freezes defaultModel/defaultProvider/defaultThinkingLevel so they only change via a manual settings.json edit, never as a side effect of using pi.
