# @devcycle/vercel-edge-config

> 标签: JavaScript

## 简介

This library provides an adapter for DevCycle Node.js and Next.js SDKs to retrieve configuration data from Vercel Global Config (formerly Edge Config). To use this adapter, you must have the Vercel integration set up.
