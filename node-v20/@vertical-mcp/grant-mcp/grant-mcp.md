# @vertical-mcp/grant-mcp

> 标签: erc, grants, krf, mcp, model-context-protocol, nrf, nsf, research

## 简介

MCP server for global research grant databases (NSF, ERC, KRF). Runs locally via stdio or hosted on Smithery via StreamableHTTP.
