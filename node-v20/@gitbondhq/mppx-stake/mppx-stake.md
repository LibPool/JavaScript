# @gitbondhq/mppx-stake

> 标签: JavaScript

## 简介

An [`mppx`](https://github.com/wevm/mppx) stake method that proves an [MPPEscrow](https://github.com/gitbondhq/mpp-stake-demo) is **already active** for a given scope and beneficiary.
