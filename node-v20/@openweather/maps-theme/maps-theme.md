# @openweather/maps-theme

> 标签: css, maps, openweather, theme, weather

## 简介

OpenWeather's designed look for the Maps SDK's designed UI kit (createWeatherMapUI / <WeatherMapUI>) — CSS built on @openweather/maps-ui-core's shared tokens, plus an optional OpenWeather logo mark
