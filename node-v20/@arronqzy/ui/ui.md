# @arronqzy/ui

> 标签: JavaScript

## 简介

React 编辑器和蓝图用的组件：Button、Dialog、Menu、Toast、可调面板等。基于 Radix 和 Tailwind，视觉和 `@arronqzy/tailwind` 的令牌一致。
