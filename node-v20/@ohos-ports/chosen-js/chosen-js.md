# @ohos-ports/chosen-js

> 标签: dropdown, form, input, multiselect, select, ui

## 简介

[ohos-ports] Chosen is a JavaScript plugin that makes select boxes user-friendly. It is currently available in both jQuery and Prototype flavors.
