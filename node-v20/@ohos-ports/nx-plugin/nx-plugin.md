# @ohos-ports/nx-plugin

> 标签: CLI, Monorepo, Nx

## 简介

This plugin is used to create Nx plugins! It contains generators for generating common plugin features like generators, executors, migrations and more. (HarmonyOS openharmony/arm64 port of @nx/plugin@19.8.4; re-export structure unchanged)
