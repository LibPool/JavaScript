# @ohos-ports/node-unix-socket-linux-x64-gnu

> 标签: JavaScript

## 简介

node-unix-socket allows you to use SO_REUSEPORT, SOCK_SEQPACKET, SOCK_DGRAM in Node.js. (OpenHarmony arm64 native binding)
