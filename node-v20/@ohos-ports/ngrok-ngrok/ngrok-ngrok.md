# @ohos-ports/ngrok-ngrok

> 标签: harmonyos, ingress, networking, ngrok, nodejs, openharmony

## 简介

The ngrok agent in library form, suitable for integrating directly into your NodeJS application. (HarmonyOS port with prebuilt openharmony-arm64 binary)

## 官网

- 官网：https://ngrok.github.io/ngrok-javascript/
- 源码仓库：git+https://github.com/ngrok/ngrok-javascript.git
- npm 页面：https://www.npmjs.com/package/@ohos-ports/ngrok-ngrok
