# @ohos-ports/playwright-browser-chromium

> 标签: JavaScript

## 简介

Playwright package that automatically installs Chromium - OpenHarmony (OHOS) port with musl Chromium shim (sigsys_diag30.so) and playwright-core openharmony platform patch (postinstall mechanism)

- 官网：https://playwright.dev
- 源码仓库：git+https://github.com/ohos-ports/ohos-ports.git
