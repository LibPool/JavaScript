# @ohos-ports/deno-openharmony-arm64

> 标签: JavaScript

## 简介

OpenHarmony arm64 distribution of Deno. Deno 2.9.6 natively compiled from Rust source for aarch64-unknown-linux-ohos (musl).

## 官网

- 官网：https://deno.land
- 源码仓库：git+https://github.com/ohos-ports/ohos-ports.git
- npm 页面：https://www.npmjs.com/package/@ohos-ports/deno-openharmony-arm64
