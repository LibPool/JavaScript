# @ohos-ports/amoo-miki-compression-webpack-plugin

> 标签: webpack

## 简介

Prepare compressed versions of assets to serve them with Content-Encoding (OpenHarmony port, bundled openharmony-arm64 @node-rs/xxhash native binding)
