# @ohos-ports/sst-linux-x64

> 标签: JavaScript

## 简介

Platform-specific binary package for sst. Compiled from Go source for HarmonyOS arm64. Uses wrapper script to resolve pulumi dependency via SST_SKIP_DEPENDENCY_CHECK.
