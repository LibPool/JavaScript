# @ohos-ports/couchbase-couchbase-openharmony-x64-napi

> 标签: JavaScript

## 简介

Couchbase Node.js SDK platform specific binary for napi runtime on openharmony OS with arm64 architecture and boringssl (compiled from source for OHOS aarch64).

## 官网

- 官网：http://www.couchbase.com/communities/nodejs
- 源码仓库：git+https://github.com/ohos-ports/ohos-ports.git
- npm 页面：https://www.npmjs.com/package/@ohos-ports/couchbase-couchbase-openharmony-x64-napi
