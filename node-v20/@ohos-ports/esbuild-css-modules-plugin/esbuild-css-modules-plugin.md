# @ohos-ports/esbuild-css-modules-plugin

> 标签: css modules, cssmodules, esbuild, esbuild plugin, esbuildplugin, fast, lightningcss, plugin

## 简介

A esbuild plugin to bundle css modules into js(x)/ts(x), based on extremely fast [Lightning CSS](https://lightningcss.dev/)
