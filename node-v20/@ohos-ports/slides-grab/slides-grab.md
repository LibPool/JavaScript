# @ohos-ports/slides-grab

> 标签: ai-agent, cdp-bridge, claude, codex, harmonyos, html-slides, ohos, openharmony, ppt, pptx, presentation, slide-editor, slides

## 简介

Agent-first presentation framework — plan, design, and visually edit HTML slides with Claude Code or Codex, then export to PDF or experimental/unstable PPTX/Figma formats. HarmonyOS adaptation: Playwright connects to system Haitai browser (Chromium M132)
