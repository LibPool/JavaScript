# @ctrlback/i18n-extract

> 标签: cli, esm, extract, gettext, i18n, internationalization, l10n, localization, oxc, typescript

## 简介

Extract translatable strings from TypeScript sources into @ctrlback/i18n catalogs, and sync/measure translations.
