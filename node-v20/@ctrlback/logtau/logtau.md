# @ctrlback/logtau

> 标签: esm, log, logger, logging, logtau, ndjson, redaction, structured-logging, typescript

## 简介

A fast, ESM-only structured logger for modern Node.js. NDJSON output, path-based redaction, zero production dependencies.
