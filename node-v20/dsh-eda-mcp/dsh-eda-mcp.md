# dsh-eda-mcp

> 标签: deepseek-harness, dsh, dsh-plugin, easyeda, eda, jlc, jlceda, mcp, plugin, schematic

## 简介

DeepSeek Harness (DSH) plugin — connects DSH to JLCEDA Pro (EasyEDA Pro) via a local MCP bridge and draws schematics through the JLCEDA extension API.
