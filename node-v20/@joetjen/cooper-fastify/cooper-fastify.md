# @joetjen/cooper-fastify

> 标签: casc, config, configuration, cooper, fastify, fastify-plugin

## 简介

Under heavy development: not for production use before 1.0.0. A Fastify plugin that loads an application's CASC configuration once, at startup, with cooper-config, and puts it on fastify.config -- the server's own options included.
