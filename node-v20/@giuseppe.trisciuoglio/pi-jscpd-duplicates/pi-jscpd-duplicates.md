# @giuseppe.trisciuoglio/pi-jscpd-duplicates

> 标签: ai-agent, code-quality, copy-paste-detector, duplicate-code, jscpd, pi, pi-extension, pi-package, refactor

## 简介

pi extension that keeps AI-generated code free of duplicates: an asynchronous jscpd scan runs after every file write, and the agent is asked to refactor when freshly written code duplicates existing code.
