# @simple-office-previewer/core

> 标签: docx, office, pptx, preview, wasm, webassembly, xlsx

## 简介

Framework-agnostic WASM/worker engine that renders .docx/.xlsx/.pptx to HTML in the browser. Shared by @simple-office-previewer/angular and (future) @simple-office-previewer/react — most consumers want one of those, not this package directly.
