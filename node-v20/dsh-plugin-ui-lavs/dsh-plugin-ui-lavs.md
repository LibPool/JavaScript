# dsh-plugin-ui-lavs

> 标签: JavaScript

## 简介

LAVS Views tab for DeepSeek Harness: a native right-Sidebar tab type whose body mounts LAVS view bundles in iframes, bridged to the lavs-host adapter over the Connection RPC
