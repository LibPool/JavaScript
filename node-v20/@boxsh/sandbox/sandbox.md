# @boxsh/sandbox

> 标签: agents, bash, browser, coreutils, sandbox, shell, virtual-filesystem, wasm, webassembly

## 简介

Run shell commands against an isolated virtual filesystem, in the browser or Node. 70+ coreutils compiled to WebAssembly; no host shell, no host filesystem.
