# @aerys/ui

> 标签: aerys, aerysx, components, jsx-free, react, ui, view

## 简介

Native Aerys UI — write React components in pure Aerys with no JSX. Provides h(), view(), and lowercase HTML-tag wrappers (button, div, h1, …).
