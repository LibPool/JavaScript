# @circuit-llm/models

> 标签: JavaScript

## 简介

Circuit SDK models — client for the circuitllm.xyz/models gateway: buy prepaid credits in USDC/SOL/CIRC, mint a Circuit API key, and call the metered OpenAI-compatible chat API.
