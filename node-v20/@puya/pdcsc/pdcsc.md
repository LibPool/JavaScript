# @puya/pdcsc

> 标签: azuredevops, cicd, devops, git, gitlab, sql server

## 简介

pdcsc is a cli tool for managing .sql database repositories. It creates/updates changesets based on changes detected in feature branches, can be integrated in cicd pipelines and is able to apply changeset(s) on custom databases in cicd pipelines or even m
