# @chantezy/cocos-bridge

> 标签: bridge, cocos-creator, game-design, mcp, model-context-protocol

## 简介

Cocos Bridge MCP — bridges game design documents to Cocos Creator 3.8 engine implementation. 17 intent-level tools + 1 fallback, dual-channel (stdio + HTTP).
