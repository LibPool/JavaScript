# @codedia/parser

> 标签: ast, aui, compiler, design-system, dsl, llm, prompt-engineering, react, token-efficiency, ui

## 简介

An LLM-first, validated UI language with a deterministic compiler: express screens in .aui, get validated canonical IR and readable React/TSX. Small grammar, host-owned registry, measured token savings.
