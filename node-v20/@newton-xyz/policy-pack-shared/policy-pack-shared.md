# @newton-xyz/policy-pack-shared

> 标签: curator, newton, newton-protocol, policy-pack, shield, vault

## 简介

Shared TypeScript contract for Newton policy packs. Defines the PolicyPack<Params, WasmArgs, Secrets> interface that @newton-xyz/newton-shield-sdk consumes.
