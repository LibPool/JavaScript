# opencode-ecosystem-manager

> 标签: dashboard, ecosystem, opencode, opencode-plugin, plugin-manager, plugins, updates

## 简介

Browse and toggle official and awesome-opencode community plugins from one tool, slash command, or local dashboard, with guarded install/uninstall and update checks that include the manager itself.
