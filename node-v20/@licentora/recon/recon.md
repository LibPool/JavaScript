# @licentora/recon

> 标签: control, release, release-control

## 简介

Automated release management CLI for Node.js packages. Parses Conventional Commits to determine semantic versioning, generates changelogs, manages Git workflows, and publishes to GitHub Releases and npm with built-in dry-run mode and interactive configura
