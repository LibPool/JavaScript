# @meshconnect/uwc-tron-connector

> 标签: JavaScript

## 简介

Mesh-owned Tron wallet connector for Universal Wallet Connector — zero third-party Tron runtime deps; signs via the wallet's injected tronWeb, builds/broadcasts via the Tron full-node HTTP API
