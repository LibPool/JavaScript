# @kyusu0918/ofc-datetime

> 标签: date, datetime, intl, lightweight, ofc, typescript, utc, utility, zero-dependency

## 简介

Lightweight, zero-dependency Date/Time utility library for fixed format (yyyy/MM/dd hh:mm:ss) with UTC and Intl support for TypeScript. Part of the ofc utility series by Kei Yusu.
