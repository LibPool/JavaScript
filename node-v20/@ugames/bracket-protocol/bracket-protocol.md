# @ugames/bracket-protocol

> 标签: bracket, lsp, lukso, protocol, tournament, ugames

## 简介

Bracket Protocol — TypeScript contract for UGames tournament bundles. CC0-licensed; implement against this to publish brackets that any LUKSO-aware host can render.
