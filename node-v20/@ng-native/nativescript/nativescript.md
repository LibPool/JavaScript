# @ng-native/nativescript

> 标签: android, angular, angular-native, ios, jsi, nativescript, react-native

## 简介

NativeScript's iOS and Android APIs in Angular Native: provideNativeScript, a NativeScript service and a <native-view> for a UIView built in TypeScript.
