# @biashara/beem-client

> 标签: JavaScript

## 简介

Unofficial NodeJS Beem.Africa client for interfacing with the [Beem.Africa](https://beem.africa/beem-api) APIs. This is created to serve the needs of [Biashara-as-a-Service](biashara.tz)
