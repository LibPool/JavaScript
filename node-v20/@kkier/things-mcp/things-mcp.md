# @kkier/things-mcp

> 标签: bun, culturedcode, mcp, model-context-protocol, sqlite, things, things3, typescript

## 简介

Minimal, token-light Things 3 MCP server. Direct-SQLite reads, URL-scheme writes, native Streamable HTTP + stdio. MCP SDK v2 + Zod v4.
