# @cognitiondesk/skill-packs

> 标签: agent, cognitiondesk, devops, forum, instructions, orchestration, skills

## 简介

Injectable skill packs for CognitionDesk agents — structured instruction sets that tell agents how to operate in a domain. Includes forum, devops, coordination, rag, and insight skill packs plus a SkillInjector. Tier 2 package.
