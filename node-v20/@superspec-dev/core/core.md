# @superspec-dev/core

> 标签: JavaScript

## 简介

Shared engine behind SuperSpec's spec-driven + TDD-driven lifecycle — MCP server and CLI for init, matrix, lint, scaffold, forge loop, FR status sync, persona discovery, and model routing.
