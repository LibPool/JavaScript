# @abloh/measure

> 标签: JavaScript

## 简介

Runs a repository's own test suite and reads what came back: the baseline and its flakiness protocol, diff-coverage acquisition and the coverage adapters, the runner report dialects, the test catalog, and the exec boundary every one of them spawns through
