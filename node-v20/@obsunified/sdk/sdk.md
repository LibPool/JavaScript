# @obsunified/sdk

> 标签: llm, obs-unified, observability, openinference, opentelemetry, otel, tracing

## 简介

Thin OpenTelemetry SDK wrapper for obs-unified — adds OpenInference LLM/tool helpers, project propagation, and one-line OTLP setup.
