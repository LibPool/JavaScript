# @mnemix-ai/livekit-kit

> 标签: caller-id, enrichment, livekit, livekit-agents, memory, mnemix, sip, voice-agent

## 简介

Mnemix integration kit for LiveKit Agents — direction-safe SIP caller-identity resolution, Northsun context fetch for voice.Agent({ instructions }), and session-end memory write-back via ctx.addShutdownCallback().
