# @arsw/kiln

> 标签: JavaScript

## 简介

An API framework on Hono for Cloudflare Workers: routes that declare only their own responses, and Kiln the ones it causes, so the OpenAPI document is the contract. Under /model, Drizzle tables on D1 and Zod schemas from one model
