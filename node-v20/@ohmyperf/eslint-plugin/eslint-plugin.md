# @ohmyperf/eslint-plugin

> 标签: cls, core-web-vitals, eslint, eslint-plugin, eslintplugin, inp, lcp, ohmyperf, performance, tbt

## 简介

ESLint rules that flag client-side performance anti-patterns linked to Core Web Vitals (LCP, INP, CLS, TBT). Shift-left companion to @ohmyperf/cli.
