# @salahfarzin/datetimepicker

> 标签: calendar, datepicker, jalali, kurdish, persian, react, shamsi, timepicker

## 简介

React date and time picker for the Gregorian, Jalali (Solar Hijri) and Kurdish calendars, with ISO or calendar-string values.
