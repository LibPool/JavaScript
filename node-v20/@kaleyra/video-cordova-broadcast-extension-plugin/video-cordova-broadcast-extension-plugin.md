# @kaleyra/video-cordova-broadcast-extension-plugin

> 标签: cordova-ios, ecosystem:cordova

## 简介

A Cordova plugin that adds a Broadcast Upload App Extension to your Cordova app using the native Kaleyra Video iOS SDK
