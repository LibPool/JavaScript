# dsh-opencli

> 标签: agent-tools, browser-automation, cdp, cordis, cordis-plugin, deepseek-harness, dsh, opencli

## 简介

Low-latency OpenCLI browser tools for DSH: drives the local OpenCLI daemon directly instead of paying a CLI cold start on every command.
