# @rendkit/core

> 标签: agentic, ai, component-catalog, copilotkit, generative-ui, react, rendkit

## 简介

Runtime-agnostic core for the Rendkit agentic component catalog — defineComponent, the component registry, and the RndEvent envelope. No framework runtime dependencies.
