# @citisen/litearea

> 标签: autocomplete, code-editor, diagnostics, dsl, editor, hover, intellisense, lightweight, react, redo, semantic-highlighting, syntax-highlighting, textarea, tooltip, undo, zero-dependency

## 简介

A lightweight textarea-based code editor: native undo/redo, fully custom syntax highlighting, VSCode-style completion, diagnostics, and hover tooltips. No CodeMirror, no Monaco.
