# launch-video-skills

> 标签: agent-skills, claude-code, codex, ffmpeg, launch-video, motion-graphics, playwright

## 简介

Agent skill + renderer for SaaS launch videos: HTML/CSS scenes -> MP4 via Playwright + ffmpeg, local TTS. Works with Claude Code, Codex, Cursor, Gemini CLI, OpenCode.
