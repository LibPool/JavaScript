# @gistui/vanilla

> 标签: dom, generative-ui, gistui, renderer, streaming, vanilla

## 简介

GistUI for vanilla JavaScript: mount a streamed GistUI program into any element, with the default components as plain DOM and no framework. The base for @gistui/vue, @gistui/svelte and @gistui/solid.
