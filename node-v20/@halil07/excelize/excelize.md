# @halil07/excelize

> 标签: excel, excelize, spreadsheet, wasm, webassembly, workbook, xlsx

## 简介

Read & write Microsoft Excel (XLSX/XLSM/XLTM/XLTX) files in the browser and Node.js via WebAssembly, powered by the Go excelize library.
