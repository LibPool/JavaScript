# @autolabz/service-auth-middleware

> 标签: JavaScript

## 简介

可复用的服务端鉴权中间件集合，支持 SIMPLE（本地 JWT 验签）与 OAuth（不透明 Token，经可配置的 userinfo 接口回落校验，默认路径为 `/oauth/userinfo`）。
