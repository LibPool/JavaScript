# @nodeops-createos/sandbox

> 标签: agent, agents, ai, ai-agents, code-execution, compute, createos, createos-sandbox, e2b-alternative, egress, isolated-sandbox, isolation, runtime, sandbox, sdk, untrusted-code

## 简介

Isolated sandboxes for AI agents and untrusted code: create, run commands, egress allowlist, pause/resume/fork, destroy. TypeScript SDK for CreateOS Sandbox.
