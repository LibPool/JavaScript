# dsh-open-dream-rsi

> 标签: agent, deepseek-harness, dsh-plugin, mcp, mcp-server, open-dream-rsi, self-improvement

## 简介

Let your coding agent dream: strategies must survive counterfactual replay before they earn trust. An offline self-improvement loop over an evolving world model — no fine-tuning, the LLM stays frozen. Speaks MCP. Ships its Python server inside the package
