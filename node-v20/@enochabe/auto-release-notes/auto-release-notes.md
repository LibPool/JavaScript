# @enochabe/auto-release-notes

> 标签: ai, anthropic, changelog, cli, conventional-commits, git, groq, llm, notifications, ollama, openai, openrouter, slack

## 简介

AI-powered release notes generator — summarizes git diffs via LLMs (OpenAI, Anthropic, Groq, OpenRouter, Ollama) or conventional commits, and sends notifications via email or Slack
