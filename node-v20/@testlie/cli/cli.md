# @testlie/cli

> 标签: ci, cli, disposable-inbox, e2e, email-testing, magic-link, otp, testlie

## 简介

Testlie command-line tool: create disposable email inboxes, wait for an email and print its one-time code or magic link, from any shell or CI job
