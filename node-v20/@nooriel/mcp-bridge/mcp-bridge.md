# @nooriel/mcp-bridge

> 标签: build-instructions, claude-code, codex, coding-agent, cursor, kiro, mcp, nooriel, prototype, windsurf

## 简介

MCP bridge for Nooriel — connects coding agents (Codex, Claude Code, Cursor, Windsurf, Kiro) to Nooriel's Build Instruction Pack. v1.1 adds auto-refresh notifications when the founder updates project knowledge.
