# @adobe/aio-cli-plugin-ffcpe

> 标签: oclif-plugin

## 简介

Adobe I/O CLI plugin for **FFCPE** (**Firefly Creative Production for Enterprise**) — manage custom catalog entries against the run-workflow Catalog API (`aio ffcpe catalog` commands).
