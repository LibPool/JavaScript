# @mandk/i18n-help

> 标签: i18n, i18nTT, javascript, js, node

## 简介

这是一个小工具且不完善，减轻手动修改的工作量。 用命令行将文件中的中文转换为$t('中文')的vue-i18n写法，并生输出被转换词的json到终端。
