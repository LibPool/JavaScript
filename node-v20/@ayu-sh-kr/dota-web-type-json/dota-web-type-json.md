# @ayu-sh-kr/dota-web-type-json

> 标签: Custom Elements Manifest, Dota Core Plugins, IDE Support, Web Components, Web Types

## 简介

Vite plugin that scans Dota Web Components once and generates JetBrains Web Types with optional Custom Elements Manifest 2.1 metadata.
