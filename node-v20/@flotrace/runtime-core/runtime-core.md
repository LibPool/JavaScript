# @flotrace/runtime-core

> 标签: devtools, fiber, flotrace, profiler, react

## 简介

Platform-agnostic core for FloTrace runtime — fiber walker, analyzers, trackers. Shared by @flotrace/runtime (web) and @flotrace/runtime-native (React Native).
