# obix-compiler-script-setup

> 标签: compiler, obix, script-setup, vue

## 简介

The <script setup> frontend of the .obix compiler: compiles the <script setup> (with any normal <script> it is merged with) of a canonical SFC with the OFFICIAL Vue script compiler — defineProps, defineEmits, withDefaults, defineExpose, defineOptions, def
