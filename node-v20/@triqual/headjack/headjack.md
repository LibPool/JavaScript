# @triqual/headjack

> 标签: JavaScript

## 简介

A personal vault for agent skills: import the skills you already have, then search and install them only when a task needs them, with optional skill suggestions on each prompt (off by default). Runs locally on SQLite by default; hosted mode is optional.
