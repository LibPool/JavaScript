# @managic/mcp

> 标签: ai-agent, claude, managic, mcp, model-context-protocol

## 简介

MCP server for Managic — gives an AI agent (Claude Code, Claude Desktop, or any MCP client) tools to create, list, and update Managic tickets and tasks.
