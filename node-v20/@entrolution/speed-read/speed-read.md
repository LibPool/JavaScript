# @entrolution/speed-read

> 标签: cbz, comic-reader, ebook, epub, lightweight, pdf, react, reader, typescript, web-component

## 简介

Lightweight, embeddable document reader for EPUB, PDF, and CBZ. Add a reader to any webpage in one line of code.
