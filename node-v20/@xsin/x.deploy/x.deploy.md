# @xsin/x.deploy

> 标签: ci-cd, deploy, docker, github-actions, nginx

## 简介

基于 Shell 脚本和 CI/CD 工作流的自动化部署解决方案，支持应用部署至阿里云多台主机、 Certbot 证书生成和自动续期、Nginx 配置、Docker 容器管理等。
