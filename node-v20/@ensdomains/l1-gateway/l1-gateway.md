# @ensdomains/l1-gateway

> 标签: JavaScript

## 简介

An instantiation of [evm-gateway](https://github.com/ensdomains/evmgateway/tree/main/evm-gateway) that targets Ethereum L1 - that is, it implements a CCIP-Read gateway that generates proofs of contract state on L1.
