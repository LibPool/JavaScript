# @keboola/tailwind-config

> 标签: config, design-tokens, keboola, tailwind, tailwindcss

## 简介

Shared Tailwind CSS v4 design tokens for the Keboola UI platform — semantic color palette, type scale, radii and shadows as a `theme` object.
