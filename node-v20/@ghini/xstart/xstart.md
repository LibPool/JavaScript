# @ghini/xstart

> 标签: JavaScript

## 简介

基于 Node 24 原生 ESM，利用"源码直连"实现免 build 实时调试；通过 esbuild 抹除后缀并配合 publishConfig，兼顾开发爽感与发布标准。
