# @acurast/vps

> 标签: acurast, sdk, tunnel, vps

## 简介

VPS deployment helpers for Acurast — SSH-tunnel keypair generation, subdomain precomputation, and a pinned tunnel bundle that serves shell + optional HTTP on the same Let's Encrypt subdomain.
