# @ferrarirosso/mcp-browser-client

> 标签: agent-365, browser, json-rpc, mcp, microsoft-365, model-context-protocol, work-iq

## 简介

Browser-compatible Model Context Protocol (MCP) client. JSON-RPC 2.0 over HTTP with session management and SSE response handling. Zero dependencies.
