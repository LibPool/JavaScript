# @axone-network/quill-illustration

> 标签: JavaScript

## 简介

This module is a modification of the quill-comment module described as "Comment plugin for Quill Editor. This plug-in is used to mark which part of a document is commented by who at what time in quill delta. It is made UX-independant by exposing callbacks
