# @liusihustore/insert-word-image

> 标签: batch, com, docx, image, insert, office, windows, word

## 简介

批量向 Word 文档指定页面范围内插入图片的命令行工具，基于 Word COM 自动化实现。

## 官网

- npm 页面：https://www.npmjs.com/package/@liusihustore/insert-word-image

- npm registry：https://registry.npmjs.org/@liusihustore/insert-word-image
- Node 要求：>=12
