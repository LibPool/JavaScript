# @beyondandsharp/dsh-plugin-notoken

> 标签: JavaScript

## 简介

DSH host plugin: one stable login entry that exchanges the process launch token for the browser-session cookie, so a first visit needs no ?token=... in the URL. WARNING: this removes the authentication step.
