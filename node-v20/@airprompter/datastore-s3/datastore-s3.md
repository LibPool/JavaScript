# @airprompter/datastore-s3

> 标签: agent, airprompter, aws, datastore, llm, prompts, s3

## 简介

The AirPrompter release datastore over an S3 bucket: a KvStore with S3's own conditional writes (If-None-Match, If-Match), for kvReleaseDatastore — the puller writes sealed releases, every runtime hydrates from them.
