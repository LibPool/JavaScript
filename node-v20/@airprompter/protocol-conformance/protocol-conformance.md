# @airprompter/protocol-conformance

> 标签: JavaScript

## 简介

The AirPrompter agent protocol's conformance harness: every vector in protocol/vectors, run against any SDK through a JSON adapter (an ES module, or any process speaking JSON lines). The reference implementations and the schema/example runner ride along.
