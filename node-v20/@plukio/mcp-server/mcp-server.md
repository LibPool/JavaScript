# @plukio/mcp-server

> 标签: JavaScript

## 简介

MCP (Model Context Protocol) server that gives AI coding agents access to Pluk tasks. Pull tasks, update status, leave notes for reviewers — all from within Claude Code, Cursor, or any MCP-compatible client.
