# @ashishkaloge/code-review-council

> 标签: ai-code-review, claude-code, code-review, codex, coding-agents, llm-council, sarif

## 简介

Cross-check code reviews with Claude Code and Codex using existing CLI logins. Deterministic diff anchoring and anonymous votes, with Markdown, JSON and SARIF reports.
