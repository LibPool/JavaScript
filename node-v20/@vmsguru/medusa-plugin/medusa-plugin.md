# @vmsguru/medusa-plugin

> 标签: medusa-plugin, medusa-plugin-integration, medusa-v2, packing-video, vmsguru

## 简介

VMS Guru connector for Medusa v2 — syncs orders, products and shipment tracking so packing videos link back to the right order.
