# @dylanlindgren/next-ui-storybook-vite

> 标签: next-experience, servicenow, vite, vite-plugin, web-components

## 简介

Vite plugins that compile ServiceNow Next Experience UI Framework components: snabbdom JSX transform, SCSS-as-string, and instance-module externals. Shared by the dev (Storybook) and build pipelines.
