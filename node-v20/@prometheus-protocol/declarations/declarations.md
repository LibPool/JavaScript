# @prometheus-protocol/declarations

> 标签: JavaScript

## 简介

Auto-generated Candid interface declarations (TypeScript bindings + IDL factories) for every Prometheus Protocol canister. These are the IDL bindings that `@prometheus-protocol/ic-js`, the App Store CLI, and the web frontends use to talk to mainnet and lo
