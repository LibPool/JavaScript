# @cp949/bb-check

> 标签: JavaScript

## 简介

라이브러리의 배포 JavaScript를 `package.json#browserslist` 기준선과 대조하는 정적 검사 CLI다. `package.json#exports`가 가리키는 빌드 산출물에서 문법, 런타임 API, 외부 의존성 문제를 찾는다.
