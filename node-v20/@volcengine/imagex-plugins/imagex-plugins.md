# @volcengine/imagex-plugins

> 标签: Volcano Engine, plugin, veImageX

## 简介

基于火山引擎 [veImageX 图片服务](https://www.volcengine.com/products/imagex) 的图片加载组件的相关插件，提供组件核心能力以外的附加能力，如加密图加载等。

## 官网

- npm 页面：https://www.npmjs.com/package/@volcengine/imagex-plugins

- 2.1.1

- npm registry：https://registry.npmjs.org/@volcengine/imagex-plugins
