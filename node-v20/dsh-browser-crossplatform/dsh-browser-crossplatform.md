# dsh-browser-crossplatform

> 标签: ai-agent, browser-automation, browser-extension, cross-platform, deepseek, deepseek-harness, dsh, dsh-market, dsh-plugin, linux, macos, marketplace, multiplatform, plugin-manager, side-panel, websocket, windows

## 简介

dsh 浏览器扩展（全平台）的桌面端一半：把浏览器扩展连到 dsh，提供 browser_* 工具，并在需要时替你识别页面上的图片。这是它的全部配置项。
