# @harness-nexus/mcp-runtime

> 标签: JavaScript

## 简介

Transport-facing MCP upstream pool — dial upstreams (SSE / Streamable HTTP / stdio), aggregate namespaced tools, route calls. Shared by the server's McpRegistry and the `hnx mcp serve` stdio shim (Phase 8 C2).
