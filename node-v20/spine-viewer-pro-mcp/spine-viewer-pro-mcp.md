# spine-viewer-pro-mcp

> 标签: ai-agent, claude, keyframe, mcp, model-context-protocol, pixi, skeletal-animation, spine, spine-viewer

## 简介

MCP server for Spine Viewer Pro: drive the viewer's window.svp API in a dedicated Chrome, load and export Spine skeletons from disk, and round-trip them through keyframe.it.
