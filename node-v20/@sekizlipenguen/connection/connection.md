> 标签: XMLHttpRequest, ajax, api client, axios alternative, connection library, fetch, http client, http requests, lightweight http client, network requests, promise-based HTTP client, react, react native http, react-native, web, xhr

## 简介

A lightweight and promise-based HTTP client for React Native, React, and Web applications. Supports fetch and XMLHttpRequest with advanced configuration options.
