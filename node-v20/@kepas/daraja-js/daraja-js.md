# @kepas/daraja-js

> 标签: b2c, c2b, daraja, kenya, m-pesa, mpesa, payments, safaricom, stk-push

## 简介

Type-safe Node.js/TypeScript SDK for Safaricom Daraja (M-Pesa). Encodes the production gotchas that silently break real PayBills. By KEPAS Technologies (kepas.co.ke).
