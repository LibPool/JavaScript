# dsh-theme-stardew-fullskin

> 标签: deepseek-harness, dsh-plugin, pixel-art, stardew-valley, theme, web-ui

## 简介

Stardew Valley theme for the DeepSeek Harness Web UI: a self-contained frontend that replaces the served dist, with the Junimo NPC dialog, farm-select mode picker, quest journal HUD, valley calendar with seasons and weather, 8-bit sound feedback, and wall
