# @kaos-intelligence/epub-forge

> 标签: accessibility, ebook, epub, epub3, epubcheck, fixed-layout, idml, indesign, mdx, media-overlays, pdf

## 简介

EPUB 3.3 production harness — extract MDX/PDF/IDML/INDD manuscripts, assemble conformance-grade EPUBs (reflowable + fixed-layout), self-heal via a reviewer loop, and validate with EPUBCheck. One pipeline. Any source. Beautiful output.
