# @zyfgood/dsh-feishu-bot

> 标签: bot, cordis, deepseek-harness, dsh, feishu, lark, plugin

## 简介

DeepSeek Harness 插件：绑定飞书（Feishu/Lark）机器人并互动 — WebSocket 长连接接收消息、LLM/Agent 自动回复、模型可调用 feishu_* 工具
