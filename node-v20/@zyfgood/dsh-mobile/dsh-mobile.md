# @zyfgood/dsh-mobile

> 标签: cordis, deepseek, deepseek-harness, dsh, dsh-plugin, lan, mobile, mobile-web, pwa, remote, session, web-ui

## 简介

DSH 插件：手机端 Web UI。同一局域网内用手机浏览全部 DSH 会话、实时查看回复并继续对话；桌面端提供二维码与访问链接。Mobile session client for DeepSeek Harness.
