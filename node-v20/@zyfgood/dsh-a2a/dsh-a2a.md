# @zyfgood/dsh-a2a

> 标签: a2a, agent-card, agent2agent, cordis, deepseek-harness, dsh, interop, json-rpc, plugin

## 简介

DeepSeek Harness 插件：A2A（Agent2Agent）协议双向支持 — 把 DSH agent 暴露为标准 A2A 服务器（Agent Card + JSON-RPC message/send、message/stream SSE、tasks/get、tasks/cancel），并提供 a2a_* 工具让 agent 调用远端 A2A agent
