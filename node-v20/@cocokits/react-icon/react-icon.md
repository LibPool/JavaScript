# @cocokits/react-icon

> 标签: JavaScript

## 简介

The `@cocokits/react-icon` package provides a powerful and flexible way to integrate SVG icons within your React applications. The core element in this package, SvgIcon, allows for dynamic SVG embedding, making it versatile for a wide range of design need
