# @arkn/react-map-chart-lite

> 标签: chart, component, country-map, custom-map, dashboard, data-visualization, frontend, geography, interactive-map, lightweight-map, map, maps, react, react-component, svg-map, vector-map, world-map

## 简介

React component for rendering interactive SVG maps of the world, continents, and countries with dynamic data. Loads built-in maps dynamically from a CDN at runtime.
