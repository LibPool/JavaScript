# @rafads/plugin-mcp

> 标签: JavaScript

## 简介

Register [Model Context Protocol](https://modelcontextprotocol.io) servers as tool integrations for an executor. Supports both stdio-launched servers and remote (HTTP) servers, with optional OAuth.
