# @yanglaofish/dsh-proxy-pro

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, network, proxy, undici

## 简介

DSH proxy manager: route model requests, web fetches and spawned tools through the Windows system proxy or a custom address; per-URL route diagnosis, one-click toggle from the conversation header, a dedicated Settings page, and keepalive-aware 407 hints.
