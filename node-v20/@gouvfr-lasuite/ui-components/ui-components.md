# @gouvfr-lasuite/ui-components

> 标签: JavaScript

## 简介

The unified React component library for La Suite numérique. It contains all components previously published by UI Kit and Cunningham, with a single enhanced `CunninghamProvider` that includes the UI Kit locales.
