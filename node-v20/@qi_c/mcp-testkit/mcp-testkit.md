# @qi_c/mcp-testkit

> 标签: ai, llm, mcp, mcp-client, mcp-server, model-context-protocol, test, testing, testkit, tools

## 简介

Type-safe, in-process testing toolkit for Model Context Protocol (MCP) servers. Test tools, resources, and prompts without subprocesses, with framework-agnostic assertions and a contract CLI.
