# @predictefy/sdk

> 标签: JavaScript

## 简介

Official TypeScript client for the Predictefy unified prediction-market API. Thin and global-fetch based, with ethers for client-side signing.

## 官网

- 官网：https://predictefy.com
- 源码仓库：git+https://github.com/Predictefy/predictefy-core.git
- npm 页面：https://www.npmjs.com/package/@predictefy/sdk
