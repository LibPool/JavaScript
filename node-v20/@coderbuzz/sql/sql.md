# @coderbuzz/sql

> 标签: ansi, bun, clickhouse, database, deno, node, query-builder, sql, sqlite, type-safe, typescript

## 简介

Runtime-agnostic TypeScript SQL toolkit for Bun, Node.js, and Deno with typed schemas, dialect-aware builders, engine adapters, migrations, and batch inserts.
