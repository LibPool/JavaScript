# rose-window-maker

> 标签: compass-and-straightedge, esoterica, foils, generator, gothic-architecture, gothic-tracery, javascript, pwa, quatrefoil, rose-window, sacred-geometry, stained-glass, svg, tracery, trefoil

## 简介

Rose Window Maker: build a Gothic rose window step by step with compass and straightedge, like a medieval mason: divide the circle, raise equilateral arches, set oculi and foils, then download it as SVG or PNG.
