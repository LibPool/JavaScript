# @prisma-next/upgrade-skill

> 标签: JavaScript

## 简介

Agent skill that upgrades a Prisma Next user app from one minor version to the next. Carries the bump-install-instructions-validate-commit flow plus the cumulative set of per-transition upgrade instructions.
