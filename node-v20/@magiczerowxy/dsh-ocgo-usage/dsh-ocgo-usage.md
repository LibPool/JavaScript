# @magiczerowxy/dsh-ocgo-usage

> 标签: JavaScript

## 简介

OpenCode Go subscription quota widget for the dsh web GUI: a floating window showing rolling/weekly/monthly usage with progress bars, refreshed every 5 minutes.
