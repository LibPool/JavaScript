# @nalyk/gsccli

> 标签: cli, google-search-console, gsc, indexing-api, mcp, model-context-protocol, search-analytics, search-console, seo, sitemaps, url-inspection

## 简介

Full-featured Google Search Console + Indexing API CLI — auto-paginated Search Analytics, period comparison, batch URL inspection, client-side sort, query cache, OAuth/SA auth, MCP server.
