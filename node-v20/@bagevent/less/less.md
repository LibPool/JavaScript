# @bagevent/less

> 标签: JavaScript

## 简介

```shell # 确保安装了Node # 安装 Yarn (有的话跳过) npm install -g yarn # 安装 less yarn global add less # 安装 clean-css Plugin yarn global add less-plugin-clean-css # 项目初始化 yarn install ```
