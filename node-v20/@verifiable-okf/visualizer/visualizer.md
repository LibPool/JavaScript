# @verifiable-okf/visualizer

> 标签: JavaScript

## 简介

Verifiable OKF proof-status visualizer: a bundle → a single self-contained, offline HTML report with per-concept verified/unverified/failed badges. No backend, no CDN, no data leaves the page.
