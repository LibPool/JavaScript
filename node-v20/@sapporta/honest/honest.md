# @sapporta/honest

> 标签: api, contract, hono, openapi, rest, sapporta, ts-rest, typescript, zod

## 简介

Honest — the Hono + ts-rest adapter. Mount ts-rest contracts on Hono with one-schema-two-uses request parsing and OpenAPI 3.1 emission. Adds dispatch families for runtime-resolved routes.
