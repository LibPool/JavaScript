# @theokit/acp

> 标签: JavaScript

## 简介

Agent Client Protocol (ACP) server adapter for @theokit/sdk. Exposes an SDKAgent over stdio JSON-RPC so any ACP-compatible host can drive it. ADRs D349-D360.
