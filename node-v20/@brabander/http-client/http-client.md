# @brabander/http-client

> 标签: JavaScript

## 简介

`@brabander/http-client` is het contract (`type:port`) voor HTTP-client-implementaties: request/response-types, error-normalisatie en een generieke retry-policy. Bevat zelf geen concrete implementatie — zie `@brabander/http-client-axios` voor de axios-ada
