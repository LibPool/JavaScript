# @angular-dnd/core

> 标签: JavaScript

## 简介

The **`@angular-dnd/core`** is a fork of [`@angular-skyhook/core`](https://github.com/cormacrelf/angular-skyhook) and is a toolkit for building complex drag and drop interfaces in Angular.
