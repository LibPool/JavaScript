# @multiviewer/led-panel-driver

> 标签: JavaScript

## 简介

TypeScript driver for BLE RGB LED matrix panels (LED_BLE_*, 32x32 and 64x16). Works in Node, Electron main and renderer (Web Bluetooth).

## 官网

- npm 页面：https://www.npmjs.com/package/@multiviewer/led-panel-driver
