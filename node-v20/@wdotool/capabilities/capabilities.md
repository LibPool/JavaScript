# @wdotool/capabilities

> 标签: capabilities, json-schema, types, wayland, wdotool

## 简介

TypeScript types and JSON Schema for wdotool's `wdotool capabilities` output. Lets JS/TS consumers (wflows.com, dashboards, etc.) parse a capabilities report with full type safety.
