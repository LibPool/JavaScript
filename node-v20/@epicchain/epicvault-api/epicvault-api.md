# @epicchain/epicvault-api

> 标签: epicchain, javascript, libraries, xmoohad

## 简介

The EpicVault-API Module is an advanced API layer built on top of the EpicVault-JS Core, providing an enhanced interface for seamless interaction with the EpicVault platform.
