# @capyup/pi-exa

> 标签: exa, pi, pi-extension, pi-package, pi-skill, research, web-search

## 简介

Exa web research for pi via five first-class tools + skill + local CLI. Uses the official exa-js SDK directly — no MCP server, no adapter. Tools: exa_search, exa_similar, exa_fetch, exa_answer, exa_research. Supports real-time livecrawl, subpage extractio
