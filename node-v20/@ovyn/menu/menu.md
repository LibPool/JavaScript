# @ovyn/menu

> 标签: angular, menu, ng, primeng

## 简介

`@ovyn/menu` is a modern, responsive navigation menu component library for Angular applications built with Angular Signals, PrimeNG, and Tailwind CSS. It supports horizontal top navigation, vertical left sidebar rails, responsive mobile drawers, role-base
