# @githumbi/grabby

> 标签: ai, angular, annotation, claude, coding-agent, developer-tools, esbuild, feedback, grabby, react, svelte, ui-feedback, vite, vue, webpack

## 简介

Point at any UI element, leave a comment, and hand the feedback to an AI coding agent. Works with React, Angular, Vue, Svelte and plain HTML.
