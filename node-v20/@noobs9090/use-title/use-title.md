# @noobs9090/use-title

> 标签: hooks, react, title

## 简介

useTitle 훅은 React 애플리케이션에서 웹 페이지의 타이틀을 동적으로 업데이트하는 데 사용됩니다. 이 훅을 사용하여 문서의 <title> 태그를 효율적으로 관리할 수 있습니다.
