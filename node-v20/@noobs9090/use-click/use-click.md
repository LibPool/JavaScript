# @noobs9090/use-click

> 标签: click, hooks, react

## 简介

useClick 훅은 React 애플리케이션에서 클릭 이벤트 리스너를 쉽게 관리할 수 있게 해주는 훅입니다. 이 훅을 사용하여 특정 DOM 요소에 클릭 이벤트 핸들러를 추가하고 제거할 수 있습니다.
