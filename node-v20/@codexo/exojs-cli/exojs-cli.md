# @codexo/exojs-cli

> 标签: asset-pipeline, cli, cross-origin-isolation, exojs, scaffold, static-server

## 简介

Command line tools for ExoJS projects: a cross-origin-isolated static server, the app scaffolder, an environment check, and the .exoa asset container packer.
