# @aditkuma/ngx-bulk-upload

> 标签: angular, bulk-upload, csv, excel, import, laravel, queue, upload

## 简介

Angular component for uploading huge CSV/Excel files to a Laravel queue-backed backend, with a live processed/failed/in-progress/remaining dashboard (WebSocket + polling fallback).
