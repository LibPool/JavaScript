# @kybernesis/artifacts

> 标签: agent, artifacts, eve, kybernesis

## 简介

Artifacts for eve agents: pages an agent makes for a person (reports, dashboards, trackers) that KYBER Studio and the phone draw inline, stored on the agent's own machine.
