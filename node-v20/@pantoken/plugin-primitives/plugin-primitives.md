# @pantoken/plugin-primitives

> 标签: JavaScript

## 简介

Opt-in utility classes for the raw pantoken primitive palette (--instui-primitive-*): background/text/border colors plus font-family and font-weight. Kept out of the semantic utilities so overrides there stay semantic-only.
