# @moksa/plugin-ecpay

> 标签: JavaScript

## 简介

綠界：信用卡、ATM、超商代碼與條碼付款及退款，超商取貨與宅配，以及 B2C 電子發票，需搭配 @moksa/emdash-shop 網站整合套件。
