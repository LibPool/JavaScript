# @chickencuber/cocl

> 标签: JavaScript

## 简介

COCL is a shell like config language similar to bash but doesn't run commands or have any fancy control flow   it is designed to be lightweight though this implementation is not lightweight due to using an entire bash parser(because I'm lazy)
