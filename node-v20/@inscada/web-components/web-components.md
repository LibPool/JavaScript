# @inscada/web-components

> 标签: faceplate, industrial, inscada, live-value, scada, web-components

## 简介

inSCADA Web Components (JDK21) — live values, faceplates, REST fetch. <ins-faceplate> v3 uses the domain FaceplateApi (getFaceplateByName/Svg/Elements/Placeholders) — requires backend build ≥ 20260706-8.
