# @tsip/computed-flow

> 标签: async, computed, data-flow, dependency-tracking, flow, memoization, observable, reactive, reactive-programming, signals, state-management, streams, tsip, typescript

## 简介

Computed reactive data flows with automatic dependency tracking, async support, and parameterized computations. Built on TypeScript Interface Proposals (TSIP) for seamless compatibility.
