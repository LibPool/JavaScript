# @danielgap/pi-claude-usage

> 标签: claude, claude-code, pi, pi-claude-bridge, pi-coding-agent, pi-package, quota, usage

## 简介

Claude subscription usage meter for pi-claude-bridge: registers the claude-bridge provider as a Gentle Shell usage source so the native usage bar and /gentle:usage panel show the 5-hour and weekly Claude windows.
