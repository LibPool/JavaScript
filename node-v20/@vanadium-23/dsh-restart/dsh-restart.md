# @vanadium-23/dsh-restart

> 标签: cordis, deepseek-harness, dsh, restart, rollback, supervisor

## 简介

Out-of-process restart supervisor for DeepSeek Harness: a small control agent on its own port restarts dsh, rolls the profile configuration back to the last known-good snapshot when the new boot fails, and hands the failure report to the restarted harness
