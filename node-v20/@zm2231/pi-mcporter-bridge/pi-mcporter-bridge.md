# @zm2231/pi-mcporter-bridge

> 标签: mcp, mcporter, model-context-protocol, pi-extension, pi-package

## 简介

pi extension that registers each mcporter-managed MCP server's tools natively into pi by attaching to a running `mcporter serve` over Streamable HTTP. Per-server allowlist; tools surface to the agent as first-class pi tools.
