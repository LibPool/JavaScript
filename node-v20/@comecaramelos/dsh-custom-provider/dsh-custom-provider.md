# @comecaramelos/dsh-custom-provider

> 标签: dsh, dsh-plugin, llm, pi-ai, providers

## 简介

DSH plugin: a "No API key required" toggle on saved hand-declared provider cards that writes Authorization: Bearer none so keyless local/self-hosted endpoints stop aborting with "No API key for provider"
