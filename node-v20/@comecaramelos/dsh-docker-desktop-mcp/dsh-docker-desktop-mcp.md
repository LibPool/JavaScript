# @comecaramelos/dsh-docker-desktop-mcp

> 标签: JavaScript

## 简介

Independent DSH plugin connecting DeepSeek Harness to the MCP Toolkit in Docker Desktop, with a UI profile picker. Not affiliated with, endorsed by, or sponsored by Docker, Inc.
