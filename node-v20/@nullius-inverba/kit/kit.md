# @nullius-inverba/kit

> 标签: agents, audit, claude-code, hooks, journal, llm, provenance, retro, subagents

## 简介

Witness recording for agent runs — harness hooks emit a journal the agent cannot decline to write, and `nullius witness validate` judges it.
