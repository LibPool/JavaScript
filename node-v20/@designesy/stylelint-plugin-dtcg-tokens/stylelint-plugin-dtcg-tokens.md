> 标签: css, design-system, design-tokens, design-tokens-community-group, designesy, dtcg, lint, postcss, postcss-plugin, stylelint, stylelint-plugin, token-validation, w3c

## 简介

stylelint + PostCSS plugin that enforces DTCG 2025.10 design token usage in CSS — no bare hex, no magic numbers, no undeclared var() references.
