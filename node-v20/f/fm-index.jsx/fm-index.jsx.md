# fm-index.jsx

> 标签: altjs, amd, browser, commonjs, js, jsx, lib, nlp, nodejs, search

## 简介

FM-index is the fastest full text search algorithm using a compressed index file. This is FM-index for JSX/JS/AMD/Common.js.
