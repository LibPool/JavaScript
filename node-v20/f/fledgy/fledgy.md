# fledgy

> 标签: agent-skills, ai-agents, claude-code, claude-code-plugin, claude-code-skills, codebase-atlas, codebase-map, documentation, knowledge-base, living-documentation, manual-qa, pragmatic-programmer, vibe-coding

## 简介

Understand the app your agent built, without reading its code. Fledgy keeps a plain-words map of every user flow, the parts of the system each step runs through, and a manual QA script for each path, checked against the code after every change.
