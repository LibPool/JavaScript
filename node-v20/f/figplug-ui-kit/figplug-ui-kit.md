# figplug-ui-kit

> 标签: JavaScript

## 简介

Figplug - a ready-to-use Figma plugin starter with theme-aware UI, resizable window, and TypeScript tooling. Use it as a template to jumpstart new plugins or to learn modern Figma plugin patterns.
