# fish-npm

> 标签: JavaScript

## 简介

相关的字段 - name： 必填，表明我们的包名。需要在npmjs上唯一，记得提前到npm官网上搜索一下 - version： 必要，每次上传这个值只能增加，不能不变或者减少。 - homepage: 尽量填写，一般就是github地址，这样如果别人对我们的项目有兴趣，就可以找到地方。

## 官网

- 官网：https://github.com/fish-nodejs/npm
- npm 页面：https://www.npmjs.com/package/fish-npm
