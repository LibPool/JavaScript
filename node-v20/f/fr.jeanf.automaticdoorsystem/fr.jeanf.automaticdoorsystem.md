# fr.jeanf.automaticdoorsystem

> 标签: automatic, doors, doorsystem, ecs, entities, jeanf, pooling

## 简介

A high-performance automatic door system using Unity ECS (Entities) with pooled audio and colliders.
Supports rotating and sliding doors, single and double configurations.
Features   distance-based culling, object pooling for AudioSources and BoxColliders
