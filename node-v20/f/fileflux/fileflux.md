# fileflux

> 标签: express, fastify, file, fileflux, hono, mern-packages, merndev, multer, multipart, next, nextjs, nodejs, npm-pm, observability, r2, s3, typescript, upload

## 简介

File upload handler with resumable multipart uploads, signed URLs, virus scanning hooks, and pluggable storage adapters for S3, GCS, and local disk.
