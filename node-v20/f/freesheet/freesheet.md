# freesheet

> 标签: data-grid, datagrid, datatable, editable-table, excel, fastapi, formulas, grid, handsontable, handsontable-alternative, no-dependencies, pandas, spreadsheet, table, vanilla-js

## 简介

Free, MIT-licensed, zero-dependency Excel-like data grid (Handsontable-style API): virtual scrolling, editing, formulas, sorting, filter row, quick filter, copy/paste with Excel, fill handle, undo/redo, merge cells, comments, frozen panes, dark mode, CSV/
