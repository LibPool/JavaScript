# fault-mcp

> 标签: agents, chaos-engineering, fault-injection, llm, mcp, model-context-protocol, reliability, testing

## 简介

An MCP server that injects tool faults on purpose, so you can test how your agent copes when a tool errors, stalls, truncates, or quietly returns the wrong answer.
