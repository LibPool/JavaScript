# fractalia-faro

> 标签: JavaScript

## 简介

Wizard FARO: CREA o ADOPTA un repo de trabajo (clasificación por dominio) desde el template oficial, con nombre natural, topics de clasificación, ramas main+develop, metadato que el harness lee y clon local listo.
