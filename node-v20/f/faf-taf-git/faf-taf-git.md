# faf-taf-git

> 标签: bitbucket-pipelines, ci-cd, faf, git, github-actions, gitlab-ci, jest, platform-agnostic, taf, test-automation, testing

## 简介

A Test Receipt Printer for git. Every CI run prints a receipt to .taf — append-only, timestamped, cannot be gamed. Proof over time.
