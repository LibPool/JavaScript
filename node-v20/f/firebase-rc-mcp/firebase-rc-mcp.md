# firebase-rc-mcp

> 标签: claude, claude-code, firebase, mcp, model-context-protocol, remote-config

## 简介

MCP server for managing Firebase Remote Config from Claude Code. Chat-driven CRUD with diff-gated publishes, including parameters nested inside parameter groups. Sign in with Google once; no service-account JSON, no GCP console setup.
