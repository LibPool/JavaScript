> 标签: attributes,access,rights,permissions,symbolic,numeric,owner,group,fs,stat,mode,string,rwx,read,write,execute,directory,ls,file system,chmod, file,directory

## 简介

Create a Unix-like permissions string from an fs.stat file or directory mode, eg `0777` to `-rwxrwxrwx`
