# fixed-in-screen

> 标签: JavaScript

## 简介

在页面上下滚动的时候，可以指定将某一dom固定到屏幕上。 比如页面滚动时，表头滚动到顶部时被固定；底部操作按钮滚到底部时被固定。 省去用css布局。
