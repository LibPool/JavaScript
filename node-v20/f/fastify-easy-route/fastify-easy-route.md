# fastify-easy-route

> 标签: auto, automatic, easy, fastify, multiple, route, router, routing

## 简介

Данный пакет предназначен для автоматической регистрации контроллеров api с использованием fastify. Больше не нужно прописывать каждый GET, POST и тд. запросы для создания api. Установи этот пакет и наслаждайся! =)
