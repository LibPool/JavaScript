# fast-jev-opencode

> 标签: compaction, context, jev, opencode, opencode-plugin, typesafe

## 简介

Verbatim context pruning for OpenCode v1 and v2: prune stale tool calls and truncate bulky tool results from the outgoing model request using TypeSafe Jev decisions, instead of summarizing context.
