# flusterduck-vite-plugin

> 标签: auto-inject, build-plugin, bundler-plugin, click-tracking, dead-click, flusterduck, friction, rage-click, react-vite, svelte-vite, ux-analytics, vite, vite-plugin, vitejs, vue-vite

## 简介

Vite plugin for rage click detection and UX friction tracking. Auto-injects Flusterduck SDK. Works with React, Vue, Svelte, Solid.
