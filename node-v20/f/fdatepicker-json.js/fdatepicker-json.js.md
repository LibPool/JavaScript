# fdatepicker-json.js

> 标签: calendar, date, datepicker, frend

## 简介

支持后台渲染后台数据的移动端满屏日历插件，支持单个月份切换和多个月份平铺展示两种方式。使用多月份平铺展示时，支持初始化加载个数、分页加载。
