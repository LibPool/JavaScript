# foodscore-mcp

> 标签: ai-tools, claude, food-database, foodscore, mcp, model-context-protocol, nutrition, usda

## 简介

MCP server for foodscore.us — query 19 414 US foods scored 0–100 from USDA data, compare any two foods, search by name/brand. Use with Claude Code, Cursor, or any MCP-compatible client.
