## what? 什么是cli工具？ > 什么是命令行工具？ CLI全称是（Cmmand Line Interface），翻译过来是命令行界面，我理解在命令行界面使用的工具，便是命令行工具，通常也就把cli认为是命令行工具。我们常用的 git 、npm、vim 等都是命令行工具，比如我们可以通过 git clone 等命令简单把远程代码复制到本地。那对应的还有图形用户界面（GUI）使用的工具。那就提出下面的问题了
