# form-states-storage-plugin

> 标签: form, localStorage, plugin, storage

## 简介

一个轻量级的表单数据存储插件，支持将表单数据持久化到 `localStorage` 中，方便在页面刷新或关闭后恢复表单数据。支持多标签页间的数据同步。
