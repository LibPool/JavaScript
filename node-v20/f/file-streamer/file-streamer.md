# file-streamer

> 标签: base64, buffer, csv, data-export, data-streaming, download, excel, file-download, file-generation, file-streaming, file-system, http-response, json, mime-types, path-streaming, response-streaming, spreadsheet, static-files, streaming, typescript, xlsx

## 简介

A TypeScript package for streaming data as files (Excel, CSV, JSON, Base64) and streaming files from file system through HTTP responses
