# figma-icons-tokens

> 标签: Design System, Design Tokens, Figma, Tokens Studio Figma, cli, design, tokens

## 简介

Figma-icons-tokens aims to import figma icons given a design tokens configuration file exposed by Tokens Studio Figma.
