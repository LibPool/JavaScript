# flashbase

> 标签: auth, baas, backend, better-auth, cloudflare, durable-objects, edge, electric-sql, framework, postgres, postgrest, r2, realtime, supabase, workers

## 简介

Cloudflare-native backend framework with Supabase-compatible ergonomics. REST API, auth, realtime sync, storage and edge functions on Workers + Containers + R2. Spins up in under 2 seconds locally with no Docker required.
