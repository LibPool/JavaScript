# flatbuffers-format

> 标签: antlr, antlr4, antlr4ng, cli, fbs, flatbuffers, formatter, pretty-printer, schema

## 简介

Opinionated FlatBuffers (.fbs) schema formatter, built on an ANTLR4 grammar. Pure TypeScript runtime (antlr4ng) — no JVM, no codegen at install time. Runs in Node and the browser, ships a CLI.
