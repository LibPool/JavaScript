# fortune-chinese-poetry

> 标签: chinese, cli, fortune, motto, poetry

## 简介

fortune-chinese-poetry linux cli tool to return a chinese poetry randomly, like the fortune cli. It would be great to use it like 'fortune-chinese-poetry | cowsay | lolcat' or 'fortune-chinese-poetry | cowthink | lolcat'. Use '--song' to return only from
