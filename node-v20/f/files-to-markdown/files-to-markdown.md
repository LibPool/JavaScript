# files-to-markdown

> 标签: csv, docx, llm, markdown, markitdown, ocr, pdf, tokens, xlsx

## 简介

Convert uploaded files (PDF, Word, Excel, HTML, CSV, images) to Markdown to cut LLM token usage. Node-native, no Python.
