# fluent-query-builder

> 标签: builder, database, database-agnostic, db-agnostic, ddd, domain-driven-design, fluent-api, hexagonal-architecture, linq, mongoose, orm, prisma, query, query-builder, query-interface, repository-pattern, type-safe, typeorm, typescript, typescript-library

## 简介

A type-safe, DB-agnostic query builder for TypeScript inspired by LINQ. Build database queries with a fluent API that works across Prisma, TypeORM, and more.
