# fireworks-drawio-graph

> 标签: ai, architecture, diagram, drawio, flowchart, hermes-skill, mcp, sequence, uml, visualization

## 简介

Generate production-quality draw.io (mxGraphModel XML) technical diagrams with 7 built-in styles. Architecture, flowchart, sequence, ER, class diagrams and more.
