# fakenet-signer

> 标签: bitcoin, bitcoin-core, blockchain, chain-signatures, cross-chain, ethereum, mempool, mpc, multi-chain, psbt, signature, solana, utxo, web3

## 简介

Multi-chain signature orchestrator for Solana - listens for signature requests, executes transactions on target chains (Ethereum, Bitcoin, etc.), and returns results. Includes Bitcoin adapters for mempool.space API and Bitcoin Core RPC.
