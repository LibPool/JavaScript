## 简介

Verify what an AI wrote against what is true. Blocks PR descriptions, READMEs, changelogs and reports that state a number, date, name or tool your diff, tests or facts contradict. Deterministic, zero dependencies, zero LLM calls. CLI, library, GitHub Acti
