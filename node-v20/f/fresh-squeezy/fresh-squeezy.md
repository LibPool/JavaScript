# fresh-squeezy

> 标签: billing, ci, cli, discounts, doctor, lemon-squeezy, lemonsqueezy, license-keys, nodejs, payments, saas, subscriptions, typescript, validator, webhooks

## 简介

Dual-mode Lemon Squeezy ops + doctor: validate billing setup, and run docs-backed API ops (webhooks, discounts, checkouts, subscriptions, refunds, …) from CLI or TypeScript.
