# finn-tannlege-mcp

> 标签: a2a, claude, dental, dentist, finn-tannlege, helfo, mcp, norway, norwegian-healthcare, tannlege

## 简介

MCP server for finn-tannlege.com — find Norwegian dental clinics from Claude Desktop, ChatGPT, and other AI assistants. ~6,900 clinics with Helfo-agreement, specialty, and emergency-duty data.
