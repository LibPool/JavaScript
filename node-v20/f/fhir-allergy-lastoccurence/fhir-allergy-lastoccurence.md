# fhir-allergy-lastoccurence

> 标签: JavaScript

## 简介

&lt;fhir-allergy-lastoccurance&gt; adds allergy last date to the page. Uses input tupe date in mm/dd/yyyy format  * In typical use, just use &lt;fhir-allergy-lastoccurance url=""/fhir-allergy-lastoccurance&gt;
