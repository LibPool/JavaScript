# find5

> 标签: JavaScript

## 简介

在搜索框中，模拟 Ctrl + F 的搜索功能，支持自选可搜索区域范围，且支持回车查看下一个，上下查看，自动滚动定位，帮助小白解决不会快捷键操作的搜索。
