# ffiko

> 标签: binding, c, calling-convention, dll, dlopen, dylib, ffi, ffmpeg, koffi, libffi, napi, native, so

## 简介

A fast, minimal Foreign Function Interface (FFI) library for Node.js, inspired by koffi. Load native libraries and call C functions directly from JavaScript.
