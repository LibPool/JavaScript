# ffmpeg-helper

> 标签: JavaScript

## 简介

A Node.js module that provides an interface for executing platform-dependent binaries on multiple architectures (x64 and arm64) across macOS, Linux, and Windows. The module determines the underlying OS and architecture and provides the appropriate binary
