# fscss-props

> 标签: browser, css, fscss, ratio-fit, runtime, shorthand, utility, xfscss

## 简介

Lightweight browser runtime for FSCSS property shorthands (size, mx/px, stack, ratio-fit, …). No @define or arrays — expand CSS and drive styles from JS.
