# forsap-s4hana-private-simulator

> 标签: business-partner, cap, odata, odata-v2, odata-v4, s4hana, s4hana-private-edition, sap, sap-cap, simulator

## 简介

Local simulator for SAP S/4HANA Private Edition APIs, supporting OData V2/V4, CRUD operations, queries, filters, metadata and in-memory SQLite using SAP CAP.
