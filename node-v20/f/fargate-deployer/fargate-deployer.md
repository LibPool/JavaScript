# fargate-deployer

> 标签: alb, aws, cdk, deploy, ecs, eventbridge, fargate, github-actions

## 简介

Deploy containers to AWS ECS Fargate from a declarative manifest — long-running services behind an ALB, or EventBridge-scheduled tasks.
