# foldkit-command-palette

> 标签: cmdk, combobox, command-palette, effect, elm-architecture, foldkit, search

## 简介

Command palette for Foldkit: a dialog with a query input and a sectioned listbox; ⌘K / Ctrl+K opens it, the host supplies the items.
