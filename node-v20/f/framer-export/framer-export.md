> 标签: bubble, carrd, cli, export, exporter, framer, ghost, gumroad, mirror, notion, scraper, shopify, site-downloader, site-export, squarespace, webflow, wix, wordpress

## 简介

Export public pages from 25 website platforms into local HTML, CSS and assets. Captures dynamic styles, responsive resources and reusable scripts, with diagnostics for incomplete exports.
