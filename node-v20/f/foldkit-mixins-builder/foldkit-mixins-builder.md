# foldkit-mixins-builder

> 标签: accessibility, foldkit, mixins, page-builder, typescript

## 简介

The page builder drawn as accessible HTML through foldkit-mixins slots: a palette, a keyboard-driven layers tree, an inspector, and the page in edit mode.
