# fractals-visualizer-react

> 标签: JavaScript

## 简介

A webapp built with React that draws fractals, which users can manipulate through various attributes. Programmed with Javascript, HTML Canvas, and React.js. Live site lives here: https://fractal-visualizer.vercel.app/
