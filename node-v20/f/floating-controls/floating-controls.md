# floating-controls

> 标签: card-controls, control-panel, custom-element, floating-panel, floating-ui, glassmorphism, hover-controls, interactive-panel, ui-component, web-component

## 简介

A beautiful, customizable floating control panel web component with glassmorphic design. Automatically adjusts to parent container size and slides up on hover.
