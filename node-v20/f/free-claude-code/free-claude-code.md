# free-claude-code

> 标签: claude-code, cli, proxy, tray

## 简介

Free Claude Code proxy as a background service + system tray icon, launched via `fcc start`. Thin launcher: downloads the prebuilt Windows app from this repo's GitHub Releases (see .github/workflows/build-windows.yml) and runs it detached, so it survives
