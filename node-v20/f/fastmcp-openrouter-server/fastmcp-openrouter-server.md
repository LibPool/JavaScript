# fastmcp-openrouter-server

> 标签: JavaScript

## 简介

OpenRouterのAPIと連携するModel Context Protocol (MCP) サーバーです。このプロジェクトは、AI アシスタントがOpenRouterAPIを使用してWeb検索を行うことができるインターフェースを提供します。
