# flip-expanding-grid-template-start

> 标签: arte, astro, cards, component, flip, gsap, translate

## 简介

An Astro component that generates an interactive flip-and-expand grid layout, perfect for displaying cards, portfolios, or galleries. Each grid item flips to reveal detailed content and expands smoothly
