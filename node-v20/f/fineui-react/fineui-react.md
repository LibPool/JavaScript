# fineui-react

> 标签: JavaScript

## 简介

因为配置文件用了 es6+ 语法所以要求 node 的版本大于 6.10，同时建议使用 [yarn](https://yarnpkg.com/zh-Hans) 来管理依赖包。fork 项目之后可以按如下命令操作。
