# fimaflow-studio-react

> 标签: fimaflow, low-code, no-code, react, studio

## 简介

Contrat entre un composant React et l'éditeur Fima Studio — defineProperties/defineData/defineEvents/defineSlots/defineActions, l'équivalent Fimaflow du figma:react de Figma. Source de vérité unique pour le hover TypeScript du Studio et, à terme, l'aperçu
