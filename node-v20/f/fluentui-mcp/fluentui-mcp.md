# fluentui-mcp

> 标签: ai-assistant, claude, cline, design-system, developer-tools, documentation, fluent-ui, fluentui, llm, mcp, microsoft, model-context-protocol, react, react-components, ui-components

## 简介

MCP (Model Context Protocol) server providing AI assistants with intelligent, context-efficient access to Microsoft FluentUI documentation. Supports multiple FluentUI versions (v8, v9, v10+) with in-memory indexing, smart search, and 12 specialized tools
