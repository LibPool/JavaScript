# f2c-cli

> 标签: ai, automation, claude, cli, code-generation, component, component-generator, css-modules, design-system, design-to-code, figma, figma-plugin, figma-to-code, figma-to-react, figma-to-vue, frontend, github, openai, react, tailwind, tailwindcss, typescript, vue, vue3

## 简介

CLI tool to convert Figma designs to React / Vue 3 components using AI. One command, zero boilerplate. Supports Tailwind, CSS Modules, TypeScript, GitHub PR auto-create.
