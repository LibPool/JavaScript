# fraight-bot-client

> 标签: JavaScript

## 简介

In order to get tests working on your computer, after running `npm install fraight-bot-client`, you will have to cd into the directory in `node_modules` and run `npm run symlink PATH` where PATH is the path from the symlink file to your fraight-js directo
