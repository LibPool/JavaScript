# fastly.js

> 标签: cache, cdn, edge, esi, fastly, proxy, varnish, vcl

## 简介

A reimplementation of the Fastly platform in TypeScript: parse and execute Fastly VCL locally, with the full request pipeline, caching, ESI, and the VCL standard library.
