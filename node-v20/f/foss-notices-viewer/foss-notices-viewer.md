# foss-notices-viewer

> 标签: black-duck, cli, cyclonedx, foss, license, notices, react, sbom, spdx, third-party-notices

## 简介

Parse SPDX, CycloneDX, generate-license-file, and Black Duck notices output into one normalized model, with React components to search, group, and diff third-party license disclosures.
