# fitllm

> 标签: amd, apple-silicon, gguf, kv-cache, llama-cpp, llm, memory-calculator, mla, mlx, moe, nvidia, ollama, quantization, vram, will-it-run

## 简介

Auditable local-LLM memory estimates for GPUs and Macs. Models sliding-window, hybrid/linear, MLA compressed-KV and MoE architectures. Zero deps, single file, conformance-vector tested.
