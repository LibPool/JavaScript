# fkbuilder

> 标签: animation, canvas, creatomate, editly, ffmpeg, paper.js, video, webgl

## 简介

基于 Node.js + Paper.js 的程序化视频生成库，支持多轨道多场景、丰富动画效果、转场特效和并行渲染
