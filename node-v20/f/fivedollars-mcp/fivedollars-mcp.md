# fivedollars-mcp

> 标签: api-client, claude, cursor, fivedollars, http, mcp, model-context-protocol, rest

## 简介

Model Context Protocol server for the FiveDollars API Client. Lets Claude/Cursor run saved requests, read collections, manage environments.
