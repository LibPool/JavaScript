# freeswitch-esl-node

> 标签: cti, esl, event-socket, freeswitch, freeswitch-esl, modesl, no-dependencies, pbx, sip, telephony, typescript, voip

## 简介

Dependency-free FreeSWITCH Event Socket (ESL) client for Node.js. TypeScript types, correct Content-Length framing, bgapi, events, auto-reconnect, ESM and CommonJS.
