# figma-rest-api

> 标签: color, design-tokens, figma, figma-api, oklch, rest-api

## 简介

Pull design data (colors, variable bindings) from Figma via the official REST API — no app patching, no MCP rate limits. Maps Figma colors to your design tokens.
