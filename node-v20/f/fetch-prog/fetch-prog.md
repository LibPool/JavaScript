# fetch-prog

> 标签: axios, download, fetch, lightweight, progress, stream, upload, zero-dependencies

## 简介

A lightweight axios-like fetch wrapper with built-in progress tracking for both uploads and downloads. Simple API, zero dependencies.(一个基于 fetch 的轻量 axios 风格请求库，支持上传和下载进度跟踪，简单 API，零依赖)
