# fly-rev

> 标签: asset, assets, cache, expire, fly, fly-plugin, hash, manifest, manifest.json, optimize, replace, rev, revision, revving, static, version, versioning

## 简介

Append a unique hash to filename. Optionally create a manifest mapping. Optionally rewrite references to updated filenames.
