# fracadot

> 标签: autorunner, cs, dotnet, run

## 简介

## Introduction This Node.js script automates the execution of C# projects. It allows for the creation of new C# console projects, automatically opens them in the default editor, and watches a directory for changes in any C# files to run them instantly.
