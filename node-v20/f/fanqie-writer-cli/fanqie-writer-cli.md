# fanqie-writer-cli

> 标签: cli, fanqie, novel, workbuddy, writer, 番茄小说

## 简介

番茄小说作家后台命令行工具：建书、分卷、章节存草稿与定时发布、短故事存草稿。输出 JSON，供 AI 助手调用。
