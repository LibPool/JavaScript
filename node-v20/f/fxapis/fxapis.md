# fxapis

> 标签: algorithmic-trading, copy-trading, forex, forex-api, metatrader, metatrader 5 api, metatrader-5, metatrader5, mt5, mt5-api, rest-api, sdk, trade-copier, trading-api, typescript

## 简介

MetaTrader 5 (MT5) REST API client for Node.js and TypeScript: trade MT5 accounts over HTTPS with no terminal, VPS or EA. Copy trading, click-to-trade, multi-account orders.
