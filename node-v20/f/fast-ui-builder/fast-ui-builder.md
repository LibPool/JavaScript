# fast-ui-builder

> 标签: JavaScript

## 简介

Fast UI Builder is a package for building UI components which can be used in React, Vue, and other frameworks. The tool is fully compatible with a FastAPI backend server powered by our package called Fast API Builder (https://pypi.org/project/fast-backend
