# flow-topology-vue3

> 标签: flow, sop, topology, typescript, vue, vue3

## 简介

flow-topology-vue3是一个用于创建流拓扑图的Vue 3组件库。它提供了一组可重用的组件和实用程序，以帮助您构建交互式的、具有视觉吸引力的流程图、流程图或表示数据流的任何其他类型的图
