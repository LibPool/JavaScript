# firecrawl-access

> 标签: cli, cloudflare, cloudflare-access, crawler, firecrawl, reverse-proxy, scraper, service-token

## 简介

Run the Firecrawl CLI against a Cloudflare Access protected origin from one command. Bundles a header-injecting shim + the Firecrawl CLI into a single self-contained binary.
