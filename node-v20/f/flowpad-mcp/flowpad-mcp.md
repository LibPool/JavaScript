# flowpad-mcp

> 标签: JavaScript

## 简介

Local validation helper for Flowpad's canvas engine — runs flowpad-core on your machine (validate_design, preview_layout, describe_engine) so an AI host can self-check a design before writing it through the Flowpad connector. Optional enhancer for the hos
