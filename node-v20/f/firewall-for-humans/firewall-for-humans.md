# firewall-for-humans

> 标签: cli, debian, devops, firewall, linux, network, security, ubuntu, ufw

## 简介

Intuitive CLI wrapper for UFW with human-readable commands, 100+ service presets, named IP groups, diagnostics, and tab completion.
