# feayicode

> 标签: agentic, ai, cli, coding-agent, deepseek, glm, llm, openai-compatible, qwen, terminal

## 简介

AI 编码助手 CLI：终端里的 agentic coding 助手。默认 DeepSeek，支持通义千问/GLM/豆包/Kimi 及任意 OpenAI 兼容网关（Token 工厂）。25+ 工具、子代理、权限档位、记忆、任务跟踪。
