# fhir-create-patient

> 标签: JavaScript

## 简介

&lt;fhir-create-patient&gt; creates a form/page to create a new patient with all reusable components like fhir-active-status,  * fhir-birth-date, fhir-decease-status, fhir-human-address, fhir-human-contact, human-gender, fhir-human-language, fhir-human-na
