# fcestimator

> 标签: cost-calculator, estimator, fcestimator, pricing, quote-calculator, react, widget

## 简介

FCEstimator — a scalable, customizable project cost estimator widget for React. Configure any set of services, fields, and pricing formulas (with variables, conditionals, and dependencies) and drop it into any site.
