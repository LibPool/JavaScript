# flashjdk

> 标签: cli, cross-platform, flashjdk, java, java-home, jdk, jdk-switch, jdk-version, linux, macos, windows

## 简介

flashJDK — 极速切换 JDK 版本，自动更新 PATH 和 JAVA_HOME，支持 Windows / macOS / Linux
