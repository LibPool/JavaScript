# fullsy

> 标签: agent, archive, capture, evidence, screenshot, sha256, verifiable, webpage

## 简介

Capture entire webpages as fingerprinted, verifiable records, filed into one downloadable zip that works offline. CLI for the Fullsy browser engine.

- 官网：https://getfullsy.com/agents
- npm 页面：https://www.npmjs.com/package/fullsy
