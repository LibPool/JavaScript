# factum-orm

> 标签: Cypher, ERD, LadybugDB, NORMA, ORM, Object-Role Modeling, SQL, conceptual schema, data modeling, fact-based modeling, property graph, verbalization

## 简介

Visual Object-Role Modeling (ORM 2) editor for VS Code: draw conceptual schemas, verbalize them in FORML, validate them, and map them to relational and property graph schemas. Imports NORMA .orm files.
