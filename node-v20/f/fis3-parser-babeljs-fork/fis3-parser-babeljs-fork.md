# fis3-parser-babeljs-fork

> 标签: babel, fis, parser

## 简介

a babel 6.x parser for fis,默认增加了对注解的解析,与原来的区别是去掉了babel_plugin_styled_components插件，此插件会严重影响编译性能

## 官网

- 官网：https://code.aliyun.com/senro/fis3-plugins
- npm 页面：https://www.npmjs.com/package/fis3-parser-babeljs-fork

- 1.0.0
