# frc-mcp

> 标签: ai-agents, fha, hmda, mcp, mcp-server, model-context-protocol, mortgage, mortgage-data, open-data

## 简介

MCP server for FinanceRateCalc — lender-level FHA denial statistics from the complete 2025 federal HMDA record. Historical observations, never individual predictions.
