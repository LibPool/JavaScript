# flowengine.cloud

> 标签: automation, claude, cli, deploy, flowengine, functions, mcp, mcp-app, model-context-protocol, n8n, serverless

## 简介

FlowEngine CLI + MCP server. `fe` deploys folders to FlowEngine Functions (serverless containers on GCP). `flowengine-mcp` runs the Model Context Protocol server so Claude can manage your account.
