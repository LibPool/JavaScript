# fhir-person-identifier

> 标签: JavaScript

## 简介

&lt;fhir-person-identifier&gt; adds select option and two mwc-textfields to page. Uses mwc-textfield and iron-ajax  * In typical use, just use &lt;fhir-person-identifier url=""&gt; &lt;/fhir-person-identifier&gt;
