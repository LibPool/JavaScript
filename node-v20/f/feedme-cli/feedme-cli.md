# feedme-cli

> 标签: cli, crm, feedme

## 简介

CLI da FeedMe — superfície única de terminal pra operar o CRM (propostas, projetos, tarefas, financeiro, pessoas, empresas) com login por pessoa. Substitui o feedme-html-publisher-mcp.
