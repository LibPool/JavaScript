# fluxlane

> 标签: backend, express, framework, mvc, socket.io

## 简介

Este es un Framework basado en [esbuild](https://esbuild.github.io/) para servidores HTTP, WebSockets y con soporte para workers en el mismo proyecto. Con el Patrón MVC puedes crear servidores Web o bien, software de proposito general creando un servidor
