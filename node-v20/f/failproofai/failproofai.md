# failproofai

> 标签: agent-harness, agent-monitoring, agent-observability, agent-reliability, agent-tracing, ai-agent, autonomous-agent, claude-code, cli, codex, enforcement, evals, failure-prevention, guardrails, hermes, hooks, llm-observability, local-first, openclaw, policies

## 简介

Observability and enforcement for AI agent harnesses. 39 built-in policies hooked into 12 of them — Claude Code, Codex, Cursor, Hermes, OpenClaw and more — blocking the tool call before it runs. Local dashboard included, no account needed.
