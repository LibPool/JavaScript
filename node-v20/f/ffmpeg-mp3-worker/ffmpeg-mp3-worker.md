# ffmpeg-mp3-worker

> 标签: WebAssembly, audio, encoder, ffmpeg, lame, mp3, non-blocking, pcm, transcode, wasm, web-worker

## 简介

Minimal FFmpeg WASM for PCM to MP3 conversion (~2MB). Zero dependencies, Web Worker support, non-blocking.
