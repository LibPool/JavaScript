# flowforge-capture

> 标签: api, flow-capture, flowforge, playwright, qa, testing, whisper

## 简介

CLI that records a QA engineer's browser flow (screen + mic + HAR + activity markers) and emits a structured flow.md for FlowForge ideas generation.
