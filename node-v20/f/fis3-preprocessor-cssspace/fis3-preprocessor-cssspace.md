# fis3-preprocessor-cssspace

> 标签: css, fis, fis3, jello, yog2

## 简介

给模块的css添加模块名为前缀，相当于每个模块的css都在独立的命名空间里，简化模块内css命名的同时，解决css命名冲突的问题。1.0.x对应java-velocity模板，1.1.x对应php-smarty模板
