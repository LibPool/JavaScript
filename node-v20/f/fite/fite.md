# fite

> 标签: JavaScript

## 简介

> `fite`是一种不算新型前端构建工具，能够显著提升前端开发体验。基于`原生ESM模块`运行。 > `fite`的理念是, 让第三方依赖全部走CDN, fite只处理业务代码本身, 从而让编译和构建的速度达到今人发指的地步。比`vite`快十几倍。
