# firecrawl-pool

> 标签: cli, firecrawl, mcp, pi-package, proxy, web-scraping

## 简介

Multi-key Firecrawl proxy with credit-aware routing, keyless fallback, and 402 retry. CLI + Go binary (~5MB RAM) with Node.js fallback.
