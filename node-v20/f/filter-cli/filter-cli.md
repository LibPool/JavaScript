# filter-cli

> 标签: agent, ai-agents, cli, content, filter

## 简介

Command-line client for the Filter API. Lets agents and scripts query and mutate a user's Filter account over HTTP.

## 官网

- 官网：https://getfilter.ai/docs/cli
- 源码仓库：git+https://github.com/cbelling/filter-cli.git
- npm 页面：https://www.npmjs.com/package/filter-cli
