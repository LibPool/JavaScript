# feedbapp-cli

> 标签: cli, feedback, feedbapp, mcp, model-context-protocol

## 简介

Hybrid CLI + MCP server for Feedbapp's read API. Use 'feedbapp' in scripts, 'feedbapp-mcp' as a Claude Code / Cursor MCP server.
