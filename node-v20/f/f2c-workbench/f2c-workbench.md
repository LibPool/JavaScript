# f2c-workbench

> 标签: JavaScript

## 简介

f2c-workbench 是基于浏览器的工作台前端框架组件，提供可拖拽的分割面板、以及工作台的基本结构和样式

- 源码仓库：git+https://github.com/fit2cloud-ui/workbench.git
