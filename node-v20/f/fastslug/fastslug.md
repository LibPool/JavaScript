# fastslug

> 标签: permalink, remove-accents, slug, slug-generator, slugify, url-slug

## 简介

Tiny, zero-dependency slug generator for English text, symbols, and currency signs. Turns any string into a URL-safe slug: "Café & Crème $5 🚀" → "cafe-and-creme-dollar-5".
