# figma-local-bridge

> 标签: ai-agent, automation, bridge, design-to-code, figma, figma-plugin, websocket

## 简介

Figma 本地插件桥：无需 Figma MCP 权限，免费账号即可通过本地中继读写 Figma 画布（渲染节点树/组件实例/导出/结构读取）
