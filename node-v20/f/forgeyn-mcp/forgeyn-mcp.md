# forgeyn-mcp

> 标签: ai-agents, baas, forgeyn, mcp, model-context-protocol, postgres, supabase

## 简介

Forgeyn Base MCP server — hosted remote MCP (a URL agents connect to, render.com/mcp style) AND a local stdio server (npx forgeyn-mcp). Projects, SQL, tables, gateway apps. Authenticate with a scoped access token.
