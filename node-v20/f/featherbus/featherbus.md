# featherbus

> 标签: async, bus, emit, event, event-emitter, lightweight, middleware, pub-sub, pubsub, retry, subscribe, wildcard

## 简介

A lightweight, flexible event bus for JavaScript with middleware, wildcard matching, retry, and async support.
