# friendly-errors-warn-webpack-plugin

> 标签: JavaScript

## 简介

- 使用方式同friendly-errors-webpack-plugin一致 - 添加额外参数   - hasSuccessMessage：表示在编译为warning的情况下，也要有compilationSuccessInfo下的message的展示   - showWarning：是否展示warning
