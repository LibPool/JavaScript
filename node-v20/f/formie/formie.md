# formie

> 标签: FormData, ajax, data binding, form, form data, jsonp, knockout, multipart, ui binding

## 简介

Formie submits form data via AJAX. Formie supports JSONP, GET, POST, PUT, DELETE and multipart/form-data file Uploads without the baggage of a full framework.
