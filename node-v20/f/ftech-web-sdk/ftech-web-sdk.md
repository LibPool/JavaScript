# ftech-web-sdk

> 标签: JavaScript

## 简介

本项目基于 qianqun 来实现智能客服，质检，辅助等页面的极易集成 APAAS 方案。 本项目提供便利的 JS SDK 接入，可以将智能客服，质检，辅助页面快速接入到业务系统中，可以避免传统 iframe 的页面引入方式的跨域，身份认证等业务开发，也可以避免代码直接引入带来的 JS、CSS 样式冲突。
