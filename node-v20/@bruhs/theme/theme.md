# @bruhs/theme

> 标签: css, dark-mode, design-system, monaspace, oklch, tailwindcss, tokens

## 简介

Bruhs design system — fruit-named OKLCH colors, Monaspace all-mono typography, warm-dark neutrals, no drop shadows. Framework-agnostic tokens + patterns; works with Tailwind v4 or as a precompiled CSS bundle.
