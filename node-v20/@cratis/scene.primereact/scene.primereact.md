# @cratis/scene.primereact

> 标签: components, cratis, low-code, primereact, react, scene, themes, ui

## 简介

The PrimeReact component package: maps Scene's abstract component names onto real PrimeReact components, and PrimeReact's free themes onto Scene themes.
