# @cratis/scene.engine

> 标签: cqrs, cratis, event-modeling, low-code, renderer, runtime, scene, ui

## 简介

The Scene runtime: walks a Scene element tree and drives whichever renderer is plugged in. Does not know React, or any other rendering platform, exists.
