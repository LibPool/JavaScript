# @cratis/cast

> 标签: astro, astro-integration, cast, cratis, cv, event-modeling, event-sourcing, portfolio

## 简介

Cast: the Cratis profile-site engine. One cast.yaml becomes a verified, event-sourced personal site with a printable CV, live GitHub numbers and a Cast badge.
