# @dogsbay/artifact-viewer

> 标签: JavaScript

## 简介

Publish a Dogsbay Markdown document as a claude.ai Artifact: a fixed viewer page renders the .md beside it in the reader's browser, with comments anchored to source lines and a Changes view for review rounds (npx -y @dogsbay/artifact-viewer doc.md)
