# @dogsbay/format-docusaurus

> 标签: JavaScript

## 简介

Generic Docusaurus importer for Dogsbay — converts standard Docusaurus docs (config instances, sidebars, MDX with Tabs/admonitions/CodeBlock) into TreeNode[]. Site-specific extensions live in injected adapter packages.
