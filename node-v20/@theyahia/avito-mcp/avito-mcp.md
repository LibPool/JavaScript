# @theyahia/avito-mcp

> 标签: ai, avito, classifieds, claude, emerging-markets, marketplace, mcp, mcp-server, model-context-protocol, russia, russian-api

## 简介

MCP server for Avito — Russia's #1 classifieds platform (50M+ MAU). 3 tools: list seller's items, get item details, list messenger chats. OAuth 2.0 Client Credentials with auto-refresh.
