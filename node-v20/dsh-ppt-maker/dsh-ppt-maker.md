# dsh-ppt-maker

> 标签: deepseek-harness, dsh, dsh-plugin, ppt, pptd, pptx, presentation, skill, slides

## 简介

DeepSeek Harness plugin that bundles the ppt-maker skill and the PPT tool surface: create, inspect, edit, undo and redo a PPTD project that exports to a locally generated .pptx.
