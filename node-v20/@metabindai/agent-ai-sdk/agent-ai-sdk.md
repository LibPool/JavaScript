# @metabindai/agent-ai-sdk

> 标签: ai-sdk, assistant-ui, mcp, metabind

## 简介

Vercel AI SDK adapter for the Metabind agent proxy. Drop-in transport for `useChat`, with an assistant-ui flavour at `@metabindai/agent-ai-sdk/assistant-ui`.
