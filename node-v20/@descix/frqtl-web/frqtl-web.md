# @descix/frqtl-web

> 标签: cellular-automata, descix, discrete-physics, egpt, emergent, engine, fractal, frqtl, particle, physics, quantum, simulation, wave-particle-duality

## 简介

FRQTL for the browser — the discrete fractal physics engine (compiled Rust → WASM), its parts as ES modules, the scene doors (bootScene, bootProject) and frqtl-web.min.js.
