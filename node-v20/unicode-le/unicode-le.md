# unicode-le

> 标签: audit, bidi, cli, homoglyph, letools, nolindnaidoo, security, trojan-source, unicode, unicode-le

## 简介

Find the Unicode characters in a codebase that hide meaning: Trojan Source bidi controls, invisibles, homoglyphs and mixed scripts. Reports codepoints, never the characters.
