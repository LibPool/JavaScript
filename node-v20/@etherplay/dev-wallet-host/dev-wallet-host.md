# @etherplay/dev-wallet-host

> 标签: dev-server, development, e2e, etherplay, mnemonic, sign-in, testing, wallet

## 简介

The Etherplay sign-in host, prebuilt, for DEVELOPMENT and e2e only - run it next to your app the way you run a faucet. Unfit for real accounts by construction.
