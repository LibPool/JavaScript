# @kongxiangyiren/ld-api

> 标签: Local Dream, ld-api

## 简介

本地扩散模型（Local Diffusion）HTTP API 的 Node.js / TypeScript 客户端，支持文生图、图生图、inpaint 以及扩散过程预览。
