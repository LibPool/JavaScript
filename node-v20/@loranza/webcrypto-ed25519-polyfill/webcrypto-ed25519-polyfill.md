# @loranza/webcrypto-ed25519-polyfill

> 标签: blockchain, solana, web3

## 简介

A polyfill that adds Ed25519 key manipulation capabilities to `SubtleCrypto` in environments where it is not yet supported

- 官网：https://www.solanakit.com/api#solanawebcrypto-ed25519-polyfill
- 源码仓库：git+https://github.com/anza-xyz/kit.git
