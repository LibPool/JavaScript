> 标签: admin-dashboard, admin-panel, admin-ui, ai, crud, crud-generator, dashboard, graphql, headless-ui, internal-tools, low-code, plugin, react, react-admin, react-admin-dashboard, scaffold, tailwindcss, typescript, vite

## 简介

AI-assisted, plugin-based React admin dashboard scaffold — Vite + Tailwind + Headless UI, with schema-validated CRUD and backend connectors for PocketBase, Supabase, Appwrite, Directus, Strapi & GraphQL.
