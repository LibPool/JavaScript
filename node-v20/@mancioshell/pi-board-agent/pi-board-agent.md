# @mancioshell/pi-board-agent

> 标签: agents, automation, github, github-projects, kanban, pi, pi-agent, pi-extension, pi-package, spec-kit, workflows

## 简介

Autonomous GitHub Project (v2) board executor for Pi — picks Ready cards, implements them in parallel git worktrees via pi-dynamic-workflows, and opens one PR per plan.
