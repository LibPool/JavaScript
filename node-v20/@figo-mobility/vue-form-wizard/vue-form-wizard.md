# @figo-mobility/vue-form-wizard

> 标签: JavaScript

## 简介

The Vue Form Wizard package is a lightweight, unstyled solution to create multi-step forms using Vue 3. This package handles the logic of stepping through the form, leaving the design and customization entirely up to you.
