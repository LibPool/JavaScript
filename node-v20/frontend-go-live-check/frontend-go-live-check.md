> 标签: accessibility, angular, api-testing, astro, audit, axe, ci, e2e, frontend, go-live, go-live-check, lighthouse, merge-gate, nextjs, nuxt, openapi, playwright, postman, pre-launch, react, readiness, release, release-readiness, responsive, security, seo, svelte, swagger, testing, visual-regression, vue, wcag

## 简介

Is your frontend ready to go live? One command tests any web frontend (React, Next.js, Vue, Angular, Svelte, plain HTML…): pages, responsive design, accessibility, keyboard, performance and load, sign-in, the API found in the code, user journeys, security
