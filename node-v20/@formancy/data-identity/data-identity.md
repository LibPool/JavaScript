# @formancy/data-identity

> 标签: JavaScript

## 简介

The host identity tokens Formancy Data verifies: a JWT checked offline under a pinned algorithm, against one key or a JSON Web Key Set read from a file, and the secret references a setting names. jose and Node, and nothing else.
