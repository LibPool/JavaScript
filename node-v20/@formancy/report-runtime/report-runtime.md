# @formancy/report-runtime

> 标签: JavaScript

## 简介

Formancy Report runtime: validates the data a report is given against its contracts, evaluates its expressions, groups, sorts and totals with exact decimals, formats for a locale, and lowers the result to a renderer-neutral document. No framework, no PDF
