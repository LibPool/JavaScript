# @andreasnicolaou/web-notifier

> 标签: andreasnicolaou, auto-dismiss, browser, desktop-notifications, event-driven, notification, notification-api, notifications, observable, permission, permission-handling, promise, rxjs, typescript, web, web-notifications

## 简介

A lightweight, RxJS-based wrapper around the browser Notification API with permission handling, auto-dismiss, delay, a Promise-based API and event callbacks.
