# @telorun/k8s-runner

> 标签: kubernetes, runner, telo

## 简介

Telo Kubernetes Runner - HTTP service that runs Telo Applications as sandboxed Kubernetes Pods. A backend over @telorun/runner-core, sibling to docker-runner.
