# @bedrock-core/observable

> 标签: bedrock, ddui, minecraft, observable, reactive, signal

## 简介

The reactive primitive for @bedrock-core: observable values with get / set / subscribe, computed values, effects and batching, plus a bridge to Minecraft's data-driven UI observables
