# @identsphere/react-shadcn

> 标签: authentication, components, identsphere, radix, react, shadcn, tailwind, ui

## 简介

Opinionated, accessible web (DOM) auth components for the IdentSphere SDK, built on @identsphere/react hooks and styled with shadcn/Radix + Tailwind conventions
