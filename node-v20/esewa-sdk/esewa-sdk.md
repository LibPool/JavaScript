# esewa-sdk

> 标签: epay, esewa, nepal, payment, payment-gateway, sdk, typescript

## 简介

Unofficial, type-safe TypeScript SDK for the eSewa payment gateway (ePay v2 and Token payment). Zero dependencies, runs on Node 18+, Bun, Deno and edge runtimes.
