# @thespeakup/mcp-cli

> 标签: anthropic, claude-desktop, mcp, model-context-protocol, speakup

## 简介

Static-token MCP transport proxy for SpeakUp — bypasses OAuth race in Claude Desktop by reading a long-lived PAT from env and speaking MCP Streamable HTTP to api.speak-up.pro.
