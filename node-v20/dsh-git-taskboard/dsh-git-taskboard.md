# dsh-git-taskboard

> 标签: deepseek, dsh, dsh-plugin, git, harness, task-board, worktree

## 简介

DeepSeek Harness 插件：按分支 Worktree 并行分发 Agent 任务，支持按任务选模型、看板验收与返工。
