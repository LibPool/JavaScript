# @hbar-kit/payments

> 标签: crypto-payments, hashgraph, hbar, hedera, hts, mirror-node, payment-links, payment-verification, payments, sdk, typescript

## 简介

Verify native Hedera payments (HBAR & HTS) by receiver, amount, memo, and time window via the Mirror Node — read-only, non-custodial, bigint-safe.
