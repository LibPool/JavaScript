# @uublue/yimi-element-plus

> 标签: JavaScript

## 简介

Yimi Element Plus是一个基于`Element Plus`进行二次封装的组件库，封装的过程一般是将`Element Plus`原有的多个组件进行组合，然后在此基础上增加了新的功能。
