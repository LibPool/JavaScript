# @arena.ai/faster-latex

> 标签: html, latex, math, mathml, parser, renderer, wasm, webassembly

## 简介

Render full LaTeX documents to HTML (with MathML math) in the browser or on the server (SSR) — pure Rust compiled to WebAssembly.
