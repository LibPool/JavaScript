# @treenwang/gitkit

> 标签: git, github, merge-conflict, partial-clone, pull-request, sparse-checkout, worktree

## 简介

Embeddable server-side git operations with sparse checkout, worktree-isolated concurrency, structured conflict resolution, and optional GitHub PR integration.
