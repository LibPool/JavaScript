# @magist/mcp-server

> 标签: citation, compliance, grounding, legal, magist, mcp, model-context-protocol, regulation

## 简介

Thin stdio bridge to the hosted Magist MCP server: open, deterministic, cited regulatory research for product launches. Returns legal information for research and attorney handoff, not legal advice.
