# @ivliu/micro-page

> 标签: JavaScript

## 简介

micro-page是一款基于history package实现的类spa工具，配合postmessage可以轻松实现多页面之间的数据通信。 micro-page同时支持iframe形式和react component组件形式嵌入，且内置缓存，保证页面的切换流畅
