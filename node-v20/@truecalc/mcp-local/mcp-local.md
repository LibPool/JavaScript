# @truecalc/mcp-local

> 标签: ai, claude, mcp, model-context-protocol, spreadsheet, truecalc

## 简介

TrueCalc Local — a native MCP server exposing TrueCalc's spreadsheet document engine (read/edit cells, formulas, formatting, charts, pivots, and more) as MCP tools over stdio. Paid, one-time-license product; run via npx.
