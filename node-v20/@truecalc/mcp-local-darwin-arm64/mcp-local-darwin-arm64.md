# @truecalc/mcp-local-darwin-arm64

> 标签: JavaScript

## 简介

Prebuilt truecalc-mcp-local (core-pro) binary for darwin/arm64 — installed automatically as an optionalDependency of @truecalc/mcp-local, not meant to be depended on directly. The binary itself is NOT checked into this repo: the release workflow builds it
