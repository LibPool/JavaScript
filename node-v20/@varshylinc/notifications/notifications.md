# @varshylinc/notifications

> 标签: apns, broadcast, capacitor, device-tokens, fcm, firebase-admin, local-notifications, push-notifications, typescript

## 简介

Reusable push notification engine for Capacitor apps: device token storage, FCM/APNs send via Firebase Admin, local notification scheduling, and Hub-ready broadcast delivery reports.
