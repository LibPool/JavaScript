# @utkarshuv/7d-db

> 标签: crud, database, file-database, github-storage, json, json-database, lightweight, query, schema, zero-dependency

## 简介

A lightweight, SQL-inspired database engine for Node.js that stores data in JSON files with optional GitHub-backed remote storage.
