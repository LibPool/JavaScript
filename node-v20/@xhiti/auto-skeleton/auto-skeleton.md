# @xhiti/auto-skeleton

> 标签: auto-skeleton, dark-mode, ghost-rendering, loading, loading-state, next-themes, nextjs, pixel-perfect, placeholder, radix-ui, react, react-skeleton, responsive, shadcn, shadcn-ui, skeleton, skeleton-loader, tailwind, tailwindcss

## 简介

A runtime React component that transforms your actual UI into pixel-perfect, responsive skeleton loaders automatically. No more duplicate JSX for loading states.
