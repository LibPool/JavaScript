# @eamonxg/luci-theme-devkit

> 标签: luci, luci-theme, navigation-api, openwrt, vite-plugin

## 简介

Shared mechanism for eamonxg's LuCI themes: the theme-neutral same-document router, its page-scoped patch loader, and the Vite plugin that ships them as resources/router-<theme>.js.
