# @jaenster/node-debugger-mcp

> 标签: anthropic, breakpoint, cdp, chrome-devtools-protocol, claude, debugger, mcp, model-context-protocol, node, v8-inspector

## 简介

Model Context Protocol server that lets Claude drive a Node.js debugger via the V8 Inspector Protocol — breakpoints, stepping, eval, scope inspection, watches, source-map-aware BPs, child-process and worker-thread auto-attach.
