# dsh-process-kit

> 标签: agent-skills, cordis, deepseek-harness, development-process, dsh, dsh-plugin, subagent, workflow

## 简介

通用单人开发流程框架：文件状态机 + Gate 必停 + 角色分离。自带 9 个角色 subagent、流程骨架文档、门禁脚本与 process_init / process_uninstall 工具。
