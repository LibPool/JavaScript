# @biref/scanner

> 标签: adapter, bidirectional, codegen, data-model, database, driver-agnostic, fluent-api, foreign-key, introspection, mariadb, mysql, orm, postgres, postgresql, prisma, query-builder, relationships, scanner, schema, sql, type-safe, typed, typescript, zero-dependency

## 简介

Paradigm-agnostic database introspection and typed query builder. Bidirectional reference detection, codegen-driven autocomplete, and Prisma-style fluent queries against any table the scanner finds.
