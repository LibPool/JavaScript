# @locnative/sdk

> 标签: address-autocomplete, g-naf, geocoding, geofencing, international, location, locnative, openaddresses, overture, reverse-geocoding, webhooks

## 简介

Official TypeScript SDK for the Locnative location API — international geocoding, geofencing zones, device tracking, and webhooks over authoritative open address data (G-NAF, Overture, OpenAddresses, and more).
