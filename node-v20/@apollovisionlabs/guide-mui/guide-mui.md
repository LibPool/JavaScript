# @apollovisionlabs/guide-mui

> 标签: accessibility, material-ui, mui, onboarding, product-tour, react, walkthrough

## 简介

`guide` is a headless React library for building in-app product tours. `@apollovisionlabs/guide-core` owns the state machine, target resolution, routing, persistence and accessibility concerns, and exposes them as hooks with no rendering opinion. Two pack
