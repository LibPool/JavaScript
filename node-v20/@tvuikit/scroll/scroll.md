# @tvuikit/scroll

> 标签: gsap, scroll, tv, tvkit, virtual, virtualizer

## 简介

Renderer-agnostic virtual scrolling engine for TV UIs. Supports centered/edge-aligned scrolling, dynamic sizes, GSAP animation.
