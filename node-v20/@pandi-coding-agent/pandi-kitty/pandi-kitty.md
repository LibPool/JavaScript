# @pandi-coding-agent/pandi-kitty

> 标签: kitty, pi, pi-extension, pi-package, remote-control, terminal

## 简介

Extensión de Pi para controlar el terminal kitty vía su protocolo de control remoto: un comando /kitty y una herramienta kitty_remote invocable por el modelo (tabs, ventanas, splits, layout).
