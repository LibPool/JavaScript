# @pandi-coding-agent/pandi-rename

> 标签: pi, pi-extension, pi-package, rename, session

## 简介

Extensión de Pi que agrega un comando /rename al estilo Claude para renombrar la sesión actual y autogenerar un nombre desde el historial cuando no se proporciona uno.
