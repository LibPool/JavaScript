# @flyewi/eleventy-plugin-redirects

> 标签: 11ty, eleventy, eleventy-plugin, htaccess, netlify, redirects, seo

## 简介

Eleventy plugin that generates Netlify _redirects, Apache .htaccess, and static HTML fallback pages from a single redirects config.
