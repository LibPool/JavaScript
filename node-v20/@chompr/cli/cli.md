# @chompr/cli

> 标签: ai-search, aiseo, ci, cli, geo, llm, seo

## 简介

Chompr.io CI checker — fetches a URL or local HTML file, scores it with the same engine as the extension and API, and exits non-zero on a failed threshold or a regression against a baseline.
