# @viseed/core

> 标签: JavaScript

## 简介

Core runtime for [Viseed CMS](https://viseed.github.io/cms). Exports `ViseedCMS`, `HookRegistry`, `createDatabase()`, `LocalStorageAdapter`, the widget type registry, and built-in media + widget CRUD routes.
