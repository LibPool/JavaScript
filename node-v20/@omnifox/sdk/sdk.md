# @omnifox/sdk

> 标签: boards, calendar, crm, instagram, messaging, messenger, omnichannel, omnifox, quotes, respond.io, sdk, telegram, webchat, whatsapp

## 简介

Official TypeScript SDK for the Omnifox.io REST API — inbox, CRM, boards, calendar, catalog, quotes, workflows and reports. Verified end-to-end against a live workspace.
