# @electron-stagewright/plugin-storage

> 标签: ai-agent, cookies, electron, mcp, stagewright, storage, testing

## 简介

Storage plugin for Electron Stagewright: read, seed, and assert an Electron app's cookies, storage snapshot, per-key localStorage/sessionStorage, and IndexedDB for agent-driven testing.
