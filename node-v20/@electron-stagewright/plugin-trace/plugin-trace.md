# @electron-stagewright/plugin-trace

> 标签: ai-agent, electron, mcp, observability, stagewright, tokens, trace

## 简介

Trace plugin for Electron Stagewright: record a driving session to JSONL, report token usage, and replay the recorded tool calls.
