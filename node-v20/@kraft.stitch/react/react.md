# @kraft.stitch/react

> 标签: JavaScript

## 简介

Hand-written React wrapper for the <ks-button> Stencil custom element from @ks/core — proof-of-concept for the WebComponents wrapper pattern (core in Stencil, framework-idiomatic props/handlers in the wrapper).
