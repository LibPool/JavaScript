# @nextera.one/tps-standard

> 标签: calendar, chinese, coordinates, geolocation, gregorian, hijri, holocene, human-era, jalali, julian, persian, reality-address, space-time, stuid, time-protocol, tps, tps-uid, unix

## 简介

The Universal Protocol for Space-Time Coordinates. A standard URI scheme (tps://) combining WGS84 spatial data with hierarchical, multi-calendar temporal coordinates. Includes TPS-UID: time-first, reversible event identifiers.
