# @ilpachi/pachi-kit

> 标签: components, date-picker, dialog, edit-dialog, file-upload, ilpachi, pachifast, popup-edit, quasar, server-side-table, table, typescript, upload, vue, vue3

## 简介

Generic Vue 3 / Quasar component kit: UI building blocks, dialogs, section-based edit dialogs with declarative fields, server-side table with CRUD and file uploader. Tree-shakeable sub-path entries.
