# @ilpachi/pachifastquasar

> 标签: alova, application-shell, authentication, dashboard, i18n, layout, pachifast, quasar, typescript, vue, vue3

## 简介

Vue 3 / Quasar application shell for pachifast backends: layout, optional auth, dashboard, i18n, router and HTTP client in a few lines of configuration.
