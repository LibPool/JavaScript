# @fullcalendar/bootstrap

> 标签: bootstrap, bootstrap4, calendar, event, full-sized, fullcalendar

## 简介

FullCalendar v6 only (v7 is current: Bootstrap 4 is not supported; use @fullcalendar/bootstrap5). Bootstrap 4 theme for FullCalendar
