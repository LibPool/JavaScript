# @fullcalendar/daygrid

> 标签: calendar, event, full-sized, fullcalendar, month, month-view

## 简介

FullCalendar v6 only (in v7, this plugin is built into each framework package, e.g. @fullcalendar/react/daygrid). Display events on a month view or "day grid" view

## 官网

- 官网：https://fullcalendar.io/docs/month-view
- 源码仓库：git+https://github.com/fullcalendar/fullcalendar.git
- npm 页面：https://www.npmjs.com/package/@fullcalendar/daygrid
