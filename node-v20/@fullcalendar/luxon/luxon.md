# @fullcalendar/luxon

> 标签: calendar, event, full-sized, fullcalendar, luxon, luxon1, timezone

## 简介

FullCalendar v6 only (v7 is current: use @fullcalendar/format-luxon3 instead). Enhanced date formatting, conversion, and named time zone functionality with Luxon 1
