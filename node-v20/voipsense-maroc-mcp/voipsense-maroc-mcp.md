# voipsense-maroc-mcp

> 标签: call-center, claude, click-to-call, maroc, mcp, model-context-protocol, morocco, pbx, voip, voipsense

## 简介

MCP server for the VoIPSense Cloud public API (VoIPSense Maroc): click-to-call, hangup, transfer, recordings, leads, campaigns, dispositions and GoHighLevel services, plus optional console mode (analytics, live PBX status, CRM, omnichannel inbox) from Cla
