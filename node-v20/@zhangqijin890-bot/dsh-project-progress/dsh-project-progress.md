# @zhangqijin890-bot/dsh-project-progress

> 标签: cordis, deepseek-harness, dsh, handoff, plugin, progress, project

## 简介

DeepSeek Harness plugin: auto-create a project record per workspace, auto-sync project progress, and let a fresh session pick up where the last one ran out of context (DSH 插件：自动记录项目进展，新会话快速接手)
