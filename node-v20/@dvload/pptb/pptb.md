# @dvload/pptb

> 标签: csv, data-load, dataverse, excel, import, powerplatform, toolbox, upsert

## 简介

Map an Excel table or CSV (typically a Power Query output) to a Dataverse table and load it: column mapping with suggestions, lookup resolution by GUID / alternate key / text, insert / upsert / skip / sync modes, dry runs, resumable imports, and dataflow
