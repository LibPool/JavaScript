# @warlock.js/devtools

> 标签: debugging, devtools, mailbox, n+1, profiler, timeline, warlock.js

## 简介

Development-only dashboard for Warlock.js apps at /__warlock: request timeline, queries with EXPLAIN, N+1 detection, dev mailbox, logs, cache operations and the route map. Refuses to run outside development.
