# @enprompta/instrument-openai

> 标签: enprompta, instrumentation, observability, openai, opentelemetry, tracing

## 简介

Enprompta framework instrumentation for the OpenAI SDK — emits typed OpenTelemetry spans that Enprompta ingests as first-class LLM spans.
