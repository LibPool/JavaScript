# @a7mddra/react-dino-game

> 标签: chrome, dinosaur, game

## 简介

A React component for the classic Google Chrome Dinosaur Game (T-Rex Runner).  Originally extracted from Chromium, this game has been packaged as a modern, easy-to-import React component with full TypeScript support.
