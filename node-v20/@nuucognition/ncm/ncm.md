# @nuucognition/ncm

> 标签: ast, commonmark, gfm, markdown, ncm, nuucognition, parser

## 简介

Reference parser for NUU Cognition Markdown (NCM) — a deterministic two-stage document model (syntactic Elements → semantic Blocks with dual IDs and promotion).
