# @openbarclay/telltale-client

> 标签: bug-report, cloudflare-workers, expo, feedback, github-issues, react-native

## 简介

Send in-app bug reports to a Telltale ingest Worker, which opens or comments on a GitHub issue in the project's own repo. Zero dependencies; works in browsers, React Native, Expo, Node and Deno.
