# @jibaru/vocaloid-cli

> 标签: agent, cli, diffsinger, music, openutau, vocaloid

## 简介

Agent-first CLI to compose VOCALOID-style songs and render them headlessly (OpenUtau/DiffSinger), with VOCALOID project export.
