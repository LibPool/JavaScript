> 标签: browser, codec, h.265, h265, hevc, hls, hls.js, hlsjs, media-source-extensions, mediasource, mse, ott, plugin, streaming, transcoding, video, wasm, webassembly

## 简介

hls.js plugin for HEVC/H.265 playback — transparently intercepts MSE to decode HEVC streams via @hevcjs/core
