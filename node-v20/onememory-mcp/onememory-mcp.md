# onememory-mcp

> 标签: ai-agents, claude, fts5, mcp, memory, note-store, rest-api, self-hosted, semantic-search, sqlite

## 简介

OneMemory — one self-hosted SQLite memory store shared across your AI agents over MCP and a plain REST API, reachable from desktop, web, and your phone.
