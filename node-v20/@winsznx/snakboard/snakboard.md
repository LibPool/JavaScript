# @winsznx/snakboard

> 标签: arena, battle-royale, celo, escrow, snak, stacks

## 简介

Arena escrow SDK for Snak on Celo (cUSD) + Stacks. Match creation, score digest, prize-split math, strike streak counter, rank badge tiers.
