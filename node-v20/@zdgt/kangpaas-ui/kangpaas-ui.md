# @zdgt/kangpaas-ui

> 标签: JavaScript

## 简介

kangpaas-ui提供产品层公共组件能力，为各个项目提供公用的前端组件。具体解决如下问题：  ~~~  1.提供共同的组件，一份维护，多处引用。  2.目前项目前端，完全定制，采用的是拷贝修改的模式，各项目之间会出现微小差异。  ~~~ #### 公共组件列表
