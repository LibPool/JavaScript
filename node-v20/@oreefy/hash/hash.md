# @oreefy/hash

> 标签: browser, client, ecosystem, edge, hash, hashing, oreefy, password, pbkdf2, sha512

## 简介

Zero-dependency, secure password hashing for JavaScript/TypeScript using Web Crypto API (PBKDF2-SHA512) with constant-time comparison, Base64Url encoding, and 100k iterations.
