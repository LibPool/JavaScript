# @realitycollective/native-interactions

> 标签: conformance, hermes, input, interaction, native, openxr, physics, pointer, realitycollective, typescript, visionos, webxr, xr

## 简介

Native host adapter for the Reality Collective Interaction Extensions - reads the `input`, `interactions` and `physics` slices a native app (OpenXR, visionOS) installs on `globalThis.__rcHost`, or an injected fake, maps them into the engine-free @realityc
