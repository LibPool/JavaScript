# @immiscible/claude-code-hook

> 标签: agent governance, agent-security, agents, ai agents, ai-safety, anthropic, approval, approvals, audit-log, block-commands, claude, claude code, claude-code, claude-code-hooks, finops, guardrails, hooks, human-in-the-loop, immiscible, kill-switch, mcp, permissions, pretooluse, spend control, tokenops

## 简介

Block or approve Claude Code tool calls by rule: a PreToolUse hook that asks Immiscible before every Bash command, file edit, web fetch and MCP call. Allow, deny, or ask a person; fails closed. One file, no dependencies.
