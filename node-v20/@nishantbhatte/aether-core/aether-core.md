# @nishantbhatte/aether-core

> 标签: anti-entropy, backend-less, collaborative, crdt, distributed-systems, e2e-encryption, hlc, hybrid-logical-clock, lww, merkle-tree, offline-first, react, react-hook, real-time, sync, useaether, websocket, zero-transit

## 简介

Delete the backend. Your React state IS the database. CRDT-backed multiplayer, offline-first, and optional end-to-end encryption so even your own server can't read your data.
