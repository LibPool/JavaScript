# @kaleidorg/wdk-wallet-rln

> 标签: bitcoin, kaleidoswap, lightning, rgb, rln, wallet, wdk

## 简介

WDK wallet adapter for an RGB Lightning Node (RLN) — connects an existing RLN HTTP daemon to the WDK account model.
