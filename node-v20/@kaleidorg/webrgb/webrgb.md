# @kaleidorg/webrgb

> 标签: bitcoin, dapp, kaleidoswap, lightning, provider, rgb, typescript, webrgb

## 简介

WebRGB: TypeScript declarations, discovery, a mock wallet and a conformance suite for the window.rgb provider injected by RGB wallets such as the KaleidoSwap extension.
