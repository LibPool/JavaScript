# @pavelhopson/retry-http

> 标签: abort, backoff, exponential, fetch, http, jitter, resilience, retry

## 简介

Exponential backoff retry for HTTP requests — configurable attempts, delays, jitter, shouldRetry predicate, AbortSignal support.
