# @ultrachess/pieces

> 标签: alpha, cburnett, chess, chess-pieces, chesscom, merida, neo, react, svg, ultrachess

## 简介

Tree-shakable SVG piece sets for @ultrachess/react — cburnett, merida, alpha, neo, chesscom. Each set is a sub-path export (~660 B gzip) so unused sets drop at bundle time.
