# @daysmart/cdk-api-gateway-domain

> 标签: api-gateway, apigateway, cdk, custom domain

## 简介

This CDK Construct Library includes a construct (`CdkApiGatewayDomain`) which creates a custom domain for the specified API Gateway api, along with a base path mapping and route53 alias record to the endpoint cloudfront distribution
