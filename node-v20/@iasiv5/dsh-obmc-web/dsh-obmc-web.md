# @iasiv5/dsh-obmc-web

> 标签: bmcweb, deepseek-harness, dsh, dsh-plugin, openbmc, redfish, same-origin-proxy, settings-section

## 简介

OpenBMC 控制台入口：设置一级菜单「BMC 控制台」面板一键在顶层标签页打开 BMC Web UI，同源代理经 SSH 本地转发 relay（obmc-web-relay）抵达 BMC，BMC IP 变化自动探测并重定向隧道；需 SSH 跳板机可达 BMC。
