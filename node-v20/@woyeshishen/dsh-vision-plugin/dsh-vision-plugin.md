# @woyeshishen/dsh-vision-plugin

> 标签: cordis, deepseek-harness, dsh, image, multimodal, plugin, vision

## 简介

为 DeepSeek Harness 提供外部视觉模型能力：纯文本主模型通过 describe_image 工具调用外部视觉模型看图，拿到纯文字描述（多模态补全）。静态 Cordis 插件，随 DSH 启动自动加载。
