# @misarseo/cli

> 标签: backlinks, cli, keyword-research, misar, misarseo, rank-tracking, search-console, seo, site-audit

## 简介

MisarSEO from the terminal: every endpoint of the MisarSEO API (keyword research, site audits, rank tracking, backlinks, AI search visibility, Search Console, GA4) as a command, with plan-limit upgrade cards and live crawl progress.
