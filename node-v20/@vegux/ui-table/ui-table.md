# @vegux/ui-table

> 标签: css-layers, data-table, design-system, material-react-table, mui, react, react-19, table, typescript

## 简介

Data tables for the vegux design system: Material React Table under vegux tokens and components, with a standard table, a list table with filter panel and status bar, and a grouped table.
