# simfleet

> 标签: agents, android-emulator, avdslim, claude-code, codex, developer-tools, emulator, expo, ios-simulator, metro, react-native, scrcpy, simslim, simulator, worktree

## 简介

One control plane for parallel React Native work on macOS: slimmed iOS simulators and Android emulators, a live browser dashboard, leased Metro ports, a shared native build cache, and per-agent device attribution for Claude Code and Codex.
