# @aaroncarry/dsh-plugin-swarm

> 标签: cordis, deepseek-harness, dsh, master-worker, multi-agent, orchestration, plugin, subagents, swarm

## 简介

Master/worker multi-agent orchestration plugin for DeepSeek Harness: one master agent fans a goal out to parallel worker subagents with per-tier budgets, optional review-with-redo, and a final synthesis step.
