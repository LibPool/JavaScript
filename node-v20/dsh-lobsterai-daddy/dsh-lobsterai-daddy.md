# dsh-lobsterai-daddy

> 标签: deepseek-harness, dsh-plugin, float-ball, lobster-daddy, lobsterai, multi-account, 悬浮球

## 简介

LobsterAIDaddy — a draggable floating ball for DSH that manages multiple LobsterAI accounts with its own built-in data layer (reads LobsterAI's SQLite directly and calls the official APIs), so no separate desktop console has to be running: the drawer show
