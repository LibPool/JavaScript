# @arkstack/realtime

> 标签: arkstack, firebase, notifications, pusher, react, realtime, vue, websocket

## 简介

Client for consuming Arkstack realtime notifications (Pusher/Firebase), with framework-agnostic core plus React and Vue bindings.
