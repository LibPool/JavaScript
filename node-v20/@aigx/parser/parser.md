# @aigx/parser

> 标签: agents, ai, aigx, context, genome, parser

## 简介

Reference parser for AIGX (AI Genome Exchange) genomes. Zero dependencies. Text-in, data-out; data model matches the AIGX 1.1 JSON schema.
