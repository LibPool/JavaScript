# @aigx/lint

> 标签: agents, ai, aigx, conformance, context, genome, lint, validate

## 简介

Programmatic validator for AIGX (AI Genome Exchange) genomes. Implements the AIGX 1.1 conformance checks. Built on @aigx/parser.
