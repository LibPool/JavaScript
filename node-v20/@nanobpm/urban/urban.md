# @nanobpm/urban

> 标签: cli, codegen, derivation, nano-app, nanobpm, rad, runtime, urban

## 简介

Urban: build and run code-first apps on Nano — runtime, derivation toolkit, and CLI in one. Author durable processes with @nanobpm/workflow (defineFlow), a typed datasource, forms, triggers and surfaces from a nano.app.json manifest, on Node or Deno.
