# @nanobpm/nano-workforce

> 标签: nano-ide-agentic-sdlc, nano-ide-ext

## 简介

Nano Workforce — an Agent Graph Orchestration application for Agentic SDLC: durable BPMN processes that coordinate a graph of AI agents across the software delivery lifecycle.
