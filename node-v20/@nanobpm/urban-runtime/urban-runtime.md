# @nanobpm/urban-runtime

> 标签: bpmn, nano-app, nanobpm, rad, urban, urban-runtime

## 简介

The Urban runtime: reads a nano.app.json manifest and materializes the app (deploy models, provision datasources + migrations, start workers, mount surfaces, install triggers, apply security) against a Nano engine. Runtime-agnostic core with Node + Deno a
