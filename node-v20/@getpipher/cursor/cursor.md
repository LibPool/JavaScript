# @getpipher/cursor

> 标签: cmux, cursor, focus, ghostty, herdr, pi-extension, pi-package, tmux, truecolor, tui

## 简介

Focus-aware, customizable editor cursor for the pi coding agent (truecolor + Ghostty/tmux deep; tmux + cmux + herdr; static fallback).
