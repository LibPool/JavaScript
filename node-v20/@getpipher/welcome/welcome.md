# @getpipher/welcome

> 标签: dashboard, home, pi-extension, pi-package, splash, tui, welcome

## 简介

Information-only startup dashboard widget for pi/omp coding agents — branded panel above the live prompt at startup, cleared on the first agent turn. No overlay, no hotkey rebinding.
