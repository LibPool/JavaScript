# @weavetab/plugin-github

> 标签: browser-automation, github, issues, mcp, pull-requests, repository, weavetab, weavetab-official, weavetab-plugin

## 简介

Official Weavetab GitHub plugin - analyze repository structure, read raw source files, search and inspect issues, and examine pull requests over the GitHub API without burning browser turns.
