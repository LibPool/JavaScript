# @duckdb/node-bindings-linux-x64-musl

> 标签: JavaScript

## 简介

Binaries supporting [Node](https://nodejs.org/) bindings to the [DuckDB C API](https://duckdb.org/docs/api/c/overview) for Linux x64 musl.
