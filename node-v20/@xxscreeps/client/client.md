# @xxscreeps/client

> 标签: JavaScript

## 简介

This package provides local browser access to [xxscreeps](https://github.com/laverdet/xxscreeps) users who have purchased the [official Screeps app](https://store.steampowered.com/app/464350/Screeps/) on Steam.
