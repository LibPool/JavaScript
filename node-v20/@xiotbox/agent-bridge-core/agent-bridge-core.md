# @xiotbox/agent-bridge-core

> 标签: agent, bridge, mcp, xiotbox

## 简介

Runtime-neutral L1 stdio MCP bridge with XiotBox-issued session IDs, explicit host lifecycle routing and immutable GitHub credential roles.
