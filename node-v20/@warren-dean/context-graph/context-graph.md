# @warren-dean/context-graph

> 标签: ai-agents, architecture-decision-records, claude-code, claude-code-plugin, codex, context, mcp

## 简介

Gives AI coding agents the why behind your code, and makes them keep it: file cards, rules and decisions kept in git and delivered before every edit, for Claude Code and Codex
