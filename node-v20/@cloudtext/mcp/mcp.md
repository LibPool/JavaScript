# @cloudtext/mcp

> 标签: ai-agent, android, claude, cloudtext, cursor, mcp, model-context-protocol, sms, sms-gateway

## 简介

MCP server for cloudtext.frionode.online. Give your AI agent a phone number: send and read SMS through your own Android phone.
