# @d4y/agent-runtime-nuxt

> 标签: agent, agent-runtime, ai, chat, nuxt, nuxt-module

## 简介

Headless Nuxt module that connects a Nuxt app to an agent-runtime server. Ships server-side proxy routes and a single composable, useAgentRuntime(), that exposes a typed chat client.
