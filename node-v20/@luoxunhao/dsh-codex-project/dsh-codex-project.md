# @luoxunhao/dsh-codex-project

> 标签: JavaScript

## 简介

DSH web plugin inspired by Claude Code /add-dir: a native workspace gains any number of additional writable directories (cross-drive), the model can add directories via the add-dir tool (core approval confirms), and sessions read/write them under workspac
