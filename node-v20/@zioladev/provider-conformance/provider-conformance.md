# @zioladev/provider-conformance

> 标签: agent, attribution, conformance, interoperability, model-context, provider, webmcp

## 简介

Find out where WebMCP interoperability actually broke: measure provider behavior across consumer and runtime paths, attribute failures to the layer that caused them, and keep consumer/browser failures from becoming provider failures.
