# @zioladev/interop-runtime

> 标签: agent, attribution, carried-state, cross-model, interoperability, model-context, multi-provider, runtime, trajectory, webmcp

## 简介

A model-agnostic runtime for executing stateful, multi-step trajectories across independent WebMCP providers — lineage-bearing carried state, explicit terminal requirements, and evidence attributing any failure to model, orchestration, provider, or runtim
