# @squareetlabs/capacitor-android-edge-to-edge

> 标签: android, capacitor, edge-to-edge, native, plugin

## 简介

Capacitor 6 and 7 plugin to support edge-to-edge display on Android using WindowCompat.enableEdgeToEdge()
