# @libka/tokens

> 标签: accessibility, css, design-tokens, dtcg, libka, scss, tailwind

## 简介

The LibKa design tokens (W3C DTCG) with light, dark and high-contrast themes, as CSS custom properties, SCSS and Tailwind themes, with WCAG contrast gates.
