# @libka/mcp

> 标签: accessibility, ai, libka, mcp, model-context-protocol

## 简介

The LibKa MCP server: AI tools list LibKa blocks, check LibKa Markdown and build it into checked, signed web pages, PDFs, slides and Word files.
