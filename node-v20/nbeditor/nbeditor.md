# nbeditor

> 标签: codemirror, docx, editor, katex, markdown, mermaid, pdf, preview, vue

## 简介

A reusable Vue 3 markdown editor: CodeMirror 6 editing, live preview, Mermaid diagrams, KaTeX math, and Markdown / Word / PDF export.
