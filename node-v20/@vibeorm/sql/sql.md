# @vibeorm/sql

> 标签: ast, bun, database, dialect, mysql, orm, postgres, query-builder, sql, sql-builder, sqlite, type-safe, typescript

## 简介

Dialect-aware SQL layer for VibeORM v2 — SQL AST, renderers and capability tables for postgres, sqlite and mysql
