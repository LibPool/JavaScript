# @gmfe/frame

> 标签: JavaScript

## 简介

`@gmfe/frame` 是 gmfe 组件库的页面框架布局包，提供经典的后台管理系统布局结构，包括左侧菜单栏、顶部导航栏、内容区域、面包屑导航和标签页等功能组件。
