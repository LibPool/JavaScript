# @gmfe/react

> 标签: JavaScript

## 简介

`@gmfe/react` 是 gmfe 组件库的核心 UI 包，提供 70+ 个 React 组件，涵盖表单、布局、导航、反馈、数据展示等常用场景。是所有其他 gmfe 包的基础依赖。
