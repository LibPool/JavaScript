# @condorhero/git-xray

> 标签: audit, bus-factor, churn, cli, codebase, git, html, report

## 简介

Diagnose a new codebase with 5 git commands before reading a single file. Generates a self-contained HTML report with charts, dark/light theme, i18n and a11y controls.
