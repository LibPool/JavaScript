# @tailored-ai/google-tools

> 标签: agent, ai, gmail, google-calendar, google-drive, tailored-ai, tools

## 简介

Gmail, Google Calendar, and Google Drive tools for Tailored AI agents. Ships as a register(ctx) plugin — install with `tai plugin install @tailored-ai/google-tools` and list under `plugins:` in config.yaml.
