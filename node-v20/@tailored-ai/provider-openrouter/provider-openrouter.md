# @tailored-ai/provider-openrouter

> 标签: agent, ai, llm, openrouter, provider, tailored-ai

## 简介

OpenRouter model provider for Tailored AI agents. Ships as a register(ctx) plugin — install with `tai plugin install @tailored-ai/provider-openrouter`, list under `plugins:`, and select with `agent.defaultProvider: openrouter`.
