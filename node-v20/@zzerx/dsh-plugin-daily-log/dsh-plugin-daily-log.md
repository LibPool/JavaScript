# @zzerx/dsh-plugin-daily-log

> 标签: daily-log, deepseek-harness, dsh, git, llm, plugin, weekly-report, work-report

## 简介

每日工作日志：聚合 Git 提交与本地 agent 对话（deepseek/claude/codex），按自定义模板生成日报/周报/月报；agent 工具按需注入，默认只挂一个 daily_log 派发器。
