# @libraz/formulon-cell

> 标签: canvas, datagrid, formula, headless-ui, i18n, spreadsheet, wasm, workbook, xlsx

## 简介

Spreadsheet UI for the formulon WASM calc engine — extension-based, i18n-aware, theme-tokenized, and desktop-spreadsheet-style.
