# @idooel/expression

> 标签: JavaScript

## 简介

一个轻量、安全且强大的 JavaScript/TypeScript 表达式求值引擎。它允许你针对数据上下文解析和计算字符串表达式（例如 `user.age > 18 && status === 'active'`），支持 AST 缓存和严格安全模式。
