# @metorial-outpost/crypto

> 标签: JavaScript

## 简介

Low-level cryptographic primitives for the [Metorial Outpost Signature Protocol](../../spec.md): Ed25519 keys and signatures, SHA-256, base64url encoding, and the Metorial Canonical Encoding v1 codec used to build deterministic signature bases.
