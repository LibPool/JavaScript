# @metorial-outpost/parent-adapter

> 标签: JavaScript

## 简介

An [`OutpostAdapter`](../../packages/outpost-adapter) that puts this Outpost behind a parent Outpost, per the ["Nested Outposts"](../../spec.md#59-nested-outposts-outpost-chains) section of the Metorial Outpost Signature Protocol.
