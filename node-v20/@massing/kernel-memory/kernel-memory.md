# @massing/kernel-memory

> 标签: aec, bim, ifc, kernel, reference-implementation

## 简介

A reference KernelProvider that passes the conformance suite. Proves the contract is satisfiable, serves as the template for a third-party kernel, and makes the rest of the stack testable without WASM, a worker or a server.
