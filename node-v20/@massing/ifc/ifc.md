# @massing/ifc

> 标签: aec, bim, ifc, iso-10303-21, parser, step

## 简介

IFC/STEP entity table with byte-preserving emit. Reads a file, lets you edit entities, and writes back the bytes it did not touch — so editing a wall cannot delete a consultant's analytical model.
