# @ddd-framework/uuid

> 标签: JavaScript

## 简介

> `@ddd-framework/uuid` is a package within the comprehensive `@ddd-framework` framework. It provides a class for working with Universally Unique Identifiers (UUIDs) following the RFC4122 standard.
