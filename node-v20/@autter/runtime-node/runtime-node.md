# @autter/runtime-node

> 标签: error-tracking, express, nodejs, opentelemetry, otlp, telemetry

## 简介

Autter Runtime for Node.js: request wide events, coded errors, operation logging, same-origin browser relay and a curated OpenTelemetry server tracker
