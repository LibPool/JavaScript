# @autter/otlp-ingester

> 标签: clickhouse, error-tracking, ingest, opentelemetry, otlp, telemetry

## 简介

Self-hostable OTLP + browser-error ingest service for Autter Runtime: normalises telemetry into a per-repo ClickHouse data model
