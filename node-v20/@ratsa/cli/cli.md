# @ratsa/cli

> 标签: agent, cli, hardware, harness, mcp, ratsa, sof

## 简介

RATSA-Harness CLI — wire RATSA.ai into your Agent: install skill/MCP integrations, use a least-privilege key to search SOFs, generate and pull Harness Packages and SOF files, and report local evaluation results back
