# @obyflow/llm-gemini

> 标签: JavaScript

## 简介

Google Gemini adapter for [Obyflow](https://github.com/Obyflow/obyflow)'s AI-assisted investigation features, implementing the `LLMAdapter` interface from [`@obyflow/llm-core`](https://www.npmjs.com/package/@obyflow/llm-core).
