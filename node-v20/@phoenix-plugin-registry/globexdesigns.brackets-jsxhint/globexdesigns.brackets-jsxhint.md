# @phoenix-plugin-registry/globexdesigns.brackets-jsxhint

> 标签: code, javascript, jshint, jsxhint, linter, linting

## 简介

Adds JSXHint support to Brackets. It's a wrapper around JSHint for linting React JSX files. 100% compatible with existing tools using JSHint.
