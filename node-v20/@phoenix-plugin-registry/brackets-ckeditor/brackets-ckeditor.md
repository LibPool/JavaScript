# @phoenix-plugin-registry/brackets-ckeditor

> 标签: JavaScript

## 简介

Paste or edit HTML-content in Brackets with CKEditor. Notice: After installation or update YOU MUST DOWNLOAD CKeditor AND EXTRACT IT into the extension-folder!!!
