# @phoenix-plugin-registry/lmoustak.brackets-tortoise-svn

> 标签: JavaScript

## 简介

FOR WINDOWS ONLY. Adds TortoiseSVN commands like commit, switch, update, revert, log, diff, blame in File menu, directory tree and working set context menus

- 官网：https://github.com/lmoustak/brackets-tortoise-svn
