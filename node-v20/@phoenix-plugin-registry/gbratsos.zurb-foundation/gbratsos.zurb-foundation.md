# @phoenix-plugin-registry/gbratsos.zurb-foundation

> 标签: CSS, CSS3, Foundation 6, HTML, HTML5, Zurb, extension, grid, mobile-first, responsive

## 简介

Adds Zurb Foundation 6 basic template to your page. Go to menu and select File -> New Zurb Foundation 6 Document.
