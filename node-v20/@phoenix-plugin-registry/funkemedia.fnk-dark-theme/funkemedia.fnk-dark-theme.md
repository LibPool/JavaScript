# @phoenix-plugin-registry/funkemedia.fnk-dark-theme

> 标签: dark, dreamweaver, theme

## 简介

A Dark Theme based on an inverted version of Dreamweavers light standard theme. Great if you are used to dreamweavers colours but a lot easier on the eye.
