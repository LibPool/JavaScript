# @phoenix-plugin-registry/pelatx.flexible-boilerplate

> 标签: boilerplate, copy, file, folder, subfolder, template

## 简介

Set a boilerplate repository folder. Then you can select a file or a folder to copy it directly to your project, or copy only some items from a directory if you want.

- 官网：https://github.com/pelatx/brackets-flexible-boilerplate
