# @phoenix-plugin-registry/brackets-robotframework

> 标签: JavaScript

## 简介

Editing mode for Robotframework plain text files, providing syntax highlighting, code folding, auto-completion (requires robotframework-hub - https://github.com/boakley/robotframework-hub) and more.
