# @phoenix-plugin-registry/brackets-semicenter

> 标签: js, javascript, edit, editing

## 简介

ALT+ENTER - > Puts semicolon at current line, creates and indents new line below. 
ALT+SEMICOLON - > Puts semicolon at current line, goes to the end of current line. 
Simple, useful.
