# @work.books/workbench

> 标签: agent, eval, observability, otel, workbook

## 简介

Workbench — agent evaluation, observability, and iterate-agent loop. Drives `workbook chat / git / session` to run eval specs, aggregate session traces, and propose improvements against failing agents.
