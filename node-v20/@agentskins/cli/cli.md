# @agentskins/cli

> 标签: agent, ai, claude, codex, cursor, electron, skins, themes

## 简介

Toolkit for skinning AI agent desktop apps — detect skinnable hosts (Codex, Claude Desktop, Cursor, Antigravity, Windsurf) and find skin tools for each.
