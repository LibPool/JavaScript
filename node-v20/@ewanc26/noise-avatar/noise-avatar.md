# @ewanc26/noise-avatar

> 标签: avatar, canvas, deterministic, noise, procedural

## 简介

Deterministic value-noise avatar generation from a string seed. Thin wrapper around @ewanc26/noise. Zero extra dependencies, works in any environment with a Canvas API.
