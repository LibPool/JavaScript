# @ewanc26/noise

> 标签: canvas, deterministic, fbm, noise, procedural, value-noise

## 简介

Generic deterministic value-noise generation. Arbitrary dimensions, multi-octave FBM, multiple colour modes. Zero runtime dependencies, works in browsers and Node.js.
