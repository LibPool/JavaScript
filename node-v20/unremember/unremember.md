# unremember

> 标签: agent, claude-code, context, deepseek-harness, dsh, forget, privacy, transcript

## 简介

Make a local coding agent truly forget something: remove it from the session, its echoes and its off-session copies (memory, prompt history), then prove it with leak probes.
