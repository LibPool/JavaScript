# @unicorn.eth/autoconnect

> 标签: autoconnect, ethereum, gasless, rainbowkit, smart-account, thirdweb, unicorn, wagmi, wallet, wallet connector, web3, web3 account, web3modal

## 简介

Drop-in Unicorn wallet integration for existing web3 apps. Works alongside your existing wallet setup (RainbowKit, Wagmi, Web3Modal, etc.) without modifying any code.
