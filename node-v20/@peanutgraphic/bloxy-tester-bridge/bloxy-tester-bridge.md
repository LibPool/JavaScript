# @peanutgraphic/bloxy-tester-bridge

> 标签: JavaScript

## 简介

JS port of bloxy-tester-bridge. Verifies HMAC-signed requests from the TESTER worker, exposes a /tester/health handler, and discovers TS scenario manifests. Targets Node runtime; Next.js / Express / generic Node-HTTP friendly.
