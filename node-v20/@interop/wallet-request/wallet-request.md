# @interop/wallet-request

> 标签: app-connect, isomorphic, vc-api, verifiable-credentials, verifiable-presentation-request, wallet

## 简介

Wallet-request and exchange protocol handling for Interop wallet apps: input classification, VPR parsing, QueryByExample matching, cryptosuite negotiation, VP composition, the App Connect app-key credential, and the VC-API / ephemeral-exchange clients.
