# @interop/was-sync

> 标签: isomorphic, offline-first, replication, rxdb, sync, wallet-attached-storage

## 简介

The WAS replication driver for RxDB: the changes-feed pull handler, the conditional-write push handler, the conflict-handler seam, the synced-document schema, and the session controller core.
