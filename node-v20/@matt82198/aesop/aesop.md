> 标签: ai-agents, claude, developer-tools, llm, multi-agent, orchestration, resilience, template

## 简介

Multi-agent orchestration for AI coding agents, designed to survive failure — a plain-file brain, git as the only durable layer, cheap subagent fleets, and guardrails enforced in code.
