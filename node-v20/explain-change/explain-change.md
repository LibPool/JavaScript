# explain-change

> 标签: agent, architecture, claude-code, code-review, diff, openspec, pull-request, skill

## 简介

Visual, architecture-first explanation of a code change, as one self-contained HTML page. A deterministic CLI does the analysis; an agent writes only the prose.
