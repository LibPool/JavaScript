# @metalfs/snappy-decompress

> 标签: JavaScript

## 简介

This implementation adds a thin wrapper over the [FPGA-Snappy-Decompressor ](https://github.com/ChenJianyunp/FPGA-Snappy-Decompressor) implementation to provide Metal FS integration.
