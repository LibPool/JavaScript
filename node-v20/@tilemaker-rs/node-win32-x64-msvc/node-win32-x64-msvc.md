# @tilemaker-rs/node-win32-x64-msvc

> 标签: geojson, multipolygon, napi, openstreetmap, osm, osm.pbf, pbf, rust, streaming

## 简介

Stream OpenStreetMap data out of .osm.pbf files in Node.js: filtered elements and assembled points, lines and multipolygons, fast and with bounded memory (Rust, N-API).
