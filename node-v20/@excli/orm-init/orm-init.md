# @excli/orm-init

> 标签: cli, code-generator, database, database-setup, drizzle, excli, nodejs, orm, orm-init, orm-setup, prisma, sequelize, typeorm, typescript

## 简介

A CLI tool for setting up popular SQL and NoSQL ORMs/ODMs in Node.js projects, with support for both JavaScript and TypeScript.
