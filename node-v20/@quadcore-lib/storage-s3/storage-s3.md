# @quadcore-lib/storage-s3

> 标签: JavaScript

## 简介

Driver de `@quadcore-lib/storage-server` que sube/firma/borra archivos en S3 o compatibles (AWS S3, Cloudflare R2, MinIO), en reemplazo de `LocalStorageDriver` para producción.
