# @quadcore-lib/mailer-server

> 标签: JavaScript

## 简介

Envío de emails con **proveedor intercambiable** (SMTP/Resend/SES) y plantillas. Módulo `@Global()`: inyectá `MailerService` donde lo necesites (confirmación de orden, respuesta a tickets, bienvenida). Trae `ConsoleMailProvider` por defecto.
