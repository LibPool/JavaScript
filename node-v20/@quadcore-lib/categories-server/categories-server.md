# @quadcore-lib/categories-server

> 标签: JavaScript

## 简介

CRUD de categorías para e-commerce, sobre NestJS + TypeORM. Lectura pública (storefront), escritura `admin`. Soporta jerarquía (`parentId`), orden, soft-delete.
