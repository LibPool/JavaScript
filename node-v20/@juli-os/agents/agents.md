# @juli-os/agents

> 标签: JavaScript

## 简介

juli-os L0 layer: the execution substrate — tmux-based agent session runtime with delivery confirmation, self-healing dispatch, PTY attach, hooks, snapshots, skills, and an ACP executor. Zero npm dependencies.
