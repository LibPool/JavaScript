# @rectrix/iotcore-drivers

> 标签: JavaScript

## 简介

SerialConnection  - It is using one address to read the data  - default     -- SERIAL_PORT = COM4     -- BAUD_RATE = 9600     -- PARITY = None     -- STOP_BITS = 1     -- Client ID = 1 - hardcoded     -- Timeout = 1 second
