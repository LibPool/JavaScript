# @xproeditor/vue

> 标签: block-editor, contenteditable, editor, notion, rich-text, vue, wysiwyg

## 简介

Notion-like block editor for Vue 3 — supports a sticky format toolbar and/or a floating Notion-like bubble toolbar + slash menu.
