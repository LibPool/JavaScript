# @gant-lowcode/code-generator

> 标签: JavaScript

## 简介

所谓出码，即将低代码编排出的 schema 进行解析并转换成最终可执行的代码的过程。本模块提供有 Gant 和 GantLegacy 两套框架的出码方案，并提供了强大而灵活的扩展机制。
