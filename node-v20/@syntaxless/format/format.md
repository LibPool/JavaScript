# @syntaxless/format

> 标签: currency, date-format, formatter, intl, natural-language, nlp, number-format, offline, on-device, parser, percentage, plain-english, syntaxless, typescript, zero-dependency

## 简介

Convert plain English formatting instructions to Intl number, currency, percentage and date formatters. On-device natural-language parser for TypeScript and JavaScript, offline, zero dependencies.
