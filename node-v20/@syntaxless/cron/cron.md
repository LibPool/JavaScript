# @syntaxless/cron

> 标签: cron, cron-expression, crontab, natural-language, nlp, offline, on-device, parser, plain-english, recurrence, schedule, scheduler, syntaxless, typescript, zero-dependency

## 简介

Convert plain English schedules to cron expressions and next run dates. On-device natural-language parser for TypeScript and JavaScript, offline, zero dependencies.
