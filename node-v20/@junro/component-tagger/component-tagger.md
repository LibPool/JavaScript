# @junro/component-tagger

> 标签: component-tagging, component-tracking, customizable, cypress, debugging, development-tools, devtools, e2e, jsx, playwright, react, testing, tsx, vite, vite-plugin

## 简介

Vite plugin that tags JSX elements with data-dev-* attributes (source path, line, enclosing component) so Junro's web plugin can point a report at the right file.
