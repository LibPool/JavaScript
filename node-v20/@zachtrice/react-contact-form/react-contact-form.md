# @zachtrice/react-contact-form

> 标签: contact, email, form, headless, honeypot, react, typescript, unstyled

## 简介

Tiny, unstyled, dependency-free React contact form: honeypot spam trap, validation, and a JSON POST to any endpoint. Bring your own styles.
