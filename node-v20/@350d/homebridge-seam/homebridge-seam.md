# @350d/homebridge-seam

> 标签: august, door-lock, home-automation, homebridge, homebridge-plugin, homekit, iot, kwikset, lock, schlage, seam, seam-co, smart-door, smart-lock, universal-api, yale

## 简介

Modern Homebridge plugin for smart locks via Seam.co API. Supports August, Yale, Schlage, Kwikset, and 100+ other smart lock brands through Seam's universal API with real-time webhook updates and comprehensive HomeKit integration.
