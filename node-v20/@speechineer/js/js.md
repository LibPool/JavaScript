# @speechineer/js

> 标签: ai-forms, dictation, forms, speech-to-form, speech-to-text, speechineer, structured-data, voice-documentation, voice-input

## 简介

Build voice-based documentation into any web app — spoken or typed input becomes structured, typed values in real time. Framework-free.
