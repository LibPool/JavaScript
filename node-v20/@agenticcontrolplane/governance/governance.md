# @agenticcontrolplane/governance

> 标签: acp, agent-governance, agentic-control-plane, delegation-chain, tool-call-audit

## 简介

Thin Node SDK for the Agentic Control Plane governance hook protocol. Wrap any tool call; ACP decides allow/deny/redact.
