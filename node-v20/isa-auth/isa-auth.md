> 标签: agent-skill, apple-auth, auth, authentication, discord-auth, fido2, github-auth, google-auth, headless, jwt, kakao-auth, line-auth, meta-auth, naver-auth, oauth, oauth2, passkey, rbac, react, siwe, skills, svelte, vue, web3, webauthn, world-id, worldcoin

## 简介

Unified, framework-agnostic frontend authentication library supporting OAuth (Google, Apple, Meta, Line, Kakao, Naver), Developer (GitHub, Discord), Web3 (SIWE), Identity (World ID Orb, Passkey WebAuthn), reactive store, and RBAC guards with AI Agent skil
