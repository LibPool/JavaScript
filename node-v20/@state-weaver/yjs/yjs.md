# @state-weaver/yjs

> 标签: CRDT, Collaborative editing, Conflict-free replicated data types, Data synchronization, Distributed systems, JSON, JavaScript, Real-time collaboration, Shared types, State management, TypeScript, Wrapper library, Y.Array, Y.Map, Yjs

## 简介

A TypeScript library that provides a wrapper around Yjs shared types, facilitating easy interaction with Yjs CRDTs using plain JavaScript objects.
