# @asksql/mcp

> 标签: agents, ai, ask-database, database, database-chat, llm, mcp, mcp-server, model-context-protocol, natural-language, nl2sql, sql, sql-generation, text-to-sql, tools

## 简介

Model Context Protocol server for AskSQL: exposes list-connections / schema / query / run as MCP tools so AI agents can safely query registered databases (read-only, guarded).
