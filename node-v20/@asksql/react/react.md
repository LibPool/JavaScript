# @asksql/react

> 标签: ai, ask-database, chat-ui, data-chat, database, database-chat, llm, natural-language, nl2sql, react, react-component, sql, sql-generation, text-to-sql, text2sql

## 简介

React UI for AskSQL: <AskSqlChat/> full-page chat and <AskSqlBubble/> floating chat-head, plus headless hooks. Light/dark, loading/empty/error states built in.
