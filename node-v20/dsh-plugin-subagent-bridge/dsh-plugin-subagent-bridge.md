# dsh-plugin-subagent-bridge

> 标签: bridge, codex, deepseek, dsh-plugin, harness, mcp

## 简介

Subagent bridge: lets Codex delegate a task to DeepSeek Harness the way it would spawn a subagent (one call, waits for the answer), plus a codex_dispatch tool for the reverse direction.
