# @rine-kit/agent-memory

> 标签: JavaScript

## 简介

Host-agnostic agent memory runtime: recall (exact/lexical/semantic fusion), explicit writes, evidence-based dreaming. Authorization stays opaque; hosts supply storage, model, embedding and clock ports.
