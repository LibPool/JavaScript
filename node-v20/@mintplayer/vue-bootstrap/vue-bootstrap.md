# @mintplayer/vue-bootstrap

> 标签: JavaScript

## 简介

Vue 3.5 SFC adapters around @mintplayer/web-components. Each sub-entry maps one-to-one with a WC sub-entry and exposes typed Vue components with v-model support for input WCs.
