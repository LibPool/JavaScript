# @fly/sprites

> 标签: agent-sandbox, ai-agents, checkpoint-restore, fly-io, microvm, remote-execution, sandbox, sprites

## 简介

JavaScript and TypeScript SDK for Fly.io Sprites: computers for agents. Node-style APIs for creating Sprites, running remote commands, moving files, and managing checkpoints.

- 官网：https://fly.io/sprites/
- 源码仓库：git+https://github.com/superfly/sprites-js.git
