# @latentic/live-markdown

> 标签: codemirror, codemirror-6, codemirror-extension, editor, footnotes, frontmatter, gfm, inline-preview, katex, latex, live-markdown, live-preview, local-first, markdown, markdown-editor, markdown-preview, markdown-wysiwyg, math, mermaid, mermaid-diagrams, notion-like, obsidian, react, react-markdown-editor, rich-markdown-editor, rich-text-editor, tables, text-editor, wikilinks, wysiwyg, wysiwyg-markdown

## 简介

WYSIWYG markdown editor for React, built on CodeMirror 6. Headings, tables, LaTeX math and Mermaid diagrams render inline as you type — no preview pane and no AST: value in and onChange out is the same markdown string, frontmatter included.
