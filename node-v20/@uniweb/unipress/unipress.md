# @uniweb/unipress

> 标签: cli, document, docx, foundation, pdf, typst, unipress, uniweb, xlsx

## 简介

Compile a content directory into a document (PDF, EPUB, Paged.js HTML, Typst source bundle, DOCX, XLSX) using a Uniweb foundation. Five built-in templates: book, monograph, report, data-report, directory.
