# @pyroprompts/mcp-stdio-to-streamable-http-adapter

> 标签: JavaScript

## 简介

A Model Context Protocol Server that runs as stdio, wrapping a Streamable HTTP server, so any MCP-supporting client can use Streamable HTTP MCP Servers
