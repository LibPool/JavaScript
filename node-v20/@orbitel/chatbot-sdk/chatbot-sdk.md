# @orbitel/chatbot-sdk

> 标签: JavaScript

## 简介

A lightweight, embeddable AI chatbot widget that works with **any website** — HTML, PHP, WordPress, Angular, Vue, React, Webflow, Laravel, or custom JS apps — without needing frameworks or builds.
