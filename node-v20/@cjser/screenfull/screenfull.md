# @cjser/screenfull

> 标签: browser, fullscreen

## 简介

Simple wrapper for cross-browser usage of the JavaScript Fullscreen API, which lets you bring the page or any element into fullscreen.

## 官网

- 源码仓库：https://code.moenext.com/3rdeye/cjser.git
- npm 页面：https://www.npmjs.com/package/@cjser/screenfull
