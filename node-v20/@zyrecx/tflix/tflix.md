# @zyrecx/tflix

> 标签: samsung, streaming, tizen, tizenbrew, tmdb, tv

## 简介

TFlix is a 10-foot streaming web app for Samsung Smart TVs running TizenBrew, featuring TMDB discovery and multi-embed streaming.
