# @nonnajs/vue

> 标签: composables, dependency-injection, di, ioc, nonna, vue, vue3, zero-reflection

## 简介

Vue bindings for @nonnajs/di - a <NonnaProvider> component plus useInjection()/useOptionalInjection()/useAllInjections()/useInjector() composables for zero-reflection dependency injection in Vue 3 apps.
