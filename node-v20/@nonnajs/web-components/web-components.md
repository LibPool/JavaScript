# @nonnajs/web-components

> 标签: context-protocol, custom-elements, dependency-injection, di, ioc, lit, nonna, web-components, zero-reflection

## 简介

Web Components & Custom Elements bindings for @nonnajs/di - W3C Context Protocol provider, <nonna-provider> element, requestInjection() helpers, and @inject() decorator for custom elements.
