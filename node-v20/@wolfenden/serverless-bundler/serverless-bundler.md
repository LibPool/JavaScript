# @wolfenden/serverless-bundler

> 标签: JavaScript

## 简介

@wolfenden/serverless-bundler is a combination of a [Serverless Framework](https://www.serverless.com) plugin as well as a CLI that abstracts away all the packages and configuration for my serverless projects.
