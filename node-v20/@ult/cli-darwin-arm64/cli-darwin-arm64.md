# @ult/cli-darwin-arm64

> 标签: JavaScript

## 简介

The ult command line and its prebuilt runtimes for macOS on Apple silicon. Installed by the ult package; not for direct use. 3.0.0-alpha.0 claims the name; the binary arrives with 3.0.0-alpha.1.
