# dsh-skill-auditor

> 标签: agent-tools, audit, capability-depreciation, deepseek-harness, dsh, dsh-plugin, regression, skill

## 简介

能力折旧表 · capability depreciation auditor for agent assets: regression-tests installed skills/plugins against the current model, attributes degradation, and recommends what to keep, rewrite, or drop. Ships as a DSH plugin (tools) and a host-neutral skill.
