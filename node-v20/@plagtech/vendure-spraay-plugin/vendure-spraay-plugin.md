# @plagtech/vendure-spraay-plugin

> 标签: base, batch-payments, marketplace, payouts, spraay, usdc, vendure, vendure-plugin, x402

## 简介

Admin-approved, noncustodial USDC batch payouts to sellers on Base for Vendure, powered by the Spraay batch contract and gateway.
