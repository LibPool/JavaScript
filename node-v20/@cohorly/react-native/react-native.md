# @cohorly/react-native

> 标签: analytics, cohorly, mixpanel, product-analytics, react-native, tracking

## 简介

Standalone React Native SDK for Cohorly, hosted product analytics (Mixpanel-style). No hard dependency on react-native; works out of the box with in-memory storage and upgrades to AsyncStorage when injected. Ships an autolinked native module for device-in
