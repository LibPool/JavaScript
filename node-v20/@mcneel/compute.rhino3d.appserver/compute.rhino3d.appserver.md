# @mcneel/compute.rhino3d.appserver

> 标签: compute.rhino3d, expressjs, grasshopper3d, node.js, rhino3d, rhino3dm

## 简介

A node.js/expressjs server which communicates to a rhino3d compute geometry server to remote solve Grasshopper definitions.
