# @guren/plugin-markdown

> 标签: bun, framework, fullstack, gfm, guren, markdown, shiki, typescript

## 简介

Markdown-to-HTML rendering for Guren applications: GitHub Flavored Markdown, sanitized output, alerts, heading anchors and optional shiki highlighting.
