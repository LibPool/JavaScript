# @smithy-hono/create

> 标签: JavaScript

## 简介

Scaffold a new smithy-hono app with one command: `npm create @smithy-hono`. Prompts for a deploy target (Cloudflare / Node / AWS), full-stack vs API-only, and auth (none / OIDC), then generates a ready-to-deploy project wired to the matching @smithy-hono/
