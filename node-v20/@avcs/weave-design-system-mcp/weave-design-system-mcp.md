# @avcs/weave-design-system-mcp

> 标签: ai-agents, design-system, design-tokens, mcp, model-context-protocol, storybook, tailwind, vanilla-extract

## 简介

Generic MCP server that makes any design system (tokens + components) queryable by coding agents, and agent-generated UI checkable against it.
