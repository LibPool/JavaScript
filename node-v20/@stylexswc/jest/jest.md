# @stylexswc/jest

> 标签: babel-free, css-in-js, css-in-js-testing, jest, jest-transform, jest-transformer, napi-rs, react-testing, rust, stylex, stylex-jest, swc, testing

## 简介

Jest transformer for StyleX that compiles CSS-in-JS with the Rust NAPI-RS/SWC compiler, enabling Babel-free StyleX component tests.
