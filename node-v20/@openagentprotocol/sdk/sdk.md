# @openagentprotocol/sdk

> 标签: agent, ai, did, ed25519, manifest, oap, open-agent-protocol, rfc-0019

## 简介

Official TypeScript SDK for the Open Agent Protocol (OAP). Build OAP servers and clients with manifest publishing, signed invocation, hash-chained receipts, and conformance attestation.
