# @cmori/skyscope-core

> 标签: JavaScript

## 简介

Headless engine for Mori.SkyScope: ring buffers, M4 decimation, SkyScopeFrame codec, scales, painter contract, trend chart, gauges, analytic charts, scene layers, source-plugin contracts.
