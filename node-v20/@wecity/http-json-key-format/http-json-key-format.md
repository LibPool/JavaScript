# @wecity/http-json-key-format

> 标签: JavaScript

## 简介

只需添加一行代码即可对http请求的请求参数和响应参数中的json字段进行格式化，无依赖，无侵入，支持微信小程序端（weApps/原生小程序）、浏览器端（axios/fetch/原生js）,支持自定义格式化和自定义过滤请求。
