# @deviceinsight/scale-ui-custom-scripts

> 标签: JavaScript

## 简介

scale-ui-custom-scripts will automatically parse .env files and expose any variable starting with `REACT_APP_` or `NGUI_` to the custom project where you can access it via `process.env.NGUI_SOME_CUSTOM_SETTING`.
