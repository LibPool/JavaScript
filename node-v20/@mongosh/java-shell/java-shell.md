# @mongosh/java-shell

> 标签: JavaScript

## 简介

Java application that uses mongosh-shell-api node module and MongoDB java driver to run mongo shell on JVM

## 官网

- 官网：https://github.com/mongodb-js/mongosh#readme
- 源码仓库：git://github.com/mongodb-js/mongosh.git
