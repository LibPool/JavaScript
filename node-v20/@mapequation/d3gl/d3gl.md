# @mapequation/d3gl

> 标签: canvas, d3, geojson, gpu, luma.gl, map, svg, visualization, webgl

## 简介

GPU-accelerated rendering for d3 — especially maps with GeoJSON and grid-cell data, with switchable SVG / Canvas2D / WebGL2 backends.
