# @spencermcw/oidc-rp

> 标签: back-channel-logout, oauth2, oidc, openid-connect, pkce, relying-party

## 简介

Shared OpenID Connect relying-party library: code + PKCE sign-in, back-channel logout and local user resolution, with node:http, h3 and Hono adapters.
