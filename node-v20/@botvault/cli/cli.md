# @botvault/cli

> 标签: agent-credentials, ai-agents, anthropic, api-keys, botvault, claude-code, credential-vault, cursor, llm-tools, mcp, model-context-protocol, openclaw, secrets-manager

## 简介

BotVault CLI — install the BotVault MCP server (Claude Code, OpenClaw, Cursor) so your AI agents can fetch credentials at runtime instead of you pasting them into chat.
