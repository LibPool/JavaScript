# @lynqly/runtime

> 标签: eject, export, fair-source, lynqly, no-code, portability, runtime

## 简介

Runtime for exported Lynqly apps: plain Node plus Postgres, no platform dependency. Eject your app and run it anywhere. Fair Source (FSL-1.1-MIT); every release becomes MIT two years after it ships.
