# @bandeira-tech/b3nd-save

> 标签: JavaScript

## 简介

B3nd data-saving layer: Store backends (postgres, mongo, sqlite, fs, ipfs, s3, elasticsearch, localstorage, indexeddb, memory) and Store→ProtocolInterfaceNode clients.
