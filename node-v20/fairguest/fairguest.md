# fairguest

> 标签: guest-registration, mossos, rd-933-2021, ses-hospedajes, short-term-rental, vacation-rental

## 简介

Guest registration for short-term rentals, on the host's computer: the data Spain's Real Decreto 933/2021 asks for, deadlines, retention, field encryption, and the Mossos d'Esquadra file for Catalonia. No network, no files.
