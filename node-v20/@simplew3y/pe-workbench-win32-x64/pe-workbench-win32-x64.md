# @simplew3y/pe-workbench-win32-x64

> 标签: JavaScript

## 简介

Test distribution. Supported targets: win32-x64. Requires Node >=22.23.2; Windows requires Git Bash. First launch downloads a SHA256-verified private Python runtime. Run pe-workbench setup to prepare it, or pe-workbench --check for offline diagnostics. Us
