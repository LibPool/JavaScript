# @simplew3y/pe-workbench-darwin-arm64

> 标签: JavaScript

## 简介

Test distribution. Supported targets: win32-x64, darwin-arm64, darwin-x64. Requires Node >=22.23.2; Windows requires a working Bash (Git Bash recommended). First launch downloads a SHA256-verified private Python runtime. Run pe-workbench setup to prepare
