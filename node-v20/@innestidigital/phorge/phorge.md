# @innestidigital/phorge

> 标签: agent-tools, ai, code-graph, coding-agent, git-mining, laravel, static-analysis

## 简介

Zero-LLM static intelligence layer for Laravel coding agents. Provides commit-mining, code graphs, anchor resolution, and plan validation as deterministic signals before agent planning.
