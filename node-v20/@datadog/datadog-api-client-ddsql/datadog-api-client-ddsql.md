# @datadog/datadog-api-client-ddsql

> 标签: api, fetch, typescript

## 简介

Execute DDSQL queries against the Datadog data catalog and poll for their results. Queries are dispatched asynchronously: the initial request may return a `running` state with a `query_id`, and clients poll the fetch endpoint until the response transition
