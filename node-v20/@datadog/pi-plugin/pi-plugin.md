# @datadog/pi-plugin

> 标签: datadog, infrastructure, mcp, observability, pi, pi-package, productivity

## 简介

Use Datadog directly in the Pi coding agent through a preconfigured Datadog MCP server. Query logs, metrics, traces, dashboards, and more through natural conversation.
