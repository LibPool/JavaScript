# @ifc-lite/flow

> 标签: bim, dataflow, ifc, node-graph, visual-programming

## 简介

Keyed-data graph runtime for BIM workflows: typed ports, item/list/group lifting, memoised evaluation, and element tracking for re-runnable graphs
