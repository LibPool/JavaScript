> 标签: css-variables, dark-mode, design-system, design-tokens, dtcg, figma, figma-variables, live-reload, style-dictionary, tailwind, tailwindcss, theming, tokens-studio

## 简介

Figma variables and styles to CSS variables, Tailwind v3/v4, SCSS and JS. Serve them live so your website updates when the design changes, with no redeploy.
