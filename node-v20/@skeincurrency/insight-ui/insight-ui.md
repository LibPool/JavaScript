# @skeincurrency/insight-ui

> 标签: bitcore-dash, blockchain, blockexplorer, dash, dashcore, front-end, insight

## 简介

An open-source frontend for the Insight API. The Insight API provides you with a convenient, powerful and simple way to query and broadcast data on the SkeinCurrency network and build your own services with it.
