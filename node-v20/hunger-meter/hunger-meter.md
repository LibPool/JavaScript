# hunger-meter

> 标签: JavaScript

## 简介

A read-only analytics tool that scans directory trees and ranks directories by 'storage hunger' — how aggressively they consume disk space over time — using 14 statistical metrics and composite scoring. Built with Bun, zero runtime dependencies.
