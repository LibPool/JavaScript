# dsh-batch-uninstall

> 标签: batch, deepseek, deepseek-harness, dsh, dsh-plugin, harness, plugin-manager, uninstall, uninstaller

## 简介

Geek 风格 DSH 工具箱：批量卸载插件、批量删除工作区（软删除到回收站）、回收站管理，核心系统插件自动锁定保护。A Geek-style DSH toolbox: batch plugin uninstall, batch workspace delete (soft-delete to trash) and trash management.
