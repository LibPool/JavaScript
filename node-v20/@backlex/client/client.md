# @backlex/client

> 标签: baas, backend-as-a-service, backlex, client, realtime, rest, sdk, typescript

## 简介

Typed TypeScript client for the backlex API — auth, collection CRUD, query builder, realtime, storage, jobs, flags, and offline sync. Ships as source; runs on any bundler (Vite, Next, esbuild, Bun, Deno) and on Node ≥22.6 native type-stripping.
