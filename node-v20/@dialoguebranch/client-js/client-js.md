# @dialoguebranch/client-js

> 标签: JavaScript

## 简介

JavaScript client for a Dialogue Branch Web Service — DialogueBranchClient for playback (the default export), DialogueBranchAuthoringClient (./authoring) for project/dialogue authoring.
