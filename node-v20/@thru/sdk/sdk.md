# @thru/sdk

> 标签: abi, blockchain, risc-v, rpc, sdk, thru, typescript

## 简介

Open-source TypeScript SDK for the Thru RISC-V Layer-1 blockchain: typed RPC client, transaction builder, keys and crypto, protobufs, and ABI reflection.
