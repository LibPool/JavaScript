# @qrcommunication/viva-cloud-terminal-sdk

> 标签: api, cloud-terminal, ecr, eft-pos, payments, pos, sdk, typescript, viva, viva-wallet, vivapayments

## 简介

TypeScript SDK for the Viva Wallet Cloud Terminal API (merchant /ecr/v1/) — drive a physical EFT POS terminal: sale, pre-auth capture, refunds, sessions and polling. OAuth2 client_credentials.
