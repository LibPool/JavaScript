# @nswds/typescript-config

> 标签: nextjs, nsw-government, nswds, react, tsconfig, typescript, typescript-config

## 简介

Shared TypeScript configuration for the NSW Design System fleet: a base for libraries and scripts, a Next.js app config and a React library config.
