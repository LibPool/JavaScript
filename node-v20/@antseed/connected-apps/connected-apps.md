# @antseed/connected-apps

> 标签: JavaScript

## 简介

Connect local AI tools (Codex, Claude Code, OpenCode, Droid, pi, Zed, …) to the AntSeed buyer proxy by patching their own config files. Shared by the AntSeed CLI and desktop app
