# @sortofrad/dokt

> 标签: command-line-utilities, development-tools, docs, documentation, markdown

## 简介

Build documentation from Markdown that lives inside a repo. Navigate using Obsidian-style wikilinks, render Mermaid, and build or serve a static docs site.
