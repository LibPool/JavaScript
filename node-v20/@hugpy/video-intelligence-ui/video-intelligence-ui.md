# @hugpy/video-intelligence-ui

> 标签: JavaScript

## 简介

Video-intelligence console — sibling arm of media_intelligence_ui (Vite + Tailwind v4), served at /video. Four stations (image crop, audio crop, frames/models, generate) over the hugpy job bus. Dials the same-origin current-hugpy API (/api).
