# @genclass/runtime-model

> 标签: genclass, model, onnx, onnxruntime-web, runtime, wasm, webgpu

## 简介

The local decision model for @genclass/runtime: a 17M-parameter GenClass encoder (ONNX, int8 for WASM and fp16 for WebGPU), its tokenizer and calibration. Loaded by the runtime from jsDelivr, or self-hosted.
