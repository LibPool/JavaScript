# @adapttable/base-ui

> 标签: base-ui, data-table, datagrid, react, rtl, server-side-pagination, typescript, url-state

## 简介

Base UI adapter for AdaptTable — a batteries-included Base UI data table with sorting, filtering, URL state, selection, RTL, and dark mode.
