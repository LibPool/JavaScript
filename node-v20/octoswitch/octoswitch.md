# octoswitch

> 标签: agents, claude, codex, copilot, cursor, gemini, github, hermes, mcp, multi-account, windsurf

## 简介

One MCP server, every GitHub account. Routes each call to the right token for Claude, Cursor, Copilot, Codex, Gemini, Windsurf, Hermes and more.
