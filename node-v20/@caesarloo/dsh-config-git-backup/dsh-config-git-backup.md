# @caesarloo/dsh-config-git-backup

> 标签: backup, deepseek-harness, dsh, dsh-plugin, git, sync

## 简介

Backup/restore DSH config, custom skills and plugin sources against a local git repository, callable by the agent as the dsh_config_git_backup tool (backup = sync + git commit; restore = repo back to live sources).
