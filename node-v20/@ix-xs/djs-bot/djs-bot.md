# @ix-xs/djs-bot

> 标签: bot-framework, discord, discord-api, discord-bot, discord.js, esm, framework, interactions, slash-commands, typescript

## 简介

A TypeScript-first, production-ready framework for building Discord bots on top of discord.js. Typed slash commands, typed customId routing, auto intents, error boundaries, DI, plugins, jobs and a batteries-included CLI - with zero plumbing.
