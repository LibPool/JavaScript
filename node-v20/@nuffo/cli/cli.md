# @nuffo/cli

> 标签: ai-agents, claude-code, cursor, focus, hooks, mcp, model-context-protocol, nuffo, productivity, todo

## 简介

Connect Claude Code and Cursor to nuffo in one command: your agent saves ideas instead of chasing them, knows your three projects and today's three, and asks before starting a fourth.
