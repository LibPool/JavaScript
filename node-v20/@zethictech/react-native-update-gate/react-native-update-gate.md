# @zethictech/react-native-update-gate

> 标签: app-store, force-update, in-app-updates, play-core, play-store, react-native, update-prompt, version-check

## 简介

Beautiful, type-safe, server-driven force/suggest update gate for React Native. Uses Google Play's native immediate flow on Android; ships a polished animated modal on iOS.
