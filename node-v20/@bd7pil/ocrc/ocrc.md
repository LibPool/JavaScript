# @bd7pil/ocrc

> 标签: ai-agent, mobile, opencode, plugin, pwa, remote-control, remote-hosts, ssh, telegram

## 简介

Remote-control opencode from Telegram and a web PWA — live sessions, tool streams, approvals, SSH remote hosts, schedules. Plugin mode or standalone host.
