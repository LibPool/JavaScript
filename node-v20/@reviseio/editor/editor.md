# @reviseio/editor

> 标签: agent, ai, comments, document-editor, docx, react, redlines, rich-text-editor, tracked-changes, word, word-processor, yjs

## 简介

A word processor for React: DOCX in and out, real pagination, tracked changes, comments, collaboration, and agent tools. Free for evaluation, personal projects, and education.
