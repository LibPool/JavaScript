# @saastro/visual-editor-bridge

> 标签: bridge, iframe, postmessage, saastro, saastrocms, visual-editor

## 简介

Iframe postMessage bridge for the SaastroCMS visual editor. Ships an IIFE for inline HTML injection plus typed ESM exports for editor hosts.
