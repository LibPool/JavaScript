# @kivcode/plugin-seo

> 标签: kiv, page-builder, plugin, seo, visual-editor

## 简介

SEO plugin for Kiv — meta tags, Open Graph, canonical URLs, and sitemap priority driven by a KivDocument's page-level SeoMeta.
