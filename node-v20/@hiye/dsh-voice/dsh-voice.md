# @hiye/dsh-voice

> 标签: JavaScript

## 简介

Voice plugin for DeepSeek Harness (dual-face): cloud ASR (Doubao SAUC) + speechified TTS playback, mic button + TTS toggle in the web GUI. One package, one `dsh plugin add`.
