# @easy-web/swa

> 标签: 404, astro-integration, azure-static-web-apps, not-found, staticwebapp, swa

## 简介

AstroIntegration that merges a sentinel-marked staticwebapp.config.json slice for shared 404 handling on Azure Static Web Apps.
