# @mpcfintech/prompt-compass-sdk

> 标签: edge, guardrails, jailbreak, llm, on-device, pii, prompt, router

## 简介

On-device prompt router & firewall: keep simple prompts local, send hard ones to the cloud, block PII/jailbreaks — 0.57 MB, ~ms, offline. Licensed per app.
