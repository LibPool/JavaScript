# opencode-quill

> 标签: autocomplete, autosuggest, ngram, opencode, opencode-plugin, opencode-tui, prompt, tui, word-prediction

## 简介

OpenCode prompt autocomplete: local n-gram word and next-word prediction shown as inline ghost text in the TUI composer, accepted with Tab.
