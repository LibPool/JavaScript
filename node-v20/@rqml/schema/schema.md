# @rqml/schema

> 标签: requirements, rqml, schema, xsd

## 简介

Canonical RQML XSD schemas (the single source of truth), example documents, and the AGENTS.md template, with a typed version resolver. Schema text is inlined for offline, bundler-friendly consumption.
