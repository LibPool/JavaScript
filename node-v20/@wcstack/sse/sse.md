# @wcstack/sse

> 标签: custom-elements, declarative, eventsource, framework-agnostic, real-time, server-sent-events, sse, streaming, wc-bindable, web-components, zero-dependencies

## 简介

Declarative Server-Sent Events (EventSource) component for Web Components. Framework-agnostic one-way streaming via wc-bindable-protocol.
