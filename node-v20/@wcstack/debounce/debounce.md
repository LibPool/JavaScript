# @wcstack/debounce

> 标签: custom-elements, debounce, declarative, framework-agnostic, rate-limit, throttle, wc-bindable, web-components, zero-dependencies

## 简介

Declarative debounce/throttle components for Web Components. Framework-agnostic signal coalescing via wc-bindable-protocol.
