# @wcstack/idle

> 标签: custom-elements, declarative, framework-agnostic, idle-detection, presence, wc-bindable, web-components, zero-dependencies

## 简介

Declarative Idle Detection component for Web Components. Framework-agnostic IdleDetector wrapper via wc-bindable-protocol.
