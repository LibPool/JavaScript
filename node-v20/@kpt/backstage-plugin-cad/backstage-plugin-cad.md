# @kpt/backstage-plugin-cad

> 标签: JavaScript

## 简介

Welcome to the Configuration as Data plugin! This plugin powers the WYSIWYG Configuration GUI over GitOps using [kpt](https://kpt.dev/) and its new Package Orchestrator, [porch](https://github.com/GoogleContainerTools/kpt/tree/main/porch).
