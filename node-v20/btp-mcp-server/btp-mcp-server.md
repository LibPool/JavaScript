# btp-mcp-server

> 标签: btp, cf, claude, cloud-foundry, mcp, model-context-protocol, sap

## 简介

MCP server for the Cloud Foundry V3 API on SAP BTP. Runs locally over stdio using your cf CLI login, or hosted on BTP.
