# @wrux/astro-datastar

> 标签: astro, astro-integration, datastar, hypermedia, sse

## 简介

Astro integration for Datastar (vendored v1.0.2 bundle) implementing the Datastar SDK spec: ServerSentEventGenerator, readSignals, plus Astro endpoint helpers and a replace-url plugin
