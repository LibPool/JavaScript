# sidera-ui

> 标签: JavaScript

## 简介

Dense, utilitarian, formally restrained design system and component kit built with **React 19**, **TypeScript**, **Tailwind CSS v4**, and **Radix UI Primitives**, deployable directly to **Cloudflare Workers**.
