# @xanots/sdk

> 标签: deploy, ephemeral, infrastructure-as-code, preview-environments, sdk, typescript, xano, xanots

## 简介

XanoTS — your Xano backend as TypeScript. `xanots deploy` ships your typed workspace (and an optional static frontend) to a live, auto-expiring ephemeral environment and prints its URL. init → deploy → URL.
