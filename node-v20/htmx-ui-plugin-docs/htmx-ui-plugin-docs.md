# htmx-ui-plugin-docs

> 标签: ai-agents, docs, documentation, htmx, htmx-ui, htmx-ui-plugin, llms.txt, markdown, sitemap

## 简介

Docs for htmx-ui-engine sites that people and AI agents can both read: heading anchors, Markdown for every page, llms.txt, JSON and XML sitemaps, docs navigation and page macros.
