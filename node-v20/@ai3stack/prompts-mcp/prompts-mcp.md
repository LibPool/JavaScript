# @ai3stack/prompts-mcp

> 标签: ai, ai3, chatgpt, claude, claude-desktop, cline, cursor, mcp, model-context-protocol, prompt-engineering, prompt-library, prompts

## 简介

MCP server exposing 930+ structured, expert-curated English AI prompts from the AI³ Prompt Dictionary. Plug into Claude, ChatGPT, Gemini, Copilot, Cursor, Cline, and any MCP-capable AI client.
