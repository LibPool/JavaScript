# @dsgraph/mcp

> 标签: design-system, design-tokens, dtcg, mcp, model-context-protocol

## 简介

MCP server for design tokens: find the token for a value, read a token with its references, compare versions, run checks. DTCG, token JSON and CSS; folders, npm and GitHub.
