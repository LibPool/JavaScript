# @linuxsuren/smart-chat

> 标签: chat, deepseek-harness, dsh, mcp

## 简介

Minimal MCP-driven AI chat web tool for DeepSeek Harness: a single-file chat page over plain REST+SSE, bridged to the dsh agent loop; every tool comes from MCP servers.
