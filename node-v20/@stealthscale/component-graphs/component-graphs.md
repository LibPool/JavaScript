# @stealthscale/component-graphs

> 标签: components, d3-force, dagre, graphs, react, react-flow

## 简介

Renders node graphs over React Flow: a canvas of named nodes and ports, removable edges, zoom controls, a minimap, and layouts by rank or by force.
