# @reqport/cli

> 标签: auth.002, cli, iso20022, mcp, reqport, responder

## 简介

Reqport responder CLI + MCP server — discover, read, and answer content-blind data requests (e.g. Engagemangskontroll / business-relationship checks) with an rqk_live_ API key.
