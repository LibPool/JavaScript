# @drscrewdriver/dsh-tidychat

> 标签: conversation, deepseek-harness, dsh, fold, navigator, plugin, timeline

## 简介

DSH Web 会话时间线整理：已完成轮次自动折叠（只留最终结论）+ 过程/结论分隔线 + 边缘导航消息轨（左右贴边、横线/圆点）+ 智能加载更早历史；0.1.2+ 可用「接管官方消息轨」开关替代官方右缘 TurnNavigator。设置面走 DSH 0.1.7 声明式 volatile 字段（自动成表），仅支持 0.1.7-rc.1+ 宿主。
