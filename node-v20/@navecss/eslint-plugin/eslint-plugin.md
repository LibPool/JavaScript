# @navecss/eslint-plugin

> 标签: css, design-system, eslint, eslint-plugin, eslintplugin, jsx

## 简介

Nave's ESLint plugin: closes the JSX className/style escape hatches a consumer's own lint does not see, with every deliberate escape declared, reasoned and countable.
