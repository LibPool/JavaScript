# @keypro/cli

> 标签: b2b, cli, keypro, license, mcp

## 简介

KeyPro.hu B2B szoftverlicenc webshop CLI: rendeles leadas, rendelesek/szamlak/termekkulcsok lekerdezese, profil kezeles. AI-ugynok (ChatGPT, Claude, Gemini, Codex, OpenCode) barat: --json kimenet es beepitett MCP szerver (keypro mcp).
