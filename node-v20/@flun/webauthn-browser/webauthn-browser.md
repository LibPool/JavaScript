# @flun/webauthn-browser

> 标签: fido, passkeys, typescript, umd, webauthn

## 简介

WebAuthn 前端库,提供简单易用的接口来处理 WebAuthn 认证流程,支持 Passkeys 和 FIDO2 标准;
