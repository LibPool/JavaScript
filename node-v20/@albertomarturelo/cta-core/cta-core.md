# @albertomarturelo/cta-core

> 标签: banco, bank, bci, cartola, chile, core, read-only

## 简介

Shared core for reading your own Chilean bank accounts: domain, tasks, seams and bank drivers. Side effects are injected via seams; Node adapters live behind the ./node subpath (ADR-003).
