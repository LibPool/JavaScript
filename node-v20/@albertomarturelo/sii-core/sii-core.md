# @albertomarturelo/sii-core

> 标签: JavaScript

## 简介

Shared SII domain core: rut, config (prod hostnames), contracts, tasks, seams. A Node library; external side-effects (portal, secrets, audit, clock) are injected via seams (ADR-003).
