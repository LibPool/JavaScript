# @chironbuilder/ootle-sdk

> 标签: blockchain, ootle, tari, wallet, web3

## 简介

Shared TypeScript client for Tari Ootle (L2): account derivation, balances, transactions, HTLCs, and stealth/confidential transfers — the account core behind Sapient and the Tari L1 web wallet's Ootle support.
