# oajax.js

> 标签: ajax, background-sync, capacitor, cordova, fetch, jquery, offline, offline-first, outbox, pwa

## 简介

Offline-first requests on top of fetch: reads fall back to a cached copy when the network fails, writes go to a persisted, ordered outbox and replay with idempotency keys when the connection returns. Zero dependencies; optional jQuery-style $oajax wrapper
