# @shop-on/theme-dev-host

> 标签: JavaScript

## 简介

Local theme-editor dev server: serves the editor contract + proxies a theme's dev server behind one origin, so a theme runs locally and previews in a real admin theme-editor. Nucleus of the future theme CLI.
