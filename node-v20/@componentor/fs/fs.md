# @componentor/fs

> 标签: async, browser-filesystem, browser-storage, file-api, filesystem, fs, in-browser, isomorphic-git, node-fs, opfs, origin-private-file-system, polyfill, readfilesync, shared-array-buffer, shim, storage, sync, sync-fs, typescript, vfs, virtual-filesystem, web-ide, web-worker, writefilesync

## 简介

Node's fs in the browser, including a real synchronous readFileSync/writeFileSync, stored in OPFS. Handles the workers, cross-tab locking and encodings for you.
