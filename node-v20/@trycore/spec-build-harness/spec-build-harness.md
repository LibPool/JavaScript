# @trycore/spec-build-harness

> 标签: agentic, build-harness, claude-code, gitflow, openspec, quality-gates, release-gate, tdd, trycore, two-loop

## 简介

Arnés agéntico de construcción de Trycore para Claude Code: pipeline de dos loops (slice por épica + release gate) con gates de calidad, estado compartido y OpenSpec. Compañero de @trycore/spec-product-flow. Agnóstico al proyecto.
