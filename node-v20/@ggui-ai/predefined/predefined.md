# @ggui-ai/predefined

> 标签: blueprints, components, design-system, ggui, react, ui

## 简介

ggui's official reference component library — components, composites, and blueprints the UI generator consults on its predefined-match path. Pure data plus reference React TSX; no JavaScript entry point.
