# @ggui-ai/agent-runtime

> 标签: adapter, agent, agent-runtime, claude-agent-sdk, ggui

## 简介

Pluggable adapter seam for supervising whatever actually runs an agent — the Claude Agent SDK, OpenAI Agents, the Vercel AI SDK, a plain subprocess, and more. Lets a host swap agent runtimes without hardcoding any framework into its dev loop.
