# @moocfi/exercise-iframe-host

> 标签: exercise-service, host, iframe, moocfi

## 简介

Host-side SDK for embedding moocfi exercise-service iframes: MessageChannelIFrame owns the sandboxed iframe, the MessagePort handshake, and the set-state/set-language protocol.
