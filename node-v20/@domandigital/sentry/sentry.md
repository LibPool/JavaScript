# @domandigital/sentry

> 标签: JavaScript

## 简介

One Sentry setup for every Doman Digital site: init options for the browser, Cloudflare Workers and Next.js (environment, release, PII scrubber, noise filters, sample rates), and a release and source-map CLI for Worker and Astro builds.
