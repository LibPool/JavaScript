# @tetherto/wdk-protocol-lending-aave-evm

> 标签: aave, erc-4337, ethereum, lending, protocol, wdk

## 简介

A simple package that lets @tetherto/wdk-wallet-evm and @tetherto/wdk-wallet-evm-erc-4337 wallet accounts interact with the aave protocol.
