# @tetherto/wdk-protocol-swap-velora-evm

> 标签: erc-4337, ethereum, paraswap, protocol, swap, wdk

## 简介

A simple package that lets @tetherto/wdk-wallet-evm and wallet-evm-erc-4337 wallet accounts interact with the velora protocol.
