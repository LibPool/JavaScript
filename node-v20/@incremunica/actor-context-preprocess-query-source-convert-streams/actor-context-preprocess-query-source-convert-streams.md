# @incremunica/actor-context-preprocess-query-source-convert-streams

> 标签: actor, actor-context-preprocess, incremunica, query-source-convert-streams

## 简介

A Context Preprocess actor that converts all streams in the query sources to AsyncIterators and puts them in an object.
