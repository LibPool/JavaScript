# @0xyph3r/concise

> 标签: agent-skills, ai-agent, claude-code, claude-code-plugin

## 简介

Cuts prose filler from Claude Code responses while leaving code, analysis depth, and correctness untouched. Shows a live per-response prose-budget bar in the statusline.
