# @companydata/companies-house-api

> 标签: b2b-data, business-register, companies-house, companies-house-api, company-data, company-number, company-search, sdk, typescript, uk, united-kingdom

## 简介

Companies House API wrapper: UK company data from the Companies House register with full addresses, phone, email, website and firmographics, through one REST call. A thin layer over @companydata/companydata-sdk, pinned to GB.
