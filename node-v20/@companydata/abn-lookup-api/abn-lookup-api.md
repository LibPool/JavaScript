# @companydata/abn-lookup-api

> 标签: abn, abn-lookup, abn-lookup-api, abr, acn, australia, australian, b2b-data, business-register, company-data, company-search, sdk, typescript

## 简介

ABR API wrapper: Australian company data from the Australian Business Register (ABN Lookup) with full addresses, phone, email, website and firmographics, through one REST call. A thin layer over @companydata/companydata-sdk, pinned to AU.
