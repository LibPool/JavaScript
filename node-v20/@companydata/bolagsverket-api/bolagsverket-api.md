# @companydata/bolagsverket-api

> 标签: b2b-data, bolagsverket, bolagsverket-api, business-register, company-data, company-search, foretag, organisationsnummer, sdk, sweden, swedish, typescript

## 简介

Bolagsverket API wrapper: Swedish company data from the Bolagsverket register with full addresses, phone, email, website and firmographics, through one REST call. A thin layer over @companydata/companydata-sdk, pinned to SE.
