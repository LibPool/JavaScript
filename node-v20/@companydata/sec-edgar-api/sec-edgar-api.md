# @companydata/sec-edgar-api

> 标签: b2b-data, business-register, cik, company-data, company-search, edgar, sdk, sec-edgar, sec-edgar-api, secretary-of-state, typescript, united-states, usa

## 简介

SEC EDGAR API wrapper: US company data from state registers and SEC EDGAR with full addresses, phone, email, website and firmographics, through one REST call. A thin layer over @companydata/companydata-sdk, pinned to US.
