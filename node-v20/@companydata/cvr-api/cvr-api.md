# @companydata/cvr-api

> 标签: b2b-data, business-register, company-data, company-search, cvr, cvr-api, cvr-nummer, danish, denmark, sdk, typescript, virk, virksomheder

## 简介

CVR API wrapper: Danish company data from the CVR (Central Business Register) with full addresses, phone, email, website and firmographics, through one REST call. A thin layer over @companydata/companydata-sdk, pinned to DK.
