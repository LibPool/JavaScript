# @companydata/kbo-api

> 标签: b2b-data, bce, belgian, belgium, business-register, company-data, company-search, crossroads-bank, kbo, kbo-api, ondernemingsnummer, sdk, typescript

## 简介

KBO/BCE API wrapper: Belgian company data from the KBO/BCE (Crossroads Bank for Enterprises) with full addresses, phone, email, website and firmographics, through one REST call. A thin layer over @companydata/companydata-sdk, pinned to BE.
