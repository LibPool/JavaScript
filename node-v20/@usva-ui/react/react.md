# @usva-ui/react

> 标签: accessible, component-library, dark-mode, design-system, design-tokens, react, registry, rsc, shadcn, shadcn-ui, tailwind, tailwind-v4, tailwindcss, theming, typescript, ui-components, usva, webgl

## 简介

A React design language in three themes: kajo is atmospheric and dark, sisu is dense and quick, savi is the light ground. One token vocabulary under all three.
