# @gbeata/mapping

> 标签: JavaScript

## 简介

- <InitStage />   props所有的值先尽可能得枚举出来: - size: {width: number, width: number} - boundary: 地图边界 传值: [   minX,   maxY,   maxX,   maxY,   maxX,   minY,   minX,   minY,   minX,   maxY,   ], 不传的话会遍历所有的点得出边界值 - boundaryVisible: 是否显示地图边界 - boundaryProps: React-ko
