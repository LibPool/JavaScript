# semantic-arkiv

> 标签: JavaScript

## 简介

Deterministic semantic resolution layer for Arkiv queries. Compiles the live on-chain Arkiv vocabulary into a validated ontology and serves it as an MCP tool that emits grammar-correct Arkiv filter expressions.
