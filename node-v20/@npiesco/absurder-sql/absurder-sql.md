# @npiesco/absurder-sql

> 标签: browser-database, database, indexeddb, offline-first, persistent-storage, rust, sql, sqlite, wasm, webassembly

## 简介

High-performance SQLite for browsers with IndexedDB or Hybrid OPFS persistence, export/import, multi-tab coordination, and a production offline PWA.
