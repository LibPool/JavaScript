# @streetjs/diagnostics

> 标签: diagnostics, error-reporting, esm, observability, stack-trace, street-framework, streetjs, structured-logging, typescript, zero-dependencies

## 简介

StreetJS structured diagnostics reporter: serializes errors into clean JSON DiagnosticEvents on stderr, strips Node-internal stack frames, and emits a 'diagnostic' event. Zero runtime dependencies.
