# @streetjs/search

> 标签: facets, full-text-search, postgresql, search, street, street-framework, streetjs

## 简介

Official Street Framework search module: a provider-based search API (indexing, ranking, filters, facets, suggestions) with an in-memory default and a PostgreSQL full-text-search adapter.
