# @streetjs/client-offline

> 标签: cache, client, esm, offline, offline-first, outbox, street-framework, streetjs, sync, typescript

## 简介

StreetJS offline support for client apps: a read-through cache with TTL and a persistent, ordered mutation outbox with retry/backoff and online/offline flushing. Transport-agnostic and storage-pluggable; zero runtime dependencies.
