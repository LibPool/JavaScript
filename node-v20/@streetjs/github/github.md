# @streetjs/github

> 标签: connector, esm, github, integration, issues, pull-request, street-framework, streetjs, typescript, webhook

## 简介

StreetJS GitHub connector: a typed GitHub REST API client (issues, comments, pull requests, releases, workflow/repository dispatch) built on @streetjs/integrations, plus X-Hub-Signature-256 webhook verification for inbound events.
