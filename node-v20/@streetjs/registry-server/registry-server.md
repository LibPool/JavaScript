# @streetjs/registry-server

> 标签: ed25519, plugin-registry, registry, signed-plugins, street, streetjs

## 简介

Street Framework Network Plugin Registry server: secure publish/download/verify/search/list/versions REST API over /api/v1, built on @streetjs/core signing primitives.
