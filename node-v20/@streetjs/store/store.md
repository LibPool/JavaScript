# @streetjs/store

> 标签: abuse-prevention, counter, esm, in-memory, key-value-store, rate-limit, sliding-window, street-framework, streetjs, typescript, zero-dependencies

## 简介

StreetJS backing-store abstractions: pluggable KeyValueStore, CounterStore, and RateLimitStore interfaces with deterministic, clock-injectable in-memory sliding-window implementations for rate limiting and abuse counters. Zero runtime dependencies.
