# @navid.kianfar/node-bundle

> 标签: bundle, bytecode, nodejs, obfuscate, pkg, protect, single-executable

## 简介

Bundle & protect a Node.js app into a single self-contained, bytecode-compiled executable, per CPU architecture (amd64/arm64).
