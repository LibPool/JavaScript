# @liiift-studio/sanity-font-manager

> 标签: collections, css-generation, font, font-conversion, font-management, font-manager, font-upload, sanity, sanity-plugin, sanity-studio, typeface, variable-font, woff2

## 简介

Sanity Studio plugin — full font management suite with batch upload, format conversion, metadata extraction, CSS generation, collection/pair generation, and script variant support. Supports Sanity Studio v3 through v6.
