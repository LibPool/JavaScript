# @wowoengine/sawitdb

> 标签: agricultural, btree, database, database-binary, database-client, database-embedded, database-engine, database-file, database-local, database-remote, database-server, database-single-file, document-database, embedded-database, indexing, indonesian, json, mongodb-like, networking, nosql, sawitdb, tcp-server, wowoengine, wowoengine/sawitdb

## 简介

A high-performance hybrid paged database with Agricultural Query Language (AQL) and Generic SQL support. Features single-file storage (.sawit), object caching, worker-thread parallelism, and crash recovery.
