# @xterm/addon-canvas

> 标签: canvas, terminal, xterm, xterm.js

## 简介

An addon for [xterm.js](https://github.com/xtermjs/xterm.js) that enables a canvas-based renderer using a 2d context to draw. This addon requires xterm.js v5+.
