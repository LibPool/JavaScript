# @mcbeutils/claimapi

> 标签: JavaScript

## 简介

ClaimAPI is a [BeAPI](https://github.com/MCBE-Utilities/BeAPI) module that allows players to create claimed boundaries so that untrusted players can not interact with that claimed land.
