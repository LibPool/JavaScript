# @deftship/mcp

> 标签: carrier, deftship, freight, logistics, mcp, model-context-protocol, parcel, shipping

## 简介

Model Context Protocol server for the Deftship multi-carrier shipping API. Quote, ship, track, void and manage parcel, freight, pickup, insurance and batch shipments from any MCP client.
