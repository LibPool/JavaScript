# @cgvweb/ui

> 标签: JavaScript

## 简介

A set of reusable components for Nuxt 3 heavily inspired by [`@nuxt/ui`](https://ui.nuxt.com) and [`shadcn-vue`](https://www.shadcn-vue.com).
