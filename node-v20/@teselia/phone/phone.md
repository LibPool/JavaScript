# @teselia/phone

> 标签: a11y, accessibility, custom-element, e164, international, phone, phone-input, tel, vue, wcag, web-component

## 简介

Accessible international phone input with country calling code, shipped as a framework-agnostic Web Component. WCAG 2.2 AA by default.
