# @blockialabs/ssi-did

> 标签: blockchain, cryptography, decentralized-identity, did, did-core, did-methods, did-resolution, ssi, typescript, w3c

## 简介

Professional TypeScript SDK for universal DID operations supporting multiple methods (did:key, did:web). W3C DID Core 1.0 compliant with registry-based architecture.
