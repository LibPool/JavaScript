# @sperax/tool-name-service

> 标签: agent-tools, ai-agent, defi, function-calling, llm-tools, sperax, sperax-name-service, speraxos, tool-calling, web3

## 简介

Resolve Web3 names to addresses and back — ENS (.eth), SNS (.sol) and Space ID (.bnb, .arb), across Ethereum, Solana, BNB Chain and Arbitrum. — an agent tool for SperaxOS.
