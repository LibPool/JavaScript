# h5-miao

> 标签: JavaScript

## 简介

1. 注册 npm 账号 2. 将源切换至 npm(使用 nrm 淘宝镜像的需要切换) $ nrm use npm 3. 完成项目初始化 $ npm init 4. 创建入口文件 5. 开发 6. 登录 npm 账号 `$ npm adduser` 7. 发布 `$ npm publish`
