# haip

> 标签: JavaScript

## 简介

The Human‑Agent Interaction Protocol (HAIP) is an open standard that streamlines real‑time, multi‑modal exchanges between user‑facing applications and AI agents. It complements the Model Context Protocol (MCP) by concentrating on the human‑agent layer.
