# headsign

> 标签: agy, antigravity, claude-code, cli, codex, coding-agent, graph-engineering, loop-engineering, phase-gate, state-machine, workflow

## 简介

A tiny phase gate for coding agents. Ask it what's next; it runs deterministic checks and tells the loop where to go.
