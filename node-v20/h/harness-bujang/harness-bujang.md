# harness-bujang

> 标签: agents, anthropic, bujang, claude, claude-code, harness, init, korean, multi-agent, orchestration, scaffold, subagent

## 简介

Install the Harness-Bujang multi-agent harness into any project — Director, 16 specialist teams, standalone localhost chat-room viewer. Korean and English personas. Works with Claude Code, Cursor, Cline, Aider, Codex, Gemini, or any tool that reads .claud
