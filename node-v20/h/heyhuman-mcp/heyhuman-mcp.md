# heyhuman-mcp

> 标签: ai-agents, claude, mcp, model-context-protocol, reminders, todo

## 简介

HeyHuman MCP connector — let Claude (or any MCP client) capture todos into HeyHuman and remind you until they are done. Thin HTTP client for the hosted API; no database required.
