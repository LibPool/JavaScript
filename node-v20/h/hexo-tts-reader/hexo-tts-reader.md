# hexo-tts-reader

> 标签: accessibility, audio, edge-tts, hexo, hexo-plugin, reader, text-to-speech, tts

## 简介

A Hexo plugin that reads your posts aloud. Builds MP3 audio for each post at generate-time using Edge TTS, and injects a floating player into post pages.
