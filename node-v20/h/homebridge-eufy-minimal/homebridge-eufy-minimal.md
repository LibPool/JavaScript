# homebridge-eufy-minimal

> 标签: eufy, homebridge, homebridge-plugin, robovac, tuya, vacuum

## 简介

A lightweight Homebridge plugin to control Eufy RoboVac via Tuya local commands using a simple HomeKit switch.
