# harness-restart-button

> 标签: button, client-plugin, cordis, deepseek, deepseek-harness, dsh, dsh-plugin, relaunch, restart

## 简介

DeepSeek Harness 重启按钮插件：窗口顶部「应用/编辑」标题栏菜单里、以及每个插件详情页顶部各一个重启入口，确认后关闭并重新拉起应用，让「下次启动生效」的插件与配置改动立刻起作用。 / A DeepSeek Harness plugin that puts one restart control beside the window caption menu and one on every plugin detail page: it closes and relaunches the ap
