# hermes-zalo-plugin

> 标签: bridge, chatbot, gateway, hermes, hermes-agent, messaging, zalo, zca-js

## 简介

Connect a personal Zalo account to the Hermes Agent gateway via zca-js (unofficial Zalo API). SSE inbound + REST outbound. Cross-platform (macOS, Linux, Windows).
