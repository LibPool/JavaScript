# harmar-ai

> 标签: armenian, captions, cli, mcp, speech-to-text, srt, subtitles, transcription, vtt

## 简介

Harmar subtitle API for agents and scripts — CLI, MCP server and typed client. Word-timed transcripts, SRT/VTT and styled captioned videos for Armenian, Russian, English and 50+ more languages, code-switching included.
