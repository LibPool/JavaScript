# hyperwave-engine

> 标签: JavaScript

## 简介

HyperWave engine: permissionless P2P coordinated-round primitive over Hyperswarm/Hypercore — deterministic ring sweep + per-wave multicore CRDT feed, payment-agnostic, host-agnostic, runs under Bare.
