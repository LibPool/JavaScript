# homebridge-boxzilla

> 标签: battery, boxzilla, contact-sensor, homebridge, homebridge-plugin, lora, mailbox

## 简介

Homebridge plugin for Boxzilla LoRa mailbox notifier. Exposes mail contact sensor with battery status via HTTP polling.
