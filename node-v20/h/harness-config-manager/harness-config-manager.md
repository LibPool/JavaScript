# harness-config-manager

> 标签: agents, claude-code, cli, github-copilot, mcp, opencode, pi, reasonix, skills

## 简介

Define agents, skills, commands, rules and MCP servers once; install them into Claude Code, GitHub Copilot, Reasonix, OpenCode and Pi with exact, item-level rollback.
