# hooddomains

> 标签: domains, ens, hood, robinhood-chain, sdk, viem, web3

## 简介

TypeScript SDK for Hood Domains — resolve, look up, and register .hood names on Robinhood Chain. All on-chain, no backend.

## 官网

- 官网：https://www.hood.domains
- 源码仓库：git+https://github.com/Hooddomains/hoodsdk.git
- npm 页面：https://www.npmjs.com/package/hooddomains
