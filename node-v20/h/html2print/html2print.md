# html2print

> 标签: electron, escpos, html, node, pdf, pos, print, printer, thermal

## 简介

A Node.js module for printing HTML directly, specifically designed for POS printers and Electron applications. It utilizes wkhtmltopdf to convert HTML to PDF and pdf-to-printer to send the PDF to the printer without requiring user intervention or saving t
