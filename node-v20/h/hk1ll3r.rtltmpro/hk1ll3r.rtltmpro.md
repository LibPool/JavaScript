# hk1ll3r.rtltmpro

> 标签: Arabic, Farsi, Persian, RTL, Right-To-Left, TMPro, TextMeshPro

## 简介

This plugin adds Right-to-left language support to TextMeshPro Unity package. You need to have TextMeshPro plugin in your project.
