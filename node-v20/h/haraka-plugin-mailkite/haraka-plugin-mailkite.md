# haraka-plugin-mailkite

> 标签: email, email-api, haraka, haraka-plugin, inbound-email, mailkite, mx, smtp, webhook

## 简介

Connect an existing Haraka MX or submission server to a MailKite-contract backend (MailKite Cloud or self-hosted api-local): inbound mail as signed webhooks, anti-open-relay RCPT checks, SMTP AUTH + relay.
