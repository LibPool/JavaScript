# hirunews-scrap

> 标签: hiru, hirunews, hirunews-api, hirunews-scrap, news

## 简介

An unofficial Node.js package for scraping latest news from Hiru News (hirunews.lk). Supports breaking news, trending, sports, entertainment and more.
