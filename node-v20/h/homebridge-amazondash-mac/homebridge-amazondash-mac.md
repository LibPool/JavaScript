# homebridge-amazondash-mac

> 标签: Amazon-Dash, Apple-Home, HomeKit, StatelessProgrammableSwitch, button, homebridge-plugin

## 简介

A modern (post-2019) Homebridge-verified Amazon Dash plugin for Homebridge. Requires elevated privileges to configure and a WiFi device in monitor mode.
