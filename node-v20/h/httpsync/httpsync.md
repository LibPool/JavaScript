# httpsync

> 标签: curl, http, sync

## 简介

`httpsync` is a port of libcurl to node.js. Its interface emulates the  `http` module of node.js. But in contrast to `http` module's asynchronous functions, `httpsync` provides the equivalent synchronous APIs.
