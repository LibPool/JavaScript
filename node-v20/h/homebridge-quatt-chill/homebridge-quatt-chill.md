# homebridge-quatt-chill

> 标签: air-conditioning, airco, chill, heatercooler, homebridge-plugin, homekit, quatt

## 简介

Homebridge 2.0 plugin to control the Quatt Chill airco from Apple HomeKit (via the Quatt cloud mobile API).
