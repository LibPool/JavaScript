# hivexph-sdk

> 标签: blockchain, custom_json, hive, hive-engine, keychain, sdk

## 简介

TypeScript SDK for Hive Custom JSON: configuration, backend signing, Hive Keychain, Hive Engine token/NFT issuers, block streaming, payments and transaction reading.
