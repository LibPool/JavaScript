# homebridge-rotel-arkku

> 标签: homebridge, homebridge-plugin, rotel

## 简介

Homebridge module to control Rotel A14 amplifier over telnet. This is a fork of a plugin developed by arkku found on github. There's no config compatible with homebridge UI, any changes must be made inside index.js file.
