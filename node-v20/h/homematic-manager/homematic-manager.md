# homematic-manager

> 标签: ccu, ccu3, homegear, homematic, homematicip, openccu, raspberrymatic, smarthome, xmlrpc

## 简介

Configure and administer Homematic and HomematicIP devices - devices and channels, direct links, paramsets, RSSI, service messages, events and an RPC console - from a local HTTP/WebSocket server that also serves the web UI
