# homebridge-oasis-mini

> 标签: homebridge-plugin, kinetic-sand, oasis, oasis-mini, sand-table

## 简介

Homebridge plugin for Oasis Mini kinetic sand tables — power, play/pause, LED color and effects via HomeKit and Siri. Supports multiple tables.
