# hi3d-cli

> 标签: 3d-generation, 3mf, agent-skill, cli, fbx, glb, hi3d, hi3d.ai, hitem3d, image-to-3d, obj, stl

## 简介

CLI tool and AI Agent skill for Hi3D API (hitem3d.ai): generate 3D models (GLB, OBJ, STL, FBX, USDZ, 3MF) from images, reliefs, model splitting, and multicolor
