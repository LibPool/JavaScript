# hyper-http

> 标签: api, http, middlewares, node, response

## 简介

We present a simple HTTP server framework using the native Node.js http module. It's designed to work with TypeScript decorators that you shared earlier. It's a simplified, lighter version of Express or Koa with a decorator-based approach like NestJS.
