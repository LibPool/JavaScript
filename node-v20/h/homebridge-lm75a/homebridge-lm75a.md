# homebridge-lm75a

> 标签: homebridge, homebridge-plugin, homekit, lm75, pi

## 简介

A Temperature plugin for [HomeBridge](https://github.com/nfarina/homebridge) to read from an [LM75A](http://www.ti.com/product/LM75A) sensor.
