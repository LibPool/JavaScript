# humanize-string

> 标签: camelcase, capitalize, case, convert, dash, human, humanize, hyphen, pretty, string, text, underscore, uppercase

## 简介

Convert a camelized/dasherized/underscored string into a humanized one: `fooBar-Baz_Faz` → `Foo bar baz faz`
