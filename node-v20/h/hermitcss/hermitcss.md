# hermitcss

> 标签: cascade-layer, css, hcss, hermitcss, vite

## 简介

HermitCSS — light-DOM authoring as *.hcss (CSS syntax) plus optional @define preprocessing; cascade layers beat legacy specificity when non-Hermit CSS lives in @layer.
