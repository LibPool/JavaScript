# homebridge-simplisafe-alarmdecoder-bridge

> 标签: alarmdecoder, homebridge, homebridge-plugin, security, simplisafe, vista

## 简介

Homebridge platform plugin that bidirectionally bridges SimpliSafe3 HomeKit state changes to an AlarmDecoder/Vista 20P alarm panel.
