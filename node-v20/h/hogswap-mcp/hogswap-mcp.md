# hogswap-mcp

> 标签: ai-agents, algorand, dex, hogswap, mcp, model-context-protocol, payments, swap, x402

## 简介

HOGSWAP MCP server - quotes, swap builds, and pay-any-x402-invoice tools for AI agents on Algorand. Non-custodial: returns unsigned transactions only.
