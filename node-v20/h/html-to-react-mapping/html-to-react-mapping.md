# html-to-react-mapping

> 标签: JavaScript

## 简介

This library can be used to parse raw HTML to React components, and it's a wrapper on top of the `html-react-parser` library to make it plug-and-play. Useful when you receive raw HTMl from third party services (like Greenhouse or Zendesk), and want to map
