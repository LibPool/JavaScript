# habeassafe-mcp

## 简介

Servidor MCP (Model Context Protocol) de HabeasSafe — anonimización reversible y des-identificación de documentos judiciales colombianos (tutelas, providencias, radicados, cédulas) con supervisión humana (Acuerdo PCSJA24-12243, numeral 3.9 y Sentencia T-3
