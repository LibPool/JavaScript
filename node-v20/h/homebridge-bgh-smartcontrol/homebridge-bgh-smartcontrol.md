# homebridge-bgh-smartcontrol

> 标签: air-conditioner, bgh, homebridge-plugin, hvac, smart-control, solidmation, supports-hap

## 简介

Unofficial local-network Homebridge plugin for BGH/Solidmation Smart Control home-automation hubs (reverse-engineered HACommand UDP protocol).
