# hockey-line-cli

> 标签: ai-agent, cli, hockey, league, llm, mcp, pointstreak, schedule, sports, standings

## 简介

Agent-friendly CLI for Hockey Line Leagues — run a rink's hockey leagues (seasons, teams, rosters, schedules, scores, standings) from the terminal or an AI agent. JSON in, JSON out.
