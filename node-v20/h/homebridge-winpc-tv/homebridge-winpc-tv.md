# homebridge-winpc-tv

> 标签: airytec, homebridge-plugin, television, wake-on-lan, windows, wol

## 简介

Exposes a Windows PC as a single HomeKit Television accessory: turns it on with Wake-on-LAN and off/status via Airytec Switch Off's web interface. No separate helper script needed.
