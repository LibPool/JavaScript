# hook-fn

> 标签: decorator, function, function decorator, function hook, function hookable, function hookable decorator, function hookable decorator typescript, hook, hookable, javascript, typescript

## 简介

A library which provides pre-execution and post-execution hooks both as a decorator and as a higher-order function.
