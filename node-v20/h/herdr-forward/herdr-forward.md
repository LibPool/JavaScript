# herdr-forward

> 标签: cli, cloudflared, herdr, port-forwarding, ssh, terminal, tunnel

## 简介

Port forwarding for herdr saved SSH machines — forward remote TCP ports to localhost (ssh -L) and optionally publish local ports to the public internet (Cloudflare quick tunnel). The herdr plugin itself installs from GitHub: herdr plugin install zzjcool/h
