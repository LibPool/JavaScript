# h11-x

> 标签: JavaScript

## 简介

SSR/гидрация поверх [`h11`](../h11) + Vite + [regan](https://www.npmjs.com/package/regan). Экспериментальный, активно меняющийся слой (версия `0.0.x`) — рабочий пример смотри в [`h11-x-example`](../h11-x-example).
