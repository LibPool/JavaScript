# homebridge-somfy-remote

> 标签: blinds, homebridge-plugin, homekit, raspberry-pi, somfy

## 简介

Homebridge plugin that exposes a Pi-attached Somfy Telis 4 remote as HomeKit WindowCovering accessories.
