# homebridge-button-platform-22

> 标签: button, flic, homebridge-plugin, http, shelley, stream deck, virtual button

## 简介

A Homebridge platform plugin (for Node v22+) to create virtual buttons that respond to HTTP requests from things like Shelley, Flic or an Elgato Stream Deck
