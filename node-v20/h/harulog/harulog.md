# harulog

> 标签: JavaScript

## 简介

`harulog`는 Codex 대화 이력과 로컬 git 작업 흔적을 읽어서 글감과 초안을 추천하는 macOS용 CLI다. 배포 목표는 `bunx harulog ...` 한 줄로 어느 PC에서든 설정하고, `launchd`가 매주 금요일 오전 9시에 자동 실행되도록 만드는 것이다.
