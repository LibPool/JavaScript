# hedera-insights-mcp

> 标签: agentic-commerce, ai-agent, hbar, hedera, mcp, model-context-protocol, on-chain, x402

## 简介

MCP server that lets any AI agent buy Hedera on-chain intelligence over x402 — discovers the catalog, pays in HBAR, and returns verified data.
