# hexo-theme-hermes-agent

> 标签: blog, hexo, minimal, terminal, theme

## 简介

A Hexo theme inspired by the Nous Research Hermes Agent visual language: deep-teal phosphor-decay aesthetic, grid-framed panels, terminal-style chrome.
