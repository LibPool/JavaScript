# homebridge-oauth2-oidc

> 标签: authentication, authorization, homebridge, homebridge-plugin, oauth2, oidc, openid-connect

## 简介

A Homebridge platform plugin that provides native OAuth2 and OpenID Connect authentication support, enabling other plugins to authenticate against identity providers using standard flows.
