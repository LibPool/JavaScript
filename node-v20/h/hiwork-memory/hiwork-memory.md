# hiwork-memory

> 标签: JavaScript

## 简介

HiWork 记忆插件：接 TencentDB Agent Memory（memory-core /v3），给 Agent 提供只读记忆检索工具，并在桌面端提供记忆设置页。

- npm 页面：https://www.npmjs.com/package/hiwork-memory
