# homebridge-hue-motion-restore

> 标签: homebridge-plugin, homekit, motion-lighting, multi-zone-lighting, philips-hue, security-lighting, supports-hap

## 简介

MotionGuard for Hue: low-latency Homebridge motion lighting with live Hue state caching, parallel writes, clean Apple Home controls, and exact state restore.
