# hookmcp-mcp

> 标签: claude, cursor, directory, mcp, mcp-server, model-context-protocol, vscode

## 简介

Read-only MCP server to search the HookMCP directory of 800+ MCP servers and get ready-to-paste configs for Claude Desktop, Cursor, VS Code and Claude Code.
