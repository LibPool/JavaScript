# hubspot-multi-mcp

> 标签: claude, crm, hubspot, mcp, model-context-protocol, multi-account, multi-portal

## 简介

Local, read-only MCP server that connects Claude to MANY HubSpot portals at once, by name. Unofficial, not affiliated with HubSpot.
