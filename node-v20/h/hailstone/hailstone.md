# hailstone

> 标签: domain, embedded, entity, entityid, flake, global, hailstone, id, identifier, object, objectid, random, snow, snowflake, type, unique

## 简介

A simple, lightweight, stateless utility for generating quasi-unique, variable length identifiers with embedded type information.
