# homebridge-somfy-rts-shutters

> 标签: homebridge-plugin, rfxcom, rfxtrx, rts, shutters, somfy, supports-hap, volet-roulant, windowcovering

## 简介

Homebridge plugin exposing Somfy RTS roller shutters (via an RFXtrx433E dongle) as native HomeKit WindowCovering accessories. Converts the target position (%) into an up/down RTS command duration to simulate absolute positioning.
