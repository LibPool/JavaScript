# homebridge-git-backup

> 标签: backup, config, forgejo, git, github, gitlab, homebridge, homebridge-plugin, isomorphic-git

## 简介

Homebridge plugin that backs up your Homebridge configuration to any Git remote (GitHub, Forgejo, GitLab, self-hosted) on every change.
