# hydration-proof

> 标签: ci, cli, dom-diff, hydration, hydration-error, hydration-mismatch, next.js, nextjs, playwright, react, react-19, react-hydration, server-side-rendering, ssr, suppresshydrationwarning, testing

## 简介

Find, explain, reproduce and prevent React hydration mismatches before users see them. Compares real server HTML with the hydrated DOM in CI. Next.js, React 18 and 19. Adds nothing to your production bundle.
