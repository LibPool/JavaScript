# hudline

> 标签: agent, antigravity, claude-code, cli, codex, copilot-cli, qwen-code, status-line, statusline, tui

## 简介

Claude Code status line for context usage, remaining quota, and cumulative input/output tokens with cache-read and thinking shares. Customizable, zero dependencies.
