# html-overlay-node

> 标签: canvas, canvas-html-hybrid, data-flow, flow-based-programming, graph-editor, html-overlay, litegraph-alternative, node-editor, node-graph, rete-alternative, typescript, undo-redo, visual-node-editor, visual-programming, visual-scripting, workflow, zero-dependencies

## 简介

Zero-dependency visual node editor — Canvas rendering + HTML/CSS widget overlay. Data-flow graphs, workflow editors, visual scripting. Undo/redo, minimap, sub-graphs, TypeScript support.
