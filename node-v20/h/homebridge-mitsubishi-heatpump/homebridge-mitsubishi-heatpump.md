# homebridge-mitsubishi-heatpump

> 标签: heat-pump, heatercooler, homebridge-plugin, hvac, mini-split, mitsubishi, mlz, msz, supports-hap

## 简介

Homebridge plugin for Mitsubishi ductless heat pumps (MLZ/MSZ) over the Mitsubishi Comfort v3 API, with local LAN control, fan speed and vane control
