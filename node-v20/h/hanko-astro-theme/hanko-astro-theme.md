# hanko-astro-theme

> 标签: astro-theme, business, corporate, gsap, hanko, japanese, tailwindcss

## 简介

Hanko is a Japanese corporate Astro theme with seal motif branding, bento layouts, Tailwind v4 styling, and GSAP stamp animations.
