# hermes-claude-bridge

> 标签: claude, claude-agent-sdk, claude-code, hermes, hermes-agent, model-provider, openai-compatible

## 简介

Use Claude (via a Claude Code Pro/Max subscription) as a model provider for the Hermes agent — no ANTHROPIC_API_KEY. A local OpenAI-compatible bridge that drives the `claude -p` CLI.
