# hakolkal-tickets-mcp

> 标签: claude, hakolkal, mcp, tickets

## 简介

MCP server + one-command onboarding for Hakolkal Tickets: create billable tickets from a Claude Code session, scoped to your assigned projects. Run `npx -y hakolkal-tickets-mcp onboard` to set up.
