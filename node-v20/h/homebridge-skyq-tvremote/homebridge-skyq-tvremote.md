# homebridge-skyq-tvremote

> 标签: homebridge-plugin, sky, sky tv, sky-q, sky-q tv

## 简介

Exposes and Sky Q Box as a TV Accessory in HomeBridge, allow you to use the Remote UI in Control Centre
