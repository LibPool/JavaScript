# hrnet-components

> 标签: JavaScript

## 简介

- Download the package. - Download the dependencies ( react, react-dom ). - Use this import for the Modal : import { Modal } from "hrnet-components"; - Import the CSS : import "hrnet-components/style.css"; (I used Tailwindcss in this project.)
