# hexo-helper-link-too

> 标签: external, helper, hexo, link, nofollow

## 简介

Help you insert `<a>` snippet in hexo templates. A bit different from Hexo `link_to`. Helpers are used in templates to help you insert snippets quickly. Helpers cannot be used in source files.
