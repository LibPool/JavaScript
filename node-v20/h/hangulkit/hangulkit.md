# hangulkit

> 标签: hangeul, hangul, josa, 로 으로, 은는이가, 을를, 조사, 종성, 중성, 초성, 한글

## 简介

Useful tools for Hangul (Korean Alphabet & Korean Language). Split Hangul by each components and easily put Josa(Suffix) on it.
