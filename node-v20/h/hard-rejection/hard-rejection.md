# hard-rejection

> 标签: catch, debug, debugging, exit, fail, handler, hard, immediate, immediately, promise, promises, rejection, throw, uncaught, unhandled, verbose

## 简介

Make unhandled promise rejections fail hard right away instead of the default silent fail
