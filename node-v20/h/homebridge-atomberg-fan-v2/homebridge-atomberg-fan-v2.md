# homebridge-atomberg-fan-v2

> 标签: aris, atomberg, atomberg-fan, boost, efficio, erica, fan, gorilla, homebridge, homebridge-plugin, homekit, led, renesa, smart-fan, studio

## 简介

Homebridge platform plugin for Atomberg Smart Fans. Adds Homebridge v2.0 compatibility, the 6th (Boost) speed, LED on/off + brightness + colour-temperature control, local UDP state sync, debounce + throttle, and offline detection.
