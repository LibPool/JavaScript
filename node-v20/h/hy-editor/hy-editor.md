# hy-editor

> 标签: block-editor, editor, html-editor, quill, quill2, rich-text-editor, wysiwyg, 好运编辑器, 富文本编辑器

## 简介

好运编辑器（hy-editor）—— Quill 2 内核的轻量块级富文本编辑器：表格、代码块、公式、Mermaid 图表、高亮块、步骤条、时间轴、批注开箱即用，落库语义 HTML，前台一行代码还原
