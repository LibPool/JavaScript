# homebridge-tcl-androidtv

> 标签: adb, android-tv, androidtv, homebridge-plugin, homekit, tcl, television, tv

## 简介

Homebridge plugin to control TCL Android TV (e.g. 65X10) over network ADB: power, HDMI/app/broadcast input switching, channel selection and volume.
