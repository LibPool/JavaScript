# huly-mcp-selfhost

> 标签: anthropic, claude, huly, issue-tracker, mcp, model-context-protocol, project-management

## 简介

MCP server for Huly (self-hosted + cloud) — connect Claude Desktop to your Huly workspace via the native WebSocket SDK. Fork of huly-mcp-sdk with self-hosted document/description support, chat, attachments, custom issue statuses, and organizations.
