# hertzscript-velocity

> 标签: automatic-concurrency, concurrency, concurrent, concurrent-javascript, concurrent-programming, cooperative-multitasking, coroutine, coroutine-dispatcher, coroutines, green-threads, javascript, multitasking, preemptible, preemption, preemptive, preemptive-multitasking, protothreads, repl, stackless-coroutines, voluntary-preemtive-multitasking

## 简介

Velocity is a concurrent REPL which is designed specifically for HertzScript coroutines. All code runs concurrently alongside the REPL, so you can continue typing/adding code while existing code is still running.
