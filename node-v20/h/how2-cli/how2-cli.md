# how2-cli

> 标签: JavaScript

## 简介

How2 (or just how) is a cli tool to help you better communicate with the repository. How to start use it: ```sh npm install -g how2-cli cd /to/some/repo how ``` Upgrage to latest version: ```sh npm upgrade -g how2-cli ```
