# htmx-ui-plugin-search

> 标签: command-palette, docs, fuzzy-search, htmx, htmx-ui, htmx-ui-plugin, search

## 简介

Site search for htmx-ui-engine sites: a Ctrl/⌘K command palette with fuzzy matching over pages and sections, reading the sitemap htmx-ui-plugin-docs publishes.
