# holdpty

> 标签: attach, conpty, cross-platform, detach, dtach, node-pty, pi-package, pty, screen, terminal, tmux, windows

## 简介

Minimal cross-platform detached PTY. Launch commands in a pseudo-terminal, attach/view/record later.
