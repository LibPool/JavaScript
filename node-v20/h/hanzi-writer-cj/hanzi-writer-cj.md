# hanzi-writer-cj

> 标签: JavaScript

## 简介

Fork From http://chanind.github.io/hanzi-writer/. Hanzi Writer CJ is a free and open-source javascript library for both animating simplified Chinese characters and quizzing users on character stroke order.Support animCJK svg
