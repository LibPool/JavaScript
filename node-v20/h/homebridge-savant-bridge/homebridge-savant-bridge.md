# homebridge-savant-bridge

> 标签: automation, homebridge-plugin, homekit, hvac, lighting, savant, scenes, smart-home

## 简介

Homebridge plugin for Savant home automation. Controls lights, switches, thermostats and scenes via Apple HomeKit. No token required.
