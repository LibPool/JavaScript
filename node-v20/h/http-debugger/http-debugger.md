## 简介

Zero-dependency HTTP debug middleware for Node.js, Deno, Bun, and the Edge. Stream-level request capture, smart body truncation, cURL generation, and framework adapters for Astro, Express, Fastify, Hono, Astro, Elysia and Next.js.
