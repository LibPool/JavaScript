# hclsvg

> 标签: JavaScript

## 简介

Light and easy to use graphic library for Angular :  - line, rectangle, circle, arc, polyline, polygon, text, path, image - translate, rotate, scale, remove all shapes - make shapes draggable or clickable, including callbacks - export complete SVG code or
