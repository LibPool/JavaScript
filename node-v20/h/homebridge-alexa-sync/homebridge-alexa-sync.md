# homebridge-alexa-sync

> 标签: alexa, homebridge-plugin, homekit, smart-home, smart-life

## 简介

Homebridge plugin that mirrors Alexa-linked smart-home devices (Smart Life, Sengled, Hue, etc.) into HomeKit via a captured Amazon session cookie.
