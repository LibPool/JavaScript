# http-atrium-cdvi

> 标签: JavaScript

## 简介

Communicates with Atrium CDVI smart locks in http://storage.squareremoteaccess.com/#/ by running GET and POST requests. Handles setting cookies, and rc4 encryption needed to access the portal.
