# herbstutil

> 标签: bash, cli, configuration, herbstclient, herbstluftwm, json, linux, tiling, utility, window-manager, wm

## 简介

A utility to convert herbstclient attribute output into JSON. Perfect for programmatically interacting with the herbstluftwm tiling window manager.
