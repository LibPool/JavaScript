# homebridge-kasa

> 标签: automation, home, homeautomation, homebridge, homebridge-plugin, kasa, klap, smartbulb, smarthome, smartplug, smartswitch, tplink

## 简介

Kasa smart home plugin for Homebridge. Supports Legacy XOR, KLAP v2, AES, and TPAP protocols.
