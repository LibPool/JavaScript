# hearth-client

> 标签: JavaScript

## 简介

Light weight client for [Hearth](https://github.com/rxbryan/hearth). It presents one small interface over both of Hearth's surfaces: an HTTP control plane for provisioning rooms and minting capabilities, and a WebSocket runtime plane for live messaging.
