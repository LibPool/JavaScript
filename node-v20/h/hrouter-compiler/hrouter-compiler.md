# hrouter-compiler

> 标签: HarmonyOS, OpenHarmony, compile-time, hrouter, hvigor, navigation, plugin, router, routing

## 简介

HRouter compile-time plugin for HarmonyOS hvigor: scans @Route/@Service/@Interceptor decorators and generates router_map.json / service_map.json / page wrappers.
