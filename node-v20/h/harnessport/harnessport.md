# harnessport

> 标签: ai-agents, claude-code, codex, config-converter, copilot, cursor, harness, mcp, opencode, rules, windsurf

## 简介

Convert AI coding harness configs (rules, agents, skills, commands, MCP, hooks, permissions) between Claude Code, OpenCode, Cursor, Windsurf, Copilot, and Codex CLI
