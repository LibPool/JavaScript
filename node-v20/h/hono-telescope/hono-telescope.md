# hono-telescope

> 标签: ai, bun, debugging, hono, mcp, middleware, model-context-protocol, monitoring, nodejs, observability, performance, telescope, typescript

## 简介

Laravel Telescope-style debugging for Hono, with an MCP server so AI coding agents can read your app's live requests, exceptions and queries. Zero runtime dependencies.
