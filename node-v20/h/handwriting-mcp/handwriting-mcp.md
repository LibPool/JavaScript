# handwriting-mcp

> 标签: gtm, handwriting, mcp, outbound

## 简介

MCP server that turns text (or every row of a CSV) into realistic handwritten notes. Renders locally; nothing leaves your machine.

## 官网

- 官网：https://gtm.millwrighttech.com
- 源码仓库：git+https://github.com/aakash-rengaraj/handwriting-mcp.git
- npm 页面：https://www.npmjs.com/package/handwriting-mcp
