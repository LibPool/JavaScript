# hireach-d1

> 标签: cloudflare, d1, database, migrations, mongoose, orm, query-builder, relationships, sequelize, sql, typescript

## 简介

A powerful, type-safe ORM for Cloudflare D1 with a familiar Sequelize/Mongoose-like API, featuring modular architecture, advanced aggregates, and Prisma-style syntax
