# homebridge-xbee

> 标签: homebridge-plugin, relay, xbee, zigbee

## 简介

Homebridge Plugin for Digi XBee radio modules. Originally built for sliding and swing gate automation. Provides accessory for impulse-button. Target device project can be found from https://github.com/exsilium/pxbee-trigger
