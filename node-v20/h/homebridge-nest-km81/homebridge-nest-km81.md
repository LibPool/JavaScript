# homebridge-nest-km81

> 标签: google, homebridge-plugin, nest, sdm, thermostat

## 简介

Nest Thermostat Homebridge plugin using the official Google SDM API. Auto-refreshing OAuth — no cookie extraction, no token expiry chores.
