# hakojs

> 标签: code-execution, containerization, edge-functions, embeddable, isolation, javascript-engine, permissions, plugin-system, quicksjs, resource-limits, sandbox, security, serverless, untrusted-code, wasm, webassembly

## 简介

A secure, embeddable JavaScript engine that runs untrusted code inside WebAssembly sandboxes with fine-grained permissions and resource limits
