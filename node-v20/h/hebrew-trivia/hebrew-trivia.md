# hebrew-trivia

> 标签: JavaScript

## 简介

A fun and simple npm package that provides random Hebrew trivia questions with different difficulty levels (Easy, Medium, Hard). Perfect for quiz games, educational apps, or adding trivia challenges to your projects!
