# homebridge-balboa-esp32

> 标签: balboa, esp32, esphome, homebridge-plugin, homekit, hot-tub, spa, supports-hap

## 简介

Homebridge plugin for older Balboa hot tub controllers, using an ESP32/ESPHome topside interface.
