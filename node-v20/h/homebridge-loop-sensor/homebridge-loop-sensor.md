# homebridge-loop-sensor

> 标签: automation, homebridge-plugin, homekit, interval, loop, sensor, switch, timer

## 简介

A switch that pulses a HomeKit sensor every X minutes while it's on, or once after a countdown. Great for repeating automations (e.g. 'window open while AC is on' alerts).
