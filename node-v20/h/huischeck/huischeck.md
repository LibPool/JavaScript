# huischeck

> 标签: commute, dashboard, due-diligence, dutch, erfpacht, funda, gemini, huis-kopen, hypotheek, maximale-hypotheek, nederland, neighbourhood, netherlands, nextjs, nhg, property, real-estate, self-hosted, startersvrijstelling, woning

## 简介

Paste a Dutch house listing, get a scored due-diligence report: commute gates, erfpacht, neighbourhood safety, amenities, mortgage affordability and a condition read from the photos. Self-hosted, web dashboard included.
