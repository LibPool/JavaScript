# homebridge-broadlink-rm-pro-shades

> 标签: broadlink, homebridge-plugin, rm mini 3, rm pro 3, rm4

## 简介

Broadlink RM plugin (including the mini and pro) for homebridge with AC Pro and TV features. This fork provides an useful delay setting that allows the hombridge device to cooldown between broadcasts
