# @ttrpg/meters

> 标签: counter, gauge, hp, meter, resource, rpg, stamina, stress, track, ttrpg

## 简介

Unified meter / track / gauge primitive for TTRPG digital tools. The one shape behind HP, stamina, stress, mana, fate points, sanity, friendship hearts, segment clocks, debt — any bounded counter with min/max, optional refresh, and threshold detection. Ze
