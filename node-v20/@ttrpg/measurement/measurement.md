# @ttrpg/measurement

> 标签: 5e, aoe, cone, line, measurement, rpg, sphere, template, ttrpg

## 简介

AoE template math for TTRPG digital tools. Cones, lines, circles, cubes — square grid + hex grid implementations. Pure functions, zero dependencies. Pairs with @ttrpg/grid.
