# @ttrpg/printables

> 标签: aoe-template, battle-map, dot-grid, gm-screen, grid-paper, hex-grid, isometric, paper-dice, print-and-play, printable, rpg, standees, svg, tokens, ttrpg, tuck-box, zine

## 简介

Print-ready SVG generators for tabletop play at true physical scale: grid, dot and isometric paper, poster-tiled battle maps, AoE cut-out templates, token discs, paper standees, condition rings, fold-up dice, reference cards, initiative tents, tuck boxes,
