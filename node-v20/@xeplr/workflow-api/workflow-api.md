# @xeplr/workflow-api

> 标签: api, automation, express, triggers, workflow

## 简介

The free workflow HTTP API over @xeplr/workflow-engine: mount it in an Express app with registerWorkflow(), or run it on its own, and build your own workflow screens on it.
