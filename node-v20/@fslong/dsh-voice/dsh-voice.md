# @fslong/dsh-voice

> 标签: asr, deepseek-harness, dsh, plugin, speech, stt, voice, web-speech-api, whisper

## 简介

DSH 语音插件（参考 vokie）：点击🎤或按 F2 口喷→ASR 识别→口语润色→识别文本实时入聊天框，确认后发送。双引擎：浏览器 Web Speech API（默认）/ 本地 faster-whisper（离线质量优，状态条可切）。
