# @brandstack/cli

> 标签: brandstack, cli, color palette, image resizer, og image generator, shader generator, utm builder

## 简介

Brand Stack's tools from the command line: free tools that run offline with no account, plus workspace commands that turn screenshots into product mockups over the same API as the MCP connector.
