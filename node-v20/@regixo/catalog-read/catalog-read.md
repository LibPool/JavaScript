# @regixo/catalog-read

> 标签: ai-agent, compliance, context-layer, data-catalog, dora, gdpr, local-first, mcp, metadata, read-api, regixo, ropa

## 简介

Regixo's read layer for AI agents — one read path over the local catalog and the free compliance DRAFT, consumed by both the /api/v1 read API and the read-only `regixo mcp` server so they always agree. Read-only by construction (no setter); zero metadata
