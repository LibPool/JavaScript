# @regixo/web-data-lens

> 标签: compliance, data-catalog, data-map, dora, gdpr, local-first, metadata, portal, regixo, ropa, server-rendered

## 简介

Regixo's free portal — the data map, drafted RoPA/DORA record, and the versioned /api/v1 read API, server-rendered from the local Node process (no SPA framework). Default port 4319, loopback-only.
