# @brightlocal/a-brain-ui

> 标签: brightlocal, local-seo, react, sdk, typescript, ui

## 简介

Presentational React components for the public BrightLocal APIs. Takes domain-typed props from @brightlocal/a-brain-api; never calls an API itself.
