# pqc-audit

> 标签: audit, cbom, cryptography, post-quantum, pqc, sarif, scanner

## 简介

Alias of quantum-safe-audit: find quantum-vulnerable cryptography in JavaScript and TypeScript projects (SARIF and CycloneDX CBOM output).
