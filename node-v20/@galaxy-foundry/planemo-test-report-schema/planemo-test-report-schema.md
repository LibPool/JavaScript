# @galaxy-foundry/planemo-test-report-schema

> 标签: foundry, galaxy, json-schema, planemo, schema

## 简介

JSON Schema for `planemo test --test_output_json` reports, vendored from upstream planemo, plus an AJV-backed validator and CLI.
