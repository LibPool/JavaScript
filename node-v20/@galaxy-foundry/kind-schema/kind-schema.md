# @galaxy-foundry/kind-schema

> 标签: foundry, frontmatter, kind, schema, zod

## 简介

The shared kind machinery for Foundry-pattern instances — the KindDefinition contract, per-kind and discriminated-union assembly, and path→kind collection routing. The kinds themselves stay per-instance.
