# @galaxy-foundry/site-kit

> 标签: astro, foundry, layout, navigation, site

## 简介

Reusable reading surfaces for Foundry-pattern instances — shell, note frame, tags, references, and licences. Values, domain furniture, theme, and corpus stay per-instance.
