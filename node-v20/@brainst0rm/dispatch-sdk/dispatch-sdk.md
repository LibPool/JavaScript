# @brainst0rm/dispatch-sdk

> 标签: JavaScript

## 简介

Programmatic Brainstorm dispatch primitive for autonomous-agent operators (P1.7). Wraps the operator-side WebSocket flow with an async-iterator API for progress events and a typed dispatch() function.
