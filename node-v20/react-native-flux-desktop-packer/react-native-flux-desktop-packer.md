# react-native-flux-desktop-packer

> 标签: electron-alternative, launcher, packer, react-native-flux-desktop, windows

## 简介

Package a react-native-flux-desktop app into a self-contained Windows .exe (Go launcher + go:embed payload). Install as a devDependency, add `output`/`main` to app.json, then run `flux-pack`.
