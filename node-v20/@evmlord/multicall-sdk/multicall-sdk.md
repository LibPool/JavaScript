# @evmlord/multicall-sdk

> 标签: EVM multicall, Ethereum RPC optimization, Multicall SDK, batch eth_call, defi, ethereum, ethers v6, gas savings, multicall, multicall3, multichain

## 简介

A lightweight library to batch multiple calls via a single eth_call using Multicall3 on 285+ chains.
