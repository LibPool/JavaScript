# @jetserge/rpiv-ask-user-question

> 标签: pi-extension, pi-package, rpiv

## 简介

Pi extension. A structured questionnaire the model can put to you when it would otherwise guess, with typed options instead of free-form replies. Fork of @juicesharp/rpiv-ask-user-question with unreleased fixes applied.
