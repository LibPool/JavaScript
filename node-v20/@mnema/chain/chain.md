# @mnema/chain

> 标签: append-only, audit-trail, ed25519, hash-chain, tamper-evident

## 简介

The mnema proof engine: typed event catalog, per-tail hash chain, Ed25519 checkpoints, and verification. Zero runtime dependencies.
