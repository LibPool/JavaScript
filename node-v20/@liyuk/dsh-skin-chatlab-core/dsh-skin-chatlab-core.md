# @liyuk/dsh-skin-chatlab-core

> 标签: JavaScript

## 简介

ChatLab 基座：可扩展聊天皮肤插件的核心——皮肤注册表、切换器、装饰逻辑、设置面板。皮肤数据由各皮肤包(如 @liyuk/dsh-skin-feishu)通过 ctx.chatlab.registerSkin 注入。
