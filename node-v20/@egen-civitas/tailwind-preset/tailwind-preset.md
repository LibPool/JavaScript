# @egen-civitas/tailwind-preset

> 标签: JavaScript

## 简介

Point d'entrée Tailwind v4 partagé pour les apps EGEN : pont vers les tokens de @egen-civitas/esm-theme, preflight en @layer base (priorité minimale) et utilitaires non layerés pour battre le reset Carbon. À utiliser avec la règle rspack *.tw.css fournie
