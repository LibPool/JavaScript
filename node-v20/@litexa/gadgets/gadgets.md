# @litexa/gadgets

> 标签: Alexa, Custom Interface, Echo Buttons, Gadgets, Game Engine, Litexa, SDK, Skill

## 简介

This module adds support for GameEngine, GadgetController, and CustomInterfaceController directives and events to Litexa.
