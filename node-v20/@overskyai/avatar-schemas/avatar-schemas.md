# @overskyai/avatar-schemas

> 标签: avatar, oversky, schema, zod

## 简介

Tiny shared Zod schemas for the OverSky avatar wire contract (AvatarActivity, AvatarFleet, AgentsPinnedChanged). Imported by daemon, data-schemas, and Electron desktop. Zero runtime deps beyond zod.
