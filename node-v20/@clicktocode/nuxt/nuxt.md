# @clicktocode/nuxt

> 标签: ai, coding-agent, devtools, element-picker, nuxt, nuxt-module, opencode, vue

## 简介

Click an element in your running Nuxt 3 app and hand it to a coding agent — element picker + OpenCode bridge.
