# @huakunshen/dsh-plugin-voice

> 标签: JavaScript

## 简介

Voice for the DeepSeek Harness web UI: user-managed speech provider profiles (Xiaomi MiMo, Fish Audio, OpenAI-compatible) with independent provider selection for read-aloud TTS and composer dictation STT.
