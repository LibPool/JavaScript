# homebridge-philips-airplus-cloud

> 标签: air purifier, air+, airplus, homebridge-plugin, homekit, philips, supports-hap, versuni

## 简介

Homebridge plugin for Philips Air+ / PureProtect air purifiers via the Philips (Versuni) cloud — the same MQTT protocol used by the Air+ app and Google Home.
