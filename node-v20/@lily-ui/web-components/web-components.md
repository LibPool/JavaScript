# @lily-ui/web-components

> 标签: accessibility, component-library, custom-elements, design-system, framework-agnostic, typescript, ui, wcag, web-components

## 简介

Lily UI — accessible (WCAG 2.1 AAA), framework-agnostic Web Components (custom elements). Light-DOM markup styled by @lily-ui/css; usable in any framework or none.
