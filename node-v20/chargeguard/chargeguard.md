# chargeguard

> 标签: amex, chargeback, chargebacks, dispute, ecommerce, fraud, mastercard, payments, reason-codes, stripe, visa

## 简介

CLI for the ChargeGuard public API: card-network chargeback reason codes (Visa, Mastercard, Amex), response deadlines per gateway, and free store audits.
