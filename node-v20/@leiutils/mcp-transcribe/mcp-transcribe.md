# @leiutils/mcp-transcribe

> 标签: audio, leiutils, mcp, model-context-protocol, stdio, transcript, transcription

## 简介

Local MCP server that uploads a local audio file to LeiUtils and retrieves the transcript, via the LeiUtils integration API.
