# @synbee-webcomponents/sw-content-wrapper

## 简介

sw-content-wrapper is a web-component from Synbee Webcomponents Library, built with StencilJS, TypeScript, Storybook. It's based on the web-component standard and it's designed to be agnostic from the JavaScirpt framework you are using.
