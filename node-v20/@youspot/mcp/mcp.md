# @youspot/mcp

> 标签: agent, crm, mcp, mcp-server, model-context-protocol, personal-crm, stdio, youspot

## 简介

YouSpot MCP server. Bridges stdio to the remote YouSpot MCP endpoint, for Claude Desktop, Cursor and any other client that cannot speak streamable HTTP.
