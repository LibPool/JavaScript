# tollbooth-sdk

> 标签: agents, ai-agents, arc, arc-network, circle, escrow, payments, tollbooth, usdc, viem

## 简介

TypeScript SDK for Tollbooth, a role-based USDC escrow on Arc for software that pays software. Typed client plus LLM tool definitions.
