# @homes-ph/api

> 标签: JavaScript

## 简介

Framework-agnostic API client for the Homes fleet: one canonical mirror of the services' wire DTOs plus the axios transport, shared by @homes-ph/console, @homes-ph/mobile and @homes-ph/public.
