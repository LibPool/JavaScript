# @coclaw/openclaw-coclaw

> 标签: bridge, channel, chatbot, coclaw, openclaw, openclaw-plugin, webchat

## 简介

OpenClaw plugin for remote chat over WebRTC. Run `openclaw coclaw enroll` after install.
