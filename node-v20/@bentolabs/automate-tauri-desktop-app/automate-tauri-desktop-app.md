# @bentolabs/automate-tauri-desktop-app

> 标签: JavaScript

## 简介

A Tauri v2 plugin and MCP server that let AI agents (Claude Code, Cursor, etc.) interact with your desktop app — screenshots, DOM access, clicking, typing, scrolling, and more.
