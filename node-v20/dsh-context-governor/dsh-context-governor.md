# dsh-context-governor

> 标签: cache-hit, compaction, context, cost, deepseek-balance, deepseek-harness, dsh, dsh-plugin, off-peak, tokens

## 简介

Session context governor for DeepSeek Harness: prompt size and per-step cost in dollars (cache-read/cache-write aware), cache-hit, context bands, a per-session compaction threshold derived from the model window, DeepSeek balance and peak/off-peak tariff,
