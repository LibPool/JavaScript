# @memobit/icons

> 标签: icon-set, icons, memobit, react, svg, svg-icons, tree-shakeable, typescript

## 简介

495 hand-built SVG icons for the Memobit apps — individually exported and tree-shakeable, with categories and search aliases. TypeScript-first, ESM-only, React 19.
