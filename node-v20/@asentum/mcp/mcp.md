# @asentum/mcp

> 标签: ai-agents, asentum, blockchain, claude, cursor, mcp, model-context-protocol, smart-contracts

## 简介

Model Context Protocol server for building on Asentum from AI agents (Claude Code, Claude Desktop, Cursor): chain reads, contract validation on the real VM, docs, and opt-in signed transactions.
