# @icedesign/opensource-site-scaffold

> 标签: JavaScript

## 简介

该模板基于 docsite，适用于开源站点类的场景，支持 markdown 文档和中英文国际化等功能。

## 官网

- 官网：https://alibaba.github.io/ice/scaffold-preview/ice-opensource-site/index.html
- npm 页面：https://www.npmjs.com/package/@icedesign/opensource-site-scaffold
