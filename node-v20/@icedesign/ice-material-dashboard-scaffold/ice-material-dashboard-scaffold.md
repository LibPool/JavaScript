# @icedesign/ice-material-dashboard-scaffold

> 标签: JavaScript

## 简介

该模板基于社区的 material-dashboard-react 改造而成，默认使用 material-ui 组件和 react-scripts 构建，同时也支持飞冰基础组件和区块的使用，支持 Iceworks 一键创建项目和完整的 GUI 操作
