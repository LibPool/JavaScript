# @icedesign/ice-midway-template

> 标签: ice, ice-midway-template, ice-template

## 简介

基于 Iceworks 能够一键生成 ice 和 Node 的前后端分离的项目；前端使用 React 技术栈，后端使用 Midway 作为服务端开发框架。
