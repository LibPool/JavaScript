# @cocorograph/hub-agent

> 标签: agent, cockpit, cocorograph, hub, remote, tmux

## 简介

Hub Hosted Cockpit のローカル常駐 agent。Hub と outbound WSS で接続し、ローカルの Claude / Codex チャットと tmux セッションを中継する。
