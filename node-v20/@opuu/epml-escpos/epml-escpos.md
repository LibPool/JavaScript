# @opuu/epml-escpos

> 标签: barcode, compiler, epml, esc-pos, escpos, markup, pos, printer, qrcode, receipt, thermal-printer

## 简介

An XML-style templating language compiler for ESC/POS thermal printers. Transform markup templates and JSON data into raw byte arrays.
