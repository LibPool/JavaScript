# dsh-remote-control-desktop

> 标签: cpolar, deepseek-harness, dsh, dsh-plugin, frp, ngrok, remote, remote-control, remote-desktop, 内网穿透, 手机, 远程, 远程控制, 远程桌面

## 简介

DSH 手机远程访问 + 远程桌面：内置本地代理(8090)+配置面板+远程屏幕/鼠标/键盘。配合任意内网穿透工具（cpolar/frp/ngrok等）把公网URL转发到 127.0.0.1:8090 即可用手机浏览器远程使用本机 Harness。本包为 dsh-remote-desktop 的修复分支，已修补 DSH 0.2.x browser-auth 导致的 401（dsh web authentication required）。
