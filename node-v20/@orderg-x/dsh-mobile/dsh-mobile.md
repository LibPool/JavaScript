# @orderg-x/dsh-mobile

> 标签: cloudflare-tunnel, deepseek-harness, dsh, dsh-plugin, mobile, phone, qr-code, remote

## 简介

Scan a QR code and use DSH from your phone's browser: watch the tasks running on your computer, reply and approve, live. One QR code works anywhere: a free Cloudflare tunnel is set up automatically. One-time QR pairing, per-device access you can revoke.
