# @tapepack/core

> 标签: compression, deploy, deweb, onchain, tapeout, tapepack, web3

## 简介

TapePack：把静态站点压缩后部署到 DeWEB（TapeOut）链上，上链 Gas 直降——压缩、估算、增量更新、一条命令部署
