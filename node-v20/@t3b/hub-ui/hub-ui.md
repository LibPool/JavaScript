# @t3b/hub-ui

> 标签: JavaScript

## 简介

The3Beez apps' look, built from the3beez-design-system (D-053): its tokens and app components as one stylesheet, its POS set as a second one for a counter, plus the logo. Installed by every app; never copied by hand.
