# @qzsy/dsh-workspace-context-menu

> 标签: context-menu, deepseek-harness, dsh, plugin, sidebar, workspace

## 简介

Right-click menu for sidebar workspace (project) rows: new session, rename, copy path, open directory, and remove from sidebar.
