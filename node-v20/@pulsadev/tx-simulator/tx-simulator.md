# @pulsadev/tx-simulator

> 标签: debug, ethereum, evm, gas-estimation, revert, simulation, trace, transaction, typescript, web3

## 简介

Transaction simulation — preview results, revert reasons, gas usage, state diffs, event logs before sending. Zero dependencies, pure RPC.
