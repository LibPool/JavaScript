# @eave_bounty/dsh-graph-usage

> 标签: cache, deepseek-harness, dsh, dsh-plugin, plugin-graph, skills, token, visualization

## 简介

DSH 已装插件关系图谱：侧边栏展开面板，按依赖/相似/项目连线，球大小=调用频次，颜色=类型，亮暗=启用状态；含技能使用与 token 缓存成本分析。
