# @valve-tech/unchained-reader

> 标签: address-appearances, bloom-filter, ethereum, evm, ipfs, transaction-history, trueblocks, unchained-index

## 简介

Browser-safe, zero-dependency reader for the TrueBlocks Unchained Index. Resolves the index manifest, fetches bloom filters and index chunks from any IPFS gateway, and parses the binary bloom/chunk formats client-side into address appearances — no chifra
