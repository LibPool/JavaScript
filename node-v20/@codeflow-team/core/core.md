# @codeflow-team/core

> 标签: agent, ast, codeflow, codegen, json-schema, static-analysis, ts-morph, typescript, visual-programming, workflow

## 简介

Analyze a TypeScript agent flow into a workflow graph and patch it back byte-for-byte — domain model, tool registry, typed API codegen. Browser-safe, never executes the code it reads.
