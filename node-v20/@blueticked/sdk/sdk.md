# @blueticked/sdk

> 标签: api, blueticked, email, messaging, notifications, sms, south-africa, typescript, whatsapp, whatsapp-api

## 简介

Official TypeScript SDK for the Blueticked API — send WhatsApp, SMS and email from one endpoint. Typed, zero-dependency, generated from the published OpenAPI spec.
