# vite-plugin-request-logger

> 标签: api-logger, dev-server-logger, http-logger, logger, middleware-logger, morgan, request-logger, typescript, vite, vite-dev-logger, vite-logger, vite-morgan, vite-plugin, vite-plugin-morgan

## 简介

A robust, Morgan-like HTTP request logger plugin for Vite supporting Vite 5, 6, 7, 8+ with body logging and TypeScript support.
