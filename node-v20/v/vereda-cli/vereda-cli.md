# vereda-cli

> 标签: ESM, TypeScript, arrow-keys, clack, cli, declarative, interactive, menu, prompt, tui

## 简介

Declarative interactive CLI builder over @clack/core. Define a menu config, get a navigable arrow-key UI with safe action execution and argv routing.
