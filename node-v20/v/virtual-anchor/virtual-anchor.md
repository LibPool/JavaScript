# virtual-anchor

> 标签: infinite-scroll, intersection, react, scroll-anchoring, scroll-to-index, variable-height, virtual, virtual-list, virtual-scroll, virtualization, windowing

## 简介

Virtual scrolling that models position as an anchor rather than a pixel offset: variable item heights, per-item viewport events, and scroll-to-item that lands sub-pixel exactly. Framework-agnostic core, with a React adapter at virtual-anchor/react.
