# vscode-playwright-mcp

> 标签: ai, automation, electron, llm, mcp, playwright, testing, vscode

## 简介

Playwright for VS Code. MCP server that gives LLMs full mouse, keyboard, and visual control over VS Code via Playwright's Electron API.
