# virtuous-ts-mcp

> 标签: crm, mcp, model-context-protocol, virtuous

## 简介

Read-only MCP server for Virtuous CRM+, built on virtuous-ts. Contacts, gifts, and campaigns for Claude, Cursor, and other MCP hosts.
