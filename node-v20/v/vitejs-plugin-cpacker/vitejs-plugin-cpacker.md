# vitejs-plugin-cpacker

> 标签: JavaScript

## 简介

倘若你的浏览器应用是一个需要被嵌入到其它页面中的应用， 而且在嵌入过程中你遇到了样式的干扰性问题， 那么你可以使用本插件来帮助你解决这个问题。
