# vespera-sdk

> 标签: arisan, celo, defi, rosca, stablecoin, vespera, viem, web3

## 简介

TypeScript SDK for the Vespera arisan (ROSCA) protocol on Celo — typed contract ABIs, mainnet addresses, chain config, and agent policy metadata.
