# vibe-audit-security

> 标签: claude-code, cors, mcp, rls, scanner, secrets, security, ssrf, supabase, vibe-coding

## 简介

Security scanner for vibe-coded projects: local CLI and MCP server that catch the security mistakes an AI coding assistant can silently introduce (hardcoded secrets, disabled RLS, open CORS, missing security headers) before you push.
