# vite-plugin-env-main

> 标签: JavaScript

## 简介

根据环境不同，区分不同的入口文件。默认入口文件为`/src/main.js`，开发环境入口文件为`/src/main.dev.js`。 比如你想在开发阶段全量引入element-plus，在生产环境中按需引入，此时需要编写不同的入口文件。
