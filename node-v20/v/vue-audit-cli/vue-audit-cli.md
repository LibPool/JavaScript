# vue-audit-cli

> 标签: audit, cli, code-review, linter, static-analysis, vue, vue2, vue3

## 简介

本地 CLI 工具：静态扫描 Vue2/Vue3 项目的 .vue 组件，检查 32 类常见隐患（v-for key、props 修改、this 未定义属性、Options API 陷阱等），输出 JSON + Markdown 审计报告
