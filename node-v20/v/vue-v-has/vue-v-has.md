# vue-v-has

> 标签: JavaScript

## 简介

``` import v_has from 'vue-v-has'; Vue.use(v_has); window.localStorage.removeItem('login'); window.localStorage.setItem('login',JSON.stringify(<'name'>)) <div v-has="<name>">Has</div> ```
