# vue-scramble-text

> 标签: Vue.js, scramble, text

## 简介

* Vue.jsでString配列を渡すといい感じにシャカシャカしてくれるコンポーネントライブラリ * Component library for Vue.js. Pass string array for text shuffled effect.
