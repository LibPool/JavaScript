# vue2-file-previewer

> 标签: docx-preview, file-preview, markdown-preview, mermaid-preview, offline-intranet, pdf-preview, pptx-preview, pure-frontend, vue2, vue2-file-previewer, xlsx-preview, xmind-preview

## 简介

A powerful, pure front-end file preview component for Vue 2 (2.6 & 2.7) supporting DOCX, PDF, XLSX, PPTX, XMIND, Mermaid, Markdown, Text, CSV, Images and Media.
