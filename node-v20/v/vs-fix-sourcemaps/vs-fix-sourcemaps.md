# vs-fix-sourcemaps

> 标签: Debugging, JS, JSX, React, Studio, Visual, Webpack

## 简介

A Webpack plugin that fixes javascript sourcemaps in Visual Studio (2015), allowing for JSX and JS debugging directly in Visual Studio.
