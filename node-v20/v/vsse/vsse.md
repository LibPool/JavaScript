# vsse

> 标签: client, eventsource, headers, polyfill, post, requestId, sse, stream

## 简介

Lightweight SSE manager with single-connection multiplexing, active connection support, and per-request POST options. Now supports custom headers for SSE connections via event-source-polyfill.
