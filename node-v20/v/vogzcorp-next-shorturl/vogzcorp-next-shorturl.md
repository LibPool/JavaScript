# vogzcorp-next-shorturl

> 标签: JavaScript

## 简介

The component directly uses the vogzcorp API, https://vgz.vercel.app   It automatically handles an API request to deliver unique links each time the site reloads. The links are completely temporary, possibly ranging from vgz.vercel.app/I6dsOq to vgz.verc
