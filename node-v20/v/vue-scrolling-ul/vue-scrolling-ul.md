# vue-scrolling-ul

> 标签: auto, auto scroll, auto scrolling list, scroll, scroll list, scroll ul, ul, vue, vue2

## 简介

这是一个Vue组件，提供一个自动滚动的ul列表。This is a Vue component that provides a list of ul that scrolls automatically.
