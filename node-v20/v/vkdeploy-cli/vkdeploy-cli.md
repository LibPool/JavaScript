# vkdeploy-cli

> 标签: JavaScript

## 简介

CLI em Node.js para gerar o bundle de um app React Native, compactar os assets e enviar o arquivo para o backend de versionamento.

## 官网

- npm 页面：https://www.npmjs.com/package/vkdeploy-cli

## 历史版本号

- 0.0.8

## 获取地址

- npm 安装：`npm install vkdeploy-cli`
- npm registry：https://registry.npmjs.org/vkdeploy-cli
- Node 要求：>=18
