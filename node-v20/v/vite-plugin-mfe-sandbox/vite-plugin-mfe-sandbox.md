# vite-plugin-mfe-sandbox

> 标签: JavaScript

## 简介

面向 Vite 子应用的微前端沙箱构建插件，在构建期完成 **JS 全局变量沙箱化** 与 **CSS 选择器命名空间隔离**，运行时配合 [`mfe-sandbox`](../mfe-sandbox/README.md) 工作。
