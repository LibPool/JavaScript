# vet-sign

> 标签: JavaScript

## 简介

The goal of this repo is to expose a simple tool for storing VeChain private keys and signing calldata (as a VeChain transaction). The ultimate goal being an easy tool to deploy `seth` formatted calldata to VeChain `mainnet` and `testnet`.
