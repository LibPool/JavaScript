# viewport-truth

> 标签: 100vh, address bar, android chrome, dvh, hook, ios safari, keyboard, layout viewport, lvh, mobile viewport, on-screen keyboard, pwa, react, real viewport, resize, safe-area-inset, scroll, ssr, store, svelte, svh, url bar, vh, viewport, viewport height, viewport size, virtual keyboard, visual viewport, visualviewport, vue, webview

## 简介

Tiny zero‑config VisualViewport-first store for accurate visible viewport size in CSS pixels. Detects virtual keyboard, stabilizes resize/scroll jitter, and is SSR-safe across frameworks.
