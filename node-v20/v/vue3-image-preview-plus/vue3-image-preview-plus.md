# vue3-image-preview-plus

> 标签: image, preview, vue, vue3

## 简介

一个基于vue3的图片预览插件，可以缩放图片，移动图片，旋转图片，目前只支持pc端。

## 官网

- 官网：https://github.com/lytdev/vue3-image-preview
- npm 页面：https://www.npmjs.com/package/vue3-image-preview-plus
