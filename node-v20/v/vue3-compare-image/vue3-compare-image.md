# vue3-compare-image

> 标签: compare image, image comparison, image diff, image slider, latest, picture comparison, typescript, vue 3 slider, vue-3-compare-image, vue3 compare image

## 简介

A Vue 3 component to compare and slide between two images, supports vertical and horizontal modes, and Keyboard for accessibility.
