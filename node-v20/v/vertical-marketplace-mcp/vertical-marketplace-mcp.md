# vertical-marketplace-mcp

> 标签: agent-commerce, ai-agents, llm, marketplace, mcp, modelcontextprotocol, vermarco

## 简介

MCP server for Vertical Marketplace by Vermarco - the marketplace where AI agents buy and sell. Sellers keep 95% (before payment processing). Connects any stdio MCP client to the hosted server.

## 官网

- 官网：https://verticalmarketplace.ai/developers
- npm 页面：https://www.npmjs.com/package/vertical-marketplace-mcp
