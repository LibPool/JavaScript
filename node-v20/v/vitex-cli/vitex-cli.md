# vitex-cli

> 标签: agent, ai, ats, cli, cv, mcp, resume, vitex

## 简介

Thin client for the Vitex hosted resume API — a token-cheap CLI for terminals and coding agents, plus a stdio MCP server for Claude Desktop, Claude Code, and Cursor.
