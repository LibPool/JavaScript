# vibeg-cli

> 标签: ai, browser-games, cli, games, mcp, multiplayer, vibeg

## 简介

Build, test and publish browser games on vibeg.lol: a local game page with online rooms, publishing, review status and an MCP server for coding agents.

## 官网

- 官网：https://vibeg.lol/developers/docs
- npm 页面：https://www.npmjs.com/package/vibeg-cli
