# vagrant-git

> 标签: git, vagrant

## 简介

Simple nodejs command that combine vagrant and git to fetch projects and related vagrant boxes for development.

## 官网

- 官网：https://github.com/pussinboots/vagrant-git
- 源码仓库：git://github.com/pussinboots/vagrant-git.git
- npm 页面：https://www.npmjs.com/package/vagrant-git
