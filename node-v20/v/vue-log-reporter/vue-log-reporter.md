# vue-log-reporter

> 标签: error-monitoring, frontend, log, logger, reporter, vue, vue2, vue3

## 简介

通用 Vue 日志上报插件：自动捕获 console/全局错误，批量上报到自定义 endpoint，支持 Vue 2/3。
