# vectora

> 标签: agent, ast, claude, claude-code, co-change, codebase-navigation, codex, cursor, dependency-graph, git-history, skill, vectora, windsurf

## 简介

Cuts context bloat by loading only files relevant to the current task, auto-learns coding patterns as you work, and lets you lock in rules across sessions with a single command.
