# vidcontext

> 标签: JavaScript

## 简介

`vidcontext` is a powerful, self-contained node module that allows you to easily extract frames from any video at a given time interval, filter out duplicate or mostly identical frames using Perceptual Hashing, and then automatically describe each unique
