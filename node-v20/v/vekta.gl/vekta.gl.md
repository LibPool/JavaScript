# vekta.gl

> 标签: geospatial, gis, map, mapbox, maplibre, maps, renderer, vector-tiles, vekta, webgl, webgpu, wgpu

## 简介

The map renderer for every screen. One GPU engine — web, iOS, Android, desktop. A cross-platform Rust/wgpu vector map renderer, and a cheaper alternative to Mapbox GL.
