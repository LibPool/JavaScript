# vibecraft-agent

> 标签: ai, automation, cli, code-generation, dashboard, data-visualization, gemini, react, sqlite

## 简介

SQLite 데이터베이스를 기반으로 Gemini CLI를 활용하여 React 데이터 시각화 애플리케이션을 자동 생성하는 CLI 도구
