# vue-ajax-manager

> 标签: JavaScript

## 简介

`vue-ajax-manager`使用`axios`、`vuex`来快速创建`ajax`过程常用的状态，并自动处理。 且提供了处理接口，意在减少 ajax 相关开发工作量。
