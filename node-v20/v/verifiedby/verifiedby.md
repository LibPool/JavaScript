# verifiedby

> 标签: cades, digital-signature, document-provenance, document-verification, pades, pdf, pdf-signature, rfc3161, tamper-evident, timestamp-verification, tsa, webcrypto

## 简介

Independent, offline verifier for RFC 3161 timestamped and digitally signed PDFs. Zero dependencies. The same engine that runs truedoc.eu.
