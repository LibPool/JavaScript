# verb-reflinks

> 标签: api docs, code comments, docs, documentation, generate, generator, jsdoc, markdown, plugin, readme, reflinks, template, templates, verb, verb-generator, verbgenerator, verbplugin

## 简介

Verb middleware that resolves reflinks for valid npm package names in markdown documents and appends them to the document.
