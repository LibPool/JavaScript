# verify-arch

> 标签: architecture, ci, lint, medusa, medusajs, monorepo, static-analysis

## 简介

Whole-graph architecture gate for Medusa 2.x codebases. Catches cross-file footguns a per-file linter cannot see: serviceName collisions, route-path collisions, loader-skipped index.ts side-effects (medusajs/medusa#15442), duplicate query steps without .c
