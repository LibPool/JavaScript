# vue3-simple-typeahead

> 标签: autocomplete, autosuggest, component, enhanced input, search, searchbox, select, typeahead, v-autocomplete, v-typeahead, vue, vue-autocomplete, vue-component, vue-typeahead, vue3, vue3-simple-typeahead, vue3-typeahead, vue3js, vuejs3

## 简介

A simple and lightweight Vue3 typeahead component that show a suggested list of elements while the user types in.
