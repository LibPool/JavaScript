# vue3-virtual-scroller-detect-height

> 标签: dynamic virtual scroll, support async element render, detect height after render

## 简介

A high-performance virtual scrolling component for Vue 3,it automatically measures actual hieght by real dom element, support async element creating, it renders only visible items to handle large datasets efficiently.
