# vite-markdown-injector

> 标签: markdown, plugin, vite

## 简介

Vite Markdown Injector is a powerful npm package that allows you to seamlessly inject markdown content into your Vite-powered projects. With just a few lines of code, you can enhance your web applications with dynamic and interactive markdown content.
