# vite-plugin-beasties

> 标签: JavaScript

## 简介

A Vite plugin that uses [beasties](https://github.com/danielroe/beasties) to embed critical CSS in your HTML pages.

## 官网

- 官网：https://github.com/danielroe/beasties#readme
- 源码仓库：git+https://github.com/danielroe/beasties.git
- npm 页面：https://www.npmjs.com/package/vite-plugin-beasties
