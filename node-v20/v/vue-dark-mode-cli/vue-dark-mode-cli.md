# vue-dark-mode-cli

> 标签: JavaScript

## 简介

`vue-dark-mode-cli` is a CLI tool for adding dark mode functionality to your Vue.js 2 project. It simplifies the process of creating a mixin, updating your Vue components, and adding the required styles for dark mode.
