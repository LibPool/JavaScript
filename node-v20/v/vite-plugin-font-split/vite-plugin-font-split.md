# vite-plugin-font-split

> 标签: font, font-split, font-subset, subset, vite, vite-plugin, woff2

## 简介

Vite 字体裁剪/分包插件：根据字符集裁剪压缩字体，输出多格式字体与 @font-face 样式，支持自动分包与开发态热重建
