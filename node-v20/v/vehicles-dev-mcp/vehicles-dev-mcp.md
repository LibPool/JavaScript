# vehicles-dev-mcp

> 标签: automotive, claude, mcp, modelcontextprotocol, vehicle-data, vehicles, vin

## 简介

Model Context Protocol server for the vehicles.dev API — VIN decode, specifications, recalls, vehicle photos, live listings, market value, price check, depreciation, ownership costs, and durable vehicle history reports as agent tools.
