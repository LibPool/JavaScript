# vin-scanner

> 标签: camera, computer-vision, custom-element, mobile, ocr, onnx, onnxruntime-web, paddleocr, vin, vin-ocr, vin-scanner, web-component, yolo

## 简介

Mobile-first VIN scanner web component: YOLO detection + PaddleOCR recognition in the browser via onnxruntime-web, with temporal consensus across video frames.
