# vz-skills

> 标签: agent, claude, claude-code, code-review, plugin, security, skills, workflow

## 简介

VZ Skills: an evidence-driven development lifecycle plugin for Claude Code (discovery, profiles, clarify/plan/implement/test/review/verify, advisory guards). Install with `npx vz-skills install`.
