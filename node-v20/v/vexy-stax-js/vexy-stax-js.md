# vexy-stax-js

> 标签: 3d, image-stack, scene, threejs, vexy-stax, web-component

## 简介

Browser renderer for the vexy-stax shared scene format: 3D glass plates in two views, with morphable opacity. Ships as ESM, Web Component, and a classic-script global.
