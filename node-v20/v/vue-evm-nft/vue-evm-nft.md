# vue-evm-nft

> 标签: blockchain, composable, ethereum, ethers, evm, nft, pinia, vue, vue3, web3

## 简介

Vue 3 components, Pinia stores, and utilities for working with NFTs directly on EVM-compatible blockchains. No API is needed, the blockchain is the API.
