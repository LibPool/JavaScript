# vue-cli-plugin-pack

> 标签: JavaScript

## 简介

此插件为 **vue-cli** 的扩展，用于在 **vue-cli-service build** 命令执行的最后阶段，也就是 vue-cli 内部的 webpack 的 **done** 钩子触发的时候，对构建产出目录进行 zip 打包，打包出来的文件名为使用此插件的当前项目的根目录的 package.json 中的 projectName 配置 + 当前日期(**{projectName}_{format}.zip**)
