# verifyum

> 标签: archival, audit, bitcoin, certificate-transparency, digital-preservation, eidas, evidence, fixity, merkle, notarization, opentimestamps, proof-of-existence, provenance, qualified-timestamp, rfc3161, sigsum, solana, timestamping, transparency-log, trusted-timestamp

## 简介

Proof a file existed unchanged at a point in time, witnessed by Bitcoin, a qualified eIDAS timestamp, Sigsum and Certificate Transparency. Verifies offline. No dependencies.
