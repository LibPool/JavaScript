# vite-awesome-svg-loader

> 标签: currentColor, custom-elements, icon, image, import, loader, plugin, preserve-line-width, preserve-stroke-width, react, replace-colors, sprite, sprite-sheet, sprite-sheets, sprites, svg, svg-sprite, svgo, typescript, vanilla, vite, vite-awesome-svg-loader, vite-loader, vite-plugin, vite-svg, vue, web-components

## 简介

A universal Vite SVG loader. Imports SVGs as source code, base64 and data URI. Preserves stroke width. Replaces colors with currentColor or custom colors. Creates SVG sprites. Optimizes SVGs.
