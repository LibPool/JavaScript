# vue-toast-tailwind

> 标签: alert, component, composition-api, headless, notifications, plugin, popup, snackbar, tailwind, tailwind-toast, tailwindcss, tailwindcss4, toastify, typescript, vue, vue-toast, vue-toastification, vue3, vue3-toast

## 简介

A lightweight, modern, and highly customizable Vue 3 toast notification plugin using Tailwind CSS v4 and TypeScript. Supports dark mode, dynamic components, and generic props.
