# vatucheck

> 标签: JavaScript

## 简介

Uma biblioteca de validação de esquemas para JavaScript e TypeScript desenvolvida com foco em **performance extrema, mensagens diretas e tamanho de pacote ultraleve**. Totalmente compatível com ES Modules (import) e CommonJS (require).
