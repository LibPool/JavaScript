# vite-plugin-components-plus

> 标签: vite, vite-plugin, vite-plugin-components-plus, vue3

## 简介

一个可以自动重命名index.vue的vite插件，自动给index.vue组件重命名为文件夹的名称，也可手动使用name属性来命名组件
