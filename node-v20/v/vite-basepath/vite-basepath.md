# vite-basepath

> 标签: assets, base, base-path, basename, deploy, plugin, relative-path, router, subdirectory, subfolder, vite, vite-plugin

## 简介

Vite plugin: relative base (./) builds that work in any subdirectory, with runtime path detection for routers
