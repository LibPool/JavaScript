> 标签: ai, automation, claude, claude-code, deployment, devops, mcp, model-context-protocol, vercel

## 简介

The most complete Vercel MCP server — 65+ typed tools covering the entire Vercel REST API (deployments, projects, env vars, domains, DNS, aliases, certs, logs, checks, webhooks, edge config, teams) plus a vercel_raw escape hatch and a readonly safety mode
