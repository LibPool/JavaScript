# vessel-cli

> 标签: .vessel, bundle, cli, fastapi, local-first, pyodide, sqlite, vessel

## 简介

Author, develop, package, and inspect Vessel (.vessel) tool bundles — a single file carrying a FastAPI/Python backend (run in Pyodide), a self-contained UI, and a SQLite database.
