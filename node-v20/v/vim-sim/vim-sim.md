# vim-sim

> 标签: editor, modal-editing, motions, operators, simulation, text-editor, text-manipulation, vim, vim-emulation, vim-engine

## 简介

A complete Vim editor simulation engine for Node.js. Implements motions, operators, visual mode, text objects, macros, marks, undo/redo tree, spell checking, and more. 
Check out my demo here: https://vim.colefoster.ca/demo
