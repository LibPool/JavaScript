# veilit

> 标签: credentials, gdpr, jwt, logger, logging, mask, obfuscate, password, pii, redact, redaction, sanitize, scrub, secrets, security, sensitive-data, token, typescript, zero-dependency

## 简介

Zero-config, zero-dependency deep redaction of secrets & PII from any value - by sensitive key names AND value patterns (JWTs, credit cards, AWS/GitHub/Stripe keys, private keys, URL passwords). Circular-safe, immutable, always JSON-serializable output.
