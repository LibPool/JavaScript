# vanilla-timezone-validation

> 标签: canonical-timezone, datetime, iana, intl, timezone, timezone-validation, timezones, type-guard, tz, tzdata, validation, zero-dependency

## 简介

A lightweight, zero-dependency, and tree-shakable library for validating IANA timezone strings via the native Intl API, including non-canonical (link) names.
