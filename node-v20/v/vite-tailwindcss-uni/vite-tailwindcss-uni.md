# vite-tailwindcss-uni

> 标签: JavaScript

## 简介

一个在uniapp中兼容使用tailwindcss写法的vite插件，使用postcss的class-rename功能和vite插件的transform功能修改uniapp打包后小程序中不支持的样式名

## 官网
