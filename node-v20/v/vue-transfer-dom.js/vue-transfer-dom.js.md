# vue-transfer-dom.js

> 标签: dom, dom-portal, dom-teleport, dom-transfer, portal, portal-dom, teleport, transfer, transfer-dom, vue

## 简介

A directive supported plugin for transfering DOM to another location in Vue.js 2.0 components.
