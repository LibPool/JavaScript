# vite-plugin-tailwind-uni

> 标签: JavaScript

## 简介

此插件为了解决uniapp中使用tailwindcss，遇到tailwindcss语法编译到微信小程序wxss，不支持`\[`、`\]`、`#`、`:`、`%`的问题,会将这些不能被wxss识别的class🥱转换成以下的形式
