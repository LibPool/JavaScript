# vite-antv-js-template

> 标签: JavaScript

## 简介

该模板使用`node`版本为`14+`，模板使用`Vite`作为框架，采用`Vue3`和`JS`作为开发语言。在 UI 方面采用`AntV`作为 UI 库。使用`Axios`作为 request 库。使用`Vue-Router 4`作为路由库。使用`Pinia`作为状态管理库。
