# vue-modified

> 标签: JavaScript

## 简介

A simple directive plugin for [Vue 0.11.x](http://vuejs.org/) that lets you know when your v-models have been modified. Based off of [Vue Validator](https://github.com/xrado/vue-validator) by Radovan Lozej.
