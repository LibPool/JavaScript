# vite-rgbify

> 标签: css, fivem, nui, oklab, oklch, plugin, rgb, tailwind, vite

## 简介

Vite plugin that converts modern CSS colors (oklch, oklab, lab, lch, color-mix) to rgb/rgba for FiveM NUI compatibility
