# vue3-scroll-number

> 标签: TypeScript, scroll number, vue3, vue3-scroll-number

## 简介

基于 vue3+ts 实现的数字滚动动效，支持日期格式，支持数字格式化中的相关符号，如有遗漏的符号，请在 issues 中告知我
