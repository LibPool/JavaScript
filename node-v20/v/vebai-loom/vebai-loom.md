# vebai-loom

> 标签: axios, dynamic-form, http, permission, typescript, vue, vue3

## 简介

Core toolkit for Vue 3 admin apps: axios-based HTTP with request dedupe and caching, login/menu permissions and dynamic routes, list handlers, plus a render-agnostic dynamic-form engine. No UI component library dependency.
