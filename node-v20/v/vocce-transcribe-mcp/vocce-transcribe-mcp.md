# vocce-transcribe-mcp

> 标签: ai-agent, audio, claude, mcp, model-context-protocol, speech-to-text, srt, subtitles, transcribe, transcription, video, vtt, whisper

## 简介

MCP server for vocce's hosted media tools: transcription, summaries, study notes, flashcards, document Q&A, and PDF compression. No API key required.
