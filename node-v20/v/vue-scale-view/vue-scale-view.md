# vue-scale-view

> 标签: adaptive, component, container, cover, dashboard, data-v, datav, fullscreen, large-screen, resize, responsive, scale, transform, visualization, vue, vue3

## 简介

Vue 3 viewport scale container — scales children to fill the screen without black bars (cover mode). With min-width/min-height guard. Ideal for large-screen dashboards and data visualization.
