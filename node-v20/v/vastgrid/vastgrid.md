# vastgrid

> 标签: big-data, canvas, csv, data-grid, datagrid, parquet, react, spreadsheet, virtual-scroll

## 简介

A canvas data grid for React that opens CSV, TSV, Parquet and JSON Lines files of any size, with spreadsheet selection, sorting, filters and statistics.
