# vuepress-image

> 标签: avif, image, vuepress

## 简介

分析 VuePress 文档中的图片链接并下载,可将图片转码为 Avif 格式,更加节省空间

## 官网

- 官网：https://www.itldg.com
- 源码仓库：git+https://github.com/itldg/vuepress-image.git
- npm 页面：https://www.npmjs.com/package/vuepress-image
