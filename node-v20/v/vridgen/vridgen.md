# vridgen

> 标签: checksum, generator, id, identifier, uid, verifier

## 简介

Verifiable Random ID Generator(vridgen) is a package that lets you create not just a random id, but a random id that you can as well verify its integrity anytime. IDs generated can be verified client side before performing other function on it.
