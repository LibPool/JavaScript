# vis3d-sdk

> 标签: 3d, 3dtiles, cesium, gis, map, measure, plot, viewshed, vis3d

## 简介

Vis3D 三维 GIS 功能库（基于 Cesium）：地图初始化、底图/地形、图层树、标绘、量算、通视/可视域/日照/地形/倾斜模型分析、卷帘分屏、天气特效、高清导出、无人机回放等，全部以「配置对象 + 方法调用」形式暴露，不含任何 UI，样式由业务方自行编写。
