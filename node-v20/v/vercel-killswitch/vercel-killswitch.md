# vercel-killswitch

> 标签: automatic budget control, killswitch, nextjs, panic, project pause, spend management, vercel, webhook

## 简介

Automatically pauses your Vercel project when spend limits are reached. This Next.js App router module integrates with Vercel's Spend Management to trigger a project pause via webhook.
