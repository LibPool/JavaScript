# vuemapped

> 标签: frontend, gis, google, js, map, mapbox, maplibre, ts, vite, vue, yandex

## 简介

Vue 3 component library for [MapLibre GL JS](https://maplibre.org/). Declarative, reactive map layers with full TypeScript support.
