# vue-language

> 标签: JavaScript

## 简介

+ 作用   + vue项目中简单的切换语言   + 不能够切换elementUI自带的组件内部语言,像日期控件、分页控件等 + 使用  + npm install vue-language  + src下新建utils目录新建language目录新建index.js
