# vortex-re

> 标签: ai-tools, cli, evidence, mcp, model-context-protocol, reverse-engineering, rust, security, static-analysis

## 简介

Local-first, AI-oriented reverse-engineering toolkit: evidence-backed static analysis of software you are authorized to inspect, with CLI and MCP interfaces. Inspected targets are never executed.
