# vue-cli-plugin-mock-hz

> 标签: JavaScript

## 简介

此插件为 **vue-cli** 的扩展，用于在 **vue-cli-service serve** 命令运行的时候，通过向 @vue/cli-service 插件内部使用的 webpack-dev-server 启动的 server 添加中间件，来实现接口本地 mock 功能，同时此插件还支持后端导出的 swagger.json 文件自动解析为 mock 接口配置
