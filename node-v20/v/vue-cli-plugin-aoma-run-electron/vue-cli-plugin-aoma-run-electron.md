# vue-cli-plugin-aoma-run-electron

> 标签: JavaScript

## 简介

本插件做了以下事情 1.在vue serve运行成功后，启动electron 2.将serve启动后的url，赋值与process.env.NODE_VUE_SERVE_URL 3.在electron关闭的时候，关闭serve服务
