# vue3-painter-board

> 标签: JavaScript

## 简介

一个基于vue3+vite+canvas的简单画板，支持画笔、橡皮擦、清空画布、保存图片等功能, 多用于实现项目中电子签名功能，大家也可以自行扩展使用，希望对大家有所帮助 > 本插件用于学习交流，遵循开源协议，请勿用于非法用途。
