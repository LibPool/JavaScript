# v-loading-plugin

> 标签: async, loading, loading-plugin, vue, vue-loading, vue-loading-plugin

## 简介

基于vue的自动获取异步函数的状态用于显示loading,Automatic acquisition of asynchronous function status based on Vue for display loading
