# vjs-owl-carousel

> 标签: JavaScript

## 简介

Just another vuejs wrapper for [OwlCarousel](https://owlcarousel2.github.io/OwlCarousel2/). Inspired by [Vue-Own-Carousel](https://github.com/s950329/vue-owl-carousel).
