# vue-2-virtual-scroll-tree

> 标签: JavaScript

## 简介

element-plus中提供了一个虚拟树，针对大量数据的处理做了优化。而elementUi中则缺少此类组件，因此vue-virtual-scroll-tree将提供该项能力。
