# vite-plugin-proxy-enhancer

> 标签: cookie, cookie-rewrite, cors, dev-server, http-proxy, logging, proxy, samesite, set-cookie, vite, vite-plugin, websocket

## 简介

A powerful Vite plugin that enhances the dev server proxy with cookie rewriting (Domain/Path/Secure/SameSite), proper multiple Set-Cookie handling, per-proxy defaults, WebSocket logging, and granular request monitoring.
