# @taiga-ai/monitor-web

> 标签: monitoring, rum, taiga, telemetry, web-vitals

## 简介

Taiga app monitoring — a tiny, self-contained RUM beacon (Core Web Vitals, JS errors, client-observed API health) for apps built with Taiga.
