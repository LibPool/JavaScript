# @apicity/kimicoding

> 标签: ai, anthropic, apicity, chat, k2p5, kimi, kimicoding, streaming

## 简介

Kimi for Coding provider for Apicity - completely standalone with Anthropic Messages API format, streaming-first, and built-in middleware.
