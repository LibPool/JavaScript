# koishi-plugin-docs-sandbox

> 标签: api, chatbot, docs, kkk, koishi, playground, plugin, sandbox, self-use

## 简介

【自用】把 bot 的真实指令变成在线沙盒 API：文档站 / 控制台都能直接试运行指令，支持多轮会话、图片、语音（SILK 转码）与文件，附件可直接给网络 URL 由沙盒代拉，沙盒用户自带头像（默认文档里麦麦的）
