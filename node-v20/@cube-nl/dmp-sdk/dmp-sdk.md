# @cube-nl/dmp-sdk

> 标签: JavaScript

## 简介

Dependency-free TypeScript client for the Cube DMP REST API (cube/api), with OAuth 2.1 + PKCE, and CubeApp for no-build apps (preview on mock data, live on the DMP).
