# @sarv-in/mailguard

> 标签: anti-spam, authentication-results, dkim, dmarc, email, email-security, imap, mail, phishing, spam, spam-filter, spf

## 简介

Explainable spam and phishing signals for email, computed offline from the message itself. Reads SPF/DKIM/DMARC results, sender-domain spoofing and the true origin IP out of the headers, and returns a score with human-readable reasons.
