# @sarv-in/email-chat-view

> 标签: chat, email, imap, mail, quote-stripping, react, reply-parser, signature, thread

## 简介

Turn an email thread into a chat-style conversation view. Provider-rule-driven quote/signature/disclaimer stripping plus a React chat UI.
