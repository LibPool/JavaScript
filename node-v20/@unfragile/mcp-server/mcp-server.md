# @unfragile/mcp-server

> 标签: agents, ai, answer-engine, discovery, ed25519, mcp, mcp-server, tools, trust, trust-passport, unfragile, verification

## 简介

The Unfragile MCP server — one verified answer over the invokable universe: fresh (crawled weekly), tested (machine-verified, honest tiers), signed (Ed25519 trust passports). Answer, search, verify-before-invoke, resolve, passports, census.
