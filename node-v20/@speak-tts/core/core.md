# @speak-tts/core

> 标签: audio, bcp-47, browser, framework-agnostic, highlight, speak, speech-synthesis, speechsynthesis, text-to-speech, tts, typescript, vanilla, vanilla-js, voice, webspeech, webspeech-api

## 简介

Framework-agnostic text-to-speech controller powered by the Web Speech API. Real-time word highlighting, dynamic mid-speech controls, automatic chunking for long text, and audio download.
