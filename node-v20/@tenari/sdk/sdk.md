# @tenari/sdk

> 标签: JavaScript

## 简介

Tenari embed SDK — framework-free core shared across embeds: the public REST API client, public types, formatting/DOM utils, the design-token theme layer, a tiny event bus, and a Shadow-DOM mount helper.
