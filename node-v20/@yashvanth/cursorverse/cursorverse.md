# @yashvanth/cursorverse

> 标签: animation, canvas, cursor, cursor-effects, custom-cursor, interactive-ui, particles, react, trail, webgl

## 简介

Lightweight, customizable canvas cursor effects library for React and vanilla JavaScript. Includes fire, confetti, glow, snow, spark, ripple, magnetic, and trail effects for interactive web experiences and creative UI animations.
