# nestjs-request-tracer

> 标签: axios, call-tree, debug, devtools, nest, nestjs, prisma, request, tracing

## 简介

See every function call, argument, result, database query and outgoing HTTP call a NestJS request makes — as a tree, in a built-in web viewer. One line in main.ts.
