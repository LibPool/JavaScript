# @bajustone/fetcher

> 标签: api-client, fetch, http-client, openapi, standard-schema, typed, typescript, valibot, validation, zod

## 简介

Schema-validated, typed fetch client with OpenAPI support. Standard Schema V1, zero dependencies, runs on Node, Bun, Deno, browsers, and edge workers.
