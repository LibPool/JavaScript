# @tari-project/ootle-secret-key-wallet

> 标签: JavaScript

## 简介

Local in-memory `Signer` for the Tari Ootle SDK, backed by WASM crypto. **Testing / scripting use only** — the secret key lives unencrypted in JS memory. For production, prefer [`@tari-project/ootle-wallet-daemon-signer`](../ootle-wallet-daemon-signer/REA
