# @adamcjm/dsh-memo

> 标签: deepseek-harness, dsh, memo, notes, plugin, sqlite

## 简介

Memo plugin for DeepSeek Harness: sidebar quick capture, local SQLite storage, private GitHub repo sync, and image/screenshot support.
