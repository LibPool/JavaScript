# @adamcjm/lark-skill

> 标签: agent-skill, agent-skills, ai-agent, claude-code, codex, feishu, lark, lark-cli, pi, skill, zcode, 飞书

## 简介

Expose Feishu/Lark to your coding agent as ONE skill instead of 27. Vendors the official larksuite/cli skills and routes to them on demand. Works with pi and zcode.
