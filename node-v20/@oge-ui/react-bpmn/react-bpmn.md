# @oge-ui/react-bpmn

> 标签: accessibility, bpmn, bpmn-2.0, diagram, flowchart, process-modeler, react, typescript, workflow

## 简介

React BPMN 2.0 editor from the OGE UI suite: palette click-then-place and drag-to-canvas, context pad connect/append, inline label editing, orthogonal routing, snapping with guides, pools and lanes, boundary events, sub-processes, a properties panel, mini
