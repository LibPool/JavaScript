# @oge-ui/overlay

> 标签: angular, context-menu, dialog, modal, notifications, overlay, popup, signals, toast, tooltip

## 简介

Angular overlay primitives: anchored popups, menus, tooltips, context menus, a full-featured modal dialog (focus trap, Escape stack, drag/resize) and toast notifications.
