# @oge-ui/charts-engine

> 标签: chart-engine, charts, data-visualization, headless, scales, svg, typescript

## 简介

Framework-free engine behind the OGE UI charts (Angular @oge-ui/charts and React @oge-ui/react-charts): nice-tick, log, category and calendar-true time scales, series normalization, stacking and bar slotting, single-path and LTTB-downsampled path builders
