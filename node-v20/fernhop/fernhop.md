# fernhop

> 标签: agent, claude, delegation, mcp, model-context-protocol, opencode, opencode-bridge

## 简介

OpenCode bridge for Claude: an MCP server that lets Claude (or any MCP client) delegate tasks to OpenCode through one shared, self-healing opencode serve.
