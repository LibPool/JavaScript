# @ikaros-arch/3dhop

> 标签: 3d, 3dhop, cultural-heritage, nexus, viewer, webgl

## 简介

Unofficial npm packaging of the 3DHOP viewer runtime (CNR-ISTI Visual Computing Lab): upstream 4.3 + the 4.3.5 patch set, jQuery-free. Runtime assets only; use with @ikaros-arch/react-3dhop.
