# @gooliya/port-bar-mcp

> 标签: devserver, macos, mcp, model-context-protocol, port

## 简介

Read-only MCP server for Gooliya Port Bar — query locally listening dev-server and Docker ports over stdio (list_ports, list_idle_ports). No install of the GUI app or a Rust toolchain required: npx -y @gooliya/port-bar-mcp
