# @comfortcss/flex

> 标签: accessible, css, flexbox, layout, lightweight, modern

## 简介

Modern atomic CSS for Flexbox. Implemented using logical properties, zero-specificity selectors, and a clean architecture. Part of the ComfortCSS ecosystem.
