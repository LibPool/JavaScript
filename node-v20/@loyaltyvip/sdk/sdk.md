# @loyaltyvip/sdk

> 标签: api, casino, comps, loyalty, loyaltyvip, rewards, sdk, tiers

## 简介

Typed, zero-dependency TypeScript/JavaScript client for the LoyaltyVIP API (casino player intelligence: directory, tiers, trips, offers, comps, tax).
