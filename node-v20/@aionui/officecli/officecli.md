# @aionui/officecli

> 标签: cli, docx, excel, office, ooxml, powerpoint, pptx, word, xlsx

## 简介

OfficeCLI — CLI for reading and writing Office documents (.docx, .xlsx, .pptx) via a document DOM API. The native binary is fetched on install for your platform.
