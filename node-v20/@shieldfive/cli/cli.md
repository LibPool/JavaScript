# @shieldfive/cli

> 标签: backup, cli, client-side-encryption, encryption, end-to-end-encryption, post-quantum, shieldfive, sync, zero-knowledge

## 简介

Open-source command-line client for ShieldFive: encrypt a folder on your machine and sync it to your EU-hosted, post-quantum vault. Read the code; it encrypts before upload.
