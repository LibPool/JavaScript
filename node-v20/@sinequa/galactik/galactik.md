# @sinequa/galactik

> 标签: JavaScript

## 简介

Angular UI primitives built on top of [`@angular/aria`](https://www.npmjs.com/package/@angular/aria), [`@floating-ui/dom`](https://floating-ui.com/) and [`class-variance-authority`](https://cva.style/), designed to be composed and themed with Tailwind CSS
