# @binary-brawlers/filebase-react-native

> 标签: JavaScript

## 简介

React Native / Expo SDK for uploading files to a [FileBase](https://github.com/binary-brawlers/filebase) upload gateway. Works with `expo-image-picker`, `expo-document-picker`, `react-native-image-picker`, and any other source that gives you a local `uri`
