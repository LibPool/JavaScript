# @dy-kit/gradient-parser

> 标签: JavaScript

## 简介

一个轻量的 CSS 渐变解析与字符串化工具，支持将 linear-gradient(...)、radial-gradient(...) 等解析为 AST、再序列化回 CSS，或转换为 SVG <linearGradient>/<radialGradient> 片段。
