# @ai2web/connector

> 标签: agentic, ai-agents, ai2web, chatgpt, claude, connector, discovery, mcp

## 简介

Agent-side AI2Web connector - an MCP server that fronts the Discovery Network so Claude/ChatGPT can find AI-ready sites and act on them.
