# @agentpulselabs/pulse

> 标签: agent, agentpulse, architecture, claude-code, codex, cursor, discipline, mcp

## 简介

Portable, contract-enforced build discipline for coding agents (Claude Code, Cursor, Codex, …). A pure phase state machine + pluggable architecture contract + validator + gate runner. Ships the brain; the host provides the model, UI, and human.
