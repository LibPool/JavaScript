# @chiefaia/skills-registry

> 标签: JavaScript

## 简介

Foundational typed registry for agent skills (capabilities). Lets agents declare what they can do, lets the orchestrator query/match by capability + tags + cost class, and provides an in-memory store with discriminated-union manifest schema (Zod) for runt
