# @pelagic-ui/three

> 标签: 3d, 3d-chart, a11y, accessibility, accessible, component-library, globe, gltf, particles, pelagic-ui, react, reduced-motion, three, threejs, ui-library, webgl

## 简介

Pelagic UI WebGL 3D for React — accessible, theme-aware Three.js components (Scene3D, Globe3D, ParticlesField, FloatingShapes, ModelViewer, Chart3D) with reduced-motion, off-screen pausing and static fallbacks.
