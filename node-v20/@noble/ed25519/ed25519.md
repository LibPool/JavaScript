# @noble/ed25519

> 标签: cryptography, curve25519, ed25519, eddsa, elliptic curve, fips186, noble, rfc7748, rfc8032, signature, x25519, zip215

## 简介

Fastest 5KB JS implementation of ed25519 EDDSA signatures compliant with RFC8032, FIPS 186-5 & ZIP215
