# @poolse/react-native

> 标签: android, chat, chat-sdk, expo, expo-chat, expo-router, in-app-chat, in-app-messaging, ios, messaging, mobile-chat, poolse, react-native, react-native-chat, react-native-messaging, realtime, realtime-chat, sendbird-react-native, stream-chat-react-native, typescript

## 简介

React Native chat SDK for Expo and bare RN. Drop-in ConversationView + PoolseInbox with camera, attachments, markdown, AppState lifecycle, KeyboardAvoidingView baked in. JS theme tokens. MIT — alternative to sendbird-chat-react-native and stream-chat-reac
