# @slicemenice/jquery-ui-svg

> 标签: SVG, Sprite, jQuery UI

## 简介

A jQuery UI widget based component that will initialize itself with a clone of the referenced element, so the resulting SVG can be manipulated individually using CSS and JavaScript
