# @fressh/react-native-xtermjs-webview

> 标签: android, expo, ios, react-native, ssh, terminal, webview, xterm

## 简介

React Native WebView that embeds [xterm.js](https://xtermjs.org/) with sensible defaults and a bridge for input and output.
