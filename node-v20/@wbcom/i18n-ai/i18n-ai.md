# @wbcom/i18n-ai

> 标签: ai, claude, gettext, grunt, i18n, l10n, po, pot, translation, wordpress

## 简介

AI-translate WordPress plugin/theme .po files: sync new strings (msgmerge), translate (Claude), validate placeholders, compile .mo + .json. Wires into grunt/release.
