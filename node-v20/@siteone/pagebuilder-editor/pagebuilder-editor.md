# @siteone/pagebuilder-editor

> 标签: JavaScript

## 简介

Main package used in projects to display editable page. Companion of @siteone/pagebuilder-renderer which is used for rendering page.

## 官网

- 源码仓库：git@git.siteone.cz:frontend-private/page-builder.git
- npm 页面：https://www.npmjs.com/package/@siteone/pagebuilder-editor
