# @sneeai/sneeai-agent

> 标签: JavaScript

## 简介

本地 Canvas Agent 用来连接画布网页和用户电脑上的 Codex / Claude Code。本地 Agent 不部署到云端，网站和生成后端运行在 `sneeai.com`。
