# @dshtrading/connector-alpaca

> 标签: JavaScript

## 简介

美股（us）行情与交易连接器：直连 Alpaca Market Data v2（IEX feed）与 Trading API v2（Paper/Live），实现 MarketDataService/TradeService 双契约，服务键 tradingUsMarketData/tradingUsTrade，三态闸门 + dry-run 缺省 + BYOK 凭证 ref。
