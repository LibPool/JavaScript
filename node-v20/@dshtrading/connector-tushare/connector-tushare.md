# @dshtrading/connector-tushare

> 标签: JavaScript

## 简介

Tushare Pro A 股连接器：提供 tradingCnMarketData 行情服务与 cn_get_ticker / cn_get_klines / cn_get_valuation 三个工具，Token 走 BYOK（tokenRef 指向环境变量）；无交易通道。
