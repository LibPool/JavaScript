# @anysearch-cli/dsh-plugin

> 标签: anysearch, cordis, deepseek-harness, dsh-plugin, mcp

## 简介

DeepSeek Harness (dsh) host adapter for anysearch: thin Cordis bundle — hooks layer only, all business logic stays in the anysearch server over 127.0.0.1 HTTP IPC
