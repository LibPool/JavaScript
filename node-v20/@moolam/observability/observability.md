# @moolam/observability

> 标签: JavaScript

## 简介

Internal component of Sutra SDK — applications should install sutra-sdk. Exporter-agnostic OpenTelemetry bridge for Sutra hosts: turn/sync spans and meters. OTLP, console, or noop via env — no vendor SDK on the data path.
