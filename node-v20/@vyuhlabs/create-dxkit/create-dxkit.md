# @vyuhlabs/create-dxkit

> 标签: bootstrap, create, dxkit, init, scaffold, vyuh

## 简介

One-command bootstrap for @vyuhlabs/dxkit. Detects your package manager (pnpm/yarn/bun/npm) to add it as a devDependency, then runs `vyuh-dxkit init`.
