# @evenfall/gba-game-plugins

> 标签: JavaScript

## 简介

Unofficial Pokémon party, storage and battle bridges plus player panels for the Evenfall player. Decodes the user's own ROM at runtime; bundles no game data beyond the standard type chart. Not affiliated with Nintendo, Creatures Inc., GAME FREAK inc. or T
