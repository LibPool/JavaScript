# volition-agent

> 标签: agent-security, ai-agents, approvals, claude-code, cursor, guardrails, hooks

## 简介

Guard the AI coding agents in your repo (Claude Code, Cursor). One command installs pre-tool hooks: risky actions ask you first, dangerous ones are blocked.
