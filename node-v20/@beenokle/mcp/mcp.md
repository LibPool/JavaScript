# @beenokle/mcp

> 标签: beenokle, claude, cli, connector, dos, mcp, model-context-protocol, tasks

## 简介

Stdio↔HTTP connector that links a local MCP client (Claude Desktop, …) to your Beenokle workspace (Dos tasks today) with a personal API key. Run with `npx @beenokle/mcp` (ADR-0045/0046).
