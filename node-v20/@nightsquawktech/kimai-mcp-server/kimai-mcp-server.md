# @nightsquawktech/kimai-mcp-server

> 标签: ai-agent, claude, cursor, kimai, llm, mcp, mcp-server, model-context-protocol, modelcontextprotocol, self-hosted, time-tracking, timesheet

## 简介

Kimai MCP server for Claude, Cursor, and AI agents: 16 tools covering the entire Kimai API. 13 curated time-tracking tools plus a 91-endpoint catalog, with per-call authorization, pre-write backups, cascade snapshots, and an environment gate on deletes.
