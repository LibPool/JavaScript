# dsh-auth-hub

> 标签: account, auth, channel-pack, checkin, credit, deepseek-harness, dsh, dsh-plugin, rotation

## 简介

统一账号中心：13 个内置账号渠道 + 自己加的签到渠道（一键识别 New API 中转站 / 批量导入 / 粘 cURL，自动签到并把奖励记进同一个积分台账）+ WorkBuddy 双区登录，全部收在一个设置页（界面风格对齐 DSH WorkBuddy）。
