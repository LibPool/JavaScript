# @zy-frontend/business

> 标签: JavaScript

## 简介

基于 Vue 3 + TypeScript + Element Plus 的中后台业务组件库，提供检索、列表、图表、布局、评分等开箱即用的配置化组件，以及配套的 Hooks / Utils / Service 层。
