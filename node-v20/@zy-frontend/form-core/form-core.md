# @zy-frontend/form-core

> 标签: JavaScript

## 简介

- 👍简洁的配置规则 - 📦与UI库解耦，兼容多端，可自定义样式 - ⚙️支持主动/被动联动，可实现复杂的字段/表单间的联动关系 - ⚔️支持单表单、多表单两种模式 - 🛡️支持分级字段校验 - ☁️支持远程加载选项列表
