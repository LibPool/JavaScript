# @kaynewang/inline-ruby-ja

> 标签: JavaScript

## 简介

将日文文本中的行内ルビ语法（`漢字《かんじ》`、`｜漢字《かんじ》`）批量转换为 HTML `<ruby>` 标签的轻量级 TypeScript 库。构建入口位于 `dist/index.js`，默认导出纯函数 API，可直接用于浏览器、Node.js 或任何构建流程。
