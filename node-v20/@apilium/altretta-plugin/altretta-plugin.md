# @apilium/altretta-plugin

> 标签: altretta, apilium, cli, plugin, sign

## 简介

The altretta-plugin author CLI: keygen, pack (sign), and verify Altretta plugins. Ships a prebuilt native binary per platform, resolved at run time.
