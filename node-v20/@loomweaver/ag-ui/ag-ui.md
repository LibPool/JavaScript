# @loomweaver/ag-ui

> 标签: ag-ui, agent, agentic-ui, loomweaver, plugin-platform, tool-calling

## 简介

LoomWeaver: open-source plugin platform for Angular workbenches. The AG-UI adapter: offers the workbench's own commands to an agent and runs what it asks for. Headless, with no transport, no UI and no agent.
