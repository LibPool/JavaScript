# @aegiskit/core

> 标签: appsec, content-security-policy, csp, csrf, edge, nextjs, rate-limiting, security, security-headers

## 简介

Framework-agnostic, edge-safe security primitives for Aegis: CSP, security headers, rate limiting, CSRF/origin, typed env, and security events.
