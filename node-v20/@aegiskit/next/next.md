# @aegiskit/next

> 标签: app-router, appsec, csp, csrf, middleware, nextjs, security, security-headers

## 简介

Next.js (App Router) security adapters for Aegis: secure() middleware, secureRoute() handler wrapper, getNonce(), and a server-only env boundary.
