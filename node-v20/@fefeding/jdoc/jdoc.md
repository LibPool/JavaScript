# @fefeding/jdoc

> 标签: docx, generator, office, parser, pdf, pptx, xlsx, 文档生成, 文档解析

## 简介

文档解析与生成统一库：支持 PPTX / DOCX / XLSX / PDF 的解析与生成，纯 TypeScript，浏览器与 Node.js 双端可用
