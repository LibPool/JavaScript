# @5dive/telegram-codex-mcp

> 标签: bot, bridge, codex, mcp, openai, telegram

## 简介

Telegram bridge for OpenAI Codex CLI, delivered as a stdio MCP server: wait for messages, reply, edit, react, and download attachments from a Telegram bot.
