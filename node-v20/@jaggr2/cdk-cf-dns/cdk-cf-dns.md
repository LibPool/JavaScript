# @jaggr2/cdk-cf-dns

> 标签: aws, cdk, cloudflare, cloudformation, dns, route53

## 简介

Manage Cloudflare DNS records as CloudFormation resources from AWS CDK, so Route 53 hosted zones are no longer needed.
