# @esm2cjs/fetch-blob

> 标签: blob, file, node-fetch

## 简介

Blob & File implementation in Node.js, originally from node-fetch.. This is a fork of node-fetch/fetch-blob, but with CommonJS support.

- 官网：https://github.com/node-fetch/fetch-blob#readme
- 源码仓库：git+https://github.com/esm2cjs/fetch-blob.git
- npm 页面：https://www.npmjs.com/package/@esm2cjs/fetch-blob
