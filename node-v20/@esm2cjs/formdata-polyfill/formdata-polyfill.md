# @esm2cjs/formdata-polyfill

> 标签: browser, fetch, formdata, html5, node-fetch, polyfill

## 简介

HTML5 `FormData` for Browsers and Node.. This is a fork of jimmywarting/FormData, but with CommonJS support.

- 官网：https://github.com/jimmywarting/FormData#readme
- 源码仓库：git+https://github.com/esm2cjs/formdata-polyfill.git
- npm 页面：https://www.npmjs.com/package/@esm2cjs/formdata-polyfill
