# @rolaca11/mcp-inspector

> 标签: cli, client, dashboard, inspector, mcp, model-context-protocol, oauth

## 简介

MCP client for discovering and exercising resources, tools, prompts, and completions over stdio or OAuth-protected HTTP. Ships with a CLI, an interactive REPL, and a web dashboard served by `mcp-inspector serve`.
