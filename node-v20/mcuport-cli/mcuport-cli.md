# mcuport-cli

> 标签: agent, arduino, cli, esp32, mcp, microcontroller, raspberry-pi-pico

## 简介

Command-line client for the MCUPort account API: who you are, Pro entitlement status, licence key verification, and the latest device MCP server version. Same API and same API key as the MCP server at https://mcuport.com/mcp.
