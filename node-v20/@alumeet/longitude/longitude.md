# @alumeet/longitude

> 标签: cli, data-portability, health-data, jsonl, local-first, mcp, self-tracking, wearables

## 简介

Local-first health data CLI: import wearable and health-app exports into inspectable JSONL files, with a read-only MCP server for your own tools and agents.
