# @cujuju/solidjs-pill-number-picker

> 标签: input, number-picker, solidjs, spinbutton, stepper

## 简介

Compact number stepper for SolidJS — 8 layouts, optional collapse-to-value with a portalled pop-out editor, commit-on-change or commit-on-finish, auto-repeat with acceleration, full spinbutton a11y, RTL-ready.
