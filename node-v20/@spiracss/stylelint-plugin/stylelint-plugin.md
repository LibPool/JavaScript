# @spiracss/stylelint-plugin

> 标签: architecture, bem, css, lint, rscss, scss, smacss, spiracss, stylelint, stylelint-plugin

## 简介

Stylelint plugin enforcing SpiraCSS conventions for class structure, property placement, interaction scope/properties, keyframes naming, pseudo nesting, page layer, and rel-comment links.
