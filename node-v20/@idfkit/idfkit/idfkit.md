# @idfkit/idfkit

> 标签: building-energy, energyplus, epjson, idf, simulation

## 简介

The shared install name for idfkit in JavaScript: subpath re-exports of @idfkit/core, @idfkit/schemas and the optional @idfkit/weather and @idfkit/language
