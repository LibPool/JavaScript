# @bojackduy/opencode-system-override

> 标签: agent, opencode, opencode-plugin, prompt, raw, system-override, system-prompt

## 简介

Overwrite the OpenCode system prompt per agent — a raw-system hook that replaces the assembled system with the prompt between markers in your agent file.
