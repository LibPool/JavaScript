# @sparklogs/redact-react

> 标签: logs, pii, privacy, react, redaction, upload

## 简介

Reusable React wizard for in-browser, redact-locally-then-upload flows. Classifies files, redacts PII with @sparklogs/redact-core, shows a before/after preview, and hands a redacted payload to a host-supplied onSubmit. Themeable via CSS variables; transpo
