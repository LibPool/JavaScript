# @xliic/preserving-json-yaml-parser

> 标签: JavaScript

## 简介

YAML/JSON parser and serializer that preserves formatting of the original numerical values (i.e. 1.0 vs 1) and handles integers bigger than MAX_SAFE_INTEGER
