# @pungoyal/kite-cli

> 标签: algo-trading, bse, cli, kite, kite-connect, kiteconnect, nifty, nse, stocks, terminal, trading, trading-api, zerodha

## 简介

Unofficial, safety-first CLI (and library) for the Zerodha Kite Connect v3 API — scriptable JSON, live streaming, and confirmations on anything that moves money. Not affiliated with or endorsed by Zerodha.
