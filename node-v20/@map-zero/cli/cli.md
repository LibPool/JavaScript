# @map-zero/cli

> 标签: 3d-tiles, geopackage, geospatial, gis, mvt, offline-maps, openstreetmap, osm, pmtiles, vector-tiles

## 简介

Portable vector maps from OSM or custom geospatial data, with GeoPackage storage, PMTiles delivery, and static 3D Tiles export.
