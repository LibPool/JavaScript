# @carrierllc/cli

> 标签: carrier, claude-code, claude-plugin, create, esim, mcp, mvno, scaffold, storefront, telecom, white-label

## 简介

Carrier CLI — installs the Carrier Claude Code plugin (natural-language MVNO/eSIM fleet control) and scaffolds a white-labeled eSIM storefront from the Mango template. One command from zero to a live connectivity business.
