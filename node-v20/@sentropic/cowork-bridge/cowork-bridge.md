# @sentropic/cowork-bridge

> 标签: JavaScript

## 简介

Portable client bridge for Sentropic Cowork: shared client core (ApiClient/ContextProvider/NavigationAdapter), transport/storage-agnostic auth (token lifecycle behind a StorageAdapter + injected fetch), and local-tool protocol types + portable permission
