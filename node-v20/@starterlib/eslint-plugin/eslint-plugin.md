# @starterlib/eslint-plugin

> 标签: eslint, eslintplugin, socle-frontal, starter

## 简介

Regles ESLint du socle frontal starter (gabarits et code des SPA) : no-raw-interactive, no-literal-text, no-angular-locale-pipes, route-has-title, no-toast-danger, no-free-text-query-param. Active par @starterlib/eslint-config.
