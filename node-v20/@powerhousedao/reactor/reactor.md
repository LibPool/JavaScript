# @powerhousedao/reactor

> 标签: cqrs, decentralized, document-model, event-sourcing, local-first, powerhouse, reactor, sync, vetra

## 简介

Core Powerhouse reactor — stores documents, resolves conflicts, and reprocesses operation histories. Supports local, cloud, and decentralized storage backends.
