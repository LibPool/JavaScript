# @surfrank/mcp-server

> 标签: ai-visibility, claude, cursor, mcp, model-context-protocol, surfrank

## 简介

Model Context Protocol server for SurfRank — let any MCP-compatible AI agent (Claude Desktop, Claude Code, Cursor, Windsurf, ChatGPT connectors) call the SurfRank public API.
