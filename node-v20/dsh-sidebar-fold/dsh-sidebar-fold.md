# dsh-sidebar-fold

> 标签: align, collapse, deepseek-harness, dsh, plugin, sidebar, ui

## 简介

Folds the sidebar's add-on panel rows (schedules, agent teams, plugin market, context pages, …) under the shipped "More" row: a 28×28 square toggle collapses them to that single header line and expands them back. The fold state persists per window, kept-v
