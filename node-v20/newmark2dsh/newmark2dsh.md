# newmark2dsh

> 标签: computeruse, deepseek-harness, dsh-plugin, memorylab, newmark

## 简介

Newmark Core for DeepSeek Harness：MemoryLab、ComputerUse、Agent API、NewMate 陪伴内核与 heartBeat 重启投递，五个独立开关，共用 ~/.Newmark 用户库。
