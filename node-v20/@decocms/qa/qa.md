# @decocms/qa

> 标签: cli, data-qa, deco, e2e, ecommerce, junit, playwright, qa

## 简介

E2E QA test runner for deco.cx ecommerce stores. Runs a deterministic purchase journey against data-qa-marked DOM and emits JUnit XML + JSON report.
