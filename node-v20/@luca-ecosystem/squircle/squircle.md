# @luca-ecosystem/squircle

> 标签: accessible, components, css, design-system, framework, squircle, utilities

## 简介

Squircle — a CSS-first UI framework with squircle geometry, generous whitespace, and the Luca Ecosystem Theme. No build step required; no TypeScript required.
