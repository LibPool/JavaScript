# @megabytelabs/gitr

> 标签: JavaScript

## 简介

Creates a GitLab and GitHub repository and then sets up push updating from GitLab to GitHub.

- 官网：https://gitlab.com/megabyte-labs/npm/gitr
- 源码仓库：git+https://gitlab.com/megabyte-labs/npm/gitr.git
- npm 页面：https://www.npmjs.com/package/@megabytelabs/gitr
