# @mawaru/agent-runner

> 标签: JavaScript

## 简介

mawaru の実行ラッパー（Program / AI 両対応）。GitHub Actions runner 上で handler（nodes/program/）の実行またはエージェント CLI（Claude Code / Codex、非対話。nodes/ai/）の駆動を行い、config.json の env 宣言で secrets を絞り、結果を検証して mawaru へ報告する
