# @rootnative/icons

> 标签: icons, lucide, material-design-3, md3, phosphor, react-native, vector-icons

## 简介

Icon library adapters for RootNative — Lucide, Phosphor, and @expo/vector-icons resolvers with MDI-name compatibility.
