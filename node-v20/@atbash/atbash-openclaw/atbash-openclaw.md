# @atbash/atbash-openclaw

> 标签: atbash, audit, chromia, openclaw, plugin, policy, tool-audit

## 简介

OpenClaw ATBASH tool-audit plugin. Thin adapter that maps OpenClaw's before_tool_call hook onto @atbash/sdk.
