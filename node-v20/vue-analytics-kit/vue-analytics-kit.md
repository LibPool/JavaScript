# vue-analytics-kit

> 标签: analytics, consent, facebook-pixel, firebase-analytics, ga4, google-ads, google-tag-manager, gtag, inertia, meta-pixel, tiktok-pixel, tracking, vue, vue3

## 简介

One track() call, many destinations: a consent-aware Vue 3 plugin that fans analytics and marketing events out to GA4, Google Tag Manager, Google Ads, Meta Pixel, TikTok Pixel and Firebase Analytics.
