# @flouviahq/cli

> 标签: cli, cord, sandbox, setup, testing, webhooks

## 简介

CLI de Cord: inicia sesión desde el navegador, configura tu cuenta con IA, integra tu proyecto y prueba webhooks en tu localhost.
