# powershell-sandbox-mcp

> 标签: ai-agent, bash, mcp, model-context-protocol, powershell, pwsh, sandbox, stdio

## 简介

MCP server (stdio) untuk menjalankan script PowerShell (.ps1) dan bash (.sh) di sandbox terisolasi ringan: working dir khusus, env minimal, timeout, log, dan penjaga path.
