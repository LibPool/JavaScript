# @lpextend/ui-lp

> 标签: JavaScript

## 简介

LP-aware Vue UI components for Extend apps — entity selectors (SelectSkill, …) and detail tables, styled with ep-tokens. Source-only: consumers import .vue / .ts directly via Vite, and resolve the `css/ep-tokens` Sass via @lpextend/ui in their loadPaths.
