# @coderblock/cli

> 标签: ai, claude, cli, coderblock, cursor, fullstack, mcp, vibe-coding

## 简介

Official CLI and MCP server for Coderblock.ai — initialize, push, pull and manage Coderblock projects from your terminal or from Claude Code / Cursor.
