# @uwmd/core

> 标签: JavaScript

## 简介

Reference implementation of the UW Markdown standard — parser, validator, renderer, and CLI for .uw.md underwriting files.

- 源码仓库：git+https://github.com/UWMD-OSP/UW-Markdown.git
