# @xano-sdk/xanoscript

> 标签: codegen, toolchain, xano, xanoscript, xanosdk

## 简介

Renders a Xano SDK workspace to XanoScript — the language the Xano engine runs. A file-for-file port of the engine's encoder, proven byte-for-byte against the engine's own golden corpus.
