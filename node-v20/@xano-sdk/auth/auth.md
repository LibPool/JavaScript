# @xano-sdk/auth

> 标签: auth, authentication, backend, codegen, login, signup, xano, xanoscript, xanosdk

## 简介

Plug-and-play Xano authentication (signup/login/me + user, account, event_log tables) as typed Xano SDK defs. Authentication only - no roles, permissions, or route guards.
