# @brashkie/signalis-storage

> 标签: e2e-encryption, identity-store, prekey-store, session-store, signal-protocol, signalis, storage

## 简介

Decoupled storage layer for Signalis — canonical Signal-Protocol store interfaces plus in-memory and on-disk implementations, generic over crypto types via injected codecs. Zero crypto dependencies.
