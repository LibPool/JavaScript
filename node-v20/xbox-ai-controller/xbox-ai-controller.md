# xbox-ai-controller

> 标签: ai-agent, antigravity, claude-desktop, cursor, mcp, model-context-protocol, smartglass, xbox, xbox-one, xbox-series, xccs

## 简介

Model Context Protocol (MCP) server & AI Agent controller for Xbox One and Xbox Series consoles. Control power, games, media, volume, and virtual gamepad navigation using natural language.
