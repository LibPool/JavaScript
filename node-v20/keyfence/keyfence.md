# keyfence

> 标签: claude-code, credentials, dlp, hooks, proxy, redaction, secrets

## 简介

Secrets never leave your machine. A local redaction proxy + hooks for Claude Code: paste keys freely, the model only ever sees placeholders, and commands still work.
