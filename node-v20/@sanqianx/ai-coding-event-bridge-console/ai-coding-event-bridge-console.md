# @sanqianx/ai-coding-event-bridge-console

> 标签: JavaScript

## 简介

Durable AI coding event bridge, all in one: capture connectors and installers (Claude Code, Codex, OpenCode, ZCode), journal with commit boundaries and per-commit conversation sealing, headless query, and a local conversation explorer console.
