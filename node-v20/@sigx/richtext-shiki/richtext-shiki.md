# @sigx/richtext-shiki

> 标签: richtext, shiki, signalx, sigx, syntax-highlighting

## 简介

Shiki syntax highlighting for @sigx/richtext's DOM view — a lazily-loaded, cached highlighter behind the CodeHighlighter contract, as a plugin
