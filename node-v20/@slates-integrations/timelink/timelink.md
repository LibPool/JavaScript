# @slates-integrations/timelink

> 标签: JavaScript

## 简介

Track time for clients, projects, services, and users. Discover current Timelink string IDs with `list_records`, retrieve original provider records with `get_record`, and create, update, or delete records with the `manage_*_record` tools. Inspect running
