# @slates-integrations/twitch

> 标签: JavaScript

## 简介

Connect a Twitch user through OAuth or provide a user/app access token and its exact registered Client ID. Tokens are validated against Twitch before each invocation. App tokens have no human profile and are accepted only by native endpoints and delegated
