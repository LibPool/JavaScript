# @slates-integrations/mailcheck

> 标签: JavaScript

## 简介

Verify and validate email addresses for deliverability and trustworthiness. Check individual addresses with a trust score, submit lists for batch verification, monitor progress, and download completed results. Retrieves validation data from social network
