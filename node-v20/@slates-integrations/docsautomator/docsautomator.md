# @slates-integrations/docsautomator

> 标签: JavaScript

## 简介

Generate downloadable PDFs and Google Doc documents from templates using placeholder-based data mapping. Create, read, update, delete, and duplicate document automations. List template placeholders, duplicate Google Doc templates, and trigger document gen
