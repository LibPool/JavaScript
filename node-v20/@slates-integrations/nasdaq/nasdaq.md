# @slates-integrations/nasdaq

> 标签: JavaScript

## 简介

Query Nasdaq Data Link tables and historical time-series datasets, search the data catalog, inspect database metadata, and prepare downloadable ZIP exports. Separately, retrieve equity quotes, trades, snapshots, OHLCV bars, option chains and Greeks, index
