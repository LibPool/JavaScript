# @slates-integrations/midjourney

> 标签: JavaScript

## 简介

Generate images from text prompts through APIFRAME's unofficial Midjourney API. Create variations, rerolls, upscales, blends, inpaints, pans, zoom-outs, seed lookups, short image-to-video tasks, and video extensions; fetch one or many asynchronous tasks;
