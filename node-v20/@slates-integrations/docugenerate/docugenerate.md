# @slates-integrations/docugenerate

> 标签: JavaScript

## 简介

Create reusable templates from public DOCX, DOC, ODT, RTF, TXT, or SQL files, then generate downloadable documents by merging templates with JSON data. Manage template settings, folders, and source files; download originals, PDF previews, PNG thumbnails,
