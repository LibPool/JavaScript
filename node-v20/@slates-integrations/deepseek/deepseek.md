# @slates-integrations/deepseek

> 标签: JavaScript

## 简介

Generate chat completions, thinking-mode reasoning responses, and code completions using DeepSeek V4 models. Supports non-streaming chat, structured JSON output, function calling with up to 128 tool definitions, beta strict tool-call mode, beta fill-in-th
