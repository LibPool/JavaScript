# @slates-integrations/apify

> 标签: JavaScript

## 简介

Run, schedule, and manage web scraping and browser automation Actors. Start Actor runs synchronously or asynchronously with custom input and runtime options. Create reusable Actor tasks with saved configurations. Store and export scraped data in datasets
