# connectmedia-sms

> 标签: airtel, bulk sms, connect media, kenya, safaricom, sms, sms api

## 简介

Official Node.js client for the Connect Media SMS API: bulk SMS to Safaricom, Airtel and Telkom in Kenya and 190+ countries.

- 官网：https://connectmedia.co.ke/developers/
- 源码仓库：git+https://github.com/connectmedia-ke/connectmedia-node.git
