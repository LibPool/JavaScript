# @helloaigent-dev/subscriber

> 标签: agent, agentic-web, ed25519, feed, hello-aigent, mcp, mcp-server, subscribe

## 简介

Hello Aigent reference subscriber — an MCP server that lets any agent subscribe to any Hello Aigent feed, fetch signed updates, verify them, and act.
