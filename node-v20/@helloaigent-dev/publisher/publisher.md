# @helloaigent-dev/publisher

> 标签: agent, agentic-web, analytics, feed, hello-aigent, mcp, mcp-server, publisher

## 简介

Hello Aigent publisher MCP — an MCP server that lets an agent run a publisher's feed: create feeds, publish signed updates, and read analytics (subscribers, funnel, event log).
