# @ship-it-ui/cytoscape

> 标签: cytoscape, design-system, graph, knowledge-graph, shipit

## 简介

Cytoscape adapter for the Ship-It design system. Token-driven stylesheet, theme-aware re-resolver hook, and a `<GraphCanvas>` wrapper that owns the data-theme ↔ stylesheet ↔ inspector dance.
