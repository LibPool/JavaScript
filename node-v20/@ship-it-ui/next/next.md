# @ship-it-ui/next

> 标签: app-router, design-system, next, next.js, shipit, theme

## 简介

Next.js (App Router) helpers for the Ship-It design system: SSR-safe theme persistence with FOUC prevention, cookie helpers, and a token-styled theme toggle.
