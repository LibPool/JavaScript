# botmancers

> 标签: agents, botmancers, mcp, model-context-protocol, streamable-http, supervisor, ui

## 简介

Botmancers: the UI, core engine, and authenticated MCP bridge (contracts botmancers.mcp.v1 and botmancers.mcp.v2) as one CLI-managed product. `botmancers start` runs it all; bare `botmancers` runs the bridge only.
