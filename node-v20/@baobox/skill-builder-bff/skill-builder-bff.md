# @baobox/skill-builder-bff

> 标签: backend-for-frontend, baobox, bff, hono, skill-studio

## 简介

Mountable Hono BFF router for the BaoBox Skill Studio — wraps @baobox/sdk (per-tenant apiKey, tenant-scoped) and serves the @baobox/skill-builder-contract authoring surface.
