# @raydotac/yaskawa-js

> 标签: dx100, dx200, fs100, hses, industrial-automation, motoman, robot-control, robotics, yaskawa, yrc1000

## 简介

High-performance Node.js driver for Yaskawa Motoman robot controllers (DX100, DX200, YRC1000, FS100) via High Speed E-Server (HSES) UDP protocol
