# @dialpad/rest-goblin-generator

> 标签: codegen, openapi, rest-goblin, swagger, typescript

## 简介

Code generation engine for rest-goblin that produces type-safe API clients from OpenAPI/Swagger schemas (use @dialpad/rest-goblin instead of consuming directly)
