# goatedcontext

> 标签: ai, ai-agents, claude, claude-code, cli, codex, context, cursor, developer-preferences, local-first, mcp, model-context-protocol, sqlite

## 简介

Local, shared developer memory for any AI coding agent. Works with any agent that speaks MCP, can invoke a subprocess, or reads AGENTS.md. Native zero-config integrations for Claude Code, OpenAI Codex, and Cursor.
