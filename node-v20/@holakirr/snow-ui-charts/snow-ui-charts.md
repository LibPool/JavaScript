# @holakirr/snow-ui-charts

> 标签: charts, dashboard, react, recharts, snow, snow-ui

## 简介

SnowUI charts: line, area, bar, donut and sparkline charts in the SnowUI design, built on Recharts. Companion package of @holakirr/snow-ui.
