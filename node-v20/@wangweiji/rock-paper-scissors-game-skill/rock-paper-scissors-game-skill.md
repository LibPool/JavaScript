# @wangweiji/rock-paper-scissors-game-skill

> 标签: workflow-skill

## 简介

本技能提供完整的猜拳（石头剪刀布）对战游戏能力，支持人机对战、实时计分、动画交互和历史记录功能。适用于休闲娱乐场景，可直接生成独立运行的交互式游戏页面。
