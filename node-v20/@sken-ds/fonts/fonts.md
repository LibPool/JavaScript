# @sken-ds/fonts

> 标签: JavaScript

## 简介

Font mechanism + presets for the Sken Design System. Default preset: Inter (sans) + Geist Mono (mono), both OFL-1.1, self-hosted variable WOFF2 with full Latin/Latin-Ext/Cyrillic/Cyrillic-Ext/Vietnamese/Turkish coverage.
