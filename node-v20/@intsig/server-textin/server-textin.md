# @intsig/server-textin

> 标签: converter, markdown, mcp, ocr, pdf, pdf-to-markdown, textin

## 简介

MCP Server for the Textin Robot API. TextIn官方MCP，支持文档OCR识别，文档转Markdown，文档关键信息提取。
