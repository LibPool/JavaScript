# @voidly/mcp-server

> 标签: a2a, agent, agent-relay, ai, censorship, chatgpt, claude, internet-freedom, llm, mcp, model-context-protocol, multi-agent, ooni, voidly

## 简介

MCP server for Voidly's internet censorship data and Sentinel forecasts, plus agent relay tools. Relay tools read the API key from a local 0600 file instead of taking or returning it; relay messages are relay-readable, not end-to-end encrypted.
