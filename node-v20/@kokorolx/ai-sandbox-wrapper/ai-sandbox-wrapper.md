# @kokorolx/ai-sandbox-wrapper

> 标签: ai, aider, claude, coding-assistant, docker, gemini, opencode, sandbox, security

## 简介

Docker-based security sandbox for AI coding agents. Isolate Claude, Gemini, Aider, and other AI tools from your host system.
