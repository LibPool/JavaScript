# @ctng/auth-jwt-ls

> 标签: JavaScript

## 简介

This is a library for handling Json Web Tokens by using the [jwt-decode](https://github.com/auth0/jwt-decode) library and local storage to persist the token. Additionally it checks if the token is expired.
