# @boringos/app-sdk

> 标签: agentic, ai-agents, apps, boringos, framework, plugins, sdk

## 简介

Public SDK for building apps and connectors on BoringOS — manifest types, defineApp/defineConnector helpers, slot APIs, lifecycle hooks, useBrand hook.
