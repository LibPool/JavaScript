# @hy-sde-org/dsh-code-runtime-kernels

> 标签: agent, code-runtime, deepseek, dsh-plugin, harness, javascript, kernel, persistent, python

## 简介

The run_kernel_code tool for DeepSeek Harness: persistent Python and JavaScript kernels (a long-lived python3/node subprocess per session, sharing a core host driver) — a standalone plugin with no upstream harness changes required.
