# @hy-sde-org/dsh-tool-memory

> 标签: agent, deepseek, dsh-plugin, harness, learn, memory, recall, reflect, retain

## 简介

Model-facing long-horizon memory tools (retain, recall, reflect, memory_edit, learn) over the ctx.memory service, plus first-turn project-memory prompt injection — a standalone plugin for DeepSeek Harness with no upstream harness changes required.
