# @d0nj/dsh-browser-tool

> 标签: agent, browser, deepseek-harness, dsh, playwright

## 简介

Real-browser tool for DeepSeek Harness agents: drive Chromium/Firefox/WebKit through Playwright (navigate, snapshot, observe, extract, act, wait, frames, eval, console, screenshots, tabs, storage, emulation, clipboard, network mocking, tracing).
