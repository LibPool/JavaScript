# pi-retainer

> 标签: coding-agent, memory, pi, pi-coding-agent, pi-package, sqlite

## 简介

Persistent memory for pi: a local SQLite store with tools for the model, a short budgeted recall at the start of each session, compaction summaries kept as searchable notes, daily snapshots, and optional pi-chassis rows and sidebar.
