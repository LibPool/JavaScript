# @neondatabase/functions

> 标签: database, functions, neon, platform, postgres, serverless, triggers, websocket

## 简介

Runtime helpers for Neon Functions: `waitUntil` for deferring async work past a response, `upgradeWebSocket` for serving WebSockets from a fetch handler or a Hono route, `attachDatabasePool` for node-postgres idle-client errors, and `parseTriggerDelivery`
