# @kikojs/dom

> 标签: JavaScript

## 简介

基于 [signal-polyfill](https://github.com/nicolo-ribaudo/signal-polyfill) 的响应式 DOM 库：自定义 JSX 运行时直接编译为真实 DOM 节点（无虚拟 DOM、无 diff），组件体推迟到消费点执行（惰性物化），信号变化只更新被读取到的节点。
