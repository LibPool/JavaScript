# @echo-agent/core

> 标签: agent, agent-runtime, ai-agent, llm, llm-agent, sdk, typescript

## 简介

The Echo agent runtime and SDK: a persistent agent — state machine, commands, events — and its pure loop. Zero runtime dependencies; the Agent owns the mechanism while you supply the ports and the policy.
