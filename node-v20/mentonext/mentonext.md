# mentonext

> 标签: headless-cms, nextjs, rankmath, react-hooks, rest-api, seo, wordpress, yoast

## 简介

Zero-config REST adapter for fetching WordPress content into Next.js — posts, pages, custom post types, authors, menus, and search — with SEO normalization (Yoast/RankMath/AIOSEO), pluggable caching, and React hooks.
