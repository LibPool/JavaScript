# @motorical/scope-catalog

> 标签: mcp, motorical, oauth, scopes

## 简介

Canonical MCP/OAuth scope metadata for Motorical — descriptions, Public API scope mapping, implied-read rules, and declarative tool/resource membership. One source of truth consumed by motorical-backend and @motorical/mcp.
