# @blufr/mcp-server

> 标签: JavaScript

## 简介

Blufr — serveur MCP stdio local : l'outil verify_diff vérifie le travail d'un agent de code (le diff est le contrat) et rend un verdict en clair. Tout reste local. Voir docs/mcp-clients.md.
