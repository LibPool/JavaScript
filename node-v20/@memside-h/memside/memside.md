# @memside-h/memside

> 标签: JavaScript

## 简介

AI agent（Claude Code / opencode）的本地记忆 sidecar。它监听你的 AI agent 会话，把反复出现的经验教训、踩过的坑、团队约定提炼成简洁的记忆条目，经你在 Web UI 审批后，在未来的会话里自动注入——全程不阻塞你的工作。
