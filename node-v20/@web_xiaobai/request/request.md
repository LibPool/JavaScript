# @web_xiaobai/request

> 标签: JavaScript

## 简介

多项目通用的 axios 封装：可注入 `getToken` / `refreshToken`、401 排队刷新、重复请求取消、失败重试、URL 与前缀拼接等（合并自 VAxios 实用能力，无业务路径依赖）。
