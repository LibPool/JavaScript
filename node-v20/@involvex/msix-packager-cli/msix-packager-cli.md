# @involvex/msix-packager-cli

> 标签: bundling, deployment, electron, executable, mcp, model-context-protocol, msix, ncc, node, packaging, postject, sea, single-executable-applications, uwp, vercel, windows, windows-store

## 简介

A utility to create MSIX packages from Node.js applications with MCP server support, Node.js Single Executable Application (SEA) bundling using @vercel/ncc and postject, and enhanced build options
