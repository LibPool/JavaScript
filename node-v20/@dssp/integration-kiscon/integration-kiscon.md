# @dssp/integration-kiscon

> 标签: JavaScript

## 简介

KISCON (건설공사대장 통보시스템) 연계용 Things-Factory 통합 태스크. headless-connector 위에서 KISCON 사이트에 로그인하여 공사대장 정보를 조회/추출한다.
