# @desert-ant-labs/emo

> 标签: emoji, emoji-suggestion, isomorphic, litert, multilingual, nlp, on-device, wasm

## 简介

On-device multilingual emoji suggestion for JavaScript. Runs in the browser (WebAssembly + LiteRT.js) and server-side in Node (native), from one import.
