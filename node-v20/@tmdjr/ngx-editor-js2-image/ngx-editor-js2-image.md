# @tmdjr/ngx-editor-js2-image

> 标签: JavaScript

## 简介

An image block for [Ngx-Editor-Js2](https://www.npmjs.com/package/@tmdjr/ngx-editor-js2). Users can add an image, set its title, and choose its alignment via the block's toolbar.
