# @unitsml/unitsdb

> 标签: metrology, opal, ruby, si, units, unitsdb, unitsml

## 简介

JavaScript release of unitsdb-ruby. Opal-compiled with optional shared runtime from @lutaml/opal-runtime. v3 replaces the JSON+façade approach with a real Ruby class hierarchy.
