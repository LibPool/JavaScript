# react-floating-dock

> 标签: bottom-nav, bottom-sheet, dock, mobile, navigation, pwa, react, tab-bar

## 简介

A WhatsApp-style floating bottom navigation dock for React, with an animated active-tab pill and an overflow sheet for extra destinations. Framework-agnostic — bring your own router.
