# @tcd-devkit/scripts

> 标签: checker, cli, eslint, format, formatter, javascript, lint, linter, prettier, scripts, tcd-devkit, typescript

## 简介

CLI tool for @tcd-devkit providing linting (ESLint, Prettier, TypeScript) and formatting (ESLint --fix, Prettier --write) capabilities for web development projects.
