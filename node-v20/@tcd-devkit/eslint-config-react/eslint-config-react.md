# @tcd-devkit/eslint-config-react

> 标签: config, eslint, eslint-config, eslintconfig, flat-config, jsx, lint, react, tcd-devkit

## 简介

ESLint Flat Configuration for React projects. This package provides core React linting rules using `eslint-plugin-react`, enforcing best practices and consistency for React applications.
