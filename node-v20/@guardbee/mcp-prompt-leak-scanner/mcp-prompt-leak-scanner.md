# @guardbee/mcp-prompt-leak-scanner

> 标签: ai-security, data-leak-prevention, devtools, dlp, gdpr, guardbee, guardrails, kvkk, llm-security, mcp, pii, secret-scanner, security

## 简介

PII and secret leak scanner for LLM prompts: catches API keys, TC Kimlik No, cards and IBANs in outbound prompts before they leave your app; MCP server and reverse proxy
