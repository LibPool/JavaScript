# @guardbee/mcp-oauth-auditor

> 标签: ai-security, devtools, guardbee, mcp, mcp-security, oauth, oauth2.1, security, token-passthrough

## 简介

MCP server that scans an MCP server's own authorization code for OAuth 2.1 anti-patterns named in the MCP spec's Security Considerations: token passthrough, missing audience validation, OAuth/OIDC discovery SSRF, missing PKCE, loose redirect_uri validatio
