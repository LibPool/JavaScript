# @guardbee/mcp-a2a-auditor

> 标签: a2a, agent-security, agent2agent, ai-security, devtools, guardbee, mcp, mcp-security, security, ssrf

## 简介

MCP server that scans Agent2Agent (A2A) protocol implementation code for anti-patterns found in the reference SDKs and sample agents: unauthenticated push-notification webhook fetches (SSRF), Agent Cards with no authentication requirement, and credentials
