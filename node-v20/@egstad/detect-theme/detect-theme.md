# @egstad/detect-theme

> 标签: color, dark-mode, es6, light-mode, module, prefers-color-scheme, scheme, theme, theme-changer

## 简介

A micro ES6 module (~0.5KB) for detecting a users preferred-color-scheme and watching for changes.
