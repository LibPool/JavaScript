# @sabremaps/react-native

> 标签: cog, expo, geotiff, maplibre, offline, raster, react-native

## 简介

Cloud-Optimized GeoTIFFs on a MapLibre React Native map, offline and restyled at runtime: sabre's tile server runs inside the app.
