# @wiliamferraciolli/ngx-api-client

> 标签: JavaScript

## 简介

Shared Angular client for Wiltech HTTP APIs — the ApiClientService (GET/POST/PUT/DELETE + envelope-unwrap), response envelope, HATEOAS-style links, field metadata, error shapes, and the LinkService/MetadataService/convertIdToValues helpers built on them.
