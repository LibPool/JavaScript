# @sevenryze/mediator

> 标签: JavaScript

## 简介

This module implements the `mediator` pattern, you can use this module inside nestjs framework, to introduce `CQRS` and integration events bus(For InMemory, AWS SNS-SQS, Aliyun RocketMQ).
