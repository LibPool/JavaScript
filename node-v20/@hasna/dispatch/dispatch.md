# @hasna/dispatch

> 标签: ai, automation, claude, cli, codex, coding-agent, dispatch, mcp, ssh, tmux

## 简介

Dispatch prompts to coding agents in tmux windows — reliable auto-submit, long-prompt support, delivery confirmation, scheduled + cross-machine dispatch. CLI + MCP + SDK + daemon.
