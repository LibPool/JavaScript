# kotlin-polycall

> 标签: ffi, ffm, jvm, kotlin, libpolycall, polycall

## 简介

Kotlin/JVM binding for the Polycall binding ABI v1 (Foreign Function & Memory API, JDK 22+). Source distribution of a Gradle project; not a JavaScript library.
