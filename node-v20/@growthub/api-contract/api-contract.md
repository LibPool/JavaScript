# @growthub/api-contract

> 标签: api-contract, capabilities, cms, execution, growthub, manifests, mcp, provider-assembly, sdk, skill-manifest, skills, types

## 简介

Growthub CMS SDK v1 — public contract surface. Freezes the existing growthub-local CLI truth (capabilities, manifests, execution payloads, provider assembly, profile, streaming events, skills) into one stable, additive, type-only package.
