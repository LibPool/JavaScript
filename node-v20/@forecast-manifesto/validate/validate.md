# @forecast-manifesto/validate

> 标签: bg-nbd, clv, demand-forecast, holdout, start-x, validation

## 简介

需要予測の検証モジュール：較正/検証分割・実測vs予測・累積トラッキング・誤差指標・増分性の算術（iROAS）。「予測を当てるゲームにしない」の実証装置。
