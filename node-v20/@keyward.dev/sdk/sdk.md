# @keyward.dev/sdk

> 标签: agents, broker, credentials, delegation, keyward, mcp, oauth, rfc8693, secrets

## 简介

Keyward SDK — ask the credential broker for a scoped, short-lived credential at call time. Your agent never holds a long-lived upstream key.
