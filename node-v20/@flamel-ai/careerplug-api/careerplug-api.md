# @flamel-ai/careerplug-api

> 标签: ats, careerplug, jobs, openapi, recruiting, sdk, swagger, typescript, zod

## 简介

Clean, fully-typed TypeScript SDK for the CareerPlug API, generated from the live Swagger 2.0 spec (converted to OpenAPI 3.1) with zod validation. Includes OAuth 2.0 helpers and the partner job-feed reader.
