# @ravi-labs/mindmap-mcp-server

> 标签: chatgpt, claude, context, mcp, memory, model-context-protocol

## 简介

Mind Map — a memory consolidation / context-handoff MCP server. Capture context from any AI tool, resume it anywhere, and let it decay gracefully.
