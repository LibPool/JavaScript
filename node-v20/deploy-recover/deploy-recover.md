# deploy-recover

> 标签: ChunkLoadError, chunk, deploy, dynamic import, preloadError, react, reload, spa, stale, update, version, vite

## 简介

Recover tabs left open across a deploy: detect new versions, recover from missing chunks, and never loop reloading.
