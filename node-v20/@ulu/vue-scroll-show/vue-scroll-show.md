# @ulu/vue-scroll-show

> 标签: animation, keyframes, scroll, scroll-magic, sticky, vue

## 简介

Minimal component to create sticky scrolling based slideshow. Uses scrollmagic library and position sticky to create scenes (like scroll keyframes).
