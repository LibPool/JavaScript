# @xenolithengine/graph-mcp-server

> 标签: ai-agents, claude, cursor, langchain, mcp, model-context-protocol, node-editor

## 简介

MCP (Model Context Protocol) server for XenolithGraph — lets Claude/Cursor/any MCP client drive a running editor over a localhost WebSocket bridge.
