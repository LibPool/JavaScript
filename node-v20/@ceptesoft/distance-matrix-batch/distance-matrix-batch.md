# @ceptesoft/distance-matrix-batch

> 标签: batching, distance-matrix, eta, google-maps, route-planning

## 简介

Google Distance Matrix client with transparent batching around the 25-destination request cap, parallel dispatch, and typed { ok, error } results. Injectable fetch, zero dependencies.
