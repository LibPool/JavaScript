# @ceptesoft/geo-link-parser

> 标签: coordinates, geolocation, google-maps, link-parser, short-link

## 简介

Turns messy real-world location shares (WhatsApp, Google Maps links, short links) into a routable "lat,lng" or address string. Injectable fetch, zero dependencies.
