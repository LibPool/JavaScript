# @fluid-ds/node-graph

> 标签: design-system, flow, fluid-ds, graph-editor, node-graph, web-components, workflow

## 简介

Accessible node graph editor web component for Fluid (expansion pack): draggable nodes, connection ports and Bezier edges with full keyboard support.
