# @fluid-ds/editor

> 标签: contenteditable, design-system, editor, fluid-ds, rich-text, web-components, wysiwyg

## 简介

Accessible rich-text editor web component for Fluid (expansion pack): contenteditable with a toolbar, framework-agnostic.
