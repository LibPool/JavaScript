# @appliqation/visual-regression

> 标签: JavaScript

## 简介

Standalone agent that checks a page for real visual regressions by diffing it against its own live production counterpart: no stored baseline files, no manual baseline-approval workflow. Declines rather than compares when no production equivalent exists.
