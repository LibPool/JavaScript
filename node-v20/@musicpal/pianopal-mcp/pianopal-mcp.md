# @musicpal/pianopal-mcp

> 标签: claude, course-authoring, mcp, pianopal

## 简介

Local MCP server for PianoPal partners: connects to the PianoPal course-authoring MCP with your API key, re-serves its tools over stdio, and adds a tool that uploads media from this machine — one entry in Claude Desktop, no header configuration.
