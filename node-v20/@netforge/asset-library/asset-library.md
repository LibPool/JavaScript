# @netforge/asset-library

> 标签: browser-game, cc0, game-assets, game-engine, gamedev, net-forge, three, threejs, typescript

## 简介

CC0 game asset library for Net Forge: a manifest of models, sprites and sounds addressed by library id, shared rigs, the look composer and a three.js loader.
