# @netforge/template-arena

> 标签: ai-agents, browser-game, game-engine, game-template, gamedev, html5-game, io-game, mcp, multiplayer, net-forge, netcode, threejs, typescript

## 简介

Arena shooter game template for Net Forge: up to 16 players, lag-compensated beams, loadouts, rounds and seat-filling bots (VOLTYARD).
