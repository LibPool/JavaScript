# @netforge/tabletop

> 标签: browser-game, card-game, game-engine, gamedev, idle-game, monster-collector, multiplayer, net-forge, threejs, tower-defense, typescript

## 简介

Shared client kit for Net Forge board-style game templates (tower defense, idle, card battler, monster collector): room connection, input clock, 3D stage, store and HUD.
