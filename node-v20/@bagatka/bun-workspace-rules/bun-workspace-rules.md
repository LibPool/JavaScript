# @bagatka/bun-workspace-rules

> 标签: architecture, bun, catalog, dependency-rules, effect, lint, monorepo, workspace

## 简介

Checks that a Bun workspace's packages follow your rules: what each is named, whether others may import it, and which packages it may depend on, at which versions.
