# @hughpeng/mysql

> 标签: JavaScript

## 简介

基于 [mysql2](https://github.com/sidorares/node-mysql2) 的 MySQL 连接池与 CRUD 封装，支持预编译参数、批量插入、`ON DUPLICATE KEY UPDATE` 与事务。
