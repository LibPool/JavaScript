# @hughpeng/redis

> 标签: JavaScript

## 简介

基于 [node-redis](https://github.com/redis/node-redis) v6 的 Redis 客户端封装：进程内单例、键前缀、常用 KV 操作，以及带互斥锁的 `getOrLoad`（防缓存击穿）。
