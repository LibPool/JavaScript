# @memoro/mcp-server

> 标签: ai-memory, claude, mcp, memory, model-context-protocol, personal-ai

## 简介

Local MCP connector for Memoro — lets Claude Desktop, Claude Code and other local MCP clients read and write your personal Memoro memory. Requires Memoro to already be installed and running at least once.
