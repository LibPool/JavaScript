# @calpano/ddot-parser

> 标签: ddot.it, knowledge-graph, parser, tokenizer, triples

## 简介

Canonical JavaScript parser for ddot.it (Knowledge Graph Notation): tokenizer, triple-event extraction and a `ddot-index` CLI.
