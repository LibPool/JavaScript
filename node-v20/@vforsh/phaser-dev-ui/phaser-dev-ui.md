# @vforsh/phaser-dev-ui

> 标签: debug, dev-ui, gamedev, hud, phaser, phaser3

## 简介

Pure-code debug UI primitives for Phaser 3 games — panels, buttons, labels, badges, progress bars, switch buttons, sliders, toggles, separators, and layout containers. No assets required.
