# @black942026/pi-trust-like

> 标签: pi-package

## 简介

独立的 Pi 目录信任扩展。首次进入目录时只显示「是否信任此目录？」及 **是 / 否** 两个选项：选「是」后记录目录；选「否」或取消则退出 Pi。父目录和子目录必须分别信任。
