# @black942026/pi-debug-tool

> 标签: debug, observability, observer-only, pi-extension, pi-package

## 简介

Observer-only debug extension for Pi 0.99.x: slash commands to inspect state, trace runs, summarize metrics, and debug native MCP without ever touching model context.
