# cacheplank

> 标签: bunny, cache-handler, cacheComponents, isr, libsql, next, next.js, nextjs, revalidateTag, turso, use-cache

## 简介

The shared plank your pods walk across: a single-file Next.js 16 cache handler where entries stay local and only tag invalidation is shared, via one libSQL table.
