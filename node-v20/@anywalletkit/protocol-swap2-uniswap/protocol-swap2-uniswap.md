# @anywalletkit/protocol-swap2-uniswap

> 标签: permissionless, swap, uniswap

## 简介

Uniswap v3 same-chain swaps straight from the contracts: on-chain QuoterV2 quotes, SwapRouter02 execution, no API, no frontend.
