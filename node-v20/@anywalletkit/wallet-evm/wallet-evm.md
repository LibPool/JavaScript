# @anywalletkit/wallet-evm

> 标签: bip32, eip1559, eip712, erc20, ethereum, evm, viem, wallet

## 简介

EVM wallet for Any Wallet Kit: BIP-32 m/44'/60'/0'/0/i accounts, EIP-191 / EIP-712 / EIP-1559 signing, ERC-20 transfer and approve, built on viem.
