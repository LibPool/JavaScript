# @anywalletkit/wallet-solana

> 标签: ed25519, slip10, solana, spl-token, wallet

## 简介

Solana wallet for Any Wallet Kit: SLIP-10 m/44'/501'/i'/0' accounts, SOL and SPL transfers with ATA creation, noble ed25519 signing (no WebCrypto needed), built on @solana/kit.
