# @anywalletkit/backup-cloud

> 标签: anywalletkit, backup, expo, icloud, icloud-keychain, react-native

## 简介

Cloud backups for React Native wallets on Any Wallet Kit: seed-vault backup files in the app's hidden iCloud Drive container, and a no-password option whose key lives in iCloud Keychain (end-to-end encrypted by Apple) while the file lives in iCloud Drive
