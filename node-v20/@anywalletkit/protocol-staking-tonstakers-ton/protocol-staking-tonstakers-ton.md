# @anywalletkit/protocol-staking-tonstakers-ton

> 标签: anywalletkit, gram, liquid-staking, protocol, staking, staking-protocol, ton, tonstakers, tston

## 简介

A simple package that lets @anywalletkit/wallet-ton wallet accounts stake through Tonstakers: stake GRAM → tsTON, unstake instant / standard / best-rate, track payout bills, rates and APY.
