# @anywalletkit/protocol-swap2-chainflip

> 标签: anywalletkit, bitcoin, bridge, chainflip, solana, swap2, tron

## 简介

Chainflip vault swaps for the swap2 engine: native BTC / ETH / SOL / TRX and USDC / USDT across Ethereum, Arbitrum, Solana, Tron and Bitcoin through Chainflip's public backend (its own broker, 0 bps, no account). Sources in this release: Ethereum, Arbitru
