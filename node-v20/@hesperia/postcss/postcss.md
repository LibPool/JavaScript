# @hesperia/postcss

> 标签: JavaScript

## 简介

Run an explicit, ordered list of PostCSS plugins during a Hesperia build. The integration transforms imported and generated CSS, passes source maps to Hesperia, and carries PostCSS file and directory dependencies into development watches.
