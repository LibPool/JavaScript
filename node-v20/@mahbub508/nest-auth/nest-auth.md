# @mahbub508/nest-auth

> 标签: auth, authentication, email-verification, forgot-password, nestjs, otp, reset-password

## 简介

A plug-and-play, globally reusable NestJS authentication package with email verification (OTP), login, forgot password, reset password and resend OTP.
