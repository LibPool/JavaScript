# @mcp-abap-adt/background-runs-memory

> 标签: abap, adt, background-runs, mcp, sap

## 简介

The in-memory store of the MCP ABAP ADT server's background runs: an IBackgroundRuns of @mcp-abap-adt/lib keeping each caller's runs and their answers in the process's memory, 16 per caller, until discarded or the process ends.
