# @zvonok/client

> 标签: JavaScript

## 简介

Headless TypeScript core for ZvonOK video rooms: SFU connection, media capture, device management, and screen share over mediasoup + Socket.io. Framework-free; the React layer lives in [`@zvonok/react`](https://www.npmjs.com/package/@zvonok/react).
