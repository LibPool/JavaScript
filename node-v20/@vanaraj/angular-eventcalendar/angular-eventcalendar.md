# @vanaraj/angular-eventcalendar

> 标签: angular-calendar, angular-calendar-scheduler, angular-eventcalendar, calendar-scheduler, event-calendar, ng-calendar, ngx-calendar, resposive calendar

## 简介

The **Angular - Event Calendar** is a lightweight and developer-friendly _Angular_ library where you can `add`, `edit` and `view` the events.
