# @henlii/dsh-web-mobile

> 标签: JavaScript

## 简介

DSH plugin: phone-viewport adapter for the official dsh web shell. Single-column chat plus overlay sheets; feature-detects dsh-web-auth / dsh-sidebar / dsh-web-terminal without depending on them.
