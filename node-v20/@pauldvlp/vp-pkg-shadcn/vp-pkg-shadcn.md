# @pauldvlp/vp-pkg-shadcn

> 标签: react, shadcn, template, vite-plus, vite-plus-generator

## 简介

Add a shared, fully customizable shadcn UI package (packages/ui) into an existing Vite+ monorepo, themeable via shadcn presets.
