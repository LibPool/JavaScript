# @forjajs/contracts

> 标签: contracts, dependency-inversion, dip, interfaces, typescript, utility

## 简介

Zero-dependency DIP contracts (Repository, Hasher, ViewEngine, Addon) and the assertImplements() runtime guard, shared by every Forja addon — HTTP-based or not.
