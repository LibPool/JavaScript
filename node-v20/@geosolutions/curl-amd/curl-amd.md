# @geosolutions/curl-amd

> 标签: amd, commonjs, css, cujo, curl, html, json, loader, module

## 简介

curl.js is small, fast, extensible module loader that handles AMD, CommonJS Modules/1.1, CSS, HTML/text, and legacy scripts.
