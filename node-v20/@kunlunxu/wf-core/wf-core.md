# @kunlunxu/wf-core

> 标签: JavaScript

## 简介

WriteFlow 的编辑器内核，负责创建 ProseMirror `Schema`、`EditorState` 和 `EditorView`，并统一装配扩展提供的节点、标记、命令、辅助函数、输入规则、快捷键、插件和 NodeView。
