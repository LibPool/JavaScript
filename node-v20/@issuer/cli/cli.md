# @issuer/cli

> 标签: agent, cli, github, gitlab, issues, mcp, pm, requirements, skill, yunxiao

## 简介

Skill-driven PM gateway. Breakdown requirements → sync to any platform via MCP. Built-in: GitHub, GitLab, Yunxiao, PingCode, Jira.
