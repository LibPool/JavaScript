# agent-sdk-watchdog

> 标签: agent, ai-agent, anthropic, claude, claude-agent-sdk, claude-code, hang, idle, llm, rate-limit, timeout, watchdog

## 简介

An idle watchdog for Claude Agent SDK query() sessions, with the rate-limit monitor that feeds it and an SDK warning filter.
