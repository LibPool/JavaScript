# @mailwoman/un-locode-lookup

> 标签: JavaScript

## 简介

Place → UN/LOCODE (UNECE Code for Trade and Transport Locations), by country + name or nearest coordinate. node:sqlite over the UNECE code list. An @mailwoman/annotations Annotator.
