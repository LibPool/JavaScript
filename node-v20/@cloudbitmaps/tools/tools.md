# @cloudbitmaps/tools

> 标签: bitmap, cloudbitmaps, cost, cost-estimate, object-storage, pricing, redis, roaring-bitmap, s3, serverless, typescript

## 简介

Offline tools for CloudBitmaps that need nothing internal from a store: the cost model, which prices a workload on object storage against an always-on Redis.
