# @ashushunov/plop-vue-component-generator

> 标签: cli, component, generator, vue

## 简介

[Plop](https://plopjs.com/) generator to create [Vue Components](https://vuejs.org/v2/guide/single-file-components.html)  with [jest test](https://jestjs.io/), [storybook](https://storybook.js.org/), connected to [vuex](https://vuex.vuejs.org/guide/).
