# @gexarus/jseditor-navigation-menu

> 标签: autocomplete, dropdown, jseditor-navigation-menu, ui

## 简介

Flexible Editor.js navigation menu block with automatic or manual heading selection, anchor picker, drag-and-drop sorting, and customizable UI with isolated styles.
