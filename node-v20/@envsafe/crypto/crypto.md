# @envsafe/crypto

> 标签: aes-gcm, encryption, end-to-end-encryption, secrets, webcrypto, zero-knowledge

## 简介

Frozen client-side crypto core for envsafe. AES-GCM-256 with a versioned envelope, zero runtime dependencies, pure WebCrypto.
