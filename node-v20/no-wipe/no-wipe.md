# no-wipe

> 标签: ai-agents, antigravity, claude-code, codex, copilot, cursor, delete-protection, rm-rf, security, windows

## 简介

Stop AI coding agents from wiping your files. One rules file becomes the safety config for Claude Code, Codex, Cursor, Copilot CLI and Antigravity.
