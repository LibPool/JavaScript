# @tool-chain/core

> 标签: async, async-chain, chain, chaining, error-handling, promise, retry, timeout, toolchain, typescript, utility, workflow, 工作流, 异步, 链式

## 简介

强大的链式异步执行库 - 支持 ESM 和 CommonJS 双模块格式。用优雅的 API 构建复杂的异步工作流，提供完整的 TypeScript 类型安全和灵活的错误处理。
