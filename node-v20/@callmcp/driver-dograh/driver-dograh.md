# @callmcp/driver-dograh

> 标签: JavaScript

## 简介

CallMCP driver for Dograh (github.com/dograh-hq/dograh) — a self-hostable, BYO-carrier voice-AI platform. Wraps Dograh's own REST API directly (not Dograh's MCP server) so a local, fully air-gapped Dograh instance can be driven through the CallMCP tool co
