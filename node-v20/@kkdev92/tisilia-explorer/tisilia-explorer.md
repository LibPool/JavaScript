# @kkdev92/tisilia-explorer

> 标签: api-explorer, aspnetcore, tisilia, vite, vue

## 简介

The source of the Tisilia Explorer, an API explorer page that runs every call through the generated client's own codecs; `tisilia explorer build` bundles it with an application's trusted codec modules.
