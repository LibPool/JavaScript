# @kkdev92/tisilia-nuxt

> 标签: aspnetcore, hydration, nuxt, nuxt-module, ssr, tisilia, typescript

## 简介

The Nuxt 4 module for Tisilia clients: request-scoped clients, allowlisted header forwarding during SSR, and hydration envelopes that keep exact values from the server render to the browser.
