# @grean/react-native-carousel-picker

> 标签: carousel, combo, dropdown, picker, react-native, reanimated, select

## 简介

Carousel-picker is a component that allows you to display your data in a circular select/dropdown way.<br/> It's a full typescript responsive component that uses reanimated 2.<br/> The work is still in progress but you can use it and improve it if you wan
