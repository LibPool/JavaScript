# @sliverkeigo/yata

> 标签: a2a, agent, automation, codex, discord, discord-bot, multi-bot, openai

## 简介

Yata — Discord-native multi-agent collaboration bot. Runs N personas (one Discord App each) on top of a shared Codex CLI executor.
