# @omniviewdev/vite-plugin

> 标签: omniview, plugin, shared-dependencies, vite

## 简介

Vite plugin for Omniview plugin development. Redirects shared dependency imports to the host app's singleton instances via window.__OMNIVIEW_SHARED__.
