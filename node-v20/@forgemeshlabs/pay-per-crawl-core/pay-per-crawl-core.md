# @forgemeshlabs/pay-per-crawl-core

> 标签: 402, ai-crawlers, base, mpp, pay-per-crawl, usdc, x402

## 简介

Pay-per-Crawl core: crawler classifier, x402 v1/v2 + MPP 402 challenges, facilitator verify/settle, discovery files. Runs on Node 20+, Cloudflare Workers and the Next.js edge runtime.
