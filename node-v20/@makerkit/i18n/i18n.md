# @makerkit/i18n

> 标签: ai-agents, i18n, i18next, mcp, next-intl, translations

## 简介

Lets coding agents read and edit JSON translation files stored as <locale>/<namespace>.json (i18next, next-i18next, next-intl with namespace files): list, update, stats, add and remove locales and namespaces.
