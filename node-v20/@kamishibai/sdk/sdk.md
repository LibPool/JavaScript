# @kamishibai/sdk

> 标签: agent, claude, html, ir, offline, presentation, renderer, sdk, single-file

## 简介

Agent Presentation SDK — agents author a structured IR; the SDK deterministically renders self-contained offline single-file HTML artifacts (five genres, template packages, replay/resk in, lint gates).
