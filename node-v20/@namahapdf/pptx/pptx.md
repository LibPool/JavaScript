# @namahapdf/pptx

> 标签: client-side, on-device, ooxml, powerpoint, powerpoint-editor, powerpoint-viewer, pptx, pptx-editor, pptx-parser, pptx-to-pdf, sdk, slides, typescript

## 简介

Headless in-browser PowerPoint engine — parse, render, edit (.pptx write-back), export to PDF, and project to an AI-readable model. Part of the NamahaPDF SDK.
