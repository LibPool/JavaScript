# @mcpstack/agent-sdk

> 标签: agent, ai, chat, embeddable, llm, mcp, mcpstack, widget

## 简介

First-party AG-UI client for MCP Stack Agents. Add an LLM-powered agent to your web app while server tools stay on MCP.
