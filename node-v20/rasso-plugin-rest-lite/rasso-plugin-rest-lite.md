# rasso-plugin-rest-lite

> 标签: JavaScript

## 简介

极速启动的轻量级 HTTP / REST API 接口调试工作台：支持 GET / POST / PUT / DELETE / PATCH 等方法，内置 Headers 与 JSON Body 高亮编辑器，毫秒级响应测速与数据导出
