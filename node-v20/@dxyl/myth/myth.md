# @dxyl/myth

> 标签: 2d, canvas, graphic

## 简介

一个低成本的跨平台2d渲染，基于`skia-path2d`创建基本图形和文件的矢量路径，最终渲染到平台。

- 官网：https://github.com/dxlyf/DxMyth
- 源码仓库：git+ssh://git@github.com/dxlyf/DxMyth.git
- npm 页面：https://www.npmjs.com/package/@dxyl/myth
