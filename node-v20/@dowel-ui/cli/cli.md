# @dowel-ui/cli

> 标签: cli, code-generation, component-library, components, design-system, dowel, react, registry, scaffolding, shadcn, source-first, tailwind, ui

## 简介

Installs Dowel components into your project as source you own, with dependencies resolved and imports rewritten to your path aliases.
