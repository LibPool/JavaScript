# @consentx/vue

> 标签: ccpa, cmp, consent-mode, consentx, cookie-consent, dpdpa, gdpr, privacy, vue, vue3

## 简介

Vue 3 cookie consent & CMP for ConsentX — GDPR, CCPA, DPDPA. Paste your Site Key and the widget installs itself.
