# @creatorcrawl/sdk

> 标签: creatorcrawl, instagram-api, linkedin-api, mcp, reddit-api, scraper, sdk, social-media-api, tiktok-api, twitter-api, youtube-api

## 简介

Official TypeScript SDK for the CreatorCrawl social media data API. Scrape TikTok, Instagram, YouTube, LinkedIn, Twitter/X, and Reddit profiles, posts, comments, transcripts, and ads.
