# @dltech/ai-testing

> 标签: agentevals, agents, ci, cli, eval, evaluation, langchain, llm, llm-judge, openevals, testing

## 简介

Standalone CLI eval runner for LangChain chains/agents. Define a module, run it, see a score table with below-threshold case dumps. Tracing is optional via ai-testing.config.ts.
