# @dltech/nestjs-langfuse

> 标签: callback-handler, langchain, langfuse, llm, nestjs, observability, opentelemetry, prompt-management, tracing

## 简介

NestJS/LangChain integration for the Langfuse v5 OpenTelemetry SDK: a noise-filtered LangChain callback handler, a version-stepped Langfuse-managed prompt runnable, and helpers for tracing detached session turns.
