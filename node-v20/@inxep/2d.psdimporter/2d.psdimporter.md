# @inxep/2d.psdimporter

> 标签: xengine

## 简介

Adobe Photoshop PSD/PSB importer: the layer tree with names, rects, groups, and pixels, a flattened composite texture, and one sprite per layer. Parser is the MIT Paint.NET PSD plugin, ported to pure C#. Official optional package: listed in Package Manage
