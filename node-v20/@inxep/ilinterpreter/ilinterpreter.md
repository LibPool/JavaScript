# @inxep/ilinterpreter

> 标签: aot, hotupdate, il, interpreter, xengine

## 简介

Official optional IL interpreter for NativeAOT players: executes supported hot-update C# assemblies as data on HarmonyOS and desktop. Installs the interpreted-assembly classification, module loader, VM and host binding tools.
