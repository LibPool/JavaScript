# @squiryl/mcp

> 标签: ai-agent, claude, codex, encryption, mcp, model-context-protocol, personal-data, squiryl, zero-knowledge

## 简介

Local MCP server that lets your own AI agent use your Squiryl vault. Decryption happens on your machine; Squiryl's servers only ever see ciphertext.
