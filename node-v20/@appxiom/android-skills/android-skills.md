# @appxiom/android-skills

> 标签: android, antigravity, appxiom, claude, coding-agent, compose, copilot, cursor, jetpack-compose, kotlin, skills

## 简介

CLI to install Appxiom Android SDK integration skills (core, compose & screens, network, goal tracking, activity trails, test issue, deobfuscation) into a project's coding agent skills directory.
