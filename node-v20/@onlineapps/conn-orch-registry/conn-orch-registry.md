# @onlineapps/conn-orch-registry

> 标签: api, connector, environment, heartbeat, microservice, nodejs, rabbitmq, registry

## 简介

conn-orch-registry provides the core communication mechanism for microservices in this environment. It enables them to interact with a services_registry to receive and fulfill tasks by submitting heartbeats or their API descriptions.
