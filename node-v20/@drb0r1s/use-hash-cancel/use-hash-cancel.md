# @drb0r1s/use-hash-cancel

> 标签: back-button, hash, modal, navigation, popup, react, react-hook, react-router

## 简介

A React hook that syncs modal/popup state with the URL hash, so the browser back button or back gesture closes them instead of navigating away.
