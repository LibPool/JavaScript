# @attested-intelligence/aga-verify

> 标签: aga, ai-governance, attested-intelligence, ed25519, evidence-bundle, merkle, offline-verification, verifier

## 简介

Standalone offline verifier for canonical AGA SEP Evidence Bundles (Ed25519 + SHA-256 via Node's built-in crypto; zero AGA imports, zero third-party deps; producer-independent).
