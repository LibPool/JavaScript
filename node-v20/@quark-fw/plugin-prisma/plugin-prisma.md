# @quark-fw/plugin-prisma

> 标签: database, prisma, quark

## 简介

Prisma 8 client plugin for the Quark framework: loads src/prisma/db.ts into quark.db and closes the pool on shutdown (published as raw TS sources; consumers run tsx)
