# @nodetool-ai/sandbox-compiler

> 标签: compiler, esbuild, nodetool, quickjs, sandbox

## 简介

Compiles a pack's npm dependency into a guest sandbox module: esbuild bundle, scope-aware scan, QuickJS admission probe, content-addressed cache
