# @nodetool-ai/browser

> 标签: browser-automation, cdp, chrome-devtools-protocol, chrome-extension, nodetool, typescript

## 简介

Driving one real Chrome page over CDP: the action loop, element indexing, media capture, file upload, and the Chrome-extension relay that reaches the user's own signed-in browser
