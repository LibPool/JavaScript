# @restregular/dsh-memory

> 标签: bge-m3, deepseek-harness, dsh-plugin, embeddings, memory, panel, recall

## 简介

DeepSeek Harness 记忆系统(单包单入口):JSONL 存储 + 本地向量检索(BGE-M3)+ 五个模型工具 + 自动召回注入 + 管理面板。
