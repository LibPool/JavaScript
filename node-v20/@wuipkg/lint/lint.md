# @wuipkg/lint

> 标签: eslint, eslint-config, lint, prettier, stylelint, vue

## 简介

集中与收拢管理公司前端项目的代码体检（ESLint）、格式化（Prettier）以及样式检查（Stylelint）规则底座包。采用 ESLint 10 推行的全新 Flat Config 机制提供 Vue 3 生态支持。
