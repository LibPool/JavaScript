# @wuipkg/security-review

> 标签: JavaScript

## 简介

面向构建前与 CI 阶段的安全审查工具包，提供 CLI、Vite、webpack 与 ESLint 子入口。旨在从代码规范、静态资源暴露、第三方依赖风险等多维度阻断潜在安全隐患。
