# @neptune.fintech/create-neptune

> 标签: boilerplate, create, design-system, fintech, material-3, neptune, scaffold, starter, white-label

## 简介

Scaffold a themed Neptune Odyssey starter app — Web, React, Vue, Svelte, React Native or Flutter — with the provider wired, a sample dashboard, styles imported and a brandprint set. `npm create @neptune.fintech` / `npx @neptune.fintech/create-neptune`.
