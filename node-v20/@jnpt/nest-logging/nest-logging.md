# @jnpt/nest-logging

> 标签: correlation-id, express, fastify, json, logging, masking, nestjs, structured-logging

## 简介

Structured JSON logging for NestJS on Express or Fastify (port of github.com/jnpt-golangs/logging): application + request logs, correlation ID, masking, outgoing HTTP logging.
