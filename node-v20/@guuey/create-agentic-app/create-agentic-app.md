# @guuey/create-agentic-app

> 标签: JavaScript

## 简介

Scaffold a guuey agentic app: code-mode agent + custom MCP + ggui + web, local pnpm dev, one-command guuey deploy.

- 源码仓库：git+https://github.com/withguuey/guuey-sdks.git
