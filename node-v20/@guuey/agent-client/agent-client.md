# @guuey/agent-client

> 标签: agent, chat, client, guuey, react, sse

## 简介

Client SDK for Guuey's agent runtime: the `useAgentInvoke` React hook + pure SSE helpers that speak the /agent/invoke streaming contract, plus the paginated thread-history read plane. Host adapters (storage / id / transport) are injected, so it runs on we
