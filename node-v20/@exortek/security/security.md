# @exortek/security

> 标签: auth, backend, bearer, brute-force, cors, csp, csrf, express, fastify, headers, helmet, honeypot, hpp, hsts, node-crypto, nosql-injection, open-redirect, path-traversal, prototype-pollution, rate-limit, safe-redirect, security, slow-down, webhook

## 简介

Framework-agnostic defensive HTTP layer for Node.js 22+ — CSRF, sliding/fixed/token-bucket/leaky-bucket rate limiting (memory / Redis / custom stores, plus withBan escalation), helmet-style headers (CSP, HSTS, COOP/COEP/CORP, Referrer, Permissions), CORS,
