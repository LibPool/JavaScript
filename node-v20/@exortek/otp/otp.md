# @exortek/otp

> 标签: 2fa, authenticator, backend, backup-codes, hotp, mfa, node-crypto, otp, otpauth, provisioning-uri, rfc-4226, rfc-6238, security, totp

## 简介

TOTP (RFC 6238) and HOTP (RFC 4226) one-time passwords for Node.js — secure defaults, tunable window / algorithm / digits, opt-in replay defense via any @exortek/security store, backup codes with unambiguous alphabet, and Google-Authenticator-compatible p
