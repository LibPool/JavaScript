# @exortek/paseto

> 标签: authentication, backend, ed25519, node-crypto, paseto, security, stateless, token, v4, xchacha20-poly1305

## 简介

PASETO (Platform-Agnostic Security Tokens) for Node.js 22+. v4.local (XChaCha20 + keyed BLAKE2b) + v4.public (Ed25519). Purpose is bound into the token — no algorithm-confusion attacks. Server-only, zero-dependency, built on node:crypto.
