# @exortek/challenge

> 标签: 2fa, auth, backend, challenge, flow-token, hmac, mfa, multi-step, node-crypto, security, signed-token, single-use, step-up

## 简介

Signed, single-use challenge tokens for multi-step auth flows on Node.js — carries userId / method / step / metadata across a redirect or a second request without a server-side session; HMAC-signed, expiring, optional IP-binding, single-use enforcement vi
