# @exortek/jwe

> 标签: aes-gcm, aes-kw, backend, ecdh-es, encryption, jose, jwe, jwt, node-crypto, rfc-7516, rfc-7518, rsa-oaep, security

## 简介

JSON Web Encryption (JWE) — RFC 7516 / RFC 7518 for Node.js 22+. Compact serialization, RSA-OAEP / ECDH-ES / AES-KW / dir key management, AES-GCM + AES-CBC-HMAC content encryption. Alg + enc allowlist mandatory on decrypt. `RSA1_5` never accepted. Zero-de
