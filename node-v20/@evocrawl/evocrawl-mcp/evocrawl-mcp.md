# @evocrawl/evocrawl-mcp

> 标签: evocrawl, mcp, web-data, web-interaction, web-search

## 简介

MCP server for Evocrawl — search, scrape, and interact with the web. Supports both cloud and self-hosted instances. Features include web search, scraping, page interaction, batch processing, and LLM-powered content analysis.
