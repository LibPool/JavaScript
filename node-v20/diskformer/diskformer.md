# diskformer

> 标签: browser, gguf, inference, llama.cpp, llm, moe, offload, opfs, transformers, wasm, webgpu

## 简介

Run a model larger than your GPU memory in a browser tab: weights stay in OPFS, WebGPU holds only what each step needs. llama.cpp with paged MoE experts (diskformer/llama), a disk tier, and hand-written MoE engines.
