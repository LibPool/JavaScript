# @creait/dsh-think-level

> 标签: cordis, deepseek-harness, dsh, model-defaults, plugin, reasoning, reasoning-effort, thinking

## 简介

Thinking level for DeepSeek Harness: a per provider/model default reasoning effort that also reaches subagents, plus one composer pill to change it for the session.
