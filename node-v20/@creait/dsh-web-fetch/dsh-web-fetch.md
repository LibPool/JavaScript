> 标签: cordis, deepseek-harness, dsh, plugin, self-hosted, ssrf, web-fetch

## 简介

Guarded local fetch provider for the DeepSeek Harness web capability seam (ctx.web) — the backend dsh's shipped web_fetch tool is missing
