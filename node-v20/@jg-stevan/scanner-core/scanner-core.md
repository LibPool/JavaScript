# @jg-stevan/scanner-core

> 标签: browser, document-scanner, edge-detection, image-processing, ocr, opencv, pdf-export, pwa

## 简介

Motor headless de escaneo de documentos: cámara, detección de bordes, procesado, OCR, calidad y exportación. Sin UI. Browser-only (consume vía bundler).
