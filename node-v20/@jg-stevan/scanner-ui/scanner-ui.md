# @jg-stevan/scanner-ui

> 标签: JavaScript

## 简介

Capa React de la base de digitalización: visor táctil ZoomableVisor (pinza anclada, pan con clamps, doble toque, rueda, comparación por pulsación larga, swipe de carrusel y modo card). Componentes puros props+callbacks. Browser-only (consume vía bundler).
