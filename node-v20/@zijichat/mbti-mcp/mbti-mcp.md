# @zijichat/mbti-mcp

> 标签: form-m, mbti, mcp, model-context-protocol, personality, ziji.chat

## 简介

MCP server exposing the ziji.chat MBTI Form M (93-question Chinese reproduction) — list questions, score answers, fetch type descriptions. Supports stdio (local) and Streamable HTTP (hosted at ziji.chat).
