# @hlao-mcp/slack-adapter

> 标签: JavaScript

## 简介

Thin HLAO adapter proxying to Slack's official remote MCP (mcp.slack.com). Enforces HLAO authority header scoping, classifies tools as read/write by verb, emits audit receipts.
