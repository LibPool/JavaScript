# @megalo/api

> 标签: alipay, megalo, swan, toutiao, web, wechat

## 简介

重新封装各个端中的API，由 megalo 统一对外抛出方法名。目前微信小程序端提供的 API 最为丰富，所以 API 名称以微信小程序为准。
