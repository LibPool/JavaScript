# @diceytable/mcp-bridge

> 标签: JavaScript

## 简介

MCP server that lets AI agents (Claude Code, Claude Desktop, Cursor, VS Code) build, preview and play-test DiceyTable mods through a consenting DiceyTable browser tab.
