# @robiki/proxy

> 标签: cors, docker, http2, middleware, proxy, reverse-proxy, routing, ssl, tls, websocket

## 简介

A flexible HTTP/2 proxy server with WebSocket support, configurable routing, CORS, and validation. Use as npm package or Docker container.
