# @hytde/ssr

> 标签: JavaScript

## 简介

Server-side rendering middleware for HyTDE. It consumes the slotified `.ssr.json` output from the Vite plugin, prefetches eligible requests, renders HTML, and embeds the SSR state for client hydration.
