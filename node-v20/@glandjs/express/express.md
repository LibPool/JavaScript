# @glandjs/express

> 标签: adapter, architecture, event-driven, express, express-adapter, framework, gland, glandjs, http, middleware, protocol, typescript

## 简介

An Express adapter for Gland HTTP protocol layer, enabling classic middleware-based routing within the Gland architecture solution.
