# @visimer/monaco

> 标签: diagram, editor, mermaid, monaco, visual-editing, wysiwyg

## 简介

Monaco binding for visimer: two-way code sync, entity highlight decorations, shared undo authority. No monaco-editor dependency; bring your own instance.
