# claude-opencode-mcp

> 标签: claude-code, coding-agent, deepseek, mcp, model-context-protocol, opencode

## 简介

MCP bridge that lets Claude Code delegate software-engineering tasks to OpenCode agents (DeepSeek by default) inside the same workspace.
