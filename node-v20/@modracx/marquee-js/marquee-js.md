# @modracx/marquee-js

> 标签: accessibility, autoscroll, browser, carousel, drag-to-scroll, infinite-scroll, jquery-plugin, logo-wall, marquee, news-ticker, reduced-motion, scroller, seamless-loop, ticker, vertical-marquee, zero-dependency

## 简介

Lightweight seamless marquee / ticker for web pages — any direction, drag to scroll, pause on hover, edge fades, and reduced-motion aware. Zero dependencies.
