# @iflow-mcp/mongodb-partners-mongodb-gemini-extension

> 标签: extension, gemini, gemini-cli, mcp, mcp-server, mongodb, mongodb-atlas

## 简介

An Official Gemini CLI extension for MongoDB — thin wrapper around the official mongodb-mcp-server npm package, providing all MongoDB database and Atlas operations through the Gemini CLI.
