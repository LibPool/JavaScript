# @iflow-mcp/jhawkins11-task-manager-mcp

> 标签: JavaScript

## 简介

This is an MCP server built to integrate with AI code editors like Cursor. The main goal here is to maximize Cursor's agentic capabilities and Gemini 2.5's excellent architecting capabilities while working around Cursor's extremely limited context window.
