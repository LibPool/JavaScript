# @iflow-mcp/dm0lz-swiss-ephemeris-mcp-server

> 标签: asteroids, astrological-calculations, astrology, astronomy, birth-chart, celestial-bodies, ephemeris, horoscope, houses, mcp, model-context-protocol, natal-chart, planetary-positions, swiss-ephemeris

## 简介

A Model Context Protocol (MCP) server that provides access to Swiss Ephemeris astronomical calculations for planetary positions, houses, chart points, and asteroids. Supports both stdio and HTTP transport modes.
