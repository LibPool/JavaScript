# @iflow-mcp/valstro-markdown-rules-mcp

> 标签: ai, copilot, cursor, docs, documentation, markdown, mcp, model context protocol, rules, windsurf

## 简介

MCP server that provides a portable and enhanced alternative to editor-specific documentation rules (like Cursor Rules). It allows you to define project documentation and context in standard Markdown files, making them usable across any MCP-compatible AI
