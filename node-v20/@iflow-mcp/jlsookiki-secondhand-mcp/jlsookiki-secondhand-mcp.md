# @iflow-mcp/jlsookiki-secondhand-mcp

> 标签: ai-tools, claude, claude-desktop, depop, ebay, facebook-marketplace, marketplace, mcp, mcp-server, model-context-protocol, resale, secondhand, thrift

## 简介

MCP server for searching secondhand marketplaces — Facebook Marketplace, eBay, and Depop. Search listings, filter by price/category/condition, and get full details with photos.
