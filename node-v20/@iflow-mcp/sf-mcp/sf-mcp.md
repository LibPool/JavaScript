# @iflow-mcp/sf-mcp

> 标签: cli, llm, mcp, modelcontextprotocol, salesforce, sf

## 简介

Model Context Protocol (MCP) server for the Salesforce CLI, making Salesforce CLI commands available to LLM tools like Claude Desktop.
