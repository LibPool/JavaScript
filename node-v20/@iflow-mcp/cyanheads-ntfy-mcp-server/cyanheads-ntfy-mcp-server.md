# @iflow-mcp/cyanheads-ntfy-mcp-server

> 标签: AI-integration, LLM, MCP, authentication, claude, client, http, jwt, messaging, model-context-protocol, notifications, ntfy, push-notifications, sdk, server, sse, template, typescript

## 简介

An MCP (Model Context Protocol) server designed to interact with the ntfy push notification service. It enables LLMs and AI agents to send notifications to your devices with extensive customization options.
