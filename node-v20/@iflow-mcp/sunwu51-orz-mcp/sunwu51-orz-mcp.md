# @iflow-mcp/sunwu51-orz-mcp

> 标签: brave-search, mcp, model-context-protocol, proxy, stdio, web-fetch, web-search

## 简介

MCP server with web_search and web_fetch tools. Searches Brave and DuckDuckGo simultaneously with deduplication. Supports HTTP proxy for users behind firewalls.
