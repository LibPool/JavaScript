# @yueliudan/lclone-memory-dsh

> 标签: dsh-plugin, external-brain, lclone, memory

## 简介

L-clone 记忆钩子：DSH 每轮结束(turn/end)自动 capture 到外置大脑；Web GUI 侧边栏「大脑看板」按钮一键打开记忆工作台。
