# @yalambar/auth-kit

> 标签: auth, authentication, credentials, drizzle, email-verification, next-auth, nextauth, nextjs, password-reset, rate-limiting

## 简介

Reusable NextAuth credentials auth for Next.js: email verification, password reset, and DB-driven rate limiting. Client-agnostic factory + dependency injection. Ships TypeScript source (add it to Next's transpilePackages).
