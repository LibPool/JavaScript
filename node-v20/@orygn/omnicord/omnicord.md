# @orygn/omnicord

> 标签: ai, claude, discord, discord-bot, mcp, mcp-server, model-context-protocol, server-builder

## 简介

Omnicord: a Discord server management MCP for AI agents. Chat, moderate, administrate, and build out entire servers from one brief, through any MCP client.
