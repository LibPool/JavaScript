# @codessy/fetch-shield

> 标签: abort, backoff, exponential-backoff, fetch, http, retry, retry-after, timeout, typescript

## 简介

Retry transient HTTP failures with exponential backoff, jitter, per-attempt timeouts, Retry-After support, and cancellation on top of the native Fetch API.
