# @ramxnchv/geotiff-tilesource

> 标签: JavaScript

## 简介

A plugin tilesource for OpenSeadragon that uses geotiff.js to provide serverless access to view compatible local or remote TIFF files. Fork of pearcetm/GeoTIFFTileSource with OSD v6 + worker-ImageBitmap optimizations.
