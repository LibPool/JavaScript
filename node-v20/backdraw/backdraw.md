# backdraw

> 标签: chatgpt, chrome-extension, claude, claude-code, image-generation, mcp, mcp-server, model-context-protocol, native-messaging, windows

## 简介

Local MCP server, native messaging host and Chrome extension that let Claude generate images with your own signed-in ChatGPT account in a background tab.
