# @open_auth/auth

> 标签: JavaScript

## 简介

A simple and lightweight authentication library for web apps using **One-Time Passwords (OTP)** and **Password-based login**. 🔒   Built in **TypeScript**, compiled for both **CommonJS** and **ESModules**.
