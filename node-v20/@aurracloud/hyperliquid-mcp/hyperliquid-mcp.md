# @aurracloud/hyperliquid-mcp

> 标签: ai, api, blockchain, claude, defi, hyperliquid, mcp, model-context-protocol, perpetuals, tools, trading, web3

## 简介

Model Context Protocol (MCP) server for Hyperliquid API integration. Provides tools for querying Hyperliquid data including balances, positions, trades, vaults, and real-time market data.
