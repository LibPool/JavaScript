# @neworange/auth-middleware

> 标签: auth, keycloak, middleware, neworange, nextjs, password, proxy, sso, vercel

## 简介

Drop-in sign-in gate for Next.js proxy/middleware and Vercel middleware: New Orange SSO (Keycloak) and/or a site password in front of an environment.
