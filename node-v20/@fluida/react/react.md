# @fluida/react

> 标签: breakpoints, container-queries, hooks, layout, react, resize-observer, responsive

## 简介

React adapter for Fluida — a Provider, viewport-based layout primitives, and a container-measuring FluidaAdaptiveGrid, all built on @fluida/core.
