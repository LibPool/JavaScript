# @sendoka/dev-mcp

> 标签: claude-code, email-api, mcp, model-context-protocol, sendoka, sms-api

## 简介

Keyless Model Context Protocol server for Sendoka — exposes public docs, OpenAPI schema, local validators, and dry-run helpers so AI coding assistants can explore the Sendoka API without an account.
