# @dlgoodchild/verifactu-ts

> 标签: aeat, factura, hacienda, invoice, invoicing, spain, tax, veri*factu, verifactu, xades

## 简介

A project-agnostic TypeScript client for Spain's VERI*FACTU invoice-verification scheme (AEAT): records, hash chain, SOAP web service, QR codes, signing and event log.
