# @clawzam/adapter-google-maps-search

> 标签: adapter, clawzam, google-maps-search, serpapi

## 简介

Search for businesses and places on Google Maps via SerpAPI. Returns names, addresses, ratings, hours, phone numbers, and GPS coordinates.
