# @kevingu/pet-jemery

> 标签: jemery, pet

## 简介

貓貓的手會在畫面右側動阿動，增加前端工程師開發時的心情娛樂度。 當滑鼠指上去時，活潑的杰莫里會側身閃出，並且點擊他會回話。 是不是很有趣呢？ ## Features ## Install ``` $ npm i @kevingu/pet-jemery ``` ## Usage ``` import { Jemery } from "@kevingu/pet-jemery" import "@kevingu/pet-jemery/dist/main.css"
