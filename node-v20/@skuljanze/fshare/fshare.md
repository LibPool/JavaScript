# @skuljanze/fshare

> 标签: ai-agent, claude-code, cli, cloudflare, cloudflared, download, file-sharing, npx, share, tunnel

## 简介

Share a local file or folder through a public download link, served from your own computer via Cloudflare Tunnel. Agent-friendly, zero dependencies.
