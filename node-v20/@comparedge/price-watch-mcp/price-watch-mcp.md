# @comparedge/price-watch-mcp

> 标签: changelog, claude, comparedge, cursor, mcp, model-context-protocol, price-changes, price-tracking, pricing, saas, saas-pricing

## 简介

MCP server for tracking SaaS, AI, and crypto pricing changes: recent moves, per-product history, category trends, biggest increases, and current price, from a human-reviewed change log.
