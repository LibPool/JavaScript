# @earthlink/env-sync

> 标签: cognito, dotenv, dotvault, env, npmrc, parameter-store, secrets, sync, vault

## 简介

dotvault — sync .env / .npmrc / .gitconfig and any config file across machines and CI/CD. No AWS account required.
