# @noctcore/eslint-plugin-prisma

> 标签: eslint, eslint-plugin, eslintplugin, multi-tenant, noctcore, prisma, soft-delete, transaction

## 简介

Prisma tenancy, data-integrity and transaction guardrails: unscoped-client and raw-SQL fences, tenant and soft-delete filters, single-writer model fences, multi-write transactions, audit placement and audit reachability.
