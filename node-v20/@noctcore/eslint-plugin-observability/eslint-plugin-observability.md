# @noctcore/eslint-plugin-observability

> 标签: eslint, eslint-plugin, eslintplugin, logging, noctcore, observability

## 简介

Structured-logging discipline ESLint rules — context objects over interpolated messages, no sensitive fields in logs, no error-detail loss.
