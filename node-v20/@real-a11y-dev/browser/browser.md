# @real-a11y-dev/browser

> 标签: a11y, accessibility, accessibility-tree, aria, browser, playwright

## 简介

Drive a real browser for Real A11y — the Playwright-based BrowserSession plus the injected page-bundle. The one way to extract a live accessibility tree from a real Chromium.
