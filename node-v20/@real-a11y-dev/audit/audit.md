# @real-a11y-dev/audit

> 标签: a11y, accessibility, accessibility-tree, aria, audit, findings, screen-reader

## 简介

The accessibility audit engine for the Semantic Navigator tree — the Finding type, the rule set, collectFindings, and the throwing assert* helpers. What every Real A11y surface reports as "broken", in one place.
