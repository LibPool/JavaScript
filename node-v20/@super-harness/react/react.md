# @super-harness/react

> 标签: agent, agents, ai, harness, headless, hooks, llm, multi-agent, react, streaming, super-line, typescript

## 简介

Headless React client for Super Harness: a framework-free HarnessClient (join, live tree via subscribeTree, ask_user/approval state machine, threads, modes) plus provider + hooks bindings. No components, no styling — bring your own UI.
