# @gnourt812005/codemap

> 标签: cli, dependency-graph, mcp, nestjs, static-analysis, ts-morph, typescript

## 简介

Statically extracts a TypeScript project's dependency graph (imports, calls, NestJS DI wiring) into a queryable SQLite database, plus an MCP server so an LLM can navigate it.
