# @schroeer-haren/dsv

> 标签: dsv, dsv7, dsv8, parser, schwimmen, swimming, wettkampf

## 简介

TypeScript library for parsing and creating DSV files (DSV7 / DSV8) used in German swimming (DSV - Deutscher Schwimm-Verband)
