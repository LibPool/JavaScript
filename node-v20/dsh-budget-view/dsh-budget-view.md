# dsh-budget-view

> 标签: budget, codex, cost, deepseek, deepseek-harness, dsh, dsh-plugin, dsh-plugins, opencode-go, token, usage

## 简介

DSH 插件：在输入栏和新会话页展示 Codex / OpenCode Go 额度、DeepSeek 余额、波峰/波谷状态，并按 DeepSeek 官方人民币峰谷价估算会话费用。
