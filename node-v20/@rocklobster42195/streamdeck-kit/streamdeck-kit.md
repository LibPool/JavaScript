# @rocklobster42195/streamdeck-kit

> 标签: elgato, plugin, property inspector, stream deck, stream deck plus, streamdeck

## 简介

(Alpha) Building blocks for Elgato Stream Deck plugins: key and touch-strip rendering, animation, Panorama effects across dials, and a framework-free property inspector kit.
