# @ai-matrx/content-ir

> 标签: JavaScript

## 简介

The AI Matrx Content IR package: the pure parser, normalized envelope, session, schema conversion and validation kernel, plus the React render layer (kind routing, component resolver, directives, kind kit) as separate sections.
