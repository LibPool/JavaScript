# @buzo/iron-clads

> 标签: async-validation, backend, browser, custom-validation, frontend, iron-clad, node, plugin, rule-registration, schema-validation, typescript, validation, validator

## 简介

A small, flexible, plugin-friendly validator for Node.js and browser projects, supporting synchronous and asynchronous rules, custom messages and locales, rule aliases, and programmatic rule registration.
