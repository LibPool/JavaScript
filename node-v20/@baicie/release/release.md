# @baicie/release

> 标签: JavaScript

## 简介

`@baicie/release` 是用于 monorepo 固定版本发版的内部 release 工具包，适合 Zeus、Zeus UI，以及其他需要统一版本、统一 changelog、canary 发版、publish-only 补发的仓库。

## 官网

- npm 页面：https://www.npmjs.com/package/@baicie/release
