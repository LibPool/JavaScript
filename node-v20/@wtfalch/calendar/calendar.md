# @wtfalch/calendar

> 标签: calendar, jmap, jscalendar, stalwart

## 简介

A JMAP calendar client for Agora, the wtfalch communications app: events, invites, sharing and free/busy over Stalwart, and the React UI on react-big-calendar.
