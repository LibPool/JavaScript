# @wtfalch/invoicing

> 标签: JavaScript

## 简介

Norwegian invoices: gapless per-org numbering, credit notes, MVA (VAT) computed and rounded per rate, line items as first-class input, HTML documents, a period CSV export and a typed EHF seam.
