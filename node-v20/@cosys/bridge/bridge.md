# @cosys/bridge

> 标签: JavaScript

## 简介

The actor at the edge of the network (ADR-22): an inbox for a foreign protocol, a codec to signed bridge: rows that each name their origin, and an outbox that deposits them into one patient's mailbox. Runs on the estate or a clinic's node, never on a phon
