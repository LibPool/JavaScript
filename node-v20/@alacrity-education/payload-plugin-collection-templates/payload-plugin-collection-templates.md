# @alacrity-education/payload-plugin-collection-templates

> 标签: cms, collections, payload, payload-plugin, payloadcms, plugin, templates

## 简介

Payload CMS plugin: reusable template collections. Promote a document to a template, create new documents that inherit from it, and switch the whole thing off from the admin panel.
