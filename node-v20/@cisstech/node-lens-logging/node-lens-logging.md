# @cisstech/node-lens-logging

> 标签: JavaScript

## 简介

Captures your app's logs and ties each one back to the request that produced it, so you can read logs in the context of a trace instead of a flat stream. Shows them live in the dashboard as a table or a timeline, filterable by severity and text.
