# @dynamic-labs-sdk/aptos

> 标签: JavaScript

## 简介

This package contains the APTOS integration for the Dynamic SDK. It enables support for APTOS external wallets using the [@aptos-labs/wallet-standard](https://github.com/aptos-labs/wallet-standard) interface.
