# dutype

> 标签: cli, command-line-utilities, disk-usage, du, filesystem, mcp, tui

## 简介

Disk usage by kind: a fast parallel TUI that shows how much of a folder is video, PDFs, node_modules, Python envs, caches, ML models, ...
