# dsh-sidebar-drawer

> 标签: bundle, cordis, deepseek-harness, drawer, dsh, plugin, sidebar, web-gui

## 简介

Edge-hover drawer for the Web GUI left sidebar: reveal it by moving the pointer to the left screen edge, keep it while the pointer stays inside, retract it when the pointer leaves
