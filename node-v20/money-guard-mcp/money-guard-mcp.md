# money-guard-mcp

> 标签: audit-log, claude, double-entry, ledger, mcp, mcp-server, migrations, model-context-protocol, money, postgres

## 简介

MCP server that checks how a project handles money: float money columns in SQL migrations, unbalanced double-entry ledger exports, and tampered sealed audit logs. Read-only and offline.
