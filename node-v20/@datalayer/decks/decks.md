# @datalayer/decks

> 标签: datalayer, decks, presentations, reactor, reveal.js, slides

## 简介

Presentations described as data: a spec-driven Reveal.js deck engine, and the Reactor plugin that lists, opens and creates decks in any Reactor shell.
