# @lutaml/lutaml-model

> 标签: lutaml, model, opal, ruby, serialization

## 简介

JavaScript release of lutaml-model, published as @lutaml/lutaml-model on npm. Opal-compiled with optional shared runtime from @lutaml/opal-runtime.
