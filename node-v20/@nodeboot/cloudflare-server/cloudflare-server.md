# @nodeboot/cloudflare-server

> 标签: cloudflare, cloudflare-workers, nodeboot, serverless

## 简介

Node-Boot Cloudflare Workers server package. It provides a simple way to create Cloudflare Workers fetch handlers using NodeBoot, with support for routing, middleware, and request handling.
