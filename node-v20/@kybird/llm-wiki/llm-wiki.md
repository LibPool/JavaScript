# @kybird/llm-wiki

> 标签: agentic-memory, ai-agent, claude-code, kanban, knowledge-graph, llm, wiki, work-loop

## 简介

LLM-friendly knowledge graph + kanban for AI coding agents. Raw daily logs → compiled wiki → merged semantic+grep search, and a card-per-file kanban the work-loop skill consumes unattended. Drop-in for any repo.
