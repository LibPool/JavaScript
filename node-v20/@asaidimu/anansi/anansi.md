# @asaidimu/anansi

> 标签: anansi, binary, codec, schema, serialization, typescript, validation, wire-format

## 简介

Self-contained TypeScript implementation of the Anansi binary wire format — schema compile/link/addressing, dense/sparse/batch packet codecs, transforms (zstd/BLAKE3/AES-GCM), and document validation. Byte-compatible with the Go implementation.
