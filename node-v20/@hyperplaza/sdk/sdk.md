# @hyperplaza/sdk

> 标签: JavaScript

## 简介

Hyperplaza NFT Marketplace SDK is an utilities for you to build your own NFT Marketplace, built with typescript ❤️, fully typed and tested. It is integrated with Serverless framework with AWS Lambda and AWS DynamoDB.
