# @pozible/meteor-sha

> 标签: JavaScript

## 简介

A simple SHA256 originally ported from [Meteor package](https://github.com/meteor/meteor/tree/devel/packages/sha). Suitable to use when migrating from Meteor's accounts-password to your own handler.
