# @rglc/storefront-sdk

> 标签: JavaScript

## 简介

biltekv2 vitrin SDK'sı: merkez API istemcisi, veri hook'ları, i18n/SEO ve sepet/üyelik context'leri. Tenant vitrin repoları tasarımı yazar, veri katmanını buradan alır.
