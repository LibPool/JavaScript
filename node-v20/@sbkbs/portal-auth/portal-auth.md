# @sbkbs/portal-auth

> 标签: JavaScript

## 简介

Integração do Portal Unificado SBK (Nexus) para produtos Node.js/Fastify: troca do código de autorização e validação do access_token via JWKS, com cache, rotação de chave e erros tipados.

## 官网

- npm 页面：https://www.npmjs.com/package/@sbkbs/portal-auth

## 历史版本号

- 1.0.0

## 获取地址

- npm registry：https://registry.npmjs.org/@sbkbs/portal-auth
- Node 要求：>=20.0.0
