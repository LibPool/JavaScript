# @torba/authliberty

> 标签: JavaScript

## 简介

[AuthLiberty](https://gitlab.com/harmoniya/authliberty) support for torba — runs Minecraft against a custom Yggdrasil-compatible backend by attaching AuthLiberty as a JVM `-javaagent`.
