# siren-core

> 标签: animation, class-diagram, diagram, er-diagram, flowchart, mermaid, sequence-diagram, siren, state-diagram, step-reveal, svg

## 简介

A Mermaid-syntax diagram renderer with declarative step-reveal, highlight and enter/exit animation, authored in the same plain-text document.
