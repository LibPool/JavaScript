# @nais-standard/sdk

> 标签: agent, ai-agent, dns, ed25519, identity, mcp, nais, resolver, signature, web3, x402

## 简介

JavaScript/Node.js SDK for the Network Agent Identity Standard (NAIS). Resolve, validate, and verify the signatures of NAIS-compliant agent cards.
