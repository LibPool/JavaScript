# strata-survey

> 标签: bus-factor, cli, code-analysis, git, git-blame, hotspots, software-archaeology, technical-debt, typescript, visualization

## 简介

A geological survey of a git repository: line-level history replay, code half-life, hotspots, temporal coupling and bus factor in one self-contained HTML report.
