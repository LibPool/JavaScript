# @kindly-note/render-markdown

> 标签: JavaScript

## 简介

One-call markdown → safe HTML for kindly-note. renderMarkdown(src, opts) composes @kindly-note/lang-markdown (CommonMark tokeniser) + @kindly-note/emitters-markdown (semantic-HTML emitter with security-first defaults) + a sensible Highlighter, with option
