# @kindly-note/loader-dynamic-import

> 标签: JavaScript

## 简介

Dynamic-import-based language loader for kindly-note. Uses native dynamic import() to load @kindly-note/lang-* packages. Works on Node, modern browsers, Deno, Bun. spec §4.2.2.
