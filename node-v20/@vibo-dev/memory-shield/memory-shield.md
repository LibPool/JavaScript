# @vibo-dev/memory-shield

> 标签: agent, audit, llm, memory, prompt-injection, security, skill, snapshot

## 简介

Protect agent memory: snapshot before compaction, poison-scan for injected instructions, audit what changed. Zero dependencies, works with any memory backend.
