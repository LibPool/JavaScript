# @glivo/plugin-sdk

> 标签: automation, gli, glivo, mcp, node, plugin

## 简介

Build Glivo plugins: the typed contract (nodes, triggers, resources, AI tools, HTTP routes, exports), the manifest and permission model, and the glivo-plugin CLI (build, validate, pack, sign, dev).
