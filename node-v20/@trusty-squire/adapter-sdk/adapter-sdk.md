# @trusty-squire/adapter-sdk

> 标签: adapter, schema, trusty-squire, zod

## 简介

Type-checked adapter manifest + learned-skill schema SDK for Trusty Squire. Defines the wire contract every adapter and registry-stored skill is validated against.
