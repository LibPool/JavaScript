# @trusty-squire/recipe-schema

> 标签: operator-recipe, schema, trusty-squire, zod

## 简介

Type-checked operator-recipe wire schema for Trusty Squire. Defines the action-path-aware replay-plan contract shared by the mcp client (record + publish) and the registry server (validate + store).
