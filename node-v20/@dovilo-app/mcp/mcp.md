# @dovilo-app/mcp

> 标签: agent, ai, claude, cursor, dovilo, mcp, model-context-protocol

## 简介

Model Context Protocol (MCP) bridge for Dovilo Desktop. Lets Cursor, Claude Code, Claude Desktop, and other AI agents run queued tasks from the Dovilo desktop app.
