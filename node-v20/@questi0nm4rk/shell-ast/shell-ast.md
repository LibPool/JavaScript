# @questi0nm4rk/shell-ast

> 标签: ast, bash, discriminated-union, mksh, mvdan-sh, parser, posix, security, shell, shellcheck, static-analysis, typescript, wasm

## 简介

Full typed AST for bash / posix / mksh + zero-config query primitives for command-level security tools. mvdan/sh compiled to WASM, exposed as TypeScript discriminated unions with sudo-aware wrapper unwrap, per-tool global value-flag tables, and helpers li
