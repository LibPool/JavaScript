# @tincre/promo-start

> 标签: JavaScript

## 简介

A modal onboarding component for Tincre [Promo](https://tincre.dev/promo). Use it in conjunction with the [`promo-dashboard`](https://github.com/Tincre/promo-dashboard) and other Promo integration applications.
