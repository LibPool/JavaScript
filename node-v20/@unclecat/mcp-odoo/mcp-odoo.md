# @unclecat/mcp-odoo

> 标签: claude, erp, json-rpc, mcp, model-context-protocol, odoo, odoo18

## 简介

MCP server for Odoo v18+ via JSON-RPC. Multi-instance support, API key or password auth, generic CRUD tools that let Claude compose workflows on any Odoo model.
