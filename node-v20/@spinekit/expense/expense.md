# @spinekit/expense

> 标签: arc, classytic, erp, expense, petty-cash, reimbursement, spine

## 简介

Arc module for @classytic/expense: expense claims with a receipt, threshold approval, reimbursement, petty-cash top-up and count, and void. Posting rides the durable events; numbering, input tax, claimant identity, media, the float balance and the outbox
