# @spinekit/promo

> 标签: arc, classytic, coupon, discount, erp, evaluation, promo, promotions, spine, voucher

## 简介

Arc module for @classytic/promo — programs, vouchers, rules, rewards, and cart evaluation as composable arc resources. BYO engine; company-wide by default (tenantField: false — a voucher generated at one branch redeems at any other); ships the promo-kerne
