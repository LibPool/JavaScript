# @spinekit/contract

> 标签: amendment, arc, classytic, contract, proration, spine, subscription, upgrade

## 简介

Arc spine module for @classytic/contract — composes the commercial agreement/amendment kernel and orchestrates plan changes (immediate upgrade first) via capability-gated ports: price resolution, settlement, entitlement reconciliation, tax.
