# @kanunilabs/datagrid

> 标签: data-grid, data-table, datagrid, filtering, grid, javascript, no-framework, sorting, table, typescript, umd, vanilla-js, virtual-scroll, virtualized, web-worker

## 简介

High-performance data grid for vanilla JavaScript — no framework required. Virtualized rows and columns, a Web Worker pipeline, sorting, filtering, grouping and theming, with a UMD build for script-tag use.
