# @maelstrom-co/realtime-livekit-agent

> 标签: ai, cartesia, deepgram, dynamic-ui, generative-ui, livekit, llm, maelstrom, node, realtime, server, voice

## 简介

Node LiveKit voice agent worker for Maelstrom: transcribes room audio via Deepgram STT and publishes the transcript back to the room; synthesizes engine responses via Cartesia TTS and publishes them into the room as an audio track.
