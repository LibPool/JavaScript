# @simplesmoothsafe/pptb-d365-apps

> 标签: admin, alm, dataverse, dynamics365, environments, powerplatform, pptb, toolbox

## 简介

Dynamics 365 apps across environments: installed version, update available, failed install per app and environment. Tick cells, preview, run: installs are queued per environment, environments run in parallel, status is polled live. Power Platform API; pac
