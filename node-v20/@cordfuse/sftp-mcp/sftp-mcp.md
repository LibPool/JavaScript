# @cordfuse/sftp-mcp

> 标签: ai-agent, file-transfer, filesystem, ftp, mcp, model-context-protocol, sftp, ssh

## 简介

SFTP as a browsable filesystem for AI agents (MCP): list, stat, move, mkdir, delete, batch, upload, download — not just upload/download. Node, stdio + streamable HTTP.
