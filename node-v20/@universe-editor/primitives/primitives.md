# @universe-editor/primitives

> 标签: path, primitives, universe-editor, uri

## 简介

Zero-dependency primitives shared by the editor kernel and the extension SDK: the URI codec/canonical shape and text-level path helpers. Internal package — no stability promise, breaking changes may land in any release.
