# @cnct/locker

> 标签: backendless, connections, data-locker, settings-sync, sign-in-with-connections, user-settings

## 简介

The Connections data locker client — per-user settings/state storage for 'Sign in with Connections' apps, no backend needed. One ≤64KB JSON document per user per app: versioned writes with automatic conflict merge, deep-merge partial updates, ETag-cached
