# @bpim/bpidef

> 标签: beatmania, bpi, cli, iidx

## 简介

CLI that turns arena-crawl score dumps into BPI song definitions: V1 (coef) release files and V2 (ALS distribution) params. Data-agnostic, no network, no database.
