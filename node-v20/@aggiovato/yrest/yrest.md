> 标签: cli, crud, fake-api, fake-backend, fastify, frontend, json-server, mock-api, mock-server, prototype, rest, rest-api, testing, typescript, yaml

## 简介

Zero-config YAML REST API mock server. Create a full CRUD fake backend from a db.yml file for frontend development, testing and prototyping.
