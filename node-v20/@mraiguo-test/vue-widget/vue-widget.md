# @mraiguo-test/vue-widget

> 标签: JavaScript

## 简介

默认打包出来的 umd 包的导出属性名是 package.json 的 name （不能是驼峰法）,但是 js 变量不能有中划线，  也就导致了导出的变量只能用 window["vue-widget"], 可以通过 `--name VueWidget` 指定暴露的变量名
