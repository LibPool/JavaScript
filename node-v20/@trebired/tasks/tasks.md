# @trebired/tasks

> 标签: background-jobs, bun, jobs, postgres, queue, sqlite, tasks

## 简介

Durable background task host for Bun with persisted task records, Postgres and SQLite storage, progress, retries, dedupe, recovery, and pluggable executors.
