# @try-works/dsh-browser-agent

> 标签: browser, deepseek-harness, dsh, dsh-plugin, headless-chrome, puppeteer

## 简介

DeepSeek Harness bundle: a Chrome browser for agents (browser_goto / browser_evaluate / browser_screenshot tools) with a live two-way pane inside the DSH Web GUI. The browser engine is a fork of zenbu-labs/terminal-browser with the React Ink terminal UI r
