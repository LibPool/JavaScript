# @doitrix/ui

> 标签: cli, components, design-system, nuxt, registry, tailwindcss, vue, vue3

## 简介

The Doitrix component registry — professional Vue 3 components you install into your own code with `doitrix-ui add`, built on @doitrix/headless and @doitrix/tokens.
