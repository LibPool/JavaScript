# @skuio/storefront

> 标签: JavaScript

## 简介

The store platform behind SKU.io storefronts: catalogue, checkout, orders, buyer portal and the Store API over one SQL driver — Cloudflare D1 or SQLite on any Node host. Framework-agnostic; pairs with the Astro reference template.
