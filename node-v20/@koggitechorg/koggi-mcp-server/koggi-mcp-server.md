# @koggitechorg/koggi-mcp-server

> 标签: JavaScript

## 简介

Una herramienta (MCP server) ligera para exponer un comando/tool llamado `generate_simulator` usado para generar un simulador financiero basándose en el número de documento (id de lead) de un usuario. El servidor implementa el protocolo Model Context Prot
