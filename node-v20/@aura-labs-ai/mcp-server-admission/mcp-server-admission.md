# @aura-labs-ai/mcp-server-admission

> 标签: admission, agent, aura, ed25519, mcp, sandbox

## 简介

AURA admission MCP server: the local action layer that onboards an agent onto the AURA certification bench. Holds the agent's Ed25519 keys and signs every admission request locally — keys never leave the machine.
