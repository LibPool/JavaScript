> 标签: 3d, accessible, calendar-heatmap, contribution-graph, data-visualization, grid, headless, heatmap, hexbin, isometric, punchcard, quantile, react, svg, themeable

## 简介

A headless heatmap toolkit for React. Any grid, eight cell shapes, a 3D SVG mode, and full control of colour, size and layout.
