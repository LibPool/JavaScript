# antigravity-sidecar-kit

> 标签: agy, antigravity, antigravity-plugin, antigravity-sidecar, google-antigravity, hangar, sdk, sidecar

## 简介

Zero-dependency SDK and CLI scaffolder for Google Antigravity Auxiliary Pane sidecars (Connect RPC client, host theme & Tailwind proxy, BOM-safe config store, workspace URI matcher, and npx-safe installer).
