# @shreyansh1407/relaykit

> 标签: agents, ai, antigravity, claude, cli, codex, context, cursor, handoff, sdk, windsurf

## 简介

Seamless context handoff between AI coding agents. Capture coding-task context from one agent (e.g. Claude Code) and hand it off cleanly to another (Codex, Cursor, Windsurf, Antigravity, ...).
