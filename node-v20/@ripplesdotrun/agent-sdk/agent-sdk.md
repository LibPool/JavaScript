# @ripplesdotrun/agent-sdk

> 标签: agent, arc, dual-fill, erc20, launchpad, nft, ripples, robinhood-chain, solana, uniswap-v4

## 简介

Signs Ripples actions (launch with a spending charter, trade, and create, join or claim Crosscurrents on two or three chains) from an agent's own keys. Does not run an agent: bring your own model loop, memory and policy.
