# @minhduydev/pi-learning

> 标签: append-only, auditability, learning, pi, pi-coding-agent, pi-extension, pi-package, selective-fork, trust

## 简介

Append-only project-local learning ledger for Pi with two separate trust gates: manual human approval, and a bounded auto-safe machine gate that is on by default in Pi-trusted projects. Selective fork of Matt Devy's pi-continuous-learning.
