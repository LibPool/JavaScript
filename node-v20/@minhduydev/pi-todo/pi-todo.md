# @minhduydev/pi-todo

> 标签: durable, extension, markdown, pi, pi-coding-agent, productivity, subagents, tasks, todo

## 简介

Durable markdown todo manager for Pi Coding Agent — structured TODO.md phases, a `todo` tool + `/todo` command, optional TUI widget, and single-active-task invariants.
