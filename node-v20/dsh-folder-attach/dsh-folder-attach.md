# dsh-folder-attach

> 标签: attachment, composer, deepseek, deepseek-harness, directory, dsh-bundle, dsh-plugin, folder

## 简介

Drag folders into the DeepSeek Harness web composer instead of hitting 'only the desktop app supports folders'. Adds a host folder dialog, /folder, and drag/paste into @path mentions. Plain browser, no desktop app.
