# @envolvr/sdk

> 标签: agents, ai, attestation, inference, openai, private, receipts, robinhood-chain, tdx, tee, usdg, verifiable

## 简介

envolvr client: wallet sign-in, USDG deposits, private inference with signed receipts, and receipt verification (signature, billing, on-chain anchor).
