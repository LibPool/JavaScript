# @petridhsg/medusa-plugin-analytics

> 标签: analytics, dashboard, ecommerce, medusa, medusa-plugin, medusa-v2, reporting

## 简介

Pre-aggregated order analytics for Medusa v2. Tracks daily, product, and customer stats and exposes a full admin dashboard API — no raw SQL required.
