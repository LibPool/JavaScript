# @fossil-lang/introspect

> 标签: JavaScript

## 简介

Source-binding schema introspection for the Fossil editor — the canonical TS home for extractSourceRefs + DuckDB type mapping + InferredDescriptor construction. Host injects the data plane (URL resolve + DuckDB query).
