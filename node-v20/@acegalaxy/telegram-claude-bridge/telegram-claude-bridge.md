# @acegalaxy/telegram-claude-bridge

> 标签: ai-bot, anthropic, claude, claude-code, cli-bridge, codex, openai, stream, telegram, voice, whisper

## 简介

Telegram bot ↔ Claude / Codex CLI bridge with multi-project switching and optional Whisper voice. Layout: <install-dir>/{.env, projects/}. Each project may carry its own .claude/ harness. Switch per-chat with /project <name>. Zero orchestrator, zero queue
