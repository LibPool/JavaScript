> 标签: ai-agents, bitcoin, claude, document-verification, evidence, file-integrity, fre-902, gemini, mcp, model-context-protocol, opentimestamps, sha-256, unfakable

## 简介

Model Context Protocol server for Unfakable document verification. Lets AI agents verify document integrity before acting on a file. Five tools: verify_file, verify_url, verify_hash, lock_file, get_evidence_pack.
