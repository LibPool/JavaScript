# @itsgg/vazhi

> 标签: coding-agent, free, gemini, llm, nvidia-nim, openrouter, pi, pi-package, router

## 简介

Free LLM auto-router for the pi coding agent: every request goes to the best free model that is up, from a model list rebuilt nightly.
