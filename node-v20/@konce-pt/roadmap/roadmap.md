# @konce-pt/roadmap

> 标签: design-system, gantt, koncept-ui, kpt, roadmap, timeline

## 简介

Roadmap/Gantt core for Koncept UI — calendar arithmetic, timeline bands and cells, row layout, lane packing and dependency geometry. Framework-free TypeScript, zero runtime dependencies.
