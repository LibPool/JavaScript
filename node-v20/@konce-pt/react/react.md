# @konce-pt/react

> 标签: component-library, design-system, koncept-ui, kpt, react, react-components, ui-library

## 简介

Open-source React 19 component library on the Koncept UI design system — the same kpt-* CSS layer and --kpt-* tokens as the Angular port. Zero runtime dependencies.
