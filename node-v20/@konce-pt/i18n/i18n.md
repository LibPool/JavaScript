# @konce-pt/i18n

> 标签: design-system, i18n, internationalization, koncept-ui, kpt, translations

## 简介

Translation contract and base dictionaries (EN, PL) for Koncept UI — shared by the Angular and React ports. Pure TypeScript, zero runtime dependencies.
