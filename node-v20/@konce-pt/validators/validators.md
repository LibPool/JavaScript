# @konce-pt/validators

> 标签: iban, koncept-ui, nip, nrb, pesel, poland, polish, regon, validators

## 简介

Polish-domain validators for Koncept UI — NIP, REGON, PESEL, IBAN, postal code, bank account (NRB). Pure TypeScript, zero runtime dependencies.

- 源码仓库：git+https://gitlab.com/konce-pt/koncept-ui.git
- npm 页面：https://www.npmjs.com/package/@konce-pt/validators
