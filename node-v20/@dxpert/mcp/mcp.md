# @dxpert/mcp

> 标签: claude-code, codex, dxpert, industrial-ai, mcp, uns

## 简介

Stdio MCP server for dxpert.ai API keys: ask dxpert Advisor, run the UNS agents included in dxpert Pro (Try Pro on a free key), run diagnostics, and convert day-one CSV exports.
