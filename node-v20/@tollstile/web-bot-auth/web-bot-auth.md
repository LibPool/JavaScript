# @tollstile/web-bot-auth

> 标签: agent-identity, agent-payments, ai-agents, bot-authentication, http-message-signatures, rfc9421, verified-agents, web-bot-auth

## 简介

Allow only verified AI agents: verify Web Bot Auth HTTP message signatures (RFC 9421) before an agent can pay or access a route. A Tollstile requirement.
