# @tollstile/express

> 标签: agent-payments, api-monetization, express, express-middleware, mpp, paid-api, pay-per-call, payment-middleware, x402, x402-express

## 简介

Express middleware to charge per API call with x402, MPP, credits, and subscriptions. Holds the response until payment settles.
