# @3apps/fcm-notifications

> 标签: cloud-tasks, fcm, firebase, push-notifications, remote-config

## 简介

Notificações push automáticas por segmento (país ou idioma) com Firebase: Remote Config → Cloud Scheduler → Cloud Tasks → FCM, no fuso de cada segmento.
