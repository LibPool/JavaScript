# @tb.p/crypt

> 标签: aes, aes-ctr, decrypt-stream, encryption, range-request, scrypt, seekable, streaming

## 简介

Seekable AES-256-CTR file encryption with scrypt key derivation and a gzip-disguised header. Supports HTTP range streaming of encrypted files.
