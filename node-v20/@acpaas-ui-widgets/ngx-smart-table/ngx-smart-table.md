# @acpaas-ui-widgets/ngx-smart-table

> 标签: JavaScript

## 简介

This is the Angular 6+ UI for a Smart Widget implementing a table whose configuration is provided by the backend. When the corresponding API is implemented in the BFF, it provides automatic support for column types, filtering, pagination and sorting witho
