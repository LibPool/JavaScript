# @willcgage/module-schematic

> 标签: ctc, dispatcher, free-mo, freemo, model-railroad, schematic, track-graph

## 简介

Shared FreeMo module operations-schematic (track-graph): doc types, parser, feature resolver, N-scale helpers, and the editor state machine. Authored by the Module Repository, imported by Free-Dispatcher.
