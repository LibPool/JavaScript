# @geoseal/expo

> 标签: background-location, expo, expo-config-plugin, geofence, geoseal, location, react-native

## 简介

Geoseal location / geofence / ingest SDK for Expo (SDK 51+). A config plugin wiring the iOS/Android background-location config plus a thin re-export of @geoseal/react-native. The SDK is a sensor; all detection logic runs server-side.
