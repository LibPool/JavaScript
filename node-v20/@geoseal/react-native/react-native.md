# @geoseal/react-native

> 标签: background-location, geofence, geoseal, location, react-native, turbomodule

## 简介

Geoseal location / geofence / ingest SDK for React Native (iOS + Android). A thin bridge over the @geoseal/capacitor native cores; all detection logic runs server-side.
