# @greenwood/plugin-import-json

> 标签: ESM, Full Stack Web Development, Greenwood, JSON, NodeJS, Static Site Generator, Web Components

## 简介

A Greenwood plugin to allow you to use ESM (import) syntax to load your JSON.
