# @junixlabs/apiflow

> 标签: api, codebase-map, dependency-graph, developer-tools, impact-analysis, mcp, mcp-server, openapi, static-analysis

## 简介

A screen ↔ endpoint ↔ field dependency map: answers which screens break if you change an endpoint or a response field. Local-first, git-friendly, open source.
