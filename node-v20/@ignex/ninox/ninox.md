# @ignex/ninox

> 标签: aggregation, cache, dataloader, json-schema, mongodb, orm, query-builder, schema, typescript

## 简介

Schema-first MongoDB ORM with DataLoader-batched relations, query caching, in-flight dedup, and $facet pagination
