# @privitty/stdio-rpc-server

> 标签: JavaScript

## 简介

This package spawns the `deltachat-rpc-server` core binary (JSON Lines JSON-RPC over stdio). It avoids NAPI bindings—cross-compilation and deployment stay simple.
