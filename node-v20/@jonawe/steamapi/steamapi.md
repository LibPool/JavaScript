# @jonawe/steamapi

> 标签: JavaScript

## 简介

This is a wrapper for the steam api written in typescript. The project is based on [steam-api-ts](https://github.com/JarivdKaap/steam-api-ts) and [node-steamapi](https://github.com/xDimGG/node-steamapi).

## 官网

- npm 页面：https://www.npmjs.com/package/@jonawe/steamapi
