# @queryjs/typeorm

> 标签: adapter, orm, query, query-parser, queryjs, typeorm

## 简介

TypeORM adapter for QueryJS: translates validated ResourceQuery objects into TypeORM where, order, skip, and take arguments using real FindOperators.
