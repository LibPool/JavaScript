# @cntrlx/n8n-nodes-pdfgenie-pro

> 标签: n8n-community-node-package

## 简介

Node for using PDFKit to transform images into PDF, merge PDFs, convert Excel to PDF, and convert DOCX to PDF with formatting preservation.
