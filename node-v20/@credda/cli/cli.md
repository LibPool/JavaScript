# @credda/cli

> 标签: bug-reproduction, cli, command-surface, credda, debugging, mirror

## 简介

Public source mirror of the Credda CLI command surface. Ships no executable: install the `credda` package for the CLI itself. Replaces the retired 0.x, which was an unrelated product.
