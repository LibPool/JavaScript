# @aithos/mcp-remote

> 标签: JavaScript

## 简介

Aithos RemoteStorage — an AithosStorage backed by the Aithos platform primitives (reads + delegate-signed transactional writes). Pairs with @aithos/mcp for the agent-at-the-client shape.
