# @ddmnpm/ddm-product-visual-design

> 标签: JavaScript

## 简介

当用户需要把模糊品牌、App、AI agent、网站或内容产品推进到产品视觉设计时使用；触发于 logo/icon、App 图标、品牌颜色、自媒体卡片、网站 DESIGN.md、visual kit 和视觉方向，不用于无品牌判断的单纯图片美化。
