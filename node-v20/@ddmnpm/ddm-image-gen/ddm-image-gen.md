# @ddmnpm/ddm-image-gen

> 标签: JavaScript

## 简介

Generate or edit raster images with fixed gpt-image-2 through a DDM-configured image API endpoint. Use when image generation/editing must send requests to DDM_IMAGE_API_URL with DDM_IMAGE_API_KEY instead of using Codex built-in image generation or the pub
