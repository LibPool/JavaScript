# @oxc-angular-testing/binding-linux-x64-gnu

> 标签: JavaScript

## 简介

Fast Angular test transforms (resource inlining, decorator downleveling, signal initializer APIs) on oxc, with optional istanbul coverage instrumentation in a single AST pass.
