# @krasnovbusiness/devtools

> 标签: color-picker, design-qa, devtools, eyedropper, inspector, react, ruler

## 简介

Плавающий тулбар для дизайн-QA в браузере: линейка (размеры и расстояния, Figma-style), копирование контейнера в буфер для AI и колор-пикер. Чистый React, без Tailwind. Один файл — копируется в любой проект через npx.
