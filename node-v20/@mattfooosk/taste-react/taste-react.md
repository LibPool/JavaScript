# @mattfooosk/taste-react

> 标签: admin-drawer, claude-code, design, react, section-registry, taste, theme-provider

## 简介

The Taste runtime — <ThemeAdminProvider>, <SectionRegistryProvider>, <TasteAdmin /> drawer, <TasteSection> wrappers. Your app's users adjust the theme, add sections, and edit content inside the drawer; you decide which controls each tier unlocks.
