# @ar-agents/identity

> 标签: afip, agent, agentic, ai-sdk, argentina, cuil, cuit, identity, tax-id, vercel-ai

## 简介

Argentine identity validation (CUIT/CUIL) + AFIP padrón lookup as drop-in tools for the Vercel AI SDK. Algorithm-only out of the box; AFIP webservice via pluggable adapter when a cert is wired.
