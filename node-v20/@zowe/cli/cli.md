# @zowe/cli

> 标签: CLI, mainframe, mvs, os390, z/OS, z/OSMF, zos, zosmf, zowe

## 简介

Zowe CLI is a command line interface (CLI) that provides a simple and streamlined way to interact with IBM z/OS.
