# @tencentcloud/roomkit-web-react

> 标签: conference, javascript, react, tuiroomkit, webrtc

## 简介

腾讯云 TUIRoomKit 音视频房间 UI 组件库（React 版本）。提供会前预检与会中两套完整的 UI 视图组件，并配套完整的会议生命周期控制 API，帮助开发者快速将多人音视频会议能力集成到现有 React 项目中。
