> 标签: IM, WebSocket, chat, messaging, tencent, tencentcloud, uikit, uni-app, 即时通信, 通信

## 简介

TUIKit 是基于 IM SDK 实现的一套 UI 组件，其包含会话、聊天、群组、个人资料等功能，基于这些精心设计的 UI 组件，您可以快速构建优雅的、可靠的、可扩展的 Chat 应用。
