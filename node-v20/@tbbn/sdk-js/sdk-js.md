# @tbbn/sdk-js

> 标签: api, barter, exchange, marketplace, sdk, tbbn, trade, trade by barter

## 简介

JavaScript client for the TBBN Platform API — publish listings, manage offers and trade sessions, and verify webhooks. Works anywhere fetch does.
