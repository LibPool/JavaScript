# @ekwo-ai/camt053

> 标签: bank-statement, bank-to-customer-statement, camt.053, camt053, iso20022, parser, reconciliation, sepa, xml

## 简介

Reads an ISO 20022 bank-to-customer statement (camt.053) into plain objects in TypeScript: account, balances and lines, amounts as decimal strings, and what does not add up. Zero dependencies, its own strict XML reader.
