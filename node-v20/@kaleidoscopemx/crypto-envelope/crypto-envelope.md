# @kaleidoscopemx/crypto-envelope

> 标签: aes-gcm, bridge, encryption, forge, kaleidoscopemx

## 简介

Versioned AES-256-GCM envelope for KaleidoscopeMX bridge connectors. One implementation shared by connectors, the KMX server, and the browser.
