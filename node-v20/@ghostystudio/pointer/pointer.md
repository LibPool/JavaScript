# @ghostystudio/pointer

> 标签: ai-agents, element-picker, ghosty, ghosty-studio, html, visual-editing

## 简介

«Señalar»: point at an element of an HTML page, let an agent read it just-in-time and change ONLY that node — picker, in-iframe runtime (Penpal) with double-click text editing, byte-exact node splice, scope heuristics and write guards.
