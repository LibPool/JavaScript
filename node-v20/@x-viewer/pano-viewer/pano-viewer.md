# @x-viewer/pano-viewer

> 标签: 360, 360-viewer, cubemap, equirectangular, hotspot, immersive, javascript, pano, panorama, panorama-viewer, real-estate, three.js, threejs, typescript, virtual-tour, vr, webgl

## 简介

A WebGL-based 360° panorama viewer SDK built on three.js. Supports equirectangular images, cubemaps, multi-viewpoint tours, hotpoints, and custom 3D decorations.
