# @surdeddd/bottom-sheet

> 标签: a11y, bottom-sheet, drawer, framework-agnostic, gesture, headless, lit, modal, pointer-events, preact, qwik, react, snap-points, solid-js, ssr, svelte, vue, web-component

## 简介

Universal, headless bottom sheet — framework-agnostic core with React, Vue 3, Svelte, Solid, Qwik, Preact, Lit and Custom Element adapters. Pointer Events, snap points, momentum, a11y, SSR-safe.
