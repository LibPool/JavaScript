# @cerbos/embedded

> 标签: ABAC, Cerbos, PDP, RBAC, WASM, WebAssembly, access control, attribute-based access control, authorization, embedded, permissions, policy, policy decision point, role-based access control, roles, security

## 简介

Client library for interacting with embedded Cerbos policy decision points generated by Cerbos Hub from server-side Node.js and browser-based applications
