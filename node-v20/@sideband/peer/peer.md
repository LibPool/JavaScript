# @sideband/peer

> 标签: client, p2p, peer, pubsub, rpc, runtime, sdk, sideband, transport

## 简介

Peer SDK for Sideband: friendly API over runtime + transports with lifecycle utilities, pub/sub, and RPC helpers to run peers quickly.
