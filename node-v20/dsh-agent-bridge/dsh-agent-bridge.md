# dsh-agent-bridge

> 标签: agent, bridge, claude-code, cli, codex, cordis, deepseek-harness, dsh, dsh-plugin, gemini, opencode, recipe

## 简介

Bridge DeepSeek Harness to whatever coding-agent CLI is installed (OpenCode, Claude Code, Codex, Gemini, ...) through data-driven recipes: auto-discovery, capability-driven UI, per-run reports.
