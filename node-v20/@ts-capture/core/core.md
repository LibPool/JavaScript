# @ts-capture/core

> 标签: annotations, ast, cli, inference, instrumentation, ts-capture, type-inference, types, typescript

## 简介

ts-capture core — capture runtime values, shape them as TypeScript types. Engine + CLI for instrumentation, observation, and apply. (0.x — API may change between minor versions.)
