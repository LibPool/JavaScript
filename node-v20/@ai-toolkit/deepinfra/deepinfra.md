# @ai-toolkit/deepinfra

> 标签: ai-toolkit

## 简介

The **[DeepInfra provider](https://sdk.khulnasoft.com/providers/ai-toolkit-providers/deepinfra)** for the [AI TOOLKIT](https://sdk.khulnasoft.com/docs) contains language model support for the DeepInfra API, giving you access to models like Llama 3, Mixtra
