# @oko-wallet/oko-sdk-core-react-native

> 标签: oko, react-native, wallet

## 简介

React Native SDK for [Oko](https://oko.app) — an embedded wallet powered by MPC threshold signatures. Uses the OS browser (ASWebAuthenticationSession on iOS, Chrome Custom Tabs on Android) for authentication and signing instead of a WebView.
