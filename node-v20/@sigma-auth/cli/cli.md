# @sigma-auth/cli

> 标签: bap, bitcoin, cli, oauth, sigma-auth

## 简介

Headless Sigma Auth CLI: create a BAP identity locally, sign in with Bitcoin-Auth, diagnose public identities, push encrypted backups, register OAuth clients
