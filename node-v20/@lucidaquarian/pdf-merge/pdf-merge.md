## 简介

Merge PDFs from Base64 strings, Buffers, file paths, or URLs — and assemble PDFs from text (.txt) and image (.png/.jpg) inputs — in Node.js and the browser, with page selection, document metadata, text & image watermarks, page numbers, AbortSignal cancell
