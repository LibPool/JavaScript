# @spoolkit/cli

> 标签: agent, cli, demo, loom, playwright, screen-recording, spool, voiceover, walkthrough

## 简介

Agents record their own spools: real browser video, AI voiceover, word-synced captions, ffmpeg-rendered MP4. No human hits record.
