# @apipurse/sdk

> 标签: anthropic, apipurse, cost-tracking, llm, openai

## 简介

Automatically report OpenAI/Anthropic token usage to APIPurse the instant a completion finishes, via wrapOpenAI()/wrapAnthropic() client wrappers (or manual trackCompletion() calls) — for real-time cost tracking and budget alerts. Not a proxy: no request/
