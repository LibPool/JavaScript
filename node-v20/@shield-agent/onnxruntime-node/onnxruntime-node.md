# @shield-agent/onnxruntime-node

> 标签: ONNX, ONNX Runtime, ONNXRuntime

## 简介

Script-free republish of onnxruntime-node (MIT, Microsoft) for @shield-agent/kya. The upstream postinstall only downloads optional Linux CUDA binaries; CPU binaries for darwin/linux/win32 are bundled here unchanged.
