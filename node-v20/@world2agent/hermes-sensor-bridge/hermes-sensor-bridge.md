# @world2agent/hermes-sensor-bridge

> 标签: bridge, hermes, hermes-agent, sensor, w2a, webhook, world2agent

## 简介

World2Agent bridge for Hermes Agent — runs sensors as supervised subprocesses and delivers their signals into Hermes via webhook subscriptions
