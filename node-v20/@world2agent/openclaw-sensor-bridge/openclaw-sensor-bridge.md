# @world2agent/openclaw-sensor-bridge

> 标签: bridge, openclaw, sensor, w2a, webhook, world2agent

## 简介

World2Agent bridge for OpenClaw — runs sensors as supervised subprocesses and delivers their signals into OpenClaw via the gateway's /hooks/agent webhook
