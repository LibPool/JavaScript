# file-toolkit-mcp

> 标签: compress, convert, file, image, local, mcp, pdf, workbuddy

## 简介

Local file toolkit MCP server for WorkBuddy. Compress, convert and resize images; split, merge and rasterize PDFs; convert CSV/JSON/Markdown; batch rename and inspect files. 100% local processing, no uploads, no paid APIs.
