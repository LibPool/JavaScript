# @astragenie/astramem-client

> 标签: JavaScript

## 简介

Shared fail-silent client seam for the astramem memory plugin — provider resolution (dep-mode selector, dep-mode local/saas probe, runtime plugin-root discovery) plus wallclock-capped remember/recall calls — plus AstramemDaemonClient, a typed direct HTTP
