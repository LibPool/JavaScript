# @pulse-protocol/ipfs

> 标签: JavaScript

## 简介

DAG-CBOR serialisation and CIDv1 computation for Pulse Protocol consent records. Mirrors [`pulse-protocol-go/ipfs`](https://github.com/smarter-contracts/pulse-protocol-go) with byte-identical output.
