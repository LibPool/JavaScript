# @foresightjs/astro

> 标签: astro, astro-component, astro-integration, foresight, foresightjs, interaction-prediction, js.foresight, mouse-trajectory, performance, prefetch, withastro

## 简介

Astro integration for ForesightJS. Predictive prefetching that fires before hover, configured like Astro's built-in prefetch strategies.
