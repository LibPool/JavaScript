# @paramour-js/nuqs

> 标签: nextjs, nuqs, query-string, search-params, type-safe, typescript, url-state

## 简介

nuqs integration for paramour: derive nuqs parsers from a route's search codecs — presence, defaults, catch recovery, and equality read off the codec once, mechanically.
