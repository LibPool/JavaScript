# @yuants/app-postgres-storage

> 标签: JavaScript

## 简介

`@yuants/app-postgres-storage` 是 Yuan 体系中的 PostgreSQL 存储服务，通过在 Host 侧注册统一的 `SQL` 接口，为各终端提供安全、可观测的远程数据库访问能力。服务内置连接池、查询取消与指标采集，可部署在本地服务器、Docker 或 Kubernetes 集群中。
