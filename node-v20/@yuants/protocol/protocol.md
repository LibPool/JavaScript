# @yuants/protocol

> 标签: JavaScript

## 简介

`@yuants/protocol` 定义了 Yuan 体系的终端通信协议、数据模型与运行时，封装 WebSocket / WebRTC 渠道、请求路由与指标采集，帮助业务终端以统一方式接入 Host。
