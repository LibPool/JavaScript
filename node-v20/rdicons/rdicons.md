# rdicons

> 标签: cli, icon-generator, icons, lucide, rdicons, react, svg, tabler, tsx

## 简介

rdicons command line: search 78,000+ open-source icons and add them to your project as SVG, JSX or TSX. Try: npx rdicons add lucide:house
