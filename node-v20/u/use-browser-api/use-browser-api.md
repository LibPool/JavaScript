# use-browser-api

> 标签: api, browser, clipboard, custom-hook, device-orientation, event-driven, fullscreen, hook, network, react, react-hook, react-state, scroll-position, useSyncExternalStore, viewport, visibility

## 简介

React hook built on useSyncExternalStore to access event-driven browser APIs like network, scroll, fullscreen, and more as subscribable stores.
