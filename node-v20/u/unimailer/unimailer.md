# unimailer

> 标签: aws-ses, bulk-email, bun, cloudflare-workers, deno, dkim, edge, email, email-api, email-attachments, email-library, email-queue, email-sending, email-service, email-transport, email-validation, failover, html-email, mailer, mailgun, mime, multi-provider, multipart, nodejs, nodemailer, oauth2, postmark, provider, react-email, resend, resend-api, retry, sendgrid, serverless, smtp, transactional-email, ts, typescript, vercel-edge

## 简介

Modern, multi-runtime email library for Node.js, Bun, Deno, and Edge. SMTP + HTTP providers with automatic failover, retry logic, DKIM signing, and MIME encoding.
