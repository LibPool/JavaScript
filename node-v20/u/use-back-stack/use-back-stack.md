# use-back-stack

> 标签: back-button, back-stack, backstack, drawer, history, hook, modal, navigation, nextjs, overlay, pwa, react, react-hooks, ssr

## 简介

A React hook that turns browser history into a native-like back stack, so modals, drawers and other overlays close with the back button. Works with any React framework.
