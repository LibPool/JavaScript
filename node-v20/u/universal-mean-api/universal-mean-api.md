# universal-mean-api

> 标签: JavaScript

## 简介

This package allows you to set up a backend API using node.js & mongodb in 2 minutes. NodeJs-Express-MongoDB-Universal-CRUD-API(Universal MEAN API) for dynamic MongoDB tables, no need to repeat the CRUD API code for every table. Focus on run it in a serve
