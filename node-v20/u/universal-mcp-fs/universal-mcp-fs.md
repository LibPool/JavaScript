# universal-mcp-fs

> 标签: ai-filesystem, ai-tools, claude, claude-desktop, filesystem, local-mcp, mcp, mcp-server, model-context-protocol

## 简介

Local MCP server that gives AI assistants (Claude Desktop and other stdio-compatible MCP clients) filesystem access and command execution on your machine, with elicitation-based approval for dangerous operations.
