# use-overlay-stack

> 标签: alert-dialog, dialog, hook, modal, overlay, provider, radix, react, shadcn, sheet, singleton

## 简介

One Sheet. One Dialog. One AlertDialog. Open any of them from anywhere in your React app without prop-drilling state or fighting nested z-index.
