# upath

> 标签: UNC paths, add extension, change extension, cross-platform, default extension, esm, extension, file extension, forward-slash, path, replace extension, trim extension, typescript, unix, windows

## 简介

A drop-in replacement / proxy to Node.js path, replacing \\ with / for all results & adding file extension functions.
