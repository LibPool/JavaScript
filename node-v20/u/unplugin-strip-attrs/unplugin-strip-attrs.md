# unplugin-strip-attrs

> 标签: data-cy, data-testid, esbuild-plugin, jsx, rollup-plugin, rspack-plugin, strip-attrs, svelte, unplugin, vite-plugin, vue, webpack-plugin

## 简介

Strip test-related attributes like data-testid and data-cy from JSX, Vue, Svelte, and HTML at build time.
