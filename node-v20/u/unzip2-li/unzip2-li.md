# unzip2-li

> 标签: JavaScript

## 简介

Streaming cross-platform unzip tool written in node.js.  It is an improved version of [Evan Oxfeld's node-unzip](https://github.com/isaacs/node-tar), which supports unzipping for files with a "STORE" compression (uncompressed files).
