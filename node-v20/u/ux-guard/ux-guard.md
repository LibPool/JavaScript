# ux-guard

> 标签: ai, ai-agents, code-quality, empty-state, error-state, form-validation, lint, linter, loading-state, mcp, nextjs, react, ui, ux

## 简介

ESLint catches bad code. ux-guard catches unfinished UX. A linter for missing UI states (loading, empty, error, validation, disabled submit, success feedback) in React / Next.js. Built for humans and AI coding agents.
