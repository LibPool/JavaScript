# ultimateinbox

> 标签: JavaScript

## 简介

The Ultimate Inbox extension offers you a convenient way of searching the web by changing your Firefox™ browser settings (startup page, home page, new tab, and default search) to custom search powered by Bing®.

 Privacy: http://info.trovi.com/Privacy
