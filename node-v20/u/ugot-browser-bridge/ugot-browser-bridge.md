# ugot-browser-bridge

> 标签: agent, automation, browser, chrome-extension, claude, codex, mcp

## 简介

Shared Rust browser service with MCP and CLI clients and a Node execution adapter for Ugot CEF, Chrome extension and explicit CDP sessions.
