# unused-sweep

> 标签: asset-cleanup, bundle-size, cleanup, cli, code-quality, dead-assets, dead-code, frontend, images, knip, lint, monorepo, next.js, nextjs, react, refactor, static-assets, unused-assets, unused-dependencies, unused-exports, unused-files, unused-images, unused-sweep, vite, webpack

## 简介

Find unused images, static assets, and media in React/Next/Vite apps; optional Knip for unused deps and exports. CLI for monorepos and single repos.
