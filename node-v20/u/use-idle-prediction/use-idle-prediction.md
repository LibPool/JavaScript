# use-idle-prediction

> 标签: activity detection, afk, hooks, idle, idle prediction, predict idle, prediction, presence, react, react hook idle, session, user activity, user behavior, user idle

## 简介

A React hook that predicts when a user is likely to go idle based on recent activity patterns (mouse, keyboard, touch).
