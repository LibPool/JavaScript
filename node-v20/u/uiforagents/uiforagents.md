# uiforagents

> 标签: agent, ai-agents, css, design-identities, design-system, llm, prompt-pack, shadcn, tailwind, theme, ui-kit

## 简介

Design system factory: opinionated, agent-ready design identities - shadcn/ui kits and pure-CSS artifact systems - each with a prompt-pack, theme or foundation stylesheet, and a derive contract. Run npx uiforagents list.
