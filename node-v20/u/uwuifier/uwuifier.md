# uwuifier

> 标签: JavaScript

## 简介

Uwuifier is a lightweight package that allows you to uwuify any words or sentences (excluding URL's) with many configurable parameters!

- 源码仓库：git+https://github.com/Schotsl/Uwuifier.git
