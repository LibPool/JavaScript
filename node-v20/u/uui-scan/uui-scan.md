# uui-scan

> 标签: accessibility, automation, mcp, page-object, playwright, scanner, selectors, testing

## 简介

Escanea una pantalla (web hoy, escritorio después) y devuelve el catálogo de selectores: cada campo con su id, name, tipo, si es obligatorio y con qué selector alcanzarlo. CLI + servidor MCP.
