# uni-cos-sts-upload

> 标签: JavaScript

## 简介

在 uni-app 开发的 app 中，解决实现 app 直传 cos 没有现成 SDK 问题。非 uni-app 做 app 项目，建议优先考虑腾讯云官方SDK，本SDK仅提供 postObject 能力，没有实现全部 cos 能力。
