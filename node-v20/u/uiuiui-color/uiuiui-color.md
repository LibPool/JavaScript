# uiuiui-color

> 标签: JavaScript

## 简介

Based on the [uiuiui](https://github.com/danburzo/uiuiui) component library, __uiuiui-color__ offers React components to build color pickers. It uses [culori](https://github.com/danburzo/culori) as the color library.
