# unplugin-tdesign-icons

> 标签: icons, react, rollup, tdesign, tdesign-icons, unplugin, vite, vue, web-components, webpack

## 简介

An unplugin for on-demand importing TDesign icons (vue / vue-next / react / web-components). Auto rewrites `import { XxxIcon } from 'tdesign-icons-xxx'` to the exact icon module, avoiding bundling all 2000+ icons.
