# ui-scratch

> 标签: 3d, cli, components, gpu, react, registry, shaders, skratch, vgpu, webgpu, wgsl

## 简介

Install WebGPU components like source. One command copies vgpu React components — WGSL shaders, mesh binaries, and textures — into your app. You own the files.
