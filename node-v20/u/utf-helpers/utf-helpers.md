# utf-helpers

> 标签: encoding, hex, hex-string, string, utf, utf-16, utf-8, utf16, utf8

## 简介

A zero-dependency tool to encode/decode UTF-8, UTF-16 and hex strings. For browser and Node.js. With typings.
