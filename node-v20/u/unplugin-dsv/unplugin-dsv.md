# unplugin-dsv

> 标签: rollup, transform, unplugin, vite, webpack

## 简介

🍣 A universal bundler plugin which converts `.csv` and `.tsv` files into JavaScript modules with [d3-dsv](https://github.com/d3/d3-dsv).
