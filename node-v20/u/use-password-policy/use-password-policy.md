# use-password-policy

> 标签: form, haveibeenpwned, hook, nist, password, password-checker, password-policy, password-strength, password-validation, react, react-hook, react-hook-form, typescript, validation, zod, zxcvbn

## 简介

Password validation for React and Node: one policy for client and server, NIST presets, breached-password checks, zxcvbn support, Zod & react-hook-form helpers, and an accessible drop-in input.
