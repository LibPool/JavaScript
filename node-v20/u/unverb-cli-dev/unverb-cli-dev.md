# unverb-cli-dev

> 标签: agent, api, cli, transcription, unverb

## 简介

A command-line client for the unverb API, built for agents: bearer key from the environment, JSON bodies, NDJSON output, typed exit codes, resumable event streams.

## 官网

- 官网：https://unverb.com
- npm 页面：https://www.npmjs.com/package/unverb-cli-dev
