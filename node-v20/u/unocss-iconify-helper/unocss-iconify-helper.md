# unocss-iconify-helper

> 标签: devtools, icon-picker, iconify, icons, unocss, vite, vite-plugin

## 简介

Dev-only Iconify icon picker for UnoCSS. Framework-agnostic Vite plugin — works with Vue, React, Svelte, etc.
