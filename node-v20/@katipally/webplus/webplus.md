# @katipally/webplus

> 标签: agent-skills, agents, ai, claude, codex, copilot, cursor, fact-check, research, skill.md, verification, web-search

## 简介

web+ — make any AI agent fetch the latest, official, verified info from the web instead of answering from memory. One Agent Skill (SKILL.md), installed into every tool's skills directory via npx. Spends searches smartly, cites sources with dates.
