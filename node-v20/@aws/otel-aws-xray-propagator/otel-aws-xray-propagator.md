# @aws/otel-aws-xray-propagator

> 标签: awsxray, nodejs, opentelemetry, profiling, tracing

## 简介

OpenTelemetry AWS Xray propagator provides HTTP header propagation for systems that are using AWS Xray HTTP header format.
