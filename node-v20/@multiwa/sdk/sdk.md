# @multiwa/sdk

> 标签: api, gateway, messaging, multiwa, sdk, typescript, whatsapp, whatsapp-api, whatsapp-bot

## 简介

Official TypeScript SDK for the MultiWA WhatsApp Business API Gateway. Send messages, manage profiles, automate flows, and consume webhooks against a self-hosted MultiWA server.
