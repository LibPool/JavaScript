# @buyong/pi-codex-image-gen

> 标签: gpt-image, image-generation, pi-extension, pi-package

## 简介

Codex-compatible image_gen tool for Pi using Pi's openai-codex ChatGPT subscription login for image requests, without changing the chat provider. Bundles the adapted imagegen skill.
