# renderdiff

> 标签: agent-skill, ai-agent, claude-code, coding-agent, css-refactor, framework-migration, llm, migration, parity, pixel-diff, pixelmatch, playwright, refactor, screenshot-comparison, screenshot-diff, visual-diff, visual-regression, visual-testing

## 简介

Visual-parity checker for website migrations: screenshot-diffs your branch against production across viewport widths, and names the DOM element and CSS property behind each change. Built for coding agents (Claude Code, Codex, Cursor).
