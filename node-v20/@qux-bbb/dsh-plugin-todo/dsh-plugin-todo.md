# @qux-bbb/dsh-plugin-todo

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, task, todo

## 简介

User-confirmed todo list plugin for DeepSeek Harness: track tasks in a global ($DSH_HOME) or project (<projectRoot>/.dsh) level, with destructive actions requiring explicit confirmation
