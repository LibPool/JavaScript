# @zmxv/plid

> 标签: id, lexicographic, monotonic, primary-key, sortable, timestamp, ulid, uuid

## 简介

Prefix-Lexicographic ID — variable-width, lexicographically sortable identifiers with a 46-bit millisecond timestamp and a 2-bit local-date offset
