# @memosr/plugin-base-gas

> 标签: agents, base, eliza-plugin, elizaos, elizaos-plugin, gas, usdc, x402

## 简介

elizaOS plugin: live Base gas, transaction cost in USD, ready-to-sign fees, cross-chain comparison and best time to transact. Paid per call in USDC over x402, no API key.
