# @ftai/plugin-sdk

> 标签: JavaScript

## 简介

FtAi Desktop 插件 SDK：挂载点类型、宿主服务清单、设计 token 清单、编译选项、插件前端的构建预设、Typert 产物生成，以及插件项目模板
