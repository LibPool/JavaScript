# @misaka-net/fatal-guard

> 标签: error-handler, fatal, guard, misakanet, process-exit, uncaught-exception, unhandled-rejection

## 简介

Zero-dependency non-invasive fatal error guard — capture uncaught exceptions and unhandled rejections, route redacted diagnostic payload to external handler via process.env.FATAL_HANDLER
