# @digital-garden-nantes/logo-branding

> 标签: assets, brand, branding, context-menu, download, guidelines, identity, logo, png, popup, svg

## 简介

Un module JavaScript qui ajoute une popup 'clic droit' sur votre logo pour faciliter le téléchargement des assets de marque (PNG/SVG), l'accès rapide aux guidelines et l'ouverture du lien dans un nouvel onglet.
