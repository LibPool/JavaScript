# uppy.sh

> 标签: cli, curl, file-sharing, transfer, upload, uppy.sh

## 简介

Drop a file, get a link. CLI for https://uppy.sh — `uppy FILE` prints a download URL.

## 官网

- 官网：https://uppy.sh
- npm 页面：https://www.npmjs.com/package/uppy.sh
