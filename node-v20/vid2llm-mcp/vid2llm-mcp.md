# vid2llm-mcp

> 标签: ai-agents, claude, mcp, model-context-protocol, tiktok, transcript, video, x402, youtube

## 简介

Lets AI agents read public videos (TikTok, YouTube, Instagram, X) as text through vid2llm.dev, paying per video with x402. MCP server and CLI.
