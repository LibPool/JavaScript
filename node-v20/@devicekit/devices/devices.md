# @devicekit/devices

> 标签: device, devices, presets, safe-area, screen, status-bar, user-agent, viewport

## 简介

The device table behind devicekit's previews: phones and tablets with screens, pixel ratios, status bars, safe areas and user agents, plus the arithmetic that turns one into a usable window size. No DOM.
