# @mcp-ts/client

> 标签: agent, agents, anthropic, claude, context-window, durable-sessions, hook, mcp, model-context-protocol, neon, oauth, react, redis, server-sent-events, serverless, sqlite, sse, supabase, tool-discovery, tool-router, typescript

## 简介

A lightweight MCP client library for TypeScript with durable sessions across Redis, Supabase, Neon, and SQLite, cross-runtime agent support, and dynamic tool discovery to reduce LLM context usage.
