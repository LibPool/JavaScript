# @evanion/feature

> 标签: dependencies, feature-flags, feature-toggles, rollout, targeting, typescript

## 简介

Feature toggles with dependencies and composite rules: turning one flag off turns off the flags that need it, and a parent's 25% rollout does not leak to 100% of its dependants.
