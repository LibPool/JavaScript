# @askalf/fieldpass

> 标签: agent-security, ai-safety, browser-automation, cdp, lethal-trifecta, prompt-injection, puppeteer

## 简介

Governed agentic browser — an indirect-prompt-injection firewall and action gate that wraps a CDP browser so agents can read untrusted web pages safely. Part of the Own Your Stack agent-security suite (redstamp · strongroom · truecopy · cordon).
