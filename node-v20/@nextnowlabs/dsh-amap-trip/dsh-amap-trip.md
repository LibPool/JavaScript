# @nextnowlabs/dsh-amap-trip

> 标签: amap, deepseek-harness, dsh, gaode, itinerary, mcp, travel, trip-planner

## 简介

DeepSeek Harness 行程规划插件包：接入高德地图官方 MCP（15 个工具），提供「行程规划」预设与 trip-planner 技能；API Key 在「设置 → 高德地图」配置，工具只在预设会话挂载。
