# @mtechzilla/cli

> 标签: mtechzilla

## 简介

mtzc — the MTechZilla Components CLI. Copies (vendors) production-grade modules into your Next.js + Supabase project: resolves each module's dependency graph, mirrors its files, stamps migrations so they sort last, merges env vars, and installs npm deps.
