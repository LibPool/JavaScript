> 标签: ReactNativeVideoEditing, android, audio, audio-mixing, avfoundation, background-music, expo, ios, mediacodec, mp4, react-native, react-native-video-editing, video, video-editing, video-mixer

## 简介

A React Native module for mixing audio with video, perfect for adding background music to videos while preserving original audio. Works on iOS and Android. Built with Expo modules.
