# @accelerated-capacity/wegosign-mcp

> 标签: document-signing, e-signature, mcp, wegosign

## 简介

Local (stdio) MCP server for WeGoSign: envelopes, templates, packages, invoices, webhooks, apps, and SSO tools over the WeGoSign REST API
