# react-native-uiscene-bridge

> 标签: crash, expo, ios, ios-27, launch, react-native, scene-delegate, scenedelegate, uiscene, xcode-27

## 简介

Stops React Native and Expo apps built with Xcode 27 from crashing at launch with "UIScene life cycle is required for apps built with this SDK". Install it, run pod install, no code changes.
