# @cf-sync/protocol

> 标签: cloudflare, durable-objects, local-first, offline-first, sync, sync-engine, zod

## 简介

Shared app-definition kit and wire protocol for cf-sync: defineApp, defineSchema, defineMutators, zod-validated frames — importable from both worker and browser
