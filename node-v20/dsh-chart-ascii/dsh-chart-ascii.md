# dsh-chart-ascii

> 标签: ascii, bar-chart, chart, chart-ascii, dsh, line-chart, plugin, sparkline, terminal, visualization

## 简介

Terminal ASCII charts for DeepSeek Harness: draw horizontal/vertical bar charts, line/scatter/area trend charts and one-line sparklines from plain `label,value` data or a file. Zero runtime dependencies, read-only.
