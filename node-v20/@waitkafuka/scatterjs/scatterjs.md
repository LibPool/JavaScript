# @waitkafuka/scatterjs

> 标签: 散点, 浮动

## 简介

1. 直接在html中引入`./dist/scatter.js`，或者`require('@waitkafuka/scatterjs')`   2. 创建实例并传入参数：   ```javascript new Scatter(options) ``` ## options支持参数： 名称|备注|默认值   -|-|- num|生成的圆点数量|50   spreadDelay|圆点散播之前的延迟时间|300   spreadBezier|圆点散播时候的贝塞尔曲线参数|[0.15, 0.43, 0, 1]
