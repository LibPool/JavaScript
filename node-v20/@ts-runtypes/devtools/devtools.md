# @ts-runtypes/devtools

> 标签: JavaScript

## 简介

RunTypes devtools: cross-bundler plugin (Vite/Rollup/Rolldown/webpack/Rspack/esbuild) that rewrites RunTypes marker calls using the ts-runtypes resolver, plus an OXlint/ESLint lint plugin.
