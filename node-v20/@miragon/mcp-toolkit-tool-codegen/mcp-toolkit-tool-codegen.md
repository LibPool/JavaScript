# @miragon/mcp-toolkit-tool-codegen

> 标签: JavaScript

## 简介

Build-time codegen + runtime glue for type-safe MCP tool calls: TypedCallTool helper and a CLI that generates TypeScript types + React Query hooks from an MCP server's tools/list.
