# @pimia/design-tokens

> 标签: design-system, design-tokens, pimia, tailwind

## 简介

Sistema de diseño de Pimia como paquete OPCIONAL para apps de partner: tokens tipados, variables CSS y preset de Tailwind. El white-label es poder no usarlo.
