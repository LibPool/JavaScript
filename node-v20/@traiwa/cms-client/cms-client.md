# @traiwa/cms-client

> 标签: cms, flexcms, headless-cms, page-builder, traiwa, typescript

## 简介

Tiny typed client for the FlexCMS / Traiwa Page Builder API. Fetch pages, list published slugs, and load site settings in any TypeScript/JavaScript app.
