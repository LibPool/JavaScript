# cobol-polycall

> 标签: binding, cobol, copybook, ffi, gnucobol, interop, obinexus, polycall, rpc

## 简介

GnuCOBOL binding for the Polycall core (binding ABI v1): COBOL bridge, copybooks and a C shim, built from source with GnuCOBOL against an installed Polycall core >= 1.1.0
