# ondajs

> 标签: agent, ai, animation, cli, components, motion-graphics, onda, react, registry, remotion, shadcn, typescript, video

## 简介

Install Onda motion-graphics components into your Remotion project. Source you own, motion identity built in, agent-friendly contract.
