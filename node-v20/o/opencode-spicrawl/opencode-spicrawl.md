# opencode-spicrawl

> 标签: mcp, opencode, opencode-plugin, spicrawl, web-scraping

## 简介

Spicrawl plugin for OpenCode: adds the Spicrawl MCP server so agents can scrape web pages to Markdown or JSON

## 官网

- 官网：https://docs.spicrawl.com/agents/opencode
- 源码仓库：git+https://github.com/OfficialSpicrawl/agent-plugins.git
- npm 页面：https://www.npmjs.com/package/opencode-spicrawl
