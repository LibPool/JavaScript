# ofdkit

> 标签: ofd, ofd-parse, ofd-viewer, ofd.js, ofdjs, ofdkit, outline, preview, renderer, vue, vue3

## 简介

OFD 预览工具包：目录导航 + 字体兜底 + 按页懒渲染 + 功能可插拔，渲染引擎可切换（默认 Apache-2.0 的 DLTech21/ofd.js），默认零全局污染
