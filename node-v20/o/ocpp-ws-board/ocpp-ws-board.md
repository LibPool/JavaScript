# ocpp-ws-board

> 标签: cpo, csms, ev-charging, ocpp, ocpp-dashboard, ocpp-monitoring, ocpp-ui

## 简介

Monitoring UI and backend integration for ocpp-ws-io. Type-safe TypeScript toolkit for EV charging, CSMS backends, Redis scaling, and protocol validation.
