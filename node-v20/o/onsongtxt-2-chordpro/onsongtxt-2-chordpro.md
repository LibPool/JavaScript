# onsongtxt-2-chordpro

> 标签: Chordpro, MobileSheets, OnSong

## 简介

Simple node tool that allows to to convert song sheets in [OnSong](https://onsongapp.com/) text format to chordpro so they can be used by apps like [MobileSheets](https://www.zubersoft.com/mobilesheets/). This allows sharing one set of sheets between iOS
