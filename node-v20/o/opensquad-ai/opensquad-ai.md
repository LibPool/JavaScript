# opensquad-ai

> 标签: ai-agents, framework, llm, mcp, multi-agent, opensquad

## 简介

OpenSquad — Local-first Multi-Agent Collaboration Framework. npm bootstrap that installs the Python `opensquad` CLI and proxies commands to it.
