# opplevagent-mcp

> 标签: a2a, activities, claude, experiences, mcp, norway, norway-activities, norwegian-experiences, opplevagent, opplevelser

## 简介

MCP server for opplevagent.no — find Norwegian experiences and activities from Claude Desktop, ChatGPT, and other AI assistants. Curated, Brreg-verified experiences searchable by county, category, weather, season, and group size.
