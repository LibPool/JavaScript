# opencode-kanaboards-agent

> 标签: agent, automation, kanaboards, opencode-plugin

## 简介

Kanaboards local agent runner. Polls Kanaboards for pending agent assignments and launches a local coding agent (OpenCode by default; Codex and Claude via --runner) to work on them.
