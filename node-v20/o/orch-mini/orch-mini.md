# orch-mini

> 标签: cli, devops, docker-compose, monorepo, nginx, orchestrator, stack, yaml

## 简介

Orquestador declarativo mínimo: un stack.yaml describe la arquitectura, om renderiza docker-compose + nginx + scripts y levanta el stack.
