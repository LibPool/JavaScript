# oas-to-markdown

> 标签: api-docs, cli, docs, documentation, generator, llms, llms-txt, llms.txt, markdown, openapi, openapi3, swagger, widdershins

## 简介

Generate clean Markdown API docs and llms.txt from OpenAPI 3.0/3.1 specs. A maintained alternative to widdershins.
