# openapi-contract-kit

> 标签: api-contracts, cli, code-generation, json-schema, openapi, openapi3, runtime-validation, typescript

## 简介

Generate type-safe TypeScript contracts and runtime validators from JSON or YAML OpenAPI 3.1 documents.
