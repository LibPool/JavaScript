# ovb3-bridge

> 标签: claude, claude-code, claude-plugin, mcp, mcp-server, oracle, vb-studio, vbcs, visual-builder

## 简介

OVB3 (Oracle Visual Builder Bridge) — MCP server + CLI + Claude Code plugin for driving Oracle Visual Builder Studio (VBS) git-backed app development from Claude: read/write VBCS artifacts, run Oracle's build/audit tasks, and git commit/push/pull.
