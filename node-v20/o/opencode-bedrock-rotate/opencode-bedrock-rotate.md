# opencode-bedrock-rotate

> 标签: amazon-bedrock, aws, bedrock, failover, opencode, opencode-plugin, rate-limit, throttling

## 简介

opencode plugin that rotates multiple Amazon Bedrock bearer tokens across accounts and retries the next token on throttling (429 / ThrottlingException).
