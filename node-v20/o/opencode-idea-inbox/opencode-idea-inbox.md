# opencode-idea-inbox

> 标签: backlog, ideas, opencode, opencode-plugin, productivity, sidebar, tui

## 简介

opencode plugin: capture ideas to a sidebar backlog mid-conversation, then dispatch them from the command palette into the current session or background sessions
