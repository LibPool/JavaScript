# open-design-axi

> 标签: agents, axi, cli, design, open-design, opendesign

## 简介

AXI-compliant CLI for OpenDesign — list projects, read and write design files, bundle artifacts, and drive generation runs from the shell, with offline reads straight from the local data directory. Spec axi/1.0-2026-07.
