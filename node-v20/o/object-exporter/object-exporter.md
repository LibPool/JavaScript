# object-exporter

> 标签: csv, doc, docx, dom, javascript-csv, javascript-doc, javascript-html, javascript-pdf, javascript-xls, jsobjexp, object-exporter, objectexporter, xls, xlsx

## 简介

A little JavaScript plugin to generate PDF, XLS, CSV and DOC from JavaScript Object or DOM element only from the frontend!
