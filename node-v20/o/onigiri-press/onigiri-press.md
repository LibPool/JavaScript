# onigiri-press

> 标签: blog, cms, framework, markdown, modern, onigiri, portfolio, press, react, responsive, static-site, typescript, vite

## 简介

A modern, lightweight portfolio and blog framework built with React, TypeScript, and Vite. Easy to customize, supports markdown content, and includes powerful blog functionality.
