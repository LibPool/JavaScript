# omni-relay

> 标签: api-gateway, middleware, relay, schema-validation, sse, upstream, zod

## 简介

以卡片为一等公民的 API 绑定框架:把任意源站 API 包装为可复用的 API 卡片,业务卡片用命令式双钩子(collect/respond)在 IR 键值缓存上编排它们;IR 是框架执行宿主规则(注入/屏蔽/审计)的介入面。
