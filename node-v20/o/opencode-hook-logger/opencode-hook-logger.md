# opencode-hook-logger

> 标签: JavaScript

## 简介

hook-logger.ts opencode plugin (logs essentially every opencode hook event as JSONL under ~/opencode-hook-output/, for debugging/observability), published to npm so opencode's own npm-plugin loader can install it directly from a bare package name in openc
