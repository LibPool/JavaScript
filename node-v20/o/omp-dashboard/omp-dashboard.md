# omp-dashboard

> 标签: JavaScript

## 简介

OMP（Oh My Pi）会话的只读操作员追踪控制台。把一次 OMP 会话的计划、执行时间线、Agent 层级、模型用量和健康信号聚合到一个本地 Web 页面，适合观察多 Agent 任务、定位停滞点和回顾已结束的会话。
