# ontologyviewer

> 标签: cytoscape, diagram, ontology, owl, rdf, rdfs, skos, turtle, viewer

## 简介

Standalone read-only Turtle ontology viewer for web pages, with Schema and Triples diagrams powered by Cytoscape.
