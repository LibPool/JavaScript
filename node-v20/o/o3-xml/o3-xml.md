# o3-xml

> 标签: JavaScript

## 简介

NodeJS library for W3C-DOM XML api with XPath and namespaces. It is based on LibXML2.

## 官网

- 官网：http://www.ajax.org/#o3
- npm 页面：https://www.npmjs.com/package/o3-xml

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- npm 安装：`npm install o3-xml`
- npm registry：https://registry.npmjs.org/o3-xml
- Node 要求：~0.4.0
