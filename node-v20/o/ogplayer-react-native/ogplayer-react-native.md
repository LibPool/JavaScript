# ogplayer-react-native

> 标签: ads, airplay, android, chromecast, dash, drm, fabric, fairplay, hls, ima, ios, new-architecture, player, react-native, streaming, video, video-player, widevine

## 简介

OGPlayer video player SDK for React Native — native playback with a typed TypeScript API: HLS/DASH, DRM, Google IMA ads, playlists, vertical feed, offline downloads, picture-in-picture, themeable controls.
