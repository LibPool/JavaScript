# once-kernel

> 标签: agent, deduplication, exactly-once, idempotency, idempotent, mcp, retry, side-effects, sqlite

## 简介

Idempotency kernel for side-effecting operations. 1,000 racing callers, exactly one execution — proven, not asserted.
