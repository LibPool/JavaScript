# orbit-http

> 标签: api, axios, client, fetch, gravity, http, orbit, rest, titan, titanpl

## 简介

Lightweight, Axios-style HTTP client for the TitanPL Gravity Runtime. Synchronous, zero-dependency, fetch-native.
