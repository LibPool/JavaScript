# ofx-typed

> 标签: bank-statement, finance, ofx, open-financial-exchange, parser, sgml, typescript

## 简介

Fully typed OFX (Open Financial Exchange) parser for TypeScript. Supports OFX 1.x (SGML) and 2.x (XML), with fields named after their meaning in the OFX spec.
