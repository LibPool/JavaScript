# ownhwpx

> 标签: document, hancom, hwp, hwpml, hwpx, korean, reader, typescript, word-processor, writer

## 简介

HWPX file format reader/writer - TypeScript port of hwpxlib. Read, write, and manipulate HWPX (Hancom Word) documents.
