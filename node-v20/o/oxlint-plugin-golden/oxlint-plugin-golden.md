# oxlint-plugin-golden

> 标签: code-quality, eslint, linter, oxc, oxlint, plugin, typescript

## 简介

Opinionated Oxlint rules derived from a strict TypeScript coding standard: no forced casts, no unknown flow, explicit control flow, domain naming.
