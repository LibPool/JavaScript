# opencode-tab-status

> 标签: opencode, opencode-plugin, status, tab-title, terminal, windows-terminal

## 简介

Show OpenCode running status (status, model, tool, usage) in the Windows Terminal tab title via OSC escape sequences. Zero dependencies.
