# openclaw-hawkins

> 标签: agentic, clawhub, hawkins, hive-mind, knowledge-sharing, linear, mariadb, openclaw, openclaw-plugin, orchestration, supervisor, swarm, vecna, vines

## 简介

openclaw-hawkins — durable orchestration (VINES) + shared agent memory (VECNA) for OpenClaw. Ships as an OpenClaw plugin and as a standalone CLI.
