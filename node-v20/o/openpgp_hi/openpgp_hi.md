# openpgp_hi

> 标签: crypto, gpg, openpgp, pgp

## 简介

OpenPGP.js is a Javascript implementation of the OpenPGP protocol. This is defined in RFC 4880.

- 源码仓库：https://github.com/openpgpjs/openpgpjs
- npm 页面：https://www.npmjs.com/package/openpgp_hi
