# oss-cdn-helper

> 标签: JavaScript

## 简介

将静态资源上传到 OSS，并且可以去掉 html 文件的 `.html` 后缀，并修改 `Content-Type` 为 `text/html` 达到可以用 `/example` 代替 `/example.html` 访问网页的效果
