# openclaw-plugin-dg-lab

> 标签: ai-agent, coyote, dg-lab, e-stim, estim, openclaw-plugin, websocket

## 简介

Connect and control DG-Lab (Coyote) V3 devices via WebSocket. Provides agent tools, chat commands, and an emotion-driven stimulation engine.
