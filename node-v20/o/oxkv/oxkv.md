# oxkv

> 标签: keyvalue, kv-store, opentelemetry, transaction, wasm

## 简介

A transactional key-value store with WASM bindings (BTreeStore + OxKvStore), cursor pagination, streaming snapshots, optional OpenTelemetry, and a portable LSM backend (native + wasm).
