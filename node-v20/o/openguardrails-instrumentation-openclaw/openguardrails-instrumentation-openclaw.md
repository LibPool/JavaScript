# openguardrails-instrumentation-openclaw

> 标签: agent, ai, guardrails, ogr, openclaw, openguardrails, plugin, security

## 简介

Guard an OpenClaw assistant's tool calls and channel traffic through the OpenGuardrails (OGR) protocol — agent-configurable text/regex guardrails, or use your own model as the judge. No core changes.
