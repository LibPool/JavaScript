# openrelay-cli

> 标签: base, gonka, llm, openai, openrelay, payments, proxy, solana, x402

## 简介

Local x402-paying proxy + MCP server for open-relay.link — point any OpenAI-compatible harness (Cursor, Claude Code, aider, SDKs) at localhost and it pays per call from a local burner wallet. Base and Solana rails live.
