# oxlint-react-compiler-experimental

> 标签: eslint, javascript, linter, oxc, oxlint, react-compiler, typescript

## 简介

Experimental oxlint build with React Compiler rules. Multi-platform: darwin-arm64, linux-arm64, linux-x64, win32-arm64, win32-x64.
