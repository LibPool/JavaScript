# opencode-md-memory

> 标签: local-first, markdown, memory, opencode, plugin

## 简介

A lightweight, local-first memory system for opencode backed by plain Markdown files. Short ids, module scoping, rg full-text search, read-set gate, optional semantic reference injection.
