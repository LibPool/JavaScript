# onefold

> 标签: framework, reactive, signals, typescript, ui

## 简介

Zero-dependency TypeScript UI framework: fine-grained reactive signals, real-DOM rendering, secure-by-default templating — under 6kb gzipped core, full enterprise features via tree-shakeable sub-paths.
