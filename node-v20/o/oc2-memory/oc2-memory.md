# oc2-memory

> 标签: daily-log, markdown, memory, opencode, opencode-plugin, qmd, scratchpad

## 简介

OpenCode V2 plugin that gives the coding agent a memory: durable facts, a daily log and a scratchpad as plain markdown, with optional qmd-powered search. A port of pi-memory.
