# opencode-context-usage

> 标签: cache, context, cost, opencode, opencode-plugin, opencode-tui, plugin, tokens, tui

## 简介

OpenCode TUI plugin: a /context command with the exact token breakdown behind the built-in Context panel (last request) plus session-wide usage, subagent totals, cache hit rate and cost.
