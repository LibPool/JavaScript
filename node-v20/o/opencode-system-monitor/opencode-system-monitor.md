# opencode-system-monitor

> 标签: btop, cpu, cross-platform, disk, gpu, linux, macos, memory, nvidia, opencode, opencode-plugin, opencode-sidebar, opencode-tui, opencode-v2, performance-monitor, ram, resource-monitor, sidebar, swap, system-monitor, terminal, tui, vram, windows

## 简介

Cross-platform system monitor for the OpenCode TUI sidebar: live CPU, RAM, swap, disk, NVIDIA GPU and VRAM usage bars that follow your OpenCode theme. Linux, macOS and Windows.
