# oktaf-base

> 标签: oktaf, react, typescript

## 简介

1. Execute `npm install` or `yarn install` command from the project folder 2. Run `npm run dev` or `yarn run dev` command to start the application 3. Access your application at [http://localhost:5173/](http://localhost:5173/).
