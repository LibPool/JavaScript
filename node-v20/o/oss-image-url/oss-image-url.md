# oss-image-url

> 标签: aliyun, image, oss, responsive, srcset, x-oss-process

## 简介

框架无关的阿里云 OSS 图片 URL 处理工具：追加 x-oss-process 参数，支持缩放/裁剪/压缩/转 WebP 与多档响应式 srcset
