# onenotesystem

> 标签: capture, cli, linux, microsoft, microsoft-graph, notes, onenote, productivity, terminal

## 简介

Terminal client for OneNote System: create and update Microsoft OneNote pages from any shell, including Linux and locked-down work machines.
