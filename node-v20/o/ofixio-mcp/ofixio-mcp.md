# ofixio-mcp

> 标签: directorio-profesionales, electricista, fontanero, mcp, ofixio, spain, tradespeople

## 简介

MCP server for Ofixio — find skilled tradespeople in Spain (fontaneros, electricistas, pintores, cerrajeros). Search by postal code or city.
