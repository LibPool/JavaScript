# opencode-plugin-context

> 标签: context, context-window, opencode, opencode-plugin, sidebar, tokens, tui

## 简介

OpenCode TUI plugin that renders the session's context-window usage as a colored, segmented bar (cached / prompt / thinking / output / reserved output) in the sidebar
