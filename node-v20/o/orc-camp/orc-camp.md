# orc-camp

> 标签: ai-agent, claude-code, cli, codex, dashboard, developer-tools, local-first, orchestration, tmux

## 简介

Local-first CLI dashboard that visualizes tmux sessions as camps and Claude Code / Codex agent sessions as orcs. Read-only discovery, status inference, and a localhost pixel dashboard.
