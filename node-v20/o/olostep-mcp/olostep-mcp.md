# olostep-mcp

> 标签: ai-agent, ai-answers, anthropic, batch-scraping, claude, content-extraction, data-extraction, llm-tools, markdown-extraction, mcp, model-context-protocol, olostep, search-api, web-crawler, web-scraping, web-search

## 简介

API to search, extract and structure web data. Features web scraping, AI-powered answers with citations, batch processing (10k URLs), and autonomous site crawling for AI agents and LLMs.
