# oss-sdk

> 标签: copy, create, cut, delete, dir, directory, extra, file, file system, fs, gzip, log, mkdir, mkdirp, mkdirs, move, output, promise, read, remove, text, touch, write

## 简介

oss-sdk contains methods that aren't included in the vanilla Node.js fs package. Such as recursive mkdir, copy, and remove.
