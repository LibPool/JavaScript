# offline-sync-engine

> 标签: access-control, check-in, event-sourcing, idempotency, indexeddb, local-first, offline-first, pos, sse, sync

## 简介

Offline-first mutation queue + idempotent server sync for event check-in, POS, and access-control apps. Survives flaky WiFi, prevents duplicate writes, reconciles cleanly on reconnect.
