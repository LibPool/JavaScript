# opencode-yourstatus

> 标签: copilot, grok, openai, opencode, plugin, quota, sidebar, status, tui, xai, zai, zhipu

## 简介

Show quota for the selected OpenCode account in the TUI sidebar. Supports OpenAI, Zhipu AI, Z.ai, xAI, and GitHub Copilot.
