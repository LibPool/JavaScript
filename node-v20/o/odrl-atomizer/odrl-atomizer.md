# odrl-atomizer

> 标签: JavaScript

## 简介

This nodeJS library can be used to atomize ODRL Policies (Set, Offer, Agreement, Request) according to the [Rule Composition](https://www.w3.org/TR/odrl-model/#composition) defined it the ODRL Specification.
