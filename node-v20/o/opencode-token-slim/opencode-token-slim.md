# opencode-token-slim

> 标签: context, context-window, llm, opencode, opencode-plugin, prompt-cache, tokens

## 简介

Cuts the per-request payload an OpenCode agent sends to its model: old reasoning, oversized tool results, old screenshots, stale call arguments, and an oversized system prompt.
