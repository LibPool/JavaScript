# onewaydb-darwin-x64

> 标签: JavaScript

## 简介

Read-only database access gateway for AI coding agents: MySQL, PostgreSQL, Oracle and SQLite behind logical aliases, with credentials kept out of the MCP surface. (darwin x64 binary)
