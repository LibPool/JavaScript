# opensocials

> 标签: agent, atproto, bluesky, instagram, linkedin, llm, scheduler, social, threads, x-api, youtube

## 简介

OpenSocials is a social posting agent. It has an account registry, a slot engine that retries until a post lands, transports that use each platform's official API, cards, video cuts, and a review command that reads what was actually posted.
