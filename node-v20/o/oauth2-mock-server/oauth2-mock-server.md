# oauth2-mock-server

> 标签: access-token, authorization-code, cli, e2e-testing, fake, integration-testing, jwk, jwks, jwt, mock, mock-server, oauth, oauth-mock, oauth2, oauth2-mock, oidc, oidc-mock, openid, openid-connect, pkce, stub, test, test-server, testing, typescript

## 简介

OAuth2 and OpenID Connect mock server for automated testing and development. Issues cryptographically signed JWTs via JWK key pairs. OIDC-conformant, exposes discovery, JWKS, authorization, token, userinfo, introspection, revocation, and end-session endpo
