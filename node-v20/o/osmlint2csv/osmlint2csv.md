# osmlint2csv

> 标签: JavaScript

## 简介

Convert [osmlint](https://github.com/osmlab/osmlint) output geojson file to csv file for uploading in to [To-Fix](https://github.com/osmlab/to-fix)

## 官网

- 官网：https://github.com/osmlab/osmlint2csv#readme
- 源码仓库：git+https://github.com/osmlab/osmlint2csv.git
- npm 页面：https://www.npmjs.com/package/osmlint2csv
