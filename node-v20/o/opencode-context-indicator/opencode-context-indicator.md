# opencode-context-indicator

> 标签: breakdown, context, context-window, cost, opencode, opencode-plugin, panel, sidebar, tokens, tui, usage

## 简介

Real-time context-window usage for OpenCode: per-category token breakdown, a zero-LLM /cx panel with per-session cost and a searchable family-session picker, and a TUI sidebar. Dual V1 + V2 plugin entry.
