# overview-mcp

> 标签: claude, copernicus, dashboard, earth-observation, mcp, model-context-protocol, nasa, ndvi, remote-sensing, satellite, sentinel, wildfire

## 简介

Earth-observation MCP server + live mission-control dashboard. Give Claude eyes on Earth: pull satellite imagery, compute vegetation/water/burn indices, surface live wildfires and disasters, and diff a place across time — over free, open Copernicus and NA
