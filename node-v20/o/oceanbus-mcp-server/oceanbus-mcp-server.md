# oceanbus-mcp-server

> 标签: agent-to-agent, ai-agent, claude-desktop, communication, cursor, e2ee, mcp, mcp-server, messaging, model-context-protocol, oceanbus, reputation, service-discovery, yellow-pages

## 简介

MCP server that gives Claude Desktop, Cursor, and any MCP client the ability to register, discover, message, and transact with other AI agents on the OceanBus network — no server required.
