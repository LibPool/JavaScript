# opsdraw

> 标签: architecture, cli, devops, diagram, diagrams-as-code, github-action, kubernetes, mermaid, opentofu, proxmox, terraform

## 简介

Turn Terraform, OpenTofu, Kubernetes, Proxmox and other infrastructure code into Mermaid architecture diagrams, keep them in sync in CI, merge them in git and export SVG.
