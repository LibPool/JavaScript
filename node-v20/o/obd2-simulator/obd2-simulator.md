# obd2-simulator

> 标签: automotive, can, diagnostics, ecu, elm327, emulator, j1979, obd-ii, obd2, simulator, testing, vehicle

## 简介

Zero-dependency ELM327 / OBD-II vehicle simulator — a fake car for testing diagnostic apps. In-process link for React Native/browser tests, TCP server that impersonates a WiFi ELM327 adapter for any OBD app.
