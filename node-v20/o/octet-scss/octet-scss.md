# octet-scss

> 标签: 8pt-grid, css-framework, design-tokens, responsive-typography, sass, scss

## 简介

8pt-grid SCSS framework: responsive type and layout mixins, single-file layout spacing, a modern reset, and a CSS custom-property color system.
