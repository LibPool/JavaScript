# omkit

> 标签: actions, developer-tools, logging, orchestration, pipeline, process, simulation, typescript, watch

## 简介

A tiny runtime for developer workflows: typed actions that pass runtime capabilities and emit typed events, under one run and one shared log. The operational/runtime layer to tskb's knowledge layer.
