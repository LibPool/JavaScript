# obix-runtime-component

> 标签: component, dop, ir, native, obix, runtime

## 简介

The components of OBIX's native runtime: it reads canonical DOP IR (obix-dop-ir/3) as plain data and runs it — props, state, derived values, actions, effects, the view — building and updating the DOM in place. No Vue, no React, no compiler package. Phase
