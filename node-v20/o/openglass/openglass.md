# openglass

> 标签: displacement-map, feDisplacementMap, frosted, glass, glassmorphism, lens, liquid-glass, material, react, refraction, svg-filter, ui

## 简介

A portable glass material for the web — a displacement-map refraction filter plus rim/glare overlay, built for SVG filters and WebGL alike.
