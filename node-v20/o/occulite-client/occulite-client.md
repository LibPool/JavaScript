# occulite-client

> 标签: ccu, hmip, homematic, lite-rpc, occulited, openccu, openccu-lite

## 简介

One client for openccu-lite's APIs: lite-rpc requests and events, the state store, the metadata, pairing - for hm2mqtt.js, node-red-contrib-ccu, Homematic Manager and anyone else
