# opencode-telegram-send-file

> 标签: file, image, opencode, openwork, photo, plugin, send, telegram

## 简介

OpenCode plugin that adds a telegram_send_file tool — send files and photos to Telegram via OpenWork. Images are sent with inline preview (sendPhoto); other files as attachments (sendDocument). Zero config.
