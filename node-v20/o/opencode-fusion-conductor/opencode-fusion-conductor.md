# opencode-fusion-conductor

> 标签: agent-permissions, ai-agents, llm-cost-optimization, multi-agent, opencode, opencode-plugin, subagent

## 简介

Fusion Conductor - an opencode plugin: a main agent that plans and reviews but cannot edit files, delegating every change to a cheaper sidekick. Cognition's Devin Fusion pattern as a one-line install.
