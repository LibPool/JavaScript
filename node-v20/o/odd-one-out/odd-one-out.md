# odd-one-out

> 标签: anomaly-detection, convention, java, javascript, maven, migrations, pr-miner, sql, static-analysis, supabase, tree-sitter, typescript

## 简介

Finds places that deviate from the convention of the project itself: N times this way, once differently. Java, JavaScript, TypeScript, Maven pom.xml, SQL migrations on Supabase.
