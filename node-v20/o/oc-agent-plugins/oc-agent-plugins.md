# oc-agent-plugins

> 标签: agent-plugins, mcp, opencode, opencode-plugin, skills

## 简介

Load Agent Plugins, Claude Code, Codex and Cursor packages in OpenCode v2, with skills, agents, MCP servers, commands, rules, opt-in hooks and monitors, and output styles.
