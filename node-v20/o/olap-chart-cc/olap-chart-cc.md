# olap-chart-cc

> 标签: JavaScript

## 简介

* 灰度大看板，使用vue3 typescript tsx antd * vue3建议使用composite api编写组件，但同时也兼容vue2的options api + template写法 * 本地可以访问`http://localhost:8080/demo`查看vue3开发demo
