> 标签: bus, gtfs, japan, odpt, open-data, public-transportation, railway, sdk, tokyo, transit

## 简介

Typed TypeScript SDK for the ODPT (Public Transportation Open Data Center) REST API v4 — railway, bus and aviation open data for Japan.
