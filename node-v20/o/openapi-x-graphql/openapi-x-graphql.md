# openapi-x-graphql

> 标签: api-gateway, bun, cli, graphiql, graphql, graphql-schema, graphql-to-openapi, node, nodejs, openapi, openapi-specification, openapi-to-graphql, proxy, proxy-server, rest-to-graphql, schema, swagger, typescript

## 简介

Convert an OpenAPI document into a GraphQL schema and a proxy server, and back again. Runs on Bun and Node.
