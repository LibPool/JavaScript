# opencode-truncate-lsp-diagnostics

> 标签: agent, diagnostics, lsp, opencode, opencode-plugin, truncate

## 简介

OpenCode plugin that hides previously-seen LSP diagnostics and caps new ones per edit, spilling the full list to a file so edits stay readable.
