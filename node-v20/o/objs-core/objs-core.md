# objs-core

> 标签: AI friendly, ajax, auto test, caching, cookies, dom control, event delegation, fast coding, fast develop, hydrate, local storage, micro-service, mobx, objs, optimisation, optimize, preload scripts, preload styles, react speed up, redux, reload tests, samples, script cache, server side render, session storage, state control, typescript

## 简介

Lightweight (~19 kB) library for fast, AI-friendly front-end development: samples and state control, built-in store (createStore), routing, caching, and recording → Playwright tests. No build step; split design into samples and give them data and actions.
