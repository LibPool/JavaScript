# opencode-feishu-plugin

> 标签: ai-agent, coding-agent, feishu, lark, lark-bot, opencode, opencode-plugin, 飞书, 飞书机器人

## 简介

Feishu/Lark plugin for OpenCode V2 — single-user topics as sessions, in-card permission approvals, streaming cards. Minimal permissions, no public endpoint.
