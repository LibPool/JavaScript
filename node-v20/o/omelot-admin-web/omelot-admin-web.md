# omelot-admin-web

> 标签: JavaScript

## 简介

omelot-admin-web is a web console for [omelot](https://github.com/linyngfly/omelot). it is based on [omelot-admin](https://github.com/linyngfly/omelot-admin). it is just an web console example, you can implement your style like web console.
