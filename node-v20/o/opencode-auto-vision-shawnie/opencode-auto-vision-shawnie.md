# opencode-auto-vision-shawnie

> 标签: auto-vision, image, models.dev, opencode, opencode-plugin, screenshot, vision

## 简介

Automatic image/screenshot understanding for text-only opencode models. Discovers vision-capable models from OpenCode's configured provider catalog (no hardcoded model IDs), prefers free models, routes images to the best vision model, and falls back intel
