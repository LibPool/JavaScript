# obscura-aleo-sdk

> 标签: aleo, auction, dutch-auction, obscura, privacy, sdk, sealed-bid, vickrey, zero-knowledge, zk

## 简介

TypeScript SDK for Obscura — privacy-first sealed-bid auction protocol on Aleo. 10 auction formats (Sealed, Vickrey, Dutch, English, Bundle, Multi-Unit, Candle, Reverse, Blind Dutch, Timed Escalation). Points to core_v4 + settle_v6: commit-based settlemen
