# obsidian-react-ui

> 标签: dataview, mantine, obsidian, obsidian-plugin, react, react-router, shadow-dom

## 简介

React 19 + shadow-DOM runtime for building Obsidian UIs: reactive vault store, hooks, file-system routing, and a persistent MemoryRouter — designed to run as a DataviewJS-evaluated bundle.
