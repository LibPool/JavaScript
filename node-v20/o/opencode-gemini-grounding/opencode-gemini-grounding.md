# opencode-gemini-grounding

> 标签: citations, gemini, google-search, grounding, opencode, opencode-plugin, opencode-v2, websearch

## 简介

OpenCode V2 plugin for Gemini Google Search Grounding with academic-style inline citations, sources list, dynamic model selection, and automatic fallback chain.
