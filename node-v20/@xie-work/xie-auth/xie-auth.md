# @xie-work/xie-auth

> 标签: auth, authentication, authorization, cookie, embeddable, file-storage, node, rbac, session, typescript, vite

## 简介

嵌入式认证服务库：为第三方 Node.js 项目接管用户、注册、登录、鉴权与权限管理。链式 API 声明接口即可，文件存储、零外部运行时依赖。
