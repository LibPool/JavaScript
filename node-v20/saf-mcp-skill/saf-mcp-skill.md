## 简介

Security analysis for MCP servers, tool definitions, and agent architectures against the SAF-MCP (formerly SAFE-MCP) attack technique catalog, with STRIDE, MITRE ATLAS, OWASP LLM Top 10, and NIST AI RMF mappings.
