# @whatsarab/n8n-nodes-whatsarab

> 标签: n8n, n8n-community-node-package, whatsapp, whatsapp-business-api, whatsarab

## 简介

n8n nodes for WhatsArab: send WhatsApp text, media, buttons, lists and templates, manage contacts and tags through the WhatsArab API, and start workflows from signed WhatsArab webhooks.
