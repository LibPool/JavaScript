# @bbk47/yamux

> 标签: multiplex, stream, yamux

## 简介

Production-hardened Yamux multiplexer for Node.js (TypeScript), interoperable with hashicorp/yamux. Fork of @llmcode/yamux-ts with the unknown-stream session-teardown fix.
