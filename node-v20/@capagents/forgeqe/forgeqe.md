# @capagents/forgeqe

> 标签: agent, browser, cli, forgeqe, opentui, test-automation, testing

## 简介

ForgeQE: a browser agent CLI that runs goals and test cases in local Chrome or Chromium, or BrowserStack and TestMu AI/LambdaTest when configured, and turns passing runs into tests in your repo
