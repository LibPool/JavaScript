# @sequesign/mcp

> 标签: ai-agents, attestation, ed25519, mcp, model-context-protocol, receipts, sequesign, verification

## 简介

Model Context Protocol (MCP) server for Sequesign — expose cryptographically verifiable receipts of delegated AI work as MCP tools. A thin local-stdio wrapper over @sequesign/sdk; the agent key never leaves the machine.
