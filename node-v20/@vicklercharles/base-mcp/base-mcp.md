# @vicklercharles/base-mcp

> 标签: ai, base, blockchain, claude, coinbase, ethereum, mcp, web3

## 简介

A Model Context Protocol (MCP) server that provides onchain tools for Claude AI, allowing it to interact with the Base blockchain and Coinbase API. Supports both seed phrases and private keys.
