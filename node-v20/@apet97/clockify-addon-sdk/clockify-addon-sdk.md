# @apet97/clockify-addon-sdk

> 标签: add-on, addon, clockify, manifest, sdk, typescript, webhook

## 简介

TypeScript SDK for building Clockify add-on servers: manifest builders, request router, runtime adapters, and RS256 webhook-signature verification.
