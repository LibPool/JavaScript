# @aro.day/mcp

> 标签: ai-agent, aro.day, claude, claude-code, mcp, model-context-protocol, productivity, task-manager, tasks, todo

## 简介

Open-source MCP server for aro.day — let an AI client (Claude Desktop, Claude Code, Codex) read and update your tasks. Talks to your own Google Drive; aro.day's servers never see your task data.
