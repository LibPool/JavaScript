# platform-mcp-hub

> 标签: agents, api, catalog, mcp, mcp-server, model-context-protocol

## 简介

MCP servers for 450+ platform APIs from one evidence-only catalog: one package, one CLI (npx platform-mcp-hub serve <id>). TypeScript runtime; the same CLI ships on PyPI.
