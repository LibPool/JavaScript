# @satsails/sdk-react

> 标签: bitcoin, escrow, non-custodial, p2p, react, sails, sdk

## 简介

React hooks and components for @satsails/p2p-trading-sdk — providers, TanStack Query-backed data hooks, and a small set of trade/identity/feedback primitives. Not a full design system: it wraps what @satsails/p2p-trading-sdk actually exposes, nothing more
