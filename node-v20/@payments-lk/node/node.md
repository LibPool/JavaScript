# @payments-lk/node

> 标签: checkout, lkr, payable, payments, payments.lk, sri lanka, webhooks

## 简介

The Node.js library for the Payments.lk API: checkouts, payments, refunds, payment links, saved cards, events, the account and webhook verification.
