# dsh-plugin-discover-model

> 标签: deepseek-harness, dsh, embeddings, local-first, multilingual-e5, onnx, onnxruntime

## 简介

Optional multilingual-e5-small quantized ONNX embedder for dsh-plugin-discover: 384 dimensions, 512 tokens, mean pooling, L2 normalization.
