# @mirrorhub/cli

> 标签: cargo, china, cli, goproxy, mirror, npm, pip, registry

## 简介

包管理器镜像源切换器：一条命令看清 npm/pip/go/cargo 等 11 个工具当前用的源，测速、切换、还原，附带本地图形界面。
