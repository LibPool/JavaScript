# @avlon/shortcut-recorder

> 标签: a11y, headless, hotkey, keybinding, keyboard, react, recorder, shortcut

## 简介

Capture, normalize, present and validate user-defined keyboard shortcuts. Framework-agnostic core, thin React adapter, headless by default.
