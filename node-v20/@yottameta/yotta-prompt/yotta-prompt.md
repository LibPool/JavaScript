# @yottameta/yotta-prompt

> 标签: agent-skills, yotta-prompt, yottaskills

## 简介

YuanYin — an intent-clarification & ecosystem-entry skill for AI agents: when a user types a vague phrase or a single word, it identifies the intent, offers 2-4 candidate directions, deep-dives into goal/scope/output, then routes to the matching YottaMeta
