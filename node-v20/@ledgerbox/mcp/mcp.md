# @ledgerbox/mcp

> 标签: ai-agents, bank-statement, document-extraction, invoice, mcp, model-context-protocol, ocr

## 简介

MCP server that lets AI agents extract verified data from bank statements, invoices, receipts, and other financial documents via the LedgerBox API.
