# @glasskit-ui/react

> 标签: d-pad, glasses, glasskit, hud, meta-ray-ban, neural-band, ray-ban-display, react, react-hooks, spatial-navigation, wearable

## 简介

Typed 600×600 + D-pad component library for Meta Ray-Ban Display Web Apps. The platform primitives Meta does not ship.
