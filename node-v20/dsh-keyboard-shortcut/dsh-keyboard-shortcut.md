# dsh-keyboard-shortcut

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, hotkeys, keybindings, keyboard, shortcuts, web-ui

## 简介

A Keyboard Shortcuts settings page for DeepSeek Harness (DSH) with permission-mode cycling, reasoning-effort stepping, prompt navigation, and an optional composer key remap.
