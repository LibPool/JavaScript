# @c2n/command

> 标签: cmdk, command, command menu, command palette, lit, search, web component

## 简介

`c2-command` is a searchable list of commands — a search field above `c2-command-item` rows — and the core of a ⌘K palette. Put it in a `c2-modal` for a palette, or inline in a page or a popover.
