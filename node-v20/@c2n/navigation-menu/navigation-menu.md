# @c2n/navigation-menu

> 标签: lit, mega menu, navbar, navigation menu, web component

## 简介

`c2-navigation-menu` is a site navigation bar: a row of items that are either plain links or triggers opening a panel of `c2-navigation-menu-link` rows below the bar.
