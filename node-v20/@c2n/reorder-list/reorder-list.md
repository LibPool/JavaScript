# @c2n/reorder-list

> 标签: lit, reorder-list, web component

## 简介

`c2-reorder-list` presents ordinary direct children as a vertical collection and, when `editable`, lets users reorder movable items with a pointer or keyboard. It commits the visual order immediately without moving the application-owned light DOM. Listen
