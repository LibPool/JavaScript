# @c2n/phosphor-icons

> 标签: icons, lit, phosphor, web component

## 简介

Every [Phosphor](https://phosphoricons.com/) icon as a Lit web component: `<c2-phosphor-heart>`, `<c2-phosphor-camera>`, and more. Generated from `@phosphor-icons/core@2.1.1`.
