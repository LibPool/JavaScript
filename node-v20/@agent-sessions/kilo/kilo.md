# @agent-sessions/kilo

> 标签: JavaScript

## 简介

Install `agent-sessions.mjs` in exactly one Kilo-supported plugin location. Use the release-managed global registration or one project plugin, never both `.opencode/plugins` and `.kilo/plugins`, because Kilo 7.5.6 loads both.
