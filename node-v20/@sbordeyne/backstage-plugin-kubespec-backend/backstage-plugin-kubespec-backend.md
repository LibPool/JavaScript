# @sbordeyne/backstage-plugin-kubespec-backend

> 标签: JavaScript

## 简介

Ingests Kubernetes API specs and CRD manifests from GitHub, expands them into browsable schemas and stores them, so the `/kubespec` page renders from the database rather than from upstream.
