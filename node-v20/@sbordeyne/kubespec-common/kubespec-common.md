# @sbordeyne/kubespec-common

> 标签: JavaScript

## 简介

Wire types shared by `@sbordeyne/backstage-plugin-kubespec-backend` (which produces them) and `@sbordeyne/backstage-plugin-kubespec` (which renders them).
