# @matanetwork/spacedb

> 标签: crdt, database, local-first, mata, offline-first, realtime, spacedb, sync

## 简介

Offline-first, realtime, CRDT-native database client for MATA's hosted SpaceDB (Maestro Data). The real Rust engine compiled to WebAssembly — instant local reads/writes that work disconnected, conflict-free convergence, live subscriptions, and mID-signed
