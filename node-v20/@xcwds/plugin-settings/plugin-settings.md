# @xcwds/plugin-settings

> 标签: backup, offline-first, pwa, settings, xcwds, xcwds-plugin

## 简介

The settings page for @xcwds apps: every plugin's settings with built-in controls, sections plugins add, backups (download, share, import, clear) and About.

- 源码仓库：git+https://github.com/xcwds/xcwds.git
