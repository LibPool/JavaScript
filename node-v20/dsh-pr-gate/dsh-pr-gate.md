# dsh-pr-gate

> 标签: ai-agents, code-review, deepseek-harness, deterministic-gate, dsh-plugin

## 简介

Deterministic write gate for DeepSeek Harness: scope policy + residue scan on every file the agent writes, live in the session — the CI gate moved to the moment of the write
