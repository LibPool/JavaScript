# @codemenschen/werk-connect

> 标签: analytics, codemenschen, express, middleware, monitoring, overview, shop, werk

## 简介

Connects a Node or React website to Werk, the Codemenschen support app: status, hourly ping and the overview of the site with sales.

- 官网：https://werk.codemenschen.at
