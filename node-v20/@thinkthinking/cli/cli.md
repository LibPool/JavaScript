# @thinkthinking/cli

> 标签: agent, ai-agent, cli, content-publishing, golang, gongzhonghao, json-output, llm-agent, markdown, markdown-to-html, markdown-to-wechat, mcp, thinkthinking, wechat, wechat-mp, weixin, 微信公众号

## 简介

面向 LLM Agent、自动化脚本与开发者的本地 CLI 工具箱：把 Markdown 一键转成微信公众号兼容 HTML 并发布草稿，所有命令输出统一 JSON envelope。Go 单文件二进制，npm 装完即用、运行时不依赖 Node。
