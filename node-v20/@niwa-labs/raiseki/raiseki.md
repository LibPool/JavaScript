# @niwa-labs/raiseki

> 标签: agent-traces, claude-code, codex, coding-agent, context-compression, cursor, kimi, llm, minimax, qwen-code, reasoning-bank, session-log

## 简介

Compresses coding-agent session logs (Claude Code, Codex CLI, pi, Cursor, Qwen Code, Kimi, MiniMax Code) into token-efficient MD traces with lossless @L references for LLM analysis
