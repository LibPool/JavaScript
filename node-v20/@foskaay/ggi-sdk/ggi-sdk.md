# @foskaay/ggi-sdk

> 标签: arc, foskaay, games, gasless, ggi, session

## 简介

Add gasless play to any on-chain game on Arc. Open a session, act for free, settle once. Four calls, session-key signing, read helpers, runtime fee read.
