# @c0dingbear/access-prompt

> 标签: authorization, consent, cross-platform, dialog, kdialog, native, osascript, powershell, prompt, zenity

## 简介

Tiny dependency-free cross-platform native access-request dialog (allow / allow-for-session / deny / no-response). Linux kdialog→zenity, macOS osascript, Windows PowerShell.
