# aria-glass-ui

> 标签: glass, liquid-glass, motion, nextjs, primitives, react, ui

## 简介

Liquid Glass UI primitives for React with a single, centralized config: real edge refraction (LiquidLens) and iOS-style press and flex gestures (Motion).
