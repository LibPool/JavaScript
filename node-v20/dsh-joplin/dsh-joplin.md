# dsh-joplin

> 标签: deepseek-harness, dsh, joplin, note-taking, notes, plugin, web-clipper

## 简介

Joplin notes plugin for DeepSeek Harness: search, read, create and (opt-in) edit notes through the local Joplin Web Clipper API. Zero runtime dependencies.
