# @wa-templates/agent-toolkit

> 标签: agent, cli, mcp, messaging, templates, twilio, whatsapp

## 简介

WhatsApp-branded agent skins for the WhatsApp Templates gateway: an MCP server (wa-mcp) and a CLI (wa). A thin alias over @rcs-templates/agent-toolkit — same gateway, same tool catalog, WhatsApp as the default channel.
