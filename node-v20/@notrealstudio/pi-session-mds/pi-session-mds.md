# @notrealstudio/pi-session-mds

> 标签: codec, coding-agent, jsonl, mds, nr-chat, pi, session, transcript

## 简介

pi coding-agent sessions as readable nr-chat documents: the pi/2 codec, the .mds session file format, and one reader/writer for both .jsonl and .mds.
