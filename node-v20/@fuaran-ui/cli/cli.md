# @fuaran-ui/cli

> 标签: ai, byok, cli, fuaran, sdk, ui

## 简介

The Fuaran generative-UI CLI — fuaran generate / validate / recipe / scaffold over the public surfaces, with zero MCP config. Works against the real endpoint or the local mock.
