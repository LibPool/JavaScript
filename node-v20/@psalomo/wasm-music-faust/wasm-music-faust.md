# @psalomo/wasm-music-faust

> 标签: assemblyscript, audio, compiler, dsp, faust, faust-rs, webassembly

## 简介

The Faust compiler (faust-rs) built for wasm32-unknown-unknown with the AssemblyScript backend and the Faust standard libraries embedded — the compiler module loaded by WebAssembly Music.
