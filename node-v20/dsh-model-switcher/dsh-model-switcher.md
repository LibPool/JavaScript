# dsh-model-switcher

> 标签: combobox, deepseek, deepseek-harness, dsh, dsh-plugin, harness, llm, model-picker, model-selector

## 简介

Richer model picker for the DeepSeek Harness Web composer: a searchable provider select (with logos, model counts, and key status) above a keyboard-first, fuzzy-searchable model list grouped by provider, with favorites, recents, context-window/vision/reas
