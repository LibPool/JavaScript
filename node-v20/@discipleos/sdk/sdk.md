# @discipleos/sdk

> 标签: api, church, discipleos, mcp, webhooks

## 简介

The official DiscipleOS SDK: one API, two kinds of key. Community keys read one community's consented record; personal keys read their owner's own life. Typed resources, cursor pagination, signed-webhook verification, MCP config helper.
