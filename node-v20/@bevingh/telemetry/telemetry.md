# @bevingh/telemetry

> 标签: JavaScript

## 简介

Pure client for reporting app health + free-form metrics to a central collector. No transport bundled beyond fetch; caller supplies collectorUrl/apiKey. No DB client, no scheduling, no required metric shape.
