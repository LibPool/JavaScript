# @wuniq/mcp

> 标签: ai, context, knowledge, mcp, memory, modelcontextprotocol, wuniq

## 简介

Wuniq MCP server. Requires the free Wuniq desktop app. A knowledge engine that keeps decisions, constraints and intent beside your project files, readable by any MCP-enabled AI.
