# @tiledev/sdk-apptile-cart-sync

> 标签: cart, cart-assist, cart-sync, react-native, shared-cart, shopify, tile, tilepacket

## 简介

Shared-cart sync ("Cart Assist") for TilePacket apps — reports which cart a device is on and adopts the customer's shared cart across devices and the web store. Coordinates with @tiledev/sdk-shopify and @tiledev/sdk-apptile-cart-hold.
