# @tiledev/sdk-analytics-apptile

> 标签: analytics, apptile, notification, react-native, segment, tile, tilepacket, typescript

## 简介

Apptile-Analytics adapter for TilePacket apps. Implements the @tiledev/sdk-analytics-core AnalyticsAdapter and merges two platform providers into one: Segment tracking (segmentAnalytics) and the Apptile backend notification analytics (apptileNotificationA
