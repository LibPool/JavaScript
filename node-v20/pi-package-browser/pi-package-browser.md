# pi-package-browser

> 标签: pi-extension, pi-package, pi-prompt, pi-skill, pi-theme

## 简介

Browse, search and install pi ecosystem packages (extension/skill/theme/prompt) right inside the pi terminal agent. /packages command.

## 官网

- npm 页面：https://www.npmjs.com/package/pi-package-browser

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- npm 安装：`npm install pi-package-browser`
- npm registry：https://registry.npmjs.org/pi-package-browser
- Node 要求：>=18
