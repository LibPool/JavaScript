# @satanwagen/reviewkit

> 标签: annotation, feedback, nextjs, react, review, vite

## 简介

Drop-in visual review & feedback layer for React sites. Reviewers annotate the live page; nothing is ever applied — changes are recorded as a portable session for a coding agent.
