# buggy-debugger

> 标签: ai-coding, automated-repair, bug-detection, debugger, developer-tools, fuzzing, mcp, mcp-server, model-context-protocol, proof-carrying, property-based-testing, static-analysis

## 简介

Proof-carrying debugger. Executes your code to find a real failing input, verifies the failure three ways before reporting it, generates candidate repairs, and rejects patches that only fit the example that caught them. CLI, MCP server, or programmatic AP
