# @bspeckco/tinysynq-node

> 标签: JavaScript

## 简介

Node.js host utilities for [TinySynq](https://github.com/bspeckco/tinysynq).   The package bootstraps SQLite change tracking (via `@bspeckco/tinysynq-lib`) and exposes an optional WebSocket hub powered by `uWebSockets.js` so TinySynq clients can push/pull
