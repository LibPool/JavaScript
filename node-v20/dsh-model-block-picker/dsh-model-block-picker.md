# dsh-model-block-picker

> 标签: composer, cordis, deepseek-harness, dsh, dsh-plugin, model, model-selector, provider

## 简介

DeepSeek Harness 模块化模型选择器：根据模型来源（Provider 如 CodeBuddy、Qoder、DeepSeek 等）分块展示，支持分块下钻、全局搜索与推理强度调节。
