# pagefx

> 标签: animation, barba, mpa, page-transitions, preloader, scroll-reveal, swup, transitions, view-transitions, web-animations

## 简介

Drop-in page and section transitions for any website — native View Transitions with an overlay fallback, 20+ effects, no markup changes needed.
