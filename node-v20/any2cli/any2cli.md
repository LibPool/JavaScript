# any2cli

> 标签: agent, cli, llm, mcp, model-context-protocol, oauth2, openapi

## 简介

Turn any MCP server (stdio/SSE/HTTP) or OpenAPI spec into an agent-friendly CLI, with built-in OAuth2 browser login.
