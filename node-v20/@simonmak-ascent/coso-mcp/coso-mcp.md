# @simonmak-ascent/coso-mcp

> 标签: audit, compliance, coso, grc, icfr, internal-control, internal-controls, mcp, model-context-protocol, risk, sox

## 简介

Open MCP server for COSO (ICIF-2013) internal-control reviews: scope, risk assessment, control register, population, sampling, testing, workpapers, review sign-off, deficiency evaluation and reporting.
