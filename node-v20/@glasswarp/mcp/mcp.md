# @glasswarp/mcp

> 标签: computer-use, desktop-automation, glasswarp, mcp, model-context-protocol, stdio, windows

## 简介

See and control a real Windows PC you own — from any MCP client, locally or remotely. Observe (UIA + screenshots), click/type/drag/scroll, launch apps, owner Live View. Hosted MCP or npx @glasswarp/mcp. BYOH: your machine, your key, you bring the model.
