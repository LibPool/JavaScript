# @raffiniert-media-ag/payload-live-preview-inspector

> 标签: click-to-scroll, cms, developer-tools, live-preview, nextjs, payload, payload-cms, payload-plugin, payloadcms, plugin, react, storyblok, visual-editing

## 简介

Click a component in Payload's Live Preview iframe to scroll to and highlight the matching field in the admin panel, and back the other way round.
