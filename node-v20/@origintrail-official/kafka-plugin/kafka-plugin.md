# @origintrail-official/kafka-plugin

> 标签: JavaScript

## 简介

DKG daemon route plugin for publishing Kafka stream registrations as private-by-default `dkg-streams:KafkaStream` Knowledge Assets. Default mount: `/api/kafka/streams`.
