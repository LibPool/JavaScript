# @claudewerk/envelope-codec

> 标签: cbor, codec, envelope, json, wire-format

## 简介

Pure encode/decode codec for { env, body? } messages. Envelope is channel-encoded (JSON or CBOR); body is opaque octets passed through byte-for-byte.
