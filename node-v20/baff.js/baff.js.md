# baff.js

> 标签: api, baff, baff.gg, bot, chat, gateway, slash-commands

## 简介

The library for building bots on baff.gg: gateway client, REST, slash commands, components and embeds, with no runtime dependencies.

- 官网：https://docs.baff.gg
