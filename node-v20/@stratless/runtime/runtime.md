# @stratless/runtime

> 标签: JavaScript

## 简介

The local embedding runtime for stratless, pre-bundled to WASM. Downloaded once by the stratless CLI after explicit consent — never installed directly, never a dependency.

## 官网

- 官网：https://stratless.com
- 源码仓库：git+https://github.com/stratless-ai/stratless.git
- npm 页面：https://www.npmjs.com/package/@stratless/runtime
