# @unovalabs/mcp

> 标签: JavaScript

## 简介

MCP server for Unova Type-2 nodes — lets Claude, Cursor, and other AI tools create assets/events and trace provenance on your own node.

## 官网

- 官网：https://nodes.unova.io/api-docs
- npm 页面：https://www.npmjs.com/package/@unovalabs/mcp

- npm registry：https://registry.npmjs.org/@unovalabs/mcp
