# dsh-git-tools

> 标签: agent-tools, cordis, deepseek, deepseek-harness, dsh, dsh-bundle, dsh-plugin, git, slash-commands

## 简介

Git tools and /git slash commands for DeepSeek Harness, running git in the Host process so push, pull and fetch work even when the session shell is sandboxed.
