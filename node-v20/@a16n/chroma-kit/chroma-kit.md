# @a16n/chroma-kit

> 标签: breakpoints, expo, react-native, stylesheet, styling, theme, variants

## 简介

A lightweight styling layer for React Native — themed stylesheets, CVA-style variants, breakpoints, and runtime values, with no Babel or Metro plugins.
