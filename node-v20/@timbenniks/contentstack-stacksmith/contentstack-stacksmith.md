# @timbenniks/contentstack-stacksmith

> 标签: cms, content-models, content-types, contentstack, dsl, infrastructure-as-code, schema, schema-as-code, stacksmith, typescript

## 简介

TypeScript DSL for defining Contentstack content types and global fields as code. Author schemas in TypeScript, diff against live stacks, and apply changes through a safe plan/apply workflow.
