# @timbenniks/contentstack-stacksmith-cli

> 标签: cms, content-models, contentstack, contentstack-cli, csdx, csdx-plugin, oclif, oclif-plugin, schema-as-code, stacksmith

## 简介

Contentstack CLI plugin for managing content models as code. Adds `csdx stacksmith:*` commands for init, build, plan, diff, apply, typegen, promote, docs, import, and audit-org.
