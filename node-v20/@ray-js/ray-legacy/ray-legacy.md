# @ray-js/ray-legacy

> 标签: JavaScript

## 简介

老 @ray-js/ray 写法的过渡承载：@ray-js/ray-next 全量 + Kit 命名空间聚合对象（ai/device/home/…）。由 raypack --legacy 把 @ray-js/ray 指到这里，业务源码一行不改先跑起来；迁完（raypack check 无诊断）即摘开关
