# @ray-js/hybrid-robot-map

> 标签: rn-os-2, robot-map, tuya-panel

## 简介

IndoorMapInstance 是 IndoorMap 的 Web 组件实现, 您可以在 Web，涂鸦小程序，React Native 的 WebView 技术栈中使用它来进行扫地机器人地图的业务开发。
