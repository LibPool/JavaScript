# @fish-under-sea/dsh-settings-nav-order

> 标签: deepseek-harness, dsh, dsh-plugin, nav, order, settings

## 简介

DeepSeek Harness 设置导航与斜杠菜单顺序：重排、隐藏设置侧栏；为 agent-teams、companion、acp、acp-cache 补充图标和中文标题，支持自定义默认顺序。偏好随浏览器本地状态及 $DSH_HOME/dsh-settings-nav-order/state.json 持久化。
