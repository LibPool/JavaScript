# @zimzaza4/dsh-recent-sessions

> 标签: JavaScript

## 简介

Pinned, recent and active sessions for the DeepSeek Harness Web sidebar — what the workspace registry pins, the sessions you most recently worked in, and what needs you now (waiting for an answer, freshly finished, or still working), in the workspace-list
