# @midwayjs/glob

> 标签: JavaScript

## 简介

实现一个基础轻量的 globby，为了兼容 faas-glob 语法，引入纯 js 版的 picomatch 库，除此之外，无其他依赖。

- 源码仓库：git+https://github.com/midwayjs/glob.git
