# @rific/drawer

> 标签: drawer, edge-swipe, expo, gesture, navigation, react-native, react-native-gesture-handler, react-native-paper, react-native-reanimated, swipe

## 简介

Left/right sliding drawer with edge-swipe gestures for React Native: spring-animated, theme-aware, one factory call per drawer instance
