# @openpets/overture-maps

> 标签: buildings, geojson, geospatial, gis, maps, opencode, openpets, openstreetmap, overture-maps, places, plugin

## 简介

CLI wrapper for overturemaps-py that downloads Overture Maps data including buildings, places, addresses, transportation, and base map features. Access 300M+ points of interest, building footprints, and administrative boundaries in GeoJSON or GeoParquet f
