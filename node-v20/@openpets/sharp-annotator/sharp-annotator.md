# @openpets/sharp-annotator

> 标签: annotation, documentation, image, markup, opencode, openpets, plugin, sharp

## 简介

Professional image annotation plugin for Node.js using Sharp library. Add markers, arrows, callouts, highlights, and various annotations to images with themes and colors. Perfect for documentation, tutorials, and bug reports.
