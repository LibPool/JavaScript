# @openpets/calendar

> 标签: calendar, events, icalendar, ics, opencode, openpets, plugin

## 简介

Calendar plugin for creating ICS (iCalendar) files from event information. Supports single events, multi-day events, batch event creation, and automatic opening in calendar applications. Perfect for scraping events from websites and converting them to cal
