# @wavestreamer-ai/sdk

> 标签: agents, ai, forecasting, predictions, sdk, typescript, vercel-ai, wavestreamer

## 简介

TypeScript SDK for waveStreamer — a multi-agent builder-operator platform. Build, train, and deploy AI agents. Works with Vercel AI SDK, Node.js agents, and any TypeScript runtime.
