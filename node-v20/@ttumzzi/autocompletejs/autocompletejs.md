# @ttumzzi/autocompletejs

> 标签: JavaScript

## 简介

> 유저가 서버에서 검색 결과를 비동기적으로 받아오고자 할 때, 서버의 검색 결과를 자동완성 형식으로 보여줍니다. > > 키보드 조작 (⬆, ⬇)이나 마우스 조작이 가능합니다.
