# @rakettitiede/mcp-oauth-proxy

> 标签: custom-gpt, express, google, mcp, middleware, oauth

## 简介

Express middleware and router bridging Custom GPT's OAuth expectations to Google as IdP, with API-key fallback. Extracted from Rakettitiede MCP servers.
