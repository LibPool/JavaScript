# @pawells/nestjs-nats

> 标签: jetstream, messaging, microservices, nats, nestjs, pubsub

## 简介

NestJS NATS messaging utilities — module wiring, subscriber querying, event broadcasting, connection health monitoring, JetStream support, and environment-driven connection configuration with graceful shutdown
