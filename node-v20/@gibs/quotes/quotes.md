# @gibs/quotes

> 标签: bridge, cross-chain, ethereum, pulsechain, quote, viem

## 简介

Isomorphic core for asking cross-chain bridge aggregators (LI.FI, Relay, NEAR Intents) for display and execution quotes — the wire contract, refusal reading, and the shared guards a host wraps every upstream call in. Runs unchanged in a browser or in Node
