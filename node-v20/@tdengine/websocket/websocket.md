# @tdengine/websocket

> 标签: IOT, TDengine, TypeScript, database, taos, taosdata

## 简介

The websocket Node.js connector for TDengine. TDengine versions 3.3.2.0 and above are recommended to use this connector.

## 官网

- 官网：https://github.com/taosdata/taos-connector-node#readme
- 源码仓库：git+https://github.com/taosdata/taos-connector-node.git
- npm 页面：https://www.npmjs.com/package/@tdengine/websocket
