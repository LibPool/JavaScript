# opencode-sro

> 标签: bug-bounty, bugcrowd, hackerone, intigriti, opencode, opencode-plugin, pentesting, scope, security

## 简介

Scope-aware, policy-enforced security research harness for OpenCode. Reads bug bounty engagements without credentials, blocks out-of-scope targets in code, separates hypotheses from verified findings, and never submits to a platform.
