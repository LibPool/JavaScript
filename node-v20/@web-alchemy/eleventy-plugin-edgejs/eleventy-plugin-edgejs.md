# @web-alchemy/eleventy-plugin-edgejs

> 标签: edge.js, eleventy, eleventy-plugin, template engine

## 简介

This plugin allows to use [Edge.js](https://github.com/edge-js/edge/) as template engine for [Eleventy](https://11ty.dev).
