# @ravenkash/rtc

> 标签: JavaScript

## 简介

Official browser SDK for the Livqeno hosted platform — join a room, publish camera/microphone, subscribe to remote media. Hides SDP/ICE/STUN/TURN/SFU behind a small typed API.
