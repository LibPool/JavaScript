# @videoflow/core

> 标签: ffmpeg, remotion, video API, video compilation, video data model, video editor, video effects, video layers, video rendering, video transitions, videoflow

## 简介

Turn JSON code into programmatic videos. Core library for VideoFlow — data model, layers, flow API, and video JSON compilation — Open Source Remotion alternative
