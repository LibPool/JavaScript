# @333eco/corpus

> 标签: cc0, corpus, doi, mcp, model-context-protocol, opentimestamps, provenance, verifiable

## 简介

An MCP server for an open-licensed corpus, served with verifiable provenance — every document carries its sha256, DOI and OpenTimestamps proof so a consuming agent can check its own citation.
