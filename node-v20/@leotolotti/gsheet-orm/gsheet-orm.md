# @leotolotti/gsheet-orm

> 标签: database, google-sheets, oauth, oauth2, orm, prisma, typescript

## 简介

Type-safe, Prisma-inspired ORM that turns a Google Sheet into a relational database, authenticated via Google OAuth2.
