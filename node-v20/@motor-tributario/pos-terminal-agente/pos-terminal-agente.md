# @motor-tributario/pos-terminal-agente

> 标签: JavaScript

## 简介

Agente local instalable — expone POST /venta, POST /anular en localhost (envolviendo @motor-tributario/pos-terminal/node) para que cualquier ERP, en cualquier lenguaje, cobre en el terminal físico Transbank con HTTP simple, sin instalar nada de Node/TypeS
