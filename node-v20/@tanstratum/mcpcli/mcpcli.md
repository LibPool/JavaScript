# @tanstratum/mcpcli

> 标签: cli, codebase, mcp, model-context-protocol, terminal

## 简介

MCP (Model Context Protocol) codebase tools for AI agents — terminal CLI + stdio server. Reads your project files, proxies tool calls to the Zephex backend.

## 官网

- 官网：https://zephex.dev/docs/cli-terminal
- 源码仓库：git+https://github.com/zephex/mcp-proxy.git
- npm 页面：https://www.npmjs.com/package/@tanstratum/mcpcli
