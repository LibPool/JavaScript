# @workspec/schema-core

> 标签: actor, envelope, json-schema, schema, workspec, yaml, zod

## 简介

Shared base for WorkSpec Studio schema packages — the K8s-style artifact envelope (apiVersion/kind/metadata/spec), path/slug helpers, link primitives, and the canonical Actor kind every @workspec/*-schema family builds on.
