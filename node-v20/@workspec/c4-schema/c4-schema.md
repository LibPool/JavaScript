# @workspec/c4-schema

> 标签: architecture, c4, diagrams, json-schema, schema, yaml, zod

## 简介

Zod source of truth for WorkSpec C4 diagram artifacts — element/diagram/style/layout schemas, YAML parsing with line-mapped errors, and generated JSON Schema.
