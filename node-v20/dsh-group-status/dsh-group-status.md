# dsh-group-status

> 标签: badge, deepseek-ai, dsh, dsh-plugin, group-status, sidebar, workspace

## 简介

DSH 侧栏折叠分组聚合徽标：收起的文件夹行显示进行中/待审批/已完成/定时任务/等待评审的聚合状态，带数字与悬停明细。
