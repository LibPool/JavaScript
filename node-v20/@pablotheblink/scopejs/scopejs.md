# @pablotheblink/scopejs

> 标签: components, data-binding, framework, frontend, javascript, library, lightweight, modal, mvvm, reactive, router, spa, ui, vanilla-js, web-components

## 简介

A lightweight JavaScript framework for component-based development. Supports both ES6 modules and global script usage with reactive components, modals, and SPA routing.
