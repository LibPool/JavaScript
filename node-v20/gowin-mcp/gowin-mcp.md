# gowin-mcp

> 标签: eda, fpga, gowin, mcp, tang, timing, verilog

## 简介

MCP server that turns Gowin EDA build reports into structured data: resource usage, fMax per clock, timing violations with a pass/fail/unknown gate, pin assignment, synthesis/PnR warnings, and build-to-build comparison.
