# @steedos/steedos-project-enterprise

> 标签: low-code, microservices, moleculer, steedos

## 简介

在平台源码根目录启动服务时，默认启动的是与该项目文件夹同级目录下的华炎魔方社区版模板项目，对应的，该项目是用于在源码中运行企业版项目调式华炎魔方源码。
