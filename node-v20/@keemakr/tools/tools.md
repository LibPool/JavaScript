# @keemakr/tools

> 标签: JavaScript

## 简介

Ready-made eve tools for keemakr marketplace agents — drop-in capabilities (Hunter find-email, …) that run on the @keemakr/agent-sdk floor, plus an `add` CLI that scaffolds editable tool templates.
