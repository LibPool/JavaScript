# @opencalc/react

> 标签: charts, data-grid, excel, formula, grid, opencalc, pivot-table, react, spreadsheet, webassembly, xlsx

## 简介

React bindings for @opencalc/sheet — an embeddable spreadsheet that reads and writes real .xlsx, with props for configuration and callbacks for events.
