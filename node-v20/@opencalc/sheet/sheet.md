# @opencalc/sheet

> 标签: charts, csv, custom-element, data-grid, excel, formula, grid, ooxml, pivot-table, react, spreadsheet, wasm, web-component, webassembly, xlsx

## 简介

An embeddable spreadsheet that reads and writes real .xlsx — 347 worksheet functions, pivot tables and charts, running entirely in the browser as one custom element.
