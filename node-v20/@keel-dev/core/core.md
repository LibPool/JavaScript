# @keel-dev/core

> 标签: agents, ai, anthropic, fallback, framework, gemini, llm, openai, production, typescript

## 简介

An opinionated TypeScript framework for production-ready AI applications. State, Model, Tools — composed by Turns; every turn crosses four gates, and every production error is a typed gate failure, never a successful-looking incompletion.
