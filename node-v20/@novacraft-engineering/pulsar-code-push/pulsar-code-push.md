> 标签: code-push, codepush, codepush-alternative, hot-update, ota, ota-updates, over-the-air, pulsar, react-native, react-native-ota

## 简介

Pulsar OTA client for React Native — over-the-air JavaScript updates. A CodePush-compatible client (RevoPush lineage) pointed at Pulsar.
