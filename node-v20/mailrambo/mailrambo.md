# mailrambo

> 标签: bounce, catch-all, deliverability, disposable-email, email, email-validation, email-verification, mailrambo, verify-email

## 简介

Official Node.js client for the MailRambo email verification API - strict yes/no deliverability, disposable and catch-all detection.
