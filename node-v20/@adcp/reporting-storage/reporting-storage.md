# @adcp/reporting-storage

> 标签: adcp, azure, bigquery, gcs, ledger, postgresql, reporting, s3

## 简介

Storage for AdCP Reliable Reporting: the PostgreSQL ledger store, row storage with GCS, S3 and Azure providers, managed delivery, notification activity and the BigQuery warehouse sink. Depends on @adcp/sdk for the protocol layer.
