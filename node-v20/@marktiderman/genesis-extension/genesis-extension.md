# @marktiderman/genesis-extension

> 标签: JavaScript

## 简介

Build Chrome extensions (Manifest V3) with Genesis: checked messaging, settings storage, the UI as a floating panel, a top bar or Chrome's side panel, an in-page bar, native-helper jobs, React pieces built on Genesis UI, and a Chrome fake for tests. Part
