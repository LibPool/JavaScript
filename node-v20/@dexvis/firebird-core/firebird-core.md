# @dexvis/firebird-core

> 标签: dex, event-display, firebird, particle-physics, three, webgpu

## 简介

Worker-safe core of the Firebird event display: event model, DEX io, loader contracts, painters. Plain TypeScript - no Angular injector, no bootstrap; runs in web workers and node.
