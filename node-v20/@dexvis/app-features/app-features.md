# @dexvis/app-features

> 标签: angular, command-bus, config, deep-links, dependency-injection

## 简介

Angular app composition machinery: feature packs over DI multi-providers, layered config (defaults < server < localStorage < URL < runtime), a serializable command bus with URL startup commands, and config.jsonc server config loading.
