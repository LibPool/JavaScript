# lanka-movie-scraper

> 标签: cartoons, cinesubz, ginisisila, metadata, movies, scraper, sinhala, sinhalasub, sri-lanka, yts

## 简介

Search and fetch movie metadata from Sri Lankan movie sites — CineSubz, SinhalaSub, YTS and GiniSisila cartoons. Metadata only: no downloads, no keys, no bot code.
