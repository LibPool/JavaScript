# fitlocale

> 标签: arabic, ci, hebrew, i18n, internationalization, l10n, localization, playwright, pseudo-localization, right-to-left, rtl, testing, text-overflow, truncation, visual-testing

## 简介

Catch translation-caused layout bugs (overflow, text leaks, RTL mirroring) in your Playwright tests.
