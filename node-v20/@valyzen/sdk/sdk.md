# @valyzen/sdk

> 标签: agents, arbiter, ed25519, mcp, negotiation, receipt, valyzen

## 简介

TypeScript/JavaScript client for the Valyzen Negotiation Gateway: negotiate, then verify the signed receipt offline. Zero dependencies.
