# @shotlingo/text-expansion

> 标签: android, app-store, app-store-optimization, aso, i18n, internationalization, ios, l10n, localization, mobile, string-length, text-expansion, translation, ui-copy

## 简介

Translation length expansion ratios for App Store screenshot localization. Predicts how text from English grows or shrinks in 40+ target languages so UI layouts don't break post-translation.
