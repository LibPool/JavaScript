# @ztm-njau/dsh-mnemosyne

> 标签: agent, cordis, deepseek-harness, dsh, memory, plugin

## 简介

Persistent long-term memory for DeepSeek Harness agents: a cross-session `memory` service, a JSON-lines disk provider under $DSH_HOME, and the memory_remember / memory_recall / memory_forget tools.
