# @polyskill/anthropic.theme-factory

> 标签: JavaScript

## 简介

Toolkit for styling artifacts with a theme. These artifacts can be slides, docs, reportings, HTML landing pages, etc. There are 10 pre-set themes with colors/fonts that you can apply to any artifact
