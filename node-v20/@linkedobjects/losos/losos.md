# @linkedobjects/losos

> 标签: 6kb, framework, json-ld, linked-data, no-build, panes, reactive, solid, tagged-templates, websocket

## 简介

A 6KB reactive framework for building apps on linked data. No build step. No dependencies. No virtual DOM.
