# @code3d/opencascade

> 标签: JavaScript

## 简介

The OpenCascade runtime selected by `@code3d/core`. It uses the `replicad-opencascadejs@1.0.0` binding ABI and corrects native object destruction in the binding generator. The dependency on `replicad-opencascadejs` supplies the matching declarations used
