# @pdtp/core

> 标签: JavaScript

## 简介

`@pdtp/core` is a package that supports protocol transfer. It provides client functionality to parse data sent from the server and return it as objects. This package is used in `@pdtp/react` and can also be utilized when creating other PDF viewers.
