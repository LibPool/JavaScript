# @nx-devkit/diagrams

> 标签: bpmn, d2, diagram-as-code, diagrams, excalidraw, graphviz, kroki, mermaid, nx, nx-plugin, plantuml

## 简介

Nx plugin that renders text-diagram sources (PlantUML, Mermaid, D2, Graphviz, BPMN, Excalidraw) into cached, atomized targets via Kroki or local renderers.
