# @nx-devkit/skillspector

> 标签: agent-skills, llm-security, nx, nx-plugin, sarif, security, security-scanner, skillspector

## 简介

Nx plugin for SkillSpector security scanning: any SKILL.md gets a scan target reporting vulnerabilities, secrets, and risky patterns — with SARIF output and CI annotations.
