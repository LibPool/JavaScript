# @listen-fire/s3-files

> 标签: JavaScript

## 简介

The files slot's module over S3 (`@lf/s3-files`): lf keeps a run's documents in a bucket of AWS S3, Google Cloud Storage (its S3 interoperability endpoint), Cloudflare R2, MinIO or any S3 compatible service, instead of a container's disk. Served as a proc
