# @listen-fire/files-s3

> 标签: JavaScript

## 简介

The files slot over S3 or any S3-compatible service (R2, MinIO, Supabase Storage): store, stream, presign and delete a team's files. Its own package, so a deployment that stores no files carries no AWS SDK.
