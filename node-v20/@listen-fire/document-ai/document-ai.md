# @listen-fire/document-ai

> 标签: JavaScript

## 简介

The ocr slot's module on Google Document AI (`@lf/document-ai`): a scanned PDF's or an image's text, online for short files and batched through a Cloud Storage bucket for long ones, exactly as the platform reads them (packages/ocr-google), each read price
