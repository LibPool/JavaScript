# @taldres/laravel-waitlist

> 标签: consent, double-opt-in, gdpr, laravel, nextjs, waitlist

## 简介

Typed client for the Laravel Waitlist HTTP API, with Next.js helpers: signups with consent wording, confirm, unsubscribe and preference flows
