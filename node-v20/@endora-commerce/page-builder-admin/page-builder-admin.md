# @endora-commerce/page-builder-admin

> 标签: JavaScript

## 简介

The admin-side page-builder chrome and the e-mail builder (feature 091, P5b; D-192). `.` is the editor chrome `cms`, `blog` and `invoices` render — header actions, asset and catalog field factories, the colour palette, the overlay bridge and the action-ba
