# @mxmweb/auplayer

> 标签: JavaScript

## 简介

React 音频播放相关能力集合：**通用 `AudioPlayer`**、**音乐条 `MusicPlayerAdapter`**、**录音 `AudioRecorderAdapter`**，以及面向智能问答 / 语音消息的 **`VoicePlayerAdapter`**（波形 + 时间轴 + 标注 + 控制区）。
