# @mxmweb/rtext

> 标签: JavaScript

## 简介

> 统一富文本组件库，基于 Slate 与 React 封装，支持富文本编辑/渲染、Markdown/HTML/纯文本多源输入、模板字段、虚拟滚动与分段加载等能力。
