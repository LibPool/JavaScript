# @awalkerca/eleventy-plugin-inclusive-language

> 标签: eleventy, eleventy-plugin, inclusive-language, linter

## 简介

An Eleventy linter plugin to check for inclusive language in markdown files. Fork with options to skip blockquotes and allow phrases per file.
