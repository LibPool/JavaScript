# @xyavid/dsh-prompt-polish

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, prompt, prompt-engineering, web-ui

## 简介

dsh Web 插件：在输入框模型名左侧加一个小星星按钮，一键把当前草稿交给模型改写成结构化提示词，可一键撤回。
