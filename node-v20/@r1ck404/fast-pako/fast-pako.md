# @r1ck404/fast-pako

> 标签: compression, deflate, drop-in, gzip, inflate, pako, ungzip, wasm, zlib

## 简介

Faster drop-in replacement for pako 2.1.0: pako's zlib ported to Rust/WebAssembly, byte-identical output, same API and errors
