# @r1ck404/fast-noble-hashes

> 标签: drop-in, hashes, hmac, md5, noble, pbkdf2, scrypt, sha1, sha256, sha512, wasm

## 简介

Faster drop-in replacement for @noble/hashes 1.8.0: SHA-2, SHA-1, MD5, HMAC, PBKDF2 and scrypt in WebAssembly, identical results, errors and instance state
