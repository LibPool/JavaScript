# @fastyoke/lcap-codeeditor

> 标签: code-editor, fastyoke, lcap, monaco

## 简介

Code editor peer package for the FastYoke SDK's <SmartField /> resolver. Lazy-loaded when an annotation row's @ui/component = 'code'.
