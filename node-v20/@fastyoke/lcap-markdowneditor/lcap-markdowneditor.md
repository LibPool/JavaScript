# @fastyoke/lcap-markdowneditor

> 标签: editor, fastyoke, lcap, markdown

## 简介

Markdown editor peer package for the FastYoke SDK's <SmartField /> resolver. Lazy-loaded when an annotation row's @ui/component = 'markdown'.
