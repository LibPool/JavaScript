# @ux-sting/extract

> 标签: design-system, design-tokens, dtcg, extraction, oklch, theme

## 简介

Extract a design system from any live URL (colors, type scale, spacing, radii, shadows, motion, breakpoints) as W3C DTCG tokens, import DTCG files from any tool into a UX-STING OKLCH theme, and match a design to the nearest UX-STING preset.
