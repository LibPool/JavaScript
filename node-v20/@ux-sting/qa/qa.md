# @ux-sting/qa

> 标签: accessibility, ai-agents, axe, core-web-vitals, playwright, visual-qa

## 简介

Browser QA for agents: screenshots at 375/768/1440, axe, contrast, layout checks (overflow, margins, orphans, empty stretches, first-screen title), console errors and LCP/CLS, with a short markdown report and ranked top-3 fixes.
