# @teyou/openclaw-googlechatpubsub

> 标签: ai-agent, chatbot, google-chat, google-workspace, multi-agent, openclaw, openclaw-channel, openclaw-plugin, pubsub, workspace-events

## 简介

OpenClaw channel plugin — listen to Google Chat spaces via Workspace Events + Pub/Sub. No @mention required. Multi-agent routing with keyword and alwaysListen support.
