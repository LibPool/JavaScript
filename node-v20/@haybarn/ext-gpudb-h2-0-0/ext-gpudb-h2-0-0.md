# @haybarn/ext-gpudb-h2-0-0

> 标签: duckdb, extension, gpudb, haybarn

## 简介

GPU-accelerated plain DuckDB SQL on Apple Silicon Metal and NVIDIA CUDA - GROUP BY, joins, filters and top-k run on the GPU when measured faster, with the same answers. First SQL execution engine that targets Apple Silicon GPUs.
