# @haybarn/ext-read_dbf-h1-5-3-wasm-mvp

> 标签: duckdb, duckdb-wasm, extension, haybarn, read_dbf, wasm

## 简介

WebAssembly (mvp) build of the Haybarn extension 'read_dbf' for duckdb-wasm. Built against haybarn 1.5.3. Pick the variant (mvp/eh/threads) matching your duckdb-wasm bundle.
