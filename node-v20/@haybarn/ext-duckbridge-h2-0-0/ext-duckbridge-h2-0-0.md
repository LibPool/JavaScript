# @haybarn/ext-duckbridge-h2-0-0

> 标签: duckbridge, duckdb, extension, haybarn

## 简介

Bridge between SQL Server and DuckDB - import a SQL Server database, run T-SQL on DuckDB through a built-in translator, export back as a live load, a restorable .bak, PostgreSQL or Parquet
