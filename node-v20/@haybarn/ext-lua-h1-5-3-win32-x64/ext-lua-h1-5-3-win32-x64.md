# @haybarn/ext-lua-h1-5-3-win32-x64

> 标签: JavaScript

## 简介

Haybarn extension 'lua' for win32/x64. Built against haybarn 1.5.3. Installed automatically by the @haybarn/ext-lua-h1-5-3 meta-package; use that, not this leaf, in your dependencies.
