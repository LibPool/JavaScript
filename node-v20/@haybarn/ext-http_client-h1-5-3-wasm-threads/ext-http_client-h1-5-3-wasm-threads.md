# @haybarn/ext-http_client-h1-5-3-wasm-threads

> 标签: duckdb, duckdb-wasm, extension, haybarn, http_client, wasm

## 简介

WebAssembly (threads) build of the Haybarn extension 'http_client' for duckdb-wasm. Built against haybarn 1.5.3. Pick the variant (mvp/eh/threads) matching your duckdb-wasm bundle.
