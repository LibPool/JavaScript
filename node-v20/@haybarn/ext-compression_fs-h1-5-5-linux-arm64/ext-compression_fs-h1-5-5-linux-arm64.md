# @haybarn/ext-compression_fs-h1-5-5-linux-arm64

## 简介

Haybarn extension 'compression_fs' for linux/arm64 (glibc). Built against haybarn 1.5.5. Installed automatically by the @haybarn/ext-compression_fs-h1-5-5 meta-package; use that, not this leaf, in your dependencies.
