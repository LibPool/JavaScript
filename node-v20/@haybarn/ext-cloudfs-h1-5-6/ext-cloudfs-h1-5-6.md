# @haybarn/ext-cloudfs-h1-5-6

> 标签: cloudfs, duckdb, extension, haybarn

## 简介

Query SharePoint, OneDrive, Google Drive, Dropbox, SFTP, and any VPS (via cloudfs-agent) using spfs://, odfs://, gdfs://, dbxfs://, sftp://, and vfs:// — with the same capabilities as s3://. Supports Parquet, CSV, JSON, Delta Lake, Iceberg, glob patterns,
