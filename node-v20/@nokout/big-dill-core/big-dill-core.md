# @nokout/big-dill-core

> 标签: bdd, cucumber, gherkin, lint, pytest, pytest-bdd

## 简介

Headless engine for pytest-bdd tooling: Gherkin parsing, structural linting, formatting, step indexing, and the pytest discovery/execution protocol. No editor dependency.
