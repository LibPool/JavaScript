# @codeproxy/core

> 标签: anthropic, claude, deepseek, openai, responses-api, translate, typescript

## 简介

Convert upstream LLM APIs (Chat Completions / Anthropic Messages) to OpenAI Responses API format. Zero dependencies, works in browser/Node/edge.
