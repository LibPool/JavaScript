# @amazon-devices/recommendation-manager

> 标签: JavaScript

## 简介

The Amazon Media Recommendations API is a service that allows client applications to add and remove recommendations on Amazon devices. These recommendations are displayed on the device's home screen, providing users with personalized content suggestions.
