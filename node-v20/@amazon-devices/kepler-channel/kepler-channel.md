# @amazon-devices/kepler-channel

> 标签: JavaScript

## 简介

The `@amazon-devices/kepler-channel` package provides APIs for handling channel tuning operations in KeplerScript applications. This package supports channel changing and channel skipping functionality for TV applications built on the Kepler platform.
