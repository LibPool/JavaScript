# @qazana/strata

> 标签: css, design-system, design-tokens, framework-agnostic, qazana, themeable, ui-components, vanilla-js

## 简介

Qazana Strata — the shared, framework-agnostic design system — semantic design tokens + vanilla (data-attribute) component CSS/JS, themeable per product with a single :root override.
