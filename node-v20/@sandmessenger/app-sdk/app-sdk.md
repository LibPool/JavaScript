# @sandmessenger/app-sdk

> 标签: mini-app, sand, sandmessenger, sdk

## 简介

SAND mini-app SDK (bridge v2): handshake with the SAND host, the SAND ID token, storage, sharing and host UI; /server verifies SAND ID tokens in Node, Bun, Deno and Workers; /mock for unit tests.
