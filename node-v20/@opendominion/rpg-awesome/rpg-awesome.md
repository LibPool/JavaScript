# @opendominion/rpg-awesome

> 标签: JavaScript

## 简介

RPG Awesome is a suite of pictographic, rpg and fantasy themes icons for easy scalable vector graphics on websites, created and maintained by [Daniela Howe](https://github.com/nagoshiashumari) and [Ivan Montiel](http://github.com/idmontie).
