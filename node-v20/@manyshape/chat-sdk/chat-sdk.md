# @manyshape/chat-sdk

> 标签: chat-sdk, generative-ui, malleable-software, manyshape

## 简介

Embeddable Manyshape chat bubble for vendor apps: sign in, describe your interface, and the platform compiles + sandboxes it in place. Experiences save to the user's Manyshape account.
