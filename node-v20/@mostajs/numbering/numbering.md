# @mostajs/numbering

> 标签: counter, invoice-number, mosta, mostajs, multi-tenant, numbering, reference, reset, sequence, sequential-id

## 简介

Formatted sequential reference generator (AAAA-MM-JJ-NNN, PF-…) — token templates, periodic reset (day/month/year), atomic counter via pluggable store. DB-agnostic.
