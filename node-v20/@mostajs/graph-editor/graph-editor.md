# @mostajs/graph-editor

> 标签: editor, erd, flow, graph, mostajs, node, svg, workflow, zero-dependency

## 简介

Éditeur de graphe interactif SVG, zéro dépendance (nœuds déplaçables + arêtes/flèches tracées au drag). Contrôlé (props nodes/edges + callbacks). Réutilisable : workflow, ERD/schéma, graphe de dépendances.
