# @mostajs/browser-kit

> 标签: browser, clipboard, fullscreen, mostajs, pwa, wake-lock, web-api, web-share

## 简介

Façade unifiée des Web APIs du navigateur (Wake Lock, Fullscreen, Visibility, Network, Web Share, Clipboard, Vibration, Screen Orientation…). Feature-detection + API promise + cleanup, dégradation gracieuse. ESM côté navigateur (se charge aussi sous Node
