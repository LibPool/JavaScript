# @mostajs/queue-bridge

> 标签: appointment, file-attente, mostajs, queue, rdv, ticketing

## 简介

Pont générique de file d'attente / RDV — orchestration Visit (accueil → file → appel), composant un moteur de file (ticketing) et l'identification (badge QR / reconnaissance faciale). DB-agnostique.
