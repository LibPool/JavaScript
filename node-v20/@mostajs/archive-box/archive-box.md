# @mostajs/archive-box

> 标签: archive, backup, ed25519, integrity, manifest, mostajs, sha256, zip

## 简介

Une archive : un zip, un manifeste, des empreintes SHA-256 par fichier, une signature Ed25519 facultative. Générique — le module ignore ce qu'il y a DANS les fichiers. Extrait du noyau d'@mostajs/ixarchive, débarrassé de son domaine « projets ».
