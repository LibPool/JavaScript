# @mostajs/auth-plug

> 标签: auth, configuration, mostajs, plug, saas, session

## 简介

Le BRANCHEMENT de l authentification : l hote met son .env, le module y branche le moteur @mostajs/auth-lite, des sessions revocables en base et le courriel. L appelant ne sait pas ce qui est connecte. Pendant de @mostajs/data-plug pour l identite.
