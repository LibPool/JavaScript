# @mostajs/events-ui

> 标签: billetterie, events, html, mostajs, qr, ui

## 简介

Vues PURES (view-model → HTML) du domaine Événements : liste publique, fiche + inscription, billet QR, régie, contrôle d'accès. Compose @mostajs/app-shell-ui ; l'app charge la donnée (@mostajs/events) + rend les QR (@mostajs/qrpanel). Membre de mosta-ui-h
