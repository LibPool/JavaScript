# @mostajs/security

> 标签: aes-gcm, at-rest, encryption, hmac, mostajs, security, sha256

## 简介

Crypto réutilisable : chiffrement au repos (AES-256-GCM authentifié), sha256, HMAC-SHA256, keyring .env, wrapper encryptedStorage. Composé par storage/ged/users/url.
