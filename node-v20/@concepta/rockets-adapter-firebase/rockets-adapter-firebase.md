# @concepta/rockets-adapter-firebase

> 标签: auth-adapter, authentication, backend, firebase, firebase-admin, nestjs, rockets, typescript

## 简介

Firebase Authentication adapter for Rockets — implements AuthAdapterInterface from @concepta/rockets-core, validates Firebase ID tokens, maps to AuthorizedUser
