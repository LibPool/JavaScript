# @fazendatech/brafis

> 标签: JavaScript

## 简介

Módulo de integração com o SEFAZ, o Brafis facilita a comunicação com os serviços da SEFAZ, permitindo a emissão de notas fiscais eletrônicas (NF-e) e outros documentos fiscais de forma simplificada.
