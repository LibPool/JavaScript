# @elaanio/react-core

> 标签: elaan, hooks, notifications, react, sdk

## 简介

React bindings for @elaanio/core: <ElaanProvider> + hooks. Shared by @elaanio/react (web) and @elaanio/react-native. No UI, no DOM.
