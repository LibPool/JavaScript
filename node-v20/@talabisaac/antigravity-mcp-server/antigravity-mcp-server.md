# @talabisaac/antigravity-mcp-server

> 标签: agy, ai, antigravity, cli, gemini, llm, mcp, modelcontextprotocol

## 简介

MCP server for Google Antigravity CLI (agy) — exposes the Gemini-successor models to any MCP client by wrapping the local agy CLI.
