# @cqrs-ddd/pipeline-job-context

> 标签: authorization, correlation-id, cqrs, jobs, multi-tenancy, nestjs, pipeline, queue

## 简介

Carries the tenant, correlation id and principal of a request into the queue jobs it enqueues, and gives system-started work an explicit context
