# @wasm-os/mklfs

> 标签: embedded, esp32, filesystem, image, littlefs, mklittlefs, wasm

## 简介

Build and read littlefs filesystem images in pure JavaScript - littlefs compiled to WebAssembly, no native binaries, runs in Node and the browser
