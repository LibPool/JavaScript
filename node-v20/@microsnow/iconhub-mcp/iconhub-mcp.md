# @microsnow/iconhub-mcp

> 标签: ai, claude, claude-desktop, cursor, icon-library, iconhub, icons, mcp, mcp-server, model-context-protocol, svg

## 简介

IconHub 的 MCP server：search-icons / get-icon 两个工具，让 Claude / Cursor 等 AI 编程助手直接检索并内联 IconHub 的 24×24 SVG 图标（线性 + 面性，currentColor，支持中英文与拼音搜索）。数据内置为包内静态 JSON，零依赖、零网络请求。
