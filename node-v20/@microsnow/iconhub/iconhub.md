# @microsnow/iconhub

> 标签: ai, filled-icons, icon, icon-library, icons, linear-icons, outline-icons, react, svg, vue

## 简介

AI 生成的开源 SVG 图标库：线性（stroke 1.5）与面性（filled）两种风格 / 24×24 / currentColor，支持按 id 取 SVG、中英文与拼音关键词搜索、同 id 双风格互换与 addedAt 增量查询。线上站点 IconHub
