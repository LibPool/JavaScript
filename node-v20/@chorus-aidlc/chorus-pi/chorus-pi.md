# @chorus-aidlc/chorus-pi

> 标签: ai-dlc, chorus, collaboration, multi-agent, pi-extension, pi-package, project-management

## 简介

Chorus AI-DLC collaboration platform extension for Pi >=0.84.4 <2. Supports native MCP on Pi >=0.99.0 and a verified adapter on older hosts, with lifecycle skills and read-only reviewers.
