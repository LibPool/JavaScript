# @baiduplayer/brtc-beauty-effect

> 标签: brtc-beauty-effect, webgl

## 简介

BRTCBeautyEffect 封装了百度云 RTC SDK 的美颜功能(美白(亮度)、磨皮（平滑度）、清晰（锐化度）、红润、对比度（明暗度）)，可以方便开发者在 Web 中使用。
