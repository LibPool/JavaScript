# @superbase/react-native

> 标签: JavaScript

## 简介

React Native용 컴포넌트. `@superbase/react`(웹)와 거의 동일한 컴포넌트 API(Text/Button/TextField/Stack/Switch)를 제공하며 `@superbase/tokens`의 native 토큰을 소비한다.
