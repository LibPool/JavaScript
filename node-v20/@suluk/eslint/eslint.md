# @suluk/eslint

> 标签: JavaScript

## 简介

ESLint rules for Suluk apps. `composition-only`: enforce the tier discipline (pages & sections stay composition-only; native markup → blocks, logic → controllers) with configurable per-metric budgets. Pure, dependency-free detection core. CANDIDATE toolin
