# @ts-ioc-container/react

> 标签: container, dependency-injection, di, hooks, inversion-of-control, ioc, react, scope, scoped-dependencies, ts-ioc-container

## 简介

React bindings for ts-ioc-container: a Scope component that maps container scopes onto the component tree, plus hooks to resolve from the surrounding scope.
