# @ninjaai/stimulus_grid

> 标签: data-grid, datagrid, grid, hotwire, spreadsheet, stimulus, table

## 简介

HTML-first data grid for Stimulus.js (Hotwire) — sort, filter, global search, selection, pagination, inline editing, custom cell renderers/editors, virtual scrolling, and a full public grid API.
