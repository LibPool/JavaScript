# @appmonster/mcp-ofd

> 标签: china, document, e-invoice, fapiao, mcp, model-context-protocol, ofd, 数电票, 电子发票

## 简介

MCP server that reads Chinese OFD documents (GB/T 33190): e-invoices 电子发票/数电票 fields, official documents, statements — text in reading order. No keys.
