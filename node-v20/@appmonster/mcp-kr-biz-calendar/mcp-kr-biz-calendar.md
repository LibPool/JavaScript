# @appmonster/mcp-kr-biz-calendar

> 标签: business-days, calendar, holidays, korea, mcp, model-context-protocol, tax, 공휴일, 부가세, 세무, 영업일, 원천세

## 简介

MCP server for Korean business dates: tax/payroll filing deadlines (부가세·원천세·종소세·법인세·4대보험), public holidays, business-day arithmetic. No keys. 한국 세무·영업일 캘린더 MCP.
