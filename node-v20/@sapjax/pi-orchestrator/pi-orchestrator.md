# @sapjax/pi-orchestrator

> 标签: agent, autonomous, multi-model, orchestrator, pi, pi-extension, pi-package, subagent

## 简介

Autonomous multi-model orchestration for pi — a thin policy layer on top of @tintinweb/pi-subagents. Routes implementation work through an orchestrator → scout/worker/reviewer team with per-role model and thinking-level routing.
