# @opensettle/sdk

> 标签: billing, evm, non-custodial, opensettle, stablecoin, subscriptions, usdc, usdt

## 简介

Official Node SDK for the OpenSettle API. Multi-chain stablecoin billing — USDC on Base, Ethereum, Polygon, Arbitrum, and Solana; USDT on Ethereum, Polygon, Arbitrum, Solana, and Tron.
