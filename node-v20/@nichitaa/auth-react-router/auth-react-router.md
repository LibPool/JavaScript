# @nichitaa/auth-react-router

> 标签: RBAC, authorization, react, react-router, react-router-dom

## 简介

**`@nichitaa/auth-react-router`** is a lightweight package that uses and extends basic `react-router-dom` v6 functionality and allows you to define the routes based on user `authorized` and `roles` states. It provides a simple API for configuring `public`
