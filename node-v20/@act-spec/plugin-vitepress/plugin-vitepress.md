# @act-spec/plugin-vitepress

> 标签: JavaScript

## 简介

VitePress plugin for the ACT (Agent Content Tree) reference implementation. Wraps the ACT generator pipeline against VitePress 1.x / 2.x via the transformPageData and buildEnd hooks.
