# @mitm/logger

> 标签: JavaScript

## 简介

La librairie fournit :  - un logger Winston (pour le backend, donc) configuré selon nos pratiques habituelles.  - un middleware Morgan (logging des requêtes express) configuré pour utiliser Winston.
