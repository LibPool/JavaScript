# @aggbond/my-popup

> 标签: dialog, modal, popup

## 简介

`Popup` 是一个轻量的完全免费的移动端弹窗组件（无依赖），提供常见的弹窗类型：`alert`、`tips`、`msg`、`confirm`、`showImagePreview`、`showBottomPopup`、`load` 与 `close`。
