# @salesforce/code-analyzer-uibundle-engine

> 标签: JavaScript

## 简介

Plugin package that adds the 'uibundle' engine into Salesforce Code Analyzer. Validates UI Bundle build-output integrity — currently ships sourcemap-based verification of each shipped dist/ artifact against its declared sourcemap and the submitted src/ tr
