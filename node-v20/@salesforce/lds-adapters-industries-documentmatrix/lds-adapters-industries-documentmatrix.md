# @salesforce/lds-adapters-industries-documentmatrix

> 标签: JavaScript

## 简介

Document Matrix component is a custom OS element by Discovery Framework. It is an out-of-box solution that removes the need for Admins to create multiple Assessments with the same set of questions but with a different set of files to upload at the end.
