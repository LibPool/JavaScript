# @manireddyt/core

> 标签: JavaScript

## 简介

The `@manireddyt/core` package serves as an abstraction layer over the `@catalogfi/wallets`(contains different kind of bitcoin and evm wallets) and `@manireddyt/orderbook` packages. It provides a simple interface to perform atomic swaps.
