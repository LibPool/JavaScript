# @zeroroot-ai/zerocool

> 标签: JavaScript

## 简介

opencode host adapter for Gibson (zerocool): zero-config LLM through the harness, ambient knowledge, and the Gibson MCP server registered for you. The tools come from @zeroroot-ai/gibson-mcp.
