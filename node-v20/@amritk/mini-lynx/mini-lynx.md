# @amritk/mini-lynx

> 标签: jsx, lynx, mjst, native, reactive, signals, typescript, ui

## 简介

A signals runtime for Lynx: real elements created once and mutated forever, driving Lynx's Element PAPI directly, with no virtual tree.
