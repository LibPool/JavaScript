# @cloud-video-kit/bitmovin-player

> 标签: bitmovin, cloud video kit, drm, insys, secure

## 简介

The bundle includes Bitmovin Player and Cloud Video Kit integration software. It allows you to stream content created in Cloud Video Kit using one of the best video players on the market. To use the bundle, you need a Cloud Video Kit account and a Player
