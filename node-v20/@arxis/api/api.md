# @arxis/api

> 标签: angular, angular-api, angular-http, angular-httpclient, angular-library, angular-service, api-client, base-url, global-headers, http-client, http-wrapper, httpclient, inject, provideApi, rest, rest-api, rest-client, rxjs, standalone, typescript

## 简介

Type-safe Angular HTTP client wrapper for REST APIs: base URL, global headers, inject(ApiService) and provideApi(). Angular 17+.
