# @cosmos.gl/deck-layers

> 标签: deck.gl, force, graph, layers, simulation, visualization, webgl

## 简介

A deck.gl layer that runs and draws a cosmos.gl graph — cosmos.gl's own renderer under deck's camera, on a shared luma.gl device

- 官网：https://cosmosgl.github.io/graph
