# @absolutejs/machines-bridge

> 标签: JavaScript

## 简介

Shop-LAN bridge agent for @absolutejs/commerce-machines: polls your app for print/embroidery jobs and delivers them to a hot folder, a printer port (TCP 9100), an IPP printer or the OS print queue. No arbitrary command execution.
