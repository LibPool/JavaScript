# braided

> 标签: data-driven, declarative, dependency-injection, integrant, lifecycle, modular, orchestration, resource-management, stateful, system-composition, testing, topology

## 简介

Untangle your stateful resources. A minimal, type-safe library for declarative system composition with dependency-aware lifecycle management. Inspired by Clojure's Integrant.
