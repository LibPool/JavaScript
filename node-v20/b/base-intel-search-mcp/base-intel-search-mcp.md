# base-intel-search-mcp

> 标签: agent-payments, ai-agent, base, mcp, model-context-protocol, pay-per-call, search, usdc, web-search, x402

## 简介

MCP server giving any AI agent pay-per-call web search, settled in USDC on Base via x402. Wraps the Base Intel /search API. The agent pays per query from its own wallet — no API key, no subscription.
