# bun-sqlite-key-value

> 标签: Bun, Bun.js, Cache, Data-Storage, Database, Db, KV, KVS, Key-Value, Key-Value-Storage, Key-Value-Store, NoSql, NoSql-Database, SQLite, Storage, Store, TTL, Time To Live, TypeScript, bun:sqlite, synchronous

## 简介

A super fast key-value store with SQLite that uses bun:sqlite and v8 as faster JSON replacement.
