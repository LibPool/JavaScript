# base64-tool

> 标签: base64, converter, decode, decoder, developer-tools, devkits, encode, encoding, utf8

## 简介

Encode and decode Base64 strings with UTF-8 support. Simple, fast, zero-dependency Base64 utility for Node.js and browsers.
