# brussle

> 标签: ai columns, api client, brussle, calibration, classification, confidence, decisions, model-computed columns, outcomes, postgres, sdk, threshold

## 简介

Brussle SDK for TypeScript. Brussle is the database for AI columns: define a column, keep it current as records change, record outcomes, and read the calibrated number with its 95% interval.
