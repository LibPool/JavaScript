# bol-twitter-bootstrap

> 标签: JavaScript

## 简介

*To link bol-twitter-bootrap in a project you're currently working on, so you don't have to publish on each change:*  1. In terminal enter `npm link` inside this folder  2. In your project enter `npm link bol-twitter-bootstrap`
