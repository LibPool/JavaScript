# browser-harness-ts

> 标签: agent, automation, browser, browser-harness, cdp, chrome, chrome-devtools-protocol, llm

## 简介

Thin TypeScript client for the Python browser-harness daemon. Share one Chrome across Python and TS agents. / Python browser-harness 守护进程的薄 TypeScript 客户端,让 Python 和 TS agent 共享同一个 Chrome。
