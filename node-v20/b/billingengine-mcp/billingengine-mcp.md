# billingengine-mcp

> 标签: billingengine, e-invoice, invoice, invoicing, mcp, model-context-protocol, xrechnung, zugferd

## 简介

MCP server for BillingEngine: create customers and invoices, look up invoices and record payments from Claude, Cursor and other MCP clients.
