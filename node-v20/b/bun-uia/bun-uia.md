# bun-uia

> 标签: accessibility, automation, bun, desktop, e2e, ffi, playwright, testing, typescript, uiautomation, win32, windows

## 简介

Playwright for the Windows desktop, from Bun — drive and test native GUIs via the UI Automation tree (find by name, invoke, type, assert), plus synthetic input, full-screen capture + image matching, native-window introspection (Spy++-style), an LLM comput
