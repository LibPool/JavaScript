# bytekit

> 标签: formerly @sebamar88/utils, http-client, logger, typescript, utilities

## 简介

Lightning-fast TypeScript utilities: Isomorphic API client, Async toolkit (retry, debounce, parallel), functional helpers (string, object, collection), and CLI for Swagger/OpenAPI type generation.
