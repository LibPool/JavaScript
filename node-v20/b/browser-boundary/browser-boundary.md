# browser-boundary

> 标签: browser, browserslist, chromium, compatibility, es-compat, firefox, playwright, qa, testing, webkit

## 简介

Find the oldest real browser version your website can actually run on. Detects compatibility boundaries across Chromium/Firefox/WebKit using real historical browser binaries.
