# botbuilder-wit-multi

> 标签: botbuilder, bots, chatbots, nlp, wit.ai

## 简介

Provides Wit.ai NLP integration for the Microsoft Bot Builder SDK. Supports caching with Redis and Memcached - based on botbuilderwit
