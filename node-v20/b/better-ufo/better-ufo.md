# better-ufo

> 标签: better-ufo, encoding, fork, literal-types, open-redirect, prototype-pollution, punycode, rfc-3986, security, type-safe, typescript, ufo, uri, url, url-parser, url-utils, whatwg

## 简介

URL utilities for humans — a security-hardened, WHATWG-conformant, type-refined fork of ufo. Adds parseURL/joinURL/normalizeURL security guards, encoding parity with URLSearchParams.toString(), and literal-preserving TypeScript inference.
