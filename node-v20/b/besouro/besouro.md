# besouro

> 标签: android, async-storage, console, debugging, devtools, expo, in-app, inspector, ios, jotai, mmkv, network-inspector, notifications, on-device, react-native, redux, redux-toolkit, socket.io, view-hierarchy, websocket, zustand

## 简介

On-device developer tools for React Native / Expo: network, WebSocket, Socket.IO, console, notifications, element, view hierarchy, files, Redux, Zustand, Jotai, AsyncStorage and MMKV inspectors in a draggable in-app panel.
