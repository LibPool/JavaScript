# beautify-console-log

> 标签: Display the number of log lines, beautiful, beautify, console, console color, console log, console-log, console.log, console.log美化, console美化, console调试, js, log, logger, logging, node, node console, node log, node logger, node logs, node.js, node.js console, output, print, printer, shell, style, styles, terminal, typescript, 控制台日志美化

## 简介

This is a further beautification and encapsulation of the 'console' object. You can use it like using "console. log", "console. info", "console. warn", "console. error", and it can display the code line information where the log is printed.
