# bch-token-split

> 标签: apidoc, bitcoin, bitcoin cash, client, cryptocurrency, front end, javascript, react, slp, tokens, wallet

## 简介

An npm library for splitting BCH and SLP Tokens from a paper wallet after the Nov 2020 BCH chain split.
