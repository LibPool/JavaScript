# bedrock-tunnel

> 标签: aws, bedrock, inference, llm, openai, serverless

## 简介

🪨 Bedrock Tunnel is an npm package that simplifies the integration of existing OpenAI-compatible API objects with AWS Bedrock's serverless inference LLMs.
