# babel-plugin-module-rewrite-with-root

> 标签: babel, babel-plugin, dynamic, import, module, rename, require, resolve, rewrite

## 简介

Babel plugin to dynamically rewrite the path in require() and ES6 import, with ability to setup root for monorepos
