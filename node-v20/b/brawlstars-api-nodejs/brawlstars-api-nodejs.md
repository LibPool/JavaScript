# brawlstars-api-nodejs

> 标签: brawlstars, brawlstars-api

## 简介

brawlstars-api-nodejsis a Node.js library for accessing the Brawl Stars API. It provides an easy-to-use interface for making requests to the API and receiving the responses in a convenient format.
