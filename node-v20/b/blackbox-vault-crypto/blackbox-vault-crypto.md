# blackbox-vault-crypto

> 标签: aes-gcm, blackbox, crypto, encryption, hmac, key-derivation, pbkdf2, sovereign, vault, web-crypto

## 简介

Standalone vault crypto primitives: multi-round PBKDF2, AES-GCM, HMAC-SHA256, CSPRNG. Pure Web Crypto API, zero dependencies. Extracted from BlackBox Wallet.
