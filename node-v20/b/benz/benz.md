# benz

> 标签: async, async-await, asynchronous, asyncify, await, cache, callback, cb, co, compose, composition, control, controlflow, elegance, flow, fn, functions, generator, generatorify, generators, hybrid, hybridify, ko, options, parallel, promise, promisify, runners, series, sync, thunkify, thunks, utopia, vo, ware

## 简介

Compose your control flow with absolute elegance. Support async/await, callbacks, thunks, generators, promises, observables, child processes and streams. Can power applications that need to have plugins. Useful for creating task, test and bench runners.
