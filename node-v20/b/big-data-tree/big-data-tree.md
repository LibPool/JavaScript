# big-data-tree

> 标签: JavaScript

## 简介

一款基于 vue2.x 开发的树组件，能兼顾少量和大量数据处理。它运用虚拟滚动与分页加载技术，提升加载速度、降低内存占用，有效避免大数据场景下的卡顿，适用于企业数据管理、数据可视化平台等场景。
