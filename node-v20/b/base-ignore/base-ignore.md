# base-ignore

> 标签: api, app, application, base, baseplugin, building-blocks, create, exclude, exclusion, file, framework, git, gitignore, glob, ignore, inverse, match, negate, negation, negative, parse, pattern, plugin, plugins, remove, subtractive, tool, toolkit, tools, wildmatch

## 简介

Adds an `.ignore` method that parses `.gitignore` and converts the patterns from wildmatch to glob patterns, so they can then be passed to glob, minimatch, micromatch, gulp.src, glob-stream, etc
