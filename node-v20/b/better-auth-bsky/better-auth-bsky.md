# better-auth-bsky

> 标签: atproto, authentication, better-auth, bluesky, dpop, oauth, oauth2, par, pkce

## 简介

A better-auth plugin that adds ATProto/Bluesky OAuth 2.1 authentication (DPoP, PAR, PKCE) via @atcute/oauth-node-client.
