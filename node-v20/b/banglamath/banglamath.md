# banglamath

> 标签: AVRO bangla string to number, bangla math, bangla to english, bangla unicode to number, banglaMath, banglamath, english number to bangla unicode

## 简介

This package converts UNICODE bangle string to a number and vice versa. This also contains some basic math operations like sum,sub,multi and div
