# bmf-steuerrechner-api

> 标签: JavaScript

## 简介

Provides a javascript api to access the Lohn- und Einkommensteuerrechner by the  Bundesministerium der Finanzen. Reference: https://www.bmf-steuerrechner.de/interface/einganginterface.xhtml
