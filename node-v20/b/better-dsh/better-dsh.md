# better-dsh

> 标签: agent, deepseek-harness, dsh, eval, ipython, kernel, plugin, repl

## 简介

Make your dsh ready for serious coding tasks. (Tools x Schemas)^REPL. `skill://`, `ctx://`, `agent://`, `dvc://`, `dsh://`, IPython REPL, Context as Variables, cross compactions recallable, full context revive. `hash-edit`, `dvc://browser`, subagent as fu
