# bdpayments

> 标签: bangladesh, bkash, nagad, payment-gateway, payments, sslcommerz, stripe, unified-payments

## 简介

Centralized payment gateway abstraction for Stripe, SSLCommerz, bKash, and Nagad. One unified API for charge, refund, and retrieve.
