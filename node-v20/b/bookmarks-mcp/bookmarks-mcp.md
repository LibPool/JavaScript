# bookmarks-mcp

> 标签: bookmarks, browser-bookmarks, chrome, claude, cursor, firefox, mcp, mcp-server, model-context-protocol, pocket-export, read-later, reading-list, safari

## 简介

Your bookmarks, wherever they live, readable by your AI. Local read-only MCP server for Chrome, Edge, Brave, Arc, Vivaldi, Firefox, Safari (incl. Reading List) bookmarks and Pocket/Instapaper/Raindrop export files.
