# building.js

> 标签: JavaScript

## 简介

__Building__ is a JavaScript library for building first person view in the Web platform.  It based on the CSS 3D transform and DOM, can easily tranform existing sites or appications into 3D environments. #### [Demo](http://changbenny.github.io/building/de
