# bucketcode

> 标签: aws, bucket, minio, nextjs, presigned-url, r2, s3, storage, typescript, upload

## 简介

Server-side S3 uploads and downloads: upload, put, get, getUrl, delete. Works with AWS S3, Cloudflare R2, MinIO and any S3-compatible storage.
