> 标签: ai-agent, ai-agents, balance, base, claude, cursor, defi, erc20, ethereum, gas, mcp, model-context-protocol, onchain, token, wallet

## 简介

MCP server for AI agents to interact with Base chain wallets. Check balances, estimate gas, inspect tokens, verify allowances, and resolve ENS — all through your AI assistant.
