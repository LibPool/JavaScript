# billy-mcp

> 标签: accounting, ai-agent, billy, billy.dk, billysbilling, bogføring, bookkeeping, claude, danish-accounting, erp, invoicing, mcp, mcp-server, model-context-protocol, regnskab

## 简介

MCP server for Billy (billy.dk) accounting — connect Claude and other AI assistants to your Danish bookkeeping: invoices, bills, journal entries, trial balance, bank reconciliation. With human-approval write protection.
