> 标签: bash, batch, better-strip-comments, block-comment, comment, comments, dart, elixir, go, ini, javascript, json5, jsonc, jsx, kotlin, line-comment, php, powershell, python, remove-comments, rust, scala, shell, strip, strip-comments, toml, tsx, typescript, yaml

## 简介

Strip line and/or block comments from a string. A fork of strip-comments with fixes for string-aware parsing (URLs, globs, PHP quirks) and added language support (Rust, Go, Kotlin, TOML, YAML, PowerShell, Batch, and more).
