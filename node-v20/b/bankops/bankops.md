# bankops

> 标签: ai-agents, charts, deck, investment-banking, mcp, pitch-deck, powerpoint, pptx, presentation, slides

## 简介

Deck engine for AI agents: turn deck JSON into investment-banking-grade PPTX. 12-column grid layout, native charts, text-fit budgets. Free for noncommercial use; commercial license required.
