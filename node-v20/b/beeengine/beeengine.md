# beeengine

> 标签: 2d, beeengine, canvas, esm, game-engine, gamedev, html5, javascript, platformer

## 简介

Modular, universal 2D game engine for HTML5 Canvas: physics, scenes, input, touch controls, asset management, tilemaps and collision system.
