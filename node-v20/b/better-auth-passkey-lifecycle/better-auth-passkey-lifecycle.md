# better-auth-passkey-lifecycle

> 标签: better-auth, credential-manager, google-password-manager, icloud-keychain, passkey, signal-api, webauthn

## 简介

WebAuthn Signal API lifecycle sync for better-auth's passkey plugin. Deletes stale passkeys from iCloud Keychain / Google Password Manager / device credential stores when they're removed server-side.
