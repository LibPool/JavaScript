# bambu-mcp

> 标签: 3d-printing, bambu, bambu-lab, claude, mcp, model-context-protocol, p1s, p2s, x1

## 简介

MCP server for Bambu Lab printers (P2S/P1S/X1 family) in LAN mode: slice, upload, print, and monitor over MQTT + FTPS
