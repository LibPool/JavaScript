# bandcamp-mcp

> 标签: bandcamp, claude, mcp, mcp-server, model-context-protocol, music, music-discovery

## 简介

Unofficial MCP server for Bandcamp music discovery — search, browse, and inspect albums, artists, and tracks from Claude and other MCP clients.
