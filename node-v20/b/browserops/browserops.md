# browserops

> 标签: agent, ai, automation, browser-automation, browserops, chrome, chrome-extension, claude, claude-code, codex, cursor, mcp, model-context-protocol

## 简介

Drive your real Chrome browser from any MCP-compatible AI client (Claude Code, Cursor, Codex, Continue, Windsurf). CLI + MCP server with procedure runtime.
