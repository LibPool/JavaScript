# bun-openapi-server

> 标签: api, bun, framework, http, openapi, rest, server, swagger, typescript

## 简介

Bun openapi server is a package designed to help users **scaffold boilerplate for the Bun server**, based on an OpenAPI manifest. This **contract-first approach** ensures good API consistency, documentation & ease of distribution across multiple platforms
