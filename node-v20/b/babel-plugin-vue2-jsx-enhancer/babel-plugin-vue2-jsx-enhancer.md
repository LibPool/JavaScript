# babel-plugin-vue2-jsx-enhancer

> 标签: babel-plugin, jsx, vue2

## 简介

为 Vue 2 JSX 提供模板指令增强的 Babel 插件，让你在 JSX 中使用接近 SFC 模板的指令写法。

## 官网

- npm 页面：https://www.npmjs.com/package/babel-plugin-vue2-jsx-enhancer

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install babel-plugin-vue2-jsx-enhancer`
- npm registry：https://registry.npmjs.org/babel-plugin-vue2-jsx-enhancer
