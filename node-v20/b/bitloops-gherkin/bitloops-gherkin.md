# bitloops-gherkin

> 标签: Google Docs, Google Sheets, automation, bdd, behavior driven development, bitloops, cli, cucumber, gherkin, sheets, test data, testing, typescript

## 简介

bitloops-gherkin is a node.js package that allows you to generate Gherkin tables in Cucumber feature files using Google Sheets
