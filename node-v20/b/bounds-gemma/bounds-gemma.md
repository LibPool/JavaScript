# bounds-gemma

> 标签: ai, gemma, gemma-4, healthcare, hipaa, llm, ollama, on-device, phi, pii, privacy, redaction, webllm

## 简介

On-device Gemma 4 contextual PHI redaction toolkit for HIPAA Safe Harbor de-identification. Runs locally via Ollama (browser WebLLM path wired for when MLC ships a Gemma 4 build). Never on a server.
