# bdbuilder

> 标签: JavaScript

## 简介

Enhanced plugins transpiler for BetterDiscord. Allows you to build plugin with multiple files at once.

- 官网：https://github.com/BetterDiscordBuilder/bdbuilder#readme
- 源码仓库：git://github.com/BetterDiscordBuilder/bdbuilder.git
