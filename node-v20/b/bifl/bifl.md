# bifl

> 标签: JavaScript

## 简介

Easy-to-use, pre-configured cli tool to generate webfont icon kits from a bunch of .svg files, base on icon-font-generator by Tancredi Trugenberger

## 官网

- 官网：https://github.com/Workshape/icon-font-generator#readme
- 源码仓库：git+https://github.com/HadrienByr/bifl.git
- npm 页面：https://www.npmjs.com/package/bifl
