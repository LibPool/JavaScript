# brunogen

> 标签: agent, ai, bruno, cli, echo, express, fiber, gin, laravel, mcp, openapi, skill

## 简介

Scan Laravel, Express.js, and Go API projects, normalize them into OpenAPI, and emit Bruno, AI context, and MCP server artifacts.
