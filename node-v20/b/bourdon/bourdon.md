# bourdon

> 标签: JavaScript

## 简介

The unscoped `bourdon` CLI — a thin, Apache-2.0 dispatch over the supported @getbourdon/* TypeScript engine surface, including recognition, federation, participant export, leak audit, and the agents tray contract.
