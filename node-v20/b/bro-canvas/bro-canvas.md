# bro-canvas

> 标签: accessibility, canvas, command-palette, desktop, draggable, react, resizable, taskbar, window-manager, windows

## 简介

Draggable, snappable, keyboard-accessible window canvas for React — a headless useWindowManager hook plus themeable Window, Taskbar, CommandPalette, and Minimap components.
