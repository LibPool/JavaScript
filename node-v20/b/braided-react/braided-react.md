# braided-react

> 标签: braided, context, declarative, dependency-injection, hooks, integrant, lifecycle, react, resource-management, stateful, system-composition, testing

## 简介

React integration for Braided - Bridge your stateful systems to React without giving up lifecycle control. React observes, doesn't own. Minimal, type-safe dependency injection for React.
