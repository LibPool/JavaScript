# bundlesize-webpack-plugin

> 标签: JavaScript

## 简介

是一个自定义的 webpack 插件，主要作用是检查 webpack 构建输出的最终 bundle 文件的大小，并与设定的大小限制进行比较，然后根据比较结果输出相应的信息
