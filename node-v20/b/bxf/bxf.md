# bxf

> 标签: ajax, axios, bxf, chrome, crx, fetch, http, mv3, xhr

## 简介

一个基于 promise 的网络请求库,支持XMLHttpRequest和fetch两种可选请求接口。除了常规的网页请求外，它还特别设计以与使用 manifest_version: 3 的浏览器扩展无缝集成。
