# bootstrap-modbox

> 标签: bootstrap, bootstrap5, dialog, javascript, modal

## 简介

Native JavaScript wrapper for simple Bootstrap 5 modals. Provides support for alert, confirm, and prompt modals, as well as advanced custom dialogs.
