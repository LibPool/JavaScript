# bitbucket-notifications

> 标签: OAuth2, bitbucket, gmail, javascript, jira, node, nodejs, nodemailer, notifications, push notifications

## 简介

Node.js application which can send an email with links to all PRs that have been merged in last 24 hours. It connects to Bitbucket, Gmail and Jira with OAuth2 for higher security by simply adding your credentials in configuration file.
