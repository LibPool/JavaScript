# better-auth-client-credential

> 标签: Client Credential, Entra ID, Microsoft, better-auth, better-fetch

## 简介

A Better Auth plugin that implements the OAuth 2.0 client credentials flow against Microsoft Entra ID (formerly Azure AD)..
