# blur-js

> 标签: JavaScript

## 简介

blur.js is a jQuery plugin that produces psuedo-transparent blurred elements over other elements. http://blurjs.com/

## 官网

- 官网：http://blurjs.com/
- 源码仓库：git+https://github.com/CezaryDanielNowak/Blur.js.git
- npm 页面：https://www.npmjs.com/package/blur-js
