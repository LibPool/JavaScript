# backpopup.js

> 标签: back button, back button popup, backpopup, browser popup, conversion, exit intent, exit popup, javascript popup, lead capture, lightweight, modal, no dependencies, popup, vanilla js

## 简介

Show customizable popups on browser back action — ideal for exit-intent offers, surveys & lead capture. Pure JavaScript, no jQuery.
