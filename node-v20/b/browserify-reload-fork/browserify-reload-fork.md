# browserify-reload-fork

> 标签: browser, browserify, live-reload, reload, sync, watch

## 简介

browserify-reload is a browserify plugin that reload your client side bundle everytime it gets updated (e.g. through watchify)

## 官网

- 官网：https://github.com/131/browserify-reload
- 源码仓库：git+ssh://git@github.com/131/browserify-reload.git
- npm 页面：https://www.npmjs.com/package/browserify-reload-fork
