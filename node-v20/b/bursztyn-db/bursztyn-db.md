# bursztyn-db

> 标签: binary, bun, columnar, database, migrations, serialization, sharedarraybuffer, snapshot, typed-array, zero-copy

## 简介

Zero-copy, single-buffer columnar snapshots for TypeScript — typed-array fields, schema hashing, and a built-in migration system. Data, frozen in amber.
