# bettip

> 标签: api-client, gosloto, lottery, lotto, open-data, powerball, results, south-africa, uk49s

## 简介

Zero-dependency client for the free BetTip Draws API: UK49s, Gosloto and South African Lottery results as JSON

## 官网

- 官网：https://bettip.co.za/api/
- 源码仓库：git+https://github.com/bettip-co-za/bettip-draws-api.git
- npm 页面：https://www.npmjs.com/package/bettip

## 历史版本号

- 1.0.0

- npm 安装：`npm install bettip`
- npm registry：https://registry.npmjs.org/bettip
- Node 要求：>=18
