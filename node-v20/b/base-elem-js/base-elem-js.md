# base-elem-js

> 标签: CSS manipulation, DOM helpers, DOM manipulation, DOM traversal, chaining, event handling, jQuery, lightweight, query selector, small, utility library

## 简介

A super light weight package for querying the DOM, adding event listeners, removing them, making and manipulating elements and more.
