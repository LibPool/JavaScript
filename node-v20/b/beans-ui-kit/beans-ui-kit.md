# beans-ui-kit

> 标签: JavaScript

## 简介

Библиотека унифицированных компонентов под всевозможные(в будущем) формы. Планирую развивать компоненты исходя из своих рабочих задач. Сейчас наиболее функциональный - BaseSelect, последовательно буду доделывать и остальные.
