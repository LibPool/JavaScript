# babylon-pathtracer

> 标签: babylon.js, babylonjs, denoise, gpu, path-tracing, pathtracer, raytracing, renderer, webgl2

## 简介

Progressive GPU path tracer (Cycles-style) as a Babylon.js plugin: scene-agnostic ingestion, first-hit AOVs, firefly clamping, GPU a-trous denoise, reproducible sampling and PNG export.
