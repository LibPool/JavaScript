# bunroutine

> 标签: bun, channels, concurrency, goroutines, parallelism, worker-threads

## 简介

Go-goroutine-flavored concurrency for Bun: a real worker-thread pool plus Go-style channels, select, WaitGroup and Mutex for same-thread coordination.
