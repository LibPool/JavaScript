# bridge.ino

> 标签: arduino, avr, gcc, ino, leo, make, uno, yun

## 简介

The library to use the Arduino YUN. The Bridge library create a link between the 32U4 and the AR9331 enabling to control most of the linux features from the sketch.  Packaged for the leo build system.
