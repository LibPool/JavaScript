# bearer-token-parser

> 标签: api, auth, authentication, authorization, bearer, express, middleware, oauth, rfc6750, token, typescript

## 简介

Zero-dependency Bearer token parser & validator middleware for Express. Extracts and validates tokens from headers, query strings, and request bodies with async support.
