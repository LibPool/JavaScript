# blackbrake

> 标签: ai-agents, audit, claude-code, local-first, secrets, security

## 简介

Local audit of AI coding agent transcripts (exposed secrets, risky add-ons, where spend concentrates) and a guard for Claude Code. No network, no dependencies.
