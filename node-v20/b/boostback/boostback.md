# boostback

> 标签: agents, ai, gateway, mcp, model-context-protocol, rollback, safety, undo

## 简介

Boostback — the undo layer for AI agents. An MCP gateway that journals every tool call with pre-images and can roll a span of agent work back. Name claimed during active development; first milestone in progress.
