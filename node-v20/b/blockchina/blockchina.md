# blockchina

> 标签: JavaScript

## 简介

CentOS 7의 Firewalld에 중국발 IP를 막는 기능을 추가하는 스크립트입니다. 중국발 IP 대역이 변경될 수 있으므로, 영구적으로 저장되지 않아 서버 재시작 시 업데이트 후 다시 한번 실행해야 합니다.
