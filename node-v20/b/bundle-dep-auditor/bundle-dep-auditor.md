# bundle-dep-auditor

> 标签: JavaScript

## 简介

Detects duplicate/conflicting package versions bundled across separately-built frontend apps (micro-frontends, multi-app monorepos), from webpack/Rspack stats.json, esbuild metafile.json, or Rollup/Vite visualizer JSON.
