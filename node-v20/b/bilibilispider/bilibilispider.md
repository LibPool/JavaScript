# bilibilispider

> 标签: JavaScript

## 简介

这是一个用于个人获取b站数据的前端爬虫库，请求部分由我的项目 JSpider 2.0 完成，而数据转换成 xlsx 文件的部分由 sheetjs 完成。而相关js插件都是通过 jsdelivr 的 api 导入的。
