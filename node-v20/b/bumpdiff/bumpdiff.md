# bumpdiff

> 标签: audit, capability, ci, dependencies, diff, install-scripts, npm, provenance, security, supply-chain, upgrade

## 简介

What a version bump changed about what a package can do. Install scripts, new capabilities, new hosts, a new publisher. Nothing touches disk, no install script runs, zero dependencies.
