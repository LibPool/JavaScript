# botbuilder-adapter-trovo-heroku

> 标签: bot, botkit, botbuilder, adapter, trovo, chat, heroku

## 简介

An adapter to support Trovo.live chat using botkit and botbuilder. Mod for Heroku's slugs. CDP session is only available in Chromium.
