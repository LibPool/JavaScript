# billy-layout

> 标签: angular, components, dark-mode, design-system, layout, scss, shell, signals, standalone-components

## 简介

Angular design system & application shell: topbar/sidebar layout, SCSS design tokens, form fields (CVA), dialogs, feedback components and file viewers. Docs shipped in the package, AI-assistant ready.
