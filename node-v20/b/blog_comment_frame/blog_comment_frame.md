# blog_comment_frame

> 标签: JavaScript

## 简介

这个包用于在网页中引入 <a href='https://github.com/qumuchegi/blog-comment'> <img src='https://img.shields.io/badge/blog__comment-0.1.0-red'/> </a>, blog_comment 是一个开箱即用的 评论组件，适合嵌入个人博客页面，提供文章的评论功能
