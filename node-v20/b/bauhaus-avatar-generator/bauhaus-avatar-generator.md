# bauhaus-avatar-generator

> 标签: art, avatar, bauhaus, crc32, deterministic, generator, geometric, grid-layout, svg, typescript, weighted-colors

## 简介

A TypeScript library for generating deterministic Bauhaus-style SVG avatars with 2x2 grid layouts and weighted color palettes
