# baskreport

> 标签: JavaScript

## 简介

基于 **Vue 3 + TypeScript** 开发的前端组件库，用于在 Web 应用中集成 [BaskReport](http://www.basksoft.com) 报表能力。该组件库提供了丰富的报表展示、交互、导出及打印功能。
