# brisvox

> 标签: llm, realtime, telephony, voice, voice-agent, webrtc

## 简介

Brisvox for JavaScript and TypeScript: npm i brisvox. The agent SDK (@brisvox/agent) for Node and the browser client (@brisvox/web) of the brisvox real-time voice engine, under the short name.
