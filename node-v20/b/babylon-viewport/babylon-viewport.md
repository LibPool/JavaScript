# babylon-viewport

> 标签: JavaScript

## 简介

1. tsconfig.json을 prod 설정으로 적용한다. 2. `yarn build` 3. package.json에서 version을 수정한다. 4. npm login으로 회사계정 로그인 5. npm publish
