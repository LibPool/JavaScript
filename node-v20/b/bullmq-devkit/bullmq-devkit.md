# bullmq-devkit

> 标签: bull, bullmq, cli, cron, dead-letter, devtools, dlq, healthcheck, jobs, metrics, monitoring, prometheus, queue, redis, retry, worker

## 简介

A zero-dependency developer toolkit for BullMQ: queue health checks, Prometheus metrics, dead-letter / failed-job management, retry debugging, and cron validation. Library + CLI.
