# botkit-rasa

> 标签: bot, botkit, bots, messenger, rasa, rasa nlu, rasanlu, slack

## 简介

This plugin provides Botkit developers a way to use the [Rasa NLU](https://rasa.ai/) open source, self hosted natural language API.
