# bigfileupload

> 标签: breakpoint, js, react, upload, vue, web, 上传, 工具, 文件, 文件上传, 断点续传

## 简介

This is a js breakpoint continuation utility class function that supports starting, pausing, re-uploading, and throwing errors on your own initiative。这是一个js断点续传工具类函数,支持开始,暂停,重新上传,并且可以自已主动抛出错误
