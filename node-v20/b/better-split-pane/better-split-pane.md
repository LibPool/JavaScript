# better-split-pane

> 标签: JavaScript

## 简介

Like [`react-split-pane`](https://npmjs.com/package/react-split-pane) but supporting any CSS size units, not just `px` (e.g. `%`, `em`, even `calc()`, `min()`, and so on)
