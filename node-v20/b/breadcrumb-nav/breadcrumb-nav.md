# breadcrumb-nav

> 标签: accessibility, breadcrumb, breadcrumbs, custom-element, json-ld, navigation, nextjs, react, schema.org, seo, structured-data, tailwind, typescript, web-component

## 简介

Tiny, SEO-correct breadcrumb navigation for any JavaScript project: infers the trail from the URL or a type-checked route list, renders accessible markup and schema.org BreadcrumbList JSON-LD. React, Next.js and a plain custom element, styled with Tailwin
