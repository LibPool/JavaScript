# blendfile

> 标签: 3d, blend, blender, parser, sdna

## 简介

Read Blender .blend files (legacy and 5.x headers, gzip/zstd, SDNA) in browsers and Node.js.

- 官网：https://mansi1.github.io/blendfile/
- 源码仓库：git+https://github.com/Mansi1/blendfile.git
