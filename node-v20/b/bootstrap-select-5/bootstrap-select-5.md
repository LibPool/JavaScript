# bootstrap-select-5

> 标签: JavaScript

## 简介

Adds Bootstrap 5 support to Bootstrap select package. I simply created an NPM package for it. This package was created by https://github.com/farhadmammadli and Bootstrap select was created by https://github.com/snapappointments/bootstrap-select
