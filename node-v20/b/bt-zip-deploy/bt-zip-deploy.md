# bt-zip-deploy

> 标签: baota, cli, deploy, zip, 宝塔

## 简介

通过宝塔面板 API 部署本地目录：先打包成 zip，上传到远端目录，再解压覆盖

## 官网

- npm 页面：https://www.npmjs.com/package/bt-zip-deploy

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install bt-zip-deploy`
- npm registry：https://registry.npmjs.org/bt-zip-deploy
- Node 要求：>=16.0.0
