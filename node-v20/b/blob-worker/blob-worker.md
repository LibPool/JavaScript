# blob-worker

> 标签: JavaScript

## 简介

通常情况下创建webWorker是需要创建一个独立的js文件，但目前大部分是单品页面，难以维护独立的js文件。所以我们可以使用二进制创建webWorker。

## 官网

- npm 页面：https://www.npmjs.com/package/blob-worker
