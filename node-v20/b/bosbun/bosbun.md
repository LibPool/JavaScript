# bosbun

> 标签: bun, elysia, framework, fullstack, ssr, svelte

## 简介

A fast, batteries-included fullstack framework — SSR · Svelte 5 Runes · Bun · ElysiaJS. File-based routing inspired by SvelteKit. No Node.js, no Vite, no adapters.
