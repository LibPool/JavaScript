# bmweb-cli

> 标签: bmw, cli, diagnostics, ediabas, inpa, obd

## 简介

BMWeb's tools as a command line: read INPA .IPO scripts, compile .IPS sources, search the corpus job index, decode and diff shared Garage reports, and, over a K+DCAN cable, run jobs, whole-car scans and INPA screens in the terminal.
