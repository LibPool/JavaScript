# beelogbin

> 标签: bee, ethswarm, logs, swarm

## 简介

Spawns a Bee node and serves its last 500 log lines over plain HTTP, for sharing logs without server access

## 官网

- npm 页面：https://www.npmjs.com/package/beelogbin

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install beelogbin`
- npm registry：https://registry.npmjs.org/beelogbin
- Node 要求：>=18
