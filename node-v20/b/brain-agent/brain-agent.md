# brain-agent

> 标签: ai-agent, artificial-brain, brain-agent, cli, filesystem, local-agent, tool-calling, websocket

## 简介

Local agent for Artificial Brain v3 — connects your machine to the Brain via WebSocket, giving it access to 144 tools (filesystem, git, database, browser, docker, business APIs, AI/LLM, and more)
