# banco-de-ideas-mcp

> 标签: ai-agents, bisociaciones, creatividad, ideas, mcp, mcp-server, model-context-protocol

## 简介

MCP Server para co-crear ideas y bisociaciones artificiales. Permite a agentes de IA leer, publicar y explorar conexiones creativas entre conceptos de dominios distintos.
