# browser-gateway

> 标签: ai-agent, browser, cdp, chrome-devtools-protocol, failover, gateway, headless, headless-browser, load-balancer, mcp, model-context-protocol, playwright, proxy, puppeteer, websocket

## 简介

The open router for cloud browsers. One endpoint, any provider: failover, load balancing, persistent profiles, session replay, REST API, MCP server, dashboard.
