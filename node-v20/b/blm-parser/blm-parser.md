# blm-parser

> 标签: BLM, File, Parser

## 简介

.blm files are a real estate specific file format developed by Rightmove, a British-based company that runs www.rightmove.co.uk, an online real estate portal. The format definition is available at http://www.rightmove.co.uk/ps/pdf/guides/RightmoveDatafeed
