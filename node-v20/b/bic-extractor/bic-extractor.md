# bic-extractor

> 标签: BIC, IBAN, bank, generator, identifier

## 简介

A simple utility to generate the Bank Identifier Code (BIC) from an International Bank Account Number (IBAN). This tool includes mappings for most banks in Spain, and users can add banks from their own countries.
