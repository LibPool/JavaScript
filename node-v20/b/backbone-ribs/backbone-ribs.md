# backbone-ribs

> 标签: backbone ribs view region model collection  secureview simpleview helpers attribute json requirejs

## 简介

An extension project which adds an additional layer of functionality to Backbone that simplifies creation of basic types of views and separates Views from Regions which enables proper garbage handling without having to roll it all yourself.
