# bun-serial

> 标签: bun, ffi, hardware, robotics, rs232, rs485, serial, serialport, termios, uart

## 简介

Cross-platform serial ports for Bun (Linux, macOS, Windows) via bun:ffi. No native compilation, no node-gyp.
