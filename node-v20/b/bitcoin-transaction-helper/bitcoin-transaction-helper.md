# bitcoin-transaction-helper

> 标签: BTC, Bitcoin, RSK, blockchain, dapps, ethereum, rootstock, smart-contract, solidity

## 简介

Solidity library with functions to work with Bitcoin transactions inside smart contracts. Forked from RSK's btc-transaction-solidity-helper with enhanced P2PK (Pay-to-Public-Key) script support.
