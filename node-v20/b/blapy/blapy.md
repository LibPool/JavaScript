# blapy

> 标签: Ajax, Web App, Web applications, dynamic web, ecosystem:jquery, jquery-plugin

## 简介

Blapy is a jQuery plugin that helps you to create and manage ajax and single page web applications (SPA) with almost no javascript coding to do it. Your web application is built the usual way of generating web pages like with php or any standard CMS and B
