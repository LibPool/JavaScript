# bravoh-wire

> 标签: ai, chat, discriminated-union, frames, llm, protocol, streaming, typescript, websocket, zod

## 简介

Zod-typed WebSocket frame protocol for streaming AI chat UIs — the wire protocol BRAVOH's production AI chat runs on. Discriminated unions, crash-proof parsing, full TypeScript narrowing.
