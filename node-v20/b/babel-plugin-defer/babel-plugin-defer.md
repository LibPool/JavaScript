# babel-plugin-defer

> 标签: babel, babel-plugin, cleanup, defer, go, javascript, resource-management, transpiler, typescript

## 简介

Babel plugin that transpiles defer statements to JavaScript, bringing Go-like defer functionality to JavaScript/TypeScript applications
