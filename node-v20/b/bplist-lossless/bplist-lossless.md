# bplist-lossless

> 标签: apple-plist, binary-data, binary-plist, bplist, bplist-parser, bplist-serializer, ios-plist, lossless, macos-plist, plist, plist-parser, plist-serializer, plist-writer, roundtrip, serialization

## 简介

> Lossless binary plist parser and serializer for any modern JavaScript runtime. > > No `Buffer` dependency. The library uses standard `Uint8Array` / `ArrayBuffer` APIs, so it works in browsers, Bun, Deno, Node.js, workers, and other non-Node runtimes.
