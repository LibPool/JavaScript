# babel-openui5-module-formatter

> 标签: babel, babeljs, es6, openui5, sapui5, ui5

## 简介

This is a custom module formatter for the babel js transpiler. It transpiles ES6 modules to `sap.ui.define` calls (AMD-like syntax).
