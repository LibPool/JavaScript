# brfork-typeorm

> 标签: JavaScript

## 简介

Data-Mapper ORM for TypeScript, ES7, ES6, ES5. Supports MySQL, PostgreSQL, MariaDB, SQLite, MS SQL Server, Oracle, MongoDB databases.

- 源码仓库：git+https://github.com/typeorm/typeorm.git
- npm 页面：https://www.npmjs.com/package/brfork-typeorm
