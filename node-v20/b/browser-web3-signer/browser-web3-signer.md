# browser-web3-signer

> 标签: browser-wallet, ethereum, evm, metamask, signer, transaction-signing, tron, tronlink, viem, wallet, web3

## 简介

Sign EVM and TRON transactions and messages from TypeScript using your own browser wallet (MetaMask, Rabby, TronLink) — the private key never leaves the browser. Viem transport + account included.
