# browser-parser-js

> 标签: JavaScript

## 简介

这个工具是用来做不兼容浏览器跳转的，比如，你的程序最低兼容到ie8，你可以使用此程序轻松地验证所有ie8浏览器，然后对这些浏览器进行跳转，跳转到升级浏览器的页面。
