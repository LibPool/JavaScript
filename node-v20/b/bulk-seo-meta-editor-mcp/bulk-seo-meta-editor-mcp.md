# bulk-seo-meta-editor-mcp

> 标签: ai-agent, bulk-update, claude, claude-code, mcp, meta-tags, model-context-protocol, rank-math, seo, wordpress, yoast

## 简介

Bulk edit Yoast SEO and Rank Math meta on WordPress from Claude Code or Claude Desktop. MCP server for the Bulk SEO Meta Editor plugin: bulk update titles and descriptions, image alt text, JSON-LD schema, CSV import and export, taxonomy and CPT archives.
