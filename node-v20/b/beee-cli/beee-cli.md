# beee-cli

> 标签: api, beee, beeeproject, chess, cli

## 简介

CLI for the BEEE public API (beeeproject.com): banks, partner codes, registration and payments.

## 官网

- 官网：https://beeeproject.com/docs
- 源码仓库：https://beeeproject.com
- npm 页面：https://www.npmjs.com/package/beee-cli

## 历史版本号

- 1.0.0

## 获取地址

- npm 安装：`npm install beee-cli`
- npm registry：https://registry.npmjs.org/beee-cli
- Node 要求：>=18
