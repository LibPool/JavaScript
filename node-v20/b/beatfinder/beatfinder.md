# beatfinder

> 标签: beat-detection, bpm, chroma, music-information-retrieval, rhythm, tempo, web-audio

## 简介

Real-time rhythm and harmony event detection for the Web Audio API -- detected/predicted beats, downbeats, loudness spikes, chord changes, and key changes.
