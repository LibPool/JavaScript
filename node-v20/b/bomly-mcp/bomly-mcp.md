# bomly-mcp

> 标签: bomly, cyclonedx, dependencies, mcp, model-context-protocol, sbom, spdx

## 简介

Run the Bomly MCP server with npx. Downloads the matching Bomly CLI release binary and starts `bomly mcp serve`.
