# base-ui-solid

> 标签: a11y, base-ui, solid, solid-component, solidjs, unstyled

## 简介

An unofficial Solid 2.0 port of Base UI, a library of headless ('unstyled') components and low-level hooks. You gain complete control over your app's CSS and accessibility features.
