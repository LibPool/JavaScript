# bl3-convert

> 标签: bl3, borderlands 3, cli-tool, modding, pc, ps4, ps5, save-editor, save-games

## 简介

A simple, Node.js CLI tool for Borderlands 3, assisting JSON editing and conversion for PS4 to PC save files and vice versa
