# garmin-personal-api-mcp

> 标签: claude, fit, garmin, garmin-connect, health, mcp, model-context-protocol, running

## 简介

MCP server for your own Garmin Connect data (activities with FIT splits, sleep, HRV, Body Battery, weight) via Garmin's official Personal API, with an interactive key setup wizard.
