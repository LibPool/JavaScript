# @solcis/sdk

> 标签: authorization, fail-closed, pep, policy, policy-enforcement-point, solcis

## 简介

Reference Node PEP (Policy Enforcement Point) client for the Solcis policy evaluator: one API over both transports (process-exec seam + framed-TCP serve daemon) that enforces decisions fail-closed and verifies signed receipts before honouring a proceed-ab
