# @typeshade/mcp

> 标签: glsl, mcp, model-context-protocol, shader, typescript, typeshade, webgpu, wgsl

## 简介

A Model Context Protocol server that gives coding agents TypeShade's own diagnostics, compiled WGSL and GLSL, navigation, vocabulary and a CPU run of a shader.
