# create-simo-api

> 标签: api, boilerplate, create, express, jwt, postgresql, scaffold

## 简介

Scaffold an Express 5 + PostgreSQL API with JWT auth (access + refresh rotation), role permissions, Zod validation, service layer, migrations, seed and tests.
