> 标签: facet, filter, filter-bar, modal, multi-select, range-slider, react, search, taxonomy

## 简介

Dependency-free React filter bar — a search line plus buttons that open apply-on-confirm modals: cascading taxonomy pickers with search, range sliders and choice chips
