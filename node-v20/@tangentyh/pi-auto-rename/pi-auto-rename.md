# @tangentyh/pi-auto-rename

> 标签: auto-rename, fork, herdr, pi-extension, pi-package, session-name, tmux, zellij

## 简介

Auto-generate names for your pi session and the terminal surfaces it runs in (tmux window, herdr pane/tab, zellij pane/tab) so it is easy to see what each pi is doing. Fork of @normful/pi-auto-name with subagent-surface gating and config moved into pi's s
