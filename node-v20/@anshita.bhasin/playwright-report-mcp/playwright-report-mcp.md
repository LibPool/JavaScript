# @anshita.bhasin/playwright-report-mcp

> 标签: claude, cursor, mcp, model-context-protocol, playwright, test-report

## 简介

Read-only MCP server that answers compact JSON questions about Playwright JSON reporter files (summary, failures, slowest tests, run comparison).
