# @paniniapi/forensics

> 标签: bank-statement, document-integrity, fintech, forensics, india, lending, pdf, tamper-detection

## 简介

Deterministic document-integrity forensics for bank statements — PDF structural signals, CMS/PKCS#7 signature validation, and arithmetic consistency checks. Zero runtime dependencies, fully client-side.
