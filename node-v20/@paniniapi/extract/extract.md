# @paniniapi/extract

> 标签: bank-statement, csv, extraction, fintech, india, pdf, sms-parsing, upi

## 简介

Statement extraction for Indian banking documents — CSV/Excel layouts, PDF text-layer, bank SMS, and pluggable OCR/spreadsheet seams. Zero runtime dependencies.
