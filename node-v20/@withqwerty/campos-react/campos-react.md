> 标签: campos, charts, data-visualization, expected-goals, football, heatmap, pass-network, pizza-chart, radar-chart, react, shot-map, soccer, svg, typescript, xg

## 简介

React SVG components for football data visualizations — shot maps, pass networks, heatmaps, radar and pizza charts. Main entry point for the Campos library.
