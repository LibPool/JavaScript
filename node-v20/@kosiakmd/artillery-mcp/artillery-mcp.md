# @kosiakmd/artillery-mcp

> 标签: api-testing, artillery, aws, claude, cursor, fargate, http-testing, load-testing, mcp, model-context-protocol, performance-testing

## 简介

MCP server for Artillery 2.x — full CLI flag surface (run/run-fargate), counter-rich parse_results, raw-text output parser, and an optional config-driven project launcher.
