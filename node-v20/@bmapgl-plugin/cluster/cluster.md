# @bmapgl-plugin/cluster

> 标签: 地图点聚合插件, 百度地图点聚合

## 简介

基于百度地图GL API实现地理点聚合能力，用于展示海量点标记。支持将地理点数据按照距离、属性、地理围栏进行聚合，以提高地图绘制性能。
