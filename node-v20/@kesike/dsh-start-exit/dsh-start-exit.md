# @kesike/dsh-start-exit

> 标签: deepseek-harness, dsh, dsh-plugin, exit, plugin, restart, start, web

## 简介

在 dsh web 界面提供启动、退出与重新启动按钮：通过可见 Windows Terminal（PowerShell 7）管理宿主进程
