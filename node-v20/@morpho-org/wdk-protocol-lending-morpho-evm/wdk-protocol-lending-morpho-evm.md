# @morpho-org/wdk-protocol-lending-morpho-evm

> 标签: erc-4337, ethereum, lending, morpho, morpho blue, morpho-sdk, protocol, vaults, wdk

## 简介

A WDK lending module that lets EVM wallet accounts interact with Morpho vaults and markets through @morpho-org/morpho-sdk.
