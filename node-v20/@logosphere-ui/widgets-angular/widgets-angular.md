# @logosphere-ui/widgets-angular

> 标签: JavaScript

## 简介

Angular wrappers for `@logosphere-ui/widgets` (Chart.js-backed Lit components). Optional — the native custom elements (`<logosphere-chart-bar>`, etc.) from `@logosphere-ui/widgets` can be used directly in any Angular app without this package.
