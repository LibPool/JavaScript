# @ngriffin_uk/polychat-ai-experiments

> 标签: JavaScript

## 简介

Experimentation primitives for Polychat: define flags and experiments in code, assign users to variants with exposure telemetry, run generations under an assignment, track outcomes, and run offline variant evaluations with metrics
