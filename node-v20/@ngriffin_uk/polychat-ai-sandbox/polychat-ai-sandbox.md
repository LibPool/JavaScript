# @ngriffin_uk/polychat-ai-sandbox

> 标签: JavaScript

## 简介

Sandboxed execution primitives for Polychat: evaluate untrusted code in a dynamic Worker isolate, expose host tools to it as code mode, and enforce network policy through an outbound gateway
