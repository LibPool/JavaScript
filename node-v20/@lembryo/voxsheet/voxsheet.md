# @lembryo/voxsheet

> 标签: autofill, data-grid, datagrid, editable, editable-grid, excel, fill-handle, grid, large-data, react, react-data-grid, react-spreadsheet, react-table, server-side, spreadsheet, table, typescript, virtual-scroll, virtualization, virtualized, windowing

## 简介

Virtual-scrolling React spreadsheet / data grid for millions of rows — Excel-like selection, editing, autofill, clipboard, and column resize, with host-controlled (server-driven) sort, filter, and search. TypeScript-first, MIT.
