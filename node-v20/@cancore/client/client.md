# @cancore/client

> 标签: api-client, bridge, cancore, canton, swap, trading, usdcx

## 简介

A typed client for the Cancore API: orders and pool trades (./swap), USDCx bridge (./bridge), live order updates (./realtime). No keys — signing stays with @cancore/wallet or the dApp connector.
