# @boarteam/fix

> 标签: financial-information-exchange, fintech, fix, fix-protocol, fix44, market-data, parser, trading, validator

## 简介

Dictionary-driven FIX protocol toolkit: parse, validate, and encode FIX messages. Zero runtime dependencies; runs in the browser and Node.
