# @adigitalcafe/adc-drive-agent

> 标签: adc-drive, cli, file-transfer, s3, tunnel, webdav

## 简介

Agente CLI del túnel de ADC Drive: monta carpetas locales y unidades S3/WebDAV para verlas desde tus otros dispositivos, y autodescarga carpetas de transferencia. Sin dependencias.
