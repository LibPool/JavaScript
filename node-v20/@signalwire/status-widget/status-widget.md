# @signalwire/status-widget

> 标签: pagerduty, signalwire, status, statuspage, uptime, widget

## 简介

Embeddable platform status widget. Renders SignalWire's PagerDuty status feed as a full dashboard or a compact footer indicator, with no dependencies and no runtime backend.
