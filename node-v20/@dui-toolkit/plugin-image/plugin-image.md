# @dui-toolkit/plugin-image

> 标签: ansi, block-art, cli, gif, image, image-rendering, sixel, terminal

## 简介

Terminal image renderer for @bdocs/dui — renderiza imágenes PNG, JPG y GIF en la terminal usando ANSI half-blocks, Sixel y soporte para animaciones.
