# @multiplatform.one/vite-plugin-webext

> 标签: browser-extension, multiplatform.one, vite-plugin, webext, webextension

## 简介

Vite config factories for building a browser web extension (MV3 views, background service worker, content scripts) as a target of a multiplatform.one One app — workspace source aliases, the one-server-only browser stub, Tamagui wiring, and the manifest/de
