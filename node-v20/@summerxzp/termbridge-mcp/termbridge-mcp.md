# @summerxzp/termbridge-mcp

> 标签: mcp, ssh, termbridge, terminal

## 简介

TermBridge — Remote Terminal Runtime for AI Agents (MCP)。薄主包：解析当前平台的 @summerxzp/termbridge-<os>-<arch> 平台包并启动二进制，更新/安装全走 npm registry。
