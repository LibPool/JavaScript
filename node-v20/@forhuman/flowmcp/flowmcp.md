# @forhuman/flowmcp

> 标签: agency, claude-code, claude-desktop, cli, cursor, keychain, mcp, model-context-protocol, skill, webflow

## 简介

Manage multiple Webflow MCP server connections (one per client/org) without ever letting an API token pass through agent context.
