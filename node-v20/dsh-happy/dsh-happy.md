# dsh-happy

> 标签: animation, background, conversation, deepseek-harness, dsh, dsh-plugin

## 简介

Full-canvas animated backgrounds for the DSH conversation pane: ten scenes including starfield, code rain, circuit, sword, cat, girl, fighter jet, racer, snow and bubbles.
