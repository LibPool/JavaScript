# @execuro-sw-ecosystem/sw-specs-editor

> 标签: agent, cli, prd, review, shopware, specification

## 简介

Specs Editor - local zero-dependency editor that renders a PRD / tech spec as a live page and relays the user's notes back to a coding agent
