# @thorprovider/runtime

> 标签: json-render, multitenant, nextjs, react, runtime, storefront, tailwindcss, thor-commerce, zod

## 简介

Multitenant storefront runtime for Thor Commerce. Layered: host-glue (Next host), render-core (spec-driven render via json-render), contracts (Zod contracts + pure resolution).
