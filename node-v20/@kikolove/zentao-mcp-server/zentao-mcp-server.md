# @kikolove/zentao-mcp-server

> 标签: bug, chanzhi, mcp, model-context-protocol, testcase, zentao, 禅道

## 简介

禅道（ZenTao）REST API v1 的 MCP Server：stdio 传输，27 个工具覆盖 Bug 全生命周期（创建/批量/指派/确认/评论/贴图/附件与截图下载/关联/解决/激活/关闭/删除）、模块与用例查询过滤、用例创建、测试单、版本等，零运行时依赖；支持用户级共享配置与七家客户端 install 一键接入
