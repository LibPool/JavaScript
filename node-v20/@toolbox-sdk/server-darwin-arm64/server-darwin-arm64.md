# @toolbox-sdk/server-darwin-arm64

> 标签: JavaScript

## 简介

Platform-specific binary for the `toolbox` package on Darwin arm64. This package is automatically installed by the main `@toolbox-sdk/server` package and is not intended to be installed directly.
