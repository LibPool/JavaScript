# @ekanos/cli

> 标签: cli, ekanos, fusion, integration

## 简介

The Ekanos partner toolchain CLI: scaffold, validate, and test an Ekanos integration against the published @ekanos packages. Agent-native — every verb speaks JSON with a stable exit-code taxonomy.
