# @kebab-case/lcp

> 标签: cors, express, node, proxy, simple

## 简介

Fork of Gary Meehan local-cors-proxy. Simple proxy to bypass CORS issues. This was built as a local dev only solution to enable prototyping against existing APIs without having to worry about CORS.
