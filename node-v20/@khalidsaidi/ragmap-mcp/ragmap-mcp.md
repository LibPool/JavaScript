# @khalidsaidi/ragmap-mcp

> 标签: agent-tools, agents, claude, claude-desktop, cursor, discovery, json-rpc, mcp, mcp-registry, mcp-server, model-context-protocol, rag, registry, retrieval, search, semantic-search, stdio, subregistry

## 简介

Find and filter RAG-capable MCP servers by meaning or keywords. Local stdio MCP bridge to the RAGMap subregistry (semantic search, filters, explainable scores).
