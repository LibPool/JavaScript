# @paralock/sdk

> 标签: adaptor-signatures, atomic-swap, cross-chain, evm, htlc, market-maker, payments, stablecoin, tempo, zcash

## 简介

Maker and taker engines for trustless atomic swaps and payments between Zcash and stablecoins on EVM chains: factories, crash-safe persistence and recovery, quote validation, maker risk limits, and an HTTP transport.
