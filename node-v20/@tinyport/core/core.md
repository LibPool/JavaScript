# @tinyport/core

> 标签: bundle size, esbuild, import cost, imports, javascript, static analysis, tree shaking, typescript, unused imports

## 简介

The portable import-analysis engine behind TinyPort: parse imports, measure real bundle cost, detect unused/duplicate imports, and plan safe rewrites.
