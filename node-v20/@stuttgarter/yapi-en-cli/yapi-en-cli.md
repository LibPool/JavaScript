# @stuttgarter/yapi-en-cli

> 标签: JavaScript

## 简介

cli tool english version to deploy yapi-en server ## environment need * nodejs（7.6+) * mongodb（2.6+） ## install run yapi-en server to deploy yapi-en server. after deployment run node/{path/server/app.js} to start the serve. default password is ymfe.org fo
