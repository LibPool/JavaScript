# @funnelchat-hq/n8n-nodes-funnelchat

> 标签: crm, funnelchat, n8n, n8n-community-node-package, whatsapp

## 简介

n8n community node for the Funnelchat public API: actions on contacts, conversations and messages, templates, WhatsApp forms, groups, numbers and webhooks, and a trigger for signed webhooks.
