# @vocantly/call-ui

> 标签: react, telemedicine, video-call, vocantly, voice-call, webrtc

## 简介

Drop-in, themeable, symmetric 1:1 voice/video call UI for @vocantly/sdk. Both participants render the same component; role-neutral (doctor↔patient, agent↔customer).
