# @blaze-cache/core

> 标签: browser, cache, caching, eviction, indexeddb, persistence, sieve, tags, ttl, wasm, webassembly

## 简介

WebAssembly client-side cache for the browser: SIEVE eviction, per-entry TTLs, tag invalidation and optional IndexedDB persistence
