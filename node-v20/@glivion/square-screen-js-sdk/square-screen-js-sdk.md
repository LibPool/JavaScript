# @glivion/square-screen-js-sdk

> 标签: JavaScript

## 简介

A framework-agnostic JavaScript/TypeScript SDK for building SquareScreen digital signage players. It handles playlist fetching, local media caching, item advancement, background preloading, polling, heartbeats, and emergency alerts — all without touching
