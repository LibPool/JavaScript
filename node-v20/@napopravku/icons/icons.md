## 简介

Данный репозиторий содержит иконки дизайн системы. Иконки выгружаются напрямую из Figma проекта Napopravku и могут быть использованы для построения интерфейсов и UI kit Посмотреть доступные иконки можно на странице [ICONS](https://napopravku.github.io/ico
