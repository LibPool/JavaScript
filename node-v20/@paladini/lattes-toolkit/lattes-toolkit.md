# @paladini/lattes-toolkit

> 标签: brasil, cnpq, curriculo, curriculum, extrator, lattes, lattes-toolkit, parser, pesquisa, typescript, xml

## 简介

Toolkit to edit exported Currículo Lattes XML programmatically, via CLI or automated AI agents. Independent project for the platform XML format. Not affiliated with CNPq.
