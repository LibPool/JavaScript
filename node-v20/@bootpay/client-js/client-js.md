# @bootpay/client-js

> 标签: JavaScript

## 简介

* extra theme_color, theme_font_color 추가 ( 카드정기결제, 통합결제창 메인 테마 배경색 및 폰트색 지정 가능 ) * 안드로이드 iFrame으로 카드등록창 호출시 스크롤 변경으로 인한 input focus 안되는 버그 수정
