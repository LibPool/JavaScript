# dsh-wos-pipeline

> 标签: bibliography, deepseek-harness, dsh, dsh-plugin, knowledge-base, literature-review, pdf, research, systematic-review, web-of-science, wos

## 简介

Web of Science 文献流水线插件：检索式迭代历史与数量闸门（未过闸门强制用户确认检索词）、PDF 收编与 %PDF- 审计、解析编排（复用 dsh-pdf-mineru）、知识库骨架与五层 lint/index（llm-wiki 机械能力）。
