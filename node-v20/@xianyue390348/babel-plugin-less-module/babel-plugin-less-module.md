# @xianyue390348/babel-plugin-less-module

> 标签: babel, cssModule, less

## 简介

一个 `Babel` 插件，用来帮助你对文件中引用的 `less` 进行预处理、转换成 `css` 并自动管理, 支持 `cssModule`, `autoPrefix`
