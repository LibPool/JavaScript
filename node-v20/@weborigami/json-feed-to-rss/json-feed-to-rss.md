# @weborigami/json-feed-to-rss

> 标签: JavaScript

## 简介

This package exports a single function, `jsonFeedToRss`, which accepts a JavaScript function in [JSON Feed](https://www.jsonfeed.org/) format and returns the corresponding RSS XML.
