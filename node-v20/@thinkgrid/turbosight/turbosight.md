# @thinkgrid/turbosight

> 标签: app-router, boundary, devtools, flight-stream, lcp, lighthouse, nextjs, overlay, performance, react, rsc, server-components, tbt

## 简介

Visual RSC boundary inspector for Next.js App Router. See exactly how much data crosses your server→client boundary in real time. Find LCP killers before Lighthouse does.
