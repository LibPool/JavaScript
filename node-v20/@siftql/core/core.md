# @siftql/core

> 标签: ast, date, datetime, elasticsearch, filter, in-memory-search, lql, lucene, parser, query, query-language, search, typescript

## 简介

A complete, extensible Lucene-like query language: hand-written parser, serializer, and in-memory search engine with real chronological date/time support. Zero dependencies.
