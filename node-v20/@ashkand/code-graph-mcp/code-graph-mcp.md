# @ashkand/code-graph-mcp

> 标签: claude-code, code-intelligence, cursor, knowledge-graph, mcp, model-context-protocol, monorepo, token-optimization

## 简介

Local code-intelligence MCP server: index a mono-repo into a knowledge graph (routes, components, API calls, backend handlers) and answer structural questions in a fraction of the tokens.
