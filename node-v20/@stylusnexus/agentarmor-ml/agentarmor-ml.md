# @stylusnexus/agentarmor-ml

> 标签: agent-armor, agent-safety, ai-security, ml-classifier, onnx

## 简介

ML classifier add-on for Agent Armor. Downloads and runs a DeBERTa-v3-small ONNX model for agent trap detection.
