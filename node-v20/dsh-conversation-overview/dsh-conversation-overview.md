# dsh-conversation-overview

> 标签: conversation, cordis, deepseek-harness, dsh, dsh-bundle, dsh-plugin, overview, session-summary

## 简介

DeepSeek Harness (DSH) plugin: an Overview tab beside Chat/Trajectory plus a right-sidebar page summarizing session progress (goal, todos, key steps), artifacts, and references, with per-turn scoping, OpenViking memory preview, and quick-nav linkage.
