# @gotocva/react-markdown

> 标签: gfm, github-flavored-markdown, highlight.js, library, lowlight, markdown, markdown-editor, notion, notion-style, prosemirror, react, react-markdown, rich-text-editor, slash-command, syntax-highlighting, tables, tiptap, typescript, vite, wysiwyg

## 简介

React + Vite library: render Markdown into styled HTML and edit it with a Notion-style block editor (slash menu, bubble menu, syntax-highlighted code blocks, resizable tables with auto S.No, GFM round-trip).
