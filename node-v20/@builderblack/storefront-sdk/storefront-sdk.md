# @builderblack/storefront-sdk

> 标签: builderblack, ecommerce, headless, sdk, shopify-alternative, storefront, typescript

## 简介

Typed TypeScript client for building headless storefronts (Next.js, Remix, Astro, native apps) against the BuilderBlack platform.
