# @feng3d/glslup

> 标签: glsl, upgrade

## 简介

一个GLSL升级工具，可以将 GLSL100/GLSL300 到 GLSL450 版本。

## 官网

- 源码仓库：https://gitee.com/feng3d/glslup.git
- npm 页面：https://www.npmjs.com/package/@feng3d/glslup
