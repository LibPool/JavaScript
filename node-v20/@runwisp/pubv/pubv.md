# @runwisp/pubv

> 标签: automation, bump-version, changelog, changelog-generator, cli, devops, git, git-tag, keep-a-changelog, publish, release, release-automation, release-cli, release-management, release-tool, semantic-versioning, semver, tag, version, version-bump

## 简介

Automate releases from your Keep a Changelog CHANGELOG.md: bump the version, update the changelog, then commit, tag, and push in one command. A tiny, zero-config release CLI for GitHub, GitLab, and Bitbucket.
