# n8n-nodes-colis

> 标签: colis, file-transfer, freelance, n8n, n8n-community-node-package, webhook

## 简介

n8n nodes for a colis drop: start a workflow when a parcel is sent, opened, approved, sent back or deleted, and send, read or burn parcels.
