> 标签: action-authorization, ai-agents, arc-testnet, base-chain, circle-agent-wallet, circle-gateway, coinbase-kyc, eip-712, erc-8004, ethers, experimental-arc, gateway-nanopayments, google-oidc, identity, noir-lang, privacy, sdk, typescript, x402, zero-knowledge-proofs, zk-proofs, zkp

## 简介

TypeScript SDK for ZKProofport Coinbase KYC, country, OIDC, Arc eligibility and GIWA attestation proofs. Optional EIP-712 action binding for Arc/GIWA; x402 USDC and Circle Gateway payments.
