# dsh-workspace-handoff

> 标签: context, drift, dsh, handoff, manifest, migrate, plugin, session, sha256, workspace

## 简介

Workspace session handoff toolkit for DeepSeek Harness: pack the current working state (goal, decisions, open tasks, notes plus a glob-expanded context file manifest with sha256 fingerprints) into a portable handoff bundle, migrate it to another workspace
