# @fluentui-emoji/web-components

> 标签: custom-elements, emoji, fluentui, fluentui-emoji, icons, svg, web-components

## 简介

Fluent UI Emoji as a framework-less <fluent-emoji> custom element with tree-shakeable icon data (flat, high-contrast, modern).
