# @fluentui-emoji/alpine

> 标签: alpine, alpinejs, emoji, fluentui, fluentui-emoji, icons, svg

## 简介

Fluent UI Emoji as an Alpine.js plugin — x-fluent-emoji directive and $fluentEmoji magic with tree-shakeable icon data (flat, high-contrast, modern).
