# @fluentui-emoji/sprite

> 标签: emoji, fluentui, fluentui-emoji, icons, sprite, svg, symbol

## 简介

Fluent UI Emoji as SVG symbol sprites — one <use href> sheet per set, ideal for pages showing many emojis.
