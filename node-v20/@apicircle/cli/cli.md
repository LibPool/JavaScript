# @apicircle/cli

> 标签: api, api-circle, api-client, apicircle, cli, command-line, headless, http, http-client, import, insomnia, mcp, mcp-server, mock-server, openapi, postman, swagger, workspace

## 简介

Command-line interface for API Circle Studio. Run mock servers, drive the MCP server, and import OpenAPI / Postman / Insomnia collections from any terminal.
