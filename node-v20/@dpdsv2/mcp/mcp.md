# @dpdsv2/mcp

> 标签: claude, design-system, dpdsv2, mcp, model-context-protocol

## 简介

Model Context Protocol server for the DPDSv2 Design System. Lets Claude (or any MCP client) browse components, install them into a project, and keep them up to date.
