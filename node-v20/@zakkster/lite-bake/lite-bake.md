# @zakkster/lite-bake

> 标签: array-of-structs, binary, cache-locality, data-oriented, dod, flat, game, gamedev, json, performance, struct-of-arrays, tilemap, typed-array, webgl, zero-allocation, zero-gc

## 简介

Compile JSON arrays into flat interleaved binary for zero-GC, L1-cache-friendly reads. Stop parsing JSON in your game loop.
