# @zakkster/lite-di-event-bus

> 标签: dependency injection, di, emitter, event bus, multi binding, typescript, zero allocation, zero-gc

## 简介

DI-constructed static event handlers under a boot-locked multi topology, dispatched by index over a shared buffer. Zero allocation on the synchronous emit path.
