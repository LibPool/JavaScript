# @zakkster/lite-worker

> 标签: 60fps, atomics, backpressure, blob-worker, cross-origin-isolated, double-buffer, esm, frame-channel, inline-worker, latest-wins, lite, offscreen, offscreencanvas, rpc, seqlock, sharedarraybuffer, single-file, transferable, transfercontroltooffscreen, web-worker, worker, zero-gc

## 简介

Zero-GC per-frame worker channel. Define a worker inline from a function, message it with transferables, keep the main thread clean at 60fps. Zero dependencies, single file.
