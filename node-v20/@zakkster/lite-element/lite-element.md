> 标签: attributes, custom-elements, declarative-shadow-dom, drag-and-drop, element-internals, fine-grained, form-associated, framework-free, html-element, hydration, island, lifecycle, lite-signal, low-latency, mount, no-vdom, no-virtual-dom, portal, reactive, reparent, shadow-dom, signal, signals, small-bundle, sortable, ssr, tree-shakeable, web-components, zakkster, zero-allocation, zero-gc

## 简介

Zero-GC reactive Custom Elements on @zakkster/lite-signal. No virtual DOM, no templating. State survives synchronous reparents (sort, drag-and-drop, insertBefore) -- the moves that destroy React/Vue/Lit. 1.1 adds reactive observed attributes, typed proper
