# @zakkster/lite-command

> 标签: command-pattern, history, lite, no-allocation, performance, redo, ring-buffer, soa, structure-of-arrays, undo, zero-gc

## 简介

Zero-GC, SoA-backed Command Pattern for continuous UI mutations. Ring-buffered undo/redo with payload merging for slider/drag streams.
