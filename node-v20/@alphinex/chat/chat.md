# @alphinex/chat

> 标签: JavaScript

## 简介

Chat shell UI (message list, composer, presence) against a pluggable ChatTransport — the real-time transport itself is deferred, see ADR-0015. See documentation/PRODUCT-RESEARCH-MASTER-PLAN.md §10.1 (Sprint 25).
