# @simnode/redis-mock

> 标签: JavaScript

## 简介

Redis RESP protocol mock for SimNode. Supports 16 commands: GET, SET, DEL, EXPIRE, TTL, INCR, DECR, LPUSH, RPUSH, LPOP, RPOP, HSET, HGET, SMEMBERS, SADD, ZADD, ZRANGE. TTL integrates with virtual clock. Throws `SimNodeUnsupportedRedisCommand` for unsuppor
