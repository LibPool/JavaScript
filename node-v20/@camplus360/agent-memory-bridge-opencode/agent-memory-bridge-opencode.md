> 标签: agent-memory-bridge, ai-agent, claude-mem, coding-agent, cross-engine, cross-session, memory, memory-bridge, memory-recall, opencode, opencode-plugin, persistent-memory

## 简介

OpenCode plugin: captures conversation observations to the local claude-mem worker, giving OpenCode cross-session shared memory. Summarization/embedding/search stay in claude-mem.
