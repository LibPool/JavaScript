# @theaiinc/realm-sandbox

> 标签: ai-agent, docker, docker-agentic-platform, realm, sandbox, sbx

## 简介

Docker Sandbox engine for Realm — runs a realm in a Docker Agentic Platform sandbox (cloud or local) through the sbx CLI: kits, network policy and credential injection come from Docker
