# @theaiinc/yggdrasiladmin-panel

> 标签: admin, grafana, orchestration, panel, plugin, ratatoskr, yggdrasil

## 简介

Grafana panel plugin for managing Yggdrasil runners — update, restart, rotate keys, and monitor agent fleet health directly from Grafana.
