# @qontinui/ui-bridge-cli-args

> 标签: argument-parsing, argv, cli, ui-bridge

## 简介

Shared CLI argument primitives for the UI Bridge package bins — the single home for the flag-shaped-value swallow guard, unknown-flag rejection, and the shared --quiet/--help kit.
