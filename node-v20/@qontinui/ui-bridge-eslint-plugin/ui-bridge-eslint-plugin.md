# @qontinui/ui-bridge-eslint-plugin

> 标签: effect, eslint, eslint-plugin, ir, lint, state-machine, ui-bridge

## 简介

ESLint plugin for the UI Bridge IR — requires an `effect` safety class on every registered component action, and flags conditional rendering at configuration boundaries that the IR builder cannot statically pick up.
