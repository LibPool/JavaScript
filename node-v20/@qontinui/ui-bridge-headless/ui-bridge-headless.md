# @qontinui/ui-bridge-headless

> 标签: automation, chromium, headless, playwright, testing, ui-bridge

## 简介

Playwright-backed headless browser launcher for UI Bridge — spin up a real Chromium tab so web apps can be driven through UI Bridge without a visible browser open.
