# @digisquares/datasquares-embed-react

> 标签: dashboard, datasquares, embed, embedded-analytics, react

## 简介

React SDK for embedding DataSquares dashboards and reports: the <DataSquaresEmbed> component, typed events, host-side controls (params, pages, refresh), and a server-side token helper.
