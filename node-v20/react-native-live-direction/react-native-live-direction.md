# react-native-live-direction

> 标签: arabic, expo, i18n, i18nmanager, layout-direction, ltr, react-native, rtl

## 简介

Switch the native layout direction (RTL/LTR) at runtime — Yoga, native headers, modals and I18nManager — without restarting the app.
