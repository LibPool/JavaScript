# @ag-eco/agentplate

> 标签: agents, ai, ci-cd, cli, deploy, developer-tools, multi-agent, orchestration, self-improving, swarm

## 简介

Self-improving multi-agent orchestration that takes you from build → CI/CD → deploy. Interactive setup wizard, pluggable AI providers, agent swarms in git worktrees.
