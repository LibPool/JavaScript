# @hett/pi-x

> 标签: ai-agent, pi, pi-coding-agent, pi-extension, pi-package, scraper, social-listening, trending, twitter, x

## 简介

X (Twitter) for Pi agents — trending topics & news with 'why it's trending' drill-down, search, threads, profiles. No API keys: uses your logged-in browser session.
