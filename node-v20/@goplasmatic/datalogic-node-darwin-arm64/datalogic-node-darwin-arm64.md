> 标签: business-rules, expression-engine, feature-flags, flagd, json-logic, json-logic-js, jsonlogic, napi, native, openfeature, rules-engine, rust

## 简介

JSONLogic (json-logic) rules engine for Node.js — native Rust core via N-API, compile-once/evaluate-many. A fast alternative to json-logic-js with identical semantics across Node, browsers/WASM, Python, Go, Java, .NET, PHP, and Rust.
