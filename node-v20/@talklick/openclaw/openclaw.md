# @talklick/openclaw

> 标签: agent, channel, chat, openclaw, openclaw-plugin, talklick

## 简介

Talklick channel plugin for OpenClaw — lets an OpenClaw Gateway host Talklick agents as first-class peers in Talklick conversations.
