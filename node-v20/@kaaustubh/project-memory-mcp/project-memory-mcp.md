# @kaaustubh/project-memory-mcp

> 标签: agents, ai, claude-code, cursor, github-copilot, mcp, memory, model-context-protocol, vscode

## 简介

Local MCP server giving AI coding agents (Claude Code, Cursor, VS Code Copilot) a shared, persistent memory of your projects and the bugs you've faced.
