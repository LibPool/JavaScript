# @dpharness/dsh-deepseek-web

> 标签: cordis, deepseek, deepseek-harness, dsh, plugin, sidebar, webview

## 简介

网页版 AI 一键入口：点击侧边栏按钮弹出站点选择弹窗（六站图标网格），选中即在右侧边栏浏览器 tab 里打开 DeepSeek / Kimi / 豆包 / 腾讯元宝 / 通义千问 / 智谱清言的免费网页版（走 Electron webview，不受 CSP frame-ancestors 限制）。站点列表在 lib/client.js 的 SITES 常量里，可自由增删。
