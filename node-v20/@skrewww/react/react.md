# @skrewww/react

> 标签: design-system, react, skrewww, typescript

## 简介

Framework-agnostic Skrewww React components (Button, Link, Card, Text Input, Form Field, Validation Message, Spinner, Dialog) with one stylesheet and an optional router provider. Beta preparation.
