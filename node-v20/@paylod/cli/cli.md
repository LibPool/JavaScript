# @paylod/cli

> 标签: cli, daraja, kenya, m-pesa, mpesa, paylod, payments, safaricom, stk-push

## 简介

The paylod CLI — accept M-Pesa (Safaricom Daraja) payments from your terminal. STK push, live status, webhook forwarding, and offline Daraja error decoding.
