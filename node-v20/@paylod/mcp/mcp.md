# @paylod/mcp

> 标签: ai-agents, claude, cursor, daraja, kenya, m-pesa, mcp, model-context-protocol, mpesa, paylod, payments, stk-push

## 简介

OAuth-authenticated remote Model Context Protocol (MCP) server for paylod — let AI agents transact M-Pesa (STK push, payments, payouts, webhooks, error decoding) through the paylod BaaS over Streamable HTTP.
