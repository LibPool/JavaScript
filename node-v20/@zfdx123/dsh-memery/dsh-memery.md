# @zfdx123/dsh-memery

> 标签: JavaScript

## 简介

自包含跨会话记忆插件：node:sqlite 工作区记忆库 + 首轮注入/每轮关键词命中 + memory_* 工具 + 设置页记忆浏览器。无外部服务依赖。
