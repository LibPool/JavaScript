# @loomidev/lightbox

> 标签: image, lightbox, lit, loomiui, web-components

## 简介

<loomi-lightbox-image> — click an image to view it fullscreen. Wraps a single existing image with no shared container; give matching `group` values to enable Next/Prev between scattered images.
