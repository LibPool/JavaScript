# @media-info/csfd-api

> 标签: api, concerts, csfd, movies, tvshows, typescript, čsfd

## 简介

A simple UMD package to fetch data about movies and shows recursively from ČSFD for both the browser and Node.js.

- 源码仓库：https://gitlab.com/media-info/csfd-api
