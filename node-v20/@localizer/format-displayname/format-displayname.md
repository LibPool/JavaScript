# @localizer/format-displayname

> 标签: country names, currency names, display name formatting, formatting, globalization, i18n, internationalization, l10n, language names, localization, localizer

## 简介

Type-safe localization, formatting and translation library. Provides utilities for formatting country, language and currency names in a locale-aware manner.
