# @cresva/acp

> 标签: acp, agent-commerce-protocol, ai-agents, cresva, ecommerce, storefront, typescript

## 简介

Official TypeScript client for the Cresva Agent Commerce Protocol (ACP) storefront API: products, search, pricing, negotiation and trust. Renamed from @cresva/sdk.
