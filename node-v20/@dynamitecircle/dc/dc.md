# @dynamitecircle/dc

> 标签: api-client, community, dc, dcbkk, dcmex, dynamite-circle, events, founders, membership

## 简介

Official TypeScript SDK for the Dynamite Circle Member API: profiles, trips, events, tickets, rooms, chapters, search, and locator data for DC members.
