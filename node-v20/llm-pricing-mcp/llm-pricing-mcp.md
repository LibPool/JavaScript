# llm-pricing-mcp

> 标签: anthropic, claude, claude-desktop, cost, cursor, llm, mcp, model-context-protocol, pricing

## 简介

STDIO MCP server for LLM Pricing — real-time, drift-verified pricing, cost+quality model routing, and usage tracking across 26 providers. Zero local dependencies; proxies to a hosted backend.
