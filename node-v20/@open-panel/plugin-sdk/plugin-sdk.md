# @open-panel/plugin-sdk

> 标签: macropad, openpanel, plugin, sdk, stream-deck

## 简介

The OpenPanel plugin SDK: the plugin.json manifest schema, a plugin registry with per-contribution isolation and live reload, the capability surface (log/shell/http/storage/notify/device), and the adapter that turns plugin actions into ActionDefinitions.
