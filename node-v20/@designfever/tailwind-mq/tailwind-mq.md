# @designfever/tailwind-mq

> 标签: css, design-system, fluid-ui, frontend, responsive-design, tailwind-plugin, tailwindcss, vw

## 简介

Tailwind CSS plugin that converts design px values into breakpoint-aware vw utilities while preserving fixed desktop pixel targets.
