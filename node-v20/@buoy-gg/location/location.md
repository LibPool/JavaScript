# @buoy-gg/location

> 标签: debugging, devtools, expo, expo-location, geofence, geolocation, gps, location, mock-location, react-native, react-native-devtools

## 简介

Location override for React Native: pin the app to any place, play routes with speed and heading, trigger geofences and test signal loss. Works with expo-location, @react-native-community/geolocation and react-native-geolocation-service.
