# @ebrains/components

> 标签: JavaScript

## 简介

`@ebrains/components` is the EBRAINS Design System’s library of framework-agnostic Web Components, built with [Stencil](https://stenciljs.com/). It provides a consistent set of elements that can be used across all EBRAINS applications (and beyond).
