# @nandan-varma/git-fs-s3

> 标签: cloudflare-r2, filesystem, fs, git, git-server, isomorphic-git, object-storage, r2, s3, serverless

## 简介

isomorphic-git filesystem backend for S3-compatible object storage (AWS S3, Cloudflare R2, MinIO) — run git servers without a disk
