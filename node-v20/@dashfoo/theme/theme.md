# @dashfoo/theme

> 标签: JavaScript

## 简介

Opt-in default skin for the @dashfoo/react headless chrome. Tailwind v4 entry with dashfoo utilities, or prebuilt plain CSS, both over overridable --dashfoo-* design tokens.
