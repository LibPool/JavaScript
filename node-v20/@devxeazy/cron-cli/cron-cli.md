# @devxeazy/cron-cli

> 标签: agents, cli, cron, crontab, inventory, preflight, run-parts, scheduler, sysadmin, systemd, timers

## 简介

One table for everything scheduled on a Linux box: user crontab, /etc/crontab, /etc/cron.d, run-parts and systemd timers — plus a preflight that says why a job will fail before it fires.
