# @lspain1994/x402-datasets-mcp

> 标签: fda, government-data, hcad, irs, mcp, modelcontextprotocol, ssa, x402

## 简介

MCP server for the x402 government-data APIs (IRS Internal Revenue Bulletin, IRS Internal Revenue Manual, FDA IOM, SSA POMS, HCAD property tax). Free routes only; full records are paid over x402.
