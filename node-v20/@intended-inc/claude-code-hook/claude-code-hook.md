# @intended-inc/claude-code-hook

> 标签: JavaScript

## 简介

Claude Code PreToolUse hook — govern every tool call through Intended's authority layer. Fail-open when unconfigured, fail-closed on DENY / unreachable / non-2xx. npx-invokable from .claude/settings.json.
