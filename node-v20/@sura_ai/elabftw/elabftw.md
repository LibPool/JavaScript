# @sura_ai/elabftw

> 标签: ai, anthropic, claude, elabftw, electronic-lab-notebook, eln, laboratory, mcp, model-context-protocol, research, science

## 简介

Model Context Protocol toolkit for elabftw (electronic lab notebook). Stdio MCP server + programmatic eLabFTW v2 client. Search, read, and write experiments, items, attachments, comments, steps, and links from any MCP-aware AI client.
