# @sura_ai/elabftw-hosted

> 标签: elabftw, eln, hosted-mcp, mcp, model-context-protocol, self-hosted

## 简介

Hosted-mode HTTP server for the elabftw MCP toolkit. Self-service registration, per-token isolation, JSON or SQLite token store. Wraps @sura_ai/elabftw for remote MCP clients.
