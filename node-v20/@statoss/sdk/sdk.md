# @statoss/sdk

> 标签: error-tracking, errors, logs, monitoring, sentry, statoss

## 简介

Error tracking and logs for StatOSS: browsers, Node, Bun, Deno, Cloudflare Workers and Vercel Edge. Speaks Sentry's protocol.
