# @symbiote-native/device

> 标签: angular, device-info, expo-device, react, react-native, root-detection, solid, svelte, symbiote-native, vue

## 简介

expo-device wrapped for SymbioteNative — one framework-agnostic core, built once and reachable from the React, Vue, Svelte, Solid, and Angular adapters. Device brand/model/OS constants, uptime, max-memory, root/jailbreak detection, side-loading detection,
