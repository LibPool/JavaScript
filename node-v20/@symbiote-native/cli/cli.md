# @symbiote-native/cli

> 标签: android, angular, cli, create-app, cross-platform, ios, react, react-native, scaffold, solid, starter, svelte, symbiote-native, vue

## 简介

Create a native iOS/Android app in Vue, Svelte, Solid, Angular or React, on React Native's own Fabric renderer. Scaffolds a new app, or wires SymbioteNative into an existing bare React Native one.
