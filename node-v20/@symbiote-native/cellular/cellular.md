# @symbiote-native/cellular

> 标签: angular, carrier-info, cellular-generation, expo-cellular, react, react-native, solid, svelte, symbiote-native, vue

## 简介

expo-cellular wrapped for SymbioteNative — one framework-agnostic core, built once and reachable from the React, Vue, Svelte, Solid, and Angular adapters. Cellular generation (2G/3G/4G/5G), carrier/SIM info on Android (ISO country code, carrier name, MCC/
