# @symbiote-native/calendar

> 标签: angular, calendar, events, expo-calendar, react, react-native, reminders, solid, svelte, symbiote-native, vue

## 简介

expo-calendar wrapped for SymbioteNative — one framework-agnostic core, built once and reachable from the React, Vue, Svelte, Solid, and Angular adapters. Both surfaces: the modern ExpoCalendar/ExpoCalendarEvent/ExpoCalendarReminder/ExpoCalendarAttendee A
