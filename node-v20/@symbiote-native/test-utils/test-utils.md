# @symbiote-native/test-utils

> 标签: fabric, mock, react-native, symbiote-native, test-harness, test-utils, testing, vitest

## 简介

Shared, framework-agnostic fake-Fabric test harness for SymbioteNative — the fake nativeFabricUIManager recorder used by the co-located test suites across the engine, every adapter, and the example apps.
