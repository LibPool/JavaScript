# @symbiote-native/application

> 标签: android-id, angular, app-version, expo-application, react, react-native, solid, svelte, symbiote-native, vue

## 简介

expo-application wrapped for SymbioteNative — one framework-agnostic core, built once and reachable from the React, Vue, Svelte, Solid, and Angular adapters. Native app version/build/name/ID constants, the Android ID, install-referrer and install/update-t
