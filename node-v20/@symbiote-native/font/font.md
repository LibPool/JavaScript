# @symbiote-native/font

> 标签: angular, expo-font, font, react, react-native, solid, svelte, symbiote-native, typography, vue

## 简介

expo-font wrapped for SymbioteNative — one framework-agnostic core, built once and reachable from the React, Vue, Svelte, Solid, and Angular adapters. Runtime font loading/unloading by fontFamily, plus a text-to-image render utility.
