# @symbiote-native/image-manipulator

> 标签: angular, crop, expo-image-manipulator, image, react, react-native, resize, solid, svelte, symbiote-native, vue

## 简介

expo-image-manipulator wrapped for SymbioteNative — one framework-agnostic core, built once and reachable from the React, Vue, Svelte, Solid, and Angular adapters. Resizes, rotates, flips and crops images, rendering to a new file.
