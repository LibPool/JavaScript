# @symbiote-native/slider

> 标签: angular, range-slider, react, react-native, solid, svelte, symbiote-native, vue

## 简介

Third-party native Slider view wrapped for SymbioteNative — one framework-agnostic core, built once and reachable from the React, Vue, Angular, Svelte, and Solid adapters.
