# @kaimaai/vue-core

> 标签: JavaScript

## 简介

开码（kaima）体系下的 **前端壳工程**：在 Vue 3 + TypeScript + Vite 之上提供管理端基础能力（路由、模块扫描、布局、通用业务模块等），可作为**完整应用仓库**开发，也可作为 **npm 包**被薄业务工程依赖。
