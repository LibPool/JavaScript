# usesnout

> 标签: ai, claude-code, codex, coding-agent, context, context-engineering, cursor, gemini-cli, llm, mcp, token-optimization, tokens

## 简介

Context gating and token optimization for AI coding agents: trims bulky files, logs, docs, command and MCP output before they enter context, and reports what it saved.
