# @bcourbage/homebridge-ambient-weather-sensors

> 标签: air-quality, ambient-weather, awn, co2, homebridge-plugin, homekit, pm2.5, weather-station, websocket

## 简介

Independently maintained Homebridge plugin for Ambient Weather sensors via the AWN REST/websocket API, with Homebridge 2.x support, multi-station support, realtime updates, and CO2/PM coverage.
