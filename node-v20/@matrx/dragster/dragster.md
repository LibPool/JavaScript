# @matrx/dragster

> 标签: drag, drag-and-drop, dragenter, dragleave, drop, svelte, svelte3

## 简介

Port of Ben Smithett's dragster to ES6. Wraps native dragenter/dragleave to behave like mouse event when hovering over child DOM elements.
