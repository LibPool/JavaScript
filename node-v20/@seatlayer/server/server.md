> 标签: box-office, event-ticketing, inventory-management, nodejs, reserved-seating, season-tickets, seat-booking, seat-map, seating-chart, seatlayer, server-sdk, ticketing, typescript

## 简介

Official Node.js server SDK for SeatLayer inventory, Seasons, holds, booking references, allocations, and reports. Secret-key only.
