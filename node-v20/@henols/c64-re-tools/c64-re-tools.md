# @henols/c64-re-tools

> 标签: 6502, 6510, acme, c64, claude, commodore-64, installer, mcp, reverse-engineering, vice

## 简介

Installer that adds the C64 reverse-engineering skills and the VICE emulator MCP server (@henols/vice-mcp) to a project.
