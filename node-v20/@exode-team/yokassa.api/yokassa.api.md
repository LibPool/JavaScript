# @exode-team/yokassa.api

> 标签: JavaScript

## 简介

Этот модуль предоставляет интерфейс для интеграции с YooKassa, позволяя выполнять различные операции, такие как создание платежей, возвратов и управление ими. Написан на TypeScript.
