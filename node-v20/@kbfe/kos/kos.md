# @kbfe/kos

> 标签: JavaScript

## 简介

一款基于react-redux的数据流管理框架，简单轻量，目标是在多端体系下均能使用，与单页和多页方案无关，KOS配合脚手架生成的应用模板，来提供单页多页应用的使用场景
