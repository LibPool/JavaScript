# @firstrun/analytics

> 标签: analytics, cookieless, error-tracking, firstrun, opentelemetry, privacy, telemetry, web-vitals

## 简介

Analytics and error reporting for firstrun. One structured log for page views, Core Web Vitals, events and exceptions, with each measurement individually importable.
