> 标签: context, daily-log, memory, pi, pi-coding-agent, pi-extension, pi-package, scratchpad

## 简介

Pi coding agent extension for a file-based, no-embeddings long-term memory system — indexed long-term memory files, recall selection, daily logs, scratchpad checklist, and background consolidation
