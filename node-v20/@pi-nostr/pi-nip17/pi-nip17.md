# @pi-nostr/pi-nip17

> 标签: direct-messages, nip-17, nostr, pi, pi-package

## 简介

Nostr direct messages (NIP-17) for pi: the agent sends, lists and reads encrypted conversations as its own nostr identity, with nsec, generated or NIP-46 signer login
