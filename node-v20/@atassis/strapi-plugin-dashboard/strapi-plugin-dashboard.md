# @atassis/strapi-plugin-dashboard

> 标签: area, bar, chart, dashboard, line, plugin, strapi

## 简介

Plugin for Strapi that enables the visualization of customizable dashboards with multiple chart types, including Bar, Line, and Area, directly within the Strapi admin panel.
