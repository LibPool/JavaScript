# dsh-railist

> 标签: deepseek-harness, dsh, panellist, plugin, rail, sidebar, ui

## 简介

Whole-left-column manager for DeepSeek Harness: one sequence across the panel list, the footer action row and the Settings seat — reorder, drag across seats, rename, re-icon, show/hide and collect rows into flyout groups. Configuration lives in a new Sett
