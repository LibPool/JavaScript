# @lzwme/prerender-kit

> 标签: prerender, prerender-kit, puppeteer, rollup-plugin, seo, sitemap, spa, ssg, ssg-prerender, static-site-generator, vite-plugin, webpack-plugin, 静态化, 预渲染

## 简介

通用预渲染(SSG)工具包。基于无头浏览器将 SPA 路由渲染为静态 HTML，内置增量预渲染能力，支持 vite / webpack / rollup 插件及 CLI 独立使用。
