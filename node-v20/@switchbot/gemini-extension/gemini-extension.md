# @switchbot/gemini-extension

> 标签: gemini, gemini-cli, iot, mcp, smart-home, switchbot

## 简介

SwitchBot Gemini CLI extension — wires Gemini CLI to the SwitchBot MCP server (default 17 tools; `--tools all` for 28) via the native Extension system
