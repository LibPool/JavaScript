# @aiagentzoo/sdk

> 标签: agents, ai, autonomous-agents, claude, federation, multi-agent, solana

## 简介

SDK for ZOOAI AGENCY: define species and agents, run enclosures with budgets, signed signals and a hash-chained public log.
