# @steerable/agent-protocol

> 标签: agent, json-rpc, protocol, schema, sse, steerable, typescript

## 简介

Steerable framework Tier 1 — wire-format types (SSEEvent, ChatMessage, ToolCall, ToolResult, AgentSession, HarnessTrace, sidecar JSON-RPC) shared by every Steerable client and server.
