# @crazx/dsh-client-test-runtime

> 标签: JavaScript

## 简介

Browser test runtimes: a jsdom slot bench with test-owned Session and Workspace doubles, and a whole-client tier that boots the web roster through the production bootClient over an endpoint-named Remote mock
