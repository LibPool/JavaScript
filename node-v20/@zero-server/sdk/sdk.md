# @zero-server/sdk

> 标签: fetch, grpc, http, jwt, middleware, multipart, oauth, orm, router, server, sse, static, websocket, zero-server

## 简介

Zero-dependency backend framework for Node.js - routing, ORM, auth, WebSocket, SSE, gRPC, observability, and 20+ middleware. Distributed as a single SDK and as scoped @zero-server/* packages.
