# @veritiolabs/mcp-stdio

> 标签: card-sort, mcp, modelcontextprotocol, tree-test, ux-research, veritio

## 简介

Local stdio bridge to the Veritio MCP server, for clients that cannot connect to a remote HTTP server directly.
