# @voila/rich-text-editor

> 标签: JavaScript

## 简介

The Voila rich-text editor, built on [Plate](https://platejs.org) (which sits on [Slate](https://slatejs.org)). Ships the plugin set, a headless `<RichTextEditor>`, the `mention()` factory, HTML/JSON/plaintext serialization, and the default node component
