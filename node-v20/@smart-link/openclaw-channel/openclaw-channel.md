# @smart-link/openclaw-channel

> 标签: channel, im, openclaw, smart-link

## 简介

OpenClaw channel plugin for Smart Link IM (gedim): bot-account realtime text, image, voice and file send/receive. Multiple accounts configured via accounts[] each with a robot secretKey; user identity (userId/userName/avatars) is fetched from /auth/me aft
