# @tthappy/ppt-vue3

> 标签: JavaScript

## 简介

面向 **Vue 3** 的 PPT 编辑器组件（`PptEditor`）：顶部工具栏 + 左侧幻灯片缩略图（拖拽排序）+ 画布编辑区，支持文本（富文本）、业务文本（业务字段 tag 混排）、图片、形状、表格、媒体组件等元素类型。
