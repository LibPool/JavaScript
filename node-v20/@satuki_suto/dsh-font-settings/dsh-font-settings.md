# @satuki_suto/dsh-font-settings

> 标签: deepseek-harness, dsh, dsh-plugin, font, i18n, japanese, meiryo, typography

## 简介

DSH Web GUI フォント設定プラグイン: changes the GUI display fonts from the settings page. Overrides --dsw-font-family (UI) and --ds-font-family-code (code) with user-picked font stacks; ships Meiryo (メイリオ) as the default so Japanese text renders with Japanese glyph
