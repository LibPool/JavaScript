# @ngxviewbuilder/plugin-openapi

> 标签: angular, form-builder, low-code, openapi, plugin, rest, swagger, view-builder

## 简介

OpenAPI plugin for the NGX View Builder designer: browse a REST API like Swagger and turn any endpoint into a data source in two clicks.
