# skew-score

> 标签: blur-score, contrast-score, deskew, exposure-score, glare-score, image-processing, kyc-document, ocr-preprocessing, rotation, sharp, skew, skew-score, tilt-detection

## 简介

Quantifies document and image tilt/skew angle (-45° to +45°) using Radon projection profile analysis via Sharp. Optimized for pre-OCR document scanning, KYC ID verification, and receipt processing.
