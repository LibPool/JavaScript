# playproof

> 标签: agent, agent-skills, animation, canvas, claude-code, codex, cursor, game, gamedev, html5, playtest, playwright, testing, webgl

## 简介

Eyes and hands for browser games. Lets coding agents (and you) see animation frame by frame, play scripted input, fuzz for crashes, check phone layouts and measure frame pacing.
