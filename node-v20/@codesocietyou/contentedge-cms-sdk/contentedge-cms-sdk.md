# @codesocietyou/contentedge-cms-sdk

> 标签: cms, content, headless-cms, react-query, sdk, tanstack, typescript

## 简介

A lightweight, framework-agnostic TypeScript client for the ContentEdge headless CMS with API key authentication and optional React Query integration.
