> 标签: api-testing, copilot, mcp, migration, model-context-protocol, playwright, postman

## 简介

MCP server for Postman → Playwright migration. Uses MCP sampling — the client (VS Code Copilot, Claude Desktop, Cursor) provides the LLM. No API key required.
