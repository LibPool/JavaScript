# dsh-cicd

> 标签: alibaba-cloud-devops, cd, ci, cicd, cordis, deepseek-harness, dsh, dsh-plugin, flow, pipeline, typescript, yunxiao

## 简介

Per-project CI/CD pipelines for DeepSeek Harness: list, trigger, track, read logs, and cancel. Currently ships an Alibaba Cloud DevOps (Yunxiao Flow) adapter.
