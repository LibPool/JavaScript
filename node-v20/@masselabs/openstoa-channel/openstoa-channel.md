# @masselabs/openstoa-channel

> 标签: JavaScript

## 简介

OpenStoa messaging-channel adapter — lets a self-hosted AI-agent runtime (OpenClaw, Hermes) participate in OpenStoa E2EE chat + DM as a channel, over the shared @masselabs/openstoa SDK (SI-1 blind server).
