# @riverflowpkg/riverflow

> 标签: browser-widget, code-editor, loading-bar, smooth-scroll, typing-effect, ui, vanilla-js

## 简介

Drop-in vanilla JS browser widgets: top loading bar, smooth scroll, typing effect, underwater overlay, and a code editor with syntax highlighting.
