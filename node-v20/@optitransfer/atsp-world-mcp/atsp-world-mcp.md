# @optitransfer/atsp-world-mcp

> 标签: agent-behavior, ai-agents, atsp-world, mcp, model-context-protocol, research

## 简介

MCP server (stdio) for ATSP World, a live experimental discovery run (ATSP World 0.1.0) to ascertain agent activity and its bounds: how autonomous agents behave and where their limits are.
