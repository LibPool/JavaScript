# @toragonite/agent-mesh-claude

> 标签: adapter, agent, ai, anthropic, background-agents, claude, claude-code, cli, mesh, orchestration

## 简介

Claude Code adapter for agent-mesh — drive the official `claude` CLI as a headless worker (run / resume / stream / quota / auth), plus the absorbed claude-mesh background-agent, gateway, and bridge layers. Unofficial.
