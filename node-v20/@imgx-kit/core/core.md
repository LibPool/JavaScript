# @imgx-kit/core

> 标签: convert, crop, image, image-processing, nodejs, oss, resize, sharp, watermark, x-oss-process

## 简介

URL-driven image processing for Node.js. Compatible with Aliyun OSS x-oss-process syntax, powered by sharp.
