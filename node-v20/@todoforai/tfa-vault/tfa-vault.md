# @todoforai/tfa-vault

> 标签: cli, secrets, todoforai, vault

## 简介

Zero-config TODOforAI vault CLI — get/put/patch/list/rm secrets in the user's KV v2 vault. Reuses bridge credentials and derives the vault URL from the backend URL.
