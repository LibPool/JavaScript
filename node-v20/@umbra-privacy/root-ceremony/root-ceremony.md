# @umbra-privacy/root-ceremony

> 标签: ceremony, nitro-enclave, post-quantum, root-gen, tee, threshold, umbra

## 简介

Root-gen ceremony CLI: genesis, grants and identity for the root that every Umbra enclave derives its keys from. Operators need no AWS credentials: records go through the stack's ceremony API, each write signed by a ceremony key, and every key is unlocked
