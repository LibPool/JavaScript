# @code-name-jack/ngx-linkifyjs

> 标签: angular, autolink, email, find-links, hashtags, library, linkifyjs, links, mentionsm, ngx, text, url

## 简介

Angular wrapper for linkifyjs(v4) -  library for finding links in plain text and converting them to HTML &lt;a&gt; tags via linkifyjs
