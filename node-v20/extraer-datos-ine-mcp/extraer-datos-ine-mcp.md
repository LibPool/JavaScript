# extraer-datos-ine-mcp

> 标签: CURP, IFE, INE, KYC, Mexico, OCR, credencial de elector, mcp, model-context-protocol

## 简介

Servidor MCP oficial de Extraer Datos de INE: extrae CURP, nombre, domicilio y clave de elector de credenciales INE/IFE desde Claude, Cursor y otros clientes MCP.
