# @seed-fe/mfa-git

> 标签: git, mfa, micro-frontend, release, seed-fe, semver, tag

## 简介

Git operations and release naming rules for MFA (seed-fe-mfa) workspaces: branch status, fast-forward pull, push, tags with rollback, clone, tag checkout and release version calculation. Authentication stays with the developer's own Git setup.
