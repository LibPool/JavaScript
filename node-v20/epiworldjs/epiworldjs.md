# epiworldjs

> 标签: agent-based model, epidemiology, epiworld, measles, seir, simulation, sir, wasm, web component, webassembly

## 简介

Run epiworld's agent-based epidemic models in the browser (and Node) via WebAssembly, with a drop-in <epiworld-model> web component.
