# @bravobit/eslint-config

> 标签: bravobit, eslint, eslint-config, eslintconfig

## 简介

Bravobit's shared ESLint flat config: stylistic conventions, type-checked typescript-eslint rules, and waterfall sorting for TypeScript and CSS/SCSS.
