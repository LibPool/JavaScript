# @mars.liu/dsh-canary

> 标签: boot-canary, deepseek-harness, dsh, install-validation, plugin-safety

## 简介

dsh market install-safety canary: REALLY boot a profile composition (real profile bundles + a candidate plugin) to catch 'verifies statically, dies on restart'. A zero-docker, host-side boot probe with a bounded functional probe.
