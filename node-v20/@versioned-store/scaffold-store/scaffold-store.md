# @versioned-store/scaffold-store

> 标签: boilerplate, eval-gate, generator, monorepo, project-template, scaffold, scaffolding, versioned-config

## 简介

A batteries-included, versioned scaffold store with a deterministic promote-gate (pinning + placeholder-binding + executable allowlist), built on @versioned-store/core. Version, gate, and roll back your project scaffolds.
