> 标签: agent-skills, ai-agents, api-client, claude-code, claude-skills, codex, cursor, llm, mcp, sdk, skillgild

## 简介

Official TypeScript and JavaScript client for SkillGild, the marketplace for hosted AI agent skills. Search the catalog, run hosted skills and drive hybrid tool sessions from Node.js, Bun, Deno or the browser.
