# @aura3d/debug

> 标签: 3d, aura3d, browser-3d, debug, diagnostics, overlays, profiler, render-debug, shader-debug, telemetry, typescript, web-3d

## 简介

Diagnostics helpers for rendering, materials, shaders, physics, animation, ECS, profiling, resource leaks, overlays, and report export.
