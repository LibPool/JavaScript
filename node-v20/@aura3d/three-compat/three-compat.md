# @aura3d/three-compat

> 标签: 3d, aura3d, browser-3d, gltfloader, orbit-controls, threejs, threejs-alternative, threejs-compat, threejs-migration, typescript, web-3d

## 简介

Three.js compatibility adapters for Aura3D: core objects, math, cameras, geometries, materials, loaders, controls, animation, and migration helpers.
