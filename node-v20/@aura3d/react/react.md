# @aura3d/react

> 标签: 3d, aura-canvas, aura3d, browser-3d, product-viewer, react, react-3d, react-components, typed-assets, typescript, web-3d

## 简介

React components and helpers for mounting Aura3D scenes with typed assets, cameras, lights, effects, and product-viewer scene builders.
