# @secure-exec/typescript

> 标签: JavaScript

## 简介

Run the TypeScript compiler **inside the secure-exec sandbox**. The compiler is projected into the VM and every compile and type-check happens in the guest, so untrusted TypeScript never executes (or compiles) on the host.
