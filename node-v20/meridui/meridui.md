# meridui

> 标签: ai, cli, component-library, design-system, init, mcp, merid, meridui, nextjs, react, react-components, react-router, scaffold, setup, ui, vite

## 简介

Short alias for @meridui/cli. Run npx meridui init to set up the Merid React component library in Next.js, Vite or React Router.
