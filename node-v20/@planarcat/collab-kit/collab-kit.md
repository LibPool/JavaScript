# @planarcat/collab-kit

> 标签: agent, claude-code, collaboration, cursor, multi-agent, skill, workflow

## 简介

多 Agent 协作开发技能集（Claude Code / Cursor）：管理者/开发者/审查者/报告者 + 软锁/门禁/建任务。npm 分发，安装后把 collab-* skills 装到客户端 skills 目录。

## 官网

- npm 页面：https://www.npmjs.com/package/@planarcat/collab-kit

- 0.1.0

## 获取地址

- npm registry：https://registry.npmjs.org/@planarcat/collab-kit
- Node 要求：>=18
