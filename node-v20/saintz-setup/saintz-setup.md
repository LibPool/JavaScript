# saintz-setup

> 标签: claude-code, cli, codex, hermes, opencode, saintz, setup, wizard

## 简介

Guided setup for Claude Code, Codex, OpenCode and Hermes on the Saintz endpoint: a keyboard wizard and menu, doctor, models, English and Bahasa Melayu. No dependencies.
