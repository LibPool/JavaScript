## 简介

UNOFFICIAL community kit, not affiliated with Shopify. Rules, references and a linter that help AI coding agents (Claude Code, Cursor, GitHub Copilot, Codex, Windsurf) write Polaris 2.0 web components (s-page, s-table, s-modal) in embedded Shopify apps.
