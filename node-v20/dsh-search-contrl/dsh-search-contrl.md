# dsh-search-contrl

> 标签: cordis, creator-search, daily-report, dsh, dsh-plugin, search, search-control, settings-ui, skill

## 简介

DSH-Search-Contrl: a DSH skill/plugin for scoped web search and Chinese daily reports, with a settings GUI for custom search sources, arbitrary topics (not only tech), creator-link scoped search, and one-click rollback.
