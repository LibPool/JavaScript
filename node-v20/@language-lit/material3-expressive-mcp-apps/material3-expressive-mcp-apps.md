# @language-lit/material3-expressive-mcp-apps

> 标签: agent-ui, design-system, material-3, material-3-expressive, material-design, mcp, mcp-apps, model-context-protocol, react

## 简介

MCP Apps for Material 3 Expressive: a Material host frame that embeds MCP Apps in agent surfaces, and an app provider that lets an MCP App built with the design system follow the host's theme, display mode and safe areas.
