# @language-lit/material3-expressive-a2ui

> 标签: a2a, a2ui, a2ui-renderer, agent-to-user-interface, agent-ui, ai-agents, design-system, generative-ui, google-a2ui, material-3, material-3-expressive, material-design, react

## 简介

Material 3 Expressive renderer for Google's A2UI protocol — a React catalog that maps every A2UI basic-catalog component onto Material 3 Expressive, plus a surface renderer and a message-processor hook.
