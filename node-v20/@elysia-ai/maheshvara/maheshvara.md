# @elysia-ai/maheshvara

> 标签: JavaScript

## 简介

Elysia A.I. maheshvara 统一模型：跨协议（OpenAI Chat Completions / OpenAI Responses / Anthropic / Gemini）的请求、响应、流事件类型约定，以及与传输无关的 SSE 帧解析器。类型与 Elysia-Api（Go）relay 层的 maheshvara 规范逐字段对齐。
