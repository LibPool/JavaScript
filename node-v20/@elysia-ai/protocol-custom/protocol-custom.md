# @elysia-ai/protocol-custom

> 标签: JavaScript

## 简介

Elysia A.I. 自定义协议引擎：协议即数据——JSON 配置描述任意供应商线制（请求体注解树 / 响应路径映射 / 流式帧映射 / 别名系统 / 四线 preset）。与 Elysia-Api（Go）v1.4.0 custom_protocol* 引擎逐行为对齐。
