# @xodesign/xoframe

> 标签: cls, core-web-vitals, images, lazy-loading, lcp, lqip, performance, placeholder

## 简介

Zero-CLS progressive media loading in a ~2.9 KB core. Reserve space, show placeholder, load smart, reveal smoothly. Helps CLS, LCP and INP.
