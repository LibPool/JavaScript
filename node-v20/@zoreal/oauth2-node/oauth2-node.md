# @zoreal/oauth2-node

> 标签: backend, identity, liveness, login, node, oauth2, oidc, zoreal

## 简介

Login with ZOREAL for Node.js backends: exchanges the authorization code your frontend received from @zoreal/oauth2-react, verifies the ID token against the provider's JWKS, and reads personal claims from /userinfo.
