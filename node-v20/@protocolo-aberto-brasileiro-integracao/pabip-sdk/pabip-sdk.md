# @protocolo-aberto-brasileiro-integracao/pabip-sdk

> 标签: JavaScript

## 简介

TypeScript protocol layer for PABIP: envelope DTOs, typed HTTP clients for the sensor-nodes/video/analytics axes, and output-sink driver contract types.
