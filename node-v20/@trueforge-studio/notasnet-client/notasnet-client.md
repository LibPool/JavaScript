# @trueforge-studio/notasnet-client

> 标签: notasnet, school-api-client, syscol

## 简介

TypeScript client library for the Notasnet school portal API (syscol.com/notasnet). API access layer only: types, HTTP client, endpoint mapping, attachment helpers. No auth flow, no MCP/business logic.
