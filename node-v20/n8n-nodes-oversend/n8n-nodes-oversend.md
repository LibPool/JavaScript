# n8n-nodes-oversend

> 标签: n8n, n8n-community-node-package, oversend, whatsapp, whatsapp-groups

## 简介

n8n community node for OverSend: WhatsApp messages to people and groups, templates, chats, notes, scheduled messages, unsubscribes and a webhook trigger
