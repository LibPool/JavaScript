# @sectr/copilotkit

> 标签: ag-ui, agents, copilotkit, sectr

## 简介

Run CopilotKit on Sectr: an AG-UI agent that reconnects reloaded pages, and a stateless Copilot Runtime runner, both backed by your Sectr agent.
