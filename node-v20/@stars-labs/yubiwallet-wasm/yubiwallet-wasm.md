# @stars-labs/yubiwallet-wasm

> 标签: ethereum, solana, wallet, wasm, yubikey

## 简介

WASM bindings for YubiWallet's chain-independent logic (address derivation, EVM signature recovery) — for wallet integrators. Signing itself requires the native host.
