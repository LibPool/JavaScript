# @senad-d/observme

> 标签: cli, coding-agent, observability, opentelemetry, pi-coding-agent, pi-extension, pi-package, terminal, typescript

## 简介

ObservMe: a Pi extension that instruments Pi agent sessions and exports OpenTelemetry traces, metrics, and logs to an external observability stack (OTel Collector, Grafana Tempo/Loki/Prometheus).
