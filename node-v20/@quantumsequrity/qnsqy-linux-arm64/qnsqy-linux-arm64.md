# @quantumsequrity/qnsqy-linux-arm64

> 标签: arm64, cryptography, linux, post-quantum, pqc, prebuilt-binary, qnsqy, quantum-safe

## 简介

Prebuilt QNSQY binary for Linux ARM64 (aarch64). Installed automatically as an optional dependency of the `qnsqy` package. Do not install directly.
