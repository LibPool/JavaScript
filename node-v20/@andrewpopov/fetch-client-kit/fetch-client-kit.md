# @andrewpopov/fetch-client-kit

> 标签: 401, auth, bearer, csrf, fetch, http-client, retry, single-flight, token-refresh

## 简介

Framework-agnostic browser fetch client: a single-flight 401 -> refresh -> retry transport with pluggable auth (cookie / bearer / csrf).
