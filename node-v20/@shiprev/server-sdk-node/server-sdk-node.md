# @shiprev/server-sdk-node

> 标签: entitlements, metering, nestjs, sdk, shiprev, usage-based-billing

## 简介

Server SDK for Node.js and NestJS services: token verification, local entitlement rulings, usage reporting, and two-phase reservations against a ShipRev instance.
