# @golemcloud/effect-golem

> 标签: agent, durable-execution, effect, golem, wasm

## 简介

Write Golem agents on top of Effect v4: Effect Schema-typed methods, durable execution, snapshots, sagas, RPC, HTTP, webhooks, KV/blob, and RDBMS adapters compiled to a Golem WASM component.
