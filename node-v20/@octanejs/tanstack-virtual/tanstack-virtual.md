# @octanejs/tanstack-virtual

> 标签: JavaScript

## 简介

TanStack Virtual bindings for the octane renderer — reuses the framework-agnostic @tanstack/virtual-core and swaps the React adapter (useVirtualizer, useWindowVirtualizer) for an octane port.
