# xslt-bridge

> 标签: chrome, edge, firefox, legacy, libxslt, polyfill, safari, xpath, xslt, xslt-1.0, xsltprocessor

## 简介

Pure JavaScript drop-in replacement for the browser XSLTProcessor (XSLT 1.0) for when browsers drop XSLT. Works in any modern browser with the same output as Chrome. No WebAssembly.
