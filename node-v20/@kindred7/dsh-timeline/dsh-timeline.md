# @kindred7/dsh-timeline

> 标签: arrow-up, conversation, deepseek-harness, dsh, history, plugin, recall, timeline

## 简介

Conversation timeline plugin (left-side markers with hover tooltip and click-to-scroll) plus terminal-style history recall: ArrowUp on an empty composer fills the previous question directly into the input box
