# @rs25-labs/pi-mindvault

> 标签: agent-memory, ai-agent, coding-agent, embeddings, llm-memory, local, local-first, long-term-memory, memory, memory-subsystem, offline, on-device, pi, pi-package, privacy, private, rag, semantic-search, sqlite, vector-search

## 简介

Private, local-first memory subsystem for the pi coding agent. Long-term memory across sessions, stored on your own machine in SQLite, with optional on-device semantic search. No server, no cloud, nothing leaves your machine.
