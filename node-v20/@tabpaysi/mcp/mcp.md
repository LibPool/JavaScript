# @tabpaysi/mcp

> 标签: agent-payments, ai-agent, claude, mcp, solana, usdc, x402

## 简介

MCP server that lets Claude, Cursor or any MCP agent pay x402 APIs on Solana from a capped TAB allowance. The agent never holds a wallet key.
