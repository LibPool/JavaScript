# agent-intercom

> 标签: agents, antigravity, claude-code, codex, gemini, mcp, messaging, multi-agent

## 简介

Let Claude Code, Codex CLI and Antigravity (Gemini) message each other, with optional live push into open sessions. A zero-dependency MCP mailbox.
