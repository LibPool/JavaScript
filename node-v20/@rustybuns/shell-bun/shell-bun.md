# @rustybuns/shell-bun

> 标签: bun, desktop, durable-objects, rustybuns, sqlite

## 简介

The Bun host: token-gated server, in-process Durable Objects, sqlite behind D1/KV/DO storage, R2 over a directory, launcher.
