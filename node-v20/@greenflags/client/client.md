# @greenflags/client

> 标签: feature-flags, greenflags, sdk

## 简介

Framework-agnostic JavaScript/TypeScript SDK for consuming GreenFlags feature flags. Zero runtime dependencies, ESM-only, billing-safe snapshot + cache.
