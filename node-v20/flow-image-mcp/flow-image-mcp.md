# flow-image-mcp

> 标签: chrome-extension, claude, claude-code, google-flow, image-generation, mcp, nano-banana

## 简介

MCP server + Chrome extension: generate images with Google Flow in your own signed-in browser, from Claude Code or any MCP client. No API key.
