# @bestfunc-com/argus-file-mcp

> 标签: argus, bestfunc, file-transfer, mcp

## 简介

Argus 本地文件 MCP Server — 通过 HTTP 直连 argus.bestfunc.com/api/transfers/* 实现大文件上传/下载，绕开 MCP base64 内联限制
