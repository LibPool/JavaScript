# @nodepay/vnpay

> 标签: JavaScript

## 简介

VNPay payment gateway integration (Payment Gateway: pay, querydr, refund, refundbatch, IPN, Return) — framework-agnostic core usable from Express/Fastify/plain Node, plus an optional NestJS module (`@nodepay/vnpay/nestjs`) supporting single- and multi-ten
