# @prometheusavatar/openclaw-plugin

> 标签: ai-agent, avatar, emotion, image-generation, lip-sync, live2d, marketplace, openclaw, openclaw-plugin, tts

## 简介

Prometheus Avatar plugin for OpenClaw — Live2D body with TTS, lip-sync, emotion, plus AAA image generation for marketplace skin previews. Now ships with bundled Skill that teaches the agent when and how to use the 3 creator tools.
