# @verisaegis/sdk

> 标签: aegis, agent-identity, ai, ai-agents, ai-governance, audit, compliance, identity, security, trust

## 简介

Official HTTP client for the Veris Protocol API — issue signed AI Passports, verify agent capabilities in real time, and read tamper-evident audit trails from the hosted service at verisaegis.com.
