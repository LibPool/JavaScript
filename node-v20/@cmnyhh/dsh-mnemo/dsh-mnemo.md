# @cmnyhh/dsh-mnemo

> 标签: dsh, dsh-plugin, long-term-memory, memory, recall

## 简介

Long-term memory for dsh: capture finished turns, recall them into the first step of a later turn, and expose recall and write as tools. Ships a bundle layer and a settings panel for the service address and token.
