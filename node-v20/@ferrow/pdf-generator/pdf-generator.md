# @ferrow/pdf-generator

> 标签: helvetica, pdf, pdf-generation, typescript, zero-dependencies

## 简介

Minimal text-and-lines PDF 1.4 writer built from scratch, zero dependencies. Helvetica core font, multi-page, mm/pt units.
