# @ferrow/readme-toc-gen

> 标签: documentation, github-flavored-markdown, markdown, readme, table-of-contents, toc

## 简介

Generate a GitHub-style table of contents for markdown files, with idempotent marker-based insertion and dry-run diffs. Zero runtime dependencies.
