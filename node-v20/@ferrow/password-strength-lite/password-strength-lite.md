# @ferrow/password-strength-lite

> 标签: entropy, password, security, strength, typescript, zero-dependencies, zxcvbn-alternative

## 简介

Lightweight, dependency-free password strength estimator: entropy scoring, pattern penalties (repeats, sequences, keyboard runs, years, leetspeak), a built-in common-password list, and documented crack-time estimates. Smaller and less accurate than zxcvbn
