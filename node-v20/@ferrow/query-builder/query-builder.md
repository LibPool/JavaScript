# @ferrow/query-builder

> 标签: database, parameterized-queries, postgres, query-builder, sql, typescript

## 简介

Chainable SQL query builder for SELECT/INSERT/UPDATE/DELETE with nested AND/OR WHERE, joins, ordering, limit/offset, and safe identifier escaping. Produces { sql, params } — no DB driver dependency.
