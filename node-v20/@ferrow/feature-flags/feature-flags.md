# @ferrow/feature-flags

> 标签: consistent-hashing, feature-flags, feature-toggle, rollout, targeting, typescript

## 简介

Deterministic feature flag evaluation engine: boolean flags, percentage rollout via consistent hashing, attribute targeting rules (eq/in/gt/lt), environment overrides, and a pluggable async store.
