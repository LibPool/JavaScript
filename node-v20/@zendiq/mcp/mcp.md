# @zendiq/mcp

> 标签: ai-agents, jupiter, mcp, mev, model-context-protocol, solana, token-risk, x402

## 简介

MCP server for ZendIQ: screen Solana tokens for free, triage a swap ($0.01) or build it ($0.02), paid per call over x402. Zero custody.
