# @liquid-dom/r3f

> 标签: JavaScript

## 简介

`@liquid-dom/r3f` bridges React Three Fiber, Three's WebGPU renderer, and the React liquid-glass scene. It renders your R3F scene into an intermediate backdrop target, then composites liquid glass over it.
