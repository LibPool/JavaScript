# @vulcx/sdk

> 标签: aggregator, defi, dex, firm-quotes, fogo, solana, svm, swap, valiant, vulcx

## 简介

TypeScript client for Vulcx, the best-price swap router for Fogo — multi-hop split routing, firm quotes, and ready-to-sign transactions.
