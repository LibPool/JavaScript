# @formgong/vue

> 标签: bolt, composable, contact form, contact-form, email, form backend, form-backend, formgong, forms, formspree alternative, formspree-alternative, gdpr, lovable, no-backend, nuxt, spam-protection, static-site, telegram, vue, vue3, web3forms alternative, web3forms-alternative

## 简介

Vue 3 / Nuxt contact form without a backend: <ContactForm>, <FormgongForm> and useFormgong(). Submissions go to email, Telegram and webhooks via Formgong. A Formspree / Web3Forms alternative.
