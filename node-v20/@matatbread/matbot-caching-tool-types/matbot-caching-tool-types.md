# @matatbread/matbot-caching-tool-types

> 标签: agent, ai, llm, matbot, matbot-plugin, typescript

## 简介

Node ToolTypeIndex that keeps @matatbread/matbot-tool-types' build in plugin settings, so a process whose plugins and tools are unchanged skips the TypeScript build on its first tool call.
