# @v1v2/nanoid

> 标签: JavaScript

## 简介

A [Nano ID](https://github.com/ai/nanoid) default configuration with no lookalikes (`0`, `O`, `1`, `l`, `I`), and without `-` and `_`. This custom alphabet uses a length of 22 to have a similar collision risk to UUID v4 (twice less actually), for a 30% sh
