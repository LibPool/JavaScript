# @octopus-diagram/core

> 标签: bpmn, bpmn2, diagram, process-modeling, typescript, workflow

## 简介

Framework-independent BPMN 2.0 diagram engine: domain model, commands with undo/redo, validation, routing, layout, interaction logic and serialization.
