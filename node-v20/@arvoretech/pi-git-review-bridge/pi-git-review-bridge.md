# @arvoretech/pi-git-review-bridge

> 标签: code-review, extension, git, pi, pi-package, pull-request

## 简介

PI extension that bridges a local pi session to the git-review-cloud PR reviewer: browser comments are delivered to the agent in real time over WebSocket
