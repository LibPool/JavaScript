# @leadpulse/pseo-bootstrap

> 标签: JavaScript

## 简介

Scaffold programmatic SEO (pSEO) drafts for any product. Interactive by default, non-interactive for agents/harnesses via JSON or flags. Stdlib-only — no runtime dependencies.
