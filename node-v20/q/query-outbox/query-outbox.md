# query-outbox

> 标签: idempotency, mutation-queue, offline, offline-first, optimistic-updates, outbox, react-native, react-query, sync, tanstack-query

## 简介

Durable, causally-ordered offline mutation queue for TanStack Query. Transactional outbox for React and React Native: survives app kill, replays in dependency order, deduplicates with idempotency keys.
