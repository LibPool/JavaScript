> 标签: better-sqlite3, drizzle, knex, libsql, mongodb, mongoose, mysql, mysql2, n+1, neon, orm, performance, pg, planetscale, postgres, postgres.js, prisma, query, sequelize, sqlite, turso, typeorm

## 简介

QueryLens SDK for Node.js: monitors the queries your app sends to PostgreSQL (pg, postgres.js, Neon), MySQL (mysql2, PlanetScale), SQLite (better-sqlite3, sqlite3, node:sqlite, libSQL / Turso) and MongoDB (mongodb, Mongoose), through Sequelize, Knex, Type
