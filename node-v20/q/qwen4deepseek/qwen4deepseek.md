# qwen4deepseek

> 标签: claude-code, dashscope, deepseek, mcp, ocr, pdf, qwen, vision

## 简介

MCP server that gives DeepSeek and other non-vision models the ability to see images and read documents, powered by Qwen VL (阿里云百炼)
