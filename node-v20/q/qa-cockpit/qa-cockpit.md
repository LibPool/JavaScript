# qa-cockpit

> 标签: agents, ai-agents, claude-code, codex, collaborative, dashboard, e2e, multi-user, playwright, qa, testing, vibe-coding

## 简介

Vibe coding for integration tests: coding agents write and run multi-user Playwright suites, one browser per person; people watch every screen live in a cockpit and pin notes for the agent to fix.
