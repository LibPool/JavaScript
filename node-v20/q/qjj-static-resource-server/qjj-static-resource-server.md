# qjj-static-resource-server

> 标签: JavaScript

## 简介

``` npm i -g qjj-static-resource-server ```  ##使用方法 ``` qjj-static-resource-server   #将当前目录作为静态资源的根目录 qjj-static-resource-server -p 9999   #将端口号设置为9999 qjj-static-resource-server -h localhost   #将host设置为localhost qjj-static-resource-server -d /usr
