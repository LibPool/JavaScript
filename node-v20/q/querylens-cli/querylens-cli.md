# querylens-cli

> 标签: ci, index, n+1, orm, performance, postgres, postgresql, profiler, query, sequelize

## 简介

Find the N+1 queries, missing indexes and other database problems in what your app actually sends to PostgreSQL. Fixes written for your ORM.
