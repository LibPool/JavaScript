# quilly-mcp

> 标签: claude-code, google-meet, mcp, model-context-protocol, quilly, transcript

## 简介

MCP server that lets local AI agents list, search and read Google Meet transcripts recorded by the Quilly Chrome extension, including the one being recorded.
