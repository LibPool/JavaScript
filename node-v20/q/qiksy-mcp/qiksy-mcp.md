# qiksy-mcp

> 标签: a11y, accessibility, agent, browser, browser-automation, browser-mcp, chrome-extension, chrome-mcp, claude, claude-code, codex, cursor, mcp, mcp-chrome-extension, mcp-server, modelcontextprotocol, qa, testing

## 简介

Browser MCP server for the Chrome tab you already have open — your session, your logins. Gives Claude Code, Cursor, Codex and VS Code the live page: findings, forms, failed requests with server bodies.
