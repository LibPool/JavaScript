# quidemeos

> 标签: compare, error, est, fast, fugit, fuzzy, molestiae, omnis, quas, qui, similarity, sint, string, sunt, temporibus, text

## 简介

The most efficient JS implementation calculating the Levenshtein distance, i.e. the difference between two strings.
