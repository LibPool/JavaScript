# quicke2e

> 标签: ai-testing, browser-testing, decision-model, e2e, end-to-end, exploratory-testing, jev, plain-english, playwright, testing

## 简介

Plain-English end-to-end browser tests: a small decision model picks each click, your spec supplies every typed value, code decides pass/fail, and a passing run exports a Playwright spec.
