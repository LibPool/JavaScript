# qrtap-mcp

> 标签: ai-agent, analytics, claude, llm-tools, mcp, model-context-protocol, qr, qr-code, qrtap, short-link

## 简介

MCP (Model Context Protocol) stdio server for QRTap: editable QR codes, short links, public pages, guest reviews, booking requests and smart redirect rules as tools for AI agents.
