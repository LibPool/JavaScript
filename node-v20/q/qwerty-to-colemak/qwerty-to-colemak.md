# qwerty-to-colemak

> 标签: JavaScript

## 简介

Look up the COLEMAK key for a given QWERTY keyboard key press (or vice versa).

## 官网

- npm 页面：https://www.npmjs.com/package/qwerty-to-colemak

- Node 要求：>10
