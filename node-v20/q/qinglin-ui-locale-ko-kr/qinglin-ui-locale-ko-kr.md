# qinglin-ui-locale-ko-kr

> 标签: i18n, locale, qinglin-ui, 한국어

## 简介

Korean (ko-KR) language pack for qinglin-ui. Install this alongside qinglin-ui to enable 한국어 UI text.

## 官网

- npm 页面：https://www.npmjs.com/package/qinglin-ui-locale-ko-kr

- 1.0.1

## 获取地址

- npm registry：https://registry.npmjs.org/qinglin-ui-locale-ko-kr
