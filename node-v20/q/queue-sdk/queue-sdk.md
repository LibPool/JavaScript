# queue-sdk

> 标签: JavaScript

## 简介

Queue-sdk is a npm module which helps you to integrate with Queue services like Redis and Kafka. The sdk also has its own simple in-memory queue implemented which uses array as datast. Of-course you do not want to use it for production, but good for testi
