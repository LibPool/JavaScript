# qb-json-tok

> 标签: JSON, UTF-8, UTF8, error, fast, parse, partial files, recovery, repair, small, tokenize

## 简介

Fast (~300 MB/sec) and light (~1.3 kb) JSON/UTF-8 tokenizer for creating custom parsers
