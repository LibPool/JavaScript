# quick-drawio-mcp

> 标签: anthropic, claude, diagrams, draw.io, drawio, export, llm, mcp, mermaid, png, quick, xml

## 简介

draw.io MCP server for LLMs - open diagrams in the draw.io editor, search official shapes, and export real PNG/SVG/PDF/JPG files via the local draw.io Desktop CLI. Fork of @drawio/mcp (jgraph/drawio-mcp) adding the export_drawio_image tool and removing op
