# quotebot-mcp

> 标签: discord, mcp, model-context-protocol, quotebot, quotes

## 简介

MCP server for QuoteBot — connect an AI agent (Claude Desktop or any MCP client) to QuoteBot with a personal API key. Image keys (Google/email sign-in) generate quote images; full keys (Discord sign-in) also drive the Discord quote workflow.
