# qoyod-mcp

> 标签: accounting, erp, mcp, model-context-protocol, qoyod, saudi-arabia, zatca, قيود

## 简介

Unofficial MCP server for the Qoyod accounting API: separate read, write and delete tools, multi-company, works with any MCP client
