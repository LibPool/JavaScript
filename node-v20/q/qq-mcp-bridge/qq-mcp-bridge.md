# qq-mcp-bridge

> 标签: bot, dsh, dsh-bundle, mcp, qq, qqbot

## 简介

QQ official bot (bot.q.qq.com) MCP bridge for DeepSeek Harness: private-chat receive/reply and proactive push. No external dependencies, no credentials in the package.
