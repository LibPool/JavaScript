# q-upload-container

> 标签: container, q-upload, q-upload-container, react, react-upload, upload

## 简介

这是一个包含文件上传的逻辑容器组件，其功能包含小文件、大文件常见功能等，只提供功能的封装，不提供UI的具体组件，展示组件完全由用户自己创建。
