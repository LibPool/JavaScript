# quality-guard

> 标签: claude-code, claude-code-plugin, code-quality, mcp, refactoring, static-analysis

## 简介

Structural code quality gate. Claude Code plugin with an MCP server and a PostToolUse hook that ratchets every write against a recorded baseline. Ships 1 skill: /quality-refactor.
