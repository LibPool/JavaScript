# claude-code-notebook

> 标签: ai-agents, anthropic, claude, claude-code, compaction, context, developer-tools, hooks, memory

## 简介

Claude Code forgets what it was doing after context compaction. This keeps a per-session working notebook and restores it automatically. Two hooks, zero dependencies.
