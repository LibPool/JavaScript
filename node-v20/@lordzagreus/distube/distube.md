# @lordzagreus/distube

> 标签: bot, discord, discord-js, discord-music-bot, discordjs, distube, music, music-bot, musicbot, queue, youtube

## 简介

A Discord.js module to simplify your music commands and play songs with audio filters on Discord without any API key. Implements a fix for 74-byte UDP packets.
