# @pickhooks/mcp

> 标签: ai-agent, bnb-chain, launchpad, mcp, model-context-protocol, pancakeswap, pickhooks

## 简介

pickhooks for AI agents: an MCP server that reads, quotes, tests, launches and trades rule coins on BNB Chain. Runs locally, your key stays in your environment.
