# @engineering-toolkit/mcp

> 标签: adr, ai, architecture-decision-record, decision-records, engineering, llm, mcp, model-context-protocol

## 简介

Model Context Protocol server that exposes an Engineering Toolkit workspace to AI assistants, so they can read the decisions, plans and risks a project already recorded.
