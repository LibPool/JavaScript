# @heraldserver/server

> 标签: control-plane, herald-protocol, outpost, postgres, server

## 简介

Servidor de controle do Herald Protocol — gestão de Outposts, usuários e histórico de métricas, backed by Postgres. Sem dashboard/UI de dados (ver @herald/dashboard, congelado em ICA-34) — só a tela mínima de autorização do device flow (herald login).
