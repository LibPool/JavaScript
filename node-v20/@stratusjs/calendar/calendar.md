# @stratusjs/calendar

> 标签: angularjs, fullcalendar, ical, javascript, lodash, sitetheory, stratus, typescript

## 简介

AngularJS Calendar component and iCAL service to be used as an add on to StratusJS. Makes use of fullcalendar and iCAL
