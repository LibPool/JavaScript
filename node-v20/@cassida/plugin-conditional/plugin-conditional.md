# @cassida/plugin-conditional

> 标签: cassida, compile-time, conditional, css-in-js, react, single-class

## 简介

Cassida parser plugin: rewrites `{...(cond ? cas().X() : cas().Y()).props}` and `{...cond && cas().X().props}` JSX spreads to a single className expression at build time. Lets component libraries express prop-driven variants without a runtime variant DSL.
