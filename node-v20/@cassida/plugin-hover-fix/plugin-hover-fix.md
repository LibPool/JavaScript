# @cassida/plugin-hover-fix

> 标签: cassida, compile-time, css-in-js, react, single-class

## 简介

Cassida plugin: wraps :hover scopes in @media (hover: hover) to neutralize iOS Safari's sticky-hover artifact on touch devices.
