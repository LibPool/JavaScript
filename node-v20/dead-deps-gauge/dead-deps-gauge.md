# dead-deps-gauge

> 标签: cli, dead-code, depcheck, dependencies, github-action, imports, lint, package-json, sarif, unused-dependencies

## 简介

Find dependencies declared in package.json but never imported, and imports missing from package.json (or only in devDependencies). Understands ESM/CJS/TS, dynamic import, scripts, bins, config files and @types. Text/JSON/SARIF/Markdown, allowlist with exp
