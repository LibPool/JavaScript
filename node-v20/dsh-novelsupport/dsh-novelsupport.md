# dsh-novelsupport

> 标签: JavaScript

## 简介

Novel-writing workspace for DeepSeek Harness: a three-pane UI with map, timeline, character/place/item/organisation graph, chapter editor, full-book export and plain-text import — stored as plain files in the project.
