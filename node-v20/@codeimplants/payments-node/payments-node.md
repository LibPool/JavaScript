# @codeimplants/payments-node

> 标签: codeimplants, payments, phonepe, upi, webhooks

## 简介

Server-side client for Code Implants Pay (pay.codeimplants.com): payment intents, refunds, event replay and webhook signature verification. Zero dependencies.
