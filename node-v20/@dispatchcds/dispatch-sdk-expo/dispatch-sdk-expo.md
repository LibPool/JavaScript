# @dispatchcds/dispatch-sdk-expo

> 标签: bi-group, cds, dispatch, expo, orders, react-native, sdk

## 简介

Expo/React Native мост к нативному Dispatch CDS orders SDK: open(token) открывает нативный экран заказов (Kotlin/Swift). SDK приходит бинарно: Maven Central (Android) и GitHub Releases/XCFramework (iOS).
