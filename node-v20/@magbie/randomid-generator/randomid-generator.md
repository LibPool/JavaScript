# @magbie/randomid-generator

> 标签: JavaScript

## 简介

Generator unikalnych identyfikatorów. Paczka generuje losowy string z literami i liczbami. Podajemy jej jeden parametr idLength, który będzie decydował o ilości znaków wygenerowanego stringa.
