# @daxlib/mcp-win32-x64

> 标签: JavaScript

## 简介

Windows x64 binary for @daxlib/mcp, the DAX Lib MCP server. Install @daxlib/mcp instead of this package.

## 官网

- 官网：https://daxlib.org
- 源码仓库：git+https://github.com/daxlib/daxlib-mcp.git
- npm 页面：https://www.npmjs.com/package/@daxlib/mcp-win32-x64

- npm registry：https://registry.npmjs.org/@daxlib/mcp-win32-x64
- Node 要求：>=18.0.0
