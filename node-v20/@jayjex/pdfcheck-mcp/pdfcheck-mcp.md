# @jayjex/pdfcheck-mcp

> 标签: mcp, modelcontextprotocol, page-tree, pdf, qa, validation, xref

## 简介

MCP server that validates PDF page-tree graphs: Kids->Page, Contents->stream, orphan pages, Count mismatch. stdio, zero native deps.
