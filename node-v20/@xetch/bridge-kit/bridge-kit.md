# @xetch/bridge-kit

> 标签: JavaScript

## 简介

Shared Xetch ⇄ wallet contract: signing-bridge protocol, canonical action pricing, and the action-to-transaction builder. Imported by both Xetch and any wallet that signs for it, so the two cannot drift.
