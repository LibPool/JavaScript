# @cawabunga/aurora-engine-utils-js

> 标签: JavaScript

## 简介

This package provides utilities for parsing Aurora transactions in JavaScript applications. It supports various Ethereum transaction types and simplifies the process of working with Aurora transactions within the NEAR ecosystem.
