# shipped-secrets

> 标签: bundle, ci, env, git-history, leak, nextjs, secrets, security, stripe, supabase, verify, vite, vite-plugin

## 简介

Find secrets that ship to the browser or sit in git history, and check whether they still work: your real .env values, known key shapes and risky public env names, in any framework's build output, source maps included.
