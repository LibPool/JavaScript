# @vheins/opencode-system-one

> 标签: ai, guardrail, jev, opencode, opencode-plugin, system-one, systemone, typesafe

## 简介

opencode plugin that routes TypeSafe Jev (System One) structured judgments through opencode's plugin hooks: tool guardrails, permission arbitration, cascade routing, and event triage.
