# @sealpost/sdk

> 标签: api-client, email, resend-alternative, sdk, sealpost, smtp, transactional-email

## 简介

Zero-dependency TypeScript client for the Sealpost API. Resend-style { data, error } results; works in Node 18+, browsers, Deno, Bun and edge runtimes.
