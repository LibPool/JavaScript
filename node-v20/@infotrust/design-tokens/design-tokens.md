# @infotrust/design-tokens

> 标签: css-variables, design-system, design-tokens, infotrust, primevue, tailwind

## 简介

InfoTrust design tokens (W3C DTCG source) with CSS variable, Tailwind v4, PrimeVue, and JSON outputs. Framework-neutral. Built for InfoTrust products; no support for outside use.
