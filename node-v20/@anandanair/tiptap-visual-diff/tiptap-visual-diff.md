# @anandanair/tiptap-visual-diff

> 标签: compare, diff, prosemirror, rich-text-editor, tiptap, tiptap-extension, track-changes, visual-diff

## 简介

ProseMirror decoration-based visual diff extension for Tiptap v3. Compares editor content against a reference document and highlights additions, removals, and modifications inline — without touching the actual document content.
