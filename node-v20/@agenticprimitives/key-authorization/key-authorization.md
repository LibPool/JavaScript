# @agenticprimitives/key-authorization

> 标签: agent-authority, agentic, agentic-primitives, agentic-trust, agenticprimitives, ai-agents, decrypt-grant, kas, key-authorization, primitives, vault

## 简介

Policy-bound one-time key release (spec 277 §14): DecryptGrant construction + KAS verification + one-time replay store. Authority stays delegation/entitlement/policy; key-custody does the DEK unwrap.
