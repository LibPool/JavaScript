## 简介

Agent Naming Service SDK: typed hierarchical naming for Smart Agents (.me .org .team .svc .workspace .treasury — a suffix names the derived agent type; spec 346). Owns name grammar + normalization, namehash/labelhash, records schemas, the DNS/A2A endpoint
