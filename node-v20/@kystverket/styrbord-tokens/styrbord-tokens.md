# @kystverket/styrbord-tokens

> 标签: JavaScript

## 简介

`@kystverket/styrbord-tokens` is the CSS design token package for Kystverket's design system, Styrbord. It provides color, typography, spacing, and other design tokens as CSS custom properties, plus a typed JavaScript module for use in TypeScript/Node.js
