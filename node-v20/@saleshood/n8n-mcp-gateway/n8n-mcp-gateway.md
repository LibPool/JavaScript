# @saleshood/n8n-mcp-gateway

> 标签: JavaScript

## 简介

Per-user local stdio MCP proxy for n8n's streamable HTTP MCP endpoint. Owns the n8n OAuth 2.1 flow and requests read/execute scopes only.
