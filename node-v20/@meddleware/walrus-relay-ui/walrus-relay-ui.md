# @meddleware/walrus-relay-ui

> 标签: JavaScript

## 简介

Shared Vue 3 UI for the Walrus upload relay: relay selection + tip estimation, NFT-gate access, and a blob-upload widget. Built on @meddleware/walrus-client + @meddleware/nft-gate-client. Consumed by apps/walrus-relay-app and apps/token-deployer-sui.
