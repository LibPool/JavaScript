# @fundamental-engine/dom

> 标签: Fundamental, dom, feedback, measurement, overlays, relationships, state, web

## 简介

The platform-adjacent layer for Fundamental — native-first registries for measurement, semantic state, feedback, relationships, visual-semantic bindings, and overlays. The browser primitives Fundamental wishes existed, built on the ones it has.
