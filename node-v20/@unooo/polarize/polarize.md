# @unooo/polarize

> 标签: JavaScript

## 简介

polarize MCP server: a stdio Model Context Protocol server that automates real native macOS AppKit applications (screenshot, accessibility-tree inspection, synthetic input). Thin binary that wires MCP tool calls to polarize-core/polarize-macos.
