# @exponential_app/ui

> 标签: a2ui, exponential-ui, generative-ui

## 简介

Exponential UI: the core A2UI catalog (components, macros, model descriptions, token names), the A2UI basic catalog map, the TypeScript reference reducer, the runtime theme format with the built-in themes, and the theme builder.
