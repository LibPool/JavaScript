# leaveguard

> 标签: beforeunload, dirty-form, framework-agnostic, leave-page, navigation-api, navigation-guard, prevent-navigation, react, react-hook, spa, unsaved-changes

## 简介

Warn before users leave with unsaved changes, on page reloads and on in-app (SPA) navigation. Zero dependencies, works with any framework.
