# @gears-frontx/routing-tanstack

> 标签: frontx, navigation, router, routing, tanstack, typescript

## 简介

FrontX's default routing-engine provider - binds the navigation substrate's shared history to TanStack Router, projecting each occupant's own entry into a virtual location that engine can navigate
