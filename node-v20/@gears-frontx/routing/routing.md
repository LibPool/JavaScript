# @gears-frontx/routing

> 标签: frontx, navigation, router, routing, typescript, url

## 简介

FrontX navigation library - a framework-agnostic navigation substrate sharing one browser history across independently bundled microfrontends, plus a route ownership signal, with no dependency on any concrete router engine
