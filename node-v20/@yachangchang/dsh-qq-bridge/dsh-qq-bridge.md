# @yachangchang/dsh-qq-bridge

> 标签: agent, cordis, dsh, dsh-plugin, napcat, onebot, qq

## 简介

A pluggable DSH host plugin that connects QQ (NapCat/OneBot) and forwards messages to DSH agents / local capabilities.
