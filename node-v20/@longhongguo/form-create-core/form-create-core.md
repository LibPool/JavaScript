# @longhongguo/form-create-core

> 标签: @form-create, components, dynamic-form, form, form-builder, json-form, vue3, 动态表单

## 简介

FormCreate低代码表单渲染引擎，可以通过 JSON 生成具有动态渲染、数据收集、验证和提交功能的低代码表单。支持6个UI框架，适配移动端，并且支持生成任何 Vue 组件。
