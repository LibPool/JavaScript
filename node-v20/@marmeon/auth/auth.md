# @marmeon/auth

> 标签: api-tokens, auth, authentication, authorization, marmeon, policies

## 简介

Authentication and authorization for Marmeon apps: session guard, remember-me, password hashing and resets, e-mail verification, API tokens, policies and make:auth.
