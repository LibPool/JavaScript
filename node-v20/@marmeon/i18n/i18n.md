# @marmeon/i18n

> 标签: i18n, icu, localization, marmeon, translations

## 简介

Translations for Marmeon apps: typed messages per module (TS files), an ICU subset, a translator per request and the locale middleware. UI-agnostic — `@marmeon/i18n/messages` is the browser-safe core the UI adapters build on.
