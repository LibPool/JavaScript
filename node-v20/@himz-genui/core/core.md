# @himz-genui/core

> 标签: claude-code, codex, coding-agent, contracts, copilot, cursor, design-system, generative-ui, react, ui

## 简介

Contract-driven UI for coding agents. Ship component contracts, let the agent materialize them once, compose screens from them, and gate every step with a deterministic check.
