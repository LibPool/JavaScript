# @rdlabo/workers-hono-kit

> 标签: aws-secrets-manager, cloudflare-workers, edge, etag, firebase, hono, jose, middleware, nestjs, workers, zod

## 简介

Infrastructure toolkit for building APIs on Hono + Cloudflare Workers: Firebase ID-token verification (jose), AWS Secrets Manager (aws4fetch), ETag/validation/zod-coerce middleware, deadlock retry, and shared HTTP helpers.
