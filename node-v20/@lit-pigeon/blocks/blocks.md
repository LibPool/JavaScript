> 标签: blocks, email, email-editor, email-template, html-email, lit, mjml, plugins, web-components

## 简介

Optional standard block catalog for Lit Pigeon — video, countdown, accordion, table, carousel — shipped as plugin BlockDefinitions, not built-ins.
