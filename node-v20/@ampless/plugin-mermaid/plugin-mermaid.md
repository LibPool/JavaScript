# @ampless/plugin-mermaid

> 标签: ampless, ampless-plugin, cms, diagram, flowchart, mermaid, plugin

## 简介

Mermaid diagram plugin for ampless — renders `code.language-mermaid` blocks on the public site as diagrams via a lazily CDN-loaded mermaid.js
