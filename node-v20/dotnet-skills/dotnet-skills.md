# dotnet-skills

> 标签: agent-skills, csharp, deepseek-harness, dotnet, dsh, dsh-plugin, skills

## 简介

A fork of Microsoft's official .NET/C# skills for AI coding agents, additionally packaged as a DeepSeek Harness plugin — covering development, testing, diagnostics, migration, and AI integration.
