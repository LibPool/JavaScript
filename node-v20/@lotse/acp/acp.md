# @lotse/acp

> 标签: acp, agent-client-protocol, coding-agent, json-rpc

## 简介

Agent Client Protocol, layer 1: the protocol types against refs/acp/schema.v1.json, the JSON-RPC 2.0 codec, and the client session lifecycle. NO spawn, NO gi://, NO dependencies — the transport is an injected interface, so every byte of protocol lives her
