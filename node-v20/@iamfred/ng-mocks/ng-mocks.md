# @iamfred/ng-mocks

> 标签: TestBed, angular, component, dependency, directive, enzyme, front-end, frontend, how-to, jasmine, jest, mock, mocking, pipe, provider, service, stub, test, testing

## 简介

An Angular testing library for creating mock services, components, directives, pipes and modules in unit tests. It provides shallow rendering, precise stubs to fake child dependencies. ng-mocks works with Angular 17 18 19 20 21, jasmine and jest.
