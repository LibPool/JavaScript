# @figviz/figviz-mcp

> 标签: ai, claude, cursor, diagram, diagram-generator, education, figviz, mcp, model-context-protocol, science

## 简介

MCP server for Figviz — generate labeled science & math diagrams (biology, chemistry, physics, K-12 math) from text via the Figviz API.
