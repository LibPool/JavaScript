# create-comwit

> 标签: claude-code, comwit, create, domain-driven, nextjs, template, vibe-coding

## 简介

Scaffold a Next.js app with the Comwit template: services sliced by domain, one-way layers (page → state → api → repository), .ai.md rules per layer, and agent skills for app shell, auth and SEO.
