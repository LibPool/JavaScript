# @complyedge/mcp

> 标签: ai-act, ai-compliance, ai-governance, ai-safety, article-5, article-50, compliance, complyedge, coppa, eu-ai-act, gdpr, hipaa, mcp, mcp-server, model-context-protocol, npx, offline, pci-dss, prompt-injection, prompt-scanning, sox, trustlint

## 简介

Offline MCP server for EU AI Act compliance checks. Three read-only tools over a bundled 63-rule corpus — Art. 5 prohibited practices, Art. 50 transparency, GDPR, HIPAA, SOX, PCI DSS, COPPA. Runs with npx: no Python, no API key, no network call.
