# @ensemble-sheets/scim-adapter

> 标签: JavaScript

## 简介

SCIM 2.0 (RFC 7644) Users + Groups handler for ensemble host applications. Wires identity-provider provisioning (Okta, Azure AD, JumpCloud) into a custom IdentityAdapter.
