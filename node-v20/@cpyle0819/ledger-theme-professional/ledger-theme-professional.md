# @cpyle0819/ledger-theme-professional

> 标签: JavaScript

## 简介

A clean, corporate-grade theme for The Ledger: neutral graphite palette, crisp white cards, one disciplined cobalt-blue accent, and the IBM Plex type system doing the work. Ships dark, with a light mode in the theme's gear (Appearance: Dark/Light). No tex
