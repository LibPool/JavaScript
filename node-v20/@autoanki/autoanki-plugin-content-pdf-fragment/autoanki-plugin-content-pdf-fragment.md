# @autoanki/autoanki-plugin-content-pdf-fragment

> 标签: anki, autoanki, autoanki-content-plugin, pdf

## 简介

This plugin injects the necessary JavaScript to dynamically render PDF (fragments) referenced inside Anki notes.
