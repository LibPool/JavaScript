# dsh-context-explorer

> 标签: context, deepseek-harness, dsh, dsh-plugin, plugin, token, web-ui

## 简介

See the context a Session submits to its model in the DeepSeek Harness Web UI: the system prompt, the tool schemas and every message, drawn as a grid of token squares.
