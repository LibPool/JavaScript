# @firevibe/vite-tanstack-config

> 标签: JavaScript

## 简介

The Vite configuration every FireVibe-generated app uses: TanStack Start, React, Tailwind v4, Cloudflare Workers, and the sandbox dev-server contract, in one versioned place.
