# @ch2lab/opencode-goals

> 标签: JavaScript

## 简介

OpenCode v2 goal-loop plugin: set a goal, the model works autonomously toward evidence-gated completion — wake-on-boundary loop, stall arbitration, opt-in budget caps, built for unattended long-running tasks
