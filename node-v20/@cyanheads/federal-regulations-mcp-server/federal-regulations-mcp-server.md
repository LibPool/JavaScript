# @cyanheads/federal-regulations-mcp-server

> 标签: administrative-law, cfr, ecfr, federal-register, mcp, mcp-server, model-context-protocol, regulations, regulations-gov, rulemaking, stdio, streamable-http

## 简介

Search and trace US federal rules across the Federal Register (proposed/final rules and notices), the eCFR (codified, point-in-time CFR full text, locally mirrored), and Regulations.gov (rulemaking dockets and public comments) via MCP. STDIO or Streamable
