# @cyanheads/chembl-mcp-server

> 标签: ai-agent, bioactivity, bun, chembl, cheminformatics, compounds, drug-discovery, mcp, mcp-server, medicinal-chemistry, model-context-protocol, protein-targets, stdio, streamable-http, typescript

## 简介

Link compounds to protein targets, rank bioactivity (IC50/Ki/EC50), and look up drug mechanisms and indications over ChEMBL via MCP. STDIO or Streamable HTTP.
