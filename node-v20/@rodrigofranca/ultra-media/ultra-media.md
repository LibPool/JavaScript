# @rodrigofranca/ultra-media

> 标签: JavaScript

## 简介

Web Component moderno para reprodução de vídeos em múltiplos formatos (HLS, MP4, DASH), construído sobre `super-media-element`, com auto detecção de formato e suporte a build ESM/CDN.
