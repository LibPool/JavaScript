# @stdlib/ndarray-base-to-flippedlr

> 标签: base, data, flip, matrix, ndarray, numpy.fliplr, reverse, slice, stdlib, stdtypes, structure, types, vector, view

## 简介

Return a new ndarray where the order of elements along the last dimension of an input ndarray is reversed.
