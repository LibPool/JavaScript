# @stdlib/stats-base-ndarray-dstdevyc

> 标签: deviation, dispersion, double, double-precision, dstdev, float64, float64array, math, mathematics, ndarray, sample standard deviation, spread, standard deviation, statistics, stats, std, stdlib, stdmath, typed, unbiased, var, variance

## 简介

Compute the standard deviation of a one-dimensional double-precision floating-point ndarray using a one-pass algorithm proposed by Youngs and Cramer.
