# @stdlib/math-base-special-kernel-log1p

> 标签: kernel, log, logarithm, math, mathematics, stdlib, stdmath

## 简介

Evaluate a correction term for double-precision base-2 and base-10 logarithms when 1+f is in [√2/2, √2].
