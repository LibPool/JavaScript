> 标签: arithmetic mean, array, average, avg, central tendency, math, mathematics, mean, statistics, stats, stdlib, stdmath, strided, strided array

## 简介

Calculate the arithmetic mean of a strided array using a second-order iterative Kahan–Babuška algorithm.
