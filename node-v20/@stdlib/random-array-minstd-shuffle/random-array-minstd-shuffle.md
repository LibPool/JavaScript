# @stdlib/random-array-minstd-shuffle

> 标签: array, bays, durham, generator, lcg, lehmer, math, mathematics, miller, minstd, park, prng, pseudorandom, rand, randi, randint, random, randu, rng, seed, seedable, shuffle, shuffled, statistics, stats, stdlib, stdmath, vector

## 简介

Create an array containing pseudorandom numbers generated using a linear congruential pseudorandom number generator (LCG) whose output is shuffled.
