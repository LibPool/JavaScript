# @stdlib/iter-fill

> 标签: fill, iterable, iterate, iterator, overwrite, replace, stdlib, stdutil, stdutils, subseq, subsequence, util, utilities, utility, utils

## 简介

Create an iterator which replaces all values from a provided iterator from a start index to an end index with a static value.
