# @stdlib/blas-ext-base-dnancusumkbn

> 标签: accumulate, array, blas, compensated, cumulative, double, extended, float64, float64array, kahan, kbn, math, mathematics, statistics, stats, stdlib, stdmath, strided, strided array, sum, summation, total, typed

## 简介

Calculate the cumulative sum of double-precision floating-point strided array elements ignoring NaN values and using an improved Kahan–Babuška algorithm.
