# @stdlib/ndarray-base-broadcast-scalar-like

> 标签: base, broadcast, convert, data, ndarray, scalar, stdlib, stdtypes, structure, types, wrap

## 简介

Broadcast a scalar value to an ndarray having the same shape and data type as a provided input ndarray.
