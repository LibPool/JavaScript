# @stdlib/utils-reduce2d

> 标签: accumulate, accumulation, accumulator, aggregate, array, array-like, array.reduce, collection, iterate, matrix, reduce, reducer, reduction, stdlib, stdutil, stdutils, typed, typed array, typed-array, util, utilities, utility, utils

## 简介

Reduce the number of dimensions by one of a two-dimensional nested array by applying a function against an accumulator and each element along the innermost dimension and returning the accumulation results as a one-dimensional array.
