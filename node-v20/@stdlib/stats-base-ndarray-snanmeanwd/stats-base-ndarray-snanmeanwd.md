# @stdlib/stats-base-ndarray-snanmeanwd

> 标签: arithmetic mean, average, avg, central tendency, math, mathematics, mean, ndarray, statistics, stats, stdlib, stdmath

## 简介

Compute the arithmetic mean of a one-dimensional single-precision floating-point ndarray, ignoring `NaN` values and using Welford's algorithm.
