# @sprinklrjs/integration-sdk

> 标签: JavaScript

## 简介

Sprinklr Integration SDK is a TypeScript SDK that enables seamless communication between Sprinklr's agent interface and third-party applications. It provides a bridge for accessing agent status information, managing cases, and controlling agent workflows
