# @gr4vy/poutine-tokens

> 标签: JavaScript

## 简介

Poutine tokens contains all of the design tokens for building interfaces at Gr4vy. These are platform agnostic and exported to common formats, e.g. SCSS variables, CSS, JSON and ES6.
