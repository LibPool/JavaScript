# @vibekast/sdk

> 标签: agents, ai-agents, base, elizaos, forecasting, lmsr, mcp, prediction-market, sdk, vibekast

## 简介

TypeScript SDK for VibeKast weekly BTC distribution markets on Base Sepolia: read markets and trades, build orders, and trade from your own wallet.
