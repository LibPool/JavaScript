# @chrono-os/cron-guard

> 标签: chrono-os, cron, nestjs, nextjs, timing-safe, vercel-cron

## 简介

Proteção de rota de cron por segredo compartilhado: comparação timing-safe (sha256 + timingSafeEqual), fail-closed sem segredo configurado, helper para route handler do Next.js e CronAuthGuard para Nest em entry separado.
