# @ghostmind-dev/agent

> 标签: agent, agent-skills, budget, cli, hooks, jev, llm, mcp, openrouter, tool-loop, typesafe

## 简介

The agent engine every app builds its own agent from: the tool loop and its guards, a model seam (OpenRouter + Jev), the Jev guide, budgets with a USD cap, go/pause/stop hooks, and an append-only event log. A library, plus the `agento` command line to try
