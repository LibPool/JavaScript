# @ghostmind-dev/agento

> 标签: acp, agent, agent-client-protocol, agent-skills, budget, cli, hooks, jev, llm, mcp, openrouter, tool-loop, typesafe

## 简介

agento: the agent engine (tool loop and guards, Jev as the guide, USD budgets, go/pause/stop hooks, an append-only event log) as a library, plus the `agento` command: a terminal agent that also runs in editors and chats over the Agent Client Protocol.
