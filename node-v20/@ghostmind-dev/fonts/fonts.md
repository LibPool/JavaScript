# @ghostmind-dev/fonts

> 标签: animation, font, handwriting, hershey, single-stroke, sketch, stroke-font, svg

## 简介

Single-stroke handwriting fonts as pen-stroke data: characters stored as the path a pen travels, so a renderer can write them stroke by stroke.
