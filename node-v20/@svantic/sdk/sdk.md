# @svantic/sdk

> 标签: a2a, agent, ai, mesh, sdk, svantic, telemetry

## 简介

Svantic SDK — A2A agent framework. Turns any Node.js app into an A2A-compliant agent. Optional mesh integration via @svantic/sdk/mesh.
