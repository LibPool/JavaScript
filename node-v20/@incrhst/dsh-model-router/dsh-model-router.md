# @incrhst/dsh-model-router

> 标签: cost-optimization, deepseek, dsh, harness, llm, model, router

## 简介

Routes each DSH agent request to the least powerful model that can handle it — flash for simple work, pro for complex, vision for images — with a settings page and live composer readout.
