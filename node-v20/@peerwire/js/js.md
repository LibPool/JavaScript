# @peerwire/js

> 标签: multiplayer, nostr, p2p, rooms, wasm, webrtc

## 简介

Peer-to-peer rooms for the browser and Node with no backend: the Peerwire core as a zero-import wasm, WebRTC DataChannels and Nostr signaling.
