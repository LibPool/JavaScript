# @aeranko/ship

> 标签: aeo, ai-search, crawlers, express, geo, gptbot, nextjs, observability

## 简介

Drop-in AI crawler tracking and AEO telemetry for Node.js apps. Ships data to Aeranko for AI-visibility analytics.
