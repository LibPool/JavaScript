# @quran-cli/q-cli

> 标签: audio, cli, mp3, mpv, quran, radio, recitation

## 简介

A simple command line interface for listening to Quran. ## Used API [mp3quran](https://mp3quran.net/eng/api) ## Installation - `npm install` - Install **mpv** as it is required for playing the audio.   - Debian based distributions `sudo add-apt-repository
