# @creator-notes/cnotes-darwin-x64

> 标签: JavaScript

## 简介

cnotes standalone binary for darwin-x64. Fetched by the installer at https://creatornotes.app/install.sh — install the CLI with that script or `npm i -g @creator-notes/cnotes`, not by depending on this package.
