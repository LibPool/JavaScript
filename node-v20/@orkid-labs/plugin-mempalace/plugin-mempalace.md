# @orkid-labs/plugin-mempalace

> 标签: elizaos, mcp, memory, mempalace, persistent, plugin

## 简介

Persistent agent memory via MemPalace MCP — store, search, and recall context across sessions. Supports stdio and HTTP/SSE transports.
