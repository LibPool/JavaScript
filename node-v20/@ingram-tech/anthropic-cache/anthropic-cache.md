# @ingram-tech/anthropic-cache

> 标签: ai-sdk, anthropic, bedrock, claude, middleware, prompt-caching, vercel-ai

## 简介

Automatic Anthropic prompt caching for the Vercel AI SDK: one middleware places the cache_control breakpoints on every request. Works on Bedrock too.
