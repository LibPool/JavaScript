# @ingram-tech/nk-db

> 标签: JavaScript

## 简介

The Ingram Postgres data layer: one TLS-aware pg pool, raw-SQL helpers, Drizzle wiring, and a PGlite (no-Docker) dev/test harness for Next.js sites.
