# @humanfriend22/is-safari

> 标签: JavaScript

## 简介

A dedicated package to check if the browser is running Safari (webkit) via the [user agent](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/User-Agent).
