# @warda_protocol/verify

> 标签: agent, covenant, kaspa, spending-limits, verification, warda

## 简介

An HTTP endpoint that answers a counterparty's question about a Warda grant: are these terms real, where did the grant go, and what would the covenant refuse right now. Reads a node, decides nothing.
