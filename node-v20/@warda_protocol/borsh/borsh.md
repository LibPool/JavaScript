# @warda_protocol/borsh

> 标签: agent-payments, borsh, covenant, kaspa, resolver, utxo, wrpc

## 简介

Kaspa over borsh wRPC — the encoding the public resolvers actually serve. Reads the UTXO set, and submits covenant-carrying transactions through a build that has them, so neither side of a Warda payment needs a node.
