# @spicyapi/skill

> 标签: JavaScript

## 简介

Operate the SpicyAPI developer API from a coding agent: inspect live models and prices, create and wait for media tasks, upload inputs, retrieve results, and verify webhooks — through the official SDK, CLI, or MCP server.
