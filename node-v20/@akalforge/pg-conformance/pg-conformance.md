# @akalforge/pg-conformance

> 标签: conformance, diff, fingerprint, migration, postgres, postgresql, schema

## 简介

A PostgreSQL schema fingerprint and DDL conformance corpus, shared by tools that need to agree on whether two schemas are the same.
