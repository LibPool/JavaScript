# @nudata/nu-duck-df

> 标签: JavaScript

## 简介

A framework-agnostic in-browser analytics stack built on [DuckDB-wasm](https://duckdb.org/docs/api/wasm/overview). Query engine, notebook, DataFrame API — no server, no framework lock-in.
