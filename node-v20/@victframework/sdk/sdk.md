# @victframework/sdk

> 标签: JavaScript

## 简介

Stable, schema-library-neutral authoring ABI for Vict: contracts, capabilities, graphs, capability packs, applications, resources and releases. Optional Zod adapter under ./zod. Has NO dependency on the runtime.
