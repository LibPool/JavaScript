# @groupdocs/groupdocs.redaction

> 标签: annotation, docx, gdpr, groupdocs, groupdocs-redaction, java, metadata, nodejs, pdf, pptx, privacy, redact, redaction, xlsx

## 简介

Document redaction API for Node.js (powered by Java). Permanently remove or mask sensitive text, metadata, annotations, and image areas from PDF, Office, and image files.
