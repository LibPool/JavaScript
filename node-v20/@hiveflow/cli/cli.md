# @hiveflow/cli

> 标签: agent, agentic, ai, aider, claude, cli, codex, gemini, hiveflow, mcp, orchestrator, tool-use

## 简介

🐝 Hiveflow CLI — orchestrates AI coding CLIs (Claude Code, Gemini, Codex, Aider) with task-type router + embedded native agent with own tool-use loop (read/write/edit/bash/web/grep/glob/subagent, permissions, sessions, hooks, skills, MCP)
