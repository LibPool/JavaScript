# @factorial/stack-images

> 标签: JavaScript

## 简介

This is the Image plugin for `@factorial/stack-core`. It uses [@squoosh/lib](https://github.com/GoogleChromeLabs/squoosh/tree/dev/libsquoosh) under the hood.
