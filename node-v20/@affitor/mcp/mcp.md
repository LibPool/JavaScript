# @affitor/mcp

> 标签: affiliate, affitor, agent, ai, claude, cursor, mcp, model-context-protocol, tracking

## 简介

Model Context Protocol (MCP) stdio server for Affitor. Lets AI agents (Claude Desktop, Cursor and more) call Affitor affiliate-tracking tools.
