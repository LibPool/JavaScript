# @kinsh/vodozemac-rn

> 标签: android, crypto, e2ee, ios, olm, react-native, turbomodule, vodozemac

## 简介

React Native bindings for vodozemac (Olm + Megolm primitives) via UniFFI-generated Swift + Kotlin. Drop-in replacement for @kinsh/vodozemac-wasm on the RN target — same JS surface, same JSON shapes.
