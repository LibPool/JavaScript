# @rashidazarang/metamcp

> 标签: agent, ai, automation, claude, llm, mcp, mcp-orchestration, mcp-server, meta-mcp, model-context-protocol, tool-routing

## 简介

A meta-MCP server that collapses N child MCP servers into 4 tools. Intent routing, lazy spawning, connection pooling, and sandboxed code execution.
