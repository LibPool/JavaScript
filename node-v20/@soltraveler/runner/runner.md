# @soltraveler/runner

> 标签: JavaScript

## 简介

Standalone, headless PM Cockpit runner — executes cloud-dispatched subscription sorties on your own Codex CLI. No desktop app, no SQLite, no repo clone. Outbound HTTPS only.
