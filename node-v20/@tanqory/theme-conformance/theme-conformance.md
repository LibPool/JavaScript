# @tanqory/theme-conformance

> 标签: conformance, storefront, tanqory, testing, theme, workerd

## 简介

Conformance runner for Theme ABI v2 — boots a theme artifact under workerd with a host shim, runs the contract's nine suites (conformance-report.json) and the storefront / budgets tiers (storefront-report.json).
