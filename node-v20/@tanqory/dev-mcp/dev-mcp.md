# @tanqory/dev-mcp

> 标签: claude-code, codex, mcp, model-context-protocol, storefront, tanqory, theme

## 简介

Local MCP server (stdio) for building Tanqory storefront themes with coding agents: versioned docs and schemas, kit examples, section scaffolding, theme checks, and pages and screenshots of the running dev server.
