# @vertexa/prisma-client

> 标签: CockroachDB, GIS, GeoJSON, JS, JavaScript, MSSQL, MariaDB, MongoDB, MySQL, ORM, PostGIS, PostgreSQL, Postgres, Prisma, Prisma Client, SQL, SQL Server, SQLServer, SQLite, TS, TypeScript, client, database, db, fork, geography, geometry, pg, prisma2, query, query-builder, spatial, vertexa

## 简介

Fork of Prisma Client — auto-generated, type-safe ORM for Node.js with PostGIS support. Adds Geometry/Geography scalar types, spatial query filters (near, within, intersects, distanceFrom), and GeoJSON serialization for PostgreSQL.
