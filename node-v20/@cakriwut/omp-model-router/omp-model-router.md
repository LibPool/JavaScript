# @cakriwut/omp-model-router

> 标签: ai, cost-optimization, extension, llm, model-router, oh-my-pi, omp, routing, toon-compression

## 简介

Cost-optimized model routing for Oh-My-Pi — routes prompts to cheap/mid/expensive models based on task complexity. Tracks per-turn and session costs. Uses TOON compression for conversation history optimization.
