# @blackwood-state/mcp

> 标签: ai-agents, base, crypto, mcp, onchain, pay-per-call, usdc, x402

## 简介

Blackwood State tools for AI agents over MCP: pay-per-call APIs (USDC on Base over x402) with a free starting credit, a spend cap per call and per day, and payment built in.
