# @intlayer/svelte-compiler

> 标签: compiler, hmr, i18n, internationalization, intlayer, svelte, typescript, vite

## 简介

Vite-compatible compiler plugin for Svelte with Intlayer, providing HMR support, file transformation, and optimized dictionary loading for Svelte applications.
