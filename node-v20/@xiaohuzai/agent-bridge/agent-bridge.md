# @xiaohuzai/agent-bridge

> 标签: acp, agent, agent-client-protocol, bridge, byok, claude, cli, codex, gateway, local-llm, sse

## 简介

Local daemon that turns CLI coding agents (codex, claude code, … any ACP agent) into an HTTP+SSE chat backend any client can drive — plus opt-in ACP doors: a WebSocket endpoint for ACP clients and a spawnable stdio agent mode. Zero dependencies.
