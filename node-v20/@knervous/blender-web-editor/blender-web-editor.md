# @knervous/blender-web-editor

> 标签: babylon-lite, babylonjs, blender, editor, threejs, webassembly

## 简介

An editor HUD on @knervous/blender-web: mounts over a Babylon.js, Babylon Lite or three.js scene and drives Blender (WebAssembly) from it, with a swap to the full Blender UI.
