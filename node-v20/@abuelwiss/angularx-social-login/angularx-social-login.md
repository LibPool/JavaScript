# @abuelwiss/angularx-social-login

> 标签: amazon-authentication, angular, angular-social-login, angular19, facebook-authentication, google-authentication, social-authentication, social-login

## 简介

Social login and authentication module for Angular 19. Supports authentication with Google, Facebook, Amazon, and VK. Can be extended to other providers also. THis package is forked and upgraded from @abacritt/angularx-social-login
