# @freeappstore/sdk

> 标签: api-key, auth, cloudflare-workers, freeappstore, github-oauth, kv, proxy, rooms, sdk, websocket

## 简介

Browser SDK for apps on freeappstore.online — auth, per-user KV, shared counters, document collections, real-time rooms, API proxy, user API key vault, RBAC roles, React hooks, and 18 UI components.
