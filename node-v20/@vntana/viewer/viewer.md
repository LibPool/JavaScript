# @vntana/viewer

> 标签: 3d-model, 3d-viewer, ar, augmented-reality, custom-element, ecommerce, glb, gltf, product-visualization, threejs, web-component, webgl, webxr

## 简介

A web component for rendering interactive 3D models with augmented reality support, built on Three.js. Loads glTF/GLB files directly in the browser.
