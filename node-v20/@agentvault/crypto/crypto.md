# @agentvault/crypto

> 标签: JavaScript

## 简介

Shared cryptographic primitives and telemetry types for the [AgentVault](https://agentvault.chat) ecosystem. Used by `@agentvault/agentvault`, `@agentvault/client`, and the Expo web app.
