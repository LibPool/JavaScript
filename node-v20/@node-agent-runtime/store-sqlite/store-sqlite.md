# @node-agent-runtime/store-sqlite

> 标签: agent, node-agent-runtime, persistence, sqlite, storage

## 简介

C9 optional Storage backend of the Agent runtime: SQLiteStorage implementing the core Storage trait via node:sqlite (bundled with Node, no third-party native deps). Deliberately kept out of the core dependency graph.
