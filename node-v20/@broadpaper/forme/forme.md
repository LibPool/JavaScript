# @broadpaper/forme

> 标签: broadpaper, browserless, document-generation, pdf, pdf-generation, report, report-designer, reporting, serverless, wasm, webassembly

## 简介

Browserless PDF backend for BroadPaper, built on the Forme (Rust/WASM) engine. Runs in Node, edge runtimes and the browser.
