# @augmem/cortext-pi-extension

> 标签: compaction, cortext, memory, pi, pi-coding-agent, pi-extension, pi-package

## 简介

Cortext memory for the pi coding agent: per-session-isolated durable memory, live per-turn recall, zero-LLM-call compaction, and a streaming interrupt gate.
