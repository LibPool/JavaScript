# @layermetry/video-editor

> 标签: ai-assistant, captions, editor-sdk, embeddable, gif, layermetry, mp4, react, srt, subtitles, svelte, timeline, typescript, video-editing, video-editor, video-editor-sdk, video-export, voiceover, vue, web-component, webcodecs, webm, white-label

## 简介

Embeddable video editor SDK for web apps: timeline, captions and subtitles, animations, voice-over, AI assistant, and in-browser export to MP4, WebM and GIF with WebCodecs (no FFmpeg). React, Vue, Svelte or plain JavaScript.
