# @ordinal402/ordinal-mcp

> 标签: agent-payments, mcp, ordinal, robinhood-chain, x402

## 简介

Local MCP bridge to the Ordinal marketplace. Pays for x402 service calls from your own wallet — the private key signs locally and never leaves your machine.
