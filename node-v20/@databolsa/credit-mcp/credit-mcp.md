# @databolsa/credit-mcp

> 标签: credit, credito-privado, databolsa, fidc, mcp, model-context-protocol

## 简介

Servidor MCP da mesa de crédito do DataBolsa (Credit Desk) — tools geradas a partir do contrato OpenAPI do Credit. Autentica com a chave pessoal (db_live_...).
