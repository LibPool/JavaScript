# @vel4ai/ai-sdk

> 标签: JavaScript

## 简介

`@vel4ai/ai-sdk` is an optional AI SDK adapter for Vela. It keeps `@vel4ai/sdk` framework-agnostic while collecting the repeated AI SDK wiring needed in chat routes.
