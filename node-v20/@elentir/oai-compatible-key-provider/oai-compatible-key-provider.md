# @elentir/oai-compatible-key-provider

> 标签: JavaScript

## 简介

OpenCode plugin: multi-key LLM rotation, budget rollover, auth.json sync. Replaces the legacy provider-factory entry point to bypass opencode's racy Npm.add path.
