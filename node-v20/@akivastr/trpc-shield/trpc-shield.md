# @akivastr/trpc-shield

> 标签: authorization, middleware, permissions, rbac, shield, trpc

## 简介

Lightweight, type-safe permission middleware for tRPC v11 routers — gate any procedure, at any nesting depth, by a rules object shaped like your router.
