# @hoodag/sdk

> 标签: ens, ethereum, hood, name-service, resolver, robinhood-chain, viem, web3

## 简介

Resolve .hood names on Robinhood Chain (ENS-standard) — one call, ENSIP-15 name normalization, optional viem helpers.
