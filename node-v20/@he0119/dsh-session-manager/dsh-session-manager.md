# @he0119/dsh-session-manager

> 标签: deepseek-harness, dsh, dsh-plugin, migration, relocate, session, workspace

## 简介

DSH 的会话管理插件：设置里的一页，用来导出/导入 .dshsess 会话包，以及把工作区与会话迁移到新目录——改写会话日志 cwd、迁移日志目录、重挂工作区归属，并可选择性搬迁会话创建的文件。
