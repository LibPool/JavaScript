# @rasmx/hash

> 标签: hash, keccak, performance, rust, sha256, sha3, streaming, wasm, xxhash

## 简介

Blazing fast WASM hashing library powered by Rust. Support for SHA2, SHA3, Keccak, XXHash, and MD5 with streaming support.
