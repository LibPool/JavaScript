> 标签: gettext, i18n, internationalization, l10n, localization, mo-parser, nextjs-i18n, plural, po-parser, react-gettext, sprintf, translation, typescript, wordpress, wordpress-i18n

## 简介

High-performance, zero-dependency universal gettext i18n library for React, Next.js, Node.js, and all JavaScript frameworks with complete WordPress function parity, safe AST plural evaluator, PO/MO/JSON parsers, and JSX interpolation.
