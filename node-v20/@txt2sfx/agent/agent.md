# @txt2sfx/agent

> 标签: JavaScript

## 简介

The LLM half of the pipeline: providers, the system prompt built from the live grammar tables, and the generate-validate-render-optimize loop. Zero runtime dependencies — providers speak HTTP through `fetch`.
