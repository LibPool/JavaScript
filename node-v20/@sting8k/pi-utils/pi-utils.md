# @sting8k/pi-utils

> 标签: pi-coding-agent, pi-extension, pi-package

## 简介

Utility extensions for the Pi coding agent: deep fs-search (grep/glob), background shell (shell-bg), script-mode edit, and the skills write layer (skill_write)
