# @chirag127/tokens

> 标签: css-variables, design-system, design-tokens, framework-agnostic, theme

## 简介

Framework-agnostic design tokens: shared primitives + per-archetype identity palettes (editorial, marketing, dashboard, docs). Pure CSS — works in Astro, Next.js, React, Vue, Svelte, or plain HTML.
