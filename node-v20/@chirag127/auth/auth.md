# @chirag127/auth

> 标签: auth, clerk, design-system, framework-agnostic, island, oriz, react

## 简介

Clerk auth adapter for oriz family sites. Drop-in React island — ClerkProvider wrapper, sign-in/out buttons, account panel, and useOrizAuth hook. Unstyled with data-oriz-auth-* hooks so each site themes it.
