# @amd-gaia/gaia

> 标签: agent, amd, gaia, local-llm, privacy, ryzen-ai, sidecar, tui

## 简介

One command to run GAIA: fetches and SHA-256 verifies the flagship agent sidecar and the terminal UI, then launches them. Runs 100% locally on AMD Ryzen AI.
