# @mattuy/text-frame

> 标签: Chinese, canvas, text pagination, typesetting, 中文, 分页, 排版禁则, 文本排版

## 简介

a javascript tool to split long text into pages, with typesetting prohibition processed and unicode full support.
一个将长文本分成若干页的js工具，处理排版禁则，支持Unicode
