# @easyfe/web-request

> 标签: axios, refresh token, 请求取消, 请求合并, 请求重试, 防抖节流

## 简介

基于axios扩展的请求库，支持取消重复请求、请求节流、请求队列等待、请求重试，支持自定义拦截器
