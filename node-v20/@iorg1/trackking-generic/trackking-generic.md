# @iorg1/trackking-generic

> 标签: analytics, cookieless, events, gdpr, privacy, server-side, tracking

## 简介

Framework-agnostic, server-side event tracking for Trackking. Call track() from any Node backend to record manual events (e.g. "preview-generated") — no cookies, no client-side script.
