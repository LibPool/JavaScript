# @telenotify/node

> 标签: amharic, ethiopia, notifications, otp, phone verification, sdk, sms, telegram, telegram-bot, typescript, webhooks

## 简介

Official Node.js and TypeScript client for the Telenotify API: Telegram notifications and phone verification with an instant fallback signal.
