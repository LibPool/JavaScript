# @generativereality/review-md

> 标签: ai-agents, claude-code, documentation, html, markdown, mermaid, pdf, static-site

## 简介

Markdown → one self-contained styled HTML file (and a sane PDF). Build-time mermaid→inline-SVG, glyph callouts, footnote-integrity checking, jump rail, print stylesheet, pack manifests. Repo-agnostic CLI + Claude Code plugin.
