# @wiltech-labs/ngx-styles

> 标签: JavaScript

## 简介

Shared Material 3 Sass partials — breakpoints, spacing scale, and design-system mixins (page-title, banner, state-layer, focus-ring, ...) that read --mat-sys-* tokens. Raw .scss, no compile step.
