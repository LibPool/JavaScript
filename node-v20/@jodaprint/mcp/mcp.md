# @jodaprint/mcp

> 标签: ai, claude, jodaprint, label, llm, mcp, model context protocol, pos, print, receipt

## 简介

MCP server for JodaPrint: let AI assistants and agents (Claude, Cursor, …) list printers, print receipts, labels and documents, and follow print jobs.
