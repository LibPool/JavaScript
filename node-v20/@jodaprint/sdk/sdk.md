# @jodaprint/sdk

> 标签: browser, cash drawer, escpos, jodaprint, label printer, pdf, pos, print, receipt, silent printing, thermal printer, zpl

## 简介

Print silently from any web page to local printers (receipts, labels, PDF) through the JodaPrint agent. No print dialog, works offline.
