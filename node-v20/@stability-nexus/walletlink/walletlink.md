# @stability-nexus/walletlink

> 标签: eip-1193, eip-6963, ethereum, evm, viem, wagmi, wallet

## 简介

A small, SaaS-free library to connect frontends to EVM wallets using EIP-1193 + EIP-6963 (no WalletConnect relay, no projectId).
