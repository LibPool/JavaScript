# @xiaobanli/dsh-compact-after-task

> 标签: compaction, context, cordis, deepseek, dsh, dsh-plugin, harness

## 简介

Auto-compact a DSH conversation after the current task finishes, at a user-set context threshold. Volatile Config fields + a dedicated card in Settings -> Plugins.
