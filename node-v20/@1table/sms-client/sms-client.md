# @1table/sms-client

> 标签: 1table, client, microservice, sdk, sms

## 简介

HTTP 客户端 SDK，用于调用短信微服务（发送模板短信、批量发送、按网关发送）

## 官网

- npm 页面：https://www.npmjs.com/package/@1table/sms-client

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install @1table/sms-client`
- npm registry：https://registry.npmjs.org/@1table/sms-client
- Node 要求：>=14
