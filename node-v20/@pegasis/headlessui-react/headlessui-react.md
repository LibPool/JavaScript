# @pegasis/headlessui-react

> 标签: JavaScript

## 简介

A set of completely unstyled, fully accessible UI components for React, designed to integrate beautifully with Tailwind CSS.

- 源码仓库：git+https://github.com/tailwindlabs/headlessui.git
