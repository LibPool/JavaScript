# @voxell/forge-mcp

> 标签: embeddings, forge, mcp, rag, vector, voxell

## 简介

MCP server for Forge — Voxell's text-embedding API (turbo→ultra; ultra = Qwen3-Embedding-8B, ~75+ avg MTEB). embed + list_models for semantic search & RAG.
