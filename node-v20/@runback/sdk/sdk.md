# @runback/sdk

> 标签: ai-agents, audit, compliance, eu-ai-act, evals, governance, llm, observability, policy-enforcement, replay, runback, tracing, vercel-ai-sdk

## 简介

Capture, replay, and audit every AI agent decision. Auto-instruments the Vercel AI SDK; a generic recorder (@runback/sdk/core) can be called manually from LangChain, OpenTelemetry, or any other agent framework's own hooks.
