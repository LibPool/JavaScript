# @misardev/cli

> 标签: ai-app-builder, app-builder, chat-completions, cli, code-search, command-line, deploy, hosting, misar, misardev, openai-compatible, projects, sse, templates

## 简介

Misar.Dev from the terminal: every API route as a command — create, build and deploy projects, write files, manage domains and env vars, start from templates, search code, stream chat completions. Plan refusals render as an upgrade card.
