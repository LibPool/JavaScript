# @openclaw-cloud/mcp-proxy

> 标签: mcp, openclaw, proxy, stdio, streamable-http

## 简介

Stdio-to-HTTP bridge for MCP servers. Lets stdio-only MCP clients (OpenClaw, Claude Desktop) connect to remote Streamable HTTP MCP servers.
