# @hackthedev/dsync-auth

> 标签: JavaScript

## 简介

`dSyncAuth ` is an addition to `dSync` that uses `dSyncSign` to create random encrypted challenges and checks if the decrypted response from a user is correct. It also requires `epxress`.
