# @gz2016/dsh-plugin-insight-mode

> 标签: deepseek-harness, dsh, dsh-plugin, insight, master-worker, research, subagent

## 简介

Master/worker deep-research architecture: the top-level agent clarifies your request, gets your approval on a task breakdown and operating budget, then dispatches independent parallel worker subagents until the report is done.
