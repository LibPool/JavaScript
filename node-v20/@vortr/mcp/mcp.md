# @vortr/mcp

> 标签: 0x, ai-agent, base, defi, dex, mcp, model-context-protocol, non-custodial, swap, vortr

## 简介

Vortr MCP — non-custodial DeFi swap tools on Base for AI agents (search tokens, 0x quotes, ERC-5792 approve+swap calldata). Your agent signs + sends the ERC-5792 payload with its own wallet, or runs the @vortr/wallet local signer for autonomous execution;
