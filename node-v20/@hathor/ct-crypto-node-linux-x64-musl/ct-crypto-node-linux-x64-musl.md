# @hathor/ct-crypto-node-linux-x64-musl

> 标签: confidential-transactions, hathor, napi, pedersen, range-proofs, secp256k1

## 简介

Hathor confidential transaction cryptography — NAPI native addon for Node.js. Implements @hathor/ct-crypto-provider's IShieldedCryptoProvider via the './provider' subpath. Mobile lives in @hathor/ct-crypto-mobile.
