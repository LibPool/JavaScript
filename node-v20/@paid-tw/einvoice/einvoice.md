# @paid-tw/einvoice

> 标签: e-invoice, einvoice, fapiao, invoice, taiwan, 電子發票

## 简介

Provider-agnostic core for Taiwan e-invoice: unified types, InvoiceProvider interface, validation schemas, and a MockProvider.
