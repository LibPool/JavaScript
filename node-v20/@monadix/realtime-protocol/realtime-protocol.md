# @monadix/realtime-protocol

> 标签: a2a, monadix, protocol, realtime, supabase

## 简介

Monadix collaboration-network realtime protocol: channel/event names and payload schemas shared by the API, the web/desktop clients, and third-party providers (e.g. monad).
