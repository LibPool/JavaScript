# @wdio/dioxus-bridge

> 标签: automation, dioxus, testing, wdio, webdriverio

## 简介

Guest-side JS bundle for the wdio-dioxus-bridge Rust crate. Installs window.__WDIO_DIOXUS__.invoke for use by @wdio/dioxus-service.
