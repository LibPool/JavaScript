# @cotera/griddle

> 标签: data-grid, datagrid, duckdb, duckdb-wasm, griddle, parquet, react, table, virtualized

## 简介

A batteries-included React data grid that joins multiple data sources into one view — DuckDB-wasm, HTTP and in-memory adapters, themeable, with component override slots.
