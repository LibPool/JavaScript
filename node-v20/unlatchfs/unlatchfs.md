# unlatchfs

> 标签: claude-code, codex, file-provider, finder, fuse, remote-development, ssh, sync, vm

## 简介

Your cloud VM's files in macOS Finder, as snappy as a local folder, for people who run Claude Code or Codex on remote VMs. Pre-release: the Linux VM daemon and Linux FUSE client work; the Mac app is not published yet.
