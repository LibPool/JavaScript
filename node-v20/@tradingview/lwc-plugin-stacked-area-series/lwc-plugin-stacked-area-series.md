# @tradingview/lwc-plugin-stacked-area-series

> 标签: lightweight-charts, lightweight-charts-plugin, lwc-plugin

## 简介

Area series that stacks several values per time point into cumulative bands. Useful for composition-over-time views such as portfolio allocation.
