# @yangzhe1991/dsh-code-review

> 标签: code-review, deepseek-harness, diff, dsh, plugin, web

## 简介

DSH Web 插件:git diff 一键打开独立双列 Code Review 页,支持语法高亮、行内评论与中英双语;对话中的本地 .diff/.patch 路径自动变成一键查看按钮 | DSH web plugin: one-click standalone two-column code review page for git diff with syntax highlighting, inline comments & bilingual UI; local .diff/.patch paths
