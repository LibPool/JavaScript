# @sweberdev/sigmoid

> 标签: animation, easing, linear-easing, parallax, reduced-motion, reveal, scroll, scroll-driven-animations, scroll-timeline, spring, tailwindcss, view-timeline

## 简介

Scroll motion without the JavaScript tax: native CSS scroll-driven animations, spring and S-curve easings as CSS linear(), a tiny fallback, reduced motion by default.
