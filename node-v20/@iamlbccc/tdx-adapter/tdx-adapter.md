> 标签: acp, adapter, agent, paperclip, tdx

## 简介

TDX-Adapter — Paperclip external adapter: bridges mature ACP agents (opencode) via TDX-Daemon (NDJSON streaming, session continuity, usage metering, permission approval). 与 @iamlbccc/tdxd 同版本线配套发布
