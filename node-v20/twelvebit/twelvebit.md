# twelvebit

> 标签: agents, analytics, cli, mcp, tracking-plan, twelvebit

## 简介

Set up twelvebit analytics from the terminal: device sign-in, tracking plan (analytics.yaml), validate, browser and server codegen, drift check, link, integrations status, exclusions, agent skills and MCP setup.
