# @dappql/mcp

> 标签: ai-agents, claude, cursor, dappql, mcp, model-context-protocol, smart-contracts, viem, wagmi

## 简介

MCP server exposing a DappQL project to AI coding agents — contract introspection, multicall reads, write simulation, and optional gated write execution.
