# @2018kguo/zapcode

> 标签: agent, agents, code-mode, interpreter, sandbox, tool-use, typescript

## 简介

Sandboxed TypeScript interpreter for running model-written code: suspend/resume tool calls, durable snapshots and sessions, typecheck and dry runs
