# @barrierenlos/docusaurus-prerender-mermaid

> 标签: docusaurus, docusaurus-plugin, mermaid, prerender, static, svg

## 简介

A Docusaurus plugin to pre-render Mermaid diagrams into static images (SVG or PNG) at build time, with support for light/dark themes.
