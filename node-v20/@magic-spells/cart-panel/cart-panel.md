# @magic-spells/cart-panel

> 标签: a11y, accessibility, cart-item, cart-panel, custom-elements, dialog, e-commerce, modal, shopify, shopping-cart, web-components

## 简介

Shopping cart panel web component for Shopify. Manages cart data and AJAX, delegates modal behavior to dialog-panel. The root import registers the panel and the cart item; each is also available on its own subpath.
