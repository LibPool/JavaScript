> 标签: api-gateway, colombia, conecta, insurance, n8n, n8n-community-node-package, seguros-bolivar

## 简介

n8n community node to consume Conecta 2.0 API Gateway services from Seguros Bolivar (Colombia). The service catalog is loaded dynamically from the Conecta developer portal.
