# @trevixal/extension-blocks

> 标签: callout, columns, editor, extension, footnote, rich-text, rich-text-editor, toggle, trevixal, typescript, wysiwyg

## 简介

Structural blocks for the Trevixal editor: callouts, toggles, columns, cards, timelines, page breaks, badges, buttons, footnotes and anchors.
