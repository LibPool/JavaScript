# @scaleflex/bulk-edit

> 标签: JavaScript

## 简介

Standalone bulk metadata editor for Scaleflex DAM — pick fields, apply SET/ADD/DELETE across many assets, preview diffs. Built on @scaleflex/dam-metadata; embeddable without the uploader.
