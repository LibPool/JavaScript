# @scaleflex/dam-core

> 标签: JavaScript

## 简介

Headless, framework-agnostic foundation for Scaleflex DAM widgets: auth, REST client, domain types, browse store, and CDN/thumbnail URL helpers. No UI, no Lit, no React — Fetch only.
