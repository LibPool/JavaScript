# @scaleflex/dam-ui

> 标签: JavaScript

## 简介

Shared Lit UI layer for Scaleflex DAM widgets: theme tokens (--sfx-*), brand-color, an i18n factory, and reusable style fragments. Phase 3b adds the sfx-* primitive elements.
