# @cardenelabs/dragon

> 标签: animation, diagram, dragon, mermaid-alternative, svg-animation, text-dsl

## 简介

Dragon — 動く図を、人は行ごとの記法で、AI は JSON で書く。時系列図と構成図を段ごとに動かし、mp4・GIF・HTML・PNG に書き出す。
