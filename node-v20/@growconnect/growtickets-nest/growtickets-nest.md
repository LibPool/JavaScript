# @growconnect/growtickets-nest

> 标签: JavaScript

## 简介

GrowTickets para NestJS (Express o Fastify): el proxy que guarda la clave de API y reenvía a api/ingest por una lista blanca de 9 rutas, y la seguridad del producto (bloqueo de IP, sondeos, ruta de salud, dependencias del front).
