# @lijian-ui/dsh-schedule-view

> 标签: cordis, cron, deepseek-harness, dsh, dsh-plugin, scheduled-tasks, scheduler, timer

## 简介

Cron-based scheduled task plugin for DeepSeek Harness (dsh): UI panel plus a cron_manage agent tool (list/create/update/delete), cross-session timer, multi-level notifications.
