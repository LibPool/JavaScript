# @tengxiaohtx/agent-connect

> 标签: agent-connect, cc-connect, claude-code, cli, dingtalk

## 简介

agent-connect — 从手机(钉钉/飞书/…)监控与控制本机多个 coding agent 会话：读写分离、信使寻址分派、写操作人工确认、Web 看板
