# @yexuens0811/apifox-mcp

> 标签: JavaScript

## 简介

这是一个基于 Model Context Protocol (MCP) 的 Apifox 服务。它会通过 Apifox OpenAPI 导出接口获取项目数据，将 OpenAPI JSON 快照缓存到本地，并支持按“浏览、选择、生成”三阶段使用：先搜索接口候选，再确认具体 `method + path`，最后在用户明确需要时生成 TypeScript 类型。
