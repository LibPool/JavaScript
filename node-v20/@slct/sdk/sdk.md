# @slct/sdk

> 标签: agents, llm, routing, sdk, slct

## 简介

SLCT JavaScript SDK: dependency-free, fetch only, server-side. CommonJS is pinned so a parent package.json with "type": "module" can never make require() of slct.js throw ERR_REQUIRE_ESM (audit #3). ESM import works through Node's CommonJS named-export de
