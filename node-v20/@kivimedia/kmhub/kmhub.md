# @kivimedia/kmhub

> 标签: claude-code, crm, kivimedia, kmhub, mcp, model-context-protocol, terminal-mode

## 简介

KM Hub Terminal Mode. Installs the KM Hub MCP connector into your own Claude Code on your own machine, and ships the kmhub CLI that registers, updates and diagnoses it.
