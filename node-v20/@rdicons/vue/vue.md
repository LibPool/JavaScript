# @rdicons/vue

> 标签: animated-icons, heroicons, icons, lucide, material-icons, phosphor, rdicons, svg, tabler, vue, vue-icons, vue3

## 简介

79,000+ open-source icons as tree-shakable Vue 3 components, from 19 libraries. Import only what you use, e.g. import { House } from '@rdicons/vue/lucide'.
