# @xemahq/backend-slot-registry

> 标签: JavaScript

## 简介

Kernel-leaf in-process server-side mirror of the FE HostExtensionSlots — the union catalog of every Contribution, indexed by ContributionKind. It ships in-process per service (one BackendSlotRegistry instance per NestJS process).
