# @xemahq/llm-client-nest

> 标签: gen-ai, llm, nestjs, opentelemetry, xema, xema-platform

## 简介

The one way a Xema service calls a model: resolve the LLM gateway from the service registry, mint a short-lived sealed grant through llm-registry-api, call it, and emit the OpenTelemetry GenAI semantic conventions — once, instead of eleven times.
