# @embedpdf-editor/react-chapter-viewer

> 标签: JavaScript

## 简介

React 版章节 PDF 阅读器。它把多份章节 PDF 组织成一本连续滚动的书，并内置划线/高亮、附注、段落书签、章节目录和标注导入导出能力。
