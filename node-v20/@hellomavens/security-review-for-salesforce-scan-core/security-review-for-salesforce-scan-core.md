# @hellomavens/security-review-for-salesforce-scan-core

> 标签: JavaScript

## 简介

Side-effecting evidence collector for the HelloMavens security review. Takes a Salesforce Connection + options, returns an EvidenceBundle (SOQL bundle, Health Check API, Code Analyzer subprocess output) the engine can score.
