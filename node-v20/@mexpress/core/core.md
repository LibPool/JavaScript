# @mexpress/core

> 标签: mcp, model-context-protocol, schema, tools, zod

## 简介

Define MCP tools and their Zod schemas, then export them. Works from TypeScript and plain JavaScript (ESM and CommonJS), with Zod 3 and Zod 4.
