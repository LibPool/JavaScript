# codex-bridge-mcp

> 标签: claude-code, code-review, codex, mcp, model-context-protocol, multi-agent

## 简介

Two-way MCP bridge that lets Claude Code drive the Codex CLI (execute plans, adversarial plan review) while Codex can ask Claude questions back.
