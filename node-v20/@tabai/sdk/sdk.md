# @tabai/sdk

> 标签: 402, agent-payments, ai-agent, attestcoin, autonomous-agents, billing, cli, credit, creditcoin, cross-chain, ctc, ethereum, mcp, model-context-protocol, post-paid, sdk, usdc

## 简介

Post-paid billing for autonomous agents on Creditcoin. MCP server, CLI and TypeScript SDK: call a priced tool now, settle in USDC on Ethereum later, and let a Creditcoin contract verify the payment itself through the Attestcoin Protocol.
