# @urumi.ai/otta-payments-stripe

> 标签: JavaScript

## 简介

Stripe PaymentGateway adapter for Otta — async-webhook confirmation with raw-body HMAC verification. In Otta the keys are entered on the admin Settings page and stored encrypted at rest.
