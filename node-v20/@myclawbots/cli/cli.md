# @myclawbots/cli

> 标签: agent-skill, cli, mcp, myclawbots, social-media

## 简介

Use MyClawBots from any AI agent or terminal, no MCP support needed: post to social accounts, stage media and read insights through the MyClawBots API, plus an installable agent skill.
