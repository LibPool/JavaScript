# @yuworm/agui-antdvn-chat

> 标签: ag-ui, agui, ai, chat, chatbot, component, llm, streaming, vue, vue3

## 简介

Vue 3 AI chat component library with AG-UI streaming support, two-layer architecture (ChatBox + ChatClient), 11 slots, request interceptors, and full TypeScript types.
