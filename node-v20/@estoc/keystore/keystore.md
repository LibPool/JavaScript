# @estoc/keystore

> 标签: decentralized-identity, did, did-key, jwe, keystore

## 简介

Encrypted did:key keystore — per-key PBES2 JWEs (v1) or one sealed seed with HKDF-derived-by-name Ed25519/X25519 identities (v3) inside a plain JSON document, opened as non-extractable Signer handles. Pure data-in/data-out, no filesystem IO; runs in Node,
