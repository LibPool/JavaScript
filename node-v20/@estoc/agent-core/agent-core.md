# @estoc/agent-core

> 标签: agent, decentralized-identity, did, didcomm, opfs

## 简介

The DIDComm v2 agent behind Estoc's clients: mediation, pickup, live delivery and hand-layered packing over an .estoc vault (@estoc/vault: config, seed keystore, contacts, append-only message log, through a pluggable VaultBackend). Runs wherever didcomm-r
