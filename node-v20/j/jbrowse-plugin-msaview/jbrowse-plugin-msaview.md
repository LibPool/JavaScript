# jbrowse-plugin-msaview

> 标签: jbrowse, jbrowse2

## 简介

A multiple sequence alignment and phylogenetic tree viewer for JBrowse 2, linked column by column to the genome. It packages [react-msaview](https://github.com/GMOD/react-msaview), whose [user guide](https://github.com/GMOD/react-msaview/blob/main/docs/us
