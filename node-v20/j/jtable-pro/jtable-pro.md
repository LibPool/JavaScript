# jtable-pro

> 标签: data-table, datatable, filter, grid, jquery, jquery-plugin, pagination, search, sort, table, tailwind, tailwindcss

## 简介

Premium, app-like jQuery data-table plugin: global search, per-column search, sortable columns, dropdown filters, client-side pagination and row selection — one file, no build step.
