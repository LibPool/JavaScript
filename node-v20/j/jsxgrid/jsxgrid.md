# jsxgrid

> 标签: grid, jquery, jsgrid, plugin

## 简介

Lightweight data grid jQuery plugin, with a built-in extra field set (avatars, JSON editor, select, collapsible textarea, datetime picker, row selection). A maintained fork of jsGrid.
