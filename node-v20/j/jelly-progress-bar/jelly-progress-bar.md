# jelly-progress-bar

> 标签: gpu, jelly, liquid, progress, progress-bar, react, shader, three, threejs, training, webgl

## 简介

GPU-accelerated "liquid fill" progress bar for React. A fullscreen-quad Three.js ShaderMaterial does all per-pixel work; the CPU only integrates two springs.
