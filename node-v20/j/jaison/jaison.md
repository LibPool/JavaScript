# jaison

> 标签: ai-json, ai-output, ai-systems, auto-complete, chatgpt, claude, error-tolerant, fault-tolerant, json, json-fix, json-recovery, json-repair, language-model, llm-json, malformed-json, markdown-json, parser, robust-parsing, streaming-json

## 简介

A robust, fault-tolerant JSON parser engineered specifically for handling malformed JSON output from AI systems and language models. Supports Chinese punctuation and international characters.
