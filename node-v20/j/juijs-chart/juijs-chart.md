# juijs-chart

> 标签: CSS, Chart, Framework, HTML5, JS, JavaScript, MIT, NodeJS, SVG, Web development, free

## 简介

SVG-based JUI chart that can be used in the browser and Node.js. Support many types of charts. (Dashboard, Map, Topology, Full 3D)

- 源码仓库：git+https://github.com/juijs/jui-chart.git
