> 标签: anomaly, database, isolation, jepsen, migration, multi-tenant, pentest, postgres, property-testing, rls, row-level-security, schema, security, transaction

## 简介

Pries open the database the application thinks is locked. RLS, multi-tenant isolation, transaction anomalies, schema integrity, migration safety.
