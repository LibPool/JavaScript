# jev-skill-router

> 标签: agent, jev, openrouter, prompt-injection, router, security, skills, system-one

## 简介

Jev-powered skill router & security auditor for any AI agent: analyzes each request, tells the model WHICH skill to load, and scans skill libraries for prompt injection / dangerous commands.
