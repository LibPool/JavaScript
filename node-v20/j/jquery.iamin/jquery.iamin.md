# jquery.iamin

> 标签: jquery-plugin, positioning

## 简介

jquery-plugin that will set your element on a side of its parent within body (if it can) or at start of the body (if can't).

## 官网

- 官网：https://github.com/ezhikov/jQuery.iAmIn
- 源码仓库：https://github.com/ezhikov/jQuery.iAmIn.git
- npm 页面：https://www.npmjs.com/package/jquery.iamin
