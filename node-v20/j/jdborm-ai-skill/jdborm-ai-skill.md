# jdborm-ai-skill

> 标签: ai, jdbc, jdborm, opencode, orm, query-builder, schema, skill, sql, uuid

## 简介

Install jdborm AI skill into your project. Gives AI coding assistants deep knowledge of the jdborm fluent JDBC query builder, declarative schema, and UUID APIs.
