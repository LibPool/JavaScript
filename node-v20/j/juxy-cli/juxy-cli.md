# juxy-cli

> 标签: JavaScript

## 简介

Juxy CLI là một trợ lý lập trình chạy trong terminal, viết bằng TypeScript/Node.js. CLI kết nối tới Juxy-compatible API, đọc ngữ cảnh workspace hiện tại, gọi tool cục bộ khi cần và hỗ trợ các thao tác agentic như đọc file, tìm kiếm code, chỉnh sửa có diff
