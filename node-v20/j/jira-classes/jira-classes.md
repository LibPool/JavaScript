# jira-classes

> 标签: jira

## 简介

A library to provide Typescript interfaces for the Jira API and the React Framework. Currently only supports Connect Modules (browser and ACE provided that AP or an httpClient are defined) but Forge API could be enabled in the future. This is a total work
