# j-agy-mcp

> 标签: agy, antigravity, claude-code, codex, gemini, mcp, model-context-protocol, subagent

## 简介

MCP server that wraps the Antigravity CLI (agy) as tools — lets CodeX / Claude Code dispatch exploration or coding tasks to AGY as an external subagent.
