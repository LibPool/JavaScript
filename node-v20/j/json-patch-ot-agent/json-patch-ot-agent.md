# json-patch-ot-agent

> 标签: OT, json, json-patch, jsonpatch, queue, versioned-json-patch

## 简介

OT Agent/Queue for JSON-Patch OT - makes sure that your JSON Patches (RFC6902) gets transformed and applied in correct order
