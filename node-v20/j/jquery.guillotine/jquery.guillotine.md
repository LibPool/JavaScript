# jquery.guillotine

> 标签: center, crop, drag, fit, fluid, guillotine, image, jquery, jquery-plugin, responsive, rotate, touch, zoom

## 简介

Allow users to crop images within an area (fully responsive). Supports dragging (touch support), zoom and rotation.
