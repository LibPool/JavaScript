# js-deobfuscator-vm

> 标签: JavaScript

## 简介

A specialized Node.js utility for deobfuscating JavaScript bundles (like those packed with `obfuscator.io` or similar string-array obfuscators) by executing the decryption routines safely inside an isolated Node.js `vm` context.
