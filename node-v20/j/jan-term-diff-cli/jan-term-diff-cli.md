# jan-term-diff-cli

> 标签: JavaScript

## 简介

`jan-term-diff-cli` is a command-line interface (CLI) tool that allows you to upload a file to a specified server for diffing against another file uploaded by a different user in the same "room". It then displays the real-time diff results directly in you
