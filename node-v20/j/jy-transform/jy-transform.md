> 标签: api, cli, convert, javascript, js, js-2-yaml, js-to-yaml, js2yaml, json, json-2-yaml, json-to-yaml, json2yaml, jsontoyaml, jstoyaml, jy, jy-transform, jyt, promise, transform, yaml, yaml-2-js, yaml-2-json, yaml-to-js, yaml-to-json, yaml2js, yaml2json, yamltojs, yamltojson

## 简介

This project aims to read, write and transform YAML, JS or JSON objects into each other using CLI or API, while the source and destination resources can be files on CLI and additionally, objects or streams on API level.
