# json-proxy

> 标签: api proxy, connect proxy, express proxy, grunt, grunt proxy, gruntplugin, json proxy, middleware, proxy, utility

## 简介

Grunt plugin / CLI utility / Express middleware to proxy API requests to remote servers without CORS or JSONP.
