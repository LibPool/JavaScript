# james-api-sign

> 标签: api-sign, axios, hmac, interceptor, request-signing, sha256, signature

## 简介

Axios request interceptor with HMAC-SHA256 API signing (X-Access-Key/X-Timestamp/X-Nonce/X-Sign), Bearer token and comid header injection. Zero-config by default, fully configurable.
