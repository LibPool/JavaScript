# jscrewit

> 标签: esoteric, jsfuck, obfuscation

## 简介

Converts plain JavaScript into JSFuck code, which consists of only six different characters: ! ( ) + [ ]

- 源码仓库：git+https://github.com/fasttime/JScrewIt.git
