# js_antlr

> 标签: antlr, antlr4, clojure, clojurescript, grammar, infix, lexer, lisp, parser, prefix, sexpr

## 简介

Partial port of aphyr/clj-antlr bindings for ANTLR 4 parser library, returning a tree or sexpr-formatted tree
