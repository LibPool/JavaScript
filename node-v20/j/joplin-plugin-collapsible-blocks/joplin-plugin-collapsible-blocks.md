# joplin-plugin-collapsible-blocks

> 标签: joplin-plugin

## 简介

This Joplin plugin allows you to create collapsible blocks with a title and extendable body. The blocks:  * Can be nested within one another * Remember if they were left opened or closed * Can color-coordinate between the editor and webview * Collapse in
