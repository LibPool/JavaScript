# joplin-plugin-agenda2

> 标签: agenda, calendar, date, joplin, joplin-plugin, schedule, todo, upcoming

## 简介

An agenda/calendar/schedule panel for Joplin that shows all uncompleted to-dos with a due date, on desktop and mobile.
