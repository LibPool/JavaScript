# jsonshim-mcp

> 标签: agent, json, llm, mcp, model-context-protocol, parsing, recovery, stdio

## 简介

One-file MCP stdio server for JSON recovery in agent loops. 218/300 exact on MALFORMED-300, 0 invented values, 55 false refusals. Standard library only, CC0.
