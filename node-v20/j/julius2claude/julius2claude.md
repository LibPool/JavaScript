# julius2claude

> 标签: 5-hour-limit, account-switcher, anthropic, bedrock, claude, claude-account-switcher, claude-code, claude-code-cli, claude-enterprise, claude-max, claude-pro, claude-team, cli, failover, multi-account, multiple-accounts, rate-limit, session-resume, switch-account, usage-limit, vertex-ai, weekly-limit

## 简介

Claude Code account switcher: use several Claude accounts (Pro/Max, Team/Enterprise, Bedrock, Vertex, API key) and switch automatically when one hits its usage limit, resuming the same session.
