# json-storyteller

> 标签: ai, anthropic, component, json, llm, llm-apps, mistral, openai, react, storyteller

## 简介

A React component that transforms raw JSON into human-readable narratives. Works with any LLM provider — Anthropic, OpenAI, Mistral, or a custom adapter.
