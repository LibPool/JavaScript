# jquery.ellipsis

> 标签: JavaScript

## 简介

jquery.ellipsis makes it possible to hide content using ellipsis (...) or some other markup. After that is clicked, it will show rest of the content.

- 官网：https://github.com/bebraw/jquery.ellipsis
