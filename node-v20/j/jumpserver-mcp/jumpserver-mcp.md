# jumpserver-mcp

> 标签: ai-agent, bastion, jumpserver, mcp, modelcontextprotocol, ops, sre, ssh

## 简介

JumpServer (KoKo) bastion connector for WorkBuddy as an MCP stdio server: persistent SSH/PTY session with explicit state machine, asset discovery, permission-gated audited commands, target-affinity batch execution, fixed-profile structured host inventory,
