# justerm-web

> 标签: ansi, canvas, justerm, terminal, terminal-emulator, vt100, wasm, webgl, webgl2, xterm

## 简介

Browser terminal widget for the justerm engine: consumes decoded frames and paints them with justerm-renderer (WASM + WebGL2).
