# jquery-elastic-stack

> 标签: elastic, jquery, plugin, stack

## 简介

ElastiStack is a little script that let's you navigate through a stack of items by dragging away the first one. It comes with an elastic touch meaning that when dragging the top-most item, the other ones will follow as if they were connected elastically.
