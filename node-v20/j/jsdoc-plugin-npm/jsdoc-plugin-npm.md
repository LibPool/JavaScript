# jsdoc-plugin-npm

> 标签: JSDoc, jsdoc, jsdoc plugin, jsdoc plugin link, jsdoc plugin links, jsdoc plugin npm, jsdoc plugin url, jsdoc plugin urls, jsdoc plugins, plugin jsdoc

## 简介

Generate a jsdoc @link tag from an @npm tag, e.g., `{@npm jsdoc-plugin-npm}` => `{@link https://www.npmjs.org/package/jsdoc-plugin-npm|jsdoc-plugin-npm}`
