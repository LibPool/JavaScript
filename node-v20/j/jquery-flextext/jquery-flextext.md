# jquery-flextext

> 标签: auto, flextext, height, jquery, textarea

## 简介

A lightweight jQuery version of the A List Apart - Expandind textarea concepto for auto-height textareas, extended for additional browser compatibility, addressing a few browser bug/issues. Tested and working fine in Safari Mac/iOs 5, Chrome, Firefox 3.6+
