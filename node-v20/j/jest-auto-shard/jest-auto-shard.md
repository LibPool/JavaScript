# jest-auto-shard

> 标签: automatic, ci-cd, coverage, distribution, jest, merge, optimization, parallel, performance, reporter, runner, shard, sharding, test, testing, zero-config

## 简介

Automatic test sharding for Jest with zero configuration. Intelligently distributes tests across multiple runners and merges coverage reports seamlessly.
