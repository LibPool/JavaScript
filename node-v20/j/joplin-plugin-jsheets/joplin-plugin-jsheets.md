# joplin-plugin-jsheets

> 标签: joplin-plugin

## 简介

Implementation of [Luckysheet](https://github.com/mengshukeji/Luckysheet) for Joplin. You can now write excel-like notes! Note: [Luckysheet](https://github.com/mengshukeji/Luckysheet) is bundled into the plugin.
