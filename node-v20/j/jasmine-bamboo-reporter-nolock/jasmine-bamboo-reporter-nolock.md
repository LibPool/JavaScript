# jasmine-bamboo-reporter-nolock

> 标签: JSON, bamboo, jasmine, protractor, reporter, tests

## 简介

A reporter for Jasmine (without lock, to be run in a single thread) which produces a report compatible with Atlassian Bamboo Mocha Test Parser.
