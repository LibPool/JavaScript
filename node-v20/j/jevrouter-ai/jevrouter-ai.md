# jevrouter-ai

> 标签: ai-gateway, anthropic, gateway, jev, llm, model-routing, openai, router

## 简介

Open-source production JEV model router. JEV decides the capability tier (fast/balanced/powerful); policy + scoring choose the model. Use as a gateway or embed in-process.
