# jugglework-vision-mcp

> 标签: claude-desktop, cursor, gemini, gpt-4o, image-recognition, jugglework, mcp, model-context-protocol, ocr, qwen-vl, vision

## 简介

Multi-provider vision MCP server for image recognition (OCR, scene description, chart extraction). Supports Qwen-VL, OpenAI, Gemini, Claude, OpenRouter, Ollama and any OpenAI-compatible endpoint.
