# js-security

> 标签: content-filter, input-validation, javascript, node-security, rich-text, security, sql-injection, web-security, whitelist, xss, 安全, 检测, 防护

## 简介

一个轻量级的JavaScript安全防护工具库，提供XSS攻击和SQL注入检测功能，支持自定义富文本字段白名单管理
