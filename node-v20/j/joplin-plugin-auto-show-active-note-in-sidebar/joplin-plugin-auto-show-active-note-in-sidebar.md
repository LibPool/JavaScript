# joplin-plugin-auto-show-active-note-in-sidebar

> 标签: joplin-plugin

## 简介

This [Joplin](https://joplinapp.org/) auto open the current note in the Notebooks sidebar. Basically this auto execute the joplin command `focusElementSideBar` (shortcut `Shift+Cmd+S`).
