# jquery.transport.xdr

> 标签: AJAX, CORS, IE8, IE9, XDR, XDomainRequest, cross-domain, jquery-plugin

## 简介

A jQuery plugin that enables cross-domain AJAX requests for IE8 and IE9 with XDomainRequest.
