# js-fn-module

> 标签: JavaScript

## 简介

解决普通建站页面js代码混乱的问题，js执行代码越多会越乱。 > 像vue一样去写我们普通的前端代码，各种this的应用，便于页面功能模块的整理修改，以及相互调用，数据修改。
