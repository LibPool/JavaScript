# jira-tempo-mcp

> 标签: jira, mcp, model-context-protocol, python, report, tempo, timesheets, worklog

## 简介

MCP server for self-hosted Jira + Tempo Timesheets: track time, list worklogs, generate weekly reports. npm wrapper — installs and runs the Python package (PyPI: jira-tempo-mcp).
