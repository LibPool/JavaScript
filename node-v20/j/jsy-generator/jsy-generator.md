# jsy-generator

> 标签: JavaScript

## 简介

`jsy-generator` 是一个命令行工具，用于根据提供的接口名称和 JSON 配置 URL，在项目目录中自动生成 Vue 文件。该工具旨在帮助开发者快速创建接口相关的 Vue 组件，减少重复性工作。
