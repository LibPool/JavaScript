# jimi-login

> 标签: JavaScript

## 简介

&emsp;&emsp;本系统基于node实现（初次使用请确保已安装node），使用百度文本识别方式识别萌友系统验证码，识别成功率达70%，速度快；本系统使用方便；配置简单。
