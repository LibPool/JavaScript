# job-application-tracker-mcp

> 标签: claude, claude-desktop, job-application, job-search, job-tracker, mcp, model-context-protocol

## 简介

MCP server for tracking job applications and follow-ups, backed by a local JSON file. Works with Claude Desktop and any MCP client over stdio.
