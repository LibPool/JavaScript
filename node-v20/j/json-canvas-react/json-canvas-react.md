# json-canvas-react

> 标签: canvas, diagram, infinite-canvas, json-canvas, jsoncanvas, node-editor, obsidian, react

## 简介

A dependency-light React framework for rendering and editing the JSON Canvas (jsoncanvas.org) open file format. DOM + CSS transform based: pan/zoom, drag, resize, edge drawing, markdown text nodes.
