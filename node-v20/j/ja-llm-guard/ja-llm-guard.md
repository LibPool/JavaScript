# ja-llm-guard

> 标签: guardrails, japanese, llm, validation, ローカルLLM, 日本語

## 简介

日本語LLM出力の『読めるのに壊れている』を機械で拾う出口検査（かな比率・簡体字混入）。本番運用の失敗ログ実測から抽出。依存ゼロ。
