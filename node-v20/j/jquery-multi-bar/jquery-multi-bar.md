# jquery-multi-bar

> 标签: bar, color bar, jquery, marker, multi bar, progressbar

## 简介

jQuery plugin which you can build custom progress bar with multi and personalized colors. The number and style of the colors are at your choice, so 'as the initial and final values. This allows you to create progress bar completely tailored to your needs.
