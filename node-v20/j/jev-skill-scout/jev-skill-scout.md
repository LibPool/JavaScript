# jev-skill-scout

> 标签: audit, claude-code, function-hooks, jev, mod, skills, system-one, typesafe

## 简介

Finds the turns where Claude Code should have loaded one of your skills and did not, judged by TypeSafe's Jev. Ships the audit CLI and the mod that fixes it live.
