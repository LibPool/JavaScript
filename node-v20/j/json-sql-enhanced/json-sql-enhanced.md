# json-sql-enhanced

> 标签: builder, json, mongodb, mssql, mysql, operators, postgresql, query, regex, sql, sqlite

## 简介

Node.js library for mapping MongoDB-style query objects to SQL queries with enhanced operators and multi-dialect support
