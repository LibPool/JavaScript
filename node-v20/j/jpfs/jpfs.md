# jpfs

> 标签: JavaScript

## 简介

JPFS is a simple JavaScript module for [content-addressable storage](https://en.wikipedia.org/wiki/Content-addressable_storage) and retrieval of arbitrary data by its hash, in Node.js or the browser.
