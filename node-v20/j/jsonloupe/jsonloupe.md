# jsonloupe

> 标签: diff, int64, json, jsonpath, local-first, lossless, mcp, mcp-server, viewer, zstd

## 简介

A loupe for large JSON — lossless, local-first viewer, differ, and query tool. Int64-exact, worker-powered, zstd-aware.
