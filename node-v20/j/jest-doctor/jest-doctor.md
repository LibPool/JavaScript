# jest-doctor

> 标签: async-leaks, ci, developer-tools, flaky-tests, issue detection, jest, jest environment, jest-doctor, leak detection, open handles, test diagnostics, test hygiene, test-isolation, testing

## 简介

Custom Jest environment that detects async leaks between tests, enforces test isolation, and prevents flaky failures in CI.
