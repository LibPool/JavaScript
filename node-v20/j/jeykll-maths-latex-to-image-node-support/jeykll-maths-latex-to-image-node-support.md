# jeykll-maths-latex-to-image-node-support

> 标签: converter, equations, jekyll, latex, math, mathematics, png, svg

## 简介

A support package for Jekyll plugin that converts LaTeX mathematical expressions to PNG images for better compatibility and improved rendering across different platforms
