# js-theme-switcher

> 标签: color-palette, css-variables, dark-mode, light-mode, theme, theming, vanilla-js, vue

## 简介

A lightweight, framework-agnostic color palette theme switcher using CSS variables. Comes with curated built-in palettes, selectable by ID or slug — no config needed.
