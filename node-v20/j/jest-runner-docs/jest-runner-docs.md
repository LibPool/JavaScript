> 标签: comments, developer-experience, development, docs, documentation, dx, hela, jsdoc, parse-comments, tsc, tsdoc, tunnckocore-oss, tunnckocorehq, typescript

## 简介

Jest runner for API documentation generation from code comments, supports TypeScript. Very stable and reliable, based on `parse-comments` package
