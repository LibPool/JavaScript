# json-object-mapper

> 标签: DTO, Data Transfer Objects, JSON, JSON Deserialize, JSON Serialize, JsonProperty, TypeScript

## 简介

A TypeScript library to serialize and deserialize JSON objects in a fast and non-recursive way
