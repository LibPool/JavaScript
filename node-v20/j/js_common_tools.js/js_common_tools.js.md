> 标签: api, canvas, common, js, qrcode, tools, 二维码, 二维码绘制, 函数, 工具, 工具函数, 常用, 常用工具, 常用工具函数, 海报, 海报绘制

## 简介

一个简单的js工具库，包含：二维码绘制、海报绘制、加减乘除 （解决精度问题）、随机字符串获取等常工具函数;兼容web和微信小程序
