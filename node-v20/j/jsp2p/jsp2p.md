# jsp2p

> 标签: JavaScript

## 简介

Lightly modified version of binaryjs to bring p2p binary stream for web and node.js

## 官网

- 官网：http://iwebpp.com
- 源码仓库：git://github.com/InstantWebP2P/jsp2p.git
- npm 页面：https://www.npmjs.com/package/jsp2p

## 历史版本号

- 当前版本：0.1.7

- 0.0.0

## 获取地址

- npm 安装：`npm install jsp2p`
- npm registry：https://registry.npmjs.org/jsp2p
- Node 要求：>=0.6.0
