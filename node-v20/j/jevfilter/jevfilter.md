# jevfilter

> 标签: ai, filter-bar, filters, intent, jev, llm, natural-language, natural-language-search, no-sql-generation, search, text-to-filter, typesafe, typescript

## 简介

Turn a user's search sentence into filters your API already accepts. Typed, validated filters from a closed schema; your own query code and authorization run the search, and no SQL is generated.
