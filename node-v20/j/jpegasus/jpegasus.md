# jpegasus

> 标签: blob, browser, canvas, client, client side, client-side, compress, compression, compressor, dom, file, front, front end, front-end, gif, image, javascript, jpeg, png, reduce, resize, scale, size, smaller

## 简介

A client-side JavaScript tool that takes in a `File` of type `.jpeg`, `.png`, or `.gif` and returns a compressed `File` of type `.jpeg`.
