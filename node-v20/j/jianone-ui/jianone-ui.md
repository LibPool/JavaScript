# jianone-ui

> 标签: jianone, ui组件库, uni-app, 简一, 组件

## 简介

JianOne 简一 UI 组件库：图片视频轮播、图片裁剪、自定义导航栏、瀑布流布局、确认弹窗等通用组件，基于 uni-app + Vue2
