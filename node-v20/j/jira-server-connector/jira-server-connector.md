# jira-server-connector

> 标签: Atlassian Jira, Atlassian Jira REST, Atlassian Jira Server REST, Jira, Jira REST, Jira Server REST

## 简介

Module to handle and work with Atlassian Jira Server throug REST API. Admin your projects and issues in Jira easy. This project is not an Atlassian official project but use the Atlassian Jira Server REST API
