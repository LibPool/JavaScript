# jarp-mcp

> 标签: ai, ai-assistant, anthropic, bytecode, class-analyzer, claude, copilot, cursor, decompilation, decompiler, dependency-analysis, gradle, intellij, jar, jarp, java, java-decompiler, llm, maven, mcp, model-context-protocol, reverse-engineering, spring, spring-boot, vscode

## 简介

MCP server that gives AI agents instant access to decompiled Java code from Maven/Gradle dependencies. Blazing fast Java class analysis for Claude, Cursor, and other LLM-powered IDEs.
