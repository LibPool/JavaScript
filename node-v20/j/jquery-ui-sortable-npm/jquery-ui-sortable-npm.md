# jquery-ui-sortable-npm

> 标签: JavaScript

## 简介

This is a minimal standalone build of jQuery UI Sortable. It includes: jquery.ui.core.js, jquery.ui.widget.js, jquery.ui.mouse.js and jquery.ui.sortable.js.
