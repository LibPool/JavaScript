# @imaps/ai-chat

> 标签: ai, arcgis, assistant, chat, custom-element, international-mapping, langchain, maplibre, mcp, web-component

## 简介

Provider-agnostic AI assistant (Anthropic/OpenAI, BYO key) with MCP tools, as a React component, an embeddable <imaps-ai-chat> web component, and expand widgets for MapLibre GL and the ArcGIS Maps SDK.
