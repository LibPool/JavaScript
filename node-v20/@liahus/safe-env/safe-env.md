# @liahus/safe-env

> 标签: env, env-validation, environment, environment-variables, framework-agnostic, secure-env, type-safe, typescript, typescript-env, validation, variables, zod

## 简介

Type-safe environment variable validation for TypeScript & JavaScript. Framework-agnostic, validates at startup, secrets masked, DoS protected.
