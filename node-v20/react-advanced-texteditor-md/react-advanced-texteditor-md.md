## 简介

React bindings for advanced-texteditor-md: a WYSIWYG editor that stores Markdown. A controlled or uncontrolled <MarkdownEditor />, a native <MarkdownView /> renderer (server-component friendly), and hooks. Mentions, chips, uploads, plugins, themes.
