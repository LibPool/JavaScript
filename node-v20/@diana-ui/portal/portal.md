# @diana-ui/portal

> 标签: JavaScript

## 简介

The Portal component uses <a href="https://reactjs.org/docs/portals.html">React Portals</a> to render a DOM element outside the DOM hierarchy of the parent element, namely as a child of the `<body>`.
