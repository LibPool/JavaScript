# peel-bridge

> 标签: bridge, design, figma, html-to-figma, peel

## 简介

The Peel local bridge: send captures from the Peel browser extension to the Peel Figma plugin, saved as files on your own computer. No dependencies.

## 官网

- 官网：https://trypeel.co/local-bridge
- npm 页面：https://www.npmjs.com/package/peel-bridge
