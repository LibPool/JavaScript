# @structyl/styled

> 标签: accessible, compound-components, design-system, headless, react, rsc, structyl, tailwind-variants, tailwindcss, theming, typescript, ui-components, wai-aria

## 简介

Tailwind CSS v4 styled React components built on accessible WAI-ARIA primitives, with a token-driven theme preset and type-safe variants.
