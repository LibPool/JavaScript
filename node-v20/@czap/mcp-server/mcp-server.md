# @czap/mcp-server

> 标签: ai-tooling, czap, liteship, mcp, model-context-protocol, typescript

## 简介

The Model Context Protocol server for LiteShip: exposes the `czap` commands and capsule catalog as MCP tools that AI assistants can call.
