# @czap/web

> 标签: browser-runtime, czap, dom, liteship, streaming, typescript

## 简介

The browser runtime for LiteShip: apply CSS, streamed HTML, worker output, and LLM chunks to a live DOM with focus- and scroll-preserving morphing.
