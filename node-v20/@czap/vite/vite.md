# @czap/vite

> 标签: css, czap, hmr, liteship, typescript, vite-plugin

## 简介

The Vite plugin for LiteShip: compile `@token`, `@theme`, `@style`, and `@quantize` blocks into native CSS and hot-reload boundary definitions as you edit.
