# @owasp-webshield/vue

> 标签: acl, authentication, authorization, csrf, input-sanitization, owasp, owasp-top10, rbac, secure-coding, security, ssrf, vue, vue-composables, vue-router, vue3, webshield

## 简介

Vue 3 adapter for OWL (OWASP Webshield Library): a plugin, category-aligned composables, guard components, a sanitizing v-safe-html directive and a Vue Router guard for @owasp-webshield/core
