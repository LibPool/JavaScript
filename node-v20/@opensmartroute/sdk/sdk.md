# @opensmartroute/sdk

> 标签: agents, llm, openai, opensmartroute, routing, sdk

## 简介

TypeScript client for the OpenSmartRoute platform and osr serve: routing, feedback, quotes and the OpenAI-compatible endpoint (fetch-based, zero dependencies).
