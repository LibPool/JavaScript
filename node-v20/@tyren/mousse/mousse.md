# @tyren/mousse

> 标签: framework, http, openapi, router, server, sse, standard-schema, typescript, uwebsockets, web, websocket

## 简介

Fully typed Node.js web framework built on µWebSockets.js : HTTP routing, WebSockets and Server-Sent Events through a single Context API, Standard Schema validation and documentation generation.
