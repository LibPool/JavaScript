# korea-mcp

> 标签: ai-agent, claude, korea, mcp, metro, model-context-protocol, seoul, subway, travel

## 简介

MCP server that helps AI agents get around Korea: subway routes in English, fares, public holidays and practical guides. Works with no API key.
