# @peckey954/ui

> 标签: design-system, design-tokens, multi-brand, radix-ui, react, shadcn, shadcn-ui, tailwindcss, thai

## 简介

Multi-brand design system built on shadcn/ui and Tailwind CSS v4, with first-class Thai font support. Swap colours and fonts per brand without touching component code.
