# dsh-skillbox

> 标签: deepseek-harness, dsh, dsh-plugin, settings, skill, skill-manager, skills

## 简介

Skill shelf for DeepSeek Harness (dsh): a sidebar panel next to Plugins and Automation that lists every skill DSH resolves, discovers and installs skills from skills.sh, upgrades them safely (previous version quarantined, never deleted), uninstalls or res
