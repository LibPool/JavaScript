# @angineer/table-ui

> 标签: JavaScript

## 简介

通用表格组件库（Vue 3 + ant-design-vue）：配置驱动的 DataTable——筛选栏、列宽拖拽持久化、容器自适应填满，外加配套卡片容器 SectionCard。
