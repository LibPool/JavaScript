# @archiyou/meshup

> 标签: 3d, 3d-printing, cad, csg, geometry, gltf, mesh, nurbs, sdf, wasm

## 简介

General purpose 3D mesh library with various modeling techniques (CSG, 2D, quasi-CAD) and target applications (3D printing, craft, CNC) in Typescript and powered by Rust (CSGRS).
