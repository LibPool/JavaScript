# dsh-plugin-shell-selector

> 标签: deepseek-harness, dsh, dsh-plugin, powershell, shell

## 简介

在 设置 → Shell 页面选择 AI 命令执行所用的 shell（自动 / PowerShell 7 / Windows PowerShell 5.1 / Git Bash），带真实可用性检测。
