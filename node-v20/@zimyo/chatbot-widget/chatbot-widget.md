# @zimyo/chatbot-widget

> 标签: JavaScript

## 简介

Drop-in Zimyo chatbot as a React component. In-process chat — voice, demo calendar, inline guided org-signup, and a built-in Stripe card form. Mirrors the sales_ai_boat chat agent.
