# @underlying/core

> 标签: accessibility, animation, inertia, interruptible, motion, physics, reduced-motion, spring, waapi

## 简介

Physics-first web animation: interruptible springs with velocity conservation, inertia, colors, units, keyframes, accessible by default, zero dependencies, ~12 kB gzip for animate() (tree-shakes to ~3.5 kB for primitives).
