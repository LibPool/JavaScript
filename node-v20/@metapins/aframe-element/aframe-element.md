# @metapins/aframe-element

> 标签: aframe, aframe-element, lit, lit-html, lit-observe, metapins, redux, rxjs

## 简介

aframe-element is a library inspired from the very nice library [Polymer lit](https://lit.dev/) to map [A-Frame](https://aframe.io/) AR / VR / 3D elements on typescript classes like Angular/React/Lit.   Used with [@metapins/lit-observable](https://github.
