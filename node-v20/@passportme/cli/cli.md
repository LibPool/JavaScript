# @passportme/cli

> 标签: cli, mcp, oauth, passport.me, passportme

## 简介

Official Passport.Me CLI for Passport login, approved data access (Gmail, Calendar, Drive, GitHub, Oura), wallet portfolio/activity/NFTs/DeFi, and MCP config export.
