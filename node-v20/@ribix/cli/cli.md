# @ribix/cli

> 标签: agent, autonomous-qa, browser-testing, cli, findings, qa, ribix, staging, testing

## 简介

Ribix CLI — terminal client for the Ribix autonomous QA agent. Connect staging environments, trigger agent runs, stream live findings, and approve or reject fixes.
