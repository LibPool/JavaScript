# @kevincii/http-query-client

> 标签: client, fallback, fetch, filter, http, pagination, query, request, retry, typescript

## 简介

Batteries-included TypeScript client for the HTTP QUERY method: type-safe queries, nested filters, fallbacks, retries, timeout, caching, pagination. Browser + Node.
