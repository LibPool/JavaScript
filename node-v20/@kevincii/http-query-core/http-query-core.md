# @kevincii/http-query-core

> 标签: cache, fetch, filter, http, pagination, query, retry, rfc, serialize, typescript

## 简介

Framework-agnostic engine for the HTTP QUERY method: type-safe query building, nested filter serialization, fallbacks, retries, timeout, caching, pagination. Zero dependencies.
