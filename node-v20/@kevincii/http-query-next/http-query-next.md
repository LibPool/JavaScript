# @kevincii/http-query-next

> 标签: http, next, nextjs, query, route-handler, rsc, server, typescript

## 简介

Next.js integration for the HTTP QUERY method: a Node server client, RSC data fetching, App Router route-handler helpers, and re-exported React hooks.
