# @k8slens/channel-contracts

> 标签: JavaScript

## 简介

What a channel is: the message, request and computed channel types of Lens Desktop, and the functions declaring one. Nothing but declarations, so that the host's messaging and the contracts extensions are given speak of the same channels.
