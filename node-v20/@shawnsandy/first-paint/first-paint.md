# @shawnsandy/first-paint

> 标签: CSS, Classless, HTML, SCSS, SEMANTIC, Toolkit

## 简介

First Paint is an easy to use CSS/SCSS starter library that contains accessibility focused, semantic HTML elements and components for quickly scaffolding/building modern, lightweight mobile friendly websites.
