# @claucondor/utxo

> 标签: babyjub, circom, evm, flow, groth16, merkle, nullifier, poseidon, privacy, utxo, zk

## 简介

Privacy UTXO primitive for Flow — Merkle tree + nullifiers + ZK shield/transfer/unshield. Foundation for AurumFlow-class RAILGUN-style apps.
