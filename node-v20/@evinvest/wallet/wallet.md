# @evinvest/wallet

> 标签: JavaScript

## 简介

Host wrappers for the banking wallet microfrontends: the wallet and the pay-invoice button, and the popup helper that carries a money action to evinvest.ltd and brings its result back by postMessage. A thin layer over @evinvest/mfe.
