# reviewstage

> 标签: ai-code-review, claude, claude-code, code-review, developer-tools, electron, github, human-in-the-loop, pr-review, pull-request, self-hosted

## 简介

ReviewStage is the human review layer for AI-written pull requests. Claude drafts the review privately; you verify, edit and post it as yourself. Desktop app: npx reviewstage
