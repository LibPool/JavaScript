# @partykeys/mcp-server

> 标签: keyboard, led, mcp, midi, partykeys, sysex, workbuddy

## 简介

MCP server that lets AI assistants light up the keys of a PartyKeys 36 / PopuPiano 29 keyboard over USB or Bluetooth MIDI.

## 官网

- 官网：https://protocol.partykeys.ai
- 源码仓库：git+https://github.com/PartyBohan/partykeys-mcp-server.git
- npm 页面：https://www.npmjs.com/package/@partykeys/mcp-server
