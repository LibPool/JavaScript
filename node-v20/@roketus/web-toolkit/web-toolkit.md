# @roketus/web-toolkit

> 标签: JavaScript

## 简介

+ Generate PAT in your github account page go to `Settings->Developer Setting->Personal Access Token` + Login to your registry     + `npm login --scope=@roketus --registry=https://npm.pkg.github.com`     + When prompting for a password fill you PAT
