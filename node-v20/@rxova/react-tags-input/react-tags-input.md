> 标签: a11y, accessible, chips, chips-input, headless, multi-select, multi-value, react, roving-tabindex, tag-input, tags, tags-input, token-input, tokens, zero-dependency

## 简介

A tag / token input with real roving-tabindex keyboard navigation and announced add and remove. Headless, zero-dependency.
