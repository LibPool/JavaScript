# @powerduck/workspace-yaml

> 标签: atomic-write, browser-safe, conf-patch, electron, file-lock, initializer, openapi, openapi-3.2, powerduck, scaffold, workspace, yaml

## 简介

Initialize workspace.yaml and OpenAPI 3.2 YAML files with confidence. Two-layer architecture: browser-safe core for generating YAML content, plus Node.js/Electron file layer that reuses @powerduck/conf-patch for atomic writes and locking.
