# @waukeshamakerspace/service-kit

> 标签: fastify, health, openapi, swagger, waukesha-makerspace

## 简介

The house Fastify service shell for Waukesha Makerspace: the {success,data}/{success,error} envelope, Swagger wiring, and a health endpoint that actually checks the database
