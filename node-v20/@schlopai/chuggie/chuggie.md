# @schlopai/chuggie

> 标签: agb, game-engine, gameboy-advance, gba, tish

## 简介

Game engine packages for writing Game Boy Advance games in tish — scenes, isoboard, platformer, top-down, shmup, versus fighting, brawler, grids, dialog, menus, save and link.
