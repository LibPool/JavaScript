# @fnconfig/config

> 标签: config, configuration, ioc, options, typescript

## 简介

Layered configuration engine: ConfigurationBuilder/Root/Section, ConfigurationKeyComparer, the Memory provider, an index-navigable Section tree, and a runtime schema (Schema/Infer/OPTIONAL) that coerces on build().
