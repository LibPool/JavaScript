# @nickpaustian/telemetry

> 标签: debug, fps, graph, hud, overlay, telemetry, typescript

## 简介

An on-screen panel of live debug widgets: values, scrolling graphs and 2D plots, with an FPS binding, for watching what an app is doing while it runs
