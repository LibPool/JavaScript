# @nickpaustian/catalyst

> 标签: engine, game-loop, gaussian-splatting, physics, scene-graph, three, typescript

## 简介

A small modular engine for three.js experiences: a frame loop with update, render and resize signals, a node tree with cached world transforms, cameras and debug shapes in the core, and physics, input, Gaussian splats and prefabs as separate entry points
