# @rivetts/openapi

> 标签: JavaScript

## 简介

Генерация OpenAPI 3.1.1 из существующих HTTP-маршрутов Rivet. Пакет не зависит от Fastify или TypeBox: читает общий контракт `Schema.jsonSchema` из `@rivetts/http`.
