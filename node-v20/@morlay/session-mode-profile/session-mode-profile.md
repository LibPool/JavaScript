# @morlay/session-mode-profile

> 标签: bundle-entry, dsh, dsh-bundle, dsh-plugin

## 简介

会话模式与注入面：会话模式行（各模式的 persona、工具与 policy 名单、开关；按会话收口也由它内部持有）+ subagent 服务接管行 + 注入通道 + 工具说明（汉化 / 用法分组），一次装齐；行清单归会话挂着的 shipped preset，本包不自建 preset。
