# @morlay/dsh-preset

> 标签: dsh, dsh-bundle, llm-pi-ai, preset

## 简介

Personal dsh profile bundle: disables the shipped agent presets, builds generated standard / ptc presets into dist, declares personal llm-pi-ai provider routes, and carries the deployment sandbox access rules.
