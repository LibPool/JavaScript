# @kareemelbalshe/any-table

> 标签: any-table, auto-columns, data-table, pagination, react, react-table, search, smart-table, sorting, table, typescript

## 简介

A developer-facing, smart data table library with 3-tier API detection, auto columns, server/client search, sort & pagination, extensible action callbacks, and customizable themes.
