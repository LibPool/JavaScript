# @alex_rexby/n8n-nodes-telegram-mtproto

> 标签: gramjs, mtproto, n8n, n8n-community-node-package, telegram, userbot

## 简介

Telegram MTProto (GramJS) userbot trigger for n8n — слушает новые сообщения по StringSession. Корректный disconnect при деактивации (смена сессии без рестарта n8n) и явная ошибка на отозванной сессии.
