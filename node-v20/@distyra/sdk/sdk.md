# @distyra/sdk

> 标签: counterparty, distyra, europe, merchant enrichment, open banking, openapi, psd2, sepa, transaction categorization, transaction enrichment, typescript, underwriting

## 简介

TypeScript SDK for the Distyra Transaction Enrichment & Underwriting API: EU-hosted merchant and counterparty recognition for European bank data. Generated from the committed OpenAPI spec.
