# react-native-cloudflare-worker-kv

> 标签: cloudflare, cloudflare-workers, expo, feature-flags, firebase-remote-config, react-native, remote-config, workers-kv

## 简介

Remote config for React Native and Expo, backed by Cloudflare Workers KV: in-app defaults, fetch and activate, typed getters and an offline cache.
