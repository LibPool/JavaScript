# @moncho-ai/analyst-discovery-mcp

> 标签: analyst, market-intelligence, mcp, model-context-protocol, moncho

## 简介

MCP server for Moncho analyst discovery (read lookups) plus HITL staging of market facts. Thin authenticated client over the Moncho Discovery and stage APIs; no database credentials required.
