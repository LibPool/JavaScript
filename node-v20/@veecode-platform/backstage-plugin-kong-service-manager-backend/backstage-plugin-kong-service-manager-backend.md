# @veecode-platform/backstage-plugin-kong-service-manager-backend

> 标签: JavaScript

## 简介

Backstage backend plugin that proxies requests to the [Kong Admin API](https://docs.konghq.com/gateway/latest/admin-api/), letting catalog entities manage their Kong services, routes, and plugins from the Backstage UI.
