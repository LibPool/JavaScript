# @ops-frontier/docusaurus

> 标签: JavaScript

## 简介

Ops Frontier の開発においてはドキュメントをマークダウンで記述し、 Docusaurus で配信する。 このリポジトリでは、 Docusaurus のテンプレートを利用して、マークダウンのプレビューを行う仕組みを提供する。
