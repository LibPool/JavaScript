# @straitlink/capacitor

> 标签: app-links, capacitor, capacitor-plugin, deep-linking, deferred-deep-linking, dynamic-links, ionic, universal-links

## 简介

Deep linking for Capacitor and Ionic apps: direct links (App Links, Universal Links, custom schemes), deferred links that survive the install and link-open analytics. Wraps the Strait Android and iOS SDKs.
