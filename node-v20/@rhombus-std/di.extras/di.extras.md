# @rhombus-std/di.extras

> 标签: compiler, dependency-injection, di, ioc, transformer, typescript

## 简介

The ioc authoring surface: the build-time primitives a registration author writes against. A Go/ttsc descriptor package — the primitive-transform runs in the shared owner binary.
