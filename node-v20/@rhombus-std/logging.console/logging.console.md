# @rhombus-std/logging.console

> 标签: console, ioc, logger, logging, typescript

## 简介

Console logging provider: ConsoleLogger + ConsoleLoggerProvider, the ConsoleFormatter abstraction with the simple/json/systemd built-ins (ANSI colors), formatter/logger options, and an async background queue writer — against @rhombus-std/logging.core's IL
