# @richardmcquiston01/gemini-icon-gen

> 标签: ai, gemini, gemini-api, genai, generative-ai, google-gemini, icon-generation, image-generation

## 简介

Generate style-consistent icons with Google's Gemini image API, the same way a Gemini "Gem" does — system instructions plus reference images in, a matching icon out.
