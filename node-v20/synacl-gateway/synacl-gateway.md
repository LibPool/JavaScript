# synacl-gateway

> 标签: gateway, iot, modbus, modbus-tcp, mqtt, raspberry-pi, synacl, tasmota, telemetry, zigbee2mqtt

## 简介

Reference gateway for the Synacl IoT platform: turn any machine with Node.js into a Synacl gateway (host metrics, local MQTT bridge, Modbus TCP).
