# @t2000/cli

> 标签: agent, ai, cli, gasless, mcp, mpp, sui, t2000, usdc, usdsui, wallet

## 简介

Agent Wallet for AI agents on Sui — gasless USDC + USDsui sends, Cetus swap, MPP paid API access, MCP integration, scriptable from any shell.
