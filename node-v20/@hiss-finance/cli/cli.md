# @hiss-finance/cli

> 标签: agentic, cli, coilops, defi, hiss, hiss-finance, read-only, robinhood-chain, staking, unsigned-transactions, usdg, vault

## 简介

Command-line interface for the HISS agentic trading control plane on Robinhood Chain — public reads, strategy compilation, risk fuses, unsigned transaction preparation and receipt verification.
