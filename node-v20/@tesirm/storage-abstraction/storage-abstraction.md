# @tesirm/storage-abstraction

> 标签: amazon s3, azure, backblaze b2, cloud, cloud filesystem, cloud storage, cloudflare r2, cubbit, google cloud, minio, storage, storage abstraction

## 简介

This is a fork of @tweedegolf's package. It provides an abstraction layer for interacting with a storage; the storage can be local or any of the supported cloud storage services.
