# @agdsoftware/sso-sdk

> 标签: authorization, iam, jwt, keycloak, nestjs, oauth2, oidc, permissions, pkce, rbac, react, sdk, sso

## 简介

Keycloak/OIDC tabanlı merkezi yetkilendirme SDK'sı — evrensel izin istemcisi, sunucuda JWT doğrulama, web ve mobil için PKCE, NestJS guard zinciri ve React hook'ları; tek paket, ayrı girişler.
