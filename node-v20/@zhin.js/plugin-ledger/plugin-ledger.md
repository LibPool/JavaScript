# @zhin.js/plugin-ledger

> 标签: bot, expense, ledger, plugin, zhin, zhin.js

## 简介

Personal expense ledger for Zhin.js (Plugin Runtime): per-user entries in integer cents, period and category summaries, group privacy and an opt-in daily report
