# @unikia/upe-renderer

> 标签: JavaScript

## 简介

Unikia's three.js for games, build r186p10: three.js r186 with GPU instance culling, leaner GPU uploads, batched uniform writes, per-pass GPU timings, capability tiers and a public API for freeing GPU resources. Installs as `three` through an npm alias.
