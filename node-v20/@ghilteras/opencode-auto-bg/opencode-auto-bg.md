# @ghilteras/opencode-auto-bg

> 标签: architect, async, background, delegation, opencode, opencode-plugin, subagent

## 简介

Transparent automatic backgrounding for OpenCode subagents. Backgrounds a configured parent agent's children on session.created and delivers missed child results with a bounded, generation-deduped wake path, plus a state-based TODO-sync nudge. No API chan
