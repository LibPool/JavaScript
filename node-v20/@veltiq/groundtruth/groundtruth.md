# @veltiq/groundtruth

> 标签: agent, ai, claude, claude-code, cli, code-review, coding-assistant, cursor, diff, hallucination, hook, playwright, provenance, self-healing, verification

## 简介

The human-in-the-loop for AI coding, automated. Catch when your agent lies, leaves typos, or skips work — verify every turn against the real diff, then make it run/screenshot/test and self-fix before finishing. Claude Code hook + CLI.
