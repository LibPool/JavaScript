# transitions-agent

> 标签: accessibility, animations, css, lint, motion, scanner, transitions, ui

## 简介

Scan your codebase for missing, janky, or inconsistent UI transitions. Get a motion score, ready-to-apply fixes from transitions.dev recipes, and an optional pull request with the fixes.
