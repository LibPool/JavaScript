# @johnhenry/a2a-query-tanstack

> 标签: JavaScript

## 简介

TanStack Query bridge for @johnhenry/a2a-query — queryOptions/mutationOptions factories that sync a2a-query's own reactive cache into TanStack Query, including task/card push updates and optimistic updates, with zero extra refetches.
