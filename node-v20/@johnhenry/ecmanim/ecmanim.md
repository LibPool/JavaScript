# @johnhenry/ecmanim

> 标签: 3blue1brown, animation, bezier, canvas, manim, math

## 简介

A JavaScript port of manim (Mathematical Animation Engine). Runs in Node (renders to MP4 via ffmpeg) and in the browser (live canvas + WebM export).
