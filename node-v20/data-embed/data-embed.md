# data-embed

> 标签: JavaScript

## 简介

An embeddable aggregate data widget that renders inside a Shadow DOM. Configure dimensions (grouping fields) and metrics (aggregations) to show chart and table views of summarized data. Powered by React, Highcharts, and shadcn/ui.
