# @elinpf/dsh-ops-tool-prometheus

> 标签: JavaScript

## 简介

prometheus tool consumer of the ops-access seam — resolves prometheus profiles and runs PromQL instant/range queries over the Prometheus HTTP API, injecting the bearer token automatically.
