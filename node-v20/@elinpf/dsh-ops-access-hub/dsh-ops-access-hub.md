# @elinpf/dsh-ops-access-hub

> 标签: JavaScript

## 简介

Standalone credential hub for the dsh ops suite: encrypted-at-rest storage, token-authenticated REST API, minimal web UI, and a YAML registry importer. Not a dsh plugin.
