# @elinpf/dsh-ops-access-gate

> 标签: JavaScript

## 简介

Ops access gate — per-session credential brokering. Owns an in-process grant ledger keyed by agent.id and registers a pure-decision broker (ro/rw) into the ops-access seam. Never touches credential fields.
