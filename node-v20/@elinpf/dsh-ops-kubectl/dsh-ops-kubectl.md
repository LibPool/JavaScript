# @elinpf/dsh-ops-kubectl

> 标签: JavaScript

## 简介

kubectl tool consumer of the ops-access seam — resolves k8s profiles into kubeconfig paths and runs kubectl via ctx.shell; list_access surfaces registered profiles without secret fields.
