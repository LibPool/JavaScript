# @screenshotapp/screenset

> 标签: app-store, cli, fastlane, google-play, marketing, mcp, screenshots

## 简介

Screenset: App Store and Google Play screenshot sets from a JSON spec, rendered by the Appshot engine. CLI + MCP server for terminal and agent workflows.
