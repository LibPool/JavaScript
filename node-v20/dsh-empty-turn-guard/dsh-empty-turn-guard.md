# dsh-empty-turn-guard

> 标签: deepseek-harness, dsh, dsh-plugin, empty-turn, plugin, reasoning, transcript, zero-width

## 简介

DSH plugin: detect assistant turns that end with no visible text (zero-width placeholder) and re-prompt the model to write the answer; also injects a visible-closing-answer system prompt rule.
