# @taprun/from-playwright

> 标签: ai-agent, browser-agent, browser-automation, claude-code, compile, cursor, deterministic, drift-detection, mcp, mcp-server, model-context-protocol, playwright, playwright-converter, playwright-migration, playwright-to-mcp, replay, scraping, tap, tap-cli, taprun

## 简介

Convert Playwright scripts into Tap v2 plans. Compile .spec.ts / .test.ts files into deterministic v2 Plan JSON that runs at zero LLM tokens in Claude Code, Cursor, and any MCP host.
