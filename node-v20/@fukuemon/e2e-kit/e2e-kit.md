# @fukuemon/e2e-kit

> 标签: JavaScript

## 简介

Playwright の E2E のテストで、字幕とカーソルを重ねたエビデンスの録画、エビデンスの名前と置き場、ログインの保存を行う kit と、テストの書き方の ESLint の規則
