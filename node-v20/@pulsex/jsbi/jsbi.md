# @pulsex/jsbi

> 标签: JavaScript

## 简介

JSBI is a pure-JavaScript implementation of [the official ECMAScript BigInt proposal](https://tc39.es/proposal-bigint/), which is on track to become a part of the JavaScript language in the near future.
