# @dloizides/game-shell

> 标签: crash-overlay, dvh, eisaipollis, game, install-prompt, pwa, viewport, web-game

## 简介

Framework-free web game shell: fits the visible viewport (--gs-vh), offers install (chip / card / iOS steps), shows a crash overlay, pauses on hide, unlocks audio, polls for new versions, shares a link (Web Share, copy, QR) and downloads assets for offlin
