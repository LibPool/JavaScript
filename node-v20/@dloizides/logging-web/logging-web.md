# @dloizides/logging-web

> 标签: logging, observability, offline-queue, react-native, structured-logging

## 简介

Client-side structured logging for RN-web apps: batching LoggingService, offline replay queue, HTTP transport, device/session enrichers, and a console-style logger facade.
