# @dloizides/frontend-devtools

> 标签: dev-tooling, dloizides, eslint, eslint-plugin, react-native

## 简介

Shared RN-web dev tooling (dev-only) for the dloizides.com SaaS frontends: the custom ESLint plugin pack and rule packs (/eslint) and the test-results reporters (/test-results). initI18n moved to @dloizides/i18n in 2.0.0. Never imports a product.
