# grunt-buildfiles

> 标签: assets, build, buildfiles, concat, css, files, grunt-buildfiles, gruntplugin, html, javascript, jshint, less, lint, minify, template, uglify

## 简介

Build and set javascript, css, html, and less assets dynamically for other grunts tasks (jshint, concat, uglify) and to build index.html and other grunt template files
