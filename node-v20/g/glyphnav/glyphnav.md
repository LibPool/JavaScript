# glyphnav

> 标签: address-bar, angular-router, animation, decode, glitch, history, navigation, next, nextjs, nuxt, preact, preact-iso, react-router, router, scramble, solid-js, solid-router, spa, svelte, sveltekit, tanstack-router, text-effect, url, vue-router

## 简介

Animate navigation: random glyphs resolve into the destination URL right in the address bar. Framework-agnostic core with Vue Router, React Router, Solid Router, TanStack Router (React & Solid), Angular Router, Preact (preact-iso), Next.js, Nuxt and Svelt
