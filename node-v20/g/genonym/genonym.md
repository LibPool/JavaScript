# genonym

> 标签: Convert, DNA, Gene, Genetics, Genome, Genomics, Protein, RNA, Species, Transfer, Translate

## 简介

Convert the DNA sequence that codes for a protein in one species to the appropriate sequence that will work in a different species, while optimizing for translation.
