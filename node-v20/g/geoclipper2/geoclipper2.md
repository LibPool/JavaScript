# geoclipper2

> 标签: JavaScript

## 简介

This is a set of polygon clipping and offsetting operations, originally based off of (clipper2)[https://github.com/AngusJohnson/Clipper2]. The port of Clipper2 is limited to Clipper64 and inflatePaths, with a focus on the int64 implementations.
