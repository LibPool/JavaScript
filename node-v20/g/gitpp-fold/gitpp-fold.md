# gitpp-fold

> 标签: append-only, fold, git, git.pp, provenance, quilt, records

## 简介

A browser-portable JavaScript port of the git.pp fold. Pure ESM, no build step, no transpilation, no dependencies. Returns setters (spec §5.6) so nudges can be authored against the record that actually holds a key. 4th port in the doc-only-discipline seri
