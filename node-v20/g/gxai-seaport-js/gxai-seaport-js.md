# gxai-seaport-js

> 标签: JavaScript

## 简介

[Seaport](https://github.com/DogeLandGame/gxai-seaport-js) is a new marketplace protocol for safely and efficiently buying and selling NFTs. This is a TypeScript library intended to make interfacing with the contract reasonable and easy.
