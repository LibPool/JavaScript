# generate-password-in-client-side

> 标签: browser generator, client-side generator, generate passphrase, generate password, generator, passphrase, passphrase generator, password, password generator, secure passphrase, secure password

## 简介

A lightweight and secure password and passphrase generator for JavaScript and TypeScript. Suitable for generating strong passwords and memorable passphrases for applications, websites, and other purposes, both in the browser and in Node.js environments.
