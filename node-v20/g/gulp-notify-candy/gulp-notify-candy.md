# gulp-notify-candy

> 标签: growl, gulp, gulpplugin, mac notification, notification, notify, notify-osd, notify-send, reporter, windows notification

## 简介

fork for gulp-notify / gulp plugin to send messages based on Vinyl Files or Errors to Mac OS X, Linux or Windows using the node-notifier module. Fallbacks to Growl or simply logging
