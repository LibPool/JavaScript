# ghini

> 标签: JavaScript

## 简介

2026 版现代 TS 脚手架：基于 Node 24 原生 ESM，利用“源码直连”实现免 build 实时调试；通过 esbuild 抹除后缀并配合 publishConfig，兼顾开发爽感与发布标准，是极致紧凑的 npm 库闭环模板。
