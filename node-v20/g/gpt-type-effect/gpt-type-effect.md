# gpt-type-effect

> 标签: animator, chat, chatgpt, chatgpt-text, chatgpt-typing-effect, effect, gpt, gpt-typing, gpt4 text effect, react-text, react-type-effect, react-typing-effect, text, text-effect, type, typewriter, typing, typing effect, typing-effect

## 简介

A typewriter, which generates the type effect like the ChatGPT website's like AI typing, with thinking. Here are lots of features that you can use, ie. thinking delay, typing delay, minimum typing delay, maximum typing delay.
