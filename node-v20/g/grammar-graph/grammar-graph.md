# grammar-graph

> 标签: automaton, context-free grammar, decision graph, decision tree, decision-making graph, digraph, directed graph, formal language, generator, grammar, grammar graph, graph, language generator, nfa, non-deterministic finite state machine, nondeterministic, state machine

## 简介

Takes a context-free grammar and converts it into a decision-making graph. Can produce interactive Guides which generate valid sentences from the grammar.
