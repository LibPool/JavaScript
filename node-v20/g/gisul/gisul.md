# gisul

> 标签: agent, claude, claude-code, eval, framework, llm, skills, test-runner

## 简介

A framework for authoring and testing Claude Code skills. Scaffold, lint, and format SKILL.md files, run YAML cases through `claude -p` to check that each skill triggers the way it should, and bench the skill-on/off lift to see if it actually helps.
