# gw-sso-sdk

> 标签: auth, authentication, gw-sso, sso, sso-sdk, 单点登录, 统一认证

## 简介

统一认证（SSO）前端接入 SDK：通过 window.GW_SSO 配置，自动完成 getCurrInfo 登录态检测、ticket 换 token、注销与认证中心跳转
