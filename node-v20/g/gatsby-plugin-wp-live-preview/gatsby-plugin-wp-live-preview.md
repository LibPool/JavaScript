# gatsby-plugin-wp-live-preview

> 标签: gatsby, gatsby-plugin, live-preview, preview, wordpress, wp

## 简介

Gatsby plugin that adds a WordPress live preview page with URL-reachability polling and a Gatsby-Cloud-style status bar.
