# gt-docmost

> 标签: JavaScript

## 简介

`gt-docmost` 是一个自注册的 Web Component 富文本编辑器。引入后使用 `<gt-docmost>` 标签即可接入，支持 Vue 2、Vue 3、React 和原生 HTML；同一页面可以创建多个相互独立的编辑器实例。
