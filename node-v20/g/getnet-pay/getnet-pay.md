# getnet-pay

> 标签: GetnetPay, expo, getnet-pay, react-native

## 简介

Este pacote fornece métodos para inicializar o terminal, capturar cartões via aproximação (Tap-to-Pay), processar transações e lidar com callbacks do fluxo de pagamento.
