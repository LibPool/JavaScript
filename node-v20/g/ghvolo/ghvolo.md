# ghvolo

> 标签: JavaScript

## 简介

A command line tool that uses volo as a library to do searches and resolutions of github IDs for front end/browser-based web dependencies

## 官网

- 官网：http://github.com/volojs/ghvolo
- npm 页面：https://www.npmjs.com/package/ghvolo

## 历史版本号

- 当前版本：0.0.1

- 0.0.1

## 获取地址

- npm 安装：`npm install ghvolo`
- npm registry：https://registry.npmjs.org/ghvolo
- Node 要求：>=0.6.17
