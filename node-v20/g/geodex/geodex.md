# geodex

> 标签: countries, country, currencies, currency, data, esm, geo, geography, i18n, internationalization, iso, iso-3166, iso-4217, language, languages, locale, lookup, tree-shaking, typescript, world, zero-dependency

## 简介

A modern, zero-dependency, and tree-shakeable JavaScript library for comprehensive country, currency, and language data. Includes full TypeScript support and lookup functions.
