# google-ads-mcp-unofficial

> 标签: ads-automation, advertising, ai-agents, campaign-management, google-ads, marketing, mcp, model-context-protocol

## 简介

Unofficial MCP server for connecting AI agents to the Google Ads API. Read campaigns, keywords, performance. Optional gated mutations for bids, budgets, and pause/resume.
