# glyphforge

> 标签: 3d, ascii, crt, generative, glsl, hero, landing-page, postprocessing, react-three-fiber, shader, three, webgl

## 简介

Drop-in WebGL ASCII hero sections for React. One component, any 3D model — or forge one in the browser from text, SVG, an image, or a parametric shape.
