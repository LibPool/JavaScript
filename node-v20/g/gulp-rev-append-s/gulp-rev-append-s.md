# gulp-rev-append-s

> 标签: cache, cache-busting, gulp, gulp-rev-append, gulpplugin, revision

## 简介

The MD5 of the file is not verified, but the suffix is generated according to the file name and current time 不校验文件的MD5,而是根据文件的文件名和当前时间生成后缀
