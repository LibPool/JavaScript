# grapple

> 标签: document references, mongo, mongodb, mongoose, nested documents, nested references, schema

## 简介

Abstracts the creation of Mongoose schemas, encapsulating the creation of inline dynamic schemas, the definition of 'in' and 'out' transformation methods that handle complex nested document references.
