# glove-env-base

> 标签: JavaScript

## 简介

Knowledge-base stdlib adapter for glove-working-environment. Mounts pages, blocks and collections as env:base — pages read as markdown, rows as flat records, files pulled into the tree. Bring a provider: two methods are required, the rest are capabilities
