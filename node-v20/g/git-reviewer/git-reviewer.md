# git-reviewer

> 标签: agent, ai, cli, code-review, code-review-tool, coding-agent, developer-tools, diff, git, llm, local-first, review

## 简介

Review your coding agent's changes like a pull request — locally, with inline comments and threaded follow-ups, then hand the marked-up review back to the agent
