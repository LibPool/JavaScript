# ghake-jsnote

> 标签: JavaScript

## 简介

1. Install globally    ```bash    npm install -g ghake-jsnote    ```    - Preferred way    ```bash    ghake-jsnote serve    ``` 1. Or use npx    ```bash    npx ghake-jsnote serve    ``` 1. A notebook will be either created or opened depending
