# gulp-html-tojsfile

> 标签: JavaScript

## 简介

Allows you to write your lit-html in a separate file and have it sucked into your Polymer / Web Component at build time

## 官网

- npm 页面：https://www.npmjs.com/package/gulp-html-tojsfile

## 历史版本号

- 当前版本：0.4.8

- 0.4.8

## 获取地址

- npm 安装：`npm install gulp-html-tojsfile`
- npm registry：https://registry.npmjs.org/gulp-html-tojsfile
- Node 要求：>=8.0
