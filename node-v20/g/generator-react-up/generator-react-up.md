# generator-react-up

> 标签: ES6 Classes, Pure Functions, React Generator, Stateless Component, Yeoman Generator, boiler-plate, component, yeoman-generator

## 简介

A simple and customizabe React Generator. 
Written in ES6 (babel) this generator allows the end user to configure the templating of custom templates... 
Spend less time writing boiler-plate code and more time writing the fun stuff.
