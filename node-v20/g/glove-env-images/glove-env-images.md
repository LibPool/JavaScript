# glove-env-images

> 标签: JavaScript

## 简介

Image stdlib adapter for glove-working-environment. Bridges sharp into the agent's virtual filesystem as env:images — describe an image without reading its bytes, resize, convert, crop, rotate, composite, draw text and contact-sheet. Animated GIF/WebP kee
