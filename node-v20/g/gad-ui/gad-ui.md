# gad-ui

> 标签: gad, primitives, radix, react, shadcn, tailwind, ui

## 简介

shadcn/ui-based primitives consumed by gad-visual-context and downstream GAD-framework apps. Button, Dialog, Tabs, HoverCard, Tooltip, Sheet, ScrollArea, Select, Sidebar, Switch, etc. — Radix-driven, Tailwind v4 compatible.
