# grounded-rag-mcp

> 标签: embeddings, hybrid-search, llm, mcp, model-context-protocol, rag, reranking, retrieval

## 简介

An MCP server that gives any LLM host grounded, cited retrieval over your own documents — hybrid BM25 + dense retrieval, cross-encoder-ready reranking, and built-in eval.
