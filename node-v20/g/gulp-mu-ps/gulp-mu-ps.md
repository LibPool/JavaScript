# gulp-mu-ps

> 标签: atlas, css, layer-effects, microgulp, png, psd, sprite, ugulp

## 简介

microPS - Node module to render PNG series and sprite atlases from layered image drafts (PSD), replacing the old Adobe-based workflow.
