# google-flights-mcp

> 标签: ai-tools, carbon-emissions, claude, flight-search, flights, google-flights, mcp, model-context-protocol, price-tracking, travel

## 简介

The most feature-rich MCP server for Google Flights. 12 tools for search, price tracking, cabin comparison, emissions, layover analysis, and more. No API key required.
