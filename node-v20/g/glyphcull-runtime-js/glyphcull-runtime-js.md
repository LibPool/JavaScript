# glyphcull-runtime-js

> 标签: canvas, compiled, document, gpu, msdf, renderer, runtime, webgl

## 简介

The GlyphCull JavaScript document runtime: a compiled-document host for .cull packages (load/scroll/paint/select/copy/destroy).
