# goldsrc-rcon

> 标签: counter-strike, cs1.6, goldsrc, half-life, rcon, source-engine

## 简介

Minimal GoldSrc (CS 1.6, TFC, ...) RCON client for Node.js — UDP challenge handshake + split-packet response reassembly, no dependencies.
