# git-regrets

> 标签: audit, blame, cli, code-quality, codebase, developer-tools, fixme, git, git-blame, hack, leaderboard, tech-debt, technical-debt, todo

## 简介

The leaderboard of shame for any git repo: your oldest TODO, FIXME, HACK and "temporary" fixes, git-blamed with age and author. Zero config, zero dependencies, works offline.
