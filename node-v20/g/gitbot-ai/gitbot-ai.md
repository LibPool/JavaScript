# gitbot-ai

> 标签: agent, ai, bot, claude, cli, codex, coding-agent, opencode, websocket

## 简介

Run Claude Code, Codex, or OpenCode from any device on your network — a local server that puts an AI coding agent in your browser, with reusable bots, threads, and per-bot setup instructions.
