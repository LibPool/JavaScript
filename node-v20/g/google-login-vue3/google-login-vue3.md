# google-login-vue3

> 标签: authentication, authorization, code-grant, frontend-auth, google-login-vue3, google-oauth2, google-signin, javascript, login, oauth, security, vue-component, vue3

## 简介

A lightweight and customizable Vue 3 component for Google OAuth 2.0 authentication, supporting both code-based and JWT-based authentication modes.
