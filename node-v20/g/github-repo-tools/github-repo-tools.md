# github-repo-tools

> 标签: github

## 简介

Useful tool to get versions (node or npm package) from repo(s) of Github user/org

- 官网：https://github.com/lightness/github-repo-tools#readme
- 源码仓库：git+https://github.com/lightness/github-repo-tools.git
