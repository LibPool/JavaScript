# glyphfill

> 标签: font-weight, loading, progress, progress-bar, react, svelte, tailwind, text, typography, variable-font, vue

## 简介

Show progress inside a word: letters get heavier, or fill with ink, as a task completes. For React, Vue, Svelte and plain JavaScript.
