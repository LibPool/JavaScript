# gqlviz

> 标签: JavaScript

## 简介

Upload a local GraphQL schema file into a deployed graphql-editor visualizer instance, without any server-side infrastructure.

## 官网

- 官网：https://graphqleditor.com
- 源码仓库：git+https://github.com/graphql-editor/graphql-editor.git
- npm 页面：https://www.npmjs.com/package/gqlviz
