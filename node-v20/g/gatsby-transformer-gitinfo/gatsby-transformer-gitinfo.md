# gatsby-transformer-gitinfo

> 标签: gatsby, gatsby-plugin, git

## 简介

Gatsby transformer plugin which add git info to File nodes created by gatsby-source-filesystem

- 官网：https://github.com/kraynel/gatsby-transformer-gitinfo
