# gruenstromindex-server

> 标签: corrently, energy, greenpowerindex, gruenstromindex, swagger

## 简介

[EN] Forecast for the amount of renewable energy in german grid.  [DE] Prognose des Anteils an Grünstrom an einem Ort in Deutschland. Der Grünstromindex kann bundesweit zur Optimierung von Ladezeiten von E-Autos dienen sowie zum Anbieten von zeitvariablen
