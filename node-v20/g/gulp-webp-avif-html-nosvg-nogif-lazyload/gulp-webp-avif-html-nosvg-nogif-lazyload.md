# gulp-webp-avif-html-nosvg-nogif-lazyload

> 标签: avif, gulp, html, lazyload, webp

## 简介

Converting <img> images to <picture> with support for modern formats and popular layout methods. No SVG, no GIF format, data- support for https://github.com/verlok/vanilla-lazyload and support img atrr sizes, srcset
