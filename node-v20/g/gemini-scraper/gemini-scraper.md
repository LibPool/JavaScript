# gemini-scraper

> 标签: ai-scraping, gemini-api, gemini-api-endpoint, gemini-scraper, gemini-scraper-api, google-gemini, llm-scraping, scraping-api, scrapingbee, web-scraping-api

## 简介

Gemini scraper and Gemini API endpoint client built on ScrapingBee. Send prompts to Google Gemini, get text, markdown and citations as JSON.

## 官网

- 官网：https://www.scrapingbee.com/features/gemini/
- 源码仓库：git+https://github.com/ScrapingBee/gemini-scraper.git
- npm 页面：https://www.npmjs.com/package/gemini-scraper
