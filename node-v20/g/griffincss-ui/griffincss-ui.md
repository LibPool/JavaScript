# griffincss-ui

> 标签: button, card, combobox, components, css, form, gallery, griffincss, griffinjs, lightbox, megamenu, sass, scss, slider, ui

## 简介

Griffincss UI — компоненты интерфейса: кнопки, поля, карточки, таблицы, статусы; на токенах ядра, с обеими темами и режимом для слабовидящих. Плюс GriffinJS — опциональный слой виджетов: слайдер, галерея, лайтбокс, параллакс, мегаменю, дропдаун, подсказка
