# git-replay

> 标签: ai-agent, bisect, bug, claude, codex, git, regression, repro, testing, vercel-ai-gateway

## 简介

A deterministic bug-fixing harness: hand it a bug, get back a reproducing test, a verified fix, and the commit that introduced it — proven by code that runs, not by prose.
