# gs-web-hooks

> 标签: JavaScript

## 简介

一个轻量级库，为 Web 应用中的 `XMLHttpRequest` 和 `fetch` API 提供响应拦截器。它允许您在应用处理 HTTP 响应之前拦截和修改它们。
