# gridsome-plugin-svg

> 标签: gridsome, gridsome-plugin, svg, svgo

## 简介

Everytime I start a new [Gridsome](https://gridsome.org) project, I have to go and set up SVG inlining. It's annoying having to do it over and over, so like my [Tailwind CSS](https://github.com/brandonpittman/gridsome-plugin-tailwindcss) plugin, I created
