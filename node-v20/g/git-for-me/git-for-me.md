# git-for-me

> 标签: agent-skills, claude-code, codeberg, github, gitlab, mcp, mcp-server, open-source

## 简介

Git for me! Odds are, most of what you want to build is already open source. Tell your AI agent what you're making; it finds the repos on GitHub, GitLab and Codeberg, every one checked live.
