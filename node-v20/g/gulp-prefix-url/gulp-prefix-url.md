# gulp-prefix-url

> 标签: css, gulp, html, img, path, plugin, prefix, replace, script, tag, url

## 简介

为html中的某些标签特定的属性值,如link[href]的值添加前缀(往往是静态资源cdn域名地址),修改自gulp-prefix
