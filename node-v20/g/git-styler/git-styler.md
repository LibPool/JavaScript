# git-styler

> 标签: cli, commit, commitlint, formatter, git, git hooks, style

## 简介

**Git Styler** is a CLI tool designed to simplify and standardize commit message styling by providing structured commit commands. It follows the **conventional commit format**, helping developers maintain clean, consistent, and meaningful commit histories
