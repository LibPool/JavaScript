# grundlage

> 标签: custom-elements, declarative-shadow-dom, grundlage, hydration, shadow-dom, ssr, template-literals, web-components, zero-dependency

## 简介

Zero-dependency library for building web components with tagged template literals, server-rendered and hydrated on the client.
