# gulp-rev-all

> 标签: all, asset, assets, aws, cache, cdn, cloudfront, expire, gulp-rev, gulp-rev-all, gulpplugin, hash, optimize, rev, revision, s3, static, version, versioning

## 简介

Static asset revisioning by appending content hash to filenames: unicorn.css => unicorn.098f6bcd.css, also re-writes references in each file to new reved name.
