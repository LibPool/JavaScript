# gulp-mu-ft

> 标签: color-font, colr, css, emoji, font, gulp, icomoon, icon, microgulp, svg, ttf, ugulp, woff, woff2

## 简介

microFT - Node module to generate icon fonts from SVG glyphs and package webfonts including OpenType color fonts and emoji fonts (TTF/OTF/WOFF/WOFF2, CSS, HTML overview).
