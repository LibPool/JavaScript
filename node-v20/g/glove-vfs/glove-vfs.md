# glove-vfs

> 标签: agent, glove, llm, sandbox, vfs, virtual-filesystem

## 简介

One virtual filesystem for a whole agent. A zero-dependency Vfs contract plus backends (in-memory, host directory copy-on-write, object storage), a mount table that composes them into a single tree, path-scoped access policies, an optional metadata/proven
