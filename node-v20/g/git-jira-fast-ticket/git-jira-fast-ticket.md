# git-jira-fast-ticket

> 标签: automation, bash-script, branch-management, cli, development-tools, git, jira, linux, macos, productivity, project-management, ticket-creation, unix, workflow

## 简介

Streamline your workflow with this CLI tool that creates Jira tickets and automatically switches to a new Git branch named after the ticket. Perfect for developers using Git and Jira for project management on Unix-like systems.
