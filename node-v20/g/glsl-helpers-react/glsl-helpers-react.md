# glsl-helpers-react

> 标签: glsl, glsl-helpers, react, shader, shadertoy, webgl, webgl2

## 简介

React GLSL canvas component with Shadertoy-compatible uniforms, WebGL2 support, and extended texture helpers. Fork of shadertoy-react.
