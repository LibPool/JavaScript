# grunt-vmc-versioning

> 标签: assets, assets versioning, cdn, css file, file name, grunt, gruntplugin, js file, json output, statics, version, versioning

## 简介

Generate md5/sha1/sha256/sha512 hash based on the content of a file and append to it. Versioning static assets with Grunt.
