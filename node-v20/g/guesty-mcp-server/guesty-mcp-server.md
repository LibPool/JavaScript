# guesty-mcp-server

> 标签: ai-agent, airbnb, automation, enterprise, guesty, hospitality, iot, mcp, mcp-server, model-context-protocol, pms, property-management, real-estate, short-term-rental, vacation-rental, vrbo

## 简介

MCP server for Guesty property management — 43 registered tools, all free (42 Guesty tools + get_license_info), + 7 addressable resource templates covering reservations, guests, messaging, pricing, revenue, tasks, webhooks, and IoT/property-health.
