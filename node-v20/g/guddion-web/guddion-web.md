# guddion-web

> 标签: claude, claude-code, design-review, landing-page, mcp, model-context-protocol

## 简介

Local, click-to-comment visual review for HTML you're still building — Claude Code publishes a block to a local review server, you click an element and leave feedback, Claude reads it back anchored by a screenshot.
