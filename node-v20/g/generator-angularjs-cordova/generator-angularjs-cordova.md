# generator-angularjs-cordova

> 标签: angularjs, bootstrap3, cordova, grunt, phonegap, yeoman-generator

## 简介

A yeoman generator which combines the best features and practices to initialise and scaffold an AngularJS based cordova mobile app using a module based approach. Includes Angular UI, Bootstrap 3.
