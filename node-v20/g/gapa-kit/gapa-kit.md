# gapa-kit

> 标签: agent, ai, claude-code, copilot, cross-ide, cursor, hooks, kiro, self-learning, steering, trae, vscode, windsurf

## 简介

GAPA — Generalized Action and Prompt Adaptation. A cross-IDE self-learning framework for AI Agents. Supports Kiro, Cursor, Claude Code, VS Code (Copilot), Windsurf, and TRAE.
