# grunt-qiniu-deploy-glob

> 标签: JavaScript

## 简介

A grunt plugin which to deploy static resources to qiniu base on grunt-qiniu-deploy.Replace options.resource attribute with this.files

## 官网

- npm 页面：https://www.npmjs.com/package/grunt-qiniu-deploy-glob

- npm registry：https://registry.npmjs.org/grunt-qiniu-deploy-glob
- Node 要求：>= 0.10.0
