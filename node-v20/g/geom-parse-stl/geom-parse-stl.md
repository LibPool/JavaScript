# geom-parse-stl

> 标签: ascii, parser, simplicial-complex, stl, webgl, webgpu

## 简介

Parse a STL (StereoLithography) ASCII string, ArrayBuffer or ArrayBuffer with ASCII data, and return a simplicial complex.
