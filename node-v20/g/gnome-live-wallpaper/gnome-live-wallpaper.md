# gnome-live-wallpaper

> 标签: gnome, gnome-shell, hanabi, live-wallpaper, opengl, particles, wallpaper, wayland

## 简介

Live wallpapers for GNOME Shell on Wayland: a Hanabi fork with HTML wallpapers and a native C++/OpenGL ES particle renderer.
