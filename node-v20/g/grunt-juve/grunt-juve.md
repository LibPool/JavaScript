# grunt-juve

> 标签: gruntplugin

## 简介

Grunt plugin to execute juve (assertions for Phantomas) performance tests and act upon the results, e.g beacon out, write to log, etc.

## 官网

- npm 页面：https://www.npmjs.com/package/grunt-juve
