# git-backstory

> 标签: agents, ai-coding, backstory, claude-code, cli, code-archaeology, codex, context-engineering, copilot, cursor, developer-tools, git, git-blame, git-log, history, zero-dependencies

## 简介

The backstory of a file, in one page, for whoever has to change it next: reverts, fix bursts, reasons from commit bodies, co-changed files and owners, from git log and git blame. Zero dependencies.
