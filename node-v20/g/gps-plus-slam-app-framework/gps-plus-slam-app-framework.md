# gps-plus-slam-app-framework

> 标签: ar, framework, gps, slam, three.js, webxr

## 简介

Reusable AR+GPS app framework layer — WebXR session management, Three.js visualization, GPS sensors, storage abstractions, replay engine, and store wiring for gps-plus-slam-js.
