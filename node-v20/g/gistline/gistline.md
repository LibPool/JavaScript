# gistline

> 标签: ai, aider, claude-code, cli, codex, compression, context-window, copilot, cursor, deterministic, docx, gemini-cli, html, llm, logs, markdown, mcp, pdf, pptx, test-output, tokens, xlsx, zero-dependencies

## 简介

Compress large command output, logs and documents before an AI assistant reads them - and know whether anything was removed. Zero dependencies, deterministic, with the original always retrievable.
