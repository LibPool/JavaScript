# gql-codegen-pydantic

> 标签: JavaScript

## 简介

`gql-codegen-pydantic` is a plugin for [`graphql-codegen`](https://graphql-code-generator.com/docs/getting-started/)  that generates [Pydantic](https://pydantic-docs.helpmanual.io/) types from any graphql schema

## 官网

- npm 页面：https://www.npmjs.com/package/gql-codegen-pydantic
