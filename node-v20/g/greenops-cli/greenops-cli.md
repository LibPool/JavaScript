# greenops-cli

> 标签: aws, azure, carbon, carbon-footprint, ci, cloud, co2, devops, finops, gcp, github-actions, green-cloud, greenops, infrastructure, multi-cloud, sustainability, terraform

## 简介

Carbon footprint linting for Terraform plans: AWS, Azure, and GCP. Analyses infrastructure changes including Kubernetes node groups for Scope 2, Scope 3, and water impact. Posts recommendations directly on GitHub PRs.
