# google-measurement-mcp

> 标签: analytics, claude, cursor, ga4, google-analytics, google-search-console, google-tag-manager, gsc, gtm, mcp, mcp-server, measurement, modelcontextprotocol, search-console, seo, tag-manager

## 简介

MCP server for the Google measurement stack — GA4, Search Console, and Tag Manager in one server. Read tools always on, write tools behind an explicit flag, destructive operations omitted by design.
