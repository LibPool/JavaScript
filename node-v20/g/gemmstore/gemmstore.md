# gemmstore

> 标签: blas, compute-shader, gemm, gpu, matrix-multiplication, webgpu, wgsl

## 简介

Single-file WebGPU GEMM library with device-tuned kernels (F32, F16). Use for fast matrix multiply in browser WebGPU apps.
