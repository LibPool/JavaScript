# geolibre-wasm

> 标签: geolibre, geospatial, geotiff, gis, lidar, wasi, wasm, whitebox

## 简介

Pure-Rust geospatial toolkit (whitebox_next_gen) compiled to WebAssembly (WASI) for GeoLibre's in-browser tool execution
