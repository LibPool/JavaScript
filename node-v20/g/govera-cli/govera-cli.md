# govera-cli

> 标签: agenda, ai-agent, api, cli, govera, government, govtech, mcp, public-agency

## 简介

Official CLI for the Govera public API — governance platform for public agencies (cities, counties, school districts). Query service status, product info, capabilities, and guides from the terminal or CI.
