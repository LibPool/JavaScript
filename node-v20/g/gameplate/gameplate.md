# gameplate

> 标签: browser, canvas, esm, fsm, game, game-engine, game-framework, game-loop, headless, renderer-agnostic, state-machine, tiny, typescript, webgl, zero-dependencies

## 简介

Tiny, zero-dependency, fully-typed TypeScript framework for browser & headless games — state, loop, input, scenes. Bring any renderer.
