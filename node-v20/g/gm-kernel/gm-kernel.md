# gm-kernel

> 标签: Cesium, Supercluster

## 简介

GM Kernel 是 GM-Builds 系列的核心基础库，主要负责封装 Cesium 引擎和相关依赖库，为其他 GM 系列库提供统一的基础模块导出。

- npm 页面：https://www.npmjs.com/package/gm-kernel
