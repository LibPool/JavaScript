# generator-angular-reply

> 标签: angular, docker, javascript, ngRx, pwa, yeoman-generator

## 简介

Project structure Angular2+ (tested with v.13). Optionals: imagemin(images compression), Flask(server mocks), Cordova(mobile), ngRx(state management) and much more!
