# github-nodejs-shell-server-updater

> 标签: auto deploy, github, github hooks, node, nodejs, server, update

## 简介

Automatic deploy from Github to your server, listen to push updates from Github, pull updated code, install, build and start pm2 process.

## 官网

- 源码仓库：https://github.com/Jsox/github-nodejs-shell-server-updater.git
- npm 页面：https://www.npmjs.com/package/github-nodejs-shell-server-updater
