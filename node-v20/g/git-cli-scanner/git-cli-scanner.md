# git-cli-scanner

> 标签: api-keys, cli, git, pre-commit, scanner, secrets, security, vulnerability

## 简介

A powerful interactive CLI tool that scans your codebase for hardcoded secrets, API keys, passwords, and private keys before they reach your Git history.
