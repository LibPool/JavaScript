# ganaderiajs

> 标签: agent, beefmaster, cli, ganaderia-js-beefmasters, llms-txt, openapi

## 简介

Official CLI for the Ganadería JS Beefmasters public content API: fetch pages with content negotiation, inspect rate-limit headers, and read the OpenAPI spec, sitemap, and llms.txt.
