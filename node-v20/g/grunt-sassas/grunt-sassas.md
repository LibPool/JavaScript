# grunt-sassas

> 标签: gruntplugin

## 简介

Grunt plugin to take advantage of the SASSAS Direct Conversion API to remove the need to have SASS installed on the local machine

## 官网

- 官网：http://sassas.uk
- 源码仓库：git://github.com/hazanjon/sassas-grunt.git
- npm 页面：https://www.npmjs.com/package/grunt-sassas

- npm registry：https://registry.npmjs.org/grunt-sassas
- Node 要求：>= 0.8.0
