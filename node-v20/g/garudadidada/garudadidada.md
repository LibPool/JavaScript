# garudadidada

> 标签: bytes, duration, esm, filesize, format, human-readable, humanize, ordinal, pluralize, relative-time, time-ago, zero-dependencies

## 简介

Tiny zero-dependency helpers to turn machine values (bytes, durations, numbers, dates) into human-readable strings.
