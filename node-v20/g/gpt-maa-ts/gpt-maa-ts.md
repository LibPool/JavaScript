# gpt-maa-ts

> 标签: ai, artificial-intelligence, function-calling, genai, genai-chatbot, large-language-models, llm, multi-agent, multi-agent-systems, openai, openai-api

## 简介

A TypeScript client for submitting AgentDefinitions and user prompt to a gpt-multi-atomic-agents REST API, to generate supported mutations.
