# glitchless-playtest

> 标签: automated-testing, bots, game-development, game-observability, gamedev, mcp, performance, phaser, playtest, playtesting, playwright, regression-testing, threejs, web-games

## 简介

Playtest bots for game observability: autoplay bots play your web game (Three.js, Phaser) on the current code and on a saved baseline, and Glitchless flags what got slower or started breaking.
