# graphql-butler

> 标签: api, client, graphql, graphql-client, microservice, ql, react, react-native

## 简介

Cliente GraphQL desenvolvido em NodeJS para facilitar o desenvolvimento de projetos JavaScript que usam GraphQL como API. A declaração de tipo TypeScript está dentro do pacote para projetos em TypeScript
