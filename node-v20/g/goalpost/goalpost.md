# goalpost

> 标签: agent, autonomy, claude-code, cli, codex, goal-contract, roadmap, task, verification

## 简介

A goal-contract roadmap loop for agentic development: verification-gated tasks, a single live pointer, and an agent-agnostic autonomy runner. No dependencies.
