# go-equality

> 标签: check equality, deep equal, deep equality, equal, equality, equality check, loose equal, loose equality, loosely equal, strict equal, strict equality, strictly equal

## 简介

Equality checking functions that work for both primitive types and objects, including nested objects and cyclic objects with a circular reference.
