# gft-mcp

> 标签: claude, gitforthought, mcp, mcp-server, memory, modelcontextprotocol, thinking-map, white-box-context

## 简介

GFT (Git for Thought) MCP server — bring your white-box thinking map to any AI agent. 把你在 GFT 确认过的思维脉络接给任何 agent:用它们的 token,走 GFT 的规则。
