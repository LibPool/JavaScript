# gesso-devtools

> 标签: canvas, debugging, devtools, error-overlay, gesso, inspector, profiler, typescript, ui

## 简介

See what a Gesso application is doing, and what it threw: an error overlay with source-mapped stacks, drawn over the app that failed.
