# generator-frontapp

> 标签: yeoman-generator

## 简介

Yeoman generator for front apps, it let's you specify folder structure and generates gruntfile/Gulpfile accordingly, optionally it let's you add tools such as (Bootstrap/Foundation, Grunt/Gulp, optional IE8 support, jQuery, Less/Sass ...)
