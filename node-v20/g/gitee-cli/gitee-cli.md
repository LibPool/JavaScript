# gitee-cli

> 标签: JavaScript

## 简介

gitee-cli，一个简单的gitee命令行工具，利用[Gitee API](https://gitee.com/api/v5/swagger)。可以在命令行中列出、创建、删除仓库，启动、更新Gitee Pages。 ### 安装 `npm install -g gitee-cli` ### 使用 #### 配置 使用前需设置access_token和username
