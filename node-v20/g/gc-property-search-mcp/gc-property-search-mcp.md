# gc-property-search-mcp

> 标签: gis, greenville-county, mcp, property-search, register-of-deeds, south-carolina, tax-records

## 简介

MCP server for Greenville County SC property records: GIS parcels, Register of Deeds, tax assessments, zoning, vehicle tax, scanned archives (1780s-present), and historical court records
