# gentelella

> 标签: admin, command-palette, css, dark-mode, dashboard, datatables, echarts, html, modern, pwa, scss, template, theme-generator, vanilla-js, vite

## 简介

Gentelella v4 — free admin template. 58 pages, 20 chart variants, fully interactive inbox & kanban, live theme generator, component playground, PWA-ready. Vite 8, vanilla JS, no Bootstrap, no jQuery.
