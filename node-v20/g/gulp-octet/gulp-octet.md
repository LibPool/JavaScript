# gulp-octet

> 标签: engine, es, es-template, es6, es6-template, gulp, gulpplugin, plugin, template, tpl, transform

## 简介

Gulp plugin for `octet` - 1kb template engine. Support helpers, partials and more. Used in AbsurdJS apps.
