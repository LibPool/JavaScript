# get-runtime-lm

> 标签: JavaScript

## 简介

该函数判断浏览器类型和版本，返回字符串形式，可能的值有'IE11~6'，'chrome'，‘FF’，'Opera','Safari','sougoujisu Chrome/49.0'。
