# git-commit-helper-skill

> 标签: agent, claude, cli, codex, conventional-commits, git, skill

## 简介

An installable agent skill that analyzes git changes, drafts a Conventional Commits message, and commits only after user confirmation. Works with Codex, Claude Code, and any agent that reads SKILL.md.
