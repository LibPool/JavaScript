# gh-issue-lease

> 标签: agents, coordination, distributed-lock, gh, git, github, issues, lease, lock, multi-agent, mutex

## 简介

Atomic, GitHub-native mutex for multi-agent work. The lock IS a git ref — no server, no database. First writer wins.
