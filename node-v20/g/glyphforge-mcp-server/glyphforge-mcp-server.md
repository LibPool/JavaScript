# glyphforge-mcp-server

> 标签: agent, ascii, claude, codex, cursor, glyphforge, mcp, model-context-protocol, three, webgl

## 简介

MCP server for Glyphforge — teaches a coding agent the library, recommends a hero that suits the site it is looking at, and finds the 3D model to put in it.
