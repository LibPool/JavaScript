# grunt-auto-version

> 标签: file version, version, version control, versioning

## 简介

this grunt plugin automates versioning of modified files and backs-up the files as well.This is integrated with Git and quite helpful for the versioning of static resources which needs to versioned to remove caching on CDN servers.
