# gap-cli

> 标签: JavaScript

## 简介

**gap-cli**는 브랜치 생성, 커밋, 푸시를 한 번에 처리하는 간단한 **Git 자동화 CLI**입니다.   복잡한 명령어 입력 없이, `gap main feat: 첫 커밋` 한 줄로 끝낼 수 있습니다.
