# gulp-estilo

> 标签: JavaScript

## 简介

Plugin de `gulp.js` usado internamente en [Estudio Cíclope](http://ciclo.pe/) para validar nuestra guía de estilo de `html`, `css` y `javascript`.

## 官网

- npm 页面：https://www.npmjs.com/package/gulp-estilo
