# geodata-js

> 标签: address, cities, countries, country-list, geography, iso-3166, iso-639, nextjs, provinces, states, subdivisions

## 简介

250 countries, 5,308 subdivisions, 152,970 cities and 420 ISO 639 languages, validated and versioned. Zero dependencies. Works in Node, Next.js, Vite, Bun, Deno and React Native.
