# gulp-svg-css-pseudo

> 标签: css, gulpplugin, inline, minification, pseudoelements, svg

## 简介

Gulp plugin that embeds svg images inside a single CSS file using data-uri. Created on the basis of the plugin gulp-svg-css by Jan Bevers
