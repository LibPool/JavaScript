# gestao-cli

> 标签: JavaScript

## 简介

Esta CLI permite gerar módulos NestJS (Service, Resolver, DTOs, Entity) a partir do seu `schema.prisma`, facilitando o desenvolvimento de aplicações NestJS com Prisma.
