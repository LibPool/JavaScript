# gatsby-source-custom-api-with-fetchoptions

> 标签: allows-post-requests, api, cache, fetchOptions, gatsby, gatsby-plugin, image, json, source

## 简介

Source data from any API and transform it into Gatsby-nodes. Download your image files and use them with Gatsby Image. Allows POST requests.
