# glove-env-zip

> 标签: JavaScript

## 简介

Archive stdlib adapter for glove-working-environment. Reads and writes zip, tar and tar.gz inside the agent's virtual filesystem as env:archives — list, describe, extract selectively, package a directory back up. Includes password-based unlocking for encr
