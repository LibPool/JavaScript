# google-search-console-connector

> 标签: antigravity, claude, claude-code, csv-export, google-oauth, google-search-console, gsc, gsc-api, mcp, mcp-server, model-context-protocol, search-analytics, search-console, search-console-api, seo, seo-dashboard, seo-tools, site-verification, sitemaps, url-inspection

## 简介

Google Search Console for Claude Code: MCP server, one-command GSC report export (CSV), URL inspection, sitemaps, site verification and a local SEO dashboard. Sign in with Google in one click; runs locally, no API keys.
