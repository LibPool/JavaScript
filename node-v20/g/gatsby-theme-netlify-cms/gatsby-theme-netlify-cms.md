# gatsby-theme-netlify-cms

> 标签: cms, gatsby, gatsby-plugin, gatsby-theme, local development, netlify, netlify-cms, react

## 简介

Gatsby theme for Netlify-CMS. The theme uses netlify-cms-backend-fs to support local development.
