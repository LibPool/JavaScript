# github-mcp-sketch

> 标签: agent, anthropic, claude, claude-code, github, github-mcp, json-schema, llm, mcp, model-context-protocol, token-efficiency

## 简介

MCP proxy in front of the GitHub MCP that returns inferred schemas instead of raw JSON, plus a query_response tool for drilling back into cached values. Built on json-schema-sketch.
