# gls-channel-address-plugin

> 标签: JavaScript

## 简介

Este é um plugin para o [framework de e-commerce Vendure](https://www.vendure.io/) é uma ferramenta que facilita o gerenciamento dos endereços associados aos canais de venda em uma loja online. Com esse plugin, você pode registrar, atualizar e excluir end
