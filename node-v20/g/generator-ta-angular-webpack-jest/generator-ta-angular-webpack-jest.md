# generator-ta-angular-webpack-jest

> 标签: angular, angular-material, es2015, es6, generator, jest, lazy-load, sass, webpack, yeoman-generator

## 简介

Angular Webpack ES6 generator. Uses SASS as CSS preprocessor, UI router as default angular router, LazyLoading example included. Forked from generator-angular-webpack-es6
