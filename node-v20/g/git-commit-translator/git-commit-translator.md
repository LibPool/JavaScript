# git-commit-translator

> 标签: JavaScript

## 简介

在git提交时调用谷歌API把提交信息转换成英文， 配置项： project-id 谷歌云的项目ID（使用前先要在环境变量中设置account和项目对应的tockenjson，具体参考[google cloud link](https://cloud.google.com/sdk/docs/initializing)
