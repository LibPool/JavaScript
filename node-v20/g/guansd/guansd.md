# guansd

> 标签: guansd, local-dev, mcp, 观思动

## 简介

观思动本地开发命令行：登录一次，在你自己的编程助手（Codex / Qoder / Claude Code / Trae …）里建应用、推代码、部署开发版。

- 源码仓库：git+https://github.com/wenguo17/guansd.git
