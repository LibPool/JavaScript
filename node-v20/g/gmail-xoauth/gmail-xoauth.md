# gmail-xoauth

> 标签: gmail, imap, xoauth

## 简介

Generate xoauth string from oauth 1.0 token for Gmail IMAP login. The logic is taken from http://code.google.com/p/google-mail-xoauth-tools/source/browse/trunk/python/xoauth.py
