# guddion-mcp

> 标签: ai-agent, claude, claude-code, mcp, model-context-protocol

## 简介

Free, self-hosted MCP agent for Claude Code: search and get briefings on your local projects, and delegate routine subtasks to a budget-tier model through your own API key.
