# gulp-custom-rev

> 标签: asset, assets, cache, expire, gulpplugin, hash, optimize, rev, revision, static, version, versioning

## 简介

Static asset revisioning by appending content hash to filenames: unicorn.css => unicorn-098f6bcd.css
