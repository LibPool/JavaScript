# generator-cronjob

> 标签: JavaScript

## 简介

In order to scaffold a new cron job, from the *root* of the [infra-reporting-jobs](https://github.com/Morgan-and-Morgan/infra-reporting-jobs) project run the following: ``` npx yo cronjob ```
