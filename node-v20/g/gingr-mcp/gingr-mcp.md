# gingr-mcp

> 标签: boarding, claude, daycare, gingr, grooming, mcp, model-context-protocol, pet-care

## 简介

Model Context Protocol (MCP) server for read-only access to Gingr pet-care facility data — owners, animals, reservations, appointments, and services.
