# gitdep

> 标签: deterministic, git-dependencies, monorepo, npm, package-manager, source-dependencies, subpath, workspaces

## 简介

A source-based package layer for npm. Git repos are the source of truth; gitdep resolves, builds, packs, and caches them deterministically, then lets npm install.
