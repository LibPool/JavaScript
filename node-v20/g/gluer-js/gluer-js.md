# gluer-js

> 标签: browser, gluer, integration, message-bus, messagepack, pubsub, realtime, rpc, sdk, websocket

## 简介

Browser/JavaScript SDK for Gluer, a managed real-time integration layer: WebSocket messaging with RPC, pub/sub, automatic reconnect, offline queue and HTTP fallback.
