# guang-js-code

> 标签: encrypt, js加密, js混淆, obfuscate

## 简介

这是一个加密js文件的工具，默认指定当前目录以及子目录的js文件，也可以指定目录，记得先备份好原js文件

## 官网

- npm 页面：https://www.npmjs.com/package/guang-js-code

- npm registry：https://registry.npmjs.org/guang-js-code
- Node 要求：>=14.0.0
