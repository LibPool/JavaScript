# grunt-svg2png-width

> 标签: grunt, gruntjs, gruntplugin, image, phantom, phantomjs, png, rasterise, rasterize, svg

## 简介

Grunt plugin to rasterize SVG to PNG images using PhantomJS. From nwtn's fork of dbushel's package. Allows specific svg widths to be set.
