# grunt-updateref

> 标签: gruntplugin

## 简介

A Grunt plugin to update the references of external js/css files in html file. 
It is mostly used after grunt-contrib-concat plugin.

- 官网：https://github.com/meronmee/grunt-updateref
- 源码仓库：git://github.com/meronmee/grunt-updateref.git
- npm 页面：https://www.npmjs.com/package/grunt-updateref
