# gaollard-gyp-test

> 标签: JavaScript

## 简介

JSON.parse 无法处理 int64, 被广泛使用的方案是 [json-bigint](https://www.npmjs.com/package/json-bigint), 但这个库的性能实在太慢了，处理大 JSON 会严重阻塞 node 主线程。
