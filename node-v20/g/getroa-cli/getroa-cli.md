# getroa-cli

> 标签: agent, ai, aider, claude, codex, human-in-the-loop, notifications, remote, telegram

## 简介

Remote control plane for AI agents: notifications, two-way prompts. Built for Claude Code, Codex, Aider, and any CLI that needs to ask a human something while they're away from the keyboard.
