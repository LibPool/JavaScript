# @markieboy1991/cordova-plugin-inset-injector

> 标签: Insets, android-only, cordova, cordova-android, e2e, ecosystem:cordova, edge-to-edge, edgetoedge, ete, safe area, system bars

## 简介

A Cordova plugin that will inject css variables that correspond with the hardware level insets. This is to get around the limitations of lower versions of the android webview that do not correctly inject the safe-area-inset values
