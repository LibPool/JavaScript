# dsh-agnes-image

> 标签: agnes, ai, deepseek, deepseek-harness, dsh, dsh-plugin, image-generation, video-generation

## 简介

Agnes image and video generation for DeepSeek Harness: two agent tools, an AI prompt optimizer, and a sidebar panel whose API key is entered in the panel and never shipped in the code.
