# @nometria-ai/appwrite-migrate

> 标签: appwrite, baas, backend, cli, collections, database, devtools, migrations, schema, seed

## 简介

Schema-driven migration runner for Appwrite. The missing prisma migrate for Appwrite - creates collections, seeds data, tracks applied migrations.
