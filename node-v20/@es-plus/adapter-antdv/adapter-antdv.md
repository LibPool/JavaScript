# @es-plus/adapter-antdv

> 标签: ai-friendly, ant-design-vue, antdv, component-library, config-driven, crud, dialog, enterprise, es-plus, form, json-schema, modal, table, typescript, vue, vue3

## 简介

ES-Plus Ant Design Vue adapter — configuration-driven enterprise components (EsForm/EsTable/EsDialog/EsCrudPage) for Vue 3 + Ant Design Vue 4.x. Shares the same JSON config schema as @es-plus/vue3 and @es-plus/vue2.
