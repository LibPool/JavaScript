# @blackunicorn/bonklm-daytona

> 标签: ai-safety, code-execution, daytona, experimental, guardrails, sandbox, security

## 简介

Daytona Workspace wrapper for BonkLM. Proxies process.* + fs.* with code-injection + path-traversal validation. EXPERIMENTAL (Story 3.5).
