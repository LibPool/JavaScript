# @blackunicorn/bonklm-e2b

> 标签: ai-safety, code-execution, e2b, experimental, guardrails, sandbox, security

## 简介

E2B Sandbox wrapper for BonkLM. Proxies commands.run / runCode / files.* with code-injection + path-traversal validation. EXPERIMENTAL (Story 3.5).
