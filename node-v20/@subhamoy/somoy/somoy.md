# @subhamoy/somoy

> 标签: agent, ai, llm, providers, runtime, sdk, typescript, zod

## 简介

Somoy (Bengali for 'time') — a transparent, hand-rolled AI Agent SDK for TypeScript. Provider-agnostic, zod-typed, runtime-agnostic (Bun + Node 18+).
