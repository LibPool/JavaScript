> 标签: buy me a coffee, crowdfund, crowdfunding, donations, funding goal, github sponsors, ko-fi, paypal, stretch goals, stripe, webhook, zod

## 简介

Crowdfunding state as data: zod schemas for goals, tiers, donations and refunds, integer minor-unit money math in any currency, goal progress, stretch tiers, top donors that respect anonymity, dedupe, and webhook helpers for Ko-fi, Stripe, PayPal, GitHub
