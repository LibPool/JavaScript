# @haruhimemoe/vcs

> 标签: diff, diff3, history, json diff, merge, revisions, three-way merge, version control

## 简介

Revisions, diffs and 3-way merges for JSON documents and text. Line diffs, keyed-list aware JSON diffs, diff3 text merge, structured merge with conflicts, canonical hashing. No dependencies.
