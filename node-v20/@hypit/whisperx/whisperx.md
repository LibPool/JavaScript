# @hypit/whisperx

> 标签: JavaScript

## 简介

Explicit WhisperX model-family capability for speech alignment. Importing this package selects WhisperX; Runtime registration binds the resulting evidence Need to a concrete Endpoint. The package contains no credentials, Python environment or queue.
