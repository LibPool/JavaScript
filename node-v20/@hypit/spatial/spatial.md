# @hypit/spatial

> 标签: JavaScript

## 简介

Pure two-dimensional video geometry. The package owns the final raster viewport, resolved picture-plane geometry, source extents and affine mappings. It owns no layer tree, media, Paint, motion, Timeline, detector, Provider or renderer policy.
