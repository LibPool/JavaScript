# @hypit/timeline-author

> 标签: JavaScript

## 简介

Construct one finite absolute Timeline from a small acyclic graph of named Instants and Windows. This package owns author syntax and lowering; [`@hypit/timeline`](../timeline/README.md) owns only the completed value `{ id, frameRate, frameCount }`.
