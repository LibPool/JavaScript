# @s3p1r0o/snoopy

> 标签: ai-agent, cli, deepseek-harness, dsh, llm, openai-compatible, proxy, rill

## 简介

Run DeepSeek Harness (dsh) against Rill Cloud's AI assistant in one command, through an embedded OpenAI-compatible proxy (localhost-only, ephemeral key).
