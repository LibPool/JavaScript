# @iyowei/sweep-node-modules-cli

> 标签: batch, bulk, bun, clean, cleaner, cleanup, cli, cli-tool, del, delete, disk-space, disk-usage, free-up-space, modules, monorepo, node, node-modules, node_modules, npm, pnpm, prune, remove, remover, sweep, tool, workspace, yarn

## 简介

CLI to find and delete node_modules across projects: scan multiple workspace roots (monorepo friendly), bulk-remove them to free up disk space, preview first and delete after confirmation. 工作区级 node_modules 批量清理工具。
