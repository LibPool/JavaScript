# @wog890/mxcomponent

> 标签: cjs, commonjs, ecmascript, esm, javascript, nodejs, npm, typescript

## 简介

Package which provides the mxcomponent class to provide progressive enhancement for HTMLElements by wrapping them in a class with additional properties and methods.
