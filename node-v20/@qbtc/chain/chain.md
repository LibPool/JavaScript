# @qbtc/chain

> 标签: JavaScript

## 简介

Esplora-compatible chain client for wallets on the QBitcoin protocol — balance, UTXOs, fee estimates, broadcast, node failover. Ships no endpoint URLs: the consumer supplies its node list.
