# @formwright/ui

> 标签: custom-elements, design-system, form-associated, formwright, ui, web-components

## 简介

Web components built on Formwright's headless foundation: <fw-button>, <fw-input>, <fw-select> and the rest. Framework-free, form-associated, themeable with CSS custom properties, one import path per component.
