# @vastare/pkgn-vastui

> 标签: JavaScript

## 简介

Tree-shakable SCSS and TypeScript UI kit for Vastare, providing reusable public, admin, and framework-adaptable components for WordPress, raw JS/TS, and SPA frontends.
