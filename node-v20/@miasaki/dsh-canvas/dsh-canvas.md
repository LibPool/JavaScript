# @miasaki/dsh-canvas

> 标签: JavaScript

## 简介

会话布：可浏览、可分支、可合并的 DSH 会话画布。把会话从一条时间线变成一张可拖拽的地图，双线汇合产出真实 DSH 会话；不改系统提示、不改模型请求、不改工具 schema。
