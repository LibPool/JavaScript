# @miasaki/dsh-ssh

> 标签: JavaScript

## 简介

会话头第一行入口 + 页面内交互式 SSH：多 shell、SFTP 文件传输、跳板与本地转发。不用切外部终端，在 DSH 里直接连服务器。

- npm 页面：https://www.npmjs.com/package/@miasaki/dsh-ssh
