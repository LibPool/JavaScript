# @gang-of-beads/pi-web-background-runs

> 标签: pi-background-tasks, pi-package, pi-web, pi-web-plugin

## 简介

PI WEB plugin for pi-background-tasks: a Background tab listing the session's tasks, a running count in the activity line, and task-ended notices in the conversation.
