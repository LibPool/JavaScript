# @zahardev/aicontext

> 标签: ai, ai-context, claude, codex, coding-assistant, context, copilot, cursor, developer-tools, django, flutter, laravel, nestjs, nextjs, project-context, sdd, spec-driven-development, wordpress

## 简介

Give your AI coding assistants persistent memory about your project. Works with any language (PHP, Python, JS, Rust, Go) and framework (Laravel, Django, Next.js, WordPress). Supports Claude Code, Codex, Cursor, opencode, Pi, and GitHub Copilot.
