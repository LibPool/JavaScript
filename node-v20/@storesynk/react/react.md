# @storesynk/react

> 标签: commerce, headless, react, react-router, remix, shopify, ssr, storefront, tanstack-start, web-components

## 简介

Framework-agnostic React bindings for Storesynk — server-render Shopify data inside Storesynk tags from any classic-SSR React stack (TanStack Start, Remix, Vite SSR), adopted flash-free by the client runtime.
