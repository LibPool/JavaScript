# @nadeemlab/sm-rust

> 标签: bioinformatics, multiomics, rust, spatial, wasm, webassembly

## 简介

Spatial multiomics primitives (neighbour graphs, Moran's I, nhood enrichment, Ripley, co-occurrence) compiled to WebAssembly.
