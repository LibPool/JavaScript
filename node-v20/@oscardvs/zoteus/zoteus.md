# @oscardvs/zoteus

> 标签: bibliography, chatgpt, citations, claude, mcp, mcp-server, model-context-protocol, reference-manager, zotero, zotero-api

## 简介

MCP server that gives Claude, ChatGPT and other MCP clients access to a Zotero library: search, citations, adding items, safe writes, semantic search, PDF passages and page images.
