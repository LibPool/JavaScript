# @opticell/drawpad-mcp

> 标签: 3d-printing, cad, claude, cookie-cutter, drawpad, keychain, mcp, stl

## 简介

Lets Claude design 3D-printable models (keychains, cookie cutters, signs, stencils, custom parts) with DrawPad Pro.stl's engine: watertight STL, editable DrawPad project and a preview. An MCP server for macOS.
