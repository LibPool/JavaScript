# @hlf-core/transport

> 标签: block-parser, blockchain, chaincode, distributed-ledger, fabric, hyperledger, hyperledger-fabric, transport, typescript

## 简介

TypeScript library for Hyperledger Fabric client transport: command sending, block and event parsing, batch delivery and chaincode error handling
