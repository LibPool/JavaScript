# @metamynd/magp-hcs2

> 标签: agentsafe, decentralized-identity, did, did:hedera, hcs, hedera, magp, metamynd, mirror-node, trustless

## 简介

MAGP Phase D — decentralized discovery: resolve did:hedera documents + service endpoints from the DID's own HCS registry topic via a public Hedera mirror node, trustlessly, with MetaMynd offline. Zero dependencies.
