# @metamynd/agentsafe-guard

> 标签: agent, agents, agentsafe, ai, ai-safety, authorization, compliance, ed25519, governance, guardrails, magp, mandate, metamynd, policy

## 简介

Zero-dependency runtime governance for any Node AI agent — gate tool calls through MetaMynd/AgentSafe (allow / block / escalate) against the agent's mandate, enforced Standards, and SOPs. Ed25519-signed, deterministic, fail-closed.
