# @bractjs/bractjs

> 标签: bun, framework, full-stack, react, react19, routing, server-actions, ssr, streaming, typescript

## 简介

Production-grade SSR framework for Bun + React 19. File-based routing, streaming SSR, server actions, typed routes.
