# lanyard-cli

> 标签: cli, git, github, gitlab, huggingface, multiple-accounts, remote-servers, ssh, ssh-client, ssh-config, ssh-keys, ssh-manager, tauri

## 简介

Wear the right identity everywhere: switch between GitHub, GitLab, Bitbucket and Hugging Face accounts in one click, and manage your remote SSH servers, keys, ssh-agent and known_hosts from a desktop app, the system tray or the command line.
