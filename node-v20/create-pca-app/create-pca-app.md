# create-pca-app

> 标签: agent authorization, ai agents, cli, create-app, pca, proof-carrying authority, scaffold, starter

## 简介

Scaffold a working Proof-Carrying Authority app in seconds: npm create pca-app@latest — mint a capability, build + sign a proof-carrying action, and verify it offline (valid passes, tampered fails).
