# @letznav/ngtools-webpack

> 标签: angular, aot, plugin, webpack

## 简介

Webpack plugin that AoT compiles your Angular components and modules. Modified by letznav to allow multiple entry modules.

- 官网：https://github.com/angular/angular-cli/tree/master/packages/@ngtools/webpack
- 源码仓库：git+https://github.com/angular/angular-cli.git
- npm 页面：https://www.npmjs.com/package/@letznav/ngtools-webpack
