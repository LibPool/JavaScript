# @adelie/agent-company

> 标签: JavaScript

## 简介

Company mode for Adelie agents: creating the organization with the user, the employee protocol every desk and ticket session follows, plus the CEO, HR and finance playbooks for running an organization on calendar events, tickets, channels and budgets.
