# @shinjinseop/next-api-capture

> 标签: api, app-router, capture, debugging, devtools, fetch, instrumentation, nextjs, rsc

## 简介

Capture server-side (SSR/RSC, route handlers, server actions) and client API calls of a Next.js App Router app, and inspect them in a Chrome DevTools panel.
