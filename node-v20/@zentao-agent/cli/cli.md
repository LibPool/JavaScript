## 简介

AI-agent toolkit CLI (`zt`) for ZenTao — installs agent integrations, manages the bug hub + repos.yaml registry, exposes direct ZenTao API commands via @zentao-agent/sdk, and ships a built-in stdio MCP server (`zt mcp`).
