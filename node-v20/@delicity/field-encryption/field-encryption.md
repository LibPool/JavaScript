# @delicity/field-encryption

> 标签: aes-256-gcm, bun, database, encryption, field-level-encryption, iban, key-rotation, totp

## 简介

Versioned field-level encryption for database columns (v1.<ciphertext>) — AES-256-GCM, built-in key rotation, zero dependencies. Bun & Node.js.
