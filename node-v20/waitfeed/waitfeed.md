# waitfeed

> 标签: hacker-news, news, opencode, opencode-plugin, reader, rss, terminal, ticker, tui

## 简介

While your agent works: a slim news ticker above the input box + a /news fullscreen reader, with story-anchored AI digests. No ads, no keys, no server.
