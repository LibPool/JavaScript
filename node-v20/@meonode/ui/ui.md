# @meonode/ui

> 标签: accessible-components, component-composition, component-library, css-in-js, design-system, dynamic-theming, frontend, jsx-free, meonode, meonode-ui, no-jsx, react, react-components, theme-engine, type-safe, typescript, ui-framework, web-development

## 简介

A structured approach to component composition, direct CSS-first prop styling, built-in theming, smart prop handling (including raw property pass-through), and dynamic children.
