# @meonode/compiler

> 标签: compiler, meonode, nextjs, swc, swc-plugin, vite, wasm

## 简介

SWC WASM plugin that rewrites @meonode/ui call sites into pre-partitioned marker props at build time, letting the @meonode/ui runtime skip its own static/dynamic prop classification and prop-signature hashing on every render
