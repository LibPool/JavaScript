# @gaia-ai/addon-ports

> 标签: JavaScript

## 简介

GAIA ports command plugin: discover a ticket worktree's running services (DDEV, Designbook, ad-hoc listeners) and bring shareable tunnels up and down. The command half of GAIA-475; usable without the cockpit half.
