# @ploutosservices/estate-table

> 标签: copy, css, filter, html-table, no-framework, react, sort, table, vanilla-js

## 简介

One look and one behaviour for plain HTML tables: a stylesheet and a small script — sort, filter, copy to a spreadsheet or an email. No framework, no build step.
