# @emulates/oauth

> 标签: apple, emulates, emulator, fault-injection, github, google, microsoft, oauth, openid-connect, social-login

## 简介

Social-login emulator with Google, Apple, Microsoft, GitHub and generic OIDC profiles, private relay identities, reproducible edge cases, signed tokens and an accessible UI.
