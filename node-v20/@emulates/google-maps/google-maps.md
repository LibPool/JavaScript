# @emulates/google-maps

> 标签: address-validation, autocomplete, emulates, geocoding, google, maps, places, service, usps

## 简介

Emulator of Google Places Autocomplete / Details / Find Place, the Geocoding API, a Maps JavaScript (places) shim and the Address Validation API (USPS CASS/DPV verdicts), over a QA address corpus, with Google's status codes and fault presets.
