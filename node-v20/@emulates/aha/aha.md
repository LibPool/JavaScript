# @emulates/aha

> 标签: aha, bloodwork, emulates, lab, phlebotomy, service, sftp, webhooks

## 简介

Stateful AHA phlebotomy emulator with signed HTTP orders, status webhooks, and a real deterministic SSH/SFTP result server.
