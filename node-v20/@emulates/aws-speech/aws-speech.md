# @emulates/aws-speech

> 标签: aws, emulates, eventstream, polly, service, speech, stt, transcribe, tts

## 简介

Stateful emulator of AWS Polly (SynthesizeSpeech, StartSpeechSynthesisStream) and Transcribe (streaming over h2c, batch jobs), with exact event-stream framing and scripted transcripts.
