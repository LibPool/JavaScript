# @medullaflow/ribosome-schema

> 标签: json-schema, mcp, mcp-registry, ribosome

## 简介

TypeScript types, validation, and version pins for the ribosome standard (project manifest + lockfile). The normative artifact is the JSON Schema itself; this package is a convenience layer on top.
