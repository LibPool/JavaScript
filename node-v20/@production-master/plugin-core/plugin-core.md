# @production-master/plugin-core

> 标签: JavaScript

## 简介

Host-neutral thin-client core for the Production Master multi-IDE plugin (service client, device-code auth, MCP session scoping, SSE event stream, projection renderers). Imports NO LLM/provider SDK — enforced by CI.
