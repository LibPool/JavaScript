# @ttigger/claude-status

> 标签: claude, claude-code, cli, hud, statusline, usage

## 简介

A portable Claude Code statusline HUD (usage, model, git, context) with 4 styles, desktop ping notifications, a cc launcher, and a config CLI with live preview.
