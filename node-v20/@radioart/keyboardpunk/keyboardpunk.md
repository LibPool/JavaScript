# @radioart/keyboardpunk

> 标签: audit, css, ios, keyboard, lint, mobile, scanner, visualviewport

## 简介

Find iOS keyboard input traps in your codebase. Scans HTML, JSX, TSX, Vue, Svelte for position:fixed bottom-pinned containers with focusable inputs that the iOS soft keyboard hides.
