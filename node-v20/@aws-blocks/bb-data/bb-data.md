# @aws-blocks/bb-data

> 标签: aurora, aws-blocks, database, postgresql, sql

## 简介

Full PostgreSQL database — provisions Aurora Serverless v2 by default, or connects to an existing PostgreSQL database (Supabase, Neon, etc.) via `fromExisting()`. Full relational modeling with foreign keys, transactions, Row Level Security, and a type-saf
