# @integraledger/profile-facilitator

> 标签: asset-hub, facilitator, lcp, legal-context-protocol, polkadot, trc20, tron, x402

## 简介

An x402 facilitator for the LCP profiles x402/exact/tron/lcp-trc20-memo and x402/exact/polkadot/lcp-assets-remark: verifies and settles payments whose signed transaction carries the ATR hash.
