# @twobots/game-kit

> 标签: JavaScript

## 简介

Shared non-visual logic for the twobots.dev card-game lineup — a seeded bot-naming pool/picker, a bot thinking-delay picker, feedback-sending primitives, and storage primitives. Ships raw source; consuming apps compile it with their own TypeScript pipelin
