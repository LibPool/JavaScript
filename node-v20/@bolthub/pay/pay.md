# @bolthub/pay

> 标签: ai-agent, bitcoin, l402, lightning, mcp, micropayments, model-context-protocol, payments, paywall

## 简介

The bolthub payments SDK: charge for an MCP tool or HTTP endpoint — and pay for them — in a few lines. Lightning-only (L402) micropayments for AI-agent tool calls
