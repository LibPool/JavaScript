# @catmeow/readme-ai

> 标签: ai, claude, cli, documentation, gemini, grok, ollama, openai, readme, readme-generator

## 简介

One command to generate an accurate, polished README.md from your codebase. Works with Gemini, Claude, OpenAI, Grok or a local Ollama model.
