# @sobree/block-tools

> 标签: block, editor, floating, sobree, toolbar, ui, wysiwyg

## 简介

Floating toolbar + gutter indicator + zone editor for @sobree/core. Mount via the `blockTools()` factory in `createSobree({ plugins: [...] })`.
