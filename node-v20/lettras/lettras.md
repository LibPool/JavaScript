# lettras

> 标签: accents, crossword, crucigrama, fancy-text, font-generator, french, german, i18n, italian, mcp, portuguese, puzzle, spanish, sudoku, text-styles, unicode, unicode-text, wasm, word-search, wordsearch

## 简介

Word-search, crossword (crucigrama) and sudoku generators plus Unicode text styles for 6 languages (es, en, pt, fr, de, it), with native accented letters kept. Runs locally via WebAssembly, no network or API key. Library and CLI.
