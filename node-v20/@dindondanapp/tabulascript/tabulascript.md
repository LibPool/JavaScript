# @dindondanapp/tabulascript

> 标签: church, dindondan, dsl, evaluator, parser, tabulascript, timetable

## 简介

TabulaScript — reference TypeScript implementation of the DSL used by DinDonDan to describe church mass timetables. Pure, isomorphic, zero runtime dependencies.
