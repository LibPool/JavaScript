# @bridge-ds/tokens

> 标签: bridge, css-variables, design-system, design-tokens, dtcg

## 简介

Bridge design tokens in W3C DTCG 2025.10 format (primitives, brands, semantic light/dark, density, component tier), built to CSS variables and TypeScript with Style Dictionary.
