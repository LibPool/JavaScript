# @etoe/sdk-web

> 标签: JavaScript

## 简介

Etoe browser SDK — E2EE client backed by libsignal-protocol compiled to WASM. Surface parity with @etoe/sdk-node; same upstream Rust crate behind both adapters. Cross-platform interop guaranteed by byte-identical libsignal serialisation. Dual-licensed: AG
