# @privata/mcp

> 标签: anthropic, bitcoin, claude, crypto, mcp, model-context-protocol, monero, privacy, privata, swap

## 简介

MCP server for Privata - privacy-first crypto swap aggregator. Exposes quote, createOrder, getOrder, compareProviders, explainStatus, analyzePrivacy as MCP tools.
