# @vue-cmd/vant

> 标签: adapter, async, command, component, dialog, h5, imperative, mobile, popup, promise, van-dialog, van-popup, vant, vue, vue3, 命令式, 对话框, 弹窗, 移动端

## 简介

Vant命令式组件适配器 - 让Vant的Popup、Dialog等组件支持命令式调用，专为移动端优化
