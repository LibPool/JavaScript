> 标签: agent, ai, ai-agent, ai-chat, chat, chat-widget, chatbot, conversational-ai, customer-support, embed, embeddable, framework-agnostic, helpdesk, human-handoff, lead-generation, live-chat, markdown, mazaal, react, server-sent-events, sse, streaming, support-widget, typescript, website-chat, widget, zero-config

## 简介

Drop-in AI chat widget for any website — one script tag connects any Mazaal agent with streaming replies, markdown rendering, visitor identification, and human handoff. Framework-agnostic, zero-config.
