# dsh-session-rail

> 标签: counters, deepseek-harness, dsh, dsh-plugin, session, sidebar, status, workspace

## 简介

Session status at a glance for the DSH Web UI: five-state header counters (running / asking / error / interrupted / unread), a pinned hover panel, per-workspace badges in the left rail, and a Progress tab for long tasks.
