# @triggery/vite

> 标签: auto-discovery, hmr, triggery, virtual-module, vite-plugin

## 简介

Vite plugin for Triggery — auto-imports every *.trigger.ts via a virtual module + HMR. Framework-agnostic (works alongside React, Solid, Vue).
