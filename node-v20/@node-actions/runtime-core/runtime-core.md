# @node-actions/runtime-core

> 标签: execution, frame, handler, node-actions, runtime

## 简介

A porta INTERNA do node-actions: o vocabulário de execução que os back-ends e a portaria falam entre si — o frame, o fluxo de controle, o envelope, o escopo de halt e a assinatura do handler. Sem registry, sem gates, sem eval.
