# @node-actions/analysis

> 标签: acl, actions, analysis, governance, node-actions, policy, static-analysis

## 简介

O eixo de JULGAMENTO sobre o par (AST, FACTS) — a ACL declarativa tag→tag, tier, grants e ciclos. Verificador puro: entra (Program, Facts, política), sai diagnóstico ancorado. Sem fixpoint, sem estado. Folha, opt-in, sem throw — nunca trava o emit.
