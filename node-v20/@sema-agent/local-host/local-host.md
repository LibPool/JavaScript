# @sema-agent/local-host

> 标签: agent, config-home, driver, layout, node

## 简介

Node/OS runtime driver for sema human clients (TUI + desktop): config-home resolution, on-disk layout, cross-process mutex & atomic-write primitives, and the local engine anchor/token/flock protocol. Config SEMANTICS live in @sema-agent/settings-schema; s
