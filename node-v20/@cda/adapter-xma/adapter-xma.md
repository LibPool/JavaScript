# @cda/adapter-xma

> 标签: archimate, cda, enterprise-architecture, typescript, xma

## 简介

XMA output adapter for the Continuous-Driven Architecture (CDA) ecosystem. Serializes the ArchiModel produced by @cda/archi-semantic-core into an XMA document.
