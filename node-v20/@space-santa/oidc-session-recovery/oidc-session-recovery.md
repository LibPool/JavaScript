# @space-santa/oidc-session-recovery

> 标签: cognito, ios, oauth, oidc, oidc-client-ts, react-oidc-context, refresh-token, safari, silent-renew

## 简介

Keeps react-oidc-context sessions alive through mobile tab freezes, discards and dropped requests, redirecting to login only when the refresh token is actually refused.
