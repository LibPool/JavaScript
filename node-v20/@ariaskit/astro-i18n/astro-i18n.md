# @ariaskit/astro-i18n

> 标签: astro, astro-component, astro-integration, hreflang, i18n, internationalization, intl, l10n, localization, pluralization, translation, typescript

## 简介

Type-safe internationalization for Astro: server and client rendering, translated URLs, content-collection blogs, plurals and Intl formatting.
