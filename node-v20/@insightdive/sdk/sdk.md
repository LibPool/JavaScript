# @insightdive/sdk

> 标签: csat, feedback, insightdive, nps, sdk, survey

## 简介

JavaScript/TypeScript SDK for Insightdive in-app surveys. Embeds a survey as a modal bottom sheet or inline widget, streams lifecycle events.
