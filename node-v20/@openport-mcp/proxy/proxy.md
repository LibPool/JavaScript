# @openport-mcp/proxy

> 标签: bridge, gateway, http, mcp, openport, proxy, sse, stdio, stream, websocket

## 简介

OpenPort local proxy: bridge stdio/SSE/streamable-http MCP servers to SSE/WS/StreamableHTTP with process isolation, auto-restart, and health/latency endpoints
