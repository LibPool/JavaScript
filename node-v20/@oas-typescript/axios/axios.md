# @oas-typescript/axios

> 标签: JavaScript

## 简介

oas-typescript-axios is a generator for [OpenAPI Specification 3](https://swagger.io/specification/v3/) to [axios](https://axios-http.com/docs/intro). This tool is powered by [openapi-zod-client](https://github.com/astahmer/openapi-zod-client) for the OAS
