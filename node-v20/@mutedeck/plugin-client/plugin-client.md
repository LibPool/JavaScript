# @mutedeck/plugin-client

> 标签: meeting, mute, mutedeck, plugin, stream-deck, websocket

## 简介

Client for MuteDeck's plugin API: WebSocket protocol v2 with approval-based auth, the HTTP API with optional bearer tokens, and automatic fallback for older MuteDeck versions
