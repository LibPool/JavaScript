# @amends-dev/log

> 标签: append-only, effect, event-sourcing, journal, log, storage

## 简介

Typed append-only logs over host storage: positions, commits that span logs, idempotent appends, paged reads, and live tails, with a memory implementation and the suites every adapter runs.
