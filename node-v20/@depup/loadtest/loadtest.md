# @depup/loadtest

> 标签: black box, depup, http, latest, load test, load testing, loadtest, patched, performance, security, test, testing, updated-dependencies

## 简介

Run load tests for your web application. Mostly ab-compatible interface, with an option to force requests per second. Includes an API for automated load testing. (with updated dependencies)
