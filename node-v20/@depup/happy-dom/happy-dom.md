# @depup/happy-dom

> 标签: browser, components, custom, depup, dom, elements, happy-dom, html, jsdom, latest, patched, security, updated-dependencies, w3c, web, whatwg

## 简介

Happy DOM is a JavaScript implementation of a web browser without its graphical user interface. It includes many web standards from WHATWG DOM and HTML. (with updated dependencies)
