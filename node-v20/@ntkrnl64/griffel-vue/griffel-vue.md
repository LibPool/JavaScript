# @ntkrnl64/griffel-vue

> 标签: atomic-css, css-in-js, fluent-ui, griffel, makeStyles, styling, vue, vue3

## 简介

Vue 3 adapter for @griffel/core CSS-in-JS engine. Provides composables (useStyles, useResetStyles) and a plugin for Vue applications using Griffel's atomic CSS-in-JS.
