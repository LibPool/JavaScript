# @ssroute/data-eurostat

> 标签: eurostat, graph, maritime, routing, searoute

## 简介

Eurostat SeaRoute / MARNET maritime routing graph data (JSON tuples) for JavaScript/TypeScript. Works in browser and Node.js.
