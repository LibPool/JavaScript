# @vibingminers/schema

> 标签: ai-receipts, canonical-json, decision-record, dr-1, ledgerline, rfc-8785, schema, trace.ai

## 简介

DR-1 (Decision Record v1) schema, canonical JSON, and hashing utilities for trace.ai. RFC 8785 canonicalization + SHA-256 / keccak256 helpers.
