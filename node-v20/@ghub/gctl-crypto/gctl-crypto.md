# @ghub/gctl-crypto

> 标签: JavaScript

## 简介

Signing and verification for GControl: JWS EdDSA leases, dual-signature (Ed25519 + RSA-4096) licences and bundles, armoured licence codec, envelope encryption and audit hash chains.
