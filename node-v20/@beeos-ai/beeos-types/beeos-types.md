# @beeos-ai/beeos-types

> 标签: acp, agent-client-protocol, beeos, json-rpc, types, wire-protocol

## 简介

Domain-namespaced TypeScript wire types for BeeOS protocols and shared agent/conversation surfaces. Independent of upstream @agentclientprotocol/sdk.
