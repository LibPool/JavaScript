# @dimple-smile/uni-container

> 标签: uniapp, 固定头部底部, 安全距离, 禁用回弹, 自定义导航栏, 页面容器

## 简介

用于uniapp的页面容器组件，兼容ios默认回弹，头部底部支持动态插槽内容，支持自定义导航栏，自动设置安全距离。
