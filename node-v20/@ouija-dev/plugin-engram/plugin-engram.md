# @ouija-dev/plugin-engram

> 标签: agents, ai, engram, memory, ouija

## 简介

Ouija notification plugin that ingests pipeline events into an Engram memory instance. Gives Ouija-dispatched agents durable cross-run memory via Engram's MCP recall tools.
