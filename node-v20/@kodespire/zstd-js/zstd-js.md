# @kodespire/zstd-js

> 标签: compression, decompression, napi, react-native, stream, wasm, zstandard, zstd

## 简介

Zstandard compression for Node.js, Bun, Deno, browsers, edge runtimes and React Native. Native bindings to the official facebook/zstd library with a WebAssembly fallback.
