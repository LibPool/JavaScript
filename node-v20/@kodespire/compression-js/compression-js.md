# @kodespire/compression-js

> 标签: brotli, compression, decompression, deflate, gzip, lz4, napi, snappy, stream, wasm, zlib, zstd

## 简介

One API for zstd, gzip, zlib, deflate, brotli, LZ4 and snappy on Node.js, Bun, Deno, browsers and edge runtimes, with format detection. Loads only the codecs you use.
