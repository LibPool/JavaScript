# @kodespire/snappy-js

> 标签: compression, decompression, framing, napi, parquet, react-native, snappy, stream, wasm

## 简介

Snappy compression for Node.js, Bun, Deno, browsers, edge runtimes and React Native: raw blocks and the framing format. Native bindings to the official google/snappy library with a WebAssembly fallback.
