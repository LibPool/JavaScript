# @kodespire/lz4-js

> 标签: compression, decompression, lz4, lz4hc, napi, react-native, stream, wasm

## 简介

LZ4 compression for Node.js, Bun, Deno, browsers, edge runtimes and React Native. Native bindings to the official lz4/lz4 library with a WebAssembly fallback. Frame and raw block formats.
