# @emotionalamo/plugin-extratheme

> 标签: appearance, background, customization, glassmorphism, nocobase, nocobase-plugin, theme

## 简介

Global theme-enhancement plugin for NocoBase 2.x: custom background (image/gradient/color + fit modes), transparency, frosted-glass, top/side navigation styling, global font (system/custom/uploaded), and macOS-style scrollbar. Configured globally in one s
