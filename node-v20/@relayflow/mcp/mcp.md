# @relayflow/mcp

> 标签: claude, email, mcp, model-context-protocol, relayflow, transactional-email

## 简介

Model Context Protocol server for RelayFlow: send and inspect email, read the inbound inbox, and manage domains, suppressions and short links from any MCP client.
