# @aparte/secretlint-rule-secrets

> 标签: aparte, api-key, credentials, password, rule, secret-scanning, secretlint, secretlintrule, secrets, security

## 简介

A secretlint rule that finds passwords, API keys and tokens with a 196 KB model, not patterns: what has no fixed format too. No network.
