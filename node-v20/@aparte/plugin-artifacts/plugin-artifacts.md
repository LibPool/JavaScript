# @aparte/plugin-artifacts

> 标签: aparte, artifact, artifacts, plugin, preview, tool, web-components

## 简介

Artifacts for aparté — a create_artifact tool the model calls, a rich Code/Preview card that renders its result, and the <artifact> tag grammar for a model that writes one in its prose.
