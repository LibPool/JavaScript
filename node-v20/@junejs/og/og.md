# @junejs/og

> 标签: cloudflare-workers, image-response, june, og, og-image, open-graph, satori, vercel

## 简介

June — cross-platform OG image generation. Cloudflare Workers, Vercel Edge, and Node.js dev all share one import; the right backend is selected at build time via export conditions.
