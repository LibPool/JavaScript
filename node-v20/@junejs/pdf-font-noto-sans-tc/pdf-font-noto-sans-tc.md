# @junejs/pdf-font-noto-sans-tc

> 标签: font, june, noto, pdf, traditional-chinese, typst

## 简介

June — Noto Sans TC (Traditional Chinese, regular and bold) as an offline font provider for @junejs/pdf-typst-wasm: no network call, on Node, Bun, Deno and Cloudflare Workers.
