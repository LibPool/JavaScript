# @vui-rs/rolldown

> 标签: rolldown, sfc, terminal, tsdown, tui, vue, vui-rs

## 简介

Compile .vue SFCs for the vui-rs custom renderer in rolldown/tsdown builds (unplugin-vue + vui compiler options + style strip).
