# @vui-rs/vue

> 标签: bun, custom-renderer, renderer, terminal, tui, vue, vui-rs

## 简介

Vue 3 custom renderer for vui-rs — build reactive terminal UIs with Vue components, reactivity, and lifecycle over the native cell buffer.
