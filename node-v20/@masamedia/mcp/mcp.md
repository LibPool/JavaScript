# @masamedia/mcp

> 标签: geo, masa-media-digital, mcp, mcp-server, model-context-protocol, seo

## 简介

MCP server for Masa Media Digital, an Israeli SEO and GEO agency. Lets AI assistants search the agency's articles, SEO glossary and Google update log, and read its services, prices and contact details.
