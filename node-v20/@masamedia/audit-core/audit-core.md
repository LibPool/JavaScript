# @masamedia/audit-core

> 标签: ai-visibility, geo, gptbot, hreflang, open-graph, schema, seo, structured-data, web-audit

## 简介

Framework-free web-page audit engine: SEO, GEO / AI visibility, schema, Open Graph, hreflang, headings, images and AI-crawler access. A free tool from Masa Media Digital, an Israeli SEO and GEO agency.
