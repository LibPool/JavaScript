# @insession/extension-whiteboard

> 标签: drawing, realtime, reducer, state-machine, whiteboard

## 简介

A dependency-free, framework-agnostic Whiteboard state machine: shared free-draw strokes/shapes plus an optional "drawing telephone" relay game. The server holds the authoritative state; reduce() is a pure function.
