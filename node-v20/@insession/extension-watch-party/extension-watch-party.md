# @insession/extension-watch-party

> 标签: realtime, reducer, state-machine, sync, video, watch-party

## 简介

A dependency-free, framework-agnostic Watch Party state machine: server-authoritative synchronized video/audio playback with a queue and history. reduce() is a pure function that returns the next state plus effect descriptors for the host to execute.
