# @picoberry/mcp-server

> 标签: 3d, ai, blender, game-assets, image-to-3d, mcp, modelcontextprotocol, picoberry, text-to-3d, unity

## 简介

PicoBerry MCP server — an AI 3D workspace for games, VR, and beyond, from any MCP client. Generate, remesh, texture, and animate 3D assets; several engines behind one API (query list_models for the live set). A thin wrapper over the PicoBerry /v1 API.
