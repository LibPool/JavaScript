# @oceanalt/plugin-elizaos

> 标签: agent-payments, aml, eliza, elizaos, elizaos-plugin, plugin, pre-payment, x402

## 简介

ElizaOS plugin: a CHECK_PAYMENT action and a payment-policy provider that ask OceanAlt about a payee before an agent pays, plus an opt-in guard that holds named payment actions until the payee is allowed. No keys, no custody. Not affiliated with elizaOS.
