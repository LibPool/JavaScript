# @oceanalt/mcp-guard

> 标签: agent-payments, blind-signing, mcp, pre-settlement

## 简介

Payment-runtime guard for MCP clients: wraps callTool so that payment-shaped tool calls (pay / transfer / send / approve / sign) get a pre-settlement decision, a calldata intent check and a secret-exfiltration scan before they run. Everything else passes
