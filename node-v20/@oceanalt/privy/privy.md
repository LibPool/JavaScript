# @oceanalt/privy

> 标签: agent-payments, agent-wallets, aml, eip-3009, pre-signing, privy, server-wallets, x402

## 简介

Guard for Privy server wallets: ask OceanAlt about the real payee (allow / review / decline) before Privy signs a transfer, approval or x402 authorization. Fails closed. No keys, no custody. Not affiliated with Privy.
