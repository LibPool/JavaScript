# @basein/runner

> 标签: agent, claude-code, mcp, observability, proxy, recorder, replay, scenario

## 简介

A recording MCP proxy: sits between any MCP client and its MCP servers, executes each call on the client's behalf, and records the run as a reusable BaseIn scenario.
