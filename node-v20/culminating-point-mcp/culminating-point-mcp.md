> 标签: ai-agent, claude-code, codex, culminating-point, gemini-cli, mcp, mcp-server, wargame

## 简介

Play Culminating Point, a WWII operational wargame, with your own AI agent (Claude Code, Codex, Gemini CLI or any MCP client): the MCP server that links it to the game in your browser.
