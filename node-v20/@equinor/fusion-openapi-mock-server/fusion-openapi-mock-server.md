# @equinor/fusion-openapi-mock-server

> 标签: equinor, fusion, mock, openapi, server, testing, typescript

## 简介

Standalone HTTP server that serves @equinor/fusion-openapi-mock fakes from a directory of OpenAPI specs, addressable directly by tests (e.g. Playwright) as well as local dev
