# security-hub

> 标签: cli, express, nextjs, sast, security, sql-injection, static-analysis, vulnerability-scanner, xss

## 简介

Open-source SAST scanner CLI for Node.js/Express and Next.js apps — catches SQL injection, XSS, command injection, SSRF, CSRF, IDOR and more, built for AI-assisted ("vibe coded") projects.
