# @miiajs/rate-limit

> 标签: guard, http, middleware, miia, miiajs, rate-limit, rate-limiting, throttle

## 简介

Rate limiting for MiiaJS - fixed-window limiter, in-memory store, middleware, guard, decorators, draft-6/legacy headers, optional block duration.
