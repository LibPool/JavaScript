# @miiajs/serve-static

> 标签: etag, http, miia, miiajs, mime, range, spa, static-files

## 简介

Static file serving for MiiaJS - Range, weak ETag, conditional GET, charset negotiation, SPA fallback, dotfile guard, symlink-safe paths.
