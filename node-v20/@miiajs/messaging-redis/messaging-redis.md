# @miiajs/messaging-redis

> 标签: events, messaging, miia, miiajs, pubsub, redis, streams, transport

## 简介

Redis Streams transport for @miiajs/messaging - consumer groups, exponential backoff retry held in the group's PEL, auto-DLQ, idempotency store.
