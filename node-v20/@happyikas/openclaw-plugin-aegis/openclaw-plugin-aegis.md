# @happyikas/openclaw-plugin-aegis

> 标签: aegis, agent, audit, firewall, openclaw, openclaw-plugin, security

## 简介

OpenClaw plugin that runs every tool call through Aegis ATV's 16-step firewall + cryptographic audit chain. Multi-channel + multi-provider attribution; E2E-tested against a real Aegis sidecar.
