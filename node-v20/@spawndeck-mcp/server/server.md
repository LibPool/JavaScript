# @spawndeck-mcp/server

> 标签: gamedev, mcp, model-context-protocol, spawndeck, unreal

## 简介

SpawnDeck Dev-Sync MCP: push aggregate progress stats from your local game project to SpawnDeck. Aggregates only, never file contents or paths.
