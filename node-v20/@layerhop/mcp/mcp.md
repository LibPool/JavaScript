# @layerhop/mcp

> 标签: ai-agents, bridge, claude, cross-chain, cursor, defi, evm, layerhop, llm, mcp, model-context-protocol, solana, swap

## 简介

LayerHop MCP server: let AI agents (Claude, ChatGPT, Cursor, ...) quote and prepare cross-chain swaps. Holds no keys and never signs.
