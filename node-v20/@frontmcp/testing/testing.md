# @frontmcp/testing

> 标签: agentfront, e2e, frontmcp, integration-testing, jest, mcp, mcp-client, model-context-protocol, testing

## 简介

End-to-end testing for FrontMCP servers: Jest fixtures with a connected MCP client, MCP matchers, JWT and OAuth mocks, and HTTP mocking
