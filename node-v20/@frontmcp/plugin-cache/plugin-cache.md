# @frontmcp/plugin-cache

> 标签: agentfront, cache, frontmcp, mcp, model-context-protocol, plugin, redis, vercel-kv

## 简介

Cache plugin for FrontMCP: answers repeated tool calls from memory, Redis or Vercel KV instead of running the tool again

## 官网

- 官网：https://frontmcp.dev/reference/plugins/cache
- 源码仓库：git+https://github.com/agentfront/frontmcp.git
- npm 页面：https://www.npmjs.com/package/@frontmcp/plugin-cache
