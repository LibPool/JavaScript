# @pifu/dsh-pixel-pet

> 标签: 8-bit, desktop-pet, dsh, dsh-plugin, overlay, pet, pixel, sprite

## 简介

DeepSeek Harness Web 的宝可梦风像素桌宠：渲染在现有 Web 界面浮动层内，实时反应对话状态（idle/thinking/tool/waiting/error/success/sleeping），支持导入 sprite sheet 宠物包。
