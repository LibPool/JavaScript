# motion-presets-kit

> 标签: agent-skill, ai, animation, framer-motion, motion, motion-react, presets, react, typescript, variants, zod

## 简介

Set tipado y validado en runtime de helpers y presets para motion/react: fade, slide, scale, clipReveal, parentVariants, más componentes como TextAnimate, Marquee, Draggable y el hook useCounter.
