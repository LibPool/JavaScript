# monorepo-secret-manager

> 标签: aws, azure, cli, configuration, deployment, devops, env-management, environment-variables, gcp, monorepo, nodejs, secret-manager, secrets, ssh, tls, typescript

## 简介

A multi-cloud secret manager for monorepos. Sync env files, SSH keys, TLS bundles, and other secret kinds to GCP, AWS, Azure, or a local encrypted store.
