# minimal-agent

> 标签: agent, ai, cli, deepseek, education, ink, llm, minimax, openai-compatible, tui

## 简介

Bun-first 的本地 Agent 内核，支持工具、插件、工作流、上下文压缩、长期记忆与 OpenAI 兼容接口；Tauri 桌面宿主和 Node.js npm 发布可复用同一内核
