# maven-hackathon-design-tokens

> 标签: JavaScript

## 简介

1. Import tokens in multiple file format into `tokens-studio-tokens` 2. Run `node transformTokensStudio.js` to generate style-dictionary accepted `transformed-tokens` directory files 3. Run `node build.js` to generate files for each platform 4. Increment
