# mymonero-exchange

> 标签: cryptocurrency-conversion, cryptocurrency-exchange, monero-to-bitcoin, monerotobitcoin, mymonero, xmrtobtc

## 简介

This module is used by the desktop and web versions of the MyMonero wallet to facilitate the exchange of XMR into other cryptocurrencies. It can be used to facilitate transactions where a user converts one cryptocurrency into another.
