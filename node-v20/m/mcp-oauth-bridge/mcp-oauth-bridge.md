# mcp-oauth-bridge

> 标签: ai, bridge, claude, mcp, model-context-protocol, oauth, oauth2, pkce, proxy, stdio

## 简介

A stdio MCP server that proxies requests to remote MCP servers with OAuth 2.0 authentication (Authorization Code + PKCE)
