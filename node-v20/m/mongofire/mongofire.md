# mongofire

> 标签: atlas, change-streams, conflict-resolution, local-first, mongodb, mongoose, offline, offline-first, realtime, replication, sync, sync-engine, typescript

## 简介

Offline-first MongoDB sync — Local + Atlas feel like ONE database. Automatic conflict resolution, Mongoose plugin, interactive CLI, zero boilerplate.
