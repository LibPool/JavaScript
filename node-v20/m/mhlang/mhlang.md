# mhlang

> 标签: cli, i18n, internationalization, localization, nextjs, react, typescript

## 简介

Interactive CLI that scaffolds a type-safe i18n system for React and Next.js projects, plus a lightweight runtime (I18nProvider, useTranslation) to power it.
