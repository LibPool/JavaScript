# mcp-tvsubtitles

> 标签: mcp, mcp-server, model-context-protocol, no-api-key, subtitles, tv-series, tvsubtitles

## 简介

MCP server for tvsubtitles.net. Search TV series, read a season's subtitle coverage and one subtitle's record. No API key required.
