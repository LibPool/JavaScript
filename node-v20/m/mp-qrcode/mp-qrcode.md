# mp-qrcode

> 标签: qr, qrcode

## 简介

QR code generator, supports Numeric, Alphanumeric and Binary input mode up to lvl 40.

## 官网

- 官网：https://github.com/zhou-yg/qrcode.js
- 源码仓库：git+https://github.com/zhou-yg/qrcode.js.git
- npm 页面：https://www.npmjs.com/package/mp-qrcode

- npm registry：https://registry.npmjs.org/mp-qrcode
