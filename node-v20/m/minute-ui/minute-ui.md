# minute-ui

> 标签: JavaScript

## 简介

下面内容将介绍如何安装组件库 ###		1、安装代码 ```js npm install minute-ui ``` ###	2、引入组件库 ```js import MinuteUi from 'minute-ui'; import 'minute-ui/dist/minute-ui.css'; Vue.use(MinuteUi); ``
