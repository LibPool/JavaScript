# mcp-google-apps-script

> 标签: apps-script, automation, claude, codex, cursor, google, google-apps-script, mcp, model-context-protocol, scripting

## 简介

MCP server for the Google Apps Script API — create script projects, read and update code files, manage versions and deployments, run functions and inspect executions. For Claude, Cursor, Codex and other AI clients.
