# myapi-asc-mcp

> 标签: JavaScript

## 简介

MyApi MCP server — set MYAPI_TOKEN once, MCP auto-registers its Ed25519 keypair against your account, user approves at /dashboard/devices, then the key is the permanent credential (token can be removed). Requires a paid plan (Pro or Heavy).
