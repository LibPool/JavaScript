# mcp-gemini-server

> 标签: ai, gemini, google-gemini, llm, mcp, model-context-protocol, stdio, typescript

## 简介

A thin, stdio Model Context Protocol (MCP) server exposing the Google Gemini API as composable primitives: chat, web search, role-based agents, multimodal analysis, image generation, code execution, and file management.
