# mnemopay-paperclip-plugin

> 标签: agent-credit-score, ai-agent, audit-trail, behavioral-scoring, memory, mnemopay, paperclip

## 简介

Paperclip adapter that injects MnemoPay Agent Credit Score (300-850, FICO-style behavioral scoring; not affiliated with Fair Isaac Corporation) and persistent behavioral memory into any Paperclip-managed agent
