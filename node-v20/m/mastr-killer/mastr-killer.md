# mastr-killer

> 标签: config, configservice, i18n, magic, magicstrings, nestjs, paths, proxy, string, type-safe, typescript

## 简介

Magic String Killer — turn object property paths into typed, refactor-safe dot-path strings. Kills magic strings for NestJS ConfigService, i18n keys, or any string used to reach an object property.
