# midday

> 标签: am-time, ampm, ante-meridiem, glize, meridiem, meridiem-time, midday, midday-time, military-time, pm-time, post-meridiem, time

## 简介

Converts 24-hour (military) time string to 12-hour (meridiem) time string and vice versa.
