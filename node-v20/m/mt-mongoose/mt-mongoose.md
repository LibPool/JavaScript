# mt-mongoose

> 标签: mongoose

## 简介

This is a library module which adds multi tenancy capability to mongoose. By default mongoose models are attached to a single mongo db, in scenarios where each tenant(customer)  has its own mongo db defined, the logic to switch between mongo dbs gets in
