# modeldispatcher-client

> 标签: backoff, firebase-app-check, gateway, interceptor, llm, react, retry

## 简介

Resilient TypeScript client for the ModelDispatcher AI gateway: interceptor pipeline with request timeouts, exponential backoff on 5xx, and structured 402/429 key-wizard handoff decoding.
