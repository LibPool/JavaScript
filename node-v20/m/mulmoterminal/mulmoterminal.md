# mulmoterminal

> 标签: agentic-coding, ai-agents, claude, claude-code, codex, git-worktree, mulmoterminal, parallel-agents, terminal, tmux, vibe-coding, xterm

## 简介

Run multiple Claude Code and Codex sessions in parallel — a browser terminal grid that shows which agent needs you. Local, tmux-backed.
