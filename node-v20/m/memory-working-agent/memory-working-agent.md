# memory-working-agent

> 标签: agent, agent-working-memory, awm, cognitive-memory, llm, mcp, memory, orchestrator

## 简介

MWA — Memory Working Agent. A turnkey TS agent runtime built on AWM as an always-on cognitive substrate, so a cheap model conducts, resumes, builds on prior reasoning, and runs long without re-onboarding or context rot.
