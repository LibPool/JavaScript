# mobileui

> 标签: Mobile UI, app, framework, mobile, mobileui, prototypes

## 简介

MobileUI is a simple and easy NPM package to install UI Components for web mobile apps using HTML, CSS and JavaScript.

## 官网

- 官网：https://mobileui.github.io
- 源码仓库：git+https://github.com/MobileUI/mobileui.git
- npm 页面：https://www.npmjs.com/package/mobileui
