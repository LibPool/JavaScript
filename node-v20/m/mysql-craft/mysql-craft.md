# mysql-craft

> 标签: database, jwt, mysql, mysql2, security, sql-injection-prevention, transactions, tree-shaking, typescript, wrapper, zero-overhead

## 简介

Modern, lightweight, developer-friendly MySQL wrapper for Node.js & TypeScript with built-in security, transactions, and modern logging.
