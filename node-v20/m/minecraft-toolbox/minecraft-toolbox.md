# minecraft-toolbox

> 标签: bedrock, java, minecraft, ping, query, rcon, server, status, vote, votifier

## 简介

A Node.js library for Minecraft servers that can retrieve status, perform queries, and RCON into servers.

- npm 页面：https://www.npmjs.com/package/minecraft-toolbox

- Node 要求：>=10.0.0
