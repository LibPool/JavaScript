# mongoose-advanced-plugin

> 标签: mern, mongodb, mongoose, pagination, plugin, soft-delete, typescript

## 简介

Mongoose plugin: soft delete, pagination, actor tracking, embedded audit trail (auditLog), optimistic versioning + history snapshots.
