# mcp-sitter

> 标签: ai, claude, claude-code, dev-tool, hot-reload, mcp, mcp-server, model-context-protocol, proxy

## 简介

Hot-reload bridge for stdio MCP servers. Rebuild your MCP server without restarting the MCP client. Injects restart notices and tools-list diffs into tool/call responses so the AI self-corrects after schema changes.
