# mermaid-workbench

> 标签: architecture, bmad, diagrams, flowchart, mermaid, preact, viewer, vite

## 简介

BMAD module + live viewer for multi-layer Mermaid diagrams. Generate, organize, and navigate diagrams with drill-down support.
