# manimgx

> 标签: animation, manim, manimgx, math, player, pyodide, python, video, webgpu

## 简介

The animation engine for agents, in the browser: blazingly fast math and 3D videos with Manim's Python API, run by Pyodide in a Web Worker, on a Rust GPU core with WebGPU.
