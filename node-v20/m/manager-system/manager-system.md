## 简介

- 1.修改package.json当中的version值，建议：如果是Bug修复，增加最后的版本号，如果是新增功能，增加中间的版本号 - 2.在项目根目录下使用命令行执行如下命令:`npm publish` - 3.在引用到当前组件的项目当中修改版本号，并执行`npm install --registry http://npm.xiqiao.io`获取到最新的版本
