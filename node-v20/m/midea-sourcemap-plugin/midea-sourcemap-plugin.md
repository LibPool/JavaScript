# midea-sourcemap-plugin

> 标签: JavaScript

## 简介

抽离source-map文件到一个单独文件夹,保护source-map文件不会被混淆到插件包中

## 官网

- npm 页面：https://www.npmjs.com/package/midea-sourcemap-plugin
