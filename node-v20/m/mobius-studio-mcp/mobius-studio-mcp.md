# mobius-studio-mcp

> 标签: ai, elementor, flatmobile, mcp, site-builder, sweipe, wordpress

## 简介

Mobius Studio MCP server for Sweipe and FlatMobile WordPress sites: import demos, plan and build a site from a brief, rewrite copy, review the result.
