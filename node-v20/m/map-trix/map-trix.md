# map-trix

> 标签: clustering, directions, google, interface, leaflet, loader, map, mapbox, maplibre, maps, marker, store-locator, typescript

## 简介

One easy-to-use interface to load and use any map client (Google Maps, Leaflet, MapLibre, Mapbox): markers, popups, store locator, routing and clustering.
