# markdown-check

> 标签: HTTP, markdown, md, node, verify

## 简介

Lib criada para automatizar o processo de verificação de links dentro de arquivos Markdown para poder analisar arquivos que estão fora do AR e seu status code trazendo otimização na verificação de grandes blogs. Foi implementado verificação por Diretorios
