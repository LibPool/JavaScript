# mcp-signal

> 标签: analytics, apps-sdk, chatgpt-apps, claude, event-tracking, iframe, instrumentation, mcp, mcp-apps, mcp-ui, model-context-protocol, observability, openai, openai-apps, posthog, product-analytics, sandbox, telemetry, typescript, webhook, widget

## 简介

Tiny, zero-dependency, pluggable telemetry SDK for MCP widgets (Claude MCP Apps, ChatGPT Apps SDK, mcp-ui). Capture lifecycle, custom, and error events and forward them to any analytics destination.
