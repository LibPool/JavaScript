# mobile-base-layout

> 标签: JavaScript

## 简介

### 描述 一种简单的移动端可伸缩布局，主要包括头部、内容区域、底部，其中内容区域为可伸缩部分，即当头部或者底部不存在时，内容区域会自动扩展将其覆盖
