# mmtabler

> 标签: angular, custom, javascript, misha mashina, mm-tabler, mmtabler, table, tabler, typescript

## 简介

MMTabler is a ready-made Angular component for displaying and handling the tabular display of one-dimensional json data. With various options to configure, MMTabler also features options for editing, deleting and adding new entries.
