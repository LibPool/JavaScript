# multi-agents-workflow

> 标签: agent-workflow, cc-switch, claude-code, codex, cost-control, graph-workflow, loop-engineering, multi-agent, orchestration, subagents

## 简介

A portable, dynamic multi-agents workflow system for complex codebases. Reads cc-switch config, selects the right agent architecture (loop / orchestrator-workers / multi-agent / graph / dynamic / ultracode), generates per-agent configs, enforces cost-rate
