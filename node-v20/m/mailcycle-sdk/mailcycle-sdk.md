# mailcycle-sdk

> 标签: api-client, e2ee, email, email-alias, email-api, email-client, encrypted-email, end-to-end-encryption, inbox, mailbox, mailcycle, privacy, receive-email, send-email, typescript

## 简介

TypeScript client for the Mailcycle API. Create addresses that receive mail, read and decrypt it on your machine, send, and listen for events.
