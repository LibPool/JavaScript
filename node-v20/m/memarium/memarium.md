# memarium

> 标签: ai, claude, codex, copilot, digest, memarium, memory, sessions, vibe-coding

## 简介

Cross-device sync + resume for AI coding sessions (Claude Code, Copilot Chat, and Codex). Companion to the memarium Claude Code plugin which provides digest + recall.
