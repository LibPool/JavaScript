# mapv-cloudrenderengine

> 标签: cloud render, unreal

## 简介

CloudRenderEngine 是百度地图开放平台推出的 UE5 像素流三维数字孪生前端 SDK。   它通过 WebRTC 将 Unreal Engine 5 场景实时推流到浏览器，并提供统一 JavaScript API 完成场景渲染、交互控制、对象管理和行业可视化能力接入。
