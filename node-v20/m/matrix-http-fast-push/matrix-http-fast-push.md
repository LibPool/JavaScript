# matrix-http-fast-push

> 标签: JavaScript

## 简介

FIS 默认插件 fis3-deploy-http-push 由于对任意一次的编译产出都采取单个文件逐个上传的策略，在项目文件数量较多的时候，速度会变得非常慢且容易在中途崩溃。
