# mcp-context-card

> 标签: agent-identity, agent-memory, agents-md, ai-catalog, mcp, model-context-protocol, project-context, server-card

## 简介

The essential MCP components for a project's context (AGENTS.md), cross-session memory, and identity — a base MCP on its own, or a drop-in extension for any existing MCP server. Discoverable through the Server Card _meta block and ai-catalog.json sibling
