# mrcipher-cli

> 标签: aes-256-gcm, cli, encryption, encryption-as-a-service, mrcipher

## 简介

Official command-line client for MRcipher — encrypt, decrypt, and manage your API keys from the terminal, fully in sync with the MRcipher website in real time.
