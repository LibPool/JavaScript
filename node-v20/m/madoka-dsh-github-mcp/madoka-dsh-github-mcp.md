# madoka-dsh-github-mcp

> 标签: deepseek-harness, dsh, dsh-plugin, github, mcp

## 简介

DSH 插件 — GitHub 官方远端 MCP 开箱即用：安装即连 api.githubcopilot.com，PAT 走环境变量。Out-of-the-box hosted GitHub MCP for DSH: connects to api.githubcopilot.com on install, PAT via environment variable.
