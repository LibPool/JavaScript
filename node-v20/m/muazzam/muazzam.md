# muazzam

> 标签: JavaScript

## 简介

**Muazzam** is a fun, flashy, and useful Node.js package that lets you monitor your system in style!   It provides **colorful terminal logs**, **CPU/RAM/OS info**, **battery stats**, and more — all with **bold headers, emojis, and colors**.
