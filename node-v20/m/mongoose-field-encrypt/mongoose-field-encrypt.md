# mongoose-field-encrypt

> 标签: cqrs, encrypt, encryption, field, mongo, mongoose, search, searchable, security, string

## 简介

A simple symmetric encryption plugin(modified varsion of mongoose-field-encryption) for individual fields with the dynamic secret keys in the query options
