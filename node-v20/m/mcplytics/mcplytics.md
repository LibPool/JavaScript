# mcplytics

> 标签: ai-agents, analytics, cloudflare-workers, mcp, mcp-security, model-context-protocol, oauth, observability, security, telemetry

## 简介

Usage, health and security for a remote MCP server: which tools, which apps, how calls ended, how long they took, and the signs of an attack. One wrapper, no SDK, no backend, never stores arguments or error text. Plus a check that says what to fix.
