# mxframework

> 标签: framework, light-weight, mxframework, node.js, object oriented, object-oriented, oo

## 简介

MXFramework is a light-weight Object Oriented JavaScript framework. mxframework-node is the specified version for Node.

## 官网

- 官网：https://github.com/MagicCube/mxframework-node
- 源码仓库：git://github.com/MagicCube/mxframework-node.git
