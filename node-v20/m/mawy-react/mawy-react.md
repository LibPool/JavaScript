# mawy-react

> 标签: a11y, accessibility, accessible, dark-mode, editor, esm, markdown, markdown-editor, markdown-parser, markdown-viewer, mawy, mawy-react, preview, react, react-component, react-markdown, reactjs, rich-text, rich-text-editor, text-editor, tsx, typescript, viewer, wysiwyg, wysiwyg-editor

## 简介

A Markdown editor that also does the reading — write in WYSIWYG or in the source, switch freely, and show the finished document through a read-only viewer.
