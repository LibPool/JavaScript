# mitsumori-vue

> 标签: mitsumori-vue, vue

## 简介

さまざまな見積もりを算出するためのインターフェースコンポーネントです。 mitsumori-vueコンポーネントは、propsのurlで設定したパスからjson形式のデータを読み込み、画面を構成しています。 propsの設定値については[こちら](#props)を参照してください。
