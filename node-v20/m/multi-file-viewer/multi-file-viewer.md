# multi-file-viewer

> 标签: document-viewer, excel, file-viewer, markdown, pdf, preview, react, vue, word

## 简介

A clean, extensible multi-format file preview library for React and Vue with native PDF, Excel, Word, Markdown, code, media, and text renderers.
