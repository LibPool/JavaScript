# mcp-server-kingbasees

> 标签: claude, database, kingbasees, mcp, model-context-protocol, postgis, spatial, sql-server-compatible, 人大金仓

## 简介

MCP server for KingbaseES (人大金仓) - SQL Server compatible mode with PostGIS spatial query support. Connect, query, and manage KingbaseES databases with spatial extensions through the Model Context Protocol.
