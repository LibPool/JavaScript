# miaoda-game-rpg-battle-core

> 标签: battle, combat, game, jrpg, rpg, turn-based

## 简介

Engine-neutral command-planning and action-resolution kernel for classic party RPG battles, with deterministic priority/speed queues, execution-time revalidation, follow-up actions, structured events, and host-owned state.
