# mcp-rncp

> 标签: certification, cpf, edof, formation, france-competences, mcp, mcp-server, model-context-protocol, qualiopi, rncp, rs

## 简介

MCP server for the French RNCP / RS registers of professional certifications (France compétences open data). Local stdio server with embedded SQLite, no API key.
