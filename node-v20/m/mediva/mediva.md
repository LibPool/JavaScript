# mediva

> 标签: checker, github, issue-template, markdown, mdv, mediva, pull-request, standard, validation, validator

## 简介

The Markdown validator for the agentic era — check that filled-in templates and agent-generated Markdown kept their contract. Zero-dependency CLI, GitHub Action, and library.
