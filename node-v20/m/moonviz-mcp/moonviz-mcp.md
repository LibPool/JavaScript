# moonviz-mcp

> 标签: ai-agent, design, mcp, model-context-protocol, moonbit, moonviz, prototype

## 简介

MCP server launcher for the MoonViz prototype design engine. Ships a prebuilt native binary per platform (zero compile, instant start); falls back to `moon run` when no binary matches.
