# mandate-verify

> 标签: agents, attestation, bnb, bnb-chain, bsc, erc-8004, verification

## 简介

Re-derive and check a MANDATE settlement on BNB Smart Chain from public chain state alone. Reads no database, no API and no file the operator controls.
