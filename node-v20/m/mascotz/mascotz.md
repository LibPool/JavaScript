# mascotz

> 标签: animation, avatar, cursor, custom-element, eyes, html, interactive, login, mascot, react, svelte, svg, vue, web-component

## 简介

Interactive mascots for any website: eyes that follow the cursor, blink and react. Works with React, plain JavaScript, HTML (<mascot-z>), Vue, Svelte and any framework. Zero dependencies.
