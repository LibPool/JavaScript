# mcp-vue

> 标签: ai, mcp, modelcontextprotocol, ts, vue

## 简介

A Local MCP server for finding vue code references using Tree-sitter. Usage: npx mcp-vue [--cwd=<path>] [--level=<DEBUG|INFO|WARN|ERROR>] [--log-file=<path>] [--no-console] [--no-file]
