# modelgate-mcp

> 标签: anthropic, claude, cursor, gemini, llm, llm-gateway, mcp, mcp-server, model-context-protocol, modelgate, observability, openai

## 简介

Official Model Context Protocol (MCP) server for ModelGate: run LLM inference through the ModelGate gateway and inspect models, usage, cost and request traces from Claude, Cursor, VS Code and any MCP client.
