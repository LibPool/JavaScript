# mindforge-mcp-server

> 标签: agentic, anthropic, audit, claude, claude-code, knowledge-graph, mcp, memory, mindforge, model-context-protocol

## 简介

MindForge MCP server — exposes the MindForge engine (knowledge graph, project health, audit log) and the MindForge browser daemon to Claude Code and any MCP host as 8 stdio tools. Self-contained, zero runtime dependencies.
