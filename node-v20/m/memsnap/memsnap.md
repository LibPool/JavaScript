# memsnap

> 标签: analytics, browser, coffeescript, framework, javascript, library, log, memory, micro, snapshot, statistic, track

## 简介

MemSnap is a 0.2KB analytics micro-library written in both CoffeeScript and JavaScript that logs browser memory statistic snapshots over time.
