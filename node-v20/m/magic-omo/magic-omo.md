# magic-omo

> 标签: cli, coding-agent, context-management, cortexkit, llm, magic-context, memory, oh-my-openagent, omo, pi, senpi

## 简介

Unofficial community bridge: run Magic Context (cortexkit) inside OMO Native (oh-my-openagent's Senpi-based omo CLI), sharing one context.db with OpenCode and Hermes.
