# mcp-yt-local-audio-play

> 标签: JavaScript

## 简介

MCP server to play YouTube audio locally via yt-dlp + mpv (child_process). No remote sink, no search, just play/stop by URL.

## 官网

- npm 页面：https://www.npmjs.com/package/mcp-yt-local-audio-play

- 0.1.0

- npm registry：https://registry.npmjs.org/mcp-yt-local-audio-play
- Node 要求：>=18.0.0
