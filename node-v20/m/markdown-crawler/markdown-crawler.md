# markdown-crawler

> 标签: ai, ai-content, ai-processing, clean-text, cli-tool, content-extraction, gfm, html-to-markdown, llm, machine-learning, markdown, nlp, playwright, readability, semantic-content, structured-data, text-extraction, turndown, web-crawler, web-scraping

## 简介

A powerful web crawler that extracts content from web pages and converts them to clean Markdown format, with support for code blocks and GitHub Flavored Markdown
