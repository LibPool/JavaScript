# multiple-slider

> 标签: carousel, frontend, image-slider, multi-slider, react, react-component, react-slider, swiper, ui-component

## 简介

A lightweight, fully customizable React multi-slider / carousel component with touch support, infinite looping, keyboard navigation, and flexible arrow customization.
