# mcp-agent-bridge

> 标签: agent, bridge, channels, claude, claude-code, collaboration, cross-machine, distributed, mcp, model-context-protocol, multi-agent, pub-sub, real-time, redis, workspace

## 简介

Real-time communication between Claude Code instances across machines and workspaces. Redis-backed channels with background task notifications for true push in VS Code.
