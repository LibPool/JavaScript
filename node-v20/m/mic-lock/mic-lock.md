# mic-lock

> 标签: adb, agents, bakery-algorithm, cli, device, emulator, fencing-token, lock, mutex, simulator, worktree

## 简介

Local, serverless CLI that locks shared test devices (Android emulators, iOS simulators, physical devices) across concurrent AI coding agents — fair FIFO queue, notify-on-free, and hold-until-human-approves.
