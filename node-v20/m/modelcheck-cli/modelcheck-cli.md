# modelcheck-cli

> 标签: anthropic, benchmark, cli, evals, evaluation, llm, model, openai, openrouter, structured-output, tool-calling

## 简介

Measure what a model change does to the capability you ship. Runs a versioned suite against any model with your own API key and writes a report where every number carries its evidence.
