# mainam-react-native-date-picker

> 标签: JavaScript

## 简介

Thư viện chọn ngày/giờ dạng modal cho React Native, có giao diện riêng cho iOS và Android. Phiên bản hiện tại hướng tới React Native `0.80.3`, React `19.1.0`.
