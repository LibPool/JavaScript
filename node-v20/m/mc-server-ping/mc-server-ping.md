# mc-server-ping

> 标签: bedrock, java-edition, minecraft, minecraft-server, motd, raknet, server-ping, server-status, slp, varint

## 简介

Zero-dependency Minecraft server status checker for Node.js. Supports Java Edition (TCP/SLP) and Bedrock Edition (UDP/RakNet).

- 官网：https://minecraft-serverhub.com/tools/server-status-checker
- 源码仓库：git+https://github.com/DRAGINOXd/mc-server-ping.git
