# mermaid-ascii

> 标签: ascii, ascii-art, cli, diagram, flowchart, library, mermaid, text-diagram, typescript

## 简介

Convert Mermaid diagrams to ASCII art. A TypeScript library and CLI tool for rendering beautiful text-based diagrams.
