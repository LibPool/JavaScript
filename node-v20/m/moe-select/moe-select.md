# moe-select

> 标签: autocomplete, dropdown, multiselect, select, tag, tagging, typeahead

## 简介

Select2 is a jQuery based replacement for select boxes. It supports searching, remote data sets, and infinite scrolling of results.

## 官网

- 官网：https://select2.github.io
- 源码仓库：git://github.com/select2/select2.git
- npm 页面：https://www.npmjs.com/package/moe-select
