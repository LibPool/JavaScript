# mongoose-performance-cache

> 标签: aggregation, bun, cache, lru, mongodb, mongoose, nodejs, performance, query-caching, redis, smart-invalidation

## 简介

Automatic MongoDB query caching for Node.js and Bun that wraps your Mongoose schemas to handle cache storage, live updates, and smart invalidation seamlessly.
