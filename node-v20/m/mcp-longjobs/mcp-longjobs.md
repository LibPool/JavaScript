# mcp-longjobs

> 标签: agent, chunked-transfer, durable-execution, long-running, mcp, model-context-protocol, resumable, tasks

## 简介

Durable, resumable operations for MCP servers: long-running tasks and chunked file transfers that survive timeouts, disconnects, and client restarts — on every client, no Tasks-extension support required.
