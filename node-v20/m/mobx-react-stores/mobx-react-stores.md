# mobx-react-stores

> 标签: mobx, react, stores

## 简介

mobx-react-stores 是为了方便将 antd pro 改为使用 mobx 而开发的，里面的思路和代码大量的参考了 dva 和 umi 的实现，mobx 版的 antd pro 并且全功能版的将于不久开源，即基于此库
