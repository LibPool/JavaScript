# mtl-framework

> 标签: JavaScript

## 简介

mtl-framework 定位于基于 React Native 某个版本 Fork 出来进行裁剪和升级的底层框架，用于解决在生产环境时遇到的一些问题（部分问题等待官方修复较多，或是社区方案不统一）。
