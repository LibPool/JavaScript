# mcp-libraryofcongress

> 标签: archives, chronicling-america, full-text-search, library-of-congress, loc, mcp, model-context-protocol, newspapers

## 简介

MCP server for the Library of Congress. Search inside digitised newspaper pages, browse the catalogue by format, and read records and collections. No API key required.
