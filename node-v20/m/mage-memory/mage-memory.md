# mage-memory

> 标签: agents, ai-agents, claude-code, documentation, knowledge-base, memory, notes, obsidian

## 简介

mage — a portable, self-maintaining knowledge base for software systems: durable git-backed notes navigable as an Obsidian graph, usable by any AI coding agent.
