# mana-engine

> 标签: 3d, engine, gltf, react, renderer, scene-graph, shaders, webgl2, webgpu

## 简介

A small, fast 3D engine for the web: one scene graph, two backends (WebGPU + WebGL2), Z-up, shader hooks, and an optional React renderer.
