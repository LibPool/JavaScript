# motiland-mcp

> 标签: 3d-printing, 3mf, maps, mcp, modelcontextprotocol, motiland, terrain

## 简介

MCP server for Motiland Studio Pro -- generate print-ready 3D city/terrain models from Claude Desktop, Cursor, or any MCP client, backed by the Studio REST API (/api/v1).
