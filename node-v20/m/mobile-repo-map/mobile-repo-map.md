# mobile-repo-map

> 标签: architecture, cli, codebase-visualization, dart, dependency-graph, flutter, ios, navigation, static-analysis, swift, swiftui, uikit

## 简介

Point it at any Flutter or iOS repo and get an interactive map of how the app works: screens, navigation, API calls, architecture and risks.
