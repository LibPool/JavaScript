# mf-add-to-shell

> 标签: cli, codegen, micro-frontend, microfrontend, module-federation, react, rspack, scaffold, shell, webpack

## 简介

Interactive CLI that registers a new Module Federation microfrontend in a host shell app — routes, i18n, permissions, proxy and remotes in one command.
