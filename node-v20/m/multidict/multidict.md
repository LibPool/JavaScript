# multidict

> 标签: array map, bidirectional mapping, dictionary, graph, many to many relationship, map, multiple keys, multiple values, object map, two-way association

## 简介

MultiDict is an extension of Map that supports bidirectioal, many to many relations among multiple keys and values.
