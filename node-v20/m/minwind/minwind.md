# minwind

> 标签: classname, classnames, compression, css, css-modules, minify, tailwind, tailwindcss, vite, vite-plugin

## 简介

Build-time CSS name compression for Tailwind and CSS Modules: renames and consolidates classes across JS/TS, SFC, HTML, and CSS, with optional custom-property aliases. Vite and webpack/rspack plugins plus a post-build CLI.
