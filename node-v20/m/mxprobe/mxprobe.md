# mxprobe

> 标签: ai-agent, bounce, email, email-verifier, mcp, mcp-server, mx, outreach, smtp, verification

## 简介

Email verification for AI agents. One call returns send, hold or kill with the reason. Free DNS tier runs locally; the hosted SMTP probe is 9 USD per 10,000 checks. CLI + MCP server.
