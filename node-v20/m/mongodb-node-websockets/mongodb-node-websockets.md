# mongodb-node-websockets

> 标签: driver, mongodb

## 简介

A fork of the official MongoDB driver for Node.js that uses WebSockets but for running in a Node based env

## 官网

- 官网：https://github.com/mongodb/node-mongodb-native
- 源码仓库：git+ssh://git@github.com/pffigueiredo/node-env-mongodb-websockets.git
- npm 页面：https://www.npmjs.com/package/mongodb-node-websockets
