# myfacebook-login-btn

> 标签: capacitor, native, plugin

## 简介

Plugin para hacer login y logout en Facebook, además de obtener algunos datos del usuario, para obtener mas datos se deben realizar modificaciones. PDT: Este plugin está basado en el plugin capacitor-facebook-login de oxylian
