# mock2file

> 标签: create-excel, create-json, create-xlsx, excel, json, json-to-excel, microsoft-xlsx, mock, xlsx, xlsx-from-json

## 简介

mock2file is a command line tool that parses the mock syntax in JSON files and exports the parsed mock data to a new file
