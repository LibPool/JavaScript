# memee

> 标签: cache, debounce, functions, javascript, javascript-cache-function, javascript-debounce-function, javascript-functions, javascript-memoize-function, javascript-optimize-function, javascript-performance-function, memee, memoizing, memorize-javascript-function, optimize

## 简介

Javascript package for memoizing functions. Returning directly the result of function if it was called with the same arguments avoiding it's redundant work.
