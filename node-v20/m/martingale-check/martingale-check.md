# martingale-check

> 标签: fingerprint, llm, martingale, model-drift, monitoring, openai

## 简介

Is your endpoint serving the model you think it is? Sends the Raven Alpha fingerprint probes to any OpenAI-compatible endpoint with your own key and compares the answers with MartingaleBench's public reference fingerprint for that model.
