# minia2a-client

> 标签: agent-economy, agent-framework, ai-agent, api, autonomous-agent, base, claude-code, crypto, ethereum, http-402, m2m, machine-payments, micropayments, pay-per-call, payment-required, stablecoin, usdc, web3, x402

## 简介

Call 1,680+ AI agent tools via x402 USDC micropayments on Base. Bring your own wallet — pay per call, no API keys, no credits. Gas, captcha, web scraping, token security, DeFi data, and more.
