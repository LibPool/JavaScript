# mojaq-openai

> 标签: ai-gateway, eu, gdpr, llm, llmops, mojaq, observability, openai

## 简介

Drop-in OpenAI SDK wrapper that routes calls through the MOJAQ AI gateway — EU-hosted observability, cost logging, budget caps, kill-switch and model fallback with one import.
