# modularisan

> 标签: angular, architecture, cli, ddd, feature-driven, generator, laravel-modules, microservices, modular, monorepo, nest.js, next.js, nuxt.js, react, scaffold, svelte, vue

## 简介

A framework-agnostic CLI tool for generating modular, scalable code structures inspired by Laravel modules. Supports Next.js, Nuxt.js, Nest.js, and more.
