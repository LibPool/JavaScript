# macos-pdf-ocr

> 标签: apple-vision, macos, ocr, offline-ocr, pdf-ocr, vietnamese-ocr

## 简介

Ultra-fast, offline, and free PDF OCR using native macOS Vision Framework and PDFKit. Supports Vietnamese & English.
