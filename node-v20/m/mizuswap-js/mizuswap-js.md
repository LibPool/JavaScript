# mizuswap-js

> 标签: crypto, embeddable, exchange, mizuswap, preact, swap, web-component, widget

## 简介

Framework-agnostic, fully-themeable, embeddable crypto-swap widget. Drops onto any site via a <script> tag or <mizu-swap> custom element.
