# merrykat

> 标签: JavaScript

## 简介

The uploader for [Merrykat](https://github.com/happo/merrykat), visual regression testing for Storybook as a GitHub App. It packs a static Storybook build in CI and uploads it; the server does the rendering, diffing and reporting.
