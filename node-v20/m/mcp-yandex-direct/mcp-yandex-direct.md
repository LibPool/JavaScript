# mcp-yandex-direct

> 标签: advertising, mcp, model-context-protocol, ppc, yandex, yandex-direct

## 简介

MCP server for the Yandex Direct API v5 — manage PPC campaigns, ad groups, ads, keywords and pull statistics from AI agents.
