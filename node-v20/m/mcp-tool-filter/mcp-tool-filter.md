> 标签: ai, claude, claude-code, context-window, cursor, filter, llm, mcp, model-context-protocol, proxy, token-optimization, tools, windsurf

## 简介

A generic MCP proxy that filters which tools are exposed from a remote MCP server. Reduces context window token usage.
