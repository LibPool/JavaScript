# mesh-neo

> 标签: cdc, database, embedded, jsql, mesh, plugin, replication, sql, sync, wal

## 简介

基于 jsql-neo 的网格化数据框架：嵌入引擎 + 插件体系，内置数据同步（CDC 表镜像 / 全量快照+增量 / 多节点副本 / WAL 刷盘）
