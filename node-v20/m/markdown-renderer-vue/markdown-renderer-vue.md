# markdown-renderer-vue

> 标签: markdown, markdown-renderer-vue, md, renderer, streaming, typewriter, vue, vue3

## 简介

A Vue 3 Markdown renderer component with streaming and non-streaming modes, featuring typewriter animation, syntax highlighting, and table support.
