# mediable

> 标签: attachments, bullmq, conversions, express, fastify, file-uploads, hono, image-processing, media, media-library, mongodb, mysql, nestjs, nextjs, nodejs, postgres, s3, sharp, signed-urls, sqlite, storage, thumbnails, typescript, uploads

## 简介

Headless, framework-agnostic media library for Node.js. Attach files to any model with named collections, image conversions, pluggable storage (local FS, S3) and databases (SQLite, Postgres, MySQL, MongoDB).
