# mcp-for-memos

> 标签: http, mcp, memos, model-context-protocol, multi-tenant, note-taking, sse

## 简介

MCP server that turns Memos into a multi-purpose database for AI — notes, projects, tasks, agendas, knowledge base. Supports HTTP/SSE multi-tenant access.
