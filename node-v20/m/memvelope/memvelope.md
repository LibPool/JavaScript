# memvelope

> 标签: ai, chatgpt, claude, converter, envelope, export, memvelope, portable-memory

## 简介

Convert any AI chat export (ChatGPT, Claude) into an envelope-v0 file — the open, MIT-licensed portable memory format. Streams large exports the browser can't.
