# matterbridge-mqtt-gateway

> 标签: gateway, iot, matter, matterbridge, matterbridge-plugin, mqtt, smarthome

## 简介

Matterbridge dynamic platform plugin — expose MQTT topics as Matter devices (outlet, switch, light, sensors, cover, stove,thermostat)
