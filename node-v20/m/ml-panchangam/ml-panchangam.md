# ml-panchangam

> 标签: astronomy, ayanamsa, ephemeris, hindu-calendar, jyotish, karana, kerala, kollavarsham, malayalam, nakshathram, nakshatra, onam, panchang, panchangam, rashi, sunrise, sunset, tithi, vishu, yoga

## 简介

Malayalam Panchangam - Accurate Hindu calendar with nakshathram, tithi, kollavarsham, sunrise/sunset, festivals & more. Pure JavaScript astronomical engine based on NASA/Moshier ephemeris.
