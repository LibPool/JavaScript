# mee-tool

> 标签: JavaScript

## 简介

`--build-path`: `build`目录，默认`build` `--remote`: 远程分支名称，默认`dist-dev` `--build-cmd`: 打包命令，默认`build` `--host`: 服务器主机地址 `--username`: 用户名，默认`root` `--password`: 密码 `--remote-cwd`: 服务器目录，默认`/`
