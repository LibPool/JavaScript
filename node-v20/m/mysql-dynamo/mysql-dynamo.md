# mysql-dynamo

> 标签: abstraction, amazon, aws, db, dynamo, local, model, mysql, offline, simple

## 简介

A solution to use the `simple-dynamo` interface with a MySQL database. So you can create a offline version of a AWS-DynamoDB project.
