# multi-content-proxy

> 标签: audio, dots.ai, multimodal, pi, pi-agent, pi-extension, pi-package, video, vision

## 简介

Pi agent extension that parses image/audio/video inputs and forwards them to an OpenAI-compatible multimodal proxy (e.g. dots.ai).
