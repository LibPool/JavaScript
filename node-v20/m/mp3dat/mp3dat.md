# mp3dat

> 标签: JavaScript

## 简介

A simple MP3 parser that returns stat infos in a similar style to fs.stat for MP3 files or streams. (MPEG-1 compatible only)

## 官网

- 官网：http://nodecookbook.com/mp3dat
- 源码仓库：git://github.com/davidmarkclements/mp3dat.git
- npm 页面：https://www.npmjs.com/package/mp3dat
