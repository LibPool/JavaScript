# mailcheck-dev

> 标签: api, bulk-verify, disposable, dkim, dmarc, dns, email, email-validation, email-verification, mailcheck, mx, sdk, spf, validate, verification

## 简介

Official Node.js/TypeScript SDK for the MailCheck.dev email verification API. Verify emails, detect disposable addresses, check DNS/SPF/DKIM/DMARC, and bulk verify lists.
