# mercury-tech-cli

> 标签: agents, ai, anthropic, cli, coding-agent, deepseek, gemini, llm, mcp, openai, terminal

## 简介

Run multiple AI coding sessions in one terminal. Mix and match model providers, spawn cross-company agents, and use built-in debugging, screen control, and voice dictation.
