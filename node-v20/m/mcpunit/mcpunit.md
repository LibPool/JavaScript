# mcpunit

> 标签: agents, ai, automation, ci, cli, developer-tools, mcp, model-context-protocol, test-runner, testing

## 简介

A declarative, CI-first testing framework for Model Context Protocol (MCP) servers. Like pytest/vitest, but for MCP.
