# mermaid-png-mcp

> 标签: diagram, mcp, mcp-server, mermaid, modelcontextprotocol, png

## 简介

Mermaid → PNG MCP server. Two renderers: beautiful-mermaid (fast, no DOM needed for SVG) and CDN mermaid (full features, subgraphs). Both use Chromium for final PNG output.
