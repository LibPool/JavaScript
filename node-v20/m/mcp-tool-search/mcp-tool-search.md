# mcp-tool-search

> 标签: ai, claude, claude-code, claude-desktop, context-optimization, cursor, fuzzy-search, lazy-loading, llm, mcp, model-context-protocol, proxy, token-optimization, token-reduction, tool-management, tool-search, windsurf

## 简介

MCP proxy that reduces Claude context token usage by ~85-96% via lazy tool loading. Works with Claude Code, Claude Desktop, and any MCP client.
