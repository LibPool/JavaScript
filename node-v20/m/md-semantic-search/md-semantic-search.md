# md-semantic-search

> 标签: cli, e5, embeddings, local, markdown, offline, rag, semantic-search, transformers, vector-search

## 简介

Local, private semantic (vector) search over any folder of Markdown files. Finds passages by meaning — cross-lingual — using transformers.js. No API keys, no cloud, no vector database.
