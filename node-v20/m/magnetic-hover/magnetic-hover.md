# magnetic-hover

> 标签: hover, hover near the element, hover next to the element, trigger mouseover, trigger mouseover near the element, trigger mouseover next to the element

## 简介

magneticHover lets you trigger hover effect on the element when the cursor is near it, but not over it yet.
