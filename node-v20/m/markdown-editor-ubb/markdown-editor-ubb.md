# markdown-editor-ubb

> 标签: JavaScript

## 简介

A **lightweight, split‑pane Markdown IDE** with live preview, rich toolbar, dark/light themes, resizable panes, full‑screen, undo/redo history, HTML & PDF export, and first‑class TypeScript support.
