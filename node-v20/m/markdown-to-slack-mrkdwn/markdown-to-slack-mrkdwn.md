# markdown-to-slack-mrkdwn

> 标签: bot, chat, converter, format, markdown, markup, mrkdwn, slack

## 简介

Convert standard Markdown to Slack mrkdwn format. Handles tables, bold/italic, code blocks, links, lists, headings, and more.
