# mermaid-highlighter

> 标签: diagram, flowchart, graph, highlight, highlighter, mermaid, svg, zoom

## 简介

Render mermaid into a zoomable, interactive & highlightable SVG. Plug-and-play: pass a DOM container + mermaid text.
