# mcp-server-web-fetcher

> 标签: ai-tools, cheerio, claude, html-to-markdown, llm, markdown, mcp, mcp-server, metadata, model-context-protocol, open-graph, turndown, web-scraping

## 简介

Fast, lightweight MCP server that fetches any web page, strips HTML bloat, converts it to clean Markdown, and extracts metadata and links for LLM analysis.
