# mui-csi-datagrid

> 标签: JavaScript

## 简介

A **modular and extensible React DataGrid package** built on top of **Material UI’s `@mui/x-data-grid-pro`**.   It provides a unified, customizable data grid experience for CSI applications — with centralized styling, toolbars, view presets, context menus
