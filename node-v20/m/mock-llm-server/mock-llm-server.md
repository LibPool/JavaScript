# mock-llm-server

> 标签: agent, anthropic, claude, fake, gemini, llm, mock, openai, reasoning, responses-api, sse, streaming, test, testing, tool-calling

## 简介

Fake OpenAI-, Anthropic- and Gemini-compatible API server that returns scripted replies, tool calls, reasoning, errors and streams, so you can test agents without API keys. Zero dependencies.
