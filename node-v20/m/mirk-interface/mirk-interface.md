# mirk-interface

> 标签: bem, buildless, css, departure-mono, design-system, form-components, html-css, no-build, pixel-font, semantic-classes, tailwind, ui-kit

## 简介

A form-focused HTML/CSS UI kit. Seventeen form components plus a content tier (note, hint, list, badge, table, page scaffold) as semantic BEM classes in one hand-written CSS file plus one tiny delegated script. No build step, no React, no web components.
