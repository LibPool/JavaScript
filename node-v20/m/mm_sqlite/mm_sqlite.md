# mm_sqlite

> 标签: async, async-await, await, batch, compatible, database, mm_mysql, node-sqlite3, node.js, promise, sql, sqlite, transaction

## 简介

高性能SQLite数据库操作模块，提供与mm_mysql完全兼容的API接口，支持异步操作、事务处理和批量操作
