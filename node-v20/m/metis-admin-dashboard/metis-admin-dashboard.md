# metis-admin-dashboard

> 标签: admin, admin-dashboard, admin-template, alpinejs, apexcharts, auth-pages, bootstrap, bootstrap5, dark-mode, dashboard, error-pages, html-template, login-page, metis, modern, responsive, scss, vite

## 简介

Metis — free Bootstrap 5.3 admin dashboard template. 30 pages including auth and error pages, Alpine.js, ApexCharts, dark mode, self-hosted fonts and icons. Vite 8, ES modules, no jQuery, zero third-party runtime requests.
