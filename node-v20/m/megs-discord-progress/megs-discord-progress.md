# megs-discord-progress

> 标签: ansi, discord, discord.js, embed, megs, megsnaf, music, music-bot, now-playing, player, progress, progress-bar

## 简介

Beautiful live-updating progress bars for Discord bots — music players, downloads, tasks. Supports embeds and ANSI colored code blocks.
