# muro-tui

> 标签: agent, ai, brutalism, cli, llm, lmstudio, ollama, terminal, textual, tui

## 简介

A brutalist, polished AI coding-agent TUI for any local model - planning, tool calling, multi-step automation. Works with Ollama, LM Studio, OpenAI-compatible servers, and cloud providers.
