# message-type-input

> 标签: chat, contenteditable, message-input, react

## 简介

A lightweight, customizable React component that mimics modern chat input fields. It supports dynamic text wrapping using a contentEditable div and displays a placeholder when the field is empty — perfect for messaging apps, chatbots, or support UIs.
