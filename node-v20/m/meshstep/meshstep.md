# meshstep

> 标签: brep, cad, iso-10303, isotropic-remesh, mesh, step, stl, tessellation

## 简介

STEP -> watertight process-grade mesh importer (analytic + NURBS surfaces, assemblies). Pure TypeScript, zero runtime dependencies, no WASM.
