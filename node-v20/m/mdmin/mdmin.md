# mdmin

> 标签: agent, ai, anthropic, claude, compression, context-budget, context-extraction, context-window, extract, gpt, llm, markdown, minify, openai, rag, sliding-window, tfidf, tokens

## 简介

Markdown compression + context extraction for LLM apps. Rule-based engine (up to 35% savings) + TF-IDF context extractor (up to 95% reduction on targeted queries).
