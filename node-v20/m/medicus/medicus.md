# medicus

> 标签: avvio, diagnostics, fastify, fastify-plugin, health, health check, health-check, healthcheck, heartbeat, hono, k8s, kubernetes, liveness, monitoring, node, nodejs, observability, pino, probe, readiness, tanstack-start, typescript, uptime

## 简介

Flexible, framework-agnostic health check library for Node.js and TypeScript. Liveness and readiness checks with Fastify, Hono, Avvio and plain HTTP integrations.
