# mao-service-discovery-raspberry-pi

> 标签: etcd, etcdv3, grpc, grpc-go, grpc-ping, icmp, icmp-ping, icmpv6, microservices, monitor, service-discovery, system-monitor, utils

## 简介

Discover your services by using gRPC stream, ICMP or etcd. Come with WebGUI, Restful API and Config Persistence ability.
