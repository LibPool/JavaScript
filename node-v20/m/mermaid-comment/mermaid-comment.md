# mermaid-comment

> 标签: JavaScript

## 简介

您可以在您的函数中编写注释，其中包含特别标记的 Mermaid 代码，该库将生成一个 MERMAID.md 文件，可以预览该文件以显示 sequenceDiagram 图。 目前，该库仅支持 sequenceDiagram。
