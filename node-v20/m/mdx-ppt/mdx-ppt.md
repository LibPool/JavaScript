# mdx-ppt

> 标签: JavaScript

## 简介

通过 `MDX` 语法，让你便捷组织你的内容的同时，可以便捷地展示你的内容。使用 `MDX` 你还可以享受 `React` 非常强大的组件化功能，让你可以任意展示你的创意。
