# mischief

> 标签: accessibility, cdp, chaos, e2e, fuzzing, monkey-testing, playwright, qa

## 简介

Seeded, guard-railed monkey testing for web apps in a real browser. Every finding replays from its seed; a run that could not reach the page it asked for fails instead of passing.
