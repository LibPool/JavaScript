# mcp-jira-tempo

> 标签: ai, ai-connector, ai-integration, anthropic, atlassian, claude, cli, external-tools, issue-tracking, jira, llm, mcp, mcp-inspector, mcp-server, model-context-protocol, project-management, resources, server, tempo, tooling, tools, typescript

## 简介

MCP server for Jira Cloud (multi-profile) and Tempo Cloud: generic REST tools, file-based Jira profiles, and optional Tempo helpers for worklogs and accounts.
