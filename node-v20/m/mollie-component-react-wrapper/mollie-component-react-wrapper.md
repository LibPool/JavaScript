# mollie-component-react-wrapper

> 标签: components, mollie, mollie.js, react, ui

## 简介

🚀 **Unofficial React Wrapper for Mollie.js**\ This package provides a **React-friendly integration** for [Mollie Components](https://docs.mollie.com/docs/mollie-components), enabling secure and PCI-compliant card payment forms.
