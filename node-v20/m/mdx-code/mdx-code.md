# mdx-code

> 标签: JavaScript

## 简介

A MDX Deck [Layout](https://github.com/jxnblk/mdx-deck#layouts) that renders code blocks on a slide as a Runnable [RunKit](https://runkit.com) playground. _Only for JavaScript (Node)_
