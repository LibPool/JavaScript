# mini-baas-sdk

> 标签: JavaScript

## 简介

SDK TypeScript do Mini BaaS com cliente JWT e serviços tipados (auth, projetos, coleções, documentos, arquivos, funções, chaves de API, times, auditoria, RBAC, políticas, RLS, webhooks e realtime via SSE)
