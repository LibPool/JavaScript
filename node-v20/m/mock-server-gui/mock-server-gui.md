# mock-server-gui

> 标签: JavaScript

## 简介

一个带有界面的 mock 数据服务器，使用 TypeScript，React，Node.js 技术实现。 ## 动机 在平时开发中，会遇到页面提前完成，而接口还没有完成的情况，我平时会用 `setTimeout` 和 `Promise` 来模拟延迟返回数据，因为我不想配置一些类似 `mock.js` 的工具，感觉很麻烦，可能之后会去了解一下。
