# mineru-dsh-plugin

> 标签: deepseek-harness, document-parser, dsh, markdown, mineru, ocr, pdf, plugin

## 简介

MinerU document parsing plugin for DSH (DeepSeek Harness): dual-mode cloud parsing (free Agent API / Standard API with token and auto-routing), agent tools, and a browser panel with drag-drop upload. One-command install via the bundled CLI.
