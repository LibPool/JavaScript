# markdown-live-editor

> 标签: JavaScript

## 简介

A live, WYSIWYG-style markdown editor built on Tiptap/ProseMirror — real block elements instead of a plain-text buffer with syntax hidden/revealed via decorations. Ships no embeds of its own; bring your own Tiptap node extensions.
