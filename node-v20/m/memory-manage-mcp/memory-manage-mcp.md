# memory-manage-mcp

> 标签: ai-agents, context, handoff, local-first, mcp, memory, model-context-protocol

## 简介

Local-first, database-free persistent memory MCP server. Lets any AI coding agent (VS Code, Cursor, Claude, Gemini CLI, ...) continue a project exactly where another agent left off.
