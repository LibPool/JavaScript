# mavunta-cli

> 标签: cli, kenya, mavunta, mavunta-pay, mpesa, payments, webhooks

## 简介

Mavunta Pay command-line tools: verify keys, trigger sandbox webhooks, and forward live events to your local server for webhook testing.
