# mym-template

> 标签: JavaScript

## 简介

根据命令，形如：mym g list [name]，执行模板生成函数。即可在执行目录下生成代码文件。     web端项目新增内容：         1. 添加路径别名：@components、@utils，可在引入模块时使用         2. 创建表单的formItem函数，添加自定义组件的功能     ### 功能
