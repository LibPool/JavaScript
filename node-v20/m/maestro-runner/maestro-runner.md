# maestro-runner

> 标签: android, appium, e2e, flutter, ios, maestro, mobile-testing, react-native, test-automation, ui-testing

## 简介

Fast mobile UI test automation for Android, iOS, React Native, Flutter and Expo. Runs Maestro YAML flows from a single binary — no JVM.
