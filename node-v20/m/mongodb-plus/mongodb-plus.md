# mongodb-plus

> 标签: mongodb, mongodb-p, mongodb-pl, mongodb-plu, mongodb-plus, node-mongodb

## 简介

This is a wrapper library for the mongodb method that makes it easier for nodes to manipulate the mongodb database.
