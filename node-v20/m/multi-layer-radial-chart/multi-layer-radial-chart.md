# multi-layer-radial-chart

> 标签: activity-rings, animation, charts, data-visualization, progress-ring, radial-chart, react, react19, svg, typescript, vite

## 简介

A lightweight, dependency-free React 19 + TypeScript library for animated multi-layer radial (activity-ring) charts, rendered with pure SVG.
