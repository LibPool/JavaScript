# mvr-apollo

> 标签: JavaScript

## 简介

* **ES6/ESNext** - Write _ES6_ code and _Babel_ will transpile it to ES5 for backwards compatibility * **Lint** - Preconfigured _ESlint_ with _Airbnb_ config * **Minify** - Built code will be minified for performance
