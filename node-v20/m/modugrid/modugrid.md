# modugrid

> 标签: data-grid, datagrid, dirty-tracking, editable-table, grid, ime, inline-edit, no-dependencies, table, vanilla-js

## 简介

Dependency-free vanilla JS data grid for enterprise forms — inline editing, dirty tracking, frozen columns, grouped headers, IME-safe Korean input.
