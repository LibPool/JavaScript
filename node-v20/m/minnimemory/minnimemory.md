# minnimemory

> 标签: agent, claude, context, llm, mcp, memory, prompt-caching, tokens

## 简介

MinniMemoryMCP: an MCP server that gives an AI coding agent curated memory. Tools audit the agent's memory file, compile it into a small AlwaysOnMemory body plus OnDemandMemory files, serve it back on demand and keep it maintained. Deterministic, lossless
