# markdown-plaintext

> 标签: commonmark, embeddings, markdown, plain-text, plaintext, rag, search, strip, text-extraction, zero-dependency

## 简介

Turn markdown into plain text without destroying the text: code blocks, escapes, entities and autolinks all survive. Zero dependencies.
