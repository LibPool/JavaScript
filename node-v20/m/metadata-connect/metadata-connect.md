# metadata-connect

> 标签: aac, aiff, album-art, artwork, audio, bpm, cover, dj, extractor, flac, genre, id3, id3v2, key, m4a, metadata, mp3, mp4, music, network, parser, partial-read, streaming, tempo

## 简介

Extract audio metadata (title, artist, album, BPM, key, artwork) from MP3, M4A, FLAC, and AIFF files with minimal network transfer using partial file reads
