## 简介

Full-featured file upload component for any backend. Pluggable strategies (direct-to-S3 multipart, direct-to-Azure Blob, tus 1.0.0, server-side URL import), chunked uploads with parallel chunks, IndexedDB-backed resume (Golden Retriever equivalent), Web W
