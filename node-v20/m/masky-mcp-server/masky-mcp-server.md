# masky-mcp-server

> 标签: ai, anthropic, avatar, claude, masky, mcp, model-context-protocol

## 简介

MCP server for the Masky AI avatar platform — gives Claude tools to list/create avatars, run conversations, and inject turns whose audio/video can be embedded in OBS or any web embed.
