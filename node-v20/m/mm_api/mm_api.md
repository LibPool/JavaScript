# mm_api

> 标签: API管理器, api, mm_in_port, mm_mod, mm_port, mvc, oauth, router

## 简介

API框架，用于实现web api和mvc模式路由请求，负责配置路由路径、访问权限、校验机制；基于 mm_corejs，内置管理器池，无全局/原型扩展依赖
