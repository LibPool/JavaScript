# mcpcompat

> 标签: cli, compatibility, mcp, model-context-protocol, registry, sdk

## 简介

Client-side MCP server compatibility facts (SDK drift, transport, liveness) from public metadata — the free CLI companion to mcpcompat.io. T0 = metadata only; never installs, runs, imports, or evals a scanned package.

- npm 页面：https://www.npmjs.com/package/mcpcompat
