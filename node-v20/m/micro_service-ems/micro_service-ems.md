# micro_service-ems

> 标签: JavaScript

## 简介

`micro_service-ems` is a lightweight Node.js utility built to manage **hierarchical relationships** between entities (like users, employees, or nodes) using **Prisma ORM**.   It allows you to easily **create, update** between records — such as parent-chi
