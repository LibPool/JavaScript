# modeler-jbpm

> 标签: jbpm, modeler, node-red

## 简介

The Set of nodes help make Execute the following set of actions: * Create Process Instance * Create Task Instances * Claim Task * Start Task * Complete Task * Check-in Task (Complex Type) * check-out Task (Complex Type)
