# mapbox-gl-draw-paint-mode

> 标签: JavaScript

## 简介

This is a custom mode for @mapbox/mapbox-gl-draw that allows user to paint freestyle on the map This mode used to be one of the core modes prior to the v1.0.0 release of Mapbox Draw
