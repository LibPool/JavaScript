# map-routing

> 标签: coordinate, image-overlay, interactive-map, map, navigation, pan-zoom, react, route, route-visualization, svg-overlay, videomapping

## 简介

Interactive image route overlay: render points and segments in an SVG layer, convert pointer input to normalized coordinates, and support pan/zoom navigation with video synchronization.
