# mcp-safeguard

> 标签: agent, ci, mcp, model-context-protocol, owasp, safeguard, scanner, security, tool-poisoning

## 简介

Scan an MCP server's tools for security risks (tool poisoning, secret leaks, dangerous capabilities) mapped to the OWASP MCP Top 10. CI-friendly.
