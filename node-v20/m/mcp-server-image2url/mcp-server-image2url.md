# mcp-server-image2url

> 标签: image-upload, image2url, mcp, model-context-protocol

## 简介

One-command MCP server that uploads images to image2url.com and returns shareable links/snippets without an API key.

- 官网：https://www.image2url.com/tools/mcp-server-image2url

- npm 页面：https://www.npmjs.com/package/mcp-server-image2url
