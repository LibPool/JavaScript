# miview

> 标签: component, miview, vue

## 简介

`miview` 是一款基于 `Vue.js 2.0` 和 `ElementUI 2.0` 的前端 UI 通用组件库，主要用于快速开发 PC 网站中后台产品

- 源码仓库：git+ssh://git@github.com/miview/miview.git
