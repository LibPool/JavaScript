# memorize-mcp

> 标签: agent, ai, claude, copilot, llm, mcp, memory, model-context-protocol, prompts, workflow

## 简介

A minimal Model Context Protocol (MCP) server to persist work summaries as local JSON memories with CLI support for pulling AI agent prompts and skills.
