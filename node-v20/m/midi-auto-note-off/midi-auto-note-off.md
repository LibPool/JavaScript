# midi-auto-note-off

> 标签: DAW, E-DRUM, JavaScript, Logic Pro X, MIDI

## 简介

Solves the problem with certain e-drums not sending MIDI NOTE OFF command by playing a proxy and adding the missing MIDI NOTE off command.
