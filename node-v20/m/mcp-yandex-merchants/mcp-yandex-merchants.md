> 标签: e-commerce, mcp, model-context-protocol, price-management, product-feed, yandex, yandex-merchants, yandex-products

## 简介

MCP server for the Yandex Merchants (Яндекс Товары) partner API — feed info, offer price updates, discounts, hiding and unhiding offers for AI agents.
