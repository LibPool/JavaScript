## 简介

&nbsp;   Atur konfigurasi pada Client Service.   Pastikan **SVC_ID** dan **SVC_CMNT** ada pada file `.env` client. ```env SVC_ID=********-****-****-****-************ SVC_CMNT=http://comment ```
