# micro-core-ui

> 标签: component-library, components, css-components, custom-components, design-system, frontend, frontend-ui, javascript-ui, lightweight-ui, modern-ui, typescript, ui, ui-library, vite, vite-plugin, vue, vue-component-library, vue-components, vue-design-system, vue-ui, vue3, web-components

## 简介

Micro Core UI is a Vue 3 component library built with Vite and Tailwind CSS that provides reusable, customizable UI components to help teams build consistent and modern interfaces faster.
