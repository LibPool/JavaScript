# metalmind

> 标签: JavaScript

## 简介

Unified CLI for a local markdown-as-memory vault (Obsidian-compatible, not required) and cross-repo code intelligence. Hosts: Claude Code + Codex CLI. Mistborn-themed with a neutral alias set.
