# mufmuf-mcp

> 标签: ai, compatibility, image, mcp, model-context-protocol, mufmuf

## 简介

MCP server for Mufmuf, AI-powered visual compatibility scoring. Exposes a compare_compatibility tool that scores how well two photos match.
