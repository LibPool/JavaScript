# mcp-databnf

> 标签: authority-records, bibliography, bnf, data-bnf, linked-data, mcp, model-context-protocol, sparql

## 简介

MCP server for data.bnf.fr, the Bibliothèque nationale de France open catalogue. Look up authors, works, editions and the Gallica links attached to them. No API key required.
