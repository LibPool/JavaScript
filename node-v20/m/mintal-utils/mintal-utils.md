# mintal-utils

> 标签: JavaScript

## 简介

基于 Vue 3 + TypeScript + Vite 的高质量工具函数库，适用于现代前端项目。原始代码由 Vue2 工具库 [liao_modules](https://www.npmjs.com/package/liao_modules) 升级迁移而来，现已全面适配 Vue3 生态。
