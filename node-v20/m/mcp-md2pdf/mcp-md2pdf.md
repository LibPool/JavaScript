# mcp-md2pdf

> 标签: api, katex, library, markdown, mcp, mermaid, model-context-protocol, pdf, syntax-highlighting

## 简介

Convert Markdown to beautiful PDFs. MCP server, CLI, and programmatic API. Supports Mermaid diagrams, KaTeX math, syntax highlighting, tables, and auto-generated Table of Contents.
