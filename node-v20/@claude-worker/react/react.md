# @claude-worker/react

> 标签: agent, anthropic, claude, claude-code, headless, hooks, react

## 简介

Headless React layer for claude-worker: useClaudeSession hook + pure transcript reducer. No styling opinion — @claude-worker/ui is the styled layer on top.
