# @ztl0001/dsh-notify

> 标签: cordis, deepseek, dsh, dsh-plugin, harness, notification, plugin, toast, windows

## 简介

Windows notifications when a DeepSeek Harness task finishes — a native toast with the session title, the outcome and a summary of the reply.
