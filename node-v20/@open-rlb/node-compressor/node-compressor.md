# @open-rlb/node-compressor

> 标签: archive, brotli, cli, compression, deflate, gzip, stream, tar, typescript, zip, zstd

## 简介

Compression of buffers, streams and files plus tar/zip archiving, built on Node built-in modules only. Zero runtime dependencies.
