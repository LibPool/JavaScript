# @toytown/cli

> 标签: buildings, cli, maplibre, openstreetmap, osm, overpass, pbf, toytown-gl

## 简介

toytown build-data: fetch OpenStreetMap buildings, open spaces and trees for any bbox, classify them, and write a compact data file for toytown-gl.
