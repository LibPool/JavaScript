# @4admin/pdf-viewer

> 标签: heroui, pdf, pdf-viewer, pdfjs, react, react-pdf-viewer

## 简介

Drop-in, pdf.js-based replacement for the archived @react-pdf-viewer — virtualized, HeroUI-styled, built for the 4admin client.
