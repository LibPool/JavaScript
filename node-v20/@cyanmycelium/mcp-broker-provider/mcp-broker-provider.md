# @cyanmycelium/mcp-broker-provider

> 标签: broker, cyanmycelium, mcp, model-context-protocol, provider, transport, tunnel, websocket

## 简介

Provider side of the CyanMycelium MCP broker tunnel: publish an MCP server to a broker slot over the shared envelope protocol.
