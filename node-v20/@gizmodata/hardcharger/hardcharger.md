# @gizmodata/hardcharger

> 标签: apache-arrow, arrow, duckdb, gizmodata, hardcharger, sql, warp-sql

## 简介

JavaScript/TypeScript client for Hardcharger™, GizmoData™'s DuckDB 2.0 server: hardcharger:// URLs on the Warp SQL client, for Node, browsers, Deno, Bun and edge runtimes.
