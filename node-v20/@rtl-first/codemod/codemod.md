# @rtl-first/codemod

> 标签: arabic, ast, codemod, css, hebrew, i18n, jscodeshift, logical-properties, postcss, right-to-left, rtl, tailwind

## 简介

Convert CSS physical properties to logical for RTL. Multi-engine: PostCSS AST for CSS, jscodeshift for CSS-in-JS, Tailwind class mapper, regex fallback.
