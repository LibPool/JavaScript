# @simplr-ai/angular

> 标签: ai-delegation, angular, behavioral-biometrics, device-fingerprinting, feature-flags, fraud-detection, rum, rxjs, simplr

## 简介

Idiomatic Angular adapter for the Simplr platform — DI services, RxJS observables, directives and components over the @simplr-ai/js browser core (fraud, device fingerprint, behavioral biometrics, feature flags, profiles, RUM, AI delegation).
