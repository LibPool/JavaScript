# @vtexlab/axios-concurrent-retry

> 标签: JavaScript

## 简介

[Deprecated: Use @vtex/axios-concurrent-retry instead] Axios plugin that intercepts failed requests and retries them whenever possible, and runs concurrent requests after a set timeout.
