# @bisquecloud/sdk

> 标签: agents, api-client, bisque, mcp, narration, openapi, presentations, sdk

## 简介

Official TypeScript SDK for the Bisque API: create narrated presentations from a program — the slides go up first and each slide's narration follows — and read any shared one back as text.
