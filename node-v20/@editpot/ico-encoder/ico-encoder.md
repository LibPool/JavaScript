# @editpot/ico-encoder

> 标签: bmp, encoder, favicon, ico, icon, png

## 简介

Dependency-free ICO encoder for browsers and Node. RGBA pixels become 32bpp BMP entries, PNG bytes are stored as-is.

## 官网

- 官网：https://editpot.com
- npm 页面：https://www.npmjs.com/package/@editpot/ico-encoder
