# @trebor/buildhtml

> 标签: dashboard, html, html-builder, no-dependencies, nodejs, reactive, report, server-side-rendering, ssr, template

## 简介

Server-side HTML compiler for Node.js. Build pages with a JavaScript API while reactive state, events, and DOM bindings compile automatically.
