# @neuctra/ui-mcp

> 标签: component-registry, mcp, model-context-protocol, neuctra, react, ui

## 简介

MCP server exposing the @neuctra/ui component registry (props, defaults, examples, theme tokens) so AI coding tools generate accurate Neuctra UI code.
