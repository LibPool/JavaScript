# @vigilia/sentinel-hook

> 标签: ai-agents, ai-safety, audit-log, claude-code, coding-agent, ed25519, hash-chain, hooks, transparency-log, witness

## 简介

A free Swiss witness for your coding agent: a local hash-chained record of every Claude Code tool call, its fingerprint sealed with an independent witness. Optional allow/ask/deny gate.
