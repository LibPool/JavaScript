# @mieweb/cloud-types

> 标签: JavaScript

## 简介

Portable platform-service contracts (database, object storage, key/value, queues, stateful objects, vector index, AI). On Cloudflare these are exact aliases of the native binding types, so existing code keeps compiling unchanged; other adapters implement
