# @mieweb/cli

> 标签: cli, cloudflare, mieweb, serverless, workers, wrangler

## 简介

`mieweb` CLI — a thin, target-aware wrapper over wrangler. On the cloudflare target it delegates verbatim to the real wrangler binary; on other targets it drives the matching @mieweb adapter (e.g. the local Node host harness).
