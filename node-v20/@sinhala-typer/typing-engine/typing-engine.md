# @sinhala-typer/typing-engine

> 标签: ime, input-method, keyboard-layout, phonetic, sinhala, sri-lanka, transliteration, typing, unicode, wijesekara

## 简介

Framework-agnostic, zero-dependency Sinhala transliteration engine (phonetic + Wijesekara input methods, plus a legacy-font converter), with zero DOM/browser dependencies and a pluggable LanguageModule interface for future languages.
