# @iappx/app-config-yaml

> 标签: class-transformer, class-validator, config, configuration, decorators, env, environment, nestjs, placeholders, settings, typescript, validation, yaml

## 简介

Layered YAML configuration for Node.js: a base file plus a per-environment override, ${ENV} placeholders, and typed config sections validated with class-validator.
