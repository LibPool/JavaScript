# @jiangshengdev/mini-vue

> 标签: JavaScript

## 简介

一个面向自学的 Vue 3 核心精简实现，覆盖响应式系统、JSX 渲染链路以及 jsdom 测试场景。项目基于 Vite 7 + TypeScript + Vitest，所有 API 由 `src/index.ts` 统一导出，方便在 Demo 与测试间共享。
