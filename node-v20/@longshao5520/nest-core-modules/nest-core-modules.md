# @longshao5520/nest-core-modules

> 标签: JavaScript

## 简介

一个面向 NestJS 的核心模块集合，提供严格类型的本地配置读取与 Typegoose/Mongoose 集成，支持通过 CLI 自动生成配置类型并进行运行时校验。
