# @conduction/docusaurus-preset

> 标签: conduction, connext, design-system, diagrams, docusaurus, docusaurus-preset, hex, nextcloud, web-components

## 简介

Conduction brand preset for Docusaurus 3. Tokens, theme, navbar, footer, i18n config for nl/en/de/fr, and the React component library that powers conduction.nl and the Conduction product sites.
