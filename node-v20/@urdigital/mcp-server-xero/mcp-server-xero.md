# @urdigital/mcp-server-xero

> 标签: accounting, claude, invoicing, mcp, model-context-protocol, xero

## 简介

MCP server for Xero: 41 tools across Accounting, Reports, Payments, Manual Journals, Budgets, Attachments, Payroll AU, Files, Assets, and Projects. Full OAuth 2.0 (not Custom Connections) — see this package's README for the required one-time setup step.
