# @makaio/adapter-pi-sdk

> 标签: JavaScript

## 简介

Pi coding agent SDK adapter for the Makaio AI framework. Wraps the `@mariozechner/pi-coding-agent` SDK — specifically `createAgentSession()` + `session.prompt()` + `session.subscribe()` — and bridges its procedural agentic loop into the Makaio three-layer
