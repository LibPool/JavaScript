# @makaio/provider-openai

> 标签: JavaScript

## 简介

Type-only package that declares the OpenAI provider identity for the Makaio framework. It exports a single `providerDefinition: ProviderDefinitionInput` for the official OpenAI API, communicating over the OpenAI Chat Completions wire protocol. No runtime
