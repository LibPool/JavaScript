# @narai/db-agent-connector

> 标签: agent, claude, connector, database, dynamodb, mongodb, mysql, oracle, postgresql, sql, sqlite

## 简介

Safe, read-only database query connector with guard-rail policy enforcement. Built on @narai/connector-toolkit. Ships a JSON-envelope CLI and a library API. Supports PostgreSQL, MySQL, SQLite, SQL Server, MongoDB, DynamoDB, and Oracle via pluggable driver
