# @narai/github-agent-connector

> 标签: agent, claude, connector, github

## 简介

Read-only GitHub connector: repo info, code search, PR/issue listing, file retrieval. Built on @narai/connector-toolkit with an approval gate and hardship logging. JSON-envelope CLI + library API.
