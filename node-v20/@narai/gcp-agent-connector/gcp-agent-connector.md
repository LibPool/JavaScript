# @narai/gcp-agent-connector

> 标签: agent, claude, cloud-run, cloud-sql, connector, gcp, pubsub

## 简介

Read-only GCP connector: Cloud Run, Cloud SQL, Pub/Sub, Cloud Logging. Shells out to gcloud/bq. Built on @narai/connector-toolkit with an approval gate and hardship logging. JSON-envelope CLI + library API.
