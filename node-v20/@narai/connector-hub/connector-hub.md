# @narai/connector-hub

> 标签: agent, claude, connector, hub, narai, orchestration

## 简介

Read-only orchestration layer over @narai/*-agent-connector packages. Plans connector calls from a natural-language prompt via the Claude Agent SDK and dispatches them in parallel.
