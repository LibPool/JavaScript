# @primethoughts/primecredence-sdk

> 标签: did, primecredence, sdk, ssi, trust-os, verifiable-credentials

## 简介

TypeScript SDK for PrimeCredence Trust OS — typed client for the gateway endpoints covering W3C VCs, OID4VCI/OID4VP, Trust Registry, billing, and DPP lifecycle
