# @wdp-api/wim-api

> 标签: 51AES, 51WDP, 51WORLD, WIM, WdpApi

## 简介

51WORLD WIM Api is a JavaScript plugin for WdpApi, It provides a set of APIs for developers to integrate WIM into their own applications.
