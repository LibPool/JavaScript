# @noetic-tools/acp

> 标签: acp, agent-client-protocol, agents, claude-code, codex, coding-agent, noetic

## 简介

Both directions of the Agent Client Protocol for Noetic. Drives any ACP-speaking coding agent (Claude Code, Codex, Gemini CLI, …) as a step, and serves a Noetic harness as an ACP agent for editors like Zed (toAcpAgent / serveAcp).
