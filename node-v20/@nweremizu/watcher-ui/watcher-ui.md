# @nweremizu/watcher-ui

> 标签: css, design, design-system, devtools, figma, inspector, overlay, react, svg-editor

## 简介

Open your running React app like a design file: rulers, live style editing, canvas mode, an SVG editor, design-system extraction and a profiler. Dev-only, zero bytes in production.
