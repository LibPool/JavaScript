# @actuate-media/plugin-forms

> 标签: JavaScript

## 简介

Forms for [Actuate CMS](https://github.com/actuate-media/actuatecms) — schema-versioned form definitions, public submission API, spam protection, submissions inbox, notifications, and webhooks.
