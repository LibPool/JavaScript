# vite-plugin-perf-gate

> 标签: baseline, budget, bundle-analyzer, bundle-size, chunk, ci, gate, perf, performance, performance-budget, regression, size-limit, vite, vite-plugin, vitejs

## 简介

Vite build-time performance gate: enforce bundle size, gzip size, chunk count and baseline regression budgets, then block the build when they are exceeded. Optionally gates the first-screen JS/CSS closure separately.
