> 标签: ai-agent, air-quality, claude, gios, jakosc-powietrza, mcp, model-context-protocol, open-data, pm10, pm2.5, poland, pollen, pylki, smog

## 简介

MCP server: air quality in Poland for AI agents – live GIOŚ measurements (PM2.5, PM10, NO2, O3) with the Polish air quality index, smog warnings, 3-day CAMS forecast and pollen. No API key.
