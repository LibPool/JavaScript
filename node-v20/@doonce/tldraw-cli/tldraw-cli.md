# @doonce/tldraw-cli

> 标签: JavaScript

## 简介

通过 CLI 和 HTTP JSON-RPC 操作浏览器中的 [tldraw](https://github.com/tldraw/tldraw) 画布——创建图形、读取状态、跟踪变更。支持 Code Agent 通过 skill 自主驱动画布，也支持脚本和 SDK 通过 RPC 直接调用。人和 AI 共用同一块画布，互相可见。
