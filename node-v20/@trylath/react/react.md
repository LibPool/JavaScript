# @trylath/react

> 标签: auth, authentication, components, lath, mfa, passkeys, react, sign-in

## 简介

Drop-in React components for Lath authentication: sign-in, sign-up, MFA, passkeys, profile and organization switcher, themed from the project's own tokens.
