# @trylath/auth-ui

> 标签: auth, authentication, headless, lath, mfa, passkeys

## 简介

Headless auth client for Lath: sign-in, sign-up, MFA, passkeys, profile and organizations, with no UI of its own. The engine under @trylath/react and @trylath/react-native.
