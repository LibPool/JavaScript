# @craftstory/mcp

> 标签: ai-video, craftstory, lip-sync, mcp, minimax, model-context-protocol, talking-avatar, text-to-video

## 简介

MCP server for the CraftStory API: talking-avatar videos from a photo (CraftStory 2.0), short clips with generated sound (MiniMax H3), images (Nano Banana) and music, from Claude, Cursor and other MCP clients.
