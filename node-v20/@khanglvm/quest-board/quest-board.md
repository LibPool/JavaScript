# @khanglvm/quest-board

> 标签: agent-skill, ai-agents, claude-code, cli, codex, human-in-the-loop, interactive-questions, prototype, visualization

## 简介

Browser-based question boards & HTML idea visualization for AI coding agents (Claude Code, Codex, …): ask users structured questions, present prototypes, wait for submit, read answers as JSON.
