# @wanggangqi/chat-manager-sdk

> 标签: JavaScript

## 简介

Remote SessionManager + MessageStore for @wanggangqi/chat-ui-core, backed by chat-manager backend. Versioned together with the chat-manager project (backend + frontend + this SDK share the same release).
