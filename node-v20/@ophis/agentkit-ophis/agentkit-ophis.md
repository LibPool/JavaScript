# @ophis/agentkit-ophis

> 标签: agent, agentkit, ai-agent, coinbase, cow-protocol, defi, ophis, rebate, swap

## 简介

Coinbase AgentKit action provider: let an AI agent swap ERC-20s via Ophis (CoW Protocol), carrying the Ophis partner fee + your referral code so you earn the 8-12% rebate.
