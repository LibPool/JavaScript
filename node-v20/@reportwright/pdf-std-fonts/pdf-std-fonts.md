# @reportwright/pdf-std-fonts

> 标签: JavaScript

## 简介

Optional outlines for the 14 standard PDF fonts, for @reportwright/pdf's renderer: Liberation Sans / Serif / Mono 2.1.5 (metric-compatible with Helvetica, Times and Courier) and Noto Sans Symbols 2 for ZapfDingbats, all under the SIL Open Font License 1.1
