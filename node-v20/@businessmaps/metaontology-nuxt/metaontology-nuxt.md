# @businessmaps/metaontology-nuxt

> 标签: ddd, domain-modeling, indexeddb, metaontology, nuxt, offline-first, sync, triple-store, vue

## 简介

Vue 3 and Nuxt 4 integration layer for @businessmaps/metaontology. Reactive composables for commit-sourced persistence, cloud sync, cross-tab coordination, and a reactive triple store.
