# @flemo/react-layout

> 标签: flemo, layout, motion, react, shared-element, transition

## 简介

layoutId / shared-element morphs for flemo. Wraps a Screen with motion's AnimatePresence + MotionConfig so children with matching layoutId animate between screens.
