# @comradeweb/pipeline-queue-kit

> 标签: bullmq, nestjs, pipeline, queue, worker

## 简介

BullMQ host for @comradeweb/pipeline-kit pipelines: queue-bound processors, per-queue worker options, fire-and-forget enqueuer, Bull Board friendly job-reporting logger.
