# @c15t/iab

> 标签: cmp, consent, cookie-consent, gdpr, global-privacy-platform, global-vendor-list, gpp, iab, iab-tcf, iab-tcf-2.4, privacy, programmatic-advertising, tc-string, tcf, tcf-cmp, transparency-consent-framework

## 简介

IAB TCF 2.4 CMP addon for c15t. Generates TC Strings and GPP strings, loads the Global Vendor List (GVL), and collects GDPR consent for programmatic advertising.
