# @dsh-cc/web-fetch-http

> 标签: JavaScript

## 简介

CC host-plane HTTP(S) fetch provider: wraps the harness HttpFetchProvider with a literal SSRF gate (private/loopback/link-local block) and optional http→https upgrade
