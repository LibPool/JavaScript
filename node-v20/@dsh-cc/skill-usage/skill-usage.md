# @dsh-cc/skill-usage

> 标签: JavaScript

## 简介

Skill lifecycle usage telemetry: observe-only listeners counting committed skill loads (tool form via tools/result, slash form via persisted skill-invocation messages) into a per-workspace sidecar ledger with an observation-start marker; default on
