# @richkitjs/extension-ai

> 标签: ai, ai-writing, copilot, editor, llm, prosemirror, rich-text, rich-text-editor, richkit, richkit-extension, streaming, suggestions, text-editor, wysiwyg

## 简介

AI writing for RichKit: stream model output into the document as tracked suggestions the user accepts or rejects. Bring any provider through a transport function.
