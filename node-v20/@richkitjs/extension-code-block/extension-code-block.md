# @richkitjs/extension-code-block

> 标签: code, code-block, editor, highlight.js, lowlight, prosemirror, rich-text, rich-text-editor, richkit, richkit-extension, syntax-highlighting, text-editor, wysiwyg

## 简介

Code blocks for RichKit with syntax highlighting (16 languages built in, add any highlight.js grammar), language picker, line numbers, copy button and Tab indenting.
