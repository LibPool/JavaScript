# @richkitjs/extension-hard-break

> 标签: br, editor, hard-break, line-break, prosemirror, rich-text, rich-text-editor, richkit, richkit-extension, text-editor, wysiwyg

## 简介

Hard line break for RichKit: Shift-Enter or Mod-Enter inserts a <br> inside a block.
