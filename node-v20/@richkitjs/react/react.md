# @richkitjs/react

> 标签: block-editor, bubble-menu, contenteditable, document-editor, editor, headless, headless-editor, notion-like, prosemirror, react, react-component, react-editor, react-hooks, rich-text, rich-text-editor, richkit, text-editor, toolbar, typescript, wysiwyg

## 简介

React 18/19 bindings for RichKit: useEditor hook, EditorContent, ready-made DefaultToolbar, BubbleMenu, table/link/image/color menus and EditorProvider.
