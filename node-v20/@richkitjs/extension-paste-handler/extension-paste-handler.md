# @richkitjs/extension-paste-handler

> 标签: clipboard, editor, google-docs, paste, paste-from-word, prosemirror, rich-text, rich-text-editor, richkit, richkit-extension, sanitize, text-editor, wysiwyg

## 简介

Smart paste for RichKit: cleans HTML from Word and Google Docs, converts pasted Markdown, and turns pasted URLs into links.
