# @patrick.kokou/zag-backend-pg

> 标签: metrics, zag

## 简介

postgres backend for zag metrics — pinned to the legacy 0.0.7 schema (prod_metrics_data with metrics_key/time_start/data) on pg@^8 for Node 18+ compatibility
