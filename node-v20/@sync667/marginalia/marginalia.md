# @sync667/marginalia

> 标签: agent-skill, annotations, claude-code, comments, docs, documentation, markdown, review

## 简介

Turn any project's markdown docs into a self-contained web review tool — highlight passages, add inline comments, hand the batch back to your AI agent as structured JSON.
