# @pusula/text-captcha

> 标签: JavaScript

## 简介

A lightweight, canvas-based **text CAPTCHA** component for **Vue 2.7 + TypeScript**.   Includes language-aware character sets, **RTL (right-to-left)** layout, customizable colors, and a standalone helper API.
