# @marionebl/bundle-id

> 标签: CFBundleIdentifier, CFBundleName, applescript, bundle, bundleid, bundlename, id, identifier, macos, osx, plist, uti

## 简介

Get bundle identifier from a bundle name (macOS): `Safari` → `com.apple.Safari`
