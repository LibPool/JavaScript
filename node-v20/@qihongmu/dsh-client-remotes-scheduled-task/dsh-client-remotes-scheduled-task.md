# @qihongmu/dsh-client-remotes-scheduled-task

> 标签: JavaScript

## 简介

External user plugin: browser assembly that mounts the vendored scheduledTasks Remote contribution before the scheduled-tasks UI entry activates (plugin-scoped counterpart of the in-repo dsh-api-remotes assembly).
