# @njweber/android-manifest-check

> 标签: aab, android, androidmanifest, apk, cli, expo, google-play, manifest, react-native, release

## 简介

Audit an Android manifest (from an .aab or a text AndroidManifest.xml) for debuggable/cleartext/exported/permission problems — dependency-free.
