# @kidlab/dsh-kid-network

> 标签: dsh, dsh-plugin, kid, network

## 简介

给小朋友的网络启蒙插件：一个包 = 一张 🕊️「信鸽邮局」卡片 + 五个模型工具（net_my_identity / net_trace_trip / net_test_speed / net_who_is_home / net_dns），零第三方依赖、无构建步骤。
