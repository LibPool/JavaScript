# @origin.jewe/strapi-plugin-geolocation

> 标签: coordinates, geolocation, leaflet, map, osm, strapi, strapi-plugin

## 简介

A Strapi v5 plugin that provides a custom field for geolocation data with an interactive Leaflet map interface with OSM data
