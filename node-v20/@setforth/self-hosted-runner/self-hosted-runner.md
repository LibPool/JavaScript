# @setforth/self-hosted-runner

> 标签: JavaScript

## 简介

Run SetForth's AI coding agents on your own machine or infrastructure, inside Docker, on your own repositories. The runner connects out to the SetForth platform, picks up agent work for your organization, and executes each session in an isolated container
