## 简介

The data-conversion hub of the Lacspace Sheets Kit — convert tabular and structured data between JSON, NDJSON, CSV, TSV, XLSX, YAML, TOML, Markdown, HTML and SQL in one call. Format sniffing, type inference, flatten/unflatten, column select/rename, stream
