# @lacspace/llm-cache

> 标签: 429, cache, content-hash, gemini, groq, isomorphic, llm-cache, lru, memoize, openai, prompt-cache, rate-limit, ttl, typescript, zero-dependency

## 简介

A content-hash cache for LLM calls — key by (model family, prompt version, normalized input) so identical requests, retries after a 429, and repeated rewrites never pay twice. Pluggable async store (in-memory LRU built in, Mongo/Redis/KV via a tiny adapte
