# @lacspace/webhooks

> 标签: endpoint-routing, event-envelope, exactly-once, github-webhook, hmac, idempotency, retry, shopify-webhook, sign-webhook, stripe-webhook, svix-alternative, typescript, verify-webhook, web-crypto, webhook, webhook-delivery, webhook-events, webhook-signature, webhooks

## 简介

The webhook toolkit for both directions — sign & deliver outgoing webhooks with retries, and verify incoming ones (timing-safe, replay-protected) with Stripe / GitHub / Shopify presets. Plus event ids & idempotency. One internal dependency (@lacspace/cryp
