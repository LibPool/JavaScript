# @lacspace/consent

> 标签: ccpa, consent, consent-management, cookie-banner, cookie-consent, cookies, framework-agnostic, gdpr, isomorphic, privacy, react, script-gating, typescript, zero-dependency

## 简介

GDPR-friendly cookie consent with zero dependencies — a framework-agnostic store (analytics/marketing/preferences), a drop-in vanilla banner, and a React binding (<ConsentBanner/> + useConsent). Persists to a cookie so your server can gate too, plus whenC
