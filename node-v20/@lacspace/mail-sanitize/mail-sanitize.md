# @lacspace/mail-sanitize

> 标签: cid, css-scope, edge, email, html, html-to-text, isomorphic, linkify, remote-images, sanitize, sanitizer, tracking-pixel, typescript, webmail, xss

## 简介

Isomorphic email-HTML sanitizer for webmail. Allowlist-based tags and attributes, URL scheme filtering (entity/tab/case tricks decoded), remote images blocked behind placeholders with data-lac-src for a "Load images" button, tracking pixels removed and li
