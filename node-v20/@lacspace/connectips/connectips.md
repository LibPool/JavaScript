# @lacspace/connectips

> 标签: connect-ips, connectips, edge, isomorphic, nchl, nepal, paisa, payment, payment-gateway, payment-validation, rsa, rsa-sha256, signature-verification, transaction-validation, typescript, validate-txn, web-crypto

## 简介

Connect IPS (Nepal) merchant integration over Web Crypto — sign the redirect transaction token with your RSA private key and validate transactions server-to-server. Zero-dep, isomorphic (Node, edge, browser).
