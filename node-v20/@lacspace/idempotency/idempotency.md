# @lacspace/idempotency

> 标签: concurrency, dedupe, deduplication, exactly-once, idempotency, idempotency-key, idempotent, in-flight-lock, isomorphic, payment-safety, request-fingerprint, response-replay, retry-safe, stripe-idempotency, sweep, ttl, typescript, webhook-idempotency

## 简介

Make any operation exactly-once with an idempotency key — replay stored results on retries, safe under concurrency, with optional request fingerprinting. Framework-agnostic, pluggable store, zero-dependency, isomorphic.
