# @lacspace/vector

> 标签: ai, cosine-similarity, embeddings, in-memory, isomorphic, knn, llm, nearest-neighbor, rag, retrieval, semantic-search, similarity-search, typescript, vector, vector-database, vector-store, vectordb, zero-dependency

## 简介

A tiny, zero-dependency in-memory vector store for RAG and semantic search — upsert records, brute-force k-nearest-neighbour query with cosine / dot / euclidean metrics, metadata filtering, and plain-JSON persistence. Isomorphic and fully typed.
