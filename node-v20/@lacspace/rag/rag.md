# @lacspace/rag

> 标签: ai, chunking, context-assembly, embeddings, gen-ai, index, isomorphic, keyless, llm, prompt-context, prompt-engineering, rag, retrieval, retrieval-augmented-generation, semantic-search, typescript, vector-database, vector-search, zero-dependency

## 简介

The zero-dependency glue for a Retrieval-Augmented Generation pipeline — index documents and retrieve + assemble prompt context by composing an injected embedder, vector store and splitter. Keyless, isomorphic and fully typed.
