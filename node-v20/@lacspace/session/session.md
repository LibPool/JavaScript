# @lacspace/session

> 标签: aes-gcm, auth, cookie, cookie-session, csrf, encrypted-cookie, iron-session, isomorphic, oauth-state, session, typescript, web-crypto, zero-dependency

## 简介

Encrypted, signed cookie sessions for any runtime — AES-256-GCM over Web Crypto, secret rotation, rolling and absolute expiry, __Host- cookie rules, a 10-minute OAuth state store and double-submit CSRF tokens. Works with Web Request/Response, Node http, N
