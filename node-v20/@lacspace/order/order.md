# @lacspace/order

> 标签: audit-trail, checkout, ecommerce, fulfillment, headless, immutable, isomorphic, minor-units, order, order-management, order-status, order-timeline, partial-fulfillment, refund-tracking, refunds, state-machine, typescript

## 简介

Headless order-lifecycle engine — an immutable order model with a state machine, order-number generation, line-item price snapshotting and timestamped status history. Integer minor units, zero-dependency, isomorphic (Node, edge, browser).
