# @lacspace/fonepay

> 标签: dynamic-qr, edge, fonepay, hmac, hmac-sha512, isomorphic, nepal, payment, payment-gateway, prn, qr, request-to-pay, sandbox, typescript, validation, verify, web-crypto

## 简介

Fonepay (Nepal) merchant redirect / Request-To-Pay over Web Crypto — HMAC-SHA512 sign the request DV and verify the response DV. Zero-dep, isomorphic (Node, edge, browser).
