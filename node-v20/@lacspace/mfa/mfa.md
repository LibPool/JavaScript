# @lacspace/mfa

> 标签: 2fa, 3fa, aal, auth-flow, backup-codes, enrollment, lockout, mfa, multi-factor, passkey, rate-limit, recovery-codes, remember-device, security, step-up, step-up-auth, step-up-authentication, totp, trusted-device, two-factor-authentication, typescript, webauthn

## 简介

Orchestrate multi-factor auth — combine password + TOTP + passkeys into 2FA/3FA step-up flows with NIST assurance levels (AAL). Zero-dependency (bar @lacspace/otp), isomorphic.
