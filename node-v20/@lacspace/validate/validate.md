# @lacspace/validate

> 标签: brand, coerce, discriminated-union, form-validation, intersection, isomorphic, native-enum, parse, recursive-schema, refine, runtime-validation, safeparse, schema, transform, tuple, type-inference, type-safe, typescript, validation, validator, zero-dependency, zod-alternative, zod-lite

## 简介

A tiny, typed schema validator — the ergonomics of zod (parse/safeParse, object/array/enum/union, coercion, type inference) in a zero-dependency, isomorphic package. Great for forms, API bodies, env and query strings.
