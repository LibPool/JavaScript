# @lacspace/humanize

> 标签: compact-number, duration, format-bytes, format-number, humanize, initials, isomorphic, metric-prefix, number-to-words, ordinal, pluralize, pretty-bytes, relative-time, roman-numerals, si-units, slugify, time-ago, truncate-middle, typescript, zero-dependency

## 简介

Turn machine values into human-readable text — bytes, durations, relative time, ordinals, plurals, compact numbers, grammatical lists, number-to-words, Roman numerals and SI units. Zero-dependency, isomorphic.
