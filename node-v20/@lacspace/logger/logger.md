# @lacspace/logger

> 标签: browser-logger, child-logger, isomorphic, json-logger, leveled-logging, log-levels, logger, logging, observability, pino-alternative, redact, redaction, structured-logging, structured-logs, transports, typescript, winston-alternative, zero-dependency

## 简介

A tiny structured logger for Node and the browser — leveled JSON logging, child loggers, field redaction and pluggable transports (JSON, pretty, in-memory). Sub-level logs cost nothing. Zero-dependency, isomorphic, TypeScript-first.
