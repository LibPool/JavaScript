# @lacspace/id

> 标签: base58, base62, csprng, cuid2, custom-alphabet, decode-time, id-generator, isomorphic, nanoid, prefixed-id, short-id, snowflake, snowflake-id, sortable-id, time-sortable, typescript, ulid, unique-id, uuid, uuid-v7, uuidv4, uuidv7, web-crypto, zero-dependency

## 简介

Every ID kind you need — UUID v4/v7, ULID, cuid2, Snowflake, Nano-ID, base62/base58 and Stripe-style prefixed ids. Custom alphabets with unbiased sampling, time-sortable + decodeTime. Cryptographically random (Web Crypto), zero-dependency, isomorphic.
