# @sonatel-os/json-sculpt

> 标签: data parser, data sculpting, data transformation, javascript, js utility, json, json mapping, json template, lpix-11, nested path resolution, object mapping, object transformation, recursion, sonatel, type casting, typescript

## 简介

Declarative JSON transformation engine that reshapes and maps complex data structures with nested resolution, type casting, recursion, and more. Ideal for APIs, SDKs, and frontend shaping.
