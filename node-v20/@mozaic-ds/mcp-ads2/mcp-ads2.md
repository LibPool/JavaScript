# @mozaic-ds/mcp-ads2

> 标签: ads2, design-system, mcp, model-context-protocol, mozaic

## 简介

MCP server exposing read-only Mozaic ADS2 Vue design-system documentation (components, icons, styles) and the screenshot-to-code workflow to AI agents.
