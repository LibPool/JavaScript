# @mozaic-ds/designer-kit

> 标签: adeo, adeo design system, design files, design system, mozaic design system

## 简介

The Mozaic designer-kit contains all the sketch libraries and assets required to enable designers to work with the Mozaic Design System - the Design System of Adeo.
