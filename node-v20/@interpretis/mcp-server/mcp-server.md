## 简介

Interpretis MCP server — safety-gated Meta Ads Marketing API tools for Claude, GPT, Gemini, and any MCP-compatible AI client. Humanized rate-limit timing, quota ceilings, FIFO queueing, exponential backoff, and a confirmation gate on every write.
