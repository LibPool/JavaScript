# tripwire-scan

> 标签: credentials, devsecops, github-action, gitleaks, osv, pre-commit, secret-scanning, secrets, security

## 简介

Finds leaked secrets in code, git history and commits, maps what each unlocks, checks which are live, and revokes them. CLI, pre-commit hook and GitHub Action.
