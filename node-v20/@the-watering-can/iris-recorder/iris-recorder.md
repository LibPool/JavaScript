# @the-watering-can/iris-recorder

> 标签: error-tracking, monitoring, rrweb, self-hosted, session-replay, web-vitals

## 简介

Browser SDK for Iris — self-hosted session replay & frontend monitoring. Records DOM replay (rrweb), errors, network + console breadcrumbs, WebSocket/SSE frames, and Web Vitals to your own Iris server.
