# @snomiao/rgui

> 标签: canvas, canvas2d, d3, d3-zoom, dataflow, framework-agnostic, graph-editor, graph-visualization, grid, infinite-canvas, level-of-detail, lod, node-editor, node-graph, pan-zoom, readable-grid, semantic-zoom, snap-to-grid, webgpu

## 简介

Framework-agnostic readable-grid UI library — screen-adaptive grid, snap-everything, semantic-zoom LOD node graphs. Canvas 2D now, WebGPU next.
