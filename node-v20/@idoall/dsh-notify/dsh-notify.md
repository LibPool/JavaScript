# @idoall/dsh-notify

> 标签: cordis, deepseek, deepseek-harness, dsh, dsh-plugin, harness, notifications, plugin, toast, web

## 简介

DSH web plugin: in-page task notifications for DeepSeek Harness — enhanced or soft status toasts, a collapsible top-right stack, answer buttons, background-tab attention, and a WebAudio cue that also plays while the page is hidden. Live delivery only: no
