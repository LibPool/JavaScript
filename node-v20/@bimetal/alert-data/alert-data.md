# @bimetal/alert-data

> 标签: alerting, event-sourcing, headless, idempotent, notifications

## 简介

Event-sourced alert lifecycle aggregate: scheduled → requested → dispatched/failed/cancelled, keyed by a deterministic triggerKey so replay never re-delivers. Built on @bimetal/event-sourcing.
