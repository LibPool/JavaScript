# @bimetal/devtools-react

> 标签: devtools, event-inspector, event-sourcing, headless, react

## 简介

React UI for the BIMETAL event-debugger: EventInspectorPanel + DevtoolsRegistryProvider/useDevtoolsRegistry. Depends only on `react` and `@bimetal/devtools` — no event-sourcing, broker, or domain imports.
