# @bimetal/forms-vanilla-components

> 标签: components, form-builder, forms, validation, vanilla

## 简介

Zero-framework form builder + renderer: mountFormBuilder() edits the schema aggregate, mountFormRenderer() fills it live and composes mountPicker() per select field. Plain-DOM peer of the forms-{react,vue,svelte,angular}-components packages on the canonic
