# @jupyter-kit/executor-pyodide

> 标签: in-browser, ipynb, jupyter, jupyter-kit, notebook, pyodide, python, renderer, wasm

## 简介

In-browser Python executor for @jupyter-kit. Loads Pyodide from a CDN (the runtime is ~10MB WASM, so bundling isn't practical).

## 官网

- 官网：https://jupyter-kit.walkframe.com/demos/pyodide/
- 源码仓库：git+https://github.com/walkframe/jupyter-kit.git
- npm 页面：https://www.npmjs.com/package/@jupyter-kit/executor-pyodide
