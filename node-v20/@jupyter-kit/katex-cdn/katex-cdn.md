# @jupyter-kit/katex-cdn

> 标签: cdn, ipynb, jupyter, jupyter-kit, katex, latex, math, notebook, renderer

## 简介

KaTeX via CDN loader for @jupyter-kit/core. Tiny bundle; KaTeX auto-render runs in the browser.

- 官网：https://jupyter-kit.walkframe.com/reference/math-plugins/
