# @cbrew/vue

> 标签: feedback, feedback-widget, nuxt, user-feedback, vue, widget

## 简介

Context Brew feedback FAB for Vue 3 / Nuxt 3 — a tiny wrapper that mounts the hosted script-tag embed. React is bundled inside the embed; your app stays 100% Vue.
