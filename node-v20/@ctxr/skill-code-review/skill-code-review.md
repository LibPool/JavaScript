# @ctxr/skill-code-review

> 标签: agent-skills, agents, agents-md, agentskills, ai, claude-code, code-review, codex, skill

## 简介

Agent Skills code-review harness (Claude Code, Codex CLI): wiki-organised corpus of ~476 specialist reviewer leaves selected by semantic tree descent against the diff, aggregated into an 8-gate GO/NO-GO release verdict.
