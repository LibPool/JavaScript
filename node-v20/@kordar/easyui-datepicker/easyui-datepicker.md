# @kordar/easyui-datepicker

> 标签: JavaScript

## 简介

基于 `flatpickr` 与 `rc-easyui` 的日期选择封装，提供一个可插拔的 `TextBox` 日期输入组件，以及轻量的 `flatpickr` 初始化/销毁工具方法。
