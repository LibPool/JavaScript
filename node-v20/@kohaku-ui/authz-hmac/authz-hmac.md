# @kohaku-ui/authz-hmac

> 标签: JavaScript

## 简介

HMAC-SHA256 capability tokens for kohaku's AuthzPort: an on-behalf-of token whose payload is transparent (base64url(payload).base64url(hmac)), suitable as the default issuer for a single host and as the capability signer behind a JWT/OIDC principal resolv
