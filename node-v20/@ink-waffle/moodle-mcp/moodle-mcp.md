# @ink-waffle/moodle-mcp

> 标签: lms, mcp, moodle, playwright, webservice

## 简介

MCP server for any Moodle site: reads courses, deadlines, grades, forums and downloads files via the mobile web-service API, with browser-based SSO token minting
