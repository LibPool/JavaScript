> 标签: ai, boilerplate, cli, codegen, create-rag-app, embeddings, generator, llm, rag, retrieval-augmented-generation, scaffold, starter, typescript, vector-search

## 简介

Scaffold a production RAG app in TypeScript. `npm create @ragfoundry` or the `rag` command. Generates typed config and pipeline code you own.
