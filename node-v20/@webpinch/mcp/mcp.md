# @webpinch/mcp

> 标签: claude, cursor, mcp, model-context-protocol, webpinch

## 简介

MCP server for Webpinch — exposes tasks, projects, site audits, and stats to Claude Code, Cursor, and other MCP clients (stdio + hosted HTTP).
