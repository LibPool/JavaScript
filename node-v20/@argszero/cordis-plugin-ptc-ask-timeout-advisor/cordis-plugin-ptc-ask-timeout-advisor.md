# @argszero/cordis-plugin-ptc-ask-timeout-advisor

> 标签: approval, ask_user_question, cordis, deadline, deepseek-harness, dsh, guard, plugin, ptc, run_code, timeout

## 简介

Tells a PTC program's next request what its own deadline hid: that the human question it was waiting on was aborted, not answered. Discussion #8368: in PTC mode the model can only call `run_code`, and a program that asks through `tools.ask_user_question(.
