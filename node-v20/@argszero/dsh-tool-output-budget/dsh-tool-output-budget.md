# @argszero/dsh-tool-output-budget

> 标签: agent-pre-step, compaction-prune, context-budget, cordis, deepseek-harness, dsh, plugin, session-surface, token-budget, tool-output, tool-result

## 简介

A tool result enters the model's history exactly as the tool printed it, and stays there for every later request of the session: one 3 MB build log, one read of a generated bundle, one recursive grep becomes context replayed on every turn of every subagen
