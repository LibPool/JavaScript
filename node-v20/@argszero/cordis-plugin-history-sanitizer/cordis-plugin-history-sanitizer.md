# @argszero/cordis-plugin-history-sanitizer

> 标签: cordis, deepseek-harness, dsh, history, llm, messages, plugin, sanitizer, unrecoverable-session

## 简介

Request-level history sanitizer for dsh: a session whose durable log holds content the target wire protocol cannot represent is permanently unusable, because the offending block sits in the log and no UI can edit it. Mounted on the public llm/stream water
