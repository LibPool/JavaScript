# @argszero/cordis-plugin-team-delegation-guard

> 标签: agent-teams, cordis, deepseek-harness, delegation, dsh, guard, plugin, preset, restrict, subagent, team, tools

## 简介

Withdraws the legacy delegation tools (subagent/subagent_fork) from every agent the Agent Teams runtime owns, so a Team session's delegation goes through the Team tools alone. On Web/Desktop the Agent Teams bundle's own `disabled` patches hit host-plane r
