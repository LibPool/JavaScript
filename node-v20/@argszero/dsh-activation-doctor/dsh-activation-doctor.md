# @argszero/dsh-activation-doctor

> 标签: activation, cordis, deepseek-harness, diagnostics, dsh, duplicate-tool-name, loader, observability, plugin, plugin-failure

## 简介

Writes the activation report the harness already composes but never files. When a third-party plugin fails to activate — most often because a tool or prompt-section name it registers is already taken — the fiber that threw is unloaded whole, so every tool
