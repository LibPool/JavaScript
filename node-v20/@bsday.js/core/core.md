# @bsday.js/core

## 简介

Ultra-fast, zero-dependency Day.js-compatible dual-calendar (Bikram Sambat BS ↔ Gregorian AD) SDK with Nepali fiscal year, KYC age, and Panchang engine for JavaScript and TypeScript.
