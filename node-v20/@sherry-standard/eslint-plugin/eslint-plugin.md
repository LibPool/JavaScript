# @sherry-standard/eslint-plugin

> 标签: eslint, eslint-plugin, prettier, sherry-standard

## 简介

用于在项目的 ESLint 中集成 ESLint 规则集合，包含了 JS、TS、Vue+JS、Vue+TS、React 等常用的 ESLint 配置。
