# @xinliang/figma

> 标签: JavaScript

## 简介

这个npm包旨在帮助开发者从Figma设计文件中下载图片。它支持通过Figma API下载特定类型节点的图片，并允许用户通过命令行参数、配置文件或`package.json`中的配置来指定下载选项。
