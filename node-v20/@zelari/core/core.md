# @zelari/core

> 标签: agent, ai, anathema, coding, council, llm, zelari

## 简介

Zelari Code core library — provider-neutral agent loop (AgentHarness), multi-agent council orchestration, and built-in skills. Used by the zelari-code CLI; consumable by other agent frontends.
