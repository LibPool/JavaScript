# @apsis-io/magicseam

> 标签: magic-seam, mtls, periapsis, quic, rpc

## 简介

Magic-seam (ADR-0028) provider/consumer for a genuinely non-WASM TypeScript program (Node.js/Bun) - the revived MSK1 protocol (magicseam.ts) or the mTLS QUIC transport (quic.ts, ADR-0043), mirroring go/magicseam. NOT for use inside a dwarf/WASM component
