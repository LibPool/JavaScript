# @lazyants/transkribus-mcp-server

> 标签: api, handwritten-text-recognition, htr, mcp, model-context-protocol, ocr, transkribus

## 简介

MCP server for the Transkribus REST API — manage collections, documents, recognition, models, and more, plus the Metagrapho Processing API. 304 tools across 23 resource domains.
