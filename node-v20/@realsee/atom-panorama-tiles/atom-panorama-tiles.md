# @realsee/atom-panorama-tiles

> 标签: JavaScript

## 简介

Shared bounded equirectangular panorama loader for Workshop and NextVR. Uses the host Three.js r117 renderer and camera. No input handlers, business requests, server transforms, or animation loop are created by the package.
