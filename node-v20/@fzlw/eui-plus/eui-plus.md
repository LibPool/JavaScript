# @fzlw/eui-plus

> 标签: element-plus, json form, json table, vue

## 简介

1. 基于 `vue3` + `element-plus` + `typescript` 1. 减少 template 代码和 setup 代码，配置 json 数据即可完成常见交互 1. 较为完全的 TS 推导 1. 为支持 jsx 写法，推荐安装 `@vitejs/plugin-vue-jsx`
