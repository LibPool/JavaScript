# @sparkelf/dsh-patch-image-offload-hoist-replay

> 标签: JavaScript

## 简介

Read sessions whose image/offload decisions were recorded against hoisted image positions: replay leniently when the log carries image/hoist rows, and fold detached reads with the mounted message projections
