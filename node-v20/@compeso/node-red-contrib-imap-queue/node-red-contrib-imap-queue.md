# @compeso/node-red-contrib-imap-queue

> 标签: ack, at-least-once, email, imap, mail, node-red, queue

## 简介

Stable Node-RED IMAP queue nodes with externally triggered bounded front-window fetch, at-least-once ACK deletion, diagnostics, timings, and comprehensive help documentation.
