# @blokjs/trigger-pubsub

> 标签: JavaScript

## 简介

Pub/Sub trigger for Blok workflows — supports NATS (Core + JetStream), Redis Streams, Kafka, GCP Pub/Sub, AWS SNS+SQS, and Azure Service Bus.
