# @blokjs/session

> 标签: blok, cookie, neon, postgres, redis, session, sqlite

## 简介

Signed, HttpOnly server-side sessions for Blok — pluggable store (memory / sqlite / postgres / redis), session.get/set/forget/regenerate nodes, and the inertia.session middleware.
