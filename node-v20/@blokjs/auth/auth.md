# @blokjs/auth

> 标签: auth, blok, inertia, login, password, starter-kit

## 简介

Blok's auth starter kit — scrypt password hashing, login/register/logout/reset nodes, login throttling, and a UserStore interface with SQLite and Neon/Postgres backends. No ORM.
