# n8n-nodes-chh-imap

> 标签: imap, n8n, n8n-community-node-package, uid-move, uidvalidity

## 简介

Minimal IMAP node for n8n: UIDVALIDITY-checked UID operations, native UID MOVE with COPYUID, partial body sections, a total deadline per operation.
