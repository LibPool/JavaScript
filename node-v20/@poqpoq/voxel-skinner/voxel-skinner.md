# @poqpoq/voxel-skinner

> 标签: 3d, animation, auto-skinning, babylonjs, bone-heat, character-rigging, geodesic, rigging, skeleton, skin-weights, skinning, threejs, voxel, webgl

## 简介

Voxel geodesic skinning weights for 3D character meshes. The first standalone browser-native library for automatic skin weight computation using volumetric geodesic distance.
