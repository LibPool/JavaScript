# @yizhiyanhua-ai/fireworks-tech-graph

> 标签: architecture, claude-code, diagram, er-diagram, flowchart, sequence-diagram, skill, svg, uml, visualization

## 简介

Generate production-quality SVG technical diagrams (architecture, flowchart, UML, ER, sequence, etc.) with 7 built-in styles. Export as SVG+PNG via rsvg-convert.
