# @console-visualization/core

> 标签: JavaScript

## 简介

Эта библиотека предоставляет простой способ визуализации консольных выводов на веб-странице.  Она позволяет стилизовать вывод в зависимости от типа команды (логи, информация, ошибки и т.д.).
