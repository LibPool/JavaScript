# @ngx-tonysamperi/native-date-adapter

> 标签: JavaScript

## 简介

Material date adapter for Angular 13+ (w/ Material) applications. Uses the native Date to provide values for datepickers. @angular/material is required as dependency. Plus this offers some utils you can use to get current date and other useful stuff.
