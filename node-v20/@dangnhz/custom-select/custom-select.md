# @dangnhz/custom-select

> 标签: a11y, accessible, checkbox, component, custom-select, dropdown, form, hierarchical, multi-select, multiselect, nested-options, radio, select, single-select, typescript, ui, vanilla-js, wcag, zero-dependencies

## 简介

A lightweight, accessible TypeScript library for custom single and multi-select dropdowns that transforms native HTML select elements into modern, customizable interfaces
