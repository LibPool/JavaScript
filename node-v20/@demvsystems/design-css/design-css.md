# @demvsystems/design-css

> 标签: JavaScript

## 简介

The CSS Framework for building sites (also used by the components). Internally we use the utility-first framework [Tailwind CSS](https://tailwindcss.com/) which uses PostCSS for compilation (no SASS, LESS, ...).
