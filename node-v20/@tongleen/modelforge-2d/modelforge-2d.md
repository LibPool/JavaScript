# @tongleen/modelforge-2d

> 标签: 2d, semiconductor, sentaurus, silvaco, simulation, tcad

## 简介

TypeScript 库，用于生成 TCAD 模型生成脚本，支持多后端（SILVACO / Sentaurus）与 SVG 预览
