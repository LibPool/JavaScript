# @compounding/logger

> 标签: analytics, bot-detection, event-tracking, logging, react-native, retry-queue, session, telemetry

## 简介

Event logging SDK for React Native and web: session/client id lifecycle, a persistent retry queue that survives restarts, and bot filtering on by default.
