# @engramprotocol/mcp-server

> 标签: JavaScript

## 简介

MCP wrapper for the EML HTTP API — exposes the Engram Protocol as MCP tools for Claude Code and other MCP clients. Includes setup-mode for one-shot install/update/uninstall.
