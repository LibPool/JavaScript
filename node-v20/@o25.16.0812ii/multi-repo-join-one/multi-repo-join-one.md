# @o25.16.0812ii/multi-repo-join-one

> 标签: azure-repos, firebase, git, github, mirror, monorepo, rtdb, sync, webhook

## 简介

Node.js service that listens to Firebase RTDB (no HTTP server, no webhook verify), consumes GitHub/Azure push events FIFO, shallow-clones by SHA and fans them out into one or many target repos with original commit metadata.
