> 标签: ai, ai-connector, ai-integration, anthropic, atlassian, claude, cli, external-tools, issue-tracking, jira, llm, mcp, mcp-inspector, mcp-server, model-context-protocol, project-management, resources, server, tooling, tools, typescript

## 简介

Enterpret fork of @aashari/mcp-server-atlassian-jira adding an ATLASSIAN_OAUTH_BEARER mode (3LO bearer + cloudId discovery) so a Nango-supplied access token plugs straight into Jira Cloud REST. Used by the Orbit/wisdom-v2 jira_mcp bring_token connector.
