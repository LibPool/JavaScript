# @telegraf-hardened/fetch

> 标签: fetch, hardened, http-proxy, proxy, socks, socks5, telegraf, undici

## 简介

Native fetch wrapper for Node.js 18+ with built-in SOCKS5 and HTTP/HTTPS proxy support via undici dispatchers.
