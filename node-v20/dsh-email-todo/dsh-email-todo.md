# dsh-email-todo

> 标签: deepseek-harness, dsh, dsh-plugin, email, todo

## 简介

邮件待办：读取 dsh-email 的邮件内容，用 LLM 把邮件里的工作事项提取成可管理的待办清单，并在 Web 客户端右侧 Sidebar 提供一个「待办」tab。
