# @pattern-js/mod-agents-openai

> 标签: JavaScript

## 简介

OpenAI Agents SDK provider for Pattern: agent/run ops that reify @pattern-js/mod-agents descriptors into SDK agents — workflow tools as linked sub-runs, guardrails, MCP servers, streamed turn events, history threading, compaction, HITL approvals, realtime
