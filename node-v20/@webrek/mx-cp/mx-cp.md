# @webrek/mx-cp

> 标签: asentamientos, codigo-postal, codigos-postales, colonias, cp, inegi, mexico, sepomex, zip-code

## 简介

Códigos postales de México (SEPOMEX) → estado, municipio (CVEGEO de INEGI) y colonias. Carga por prefijo bajo demanda, sin API key.
