# @framecast/rt

> 标签: frame-interpolation, machine-learning, real-time, rife, video, webgpu, wgsl

## 简介

Real-time neural frame interpolation on raw WebGPU: hand-written WGSL kernels, 2.9 MB model, ~3 ms per generated frame on a mid-range GPU. The runtime behind the Framecast extension.
