# @dephub/command

> 标签: arguments, cli, command, flags, help, inline-options, node, options, parser, subcommands, type-safe, typescript, variadic, version

## 简介

A type-safe CLI command builder for Node.js, enabling easy creation of commands with arguments, options, subcommands, and handlers.
