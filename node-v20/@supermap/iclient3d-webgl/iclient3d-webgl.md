# @supermap/iclient3d-webgl

> 标签: JavaScript

## 简介

@supermap/iclient3d-webgl（SuperMap iClient 3D for Cesium） 一款在服务式 GIS 架构体系中， 无任何插件，跨浏览器的客户端产品。它基于Cesium开源框架，面向 HTML 5 的三维应用开发，快速构建内容丰富、响应迅速、体验流畅的三维真空间应用。
