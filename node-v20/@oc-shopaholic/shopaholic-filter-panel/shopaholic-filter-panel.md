# @oc-shopaholic/shopaholic-filter-panel

> 标签: filter, octobercms, shopaholic

## 简介

Package adds helper methods for integration with [Filter for Shopaholic](https://octobercms.com/plugin/lovata-filtershopaholic) and [Shopaholic](https://octobercms.com/plugin/lovata-shopaholic) plugins.
