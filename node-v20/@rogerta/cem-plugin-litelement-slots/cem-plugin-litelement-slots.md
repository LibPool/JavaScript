# @rogerta/cem-plugin-litelement-slots

> 标签: custom-elements, custom-elements-json, custom-elements-manifest, customelements, customelementsjson, customelementsmanifest, lit, litelement, webcomponents

## 简介

A plugin for @custom-elements-manifest/analyzer that maps `<slot>` elements in web components to the 'slots' property of the Custom Elements Manifests without requiring JSDoc tags.
