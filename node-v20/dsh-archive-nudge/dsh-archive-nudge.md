# dsh-archive-nudge

> 标签: archive, cordis, deepseek-harness, dsh, dsh-plugin, notification, nudge, plugin, session, sidebar

## 简介

DeepSeek Harness plugin: a small archive-box icon next to sidebar session titles marks sessions that are worth archiving (idle too long, or the agent says the work is done). Reminds only, never archives for you.
