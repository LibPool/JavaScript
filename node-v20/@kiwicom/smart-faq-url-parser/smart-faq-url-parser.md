# @kiwicom/smart-faq-url-parser

> 标签: JavaScript

## 简介

Convert `@kiwicom/smart-faq`'s `<iframe>` URLs into `@kiwicom/search`, `@kiwicom/mmb` and `@kiwicom/account` URLs and vice-versa
