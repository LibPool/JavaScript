# @thatapicompany/overture-maps-mcp

> 标签: claude, geospatial, gis, llm, mcp, modelcontextprotocol, overture, overture-maps, places, poi

## 简介

MCP server for the Overture Maps API — query places (POIs), buildings and administrative divisions from Overture Maps data inside Claude and other LLM tools.

## 官网

- 官网：https://www.overturemapsapi.com
- 源码仓库：git+https://github.com/thatapicompany/overture-maps-mcp.git
- npm 页面：https://www.npmjs.com/package/@thatapicompany/overture-maps-mcp
