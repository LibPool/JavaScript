# @angelmsger/jira-cli

> 标签: agent, claude, cli, issues, jira, jql, time-tracking, worklog

## 简介

Drive Jira issue-tracking workflows from the command line, built for coding agents: read and search issues via JQL, create/edit/assign/transition them, manage comments, and log work across Cloud and Data Center.
