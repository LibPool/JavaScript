# @angelmsger/prometheus-cli

> 标签: agent, alerting, claude, cli, metrics, monitoring, observability, prometheus, promql, timeseries

## 简介

Query Prometheus from the command line for coding agents: PromQL instant and range queries, metric/label/series discovery, scrape targets, rules and alerts, with structured JSON output.
