# @mulmobridge/relay

> 标签: cloudflare-workers, mulmobridge, offline-queue, relay, webhook, websocket

## 简介

Cloudflare Workers relay for MulmoBridge — receives webhooks, queues messages, forwards via WebSocket to MulmoClaude
