# @adev-org/adev-cli

> 标签: adev, agentic-development, claude-code, cli, context-engineering, opencode, plugin

## 简介

CLI for the Agentic Development Framework — installs adev into Claude Code, OpenCode, and other AI coding assistants. Scaffolds .context-index/ with constitution, manifests, and templates.
