# @atourin/ds

> 标签: JavaScript

## 简介

Design system Atourin lintas framework: token desain, CSS chrome (navbar & footer), data tautan, dan ikon. Dipakai bersama oleh marketplace-v3 (Nuxt) dan directory-app (Next).
