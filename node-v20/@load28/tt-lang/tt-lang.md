# @load28/tt-lang

> 标签: compiler, enum, match, pattern-matching, preprocessor, tt, typescript

## 简介

tt — a tiny TypeScript preprocessor adding Rust-style enums, match expressions, try, let-else, if let and the pipeline operator. Installs the ttc compiler.
