# @gustkit/react-native

> 标签: JavaScript

## 简介

GustKit for React Native — Skia color field & particles, hooks, and controls; <GustKitMap> for Mapbox on the optional ./mapbox subpath, <GustKitOverlay> for BYO maps (ADR-016). Data/decoding live in @gustkit/client.
