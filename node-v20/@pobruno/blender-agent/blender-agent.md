# @pobruno/blender-agent

> 标签: 3d, ai-agent, animation, blender, bpy, claude, copilot, cursor, fbx, gltf, mcp, model-context-protocol, rigging, ue5

## 简介

MCP server giving AI agents complete deterministic control of Blender 4.2 LTS+ (modeling, rigging, animation, materials, shader/geometry nodes, rendering, granular import/export).
