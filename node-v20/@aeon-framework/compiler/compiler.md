# @aeon-framework/compiler

> 标签: JavaScript

## 简介

Aeon AOT compiler: whole-project static analysis (real binding-kind validation, unused @aeon-framework/* imports, unreachable routes) powering `aeon check`, plus a build-time esbuild plugin (aeonPrecompile) that runs the real template compiler at build ti
