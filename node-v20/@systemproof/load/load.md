# @systemproof/load

> 标签: JavaScript

## 简介

Burst/load plane for the QA harness: the k6 protocol-level script wrapper, the `kind: burst` executor (N parallel scenario instances via the replay driver), and deterministic seed capture/replay (`qa load replay <run>` re-executes with identical RNG/data/
