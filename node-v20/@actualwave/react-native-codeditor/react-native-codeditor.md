# @actualwave/react-native-codeditor

> 标签: android, code-editor, codemirror, codemirror6, editor, expo, ios, react-native, webview

## 简介

CodeMirror 6 code editor for React Native, embedded in a WebView with a full bidirectional RPC bridge. Offline, no CDN required.
