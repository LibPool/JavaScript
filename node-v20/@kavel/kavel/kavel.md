# @kavel/kavel

> 标签: ai, image-editing, image-generation, image-to-image, kavel, no-api-key, sdk, text-to-image

## 简介

Generate and edit images from JavaScript and TypeScript with no API key, no account and no card. Zero dependencies; Node 18+, Bun, Deno and edge runtimes.
