# @lhx-kit/renderer

> 标签: config-driven, json-schema, lhx-kit, low-code, react, renderer, vue3, zod

## 简介

JSON config-driven renderer with Vue3 and React bindings. Walker / merge / variant / CSP-safe expression eval + lazy zod validation.
