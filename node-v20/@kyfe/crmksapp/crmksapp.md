## 简介

``` npm i @kyfe/crmksapp -g ``` ##### 2、创建项目 格式: ``` crmksapp init <project-name> ``` ``` crmksapp init demo ``` ##### 3、安装运行依赖 ``` cd demo npm install ``` ##### 4、运行 ``` npm run stg ```
