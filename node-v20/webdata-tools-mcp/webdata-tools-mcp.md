# webdata-tools-mcp

> 标签: apify, exhibitors, google-news, hiring-signals, jobs, lead-generation, mcp, model-context-protocol, reviews, trade-shows, trustpilot, web-scraping

## 简介

MCP server for AI agents: job postings, hiring signals, Google News, Trustpilot and app reviews, Reddit mentions, website contacts, German real estate, Shopify products and trade-show exhibitor lists. Runs ready-made Apify Actors with your own Apify token
