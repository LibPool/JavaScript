# @diorray/vue-auth

> 标签: auth, authentication, json, jwt, plugin, token, vue, vue.js, web

## 简介

Vue.js token based authentication plugin. Supports simple token based and Json Web Tokens (JWT) authentication. Forked from websanova/vue-auth to implement Quasar Framework support
