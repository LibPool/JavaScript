# @uveysservetoglu/kobil-tms

> 标签: kobil, oauth2, tms, transaction-signing

## 简介

KOBIL TMS (transaction signing) client for Node.js: start a signing request, poll its status and fetch the signed result, with automatic OAuth token management.
