# @zhuxixi/pi-time-inject

> 标签: date, inject, pi, pi-extension, pi-package, time, timestamp

## 简介

Time injection for pi: stamps every user message with the real current time, so third-party models without a built-in clock (GLM/DeepSeek) never misread dates
