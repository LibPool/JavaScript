# @dekimuhq/anchors-vc

> 标签: JavaScript

## 简介

W3C Verifiable Credential binding for the Anchored Receipts family — carries an anchored ar.* receipt verbatim inside a VC so VC-native consumers (A2A/AP2/MCP) can ingest it, while the embedded envelope stays the cryptographic root of trust. Additive, byt
