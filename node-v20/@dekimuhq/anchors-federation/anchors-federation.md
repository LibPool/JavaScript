# @dekimuhq/anchors-federation

> 标签: anchored-receipts, did-web, discovery, ed25519, federation, interop, issuer-manifest

## 简介

Federated discovery for the Anchored Receipts protocol family. Fetch + verify per-issuer manifests (ar.issuer_manifest.v1), cross-issuer handshake orchestrator, and manifest caching. Pure library, zero runtime npm dependencies beyond @dekimuhq siblings.
