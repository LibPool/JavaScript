# @mnaoumov/obsidian-dataview

> 标签: dataview, obsidian, obsidian-plugin, types, typescript

## 简介

Working TypeScript types for the Obsidian Dataview plugin's API, plus its getAPI / isPluginEnabled helpers: a drop-in replacement for the obsidian-dataview npm package.
