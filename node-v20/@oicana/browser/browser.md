# @oicana/browser

> 标签: browser, client-side, invoice, oicana, pdf, pdf-generation, pdf-generator, report, template, typst, wasm, webassembly

## 简介

Generate typeset PDFs in the browser from Typst templates, compiled to WebAssembly. No server, no headless browser, no data egress.
