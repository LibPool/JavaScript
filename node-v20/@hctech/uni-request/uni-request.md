# @hctech/uni-request

> 标签: JavaScript

## 简介

1. [x] 通过传入config实现配置请求，不用写一大堆代码 2. [x] 每次请求可以自动带上一些数据，比如极智报销里的`user_id` 3. [x] 乐观更新功能, 先响应界面后请求，出现问题再提示 4. [x] 控制是否显示loading 5. [x] 是否显示错误提示 6. [x] 断开网络了会直接提示 7. [x] 超出请求时间会关闭请求或加载
