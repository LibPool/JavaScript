# @yashau/thaana

> 标签: bidi, dhivehi, divehi, fonts, keyboard, maldives, rtl, thaana

## 简介

Everything to make Thaana (Dhivehi) work on the web: phonetic keyboard for any input, legacy A_-font text converter, bidi helpers, font loading and sane CSS defaults.
