# @phcdevworks/spectre-ui

> 标签: class-recipes, css-bundles, css-framework, css-utilities, design-system, design-tokens, phcdevworks, spectre, spectre-ui, tokens, utilities

## 简介

@phcdevworks/spectre-ui is the styling layer of the Spectre system. It transforms Spectre tokens into reusable CSS, utilities, and class recipes for consistent application interfaces.
