# react-virtual-dnd-table

> 标签: dnd-kit, drag-and-drop, react, react-window, row-reorder, tanstack-table, tanstack-virtual, virtualization

## 简介

Drag-to-reorder for virtualized row lists (TanStack Virtual, react-window, ...) where dnd-kit alone can't see off-screen rows.
