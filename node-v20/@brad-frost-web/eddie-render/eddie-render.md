# @brad-frost-web/eddie-render

> 标签: JavaScript

## 简介

Eddie's generative-UI layer: a surface host that renders a2ui-eddie/1.0 messages and SpecStream patches into Eddie DOM, the spec validator it shares with the Brain, and the composer kit that drives a model against a catalog profile.
