# @lumin-io/openclaw-diagnostics

> 标签: ai-agent, llm-monitoring, lumin, observability, openclaw, opentelemetry, tracing

## 简介

Lumin observability + Agent Firewall for OpenClaw — captures prompts, responses, tool I/O, and synchronously enforces firewall policies on every tool call.
