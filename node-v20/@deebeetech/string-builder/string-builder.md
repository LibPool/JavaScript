# @deebeetech/string-builder

> 标签: builder, concat, concatenate, concatenation, javascript, js, string, string builder, string-builder, stringbuilder, ts, typescript

## 简介

A lightweight, chainable string builder for TypeScript and JavaScript. Inspired by builders in C#, Java, and Go — intended for small collections of strings, not extremely large buffers.
