# @rdxkeerthi/kpay

> 标签: bharatpe, cybersecurity, failover, india-payment, kpay, npci, payment-gateway, paytm, phonepe, sse, typescript, upi, upi-qr, zero-commission, zero-mdr

## 简介

Enterprise-grade, zero-commission, cyber-hardened UPI payment gateway for Node.js & TypeScript with in-built Razorpay-style Checkout Gateway UI, direct-to-bank settlement, multi-PSP routing (PhonePe, Paytm, BharatPe), real-time SSE listener, branded QR en
