# @rpxl/eko-web

> 标签: audio, eko, gapless, loudness, normalization, player, replaygain, web-audio

## 简介

EKO's web playback engine: gapless + loudness-normalized Web Audio. The web-grade sibling of the native EKO player. (Not bit-perfect: that's a browser limit, not a goal.)
