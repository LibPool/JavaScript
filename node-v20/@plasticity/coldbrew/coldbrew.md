# @plasticity/coldbrew

> 标签: coldbrew, cpython, emscripten, native, pip, pypi, python, python3, wasm, webassembly

## 简介

Coldbrew is Python compiled into JavaScript using Emscripten. It is the easiest way to run Python code in JavaScript and is developed by Plasticity.
