# @swiveltech/paneo

> 标签: agile, bmad, dashboard, paneo, project-management, sprint, status

## 简介

Paneo — one pane for AI-built delivery. A configurable local dashboard that turns BMAD project files into a live sprint board. One npx command, no backend.
