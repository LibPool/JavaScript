# @alistigo/artifact-storage-explorer

> 标签: alistigo, artifact, claude, debugger, explorer, storage, umd

## 简介

Self-contained UMD bundle — a Claude artifact that lets developers inspect, browse, and delete entries from window.storage (the Claude artifact storage API).
