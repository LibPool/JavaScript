# @beezping/screenshot-storage

> 标签: beezping, cloudflare-images, drizzle, filesystem, libsql, postgres, r2, s3, screenshot, storage, turso, typescript

## 简介

Screenshot storage for Beezping — Cloudflare Images, any S3-compatible bucket, your database (Drizzle: PostgreSQL, Turso/libSQL), the local filesystem, memory, or your own backend
