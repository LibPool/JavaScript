# @node-idempotency/express

> 标签: api-idempotency, at-least-once semantics, data consistency, deduplicate, distributed-systems, duplicate handling, express, express-middleware, http-idempotency, idempotency, idempotency-key, idempotent, node-idempotency, nodejs, request deduplication, request-deduplication, request-idempotency, retry with safety, safe operation

## 简介

Express middleware to provide Race-Condition free idempotency for HTTP requests, preventing unintended duplicate operations.
