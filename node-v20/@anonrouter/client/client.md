# @anonrouter/client

> 标签: anonrouter, api, client, inference, openai-compatible, ticket

## 简介

Thin, dependency-free JS client for AnonRouter's public API (plaintext / TEE / private routes). For content AnonRouter must never see, use @anonrouter/confidential.
