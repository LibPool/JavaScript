# @nest-batch/postgresql

> 标签: batch, drizzle, job-repository, mikro-orm, nestjs, persistence, postgres, postgresql, prisma, typeorm

## 简介

PostgreSQL driver shells for @nest-batch/core. Provides 4 Postgres adapter shells (MikroORM, TypeORM, Drizzle, Prisma) and the shared test-contracts e2e harness against a real Postgres testcontainer.
