# @adiprmx/id-utils

> 标签: bpjs, hijri, indonesia, islamic-finance, javanese-calendar, pph21, qris, tax, thr, weton, zakat

## 简介

Pure-JS utilities for everyday Indonesian calculations: PPh 21 income tax, zakat, THR, Javanese weton calendar, Hijri calendar conversion, electricity tokens, BPJS contributions, loan installments, and more. Zero dependencies.
