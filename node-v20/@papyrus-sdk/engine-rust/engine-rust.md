# @papyrus-sdk/engine-rust

> 标签: document, papyrus, pdf, rust, viewer, wasm

## 简介

Adapter incremental de PDF para o Papyrus. O PDF.js continua renderizando o canvas e a camada visual; o core Rust/WASM assume extração de texto e busca.
