# @papyrus-sdk/engine-native

> 标签: document, papyrus, pdf, pdfium, pdfkit, react-native, sdk, viewer

## 简介

React Native native engine for PDF rendering (PDFKit on iOS, PDFium on Android), plus a WebView runtime for EPUB/TXT/CBZ via `MobileDocumentEngine`.
