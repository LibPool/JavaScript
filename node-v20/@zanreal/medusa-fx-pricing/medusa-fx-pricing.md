# @zanreal/medusa-fx-pricing

> 标签: currency, exchange-rates, fx, medusa, medusa-plugin, medusa-plugin-integration, medusa-plugin-other, medusa-v2, nbp, plugin, poland, pricing

## 简介

Medusa v2 plugin that derives USD/EUR variant prices from a native PLN selling price using the NBP (Polish central bank) table A mid rate, as soon as that price changes and again daily, with a configurable margin and manual-override protection.
