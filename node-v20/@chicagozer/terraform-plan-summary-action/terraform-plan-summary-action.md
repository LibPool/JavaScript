# @chicagozer/terraform-plan-summary-action

> 标签: CI, envoy, summary-report, terraform, terraform-report, terraform-summary, terraform-summary-report, utility

## 简介

Github custom action to parse terraform plan json report and generate summary report to help infrastructure engineers to review and analyze the terraform changes for easy review and approval process
