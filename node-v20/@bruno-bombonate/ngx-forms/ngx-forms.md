# @bruno-bombonate/ngx-forms

> 标签: JavaScript

## 简介

A package containing `ControlTipComponent` and `ControlErrorComponent`, with `FormsService`/`provideNgxForms` to customize error messages and error-visibility rules app-wide. `ControlErrorComponent` works with both Reactive Forms (`AbstractControl`) and S
