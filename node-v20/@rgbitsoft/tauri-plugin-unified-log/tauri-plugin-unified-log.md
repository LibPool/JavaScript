# @rgbitsoft/tauri-plugin-unified-log

> 标签: logging, plugin, rgbitsoft, tauri, unified-log

## 简介

Unified logging bridge for Tauri. Consolidates Frontend (JS) and Backend (Rust) logs into a single terminal with a professional layout.
