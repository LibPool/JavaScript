# @helmmasters/agentvault-mcp

> 标签: agent, agentvault, ai-agent, claude, helm, mcp, model-context-protocol, solana, spending-limits, vault

## 简介

MCP server for Helm (AgentVault) — expose Solana agent-vault operations as Model Context Protocol tools. Read vault/policy state and (with a keypair) propose, approve, and execute guardian-gated transactions.
