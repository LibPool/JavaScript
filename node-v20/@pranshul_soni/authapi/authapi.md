# @pranshul_soni/authapi

> 标签: auth, authentication, express, jwt, oauth, postgresql, typescript

## 简介

Express authentication router with JWT, refresh tokens, PostgreSQL storage, email verification, password reset, rate limiting, and Google OAuth.
