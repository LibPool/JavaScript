# @contextq/cli

> 标签: cli, contextq, installer, mcp

## 简介

One-command installer for ContextQ -- wires the MCP server, the contextq SessionStart boot hook, and the task manifest into a project (or prints a manual connect guide for Desktop/Cowork).
