# @rotwang9000/spqr-code

> 标签: barcode, color, colour, decoder, encoder, qr, qr-code, qrcode, rgb, scanner, spqr

## 简介

Stacked Polychromatic QR: 2-3 ordinary QR codes in the red, green and blue channels of one image, for bigger modules at the same data size. Encoder, decoder and CLI.
