> 标签: a11y, accessibility, caption-with-intention, captions, color-vision-deficiency, colour-blindness, cwi, deaf, hard-of-hearing, subtitles, variable-fonts, wcag, webvtt

## 简介

Reference implementation of the Caption with Intention design system: palettes, acoustic-to-typography mapping, character colour assignment, manifest validation. Zero dependencies.
