# @adamancyzhang/agent-py-debugger

> 标签: agent, breakpoint, cli, debugger, jdwp, pdb, python, remote-debug, step, trace

## 简介

Python breakpoint debugging CLI for AI agents — JDWP-style remote debug: breakpoints, stack, locals, eval and stepping over TCP. PyCharm-like, driven entirely from the command line.
