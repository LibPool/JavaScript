# @adamancyzhang/agent-java-debugger

> 标签: agent, breakpoint, cli, debugger, graphql, java, jdwp, jvm

## 简介

JDWP CLI debugger for remote JVMs — breakpoints, stepping, and in-memory inspection for AI agents (pure Python stdlib; requires Python >= 3.10).
