# @rind-ui/solid

> 标签: a11y, accessibility, components, design-system, headless, headless-ui, solid, solid-js, solidjs, state-machine, ui, wai-aria

## 简介

Accessible headless SolidJS components: behaviour, keyboard, ARIA and state, styled through data-* attributes. Every component ships a test driver.
