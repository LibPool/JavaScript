# @rind-ui/react

> 标签: a11y, accessibility, components, design-system, headless, headless-ui, playwright, react, react-components, state-machine, testing-library, ui, wai-aria

## 简介

Accessible headless React components: behaviour, keyboard, ARIA and state, styled through data-* attributes. Every component ships a test driver.
