# @zero-ai-offline/chat

> 标签: chat, local-ai, local-llm, offline, ollama, sveltekit, zero-ai

## 简介

Offline chatbot made by Zero AI. Powered by local LLMs from Ollama. No API keys required. No data sent to the cloud. Completely free and offline.
