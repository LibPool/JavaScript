# @dayflow/core

> 标签: calendar, day-view, drag-drop, event-calendar, events, month-view, plugin-architecture, preact, schedule, typescript, virtual-scroll, week-view, year-view

## 简介

A flexible and feature-rich calendar engine powered by Preact with drag-and-drop support, multiple views (Day, Week, Month, Year), and plugin architecture
