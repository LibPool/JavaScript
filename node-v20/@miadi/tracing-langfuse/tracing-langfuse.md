# @miadi/tracing-langfuse

> 标签: langfuse, miadi, observability, provider, tracing

## 简介

Langfuse as a Miadi tracing provider: one Langfuse project per domain (ceremony, story, eng) read through <DOMAIN>_LANGFUSE_PUBLIC_KEY, _SECRET_KEY and _BASE_URL, answering the @miadi/tracing provider contract with metadata only. The app consumes @miadi/t
