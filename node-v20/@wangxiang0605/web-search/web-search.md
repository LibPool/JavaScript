# @wangxiang0605/web-search

> 标签: pi, pi-extension, pi-package, search, tool, web-search

## 简介

Pi extension: Provides a `web_search` tool and a `/search` command: uses a configured search API when present, otherwise falls back across multiple engines (Bing / DuckDuckGo / Sogou / 360 / Baidu) with rate-limit cooldowns, retries, caching, and a Python
