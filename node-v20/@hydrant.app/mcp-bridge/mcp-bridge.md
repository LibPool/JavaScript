# @hydrant.app/mcp-bridge

> 标签: JavaScript

## 简介

Protocol-only stdio MCP bridge for the open Hydrant tab. Tool catalogs come from the tab, not this package.

## 官网

- npm 页面：https://www.npmjs.com/package/@hydrant.app/mcp-bridge

- Node 要求：>=20.9.0
