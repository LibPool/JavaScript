# @yoyohan1/vue-treeselect

> 标签: component, control, dropdown, form, input, multiselect, select, tree, treeselect, treeview, ui, vue

## 简介

这个插件是github上riophae分享的 我修改了部分代码放在https://gitee.com/yoyohan1/vue-treeselect，实现了1.单选时 点击非最终子节点时不会关闭下拉框 并且可以设置值 参见Option.vue和treeselectMixin.js
