# eas-simulator-evidence

> 标签: agent, ci, eas, eas-simulator, emulator, evidence, expo, qa, simulator

## 简介

Turn an EAS Simulator run into a static evidence site: verdict, screenshots, action timeline, CPU and memory charts, and the session recording.
