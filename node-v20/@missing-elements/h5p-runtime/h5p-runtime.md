# @missing-elements/h5p-runtime

> 标签: h5p, h5p-core, h5p-offline-player, runtime

## 简介

The H5P core runtime and the frame boot script that @missing-elements/h5p-offline-player loads inside its frame. GPL-3.0, kept apart from the MIT player on purpose.
