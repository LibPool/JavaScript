# @toytoy.dev/chat

> 标签: agent, ai-sdk, chat, convex, react, streaming

## 简介

The chat an app's agent talks in: AI SDK messages in; a transcript, tool steps that fold, streaming answers and a message box out. Over useChat or Convex Agent.
