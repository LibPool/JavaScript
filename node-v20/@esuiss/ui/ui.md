# @esuiss/ui

> 标签: accessibility, base-ui, cli, component-library, components, copy-paste, dark-mode, design-system, expo, jetpack-compose, nextjs, oklch, phosphor-icons, react, react-components, react-native, swiftui, tailwind, tailwindcss, typescript, ui, ui-components, vite

## 简介

Copy-paste React components with a clean, minimal design, built with Tailwind CSS v4 on your choice of three primitive bases. CLI for Next.js and React (Vite), plus React Native, Expo, SwiftUI and Jetpack Compose components.
