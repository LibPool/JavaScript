# @courmap/client

> 标签: anidb, anilist, anime, episode, kitsu, myanimelist, numbering, release-name, sonarr, tmdb, tvdb

## 简介

Courmap client: translate anime episodes between AniDB, AniList, MAL, Kitsu, TVDB, TMDB, IMDb and absolute numbering, and resolve release names, offline or remote
