# dolljs

> 标签: 3d, animation-retargeting, avatar, avatar-framework, fbx, humanoid, mixamo, threejs, vrm, vrm0, vrm1, vroid

## 简介

Zero-dependency JavaScript framework for VRM avatars, humanoid animation retargeting, expressions, and reusable avatar presets.
