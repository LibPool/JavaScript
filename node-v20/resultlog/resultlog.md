# resultlog

> 标签: alerting, anthropic, audit, cloud-functions, cloud-monitoring, error-reporting, firebase, gemini, idempotency, llm, logging, neverthrow, observability, openai, result, retry, structured-logging, wide-events

## 简介

One record per Firebase Function invocation: neverthrow Results, errors that keep their stack, audit trail, retries that never stack, timeout guard, duplicate-event protection, LLM call accounting.
