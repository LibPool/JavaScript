# @application-kit/observability

> 标签: cqrs, health, logging, metrics, nestjs, observability, opentelemetry, pino, prometheus, terminus, tracing

## 简介

Наблюдаемость NestJS-процесса: метрики Prometheus и RED-гистограммы, health-чеки и пробы, опции pino с request-id и trace-контекстом, логирование CQRS-шин, реальный IP клиента за прокси, трейсинг OpenTelemetry
