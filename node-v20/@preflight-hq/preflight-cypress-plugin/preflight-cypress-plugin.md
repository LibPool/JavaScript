## 简介

1. Tests adapt to UI changes when selectors are broken. 2. Generic tests.  ``type('{{name.firstName}}'); => should('include.text', 'Good morning, {{name.firstName[1]}} `` 3. Email testing ``cy.openEmail('Verify your email');`` 4. PDF testing ``cy.open
