> 标签: ai-agents, audio, mcp, model-context-protocol, podcast, subtitles, tts

## 简介

MCP server for SonicCraft, the declarative multi-track audio engine for AI agents: launches `soniccraft mcp`, downloading a prebuilt binary when needed.
