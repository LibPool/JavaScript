# @amirali_yavari/esx-node

> 标签: esx, esx-legacy, fivem, gaming, gta5, mysql, nodejs, rcon, roleplay

## 简介

Node.js library for interacting with FiveM ESX Legacy: MySQL database access (players, money, bank, jobs, inventory) and live server RCON commands.
