# @conversokit/bridge

> 标签: chatgpt-apps, conversokit, mcp, openai, react, tool-calling

## 简介

Widget Bridge for ConversoKit — `<BridgeProvider>` + `useBridge()` that prefers `window.openai.callTool` and falls back to `fetch` for local dev.
