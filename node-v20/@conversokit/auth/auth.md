# @conversokit/auth

> 标签: chatgpt-apps, conversokit, express, jwks, jwt, middleware, oauth

## 简介

Auth providers (API key, JWT/JWKS, Google/GitHub/Microsoft/Auth0 OAuth, Clerk, Supabase) and Express middleware for ConversoKit ChatGPT Apps.
