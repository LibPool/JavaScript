# @svgd/core

> 标签: compression, d-attribute, optimize, path, pathD, svg, svg-conversion, svg-icons, svg-minification, svg-parser, svg-storage, svg-to-path, svg-transform, svg-utils, svgd, svgo, svgo-plugin, vector-graphics

## 简介

An SVG optimization tool that converts SVG files into a single path 'd' attribute string for efficient storage and rendering.
