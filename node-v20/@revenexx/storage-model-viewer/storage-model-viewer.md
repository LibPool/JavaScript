# @revenexx/storage-model-viewer

> 标签: 3d, glb, gltf, model-viewer, revenexx, three, web-component

## 简介

Framework-agnostic <rx-model-viewer> web component for revenexx storage 3D assets (three.js by default, Google model-viewer/AR as a configurable engine).
