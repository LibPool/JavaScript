# @lemonyc/map-picker

> 标签: amap, geocoding, lnglat, map, map-picker, poi, vue3

## 简介

基于 Vue 3 + 高德地图的经纬度选择弹框组件，支持 element-plus / ant design vue 弹框切换，支持 POI 搜索与逆地址编码
