# @bridgetek/eab-mcp-server

> 标签: Bridgetek, asset builder, eab, eab_tools, eve, ft4222, mcp, model context protocol, mpsse

## 简介

Bridgetek Eve Asset Builder (EAB) MCP server. Drives eab_tools.exe for AI agents — convert, compress, validate and program EVE graphics assets (images, fonts, audio, video, GIF animations, raw pixel buffers, SPI flash images).
