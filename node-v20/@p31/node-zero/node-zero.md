# @p31/node-zero

> 标签: aes-256-gcm, assistive-technology, cryptography, ecdh, ecdsa, esp32, hkdf, k4-topology, lora, mesh-network, neurodivergent, node-zero, p31, tetrahedron, webcrypto

## 简介

Node Zero Protocol — identity, state, bond, and vault primitives for assistive mesh networks. Zero runtime dependencies. WebCrypto P-256 ECDSA/ECDH, AES-256-GCM, HKDF. Runs in browser and Node.js.
