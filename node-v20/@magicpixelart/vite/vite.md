# @magicpixelart/vite

> 标签: asset-sync, gamedev, hmr, magicpixel, pixel-art, sprites, vite, vite-plugin

## 简介

Vite plugin that auto-syncs MagicPixel pixel-art assets into your project — no second terminal required.
