# @nwire/studio

> 标签: devtools, nwire, shadcn, studio, vue, vueflow

## 简介

Nwire Studio — visual companion for the framework. Vue 3 + Vite + shadcn-vue + VueFlow. System topology, action runner, actor browser, projection viewer, DLQ inspector.
