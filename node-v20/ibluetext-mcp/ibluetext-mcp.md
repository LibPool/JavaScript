# ibluetext-mcp

> 标签: 2fa, ai-agent, campaigns, claude, crm, ibluetext, imessage, iphone-lookup, lead-score, mcp, model-context-protocol, otp, phone-verification, sms, whatsapp

## 简介

MCP server for iBlueText: send iMessage, SMS and WhatsApp (single messages and whole campaigns), check which numbers are iPhones or on WhatsApp, read conversations and lead scores, and run phone verification, as native tools for AI agents.
