# @zeroman.yang/react-auto-components

> 标签: chat, components, form, react, schema-driven, table, typescript, virtualization

## 简介

Schema-driven React 19 UI components (forms, tables, search, tabs, dialogs, chat, navigation) designed for AI-assisted development: typed schemas, zero-function JSON configs, error codes that name the fix.
