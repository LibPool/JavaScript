# @proxon/agent-observer

> 标签: agent-cost, anthropic, gen-ai, llm, observability, openai, opentelemetry, proxon, telemetry, token-usage

## 简介

Drop-in agent-cost telemetry SDK: auto-instruments the Anthropic + OpenAI SDKs (ESM, via import-in-the-middle), maps per-call token usage to the Proxon-native agent-cost event, and fire-and-forget POSTs it to the ingest tier (POST /v1/agent-cost/events).
