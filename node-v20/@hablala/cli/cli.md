# @hablala/cli

> 标签: account-as-code, ai-agent, apply, claude, declarative, hablala, ontology, plan

## 简介

CLI de Account as Code de Hablalá — configura la cuenta completa (modelo de datos, workflows, agentes, org) desde archivos declarativos con el ciclo plan/apply.
