# @tasklite/mcp

> 标签: baas, backend, claude, claude-code, mcp, modelcontextprotocol, no-code, tasklite

## 简介

TaskLite MCP server: build a full backend (projects, boards, data, REST endpoints), deploy a frontend onto it, and get a ready-made admin, from Claude Code and other MCP clients
