# @bwo-ui/core

> 标签: animation, bwo-ui, design-system, gsap, magnetic, marquee, motion, parallax, scroll, scroll-trigger, splittext, tilt, tokens

## 简介

Framework-agnostic motion engine behind @bwo-ui/{react,vue,svelte}. Ships GSAP-backed factories for every primitive owned end-to-end — Tilt, Ripple, Pulse, Spin, Parallax, ScrollReveal, ScrollMask, ScrollVelocity, ScrollSnap, ScrollProgress, CircleReveal,
