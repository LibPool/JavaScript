# @datatablex/react

> 标签: data-table, datatable, export, filter, headless, hook, pagination, react, server-side, table

## 简介

Headless useDataTable hook for DataTableX, with REST and local data sources, URL sync and export. UI library independent; see @datatablex/antd for Ant Design components.
