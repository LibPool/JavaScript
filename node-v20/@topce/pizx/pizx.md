> 标签: agentic, ai, ai-scripting, automation, cache, cli, cordis, llm, pi, pi-ai, pi-coding-agent, plugin, script, shell, shell-scripting, template-tag, trace, zx

## 简介

zx fork with native Pi AI integration on the cordis plugin framework — shell scripting with AI agents, user-definable letter tags, traceable runs with JSONL log export, and a local result cache. Ships with π (text generation), Π (coding agent), α (any ACP
