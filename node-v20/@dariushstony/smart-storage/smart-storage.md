# @dariushstony/smart-storage

> 标签: browser-storage, cache, debounce, expiration, localStorage, sessionStorage, ssr-safe, storage, transform, ttl, typescript, web-storage

## 简介

A robust, SSR-safe, production-ready wrapper around Web Storage (localStorage/sessionStorage) with TTL, transforms, debouncing, and automatic cleanup
