# litecoder

> 标签: agent, ai, automation, cli, coding-agent, llm, orchestrator, react, worker

## 简介

Plan one goal with a tool-less orchestrator, then delegate subtasks to concurrent ReAct worker agents (Kooder engine) from the command line.
