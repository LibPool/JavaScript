# @toreador/mcp-server

> 标签: bitcoin, chatgpt, claude, claude-desktop, crypto, ethereum, mcp, model-context-protocol, qr-code, solana, stablecoin, toreador

## 简介

Official Model Context Protocol (MCP) server for Toreador — generate crypto QR codes and manage payment sessions from Claude Desktop, ChatGPT and other MCP clients.
