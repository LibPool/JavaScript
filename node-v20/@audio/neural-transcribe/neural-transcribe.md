# @audio/neural-transcribe

> 标签: audio, basic-pitch, midi, ml, neural, onnx, pitch-bend, polyphonic, transcription

## 简介

Polyphonic note transcription with pitch bends: Spotify's Basic Pitch (ICASSP 2022) through ONNX Runtime, in Node and the browser
