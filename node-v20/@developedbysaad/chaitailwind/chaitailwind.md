# @developedbysaad/chaitailwind

> 标签: client-side, css, dom, inline-styles, lightweight, no-dependencies, tailwind, utility-first

## 简介

A lightweight utility-first CSS engine in pure JavaScript. Reads chai-* classes from the DOM and applies them as inline styles.
