# @silversoft/api-signer

> 标签: api, ed25519, hmac, http-message-signatures, http-signatures, rfc9421, security

## 简介

HTTP request signing and verification per RFC 9421 (HTTP Message Signatures), with no dependencies. The PHP counterpart is silversoft/api-signer.
