# epoxy-server-node

> 标签: epoxy, epoxy-server, mercury-workshop, napi, proxy, rust, tcp, udp, websocket, wisp, wisp-server

## 简介

Node.js bindings for epoxy-server, the Rust Wisp protocol server from Mercury Workshop. Start, stop and configure it from JavaScript.
