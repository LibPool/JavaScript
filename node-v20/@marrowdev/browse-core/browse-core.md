# @marrowdev/browse-core

> 标签: JavaScript

## 简介

The browser-side reading kit behind marrow-browse: the map of what can be pressed, opening what can be opened, walking pages, and reading the DOM. Published so Marrow's deep read can share it instead of keeping a second copy.
