# gemini-web-bridge

> 标签: agy, bridge, gemini, openai-compatible, opencode, proxy

## 简介

Use your Gemini Web subscription in opencode and agy: a local OpenAI-compatible bridge with multi-account rotation, a dashboard and one-command setup.
