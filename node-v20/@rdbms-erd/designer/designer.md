# @rdbms-erd/designer

> 标签: database, erd, react, reactflow, schema, sql

## 简介

`@rdbms-erd/designer` is the React canvas UI package for ER modeling. It uses `@xyflow/react` internally and is intended to be used with `@rdbms-erd/core`.
