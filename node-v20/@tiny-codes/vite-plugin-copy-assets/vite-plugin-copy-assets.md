# @tiny-codes/vite-plugin-copy-assets

> 标签: copy-assets, front-end, node.js, typescript, vite, vite-plugin

## 简介

A Vite plugin for copying static assets to the output directory, with support for development-time proxying. Similar to Webpack's CopyWebpackPlugin.
