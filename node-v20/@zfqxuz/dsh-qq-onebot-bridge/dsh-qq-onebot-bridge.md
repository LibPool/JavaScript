# @zfqxuz/dsh-qq-onebot-bridge

> 标签: asr, bridge, control-console, cordis, debuggable, deepseek-harness, dsh, napcat, observability, onebot, onebot-v11, qq, replay, speech-to-text, tracing

## 简介

QQ ↔ DeepSeek Harness agent bridge over OneBot v11 (reverse WebSocket)：把 QQ 群/私聊接到 DSH agent，自带权限（RBAC）、可视化控制台与可回放调试
