# @discowrap/elastic

> 标签: discovery, elasticsearch, prototyping, rapid, search

## 简介

Discowrap is a set of tools and practices to facilitate rapid development and iteration of search-centric applications.  The /elastic module implements a set of helper functions for the Elasticsearch platform.
