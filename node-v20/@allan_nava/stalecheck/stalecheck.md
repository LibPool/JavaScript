# @allan_nava/stalecheck

> 标签: ci, claude-code, dead-links, docs, documentation, lint, markdown, stale

## 简介

Verifies that what the documentation says is still true: dead links, renamed files, line citations past the end, stale versions and facts dated long enough ago to be worth re-reading. Deterministic — no model, no network.
