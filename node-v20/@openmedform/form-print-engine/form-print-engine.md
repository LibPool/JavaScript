# @openmedform/form-print-engine

> 标签: JavaScript

## 简介

Custom A4 print engine: reconstructs a print-accurate HTML/CSS (@page in mm) document from a jsonforms FormDefinition's UI + Print schemas, plus a pixel-diff primitive for the render→compare→AI-patch visual-fidelity loop. Framework-independent.
