# dsh-member-manager

> 标签: agent-runtime, agent-team, company, deepseek-harness, dsh, dsh-plugin, member, org-chart

## 简介

Manage the DSH member roster from a local registry overlay AND run members like a company: departments, order dispatch, attempt credentials, audit ledger and cost accounting on top of ctx.agents/subagents — no native team layer required.
