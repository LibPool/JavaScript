# @szhl/dsh-session-delete

> 标签: cleanup, cordis, deepseek-harness, delete, dsh, dsh-plugin, privacy, session

## 简介

DeepSeek Harness plugin: delete a conversation for good — the log, the projection cache, the archive marker, the workspace registration and the live Session object, subagent sessions included. DSH ships archive only.
