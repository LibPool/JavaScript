# @flowlabkit/ui

> 标签: breakpoints, components, css-override, css-variables, dark-mode, design-system, flowlabkit, layout, light-mode, mobile-first, modular, panels, react, react-components, responsive, responsive-design, theme, themes, theming, typescript, ui, ui-library, unified-components

## 简介

React UI library with 8 beautiful themes, advanced responsive system, dark/light mode, TypeScript support, and comprehensive component system. Features CSS-like responsive behavior, resizable panels, mobile-first design, and modular architecture.
