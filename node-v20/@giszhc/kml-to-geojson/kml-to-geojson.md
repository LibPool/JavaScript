# @giszhc/kml-to-geojson

> 标签: geojson, gpx, kml, ovjsn, ovkml

## 简介

一个简单、轻量的 JavaScript / TypeScript 工具库，用于将 **KML**、**GPX**、**OVKML**（奥维 KML）或 **OVJSN**（奥维 JSON）文件转换为 **GeoJSON** 格式。
