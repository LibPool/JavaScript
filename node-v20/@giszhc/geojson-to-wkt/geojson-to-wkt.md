# @giszhc/geojson-to-wkt

> 标签: geojson, wkt

## 简介

一个 **简单、轻量、健壮** 的 JavaScript / TypeScript 库，用于将 **GeoJSON** 数据转换为 **WKT（Well-Known Text）** 格式。
