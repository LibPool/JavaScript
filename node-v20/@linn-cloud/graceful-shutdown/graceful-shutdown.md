# @linn-cloud/graceful-shutdown

> 标签: JavaScript

## 简介

Graceful shutdown for Linn's node HTTP services: drains in-flight requests on SIGTERM instead of severing them. Published to support Linn's own consumers; intended for internal use, unsupported, and provided as-is without warranty of any kind. Proprietary
