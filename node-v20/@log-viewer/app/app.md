# @log-viewer/app

> 标签: jsonl, log-viewer, logs, offline, on-prem, opfs, pwa, self-hosted, sqlite

## 简介

Self-hosted PWA log viewer — runs entirely client-side (OPFS + sqlite-wasm). Ships a bundled HTTP server for on-prem / Docker deploys in air-gapped networks.
