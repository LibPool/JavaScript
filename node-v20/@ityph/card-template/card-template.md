# @ityph/card-template

> 标签: JavaScript

## 简介

Developer-authored card templates: the closed Block vocabulary as data. Template schema, validator, declared payload format and canonical content hash. Standalone: imports no other internal lib, no Node-only APIs, no DOM, no React.
