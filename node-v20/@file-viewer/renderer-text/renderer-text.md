# @file-viewer/renderer-text

> 标签: code, document-preview, document-viewer, file-preview, file-viewer, git-bundle, highlight.js, markdown, patch, renderer, self-hosted, text

## 简介

Standalone code, text, and Markdown renderer for File Viewer; Mermaid, patch diff, and Git bundle tools are explicit opt-in capabilities.
