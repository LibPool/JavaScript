# @file-viewer/renderer-binary

> 标签: binary, document-preview, elf, file-viewer, hex, inspector, pe, renderer, self-hosted

## 简介

Opt-in, browser-local binary inspector plugin for File Viewer with virtualized hex rows and bounded Worker parsing.
