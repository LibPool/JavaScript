# @quarry-systems/pangolin-orchestrator

> 标签: JavaScript

## 简介

Orchestrator-engine (codename pangolin-offload) — named queues, depends_on resolution, resource locks, a fire-and-reconcile tick loop, and SQLite run-state behind pluggable Executor/Trigger seams.
