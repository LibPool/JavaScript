# dsh-sub2api-sync

> 标签: dsh, dsh-plugin, llm, provider-sync, sub2api

## 简介

Sync one sub2api instance's groups, keys, and models into dsh-llm-pi-ai provider routes: panel-driven login (password / OAuth), one relay key one provider.
