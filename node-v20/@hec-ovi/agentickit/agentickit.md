# @hec-ovi/agentickit

> 标签: agentic, ai, ai-sdk, anthropic, chat, copilot, form, hooks, llm, openai, react, react-hook-form, sidebar, skills

## 简介

Three hooks that wire an AI copilot into your React app's state, actions, and forms. AI SDK 6 native. Ships with an optional .pilot/ skills folder and an `agentickit` CLI for scaffolding it. MIT.
