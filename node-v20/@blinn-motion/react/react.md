# @blinn-motion/react

> 标签: adapter, animation, blinn-motion, figma, figma-motion, hooks, motion, motiondoc, react, timeline

## 简介

Blinn Motion React adapter — a <BlinnMotion/> component and useBlinnMotion() hook that play a MotionDoc via the DOM or Canvas backend.
