# n8n-nodes-mxhdr-mastodon

> 标签: fediverse, mastodon, n8n-community-node-package

## 简介

n8n community node for Mastodon (personal-access-token auth, statuses/accounts/timelines/notifications/media/search/bookmarks/favourites, plus a notifications/bookmarks polling trigger).
