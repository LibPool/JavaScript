# ngx-pdfium-viewer

> 标签: angular, capacitor, ionic, pdf, pdfium, pinch-zoom, viewer, wasm

## 简介

Angular PDF viewer built on PDFium (WASM): pinch-zoom, search, links, form fields and thumbnails, tuned for mobile WebViews.
