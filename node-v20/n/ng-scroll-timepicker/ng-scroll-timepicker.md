# ng-scroll-timepicker

> 标签: angular, angular18, bootstrap, bootstrap5, component, dark-mode, ng, ngx, picker, reactive-forms, scroll, standalone, time, time-picker, timepicker

## 简介

Smooth scroll-based time picker for Angular 18+. Supports 12h/24h formats, Bootstrap 5, reactive forms (ControlValueAccessor), dark mode, and full CSS custom property theming.
