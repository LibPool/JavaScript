# next-plugin-styletyper

> 标签: css-modules, dts, next, next-plugin, nextjs, sass, scss, styletyper, typescript

## 简介

Next.js plugin that writes a per-class TypeScript declaration (.d.ts + .d.ts.map) next to every *.module.{scss,css,sass} on save (next dev) and build (next build). Runs in-process via the styletyper engine; works with webpack and Turbopack.
