# n8n-nodes-bunwa

> 标签: automation, bunwa, messaging, n8n, n8n-community-node-package, whatsapp

## 简介

n8n community nodes for the BunWa WhatsApp HTTP API: sessions, messages, chats, groups, channels, labels, presence, statuses, templates, audit and a webhook trigger.
