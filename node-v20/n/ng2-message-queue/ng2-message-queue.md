# ng2-message-queue

> 标签: 4, active mq, angular, angular kafka, angular4, component, message, message broker, ng, ng2, queue

## 简介

A message queue for Angular 2+ application components to communication each other. `ng2-message-queue` supports message headers and payload. It also supports subscribers to subscribe to only messages with specific message header via 'msgSelector'. Message
