# navrary-layout

> 标签: JavaScript

## 简介

- maxWidth, minWidth, maxHeight, minHeight 지정 가능   - 이거 지정하면 width || height 지정은 안됨 - width, height 지정 가능   - 이거 지정하면 maxWidth, minWidth || maxHeight, minHeight 지정은 안됨 - 모든 방향 margin 지정 가능 - 모든 방향 padding 지정 가능 - position 지정가능   - absolute & fixed & stick
