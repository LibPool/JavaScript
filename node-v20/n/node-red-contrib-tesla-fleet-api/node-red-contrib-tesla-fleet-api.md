# node-red-contrib-tesla-fleet-api

> 标签: battery, electric-vehicle, ev, fleet-api, home-automation, node-red, soc, state-of-charge, tesla, vehicle-data

## 简介

Node-RED nodes to read your Tesla's state of charge and ~160 other read-only metrics via the official Tesla Fleet API (read-only, your own developer app, never wakes the car). Not an official Tesla tool — not affiliated with Tesla, Inc.
