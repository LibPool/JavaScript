# n8n-nodes-decionis

> 标签: ai-agents, approval, decionis, decision-dossier, governance, guardrails, n8n-community-node-package, policy

## 简介

n8n community node for Decionis. Every automation step asks permission: gate any workflow step through the Decionis decision protocol and branch on the returned verdict, backed by a signed Decision Dossier.
