# nsyslog

> 标签: RFC 3164, RFC 5424, agent, aggregate, bsd, cep, correlation, log, logreader, logstats, modular, parser, reader, server, stats, syslog, transform, transport

## 简介

Modular new generation log agent. Reads, transform, aggregate, correlate and send logs from sources to destinations
