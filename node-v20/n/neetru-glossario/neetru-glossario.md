# neetru-glossario

> 标签: JavaScript

## 简介

Vocabulário plain PT-BR do ecossistema Neetru como código — fonte única de verdade da terminologia, importada pelo CLI e pelo Core, base do lint anti-jargão. Funções puras, zero dependências.
