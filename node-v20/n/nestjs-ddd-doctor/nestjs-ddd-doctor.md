# nestjs-ddd-doctor

> 标签: architecture, clean-architecture, ddd, hexagonal, linter, nestjs

## 简介

Zero-dependency architecture linter for NestJS projects with DDD leanings: thin controllers, pure domain, ports over concrete infrastructure.
