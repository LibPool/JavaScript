# nestjs-metrics

> 标签: analytics, charts, dashboard, fluent-api, laravel-metrics, metrics, mysql, nestjs, postgresql, sqlite, time-series, trends, typeorm, typescript

## 简介

Generate chart-ready metrics and trends from your TypeORM entities in NestJS. Fluent API, locale/timezone-aware bucketing, PostgreSQL/MySQL/SQLite.
