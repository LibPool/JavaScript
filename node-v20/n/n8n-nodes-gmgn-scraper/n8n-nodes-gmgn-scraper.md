# n8n-nodes-gmgn-scraper

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Scrape **real-time trending token data** from **GMGN.ai** across 5 chains (Solana, Ethereum, Base, BSC, Tron). Returns **40+ fields** per token: price, volume, market cap, liquidity, holder count, **smart-money signals**, and **risk flags** — honeypot, ru
