# non-spooky-react-cookie

> 标签: consent-mode, cookie, cookie-banner, cookie-consent, gdpr, nextjs, privacy, react, script-loader

## 简介

A friendly, lightweight cookie consent manager for React and Next.js. Optional scripts stay out of the DOM until the visitor says yes.
