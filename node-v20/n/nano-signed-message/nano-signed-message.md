# nano-signed-message

> 标签: blake2b, ed25519, nano, rfc8785, signed-message

## 简介

Canonical signed messages for Nano accounts: prefixed RFC 8785 JSON, blake2b-256 digest, ed25519-blake2b signature in direct or block-envelope mode
