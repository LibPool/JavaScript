# n8n-nodes-billplz

> 标签: n8n-community-node-package

## 简介

Use this API to access Billplz API endpoints to start sending bills and collecting payment. Our API is organized around REST. JSON will be returned in all responses from the API, including errors. The API will accept both application/x-www-form-urlencoded
