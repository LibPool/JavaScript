# nest-auth-prisma-mcp

> 标签: auth, claude-code, cloud-agnostic, jwt, mcp, nestjs, prisma, scaffold

## 简介

MCP server to scaffold a cloud-agnostic NestJS JWT auth backend with Prisma. Deployment is intentionally out of scope.
