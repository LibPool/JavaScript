# n8n-nodes-couchbase

> 标签: n8n-community-node-package

## 简介

Community nodes for using Couchbase Key-Value, Query, Full-Text Search, Couchbase Search Vector Store, Couchbase Query Vector Store, and Couchbase as Chat Memory with n8n.
