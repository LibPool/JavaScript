# noisejs-ilmiont

> 标签: noise

## 简介

ES6 JavaScript library for 2D and 3D Perlin and Simplex noise generation, based on the original "noisejs" project by "josephg" (https://github.com/josephg/noisejs), which in turn is based on Stefan Gustavson's noise implementation.
