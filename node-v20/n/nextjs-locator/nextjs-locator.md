# nextjs-locator

> 标签: click-to-component, cursor, developer-tools, devtools, nextjs, react, react-devtools, source-locator, turbopack, vscode

## 简介

Alt+Click any React component to open its source in VS Code. Zero-config for Next.js with Turbopack.
