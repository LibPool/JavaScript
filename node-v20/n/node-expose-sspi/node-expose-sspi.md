# node-expose-sspi

> 标签: Microsoft, NTLM, Negotiate, SPNEGO, SSO, SSPI, Single Sign On, Windows, auth, authentication, kerberos, node-addon

## 简介

Expose the Microsoft Windows SSPI interface in order to do NTLM and Kerberos authentication.
