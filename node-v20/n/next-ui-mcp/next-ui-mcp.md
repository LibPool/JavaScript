# next-ui-mcp

> 标签: mcp, model-context-protocol, next-experience, now-experience, now-ui-framework, seismic, servicenow, ui-core

## 简介

MCP server for building ServiceNow Now/Next Experience UI Framework (@servicenow/ui-core) components — component patterns and now-ui.json manifest sync checking. Unofficial, community-maintained, not affiliated with or endorsed by ServiceNow.
