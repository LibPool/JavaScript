# n-multi-hashing

> 标签: POW, argon2, c11, crypto, hashing, kawpow, lyra2z, quark, scrypt, sha256, typescript, x11, x16r

## 简介

A re-write of the Node Multi Hashing library, which provides Javascript bindings for C/C++ based hashing algorithms.
