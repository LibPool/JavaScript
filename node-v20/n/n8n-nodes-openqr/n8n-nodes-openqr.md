# n8n-nodes-openqr

> 标签: dynamic-qr, n8n, n8n-community-node-package, openqr, qr, qr-code, qrcode

## 简介

n8n community node for OpenQR: generate QR codes and manage dynamic (editable) QR codes with scan analytics. https://openqr.uk
