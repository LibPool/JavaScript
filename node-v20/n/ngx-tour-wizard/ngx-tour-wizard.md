> 标签: Angular, Angular 16, Intro.js, Tour Wizard, UI Tour, ngx-tour

## 简介

A cool Angular 8+ module for intro tours! *ngx-tour-wizard* a highly customizable library. Popper are made with NgxPopperjs.
