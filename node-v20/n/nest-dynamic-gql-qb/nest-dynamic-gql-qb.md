# nest-dynamic-gql-qb

> 标签: dynamic, graphql, n+1, nestjs, over-fetching, query-builder, selection, typeorm

## 简介

Turn GraphQL selection into a single TypeORM query with leftJoin + addSelect. NestJS + TypeORM + GraphQL.
