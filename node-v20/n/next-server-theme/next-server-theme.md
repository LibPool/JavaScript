# next-server-theme

> 标签: background-color, color-scheme, dark-mode, hydration, light-mode, next, next-server-theme, next-theme, nextjs, nextjs-server-theme, nextjs-theme, prefers-color-scheme, server, server-side-rendering, ssr, theme, user-preference

## 简介

This is a theme library that allows you to know the user's theme preference on the server and allow you to server pages with no hydration errors.
