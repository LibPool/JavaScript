# nocap-js

> 标签: anti-ai-scraper, anti-scraping, anti-screenshot, canvas, flicker, hide-text-from-ai, persistence-of-vision, prevent-screen-capture, prevent-screenshot, privacy, screen-capture, screenshot-proof, screenshot-protection, secret, security, typescript, watermark, web-component

## 简介

Prevent screenshots of text on the web. Anti-screenshot, anti-AI-scraper display: frames alternate at refresh rate so your eye reads the secret and a single screen capture gets noise -- and the text never enters the DOM.
