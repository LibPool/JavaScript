# node-role-permissions

> 标签: access control, authentication, authorization, authorization middleware, express middleware, mongodb, mongoose, node-role-permissions, node.js, permission assignment, permissions, rbac, responsibility, role assignment, role management, role-based access control, roles, security, user access, user management, user permissions, user roles

## 简介

A comprehensive Node.js package for role-based access control (RBAC) in Express applications. Features complete CRUD operations, permission management, utility functions, and flexible middleware system with MongoDB integration.
