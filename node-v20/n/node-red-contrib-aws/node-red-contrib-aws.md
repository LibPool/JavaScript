# node-red-contrib-aws

> 标签: aws, dynamodb, ec2, ecs, es, firehose, iot, kinesis, lamdba, node-red, polly, rds, redshift, rekognition, s3, sns, sqs, tagging

## 简介

A collection of Node-RED nodes for AWS.  Includes nodes for DynamoDB, EC2, IoT, Kinesis, Lambda, SNS, SQS and S3.
