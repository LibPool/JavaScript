# nicehire-mcp-talent

> 标签: jobs, mcp, model-context-protocol, nicehire, talent

## 简介

Talent-persona launcher for the NiceHire MCP connector. Same proxy, same endpoint as nicehire-mcp; the tool set comes from your talent account's access token.
