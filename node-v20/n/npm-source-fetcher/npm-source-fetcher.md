# npm-source-fetcher

> 标签: JavaScript

## 简介

`npm-source-fetcher` is a CLI tool that fetches the source code of any npm package by retrieving its repository and cloning it.

## 官网

- npm 页面：https://www.npmjs.com/package/npm-source-fetcher
