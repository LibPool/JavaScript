# nibbles-store

> 标签: devtools, hooks, nibbles, persist, react, state, store, tiny, useSyncExternalStore, zero-dependency, zustand

## 简介

Tiny (< 1 KB) zero-dependency state management for React and plain JavaScript: create a store from a plain object, read with a selector hook, update with store.set.count++.
