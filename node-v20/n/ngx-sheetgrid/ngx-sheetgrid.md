# ngx-sheetgrid

> 标签: ag-grid, angular, cell-selection, clipboard, datagrid, fill-handle, grid, signals, table, zoneless

## 简介

A declarative Angular grid on ag-Grid Community — range selection, clipboard, fill handle, set filter, master/detail and tree data, in one MIT package. Not affiliated with AG Grid Ltd.
