# n8n-nodes-bulktranscripts

> 标签: bulktranscripts, captions, n8n, n8n-community-node-package, subtitles, transcript, youtube, youtube-transcript

## 简介

n8n community node for BulkTranscripts: YouTube transcripts for a video, channel or playlist, YouTube search, and free new-upload tracking.
