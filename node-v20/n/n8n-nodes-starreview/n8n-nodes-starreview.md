# n8n-nodes-starreview

> 标签: google-reviews, n8n, n8n-community-node-package, reputation, review-management, review-replies, reviews, starreview

## 简介

n8n community node for StarReview: list unanswered reviews, draft replies, and submit them to the owner's approval queue. The node never publishes a reply itself.
