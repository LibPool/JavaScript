# noya-agent-mcp

> 标签: ai-agent, crypto, mcp, model-context-protocol, noya, proxy, trading

## 简介

Thin stdio ↔ HTTP proxy for the Noya MCP server — bridges local MCP clients (Claude Desktop, Cursor, VS Code) to https://agent-api.noya.ai/mcp
