# notify-zh

> 标签: alert, angular, browser, lightweight, message, notification, popup, react, solid, svelte, toast, typescript, ui, vanilla-js, vue, zero-dependencies

## 简介

Extremely lightweight (~2.7 KB gzipped), zero-dependency toast notification library with promise support for React, Vue, Angular, Svelte, and Vanilla JS.
