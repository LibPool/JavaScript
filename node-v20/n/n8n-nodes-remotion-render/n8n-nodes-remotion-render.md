# n8n-nodes-remotion-render

> 标签: n8n, n8n-community-node, n8n-nodes, remotion, render, video, video-generation

## 简介

n8n community node for rendering videos using your self-hosted Remotion server. Supports Manual timeline and Batch Render (each scene rendered individually, concat with ffmpeg, returns binary). No internal file upload — you control the upload strategy.
