# no-eval-handlebars

> 标签: @elastic/handlebars, handlebars no eval, kbn-handlebars, kbn/handlebars, no-eval-handlebars

## 简介

A custom version of the handlebars package which, to improve security, does not use 'eval' or 'new Function'
