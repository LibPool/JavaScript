# nostrumrerum

> 标签: JavaScript

## 简介

Provides insights and predicts slippage amount on DeX swaps. Currently works on ETH/USDT and ETH/USDC pairs on Uniswap V3 For more info and starting guide go to info.xtreamly.io. For support use info@xtreamly.io
