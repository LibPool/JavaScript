# n8n-nodes-captchaai-detect

> 标签: automation, captcha, captcha detector, captchaai, captchafox, cloudflare, friendly captcha, geetest, lemin, n8n, n8n-community-node-package, playwright, recaptcha, turnstile

## 简介

CaptchaAI Detect community node for n8n - finds CAPTCHA widgets (reCAPTCHA, Turnstile, GeeTest, and more) on a page across every frame and returns their identifying parameters. Detection only - never solves, never injects tokens.
