# n8n-nodes-marktplaats-listings-scraper

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Scrape Marktplaats.nl (Netherlands #1 classifieds) by keyword, category, location, price & seller type. Clean structured fields: price (EUR) + type (fixed/bid/free), condition, seller, GPS, images, date, URL. First-party JSON API — stable, no HTML parsing
