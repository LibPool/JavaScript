# nibula

> 标签: 11ty, beginner-friendly, boilerplate, bootstrap, bulma, cli, deploy-ready, eleventy-template, nginx, njk, nodejs, php, rest-api, sass, scaffolder, seo-optimization, ssg, static-site-generator, typescript

## 简介

A beginner-friendly static site generator built on Eleventy that stays close to vanilla HTML, CSS and JS — with a page-management CLI, an optional PHP backend, and SEO files generated for you.
