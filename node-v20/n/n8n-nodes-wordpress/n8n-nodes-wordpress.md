# n8n-nodes-wordpress

> 标签: LearningSpot, Wordpress, automation, integration, n8n, n8n-community-node-package, n8n-nodes, wp

## 简介

This wordpress node adds advanced Post, Page, and User operations to n8n with features that the official WordPress node does not provide.
