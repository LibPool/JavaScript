# n8n-nodes-scanify

> 标签: n8n-community-node-package

## 简介

Este é um pacote de nodes da comunidade n8n que permite integrar a API do Scanify diretamente nos fluxos de automação.

## 官网

- 官网：https://scanify.com.br
- 源码仓库：git+https://github.com/scanifybr/n8n-nodes-scanify.git
- npm 页面：https://www.npmjs.com/package/n8n-nodes-scanify

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install n8n-nodes-scanify`
- npm registry：https://registry.npmjs.org/n8n-nodes-scanify
- Node 要求：>=20.15
