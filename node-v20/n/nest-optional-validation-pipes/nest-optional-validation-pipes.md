# nest-optional-validation-pipes

> 标签: nest, nest-pipes, nestjs, nestjs-pipes, optional, optional pipes, pipes

## 简介

A NestJS addon that provides validation pipes for the simple data types with the option of optionality.
E.g. a ParseBoolOptionalPipe that validates & transforms @Query parameters that are then either true, false or undefined/null or throw an error.
