# n8n-nodes-waops

> 标签: automation, bulk-messaging, messaging, n8n, n8n-community-node-package, wa-ops, waops, whatsapp, whatsapp-api, whatsapp-bot

## 简介

WaOps WhatsApp API nodes for n8n. 140+ operations: send messages, manage groups, communities, newsletters, bulk messaging, business catalogs, sessions, labels, and more. Connect your WhatsApp at waops.app and automate everything via api.waops.app.
