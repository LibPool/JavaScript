# ng-track-event-directive

> 标签: analytics, angular, angular 22, angular analytics, angular click tracking, angular event tracking, angular ga4, angular google analytics, angular mixpanel, angular segment, angular standalone, click tracking, declarative analytics, directive, event tracking, ga4, hover tracking, intersection observer, mixpanel, ng-track, segment, standalone directive, track events, view tracking, viewport tracking

## 简介

Declarative Angular directive for analytics event tracking — click, hover, and viewport-view triggers. Adapter-based: works with Mixpanel, Segment, GA4, or any custom backend.
