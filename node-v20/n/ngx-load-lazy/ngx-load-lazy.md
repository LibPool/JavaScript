# ngx-load-lazy

> 标签: JavaScript

## 简介

Load angular components with Ivy in runtime with ease and simplicity in mind.   Pages get complex from day to day, load time decrease and UX is damaged. LoadLazy will help take the burden of the complexity of loading components in run time.
