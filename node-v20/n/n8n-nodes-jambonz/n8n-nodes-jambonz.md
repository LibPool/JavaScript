# n8n-nodes-jambonz

> 标签: cpaas, ivr, jambonz, n8n-community-node-package, telephony, voice, voicebot, voip

## 简介

n8n community nodes for jambonz — build voicebots by receiving jambonz webhooks, composing verb responses (say, gather, play, dial, llm, ...) and calling the jambonz REST API
