# nearcall

> 标签: cost-optimization, fallback, llama-cpp, llm, lm-studio, local-first, local-llm, ollama, openai-compatible, openai-proxy, proxy, router

## 简介

Local-first router with an OpenAI-compatible surface. Point any OpenAI client at it and requests reach a paid API only when nothing local can serve them. Zero dependencies.
