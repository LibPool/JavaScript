# ng-breadcrumb

> 标签: JavaScript

## 简介

This component is a fork from https://github.com/akiocloud/ng-breadcrumb which is a fork of https://github.com/gmostert/ng2-breadcrumb. The component has been updated to work with Angular 6 and Angular CLI 6.
