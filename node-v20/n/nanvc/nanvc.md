# nanvc

> 标签: approle, database-secrets, esm, hashicorp, hashicorp-vault, http-client, kv, kv-v2, node, nodejs, response-wrapping, secret-management, secrets, typescript, typescript-vault-client, vault, vault-approle, vault-client, vault-database, vault-http-client, vault-kv, vault-kv-v2

## 简介

Lightweight TypeScript client for HashiCorp Vault with typed KV v2, AppRole, response wrapping, and database secrets support.
