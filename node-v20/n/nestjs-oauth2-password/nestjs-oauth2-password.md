# nestjs-oauth2-password

> 标签: access-token, auth, authentication, guard, nest, nestjs, oauth, oauth2, opaque-token, password-grant, refresh-token, ropc

## 简介

OAuth2 Resource Owner Password Credentials (ROPC) for NestJS — opaque, server-stored, revocable access + refresh tokens, an RFC 6749 token endpoint, and a bearer guard.
