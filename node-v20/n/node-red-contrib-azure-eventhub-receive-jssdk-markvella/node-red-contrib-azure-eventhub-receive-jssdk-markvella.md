# node-red-contrib-azure-eventhub-receive-jssdk-markvella

> 标签: Azure, Azure Event Hub, Event Hub, Event Hubs, IoT, node-red

## 简介

A simple node that receives messages from an Azure Event Hub. Based on the work of Jan Tielens and updated to use the latest Azure Java Script SDK.
