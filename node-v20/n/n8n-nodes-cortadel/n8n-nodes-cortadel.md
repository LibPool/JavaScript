# n8n-nodes-cortadel

> 标签: agents, ai, cortadel, knowledge-graph, llm, long-term-memory, memory, n8n, n8n-community-node-package, rag

## 简介

n8n community node for Cortadel — self-hosted long-term temporal graph memory for AI agents. Ships a Cortadel action node (usable as an AI Agent tool) and a Cortadel Memory sub-node for the ai_memory slot.
