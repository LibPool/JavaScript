# node-i18n-yx

> 标签: JavaScript

## 简介

基于 AST 的 Vue 国际化扫描工具   自动识别 Vue 模板中未翻译的中文字段，生成待办清单和翻译 key 建议，提升翻译覆盖率，减少人工成本。
