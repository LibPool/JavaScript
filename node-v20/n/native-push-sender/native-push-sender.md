# native-push-sender

> 标签: android, apns, apns-http2, apple-push-notification, cloudflare-workers, edge, fcm, fcm-http-v1, firebase-admin-alternative, firebase-cloud-messaging, ios, jwt, mobile-push, native-push, push, push-notification, push-notifications, webcrypto, workerd, zero-dependency

## 简介

Send FCM (Android) and APNs (iOS) native push notifications from Cloudflare Workers without firebase-admin. Zero-dependency FCM HTTP v1 + APNs HTTP/2 sender using Web Crypto JWT signing. FCM also works on Node.js.
