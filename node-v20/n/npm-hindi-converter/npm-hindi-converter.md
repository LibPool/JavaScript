# npm-hindi-converter

> 标签: hindi-converter, node-hindi, node-hindi-converter, npm-hindi-converter

## 简介

A small package to convert html string into Hindi by picking some basic hindi fonts. As of now this plugin supports `Krutidev10` and `Chanakya` fonts.
