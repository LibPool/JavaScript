# n8n-nodes-grailed-listings

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Search Grailed resale listings via the public Algolia API. Returns price, price_drops, sold_price, condition, designer, size, strata (hype/luxury), seller score. Two-tier PPE: $1.50/1K active, $2.50/1K sold listings with confirmed prices. No proxy. Pay pe
