# n8n-nodes-datacheck

> 标签: automation, csv, data-cleaning, data-quality, data-validation, etl, n8n, n8n-community-node-package

## 简介

Catch data problems inside your n8n workflow before they reach the next node — duplicate keys, impossible dates like 2026-02-30, amounts that become NaN, rows that vanish silently.
