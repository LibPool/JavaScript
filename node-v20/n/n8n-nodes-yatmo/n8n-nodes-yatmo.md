# n8n-nodes-yatmo

> 标签: geocoding, isochrone, map, n8n-community-node-package, neighbourhood, points-of-interest, proptech, real-estate, seo, yatmo

## 简介

Real estate neighbourhood data in n8n workflows: nearest places with travel times, neighbourhood text as HTML, listing enrichment, scores, geocoding, isochrones, routes and static maps from Yatmo. The official Yatmo community node.
