# ngx-svg-schematic

> 标签: angular-schematics, angular-svg, angular-svg-component, angular-svg-icon, ngx-svg-schematic, schematics, svg

## 简介

A schematic to generate SVG components from SVG files; making it easier to embed SVGs in templates and avoid conflicting CSS rules from multiple embedded SVGs.
