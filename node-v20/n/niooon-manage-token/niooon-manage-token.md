# niooon-manage-token

> 标签: credentials, devops, github token, niooon, secrets, supabase token, token vault, vercel token

## 简介

Secure token vault client for NIOOON — fetch your GitHub, Vercel and Supabase tokens at runtime with a single platform API key. Tokens stay in memory for 5 minutes and are never written to disk.
