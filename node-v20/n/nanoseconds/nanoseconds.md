# nanoseconds

> 标签: conversion, convert, format, formatting, hrtime, nano, nanosecond, nanoseconds, ns, pretty, second, seconds, time, time-stamp, timestamp

## 简介

Convert the process.hrtime() array to a single nanoseconds value. This makes it easier to diff times.
