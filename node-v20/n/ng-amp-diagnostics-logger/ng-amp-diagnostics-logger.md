# ng-amp-diagnostics-logger

> 标签: amp-diagnosticslogger.js, angular, applicationinsights-js

## 简介

ng-amp-diagnostics-logger is a package that sends Azure Media Player telemetry information to Azure Application Insights in a Angular application
