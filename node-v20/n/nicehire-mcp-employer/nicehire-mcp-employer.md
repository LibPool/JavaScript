# nicehire-mcp-employer

> 标签: employer, jobs, mcp, model-context-protocol, nicehire

## 简介

Employer-persona launcher for the NiceHire MCP connector. Same proxy, same endpoint as nicehire-mcp; the tool set comes from your employer account's access token.
