# nanopak

> 标签: addon, binary, bundle, bundling, code, encryption, minifier, minify, nanopack, nanopak, obfuscation, pack, protection, source

## 简介

Nanopak encrypts Node.js modules (and other forms of content) into binary modules which can be used just as the original modules. Users of the modules have no visibility into the JavaScript code, thereby creating a high degree of code protection.
