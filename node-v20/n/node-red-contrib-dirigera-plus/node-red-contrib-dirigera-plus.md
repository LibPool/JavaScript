# node-red-contrib-dirigera-plus

> 标签: dirigera, events, home-automation, ikea, node-red, smart-home, tradfri, websocket

## 简介

Node-RED nodes for the IKEA DIRIGERA hub: control devices/rooms/scenes and receive live hub events (motion, buttons, open/close, state changes) via websocket.
