# ngx-forms-validator

> 标签: angular, angular forms library, angular validators, custom validators, form error messages, form helper, form validation, forms, ngx, ngx-forms-validator, reactive forms, typescript, validation

## 简介

Lightweight and extensible form validation library for Angular applications. Includes custom validators, reusable error messages, and simple integration with reactive forms.
