# no-vibe

> 标签: ai-tutor, claude-code-plugin, codex-plugin, education, gemini-extension, learning, no-vibe, opencode-plugin, pi-package

## 简介

Tutor mode for AI coding assistants. AI shows code in chat and reviews your work, but never writes to your project files. Ships across Claude Code, OpenCode, Codex, Gemini CLI, and Pi.
