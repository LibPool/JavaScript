# n8n-nodes-builder-io

> 标签: api, automation, builder.io, builderio, content-management, headless-cms, n8n, n8n-community-node-package, no-code, visual-cms, workflow

## 简介

A comprehensive n8n community node for Builder.io visual CMS providing 10 resources and 60+ operations for content management, publishing workflows, and cross-platform content distribution. Includes trigger node for real-time content change notifications.
