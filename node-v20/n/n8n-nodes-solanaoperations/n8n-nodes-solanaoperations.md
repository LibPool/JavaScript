# n8n-nodes-solanaoperations

> 标签: blockchain, n8n-community-node-package, solana, solana-node, spl-token, stake, wallet, web3

## 简介

A custom n8n node to interact with the Solana blockchain. Supports sending SOL and tokens, wallet creation, balance checks, staking, and cryptographic operations.
