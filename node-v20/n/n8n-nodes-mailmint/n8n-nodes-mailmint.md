# n8n-nodes-mailmint

> 标签: email, email-parser, eml, extraction, imap, inbound-email, invoice, mailmint, mime, n8n, n8n-community-node-package

## 简介

Turn inbound email into structured JSON. Define the fields you want right inside n8n, then receive parsed messages by webhook or polling — or parse mail that another node already fetched.
