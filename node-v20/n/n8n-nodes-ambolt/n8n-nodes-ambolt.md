# n8n-nodes-ambolt

> 标签: ambolt, company-data, kyb, mcp, n8n-community-node-package, tenders

## 简介

n8n node for Ambolt: company registry lookup, EU and UK tenders, VAT, IBAN and LEI checks, domain and SSL expiry and URL metadata. Free through the hosted MCP server.
