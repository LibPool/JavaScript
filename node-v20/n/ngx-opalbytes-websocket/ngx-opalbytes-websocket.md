# ngx-opalbytes-websocket

> 标签: JavaScript

## 简介

Uma biblioteca genérica de WebSocket para aplicações Angular, construída sobre o Template Method Pattern. Fornece uma classe abstrata base (`CaoWebSocketService`) com reconexão automática, gerenciamento de estado e transformação de mensagens — basta esten
