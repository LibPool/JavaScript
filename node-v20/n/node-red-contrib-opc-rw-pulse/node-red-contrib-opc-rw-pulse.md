# node-red-contrib-opc-rw-pulse

> 标签: node-red, opc, opc-ua, pulse

## 简介

OPC UA nodes for Node-RED: read, write, and pulse a tag TRUE then back to FALSE after a configurable delay, sharing a common connection manager.
