# novacheck

> 标签: ai-generated-code, cli, code-scanning, dependency-confusion, ghost-dependencies, hallucinated-packages, npm, pypi, sarif, secrets, security, slopsquatting, supply-chain-security, typosquatting

## 简介

Local-first CLI that finds hallucinated and typosquatted dependencies — in manifests, imports, and the install commands written in docs and agent instruction files — before you install them.
