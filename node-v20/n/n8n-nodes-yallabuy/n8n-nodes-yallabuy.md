# n8n-nodes-yallabuy

> 标签: ecommerce, erp, n8n, n8n-community-node-package, pos, webhooks, yallabuy

## 简介

n8n community nodes for YallaBuy — the Public API v1 action node (orders, products, inventory, customers, returns, marketing, analytics) and the signed merchant-webhook trigger (16 event types, §3.1 HMAC verification).
