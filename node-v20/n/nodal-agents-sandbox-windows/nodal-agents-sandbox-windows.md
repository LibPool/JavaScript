# nodal-agents-sandbox-windows

> 标签: JavaScript

## 简介

Windows-only carrier of Microsoft MXC for the Nodal-Agents OS sandbox (#628). Installs only on win32; on other platforms npm skips it and its native dependency tree (node-pty) is never fetched.
