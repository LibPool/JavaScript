# nightwatch-agent

> 标签: agent-observability, ai-agents, audit-trail, autonomous-agents, claude-code, fable-5, hash-chain, verifiable-agents

## 简介

The black box recorder for overnight AI agents. Hash-chained run ledgers, checkpoints, and a morning debrief that verifies what your agent claims it did.
