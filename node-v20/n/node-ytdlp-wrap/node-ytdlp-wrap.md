# node-ytdlp-wrap

> 标签: binary, installer, nodejs, youtube, yt-dlp

## 简介

A basic yt-dlp wrapper for node projects. Installs the correct binary of yt-dlp for the current platform. Supports Linux, Windows, and MacOS/X.
