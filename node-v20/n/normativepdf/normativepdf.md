# normativepdf

> 标签: cos, iso-32000, pdf, pdf-2.0, pdf-parser, typescript

## 简介

Clause-driven PDF library in pure TypeScript. Every behaviour tied to an ISO 32000 clause; what cannot be tied is not claimed.
