# n8n-nodes-cobra-cxm

> 标签: adressen, cobra, cobra-cxm, crm, n8n, n8n-community-node-package, webconnect

## 简介

n8n community nodes for cobra CXM WEB CONNECT (cobra Classic) — read, create, update and delete cobra records, search by mail/phone, manage keywords, documents and images.
