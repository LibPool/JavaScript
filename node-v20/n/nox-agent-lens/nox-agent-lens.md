# nox-agent-lens

> 标签: agent, agentlens, ai, claude, cli, cursor, mcp, scanner, secrets, security

## 简介

See what your AI agents can access. Scans for installed AI coding agents, maps their MCP data sources, and flags hardcoded secrets.
