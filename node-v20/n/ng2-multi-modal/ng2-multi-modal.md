# ng2-multi-modal

> 标签: accessible, angular, angular20, angular21, angular22, component, customizable, dialog, draggable, library, modal, ng2-multi-modal, resizable, signals, window-manager, zoneless

## 简介

Signals-based, zoneless multi-window modal library for Angular 20, 21 & 22. Draggable, resizable, maximizable, minimizable (dock), themeable and accessible.
