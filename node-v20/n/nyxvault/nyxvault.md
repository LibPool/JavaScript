# nyxvault

> 标签: argon2, burn-after-reading, encryption, end-to-end, file-sharing, privacy, self-hosted, tweetnacl, zero-knowledge

## 简介

End-to-end encrypted, zero-knowledge file sharing. Encrypt in your browser, share a link — the server never sees your data.
