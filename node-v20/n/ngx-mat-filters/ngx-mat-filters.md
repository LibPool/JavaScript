# ngx-mat-filters

> 标签: Angular, Angular Material Filters Mobile Responsive, Angular material, Filters, Full Screen, Bottom Sheet View, list filter for angular material, table filter for angular material

## 简介

This library was generated for  Angular Material to Providing Filters such as
Number Box, TextBox, Date, Single Select, Multi Select And True/False Filters for grids or list.
