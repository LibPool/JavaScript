# netkitty

> 标签: decode, deep-packet-inspection, dpi, encode, iec61850, industrial-protocol, modbus, netkitty, network, network-toolkit, network-tools, opcua, ot, packet, packet-analysis, packet-capture, packet-decoder, pcap, pcapng, protocol-decoder, scada, tcpdump, wireshark

## 简介

Network toolkit for Node.js — packet encode/decode (180+ protocols incl. industrial/OT), pcap/pcapng read-write, cross-packet analysis, live capture and replay.
