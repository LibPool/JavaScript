# next-easytour

> 标签: animated, composable, guide, headless, interactive, nextjs, onboarding, overlay, product-tour, react, svg-arrow, tour, tutorial, walkthrough

## 简介

Interactive tutorial overlays for React/Next.js. One config object, selector targeting, step actions, waitFor conditions, a drag-to-author editor with a real permission model, and pluggable step stores.
