# n8n-nodes-charityspurseapi

> 标签: charityspurse, donations, n8n-community-node-package

## 简介

A collection of custom n8n trigger nodes that monitor donation events — including processing, confirmed, and abandoned donations — and fetch related data for automated email notifications to users.
