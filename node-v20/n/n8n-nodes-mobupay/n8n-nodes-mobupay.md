# n8n-nodes-mobupay

> 标签: mobupay, n8n-community-node-package, new-caledonia, payment-gateway, payment-link, payments, xpf

## 简介

n8n community node for Mobupay payments (New Caledonia and the Pacific): create hosted payment links, fetch payment status, refund, and receive signed webhook events.

## 官网

- 官网：https://docs.mobupay.nc/guides/no-code
- 源码仓库：git+https://github.com/mobupay/n8n-nodes-mobupay.git
- npm 页面：https://www.npmjs.com/package/n8n-nodes-mobupay
