# nodebb-plugin-alioss-new

> 标签: aliyun, nodebb, oss, plugin, uploads

## 简介

A plugin for NodeBB to take file uploads and store them on Aliyun OSS, NodeBB version >=  nodebb 1.15*, Less than 1.15 unknown compatibility
