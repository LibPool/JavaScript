# ng2-custom-tag-input

> 标签: angular, angular tag input, material tag input, tag input component

## 简介

This is just a simple changed version 1.3.3 of the ng2-tag-input (by Giancarlo Buomprisco) to add readonly back and fix some bugs with drag and drop on a autocompleteItems dropdown.
