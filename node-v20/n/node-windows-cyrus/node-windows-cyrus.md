# node-windows-cyrus

> 标签: cyrus, daemon, elevate, event, event logging, logging, ngn, service, sudo, task, windows

## 简介

Support for Windows services, event logging, UAC, and several helper methods for interacting with the OS. Fix Snyk Vulnerabilities
