# n8n-nodes-nemix

> 标签: accounting, ai-agent, crm, erp, germany, gobd, langchain, n8n-community-node-package, nemix, rag, zugferd

## 简介

Nemix ERP integration for n8n. Action mode (all resources + all operations as prefab forms) + Custom API Call (truly free request builder) + Nemix Knowledge AI-Agent tool (RAG search over your ERP). 27 webhook triggers, bulk sync helpers.
