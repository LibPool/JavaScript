# n8n-nodes-azur

> 标签: azur, comprobantes-electronicos, ecuador, factura-electronica, facturacion-electronica, n8n, n8n-community-node-package, sri

## 简介

Nodos de n8n para AZUR: facturación electrónica del SRI de Ecuador (facturas, notas de crédito y débito, guías, retenciones, liquidaciones, compras, inventario, cartera, contabilidad y avisos por webhook).
