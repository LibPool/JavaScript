# neo4j-browser

> 标签: JavaScript

## 简介

Neo4j Browser is the general purpose user interface for working with Neo4j. Query, visualize, administer and monitor the database.

## 官网

- 官网：https://neo4j.com/developer/guide-neo4j-browser/
- 源码仓库：git+https://github.com/neo4j/neo4j-browser.git
- npm 页面：https://www.npmjs.com/package/neo4j-browser
