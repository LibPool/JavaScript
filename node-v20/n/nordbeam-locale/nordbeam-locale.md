# nordbeam-locale

> 标签: cli, compiler, i18n, icu, internationalization, l10n, localization, messageformat, translations, tree-shaking, typed, typescript, vite

## 简介

Nordbeam Locale: compile ICU translations into typed, tree-shakable JavaScript with lazy locale loading. The CLI, compiler, Vite and Next.js plugins, and test helpers; apps import the runtime from @nordbeam/locale.
