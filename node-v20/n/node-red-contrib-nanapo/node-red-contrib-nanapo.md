# node-red-contrib-nanapo

> 标签: node-red

## 简介

ビット・トレード・ワン社製の[Nanapo](https://bit-trade-one.co.jp/ad7sgpr/Nanapo)をコントロールするためのノードです。 表示内容を変更やスイッチの情報取得が行えます。
