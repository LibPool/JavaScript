# nuxt-skeletonizer

> 标签: loading, nuxt, nuxt-module, placeholder, shimmer, skeleton, skeleton-loader, skeletonizer, ui, vue

## 简介

Automatic skeleton UI for Nuxt 4 — turn any component into a layout-preserving skeleton. The Vue/Nuxt equivalent of Flutter Skeletonizer.
