# n8n-nodes-apple-app-store-search

> 标签: ai-tool, apify, app-discovery, app-search, app-store, app-store-optimization, apple-app-store, aso, ios-apps, n8n, n8n-community-node-package, n8n-nodes

## 简介

Search the Apple App Store by keyword and return app titles, developers, ratings, prices, and metadata. Apify-backed n8n community node, pay-per-result, and usable as an AI agent tool.
