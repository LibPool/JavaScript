# node-wifi-handler

> 标签: ssid, wifi, wireless, wlan, wpa

## 简介

Node module to work with the Wi-Fi inspired on [node-wifi](https://github.com/friedrith/node-wifi) with TypeScript support and other features (WPA Personal and WPA enterprise).
