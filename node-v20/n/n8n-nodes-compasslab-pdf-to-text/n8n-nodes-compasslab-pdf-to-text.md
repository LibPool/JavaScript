# n8n-nodes-compasslab-pdf-to-text

> 标签: compasslab, n8n, n8n-community-node-package, pdf extraction, pdf parser, pdf to markdown, pdf to text, rag

## 简介

n8n node for PDF to Text and Markdown (CompassLab): Extract the text of a PDF (URL or file) as plain text, Markdown or page by page, with metadata and scanned-page flags.
