# n8n-nodes-mews

> 标签: automation, booking, hospitality, hotel, housekeeping, mews, n8n, n8n-community-node-package, pms, property-management, reservations

## 简介

A comprehensive n8n community node for Mews property management system, providing 10 resources and 60+ operations for hospitality workflow automation including reservations, guests, billing, and housekeeping.
