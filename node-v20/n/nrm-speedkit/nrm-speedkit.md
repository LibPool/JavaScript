# nrm-speedkit

> 标签: JavaScript

## 简介

`nrm-speedkit` 是基于 `nrm` 的 npm 源网络性能测试工具。快速、轻量地测试各 npm 源的网络延迟和可用性。

## 官网

- npm 页面：https://www.npmjs.com/package/nrm-speedkit

## 历史版本号

- 当前版本：1.0.0

- 1.0.0

## 获取地址

- npm 安装：`npm install nrm-speedkit`
- npm registry：https://registry.npmjs.org/nrm-speedkit
