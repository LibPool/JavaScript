# nulabg-mcp

> 标签: accounting, bulgaria, claude, invoices, mcp, model-context-protocol, nula, nula.bg

## 简介

MCP server for the Bulgarian accounting platform nula.bg: invoices, bills, OCR, customers, inventory and banking for Claude and other MCP clients.
