# nexusflex-mcp

> 标签: claude, logistica, mcp, modelcontextprotocol, nexusflex

## 简介

MCP de Nexus Flex: operá tu nodo/cuenta desde un asistente de IA (altas de clientes, stock, KPIs). Login por autorización web (device-flow). NO toca dinero.
