# ngrx-store-wrapper

> 标签: angular, angular dynamic store, angular state, auto cleanup, dynamic store, local storage sync, ngrx, ngrx dynamic, ngrx effects, ngrx store, ngrx tools, ngrx without actions, ngrx without boilerplate, ngrx without reducers, ngrx wrapper, runtime reducer, session storage sync, state management, state sync

## 简介

Angular library that lets you manage NgRx store state without writing actions, reducers, or effects manually, with built-in support for syncing to session and local storage
