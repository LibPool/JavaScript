# ngx-smart-tooltip

> 标签: accessible, angular, angular-component, angular-tooltip, angular21, animations, aria, directive, lightweight, modern, ngx, ngx-tooltip, onpush, overlay, performance, popover, positioning, signals, standalone, templateref, tooltip, typescript, ui-component, web-animations, zero-dependencies

## 简介

A modern, lightweight (~5.4kb), zero-dependency tooltip library for Angular 21+. Built with Signals, Web Animations API, and OnPush strategy for maximum performance. Features smart positioning, rich content support, accessibility, and beautiful animations
