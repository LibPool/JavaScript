# n8n-nodes-printerflo

> 标签: n8n, n8n-community-node-package, print shop, printerflo, sign shop

## 简介

n8n nodes for PrinterFlo, the shop management app for sign and print shops: create quotes, orders and customers, and trigger workflows on new orders, status changes, invoices and payments.
