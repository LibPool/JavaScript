# nodewordfreq

> 标签: nlp, nodejs, tokenization, typescript, word-frequency, zipf

## 简介

TypeScript/Node.js 版 wordfreq，内置词频数据与中文分词词典，开箱即用的跨语言词频查询与 Zipf/分词能力。
