# nostr-mill

> 标签: bitcoin, decentralized, identity, login, nip-07, nip-46, nip-55, nostr, signer, web-component

## 简介

MILL — Multi-Interface Login Layer. Lightweight Web Component for Nostr account access. Supports NIP-07, NIP-46, NIP-55, private key, read-only, new keypair, and optional Continue-with-Google (pomegranate/FROST or Drive+PIN).
