# nodebb-plugin-cloudflare-cache

> 标签: cache, cache-rules, cache-warmer, caching, cdn, cloudflare, edge-cache, forum, guest-cache, nodebb, nodebb-plugin, page-cache, performance, sitemap

## 简介

Deploy Cloudflare Cache Rules for a NodeBB forum and warm anonymous pages from the sitemap. Fast edge caching of guest HTML and static assets, with safe bypass for logged-in users, API, Socket.IO, and admin routes.
