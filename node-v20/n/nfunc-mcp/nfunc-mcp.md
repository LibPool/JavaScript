# nfunc-mcp

> 标签: accessibility, ai-tools, claude, cls, core-web-vitals, crux, eslint, inp, lcp, lighthouse, mcp, non-functional-testing, pa11y, pagespeed, pagespeed-insights, performance, psi, qa, quality-assurance, semgrep, wcag, web-vitals

## 简介

MCP server for non-functional QA — Lighthouse, pa11y, ESLint and Semgrep in parallel with cross-tool correlation, plus PageSpeed Insights audits that compare lab scores against real-user Core Web Vitals from CrUX
