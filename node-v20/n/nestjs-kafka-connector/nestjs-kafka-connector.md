# nestjs-kafka-connector

> 标签: avro, confluent, confluent-kafka-javascript, consumer-group, dead-letter, dead-letter-queue, decorator, dlq, kafka, kafka-consumer, kafka-producer, librdkafka, multi-environment, namespace, nest, nestjs, schema-registry

## 简介

Decorator-driven Kafka consumers and producer for NestJS, built on librdkafka (@confluentinc/kafka-javascript), with dead-letter topics, Avro, and topic namespacing
