# n8n-nodes-asyntai

> 标签: ai, asyntai, chatbot, customer-support, leads, n8n-community-node-package

## 简介

n8n community node for Asyntai — AI chatbot: send chat messages, fetch leads and conversations, manage the knowledge base, and trigger workflows on chat events.
