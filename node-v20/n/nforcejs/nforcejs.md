# nforcejs

> 标签: api, database.com, force.com, forcedotcom, rest, salesforce, salesforce.com, sfdc

## 简介

(fork from kevinohara80) - nforcejs is a REST API wrapper for force.com with minor fixes and updated version of nforce, database.com, and salesforce.com
