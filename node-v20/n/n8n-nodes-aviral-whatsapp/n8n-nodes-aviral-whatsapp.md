# n8n-nodes-aviral-whatsapp

> 标签: aviral, n8n-community-node-package, whatsapp, whatsapp-business

## 简介

n8n community nodes for the WhatsApp Business Platform by Aviral Techlab: send messages and templates, manage contacts and conversations, trigger automations, and react to WhatsApp events.
