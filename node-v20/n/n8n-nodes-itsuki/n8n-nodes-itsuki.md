# n8n-nodes-itsuki

> 标签: agent, ai, itsuki, memory, n8n-community-node-package

## 简介

Itsuki memory for n8n workflows and AI Agents: save durable facts, recall them in any later run, and hand memory to an AI Agent as a tool.
