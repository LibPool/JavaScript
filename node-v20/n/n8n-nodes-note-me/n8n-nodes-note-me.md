# n8n-nodes-note-me

> 标签: automation, n8n-community-node-package, note-taking, noteme, notes, productivity, reminders, task-management

## 简介

n8n community node for NoteMe - automate note creation and reminders. Capture notes from workflows, set date-time reminders, organize with tags, and sync to mobile app.
