# nestjs-eureka-grpc-connector

> 标签: eureka, grpc, load-balancing, microservices, nestjs, netflix-eureka, service-discovery, typescript

## 简介

A NestJS module for seamless integration between Eureka service discovery and gRPC clients with automatic service registration, load balancing, and direct Eureka client support
