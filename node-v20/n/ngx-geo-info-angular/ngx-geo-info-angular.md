# ngx-geo-info-angular

> 标签: Geo info, angular geo info, get user geo information for angular, tejas rana geo info, tejasrana95, user lat long

## 简介

A module which gives you GEO info of user 'latitude', 'longitude', 'accuracy', 'altitude', 'altitudeAccuracy', 'heading', 'speed', 'timestamp' and best of all it is AOT ready
