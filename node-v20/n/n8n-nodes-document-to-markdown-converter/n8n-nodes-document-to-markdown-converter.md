# n8n-nodes-document-to-markdown-converter

## 简介

n8n community node: convert PDF, scanned PDF (OCR), DOCX, PPTX, XLSX, EPUB and HTML to clean Markdown, text and table-aware RAG chunks with the Apify Document to Markdown Actor.
