# nxip-cli

> 标签: aws, azure, cidr, ip-address-management, ip-allocation, ipam, multi-cloud, network-automation, networking, subnet, terraform, vnet, vpc

## 简介

Scan AWS and Azure for overlapping CIDRs and wasted IP space across clouds, and manage IP allocation with plan/apply - no Terraform required
