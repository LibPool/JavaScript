# nzm

> 标签: NPM, registry

## 简介

NPM registry manager can help you easy and fast switch between different npm registries, now include: cnpm, taobao, nj(nodejitsu), rednpm, edunpm

## 官网

- 官网：https://github.com/HerbertKarajan/nzm
- 源码仓库：git+https://github.com/HerbertKarajan/nzm.git
- npm 页面：https://www.npmjs.com/package/nzm
