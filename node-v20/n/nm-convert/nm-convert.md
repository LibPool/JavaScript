# nm-convert

> 标签: Nirav-Mathukiya, cli, css, mathukiya, nirav, niravmathukiya, nm-tailwind, tailwind, tailwindcss, utility-classes

## 简介

A tool for converting a custom Tailwind-like JSON configuration file into a global CSS file and that is build because of tailwind v4 configurations not have option and the Manual writing configuration is a Time Consuming .
