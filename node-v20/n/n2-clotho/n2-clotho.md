# n2-clotho

> 标签: ai-governance, behavioral-contract, code-generation, compiler, mcp, multi-target, n2, state-machine

## 简介

Compiled instruction language for AI agents — Define, compile, and enforce rules that markdown can't. Includes WASM runtime.
