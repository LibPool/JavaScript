# npa-core

> 标签: JavaScript

## 简介

npm和yarn的算法是一致的， 即扁平化。 当`a`包依赖一个`b`包时, 会从顶层node_modules开始， 一直到`a`包的node_modules目录， 找到第一个不存在冲突的目录， 安装在此。
