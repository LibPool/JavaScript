# nuxt-bezier

> 标签: animations, bezier, blur, clip-path, css-transitions, dissolve, fade, nuxt, nuxt-module, push, rotate, scale, slide, transition-group, transitions, vue, vue-transitions, vue3, wipe, zoom

## 简介

A Nuxt module providing Vue 3 transition components with Bezier timing functions. Includes fade, dissolve, blur, scale, slide, push, wipe, rotate, zoom, and clip-path transitions.
