# nodejs-bca-scraper

> 标签: bankbca, bca, klikbca, mutasi, rekening, saldo

## 简介

Plugin untuk mendapatkan saldo terakhir dan mutasi rekening BCA via klikbca tanpa menggunakan official API dari Bank BCA.

- 源码仓库：https://github.com/apriady/nodejs-bca-scraper.git
