# ngx-mat-datetime-panel

> 标签: angular, angular-material, date-range, datepicker, datetime, material, timepicker

## 简介

Compact single-view date + time picker panel for Angular Material 21+, with built-in range mode. Generic over DateAdapter<D> — no moment/date-fns/luxon dependency.
