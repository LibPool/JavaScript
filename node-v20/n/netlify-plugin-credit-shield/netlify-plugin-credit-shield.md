# netlify-plugin-credit-shield

> 标签: billing, build, cli, credits, deploy, netlify, netlify-plugin

## 简介

Automatically cancels Netlify cloud builds to protect your 15-credit deployment balance. Includes CLI companion for local deploys, credit tracker, and GitHub Action.
