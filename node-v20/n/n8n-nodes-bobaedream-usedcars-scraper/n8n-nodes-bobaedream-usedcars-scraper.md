# n8n-nodes-bobaedream-usedcars-scraper

> 标签: apify, n8n, n8n-community-node-package, n8n-nodes, scraping

## 简介

Scrape Bobaedream (bobaedream.co.kr) used cars in Korea. Get price (KRW), year, mileage, fuel, transmission, plate number, seller phone, options, photos and description. Pay per result. No login needed.
