# node-red-contrib-timescaledb

> 标签: database, iot, mqtt, node-red, postgresql, time-series, timescaledb

## 简介

Node-RED nodes for writing data to TimescaleDB without SQL queries. Supports MQTT topic mapping and automatic data type detection.
