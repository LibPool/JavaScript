# npm5-git-publish

> 标签: bitbucket, enterprise, git, github, gitlab, npm, online, private, publish, registry, services, team

## 简介

NPM 5 compliant dev tool to publish an NPM package to a remote Git repository, instead of a registry or CDN of tarballs
