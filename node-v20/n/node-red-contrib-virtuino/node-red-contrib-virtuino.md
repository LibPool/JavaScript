# node-red-contrib-virtuino

> 标签: iot, modbus, mqtt, node-red, virtuino

## 简介

Node-RED nodes for Virtuino Cloud — publish/subscribe to your account's fields without typing MQTT topics, over one connection with a stable client ID.

## 官网

- 官网：https://virtuino.com/tutorials/get-started-nodered.html
- npm 页面：https://www.npmjs.com/package/node-red-contrib-virtuino
