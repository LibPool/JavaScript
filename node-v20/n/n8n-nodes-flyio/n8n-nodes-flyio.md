# n8n-nodes-flyio

> 标签: automation, cloud, containers, deployment, devops, edge-computing, firecracker, fly, fly.io, flyio, infrastructure, machines, microvm, n8n, n8n-community-node-package

## 简介

A comprehensive n8n community node for Fly.io providing 8 resources and 50+ operations for managing Fly Apps, Machines (fast-launching VMs), Volumes, Secrets, Certificates, IP Addresses, Organizations, and Regions through the Machines REST API and GraphQL
