# ng-easycommerce

> 标签: JavaScript

## 简介

- Precios de productos, líneas de carrito y resúmenes: se incorporan contratos explícitos de neto, impuesto y bruto, con fallback compatible para respuestas legacy. - Carrito, sidebar y checkout: descuentos de orden, cupones y envío seleccionan neto o bru
