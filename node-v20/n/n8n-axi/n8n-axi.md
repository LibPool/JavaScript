# n8n-axi

> 标签: agents, axi, cli, mcp, n8n, workflow-automation

## 简介

AXI-compliant CLI for n8n over the official n8n MCP server - search, inspect, run, test, publish, and manage workflows, executions, projects, data tables, and credentials. Spec axi/1.0-2026-07.
