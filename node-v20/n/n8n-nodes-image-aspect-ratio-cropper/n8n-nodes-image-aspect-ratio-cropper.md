# n8n-nodes-image-aspect-ratio-cropper

> 标签: aspect, aspect-ratio, automation, center-crop, cover, crop, cropper, editor, image, n8n, n8n-community-node-package, n8n-nodes, ratio, resize

## 简介

n8n community node for cropping images to exact aspect ratios using center-cover mode. Supports 10 common aspect ratios including 1:1, 16:9, 9:16, 4:3, 3:4, and more.
