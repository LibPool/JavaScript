# ngx-liquid-glazz

> 标签: angular, backdrop-filter, directive, frosted-glass, glassmorphism, ios, liquid-glass, refraction, ui

## 简介

Real iOS-style Liquid Glass (refraction, not just blur) for any Angular element via an SVG displacement filter directive.
