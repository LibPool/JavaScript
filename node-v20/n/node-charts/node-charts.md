# node-charts

> 标签: JavaScript

## 简介

NodeChart 是一个基于puppeteer的Node生成chart 图片的库，简单易用，扩展方便，内置了echarts 和 highcharts两种类型的图表库，使用者可根据自身需求灵活添加，配置非常方便。
