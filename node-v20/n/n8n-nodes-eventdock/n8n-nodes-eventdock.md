# n8n-nodes-eventdock

> 标签: eventdock, github, n8n, n8n-community-node-package, retry, shopify, stripe, twilio, webhook, webhook-reliability, webhooks

## 简介

EventDock community node for n8n — trigger workflows on reliable, retried, de-duplicated webhook deliveries. EventDock buffers your provider webhooks (Stripe, Shopify, GitHub, Twilio, or any generic source), retries failures with exponential backoff, hold
