# node-red-contrib-mqttssl

> 标签: mqtt, node-red, ssl, tls

## 简介

Based on node-red-node-mqtt. Contains in/out nodes that connect to brokers that allow unrestricted connections (clients do not need to supply the client certificates) using certificate based SSL/TLS encryption.
