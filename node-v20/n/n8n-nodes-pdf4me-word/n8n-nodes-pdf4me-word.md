# n8n-nodes-pdf4me-word

> 标签: automation, documents, docx, n8n, n8n-community-node-package, office, pdf4me, watermark, word

## 简介

n8n community node for Word document processing with PDF4me API: watermarks (text/image), extract metadata, optimize, compare, split/merge, delete pages, secure, update TOC, replace text, headers/footers
