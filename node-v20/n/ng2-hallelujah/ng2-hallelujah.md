# ng2-hallelujah

> 标签: Angular 2, HAL, REST, Spring, Spring Data Rest, hypermedia

## 简介

Hallelujah! This Angular module offers a HAL/JSON http-client to easily interact with a Spring Data Rest API or any API that implements the Spring Data Rest resource model
