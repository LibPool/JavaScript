# n8n-nodes-formfeed

> 标签: formfeed, n8n, n8n-community-node-package, pdf, pdf-generation, template

## 简介

n8n community node for Formfeed: render PDFs and images from templates, wait for async renders and react to render webhooks.

## 官网

- 官网：https://docs.formfeed.dev/integrations/n8n
- 源码仓库：git+https://github.com/formfeed-dev/formfeed.git
