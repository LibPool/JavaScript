# noa-mcp-proxy

> 标签: ai-agent, governance, mcp, model-context-protocol, provenance, proxy, receipt

## 简介

Transparent MCP proxy-middleware: sits between an MCP host and an EXISTING, unmodified downstream tool server, dynamically reflects its tool surface, and gates every tools/call through noa-mcp-adapter-core's preCheck before forwarding — fail-closed on DEN
