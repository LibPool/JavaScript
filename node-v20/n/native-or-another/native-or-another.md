# native-or-another

> 标签: any, any-promise, autoload, bluebird, common, common-promise, ecma, ecmascript, es2015, es2017, es6, load, load-promise, loading, native, native-promise, promise, promises, register, register-promise, registration, specification

## 简介

Guaranteed way for getting a Promise. Always native Promise if available, otherwise looks for common promise libraries and loads which is installed. Allows registering custom Promise implementation in node < 0.12 versions
