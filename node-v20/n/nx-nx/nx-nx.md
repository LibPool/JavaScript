# nx-nx

> 标签: cli, generator, nx, scaffold, web-panel

## 简介

nx 系列项目生成器 — 把 server-cli-web 骨架物化成项目：CLI 与 Web 面板同源，提供 JS 与 TypeScript 两套模板（TS 模板带编译期类型安全）
