# n8n-nodes-macadress

> 标签: device-fingerprint, enrichment, mac-address, mac-vendor, macadress, n8n, n8n-community-node-package, oui

## 简介

n8n community node for macadress.com: enrich a MAC address with its IEEE-registered vendor, an inferred device category, virtualization / special-use classification and MAC-randomization confidence.
