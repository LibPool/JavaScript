# n8n-nodes-xlsx

> 标签: excel, exceljs, n8n, n8n-community-node-package, spreadsheet, xlsx

## 简介

n8n community node to read, write and style XLSX files entirely in memory (binary in / binary out), inspired by the Google Sheets node.
