# node-image-farmer

> 标签: connect, content-aware, crop, express, imagemagick, middleware, photos, resize, smartcrop, thumb, thumbnail

## 简介

Image thumbnailing middleware based on connect-thumb. Adds ability to retrieve files from the filesystem.
