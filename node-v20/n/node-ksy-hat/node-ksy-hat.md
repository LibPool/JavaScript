# node-ksy-hat

> 标签: KSY, Raspberry Pi, Sensor, Smart Remote Control HAT

## 简介

node-ksy-hat は KSY 社の Raspberry Pi 向けマルチセンサー HAT「Smart Remote Control HAT」を制御および計測値を取得するモジュールです。

- 源码仓库：git+https://github.com/futomi/node-ksy-hat.git
- npm 页面：https://www.npmjs.com/package/node-ksy-hat
