# nukeport

> 标签: dashboard, devtools, gui, kill, kill-port, lsof, monitor, netstat, node, port, ports, process, system-monitor, terminal, tui

## 简介

A beautiful terminal GUI to inspect listening ports, find which project owns each port, kill processes, and monitor your system in real time.
