# node-milight-promise

> 标签: LED, Milight, SmartHome, WifiLight

## 简介

A node module to control Milight LED bulbs and OEM equivalents auch as Rocket LED, Limitless LED Applamp, Easybulb, s`luce, iLight, iBulb, and Kreuzer
