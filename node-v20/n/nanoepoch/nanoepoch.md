# nanoepoch

> 标签: CLOCK_REALTIME, GetSystemTimePreciseAsFileTime, bigint, clock_gettime, epoch, hrtime, nanosecond, timestamp, unix-time, wall-clock

## 简介

Nanosecond Unix-epoch timestamps read fresh from the OS realtime clock on every call, returned as a BigInt.
