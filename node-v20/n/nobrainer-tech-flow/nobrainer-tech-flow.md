# nobrainer-tech-flow

> 标签: agent-skills, agentic-workflows, claude-code, codex, cursor, gemini-cli, multi-agent, opencode, pi-package, spec-driven-development, verification

## 简介

From task to done. nobrainer-tech-flow is one workflow of 18 modules for AI coding agents: it scopes the task, delegates ready work, checks the result and hands over the evidence, including what was not checked.
