# n8n-nodes-condoc

> 标签: automation, condoc, document-processing, n8n, n8n-community-node-package, ocr, thai

## 简介

n8n community node for ConDoc — a multi-tenant document processing and OCR platform. Automate OCR extraction, simple OCR with field mapping, and document management.
