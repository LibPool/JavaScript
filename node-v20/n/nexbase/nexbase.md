# nexbase

> 标签: api, crud, fastify, filtering, framework, pagination, postgres, rest

## 简介

Declarative CRUD framework for Fastify + Postgres. One resource definition → full REST API with filtering, sorting, search, pagination, exports, multi-tenancy and hooks. Zero dependencies.
