# nodejs-line-notify

> 标签: JavaScript, LINE, LINE Notify, Node.js, notification

## 简介

โมดูลนี้ให้บริการการจัดการ LINE Notify API ใน Node.js อย่างง่าย ๆ ทำให้คุณสามารถส่งข้อความและไฟล์ไปยัง LINE Notify ได้โดยง่าย
