# @getly/mcp

> 标签: claude, cursor, digital-products, ecommerce, getly, mcp, model-context-protocol

## 简介

MCP server for Getly — let Claude, Cursor and other AI assistants run your digital-products store (products, blog, coupons, checkout links, licenses, orders, Getly Billing).
