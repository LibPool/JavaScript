# @tc-libs/core

> 标签: JavaScript

## 简介

Libreria umbrella che aggrega il kernel condiviso delle `tc-libs-nestjs` (REST + Mongo + auth/access + observability + file/storage) in un unico modulo `CoreModule.forRootAsync`.
