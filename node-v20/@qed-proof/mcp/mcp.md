# @qed-proof/mcp

> 标签: ai-agents, mcp, model-context-protocol, qed-proof, receipts, verification

## 简介

QED Proof as an MCP server: submit an AI agent's claim, read the verdict QED Proof reached by checking the destination, and verify a signed receipt offline.
