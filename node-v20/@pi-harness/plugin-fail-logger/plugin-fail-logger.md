# @pi-harness/plugin-fail-logger

> 标签: cordis, pi-harness, pi-harness-plugin, plugin

## 简介

Aggregate bounded extension, Agent, and non-aborted compaction failures through descriptor-safe event inspection, safe diagnostic summaries, and occurrence counts without retaining full payloads.
