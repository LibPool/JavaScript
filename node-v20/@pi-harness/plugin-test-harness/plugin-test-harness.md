# @pi-harness/plugin-test-harness

> 标签: cordis, pi-harness, pi-harness-plugin, plugin

## 简介

Run five fixed npm script names from a trusted workspace, reporting real status with a sanitized 12 KiB UTF-8-safe untrusted output tail, a bounded configurable timeout, and cancellable process-tree cleanup.
