# @cyberion/tapal-adapters-outlook

> 标签: applescript, com, email, jxa, mail, mcp, model-context-protocol, outlook, outlook-mac, outlook-windows, tapal, tapal-adapter, winax

## 简介

Tapal Outlook adapter — local desktop scripting (macOS AppleScript + Windows COM) for the Tapal MCP server. No cloud APIs (per ADR 0006).
