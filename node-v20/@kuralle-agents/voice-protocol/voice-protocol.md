# @kuralle-agents/voice-protocol

> 标签: cloudflare-voice, kuralle, voice, wire-protocol

## 简介

Canonical client-server wire protocol for Kuralle voice transports. Pure TypeScript types + optional Zod schemas, zero runtime.
