# @jannchie/icons-vue

> 标签: component, icons, line-icons, svg, vue, vue3

## 简介

Vue 3 component for Jannchie Icons: one <JIcon> for every icon, with app-wide radius and weight defaults, pixel hinting and duo-tone colors
