# @fimagine/writeboard

> 标签: canvas, drawing, handwriting, typescript, whiteboard, 画板, 白板

## 简介

Extensible whiteboard for writing, with zero runtime dependencies. 可扩展的书写用白板，不依赖任何第三方库。
