# @glyphcss/maps

> 标签: ascii, gis, glyphcss, maps, raster, ssg, static

## 简介

Geographic raster data → glyphcss. Deterministic sample/classify/compile pipeline for baking a georeferenced field to static ASCII, with zero runtime.
