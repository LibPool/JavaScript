# dsh-idea-mcp

> 标签: cordis, dsh, dsh-plugin, idea, intellij, jetbrains, mcp

## 简介

DSH IDEA 工具：把 IntelliJ IDEA 的 MCP 能力（符号搜索、静态检查、调用层次、构建、Git、数据源、调试器）包装成一组一等公民 agent 工具，跨工程自动解析 projectPath
