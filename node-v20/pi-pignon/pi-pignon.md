# pi-pignon

> 标签: jev, laya, llm, llm-router, model-routing, pi-coding-agent, pi-extension, pi-package

## 简介

Pi coding agent extension that shifts to the right LLM for each prompt, using a local (Laya) or remote (Jev) decision model to judge task difficulty
