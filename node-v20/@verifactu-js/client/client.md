# @verifactu-js/client

> 标签: aeat, facturacion, invoicing, mtls, soap, spain, tax, veri-factu, verifactu

## 简介

Envío de registros VERI*FACTU a la AEAT con certificado cliente (mTLS). Capa HTTP inyectable, Node por defecto. / Submission of Spanish VERI*FACTU records to the AEAT over mTLS. Injectable HTTP layer, Node by default.
