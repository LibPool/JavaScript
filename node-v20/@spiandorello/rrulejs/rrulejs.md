# @spiandorello/rrulejs

> 标签: calendar, dates, icalendar, recurrences, rfc, rfc5545, rrule, typed, typescript

## 简介

Hardened fork of rrule — JavaScript library for working with recurrence rules for calendar dates. DoS-resistant parser, iteration guards, and a typed Recurrence API with inclusive-day UNTIL semantics.
