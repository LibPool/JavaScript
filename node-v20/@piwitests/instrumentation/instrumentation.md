# @piwitests/instrumentation

> 标签: nitro, nuxt, piwi-dashboard, playwright, server-logs, test-results

## 简介

Nitro/Nuxt server plugin for sending backend logs to Piwi Dashboard via the X-Piwi-Logs response header
