# @kairotic/analysis

> 标签: analysis, chroma, kairotic, meyda, monitor, music, onset, pitch, transcription, web audio

## 简介

Kairotic analysis components: features~ (descriptors with Meyda), pitch~ (YIN), onset~, chroma~ spectrum~, transcribe (pitch~ into a freqt) and monitor (any stream of messages, drawn), from any signal or adc~ into messages and pictures
