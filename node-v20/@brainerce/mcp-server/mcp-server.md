# @brainerce/mcp-server

> 标签: ai, brainerce, claude-code, cursor, ecommerce, lovable, mcp, model-context-protocol, vibe-coding

## 简介

Framework-agnostic domain knowledge API for Brainerce. Provides SDK docs, types, business flows, critical rules, and store capabilities to AI tools like Lovable, Cursor, Bolt, v0, and Claude Code. Does NOT provide framework-specific boilerplate — clients
