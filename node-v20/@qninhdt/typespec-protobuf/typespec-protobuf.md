# @qninhdt/typespec-protobuf

> 标签: emitter, grpc, openlet, protobuf, typespec

## 简介

First-party Protobuf emitter for the openlet TypeSpec stack — ergonomic decorators, auto type mapping, cross-file imports, single-source @entity sharing with ent/sqlmodel, auto-generated buf configs.
