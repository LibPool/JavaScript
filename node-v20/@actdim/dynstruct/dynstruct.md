# @actdim/dynstruct

> 标签: architecture, clean-architecture, component-model, declarative, design-system, enterprise, event-driven, frontend-architecture, message-bus, microfrontends, mobx, modularity, react, state-management, type-safe, typescript, ui-framework

## 简介

Structure-first, type-safe component model for TypeScript and React apps with explicit dependency wiring and message bus communication.
