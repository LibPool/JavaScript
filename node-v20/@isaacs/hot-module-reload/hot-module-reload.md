# @isaacs/hot-module-reload

> 标签: JavaScript

## 简介

Gracefully reload your modules when they change. Only works with CJS, not ESM. Uses stat polling.

## 官网

- npm 页面：https://www.npmjs.com/package/@isaacs/hot-module-reload

- 1.0.0

## 获取地址

- npm 安装：`npm install @isaacs/hot-module-reload`
- npm registry：https://registry.npmjs.org/@isaacs/hot-module-reload
- Node 要求：>= 16
