# @calcom/embed-snippet

> 标签: JavaScript

## 简介

Vanilla JS embed snippet that is responsible to fetch @calcom/embed-core and thus show Cal Link as an embed on a page.

## 官网

- 源码仓库：https://github.com/calcom/cal.com
