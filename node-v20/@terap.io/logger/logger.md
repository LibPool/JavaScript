# @terap.io/logger

> 标签: JavaScript

## 简介

Common wrapper for Bunyan logger for Terap.io projects. Blabu originated. If you use logger.fatal it will send event to Sentry.

- 官网：https://gitlab.com/terapio/logger/-/blob/master/README.md
- 源码仓库：git+ssh://git@gitlab.com/terapio/logger.git
- npm 页面：https://www.npmjs.com/package/@terap.io/logger
