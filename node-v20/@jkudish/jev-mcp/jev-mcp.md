# @jkudish/jev-mcp

> 标签: ai, guardrails, jev, mcp, model-context-protocol, semantic-search, system-one, typesafe, verification

## 简介

MCP server exposing TypeSafe Jev as purpose-built judgment tools: verify claims, screen for injection, find, rerank, classify, decide, compare passages, extract fields, review patches, and gate completion claims, each with typed probabilities.
