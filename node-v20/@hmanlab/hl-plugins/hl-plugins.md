# @hmanlab/hl-plugins

> 标签: MiniMax, cli, image-generation, installer, mmx, multimodal, music-generation, opencode, opencode-plugin, plugin, text-to-speech, token-plan, video-generation

## 简介

One-command installer for curated OpenCode plugins. Adds image, video, music, and speech generation to your coding agent without leaving the chat. MIT, no telemetry.
