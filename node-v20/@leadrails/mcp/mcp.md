# @leadrails/mcp

> 标签: ai, claude, lead-routing, leadrails, mcp, model-context-protocol

## 简介

Model Context Protocol (MCP) server for LeadRails. Lets MCP-aware agents (Claude Desktop, Claude Code, Cursor, …) read and manage sources / destinations / routes / events through your LeadRails workspace.
