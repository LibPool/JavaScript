# @excaliwow/mcp

> 标签: agents, ai, diagrams, excalidraw, excaliwow, mcp, model-context-protocol

## 简介

Excaliwow Model Context Protocol (MCP) server — lets AI agents create, read, render, and edit Excaliwow diagrams over the public REST API, via stdio.
