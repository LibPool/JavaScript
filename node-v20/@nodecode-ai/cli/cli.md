# @nodecode-ai/cli

> 标签: JavaScript

## 简介

This directory contains the small Node.js launcher that makes the native `nodecode` Rust binary runnable via `npm`, `npx`, `bun`, and `bunx`.

## 官网

- 官网：https://github.com/nodecode-ai/nodecode
- 源码仓库：git+https://github.com/nodecode-ai/nodecode.git
- npm 页面：https://www.npmjs.com/package/@nodecode-ai/cli
