# @yeliu84/pi-model-router

> 标签: coding-agent, extension, llm, model-router, pi, pi-package

## 简介

Smart per-turn model router for Pi that optimizes your AI budget and usage limits by dynamically switching LLM tiers based on task complexity, budget, and phase awareness.
