# @drzl/generator-forms

> 标签: codegen, drizzle, drizzle-orm, forms, react-hook-form, tanstack-form, validation

## 简介

Generate react-hook-form resolvers, TanStack Form options and per-field input metadata from a Drizzle schema, with the min, max, maxlength and pattern the column really has.
