# @drzl/generator-openapi-fetch

> 标签: client, codegen, drizzle, drizzle-orm, fetch, openapi, openapi-fetch

## 简介

Generate a typed openapi-fetch client from a Drizzle schema, with the paths type derived from the same document DRZL emits so the two cannot disagree.
