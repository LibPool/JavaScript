# git-meta-up

> 标签: azure-devops, bitbucket, cnb, codeup, git, git-url, gitea, gitee, github, gitlab, remote

## 简介

Resolve Git remote URLs to their hosting provider and build web links for repositories, branches, tags, commits and comparisons.
