# @pallamart/pm-jev

> 标签: JavaScript

## 简介

Standalone Jev AI (TypeSafe, model `jev-latest`) client for Pallamart. Jev decides first; keywords are the fallback; then a default. It has no `@pallasoft/*` dependency; the only runtime dependency is `@pallamart/pm-utilities`.
