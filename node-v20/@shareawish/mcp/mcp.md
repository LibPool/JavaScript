# @shareawish/mcp

> 标签: affiliate, claude, creator, cursor, ecommerce, mcp, model-context-protocol, shareawish, shopify, wishlist

## 简介

MCP servers for Share a Wish: build creator shops (lists, products with affiliate links, videos) and integrate the wishlist basket/save button (API keys, basket configs, snippets) from Claude, Cursor, Copilot and other MCP clients.
