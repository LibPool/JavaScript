# wiki-plugin-aether

> 标签: aether, audio, federated-wiki, fedwiki, web-audio, wiki-plugin

## 简介

Federated Wiki plugin — plays one Aether node (.aethernode) in the page, its code held in a sandboxed frame; pages side by side in the lineup play together
