# @thomas-labs/ai-mcp

> 标签: JavaScript

## 简介

Sync MCP server configs (Claude Code, Codex CLI, Gemini CLI, DeepSeek Harness) across machines via a private GitHub repo, age-encrypted at rest — npm wrapper around the ai-mcp Go CLI; postinstall downloads the matching prebuilt binary from GitHub Releases
