# ng2-konva

> 标签: JavaScript

## 简介

Angular components for the Konva 2d canvas library. Build interactive graphics, design editors, and whiteboards in Angular.

- 源码仓库：git+ssh://git@github.com/konvajs/ng2-konva.git
