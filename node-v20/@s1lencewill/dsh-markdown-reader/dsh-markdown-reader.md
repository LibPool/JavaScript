# @s1lencewill/dsh-markdown-reader

> 标签: deepseek-harness, dsh-plugin, katex, markdown, mermaid

## 简介

DSH Web GUI 全屏 Markdown 阅读器插件：GFM、KaTeX、Mermaid、目录与阅读进度、外部文件变更同步、图片/代码/表格/长章节增强，以及打印与另存 PDF。工作区门禁的只读路由；零构建、零运行时依赖。
