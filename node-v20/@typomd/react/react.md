# @typomd/react

> 标签: editor, markdown, milkdown, prosemirror, react, slash-commands, typora, wysiwyg

## 简介

React WYSIWYG Markdown editor: toolbar, floating selection bar, slash menu. Typora-like editing with GFM, math, Mermaid, and Shiki.
