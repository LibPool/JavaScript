# @systemfsoftware/stryker-test-contribution

> 标签: evaluator, mutation-testing, stryker, stryker-mutator, test-contribution, test-quality

## 简介

Stryker evaluator addon that fails a run when a required test file kills no mutant that another test file does not also kill.
