# @systemfsoftware/stryker-js-angular

> 标签: angular, framework, html, mutation-testing, plugin, stryker, stryker-mutator, vue

## 简介

Stryker framework plugin for Angular and Vue templates: claims .html, .htm, and .vue files and instruments their embedded script regions, never template expressions.
