# @systemfsoftware/stryker-ignorer-interface

> 标签: ast, estree, ignorer, mutation-testing, plugin, stryker, test-quality

## 简介

The ignorer interface for StrykerJS-style mutation tooling — the Ignorer descriptor, the canonical AST node vocabulary, and the walker types. Types only, with no runtime exports and no Effect dependency.
