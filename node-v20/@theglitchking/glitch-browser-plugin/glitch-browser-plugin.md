# @theglitchking/glitch-browser-plugin

> 标签: browser, cdp, chrome-devtools-protocol, claude-code, frontend, mcp, playwright, plugin, remote-development, ssh-tunnel

## 简介

Let Claude Code drive your real local browser (which you also see and control) for frontend troubleshooting, over a CDP-over-SSH reverse tunnel.
