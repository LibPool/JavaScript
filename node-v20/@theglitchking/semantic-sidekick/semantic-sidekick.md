# @theglitchking/semantic-sidekick

> 标签: ai, claude, embeddings, knowledge-graph, llm, markdown, mcp, model-context-protocol, notes, obsidian, semantic-search, vault, vector-search, wikilinks

## 简介

Activation, mode-routing, and capture layer on top of semantic-pages. Turns a retrievable markdown vault into a present one — auto-fires during work, matches the situation (research vs code vs outage), and forces capture at transitions.
