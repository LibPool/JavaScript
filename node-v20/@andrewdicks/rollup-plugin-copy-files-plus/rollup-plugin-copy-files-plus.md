# @andrewdicks/rollup-plugin-copy-files-plus

> 标签: copy, copyPlus, glob, rollup, rollup-plugin

## 简介

Rollup plugin to copy all files/folders matching a glob.  Supports flattening, text replacement and renaming during packaging.
