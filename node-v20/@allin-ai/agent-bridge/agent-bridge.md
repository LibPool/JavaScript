# @allin-ai/agent-bridge

> 标签: agent, bridge, daemon, downlink, hub, sdk, websocket

## 简介

Standalone agent-client bridge SDK: register/heartbeat with a hub, receive downlink tasks, run platform agents via host ports, and report events upstream.
