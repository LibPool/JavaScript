# sikuwa

> 标签: apime, evolution-api, fonnte, gateway, openwa, sdk, waxum, whatsapp, whatsapp-api, whatsapp-gateway, wuzapi, wwebjs

## 简介

SDK multi-gateway WhatsApp untuk JavaScript/TypeScript — satu antarmuka untuk Fonnte, OpenWA, ApiMe, Evolution API, Wuzapi, Wwebjs, dan Waxum. Porting dari paket PHP mdestafadilah/sikuwa, tanpa dependensi runtime.
