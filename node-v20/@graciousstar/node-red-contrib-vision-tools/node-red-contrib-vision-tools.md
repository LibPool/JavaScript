# @graciousstar/node-red-contrib-vision-tools

> 标签: aoi, barcode, calibration, caliper, checkerboard, code128, datamatrix, edge-detection, golden-template, image, inspection, line-finder, machine-vision, node-red, opencv, qc, qr, resize, sharp, vision

## 简介

Machine-vision nodes for Node-RED on a fixed camera rig: golden-template AOI with position and blemish tolerances, mm/px calibration and camera perspective from a checkerboard, deskew-and-crop of a physical label, caliper edge and line finding over a draw
