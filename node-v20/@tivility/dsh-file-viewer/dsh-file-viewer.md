# @tivility/dsh-file-viewer

> 标签: deepseek-harness, dsh-plugin, file-browser, markdown, readonly

## 简介

Read-only browser preview of DeepSeek Harness workspace files: directory listings, rendered Markdown, inline media, and raw bytes.
