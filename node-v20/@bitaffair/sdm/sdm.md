# @bitaffair/sdm

> 标签: AN12196, nfc, ntag424dna, nxp424dna

## 简介

A JavaScript library for handling nfc-sdm (NXP424dna) parameters based on [AN12196](https://www.nxp.com/docs/en/application-note/AN12196.pdf) specs.
