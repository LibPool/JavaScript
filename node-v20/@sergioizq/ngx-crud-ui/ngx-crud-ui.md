# @sergioizq/ngx-crud-ui

> 标签: angular, crud, ngrx-signals, primeng, ui-components

## 简介

PrimeNG components (table + mobile dataview, toasts, confirmations, skeletons, help glossary) that turn a CrudListConfig plus a @sergioizq/ngrx-crud-store store into a full CRUD list screen.
