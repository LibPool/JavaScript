# @blazefw/vite-plugin

> 标签: JavaScript

## 简介

BlazeFW Vite plugin — intercepts .blazefw.tsx files and routes them through the Rust compiler binary via stdin/stdout JSON bridge, splitting each file into server and client bundles automatically
