# rasso-plugin-varname-translator

> 标签: camelcase, pascalcase, plugin, rubick, translator, utools, variable-naming, varname

## 简介

Sub-Input 模式中文变量命名插件，支持小驼峰 (camelCase) / 大驼峰 (PascalCase) / 下划线 (snake_case) / 中横线 (kebab-case)，内置词库与同义词笛卡尔积装配
