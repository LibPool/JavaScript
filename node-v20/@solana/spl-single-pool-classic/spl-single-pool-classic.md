# @solana/spl-single-pool-classic

> 标签: JavaScript

## 简介

A TypeScript library for interacting with the SPL Single-Validator Stake Pool program, targeting `@solana/web3.js` 1.x. **If you are working on the new, bleeding-edge web3.js, you want `@solana/spl-single-pool`.**
