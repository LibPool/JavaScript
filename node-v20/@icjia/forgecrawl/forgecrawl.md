# @icjia/forgecrawl

> 标签: claude, crawler, llm, markdown, mcp, playwright, readability, scraper, scraping, spa, turndown

## 简介

MCP web-scraping server for Claude Code — fetches URLs, runs Mozilla Readability, and returns clean Markdown optimized for Claude's context window. Works with SPAs via headless Chromium.
