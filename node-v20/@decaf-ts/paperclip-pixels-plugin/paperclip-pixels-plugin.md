# @decaf-ts/paperclip-pixels-plugin

> 标签: bridge, paperclip, pixel-agents, plugin, relay, worker

## 简介

Independent Paperclip plugin for the Paperclip <-> Pixel Agents bridge: Paperclip SDK worker, Pixel Office UI (page + sidebar), persistence, metrics, policy, snapshot/event normalization, reconciliation, and the outbound feed mapper + retry/observability
