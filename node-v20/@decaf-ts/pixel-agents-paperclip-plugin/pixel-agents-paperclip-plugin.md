# @decaf-ts/pixel-agents-paperclip-plugin

> 标签: feed, manifest, paperclip, pixel-agents, plugin

## 简介

Independent Pixel Agents plugin surface for the Paperclip <-> Pixel Agents bridge: manifest + lifecycle registration, the mountable `POST /api/plugin-feed` endpoint, idempotent feed-operation application, the WS4-A/WC4 appearance adoption, reverse-action
