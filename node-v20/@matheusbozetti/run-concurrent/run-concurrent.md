# @matheusbozetti/run-concurrent

> 标签: async, async-queue, await, batch, batch-processing, concurrency, concurrency-limit, concurrent, error-handling, nodejs, parallel, parallel-execution, promise, promise-all, promise-pool, rate-limit, task-queue, task-runner, throttle, typescript

## 简介

Run async functions concurrently with a concurrency limit. A lightweight, type-safe alternative to Promise.all for batch processing and parallel task execution.
