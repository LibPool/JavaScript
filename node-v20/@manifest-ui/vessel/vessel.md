# @manifest-ui/vessel

> 标签: JavaScript

## 简介

Pre-packaged configs for the Babel, ESLint, Jest, Prettier, and TypeScript drivers and developer tools. Inspired by [@beemo/dev](https://github.com/beemojs/dev).
