> 标签: accessibility, aria, dialog, disclosure, focus-trap, headless-ui, modal, popover, toast, tooltip, typescript

## 简介

Headless browser UI primitives (toast, tooltip, popover, popup, dialog, modal, ask, disclosure, focus-trap, roving-focus, theme, view-transition, announce, skeleton) with behavior + accessibility + a documented CSS class/custom-property contract. Consumin
