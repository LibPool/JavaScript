# @cella-lang/cpp

> 标签: c++, cella, formal-verification, integer, proof

## 简介

A formally verified C++ subset for the Cella proof checker: integer types with C++ promotions and conversions (LP64 / AVR), control flow with small-step semantics, iostream, arrays, vector, sort, and standard containers — compiled module pack.
