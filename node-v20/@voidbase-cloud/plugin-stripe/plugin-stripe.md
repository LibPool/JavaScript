# @voidbase-cloud/plugin-stripe

> 标签: cloudflare-workers, payments, stripe, voidbase, voidbase-plugin

## 简介

The stripe plugin of voidbase. Taking money through Stripe: provides payments@1 with Stripe's REST API, its signed webhooks and the shared payment rows
