# @crvouga/mockingbird-openapi-metadata

> 标签: extensions, mockingbird, openapi

## 简介

Mockingbird's x-mockingbird-* OpenAPI extensions: types, readers, semantic validation and schema-guided value annotation (identities, volatile fields).
