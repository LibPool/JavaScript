# @crvouga/mockingbird-service-stripe

> 标签: billing, checkout, mockingbird, payments, service, stripe, webhooks

## 简介

Stateful mock of the Stripe API (accounts by key, customers, payments, subscriptions with renewals, invoices, checkout with a hosted page, a Stripe.js stand-in, signed webhooks) at API versions 2024-06-20 and 2025-02-24.acacia, verified by differential pr
