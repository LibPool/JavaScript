# @crvouga/mockingbird-openapi

> 标签: json-schema, mockingbird, openapi

## 简介

OpenAPI 3.1 loading, $ref resolution, operation discovery, schema traversal and instance validation for Mockingbird. No fast-check, no Hono, no providers.
