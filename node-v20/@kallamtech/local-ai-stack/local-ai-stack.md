# @kallamtech/local-ai-stack

> 标签: electron, local-first, offline, ollama, pgvector, postgres, postgrest, redis, sidecar, whisper

## 简介

Run Postgres+pgvector, PostgREST, Redis, Ollama and whisper.cpp as native sidecars inside an Electron (or Node) app — no Docker.
