# @knight-lab/googledrive2jekyll

> 标签: JavaScript

## 简介

Grabs images and Google Docs in a designated folder marked up with ArchieML and turns them into Jekyll post files.

- 官网：https://github.com/NUKnightLab/GoogleDocs2Jekyll#readme
