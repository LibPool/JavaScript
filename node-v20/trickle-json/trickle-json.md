# trickle-json

> 标签: ai, anthropic, incremental, json, llm, openai, parser, partial-json, sse, stream, streaming, zod

## 简介

Incremental, typed, zero-dependency partial-JSON parser for LLM streams — get the best valid value out of JSON that is still arriving.
