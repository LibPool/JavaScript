# dsh-gemini-tool-schema

> 标签: cordis, deepseek-harness, dsh, function-calling, gemini, json-schema, mcp, openapi, plugin, tool-schema

## 简介

DeepSeek Harness plugin — normalize tool schemas into the strict OpenAPI 3.0 subset that Gemini function declarations accept (fixes HTTP 400 on MCP and built-in tools).
