# @codedesignplus/playwright-microservice

> 标签: api-testing, codedesignplus, dotnet, e2e, grpc, microservices, playwright, testing

## 简介

Shared Playwright utilities for testing CodeDesignPlus microservices — auth setup, API fixtures, cleanup tracker, MongoDB cleanup, and gRPC client factories.
