# @xmlvalid/sdk

> 标签: dtd, e-invoice, einvoicing, en16931, factur-x, peppol, relaxng, schematron, sdk, ubl, validation, validator, xml, xrechnung, xsd, zugferd

## 简介

TypeScript / JavaScript client for the xmlvalid API: validate XML and e-invoices (Peppol, XRechnung, Factur-X, UBL, CII) against XSD, DTD, RelaxNG and Schematron business rules.
