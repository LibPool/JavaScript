# @oribos/model-router

> 标签: agent-framework, ai-agents, llm, model-router, models-dev, typescript

## 简介

Oribos model-router capability package — route 'provider/model' strings to model instances against a models.dev-style catalog you paste in. Parse and resolve only; the provider packages and the catalog stay yours, and the core keeps no registry and no mag
