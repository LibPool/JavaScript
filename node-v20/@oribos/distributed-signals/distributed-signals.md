# @oribos/distributed-signals

> 标签: agent-framework, ai-agents, distributed-signals, leases, llm, pubsub, typescript

## 简介

Oribos distributed-signals capability package — cross-instance signals routing: the send primitives route over a shared PubSub, leases arbitrate idle wakes, in-memory defaults ship zero-dependency and any Redis-compatible client rides the structural subse
