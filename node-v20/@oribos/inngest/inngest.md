# @oribos/inngest

> 标签: agent-framework, ai-agents, durable-execution, inngest, llm, typescript, workflow

## 简介

Oribos inngest capability package — trigger-level durable execution: workflow start/resume ride Inngest trigger events, the walker and snapshot store stay in process (the snapshot remains the state truth), a crashed run is continued by the engine's retry
