# @aemvite/vite-plugin-glob

> 标签: aem, aemvite, clientlib, css, edge-delivery, glob, scss, vite, vite-plugin

## 简介

Vite plugin that expands glob specifiers inside .scss and .css files (replacement for glob-import-loader).
