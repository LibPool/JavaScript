# @hazeloft/insights

> 标签: analytics, beacon, browser, core-web-vitals, hazeloft, nextjs, privacy, react, web-vitals

## 简介

Privacy-first analytics and Core Web Vitals beacon for sites hosted on Hazeloft. Drop-in <HazeloftInsights /> React component, zero config, no cookies, no visitor identifiers.
