# @paneljs/mikroorm

> 标签: django-admin-alternative, express-admin, mikro-orm, mikroorm, mikroorm-admin, paneljs

## 简介

MikroORM adapter for PanelJS, a Django-style admin panel for Express and Node.js applications.
