# @nordio/mcp-updater

> 标签: auto-update, mcp, self-upgrade, semver, update

## 简介

Invocation-riding update-awareness for self-hosted MCP servers — a runtime-agnostic (node/bun) library that decides whether to notify or silently self-upgrade a source-run MCP server.
