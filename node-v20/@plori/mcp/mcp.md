# @plori/mcp

> 标签: ai-agents, claude, cursor, mcp, mcp-server, model-context-protocol, plori

## 简介

plori (plori.ai): a cloud AI agent with its own persistent environment - durable disk, real CLI tools, and memory. Stdio bridge to plori's hosted MCP server (https://api.plori.ai/mcp) for clients that don't speak remote MCP natively.
