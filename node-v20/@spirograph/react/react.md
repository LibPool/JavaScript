# @spirograph/react

> 标签: canvas, epitrochoid, generative-art, hypotrochoid, react, spirograph

## 简介

React components for Spirograph: a render-only <SpirographCanvas> and an animated, controllable <SpirographAnimated>, on @spirograph/core + @spirograph/canvas
