# @po-to/tomato-jquery

> 标签: JavaScript

## 简介

tomato-jquery是采用jquery作“适配层”来实现和扩展tomato，所以在学习本章之前，请先学习tomato和jquery框架

## 官网

- 官网：http://www.po-to.org
- 源码仓库：git+https://github.com/po-to/tomato-jquery.git
- npm 页面：https://www.npmjs.com/package/@po-to/tomato-jquery
