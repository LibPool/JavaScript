# @getnarro/atlas

> 标签: camera, developer-tools, infinite-canvas, presentation, prezi, react, zooming

## 简介

A spatial canvas for Narro — a camera path as text, one pure camera function over it, and scene providers a deck, a video and a web page all render the same way
