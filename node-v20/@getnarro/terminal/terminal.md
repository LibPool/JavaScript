# @getnarro/terminal

> 标签: asciicast, asciinema, developer-tools, gif, presentation, screencast, terminal, vhs

## 简介

Terminal playbooks for Narro — a text format for a terminal session, a screen that is a pure function of the frame number, and a renderer that draws it on a grid
