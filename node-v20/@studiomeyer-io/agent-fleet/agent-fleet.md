# @studiomeyer-io/agent-fleet

> 标签: ai-agents, autonomous-agents, claude, claude-code, code-analysis, mcp, multi-agent, orchestration, research

## 简介

Multi-agent orchestration framework for Claude Code CLI. Run agents in parallel (Conductor) or stateful workflows with crash-resume + Human-in-the-Loop (Conductor-LangGraph). Subscription-flat by default.
