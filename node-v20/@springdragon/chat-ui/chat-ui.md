# @springdragon/chat-ui

> 标签: typescript, ui-components, vue, vue3

## 简介

VueChatUI - 一个现代的 Vue 3 组件库，专为构建交互式聊天界面设计。结合 Vue 3 的响应式特性和高性能，提供了一套丰富、灵活且易于集成的聊天 UI 组件，适用于构建高度交互和定制化的聊天应用。
