# @thenavidm/mastodon-mcp

> 标签: activitypub, ai-agents, claude, claude-code, fediverse, llm-tools, mastodon, mcp, mcp-server, model-context-protocol

## 简介

MCP server for Mastodon and the fediverse. 60 tools for posting, editing, threads, five timelines, hashtags, lists, notifications and the social graph, with LLM-optimised output. One-command app registration. Works with Claude Code, Claude Desktop, Cursor
