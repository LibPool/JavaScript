> 标签: ai-agents, claude, claude-code, llm-tools, mcp, mcp-server, model-context-protocol, newsletter, substack, substack-api

## 简介

MCP server for Substack. 65 tools for drafts, posts, Notes, subscribers, analytics, tags, comments, the reader feed and researching other writers, with markdown that renders as real Substack formatting. Works with Claude Code, Claude Desktop, Cursor, Wind
