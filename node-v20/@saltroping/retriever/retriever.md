# @saltroping/retriever

> 标签: agent, automation, chatops, cli, cron, daemon, feishu, lark, personal-assistant

## 简介

Personal agent daemon: one chat surface, child sessions that return to the main agent, and scheduled wakeups; pluggable channel and agent adapters
