# @supersuit/journey

> 标签: firestore, journey, nextjs, supersuit, timeline

## 简介

Journey: a private timeline of days. Each person's machine contributes calls, photos, video, texts and shipped work to a day, an account is written from what is there, and anyone in the app can remove any item. Rules, a Firestore store, Next.js route hand
