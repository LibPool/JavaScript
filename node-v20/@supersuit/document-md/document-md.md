# @supersuit/document-md

> 标签: agents, document, frontmatter, hypercontext, markdown, records, supersuit

## 简介

A written standard for a document in a workspace's documents/ folder: a stamped markdown file whose YAML header names its standard and who it is for, with a checker and a byte-preserving stamp.
