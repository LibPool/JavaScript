# @supersuit/capture-connector

> 标签: capture, connector, contract, freedom, transcripts, validator

## 简介

The contract a capture connector honors (stage never file, dedupe by recording id, checkpoint only after staging, end with one CONNECTOR status line), as a validator, a CLI and TypeScript types, so a connector written anywhere can check itself.
