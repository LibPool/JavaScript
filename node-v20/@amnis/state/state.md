# @amnis/state

> 标签: data management, default data, javascript, mutations, schema, selection methods, state management, typescript

## 简介

An extensible JavaScript/TypeScript library for data management, providing well-defined data types, default data generation, schema definitions, and state mutation management with a variety of selection methods.
