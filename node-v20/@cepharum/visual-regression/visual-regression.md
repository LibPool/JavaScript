# @cepharum/visual-regression

> 标签: baseline, pixelmatch, playwright, qa, screenshot, testing, visual-regression

## 简介

Playwright-based visual regression QA for web applications: drive every view in a fixed-size browser, mock the backend from composable maps, capture screenshots and verify them against managed reference sets.
