# @srgssr/live-dvr-time-display

> 标签: player, video.js

## 简介

Live DVR Time Display is a component that overrides the default behaviors of the video.js `CurrentTimeDisplay` and `TimeTooltip` components, allowing to display the time corresponding to the position in the progress bar in a live stream with DVR.
