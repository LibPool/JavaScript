# @zkterm/zkstorage

> 标签: aes-256-gcm, circom, client-side-encryption, decentralized, encryption, file-storage, groth16, ipfs, pbkdf2, pinata, poseidon, privacy, secure-storage, snarkjs, zero-knowledge, zk-proof, zksnark, zkstorage, zkterm

## 简介

Privacy-first decentralized file storage with client-side AES-256-GCM encryption and Groth16 zkSNARK password proofs. Files never leave your browser unencrypted - only the password holder can decrypt.
