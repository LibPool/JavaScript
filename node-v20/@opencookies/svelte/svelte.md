# @opencookies/svelte

> 标签: JavaScript

## 简介

Svelte adapter for OpenCookies. Runes-first for Svelte 5; ships a `Readable<ConsentState>` fallback at `@opencookies/svelte/stores` for Svelte 4. Wraps [`@opencookies/core`](../core/).
