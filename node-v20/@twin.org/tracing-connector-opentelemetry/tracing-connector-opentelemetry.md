# @twin.org/tracing-connector-opentelemetry

> 标签: adapter, blockchain, connector, framework, integration, iota, observability, opentelemetry, otel, otlp, spans, tracing, trade, twin

## 简介

Exports spans to an OTLP compatible endpoint using OpenTelemetry for consumption by observability backends.
