# @subscraper/sdk

> 标签: JavaScript

## 简介

Official TypeScript SDK for the Reddit Scraping API. Search posts, scrape comments, pull subreddit data, and get user profiles.

## 官网

- npm 页面：https://www.npmjs.com/package/@subscraper/sdk

- npm registry：https://registry.npmjs.org/@subscraper/sdk
- Node 要求：>=18
