# @mariozechner/cc-antidebug

> 标签: anthropic, anti-debug, claude, claude-code, debug, debugging, sdk

## 简介

Disable Claude Code's anti-debugging so you can debug your NodeJS apps using the official Claude Code Typescript SDK.
