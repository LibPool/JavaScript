# dsh-restart-autostart

> 标签: autostart, daemon, deepseek-harness, dsh, guard, plugin, restart

## 简介

DSH 进程控制插件：设置面板标题栏的「重启」按钮（任何分页都能点，免滚动），以及「设置 → 通用」的「跟随系统启动」勾选框（写入 macOS launchd / Linux systemd / Windows 服务自启条目，开机拉起并在崩溃后自动重启）。
