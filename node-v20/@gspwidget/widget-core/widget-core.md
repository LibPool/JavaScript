# @gspwidget/widget-core

> 标签: JavaScript

## 简介

元部件接口工具，外部框架使用。 - Systemjs 的版本有坑，现在 widget core 用的版本是 systemjs@0.21.5，但 @>=2 版本与之前不兼容，暂时不能用新的。
