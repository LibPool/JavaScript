# @fonderie/react-native-workspaces

> 标签: fonderiejs, hooks, react-native, teams, typescript, workspaces

## 简介

React Native workspaces hooks for Fonderie — re-exports @fonderie/react-workspaces (no platform-specific code: no storage, no DOM/RN APIs).
