# @boytecht/threeengine

> 标签: 3d, browser, canvas, esm, javascipt, rendering, three.js, typescript, viewer, webgi, webgl

## 简介

ThreeEngine - A modern 3D viewer framework built on top of three.js, written in TypeScript, designed to make creating high-quality, modular, and extensible 3D experiences on the web simple and enjoyable.
