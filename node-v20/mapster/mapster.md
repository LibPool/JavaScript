# mapster

> 标签: antigravity, architecture, claude, code map, flow diagram, mcp, mcp-server

## 简介

Mapster: see your project as flow diagrams with the exact code behind every step. An MCP server for AI coding agents (Claude Code, Antigravity) plus a local viewer.
