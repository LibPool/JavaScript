# @converly/cli

> 标签: agent, attribution, claude-code, cli, converly, conversion-tracking, facebook-capi, ga4, google-ads, marketing, mcp, meta-ads, openclaw

## 简介

Command line tool for Converly conversion tracking. Set up server-side conversion tracking for Google Ads, Meta, GA4 and more from a terminal or an AI agent.
