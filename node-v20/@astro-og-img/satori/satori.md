# @astro-og-img/satori

> 标签: astro-integration, og-image, satori

## 简介

Satori-based renderer for [astro-og-img](https://www.npmjs.com/package/astro-og-img). Uses [Satori](https://github.com/vercel/satori) + [resvg-js](https://github.com/thx/resvg-js) + [Sharp](https://github.com/lovell/sharp).
