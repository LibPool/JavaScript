# @automatey-org/mcp

> 标签: JavaScript

## 简介

Provider-agnostic MCP helpers for the Vercel AI SDK: a Streamable-HTTP MCP client and a buildMcpToolSet() that exposes MCP tools as AI SDK tools with destructive-tool gating and call/result callbacks.
