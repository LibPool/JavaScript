# @5voltfx/design-system

> 标签: JavaScript

## 简介

A shared React component library and token system for the three 5VoltFX/Matt Welker sites — `song-chart`, `mattwelker.com`, and `5voltfx.com`. Plain React 19 and plain CSS custom properties, no UI framework.
