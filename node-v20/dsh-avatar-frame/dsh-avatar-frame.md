# dsh-avatar-frame

> 标签: avatar, deepseek-harness, dsh, dsh-plugin, text-to-speech, tts, tts-client

## 简介

Character avatar, editable ID and read-aloud beside every assistant reply — system voice or your own local TTS service, with tone and speed controls, presets, a playback bar, one-click launching of your own TTS process, and a Chinese/English UI switch.
