# @soldy-ui/theme-base

> 标签: css, soldy, theme, ui

## 简介

Общий слой тем Soldy UI: сброс частей библиотеки, знак направления письма и структура частей с числами в переменных — чистый CSS, без препроцессора, — и плагины раскладки для поведения темы
