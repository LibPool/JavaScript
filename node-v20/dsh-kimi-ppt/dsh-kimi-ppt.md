# dsh-kimi-ppt

> 标签: deepseek-harness, dsh, dsh-plugin, kimi, ppt, pptx, presentation, skill, slides

## 简介

DeepSeek Harness plugin that bundles the kimi-ppt skill: create, edit and export PPT / slides / presentations as a locally generated .pptx with Pillow-rendered previews, no browser needed.
