# @leetrout/jsongraph

> 标签: canvas, diagram, edges, erd, graph, json, nodes, typescript, visualization, zero-dependency

## 简介

Zero-dependency interactive node/edge graph renderer for the browser. Graph any JSON { nodes, edges } on a canvas — pan/zoom/drag, hover-to-highlight, PNG/SVG export.
