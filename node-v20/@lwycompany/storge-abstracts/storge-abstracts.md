# @lwycompany/storge-abstracts

> 标签: JavaScript

## 简介

App前端使用的数据存储服务,该服务使用[key,value]的数据结构存储数据 在js中，实现的方式通常有内存，localstorge或cookie ,对于一些固定的场景,比如localstorge,可直接存入数据, 对于需要存储策略的场景,可以使用CacheItem作为存储数据
