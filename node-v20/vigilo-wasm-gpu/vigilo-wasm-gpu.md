# vigilo-wasm-gpu

> 标签: browser, exam-integrity, face-detection, gaze-tracking, gpu, hardware-acceleration, head-pose, onnxruntime-web, proctoring, rust, stream-fusion, wasm, webassembly, webgpu

## 简介

High-performance GPU-accelerated in-browser exam proctoring: YuNet, head pose, gaze and prohibited-object detection with onnxruntime-web (WebGPU), fused by the vigilo-core temporal engine compiled to WebAssembly.
