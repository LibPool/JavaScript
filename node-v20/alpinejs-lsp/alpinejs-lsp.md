# alpinejs-lsp

> 标签: alpine, alpinejs, diagnostics, html, language-server, linter, lsp, opencode

## 简介

Alpine.js language server: diagnostics, completions, hover for x- directives in HTML. CLI linter + stdio LSP for opencode/IDE/CI.
