# @iaceene/device-detector

> 标签: browser, desktop, device, device-detector, device-type, lightweight, mobile, nextjs, nodejs, responsive, ssr, tablet, tv, typescript, ua, user-agent, zero-dependency

## 简介

A lightweight TypeScript utility that detects the device type from a user agent string and returns "mobile", "tablet", "desktop", or "tv".
