# nfxmap-graphql

> 标签: dataloader, distributed, fxmap, graphql, mapping, microservices, nfxmap

## 简介

GraphQL integration of nfxmap (FxMap for Node.js): resolves the mapped fields of a graphql-js schema, batched per query level
