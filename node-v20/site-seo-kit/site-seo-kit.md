## 简介

Pick-what-you-need SEO and GEO plumbing for static and Next.js sites: sitemap + routes manifest, robots.txt with AI-crawler policy, JSON-LD, Atom feed, llms.txt + Markdown pages, Google Indexing API and IndexNow submission, live GEO audit.
