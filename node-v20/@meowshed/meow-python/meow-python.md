# @meowshed/meow-python

> 标签: meowpaw, pi-package

## 简介

Detects a Python project from the pyproject.toml git tracks, reads the environment tool it declares, prints a stages table bound from the tools it configured and run through that environment, reports a stage that runs a tool outside the environment or let
