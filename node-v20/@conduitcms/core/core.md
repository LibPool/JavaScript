# @conduitcms/core

> 标签: JavaScript

## 简介

Conduit — an AI-first, code-first headless CMS. This is a name reservation for @conduitcms/core, the framework-agnostic core library that holds all real logic (collections, entries, validation, migrations, DB access). See scope.md.
