# @dotdance/dsh-skill-scope

> 标签: cordis, deepseek-harness, dsh, dsh-plugin, mcp, skill

## 简介

Skill and MCP visibility manager for DeepSeek Harness: the global layer sets a default, and each workspace can override any name both ways, with a sidebar panel and an input-card entry.
