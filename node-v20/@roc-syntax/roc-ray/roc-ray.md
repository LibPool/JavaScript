# @roc-syntax/roc-ray

> 标签: gamedev, raylib, roc, roc-ray, roc-syntax-mcp, roc-syntax-mcp-plugin

## 简介

The RocRay platform: a frame loop over raylib, with drawing, input devices, audio, assets, tilemaps, physics, tasks, declared permissions, files, HTTP, UDP, SQLite, commands, and capture.
