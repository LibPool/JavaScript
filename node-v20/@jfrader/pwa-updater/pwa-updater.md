# @jfrader/pwa-updater

> 标签: pwa, reload, service-worker, typescript, update, version-reload

## 简介

Zero-dependency PWA version-reload for small apps: new-deploy detection against /version.json, once-per-version prompt state, reload orchestration. Extracted from @jfrader/observability.
