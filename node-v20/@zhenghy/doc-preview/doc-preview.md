# @zhenghy/doc-preview

> 标签: binary-parser, browser, cfb, compound-file, doc, doc-preview, doc-viewer, document-parser, docx, docx-preview, docx-viewer, frontend, in-browser, microsoft-word, ms-word, no-backend, ole2, preview, pure-frontend, viewer, vue, vue-component, vue-plugin, vue3, word, word-parser, word-preview, word-viewer

## 简介

Vue 3 component for previewing Microsoft Word .doc files (OLE2/CFB) in the browser. Pure frontend, no server, no backend. Supports search, zoom, print, dark mode.
