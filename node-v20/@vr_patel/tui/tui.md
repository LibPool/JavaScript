# @vr_patel/tui

> 标签: ansi, cli, components, input, progress, select, spinner, table, terminal, tui, typescript, zero-dependency

## 简介

Zero-dependency TypeScript Terminal UI component library — spinners, progress bars, tables, inputs, and more, built entirely on ANSI escape codes.
