# @mongrov/core

> 标签: dev-tools, expo, logging, offline-queue, react-native, ring-buffer, structured-logging, webhook

## 简介

Structured logging for React Native / Expo — ring buffer, file, and webhook transports with offline queue. Includes dev-tools UI components.
