# @pmcollab/coworkstream-engine-msagent

> 标签: JavaScript

## 简介

Microsoft Agent Framework AgentRunner adapter for @pmcollab/coworkstream-engine. Wraps an in-process MAF agent (when available in JS) or an MAF-hosted HTTP endpoint.
