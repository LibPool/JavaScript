# @astrai/cosmix

> 标签: agents, ai, astrai, cli, coding-assistant, orchestrator

## 简介

Cosmix — terminal CLI for the ASTRAI-orchestrated coding studio. An Architect plans, Builders execute in parallel, a Reviewer checks the result — all from your terminal, billed to your own ASTRAI plan.
