# @galvanized-pukeko/vue-ui

> 标签: a2ui, ag-ui, agent, ai, chat, components, generative-ui, llm, vue, vue3

## 简介

Vue 3 component library that lets an LLM agent render real UI — chat, forms, charts, tables and interactive A2UI surfaces — over the AG-UI protocol.
