# @sisylabs/create-plugin

> 标签: create, scaffolder, sisyphus, sisyphus-plugin, template

## 简介

Scaffolder for Sisyphus plugins. Run `npm create @sisylabs/plugin@latest my-plugin` to get a working plugin skeleton in seconds.
