# @eva/react-eva-lottie

> 标签: dragonbone, eva, react, react-component, react-eva

## 简介

React EVA是一个让开发同学能够在React技术体系下，利用EVA JS的游戏研发能力，开发动画、游戏类场景的框架。它可以让开发同学用熟悉的JSX和Hooks语法编写动画、游戏场景的代码。
