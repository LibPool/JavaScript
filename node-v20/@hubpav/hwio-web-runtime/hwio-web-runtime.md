# @hubpav/hwio-web-runtime

> 标签: JavaScript

## 简介

Framework-free browser runtime for the HARDWARIO websites: consent (Consent Mode v2 + GTM), HubSpot forms with Turnstile, attribution, theme, CTA tracking and small behaviours. View-transition safe.
