# @wigtoken-temp/agent

> 标签: agent, anthropic, claude, claude-code, cli, telemetry, token-usage, wigtoken

## 简介

Cross-platform agent that watches Claude Code transcripts on a developer's machine and pushes new messages to a wigtoken server.
