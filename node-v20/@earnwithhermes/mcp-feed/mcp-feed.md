# @earnwithhermes/mcp-feed

> 标签: ai-agents, curation, feed, mcp, rss, toon

## 简介

MCP server for the Earn With Hermes daily feed — exposes TOON-format daily content as discoverable MCP resources for any MCP-compatible agent (Claude Desktop, Cursor, VS Code, Hermes, etc.)
