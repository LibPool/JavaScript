# @imenam/mcp-feature-analyzer

> 标签: agent, ai, code-review, diff, mcp, model-context-protocol, review

## 简介

MCP server that helps a human review a feature developed by an AI agent: summary, changed files, frozen diff, findings ranked by severity, diagrams, and structured feedback the agent reads back.
