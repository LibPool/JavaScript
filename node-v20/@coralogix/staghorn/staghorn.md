# @coralogix/staghorn

> 标签: dev-server, developer-experience, git-worktree, hosts-file, local-development, localhost, monorepo, multi-tenant, reverse-proxy, subdomain, vite, worktree

## 简介

Every git branch gets its own localhost hostname instead of a port, via one shared unprivileged reverse proxy. Zero dependencies, no sudo, no /etc/hosts, no config.
