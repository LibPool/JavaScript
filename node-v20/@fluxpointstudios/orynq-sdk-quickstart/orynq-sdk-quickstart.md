# @fluxpointstudios/orynq-sdk-quickstart

> 标签: ai-trace, cli, developer-experience, materios, orynq, quickstart

## 简介

Solo-developer quickstart for orynq — sub-5-minute first trace. Generates identity, faucet-drips MATRA, anchors a sample trace on Materios, prints an explorer URL.
