# @qti-editor/qti-roundtrip-import

> 标签: JavaScript

## 简介

Lossless QTI 3.0→ProseMirror roundtrip import. ONLY restores items previously written by @qti-editor/qti-roundtrip-export. NOT a generic QTI 3.0 importer. See ROUNDTRIP.md.
