# @blinkdiff/cli

> 标签: ci, expo, ios, macos, react-native, screenshot, visual-regression, xcuitest

## 简介

Per-build visual diffing for iOS and macOS apps, native or React Native. Drive declared flows through the accessibility tree, screenshot at checkpoints, diff against a baseline, report.
