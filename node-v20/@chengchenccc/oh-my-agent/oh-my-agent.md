# @chengchenccc/oh-my-agent

> 标签: JavaScript

## 简介

Oma 是本仓库自研的 Agent 执行引擎：既可**独立交互式 TUI**（默认 `oma` 进入终端界面），也可作为无 UI 的一次性 CLI 被 Product Backend 的 Adapter（`@chengchenccc/adapter-oma-agent`）按**每个 Agent Run** spawn 一次。
