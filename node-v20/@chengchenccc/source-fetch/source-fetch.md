# @chengchenccc/source-fetch

> 标签: JavaScript

## 简介

Shared mechanical capability for materializing external sources onto disk: git clone/checkout, zip extraction, and directory fingerprinting. No business semantics, no backend/oma coupling — consumed by both `apps/backend` skill-pack and `apps/oh-my-agent`
