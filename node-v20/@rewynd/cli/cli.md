# @rewynd/cli

> 标签: cli, debugging, devtools, mcp, observability, opentelemetry, otlp, tui

## 简介

A zero-config, OTLP-native flight recorder for your backend — a beautiful TUI, a JSON CLI, and an MCP server your coding agent can drive.
