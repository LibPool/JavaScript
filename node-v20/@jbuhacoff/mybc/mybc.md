# @jbuhacoff/mybc

> 标签: android, bc, bouncycastle, droidycastle, jca, jce, mybc, provider, sc, spongycastle, tool, util

## 简介

Automates custom packaging of BouncyCastle libraries for Android apps or other environments that include earlier versions of BouncyCastle that would conflict with the required version
