# @kervo-os/kervo

> 标签: agents, ai, claude, claude-code, cli, context, context-engineering, memory

## 简介

Deterministic context compiler for AI agents — compiles your repo into a trust-labeled Context Artifact injected into CLAUDE.md. Downloads the prebuilt kervo binary (checksum-verified) on first run; the npm version tracks the binary release tag.
