# @heinrichb/web-suite

> 标签: a11y, accessibility, check-primitives, crawler, design-tokens, e2e, mcp, perf-budget, playwright, visual-regression

## 简介

Config-driven Playwright + visual-regression harness for any website. Route-catalog discovery, reusable check primitives (a11y, broken-links, perf-budget, computed-style, visual-baseline), flow runner, edge-case generators, CLI, MCP server. Target-agnosti
