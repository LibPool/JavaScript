# @buckeyestudio/toh-permission-presets

> 标签: JavaScript

## 简介

User-facing permission presets (ctx.permissionPresets) for the TheOpen Harness: one product-level Permissions select bundling the sandbox-mode and approval-policy knobs, written through to their own session events
