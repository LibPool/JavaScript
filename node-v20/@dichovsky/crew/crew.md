# @dichovsky/crew

> 标签: agents, claude-code, cli, codex, coding-agents, coordination, copilot-cli, gemini-cli, inbox, sqlite, tmux

## 简介

Local coordination for terminal coding agents (Claude Code, Codex, Gemini, Copilot, Antigravity) via a workspace-local SQLite inbox and reviewed task workflow — no daemon, no model provider.
