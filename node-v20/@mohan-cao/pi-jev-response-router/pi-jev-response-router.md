# @mohan-cao/pi-jev-response-router

> 标签: classifier, jev, pi-extension, pi-package, response-router, typesafe-ai

## 简介

Pi extension that uses TypeSafe Jev to route each request into bounded verification, decomposition, or normal response policy.
