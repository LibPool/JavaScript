# @awesome-markdown/board-ui

> 标签: JavaScript

## 简介

The awesome-markdown board surface — board list, kanban board with filter-derived drag-and-drop, homeless panel, inline layout editing, item editor and sync-engine conflict resolution — as a router-agnostic React 19 library.
