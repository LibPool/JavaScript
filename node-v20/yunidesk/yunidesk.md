# yunidesk

> 标签: cloudflare-workers, helpdesk, intercom-alternative, live-chat, self-hosted, support

## 简介

Yunidesk client SDK core: types, the contact client (REST + realtime), identity tokens and webhook signatures for self-hosted Yunidesk support desks.
