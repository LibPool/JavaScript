# @croco/telemetry-api

> 标签: JavaScript

## 简介

애플리케이션 코드에서 사용하는 OpenTelemetry 추적 API입니다. SDK 초기화는 `@croco/telemetry-sdk-node`가 담당하고, 이 패키지는 Span 생성과 이벤트 기록을 담당합니다.
