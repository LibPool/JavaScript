# @havocrao/pickui

> 标签: filter, fzf, menu, picker, select, tui

## 简介

TUI candidate picker — TS/JS bindings for the pickui engine (protocol v1). Filter / pick / history / confirm, tree-shakable, same behavior as the Go engine.
