# @tsyche/membrane

> 标签: async, boundary, context, ddd, dto, immutable, interceptor, mapper, middleware, nestjs, pipeline, transform, type-safe, typescript

## 简介

Type-safe async before/after pipelines for TypeScript service boundaries — input enrichment, output mapping, request context, and enforced immutability. Zero dependencies.
