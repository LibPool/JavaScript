# @ksp-gonogo/kerbcast

> 标签: h264, kerbal-space-program, kerbcast, ksp, protocol, typeshare, webrtc

## 简介

TypeScript client for the kerbcast KSP camera-streaming sidecar. KerbcastClient wraps the WebRTC peer + control channel; wire-format types are typeshare-generated from the sidecar's Rust protocol module.
