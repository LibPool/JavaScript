# @batthewz/response-ui-css

> 标签: css, design-system, oklch, tailwind, tailwindcss-v4, themes, tokens

## 简介

Design tokens, a theme contract, responsive scales, and animations for the response-ui design system. Tailwind v4 CSS-first. The foundation layer, usable on its own.
