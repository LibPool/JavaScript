# @nodearchive/nodearchive

> 标签: archive, bun, cli, commonjs, esm, gzip, javascript, nar, node, tar, typescript, zip

## 简介

Pack and unpack nar, zip, tar, tgz, tar.gz, and gz archives from one API and CLI for Node.js and Bun.
