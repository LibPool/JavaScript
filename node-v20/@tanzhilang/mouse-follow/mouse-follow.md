## 简介

* 注意： * 对用户：Vue2使用自定义组件按需引入时，需要将组件在data中声明，Vue3则import即可 ```javascript import ChildrenCom from '@/components/ChildrenCom.vue' export default {   data(){     return{         ChildrenCom     }   } } ``` * 对开发：组件命名尽量以 Mouse 打头，以免造成组件冲突
