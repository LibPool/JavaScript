# @adep/client

> 标签: JavaScript

## 简介

AgentDeploy 实时客户端订阅库（RT-005）：换票→建连→订阅→断线自动重连→对称心跳。独立 npm 包，可被 FE-003 卡片渲染等非 Page 场景复用（见任务单 RT-005 归属裁定）。
