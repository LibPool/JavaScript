# @tuskcms/mcp

> 标签: claude, cms, headless-cms, mcp, model-context-protocol, tusk, tuskcms

## 简介

Model Context Protocol server for Tusk CMS: connect Claude Code or Codex to a Tusk studio and manage sites headlessly — create, scan, save fields, publish, check deploys — over a scoped personal access token.
