# dumbeditor-canvas

> 标签: JavaScript

## 简介

Installs the native canvas library DumbEditor uses to draw text as images on macOS and Linux. Windows skips it.

- 官网：https://github.com/shing1Sks/DumbEditor#readme
- 源码仓库：git+https://github.com/shing1Sks/DumbEditor.git
- npm 页面：https://www.npmjs.com/package/dumbeditor-canvas

- npm 安装：`npm install dumbeditor-canvas`
- npm registry：https://registry.npmjs.org/dumbeditor-canvas
- Node 要求：>=22.19.0
