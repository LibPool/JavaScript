# @kinetixui/ui

> 标签: components, design-system, kinetixui, radix-ui, react, tailwindcss, ui

## 简介

KinetixUI React components — CVA + Radix + Tailwind on the KinetixUI token contract. Also distributed via the kinetixui CLI as a component registry.
