# @lukealee/nuwa-cli

> 标签: agent-skills, claude-code, cli, codex, llm, nuwa, persona

## 简介

Command-line tool for distilling and chatting with anyone's cognitive operating system, powered by the Nuwa Skill — with long-term memory. English by default, switchable to Chinese.
