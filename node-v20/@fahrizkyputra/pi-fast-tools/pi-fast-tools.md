# @fahrizkyputra/pi-fast-tools

> 标签: codemode, grep, performance, pi, pi-extension, pi-package, timeout, tool-calls

## 简介

Fewer and faster tool calls for Pi: recursive grep skips node_modules/build output, tests and builds get a timeout, tsc gets a bigger heap, and the model is told to batch calls and use rg/fd. Optional codemode auto-enable.
