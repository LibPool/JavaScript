# n8n-nodes-twittrapi

> 标签: n8n, n8n-community-node-package, social media data, tweets, twitter api, twitter followers, twitter scraper, twitter search, twittrapi, x api

## 简介

n8n community node for TwittrAPI: read public Twitter/X tweets, profiles, followers and search results, and post, like, follow and send DMs from your own account. Pay as you go from $0.065 per 1,000 calls.
