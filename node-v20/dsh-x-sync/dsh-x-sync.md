# dsh-x-sync

> 标签: backup, deepseek-harness, dsh, dsh-plugin, s3, sync, webdav

## 简介

把 dsh 的会话记录、附件、插件配置、技能和记忆同步到 S3 兼容存储 / WebDAV / 本地目录 / 单个 ZIP：和 DSH-X 启动器共用同一只桶、同一套目录结构，双向并集合并、不丢插件。Sync DSH sessions, attachments, plugin config, skills and memory to S3-compatible storage / WebDAV / a local folder / a single ZIP — same bucket and layout
