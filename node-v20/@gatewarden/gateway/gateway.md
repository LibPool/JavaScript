# @gatewarden/gateway

> 标签: agent, capability, gateway, least-privilege, mcp, model-context-protocol, proxy, security

## 简介

MCP Gateway — one in-path proxy that scores a downstream MCP server and governs every tool call with capability leases. Fuses @gatewarden/score and @gatewarden/govern.
