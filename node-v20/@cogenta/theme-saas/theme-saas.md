# @cogenta/theme-saas

> 标签: JavaScript

## 简介

A B2B software theme for Cogenta: Geist and Geist Mono, white and a structured grey scale with one signal blue, framed product screenshots, a ruled plan comparison, a designed dark mode and zero client JavaScript.
