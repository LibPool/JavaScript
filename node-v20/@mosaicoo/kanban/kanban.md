# @mosaicoo/kanban

> 标签: angular, board, drag-and-drop, headless, kanban, mosaicoo, swimlane

## 简介

Flexible board engine and Angular UI for Kanban-style visual organization — configurable columns, swimlanes and dynamic grouping, with a headless zero-dependency core.
