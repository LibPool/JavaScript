# @iframely/embed.js

> 标签: embed, embed.js, embedjs, iframe, iframely, oembed

## 简介

Iframely embeds cloud JavaScript library, helps with rich media embed codes rendering for Iframely hosted iFrames. Library functions include unfurling URLs, lazy-loading, and rich-media events handling.
