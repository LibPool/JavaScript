# @k9o/kibo-react-native

> 标签: byok, encryption, hyok, kibo, kilimanjaro, react-native

## 简介

Kibo Zero-Knowledge BYOK/HYOK vault SDK for React Native — client-side encrypt/decrypt against your own KMS, over the audited Rust core (kibo-kms-rest-ffi) compiled to wasm. The platform never sees plaintext.
