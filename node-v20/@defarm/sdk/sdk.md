# @defarm/sdk

> 标签: agriculture, blind-envelope, defarm, hpke, sealed-field, stellar, traceability

## 简介

DeFarm SDK — verifiable agri traceability with client-side sealing (blind envelopes). The DeFarm server never sees your keys or your sealed data.
