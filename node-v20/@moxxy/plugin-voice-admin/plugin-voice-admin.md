# @moxxy/plugin-voice-admin

> 标签: agent, moxxy, tools, tts, voice

## 简介

Voice/TTS control for moxxy. set_voice / list_voices let the agent switch which text-to-speech backend read-aloud surfaces use (a registered synthesizer, or 'system' for the OS voice) without a settings UI.
