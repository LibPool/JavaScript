# @moxxy/channel-kit

> 标签: agent, channel, framework, moxxy

## 简介

Shared channel-building machinery for moxxy messaging channels: throttled send-once-then-edit frame pump, turnId-filtered turn running with single-flight coordination, pairing state machines (host-issued code + TOFU), vault-backed secret resolution, audit
