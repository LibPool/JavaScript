# @moxxy/plugin-provider-claude-code

> 标签: agent, anthropic, claude, llm, moxxy, oauth, provider

## 简介

Claude Pro/Max subscription provider for moxxy. Streams through the user's authenticated installed Claude CLI, with opt-in native-tool tasks and no Anthropic API key.
