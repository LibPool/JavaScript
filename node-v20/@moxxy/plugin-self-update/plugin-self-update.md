# @moxxy/plugin-self-update

> 标签: agent, moxxy, self-update, tools

## 简介

Model-callable self-update: guardrailed, transactional editing of moxxy's own plugins/skills (Tier 1, hot-reloaded) and core packages (Tier 2, build+overlay+restart). Every change is approval-gated, verified, and auto-rolled-back on failure. Disable to lo
