# @moxxy/plugin-provider-zai

> 标签: agent, glm, llm, moxxy, provider, zai, zhipu

## 简介

z.ai (Zhipu GLM) LLMProvider plugin for moxxy. Ships two providers: `zai` (pay-as-you-go, OpenAI-compatible endpoint) and `zai-coding-plan` (GLM Coding Plan, Anthropic-compatible endpoint).
