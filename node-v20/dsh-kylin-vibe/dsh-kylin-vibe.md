# dsh-kylin-vibe

> 标签: cordis, deepseek-harness, dsh, graphrag, knowledge-graph, kylin, qilin

## 简介

DSH/QiLin 双引擎 GraphRAG 插件：把显式授权的本地语料增量索引成知识图谱（实体-关系-社区），以 agent 工具形式暴露，供模型在任务执行中做关系性/全局性推理检索
