# @alejandbel/ton-connect-ui

> 标签: Connect, TON, Tonkeeper, UI, Wallet, sdk, ton-connect, tonconnect

## 简介

TonConnect UI is a UI kit for TonConnect SDK. Use it to connect your app to TON wallets via TonConnect protocol.
