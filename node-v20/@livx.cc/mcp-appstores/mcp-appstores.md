# @livx.cc/mcp-appstores

> 标签: altool, android, app-store-connect, ci, deploy, google-play, ios, mcp, testflight

## 简介

Multi-org, multi-app deploy + control for App Store Connect (Apple) and Google Play (Android) — one-shot CI upload CLIs (apple-upload/android-upload) + an MCP server for releases, testers, pricing, products.
