# @kabeersnetwork/spatialnavigation

> 标签: Kabeers, Navigaton, Network, TV, TVOS, WebOs

## 简介

For a currently focused element, this simple library calculates the nearest element in all four directions. We first applied the library to the TV Home screen, which was under development. During the testing iteration, we gradually improved its navigation
