# ai-agent-bell

> 标签: ai, alarm, claude-code, codex, hooks, notification, opencode, plugin, terminal

## 简介

AI Agent Bell: a loud alarm when your AI coding agent finishes, fails, or needs your input. Works with OpenCode, Claude Code, Codex CLI and any terminal tool. Global-only: zero project impact, never ships in your build. Local-only: no network, no usage tr
