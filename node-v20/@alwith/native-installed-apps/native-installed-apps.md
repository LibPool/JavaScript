# @alwith/native-installed-apps

> 标签: JavaScript

## 简介

Independent closed installed-apps native library. Only the matching platform binary is installed. Call `stageNative(target, destination, licenses)` from `@alwith/native-installed-apps/stage` at build time. The loader verifies module identity, version, tar
