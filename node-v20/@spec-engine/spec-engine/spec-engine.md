# @spec-engine/spec-engine

> 标签: bun, ci, cli, coverage, mcp, requirements, spec, traceability

## 简介

Cross-repo spec engine — durable requirements with permanent IDs, bound to code via @spec tags, checked in CI. Ships the spec CLI, the local coverage webapp (spec serve), and offline docs (spec docs).
