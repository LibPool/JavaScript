# @jeffreyjyz/opencode-shell-rc

> 标签: aliases, opencode, opencode-plugin, zdotdir, zsh

## 简介

Make the opencode agent shell load your zsh aliases and functions (via a fast ZDOTDIR shim), without paying for oh-my-zsh/compinit on every command.
