# @useqr/core

> 标签: bip21, qr, qr-code, qr-generator, qrcode, svg, typescript, upi, vcard, wifi-qr

## 简介

UseQR core engine: QR matrix, styled SVG renderer, typed payload builders, decode-verify loop. MIT, zero-tracking, works in browser and Node.
