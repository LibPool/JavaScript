# @noambz/ui

> 标签: components, design-system, nextjs, radix, react, storybook, tailwind, ui

## 简介

Shared React UI library: atomic design system, Tailwind v4 tokens, Radix primitives, Storybook docs. Built for Next.js 16 + React 19.
