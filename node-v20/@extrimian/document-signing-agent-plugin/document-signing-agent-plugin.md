# @extrimian/document-signing-agent-plugin

> 标签: JavaScript

## 简介

IAgentPlugin adapter for the document signing protocol: routes the inbound types of the declared role into @extrimian/document-signing-protocol. Thin by design — no protocol logic of its own.
