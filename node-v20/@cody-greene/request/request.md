# @cody-greene/request

> 标签: JavaScript

## 简介

Minimal dependency http(s) library for node & modern browsers with: - exponential backoff/retry - configurable error parsing - [callback API](#callback-api) - [support for native Promises](#native-promises) - [support for bound Promise](#bound-promise) -
