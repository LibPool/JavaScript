# dsh-composer-input-history

> 标签: composer, deepseek-harness, dsh, history, input-history, plugin

## 简介

Shell-style input history for the DSH composer: ArrowUp recalls messages you already sent, ArrowDown walks forward, restores your draft, and a further press discards it.
