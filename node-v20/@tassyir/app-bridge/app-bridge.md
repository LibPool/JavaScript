# @tassyir/app-bridge

> 标签: app-bridge, embedded-app, iframe, postmessage, react, tassyir, tassyir-app

## 简介

App Bridge for Tassyir apps: the embedded page's side of the dashboard bridge (ID tokens, toasts, modals, navigation, save bar, title bar, resource pickers, context), with React bindings.
