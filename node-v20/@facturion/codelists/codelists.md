# @facturion/codelists

> 标签: codelists, einvoicing, en16931, i18n, iso-3166, iso-4217, peppol, untdid, vat

## 简介

Friendly, multilingual EN 16931 / UN-CEFACT e-invoicing code lists (units, VAT categories, payment means, invoice types, countries, currencies, Peppol EAS schemes) with curated labels and explanatory hints.
