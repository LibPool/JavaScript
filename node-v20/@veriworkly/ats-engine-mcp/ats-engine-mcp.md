# @veriworkly/ats-engine-mcp

> 标签: applicant-tracking-system, ats, ats-checker, ats-score, claude, cursor, cv, job-match, mcp, mcp-server, model-context-protocol, resume, resume-checker, resume-parser

## 简介

ATS resume checker MCP server: lets Claude, Cursor or VS Code read your resume the way an applicant tracking system does and score it with a published, deterministic rubric. Runs locally.
