# @veriworkly/ats-engine

> 标签: applicant-tracking-system, ats, ats-checker, ats-engine, ats-friendly, ats-score, cv, docx, job-description, job-match, jsonresume, keyword-matching, pdf, resume, resume-analyzer, resume-checker, resume-parser, resume-scanner, resume-scoring

## 简介

ATS resume checker and parser: reads a resume (PDF, DOCX, text, JSON Resume) the way an applicant tracking system does, scores it with a published deterministic rubric, and matches it to a job description. Browser- and edge-safe.
