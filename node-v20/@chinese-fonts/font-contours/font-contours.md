# @chinese-fonts/font-contours

> 标签: JavaScript

## 简介

1. getAllFontNames 获取 noto sans 文件中的 ttf 文件的具体路径 2. getFontUnicodes 获取字体中的字符复杂度并输出数组 3. contours_binary 压缩成品为二进制格式 4. binary_read 是读取的方式
