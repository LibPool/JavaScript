# @clossys/builder

> 标签: aggregation, ci-gate, deployment, drift-detection, fail-closed, gate-result, observation-bundle, provisioning, toolchain, typescript

## 简介

Declared reality made actual: an idempotent manifest engine and machine verification, a deployment surface contract with read-only platform adapters, a toolchain pin (runtime, package manager, build order), the liveStateSurface contract and shared CI gate
