# @hank-warren/pi-loop

> 标签: automation, cron, loop, pi, pi-extension, pi-package, scheduler

## 简介

Long-running work for Pi: settle-paced loops with a durable ledger, adaptive waits, no-progress breakers, evidence-gated completion, and a task scheduler.
