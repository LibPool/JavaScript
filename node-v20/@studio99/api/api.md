# @studio99/api

> 标签: calligraphy, devanagari, gujarati, hindi, indic, marathi, studio99, svg, typography

## 简介

Official Node.js client for the Studio99 Indic Typography API: exact Hindi, Marathi, Gujarati and English typography as editable SVG and PNG.

- 官网：https://studio99.app/developers
- 源码仓库：git+https://github.com/studio99-app/studio99-node.git
- npm 页面：https://www.npmjs.com/package/@studio99/api
