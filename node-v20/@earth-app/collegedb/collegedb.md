# @earth-app/collegedb

> 标签: cloudflare, d1, database, drizzle, durable-objects, horizontal-scaling, hyperdrive, kv, mariadb, mysql, nuxthub, postgres, postgresql, redis, shard, sharding, sql, sqlite, valkey, workers

## 简介

Horizontal sharding router for SQL databases. Routes queries by primary key across many database instances, with adapters for D1, PostgreSQL, MySQL, MariaDB, SQLite and Drizzle, and key-value mapping backed by Workers KV, Redis, Valkey or NuxtHub.
