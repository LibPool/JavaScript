# @volksverpetzer/whitelist-ip

> 标签: JavaScript

## 简介

CLI that adds your current public IPv4 to a Scaleway Managed Database instance's ACL allow list. Run via `npx @volksverpetzer/whitelist-ip` from any repo instead of keeping a repo-local copy of the script.
