# @parcel/bundle-stats

> 标签: JavaScript

## 简介

- Run `yarn link` in `packages/dev/bundle-stats-cli` - Run `parcel-bundle-stats` in the project root, a `parcel-bundle-reports` directory will be created with the stats file inside
