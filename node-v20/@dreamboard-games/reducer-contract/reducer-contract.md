# @dreamboard-games/reducer-contract

> 标签: JavaScript

## 简介

Single-source-of-truth wire contract between the JS reducer bundle and the Kotlin reducer runtime. The JSON Schema in ./schema is authoritative; TS and Kotlin artifacts are generated.
