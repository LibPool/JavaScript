# @effectweb/keycloak

> 标签: JavaScript

## 简介

EffectWeb adapter for the `keycloak-js` SDK. In an Effect scope, call `mountKeycloak(client, initOptions, options?)` with an SDK instance. It initializes the client, exposes an immutable EffectWeb source of authentication/identity/realm roles, and runs sc
