# @arpoly/react

> 标签: 3d, ar, augmented-reality, gltf, quick-look, react, scene-viewer, usdz, webxr

## 简介

ARpoly web SDK: OS-native AR handoff (Quick Look / Scene Viewer), in-page WebXR, 3D preview and capture helpers. Sector-agnostic.
