# @storewatch/medusa-v1

> 标签: analytics, ecommerce, medusa, medusa-plugin, medusa-v1, storewatch

## 简介

Storewatch for Medusa v1: a plugin that sends server-confirmed orders, cancellations and refunds, tied to the shopper's live session.
