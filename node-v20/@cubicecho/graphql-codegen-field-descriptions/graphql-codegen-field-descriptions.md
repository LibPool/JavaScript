# @cubicecho/graphql-codegen-field-descriptions

> 标签: codegen, descriptions, documentation, graphql, graphql-code-generator, graphql-codegen, plugin, typescript

## 简介

GraphQL Code Generator plugin that emits your SDL field descriptions as a runtime map, so authored docs are available at run time and not just as JSDoc.
