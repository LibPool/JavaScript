# @dbcube/vector

> 标签: @dbcube, dbcube, embeddings, knn, milvus, pgvector, pinecone, qdrant, semantic search, similarity search, typescript, vector, vector database, weaviate

## 简介

Portable vector-store abstraction for Dbcube: one VectorStore interface (with a capability map) over pgvector, Qdrant, Pinecone, Weaviate, Milvus — plus an in-memory reference store. The L1 storage/search layer of the Dbcube Data + AI ORM.
