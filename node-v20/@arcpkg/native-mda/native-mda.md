# @arcpkg/native-mda

> 标签: arcjs, components, design-system, expo, mda, react-native, responsive, ui

## 简介

NATIVE MDA est le système de composants design MDA pour React Native et Expo : ~80 composants portés depuis MDA, basés sur StyleSheet, avec valeurs responsive/scroll par propriété et icônes fournies par @arcpkg/native-mda-svgicons.
