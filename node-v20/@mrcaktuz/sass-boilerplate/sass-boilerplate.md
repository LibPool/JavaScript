# @mrcaktuz/sass-boilerplate

> 标签: boilerplate, css, mrcaktuz, normalize, reset, sass, scss, starter, style, styles, theme, themes

## 简介

This is a boilerplate kit for you sass project. It contains basics functions, mixins, variables and normalize to enable you to start from a strong and healthy base. The goal is to help you start not holding you back, please make it your own and customize
