# @pkxp/solparse-exp-jb

> 标签: JavaScript

## 简介

PEG.js Solidity parser for Javascript, experimental work (jb) to support latest solidity features and work with vscode solidity, this should NOT be merged with the main repo as it includes support for incomplete statements
