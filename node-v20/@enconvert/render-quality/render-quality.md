# @enconvert/render-quality

> 标签: agents, anti-bot, cloudflare, crawl4ai, firecrawl, jina, llm, login-wall, rag, render-quality, soft-404, web-scraping

## 简介

Score a rendered web page 0-1 and name why it failed: Cloudflare challenge, WAF block, login wall, empty SPA shell, HTTP error, soft 404. The scorer behind EnConvert's render_quality. Zero dependencies.
