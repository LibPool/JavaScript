# @postfetch/core

> 标签: cobalt, downloader, facebook, instagram, linkedin, media, pinterest, reddit, soundcloud, tiktok, twitter, youtube, zero-dependency

## 简介

Zero-dependency typed core that turns Facebook, Instagram, LinkedIn, Pinterest, Reddit, SoundCloud, TikTok, X and YouTube post URLs into media files.
