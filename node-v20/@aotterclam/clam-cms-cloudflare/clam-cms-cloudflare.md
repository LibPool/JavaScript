# @aotterclam/clam-cms-cloudflare

> 标签: JavaScript

## 简介

Cloudflare Workers adapter for clam-cms. Hono-based mountServerEndpoints / mountMcp / mountPublicRoutes. Better Auth (admin + mcp plugins) for sign-in + bearer-token validation.
