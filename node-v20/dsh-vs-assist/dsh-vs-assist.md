# dsh-vs-assist

> 标签: code-assistant, deepseek-harness, dsh-plugin, dte, msbuild, visual-studio

## 简介

DeepSeek Harness plugin that drives Visual Studio through its DTE COM automation: read the editor context, insert or replace code in VS, build, read errors, and run.
