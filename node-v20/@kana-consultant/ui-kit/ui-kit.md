# @kana-consultant/ui-kit

> 标签: accessible, admin, backoffice, component-library, dashboard, data-table, design-system, radix-ui, react, storybook, tailwind, tailwindcss, tanstack-form, tanstack-store, tanstack-table, typescript, ui-kit

## 简介

A modern React UI kit for building back-office apps and admin dashboards — accessible primitives, dashboard blocks, TanStack Form + TanStack Store integrations, Tailwind v4 design tokens, Storybook included.
