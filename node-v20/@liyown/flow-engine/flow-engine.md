# @liyown/flow-engine

> 标签: automation, business-process, dsl, engine, flow, node, process, typescript, visual, workflow, workflow-engine

## 简介

一个基于JavaScript的无状态工作流引擎框架，支持可视化拖拽、DSL定义、断点继续、自动重试等高级功能
