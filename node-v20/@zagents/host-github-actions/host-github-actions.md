# @zagents/host-github-actions

> 标签: ADR-033, agent-gemini, ci-cd, composite-action, github-actions, host-adapter, non-interactive, ruflo, workflow

## 简介

GitHub Actions host adapter for zagents-generator. Emits .github/workflows/<name>.yml + a composite action.yml for non-interactive CI/CD agent harnesses (ADR-033).
