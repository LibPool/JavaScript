# @zagents/darwin

> 标签: agent-gemini, cheap-llm, compute-arbitrage, cost-optimization, darwin-mode, evolutionary-search, llm, llm-optimizer, sandbox, self-improvement, swe-bench, zagents

## 简介

An LLM supercharger and cost optimizer: freeze the model class, evolve the gemini. Measured on full SWE-bench Lite (300, official swebench Docker): 7.7% open-loop -> 15.3% +repair -> 29.3% (deepseek-v4-pro base) -> 40.3% v4-pro+frontier-tail hybrid, ~$0.0
