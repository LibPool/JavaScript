# @spectrayan/ng-sse-client

> 标签: angular, eventsource, reactive, real-time, reconnection, rxjs, server-sent-events, sse, streaming, zone-aware

## 简介

Typed, zone-aware Server-Sent Events (SSE) client for Angular. Features auto-reconnect with exponential backoff, named event support, lastEventId resumption, optional event-driven API callbacks with retry, and lifecycle hooks. Runs network I/O outside NgZ
