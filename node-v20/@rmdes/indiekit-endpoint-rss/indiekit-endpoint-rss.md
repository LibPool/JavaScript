# @rmdes/indiekit-endpoint-rss

> 标签: aggregator, atom, feed, indiekit, indiekit-plugin, indieweb, reader, rss

## 简介

RSS feed reader endpoint for Indiekit. Aggregates multiple feeds, caches in MongoDB, displays on frontend.
