# @rmdes/indiekit-endpoint-webmention-io

> 标签: indiekit, indiekit-plugin, indieweb, moderation, webmention

## 简介

Webmention moderation endpoint for Indiekit. Syncs webmentions from webmention.io into MongoDB with delete, block, and privacy removal capabilities.
