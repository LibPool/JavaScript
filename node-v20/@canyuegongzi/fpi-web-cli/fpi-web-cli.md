# @canyuegongzi/fpi-web-cli

> 标签: JavaScript

## 简介

现阶段该脚手架可用于快速搭建微前端主、子应用，也支持创建通用的项目（需要整理出项目模板并且修改配置信息【配置信息见 update 指令】）。
