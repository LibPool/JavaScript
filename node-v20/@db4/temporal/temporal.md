# @db4/temporal

> 标签: activities, cloudflare, db4, durable-objects, orchestration, queries, signals, temporal, workers, workflow

## 简介

EXPERIMENTAL: Temporal-compatible API definitions for db4 workflows. Provides type-safe workflow, activity, signal, and query interfaces. Runtime execution integration with Durable Objects is not yet implemented.
