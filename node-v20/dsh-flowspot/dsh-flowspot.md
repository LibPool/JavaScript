# dsh-flowspot

> 标签: capture, deepseek, dsh, dsh-plugin, flowspot, harness, https, mitm, proxy

## 简介

Flowspot — Charles-style HTTPS capture for DeepSeek Harness (Windows): an in-plugin MITM proxy, system-proxy and CA automation, flow storage, and agent tools. Flowspot：面向 DeepSeek Harness 的 Charles 式抓包插件——插件内 MITM 代理 + Windows 系统代理/CA 自动配置 + 流量存储 + agent
