# @moxo/mcp-server

> 标签: ai-tools, claude-desktop, continue, cursor, mcp, model-context-protocol, moxo, workflow

## 简介

Model Context Protocol server for Moxo — bridges Claude Desktop / Cursor / Continue to your Moxo workspace via a stdio→HTTP proxy.
