# @ir-kit/openapi-kotlin

> 标签: android, client, codegen, kotlin, kotlinx-serialization, okhttp, openapi, sdk

## 简介

Generate idiomatic Kotlin (OkHttp + kotlinx-serialization + suspend) client SDKs from an OpenAPI 3.x spec.
