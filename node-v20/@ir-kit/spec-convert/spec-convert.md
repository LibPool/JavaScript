# @ir-kit/spec-convert

> 标签: asyncapi, convert, ir-kit, json-schema, openapi, protobuf, spec, typespec

## 简介

Convert between API specification formats — OpenAPI 3, AsyncAPI 3, TypeSpec, Protobuf, JSON Schema. Pair-handler registry; programmatic API; thin wrappers around upstream conversion tools where available.
