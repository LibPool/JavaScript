# @ir-kit/spec-diff

> 标签: asyncapi, breaking-change, diff, ir-kit, openapi, postman, protobuf, typespec

## 简介

Cross-family API spec diff. Converts any supported spec to OpenAPI 3, then runs `api-smart-diff` — breaking / non-breaking / annotation classification.
