# @ir-kit/cli

> 标签: asyncapi, cli, codegen, ir-kit, openapi, typespec

## 简介

Unified `ir` CLI — single entry point for spec loading, conversion, codegen, and reverse-engineering across every supported API standard. Commands are JSON-Schema-defined; runtime auto-derives flags, prompts, help, and validation from the schema.
