# @ir-kit/fn-schema-unplugin

> 标签: esbuild-plugin, function-signature, hmr, json-schema, rollup-plugin, unplugin, vite-plugin, webpack-plugin

## 简介

Bundler plugin for fn-schema. Exposes a virtual module that resolves to the extracted bundle, with HMR on source change in dev. Built on unplugin so the same package powers Vite, webpack, Rollup, esbuild, Rspack, Rolldown, and Farm.
