# @remcp/remcp

> 标签: agent, chatgpt, cli, codex, computer, mcp, model-context-protocol, remote, self-hosted

## 简介

ReMCP device client: pair a computer with ReMCP and run the outbound-only agent that hosts the local MCP runtime.
