# @jperezmart/casl-core

> 标签: abac, abilities, authorization, casl, permissions, rbac

## 简介

Framework-free core of the jperezmart CASL Adapters: Role permissions, the Ability, the Denial rule and the Access conditions. Depends only on CASL.
