# numsy

> 标签: class-based, cli, contact-processor, csv-parser, dashboard, data-cleaning, deduplication, excel, excel-parser, india, indian-mobile, indian-phone, json, markdown, mobile-number, number-processor, numsy, phone-number, phone-sanitizer, phone-validation, phone-validator, typescript, validator, xlsx

## 简介

Validate, sanitize, extract and de-duplicate Indian mobile numbers from text, CSV and Excel — as a typed TypeScript library, a CLI with JSON/CSV/Markdown/Excel output, and a local dashboard on localhost:6789.
