# @aeroline_1025/hapi-corpsso

> 标签: hapi, saml, sso

## 简介

A Hapi plugin that wraps passport-saml for SAML SSO (as SP). This is a fork from hapi-passport-saml project (https://github.com/molekilla/hapi-passport-saml)
