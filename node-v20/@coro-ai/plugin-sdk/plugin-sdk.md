# @coro-ai/plugin-sdk

> 标签: JavaScript

## 简介

Public SDK for authoring Coro plugins (SCM, tracker, …). Re-exports the runner's plugin contracts plus a small set of authoring helpers (HMAC verification, base classes, MCP-server descriptors).
