# @usequeek/app-sdk

> 标签: commerce, merchant-api, queek, queek-app, sdk, typescript, webhook-signature, webhooks

## 简介

SDK for Queek apps: signed install and webhook handlers, a typed Merchant API client with retries and pagination, installation tokens and an encrypted installation store.
