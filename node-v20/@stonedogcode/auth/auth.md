# @stonedogcode/auth

> 标签: argon2, authentication, magic-link, passkey, totp, two-factor, webauthn

## 简介

Authentication factor primitives: password, PIN, TOTP, WebAuthn challenges and single-use emailed tokens. No storage, no transport, no framework.
