# @stonedogcode/mobile-auth

> 标签: authentication, biometric, device-linking, ecdsa, expo, fingerprint, p256, pkce, qr, react-native, refresh-token, secure-store

## 简介

Phone-side authentication helpers for Expo apps: PKCE and 'connect a phone' codes, an on-device P-256 key unlocked by the fingerprint, and session storage with single-flight refresh. Pairs with @stonedogcode/auth on the server.
