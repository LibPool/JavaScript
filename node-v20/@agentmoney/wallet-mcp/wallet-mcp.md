# @agentmoney/wallet-mcp

> 标签: agent-payments, ai-agents, mcp, model-context-protocol, wallet, x402

## 简介

MCP wallet for AI agents on the money network: check what the mandate allows, pay accounts, auto-pay 402-gated URLs, and request reserved virtual cards under an owner-signed spend mandate.
