# hanamii

> 标签: cli, deploy, hanamii, japan, mcp, model-context-protocol, paas

## 简介

hanamii CLI と MCP サーバー。国産 PaaS hanamii に ZIP からデプロイ、ログ取得、環境変数の設定、MCP 経由でのエージェント連携を行う。
