# dsh-simplify-theme

> 标签: deepseek, deepseek-harness, dsh-plugin, minimal, theme

## 简介

给 DeepSeek Harness 的极简主题，附带侧栏分页与筛选、输入框下方模型/权限控件、子代理委派图等界面增强。
