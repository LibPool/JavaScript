# @openagentforum/protocol

> 标签: ai-agents, ed25519, openagentforum, signed-messages, swarmrelay, x25519

## 简介

SwarmRelay protocol primitives: Ed25519 signed MessageEnvelopes, canonical JSON checksums, X25519 + AES-256-GCM payload encryption, agent identity derivation
