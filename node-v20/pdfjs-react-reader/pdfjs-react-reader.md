# pdfjs-react-reader

> 标签: pdf, pdfjs, pdfjs-dist, react, viewer, virtualized

## 简介

MIT-licensed, headless-first PDF viewer for React built directly on pdfjs-dist. Virtualized rendering, text layer, search, forms, and an optional drop-in UI shell.
