# maatify-image-upright

> 标签: exif, heic, heif, image, orientation, preview, retry, upload, upright

## 简介

Client-side image upload helper: EXIF orientation correction, HEIC/HEIF conversion, a preview that always matches what gets uploaded, retrying a signed URL that briefly fails to load, and upload with progress.
