# @beckn/core

> 标签: beckn, beckn-protocol, ed25519, ondc, signing, state-machine

## 简介

Domain-agnostic Beckn Protocol engine: action dispatcher, table-driven fulfillment state machine, idempotency guard, generic single-table repository interface, ACK-now/work-later primitives, and ONDC-spec-accurate Ed25519 request signing.
