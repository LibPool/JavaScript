# portcheck-cli

> 标签: address-already-in-use, cli, dev-server, eaddrinuse, free-port, kill, kill-port, killport, localhost, lsof, netstat, port, port-3000, port-in-use, port-kill, process

## 简介

See what's using a port and free it safely: a safer kill-port that shows the process and who started it before stopping it. Fixes "port already in use" (EADDRINUSE).
