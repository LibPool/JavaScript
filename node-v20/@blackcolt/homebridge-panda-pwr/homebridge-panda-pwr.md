# @blackcolt/homebridge-panda-pwr

> 标签: homebridge, homebridge-panda-pwr, homebridge-plugin, homekit, homekit-accessory, homekit-accessory-plugin, panda-pwr

## 简介

This is a Homebridge plugin for Panda Pwr, it works with the Panda Pwr API to control your Panda Pwr devices.
