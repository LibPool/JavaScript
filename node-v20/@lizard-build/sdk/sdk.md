# @lizard-build/sdk

> 标签: ai-agents, cloud, code-execution, code-interpreter, firecracker, lizard, microvm, paas, sandbox, sandboxes

## 简介

Firecracker microVM sandboxes for AI agents — boot Linux in milliseconds, run code, write files, expose ports over HTTPS, then pause a session with memory intact and resume it later. TypeScript SDK for Lizard Sandboxes (lizard.build).
