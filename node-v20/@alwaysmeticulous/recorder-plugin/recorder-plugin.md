# @alwaysmeticulous/recorder-plugin

> 标签: JavaScript

## 简介

Meticulous plugin for Vite, Webpack, Rspack, Rsbuild, and Nuxt that injects the recorder script into the HTML head, plus a Vite plugin that emits CSS source maps for stylesheet coverage.
