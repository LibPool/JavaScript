# dsh-file-extras

> 标签: context-menu, deepseek-harness, dsh, file-manager, file-mention, plugin, prompt-history, slash-command, web-ui

## 简介

DSH Web GUI 日常操作增强：工作区文件树行内显示大小与修改日期，右键下载 / 上传 / @ 到对话 / 复制路径 / 删除（走回收站，跨平台）；另有 ~/.dsh/commands/*.md 驱动的斜杠命令与输入框 ↑/↓ 历史指令回填。
