# @usetoki/toki-ratelimiter

> 标签: middleware, per-route, rate-limit, ratelimiter, tcp, throttle, toki, udp

## 简介

Flexible rate limiting for toki — HTTP routes, raw TCP connections, and UDP datagrams, with custom keys and pluggable stores.
