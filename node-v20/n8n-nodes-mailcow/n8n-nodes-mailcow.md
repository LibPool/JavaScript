# n8n-nodes-mailcow

> 标签: dovecot, email, mail-server, mailcow, n8n-community-node-package, postfix, self-hosted

## 简介

n8n community nodes for mailcow: manage domains, mailboxes, aliases, app passwords, quarantine, mail queue, DKIM and logs, with a polling trigger.
