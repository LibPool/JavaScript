# @peter.prib/sqlengine

> 标签: archimate, cypher, data-modelling, database, embedded-database, graph-database, hnsw, in-memory-database, llm, notebook, sql, vector-database, workflow

## 简介

A whole database in one JavaScript package — SQL, graphs (Cypher), vectors, workflows and AI — with no runtime dependencies; embedded, in the browser, or as a server with a browser workbench.
