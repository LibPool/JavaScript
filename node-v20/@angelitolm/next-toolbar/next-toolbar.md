# @angelitolm/next-toolbar

> 标签: app-router, broken-links, cache, cache-tags, debug, devtools, fetch-cache, isr, json-ld, link-checker, metadata, next, nextjs, open-graph, performance, profiler, react, rendering, revalidate, revalidate-tag, security, seo, server-actions, staging, toolbar, vulnerabilities

## 简介

Floating debug toolbar for the Next.js App Router (dev only): status, route, render mode, timings, fetch cache with tags and revalidation, request profiler, Server Actions with revalidation, SEO metadata, broken links and security advisories
