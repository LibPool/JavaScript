# dsh-jiuling-remote-desktop

> 标签: cloudflare-tunnel, deepseek-harness, dsh, dsh-plugin, dshapp-plugin, remote

## 简介

DSH 远程目录（电脑端）：把本机 DSH 会话的事件流经 Cloudflare 隧道搬到手机，手机进入电脑目录并发起对话，公网只传文本。含激活码配对流程。
