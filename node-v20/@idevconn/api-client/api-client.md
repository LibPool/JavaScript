# @idevconn/api-client

> 标签: api-client, fetch, http, jwt, token-refresh, typed-errors

## 简介

Tiny JWT fetch wrapper with auto refresh, typed errors, and pluggable callbacks. Framework-agnostic. ~80 LOC. Zero runtime deps.
