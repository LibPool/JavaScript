# @idevconn/use-draft

> 标签: dirty-state, forms, navigation-blocker, react, tanstack-router, unsaved-changes, zustand

## 简介

Global unsaved-changes blocker for TanStack Router SPAs. Aggregates dirty state from every mounted form via a Zustand store and blocks both in-app navigation (router dialog) and browser refresh/close (native dialog).
