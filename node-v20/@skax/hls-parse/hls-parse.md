# @skax/hls-parse

> 标签: hls, http-live-streaming, ll-hls, low-latency, m3u8, m3u8-parser, parse, parser, playlist

## 简介

A robust M3U8/HLS playlist parser supporting RFC 8216, Master playlists, Media playlists, and LL-HLS (Low-Latency HLS)
