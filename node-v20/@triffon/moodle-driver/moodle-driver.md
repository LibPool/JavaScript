# @triffon/moodle-driver

> 标签: automation, browser, lms, moodle, playwright

## 简介

Fork of @falkenslab/moodle-driver with Firefox as a browser channel, until it is merged upstream. Full control of Moodle as any user, from code or the command line, with their own login: no web services, no tokens, no admin.
