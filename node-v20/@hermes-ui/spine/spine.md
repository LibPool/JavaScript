# @hermes-ui/spine

> 标签: JavaScript

## 简介

Angular UI shell library built on top of [Clarity Design System](https://clarity.design). Provides the full application frame — layout, navigation, routing infrastructure, and a set of built-in feature pages — for Spine applications.
