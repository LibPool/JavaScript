# @gamebridge/sdk-realtime

> 标签: gamebridge, multiplayer, realtime, sdk, websocket

## 简介

GameBridge 实时通信 SDK：客户端（连接/自动重连/心跳/房间广播）与服务端（self-host 实时通道服务）共用一个包，按子路径分别引入，浏览器不会携带服务端代码。
