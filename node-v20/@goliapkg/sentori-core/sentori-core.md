# @goliapkg/sentori-core

> 标签: core, error-tracking, monitoring, sentori

## 简介

Sentori SDK core — wire-format types (incl. Span), uuid v7, breadcrumb + span ring buffers, trace context, stack parsers shared across @goliapkg/sentori-* SDKs.
