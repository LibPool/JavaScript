# @goliapkg/kevy-electron

> 标签: JavaScript

## 简介

kevy embedded in an Electron app — the real native engine in the main process (via the N-API door), reached from any renderer through a contextBridge preload + IPC. Safe under contextIsolation and sandbox; no electron-rebuild (stable Node-API).
