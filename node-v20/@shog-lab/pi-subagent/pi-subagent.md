# @shog-lab/pi-subagent

> 标签: agent-tools, extension, pi, pi-coding-agent, pi-package, subagent

## 简介

Spawn focused sub-pi processes from inside pi. Registers a `spawn_subagent` tool: agent calls it with cwd + prompt, gets back the sub-agent's response. Fire-and-forget child pi via spawnPi. Previously bundled in @shog-lab/pi-toolkit 0.2.x.
