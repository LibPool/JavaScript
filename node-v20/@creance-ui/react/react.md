# @creance-ui/react

> 标签: accessibility, agents, ai, approval, components, design-system, human-in-the-loop, react, ui

## 简介

A React component library in a frosted-glass style: 109 components in light and dark, with a set for supervising AI agents (approvals, tool calls, run timelines, diff review and handoffs).
