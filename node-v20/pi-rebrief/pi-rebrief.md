# pi-rebrief

> 标签: agents-md, claude-md, context-files, pi, pi-coding-agent, pi-extension, pi-package, reload, system-prompt

## 简介

Reload only the project context files, including AGENTS.md and CLAUDE.md, into a running Pi session: no extension restart or MCP reconnect like /reload, plus a report of what changed.
