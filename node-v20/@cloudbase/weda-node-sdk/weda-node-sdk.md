# @cloudbase/weda-node-sdk

> 标签: JavaScript

## 简介

微搭低码数据源云函数公共 node 包, 数据源相关 `lcap-datasource-test`(微搭控制台数据源测试专用的云函数)、`lcap-common-service`(微搭应用运行态依赖的公共云函数, 提供用户注册、获取用户信息、调用微搭后端服务等公共功能)、数据源云函数(在微搭控制台中数据源保存和发布均会部署对应的云函数) 均使用了该包.
