# @cloudbase/framework-plugin-container

> 标签: JavaScript

## 简介

云开发 Tencent CloudBase Framework Container Plugin 插件，将项目下的后端应用一键部署云开发云托管环境，提供自动弹性伸缩的高性能容器服务。
