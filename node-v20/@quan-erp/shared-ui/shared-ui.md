# @quan-erp/shared-ui

> 标签: JavaScript

## 简介

The visual core and design system for the Quan ERP ecosystem. Built on top of **React**, **Tailwind CSS**, and **Radix UI**, this library provides a suite of 60+ atomic and complex components designed for high-performance, accessible, and consistent enter
