# @stargantt/plugin-export

> 标签: gantt, gantt-chart, plugin-architecture, project-management, scheduling, timeline, typescript, zero-dependencies

## 简介

Official StarGantt plugin: image and PDF export, CSV/JSON/iCal and MS-Project interchange, an .xlsx writer, and read-only/embed viewing.
