# @bytetrue/pi-background-terminal

> 标签: background-process, pi-extension, pi-package

## 简介

Pi extension: background_run starts shell commands hands-off with automatic exit notifications; background tasks are hard-capped at 28800s (8h) with renewal via restart. The optional 300s foreground shell cap is the separate pi-bash-timeout small extensio
