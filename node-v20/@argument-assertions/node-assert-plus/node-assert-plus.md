> 标签: assert, assert plus, assertion, assertion library, assertions, asserts, asserts plus, data validation, datatype validation, nodejs, runtime assertion, testing, testing library, testings, type check, type-check, typescript, validation

## 简介

Node.js assertion library on top of the built-in assert module with strict and flexible validation. Much more secure and up to 10 times faster than the original 'node-assert-plus', 80 % less CPU usage and memory consumption.
