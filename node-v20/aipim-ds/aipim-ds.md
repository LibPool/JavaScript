# aipim-ds

> 标签: accessibility, agents, ai, brazil, components, css, design-system, design-tokens, figma, icons, llms, storybook, wcag

## 简介

A small, open, Brazilian design system with all the parts in place: tokens, 17 HTML and CSS components, 63 line icons, documentation and an accessible-color token generator. Made to be customized and used by people and by AI.
