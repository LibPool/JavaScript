# @pi-kaush/pi-simple-subagents

> 标签: delegation, pi-extension, pi-package, subagents

## 简介

Delegate bounded tasks to isolated Pi subagent processes, with execution profiles, bounded delegation, process-tree cleanup, and resumable child sessions.
