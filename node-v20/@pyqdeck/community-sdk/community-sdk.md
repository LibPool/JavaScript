# @pyqdeck/community-sdk

> 标签: community, expo, pyqdeck, react-native, sdk, tanstack-query

## 简介

Typed client for the PYQDeck Community API (posts, comments, members, short links). No Clerk, React or cache inside: the app supplies the token and owns caching.
