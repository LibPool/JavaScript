# @meltdownjs/droppy

> 标签: TanStack, api-data, combobox, components, debounce, dropdown, dropdown-list, dropdown-menu, floating-ui, frontend, hooks, infinite-scroll, multicombobox, multiselect, pagination, react, react-query, search, select, virtualization, virtualized

## 简介

@meltdownjs/droppy is a react library which provides hooks for creating virtualized Select-, MultiSelect-, ComboBox- & MultiComboBox-Components easily.
