# @mindpeeker/entropy

> 标签: anu, csprng, drand, entropy, qrng, quantum, random, random.org, randomness, trng

## 简介

Provider-pluggable quantum (QRNG) and true (TRNG) randomness for web and Node — ANU, RANDOM.ORG, drand, NIST beacon and more, with composable fallback/xor/race strategies and streaming.
