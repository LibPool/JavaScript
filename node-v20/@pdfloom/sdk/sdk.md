# @pdfloom/sdk

> 标签: JavaScript

## 简介

PDFLoom's PDF engine as a library: organize, edit, redact, sign (RSA/ECDSA, timestamps, incremental), encrypt (AES-256), convert and more. Runs in the browser and in Node 20+, with no server.
