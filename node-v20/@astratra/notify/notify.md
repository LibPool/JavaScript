# @astratra/notify

> 标签: astratra, email, notifications, push, sms, transactional

## 简介

Outbound messages done once — email, SMS and push. Transport injected, never throws, header-injection safe, loud simulation when unconfigured, dead push subscriptions handed back for pruning.
