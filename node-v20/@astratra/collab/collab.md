# @astratra/collab

> 标签: astratra, collaboration, crdt, hocuspocus, markdown, tiptap, wiki, yjs

## 简介

Real-time collaborative editing: Hocuspocus server wired to your auth (read/write per document), injectable persistence with Yjs snapshots, named versions and restore, size limits, a headless Tiptap editor factory, and Yjs to JSON/Markdown/HTML conversion
