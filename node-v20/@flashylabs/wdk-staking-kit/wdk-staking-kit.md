# @flashylabs/wdk-staking-kit

> 标签: agent, crypto, defi, staking, tether, wallet, wdk, web3

## 简介

A reference staking primitive for wallets built on Tether's WDK (or any wallet SDK): lock a balance for a fixed term at a published rate, without touching an on-chain contract or a ledger's internals — a lock earmarks a balance a provider already credits,
