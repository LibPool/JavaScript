# @alex-tiplink/tiplink-wallet-adapter-react-ui

> 标签: JavaScript

## 简介

This package is a modified version of https://github.com/solana-labs/wallet-adapter/tree/master/packages/ui/react-ui, with a minor change in terms of  ordering in the WalletModal UI, in addition to a couple of new  wallet adapter related UI components.
