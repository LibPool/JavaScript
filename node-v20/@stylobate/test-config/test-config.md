# @stylobate/test-config

> 标签: JavaScript

## 简介

公司前端共享 Vitest 测试预设。基于 `vitest@^4` + `jsdom@^29` + `@vitest/coverage-v8`，提供框架无关、React、Vue 三套预设，并内置 Testing Library 的 `cleanup()` + `jest-dom` matchers。
