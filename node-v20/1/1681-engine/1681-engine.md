# 1681-engine

> 标签: 2d, ecs, game-engine, gamedev, multiplayer, pixel-art, pixijs, tiled, typescript

## 简介

A 2D game engine on PixiJS 8 for any art style: scenes and a fast ECS, a fixed-step loop, asset loading, Tiled maps, sprite animation, input actions, camera follow, audio and deterministic, server-replayable movement, plus Dither, an optional pixel-art mo
