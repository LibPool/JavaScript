# 148tls-fetch

> 标签: boringssl, chrome, curl-cffi, fingerprint, http2, impersonate, ja3, ja4, tls

## 简介

curl_cffi-like HTTP client with a real Chrome 148 TLS + HTTP/2 fingerprint (Rust/BoringSSL via napi-rs). Windows x64.
