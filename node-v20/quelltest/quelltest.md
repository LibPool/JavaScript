# quelltest

> 标签: ai-generated-tests, claude-code, code-review, edge-cases, mcp, mutation-testing, production-readiness, sarif, test-generation, test-quality, testing, typescript

## 简介

Free, offline gate for AI-written tests: proves tests fail when the code is wrong (mutation verification), detects weakened tests in a change, and finds untested risky edges in JavaScript and TypeScript.
