# @seiva-ai/support-mcp-server

> 标签: claude-code, mcp, model-context-protocol, seiva, support

## 简介

Read-only support MCP for Seiva platform admins. Aggregates DB logs, Fly.io, Cloud Run and Sentry to triage production bugs from Claude Code.
