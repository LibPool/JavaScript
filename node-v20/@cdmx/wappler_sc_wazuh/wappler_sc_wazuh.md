# @cdmx/wappler_sc_wazuh

> 标签: opensearch, server connect, wappler server connect, wappler wazuh tools server connect, wazuh

## 简介

This SC Module provides a set of Wazuh and OpenSearch tools for retrieving vulnerability findings, managing agents, and integrating with Wazuh APIs. It is designed for Node.js applications, with robust error handling and clear parameter validation.
