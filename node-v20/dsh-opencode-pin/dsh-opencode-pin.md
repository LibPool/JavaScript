# dsh-opencode-pin

> 标签: deepseek-harness, dsh, dsh-plugin, opencode, opencode-go, provider-routing, upstream, x-opencode-session

## 简介

Pins OpenCode Go (and OpenCode Zen) traffic to a chosen upstream route by keeping one stable x-opencode-session key, with an in-GUI upstream picker, a remembered key pool, and drift checks.
