# @open-music-sdk/client-user

> 标签: api-client, apple-music, apple-music-api, library, musickit, playlists, ratings, recommendations, sdk, typescript

## 简介

A listener's side of the Apple Music API, one typed function per endpoint: library, playlists, ratings, recommendations, history, replay. Developer token and Music User Token.
