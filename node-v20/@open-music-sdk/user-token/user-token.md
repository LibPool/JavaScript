# @open-music-sdk/user-token

> 标签: apple-music, apple-music-api, authentication, music-user-token, musickit, sdk, token-store, typescript

## 简介

Music User Token intake, validation, and pluggable stores for the Apple Music API. Consumes tokens, never issues them.
