# @paddle/paddle-node-sdk

> 标签: JavaScript

## 简介

A Node.js SDK that you can use to integrate Paddle Billing with applications written in server-side JavaScript.

## 官网

- 官网：https://developer.paddle.com/api-reference/overview
- 源码仓库：git+https://github.com/PaddleHQ/paddle-node-sdk.git
- npm 页面：https://www.npmjs.com/package/@paddle/paddle-node-sdk
