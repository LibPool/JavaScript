# reinloop

> 标签: agent-framework, agents, harness, llm, mcp, opentelemetry, tool-calling

## 简介

Agents as files, harness included: zero-dependency agent runtime with budgets, permissions, durable resume, multi-agent patterns, MCP and OpenTelemetry.
