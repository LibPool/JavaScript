# @zhushanwen/pi-session-path

> 标签: active-path, pi, pi-package, session, shared

## 简介

Active-path clipping for pi session entries — single shared implementation for state-rebuilding extensions (todo/plan/goal/scheduler), so revoked subtrees stay out of rebuild inputs (shared library, not a Pi extension, zero dependencies).
