# @zhushanwen/pi-rename-session

> 标签: pi-package

## 简介

Pi rename-session 扩展 — 三种触发模式下自动/自主为会话生成 slug 式标题并落库（`setSessionName`），让 session 列表摆脱默认的日期/序号占位，一眼可辨。
