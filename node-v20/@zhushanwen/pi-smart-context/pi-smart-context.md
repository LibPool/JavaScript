# @zhushanwen/pi-smart-context

> 标签: pi-package

## 简介

智能上下文压缩 pi extension：把 compact 时机交给 agent 自决，压缩生成用双模式接管（same-model KV 缓存命中 / cross-model 廉价模型），3 档阈值提醒不强制。
