# @panando/dsh-prompt-library

> 标签: deepseek-harness, dsh, dsh-plugin, fork, plugin, prompt, prompt-library

## 简介

DSH 词库插件（@sunjuntao/dsh-prompt-library 的 fork）：集中管理提示词（增删改查、标签分类、导入导出、AI 优化），聊天快捷收录与调用。入口已收敛进「设置 → 词库设置」，不再向宿主侧边栏注入按钮。 Fork of @sunjuntao/dsh-prompt-library: manage prompts (CRUD, tags, import/export, AI polish), quick capture & reuse in chat; entry point
