# @ardethian/webpack-starter

> 标签: babel, es6, starter, webpack

## 简介

A Webpack Starter Kit, bundled with - - Babel (es2015 preset) - JavaScript & CSS minification - CSS Reset - CSS Hot Loader - CSS Loader - Sass Loader
