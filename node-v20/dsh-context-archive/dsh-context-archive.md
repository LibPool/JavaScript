# dsh-context-archive

> 标签: archive, compaction, context, cordis, deepseek-harness, dsh, dsh-plugin, tool-result

## 简介

Model-driven tool-result archiving for DeepSeek Harness: long results carry an inline id, the model archives the ones it no longer needs into the session's own folder, and a recoverable stub stays in context.
