# @lucaffz/glyph

> 标签: JavaScript

## 简介

Bibliothèque de composants UI pour **Angular**, dans l'esprit de [shadcn/ui](https://ui.shadcn.com) : des composants autonomes, accessibles et thémables, écrits avec les **signals**, en `standalone`, et stylés avec **Tailwind CSS v4**.
