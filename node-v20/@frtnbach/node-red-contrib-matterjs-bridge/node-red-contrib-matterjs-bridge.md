# @frtnbach/node-red-contrib-matterjs-bridge

> 标签: home-automation, iot, matter, matterjs-server, node-red

## 简介

Node-RED bridge between matterjs-server (Matter-over-IP controller) and Node-RED flows. Built on the official @matter-server/ws-client.
