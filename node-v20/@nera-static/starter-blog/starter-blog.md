# @nera-static/starter-blog

> 标签: blog, nera, nera-starter, starter, static-site-generator

## 简介

A ready-to-edit Nera blog on @nera-static/theme-blog: three sample posts, tags, an archive by year, prev/next, an Atom feed, a sitemap, code blocks, navigation, responsive images, social links and imprint and privacy placeholders. No JavaScript.
