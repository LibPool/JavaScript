# dsh-code-taste

> 标签: coding-style, conventions, deepseek-harness, dsh-plugin, preferences, taste

## 简介

Learns your coding taste from explicit instructions and corrections, stores it as confidence-scored rules in editable markdown, and injects them into every session.
