# @nomercy-entertainment/nomercy-player-core

> 标签: NoMercy, hls, player, plugin, webvtt

## 简介

NoMercy player core — shared spine for nomercy-music-player and nomercy-video-player. Plugin runtime, event system, lifecycle helpers, streams, cues, errors, auth.
