# @8bitscript/color

> 标签: JavaScript

## 简介

A whole-frame flicker blend between two of a machine's fixed palette colors — the C64 demoscene's "more than 16 colours" trick, riding on @8bitscript/raster's own list. Resolves per target to that machine's own color implementation; #fact(video.colorBlend
