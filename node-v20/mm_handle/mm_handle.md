# mm_handle

> 标签: after, before, check, error, handle, hook, hooks, lifecycle, main, middleware, mm_in_port, mm_mod, mm_port, render, success, 请求处理

## 简介

请求处理基类，提供 before / check / main / render / success / error / after 七阶段生命周期钩子编排，支持短路、错误恢复与结果覆盖；内置钩子登记表与管理器池，基于 mm_corejs。
