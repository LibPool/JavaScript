# @jencube/revly-mcp-server

> 标签: ai-agent, git, mcp, model-context-protocol, revly

## 简介

MCP server exposing Revly's local AI Agent Gateway to MCP-compatible AI tools (Claude Code, Codex, Gemini CLI, etc.) - runs locally and only ever talks to your own machine's Revly desktop app.

## 官网
