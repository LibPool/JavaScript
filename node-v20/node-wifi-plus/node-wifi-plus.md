# node-wifi-plus

> 标签: auto-reconnect, connect, disconnect, fresh-scan, network, node-wifi, scan, signal, ssid, wifi, wifi-manager, wireless

## 简介

Advanced WiFi manager for Node.js built on top of node-wifi. Adds events, auto-reconnect, signal monitoring, forced fresh scans, and many useful utilities.
