# @undercroft/pulse-frame

> 标签: binary, buffer, decoder, deflate, encoder, frame, masking, nodejs, packet, payload, protocol, rfc6455, transport, typescript, unmask, websocket, websocket-frame, ws

## 简介

Low-level WebSocket framing library implementing RFC 6455. Supports payload masking, control frames, and binary/text handling.
