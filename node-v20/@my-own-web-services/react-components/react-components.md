# @my-own-web-services/react-components

> 标签: components, mows, radix, react, shadcn, tailwindcss, ui

## 简介

Shared React component + context library for MOWS frontend apps (auth, theme, language, action manager, hotkeys, modals, plus a large component set built on Radix UI and shadcn/ui).
