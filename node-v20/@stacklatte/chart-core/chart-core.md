> 标签: ai-agent, backtest, bollinger-bands, candlestick, candlestick-chart, chart, chartconfig, charts, crypto, finance, indicators, json-schema, llm, macd, open-source, react-native, react-native-chart, rsi, skia, stock, structured-output, technical-analysis, trade-markers, trading, trading-view, typescript, volume

## 简介

GPU-accelerated React Native trading chart (Skia): candlesticks, RSI/MACD/Bollinger/Volume, trade markers, pinch-zoom, live streaming. Ships an LLM-safe declarative ChartConfig + JSON Schema so agents can generate charts without hallucinating props.
