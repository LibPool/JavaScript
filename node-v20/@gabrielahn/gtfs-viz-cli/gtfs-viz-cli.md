# @gabrielahn/gtfs-viz-cli

> 标签: accessibility, cli, duckdb, export, gtfs, pathways, routes, schedules, stations, stops, transit, visualization

## 简介

Lightweight GTFS data visualizer and editor — import, browse stations/stops/routes/pathways, edit connections, compare schedules, and export feeds from the terminal with DuckDB and a browser dashboard
