# @voyantjs/admin-client

> 标签: JavaScript

## 简介

A framework-neutral TypeScript client for the Voyant Admin API. Built on the typed operation descriptors in [`@voyantjs/admin-contracts`](../admin-contracts/README.md), it runs in **Expo, Node, Cloudflare Workers, and Max/AI tools** — no React, no web-UI,
