# react-native-secure-auth

> 标签: appauth, auth, authentication, custom-tabs, oauth, oauth2, openid, postmessage, react, react-native

## 简介

React Native bridge for AppAuth (OAuth 2.0 / OpenID Connect) with customizable browser headers, browser postMessage messaging, discovery helpers and automatic token refresh
