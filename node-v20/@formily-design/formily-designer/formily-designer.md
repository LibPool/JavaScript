# @formily-design/formily-designer

> 标签: JavaScript

## 简介

基于 [Designable](https://github.com/alibaba/designable) 和 [Formily](https://formilyjs.org/) 的表单设计器组件库，提供可视化表单设计器和 Schema 渲染表单两个核心组件。

## 官网

- 官网：https://github.com/alibaba/designable#readme
- 源码仓库：git+https://github.com/alibaba/designable.git
- npm 页面：https://www.npmjs.com/package/@formily-design/formily-designer
