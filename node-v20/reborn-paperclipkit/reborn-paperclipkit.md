# reborn-paperclipkit

> 标签: agent-skills, ai-agents, claude, claude-code, hermes, multi-agent, orchestration, paperclip, skill

## 简介

Paperclip — 오픈소스로 AI 에이전트를 회사처럼 굴리는 관제 도구를 지금 어떻게 설치하고 무엇을 조심할지 알려 주는 클로드 코드 스킬. 설치 명령, 필요한 Node 판, 예산 상한, 에이전트가 쓰는 비용, 로컬에서 켜 둬야 돈다는 사실까지 먼저 말한다.
