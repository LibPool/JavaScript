# @pocket-ai/connector

> 标签: JavaScript

## 简介

Pocket AI 连接器：把你本机的 Claude Code / Codex / OpenClaw / Hermes 编码 agent 桥接到手机（E2EE，出站连接）。npx 一行启动 + 二维码配对。
