> 标签: collaborative, csv, data-grid, defter, editable-grid, grid, markdown-spreadsheet, react, react-data-grid, react-spreadsheet, spreadsheet, themeable, typescript, xlsx, yjs

## 简介

React renderer for Defter — a thin, themeable (CSS-variable) grid projection of the text model. Bring your own Y.Text for collaboration.
