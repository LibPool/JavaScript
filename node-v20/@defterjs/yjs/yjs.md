# @defterjs/yjs

> 标签: awareness, collaboration, collaborative-editing, crdt, defter, presence, realtime, spreadsheet, typescript, y-text, yjs

## 简介

Bind a Defter grid to a Yjs Y.Text for collaboration. Inject the shared type; the transport, persistence, and awareness stay entirely the host's concern.
