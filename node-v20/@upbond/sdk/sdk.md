# @upbond/sdk

> 标签: JavaScript

## 简介

RP 開発者が **UPBOND ID（OIDC）+ 埋め込みウォレット（MPC/TSS）+ リカバリ**を数行で組み込むための SDK（`docs/00-BUILD-SPEC.md` §1）。auth0-spa-js や `@web3auth/*` を直接使わずに済ませることが目的。
