# totalfusion

> 标签: ai, go, interop, ipc, machine-learning, mcp, python, rust, sandbox, streaming, total.js, totaljs, wasm, webassembly, worker, workers

## 简介

Extends Total.js with Python, Rust, Go and WebAssembly: supervised workers, contracts that become actions and MCP tools, streaming, binary data and development reload.
