# @marketcheck/mcp-client

> 标签: automotive, car-search, claude, dealer, marketcheck, mcp, model-context-protocol, pricing, vehicle, vin

## 简介

MCP client for MarketCheck automotive data API. Connects Claude Desktop, Claude Code, and other MCP clients to MarketCheck's vehicle search, pricing, VIN decode, and market analytics tools via a remote server.
