# @bymax-one/nest-storage

> 标签: aws-s3, backblaze-b2, cloudflare-r2, digitalocean-spaces, minio, multipart-upload, nestjs, object-storage, presigned-url, s3, storage, wasabi

## 简介

Provider-agnostic S3-compatible object storage for NestJS. Works with AWS S3, DigitalOcean Spaces, Cloudflare R2, Backblaze B2, MinIO, Wasabi.
