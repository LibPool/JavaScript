# @bymax-one/nest-ai-tokens

> 标签: ai, anthropic, billing, budget, gemini, ledger, llm, markup, metering, nestjs, openai, pricing, tokens, usage-based-billing, wallet

## 简介

AI token metering & usage-based billing for NestJS 11: provider usage normalizer (×9), versioned effective-dated pricing, immutable append-only ledger, prepaid wallets, multi-dimension budgets, and markup/margin. Zero runtime dependencies.
