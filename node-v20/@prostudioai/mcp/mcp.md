# @prostudioai/mcp

> 标签: ai, createstudio, image-generation, mcp, model-context-protocol, prostudio, video-generation

## 简介

Stdio MCP server that lets MCP-capable agents (Claude Desktop, Claude Code, Cursor) drive ProStudio's hosted image/video/audio generation API as native tools.
