# @jataka/core

> 标签: astrology, dasha, jyotish, nakshatra, panchang, sidereal, vedic-astrology

## 简介

A Vedic astrology (Jyotish) engine: sidereal chart, nakshatra, Vimshottari dasha, panchang and Rahu kalaya. Pure TypeScript, runs in browsers, Node and React Native.
