# @nexustools/releasepackager

> 标签: cross-platform, deb, dmg, executable, flatpak, installer, msi, nexustools, packager, release, zip

## 简介

Pure Node.js cross-platform executable and application release packager generating Windows (.zip, .msi), macOS (.dmg with drag-to-Applications .app), and Linux (.deb, .flatpak, .zip) releases with zero external tool dependencies
