# @istar-ts/gmodel

> 标签: glsp, gmodel, goal-model, istar, istar2, pistar

## 简介

The GModel (GLSP's notation model) of an istar-ts model, as plain schema JSON: framework-free, depends only on @istar-ts/core and @istar-ts/actions.
