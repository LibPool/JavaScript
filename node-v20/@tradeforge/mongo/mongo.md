# @tradeforge/mongo

> 标签: algorithmic-trading, backtest, backtesting, crypto, cryptocurrency, ioredis, mongodb, mongoose, persistence, redis, storage, trading, trading-bot

## 简介

MongoDB + Redis persistence adapter for tradeforge. Replaces the default file-based storage with a production-grade backend — O(1) reads via Redis, atomic writes via Mongoose.
