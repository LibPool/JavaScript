# @cstack-dev/convex-s3

> 标签: aws-s3, component, convex, convex-component, file-upload, minio, multipart-upload, presigned-url, r2, s3, storage

## 简介

A Convex component for S3-compatible storage (AWS S3, Cloudflare R2, MinIO): browser uploads with multipart and resume, presigned and public URLs, prefixes and folders, copies and deletes, with the R2 component's API.
