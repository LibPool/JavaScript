# @git-ai/cli

> 标签: ai, cli, commit, git

## 简介

一个基于 AI 的 Git 提交消息生成器 CLI 工具，可自动分析代码变更并生成符合规范的提交信息

## 官网

- 源码仓库：git+https://github.com/code-ba/git-ai.git
- npm 页面：https://www.npmjs.com/package/@git-ai/cli
