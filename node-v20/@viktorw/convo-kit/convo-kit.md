# @viktorw/convo-kit

> 标签: JavaScript

## 简介

Two small, generic React building blocks for LLM chat UIs. Framework/LLM/database agnostic — bring your own chat state (e.g. the Vercel AI SDK's `useChat`); this package is a UI shell only.
