# @camstack/nx-plugin

> 标签: addon, camstack, deploy, nx, nx-plugin

## 简介

Nx plugin for CamStack addon authors — `deploy` executor and `addon` generator. Drop into any Nx workspace to package + push addons to a running CamStack hub from the CLI.
