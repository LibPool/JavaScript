# @camstack/addon-export-ha-mqtt

> 标签: addon, camstack, camstack-addon, discovery, home-assistant, mqtt

## 简介

HomeAssistant MQTT discovery exporter for CamStack devices. Publishes discovery topics so HA auto-creates entities for exposed cameras/switches/intercoms/sensors.
