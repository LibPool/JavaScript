# @living-agents/reference

> 标签: a2a, agent-identity, ai-agents, authorization, did, ed25519, jws, mcp, merkle, protocol, rfc9421, sigstore

## 简介

Living Agents Protocol (LAP) reference implementation: agent passport (LIP-1), scope algebra (LIP-3), Micro-Core request verification and receipts (LIP-4), RFC 6962 Merkle log, Sigstore Rekor binding. Zero dependencies.
