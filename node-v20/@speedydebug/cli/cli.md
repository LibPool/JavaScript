> 标签: agent, bug-report, claude-code, cli, cursor, expo, feedback, react-native, speedydebug, windsurf

## 简介

Speedydebug CLI — read and fix your app's bug reports from any coding agent with one access token. `speedydebug bugs` / `read` / `fix`.
