# @tinasoft/miniapp-host-demo

> 标签: mini-app, module-federation, react-native, repack, super-app, webview

## 简介

Host mini apps inside a React Native app: WebView mini apps with a secure token bridge and log forwarding, and React Native mini apps loaded with Re.Pack / Module Federation.
