# @lumifai/harness-model-codex-oauth

> 标签: JavaScript

## 简介

Mastra model gateway that bills OpenAI requests to a ChatGPT / Codex subscription (Plus, Pro, Team, Business, or Enterprise) instead of a Platform API key. Registering it lets any harness model string of the form `codex-oauth/openai/<model-id>` run agains
