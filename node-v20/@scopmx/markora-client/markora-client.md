# @scopmx/markora-client

> 标签: annotation, canvas, drawing, editor, fabric, fabricjs, markup, pdf, react

## 简介

Fabric.js markup and drawing editor for React — shapes, text, PDF and image backgrounds, comments, version history, PDF/image/HTML export, and multi-user saving to @scopmx/markora-server.
