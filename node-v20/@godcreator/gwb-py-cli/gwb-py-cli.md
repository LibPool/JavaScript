# @godcreator/gwb-py-cli

> 标签: gwb-plugin

## 简介

运行 python 写的命令行工具：在调用方插件的包根下用 uv 建 venv、启动里面的可执行文件（本插件自己不带 python 项目）。服务 gwbPyCli；skill 1 份；命令 1 条。
