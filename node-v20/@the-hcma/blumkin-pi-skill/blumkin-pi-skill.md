# @the-hcma/blumkin-pi-skill

> 标签: blumkin, microsoft-365, microsoft-graph, outlook, pi-package, pi-skill, teams

## 简介

Pi package exposing the blumkin Agent Skill (personal Microsoft 365 via the blumkin CLI: calendar, mail, Teams chat, free/busy). Requires the separately installed `blumkin` binary on PATH.
