# @orchestral/discovery

> 标签: agents, ai, bm25, llm-tools, orchestration, pattern-registry, retrieval, search, tool-discovery, typescript

## 简介

Pattern discovery layer for @orchestral/core — a BM25 search index over a PatternRegistry plus the find_pattern tool handler that turns a free-form LLM query into ranked Pattern descriptors. Retrieval, not contract: core stays search-free.
