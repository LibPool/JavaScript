# @noeva/agents-mcp

> 标签: JavaScript

## 简介

MCP server for the NOEVA Mastra agents — lets external LLMs invoke NOEVA agents and converse with them over the noeva-agents server (chat SSE, threads). Ships an HTTP service (central deploy) and a stdio package (client-distributable).
