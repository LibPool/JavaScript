# dsh-doc-outline

> 标签: doc, documentation, dsh, heading, markdown, outline, plugin, toc

## 简介

doc outline toolkit for DeepSeek Harness: md_outline (build markdown heading tree), check_toc (verify TOC vs heading consistency), insert_toc (generate and insert a TOC). Zero runtime dependencies, read-only by default.
