# @devchecks/configcheck

> 标签: config, dotenv, env, security, validation, yaml

## 简介

Validate configuration: .env drift against .env.example, required and typed variables, JSON/YAML syntax, and risky settings such as debug mode, CORS wildcards and disabled TLS verification.
