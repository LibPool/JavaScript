# @mvarble/mesearch

> 标签: cli, katex, markdown, mdsvex, notes, static-site, svelte, sveltekit

## 简介

An opinionated static site for a library of agent-written notes: concepts, writeups and sequences under content/, rendered as a textbook with KaTeX, a dependency graph and an index.
