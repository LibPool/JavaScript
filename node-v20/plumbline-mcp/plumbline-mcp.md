# plumbline-mcp

> 标签: deepbook, market-data, mcp, model-context-protocol, orderbook, read-only, sui

## 简介

Plumbline: a free, read-only MCP server for Sui DeepBook v3 market data (pools, mid price, depth, volume, fees, trades, OHLCV). Education/information only, not financial advice.
