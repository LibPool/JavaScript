# @nexus-ioc/graph-analyzer

> 标签: ast-parser, code-analysis, dependency-graph, dependency-injection, di-container, graph-visualization, graphviz, nexus-ioc, static-analysis, typescript

## 简介

Static analysis and visualization tool for Nexus IoC dependency injection graphs. Detect circular dependencies, unused providers, scope mismatches, and visualize your architecture with interactive HTML graphs.
