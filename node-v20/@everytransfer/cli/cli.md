# @everytransfer/cli

> 标签: cli, everytransfer, file-sharing, file-transfer, mcp, model-context-protocol, wetransfer

## 简介

Command line client and MCP server for EveryTransfer — send large files and get a share link from your terminal or from an AI assistant.
