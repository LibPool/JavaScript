# @nx-lang/previewer

> 标签: JavaScript

## 简介

Unstable. Runs one NX component as a headless preview session on @nx-lang/ir-runtime: a timeline of ticks with branches, dispatch by handler, scenarios and hot reload. No UI and no framework.
