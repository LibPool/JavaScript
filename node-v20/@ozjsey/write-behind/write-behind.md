# @ozjsey/write-behind

> 标签: auto-save, autosave, batch-save, debounce-save, dirty-tracking, framework-agnostic, local-first, offline, optimistic, outbox, retry, sync, typescript, write-back, write-behind, zero-dependencies

## 简介

Write-behind cache in plain TypeScript — local state stays authoritative, the server's reply is discarded on purpose, and a slow response can never clear a newer edit
