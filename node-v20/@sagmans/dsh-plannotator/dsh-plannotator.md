# @sagmans/dsh-plannotator

> 标签: code-review, cordis, deepseek-harness, dsh, dsh-plugin, plan-review, plannotator, plugin, tui

## 简介

Plannotator browser review surfaces for the DeepSeek Harness terminal profile: plan review, code review, file annotation, and last-answer annotation, driven on demand from slash commands.
