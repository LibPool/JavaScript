# @vantageos/agent-engine

> 标签: agents, ai-agents, convex, convex-component, durable-agents, vantageos, workflow

## 简介

Reusable Convex component: durable agent engine. Agent = data aggregate (root sheet + child tables), never compiled code. Built on @convex-dev/workflow + @convex-dev/workpool (+ @convex-dev/agent). Eve parity by design.
