# @frostbase-dev/storage

> 标签: agents, cloudflare, durable-objects, frostbase, object-storage, r2, storage, workers

## 简介

Object storage on Cloudflare R2 - buckets of files with per-bucket access modes, an object index with keyset paging, one Durable Object orchestrator per project - the storage primitive behind Frostbase.
