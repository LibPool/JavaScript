# @typren/adapter-media-s3

> 标签: cms, media, minio, r2, s3, supabase, typren

## 简介

S3-compatible media adapter for typren: one MediaAdapter over any S3 API-compatible object store (Cloudflare R2, Supabase Storage, AWS S3, MinIO). Edge-compatible, fetch + WebCrypto only, no node:fs or sharp.
