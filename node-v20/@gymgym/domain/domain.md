# @gymgym/domain

> 标签: JavaScript

## 简介

Pure training logic and importers shared by the gymgym app, CLI and SDK: progression rules, plan documents, workout parsing, Strong/Hevy/FitNotes import and plan sharing. No I/O, no framework.
