# @gymgym/catalog

> 标签: JavaScript

## 简介

The gymgym exercise library: 5,632 exercises with names in 17 languages and instruction steps in all 17. Data lives in data/ (catalog.json, instructions, names); scripts rebuild it from the upstream datasets.
