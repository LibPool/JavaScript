# @jonathanleelx/dsh-balance

> 标签: balance, cordis, deepseek, dsh, harness, plugin, web-ui

## 简介

dsh bundle: DeepSeek account balance on the DeepSeek Harness Web surface — /api/dsh-balance route, a draggable balance badge injected via index tap, and a no-store index override for caching proxies.
