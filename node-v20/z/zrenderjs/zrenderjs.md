# zrenderjs

> 标签: 2d, canvas, chart, echarts, graph, svg, vml, webpack, zrender

## 简介

A lightweight canvas library which providing 2d draw for ECharts。一个轻量级的Canvas类库，MVC封装，数据驱动，提供类Dom事件模型，让canvas绘图大不同！
