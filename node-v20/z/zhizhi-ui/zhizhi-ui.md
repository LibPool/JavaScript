# zhizhi-ui

> 标签: JavaScript

## 简介

- 所有的组件必须写在packages目录下 - 以组件的名称作为文件夹名，首字母必须大写，如： `packages/HelloWorld/index.js` - 组件内部必须声明 `name` 属性 - `name` 属性全部为小写字母，单词间用 `-` 来间隔 - style声明必须加上 `scoped` 关键字 - 组件最外层的样式名格式：`${name}_wrapper` - 样式单位为 `px`
