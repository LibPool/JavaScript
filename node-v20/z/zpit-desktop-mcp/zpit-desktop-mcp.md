# zpit-desktop-mcp

> 标签: JavaScript

## 简介

Desktop-control MCP server for zpit (https://github.com/zac15987/zpit). Fork of @zavora-ai/computer-use-mcp with Windows AUMID launch support and zpit-specific fixes. Cross-platform (macOS + Windows), backed by Rust NAPI.
