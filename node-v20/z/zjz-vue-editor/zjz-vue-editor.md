# zjz-vue-editor

> 标签: editor, vue, 编辑器

## 简介

> 基于vue wangeditor二次封装的富文本编辑器,大大简化了原wangeditor的多数配置项,仅需传入一个上传图片的url地址即可 ## 安装 ``` npm i zjz-vue-editor ```
