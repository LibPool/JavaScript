# zinnector

> 标签: cli, deploy, hosting, playground, wordpress, zinn, zinnector

## 简介

Zinnector — the Zinn Digital developer CLI. Scaffold a WordPress site, run it locally with no Docker required, pre-flight it against the slot you are about to deploy to, and push. Built on the public Zinn Digital API.
