# zkd-cli

> 标签: JavaScript

## 简介

### 背景 团队中每个人的代码风格不一致，代码`push`上来之后，其他成员保存后全是`diff`的差异，看起来非常难受，就想着从`husky`入手，把一些规范类、代码风格类以及业务库，写成一个自动化工具，快速迭代。
