# zetta-beaglebone-proxy

> 标签: JavaScript

## 简介

Create a npm proxy and zetta cloud proxy for beaglebone usb tethering without usb internet sharing.

## 官网

- npm 页面：https://www.npmjs.com/package/zetta-beaglebone-proxy
