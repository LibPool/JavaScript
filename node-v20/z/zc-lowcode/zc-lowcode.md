# zc-lowcode

> 标签: lowcode, lowcode-editor

## 简介

Vue 3 可视化页面搭建 SDK。提供 **设计器** 与 **运行时** 两套入口，共享同一套 Page 协议与物料协议，可快速嵌入你的业务系统。
