# zeba

> 标签: fully trim extra spaces from front, between and end, javascript, library, npm, remove extra spaces from strings, string manipulation, uppercase all letters in a string, uppercase first letter of a string, uppercase first letter of each words in a string, zeba

## 简介

A very lightweight JavaScript library for taking out extra spaces in a string, can make first letter of a string, first letter of each words in a string or all letters in a string to uppercase.
