# z3-solver

> 标签: Z3, prover, satisfiability, satisfiability modulo theories, smt, solver, theorem

## 简介

This project provides high-level and low-level TypeScript bindings for the [Z3 theorem prover](https://github.com/Z3Prover/z3). It is available on npm as [z3-solver](https://www.npmjs.com/package/z3-solver).

## 官网

- 官网：https://github.com/Z3Prover/z3/tree/master/src/api/js
- 源码仓库：git+https://github.com/Z3Prover/z3.git
- npm 页面：https://www.npmjs.com/package/z3-solver
