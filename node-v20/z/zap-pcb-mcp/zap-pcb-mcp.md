# zap-pcb-mcp

> 标签: ai-agent, autorouter, autorouting, drc, eda, freerouting-alternative, jlcpcb, kicad, mcp, model-context-protocol, pcb

## 简介

KiCad PCB autorouter MCP server (Zap!): route a placed .kicad_pcb and get a JSON manufacturability report (DRC, shorts, JLCPCB capability, copper heat). Keyless trial for small boards.
