# zq_auto_publish

> 标签: JavaScript

## 简介

# 使用方式 1. npm link  2. 在 /Users 文件夹下添加 config.js 文件 3. 在 config.js 文件中更改对应的 codePath、buildPath 地址 4. auto p test  发布 测试 test-build 版本 5. auto p pre  发布 预上线 pre-build 版本 6. auto p pro  发布 正式 build 版本
