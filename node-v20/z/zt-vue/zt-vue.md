# zt-vue

> 标签: JavaScript

## 简介

随便写的组件 此版不是特别遵从vue的组件思想 即事件从子组件到父组件 数据从父组件流向子组件 即单向数据流和尽量解耦的原则 写给自己用的 利用了一些简单的方法避开了vue在开发环境下 检查子组件更改父组件数据的控制台警告 如果你特别在意这点 就可以右上角x了
