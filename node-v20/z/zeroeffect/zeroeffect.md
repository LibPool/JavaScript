# zeroeffect

> 标签: dom, esm, framework, no-proxy, no-signal, no-virtual-dom, reactive, typescript, ui

## 简介

A reactive DOM library with no Signal, no Proxy, no Virtual DOM. Just plain JavaScript objects.
