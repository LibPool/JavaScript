# ze-mcp-unofficial

> 标签: ai-agents, drinks, local-first, mcp, model-context-protocol, ze, ze-delivery

## 简介

Unofficial local-first Zé Delivery MCP for catalog, product search and order tracking. Never pays unless ZE_ALLOW_MUTATIONS and explicit_user_intent are both set.
