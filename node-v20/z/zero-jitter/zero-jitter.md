# zero-jitter

> 标签: ai, canvas, chatgpt, cjk, claude, i18n, jitter, layout-thrashing, llm, next-js, nextjs, performance, react, remix, rtl, server-sent-events, sse, streaming, text-rendering, token-streaming, virtualized-text, vite, web-worker

## 简介

Zero-layout-jitter streaming text renderer for LLM tokens. Off-thread measurement (Web Worker + pretext) + canvas paint. Works in React, Next.js, Vite, Remix.
