# zsh-github-issues

> 标签: github issues, github issues notifications, zsh

## 简介

Subscribe to projects on Github and receive within shell (under prompt) notifications about new issues.

## 官网

- 官网：https://github.com/zdharma/zsh-github-issues
- npm 页面：https://www.npmjs.com/package/zsh-github-issues
