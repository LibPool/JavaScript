# zhq

> 标签: chinese, chinese-text, faq, jieba, nlp, search, text-similarity, tf-idf, zhq

## 简介

🔍 ZHQ 是一個基於 BM25 與 Jieba 斷詞 的中文檢索引擎，完全運行於客戶端，適用於 問答、搜尋、內容推薦、文本比對。
