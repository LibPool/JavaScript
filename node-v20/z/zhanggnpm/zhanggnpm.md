# zhanggnpm

> 标签: JavaScript

## 简介

- 全局安装 ```     npm install -g webpack ```     - 让webpack可以在全局下使用     - 全局变量里的可以直接使用 npm里映射了一个webpack指向了真实的文件 - 安装本地 - 开发时候的依赖(在开发的时候才用到，上线的时候用不到了) ```     npm install --save-dev 文件名 ``` - 写代码时候的依赖(代码依赖，必须要存在) ```     npm install --save 文件名 `
