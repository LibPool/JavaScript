# zkbiotime-sdk

> 标签: attendance, biotime, biotime8, client, rest, sdk, time-attendance, typescript, zkbiotime, zkteco

## 简介

Typed, isomorphic TypeScript client for the ZKBioTime / BioTime 8 REST API (personnel, iclock devices, attendance).
