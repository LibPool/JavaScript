# zipzy-icons

> 标签: brand-icons, currentColor, dashboard, hrms, icon-library, icons, logo, logomark, payments, product-icons, react, react-icons, react-svg, svg, svg-icons, tailwind, tailwindcss, tree-shakeable, typescript, zipzy, zipzy-dashboard, zipzy-hrms, zipzy-icons, zipzy-payments

## 简介

Lightweight, customizable React SVG icon library for ZipZy products — logomarks, wordmarks, and product icons (HRMS, Payments, Dashboard) with TypeScript support and Tailwind CSS compatibility.
