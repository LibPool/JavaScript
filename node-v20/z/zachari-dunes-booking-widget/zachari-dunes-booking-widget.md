# zachari-dunes-booking-widget

> 标签: JavaScript

## 简介

An embeddable widget by [Smarter Labs](http://smarterlabs.com/) for [WeCreate](https://www.wecreate.one/) that takes user information for booking a hotel and directs the user to the [Hilton website](https://www.hilton.com/) to complete the transaction.
