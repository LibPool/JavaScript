# zettel-compress

> 标签: aaak, agent-memory, ai-sdk, bm25, context-compression, conversation-history, deterministic, edge, edge-compatible, langchain, llm, local-first, memory, nlp, offline, rag, retrieval, token-reduction, zettel, zettelkasten

## 简介

Deterministic memory engine for LLM apps — compress, search, and inject conversation memory offline, on-device, or at the edge. Zero external calls, zero infrastructure, zero dependencies.
