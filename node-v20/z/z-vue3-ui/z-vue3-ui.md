# z-vue3-ui

> 标签: JavaScript

## 简介

[查看项目](http://wangfan.store) ### 项目介绍 本项目是为了学习vue3.0而写的一个组件库，使用`typescript`、`less`可以让你快速学习vue3的新特性。项目仅供学习。（请勿在生产环境中使用） ### 重要概念     1. 数据响应式     2. 组件化     3. 编译     4. 事件、双向绑定、插槽     5. 缓存组件、动画（transition）     6. Vue-Router     9. Vuex
