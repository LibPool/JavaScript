# zx-list-chat

> 标签: JavaScript

## 简介

一个基于 uni-app、Vue3 <script setup> 语法开发的高兼容性聊天列表项组件，适配 H5、小程序、App。可嵌入于 zx-list 组件中，支持头像、群头像、角标、时间、草稿、跳转等功能，适合自定义各类聊天/会话列表场景。
