# zread-mcp

> 标签: ai, claude, code-repository, documentation, llm, mcp, mcp-server, model-context-protocol, zread

## 简介

Zread.ai MCP Server - 连接 zread.ai 文档平台的 MCP 服务器，让 AI 助手能够阅读 GitHub 仓库文档、搜索代码、与仓库 AI 对话。
