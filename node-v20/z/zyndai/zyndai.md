# zyndai

> 标签: agent, agent-network, ai, ed25519, micropayments, sdk, webhook, x402, zyndai

## 简介

Multi-framework AI agent SDK for the Zynd AI Network. Ed25519 identity, agent discovery, A2A protocol communication, agent cards, x402 micropayments, and one-shot deploy via zynd-deployer.
