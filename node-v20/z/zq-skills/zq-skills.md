# zq-skills

> 标签: agent, claude-code, cli, codex, cursor, skills, zq-skills

## 简介

zq-skills 平台 skill 的命令行安装器——一键安装付费/免费 skill 到 Claude Code、Codex、Cursor 或豆包等网页端 agent（API-only：数据源为 platform 的 /v1/skills 与 /v1/skills/{id}/client）
