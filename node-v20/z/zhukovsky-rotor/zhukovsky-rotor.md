# zhukovsky-rotor

> 标签: Helicopter, Main rotor, Rotor diameter, Rotor figure of merit, Rotor power, Rotor thrust

## 简介

It provides few simple formulas for estimating helicopter rotor parameters in hovering flight. Those should be use only as a rule of thumb only, for getting the very initial idea.
