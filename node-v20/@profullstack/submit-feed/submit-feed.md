# @profullstack/submit-feed

> 标签: atom, directory, feed, feed-discovery, json-feed, mcp, opml, p0dcasters, podcast, rss, rssamplifier, ssrf, submit

## 简介

One way to add a feed to a directory, shared by every Profullstack site that takes one. Turns whatever a person pastes into a feed: normalises the URL, refuses private addresses, discovers the feed behind a site, parses RSS, Atom and JSON Feed at channel
