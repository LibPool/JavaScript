# @profullstack/encrypt

> 标签: chacha20-poly1305, e2ee, encryption, hkdf, kyber, mcp, ml-kem, post-quantum, qrypt

## 简介

Quantum-resistant encrypt/decrypt: qrypt.chat's ML-KEM-1024 + HKDF-SHA-256 + ChaCha20-Poly1305 by default, with room for more algorithms. Library, CLI and MCP server.
