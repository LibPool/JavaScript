# @profullstack/tsbb-mcp

> 标签: bulletin-board, forum, mcp, model-context-protocol

## 简介

MCP server for a tsbb bulletin board. Lets an AI assistant read and post on any board, as the member whose token it holds.

- 官网：https://tsbb.dev
- 源码仓库：git+https://github.com/profullstack/tsbb.git
