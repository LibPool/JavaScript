# @profullstack/throttle

> 标签: 402, anti-scraping, coinpay, crawler, hono, middleware, nextjs, payment-required, rate-limit, scraping, throttle, usdc, x402

## 简介

An app-wide rate limit whose answer to going over is a price, not a 429. 100 requests a minute free, then x402 Payment Required with an offer, settled by CoinPay. Meters every route, so a scraper wearing a browser user agent is charged like any other craw
