# @profullstack/wx93-mcp

> 标签: agents, mcp, model-context-protocol, short-links, url-shortener

## 简介

MCP server for wx93.me: let any MCP client shorten URLs, list links and read click stats. Same tools as the hosted https://wx93.me/mcp.

- 官网：https://wx93.me/docs#mcp
