# @profullstack/libsql-pg

> 标签: adapter, copy, drop-in, libsql, migration, pg, port, postgres, postgresql, schema, sqlite, turso

## 简介

Drop-in replacement for @libsql/client that talks to Postgres, plus the tools to move a Turso/libSQL database into it: the same execute/batch/transaction surface, SQLite idioms rewritten on the way through, a schema converter and a row copier.
