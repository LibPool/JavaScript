# @chuva.io/less-cli

> 标签: aws, c#, cloud, deploy, distributed, event-driven, events, fault tolerant, go, infinite scale, infrastructure, javascript, less, less-cli, microservice, pub/sub, python, realtime, rest api, rust, serverless, websocket

## 简介

`less-cli` is a CLI tool that allows you to deploy your Less projects to AWS while providing several other tools to facilitate your interaction with Less.
