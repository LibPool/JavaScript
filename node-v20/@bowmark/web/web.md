# @bowmark/web

> 标签: agent, bowmark, browser-automation, capability, typescript

## 简介

The public client for the Bowmark capability library — real TypeScript for the whole bowmark.* surface, with no Bowmark source on the caller's disk. ZERO runtime dependencies, deliberately and permanently.
