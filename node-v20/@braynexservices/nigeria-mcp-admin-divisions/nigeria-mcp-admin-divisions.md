# @braynexservices/nigeria-mcp-admin-divisions

> 标签: administrative-divisions, geography, lga, mcp, model-context-protocol, nigeria, offline, states

## 简介

Nigeria's 36 states + FCT and 774 LGAs as MCP tools — list states with LGA counts, and get an LGA breakdown for any state. Fully offline bundled dataset; no network, no key.
