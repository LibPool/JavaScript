# @ubuligan/locknpm

> 标签: airgap, cli, npm, offline, tgz, vendor

## 简介

List and install pre-packed .tgz npm archives offline, from a bundled vendor directory or any folder on your machine.

## 官网

- npm 页面：https://www.npmjs.com/package/@ubuligan/locknpm

- npm 安装：`npm install @ubuligan/locknpm`
- npm registry：https://registry.npmjs.org/@ubuligan/locknpm
- Node 要求：>=18
