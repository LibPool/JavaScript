# @sebastienrousseau/crypto-edge

> 标签: bun, cloudflare-workers, cryptography, deno, edge, encryption, runtime-detection, serverless, vercel-edge, webcrypto

## 简介

Edge and serverless cryptography for Cloudflare Workers, Vercel Edge, Deno, Bun and browsers, with runtime detection and a Web Crypto API adapter for crypto-lib.
