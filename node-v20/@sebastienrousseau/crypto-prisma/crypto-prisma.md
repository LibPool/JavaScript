# @sebastienrousseau/crypto-prisma

> 标签: cryptography, database-encryption, encryption, field-level-encryption, orm, prisma, prisma-extension, xchacha20-poly1305

## 简介

Prisma Client extension for transparent field-level encryption with XChaCha20-Poly1305: encrypt chosen model fields before they reach the database.
