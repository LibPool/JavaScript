# @elthratech/shopagent-react

> 标签: ai-agent, chatbot, customer-support, ecommerce, react, shopagent

## 简介

Drop-in React chat widget for ShopAgent-OS, a self-hosted e-commerce AI agent. Answers product, order status, and policy questions against your own store backend.
