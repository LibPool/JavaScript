# @accesslumens/mcp

> 标签: a11y, accessibility, axe-core, mcp, model-context-protocol, wcag

## 简介

AccessLumens accessibility scanner as an MCP server: WCAG checks, keyboard traps, reflow and focus, for any URL including localhost. Free.
