# @integrattion/telemetria

> 标签: integrattion, performance, rum, telemetry, web-vitals

## 简介

Telemetria leve de performance percebida (T0-T4 + web-vitals) para os sistemas do ecossistema Integrattion. Núcleo <=3KB gzip, carregado fora do caminho crítico.
