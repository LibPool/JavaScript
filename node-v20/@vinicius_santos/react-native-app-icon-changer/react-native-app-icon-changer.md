# @vinicius_santos/react-native-app-icon-changer

> 标签: android, ios, react-native

## 简介

react-native-app-icon-changer is a tool for easily updating the app icon of your React Native project for both iOS and Android platforms. This package simplifies the process of changing the default app icon without needing to manually modify platform-spec
