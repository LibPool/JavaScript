# @klutometis/linkedin-mcp

> 标签: linkedin, mcp, messaging, model-context-protocol, unipile

## 简介

Stdio MCP server exposing LinkedIn (via Unipile) as a mood-neutral primitive surface. Read: list_threads, read_thread, search, fetch_attachment, list_relationship_requests, get_profile. Write: set_thread_state, send_message, send_invitation, respond_to_in
