# @esimfly/mcp

> 标签: ai-agent, claude, connectivity, cursor, esim, esimfly, mcp, model-context-protocol, travel

## 简介

MCP server for the eSIMfly Business API — let Claude, ChatGPT, Cursor and other AI agents search eSIM plans, check usage, diagnose connectivity and (optionally) place orders
