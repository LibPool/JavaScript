# @fernandoslim/odoo-jsonrpc

> 标签: client, external-api, json-2, json2, jsonrpc, odoo, rpc, typescript

## 简介

A lightweight Odoo client for JSON-RPC and the JSON-2 API (Odoo 19+), with zero dependencies.
