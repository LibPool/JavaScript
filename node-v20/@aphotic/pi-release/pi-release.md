# @aphotic/pi-release

> 标签: pi-package

## 简介

Standalone, project-agnostic release skill for Pi: drives single-package and monorepo releases through one interface with shape auto-detection, a full security audit, manual release-notes review, user-owned credentialed actions, and a governed .pi/release
