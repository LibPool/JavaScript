# @flagsman/sdk-node

> 标签: feature-flags, feature-toggles, flagsman, local-evaluation, sdk

## 简介

Flagsman server-side SDK for Node.js — in-process feature-flag evaluation, byte-identical to the backend decide(). Zero runtime dependencies.
