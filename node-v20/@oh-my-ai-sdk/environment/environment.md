# @oh-my-ai-sdk/environment

> 标签: JavaScript

## 简介

Turn-scoped execution Environment for AI SDK agents: (host, fs, user, cwd) behind one ctx feeding a whole tool suite — bash and fs tools share the same environment by construction.
