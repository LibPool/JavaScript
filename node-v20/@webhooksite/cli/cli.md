# @webhooksite/cli

> 标签: api, forward, mock, mocking, ngrok, proxy, redirect, requestbin, testing, tunnel, webhook, webhook.site

## 简介

A console utility used to interact with the Webhook.site API and proxy/forward/tunnel requests from a Webhook.site URL to any destination on your local network.
