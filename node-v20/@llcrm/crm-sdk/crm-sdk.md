# @llcrm/crm-sdk

> 标签: crm, fetch, liguelead, openapi, sdk, typescript

## 简介

Official TypeScript SDK for the LigueLead CRM API. Generated from OpenAPI 3.1 with hand-authored auth, cursor pagination, and typed errors.
