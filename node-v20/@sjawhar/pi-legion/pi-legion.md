# @sjawhar/pi-legion

> 标签: JavaScript

## 简介

`@sjawhar/pi-legion` is the Oh My Pi plugin a Legion pane loads beside `@sjawhar/pi-envoy` (`packages/pi-envoy`). It carries one extension entry, `extensions/legion.ts`: the Legion lifecycle, which boots a root architect or a phase worker from the daemon'
