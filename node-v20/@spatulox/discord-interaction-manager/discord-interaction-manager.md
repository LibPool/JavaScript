# @spatulox/discord-interaction-manager

> 标签: cli, context menu, discord, interaction, slash commands

## 简介

discord-interaction-manager is a lightweight CLI tool to manage Discord bot interactions (slash commands, context menus) in under 30 seconds. Deploy, update, delete, and generate interaction files with an interactive terminal interface.
