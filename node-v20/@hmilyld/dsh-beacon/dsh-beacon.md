# @hmilyld/dsh-beacon

> 标签: cordis-plugin, deepseek-harness, dsh, notification, webhook

## 简介

DSH (DeepSeek Harness) webhook beacon: POST a JSON payload with variable substitution when a task completes or the agent needs user questions, plan confirmation, or approval.
