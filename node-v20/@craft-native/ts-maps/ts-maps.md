# @craft-native/ts-maps

> 标签: craft, cross-platform, maps, native, ts-maps, webview

## 简介

Craft SDK bindings for the ts-maps interactive map runtime. Provides a cross-platform MapView component backed by the MapProvider.ts_maps variant in the Zig core.
