# @amplytools/amply-mcp

> 标签: amply, analytics, claude, codex, mcp, mobile, model-context-protocol

## 简介

Local MCP server for Amply — lets AI agents sign up, log in, create projects/applications, and fetch API keys from the Amply admin GraphQL API.
