# @orkestrel/sea

> 标签: executable, node, sea, server, single-executable-application, typescript

## 简介

A pure-TypeScript Node.js Single Executable Application (SEA) builder — compresses assets, assembles the SEA blob, and injects it into PE/ELF/Mach-O binaries with no size ceiling. Part of the @orkestrel line.
