# @mikkel-ol/yatsi

> 标签: expose, http, localhost, self-hosted, sse, tunnel, tunneling, websocket

## 简介

Client CLI and library for YATSI, a self-hosted tunneling service. Expose a local HTTP, SSE, or WebSocket service through a temporary public URL.
