# @mac-xiang/autojs-dev-webpack-plugin

> 标签: AutoX, autojs, dev

## 简介

AutoX.js 的开发及部署工具,主要替换 VScode 插件 Auto.js-VSCodeExt-Fixed,且有别于"autox-deploy-webpack-plugin"因为他热更新有不及时等弊端.

## 官网

- 源码仓库：https://gitee.com/tmkmk/autojs-dev-webpack-plugin.git
- npm 页面：https://www.npmjs.com/package/@mac-xiang/autojs-dev-webpack-plugin
