# framefields

> 标签: audio-dsp, composition, headless-rendering, motion-graphics, signals, vfx, video, webgpu

## 简介

High-performance WebGPU rendering SDK for video composition, Photoshop-grade 2D VFX, audio DSP, and reactive signals. Built for AI Agents.
