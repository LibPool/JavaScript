# @butterfly-liu/gitlab-mcp

> 标签: api, claude, cursor, gitlab, mcp, model-context-protocol

## 简介

MCP (Model Context Protocol) server for GitLab: list/create/update projects, commits, files; list/create/update/merge merge requests and notes; list/create/update/delete issues and issue notes; list/get/create/update/delete wiki pages.
