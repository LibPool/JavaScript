# @alltomatos/izapia-mcp

> 标签: ai-agents, izapia, mcp, modelcontextprotocol, whatsapp

## 简介

Servidor MCP para a API WhatsApp da izapia (api.izapia.com) — conecte seu agente de IA pra enviar mensagens, gerenciar sessões/grupos/webhooks e construir integrações WhatsApp.
