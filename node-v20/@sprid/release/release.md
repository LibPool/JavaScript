# @sprid/release

> 标签: app-store-connect, aso, google-play, keywords, localization, metadata, screenshots

## 简介

Build, sign and release mobile apps locally. Store copy, screenshots, binary uploads and review submissions from one app-owned configuration. Dry run by default.
