# @goodandready/dsh-cron

> 标签: automation, cron, deepseek-harness, dsh, dsh-plugin, scheduler

## 简介

Background automation runner for DSH: isolated agent runs, script/HTTP/SSH/Docker runtimes, cost guard, notifications, heartbeats.
