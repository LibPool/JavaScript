# fizzl-paypal-guard-mcp

> 标签: agent-toolkit, agentic-commerce, ai-agents, approval, claude, cursor, guardrails, human-in-the-loop, mcp, mcp-server, model-context-protocol, paypal, refunds, telegram

## 简介

PayPal's Agent Toolkit as an MCP server for Claude, Cursor and any MCP client, guarded by fizzl-paypal-guard: never more than is left of a payment, the owner's limits, and Approve/Deny on the owner's phone (Telegram, Fizzl wallet) or in the chat app above
