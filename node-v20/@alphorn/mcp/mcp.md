# @alphorn/mcp

> 标签: ai-agents, alphorn, mcp, model-context-protocol, notifications, slack, sms, webhook

## 简介

MCP server for Alphorn: lets AI agents send notifications to Slack, email, SMS, push, and other channels through Alphorn.
