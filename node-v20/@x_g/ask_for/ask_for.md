# @x_g/ask_for

> 标签: JavaScript

## 简介

轻量级的命令行输入工具 # 用法 用例: ```javascript const askFor = require('@x_g/ask_for'); const {AskFor, askForConfirm} = require('@x_g/ask_for'); var response = await askFor("please enter"); var response = await askForConfirm(""); //肯定输入返回true，否定返回false，其余返回undefined `
