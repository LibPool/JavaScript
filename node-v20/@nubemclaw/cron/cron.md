# @nubemclaw/cron

> 标签: JavaScript

## 简介

NubemClaw v3 — cron scheduler runtime (F17). Replaces the F15 cronjob-tools.ts stub. SchedulerDriver pluggable (croner default in-process; BullMQ defer F18 multi-tenant gateway), lifecycle (queue → running → completed/failed/timeout/cancelled), retry/back
