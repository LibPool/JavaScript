# @adatechnology/game-vehicles-fleet

> 标签: cars, fleet, game, procedural, three, threejs, vehicles

## 简介

Fleet content pack for @adatechnology/game-vehicles: 69 procedural vehicles (motorcycles, cars, SUVs, pickups, vans, trucks, buses, tractors, military, boats, planes and helicopters), fuels, groups, generic crash scenarios and en / pt-BR texts.
