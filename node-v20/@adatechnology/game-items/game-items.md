# @adatechnology/game-items

> 标签: catalog, game, inventory, items, loot, survival

## 简介

Engine-agnostic item catalog engine: item definitions (category, size, weight, rarity, durability, shelf life, protection, carry), an extensible registry with patch/remove/include, and the default rules for finds, freshness, storage, carry weight and prot
