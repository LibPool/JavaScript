# @p-pavlo/git-profile

> 标签: cli, credential-helper, git, git-profile, gitconfig, github-token, gpg-signing, identity-manager, multi-account, ssh-key

## 简介

A lightweight, zero-dependency CLI identity manager to switch Git profiles, SSH keys, GPG keys, and service tokens instantly.
