# @bdocs/plugin-ask-ai

> 标签: JavaScript

## 简介

Context-aware AI assistant querying plugin for Boltdocs. OpenAI-powered, page-scoped, streaming. Ships the `<AskAiBubble />` and `<AskAiDialog />` client components for manual composition in custom layouts.
