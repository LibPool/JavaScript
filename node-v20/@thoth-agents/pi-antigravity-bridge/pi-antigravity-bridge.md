# @thoth-agents/pi-antigravity-bridge

> 标签: acp, agent-client-protocol, agy, antigravity, antigravity-acp, gemini, google, google-acp, mcp, mcp-server, pi-extension, pi-package, provider, streaming

## 简介

Gemini provider for Pi on the Antigravity ACP server (official Google ACP) or the stream-json agy CLI. Use antigravity/* models in Pi. Full /model picker support. Models runs Pi's tools. ToS safe to use.
