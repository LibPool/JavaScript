# @coda-console/review

> 标签: JavaScript

## 简介

会话开的 PR 从开出来起一条流程：每个新版本先跑项目声明的检查，再请另一家 Agent 评审，要求修改时交给开 PR 的会话处理、有分歧时交给你仲裁；通过后请你批准合并，合并后按你的选择调用项目的部署、发布流程，PR 合并或关闭时结束。
