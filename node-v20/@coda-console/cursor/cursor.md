# @coda-console/cursor

> 标签: JavaScript

## 简介

Cursor Agent：Coda 的入口在运行机的 Cursor CLI（cursor-agent acp）与 Coda 之间转发，并把会话指令放进原生会话的第一轮；每个会话一个进程。
