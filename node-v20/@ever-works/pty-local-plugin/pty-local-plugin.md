# @ever-works/pty-local-plugin

> 标签: JavaScript

## 简介

Streaming-terminal session host for Ever Works — spawns the agent CLI under a real PTY inside the executing job-runtime worker (node-pty prebuilt), degrading to a child_process pipe floor when the native addon is unavailable.
