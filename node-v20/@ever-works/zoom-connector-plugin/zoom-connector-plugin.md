# @ever-works/zoom-connector-plugin

> 标签: JavaScript

## 简介

Zoom connector plugin for Ever Works platform (event-source pull of completed cloud recordings with transcripts into the event-ingest pipeline via the official @zoom/rivet SDK, Server-to-Server OAuth)
