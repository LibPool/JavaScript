# @ever-works/mastodon-connector-plugin

> 标签: JavaScript

## 简介

Mastodon social connector plugin for Ever Works platform (outbound statuses via the masto SDK, and event-source pull of mentions/notifications plus the account's own statuses into the event-ingest pipeline, with opt-in historical backfill)
