# @kanso-protocol/react

> 标签: custom-elements, design-system, kanso, react, react-components, ui-components, web-components

## 简介

Typed React wrappers over the Kanso Protocol <kp-*> custom elements — ergonomic, type-checked <KpButton>, <KpSelect>, … components with object-prop and event support on React 18 and 19.
