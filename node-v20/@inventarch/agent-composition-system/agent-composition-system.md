# @inventarch/agent-composition-system

> 标签: JavaScript

## 简介

The composition compiler: it compiles admitted `@agent-profile`, `@capability`, `@harness` and `@execution-binding` records against an installed catalog into a compiled harness and an execution manifest, and owns the captured-read adapters and the task-ca
