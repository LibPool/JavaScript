# @dvdagames/pgn-tokenizer

> 标签: bpe, byte pair encoding, chess, llm, pgn, tokenizer, tokenizers

## 简介

TypeScript version of PGN Tokenizer, a Byte Pair Encoding (BPE) tokenizer for Chess Portable Game Notiation (PGN).
