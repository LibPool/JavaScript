# @monitext/nprint

> 标签: ansi, browser, bun, cli, color, console-color, deno, highlight, javascript, monitext, nodejs, string-format, terminal, text-formatting, typescript

## 简介

A lightweight library for text coloring, highlighting, and formatting in the console. Works with Node.js, Deno, Bun, and browsers.
