# @sushant-kum/ccstatus

> 标签: ccstatusline, claude-code, ink, status-bar, statusline, tui

## 简介

Interactive configurator (npx @sushant-kum/ccstatus) for the ccstatus Claude Code status bar — band, status line, pane, and threshold toasts from one config.
