# @clawsjoy/dsh-session-retention

> 标签: deepseek-harness, dsh, dsh-plugin, retention, session-persistence

## 简介

Never front-truncate a DSH session log: keeps logs whole by default and treats the size cap as opt-in, because a rotated log cannot be loaded (seq gap in committed region).
