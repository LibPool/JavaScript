# @usecanary/cli

> 标签: ai-agent, browser-automation, claude, cli, playwright, qa, session-recording, testing

## 简介

Canary session orchestrator CLI. Drives the daemon to run capture-enabled QA sessions (trace/video/HAR/console) and renders self-contained verification reports.
