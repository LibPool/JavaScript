# @vanillagreen/pi-nested-agents-md

> 标签: agents-md, coding-agent, context, pi, pi-package

## 简介

Attaches a subdirectory's AGENTS.md to the model's context the first time a file under it is read. Pi loads the root AGENTS.md and the ancestors of the cwd only; this adds the nested ones, once per session per file, bounded by the project root.
