# crowdplaysdk-web

> 标签: audio, crowdplay, livekit, opfs, recording, webrtc

## 简介

CrowdPlay browser SDK: a voice call where each participant's microphone is recorded locally, uncompressed, in a 24-bit WAV at the device's own rate, timestamped against the CrowdPlay server clock and uploaded for aligned delivery.
