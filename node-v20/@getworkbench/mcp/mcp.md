# @getworkbench/mcp

> 标签: ai, bullmq, claude, cursor, llm, mcp, model-context-protocol, queue, redis, workbench

## 简介

Model Context Protocol server for Workbench — let LLMs (Cursor, Claude Desktop, Zed, Continue.dev) inspect, debug, and operate your BullMQ queues through your running Workbench dashboard.
