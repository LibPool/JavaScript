# @implexa/mcp-server

> 标签: agent-skills, anthropic, claude, implexa, mcp, model-context-protocol, skill-graph

## 简介

Implexa MCP server — call Implexa's Skill Graph tools (record-skill, share-this, list_org_skills, fork_org_skill, find_accounts, etc.) from Claude Desktop, Claude Code, Claude.ai, Cursor, or any MCP-speaking client.
