# @dawlabs/jira-cli-mcp

> 标签: atlassian, cli, jira, jql, mcp, model-context-protocol

## 简介

Jira Cloud + Confluence Cloud CLI & MCP server — full Jira REST v3 surface, Confluence spaces/pages with markdown, two-way file sync. Pure Jira + Confluence REST API only (no Rovo, no paid endpoints).
