# @agentwares/web-bot-auth

> 标签: ai-agents, cloudflare, ed25519, http-message-signatures, jwks, rfc9421, signature-agent, verified-bots, web-bot-auth

## 简介

Web Bot Auth for agents: Ed25519 keys, a signed /.well-known/http-message-signatures-directory, and RFC 9421 HTTP Message Signatures on outbound requests, so Cloudflare can verify your bot. Web Crypto only, no Node built-ins.
