# @dokebi/migrate

> 标签: database, dokebi, dokebi-plugin, migrations, seeds

## 简介

Migrations and seeds for dokebi-db connections: history and lock for PostgreSQL, MySQL, MariaDB and MongoDB, run from the deployment.
