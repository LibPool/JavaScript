# @andyrmitchell/multipart-mixed

> 标签: batch, gmail, google-api, multipart, multipart/mixed, parser, stream

## 简介

Streaming parser for multipart/mixed HTTP batch responses (e.g. Google batch APIs), with per-part error isolation and truncation detection.
