# @nextrush/adapter-serverless

> 标签: adapter, api-gateway, aws, azure, framework, gcf, http, lambda, nextrush, serverless, vercel

## 简介

Serverless adapter for NextRush (AWS Lambda, API Gateway, GCF, Azure) via a generic, adapter-scoped EventMapper registry
