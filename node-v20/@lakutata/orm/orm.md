# @lakutata/orm

> 标签: database, entity, lakutata, migrations, mongodb, mysql, orm, postgresql, sql.js, sqlite, typeorm, typescript

## 简介

The ORM of the lakutata framework, on TypeORM: the Database component and provider, the entity decorators and the generation of the migrations.
