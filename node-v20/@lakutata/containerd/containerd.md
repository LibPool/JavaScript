# @lakutata/containerd

> 标签: buildkit, containerd, containers, images, lakutata, oci, typescript

## 简介

The containerd component of the lakutata framework: images (pull, push, import, export, of any platform), containers and their processes, over the API of containerd, for the systems which run containerd without Docker.
