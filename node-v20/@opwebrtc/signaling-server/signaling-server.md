# @opwebrtc/signaling-server

> 标签: p2p, signaling, turn, webrtc, websocket

## 简介

Servidor de señalización WebSocket para @opwebrtc/core: relay SDP/ICE, salas 1-a-1, sala de espera, auth, TURN efímero y WSS.
