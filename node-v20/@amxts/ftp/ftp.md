# @amxts/ftp

> 标签: amxmodx, amxts-ftp, amxts-module, counter-strike, ftp, ftps, sftp

## 简介

FTP, FTPS and SFTP for amxts plugins: upload, download and list files on another server, every call a promise that never holds the game up.
