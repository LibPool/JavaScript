# @norbelys/sdk

> 标签: api, cold-email, email, norbelys, openapi, outreach, sdk

## 简介

Official TypeScript SDK for the Norbelys API — cold email from your own mailboxes, warmup, DMARC and honest analytics. Fully typed from the OpenAPI spec.
