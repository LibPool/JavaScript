# @anamico/4ars-reporter

> 标签: 4ars, analytics, anamico, arr, events, monitoring, mrr, reporter, saas, webhook

## 简介

Fire-and-forget event reporter for the 4ARS monitoring platform — typed signup/login/subscription/purchase emitters with HMAC-signed delivery and a custom-metric API.
