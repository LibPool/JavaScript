# @gethinto/browser-sdk

> 标签: analytics, browser-sdk, hinto, observability, session-capture, session-replay, support, telemetry

## 简介

Browser session capture for Hinto: records page views, clicks, scrolls, console, and network activity, and matches sessions to customers so support investigations can cite real evidence.
