# @pictel/cli

> 标签: JavaScript

## 简介

Headless image renderer for [pictel](https://www.npmjs.com/package/pictel) compositions. Wraps Puppeteer + Sharp behind a `pictel render` command that takes a composition entry module and produces image files.
