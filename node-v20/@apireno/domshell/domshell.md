# @apireno/domshell

> 标签: ai-agent, browser-automation, chrome-extension, claude, dom, filesystem, mcp, model-context-protocol, web-scraping

## 简介

MCP server that gives AI agents Unix-style filesystem commands (ls, cd, grep, click, type) to drive Chrome. Single-tool interface, concurrent multi-agent isolation, per-lane tab groups.
