# @syncropel/projections

> 标签: declarative-ui, projections, schema, srp, syncropel

## 简介

TypeScript schema + validators for the Syncropel Rendering Protocol (SRP v0.9) — declarative UI documents for query-driven and AI-generated interfaces. v0.9 adds two settings/config input atoms (toggle, accordion) + the secret text-input kind for faculty-
