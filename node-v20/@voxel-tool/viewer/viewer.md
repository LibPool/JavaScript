# @voxel-tool/viewer

> 标签: magicavoxel, three, viewer, vox, voxel, voxel-tool

## 简介

Framework-agnostic Three.js voxel viewer core (buildVoxelGeometry + createVoxelViewer), shared by the React/Vue/Solid/Preact/Svelte/Qwik components
