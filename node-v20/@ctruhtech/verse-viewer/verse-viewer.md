# @ctruhtech/verse-viewer

> 标签: 3d, ctruh, custom-element, gltf, real-estate, verse, viewer, web-component

## 简介

<verse-viewer>: the official Verse Engine web component. Framework-agnostic, dependency-free, SSR-safe; poster-first lazy embed of any Verse scene, with an upgrade path to the full embed SDK API.
