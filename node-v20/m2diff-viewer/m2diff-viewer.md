# m2diff-viewer

> 标签: code-review, compare, csv-diff, diff, diff-viewer, highlight.js, json-diff, merge, patch, react, shiki, side-by-side, syntax-highlighting, text-diff, typescript, unified-diff

## 简介

A multi-language code and data diff viewer for React: side-by-side, inline and unified views, word-level highlighting, folding, search, JSON/CSV structural diffs, and a framework-independent comparison engine.
