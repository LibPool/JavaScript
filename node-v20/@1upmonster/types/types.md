# @1upmonster/types

> 标签: JavaScript

## 简介

Shared TypeScript type definitions for the 1upmonster platform. Consumed internally by `@1upmonster/sdk`, `@1upmonster/versus`, and `@1upmonster/cli` — you generally don't need to install this directly.
