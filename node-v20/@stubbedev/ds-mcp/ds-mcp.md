# @stubbedev/ds-mcp

> 标签: database, duckdb, elasticsearch, mcp, model-context-protocol, mongodb, mysql, postgres, redis, sqlite

## 简介

DataStore MCP — one MCP server for MySQL/MariaDB, PostgreSQL, SQLite, DuckDB, SQL Server, ClickHouse, MongoDB, Redis/Valkey, Elasticsearch/OpenSearch and Qdrant (Rust, distributed as a prebuilt binary)
