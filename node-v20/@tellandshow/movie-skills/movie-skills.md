# @tellandshow/movie-skills

> 标签: JavaScript

## 简介

Movie-specific skill recipes + wizard.json schemas for Tell and Show. Each skill is a Markdown file under .claude/skills/, with a sibling wizard.json that defines the kid's Q&A flow. M1 = stub; M2 ships the first wave of skills.
