# @tellandshow/story-builder

> 标签: JavaScript

## 简介

The visual builder UI for Tell and Show's Story Studio. React + Vite app the kid opens via `tns builder`. Cards organized by intent (start a story, add a node, draw a scene, animate a drawing, branch the story, etc.); imports the wizard engine + AI Partne
