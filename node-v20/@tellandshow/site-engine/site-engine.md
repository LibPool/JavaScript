# @tellandshow/site-engine

> 标签: JavaScript

## 简介

DOM-first runtime for Tell and Show's Site Studio. Renders the kid's site.config.json + page JSONs + theme JSONs into plain HTML+CSS+tiny-JS under site/_built/. Ships inside the kid's deployed artifact, so MIT.
