# @tellandshow/cli-core

> 标签: cli, tellandshow

## 简介

Shared `tns` shell command for Tell and Show studios. Provides `tns update`, `tns skill-up`, `tns deploy`, `tns ask`, `tns builder`. Game-specific extensions register via plugin hooks (later).
