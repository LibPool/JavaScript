# @exlabs/playwright-bdd-wizard

> 标签: Automation, BDD, Playwright, Testing, TypeScript

## 简介

It's easy-to-use TypeScript library designed to simplify Playwright BDD (Behavior-Driven Development) tests by providing a comprehensive set of reusable and flexible common steps.
