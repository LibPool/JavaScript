# @hypout/react

> 标签: crdt, hooks, presence, pubsub, react, realtime, websocket

## 简介

React client for Hypout: a reconnecting WebSocket client with replay and CRDT presence, hooks, and the Studio components (topology, presence roster, wire inspector, chaos simulator).
