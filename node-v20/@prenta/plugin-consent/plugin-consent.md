# @prenta/plugin-consent

> 标签: JavaScript

## 简介

Cookie consent banner, `am_cookie_consent` storage, and `am-consent` events for Prenta CMS public sites. Gates GA4, Google Ads, and Meta Pixel until the visitor chooses **Accept all**.
