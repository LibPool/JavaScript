# @justweb3/xmtp-plugin

> 标签: JavaScript

## 简介

The **@justweb3/xmtp-plugin** extends the **JustWeb3 Widget** with **XMTP (Extensible Message Transport Protocol)** functionalities, allowing users to **Chat** directly within your dApp.
