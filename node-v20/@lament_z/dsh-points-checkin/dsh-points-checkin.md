# @lament_z/dsh-points-checkin

> 标签: JavaScript

## 简介

面向 WorkBuddy 与 TRAE 的积分与每日签到插件：在侧边栏底部提供一键签到入口，展开式卡片清晰展示积分余额、签到状态与 Token 配置，支持每日一键签到并即时反馈积分变动。
