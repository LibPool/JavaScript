# @inplain/cli

> 标签: ai, cli, deck, markdown, mcp, office, plain, pptx, presentation

## 简介

Plain — AI-native Office. Generate, edit, and export decks, docs, and sheets from your terminal. Includes an MCP server (plain mcp) for Claude Code / Cursor / any MCP-aware agent.
