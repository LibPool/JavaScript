> 标签: agentic-ai, ai-audit, ai-middleware, ai-safety, ai-security, anthropic, edge, enterprise, gemini, jailbreak-detection, langchain, llamaindex, llm, llm-guardrails, llm-security, nextjs, node, openai, output-firewall, owasp-llm, pii, pii-masking, prompt-injection, rag-security, retrieval-sanitizer, shadow-mode, streaming-firewall

## 简介

Security middleware for Node.js and Next.js LLM apps. Blocks prompt injection, masks PII, inspects outputs, and gates agent tools.
