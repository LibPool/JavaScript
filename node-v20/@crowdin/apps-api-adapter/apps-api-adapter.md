# @crowdin/apps-api-adapter

> 标签: adapter, api-client, crowdin, crowdin-apps, http-client

## 简介

Adapter that lets @crowdin/crowdin-api-client run inside Crowdin apps by routing REST calls through the host AP.apiRequest bridge.

- 官网：https://support.crowdin.com/developer/crowdin-apps-js/#making-api-requests
