# cortico-world-pet-voice

> 标签: coopanion, cortico, cortico-world, desktop-pet, minimax, tts

## 简介

Coopanion 扩展：把桌宠气泡里的文字念出来——优先 MiniMax 云端 TTS（音色/语速/模型可配），失败或没配 key 时自动回退 Windows 自带语音。默认关闭。
