# @dmisdm/pandatail

> 标签: css-in-js, design-tokens, panda-preset, pandacss, preset, tailwind, tailwind-v4, tailwindcss, typescript

## 简介

PandaCSS preset that mirrors every token in your Tailwind v4 @theme into typed Panda style props. One source of truth, full TS type safety.
