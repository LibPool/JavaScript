# @aphrody/play

> 标签: JavaScript

## 简介

play.aphrody.app: the Bun OS gaming web app. Bun Engine library, Steam, LAN cache, the WebRTC gamestream and web emulation behind one Bun.serve server fronted by a bun:nginx-owned NGINX engine.
