# ttyreel

> 标签: asciinema, cli, demo, developer-tools, gif, png, readme, recorder, redact, screencast, screenshot, svg, terminal, terminal-to-gif, terminal-to-svg

## 简介

Turn terminal output into polished SVG, GIF, PNG and HTML: record a command, type and script demos, import asciinema casts. Masks secrets automatically.
