# @stashidb/mcp-server

> 标签: JavaScript

## 简介

Model Context Protocol server for Stashi PostgreSQL databases — schema inspection, scoped query execution, checkpoint/rollback, database branching, per-agent key management, and pgvector-backed agent memory.
