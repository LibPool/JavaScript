# @appnigma/sdk

> 标签: appnigma, crm, hubspot, microserver, sdk

## 简介

The package a customer's product installs to reach its Appnigma microserver: run its own functions and list them, read contacts, companies and deals in one shape, call any platform's API, connect end customers, and write its own guide
