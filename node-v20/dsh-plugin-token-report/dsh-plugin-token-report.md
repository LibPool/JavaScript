# dsh-plugin-token-report

> 标签: deepseek, dsh, plugin, telemetry, token, usage

## 简介

DSH 插件：无人值守地把 token 用量实时上报到部门服务端，另提供 token_usage 工具、ctx.tokenReport 服务与界面用量面板。
