# @pdfrest/n8n-nodes-pdfrest

> 标签: document-processing, n8n-community-node-package, pdf, pdfrest

## 简介

Convert, compress, secure, OCR, and extract PDF data, built on the Adobe PDF Library. Runs in the cloud or self-hosted.
