# @bicharts/chart-mcp

> 标签: bic, charts, d3, data-visualization, dataviz, mcp, modelcontextprotocol, plotly

## 简介

AI Data Components for Power BI, Excel, Fabric Apps and the web, over MCP: bivariate maps, what-if projections and about 90 everyday chart types, with selection and cross-filtering already wired. It profiles your table locally; the code it writes is yours
