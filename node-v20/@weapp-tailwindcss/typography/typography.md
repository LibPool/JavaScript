# @weapp-tailwindcss/typography

> 标签: tailwindcss, typography, weapp

## 简介

Tailwind CSS Typography plugin and markup transforms for cross-platform apps. 面向跨端应用的 Tailwind CSS Typography 插件与标记转换工具。
