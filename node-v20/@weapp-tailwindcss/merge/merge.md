# @weapp-tailwindcss/merge

> 标签: merge, mini-program, runtime, tailwindcss, v4

## 简介

Cross-platform Tailwind CSS class merging runtime with mini-program compatibility. 兼容小程序的跨端 Tailwind CSS 类名合并运行时。
