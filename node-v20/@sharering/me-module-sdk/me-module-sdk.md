# @sharering/me-module-sdk

> 标签: bridge, me-module, mini-app, miniapp, postmessage, react-native, react-native-webview, sharering, super-app, superapp, webview

## 简介

TypeScript SDK for miniapps in a React Native WebView: a typed postMessage client for the miniapp, and the matching event router for the superapp that hosts it. Ships the ShareRing Me event catalog; the catalog is swappable.
