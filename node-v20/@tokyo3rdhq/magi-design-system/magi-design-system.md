# @tokyo3rdhq/magi-design-system

> 标签: components, dark-theme, design-system, magi, react, tokens, ui

## 简介

Shared visual foundation for the MAGI product family — dark-first by default (canonical), with Light as a supported alternative. Near-monochrome, restrained, framework-agnostic.
