# @limbo1996/dshsync

> 标签: backup, config, deepseek-harness, desktop, dsh, dsh-plugin, mcp, migration, sync, web-ui

## 简介

Export and import a DeepSeek Harness Desktop configuration, including installed plugins, plugin settings, MCP entries, and user skills. Credentials and API keys are not exported.
