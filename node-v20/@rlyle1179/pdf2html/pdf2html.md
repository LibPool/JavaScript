# @rlyle1179/pdf2html

> 标签: convert, html, pdf, pdfbox, pdftohtml, thumbnail, tika

## 简介

PDF to HTML or Text conversion using Apache Tika. Also generate PDF thumbnail using Apache PDFBox.
