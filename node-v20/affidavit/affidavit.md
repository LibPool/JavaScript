# affidavit

> 标签: ai, claude, cli, e2e, llm, playwright, qa, screenshots, testing, visual-testing

## 简介

Visual-only QA for web apps: specs in on-screen language, a browser that finds things by what it can see, and a reviewer that testifies only to the screenshots.
