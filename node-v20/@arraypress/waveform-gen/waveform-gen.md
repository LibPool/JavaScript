# @arraypress/waveform-gen

> 标签: audio, cli, generator, mp3, peaks, visualization, wav, waveform, waveform-player

## 简介

Generate waveform peak data from audio files. CLI and library for pre-computing waveform data for WaveformPlayer, and sounds manifests for WaveformSounds.
