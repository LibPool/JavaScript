# @arraypress/waveform-sounds-svelte

> 标签: audio, audio-player, filter, player, presets, preview, sample-pack, samples, search, sound-browser, svelte, svelte-component, svelte5, waveform

## 简介

Svelte 5 component wrapper for @arraypress/waveform-sounds — a searchable, filterable sound list with typed props for every option, lifecycle callback props, an exported imperative API, and server-rendered markup the runtime adopts.
