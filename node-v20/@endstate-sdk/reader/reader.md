# @endstate-sdk/reader

> 标签: chip-pairing, endstate, ndef, nfc, tappy, taptrack, tcmp, web-nfc, web-serial, webusb

## 简介

Read Endstate chips with NFC readers in the browser - TapTrack Tappy (Web Serial / WebUSB) and Web NFC behind one interface.
