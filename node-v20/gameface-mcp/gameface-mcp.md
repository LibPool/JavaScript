# gameface-mcp

> 标签: browser-automation, cdp, chrome-devtools-protocol, coherent-labs, cohtml, game-ui, gameface, mcp

## 简介

MCP server for driving and validating Coherent Gameface UI development over the Chrome DevTools Protocol: launch/connect to Gameface Player, inspect and interact with the DOM, run layout and performance assertions, and search Gameface documentation.
