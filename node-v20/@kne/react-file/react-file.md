# @kne/react-file

> 标签: antd, avatar, download, file, file-system, i18n, image, office, pdf, preview, react, upload, zip

## 简介

React文件操作组件库，提供文件上传、多格式预览、下载、列表管理及文件系统浏览，支持i18n
