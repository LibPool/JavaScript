# @kne/code-review

> 标签: antd, code-review, code-viewer, file-browser, file-tree, file-viewer, i18n, react, react-component, syntax-highlighting, tree-view, virtual-scroll

## 简介

一个用于代码审查场景的 React 组件，提供文件树导航和代码预览功能，支持语法高亮、虚拟滚动和多格式文件预览
