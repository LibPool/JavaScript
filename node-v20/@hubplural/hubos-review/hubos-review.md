# @hubplural/hubos-review

> 标签: ci-cd, cli, code-review, codex, github, hubos, pr-gate, review-bot

## 简介

Standalone CLI to install portable PR review gates (codex-gate, etc.) on any GitHub repo. Part of the hub-os ecosystem.
