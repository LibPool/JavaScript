> 标签: agent, chat-adapter, chat-sdk, novu, slack, teams, telegram, whatsapp

## 简介

Novu adapter for the Chat SDK — expose all of Novu's normalized chat channels (Slack, WhatsApp, Teams, Telegram, Email) as a single Chat SDK platform adapter
