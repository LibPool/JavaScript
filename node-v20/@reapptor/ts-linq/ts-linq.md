# @reapptor/ts-linq

> 标签: array extension, collection extension, github, language-integrated query, linq, npm, ts, typescript

## 简介

It is a complete, fully tested analog of C# Language-Integrated Query (LINQ) written in TypeScript. LINQ package generally operates on the collection types and comes as extension methods serving a variety of purposes in working with collections of types.
