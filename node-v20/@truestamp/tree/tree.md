# @truestamp/tree

> 标签: Merkle, Merkle tree, Truestamp, authenticity, blockchain, crypto, cryptography, data, hash, hash function, hashing, integrity, proof, provenance, timestamp, verification, verify

## 简介

This library provides a TypeScript/JavaScript API for creating Merkle trees, and validating Merkle inclusion proofs.
