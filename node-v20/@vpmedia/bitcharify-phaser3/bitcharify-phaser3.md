# @vpmedia/bitcharify-phaser3

> 标签: bitcharify, phaser, phaser3

## 简介

@vpmedia/bitcharify-phaser3 is the integration add-on for the @vpmedia/bitcharify bitmap font generator with the Phaser v3 game engine
