# @clawbureau/clawverify-cli

> 标签: DID, Ed25519, agent-verification, clawsig, offline-verification, proof-bundle, verifier

## 简介

Offline verifier CLI for the Clawsig Protocol — verify proof bundles, export bundles, and commit signatures without network access.
