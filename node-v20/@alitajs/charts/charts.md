# @alitajs/charts

> 标签: JavaScript

## 简介

基于 [@alitajs/f2](https://github.com/alitajs/f2) 封装的图表组件。帮助你快速的在移动端项目中构建图表。

## 官网

- 官网：https://github.com/alitajs/f2#readme
- 源码仓库：git+https://github.com/alitajs/f2.git
- npm 页面：https://www.npmjs.com/package/@alitajs/charts
