# @keykosh/sdk

> 标签: config, configuration, feature-flags, k2, keykosh, secrets, self-hosted

## 简介

Client SDK for reading configuration from a self-hosted KeyKosh (K2) platform — token-scoped reads, SSE hot reload, and a plaintext offline config file. Zero runtime dependencies.
