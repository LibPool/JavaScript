# @alexeyco/microspec

> 标签: agents, micro-sdd, opencode, opencode-plugin, pi-package, sdd, skills, task-contract, workflow

## 简介

Task Contract — a task-scoped Micro-SDD flow for OpenCode and Pi: /microspec.brief turns a request into one executable TASK.md, /microspec.execute runs it through parallel subagent waves with evidence
