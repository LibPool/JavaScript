# @qidiancn/storage-free

> 标签: localStorage, localStorage设置过期时间, print, sessionStorage

## 简介

开放性封装storage，不一定是浏览器storage，还可以对uni-app的storage或小程序storage方法做自定义封装，并且可加入过期时间

- 源码仓库：https://gitee.com/git_zs/storage-free
- npm 页面：https://www.npmjs.com/package/@qidiancn/storage-free
