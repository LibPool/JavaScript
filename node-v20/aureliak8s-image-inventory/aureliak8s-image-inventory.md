# aureliak8s-image-inventory

> 标签: aureliak8s-extension, lens-extension

## 简介

Inventario de solo lectura de las imágenes de contenedor de un clúster: una página por clúster, una sección en el detalle de cada Pod y un aviso en la barra de estado para las que usan :latest o no tienen tag.
