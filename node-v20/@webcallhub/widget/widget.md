# @webcallhub/widget

> 标签: ai-receptionist, browser-calling, call-button, call-widget, click-to-call, customer-support, live-chat-alternative, voice, webcallhub, webrtc

## 简介

Add a click-to-call widget to any website. AI receptionist answers 24/7, qualifies leads, books appointments. Browser-to-browser WebRTC voice calls.
