# @ahtmljs/sveltekit

> 标签: agent-web, ahtml, ai, sveltekit

## 简介

AHTML adapter for SvelteKit — .well-known/ahtml.json, snapshot routes with content negotiation, MCP emission, and llms.txt for any SvelteKit app. Built on the @ahtmljs/extract plugin API.
