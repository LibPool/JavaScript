# @ahtmljs/badge

> 标签: agent-web, ahtml, ai, badge

## 简介

Hosted AHTML score badge service — re-runs the canonical ahtml score against any URL and serves a README-embeddable SVG badge with a linked score report. Deployable as a Cloudflare Worker or any fetch-handler runtime.
