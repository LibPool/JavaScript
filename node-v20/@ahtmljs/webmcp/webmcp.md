# @ahtmljs/webmcp

> 标签: agent, ahtml, browser, mcp, tools, w3c, webmcp

## 简介

Register AHTML page actions as WebMCP browser tools — the bridge between AHTML's structured action contracts and the W3C WebML CG WebMCP API.
