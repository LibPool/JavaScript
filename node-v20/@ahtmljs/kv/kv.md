# @ahtmljs/kv

> 标签: ahtml, cache, cloudflare, kv, rate-limit, redis, upstash

## 简介

Pluggable KV and cache backends for AHTML — in-memory, Upstash Redis, and Cloudflare KV. Drop-in replacements for AHTMLClient's cache and rate-limiting surfaces.
