# oops-errors-mcp

> 标签: crash-reporting, error-tracking, exceptions, issues, mcp, model-context-protocol, oops, rbac

## 简介

MCP server for oops, the open-source error-tracking service: list and triage issues, inspect error events and stack traces, read stats, resolve or ignore issues, manage projects and report an agent's own failures, with role-based tool access and audit log
