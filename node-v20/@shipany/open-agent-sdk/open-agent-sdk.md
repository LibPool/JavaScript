# @shipany/open-agent-sdk

> 标签: agent, agentic, ai, anthropic, claude, coding-agent, llm, open-agent-sdk, sdk, shipany, tools

## 简介

Open-source Agent SDK inspired by @anthropic-ai/claude-agent-sdk. Runs the agent loop in-process — no local CLI required. Deploy anywhere: cloud, serverless, Docker, CI/CD.
