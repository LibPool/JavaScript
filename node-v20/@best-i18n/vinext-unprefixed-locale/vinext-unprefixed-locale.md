# @best-i18n/vinext-unprefixed-locale

> 标签: app-router, cloudflare-workers, codegen, default-locale, i18n, locale, vinext, vite

## 简介

Serve the default locale unprefixed in a vinext app: mirrors app/[locale] into a route group that pins the locale, so no proxy rewrite is needed
