# @cordis-tavern/ct-all-uninstall

> 标签: cleanup, cordis-tavern, uninstall

## 简介

cordis-tavern 全局残留卸载器：幂等清掉内核、插件包、$CT_HOME 数据与 ~/.cordis-tavern 配置。经 npx 运行，自身不落盘。

## 官网

- npm 页面：https://www.npmjs.com/package/@cordis-tavern/ct-all-uninstall

## 历史版本号

- 0.0.1-alpha.1

## 获取地址

- npm 安装：`npm install @cordis-tavern/ct-all-uninstall`
- npm registry：https://registry.npmjs.org/@cordis-tavern/ct-all-uninstall
- Node 要求：>=22.18
