# @synapxlab/ladder-timeline

> 标签: carousel, drag, geological-time, logarithmic, scale, temporal, timeline, typescript, zero-dependency, zoom

## 简介

Multi-scale temporal carousel — drag/zoom across 16 scales from billion-years to milliseconds. Markers, keyboard, pinch. Zero runtime dependency, TypeScript + SCSS.
