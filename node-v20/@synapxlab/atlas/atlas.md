# @synapxlab/atlas

> 标签: atlas, geo, historical, map, pan, svg, typescript, world, zero-dependency, zoom

## 简介

Zero-dependency SVG world map — pan, zoom, markers. Designed as a building block for ChronoMap (historical atlas).
