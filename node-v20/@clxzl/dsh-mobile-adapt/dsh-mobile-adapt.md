# @clxzl/dsh-mobile-adapt

> 标签: android, deepseek, deepseek-harness, dsh, dsh-plugin, ios, mobile, responsive, safe-area, touch

## 简介

Phone and tablet adaptation layer for the DeepSeek Harness (DSH) web GUI: single-column layout with a drawer sidebar, readable type, 40px touch targets, safe-area and soft-keyboard handling.
