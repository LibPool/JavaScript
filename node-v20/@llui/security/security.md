# @llui/security

> 标签: csrf, llui, loopback, sanitize, security, url

## 简介

LLui shared security primitives — one canonical, dependency-free home for URL-scheme sanitization (sanitizeUrl) and loopback/same-origin recognition (CSRF/CSWSH gating), so security-sensitive logic can't drift between packages
