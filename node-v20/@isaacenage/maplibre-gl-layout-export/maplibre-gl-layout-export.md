# @isaacenage/maplibre-gl-layout-export

> 标签: export, gis, layout, map, maplibre, maplibre-gl, pdf, png, print, svg, webgis

## 简介

A powerful print layout and export plugin for MapLibre GL JS — drag-and-drop map frames, rich text, images, and export to PNG/PDF/SVG.
