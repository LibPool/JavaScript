# @safagayret/error-reporter

> 标签: browser, bug-report, console-log, debugging, error-reporter, network-log, screenshot

## 简介

A lightweight, configurable browser-side error reporter. Captures console logs, network requests and a screenshot, then packages everything into a ZIP — either downloaded locally or uploaded to your endpoint.
