# @pro-laico/fonts

> 标签: JavaScript

## 简介

Atomic Payload fonts package. Provides the Font upload collection and a CLI script for downloading fonts from the active design set to disk for use with next/font/local.

- 源码仓库：git+https://github.com/pro-laico/atomic-payload.git
