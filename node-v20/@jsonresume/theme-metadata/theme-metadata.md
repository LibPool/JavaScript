# @jsonresume/theme-metadata

> 标签: config, cv, json-resume, resume, theme-gallery, theme-metadata, themes

## 简介

Theme registry metadata for JSON Resume themes — names, descriptions, tags, authors, and helpers (THEME_METADATA, THEME_NAMES, getRandomTheme) for building theme galleries and pickers
