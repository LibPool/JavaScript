# @tier0/node-dcom

> 标签: com, dcom, ntlm, ntlmv2, opc, opc-da, rpc

## 简介

An implementation of the DCOM Protocol for node.js, with NTLMv2 and packet signing (fork of node-dcom, OPC DA friendly)
