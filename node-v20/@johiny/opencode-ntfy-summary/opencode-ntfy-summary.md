# @johiny/opencode-ntfy-summary

> 标签: alerts, notifications, ntfy, opencode, opencode-plugin, push-notifications, summary

## 简介

OpenCode plugin that sends push notifications via ntfy.sh with a summary of what the agent just said when the session goes idle.
