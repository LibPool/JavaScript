# @3sln/trove

> 标签: drive, file storage, plugins, s3, self-hosted, semantic search

## 简介

Trove — a self-hostable, plugin-extensible Google Drive. Semantic search, pluggable storage (S3 / filesystem / NAS), and a VS Code-style contribution system with sandboxed plugins.
