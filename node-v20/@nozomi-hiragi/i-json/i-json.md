# @nozomi-hiragi/i-json

> 标签: i-json, json, parser, rfc7493, validator

## 简介

Strict JSON parser, serializer and validator conforming to I-JSON (RFC 7493): UTF-8 only, no duplicate keys, IEEE 754 safe numbers, no lone surrogates.
