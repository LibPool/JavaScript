# @cpp.js/core-embind-rust

> 标签: bind, c++, embind, jsi, react-native, rust, webassembly

## 简介

Rust producer for the cpp.js embind registration protocol - bind Rust structs as classes reachable from JS on web (embind) and mobile (embind-jsi). Research/spike stage.
