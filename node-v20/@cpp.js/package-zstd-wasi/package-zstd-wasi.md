# @cpp.js/package-zstd-wasi

> 标签: compression, cpp.js, cpp.js-package, libzstd, wasi, webassembly, zstandard, zstd

## 简介

WASI build of the precompiled Zstandard (zstd) library, built with cpp.js. Use it together with the main package @cpp.js/package-zstd.
