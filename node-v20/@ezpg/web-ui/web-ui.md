# @ezpg/web-ui

> 标签: JavaScript

## 简介

EZPG 스토어프론트용 Next.js UI 킷. EZPG가 생성한 상점 사이트(손님 웹)를 그리는 컴포넌트, 커머스 블록, 섹션 렌더러를 담는다.
