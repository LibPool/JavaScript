# @corvus-dotnet/json-schema

> 标签: code-generation, draft-07, draft-2019-09, draft-2020-12, json-schema, jsonschema, validation, validator

## 简介

A high-performance JSON Schema evaluator (draft 4 to 2020-12) that compiles schemas to specialised JavaScript, with results collection and annotations, ported from the Corvus.Text.Json V5 runtime evaluator.
