# @calloop/agent-sdk

> 标签: agent, call-center, calloop, sip, voip, webrtc, whatsapp

## 简介

Agent client for Calloop: ring, answer, hang up and transfer calls over Calloop's agent gateway (Socket.IO + WebRTC).
