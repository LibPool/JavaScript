# @hashspan/mpp

> 标签: ai-agents, mpp, mppx, observability, opentelemetry, opentelemetry-instrumentation, otel, payments, tempo, tracing

## 简介

OpenTelemetry instrumentation for MPP payments made with mppx: traces the payments an AI agent makes with the Machine Payments Protocol as payment spans.
