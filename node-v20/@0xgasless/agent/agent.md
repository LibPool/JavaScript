# @0xgasless/agent

> 标签: 0xgasless, agents, ai-agents, autonomous-agents, avalanche, base, erc-8004, erc8004, evm, fuji, gasless, kms, micropayments, payments, stablecoins, usdc, x402

## 简介

TypeScript client for the 0xgas agent platform — KMS-managed agent wallets, x402 micropayments on Avalanche/Fuji/Base, and ERC-8004 on-chain identity. Zero gas, zero key management.
