# @vecto-os/entity-schema

> 标签: entity, graph, schema, vecto, zod

## 简介

Shared Zod schemas for the Vecto ENTITY node-type. Single source of truth for ExternalRef, EntityAttributes, EntityCreatePayload, EntityUpdatePayload — consumed by dash-api (CommonJS REST), graph-tools and vecto-mcp (ESM, via Node interop).
