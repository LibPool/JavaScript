# @phemium-costaisa/cordova-plugin-webview-overlay

> 标签: cordova-android, cordova-ios, ecosystem:cordova, iframe, multi-webview, multiple-instances, overlay, webview

## 简介

Plugin de Cordova para mostrar múltiples WebViews nativos superpuestos que cargan contenido externo sin CORS. Soporta gestión independiente de múltiples instancias.
