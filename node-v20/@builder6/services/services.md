# @builder6/services

> 标签: JavaScript

## 简介

Builder6 Services 模块为 Builder6 框架提供通用的 Moleculer 微服务 API 网关。它通过统一的 HTTP 端点允许经过身份验证的管理员动态调用任意 Moleculer 微服务和操作，是 HTTP 客户端与内部 Moleculer 服务网格之间的桥梁。
