# @bauer-group/accessibility-widget

> 标签: a11y, accessibility, barrierefreiheit, bfsg, eaa, en301549, lazy-loading, wcag, wcag2.2, widget

## 简介

Lazy-loading Accessibility-Widget nach BFSG/EN 301 549/WCAG 2.2 AA. Loader ~4 KB gzip, Core ~14 KB gzip. Kein Tracking, kein Cookie, kein DOM-/ARIA-Override.
