# @antelopejs/file-storage-s3

> 标签: antelopejs, cloudflare-r2, file-storage, presigned-url, s3, upload

## 简介

S3-compatible storage module for AntelopeJS (AWS S3, Cloudflare R2), implementing the File Storage interface with presigned URLs
