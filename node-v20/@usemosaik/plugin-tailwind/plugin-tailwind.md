# @usemosaik/plugin-tailwind

> 标签: JavaScript

## 简介

The Tailwind CSS Plugin implementation: wires the @tailwindcss/vite plugin into vite.config and adds the CSS-first @import to index.css (Tailwind v4 — no tailwind.config.js needed).
