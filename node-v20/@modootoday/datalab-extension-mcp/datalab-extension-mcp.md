# @modootoday/datalab-extension-mcp

> 标签: chrome-extension, mcp, modelcontextprotocol, naver

## 简介

Local MCP server that exposes the DataLab Tools browser extension's tools to an MCP host. Read-only lookups run without a prompt; anything that edits a document or costs money is gated by the extension and confirmed by you first. Holds no credentials; eve
