# @screenpipe-ui/react

> 标签: JavaScript

## 简介

React hooks for [screenpipe](https://github.com/screenpipe/screenpipe), bridging `@screenpipe-ui/core` stores to React via `useSyncExternalStore`. Used by both the TUI (Ink) and Web (React DOM) packages.
