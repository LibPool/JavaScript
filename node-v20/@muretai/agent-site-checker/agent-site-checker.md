# @muretai/agent-site-checker

> 标签: a2a, agent-card, agent-readiness, ai-agent, did, dns-aid, ed25519, llms-txt, mcp, verification, webmcp

## 简介

Verify what a website tells AI agents: follow the DNS and HTTP signposts, then check whether what is at the end is real — the agent card's signature, the DID's claim on the origin, and whether anything reached the door at all.
