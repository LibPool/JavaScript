# @kidsinai/kids-opencode-tui-plugin

> 标签: education, k-12, kids, opencode, opencode-tui-plugin, theme

## 简介

opencode TUI plugin that gives Kids OpenCode its kid-warm theme, simplified keymap, kid-friendly status text, Mission progress sidebar, and a Kids Helpline overlay on dangerous-topic triggers.
