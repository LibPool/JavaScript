# @salve-software/nodeless

> 标签: browser, browser-build, bundler, esbuild, esbuild-wasm, live-preview, npm-install, package-manager, playground, react, typescript, vfs, virtual-filesystem

## 简介

npm install and a React build, without Node. The same code in a server and in the browser: no shell, no filesystem, no VM.
