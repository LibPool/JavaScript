# @danolekh/cardstock

> 标签: base-ui, card, carousel, credit-card, fintech, headless, react

## 简介

Headless, composable bank-card primitives for React: flip, tilt, storable backgrounds and live shader backgrounds, masked number reveal with timeouts and copy, freeze, statuses, spending meter, limit field and a swipeable card carousel.
