# @rythra/connector-discordjs

> 标签: JavaScript

## 简介

Official **Discord.js** connector for [Rythra](https://github.com/Ekretos/Rythra). Bridges Discord.js gateway events and voice state with Rythra's framework-agnostic audio runtime.
