# wireproof

> 标签: api, ci, idempotency, lint, plaid, stripe, webhooks

## 简介

Checks code that calls Stripe, Plaid, Gusto, Wise and other APIs for mistakes that pass in testing and break in production, and serves the same facts to your coding agent over a local MCP server.
