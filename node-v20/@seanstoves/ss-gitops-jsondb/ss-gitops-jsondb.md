# @seanstoves/ss-gitops-jsondb

> 标签: content-sync, github-app, gitops, installation-token, revalidate, webhook, x-hub-signature-256

## 简介

GitHub App content-sync toolkit: mint an installation token, verify webhook signatures, pull/push a content repo over git, and compute which paths to evict. Native Node, no runtime deps.
