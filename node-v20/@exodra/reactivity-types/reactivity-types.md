# @exodra/reactivity-types

> 标签: bindable, contract, exodra, reactivity, types, typescript

## 简介

The reactive-value contract for Exodra (types only) — TExoBindable / TExoBindableList / TExoListOp. Renderers and reactivity implementations depend on this, not on each other.
