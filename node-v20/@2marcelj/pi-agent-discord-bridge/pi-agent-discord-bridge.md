# @2marcelj/pi-agent-discord-bridge

> 标签: agent, ai, bot, bridge, discord, middleware, pi

## 简介

Bridge agent that connects Discord (and Telegram) to the pi coding agent. Install globally to run the bridge server alongside pi, or locally in a project.
