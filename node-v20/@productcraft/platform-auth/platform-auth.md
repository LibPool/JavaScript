# @productcraft/platform-auth

> 标签: platform-auth, productcraft, sdk

## 简介

PlatformUser auth, workspaces, members, invites, roles + IAM policies, API keys, service activation, and the introspect endpoint every ProductCraft backend uses to resolve permissions. Generated from the production OpenAPI spec.
