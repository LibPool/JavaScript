# @productcraft/heimdall-passport

> 标签: auth, heimdall, jwt, passport, passport-jwt, productcraft, sdk

## 简介

Passport-JWT adapter for ProductCraft Heimdall. Plug a Heimdall ConsumerScope into a `passport-jwt` Strategy so existing Passport setups can authenticate Heimdall-issued tokens.
