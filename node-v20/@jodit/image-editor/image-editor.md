# @jodit/image-editor

> 标签: canvas, crop, filters, image-editor, reactive, resize, rotate, typescript, vanilla

## 简介

Vanilla, framework-free, reactive image editor (crop, resize, rotate, flip, filters, finetune, text annotations). view = f(state).
