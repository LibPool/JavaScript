# @alaarab/ogrid-react-xlsx

> 标签: datatable, excel, grid, ogrid, react, sheetjs, spreadsheet, xlsx

## 简介

Drop an xlsx Blob, get a fully featured OGrid — and export grid data back to .xlsx. Wraps ExcelJS + @alaarab/ogrid-react-radix with formula engine + Excel cell references on by default.
