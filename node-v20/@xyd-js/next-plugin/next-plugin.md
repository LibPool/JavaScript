# @xyd-js/next-plugin

> 标签: docs, documentation, next, nextjs, xyd

## 简介

Next.js plugin that builds xyd docs during `next build` and serves them under a subpath of your app — with a spawned `xyd dev` + proxy rewrites in `next dev`
