# @ansempay/sdk

> 标签: ai-agents, ansem, mastercard, payments, solana, usdc, virtual-card

## 简介

Typed TypeScript client for the Ansem Pay API — mint single-use virtual Mastercards funded with USDC or $ANSEM on Solana. No KYC, no accounts.
