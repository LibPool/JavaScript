# @wshcmx/cli

> 标签: WebSoftHCM, webtutor, wshcmx, wshcmx/cli, wt

## 简介

Набор CLI-инструментов предназначен для автоматизации сборки и отслеживания изменений в исходном коде с последующей транспиляцией в синтаксис WebSoftHCM.
