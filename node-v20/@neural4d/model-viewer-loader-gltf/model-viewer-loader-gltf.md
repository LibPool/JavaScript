# @neural4d/model-viewer-loader-gltf

> 标签: JavaScript

## 简介

The GLB/GLTF 2.0 `ModelLoader` for Neural4D Model Viewer. It uses the official Three.js `GLTFLoader` and delegates external resource transport to Core `ResourceProvider` and `assets-required` resolution.
