# @neural4d/model-viewer-feature-effects

> 标签: JavaScript

## 简介

Optional, framework-neutral Viewer effects. The package currently owns reversible fluid-breath, soft-shading, smooth-normal, and face-normal visualization sessions. It does not provide UI, visual presets, Loader transport, or business state.
