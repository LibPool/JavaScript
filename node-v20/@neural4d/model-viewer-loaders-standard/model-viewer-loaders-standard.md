# @neural4d/model-viewer-loaders-standard

> 标签: JavaScript

## 简介

The lazy standard-loader catalog for Neural4D Model Viewer. It provides the official VRM, GLB/GLTF, OBJ/MTL, and FBX `ModelLoader` implementations in a stable precedence order while loading each format package only when its loader is first needed.
