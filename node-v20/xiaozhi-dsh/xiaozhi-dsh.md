# xiaozhi-dsh

> 标签: deepseek-harness, dsh, dsh-plugin, esp32, json-rpc, mcp, voice, websocket, xiaozhi, 小智

## 简介

Expose DeepSeek Harness (DSH) Web capabilities to the Xiaozhi voice assistant over MCP: multi-device capable self-contained DSH bundle that registers DSH as an MCP tool provider on a Xiaozhi MCP endpoint (or as a Xiaozhi-connectable MCP server), plus a DS
