# @farhansadikgalib/bd-map

> 标签: bangladesh, choropleth, district, division, geo, map, react, svg, union, upazila, visualization

## 简介

Interactive drill-down maps of Bangladesh for React, plus a geography and data API for Node: division to union, English and Bangla names, choropleths from JSON or an API, and server-side SVG rendering. Zero dependencies.
