# @attebyte/react-tree-select

> 标签: a11y, accessible, aria, checkbox, checkbox-tree, file-tree, folder-tree, hierarchy, indeterminate, keyboard-navigation, multi-select, nested, react, react-component, tailwind, tailwindcss, tree, tree-checkbox, tree-select, tree-view, treeselect, treeview, tri-state, typescript, wai-aria

## 简介

Accessible React tree select and checkbox tree component with tri-state (indeterminate) selection, keyboard navigation, TypeScript generics and customizable, Tailwind-friendly styling.
