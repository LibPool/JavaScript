# @qorechain/svm

> 标签: JavaScript

## 简介

QoreChain SVM adapter: thin, type-safe conveniences over @solana/web3.js for QoreChain's Solana-compatible JSON-RPC, including SOL transfers, native program IDs, and SPL-Token/Memo instruction helpers.
