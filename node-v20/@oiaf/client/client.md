# @oiaf/client

> 标签: api-client, cms, iaf, machine-api, news, stories

## 简介

Dependency-free SDK for the Ngọn Đèn Đêm (Innovative Arts Fiction) machine API — lets an external bot / 3rd-party app create content, manage chapters, and submit drafts for review.
