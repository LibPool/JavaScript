# @tapacapi/mcp

> 标签: apollo-alternative, b2b, cold-email, contacts, email-verification, lead-generation, mcp, mcp-server, modelcontextprotocol, tapac

## 简介

TAPAC MCP server — find and verify B2B business contacts (real-time sourcing + SMTP email verification) from any MCP-compatible agent. Run with npx.
