# @notnotype/nb-markdown

> 标签: JavaScript

## 简介

Markdown 的语言、编解码器与组件：只读显示、行内小块、提示词编辑器与编辑器扩展；建在 nb-ui 之上，宿主经 provideMarkdownHost 给语言与链接目标的分类。
