# hlplanet-mcp

> 标签: gaming, hall-effect, hlplanet, keyboard, keyboard-size, mcp, mcp-server, mechanical-keyboard, model-context-protocol, rapid-trigger

## 简介

MCP server for keyboard sizes: compare 100%, TKL, 75%, 65% and 60% layouts and 30 real keyboards, check desk and mousepad fit, find keys, and search HLPlanet keyboard reviews.
