# @vue-flex/layout

> 标签: JavaScript

## 简介

1. FlexContainer    1. Width and Height ： Auto（default）: 根据子元素的内容来自动设置 ， Pixels:'10px' Percentage:'80%'    2. Display：  Flex (default)：弹性布局， None：：该节点从布局树中删除并且不可见    3. Flex Direction: Column (default), Row,Row reverse,Column reverse    4. Justify Content
