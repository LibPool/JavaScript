# @tarhnama/links

> 标签: docx, editor, markdown, outline, persian, prosemirror, rtl

## 简介

Cross-document linking: sparse anchors, text-quote fallback anchoring, link registry with backlinks, broken-link repair, and a Persian-aware search index. Runs in Node with no DOM.
