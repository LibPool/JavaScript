# @tarhnama/schema

> 标签: docx, editor, markdown, outline, persian, prosemirror, rtl

## 简介

ProseMirror/Tiptap schema for the flat outline model: outlineBlock node, stable block IDs, collapse decorations, level-invariant commands. DOM, no framework.
