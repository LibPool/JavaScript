# @tarhnama/rtl

> 标签: docx, editor, markdown, outline, persian, prosemirror, rtl

## 简介

Persian/RTL text layer: ZWNJ handling, import-time normalization, first-strong direction detection, Word artifact repair. No DOM, no runtime deps.
