# @hwpdf/engine

> 标签: hancom, hwp, hwpx, layout, svg, wasm

## 简介

HWP/HWPX parsing, layout and SVG rendering engine for hwpdf — patched rhwp (Rust→wasm) with Hancom-fidelity pagination fixes, bundled wasm, zero CDN dependency.
