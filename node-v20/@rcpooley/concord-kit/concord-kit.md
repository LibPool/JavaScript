# @rcpooley/concord-kit

> 标签: concord, declarative, docker, infrastructure, nginx, reconciler

## 简介

Opinionated building blocks for a Concord config repo: apps as one file each, machines that derive their base layers, an nginx edge with derived certificate coverage, and assemble() to put the modules in order.
