# @cxcxcx/client-logger

> 标签: client-log, electron, indexeddb, logger, react, vue, vue3

## 简介

前端客户端日志 SDK：全局错误监控、UI 库自动识别、行为埋点、IndexedDB 即时持久化、定时批量上报；内置 Electron/HBuilder/Web 设备 ID 识别；支持 Vue 2/3、React、Electron
