# @humanexon/feedback-db

> 标签: JavaScript

## 简介

`@humanexon/feedback-core` 写侧 `FeedbackRepository` 与读侧 `FeedbackQueryPort` 的 Drizzle/Postgres 参考实现。schema 自包含 —— **不对任何宿主身份/租户表建外键** —— 所以可直接接入任意项目。用其他 ORM 的项目自行实现 core 接口即可。
