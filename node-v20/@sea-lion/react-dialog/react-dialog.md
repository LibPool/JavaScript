# @sea-lion/react-dialog

> 标签: JavaScript

## 简介

Dialog 是一个模态对话框组件，用于显示需要用户注意或操作的内容，同时阻止与页面其余部分的交互，直到对话框关闭。支持多种尺寸、对齐方式、自定义宽度以及受控/非受控两种用法。
