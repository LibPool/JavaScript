# @sea-lion/react-context-menu

> 标签: JavaScript

## 简介

ContextMenu 是在用户右击或长按元素时显示的菜单，提供与该上下文相关的操作选项。支持子菜单、复选框、单选框、分组标签、禁用项等丰富的菜单能力。
