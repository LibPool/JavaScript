# @mambasdk/progress

> 标签: JavaScript

## 简介

O módulo `Progress` é composto por dois componentes: `ProgressBar` e `CircleProgress`. Ambos podem ser utilizados para representar a execução de um tarefa com etapas definidas ou não.
