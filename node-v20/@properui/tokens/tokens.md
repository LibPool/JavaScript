# @properui/tokens

> 标签: css, css-variables, dark-mode, design-system, design-tokens, tailwindcss, theme

## 简介

Proper UI design tokens as plain CSS: the Tailwind v4 theme, a framework-free CSS-variables file, the theme presets, and a prebuilt properui.css for pages with no build step.
