# @wa-ma/sdk

> 标签: agent, api-client, messenger, sdk, typescript, wama, whatsapp

## 简介

Framework-agnostic TypeScript SDK client for WAMA (WhatsApp Multi-Agent) enabling token-based message dispatch, media file rendering, and client interactions.
