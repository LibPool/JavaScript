# noskip

> 标签: agentic-coding, ai, ai-agents, claude-code, cli, code-review, codex, coding-agents, copilot, cursor, gemini-cli, git-hooks, github-action, hooks, llm, pre-commit, reward-hacking, test-integrity, testing, vibe-coding

## 简介

Anti-cheat for AI coding agents. Catches Claude Code, Codex, Cursor and Gemini CLI when they skip, weaken or delete tests, hardcode answers or switch CI off to make tests pass.
