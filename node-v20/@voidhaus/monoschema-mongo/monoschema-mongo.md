# @voidhaus/monoschema-mongo

> 标签: JavaScript

## 简介

MongoDB extension for [@voidhaus/monoschema](https://www.npmjs.com/package/@voidhaus/monoschema) that provides type-safe MongoDB operations with schema validation.
