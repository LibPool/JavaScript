# @zbs-gg/zbs-researcher

> 标签: claude-code, claude-plugin, deep-research, installer

## 简介

One-command installer for the ZBS Researcher (deep-research) Claude Code plugin: adds the zbs-researcher marketplace and installs the plugin.
