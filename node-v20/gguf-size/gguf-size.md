# gguf-size

> 标签: gguf, kv-cache, llama.cpp, llm, quantization, vram

## 简介

GGUF quantization file size (F16 to Q2_K) and VRAM estimate (weights, KV cache, overhead) for local LLMs. Zero dependencies.
