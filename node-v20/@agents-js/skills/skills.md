# @agents-js/skills

> 标签: agent, discovery, skills, tools

## 简介

TypeScript-native skill loading, validation, and in-memory registry for SKILL.md-formatted skills. Pure, filesystem-only, no network or persistence.

- 官网：https://agents-js.bodal.dev/
