# @ztachi007/react-native-drag-sort-strip

> 标签: android, drag-and-drop, drag-sort, gesture-handler, ios, react-native, reanimated, reorder, sortable

## 简介

A highly customizable, performant drag-and-sort strip component for React Native, powered by Reanimated v3 and Gesture Handler v2. Supports 2D drag, sorting, and drag-to-delete.
