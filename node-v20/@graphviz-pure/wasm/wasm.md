# @graphviz-pure/wasm

> 标签: circo, diagram, dot, fdp, graphviz, neato, rust, sfdp, svg, twopi, wasm, webassembly

## 简介

A pure-Rust port of Graphviz 16.1.0 (all eight layout engines), compiled to WebAssembly, with the same output in browsers, Node.js, Deno, Bun and Workers. Not affiliated with the Graphviz project.
