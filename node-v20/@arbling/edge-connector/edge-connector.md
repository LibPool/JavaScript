# @arbling/edge-connector

> 标签: ai-agents, ai-crawlers, arbling, edge, middleware

## 简介

Arbling's edge connector: classifies each request with Arbling's AI agent catalogue and reports AI crawlers, AI agents and visitor counts to Arbling. Observe and report only: it never blocks, delays or throws.
