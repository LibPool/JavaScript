# @auto-hwp/engine

> 标签: document, hancom, hwp, hwpx, pdf, svg, wasm, webassembly

## 简介

auto-hwp engine as WebAssembly: open .hwp/.hwpx in the browser, render pages to SVG, edit via Intent JSON, export HTML/PDF/HWPX. No LLM, no filesystem, no bundled fonts.
