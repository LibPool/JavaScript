# @crouton-kit/agent-chat-core

> 标签: JavaScript

## 简介

Headless transport + view-model engine for the Hearth agent-chat UI kit — wire protocol, transcript reducer, ChatItem normalizer, activity derivation, queue/steer/abort state machine, dialog plumbing, and the useAgentChat hook.
