# @wsxwj123/dsh-session-manager

> 标签: JavaScript

## 简介

DSH web plugin: recycle-bin session deletion (5s undo) + archived-session view / unarchive. Host (node) half owns the /sm/* RPC surface and the workspace storage-domain archive write.
