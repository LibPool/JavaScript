# @gooddata/sdk-ui-metric-component

> 标签: JavaScript

## 简介

Metric component is a library for editing metrics in gdc-analytical-designer and gdc-meditor. Originally it was part of gdc-meditor and released as npm private package @gooddata/metric-component. The npm package is now obsolete as the library is now here
