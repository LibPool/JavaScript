# @pipedog/pocket-tts

> 标签: conversational-ai, kyutai, local, onnx, pipecat, pipedog, pocket-tts, realtime, text-to-speech, tts, voice-ai

## 简介

Pocket TTS for pipedog: a port of Pipecat's PocketTTSService, running Kyutai's Pocket TTS locally on ONNX Runtime through @pipedog/onnx.
