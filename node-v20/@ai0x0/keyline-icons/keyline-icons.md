# @ai0x0/keyline-icons

> 标签: icon-set, icons, react, shadcn, shadcn-ui, svg, tailwind

## 简介

Icons on one 24×24 grid, as React components in three weights: stroke, duotone and fill, each in rounded or sharp corners. Built for shadcn/ui.
