# @mionjs/create-starter-nuxt

> 标签: api, create, mion, mionjs, nuxt, rpc, starter, template, typescript, vue

## 简介

Starter template for building full-stack apps with mion + Nuxt. Run `npm create @mionjs/starter-nuxt <project-name>` to scaffold.
