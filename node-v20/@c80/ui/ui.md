# @c80/ui

> 标签: JavaScript

## 简介

Libreria de componentes Angular reutilizables del ecosistema barman (icon, table, modal, select, navigation-card, login-card, etc.). Fuente unica de UI para kyron-front, midas-front y chillbox.
