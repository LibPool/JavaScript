# @mafesoftware/tesoreria

> 标签: JavaScript

## 简介

Decisiones de negocio de tesorería para los productos de MAFE Software: saldos de caja, transferencias entre cajas (con tipo de cambio implícito cuando cambian de moneda), arqueo y el ciclo de una rendición de gastos.
