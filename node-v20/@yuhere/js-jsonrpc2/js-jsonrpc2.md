# @yuhere/js-jsonrpc2

> 标签: express, json-rpc, jsonrpc, jsonrpc2, middleware, typescript, zod

## 简介

A TypeScript JSON-RPC 2.0 server library with schema validation, authorization, dependency injection, and multiple transports.
