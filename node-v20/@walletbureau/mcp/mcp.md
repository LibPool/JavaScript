# @walletbureau/mcp

> 标签: agent-payments, base, counterparty, mcp, model-context-protocol, risk, usdc, wallet, x402

## 简介

MCP server for WalletBureau: check the behavioral risk score of a Base wallet before paying it. Pay per call with x402 or a prepaid API key.
