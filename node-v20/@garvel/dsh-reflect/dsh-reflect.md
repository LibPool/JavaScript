# @garvel/dsh-reflect

> 标签: cordis, cordis-plugin, deepseek-harness, dsh, memory, reflect, self-learning

## 简介

File-level self-learning prototype for DeepSeek Harness: a persistent memory store (per-workspace + global markdown), a credential screen, a human-gated review queue (tool + /reflect-review), model-driven consolidation tools, and a per-session system-prom
