# @cherrydotfun/bots-sdk

> 标签: bot, bot-api, chat, cherry, cherrydotfun, inline-keyboard, messaging, polling, sdk, solana, webhook

## 简介

Node SDK for the Cherry Bot API — typed bot client with DM, group mentions, inline keyboards, polling, webhooks, signature/transaction requests, and inline miniapp messages.
