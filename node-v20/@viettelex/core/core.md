# @viettelex/core

> 标签: ime, input method, telex, vietnamese, vni, wasm

## 简介

VietTelex Core — Vietnamese Telex/VNI input engine for the web (WebAssembly, same engine as the VietTelex apps). Full and lite builds, inlined or separate .wasm.
