# rea-from-api

> 标签: agent-skills, api, api-discovery, codegen, evidence, mcp, mcp-server, openapi, rea, reverse-engineering, schemathesis

## 简介

Reverse engineer any API: discover how a website serves its data (publisher catalogs, OpenAPI, framework routes, APIs.guru, Wayback, CT, REA browser capture, jsluice, source maps, GraphQL), prove it with evidence, export OpenAPI 3.1, and generate tested T
