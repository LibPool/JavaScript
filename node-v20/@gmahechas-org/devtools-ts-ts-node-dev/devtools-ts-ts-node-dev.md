# @gmahechas-org/devtools-ts-ts-node-dev

> 标签: JavaScript

## 简介

Pins one ts-node-dev install. The `ts-node-dev` and `tsnd` binaries always run the `ts-node-dev` version declared in this package. This package does not publish a TypeScript config.
