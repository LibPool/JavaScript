# @gmahechas-org/devtools-ts-dependency-cruiser

> 标签: JavaScript

## 简介

Pins one dependency-cruiser install. The `depcruise` binary always runs the `dependency-cruiser` version declared in this package. This package does not publish a dependency-cruiser config.
