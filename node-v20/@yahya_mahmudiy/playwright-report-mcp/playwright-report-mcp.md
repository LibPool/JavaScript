# @yahya_mahmudiy/playwright-report-mcp

> 标签: claude, cursor, mcp, mcp-server, model-context-protocol, playwright, test-report

## 简介

MCP server that reads Playwright JSON reports and returns compact JSON answers (summary, failures, slowest tests, run comparison) so an AI agent never has to read the whole report.
