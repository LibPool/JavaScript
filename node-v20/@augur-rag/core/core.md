# @augur-rag/core

> 标签: ai, beir, bm25, contextual-retrieval, cross-encoder, embeddings, huggingface, hybrid-search, information-retrieval, llm, mteb, nlp, onnx, pgvector, pinecone, rag, rag-pipeline, reranking, retrieval, retrieval-augmented-generation, semantic-search, sentence-transformers, turbopuffer, typescript, vector-retrieval, vector-search

## 简介

Adaptive retrieval orchestration for RAG and semantic search in TypeScript: per-query routing across vector / BM25 / hybrid + cross-encoder reranking, with full traces. Works with pgvector, Pinecone, Turbopuffer, or any custom adapter.
