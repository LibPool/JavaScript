# @arrowster/shared-ui

> 标签: JavaScript

## 简介

Shared Vue 3 component library for Arrowster projects. Built with Vite in library mode; works in plain Vue 3 apps and Nuxt 3 (Nuxt is Vue 3 under the hood).
