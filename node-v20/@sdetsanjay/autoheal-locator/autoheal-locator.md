# @sdetsanjay/autoheal-locator

> 标签: ai, ai-testing, anthropic, autoheal, claude, deepseek, element-locator, flaky-tests, gemini, grok, javascript, locator-healing, multi-provider, openai, playwright, selenium, self-healing, test-automation, test-maintenance, typescript, webdriver

## 简介

AI-powered test automation framework that automatically heals broken locators for Playwright and Selenium WebDriver in JavaScript/TypeScript. Supports cloud AI providers and local/custom models.
