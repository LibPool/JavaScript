# @dwk/remotestorage

> 标签: cloudflare-workers, data-vault, durable-objects, oauth2, personal-data, remotestorage

## 简介

remoteStorage (draft-dejong-remotestorage) personal data vault: OAuth-bearer GET/PUT/DELETE documents and folder listings over @dwk/store. Ships the per-account Durable Object.
