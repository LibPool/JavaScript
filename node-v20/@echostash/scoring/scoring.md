# @echostash/scoring

> 标签: assertion, echostash, eval, llm, prompt, regression, scorer, testing

## 简介

Isomorphic scorer engine for LLM evals: deterministic assertions (contains, regex, json-schema, ...) plus the scorer catalog shared by the runner and the UI.
