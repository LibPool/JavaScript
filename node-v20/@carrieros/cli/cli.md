# @carrieros/cli

> 标签: ai, carrier-os, carrieros, chat, cli, cos, developer-platform, llm, shell

## 简介

Carrier OS command-line interface — an interactive shell plus commands for the Carrier OS developer platform (chat, sessions, files, usage) over the public /v1 API.
