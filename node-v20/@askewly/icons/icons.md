# @askewly/icons

> 标签: askewly, design-system, icons, react, svg

## 简介

Askewly icon set — original 24px stroke icons (hand-authored), generated from single-source SVG files and shipped as React components with TypeScript types. Brand glyphs stay in the source repo and are not part of this package.
