# dsh-plugin-lavs-host

> 标签: JavaScript

## 简介

LAVS host adapter for DeepSeek Harness: discovers lavs.json view bundles, serves them same-origin for the iframe bridge, exposes list/call on the /lavs Connection channel plus a loopback CLI endpoint
