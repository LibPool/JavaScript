# @mia-cx/tailwindcss-themes

> 标签: css, css-in-js, plugin, tailwind, tailwindcss, theme, themes, theming

## 简介

Tailwind plugin for theming. Provide media queries and/or multiple selectors, and variants for each theme will be generated.
