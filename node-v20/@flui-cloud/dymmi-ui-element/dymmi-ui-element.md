# @flui-cloud/dymmi-ui-element

> 标签: JavaScript

## 简介

The dymmi database console as a framework-agnostic Web Component (<dymmi-database-console>). Self-contained Angular 22 bundle — embeddable in any host (incl. Angular 18) without recompiling.
