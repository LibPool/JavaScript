# @meteo-layer/core

> 标签: cesium, gis, gpu, maplibre, meteorology, raster, visualization, weather, wind

## 简介

meteo-layer 渲染器无关内核：解码(含 Go wasm 内核与 Worker)、调色板、格式注册、数据源注册、色标组件。可被 Cesium / MapLibre 等渲染器包复用。
