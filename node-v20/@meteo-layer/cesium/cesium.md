# @meteo-layer/cesium

> 标签: 3d, cesium, gis, meteorology, visualization, weather, wind

## 简介

meteo-layer 的 Cesium 渲染器：填色图层 / 风场粒子 / 拾取 / 格点值 / 垂直剖面（依赖 @meteo-layer/core）。
