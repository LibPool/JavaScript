# @adlc/autopilot

> 标签: adlc, agents, autopilot, github-issues, orchestration

## 简介

Quota-gated local issue-to-PR loop: picks a GitHub issue, shapes an ADLC ticket, dispatches one sandboxed fleet run per issue, gates, attests and opens the PR. Composes @adlc/fleet; adds no gate logic.
