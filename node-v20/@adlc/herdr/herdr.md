# @adlc/herdr

> 标签: adlc, agentic, ai, herdr, observability, tmux

## 简介

ADLC surfaced at the terminal-multiplexer layer: a herdr plugin showing per-pane ticket/phase/gate state, a backlog board, and gate actions. Published for discovery — herdr itself installs this plugin from the GitHub subdirectory, not from npm.
