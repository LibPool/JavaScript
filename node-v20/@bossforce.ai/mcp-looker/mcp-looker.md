# @bossforce.ai/mcp-looker

> 标签: JavaScript

## 简介

MCP server for the [Looker](https://cloud.google.com/looker) **API 4.0**, using API3 client-credentials authentication. A good fit for listing Looks and dashboards, running a saved Look, or running an ad-hoc inline query from an agent.
