# @bossforce.ai/mcp-google-analytics

> 标签: JavaScript

## 简介

MCP server for **Google Analytics 4** (Data API v1beta). Run reports on traffic, users and events, fetch realtime activity, and list available metrics and dimensions. Read-only.
