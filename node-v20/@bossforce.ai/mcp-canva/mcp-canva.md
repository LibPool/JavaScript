# @bossforce.ai/mcp-canva

> 标签: JavaScript

## 简介

MCP server for the [Canva Connect API](https://www.canva.dev/docs/connect/). Read-only access to a Canva account: list and search designs, read a design's metadata, browse folder contents, and read the current user and profile. Authenticated with OAuth2 u
