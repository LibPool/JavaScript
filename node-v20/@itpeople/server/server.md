# @itpeople/server

> 标签: JavaScript

## 简介

Сервер Node.js на основе HTTP/2. Имеется поддержка виртуальных хостов, некоторые функции реверс-прокси. Возможен запуск как с системе под управлением pm2, так и внутри отдельного проекта.
