# dsh-gemini-kitten-widget

> 标签: deepseek-harness, dsh, dsh-plugin, gemini, quota, widget

## 简介

DSH 界面右下角的 Gemini 猫娘额度挂件：显示 Google Gemini API 免费层今日已用/剩余次数（20 次/模型/天，UTC 午夜重置），可按型号切换查看、按额度变色预警、拖拽吸附、点击换台词。
