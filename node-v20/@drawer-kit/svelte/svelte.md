# @drawer-kit/svelte

> 标签: a11y, daisyui, drawer, modal, rtl, svelte, svelte5, tailwindcss

## 简介

A headless, primitive drawer/sidebar component for Svelte 5 — inline or overlay, collapsible, resizable, RTL-aware, zero runtime icon dependency.
