# @gitsea/mcp

> 标签: ai-agents, base, ethereum, gitsea, mcp, model-context-protocol, viem

## 简介

Model Context Protocol server for the GITSEA protocol on Base. Plug into Claude Desktop, Cursor, Cline, or any MCP-compatible AI client to read + write GITSEA on-chain state from natural language.
