# @jason-yin/ai-sync-cli

> 标签: "cli", "gist"], "sync", ["ai"

## 简介

这是一个极客专属的跨端同步工具，用于在 Windows、macOS 和 Linux 之间无缝同步各类 AI 辅助编程工具（如 Antigravity, Claude Code, Codebuddy 等）的 **全局偏好设置**、**权限配置**（例如 `accept-edits`）以及 **第三方 Skills 库文件夹**。
