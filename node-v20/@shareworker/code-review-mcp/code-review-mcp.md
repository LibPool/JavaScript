# @shareworker/code-review-mcp

> 标签: ai, claude, code-review, codex, devin, llm, mcp, model-context-protocol

## 简介

MCP server exposing the deterministic engineering layer of code review as tools for host agents (Claude Code, Codex, Devin). The server never calls an LLM.
