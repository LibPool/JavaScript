# dsh-x-memory

> 标签: deepseek-harness, dsh, dsh-plugin, markdown, memory, zcode

## 简介

文件式长期记忆：一条事实一个 Markdown 文件 + MEMORY.md 索引，按工作区隔离、会话级注入，给 agent 六个读写工具，设置页里可浏览与编辑。照 ZCode 那套记忆语义实现。File-based long-term memory for DeepSeek Harness — one fact per Markdown file plus a MEMORY.md index, per-workspace, injected per session, with six agent too
