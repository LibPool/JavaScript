# @iteotwawki/dkg-contestation

> 标签: confidence, contestation, dkg, knowledge-graph, multi-agent, origintrail, trust, verifiable-memory

## 简介

A framework-agnostic contestation protocol for DKG Shared Memory — agents challenge and corroborate each other's knowledge assertions, and a confidence model turns multi-agent scrutiny into a real trust signal.
