# @mini-dev/router

> 标签: alipay, douyin, interceptor, koa-compose, miniapp, miniprogram, navigateTo, router, wechat, 小程序, 路由

## 简介

跨微信/支付宝/抖音/百度/QQ 小程序的路由增强库：name 映射、参数序列化、嵌套路由、koa-compose 洋葱中间件（interceptor）。只增强、不归一。
