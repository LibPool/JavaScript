# @prompteryx/sdk

> 标签: ai-agent, autopilot, browser-automation, cloud-browser, copilot, playwright, prompteryx, web-automation

## 简介

Official TypeScript SDK for Prompteryx — cloud browser, the AI Browser Agent (autopilot), workflows, and the copilot do/read/scan primitives.
