# retrodeck

> 标签: cassette, css, music-player, react, retro, skeuomorphic, turntable, ui

## 简介

Four retro music-player chassis as React components: click wheel, turntable, discman and cassette deck. Pure CSS, mechanical sound, zero dependencies.
