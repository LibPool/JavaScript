# @namzu/analysis

> 标签: JavaScript

## 简介

Native, paged semantic index of JavaScript and TypeScript for @namzu/sdk. Answers "which function holds this string, what is its source, who calls it" with cited, evidence-carrying results, built on oxc-parser and node:sqlite.
