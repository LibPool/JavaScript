# @snap-rail/plugin-sdk

> 标签: cordis, electron, industrial, plugin, sdk, snap-rail

## 简介

Public SDK for developing, validating, building, signing, and publishing snap-rail plugins outside the monorepo — init templates, a doctor, the release packer, and the snap-rail-plugin CLI
