# dsh-block-hanging-commands

> 标签: agent, deepseek, deepseek-harness, dsh, dsh-plugin, guard, hang, interactive, shell

## 简介

DeepSeek Harness plugin that stops shell commands that would hang a turn (editors, REPLs, pagers, watch modes, dev servers, tail -f, interactive logins, git commit without -m) and tells the model the non-interactive alternative.
