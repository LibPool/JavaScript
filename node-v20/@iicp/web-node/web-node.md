# @iicp/web-node

> 标签: browser, consumer, discovery, e2e, encryption, esm, iicp, mesh, node, provider, webllm

## 简介

Browser-native IICP node (consume + serve): discovery-mesh client with mandatory E2E encryption (IICP-CX) + WebLLM provider. Zero-config, ESM.
