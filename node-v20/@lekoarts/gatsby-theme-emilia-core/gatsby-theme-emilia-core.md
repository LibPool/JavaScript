# @lekoarts/gatsby-theme-emilia-core

> 标签: gatsby, gatsby-plugin, gatsby-theme, lekoarts

## 简介

Core Theme for @lekoarts/gatsby-theme-emilia. This theme implements the Project node interface and exports templates (+ queries) which you can shadow.
