# @pikku/addon-commerce-stripe

> 标签: checkout, ecommerce, payments, pikku, pikku-addon, stripe, subscriptions

## 简介

A ready-made Stripe storefront: catalogue, cart, checkout, orders, fulfilment, refunds and subscriptions, shipping its own tables. Talks to the Stripe HTTP API directly, with no SDK dependency.
