# @voltro/plugin-sentry

> 标签: framework, typescript, voltro

## 简介

Deep Sentry integration — error tracking correlated to distributed traces, breadcrumbs from the framework log sink, controlled browser performance spans, and server traces routed from the framework's OTel tracer via @sentry/node in OTel-consumer mode.
