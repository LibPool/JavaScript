# @mdchristians/react-leaflet-cluster

> 标签: cluster, leaflet, map, marker-cluster, react, react-leaflet-v4

## 简介

React-leaflet-cluster is a plugin for react-leaflet. A wrapper component of Leaflet.markercluster.
