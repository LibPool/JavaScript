# ictrp-mcp-server

> 标签: chictr, clinical-trials, ictrp, mcp, model-context-protocol, trial-registry, who

## 简介

MCP server for the WHO International Clinical Trials Registry Platform (ICTRP). Plain HTTP, no browser. Every response is explicit about the export's known incompleteness.
