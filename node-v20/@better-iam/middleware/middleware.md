# @better-iam/middleware

> 标签: abac, access-control, authentication, authorization, express, fastify, hono, iam, middleware, multi-tenant, rbac, typescript

## 简介

Express, Hono, and Fastify middleware for Better IAM: serve the IAM API, add per-request helpers, and guard routes with requireSession and authorize.
