# @sumidata/browser

> 标签: JavaScript

## 简介

Session replay, console/error capture, and product events for the browser. Same SDK that ships on the CDN `<script>` tag — packaged for Next.js, Vite, Nuxt, and any bundler/CSP-strict setup.
