# @keelcodes/settlement

> 标签: agent, http-402, machine-payments, mpp, payments, receipts, settlement, x402

## 简介

Settlement core for agent payments: x402 v2 and MPP (HTTP Payment auth scheme) codecs, receipts and a reconciliation ledger. No billing.
