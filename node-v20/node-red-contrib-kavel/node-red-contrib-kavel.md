# node-red-contrib-kavel

> 标签: ai, image-editing, image-generation, kavel, node-red, text-to-image

## 简介

Node-RED node for Kavel: turn a prompt into an AI image, or edit an image, and get back a CDN link. Works on the free tier with no API key.
