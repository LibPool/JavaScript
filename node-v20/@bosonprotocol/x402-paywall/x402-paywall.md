# @bosonprotocol/x402-paywall

> 标签: boson-protocol, browser, escrow, payments, paywall, react, viem, wagmi, web3, x402

## 简介

Browser paywall for the Boson Protocol x402 escrow scheme — renders the FullOffer, connects a wallet via wagmi, drives the atomic commit-and-redeem flow, and returns the resource. Mirrors the upstream @x402/paywall PaywallProvider contract.
