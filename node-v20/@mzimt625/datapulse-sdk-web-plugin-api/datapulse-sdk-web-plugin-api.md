# @mzimt625/datapulse-sdk-web-plugin-api

> 标签: JavaScript

## 简介

DataPulse Web SDK 的插件契约包。它定义 SDK 配置、插件初始化上下文、预置属性与页面上下文扩展点，不包含任何自动采集行为。
