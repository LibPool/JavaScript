# @mzimt625/datapulse-sdk-web-sender-batch

> 标签: JavaScript

## 简介

批量 Sender。接收 SDK 批次后合并事件，达到 `maxEvents` 或 `flushInterval` 时交给下游 Sender。`flush()` 会串行排空不足一批的尾部事件；不同项目或写入密钥的事件不会合并到同一个批次。
