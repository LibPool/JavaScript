# @distilled.cloud/waku

> 标签: cloudflare, rsc, vite, waku, workers

## 简介

Wrangler-free Waku integration implementing the framework-core Framework service: programmatic build/dev with the deploy platform behind a DeployTarget value (Cloudflare Workers built in at ./cloudflare).
