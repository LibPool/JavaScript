# @shtrikh17/shadcn-ex

> 标签: JavaScript

## 简介

This repository contains several projects used to extend the functionality of [shadcn/ui](https://github.com/shadcn-ui/ui) library. We provide several components which were not present (at least at the time of development) in the original library.
