# @hyperse/esbuild-plugin-preserve-directives

> 标签: esbuild, hyperse, preserve-directives, tsup, typescript, use client

## 简介

This plugin that preserves important directives (e.g., 'use client') at the top of output files for esbuild, tsup, etc.
