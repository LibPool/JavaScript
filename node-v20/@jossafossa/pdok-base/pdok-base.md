# @jossafossa/pdok-base

> 标签: JavaScript

## 简介

PDok Api Wrapper is a TypeScript library designed to interact with PDOK (Publieke Dienstverlening Op de Kaart) geocoding and location services. It provides a modular, type-safe interface for accessing PDOK endpoints and working with geospatial data in mod
