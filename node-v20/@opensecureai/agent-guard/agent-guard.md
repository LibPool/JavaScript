# @opensecureai/agent-guard

> 标签: agent, ai-security, excessive-agency, genai, llm, mcp, owasp, prompt-injection, security, tool-calling

## 简介

Dependency-free static analyzer that audits LLM agent tool/function definitions (OpenAI, Anthropic, MCP) for excessive agency, code-execution & SSRF sinks, secret access, and data-exfiltration surface — mapped to the OWASP 2025 LLM Top-10. Runs in CI.
