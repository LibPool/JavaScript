# @devbux/typesafe-mcp

> 标签: ai, decision-model, jev, mcp, model-context-protocol, typesafe, typescript

## 简介

A Model Context Protocol server for TypeSafe AI's Jev decision model, with typed Choice, Score, Noul and Box tools and image inputs.
