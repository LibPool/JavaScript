# @fmfi-uk-1-ain-412/resolution-editor

> 标签: JavaScript

## 简介

An interactive editor of first-order resolution proofs, intended to be used as a teaching tool. Web-based, client-only, available for use at https://fmfi-uk-1-ain-412.github.io/resolution-editor/.
