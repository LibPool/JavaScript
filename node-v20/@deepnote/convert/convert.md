# @deepnote/convert

> 标签: JavaScript

## 简介

Bidirectional converter between Deepnote project files (`.deepnote`) and multiple notebook formats: Jupyter (`.ipynb`), Quarto (`.qmd`), Percent (`.py`), and Marimo (`.py`).

- 源码仓库：git+https://github.com/deepnote/deepnote.git
