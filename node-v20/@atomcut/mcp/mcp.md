# @atomcut/mcp

> 标签: atomcut, claude-code, mcp, model-context-protocol, motion-design, video-editing

## 简介

Drive a running AtomCut editor from Claude Code, Claude Desktop, Cursor or any MCP client — every editor verb as a tool, renders as images, the AtomCut skill as resources.
