# iris-eval

> 标签: agent-eval, iris, llm-eval, mcp, mcp-server

## 简介

Runs Iris, the MCP server that scores every agent output for quality, safety and cost. The server is @iris-eval/mcp-server; this package makes `npx iris-eval` start it, at the server's latest release.
