# @ohto/nuxt-gtag-ecommerce

> 标签: JavaScript

## 简介

A Nuxt 3 module that extends [`nuxt-gtag`](https://nuxt.com/modules/gtag) with a typed API for Google Analytics 4 (GA4) ecommerce events.
