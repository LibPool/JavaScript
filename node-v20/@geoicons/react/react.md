# @geoicons/react

> 标签: areas, countries, country-map, geography, geography-icons, geoicons, icons, iso-3166, iso-3166-2, map, maps, provinces, react, react-component, states, subdivisions, svg, svg-icons, territories, tree-shakable, world-map

## 简介

799 geographic map SVG icons (255 countries & territories + 167 world areas + 377 subdivisions) as tree-shakable React components — control weight, color, and fill with props, themed via currentColor.
