# @atomicloud/diene.standard-config

> 标签: atomicloud, bun, cjs, config, esm, postgres, presets, redis, s3, testcontainers, zod

## 简介

Infra config preset schemas (postgres, cache, kv, storage) + Testcontainers TestHelper for the AtomiCloud TypeScript family — keyed, UPPERCASE, secrets blank-in-yaml, composed into a lib/bun/config registry.
