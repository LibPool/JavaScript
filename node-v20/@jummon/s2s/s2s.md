# @jummon/s2s

> 标签: client-credentials, jummon, oidc, private_key_jwt, s2s, service-account

## 简介

Server-side helper for Jummon service-account integrations: private_key_jwt token minting (cache/refresh, fail-closed) + thin catalog-api wrappers (createUser, invite, setPassword) with correct field names baked in.
