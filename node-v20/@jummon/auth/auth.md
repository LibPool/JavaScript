# @jummon/auth

> 标签: auth, authentication, jummon, oidc, pkce, sso

## 简介

Official Jummon browser auth SDK for customer apps: OIDC authorization-code + PKCE (redirect flow), silent refresh, headless in-app login (mode: "headless"), and a headless-aware React binding.
