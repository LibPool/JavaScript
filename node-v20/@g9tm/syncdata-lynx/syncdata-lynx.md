# @g9tm/syncdata-lynx

> 标签: brotli, g9, lynx, native-module, offline, sync

## 简介

Lynx support for the G9SyncData TypeScript client: a Brotli native module (Android org.brotli decoder, iOS Compression framework, Lynxtron/Node zlib) for the sync frames, and the transport over @g9tm/signalr-supernetcore-lynx.
