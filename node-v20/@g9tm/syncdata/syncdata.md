# @g9tm/syncdata

> 标签: g9, lynx, offline-first, signalr, sqlite, sync

## 简介

TypeScript twin of the G9SyncData .NET client for Lynx, Node and browsers: the sync engine, the G9RowBatch protocol, the SQLite client store (same schema as the .NET store) and the SignalR transport.
