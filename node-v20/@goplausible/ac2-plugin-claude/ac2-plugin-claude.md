# @goplausible/ac2-plugin-claude

> 标签: JavaScript

## 简介

AC2 channel plugin for Claude Code — connects Claude Code to AC2 wallet peers (e.g. Regent) over Liquid Auth (FIDO2) + WebRTC DataChannels.
