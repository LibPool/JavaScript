# @goku_12/stream-zip-downloader

> 标签: azure-blob, browser-download, cloudflare-r2, file-system-access-api, google-cloud-storage, large-files, minio, nextjs, r2, s3, streaming, streamsaver, zero-memory, zip, zip64

## 简介

Universal high-performance browser streaming ZIP downloader for large files & folders (5GB-100GB+) from any cloud storage (AWS S3, GCS, Azure Blob, Cloudflare R2, MinIO, or custom CDN/HTTP URLs) directly to disk with zero memory overflow.
