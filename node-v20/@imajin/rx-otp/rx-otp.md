# @imajin/rx-otp

> 标签: Async, Browser, ES2015, ES2016, ES2017, ES2018, ES6, ES7, ES8, ES9, Google Authenticator, HOTP, OTP, Observable, Observer, One-Time Password, RFC 3548, RFC 4226, RFC 6238, ReactiveX, Rx, RxJS, Streams, TOTP, Two-Factor Authentication, Typescript

## 简介

HMAC-based (HOTP) and Time-based (TOTP) One-Time Password manager. Works with Google Authenticator for Two-Factor Authentication.
