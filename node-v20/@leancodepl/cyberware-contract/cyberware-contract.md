# @leancodepl/cyberware-contract

> 标签: contract, embed, iframe, javascript, leancode, penpal, react, typescript

## 简介

Creates type-safe contracts between a host app and a remote iframe app (e.g., Replit embed). Uses `postMessage` via Penpal for secure cross-origin communication.
