# @dailies-studio/effects

> 标签: JavaScript

## 简介

First-party effect library: tsl-textures generators auto-adapted into contracted react-three-fiber components (foundations.md §4 — effect = contracted component), rendered unlit on a viewport-filling plane through the WebGPU-first stage; plus Paper Shader
