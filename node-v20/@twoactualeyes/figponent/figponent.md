# @twoactualeyes/figponent

> 标签: JavaScript

## 简介

Convert Figma components into framework component files (Astro first). Reconciles re-runs via section hashes; supports adopt/rename for bare files, a tokens.json semantic-class rewriter, and an opt-in inline-style output mode.
