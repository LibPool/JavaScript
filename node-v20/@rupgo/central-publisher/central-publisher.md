# @rupgo/central-publisher

> 标签: blog, central, nextjs, publisher, rupgo

## 简介

Handler listo para Next.js que implementa el contrato HTTP v1 de Central (central.rupgo.com) para publicar artículos en tu página.

## 官网

- 官网：https://central.rupgo.com/docs/publisher
- 源码仓库：git+https://github.com/ruposhop/central.git
