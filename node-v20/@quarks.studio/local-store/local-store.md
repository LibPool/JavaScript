# @quarks.studio/local-store

> 标签: JavaScript

## 简介

Local persistence of installations and a global cache of artifacts. It keeps per-project catalogs/locks and content-addressed bundles in `~/.quark/cache/skills/sha256/<hash>.tgz`.
