# @ziro-agent/checkpoint-redis

> 标签: agent, ai, checkpoint, durable, redis, ziroagent

## 简介

Redis Checkpointer adapter for ZiroAgent SDK — durable agent state with sorted-set indexed snapshots (RFC 0006).
