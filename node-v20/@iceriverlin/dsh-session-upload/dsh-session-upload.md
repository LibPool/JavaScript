# @iceriverlin/dsh-session-upload

> 标签: attachment, deepseek-harness, dsh, dsh-plugin, file, upload

## 简介

Attach files to a DSH conversation: paperclip button in the composer, inline file capsule in the draft, files stored under the uploads dir with an auto-extracted .txt sidecar so any agent can read text/docx/xlsx/pptx/zip content.
