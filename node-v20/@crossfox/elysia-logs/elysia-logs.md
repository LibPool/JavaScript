# @crossfox/elysia-logs

> 标签: activity-log, audit-log, bun, crossfox, elysia, error-log, logging

## 简介

Universal DB-backed logging for Elysia apps: activity/audit log with entity+actor diffing, error log (backend+frontend), client ingestion, admin query API, unread badge, retention.
