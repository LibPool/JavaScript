# @crossfox/ws

> 标签: ack, bun, crossfox, dedup, elysia, offline-queue, pubsub, react, realtime, reconnect, redis, redis-streams, reliable, replay, seq, typescript, websocket, ws

## 简介

Reliable WebSocket protocol: client (reconnect, offline queue, ack) + server (Redis Streams seq/replay/dedup) + Elysia adapter. Browser and Bun/Node.
