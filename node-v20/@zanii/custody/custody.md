# @zanii/custody

> 标签: JavaScript

## 简介

Supply-chain provenance: co-signed custody chains for physical goods. Each handoff (factory→shipper→customs→retailer) is a 2-party co-signed receipt, multi-party events are N-party swarm receipts, and item history is a pseudonymous verifiable slice — no p
