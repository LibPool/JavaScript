# @zanii/trading

> 标签: JavaScript

## 简介

Accountable agent trading desks: pre-trade checks (limits, restricted lists, fat-finger bands) recorded before an order leaves, best-execution evidence across venues, clock-sync statements, and order-to-fill trails a compliance officer can replay.
