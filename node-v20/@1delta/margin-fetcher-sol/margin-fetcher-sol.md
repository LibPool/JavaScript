# @1delta/margin-fetcher-sol

> 标签: JavaScript

## 简介

Lending data provision for the Solana families (Kamino, Jupiter Lend, Save, Loopscale, Project 0) and the Solana earn rows, in margin-fetcher's shapes. Zero runtime dependency on viem: margin-fetcher is imported type-only.
