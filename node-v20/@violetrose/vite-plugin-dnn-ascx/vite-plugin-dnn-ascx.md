# @violetrose/vite-plugin-dnn-ascx

> 标签: ascx, dnn, dotnetnuke, vite, vite-plugin

## 简介

Vite plugin to inject hashed assets into DotNetNuke (DNN) .ascx skin files and generate dev-ready skins.
