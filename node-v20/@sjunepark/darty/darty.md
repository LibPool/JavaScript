# @sjunepark/darty

> 标签: JavaScript

## 简介

한국 DART 공시를 검색하고 조회하는 읽기 전용 CLI 도구입니다. 사람과 에이전트 모두 `darty` 명령을 subprocess로 실행해 같은 기능을 사용할 수 있습니다.
