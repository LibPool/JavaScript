# @endorian/tailwindcss-plugin-angular

> 标签: angular, tailwind, tailwindcss, tailwindcss-plugin

## 简介

This is a plugin for [Tailwind CSS](https://tailwindcss.com/) that adds support for the [Angular framework](https://angular.io). Using it enables you to easily style Angular's components and directives using Tailwind CSS classes.
