# hostlesswp

> 标签: cloudflare, hyperdrive, migration, php-wasm, serverless, wordpress, workers

## 简介

Move a running WordPress site onto Cloudflare Workers with one command: PHP compiled to WebAssembly, your existing MySQL behind Hyperdrive.
