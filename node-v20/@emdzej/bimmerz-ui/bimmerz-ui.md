# @emdzej/bimmerz-ui

> 标签: JavaScript

## 简介

Shared Svelte 5 components + lifecycle hooks for the bimmerz app family — brand wordmark, M-stripe, embedded-mode auto-connect hook. Source-only — consumer apps' Vite compiles them.
