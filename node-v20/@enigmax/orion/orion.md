# @enigmax/orion

> 标签: enigma, enigma-agent, orion, performance, qa, scalability, skills

## 简介

Orion packaged as an optional enigma agent: skills, slash commands and sub-agents that hunt broken flows, slow loads and scaling limits in a real browser. Installed on demand into an isolated agent context by enigma-cli; never deployed to your normal codi
