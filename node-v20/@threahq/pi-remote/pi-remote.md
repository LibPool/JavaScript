# @threahq/pi-remote

> 标签: agent, pi, pi-package, threa

## 简介

A Pi extension that links a local Pi session to a Threa scratchpad, so you can drive Pi from Threa.

## 官网

- 官网：https://threa.io/developers
- 源码仓库：git+https://github.com/threahq/threa.git
- npm 页面：https://www.npmjs.com/package/@threahq/pi-remote
