# @jugaaadi/advance-scroll-input

> 标签: cad, dimension, drag, input, number-input, react, roller, scrubber, touch, units

## 简介

A touch-friendly number input with a vertical roller scrubber and unit-aware parsing (10ft, 100in, 123mm, 123", 5' 6").
