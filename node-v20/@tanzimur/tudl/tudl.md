# @tanzimur/tudl

> 标签: JavaScript

## 简介

TUDL — Nothing Universal Downloader. Windows-native yt-dlp/gallery-dl frontend with a Nothing OS dot-matrix TUI, format picker with file-size estimates, themes, cookies, aria2c multi-thread and bulk queue.
