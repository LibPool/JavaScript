# @meregy/nodejs-nets-core

> 标签: api, authentication, email, express, firebase, middleware, nodejs, oauth2, permissions, push-notifications, rbac, typescript

## 简介

A comprehensive Express.js framework for Node.js applications providing lazy API request handlers, authentication, permissions, email notifications, push notifications and common tasks - Port of django-nets-core
