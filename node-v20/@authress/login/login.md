> 标签: Authress, Authress client, DBSC, Device Bound Session Credentials, IDaaS, Login, Login Client, Oauth2, Oauth2.1, Oauth3, application security, auth, authentication, authentication as a service, extension, federated login, platform, platform login, secure login, universal login, user authentication, user identity, user security

## 简介

Universal login sdk for Authress authentication as a service. Provides managed authentication for user identity, authentication, and token verification.
