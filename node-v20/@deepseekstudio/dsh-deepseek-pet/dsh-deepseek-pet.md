# @deepseekstudio/dsh-deepseek-pet

> 标签: balance, deepseek, desktop-pet, dsh, dsh-plugin

## 简介

DeepSeek 桌宠：把「DSH 账户余额 + 蓝鲸女仆桌宠」连起来。宿主端查询余额、通过 127.0.0.1 回环接口喂给桌面悬浮窗，并提供 pet_balance / pet_control 两个模型工具。
