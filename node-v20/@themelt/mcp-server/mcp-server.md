## 简介

Melt MCP server — exposes value-leak discovery (melt_analyze_value_vectors, melt_estimate_annual_leak) and a lead-capture handoff (melt_request_scan) to Claude, Cursor, GitHub Copilot, and any MCP-compatible agent.
