# @mfejs/pkg-cli

> 标签: mfejs, package

## 简介

Pkg CLI 是一个基于 Vite 实现的 Vue 组件库构建工具，通过 Pkg CLI 可以快速搭建一套功能完备的 Vue 组件库。
