# xterm-addon-webgl.es

> 标签: terminal, webgl, xterm, xterm.js

## 简介

An addon for [xterm.js](https://github.com/xtermjs/xterm.js) that enables a WebGL2-based renderer. This addon requires xterm.js v4+.
