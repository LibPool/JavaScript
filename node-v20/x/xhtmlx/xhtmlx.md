# xhtmlx

> 标签: ajax, api, attributes, client-side, declarative, fetch, html, htmx, json, lightweight, no-build, rendering, rest, spa, template

## 简介

Declarative HTML attributes for REST API driven UIs. Like htmx, but with JSON APIs and client-side rendering.
