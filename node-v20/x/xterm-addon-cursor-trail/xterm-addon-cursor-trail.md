# xterm-addon-cursor-trail

> 标签: cursor, terminal, trail, xterm, xterm.js

## 简介

A kitty-inspired cursor trail addon for xterm.js. When the cursor moves, a translucent quad with rounded corners smoothly chases the cursor position, fading out behind it.
