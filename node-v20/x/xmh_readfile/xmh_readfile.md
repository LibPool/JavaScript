# xmh_readfile

> 标签: JavaScript

## 简介

1.注册npm账号 2.将源切换到npm(用taobao源的要切换)  `nrm use npm` 3.初始化项目  `$ npm init -y` 4.创建入口文件 5.开发 6.登录npm账号  `$npm adduser` 7.发布包 `$ npm publish`
