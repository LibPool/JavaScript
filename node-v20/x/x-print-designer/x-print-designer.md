# x-print-designer

> 标签: JavaScript

## 简介

基于 Vue 3 + TypeScript 开发的打印设计器，支持可视化拖拽设计打印模板，集成 ECharts 图表组件。

- 源码仓库：git+https://github.com/0ldFive/Vue-Print-Designer.git
