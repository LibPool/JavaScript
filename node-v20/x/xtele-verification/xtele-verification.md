# xtele-verification

> 标签: JavaScript

## 简介

**XTele-Verification** adalah modul verifikasi berbasis Telegram Bot yang simple, cepat, dan powerfull! Cocok buat project Node.js yang butuh sistem verifikasi akun via bot Telegram.
