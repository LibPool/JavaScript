# xinye-form-api-mcp

> 标签: erp, form-api, mcp, model-context-protocol, xinye

## 简介

MCP server for the XinYe ERP generic form API (list/detail/add/edit/delete/check/uncheck). Zero dependencies, stdio transport.

- npm 页面：https://www.npmjs.com/package/xinye-form-api-mcp
