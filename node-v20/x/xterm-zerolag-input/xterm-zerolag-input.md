# xterm-zerolag-input

> 标签: addon, input-latency, keystroke, latency, local echo, local-echo, mosh, overlay, predictive, remote-terminal, ssh, terminal, web-terminal, write-through, xterm, xterm.js, zero-lag

## 简介

Instant keystroke feedback overlay for xterm.js: Mosh-inspired local echo that removes perceived input latency over SSH, tunnels and other high-RTT connections
