# xoobo-cli-linux-arm64-gnu

> 标签: JavaScript

## 简介

A secure, multi-provider AI coding agent for the terminal with durable sessions, approvals, tools, skills, MCP, and a full-screen TUI. Native binary for linux/arm64/glibc.
