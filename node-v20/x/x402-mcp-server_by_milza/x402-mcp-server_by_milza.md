## 简介

MCP server exposing 5 pay-per-call x402 tools on Base Mainnet, each self-paying via EIP-3009 through a local wallet -- no API keys, no signup: Markdown Extractor, SPA Render & Extract, Burn-Once Secret Vault, SVG Bar Chart Renderer, GeoTIFF → PNG/WebP Til
