# xiaolizi-http-sdk

> 标签: http, sdk, xzfg, 二次开发包, 小栗子, 机器人

## 简介

内核框架为小栗子机器人，采用社区 xzfg 大佬的 http 插件进行二次封装的 sdk 开发包，主要方便直接进行机器人的操作，接口方法特性侧重于原酷Q的接口名
