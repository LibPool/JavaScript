# xanima-openclaw

> 标签: agent-continuity, agent-memory, ai-memory, fsrs, knowledge-graph, openclaw, openclaw-plugin, spaced-repetition, xanima

## 简介

Xanima for OpenClaw (formerly openwave): autonomic long-term memory and agent continuity. Injects identity, goals and query-relevant recall (with confidence and relative-time labels) into every turn, and runs the sleep system. Local brains or a shared Xan
