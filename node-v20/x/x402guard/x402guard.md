# x402guard

> 标签: agent-payments, ai-agents, audit, sast, scanner, security, solidity, usdc, x402

## 简介

Security scanner for x402 / agent-payment integrations — finds the integration-layer bugs general Solidity scanners miss (replay, allowance, idempotency, unauthenticated broadcast, SSRF webhooks).
