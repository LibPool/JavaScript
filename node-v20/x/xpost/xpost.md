# xpost

> 标签: bluesky, cli, facebook, instagram, linkedin, mcp, pinterest, scheduling, social-media, threads, tiktok, x, xpost, youtube

## 简介

Post to 9 social networks from the terminal or from any MCP client. Every post waits for your approval. CLI + local MCP server for xpost.to.
