# xenocept-plugin-aeor-claude

> 标签: anthropic, claude, claude-code, mcp, ocr, plugin, vision, xenocept, xenocept-plugin

## 简介

Xenocept plugin for Anthropic Claude — delivers sessions to Claude Code via MCP channels or polling, AND optionally runs Claude as the OCR / vision provider for screenshot enrichment. One Anthropic API key, two roles.
