# xy-ai-chat

> 标签: 1.0.0, ai-chat, lit, lit-element, web-components

## 简介

基于 Lit 的 AI 智能聊天 Web Component，支持浮动按钮 / 嵌入模式，可在 Vue2、React、UniApp、原生 HTML 等任意项目中使用。
