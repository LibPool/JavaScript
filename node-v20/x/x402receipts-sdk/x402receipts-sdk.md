# x402receipts-sdk

> 标签: accounting, agents, audit, base, hedera, receipts, reconciliation, solana, usdc, x402

## 简介

Record every x402 purchase your agent makes as a reconciled, auditable receipt. One wrapper around the fetch the agent already pays with; no API key — the agent's wallet is the account.
