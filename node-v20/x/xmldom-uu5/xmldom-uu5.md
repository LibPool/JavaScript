# xmldom-uu5

> 标签: DOMParser, XMLSerializer, dom, javascript, parser, uu5, w3c, xml

## 简介

A W3C Standard XML DOM(Level2 CORE) implementation and parser(DOMParser/XMLSerializer) with extensions for uu5 (attribiutes without values are supported during parsing).
