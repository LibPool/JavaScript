# x402-aa-wallet

> 标签: account-abstraction, agent, ai-agent, base, eip-3009, erc-4337, smart-wallet, wallet, x402

## 简介

Give an ERC-4337 / account-abstraction agent a dedicated, non-custodial EOA so it can pay x402 (HTTP 402) challenges against any x402 merchant — smart-wallet signatures don't yet settle on today's facilitators. Optional maxAmountUsd spend cap.
