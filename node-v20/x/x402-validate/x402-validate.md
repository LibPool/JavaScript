# x402-validate

> 标签: blockchain, cli, coinbase, crypto, http402, payment, paywall, validator, web3, x402

## 简介

CLI + library to check if URLs support the x402 HTTP payment protocol. Validates schema, checks facilitator reachability, and outputs colored results.
