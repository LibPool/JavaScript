# xactus

> 标签: component, declarative, dom, event-bus, lightweight, micro-frontend, no-virtual-dom, reactive, template, two-way-binding, ui, vanilla-js, widget, x-if, x-map, x-model

## 简介

Lightweight declarative UI component library for vanilla JavaScript. Define state and an HTML template — Xactus handles rendering, two-way binding, list management, computed properties, and surgical DOM updates. No virtual DOM, no build step required.
