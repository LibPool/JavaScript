# xml-to-srt-cli

> 标签: Accessibility, BBC, BBC Academy, Beitragsservice, GEZ, Mediathek, MediathekView, MediathekViewWeb, SRT, SubRip, VTT, WEBVTT, capturing, stream, Öffentlich-Rechtliche

## 简介

Convert XML subtitles (EBU-TT format) from online broadcasting platforms like MediathekView (Germany) or the BBC (UK) into SRT (SubRip) subtitles.
