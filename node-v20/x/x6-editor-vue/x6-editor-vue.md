# x6-editor-vue

> 标签: antv, editor, flowable, vue, x6, 拓扑图, 流程图, 编辑器

## 简介

用vue开发的基于antv/x6打造的流程图编辑器，支持自定义节点，导入数据，导出数据，保存xml文件等等
