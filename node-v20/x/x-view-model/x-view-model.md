# x-view-model

> 标签: computed, event-driven, flow, lightweight, management, mvvm, observable, performance, proxy, react, react-hooks, reactive, reactive-programming, state, state-management, store, typescript, view-model

## 简介

A lightweight, type-safe MVVM state management solution for React applications. Features reactive updates, computed properties, and deep path selection with minimal bundle size.
