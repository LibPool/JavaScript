# xslt-migrate-check

> 标签: audit, chrome, cli, codemod, compatibility, deprecation, migration, xml-stylesheet, xslt, xsltprocessor

## 简介

Scans a project for XSLT that stops working when Chrome removes native XSLT (Chrome 158, 17 November 2026), writes the migration patch, and tests the stylesheets on @tradik/xslt-processor against the browser
