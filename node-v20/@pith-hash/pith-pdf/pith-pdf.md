# @pith-hash/pith-pdf

> 标签: cmap, fonts, hashing, pdf, text-extraction

## 简介

PDF text extraction SDK: classic xref, xref streams, cmap and CID fonts via the pith-pdf Rust cdylib (koffi, prebuilt)
