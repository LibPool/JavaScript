# @pith-hash/pith-inflate

> 标签: decompression, deflate, hashing, inflate, zlib

## 简介

DEFLATE and zlib decompression SDK: RFC 1951/1950 streams with hard size limits via the pith-inflate Rust cdylib (koffi, prebuilt)
