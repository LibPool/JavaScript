# @saas-kit-dev/file-type-validator

> 标签: file-signature, file-type, magic-numbers, security, type-safe, upload, validation

## 简介

Validate file types using magic numbers (file signatures), not just extensions. Zero dependencies, TypeScript, works in Node.js and browser.
