# @api-common/spectral-ruleset-studio

> 标签: api-commons, api-governance, asyncapi, grounding, linting, openapi, ruleset, spectral, style-guide

## 简介

Turn a prose style guide into an OWNED, GROUNDED, well-named Spectral ruleset in your browser — pick a target, one of the 9 core functions, write the message and severity, and ground every rule with an owner, rationale and docs link. An API Commons tool.
