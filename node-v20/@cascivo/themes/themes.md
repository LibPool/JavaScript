# @cascivo/themes

> 标签: cascivo, css, css-theme, dark-mode, design-system, react, signals, theme

## 简介

First-party cascivo themes: light, dark, warm, flat, minimal, midnight, pastel, brutalist, corporate, terminal, cyberpunk, arcade. Components: @cascivo/react. Docs offline: npx @cascivo/docs
