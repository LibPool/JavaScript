# @hecigolab/utm-alias

> 标签: analytics, attribution, channel-grouping, cloudflare-workers, ga4, short-link, utm

## 简介

Turn short link aliases into URLs whose utm_medium GA4 can actually group. Zero dependencies, runs on Workers, Node and the browser.
