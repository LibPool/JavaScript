# @ddd-ts-kit/kafka

> 标签: clean-architecture, ddd, dead-letter-queue, domain-driven-design, event-driven, hexagonal-architecture, integration-events, kafka, transactional-outbox, typescript

## 简介

Kafka provider for integration events: idempotent keyed publishing for the outbox relay, one consumer group per consumer, offsets committed after handling, bounded retries and a dead-letter topic.
