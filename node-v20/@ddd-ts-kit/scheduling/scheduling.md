# @ddd-ts-kit/scheduling

> 标签: background-jobs, clean-architecture, cron, ddd, domain-driven-design, hexagonal-architecture, scheduled-jobs, scheduler, typescript

## 简介

Scheduled jobs that only trigger use cases: interval and cron schedules, one run across instances, no overlap, each run in its own execution scope.
