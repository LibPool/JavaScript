# @hrmoller/maildrop-mcp

> 标签: claude, disposable-email, maildrop, mcp, model-context-protocol, otp, testing

## 简介

MCP server for maildrop.cc disposable inboxes: list, read, wait for, extract one-time codes from, and delete test mail via the public GraphQL API.
