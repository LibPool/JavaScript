# @jules_davis/lightbase

> 标签: JavaScript

## 简介

Un client TypeScript générique pour consommer des API REST avec support de filtres avancés (`eq`, `neq`, `lt`, `gte`, `like`, `in`, `nin`) et de combinaisons logiques (`and`, `or`).
