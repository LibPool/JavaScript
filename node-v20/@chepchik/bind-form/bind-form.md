# @chepchik/bind-form

> 标签: accessibility, form, form-validation, spa, typed-forms, validation

## 简介

Dependency-free typed form engine: createForm() with types inferred from schema, sync/async/server validation pipeline, automatic server error mapping and built-in accessibility (aria-invalid, focus management). Also exports the original bindForm() helper
