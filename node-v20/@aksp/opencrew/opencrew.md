# @aksp/opencrew

> 标签: ai-agents, claude-code, cli, codex, crews, cursor, gemini, multi-agent, opencode, orchestration

## 简介

A reworked build of OpenSquad (by Renato Asse) — create AI agent crews that work together, right from your IDE. Multi-agent orchestration with an npm installer.
