# ferry-shaders

> 标签: background, dither, react, shader, webgpu, wgsl

## 简介

ferry-shaders: WebGPU background shaders for React. Every shader declares its parameters (colors, numbers, booleans, selects), so a panel can configure it live.

- npm 页面：https://www.npmjs.com/package/ferry-shaders
