# @citation-media/html-parser

> 标签: cloudflare-workers, html, mdream, parser, scraping, seo

## 简介

HTML parser for any JavaScript runtime: links, images, resources, metadata, JSON-LD, styles, hydration, and text in one pass without a DOM, with Markdown from mdream.
