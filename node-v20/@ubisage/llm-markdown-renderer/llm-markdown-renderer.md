# @ubisage/llm-markdown-renderer

> 标签: ai, assistant, chatbot, chatgpt, claude, gemini, gfm, llm, markdown, markdown-renderer, openai, react, syntax-highlighting

## 简介

A production-ready React component for rendering LLM/AI assistant markdown output with syntax highlighting, copy-to-clipboard, GFM support, and full customization.
