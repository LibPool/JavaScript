# @shashi-hans/icons

> 标签: heroicons, icon-library, icons, lucide, material-symbols, phosphor, react, svg, tabler, tree-shakeable, typescript

## 简介

A tree-shakeable React icon library of 8469 icons, with a weight prop (thin, regular, fill, duotone). Artwork from Phosphor, Lucide, Feather, Tabler, Heroicons, Iconoir, Material Symbols and Ionicons.
