# go-tokenless

> 标签: agent-skill, changesets, github-actions, mcp, npm, npm-token, oidc, provenance, publish, release, semantic-release, trusted-publishing

## 简介

Switch npm publishing in GitHub Actions from NPM_TOKEN to trusted publishing (OIDC) with one command. CLI, MCP server and Agent Skill.
