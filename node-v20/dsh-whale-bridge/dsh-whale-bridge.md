# dsh-whale-bridge

> 标签: bridge, deepseek-harness, desktop-pet, dsh, dsh-plugin, dsh-whale-widget, pet-whale, whale, widget

## 简介

串联 pet-whale 与 dsh-whale-widget：桌宠靠近挂件时进入「假装工作」并转身面向挂件，挂件扫到桌宠时用默认气泡播一条默认文字（不改动两个前置插件的源文件）
