# @contraagent/ui

> 标签: coding-agent, contraagent, custom-elements, lit, monitor, web-components

## 简介

Web components for the contraagent monitor: transcripts, task tables, the journal, plans, contracts. Framework-free (Lit), typed by @contraagent/api
