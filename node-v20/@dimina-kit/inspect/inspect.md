# @dimina-kit/inspect

> 标签: devtools, dimina, inspector, wxml

## 简介

Host-agnostic WXML tree extraction and inspection for dimina render layers: Vue runtime walk, stable-id registry, mutation-observing inspector, and a React tree panel.
