# @atlasauth/qwik

> 标签: JavaScript

## 简介

Qwik and Qwik City bindings for [Atlas](https://atlasauth.net). Same shape as `@atlasauth/react` and `@atlasauth/vue` — a provider, hooks, conditional guards, and mountable sign-in widgets — expressed idiomatically in Qwik.
