# @atlasauth/svelte

> 标签: JavaScript

## 简介

The official **Svelte / SvelteKit** SDK for Atlas — the Svelte peer of [`@atlasauth/react`](../react). Same surface, expressed the Svelte way: a client installed through **context**, reactive auth state exposed as **stores**, and `.svelte` **components**
