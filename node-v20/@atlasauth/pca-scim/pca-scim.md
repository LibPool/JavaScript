# @atlasauth/pca-scim

> 标签: agent authorization, agent registry, ai agents, entra, okta, pca, proof-carrying authority, provisioning, scim

## 简介

SCIM 2.0 /agents provisioning for PCA: expose the agent-passport registry as a SCIM resource (and push-provision to Entra Agent ID / Okta), so PCA agents live in the enterprise directory with lifecycle/governance.
