# @atlasauth/pca-attest-eat

> 标签: agent authorization, ai agents, channel binding, eat, pca, proof-carrying authority, rats, remote attestation, rfc 9711

## 简介

Per-session attestation freshness + channel binding for PCA (IETF SEAT / RA-TLS), emitting EAT (RFC 9711) with a RATS appraisal-policy split — so TEE evidence can't be replayed.
