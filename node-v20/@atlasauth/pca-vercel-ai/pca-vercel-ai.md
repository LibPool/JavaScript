# @atlasauth/pca-vercel-ai

> 标签: agent authorization, ai agents, middleware, pca, proof-carrying authority, step-up, tool calling, vercel ai sdk

## 简介

Vercel AI SDK tool-execution middleware for PCA: wrap a tool so each call attaches/verifies a proof-carrying action before execution, with step-up (prepareStep) on the agent loop.
