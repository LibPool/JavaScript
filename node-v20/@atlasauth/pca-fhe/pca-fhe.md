# @atlasauth/pca-fhe

> 标签: agent authorization, ai agents, bfv, homomorphic encryption, pca, proof-carrying authority, risk scoring, seal

## 简介

Homomorphic risk-gate evaluation for PCA: the evaluator computes the weighted risk functional + admission slack over ENCRYPTED risk inputs (node-seal / Microsoft SEAL BFV) and never sees the plaintext — only the authorized key holder decrypts the verdict.
