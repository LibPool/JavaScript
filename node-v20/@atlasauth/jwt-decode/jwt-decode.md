# @atlasauth/jwt-decode

> 标签: atlas, atlasauth, auth, decode, jwt, jwt-decode, token

## 简介

Tiny, zero-dependency helper to decode (not verify) an Atlas JWT in the browser or Node — the Atlas peer of jwt-decode. For verification, use @atlasauth/backend.
