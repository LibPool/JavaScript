# @atlasauth/pca-revoke

> 标签: agent authorization, ai agents, delegation, kill switch, pca, proof-carrying authority, revocation

## 简介

Realtime revocation + mid-run kill-switch for PCA: revoke a capability, an agent holder, or a whole delegation subtree, and deny in-flight actions against a pluggable revocation registry (Shared-Signals/CAEP consumable).
