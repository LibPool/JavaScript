# @atlasauth/pca-spiffe

> 标签: agent authorization, ai agents, pca, proof-carrying authority, spiffe, spire, svid, workload identity

## 简介

Bridge PCA agent identity with SPIFFE/SPIRE workload identity: parse/verify JWT-SVIDs and X.509-SVID SPIFFE IDs, map a SPIFFE ID to/from a PCA agent holder.
