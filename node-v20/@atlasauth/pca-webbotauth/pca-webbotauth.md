# @atlasauth/pca-webbotauth

> 标签: agent authorization, ai agents, bot authentication, http message signatures, pca, proof-carrying authority, rfc 9421, web bot auth

## 简介

Web Bot Auth for PCA (RFC 9421 HTTP Message Signatures): sign outbound agent HTTP requests with an Ed25519 key published at /.well-known/http-message-signatures-directory, optionally carrying the PCA per-action proof, so PCA agents pass Cloudflare/AWS-WAF
