# @atlasauth/pca-connect

> 标签: agent authorization, ai agents, connections, oauth, pca, proof-carrying authority, token vault

## 简介

Outbound connection token vault for PCA agents: hold and refresh an agent's third-party OAuth tokens (Google/Slack/etc.) under a PCA capability, so a tool call presents a provably-authorized, least-privilege outbound token.
