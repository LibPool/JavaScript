# @atlasauth/pca-agentcard

> 标签: a2a, agent authorization, agent card, agentfacts, ai agents, pca, proof-carrying authority, well-known

## 简介

Signed agent card + AgentFacts attestor for PCA: issue/host a /.well-known/agent-card.json (A2A AgentCardSignature) and an AgentFacts metadata doc where PCA is the THIRD-PARTY attestor (separating self-asserted from attested), pointing to live verifiable
