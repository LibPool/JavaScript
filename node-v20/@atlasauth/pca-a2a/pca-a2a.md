# @atlasauth/pca-a2a

> 标签: a2a, agent authorization, agent card, agent2agent, ai agents, ap2, pca, proof-carrying authority

## 简介

A2A (Agent2Agent) adapter for PCA: verify/attach proof-carrying actions on A2A task send/receive, validate Signed Agent Cards, and an AP2 payment-mandate profile.
