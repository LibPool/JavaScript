# @atlasauth/pca-notary

> 标签: agent authorization, ai agents, external facts, notary, pca, proof-carrying authority, tlsnotary, zktls

## 简介

External-fact attestation (zkTLS/TLSNotary direction) for PCA: a notary signs the observed response of an external request, selectively redactable, bound into a PCActn so an agent proves 'the external API returned X' as part of its proof-carrying action.
