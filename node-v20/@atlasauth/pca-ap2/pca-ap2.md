# @atlasauth/pca-ap2

> 标签: agent authorization, agent payments protocol, ai agents, ap2, mandates, payments, pca, proof-carrying authority

## 简介

AP2 (Agent Payments Protocol) Intent/Cart/Payment mandates as real SD-JWT credentials (integer minor units, key binding), bound to a PCA grant and action proof; x402 / Stripe Shared-Payment-Token settlement shapes.
