# @atlasauth/pca-idjag

> 标签: agent authorization, ai agents, cross app access, id-jag, identity assertion, oauth, pca, proof-carrying authority

## 简介

ID-JAG / OAuth Cross-App-Access bridge for PCA: verify an identity-assertion authorization grant (sub=human, act=agent, scoped, single-audience) and map it to a PCA principal/capability; RFC 8693/7523 token-exchange.
