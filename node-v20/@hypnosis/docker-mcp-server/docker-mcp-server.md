# @hypnosis/docker-mcp-server

> 标签: ai, claude, cursor, docker, docker-compose, mcp, model-context-protocol

## 简介

Docker MCP server for AI agents — containers, compose stacks, logs, databases and backups, on this machine or on a remote host over SSH, with destructive operations blocked. Works with Claude Code, Codex, Cursor and any MCP client.
