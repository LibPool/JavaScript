# @apislash/storage-native

> 标签: apislash, encrypted, indexeddb, local-first, offline, storage, sync, typescript

## 简介

React Native storage adapter (AsyncStorage / Expo SecureStore KV + Expo SQLite structured store) for the Apislash storage core. Published by Apislash.
