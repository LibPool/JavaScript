# @timerecord/agent

> 标签: JavaScript

## 简介

timerecord-agent — a Claude Code SessionEnd hook that parses session logs, dedups + prices token usage, and uploads it to TimeRecord's AI-costs API. Measuring costs zero tokens; nothing feeds back into your context.
