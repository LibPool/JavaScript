# @arhen/pi-core-todo

> 标签: pi, pi-coding-agent, pi-extension, pi-package, todo

## 简介

Flat or arbitrarily nested Pi todos with explicit statuses, direct-child progress, dependencies, a compact widget, and a scrollable tree browser.
