# @riskaverse/toolgate

> 标签: agent-safety, ai-agents, ai-gateway, claude-code, claude-code-hooks, firewall, guardrails, hooks, jev, llm-security, mcp, mcp-proxy, model-context-protocol, pretooluse, system-one, tool-calling, typesafe

## 简介

Open auto mode for AI agents: a calibrated tool-call firewall powered by TypeSafe's Jev decision model (direct API or Vercel AI Gateway). Ships as a Claude Code PreToolUse hook.
