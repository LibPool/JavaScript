# @maxentr/sentry-selfhosted-mcp

> 标签: debugging, mcp, model-context-protocol, self-hosted, sentry

## 简介

Model Context Protocol server for self-hosted Sentry instances with debugging tools, filtering, raw API access, and stack frame extraction.
