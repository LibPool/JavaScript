# @rifrocket/fdt-plugin-pages

> 标签: JavaScript

## 简介

Multi-page document orchestration (add/duplicate/delete/reorder pages, front/back pairing) for the FabricJS Design Tool v2, built on @rifrocket/fabricjs-design-tool's CanvasEngine.
