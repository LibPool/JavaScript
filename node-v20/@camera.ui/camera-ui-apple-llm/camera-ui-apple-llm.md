# @camera.ui/camera-ui-apple-llm

> 标签: apple, assistant, camera-ui-plugin, foundation-models, llm, on-device

## 简介

Apple's on-device foundation model as an assistant model for camera.ui, with tools and pictures. Runs on the Mac itself, no key and no cloud.
