> 标签: airline, booking, cinema, kerusi, react, seat-map, seat-picker, seat-selection, seatmap, svg, ticketing, venue

## 简介

A React seat-map component that renders Kerusi Seat Map & Availability Format documents as interactive, accessible inline SVG.
