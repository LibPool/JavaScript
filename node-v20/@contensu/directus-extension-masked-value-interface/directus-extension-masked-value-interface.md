# @contensu/directus-extension-masked-value-interface

> 标签: directus, directus-custom-interface, directus-extension, mask, masked, redact, sensitive

## 简介

A Directus interface that masks a stored value in the form (e.g. *****786), with a configurable number of visible characters, mask character, and an optional reveal toggle.
