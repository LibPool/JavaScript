# @hxmc/theme

> 标签: JavaScript

## 简介

A theme for @hxmc/ui's unstyled widgets, based on shadcn/ui: its tokens, slots, variants and Tailwind class lists, turned into rules at compile time (Tw: Tailwind v4 classes as hxmc.ui rules)
