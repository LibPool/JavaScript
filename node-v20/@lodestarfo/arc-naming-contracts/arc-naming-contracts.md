# @lodestarfo/arc-naming-contracts

> 标签: arc, did, ens, erc4337, naming, paymaster

## 简介

Interfaces, ABIs, TypeScript types, and deployed addresses for the .arc naming service on Arc (testnet). Resolve names, register names, and sponsor gas via the paymaster — without vendoring the contracts.
