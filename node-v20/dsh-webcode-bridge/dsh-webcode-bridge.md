# dsh-webcode-bridge

> 标签: deepseek-harness, deepseek-web, dsh-bundle, dsh-plugin, llm-adapter, model-provider, web-ai, webcode

## 简介

Use your logged-in web AI (DeepSeek, GLM, Kimi, Qwen, Doubao...) as model providers in DeepSeek Harness. Web models emit tool calls, DSH runs them under its native permission system, and results return to the same web session. No API keys.
