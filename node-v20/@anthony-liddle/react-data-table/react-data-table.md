# @anthony-liddle/react-data-table

> 标签: data-table, datagrid, pagination, react, selection, shadcn, sorting, table, tailwind

## 简介

A data-dense React table: sorting, grouped columns, row and drag selection, column management, pagination, and URL + localStorage persistence. Styled with Tailwind CSS over shadcn-style theme tokens.
