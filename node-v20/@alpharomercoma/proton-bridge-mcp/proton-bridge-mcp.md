# @alpharomercoma/proton-bridge-mcp

> 标签: claude, email, imap, mcp, model-context-protocol, proton-bridge, proton-mail

## 简介

MCP server for reading, searching, organizing, and sending Proton Mail via Proton Mail Bridge (IMAP/SMTP), with certificate pinning instead of disabled TLS verification.
