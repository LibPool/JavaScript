# @naculus/connect-native

> 标签: expo, mobile-wallet-adapter, react-native, solana-mobile, wallet, walletconnect, web3

## 简介

Naculus Connect for React Native — AsyncStorage sessions, WalletConnect deep links, Solana Mobile Wallet Adapter, Coinbase Mobile Wallet Protocol and a Keystore-sealed embedded wallet, wired into the React hooks
