# @akebifiky/remark-simple-plantuml

> 标签: plantuml, remark

## 简介

`remark-simple-plantuml` is a simple plugin for [remarkjs](https://github.com/remarkjs/remark) that converts PlantUML code written in Markdown to `img` tags.
