# @pubinfo-pr/module-auth

> 标签: JavaScript

## 简介

Pubinfo 的认证模块，核心是“认证客户端 + 路由模块”两层能力：一层负责统一登录、回调认证、二维码渲染；一层负责把 `/auth/:type` 回调页和登录跳转逻辑挂到应用里。
