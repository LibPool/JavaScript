# @nxisai/agent-harness

> 标签: a2ui, agent, gemma, llm, mcp, nxis, on-device, schema.org, webmcp

## 简介

An on-device agent for the browser: a tool-calling harness over WebMCP and remote MCP, plus a drop-in chat UI. Decides whether to run a tool, ask for what's missing, or confirm before writing.
