# @moy-apps/agent-office

> 标签: agent-office-protocol, claude-code, codex, cursor, hooks, jira

## 简介

Adapter for Agent Office for Jira: hooks for Claude Code, Codex, Cursor, Rovo CLI and OpenClaw that report agent activity over the Agent Office Protocol (AOP v0).
