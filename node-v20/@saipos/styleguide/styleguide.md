# @saipos/styleguide

> 标签: JavaScript

## 简介

Este é o pacote de styleguide compartilhado entre as aplicações do Single SPA na Saipos. As aplicações micro frontend já possuem o pacote instalado via NPM e utilizam a versão mais recente que está publicada no S3 (Através do Importmap)
