# @opensyber/mcp-watch

> 标签: ai-agents, ai-security, drift-detection, fingerprint, mcp, model-context-protocol, opensyber, prompt-injection, rug-pull, security

## 简介

MCP rug-pull detection. Records SHA-256 fingerprints per tool, per server, across days — catches what session-scoped scanners miss.
