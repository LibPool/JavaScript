# @hyper.authio/client

> 标签: authio, authorization, jwt, oauth, oidc

## 简介

Authio client for Node.js and edge runtimes: discovery, interactive sign-in with ID tokens and logout, every grant, JWE, introspection, client-credentials cache, Admin API credentials, roles and permissions, webhooks.
