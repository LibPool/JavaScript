> 标签: agent, ai, ai-agent, coding-agent, debugging, e2e, e2e-testing, flaky-tests, json, json-reporter, llm, observability, opentelemetry, playwright, playwright-reporter, reporter, test-reporter, testing, trace-correlation, traceparent

## 简介

Playwright reporter that outputs structured JSON for LLM agents. Minimal console output, flat schema, easy to filter to failures.
