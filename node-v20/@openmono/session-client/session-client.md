# @openmono/session-client

> 标签: agent, client, event-stream, feno, openmono, projection, resume-cursor, session

## 简介

Transport-agnostic conversation client runtime for agent sessions — give it a transport and it maintains live thread state through the @openmono/session-stream kernel reducer: snapshot-then-live subscribe with (epoch, seq) resume cursors, binary full/resu
