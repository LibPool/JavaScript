# @openmono/helm-client

> 标签: agent, client, feno, helm, openmono, projection, session

## 简介

Helm client runtime — drive a HelmHost (local in-process, remote over WS, or federated) into fully reduced thread state via @openmono/session-client. The thin, render-side half of the Helm protocol; the WS transport carries no node-only deps so it runs in
