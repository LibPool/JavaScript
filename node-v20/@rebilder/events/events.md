# @rebilder/events

> 标签: agent-traffic, analytics, edge, events, schema

## 简介

The observation-layer contract: single versioned event schema (v0), structural runtime validation, and the edge emission client (HTTP + console sinks). Zero runtime dependencies, edge-safe.
