# @cmpxchg16b/serverless-express

> 标签: api gateway, aws, express, hapi, http, koa, lambda, node.js, sails, serverless

## 简介

This library enables you to utilize AWS Lambda and Amazon API Gateway to respond to web and API requests using your existing Node.js application framework. This version includes Azure Function support
