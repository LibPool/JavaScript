# @dreki-gg/pi-plan-mode

> 标签: pi-package

## 简介

Two-phase planning workflow for pi — plan with claude-opus-4-6:medium, execute with gpt-5.5:low, with file-based plan-ledger handoff (default .taskman/plans/, configurable via .taskmanrc)
