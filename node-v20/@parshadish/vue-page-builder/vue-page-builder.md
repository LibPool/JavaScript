# @parshadish/vue-page-builder

> 标签: JavaScript

## 简介

A Vue 3 visual page builder that can run as a standalone editor or as a controlled component inside another Vue app. It accepts page data as JSON and can emit the updated document, JSON, HTML, and CSS so the parent app can save the result to a backend.
