# nah-ai

> 标签: agent, ai-sdk, cli, coding-agent, opencode, pi, tui

## 简介

nah — not another harness, the CLI. A fast, minimal coding-agent terminal (Pi-style): streaming agent loop, capped tools, JSONL sessions, slash commands.
