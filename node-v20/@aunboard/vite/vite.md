# @aunboard/vite

> 标签: aunboard, data-attribute, jsx, onboarding, product-tour, vite, vite-plugin

## 简介

Vite plugin that stamps stable data-aun ids onto exactly the JSX elements your committed aunboard tours reference, so tours survive UI refactors.
