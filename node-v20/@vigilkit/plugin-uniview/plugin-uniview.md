# @vigilkit/plugin-uniview

> 标签: lightapi, player, rtsp, surveillance, uniview, unv, video, webcodecs

## 简介

Uniview (UNV) LightAPI vendor plugin for vigilkit: digest auth, device info, channel enumeration, PTZ control, and RTSP / MJPEG / snapshot stream URL building
