# @wizpro/auth-sdk

> 标签: 2fa, authentication, mfa, nextjs, push-auth, totp, wizauth, wizpro

## 简介

SDK for integrating WizAuth 2FA into WizPro applications. Includes server-side API client, Next.js route handlers, and React hooks.
