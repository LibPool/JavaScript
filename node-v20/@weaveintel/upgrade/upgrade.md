# @weaveintel/upgrade

> 标签: JavaScript

## 简介

Self-upgrade engine primitives — signed release manifest discovery + Ed25519 verification, priority banding for a reconcile review queue, pre-upgrade database snapshots, and a structured id-keyed three-way merge.
