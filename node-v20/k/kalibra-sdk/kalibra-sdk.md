# kalibra-sdk

> 标签: agents, ai, evals, kalibra, llm, observability, rag, testing, tracing

## 简介

Kalibra SDK: trace what happens inside your AI app, link it to Kalibra eval runs, record and replay tools, and run evals as code. Zero dependencies; switch it off for production.
