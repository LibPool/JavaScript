# kyc-encrypt

> 标签: aes-gcm, crypto, encryption, kyc, npm-package, rsa, shamir

## 简介

Secure hybrid encryption library for KYC data using AES-256-GCM, RSA-2048-OAEP, and multi-authority key flows.
