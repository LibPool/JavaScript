# kissmyhash

> 标签: cryptography, hash

## 简介

Hashes as long and strong as you need. It defaults to 1024 bytes, but you can set higher or lower. It based on PRNG and xor operations, and its code is so short and clean with nothing obscure that it is easy to undersand how it works.
