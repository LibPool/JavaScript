# king-lcode

> 标签: JavaScript

## 简介

``` 组件上传完成 查看功能 当上传文件类型不为图片类型 在业务口调用处 声明 provide 方法 固定方法名称为：openFiles：this.xxx     - xxx 为业务口 method 自定义方法名     - 通过自定义组件调用业务口方法后 业务自行开发不同展示文件功能 ```
