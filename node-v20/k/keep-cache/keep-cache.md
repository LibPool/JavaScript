# keep-cache

> 标签: browser, bun, cache, caching, deno, eviction, in-memory, isomorphic, lfu, lfu-cache, lru, lru-cache, max-size, memoization, memoize, tree-shakeable, ttl, typescript, zero-dependencies

## 简介

Tiny, dependency-free typed cache with pluggable eviction policy (LRU / LFU), TTL, size limits and eviction callbacks. Works in browsers, Node, Deno, Bun and Web Workers.
