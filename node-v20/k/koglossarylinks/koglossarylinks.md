# koglossarylinks

> 标签: CSS, JSON, ecosystem:jquery, glossary, jquery, jquery-plugin, kickoff

## 简介

KOglossaryLinks is a jQuery plugin that shows glossary-style tooltips when hovered (or tapped on touchscreen devices)
