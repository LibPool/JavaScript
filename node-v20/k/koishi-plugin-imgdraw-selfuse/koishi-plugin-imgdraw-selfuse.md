# koishi-plugin-imgdraw-selfuse

> 标签: chatbot, koishi, plugin

## 简介

修改自ai-image的画图插件,支持openai兼容api,增加base64转换自由开启，增加图文合并消息图生图，增加预置提示词，增加比例匹配
