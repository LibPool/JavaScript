# keypal

> 标签: api-key-management, api-keys, authentication, authorization, drizzle, hashing, keypal, permissions, prisma, redis, scopes, security, storage, typescript

## 简介

A TypeScript library for secure API key management with cryptographic hashing, expiration, scopes, and pluggable storage
