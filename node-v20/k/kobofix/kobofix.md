# kobofix

> 标签: adobe-digital-editions, css, ebook, epub, epubcheck, kepub, kobo, rmsdk

## 简介

Make EPUBs work on Kobo e-readers (Adobe RMSDK): detect and fix the modern CSS that breaks them. Node CLI + library + browser engine.
