# kompensa

> 标签: backoff, bullmq, compensation, crash-recovery, distributed-transactions, durable, exponential-backoff, fault-tolerant, idempotency, idempotent, microservices, nodejs, offline-first, orchestration, orchestrator, postgres, process-manager, react-native, redis, reliability, resilience, resilient, retry, saga, saga-pattern, state-machine, temporal-alternative, typescript, webhooks, workflow, workflow-engine

## 简介

Saga pattern workflow library for Node.js, browser and React Native. Typed builder with idempotency keys, retry with exponential backoff, compensation on failure, distributed locking (Postgres/Redis) and crash recovery. Zero runtime dependencies.
