# koishi-plugin-minecraft-chatbridge-to-chat

> 标签: MCDR, chatbot, chatbridge, koishi, minecraft, plugin

## 简介

此Koishi插件对接了MCDR的Chatbridge插件，在原版Chatbridge的gocq配置不变的情况下，仅需修改ws地址，即可完美对接Chatbridge实现消息互通
