# knx-dpts-baos

> 标签: baos, datapoints, dpt, knx

## 简介

Simple library to work with KNX datapoints in JS. Supports DPT1-18, as KNX BAOS 830 ETS database. Thanks to npm 'knx-datapoints' package and Rafelder as it is based on his library but much simplified.
