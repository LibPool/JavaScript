# kruko-whisper-rn

> 标签: android, ios, kruko, native module, openai, pcm16, react-native, silence gating, speech recognition, whisper, whisper.cpp

## 简介

Hardened fork of whisper.rn for React Native. Adds a signed 16-bit PCM input guard and an opt-in silence gate.
