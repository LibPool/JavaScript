# kipphi-canvas-editor

> 标签: JavaScript

## 简介

此项目是[奇谱发生器](https://github.com/TeamZincs/kipphi-apparatus)的音符列表及事件序列编辑器。由于这两个编辑器使用HTML5 Canvas 2D绘制，使用框架并不能带来明显的开发便利，故与播放器一样被提出主项目，意图是使得此编辑器能够适配其他任何框架，而不仅仅是奇谱发生器所用的Svelte。
