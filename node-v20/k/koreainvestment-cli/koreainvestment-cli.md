# koreainvestment-cli

> 标签: agent, claude-code, cli, kis, koreainvestment, opencode, stock, trading

## 简介

한국투자증권 open-trading-api 를 위한 에이전트 친화 CLI. Agent-friendly command-line interface for the Korea Investment & Securities (KIS) open trading API.
