# kanban-skill-ui

> 标签: agent, board, claude, claude-code, kanban, markdown, ui

## 简介

Local kanban board UI — run it on your machine to see the board and spawn agents (claude -p) to do the kanban work. Files in docs/kanban/ stay the source of truth.
