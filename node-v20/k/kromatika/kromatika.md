# kromatika

> 标签: color palette, colors, css variables, design tokens, oklch, tailwind, user interface

## 简介

An elegant color palette for user interfaces — 16 scales with contrast data, semantic light/dark tokens, and every format: CSS, SCSS, LESS, Stylus, YAML, JSON, JS, Tailwind, Design Tokens.
