# koishi-plugin-streetfighter6-rank

> 标签: buckler, chatbot, gaming, koishi, plugin, rank, sf6, street-fighter, streetfighter6

## 简介

一个用于查询《街头霸王6》玩家数据的 Koishi 插件，支持排位查询、胜率分析、战斗记录截图、玩家搜索和绑定ID功能
