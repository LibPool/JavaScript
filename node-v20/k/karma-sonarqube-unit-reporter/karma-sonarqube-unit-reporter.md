# karma-sonarqube-unit-reporter

> 标签: junit, karma-plugin, karma-reporter, sonar, sonar-generic-coverage, sonarqube

## 简介

A Karma plugin. Report results in SonarQube generic test execution (sonar-unit-tests) XML format.
