# karma-ember-native-launcher

> 标签: karma-launcher, karma-plugin

## 简介

Karma browser launcher for `nativescript test android`/`nativescript test ios`, used by Ember Native's own test suite. A patched fork of NativeScript's karma-nativescript-launcher (Apache-2.0) that reports its own launcher id back to karma on device regis
