# koishi-plugin-keyword-filtering

> 标签: chatbot, keyword, koishi, onebot, plugin, qq

## 简介

[关键词触发]自用：当触发关键词时，会撤回该消息，并将关键字替换为图标（自己设置），并发送撤回的消息。ps:如果无法显示配置请删除本插件重新添加！
