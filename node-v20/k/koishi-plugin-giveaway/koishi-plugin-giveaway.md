# koishi-plugin-giveaway

> 标签: chatbot, draw, giveaway, koishi, lottery, plugin, raffle, 抽奖

## 简介

A versatile giveaway plugin for Koishi: interactive giveaway creation, scheduled auto-draw, reminders, i18n and multi-timezone support.
