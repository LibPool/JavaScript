# kingchop

> 标签: CommonJS text tokenizer, Easy tokenizer, English text tokenizer, Flexible text tokenizer, Light text tokenizer, NLP tokenizer, Node.js tokenizer, Paragraph tokenizer, Sentence tokenizer, Stable tokenizer, Sub sentence tokenizer, Text tokenizer, Tokenizer

## 简介

A text tokenizing library that handles strings, by tokenizing them into arrays, depending on intended format, like sentences, sub sentences, paragraphs, words...
