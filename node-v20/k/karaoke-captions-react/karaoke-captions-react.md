# karaoke-captions-react

> 标签: captions, karaoke, literacy, react, same-language-subtitling, subtitles

## 简介

Word-by-word highlighted (karaoke) captions for React. Feed it a word-timed caption document and a currentTime, get Same Language Subtitling: the proven reading-practice technique, as a component.
