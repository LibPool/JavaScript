# koishi-plugin-chouxianghua

> 标签: koishi, plugin

## 简介

/*抽象话生成*/把中文输入转换为emoji抽象话。比如：💉💦太🤡🐘🌶！（真的太抽象啦！）。是个很单纯的字符转换插件而已
