# keyweaver

> 标签: cache-key, deduplication, key-generator, memoization, nested, object, query-key, serialize, stable-key, stringify, typescript, unique

## 简介

Fast, zero-dependency generator of stable string keys from nested data structures — object key order doesn't matter. Ideal for cache keys, memoization and deduplication.
