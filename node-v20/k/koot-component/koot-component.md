# koot-component

> 标签: JavaScript

## 简介

> koot-component 是koot的组件库，配套koot使用，目前包含常用的样式组件，可快速搭建一套供后台使用的前端样式和展示数据图表的组件（基于[ECharts](https://github.com/apache/incubator-echarts)进行二次开发）
