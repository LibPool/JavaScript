# koishi-plugin-course-schedule

> 标签: chatbot, koishi, plugin

## 简介

📚📅 课程表插件，支持 WakeUp/星链/拾光 等课程表，ICS/JSON 等多格式导入，渲染为图片输出个人课表、群课表、周课表和排行榜 🎓🖼️✨
