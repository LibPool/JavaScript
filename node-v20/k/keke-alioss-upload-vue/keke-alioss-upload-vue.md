# keke-alioss-upload-vue

> 标签: ali-oss, alioss, aliyun, component, file, keke, upload, vue

## 简介

一个基于 Vue 3 和阿里云 OSS 的高性能文件上传组件，支持断点续传、分片上传、多文件上传等功能。
