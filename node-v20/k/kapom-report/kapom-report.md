# kapom-report

> 标签: autotable, backend, browser, declarative, easy-report, grouped-table, invoice, jspdf, jspdf-autotable, kapom-report, nodejs, pdf, quick-report, report, report-builder, report-generator, server-side, serverless, subtotal, table, thai, typescript

## 简介

The easy way to build jsPDF + AutoTable reports — declarative, strictly-typed, with automatic grouping, subtotals, and multi-page layout, no manual cursor math. Thai-ready.
