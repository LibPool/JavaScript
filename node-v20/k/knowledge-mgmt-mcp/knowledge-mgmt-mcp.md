# knowledge-mgmt-mcp

> 标签: chromadb, claude, document-ingestion, document-processing, embeddings, knowledge-management, mcp, model-context-protocol, openai, pdf-parser, rag, semantic-search, transformers, vector-search

## 简介

Production-ready MCP server for document ingestion and knowledge management with vector search. Supports PDF, DOCX, TXT, MD, CSV, JSON, HTML with ChromaDB and multiple embedding providers.
