# koishi-plugin-qq-http-relay

> 标签: chatbot, koishi, plugin

## 简介

实现 QQ 群消息与外部服务之间的双向通信。插件通过 HTTP 协议将 QQ 群消息转发至外部服务的 Webhook 端点，并接收外部 HTTP POST 请求发送的回复，发送到对应的 QQ 群。
