# koa-body-clean

> 标签: body, formidable, gc, koa, koa-middleware, middleware, multer

## 简介

Koa middleware for auto cleanup files created to disk by koa-body, koa-better-body, koa-multer or any multipart middleware that populate ctx.*.files

- 官网：https://github.com/rferro/koa-body-clean
- 源码仓库：git+https://github.com/rferro/koa-body-clean.git
