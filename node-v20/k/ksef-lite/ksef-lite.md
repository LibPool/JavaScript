# ksef-lite

> 标签: e-faktura, e-invoice, fa3, invoice, javascript, krajowy-system-e-faktur, ksef, poland, typescript, xml

## 简介

Unofficial TypeScript/JavaScript client for Polish KSeF (Krajowy System e-Faktur) with FA(3) XML generation, submission helpers and QR support.
