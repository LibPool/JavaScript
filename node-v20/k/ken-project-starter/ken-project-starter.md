# ken-project-starter

> 标签: cli, firebase, monorepo, nextjs, shadcn, supabase, tailwind, turborepo

## 简介

A CLI tool to scaffold a Turborepo monorepo with a Next.js app, shadcn/ui, cursor rules, Supabase, Firebase, and Tailwind CSS.
