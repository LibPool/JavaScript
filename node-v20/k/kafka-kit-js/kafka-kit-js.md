# kafka-kit-js

> 标签: dead-letter-queue, dlq, idempotent, kafka, kafkajs, microservices, resilience, typescript

## 简介

High-level, resilient Kafka client for Node.js with connection pooling, idempotent publishing, and poison-pill DLQ isolation.
