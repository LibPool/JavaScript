# kxco-pq-vault

> 标签: aes-gcm, bech32m, cli, encryption, envelope-encryption, file-encryption, fips-203, harvest-now-decrypt-later, kxco, kyber, ml-kem, multi-recipient, nist, post-quantum, pqc, quantum-resistant

## 简介

Post-quantum file and envelope encryption with ML-KEM-768 (FIPS 203). Encrypt to one recipient or many; each opens it with their own key. bech32m recipient strings, AES-256-GCM payloads.
