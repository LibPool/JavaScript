# kjeks-scanner

> 标签: cookie-consent, cookie-scanner, gdpr, kjeks, playwright, privacy, tracker-scanner, wordpress

## 简介

Standalone Playwright discovery scanner for the Kjeks cookie-consent plugin. Runs separately from the WordPress runtime.
