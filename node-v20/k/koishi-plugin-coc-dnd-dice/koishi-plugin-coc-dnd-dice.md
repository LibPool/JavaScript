# koishi-plugin-coc-dnd-dice

> 标签: chatbot, koishi, plugin

## 简介

多功能跑团（TRPG）骰点插件，内置对《克苏鲁的呼唤》（CoC7）和《龙与地下城》（D&D5E）等多种规则的支持。
