# koishi-plugin-webhook-notify

> 标签: chatbot, koishi, napcat, notify, qinglong, qq, webhook

## 简介

Webhook 通知中转插件：接收青龙面板等第三方系统的 HTTP 通知，通过 QQ 机器人推送给指定用户或群
