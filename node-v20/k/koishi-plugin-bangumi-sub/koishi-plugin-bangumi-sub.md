# koishi-plugin-bangumi-sub

> 标签: anime, bangumi, koishi, plugin, subscribe, 番剧, 订阅

## 简介

Bangumi新番订阅插件！支持查询当日或本周要放送的所有番剧以及到点推送功能。现支持Bangumi链接解析。
