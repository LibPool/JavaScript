# koishi-plugin-daigan-reminder

> 标签: chatbot, koishi, plugin, reminder, 代肝, 提醒

## 简介

Koishi 插件：自动记录并提醒每日代肝完成情况，支持可配置重置时间、私聊提醒与重复记录策略。
