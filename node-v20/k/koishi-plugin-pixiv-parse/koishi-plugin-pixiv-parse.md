# koishi-plugin-pixiv-parse

> 标签: koishi, parse, pixiv, plugin, subscription, 解析, 订阅

## 简介

提供 Pixiv 链接解析与订阅功能的插件，支持 原图/合并转发/PDF 多种发送方式。现已支持Chatluna工具调用。
