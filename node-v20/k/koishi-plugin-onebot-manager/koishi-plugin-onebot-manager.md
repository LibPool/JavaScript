# koishi-plugin-onebot-manager

> 标签: chatbot, group, koishi, manager, onebot, plugin, user

## 简介

群管插件，功能梭哈，支持禁言/踢出等全部管理可用功能，还支持进退群等事件通知（申请逻辑已拆分至onebot-verifier）
