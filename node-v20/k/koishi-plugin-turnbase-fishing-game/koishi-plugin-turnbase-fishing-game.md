# koishi-plugin-turnbase-fishing-game

> 标签: chatbot, economy, fishing, game, koishi, plugin, rpg, turn-based

## 简介

一款为Koishi打造的深度回合制钓鱼RPG插件。拥有750+种可收集生物、拟真咬钩机制、可实时调节的战斗公式、动态世界事件、完整技能树与等级系统、波动的市场经济以及策略性装备管理。这不仅是钓鱼，更是一场冒险。(ai爆改自fishing-game)
