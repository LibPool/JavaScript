# koishi-plugin-qq-chat

> 标签: chat, console, koishi-plugin, mobile, pwa, qq, qqbot, rest-api, sandbox, unread, webui

## 简介

夺舍 QQ 官方机器人：在 Koishi 控制台直接接管官方 QQ 机器人的群聊，内置沙盒窗口、指令桥接、媒体收发、未读持久化、手机 App（PWA + 原生 Android，支持离线浏览与通知快捷回复）与开放 API、群管理（支持 auth 插件登录保护）
