# knockback-inspector

> 标签: backbone, backbonejs, knockback, knockback-inspector, knockbackjs, knockbackjs-inspector, knockout, knockoutjs

## 简介

Knockback-Inspector.js provides an inspector tree view library for Backbone.Models and Backbone.Collections using Knockback.js
