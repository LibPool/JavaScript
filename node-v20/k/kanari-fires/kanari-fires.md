# kanari-fires

> 标签: GOES, Meteosat, NASA FIRMS, fire, kanari, mcp, open data, satellite, wildfire

## 简介

Tiny, dependency-free client for the kanari wildfire API: live fire clusters, verified witness signals, open-data archive and MCP endpoint.
