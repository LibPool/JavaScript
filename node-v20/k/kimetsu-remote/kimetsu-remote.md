# kimetsu-remote

> 标签: brain, kimetsu, mcp, remote, server

## 简介

Kimetsu Remote (beta) — server-hosted Kimetsu brain over HTTP MCP. Installs the prebuilt native server binary for your platform. Separate from the `kimetsu-ai` CLI.
