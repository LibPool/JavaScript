# knx-toolkit

> 标签: ets, home-automation, knx, knx-secure, knxip, knxnet, tunneling, typescript

## 简介

Pure-TypeScript KNX/IP client library — UDP tunnelling, KNX IP Secure over TCP, gateway discovery, DPT codecs, and ETS .knxproj parsing.
