# kern-sandbox

> 标签: agent, code-execution, code-interpreter, container, e2b, isolation, jupyter, kern, llm, sandbox, seccomp

## 简介

Your model writes the code. This runs it where it can't touch your machine: a rootless Linux container, no daemon, no VM, no cloud, no account. A kernel boundary, not a microVM: for deliberately hostile code, use one.
