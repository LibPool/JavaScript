# kussetsu

> 标签: glass, glassmorphism, gpu, r3f, react, react-reconciler, react-three-fiber, renderer, shaders, ui, webgpu, webgpu-ui, wgsl

## 简介

R3F for 2D UI — React-authored interface painted entirely on the GPU (WebGPU/WGSL), with the DOM as an invisible accessibility + input layer.
