# kenteiscript

> 标签: decision-model, dsl, exam, gui-chat-protocol, kenteiscript, llm, mcp, quiz, test

## 简介

KenteiScript: a small JSON language for quizzes and tests, written by an LLM, with answers in the taker's own words graded by a decision model (TypeSafe JEV). Includes MulmoKentei, a sample runtime on Cloudflare Workers + D1
