# koishi-plugin-bili-fans-monitor

> 标签: chatbot, koishi, plugin

## 简介

使用 B 站官方接口获取粉丝数，支持配置多个 UID 和目标群，并且可以在粉丝数达到整数大关（如 10 万、11 万）或自定义目标时发送通知
