# koishi-plugin-chatluna-character-buffer-backup

> 标签: chatbot, chatluna, chatluna-character, context, koishi, memory, plugin

## 简介

Persist chatluna-character's in-memory message buffer to the database and restore it on restart / config-save, so the bot keeps recent context across reloads.
