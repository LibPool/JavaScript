# klamdo-mcp

> 标签: agentic, ai-content, content-generation, creator-tools, image-generation, klamdo, mcp, model-context-protocol, video-generation

## 简介

MCP server for Klamdo — AI content generation plus agentic package orchestration for coaches and creator-founders. Generate media, create packages, and hand structured deliverables to downstream AI agents.
