# koishi-plugin-dstonebot

> 标签: chatbot, koishi, plugin

## 简介

饥荒（Don't Starve Together）游戏与QQ群互通插件。实现游戏信息实时同步到QQ群，支持服务器状态查询、玩家信息获取等扩展功能。增强游戏社区互动体验。
