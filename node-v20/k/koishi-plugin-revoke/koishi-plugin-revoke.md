# koishi-plugin-revoke

> 标签: chatbot, koishi, plugin

## 简介

灵感来自官方插件。高阶撤回消息，可选择撤回bot、其他人、所有人，或从某条消息起始的任意条消息，非常灵活。还有设精和取精的额外功能，快来试试吧
