# komode

> 标签: agent, agents, ai, ai-sdk, code-mode, codemode, llm, mcp, openai-agents, quickjs, sandbox, skills, tools, typescript

## 简介

Code-mode agent runtime for TypeScript: the model writes code against your tools, run in an in-process QuickJS sandbox. Skills, MCP, and drop-in tools for the Vercel AI SDK and OpenAI Agents SDK.
