# kin-prototype

> 标签: authorization, capability, fine-grained, framework, kin, reactive, ui

## 简介

Kin — a minimal reactive UI framework built around a Home/Node/Relationship mental model. Fine-grained reactivity, capability-based authorization, and a platform-independent view layer.
