# kusanaji-analyzer

> 标签: adapter, japanese, kusamoji, kusanaji, morphological-analyzer, tokenizer

## 简介

Kusamoji-based morphological analyzer adapter for kusanaji — bridges kusamoji tokenizer into kusanaji's analyzer interface
