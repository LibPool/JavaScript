# kt-map-sdk-geoanalysis

> 标签: map anaylsis

## 简介

kt-map-sdk-geoanalysis는 분석 도구를 제공하는 플러그인으로, `GeoJSON`, `ktGms.Geometry`, `Shape 파일` 입력을 지원합니다. <br/> 또한, 각 함수들은 비동기(Promise를 반환) 버전과 Remote 버전(url 입력을 통한 함수 파라미터 전달)을 제공합니다. <br/> 비동기 함수와 Remote 함수는 `"async" + "함수명"`, `"remote + "함수명"`의 형식을 가집니다.
