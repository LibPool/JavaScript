# kapsula-client

> 标签: ai-generated, alarm, android, capacitor, html, ios, kapsula, mobile, notification, sandbox, single-file, webview

## 简介

Types and reference implementation of the window.kapsula bridge used by Kapsula (kapsula.app) — run a single HTML file as an Android/iOS app with exact alarms, storage, sound and haptics.
