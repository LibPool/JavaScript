# koishi-plugin-live-monitor

> 标签: koishi, live, monitor, plugin

## 简介

多平台直播开播/下播检测与推送插件，支持抖音、B站、YouTube、Twitch 等主流平台，需配合 Live-Monitor 后端服务使用。
