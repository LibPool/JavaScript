# keepreceipts

> 标签: agents, ai, ci, claude-code, codex, llm, proof-of-work, receipts, testing, verification

## 简介

🧾 Receipts for your coding agents. Your agent says done — make it prove it. Runs your checks outside the agent, cross-examines Claude Code transcripts, and prints a signed, tamper-evident receipt.
