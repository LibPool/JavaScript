# klanex-mcp

> 标签: agents, ai-agents, idempotency, klanex, mcp, mcp-server, modelcontextprotocol, reliability, retries, tool-calling, webhooks

## 简介

MCP server for klanex — reliable asynchronous execution for agent tool calls (schema gating, retries, circuit breakers, audit trail). Thin stdio proxy to the hosted klanex MCP endpoint.
