# kiiii

> 标签: api, backend, devalue, full-stack, functions, h3, remote-procedure-call, rpc, server-actions, server-functions, type-safe, typescript, vite, vite-plugin

## 简介

Server actions for Vite: write functions in any file and call them directly from the client - type-safe (types from original signatures), devalue serialization, dev/prod consistent
