# keel-sdk

> 标签: ai, ai-gateway, ai-governance, ai-proxy, anthropic, audit-trail, budget-controls, compliance, cost-control, drop-in-replacement, google-gemini, keel, llm, meta-llama, openai, permits, policy-enforcement, xai-grok

## 简介

TypeScript SDK and drop-in provider wrappers for Keel AI governance. One-line provider imports route calls through Keel's managed proxy for policy enforcement, budget controls, audit trails, and usage recording.
