# kiro-agent-swarm

> 标签: agent, agent-swarm, ai, coding-agent, cost-optimization, kiro, kiro-cli, llm-router, model-routing, multi-agent, orchestrator, parallel, swarm

## 简介

Self-organizing multi-agent swarm for Kiro CLI. Adaptive model routing across the real 19-model catalog, evidence-based escalation, and a learning loop that gets cheaper over time. One install, zero config.
