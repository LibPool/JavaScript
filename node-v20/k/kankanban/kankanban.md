# kankanban

> 标签: agents, ai, automation, claude, claude-code, cli, git-worktree, kanban, mcp, model-context-protocol, orchestration, subagents

## 简介

A live Kanban board that orchestrates Claude Code — plans features into cards and runs builder/reviewer subagents in isolated git worktrees.
