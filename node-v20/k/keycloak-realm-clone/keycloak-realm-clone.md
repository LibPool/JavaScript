# keycloak-realm-clone

> 标签: clone, export, iam, identity, import, keycloak, migration, oidc, realm, sso

## 简介

Clone a Keycloak realm export for re-import on the same instance: rewrites all UUIDs, renames the realm, and clears masked secrets to avoid duplicate key constraint errors.
