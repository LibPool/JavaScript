# kucun-cli

> 标签: JavaScript

## 简介

+ 出货表名固定：`出库表（发货自配送返修）` + 尺码固定，只能是那么几种，如有添加，需改代码 + 表头的颜色、尺码、sku、asin、入库总数、出库总数、仓库剩余的名称必须一样，不能改动，顺序可以不一样，表格两边可以添加用于备注的列，中间不能
