# koishi-plugin-apexrankwatch

> 标签: apex, apex-legends, chatbot, koishi, plugin, rank, tracker

## 简介

支持查询 Apex 玩家段位、地图轮换、全天地图、赛季时间，并持续监控玩家段位变化通知的 Koishi 插件
