# koishi-plugin-maibot

> 标签: koishi, maibot, maimai, maimai-dx, plugin, 舞萌

## 简介

舞萌DX游戏高级操作插件 for Koishi - 支持用户绑定、B50更新、账号状态提醒、1.5倍票获取等功能
