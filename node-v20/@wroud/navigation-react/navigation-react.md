# @wroud/navigation-react

> 标签: browser-navigation, esm, history-management, navigation, path-matching, pattern-matching, react, react router, route-parameters, router, routing, single-page-application, spa, typescript, url-management, url-matching

## 简介

React 19 bindings for @wroud/navigation that run every navigation as a React transition, with transition-aware links, pending state, and scroll restoration deferred until the routed content commits
