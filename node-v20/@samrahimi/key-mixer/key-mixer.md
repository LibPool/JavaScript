# @samrahimi/key-mixer

> 标签: ai orchestration, api key management, api keys, api management, dotenv replacement, env, environment variables, free trial keys, gemini api key, key, key rotator, key server, keystore, load balancing, management, openai api key, resource consolidation, round-robin

## 简介

A Node.js module for managing and distributing API keys and environment variables from a JSON keystore. Upgrade from .env with no code changes, key-mixer automatically syncs to process.env
