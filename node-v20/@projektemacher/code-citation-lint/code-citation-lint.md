# @projektemacher/code-citation-lint

> 标签: cff, citation, citation-file-format, codemeta, json-schema, lint, metadata, research-software, validator

## 简介

Lint and validate CodeMeta (codemeta.json) and Citation File Format (CITATION.cff) metadata files. All released schema versions supported, schemas bundled for offline and browser use.
