# @rebink/patchwire

> 标签: ai, anthropic, claude, claude-code, cli, dart, developer-tools, diff, flutter, mac-mini, patch, remote, rsync

## 简介

Local-first dev tool: push your project to a remote Mac Mini, run Claude Code there, and pull back a reviewable unified diff.
