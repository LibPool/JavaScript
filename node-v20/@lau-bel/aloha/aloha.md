# @lau-bel/aloha

> 标签: JavaScript

## 简介

The designing of this tool was an exercise for Becode.org. The goal was to design a CLI-tool using de [pwned API](https://haveibeenpwned.com/API/v2#BreachesForAccount) and style it with our own taste. I used other packages such as : figlet, ora, chalk-rai
