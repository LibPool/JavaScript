# @ouedyan/survey-pdf

> 标签: client-side, data-collection, editable-pdf, export-form, fillable-pdf, form, interactive-pdf-form, javascript, jsPDF, json-form, json-schema, pdf, pdf-export, pdf-generator, print-form, survey, survey-export, survey-library, surveyjs, typescript

## 简介

A UI component that uses SurveyJS form JSON schemas to render forms as PDF documents. It populates PDF fields with data collected using SurveyJS Form Library and lets you export your SurveyJS forms as editable or pre-filled PDFs.
