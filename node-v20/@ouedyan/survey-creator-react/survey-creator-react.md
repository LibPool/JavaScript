# @ouedyan/survey-creator-react

> 标签: client-side, data-collection, drag-and-drop-form-builder, dynamic-form-builder, form, form-builder, form-library, form-management, frontend, javascript, json, json-schema, questionnaire, react, react-component, react-schema-form, survey, survey-builder, survey-creator, survey-library, surveyjs, typescript, ui-component

## 简介

A white-label drag-and-drop form builder for React that lets you design complex, interactive forms and surveys without writing code. It generates JSON schemas used by the SurveyJS Form Library to render dynamic forms in your React app.
