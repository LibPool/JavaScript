# @dsh-git/bitbucket

> 标签: bitbucket, deepseek, dsh, dsh-plugin, git, harness, pull-requests

## 简介

Bitbucket adapter for gitPlatform: Cloud REST 2.0 over Node fetch, normalized into the gitPlatform vocabulary (PRs, issues, pipelines). Releases map to tags; security alerts are unsupported.
