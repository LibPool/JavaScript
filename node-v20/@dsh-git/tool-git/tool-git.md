# @dsh-git/tool-git

> 标签: agent-tools, deepseek, dsh, dsh-plugin, git, harness, source-control

## 简介

Consumer: registers the grouped model-facing git tools (git_repo, git_inspect, git_pr, git_issues, git_release, git_security, git_ci) over the gitLocal and gitPlatform services, with approval and sandbox hardening.
