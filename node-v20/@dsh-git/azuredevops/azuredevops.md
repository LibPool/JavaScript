# @dsh-git/azuredevops

> 标签: azure, azure-devops, deepseek, dsh, dsh-plugin, git, harness, pipelines

## 简介

Azure DevOps adapter for gitPlatform: Git REST + Build + Work Item APIs over Node fetch, normalized into the gitPlatform vocabulary. Issues map to Work Items; releases and security alerts are unsupported.
