# @dsh-git/tool-git-memory

> 标签: agent-tools, deepseek, dsh, dsh-plugin, harness, memory

## 简介

Consumer: registers the git_memory tool (record / recall / forget) so the model can persist user-stated preferences, project conventions, and error resolutions, and consult them before git operations.
