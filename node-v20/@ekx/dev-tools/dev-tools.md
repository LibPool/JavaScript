# @ekx/dev-tools

> 标签: JavaScript

## 简介

- Hierarchy to navigate scene entities tree - Inspector to inspect and edit components data - Console for logs and commands - Scene window for gizmos, picking, navigation and to transform nodes - Game window for preview - Debug inspectors: Stats, Memory,
