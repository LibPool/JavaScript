# @millihq/pixel-express

> 标签: JavaScript

## 简介

This is the express middleware package of [Pixel for Next.js](https://github.com/milliHQ/pixel). It enables you to use the image optimizer of Next.js in a express app without starting the whole Next.js server. Useful when you want to provide the image opt
