# @zoblocks/elements

> 标签: accessibility, angular, clinical, custom-elements, fhir, healthcare, react, svelte, switch, toggle, vue, web-components

## 简介

ZoBlocks controls as dependency-free custom elements. A clinical switch that distinguishes off from never-asked, renders a write in flight without removing the control, and says which value the record holds when one fails. Works in React, Vue, Angular, Sv
