# @zoblocks/host-react

> 标签: ant-design, design-system, healthcare, material-ui, mui, react

## 简介

The host primitives an application is built from — Button, Input, Switch, Checkbox, Select, Tabs — resolved from whichever UI framework the host runs, so one demo source renders under Ant Design, Material UI, or neither.
