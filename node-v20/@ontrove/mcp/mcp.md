# @ontrove/mcp

> 标签: ai, claude, hosted-mcp, mcp, model-context-protocol, sdk, toolkit, trove, zod

## 简介

Thin standard library for authoring your own Trove toolkits (each a hosted MCP server) — defineMcpServer, the ctx capability object, and ToolError.
