# @bacnh85/pi-attachments

> 标签: attachments, clipboard, images, pi-extension, pi-package

## 简介

Image and file attachments for Pi — converts pasted/dropped file paths into real image attachments, collapses large text pastes into readable file references, inlines text files, and pastes clipboard file references.
