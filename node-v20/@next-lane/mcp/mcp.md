> 标签: agile, ai-agent, claude, issue-tracker, jira-alternative, kanban, mcp, model-context-protocol, modelcontextprotocol, next-lane, project-management, self-hosted

## 简介

Model Context Protocol (MCP) server for Next Lane — read & write a project's workflows/SDLC and core entities from external agents (Claude Desktop, Claude Code, etc.).
