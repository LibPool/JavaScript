# @agent-ui-kit/components

> 标签: accessibility, agent-ui, custom-elements, design-system, form-controls, light-dom, signals, ui-components, web-components

## 简介

The agent-ui component framework: a fine-grained signals kernel, 50+ accessible light-DOM `ui-*` custom elements (form controls, containers, overlays, data-viz), and a token-driven styling system.
