# @flowconsent/server-sdk

> 标签: cmp, consent, cookie, flowconsent, gdpr, rgpd, server-side, webhook

## 简介

Décision de consentement FlowConsent côté serveur : lit le cookie first-party (contrat v1), refuse par défaut, vérifie les signatures de webhook. Zéro dépendance, compatible edge.
