# @mailsenpai/smtp-senpai

> 标签: email, email-api, eu, gdpr, mailsenpai, smtp, smtp-relay, smtp-senpai, transactional-email, webhook

## 简介

Official Node.js SDK for SMTP Senpai, the EU SMTP relay and email API by MailSenpai: send email, read delivery events, manage suppressions, verify webhooks.
