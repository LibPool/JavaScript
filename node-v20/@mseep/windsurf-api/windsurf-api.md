# @mseep/windsurf-api

> 标签: anthropic, api-proxy, claude, codeium, gemini, gpt, llm-gateway, mcp-server, mseep, openai, reverse-engineering, windsurf, zero-dependency

## 简介

Windsurf to OpenAI + Anthropic compatible API proxy. Turns Windsurf's 107 AI models (Claude, GPT, Gemini, DeepSeek, Grok, Qwen, Kimi, GLM, SWE) into dual-protocol API endpoints. Zero npm deps.
