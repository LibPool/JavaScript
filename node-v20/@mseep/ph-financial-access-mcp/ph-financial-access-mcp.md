# @mseep/ph-financial-access-mcp

> 标签: banking, bsp, cloudflare-workers, financial-inclusion, mcp, mcp-server, mseep, philippines, psgc

## 简介

Philippine Financial Access MCP Server. 587 BSP-supervised institutions across 7 categories, 37,834 financial access points (bank offices, ATMs, NSSLAs), and coverage analytics with PSGC and 2024 Census population data. Built on Cloudflare Workers.
