# @mseep/codemode-mcp

> 标签: ai, code-mode, deno, llm, mcp, mcp-server, model-context-protocol, mseep, proxy, server, typescript

## 简介

A local implementation of the Code Mode workflow for Claude Code. LLMs write TypeScript/JavaScript code that calls a simple HTTP proxy to access your MCP servers.
