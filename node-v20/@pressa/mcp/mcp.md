# @pressa/mcp

> 标签: latex, latex-to-pdf, mcp, mcp-server, model-context-protocol, pdf, pdf-generation, pdflatex, pressa, texlive

## 简介

MCP server for Pressa: compile LaTeX to PDF without installing TeX Live. No API key needed to start.

- 官网：https://pressa.dev
- 源码仓库：git+https://github.com/pressa-dev/mcp.git
