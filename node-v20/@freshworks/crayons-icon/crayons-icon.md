> 标签: Freshworks, crayons-icon, crayons-icon-cli, icon lib, icons, svg JS Exports, svg optimizer, svgo, svgo yml config

## 简介

Freshworks `Crayons Icon` is an Icon library of SVGs. It also provides a NodeJS CLI to optimize SVGs.
