# @gyyxds/gyy-web-plugin

> 标签: element-plus, vite, vue3

## 简介

基于 Vue 3 + Vite + Element Plus 构建的可复用业务组件库，面向大数据平台的运营配置、权限管理与主题定制等场景，提供开箱即用的页面级组件与工具函数。
