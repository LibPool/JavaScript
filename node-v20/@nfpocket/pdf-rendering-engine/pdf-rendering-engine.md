# @nfpocket/pdf-rendering-engine

> 标签: invoice, live-preview, page-break, paginate, pagination, pdf, print, print-to-pdf, puppeteer, report, running-header, tailwind, vue, vue3, wysiwyg

## 简介

A measurement-driven, live-preview pagination engine for Vue 3 + Tailwind documents (invoices, offers, delivery notes). Framework-agnostic core + Vue binding. The same DOM drives the on-screen preview and the Puppeteer printToPDF output.
