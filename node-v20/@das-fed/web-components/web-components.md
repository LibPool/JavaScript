# @das-fed/web-components

> 标签: JavaScript

## 简介

das-web-components 是 DAS 前端体系的 Web 组件库，基于 Web Components 技术，支持 Vue、React、原生 JS 等多种框架集成，适用于企业级中后台系统的统一架构和快速开发。
