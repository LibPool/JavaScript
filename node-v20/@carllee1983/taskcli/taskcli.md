# @carllee1983/taskcli

> 标签: cli, draft, task, task-management, taskcli, todo, workflow

## 简介

在任何 repo 的 .taskcli/ 資料夾中，以「draft → 本地 HTML 審閱 → 正式 task」流程建立並追蹤 task 的 CLI 工具
