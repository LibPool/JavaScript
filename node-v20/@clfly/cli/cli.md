> 标签: agents, cli, cli-framework, file-based-routing, json-schema, mcp, mcp-server, openapi, standard-schema, typescript, zod

## 简介

File-based routing for CLIs — one commands/ tree becomes a CLI, shell completions, and an MCP server.
