# @osm-editor-kit/maplibre-editor-layer-index

> 标签: basemap, editor-layer-index, eli, imagery, maplibre, maplibre-gl, openstreetmap, osm, raster, react-map-gl

## 简介

Use the OSM Editor Layer Index as background/imagery layers in react-map-gl and maplibre-gl-js, with viewport filtering.
