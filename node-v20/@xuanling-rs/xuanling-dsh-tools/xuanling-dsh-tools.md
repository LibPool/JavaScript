# @xuanling-rs/xuanling-dsh-tools

> 标签: JavaScript

## 简介

DeepSeek Harness bundle: lazily mount XuanLing through a bundle-owned wrapper around the official MCP bridge. Additive variant: built-in tools stay enabled.
