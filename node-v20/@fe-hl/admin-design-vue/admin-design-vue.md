# @fe-hl/admin-design-vue

> 标签: component library, element, element-plus, ui, ui framework, vue

## 简介

本项目是基于Vite、vue3、typescript、element-plus组件二次封装的组件库，能够快速配置出表单、列表...，能够快速的构建管理页面，解放你的双手，摸鱼神器
