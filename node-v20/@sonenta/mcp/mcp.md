# @sonenta/mcp

> 标签: claude, i18n, mcp, sonenta, translations

## 简介

MCP server for Sonenta translation management. Pure TypeScript, no Python. Wires Claude Desktop and other MCP clients into your project's keys, translations, accessibility, and source-health tools.
