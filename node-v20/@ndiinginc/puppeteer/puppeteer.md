# @ndiinginc/puppeteer

> 标签: JavaScript

## 简介

Helper wrapper around [`puppeteer-core`](https://www.npmjs.com/package/puppeteer-core) that connects to (or auto-launches) a real, persistent Chrome instance via the DevTools remote-debugging protocol — instead of spinning up a fresh, disposable Chromium
