# @ndiinginc/fetch

> 标签: JavaScript

## 简介

Wrapper tipis di atas [`undici`](https://github.com/nodejs/undici) yang menambahkan beberapa kemudahan umum saat memanggil HTTP API: path params (`:id`), query string otomatis, dukungan cookie jar, hook `beforeRequest`/`beforeResponse`, serta dukungan pro
