# @dexy-ai/agent-sdk

> 标签: JavaScript

## 简介

Node.js/TypeScript client for Dexy’s agent orchestration layer. It wraps the `/api/search`, `/api/execute/:id`, and `/api/run` endpoints and adds simple streaming support.
