# @cloudgeek/md2docx

> 标签: JavaScript

## 简介

Markdown → DOCX converter (local, no server). Supports Mermaid/Graphviz/Vega/HTML/SVG rendering, math, and code highlighting.

## 官网

- 官网：https://github.com/xicilion/markdown-viewer-extension
- 源码仓库：git+https://github.com/xicilion/markdown-viewer-extension.git
- npm 页面：https://www.npmjs.com/package/@cloudgeek/md2docx
