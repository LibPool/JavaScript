# @constructive-io/errors

> 标签: constructive, error-codes, errors, graphql, i18n, postgresql

## 简介

Canonical Constructive error system: registry, codes, i18n messages, and cross-source (PostgreSQL/GraphQL/client) parsing. Zero runtime dependencies.
