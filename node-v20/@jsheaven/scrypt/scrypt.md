# @jsheaven/scrypt

> 标签: fast, kdf, password, scrypt, web-crypto

## 简介

Implements `scrypt` based on the original codebase of `scrypt-js`, but using the Web Crypto API, isomorphic, for Browsers, Node.js and shipped in all module formats
