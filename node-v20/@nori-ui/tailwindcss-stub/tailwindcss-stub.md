# @nori-ui/tailwindcss-stub

> 标签: JavaScript

## 简介

Crypto-free stub of tailwindcss@3.3.3 — satisfies NativeWind's peer dep inside Expo Snack (Snack's webpack rejects Node built-ins like crypto that real tailwindcss requires). NOT intended for general use outside Snack.
