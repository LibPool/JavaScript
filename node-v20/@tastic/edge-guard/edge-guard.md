# @tastic/edge-guard

> 标签: config-plugin, expo, gesture, home-indicator, ios, reachability, react-native, safe-area

## 简介

Opt-in guard against iOS's top- and bottom-edge system gestures (Notification Center / Control Center, home-indicator swipe / Reachability) firing over a full-screen or edge-anchored touch control zone — an Expo config plugin plus the hook that drives it
