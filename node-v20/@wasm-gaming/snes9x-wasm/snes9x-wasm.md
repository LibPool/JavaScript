# @wasm-gaming/snes9x-wasm

> 标签: JavaScript

## 简介

Snes9x (Super Nintendo / Super Famicom emulator) compiled to WebAssembly via Emscripten, with a JS SDK conforming to the wasm-gaming engine contract.
