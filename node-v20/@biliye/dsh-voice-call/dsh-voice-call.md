# @biliye/dsh-voice-call

> 标签: deepseek-harness, dsh, dsh-desktop, dsh-plugin, funasr, sensevoice, speech-recognition, text-to-speech, voice, voice-assistant, wake-word

## 简介

个人语音通话助手（DSH 桌面端与 Web GUI 通用，profile 换成 desktop/web 即可）：专属工作区/会话（自动创建、跨重启保持）、悬浮球通话面板、本地 SenseVoice 语音识别（复用 DSH 语音输入插件已下载的模型，免装模型）/ FunASR 流式/HTTP、云端 TTS 语音回复（MiniMax / MiMo-V2.5-TTS 含导演模式 / OpenAI 兼容）、唤醒词通话模式（可配置唤醒词/休眠时长，建议本地 ASR）、子代理任务分发与进度跟踪。持久化安装，重启后仍在
