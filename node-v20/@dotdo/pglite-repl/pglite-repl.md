# @dotdo/pglite-repl

> 标签: JavaScript

## 简介

A REPL, or terminal, for use in the browser with PGlite, allowing you to have an interactive session with your WASM Postgres in the page.

- 官网：https://pglite.dev
- 源码仓库：git+https://github.com/electric-sql/pglite.git
