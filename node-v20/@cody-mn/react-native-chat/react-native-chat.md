# @cody-mn/react-native-chat

> 标签: ai, chat, cody, expo, react-native, shopping-assistant, webview

## 简介

Cody AI chat for React Native and Expo apps: the store's web widget chat inside the app, with add to cart, product, checkout and sign-in handed to the app's own screens.
