# @m.huda/mcp-playground

> 标签: JavaScript

## 简介

Short description This repository contains an MCP (Model Context Protocol) server implementation packaged as the npm package `@m.huda/mcp-playground`. The server exposes a small set of tools over the MCP server API and runs over stdio when started.
