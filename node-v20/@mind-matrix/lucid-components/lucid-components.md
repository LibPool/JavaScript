# @mind-matrix/lucid-components

> 标签: a11y, accessibility, button, card, component-library, custom-elements, design-system, framework-agnostic, i18n, lucid, nav, shadow-dom, tabs, wcag, web-components

## 简介

Framework-agnostic UI components built on Web Components. Accessibility-first (WCAG 2.1 AA) and internationalization-ready. Works in React, Vue, Angular, Astro, Svelte, and vanilla HTML.
