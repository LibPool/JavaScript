# @qwqweeo123/dsh-open-in-app

> 标签: dsh, dsh-plugin, editor, ide, open-in-app, terminal, vscode

## 简介

The Session-header "Open In…" split button — open the workspace directory in an installed editor, Git GUI, terminal, or file manager. Self-contained copy of the built-in feature with the desktop-build fixes, so it travels as a plugin instead of an app.asa
