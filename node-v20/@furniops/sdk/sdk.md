# @furniops/sdk

> 标签: api, catalog, furniops, furniture, product-data, sdk, typescript, webhooks

## 简介

The FurniOps TypeScript SDK: typed resources from the public OpenAPI spec on a zero-dependency fetch core with retries, idempotency keys, typed errors, auto-pagination and webhook verification
