# @contai-evoluke/mcp-server

> 标签: brasil, calculator, claude, clt, fiscal, llm-tools, mcp, model-context-protocol, rescisao, salario-liquido

## 简介

MCP server para 90+ calculadoras fiscais brasileiras (CLT/PJ/impostos/imóveis/finanças/saúde/patrimônio) + lookup INSS/IRRF/SM + busca lei + decisão CLT vs PJ. Engine TypeScript local — zero network, zero latência, zero alucinação fiscal.
