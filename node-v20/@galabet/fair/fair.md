# @galabet/fair

> 标签: casino, fairness, gfs, hmac, provably-fair, sha256

## 简介

Reference implementation of the Galabet Fair Spec (GFS/1.0): provably fair seeds, commitments, HMAC derivation, float extraction, game mappers, records and verification. Zero runtime dependencies.
