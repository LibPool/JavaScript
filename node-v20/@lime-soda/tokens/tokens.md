# @lime-soda/tokens

> 标签: JavaScript

## 简介

Design tokens for the Lime Soda design system, built with Style Dictionary. Features a modern two-layer token architecture with primitive and semantic tokens, supporting both light and dark themes with WCAG 2.1 AA accessibility compliance.
