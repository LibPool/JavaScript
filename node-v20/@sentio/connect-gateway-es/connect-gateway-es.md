# @sentio/connect-gateway-es

> 标签: connect, connectrpc, grpc, grpc-gateway, protobuf-es, rest, transcoding, transport

## 简介

Connect-ES transport that speaks the grpc-gateway REST dialect, driven by google.api.http annotations read from protobuf-es descriptors
