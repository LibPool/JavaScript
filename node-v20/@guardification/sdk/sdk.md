# @guardification/sdk

> 标签: angular, astro, build-health, error-boundary, express, guardification, hono, monitoring, nextjs, nuxt, observability, performance, react, security, sveltekit, vite, vue

## 简介

Fail-open, async monitoring SDK for Next.js, React, Vite, Vue, SvelteKit, Astro, Nuxt, Express, Hono and Angular apps - health, performance & passive security, reported to Guardification.
