# @salesway/kohr

> 标签: JavaScript

## 简介

* `DATABASE_URL` *mandatory* a connection string to a PostgresSQL instance. * `KOHR_JSON_SIZE_LIMIT` defaults to `'100mb'`, used to limit the size of JSON data sent to us.
