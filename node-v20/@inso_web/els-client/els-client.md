# @inso_web/els-client

> 标签: apm, browser, cjs, crash-reporting, els, error-logging, error-monitoring, error-tracking, esm, inso, insoweb, logging, logrocket-alternative, monitoring, nodejs, observability, sentry-alternative, typescript, universal, zero-dependencies

## 简介

Lightweight TypeScript client for the Error Logs Service (ELS) — capture, batch and ship errors from the browser and Node.js. Zero dependencies, retry with Retry-After support, silent fail, sendBeacon, traceId idempotency, universal (browser + Node >=18).
