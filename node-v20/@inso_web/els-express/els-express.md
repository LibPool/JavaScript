# @inso_web/els-express

> 标签: els, error-monitoring, error-tracking, express, express-middleware, inso, insoweb, logger, logging, loki-alternative, morgan-alternative, observability, pino-http-alternative, request-logger, structured-logging, winston-alternative

## 简介

Express middleware for @inso_web/els-client with request-scoped logging (req.log) and an error handler. A drop-in replacement for pino-http and morgan + winston.
