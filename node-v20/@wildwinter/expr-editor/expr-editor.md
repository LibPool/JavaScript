# @wildwinter/expr-editor

> 标签: ast, condition, editor, expression, ui, wildwinter

## 简介

Framework-neutral (vanilla TS + DOM) visual editor for @wildwinter/expr expressions: a hybrid pill-strip + AND/OR tree builder with a raw-text fallback, property picker, and live validation. Scopes, properties and functions come from an injected Dialect +
