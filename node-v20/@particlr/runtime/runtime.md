# @particlr/runtime

> 标签: 2d, animation, game-development, gamedev, particle-effects, particle-system, particles, phaser, pixi, pixijs, three, threejs, vfx, webgl, webgpu

## 简介

Framework-agnostic particle simulation core + Pixi v8/v7, Three.js, and Phaser 4 adapters for the .prt format.
