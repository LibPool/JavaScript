# @sx4im/chronos-core

> 标签: chronos, deterministic-simulation-testing, distributed-systems, dst, prng, simulation, testing, typescript, virtual-clock, xoshiro256

## 简介

Deterministic Simulation Testing core: PRNG (xoshiro256**), VirtualClock, MinHeap scheduler, SimEnv, strict guards, invariants, trace, RealEnv. Zero runtime dependencies.
