# dsh-exa-search

> 标签: deepseek-harness, dsh-plugin, exa, mcp, web-search

## 简介

Exa-powered web search for DeepSeek Harness: keyless free tier, your own API key, or a signed-in Exa account, with a settings page that shows which Exa tools each mode exposes.
