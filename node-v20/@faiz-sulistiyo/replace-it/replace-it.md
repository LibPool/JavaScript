# @faiz-sulistiyo/replace-it

> 标签: custom-regex, placeholders, replace, template

## 简介

A lightweight template engine for Node.js written in TypeScript.   Supports **expressions, conditionals, loops, custom helpers, custom handlers, and template loading from file paths**.
