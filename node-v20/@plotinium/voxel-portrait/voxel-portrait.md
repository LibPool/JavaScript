# @plotinium/voxel-portrait

> 标签: 3d, animation, canvas, portrait, r3f, react, scroll, three.js, voxel

## 简介

Scroll-driven 3D voxel portrait canvas component for React. Converts any image into an interactive particle sculpture powered by React Three Fiber.
