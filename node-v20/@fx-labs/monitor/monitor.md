# @fx-labs/monitor

> 标签: JavaScript

## 简介

轻量级浏览器监控 SDK（TypeScript）。该包对 XHR、WebSocket 和静态资源加载进行埋点，允许用户通过回调钩子对请求/消息/资源加载做自定义校验。
