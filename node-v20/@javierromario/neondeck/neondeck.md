# @javierromario/neondeck

> 标签: JavaScript

## 简介

NEONDECK — a cyberpunk React component library. Terminal-monospace primitives (à la SRCL / www-sacred) rebuilt with neon glows, semi-transparent glass panels, and ticker-board edge readouts.
