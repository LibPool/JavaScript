# @clickonsearch/whatsapp-mcp-server

> 标签: JavaScript

## 简介

MCP server that connects to a personal WhatsApp account (via Baileys) and exposes it as tools — send messages, list chats, read recent messages, search contacts — plus an SSE stream of incoming messages.
