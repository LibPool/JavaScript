# @clickonsearch/github-agent

> 标签: JavaScript

## 简介

Agent that talks to GitHub via the GitHub remote MCP server, routed through the OpenAI, Claude, or DeepSeek remote MCP bridge depending on user preference. Ships an AG-UI protocol server plus a browser chat UI for end users.
