# @useprivatus/sdk

> 标签: agent-economy, ai-agents, confidential-transfers, neobank, payments, privacy, privatus, sdk, solana, stablecoin, typescript, usdg, web3, x402, zero-knowledge

## 简介

The official TypeScript SDK for Privatus, the private financial layer of the agent economy. Confidential transfers, agent accounts with on-chain spend policies, and native x402 payments on Solana, fully typed and ready in minutes.
