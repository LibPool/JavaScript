# @eddie-doc/cli

> 标签: annotations, asciidoc, asciidoctor, cli, copyedit, pdf, proofreading, publishing, review

## 简介

Map an editor's PDF annotations back onto your AsciiDoc source from the command line: highlights, strikeouts, comments and inserts become tracked, resolvable review items. The CLI of the Eddie Doc VS Code extension and Obsidian plugin.
