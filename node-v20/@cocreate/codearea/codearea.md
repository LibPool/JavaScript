# @cocreate/codearea

> 标签: codearea, collaboration, html5-framework, javascript-framework, low-code, realtime, realtime-framework, shared-editing

## 简介

A simple codearea component in vanilla javascript. Easily configured using HTML5 data-attributes and/or JavaScript API.
