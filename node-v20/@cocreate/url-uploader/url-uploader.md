# @cocreate/url-uploader

> 标签: collaboration, html5-framework, javascript-framework, low-code, realtime, realtime-framework, shared-editing, url-uploader

## 简介

A simple url-uploader component in vanilla javascript. Easily configured using HTML5 data-attributes and/or JavaScript API.
