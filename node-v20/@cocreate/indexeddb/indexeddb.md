# @cocreate/indexeddb

> 标签: collaboration, html5-framework, indexeddb, javascript-framework, low-code, realtime, realtime-framework, shared-editing

## 简介

A simple indexeddb component in vanilla javascript. Easily configured using HTML5 data-attributes and/or JavaScript API.
