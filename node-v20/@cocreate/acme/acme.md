# @cocreate/acme

> 标签: acme, acme-client, automation, certificates, cocreate, cocreate-app, dns-01, http-01, letsencrypt, multi-tenant, proxy, reverse-proxy, security, ssl, tls

## 简介

An automated multi-tenant ACME SSL/TLS certificate provisioning and management wrapper for CoCreate, featuring distributed http-01 challenge syncing via custom CRUD gateways, automatic 2048-bit RSA key generation, staggered renewal windows, and hot proxy
