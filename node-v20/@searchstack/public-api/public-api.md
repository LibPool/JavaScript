# @searchstack/public-api

> 标签: api-client, autocomplete, faceted-search, full-text-search, geo-search, hybrid-search, image-search, mcp, search, search-api, search-engine, searchstack, semantic-search, typeahead, typescript, vector-search

## 简介

TypeScript client for the Search Stack public API. A typed, fetch-based wrapper that authenticates with an API key or access token and covers the full public surface.
