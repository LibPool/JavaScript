# @mistweaverco/fs-extra

> 标签: copy, create, delete, directory, extra, file, file system, fs, json, mkdir, mkdirp, mkdirs, move, output, promise, read, recursive, remove, text, touch, write

## 简介

fs-extra contains methods that aren't included in the vanilla Node.js fs package. Such as recursive mkdir, copy, and remove.
