# @inneranimalmedia/agentsam-telemetry

> 标签: agentsam, analytics, basin, cloudflare-worker, d1, event-spool, ingestion, telemetry

## 简介

AgentSam analytics/event ingestion boundary: typed event envelopes, durable local spool (batching, backoff, dedupe), authenticated Worker gateway transport, and the device credential policy.
