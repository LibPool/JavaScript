# @inneranimalmedia/agentsam-platform-web

> 标签: agentsam, capability-adapter, opfs, pwa, service-worker, web

## 简介

Web and installable-PWA implementation of the AgentSam capability contract: OPFS filesystem, getUserMedia capture, Web Share, Async Clipboard, Notification API, and periodic background sync.
