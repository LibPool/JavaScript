# @displayxr/inline3d

> 标签: 3d-display, displayxr, glasses-free-3d, inline-3d, lightfield, playcanvas, spatial-display, stereo, three, webxr

## 简介

Turn any HTML <canvas> into a 3D window on a spatial display, inside an ordinary web page, for the DisplayXR Browser. Dependency-free; progressive enhancement (falls back to plain 2D everywhere else).
