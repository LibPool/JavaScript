# @webapp.mk/cli

> 标签: agent, claude-code, cli, deploy, hosting, webapp.mk

## 简介

webappmk — deploy and run everything on webapp.mk from the command line, built for coding agents: a self-describing command registry, a machine-readable manifest, exit codes that mean something, and a public price calculator.
