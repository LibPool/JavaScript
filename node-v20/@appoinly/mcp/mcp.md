# @appoinly/mcp

> 标签: appoinly, appointments, booking, claude, mcp, modelcontextprotocol, scheduling

## 简介

MCP server for Appoinly — lets AI assistants browse services, check availability and book appointments through a tenant's Appoinly public API key (stdio transport)
