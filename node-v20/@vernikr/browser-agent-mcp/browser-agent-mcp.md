# @vernikr/browser-agent-mcp

> 标签: automation, browser, chrome, claude, cloudflare, cursor, mcp, model-context-protocol, stealth, turnstile, web-scraping, x11

## 简介

MCP server that gives LLM agents a real headful Chrome (X11 mouse, Cloudflare Turnstile auto-solve) via the browser-agent-server daemon. Companion: github.com/vernikr/browser-agent
