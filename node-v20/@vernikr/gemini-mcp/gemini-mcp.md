# @vernikr/gemini-mcp

> 标签: JavaScript

## 简介

One-command Gemini free-tier MCP gateway: quota-aware model routing, massive-body chunked analysis, file ingest — text extracted server-side, PDFs/images/audio read by the provider Files API — async tickets. Thin bootstrap for the Python core gemini-mcp-g
