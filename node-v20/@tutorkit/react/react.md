# @tutorkit/react

> 标签: education, hooks, react, realtime-sync, tutoring, video-call, webrtc

## 简介

React hooks and headless components for TutorKit: room lifecycle, lesson material sync primitives (shared deck, synced clicks/inputs, control grant), session chat, talk-time, and transcript capture.
