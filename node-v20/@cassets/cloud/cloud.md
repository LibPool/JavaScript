> 标签: aws-s3, azure-blob, cassets, cloud, gcs, google-cloud-storage, minio, s3, signed-url, typescript, upload, wasabi

## 简介

Signed-upload URL adapters for @cassets/http-client across S3-compatible storage, Azure Blob Storage, and Google Cloud Storage.
