# @ngdream/krea

> 标签: 2d, agent-skills, ai-agent, collision, game-development, gamedev, level-editor, map-editor, tilemap

## 简介

2D and 3D map editor for video games — single-file .krea projects, editable models, sprites, terrain, game-ready export, and a stateless HTTP API + skill for AI agents.
