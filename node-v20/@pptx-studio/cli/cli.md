# @pptx-studio/cli

> 标签: bisect, cli, delta-debugging, inspect, ooxml, powerpoint, pptx, render, roundtrip, svg, thumbnail, validate

## 简介

Command line tools for PPTX packages: render slides to SVG without a browser, inspect a deck, validate it, prove a round trip, and bisect the change that breaks it
