# @tokemak/autopool-hooks

> 标签: JavaScript

## 简介

React Query hooks over the `@tokemak/autopools` SDK read surface. This is the shared hooks layer for apps that render autopool data — the SDK stays headless (viem + fetch only); this package adds caching, keys, and query-options factories on top.
