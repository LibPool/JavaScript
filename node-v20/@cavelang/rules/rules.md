# @cavelang/rules

> 标签: JavaScript

## 简介

CAVE rules engine (spec §24) — forward-chaining `premises => conclusion` rules over current beliefs, with BECAUSE/VIA derivation lineage, noisy-AND confidence, tx-watermark incrementality and idempotent re-runs.
