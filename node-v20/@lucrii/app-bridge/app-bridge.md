# @lucrii/app-bridge

> 标签: JavaScript

## 简介

The client-side SDK for Lucrii app UIs. Apps run inside a sandboxed iframe in the Lucrii host; this package owns the `postMessage` RPC, KV access, OAuth-flow triggers, host-API calls, toast/confirm/external-link helpers, theme sync, and first-party analyt
