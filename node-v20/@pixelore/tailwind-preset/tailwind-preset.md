# @pixelore/tailwind-preset

> 标签: 8-bit, design-system, pixel-art, retro, tailwind-preset, tailwindcss, theme

## 简介

Tailwind CSS preset for pixelore — exposes the 8-bit theme tokens as utilities. Compatible with Tailwind v3 (preset.cjs/.js) and Tailwind v4 (preset.css).
