# @loom-js/esbuild-plugin-html-split

> 标签: code splitting, esbuild, esbuild-plugin, html, loomjs

## 简介

esbuild plugin that emits one HTML shell per route from a metafile-aware template: shared, route-scoped and dynamic chunks classified, per-route CSS split and hashed.
