# @ds-hu/dsh-auto-task-center

> 标签: agent-preset, automation, cordis, cron, deepseek-harness, dsh, dsh-bundle, dsh-plugin, scheduler, webhook

## 简介

Task Center for the DeepSeek Harness Web GUI: create and manage Host-wide scheduled and webhook tasks from the right sidebar, delivered into a new session in any workspace or into an existing session, plus a 任务管理 agent preset.
