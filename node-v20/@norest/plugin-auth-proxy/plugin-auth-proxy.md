# @norest/plugin-auth-proxy

> 标签: noREST, plugin

## 简介

A plugin that allows to add a authentication for Github to secure the noREST server and only allow changes by people that have authorized Github. It adds three new endpoints: 1. GET /github/login -> used to login 2. GET /github/auth -> callback URL if suc
