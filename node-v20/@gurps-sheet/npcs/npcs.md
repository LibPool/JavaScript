# @gurps-sheet/npcs

> 标签: combat-engine, fixtures, gurps, npc, rpg

## 简介

Ready-made GURPS 4e NPCs in the gurps-character format, grouped by adventure style and built only from Basic Set skills, traits and equipment — examples for GMs and fixtures for engine tests.
