# @jiangsier/local-spy

> 标签: debugging, http, macos, mitm, proxy, sniffer, tcpdump, traffic

## 简介

Local HTTP traffic inspector for macOS — passive capture with an opt-in MITM HTTPS proxy and Chrome-style Copy-as-cURL
