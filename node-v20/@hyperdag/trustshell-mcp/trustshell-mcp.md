# @hyperdag/trustshell-mcp

> 标签: ai-agent, claude-desktop, cursor, hal, hyperdag, mcp, model-context-protocol, repid, trust, trustshell, windsurf, zkp

## 简介

MCP server for HyperDAG TrustShell — add real cross-LLM trust verification, portable RepID, and ZK proofs to your AI agent in Claude Desktop / Cursor / Windsurf with zero code. Wraps @hyperdag/trustshell and exposes it as MCP tools.
