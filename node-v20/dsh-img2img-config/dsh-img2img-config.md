# dsh-img2img-config

> 标签: deepseek-harness, dsh-plugin, image-editor, provider-config, vision

## 简介

DSH plugin: a composer image editor (numbered marks, background removal, brush-mask erase, resize and crop) plus a vision/generation provider panel that writes the resolved providers back to the skills' .env files.
