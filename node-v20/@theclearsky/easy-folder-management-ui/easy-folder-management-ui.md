# @theclearsky/easy-folder-management-ui

> 标签: file-system-access, file-tree, indexeddb, opfs, react, tabs, typescript, vscode

## 简介

VS Code-style file library and tabs for web apps: linked local folders (File System Access), in-browser storage, a file tree sidebar and a tab strip — headless core, React hooks and styled components.
