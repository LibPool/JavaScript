# @theclearsky/react-blender-nodes-timeline

> 标签: JavaScript

## 简介

Timeline plugin for @theclearsky/react-blender-nodes — multipart named curves with per-side interpolation, a drag/play transport that drives AudioParams sample-accurately, and a curve node factory.
