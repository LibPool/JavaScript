# pi-image-slim

> 标签: bandwidth, coding-agent, context, image, images, pi, pi-coding-agent, pi-extension, pi-package, screenshot, tokens, upload

## 简介

Pi extension that stops historical images from being re-uploaded on every request — each image is sent in full exactly once, then replaced by a path-carrying placeholder.
