# @bo-agent/bash-sandbox

> 标签: JavaScript

## 简介

Sandbox-consuming bash executor: wraps the local bash argv through ctx.sandbox, inherits local process mechanics, and reports the selected mode, enforcement, and denial facts (standalone product, forked from the DeepSeek Harness)
