# @openmaic/dsl

> 标签: contract, dsl, maic, schema, slide

## 简介

The MAIC slide DSL: the pure, dependency-free contract (types + JSON Schema + validators + version/migration helpers) that @openmaic/renderer and @openmaic/importer both depend on.
