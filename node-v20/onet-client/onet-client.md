# onet-client

> 标签: bls, careers, holland-codes, interest-profiler, labor, o*net, occupations, onet, onetcenter, riasec, soc

## 简介

Typed client for O*NET Web Services v2 (api-v2.onetcenter.org): occupation search and reports, details pagination, the Interest Profiler and Mini-IP, plus parsers for the O*NET bulk database files. Zero dependencies.
