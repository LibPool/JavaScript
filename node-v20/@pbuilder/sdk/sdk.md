# @pbuilder/sdk

> 标签: ast, code-generation, codemod, project-builder, scaffolding, schematics

## 简介

The public TypeScript/Bun authoring layer for Project Builder schematics. Authors file mutations (create, replaceContent, remove, rename, move, copy, copyIn), lowers them to IR, and talks to the Project Builder engine over framed stdio (see docs/engine-sd
