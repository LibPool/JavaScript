# @npmsolsentry/mcp

> 标签: ai-agents, claude, cursor, mcp, model-context-protocol, solana, transaction-simulation, wallet-drainer

## 简介

Model Context Protocol server for SolSentry. Add it to Claude, Cursor, or any MCP client to guard Solana transactions and score protocol risk. Thin stdio proxy; holds no keys.
