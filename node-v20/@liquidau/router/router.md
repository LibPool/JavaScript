# @liquidau/router

> 标签: classifier, edge, embeddings, release-validation, routing, rules

## 简介

Validates an immutable classifier + rules + policy + evidence bundle, settles requests with certified rules first, embeds and scores only when needed, and returns enforce or shadow route decisions.
