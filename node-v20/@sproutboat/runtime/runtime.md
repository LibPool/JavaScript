# @sproutboat/runtime

> 标签: JavaScript

## 简介

The sprout runtime as a unit: the binding and trigger wrapper, handler source validation, both transports (broker and embedded), and the native-fetch prelude. These move as one because `wrap.ts` locates the prelude and transports by file URL beside itself
