# @venloc/typemo

> 标签: decorators, mongodb, mongoose, mongoose-alternative, odm, schema, typed, typegoose, typescript

## 简介

A strictly typed ODM for MongoDB: class-and-decorator schemas, types inferred from the implementation, strict by default.
