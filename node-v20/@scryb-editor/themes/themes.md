# @scryb-editor/themes

> 标签: css, dark-mode, design-tokens, editor, prosemirror, rich-text-editor, stylesheet, theme, tiptap, wysiwyg

## 简介

CSS design tokens, light and dark themes, and content styles for the Scryb rich text editor, with a viewer-only stylesheet for read-only pages
