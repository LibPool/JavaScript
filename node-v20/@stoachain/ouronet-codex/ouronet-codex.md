# @stoachain/ouronet-codex

> 标签: JavaScript

## 简介

Modular React Codex for the Ouronet ecosystem. Drop-in <CodexProvider> + hooks + headless components giving any React consumer (OuronetUI, AncientHoldings hub, future apps) full 1:1 Codex functionality — onboarding flows, CodexPrime account, account/key m
