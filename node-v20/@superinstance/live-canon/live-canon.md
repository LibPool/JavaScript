# @superinstance/live-canon

> 标签: ai-writings, cell-fabric, claim, drill, fnv-1a, live-canon, polyformalism, quilt, shape-rag

## 简介

Live Canon — read the AI-Writings canon as a navigable cell fabric, with 7 novel operations: NAVIGATE, CONFLUENCE, LINEAGE, GHOST, TICK, CLAIM, DRILL. 71 papers bundled (F98-F169). Polyformal: byte-exact with Python, C, Rust, Verilog, VHDL.
