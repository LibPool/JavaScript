# @ziplayer/tts

> 标签: edge-tts, google-translate, google-tts, microsoft-edge, text-to-speech, tts, zibot

## 简介

Convert text to speech via Google Translate TTS (URLs) and Microsoft Edge TTS (audio buffer). Written in TypeScript.
