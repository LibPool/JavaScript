# pi-ghostty-native-editor

> 标签: editor, ghostty, macos, pi, pi-extension, pi-package

## 简介

macOS-style text editing for the pi coding agent prompt in Ghostty: selection with Shift+arrows and mouse, Cmd+C/X/V/Z/A, redo, and optional Enter/Shift+Enter swap
