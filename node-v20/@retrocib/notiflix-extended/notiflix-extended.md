# @retrocib/notiflix-extended

> 标签: alert, angular notifications, async-await, block ui element, client-side, confirm box, daisyui, fork, javascript alert, javascript confirm, loading indicator, nextjs notifications, non-blocking, notification, notifications, notiflix, notify, popup boxes, promise, react notifications, tailwindcss, toast, ui block, zero dependency

## 简介

Unofficial fork of Notiflix that adds a Promise-based (async/await) API for Confirm and Report, plus live/reactive CSS-variable theming (DaisyUI v5 / Tailwind / plain CSS), on top of the original dependency-free notification, popup, and loading-indicator
