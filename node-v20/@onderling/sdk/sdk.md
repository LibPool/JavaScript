# @onderling/sdk

> 标签: JavaScript

## 简介

Batteries-included, LAYERED developer facade for @onderling. ONE import for the whole SDK. LOW layer: named re-exports of the kernel (@onderling/core) plus the default adapters (VaultMemory + Vault family from @onderling/vault, the transports from @onderl
