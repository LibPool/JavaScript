# @voyant-travel/transactions-contracts

> 标签: JavaScript

## 简介

Pure transactions validation schemas (offers, orders, order terms) and enums, zod-only, for consumers (admin SDK, Voyant Connect) that validate transaction payloads from pre-v1 integrations. Runtime transactions are retired in v1.
