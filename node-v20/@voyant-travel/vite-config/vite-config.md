# @voyant-travel/vite-config

> 标签: JavaScript

## 简介

Versioned Vite build preset for Voyant TanStack Start apps: vendor chunking (cold-start tuning), SSR dependency pre-bundling, the route-file ignore pattern, and the `@` alias — delivered as a dependency instead of a copied `vite.config.ts`.
