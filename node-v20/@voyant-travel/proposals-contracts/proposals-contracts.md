# @voyant-travel/proposals-contracts

> 标签: JavaScript

## 简介

Pure validation schemas for proposals, proposal versions, proposal lines, proposal participants, proposal products, pipelines, stages, and proposal-facing enums, zod-only, for consumers that validate proposal payloads without depending on the runtime pack
