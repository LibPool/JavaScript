# @voyant-travel/crm-contracts

> 标签: JavaScript

## 简介

Pure validation schemas for people, organizations, quotes, activities, custom fields, and enums, zod-only, for consumers (admin SDK, Voyant Connect) that validate relationship or quote payloads without depending on a runtime package.
