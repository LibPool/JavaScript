# @segurudigital/seguru-debug-toolbar

> 标签: bricks, data-ref, debug, design-system, elementor, overlay, qa, shopify, toolbar, wireframe, wordpress

## 简介

Zero-dependency visual overlay for data-ref element labels. Label, target, level-filter, outline, tree, and click-to-copy controls. Default hidden — press D to reveal. Works in static HTML, Vite/Webpack builds, React/Next/Vue, WordPress, and Shopify.
