# @leko/expo-ios-build-settings

> 标签: JavaScript

## 简介

An [Expo Config Plugin](https://docs.expo.dev/config-plugins/introduction/) that lets you set arbitrary iOS build settings directly from your `app.config.js` / `app.config.ts`.
