# @cldmv/slothlet

> 标签: api, api-loader, api-management, asynclocalstorage, cjs, context-isolation, copy-left-materialization, deferred-loading, dual-loading, dynamic-import, eager-loading, esm, framework, lazy-loading, live-binding, mixed-modules, modular, module-loader, nodejs, optimization, performance, proxy, startup-performance, typescript, zero-dependencies

## 简介

Slothlet: Modular API Loader for Node.js. Lazy mode dynamically loads API modules and submodules only when accessed, supporting both lazy and eager loading.
