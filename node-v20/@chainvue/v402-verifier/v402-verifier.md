# @chainvue/v402-verifier

> 标签: JavaScript

## 简介

Framework-agnostic verification core of v402: multi-scheme registry and the verus-prepaid-sig verifier (RPC mode) — amount pre-check, extension validation, bodyHash policy, timestamp window, two-phase debit against injected storage.
