# @pithyjs/vite-plugin

> 标签: JavaScript

## 简介

Vite plugins for the PithyJS framework. Provides `.pithy` file compilation, `html\`…\`` template transformation, file-based routing, build optimization, design system CSS tree-shaking, SSR dev server, and icon sprite generation.
