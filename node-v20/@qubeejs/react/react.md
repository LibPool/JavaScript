# @qubeejs/react

> 标签: data-fetching, hooks, nextjs, pagination, qubee, query-builder, react, react-router, search-params, swr, tanstack-query, tanstack-router, url-state, use-sync-external-store

## 简介

React hooks for @qubeejs/core: lists whose state lives in the URL of your router, fetched for you, and a query builder per component or per subtree
