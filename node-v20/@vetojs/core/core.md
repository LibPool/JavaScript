# @vetojs/core

> 标签: abac, access-control, ai-agents, authorization, casl-alternative, guard, mcp, permissions, rbac, rsc, typescript

## 简介

Type-safe authorization for TypeScript, with no classes and no hidden state. Rules are plain JSON: they cross the server/client boundary, answer can(), gate writes field by field, and become a SQL WHERE through the Drizzle adapter. One guard covers server
