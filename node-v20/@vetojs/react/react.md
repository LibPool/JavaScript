# @vetojs/react

> 标签: access-control, authorization, casl-alternative, permissions, react, rsc, typescript

## 简介

React bindings for @vetojs — <Can>, useCan, useAbility, AbilityProvider, plus a server <Can> that decides while rendering, with no client boundary and no hooks. The same rules that guard the server decide what the user can reach in the UI.
