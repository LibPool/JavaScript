# @eslym/sveltekit-adapter-cli

> 标签: JavaScript

## 简介

A Sveltekit adapter which run as cli and render the content via a very simple protocol, designed to run on shared web hosting (usually lamp stack) with bun, **not an ideal way to host sveltekit but it could be a cheap way.**
