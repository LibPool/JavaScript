# @verter/svelte-jsx

> 标签: jsx, svelte, tsx, verter

## 简介

Verter-owned, module-scoped JSX namespace for Svelte IDE projections, with native Svelte 5 Component adaptation, official-derived element attributes, a child-only projection adapter, and dedicated SVG and MathML entrypoints. Types-only, no runtime JS.
