# @syn7xx/opencode-dynamic-workflows

> 标签: agents, llm, multi-agent, opencode, opencode-plugin, orchestration, subagents, tui, workflow

## 简介

Deterministic multi-agent Workflows for OpenCode: TypeScript scripts that fan work out to subagents, with typed results, a live TUI panel, a web app and a versioned protocol.
