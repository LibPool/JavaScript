# @mcd0luo/celes-dsh-watchdog

> 标签: JavaScript

## 简介

Celes 调度中心 DSH 插件：单例会话巡检看门狗（lock 文件 + flock 全局单例；session.list 巡检卡死/实例死亡并汇报主 worker 会话，冷却去重不轰炸）
