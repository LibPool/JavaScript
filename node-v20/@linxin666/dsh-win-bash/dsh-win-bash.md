# @linxin666/dsh-win-bash

> 标签: JavaScript

## 简介

Pinned private bash for Windows x64 DSH sessions: one persistent bash process per session behind the win_bash tool, carrying a digested Git for Windows MinGit payload and no PATH fallback.
