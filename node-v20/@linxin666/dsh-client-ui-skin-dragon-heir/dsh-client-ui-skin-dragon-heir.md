# @linxin666/dsh-client-ui-skin-dragon-heir

> 标签: JavaScript

## 简介

Hot-pluggable 龙的传人 (Dragon Heir) skin for the dsh web GUI: one skin, two paintings — light theme rides the ink dragon with a vermilion seal, dark theme rides the Great Wall with gold accents; both artworks inline, no static files
