# @pleri/pylon-cli

> 标签: authz, cli, mcp, olam, pleri, pylon, rbac

## 简介

Pylon CLI — log in to your org's Pylon, manage apps and roles, query the audit log. The user-facing half of the @pleri/pylon RBAC service.
