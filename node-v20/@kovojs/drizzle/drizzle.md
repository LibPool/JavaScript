# @kovojs/drizzle

> 标签: JavaScript

## 简介

Drizzle integration for Kovo's data layer. It annotates tables with domains, owners, secret fields, governed columns, and concurrency facts so Kovo can derive read/write graphs from ordinary Drizzle queries.
