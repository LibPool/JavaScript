# @wefi-ai-platform/agent-loop

> 标签: JavaScript

## 简介

与框架无关的 agent 循环卫生机制:重复调用拦截、工具超时、任务清单、下一步建议解析、模型错误人话化。神灯(AI SDK)与所罗门(Mastra)共用。
