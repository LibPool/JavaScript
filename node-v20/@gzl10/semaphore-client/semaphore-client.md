# @gzl10/semaphore-client

> 标签: ansible, ansible-semaphore, api, automation, cli, client, devops, infrastructure-as-code, opentofu, sdk, semaphore, semaphore-ui, terraform, typed, typescript

## 简介

Typed TypeScript client and CLI (smphe) for the Semaphore UI API: run Ansible, Terraform/OpenTofu, bash and Python tasks, wait for the result, and manage templates, schedules, inventories, keys, workflows and webhooks.
