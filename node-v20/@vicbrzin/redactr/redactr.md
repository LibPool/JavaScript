# @vicbrzin/redactr

> 标签: anonymize, api-key, chatgpt, data-loss-prevention, dlp, llm, mask, pii, privacy, prompt, redact, redaction, scrub, secrets, security

## 简介

Scrub secrets & PII (API keys, tokens, emails, cards, CPF/CNPJ...) from text before you paste it into AI, issues or pastebins. Reversible, 100% client-side, zero runtime dependencies.
