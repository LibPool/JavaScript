# @violetjs/kite-player

> 标签: audio, custom-elements, kite, lit, lyrics, music, netease, player, react, web-components

## 简介

A music player for any web page, backed by your own kite-server: a floating player, track and playlist cards, word-by-word lyrics. Custom elements built with Lit, plus React components.
