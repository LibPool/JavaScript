# @ithinkdt/storage

> 标签: JavaScript, Node.js, TypeScript, cookie, localStorage, sessionStorage

## 简介

Web存储localStorage、sessionStorage的TypeScript封装，提供通用的API方法（同原有的js方法名称均一致），同时支持泛型方法。
