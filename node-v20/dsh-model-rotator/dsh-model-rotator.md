# dsh-model-rotator

> 标签: deepseek-harness, dsh, dsh-plugin, failover, llm, model-routing, resilience

## 简介

Model auto-ranking and transparent failover for DeepSeek Harness: ranks discovered models by measured connectivity and speed, switches to the next candidate inside the same turn when the current one is unusable, and ships a grouped model list with per-cha
