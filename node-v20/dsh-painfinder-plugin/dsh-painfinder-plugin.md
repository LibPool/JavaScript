# dsh-painfinder-plugin

> 标签: JavaScript

## 简介

This ESM plugin runs on DSH **`>=0.2.1-rc.2`** — the official desktop app's current runtime — and refuses older runtimes through `engines.dsh` (the harness compatibility gate lets an own `engines.dsh` range decide alone). DSH 0.2.1 changed the delegation
