# is-apple-silicon

> 标签: apple, arm64, cpu, m1, m2, m3, m4, mac, macbook, macos, osx, processor, rosetta, silicon

## 简介

A simple utility to check if a machine has an Apple (arm64) processor; useful for npm/developer scripts.
