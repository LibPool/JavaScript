# insight-ui-safe

> 标签: bitcore-safe, blockchain, blockexplorer, front-end, insight, safe

## 简介

An open-source frontend for the Insight API. The Insight API provides you with a convenient, powerful and simple way to query and broadcast data on the Safe network and build your own services with it.
