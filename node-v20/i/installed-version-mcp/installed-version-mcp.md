# installed-version-mcp

> 标签: claude, coding-agent, cursor, grounding, installed-version, lockfile, mcp, model-context-protocol, node_modules, npm

## 简介

MCP server that grounds coding agents on the dependency versions ACTUALLY installed in the current project — read from the lockfile and node_modules — so they stop coding against a blend of every version.
