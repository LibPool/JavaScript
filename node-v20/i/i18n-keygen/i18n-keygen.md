# i18n-keygen

> 标签: codegen, crowdin, esbuild-plugin, i18n, i18next, internationalization, keygen, lokalise, ngx-translate, nx, phrase, react-i18next, rollup-plugin, rspack-plugin, translation, translation-keys, transloco, type-safe, typescript, unplugin, vite-plugin, webpack-plugin

## 简介

Type-safe i18n keys for every build tool. Reads your translation JSON files, generates a TypeScript union type.
