# i-am-cooking

> 标签: agent, autonomy, cooking, notification, pi-package, tui

## 简介

Pi extension: when the user is away cooking, the agent works autonomously. When blocked or when work is done, it shouts loudly — through sound, TTS, desktop toast, and phone push — so the user can come back from the kitchen.
