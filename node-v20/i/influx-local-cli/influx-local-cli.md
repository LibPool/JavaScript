# influx-local-cli

> 标签: cli, database, development, flux, influx, influxdb, influxql, local, mise, time-series, web, without-docker

## 简介

Create, start and manage local InfluxDB instances (1.x / 2.x / 3.x) without Docker/Podman. CLI + Web dashboard, powered by mise.
