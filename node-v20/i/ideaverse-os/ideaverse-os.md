# ideaverse-os

> 标签: agentic, claude, ideaverse, karpathy, knowledge-base, llm, obsidian, position-addressed, second-brain, vault-template

## 简介

Bootstrap a position-addressed, LLM-agnostic knowledge vault from a template. Karpathy's wiki pattern with conversational ingestion baked in.
