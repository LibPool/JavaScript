# imgalpha.js

> 标签: image, image-processing, javascript, jpeg, jquery, jquery-plugin, low-weight, rgba, transparent

## 简介

imgAlpha.js is a jQuery plugin by Yann Masoch to use light-weight transparent images on any website!
