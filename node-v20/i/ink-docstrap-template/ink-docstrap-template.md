# ink-docstrap-template

> 标签: bootstrap, bootswatch, docstrap, documentation, jsdoc, jsdoc3, theme

## 简介

This is a reduced version of Terry Weiss' [docstrap](https://github.com/docstrap/docstrap), containing only the [JSDoc3](https://jsdoc.app/) template, but with updated dependencies.
