# iss-toast-lib

> 标签: iss-ui-kit, notification, toast, typescript, vue, vue3

## 简介

A lightweight toast/notification library for **Vue 3 + TypeScript**. One plugin mounts a single container, a small reactive store powers everything, and a styled Toast component ships out‑of‑the‑box – fully themable with CSS variables.
