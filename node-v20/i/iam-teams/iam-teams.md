# iam-teams

> 标签: JavaScript

## 简介

SDK para Node.js que permite interactuar con la API de IA-MANAGER y gestionar el flujo conversacional de bots en Microsoft Teams. Incluye autenticación, transmisión de mensajes en tiempo real, gestión de chats, almacenamiento de cookies, subida de archivo
