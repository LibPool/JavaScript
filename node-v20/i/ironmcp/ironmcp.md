# ironmcp

> 标签: additionalProperties, ai-agents, conformance, hardening, mcp, mcp-server, model-context-protocol, strict, strict-args, tool-validation, zod

## 简介

Hardened, conformant MCP tools that refuse undeclared arguments with a recoverable error and enforce exactly what they advertise.
