# imooc-test-sf

> 标签: JavaScript

## 简介

1. 创建项目 2. npm init -y 完成初始化 3. 创建 bin 文件夹 创建 index.js 4. index.js 上方写入 ` #!/user/bin/env node ` 5. 发布到 npm 上
