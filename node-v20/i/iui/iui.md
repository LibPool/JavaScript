# iui

> 标签: iui

## 简介

一套前端开发框架，视觉体验一致的基础样式库，借助开源力量为客服系统 Web 开发量身设计，可以令我们开发的系统使用感知更加统一。我们希望借助gulp加载正在使用的部分CSS代码。

- npm 页面：https://www.npmjs.com/package/iui
