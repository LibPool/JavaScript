# ifood-mcp-unofficial

> 标签: ai-agents, food-delivery, ifood, local-first, mcp, model-context-protocol

## 简介

Unofficial local-first iFood MCP for personal restaurants, cart, addresses and orders. Never pays unless IFOOD_ALLOW_MUTATIONS and explicit_user_intent are both set.
