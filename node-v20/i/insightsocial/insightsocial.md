# insightsocial

> 标签: agents, cli, insightsocial, linkedin-api, mcp, modelcontextprotocol, scraping, social-media-api, tiktok-api

## 简介

Official CLI and MCP server for the InsightSocial API: 230+ social data endpoints across 22 platforms (TikTok, LinkedIn, YouTube, X, Reddit, Bluesky, Telegram, Douyin, Weibo and more) behind one key.
