# image2ppt

> 标签: api, image-to-pptx, image2ppt, ocr, pdf, powerpoint, pptx, presentation, sdk, slides

## 简介

Official Node.js/TypeScript client for the image2ppt API — convert images and PDFs into editable PowerPoint (.pptx).

- 官网：https://image2ppt.com
- 源码仓库：git+https://github.com/image2ppt/image2ppt-sdk.git
- npm 页面：https://www.npmjs.com/package/image2ppt
