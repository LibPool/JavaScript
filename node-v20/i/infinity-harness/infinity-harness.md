# infinity-harness

> 标签: agent-pipeline, autonomous, continuous-development, harness, pi-extension, pi-package

## 简介

A pi agent extension that runs a gated build pipeline unattended — enforces phases, validates with deterministic gates, and keeps working for hours or days without losing the plan.
