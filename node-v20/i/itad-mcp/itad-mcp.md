# itad-mcp

> 标签: game-deals, game-prices, gaming, isthereanydeal, itad, mcp, model-context-protocol

## 简介

MCP server for IsThereAnyDeal (ITAD) API v3 — query game prices across storefronts, all-time historical low prices, active deals, and ITAD ID lookups.
