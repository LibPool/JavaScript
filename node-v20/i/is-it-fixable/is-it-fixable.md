# is-it-fixable

> 标签: cli, contributing, fixability, github, good-first-issue, issues, open-source, triage

## 简介

Tells an open-source contributor whether a GitHub issue is actually fixable and worth their time — a scored, evidence-backed verdict per issue, not just a claim-check.
