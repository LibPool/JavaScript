# ingenium-redis

> 标签: background-jobs, idempotency, ingenium, jobs, multi-instance, queue, rate-limit, redis, session

## 简介

Redis-backed session, idempotency, rate-limit, and background-job queue stores for Ingenium. Drop-in replacements for the in-memory defaults; required for multi-instance deployments.
