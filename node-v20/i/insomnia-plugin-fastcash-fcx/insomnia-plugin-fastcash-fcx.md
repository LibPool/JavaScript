# insomnia-plugin-fastcash-fcx

> 标签: JavaScript

## 简介

1.	Instale o plugin `insomnia-plugin-fastcash-fcx` 2.  No `Base Environment` do Insomnia defina a variavel `use-fastcash-fcx-on` que é o nome do objeto que contém os hosts da api
