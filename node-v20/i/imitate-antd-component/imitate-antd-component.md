# imitate-antd-component

> 标签: JavaScript

## 简介

这是一个 仿造 antd的练习组件库。 组件上，支持按需加载。     import {Message、Tab、Modal、Button} from "imitate-component"     目前支持 message、tab、modal、button 样式上，需要在主程序上 import "imitate-component/dist/index.css"。引入全部组件的css     需要按需引入css，可以配置babel来支持。
