# icon-for-file-type

> 标签: JavaScript

## 简介

This is a module that returns uris of data, given a file extension and size. The file extensions can be: html, css, js, png, jpg, jpeg, svg, ico, gif, json, php, sql, py, txt, docx, xlsx, pptx, or mp4; and the sizes can be 16x16, 32x32, 64x64, 128x128, or
