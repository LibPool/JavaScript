# immutable-data-store

> 标签: datastore, immutable, observable

## 简介

An Observable Data Store Based on Immutable Data from [ImmutableJS](https://github.com/facebook/immutable-js). The Change detection is super performant thanks to the immutable nature of the data. This store can easily be hooked to an Observer for Granular
