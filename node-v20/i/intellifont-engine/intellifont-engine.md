# intellifont-engine

> 标签: browser-extension, document-analysis, font, font-identification, font-recognition, image-analysis, napi, pdf, rust, typography, visual-matching, wasm

## 简介

Visual font identification engine. Identifies fonts from images, documents, URLs, and web pages. Includes hybrid ML matching, browser extensions, and WASM build.
