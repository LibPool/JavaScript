# invoicegen-cli

> 标签: billing, cli, freelance, invoice, mssql, mysql, pdf, postgresql, sqlite, typescript

## 简介

A command-line invoice generator — create professional PDF invoices, manage clients and track history. Supports SQLite, PostgreSQL, MySQL and MSSQL.
