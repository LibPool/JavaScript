# i18n-auto-extractor

> 标签: extract, google-translate, i18n, internationalization, language, plugin, translation, 中文提取

## 简介

i18n-auto-extractor is an automated internationalization (i18n) tool that intelligently extracts Chinese text from projects and automatically generates files in multiple languages. It supports integration with mainstream front-end frameworks (Vue/React),
