# indonesian-badwords-check

> 标签: JavaScript

## 简介

`indonesia-badwords-check` adalah package NPM yang digunakan untuk memeriksa dan memfilter kata-kata kasar atau tidak pantas dalam Bahasa Indonesia. Package ini cocok untuk aplikasi yang memerlukan moderasi teks seperti media sosial, forum, atau platform
