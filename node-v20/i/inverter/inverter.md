# inverter

> 标签: css, i18n, internationalization, invert, inverter, ltr, rtl

## 简介

Simply translate LTR-based CSS file to RTL, or the opposite. Can be both used on the server-side with Node.js, or client-side.

- 源码仓库：git://github.com/coolony/inverter.git
- npm 页面：https://www.npmjs.com/package/inverter
