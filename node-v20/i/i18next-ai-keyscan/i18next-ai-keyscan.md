# i18next-ai-keyscan

> 标签: extraction, globalization, i18n, i18next, i18next-react, internationalization, l10n, localization, locize, scanner, translation

## 简介

i18next-ai-keyscan is an unofficial i18next key scanner that uses OpenAI. Scan your source code and extract the key/values into a JSON file.
