# indian-rail-mcp

> 标签: indian-railways, irctc, live-train-status, mcp, model-context-protocol, ntes, pnr, seat-availability, train, train-schedule

## 简介

Indian Railways data from official sources (NTES + IRCTC) — typed library and MCP server. Train schedules, live running status, trains between stations, live station boards, PNR status and berth-level seat availability.
