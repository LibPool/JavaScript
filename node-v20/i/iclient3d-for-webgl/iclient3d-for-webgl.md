# iclient3d-for-webgl

> 标签: JavaScript

## 简介

iclient3d-for-webgl（SuperMap iClient 3D for WebGL/WebGPU）基于 WebGL/WebGPU 技术实现的三维GIS客户端开发平台，可用于构建无插件、跨操作系统、 跨浏览器的三维 GIS 应用程序，可访问SuperMap iServer发布的多种服务、 实现了三维场景可视化浏览、交互操作和地理信息管理等功能。
