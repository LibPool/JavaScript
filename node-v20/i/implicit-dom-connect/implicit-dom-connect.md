# implicit-dom-connect

> 标签: addEventListener, cli, coffeescript, connect, dom, getElementById, implicit, implicit-dom-connect, pug

## 简介

A small helper toot - reading pug files to retrieve defined IDs then checks if they used in coffeescript. If they are used, the connection to the DOM is implicitly established - creating a file to be explicitly included in the build-process.
