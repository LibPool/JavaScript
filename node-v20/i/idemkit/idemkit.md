# idemkit

> 标签: agent, bullmq, consumer, crash-recovery, dedup, deduplication, effectively-once, exactly-once, express, fastify, hono, http, idempotency, idempotency-key, idempotent, kafka, llm, mcp, middleware, postgres, queue, redis, retry, retry-safe, sqs, tool-calls, webhook

## 简介

Make any operation safe to retry: crash-safe idempotency for HTTP requests, queue messages, and function calls, on Redis, Postgres, MongoDB, or DynamoDB.
