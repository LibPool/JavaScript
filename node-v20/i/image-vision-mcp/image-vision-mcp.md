# image-vision-mcp

> 标签: anthropic, claude-code, doubao, image-recognition, mcp, mcp-server, vision, vision-model

## 简介

Multi-model vision MCP server (GLM-4.6V, Kimi, Qwen-VL, GPT-4o) that lets text-only coding models in Claude Code see and understand images.
