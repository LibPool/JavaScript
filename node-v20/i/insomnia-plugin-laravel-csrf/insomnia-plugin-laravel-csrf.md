# insomnia-plugin-laravel-csrf

> 标签: csrf, insomnia, laravel, laravel-sanctum, plugin

## 简介

The insomnia plugin for setting X-XSRF-TOKEN header in request from XSRF-TOKEN cookie in laravel applications.
