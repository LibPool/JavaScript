# i18n-text-tools

> 标签: i18n, i18n-pick, i18n-tools, vue-i18n

## 简介

一个用于自动提取、管理和同步项目多语言文本的命令行工具，支持 Vue3、JS/TS 文件的国际化文本收集、唯一key生成、重复检测、与YiCAT平台集成等功能。
