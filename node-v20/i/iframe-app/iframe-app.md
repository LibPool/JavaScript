# iframe-app

> 标签: JavaScript

## 简介

## 介绍 基于原生 iframe 实现库，搭建微前端服务，体量极小，适合一般功能的微前端应用，支持，注入js，link，主子应用通信等；但是由于使用原生 iframe；一些基于 iframe 的问题无法解决；
