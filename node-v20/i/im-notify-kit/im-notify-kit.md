# im-notify-kit

> 标签: alert, bot, cloudflare-workers, feishu, lark, notification, webhook, wechat-work, wecom, zero-dependency

## 简介

飞书 / 企业微信群机器人通知的发送层：业务码校验、重试、超时、告警去重、卡片构建器。零依赖，跨 Node / Cloudflare Workers / Deno。Send layer for Feishu (Lark) & WeCom bot webhooks — biz-code aware, retrying, timeout-guarded, with alert dedupe.
