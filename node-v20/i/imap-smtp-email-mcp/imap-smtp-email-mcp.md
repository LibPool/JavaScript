# imap-smtp-email-mcp

> 标签: email, gmail, imap, mcp, outlook, smtp

## 简介

MCP server for IMAP/SMTP email operations. Works with Gmail, Outlook, 163.com, 126.com, 188.com, and any standard IMAP/SMTP server.
