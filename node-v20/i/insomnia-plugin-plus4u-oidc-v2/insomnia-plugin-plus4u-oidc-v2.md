# insomnia-plugin-plus4u-oidc-v2

> 标签: insomnia, insomnia-plugin, oauth, oidc, pkce, plus4u

## 简介

Insomnia plugin for OIDC authentication against Plus4U and custom uuOIDC servers. Implements OAuth 2.1 Authorization Code + PKCE + state + nonce, encrypted local vault (scrypt + AES-256-GCM), and opt-in ROPC for uuEE.
