# inferhub-client

> 标签: chat, inference, inferhub, llm, ollama

## 简介

Client for InferHub, a self-hosted, Ollama-compatible inference mesh — chat, generate, embeddings, retrieval/RAG, ingestion/search, audio, images, the admin plane and the node (1.0).
