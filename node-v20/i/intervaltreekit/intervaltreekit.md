# intervaltreekit

> 标签: augmented-avl, calendar, genomics, interval, interval-tree, intervaltree, overlap, range, range-query, scheduling, stabbing-query, typescript, zero-dependency

## 简介

Zero-dependency augmented interval tree for TypeScript: find all intervals overlapping a point or range in O(log n + k). Port of Python intervaltree / Java Guava RangeSet.
