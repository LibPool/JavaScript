# idmly-mcp

> 标签: claude, codex, cursor, design, html, idml, indesign, mcp, model-context-protocol

## 简介

MCP server for idmly: convert a self-contained HTML design into an editable Adobe InDesign file (.idml) from Claude Code, Cursor, Codex, Windsurf or Claude Desktop.
