# im2-link-jssdk

> 标签: JavaScript

## 简介

`im2-link-jssdk` 是 H5 小程序与宿主 App/WebView 之间的通信 SDK。Web 侧通过统一 API 请求宿主完成支付 、导航、系统分享、下载、网络请求等原生能力；SDK 负责平台识别、消息封装和回调分发。
