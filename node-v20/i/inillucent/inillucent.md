# inillucent

> 标签: cli, database, embedding, mcp, rag, search, sql, sqlite, vector

## 简介

Embedded SQL database with full-text and vector search, an MCP server, and a sqlite3-shaped shell. No native build step: the binaries ship as platform packages.
