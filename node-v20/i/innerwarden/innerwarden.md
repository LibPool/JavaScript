# innerwarden

> 标签: agent, ai, ai-agent, claude-code, codex, cursor, guardrail, llm, mcp, openclaw, prompt-injection, security

## 简介

InnerWarden Community: open-source guardrail for AI coding agents. Screens the shell commands and MCP/tool calls your agent runs and returns allow / review / deny, before it runs.
