# infraquery

> 标签: bacnet, discovery, icmp, infrastructure, iot, modbus, network, onvif, ot, ping, port-scan, prometheus, scanner, security, snmp, tcp, udp, wmi

## 简介

Open-source, Agentless network discovery and data extraction engine. Discovers, fingerprints, and maps IT, IoT, and OT devices via SNMP, Modbus, ONVIF, WMI, Prometheus, BACnet, HTTP, and more
