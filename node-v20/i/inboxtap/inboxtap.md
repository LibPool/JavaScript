# inboxtap

> 标签: capture, cypress, development, e2e, email, email-testing, fake-smtp, inbox, jest, magic-link, mail, mailbox, no-docker, otp, password-reset, playwright, smtp, smtp-server, testing, typescript, vitest

## 简介

A local email capture server and TypeScript SDK for testing verification links, magic links, OTPs, invitations, and password-reset emails.
