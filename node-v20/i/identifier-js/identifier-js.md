# identifier-js

> 标签: IRI, IRI-reference, RFC3986, RFC3987, RFC8141, URI, URI-reference, URN, ipv4, ipv6, parser, uuid, validator

## 简介

A fast RFC 3986/3987 URI/IRI parser, validator, normalizer, resolver, and reference converter.
