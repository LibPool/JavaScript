# interchange-dsh

> 标签: deepseek-harness, dsh, interchange, plugin, sidecar, webhook

## 简介

Interchange 本地优先协同工具（角色化转化/知识沉淀/协同发送）的 DeepSeek Harness 插件：宿主侧服务生命周期管理 + interchange_* 模型工具 + 设置面板（内嵌 Web 应用）。
