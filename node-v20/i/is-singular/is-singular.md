# is-singular

> 标签: check, english, form, grammar, inflect, lang, language, plural, pluralize, singular, singularize, test, tool, util, validate, word, words

## 简介

Return true if given word is in singular form like `apple`, `car`, `test` and false otherwise, never throws.
