# instantsearch.js

> 标签: JavaScript

## 简介

InstantSearch.js is a JavaScript library for building performant and instant search experiences with Algolia.

- 源码仓库：git+https://github.com/algolia/instantsearch.git
- npm 页面：https://www.npmjs.com/package/instantsearch.js
