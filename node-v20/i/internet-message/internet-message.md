# internet-message

> 标签: imf, rfc2045, rfc2046, rfc2047, rfc2048, rfc2049, rfc2822, rfc733, rfc822

## 简介

Parse and stringify RFC 822 ARPA Internet Text Messages. Useful format for messages with headers and body. Similar to HTTP.
