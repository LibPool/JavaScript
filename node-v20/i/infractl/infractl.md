# infractl

> 标签: artifact-registry, cli, cloud-run, cloud-sql, cloud-storage, compute-engine, declarative, deploy, devops, gcp, gcs, google-cloud, iac, idempotent, infrastructure, multi-environment, netlify, secret-manager, workload-identity

## 简介

Declarative infrastructure CLI for GCP. Define your Cloud Run services, Cloud SQL databases, VMs, buckets, and secrets in YAML — infractl handles the rest.
