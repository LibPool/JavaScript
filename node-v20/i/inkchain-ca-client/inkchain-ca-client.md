# inkchain-ca-client

> 标签: JavaScript

## 简介

SDK for writing node.js applications to interact with [Inklabsfoundation Inkchain CA](http://inklabsfoundation-inkchain.readthedocs.io/en/latest/Setup/ca-setup.html).
