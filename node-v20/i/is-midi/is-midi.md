# is-midi

> 标签: audio, binary, buffer, check, detect, file-type, is, magic-bytes, mid, midi, music, riff, rmi, smf, type, uint8array

## 简介

Check if a Buffer/Uint8Array is a MIDI file (supports standard MIDI and RIFF MIDI/.rmi)
