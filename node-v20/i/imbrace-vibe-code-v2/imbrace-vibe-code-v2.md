# imbrace-vibe-code-v2

> 标签: cli, deploy, faas, fission, hono, imbrace, serverless, vite

## 简介

Create, deploy and run apps on iMBRACE vibe-fission: scaffold React/Vite + Hono (or py/js/go scripts), upload the source, the cluster builds it and serves it at http://<app>.vibe.<env>.imbrace.co/.
