# ichina-channeltalk-plugin

> 标签: JavaScript

## 简介

iCHINA 모바일 에플리케이션 채널톡 전용 React Native 플러그인입니다. TypeScript로 작성되었기 때문에 `npx tsc`를 통해 Js파일로 변환해줘야합니다.
