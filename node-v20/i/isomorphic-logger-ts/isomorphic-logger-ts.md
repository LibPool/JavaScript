# isomorphic-logger-ts

> 标签: browser, isomorphic, logger, nodejs

## 简介

Lightweight isomorphic logger for Next.js and various runtimes (browser, Node.js, serverless). Provides a consistent logging interface for both client and server, with automatic environment detection.
