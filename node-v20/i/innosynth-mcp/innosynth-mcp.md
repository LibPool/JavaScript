# innosynth-mcp

> 标签: ai, browser-automation, claude, headless-chrome, innosynth, local, mcp, openai, playwright, stagehand

## 简介

MCP server for AI browser automation using Stagehand - supports LOCAL mode without Browserbase cloud. Fork with custom OpenAI endpoint support.
