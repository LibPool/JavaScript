# insight-ui-polis

> 标签: bitcore-polis, blockchain, blockexplorer, front-end, insight, polis

## 简介

An open-source frontend for the Insight API. The Insight API provides you with a convenient, powerful and simple way to query and broadcast data on the Polis network and build your own services with it.
