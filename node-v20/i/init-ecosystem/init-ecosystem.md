# init-ecosystem

> 标签: authentication, bitbucket, cli, ecosystem, fnm, launcher, node-version, nvm

## 简介

Interactive project launcher with automatic Node version switching, shared Bitbucket authentication, and AES-256-GCM encrypted credential storage
