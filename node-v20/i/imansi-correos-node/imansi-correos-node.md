# imansi-correos-node

> 标签: 2fa, autenticacion, auth, correos, email, espanol, imansi, nodemailer, plantillas, smtp, spanish, templates

## 简介

Plantillas de correo reutilizables en español con envío SMTP integrado. HTML responsive compatible con Gmail, Outlook y Apple Mail.
