# imprnt-plugin-anti-slop

> 标签: anti-slop, imprnt, imprnt-plugin, writing

## 简介

imprnt plugin: universal anti-AI-slop rules (banned punctuation, words, phrases, rhetorical patterns) for any prose the agent produces.
