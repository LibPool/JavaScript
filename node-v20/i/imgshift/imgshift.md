# imgshift

> 标签: alteration, assets, checksum, image

## 简介

CLI utility to slightly alter image assets to change their checksums while keeping visual changes imperceptible

- 官网：https://github.com/sincerely-manny/imgshift
- 源码仓库：git+https://github.com/sincerely-manny/imgshift.git
