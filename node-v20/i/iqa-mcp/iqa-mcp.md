# iqa-mcp

> 标签: agents, attestation, iqa, mcp, offline, rttp

## 简介

Launcher for the IQA attestation MCP server (wraps the Python package iqa-mcp on PyPI). Spawns the installed iqa-mcp console script, a server.py checkout, or an IQA_MCP_CMD override.

## 官网

- 官网：https://iqa.org/MCP/
- 源码仓库：git+https://github.com/Aicent-Stack/iqa-mcp.git
