# iipc

> 标签: communication, exchange, interchange, interprocess, ipc, message, msg, node, node-ipc, port, tcp, websocket

## 简介

iipc is a simple Inter Process Communication for nodejs to communicate between processes safely and easily using tcp and websocket.
