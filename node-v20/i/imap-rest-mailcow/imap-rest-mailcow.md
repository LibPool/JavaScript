# imap-rest-mailcow

> 标签: addon, imap, mailcow, mcp, mistral, model-context-protocol, ocr, rest

## 简介

Stateless REST facade for IMAP, designed as a third-party addon for mailcow-dockerized. Optional Mistral OCR for attachments.
