# invoice-generator-mcp

> 标签: accounting, billing, freelancer, invoice, mcp, pdf, quote, receipt

## 简介

MCP server for the Professional Invoice Generator — lets AI agents create pre-filled invoices with line items, taxes, discounts, 14 languages, and 10 colour themes.
