# isitdone

> 标签: ai-agent, claude-code, codex, coding-agent, cursor, gemini-cli, hooks, stop-hook, tests, verification

## 简介

Short name for @aivolution/isitdone: don't let your coding agent say "done" until the tests actually pass. `npx isitdone init` installs the Stop hook for Claude Code, Codex, Cursor and Gemini CLI.
