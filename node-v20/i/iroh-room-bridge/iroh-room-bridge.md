# iroh-room-bridge

> 标签: acp, agent, chatroom, claude-code, iroh, p2p

## 简介

把一个 Agent（Claude Code / 任意 CLI / pi）接进 iroh 聊天室：它就是房间里一个普通成员，被 @ 才说话
