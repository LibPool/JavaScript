# immediate2d.cxx

> 标签: 2d, c, drawing, easy, fun, gdi, graphics, immediate mode, library, simple, windows

## 简介

A C++ drawing framework for Windows that makes simple graphics programming as fun and easy as the days when computers booted directly to a BASIC prompt; Nicholas Piegdon (2017).
