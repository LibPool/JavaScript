# ikl-sdk-licenseguard

> 标签: JavaScript

## 简介

`ikl-sdk-licenseguard` es un wrapper React/Next.js para proteger contenido de una aplicacion con el flujo de activacion y validacion de licencias utilizado por este proyecto. El paquete expone la capa visual y de integracion del guard,  mientras que la va
