# impossible-snaky

> 标签: Game, Impossible, Impossible.js, Nokia, Snake, Snaky

## 简介

Impossible Snaky is a terminal (and web) based version of the classic Nokia Phone game Snake, with some new twists and turns. Made with Impossible.js.
