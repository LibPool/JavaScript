# imgpresso

> 标签: JavaScript

## 简介

**A blazing-fast, local image optimizer CLI built with Node.js + TypeScript.**   Compress JPG, PNG, WebP, AVIF, and TIFF images without using any external APIs (no TinyPNG, no limits).
