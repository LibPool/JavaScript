# ink-uplot

> 标签: ascii-chart, chafa, chart, charts, cli, cli-chart, dashboard, dataviz, graph, ink, ink-component, iterm2, kitty, kitty-graphics-protocol, plot, react, sixel, terminal, terminal-charts, terminal-graphics, time-series, trading, truecolor, tui, typescript, unicode, uplot, visualization

## 简介

Render uPlot charts in the terminal with React Ink — truecolor Unicode block art plus native kitty, sixel, and iTerm2 graphics protocols. Line charts, time series, and live dashboards for the CLI.
