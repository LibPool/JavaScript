# is-typed-array

> 标签: @@toStringTag, ES6, Float32Array, Float64Array, Int16Array, Int32Array, Int8Array, Symbol.toStringTag, TypedArray, Uint16Array, Uint32Array, Uint8Array, Uint8ClampedArray, array, is, toStringTag, typed, typed array

## 简介

Is this value a JS Typed Array? This module works cross-realm/iframe, does not depend on `instanceof` or mutable properties, and despite ES6 Symbol.toStringTag.
