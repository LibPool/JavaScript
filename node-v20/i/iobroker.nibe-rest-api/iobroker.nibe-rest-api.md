# iobroker.nibe-rest-api

> 标签: Nibe, S1155, heatpump, ioBroker, iot

## 简介

Read and write datapoints of your Nibe Heatpump via REST API (integrated from Firmware 4.6.4). Developed with my Nibe S1155.
