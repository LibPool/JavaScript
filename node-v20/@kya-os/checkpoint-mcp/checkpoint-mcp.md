# @kya-os/checkpoint-mcp

> 标签: agent, audit, checkpoint, kya-os, mcp, model-context-protocol, observability

## 简介

Wire a self-hosted KYA-OS MCP server into Checkpoint: register it as a server, publish its tool catalog, and report every tool dispatch attributed to it.
