# @ths-fe-cli/lego-to-vite-converter

> 标签: cli, converter, lego, micro-app, ths, vite, vue3

## 简介

把低代码平台（一张图/lego）导出的纯静态 Vue 3 项目，一键转换为 Vite + 单文件 .vue 工程，并接入 micro-app 微前端基座。
