# @imagineartofficial/mcp

> 标签: ai, cli, image-generation, imagine, imagineart, mcp, model-context-protocol, video-generation

## 简介

Connect the Imagine MCP server (mcp.imagine.art) to Claude, Cursor, Codex, Hermes, OpenClaw and any MCP client. Login once, install everywhere.
