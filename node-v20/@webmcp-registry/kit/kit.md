# @webmcp-registry/kit

> 标签: agents, ai, browser, mcp, model-context-protocol, react, tools, webmcp, zod

## 简介

Define and register WebMCP tools with Zod schemas, React hooks, and a CLI that syncs them to the WebMCP Registry.
