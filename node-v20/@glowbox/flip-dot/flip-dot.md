# @glowbox/flip-dot

> 标签: display, dithering, electromechanical, flip-disc, flip-dot, flipdot, glowbox, retro

## 简介

Electromechanical flip-dot board component — physical disc flips, scan-wave stagger, dithering, optional solenoid click, in the glowbox family.
