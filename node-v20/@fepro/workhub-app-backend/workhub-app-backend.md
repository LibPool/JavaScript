# @fepro/workhub-app-backend

> 标签: backend, saas, sdk, server, tenant, workhub

## 简介

Server-side SDK for WorkHub developer workspaces. defineWorkspace() to declare routes + scopes; run() boots a JWT-verifying HTTP server that the WorkHub proxy calls into.
