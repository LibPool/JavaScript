# @elfa-ai/sdk

> 标签: analytics, api, chat, crypto, elfa, intelligence, mentions, narratives, sdk, social, telegram, trading, twitter, typescript

## 简介

Official TypeScript SDK for the Elfa API v2 and v3 - social intelligence, AI chat, the Auto condition engine, and v3 events, calls and market data for crypto and equities
