# @yakavkaz/uikit

> 标签: JavaScript

## 简介

**@yakavkaz/uikit** — это UI-kit, разработанный для проектов экосистемы Yakavkaz.   Он предоставляет готовый набор компонентов на **React + TypeScript**, стилизованных с помощью **TailwindCSS**, для быстрой и единообразной разработки интерфейсов.
