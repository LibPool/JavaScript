# @cpulvermacher/vite-plugin-handlebars

> 标签: handlebars, vite, vite-plugin

## 简介

A maintenance fork of @yoichiro/vite-plugin-handlebars that makes Vite a peer dependency and keeps things up to date. Use `1.4.x` as a drop-in replacement for the original plugin (supports Vite 5-8), or `1.5.x` for slightly faster builds (supports Vite 6.
