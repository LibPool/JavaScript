# mysql2-mcp-server

> 标签: ai-tools, database, mcp, model-context-protocol, mysql, mysql2, ssh-tunnel

## 简介

MySQL MCP server that enables AI assistants to interact with MySQL databases. Supports direct connection, SSH tunnel, connection pool, transactions, and security enforcement.
