# @mnemosyne_os/mcp

> 标签: agent-awareness, ai, layer2, local-ai, mcp, memory, mnemosyne, model-context-protocol, observability, sovereign, transcripts

## 简介

MCP server for Mnemosyne OS. Gives AI agents access to vault memory, resonances, git context, and to what the other coding agents on this machine are doing.
