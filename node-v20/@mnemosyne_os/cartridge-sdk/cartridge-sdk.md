# @mnemosyne_os/cartridge-sdk

> 标签: cartridge, iframe, local-ai, memory, mnemosyne, plugin, postmessage, sdk

## 简介

Official Cartridge SDK for Mnemosyne OS. A secure postMessage bridge for sandboxed in-app cartridges, the iframe widgets on the canvas. The one canonical MnemoCartridgeSDK.
