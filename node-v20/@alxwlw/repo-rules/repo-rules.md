# @alxwlw/repo-rules

> 标签: JavaScript

## 简介

Whole-repo lint rules from the alxwlw defect corpus — long files, unjustified suppressions, skipped/focused tests, Number(x) || <default>, removed assertions — with a shrink-only baseline.
