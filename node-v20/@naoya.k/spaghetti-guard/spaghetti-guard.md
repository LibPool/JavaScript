# @naoya.k/spaghetti-guard

> 标签: JavaScript

## 简介

AIエージェント（Antigravity、Cursor、Aiderなど）を用いた開発において、コードの「スパゲッティ化」を、仕様・アーキテクチャテスト・カバレッジ駆動テストの3段で防ぐための、プロジェクトへの一度きりのセットアップCLIです。
