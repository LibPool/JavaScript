# @openleaf-editor/plugins-highlight

> 标签: JavaScript

## 简介

Opt-in syntax highlighting and HTML formatting for OpenLeaf: coloured code blocks and a formatted, highlighted source view. Ships a small built-in tokenizer for HTML/CSS/JS and a seam for Prism, refractor or highlight.js.
