# @hasdata/google-flights-mcp

> 标签: flights, google-flights, google-flights-mcp, hasdata, mcp, model-context-protocol, scraper, travel

## 简介

MCP server for Google Flights through HasData's hosted API: one-way, round-trip and multi-city itineraries with fares, legs, carbon emissions and price history. 1,000 free credits every month.
