# @hasdata/google-flights-deals-mcp

> 标签: fares, flight-deals, google-flights, hasdata, mcp, model-context-protocol, scraper, travel

## 简介

MCP server for Google Flights Deals through HasData's hosted API: turn a plain-language trip description into dated flight deals with prices, discounts, airlines and booking links. 1,000 free credits every month.
