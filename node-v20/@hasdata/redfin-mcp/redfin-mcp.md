# @hasdata/redfin-mcp

> 标签: hasdata, mcp, mls, model-context-protocol, property-data, real-estate, redfin, redfin-mcp, scraper

## 简介

MCP server for Redfin through HasData's hosted API: search for-sale, for-rent and sold listings with the full filter set, and read one property page in full. No MLS licence, no broker account. 1,000 free credits every month.
