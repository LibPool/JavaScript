# @hasdata/bing-mcp

> 标签: bing, bing-mcp, hasdata, mcp, model-context-protocol, scraper, search-engine, seo, serp

## 简介

MCP server for Bing search through HasData's hosted API: organic results, the ad block where Bing shows one, and the Copilot answer, with geo, market and language targeting. No Azure subscription. 1,000 free credits every month.
