# @zentiq/node

> 标签: ai, avatar, livekit, sdk, talking-head, zentiq

## 简介

Official Node.js SDK for the Zentiq AI avatar API (server-side): manage personas, voices, avatars, mint session tokens, steer live sessions, and verify webhooks.
