# @mazzen.emad/photoeditor

> 标签: JavaScript

## 简介

A simple photo editor built enabling users to upload, edit, and combine photos with themes, and download the final product. The editor allows for manipulation of images, resizing, moving, and adding overlay themes, as well as toggling between editor mode
