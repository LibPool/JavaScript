# @cardano402/core

> 标签: ada, agent, cardano, facilitator, mcp, payment, stripe-for-agents, x402, zod

## 简介

Schemas, types, header codec, and FacilitatorClient for x402 payments on Cardano. Zero-runtime-dep core (except zod) for clients, resource servers, and MCP tooling.
