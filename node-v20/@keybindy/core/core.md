# @keybindy/core

> 标签: framework-agnostic, hotkeys, keybind, keybinding, keyboard, shortcut, shortcut-engine, shortcut-manager, typescript, web

## 简介

A lightweight and framework-agnostic keyboard shortcut manager for web apps. Define, register, and handle keybindings with ease.
