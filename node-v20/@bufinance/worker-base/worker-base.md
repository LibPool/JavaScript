# @bufinance/worker-base

> 标签: auth, bufi, cloudflare-workers, cors, hono, middleware

## 简介

Shared Hono middleware for Cloudflare Workers: bearer-token auth composition, configurable CORS, and a standard error-handler + request-context contract.
