# @dataflow-animator/element

> 标签: animation, custom-element, dataflow, diagram, framework-agnostic, teaching, vanilla, visualization, web-component

## 简介

<dataflow-player> custom element for @dataflow-animator/core: compiles a JSON specification into a deterministic, scrubbable animation of data flows, in any framework or none.
