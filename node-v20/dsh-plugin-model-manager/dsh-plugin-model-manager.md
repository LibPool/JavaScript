# dsh-plugin-model-manager

> 标签: deepseek-harness, dsh-plugin, llm-router, model-router, model-routing, mybuddy

## 简介

DSH 模型管家：按任务特征自动为每一步选择性价比最优的模型（快速/均衡/极致三档），并把每次选型显示在对话角标上
