# @designtoolkit/mcp

> 标签: animation, browser, claude, css, cursor, design, mcp, modelcontextprotocol

## 简介

Give your AI coding agent the real numbers behind any web page: sizes, spacing, type, colors and the animation timings a screenshot can't carry. Bridges the Design Toolkit browser extension to Claude Code, Cursor, Windsurf and any MCP client.
