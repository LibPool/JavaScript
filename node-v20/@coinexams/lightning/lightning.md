# @coinexams/lightning

> 标签: Bitcoin, CoinExams, LNURL-pay, Lightning Network, Lightning invoice, Nostr, Phoenixd, SDK, TypeScript, Zap, bech32, bitcoin-lightning, kind-9735, npub, nsec, self-custodial

## 简介

Self-custodial Bitcoin Lightning Network client for Node.js — invoices, payments, balances, LNURL-pay addresses and Nostr Zap receipts via a local Phoenixd node.
