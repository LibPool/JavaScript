# @subdomainto/node

> 标签: custom-domains, dns, domain-management, nodejs, saas, ssl, tls, typescript, webhooks

## 简介

Typed Node.js SDK for adding customer custom domains to SaaS products with DNS, TLS, routing, widget, usage, and signed webhook APIs.
