# @noah-medra/htsl-core

> 标签: ast, html, htsl, lexer, markup, parser, renderer

## 简介

HTSL (HyperText Structured Language) — declarative markup engine for math/physics documents: parser, renderer and runtime that compiles to HTML through an AST.
