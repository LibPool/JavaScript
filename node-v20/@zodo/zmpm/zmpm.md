# @zodo/zmpm

> 标签: atmosphere, atmosphere-alternative, cli, devtools, github-releases, meteor, meteor-packages, meteorjs, nodejs, npm, package-manager, private-packages, vendor, vendoring

## 简介

Zodo Meteor Package Manager — vendor Meteor packages into an app's packages/ dir from GitHub Releases or any tarball URL, with auth and transitive-dependency resolution. A generic alternative to Atmosphere for private/self-hosted packages.
