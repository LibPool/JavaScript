> 标签: ai, anthropic, ast, changelog, cli, code-analysis, developer-tools, documentation, generator, jsdoc, mermaid, ollama, openai, readme, typescript

## 简介

AI-powered documentation generator for codebases. Analyzes code via AST parsing and LLM to generate README, API docs, JSDoc, CHANGELOG, and architecture diagrams.
