# @hardhat-kms/turnkey

> 标签: ethereum, ethers, hardhat, hardhat-kms, hardhat-plugin, hardhat3, kms, remote-signer, secp256k1, signer, smart-contracts, turnkey, viem, wallet

## 简介

Turnkey signer for Hardhat 3 (hardhat-kms provider): signs with a Turnkey wallet account through Turnkey's API, with an API key stamp.
