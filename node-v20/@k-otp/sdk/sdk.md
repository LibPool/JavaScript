# @k-otp/sdk

> 标签: alimtalk, headless-ui, k-otp, korea, one-time-password, orpc, otp, otp-input, react, sms, svelte, verification, vue

## 简介

Official K-OTP (Korean OTP API) SDK: issue and verify one-time passwords from browsers, SSR, edge and servers, with React, Vue and Svelte bindings, headless UI components with an optional theme, and a CDN bundle.
