# @map-gesture-controls/leaflet

> 标签: a11y, accessibility, browser, computer-vision, gesture-control, gesture-navigation, gesture-recognition, gis, hand-gesture, hand-gestures, hand-tracking, hands-free, interaction, kiosk, leaflet, leaflet-map, leaflet-plugin, leafletjs, map, map-controls, maps, mediapipe, no-touch, touchless, touchless-navigation, wasm, webcam

## 简介

Control Leaflet maps with hand gestures via MediaPipe webcam hand tracking. Pan, zoom, and rotate with no backend.
