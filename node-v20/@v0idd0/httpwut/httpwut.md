# @v0idd0/httpwut

> 标签: api, cli, curl, debug, debugger, diff, http, https, redirects, request, rest, testing, timing, ttfb, voiddo

## 简介

httpwut — HTTP request debugger. Why isn't my request working? Show DNS/TCP/TLS timing, follow redirects, diff endpoints, retry on 5xx, emit curl or JSON. Free forever from vøiddo.
