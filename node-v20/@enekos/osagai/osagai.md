# @enekos/osagai

> 标签: brutalist, components, dark-mode, design-system, svelte, svelte5, ui

## 简介

A small, dependency-free component kit for Svelte 5: buttons, fields, menus, dialogs, toasts, tooltips, tables, an imperative confirm, query/task/draft helpers, keyboard shortcuts and clipboard copy, themed by CSS variables with light and dark built in.
