# @pi-in-go/pigpen-rpiv-web-tools

> 标签: extension, fetch, ollama, pig-package, pigpen, search, searxng, web-fetch, web-search

## 简介

Go port of @juicesharp/rpiv-web-tools: web_search over ten backends (Brave, Tavily, Serper, Exa, You.com, Jina, Firecrawl, Perplexity, SearXNG, Ollama), web_fetch and /web-tools; nothing starts until a tool runs
