# @pi-in-go/pigpen-aot-runtime

> 标签: aot, extension, pig-package, pigpen, runtime

## 简介

The aot TypeScript runtime slot for PiG (Go): compiles a session's TypeScript extensions into one executable in the background and runs it from the next start.
