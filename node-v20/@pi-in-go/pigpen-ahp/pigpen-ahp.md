# @pi-in-go/pigpen-ahp

> 标签: agent-host-protocol, ahp, extension, pig-package, pigpen, remote

## 简介

Go port of pi-ahp: serves the running PiG session to remote Microsoft Agent Host Protocol clients over WebSocket, with reconnect and auth. No listener unless you ask; no remote filesystem or terminal unless you opt in
