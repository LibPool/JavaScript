# @pi-in-go/pigpen-hardening

> 标签: enterprise, hardening, library, pig-package, pigpen, security

## 简介

Shared Go library for the opt-in enterprise profile of Pigpen Packages: profile loading, per-request credential files, an allow-listed egress transport, closed-field audit events, headless helpers, a fail-closed policy Decider (Cedar in a nested module) a
