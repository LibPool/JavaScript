# @pi-in-go/pigpen-a2a

> 标签: a2a, agent2agent, extension, kagent, pig-package, pigpen, protocol

## 简介

A2A (Agent2Agent) for PiG: serve PiG tasks to A2A agents and call remote A2A agents, on the upstream Go SDK a2a-go. The listener is off unless configured.
