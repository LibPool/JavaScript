# @kiwa-test/fresh

> 标签: deno, fresh, head, islands, kiwa, meta, partial-hydration, route-handler, testing, vitest

## 简介

Deno Fresh Islands + Route Handler + Head normalization test adapter for kiwa — invoke Fresh Handler / defineRoute without a Deno runtime, capture partial-hydration Island mounts, and merge Head fragments (meta / title / link) for assertion-based testing
