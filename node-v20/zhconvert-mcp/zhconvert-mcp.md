# zhconvert-mcp

> 标签: chinese, conversion, dawn-studio, mcp, model-context-protocol, opencc, s2hk, s2t, s2tw, simplified, t2s, traditional, zhconvert

## 简介

MCP server for ZhConvert — Simplified <-> Traditional Chinese conversion with OpenCC configs (s2t, s2tw, s2hk, s2twp, t2s, …) for Claude and other MCP clients. By Dawn Studio.
