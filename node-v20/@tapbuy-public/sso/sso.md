# @tapbuy-public/sso

> 标签: auth, checkout, cookie, single-sign-on, sso, tapbuy, typescript

## 简介

Framework-agnostic SSO handler for Tapbuy checkout — decrypts an encrypted token from a query param and sets/deletes auth cookies accordingly
