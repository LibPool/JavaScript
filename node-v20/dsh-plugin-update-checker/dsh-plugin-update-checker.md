# dsh-plugin-update-checker

> 标签: deepseek, deepseek-harness, dsh, dsh-plugin, plugin-manager, update-checker

## 简介

A DeepSeek Harness plugin that adds a "Check updates" button to the Plugins settings section: it scans every installed plugin bundle for published updates and evaluates its peer-dependency compatibility against the running DSH runtime.
