# @vat-office/pdf

> 标签: pdf, pdf-preview, pdfjs, vat-office, vue, vue-office, vue3

## 简介

基于 vue-office 二次开发的 Vue PDF 预览组件，底层基于 pdf.js，支持自定义 worker 路径与缩放控制。
