# finger-gestures

> 标签: four-finger, gesture, multi-finger, multi-touch, pointer-events, redo, swipe, tap, three-finger, touch, two-finger, undo

## 简介

Multi-finger taps and swipes for the web, built on Pointer Events. Two-finger tap to undo, three-finger swipe up, four-finger tap: any finger count, any direction. Zero dependencies.
