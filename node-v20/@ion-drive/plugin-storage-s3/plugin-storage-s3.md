# @ion-drive/plugin-storage-s3

> 标签: ion-drive, minio, plugin, r2, s3, storage

## 简介

Ion Drive plugin: S3-compatible storage provider — swaps the platform's filesystem blob store for AWS S3, MinIO, Cloudflare R2, or any S3-compatible endpoint, with pre-signed download URLs.
