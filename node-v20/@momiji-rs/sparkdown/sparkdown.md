# @momiji-rs/sparkdown

> 标签: JavaScript

## 简介

Fast, standards-first CommonMark → HTML (100% CommonMark 0.31.2), as WASI-free WebAssembly — zero dependencies, runs in Node/browsers/bundlers/Deno/edge. GitHub Flavored Markdown via the `/gfm` subpath; every extension via `/full`; a ~80× faster drop-in r
