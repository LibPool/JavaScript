# @anubhav-cap-js/mongo

> 标签: Atlas, BTP, CAP, CDS, MongoDB, SAP, anubhav trainings, cds-plugin, database

## 简介

CDS database service for MongoDB and MongoDB Atlas - use MongoDB as the persistence of SAP CAP (Node.js) applications, with hardcoded credentials or SAP BTP destinations.
