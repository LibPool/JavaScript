# @sealpixel/svelte

> 标签: JavaScript

## 简介

Svelte 5 bindings for the Sealpixel image editor: <SealpixelEditor> with a bindable editLog and createSealpixelStore for headless use.

## 官网

- 官网：https://docs.sealpixel.dev
- 源码仓库：git+https://github.com/9feet/sealpixel.git
