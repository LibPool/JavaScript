# @applicature/ngx-web3-synergy

> 标签: angular, angular2, ng, ng2, ngx, web3, web3.js

## 简介

This library was created and maintained by [**Applicature**](https://applicature.com/) to help create a front-end on any blockchain projects for ourselves, our partners or any blockchain developer. This library supports Angular from version 13 and higher.
