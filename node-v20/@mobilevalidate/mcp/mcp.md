# @mobilevalidate/mcp

> 标签: ai agents, api client, carrier lookup, claude, cursor, email verification, hlr, mcp, mcp server, model context protocol, phone validation, spam reputation, whatsapp check

## 简介

MobileValidate MCP server (stdio + Streamable HTTP): let AI agents check phone numbers on WhatsApp, Telegram and more, carrier, spam reputation and e-mails.
