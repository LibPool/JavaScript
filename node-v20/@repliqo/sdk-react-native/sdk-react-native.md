# @repliqo/sdk-react-native

> 标签: analytics, heatmaps, react-native, repliqo, screen-capture, session-replay, uxcam

## 简介

Session replay & analytics SDK for React Native. Captures screenshots (including modals/alerts), navigation, screen visits, and custom events.
