# @deeblr/auth-session

> 标签: JavaScript

## 简介

Session Manager and session-strategy infrastructure for Deeblr Auth: memory/database strategies, device tracking, expiration, and the SessionStrategy contract custom strategies (e.g. @deeblr/auth-jwt) implement.
