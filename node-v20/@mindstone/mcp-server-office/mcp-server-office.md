# @mindstone/mcp-server-office

> 标签: JavaScript

## 简介

Microsoft Office (Word, Excel, PowerPoint) MCP server for Model Context Protocol hosts. Bundles the stdio MCP server, the Office add-in sidecar, and the add-in task pane assets.
