# @numueg/theme-kit

> 标签: byot, ecommerce, helpers, i18n, numu, storefront, theme, utils

## 简介

Pure, React-free helpers shared across NUMU V3 storefront themes — i18n defaults, setting-value guards, money formatting, and image transforms.
