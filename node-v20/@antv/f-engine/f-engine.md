# @antv/f-engine

> 标签: JavaScript

## 简介

FEngine 是 AntV F 系列可视化引擎的底层渲染引擎，为移动端提供了一套完整的渲染、事件、动画能力，能方便的构建可视化 UI

## 官网

- 官网：https://github.com/antvis/FEngine
- 源码仓库：git+https://github.com/antvis/FEngine.git
- npm 页面：https://www.npmjs.com/package/@antv/f-engine
