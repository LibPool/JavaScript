# @miraiclip/mcp

> 标签: ai, claude, llm, mcp, model-context-protocol, video, video-editor

## 简介

MCP server for Miraiclip: let Claude, Codex, or any MCP client edit a video project through the command catalog — with frame previews so the agent sees its edits, and export to file.
