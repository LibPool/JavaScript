# @rabbat/react

> 标签: JavaScript

## 简介

Rabbat's React adapter: the rabbatReact() Vite plugin, server-side rendering that preloads reactive Rabbat queries, and the client router (Link, useRouter, useParams, usePage, and the <Meta> head component).
