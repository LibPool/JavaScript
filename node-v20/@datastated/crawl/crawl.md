# @datastated/crawl

> 标签: ai, analytics, claudebot, crawler, datastated, googlebot, gptbot, middleware

## 简介

Report search engine and AI crawler visits from your own server to DataStated. Zero dependencies; Next.js, Express, Hono, Cloudflare Workers, or any fetch.
