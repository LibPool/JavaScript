# @stack_layout/tetris-ui

> 标签: blocks, components, dashboard, design-system, glassmorphism, grid, layout, react, responsive, spatial, tetris, ui

## 简介

Spatial React UI — priority-packed blocks that fall, stack, lock, and clear. Glass cards, responsive sizeAt/shapeAt/layoutAt, tetromino ShapeFrames.
