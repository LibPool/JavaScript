# @k4black/hex-cli

> 标签: agents, cli, command-line-utilities, development-tools, llm, orchestration, workflow

## 简介

hex: a thin, deterministic control plane that runs agent CLIs (Claude Code, Codex, Pi, opencode) over a bounded, journaled graph
