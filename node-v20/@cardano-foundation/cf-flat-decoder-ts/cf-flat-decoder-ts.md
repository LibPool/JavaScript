# @cardano-foundation/cf-flat-decoder-ts

> 标签: binary, browser, decoder, flat, javascript, node, typescript

## 简介

This package aims to offer a simple and fast method for decoding flat binary-encoded data using TypeScript and plain JavaScript, suitable for both node.js and browser
