# @windagency/valora-runtime

> 标签: runtime, shared, utilities, valora

## 简介

Pure-leaf runtime utilities shared across Valora packages: path resolution, ID generation, minimal error and logger types. Has no host dependencies — safe to consume from any plugin package.
