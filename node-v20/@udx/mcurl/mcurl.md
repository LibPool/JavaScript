# @udx/mcurl

> 标签: ai-tools, cli, curl, html, json, markdown, searchapi, site-map, web-scraping, web-search, yaml

## 简介

curl for markdown — fetch any URL as clean Markdown, search the web, and map domains. Pipe to mq for jq-like querying.
