# @wjj-8283/dsh-web-fetch-fakeip

> 标签: clash, deepseek-harness, dsh, fake-ip, mihomo, plugin, tun, web-fetch

## 简介

DSH 插件：让 web_fetch 在 Clash / mihomo 的 TUN + fake-ip 模式下正常工作。只豁免 fake-ip 保留段（198.18.0.0/15、fdfe:dcba:9876::/64、2001:2::/48），其余 SSRF 防护不变；不需要任何代理环境变量或 Clash 改动。
