# @olundot/eslint-plugin-tokens

> 标签: design-tokens, eslint-plugin, olun, tailwindcss

## 简介

ESLint plugin for OLUN design tokens — blocks arbitrary `[var(--xxx)]` in JSX className, enforcing exposed Tailwind utilities instead.
