# dsh-system-fonts

> 标签: appearance, deepseek, deepseek-harness, dsh, dsh-plugin, font, fonts, typography, windows

## 简介

DeepSeek Harness 的纯字体插件：把内容/代码/终端三个系统字体选择器放进通用设置里宿主可折叠的字体区（分别紧跟官方族名行，折叠时一并收起），按字体族枚举 Windows 已装字体，另带行距与字距；字重与字号归宿主主题，文案随宿主语言切换。只改字体，不动配色与版式。 / Pure font plugin for DeepSeek Harness: seats text/code/terminal system-font pickers inside the host's collapsibl
