# @vennyx/soliconfig-vue

> 标签: ab-testing, composable, feature-flags, remote-config, soliconfig, vennyx, vue

## 简介

Vue 3 bindings for soliconfig Remote Config — createSoliRemoteConfig plugin + useSoliConfigValue/useSoliRemoteConfig composables with live A/B custom signals and matchedCondition.
