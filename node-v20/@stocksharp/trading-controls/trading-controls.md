# @stocksharp/trading-controls

> 标签: blotter, dom, market-data, orders, positions, stocksharp, terminal, trading, typescript, watchlist

## 简介

Browser trading controls for StockSharp: order blotters, positions, trade history, watchlist and trade feed, each built against one host port and rendering its own DOM.
