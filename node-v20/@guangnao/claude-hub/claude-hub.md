# @guangnao/claude-hub

> 标签: anthropic, api, claude, hub, load-balancer, messages, pool

## 简介

Pool many claude subscription nodes behind one Anthropic-compatible /v1/messages endpoint. Star topology: nodes dial out, the hub load-balances.
