# @ilingo/vuelidate

> 标签: i18n, ilingo, internationalization, locale, translation, typescript, validation, validation-messages, vue, vue3, vuelidate

## 简介

Vuelidate message adapter for ilingo — drop-in localized validator messages (EN/DE/FR/ES) for Vue 3 forms.
