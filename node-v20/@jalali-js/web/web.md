# @jalali-js/web

> 标签: calendar, custom-elements, date, date-picker, datepicker, farsi, jalali, jalali-calendar, persian, shamsi, vanilla-js, web-components

## 简介

Framework-agnostic Web Components for jalali-js: a headless Calendar grid and a default-styled DatePicker, usable from plain HTML/JS or any framework.
