# @appydave/appysentinel-core

> 标签: appydave, appysentinel, bun, collector, node, observability, sentinel, signal, telemetry

## 简介

AppySentinel runtime library — Signal envelope, event bus, createSentinel(), query result. Foundation primitives (lifecycle, config, logger, atomic-write, serial-queue) are NOT re-exported; import them from @appydave/core (one symbol, one home)
