# @marble-sh/backstage-plugin-grafana-node

> 标签: backstage, grafana, plugin

## 简介

Node-side library for the Grafana Backstage plugins: the Grafana HTTP client, instance configuration, and filtering helpers shared by the backend plugin and catalog module
