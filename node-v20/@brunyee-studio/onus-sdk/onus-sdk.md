# @brunyee-studio/onus-sdk

> 标签: JavaScript

## 简介

Official Onus SDK: browser errors, session replay, custom events, logs and web analytics, plus Node, pino, winston and Next.js log exporters (existing Sentry SDKs work unchanged; OTLP for server logs)
