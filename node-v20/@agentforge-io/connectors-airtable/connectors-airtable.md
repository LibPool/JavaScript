# @agentforge-io/connectors-airtable

> 标签: JavaScript

## 简介

Airtable connector for AgentForge — read and write records, bases, and tables from the authorized user's Airtable workspaces. OAuth 2.0 with PKCE and Basic-auth token endpoint.
