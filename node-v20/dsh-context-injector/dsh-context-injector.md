# dsh-context-injector

> 标签: agent-preset, context-injection, cordis, cordis-plugin, deepseek-harness, dsh, session

## 简介

DeepSeek Harness (DSH) preset plugin that injects a prepared conversation history into new sessions as a single DSH-valid user message.
