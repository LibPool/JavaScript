# @wasmagent/evals-runner

> 标签: agent, ai, executor, llm, portable, sandbox, typescript, wasm, wasmagent

## 简介

Evaluation runner for wasmagent — multi-model multi-axis benchmark harness with paired statistics + Pareto report. Targets the gaps in evomerge-style single-axis evaluation: long-context recall, multi-turn memory, agent trajectory, latency, cost.
