# @kangwifiinc/baileys

> 标签: baileys, bot, lightweight, multi-device, pairing-code, qr, typescript, wa, whatsapp

## 简介

WhatsApp library — ringan, multi-fitur, tahan lama. Client API di atas Baileys 7: QR/pairing, auto-reconnect, state-machine recovery, MessageBuilder, CommandSystem, Automation, Plugins, Media/Sticker helpers. 1 dependency.
