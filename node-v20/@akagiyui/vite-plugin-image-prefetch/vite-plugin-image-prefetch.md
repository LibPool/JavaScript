# @akagiyui/vite-plugin-image-prefetch

> 标签: image, optimization, performance, prefetch, preload, vite, vite-plugin

## 简介

Vite 插件：构建时自动收集指定目录的图片资源，注入 <link rel="prefetch/preload"> 脚本实现图片预加载
