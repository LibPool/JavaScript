# @pgpm/reserved-names

> 标签: names, pgpm, postgresql, reserved, subdomains

## 简介

Reserved names (subdomains, usernames, domains, slugs, ...) that nobody may claim, as tables checked live by reserved_names.is_reserved(kind, name)
