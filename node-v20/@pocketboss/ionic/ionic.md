# @pocketboss/ionic

> 标签: JavaScript

## 简介

Lifecycle adapters for PocketBoss React, Vue, and Angular SDKs running in Ionic routed pages. Ionic may keep a page mounted while it is hidden, so normal unmount cleanup is not enough. These adapters bind bridge requests/events and comments sessions to Io
