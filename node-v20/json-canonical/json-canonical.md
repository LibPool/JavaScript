# json-canonical

> 标签: bigint, canonical, canonical-json, canonicalization, canonicalize, deterministic, digest, hash, jcs, json, json-pointer, minify, napi, rfc8785, rust, sha256, sign, signature, sort, sort-keys, stable, stable-stringify, stringify, validate

## 简介

RFC 8785 canonical JSON for Node, native (Rust) and computed from JSON text: deterministic stringify, key sorting that keeps big numbers exact, canonical hash, equal, minify, validate and JSON Pointer select
