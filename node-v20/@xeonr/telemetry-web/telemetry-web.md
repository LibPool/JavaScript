# @xeonr/telemetry-web

> 标签: JavaScript

## 简介

Browser telemetry for Xeonr consoles: errors, reachability, web vitals and RPC spans as OTLP/HTTP JSON to Lantern's client ingest, and a reader for a client project's own telemetry (./read). Replaces Sentry.
