# @ixblix/sdk-js

> 标签: crm, desk, e2ee, encryption, ixblix, messaging, overflow

## 简介

Official ixblix SDK for desk/CRM integrations. Create overflow conversations, exchange end-to-end encrypted messages and media, and manage company onboarding.
