# @yanqirenshi/markdown.sitter

> 标签: custom-element, editor, markdown, marked, prismjs, viewer, web-component

## 简介

Framework-agnostic Markdown viewer / editor Web Components (marked + Prism rendering, collapsible headings, split workspace with scroll sync, CSS-variable theming via Shadow DOM).
