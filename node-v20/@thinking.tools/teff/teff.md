# @thinking.tools/teff

> 标签: component-library, components, css, dark-mode, semantic-html, teff, ui, web-components

## 简介

An ultra-lightweight semantic UI library: one CSS file, one JS file. No framework, no build step, no dependencies — dark mode built in.
