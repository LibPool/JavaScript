# @plandesk/cli

> 标签: agents, canvas, kanban, local-first, mcp, plan-desk, planning, tasks

## 简介

Plan Desk CLI — run a local-first planning workspace (canvas + docs + tasks + board + MCP). Provides the `plandesk` command.
