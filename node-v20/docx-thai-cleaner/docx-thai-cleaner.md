# docx-thai-cleaner

> 标签: cleaner, docx, nfc, normalization, ooxml, openxml, sanitizer, thai, thai-text, typescript, unicode, word, zero-width

## 简介

Production-grade Thai text sanitizer for .docx / OpenXML pipelines: strips leaked HTML tags, removes zero-width characters, applies NFC normalization, repairs floating vowels and tone-mark stacking order, and produces OpenXML-safe output.
