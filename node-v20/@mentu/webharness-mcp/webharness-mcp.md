# @mentu/webharness-mcp

> 标签: aggregator, macos, mcp, model-context-protocol, sealed-binary, webharness

## 简介

MCPHarness — sealed-engine MCP aggregator for WebHarness apps. Thin npm launcher; the engine is a signed, notarized Mach-O downloaded on install from dist.webharness.io.
