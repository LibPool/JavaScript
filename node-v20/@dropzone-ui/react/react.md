> 标签: drag, drop, dropzone, dropzone-ui, file, file upload, framework, front-end, kamui, material, material-ui, mui, react, react-component, react-dropzone, typescript, ui, upload

## 简介

The best and most complete React library for managing file uploads. Multilanguage support. Server side support. Material design styles. Code generator on webpage.
