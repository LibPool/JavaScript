# @typedstandards/verify-core

> 标签: browser, ed25519, jcs, provenance, record-package, rfc8785, typed-standards, verification

## 简介

Portable, browser-safe verification core for Typed Standards record packages — the §9.2 check suite, single-sourced so it verifies identically on a server and in the browser.
