# @typedstandards/cli

> 标签: cli, did-key, ed25519, provenance, record-package, signing, typed-standards, verification

## 简介

Sign, withdraw, attest, build a commitment view for, and verify Typed Standards records from the command line, through @typedstandards/produce-core and @typedstandards/verify-core. JSON in, JSON out; the signing seed comes from one environment variable.
