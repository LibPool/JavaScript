# pi-balance-gateway

> 标签: api-gateway, balance, billing, pi-extension, pi-package, quota, relay, usage, wallet, 中转站, 余额

## 简介

Multi-account API gateway wallet balance in the pi footer. 在 pi 底部栏显示多个中转站账号的钱包余额，支持任何返回 balance 字段的 GET /v1/usage 接口。复用 models.json 里已有的 API key，无需额外配置。
