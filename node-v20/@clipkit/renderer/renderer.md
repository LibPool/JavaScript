# @clipkit/renderer

> 标签: clipkit, headless, mp4, playwright, renderer, video, webcodecs

## 简介

Render a ClipKit Source to MP4 locally — headless Chrome + WebCodecs, driven by Playwright. The Node-side renderer for @clipkit/runtime.
