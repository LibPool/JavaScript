# @1ecomm/dt-ui-core

> 标签: 1ecomm, design-system, dt-ui, ecommerce, storefront, tailwind, ui-components

## 简介

Framework-agnostic core for dt-ui: typed component contracts, Tailwind v4 semantic tokens, 24 palettes, and the behaviour primitives the Angular, React and Vue packages share.
