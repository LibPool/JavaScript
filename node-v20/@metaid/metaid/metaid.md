# @metaid/metaid

> 标签: DID protocol, MetaID, MetaID-Labs, Microvision Chain, blockchain, metaid, mvc

## 简介

MetaID is a library for MetaID protocol. It provides a set of functions to manage the DID document and the DID transaction.
