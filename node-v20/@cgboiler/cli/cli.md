# @cgboiler/cli

> 标签: vant

## 简介

Vant CLI 是一个基于 Vite 实现的 Vue 组件库构建工具，通过 Vant CLI 可以快速搭建一套功能完备的 Vue 组件库。

## 官网

- 官网：https://github.com/vant-ui/vant#readme
- 源码仓库：git+https://github.com/vant-ui/vant.git
- npm 页面：https://www.npmjs.com/package/@cgboiler/cli
