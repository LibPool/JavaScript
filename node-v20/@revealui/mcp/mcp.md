# @revealui/mcp

> 标签: ai, mcp, model-context-protocol, revealui, servers, tool-discovery

## 简介

Model Context Protocol framework — first-party server launchers, adapter pattern, tool discovery, and an incubating multi-server hypervisor (not app-mounted by default; ADR-007).
