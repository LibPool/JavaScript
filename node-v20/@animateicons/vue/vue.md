# @animateicons/vue

> 标签: animated icons, animated svg, free animated icons, huge animated, icons, lucide animated, motion icons, nuxt icons, svg icons, vue 3, vue icons

## 简介

Animated SVG icons for Vue 3 and Nuxt. The same motion as @animateicons/react, with server rendering and typed refs.
