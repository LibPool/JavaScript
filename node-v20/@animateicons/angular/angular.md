# @animateicons/angular

> 标签: angular, angular icons, animated icons, animated svg, free animated icons, huge animated, icons, lucide animated, motion icons, standalone component, svg icons

## 简介

Animated SVG icons for Angular. One standalone component with signal inputs, server rendering and zoneless support, with the same motion as @animateicons/react.
