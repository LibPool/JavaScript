# @navarchus/cf-headers

> 标签: cache-control, cloudflare, cloudflare-pages, cloudflare-workers, headers, http-headers, security-headers, typescript, vite-plugin

## 简介

Type-safe _headers file generator for Cloudflare Pages & Workers static assets, with a full catalog of HTTP response headers (status, deprecation, and reference info) and autocomplete for header names and values.
