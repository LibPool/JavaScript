# @edgelinkapp/sdk-web

> 标签: analytics, attribution, browser, conversion-tracking, edgelink

## 简介

Edgelink browser SDK for conversion tracking. Captures el_cid clickId from URL → 1st-party cookie → POST /api/v1/track.
