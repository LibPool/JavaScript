# @wextl/sdk

> 标签: api, automation, mcp, sdk, wextl, workflow

## 简介

Official TypeScript SDK for the wextl Public API (REST v1) — isomorphic fetch, zero runtime dependencies, semver tied to the v1 frozen-additive contract.
