# @hanzo/quickbooks

> 标签: accounting, ai, finance, hanzo, intuit, quickbooks, quickbooks-online

## 简介

Hanzo AI for QuickBooks Online — AI over your books: summarize financials, explain reports, draft invoice line descriptions, categorize transactions, and ask about the books. A web panel plus an Intuit OAuth2 + Accounting API v3 proxy, built on @hanzo/ai
