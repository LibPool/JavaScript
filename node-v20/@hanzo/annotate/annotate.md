# @hanzo/annotate

> 标签: analytics, autocapture, babel, hanzo, observability, session-replay, vite, webpack

## 简介

The build-time half of @hanzo/observe — annotates every component's root element with its own name (data-observe="ComponentName") so a production build keeps the semantic hierarchy React's dev-only fiber owner would have given you. Parses with TypeScript
