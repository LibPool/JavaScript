# @hanzo/shadcn

> 标签: JavaScript

## 简介

The shadcn-compatible React surface extracted from @hanzo/ui. Radix behaviour, Tailwind styling, standard shadcn tokens. @hanzo/ui renders on @hanzo/gui now; this is where its shadcn components went.
