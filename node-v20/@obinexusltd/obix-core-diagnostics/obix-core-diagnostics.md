# @obinexusltd/obix-core-diagnostics

> 标签: compatibility, diagnostics, host, obix, obix-core

## 简介

Stable compatibility errors, human (stderr) and single-document JSON (stdout) reporters, and an injection-based doctor runner for the OBIX CLI.
