# @obinexusltd/obix-component-datepicker

> 标签: accessibility, calendar, component, date, datepicker, dop, form, obix

## 简介

OBIX ObixDatePicker — a native <input type="date"> with min / max bounds plus an optional role="dialog" calendar panel with month navigation state. Data-Oriented, zero dependencies.
