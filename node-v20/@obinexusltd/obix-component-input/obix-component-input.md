# @obinexusltd/obix-component-input

> 标签: accessibility, component, dop, field, form, input, obix, textbox, validation

## 简介

OBIX ObixInput — a single-line text field with typed validation (email / url / required), a hint line, and aria-invalid + aria-describedby error wiring. Data-Oriented, zero dependencies.
