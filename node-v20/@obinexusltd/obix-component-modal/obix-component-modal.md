# @obinexusltd/obix-component-modal

> 标签: accessibility, component, dialog, dop, modal, obix, overlay

## 简介

OBIX ObixModal overlay — accessible dialog with focus-trap hooks, aria-modal, and configurable escape/backdrop close. Data-Oriented, zero dependencies.
