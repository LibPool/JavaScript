# wechat-draft-mcp

> 标签: draft, mcp, model-context-protocol, wechat, wechat-official-account

## 简介

本地 MCP 服务：把磁盘上的文章创建或原地更新为微信公众号草稿；更新/删除属破坏性操作，默认关闭。
