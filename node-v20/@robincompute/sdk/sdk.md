# @robincompute/sdk

> 标签: ai, decentralized, inference, llm, on-chain, openai-compatible, robincompute, robinhood-chain, streaming, web3

## 简介

TypeScript client for RobinCompute, the decentralized AI inference network on Robinhood Chain. Chat completions in the OpenAI shape, token streaming, and a verifiable on-chain settlement receipt for every job.
