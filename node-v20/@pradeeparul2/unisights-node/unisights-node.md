# @pradeeparul2/unisights-node

> 标签: analytics, bun, cloudflare-workers, deno, elysia, event-collection, express, fastify, hono, koa, nestjs, netlify-edge, unisights, vercel-edge

## 简介

Server package for unisights. Creates a configurable endpoint that receives events from the unisights client SDK. Processing is optional. Always returns 200.
