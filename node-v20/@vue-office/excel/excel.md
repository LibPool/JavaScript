# @vue-office/excel

> 标签: JavaScript

## 简介

支持多种文件(**docx、excel、pdf、pptx**)预览的vue组件库，支持vue2/3。也支持非Vue框架的预览。

- 源码仓库：git+ssh://git@github.com/501351981/vue-office.git
