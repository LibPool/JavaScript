# @dotrino/opaque

> 标签: dotrino, opaque, pake, password, rfc9807, wasm

## 简介

OPAQUE (RFC 9807) for the Dotrino ecosystem: check a password without the server ever seeing it. opaque-ke compiled to WASM in CI.
