# @hjtdev/django-cleanup

> 标签: JavaScript

## 简介

Admin-only orphan-file review and cleanup-run SDK for hjtdev-django-cleanup — typed hooks over the /api/v1/cleanup/admin/ endpoints, generated from the backend's own OpenAPI schema.
