# @md-code/component-uniqueness

> 标签: design-system, duplicate-components, eslint, eslint-plugin, eslintplugin

## 简介

ESLint rule and CLI that find duplicate components, raw HTML that should be a canonical component, and copied parts of components, by comparing structure, CSS, behavior, accessibility and framework profile.
