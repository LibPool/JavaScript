# @stringzhao/analytics-sdk

> 标签: JavaScript

## 简介

轻量数据统计接入封装，用于 stringzhao 名下 Vercel 应用的统一分析接入。后端委托官方 `@umami/node`（自托管 Umami），浏览器端自研 `<Analytics/>` script 注入 + `track()` 事件上报。
