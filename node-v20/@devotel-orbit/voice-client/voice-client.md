# @devotel-orbit/voice-client

> 标签: conversational-ai, cpaas, devotel, expo, in-app-voice, low-latency, mobile, opus, orbit, pcm, react-native, realtime, speech-to-speech, twilio-alternative, twilio-conversationrelay, voice, voice-agent, voice-ai, websocket

## 简介

Official client SDK for the Orbit Voice protocol — low-latency WebSocket bridge to Orbit's AI voice agents. Browser, Node, and React Native (Expo) for in-app voice. Built for low latency, observability, and developer ergonomics.
