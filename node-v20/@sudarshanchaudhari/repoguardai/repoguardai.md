# @sudarshanchaudhari/repoguardai

> 标签: ai-agents, audit, cli, code-review, security, static-analysis

## 简介

Tool-independent repository auditing framework that guides coding agents to review any repo for bugs, security, API and rate-limiting issues, dependency risk, and missing tests.
