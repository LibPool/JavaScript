# @biks2013/outlook-cli

> 标签: automation, calendar, cli, email, microsoft, outlook, playwright

## 简介

CLI for Outlook web — authenticate via Playwright, manage inbox, calendar, folders, and attachments through the Outlook REST v2.0 API.
