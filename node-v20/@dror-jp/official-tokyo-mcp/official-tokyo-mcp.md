# @dror-jp/official-tokyo-mcp

> 标签: civic-tech, foreign-residents, japan, mcp, mcp-server, modelcontextprotocol, open-data, tokyo

## 简介

MCP server for official.tokyo.jp — human-verified data on official procedures in Tokyo for foreign residents (resident registration, health insurance, wards, emergencies). Independent project, not a government service. Data CC BY 4.0.
