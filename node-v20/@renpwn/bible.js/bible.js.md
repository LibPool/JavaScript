# @renpwn/bible.js

> 标签: alkitab, api, audio, bible, database, fts5, hebrew, javascript, jewish bible, kristiani, lexicon, nodejs, sqlite, tanakh, terjemahan

## 简介

Node.js library untuk mengakses Bible dengan database SQLite + FTS5. Dilengkapi 12 Versi Bible & 1 Versi Jewish Bible (Hebrew & English), Lexicon beserta artinya, dan audio. Ideal untuk bot WhatsApp/Telegram, aplikasi mobile, dan website Kristiani.
