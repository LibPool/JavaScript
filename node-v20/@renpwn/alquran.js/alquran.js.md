# @renpwn/alquran.js

> 标签: alquran, api, arabic, audio, database, fts5, hadis, islamic, javascript, muslim, nodejs, quran, sqlite, tafsir, terjemahan

## 简介

Node.js library untuk mengakses Al-Qur'an dengan database SQLite + FTS5. Dilengkapi teks Arab, terjemahan, tafsir 6 sumber, transliterasi, dan audio. Ideal untuk bot WhatsApp/Telegram, aplikasi mobile, dan website Islamic.
