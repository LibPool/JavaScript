# @abmdev/mcp

> 标签: abm, ai-agents, b2b-data, enrichment, mcp

## 简介

abm.dev — the account-based marketing API for AI agents. Search, Enrich, and Create across B2B people and companies; every field cited with a source and confidence score. Thin local stdio bridge to the hosted MCP server (mcp.abm.dev, OAuth 2.1 PKCE).
