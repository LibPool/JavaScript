# @abineshsolairaj/pdf-merge

> 标签: base64, buffer, cli, combine-pdf, combine-pdfs, commonjs, concat-pdf, esm, fetch, merge, merge-pdf, merge-pdfs, metadata, node, nodejs, page-range, page-selection, pdf, pdf-lib, pdf-merge, pdf-merger, pdf-tools, pdf-utils, secure, ssrf, typescript, url

## 简介

Utility to merge PDFs from Base64 strings, Buffers, file paths, or URLs, with page selection, document metadata, watermarks, page numbers, AbortSignal cancellation, and dual ESM/CJS support.
