# @thewishlistco/storefront-event-capture

> 标签: JavaScript

## 简介

JS capture tag for recording search events on Shopify storefronts. Captures search queries across all major search providers (Shopify native, Algolia, Klevu, Bloomreach) and sends them to the TWC ingest endpoint as `search_submitted` events.
