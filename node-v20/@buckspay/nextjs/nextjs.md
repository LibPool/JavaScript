# @buckspay/nextjs

> 标签: account-abstraction, bff, gasless, nextjs, sdk, smart-wallet, soroban, stellar, usdc, web3

## 简介

Next.js (App Router) server helpers for the Buckspay SDK: BFF relay proxy + social/email signer-proxy route handlers for gasless Stellar (Soroban) USDC payments.
