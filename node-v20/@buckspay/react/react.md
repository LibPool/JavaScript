# @buckspay/react

> 标签: account-abstraction, gasless, hooks, react, sdk, smart-wallet, soroban, stellar, usdc, web3

## 简介

React 19 hooks for the Buckspay SDK: BuckspayProvider, useWallet, useStellarPay for gasless Stellar (Soroban) USDC payments.
