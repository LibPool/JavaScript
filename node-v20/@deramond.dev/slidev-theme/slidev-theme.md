# @deramond.dev/slidev-theme

> 标签: carousel, deramond, design-system, linkedin, slidev, slidev-theme

## 简介

A Slidev theme on @deramond.dev/tokens: one dark theme, self-hosted fonts, the brand code theme, talk layouts (cover to closing), LinkedIn carousel layouts (4:5), and French typography.
