# @hexrailsec/mcp

> 标签: ai-agent, claude, cursor, defi, mcp, model-context-protocol, scanner, security, solidity

## 简介

HexRail as a Model Context Protocol server — give your AI agent (Claude Desktop, Cursor, Cline) the ability to scan smart contracts and code, replay famous exploit patterns, and post onchain attestations.
