# @mumzworldtech/wadi-capture-web

> 标签: analytics, clevertap, events, typescript, wadi

## 简介

Wadi Capture Web — a tiny first-party event SDK for Mumzworld web, replacing clevertap-web-sdk. TypeScript, with ESM, CommonJS and <script> builds. Sends to the wadi-infra proxy in CleverTap's web wire format (POST /a, lz-string).
