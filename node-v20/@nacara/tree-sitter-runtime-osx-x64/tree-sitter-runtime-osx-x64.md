# @nacara/tree-sitter-runtime-osx-x64

> 标签: JavaScript

## 简介

tree-sitter built with wasm support, and the wasmtime engine it uses, for osx-x64. Fetched by Nacara.Plugin.Highlight.TreeSitter; there is nothing here for JavaScript to call.
