# @vektorgeist/pandaclip

> 标签: agent-tools, cache, clipboard, knowledge-graph, local-first, mcp, model-context-protocol, sqlite

## 简介

PandaClip — one local-first MCP server: clipboard history & snippets, TTL cache, file-organizer overlay, and a knowledge graph. SQLite everywhere, no daemons, no network.
