# @kagurazakanyaa/dsh-history-cache

> 标签: client-cache, deepseek-harness, dsh-plugin, session-history

## 简介

Keeps recently opened DSH Web sessions warm in the browser so switching back to a session no longer re-pulls its history from the Host.
