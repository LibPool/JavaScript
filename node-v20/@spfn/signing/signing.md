# @spfn/signing

> 标签: ecdsa, ed25519, jws, jwt, key-rotation, kms, signing, spfn, typescript

## 简介

Asymmetric token signing for SPFN with pluggable key providers (local, GCP KMS, AWS KMS) and a zero-dependency verifier.
