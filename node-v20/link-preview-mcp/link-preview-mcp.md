# link-preview-mcp

> 标签: extract, link-preview, link-preview-mcp, mcp, web

## 简介

链接预览与网页信息提取 MCP：抓取网页标题/描述/正文摘要，提取站内链接。stdio 传输，零第三方依赖（node 原生 fetch）。
