# @alayrasystems/nexus-core

> 标签: ai-gateway, anthropic, byok, cost-tracking, llm-proxy, openai-compatible, rate-limiting

## 简介

The Alayra Nexus gateway core: OpenAI- and Anthropic-compatible request handling, routing, rate windows and usage accounting, with storage supplied by the host through five small ports.
