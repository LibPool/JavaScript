# @gotong/workflow-assistant

> 标签: JavaScript

## 简介

Gotong workflow assistant — LlmAgent that turns a natural-language description into an gotong.workflow/v1 YAML draft. Lives outside @gotong/workflow so the runner stays free of any LLM runtime dependency.
