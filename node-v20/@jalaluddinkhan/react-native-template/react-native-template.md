# @jalaluddinkhan/react-native-template

> 标签: react-native, react-native-template, react-navigation, redux-toolkit, rtk-query, typescript

## 简介

A React Native CLI template with auth flow + bottom-tab navigation, Redux Toolkit + RTK Query, a 16-component accessible UI library, theming, centralized i18n, and a two-tier (Keychain + MMKV) storage strategy already wired up.
