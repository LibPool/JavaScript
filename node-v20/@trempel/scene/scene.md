# @trempel/scene

> 标签: agent-first, editor, game, pixijs, scene, svg, trempel

## 简介

Trempel — agent-first 2D game scenes: a scene format that is valid SVG (+ tml: namespace), a PixiJS runtime, an animation player and an editor core.
