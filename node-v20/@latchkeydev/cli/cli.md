# @latchkeydev/cli

> 标签: agent, cd, ci, latchkey, runner, testing

## 简介

Latchkey CLI. Runs one-off commands on fresh Latchkey runners: packs the working tree into a deterministic context tarball, uploads it, and streams the job's logs back.
