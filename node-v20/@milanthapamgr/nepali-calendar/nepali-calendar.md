# @milanthapamgr/nepali-calendar

> 标签: JavaScript

## 简介

A fully themable Bikram Sambat (BS) / Gregorian (AD) calendar built with React + TypeScript + Tailwind CSS. Supports year/month views, BS↔AD toggle, resizable panel, events and reminders with date ranges.
