# @wheewise-mcp/dealer

> 标签: claude, dealer, mcp, model-context-protocol, used-cars, wheewise

## 简介

MCP server for Wheewise dealers: build your own private website with Wheewise as its backend (vehicles, leads, test drives), and manage your shop from Claude or any MCP assistant.
