# @razohq/triage

> 标签: ci, flaky-tests, playwright, razo, test-reporting, testing, triage

## 简介

Morning triage for Playwright runs narrated by razo: clusters CI failures by cause, classifies them (regression, flaky, environment, stale test), names the suspect commits, and reports them. Deterministic, no model calls.
