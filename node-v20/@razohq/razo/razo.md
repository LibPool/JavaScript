# @razohq/razo

> 标签: ai, e2e, page-object, playwright, reporter, test-automation, test-reporting, testid, testing, vite-plugin

## 简介

Playwright UI controls with human names that narrate every action twice: a readable test.step() sentence and a structured StepEvent JSON artifact built for AI failure analysis.
