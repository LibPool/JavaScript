# @tesseractcollective/react-graphql-ui

> 标签: datatable, graphql, hasura, react-graphql

## 简介

A library built on top of react-graphql to give you various components and hooks to help speed up development. Currently include features for DataTables, Forms, and Dropdowns based on DB relationships
