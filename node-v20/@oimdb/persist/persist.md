# @oimdb/persist

> 标签: codec, engine, oimdb, persist, persistence, ssr, typescript

## 简介

Storage-agnostic persistence engine for OIMDB (source adapters, resources, versioned codec). Backends ship as @oimdb/persist-memory, -localstorage, -idb.
