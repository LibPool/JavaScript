# @onetwoagent/integration

> 标签: account-lookup, customer-support, express, nextjs, onetwoagent, support-widget

## 简介

OneTwoAgent integration kit: server handlers for signed-in identity and live account data, and the browser identity lifecycle. The app supplies only its session, membership and read-only data.
