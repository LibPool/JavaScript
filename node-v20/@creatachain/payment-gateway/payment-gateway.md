# @creatachain/payment-gateway

> 标签: creatachain, crypto, gateway, payment, sdk

## 简介

Creatachain Payment Gateway – An npm package to accept cryptocurrency payments (CTA, USDT, BTC, ETH) in your application. It offers order management, currency conversion and account management in a simple developer-friendly way.
