# @craftlabs/schematic-renderer

> 标签: 3d, litematic, minecraft, nbt, renderer, schematic, three.js, webgl

## 简介

A schematic renderer package for Minecraft schematics using Three.js (the craftlabs-nexus fork of Schem-at/schematic-renderer: 26.x packs, mod namespaces, connected textures)
