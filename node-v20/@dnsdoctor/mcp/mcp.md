# @dnsdoctor/mcp

> 标签: deliverability, dkim, dmarc, dns, email, mcp, spf

## 简介

Thin stdio MCP server for DNS Doctor — scan, fix and verify a domain's DNS: SPF, DMARC, DKIM, multi-region propagation, MX, DNS health, blacklists and expiry, over the public DNS Doctor REST API.
