# @dewib/dw-ui

> 标签: css, library, nuxtjs, tailwindui, ui

## 简介

Dewib ui is an open source ui library for developing HTML/CSS and JS websites. This package is developed with Vue.js and tailwindcss and to use with NuxtJS
