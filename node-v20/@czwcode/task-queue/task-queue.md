# @czwcode/task-queue

> 标签: JavaScript

## 简介

- 最合理的更新方式，不需要更新的模块不应该被通知到 - 当任务流正在执行的时候，会动态合并执行的任务模块，避免无效的任务执行 - 当任务被触发多次的时候，结束事件仅会被调用一次
