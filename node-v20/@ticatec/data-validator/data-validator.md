# @ticatec/data-validator

> 标签: boundary-checking, data-validation, entity-validator, form-validation, input-validation, javascript, rules-based, schema-validation, typescript, validation, validator

## 简介

A TypeScript/JavaScript library for rule-based entity validation with boundary checking for strings, numbers, dates, enums, objects, and arrays.
