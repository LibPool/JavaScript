# @ticatec/consul-client

> 标签: config, consul, consul-client, hashicorp-consul, keelson, key-value, kv, multi-instance, nodejs, singleton, ticatec, typescript

## 简介

A lightweight, robust TypeScript client for HashiCorp Consul HTTP API, featuring comprehensive KV store management, connection pooling, and dual ESM/CommonJS builds.
