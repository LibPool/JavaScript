# @ticatec/express-exception

> 标签: 400, 401, 403, 404, 500, api, authentication, authorization, content-negotiation, enterprise, error-handler, error-handling, error-middleware, error-response, exception, exception-handler, express, express-middleware, http-error, http-errors, http-status, middleware, nodejs, production-ready, rest-api, status-codes, ticatec, type-safe, typescript, validation

## 简介

Production-ready Express error handling middleware with standardized HTTP error types, centralized exception management, and automatic content negotiation for REST APIs. Type-safe, zero-dependency core.
