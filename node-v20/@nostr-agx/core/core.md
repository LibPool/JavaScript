# @nostr-agx/core

> 标签: a2a, agent-to-agent, agents, nip-agx, nostr, nostr-agx, protocol

## 简介

Transport-agnostic core of NIP-AGX, a draft Nostr standard for agent-to-agent task exchange: task lifecycle, result matching, delivery receipts, replay protection and capability matching.
