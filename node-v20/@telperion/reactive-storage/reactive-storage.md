# @telperion/reactive-storage

> 标签: async-storage, browser-storage, cookie-storage, cookies, immutable, localstorage, observable, reactive, reactive-programming, rxjs, sessionstorage, state-management, storage, storage-sync, typescript, web-storage

## 简介

RxJS-based reactive storage library for browser environments. Provides Observable-based wrappers for localStorage, sessionStorage, and cookies with immutability, type safety, and cross-instance synchronization support. Built with TypeScript and RxJS for r
