# @fenn-chat/mcp-server

> 标签: calendar, chat, claude-code, fenn, location, mcp, mcp-server, model-context-protocol

## 简介

Fenn MCP server for Claude Code and other stdio MCP clients: read location, conversations, messages, and calendars; send messages with an explicitly minted send token.
