# @denkwerk/unplugin-favicon-generator

> 标签: favicon, rolldown-plugin, rollup-plugin, rspack-plugin, unplugin, vite-plugin, webpack-plugin

## 简介

Vite, Rollup, Rolldown, webpack and Rspack plugin that generates favicons, touch icons and a web app manifest from an SVG or a Figma node, and adds the head tags
