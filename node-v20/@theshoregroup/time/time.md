# @theshoregroup/time

> 标签: date-fns, datetime, dst, temporal, temporal-polyfill, theshoregroup, timezone, typescript

## 简介

Minimal date-fns-style helpers for the Temporal API: a single consistent polyfill entry point, kind-safe comparisons and period edges, and explicit-zone boundary conversions.
