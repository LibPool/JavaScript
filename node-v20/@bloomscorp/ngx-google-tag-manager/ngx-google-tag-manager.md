# @bloomscorp/ngx-google-tag-manager

> 标签: analytics, angular, angular-ssr, google-tag-manager, gtm, nguniversal, server-side-rendering, ssr

## 简介

SSR-safe Google Tag Manager integration for Angular 18+ (and the latest Angular). Drop-in compatible with angular-google-tag-manager, but never touches the global window/document — works with both @nguniversal/express-engine (legacy SSR) and @angular/ssr
