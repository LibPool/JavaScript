# @priemskiyyy/simulcast-react

> 标签: expo, pubsub, react, react-hooks, react-native, real-time, realtime, simulcast, ssr, subscriptions, typed-events, typescript, websocket

## 简介

React bindings for simulcast: a provider that owns the realtime session and hooks for shared channel subscriptions, typed events, channel status, and connection state.
