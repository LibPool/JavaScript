# @priemskiyyy/pulse-react

> 标签: app-state, background, foreground, hooks, lifecycle, page-visibility, pulse, react

## 简介

React bindings for Pulse: a provider, and hooks for the Pulse and its lifecycle state that observe without starting or disposing anything.
