# @gavinc-cn/dsh-plugins

> 标签: bundle, cordis, deepseek-harness, dsh, meta, plugin

## 简介

DSH 自研插件的聚合元包：自身不是 bundle（不含任何配置行），只把 @gavinc-cn/dsh-plugins-ui 与 @gavinc-cn/dsh-plugins-runtime 一起装上。
