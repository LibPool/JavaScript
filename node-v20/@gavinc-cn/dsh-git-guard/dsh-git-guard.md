# @gavinc-cn/dsh-git-guard

> 标签: JavaScript

## 简介

git 操作归属守卫 (kimi-code git_commit_guard hook 的 DSH 原生移植): 拦下缺 agent 前缀的 git commit、越界的 reset --soft squash / amend / branch / worktree / merge / tag / config 写操作与 checkout, 经 tools/pre-execute 返回 {kind:'deny'}。
