# @gavinc-cn/kanban-board

> 标签: JavaScript

## 简介

任务看板: 待开发/正在开发/阻塞/待审核/已完成。拖入正在开发自动创建会话由 agent 执行, 完成自动进待审核, agent 提问/请求审批自动进阻塞, 回答后自动继续。
