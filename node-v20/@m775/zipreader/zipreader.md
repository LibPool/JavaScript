# @m775/zipreader

> 标签: archive, archive-reader, arraybuffer, browser, compression, file-parser, file-reader, filereader, frontend, gentbo, javascript, uint8array, utf8, utility, vanilla-js, web, zip, zip-parser, zip-reader, zipreader

## 简介

A lightweight JavaScript ZIP file reader that parses ZIP archives directly in the browser without dependencies. Supports File objects, file input elements, directory listing, compression method detection, and UTF-8 filename decoding.
