# @hydronium-js/vite

> 标签: JavaScript

## 简介

Vite 8 build/dev adapter for Hydronium: the plugin wires island entry points into the build (islands are fetched at runtime by bootstrap.js, so nothing in Vite's graph imports them), enables the build manifest hydronium_ballad.plugins.vite_assets ingests,
