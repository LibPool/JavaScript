# design-contract-checker

> 标签: ai, checker, coding-agent, css, design-system, design-tokens, guard-lite, lint, linting, pixel-perfect

## 简介

Guard Lite: check CSS or HTML text against your declared design contract (colors, fonts, font sizes, spacing, radii). Five stable checks, zero dependencies.
