# @vitral/spreadsheet

> 标签: cells, formula, grid, spreadsheet, vitral

## 简介

Framework-free spreadsheet for Vitral: the engine (cells, A1 references, formulas, the dependency graph) and a DOM renderer with a virtualised grid, which the Vue, React and Angular components wrap.
