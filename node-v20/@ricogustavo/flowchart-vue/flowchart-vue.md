# @ricogustavo/flowchart-vue

> 标签: JavaScript

## 简介

1. install the flowchart dependencies `npm i @ricogustavo/flowchart-vue@latest ` 2. add this to the file `import Flowchart from "@ricogustavo/flowchart-vue/Flowchart.vue"` 3. use the component like this `<Flowchart/>` on your system 4. add `mdi` on nodes.
