# @deftio/spab

> 标签: ecc, no-deps, provenance, steganography, text, unicode, watermark, watermarking, whitespace, zero-dependencies

## 简介

Watermark plain text — hide an arbitrary payload in the whitespace and punctuation of ordinary text, protected by error correction. Zero dependencies.
