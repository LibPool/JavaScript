# @crossbind/port-spatialite-android

> 标签: android, crossbind, crossbind-package, gis, libspatialite, react-native, spatial, spatialite, sqlite

## 简介

Android build of the precompiled SpatiaLite (spatial SQLite extension) library, built with crossbind. Use it together with the main package @crossbind/port-spatialite.
