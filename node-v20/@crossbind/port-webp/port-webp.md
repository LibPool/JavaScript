# @crossbind/port-webp

> 标签: android, crossbind, crossbind-package, image, ios, libwebp, react-native, wasm, webassembly, webp

## 简介

This package provides a WebP library compiled with crossbind, enabling seamless usage of WebP functionalities in JavaScript, WebAssembly and React Native projects. It supports efficient image processing for web and mobile applications.
