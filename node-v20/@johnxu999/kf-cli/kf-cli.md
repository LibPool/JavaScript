# @johnxu999/kf-cli

> 标签: JavaScript

## 简介

KF CLI 是知识森林的确定性项目操作工具。它默认连接知识森林生产服务，使用用户在 Web 账号页创建的 API Key，并继续受账户 CLI access 与项目权限约束。
