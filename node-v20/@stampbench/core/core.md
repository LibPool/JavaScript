# @stampbench/core

> 标签: compliance, e-invoice, e-rechnung, en16931, factur-x, invoice, peppol, ubl, validation, xrechnung, zugferd

## 简介

Validate and generate EN 16931 / XRechnung e-invoices in pure TypeScript. UBL parsing, business-rule validation (BR, BR-CO, BR-DE), and compliant XML generation.
