# cheap-eyes

> 标签: claude, delegation, mcp, model-context-protocol, openrouter

## 简介

Cheap eyes for an expensive agent: an MCP server that hands bulk reading to cheap OpenRouter models, masks secrets and mechanically checks every answer against the source.
