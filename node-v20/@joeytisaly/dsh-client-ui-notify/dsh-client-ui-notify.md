# @joeytisaly/dsh-client-ui-notify

> 标签: JavaScript

## 简介

Notification sound for DeepSeek Harness web: an audible cue when a user-decision interaction (approval / plan review / question) appears, plus a General-settings row (enable, background-only, volume, preview)
