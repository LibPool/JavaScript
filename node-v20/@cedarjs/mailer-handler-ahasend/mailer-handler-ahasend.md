# @cedarjs/mailer-handler-ahasend

> 标签: JavaScript

## 简介

We assume you have the basic boilerplate for Cedar Mailer present. We also assume that you have signed up with [AhaSend](https://ahasend.com/), verified a sending domain, and have an API key with permission to send messages, along with your account ID.
