# @lunacord/core

> 标签: audio, bun, discord, lavalink, lavalink-v4, music, typescript

## 简介

Builder-first Lavalink v4 client for Bun and Node.js. Nodes, players, queues, filters, lyrics, plugins, cache — all with a strictly-typed API.
