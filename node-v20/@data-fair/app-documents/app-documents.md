# @data-fair/app-documents

> 标签: JavaScript

## 简介

Application de gestion de documents (GED) pour [DataFair](https://github.com/data-fair/data-fair) : arborescence de dossiers et de fichiers stockés comme pièces jointes d'un jeu de données, dépôt par glisser-déposer, renommage, versionnement et historique
