# @redsift/table-pro

> 标签: JavaScript

## 简介

Pro-tier table and datagrid component library for Red Sift's Design System. This package is based on MUI X DataGrid Pro and does not include Premium-only features (pivoting, row grouping, aggregation).

- 源码仓库：git+https://github.com/redsift/design-system.git
