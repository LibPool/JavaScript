# @alpha-sdk/crsdk

> 标签: c++, camera, crsdk, remote-cli, sony

## 简介

Standalone CLI for the Sony Camera Remote SDK — accept EULA, extract the SDK zip, build and launch the Sony RemoteCli sample, install docs MCP servers
