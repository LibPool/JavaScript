# @oximg/next-loader

> 标签: image-cdn, image-loader, image-optimization, next-image, nextjs, oximg, sharp-alternative

## 简介

Next.js image loader for a self-hosted oximg server — move image optimization off Vercel/sharp and onto your own box.
