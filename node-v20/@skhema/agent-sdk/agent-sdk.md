# @skhema/agent-sdk

> 标签: agent, agent-auth, ed25519, jwt, sdk, skhema

## 简介

Client SDK for Skhema registered agents — local keypair generation, enrollment-token redemption, and proof-of-possession request signing (Agent Auth Protocol).
