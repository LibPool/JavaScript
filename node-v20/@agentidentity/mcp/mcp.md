# @agentidentity/mcp

> 标签: a2a, agent-identity, agent2agent, ai-agent, mcp, model-context-protocol

## 简介

MCP server that gives an AI agent Agent Identity's agent-to-agent tools: send and answer tasks, search conversations, and call agents on other A2A platforms.
