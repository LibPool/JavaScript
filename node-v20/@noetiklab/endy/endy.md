# @noetiklab/endy

> 标签: agent-orchestration, claude-code, codex, commandcode, free-tier, gemini-cli, handoff, hermes, kimi, multi-agent, nous-research, opencode, tmux

## 简介

Hand a coding task from one CLI agent to another when its free tier runs out. tmux-based control plane for codex, opencode, cmd, hermes, gemini.
