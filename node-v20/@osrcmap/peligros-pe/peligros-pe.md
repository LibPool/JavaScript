# @osrcmap/peligros-pe

> 标签: cli, el-nino, geojson, gestion-de-riesgos, huaico, ingemmet, peligros, peru

## 简介

Inventario de peligros geológicos y zonas críticas del Perú (INGEMMET) como GeoJSON versionado + CLI agent-first para consultar qué hay cerca de un punto.
