# @veris-ai/daytona-opencode

> 标签: daytona, integration-testing, opencode, opencode-plugin, sandbox, veris

## 简介

Run every OpenCode session in a Daytona sandbox whose vendor API calls are answered by a Veris twin. One line in opencode.json: unmodified code, real hostnames, and a receipt of what the vendor actually received.
