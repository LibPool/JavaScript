# @walknpm/dsh-todo-plugin

> 标签: cordis, deepseek-harness, dsh, plugin, productivity, task, todo

## 简介

DeepSeek Harness Tool Plugin that wraps @walknpm/todo-cli as model-callable tools (todo_add, todo_list, todo_done, todo_search, todo_stats, and more).
