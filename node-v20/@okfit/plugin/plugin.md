# @okfit/plugin

> 标签: agent, claude, cli, mcp, okf, open-knowledge-format

## 简介

Install this one package to get the okfit CLI, MCP server and LSP server in your repository. Depends on @okfit/cli, @okfit/mcp and @okfit/lsp.
