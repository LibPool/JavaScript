# @markeljan/ai-sdk-xai

> 标签: @markeljan/ai

## 简介

The **[xAI Grok provider](https://sdk.vercel.ai/providers/ai-sdk-providers/xai)** for the [AI SDK](https://sdk.vercel.ai/docs) contains language model support for the xAI chat and completion APIs.
