# @webx-ui/module-catalog-landings

> 标签: admin, catalog, cms, e-commerce, landings, seo, vue, webx-ui

## 简介

Landing pages for the catalogue of the WebX UI admin panel: a category list with filters chosen in advance under an address, texts and SEO of its own, the set builder with a live count, recommended products, and creating landings in bulk.
