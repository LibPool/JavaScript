# @webx-ui/module-blocks

> 标签: admin, blocks, page-builder, vue, webx-ui

## 简介

The block constructor for the WebX UI admin panel: the section where a block type is made — fields, Blade, CSS, script — and the wx-blocks field that builds a page out of them.
