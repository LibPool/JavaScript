# @webx-ui/module-catalog-manticore

> 标签: admin, catalog, cms, e-commerce, manticore, search, vue, webx-ui

## 简介

The search index of the WebX UI catalogue on Manticore, in the admin panel: the server, each language's table against the database, the queue, and the rebuild as a job with its progress.
