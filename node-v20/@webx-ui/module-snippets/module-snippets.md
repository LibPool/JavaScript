# @webx-ui/module-snippets

> 标签: admin, cms, snippets, vue, webx-ui

## 简介

Codes of outside services for the WebX UI admin panel: a tag manager, a counter or a chat pasted into the head or the body of every page, by place, with coverage, languages and cookie consent.
