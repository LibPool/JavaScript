# @webx-ui/module-reviews

> 标签: admin, cms, reviews, testimonials, vue, webx-ui

## 简介

Reviews for the WebX UI admin panel: photo, name, job title, rating and text, in flat categories, ordered by hand, shown on the site by a block.
