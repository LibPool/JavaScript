# @webx-ui/module-catalog-brands

> 标签: admin, brands, catalog, cms, e-commerce, manufacturers, vue, webx-ui

## 简介

Brands for the catalogue of the WebX UI admin panel: a reference book with logos, descriptions and pages of their own, a field of the product form, a column and a filter of the list.
