# @doranjs/zod

> 标签: forms, jalali, persian, schema, typescript, validation, zod

## 简介

Framework-agnostic zod schema for DoranDate — accepts ISO / Date / epoch / DoranDate and coerces to a DoranDate, with min/max bounds.
