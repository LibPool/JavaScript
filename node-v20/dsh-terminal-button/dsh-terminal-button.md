# dsh-terminal-button

> 标签: bottom-panel, cordis, deepseek, deepseek-harness, dsh, extension, plugin, terminal

## 简介

Extension for DeepSeek Harness's official terminal: renders it in an in-app bottom panel, redirects Desktop "open terminal" entry points into that panel, and exposes the dsh CLI inside terminals. No second PTY/xterm stack.
