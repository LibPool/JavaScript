# @heyhuynhgiabuu/pi-factory-droid

> 标签: claude, droid, factory, gpt, pi, pi-extension, pi-package, provider

## 简介

Unofficial Pi provider for Factory (Droid) models: Claude, GPT, Grok and open-weight models through your Factory API key, with Pi owning the agent loop and tools.
