# @qrforge/cli

> 标签: cli, offline, pdf, png, qr, qr-code, qrcode, svg, vcard, wifi

## 简介

QRForge CLI — generate beautiful QR codes (URL, Wi-Fi, vCard, email, SMS, location, events) as SVG, PNG or PDF. Fully offline.
