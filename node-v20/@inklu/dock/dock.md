# @inklu/dock

> 标签: a11y, accessibility, dock, drawer, headless, modal, panel, react, resize, side-panel, tabs, workspace

## 简介

Headless, accessible workspace dock and multi-panel system for React — docked & expanded modes, tab management, drag resize, focus trapping, and URL persistence.
