# @androidsup/dsh-plugin-updates

> 标签: deepseek-harness, dsh-plugin, plugin-updates, update-management

## 简介

DSH 插件更新管理：只管已安装插件，更新先确认、结果可核验、可忽略指定版本提醒，不是插件市场。 User-controlled, verified updates for installed DSH plugins, with per-release notification ignores. Not a marketplace.
