> 标签: android, document-scanner, expo, gemini-nano, hardware, mlkit, nfc, offline-translation, on-device-ai, pixel, react-native, speech-to-text, telemetry, uwb

## 简介

PixelKit is an SDK for building Expo and React Native applications on Google Pixel devices. It provides typed React hooks for the CPU, GPU and TPU, device sensors, radios, secure hardware, camera and audio, display and power telemetry, haptics, on-device
