# @pixelkit-labs/native

> 标签: android, expo, expo-module, pixel, react-native

## 简介

Pixel hardware for Expo apps: SoC identity, CPU clusters, memory, thermal and ADPF headroom, display modes, GPU, torch and haptic envelopes. Zero third-party dependencies. Android only.
