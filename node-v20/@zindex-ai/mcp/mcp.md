# @zindex-ai/mcp

> 标签: agent, diagrams, dsp, llm, mcp, model-context-protocol, rendering, svg, zindex

## 简介

MCP server for Zindex - agent-native diagram state infrastructure. A thin HTTP client exposing tools (create, patch, derive, propose, list-proposals, get-proposal, validate, normalize, diff, render, list-revisions, get-scene, delete-scene, undelete-scene,
