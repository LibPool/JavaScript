# @huanlin/dsh-plugin-komari

> 标签: dsh-plugin, komari

## 简介

DSH plugin exposing Komari monitoring-panel tools (list servers, run remote commands) to the model, with a settings-page card for endpoint/username/password. | DSH 插件：向模型暴露 Komari 探针工具（列机器、远程执行命令），并在设置页配置面板地址与账号。
