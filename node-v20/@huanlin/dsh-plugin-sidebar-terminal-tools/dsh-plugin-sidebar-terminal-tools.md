# @huanlin/dsh-plugin-sidebar-terminal-tools

> 标签: dsh-plugin

## 简介

DSH plugin bridging the official sidebar terminal stack to the model: sidebar_terminal_open/send/read/wait_for/close/list drive ctx.terminalController, terminals auto-appear as native sidebar tabs, and the user can take over at any time.
