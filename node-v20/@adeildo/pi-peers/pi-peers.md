# @adeildo/pi-peers

> 标签: collaboration, multi-agent, pi, pi-coding-agent, pi-extension, pi-package

## 简介

Agents working in the same folder see each other's tasks and what they edited and ran, talk in a shared room, and decide among themselves who takes what you ask the group.
