# @peridotvault/pid-sdk-js

> 标签: passkey, peridot, smart-account, solana, wallet, webauthn

## 简介

The PeridotID browser SDK — auth (Google + passkey), identity, profile, and the passkey wallet (non-custodial Solana smart account).
