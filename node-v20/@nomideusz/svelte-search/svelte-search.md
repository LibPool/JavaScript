# @nomideusz/svelte-search

> 标签: autocomplete, fts5, fuzzy, geo, polish, postgres, search, sqlite, svelte, trigram

## 简介

Full-text search engine for Svelte 5 apps — FTS5, trigram fuzzy matching, geo proximity, autocomplete, Polish locale support.
