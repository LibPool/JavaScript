# @nomideusz/zaur-world

> 标签: ambient, background, canvas, day-night, generative, open-meteo, sky, sunrise-sunset, weather, zaur

## 简介

A living ambient sky for any web page — real sunrise/sunset, live weather, seasons, day/night cycle, and small delights on a single canvas. Zero dependencies.
