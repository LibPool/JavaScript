# @qala/qala-linux-cli

> 标签: cli, event-driven, event-gateway, q-flow, qala, qflow

## 简介

Qala CLI is a command-line interface tool for Linux, designed to simplify and automate various tasks for developers that are using the Qala Q-Flow.
