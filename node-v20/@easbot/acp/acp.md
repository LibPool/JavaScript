# @easbot/acp

> 标签: acp, agent-client-protocol, agent-communication-protocol, client, easbot, http, rpc, server, stdio, typescript, websocket

## 简介

EASBot ACP (Agent Communication Protocol) adapter — multi-channel server / client / connection layer for the Agent Client Protocol (stdio / http / websocket), with config loader, L2 cache and standalone CLI.
