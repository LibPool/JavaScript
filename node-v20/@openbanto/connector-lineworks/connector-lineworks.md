# @openbanto/connector-lineworks

> 标签: chatops, connector, line-works, lineworks, openbanto, plugin

## 简介

LINE WORKS Bot connector plugin for OpenBanto — bridges a LINE WORKS Bot (Service Account / JWT auth, Bot API messaging, signed callbacks) to the OpenBanto gateway as an external plugin.
