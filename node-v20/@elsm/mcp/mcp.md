# @elsm/mcp

> 标签: ai-agents, browser, chrome-extension, cookies, devtools, indexeddb, localstorage, mcp, mcp-server, model-context-protocol, sessionstorage

## 简介

Local MCP bridge for Easy Local Storage Manager: lets any AI agent (Claude Code, Cursor, Codex, Gemini CLI, ...) read and write the real browser's storage through the ELSM extension.
