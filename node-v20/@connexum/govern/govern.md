# @connexum/govern

> 标签: JavaScript

## 简介

One entry for all three My-CC layers around any agent: data readiness before a tool reads a source, the runtime gate during (the local enforcing gate or the governance server), and correctness after (verification of the agent's claims). Thin stack adapter
