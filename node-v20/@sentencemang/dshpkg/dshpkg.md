# @sentencemang/dshpkg

> 标签: deepseek, deepseek-harness, dsh, dsh-plugin, package-manager, plugin-manager

## 简介

apt-style plugin manager for DeepSeek Harness: AUR-like recipe repos, transactional install with rollback, crash circuit breaker, watchdog self-healing. Depends only on the official kernel.

## 官网

- npm 页面：https://www.npmjs.com/package/@sentencemang/dshpkg
