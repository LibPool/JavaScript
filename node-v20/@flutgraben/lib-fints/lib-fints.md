# @flutgraben/lib-fints

> 标签: FinTS, HBCI, Home Banking, Online Banking, PIN/TAN

## 简介

Flutgraben fork of lib-fints with HKCCS (SEPA credit transfer), HKIPZ (SEPA Instant) + HKVPP built in. Typescript/Javascript client for Online-Banking via FinTS 3.0 PIN/TAN.
