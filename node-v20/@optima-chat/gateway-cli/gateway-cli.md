# @optima-chat/gateway-cli

> 标签: JavaScript

## 简介

Optima Gateway 的本地命令行客户端。登录一次，本地全用：**A 路**对话式（经 gateway）、**B 路**直调工具（scout / commerce 等），共用 `~/.optima/token.json`。命令名 `gateway`。
