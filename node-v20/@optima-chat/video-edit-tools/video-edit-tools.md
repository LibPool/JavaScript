# @optima-chat/video-edit-tools

> 标签: asr, ffmpeg, subtitle, video-edit, whisper

## 简介

Descript-mode speech video editing CLI (analyze / smart-cut / review / subtitle). Pure Python, ffmpeg + Groq Whisper as system deps.
