# @getnodded/sdk

> 标签: aeo, ai, analytics, bot, chatgpt, claudebot, crawler, geo, gptbot, llm, perplexitybot, seo

## 简介

Server-side AI crawler tracking: see which AI bots (ChatGPT, Claude, Perplexity, Gemini…) crawl your site, which pages they read, and which ones 404.
