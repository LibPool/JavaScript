# @arrow-labs/auth-sdk

> 标签: arrowlabs, auth, authentication, mfa, oauth, oidc, sdk, sso, typescript

## 简介

TypeScript SDK for the ArrowLabs Auth platform — a typed client for sign-in, MFA, OAuth/OIDC, and the account & admin APIs.
