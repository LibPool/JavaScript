# laranex-schema-viewer-ui

> 标签: database, diagram, erd, laranex, react, react-flow, schema

## 简介

The unified laranex-schema contract and the shared ERD viewer for Laravel, Python and Node.js: a React component, a standalone static bundle, JSON Schema, validator, graph builder and conformance fixtures.
