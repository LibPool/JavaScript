# @pegah-plugin/bridge

> 标签: bridge, mcp, model-context-protocol, pegah, stdio, wordpress

## 简介

stdio MCP bridge for the Pegah WP plugin — forwards JSON-RPC from an MCP client (e.g. Claude Desktop) to a WordPress site over HTTP with Application Password auth.
