# @immera/vitals

> 标签: express, health, healthcheck, kubernetes, liveness, monitoring, next, nuxt, readiness, vitals

## 简介

Framework-agnostic /vitals health endpoint: one core, thin adapters for Node workers, Express, Next.js, Nuxt, plus a build-time vitals.json generator for static SPAs.
