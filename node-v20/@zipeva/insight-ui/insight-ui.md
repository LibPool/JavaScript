# @zipeva/insight-ui

> 标签: bitcore-zip, blockchain, blockexplorer, front-end, insight, zip, zipcore

## 简介

An open-source frontend for the Insight API. The Insight API provides you with a convenient, powerful and simple way to query and broadcast data on the Zip network and build your own services with it.
