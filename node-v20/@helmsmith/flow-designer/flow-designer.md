# @helmsmith/flow-designer

> 标签: agent, designer, editor, flow, orchestration, react-flow, workflow

## 简介

Visual flow designer for @helmsmith/flow-spec catalogs — drag-and-drop canvas with the exact validator and expression evaluator the runtime uses, live on every edit. Run with npx against any harness or controlplane serving the /v1/catalog wire shape.
