# @xpaysh/cart-deeplinks

> 标签: acp, agentic-commerce, ai-shopping, cart-deeplink, hs256, jwt, ucp

## 简介

HS256-signed cart-handoff JWT (sign + verify) for the agentic-commerce-for-* plugin family. Interoperable bit-for-bit with the xpaysh/agentic-commerce-for-woocommerce PHP plugin v0.2+ and the xpay backend (Xpay_Client::verify_jwt). Zero deps; Node crypto
