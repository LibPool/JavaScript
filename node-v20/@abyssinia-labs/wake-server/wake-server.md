# @abyssinia-labs/wake-server

> 标签: agents, cloudflare-d1, drizzle, postgres, server-sent-events, sqlite, wake

## 简介

The server half of wake/v1 for any TypeScript app: let Wake start your users' agents, on Postgres or SQLite (Cloudflare D1) with Drizzle
