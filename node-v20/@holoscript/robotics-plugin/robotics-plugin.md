# @holoscript/robotics-plugin

> 标签: digital-twin, gazebo, holoscript, plugin, robotics, ros2, urdf, usd, vr

## 简介

HoloScript plugin for robotics: compile-time USD/URDF codegen + runtime ROS2/Gazebo integration. VR robot programming and digital twins.
