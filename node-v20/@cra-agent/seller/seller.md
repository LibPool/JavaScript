# @cra-agent/seller

> 标签: agent-payments, ai-agents, api-monetization, arc, circle, circle-gateway, express, hono, lightning, micropayments, middleware, paywall, usdc, x402

## 简介

Put a USDC price on any API with x402, settled on Arc: one command in front of an API you already run, or a middleware for Hono and Express. Optionally also for sale in sats over Lightning.
