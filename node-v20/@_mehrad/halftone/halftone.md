# @_mehrad/halftone

> 标签: accessible, components, copy-paste, custom-elements, design-system, lit, shadcn-like, ui, web-components

## 简介

Web components built with Lit, styled after Sentry, PostHog, Sentinel and Taskscape. Human and agent friendly. Use as a package or copy components into your project with `halftone add`.
