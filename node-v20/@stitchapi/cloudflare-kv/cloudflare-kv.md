# @stitchapi/cloudflare-kv

> 标签: cache, cloudflare, edge, session, stitchapi, store, workers, workers-kv

## 简介

Cloudflare Workers KV-backed StitchStore for StitchAPI — edge cache + shared sessions/tokens. Bring your own KV namespace binding. (incr → use a Durable Object store.)
