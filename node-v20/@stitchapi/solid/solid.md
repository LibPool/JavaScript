# @stitchapi/solid

> 标签: createStore, query, solid, solid-js, stitchapi, streaming, tanstack-query

## 简介

Solid bindings for StitchAPI — createStitch/createStitchStream primitives that reconcile a Solid store from the query-core reactive store. Streaming-first: re-render as `delta` chunks arrive. Plus an optional TanStack Query queryOptions helper.
