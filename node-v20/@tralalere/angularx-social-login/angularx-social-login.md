# @tralalere/angularx-social-login

> 标签: amazon-authentication, angular, angular-social-login, angular12, facebook-authentication, google-authentication, social-authentication, social-login

## 简介

Social login and authentication module for Angular 12. Supports authentication with Google, Facebook, Amazon, and VK. Can be extended to other providers also.
