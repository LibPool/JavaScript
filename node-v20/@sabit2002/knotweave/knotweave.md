# @sabit2002/knotweave

> 标签: JavaScript

## 简介

KnotWeave is an interactive Resource Allocation Graph simulator built to visualize deadlocks, test Banker's Algorithm, and automatically evaluate system state (Safe/Unsafe, Deadlock/No Deadlock).
