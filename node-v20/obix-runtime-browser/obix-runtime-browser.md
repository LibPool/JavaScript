# obix-runtime-browser

> 标签: browser, native, obix, runtime

## 简介

The browser entry of OBIX's native runtime: createObixApp(ir, options) makes an application of a root component of canonical DOP IR, and mounts it in a page. No Vue, no React. Phase 6 (docs/recovery/native-runtime.md).
