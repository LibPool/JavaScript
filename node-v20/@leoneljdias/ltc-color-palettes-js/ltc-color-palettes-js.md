# @leoneljdias/ltc-color-palettes-js

> 标签: color-blind, color-palette, colors, cvd, data-visualization, fork, ltc, palettes, port

## 简介

JavaScript port of the ltc R color-palette package by Loukas Theodosiou. Provides art-inspired color palettes with adjust, desaturate, CVD simulation, and visualization functions.
