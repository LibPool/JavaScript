# dsh-plan-card-sidebar

> 标签: deepseek-harness, dsh, dsh-plugin, plan, plan-mode, sidebar, ui

## 简介

DSH web plugin: gives the plan-review card ('计划待审') a second home in the right sidebar — same card, same decision buttons — with a per-card switch that moves it between the sidebar and the main conversation.
