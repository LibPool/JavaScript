# @loglayer/log-level-manager-one-way

> 标签: log, log level, log level manager, logging, loglayer, one-way

## 简介

Log level manager for loglayer that keeps log levels synchronized between parent and children (parent changes affect children, but child changes don't affect parents).

## 官网

- 官网：https://loglayer.dev
- 源码仓库：git+https://github.com/loglayer/loglayer.git
- npm 页面：https://www.npmjs.com/package/@loglayer/log-level-manager-one-way
