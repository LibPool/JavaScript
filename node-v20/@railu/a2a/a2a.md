# @railu/a2a

> 标签: a2a, advertising, agent-to-agent, agentic, clearing, escalation, railu

## 简介

A2A for a @railu/agent — publish a signed, discoverable agent card and send SIGNED outbound tasks on escalation (the swarm hand-off transport). Peers verify every hand-off against the agent's registered key.
