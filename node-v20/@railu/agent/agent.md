# @railu/agent

> 标签: adcp, advertising, agent, agentic, clearing, detached-clearing, railu, sdk

## 简介

Railu embedded agent runtime — detached clearing + swarm escalation inside your own BYO agent, in a few lines. The same execution-layer code Railu runs at the edge. Isomorphic (Node / Workers / browser); the only dependency is @railu/core.
