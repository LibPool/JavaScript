# @kiqjs/repository

> 标签: crud, data-access, decorator, persistence, repository, typescript

## 简介

Repository abstractions for kiqjs applications. Provides @Repository decorator, CrudRepository interface, and in-memory datasource to simplify data access and persistence layers.
