# @mahmood-khalil57/nuxt-devland

> 标签: JavaScript

## 简介

Devland for Nuxt: the dev server's DevTools over MCP (every RPC function, the open tab, the Nitro server with a debugger), development mail through Mailpit, a supervised `nuxt dev`, and Claude Code in tmux beside it
