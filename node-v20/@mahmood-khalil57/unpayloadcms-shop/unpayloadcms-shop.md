# @mahmood-khalil57/unpayloadcms-shop

## 简介

A made-to-order shop for Payload CMS as a Payload plugin and a Nuxt layer: Payload's ecommerce plugin with Stripe Checkout, radius delivery and pickup, orders the maker moves along, and the storefront's pages, cart and API
