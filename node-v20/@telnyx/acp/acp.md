# @telnyx/acp

> 标签: agent, ai, cli, edge-compute, email, mcp, sms, telnyx, voice

## 简介

One CLI for every agent you ship. From config to conversation in one deploy: describe the agent in agent.json and telnyx-acp deploy puts it on phone calls, texts, email and web chat on Telnyx Edge Compute.
