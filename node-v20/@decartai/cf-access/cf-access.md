# @decartai/cf-access

> 标签: cloudflare-access, middleware, nextjs, vercel, zero-trust

## 简介

Cloudflare Access middleware for Decart internal apps hosted on Vercel. Verifies the Cf-Access-Jwt-Assertion JWT and fails closed.
