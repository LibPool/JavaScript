# @basaltkit/files

> 标签: basalt, files, saas, storage, typescript, uploads

## 简介

File uploads for Basalt: validation (type/size), per-tenant storage quota, metadata records, signed URLs, and hooks (antivirus/thumbnails) over @basaltkit/storage.
