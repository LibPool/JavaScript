# @basaltkit/ai

> 标签: agent, ai, basalt, codegen, developer-experience, typescript

## 简介

AI-native developer experience for Basalt: a provider-agnostic engine plus `basalt ai` CLI that understands the project's stack, analyzes it, and diagnoses issues — following the framework's own conventions, not inventing new ones.
