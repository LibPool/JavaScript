# @basaltkit/i18n

> 标签: basalt, i18n, internationalization, intl, saas, typescript

## 简介

Internationalization for Basalt: context-resolved locale (per user/tenant), typed message catalogs with interpolation and plurals, and Intl-based formatting. Zero dependencies.
