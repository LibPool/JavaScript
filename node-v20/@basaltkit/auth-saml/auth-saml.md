# @basaltkit/auth-saml

> 标签: auth, basalt, saml, sso, typescript

## 简介

SAML 2.0 SSO for @basaltkit/auth — SP-initiated login over @node-saml/node-saml (vetted XML-DSig), plugging into Auth.socialLogin.
