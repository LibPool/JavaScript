# @basaltkit/cache-tiered

> 标签: basalt, cache, multi-level, tiered, typescript

## 简介

Multi-level (tiered) cache driver for @basaltkit/cache — an in-process near cache in front of a far cache (Redis), with read backfill and write/invalidation fan-out. Zero dependencies.
