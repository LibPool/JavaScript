# @basaltkit/notifications-prisma

> 标签: basalt, notifications, postgresql, prisma, store, typescript

## 简介

Prisma-backed implementation of the @basaltkit/notifications InAppStore (in-app notifications) — the production reference backend (PostgreSQL/MySQL). Bring your own PrismaClient; ships a reference schema.
