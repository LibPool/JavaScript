## 简介

鲸鱼娘桌面看板娘插件（DeepSeek Harness 客户端插件）：仅浮窗模式——App 内不渲染宠物，GUI 启动自动唤起桌面独立置顶浮窗；立绘随状态切换、台词气泡、系统通知、指令输入框、GLM Coding Plan 额度面板（5h/周窗口用量、剩余积分、重置倒计时）；Alt+Shift+W / 输入框旁 🐳 按钮随时显隐。
