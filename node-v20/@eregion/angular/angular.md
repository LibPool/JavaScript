# @eregion/angular

> 标签: JavaScript

## 简介

Integração do Eregion (SDK de edição visual com IA) para apps **Angular** em desenvolvimento. Registra o adapter Angular, monta o overlay de seleção + o chat e pede ao daemon o índice estático de componentes.
