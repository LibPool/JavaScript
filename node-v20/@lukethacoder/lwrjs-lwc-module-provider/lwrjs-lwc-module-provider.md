# @lukethacoder/lwrjs-lwc-module-provider

> 标签: JavaScript

## 简介

⚡ An opinionated edit to the @lwrjs/lwc-module-provider package to add support for namespaces and multi directory modules (via @lukethacoder/lwc-module-resolver)
