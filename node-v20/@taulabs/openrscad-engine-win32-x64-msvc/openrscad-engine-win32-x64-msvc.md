# @taulabs/openrscad-engine-win32-x64-msvc

> 标签: 3d, cad, csg, fork, geometry, mesh, openrscad, openscad, scad, wasm, webassembly

## 简介

Tau's fork of the OpenRSCAD geometry engine, compiled to WebAssembly — parse .scad source and render solid 3D meshes in the browser or Node. Adds an authored-scene GLB/3MF export path with source-derived feature edges; tracks upstream.
