# @kirjapro/mcp-server

> 标签: accounting, bookkeeping, chatgpt, claude, finnish, kirjanpito, mcp, mistral, openai

## 简介

MCP server for Finnish accounting — exposes Kirjapro bookkeeping, invoicing, and reporting tools to Claude, ChatGPT, Mistral, and other MCP clients.
