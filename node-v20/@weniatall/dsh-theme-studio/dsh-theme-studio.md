# @weniatall/dsh-theme-studio

> 标签: apple, deepseek-harness, design-tokens, dsh, glass, theme, ui, zcode

## 简介

Theme Studio for DeepSeek Harness: switchable built-in themes (ZCode / Apple Glass), unified design tokens compatible with every dsh plugin, and user-customizable background, fonts and field colors
