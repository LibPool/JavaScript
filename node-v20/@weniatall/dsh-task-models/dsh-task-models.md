# @weniatall/dsh-task-models

> 标签: deepseek-harness, dsh, jev, routing, subagent, task-models, typesafe

## 简介

子任务模型路由插件：按任务类型为子代理选择模型，显式标签优先、规则试运行与路由解释，可选 TypeSafe Jev 决策与轻量分类回退，并区分预选与请求头确认的 workflow 成员模型。
