# @lucianonerydev/fatturapa

> 标签: e-invoice, fattura elettronica, fatturapa, invoice, italy, sdi, xml

## 简介

Build and validate Italian electronic invoices (FatturaPA FPR12) from integer cents, with SDI-consistent totals. Zero dependencies.
