# @amittksharma/leaklint

> 标签: bunyan, ci, cli, compliance, data-leak, data-leak-prevention, devsecops, gdpr, javascript, junit, linter, log-security, logging, pii, pino, sarif, sast, secret-detection, secrets, security, sensitive-data, static-analysis, typescript, winston

## 简介

Find log statements that leak secrets or personal data (PII) in JavaScript and TypeScript. A zero-config CI gate with fix suggestions, baselines for legacy code, and SARIF, JUnit and HTML reports.
