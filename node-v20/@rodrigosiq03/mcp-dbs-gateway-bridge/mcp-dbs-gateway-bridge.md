# @rodrigosiq03/mcp-dbs-gateway-bridge

> 标签: JavaScript

## 简介

Bridge stdio<->HTTP pro mcp-dbs-gateway, autenticando com login Gates real (Cognito, PKCE) em vez de token bespoke. Roda na máquina de cada pessoa, spawnado pelo cliente MCP (ex: Claude Desktop) — zero config além do mcpServers apontar pra `npx -y @rodrig
