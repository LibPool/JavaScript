# @lawallet/sdk

> 标签: hooks, lawallet, lightning, lud16, nip98, nostr, nwc, react

## 简介

Nostr-first TypeScript client and React hooks for LaWallet instances — NIP-98 signed requests, lightning address registration, NWC wallets, LUD-16 and live events
