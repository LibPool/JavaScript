# @tslite/monaco

> 标签: completion, language-service, markers, monaco, monaco-editor, quickfix, semantic-tokens

## 简介

Monaco editor integration driven by a LanguageService: markers, completion, hover, quick-fixes, semantic tokens, definition and formatting. Language-agnostic — it never imports a language.
