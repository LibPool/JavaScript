# @tslite/react

> 标签: autocomplete, codemirror, expression, headless, input, mustache, nocode, react, typescript

## 简介

React bindings for TSLite — a headless expression field (CodeMirror 6) with type-aware highlighting, completion, diagnostics and quick-fixes, driven by the TSLite checker.
