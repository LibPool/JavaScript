# @tslite/sdk

> 标签: ast, codegen, dsl, estree, json, parser-agnostic, serializable, typescript

## 简介

TSLite — the JavaScript AST, ready to use: lightweight, normalized, serializable; the full SDK (parse, type-check, run eval-free, emit, serialize).
