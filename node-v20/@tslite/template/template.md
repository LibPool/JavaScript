# @tslite/template

> 标签: control-flow, interpolation, mustache, template, tslite, twig, typed-template

## 简介

Template front-end for TSLite: {{ expressions }} plus {% if %} / {% for %} control flow, lowered to the Language's own AST. No new semantics — the checker types it, the codegen emits it.
