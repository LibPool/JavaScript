# @tslite/estree

> 标签: acorn, ast, estree, meriyah, normalize, parser-agnostic, typescript

## 简介

TSLite estree — the bridge from any ESTree parser (Meriyah, Acorn, Esprima, Babel) into TSLite's canonical AST: normalize() strips parser metadata and the syntactic type-node
