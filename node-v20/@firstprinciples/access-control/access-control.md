# @firstprinciples/access-control

> 标签: abac, access-control, authorization, express, fastify, hono, isomorphic, permissions, rbac, react, typescript

## 简介

Isomorphic RBAC/ABAC permission engine: one portable rule schema, deny-by-default order-independent resolution, ownership rules that fail closed, Express/Fastify/Hono guards and React <Can>/usePermission over the same policy.
