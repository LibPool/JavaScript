# @firstprinciples/http-client

> 标签: abort-controller, api-client, fetch, http-client, result, retry, typescript

## 简介

A typed fetch wrapper: discriminated-union results (never thrown exceptions), retry with backoff, combined timeout/abort, and a pluggable validation adapter.
