# @jeffreyhaen/ado-axi

> 标签: ado, agent, axi, azure-devops, cli, pipelines, pull-requests, toon, work-items

## 简介

Agent-ergonomic CLI for Azure DevOps — work items, pull requests, and pipelines through token-efficient TOON output. An AXI (Agent eXperience Interface) over the Azure DevOps REST API.
