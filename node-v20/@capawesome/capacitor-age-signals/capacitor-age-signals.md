# @capawesome/capacitor-age-signals

> 标签: age assurance, age gate, age signals, age verification, capacitor, capacitor-plugin, declared age range, native, parental controls, play age signals, plugin

## 简介

Capacitor plugin to retrieve age-related signals for users via the Play Age Signals API on Android and the Declared Age Range framework on iOS.
