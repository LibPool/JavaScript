# @frigear-nu/auth

> 标签: JavaScript

## 简介

Authentication for the frigear ecosystem: sign-in flows (password, magic link, OAuth, passkeys), user API tokens, and a shared requireAuth for sessions, tokens and OAuth access tokens, with scopes.
