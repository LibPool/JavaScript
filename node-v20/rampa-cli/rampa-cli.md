> 标签: a11y, accessibility, accessibility-checker, accessibility-testing, act-rules, ai, alt-text, axe-core, cli, llm, ollama, wcag, wcag2, web-accessibility

## 简介

Open-source WCAG accessibility checker: axe-core plus per-criterion LLM judgment with verified evidence, for web pages, in a terminal or in CI.
