# @lyboai/mcp

> 标签: agents, claude, edge-ai, mcp, model-context-protocol, on-device-ai, private-ai

## 简介

MCP server for the LyboAI Edge Runtime — tag/call your private on-device agent from Claude, Cursor, VS Code or any MCP client (lyboai_ask, per-skill tools, ingest_context).
