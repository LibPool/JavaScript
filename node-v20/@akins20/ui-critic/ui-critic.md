# @akins20/ui-critic

> 标签: accessibility, agent, chatgpt, claude, claude-code, critique, design-review, gemini, gpt, openai, playwright, screenshots, ui, visual-regression

## 简介

A second pair of eyes for a UI: capture screenshots and measured facts, get a ranked visual critique from Gemini or OpenAI, and verify before and after. Built so one coding agent (Claude Code) can ask another model for design review.
