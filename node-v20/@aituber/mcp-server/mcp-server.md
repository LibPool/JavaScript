## 简介

AITuber MCP server, hosted at https://mcp.aituber.app. Create AI videos with narration, visuals, and captions, then publish to YouTube, TikTok, Instagram, Facebook, Threads, and X from Claude Desktop, Claude Code, ChatGPT, Codex, Cursor, or OpenClaw.
