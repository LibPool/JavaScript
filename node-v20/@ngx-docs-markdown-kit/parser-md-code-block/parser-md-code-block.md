# @ngx-docs-markdown-kit/parser-md-code-block

> 标签: angular, code-block, docs, markdown, syntax-highlighting

## 简介

Extension de @ngx-docs-markdown-kit/parser-md que reconoce bloques de codigo enriquecidos y tarjetas de comando (fences code-block/card-code-block), y expone los componentes de Angular (CodeBlockComponent, CardCodeBlockComponent) que los renderizan.
