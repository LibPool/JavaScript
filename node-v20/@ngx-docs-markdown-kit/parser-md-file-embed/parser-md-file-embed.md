# @ngx-docs-markdown-kit/parser-md-file-embed

> 标签: angular, code-block, docs, file-embed, markdown

## 简介

Extension de @ngx-docs-markdown-kit/parser-md que reconoce un fence "file-embed" y embebe el contenido real de un archivo de public/ (o uno o varios rangos de lineas) dentro de un code-block, siempre sincronizado con el archivo real -- sin copiar/pegar co
