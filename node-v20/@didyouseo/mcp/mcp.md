# @didyouseo/mcp

> 标签: chatgpt, claude, cursor, didyouseo, geo, mcp, model-context-protocol, search-console, seo, seo-audit

## 简介

Connect DidYouSEO's SEO audit and site tools to any MCP client (Claude, ChatGPT, Cursor). A stdio bridge to the DidYouSEO remote MCP server, with OAuth handled for you.
