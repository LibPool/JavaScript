# @csgaglobal/api-gateway

> 标签: ai-governance, api-gateway, authentication, compliance, csoai, mcp, rate-limiting, routing

## 简介

MCP API gateway for managing, routing, and securing access to CSGA governance MCP servers. Provides rate limiting, authentication, usage analytics, and unified access control.
