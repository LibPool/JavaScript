# @worldcitisim/mcp-esim

> 标签: commerce, esim, mcp, modelcontextprotocol, server, travel, worldcitisim

## 简介

MCP server for the Worldcitisim eSIM API — lets Claude and other MCP-compatible agents search plans and create eSIM orders.
