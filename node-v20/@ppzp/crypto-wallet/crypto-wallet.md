# @ppzp/crypto-wallet

> 标签: ethereum, web3

## 简介

**简化**和**统一**加密钱包（crypto wallet）的操作： + 连接钱包 + 检查链 id（chainId） + 切换链 + 添加链 + 监听账户切换 + 监听链（network）切换
