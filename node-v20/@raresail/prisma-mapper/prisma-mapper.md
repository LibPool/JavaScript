# @raresail/prisma-mapper

> 标签: camel, camel-case, cli, generate, json, map, mapper, nodejs, prisma, schema, typescript

## 简介

A CLI that adds @Map, @@Map, @updatedAt based on a json or camel case for the prisma schema
