# @williambelle-co/monitoring

> 标签: dependencies, diagnostics, drift, monitoring, observability

## 简介

Reports what only a running process can see — runtime version, environment name, and the package versions actually installed — to a William Belle LLC monitoring endpoint. Read-only and one-way: it exposes no endpoint, accepts no commands, collects no logs
