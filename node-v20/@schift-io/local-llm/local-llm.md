# @schift-io/local-llm

> 标签: legal, offline-llm, on-device, privacy, transformers.js, webgpu, webllm

## 简介

On-device LLM inference for Schift Lawyers Ultra Secure Mode. WebGPU (MLC WebLLM) + WASM (transformers.js) fallback. Zero network egress.
