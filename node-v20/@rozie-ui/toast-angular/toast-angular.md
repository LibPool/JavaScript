# @rozie-ui/toast-angular

> 标签: JavaScript

## 简介

Idiomatic Angular headless, accessible toast / notification host (queue, auto-dismiss, hover-pause, positioning, imperative show/dismiss/clear handle) — one accessible Rozie source compiled to Angular.
