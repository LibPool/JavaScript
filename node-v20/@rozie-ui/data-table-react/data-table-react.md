# @rozie-ui/data-table-react

> 标签: accessibility, aria, component, data-table, datagrid, headless, react, rozie, rozie-ui, table, table-core, tanstack-table

## 简介

Idiomatic React headless WAI-ARIA data table (sorting, filtering, pagination, selection, column visibility/resize/reorder/pinning) on @tanstack/table-core — one accessible Rozie source compiled to React.
