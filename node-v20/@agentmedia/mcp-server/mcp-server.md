# @agentmedia/mcp-server

> 标签: agent-media, ai, ai-agent, claude-code, cursor, developer-tools, mcp, model-context-protocol, product-ugc, product-video, talking-head, text-to-video, ugc, video-generation, windsurf

## 简介

MCP server for agent-media — a stdio proxy to the hosted connector at api.agent-media.ai/mcp. Generate AI UGC videos from Claude Code, Cursor, Windsurf, or any MCP-compatible client.
