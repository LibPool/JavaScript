# @cs4alhaider/screenbook

> 标签: ai-agents, design, design-tokens, mcp, mockups, no-build, prototype-studio, prototyping

## 简介

ScreenBook — a design workspace for AI agents to present to humans. HTML screens + JSON data in real device frames, with review mode, flows, themes, self-tests, a CLI and an MCP server. Fully offline, no build step, and any MCP agent can drive it.
