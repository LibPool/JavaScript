# @bryel/feedback-browser

> 标签: browser, bryel, client-side, evals, feedback, observability, rlhf

## 简介

Record user feedback — 👍/👎, scores, comments, corrections, labels — from the browser with a publishable (bkp_) key. Client-safe, no OTel, zero config.
