# @hartaithan/trophy-scout

> 标签: JavaScript

## 简介

Client for the Trophy Scout API. It manages the session token for you, wraps the JSON endpoints and turns the streaming (SSE) endpoints into promises with progress callbacks. Optional analytics: flows, correlation headers and structured errors.
