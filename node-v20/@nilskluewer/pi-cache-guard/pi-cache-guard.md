# @nilskluewer/pi-cache-guard

> 标签: anthropic, cache, cost, pi, pi-coding-agent, pi-extension, pi-package, prompt-cache

## 简介

Pi extension with a prompt-cache countdown and cost warnings. Dynamically adjusts cache estimates from API-reported hits and misses. With contributions from @paulrohde675.
