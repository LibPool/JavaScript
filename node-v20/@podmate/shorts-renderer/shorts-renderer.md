# @podmate/shorts-renderer

> 标签: podcast, podmate, remotion, shorts, video

## 简介

podmate (pm shorts) の縦型ショート動画 描画エンジン（Remotion）。`npx @podmate/shorts-renderer init` でローカルに展開し、pm shorts render から使う。

## 官网

- 官网：https://podmate.fm
- npm 页面：https://www.npmjs.com/package/@podmate/shorts-renderer

## 历史版本号

- 当前版本：0.1.0

- 0.1.0

## 获取地址

- npm 安装：`npm install @podmate/shorts-renderer`
- npm registry：https://registry.npmjs.org/@podmate/shorts-renderer
- Node 要求：>=20
