# @propjockey/breakpoint-system

> 标签: breakpoint, breakpoint units, css, media queries, named breakpoints

## 简介

Highly accessible, responsive CSS designed in pixels and implemented 1:1 with the new Breakpoint Unit for a flawless fluid experience. Custom aliases, breakpoints, and queries with heavily researched defaults. No scripts, no builds, 100% vanilla CSS. Old
