# @fastcar/mcp-vision-tools

> 标签: claude-code, codex, deepseek, gpt, image, kimi-code, mcp, multimodal, video, vision

## 简介

Universal MCP vision tools (image + video frame understanding). Delegates to any OpenAI-compatible multimodal model, so text-only agents like DeepSeek can "see" via tool calls.
