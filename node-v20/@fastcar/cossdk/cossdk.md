# @fastcar/cossdk

> 标签: cos, file

## 简介

FastCar COS SDK 封装，用于访问 FastCar COS 服务端提供的文件上传、下载、目录管理、权限管理、重定向、账号管理和图片处理接口。

- 官网：https://github.com/williamDazhangyu/fast-car
- 源码仓库：git+https://github.com/williamDazhangyu/fast-car.git
