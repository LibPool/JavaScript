# @dewsoft/landing-kit

> 标签: bilingual, boilerplate, i18n, landing-page, mongolian, react, scaffold, seo, tanstack-start

## 简介

Scaffolds a bilingual (Mongolian + English) landing site: prerendered static HTML, per-locale SEO, and swappable blocks.
