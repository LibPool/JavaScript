# dsh-jingjing-sticky-notes

> 标签: deepseek-harness, dsh, dsh-plugin, markdown, notes, sidebar, sticky-notes

## 简介

把对话中的回复、选区或整段对话收藏为本地 Markdown 便签，并在右侧栏随时查看、对比与插回输入框。
