# @ixo/openhands-sdk

> 标签: claims, cosmos, ixo, openhands-network, sdk, udid

## 简介

The Openhands protocol, board, campaign, chain, rubric, geo and UDID modules as one tree-shakeable package. Configuration is passed in (configure()) rather than read from the environment at import.
