## 简介

可转债情报局 Convertible Bond Intel：DeepSeek Harness 可转债插件——行情早报、强赎监控（最后交易日/最后转股日）、配债测算、条款科普。Convertible bond plugin for DeepSeek Harness (dsh-plugin). 仅科普，不构成投资建议。
