# @pfncl/registry-lexicons

> 标签: astrocms, atproto, cms, fair, lexicons, plugin-registry

## 简介

Generated TypeScript types for AstroCMS plugin registry lexicons (com.astrocms.experimental.*). EXPERIMENTAL: NSIDs and shapes will change.
