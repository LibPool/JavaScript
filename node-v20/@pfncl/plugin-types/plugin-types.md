# @pfncl/plugin-types

> 标签: astrocms, cms, manifest, plugin, types

## 简介

Shared TypeScript types for the AstroCMS plugin manifest contract: capability vocabulary, manifest shape, hook/route entry types. Consumed by core (manifest reader at install/runtime) and plugin-cli (manifest writer at bundle/publish time).
