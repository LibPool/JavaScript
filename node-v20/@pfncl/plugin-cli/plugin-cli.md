# @pfncl/plugin-cli

> 标签: astrocms, atproto, cli, cms, fair, plugin, plugin-cli, plugin-registry

## 简介

CLI for authoring, building, and publishing AstroCMS plugins. Covers init / build / dev / bundle / publish plus registry search and identity. Atproto OAuth, FAIR-shaped records, sandboxed-plugin-only.
