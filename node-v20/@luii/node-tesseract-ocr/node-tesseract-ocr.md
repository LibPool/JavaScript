# @luii/node-tesseract-ocr

> 标签: cmake-js, leptonica, node-addon-api, ocr, tesseract

## 简介

Native C++ addon for Node.js that exposes Tesseract OCR (`libtesseract-dev`) to JavaScript/TypeScript.
