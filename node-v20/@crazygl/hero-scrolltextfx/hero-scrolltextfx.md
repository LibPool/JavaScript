# @crazygl/hero-scrolltextfx

> 标签: animation, canvas, component, crazygl, frontend, hero, hero-section, interactive, landing-page, letter, react, scroll, scrolltextfx, three, typography, ui, webgl

## 简介

Scroll Text FX — Each letter scales, rotates and brightens as it passes the scroll midpoint — an editorial mid-line emphasis effect. A customizable CrazyGL animated hero section — WebGL, React, drop-in.
