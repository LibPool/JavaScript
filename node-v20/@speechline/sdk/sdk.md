# @speechline/sdk

> 标签: asr, diarization, llm, pipeline, speech-to-text, speechline, streaming, text-to-speech, translation, tts, websocket, webtransport

## 简介

Speechline TypeScript SDK — author GStreamer-style media pipelines (ASR, TTS, LLM, translate, diarize) that run server-side, plus low-level ASR/TTS/LLM clients.
