# @deot/vc-full

> 标签: JavaScript

## 简介

`@deot/vc-full` 是 `@deot/vc` 的全量注册包：在导出 `@deot/vc` 全部内容的基础上，提供注册全部组件的 `createVcPlugin()` 和组件集合 `Components`。
