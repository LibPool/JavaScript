# @bezrutin/cms

> 标签: bezrutin, cms, react, site-builder

## 简介

Public SDK для разработки сайтов на платформе Bezrutin — runtime API (defineBlock/definePageLayout/defineSiteLayout/definePageTemplate/defineSite/defineProject) + CLI.
