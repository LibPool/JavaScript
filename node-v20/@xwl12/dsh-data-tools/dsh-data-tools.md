# @xwl12/dsh-data-tools

> 标签: database, dsh, mysql, plugin, sql

## 简介

Read-only MySQL tooling for DeepSeek Harness: connection introspection, schema discovery, and guarded SELECT queries so the agent can see the database before writing code.
