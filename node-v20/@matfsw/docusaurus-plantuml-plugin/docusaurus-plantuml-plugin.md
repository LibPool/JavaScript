# @matfsw/docusaurus-plantuml-plugin

> 标签: browser, diagram, docusaurus, docusaurus-plugin, plantuml, svg, uml

## 简介

Render PlantUML diagrams in Docusaurus 3 entirely in the browser - no Java, no PlantUML server, no CDN.
