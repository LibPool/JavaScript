# @query-kit/vue

> 标签: advanced-search, condition, data-table, datatable, filter, filter-builder, filtering, operators, pagination, query, query-builder, schema-driven, search, typescript, ui, vue, vue3

## 简介

Vue 3 query builder and filter UI components, plus a schema-driven, sortable and paginated data table for displaying results. Server-side querying, written in TypeScript.
