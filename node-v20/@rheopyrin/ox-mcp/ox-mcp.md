# @rheopyrin/ox-mcp

> 标签: caldav, calendar, carddav, contacts, email, imap, mcp, model-context-protocol, open-xchange, sieve, smtp

## 简介

MCP server for Open-Xchange and standards-based mail platforms: email (IMAP/SMTP), mail filters (Sieve), calendar (CalDAV), contacts (CardDAV), and free/busy scheduling.
