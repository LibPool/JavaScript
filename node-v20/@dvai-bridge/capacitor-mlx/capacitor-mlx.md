# @dvai-bridge/capacitor-mlx

> 标签: apple-silicon, capacitor, dvai-bridge, llm, mlx, on-device

## 简介

DVAI-Bridge Capacitor plugin: MLX (Apple Silicon GPU/Neural Engine) LLM inference via mlx-swift-lm, with embedded HTTP server. iOS 17+ at link time; Apple-Silicon-only at runtime.
