# @tagscript/plugin-discord

> 标签: bot tag, discord, discord-api-types, discord-bot, discord.js, safe string, sandbox, string parser, tag, tagscript, tagscript discord, template, template engine, template string, templating, typescript, user-generated-content

## 简介

Library agnostic Discord parsers and transformers for TagScript: embeds, cooldowns, permissions and mentions from user-written templates.
