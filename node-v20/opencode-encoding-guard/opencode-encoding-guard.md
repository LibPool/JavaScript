# opencode-encoding-guard

> 标签: charset, eclipse, encoding, iso-8859-1, java, latin1, legacy, mojibake, opencode, opencode-plugin, windows-1252

## 简介

OpenCode V2 plugin that preserves the original text encoding (ISO-8859-1, Windows-1252, UTF-8, UTF-8 BOM), line endings and BOM when agents edit, write or patch files.
