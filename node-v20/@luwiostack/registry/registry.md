# @luwiostack/registry

> 标签: auto-registration, luwio, plugin, registry, virtual-module, vite

## 简介

The shared registry + Vite auto-discovery primitive behind @luwiostack/router and @luwiostack/translations: a tiny module-singleton registry (add/get/all, dedup by id) and a Vite plugin factory that scans suffixed files and self-registers their exports.
