# @luwiostack/language

> 标签: hooks, i18n, intl, iso-639, language, locale, luwio, react

## 简介

Typed ISO 639 language data for React — a small domain model over the ISO 639-1/2/3 list, with a `<Language>` provider and `useLanguage` hook.
