# @cvfile/cv-detector

> 标签: crawler, cv, open-format, pdf, rag, resume, sniffer

## 简介

Tiny reference sniffer for the .cv open file format. Detects .cv wrapping inside any application/pdf and unwraps the canonical Markdown payload.
