# @huiliyi37/dsh-tool-json-repair

> 标签: JavaScript

## 简介

Repair plugin for the DeepSeek tool-JSON-in-content shape: converts a text block that is exactly one tool-call JSON object into a real tool-call block on the llm/stream waterfall
