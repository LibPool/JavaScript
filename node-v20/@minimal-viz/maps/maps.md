# @minimal-viz/maps

> 标签: charts, choropleth, deck.gl, echarts, geospatial, maplibre, maps, react, satellite-package

## 简介

Optional satellite package for xviz — adds 13 deck.gl-powered map chart types (PointClusterMap, Cartodiagram, DeckGL Arc/Geojson/Grid/Hex/Heatmap/Multi/Path/Polygon/Scatter/Screengrid/Contour). Uses maplibre-gl@^5 (BSD-3 license, no token required).
