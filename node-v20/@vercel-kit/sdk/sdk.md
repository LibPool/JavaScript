# @vercel-kit/sdk

> 标签: JavaScript

## 简介

Kit from any runtime: sign users in, act as them, drive their Kit, and (via ./eve) proxy an eve agent's connections through Kit as the requesting user - one tool table every face (MCP, CLI, REST) renders from.
