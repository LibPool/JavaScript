# @sonal-labs/flexible-rate-limiter

> 标签: express, fixed-window, middleware, rate-limiter, rate-limiting, redis, sliding-window, throttle, token-bucket

## 简介

A production-ready, framework-agnostic rate limiter supporting token bucket, sliding window log, sliding window counter, and fixed window algorithms with pluggable storage backends.
