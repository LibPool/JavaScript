# @a_harmless_pyro/proxy-chain

> 标签: JavaScript

## 简介

Node.js implementation of a proxy server (think Squid) with support for SSL, authentication, upstream proxy chaining, and protocol tunneling.

- 源码仓库：git+https://github.com/AHarmlessPyro/proxy-chain
- npm 页面：https://www.npmjs.com/package/@a_harmless_pyro/proxy-chain
