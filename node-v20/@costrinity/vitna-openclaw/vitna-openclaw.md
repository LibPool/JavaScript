# @costrinity/vitna-openclaw

> 标签: agent-containment, human-in-the-loop, openclaw, openclaw-plugin, rogue-agents, vitna

## 简介

VITNA for OpenClaw: every tool call OpenClaw routes through the plugin (shell, files, browser, messaging, MCP) is checked by VITNA first; calls to tools you mark as risky wait for a person. Fails closed.
