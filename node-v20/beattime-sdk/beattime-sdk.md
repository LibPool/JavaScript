# beattime-sdk

> 标签: beat, beats, beattime, clock, internet-time, proof-of-existence, time, timestamp, universal-time, utc

## 简介

BeatTime — one universal time: 1000 .beats/day, anchored to UTC, no timezones. Local @beat clock plus the open beattime.live API and proof-of-existence.
