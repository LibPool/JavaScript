# @openagentsinc/qa-runner

> 标签: agent, bring-your-own-model, computer-use, e2e, local-first, openai-compatible, oss, playwright, qa, testing

## 简介

OSS, local-first, runtime-agnostic autonomous-QA runner. Drive any web target with a bring-your-own OpenAI-compatible model (no login), record a playable video + Playwright trace + screenshots, and distill the session into a committed e2e test. Khala / Op
