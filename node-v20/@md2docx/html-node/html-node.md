# @md2docx/html-node

> 标签: @m2d/html-node, @md2docx/html-node, @mdast2docx/html-node, html, html-in-markdown, html-to-mdast, linkedom, markdown-to-docx, md2docx, mdast, server-side, turboforge

## 简介

Server-side HTML to MDAST plugin for md2docx using linkedom. Converts HTML elements in Markdown into DOCX-compatible MDAST nodes on Node.js.
