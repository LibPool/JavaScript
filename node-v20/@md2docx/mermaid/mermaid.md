# @md2docx/mermaid

> 标签: code-block, diagram-plugin, document-conversion, document-generation, docx, docx-generator, m2d, markdown, markdown-to-docx, mayank1513, md2docx, mdast, mdast-to-docx, mdast2docx, mermaid, mindmap, open-source, plugin, remark-plugin, svg-diagram, typescript, unified-plugin

## 简介

Enhance Markdown-to-DOCX conversion with Mermaid and mindmap diagram support using this plugin for @m2d/core. Converts code blocks into SVG images with customizable Mermaid config.
