# @fjall/schema-gate

> 标签: JavaScript

## 简介

Schema-version gate runner for the synthetic fjall-schema-gate ECS container. Verifies the deployed image's expected schema version against the live database (Postgres + ClickHouse) and exits with a structured taxonomy so a refusing task stops pre-RUNNING
