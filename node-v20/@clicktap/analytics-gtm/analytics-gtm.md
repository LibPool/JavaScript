# @clicktap/analytics-gtm

> 标签: clicktap, ga4, google-tag-manager

## 简介

GA4 ecommerce events on the Google Tag Manager dataLayer for the Clicktap state machines: item mapping, event builders, a consent-gated push and a purchase that fires once per order.
