# @devlensio/cli

> 标签: ai, architecture, code-graph, codebase, go, impact-analysis, java, javascript, llm, mcp, python, rust, security, static-analysis, typescript

## 简介

DevLens CLI — turn any TypeScript, JavaScript, Python, Go, Rust, or Java codebase into a queryable graph of nodes and typed edges, with per-node functional, technical, and security summaries. Commands: detect, analyze, summarize, overview, top-nodes, find
