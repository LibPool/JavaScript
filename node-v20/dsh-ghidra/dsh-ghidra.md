# dsh-ghidra

> 标签: decompiler, deepseek-harness, disassembler, dsh, dsh-plugin, ghidra, ghidramcp, malware-analysis, mcp, pyghidra, reverse-engineering

## 简介

Ghidra bridge plugin for DeepSeek Harness (DSH): 219 reverse-engineering tools — import binaries, decompile, xrefs, search, script Ghidra, plus the full upstream GhidraMCP REST surface, served from a single Ghidra JVM. Cross-platform (Windows, Linux, macO
