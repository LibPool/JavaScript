# @petriflow/vercel-ai

> 标签: ai-agent, guardrails, petri-net, safety, tool-use, vercel-ai

## 简介

Petri net gating adapter for the [Vercel AI SDK](https://sdk.vercel.ai/) (v6+). Wraps tool definitions so each `execute` call is gated by `@petriflow/gate`.
