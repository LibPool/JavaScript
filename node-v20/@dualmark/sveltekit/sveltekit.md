# @dualmark/sveltekit

> 标签: aeo, ai-search, answer-engine-optimization, dualmark, llms-txt, markdown, svelte, sveltekit

## 简介

SvelteKit adapter for the Dualmark AEO framework. Generates .md endpoints, llms.txt, and a handle hook for bot-aware content negotiation.
