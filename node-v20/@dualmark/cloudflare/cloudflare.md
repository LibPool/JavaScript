# @dualmark/cloudflare

> 标签: aeo, ai-agents, ai-search, answer-engine-optimization, cloudflare, cloudflare-workers, dualmark, edge, workers, wrangler

## 简介

Cloudflare Workers edge adapter for the Dualmark AEO framework. Wraps any upstream Worker and transparently serves markdown to AI bots.
