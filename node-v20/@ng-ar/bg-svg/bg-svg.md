# @ng-ar/bg-svg

> 标签: Angular, Angular13, angular_svg, svg, svg_background

## 简介

This library help us to set background image for the component. You can wrap this(as top element) with any component's html element to give background effect to that component or wrap around `<router-outlet></router-outlet>` to get the same background to
