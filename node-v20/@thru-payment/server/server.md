# @thru-payment/server

> 标签: checkout, cloudflare-workers, payments, stablecoin, thru, webhooks

## 简介

Server-side SDK for thru: create hosted checkout sessions, verify the shopper's return, and verify webhooks. Web Crypto only — runs on Node, Cloudflare Workers, Deno and Bun.
