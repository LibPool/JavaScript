# @good-drive/server

> 标签: JavaScript

## 简介

Good drive is a file-sharing/cloud-storage service, presently intended to provide an alternative to e.g. google drive, for use in the bunch ecosystem The project planning is done in [this trello board](https://trello.com/b/Ff5Ejwxu/good-drive)
