# @pixelium/web-vue

> 标签: canvas, pixel ui lib, pixelium-design, vue ui lib

## 简介

A pixel-art UI component library for Vue, built with TypeScript and Vite. Nostalgic aesthetics, tree-shakable components, dark and light themes, full type safety, ready to use right out of the box.
