# @idriszade/v5-linkedin-profile-tracker

> 标签: apify, atom, linkedin, pipeline-kit, profile-tracker, sales-intelligence

## 简介

Atom V5 — LinkedIn Profile Tracker. Tracks LinkedIn profile changes via Apify snapshots, classifies change type (job change, promotion, company exit, headline update), and assesses outreach/sales opportunity.
