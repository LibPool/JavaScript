# serp402-mcp

> 标签: agents, base, google, mcp, model-context-protocol, news, places, search, serp, shopping, solana, usdc, web-search, x402

## 简介

MCP server for serp402: Google search (web, news, images, videos, places, shopping, scholar) paid per call in USDC over x402. No API key, no account.
