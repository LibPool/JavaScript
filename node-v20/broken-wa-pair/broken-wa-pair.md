# broken-wa-pair

> 标签: auth, baileys, creds, no-qr, pair-code, pairing-code, session, session-id, whatsapp, whatsapp-bot

## 简介

Get a WhatsApp pairing code or session from a phone number. No QR scanning, no API key. Dual ESM + CJS, TypeScript types.
