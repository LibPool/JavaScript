# @cityjson/cjconv

> 标签: 3d-city-model, cityjson, cityjsonseq, cityparquet, cli, duckdb, flatcitybuf, obj

## 简介

Convert between 3D city model formats (CityJSON, CityJSONSeq, FlatCityBuf, CityParquet, OBJ) from the command line or Node, with the cityjson DuckDB extension.
