# @cityjson/cjconv-core

> 标签: 3d-city-model, cityjson, cityjsonseq, cityparquet, duckdb, flatcitybuf, obj

## 简介

Engine-agnostic core of cjconv: detects 3D city model formats and builds the SQL the cityjson DuckDB extension converts them with.
