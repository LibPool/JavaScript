# @mersennet/sdk

> 标签: blockchain, evm, json-rpc, mersennet, order-book, perpetuals, sdk, zk

## 简介

TypeScript SDK for Mersennet: JSON-RPC, the on-chain order book (MersennetOrders precompile), agent keys, liquidations, shielded notes and viewing keys
