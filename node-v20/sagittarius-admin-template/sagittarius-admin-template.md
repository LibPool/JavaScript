# sagittarius-admin-template

> 标签: admin, admin-template, angular, angular-material, dark-mode, dashboard, drawer, layout, material3, sidebar

## 简介

Angular admin layout: collapsible sidebar, header with user menu, stacked drawers, footer, design tokens (light/dark) and page CSS utilities. Built on Angular Material 3.
