# @zackrobertstech/n8n-nodes-crowdstrike-api-us2

> 标签: n8n-community-node-package

## 简介

n8n community node for the CrowdStrike Falcon API for Crowdstrike tenants in the US2 Region. Interact with detections, alerts, devices, network containment, threat intelligence, and more via OAuth2-authenticated REST endpoints.
