# @readystack/cloud-manifest-audit-kit

> 标签: aks, helm, iot-edge, kubernetes, microprofile

## 简介

For platform engineers on AKS: 28 rules naming every removed apiVersion, literal credential and :latest tag in the file you have open, and 40 snippets written against the versions that still exist.
