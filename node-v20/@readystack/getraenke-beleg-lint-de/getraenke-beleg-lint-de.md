# @readystack/getraenke-beleg-lint-de

> 标签: alkoholsteuer, emcs, lint, rechnung, spirituosen, verbrauchsteuer, xrechnung, zoll

## 简介

Prüft Rechnungs- und Lieferschein-Vorlagen im Repository auf die Nachweisfelder der deutschen Alkoholsteuer: ARC, Verbrauchsteuernummer, hl rA, % vol, Steuersatz.
