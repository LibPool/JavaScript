# @readystack/bem-class-extractor-html

> 标签: bem, class names, css, html, scss

## 简介

16 BEM naming rules read the HTML file you have open and 22 markup and SCSS skeletons write the stylesheet shell, so the class names get fixed before the pull request comes back for them.
