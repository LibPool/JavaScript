# @kidkender/archmind-laravel-parser

> 标签: api-contract, archmind, form-request, laravel, parser, php, static-analysis

## 简介

Static analysis parser for Laravel projects — extracts routes, middleware chains, FormRequest validation rules, and auth patterns into ArchMind IR graphs.
