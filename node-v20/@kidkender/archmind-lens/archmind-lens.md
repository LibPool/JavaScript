# @kidkender/archmind-lens

> 标签: archmind, call-graph, go, mcp, static-analysis

## 简介

Symbol-first context for Go services: from any function, find the HTTP routes, background loops, callbacks and startup code that reach it, and whether the call runs inside a database transaction.
