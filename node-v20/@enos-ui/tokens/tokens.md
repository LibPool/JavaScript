# @enos-ui/tokens

> 标签: css, design-system, design-tokens, frontend, sass, styles, ui-kit

## 简介

A collection of design tokens defining the visual language for our projects. This package contains color palettes, typography settings, spacing, and other atomic design elements used across all applications for consistent UI/UX.
