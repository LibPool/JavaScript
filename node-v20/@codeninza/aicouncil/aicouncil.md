# @codeninza/aicouncil

> 标签: ai, consensus, council, llm-council, multi-model, oh-my-pi, omp, pi-extension, pi-package

## 简介

A council of frontier models for oh-my-pi: independent opinions → anonymized peer review → chairman synthesis, running on your existing subscriptions (Anthropic, Codex, Antigravity — no API keys).
