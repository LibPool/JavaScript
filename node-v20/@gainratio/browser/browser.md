# @gainratio/browser

> 标签: browser, content-addressed, ed25519, integrity, local-first, offline-first, opfs, signed-bundle, typescript, web-worker, zstd

## 简介

For web developers: have the browser check that downloaded data was signed by you and not changed, then keep it for offline use.
