# @koishi-ce/koishi-shim

> 标签: JavaScript

## 简介

上游包名 koishi 的下游兼容 shim：供脚手架生成的项目以 npm alias（"koishi": "npm:@koishi-ce/koishi-shim@^4.18.11"）钉住裸名，将社区生态的 koishi 依赖指回 @koishi-ce/koishi
