# @koishi-ce/console-shim

> 标签: JavaScript

## 简介

上游包名 @koishijs/plugin-console 的下游兼容 shim：供脚手架生成的项目以 npm alias（"@koishijs/plugin-console": "npm:@koishi-ce/console-shim@^5.30.11"）钉住该名，把社区生态与 CE 插件对上游 console 的 peer 依赖指回 @koishi-ce/plugin-console，避免 Bun 的 peer 自动安装拉下 npm 官方 console 形成双实例。版本冻结 5.30.x 线以满足

## 官网

- npm 页面：https://www.npmjs.com/package/@koishi-ce/console-shim
