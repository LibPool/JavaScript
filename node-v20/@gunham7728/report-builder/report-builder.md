# @gunham7728/report-builder

> 标签: JavaScript

## 简介

표/차트 기반 보고서를 **편집**하고 **미리보기/출력**할 수 있는 React 컴포넌트입니다. 데이터(JSON)를 넘기면 `{{key}}` 템플릿으로 셀·차트에 값이 바인딩되고, 배열을 넘기면 표/차트가 자동으로 반복됩니다.
