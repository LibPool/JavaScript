# @sentimentracker/signals-mcp

> 标签: agent, indicators, llm, mcp, model-context-protocol, sentimentracker, trading-signals

## 简介

Model Context Protocol server exposing Sentimentracker's proprietary indicator signals (sniperV3 / momentumUltimaPlus / structurePro / strongBuyStrongSell / momAlgoV15 / institutionalAlgo / etc.) as LLM-callable tools. Wraps the Sentimentracker /superchar
