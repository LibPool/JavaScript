# @gad-lang/ide-vuetify

> 标签: codemirror, debugger, editor, gad, ide, vue, vuetify

## 简介

Reusable Vuetify 3 IDE component for the Gad language: file explorer, CodeMirror editor, run/format/doc and a stepping debugger. Backend-agnostic — drive it with any IdeApi implementation (HTTP `gad ide` server, or a fully in-browser WASM + LocalStorage b
