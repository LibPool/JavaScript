# @proteus-vue/test-core

> 标签: JavaScript

## 简介

Proteus 测试核心（test-framework M3+B2）：createMockContext（唯一 wx 来源）+ mountMpComponent（SFC → 编译 → 逻辑层实例）+ snapshot（编译快照规范化：WXML 结构等值 / sourcemap 校验 / JS 导出检查）——L1-L3 标准件
