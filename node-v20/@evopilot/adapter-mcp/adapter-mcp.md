# @evopilot/adapter-mcp

> 标签: JavaScript

## 简介

Installable stdio MCP adapter for EvoPilot's server-governed Open Lifecycle Harness. It exposes the same lifecycle operations as the HTTP API and adds no approval, execution, or publication authority of its own.
