# @buildtovalue/simulation

> 标签: bpmn, coverage, process, simulation, token

## 简介

Headless BPMN token-simulation engine for bpmn-react: XOR/AND/event-based semantics, boundary events, approximate OR, structural path coverage and replayable scenarios. Consumes only @buildtovalue/core. Zero runtime dependencies.
