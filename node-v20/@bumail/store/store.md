# @bumail/store

> 标签: JavaScript

## 简介

Mailbox storage for a mail server: accounts, mailboxes, messages, flags, UIDs and modseqs behind one contract, with a memory store, a bun:sqlite store on disk and a PostgreSQL store (Bun.sql) for several instances
