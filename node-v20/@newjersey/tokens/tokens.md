# @newjersey/tokens

> 标签: JavaScript

## 简介

Design tokens for [Grove](https://grove.nj.gov) (NJWDS), built with [Style Dictionary](https://styledictionary.com/) and published as CSS custom properties, Sass variables, and JSON.
