# @isdk/web-fetcher

> 标签: crawler, data, fetch, spider, structure, web

## 简介

A powerful and flexible web automation and data extraction library featuring a dual-engine architecture (HTTP/Cheerio and Browser/Playwright) with declarative JSON action scripts.
