# @isdk/sandbox-executor

> 标签: c, cpp, executor, isolated-execution, javascript, php, python, ruby, runno, sandbox, security, vfs, wasm, webassembly

## 简介

Isolated multi-language function executor using WebAssembly (WASM). Supports Python, JavaScript, Ruby, PHP, C/C++ with fine-grained file system permissions and virtual FS.
