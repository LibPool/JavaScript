# @simdad/tass-cli

> 标签: JavaScript

## 简介

TASS's command line for humans and AI: score documents against the bundled open lexicons (or an imported LIWC-format .dic), analyze raw text to JSON, list the bundle with citations, run KWIC concordance, and serve the whole engine over MCP (stdio) for AI
