# @net-advantage/jo-ui-card-list

> 标签: JavaScript

## 简介

Publishable generic card list. Bind a collection, supply a card template, and the list renders one card per item plus an optional dashed "new item" card (inset slightly from a full card). Cards flow left-to-right, then wrap (Z order), fill the container w
