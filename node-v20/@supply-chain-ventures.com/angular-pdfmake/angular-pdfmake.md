# @supply-chain-ventures.com/angular-pdfmake

> 标签: angular, angular2, html, pdf, pdfmake, to

## 简介

An Angular 2+ component for printing and saving simple PDFs based on [bpampuch](https://github.com/bpampuch)'s  [`pdfmake`](https://github.com/bpampuch/pdfmake) library.
