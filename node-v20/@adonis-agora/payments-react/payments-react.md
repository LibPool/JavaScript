# @adonis-agora/payments-react

> 标签: adonis, adonisjs, agora, billing, boleto, payments, pix, polling, react-hooks

## 简介

React hook for @adonis-agora/payments — poll a Pix or boleto charge until the gateway's webhook settles it, with backoff, a stop condition and no polling in a background tab. Part of the Agora ecosystem.
