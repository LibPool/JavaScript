# @adonis-agora/durable-dashboard

> 标签: admin, adonis, adonisjs, agora, console, dashboard, durable, tanstack-intent, workflows

## 简介

Control-plane console (runs, step timeline, workflow graph, retry/cancel/fix-and-replay) for @adonis-agora/durable — a React SPA served by a thin AdonisJS provider. Part of the Agora ecosystem.
