# @shieldlabs-ai/vue

> 标签: device-intelligence, fraud-detection, identification, nuxt, risk-score, shieldlabs, vue

## 简介

Vue 3 and Nuxt bindings for ShieldLabs device intelligence: a plugin that loads the agent once and composables that return a request ID with loading and error state.
