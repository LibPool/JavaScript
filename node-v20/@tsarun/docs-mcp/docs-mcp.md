# @tsarun/docs-mcp

> 标签: aitaskrunner, documents, markdown, mcp, model-context-protocol, mupdf, ocr, pdf

## 简介

Four-tool stdio MCP server for AITaskRunner tasks: list documents, read a document as page text + page images (MuPDF), merge details into a list file, write Markdown

- npm 页面：https://www.npmjs.com/package/@tsarun/docs-mcp
