# @fictura/node

> 标签: error-tracking, errors, express, fastify, fictura, monitoring, node, opentelemetry, tracing

## 简介

Fictura for Node backends — errors with route, user and release, handled 5xx, request tracing (OTLP), crash-free request rate and event-loop stall warnings. Zero dependencies.
