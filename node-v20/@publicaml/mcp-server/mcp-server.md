# @publicaml/mcp-server

> 标签: aml, bitcoin, blockchain, bsc, compliance, ethereum, mcp, modelcontextprotocol, ofac, sanctions, tron

## 简介

MCP server for PublicAML: screen a crypto address for AML risk, trace where its money came from or went, and list its counterparties. Bitcoin, Ethereum, BSC, Tron.

- 源码仓库：git+https://github.com/publicaml/mcp-server.git
