# midi-realplayer

> 标签: custom-element, daw, listening-test, midi, midi-player, music, music-transcription, piano-roll, sf2, soundfont, stems, web-component

## 简介

Drop-in multi-track MIDI player for web pages: a <midi-realplayer> custom element with track and piano-roll views, mute/solo mixer, SoundFont playback, and audio stems in sync.
