# mytokentracker

> 标签: ai-cost, antigravity, ccusage, claude-code, codex, copilot-cli, llm-cost, token-usage

## 简介

See what your AI coding agents really cost. Local-first usage report for Claude Code, Codex, Copilot CLI, Antigravity and more, with optional sync to mytokentracker.io.
