# @hyuga/tenken

> 标签: agent, agent-skills, agents.md, ai, ci, claude.md, language-agnostic, linter, llms.txt, portability, reference-integrity, skill.md

## 简介

One command for agent config: runs reflint (reference integrity), skills-lint (skill schema + trigger collisions) and carrylint (runtime portability) over one tree in a single pass, with one report, one exit code and one GitHub Action.
