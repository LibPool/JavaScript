# @hyuga/reflint

> 标签: agent, agents.md, ai, ci, claude.md, language-agnostic, linter, llms.txt, mcp, reference-integrity

## 简介

Reference-integrity linter for AGENTS.md / llms.txt / CLAUDE.md — fail CI when agent config points at commands, scripts, or paths that no longer exist. Language-agnostic, zero-dependency.
