# @openqueue/world-bullmq

> 标签: background-jobs, bullmq, bun, ioredis, jobs, openqueue, queue, redis, typescript

## 简介

The BullMQ world for OpenQueue — a Redis-backed delivery transport paired with a write-through durable state store. The default OpenQueue delivery path.
