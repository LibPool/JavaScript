# @openqueue/workbench

> 标签: bullmq, dashboard, h3, next, openqueue, queue, ui, workbench

## 简介

OpenQueue Workbench — an embeddable dashboard (queues, runs, schedules, flows, metrics, alerts) for BullMQ / OpenQueue, with h3 and Next.js adapters.
