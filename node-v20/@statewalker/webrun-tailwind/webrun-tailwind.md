# @statewalker/webrun-tailwind

> 标签: JavaScript

## 简介

Build-only Tailwind CSS transform: a RegisteredTransform that generates the generic all-classes Tailwind stylesheet (v4) for a `tailwind-css` input and hands it to the shared CSS transform.
