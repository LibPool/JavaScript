# @neverblink/linkml

> 标签: code-generation, json-schema, linkml, rdf, schema, shacl

## 简介

A Scala 3 cross-platform library and CLI for LinkML schema validation and multi-format code generation (Scala, JSON Schema, SHACL, RDFS)
