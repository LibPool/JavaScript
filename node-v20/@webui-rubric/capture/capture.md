# @webui-rubric/capture

> 标签: JavaScript

## 简介

Playwright-based headless browser capture pipeline for `webui-rubric`. Navigates to a live URL, injects a CSS stabilization stylesheet to freeze animations and transitions, waits for network idle, auto-dismisses cookie consent banners, and captures screen
