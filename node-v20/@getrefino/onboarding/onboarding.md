# @getrefino/onboarding

> 标签: agent, codemod, copy, migration, onboarding, refino

## 简介

The engine behind `npx @getrefino/cli init`: deterministic repository inspection, copy discovery, migration planning, agent instructions and verification for adding Refino to an existing React site. Development tooling only; never part of a site's runtime
