# @yieldcraft/screenshot-paste

> 标签: clipboard, image-attachment, pi-package, pi-web, pi-web-plugin, remote-safe, screenshot, workspace-gallery

## 简介

pi-web plugin that browses and previews screenshots saved by pi-web into .pi-web/paste/ — gallery panel, lightbox, and chat-inline previews for folder-mode attachments.
