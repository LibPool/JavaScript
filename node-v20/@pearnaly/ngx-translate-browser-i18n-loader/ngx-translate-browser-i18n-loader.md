# @pearnaly/ngx-translate-browser-i18n-loader

> 标签: angular, browser extension, browser.i18n, chrome.i18n, loader, ngx-translate

## 简介

Loads _locale/<lang>/messages.json translation files as defined by the browser.i18n (or chrome.i18n) api for browser extensions made with Angular and translated with ngx-translate
