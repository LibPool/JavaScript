# @team-teddy/solid-engine

> 标签: code-quality, complexity, dependency-cruiser, refactor, solid

## 简介

Repo-agnostic, honest SOLID scorecard: measures S (size/complexity) and D (import-graph seams), refuses to fake O/L/I, and gates SOLID migrations on regression coverage of the code about to move.
