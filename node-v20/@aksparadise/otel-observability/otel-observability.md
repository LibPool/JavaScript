# @aksparadise/otel-observability

> 标签: aksparadise, apm, express, grafana, logging, metrics, monitoring, nestjs, nextjs, observability, opentelemetry, otel, signoz, tracing

## 简介

Production-ready OpenTelemetry plugin for SigNoz and Grafana observability. Minimal setup for Node.js, Express, NestJS, Next.js. Automatic instrumentation, distributed tracing, metrics, and logging. Created by AksParadise.
