# @hollyman/nuke-port

> 标签: address-in-use, cli, cross-platform, devtools, eaddrinuse, free-port, kill, kill-port, lsof, netstat, pid, port, port-in-use, process, taskkill

## 简介

Cross-platform CLI + library to find and kill the process holding a port hostage. Fixes 'port already in use' on macOS, Windows and Linux.
