# @ignotuss/dsh-desktop-bridge

> 标签: agent, bridge, cordis, deepseek-harness, dsh, dsh-plugin, http, localhost, session

## 简介

Token-authenticated loopback HTTP API that lets any local program drive the sessions of a running DSH (DeepSeek Harness) host
