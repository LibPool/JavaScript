# @goopil/clusterkit-sizing

> 标签: cgroup, cluster, clusterkit, container, docker, kubernetes, max-old-space-size, sizing

## 简介

Container sizing plugin for @goopil/clusterkit: reads cgroup CPU/memory limits and derives worker count plus per-worker --max-old-space-size (NODE_OPTIONS).
