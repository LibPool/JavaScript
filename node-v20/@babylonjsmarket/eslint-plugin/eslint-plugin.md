# @babylonjsmarket/eslint-plugin

> 标签: babylonjs, babylonjsmarket, ecs, eslint, eslint-plugin, eslintplugin

## 简介

ESLint rules + flat-config preset that enforce @babylonjsmarket/ecs framework conventions (adapter abstraction, Entity/World/EventBus API, event naming, serializable components)
