# @kpanks/ugc

> 标签: ai-video, azure-tts, ffmpeg, hedra, lipsync, luma, openai, praetor, ugc

## 简介

Praetor UGC pipeline — portrait → motion → voiceover → composite. OpenAI gpt-image-1, Luma Dream Machine, Replicate (Seedance/Nano-Banana), Hedra Character-3 lipsync, Azure Neural TTS, ffmpeg compositor.
