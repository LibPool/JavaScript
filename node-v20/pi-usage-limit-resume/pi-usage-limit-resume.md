# pi-usage-limit-resume

> 标签: pi, pi-coding-agent, pi-package, quota, rate-limit, reset, usage-limit

## 简介

Pi extension: saves when each provider's usage window resets (5h, weekly, monthly) and continues your task when an exhausted limit resets.
