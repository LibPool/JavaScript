# @cat-factory/webhooks

> 标签: cat-factory, hmac, signature, webhooks

## 简介

Verify cat-factory outbound webhook deliveries: the HMAC-SHA256 signature over the raw body and the timestamp replay window, with Web Crypto only, so one receiver runs on Node, in a browser or in a worker isolate.
