# @cat-factory/directory-sync

> 标签: cat-factory, directory, sync, webhooks

## 简介

Keep a copy of a cat-factory account's directory (workspaces, users, memberships, linked repositories) in sync: snapshot bootstrap, change-feed catch-up, signed webhook pushes and periodic reconciliation, over a storage adapter you implement.
