# @mylikita/booking-widget-react

> 标签: appointment, booking, healthcare, hospital, mylikita, react, relay, widget

## 简介

React component wrapper for @mylikita/booking-widget — drop <BookingWidget relayUrl=… websiteKey=… facilityId=… /> into any React hospital website and get appointment booking that syncs through the MyLikita relay.
