# @gjsify/storybook-nativescript

> 标签: adwaita, android, gnome, ios, nativescript, stories, storybook

## 简介

NativeScript renderer for the @gjsify/stories contract — the NS counterpart of @gjsify/storybook (GTK) and @gjsify/adwaita-storybook (browser), built on @gjsify/adwaita-nativescript real native widgets
