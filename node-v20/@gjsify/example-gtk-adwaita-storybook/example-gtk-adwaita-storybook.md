# @gjsify/example-gtk-adwaita-storybook

> 标签: JavaScript

## 简介

Interactive component browser for Libadwaita widgets — a native Adwaita storybook built on @gjsify/storybook, debuggable over DBus/MCP via @gjsify/devtools
