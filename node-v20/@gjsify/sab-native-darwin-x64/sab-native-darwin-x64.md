# @gjsify/sab-native-darwin-x64

> 标签: JavaScript

## 简介

darwin-x64 prebuilt native library + GObject-Introspection typelib for @gjsify/sab-native. Installed automatically on darwin/x64 as an optionalDependency of that package (ADR 0017) and skipped everywhere else. Contains no JavaScript.
