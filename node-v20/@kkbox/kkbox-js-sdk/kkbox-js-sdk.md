# @kkbox/kkbox-js-sdk

> 标签: API, KKBOX, Open, OpenAPI

## 简介

KKBOX Open API developer SDK for JavaScript. Use it to easily access KKBOX open API to get various metadata about KKBOX's tracks, albums, artists, playlists and stations.
