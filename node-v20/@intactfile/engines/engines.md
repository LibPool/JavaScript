# @intactfile/engines

> 标签: JavaScript

## 简介

IntactFile repair engines (SDK): repair corrupted video, ZIP/Office, PDF, JPEG, PNG, RAW photo, PSD, audio (WAV/MP3), SQLite and RAR/7z entirely in-process. Runs in the browser and in Node — files never leave the machine.
