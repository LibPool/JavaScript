# @openpath/sdk

> 标签: agents, ai-agents, beacon, beacons, home-services, jobs, llm, local-business, mcp, tools

## 简介

Beacon for JavaScript. Create a beacon: a few plain words about what you have or need right now. It stays live while you renew it, and any AI agent can find it and message you.
