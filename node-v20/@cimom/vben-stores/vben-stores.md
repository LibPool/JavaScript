# @cimom/vben-stores

> 标签: JavaScript

## 简介

基于 Pinia 的状态管理工具包，提供了应用中常用的状态存储模块，包括用户状态、权限控制、标签页管理等。

- 源码仓库：git+https://github.com/vbenjs/vue-vben-admin.git
