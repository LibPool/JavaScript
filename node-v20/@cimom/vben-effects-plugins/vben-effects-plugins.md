# @cimom/vben-effects-plugins

> 标签: JavaScript

## 简介

该包提供了多个第三方库的集成插件，每个插件都包含了可重用的逻辑、配置和组件，方便在项目中进行统一管理和调用。通过子路径导出的方式，允许应用按需引入所需的插件，避免不必要的打包体积增加。
