# @awallef/nestjs-iam

> 标签: access-management, authentication, authorization, iam, identity, mariadb, mysql, nestjs, postgresql, strapi-like, typescript

## 简介

NestJS Identity and Access Management (IAM) library with comprehensive authentication and authorization features. Supports PostgreSQL, MySQL, and MariaDB.
