# @xazab/insight-ui

> 标签: bitcore-xazab, blockchain, blockexplorer, front-end, insight, xazab, xazabcore

## 简介

An open-source frontend for the Insight API. The Insight API provides you with a convenient, powerful and simple way to query and broadcast data on the Xazab network and build your own services with it.
