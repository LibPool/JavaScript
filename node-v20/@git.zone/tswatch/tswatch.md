# @git.zone/tswatch

> 标签: CLI, TypeScript, automation, build, build automation, continuous development, development, development server, integration, live reloading, node.js, npm, project monitoring, recompiling, service development, testing, tooling, watcher, web development

## 简介

A development tool for automatically watching and re-compiling TypeScript projects upon detecting file changes, enhancing developer workflows.
