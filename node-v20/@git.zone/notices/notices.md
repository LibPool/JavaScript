# @git.zone/notices

> 标签: CLI tool, TypeDoc, TypeScript, build, bundle, documentation, git.zone, monorepo, publish, run, single executable application, test, type check, watch

## 简介

The third-party notices format of git.zone's build tools: resolve the licenses and notices of the npm packages in a build, merge the notices its prebuilt artifacts such as WebAssembly modules carry, and read, render and write <file>.third-party-notices.js
