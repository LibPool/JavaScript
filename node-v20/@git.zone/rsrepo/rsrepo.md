# @git.zone/rsrepo

> 标签: CLI tool, Rust, build tool, cargo, crates.io, release, workspace

## 简介

The git.zone Rust repository standard: Cargo workspace discovery through cargo metadata, build, fmt, clippy, test, doc and package flows, the tsrust dist_rust build for TypeScript packages with internal Rust, and the release engine for @git.zone/cli.
