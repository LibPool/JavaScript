# @git.zone/tsrepo

> 标签: CLI tool, TypeDoc, TypeScript, build, bundle, documentation, git.zone, monorepo, publish, run, single executable application, test, type check, watch

## 简介

The git.zone TypeScript repository toolchain: build, check, test, bundle, run, publish, watch, document and build single executable applications for TypeScript projects from one package.
