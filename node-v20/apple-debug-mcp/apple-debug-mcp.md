# apple-debug-mcp

> 标签: apple, debugging, ios-simulator, mcp, model-context-protocol, simctl, ui-automation, xcode

## 简介

MCP debug daemon for Apple Simulators: pool state, tool-agnostic session leases, wait queue with auto-dispatch. Built on simslim (lifecycle) + AXe (UI automation).
