# @mehdijony/nestjs-user-service

> 标签: 2fa, auth, authentication, graphql, grpc, jwt, mongoose, nestjs, oauth, otp, prisma, rbac, redis, typeorm, user-service

## 简介

Plug-and-play user service for NestJS. Interactive CLI wizard sets up authentication, database, ORM, REST/GraphQL/gRPC, OAuth, OTP, 2FA, RBAC, Redis, and Docker inside your existing project.
