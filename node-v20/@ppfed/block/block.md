# @ppfed/block

> 标签: JavaScript

## 简介

专为 Axios.js 开发的模块API管理模式。它采用集中式存储管理应用的所有 API 模块，并以相应的规则保证 API 以一种统一的方式进行调用。现已支持Vuex Plugin
