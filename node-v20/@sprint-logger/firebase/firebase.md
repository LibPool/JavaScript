# @sprint-logger/firebase

> 标签: cloud-functions, error-logging, error-tracking, firebase, observability, serverless, signals, sprint

## 简介

Sprint Signals error logger for Firebase Cloud Functions v2. Wrap a handler, get every throw captured with trigger context. Pseudonymous, PII-safe.
