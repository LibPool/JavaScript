# monorepo-gauge

> 标签: dependencies, github-action, lerna, lint, monorepo, npm, pnpm, sarif, workspaces, yarn

## 简介

Hygiene checks for npm/yarn/pnpm workspaces: circular internal dependencies, internal ranges that no longer match, shared dependency drift, duplicate names, public packages depending on private ones, per-package field checks via pkg-field-gauge, workspace
