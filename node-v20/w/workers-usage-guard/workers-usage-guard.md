# workers-usage-guard

> 标签: cloudflare, guardrail, monitoring, usage, workers, workflows

## 简介

Cloudflare Workers kill-switch — auto-disable Workers when usage crosses thresholds. Ships with the `wug` CLI for one-command setup.
