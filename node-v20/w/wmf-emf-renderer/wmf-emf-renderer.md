# wmf-emf-renderer

> 标签: canvas, converter, emf, emf+, emfplus, metafile, renderer, svg, vector, windows, wmf

## 简介

Parse and render WMF / EMF / EMF+ Windows metafiles to SVG or Canvas 2D, in Node.js and browsers. Zero dependencies.
