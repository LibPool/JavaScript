# wifi-state

> 标签: bssid, essid, iwevent, network chanel, network interface, wifi, wifi events, wifi mode, wifi protocol, wifi-state, wireless

## 简介

Fetch current wireless information (essid, bssid, protocol, chanel, network interface, mode) in a passive way and in real time.
