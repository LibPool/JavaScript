# wiki-plugin-semindex

> 标签: embeddings, federated wiki, indexer, plugin, semantic search, wiki

## 简介

Federated Wiki plugin — builds the farm's semantic vector indexes in-process (worker thread, transformers.js) so federated search needs no external indexer
