# wagtail-visual-editor-bridge

> 标签: astro, headless, nextjs, preview, streamfield, visual-editor, wagtail

## 简介

Frontend side of wagtail-visual-editor: connects your headless preview with the Wagtail visual editor. Framework-agnostic (Next.js, Astro, ...).
