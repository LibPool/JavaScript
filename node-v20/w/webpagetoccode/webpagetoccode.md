# webpagetoccode

> 标签: arduino, cpp, header, website

## 简介

Converts an output folder containing a website to C-Code. Creates a header- and a source file, which can be simply included into projects

- 官网：https://github.com/AFellmett/WebPageToCCode
- 源码仓库：git+https://github.com/AFellmett/WebPageToCCode.git
