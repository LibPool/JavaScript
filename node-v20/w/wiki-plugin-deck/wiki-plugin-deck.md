# wiki-plugin-deck

> 标签: JavaScript

## 简介

Federated Wiki plugin — a deck item whose text is a Deck Manifest; owners press Build and the farm compiles a slim reveal.js deck into the page's assets; SHOW presents any excerpt of it, FROM presents a deck built on another page
