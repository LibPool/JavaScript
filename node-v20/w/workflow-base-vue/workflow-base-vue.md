# workflow-base-vue

> 标签: workflow, 基于vue的UI组件, 工作流、审批流的显示, 流程图展示

## 简介

#### Description 基于vue2.x实现的工作流、审批流。可以实时查看节点状态。节点样式可以定制，不同类型节点对应的颜色可以配置。
