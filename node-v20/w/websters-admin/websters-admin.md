# websters-admin

> 标签: admin, admin-dashboard, admin-on-rest, admin-panel, admin-template, admin-ui, dashboard, developer-tools, frontend-framework, react, react-admin, reactjs

## 简介

websters-admin is a frontend framework for creating back office using React. It provides out-of-the-box components and tools that make developing an admin interface easy and fast.
