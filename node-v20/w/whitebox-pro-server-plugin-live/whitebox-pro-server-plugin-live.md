# whitebox-pro-server-plugin-live

> 标签: JavaScript

## 简介

WhiteBox server — live plugin. A realtime operations view of everything moving through WhiteBox: what arrives (web, replies, CRM, conversions), what leaves (mail, SMS, webhooks), and delivery health. Owns no tables; reads the core event registry and taps
