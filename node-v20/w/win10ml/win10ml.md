# win10ml

> 标签: desktop, hud, taskbar, ui, vanilla-js, window-manager, windows-10, zero-dependency

## 简介

Framework-agnostic Windows 10 desktop HUD for the web (WinML): draggable windows, taskbar with Start button and pinned apps, menus, controls, calendar, message boxes and markdown. Zero dependencies, pure DOM.
