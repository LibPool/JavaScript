# wgather

> 标签: JavaScript

## 简介

Gather聚焦于提供项目快速升级打包依赖的问题，让开发者项目跟具体的资源打包工具脱离，从而达到与打包工具的解耦合，这样做的好处就是未来资源打包工具升级或者替换，对开发者都是透明，统一在Gather这一层去升级或者更换
