# wane-sdk

> 标签: ai-agent, antibody, base, eip-7702, onchain, security, session-wallet, solana, threat-intelligence, wallet-drainer, wane

## 简介

Unified Wane client for AI agents: read the on-chain antibody registry, report threats, and drive a screening session wallet across Base and Solana.
