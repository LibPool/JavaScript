# wz-react-ui

> 标签: JavaScript

## 简介

1. Pagination 翻页组件 2. BatchAddInput 多ID输入组件  3. BgAnimationWater 水波纹背景动画 4. ComplexSelect 带搜索的下拉框组件  5. dialog 弹出层高介组件 6. MultiSelect 多选组件 7. Switch 滑块组件
