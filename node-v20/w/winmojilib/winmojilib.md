# winmojilib

> 标签: emoji, emojis, js, node, unicode, windows, winmoji

## 简介

A Collection of lightweight, up-to-date emojis supported by Windows for use in winmoji These emojis are generated from the most up-to-date resource based on the [Unicode Data](https://unicode.org/emoji/).
