# windows-98-ui

> 标签: 98, 98.css, component, component-library, design-system, library, nostalgia, react, react-components, retro, skeuomorphic, typescript, ui, ui-kit, web, windows, windows-98

## 简介

A React component library that brings the nostalgic look and feel of Windows 98 to modern web apps, powered by 98.css. Typed, polymorphic, and style-scoped so it never leaks into the rest of your UI.
