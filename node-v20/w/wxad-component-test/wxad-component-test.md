# wxad-component-test

> 标签: JavaScript

## 简介

根据微信官方提供的项目模板（https://developers.weixin.qq.com/miniprogram/dev/framework/custom-component/trdparty.html），开发第三方自定义组件；开发的组件打包到npm上，然后通过npm安装的形式在微信小程序中引入、使用相应的组件；

- npm 页面：https://www.npmjs.com/package/wxad-component-test
