# watchvideo

> 标签: claude, claude-code, competitor-research, contact-sheet, content-research, creator-tools, ffmpeg, hook-analysis, skill, transcription, video-analysis, video-transcript, whisper, yt-dlp

## 简介

Local video analyzer for Claude Code with three modes: hook (first 20 seconds only, one contact sheet per video, built for studying a whole competitor roster), condensed, and forensic (1 frame per second). Downloads with yt-dlp, tiles frames with ffmpeg,
