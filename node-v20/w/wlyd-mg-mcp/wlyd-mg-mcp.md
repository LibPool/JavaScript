# wlyd-mg-mcp

> 标签: chrome-extension, mastergo, mcp, model-context-protocol, wlyd

## 简介

MCP server for WLYD MasterGo Chrome extension - exposes mastergo canvas capabilities (selection export, image export, find-by-text) as MCP tools.
