# wbotconnect

> 标签: JavaScript

## 简介

Uma biblioteca para integração com o WhatsApp Web via Puppeteer, baseada no projeto [WPPConnect](https://github.com/wppconnect-team/wppconnect), com melhorias de performance e estrutura organizacional.
