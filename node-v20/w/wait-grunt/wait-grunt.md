# wait-grunt

> 标签: JavaScript

## 简介

An alternative to the Grunt command line interface. Ability to fork Grunt but have it wait for a signal before executing.

## 官网

- 官网：http://gruntjs.com/
- 源码仓库：git://github.com/gruntjs/grunt-cli.git
- npm 页面：https://www.npmjs.com/package/wait-grunt
