# wya-styles

> 标签: JavaScript

## 简介

* themes 定义公共的变量     * color.scss 颜色变量     * default.scss 全局变量   * mixins 定义公共的方法     * animate.scss 动画     * common.scss 公共方法   * core 输出全局的样式     * globals.scss 定义全局变量的方法     * reset.scss 输出g-reset样式     * animate.scss 输出动画     * flex.scss 输出f
