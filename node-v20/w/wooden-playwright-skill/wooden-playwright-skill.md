> 标签: agent, browser-automation, e2e, opencode, playwright, skill, testing

## 简介

A general-purpose Playwright browser-automation agent skill (SKILL.md) for OpenCode, Claude Code, Cursor and other skill-aware coding agents. Fork of lackeyjb/playwright-skill repackaged as an npm package.
