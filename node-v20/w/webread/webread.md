# webread

> 标签: agent, ai, cli, defuddle, extractor, html, html-to-markdown, llm, markdown, readability

## 简介

Minimal HTML→Markdown CLI for AI consumption. Reads HTML on stdin, outputs clean markdown on stdout. Pluggable per-site rules.
