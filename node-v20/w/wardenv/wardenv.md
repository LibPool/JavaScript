# wardenv

> 标签: ai-agent, claude-code, dotenv, env, hooks, llm, prompt-security, redaction, secrets, security

## 简介

Keep your .env out of the AI context. Blocks secret reads, redacts leaked values in tool output, and logs every unlock. Hooks for coding agents.
