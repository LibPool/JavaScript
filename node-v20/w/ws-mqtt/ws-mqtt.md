# ws-mqtt

> 标签: JavaScript

## 简介

Small try using [paho-mqtt](https://www.npmjs.com/package/paho-mqtt) to subscribe to MQTT broker using websocket. It is to try to better understand http://www.hivemq.com/demos/websocket-client and http://test.mosquitto.org/ws.html
