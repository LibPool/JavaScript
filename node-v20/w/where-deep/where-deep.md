# where-deep

> 标签: FP, Functional programming, JSON, deep, filter, predicate, ramda, where

## 简介

A deep (recursive) version of Ramda.js's where and whereEq, allowing nested JSON-like structures to be used as predicates (for filtering and so on) for use on similar JSON-like structures
