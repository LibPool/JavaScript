# webext-content-ui

> 标签: browser-extension, content-script, injection, plasmo, shadow-dom, wxt

## 简介

Inject elements into shadow DOM — single or batch anchors, with optional shared styles across shadow roots. Combines Plasmo's batch-anchor injection with WXT's clean UI API.
