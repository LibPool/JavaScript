# world-location-data

> 标签: cities, coordinates, countries, country-codes, currency, geo-data, geography, iso-codes, latitude, location-data, longitude, provinces, regions, states, subregions, timezone, translations, world-data

## 简介

Comprehensive world location data package with 250+ countries, 5000+ states, and 150K+ cities. Includes rich metadata like timezones, currencies, coordinates, translations, and more.
