# wfirma-mcp

> 标签: accounting, bookkeeping, mcp, model-context-protocol, polish, wfirma

## 简介

Unofficial read-only MCP server for the wFirma API v2 (api2.wfirma.pl): companies, invoices, contractors, expenses, payments.
