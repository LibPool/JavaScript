# wiki-plugin-model

> 标签: federated wiki, financial model, model, plugin, spreadsheet, wiki, xlsx

## 简介

Federated Wiki - Model Plugin — a frozen summary of a spreadsheet financial model, drawn through the Table Plugin, with a badge that says whether it is up to date and an owner-only Freeze.
