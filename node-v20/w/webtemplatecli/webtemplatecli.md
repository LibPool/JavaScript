# webtemplatecli

> 标签: JavaScript

## 简介

1. npm link 全局命名注册 2. liu-cli  测试安装成功 3. liu-cli cliname 新建下载脚手架模块  4. 比如  liu-cli cliname --type=vue-test 5.  vue 或者 react 是前缀 --type是命令 test是名字
