# whitebox-pro-server-plugin-people

> 标签: JavaScript

## 简介

WhiteBox server — people plugin. A browse/search/detail surface over the core passport, identity and fact primitives: look a person up, see every identity and fact held about them, fix a wrong identity, merge duplicates, and honour a right-to-be-forgotten
