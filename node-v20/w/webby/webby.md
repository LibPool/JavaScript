# webby

> 标签: babel, builder, coffeescript, css, es5, es6, front-end, frontend, generator, html, jade, javascript, js, less, pug, sass, stage0, static, stylus, typescript, webby, webpack

## 简介

Zero-configuration front-end (static HTML/CSS/JS) builder and web server. Webpack based, supported: SASS, LESS, Stylus, CoffeeScript, TypeScript, Babel (ES5, ES6, Stage 0), Pug (Jade), etc.
