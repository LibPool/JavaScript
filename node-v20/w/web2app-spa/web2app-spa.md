# web2app-spa

> 标签: android, app, capacitor, cordova, cordova-android, cordova-ios, cordova-template, cordova:template, ecosystem:cordova, ionic, ios, javascript, javascript-mobile, javascript-template, mobile, mobile-template, template

## 简介

This template is primarily designed to easily convert HTML pages and URLs into a Capacitor/Cordova based iOS/Android app that can be used as Single-page application (SPA).
