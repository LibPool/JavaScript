# wdio-pw-driver

> 标签: automation, browser-automation, chromium, e2e, firefox, playwright, playwright-core, test-runner, testing, wdio, wdio-driver, wdio-service, webdriverio, webkit

## 简介

WebdriverIO driver powered by Playwright internals — drives Chromium / Firefox / WebKit in-process, no chromedriver, no HTTP. Same WDIO API.
