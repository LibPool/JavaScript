# whytype

> 标签: ai-agents, claude-code, compiler, cursor, developer-tools, diagnostics, mcp, mcp-server, typescript, typescript-errors

## 简介

Give coding agents the TypeScript compiler's actual reasoning — an MCP server and CLI that turn type errors into because-chains pointing at the declaration to fix. Also a library: explain-trees, inference bindings, conditional-type traces.
