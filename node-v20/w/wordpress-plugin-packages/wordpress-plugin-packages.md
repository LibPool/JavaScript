# wordpress-plugin-packages

> 标签: javascript, jsx, mui, react, tsx, typescript, vite, vue, wordpress, wordpress-plugin

## 简介

Boilerplate WordPress Plugin structure, for all other frameworks: JavaScript (React, Vue, Vite), TypeScript, supporting NextJS, Nuxt, Gatsby, and JSX/TSX Components like MUI and CSS like Tailwind. Supports ESLint + Prettier code definitions and formatting
