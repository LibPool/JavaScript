# web3-connector-custom

> 标签: ethereum, react, wallet, web3

## 简介

轻量级多钱包连接组件库，支持 **MetaMask / OKX Wallet / Phantom / Coinbase Wallet / WalletConnect**。可完全自定义 UI，替代 RainbowKit。
