# web-search-make-markdown

> 标签: agent, illustrated-report, local-images, markdown, scrape, skill, web-search

## 简介

Agent skill package: collect material from the web and generate illustrated Markdown documents. All images come from real images on the web (AI generation is forbidden), are downloaded and saved as local files, and are referenced via relative paths — keep
