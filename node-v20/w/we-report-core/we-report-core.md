# we-report-core

> 标签: banded-report, barcode, expression, pdf, report, report-engine, reporting

## 简介

Framework-free report engine for we-report: report definition model, expression language, layout/pagination and PDF/Excel/HTML rendering. Runs in the browser and Node.
