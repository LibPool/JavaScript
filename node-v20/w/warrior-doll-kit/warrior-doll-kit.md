# warrior-doll-kit

> 标签: JavaScript

## 简介

关节式切件骨架成品包(披甲武将):13 根骨 —— 腿三层(髋→膝→踝)、臂两层(肩→肘,拳焊在前臂上),外加一把环首刀。idle/walk/run/attack/jump/dash/heavy 七个动作,Cocos Creator 3.8。npm 装包后跑 warrior-doll-sync 把资源同步进工程 assets/resources/。
