# watermark-image-uniapp

> 标签: JavaScript

## 简介

为图片添加水印并上传 (可选择相册图片, 相机拍照图片, 微信文件('doc', 'docx', 'pdf', 'xlsx', 'xls')), 微信文件不支持添加水印
