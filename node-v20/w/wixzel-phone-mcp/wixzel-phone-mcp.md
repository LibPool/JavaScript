# wixzel-phone-mcp

> 标签: ai-agents, claude-code, mcp, model-context-protocol, telephony, voice-agents, wixzel

## 简介

MCP server for Wixzel Phone — lets AI agents such as Claude Code create voice agents, place calls, manage leads and campaigns, and read usage over the Wixzel Phone API.
