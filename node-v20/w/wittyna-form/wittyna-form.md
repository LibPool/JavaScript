# wittyna-form

> 标签: JavaScript

## 简介

基于 Vue 3 + Element Plus（桌面端）与 Vant（移动端）的一套"配置式表单"组件库。通过一组类型安全的"表单项构造器"方法（如 `useInput`、`useSelect`、`useTableForm` 等），你可以用极少的代码搭建出复杂的表单与表格表单，内置校验、步骤、多端适配、详情模式等能力。
