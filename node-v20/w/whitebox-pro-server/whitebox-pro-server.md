# whitebox-pro-server

> 标签: JavaScript

## 简介

Whitebox backend core — HTTP server, awareness, passports, sessions, plugin loader. Channels (mail, voip, crm, engagement, analytics) ship as separate whitebox-pro-server-plugin-* packages.
