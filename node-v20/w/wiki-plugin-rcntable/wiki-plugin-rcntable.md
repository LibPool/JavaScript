# wiki-plugin-rcntable

> 标签: federated wiki, plugin, rcn, table, wiki

## 简介

Federated Wiki plugin: a table of records on a page — the shape in the column, the whole table in a popup, every name a link; Neighbourhood and Map; reads the site's own /assets/rcn-table/ folder
