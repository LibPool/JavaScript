# web3ctx

> 标签: cctp, coding-agents, context, eip, erc, ethereum, mcp, solidity, viem, wagmi, web3

## 简介

The web3ctx CLI — the five web3ctx MCP primitives (lookup · grep · search · deps · fetch) over the same wire and the same payload contract, for use outside an MCP client.
