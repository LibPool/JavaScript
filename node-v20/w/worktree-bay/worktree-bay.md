# worktree-bay

> 标签: cli, dev-environment, developer-tools, git, git-worktree, mcp, monorepo, orchestration, parallel, parallel-development, ports, worktree

## 简介

Per-feature git worktree + port slots for parallel multi-service development: auto deps, env wiring, frontend-to-backend, merge-aware reclaim, plus an MCP server for AI agents.
