# waterfall-component-vue2

> 标签: gallery, image, layout, masonry, virtual-scroll, vue2, waterfall

## 简介

高性能瀑布流布局组件 Vue2 版本，支持横向和纵向布局，具有虚拟滚动和图片懒加载功能
