# webear

> 标签: ai, analysis, audio, browser-sensors, claude, coding-assistant, copilot, cursor, debug, developer-tools, mcp, model-context-protocol, music, perception, sound, telemetry, web-audio, web-vitals, webear, windsurf

## 简介

Give your AI real senses — hear, see, and feel any web app in real time. Audio, visuals, performance, network, security, and console capture via MCP. Works with Windsurf, Cursor, Claude Code, and any MCP-compatible IDE.
