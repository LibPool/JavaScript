# whistle.data-extractor

> 标签: plugin, proxy, whistle

## 简介

whistle插件，可以用来从匹配到的pattern提取数据，替换到upstream指定地址获取到的模板中。 配置方式: ``` pattern data-extractor://{"upstream": "http://localhost:8080", extractRegex: ["<script>\\s*const\\s+data\\s*=([^<]+)"]} ```
