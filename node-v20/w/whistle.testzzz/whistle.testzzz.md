# whistle.testzzz

> 标签: JavaScript

## 简介

whistle 插件的 `server` 用来直接处理请求，可以通过配置 `pattern plugin-name://opValue` （这里 `plugin-name` 不能包含 `whistle.` 前缀，否则请求不会转发到 server，如：`test-server://xxx`，而不能为 <del>`whistle.test-server://xxx`</del>）。
