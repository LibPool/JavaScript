# workproof

> 标签: attestation, authorship, career, cli, code-ownership, engineering-evidence, engineering-report, git, git-blame, github-action, hiring, in-toto, portfolio, proof-of-work, resume, sigstore, surviving-lines, verifiable

## 简介

Turn a private git repository into a verifiable engineering report for one author, without showing any code: thirteen figures from git, a hash anyone can recompute offline, verify, and an in-toto attestation.
