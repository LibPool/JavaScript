# wunderui-mcp

> 标签: ai-agents, claude-code, cursor, design-system, mcp, model-context-protocol, react, tailwindcss, wunderui

## 简介

MCP server that gives AI coding agents the WunderUI design system: tokens, component props, templates and starters. Works with Claude Code, Cursor, Windsurf, Cline and Codex.
