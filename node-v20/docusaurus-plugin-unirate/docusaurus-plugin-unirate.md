# docusaurus-plugin-unirate

> 标签: currency, docusaurus, docusaurus-plugin, exchange-rates, fintech, forex, unirate, vat

## 简介

Docusaurus v3 plugin for UniRate — fetch currency exchange rates, currencies, and VAT rates at build time and expose them as global plugin data plus a bundled <ExchangeRate /> theme component.
