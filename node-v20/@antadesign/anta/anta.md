# @antadesign/anta

> 标签: JavaScript

## 简介

**Anta** is an opinionated design system. It provides design tokens, declarative web components, and typed JSX wrappers. Use the same components in React, Preact via compat, plain HTML, and custom JSX runtimes via `configure()`.
