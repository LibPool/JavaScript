# ghosty-autopilot

> 标签: acp, agent, ai, autopilot, chat, copilot, ghosty, human-in-the-loop, react, sse

## 简介

Ghosty Autopilot — the autopilot chat for your app, from Ghosty Studio: streaming, agent steps, attachments, voice, reconnection and human approval cards. Pure event reducer + SSE transport + React components.
