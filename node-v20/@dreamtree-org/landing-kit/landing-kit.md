# @dreamtree-org/landing-kit

> 标签: dreamtree, express, json-ld, landing-page, llms.txt, marketing, multi-tenant, prerender, react, seo

## 简介

The shared marketing site and auth frame (AuthShell + brands) for every Dreamtree product: content-driven landing pages, login/signup shell, Express routes, prerender and SEO files.
