# @krymskyimaksym/react-native-pdf-bitmap

> 标签: bitmap, expo, pdf, react-native, thermal-printer, tspl

## 简介

Render PDF pages to monochrome 1-bit bitmaps for TSPL thermal printers. Uses iOS PDFKit and Android PdfRenderer natively.
