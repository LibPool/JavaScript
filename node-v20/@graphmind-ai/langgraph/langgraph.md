# @graphmind-ai/langgraph

> 标签: agents, callbacks, debugger, graphmind, langchain, langgraph, observability

## 简介

LangChain / LangGraph adapter for the GraphMind live agent debugger: a callback handler that streams the run tree as a live graph, plus tool wrappers that honour pause / step / inject / retry / abort gates.
