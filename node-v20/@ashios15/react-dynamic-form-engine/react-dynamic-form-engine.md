> 标签: config-driven, dynamic-form, form, form-engine, form-linter, headless, multi-step, react, react-hook-form, static-analysis, typescript, zod

## 简介

Headless, config-driven multi-step form engine for React 19 with a pure static analyzer (form-lint CLI) that catches config bugs at build time.
