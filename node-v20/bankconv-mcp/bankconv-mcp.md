# bankconv-mcp

> 标签: accounting, bank-statement, bankconv, csv, mcp, model-context-protocol, ofx, pdf, qbo, quickbooks, xero

## 简介

MCP server for BankConv: convert PDF bank statements into transactions, CSV, OFX, QFX, QBO or Xero CSV from Claude, Cursor and other AI assistants.
