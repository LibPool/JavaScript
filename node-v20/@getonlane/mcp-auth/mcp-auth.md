# @getonlane/mcp-auth

> 标签: authorization, consent, jwt, mcp, model-context-protocol, oauth, oauth2, rfc8693, rfc9728, token-exchange

## 简介

Drop-in OAuth resource-server + connection gate for an MCP server fronted by Lane. Transport-agnostic core; adapters wrap it.
