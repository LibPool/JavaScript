# @duty27/eu-vat-mcp

> 标签: ai, claude, eu-vat, european-union, historical-vat-rates, mcp, mcp-server, model-context-protocol, tax, value-added-tax, vat, vat-rate

## 简介

MCP server for EU standard VAT rates by date: ask an AI assistant what the VAT rate was in any of the 27 member states on any day since 2016. Offline, no API key.
