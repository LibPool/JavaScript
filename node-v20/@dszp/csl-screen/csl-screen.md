# @dszp/csl-screen

> 标签: cloudflare-workers, consolidated-screening-list, export-compliance, restricted-party-screening

## 简介

Restricted-party screening against the US Consolidated Screening List: name normalisation, fuzzy matching and reviewable decisions. Zero runtime dependencies; runs in Node and Cloudflare Workers.
