# script-sandbox

> 标签: ai-agent, bash, file-operations, filesystem, java, lua, mcp, model-context-protocol, node, perl, php, powershell, python, ruby, sandbox, script, stdio

## 简介

MCP server (stdio) to run any script (PowerShell, bash, Python, Node, Ruby, Perl, Lua, PHP, R, Java, batch, VBScript) and any executable inside a lightweight sandbox: per-run working dir, minimal env, timeout, logs, and per-language guardrails. Plus files
