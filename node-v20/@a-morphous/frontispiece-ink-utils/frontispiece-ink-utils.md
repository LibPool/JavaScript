# @a-morphous/frontispiece-ink-utils

> 标签: JavaScript

## 简介

Helper functions to manipulate an Ink story. These work with more complex tags in a story, and can be used to implement [Storylets](https://emshort.blog/2019/11/29/storylets-you-want-them/), which can be found in the ink-storylets package.
