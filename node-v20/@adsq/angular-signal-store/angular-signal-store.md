# @adsq/angular-signal-store

> 标签: angular, jsnq, proxy, reactive, signal, state-management, store

## 简介

Angular SignalStore — reactive, proxy-based store with fine-grained signal wake. Uses jsnq (separate dependency) for queries/mutations.
