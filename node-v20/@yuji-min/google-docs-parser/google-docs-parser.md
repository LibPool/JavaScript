# @yuji-min/google-docs-parser

> 标签: cloudflare-workers, cms, edge-runtime, google-docs, headless-cms, parser, schema, typescript, vercel-edge

## 简介

Turn your Google Docs into a Headless CMS. A strictly typed, schema-based parser for Google Docs. Supports Node.js and Edge Runtime (Cloudflare Workers, Vercel Edge).
