# @gancao/base-tools

> 标签: JavaScript

## 简介

甘草医生前端团队常用工具库，包含 `ts`（通用工具）、`web`（浏览器相关）、`uni`（小程序/uniapp 相关）。支持从模块根导入，类型完整，且可在 IDE 中快捷查看源码与注释。
