# @tscg/mcp-proxy

> 标签: claude-code, mcp, model-context-protocol, proxy, tool-compression, tscg

## 简介

TSCG MCP Proxy — transparent tool-schema compression for MCP servers. Sits between Claude Code and downstream MCP servers, compressing tool descriptions using TSCG.
