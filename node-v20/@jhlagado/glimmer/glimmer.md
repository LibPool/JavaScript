# @jhlagado/glimmer

> 标签: 8-bit, azm, game-engine, preprocessor, retro, tec-1g, z80

## 简介

Glimmer: a reactive Z80 game framework compiling to readable AZM — state cells, cards, routines, layout types, and source-level Debug80 maps
