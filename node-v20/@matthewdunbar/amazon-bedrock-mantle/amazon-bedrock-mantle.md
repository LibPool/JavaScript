# @matthewdunbar/amazon-bedrock-mantle

> 标签: JavaScript

## 简介

An [AI SDK](https://ai-sdk.dev/) provider that enables using Mantle models deployed on Amazon Bedrock through an OpenAI-compatible API with AWS SigV4 authentication.
