# @lmack/sanity-heroku-preview

> 标签: JavaScript

## 简介

- Quickly create & configure a Heroku app that will provide a live preview for your Sanity site - Creates a \_redirects file in the 'static' folder - Creates a Procfile that instructs Heroku on how to run the app - Optionally creates a netlify.toml with y
