# @metamorph/react-share

> 标签: button, component, count, media, react, react-component, share, social, social-media

## 简介

A forked version of react-share, a library of social media share buttons and share counts for React built by Klaus Nygård. This package is temporary, as I am awaiting a pull request to be merged.
