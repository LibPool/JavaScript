# @apiverve/nutrition

> 标签: food api, food nutrition api, nutrition api, nutrition facts api, usda food api

## 简介

Nutrition returns the nutrition facts for a generic whole food by name - calories and the core macronutrients per 100 grams straight from the USDA food composition database - plus, on paid plans, a full micronutrient panel and derived nutrition intelligen
