# @xorgate/react-native

> 标签: expo, hooks, iot, react-native, replay, telemetry, video, webrtc, xorgate

## 简介

React Native adapters for @xorgate/react: live telemetry over MQTT, live video over WebRTC (react-native-webrtc / RTCView), and the recorded-media replay player over expo-video.
