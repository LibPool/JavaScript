# @goway.to/sdk

> 标签: api-client, geocoding, geospatial, goway, maps, oxy, places, routing, sdk

## 简介

The canonical, headless TypeScript client for GoWay's public geographic API — Places, capability filters, search, geocoding, routing, typed errors and canonical links for Node, Bun, browsers and React Native.
