# @bu7umaid/chamber

> 标签: ai-agents, citations, claude, claude-code, drift-detection, fact-checking, grounding, hallucination, knowledge-management, local-first, mcp, mcp-server, notes, obsidian, provenance, rag, sqlite, verification

## 简介

Checks that the numbers, capitalised names, and file names in a claim occur in the indexed note. Local, no model. It does not judge meaning. Zero runtime dependencies.
