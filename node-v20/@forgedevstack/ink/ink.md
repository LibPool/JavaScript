# @forgedevstack/ink

> 标签: angular, contenteditable, editor, forge, ink, react, rich-text, typescript, wordpress, wysiwyg

## 简介

ForgeStack rich text editor for React — WYSIWYG with tables, track changes, comments, block handles, sign pad, and pluggable Ink AI (BYO LLM). The writing layer of ForgeStack.
