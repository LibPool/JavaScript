# @stigmer/plugins

> 标签: agent-plugins, marketplace, mcp, plugins, skills, stigmer

## 简介

Stigmer's official plugin marketplace: a directory tree of Agent Plugins packages with a root marketplace.json, published at the CLI's own version so what `stigmer install` installs matches the control plane that serves it
