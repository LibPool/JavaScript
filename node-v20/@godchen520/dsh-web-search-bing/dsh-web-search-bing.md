# @godchen520/dsh-web-search-bing

> 标签: bing, cn-bing, deepseek-harness, dsh, dsh-plugin, free, plugin, search, web-search

## 简介

Free Bing-backed web search provider for the DeepSeek Harness web capability seam (ctx.web). Prefers Bing's RSS feed (clean structured XML) with HTML scraping as the fallback, against cn.bing.com (reachable from mainland China), so web_search works with n
