# @truealter/mcp-ollama

> 标签: claude-code, llm, local-first, mcp, model-context-protocol, offload, ollama, routing

## 简介

MCP server wrapping local Ollama models - offload bulk generation, summarisation, classification, and code tasks from API-priced orchestrators to a model running on the user's own hardware.
