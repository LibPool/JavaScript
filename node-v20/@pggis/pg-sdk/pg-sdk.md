# @pggis/pg-sdk

> 标签: 3D, cesium, globe, heatmap, map, turf, webGL

## 简介

盘古 Gis SDK 是基于开源项目 Cesium 进行二次开发的二三维一体的 WebGis 应用框架，该框架优化了部分 Cesium 的使用方式和增添一些通用功能，旨在为开发者快速构建 WebGis 应用。
