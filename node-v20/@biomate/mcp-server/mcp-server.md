# @biomate/mcp-server

> 标签: bioinformatics, biomate, claude, cursor, drug-discovery, genomics, mcp, rna-seq

## 简介

BioMate MCP server — exposes 19 scientific workflow tools (RNA-seq, ADMET, WGS, CryoEM, proteomics, drug discovery) to any MCP-compatible AI host via stdio.
