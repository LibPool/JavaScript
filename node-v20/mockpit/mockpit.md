# mockpit

> 标签: agent-tools, ai-agents, claude-code, coding-agents, design-review, html-preview, mcp, pi-package, visualization

## 简介

A design-decision loop for terminal coding agents — agents publish mocks with states and variants, ask questions and expose knobs; you answer, tune and comment, then send one reply.
