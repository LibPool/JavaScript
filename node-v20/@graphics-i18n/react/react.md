# @graphics-i18n/react

> 标签: JavaScript

## 简介

Web renderer for LPKG localized graphics (`@graphics-i18n/core`), producing a self-contained inline SVG — assets and fonts are inlined as data URIs, so the same markup works in the browser and in server-rendered output.
