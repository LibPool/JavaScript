# @megen-lebar/dsh-archive-panel

> 标签: archive, deepseek-harness, dsh, web-plugin

## 简介

DSH Web GUI 归档会话管理面板：查看和恢复归档对话，并通过 tombstone + 安全启动清理实现不可逆删除。
