# @frrazers/roblox-analytics-mcp

> 标签: analytics, claude, mcp, model-context-protocol, open-cloud, roblox

## 简介

A local MCP server that lets AI agents query Roblox experience analytics (DAU, revenue, retention, performance, funnels, and more) via the Open Cloud Analytics API.
