# dsh-zen-mode

> 标签: countdown, deepseek-harness, dsh, dsh-plugin, focus, pomodoro, zen

## 简介

Zen mode for DeepSeek Harness: a full-screen minimal countdown that hides DSH while tasks run, showing only the remaining time, the sessions that finished during the round, and an exit button.
