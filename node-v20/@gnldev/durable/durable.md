# @gnldev/durable

> 标签: agent, ai, ai-sdk, crash-recovery, durable, exactly-once, idempotency, journal, llm, replay, typescript

## 简介

Call-scoped exactly-once effect + deterministic-replay durability layer for Vercel AI SDK agents. Drop-in: generateText -> runDurable.
