# @yaocongjie/dsh-peak-status

> 标签: deepseek-harness, dsh, dsh-plugin, peak, token, 高峰

## 简介

Token 扣费高峰/空闲时段状态胶囊：显示北京时间 周一至周五 09:00-12:00、14:00-18:00 为 Token 扣费高峰，其余为空闲，实时高亮显示在会话头部，悬停显示规则。
