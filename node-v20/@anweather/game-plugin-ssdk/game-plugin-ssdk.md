# @anweather/game-plugin-ssdk

> 标签: JavaScript

## 简介

Generated GamePlugin RPC types/server (plugin-protocol/model/game-plugin.smithy) plus a hand-written Express bridge and default-handler wrapper (./runtime) -- see plugin-protocol/CLAUDE.md's "Publishing for cross-repo plugins".
