# @kynnyhsap/envi-1password

> 标签: JavaScript

## 简介

The 1Password provider of [Envi](https://github.com/kynnyhsap/envi). It resolves `op()` references through the official `@1password/sdk`, in one batch for each run. It does not need the `op` CLI.
