# @tahir810/react-native-upi

> 标签: android, bhim, google-pay, gpay, intent, payment, paytm, phonepe, react-native, startActivityForResult, upi

## 简介

Clean, lightweight, and complete React Native module for UPI payments using native Android Intent (startActivityForResult). Supports Google Pay, PhonePe, Paytm, BHIM, Cred, and System Chooser.
