# @nextgo/deployment

> 标签: JavaScript

## 简介

- Pull project `SharePoint JSOM NodeJS` trên gitlab để vào đường dẫn được định nghĩa trong `package.json` - `cd` vào `SharePoint JSOM NodeJS` sau đó build theo scripts có trong `package.json` của project này - `cd` về `spx` > `yarn build`
