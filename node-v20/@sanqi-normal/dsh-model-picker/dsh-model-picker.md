# @sanqi-normal/dsh-model-picker

> 标签: agent-harness, dsh, model, picker, plugin, ui, web

## 简介

Enhanced model picker for the dsh web GUI: provider-tabbed left column with model list on the right, both independently scrollable, plus cross-provider search
