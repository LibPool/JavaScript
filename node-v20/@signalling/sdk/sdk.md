# @signalling/sdk

> 标签: dpop, real-time, sdk, signalling, webrtc

## 简介

Browser-first JavaScript SDK for the Confrnce signalling backend (REST + DPoP + WebSocket + WebRTC). Self-contained — vendor or publish without cloning the server repo.
