# @natanims/voice-sdk

> 标签: amharic, sdk, speech-to-text, text-to-speech, voice

## 简介

A reusable JavaScript SDK for adding voice capabilities (STT, TTS, commands, intent recognition) to any website, with English and Amharic support.
