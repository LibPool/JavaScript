# @trenchbird/cli

> 标签: agent, automation, cli, execution-evidence, execution-evidence-recorder, flight-recorder, jupiter, solana, swap, transaction, transaction-verification, verification

## 简介

Local-first execution evidence recorder for Solana swaps through Jupiter. Acts like a flight recorder: records provider claims and transaction evidence, verifies externally signed message continuity, and compares externally supplied execution evidence—wit
