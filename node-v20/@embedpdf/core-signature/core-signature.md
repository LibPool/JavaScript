# @embedpdf/core-signature

> 标签: JavaScript

## 简介

Digital signatures, the cryptographic half: parse and verify detached CMS (PKCS#7 / CAdES-B) signatures, build one from a raw signer, gate a signing before it completes, validate trust chains, and the sign()/validateSignatures() helpers over an engine doc
