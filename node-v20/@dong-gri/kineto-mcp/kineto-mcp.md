# @dong-gri/kineto-mcp

> 标签: animation, figma, kineto, mcp, model-context-protocol, motion, shadcn

## 简介

MCP server that lets coding agents (Claude Code, Cursor, Codex, Figma MCP flows) pick, configure and validate Kineto motion modules from the real feature contract instead of guessing.
