# @bobfromarcher/ghcard

> 标签: badge, cli, devtools, github, github-profile, profile, readme, self-hosted, stat-card, stats, svg, zero-dependency

## 简介

Generate self-contained SVG stat cards + a profile README from any GitHub account. No third-party image services - all SVG is rendered locally. Zero dependencies.
