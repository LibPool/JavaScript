# @chaoticgoodcomputing/quartz-tags

> 标签: JavaScript

## 简介

Quartz 5 tag engine: one dictionary of tag colours and icon ids, published per page on fileData, as static/cgcTags.json, and as one --cgc-tag-* custom property per tag. See README.md and CONTEXT.md.
