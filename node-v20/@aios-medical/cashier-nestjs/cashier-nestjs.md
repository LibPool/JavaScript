# @aios-medical/cashier-nestjs

> 标签: billing, dependency-injection, nest, nestjs, nestjs-billing, nestjs-module, nestjs-recurly, nestjs-stripe, payments, recurly, stripe, subscriptions, typescript

## 简介

NestJS module for Cashier: unified subscription billing with forRoot, forRootAsync, an injectable CashierService and an exception filter.
