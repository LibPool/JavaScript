# @im-bot/llm-client

> 标签: agent, deepseek, im-bot, llm, minimax, openai-compatible, openrouter, zhipu

## 简介

Unified multi-provider LLM client for im-bot and Sun Shuhuan apps — DeepSeek, OpenRouter, MiniMax, Zhipu, and any OpenAI-compatible provider. TypeScript port of the Python im_bot_llm SDK.
