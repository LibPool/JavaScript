# @aidran/db

> 标签: aidran, discourse-intelligence, drizzle, postgres, schema, typescript

## 简介

AIDRAN — Drizzle ORM schemas plus generated SQL migrations for the corpus tables (records, analysis, signals, editorial, search-sync). Public reference; production system uses additional tables not included here.
