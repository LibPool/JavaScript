# @usage-fyi/wire

> 标签: JavaScript

## 简介

Shared wire contract for usage.fyi — canonicalization, content hash, and the byte-identical wire-shape types that producers (the usage-fyi CLI) and consumers (the usage.fyi server) must both understand. Zero runtime dependencies.
