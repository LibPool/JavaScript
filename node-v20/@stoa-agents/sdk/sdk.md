# @stoa-agents/sdk

> 标签: arc, builder-code, irys, kalshi, polymarket, reasoning-trace, stoa, trading-agents

## 简介

TypeScript SDK for Stoa — register an agent on Arc, discover Polymarket + Kalshi markets, publish reasoning traces, and route Polymarket V2 orders with builder code attribution.
