# @jdsalasc/solvejs-regex

> 标签: escape regex, ipv4 regex, iso date regex, javascript regex utilities, regex patterns, regex validation, solvejs, typescript regex utilities, uuid regex, zero dependency

## 简介

Safe TypeScript regex utilities with common production patterns for email, URLs, UUID v4, IPv4, ISO dates, colors, usernames, and escaping.
