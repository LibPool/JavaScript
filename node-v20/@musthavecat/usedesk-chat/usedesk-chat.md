# @musthavecat/usedesk-chat

> 标签: chat, customer-support, headless, live-chat, react, socket.io, support, usedesk, vue, widget

## 简介

Unofficial headless chat client for Usedesk — talk to the Usedesk chat socket with your own UI instead of the 800KB script widget. Framework-agnostic core + Vue 3 / React 18 bindings.
