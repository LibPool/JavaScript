# @inferlane/agent-hooks

> 标签: agent-hooks, anthropic, claude, claude-agent-sdk, cost-tracking, inferlane, llm-cost, managed-agents, observability

## 简介

Drop-in lifecycle hooks for Claude Agent SDK and Anthropic Managed Agents — auto-log cost, tokens, and runtime to InferLane without explicit tool calls.
