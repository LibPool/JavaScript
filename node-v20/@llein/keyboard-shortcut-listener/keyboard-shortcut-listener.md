# @llein/keyboard-shortcut-listener

> 标签: cmd-k, ctrl-k, hotkey, keyboard, react-hook, react-hotkey, shortcuts, typescript, utility, zero-dependency

## 简介

Zero-dependency keyboard shortcut listener and React hook for Cmd+K, Ctrl+S, Escape with cross-platform Mod key and input field suppression.
