# @serkanalgur/residue

> 标签: context-injection, fts5, local-first, memory, opencode, plugin, project-memory, sqlite

## 简介

Persistent, local-first project memory for OpenCode — extracts atomic 'decision + reason' facts from sessions and injects relevant notes via context hooks.
