# @doany-ai/ai-sdk

> 标签: ai, cloudflare-workers, doany, gateway, llm, openai, sdk

## 简介

Client SDK for doany-deployed sites to call the doany API Gateway with their site token (sk). Cloudflare Workers friendly.
