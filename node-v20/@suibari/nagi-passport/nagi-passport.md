# @suibari/nagi-passport

> 标签: atproto, bluesky, cloudflare-workers, jws, sso

## 简介

Short-lived signed identity tickets that let Nagi hand a signed-in session to sibling AT Protocol apps. Zero dependencies, Web Crypto only.
