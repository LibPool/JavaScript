# @tty.link/font-kku

> 标签: animation, decomposition, font, hangul, ime, jamo, korean, themes, typography, web-components

## 简介

Browser library for decomposing Korean Hangul syllables into jamo and rendering them as stylable, repositionable glyph parts

## 官网

- 官网：https://font.tty.link/
