# manga-text-regions

> 标签: bubble, canvas, comic, image-processing, manga, manhwa, no-dependencies, ocr, panel, reading-order, speech-bubble, text-detection, translation, webtoon

## 简介

Detect text regions on manga, manhwa and webtoon pages and return them in reading order. Dependency-free, no OCR model required.

## 官网

- 官网：https://mangatranslator.me
- npm 页面：https://www.npmjs.com/package/manga-text-regions
