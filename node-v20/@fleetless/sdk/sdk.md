# @fleetless/sdk

> 标签: api, fleetless, mcp, realtime, robot, robotics, ros, ros2, sdk, webrtc

## 简介

The official TypeScript SDK for Fleetless client apps — a ROS 2 robot as a REST and realtime API, cameras, jobs, and the app's own user accounts, federated sign-in and MCP consent.
