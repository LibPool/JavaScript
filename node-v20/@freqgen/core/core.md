# @freqgen/core

> 标签: arbitrary-waveform, dds, function-generator, serial, serialport, signal-generator, typescript, waveform-generator, web-serial

## 简介

Shared core for USB-serial signal / arbitrary waveform generator drivers: transports (Node serialport / Web Serial), the SignalGenerator interface, capability and frequency-limit metadata, and octave folding.
