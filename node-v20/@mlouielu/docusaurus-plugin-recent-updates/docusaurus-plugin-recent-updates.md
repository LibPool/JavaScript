# @mlouielu/docusaurus-plugin-recent-updates

> 标签: changelog, docusaurus, docusaurus-plugin, last-updated, recent-updates, wiki

## 简介

A build-time Docusaurus plugin + theme component that lists your most recently updated docs (e.g. on the homepage), using git history for the dates — just like the sitemap plugin.
