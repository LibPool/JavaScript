# @codewizwit/das-cli

> 标签: claude, claude-code, cli, documentation, progressive-disclosure, skill

## 简介

Slices documentation into context-efficient chunks with an index, so Claude loads only what it needs on demand. Point it at a GitHub URL, a Markdown file, a docs folder, or a project root.
