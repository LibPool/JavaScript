# @betrayzl/windows-computer-use-mcp

> 标签: automation, computer-use, desktop-automation, mcp, model-context-protocol, napi-rs, rust, screenshot, uia, windows

## 简介

Human-like Windows control for AI agents via the Model Context Protocol. Combines DXGI visual perception with simulated mouse/keyboard input. Built by a non-programmer with Claude Code.
