# @nizam-os/jsonapi-core

> 标签: atomic-operations, cursor-pagination, json-api, jsonapi, keyset, rest, sparse-fieldsets

## 简介

JSON:API 1.1 for any JavaScript runtime: resource definitions, documents, query parsing, request parsing, content negotiation, the Cursor Pagination profile, and the Atomic Operations extension. Framework-free.
