# @nizam-os/jsonapi-client

> 标签: atomic-operations, client, cursor-pagination, fetch, json-api, jsonapi, rest, typed

## 简介

A typed fetch client for JSON:API 1.1 servers: calls, queries, records, errors, and Atomic Operations typed from the @nizam-os/jsonapi-core definitions the server is built from, with nothing generated. Runs wherever fetch does.
