# @nizam-os/pg-catalog

> 标签: catalog, codegen, migrations, pg-catalog, pglite, postgres, postgresql, schema

## 简介

Your PostgreSQL schema as committed TypeScript: replays SQL migrations into PGlite or a throwaway database, reads pg_catalog, and writes a deterministic typed catalog of every table, column, constraint, index, policy, enum, and domain, with a browser-safe
