# @nizam-os/tanstack-query-jsonapi

> 标签: atomic-operations, cursor-pagination, json-api, jsonapi, query-core, tanstack-query

## 简介

TanStack Query options for @nizam-os/jsonapi-client's calls, for every adapter: keys that are the request each call sends, reads that pass the query's signal, infinite lists by the server's links, writes that stay pending until what they changed has refet
