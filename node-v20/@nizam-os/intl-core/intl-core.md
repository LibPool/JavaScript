# @nizam-os/intl-core

> 标签: bidi, formatting, hydration, i18n, intl, paraglide, ssr, time-zone

## 简介

Hydration-safe formatting for any JavaScript runtime: formatters that read the locale and the reader's time zone on every call through cached Intl objects built for pinned formatting tags, the reader's time zone from a cookie, and Unicode bidi isolation.
