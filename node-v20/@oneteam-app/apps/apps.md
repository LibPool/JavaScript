# @oneteam-app/apps

> 标签: authentication, authorization, nextjs, oauth, oidc, oneteam, react, sso, tanstack-start

## 简介

Oneteam login, employee context and permission checks for apps launched from Oneteam. Framework-agnostic core with Next.js, TanStack Start and React adapters.
