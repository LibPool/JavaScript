# @octopus-reef/adapter-observe

> 标签: JavaScript

## 简介

The Reef input boundary: turn an untrusted agent input (a tool call, an action) into a validated, canonical Observation via octopus-observe, then bridge it to evidence a governed session can carry. Only trusted observations cross the boundary.
