# @mpxjs/e2e

> 标签: e2e, miniprogram, mpx

## 简介

基于官方自动化库`miniprogram-automator`上进行了封装，提供了wait模式和mock的功能，另外获取dom元素更加稳定便捷。

## 官网

- 官网：https://github.com/mpx-ecology/mpx-e2e#readme
- npm 页面：https://www.npmjs.com/package/@mpxjs/e2e
