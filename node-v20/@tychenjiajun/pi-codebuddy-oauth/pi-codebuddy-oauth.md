# @tychenjiajun/pi-codebuddy-oauth

> 标签: api-key, codebuddy, extension, ioa, oauth, openai-compatible, pi, pi-coding-agent, pi-extension, pi-package, provider

## 简介

Pi extension that registers CodeBuddy (IOA, Tencent) as an OpenAI-compatible HTTP provider with OAuth login or API-key auth, auto model discovery, and retries
