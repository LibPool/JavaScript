# @streamline-pulse/creeba-iroh-mdns

> 标签: creeba, iroh, mdns, p2p, quic, transport

## 简介

Creeba iroh + mDNS transport for Bun/Node (desktop & server nodes): encrypted QUIC (holepunch + relay) with serverless mDNS discovery, plus ed25519 identity primitives. Implements @streamline-pulse/creeba-core's SyncTransport. Carries the native binding s
