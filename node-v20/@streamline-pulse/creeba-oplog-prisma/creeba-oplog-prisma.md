# @streamline-pulse/creeba-oplog-prisma

> 标签: creeba, local-first, op-log, prisma, sync

## 简介

Prisma binding for @streamline-pulse/creeba-oplog: transparent mutation capture ($extends), a ready-made OpStore and Projection. One schema covers relational connectors (pg/mysql/sqlite/cockroach); a Mongo variant (synthetic key) is provided. The app only
