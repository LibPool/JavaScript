# @streamline-pulse/creeba-mesh

> 标签: creeba, ed25519, local-first, membership, p2p, pairing, trust

## 简介

Trust layer for Creeba meshes: portable ed25519 node identity, self-contained membership certificates with revocation, and local pairing. Certificates verify offline against trust anchors — no server, no CA. Crypto is injectable and wire-compatible with i
