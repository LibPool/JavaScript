# @delightstack/crdt

> 标签: cloudflare, collaborative-editing, crdt, delightstack, durable-objects, local-first, loro, prosemirror, time-travel, version-history

## 简介

Collaborative document storage for Cloudflare Durable Objects — a Loro CRDT wrapper with an append-only op log, derived edit sessions, named checkpoints, time travel and compaction.
