# @vincweb/code-atlas

> 标签: architecture, audit, clean-code, cli, code-quality, dependency-graph, devtools, drizzle, typescript

## 简介

Map and audit a TypeScript codebase — the feature dependency graph, its layers, its metrics, scripted and AI audit rules, the Drizzle schema and its migrations, and a CI guard against regressions
