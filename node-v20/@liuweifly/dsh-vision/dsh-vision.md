# @liuweifly/dsh-vision

> 标签: cordis, deepseek-harness, dsh, image, multimodal, vision

## 简介

Give text-only DeepSeek Harness models eyes: chat image attachments are described by a vision model before they reach the DeepSeek API. Works with any OpenAI-compatible vision endpoint (DashScope Qwen-VL, SiliconFlow, local MLX/Ollama, ...).
