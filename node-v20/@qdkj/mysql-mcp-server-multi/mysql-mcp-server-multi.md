# @qdkj/mysql-mcp-server-multi

> 标签: database, ddl, mcp, model-context-protocol, multi-connection, mysql, sql

## 简介

多连接版 MySQL MCP 服务端；基于 @qdkj/mysql-mcp-server v1.0.5，单 server 实例承载 N 个 MySQL 连接，工具层显式 conn 参数路由。
