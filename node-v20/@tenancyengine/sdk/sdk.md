# @tenancyengine/sdk

> 标签: multi-tenant, platform, saas, sdk, tenancyengine

## 简介

Server-side TypeScript SDK for ISV applications integrating with the TenancyEngine platform (SaaSRuntime): runtime context, feature/plan limits, metered usage, tenant provisioning, AI extraction and prepaid AI credits, storage grants, analytics, and webho
