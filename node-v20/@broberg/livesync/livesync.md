# @broberg/livesync

> 标签: broberg, collaborative-editing, crdt, livesync, offline, realtime, yjs

## 简介

Real-time collaborative editing on Yjs for the fleet: a sync server that runs inside your own app (login check before the first byte, read/write per document, load/store hooks in your own database), and a browser client that reconnects, keeps working offl
