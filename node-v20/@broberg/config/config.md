# @broberg/config

> 标签: broberg, config, dotenv, env, environment, feature-flags, validation, zod

## 简介

The fleet's single-source config helper — a Zod-based env parser that validates + types process.env at boot (fail-fast, listing every offending key), a defineConfig factory for typed business-constant objects, and coerceInt/coerceBool/productionGuard esca
