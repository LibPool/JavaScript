# @broberg/seal

> 标签: aad, aes-256-gcm, aes-gcm, broberg, byok, encryption, encryption-at-rest, envelope-encryption, key-rotation, secrets, web-crypto

## 简介

Encrypt secrets you must store and read back — a customer's own API key, an OAuth refresh token — with AES-256-GCM envelope encryption, a required context (AAD) and key rotation. Web Crypto only, zero dependencies; Node, Bun, Deno and edge.
