# @broberg/lens-svg

> 标签: JavaScript

## 简介

Lens SVG engine: collect a rendered page in the browser and serialize it to an editable SVG (+ lint of what SVG cannot represent). Used by Cloud Lens and @broberg/lens-daemon. TypeScript source, Bun runtime.
