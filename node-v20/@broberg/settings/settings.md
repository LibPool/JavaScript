# @broberg/settings

> 标签: broberg, dirty-tracking, form, preact, settings, stack-b, unsaved-changes

## 简介

The fleet's settings surface for Stack B (Preact): a dirty-bus that knows whether anything is unsaved and waits for every panel before saying «Gemt», plus Card / SectionHeading / Field / Input / Toggle / Save button on @broberg/theme tokens. Framework-fre
