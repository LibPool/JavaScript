# @barood-labs/tinkertoy

> 标签: agent-skill, ai-agent, claude-code, codex, cursor, explorable-explanations, interactive, simulation, skill, visualization

## 简介

An agent skill that makes your coding agent answer "how does X work" with one self-contained, playable HTML simulation: sliders, a scrub bar and a break-it button.
