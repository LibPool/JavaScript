# @ai-ecoverse/wasix-f2c

> 标签: f2c, fortran, homescoop, slicc, wasix, wasm

## 简介

Fortran 77 for slicc WASIX via f2c: static PIC libf2c.a (CLAPACK 3.2.1, Pyodide's patches), f2c.h, the f2c source with bin/build-f2c.sh, and bin/gfortran (gfortran -> f2c -> wasixcc)
