# @ai-ecoverse/wasi-llvm

> 标签: clang, homescoop, lld, llvm, slicc, wasi, wasm

## 简介

LLVM 21.1.8, clang and lld as static libraries for a wasm32-wasip1-threads host, with a python3 llvm-config; a build input for the LLVM-enabled wasi-rustc and wasi-zig
