# @b-c/routeparams-from-url

> 标签: JavaScript

## 简介

Takes a route definition of the form ```/abc/:a/:b/:c``` and an actual url e.g. ```/abc/1/2/test``` and returns an object mapping ```{a: 1, b: 2, c: "test"}```.
