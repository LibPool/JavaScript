# nestjs-idempotency-key

> 标签: idempotency, idempotency-key, interceptor, nestjs, redis, retry

## 简介

Stripe-style Idempotency-Key support for NestJS: safe retries for POST/PATCH endpoints, backed by Redis or memory.
