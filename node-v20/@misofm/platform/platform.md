# @misofm/platform

> 标签: blockchain, miso, move, music, party, pressing, sdk, sui

## 简介

Complete client SDK for the Miso platform on Sui — high-level reads, pressings, listings, records, work publishing, Party extensions, and the first-party extensions built on top of the @misofm/musicos object model and the @misofm/partyos Party identity mo
