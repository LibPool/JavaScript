# @qartlabs/leaflet-geotiff

> 标签: JavaScript

## 简介

A [LeafletJS](http://www.leafletjs.com) plugin for displaying geoTIFF raster data.  Data can drawn as colored rasters or directon arrows.  The layer can be clipped using a polygon.
