# @kevinpeckham/barkup

> 标签: agents, ast, codec, grammar, html, llm, markup, round-trip, serialization, typed-tree

## 简介

Author typed trees as HTML. A config-driven grammar codec with byte-for-byte id preservation, declared attribute coercion, and round-trip guarantees — designed for humans and LLM agents authoring the same markup.
