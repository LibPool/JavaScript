# @nest-app/uapp

> 标签: mobile, uapp, uniapp, vue

## 简介

uapp 是一个方便 uniapp 离线打包的脚手架工具，类似 cordova, expo, Taro 等项目cli的作用。uapp还包含 uapp-android, uapp-ios 两个平台的模板代码
