# @openpromo/sdk-runtime

> 标签: fetch, http-client, pagination, rate-limit, sdk-runtime

## 简介

Shared runtime primitives for @openpromo ad platform SDKs — fetch-based HttpClient, cursor pagination, rate limiter, retry.
