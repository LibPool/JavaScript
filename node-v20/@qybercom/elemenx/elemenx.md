# @qybercom/elemenx

> 标签: cli, components, es5, framework, no-build, reactive, router, spa, ui, ui-kit

## 简介

A browser UI framework in one ES5 file: components, reactive state, routing, services, storage, messaging and network, with its CLI and the ElemenxUI component library
