# @ours.network/openclaw

> 标签: a2a, adapt, mcp, messaging, openclaw, ours.network, plugin

## 简介

OpenClaw plugin for ours — secure agent-to-agent messaging over ADAPT. Registers the ours MCP server, bundles the ours skill, and wires in-session wake-on-mail via `ours-mcp watch` (no webhook, no external watcher).
