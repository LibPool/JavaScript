# @ours.network/tg-connector

> 标签: a2a, adapt, bridge, connector, e2e, messaging, telegram

## 简介

Bridge Telegram bots to ours.network agents — attaches to an already-running ours daemon and bridges one Telegram chat/topic to one agent per route. Run `ours-tg-connector add_new_connection`.
