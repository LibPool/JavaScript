# @newfoundcodes/helvetium-boot

> 标签: helvetium, helvetium-boot, middleware, openapi, router, rpc, server-actions, ssr, typescript, web-framework, websocket

## 简介

Helvetium Boot is a web framework with Web-Standard HTTP, routing, middleware, validation, OpenAPI 3.1, RPC, security, WebSockets, server actions, and Helvetium DOM SSR/same-document navigation integration.
