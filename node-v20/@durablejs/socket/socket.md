# @durablejs/socket

> 标签: multiplayer, websocket

## 简介

**@durablejs/socket** is a reconnecting websocket class, with **more accuracy**, allows Ping/Pong, intended to be used with [durablejs](https://github.com/DurableJS/DurableJS)
