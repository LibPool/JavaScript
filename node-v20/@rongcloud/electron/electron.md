# @rongcloud/electron

> 标签: Electron, IM, RongCloud, SDK

## 简介

通过 @rongcloud/electron 与 @rongcloud/electron-renderer 模块赋能开发者在自己的桌面端应用上快速拥有专业的、丰富、高质量的互联网通信能力。
