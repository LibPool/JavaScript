# @usewrit/web

> 标签: automation, browser-extension, local-network, sdk, web, workflows, writ

## 简介

Let a website run Writ workflows on the visitor's own computer through the Writ browser extension: a drop-in setup banner, one-click installable workflows, a typed client from the contract file, calls with progress, cancel and typed errors.
