# @usewrit/server

> 标签: automation, browser-extension, ed25519, express, nextjs, receipts, sdk, server, workflows, writ, writ-bridge

## 简介

The server side of the Writ Bridge for Node: run your website's Writ functions on a signed-in visitor's own computer (with signed receipts) or on Writ Cloud, from one typed object, behind one route you mount.
