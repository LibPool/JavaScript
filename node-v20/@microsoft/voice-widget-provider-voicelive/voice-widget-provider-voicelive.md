# @microsoft/voice-widget-provider-voicelive

> 标签: JavaScript

## 简介

Azure Voice Live adapter for the Voice Agent Widget SDK. Implements VoiceAgentProvider over WebRTC via the Media Gateway: model & agent modes + session.update.
