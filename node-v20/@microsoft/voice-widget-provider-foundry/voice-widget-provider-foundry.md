# @microsoft/voice-widget-provider-foundry

> 标签: JavaScript

## 简介

Foundry Voice Agent adapter for the Voice Agent Widget SDK (WS-15). Phase A: a thin VoiceAgentProvider wrapper that delegates the data plane to @microsoft/voice-widget-provider-voicelive (WebRTC via the Media Gateway, agent mode) while the broker resolves
