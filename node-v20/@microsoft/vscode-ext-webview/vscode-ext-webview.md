# @microsoft/vscode-ext-webview

> 标签: JavaScript

## 简介

Webview infrastructure for VS Code extensions: type-safe tRPC over postMessage with pluggable telemetry middleware, plus an optional extension-host panel facade, a framework-agnostic webview client, and optional React hooks.
