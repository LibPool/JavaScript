# @tryonit/web

> 标签: angular, ar, augmented-reality, ecommerce, face-tracking, glasses-try-on, hand-tracking, mediapipe, shopify, svelte, three, try-on, virtual-makeup, virtual-try-on, vue, webar, webgl

## 简介

Client-side virtual try-on engine for the browser: real-time makeup, glasses, hats, earrings, watches, rings, hair color and clothing overlays using MediaPipe and WebGL. Framework-free mount() for Vue, Svelte, Angular and plain HTML.
