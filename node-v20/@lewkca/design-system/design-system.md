# @lewkca/design-system

> 标签: accessibility, component-library, design-system, react, storybook, tailwindcss, typescript, ui

## 简介

A small, typed React component library built on the araxiemiller.com design language — polymorphic primitives, composition APIs, and accessibility baked into the tokens.
