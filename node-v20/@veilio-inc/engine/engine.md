# @veilio-inc/engine

> 标签: ai, anonymizer, code, identifiers, llm, privacy, redaction, veilio

## 简介

Two-way code anonymizer: replace real identifiers with __P1__ tokens before sending source code to an LLM, restore them afterward. Pure, local, no network, no telemetry, zero runtime dependencies.
