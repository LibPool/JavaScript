# @aevion-io/catalog-client

> 标签: aevion, api-client, catalog, client, coach, devhub, discovery, module-registry, multichat, planet, qcoreai, qevents, qlearn, qmedia, qstore, sdk, typescript, zero-deps

## 简介

TypeScript client for the AEVION Hub catalog API (/api/aevion/*) — module discovery, registry stats, status badges, plus typed sub-clients for QStore, QLearn, QEvents, DevHub, Planet, QCoreAI, Multichat, QMedia, Coach. Zero deps.
