# @bysking/browser-store

> 标签: browser, cdp, chrome, cli, edge, mcp, multiprofile

## 简介

浏览器多开管理 CLI：基于 Chrome/Edge 多开实例，独立 profile 与会话，独立 CDP 调试端口，每个实例可暴露 MCP Server 给 AI 客户端，带 umijs 管理台
