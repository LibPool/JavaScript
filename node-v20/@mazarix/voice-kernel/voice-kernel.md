# @mazarix/voice-kernel

> 标签: bidi, farsi, persian, rtl, speech-to-text, transcription, unicode

## 简介

The shared kernel behind FarsiTalkWrite: Persian/English transcription prompts, tuned recording and retry constants, and the bidi isolation algorithm that keeps embedded Latin words where they were spoken.
