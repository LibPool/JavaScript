# @sahan-sac/create-admin

> 标签: admin, cms, create-app, nextjs, starter

## 简介

Scaffold a new project from the admin-template (auth, RBAC, CMS, blog, media, leads, chatbot on Next.js). Run with `npm create @sahan-sac/admin@latest`.
