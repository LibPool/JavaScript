# @cmsweb-dev/cms

> 标签: astro, cms, headless-cms, mdx, react, react-server-components

## 简介

Show posts from the cmsweb.dev CMS on your website: the API types, the rule checker, React and Astro renderers that draw each post with your own components, a Markdown copy of each post, the sitemap, llms.txt, hreflang and refresh helpers, and the command
