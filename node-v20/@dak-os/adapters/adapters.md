# @dak-os/adapters

> 标签: JavaScript

## 简介

The Dak Stack reference adapters — the concrete, swappable implementations behind @dak-os/ports' seams: keyless web + offline-fixture research (ResearchPort), a git/dry-run file publisher (PublishPort), and a local-libSQL event store + HITL approval/steer
