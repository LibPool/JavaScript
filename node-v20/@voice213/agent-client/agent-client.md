# @voice213/agent-client

> 标签: algerian, arabic, conversational ai, darija, react, realtime, speech, voice agent, voice ai, voice213, web component, websocket

## 简介

Talk to your Voice213 voice agents from any website or app: real-time voice calls in Algerian, Tunisian, Moroccan and Libyan Darija, French or English, with a React hook, a drop-in widget element and webhook verification.
