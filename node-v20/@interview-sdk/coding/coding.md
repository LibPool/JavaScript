# @interview-sdk/coding

> 标签: ai-interview, coding-interview, interview-sdk, sandbox

## 简介

Sandboxed code execution and evaluation for Coding Interview Mode, isolated in its own package so a sandbox vulnerability can't compromise the rest of the SDK.
