# @facet-llc/adapter

> 标签: JavaScript

## 简介

TypeScript types and reference parser for the Facet commerce system adapter: agents.txt v1.2, FacetPaymentRailAdapter interface, origination verifiers, and per-primitive request/response types. Zero runtime deps. Apache-2.0.
