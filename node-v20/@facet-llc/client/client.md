# @facet-llc/client

> 标签: agent-commerce, facet, kya, openapi, sdk, terminal, x402

## 简介

Agent-side client SDK for the Facet Terminal protocol. Handles KYA bearer tokens, structured error envelopes, X-Agent-Trace-Id propagation, X-Facet-RateLimit-* capture, and idempotency-key forwarding. Runs on Node 20+, Bun, and Deno. Native fetch + AbortC
