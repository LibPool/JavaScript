# @facet-llc/payment-adapter-stripe

> 标签: JavaScript

## 简介

Facet Terminal payment-rail adapter for Stripe (Cards, ACH, wallets). Implements FacetPaymentRailAdapter on top of the official stripe npm package. PaymentIntents with reserve-capture, refunds, disputes, and webhook signature verification.
