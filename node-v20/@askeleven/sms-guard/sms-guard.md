# @askeleven/sms-guard

> 标签: ai-agents, deliverability, gsm-7, mcp, mcp-server, quiet-hours, sms, sms-segments, tcpa, text-message, ucs-2

## 简介

Check a text message before an agent (or a person) sends it: GSM-7 or UCS-2, segment count, the recipient's local time, shorteners and opt-out wording. Splits long messages. CLI, library, and MCP server. Zero dependencies.
