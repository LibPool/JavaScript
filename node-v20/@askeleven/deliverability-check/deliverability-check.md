# @askeleven/deliverability-check

> 标签: bimi, can-spam, casl, deliverability, dkim, dmarc, dns, email, spf

## 简介

Check whether a domain is set up so its email actually arrives. SPF, DKIM, DMARC, MX, BIMI, blocklists. Zero dependencies, no signup, no data kept.
