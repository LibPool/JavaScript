# @hkaxlcoder/logger

> 标签: JavaScript

## 简介

A lightweight, modular, and highly customizable NestJS-inspired logger for TypeScript and JavaScript applications. Designed for developer ergonomics with distinctive ANSI colorization for variables, objects, arrays, and primitive data types out of the box
