# @veams/generator-veams

> 标签: app, boilerplate, browserify, component, es harmony, front-end, grunt, homepage, javascript, jquery, mangony, prototype, prototypes, react, scaffold, singl page apps, static page apps, templating, veams, veams-components, veams-generator, web apps, webpack, websites, yeoman-generator

## 简介

Scaffold modern frontend web apps or web pages with/out a static site generator, Grunt and/or Webpack. Use modern frameworks like Bourbon, Bootstrap or Foundation and structure your JavaScript with ES Harmony support.
