> 标签: deepseek-harness, dil, dsh, dsh-bundle, dsh-plugin, echarts, generative-ui, intelligent-ui, interactive-ui

## 简介

Intelligent UI for DeepSeek Harness — the model writes the interface in DIL (Markdown + JSX-like tags + JavaScript), the host compiles it into a program plus a constants table, and a sandboxed client runtime turns it into interactive text + rich card answ
