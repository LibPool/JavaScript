> 标签: angular, angular-components, component-library, dark-mode, design-system, signals, standalone, theme, ui, zoneless

## 简介

Standalone, signal-based Angular components with a single theme layer: buttons, inputs, chips, nav bar, lists, tree, table, dialogs and more.
