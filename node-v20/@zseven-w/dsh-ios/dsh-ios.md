# @zseven-w/dsh-ios

> 标签: dsh, ios, ios-simulator, plugin, simulator

## 简介

DeepSeek Harness plugin for the iOS Simulator — build, run, and interact with a live simulator stream inside a conversation. Tested with DSH 0.1.5-rc.1.
