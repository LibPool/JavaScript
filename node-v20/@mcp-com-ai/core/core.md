# @mcp-com-ai/core

> 标签: JavaScript

## 简介

HAPI MCP engine: Elysia server, MCP handlers, OAuth flows, swagger model, OpenAPI utilities, telemetry. Consumed by first-party plugins — not a user-facing CLI.
