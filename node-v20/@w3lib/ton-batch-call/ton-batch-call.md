# @w3lib/ton-batch-call

> 标签: batch, jetton, nft, ton, toncenter

## 简介

Batched TON reads and writes via the toncenter v3 indexer: TON / jetton balances for many owners per request, jetton metadata, NFTs, wallet states; batch transfers, collection, batch transactions (wallet v4r2 / v5r1, TON Connect). No TON SDK dependency.
