# @x1a0f3n9/dsh-experimental-webworker-runtime

> 标签: JavaScript

## 简介

Browser-only harness runtime: in-memory VFS, module transform and loader, postMessage tunnel, and the dedicated Web Worker assembly, with the Node-compatibility layer that lets the host tree run unchanged
