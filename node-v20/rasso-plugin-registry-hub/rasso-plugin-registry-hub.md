# rasso-plugin-registry-hub

> 标签: JavaScript

## 简介

Rasso 插件生态分级标准与扩展治理工作台：查看全网与本地插件的分级认证标签（官方核心、生态认证、社区试验），审计插件权限与沙箱合规度，管理版本生命周期
