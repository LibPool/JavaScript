# @stll/regex-set-win32-x64-msvc

> 标签: multi-pattern, napi-rs, native, regex, regex-set, rust

## 简介

Single-pass multi-pattern regex for Node.js/Bun. Backtracking-immune, Unicode-aware Rust engine via NAPI-RS.
