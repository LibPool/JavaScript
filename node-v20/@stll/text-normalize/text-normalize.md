# @stll/text-normalize

> 标签: arabic, i18n, normalization, search, text-search, unicode

## 简介

Search match-key text normalization — Arabic orthographic variant folding (alef/hamza/teh-marbuta/yeh, tashkeel, tatweel, digits) with per-language fold tables
