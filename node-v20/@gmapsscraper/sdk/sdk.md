# @gmapsscraper/sdk

> 标签: api-client, b2b, business data, email extractor, google maps api, google maps scraper, google-maps, lead generation, leads, local business, places, reviews, scraper, sdk

## 简介

Official Node.js SDK for the gmapsscraper.io API — scrape Google Maps business data: names, addresses, phones, emails, websites, ratings and reviews.
