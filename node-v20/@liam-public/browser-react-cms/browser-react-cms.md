# @liam-public/browser-react-cms

> 标签: JavaScript

## 简介

Batteries-included CMS framework: app-shell, auth guards, dark mode, toasts, Zod forms, data-table + pagination, dashboards, analytics, and i18n, on Tailwind v4 + Radix.
