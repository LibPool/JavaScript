# @vosso/cli

> 标签: cli, vos, vosso

## 简介

Forwarding shim: this package was renamed to @vosso/vos-plugin (the vosso platform layer of the vos CLI). Installing this name keeps older setups and prompts working; new installs should use @vosso/vos-plugin.
