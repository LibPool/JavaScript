# @reneza/ats-adapter-github

> 标签: agent-context, agent-memory, agentic, ats-adapter, claude-code, context-engineering, github, github-agent-memory, github-api, github-issues, github-mcp, hybrid-search, issues, mcp, rag, retrieval, rrf

## 简介

GitHub Issues adapter for Agentic Task System. Expose any repository's issues as agent-queryable tasks through ATS retrieval, RRF fusion, and MCP — a repo is a project, an issue is a task. Adapter, not migration.
