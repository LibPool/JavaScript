# eslint-plugin-next-security

> 标签: access-control, app-router, auth-guard, authentication, authorization, dal, data-access-layer, drizzle, eslint, eslint-plugin, eslintplugin, formdata, input-validation, lint, linter, next, nextjs, prisma, react-server-components, rsc, security, server-actions, sql-injection, taint-analysis, typescript, use-server, valibot, zod

## 简介

ESLint rules for the Next.js App Router attack surface: unguarded Server Actions, data-layer imports outside the DAL, unvalidated FormData reaching the database.
