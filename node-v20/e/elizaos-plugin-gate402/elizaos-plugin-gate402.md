## 简介

ElizaOS plugin for Gate402: pay-per-call GPU/CPU compute + open-model LLM inference, plus Base market data (onchain, token-risk, DEX, momentum, launches, best-swap), over x402 (USDC). No API keys — the agent pays the 402.
