# etymd

> 标签: agents, agents-md, ai, claude-md, cli, context-engineering, developer-tools, drift, instructions, lint, truth

## 简介

Keep your agent instructions true — verify AGENTS.md, CLAUDE.md, rules, skills, and the task you hand an agent against the actual repo, with drift caught over time and a regression ledger.
