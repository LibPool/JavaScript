# esbuild-plugin-typescript

> 标签: backend, build, build plugin, build process, build tool, d.ts, developer tools, esbuild, esbuild d.ts, esbuild plugin, esbuild tool, esbuild tsc, esbuild type check, esbuild typescript, esubild type checking, frontend, packages, plugin, tsc, type check, type checking, typescript

## 简介

The plugin enhances the build process by seamlessly integrating TypeScript, offering powerful features like type checking, automatic generation of .d.ts files, and ensuring robust type safety throughout.
