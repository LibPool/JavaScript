# es-toolkit-clean

> 标签: browser, cjs, class-instances, clean, compact, data-cleaning, empty, es-toolkit, esm, filter, functional, immutable, javascript, node, null, object, object-processing, remove, sanitize, trim, typescript, undefined, utility

## 简介

A lightweight, TypeScript-first library for cleaning JavaScript objects by removing undefined values, empty strings, empty arrays, functions, and other unwanted properties. Built on es-toolkit for superior performance.
