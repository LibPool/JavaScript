# ewx

> 标签: JavaScript

## 简介

ewx 是一个基于 wxml 扩展的小程序 html 模板。主要功能是扩展 wxml 的数据绑定（可以调用函数等），并和 mobx 结合，使用 mobx 作为状态管理。
