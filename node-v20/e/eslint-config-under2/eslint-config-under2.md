# eslint-config-under2

> 标签: config, ecmascript, eslint, javascript, lint, prettier

## 简介

- Run `yarn add -D eslint-config-under2` to add the eslint config to your project - Run `npx install-peerdeps eslint-config-under2 --dev`  to install all peer deps  - Eslint should now be running
