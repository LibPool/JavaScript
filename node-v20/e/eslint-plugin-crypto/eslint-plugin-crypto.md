# eslint-plugin-crypto

> 标签: ai-assistant, auto-fix, crypto, cryptography, cve, cwe, encryption, eslint, eslint-plugin, eslintplugin, hashing, llm-optimized, marvin-attack, nodejs-crypto, owasp, security, timing-attack, typescript, vulnerability

## 简介

Security-focused ESLint plugin with 24 AI-parseable rules for cryptographic best practices. Detects weak algorithms, insecure key handling, CVE-specific vulnerabilities, and deprecated crypto patterns.
