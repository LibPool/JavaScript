# emg-editor

> 标签: JavaScript

## 简介

Emg-editor is a hybrid between and markdown editor and a WYSIWYG editor. It allows you to write down notes, articles, documentation, or whatever you want, as quickly as it was a markdown editor, but with great customization like a WYSIWYG editor.
