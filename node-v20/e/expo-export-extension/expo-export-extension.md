# expo-export-extension

> 标签: browser-extension, chrome-extension, expo, expo-router, manifest-v3, react-native

## 简介

Turn an Expo (React Native) web export into a Chrome/browser extension. Handles CSP, underscore renames, and Expo Router in popup.
