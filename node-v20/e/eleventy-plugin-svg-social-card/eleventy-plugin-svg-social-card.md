# eleventy-plugin-svg-social-card

> 标签: eleventy, eleventy-plugin, og-image, open-graph, social-card, svg, twitter-card

## 简介

Eleventy plugin that generates per-page social card images (OG image / Twitter card) from an SVG template using a headless browser.
