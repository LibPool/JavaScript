# easystatic

> 标签: blog, boilerplate, browsersync, build, builder, compile, compiler, docs, documentation, generator, github pages, markdown, postcss, site, static, static site, static site generator, web development, website

## 简介

A simple static site generator that uses Markdown It for web pages, PostCSS and EJS for layout, Browsersync for cross-device testing..
