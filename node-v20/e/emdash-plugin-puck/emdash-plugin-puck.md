# emdash-plugin-puck

> 标签: astro, cms, emdash, emdash-plugin, page-builder, puck, puckeditor, visual-editor

## 简介

The Puck visual editor as an EmDash field widget: edit any json field as a page layout, render it on the public site, pick images from the EmDash media library, and optionally wire up Puck AI.
