# efferent

> 标签: agent, agent-runtime, ai-agent, anthropic, bun, cli, daemon, effect, gemini, llm, openai, tui

## 简介

efferent — an agent runtime on Effect.ts + Bun. One CLI to run agents: an interactive TUI, headless (print/json/rpc), or a persistent per-workspace daemon that thin clients attach to. Multi-provider (Anthropic/OpenAI/Gemini), persistent sub-agent context
