# eurostat-map

> 标签: NUTS, SVG, cartography, d3, data visualization, dataviz, europe, eurostat, eurostat-map, maps, statistics, thematic-mapping

## 简介

Reusable library to quickly create and customise web maps showing Eurostat data directly retrieved from Eurostat database.
