# eslint-plugin-snakify

> 标签: eslint, eslint-config, eslint-plugin, eslintplugin, formatter, lint, naming-convention, snakify, style, typescript

## 简介

ESLint plugin that enforces snake_case naming convention for variables and functions, with automatic fixing and configurable options
