# extraduce

> 标签: action, array, enhancer, filter, handle, handling, higher, history, order, postprocessing, postreduce, prepare, preprocessing, prereduce, process, processing, reducer, state, transform

## 简介

Function to create reducer enhancers (higher order reducers) that allow to add pre- and post-processing, handling arrays of actions, filtering and transforming of actions and state.
