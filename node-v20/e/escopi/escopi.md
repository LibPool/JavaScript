# escopi

> 标签: barcode, esc-pos, escpos, pdf, qr, receipt, thermal-printer, ticket

## 简介

Escopi converts raw ESC/POS data into a PDF that can be previewed, printed, downloaded, uploaded, or stored through standard browser APIs.
