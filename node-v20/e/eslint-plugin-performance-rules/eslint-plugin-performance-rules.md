# eslint-plugin-performance-rules

> 标签: big-o, complexity, eslint, eslint-plugin, eslintplugin, lint, nodejs, optimization, performance, react

## 简介

ESLint plugin that catches accidental O(n²) complexity and other runtime performance anti-patterns — nested loops over the same array, linear searches in loops, blocking sync calls, and more
