# easy-search-along-the-way

> 标签: along-the-way, amap, gaode, geo, mcp, modelcontextprotocol, poi, 高德

## 简介

MCP Server：周边搜索 + 沿途搜索，基于高德地图 Web 服务 API。给一个位置查周边商店；给起点终点查沿途的目标（加油站、超市等）。
