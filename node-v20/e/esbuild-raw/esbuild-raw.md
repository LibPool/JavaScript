# esbuild-raw

> 标签: build-tool, code-import, documentation-tools, esbuild, esbuild-plugin, esbuild-raw, file-loader, frontend-tooling, import-as-text, javascript, mayank1513, plugin, raw-file-loader, raw-text-import, react-live, tsup-plugin, typescript

## 简介

An ESBuild and TSUP plugin that allows importing files as raw text. Useful for loading code files in documentation, interactive demos, or tools like react-live.
