## 简介

Official ElizaOS plugin for Coin Railz (PR #8382). Yield-While-Trading on Base (Aave/Compound/Morpho) + Solana (Kamino). x402 services include NASA satellite data, Robinhood Chain, B20 compliance, prediction markets, AI inference, IoT/DePIN, vltUSDC vault
