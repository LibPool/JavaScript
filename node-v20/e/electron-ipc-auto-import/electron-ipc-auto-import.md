# electron-ipc-auto-import

> 标签: auto-import, contextBridge, electron, ipc, type-safe, unplugin, vite, webpack

## 简介

An Electron plugin for automatically discovering and registering type-safe IPC handlers, inspired by unplugin-auto-import.
