# ember-powered-datepicker

> 标签: datepicker, ember-addon, ember-power-calendar-addon, power-calendar, power-datepicker

## 简介

Ember.js datepicker component based on power-calendar using ember-tether to make the ultimate datepicker we all dreamed of. No bootstrap.
