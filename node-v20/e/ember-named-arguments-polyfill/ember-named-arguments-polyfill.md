# ember-named-arguments-polyfill

> 标签: ember-addon

## 简介

Polyfills support for named arguments for Ember 2.10 through 3.0.

## 官网

- 源码仓库：git@github.com:rwjblue/ember-named-arguments-polyfill.git
- npm 页面：https://www.npmjs.com/package/ember-named-arguments-polyfill

- npm registry：https://registry.npmjs.org/ember-named-arguments-polyfill
- Node 要求：6.* || 8.* || >= 10.*
