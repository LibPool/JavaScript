# eslint-plugin-ng-onpush-migration

> 标签: angular, change-detection, eslint, eslint-plugin, eslintplugin, onpush, performance, rxjs, typescript, upgrade-readiness

## 简介

ESLint plugin that flags Angular upgrade risk and OnPush performance debt — nested state mutation, RxJS/async callback reassignment, and change-detection hazards — across Angular v6 through v22.
