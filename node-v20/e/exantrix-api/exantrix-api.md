# exantrix-api

> 标签: 3d-printing, api, dtf, ecommerce, exantrix, marketplace, prestashop, shopify, webhook, woocommerce

## 简介

Client Node.js de l'API vendeur Exantrix : produits, stock, commandes, expedition et verification des webhooks signes de la marketplace exantrix.com (impression 3D, DTF, textile).

## 官网

- 官网：https://exantrix.com/extensions/api
- 源码仓库：git+https://github.com/tony-dev-web/exantrix-api-js.git
- npm 页面：https://www.npmjs.com/package/exantrix-api
