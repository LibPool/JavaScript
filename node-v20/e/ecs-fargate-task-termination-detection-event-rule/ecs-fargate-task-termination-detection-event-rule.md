# ecs-fargate-task-termination-detection-event-rule

> 标签: aws, aws-cdk, cdk, ecs, event, fargate, rule

## 简介

An AWS CDK construct that creates an Amazon EventBridge rule to detect ECS/Fargate task terminations caused by unexpected failures (non-zero exit codes and startup/pull failures), while excluding expected operational stops.
