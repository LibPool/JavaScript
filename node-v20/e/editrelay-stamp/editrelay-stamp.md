# editrelay-stamp

> 标签: astro, cms, editrelay, visual-editing, vite-plugin

## 简介

Build plugin that marks a site's editable elements so EditRelay can edit them in place. Does nothing unless enabled.

- 源码仓库：git+https://github.com/EditRelay/webapp.git
