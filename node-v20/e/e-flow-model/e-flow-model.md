# e-flow-model

> 标签: JavaScript

## 简介

基于bpmn.js的flowable流程引擎的模型编辑器(Demo版) 保存按钮目前是输出xml至控制台 ``` │  App.vue │  main.js │ ├─assets │      activiti.json │      flowable.json #flowable 引擎参数类型绑定 │      logo.png │ ├─components │  │  HelloWorld.vue #主页面 │  │ │  ├─customModeler #自定义bpmn.
