# easy-yandex-s3-extended

> 标签: aws, bucket, cloud, s3, yandex

## 简介

This is an extended easy-yandes-s3 [ https://www.npmjs.com/package/easy-yandex-s3 ] module with ability to handle the *.txt *.doc *.xls *.csv file extensions
