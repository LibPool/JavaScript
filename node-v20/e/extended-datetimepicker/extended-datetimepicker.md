# extended-datetimepicker

> 标签: angular, angular calendar, angular datetime picker, angular datetimepicker, angular-material, calendar, datetimepicker, front-end, material, momentjs, web

## 简介

Basic date time picker with ability to disable set of continuous or non-continuous date sets.
