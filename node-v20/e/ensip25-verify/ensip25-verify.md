# ensip25-verify

> 标签: agent-identity, cli, ens, ensip-25, erc-8004, ethereum, web3

## 简介

CLI verifier for ENSIP-25 agent registrations — resolves ENS names to ERC-8004 agents and cryptographically verifies ownership
