# eslint-plugin-aria-a11y

> 标签: a11y, accessibility, aria, eslint, eslint-plugin, eslintplugin, formatter, jsx, oxlint, react, wcag

## 简介

The accessibility formatter — meaning-preserving ARIA fixes that gate CI, plus lint-tier a11y checks. Runs in ESLint and oxlint.
