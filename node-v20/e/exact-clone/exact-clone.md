# exact-clone

> 标签: circular, clone, copy, deep-clone, deepcopy, immutable, map, set, structuredClone, zero-dependency

## 简介

Deep clone that keeps Map, Set, Date, RegExp, typed arrays, Error, class prototypes and cycles — at any depth, without recursion. Zero dependencies.
