# eslint-plugin-stringlint

> 标签: eslint, eslint-plugin, eslintplugin

## 简介

这是为项目定制的eslint插件，主要目的为禁止项目中出现的不合法字符串

## 官网

- npm 页面：https://www.npmjs.com/package/eslint-plugin-stringlint
