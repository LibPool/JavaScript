# embed-dlsurf-blogs

> 标签: blog, blog-renderer, dl.surf, dlsurf, embed, gmailo, nextjs, react, tiptap

## 简介

Embed DL Surf blog content into any React app — a full blog listing page **and** individual post viewer, all in two components.
