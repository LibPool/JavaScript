# emic-mcp

> 标签: JavaScript

## 简介

MCP del integrador EMIC: crea, programa y compila soluciones EMIC desde tu cliente de IA (Claude Code, Claude Desktop, Cursor) contra la API de soluciones de emic.io.

## 官网

- 官网：https://emic.io
- npm 页面：https://www.npmjs.com/package/emic-mcp

## 历史版本号

- 0.1.0

## 获取地址

- npm 安装：`npm install emic-mcp`
- npm registry：https://registry.npmjs.org/emic-mcp
- Node 要求：>=20
