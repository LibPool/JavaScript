# exercisebank-mcp

> 标签: claude, exercise api, exercise video api, exercisebank, fitness api, mcp, mcp-server, model-context-protocol, workout

## 简介

Model Context Protocol server for the ExerciseBank API (exercisebank.net): search 1,492 filmed exercises by muscle, equipment, movement pattern, difficulty and joints to avoid; get substitutes with reasons.
