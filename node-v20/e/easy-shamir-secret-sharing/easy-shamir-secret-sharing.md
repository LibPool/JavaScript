# easy-shamir-secret-sharing

> 标签: JavaScript

## 简介

easy-shamir-secret-sharing 是一個基於 Shamir 秘密分享方案的 TypeScript 庫。此庫允許將一個秘密分割成多個分享，並且需要一定數量的分享才能重建原始秘密。該庫提供了兩種編程風格：已實例化的物件風格和函數風格。
