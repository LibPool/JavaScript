# eslint-formatter-safety-web

> 标签: JavaScript

## 简介

[ESLint formatter](https://eslint.org/docs/latest/extend/custom-formatters) that presents the results of eslint-plugin-safety-web. This formatter only makes sense when eslint-plugin-safety-web is also installed.

- 源码仓库：git+https://github.com/google/safety-web.git
- npm 页面：https://www.npmjs.com/package/eslint-formatter-safety-web
