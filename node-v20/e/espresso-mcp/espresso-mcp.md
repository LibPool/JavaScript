# espresso-mcp

> 标签: ai-tool, claude, coffee, espresso, mcp, model-context-protocol, openai, specialty-coffee, third-wave

## 简介

MCP server for finding great espresso cafes. Codifies what makes great espresso into a transparent scoring algorithm, backed by a curated database of specialty coffee shops.
