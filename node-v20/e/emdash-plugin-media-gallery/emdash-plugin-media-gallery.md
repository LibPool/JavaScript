# emdash-plugin-media-gallery

> 标签: astro, cms, emdash, emdash-plugin, field, gallery, images, media, widget

## 简介

A multi-image gallery field for EmDash CMS: ordered media arrays with per-item metadata, a primary flag, and media search.
