# easy-toggle-state

> 标签: accessibility, checkbox, dropdown, lightbox, modal, navigation button, radio, switch, tabs, toggle, tooltip, ui components

## 简介

A tiny JavaScript library to easily toggle the state of any HTML element in any contexts, and create UI components in no time.
