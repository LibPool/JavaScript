# eaa-kit

> 标签: a11y, accessibility, accessibility-statement, agid, axe-core, barrierefreiheit, bfsg, cli, eaa, en-301-549, rgaa, wcag

## 简介

WCAG 2.2 AA auditor and EU accessibility statement generator for seven countries (AT, DE, CH, ES, FR, IT, NL). Audits a static build or a running site from the command line.
