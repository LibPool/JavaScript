# eslint-plugin-ime-safe-form

> 标签: IME, accessibility, composition, enter, eslint, eslint-plugin, form, isComposing, keydown, keypress, keyup, react, submit

## 简介

ESLint plugin to enforce IME-safe key-event handling — requires e.isComposing guards in keydown/keyup handlers and prohibits deprecated keypress events
