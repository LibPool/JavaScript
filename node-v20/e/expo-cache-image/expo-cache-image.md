# expo-cache-image

> 标签: cache, cached-image, expo, expo-file-system, image, image-cache, offline, prefetch, react-native

## 简介

Drop-in cached Image component for Expo / React Native. Downloads remote images once, stores them on the device's local filesystem, and serves them from cache on every subsequent load.
