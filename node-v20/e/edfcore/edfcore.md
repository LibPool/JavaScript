# edfcore

> 标签: bdf, bdf+, biosignal, ecg, edf, edf+, eeg, emg, european-data-format, neuroscience, neurotech, parser, polysomnography, sleep, typescript

## 简介

Modern, typed, zero-dependency reader for EDF, EDF+, BDF and BDF+ biosignal files. Works in browsers and Node with true random access.
