# expo-phone-number-hint

> 标签: android, autofill, expo, expo-module, google-identity, google-play-services, login, onboarding, phone-hint, phone-number, phone-number-hint, play-services-auth, react-native, sign-up, sim

## 简介

Expo module wrapping Google's Phone Number Hint API, provides a frictionless way to show a user's (SIM-based) phone numbers as a hint.
