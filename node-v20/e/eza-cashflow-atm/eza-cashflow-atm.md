# eza-cashflow-atm

> 标签: atm, eza, machine, npm

## 简介

An interactive ATM simulator built with TypeScript, Node.js and Inquirer, Allows users to manage their bank accounts, check balances, withdraw cash, and perform fast cash transactions with ease.
